# 三、試驗趨勢線需要第三點的驗證

道氏理論十分重视相互驗證。因此，畫出直線後，還應得到第三個點的驗證，才能確認這條趨勢線是有效的。一般來說，所畫出的直線被觸及的次數愈多，其趨勢線的有效性就愈能得到確認，用它進行預測就愈準確、有效。此外，這條直線延續的時間愈長，就愈具有可靠性。
