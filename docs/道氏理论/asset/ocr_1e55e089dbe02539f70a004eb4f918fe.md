# 理論篇

在次級波中，逆向次級波是最具虛假性的欺騙性波動，也是市場得以存在的基礎，更是導致絕大部分投資者失敗的陷阱。對信奉道氏理論的投資者或者「順勢而為」者來說，最困難之處莫過於能把基本波中常見的次級波與掉頭反轉的基本波的第一段次級波區分清楚。

關於什麼樣的情形才是真正的反轉信號，這一點在道氏理論家之間還有爭議。不過，作者試圖從基本概念入手，將問題搞清楚。根據道氏的趨勢定義，如果一系列漲勢的高點不斷墊高，回檔走勢的低點也高於先前的低點，這代表牛市；反之，市場則處在熊市中，即一系列的高點與低點不斷下滑。因此，必須要有一個判斷反轉的方法。判斷反轉的工具有許多，如趨勢線、軌道線和移動平均線等。在這裡，我們依據道氏為趨勢下的定義。我們可以利用跌破前期低點（牛轉熊）和突破前期高點（熊轉牛）來確定反轉信號。反轉信號有兩種形態：「一蹶不振」型和「物極必反」型。
