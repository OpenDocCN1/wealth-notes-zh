# # 理論篇

# # 第九章：
## 牛市的波動特性

有一個有趣的問題，道氏為什麼要用「牛」、「熊」這兩種動物來代表兩種不同性質的市場呢？據說道氏借用這兩個動物來形容股市是因為它們的進攻特性，從熊和公牛的習性分析，公牛更有蠻勁，更有攻擊性；雖然熊也十分強壯，但和見人就頂的公牛比起來，它們善於沉思，並且易於撤退。因此用牛市和熊市來形容股市中的兩個典型趨勢，這是非常具體而有趣的表達。道氏之所以不使用我們常用的上升趨勢、下降趨勢、漲勢、跌勢之類的詞彙來表達，是因為它們沒有表達出力量的特徵。牛、熊這兩種動物更加具體化地形容兩種趨勢中投資者的心態和行為。我們由此可以看出道氏的編輯風格，不但在詞彙上創新，而且用詞精準。

# ## 第一節 牛市是一股永遠向上的力量

# ### 一、牛市的意思

道氏用“Bull Markets”代表牛市，而且“Bull”是公牛，象徵粗壯有力、奮力向上頂的力量。因為公牛在進攻的時候不斷地用牛角向上頂，這個動作的意義在於向上的力量總是比向下的力量大。而這裡用“Bull”又有「哄抬股票價格，買進股票、等待價格上漲以圖謀利者」的意思。在牛市中，價格走勢的形態也像牛角，不斷用力向上頂。儘管有向下的動作，但那是為再次向上頂獲取空間。由於向上的頂力總是大於向下回測的力量，因此向上波動的空間總是於向下波動的空間。

牛市就是上漲的力量總是於下跌的力量，並伴隨有向下的動作的波動序列。
