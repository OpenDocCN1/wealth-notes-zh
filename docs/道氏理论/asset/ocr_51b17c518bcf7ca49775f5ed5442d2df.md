# ■ 三大定律的建立

技術分析的真正含義不是「看圖說話」，而是透過市場表面的波動，探索市

場基本波的規律方法。技術分析最終的目的就是為了確認市場和股票的基本波是

上漲還是下跌。但是技術分析派發展到今天，卻把這最基本的一點忽略了，執著

於如何精確地預測下個月、下一週、隔一天，甚至下一個小時、下一分鐘的具體

走勢和價位，並因此發明了許許多多眼花撩亂的「新技術、新方法」，但是最終

都沒能使散戶逃過失敗的命運。

希望能判定海浪中某一瞬間的小浪花飄向何方及波動幅度，過分注重技巧的

使用而忽略基本波，將原本並不深奧的投資弄得複雜異常，這是假技術分析人士

走入失敗的悲哀。究其原因，現代社會競爭激烈，生活節奏加快，分析師們為了

自己的職位和錢包，為了迎合現代人希望快速致富的夢想，憑藉中長期趨勢耐心

地慢慢累積財富的方法已經無法滿足人們日益貪婪的胃口，可以說人性的弱點註

定了假技術分析的失敗。

基本波是投資者所主要考慮的，對於投機者較為次要。而次級波與日常波動

都是附屬於基本波之中，唯有明白它們在基本波中的位置，才可以充分了解它

們，並從中獲利。道氏堅信，大部分股市投資者鍾情於市場的基本波，所以道氏

理論的主要著眼點是股市三種運動中的基本波。因為一旦股市潮流形成之後，儘

管也會時常發生次級波的干擾，出現日常波動的雜訊，但其整體趨勢仍會繼續延

伸下去，直到整個基本波發生根本性的逆轉。

這個原則也適用於投機者，他的操作目標是以順著次級波的方向為投資策

略。然而，這種方式不是道氏所贊成的。儘管投機者可以利用日常波動的發展，
