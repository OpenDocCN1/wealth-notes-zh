# ### 第三節 利用軌道線

+   1.和趨勢線一樣，軌道線顯示當價格向其固定方向移動時，它非常有可能是沿 著這條線繼續移動。正如趨勢線的情況一樣，軌道線未被突破的時間愈長，試探 成功的次數愈多，那麼它就愈重要愈可靠。如圖26-3-1所示。
