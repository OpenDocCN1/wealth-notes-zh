# 第一章
精讀道氏原文 了解原創精神

作者一直在思索一個問題：道氏理論給我們的最大啟示是什麼？在長期研究
之後，作者充分體認到，身為鼻祖級的理論，道氏理論給我們的最大啟示是，它
的原創精神和創新精神。

# 第一節 建立理論核心

我們今天所運用的技術分析方法都是根源於道氏理論，但是由於道氏為人
謙虛謹慎，因此，他並沒有針對「道氏理論」寫過書。在1901年和1902年上半
年，道氏寫過許多評論文章，分析股票投資的方法。因此，他的理論必須從這些
文章中以加以發掘，因為它只是說明性的，甚至是在不經意間得出的，所以從未成
為他討論的主要話題。

他的部分文章主要討論股票的投機活動，只是偶爾提到一些觀察市場的規
則，而且道氏特別對投機活動給予很高的評價。如果讀者沒有機會親眼見到道氏
