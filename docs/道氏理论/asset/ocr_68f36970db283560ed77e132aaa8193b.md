# ——成交量對趨勢的微觀驗證

# 第一節 成交量的意義

# 一、成交量

成交量是指我們所研究的對象在基本時間單位內成交的總額。交易所公布的成交數量有按單邊計算和雙邊計算兩種。在國內股票市場是按單邊計算，而國內期貨市場一般則是按雙邊計算。單邊是指多頭資金或者是空頭資金的數量，而雙邊是指多頭資金和空頭資金的總和，投資者須事先了解清楚。

我們最關心和主要研究的是每日的成交量。每日成交量通常設置在線形圖下部，也就是在價格變化圖之下，以一條豎線段表示。市場交易的要素是在有一個買方的同時，必須有一個賣方才能完成交易，所以每日成交量與買、賣數量的關係如下：

買進的數量＝賣出的數量

此外，在週線圖上，我們同樣也可以做出成交量。這時價格圖下方的豎線段對應於每一週的價格圖位置上，畫出的豎線段代表這一週內的總成交量。不過，在月線圖上，通常不再採用成交量。價格與成交量的關係主要是在日線圖中展現。
