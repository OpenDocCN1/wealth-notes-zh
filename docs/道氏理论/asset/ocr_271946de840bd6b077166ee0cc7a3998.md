# 三、依據道氏理論的選股原則選擇股票

從道氏的「價值觀」這個角度來說，道氏理論對於個股的選擇也是有帮助的。因為道氏在設計指數的時候已經制定了選股原則，那就是選擇具有長期投資價值的股票。從意義上來說，就選擇具有投資價值的股票而言，這已經不屬於技術分析的範疇。所以投資者在進入股票市場進行股票投資的關鍵是：首先要選取有價值並且有增值能力的優質股票，還要分析形勢，如經濟氣候、利率的趨勢、科技的發展、企業的獲利能力、股票市價相對於企業的獲利狀況、企業派息的政策等等，然後再配合技術分析進行投資。隨著工業和製造業公司的重要性逐漸超過鐵路公司，在1896年5月26日終於形成了12種股票為基礎的道瓊工業平均指數，如下表所示。
