# 四、必須建立的科學思想

道氏從來不說沒有根據的話，他早已發現基本波的運行週期是不嚴謹的，更沒有準確的時問表，這對於依據道氏理論研究趨勢發展變化的投資者來說面臨極大的困難，因此迫切需要其他的工具給予幫助。道氏指出，雖然道氏理論的核心是市場的三重運動，不過它並不是指一個指數的三重運動，它是建立在道瓊工業平均指數和運輸指數之上的，道瓊工業平均指數的波動必須得到運輸指數的支持和確認，才能最終發展成為股市的潮流，否則趨勢的發展將受到懷疑。幸運的是，道氏從一開始就建立了一套道瓊指數體系，這為驗證趨勢的發展變化情況，為必須建立的科學思想提供了天然土壤。

# 五、相互驗證原則是必要但非充分條件

在股票市場上，股票數量多，平均價格指數的種類也多，通常不能要求所有指數都相互驗證。為了判斷牛市的到來，各種主要指數必須能相互驗證。牛市的力量愈大，則相互驗證的指數種類必定愈多。如果某個價格指數不能創新高，至少也不能創新低。
