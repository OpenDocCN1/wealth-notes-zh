# 三大定律的建立

# 三、無人能準確預測趨勢將延續多久

趨勢的實質是質的因素，質的因素難以合理評估。如果對趨勢給予壓倒性的重視，將會導致對股票價值的高估或低估。之所以會出現這種偏差，是因為任何人都無法準確預測出趨勢將延續的時間有多長，這給順勢而為的投資者帶來極大的困難。

在前面的章節中已經論述，基本波沒有一個嚴謹的、確定的時間表，時間週期並不準確，也就是歷史會重演，但又不會簡單重演。所以看似有數學根據的估算實際上只是出於心理的因素，而且隨機性很強。於是我們把趨勢當作一種質的因素來考慮，儘管它可能可以量的形式出現。

從確定性的角度來說，趨勢實際上是以一種明確預測的形式表述對未來前景的看法。與之相似的是，關於某個企業的業務性質及管理階層能力的結論之所以重要，主要也是因爲它們與未來前景有關。這些質的因素都具有相同的基本特徵，都對分析構成同樣的困難——無法準確判斷這些因素應在價格中被反映的程度。在大多數案例中，如果這些因素得到確認，則往往會被過度重視。我們從一般的市場中發現，這樣的情況經常出現。過度漲跌一再出現的根本原因在於，當前景成爲決定價值的主要基礎時，由此得出的判斷就不再受數學上的約束，幾乎不可避免走向極端。

身爲投資者所關心的，應該是有事實支撐的價值，而不是主要以預測爲基礎的價值。從這個角度而言，投資者所使用的方法與投機者的方法截然相反，後者的成功主要取決於預測或猜測的能力。當然，投資家也必須考慮到未來可能發生的變化，但他们這麼做的主要目的不是希望從預測中獲利，而是防止因爲變化遭受損失。總而言之，投資家將未來發展看做是一種自己的結論，必須面對的風險因素，而不是他的分析依據來源。
