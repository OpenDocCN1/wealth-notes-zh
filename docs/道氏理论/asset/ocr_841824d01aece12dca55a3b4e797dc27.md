# 理論篇

# 一、正確確定基本波對成功投資的極端重要性

基本波所指出的是市場價格波動的基本方向。它以「牛市」與「熊市」輪動的形式來表現。一般來說，趨勢所涵蓋的時間愈長愈容易辨識。因此基本波最容

易辨認，也最有規律。不過，不同時期、不同情況的牛市或是熊市在時間上都會

不同，甚至會有很大的差異。以往一般的牛市只會維持兩、三年，但1987年後

開始，美國股市的大牛市卻能夠維持十多年，這和以前的牛市是不同的。

在理想的狀態下，牛市的上漲幅度應該等於熊市的下跌幅度，但兩者實際

上會有差異。因為推動股價上漲所耗費的時間，通常長於股價的下跌，所以牛

市所涵蓋的時間一般要長於熊市。以後牛市和熊市的時間可能會和以前的有更

大的差別，投資者除了應參考以往牛市、熊市時間，也要參考當時的經濟因

素，以及針對不同類型的市場進行研究，進而適當地判斷當時的牛市、熊市會

維持多長時間。

# 二、無法準確預測基本波的時間長度

迄今沒有任何方法能準確預測基本波的時間長度。時間長度可能少於1年，

也可能長達數年之久。而基本波所涵蓋的期間通常在1～2年之間，反映的是投資

者對於經濟週期發展的態度。在統計上，經濟週期由谷底到谷底所涵蓋的期間平

均大約為3.6年，所以牛市與熊市各自持續大約1～2年。

一百多年前道氏就提出沒有任何方法能準確預測基本波的长度，一百多年

後，仍然沒有任何方法能準確預測基本波的長度。這是一個非常重要的哲學思

想。投資者相信不可能發現能準確預測基本波长度方法的重要意義在於，投資方

法應以趨勢跟蹤技術為基礎，而不是以趨勢預測技術為基礎。
