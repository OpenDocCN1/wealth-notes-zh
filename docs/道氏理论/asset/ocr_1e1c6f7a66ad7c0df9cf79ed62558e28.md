# 附錄一：

# 開山始祖——查理斯·亨利·道

# 道氏是誰

道氏——查爾斯·亨利·道（Charles Henry Dow，1851～1902），是美國經濟學家和出版家。他是美國股市運動造詣最深的學者之一，是道氏理論的創始人，他被稱之為股市投資的先驅和宗師是當之無愧的，其歷史地位，以及他對於金融投資發展所作出的傑出貢獻也是首屈一指、舉世公認的。

1851年11月6日，道氏出生於美國東北部的新英格蘭康乃狄克州的斯特靈（Sterling）的一個農夫家庭。20歲時，他便開始採訪、編輯、撰稿評論的記者和編輯生涯，最初擔任美國麻省一家共和黨的編輯，先後為新英格蘭地區的三家當地報刊撰寫經濟與金融方面的新聞和編審社論。他是一位經驗豐富的新聞記者，早年曾得到薩爾爾·鮑爾斯的指導，後者是普斯林菲爾德《共和黨人》傑出的編輯。

道氏聰明、自制而且極度保守，他對自己的事業瞭若指掌。無論論戶對他討論的熱情多麼高漲，他都能以法官般的冷靜來思考任何事情。漢密爾頓說：「我從未見過他發怒，不僅如此，我甚至從未見他激動過。」極度誠實和良好的感覺使他贏得了每一位華爾街人士的信任，而當時在金融領域幾乎見不到幾位勝任的報業人士，對金融業有深入了解的人就更少見了。

道氏是紐約道瓊金融新聞服務的創始人，1882年11月，查爾斯·亨利·道與愛德華·瓊斯（Edward Jones）、查爾斯·柏格斯特里瑟（Charles Bergstresser）三人合夥共創了道瓊公司（Dow Jones & Company. 股票代碼DJ），利用與紐約股票交易所相毗鄰的優越條件，專門向投資客戶遞送他們透過複寫紙手寫的有關股票、債券交易
