# ## 理論篇

# ### 二、任意個股所伴隨的總風險包括系統性與非系統性風險

1896年的美國股市，當時組頭控制股價獲取暴利的行爲，正如上世紀90年代的新興亞洲股市一樣盛行。道氏能在當時這種市場氛圍中掃除迷霧，觀察出整體市場背景對個股股價表現的整體制約關係，可說目光如炬，見識和膽量過人。道氏所表現出的非凡智慧，絕非是普通的急功近利之輩可以比擬，這也是順勢而為思想的最好表現。這種超越常人的非凡觀點之所以能夠產生，如果沒有深厚的投資哲學思想的指導是無法想像的。

在道氏所處的時代之前，許多銀行家及商人都熟知，大多數上市公司的股票價格都傾向於同時漲跌；而那些與整體經濟趨勢相反的特例很少，一般說來，持續這種相反的走勢，不會到幾天或幾週的時間。每當一個漲勢出現後，某些股票總是比一些股票漲得快，漲幅也大一些。當這個趨勢開始轉向熊市時，一些股票迅速地下跌，而另一些則可能表現出一定的抗拒力量，以阻止這種下拉市場的作
用力，這個事實仍然保持著：大多數股票都傾向於同時波動，現在這樣，而且將
永遠如此。

上述事實已為人們所皆知，但經常被我們視為理所當然的事，以致於重要性
經常被忽視。實際上，從許多角度來看，這都是十分重要的。學習市場分析的投
資者，總是從學習道氏理論開始的一個最重要的原因，就是該理論強調整體市場
趨勢。

道氏提出一個目前成為現代金融理論之定律的命題，即任意個別的股票所伴
隨的總風險包括系統性風險與非系統性風險。其中，系統性風險是指那些會影響
全部股票的一般性經濟因素；而非系統性風險是指可能只會影響某一公司，對於
其他公司毫無影響或幾乎沒有影響的因素。

道氏的這個理論論斷，在現實的市場中表現為整體股票市場構成一個系統，
