# ## 二、支撐線轉化為壓力線

在牛市中，如果新的一輪調整一直下降到前一個低點的水平，這或許就是這輪牛市即將終結，或者至少即將蛻變成橫向延伸趨勢的先期警訊。如果價格觸及支撐線後沒有轉向，而是繼續向下，這就叫支撐線的突破。這條水平線仍然有實際作用，但這時名稱和作用已經改變，原來的支撐線變成了壓力線。以上的分析過程對於壓力線也同樣適用，只不過結論正好相反。
