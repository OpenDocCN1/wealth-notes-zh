# 四、相互驗證的適用範圍

在兩種平均指數得以存在的這些年裡，這個規則已經被證明是完全可靠的。它不僅適用於市場的基本波，大致上還適用於次級下跌和次級反彈。但是它不適用於日常波動，用它分析個別股票的波動將有可能得到錯誤的結論。同時，在其他市場，只要是有較強的相關性，但又受制於不同因素，這項原則就是適用的。例如，根據從事多年期貨交易的經驗來看，相互驗證理論也適用於商品期貨市場。

如圖15-2-1所示為倫敦三月期銅和倫敦三月期鋁、週線的價格對比圖。從倫敦銅、鋁的對比圖上看，無論是在大層級的基本波，還是在中層級的次級波，整體上它們都保持一致，但當銅、鋁的走勢相背離時，往住趨勢都將發生逆轉。
