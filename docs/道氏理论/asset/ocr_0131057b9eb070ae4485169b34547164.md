# 三、道瓊指數的誕生

道氏於1884年7月3日美國獨立日前夕，正式創立了一直沿用至今的股票市場平均價格指數——「道瓊平均工業指數」，經道瓊公司的計算和發布，首次進入華爾街，開創了美國金融投資的新纪元。當時只包括紐約股票交易所中11種最活躍和最流行的股票，其中有9家是鐵路公司。1885年2月16日，他開始公布12種股票（10種鐵路股票和2種工業股票）的每日平均價格，它們都是活躍的代表性股票。由於當時鐵路還是最主要的交通運輸工具，所以最初只包含10支最大的鐵路公司股票，稱之為「道瓊鐵路平均指數」（Dow Jones Railroad Average Index, DJRA）。1889年，道氏把每日平均價格的基礎擴大為20種股票（18種鐵路股票和2種工業股票）。1889年創建的老指數經過改組，在1896年10月26日重新命名為「鐵路平均指數」。

隨著工業公司和製造業公司的重要性逐漸超過鐵路公司，1896年5月26日，終於正式形成了以12種股票為基礎的道瓊工業平均指數（見本書432頁）。在1896年5月26日這個歷史性的日子，查理斯·亨利·道創立了道氏理論。從此，道氏開始在《華爾街日報》上發表含有道氏理論思想的文章，對美國的股票市場分析探討。有趣的是，據說道氏本人並未利用它們預測過個別股票價格的走勢。直到1902年道氏逝世，僅經歷了短短的5年時間，道氏就形成了自己的理論體系的整體輪廓。

之後，在1897年，原始的股票指數又衍生成兩個：一個是工業股票價格指數，由12種股票組成；另一個是鐵路股票價格指數，包含20種股票。
