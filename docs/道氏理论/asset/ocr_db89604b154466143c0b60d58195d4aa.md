# 第一節 基本波可預測原理

正確確定基本波的波動方向是決定成功投資（投機）的重要因素，投資勝負的更關鍵因素，也在於是否可以把投資建立在基本波的正確一方。

# 一、市場並不像在風中搖擺不定的氣球
