# 一 篇 理論篇

紙手寫的有關股票、債券交易的新聞。19世紀末的美國正值經濟飛速發展的高 峰，道瓊公司的客戶量不斷擴大。它是當時世界一流的商業財經資訊提供商，同 時也是重要的新聞媒體出版集團，總部設在美國紐約，後來旗下擁有報紙、雜 誌、通訊社、電臺、電視臺和網際網路服務等，目前在全球擁有近1,800名新聞 從業人員，這使得道瓊編发的股票價格指數更是家喻戶曉。

1789年5月，在紐約華爾街與百樂得轉角處的大楓樹下，剛有股票買賣活動 不久，美國財經新聞就誕生了。

1789年秋天，股票經紀人派職員到其他經紀人處交換最新的股票成交資 料。到1827年，華爾街下的曼哈頓區擠滿了交換資料的職員，每天要分送10份 手寫的小冊子給他們的訂戶。

1872年，愛迪生发明了用電報傳送資訊的方法，股票經紀人就在利用電訊將 最新的股票行情增送給用戶，每一用戶家裡裝置一臺收訊紙帶機，將電子信號轉 換成文字，提供用戶參閱。由於電報機傳送資料受到符號與數位的限制，所以仍 無法取代手抄小冊子。

1882年11月，查理斯・亨利・道、愛德華·瓊斯與查理斯・柏格斯特里瑟 離開了在當時財經新聞龍頭地位的《克爾倫新聞》，另創道瓊公司。

而在克爾倫時，柏格斯特里瑟發明一種描繪機，一次可以同時複寫35份， 使抄寫工作效率增加了4倍。在此之前，他曾以此為條件，要求平分《克爾倫新 聞》的股權，被克爾倫斷然拒絕，於是柏格斯特里瑟說服克爾倫的兩位記者道與 瓊斯共同冒險成立了新公司——道瓊公司。

道瓊公司以柏格斯特里瑟之筆（他發明的描繪機）使資料分送速度大為增 加，他們的編輯雖有未盡理想之處，但是他們的事業卻一帆風順地成長。公司創 立1年之後，柏格斯特里瑟說服他的夥伴，讓道瓊成為華爾街新聞服務界第一家 擁有印刷機的報紙，這項投資使公司的印刷量增加了一倍。由於採用打字印刷技 術，《道瓊公報》與手抄的報紙相較之下，在品質上也有了很大的改善。
