# 三篇 理論篇

在他的控制中萎縮。從某種意義上來說，萎縮的成交量更加真實。投資者愈認同股價，交易就愈清淡，成交量就愈小。而投資者對於股價的看法愈分歧，認為股價較低的投資者就愈積極買進，認為股價較高的投資者就會賣出手中持股，買賣交易就愈活躍，成交量就愈大。

從某種意義上看來，在趨勢穩定期，成交量並不一定隨著價格的上漲而增加，而成交量對趨勢的驗證主要是運用在趨勢的不穩定期。

# 第二節 成交量的性質

# 一、成交量領先於價格

「價隨量漲」這句話我們可以理解為：較重的成交量應該發生在與市場的基本波一致的方向上，因為成交量推動了價格的波動；而較輕的成交量反映在調整中，因為調整是由於驅動力量的減小。至於逆轉走勢是由於作用的力量發生了變化，也就是成交量的作用方向發生了變化。

如果說投資者認為利用成交量預測價格的走勢，其實是在說，無論是在上升趨勢中價格上漲力量的減小，還是在下降趨勢中價格下跌力量的減小，都可以透過成交量資料預先反應出來。如果用價格來分析，這一點要等到價格趨勢實際反轉時才能表現出來。但由於價格變化的實質是市場中買賣力量的變化——成交量作用之後結果反映在價格上，所以上升趨勢中購買力減退和下降趨勢中拋售力量的減弱，都能夠預先反映到成交量的變化上。
