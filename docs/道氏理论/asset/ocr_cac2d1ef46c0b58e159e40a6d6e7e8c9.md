# 二 篇 理論篇

# 二、成交量是推動價格波動的原動力

成交量是推動價格波動的原動力。像汽車一樣，發動機在能量的驅生下產生動力，投資者的觀點和資金推動投資品種的價格不斷波動。選像汽車轉彎需要動力一樣，價格轉彎也需要成交量，而價格走直線時因保持慣性通常並不需要太大的成交量。

成交量被認為是具有統計學確認意義的。成交量的大小可以用來測量市場價格波動的強度和緊迫性。成交量與價格結構成交易額，交易額的增加相當於貿易量的增加，代表經濟形勢轉好。

在研究價格行為變化時，透過考察成交量的變化，可以很好地把握市場變化後面的買賣雙方的力量，並借此來證實價格波動趨勢或警告價格波動的不可靠性。

此外，不論是股票市場還是期貨市場，以及其他金融市場，成交量是市場行為之一，也就是由眾多投資者參與的行為，因此必須要保持一定的成交量，才能證明參與者的眾多，否則應該考慮是否參與這種市場的交易。

# 三、成交量代表股市內的人氣
