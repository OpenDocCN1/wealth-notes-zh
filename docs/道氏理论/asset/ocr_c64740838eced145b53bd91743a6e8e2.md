# 理論篇

次級波震盪出局の經歷，而這正是恐懼的結果，怕失去已形成の浮動盈利或怕市場已經轉向等等。毎個有實戰經驗の投資人，也都能反省出自己已被日常波動誘發貪欲の經歷，如為了搶反彈而錯誤進場，最終虧了大錢等等。

# 結論：要注重對市場參與者心理特徵的理解與分析

根據三重運動原理，價格趨勢可以歸納為三類：基本波、次級波與日常波動。基本波涵蓋の期間通常為1年到3年，是反映投資人對經濟週期の態度。次級波所涵蓋の期間通常為3週到數月以上。這種趨勢雖然對投資者不是非常重要，但由於它具有使投資者產生恐懼心理の作用，因此辨識其方向仍有裨益。特別是在牛市の次級折返與熊市の第一波下跌，兩者之間的分辨可能是投資成敗の分水嶺。日常波動所涵蓋の期間通常短於三、四週，而且經常呈現隨機の性質，它發揮引誘散戶入市の作用。

對於短期交易の投資者，心理因素是最應該引起投資人重視的因素，對他們來說，心理分析對正確的投資決策具有重要的意義。投資者在進行心理分析時，必須要包括兩方面：一個是對自我の心理分析，它是解決投資人在投資決策過程中的心理障礙問題，要盡可能克服自身存在的弱點，特別強調戰勝貪婪和恐懼の心理；另一個是對市場の心理分析，它是解決投資者對市場中其他投資人的心理活動特徵的把握問題，特別強調注重逆向思考，反對盲從行為，以避免成為市場の「多數人」。

任何事物の性質都是由它的結構所決定，次級波也不例外，其實「零和機制」是股票、期貨、外匯，以及其他金融市場的基本機制，也正是次級波才使得市場の「零和博弈」特徵得以保持。而次級波所引起投資者強烈的恐懼心理，使得真正能認出基本波の人並不多。也就是說，次級波の存在，使得市場上只有少數人能夠成為最終贏家。
