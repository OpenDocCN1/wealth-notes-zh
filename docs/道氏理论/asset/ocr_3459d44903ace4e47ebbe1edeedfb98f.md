# 三大定律的建立

哲學家所表達的世界觀。其實他所說的錯誤，正是市場發展變化的原因，價格之所以變化，是由於原來的價格是錯誤的，而變化和發展就是改正原來的錯誤並向正確的方向發展，一系列的改正錯誤，就形成了市場發展的趨勢，這不就是市場以趨勢方式演繹嗎？

技術分析所謂的預測，就是圖形的提前反映，並不是無根據的臆測，而是建立在對於規律的把握上。我們進行技術分析的重要依據是三大定律：市場行為依趨勢方式演繹、市場行為包容一切、歷史會重演。其實，這三大定律說的只有一件事——市場運動是有規律的。

道氏理論已經存在一百多年了。迄今為止，在眾多的市場分析理論中，道氏理論占有最重要的地位。不過，除了它的穩健性和通用性之外，道氏理論的精髓在很大程度上仍不為人知。道氏理論首先是一種關於股票投资的哲學理論，其次才是一種技術方法體系。在作者對道氏理論進行研究時，驚異地發現，道氏理論的思想是如此之正確，它能夠解釋我們至今也解釋不清的東西。對於我們今天的投資觀念都有鮮明的指導意義。

一套科學的技術分析方法的背後，一定有著深刻的理論基礎和哲學背景。缺少理論基礎的技術分析，很難有較強的生命力和較高的實用價值。因此，想要全面深刻地把握一套技術分析方法，找出這套技術背後的理論基礎是最關鍵的。現在，讓我們收起浮躁的心，來學習道氏理論吧！
