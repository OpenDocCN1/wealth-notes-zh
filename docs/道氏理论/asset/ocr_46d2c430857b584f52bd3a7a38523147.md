# 第二節 次級波的性質

# 一、具有騙人的性質

我們知道次級波時而與基本波方向相同，時而與基本波方向相反，次級波極具欺騙性，常使人誤認為基本波已經開始轉換。次級波經常被誤以是是基本波的改變，因為牛市的初期走勢可能僅是熊市的次級反轉，相反的情況則會發生在牛市出現頭部後。次級波的這種欺騙性根源於最後一個次級波，實際上可能成為下一個基本波中的第一波。因為牛市的初期走勢，可能僅是熊市的次級波。相反地，熊市的初期走勢也可能是牛市的次級波。所以次級波也經常被誤認為是基本波的改變。道氏理論的前輩們認為，次級波是騙線，並教導我們不要理會它。

特別是次級波會受到一定的人為操縱，所以它具有些騙人的性質。因此，道氏將次級波說成是騙線，這當然帶有很強的情緒化色彩。通常認為次級波帶有一定的為人操縱性質，但是我們常常看到操縱市場的人也被市場所欺騙，正是因為這一點，道氏並不認為次級波與人類的影響有關。
