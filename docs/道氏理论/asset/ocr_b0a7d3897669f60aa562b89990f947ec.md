# 三大定律的建立

圖20-1-3的範例a代表理論性的牛市，中間夾雜著次級波。在範例a中，指數的走勢是由三個波峰與波谷所構成，第四波的漲勢未能夠穿越第三個波峰。在隨後的跌勢中，指數跌破先前的低點，在這種情況下，就存在著兩個依次下降的峰和兩個下降的谷，並在X點確認熊市的開始。X點是道氏確認日。這種反轉形態常常被稱為「一撅不振」。X點也是一個清晰的賣出信號。圖20-1-3範例b是相反的情況。

# 四、舊趨勢的結束

在許多情況下，波峰與波谷的演進形式可能比圖20-1-1和圖20-1-2複雜。以圖20-1-4的範例c來說，波峰與波谷最初不斷抬高，稍後雖然繼續創新高，但價格拉回時，在X點跌破先前的低點。在這個時候，不斷墊高的波谷已經中止，但波峰仍然超過前期的波谷。換言之，X點僅產生一半的信號。
