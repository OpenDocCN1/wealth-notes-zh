# 三大定律的建立

牛市，所對應的就是道氏所說的「牛市中第三次擺動」。牛市第一期，也就是第一個次級波動，對應第一次擺動是前一輪熊市的過度悲觀之後的一次反彈開始；牛市第二期，也就是第二個次級波動，對應第二次向上擺動與商業和利潤的增長運動；牛市第三期，也就是第三個次級波動，對應第三次也是最後一次擺動的是與價格背離的價值。這裡再次提醒讀者，將一個基本波分為三個時期是一種理想的情況，因此讀者在市場中發現較多或較少的時期也沒有什麼奇怪的。

如同基本波動一樣，次級波所構成的是次級波動。一個次級波動也有兩個方向，一個是與基本波方向相同的正向次級波，另一個與基本波方向相反的逆向次級波所構成。根據週期理論，一次運動是由低點到低點來衡量（參考圖12-1-1）。

但是這裡有個問題，如果嚴格按照週期理論的分法，很難找到合適的熊市中次級波動順序的分法，而把熊市定義當作依據的話，熊市的次級波動應該按照圖12-1-1上方的標注方式。也就是在牛市第三期中包含熊市第一期的一部分；同理，熊市的第三期中也包含下一輪牛熊市第一期的一部分。從這個意義上來說，次級波的欺騙性部分就是來自於牛市第三期與熊市第一期，或者本輪的熊市第三期
