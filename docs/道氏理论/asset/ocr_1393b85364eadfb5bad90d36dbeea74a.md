# 上編 理論篇

2000年9月15日，儘管由於銅價最高到達2,036美元／噸，超過了1月28日的高點1,919美元／噸，本應繼續上漲，但是鋁價在9月15日最高僅到達1,668美元／噸，沒有超過1月28日的最高價1,731美元／噸。在沒有得到鋁的驗證情況下，銅的上漲沒有繼續。

由此可以看出，不管是基本波還是次級波，相互驗證原則都是適用的，當得不到相互驗證時，即相互背離時，原來的趨勢都將難以繼續。

# 結論

相互驗證原則是十分重要的，它貫穿於市場分析的始終。是為了驗證趨勢的發展情況，道氏根據道瓊指數體系，建立了道氏理論整體技術分析科學思想，這為作者利用道氏理論建立道氏理論模型進行整體技術分析奠定了理論基礎。

道氏理論是建立在道瓊工業平均指數和運輸指數體系之上，為了使趨勢得到確認，道瓊工業平均指數的波動必須得到運輸指數的支持和確認，才能最終發展成為股市的趨勢。也就是說，只有股市的次級波使這兩個指數同時處於漲潮或退潮階段時，才能證實整個股市基本波的形成與發展，否則就不能確定。

相互驗證並非是現象之間簡單的驗證，它是指相關性很強，但又受不同相關制約因素影響的相互驗證關係，其實是對不同要素、不同指標間的相互驗證。雖然兩者的制約因素不同，但是又有較強的相關性，這是相互驗證原則成立的必要條件。正因為如此，道氏理論的市場信號經常有一個較長的延後期，因為它必須等候另一指數尾隨進入相同的漲落期，才給出同樣的趨勢信號。
