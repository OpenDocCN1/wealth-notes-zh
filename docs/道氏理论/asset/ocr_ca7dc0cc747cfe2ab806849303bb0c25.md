# The cornerstone of analysis of **stock market**

善、不斷創新的理論。當今的年代是一個理論創新的年代，一百多年來道氏理論也在發展，也在創新。

不論是成功的資本家，還是普通的投資者，都應該學習道氏理論這樣經典的投資理論：一分耕耘，一分收穫。當代最傑出的投資理論家索羅斯先生說：「你對抽象理論愈是能潛心研究，那你對具體實踐就愈顯得得心應手，遊刃有餘。」幾百年來，真正偉大的實戰投資家均在經典投資理論的研究上有着重大的理論突破，並且在他們自己的投資觀念、投資哲學的認知上都有獨到之處。
