# 圖 實戰篇

道氏理論也可以說是他從實踐中總結出來的。漢密爾頓在《股市晴雨表》中提到：「道氏還曾是紐約股票交易所的成員，在股票交易所大廳裡工作過一段時間（1885～1891年）。在羅伯特·古德鮑蒂為加入美國國籍而必須等待的時間裡，道氏把持著股票交易所的席位，並在大廳裡執行各種指令。」從這段描述可以看出，道氏當時應該掌管著巨額資金。作者認為，道氏理論基本思想的形成與這段經歷分不開。作者估計，道氏當時的確用巨額資金操縱過市場，但都沒能成功，透過對於巨額資金的運作，道氏從中領悟到很多哲理，其中包括：「基本波是不可能被操縱的；價格走勢具有三重運動的性質；基本波是可以被預測的；趨勢的確立必須經過相互驗證；投機行為是市場中最鲜活的因素，是市場趨勢能被預測的根源。」等衆多思想，很有可能就是他的「親身體會」，甚至於有可能包括「慘痛的教訓」。不過，作者還是喜歡做這樣的推測，道氏在市場操作過程中，最終也是獲得了巨大的成功，只是由於道氏本人過於謙虛，他自己從不提起罷了。

當然，世界上不僅是道氏操縱過市場（如果是這樣的話），有意操縱市場的人不計其數，但其他的人並沒有領悟到市場的基本波是不可被操縱的這個道理，那是因為「偉大的理論只有偉大的人才能被發現」。只有偉大的人物才能從最普通、最平常的事物中發現偉大的真理。正如只有牛頓才能從樹上的蘋果落到地上的現象中發現萬有引力一樣，世界上也只有偉大的查爾斯·亨利·道才能從看似平常的市場行為中，發現道氏理論基本思想的深邃內涵。

然而，真正使道氏理論大放異彩、備受矚目的是道氏在《華爾街日報》的助手和傳人，也就是道氏之後的《華爾街日報》總編輯威廉·彼得·漢密爾頓，他的數篇社論，尤其是1929年10月25日在經濟危機爆發、股市崩盤臨近時的23日所寫的著名社論「潮汐逆轉」（A Turn in the Tide），正確地指出「牛市」已經結束，「熊市」時代來臨。這篇文章是以道氏理論為基礎提出的預測。緊接這一預測之後，果然發生了可怕的股市崩盤，於是道氏理論名噪一時，牢固確立了道氏
