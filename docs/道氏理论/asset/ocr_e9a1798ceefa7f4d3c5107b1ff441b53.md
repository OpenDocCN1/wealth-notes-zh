# ④ 篇 理論篇

熊市的開始實際上是以下級波輸動的下降階段來表現的，通常會呈現兩種普遍的性質：(1)在下跌過程中成交量放大；(2)折返的幅度可能「吃掉」或遮掩同一輪動上升階段的80%以上。折返的幅度愈大，基本波發生反轉的可能性便愈大。如果折返的幅度超過100%，這代表價格已經破壞了先前不斷墊高的谷底 的牛市定義，因此，基本波發生反轉的可能性大增。

+   2. 由熊市反轉為牛市。在熊市中，正向次級波創新低點時，成交量應該放大，所以次級波跌勢中的成交量一旦縮小，必須留意熊市可能即將結束。折返的幅度愈大，熊市發生反轉的可能性就愈大。

一個徵兆是折返幅度至少是前一波跌勢的80%。如果次級波的跌勢沒有創新低，情況更是如此。如果折返幅度超過100%，強烈顯示熊市可能發生反轉，因為價格已經向上穿越不斷下滑的頂點。因為熊市的特色——一系列不斷下滑的低點，也就是熊市定義——已經不復存在。隨之而來的是，在牛市的第一個正向次級波中，通常出現大成交量，而且明顯大於先前的次級上升波。換言之，牛市開始的成交量將大於先前熊市的次級反彈波動 的成交量。

# 三、成交量對價格形態的驗證

在對價格形態的討論中，我們也把成交量看做重要的驗證指標。頭肩頂成立的預兆之一，就是在頭部形成的過程中，當價格衝到新高點時成交量較輕；而在隨後跌向頸線時成交量卻較重。在M頭和三重頂中，價格上衝到每個後繼的峰時，成交量都較輕；而後的回落中，成交量卻較大。

# （一） 圖形構造的形成

+   1. 頭肩形構造

在頭肩形構造中，通常在左肩處成交量較大，而其回落點的成交量稍為減少；頭部高於左肩，但成交量少於左肩（這是明顯的超買現象）；右肩低於頭部，成交量明顯減少。
