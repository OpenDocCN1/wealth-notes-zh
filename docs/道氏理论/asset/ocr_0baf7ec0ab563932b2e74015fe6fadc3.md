# 三大定律的建立

⑷向下的基本波，也就是熊市，通常有三個向下的波動階段：當有遠見的投資者賣出時，第一個下跌波動階段就發生了，這是基於他們富有經驗的判斷，認為那些高估和急速發展企業的獲利是難以持續的；第二階段下跌表現的是恐慌，由於此刻散戶不惜以任何價格進行可怕的拋售，使得最近剛剛買進的股票快要一文不值了；最後的下跌波動是由於揮淚斷頭和急需現金導致的。

⑸兩個指數必須相互驗證。對於一個牛市，信號為兩個指數必須漲到各自以前的次級波高點之上。對於一個熊市，信號為道瓊工業平均指數和道瓊運輸平均指數必須下跌至各自以前的次級波低點以下。只有一個平均指數波動至新高或新低並沒有意義。同樣，一個平均指數在其他信號以前給出改變趨勢的信號情況也並不罕見。道瓊工業平均指數與鐵路指數的相互確認並不需要發生於同一交易日。

⑹道氏理論並不保證任何時候確保兩個平均指數確認的結果是正確的。

⑺只考慮平均指數一天結束的收盤價，而忽略日間交易價格的波動。為了消滅錯誤的信號，道氏理論家漢密爾頓建議排除少於3%的移動。這並不是一個必須遵守的規則，但是這個意見值得在這裡提一下。今天的市場波動性越來越大，有必要平整天日波動，排除錯誤信號。

⑻基本波將一直持續，直到道氏理論的兩個平均指數出現反轉信號的時候。
