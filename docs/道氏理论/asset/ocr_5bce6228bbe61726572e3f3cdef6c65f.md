# 二、支撐線、壓力線與三類投資者的關係

在前面，我們只討論了問題的一個面相，即在支撐線或壓力線區域投資者的動機，但是就同一個價格而言，為什麼會同時出現多頭和空頭呢？其實，壓力部位和支撐部位是由於不同類型的投資者對市場認識上的矛盾，進而採取不同的投資行為所產生的結果。

根據分析的目的不同，對於投資者的分類也不同。我們既可以像前面那樣將投資者分為多頭、空頭和觀望者，也可以將其分為投資者、投機者和交易者。主要是由於他們彼此遵循的投資觀念不同，所以他們的持倉時間是大相徑庭的。短的只有幾天、幾個小時，甚至幾分鐘；而長的有幾個月，甚至幾年，這就導致他們在同一價位有的人買進，有的人賣出，進而形成在一個價位的成交價格。

在牛市中，投資者中的多頭是長期買進者，一方面他們對於已經買進的股票打算長期持有。另一方面，在市場提供合適的機會時候打算再度買進，而在投資者中的多頭對於已經買進的股票只打算短期持有，只要所持股票的利潤達到目標或者只要有獲利就立即平倉。投機者是進行階段性操作，他們對股票是進行中期持倉階段性的操作，因此打算平倉的時間和空間要比投資者大，而比投資者要小。這樣就構成了不同程度的調整。如圖6-2-3所示。
