例 2。假设花粉 B 每月工资 30000 元，每月社保公积金假设缴纳 4500 元，专项附加扣除中只有房贷每月可扣除 1000 元，年终奖为 60000 元，没有其他收入，他每月缴纳的个税如下：

一月份： (30000-5000-4500-1000) x 3% = 585 元; 二月份： (30000 x 2-5000 x 2-4500 x 2-1000 x 2) x 10% - 2520-585 = 795 元; 三月： (30000 x 3-5000 x 3-4500 x 3-1000 x 3) x 10%-2520-585-795 = 1950 元;

年终奖如果不纳入综合所得，那么 十二月份工资部分：(30000 x 12-5000 x 12-4500 x 12-1000 x 12) x 20% - 16920 = 25980 = 3900 元 年终奖部分：60000 / 12 = 5000 元，适用 3% 税率，那么年终奖部分的个税为 60000 * 3% = 1800 元

年终奖如果纳入综合所得，那么 (30000 x 14-5000 x 12-1700 x 12-1000 x 12) * 25% - 31920-25980 = 24000 元 所以：这种情况选择年终奖不纳入综合所得，更划算。
