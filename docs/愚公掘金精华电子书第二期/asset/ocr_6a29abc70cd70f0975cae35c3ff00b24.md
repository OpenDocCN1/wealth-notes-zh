# Costco 疯狂背后，
隐藏了什么真相？

大家都知道，在美国，线下零售业营销的套路极为成熟。

Costco 的本质，就是一个线下零售渠道，无论其如何吹捧，其商业目的只有一个：最大程度地让 客户消费。

+   * 用爱马仕，飞天茅台这样的超级商品吸引消费者的爆品营销；
* 用“超大包装肯定超值”的大包装心里暗示策略；
这背后的一切，是一个巨大的黑洞。
