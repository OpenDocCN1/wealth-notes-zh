# 第3章

# 錢都跑哪裡去了？

恭喜你！你又往前踏一步，已經清楚金錢的進出及往來，今天、上週、上個月，非常值得紀念的壯舉，你的財務智慧又進步了。但就整個練習來說，這才剛開始而已！你學到的知識，腦裡鮮活的概念，只是個起步。

步驟一及步驟二，你只需要聽專家（作者及其他成功財務自主的專家）的意見，一五一十地練習及記錄，以便打破以前的金錢觀。上個階段，你要做的只是把一些具體的收入、支出、銀行往來資料及如何消費物品，好好記下來。

但到了步驟三，你要做的事情可能更多了，你必須要評估你取得的資訊。
