# 豐足──深層的悸動

活在富裕的環境裡，一直被認為是美國夢的目標，但其实我們總是在盲目追求這個目標。當我們質疑美國夢時，才開始自我覺醒。試問落日沒夜地忙碌，在使用生命活力的同時，充實滿足感覺真的有等比例提升嗎？你了解什麼時候才能達到真正的「豐足」？

現在，我們必須開始學習區分稍縱即逝的快感與真正的充實滿足。還記得第一章中的滿足曲線，「圖中「豐足」就位於頂點的位置，此時過多的欲答已經消失，因為它們完全被滿足了！多一點太多、少一點太少。真正充溢豐足感的一餐是所有香氣、味道及口感都完全融為一體，你的食欲完全被滿足，沒有一絲吃太撐的不安。

同樣地，一部能真正帶來滿足感的車子，能符合你所有的交通所需，美觀又實用。你能一直開它跑好幾千英里，荷包不會太失血，維修也非常簡單方便（除非你人生中的最大夢想，就是擁有一台有飛翼、吃油像喝水一樣的一九五七年代的敞篷車，那麼你就值得為它努力工作）。

你的內心量尺，必須能抗拒表面上的誘惑，不要忙讓人留下深刻印象或排遣無聊，當成換車的理由。否則你就會花三年多的人生，為了這部車夜以繼日地盲目工作。你可以做一個測試，看看自己到底是使用內在量尺還是外在量尺。買個東西或某項體驗是否讓你滿意、滿足、平靜。如果你買得剛剛好，你就會停止追逐欲望。
