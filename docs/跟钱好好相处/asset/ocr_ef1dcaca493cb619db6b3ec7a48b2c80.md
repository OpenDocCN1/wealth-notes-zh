# 固定資產

在計算時，最好從最顯眼的項目著手：你的主要資產，例如：房子、車子，盡量以現值計算。詢問住家附近的房仲，或是上網調查周邊房價，評估出房子現在值多少錢，到可靠的中古車或者是網站上，找一下與你的汽車同年同款的手車，現在的價格大約多少。
