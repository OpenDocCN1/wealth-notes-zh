讓他像唐娜一樣的熱情。她開始研究另類執業的可能，最後得出結論，就算身在傳統的婚姻框架中，儘管與丈夫不同調，女人也必須活出自己的生命。

隨著自己體會日深，唐娜重新評估她的診所。她的員工不想要跟主流醫療院所一樣長時的生活，但不願意少賺一些錢，因為傳統醫院之所以收高額的費用，是要支付醫生的薪資。唐娜認為需要改弦更張，但這樣的產業生態，不斷將她拉回到舊的工作方式。

「要嘛我必須採取不同的方法，要嘛乾脆都不要做這行！」對於唐娜來說，財務自主的宗旨，就是從舊的思考中重生。金錢、工作、生命的意義和目的，都會跟著這個大方向調整。「如果新型醫療做法的代價，是少賺一點錢，那就這樣吧！」

唐娜並不孤單。「新美國夢中心」（Center for a New American Dream）曾進行一項全國性調查發現，近一半的美國人已經做出了改變，雖然賺的錢比較少。調查顯示他們很滿意這樣的改變，雖然收入減少，但壓力也相對減輕，更能讓生活保持平衡，休閒時間也更多。

# 2. 減少工作量，可以活出內心真正想要的

我們大多數人是因著外在大家庭境，決定自己的生活方式。就像中國餐廳的料理一樣，每個人都制式地在大分類中選擇自己東西。從「求職」的廣告分類中選擇「消防員」；從條件中選擇「金髮和藍眼睛」；從要生幾個小孩的問題中選擇「兩個」；在個人風格中選擇當「隨便」的人；在諸多汽車品牌中選擇「豐田」；從政治光谱中選擇藍派；從購屋條件中選擇「公寓」。
