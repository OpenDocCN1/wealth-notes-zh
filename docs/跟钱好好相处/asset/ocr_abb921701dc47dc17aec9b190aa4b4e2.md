# 談一談錢。關於錢的幾個問題

傾聽別人的故事，可以得到啟發及靈感。解放自我不代表必須孤獨生活，藉由別人的幫助，可以讓妳更快達成財務獨立的四個目標：智慧、健全、獨立及互助互賴。借用本章結尾「談一談錢」中提出的問題，跟你的另一半或是社團成員對話，每日反省自問。記得如果在反省時，都能不忘在最後加上「為什麼？」，這樣會讓妳有更深層的思考；如果都能不忘在最後多問一句：「社會如何看待我的答案？」則會讓思考層面更為廣泛。不論如何，這些問題，都沒有標準答案。

+   對於清償債務，你有沒有一些獨特、瘋狂的想法？
你希望留什麼給下一代？
如果你現在不用為錢工作，會如何利用時間？
若能一年不用工作，你會怎麼過？
除了金錢以外，你能依靠哪些技能或是社團體協助你過生活？
