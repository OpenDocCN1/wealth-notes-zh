# 琳達及麥可的故事

在聽到某個廣播節目後，琳達及麥可這對夫婦，在一九九二年七月，開始投入財務獨立計畫，那時他們大概有五萬兩千美元的債務（車貸及房貸）。因為持續記錄收支圖，也正確執行每一個步驟，很快地他們隔年七月就已經還清債務。但故事尚未結束，如果再往前推到一九八六年，你會發現，他們有一筆七萬五千美元的負債。那是因為他們追逐一個「一定能賺一百萬」股友社的建議，把錢投入股票及原料物的投資中，最後以虧損十二萬五千美元出場。麥可非常喜歡《跟錢好好相處》這本書，因為透過這本書，他與金錢的關係有更大的覺醒，也承諾要改變自己，他發誓再也不經歷股友社失敗時，那種痛不欲生的慌張。他按部就班、一點一點進行財務獨立計畫，終於達成了財務獨立的目标。琳達現在把大部分的時間投入她最愛的床罩製作，麥可則重拾吉他，有時還在附近的俱樂部中表演，賺一點零用錢。
他們現在也帶領一個財務獨立小組，協助那些想要安穩退休的人，往財務獨立的目標前進。

# 步驟五的重點摘要

每月在收支圖上登錄你的收入及支出。常常檢視，同時把這資訊分享給別人。
