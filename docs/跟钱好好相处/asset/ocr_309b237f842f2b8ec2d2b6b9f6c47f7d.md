# 別羞愧、勿責怪

這個步驟可能會讓你感覺有點自我批判，甚至到羞愧的地步，不過如果照著這樣做，負面情緒就會少些，經過這個練習，會使人完全改變想法，並開始人生全新的一頁。在過程中，我們需要建立正確的態度，在梵文裡稱之為「attitude」（咒語或座右銘），保持這樣的態度，可以讓我們的思緒更集中。這個態度就像是船隻上的方向舵，帶我們越過危險或艱難的狀況，航向更清朗更開闊的視野。這個座右銘就是：「不要怕丟臉，也不要責怪自己或任何人。」在改變不好的行為的選擇上，指責（condemn）與辨別（discriminate）之間有差異。與指責相關的是羞恥和責備、善與惡；而辨別則是從錯誤中挑出真相。責備和羞恥會減慢你在財務自由的進步；指責會讓你停滞不前、士氣低落，也會分心。辨別是覺察可能出現的陷阱，藉此趨吉避凶。
