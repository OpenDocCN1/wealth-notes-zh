# 談一談錢 關於錢的幾個問題

你跟金錢的關係，其實影響了你過去與父母、環境、文化的互動，包括信仰、認知及過去處事的種種經驗。重新檢視過後，你可能會感到驚訝、興奮，甚至有點不安。「談一談錢：關於錢的幾個問題」這個活動，可以讓自己去看到過去是如何與別人互動、檢視過去，也讓你清楚之前盲目的消費是如何牽引你的生活。抱著「不羞愧、不責怪」的態度，讓你從金錢的布幕後，看到真正的自己，也同時釐清從過去到現在的人生歷程。

借用本章結尾「談一談錢」中提出的問題，跟你的另一半或是社團成員對話，每日反省自問。記得如果在反省時，都能不忘在最後加上「為什麼？」，這樣會讓你有更深層的思考；如果都能不忘在最後多問一句：「社會如何看待我的答案？」，則會讓思考層面更為廣泛。無論如何，這些問題，都沒有標準答案。

+   1. 是誰啟蒙你有關於金錢的概念？當時學到了什麼？
2. 在你長大的過程中，曾經得到哪些與金錢有關的概念？是誰告訴你的？父母、老師、廣告、或其他？
3. 分享一下你小時候對金錢的概念是怎麼來的？這些概念如何影響你現在的作為？
4. 在處理金錢方面，說說你曾經犯過什麼樣的錯誤？若再做一次，會怎樣處理？
5. 對你而言，「豐足」的意義是什麼？
6. 從你的衣櫃或儲藏室中去掉什麼東西，會讓你的生活過得更好？你為何現在還保留這些東西？
