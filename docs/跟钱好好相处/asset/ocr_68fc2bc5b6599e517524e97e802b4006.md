# 9.用不同方式滿足你的需要

能滿足需求的方法，絕對不只一個，世間上有其他千百種的替代方案。傳統的經濟理論認<br>為，更多、更好、更不同種類的物品，才能滿足我們的需求，但這樣只會讓我們刷卡機會越來<br>多。誰說簡約生活帶來的樂趣，會因為花錢花得比較省而變少？例如，怎麼做才能最有效提升你的<br>精神：抗憂鬱藥？跑步？心理治療？看看風景？去看一場好笑的電影？幫助更需要幫助的人？還是<br>靠逛街購物？
