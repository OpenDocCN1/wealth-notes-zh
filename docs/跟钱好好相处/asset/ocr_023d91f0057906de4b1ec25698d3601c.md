# 讓我們朝目標前進

現在，花幾分鐘的時間把你的人生目標寫下來。先不要管你目前的狀況，也許對於別人來說，這目標沒什麼了不起。或者現在目標還不明確，但只要盡量把它寫下來，用這個宣言來衡量你的行為，如果之後你的目標改了也沒關係。現在就放心地把這個目標寫下來，當作行為的準則，因為目標是你自己設定的，所以也要由你自己來打分數，看看是不是都有依照設定的方向進行。一般世俗的標準，常常用物質水準、事業成功或是社會認同來衡量人生目標，但我們這邊借用問題一一使用生命活力時，是跟你自己的價值及人生目的一致嗎？一來衡量你的人生目標，每月，逐項一一檢視你的收支表。如此會更清楚自己的價值，與寫下來的人生目標不斷做調整，你人生的真正的就會浮現。

光芒。從身旁的任務做起，每萬能提醒我們，在這個相互連接的世界中，每一個角落的奉獻都能讓整個世界變得更好。偉大的志業，都是本著熱情及大愛，從一連串的小事情開始做起：提供晚餐給生病的鄰居、教小朋友讀書、寫信給報社編輯、為無家可歸的流浪漢發聲。從做這些小事情始，你會發現生命中充滿了值得奉獻及投入的意義。熱情、苦難及手邊的小事，就是在物質生活之外，讓我們找到人生目標的敲門磚。
