# 。食物

在建立帳目時，你必須坦誠，也務必正確紀錄，但不能雞蛋裡挑骨頭。除非你跟一般人非常不同，否則應該會有一個叫作「食物」的分類。

當你記錄食物花費時，有好幾種不同的分類方式可以運用，也容易記錄。你可能會在家，與家人一起吃飯。你也可能請朋友或在家吃飯，因此你的帳本中，就會有兩個不同的子分類：「自己在家吃飯」、「請客人在家吃飯」。但千萬別太龜毛，不要把請客餐桌上，客人吃了什麼，又花了多少錢，全部記錄在你的小本子中。

但必須估計你備菜的花費，有多少是因為請客產生的。例如，通常只有你跟另一半在家吃飯，但有一次請了四個人來，這樣你就可以概算，晚餐三分之二的支出，是因為請客產生的。總支出的記錄單位，必須細到一分（Cents），但多少是因為請客衍生的費用，得用估算的。在食物這個大項，當然少不了「外食用餐」這個項目，從工作時外帶午餐到外出晚餐，都要記錄。

如果外食不是偶一為之，或已經變成一種例常性且昂貴的習慣，你必須在記錄時把情境寫上去。例如，外食是因為「太累了不想煮飯」，或是「為了某個特殊原因」。如果你每天忙於工作，從出門到返家可能長達十二小時，為了睡足八小時，你恐怕沒有機會開伙，這時就要把細項及原因寫清楚。

如果你沒有辦法拒絕零食的誘惑，也要記下來，或者你是個咖啡控，務必把每個月的咖啡花費也一一記下來。如果你看電視時，喜歡吃洋芋片、爆米花、飲料或糖果，也要記清楚。你也可以更進一步地分類，區別「健康食品」及「垃圾食物」，以便知道自己對食物的偏好及習慣為何，或是對有機食物有多擁護。如果你確實地記錄，這張表會顯示你所有消費習性及模式。一般傳
