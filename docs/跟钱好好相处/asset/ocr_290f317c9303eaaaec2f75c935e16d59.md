# 公約

「別羞慬、勿責怪」：不論是對自己或他人，盡可能不要價值判斷。這並不意味著每個人必須口是心非，表達意見時必須對不同觀點保持開放態度。

保密度：不要對外透露對話內容。

投入：按時到達，留到最後，分享時要保持專心。

簡單扼要：講實話和不膚淺，發言簡單扼要，讓每個人都有時間發言。

不要有商業行為：別在這推銷東西、長篇大論、好為人師。我們不是來聲別人上課的，是來這邊認識自己、彼此及這個世界。

# 主題

開放式的問題或建議，從每個人都有經驗切入，是開啟對話最好的方法。善用本書每章末尾的問題，嘗試提出自己的問題。很多問題，都有提到「為什麼？」，千萬別害怕提出「為什麼？」，這是一個更深入理解並解決問題的好方法。

丟一些追問式問題，例如：「可以分享更多一點嗎？」或「是什麼讓你這樣想？」，但提出追問時，你的口氣很重要。因為同樣是「為什麼你會這樣想？」的問題，可能有時聽起來很有趣，有時就會令人感覺被指責。由於社會塑造了我們關於金錢的想法、感受和行為，你可以試著問問：「大環境對你的想法產生怎樣的影響？」讓對話的觀照面更寬廣。
