# 外食

為了工作，養成的飲食習慣及其產生的額外費用及時間也要列入，例如：早上及下午的咖啡；中午為了排隊吃飯所花的時間；為了節省時間，外食或叫外賣所產生的花費。假設每週需要花五小時在吃食上面，每週五天的午餐花費，假設是三十美元；犒賞自己的咖啡每週約二十美元。一共在吃食上，每週必須付出五十美元。

五小時／週，五十美元／週

# 舒壓及吐苦水

五小時／週，三十美元／週
