# 停止討好別人

停止這種無意義、無效又浪費時間及金錢的舉動，因為別人也在用盡全力討好你，根本會忽略你也在討好他這件事。一九九九年，美國人托斯丹·范伯倫（Thorstein Veblen）出了《有關階級論》（The Theory of the Leisure Class），雖然沒有造成轟動，但其提出的「炫耀性消費」（conspicuous consumption）概念，卻點出深植在美國文化中的心態。在這本書的前言中，社會評論家劄斯（Suvvir Crago）這樣說：

衣食無缺的人們，不管是現代社會，或是更早以前的時代，都沒有好好利用社會提供的多餘資源。他們沒有利用這些資源去擴展人生、增加生活智慧，或讓生活過得更精彩，或修練自己變得更有幫助。他們往往把金錢、時間、力量及資源，用來塑造形象或討好別人，要讓別人以為自己是有的人，膨脹自我，殊不知這些努力往往沒有效用。

炫耀性消費是跨文化及人類社會的反常行為，你不一定要隨之起舞。社群媒體發達也助長炫耀自我的風氣，跟別人比較的潮流越來越盛。因為朋友可能會常常在社群媒體上張貼自己到異國度假的照片，或是到高檔餐廳的美食照，買了新玩具也不忘上網炫耀一下。但如果你能做到不跟風，也許就可以为自己省下幾萬甚至幾百萬的花費。如果真的忍不住要拿東西跟別人比一比，不妨把你省錢的撇步昭告天下，或是把露營時看到的大自然美景貼在社群媒體上，勝過別人在高檔度假村的炫耀。

> ② 編註：托斯丹·范伯倫，又譯為托斯丹·凡勃倫，生於美國威斯康辛州卡托，挪威裔美國人，經濟學家，被推崇為制度經濟學的創始者。著名作品為《有關階級論》及《企業理論》。

> ② 參見：Thorstein Veblen, The Theory of the Leisure Class (New York: Modern Library, 1934), xiv.
