# 一談一談錢一團體的守則

們陷入消費主義的金錢文化中時，我們真正需要的關係、尊重和保障可能會被扭曲，更會助長貪婪。因此，這種討論形式，與跟理財專員及銀行借貸債務談判非常不同。

我們與金錢的關係，會影響到個人的想法、感受、態度、信仰及生活經驗，

解決財務問題，不是談話會的真正目的，可能只是副產品。我們希望這個聚會，能探索你心

理深處的渴望，透過公開的分享及討論，真正被發掘出來。

試著用這樣的問題開頭：「請大家交換一下彼此的经验：你在最近六個月中，有沒有曾經買

過一件衣服，但其實你根本不不需要它？「每個人都有意義的經驗，我跟你有保證。這是與金錢有關的

問題，但不會太隱私，所以很適合試試水溫。當我第一次在一個工作坊的聚會中問這個問題

很讓我吃驚。每個人都踴躍發言，我都没辦法插話，我大可直接離開現場，讓大家痛快地暢所欲言。

你可以試著用這樣的方法，問問另一半或是室友；也可以把它貼在社群網站上，看看大家的反

應；在跟同事吃飯時提出這個問題；甚至可以召集朋友到家裡或咖啡廳，舉辦一個談話會。

找朋友一起談這個話題，比較容易引起共鳴，至少你會有了一個人願意分享經驗，這話題在你們之間，也許一個星期都停不了。它甚至可以成為結識新朋友和拓展鄰里關係的一種方式。

關於錢這檔事，我們建議您使用以下的方法，更深人的對談。

這些建議是根據「對話咖啡廳」（Conversations Over Coffee）網站中所建議的流程改編而來的，世界上非常多人已經開始用這個方法，開啟彼此的對話，門檻不高，可以讓討論更有意義，甚至討論一些國家大事都行。
