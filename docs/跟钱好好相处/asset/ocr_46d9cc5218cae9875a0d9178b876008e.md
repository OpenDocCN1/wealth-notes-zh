# 工作帶來的病痛

你因為工作而生病的比率有多高？因為壓力太大，身體負擔太重，因為想要有表現，工作太劇，或是與同事及員工起衝突？

至善科學中心（The Greater Good Science Center）這個組織，一直致力於倡導用科學方法提升生命意義。他們的研究發現，幸福感能增加心臟健康、強化免疫系統、對抗壓力、減少疼痛並延長壽命。在我們自己的經驗裡，志工身體出現問題或是怠工的情況，都比一般受雇員工低很多。日子過得簡單、快樂及富足的人，相對健康許多。在這個項目中，什麼樣的疾病會歸因於工作，要花多少時間及金錢治療這些衍生的疾病，難免會有內在感覺及主觀的認定。我們假設，每週我們平均大約要花一小時，或約二十五美元的費用來看醫生、拿藥及處理這些病痛。

# 其他因工作產生的花費

檢查步驟一中的資產負債表，有沒有有些本來不會支出，但因為工作才產生的花費？在一『麗人幫忙』的項目中：請清潔公司打掃家裡、請人整理花園，雇用維工處理家務，或是找保母。如果你沒有工作，這些支出還會存在嗎？不管是單親或雙薪家庭，托兒所是一個不小的開銷，如果你沒有工作，這個開銷其實不會發生。找時間精算你一週的生活，多少花費是跟工作有關？
