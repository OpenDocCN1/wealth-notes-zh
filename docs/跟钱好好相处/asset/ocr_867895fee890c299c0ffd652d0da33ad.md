# 就從這張圖做起？

這張圖其實沒有神奇的魔力，你只要在同個月月初把數字記錄上去，剩下的時間什麼都不必做。但時間一久，若你保持平常心，跟它互動，傾聽它的訊息，繼續記錄下去，你會發現有所改變。

+   財務獨立是一連串的覺醒，你的收入、你的花費、你的存錢模式，種種行為累積起來，就會發生。恆心及決心會逐漸改變你跟金錢的關係，要時時接觸，不能抱持「眼不見，心不煩」的躲避心態，才能改變長久以來養成的花錢習慣。

+   它是一種反饋機制，收支圖能一眼清楚地告訴你，你目前的狀況及邁向目標的進程。你不用每天計算小豬撲滿裡面有多少錢，確定自己是不是存到錢，收支圖上的兩條線，不是往上就是往下。

+   它是一種激勵及提醒，記錄你體會到的滿足經驗，刺激你往更高的方向努力。當你忙碌於平常大小事的時候，抬頭看看這張圖，提醒自己美好的生活就在前方。

+   當反對的聲音充斥時，它也是你向前的動機來源，告訴你這是正確的方向；當誘惑來臨時，一想到你必須在月底，在這張圖上註記收支狀況，會有助於你當機立斷。

+   它把你的財務狀況一一五十表現在曲線上，在圖表前你很難說謊，必須對所有的進度誠實以待。
