# 簡單的夢想因財務自主而實現

艾美與吉姆創立了一本個人理財的雜誌《小氣報》（The Frugal Gazette），希望藉此宣揚簡約生活。他們想要讓一家子的人住在一個郊區的大農莊裡。當他們結婚時，已經在各自的崗位上工作了二十年，吉姆是職業軍人，服役於海軍，安妮是一個圖像設計師，但他們兩人的積蓄總共只有一千五百美元。他們認為，家庭及社區比每日快速辛勤的工作重要，但如果要過他們理想的日子，勢必得犧牲一人的工作。換句話說，只靠班歲月更重要，但如果要過他們理想的日子，勢必得犧牲一人的工作。換句話說，只靠

在少了一份薪水的狀況下，他們開始向節約省錢的父母討教如何省錢過日子的方法，最後還找到屬於自己的節約策略。安妮與吉姆都沒有因此覺得生活被剝奪，還將省錢的創意視為生活的挑戰，也因因為擁有共同的目標，兩人關係越來越好。

結婚七年，兩人生了四個小孩，還分期付款買下一個在緬因州的農莊，把所有的債還是過生活的心得以更發揮她在圖像設計的專長，在一九九〇年發行了《小氣報》，在這八頁還清，還買了新車、家具及新家電。兩年之後，安妮創立了一個論壇，與大家交換節約的刊物中，充滿如何省錢過好日子的技巧、故事及報導。一年後，他們又生了雙胞胎，
