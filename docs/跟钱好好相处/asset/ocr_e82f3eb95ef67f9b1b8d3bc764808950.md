+   2. 在記錄你的每月收支表時，同時自問問題二：「使用生命活力時，有沒有跟你自己的價值及人生目的一致？」如果有，請在欄目上加註，根據情況不同，註記＋（或一個向上的箭頭）、－（或一個向下的箭頭）或○。

+   3. 在記錄你的每月收支表時，同時自問問題三：如果你不為錢工作，你的消費型態會做怎樣的改變？

+   4. 再次檢視一下你的收支項目及註記的記號。

# 談一談錢。關於錢的幾個問題

你的夢想、價值、回憶及人生故事，都是開啟與他人對話的話題。如果從別人那裡，聽到令你有一「有為者亦若是」的衝動的夢想或目標，別客氣，把它偷過來自己用！我們可以大家一起打造真正美好的生活藍圖，用簡介裡談到的建議，透過這個計畫，讓金錢說話。借用本結尾「談一談錢」中提出的問題，跟你的另一半或是社團成員對話，每日反省自問。記得如果在反省時，都能不忘在最後加上一句「為什麼？」，這樣會讓你有更深層的思考；如果都不記不問一句：「社會如何看待我的答案？」，則會讓思慮反面更為廣泛。不論如何，這些問題，都沒有標準答案。
