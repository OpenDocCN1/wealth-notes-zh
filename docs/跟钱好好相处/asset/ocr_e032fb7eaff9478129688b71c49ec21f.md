# 這本書給誰看的？

只要有收入，也有支出，那就是這本書的讀者，不是讓每個人都變有錢，而是透過此書了解，自己生命中定義的「足夠」到是什麼樣的狀態。透過這本書，可以幫助你改善與金錢的關係，這是每個人必做的人生功課，「眼錢好好相處」希望能幫大家達到「足夠」的境界。貪求越多越好是一個永無止境的黑洞，不論你現在手上有多少錢，心中那個「越多越好」的聲音，把你帶向越買越多的死胡同。貪念是人心最多的欲望之一，非常頑強地存在著，不受公平、平衡及愛的制約，貪念會讓我們快樂的能力消失。要定義「足夠」，必須先問自己以下的關鍵問題：

+   * 什麼讓你感到快樂？
* 生命中最重要的是什麼？
* 哪些價值，你絕對不願妥協？
* 假如你現在有三千萬，你會用空下來的時間做什麼？
* 如果在你的生命中拿掉一個東西，會讓你更快樂一些，那個東西會是什麼？（只能選東西，不能選人。）
* 會有足夠的錢退休嗎？
* 如果有人可以幫你還清現在所有的債務，你還會再次去借錢嗎？你會怎麼做？

諾貝爾獎得主、同時也是暢銷書作家卡尼曼（Daniel Kahneman），曾對金錢與幸福做了一項
