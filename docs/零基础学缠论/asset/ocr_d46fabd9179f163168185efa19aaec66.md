# 3. 什么是第一类买卖点与第三类买卖点的转化？

第三类买卖点形成的原因：第三类卖点的位置加入了新的做空力量，第三类买点的位置加入了新的做多力量，从而减缓了中枢的吸引力。

例如，前走势类型（向下）发生背驰之后（出现第一类买点），出现了反弹，但新生做多力量弱小，无法推动价格回到前中枢，也存在新的做空力量的加入，抵消了原中枢的吸引力，它又延续原走势类型的方向运动，即此处会出现第三类卖点，从而出现第一类买点转第三类卖点的情况。
