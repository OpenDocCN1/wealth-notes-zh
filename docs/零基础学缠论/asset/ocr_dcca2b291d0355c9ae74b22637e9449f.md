很多人觉得两个中枢后一定会有新高，因为缠师说过走势必完美。大多数 人把完美理解成走势一定要按公式 a+A+b+B+c 的结构来进行才是完美的， 但其实走势必完美是指走势必然终结。如果按这个结构模型来说，走势一定 要出现 c 段才是完美的，那你有没有想过，这个 c 段是可以反向方式出现的？

缠论给了我们一套很好的分析方法，一个全新的视角，可以让我们从大 分析到小，从小分析到大，大的变化是用小的来判断的，走势在脑海中永远 是在生长的，不测而测才是核心。能不能产生我们所希望的新高，在没走出 来之前谁也不知道，但在生长过程中，通过多级别联立下的观察判断，当下 是可以知道哪里是次级别完成的，以及是否能引发大级别的结束。

例如，6-7 这笔，是通过观察其内部结构来判断其完成的，操作中用次 级别就可以解决。本级别中枢是由次级别构成的，次级别里还可以用区间套 观察其内部结构。
