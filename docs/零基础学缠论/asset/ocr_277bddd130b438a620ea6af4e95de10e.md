# # 六、关于走势必完美

**1. 如何理解走势必完美是交易的核心?**

当下的走势都是某级别的未完成走势，而这个走势必将完成。

当下的走势还没有走完，但这个走势是必将完成的，这就成了我们操作的依据，也就是交易它的未完成部分，这才是交易的核心：走势必完美。所以在走势必完美的基础上，我们可以构建交易体系，无论是第一、二类买卖点，还是第三类买卖点，都是这个核心逻辑在起作用。

我们需要做的是，观察它是哪一个级别的未完成走势。

# **案例 中集集团**

如图 4-91 所示，1-4 下上下结构完成，就还会对应一个上，甚至可以创新高，这样从 0 以来的盘整上涨走势才算走完标准模型（新高不是必然出现，需要通过 4-9 的次级别走势生长来跟隨），所以我们交易的就是 4-9 这个未完成段。其实当走到 5 的时候，就能判断 0-4 这个级别的走势是未完成结构，4-9 的上涨段是可期待的。
