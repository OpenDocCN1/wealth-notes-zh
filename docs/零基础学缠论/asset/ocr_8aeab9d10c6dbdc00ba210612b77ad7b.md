# 一、背驰的定义

背驰是力量衰竭的表现，体现了动力学在缠论中的运用。

背驰是力量衰竭的表现，而衰竭与否需要比较而得，所以掌握背驰，需要解决谁和谁比的问题。

# 二、中枢的引力

+     - 中枢对进入段和离开段具有相同的引力；

+     - 构筑中枢的组件越多，其能量越大；

+     - 能量越大的中枢引力越大，脱离中枢需要的能量就越大。

中枢在构筑过程中会产生势能，即中枢随着重叠区域面积的增加，会产生一种类似于地球引力的引力场（质量）。可以把它理解成一个星体的构建，能量会逐渐转换成质量，而这种质量对它的进入段和离开段就形成了一种吸引力。构筑中枢的组件越多，这种吸引力的能量也就越大。能量越大的中枢，脱离它的时候需要的能量也就越大，我们通过比较中枢的离开段和进入段就可以知道，离开段是否可以真正离开（如图 3~70 所示）。
