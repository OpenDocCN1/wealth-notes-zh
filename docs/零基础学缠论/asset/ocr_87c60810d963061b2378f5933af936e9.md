+   1. 背驰段不意味着必然背驰。

c 段只是可能背驰。这涉及我们后面的内容，比如买卖点之间的转换。

+   2. c 段无论背驰与否，仍可以生成中枢 C 和 d 段。

当 c 段的运行速度很快，与 b 段没有发生背驰时，依然可以生成中枢 C，甚至中枢 D；或者 c 段发生了背驰，但有新的力量使其继续保持原方向上的运动，从而生成了中枢 C 甚至中枢 D，这有点类似火箭的第二、第三助推器的作用。

+   3. 判断离开段的完成，需要运用区间套。

本节讲的是平面的逻辑，是大致可用的快速解决问题的办法，但想要准确地判断背驰，就需要用到多级别联立。而要做到多级别联立就需要理解和掌握区间套，真正意义上的背驰是区间套下的结构完成，单一级别下的动能比较只能是辅助手段，这是缠论进入运用层面的重要环节。
