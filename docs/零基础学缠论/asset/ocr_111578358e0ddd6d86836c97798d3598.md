# ## 二、缠论

**以市场的走势为根本，不作倾向性预判。**

缠论以市场的走势为根本，无需作太多倾向性的预判，它并没有胜率的概念，而是关注市场如何生长、当下到哪里了。

**止损用“化”，从容自如。**

缠论的止损用“化”，心中没有喜欢或者厌恶这样的情绪，只是买点买、卖点卖，从容自如地去交易。

**完全接受市场的变化无常，应对即可。**

在缠论中经常有第一类买点转化为第三类卖点的情况，当你明白第一类买点可以转化为第三类卖点的时候，才可以说你在运用缠论。它是要让我们完全接受市场的变化是客观存在的，我们只要通过缠论，知道市场在往哪里变以及怎么演变，然后作相应变应即可，即不测而测。这里不是我们的问题，也不是方法的问题，只是市场在发生变化，我们需要应变，仅此而已。我们的心态会很平和，做错几次也没有关系，因为错已经不是我们的错，只是市场要如此生长而已。
