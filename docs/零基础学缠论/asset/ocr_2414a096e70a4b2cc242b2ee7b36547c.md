用公式表达：新 ZG =max（ZG1，ZG2），新 ZD =min（ZD1，ZD2）。

# 2. 升级方式不同。

（1）中樞延伸：延伸九段则升级。

中樞延伸是通过延伸段的 3 的幂次方来完成升级的，当然升级时也可以理解成是次级别的中樞扩展，中樻区间也可以发生变化（通常不作处理）（如图 3-129 所示）。

每三段进行一个次级别合并（每三段都可以理解成是一个下上下走势运动的一个集合）形成中樼扩展，只是没有进入段和离开段。

（2）中樼扩展：形成三个次级别重叠走势升级。

中樼扩展是通过三个次级别重叠走势来完成升级的（如图 3-130 所示）。
