级别是为了精准定义某一段的属性，有了级别，才能够把走势完全划分开。没有级别的概念，所有的不测而测都是混乱的。

# 2. 为什么有的本级别的笔能走很远，而本级别线段未必走多远？

以弦理论里面的粒子举例，小粒子和大粒子之间的质量可以相差46 000倍。相对于走势，一个1分钟笔的运动（例如暴风集团刚上市的走势）可以涨几十倍，而大部分个股走几年都涨不了那么多，用这个逻辑去理解就释然了。只是级别越大，它的可判断性、可被利用性就越强，因为可以多级别联立了，而级别越低，即便它的空间很大，但不一定能为我们所用（如图4-43所示）。

# 3. 判断级别的简单方法。

一个快速定义级别的简单办法：从日线到1分钟（从大到小）逐级观察。
