# 2. 以走势类型作为最小分析单位。

为了保证交易的稳定性和有效性，充分利用好区间套，我们以走势类型作为最小分析单位。

如图 3-101 所示，想知道日线的一笔 0-1 是否在 1 的底分型位置真正终结，可以把 0-1 这一笔通过区间套到更低周期图上去观察，分析它的 30 分钟走势结构、5 分钟走势结构，甚至 1 分钟走势结构，这样就能够更加准确地得出这一笔是否终结于这个底分型。以走势类型进行分析，会更可靠，也更精准。

# 3. 笔、线段可利用其次级别以下的走势类型去观察走势构成及其变化。

我们可以利用次级别的走势类型，甚至次次级别，去观察笔和线段的走势结构、背驰以及生长变化。所以笔和线段是作为组件使用，而走势类型是作为最低的分析单位使用，形成这个观察分析习惯，效率就会提升。
