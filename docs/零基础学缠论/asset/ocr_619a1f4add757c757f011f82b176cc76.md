# 10. 形成两个中枢后，一定会有 c 段吗？

c 段未出现前一切皆有可能，这才是一定的。

如图 4-38 所示，之前有位缠友问我（时间背景：2015 年 6 月 18 日）：“如果大盘下跌回到 4572 点，就构成标准的 30 分钟中枢了，应该还要有 c 段 8-9，而且 c 段必然创 7 的新高，这样分析对不对？”我说：“没有一定的事情，一定的事情是一切皆有可能！”

![](bbox=[0.15, 0.38, 0.88, 0.68])

如图 4-39 所示，0-7 这个 30 分钟走势是可以结束的，向上走的 8-9 可以只是对 5-8 这个中枢的延伸，如果给一个次高 10，下去也可以，不一定会创新高，甚至 7 直接下到 5-8 这个中枢下方而后反抽形成第二、三类卖点的重合都是可以的。
