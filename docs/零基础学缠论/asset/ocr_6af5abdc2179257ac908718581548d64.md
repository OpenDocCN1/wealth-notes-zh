# 四、关于背驰

1. 趋势背驰、盘整背驰、盘背有什么不同?

趋势背驰、盘整背驰、盘背是发生在不同结构上的背驰现象，只是为了交流方便把发生在不同结构上的背驰进行了分类：

趋势背驰：发生在趋势走势类型上的背驰，c 段相比 b 段（c 段级别≥b 段级别）的运动空间小、力量衰竭，我们称之为趋势背驰（如图 4–52 所示）。
