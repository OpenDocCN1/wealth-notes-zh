## 11. 为什么说走势必完美是缠论最核心的思想？

使用缠论时最核心的指导原则是走势必完美。任何级别、任何走势终将终结，且任何级别、任何走势都被唯一表达。

缠师在原文中说过几次走势必完美，前面说的是“任何级别的任何走势都将终结，进入新的走势中”。也就是说无论市场出现了什么情况以及未来可能出现的所有情况，都能被缠论解释和定义，缠论对市场做到了真正的完整定义和解析。在市场运动的分析理论里，唯有缠论是无漏的。再看它后面那部分“且任何级别、任何走势都被唯一定义”，用了个“且”，“且被唯一表达”，这是缠论最核心的地方。

学习缠论过不了级别这一关，那缠论就白学了。级别是可量化的，任何级别的任何走势都能被唯一定义。无论在哪个级别，30 分钟也好，1 分钟也好，新股也好，这根 K 线从属于哪个走势中的哪一段的哪一个位置，它是被唯一定义的，是被数字化了的。有了这个精准定义之后，才能说它其大无外、其小无内，我们才能真正应用它。缠论最神奇的地方是：它把看似非常繁杂的走势，变成了一段一段可被唯一定义的走势，唯一定义的段落。先拆分，然后再组成，即便是多义性的处理，依然可以知道它是什么。只有这样，才能知道此刻身在何处，才能知道这个地方用什么样的策略是最优的，这是缠论最基础、最核心之处。

什么时候对走势分解非常自如了，知道从哪到哪是什么，对这样的定义、这样的组合能变成什么都很清楚了，才能说掌握了缠论，才能运用好缠论。

### 七、关于小转大

- 1. 一个小转大的运用分析。

### 2. 小转大形成原因是什么？

小转大在行情加速赶顶或赶底的时候比较多见。因为一旦趋势（此处是传统理论的趋势概念）形成，大家就会按趋势去想问题，小转大是市场多空双方激烈交锋的结果，是多头空头最后的宣泄造成的，一般伴随着疯狂的贪婪或极度的恐惧情绪，用均线看是非常强烈的走势（均线向下或向上快速发散，如图 4-116、图 4-117 所示）。

### 3. 小转大的实际意义是什么？

提出小转大的逻辑是为了防止大家出现一根筋思维。

小转大在提示我们，在最后的疯狂期，谨防小转大！我们的结构分析能力再强，也有无法分析的结构出现。

![](img/77d1cc7c2112cc267ea790a8866c5111_288_0.png)

在实际操作中，要防止被快速上涨或者下跌所诱惑或者恐惧。缠论就是在破当下，它用一种很清晰的表达告诉我们，当下的思考方向、思考重点应该是什么，无背驰的小转大就是“亢龙有悔”的数学化表达。

### 4. 小转大发生时的不同应对。

小转大在走势上看并没有什么征兆，即常规用区间套的背驰判断是无法得出结果的，在当下是不能判断的，但大级别的小转大出现的可能性，通过走势所处段及市场情绪还是可以预见的。很多朋友困惑于小转大的处理，其实小转大并不可怕，它是缠论体系的重要组成部分，可使任何走势在发生时都能被解释，被处理，也就是我们都可以有应对。

- （1）小转大发生在 b 段。

b 段中经常出现小转大，但是 b 段我们很少当小转大来处理，可以用中枢扩展或中枢延伸来处理，在用多义性分析时需要考虑小转大的情况。

如图 4-120 所示，2~3 和 0~1 没有发生背驰，3~4 就直接拉回中枢了，可以把它看成是中枢构建中。3~4 拉回到中枢，有承接力量，下跌会有些阻碍，一般会有一个 4~5 的反弹，起码能给一个逃命的机会，所以我们一般没有把它当小转大处理，因为它还有机会处理。

![](img/77d1cc7c2112cc267ea790a8866c5111_289_0.png)

- （2）小转大发生在 c 段。

小转大发生在 c 段时产生的危害较大，所以 c 段要重点考虑。因为 c 段一旦结束，它的调整可能是 0~1 的反趋势走势类型，这种情况是需要及时处理的。

### 6. 缠论不是可以把握到最低点吗，可是为什么一遇到小转大的操作总是把握不好？

交易，要用仓位进行控制。如果在盘整背驰的时候买入，之后发现是趋势走势类型下跌，那就等下跌完成了再买入，这个过程是根据仓位来进行控制的。

去抓住每一个低点，本身就说明对缠论的认识是有问题的。这种想法还是在用传统的思维在理解缠论，并没有理解缠论到底是干什么用的。如果你认为缠论能给你 90% 以上的成功率，那我劝你还是不要学习缠论了，因为它根本解决不了你的问题。

我们要思考，缠论到底是用来做什么的，它不是预测，而是不测而测。缠论给我们一个思维逻辑，告诉我们如何应对。小转大也是完全分类里的一种，在完全分类时，应该要分析到小转大会出现在什么地方、以及用什么样的逻辑、什么样的策略来应对它。

### 7. 小转大频繁出现，缠论是不是失效了？

小转大就是一种正常走势终结的描述，它的存在才使缠论对走势如何终结的分类具有了完备性。国际市场上很多交易品种的小转大，比国内市场的要丰富许多，而且一直是客观存在的。

缠论给我们的是逻辑，它不是在预测市场，而是完全分类市场，然后找到所有分类的应对，这才是缠论。

有个缠友问我：有很多人担忧，如果学习缠论的人越来越多，是否会影响缠论的发挥？比如说，现在看到小转大越来越多，经常一笔暴跌没有任何背驰迹象，直接用小转大上来，这是不是因为学缠的人多了而导致的？

我是这样回答他的：从你的问题来看，是你的底层逻辑出了问题，你要的是它的准，你担心使用缠论的人多了之后就变得不准了，这是这个问题的根结点。因为你想要它准，你追求稳定率、成功率、确定性，想着它背驰了，那就必须涨，用的人多了，这个背驰就找不到了，这个涨就和你无关了。但是，即便背驰了，你也抓到了，它就一定涨吗？

其实是你再不测而测时没有考虑小转大，或者说你执着着后面你以为必然出现的上涨给你带来的利润，你也在计算，只是你在计算涨 10% 你的账户是多少了，而不是在计算行情如何变化，你应该做哪些应对。所以当小转大发生的时候，你无从适应，只能说你功力差，心性有待提高。大家都跑一千米，一个什么都不想，只是盯着目标、调整身体状态、更稳更快地跑；另一个在想，我得了第一会怎样，得了第二会怎样，你觉得谁更容易出好成绩呢？

缠师有句经典的话“主力可以改变结果，却不能改变结果的结果”，只要结果呈现，即必为缠论所分析，能分析就可应对，这才是缠论的根本，所有人都用缠论和所有人都不用缠论，结果是一样的，那就是当下的交易结果必然还是这个结果，这个结果是你交易产生出来的结果，还是别人交易产生出来的结果，在走势分析上有什么区别呢？用缠论甚至可以分析 100 年前的美股走势，100 年前有缠论吗？

缠论在完全分类中就有小转大的一个分类存在，不测而测的时候我们就应该考虑到，这地方如果出现小转大，会走成什么样子，要在哪个地方应对。而你的完全分类就没有分类到这里。不测而测需要穷尽变化，如果连小转大都没有计算在内，就不算穷尽。

单边激烈上涨的时候，小转大的情况会经常出现，走势平缓的时候，处于一种弱的平衡运动中也会发生。而在一个大级别的下跌过程中，用区间套不断地由大级别观察到小级别，背了又背的情况会比较多一些。所以每一个阶段，都有它的属性和特征，这也是完全分类。

所有成相的东西，例如，出现了 A，一定推导出 B，类似于这样的推导过程对应的方法，它都是用相来解释相。但是缠论作为一种处理方法和思考方法，它是方法论，它以体系的形式存在，就像太极一样，它会形成一种动态关系。只要是动态系统，就不会失效。缠论描述的是市场本身的力量消长，它能让我们很清楚地看到这个地方在发生什么，会发生什么，只是如实而清晰地描述市场，至于发生时应该怎么去应对，那是选择，是综合功力的体现。

## 八、关于走势生长

### 1. 研究走势生长的目的是什么？

研究走势生长的关注点：走势是如何通过次级别的完成，不断地由小变大的，重点是生长的规则而非规律。不测而测建立在走势生长的基础上，如果不理解走势的生长，就不能进行不测而测的工作，做不到不测而测、穷尽变化的话，应对就会产生问题，所以走势的生长是动态的观察，是交易的应对基础。

理解走势的生长，掌握在生长过程中的节点表达，就能当下分辨出出现的走势是一个未完成走势还是已完成走势。如果是未完成走势，观察其次级别，观察其如何完成；如果是已完成走势，观察其上一级别，观察其完成的是哪一段，它要向哪里生长。

### 2. 走势生长的核心是什么？

走势生长的核心是走势必完美，我们是在走势必完美的思想指导下去做走势生长的推演的。

### 3. 是什么在推动走势的生长？

走势的生长只是在动态描述走势运动本身，走势生长是需要能量的，它不会随便地向上生长，也不会随便地向下生长，如果单纯地用走势去预判走势，就会出现问题。推动走势生长的能量我将它命名为生长因子，基本面是生长因子，贪嗔痴疑慢也是生长因子。

### 4. 走势是如何生长的，动态跟踪过程再演绎？

第三类买卖点是终结原中枢的一个信号，只有中枢级别确定下来，才能根据中枢大小来划分归属关系，所以动态观察走势生长时需要密切关注第三类买卖点的出现。换句话说，每当出现第三类买卖点（无论什么级别）时，都需要重新审视一下对走势的划分是否合理。
