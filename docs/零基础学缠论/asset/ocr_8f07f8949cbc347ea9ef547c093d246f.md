# 智慧的回向

缠论这套体系就像牛顿发现万有引力一样意义重大，应该被分享，值得去弘扬。无论是1个人、100个人还是1000个人，只要学习缠论能有所收获，我们的所有努力就都值得，哪怕只是在某一点上能让大家产生一些思考，也是极好的。所以，我在2013年立志发愿要免费推广缠论体系，由这份发心而起，我们选择了网络授课的方式，以求让更多人受益于缠论。四年时间，几千场教学直播课程，虽是免费推广，却让我们自身得到了更大的收获，即智慧的回向。

做这件事本身对于我们智慧的开启帮助是巨大的。于我自身而言，在教学过程中，自身精进的速度很快。跟大家分享交易心得、交易体系的同时，大家的问题，会触动我的思考，让我的思考更加深入，不断接近事物的本质，然后再将思考结果去运用、去实证。这种互动式直播教学形成的良性循环效果，力量超乎想象地强大，它随着时间的推移逐渐显化，在每个当下，显化在我自身和周围人的身上。很多人跟着我们一路学习下来，得到了改变，收获了财富，甚至改变了人生的轨迹。
