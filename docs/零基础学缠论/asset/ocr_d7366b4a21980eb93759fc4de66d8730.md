# 构成原理不同

# 一、传统理论

源于西方的统计学原理，研究的是统计学下的大概率事件。

传统理论是找到市场的特征性，即统计学上具备显著性的一些特殊图形，或者叫特殊性的因子，来研究它的胜率高低，也就是说所有研究胜率高低的理论都可以称为传统理论。在运用缠论时，如果仍然是在胜率上作分辨取舍，那么仍然是传统逻辑思想在起作用，掌握的仍然不是真正的缠论。

# 二、缠论

源于中国，是整体观下解决股票交易等问题的体系。

以数学逻辑构建的体系，可以唯一标识。

缠论的原名叫“市场哲学的数学原理”，它是用数学推导模型来构建的一套体系。学会缠论便会发现，任何一根K线，无论在什么位置都可以被唯一标识，这是任何其他体系、逻辑都无法做到的。

传统理论具有或然性。
