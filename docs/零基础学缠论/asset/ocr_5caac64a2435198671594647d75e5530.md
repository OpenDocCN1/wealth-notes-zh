# 二、缠论的结合律

+   1. 必须按顺序结合，不能打乱先后顺序。

数学：$a+b+c=(a+c)+b$（交换律）

缠论：$a+b+c \neq (a+c)+b$

在数学应用（都是加法时）中，可以出现 $(a+c)+b$，但在缠论应用中，各组件是不能这样打乱顺序用的，即在缠论应用中符合结合律，不符合交换律。

+   2. 任何组件不遗漏且不能重复使用。

$a+b+c \neq a+b \neq (a+b)+(b+c)$

当走势拆解、重新组合的时候，已经用过的组件，不能再被重复使用。组件遗漏或重复使用，即违反了结合律。

它的表达式是 $a+b+c \neq (a+b)+(b+c)$，$b$ 的重复使用一定导致结果的变化。

# 三、结合律在缠论中的运用

+   1. 笔的结合律运用。

笔的组成：顶（底）分型 $+n$（$n \geqslant 1$）根 $K$ 线 $+$ 底（顶）分型。

笔的确立：新一笔的生成才能确立前一笔的完成。

如图 3-102 所示，笔由三个组件构成：顶（底）分型 $+n$（$n \geqslant 1$）根 $K$ 线 $+$ 底（顶）分型。这三个组件之间不能重复使用，这也是为什么一笔一定是由五根及五根以上 $K$ 线来构筑的原因。
