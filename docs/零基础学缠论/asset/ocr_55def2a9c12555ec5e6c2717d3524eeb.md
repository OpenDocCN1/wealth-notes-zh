# ## 总结

缠论不仅是一套有法，更是一套交易哲学，但交易哲学依然要从现象开始构建，所以本书中缠论是按照我现在所理解的缠论逻辑从最基础开始来为大家进行讲解。

我认为从技术层面来构建的缠论，是缠师的交易哲学，甚至是他的哲学哲学所写的一个范本。我们学习缠论，说到根上，是在临摹缠师的思维构建，通过笔、线段、走势类型以及走势生长的相关概念，整个临摹一遍，当完全掌握之后，我们掌握的其实是如何构建思维逻辑，以及缠论视角下对市场的解读。

当我们能够通过走势的生长，以及它的拆分和组合逻辑，逐渐地衍生出交易逻辑、交易哲学的时候，才能说我们真正掌握了缠论。市场还是那个市场，但我们的视角变了，对市场的感受和买卖的选择也就完全变了。到那时你可能会由衷地说，缠论真的很伟大；到那时你也会和我一样，为弘扬缠论奉上一份绵薄之力。
