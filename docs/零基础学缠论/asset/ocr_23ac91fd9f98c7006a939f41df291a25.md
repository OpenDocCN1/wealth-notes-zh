# 4. 线段背驰后，如何判断回拉力度以及如何操作？

首先不建议在线段上判断背驰，除非已经到了最小可观察级别。在学习缠论的过程中，一直提倡交易走势的未完成段，而要完成这个基本策略，需要作以下准备：

首先，找到未完成走势；其次，等次级别完成；最后，利用次次级别的生长来完成其次级别反向走势。

所以要充分利用缠论体系完成一个简单的交易，至少需要观察 3 个级别的走势：本级别用来交易，其上一级别用来定交易方向，其下一级别用来生成本级别以及确认本级别何时完成从而离场。

如果用线段来交易，观察的次级别是笔，而笔没有结构，无从判断线段在哪里结束，所以建议先学习通过走势类型来建立交易系统，线段和笔只是组件，信息太少。
