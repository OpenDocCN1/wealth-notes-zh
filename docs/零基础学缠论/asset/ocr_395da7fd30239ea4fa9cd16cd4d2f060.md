# 2. 中枢扩展。

中枢扩展表达的是走势处在一个更大级别的中枢构建中，这时需要多级别联立(多级别联立将在后面的“多级别联立及不测而测”中进行详述)的思维，观察更大级别的走势情况，同时考察第一次次级别反向走势是否脱离原中枢的范围，以及后续次级别走势是否在构建反向的本级别走势。

# 3. 更大级别的反向走势。

更大级别的反向走势，一般其初始段的反向运动动能较强，其反向运动的持续性更好，且要走岀更大级别的反向走势，至少需要三个以上的本级别运动，可供观察的节点多。

走势是生长出来的，并非一开始就能确认一定可以走成哪一种走势，我们需要掌握的是对走势生长的跟踪考察能力，而不是一开始就去猜市场会走哪一种走势。
