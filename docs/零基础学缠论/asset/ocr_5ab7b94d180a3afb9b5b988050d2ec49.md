# 第一章
缘起

人，总是很奇怪的，就算是很聪明的人，或者在其他行业很成功的人，一旦进入资本市场，就像换了个人。虚拟和现实的鸿沟使得干实业的，且不 说期货了，就算到风险小得多的股市，也很少能干好的。

有人说，市场是老人挣新人的钱，而市场中的老人，套个10年8年的一抓一大把。其实，市场从来都是明白人挣糊涂人的钱。在市场经济中，只要 你参与到经济中来，就是经济人了，经济人当然就以挣钱为目的，特别在资 本市场中，没有慈善家，只有赢家和输家。

——节选自《教你炒股票108课》“教你炒股票1：不会赢钱的经济人， 只是废人！”

+   各位之所以有缘打开这本书，无外乎以下几个原因：
一是想学炒股票的方法，在众多方法中选择看看；
二是通过各种途径，得闻“缠论”很不错，很厉害，于是想要学习一下；
三是自己学过一段时间缠论，但觉得学习起来很难，听闻很多朋友在跟 随我们学习的几年间取得了很好的效果，即“慕名而来”；
四是学习缠论已有一定所得，以审视的态度来看看，这里说的究竟怎么样。

但究其根本，大多还是以赚钱和追求财富自由为根本出发点，来尝试寻 求更好解决方案与途径。这一点很正常，没什么可回避的。毕竟，在市场中 能赚钱是评判结果的唯一标准。但市场里，一味地追求结果未必就会如愿以偿， 大多数时候是事与愿违的。在市场中什么才能赚钱？在缠论原文中已经给 出了一个简单且透彻的答案：**市场从来都是明白人挣糊涂人的钱**。何谓明白？ 何谓糊涂？市场里自以为明白的人很多，一句简单的明白人，其中却蕴含着 很深的内容。

如何成为“明白人”？“糊涂”的原因又是什么？能否改变？应该如何做？
