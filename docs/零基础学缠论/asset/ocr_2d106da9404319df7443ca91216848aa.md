中枢扩张一定是在已经有两个同级别、同方向中枢的情况下，再去看这两个中枢之间是否存在重叠。两中枢的组件不存在重叠就是这个级别的趋势走势类型，两中枢的组件存在重叠就是发生了中枢扩张。

# 3. 初始方式不同。

+   (1) 中枢延伸：不形成第三类买卖点。

中枢延伸中是没有第三类买卖点来终结中枢的，但中枢级别可以生长，所以其对应的第二类买卖点的级别也是同步生长的，前面说过第二类买点的级别可以比第一类买点的级别大原因就在于此。

+   (2) 中枢扩展：形成第三类买卖点后，又拉回到原中枢。

中枢扩展一定需要形成第三类买卖点，而后又回到原中枢，它才进入中枢扩展模式。

+   (3) 中枢扩张：形成第三类买卖点，且形成两个同级别、同方向中枢后再去考察。

当没有形成第三类买卖点，它一定是在中枢内延伸；当形成第三类买卖点并且回到原中枢内，它一定不可能形成中枢扩张，一定是在中枢扩展中；当形成第三类买卖点并且形成了两个同级别、同方向的中枢之后，才考察两中枢是否有重叠，是否完成中枢扩张的升级（如图3-132所示）。
