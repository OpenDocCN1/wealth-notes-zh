# 案例 上证指数

如图 4-104 所示，用周线图看，只是看不到这里面的 5 分钟以下的变化而已，周线一笔的内部结构是什么，依然是可被定义的，逐级去观察就是了。

![](bbox=[0.12, 0.27, 0.86, 0.53])

图 4-104

如图 4-105 所示，日线图上，现在这个位置 3-4 是 5 分钟的中枢 B，它可以走出个 c 段，之所以现在不进场是因为没有量，若没有量，则走出 c 段的概率偏大，那就等 c 段走出来。如果它没走出 c 段就直接上去了，一定会在 2858 点上方形成第三类买点，并且出现放量，这时就能认定之前的下跌结束了。这样操作就变得非常有依据，我们也就不用天天想这些地方是买还是卖，而只需要等市场给出答案。
