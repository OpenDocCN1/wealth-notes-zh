# 学习重点不同

# 一、传统理论

特殊形态下，探究大概率变化的触发条件以及变化的方向和运动节奏。

传统理论探究的是在特殊形态下，大概率变化的触发条件及变化方向等。我们要学习的是大概率所产生的边际条件以及它可能对应的变化方向。它更看重局部显著特征 (所以我们在讲传统理论时经常告诉大家要学习它的特征)，例如、头肩底的右肩是否具备放量这样的特征。我们要找到它的触发条件和市场的大概率事件，即用已发生的现象来认定它。
