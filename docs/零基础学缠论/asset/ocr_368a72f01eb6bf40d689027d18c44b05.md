11. 缠论原文中提到：趋势走势类型看背驰，盘整走势类型看第三类买卖点。趋势走势类型看背驰能理解，背驰了走势就结束了，盘整走势类型也可以看背驰，为什么要看第三类买卖点？

因为第三类买卖点是中枢终结的标志，没有第三类买卖点，盘整走势类型是不能判断完成的；只能表述为：还在盘整走势类型的中枢构筑中。

如图 4–82 所示，这个盘整走势类型结束了吗？答案是没有。它还在中枢构筑中，连 b 段都没有走出来。

![](bbox=[0.25, 0.42, 0.75, 0.62])

如果它向下形成第三类卖点，我们才能说盘整走势类型的中枢构筑完成，可以理解为向下的结构，只是看不到进入段而已（如图 4–83 所示）。
