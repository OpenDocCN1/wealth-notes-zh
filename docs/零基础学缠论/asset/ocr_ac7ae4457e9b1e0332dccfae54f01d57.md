# 四、笔的延续

新一笔未生成前，前一笔延续。

当 K 线走势满足笔的定义时，这一笔为暂定状态（当前暂定笔的结束点，后期仍有被破坏的可能），直到新的反向笔生成，该笔被确立。在这之前，该笔延续，这就是笔的延续。
