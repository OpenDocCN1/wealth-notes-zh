在分解时，3 是最高点，一般是把 0-3 当成一个走势，因为它有中枢、进入段、离开段，结构是饱满的，所以从 3 这里切开，不把 1-4 当成一个中枢。当然，用多义性分析，把 1-4 作为一个中枢，当出现第三类卖点 5 时，中枢 1-4 被确定下来也是没有问题的。

另外，盘整走势类型看第三类买卖点，强调的是对于盘整走势类型来说是没有方向的，但第三类买卖点预示走势方向的产生，而走势的方向是交易最先需要搞清的事情。

# 12. 趋势离开段（c 段）是否应该要有第三类买卖点？

如果 c 段里有第三类买卖点，这个 c 段是标准的，从级别上讲，它就不存在小转大。如果它没有第三类买卖点，也可以在中枢 B 中继续震荡。因为趋势走势类型的结构饱满，可以随时完成，所以 c 段要更加当心一点，它很容易对应同级别的反向走势（如图 4-88 所示）。
