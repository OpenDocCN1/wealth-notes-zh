# 三、背驰的判断方法

+   1. 缠论原文中判断背驰的方法。

缠论原文中是用 MACD 红绿柱的面积来判断背驰的。

MACD 是一种常用的判断背离的指标，但是在缠论中没有用“背离”表达，而是用“背驰”表达。

背离和背驰的本质区别：MACD 指标通常用的是红绿柱的高度，而在缠论中用的是红绿柱的面积。

在传统理论里可以找到背离的概念：当走势出了新高，但是 MACD 红绿柱高度没有出新高，就发生了指标背离（如图 3-71 所示）。
