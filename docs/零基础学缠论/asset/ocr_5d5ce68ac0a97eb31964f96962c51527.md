# 附录：李晓军老师缠论金句精选

1. 交易，从本质上说是一场修行，只有从源头上解决问题，最终才能得到想要的结果。

2. “缠”在我看来是约束、是束缚，“禅”是自“在”，以“禅”破“缠”，于约束、束缚中去体证感悟自在，得大自在！

3. 缠论的简约、高效能帮助投资者快速建立起自己的操作体系。从分析到操作，各个环节的问题都能通过这套体系而得到有效的解决。

4. 缠论不只是技术，还是一套优秀的交易体系，它更是一种世界观，重构我们看待事物的底层逻辑，通达事物本质，所以缠论亦是交易哲学。

5. 缠论可以客观地定义任何一根K线，可以让任何一根K线都不再是孤立的存在，其能客观地回答：过去是什么，当下在哪里，未来怎么变化。

6. 缠论最精深的智慧基础，就是其描述了市场运动的未来：走势是生长的。
