# 2. 5分钟图。

如图3-148所示，中枢1-4和中枢5-8有重叠，形成中枢扩张，扩张后的中枢A是1-8，但它没有升级，还是5分钟中枢，所以0-1是进入段a，1-8是5分钟中枢A，8-11是离开段b，目前在5分钟中枢B的构筑中。14-15这个位置可以是走离开段c，也可以是在构筑中枢B，或者是向下形成第三类卖点，现在考察它接下来到底如何完成。如果向下形成第三类卖点，那15这个位置也依然可以形成小转大走势（10月9日开盘的跳空，使1分钟走势看不到背驰），结束整个5分钟的上涨走势。所以现在只需要防范11-14这个中枢，只要不在它下方形成第三类卖点，它就可以以中枢11-14为中心，构筑5分钟中枢B。把14作为A0，再用区间套到1分钟图上看14-15发生了什么。
