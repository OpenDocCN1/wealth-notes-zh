2. 某级别的走势必是由其次级别走势不断地完成来构筑的。

从局部来看，走势一定是从次级别走势不断生长组建出来的，次级别走势不断地终结，形成上下下、下上下这样的运动来构筑更大级别走势。

3. 交易某级别走势构筑的未完成部分。

利用次级别走势的生长来交易某级别走势构筑的未完成部分。例如，一个30分钟的未完成走势，已经有了a段和中枢A，其b段一般会对应一个5分钟走势。这就是在30分钟走势最终完成的保证下，通过跟踪b段的最终生成，来完成这个5分钟走势的交易。

4. 该交易部分的级别可供交易。

例如，1分钟级别的走势，它的次级别是秒级别，而秒级别是很难构成交易机会的（波动很大或者用杠杆除外）。

另外，交易部分的级别一定是我们的生命长度可予以保证的。因为走势其大无外，如果选用一个年线级别的走势去交易，那么这一辈子只怕都没法参与其完成一个走势。因为一个走势从它最低级别去构筑的话，需要很多根K线，每一根K线代表1年，一个年线级别可能几百年甚至几千年才能完成，这肯定不是我们的交易级别。

通过这两点，缠师建议我们的交易级别选择30分钟级别。如果你的量级足够大，例如要做几年的，那用日线级别去交易也足够了。所以我们常用的级别是30分钟级别，最高的级别用到日线级别，最低的级别用到1分钟级别。

(1) 某级别走势完成必然保证一个反向次级别运动。

某级别走势完成，必然保证一个反向次级别运动，这是一个很关键的论述。

如图3-98所示，一个日线级别的下跌结束，一定会有一个30分钟的反向运动。这是在推导过程中被充分论证的一个结论。
