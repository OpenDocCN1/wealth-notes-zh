# 9.b-A的形态是什么原因造成的？

如图 4-81 所示，为什么会有 4-5 的回落？这个回落我称之为短线获利盘的回吐，它的中线力量、驱动因子并没有消失。所以 4-5 不会被拉回中枢 2-3 内，它的每一次回落都有中线资金继续介入，使它对于中枢 A 来说没有形成回拉。第三类买点更加证明有了有新的做多力量加入，有更多的中线资金看好它的后市，它就会抵抗下面大中柱 2-3 对它的吸引。

![](bbox=[0.25, 0.4, 0.78, 0.71])

3-4 的上涨短线可能就盈利 30% 了，但是 4-5 为什么中线资金还愿意介入？介入者肯定看的是更高的上涨，比如 50% 以上的空间。从波浪学上说，3-4 是 1 浪的话，那么 5-6 就是 3 浪，5-6 的上涨力度一般是 3-4 的 1.618 倍，这是一个简单测算空间的方法。
