# 2. 第二种划分。

如图 3-107 所示，把 0–5 进行组合，5–10 进行组合，整个走势就变成了趋势走势类型+盘整走势类型运动。把 5 作为第一类买占，8 作为第二类买占，9 依然构成的是第三类买占。

![](bbox=[0.24, 0.33, 0.76, 0.58])

两种划分，9 这个第三类买占的级别可能会不同，但它的性质是不会改变的，买占只能是买占，这个买占不会因走势划分的变换而变成卖占，这就是变换不变性的核心。

通过对同一走势进行不同地拆分、组合，去看最后的买占和卖占是否发生改变，如果得出了一个相同的结果，这个结果才是被客观保证的，才可以被用。就像解题一样，用不同思路去解同一道题，当得出的答案一致时，这个结果才是被客观保证的。

多义性的运用是必须具备的能力，也是未来做好不测而测的基础，希望大家尽量多地对走势进行多义性的划分训练。
