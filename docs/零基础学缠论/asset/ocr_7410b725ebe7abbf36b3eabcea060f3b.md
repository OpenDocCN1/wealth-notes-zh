综上所述，破解背了又背的方法有三个：

+   第一，把操作级别放大，建议操作 30 分钟及以上级别的买卖点；

+   第二，用仓位应对，不同级别对应不同的仓位；

+   第三，可以用第二类买点来确认第一类买点，操作第二类买点来提高买点的稳定性。

所以，走势是鲜活的，是永远变化的，唯有用有效的策略及仓位应对才能长久地在市场上生存。

# 五、关于买卖点

# 1. 为什么要弄清楚买卖点的转化?

首先需要明白，买卖点之间的转换对应的是走势的不断演化，买卖点实际上是走势运行中的重要节点，如果对多级别联立下的走势变化运用自如，买卖点之间的转化是自然完成的，在这个基础上再来理解和熟悉买卖点的转化，会强化我们在分析走势和交易决策上的能力，当我们能用缠论应对任何走势时，你会由衷地感叹缠论的神奇。

# 2. 第一、二类买卖点是如何形成的?

第一、二类买卖点的形成涉及背驰的概念，我们先理解什么是背驰，观察背驰就是观察能量的衰竭及转换。

（1）上涨力量 = 空头的抑制 + 多头的推动。

上涨力量如果占优，一定是空头被抑制了，空头没有力量再打出低点，就会产生背驰，形成第一、二类买点，而后有新的多头推动，使它产生第三类买点，这就是上涨走势。
