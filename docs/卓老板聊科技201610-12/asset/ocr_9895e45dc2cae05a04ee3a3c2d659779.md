# 致听众信：半程收获

# Mr.Y，你好！

到了今天，我们今年节目订阅的内容就已经播完一半了，对我来说收获很多，我先聊聊自己的感受，大家再聊聊各自的感受。

我从前也做了大约一年半的音频节目，但是从不定期更新。这根源于收获和感受并不是定期产生的，所以有了就聊聊，没有就继续找。而一旦固定了周二、周五更新，这难度就加了一层。我的习惯是必须留出一些余量，无论什么事儿，只要出现了规划的时间点，在什么什么时候就必须完成。最初几期找不到节奏时还真是憋得厉害，经常为找到了节目思路而兴奋，每周只有稿子写完后的十几个小时是放松的，但马上又要进入到下一个周期。所以能做到固定时间更新，对我来说算爬上了一个新台阶，这点对从前的我来说是不可想象的。

第二个新台阶是在周二和周五的基础上又增加了周一、周三、周四的更新，最初答应的是和听众互动两三分钟，但是很多问题是需要多查些内容才敢播出的，查的多了，也就别浪费资源，把它们都说给大家，于是听众答疑也很少有5分钟以下的，有的也有七八分钟。我觉得这部分是让节目紧跟科技时代的机会，因为通常都是一些和生活相关紧密，或者和科技圈热点有关的。这部分更新量现在已经几乎填满了我的生活，可以说既忙又充实。

在全职做节目前，我本以为等到每天不用早上打卡上班了，我的生活中共周末的界限会开始模糊，但实际上完全不是，我依然盼着周五晚上，那时我的心里可以轻松一些，周末和工作日的界限还是非常明显的。但因为每天不用再跟路上堵两三个小时，所以效率提升了不少。

做节目的强度很大，用脑多了容易干扰到睡觉。很多听众也问过我怎么不失眠，我虽然从没失眠过，但睡眠效果经常不好。我自己查过这方面的资料，但也没有什么帮助，所以也没回答过，希望我也能在某一天发现一种好方法，到时和大家分享。感觉累了时可以马上休息一会儿，不用像打卡上班的时候，非常疲劳也要准时到公司，然后一整天状态低迷。

在北京上班的时间成本很高，如果单程距离25公里以上，那么很多人每天至少需要3小时在路上。这段时间我在家工作，尤其是到了周五下午5点半，就会特地打开地图软件看看二、三、四、五环上，红得发紫的线，感叹一下。我觉得巨型城市迫切需要秩序和人工智能，秩序保障一定的效率，人工智能也许可以让我们异地解决很多形式上的见面和形式上的集中。很多公司给新员工住房补贴，比如每月1000块，并且要求几位同事合租才给到手，这有几个好处。第一个，从前只敢花2000块钱租房的人这下就可以选择公司附近3000块钱的房子，也许骑车5分钟就到了，这样一来，这些人把平时花在路上的时间也都奉献给工作了，新人往往还是单身，没事做就会往公司跑，所以每月1000块钱的补助，换来了路上的2小时不说，还能促进加班的主动性。第二个好处就是促进新员工间熟悉和交流，所以这个办法是一个双赢的策略。
