# 权位上没有谦让，没实力就是坐在火山口或是政治过渡人物！

【出处】《资治通鉴》第 68 卷 汉纪 60

【原文】鲁肃去世，孙权派从事中部彭城严畯代肃，督兵万人镇陆口。众人皆为畯喜，畯固辞以“朴素书生，不闲军事”，发言恳恻，至于流涕。权乃以左护军虎威将军吕蒙兼汉昌太守以代之。众嘉严畯能以实让。

【译文】鲁肃去世，孙权派从事中部、彭城人严畯接替鲁肃的职务，率兵一万人驻守陆口。大家都向严畯贺喜，严畯却以“朴实书生，不熟悉军事”为借口坚决推辞，言辞十分恳切，甚至流下了眼泪。孙权便派左护军、虎威将军吕蒙兼汉昌太守，代替鲁肃的职位。大家都赞许严畯能据实相让。

【解析】任何人都会对天上掉馅饼的事情兴奋不已，但是这在权力上却并非好事，通常好运的背后都是飞来横祸。看得见的馅饼背后，是看不见的陷阱！因为有这三种情况搞不清楚，就相当于坐在了火山口，将会进退失据，更加可能身首异处：

1、自身实力

严畯知道自己是书生，没有军事指挥能力，也没有军队背景，更没有军队拥护，自己贸然 的去接替鲁肃对抗，河对岸的关羽，尽管这个省部级位置非常的诱人，但是自己干不下来， 去了就是赶鸭子上架，自己不单单毁了组织的未来，更会毁了自己名誉甚至生命。所以严 畯有自知之明，坚决推辞。

我们在职场就是，不是说给了位置就是好事，前提是，我们要为有可能的位置，做出相应 的准备，要学习权力心思、权谋手段、组织架构、人员拉拢、专业能力、管理能力等等准备，机会永远都是给有准备的人的，没有准备，上位了，即使做下去，要么搞的一团糟， 要么是做橡皮图章的傀儡。

2、强大潜敌

很多人会想，你说的不对，我不当官，我怎么可能够学会当官啊，我只要在了哪个位置，我 学学就会了。很多人也没有当过皇帝不照样做的好好的，有这种心思的是没有学过权谋， 皇帝是一把手，背后也是势力的代表，可能是维护正统的儒家清流，可能是背后的外戚， 可能是宫里的宦官。

汉献帝就是明显的例子，上述的清流、外戚、宦官这些势力都消失了，感觉只要自己还有 能力，就不怕经营不起来，但是，他有个最为强大的潜敌曹操，曹操是不会给汉献帝这个 机会的。严畯也是，啥都没有，背后还有一个大野心家，陆逊凯舰这个位置，严畯自己是 坐不稳的。
