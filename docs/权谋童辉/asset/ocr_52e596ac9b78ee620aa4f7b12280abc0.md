# 黑吃黑的职场进阶法——江湖派白手起家的套路！

【出处】《资治通鉴》第185卷 唐纪1

【原文】辛丑，李密将井陉王君廓帅众来降。君廓本群盗，有众数千人，与贼帅韦宝、邓豹合军虞乡，唐王与李密俱遣使招之。宝、豹欲从唐王，君廓伪与之同，乘其无备，袭击，破之，夺其辎重，奔李密；密不礼之，复来降，拜上柱国，假河内太守。

【译文】辛丑（二十七日），李密的将领井陉人王君廓率部来降唐王。王君廓部原本是一伙强盗，有数千人，和贼帅韦宝、邓豹队伍一同驻扎在虞乡，唐王和李密都派人去招降三人，韦宝、邓豹想从唐王，王君廓假意和二人相同，乘二人不防备，袭击并打败了韦、邓二人，抢了二人的辎重，投奔李密；李密对他不太尊重，又来投降唐王，唐王拜王君廓为上柱国、代理河内太守。

【解析】王君廓从一个地痞流氓，最终成为大唐开国无法回避的人物，王君廓这样的人，走了一条与平常人完全不同的白手起家之路，那就是黑吃黑，意思就是说，不断的踩着队友的人头上位。而这段通鉴材料就典型的反映了这种操作手法。

1、假意合作

普通人赚钱，都盯着客户的钱，费尽心思，还需要长期的坚持。但是高手都是盯着合伙人的钱。光明正大的学院派，就不断的融资，吸引投资人合伙，然后上市出卖股份，所涉及的产品就是个资本市场讲故事的工具。而阴暗的江湖派，就是不断的吸引合伙人，趁其不备，各种造假，专坑自己人。把合伙人的钱转移到自己的兜里，然后企业破产。合作是假，坑队友是真。

2、吞并资源

学院派是合作人赚到小钱，自己赚到大钱。而江湖派是自己赚了合作人的钱，合作人血本无归。王君廓和另外两个贼帅韦宝与邓豹，如果一起投降的话，自己所占有的功劳非常小，份额也不会大，所以，暗中吞并他们两个的队伍，才让自己有了更 大的筹码。有了更大的筹码，才能参与到更大的游戏中去，才能不断的放大这种游戏。坑队友，是为了有机会坑更多的队友。

3、带资加盟

为什么大唐和李密同时伸出橄榄枝，其他的贼帅都看到了大唐才是最终的赢家，而为什么王君廓却选择了，瓦岗寨同样土匪起家的李密呢？不是王君廓不知道大唐的强大，而是认为自己的筹码不足，选择李密是为了再次黑吃黑，但是李密和他是一样的人，李密就是这样吞并让队伍的，所以，一眼就识别出王君廓的用意，对他特别的防备，王君廓找不到机会，只能转投唐朝了。
