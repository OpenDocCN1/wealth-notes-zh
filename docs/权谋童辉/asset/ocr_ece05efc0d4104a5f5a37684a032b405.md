人，作为权谋家，带过兵打过仗，又是官僚世家，对于韩休这样的性格会不了解？会不熟
悉？即使韩休真的不配合，之前隐藏的比较深，权谋家也不会对着干，而是会背后下手，
更不会作为失败者黯然退场，因为怕被人清算。所以，排除识人不明的表面故事，我们就
能够看出来，萧嵩推荐韩休上位，就是为了利用和他的耿直性格，作为自己下驴的坡！

# 2、顺坡

明白了萧嵩的大智慧，知道他想借助韩休之间的正常的政治争论，顺利的让皇帝对他放生
的整体思路，我们就很容易看懂后来的故事了。找到坡之后，就开始利用这个坡了。于是，
不断和韩休争论，让他知道自己的无伤大雅的短处。让皇帝天天有断不完的官司，天天有
调解不完的矛盾。这个没有价值的事情，而且天天让皇帝很反感，皇帝自然就不想让他们
再待在身边了。于是当皇帝内心开始不舒服的时候，萧嵩主动的退出，流着泪，给皇帝提
出了解决方案“我承蒙陛下下的厚爱，担任宰相，富贵已达到顶点。趁着您还没厌恶我，
所以我能不慌不忙地引退；如果您已经厌恶我，我的头尚且保不住，想引退又怎能如愿！”
让皇帝厌恶了萧嵩和韩休的矛盾，而且恰当的时候又高姿态的退出，让皇帝无成本的解决
难题，这时候，皇帝必然采用权宜之计，让萧嵩下台，顺利满足萧嵩的自身愿望。

# 3、下驴

在萧嵩的恳求下，皇帝让萧嵩退了下来，萧嵩没有犯错误，而且自己的退出，还是为皇帝
解决矛盾，不想让皇帝为难。这样处地为皇帝考虑的人，又能够以情动人，自然让皇帝更
加的喜欢萧嵩。《新唐书·萧嵩传》在听到他要隐退的话之后，后面有一大段的描写，通
鉴上没有记载——帝为改容曰：“卿言切实，朕未能决。第归，夕当有诏。”俄遣高力士
诏嵩曰：“朕将你留，而君臣谊当有始有终者。”久之，进太子太师。固请老，见许。啥
意思呢？皇帝为此动容地说：“卿说得很恳切，朕不能决断。你姑且回去，傍晚会有诏书。
”不一会儿派遣高力士下诏给萧嵩说：“朕将你留下，君臣情谊应当有始有终。”一段时间以
后，萧嵩升任太子太师。他坚决请求退休，皇上同意。皇帝先罢免了萧嵩的丞相位置，变
成虚职的太子太师，最后又在虚职上退休。萧嵩和平落地，顺利下驴。

很多人知道物极必反，但是迷恋手里的权力，最后不能善终。而萧嵩具有大智慧，退休之
后，自己在家花费精力，注重养生，多活几年，就多几年的舒服日子。《旧唐书·萧嵩传》
对他退休后的生活记载的更加详细“嵩性好服饵，及罢相，于林园植药，合炼自适。毕时
为工部侍郎，辅以主婿三品，嵩蟠然就养十余年，家财丰赡，衣冠荣之。天宝八年薨，年
八十余，赠开府仪同三司。”古代七十古来稀，人家萧嵩活到八十岁，而且身体好，儿子
有作为，家里又有钱，这才是成功者的人生！
