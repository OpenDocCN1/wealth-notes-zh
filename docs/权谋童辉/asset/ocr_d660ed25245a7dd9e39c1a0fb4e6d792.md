# 上司让你给他提意见，你该怎么说？

【出处】《资治通鉴》第 197 卷 唐纪 13

【原文】辛亥，上幸九成宫。壬子，至太平宫，谓侍臣曰：“人臣顺旨者多，犯颜则少，今朕欲自闻其失，诸公其直言无隐。”长孙无忌等皆曰：“陛下无失。”刘泊（音：继）曰：“顷有上书不称旨者，陛下皆面加穷诘，无不惭愧而退，恐非所以广言路。”马周曰：“陛下比来赏罚，微以喜怒有所高下，此外不见其失。”上皆纳之。

【译文】辛亥（初八），太宗巡幸九成宫。壬子（初九），到了太平宫，对身边的大臣们说：“大臣们顺从旨意的居多数，犯颜强谏者极少，如今朕想要听到关于朕的过失的话，诸位当直说无所隐瞒。”长孙无忌等都说：“陛下没有过失。”刘泊说：“近来有人上书不合陛下圣意的，陛下都当面百姓责备，上书者无不惭愧恐惧而退下，恐怕这不是广开言路的办法。”马周说：“陛下近来赏罚，略有因个人喜怒而有所高下的情况，此外没有见到过失。”太宗都予以接受。

【解析】领导让下属畅所欲言给他提意见，总有耿直的人，对领导的缺点毫无掩饰的揭露，殊不知，领导的笑容会越来越尴尬，尽管嘴上说这样的人很不错，但是内心却会认为：没想到这家伙对我有这么大的怨气，让我脸面挂不住，下不了台，当众失去了尊严，伤害了权威。接下来的日子，上司就会对这样的耿直的人，有了看法，逐步的会边缘化，找借口开除。领导让你提意见，只是为了展示其胸怀，你以为，真的让你滔滔不绝？李世民也有这样的做法，看看下面几个高情商的权谋家下属都是怎么说的？

+   1、毫无错误型

长孙无忌等皆曰：“陛下无失。”这句话的关键是，长孙无忌后面的“等”这说明这是大多数人，都采用的态度，都认为皇帝没有任何过失。这对皇帝来说是个潜在的马尾，也让大臣自己处于安全状态。不过这个不能够衬托出皇帝纳谏的心胸态度，广开言路的政治姿态。大臣们“不求有功，但求无过”的策略，尽管四平八稳，但是不能够迎合皇帝配合表演，所以也不会出彩，属于平庸的大多数。

+   2、潜在风险型

那么总有人，想配合皇帝表演提出意见，又不能把提意见变成指责，这个平衡度很难把握，但是把握好了，就能够让自己出彩，让皇帝受用。刘泊“顷有上书不称旨者，陛下皆面加穷诘，无不惭愧而退，恐非所以广言路。”这句话非常的有艺术，就是皇帝没有过失，但是可能有潜在的不良影响。有些人做错了，皇帝批评他们，尽管是他们的问题，但是可能有堵塞言论的可能。
