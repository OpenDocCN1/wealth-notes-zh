# 平行部门发生冲突，做领导如何护犊子？

【出处】《明史》第 213 卷 列传 101

【原文】南京小奄醉辱给事中，言者请究治。居正诮其尤激者赵参鲁于外以悦保，而徐说保裁抑其党，毋与六部事。其奉使者，时令缇骑阴伺之。其党以是怨居正，而心不俯保。

【译文】南京的小宦官醉酒后侮辱给事中，舆论请求追究惩治。居正将最激进 的赵参鲁贬出京城以便取悦冯保，再慢慢劝说冯保制裁，抑制他的党羽，不要同六部摩擦。奉命行事的宦官，也不时指令锦衣卫暗中刺探他们。冯保的党羽因此怨恨居正，而且内心也不依附冯保。

【解析】在职场，很难就事论事，因为每个事件的背后，有着千丝万缕的关系，主要核心就是信任感没有建立起来的时候，所有的行为，都可能过度的做出政治解读，就会往最坏的地方想。当自己的下属被人欺负了，这时候，作为一个高手，既要保护自己的人，又要考虑到政治影响，这个平衡就很难办了。张居正作为权谋高手，很高妙的手段解决了问题：1、首先处理自己人

张居正刚刚成为大明辅辅，面对小太监侮辱自己的属官，本来可以直接出手护犊子，给小太监一点颜色看看，但是打狗也需要看主人，小太监不是问题，问题是他背后的大太监冯保。其实也不见得，小太监和冯保有多深的关系，但是就怕在合作初期冯保多想，认为张居正这是借题发挥，给自己下马威。所以张居正一开始并没有直接出手，而是放手舆论的酝酿，这样自己占有道德制高点，然后把讨论的最激烈的赵参鲁立即被张居正贬黜京城。事情搞大后，处理自己人，这就是姿态，排除冯保可能的误解，在表面上取悦了冯保。具体操作上，贬黜了赵参鲁，其实也是保护他，以免受到太监的迫害。另外，表面上赵参鲁是受到贬黜了，但是并没有去上任，请了个病假就回来了，不过因为恰好遇见丧事，回家守孝，期满后，去福建做了学政这个肥缺，没多久就调回中央了。舆论风头过去了，给自己的人一个补偿。

2、让对方管教下属

张居正自己首先做了姿态之后，还是没有直接出手给小太监惩罚，但是却给冯保建议，让他自己处理自己人。这样做的张居正，不会让冯保产生政治异议，把这件事情限制在了就事论事上。在这方面，张居正做了三方面的工作，首先是没有立即言辞激烈的劝说，而是“徐说”和颜悦色，不掺杂情绪，避免挑动冯保的情绪反应。其次，让冯保自己约束自己的党羽，谁的孩子谁管的原则，避免直接处罚，让冯保觉得张居正手伸的太长，侵犯了他自己的权力。因为做领导的都这么想，我自己的孩子我自己打可以，你打不行。最后就是，巧妙的提出自己的建议，不要与六部摩擦，完全不提自己的人被侮辱的事情，把这个事情变成了一个建议，而不是一个针对性的反击。如果还纠缠这个事情不放，必须要求严惩小
