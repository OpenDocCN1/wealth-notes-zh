# 3、所有可能手段

知道人性会知道他会选择什么样的路，知道事物的发展规律，会知道他前进的地图是什么样的。而明白所有可能的手段，就是知道他有可能选择什么样的交通工具来到达自己的目的地。所以，杨洪对黄元的手段采用了穷举，不能成就会顺着青衣江逃跑。因此提前就让陈忽、郑绰在南安峡口拦截，果然就抓住了他。权谋预测的魅力就在这里，准确断定一个人的行为之后，就能够在他前进的路上等着他，设伏，可以这么说，道路一旦确定，手段就能够穷尽。

经过上述权谋网的分析，我们能够看出来，预测事情并不是大家所想的那么的难，只要研究他的价值观，就明白了他会选择什么样的路走，知道他的选择的路走，因为阳光下没有新鲜事，他能够走的路，历史上都会有相应的地图、模板，我们就能够提前知道他要走的路是什么样子，又因为热读历史，就能够穷尽所有的手段，知道他会用什么交通工具上路，就能算出他会在某个时刻出现在某个位置，这样我们能够抓住这个机会，提前设伏，从而完成自己的目的。因此，只要我们不断的阅读历史案例，就能知道，人性价值观特点，事务发展变化的规律，处理事情的各种手段，预测能力就会大大加强！
