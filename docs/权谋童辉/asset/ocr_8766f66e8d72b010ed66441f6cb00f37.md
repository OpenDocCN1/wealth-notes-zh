# 3、夫人元氏的舆论操纵，阴谋上位策略！

可能稍微熟悉历史的人，会接着问，既然准备传位，直接打击田兴就行了，李世民死之前就是这么处理徐茂公李绩，打击走他，等李治上位把他提拔回来就行了，为什么还要装疯，滥杀无辜，搞的军备废弛呢？这不是自伤元气，为后代剪除阻力？其实，最大的可能，元氏为了自己的儿子和田兴联手，软禁田季安，软禁之后，利用他的名义滥杀无辜，制造舆论，让大家觉得，他真的是疯了，把位置交给 11 岁的儿子，之后一个月就死了，让大家没有怨气，更没有怀疑，阴谋篡位成功。

一个简单的事件背后有着错综复杂的阴谋动机，如果大家再接着想，孤儿寡母能控制住有野心的田兴嘛？没错，螳螂捕蝉黄雀在后，田兴通过一系列的手法，利用外部危机，内部小人，废了田怀谞，自己成了魏博节度使。为什么李世民利用了李绩这件事情就做成了，但是田季安利用田兴的事情就失败了呢，差别在哪？主要是，李世民时代，外部环境稳定，属于守成阶段，而田季安的时代是唐末军阀割据的乱世。守成阶段大家遵守稳定的秩序，而乱世是靠权谋和实力说话。

【附录】A、网友 Nero 留言：田兴装病成功后，司马光直接就写到田季安得了疯病。季安为什么会忽然得疯病了？是很久之前就得了还是忽然之间就得了？是真疯还是假疯这些司马光都只字未提。但从后来事件发生的情况来看，我推断季安应该是疯了，不光是真疯而且还是忽然间就疯了。而这一切我认为都是田兴搞得鬼，田兴在得知田季安要杀自己以后，便下毒使季安发疯。古时候毒药千百奇怪，无奇不有。把人先搞疯然后再死的慢性毒药也不是没有。当然这一切必然需要元氏作为内应，季安到死也不会想到自己夫人会对自己下毒，这也能解释季安在疯了没多久后就死了。等到季安疯了之后元氏便假传圣旨免了田兴的死罪。至于田兴为什么还要装病，我推测田兴自己也不知道给季安下的毒什么时候会发作，毕竟这是慢性毒药，他装病完全就是为了拖延时间。不过这一切也只是我个人猜测而已。
