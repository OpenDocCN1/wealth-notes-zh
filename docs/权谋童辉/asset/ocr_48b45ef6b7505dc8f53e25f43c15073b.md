# 小人是权力阴暗心思的遮盖布！

【出处】《资治通鉴》第221卷 唐纪37

【原文】或上言：“天下未平，不宜置郭子仪于散地。”乙未，命子仪出镇邻州；党项进去。戊申，制：“子仪统诸道兵自朔方直取范阳，还定河北，发朔生英武等禁军及朔方、坊、宁、泾原诸道蕃、汉兵共七万人，皆受子仪节度。”制下旬日，复为鱼朝恩所沮，事竟不行。

【译文】有人上言说：“天下还没有平定，不应该削夺郭子仪的实权。”乙未（初八），肃宗即命郭子仪出镇邻州，党项军队闻风而退。戊申（二十一日），肃宗下制书说：“命令郭子仪统帅各路兵马从朔方直捣范阳，然后回师平定河北地区，并征发殿前射生手英武军等禁军以及朔方、坊、宁、泾原等各路蕃人、汉人兵共七万人，都受郭子仪节制。”制书颁下后十天，因为受到宦官鱼朝恩的阻挠，此事竟作罢。

【解析】中国自古有反贪官不反皇帝的传统，坏事都是小人干得，领导永远都是好的。为什么如此呢，其实这就是一种专门的权术：利用小人来掩盖权力的阴暗心思，小人成了权力的防火墙、缓冲带、遮盖布。这次郭子仪的任命就赤裸裸的被利用小人操作了一把：

+   1、权力提前解决隐患

权力心思都是未雨绸缪，不是等到最后对立结果出现，才开始残局玩法，从而导致两败俱伤。而是一开始，就发觉了不可调和的矛盾或是即将威胁的能力，这时候就必须提前解决这个隐患。郭子仪在安史之乱的平定过程中立下汗马功劳，但是随着他的威望和军力的增强具备了极强的威胁皇权的能力，而且，随着功劳的增加，皇帝已经赏无可赏，只能让他在战争的扫尾阶段退出战场，让别人继续摘桃子立功，接管兵权，而且不会影响既定的政治大局。所以，皇帝提前解决了郭子仪这个隐患。

+   2、被人挑明后的无奈

本来这种心思就不能公开，需要遮盖布，大家都知道背后是什么，但是公然挑开，让隐私暴露出来，这就会极度的尴尬。但是有人公开宣称，战争没有结束，郭子仪必须启用。这个消息传到皇帝耳朵里，就特别的难受。接受吧，未来郭子仪助众逼宫怎么办？不接受吧，如果是郭子仪故意自己找入，是他本人的意图怎么办，如果是他自己的意图，不答应，他不会利用原有的嫡系力量搞破坏？所以，皇帝能不推定这是郭子仪自己的意思，为了避免提早矛盾激化，只能同意他继续领兵。

+   3、利用小人转移矛盾
