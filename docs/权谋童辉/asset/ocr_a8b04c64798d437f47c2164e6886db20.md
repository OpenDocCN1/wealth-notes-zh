# 3、道德约束

你以为项羽傻啊，他不知道刘邦是什么样的人？他为什么相信刘邦会受到的道德约束，从而认真执行协议？项羽是不傻，但是他心存侥幸，决定赌一把，来为自己争取喘息的时间，毕竟政治形象对于刘邦还是很重要的。但是，刘邦却也只是嘴上说说要走，做做样子而已。陈平、张良立即就为刘邦找到了下台阶的借口，你这是养虎遗患啊，时不我待，刘邦成功转移了道德压力。

上述的三大权谋手法，约束力是逐级递减的，想完全保证合作的有序进行，就必须同时使用上述三大手法，其实不仅仅政治家不相信承诺，老百姓也是如此，买房刚交了钱，签了合同，转身发现房子降价了，立即就恨不得把售楼部给砸了。因为他们不信合同，他们也不会遵守合同，他们只想通过打砸售楼部的方式，来增加对房地产公司的道德约束，逼着开发商重新回到谈判桌上。
