# 2、王曾不敢得罪众同僚

王曾作为宰相没有真凭实据，应该不会随便的检举揭发吕夷简。本来想让皇帝直接处理吕夷就行了，没有想到的是，吕夷简尽然不怕自己的受贿行为被公开，要当朝对证，这让王曾就陷入了尴尬。大家想一下，能够直接找到宰相这个级别行贿办事的人，应该是非富即贵，都是些大能量的人物。如果当朝对证，王曾必然要一项项的列举，谁行贿，多少钱，为了什么事情。如果这样，王曾扳倒的就不是吕夷简了，而是得罪了名单上的所有人，这些人，可能是皇帝的亲戚，可能是在位的各位大臣，可能是自己的亲朋好友，这让王曾很尴尬。不说出来，还是自己的事情，一旦都揭盖子，即使扳倒了吕夷简，自己也就万劫不复了，得罪了这么多人，皇帝不可能都处理，毕竟法不责众。而一旦处理不完，那么王曾就会得到报复，这就不是他一个人的事情了，而是他家旗族整体覆灭的事情了，王曾只能忍了。

# 3、王曾掉入吕夷简陷阱

野史认为王曾是吕夷简故意抛出的诱饵给算计了。故事是这样的：有一个叫王继明的小吏曾给吕夷简送了3000贯钱，吕夷简便安排他做秦州知州。王曾把这个案子举报给宋仁宗后，宋仁宗大惊，连忙质问吕夷简，没想到，吕夷简很淡定地说：“这是诬陷！”王曾为了查清此案，特地派遣吕夷简的死对头、御史中丞范讽亲自负责此案。查案的结果，让王曾大跌眼镜，第一，那个叫王博文的秦州知州并没有行贿，第二，吕夷简的确经手过3000贯钱是吕夷简自己的，只是经过他人之手打算捐给家乡修建学馆而已。王曾到此才才明白，所谓的受贿案，不过是吕夷简故意抛出来的诱饵，引王曾上当罢了。这个故事也告诉我们，势均力敌的政治斗争中，彼此都是高手，怎么可能出现漏洞和破绽？如果这么容易就发现了把柄，一定不要高兴的过早，这里可能就是对手故意引诱上钩的技巧。

经过上述的分析，我们能够看出来，吕夷简一反政治常规，要求公开对证，一下子让本来胜券在握的王曾，立即形式逆转。这给我们的教训有三个，首先是，如果都被打下去，看谁能够再次崛起。其次，如果想撞行受贿赠的案件，这背后触动的是一个群体，自己要考虑是不是斗得过。第三，不要让对方的错误诱饵给迷惑，自己高兴的太早，最终被认定诬告。所以，王曾政治斗争水平没有吕夷简高，我想王曾输得也应该是心服口服，谁让自己技不如人呢？
