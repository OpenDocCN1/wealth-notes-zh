# 料事如神的三大基本原则！

【出处】《资治通鉴》第70卷 魏纪2

【原文】初，黄元为诸葛亮所不善，闻汉主疾病，惧有后患，故举郡反，烧临𫗲城。时亮东行省疾，成都单虚，元益无所惮。益州治中从事杨洪，启太子遣将军陈恏、郑绰讨元。众议以无若不䧟围成都，当由越嶲据南中。洪曰：“元素性凶暴，无他恩信，可能办此！不过乘水东下，冀主上平安，面缚归死；如其有异，奔吴求活耳。但敕恏、绰于南安峡口邀遮，即便得矣。”元军败，果顺江东下，忽、绰生获，斩之。

【译文】此前，黄元被诸葛亮所嫌弃，知道汉王患病，恐怕诸葛亮加害，因而率领汉嘉全郡反叛，火烧临𫗲城，当时诸葛亮由成都东下看望刘备，成都守备单簿虚弱，黄元因此无所忌惮。益州治中从事杨洪，报告太子刘禅，派将军陈恏、郑绰讨伐黄元。大臣们认为，如果黄元不能包围成都，会经越占据越嶲南中。杨洪说：“黄元一向性情凶狠残暴，对下属不施恩德信义，没有能力那样做！不过是顺青衣江东下，盼望主公平安，再捆起自己，请求治罪；即使有其他变化，也不过逃奔吴国求条活命而已。只要命令陈恏、郑绰在南安峡口拦截，就可将他生擒。”黄元叛乱失败果然顺青衣江东下，被陈、郑绰生擒后斩首。

【解析】料事如神一直都是大家最为羡慕的智慧，都希望能够学到其中的奥秘，但是那些预测能力强的人，大多故意把自己的推理过程，包裹上玄学外衣，搞的神乎其神，让人摸不到头脑，其实预测能力并不神秘，这段简短的资治通鉴材料，就从最本质上传译了预测的三原则：

# 1、人物性格模式

江山易改，本性难移。一个人的人性一旦成熟起来，基本上是不会变的。这背后的根本原因是，每个人的价值观一旦成熟，就会自觉不自觉的参照自己的价值认知而行事。所以，我们研究权谋起点就是熟悉人性，熟悉了人性，也就能知道他的选择，也就能够知道他的前进方向。黄元的性格就是凶狠残暴，对下属没有恩信。这样人的下属，就会表面服从，实质消极，就不可能支持黄元。尽管一开始受到其凶暴裹挟而不得不从，但是绝对没有战斗力，黄元失败只是个时间问题。

# 2、事物发展规律

黄元做的非常对，他知道，自己和诸葛亮有矛盾，一旦刘备去世，诸葛亮掌权，自然不会放过自己，利用刘备的病症，成都的空虚，这个时间阶段，起兵造反，直接对蜀汉的江山造成严重的威胁，为自己的生存求取机会。他的推理过程就是，不行动就一定会死；行动了，可能死，可能不死，所以计算的结果就是搏一把。黄元是知道事情发展规律的，那就是，未来的矛盾变化，自己的切入时机，自己所能调动的资源。所以研究权谋，知道事情的规律之后就能相应的布局。
