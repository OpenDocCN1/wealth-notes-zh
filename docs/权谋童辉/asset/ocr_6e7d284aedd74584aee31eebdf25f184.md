# 帝王心术——下属内斗，不能不管，不能真管。

【出处】《资治通鉴》第 17 卷 汉纪 9

【原文】始，黯为谒者，以严见惮。东越相攻，上使黯往视之；不至，至吴而还，报曰：“越人相攻，固其俗然，不足以辱天子之使。

【译文】当初，汲黯担任谒者，因他为人威严而被大家忌惮。东越部族相互攻击，武帝派汲黯前去巡视；他没有到达东越，仅走到吴地就回来了，向武帝报告说：“越人自相攻击，本来他们的习俗就是如此，不值得为此折辱天子的使臣。”

【解析】汲黯面对汉武帝派遣的危险任务，选择打折执行，最终没有被追究责任，表面上看，这很不符合权力逻辑，其实这背后，恰恰是汲黯摸透了汉武帝的权力心思。权谋网细细给大家分析下：

+   1、 汲黯遭受同事排挤

古代出差，尤其是去东越，现在的浙江南部地区，是非常辛苦的，所以这并不是一个美差，为什么派汲黯去呢，这里说的是，因为他为人严肃，让大家忌惮，这样一个不合群的人，很难让大家喜欢，于是被人排挤，去做这个出力不讨好的事情，是再常见不过的斗争手段了。本卷《资治通鉴》后面也指汲黯“黯为人，性倨少礼，面折，不能容人之过。”意思就是说“汲黯为人，性情倨傲，缺少礼数，当面使人难堪，不能容忍别人的过失。”在职场合群是很重要的事情，因为你不知道，讨厌你的人背后会给你出什么难题，设什么绊子。做事先做人，其实也是这个意思，不会做人，就不会有好事找上门。

+   2、 汲黯打折执行任务

  汲黯知道，自己去未开化的东越少数民族调解内斗，基本上完不成任务，而且，还可能被乱刀砍死。如果自己去，可能会被立即被汉武帝收拾。去不行，不去也不行，两难之间，于是汲黯选择打折执行，以拖待变的策略。应该是路上走的很慢，等东越内斗结束，这时候自己也安全了，但是走到吴地快到东越的时候，还是没有出现变数，于是就直接折返回来，汇报说“他们风俗如此，不值得皇帝派专人过去”、一方面皇帝下达命令之后，立即出发，算是权力顺从，但是中途回来，算是没有完成任务，相对于，不服从命令，这处罚就会轻很多，比死在东越更强。两难的算法是：任务可失败，但权力要顺从。

+   3、 汉武帝的真正心思

但是面对没有完成指派的任务的汲黯，汉武帝并没有处罚他，而是不了了之。为什么呢，不是应该奖罚分明嘛？其实皇帝有自己的权力心思，帝王术的算法是：首先，面对东越的内斗，作为领导必须有所姿态，参与维和，组织内耗毕竟对自己不利，所以必须派人了解情况。其次，对于这些未开化的少数民族，当时内心并不是真心拥护大汉中央的，所以这些人自己内斗，互相削弱，其实并不是坏事。最后，不去不行，去了不管也不行，管住了，
