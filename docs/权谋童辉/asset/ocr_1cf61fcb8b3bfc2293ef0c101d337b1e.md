领导要树立形象，所以很多时候坏人要由下属来做！

【出处】《资治通鉴》第 101 卷 晋纪 23

【原文】匈奴刘卫辰遣使降秦，请田内地，春来秋返，秦王坚许之。夏，四月，云中护军贾雍遣司马徐帅骑袭之，大获而还。坚怒曰：“朕方以恩信怀戎狄，而汝贪小利以败之，何也！”黜雍以白衣领职，遣使还其所获，慰抚之。卫辰于是入居塞内，贡献相寻。

【译文】匈奴刘卫辰派使者向前秦投降，请求在内地划给他们农田耕种，春天来秋天走，前秦王苻坚同意了。夏季，四月，云中护军贾雍派司马徐率领骑兵袭击刘卫辰，满载而返。苻坚愤怒地说：“朕正在以恩信安抚戎狄，而你却贪图小利而败坏了事情，为什么呢！”于是废黜贾雍，让他以布衣百姓的身份兼领职务，派使者将他所掠获的财物送还了刘卫辰，并对他加以抚慰。刘卫辰从此进入关内定居，经常向前秦进献贡奉。

【解析】贾雍表面上破坏了，前秦苻坚的安抚政策，被废黜，但是职务却没有变化，很多人认为苻坚内心会特别讨厌贾雍，其实恰恰相反，贾雍这点政治觉悟都没有，怎么做到高官的，其实，他从实质上赢得了苻坚的认可，这才是最好的下属，各种原因，我们详细分析：

# 1、苻坚的尴尬

刘卫辰在没有被打败的情况下，主动投降，索取利益，这对苻坚很是尴尬。作为前秦的皇帝，必须树立良好的政治形象，别人投降，必须接纳，这样才能够树立起大国形象，柔远绥怀。但是如果不打一下，匈奴人内心不会怕，不会真心的归顺，打呢，又有损政治形象。

# 2、贾雍的揣摩

面对这样的政治形势，贾雍果断的判断出，国家需要和刘卫辰打一仗，而且必须是胜仗，这样才能够把前秦的声威打出来，这样刘卫辰的投降，才是真心的。但是这个是有名誉风险的，那就是必须要被领导谴责，但是他做了领导内心想做的事情，之后，还是会被重用的。

# 3、苻坚的处理

面对贾雍擅自开战，而且有这么多缴获，内心是非常高兴的，但是公开却不能不做谴责，于是立即就废黜了贾雍。但是如果一撸到底，以后谁还替首领解除尴尬，谁还能够在边区震慑匈奴呢，所以，苻坚采取了保留职位，让他“白衣领职”，即给匈奴做做样子，又不伤筋动骨。
