# 二、汉文帝处理方法的点评

1、当场表态，违背程序

但是既然汉文帝认为啬夫工作能力强于上林尉，任命，也就任命了，但是随后被张释之的一道说教之后，竟然又改变了想法，这就让皇帝失去了权力的威信。权力错了，就错了，不应再改。

3、处理小事，交办有司
其实韩问题具体的正确的做法是啥呢，就是明末清初的通鉴学者申涵煜的观点“黠陟小吏，此事有司，非天子所宜临问也。”意思就是说，这事交给其顶头上司按程序办就行了。
