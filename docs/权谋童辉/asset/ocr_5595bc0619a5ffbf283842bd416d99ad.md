# 骗花献佛——晋升的捷径权术！

【出处】《资治通鉴》第245卷唐纪61

【原文】初，李仲言流象州，遇赦，还东都。会留守李逄吉思复入相，仲言自言与郑注善，逢吉使仲言厚赂之。注引仲言见王守澄，守澄荐于上，云仲言善《易》；上召见之。时仲言有母服，难入禁中，乃使衣民服，号王山人。仲言仪状秀伟，倜傥尚气，颇工文辞，有口辨，多权数。上见之，大悦，以为奇士，待遇日隆。

【译文】当初，李仲言被流放到象州，后来，由于朝廷大赦，回到东都洛阳。这时，东都留守李逄吉正想再入朝担任宰相。李仲言自称和郑注关系密切，于是，李逄吉派李仲言用重金向郑注行贿。郑注引李仲言拜见右神策军护军中尉王守澄，王守澄又把李仲言推荐给文宗，声称李仲言精通《周易》。于是，文宗召见李仲言。这时，李仲言正在为母亲服丧，身着丧服，不便进入宫中，文宗便让他穿上民服，号为王山人。李仲言身材魁梧，潇洒豪迈，擅长文辞，而且口才好，足智多谋。文宗召见后，十分高兴，认为他是一个奇才，因而对他的待遇日益隆重。

【解析】一个人什么都没有，空有一番抱负和才华，如何的实现快速的升迁？这事是有捷径的，而且被多个权谋家采用，这个技巧就是骗花献佛。用别人的钱打通自己的路子，从而实现自己的目标，这段通鉴中的李仲言就是这类人物的集中代表。

李仲言很多人不熟悉这个名字，但是提到大唐的盛衰转折点，甘露之变，没几个人不知道，其中政变主角之一的李训就是改名后的李仲言。这是未来的唐朝宰相，影响大唐走势的人物。

先说下人物的背景，李仲言是李逢吉的侄子。郑注是王守澄的心腹，而王守澄就是当时权力最大的太监，这时候的皇帝唐文宗就是他政变立起来的，此时王守澄掌握御林军。

李仲言多年前因为参与政治斗争失败，被贬到当时的荒蛮之地象州，也就是现在的广西，遇见大赦终于回到东都洛阳，我想他此时脑子里想的是如何快速的崛起，从何下手。

很快自己的叔叔李逄吉就进入了他的视野，尽管李逄吉是东都留守，也是正部级的官员，但是曾经做过宰相的他，也希望重新回到权力中央，很快李逄吉这个需求就被李仲言掌握了。

于是李仲言就吹嘘自己认识王守澄的心腹郑注，可以代为活动，李逄吉心动了，确信这个侄子真的和郑注关系很熟悉，于是拿出大笔的钱，让李仲言为自己行贿打通关节。

李仲言和郑注到底熟不熟呢？历史记载相当的混乱，胡三省注释的《资治通鉴》里面给出了多种说法，其实，我认为都是假的，这些矛盾重重的说法，恰恰说明都是李仲言吹嘘出来的。
