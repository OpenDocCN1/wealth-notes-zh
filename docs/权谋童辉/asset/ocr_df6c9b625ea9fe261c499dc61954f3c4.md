# 技术性犯规的官场心法——三种情况下必须违规犯错！

【出处】《旧唐书》第 155 卷 穆宁传

【原文】广德初，加库部郎中。是时河运不通，漕挽由汴水、沇水自商山达京师。镇锁夏口者，诏以宁为鄂州刺史、鄂 · 沇河都团练使，及淮西鄂岳租庸盐铁沿江转运使，赐金紫。时淮西节度使李忠臣贪 暴不奉法，设防戍以税商贾，又纵兵士剽劫，行人殆绝。与宁夹淮为理，惮宁威名， 寇盗辄止。沲州别驾薛彦伟坐事忤旨，宁仗之致死。宁坐贬夬州司马，重贬昭州平 集尉。大历四年，起授监察御史，领转运留后事于淄青。间一年，改捡校司封郎中、 兼侍御史，领转运留后事于江西。明年，拜检校秘书少监，兼和州刺史，理有善政。

【译文】广德(763~764)初，加授库部郎中。这时黄河运输不通，水运从汴水、沇水转由商山抵达京师。朝廷选派锁守夏口的官员，诏命穆宁为鄂州刺史、鄂岳沇都团练使及淮西鄂岳租庸盐铁沿江转运使，赐佩金鱼袋服紫衣。当时淮西节度使李忠臣贪赃暴虐不奉公守法，设置军防哨卡向商贸收税，又纵容兵士抢掠，以致路上几乎行人断绝。而一旦与穆宁隔淮水理政，畏惧穆宁的威名，便停止了这种盗跖的径程。沲州别驾薛彦伟违犯圣旨获罪，穆宁施以杖刑致其身亡，因而获罪贬为夬州司马，再贬为昭州平集县尉。大历四年(769)，重新提升做监察御使，掌管淄青转运留后事。隔了一年，改任捡校司封郎中、兼侍御史，掌管江西转运留后事。次年，官拜捡校秘书少监、兼和州刺史，颇有政绩。

【解析】通常而言，官场最忌讳的就是犯规，这样明面上的错误，难以免除惩戒。但是如果有下面三种情况必须违规，必须主动寻求处分！

1、摆脱困局

淮西节度使李忠臣纵容士兵抢劫，而又和穆宁一河之隔。一介军阀真害怕，这个搞税收的转运使？俗话说，挡人财路，如杀人父母。李忠诚之所以暂时约束士兵，也是在等待反击的机会。所以，穆宁面对一群乱兵，内心也是恐惧的。刚刚被提拔过来，如何能够顺利的离开这个是非之地，还不被皇帝误解为自己无能呢？于是，借机打死忤逆圣旨的沲州别驾薛彦伟。主动犯错，于是，被调离是非之地，顺利摆脱困境，还有就是摆脱这个运粮的工作难题。做官，安全第一。

2、划清界限

穆宁作为主管，而下属沲州别驾薛彦伟违犯圣旨获罪。面对这样的，严重违背权力心思的下属，作为主管的领导难辞其责。这不仅仅是管理责任，而且还可能被皇帝认为，是受到穆宁的指使而违背圣旨的。如果有这种想法，穆宁就是有嘴也说不清楚了。即使皇帝不这么想，穆宁的对手也会引导皇帝从这方面想。所以，穆宁并没按照规定，交由司法部门去处罚薛彦伟，而是自己把他直接打死，从而和他划清政治界限。穆宁让自己顺利摆脱了，下属的政治错误带来的牵连。
