# 权谋家眼里的标配女人拥有这三点素质！

【出处】《资治通鉴》第218卷 唐纪34

【原文】张良娣性巧慧，能得上意，从上来朔方。时从兵单寡，良娣每寝，常居上前。上曰：“御寇非妇人所能。”良娣曰：“苍猝之际，妾以身当之，殿下可从后逸去。”至灵武，产子；三日起，缝战士衣。上止之，对曰：“此非妾自养之时。”上以是益怜之。

【译文】张良娣性情乖巧聪明，善于讨唐肃宗的欢心，所以跟随唐肃宗来到朔方。当时保卫唐肃宗的兵力不多，张良娣每当睡觉时，总是睡在唐肃宗的外面。唐肃宗说：“抵御敌寇不是妇人的事情。”张良娣却说：“如果发生了意外的事情，我可先用身体抵挡一阵，以便殿下能够从后面逃走。”到了灵武，张良娣生了一个孩子，三天后就起来为战士们缝补衣服。唐肃宗阻止她，她说：“现在不是我修养身体的时候。”因此唐肃宗对她更加怜爱。

【解析】安史之乱起，唐肃宗李亨在灵武即位。尊父亲玄宗为太上皇，他命郭子仪与李光弼等讨安史，先后于至德二载六月和十月收复长安、洛阳两京。这样一个逆境中崛起的权谋家，却被一个小女人打动，最终这个小女人被封为皇后。作为权谋家在众多女人的选择中，选择张良娣作为自己的皇后，她体现出什么特质呢？

# 1、重感情

可以说唐肃宗李亨在安史之乱开始的时候是人生的最低点，身边众多的女人，要么逃走，要么分手，内心最为感叹的就是世态炎凉。而这时候张良娣不离不弃的陪在身边，这给了一个逆境中的男人最大的心理慰藉。无论多高的职位，事业低潮时，都希望身边的女人给自己支持，这种患难与共的行为，都会让男人从内心去尊重她。张良娣每天陪在唐肃宗身边，有人会说，那是张良娣没的选，其实能够嫁给皇室的女人，有几个背景差的，都是娇生惯养长大的，有几个愿意赌政治风险？
