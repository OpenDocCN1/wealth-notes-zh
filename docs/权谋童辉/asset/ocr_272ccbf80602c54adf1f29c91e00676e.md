# 夺权式创业——之前的三大准备工作！

【出处】《资治通鉴》第 99 卷 晋纪 21

【原文】初，闵之为赵相也，悉数仓库以树私恩，与羌、胡相攻，无月不战。赵所徙青、雍、幽、荆四州之民及氐、羌、胡、蛮数百万口，以赵法禁不行，各还本土；道路交错，互相杀掠，其能达者什有二、三。中原大乱，因以饥疫，人相食，无复耕者。

【译文】当初，冉闵任后赵国丞相的时候，把国家仓库里的粮食财物品全部散发给人们，以此树立个人的恩誉，和羌族、胡族没有一个进行月不战。后赵国所迁徙来的青、雍、幽、荆四州的百姓，以及氐、羌、胡、蛮的数百万人，都因为后赵国不能执行法令，分别返回本土。但这些人流途交错，又互相掠夺残杀，最终能回到目的地的仅十之、二、三。中原地区大乱，因此导致了饥荒遍野，瘟疫流行，人相残食，再也没有人耕田种地了。

【解析】创业模式有很多种，可以说风险最小的，收益最高的就是夺权式的创业方式，可以说历史上几乎所有的政治家走的都是这样的路子。今天这段通鉴材料，就集中展示了，这种创业方法：

冉闵，东晋十六国时期，冉魏的创建人，本为汉人，但在他父亲冉良十二岁的时候，后赵明帝石勒打败陈午，俘虏了冉良，让石虎收养冉良为义子，这样冉闵就成了石虎的义孙。冉闵通过自己的一系列权谋手腕，最终灭了后赵，他为了自己的夺权，做了三大准备工作：

1、以树私恩

冉闵达到了丞相这个位置，获得一人之下万人之上的权力之后，有野心的人都会迈出职场的最后一步，那就是夺权，最终自己坐到老大的位置。这个第一步的准备工作就是假公济私，用别人的资源树立自己的私恩，只有这样才形成自己的号召力和实力，形成利益共同体。这样未来夺权的时候，拥有民心和嫡系，减少了外围舆论环境和内部人员的阻力。

2、无月不战

冉闵无月不战，找各种机会和借口战斗，这样做为未来夺权可以说奠定了最扎实的基础。首先是训练了队伍，通过不断的战争，筛选训练出精兵强将。其次是通过重用提拔，形成了和军队的战友关系，形成了战斗友谊，加强感情基础。最后是，只有通过劫掠才能快速的形成自己的经济基础，这可以说是积累资本最快的方式，不然不足以应付自己夺权开始时候的物质消耗。

3、法禁不行

冉闵以国家的名义，迁徙各类人口，后来又让他们各自返回，这样就造成了人员的动荡，又因为截杀，最终天下大乱。这里面的朝令夕改导致了法律和禁止性规定不被执行，一下子就失去了规则的严肃性，导致了社会混乱，这正是权谋家期待的局面，因为只有混乱的
