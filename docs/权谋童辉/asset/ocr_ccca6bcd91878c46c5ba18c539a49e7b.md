# 权谋家玩转亲情的套路！

【出处】《资治通鉴》第249卷 唐纪65

【原文】三月，敕先赐右卫大将军郑光郧县及云阳庄并免税役。中书门下奏，以为：“税役之法，天下皆同。陛下屡发德音，欲使中外画一，今独免郑光，似稍乖前意。事虽至细，系统则多。”敕曰：“朕以郑光元舅之尊贵，欲优异令免税役，初不细思。况亲戚之间，人所难议，卿等苟非爱我，岂进嘉言！庶事能尽如斯，天下何忧不理！有始有卒，当共守之。并依所奏。”

【译文】三月，唐宣宗下敕令原先赐给右卫大将军郑光郧县以及云阳的庄园一并免除税役。为此中书门下上奏，认为：“收取税役的法规，天下都应相同。您屡次发布德音，希望使中外法令齐整划一，今天唯独先免除郑光的税役，似乎与前面的意思稍有悖离。虽然这是一件很细微的事，但牵涉的问题却很多。”唐宣宗为此下敕宣称：“朕以为郑光皇帝元舅的尊贵身份，企图给他优异待遇，免除租税，起初没有细加思考。况且亲戚之间，正是人们难以议论的，你们如果不是热爱我，岂能向我进如此好的意见！其他一般性事务如果能这样，天下何忧不能治理！有始有终，君臣应当共同遵守。按照你们所奏请的去做。”

【解析】任何有权力的人，身边都有很多亲戚需要照顾，如何平衡规则与亲情之间的关系？面对亲情的请托，对于一心为公的人，直接拒绝，铁面无私；而对于满足私心的人，必然满足，徇私枉法。前者的结果是众叛亲离，孤身一人；后者是组织混乱，走向灭亡，而权谋家却要在这两者之间找到了平衡点。唐宣宗，号称小太宗的唐朝第16位皇帝。元舅郑光，也就是大舅舅郑光。他们之间的这段材料，集中体现了唐宣宗处理关系的艺术：

+   1、照顾亲情，直接下令给舅舅免除税役

如果舅舅主动要求免除自己的税役，而皇帝同意了，这时候，下面的群臣再反对，皇帝是十分没有面子的，而也是丧失权威的。舅舅也会心存怨恨，你做皇帝还斗不过群臣？你本身就不想给我这个待遇嘛。但是唐宣宗自己主动给舅舅待遇，被群臣阻止了，舅舅内心也是心怀感激的。不对舅舅好，会主动提出减除税役吗？主动，这个动作是关键性，体现了亲情。

+   2、接受谏言，唐宣宗表达自己遵守规则

面对唐宣宗直接下令给自己的舅舅免除税役，而中书门下，也就是宰相班子直接提出异议。这个很关键，不是某个人提出异议，而是整个班子集体，这样能够避免自己的舅舅怨恨某人，互相内斗而让皇帝为难，同时，皇帝也不会让某个人，获得进谏的美名，遭到群臣的妒忌。通过唐宣宗自己的一通表白，独自获得了历史的美名。而且保证组织合法运行，让舅舅无话可说。
