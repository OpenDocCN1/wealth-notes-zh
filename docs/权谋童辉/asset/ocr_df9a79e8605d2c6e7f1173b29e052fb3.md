# 这样提建议最令领导反感！

【出处】《资治通鉴》第 70 卷 魏纪 2

【原文】吴陆逊陈便宜，劝吴王以施德缓刑，宽赋息调。又云：“忠谠之言，不能极陈；求容小臣，数以利闻。”王报曰：“《书》载‘予违弼’，而云不敢极陈，何得为忠谏哉！”于是令有司尽写科条，使郎中褚遵资以就逊及诸葛瑾，意所不安，令损益之。

【译文】吴国陆逊对有利于国家的措施提出建议，劝吴王广施德政，缓和刑罚，放宽赋税，免征徭役。又说：“忠诚善良的建议，不能彻底向君王陈述；取悦君王的小臣，才反复以小利上奏。”回复说：“《尚书》上记载：‘我有错误，你要帮我改正’。你在信中不敢彻底陈述，怎么能称作忠心善良呢？”于是命令有关人员，将将要实施的条款拟好，派郎中令褚遵资（音“鸡”）带给陆逊和诸葛瑾，让他们对其中的不妥之处进行删改或增添。

【解析】这段通鉴材料，乍一看没有问题，君明臣贤，但是事实上，这背后，其实是一场激烈的名望争夺战，如果不是孙权对权力有极高的敏感度，巧妙的化险为夷，就会被陆逊表面的善意所蒙蔽，从而有可能失去政权。很多领导都是在这里犯了不可饶恕的错误。

# 1、陆逊的阴暗之处

陆逊在三国后期，夷陵之战中，以少胜多，打败了准备为关羽报仇的刘备。让其声名鹊起，建立了赫赫军功。作为一个军人，却提出了一个政治的建议，这就相当于把自己的手伸到了行政领域。一个有军队威望的人，还想谋取政治威望，这样的人，如果放纵下去，对孙权是何等的威胁，而且，提出的四条建议，施行德政、减缓刑罚、放宽税负、停止徭役，相当于卖好给大众，把孙权放在火上烤，同意了陆逊的建议，相当于自己损失，成就了他的威望，如果不同意，自己得罪了大众，成了听不进去意见的昏君。这个建议，让孙权非常的不舒服，但是又不能公开说，毕竟陆逊表面没错。

# 2、孙权的权力敏感

曹操评价过孙权“生子当如孙仲谋”仲谋是孙权的字。孙权不是一般人，对权力极为敏感，又精通权术手腕。于是抓住了陆逊的谦虚之词，进行敲打，做出臣子的职责就是为君王提供正确的建议，“你在信中不敢彻底陈述，怎么能称作忠心善良呢”。这里孙权展示了两点，一个是，提建议是你的职责，这说明，你不是为了老百姓，这是你的工作内容。第二是，你还不把话说完，有所保留，这说明你并没有完全的履行你的职责，你并不是个合格的臣子。这对陆逊整体上做了打压，让陆逊为百姓邀功的高大上形象，变成了，一个不太尽责的臣子形象，让陆逊谋取政治威望的目的没有达到。
