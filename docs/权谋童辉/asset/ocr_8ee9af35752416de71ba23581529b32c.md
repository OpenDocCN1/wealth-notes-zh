# 1、行贿上级

要不要担责，让谁担责，这是做领导的面对重大失败要考虑的问题，这时候，鲁炅作为最弱的节度使，最大的可能是由他来担责，所以他应该第一时间有这个判断，需要及时的拿出自己的钱财去中央跑路子，比如此时是大太监李辅国，立即重金结交，自己就能够不死。

# 2、打造联盟

失败又不是自己一个，九大节度使人人有份，这时候，离自己最近的，郭子仪，李光弼，都是唐朝中期的名将，这时候，鲁炅应该自己通过儿女婚姻，或是兄弟拜把，再或是金钱馈赕，立即打造和这群人的深度联盟，共损共荣，这样，集体担责就不会死了。

# 3、巩固势力

任何时候，有兵都是草头王，自己的部下既然劫掠，这时候就要散播虚假消息，说皇帝要追究责任，联合其他节度使，围剿士兵，这样所有的士兵就会恐慌，从而团结在自己的身边，再找个地方深度劫掠一番，这样就巩固了势力，能够独立造反了，或是投降史思明，也能不至于死。

# 三、职场深度启示

# 1、大家都犯错，可能你来担责

一群人犯错，在职场有时候不是集体担责，而是会选择最弱的下手，比如没有背景，没有特殊能力，性格柔弱等，天朝从来都是法不责众，而是杀鸡儆猴，自己没实力的时候，还是洁身自好，不然最后，自己会成为集体的牺牲品。

# 2、编织关系网，才能带来安全

人在组织力最重要的不是能力，而是关系，一个人的关系网有多大，决定了他的能量有多大，最好的就是和领导以及领导身边的人保持良好的信任和沟通关系，其次是和平级的人称兄道弟，这样能够互相照应，最差的就是利用下级的力量，拥兵自重。

# 3、自杀的选择，也是保全策略

现在的职场不用真的去自杀，可以辞职啊，主动辞职，也是保存颜面的方法，即使没有错，领导为了推卸责任，也会让人选择辞职，这时候，只要和领导私下谈判好，拿到高额的山偿金了就行了，杭州某互联网大公司，就有总经理贪腐被迫辞职的情况，这就是弃卒保车的自杀策略。

经过上述的分析，我们能够看出来，鲁炅表面是自杀了，史书里几十字就搞定了，但是这背后的操作和原因却不能不让我们深思，一定要加强自己的能力、势力和关系，这才是自己的永恒的保护伞，不然，有个什么风吹草动，最终还是弱者担责。
