# 谁弱谁死——官员自杀的背后算计！

【出处】《资治通鉴》第 221 卷 唐纪 37

【原文】九节度之溃于相州也，鲁灵所部兵剽掠尤甚，闻郭子仪退屯河上，李光弼还太原，灵惭惧，饮药而死。

【译文】九节度使兵败相州以后，鲁灵部下的士卒抢掠尤其厉害，得知郭子仪兵退到黄河岸边，李光弼回军太原，鲁灵惭愧害怕，饮毒药而死。

【解析】人最宝贵的是生命，生命对每个人只有一次，所以那些自杀的，尤其是官员自杀，放着高官厚禄的生活不过，选择自尽，让人感到匪夷所思，什么利益能够比自己的命更大呢？此材料中，鲁灵的自杀其实就是表象，因为真的历史不会告诉你这些背后的真相。安史之乱中，九大节度使，围攻安庆绪（安禄山的儿子）于邺城。史思明救援安庆绪，和九大节度使交战于相州，随后因为一场大风，官军溃散而败。即使鲁灵无法约束部下，自己也罪不至死啊。为什么自杀？因为原因是无法写到真实历史上的。

一、三大死亡原因：

1、政治淘汰

九大节度使围攻安庆绪，整体失败，狼狈不堪，这个涉及到政治颜面。必须有人站出来为失败担责，才能够压住舆论之口。战争中都有责任，这个无法追究，在溃逃的时候，都有劫掠，尽管都说，鲁灵最严重，其实，从郭子仪和李光弼立即站稳脚跟，能够看出来，鲁灵是节度使里力量最弱的，所以由他来承担责任。大家看到这里就该明白，政治这时候没精力追究对错，找个最弱的软柿子处理背锅就行了。

2、权力失控

如果我们站在权力角度来看，为什么别的组织劫掠轻微，而鲁灵的劫掠严重呢，这就是内部失控的原因，鲁灵自己已经无力对军队有强有力的控制。一个失控的军队，再加上劫掠而来的财富，这就让作为节度使的鲁灵彻底没有了话语权，唐朝中晚期的节度使被部下杀的比比皆是。失败后，没有实际权力的鲁灵，自己坐在火山口上，只能选择自己结束生命，才有尊严。

3、亲情压力

很多贪官在被朝廷步步紧逼的情况下，都会选择轻生，要么借口抑郁症，要么借口意外坠崖，要么故意开车事故。这其实都是一种两害相权取其轻的策略，自己奋斗了一辈子，转瞬间什么都没有，如果自己自杀，还能给自己的家人留下一部分，这时候，家庭的亲情压力，都会让他做出这样的选择。而自杀后，法律也就不会继续追究了，家人的这笔财富落袋为安。
