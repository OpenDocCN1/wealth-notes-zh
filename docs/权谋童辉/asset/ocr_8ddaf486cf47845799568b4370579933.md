# 给领导点烟的大学问！

【出处】《二号首长》第三部 第三章

【材料】方昌伦递了一支烟给唐小舟，唐小舟接过，方昌伦立即拿出打火机，给温瑞隆点
火。温瑞隆推了挡唐小舟，说：“先给首长点。”唐小舟说：“首长，你这是骂我啊。我是
什么首长？”说着，他从方昌伦手中接过打火机，主动给温瑞隆点。温瑞隆笑了笑，点了。
唐小舟又给方昌伦点，方昌伦一定不千，唐小舟便自己点了，再将打火机递给方昌伦。

【背景】唐小舟是省委书记赵德良的秘书，方昌伦是副省长温瑞隆的秘书。

【解析】官场中的等级和秩序不是只在工作中体现出来的，也会在交往的各种层面体现出
来。这个秩序的体现并不是冰冷的处理，而是隐藏在互相谦让的温情面纱之下。权谋网，
详细解析这点烟背后的官场原理：

+   1、方昌伦是副省长温瑞隆的秘书，选择给谁点烟，并不是个太难的抉择，必须第一时间给
自己的顶头上司去点烟。然后再给唐小舟，最后自己点上。这个顺序是没问题的，问题就
是谁来点是个大的问题。职场常见的问题就在这，这个事可以做，没多大的问题，但是谁
来做具有重大的政治意义了。不同人的身份做同样的事情，背后的味道不一样。
2、副省长温瑞隆在级别上远大于唐小舟，本应自己被直接点上烟就行了。唐小舟级别低但
是位置高，他是省委书记的秘书，号称二号首长，所以，在实际权力上高于温瑞隆。所以，
温瑞隆具有极高的政治智慧，不能得罪唐小舟，所以，他虚让了一下让先给唐小舟把烟点
上。这背后不是给唐小舟面子，而是给他背后的省委书记面子。
3、如果作为普通人，可能自己就接受了。不过唐小舟是政治动物，立即就明白，如果自己
这么接受，会表现出压温瑞隆半格。如果唐小舟推让温瑞隆先点上，这是平级的一个表现。
所以唐小舟，明白自己的等级，于是直接拿过火机，亲自给温瑞隆点上，这样自己就低了
半格。让温瑞隆觉得唐小舟很会办事，也符合彼此的身份。
4、唐小舟转身给方昌伦点烟，这个自然就是个虚假动作，方昌伦不可能会接受，因为唐小
舟比方昌伦位置和级别都高。如果自己这时候，把火机递过去，再让方昌伦给自己点上，
就显得做作了。于是自己把自己的烟点上，转手把火机就递给方昌伦，方昌伦自己把自己
的烟点上，这个点烟的退让过程完全的执行完毕。
5、温瑞隆更加不可能自己主动给唐小舟去点烟，这样是丢身份的事情，基本不可能发生。
如果方昌伦直接自己把自己的烟点上，把火机直接给唐小舟或是温瑞隆，也是忘记自己是
秘书的服务身份。而唐小舟如果事先没等方昌伦拿出火机，自己主动给温瑞隆点上，这是
个越位的行为，就是把方昌伦放了一个被无视的尴尬位置，相当于抢了他的活，也不行。
所以，在官场，看似一个简单的点烟过程，背后都充满着利害的计算，表达出每个人的位
置和素质。很多人想，这么复杂啊，让人家搞这么烧脑，其实官场处处都是考场，就会因
为一个小动作，被人家深度解读，让人家觉得你没有等级秩序感，立即就会被踢出局。因
此说，官场无小事，处处有学问，大家要细细揣摩！
