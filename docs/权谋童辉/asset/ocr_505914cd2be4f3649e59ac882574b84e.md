# 3、谎言是政治家的稳定手段

政治家撒谎是会伤害到自己的政治形象的，被人认为是小人，而丧失威信，无人追随。但
是为了稳定军心，人心，这一种情况下会被认为智慧的。比如曹操的望梅止渴，撒谎解
决缺水，导致人心不稳定问题，比如借用粮官人头，撒谎解决缺粮的不稳定问题。还有出
兵前，故意装神弄鬼，增加士气的问题。其实用在现在企业，公司危机没钱的时候，需要
找人假扮投资人来公司转一圈，签订意向投资书，让员工稳定下来，度过难关，不然立即
就崩盘，没机会撑过危机了。财务状况，在任何时候，都不能让员工知道。还有遭到诟病
的，慈禧太后用军费过六十大寿，其实也是这样稳定社会人心的政治意图。

经过上述的分析，我们能够学到。真相会让危机阶段的组织陷入混乱，从而丧失了最后尽
力一搏的机会，这时候，作为权谋家就必須立即制造谎言，给够美好前景，来稳定人心，
人心稳定之后，才有度过危机的可能。而且度过危机之后，这个善意的谎言是不被指责的。
如果自己不用，谎言稳定军人，说出真相，有可能会被小人所利用，兴风作浪，或是破罐
破摔，丧失斗志。但是如果不是危机阶段，不是人心问题，而是日常，小事，这样的谎言，
作为领导者尽可能不要说谎，不然就是自掘坟墓，大家切记。最后，自助者天助，刘秀到
了河边，就真的结冰了，人心也就是天意！
