# 职场最常见的五大冲突——不知不觉就会有的矛盾！

【出处】《宋史》第365卷 岳飞传

【原文】初，在诸将中年最少，以列校拔起，累立显功，世忠、俊不能平，飞屈己下之，幕中锐敏教勿苦降意。金人攻淮西，俊分地也，俊始不敢行，帅卒无功。飞闻命即行，遂解庐州围，帝授飞两镇节，俊益耻。杨么平，飞献俊、世忠楼船各一，兵械毕备，世忠大悦，俊反忌之。淮西之役，俊以前途粮乏诿飞，飞不为止。帝赐札谕，有曰：“转饷艰难，卿不复顾。”俊疑飞漏言，还朝，反倡言飞逗遛不进，以乏饷为辞。至视世忠军，俊知世忠忤桧，欲与分其背嵬军，飞议不肯，俊大不悦。及同行楚州，俊欲修城为备，曰：“当戮力以图恢复，岂可为退保计？”俊变色。

【译文】起初，岳飞在各位将领中年级最小，原本是列校的职位被提拔，但多次建立显赫的功绩。韩世忠、张俊不能平衡，岳飞对他们低调屈从，军中的精锐敏捷的士兵教导岳飞不要降心相从。金人进攻淮西，朝廷制定线路要求张俊出击，张俊不敢出兵，军队最后也没有功绩。岳飞接到命令即刻出兵，于是破解庐州的包围，皇帝授予岳飞两镇节度使之职。张俊更加感到耻辱。岳飞在平定杨么后献给了张俊和韩世忠楼船各一条，兵器都很全备，韩世忠十分喜悦，张俊反而妒忌岳飞。淮西的战役，张俊因为前线粮草紧缺而向岳飞求助，岳飞爽快地答应。皇帝赐给前线嘉奖令，上面写道“转借军饷艰难，你们不要再依赖朝廷了。”张俊怀疑是岳飞告密，返回朝廷时，反而说岳飞携带粮草逗留不前，用缺少军饷为说辞。张俊看中了韩世忠的军队，张俊知道韩世忠得罪了秦桧，想要与岳飞瓜分他的背嵬军。岳飞决议不肯，张俊十分不高兴。等到张俊与岳飞同行去楚州张俊想先修理楚州城池来增强守备，岳飞说：“应当合力来恢复中原，怎可以保全撤退设计。”张俊变了脸色。

【解析】在任何一个组织里，如果不惜权谋心理，任凭自己的性子来，你觉得，你做的对，其实你无形中就得罪了很多人，不知不觉中给自己树立了强大的敌人，而不自知。岳飞就是这样的人，他得罪张俊这个老领导的过程，就是一个无形中树敌的过程，而且得罪的非常全面，所有错误犯了一边。

# 1、派系冲突

岳飞作为组织里新兴的势力、少壮派的代表，自然和老领导这些既得利益的元老派是有冲突的。这种天然是派系冲突，很多时候是无法调和的。本身岳飞的崛起就导致了老领导的不满，自己谦退点还能缓和局面，但是总有人背后挑拔，“勿苦降意”让他更加强势一点，老领导自然很是不爽。

# 2、对错冲突

张俊自己犹豫不前，而让岳飞从容解决了庐州的包围，而且还平定了悍敌杨么。岳飞的成功，其实就是衬托了张俊的错误，而且岳飞的功劳越大，同等条件下的张俊就越是如不如人。
