# 权力决策者考虑的是势力平衡，而非事情对错！

【出处】《资治通鉴》第 211 卷 唐纪 27

【原文】京兆尹崔日知贪暴不法，御史大夫李杰将纠之，日知反构杰罪。十二月，侍御史杨珏廷奏曰：“若纠弹之司，使奸人得而恐，则御史台可废矣。”上遽命杰视事如故，贬日知为歙县丞。

【译文】京兆尹崔日知贪婪残暴，不守法度，御史大夫李杰准备检查他的恶行，崔日知却反诬李杰有罪。十二月，侍御史杨珏在朝廷上上奏玄宗说：“假如负责检察弹劾的部门，可以让奸邪之徒随意恐吓威胁，那么御史台也就应该撤销了”。唐玄宗马上下令李杰照常处理政务，并且将崔日知贬为歙县县丞。

【解析】京兆尹是首都最高行政长官，御使大夫相当于最高检察长，监察弹劾百官的。侍御史是御史大夫的副手！知道这些职务和身份，我们就能够明白这内部的权力斗争结构了。不玩虚的，先说结论：权力决策者，对于内部的争吵，不看是非对错，只看势力平衡！我们现在详细的通过这段材料给大家做出分析：

+   1、把人搞定了，事情就搞定了。

作为普通人面对别人的质疑和指责，第一时间就会做出辩解，围绕着事情本身来展开工作的。但是权谋家从来都是从人本身下手，从根本上解决问题。只要把人搞定了，事情就不是问题了。崔日知，面对指控，直接反咬一口，只要能扳倒御使大夫李杰，自己的事情就没人管了，也没人敢管了。攻击是最好的防守，这个原理不仅仅用在军事上，政治上同样有效。

+   2、不看当下，只谈未来的影响。

侍御史杨珏向唐玄宗上书，替自己的顶头上司辩护，没有在崔日知和李杰之间的对错做出是非的调查或是判断，而是从事情的后果影响下手续的。这一下子就说服了唐玄宗，原因有三点：首先，如果自己分析对错，相当于侵犯了权力的判断权。你杨珏是老几，由你来点评对错？其次，自己是御使大夫的下属，如果从事情下手，难免被人怀疑动机。最后，替唐玄宗算政治账，点醒了权力的敏感点。

+   3、政治是追求平衡，而非对错。

职场上，不能孤立的看待一件事情，每次斗争的背后，我们都要看到参与的势力和力量。为什么崔日知能够提前得知自己将被弹劾的消息，李杰自己没辩护，而是由自己的下属杨珏出面参与斗争，这背后都是一群势力。提前泄露消息给崔日知的是私人利益派系，而侍御史杨珏替顶头上司辩护，是为了职务利益派系。唐玄宗，不能打破政治平衡，所以没有处理对错，直接贬了崔日知。
