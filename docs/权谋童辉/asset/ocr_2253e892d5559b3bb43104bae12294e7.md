# 如何转换阵营，职场换队的背后门道！

【出处】《资治通鉴》第 250 卷 唐纪 66

【原文】贼别帅洪师简、许会能所部降，式曰：“汝降是也，当立效以自异。”使帅其徒为前锋，与贼战有功，乃奏以官。

【译文】裘甫手下的小头目洪师简、许会能率所部投降官军，王式说：“你们归降是好事，应当立功自效，以区别于贼寇。”于是让他们率领原先的部众充当先锋，与裘甫军作战，作战有功的，上奏朝廷授予官爵。

【解析】在职场有些派系是天然的，比如谁提拔的你？你是谁招聘进来的？你一直是谁的老部下？你和谁有私下的亲戚或是同学同乡关系？你和谁往来密切合作较多？等等，这都是常见的天然派系，一旦具备特征，你不认为是派系关系，别人眼里你也是派系，所以当你想换个领导跟随，你自己觉得没有什么，其实别人从内心并不信任你，认为你的示好不过是想打入内部的间谍。到时候，原有的派系抛弃你，而新的派系并没有接纳你，弄得两头不是人。从而失去了职场的派系支撑，成为人见人欺的墙头草。如何转换门庭呢？这时候就需要你拿出诚意，也就是投名状，才能赢得新团队的认可。通常有三种方法：

1、下策，献主

最能获得新主子的信任，表示自己切断之前的联系，必然是拿着原有主人的人头过来投降，是最合适的。不过这个后遗症最大，因为你能够出卖原有的主人，你也就可能出卖现在的主人。尽管你有一定的功劳，但是基本上在新的组织内，是很难获得信任的。不过卖主求荣的，基本上都是在斗争的最后阶段，胜负基本上没有悬念的时候，原有的部下就不再有信心追随，杀了原主人，不求显贵，只是为了切断原有的关系，保证自己的生存机会而已。

2、中策，献城

拿着原有上司的人头或是勒命出卖给新主子，在斗争的火热阶段，转换阵营，可以说，这是新领导最喜欢的做法，因为极强的后遗症，所以很少人选择。聪明点的，都会选择献城。每个领导都有自己的地盘，有自己的资源领域，这时候找机会把自己所管辖的业务或是资源，在原领导不知情的情况下，直接交付给新领导，这就是临阵倒戈。原有的主人还在，会对这种背叛咬牙切齿，可能伺机报复。新领导会得到你的资源注入而加大势力，从而获得胜利。

3、上策，献身
