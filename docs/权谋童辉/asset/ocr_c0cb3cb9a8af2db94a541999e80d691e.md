# 领导被骗该如何处理？一般人都会做错！

【出处】《资治通鉴》第 15 卷 汉纪 7

【原文】秋，九月，新垣平使人持玉杯上书阙下献之。平言上曰：“阙下有宝玉气来者。”已，视之，果有献玉杯者，刻曰“人主延寿”。平又言：“臣侯日再中。”居顷之，日却，复中。于是始更以十七年为元年，令天下大酺。平言曰：“周鼎亡在泗水中。今河决，通于泗，臣望东北汾阴有金宝气，意周鼎其出乎！兆见，不迎则不至。”于是上使修治庙汾阴南，临河，欲祠出周鼎。太宗孝文皇帝下后元年 冬，十月，人有上书告新垣平“所言皆诈也”；下吏治，诛夷平。是后，上亦怠于改正、服、鬼神之事，而渭阳、长门五帝，使祠官领，以时致礼，不往焉。

【译文】秋季，九月，新垣平指使人携带玉杯到皇宫门前上书，献给绘文帝。新垣平对文帝说：“宫门前有一股宝玉之气移来。”过了一会，前去查看，果然有人来献玉杯，杯上刻有“人主延寿”四字。新垣平又说：“我算出今天太阳将再次出现在中天。”过了一会，太阳向东退行，再次到达中天。于是，决定把文帝在位的第十七年改称为元年，并特许天下人聚会痛饮，以示庆贺。新垣平说：“周朝的大鼎沉没在泗水中。现在黄河决口，与泗水相连通，我看东北正对着汾阴有金宝之气，估计周鼎可能会出世吧！它的征兆已经出现了，如果不去迎接，周鼎是不会来的。”这个时候，文帝派人在汾阴修庙，南面靠岍近黄河，想要通过祭祀求得周鼎出世。后元年（戊寅，公元前 163 年）冬季，十月，有人向文帝上书，检举新垣平“所说的一切都是诈骗”，文帝命令司法官员审查，最后，新垣平被诛灭三族。从此之后，文帝对于改变历法、服色及祭祀鬼神的事，也就疏怠了，立于渭阳、长门的五帝庙，隶属于祠官管理，由祠官按照季节时令祭祀，文帝自己不再去了。

【解析】汉文帝被术士新垣平给骗了，汉文帝一怒之下通过司法机构诛灭了新垣平三族。

看起来坏人得到了惩罚，其实损失最大的还是汉文帝，自己的权力威望被削减，也导致了后期他只能远离各种鬼神祭祀这种事情，来减少大家对这件事情的记忆。汉文帝犯了一个经典的错误，他不清楚权力的威望比事实的对错更重要，权谋网详细的分析这背后的逻辑：

+   1、表面是检举，事实是争宠

新垣平通过手段快速的崛起，但是，一个人的快速崛起，必然会带来利益格局的变动，利益格局的变动之后，就会有既得利益的人群的损失。所以，这些损失的人群，必然在动机上就有主动攻击新垣平的欲望，于是新一轮的内斗开始。这其实已经不仅仅是新垣平的对错问题了，其实这就是变成了职场争宠的问题了。汉文帝不仅仅要考虑新垣平的处理问题，还要考虑职场势力的平衡问题。作为领导欣赏一个人，打击一个人，都必须首先考虑势力的平衡，不然，内斗就会不断给自己带来无穷麻烦。
