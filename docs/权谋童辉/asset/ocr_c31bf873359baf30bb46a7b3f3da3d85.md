# 领导说话必须模糊，让下属猜，这是权力的艺术！

【出处】《资治通鉴》第 24 卷 汉纪 16

【原文】初，许广汉女适皇曾孙，一岁，生子奭。数月，曾孙立为帝，许氏为婕妤。是时霍将军有小女与皇太后亲，公卿议更立皇后，皆心拟霍将军女，亦未有言。上乃诏求微时故剑。大臣知指，白立许婕妤为皇后。十一月，壬子，立皇后许氏。霍光以后父广汉刑人，不宜君国；岁馀，乃封为昌成君。

【译文】当初，许广汉的女儿嫁给皇曾孙刘病已，一年后生下一子，名叫刘奭。数月之后，刘病已即皇帝位，封许氏为婕妤。此时，霍光有一小女儿，与皇太后有亲属关系，所以公卿大臣商议立皇后，心中都认为应立霍光的女儿，但也没有明说。汉宣帝下诏寻找微贱时用的宝剑，大臣们懂得皇上的心意，便奏请立许为皇后。十一月壬子（十九日），许氏被立为皇后。霍光认为其父亲许广汉是受过刑的人，不宜做封国的国君。一年多以后，才封许广汉为昌成君。

【解析】稍微懂点权谋的人都知道，领导的意图需要揣摩，领导不会明确的告诉你他内心的想法，一来领导怕担责任，二来领导怕没人支持丢面子，三是试探谁最听话好用。而如果站在领导自己的角度，在权力弱势的时候，也是不能够直接表达自己的权力意志，需要通过模糊的话语表达自己的意图，这也主要是三大方面的原因：

+   1、试探各方势力的态度

刘病已就是汉宣帝，被霍光扶植上位。这位从民间崛起的皇帝，本身并没有多大的实权。想立自己的原配当皇后，并不是一个简单的事情，毕竟皇后的位置，不仅仅是个原配婚姻的问题，而是一个后宫势力，外戚利益划分的问题。所以，汉宣帝想立原配许广汉女儿这个糟糠之妻为皇后，就不能不试探各方的态度。于是让寻找微贱时侯用的宝剑，来表明自己不忘旧情。用类似的事情来试探各方态度，相当于投石问路，看看能不能推进。对于汉宣帝而言，以及各方大臣势力，其实都很清楚皇后的分量。所以，汉宣帝把许广汉的女儿立为婕妤，把皇后的位置悬空。如果大家同意了，这个位置就许婕妤，如果大家势力平衡，那就继续搁置悬空，如果失败，那就立霍光的女儿。

+   2、可进退让权力不尴尬

空缺的这皇后的位置，其实是汉宣帝的一手妙棋，挑动了霍光和别人的矛盾。因为这个位置不仅仅意味着后宫谁说了算的问题，还意味着着一方外戚势力的崛起。皇后这个位置是一个巨大的诱饵，汉宣帝抛出这个诱饵，就能够搅动当时西汉的朝堂。因为各个势力都暗流涌动，都不想让大家做大。尤其是霍光已经很大了，而如果继续让霍光的女儿成为皇后，继续做大，独霸朝廷和后宫，其他的宗族，大臣的势力是不愿意看到的。所以，大家都会出现支持汉宣帝，而这无形中就是和霍光的利益对立起来了。霍光和其他的势力因为立皇
