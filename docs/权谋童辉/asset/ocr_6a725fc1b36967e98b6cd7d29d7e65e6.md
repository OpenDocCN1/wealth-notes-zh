# 三、事情背后有两个原因

# 1、内部原因，高颍不懂权力心思

经过上述的分析，貌似只要反对领导的既定决策，自己怎么做都是错，而且别人做，自己同样会受到打击和猜忌。其实核心就是高颍未能及时认识到，反对决策，就是对抗权力。

# 2、外部原因，高颍得罪独孤皇后

当然，这一切背后最为核心的的是独孤皇后的谗言。隋文帝和独孤皇后吵架的时候，高颍为了劝解隋文帝曾经说了独孤皇后几句，就被独孤皇后怀恨在心。疏不间亲，得罪女人，职场大忌。

那么很多人会问，已经反对领导决策了，自己该怎么做呢？正确的答案什么呢？分两种情况，一种是，自己执行呢，就一定要努力做成，做成之后，立即上表夸赞皇帝的英明。如果真的打不赢，自己也要故意负伤，来个苦肉计，说明自己真的是尽力了。另外一种是，如果别人来执行决策，别人赢了，不要等等他邀功，自己一定第一时间，上表赞美皇帝的英明，自己的错误。这样让执行人的功劳，成为皇帝的功劳，自己不会接下来被对比，从而大范围丧失好印象。如果执行人失败了，这时候，千万不能有骄傲神色，而是要说自己是乌鸦嘴。是不是感觉很复杂，对了，所以，擦屁股的事情总是很难办，因此，只要我们记住这个基本权谋原理，就不会这么麻烦了，那就是，只要领导决定的事情，坚决的拥护和执行，不管事情上的对错，关键是权力上的必须顺从！
