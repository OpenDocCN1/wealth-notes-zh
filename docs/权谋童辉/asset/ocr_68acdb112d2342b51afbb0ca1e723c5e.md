# 中国式惩罚背后规则——必须考虑面子！

【出处】《资治通鉴》第101卷 晋纪23

【原文】恪虽综大任，而朝廷之礼，兢兢严谨，每事必与司徒评议之，未尝专决。虚心待士，谘询善道，量才授任，人不逾位；官属、朝臣或有过失，不显其状，随宜他叙，不令失伦，唯以此为贬；时人以是大愧，莫敢犯者。或有小过，自相责曰：“尔复欲望宰公迁官邪！”

【译文】前燕慕容恪虽然总揽大权，然而对于朝廷的礼法，小心谨慎，严加遵守，每件事情都要和司徒慕容评商议，从来不独断专行。虚心对待读书人，向他们征求治国良策，根据才能授予官职，使人们各居其位。官属、朝臣如果出现过失，也不公开宣布，只是根据情况加以调动，并且不让他们失去原来的等级次第，仅以此表示贬责。当时的人都以受到这样的处置为大愧，没有人敢轻易触犯。有人出现小过失，也都自己互相责备说：“你又想让宰公慕容恪调动你的官职啦！

【解析】“有法可依，有法必依，执法必严，违法必究。”这就是中国的执法理念，这无论对国家，还是对一个政权，再或者是一个组织，都应该遵守这样的游戏规则。但是实际上，中国从来都不是一个法律社会，执法的刚性和人情面子相违背的，刚要处理事情，一大堆的讲情电话就进来了。中国式领导有自己的处理规则，通过这个例子来给大家解析下，中国传统的处罚方式：

+   1、执法困境

政府、国企或是大型的民营企业都是如此，面对跟随之了很多年的员工，如果他们犯了错之后，依法处罚，功过分明的话，觉得组织很没有人情味，很快自己就会被这些人所抵制，会给组织带来更大的破坏力，更多时候，不仅仅是领导没有人事权力，即使有立即处理人的权力，都要顾及这个人背后的势力和这个人的破坏力。因此，中国领导处理人的时候，不能够就事论事！

+   2、处理方法

所以中国式的领导都采用了和慕容恪一样的策略，“不显其状，随宜他叙，不令失伦。”首先是不公开这个错误，中国的事情，就怕拿到桌面上，如果公开了，不处理，规则形同虚设，组织不就乱了？所以，不公开，怎么处理都行；其次，既然不公开，就无法援引相应的条款处罚，只能通过调整工作，来处理，中国常用的手法，就是边缘化、孤立化、冷淡化；最后就是工资待遇不变，让其没大损失。

+   3、背后原理

为什么对于犯错的人，这样处理？而且还成了中国几千年来的潜规则，原因就是，极大程度的照顾了犯错人的面子，中国人一旦丢失了面子，非鱼死网破不可。尤其是对高层的人
