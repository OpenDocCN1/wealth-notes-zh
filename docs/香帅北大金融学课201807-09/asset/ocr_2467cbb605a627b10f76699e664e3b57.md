# 第一天：噪音交易者：散户的悲剧指标

第一天，我讲解的是噪音交易者风险这个概念。噪音交易者这个概念是针对传统的理性人资产定价模型的一种思考，它指出市场上存在着大量的缺乏真正全面信息的交易者，这些投资者对交易价格的认知是有偏差的，所以他们的交易行为中，包含着不能被互相抵消的噪音。
