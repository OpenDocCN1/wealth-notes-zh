# 147 | 普通股投资者，怎么择时？

你好，欢迎来到高帅的北大金融党课。

今天我们接着昨天讨论的内容，继续给你分享“择时”的这个话题。

市场上有一种观点认为，我是价值投资者，看的是长期价值，所以我并不需要择时。

其实，全世界最坚定的价值投资者——巴菲特，他其实最擅长的是高手，你猜猜看，巴菲特一辈子收益最高的时候是什么时候？很多人没有想到，是2008年金融危机之后。当时金融危机的消息，和股四化，因为巴菲特的公司现金流一直控制得极严，他的安全线是账上有200亿美金，底底线是要全100亿美金的流动资金。在那个时候，只有他，所以完美地抄底。在接下来几个月之内他就赚了700多亿美金，差不多占了巴菲特一生赚的20%。

所以你看，即使是最坚定的价值投资者，也需要选择合适的时间入场和离场。

实际上在股票投资上，最重要的两种能力，一个是选股，第二个是择时。

关于选股，在前面课程里面我们讲得很多了，我们可以寻找那些基本面很好的，价格低于价值的股票，也可以选择小盘股或者现金流特别稳定的低估值。

昨天，我们讲的是择时能力是不是存在与否的辩论。很明显，正确地来择时，对投资者而言确实是有巨大风险的。昨天我们也知道，正确择时并不只是那么容易的事情。所以今天，我要从大盘和行业两个维度，来给你说说，我们普通股投资者择时的原则。

# 一、大盘上的择时

首先我们来看，在大盘上怎么择时。

在理性预期的框架底下，我们的投资决策应该是对未来的不断更新，但决策是判断是未来是怎么呢？其实肯定是从历史数据，或者是从历史经验里面学的。你说一下我们从历史经验里面的一个投资决定是怎么做的，是不是根据历史记录来的。

这是非常典型的直线思维：在股市上涨的时候，我们普通人的投资意愿就变强，如果股市低迷了，投资者就倾向于卖出，不再进行投资，或者赶紧离场。

在2013年，我记得，一个财经电台的编导曾经做过一个数据，他有个研究，他统计了每周新开入数，非常关键，一周股票上涨多，下周一周开户的人数就越多，股票越涨，开户的人数就越大；要是股票越跌，新开户的人数立马下降。

这个规律不仅在中国，美国也一样。所以说，根据历史回报来决策我们的资金投入情况，也是人性的天性。

那么这样做成对不对呢？有一个美国很有名的机构投资者，他做了去，去研究了一下，他把1871到2001年的标普年份回报率都拿出来做个研究，回报率最高的就是牛市，回报率最低的就是熊市。

他发现，和中国的经验一样，美国人也都关注在大牛市之买入。但是，如果聪明的人，会在熊市之后入市的话，他，这些人的收益会高到很多人。这100多年的数据记录，在熊市以及熊市下一年入市的，比大牛市之后买的人收益率高了整整一倍。

这个研究出来之后，就受到不少人的攻击，他们说，1871年那时期到50年代，美国市场到50年代以后才逐渐走上正轨的。

研究者又去重新验证了一下，他发现，不管是从1945年开始，还是从1871年开始，这个结论都是成立的，熊市之后场比牛市之入场的收益率要来得高。

有的同学说，我长线投资，风物长宜放眼量，哪点上大入场没关系，这个研究告诉你，还真不是这么回事。

在熊市之后，启动长线投资，平均每年比牛市中启动投资要高两个百分点，如果高两个百分点，复利10年，在其他条件都一样的情况下，两者之间的收益差距能达到22%，而不是一点点的差距。

所以，普通股在大盘上择时的第一条原则：在熊市之后入市。

在巴菲特的一本书里面，他就这样说，为什么熊市的时候我们要去观察？对我们来讲，我看到遍地黄金的机会。
