# # 142 | “聪明钱”：与泡沫同在

你好，欢迎来到翁彤北师大金融课。

昨天我们讲了噪音交易者，这是一个很让人沮丧的词语，你想想，很多投资者是没有什么事情的交易者，所以我们的交易在市场上占得价格里，可能是噪音，大家在市场上“博傻”。

今天要给你接着讲一个金融术语，这个术语讲上去比较令人愉快，叫Smart Money Effect，网络有人把它翻译成“聪明钱”，说的是很多交易者非常聪明，聪明之处就在于他们在市场上有很多不具备完全信息的人，会坐下来跟他们一起玩交易，博取最大利益。

要讲清楚这个问题，我们从一个著名的金融研究说起。

# ## 一、Smart Money Effect

你一定知道，上个世纪末是美国高科技泡沫最厉害的时候，所以那个时候有很多对冲基金特别牛，一直到最后泡沫破灭留下了一地鸡毛。

芝加哥大学有一个非常牛的教授，叫Brunnermeier，他非常好奇一件事情，既然大家都对他们冲昏头是一场超级聪明的，而且他们一天到地都在研究信息，从数据本身，难道在泡沫那么严重的情况下，就没有人意识到泡沫的存在吗？

他带着这个问题，我就去研究，找到了53个很大的对冲基金，在1998年到2000年间的股票持仓的数据，然后他发现在一个非常有意思的现象，对冲基金在当大童大量持有高科技公司的股票，在泡沫中途，也就是1999年的时候，他们曾经减持过，但是不久之后又马上大量增持，比如在1999年的时候，索罗斯旗下量子基金的首席投资官就公开说，互联网的泡沫太厉害可，马上就要破裂了，但是在不久之后，他已发现，这个泡沫很坚硬，没有破，于是他立马反手做多，大量增持了高科技股。

事实上，这个决定是对的，从1999年9月到2000年7月，在不到半年的时间里，新斯达这笔交易在高科技公司上的收益率超过100%，就是说这个基金在不到半年的时间里赚了100以上的利润。

其它的对冲基金也差不多，1999年的时候，基金经理们就一直嚷着泡沫太大，身体却很诚诚，不断地去高高科技概念股票。这些基金，大量资金的涌入，也就助推了当时高科技泡沫的不断扩大。

更有意思的是，Brunnermeier还发现，很多基金经理在2000年3月的时候，又开始减持有科技公司的股票，而高科技泡沫破灭在什么时候呢？就是在两个月以后，也就是2000年的5月。

这个研究证明了什么呢？证明了在泡沫期间，很多机构投资者并不是不知道泡沫的存在，但是他们没有选择离开，而是决定“ride with the bubble”，中文翻译就“骑乘泡沫”，也就是和泡沫共存一段时间。
