# 134 | 杰西·利弗莫尔：投机之王

你好，欢迎来到泰勒的北大金融课。

在这节课前，我要先宣布一个消息，咱们专栏的订阅人数突破15万了。这意味着有15万的同学和你一起踏入金融金局的乐章，有15万人和你一起站在“站在高处，重新理解财富”的这条路上。这对我来说是一件很快乐的事情，为了庆祝这件事，从今天开始，在接下来的6周里面，我要推出一个“投资大师顶级智库”，在每周四的延展话题里，给你们讲一位大师的投资哲学。谢过这些站在高处，重新理解这些大师的智慧。

这6个人分别是杰西·利弗莫尔、威廉·江恩、查理·芒格、巴菲、索罗斯、彼得·林奇、基米上原本过去一百多年资本市场中几次波澜的顶尖老手。谢过分析这些顶级高手，你会发现一些有趣的现象，比如说为什么在过去一百年中，最顶尖的投资者都是美国人？为什么利弗莫尔和江恩，虽然趋势见长，更注重短期投资？而巴菲、查理、彼得·林奇更注重价值投资？像索罗斯、彼得·林奇的投资哲学就是追求变化。这些大师的投资大们，他们的特性都是偶然的吗？

在准备录制这个系列课程的时候，我自己在感觉也很奇妙。当这些形象都成一条线以后，你会发现，很多以利得略、零散的知识瞬间就点亮了。我尽量把我看到的那种博然感讲给你。也希望你能看到对我提出的这些问题，和我一起开始这6周的顶级智慧之旅。

今天我要从一个被称为最传奇、最炫目，也是最聪明的交易大师开始。他的名字叫杰西，利弗莫尔。

即便你不知道这个名字，对股市略有了解的同学都应该听说过一本书叫《股票大作手回忆录》。这本书就是讲述利弗莫尔交易思想的。巴菲特说过，读得多的投资者，已见得够多的书还没做过交易，你想要在股市上盈利，基本等于空谈。

那么利弗莫尔最了不起的地方在哪里呢？很多人都会津津乐道的是市场上四处四查的传言，其实这些事迹都是表象。

对于金融交易行业的人来说，利弗莫尔最了不起的地方在于：第一，利弗莫尔是一个奠基交易的人，他是第一个把短线成为交易规律的交易员，在他的手里，这些零散的交易规则被结构化，形成了一个一套行之有效的交易系统。第二，他的一个远法超越他所在的时代的伟大交易。他是一个方法穿越了近百年的市场波动，至今仍显然是华尔街，甚至是学术圈最重要的思想来源。
