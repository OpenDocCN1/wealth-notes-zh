# 曾茜茜

老师，您好！请问，顺周期和逆周期的企业的关系是什么？还有它们和经济周期的关系是什么？是否是有对应的？

这个问题很有代表性，以前的课程里也有人问过，所以我来给你整体地做一次回答。

# 1.顺/逆周期的概念

我们先看一下概念。所谓顺周期、逆周期，就是指一个企业，或者一个经济周期的不同阶段的状态。如果是经济环境好的时候，一个行业的表现也会好，那就是顺周期。反之，就是逆周期。

还有一些行业在经济周期的不同阶段，表现出不一样，就叫无周期，或者抗周期，意思是，经济不好的时候，你至少可以不受损，可以抵御经济周期。

# 2.哪些行业是顺/逆周期？

我们再来看看什么是行业是顺周期、逆周期和无周期。

先说顺周期，在我们国家，银行、地产、建材、基建，这些都是明显的顺周期行业。为什么呢？你看，这和国家处在一个经济高速增长期，和我们的经济发展的模式是有关联的。

这些年，你肯定知道，我们国家经济增速一直很高，高在哪里呢？高在投资上。投资的主力是什么？经济好，不管是贷款，都是投资的主力。所以经济好的时候，投资速度就快，那这些行业，地产、基建、包括相关的建材、工程机械、装修家电等等，都非常好，这个行业就是顺周期的。

而且这个顺周期里会有好处。为什么呢？因为经济好的时候，大家都愿意贷款，然后大家都赚钱，坏账也少，所以银行的业绩也会很好，环境比较好。而投资的时候，往往是经济不好调经济形势不佳，往往是逆周期调控，或者投资了，要往下压一压，也就是在投资。压投资的时候，这些行业也就会表现比较强烈了。主要的是房地产和基建。要刺激经济，主要也是房地产和基建。

所以，地产、基建相关的行业，如果一压就会被压下去。

同样地，银行也会受到牵连。因为一宏观调控，贷款的总量就会下降，坏账也会增加。而且银行的杠杆率很高，一旦出现环境，影响就会很大。所以你看，宏观调控的时候，往往是银行出现问题的时候。比如1998年，再比如最近的这几年。

好，刚才说的是顺周期行业，那些是逆周期行业呢？

其实严格意义上说，没有逆周期行业。为什么呢？因为经济不好的时候，就会“镰刀之下，没有完卵”，所有行业都会受影响，所有行业都联系在一起。

但是，在经济不好的时候，有些行业受影响就比较小，比如教育、医疗、娱乐。一般人的说法是，经济不好的时候，大家也学不看什么，不能不上学，而家里有交不起的时候，经济也不好，成人教育、培训反而会很多。

而且形势不好的时候，大家时间多，心情郁闷，多有一些时间去娱乐。所以，娱乐行业会好一点。

经济学上还有一个名词叫做“口红经济”。也是指经济不好的时候，大家都没有钱去买很多昂贵的东西，像口红这样的小买消费品，能满足一下女孩子的这种消费心理，所以这个时候销量会更好。

这些说法有没有道理？还是有点道理。但是，我觉得要更多地还是取一些明显抗周期的说法，因为它们抗性强还是不明显，比如还存在其它可能性，经济不好的时候，收入紧张，就可以增加工作时间，或者打两份工，其实并没有太多时间去娱乐。

所以，这些行业叫抗周期行业可能会更好一点，就是说经济不好时候会下跌，但是程度上比那种有直接的投资相关的行业，像地产、基建会好一点。

关于顺周期和逆周期，还要注意的是，这些行业的特点可能会变化。比如前些年家电是顺周期行业，是因为当时老百姓买的是顺周期，买了新房子也要买家电。未来不一定是这样，因为大家的家电不一定时刻刻成倍，而新房销售逐步饱和了，家电变成了普通消费品，所以周期属性会慢慢变弱。

# 荣磊的小小

美国现行的证券法有一条这样的规定，当一家公司的股东超过500名并且资产超过一定规模后，即使它不上市也必须在第2年的100公告与财务状况的这美国家规定中有没有类似的老师？

这个问题也是很有趣的。它涉及到一个很深层的问题，是不是上市公司不需要披露对支持的理由？对这个信息，其实上文支持的理由很简单，支持方向，不上市是私人公司，没有大量分散的股东，是不是应该披露财务信息的，这是属于个人的商业机密和隐私。而另一方则说，公司到了一定的规模，就不完全是私人公司，涉及到员工、贷款人多方面的利益，所以你就要被披露信息。

# 1.美国情况

好，那具体到美国，在1964年的时候，美国证券局就颁布了修正案，增加了12（g）这一条。它规定，资产总额超过1000万美元，而且股东人数在500名以上而非上市公司，要向美国证券局登记。

并在财务年度结束后的120天之内，要公开财务信息。

这个法案定的初衷是解决OTC市场上的欺诈行为，保护投资者利益。

但是后来，随着科技行业的发展，像谷歌、Facebook这种快速增长的科技公司大量出现，这种企业红融资就很快，就像容易触及500人的红线，但是又不希望被披露财务信息。这条律例例使得这些公司被迫通过换股的方式来并股，或者说公司不愿意给员工发放股票期权，这样会影响公司的发展。

在这样的一个背景下，2012年，美国通过了乔布斯法案，把信息披露的要求放宽至资产总额超过1000万美元，且股东人数在2000名以上，才要履行了披露的义务。

但像谷歌、Facebook这样的企业，门实在是太大了，2000名股东这条也会很快触及，而后，资产的红线上升得其实会太快，最后被废止。

监管这个事其实一定是个硬币的两面，有天使的一面，也会有魔鬼的一面。因为你会鼓励增加新企业的营，另一方面一定程度的增加企业的经营，而另一方面又会增加信息透明度，对市场秩序也有一定的好处。

还是对原来来说的，这种合规使用简单的标准，对我们来评价，只能说是很粗放的发展，根据行业的不同，可能要做一些调整。
