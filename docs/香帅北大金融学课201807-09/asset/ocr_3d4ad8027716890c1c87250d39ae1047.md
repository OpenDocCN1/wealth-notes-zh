# 183 | IPO抑价之谜：股票“打折”背后

你好，欢迎来到老师的大金融课。

咱们中国股民里，十个人估计有八个人进行过IPO打新。打新就是你去申购新股，如果中签的话，就可以用发行价买到即将上市的股票。

我们之前分析过，由于中国股大的一些制因素，所以从概率上来讲，目前A股的IPO打新是一个稳赚不赔、甚至是大概不赔的生意。

你会有一种感觉，这是我国股市的特殊情况。

但其实，在全世界范围内，IPO打新都是一件比较赚钱的事情。

这很奇怪了，美股上并没有我们这样限制打新的政策。为什么也会出现这样明显的赚钱买卖呢？

这就是这里我想跟你讲的，排除制度方面的原因，IPO这么高的收益率到底是哪来的？

# 一、IPO抑价之谜

好，首先我们来看一看，全球范围内，IPO的收益率到底如何。

美国有一个著名的学者叫杰夫·瑞格，他做了一个研究，他发现1980年到2001年间，美国有6000多个IPO，上一年度平均的收益率比发行价格高了12%，而同期大盘的年收益率也就7%到8%左右。

学过我之前课程的同学知道啊，一天2%的收益率，是个天文数字啊。你要知道，一个金融资产的期望回报率，应该是跟整个市场的资金水平差不太多的。

比如中国，2018年，银行理财产品的年化收益率大概是4%、5%，银行有什么年化收益率超过10%的金融产品，都是非常罕见的，所以老师老提醒大家要注意风险。

IPO这么高的收益率，在美国保持了长达20多年。不管是是收益率的角度，还是从我们之前讲的有效市场的角度来看，这都不太可理解。

为什么打新收益这么高呢？如果我们换个角度想，或许能找到答案。

我们有一个通俗的解释，就是股票买卖其实是分批发市场和零售市场的。我们散户都是在零售市场（二级市场）上交易，我们的价格是零售价格（市场价）。

但是，如果打新中签的话，实际上就是让你批发市场（一级市场）的批发价去买一些股票。

一般来说，批发价比零售价要低，零售价和批发价中间的差额就是你的打新收益了。

换句话说，IPO收益率如此之高，很可能不是因为这只股票上市之后有多么看好，而是因为这一个开始的批发价，也就是发行价是被压低了。

令人费解的现象称为“IPO抑价之谜”，IPO Underpricing Puzzle，也就是说发行价格是被抑制了。

针对这个全球性的金融谜题，学者们提出了很多有趣的理论解释。下面给你介绍两个：一个叫“赢家诅咒”，一个叫“信息披露”。听完这两个理论，你可能就能明白，为什么IPO的发行价会被抑制。

# 二、赢家诅咒

先说赢家诅咒。它原来是在拍卖中最后赢得拍卖的人是个会亏的。因为拍品的价值确定的，然后一个人可能拍品是多少钱，就高了去买了超过这个物品价值的标准，所以最后要么会亏钱，要么会赔了，其实是诅咒。

最先用这个理论解释IPO抑价现象的是一个叫Roger L. Loughran的人。1988年，他就指出IPO的收益是由于一个理论效应，这个理论就是，IPO是两种人：一种人是有信息优势的机构投资人，还有一种是散户。对于某个企业的内部市场，我们都知道，我们散户就处于信息劣势。

但是有信息优势，并不意味着我们是傻瓜，我们只是根据市场信号进行分析和推算。比如说现在一个股票要上市了，按照未来现金流折算，这个企业的内在价值大概是20块钱。但是按这个价值，我们投资人是买不到的，所以我们会根据市场情况来看。

假设发行价定得比内在价值20要高，那我们就放弃了。但机构，他们并不买这些有信息优势，买到过高价股票的机构，而买到低价股票的人就会新。这产生了一种诅咒，即会亏损。

好了，这种情形就产生了一个悖论。凡是有信息优势的新股都投，不值这个价格。那买了新股的人，就会纷纷退出这个市场，就会导致IPO的发行流平。

怎么解决这个问题呢？就是这个股票的一定价要低于均价格格，所以只要买到这个新股，就能赚到钱。

用金融术语来讲，就是把IPO的发行价格压低，等到我们那些处于信息劣质的投资者进行一定的风险补偿。那样子，投资者就不会都退出市场了。IPO也就会产了。

# 三、信息披露

好了，赢家诅咒这个理论在80年代的时候影响很大。到90年代的时候，耶鲁大学的学者艾琳·辛克斯提出了一个关于信息披露的理论，叫“信息披露理论”。

我们在前面课程上讲跟风行为的时候也讲过这个理论，艾琳·辛克斯就用这个理论重新解释了IPO的情况。

他说，在IPO的认购中，大家都不是集体行动，而是有先有后。对不对？像我们这种没有信息优势的散户，一般排在这个队伍的最后面。所以，前面人的行动会影响我们的决策形成。

你想，如果前面认购的人特别多，那就会产生一个强烈的正面信号，让后面决策的投资者都会认为，这样，一层一层地往下传，整个IPO的发行就会顺利地消失，会很容易有一个完美的发行。

反过来说，要是初期认购的人不多，那我们这些后面对的人负面信息就越多，越多，希望去认购的人就会越来越少，最后就稀拉，最后流平，造成IPO的流平。

其实我想这个事，你平时出去吃饭的时候，就会特别容易理解。两个点铺摊都整着，门口冷落的容易越来越冷，而门庭若市的那个越来越火爆。

好了，在IPO市场上为了避免IPO的发行流平，有时候发行人和承销商一般会折价，去吸引那些最初投资者。这就是IPO发行打新的原因。

这两个理论你听完之后，应该会有一个感觉，就是往上走的信号不一样，但其实是一回事。IPO的折价是投资者对信息的不确定性，不过和赢家诅咒更加强调的是不同公司的信息不对称，而信息披露强调的是公司间和信息不对称的关系，但是都强调，IPO市场上巨大的信息不对称才是一种折价的原因。

根据这些理论，我们也可以得出结论，信息不对称性越大，IPO IPO越大，它的折价就越大。很多实证证据显示，那些行业更新、现金流高、越不确定的企业，发行价和市场价中间的差就可能会更大。

另外，中国的IPO市场，除了前面课程讲到的制度性的折价以外，中国市场的信息不对称也更大，所以会比美国有更大的IPO打新收益。

好了，这节课到这里就结束了。你可能已经知道了，自己的IPO打新收益高，其实是IPO Underpricing，IPO抑价。

但是，事情真的这么简单吗？比如杰夫·瑞格还发现，其实还有30%的公司，第一天的收益率和发行价是一样的。甚至，发行价还要低。这种上市价格比发行价还低的情况叫做破发。像小米、爱奇艺，好多企业都发破发。
