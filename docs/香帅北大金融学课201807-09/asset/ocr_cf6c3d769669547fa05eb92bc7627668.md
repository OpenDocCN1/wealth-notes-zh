做大做强。但是，你也要看到，形成了内部融资市场以后，很容易就产生了控股的集团公司来掏空上市公司的情况，复杂的内部融资市场就特别容易滋生这种道德风险问题。

所以，作为我们中小投资者，就要练就一双慧眼，学会识别企业。

+   延展话题 非整体上市：你投的中石油里有中石油吗？

要点2

+   1. 集团公司在内部抵押资金、“掏空”上市公司并披露上市公司中小股东利益的事情在中国A股市场上更是要发生，这个问题从20世纪九十年代到现在一直没有得到很好的解决。

+   2. 中国特色的内部融资市场使得集团企业的母公司、上市公司、非上市子公司之间形成了一个互助互保机制，以免去借贷高融资的骚扰，降低集团中各个公司的融资成本，也增强了企业的抗风险能力。
