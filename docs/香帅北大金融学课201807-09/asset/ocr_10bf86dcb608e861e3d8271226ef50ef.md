# 一、IPO溢价——二级市场定价过高?

好，我们先来看看美国的情况。

昨天的课程里面我告诉过你，七十年代的时候，你要在美国IPO打新股，收益是很糟糕的。有研究算过，当时是6000多个IPO，上市当天平均涨幅是18%，但是，这么高的收益率其实是靠那些投资IPO股票就是最在意惠呢? 其实不见得。

假设你要当一个价值投资者，好好地住进这个IPO股票，三五之后，你会发现自己去大了。

有学者对七十和年代的IPO公司做了一个长期的研究，现在假设每个投资者，每次在同一天做投资决定，一个人就买了当天上市的IPO股票，另一个买和同公司的IPO定价并不成规模的公司的股票。三年之后，你的会是什么情况？

专享IPO公司的投资者的收益大约是另一个投资者的一半，5年之后，情况也差不多。

总之，你想在IPO的股票上做一个安静的美男子，不是那么容易的事情。

这个现象在我们金融学文献里叫做IPO的长期弱表现，IPO long-term underperformance。

同样的情况，其实也发生在中国的A股市场，中国的IPO上市之后，会拉出不少涨停板，比如2018年平均值是8个，2016年是11个，但是，假如你hold住这个股票，几年之后回过头，你会发现点张已经跌了不少，有时候甚至会打回原形。

比如说华锐风电，在2011年1月份上市，上市的前期也就是高股价的时候，市值达到了800多个亿，不到一年的时间，就缩水成了400亿，缩了一半还不上，而且这不是个例，是中国股市普遍存在的现象。

IPO在长期的弱势表现到底怎么能解释呢？昨天我给你讲的一个比较，所以IPO的一级市场和二级市场就批作批和零售市场，昨天我前解释说，说，IPO为什么上市头天的回报率啊呢？可能是因为批发价定得太低（发行价）。

但是，从它们长期这么弱势的表现来看，其实它还有一种可能，就是零售价格太高，也就说它上市之后，涨得太多，透支了这些股票未来的回报率，换句话来说，IPO不是一级市场溢价，反而可能是二级市场溢溢价，也就是定价过高。

# 二、IPO溢价的几个原因

好了，那为什么会产生二级市场定价过高的情况呢？学术界有不同的解释。

1.IPO择时

一个最流行的理论叫做"IPO择时"。

我在前面课程里面跟你讲过，市场是人的市场，而不是被情绪支配的动物，所以市场情绪高涨的时候，我们对未来的预期会会更加乐观；所以资产定价一定会更高，对不对？企业也是一样，它一定会想办法在这样的市场条件下去发行股票，因为这对它来说是更加划算的。
