# 一、股票市场的处置效应

我在前面的课程里一直跟你讲，金融市场是一个最有人性化的地方，经常会发生很多理性没有办法解释的事情。比如，散户为什么会早早地就把那些赚钱的股票抛售出去？

我到这里的时候，大家可以试着想一下，有没有你或者那些身边的人朋友，年复一年都持有那些赚了一点钱的股票，而后来到了，股票大涨的时候，你却会在多人都有的股票中卖掉？或者，还会存在一些股民像在与某个股票共生，越亏越不舍。这种行为，我们给它一个名词，叫“处置效应”（disposition effect）。处置效应就是，人们过早地卖出不赚钱的股票，然后死守着亏钱的股票。

在很长的时间里，大家都以为这种观点是个别现象，直到一个著名的行为金融学家、就是前面课程里我跟你介绍过的一个著名的行为金融学家，他得到了一个真实的客户的数据。这些数据是一个经纪商在1987年到1993年的1万多个月账户的买卖。每个账户下面都有每个人每天买入和买入的行为。

Odean教授把数据仔细分析了一边，就发现了一个特别反趋势的：在1987年到1993年的间，他发现，这些人持有的亏损股票的概率比持有盈利股票的时间长度要高很多，大概4年下来，亏损股票的平均盈利是60%。

这个现象是很奇怪的，理论上我们都知道，应该清空亏损的，拿着赚钱的才是对。

有的人就说，是不是因为投资者非常地聪明，知道哪些是亏损的股票，未来一定会亏损，就卖掉了，然后知道哪些是亏损的这些股票，未来会获利，就提前做了安排。

Odean教授就进行了更加详细的分析，发现并不是那些被卖出的股票比继续持有的股票每年的收益率要高平均水平，4年下来，就是亏损股票的亏损率更高。

所以，这些人就都证明不了，投资者不是那么聪明，他们就是集体地做了不理智的选择。

从理性预期的角度来看，这就不好解释了。要么是人，或者说市场太不理性了。

按照Odean的研究，在这么长的时间，绝大多数人投资都有多多少少显示了这种效应。这不是个人，而是集体的效应。
