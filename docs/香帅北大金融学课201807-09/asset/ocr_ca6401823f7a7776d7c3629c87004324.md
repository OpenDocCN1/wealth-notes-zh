# ☑ 划重点

1.熔断机制是当市场价格波动过大时，暂停交易，以防止触发系统性风险的制度安排。我国在2016年初实施了熔断机制，结果适得其反，下跌的期速加速，投资者集体火速卖出资产，使得熔断成为了A股的新常态。

2.我国的熔断机制学自美国，然而橘生淮北辰为枳，原因在于中美的操作技术和市场环境均存在巨大不同。中国股市波动性更大，个股和大盘同涨跌，容易触碰较低的熔断阈值，触发磁吸效应，引起更大的市场波动。
