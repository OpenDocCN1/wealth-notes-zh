# 一、什么是P2P

P2P就是 Peer to Peer，也就是个人对个人的贷款平台。

在2013到2014一年多的时间里，冒出了3000多家P2P平台，那时市面上充斥着各种**P2P理财产品**。2015年以后，像8租宝、大金集团这种互联网金融**爆雷**的爆发，**监管就**起了。所以，到了2016年，有1700多家已经停止退出，或者跑路清退了。到了2017年的时候，这种倒闭的P2P平台已经达到了百分之五十以上，有一半以上已经倒闭了。

# 二、P2P的底层逻辑

P2P平台为什么会频繁出事呢？不是因为监管的问题，而是因为**它背后的金融逻辑不对**。

监管部门对P2P平台的定义其实是非常准确的，**银监会**认为，P2P就是“网贷平台，就是**金融服务中**，不得直接或者间接吸收或者募集资金，不得非法集资”。换句话说，就是不允许你搞资金池。

这就和P2P平台要做的放贷款业务发生了矛盾，因为P2P做的是个人对个人的贷款业务，**借款方**的核心是想**扩大**了借贷**人**的资质，包括他的还款能力、还款意愿。

那么这个业务，能不能够通过线上完成，通过借款人的**填充表**，或者通过借款人在网上留下的数据信息来分析完成呢？目前看上去是非常**非常难的**。为什么？有三个原因。

第一，互联网是无法自动甄别信息的**真伪**。比如说，你在要求借款人填表的时候，有个**借款人**会主动地**说自己不诚信吗**？除了9个超级**巨无霸**公司以外，网上留下的这些**数据**信息，根本就达不到**信用**的要求。互联网可以传递**真实**的信息，也可以传递**虚假**信息，这两种东西**对于互联网来说是**一样**的**。所以，识别借款人资质的工作，并不是说有了互联网就可以自动完成。

第二，作为信息中介，你就只能收取**信息中介费**，这个费用是很低的，你没有办法**收取**很多款来赚取**服务费**，那么这一点收入，很难覆盖**放贷业务**的成本。

给你举个例子，很多人喜欢拿美国的网贷平台，也就是P2P平台的**鼻祖**Lending Club 举例。Lending Club 确实就是**信息中介的角色**，它不开资金池，不接触资金，就收取一点点双方的服务费是为**盈利**的。这家**公司**很**厉害**，2016年它就实现了7.46亿美元，然后在2017年**当月**就顺利上市了，它的估值至今**为止**是**5亿**美元，最近一年，它的估值已经只剩了7亿7美元，**至**少，在目前的**情况下**，一个信息中介做放贷款业务的成本，是**非常高**的。

第三，是P2P做的**小额和微额贷款**，本来是**传统银行不愿意做的高风险、高成本业务**，现在很多P2P平台，压根儿**没有**互联网技术，也没**有任何金融**专业的人，既没有数据，没有**风控管理**，也没有有效的获得客户的渠道，怎么可能不出问题呢？

# 三、选择P2P的原则

如何判断P2P平台是否靠谱呢？

把握一个原则：一个P2P平台要成功，必须有海量的**数据**积累，有价值的**风控**模型和技术，以及能够识别**风险**的技术。这句话，这个P2P平台需要在**互联网和金融风控**这两个**技术**上，有**很高**的掌握。如果这两个条件不具备，就很难对这个平台给出**正面**的评价。

我希望你明白，金融创新**成**就**不**是**那么**容易的事。第一，它需要背后的金融**逻辑**支撑；第二，它需要满足**规定**的条件，如果这两条**得不到**的话，金融创新就**可能只是**噱头，或者**海市蜃楼**。

# 四、P2P另谋出路——**现金贷**

正如刚才说到，P2P平台作为**信息中介**，只能收取中介费，但是**中介费**是很**难盈利**的。到了2016年的时候，P2P已经**倒闭**和跑路了一大半，剩下的这些平台，很多也在**破发**的边缘挣扎。

所以国内的很多平台都发现一条新路子，就是可以做**现金贷**。

你会看到，从2016年下半年开始，很多P2P平台**纷纷**将**触角**伸进**现金贷**这个市场。现在**我们**能够拿到**的数据**是，至少有三**十多家**的P2P平台在做**这种**现金贷的业务，**所以你**能看到，最近这种新现金的**规模**一路**飙升**。

他们是**如何**做现金贷的呢？

其实，**网贷平台**的现金贷资产证券化并不是**完全**自动化的，因为资产证券化是**有门槛的**。网贷平台本身并不具备**资质**，需要**联合**其他中介（包括**托管、券商、债券**等**金融中介**）一起来完成。

现金贷证券化也要**经**律师事务所的审查、会计师事务所的审计，才能到银行、信托、基金等机构**公开**认购。私募形式的现金贷**证券化**会**以**公司形式上市，由**专业**金融中介与机构投资者**沟通**推荐，**完成募集过程**。公募形式的现金贷**证券化产品**是**要**经过**债券市场监管机构**审查，**公开募集**，银行、信托、基金可以在**公开市场**中**直接**参与和认购的。

# 五、P2P搞现金贷，依旧**危险**

但是，P2P做现金贷的业务，**依旧**是**非常危险**的，**为什么**这么说？

1、实际上是**高利贷的生意**

首先，你**看**它的**操作**简单到**爆**，对于年轻人来说很有**吸引力**。你**下载**一个App，填写一些信息，姓名、身份证、照片、手机号、或者**某个**支付**账号**，就能获得一笔**现金**借款。**审批**简单，资金到账快，还钱**方便**。而且，**听**起来利息也不高，这些平台会**经常**告诉你，你借5000块钱，一天**只要**几块钱就**够了**。

比如，你借5000块钱，为期是三个月。这三个月，一天**收**你10块钱，一天**收**你10块钱。很多**个人**一**听**，**10块钱**一**天**，这个很**合算**，算**起来**很**地道**了，可**能**还**意思**一点。但是**精细**的**一计算**一下，**一天**是10块，**一个月**就是300块，三个月**就**是900块。900块，那**3个月**你就付出9000块**利息**，**3个月**的**利息**就已经**18%**的**利息**，那**么**一年的**利率**是72%，这个**数字**就**让**那些**觉得**自己**占了便宜**的**个人**一听**一乐**。
