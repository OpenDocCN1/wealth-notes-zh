# 第一天：市场分割：不完美市场

第一天我跟你一起学习的是市场分割这个有限套系的重要因索。市场分割可以分为地理性的市场分割和制度性的市场分割。

![](bbox=[0.04, 0.33, 0.96, 0.41])

地理性的市场分割，是由于交易条件和费用的不同所致存在。所以不同市场、不同的经济状态和投资者的情绪就会使得两个市场对同一个公司的股票定价不同。

而制度性的市场分割，是一个地区里面由因素限制的。比如说中国股票市场，就可以分类为银行市场和证券市场，而银行市场流动性交易少、门槛高，机构投资者较多、风险较低。而流动性的交易市场发行利率则比较低。

![](bbox=[0.04, 0.52, 0.96, 0.58])

但是你要注意过来看，这种制度上的分割并不是完全反过来的，这种制度上的分割也不是完全好的，它只是为政府监管套利提供了机会。通过创新，来吸引中小企业开发各种金融新产品，由此促进了我国金融产业的发展。

# 第二天：涨跌停板能降低市场波动吗？

第二天和第三天分别讲了两个大家特别熟悉的两个市场机制，一个叫做涨跌停板，一个叫熔断机制。

我们先说第二天的内容。涨跌停板指的是什么？涨跌停板就是限制股票价格在某个交易日的价格的最大波动幅度。目前A股市场的涨跌幅度是10%。监管部门在设计这个制度是想限制股价的过度波动，防止市场下跌的时候跟风交易着盲目追跌。

![](bbox=[0.04, 0.85, 0.96, 0.91])

但是监管者可能忘记了一点，涨跌停板制度是有负面作用的。一来它给投资者提供了一个事后的虚度安全层，这样就助长了杠杆抄底的冲动。第二，在有效市场的情况下，它容易造成非理性的市场行为。比如大盘下跌的时候，小盘股跟跌，而小盘股波动更大，让整个市场的波动性加大。一个制度在设计之初可能是好意的，但最后产生的效果可能是完全不一样的。
