# 2、不要期待你与交谈的人能够想出这些笨人听闻的花边新闻，也不要让他们去想。

你只需要跟他们谈论一下他们的工作，问问他们自己与产品有关的故事，以及他们工作中最喜欢的好笑的或者令人震惊的流言故事。不要让他们觉得，你和他们之间的谈话是事先排练过的，就像“宴会用语”似的一一你要像和他们在酒吧里偶遇那样去交谈，并且认为他们所说的每一件事情都是你听过的最吸引人的故事。

每个人都非常喜欢谈论他们所做的事情，然而他们认识的每一个人却很讨厌听到那些。因此，你就要做那个最善于倾听的人，让他们对你知无不言言无不尽。
