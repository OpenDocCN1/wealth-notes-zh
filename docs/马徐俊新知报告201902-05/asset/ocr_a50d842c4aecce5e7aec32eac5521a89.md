"功能性障碍"患者一旦被骗诊,会承受来自生理和心理上的双重痛苦, 能够正确地识别出这种疾病,非常关键。

今天的议题分为三个部分:

+   - 什么是"功能性障碍"?
- 为什么有人会患上这种病?
- 怎样有效地治疗功能性障碍?

你身边总有一些这样的人, 总说自己身体不适, 哪儿哪儿都不舒服, 可去医院一检查吧, 什么事儿都没有。这时候别人就会说这个人, 要不就是在最关心你, 要不就是没病装病。但是, 最新一期的《新科学家》杂志的封面文章却告诉我们, 我们可能都看错了他们, 他们不是装病, 而是认真地病了。不过, 他们身上的疾病, 不是因为某个身体部位出现了问题, 而是因为他们的大脑出了问题。这种病, 就叫做**功能性障碍**(Functional Disorder)。

得了功能性障碍的人, 尽管肉体上没毛病, 但大脑会让他们觉得自己病了, 他们会承受的痛苦, 和身体上真得这个病的患者, 是一样的。好消息是, 现在医学检查已经关注好了。坏消息是, 研究发现了他, 疗效并不理想。这治疗方法倒非常简单, 患者在家就能自行操作, 今天, 我们就来给你详细讲一讲。

# 什么是功能性障碍?

能够识别出功能性障碍非常重要, 如果识别不出来, 患者很有可能得不到合适的治疗, 为此承受巨大的痛苦。

我先来给你讲讲什么是功能性障碍, 它指的是你觉得自己得了某种病, 身上出现这种病的所有症状, 但检查不出问题。

功能性障碍, 和器质性病变的区别在于, 器质性病变是可以从组织或器官层面找到病变的, 但功能性障碍不是, 它是大脑的功能出了问题, 虽然功能上的异常, 但是身体的组织或器官并没有病变。

我给你举个两个文章中的例子, 你就更好理解什么叫做**功能性障碍**了。

有一位年轻人, 说自己右手麻木, 但是检查后说没有问题。但是, 他坚持说自己有毛病。医生让他用左手做某种动作, 发现左手也没问题。但是, 当他试图用右手时, 右手真的没有反应了。这就是功能性障碍的一个例子, 他的大脑告诉他的右手它有问题, 于是它就真的没有反应了。

还有一个例子, 一位女士, 说自己肚子疼, 但是各种检查都没有问题。但是, 她坚持说自己有毛病。后来, 医生发现她的肚子上有很多小伤口, 是她自己用指甲抓出来的。医生告诉她, 这些伤口是真实的, 但是肚子疼是她的想法导致的。
