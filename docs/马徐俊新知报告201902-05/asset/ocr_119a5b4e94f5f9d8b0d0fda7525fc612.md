实时通讯，这就相当于让机器开口说话了。

我们再来说说智慧医疗。通过5G技术，医生可以实现远程的検査、诊断，甚至实施手术。2019年1月20日，华为联合了多家医院和机器人公司，成功地利用5G技术远程操控机械臂，为50公里以外的一只小猪切下了一片肝脏组织，这是全球首例远程手术。在未来，当这个技术成熟之后，医生就可以远程为人类进行治疗，让生活在医疗资源匮乏地区的人也能得到优质的治疗。

远程医疗除了可以为偏远地区解决就医问题以外，还可以为急救赢得时间。比如说，身在医院的医生可以手握远程操纵杆，通过5G网络连接，给还在120的救护车上的患者实施“远程B超”，对病人的病情做出诊断，这样就可以为抢救病患，争取宝贵的时间。

# **总结**

对于普通人来说，5G的成本过高，能用上的地方又不多，而且，5G可能会对人类健康以及生态造成负面影响，所以，5G还不具备民用推广的条件，它最有前景的应用还是在于商用，比如说无人驾驶、AR技术、智能制造和智慧医疗等多个领域。

总的来说，5G具有“大带宽、低延时、万物互联”的特性，它或许会为人类社会带来巨大的变革。但就像文章里说的那样：即便是一场移动互联冢革命正在发生，它也会以极其缓慢的速度到来。

If a mobile internet revolution is afoot, it is certainly looking suspiciously slow.
