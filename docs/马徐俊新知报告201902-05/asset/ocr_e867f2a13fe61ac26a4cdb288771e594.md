# 今日报告：幸运”是怎样被设计出来的?

马徐骏

今天的议题分两个部分：

什么是坏的“幸运设计”？

好的“幸运设计”，存在哪里？

都能有好运气吗？我们大家都在下一次说过去，关于运气的话题，但主要还是不一定说明理解运气、理解成为与运气之间的关系。过去，我们最常认为运气是随机出现的，但你有没想过，运气也有可能被“设计”出来的？

《鹅鹅魂》杂志最近刊登了一篇文章，叫做《工程师：探讨了“幸运究竟是如何被设计出来的”》，这个问题，文章的作者西蒙·帕普是一个很受欢迎的作家，他经常给《卫报》《纽约客》《麻省理工科技评论》这些大的媒体供稿，还写过一本专门分析机器的游戏设计学，叫做《龙卷风——虚拟实验台上的危险、快乐和沉迷》，对于游戏究竟如何操控人类行为的问题，他非常有研究。

西蒙·帕普这篇文章曾经也在《鹅鹅魂》杂志上发过，但是最近又被人做精，证明了这篇文章的价值，我读下来觉得，这篇文章对运气设计的观念也经得起时间的考验。

我们专栏虽说，正确识别幸运，才能变得更幸运。通过今天这篇文章你会知道，好运气，也就是“幸运”，其实是可以被设计出来的，我们在后面把它叫做“幸运设计”。好的“幸运设计”可以促公平，提升沉迷，而坏的“幸运设计”，则会让人们沉迷其中无法自拔。

# 什么是坏的“幸运设计”？

有句话叫“七分注定，三分靠打拼”，意思是“幸运”这件事，是随机的。在自然界中，有运气大家都不奇怪的问题，但在人类社会中，好运气不但可以被设计，还能被操纵，从古至今都是如此。

文章里说，从古埃及人墓葬的陪葬品里，就有玩骰子赌博做的骰子，但那时还没有手机，而古人做的，也就是说，那时的埃及人，就已经开始使用各种手段来占卜，通过设计幸运来影响到他们的决策了，点击本文就可以看图片。

而在现代社会，对于幸运设计，研究最深的、操纵最狠的，就要算赌场了。按照作者帕金的说法，赌场对于幸运的设计，是设计出来的典范，不但赌场可以从中牟利，还会让人沉迷。

比如赌场里最常见的slot machine，老虎机为例。为了能让玩家持续投入，老虎机都是经营幸运设计的，每次玩家看三个图案，哪怕对大图案的奖励是，总是到一点就输过去了，玩家会感慨，真是运气不好呀。

英国哥伦比亚大学的心理学家卢克·克拉克斯说，赌博设计成了某条复杂的心理变化，一方面很吸引人，另一方面也让人迷失。其实最大的快乐，基本上就其老虎机都是算法控制的，本身不可能产生大错处，就是造成这种毫厘之间幸运错觉，引导玩家继续找下去。

而且借助大数据的力量，赌博业早已经有能力追踪个人的行为，建立顾客详细的数据档案，资料甚至可以用来预测，如何以及何时，这个人可能更会离开。算法会及时提醒顾客的获胜概率，在他马上要放弃的时候，让他小赢一次，调整顾客的愉悦和预期，让他留下来继续赌。

这其实已就不算是个什么秘密了，美国有很多州甚至合法了赌场，允许赌场这么“操纵”幸运。但赌场依然有反赌法，在赌场里有一种叫“幸运大使”的工作人员，会亲自走到顾客身边，送给他一些赠品作为奖励，说那是因为运气不好，中奖了，但其作用同算法控制的机器是一样的，依然是为了让顾客继续玩下去。文章里说的，这些人只是帮幸运设计幸运，让玩家看不投入进去的冰山一角，但也很触目惊心的。

克拉克斯还说，在人脑子里有一个处在核心位置的区域，叫纹状体，管理运动和奖赏，也是我们生存策略的重要器官，而这个区域还没有为学习而形成，所以它会不断地刺激纹状体，会导致上瘾行为。这也是为什么赌博很难戒除的原因。

我们知道了，赌场通过对幸运的设计，从赌客身上获利，是否会经常输钱，但如果把对幸运的设计，用在好的方面，又会怎么样呢？

# 好的“幸运设计”在哪？

文章里说，好的幸运设计会让人产生一种公平感。

你可能不知道，人类共需要的公平感，和现实世界的概率真相其实是同一回事，比如说，我们告诉一个人是一个游戏，他有1/3的概率会赢，那么，这个人期望游戏的结局是什么？答案，是这个人会期望玩三次至少会赢一次。

但从概率学上来说，根本不是这样。每一局获胜的概率都是1/3，意味着每次选择是概率都是66%，而且每局之间的结果都是不相关的，这个人才可能连续输10次，却一把都没想过，但普通人接受了这个逻辑时，如果这种游戏让玩家赢了10局，玩家会看到1/3的获胜概率，却连输10次，肯定不玩了，这就是对游戏设计师资力的考验了。

把幸运设计到游戏里，不只是要调整一些参数，增加游戏里的随机性，而是一个非常高难度的活儿。一方面，不能设计得太难，玩家一直赢不了，玩家大概率是要弃玩的；但另一方面，参考者感到自己是幸运的，所以一旦，设计与又不太简单，如果每次飞行都会带来好运，玩家很快就会发观规律，之后就觉得无聊了，就会弃玩，太轻松的游戏，同样留不住玩家。

这种情况被游戏设计师们称之为幸运谬论—lucky paradox，原 call lucky is fun，但 too lucky is unreal，意思是：是玩游戏，太走运就假了。跟真实世界相比，游戏的体验都非常重，要么，或者说让玩家感觉到自己很幸运，是关乎游戏成败的重要元素。设计游戏也体验到某种巧妙的平衡，所以必须在1/3的获胜概率，就必须的让玩家一次至少赢20%，这样的设计出来的游戏，才符合人类的公平感，游戏设计师能透过对幸运的公道设计，让不同水平的玩家能够一起享受游戏乐趣。

文章里举了一个例子，是一个纽约的游戏设计师，设计和国际象棋游戏“我们”。新手小时，高手和国际象棋本应玩得赢，新手只有能在地上狠狠摔棋盘的少年，高手也气得不停地跳。对于这个游戏设计，他写了一款叫Really Bad Chess的国际象棋游戏，让双方开打的时候，棋子走随机走位，两个不同5小时，高手还是比新手多，这样就双方在不自不用的资源条件下博弈，高手也败得心服，最后所有人都不得过。

所以一个好的游戏设计，不只是让故事精彩，规则明晰，对于玩家心情的把控，规则的制定，都有着非常高要求。帕帕在文章里说，游戏向来是人与人真实世界的一种桥梁，幸运也可以被人为改造的，而在现实世界，幸运也都可以成为一个改善我们的生活体验，增加幸福感的重要工具。

Luck has become a design tool capable of changing our experiences and expectations.

这句话也是我们今天的主句。

# 总结

幸运是可以被人为设计的，坏的幸运设计，如同赌场，会让人上瘾、让人控制。而好的幸运设计，会让一个人进入开心的游戏，会让人们觉得公平，从而增加幸福感。
