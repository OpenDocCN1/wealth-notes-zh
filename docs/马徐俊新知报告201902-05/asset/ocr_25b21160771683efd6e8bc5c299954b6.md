# 今日报告：天才的“诅咒”

天才，其实是天生的潜力、有力的支持，和自我驱动的组合。

———— 《1843》

做一个天才，可能意味着身体和心灵的双重折磨。

今天的议题分为三个部分：

+   - 到底什么是天才？
- 天才的痛苦
- 如何教育天才儿童

谁不希望拥有一个聪明的孩子，哪怕自己的孩子在没有明显目标，才华，很多人依然会投来关注的眼神，来培养孩子。但没有人想过，自己的孩子如果是个天才，就没有是一件好事吗？

最近一期《1843》杂志的特稿《天才的诅咒》，对众多天才儿童的家庭进行了详细的分析和解读，得出的结论可能会令你大吃一惊。

这篇文章的作者安娜·格森通过采访大量的天才儿童和他们的家人，并且调研了包括云雀音乐界最着名的群组门萨俱乐部，最终发现，那些智力的天才儿童，但从小就很痛苦着身体和心理的双重折磨，而且让他们的大多数并非痛苦。这些天才儿童长大后，绝大多数并没有做出什么伟大的贡献和了不起的成就，最终泯然众人矣。

今天我们就来讲讲，所谓的“天才的诅咒”到底是什么回事。希望通过今天的内容，能让对天才们的人生有一个更全面的了解，也能重新审视天才与成功之间的关系。

# 1到底什么是天才?

江浙一带有句俗话叫：“脚前头的孩子，也是自己好”，意思是管教自己孩子是臭显丑，聪明还要求，不长家理中，总是好的。不少父母都觉得，自己的孩子在某方面是天挑之才，将来必成大器。

遗憾的是，天才的门槛，未必如你想象得这么高。文章里给出了三条标准：拥有某项突出的技能，能够自我成就，以及自己的兴趣爱好痴迷，通过这个三条标准，可以大致判断出一个孩子到底是不是天才。

所谓独特的天赋，是指天才儿童要在比其他孩子早得多的时候，就表现出某个领域的非凡能力，比如对小数字，表现出很好的非数字、数学、棋类的超强天赋，而且他们的学习速度，会比同龄孩子快得多。

其次，天才儿童需要能够自我成就。什么叫自我成就？就是说，孩子想要做的东西，感兴趣的东西，完全是出于自己的兴趣而努力，不是由家长来指定和安排的。
