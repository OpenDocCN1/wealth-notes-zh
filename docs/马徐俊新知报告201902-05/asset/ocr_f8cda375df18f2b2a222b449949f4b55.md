# 下期预告：

明天将给你带来的议题是#你的手机知道你抑郁了吗？#

《华尔街日报》的最新文章表示，全美国有4500万人患有不同程度的心理疾病，每个人的临床反应虽不同，但他们都有一个共同点：使用智能手机。一些特定的手机APP可以收集人们的声音、表情和健康数据，做出分析，比如抑郁症患者的笑容更浅，有自杀倾向的人更爱使用第一人称，患有PTSD的男性挑眉动作更为频繁，这些APP可以辅助医生提前诊断抑郁症等精神疾病。
