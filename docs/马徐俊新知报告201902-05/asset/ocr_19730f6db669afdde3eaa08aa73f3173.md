# 请收信！感谢你这一年的同行

![](bbox=[0.0, 0.04, 1.0, 0.06])

读者，你好

我们是彼此相伴了一年的朋友，我用音频跟你交流，你用收听和留言跟我互动。

专栏结束了，还有些话想对你说，我都写在了这里。

一共是三件事。

第一件事。你可能还记得，尤瓦尔·赫拉利在《未来简史》里的预言，他说，算法的出现，会把人类一分为二，一部分是掌握算法的神人，另一部分是被算法掌控的无用阶级。

其实，在我看来，技术把人类一分为二的情况，早就已经发生了，这项技术就是文字，书本来经这技术的进击，它记录下了人类文明最宝贵的财富——知识。

而知识却如同一头来自远古的巨兽，栖息在人类的世界。有的人被它吞入腹中，有的人靠上它的脊背，驾驭着它乘风破浪。但无论你是否意识到了，但事实是，唯有知识才能让我们免于平庸。

第二件事。跟罗振宇老师聊天，听他提的最多的一词，是“手艺”。三年前刚开始做专栏的时候，我天天画点，不管是写东西嘛，写会写，很多人也会写，而且写得还不错，关键在得到开专栏，就是手工艺了，呢？

直到有一天，我跟一个做收藏的朋友聊天，他指着桌上我看起来毫不起眼的两块玉石，斩钉截铁地说，稍大一点的就是正宗的和田玉石籽料，而小的一点就是假的。

我好奇，问，你这眼睛就这么准？他回答我，这块玉石的密度大，跟你说清楚很难，但是，玉我研究十多年了，这就是我的手艺。

那一刻我忽然明白了，到底什么是罗老师说的“手艺”，其实就是——他用生命和血写出来的高墙，每天它挡住这道生砖一砖一砖，假以时日，都是别人仰望的神迹。

专栏作家很多，日更的专栏作家，按微博有，但作品被拿来写作的日更专栏作家非常稀有。都是凡人，谁还没有写不出、写不动、找不到东西可写的时候？

这三年里，这样的状况我碰到了不知道多少次，但只要想到再写一点，多写一点，就会再多一点，这门“手艺”就会被打磨得再锋利一些，也就咬着牙继续写下去。

其实生活不可能像小说和影视作品写的那样，有什么灵气突现的顿悟时刻，或者突然获得任督二脉。所有的进步，都是一条平滑的上升曲线，你说不清到底什么时刻，就进入了另一个境界的临界点。但聪明人的雄心壮志，应该体现在日复一日的生活中。

当你的“手艺”到了的时候，你自然就会知道了。

第三件事。在一次跨年演讲里，罗振宇老师讲了一个概念，叫“国民总时间”。时间是不可售卖的，对每个人都公平。现在无论是淘宝、还是抖音，或者是美国的奈飞、亚马逊，本质上都是在抢夺国民总时间。

因为时间这个东西，你在一个地方用得多一点，在另一个地方必然就花得少一点，我们要把时间花在刀刃上。

但这还不够。过去的大半年，我发现比时间更宝贵的，其实是人的注意力。跟时间一样，注意力也是不可再生的。今天用完，也带不到明天去。但不一样的是，注意力的时间更难以争取和分配，老板可以买断你的时间，让写996加加班，但也可以买断注意力的资源，你依然可以出力不出力，上就干净利落。

哪怕是把自己包围在书桌前，逼自己一天8小时的学习，如果你的注意力不在上面，效果一定不会好。而不夸张地说，我们所关注的东西，决定了我们的人生。

科幻作家史特金曾经提出过，“史特金定理”（Sturgeon’s Law），他认为，任何一个个领域中，只有10%的东西值得关注，音乐、电影、文学作品，都是如此。

（其实原意是：任何事物，其中90%都是垃圾。）

我们的时间有限，不要在糟糕的东西上浪费掉。那么我们应该怎么判断，一个东西是好的，还是糟糕的呢？

我认为，好的作品和内容，会自然锁定你的注意力，特别是在知识领域的作品中。

注意是看还是文文字，让你读着读着就分神了，读着读着就读不下去了，大概率来说，不会是特别值得关注的内容。
