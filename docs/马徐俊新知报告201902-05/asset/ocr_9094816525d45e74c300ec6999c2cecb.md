# 189报告“慢全球化”的世界将会怎么样？

从长达几个世纪的时间尺度来看，全球化的进程是不可阻挡的。

——《经济学人》

马徐骏

《经济学人》的封面文章提出了“慢全球化”的观点，这股不可阻挡的大趋势，将如何改变我们的生活？

今天的议题分为两个部分：

+   * 全球化进程为什么变慢了？
* “慢全球化”将如何影响我们的生活？

近几年来，随着贸易保护主义的抬头、全球资本流动的回撤，不少人担心全球化（Globalization）进程是否走到了尽头，甚至可能面临倒退的风险。

对于这个问题，本期《经济学人》杂志的封面文章提出了一个观点：全球化并没有停止，只是放缓了速度。《经济学人》还对这个趋势起了一个新的概念，叫做“慢全球化”（Slowbalization）。

这期杂志的封面是一只蜗牛驮着整个地球在缓慢前行，非常形象。《经济学人》认为，“慢全球化”是一种新的全球贸易模式，也会是未来很长一段时间后内全球经济形势的全球性趋势。今天的文章，对于需要了解大的全球性趋势格局、理解世界贸易的大趋势，会是一个重要的参考。

# ｜ 全球化进程为什么变慢了？

《经济学人》杂志说，全球化进程之所以会变慢，是由很多复杂原因造成的，但我们依然可以粗略地分出两条线：红利吃尽和经济模式转型。

我们先来谈红利吃尽的问题。你可能会觉得奇怪，全球化不是一直高歌猛进吗？怎么突然的红利就不行了呢？事实上，这一轮全球化的起点，早在十年前，也就是2008年经济危机的时侯就已经出现了。

不知道你有没有注意到，我用到了一个词，叫做“一轮全球化”，对，全球化的进程其实是经济会动一样，是有周期的。《经济学人》说，上一次大规模的全球化发生在差不多100年前，而每一次世界战争在之后的冷战与打断，每当全球化都建立在之前红利的基础上，而这一轮全球化的黄金岁月，是从1990年到2010年的这20年里，吃的是上个世纪70到80年代攒下的底子，概括来说，就是三种成本的降低，包括全球的物流成本、各国的关税，以及信息传递的成本。

但是，任何一种成本的降低，都是有限度的，货物物流成本和各类的关税不可能为零，信息技术的优势也逐渐消耗殆尽。而2008年的经济危机，也是一个非常明确的信号，预示着这一轮全球化带来的高速增长到头了。

我们不妨来看几个数据：银行的跨境资金借贷，在全球GDP里的比重，从06年的60%，跌到了如今的36%，下跌了40%；国际资本流动总量，从07年触顶时贸易在全球GDP里的比重，从08年的61%下降到18年的58%，10年内下降了整整3个百分点。

注意，我们刚才提到的，都是单个国家的数据，在全球经济总量里，我们以单位只是相差个1个百分点，也代表着巨大的量级。
