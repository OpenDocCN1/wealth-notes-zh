# 今日报告：为什么聪明人总做傻事？

高智商和专业知识，也不能保证让你免于思想误导。

—《新科学家》

马徐骏

今天的议题分为两个部分：

三大智力陷阱
怎样才能避免做傻事？

你有过这样的疑问吗——我们学了很多知识，获得了高智商，脑瓜并不笨，却还是解决不了生活中迎面而来的问题，不好人、明明很有前途，却还会经常做出一些令人匪夷所思的傻事 儿来，为什么会这样呢？

《新科学家》杂志最新一期的封面文章提出了一种解释：智力和专业技能，跟我们在工作和专业上的成功密切相关。但心理学研究表明，在做决策和批判性思维方面，智力和专业技能并不能太多帮助，还有可能让我们更容易做傻事。

文章的 作 者 大 卫 · 罗 布 森（David Robson）在3月7日刊发了一本新书，书名 《智力陷阱》，《新科学家》的这篇封面文章，就提炼了这本书的精华。
