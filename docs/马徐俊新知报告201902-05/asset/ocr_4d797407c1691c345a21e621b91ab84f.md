今日报告：电子银行来了

电子银行是对传统银行最大的挑战，就是它们的商业模式与普通客户优先。

——《经济学人》

# 马徐发

电子银行最大的意义在于，它改变了银行金融巨头之间的关系，让金融巨头更好服务普通消费者。

今天的议题分为三个部分：

什么是真正的电子银行？
电子银行到底好在哪？
电子银行究竟会带来什么样的改变？

过去十年里，科技改变了很多我们熟悉的行业，从出行到外卖，从住宿到社交，可以说，科技把原来的社会化行业，一次颠覆又一次的重新发明。但是，有一个行业，科技的渗透却非常缓慢，那就是金融业。为什么呢？原因很简单，因为金融业有特定的稳定，一个国家最管的核心，在没有十分把握的情况下，不管是银行业本身还是政府，都不敢贸然推进科技对金融业的渗透。

但是，这种情况正在发生变化。《经济学人》最新的一篇专栏报道，分析了科技融入银行业的大趋势，最重要的表现，就是电子银行的崛起，它将整个银行业，以及我们普通人的生活带来一系列的变化。

这篇专栏报道篇幅不长，我先把它的核心告诉你：电子银行是银行，对传统银行业有巨大的反向作用，但对所有普通人而言，它也能够带来更大的生活便利和更理性的消费习惯。

# 什么是真正的电子银行？

这篇报道很清楚地给出了一个界定，到底什么是digital banking——传统银行的电子业务，比如是digital bank，指的是bank可以把传统的业务放到网络上，让我们可以通过电脑，或者手机这样的电子设备登录使用。

而digital bank指的是完全没有实体分支，只能用手机在网上登录操作的金融服务。这两者有什么区别？可以用一个不太准确的比方，前者像是银行拿着它把建设银行放了一个手机App，而后者则是支付宝和蚂蚁金服。

为什么说这个比喻并不准确呢？因为我们国家有自己特殊的情况，支付宝和传统的银行之间有不能分离的，但是文章提到的其他国家，这两者之间的差别还是很明显的。

来了解一下英国的情况。在欧洲，我们把这种完全独立于传统银行体系之外的新型电子银行，称为“neobank”。像Starling、Monzo、Revolut和N26是这类的neobank。它们别立不、都是主要只向消费者服务，并且没有实体银行机构，只能通过网络登录，它们很受年轻人欢迎，增长速度非常快。
