# ## “人体暗物质”包括哪些微生物？

根据美国国立卫生研究院发起的人体微生物计划 的卫生，目前有 大约900种微生物正处在研究和探索。

文章主要介绍了两种新的微生物，一种叫黑水仙菌，它的发现，让 生物学家重新认识了光合作 用的过程；另一种叫小细菌门类，这个  专门名 词太隐，研究人员  也简称“CPR细菌”。这种细菌广泛地生活在 我们的口 腔、肠道和皮肤中，但以目前  对它们却 没什么发现。

我来具体介绍 这两个微生物。先来说说黑水仙菌。美国 华盛顿大学 微生物学专家 吉莉简 · 班菲尔德 （ Jillian Banfield）和由 康奈尔 大学的微生物 学 家 利 · 卢特（ Ruth Lutz）通过研究 发现，在他们的试管里，生活着 一群新的活 生物，但 做 微 生 物 学 家，这种新菌对我们 了解 生 物 进 化 有 着 重要意义。

为 什 么 说 呢？ 因 为 黑 水 仙 菌 是 蓝 藻 的 远  祖 先， 是 唯 一 和 蓝 藻 有 亲 缘 关 系 的 细菌。蓝 藻 是 世 界 上 唯 一 一 种 能 通 过 光 合 作 用 产 生 氧 气 的 有 机 体。 植 物 所 以 能 产 生 氧 气，就 是 由 于 它 的 组 织 中 包 含 着 蓝 藻。 正 是 因 为 蓝 藻 的 存 在，地 球 才 像 今 天 这 样 丰 富 生 机 勃 勃。
