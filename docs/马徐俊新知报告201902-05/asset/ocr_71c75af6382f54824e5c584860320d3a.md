# 应对复杂，就是对抗衰老

利普希茨教授在文章里提供了几个方法，来帮助我们延续身体的复杂性，包括生理和认知两个方面。

生理上的方法其实我们基本也都已知，比如多做有氧运动就已被证明是可以增加心率复杂性的。这里利普希茨教授推荐了咱们中国的太极，他和同事经过研究发现，12周的太极训练，可以极大地改善老年人身体的状态，哪怕是90多岁的高龄老人，这是因为太极综合了身体移动、呼吸控制，**而且它是一种多组、多维度的训练，效果非常好**。

另外，利普希茨教授的研究团队还发现，**轻微但随机的足底震动也有助于保持人体的复杂性。** 具体的原理还不清楚，但是可以猜测，像这种很难感知到的随机共振现象（stochastic resonance）可以保持神经细胞对外界刺激的敏感性。

**认知上的方法，主要包括扩大自己的社交圈子，经常打破自己的固定生活规律，学习新技能，做更多一些费脑子的事儿，像解题、猜谜都可以。**

其实这些道理你都知道，但是为什么不做呢？因为不做这些事，会让我们感到更轻松。社交是需要精力和成本的，人也不爱打破自己的生活规律，而学新技能必须面对挫折，相比之下，当个沙发土豆可比干费脑子的事儿轻松多了。

但你有没有发现，所有这些，都是“简单性”很强、“复杂性”缺失的选择，这意味着，你在选择主动衰老。

# 总结

今天的内容其实说起来很简单，就是一句话：年轻能复杂，衰老只能简单。所以利普希茨教授说，如果它碰到了梭罗，面对梭罗的三个 simplicity，他会回敬三个 complexity！

最后，我想把这个结论再往前推演一点，我们不能把追求“简洁”和变得“简单”混为一谈。简洁，是为了避免干扰，简单，是缺乏应对复杂性的能力，这其实是两回事。我们当然可以选择干扰较少的方式，但不能失去应对复杂性的能力。

春节免不了走亲访友，你可能会遇到喜欢标榜自己崇尚简单、世事洞明的人，但是，在一个变化如此迅速的时代，谁又敢说完全掌控世界的复杂性呢？在这点上，**显然保持开放的心态，和持续学习理解这个世界的人，比始终过着简单生活的人，更具优势。**

咱们讲了鲁宾-戈德堡装置，也就是“小题大做机”，你觉得现实生活里，有没有符合这个逻辑的事情呢？

欢迎你在留言区写下自己的答案，也欢迎你**把今天的内容转发给自己的朋友**。

# 划重点

今日得到：
1.  所谓的“复杂性”，指的是许多不同的组成部分，在多重时间和空间层面上的互动；所谓的衰老，其实**就是身体逐渐失去了掌控这种复杂性过程的能力，**而且这是由自然规律决定的。
2.  完全**不重复的模式、和极其重复的模式，比如白噪音、节拍器都不具备复杂性；只有在不同的时间尺度上，呈现出相似性，才算得复杂。**
3.  随着衰老变得越来越简单，其实是一种无奈的选择。
