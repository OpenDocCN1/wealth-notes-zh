# 243报告 | 对“美”的追求阻碍了科学的发展

马徐骏 · 新知报告

今日报告：对“美”的追求阻碍了科学的发展？

对自然界来说，人类认为的“美”并不重要，自然压根就不在乎。

> ——《鹬鸦报》

科学家们正在花费越来越多的时间和金钱，去验证那些只是“看上去很美”的理论。他们应该停下未好好想想，这未免值不值得。

今天的议题分为两个部分：

+   科学家眼中的“美”到底是什么样的？
对“美”的追求让科学走了哪些弯路？

最近，知名科普网站《鹬鸦报》刊登了一篇粒子物理学家萨宾·霍森菲尔德（Sabine Hossenfelder）的文字，谈到了一个很多人会忽略的观点：很多科学发展历史上的弯路，竟然都是因为追求“美”导致的。

科学家眼里的“美”是什么样的？主要有两条标准，一个是简单性（simplicity），一个是自然性（naturalness）。

很多科学家都坚持相信，如果造物主真的存在，那么它用来书写万物的“语言”一定是简单且归纳的。比方说，自然法则的说明最好可以归结为一个简单的公式，包含的参数最好是常数，不大也不小。

这听起来确实是个很美妙的设想，可纵观历史，这种审美却经常导致科学走向的方向。萨宾说，物理学家们的就是先加入一类追求很多大师的，却被不断“打脸”。历史，在量子力学刚萌芽的时候，爱因斯坦曾向物理学家抱怨，上帝掷骰子实在不符合他关于宇宙的审美。

直到今天，这种审美仍在引导着科学发展。比如，科学家对目前的粒子标准模型不满意，他们认为这个理论有很多不完美的存在，才能补足一个理念看不见去的缺陷。他们提议，要求它描述更加更完美的物理学规律，来自证他们的假设。

只是“美”并没有那么强大，科学家认为，人类认的“美”并不重要，自然压根就不在乎。
