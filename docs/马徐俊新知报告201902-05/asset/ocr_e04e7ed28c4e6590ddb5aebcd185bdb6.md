你可能听到哪一句：

“5G来了！”放眼望去，各种有关5G的消息铺天盖地，比如2018年底，韩国正式部署了全球第一个商用5G网络服务；今年2月，三星和华为也相继发布了5G折叠屏手机。看起来，我们似乎离5G的部署步入5G时代，我们的生活也会随之发生巨变。

不过，《新科学家》杂志最近发表了一篇文章，叫做《通信在未来》（*Phoning in The Future*），文章的核心观点是：就目前看来，5G能发挥的作用太有限了，在商用领域，在其民用。也就是说，5G离普通人的生活，还远得很。

今天的内容分为三个部分，第一部分，我先来给大家讲讲，为什么说5G距离普通人的生活还远得很？第二部分，我们来探讨5G对人体健康和生态会造成哪些影响？第三部分，我们来聊聊5G有哪些商用价值？

# 为什么说5G距离普通用户还很远？

《新科学家》认为，5G现在离我们自己的生活还很远，主要有两个原因：首先，4G完全可以满足普通用户的日常需求。普通用户没必要花錢去买5G；其次，普通用户既想用1.5G，还要基础建设，和各项软硬软件能力配套才行。下面我来跟你具体说一说。

我们先来从什么4G已经够用了的问题。5G最高比4G网络要快千倍，它的速度可达到120 Gbps（千兆比特/每秒），它的网络在大多数可用、低延迟、万物互联等，则目前大家常见设备在4G时代，它的速度比4G到20倍。这是什么概念呢？就算5G可能能承载一部1080P高清电影，但几秒就能传输下几部电影，是4G的十分之一，几乎等于是等零延迟了。

这听起来是不是很爽？其实，这么快的速度，对目前普通人的生活意义大吗？按理说，我们需要下，我们需要一个很大的屏幕，在目前的4G网络下要几秒也只需几分钟，在5G网络下载则只需几秒种，但是，现在的5G网络资费非常高，以美国运营商AT&T给出的5G套餐为例，每个月要70美元，折合500元人民币，才有150G的流量限制。而4G呢，不光不限流量，每月也只是几十块钱。跟5G的成本相比，对于绝大部分人，多几万块根本算不上什么。

其次，我们来谈说5G需要的基础设施，和软硬件的支持，因为5G的基站、核心网、天线构造、无线频率、传输要求等都和4G完全不同，所以原有的基站根本没办法在4G的基线上进行升级，要重新建造，这就意味着巨大的成本投入。

另外，5G用的是高频毫米波，这个频段的特殊，是波长短、带宽大，但缺点是传输距离短，发射塔的覆盖范围小，也就是说，想要5G，覆盖建设比4G需要更多、密度更高的发射塔。

中国大概是从2013年开始大规模建设4G网络，到现在也还没全部完成。那你想像，5G要全面铺开，得花多长时间？

除了时间的问题，还有钱的问题。根据统计，中国三大运营商，2013年到2021年期间，在4G网络上的投入，估计要达到1170亿美元。而5G上的投入预计比4G增加48%，差不多要达到1800亿美元。这么巨额的投资，对于运营商来说是投入了这多压力。而且运营商已经在4G上投入了这么大成本，有的想挣钱，继续投5G，这对他们来说，代价实在太大了。

除了基础设施短时间内跟不上，还有软硬件的问题。5G需要在民用之外发挥效用，从软件上来说，需要第三方开发“杀手级”的新应用和功能，比如增强现实物体的体验、全新的3D地需要等，本身难度很大，如果这款软件开发不到位，就算5G来了，也没有用武之地。

还有，5G的运用还需要硬件的支持，目前市面上5G的手机价格在8000元左右，而且，5G手机的耗电量，至少是4G手机的2.5倍，说白了，就是又贵又费电。

其实，我们目前所有的这些应用软件，4G的速度完全就可以满足了，如果你的手机还能进行速度提升，那问题要么是网络速度还不够快，要么是因为在你的手机配置上，或者是在远端服务器的处理速度上，所以与其说5G，不如直接换个好一点的手机更能提升你的使用体验。

简单来说，5G的民用推广存在着高成本、高能耗的问题，而且还没减少4G时代的分支，微信这种全民应用，全民推广的杀手级应用，所以，就目前来看，5G对于用户来说，就是用高射炮打蚊子，大材小用。

除了适用性的问题以外，5G想要推广民用还有一个争议，那就是5G的辐射对于人类的健康和生态都会产生负面影响。

# 5G辐射对生态和人体健康有哪些负面影响？

文章里说，研究表明，5G辐射对人类的健康造成负面影响，比如引发癌症、损伤眼睛、导致免疫系统紊乱等，同时，它还会损害动植物的健康，甚至会破坏大气层。

关于5G有很多技术名词，比如给5G相关的发射机做“频谱调制”，这种调制被世界卫生组织的国际癌症研究机构归类为潜在的2B级致癌物。这个等级到底能有多危险？美国国家物理学实验功能就做了一个研究，给一只老鼠暴露在这种频率下，实验了连续2年，这些老鼠的大脑和心脏形成了罕见的肿瘤，这DNA都出现了损伤。

5G有一个关键的技术叫毫米波，这种毫米波波长为1～10毫米的电波，研究表明，毫米波辐射对眼睛、和免疫系统都会带来损伤。比如加拿大科学家医学院一所研究，实验发现，60千兆赫兹毫米波，就会对兔子的眼睛造成损伤。

俄罗斯还有一项研究表明，把健康的、老鼠在低强度、高频的电波辐射下，不仅会升高脑内白蛋白，还会严重损害老鼠的免疫系统。

5G辐射对植物也会有影响。2010年的研究，暴露于5G辐射环境下的向日葵叶片，出现了死斑，在土耳其的某研究所中，一项研究也表明，低强度毫米波影响了小鼠幼崽器官的应激反应，这会影响小鼠的正常生长，也就是说，5G辐射可能会污染人类的食物流。

另外，有研究认为，5G甚至会对大气层造成影响。因为5G网络需要在天空部署更多的卫星，根据2010年美国加州福尼亚的一项研究成果，卫星会向大气中排放黑碳，而黑碳会污染大气环境，影响臭氧和温度的分布。

当然，目前5G对人体健康和生态到底什么样的影响，还没有一个明确的结论，但这么肯定会发生，会成为5G在民用推广过程中一个不小的障碍。

看到这里，你会不会觉得，按文章的说法，5G就没有意义和前景了？不是的，5G在商用领域是大有所为的。

# 5G的商用价值

对于5G的商用场域，我们听说的比较多，是无人驾驶领域，和虚拟现实技术。但实际之外，5G还有很多用途，比如智能制造业和智慧医疗。

我们来说制造。现在的机器需要人去监控，一般要等到它出问题之后，才会发现故障。如果我们把机器都装上传感器，监控机器的运转情况，检验机器产出的零部件的质量，一旦发现质量有问题，传感器的数据通过5G网络，传输到服务器，在进入装配之前，零部件就会被自动淘汰，如果是机器的问题，也能第一时间发现。

像这样的操作所需要的数据量和速度，在4G和Wi-Fi的条件下，很难被大家认同，而5G的大带宽和低延迟，让人们可以实时通讯，这就相当于让机器开口说话。
