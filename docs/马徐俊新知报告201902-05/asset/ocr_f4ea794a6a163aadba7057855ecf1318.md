# 如何弥补视觉想象力的欠缺？

科学家惊讶地发现，失去视觉想象力的人，其实可以普通人一样进行思考、想象和创造。他们的秘诀，是扬长避短，找到其他的代偿方式。

就拿记忆能力来说，我们知道，很多记忆技巧都要运用到视觉想象。比如要记住一长串电话号码，记忆高手都要把这组号码想象成具体的图像，这样才能记住。视觉想象力障碍者没办法用视觉想象来进行记忆，但是他们会用文字和符号来代替。我们通常说“好记性不如烂笔头”，其实也是同样道理。一些人还说，自己虽然视觉想象力，但是有听觉想象力和嗅觉想象力，他们可以在脑中幻想声音和气味，用这种方式来展开联想，进行记忆和创造。

科学家还发现了一个有意思的趋势：视觉想象力障碍者有不少都在从事学术和计算机相关的职业。可能在这些领域，我们更能规避视觉想象力缺失所带来的劣势。美国著名的基因科学家、被称为“人造生命之父”的克雷格·文特尔（Craig Venter）就有视觉想象力障碍。他说，失去了视觉想象力，反而让自己可以不受干扰，集中精力思考科学问题。

艺术领域也有视觉想象力障碍者的身影。这些艺术家虽然无法在脑中用画面来想象，但是他们会直接描摹眼前看到的情景，或者把图片或照片摆在旁边，作为创作的灵感来源。

这些例子都说明，失去视觉想象力并不可怕。你看，之所以大众此前一直没发现“视觉想象力障碍”这种现象的存在，正是因为，这虽然是一个挺严重的问题，但仍然可以找到解决办法。

# 总结

视觉想象力是人类最强大的能力之一，人类历史上很多伟大的发明创造，都离不开它的辅助。但听完今天的报告，你就知道，这世界上还有一部分人是没有视觉想象力的。他们没有办法在脑海中想象蓝天、白云和青草，甚至连回想自己亲人的长相也做不到。

视觉想象力障碍既有先天的，也有后天外力形成的，但无论哪种，原因可能都是大脑中负责“视觉化”的神经网络出了问题。不过，失去视觉想象力，并不会让人就此丧失思考能力和创造力，他们会用其他方式，代偿缺失的“心灵之眼”。

视觉想象力障碍者的存在，也让我们意识到，或许每个人感知世界的方式都是不同的。就算没有视觉想象力，人生一样可以“不设限”。连康复教授都表示，视觉想象力障碍不需要治疗，也不是疾病，它只是一种与众不同的人生体验。

通过今天的内容，让我们不妨来重新思考优势和劣势，只有在具体的场景中，才会有所谓优势和弱点的分别，而哪怕我们确实不具备某种场景优势，依然有其他的替代方法来扬长避短，我们需要做的，是努力找到这种方法。
