# 今日报告：为什么说简单是衰老的象征？

年轻、健康与活力，其实在很多方面都是依赖于复杂性而存在的。

——《鹪鹩镇》

+   * 马修·梅

对于简单生活的推崇，是一种更有境界的追求吗？哈佛大学医学院老年医学系主任指出，简单，其实是衰老的象征，复杂性才代表了年轻与活力。

今天的议题分为三个部分：

+   * 到底什么是“复杂性”？
* 为什么说简单是一种无奈？
* 应对复杂，就是对抗衰老

我们经常能听到人们说，年纪大了应该追求简单的生活，不要有多复杂的欲望和念头。哲学系大V、获罗文有名的《瓦尔登湖》里还用到三个simplicity（简单），来赞美简单的人生态度。

梭罗说，简单可以凸显事物的美感，去除繁杂而繁夹的压力，能让我们专注于那些真正重要的事，似乎对简单的追求，代表了一种超然的智慧。

但有人并不同意这个观点——最近，《鹪鹩镇》刊登了哈佛大学医学院老年医学主任刘易斯·利普希茨教授的一篇文章，叫做《The Real Secret of the Youth Is Complexity》（In this 简单真正的秘密在于复杂性）。在这篇文章里，利普希茨教授提出了一个非常反直觉的观点：简单，其实是衰老的象征，复杂性才代表了年轻与活力。

换句话说，也许大了年纪的人对於简单的推崇，并不是——种追求，而是因为衰老考他们已经无法掌控自身和这个世界的复杂性了。

这篇文章并不是最新的研究，但是《鹪鹩镇》把它再次刊载出来，可见利普希茨教授提到的简单性、与年龄和复杂的变化意识到年轻的重要性，衰老与简单之间也的关系，今天我们就要着看告假期，来探讨这个问题。

# 1 到底什么是“复杂性”？

无论是《新科学课》，还是随曼文维格利尔的观点《精读日课》，都有人在反复强调一个观念：要复杂，不要简单。只有理解和接受这个世界的复杂多样性，我们才能活得通透，具备全面把握事物的洞察力。但是我们有过想 过，到底 什么 才 是 “复 杂性” (complexity) 呢？
