# I 为什么要去太空开采资源？

人类去太空开采资源，主要有两个原因：解决地球资源紧缺的问题、为人类将来的太空移民做准备。

太空里到底有多少资源呢？目前太空采矿的主要目标，是近地小行星。所以我们就拿这些近地小行星举例。根据NASA的数据，在这些地球为中心的，方圆450万公里的范围内，大约存在着15,000多颗大小不一的小行星。很多小行星都富含钴、钻、铁、锰等稀量金属或黄金。

NASA测算的结果显示，一颗直径1公里的小行星，就含有3000万吨铱、150万吨钻和7500吨钒。这是一个什么概念呢？我们拿地球上这些资源的储量来做下对比：2017年全球铰储量预测大约是740万吨；全球锰储量大约是大约10亿吨；4800万吨钴大约1.4万吨。所以，仅仅是一颗1公里的小行星，就拥有差不多一半的全球矿产资源了。

另外，根据美国一家专门做小行星采矿评估的网关AsteriAn的数据，一颗直径241公的小行星的价值，可以达到95.8万黄金。这个数字超过了全世界GDP的总和。

开采这些小行星，除了可以补充地球紧缺资源外，还有一个重要的作用，就是为人类太空旅行、太空探索和太空移民，做准备。现在人类如果要进行太空活动，需要大地面携带大量的物资。但换个角度想，如果能将这些物资从近地小行星上获取，就能大大节约直接太空开采的成本。比如：氢和氧可以作为火箭的燃料，而氢和氧都可以通过电解水来获取。根据科学家的估算，一颗直径75米的小行星上储备的氢，就可以让135名航天员，在任务提供能量。除此以外，小行星上富含钴、钻和锰，这些矿产可以制作工业级的钢条，这些钢条可以作为人类进行太空旅行的原材料。另外，如果有大航天真空的共其其他行星上居住的话，我们要在那建造家园，想地球上的资源全都要带过去，显然是不现实的，更可行的办法肯定是“就地取材”。

所以不论是出于哪个目的，太空开采都值得我们去做。那么我们人类下一步呢？技术、现在到底要发展到哪一步了呢？又有多少人在干这个事情呢？
