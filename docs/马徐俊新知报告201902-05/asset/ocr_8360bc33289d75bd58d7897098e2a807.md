# 今日报告：科技巨头的智能语音市场争夺战

> 智能音箱只是智能语音这块冰山的一角。

——CB Insights

马徐骏

最近，科技巨头在智能语音市场争相布局，抢占未来的市场。独立智库CB Insights发布的一份报告，清晰勾勒出巨头们排兵布阵的三大板块：

+   - 更精确地处理自然语言和语音搜索
- 更有针对性的安全和隐私保护技术
- 更先进的聊天机器人

你有没有发现，这两年市面上的智能音箱越来越多？ 从亚马逊的Home Podcast，到苹果的智音音箱Home Pod，还有咱们中国的小米、百度，也都拿出了自己的智能音箱。那为什么这些科技巨头公司都争着做语音市场呢？

独立智库CB Insights最新发布了一份报告，就回答了这个问题——其实，科技巨头们争夺的并不是智能音箱本身，而是以它为载体的、人类未来智能生活的应用场景。

报告中介绍了Facebook、亚马逊、微软、谷歌和苹果在智能语音市场的发展，清晰地描绘了这五大科技巨头在智能语音行业的版图，它们发布的主题有：更精确地处理自然语言和语音搜索；更有针对性的安全和隐私保护技术；以及更先进的聊天机器人。

# | 更精确地处理自然语言和语音搜索

所谓自然语言搜索，就是让语音助手能像人一样，理解人类说的话并作出准确的回应；只要能够理解人类语言，就能精确地帮助用户找出他们需要在搜索的内容，完成后用户下的任务。目前在搜索引擎方面，谷歌和亚马逊是处理自然语言和搜索方面的领导者，是谷歌和亚马逊。

谷歌语音处理技术方面表现最抢眼的是谷歌。谷歌的语音助手对人类语言的理解力，准确率达95%，这是什么概念呢？这其实已接近人类水平。 这句话对，你想啊，就算我们人类听到说话，也未必能达到100%。

另外，谷歌的语音助手支持的语言种类更多，在一年中，谷歌的语音助手将会支持30种语言，要知道微软才支持八种语言，单从数量上，你就感受到谷歌在处理自然语言技术上的优势了。而且，厉害的是，即使用户说多种语言，谷歌的语音助手也能理解得不错。
