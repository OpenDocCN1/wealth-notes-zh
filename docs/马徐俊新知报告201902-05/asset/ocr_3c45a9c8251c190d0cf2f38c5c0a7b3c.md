# 今日报告：如何给企业文化“排毒”？

“如果员工依旧为了一个企业文化‘中毒者’那么无论他们的个人能力有多高，都更决不能要。”

> ——《哈佛商业评论》

马徐骏
如果一家公司的员工勾心斗角、企业文化乌烟瘴气，是不是就该散伙了？《哈佛商业评论》用一个“反转”案例，给我们做出了一个给企业文化“排毒”的示范。

今天的议题分为两个部分：

+   - “有毒”的企业文化是什么样的？
- 如何给企业文化“排毒”？

你有没有遇到这样的企业——同事之间勾心斗角、在领导面前互相拆台或者背后打“小报告”，还有人看日子……如果相当不巧在你自己的文化工作过，那一定是很糟糕的经历，一家公司企业文化烂到了这份乌烟瘴气的程度，往往也走不了多远。近期的《哈佛商业评论》刊登了一篇文章，却提供了一个很有价值的“反转”案例。

这个案例来自美国知名的户外烧烤炉品牌Traeger。前年，这个有30多年历史的品牌就陷入了企业文化危机，有员工甚至因为对公司的商业决策的不满，在停车场蓄意纵火。面对如此糟糕的情况，新任CEO杰瑞米·安德鲁斯（Jeremy Andrus）想出的一套方案，最终给全企业文成了“排毒”，让公司面貌焕然一新，企业销售额也在短短几年时间里翻了儿翻。

安德鲁斯的“排毒”方法大刀阔斧，其中最值得点出的，一是将员工按照与企业文化的契合度分成了三类，分别是：“正向文化引领者”、“文化中立者”以及“文化叛离者”；二是让前两类员工都留下，对文化中立者有选择地保留，而“文化叛离者”无论个人能力多好，都坚决不要。
