# 今日报告：世界上并不存在“活化石”？

无论是鳄鱼还是人类，无论是不是显而易见，所有的生物都在不断演化。

——《鹦鹉螺》

马·徐健

在研究了近现存的23种鳄目类动物的DNA样本之后，华盛顿大学的地质学专家迈克尔·奥克斯推断，“活化石”理论至少把鳄鱼的演化时长高估了十倍。

今天的议题分为两个部分：

+   - 为什么说活化石并不存在？
- 活化石概念的颠覆带给我们的启示

如果说一种生物生存了上万年，外观和习性跟它的老祖宗相比，都没有太大的变化，那么，我们会把这种动物比喻为“活化石”。我们比较熟悉的活化石包括熊猫、中华鲟、银杏、扬子鳄这些动物，还有像银杏这样的“植物”等等。很多时候，我们从没觉得“活化石”这个概念有什么问题。

但是《鹦鹉螺》杂志最近刊登了一篇文章，挑战了活化石这个概念。文章的标题叫做“‘活化石’其实根本就不存在”，作者塞斯·博韦尔是一名记者，经常给《纽约客》《科学美国人》《纽约时报》这样的大刊写稿。

贾布尔在文章中以鳄鱼为例，向我们解释，为什么他会说这个世界上既没有什么活化石，所有的物种都在不断进化，而我们之前对于古老生物的刻板印象，需要被修正。

通过今天的报告，你会了解到：活化石这个概念到底出了什么问题？活化石理论的颠覆，又给我们带来什么样的启示。

# 为什么说活化石并不存在？

“活化石”这个概念最早是由达尔文在《物种起源》中提出的。它有什么样的生物被称为活化石呢？它需要符合三个特点：第一，这些生物远古之时就已经在地球上出现了；第二，这种生物还活到了现在；第三，这些生物存存了近似的，甚至说生物在很长一段时间里都没怎么改变，保留着远古时代的样子和生活方式，也就是说，它们很早就停止了演化。

正因为活化石停止了演化，亿万年来，它们还保持着古老的外貌和习性，所以很长时间以来，科学家都把活化石当作是观察远古地球的一个窗口。

如今，我们对活化石这个理论，已经可以“有”了，但是《鹦鹉螺》的这篇文章却提出了“活化石”，根本就不存在！作者给的理由是，世界上最古老的生物们，符合我们刚才说的第三个条件——很早就停止了演化。

《鹦鹉螺》杂志说，根据最新的科学研究，很多所谓的活化石，其实一直在演化，从没有停止过，鳄鱼就是一个活生生的例子。

文里说，鳄鱼是到目前为止人类发现的最原始的生物，可以追溯到上一个时代的物种。6500万年前，地球上发生了一次大灾难，但是大灾难后幸存下来的大多数都消亡了，但是，鳄鱼生存了下来，而且一直活到了今天。所以，用鳄鱼这种物种作为活化石的代表再合适不过了。

早期的古生物学家也一致认为，鳄鱼的祖先与现代鳄鱼的生物模板根本就是不一样的，比如它们拥有细密的尖形3条头，吻部扁平，长没有锯齿的祖先。所有，这就是为什么生物学家会得出“鳄鱼很早就停止了进化”这个结论。

其实，在历史上，科学家们曾经有发现过这个结论存在的问题——在十九世纪初，科学家们就发掘出了一些鳄鱼化石，它们与现代鳄鱼有些细微的差异，但是他们立刻意识到这些是重要的影响。
