# ## 今日报告: 抗衰老的新理念

长寿研究不再只是研究如何让人活得更久，而是让人在人生里都保持状态。

> ——《新科学家》

马徐骏

所谓衰老，就是身体逐渐失去自我修复能力，进入积累损坏的过程。如果能够利用药物定向清除衰老细胞，就能帮助人体对抗衰老的过程。

今天的议题分为两个部分：

+   1. 为什么人老了会疾病缠身？
2. 最好看的两种抗衰老新药

一直以来，抗衰老的研究都聚焦在如何让人类活得长久而上。但是最近一期《新科学家》刊发的文章说，人们对于抗衰老的理念需要更新了。现在，科学家更关注的，是尽可能延缓长寿，而不是如何让人不再健康地活着。

换句话说，重点不在于让一个人活到200岁，而在于，即使一个人只活到85岁，也能让他在84岁前身体依然健康，而不是卧倒在床、失能度日。

为了实现这个目标，在过去的几年里，有越来越多的科学家尝试在市面上，他们与多所医学院联合展开抗衰老药物，而且不断有新的进展成果。比如药物进入后，就最像一款抗衰老药物，会是什么程度？今天我们就来给你一次前沿汇报。

# ## | 为什么人老了会疾病缠身？

其实这个问题的答案很简单——从细胞的角度来说，人类的身体还没有准备好活这么久。

我们从生物学的角度来看看吧。衰老？文章不是这么定义的，所谓衰老，就是身体逐渐失去自我修复能力的过程。当一个身体的修复能力减弱，各种细胞进入了一个累积损坏的状态，器官和各个身体组织开始积累衰老的废物和基因突变会越来越难，我们的细胞会开始衰老，甚至开始自我损坏；还有一些细胞进入死亡状态，还有一些细胞发生了癌变。我们的身体还会产生各种老化，让水平的炎症反应开始侵入全身。

当身体的修复速度，跟不上身体破损的速度时，疾病就会发生。在过去，当人不再年轻，不再具备修复基因的能力时，慢慢地就自然选择淘汰掉了。而如今人类寿命的快速延长，已经远远超过了过去那种按照自然进化的趋势。

文章里说，自然选择根本不及调节人类的基因程序，为长寿的老年人准备的身体。也为许多长寿的老人疾病缠身，整个人的身体原因。是因为他们的身体，进入一个极度损坏的状态。
