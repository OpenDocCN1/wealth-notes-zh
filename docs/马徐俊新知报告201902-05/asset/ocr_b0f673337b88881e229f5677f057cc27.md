# 今日报告：牙周炎细菌可能诱发阿尔茨海默症

围绕诱发阿尔茨海默症的新蛋白，科学家已经研究了很多年。但也许，它们只是表象，而非内因。

--《新科学家》

马徐盛

最新一期《新科学家》杂志介绍了一个新的医学发现：阿尔茨海默症竟然可能和牙周炎细菌相关。

今天的议题分为两个部分：

+   - 为什么说牙周炎细菌可能诱发阿尔茨海默症？
- 新的研究发现对我们有什么意义？

我今年要在 028 报告《阿尔茨海默症研究找到最新突破口》中介绍过，目前医学界既不知道阿尔茨海默症是怎么来的，也不知道怎么预防，只知道它可能是病毒感染引起的。20 年来，只有 3 款治疗阿尔茨海默症的药物上市，治疗效果还不怎么样。

而最新一期的《新科学家》杂志的封面文章介绍了一个新发现：阿尔茨海默症竟然可能和牙周炎细菌相关。你可能有印象，咱们在报道 127 号报告《如何让大脑保持活力》中提到过，说牙周炎细菌与阿尔茨海默症有关，那么今天，我就是要来具体给你讲一讲，到底是怎么回事。

# | 为什么说牙周炎细菌可能诱发阿尔茨海默症？

牙周炎是最常见的一种慢性疾病，像是刷牙出血、牙齿松动、牙龈紫疼等，都是牙周炎的典型症状。但是在发病早期，人们通常不太把它当回事。你一定没没想到，牙周炎细菌，竟然有诱发阿尔茨海默症的可能性。

那研究者是怎么发现的呢？

最新的这项研究，是美国的制药公司 Corteva 和 Sigm 实验室共同完成的。这些实验室来自美国、英国、波兰、澳大利亚、新西兰。他们分析了 54 名阿尔茨海默症患者的大脑样本。结果发现，几乎所有样本中，都有牙周炎细菌产生的有毒物质，比例高达 99%。研究者把这种牙周炎细菌叫做**牙龈卟啉单胞菌 (Porphyromonas gingivalis)**，把它产生的有毒物质叫做**牙龈蛋白酶**。

关于这种牙龈蛋白酶，研究者有两个重要发现，首先，在这些阿尔茨海默症患者大脑样本中，负责记忆的**海马体**部分，牙龈蛋白酶水平越高，与阿尔茨海默症相关的 tau 蛋白就越高， tau 蛋白认知水平下降的越厉害。其次，研究者还在这些患者的大脑皮层样本中，还发现了这种牙周炎细菌的 DNA。

英国中央兰开夏大学的西蒙·辛格 (Sim Singhep) 说，这是研究者首次在人大脑中，发现牙周炎细菌的 DNA；也是第一次，发现牙周炎细菌与阿尔茨海默症之间的关系。这两点，都值得关注。

这还没结束，研究者接下来做的实验，进一步推进了他们的发现。当研究者把牙周炎细菌，也就是刚才说到的牙龈卟啉单胞菌，连续六周，每一天放到健康小鼠的牙齿里，他们发现，这些小鼠的大脑，都感染了这种牙周炎细菌。他们大脑中产生了阿尔茨海默症相关蛋白，神经元也受损了。也就是说，牙周炎细菌与阿尔茨海默症之间的关联，再次得到了强化。

纽约州立大学的罗伯特·格林 (Robert Genco) 说，这个研究发现太重要了，和前面的研究发现结合起来一起，就非常符合**科赫法则**，简称一下，科赫法则是现代医学里，寻找生物感染源、确认病原的黄金准则。简单来说，这个法则时有四条标准：

+   - 在患者的患病部位经常可以找到大量的病原体
- 这种病原体可被分离，并且在培养基中能够进行培养
- 即使经过多次传代，它们也能让健康个体产生与病原原本一样的症状
- 在因接种而患病的个体中，可以再次分离并培养出同一种微生物

![](bbox=[0.08, 0.95, 0.92, 0.98])

你听到这个发现，研究者在牙周炎细菌与阿尔茨海默症研究中发现，在常符合这四个标准。也就是说，即是从不危及这感染源，病原的标准上来看，牙周炎细菌与阿尔茨海默症的关联性也非常的高。

# | 看着新的研究发现，对我们来说，意味着什么？

新的医学发现给我们带来了好消息：第一，它为人类攻克阿尔茨海默症这个“世纪难题”，带来了新的希望和思路；第二，让我们能够更积极，准确地预防阿尔茨海默症。

先来说第一个好消息。咱们刚才说过，牙龈卟啉单胞菌会产生一种毒，叫**牙龈蛋白酶**，它能够诱发大脑，产生导致阿尔茨海默症相关的病理。但制药公司 Corteva 已经研发的能够阻断这种蛋白酶的**药物**，当他们把这种药物注射到，感染了牙周炎细菌的小鼠大脑中，这种药物成功阻止了小鼠大脑中的大脑感染，阻止了小鼠大脑中，有害蛋白的积累，降低了它们的大脑炎症，甚至修复了一些受损神经细胞。

据媒体文章介绍，这种药物已经初步通过了人体安全测试，在人体测试中，研究者也有了同样的发现。目前，研究者也确认了人类阿尔茨海默症的这种，今年，这家公司将进行更大规模的临床试验，为人类治疗，甚至是阻止阿尔茨海默症带来了新的希望。

那第二个好消息就是，既然知道了，牙周炎细菌与阿尔茨海默症相关，我们就可以更积极，主动的预防。首先，你得去学去判断什么是牙周炎。当牙齿上积聚了太多菌，引发了炎症，就有可能引发牙周炎。典型的症状有牙龈出血，牙龈紫肿等。当牙周炎太严重时，甚至会引起牙齿脱落。

但也不要太紧张，不是说只要牙齿出血，就说明你得了牙周炎。更常见的是，如果刷牙的时候牙龈流血了，可能是因为你刷牙太厉害了。但如果你出现了其他的症状，比如说牙龈肿痛，有口气，那你就还是去医院看看的。

那么有哪些建议可以让我们参考呢？这部分是我平时看的差不多，一天两次刷牙，刷牙不要超过两天，多洗牙，吃饭用漱口。我今年得到的最有用的建议，来自我的医生，他说，年轻人的观念都太年轻，尤其是年轻人，总是牙齿的问题都必须要复诊了。它总说，这是老生常谈的做法，定期到牙医进行复查，早进行修补治疗。我也推荐你，今年就去牙医。我的母亲排了牙医，我觉得这个做法值得推荐。

# | 总结

阿尔茨海默症的原因尽管没有被攻克，但小趋势已经显露出来了，也许是人类努力错了方向。

正如文章说的，那样，围绕诱发阿尔茨海默症的有害蛋白，人类已经研究了很多年，但也许，它们都只是表象，而非内因。
