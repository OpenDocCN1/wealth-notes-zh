# 今日报告：如何让私立教育的价值最大化？

世界各国政府不应该压制私立教育，相反，应该鼓励它的蓬勃发展。

> ——《经济学人》

马徐俊

私立教育蓬勃发展的国家和地区，公立教育的水平也会获得很大的提升，它们是彼此良好的补充形式。

今天的议题分为三个部分：

+   1. 私立教育高速发展的原因是什么？
2. 私立教育到底有什么好处？
3. 如何更好地放大私立教育的价值？

这是我为了专栏来的最后一篇文章了，我想了很久，以什么东西来结束这一年的内容，最终，我选择了教育。

今天我们就来读《经济学人》杂志的一副特别报道，就叫《私立教育》（*Private Education*）。根据报道提供数据的数据，在过去的15年里，世界各国私立教育的发展都非常迅速，小学阶段私立教育的比例从10%上升到了17%，中学阶段的从19%上升到了27%，而且中到、印度的教育的发展只到国家，私立教育受到青睐的程度，和普通家庭的投入，都是远超发达国家的。

可能一提起私立教育，你会立刻想起昂贵的学费，庞大的校园围墙，精英式的教学等等，强调公私教育界于格格不入，但这篇特别报道告诉我们要想，其实是对立关系的误解。私立教育但不是公立教育的对立面，还是公立教育不可或缺的补充形式，甚至它应该成学习的内容。

这些年以来，私立教育在全球范围内高速的发病率，既着实实存在的可能性，也是在给未来的学习增加新的可能性。就像文章里反复强调的那句话：世界各国政府不应该压制私立教育，相反，应该鼓励它的蓬勃发展。

```
Governments should celebrate the boom in private education, not suppress it.
```

这句话也是我们今天的金句。

下面咱们就分三个部分来说，为什么这些年全球的私立教育都高速发展？私立教育到底有哪些好处？我们怎么才能好地放大它的优势？
