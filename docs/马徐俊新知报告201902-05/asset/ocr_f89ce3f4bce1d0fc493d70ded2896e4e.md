另外一个故事是，有一个叫皮耶罗·曼佐尼（Piero Manzoni）的艺术家，把自己的大便装入了90个密封的罐头，还给每个罐头都贴上了标签叫“艺术家的大便”。这些罐头在1991年的苏富比拍出了六万七千美元一罐的价格。你听着，是不是都觉得荒谬至极？但之所以有人认同它的价值，是因为他们能够从这里体会到Manzoni对当代艺术收藏现状的讽刺。

说到这里，我还想跟你分享另一个问题：“学文科除了可以让你夸夸其谈以外，还有什么用？”其实，通过今天的内容你就能找到一些答案了，像历史、诗词、文学等等这些所谓没有用的东西，其实很有用，它可以提高你的审美能力，而提高审美能力可以让我们更快乐。因为根据神经科学的研究，在我们的大脑中有一个奖励机制。当人们感受到美的时候，大脑中的这个奖励机制就会被启动，分分泌出各种传递快乐的神经递质，比如多巴胺，所以，多感受到美，就能多得到快乐。

# 总结

从神经科学的角度，审美是存在的生物学基础的。审美的过程分为两步：第一步“从下到上”，在这一步里感官接收外部的信息，得到一个总体印象。第二步“从上到下”，这一步里人们利用已有的知识、记忆和情感，把接收到的信息分析处理，从而赋予作品独特的理解和新的意义。所以，审美的关键在于第二步，而第二步的结果取决于一个人的阅历，取决于很多所谓的“无用的知识”。

今天我们用科学知识解释了审美机制，不但没有损失对美的直觉，而且还增加了新的审美感悟。我的感悟是在今天这么功利的世界里，我们全身心的投入到有用的知识里，为的是找一份好的工作、赚到更多的钱。但是，赚钱的目的是什么？难道不是更好地去享受生活吗？可是当那一天真的来临的时候，你会发现因为没有那些所谓“无用的知识”，我们连享受和欣赏美都不会了。

今天想请你在留言里分享一个自己的故事，你有没有因为阅历的增长，再次欣赏一件艺术作品的时候，产生了完全不同的审美感受呢？

# 划重点

1.大脑有一套处理审美的生理机制，我们看到的艺术品，是大脑经过复杂的拆分、解构、重组之后的图像，换句话说，是大脑进行“二度创作”的结果。

2.决定艺术品鉴赏力的关键因素，除了基因之外，最重要的是我们的阅历。
