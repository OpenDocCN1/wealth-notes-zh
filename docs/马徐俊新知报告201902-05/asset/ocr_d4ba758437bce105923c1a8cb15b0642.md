# 今日报告：老龄化社会如何推动机器人革命？

咱们之前曾多次谈到人口老龄化带来的问题和隐患，而这篇文章将让你看到，老龄化社会也会带来新的市场需求，促使机器人行业的快速发展。

今天的议题分为两个部分：

+   - 为什么老龄化社会能推动机器人革命？
- 服务型机器人的发展趋势

科幻电影里经常出现一种很有趣的场景，机器人其其实很务实，它们能为主人打理各事务，把家里收拾得井井有条，特别厉害的，还能把人照顾得很无微不至。

你有没有想过，假如有这样一个机器人，《经济学人》最近就发表了一篇文章，标题叫做《奶奶的小帮手》（Grandma's Little Helper），文章指出，机器人革命正在快速到来，而推动机器人革命的，竟然是老龄化社会。

![](bbox=[0.15, 0.38, 0.85, 0.45])

为什么老龄化社会能推动机器人革命？

人口老龄化之所以能推动机器人革命，道理其实非常简单，因为与年轻人相比，老年人需要机器人的辅助，这个潜在的市场需求有多强劲？我来给你讲全球的人口老龄化状况，你就明白了。

《经济学人》的这篇文章中，从全世界的人口比例变化来看，今年出现了一个重大转折，那就是65岁以上的老年人口数量，超过了5岁以下的儿童人口数量，这在人类历史上是第一次，这组数据意味着，全人类的人口比例也在向老龄化倾斜。

咱们来看看各个国家的具体状况：到2060年，全球65岁以上的老人数量会翻两倍，这有900万；而老龄社会数最多的呢，也就是日本，65岁以上的老人占到了人口总数的40%。

咱们中国呢，根据联合国的估计，从2015年到2045年，20至64岁的劳动力群体，将会下降1.24亿，差不多接近目前总人口的1/10。

人口老龄化，带来了对机器人的两个强劲需求。首先，老龄化国家需要机器人来补充劳动力，文章里说，老龄化越严重的国家，对机器人的投资规模就越大，韩国、新加坡、德国、日本这些老龄化国家，拥有的机器人数量是全世界最多的。

国外还有研究者找出了老人人口数量和机器人数量之间的关系，弗莱明经济学者达拉斯阿格雷格（Darbon Aegregot）和波士顿大罗杰哈奇（Roger Hatch）（Pascal Restrepo）指出，55岁以上的老人口每增加10%，每100名工人中就会增加0.9个工业机器人。

按照这个规律，到了2040年，中国会新增200万个机器人，这个数据超过去年全球机器人增长总量的6倍，而这些机器人创造的价值，将会是2018年全世界工业机器人创造的价值3倍。

其次，老年人的生活需要大量服务型机器人来照料，这是老龄化社会的刚需。

目前，全世界的服务机器人都是工业机器人，也是在线作业里的机器人，比如安装汽车配、组装设备的机器人。但在未来，机器人的另一大任务，就是照顾老人。这三种机器人的作用各不相同，医疗型机器人能够提供医疗补助，陪伴型机器人能够与人类建立亲密关系，帮助人类缓解孤独，而护理型机器人能够帮助人类提取重物。
