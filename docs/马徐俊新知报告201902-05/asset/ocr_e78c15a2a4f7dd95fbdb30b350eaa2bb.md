样，用同一套卡路里的体系来衡量甚至指导饮食，这种行为简直可以用疯狂来形容了。

你可能会问，为什么卡路里这么不准确，却还有这么多人接受呢？威尔森说，因为它简单。一般人处理不了这么多的复杂因素，会倾向于使用简单的方式来应对状况，哪怕卡路里再不准，但它符合简洁好记的标准，因此受到了广泛的推崇。但对于那些真心想要减肥的人来说，计算卡路里不但没帮助，还会让人误入歧途。

那我们到底该怎么做呢？答案是，没有标准答案。如果你真的想要减重，就必须摸索出一套适合自己的方式。

不过，威尔森还是给我们提供了一些有用的指导原则，大致是这么几条：

首先，吃天然食物比精加工的食物好。注意，天然食物不是什么绿色食品，而是指自然生长出来的食物，蔬菜、水果，洗净直接吃就比做成水果派、蔬菜饼要好。

其次，吃生冷的食物比加热的食物好。哪怕喝水，冷水也比热水好，因为冷水需要我们自己的身体来加热，这个过程也会消耗卡路里。

最后，少吃糖！少吃糖！少吃糖！真正让你胖的，不是脂肪，而是糖和含糖量高的食物。

# **总结**

卡路里是一个非常不准确的能量单位，但因为它简单，所以广受推崇。可是，人体是一个非常复杂的系统，每个人的身体状况都不一样，简单粗暴的标准无法解决所有人的问题。多吃生冷的食物、多吃天然食物、少吃糖，比用不精确的方式来计算热量要靠谱多了。

文章里有句话说得特别好：在一个人类已经可以合成DNA、克隆生命的时代，我们却对跟我们生存息息相关的食物，知之甚少。

> > We can create synthetic DNA and clone animals but we still know incredibly little about the stuff that keeps us alive.

这句话，也是我们今天的金句。

最后说两点我自己的感受：首先，了解一个事物，除了要不闻关关注它最新的进展之外，还应追本溯源，理解这个事物的本质，看清它的本来面目；其次，我们正处在一个从平均主义向个性化过渡的时代，从前同质化、一刀切的思维，依然根深蒂固地影响着我们的观念。时刻警惕这种思维模式，会让我们活得更明智。
