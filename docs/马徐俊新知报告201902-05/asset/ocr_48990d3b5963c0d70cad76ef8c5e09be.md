# 今日报告：如何停止过度自我批判？

对自己狠一点，能让自己变得更强大。如果自己一直不消除这个脑海里那个声音，你的潜力就会受到限制。

> 《今日心理学》

![](bbox=[0.1, 0.22, 0.5, 0.24])

过度自我批判会让我们在长期的巨大的心理压力之下。它带来的危害，远比我们想象得更严重。

今天的议题分为两个部分：

+   * 过度自我批判的坏处
* 怎样停止过度自我批判？

不知道你最近有没有遇到这样的情况——当众发言后，觉得这个没有说没有说好，脑子里总是回响着一个声音：「我刚才的回答真是太差了！完了，别人得怎么看我！」

对，或者内心总觉得他们什么在不断地挑剔你自己。久而久之，让你的自信和勇气被自己给弄光了。像这样的时候，你就处在过度自我批判了。

我们都知道，过度自我批判会让自己不快乐，但是，怎么能够停止过度自我批判呢？最新一期《今日心理学》杂志的刊面文章，给出了四种应对办法。通过今天的报告，你会知道，它会对你造成哪些不好的影响？然后，我还会告诉你，怎么做才能把大脑里不断批评自己的声音，帮你拉回大度和自信。

![](bbox=[0.1, 0.51, 0.9, 0.65])

# 我们为什么会过度自我批判？

简单来说，一个人是否会有过度自我批判的倾向，与从小生活的家庭环境有关。

其实，每个人的脑海里都会有两种声音，一种是自我批评，一种是自己鼓励，但是有些人脑子里一个种自我批评的声音，它格外严重，压制了所有鼓励自己的声音。

美国心理学家马格利塔·福斯特 (Margalit Fodor) 认为，这种过度自我批判和孩子童年的经历密切相关。福斯特说，假如你的父母特别严厉，对他们的期望值都多于鼓励，那你会一直处于焦虑和紧张的状态，生怕自己犯错误。长大成人后，父母的指责就成为了内心的一部分。久而久之，以自己的责罚之身，我们就被自我给打自己。
