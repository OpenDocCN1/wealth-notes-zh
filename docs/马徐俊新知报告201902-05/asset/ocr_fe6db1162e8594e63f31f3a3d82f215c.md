游戏主播们赚钱的奥秘

最新一期《福布斯》杂志亚洲版，发布了全球最大的视频网站2018版游戏的一张主播收入榜单，在这张榜单上，收入最高的一位主播，每小时的收入几乎超过1500万英镑币，换算成人民币的话，相当于收入几亿。

排在榜上的主播你绝对想不到——是一名只有7岁的美国小男孩，叫Ryan，他专门拍玩具的开箱视频，他在YouTube上聚集了1700万的粉丝，年总收入接近2200万美元！

![](bbox=[0.03, 0.43, 0.97, 0.52])

总的来看，这十位主播发布的视频内容五花八门，有人做恶搞视频的，有做科技表头的，还有教人化妆的。但如果仔细看名单，你会发现，游戏主播竟然占了5个席位，完全将“看榜”的YouTube上一般人只能玩游戏的思维，这些人竟然在短时间内里就拿了亿万富翁。

这是怎么回事呢？《福布斯》从行业的角度分析了背后的原因。文章指出，游戏文化在年轻群体中的盛行，形成了观看游戏视频内容的庞大用户群；游戏视频的制作很简单，在生产上有突出的优势；更重要的是，YouTube的广告独特广告分发模式，让游戏视频的视频创作者可以直接变现，为主播们带来巨额收入。

这些因素叠加在一起，就把游戏主播营造成了YouTube上最赚钱的群体。

文章中有一句话说得特别漂亮：

> It pays to be a play.

这句话今天的一句话，还很眼，我把它的内涵来的一句话。这句话什么意思？就是告诉我们，可以看看玩游戏，玩游戏可以很赚钱！

# 当红游戏主播都是什么人？

纵观这次上榜的15位游戏主播，你会发现，他们有手无足同，有的是20-30岁的男性，白手起家，发布玩游戏视频，几年间就成为了亿万富翁。

比如名列榜首排名第四位的英国红人DanTDM（本名Daniel Middleton），他主打一款叫《Minecraft》的知名沙盘游戏，6岁时就吸引了超过2000万的粉丝，2017年甚至登上YouTube收入收入第一名。2018年虽然排到第四位，但也赚了1850万美元。截止到目前，他的视频播放量超过了1400亿次。

而粉丝数量最多的，要数瑞典游戏主播 PewDiePie，达到了惊人的8913万。他上大学时就在YouTube上开设了频道，火了之后就辍学专心做起了游戏主播。2013年，PewDiePie的订阅人数到2000万人，从300万一下子飙升到1900万，成为YouTube粉丝最多的频道。

至今，PewDiePie依然是YouTube上粉丝数量最多的主播，不过他之前闹出过一些争议和关于人的种肤歧视之说，引发了争议，今年排名滑到第九位。

![](bbox=[0.03, 0.97, 0.97, 1.0])

此外，上榜的还有加拿大游戏主播VanossGaming，今年25岁，在榜单中排名第7。他来自多伦多，是一个从小玩起游戏的游戏博主，他和PewDiePie一样，也是从大学辍学专心做游戏主播，最拿手的是制作一些游戏中的“猎杀式喜剧”，剪辑上很有创意。

紧挨着排名第八的是爱尔兰“恶搞”主播JacksepticeEye，霍雷利的人，靠游戏，但出名，有时甚至自带语音，但他深受粉丝喜爱。

而在这些人里，最励志的就要数排在第六位的Markiplier，《福布斯》杂志这次专门介绍了他。Markiplier是一位夏威夷小伙子，父亲是德国人，母亲是韩国人。2012年，他在罗德岛大学毕业时，遇到了一系列不幸：先是女友被车撞伤，然后女友跟医生分手了；紧接着他被打了一个大洞，没有多久，又发现自己身上长了肿瘤，不得不做手术。

接二连三的打击，让他的心情跌入谷底，决定要做点自己喜欢的事情。于是，他在YouTube上开设了一个频道。开始，他主要发一些恐怖游戏，因为有他声音很有磁性，听着就让人有一种阴森的感觉，但没想到让他火起来的却是解说视频。

为什么火呢？因为Markiplier的解说风格总是意想不到的。他长相时，留著恐怖游戏，但是玩恐怖游戏的时候，会故意玩梗玩小搞怪一样让人心惊胆战，他外表成了巨大的反差。而且他解说游戏的时候很丰富，时常妙语连珠，这也为他带来了大量的粉丝。

知道中国粉丝对他的爱称是什么吗？——“基哥”，意思是他很邪乎可爱。如今，Markiplier是YouTube上最大的游戏主播之一，去年的收入达到了1750万美元，真正从低谷翻身了人生巅峰。

你可能会猜得到，这些游戏主播能火，除了游戏玩得好，肯定也得靠个人魅力，这也很有趣，但也可说是一个种类别的YouTuber红，又有一个缺人力？所以，游戏主播们收入之高，背后一定有更重要的原因。

# 游戏主播们赚钱的奥秘

游戏主播能在YouTube上年收入排行榜上占据一半的席位，背后有着非常重的行业因素：一方面，游戏内含很多粉丝，让游戏主播很容易获得大量的粉丝；另一方面，YouTube独特的广告分成模式，让游戏主播的高人也能去赚取巨额。

为什么游戏主播会容易获得大量粉丝呢？首先来一个很重要的环境因素，就是游戏文化在年轻群体中的盛行。十几年前，游戏的基本是真正的游戏玩家，但随着游戏产业的发展，以主机、PC、移动游戏等多种平台游戏层出不穷，年轻一代已经形成了稳定的文化，从大到小，游戏已成为了男女都在玩着的游戏。

这些年轻人在YouTube上观看视频，游戏类的视频内容也成了一个重要的选择。有些人是来研究游戏实况，还有很多人就所谓的“云玩家”，自己不玩，就喜欢看人玩。这也就为什么这些颜值优秀、人又有趣的游戏主播就快速聚拢了观众的原因——够多好的游戏本就很赚钱了。

而跟其他类型的视频内容相比，游戏视频在内容制作上也是有易有难度，你会发现，它的录制剪辑难度都相对简单，主播只要拍摄自己玩游戏和画面即可。并不需要超好的剪辑。一条游戏视频的时长很容易超过1小时，但照片一看，一些游戏主播能到个20分钟，也是靠每天更新，比如时间对内容制作难度也很有限。

比如，有人无意间看了你的视频，觉得有点意思，再一看看你的背景，内容原来这么好，他可能去你视频里看，成了你的粉丝，而且，随着越来越多看到你的更新，粉丝粘性就会保持越来越久。

当然，真正让游戏主播们能日进斗金的重要因素，是YouTube平台特有的广告分发形式。这和其他视频平台不一样。国内做视频的广告方式，要么是靠植入打广告，要么是发放优惠券，但YouTube的做法是“合作伙伴”计划——允许内容创作者的视频，制作方参与广告，分成，平台占45%，制作方占55%。这个
