# 今日报告：爱尔兰为什么是英国脱欧的最直接受益者？

英国脱欧制造了一次鲜明的对比，它释放了不列颠的“恶魔”，却在爱尔兰头上增添了一圈夺目的光环。

> 《财富》

马德骏

原本在经济地位并起眼的小国爱尔兰，如今成了科技巨头、国际金融巨头离开伦敦后首先的落脚地。这是为什么？

今天的议题分为两个部分：

为什么爱尔兰能从英国脱欧中受益？

爱尔兰靠什么受到大型跨国企业的青睐

首先请你开一个脑洞：假如你现在是一家大型跨国企业的掌舵人，公司的欧洲总部原本设在伦敦，现在英国要脱离欧盟，你得当欧盟国家重新选择一个地方，把欧洲总部设过去。你会选择哪里呢？是德国、法国，还是瑞士？来先告诉你，在真实的世界中，多数大型企业和金融机构选择的国家，是爱尔兰。

听起来有点意外，对吧？一般人的印象里，爱尔兰在欧盟井不存在感并不算强。

它地处偏远，人口只有400多万，经济也尚未强，硬、没法跟多驾马车相比担

可奇妙的是，这个小小国家的能够收到大多数跨国公司的爱，谷歌、微软、苹果等科技巨头早早就在爱尔兰建立了分支机构。在英国启动脱欧程序之后，美林银行、巴克莱银行等大型金融机构也决定，把欧洲总部迁到爱尔兰去。

爱尔兰到底有什么魔力呢？《财富》杂志最新的一篇文章，深度分析了背后的原因。文章内容，爱尔兰具有独特的“软实力”——税率低、劳动力年轻化、母语为英语，还有极具包容性的社会文化。这几项代表因素集，似乎不不坏起，但它们在加在一起，立刻让爱尔兰在英脱欧带来的不确定性中凸显出来，成为了跨国企业离开伦敦后首选的落脚点。

《财富》认为，这跨国企业迁移的趋势将为爱尔兰带来巨大的经济发展机遇，甚至会让爱尔兰成为英国脱欧最直接的受益者。

文章说：英国脱欧制造了一次鲜明的对比，它释放了不列颠的“恶魔”，却也让爱尔兰头上的光环更加夺目。

```
Brexit is creating a contrast that hasn't existed before. It has unleashed Britain's demons and given Ireland a halo.
```

这句话，也是今天的金句。

# | 为什么爱尔兰能从英国脱欧中受益？

之所以说爱尔兰是英国脱欧最直接的受益者，原因简单：英国和爱尔兰为它制造了一个历史性的发展机遇。而这个机遇是谁带来的呢？是哪些选择把欧洲总部从英国撤出，迁入爱尔兰的跨国企业和大金融机构。别看半个举动，它们为爱兰增加了数以万计的高薪岗位，带来了巨大的经济活力。

这里面比较明显的例子是两家银行，一家是美国投资银行的沃尔济夫里姆银行，一家是英国著名的巴克莱银行。这两家银行不约而同地自从英国迁到爱尔兰，都把它们的总驻地从伦敦迁到了爱尔兰首都都柏林。单是巴克莱银行，迁过去的资产就达2150亿美元，而花旗集团，摩根斯坦利、摩根大通、高盛集团，虽然没有公开迁至都柏林，但也都承诺，会扩大它们在都柏林的分支机构的规模，来应对英国脱欧带来的不确定性。

另一波重要的力量是科技巨头们。其专家们上季不止一次说过，很多著名的互联网公司除了，在更早之前就曾经把欧洲部设在了爱尔兰，比如谷歌、微软、苹果和Facebook。不过，在英国脱欧这个重要的时间节点上，它们也都公布计划，要扩大在爱尔兰的投规模。

比如Facebook将挂在爱尔兰的办公室增加了四成，并打算1000名新员工，成为规模最大的海外分支机构；谷歌最近也在爱尔兰新建的1000名职员；还新建了一栋大楼用于计算机科学的研发；上世纪80年代在入驻爱尔兰的微软，近期将宣布计划增加2200名职员；苹果公司也将于爱尔兰第二大城市科克的总部分行扩建，员工从5000名增加到700名。

所以你看，英国这件事给爱尔兰带来的最直接的益处，就是新增了大批的就业岗位。英国官方据估计，因为脱欧的影响，英国将会损失12000个高薪岗位，其中大部分都会转移到爱尔兰去。

有一项统计显示，2018年各大跨国企业在爱尔兰的雇工加起来已经达到了23万名，创下了历史新高。新口看这23万名工，要知道，爱尔兰全国人口不过才480万。

换一句话，爱尔兰的外企员工，已经占了全国人口的近5%，这可是一个不得了的比率。更不用说，随着这些新增就业岗位一起来爱尔兰的，还有上万亿美元规模的资产。

为了顺这波浪潮，爱尔兰近两年也是大干快上。爱尔兰四大道高海地投资1亿欧元，建设一个占地将近8000平方米的办公楼综合体，位于都柏林著名高等学府三一大学正往在耗资10亿欧元建另一个占地3.5万平方米的科研区，计划容纳400家创司，希望借此成为欧洲的麻省理工或斯坦佛。

还有不少的欧洲科技企业，也都选择爱尔兰作为进入欧洲市场的又一始站。文章特意提到，中国企业小米将都柏林开设线下实验室。另外两家中国企业华为也与爱尔兰成了另一研究中心，华为还宣布将与三一学院开展人工智能等领域的深。今年6月，日本软银集团宣布，将在都柏林试点首个“智慧城市”模型。

即将上任的爱尔兰新首相西蒙·科文说：“爱尔兰已经开启了经济换模式”。数据也显示，爱尔兰连续四年成为欧盟增长数据最快的经济体。这背后是什么原因呢？

# | 爱尔兰靠什么受到跨国公司的青睐？

地处偏远的爱尔兰，为什么能吸引这么多企业？把它们的欧洲总部都设在这儿，《财富》认为它靠的，是自身的“软实力”。文章总结了四个关键原因，分别是税率低、劳动力年轻化、母语为英语，还有极具包容性的社会文化。

先来说低税率。爱尔兰的企业所得税在世界范内都是相当低的水平，只有12.5%，而欧盟国家的平均是19%，是21.6%。相比之下，英国是19%，虽低于欧盟平均水平，但依然无法和爱尔兰相比。

低税率，一个会雷下因来。因为对企业来说，它意味着省下一大笔支。所以就不难理解，为什么跨国公司都会选择爱尔兰了，因为省钱啊！。

不过，爱尔兰的低税率并不绝对优势。在欧盟国家，企业税率最的是不是爱尔兰，而是匈牙利，只有9%。可是，那些大企业并不是因为税率而选择匈牙利，可低税率并不是唯一的原因，这里面肯定还有别的因素。

什么因素呢？这就说到爱尔兰另一个吸引企业的优势——劳动力的年轻化。爱尔兰拥有全欧盟最年轻的人口，平均年龄只有35.9岁；相比之下，欧盟国家的平均人口年龄是42.8岁，跟着，这了45.9岁，是年轻的人口结构意味着什么？意味着更年轻、更有活力的劳动力。

同时，爱尔兰的教育质量也堪称世界少，国民教育高度普及，超过四成的成年人都接受过高等教育。那你年轻又高素质，这样优质的人才储备，哪个企业不想要？

这不就算，跟欧盟的其他国家相比，爱尔兰的驱动力有个极大的加分项，就是母语是英语。你可能觉得，现在每个国家没有一大堆英语好的人是不是一样。没有母英语，意味完全没有语言障碍，在商业上，这个优势能把沟通成本降到最低。
