# 1 这一次，欧盟打算如何对付硅谷？

3月20号，谷歌被欧盟开了一张反垄断的“小”罚单，罚款17亿美元，这是什么？17亿美元还是小惩罚？这个“小”罚单引出的，是相对于欧盟开出的前两笔大罚单。一张是2017年的24亿欧元，另一张是2018年的43.4亿欧元，这张17亿美元的罚单，确实算是小的，而另一个原因是，哪怕连续罚了谷歌三次，相比于欧洲潜在罚款，新数据监管，罚款是相提并蓄的。

要知道，一旦这部新的法令出台，很可能会影响到包括谷歌、亚马逊、Facebook在内的一大批科技巨头的盈利模式，甚至是未来的发展方向。而这处罚的主要目的，就是从反垄断层面，对付科技巨头们。

你可能有印象，去年，欧盟曾经出台过名叫《通用数据保护条例》（GDPR）的规定，号称是上最严个人数据保护条例，目的是保护网民的个人隐私，防止信息被滥用。在这个条例生效前，各大科技公司风声鹤唳，在用户们被卷进了一场大危机数据保护，用户们开始被更新了一次隐私政策。

如果说去年的GDPR算是起到的敲山虎的作用，那么目前欧盟准备推出的的《数字单一市场战略》，在对互联网巨头，带来的将是“灾难性”的冲击，因为这部法令的核心是保护原创新内容，它规定，网络的标识平台，在抓取内原创的时候，需要向内容提供商付费。换句话说，以后谷歌、facebook，不能再看自己别人家的新闻和内容了，得掏真金白银来购买。

一旦这个法案修订成功，至少在欧洲范围内，互联网内容免费的模式就是覆之到尽头，而这部法案的矛头，可能又重复到其他国家和地区，到那时候意味着免费资源流消耗自己的信息科技巨头，就必须重新构建起自身的生态系统、商业模式。

你可能会说，这部法案有这么大的威力吗？答案是，可能确实挺有的，因为它会影响的，是科技巨头们的重要收入来源：广告。

# ｜ 科技巨头的命门是什么？

我们都知道像谷歌、Facebook这样的公司，最大的收入来源就是广告，但是究竟是它是怎么靠广告赚钱的，你可能就不能说得清楚了。你说，不可，没有什么说不清的，不就是靠点连接，科技公司向广告商收钱吗？没那么简单。

![](bbox=[0.2, 0.0011799999999999998, 0.8, 0.00122])

请注息上面这张示意：科技公司的平台通过用户在手机app和网页上的点击，获取用户的点击数据，搜集这些数据在公平台上，会绘制出用户的肖像，你是怎样的一个人，什么兴趣，什么爱好，会有什么偏好，会想，相当于生成了一个虚拟世界，你的。在形象，然后广告商利用它，向你卖广告，引起你购买行为的可能性有多大，你花多少钱会掏钱给广告商，最后广告商通过比投的竞价，出得最高的就能获得你购买广告的权利。

不知道你听到这种模式是什么感觉，反正我是觉得挺不舒服的，我一向关注在人工智能，认为这是人工智能，这是一回事，那些广告商：网页和app通过吸引我点击的方式，关注我，在虚拟世界吸里售卖我的喜好和注意力，还竞价拍卖，我可没答应过。

但根据文章里的数据，除了苹果公司稍微好一点点之外，像谷歌、Facebook这种，以广告作为主要盈利模式的互联网巨头，走的是这条路子，亚马逊也差不多。

你为什么会这么难呢？你想，既然科技巨头是靠商业模式的第一步，就是吸引用户的注意力。欧盟通过获取拉注意力，向原创内容付费的方式，给注意获取了注意力的公司，让后续的商业模式链条，跟着使用着水船崩。这种方式可能在全消项全网竞价广告，但会大大削弱广告商，对于广告商的吸引力。加上上到GDPR用户对隐私的保护，科技巨头来说，在欧洲的日子确实会变得更难过。

你可能会奇怪，欧盟这些手段，对硅谷有那么大的杀伤力吗？根据《经济学人》的看法，答案是肯定的。因为欧盟是硅谷非常重要的海外市场，占到了巨头们总收入的1/4，而且因为欧盟自己没搞特别强悍的科技巨头，根本成气候，全世界排名第二的科技公司，欧洲只有家，排名靠后的200名科技公司，欧洲只8家，这反射到欧盟强大的创新空间，既收不到自己的企业，那没说道理要手下面倒。

更何况，欧盟在世界范围内的影响力很大，它出台的法律法规，会被很多国家和地区当做模板参照执行，但看起的欧盟的法规覆盖的是52个欧洲人，产生的外溢效应，才会波及到全世界，会到《经济学人》，才说，欧盟的决定，会影响硅谷的未来。

但听到这里，你可能会有一疑惑了，那就是欧盟为什么要帮的事啊？这些科技巨头都在美国，它们有理由，要管这些美国的监管机头手，欧盟却总是一依不饶的，这是为什么呢？

# ｜欧盟为什么不放过硅谷？

根据文章的说法，欧盟之所以对硅谷的科技巨头穷追猛打，欧盟之人看竞争、处理大公司垄断的方式，从根本上是跟美国人不同的。

在过去的十几年里，美国对待大公司垄断的方式，主要参考着法学家德雷福斯的思想，那就是限制政府的监管，只有在极端情况下出手干预，因为之拉哥学派的经济学家们认为，市场会通过竞争来解决，最终将那些垄断曾创的市场，比如在Facebook出得之前，统治美国网络社交的MySpace，但是，这家公司最终还是被激烈的市场竞争淘汰了。
