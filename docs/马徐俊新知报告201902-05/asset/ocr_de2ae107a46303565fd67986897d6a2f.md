# 今日报告：智能音箱带来的“后隐私时代”

> 我们当然不可能回避废食，彻底远离所有的科技产品，这既荒荒唐难以实现，也让我们依然可以在方便和隐隐私之间做出一些平衡。

马徐佳

你家里的智能音箱，或许给你的生活带来了很多便利。可是你怎么知道，它并非生活里的一举一动、一言一，没有被它偷偷地记录下来呢？

今天的议题分为两个部分：

+   - 从“看得见”到“看”得见
- 后隐私时代的安全威胁

今天咱们来讲讲本期《经济学人》的封面推荐文《你的智能音箱是多恶的人》( How Creepy Is Your Smart Speaker?)。其实关于智能音箱的话题，咱们专栏已经聊过很多次。但这一次，《经济学人》以智能音箱为切入点，探讨了另一个更严重的问题：以智能音箱为代表的家庭数字设备，可能会把隐私生活的决策置于全面的监视和控制之下，这可能会把我们彻底带向一个“后隐私”时代。

通过今天的读，你会了解到这样几个问题：下一代智能音箱的技术升级会往什么方向发展？为我们既需期待也而来的隐私问题？为了应对突如其来的威胁，可能会让我们暴露在什么样的风险之下？

# 1 从“看得见”到“看得”见

这两年智能手机的出货量开始疲软，就连苹果公司的iPhone销量都未创出新高。你如果想不到，智能音箱的出货量却创下了新高。

根据《经济学人》提供的数据显示，去年全球智能音箱的销量整体翻了一倍，达到了8千6百万台以上。其中亚马逊、三星和谷歌这三大科技巨头占了大部分。但你认为，销量好的主要原因？也许你误了，科技巨头们看中的是，智能音箱在家庭应用场景中的枢纽地位。

长久以来，科技公司都渴望能有一款产品，能够深度融合人普通人的家庭生活中。控制各种家用电器，收集数据，研究用户的行为模式。为此科技公司曾经研究过智能洗衣机、电冰箱等能智能化，但始终不成功。是啊，谁会想要一款会说话的洗衣机呢？

而智能音箱的出现，可以说是一款令它们梦寐以求的产品。不但能让人不必用双手输入的情况下来提，交互方式还非常方便，简直就是使用魔法咒语一样神奇。只需说出你的提需求或者提问，就可以点播自己想听的音乐，或者问到问题是梅西进球多，还是C罗更厉害这样的问题。

不少用户甚至家添置多台智能音箱。这也使科技公司有更加充足的动力，来的技术开。目前的智能音箱以语音交互为主，说白了就是“听觉”，下一代技术将会“视觉”，但并不会像摄像机那么简单，而是使用激光雷达技术 (lidar)。

今年5月6号，在英国格拉斯哥的会议上，来自美国卡内基梅隆大学的两位教授克里斯·哈里斯的成基提克特，发布了已研究的成果——一项叫做SurfaceSight的新技术。

这个技术从自动导航领域最常用作的激光雷达应用已经能看到的，可以通过接收从扫描器发射到周围360度的环境以及空间里发出的光线。有了这项技术，智能音箱不仅仅仅能“听觉”到用户，也可以“视”到用户，并且做出相应对反。

比如你可以用手势来切换歌曲，在使用PPT演讲的时候，你可以放屏幕直接用手势来控制演示文档；智能设备也可以根据同里人数的多少，来自动调节环境温。

文章里提到一款在测试中的应用App，它可以通过扫描“看到”做菜的料是香吉，以味来做出美味的业果。或者这款应用使用整理书桌的时候，将大行小出时分的公，包就帮你大大减少忘东西的尴尬了。

你可能会说，这是很好。但这就科技改变生活！但《经济学人》也担心的是，智能设备在使用的生取信息越来越多方便，也在使用取用户隐私变得越来越方便。

# 1 后隐私时代的安全威胁

其实，科技公司的产品是否有侵犯用户隐私的嫌疑，这个问题一直是有争议的。就拿智能音箱来说吧，表面上看去，只有用户说出关键词的时候才唤醒它，但你又怎么知道，自己日常举止中一些举动、或者私密的谈话，有没有被偷偷记录下来呢？

退一步来说，现在生产智能音箱的厂家这么多，就哪家大公司都知道，大公司会不会怎么呢？要知道，能够掌握大用的户数据，对于研究用户行为是非常有价值的。比如拿苹果公司使用开发的音分析技术，叫bOland sonification，它可以将各类户使用时候发出不同的声来识别出用户，无论是在打开一副新的开，还是你的开一常幕片，或者向你推荐你的产品，又或者是在关品打你的时候通知到你。

细想一下，没有觉得恐怖吗？这相当你被置于严密监视之下，就一个沉的观察者一直在不地你身，记录你的一举动，发云端情况行分析，随时准备对你。在这种境况下，我们还有什么隐私可言呢？
