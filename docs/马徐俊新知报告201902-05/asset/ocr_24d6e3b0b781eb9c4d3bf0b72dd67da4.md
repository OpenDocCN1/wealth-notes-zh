# 今日报告：帕金森症竟然可以闻出来？

超级灵敏的鼻子，正在为我们打开一扇疾病诊断的新大门。

——《新科学家》

马徐骏

每一种疾病都有独特的气味，比如帕金森症是一股烤香堆、阿尔兹海默症有点香，而癌症的气味闻着就像湿掉的泥土里采来的酸菜，这些气味背后，是待发现生物标记，它们可能成为疾病诊断带来的突破口。

今天的阅读分为两个部分：

+   *   帕金森症是怎么被闻出来的？
*   超级嗅觉开启疾病诊断新方向

我们，知道，很多疾病是早期发现，越好治疗。很多人每年都会去体检，要拍CT、验尿等，都是为了查看身体有没有潜在的问题。不过，最新一期《新科学家》杂志报道说，科学家刚刚找到一种更简单诊断方法：鼻子。他们发现，一些人体有特殊气味，超嗅觉鼻，可以直接闻出帕金森等疾病。

不可思议是吧？在医学界，从没听说过帕金森患者身上有什么气味。更何况，人类嗅觉也不上多么灵敏。可神奇的是，对拥有超级嗅觉的人来说，每一种疾病都有自己的独特的气味，比如帕金森是一种香饼干的味道，阿尔兹海默症有点香，而癌症的气味闻着就像从泥土里采来的酸菜。

对于这件事，科学家原本不太相信，但经过了跨测试之后他们发现，靠嗅觉识别疾病的准确率竟然相当高。

英国曼彻斯特大学的科学家们展开进一步研究，最新的结果是，他们发现帕金森患者有一些新的生物标记，而这些生物标记很可能就是“特殊气味”背后的原因。

目前，他们正在研究如何利用“超级嗅觉”，来提高诊断准确率，如果能在症状出现之前就患者患者身上的气味，那无疑会大大提高疾病的治愈率。

用《新科学家》的这篇文章里的话来说就是：超级灵敏的鼻子，正在为我们打开一扇疾病诊断的新大门。

The incredible nose is leading the way to new diagnostic tests for diseases.

这句话，也被选为为今天的金句。

# 帕金森症是怎么被闻出来的？

刚才提到的那些拥有“超级嗅觉”的奇人中，有一位叫乔伊·米尔恩（Joy Milne），是一名已经退休的女护士，生活在英国。她第一次注意到这种气味，是多年前在她丈夫身上闻到的。

当时发现，丈夫杰森身上突然开始散发出一种香味，像烤香饼干或者油腻的味道。她说这种气味很不喜欢，自己很排斥，于是米尔恩坚持，为自己洗个手。可除了米尔恩，别人也没说他身上有什么怪味，于是这件事就不了了之。

直到12年后，时年45岁的杰森被诊断出帕金森症，米尔恩这才意识到，她当时闻到的气味可能不寻常。

此后发生一件事印证了米尔恩猜测：在米尔恩新认识的金森患者米尔斯，夫妻俩参加了一个互动小组，小组里全是得了帕金森症的成员。在现场，米尔恩身上又闻到了一种奇怪的气味。只是米尔恩身上这种油腻腻的味道，整个房间几乎都充斥着这股味。

借着分发茶水的机会，米尔恩又仔细嗅了一下——果然，每一位帕金森患者身上都有这味道。米尔恩此时瞬间明白了，这些都是帕金森的“特殊气味”。如果说，是这样的话，那12年前，她的丈夫可能就已经有了帕金森症的苗子了。只是当时谁都没发现，维思摩的鼻子就是闻到的原因。
