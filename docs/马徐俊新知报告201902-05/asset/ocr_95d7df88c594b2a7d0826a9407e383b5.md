# 今日报告：头等舱为什么“失宠”了？

像阿联酋航空这样的公司，得想些办法来让旅客付更多的钱，并且让头等舱物有所值。

——《经济学科人》

《经济学科人》指出，有钱人越来越少，头等舱似乎受到消费者的冷落。这是怎么回事呢？

你可能也有过这样的感觉，现在的有钱人越来越少了，多到什么程度呢？根据《福布斯》杂志的测量，全球拥有身家亿美元的家庭数总计超过2100位，在过去二十年年翻了5番。专门为有钱人提供服务的行业，也发展得如火如荼，根据弗劳新迪研究机构的估算，亚洲的豪华酒店数量在未来十年内可能增长168%。

航空公司也看着这个势头，大力向高端拓展，不惜重金提升它的档次。比如说在阿联酋航空的A380巨型客机上，头等舱甚至配备了可淋浴的私人套房。阿联酋航空的竞争对手阿提哈德航空，不仅推出过奢华的商务舱，还投入了大量的资源进行营销推广。像这样的超豪华头等舱，这家全球一共有10个，可供的营销费用，比剩下的3万个其他头等座位加起来还多。

按照这个趋势，是不是头等舱也要变得越来越贵，为航空公司带来更多的收入呢？有趣的是，答案恰好相反，头等舱的盈益越来越少，反而降低了。在过去的十年里，美国大部分长途航线提供的头等舱数量，都出现了20%～40%的下降，幅度非常大。除了美国之外，其他航线，新加坡航空，都取消了头等舱，就连土豪的阿提哈德航空也开始砍头等舱了。根据行业分析师们的预测，头等舱可能马上就要消失了。

为什么会这样呢？《经济学科人》发表了一篇长文，解释了这一现象：头等舱失宠的背后，既有航空公司自己内部的战略问题，也有市场趋势变化和乘客观念变迁的原因。

# | 头等舱失宠的内部原因

头等舱“失宠”有三大内部原因，分别是经济舱的扩张，商务舱的升级，以及头等舱光环效应的减弱。

我们先来看看第一个原因——经济舱的扩张。贝克咨询公司的杰弗里·韦斯顿（Jeffrey Weston）认为，头等舱失宠的一部分原因，要怪航空公司自己。正是由于航空公司推出了大量经济舱，座位越来越便宜，使得旅途的时长越长，旅客有越必要——反正航班时间也不长，何必多花几倍的价钱买头等舱？如今，大部分头等舱的老顾客，都选择去坐经济舱了。

你觉得座空间不够？没关系，可以把旁边的位子也包下来，用横向的空间来弥补纵向的不足。至于其他的服務，像贵宾休息室、高档餐饮这些就更好解决了，只要多花点钱就能买到。这些费用全部加在一起，也比一张头等舱的机票价要高得多。所以，对于短途航线来说，头等舱就显得很鸡肋了。

第二个原因，也要怪航空公司自己。它们为商务舱提供了与头等舱类似的整体。商务舱的旅客也可以躺平到睡觉。原本，剩下睡席位，是头等舱特有的卖点。如今看来就有些多余，如果睡一晚的酒店钱。然而，在2000年，美国航空公司也把商务舱也开到能躺的座位。随后，其他航空公司也开始效仿放贷。这让头等舱的尴尬加剧了。企业旅游高管凯斯的前执行总裁格里·科赫（Greeley Knoch）说，大部分公司都认为，二级商务舱已经舒服得够了，只有少数的高管才能享受经济舱的舒服。

升级商务舱还带来了一个副作用，就是头等舱作为升级的奖励也不那么吸引人了。以前，很多航空公司为了增加用户黏性，会给头等坐飞机多的旅客，提供免费兑换免费升级的奖励。如今，既然差距都不大，头等舱也就没那么吸引人了。

第三个原因，是头等舱自身“光环效应”的减弱，使得航空公司减少了光花投入。什么是光环效应呢？就是如果高高，旅客就会对这航空公司有非常好的印象。进而认为它的经济舱也比别的家贵多。

像他们刚才提到的阿联酋航空的竞争对手——阿提哈德航空，头等舱顾客打造了世界上最豪华的“空中宿舍”，里面包含起居室，独立双人卧室加配套的浴室。同时前面还设有10种餐的休息室，整个阿提哈德航空只有10个，可它营的费用，比剩下的3万个座位加起来还多。可如今，随着高等舱的需求量越来越小，航空公司都不再相信头等舱的光环效应，从而减少了对头等舱的投入。在2014年，法国航空-荷兰皇家航空集团的首席执行官，亚力山·朱尼安克就说，生产部航力量就是个愚蠢的营销手段，没人能从它身上赚到钱。

可以说，航空公司自身的调整，比如说推行廉价座位、升级商务舱，再加上对头等舱的投入越来越少，这些因素导致头等舱再也不像前些年公司那样的香饽饽了。其实，除了这些内部因素外，外部因素也加速了头等舱的失宠。

# | 头等舱失宠的外部原因

导致头等舱失宠的外部原因，主要可以归结为两个，一是顾客消费观念的变化，二是民航飞机市场趋势的变化。

首先，我们来看看富豪们的消费观念是如何改变的。在过去一百年中，中国、印度和英国的一些科技中产中培出了一大批超级富豪。可这些富豪并不愿意消费。丹麦咨询公司ReD Associates的ceo罗伯特·瓦斯塔德（Charlotte Vorgaard）说，这些富豪新富大多来自技术业，他们希望子女能和自己小时候一样，在一个普通的中小郊区环境中长大。所以他们也很少和家人订的座商务舱的。所以他们甚至是经济舱的。

其次，从飞机的市场发展趋势来看，头等舱遇到了两个强劲的竞争对手——私人飞机和小轻型机。私人飞机的一大好处是，老板们想飞哪儿就飞哪儿，不需要照固定的航线起降飞机面。而且，私飞飞机的安全性比起大航班强得多，因为它自的航班量，进去就能安检，出来就能飞，省时的又省心。如此，现在的私人飞机过去太便宜多了。私人航班公司Privatefly的CEO迈克尔·威廉森（Adam Twidell）告诉我们，现在有两种新的私人飞机使用方式，一种是“产权共有”，就是几个人共有一架私人飞机。一种是“租赁”服务，像打车一样随用。这两种新的使用模式，使得私人飞机的费用可以平摊到极大，大大降低了成本。换句话说，能用得起私人飞机的富豪们，谁进去买头等舱啊？

除了私人飞机以外，头等舱的另一个威胁来自小型客机。现在，航空公司越来越倾向于，更小巧灵活的喷气式飞机，导致没有多余的空中客去打造头等舱。曾经以生产豪华飞机著名的波音，已经减少了大型客机A380的订单，转而购买了70架较新的A350和A330neo。这对了座机A380的最后和一架机在2014，A380的最后班机空中客车公司Airbus宣布，从2021年开始，将停止生产A380这个巨无霸机型。这样一来，飞机上就没有充足的空来提供“私人套房”或者“空中宿舍”了，头等舱的优势也基本丧失殆尽。
