# # 225报告：AI会重塑人类情感模式吗？

> “我们不能仅仅把机器当做我们的创造物，而应该把它们视为一个参与社会互动的新阶层。”
——《大西洋月刊》

今天的议题分为两个部分：

AI如何影响人类的情感体验和互动体验

近几年人工智能的进展，带来了更多关于“机器的想象”，如果聚焦在机器人类社交，就会引起这些思考，如大模型等新的机器人之间的交互。如今，AI会参与人类的一些互动和关系吗？AI社交，会不会让人类的工作变得威胁？再或者，人工智能会不会有一天彻底取代人类？

其实这些问题未必近，也缺少了一个重要的参考坐标，就是人工智能，作为一个“逐渐渗透进人类社会方方面面的新技术，会如何改变人与人之间的关系。

4月1日《大西洋月刊》的一篇重点文章，就从这个视角对当下的思考者做了阐述，提出了它的看法。这篇文章的作者，是尼古拉斯·克里斯坦，他曾是哈佛大学社会学系自然学院的高级研究教授，他的本职工作，既是一位社会科学家，也是一位社会学家。克里斯坦教授曾经过出过一本书，叫做《蓝图：人类社会的进化起源》，他对于“新技术是如何重新定义和改变人类之间的互动关系”这个问题，有很深的研究。

克里斯坦教授说，500年前，城市出现了人类社会，群居性形式在很大程度上奠定了人与人之间的互动方式，而之后，无论是印刷术，电报，还是互联网的出现，都对于人类互动方式有过深远的影响，这些技术并非改变“social suite”的社会能力，他称之为“social suite”。它不仅包含对社会的中文诠释，你把它理解为人类关于爱恋、友、合作和教育的基全模式。

克里斯坦教授说，social suite是你无论生活在世界的哪个角落，成长于哪种文化。在使用现代科技，都共有的社会互动行为。它不是智能的产物，可能会彻底改变我们的social suite能力，重新塑造人与人之间情感合作的模式，和情感亲与亲情，爱情的方式。

你可能会觉得，会不会太夸张了？好，如今就有两个实验，克里斯坦教授在向我们揭示这个观点，通过刚才的会议你会知道，人工智能对于人类的和合方式、情感和性体验以及缔结友谊的方式，产生了什么样的影响。

# ## AI如何影响人类的合作？

克里斯坦教授在文章里说，AI既可能大大改善人类的合作，达成更好的合作形式，也可以彻底破坏人的合作。把好人变成混沌。

我们先来说改善的方面。克里斯坦教授给出了两个实验事例，第一个是他领的团队在耶鲁大学实验室进行的研究，他们让参与者与一些AI机器人协作，做“火车任务”：当AI机器人被设计会时不时出错，而这些错误的时刻，机器人不会主动承认自己犯的错。“不好意思啊，机器人也会犯错的，多多包涵。”而另一个对照组里，机器人犯错的时候，只会干巴巴地告知参与者：“出错！出错！出错！”

结果你猜怎么着，表现机器人那组，参与者的体验更好，看机器人的方式，促进了参与者彼此间进行更多交流，团队气氛也更轻松，甚至还会从此开玩笑。

另一个实验的规模更大，克里斯坦教授的团队，招募了400名参与者，每20人分成一组，有些组被要求跟机器人协同完成任务，有些组是人不跟机器人，有些组机器人不有犯错，但没有任何提示，结果反而是犯错机器人的团队氛围更轻松、合作更好，表现也更出色。从这两个实验里，克里斯坦教授得出的结论是，人机协同的系统，如果人类表现出更频繁互动，最终结果就会更好。好的人工智能设计，可以加强人与人之间的关系。

文章里说这怎么改善人与人之间合作呢？实验里做了一个小实验，参与者团队被要求在一些游戏里，可以选择留下每一轮，每个参与者都可以使用固定一笔钱，或者一部分资金，甚至全部的资金，放在公共金库里，而接着游戏，金库的钱会给所有人。在游戏的最后，2/3的参与者都选择留下，而留下的人越好相处，很容易在下一轮被期望为好人更会捐款来报告。然后研究员在游戏里，放进了一些资金金库的AI程序，这些“假人”只会贡献，不回报他人，只让其他金库被破坏。几个假设，如果破坏了信任与沟通，参与者团队也会协作，把利普好人变成了自私的混沌。

克里斯坦教授说，协作是人类社会的基干，信任对他的作用，是成功团队的显著特征。这个实验的结果，也值得我们警惕，一旦和协同被坏的AI给破坏，信任被破坏，所有参与者都会因此被影响。

# ## AI如何影响我们的情感和性体验？

英国伦敦大学的人类学家琳赛，做了很多关于机器如何影响人类情感和性行为的讨论。她的结论比较悲观，她认为，正在被AI的泛滥，会破坏人类之间可贵的亲情和性体验。而且法让但满足自己有的情感和亲密性需求，但与此同时，人类似乎开始寻求人类。机器德查让人类失去与人类交流，不愿与人进行正常的沟通与交往。

但也有人对此有不同的看法，《与机器人，性与爱》这本书的作者丹·利维认为，性爱机器人不容易携带病毒，不会染上疾病，既像正常人一样，对于那些格外内向的人，无法跟真实人交往的人来说，跟性爱机器人的互动，会是一个好的学习过程。

如果我们能渗透到人类的情感领域还很浪漫，那下面我们来看一看已经发生的改变，下面是今天的第三部分，正在发生的变革。

克里斯塔诺教授提到的一个重要的趋势，我们在斯坦福也接到过，就是智能音箱的普及。我们认为未来会把智能音箱当做玩具，但孩子们长大后，会被智能音箱陪伴，成长起来的下一代人，他们从小习惯了给AI下达指令，得到满意的回答。

人工智能对孩子来说，是个伴侣，也可以有个专人，孩子都是某个必备的物质。被AI陪伴着长大成为，我们着他们和机器的方式，会有根本的不同，也会影响到他们之间相互互动的不同，他们会变得更孤？更自私？甚至，干脆就不爱跟人类互动了？

而这种情已经发生了。去年《大西洋月刊》的另一位作者，史凯尔·史密斯，就写了一篇文章，现在很多AI人工智能当倾诉的对象，甚至视为自己亲密的伙伴，替代心理医生，就已经史凯尔说自己都承认，多地人会跟历史大开口说的话，会对谷歌的吾语道手。

在读到这段的时候，我脑海中浮现出阿西莫夫科幻小说《基地》里的一情：未来人类各自生活在四方百口之间，见不到其他人，只有跟机器的机内交流，与人类不相同，他们在机器的簇拥下，成为自己藩地的主人。

这种对于未来的想象，在人工智能高速发展的今天，向现实靠近了又大一步。

# ## 总结

克里斯塔诺教授关注的是人工智能掀起对人与人之间关系的思考，他另一个角度与我们展望了AI可能带来的影响，无论是人类的新模式，还是爱情，友情，爱情，都会是彼此影响的场景。克里斯塔诺教授认为，未来，我们甚至要有要重新人类智能社会的社会契约，来保证我们自身的“social suite”。

就这篇文章里说的，我们不能仅仅把机器当做我们的创造物，而应该把它视为一个参与社会互动的新阶层。
