# 今日报告：人类会“污染”火星吗？

人类首次发现的外地生命，可能最终也是由人类自己一手消灭的。

——《发现》

马徐骏

人类在探测外太空的过程中，必须加倍小心，把自己带来的影响考虑在内，否则很可能亲手把事搞砸。

今天的议题分为三部分：

+   - 科学家为什么担心火星被污染？
- 火星被污染会带来什么后果？
- 防范措施为什么行不通？

人类离探究火星越来越近，就现在来看，NASA计划发射在2033年实现载人登陆火星，SpaceX等商业公司也积极推出了探索火星计划。不过最新一期《发现》杂志说，现在科学家意识到，人类某些活动会给火星带来污染，而最大的污染源，就是人类自己。

为什么说呢？因为人体中存在大量微生物。科学家普遍认为，火星上有生命的可能性，但即便存在生命，也是微生物级的生物，而人体恰恰会携带数以亿计的地球微生物蔓延火星。不要小看这些微生物，它们的生命力和抵御极端环境的能力可以人类最强多。地球上的微生物，很有可能会在火星上存活下来。

这就会导致一个严肃问题。你看，要是人类有一天在火星发现新的原始生命，那还怎么确定原来到火星上的原始生物，还是人类带去的微生物吗？万一宣布“人类首次发现地球外生命”的重要消息，结果仔细一看，竟然是来自地球的微生物，岂不是闹了个大乌龙？

还有一种更可怕的结果是：地球上的微生物入侵成功，抹除了火星上的原始生态系统。这又置人类于何地呢？

就像文章里说的：人类首次发现的外地生命，可能最终也是由人类自己一手消灭的。

> "In our search for life, we might be responsible for the extinction of the very first alien biosphere that we detect."

这句话，也把它为今天的金句。

# 科学家为什么担心火星被污染？

之所以会担心火星被污染，是因为火星的独特价值：它是人类最有可能是有发现地球外生命存在的地方之一。别看火星地表环境恶劣，但火星的地表之下存在着大量水冰。大家都知道，水是有生物存活的主要条件。科学家据此认为，火星上可能有生命存在。而怕被污染的，恰恰是这些地外生命。

什么污染呢？微生物。以火星的环境条件，不可能支持大型生命体的存在，所以即便有生命存在，也只能是微生物级别的生命形式。目前的推测是，火星数十亿年前有过适宜环境，那时很可能有原始的生态系统，虽然后来环境巨变，但这些生物依然很可能残存于火星地下的冰层中。

如果是这样，那麻烦就大了。因为人类探索火星的活动，会难以避免地携带地球微生物进入火星。在月球上，微生物很可能在肉眼看不见的尺度上，与火星上的微生物展开一场你死我活的战争。
