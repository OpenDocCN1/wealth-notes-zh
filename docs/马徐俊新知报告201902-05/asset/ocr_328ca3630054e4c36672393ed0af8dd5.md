# | 总结

退休危机的出现，迫使人人们对于当前的社保改革思路进行重新思考：把养老逐渐变成需要个人承担的责任，虽然减轻了政府和企业的经济压力，可长期来看却带来了严重的副作用。美国的401(K)计划就是如此，表面上看赋予了企业和个人更多的选择权，貌似各方都受益，但这种“自由度”恰恰成了一把双刃剑，为退休危机的出现推波助澜。

其实我们中国也面临着相似的困境，这两年媒体上对于养老金账户亏空和延迟退休年龄的讨论不绝于耳。再看很多中小企业，只愿意给员工按照最低的标准缴纳社保，更别说有什么企业年金之类的补充养老计划。这一切都说明，退休危机其实离我们并不遥远。

如此看来，美国老年人陷入的退休危机，应该成为一面镜子。在全球都普遍进入老龄化时代的大趋势下，让老年人能安享晚年，不再因为迫于生计而坚持工作，是全社会共同的责任。毕竟我们都有老去的那一天，这件事，关乎着我们每一个人的未来。

# 划重点

+   今日得到:
1. 美国的老年人陷入了退休危机，美国政府提供的两种养老金方案，都无法给他们提供足够的保障。养老保障从一种社会共同责任，变成了“自己对自己负责”，而老年人并没有为此做好准备。
2. 逆转“养老靠自己”的观念，有几大要点：企业不能随意中断或取消401(k)计划；401(k)计划减小自由度，不能允许参保人提前支取；取消社保基金的缴费上限，对超标准缴纳的高收入群体征收更高的“社保税”。
