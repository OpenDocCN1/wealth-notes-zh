# ■亚马逊怎样优化线下业务？

亚马逊的线下业务，主要包括一个“云”和一个“店”。“云”指的是亚马逊电商商，包括亚马逊运转的物流中心；“店”指的是亚马逊无人店 Amazon Go，它承载着亚马逊对线下零售的未来探索。

亚马逊电商业务估值高达2070亿美元，它是亚马逊最大的利润，而电商业务的营利运转，比如货物的存储、物流和配送，还有亚马逊两天之内送达门口的服务中心（fulfillment center）。《经济学人》介绍说，亚马逊在全球有超过160个巨型物流中心，其中光是北美地区就有超过100个。

那亚马逊是怎样利用人工智能来优化仓储物流的呢？具体来说，亚马逊通过使用了人工智能的仓库机器人，进行仓储物流的自动运输。来实现高效率和低成本。亚马逊在2012年，收购将近8亿美元的机器人公司一家初创科技公司，并把它收购后改名为Amazon Robotics，而这家中文就是亚马逊机器人。

亚马逊机器人为仓储而生，它长得像一个橘色的扫地机器人，身上还装着一个不修边幅的支架。它们到处移动，却不会彼此相撞。亚马逊把这个货架叫做“豆荚”——Pods。

亚马逊机器人的引入，为亚马逊的仓储物流带来了大变化。首先，它改变了以往货物仓储的方式，效率更高，仓储空间实现了完全的自化，这就不需要给人留下通道、地方，货架的密度更高，可以装更多的货物。

我人工在管理仓库时，会分门别类地摆放货物，这样的方式，而机器人的方式是，机器人是根据自己的记录系统中的位置，精准找到货物。它们根本不在乎，也不需要时间专门识别类别摆放货物。

其次，亚马逊的物流运转，彻底从人为了效率，整个仓储区实现了无人化与自动化。人类工人在仓储区外围固定的工作站，当需要补货时，仓库机器人会带货到接站，补充货后，自动移走。当需要送物品，也不需要人跑前来取，装配对应货物时，机器人会把配送站，把货物都送进仓库里就可以了，就像原来物流配送只是货架，这样的原来的货物中心化，变成配送中心化，既降低了货物仓储和分拣的成本，也大大地提升了效率。

这听起来是不是已经很强了？但亚马逊的自我优化并没有止步于此，它们又进一步地做出改进。原来货物，配货员都会拿条形码扫描，来识别货物和相关的信息。

在系统中，都有清晰的记录。而现在，亚马逊将计算机视觉技术和机器学习结合在一起，配送站只需拿起，在新近安放的扫描仪上扫一下，放在货箱子里，机器人就能自动记录物品的位置了，不用配货员再去扫描箱子了。

根据亚马逊首席机器人专家布拉德·波特（Brad Porter）的介绍，他们接下来的目标，是利用人工智能优化“豆荚间隙”。
