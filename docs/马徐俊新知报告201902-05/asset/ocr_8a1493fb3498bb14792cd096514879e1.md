# 今日报告：人类什么时候有了家？

有了火，人类就有了光和热去野营的底气，火在同一个地方共同生活，这个地方叫做“家”。

> 《新科学家》

+   - 马克维达

“家”是人类进化的结果，它不仅是物质上的进步，也是精神上的飞跃。

今天的议题分为两个部分：

+   1. 谁建构了“家”的空间概念？
2. “家”的意识是如何形成的？

一想到家，我们总联想到温暖的被窝、热腾腾的饭菜和家人的呢喃。那么“家”这个概念是怎么来的呢？是不是自行有了人类，就有了家呢？

最近，《新科学家》杂志就家的起源发表了一篇专栏，标题叫做《石器时代的家居生活》。文章综合了伦敦大学的考古学家马特·佩南、英国南安普顿大学的考古学家克里斯·甘布尔等学者的观点。他们认为，人类多进化的结果，是人类文明迈过的一个关键门槛。

家的出现，不光是一种物质上的进步，也是一种意识上的飞跃，塑造了人类祖先的原位于和互动方式。而发明了“家”的人，是50万年前生活在欧洲的尼安德特人。

# | 谁建构了“家”的空间概念？

家的出现，是一个从无到有的演变过程，而精心布局过的固定住所，就是“家”的标志。

过去科学界一直认为，史前人类大多居无定所，随遇而安。因为他们并没有留下任何固定住所的痕迹。但英国南安普顿大学的考古学家克里斯·甘布尔（Clive Gamble）发现，从40万年前开始，人类的居住形式开始变得稳定了，出现了越来越多的固定住所，这种变化席卷了整个古人类，并且在传播过程中不断演变。

甘布尔并不清楚这个变化意味着什么，后来曾对其做出了解释，他认为，这种变化是由于“家”的出现，这最早可以追溯到尼安德特人。

50万年前，尼安德特人来到了欧洲，当时的欧洲十分寒冷，冬天可以达到零下几度。要知道，那个时候也没有现在这种能全护全家的保暖内衣和羽绒服。出于生存需要，尼安德特人不再随随便便地寻找石头或者山洞休息，而是开始有意识地去选取石头，对洞穴进行加工改造，把它变成一个能遮风避雨的固定居所。

尼安德特人对住所的要求非常高。总的来说，有三方面。

首先，家的位置要好。就好像我们买房的时候都要找学区房、江景房一样，尼安德特人对家的位置也非常讲究，家不能在山顶，也不能在谷地。而要在山坡下往山的三分之一处。这样，山上和山下的情况都能尽收眼底。

其次，家要有庇护的功能。智慧的祖先告诉后代，家要选择背靠岩石或山洞的地方，而且至少有一个入口，这样就既能方便地理进出的通道，同时挡住风雪和野兽。

再次，家作为一个综合生活区，要提供睡觉、烹饪等各种场所。对于这一点，尼安德特人就和现代人很像了。从居住一开始区，尼安德特人就划分好了不同的生活区域，就好像比我们在功能上分成了卧室、客厅、厨房和卫生间。他们由排成一排的石头和动物骨块，来标记不同的区域，还可能使用了皮革和木头等材料来做隔断。
