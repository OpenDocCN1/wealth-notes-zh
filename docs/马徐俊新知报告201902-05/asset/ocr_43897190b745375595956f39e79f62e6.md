# 今日报告：怎样用人工智能来安置难民？

马徐骏

严峻的社会问题，能从技术中找到新的解决之道吗？用人工智能来安置难民就是一个好范例。

今天的议题分为三部分：

+   如何利用人工智能安置难民？
匹配——安置难民的底层机制
Annie面临的两大挑战

难民问题让很多西方国家都头疼的大问题，特朗普政府之前刚削减了难民接收数量，欧美各国的也纷纷效仿，因为绝大数西欧国家都对难民，接受难民带来了额外的负担，而难民们却很难真正带来什么，也大多靠救济活法下去，境遇非常艰难。

《大西洋月刊》最近发表了一篇长文，介绍了一种用人工智能来安置难民的新方法。文章到了一款替代代表人的软件，叫做Annie，它能够利用人工智能安置难民“匹配”到那里适合他们，欢迎他们的地区？在那里，难民们会享受到友善的对待，找到更好的定自己做出，能量重新开展生活，也能为当地经济做出贡献。文章说，这个软件的出现代表着一个大的趋势——人们可以利用技术解决严峻的社会问题。

# I如何利用人工智能安置难民？

你知道美国原来是怎么安置难民的。根文章的小道，援助机构在安置难民时，主要的依赖都是哪两个地方还有余什么空房，然后再这些空排到语言匹配的地区，能到给难民分配技能，在新地方能不能到工作，需要什么，根本不在考虑的范围里。

其实这也是没办法的事，因为难民数量实在太多了，援助机构人手又有限，安置的速度跟不上难民的增速，要想为每个难民考虑周全，安置的效率又会更低。

《大西洋月刊》说，有了Annie这款软件就不一样了。对于人工智能来说，处理那些复杂，或极其耗时的事情根本不是问题。这款软件是美国乔治斯顿本特斯顿理工、瑞典查得大学和中国天津大学等模型，其中包含了很多元素，比如难民的母体被安置在哪里，教育背景，对等和语言，被安置后哪里，安置结果如何等等，然后输入大量历史数据让机器进行不断新正这套模型，最后，当你输入一个新的难民信息，模型就能最适合这个难民的安置地区，也会为每个难民和安置地区的匹配度打分，分数越，就越适合。
