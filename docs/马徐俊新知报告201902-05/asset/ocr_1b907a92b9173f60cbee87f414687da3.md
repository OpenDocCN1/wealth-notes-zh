# 今日报告：欧美的网络审美为什么变了

他们想展示真实的自我，而不是假装变成另一个人。

> 《大西洋月刊》

Ins风已经过时了。如今，受到新一代年轻人追捧的，是那种原生、真实到近乎粗粝的质感。这与Instagram的精致风格相比，几乎南辕北辙。但为什么会这样？这背后的原因是年轻人开始自认同的方式正在发生深刻的改变。

今天的议题分为三个部分：

+   1.  Ins风为什么过时了？
2.  新一代网红是什么样的？
3.  审美风向怎样波及其他行业？

当你打开淘宝，想找一款精致有设计感的衣服，最省心的办法就是输入关键手“Ins风”。Ins，也就是Instagram这款App的简称，是全球10亿用户中的一小部分社交媒体、每月有超过10亿用户在上面分享自己精心拍摄的照片。红着最潮的App上就成了网红，这些网红们主导着互联网上的审美风格，俗称“Ins风”。

在最近几年里，Ins风特指那种精心布置、仔细调色、略带小清新风格的照片。比如，一份惬意早餐的床头边清沙的一角，龙花色的壁纸，或者一张沙滩上的完美自拍。这些照片，可能是红们花了好几个小时，经过无数试光与角度，花了几个小时，然后用高配单反相机拍摄出来的。可是，在这种看似简单的风里，这些网红也带来了巨大的经济效益。

但《大西洋月刊》最近却发表了一篇文章，题目叫《Instagram审美已经过时了》。作者认为，之前那种略微轻飘飘的风格已经过时了。取而代之的是一种粗犷而自然，是原生、真实到有些粗糙的风格。

文章解释说，这背后的原因，是年轻一代自我意识的觉醒。他们想展示真实的自我，而不是假装成另一个人。

```
They are more willing to be who they are and not make up a fake identity.
```

这句话，也被我选为了今天的金句。

今天，我就来给你讲讲，这股Ins风到底发生了怎样的变化。它会对未来的审美趋势产生什么影响。

# 1｜下一代Ins风为什么不行了？

上一代Ins风用三个关键词就能概括：精心布置、色彩明快、小清新。这就带来了一个大问题，那就是同质化极其严重。比如，沙拉一定要摆成奶油卷，咖啡一定要拉花，照片的色彩一定要柔和柔到一定底线。

曾经，在小清新风潮的引领下，很多普通人也纷纷模仿。希望自己也能拍出这样的照片，在网上获得更多的掌声。一些网红就顺上了其中的商机。他们上门拍摄所谓的打卡圣地。为此就是在让普通人能拍出网红风格的照。比如，在2016年，美国纽约的就出现了一个网红店，少女心爆棚的冰淇淋博物馆，和传统博物馆不同的，这是一家快活店，只开两周，专门针对喜欢拍照的网红和路人进去体验。里面，有各种口味的冰淇淋，用花筒做成的吸管，还有专属的网红拍。而之后，这个博物馆就很快从社交媒体上打卡起来，从纽约到洛杉矶，从纽约到洛杉矶再到旧金山。虽然门票高达38美元，是卢浮宫的两倍多，但5天门票，在开售的5分钟内就已经一抢而空。

我们在153号报告中，讲过全球建筑网红化的风潮，很多传统建筑也受到了Instagram的影响。比如，英国伦敦的UCL博物馆也是类似人拍照片分享，已经完全除了禁止内拍照片的标识，甚至还挖空心思想提高在社交媒体上的曝光率。

不过问题也出现了。一个只是想在Instagram上发张照片的地方，就会吸引一大帮人打卡。不管你喜不喜欢，只要看到那种场景，往那儿一站，就能拍出网红一样的照片，就好像批量生产的流水帐一样。然而，今天，这种流水线拍方式，遭到了新一代网红的抵制。

随看年轻一代的崛起，他们的意识到和对自己的认同，带来了新的网红文化。

# 1新一代网红是什么样的？

总的来说，新一代网红的照片可以归纳为两个词：“真实”和“原创”。

网红营销公司Estate Fivve的联合创始人琳西·伊根（Lynsey Eagon）说，新一代网红不再单轨拍，也不再拍照，通常进行自拍。而且，他们不在乎什么滤镜，什么背景。而原先的审美风格下，他们统统不在乎。他们在乎的，是照片是否能表现真实的、独特的自己。

比如，Instaram上有一个22岁的姑娘名叫里斯·布雷特史帝（Reese Blustent），她在短短的一年之内就收获了23万8千个粉丝。她的照片，没有精致的造型，也没有精修磨皮，都是最普通的自拍。她问非要说有什么特点，那就是她的原果不是士的，就是怪的。她告诉记者说：我从来不想，我发的照片是不是太多了，我的主页是不是乱了。只要有喜欢的照片，就会发上去。

像里 斯这样的年轻网红还有很多，他们都不喜欢精 心安排的样式。实际上，很多十几岁的人发出去的 照片其实很普通， 比如你 一款叫做HulaCam的软件，这款软件能让你的照片看起来，像是20世纪90年代傻瓜相机拍出来的。有点模糊，颜色也有些失真。迄今为止，这款软件已经被下载了1600万次。一个20岁的女孩表示：大家现在都想见自己真实的一面，很多人不光是 靠 手机自拍，还会随手 自拍。

从老一代“显示美好生活”的网红风，到新一代“展示真实自我”的网红风，转变的，不仅是审美， 也是审美，更是社会意识态的巨大变化。从社会结构上来说，千禧一代出生国崛起， 年轻的一代，他们 追求的是“现代化”，而不是“西方化”。他们乐子用高科 技 技术改变生活，但他们也只 追求自己的 文化特色，基于这种文化的化差异为美。这也，是新一代网红对于“真实”和“原创”的追求的底 层逻辑。

新一代网红，掀起了一系列连锁反应。这些效应，甚至扩散到了社交媒体相关的行业。

# 1 审美风向怎样波及其他行业？

总的来说，新一代网红，让老一代网红越来越真，让网红地标不再 是，也改变了网络销售的方法。

老一代网红为了跟上新一代网红，也做出了改变，让自己看起来更接见地气。在今年4月初举行的纽约美妆博览会上，美妆巨头公司，比如Lancome的 美妆师在表示，以后少有使用 磨皮 作用的 腮红，更多的是 在自己 真实的状态。不光如此， 这些博主 也开始谈论自己的 焦虑和 心理 问题，自己 为一个名人所承受的心理压力。这一切都是为了让看起来更加真实。

网红地标，已经不再那么受人欢迎了。2017年，坐落在美国洛杉矶的Happy Place公司，提供 1.5 美元 美国 最 值钱的 打卡地点，“只需美元，VIP套餐是199美元”。今年4月，它来到洛杉矶，遭遇了前所未有的冷清。人们不愿意再拍摄千篇一律 的 自拍 照片。一名 15岁 的女孩告诉《大西洋月刊》记者：“我不想把照片发出去，也不想再那拍照。”
