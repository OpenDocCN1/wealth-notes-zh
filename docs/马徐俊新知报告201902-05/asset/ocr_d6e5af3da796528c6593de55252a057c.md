# ## 今日报告：社交网络时代如何体面分手？

一个明明白白、好聚好散的分手，和恋爱的过程一样重要。

> ——《今日心理学》

马徐骏

明明白白、好聚好散的分手，和恋爱的过程同样重要。今天关于今天再次寻找分手的能力，今天的报告将教你一套“七步分手法”，让你在网络时代能够体面地分手。

今天的议题分为三个部分：

+   1. 为什么我们需要好好相？
2. 暧昧不清的分手有什么问题？
3. 怎样才能做到好聚好散？

科技会重新塑造我们的情感交往方式，既包括积极面，也包括坏面。随着社交媒体兴起，很多人发现，分手的过程似乎变得没完没了。虽然分手了，对方却还时不时给你点赞，偶尔还会在主页上留下祝福，或者突然艾特你一下。明明已经不再是恋爱关系的两个人，却始终处于一种暧昧的状态里。

最近，《今日心理学》杂志愁现个现象，发表了一篇文章，叫做《没完没了的分手》。这篇文章里，这种状态是我们这个时代特有的现象，但对分手并没有好处，其实，明明白白、好聚好散的分手，和恋爱的过程一样重要，它可以让对方都从失恋里缓下来，继续一段段旅程，最终找到真正的爱和情感的满足。

今天，我们就来谈，网络时代的分手有哪些问题，我们又该如何体面地分手。

# ### 1 为什么我们需要好好相？

《今日心理学》说，“好好聚好散”对一段情感而言，至少有两点好处：它能帮我们激活大脑的学习能力，也能影响我们未来的情感道路。

首先，在生物学上说，好聚好散可以激活大脑的学习能力。人类学家海伦·费舍尔（Helen Fisher）曾经做过一个大脑成像实验，实验对象是刚失恋的年轻人。实验结果显示，当这些人大脑启动情感的某个区域，也就是大脑中负责处理“得失”的前额，变得更加活跃了。

也就是说，这些人在思考“为什么对方要和我分手”、“到底是哪儿出了问题”，这是一种从一段情感中提取教训的行为，其实是一种反省和复盘的能力，而这种能力，直接关系到我们的生存和繁衍。

另一方面，从心理学上来说，一段感情是如何结束的，很大程度上会影响下一次情感道路。好聚好散，可以让你更积极地去看待下一段感情，从中吸取教训，然后勇敢地奔向下一段感情。

斯坦福大学的博士后劳伦·霍（Lauren Howe）曾经对180对分手的恋人进行过研究。他发现，假如一个人能清楚地知道分手的原因，并知道自己做错了什么，或者没有做错什么，那么下一个恋爱关系就会更加顺利。

所以说，明明白白、好聚好散的分手，其实都是非常需要的，可以帮助我们理解和塑造自我，投入下一段感情。

但问题是，在网络时代，恋爱从开始到结束，都很难做到明明白白，“暧昧不清”似乎已经成了这个时代最新的情感方式。

# ### 网络时代的分手都有哪些问题？

文章里主要讲了两个问题：首先，你可能根本无法确定自己是不是还爱了。在网络时代，一对恋人分手之后，必须面对面对，清楚的，这种分手的气氛虽然很紧张，但总是有始有终，能把感情界定清楚。

可是，在这个时代，网络催生了很多新的分手形式。网友们还专门给它们起了各种名字，其中一种叫做ghosting——网络直译，指在分手之后完全不回应信息、不回电话，让对方像鬼魂一样消失。你可能会问，可是为什么对方会消失呢？

换句话说，就是突然消失。

第二个问题就是，即使你知道这段感情已经结束了，你可能依然通过社交网络和他保持着不间断的联系。有两个专门用来形容这种状态，一个叫orbiting，另一个叫breadcrumbing。

Orbiting是什么意思呢？就是一个人像卫星一样，在你保持一定距离的同时还围着转。朋友在分手后给你点赞，刷你的动态，留言，却又不给你打电话，这就是orbiting。

而breadcrumbing的意思也差不多，这个原文的意思是“给小动物撒上面包屑”。在这里是形容总是用社交媒体来撩拨对方，比如在评论区或者私信里问你过得怎么样，或者在动态里暗戳戳地@你，但其实没有任何实质上的互动。

换句话说，面包你是吃不着了，但是面包屑，管够。

这两个问题，直接导致的一种后果就是，“被分手”的一方要么不清楚状况，耗费相当多的时间和精力去关注对方在社交媒体上的一举一动，甚至对对方的反应过度解读，要么像读密码一样研究半天，最后往往让自己陷入更深的孤独和痛苦中。

这种情况，无论男女都会有。

第二种后果，就是弱势一方容易被强势方利用。被分手的人，一心想着复合，可另一半却掌握着主导权，更有甚者会充分利用这种不情不意的状态，故意延长暧昧的过程，直到自己彻底腻了为止。

第三种后果，也是最严重的后果，就是被甩的一方，永远不知道感情结束的真正原因。

西北大学的心理学教授亚历山达·所罗门（Alexandra Solomon）指出，那些留在模糊中，最后很可能自认为分手的原因在于自己。男人和女人最典型的分手原因不同，女人觉得，Ta之所以离开我，是长得丑了，总之，是不值得被爱。

阿拉巴马大学的沟通学教授利亚·列费伏尔（Liah LeFevore）也指出，“被分手”的一方会从此建立一座高墙，不愿意再重新寻找新的爱情，也不敢再对他人暴露真心。

好，说了这么多网络分手的缺点，下面我们就进入今天的正题，教会你如何做到好好相散，体面地分手。

# ### 2 怎样才能做到好好相散？

首先，想要体面地分手，就必须跟对方坐下来，面对面地谈话。这是一项非常高难度，也是有价值的工作，要按照方式，其实是有技巧的。你得抓住两个关键词：共鸣和坦诚。你要去表达对的心情，同时把自己的感受明确地表达出来。围绕这两个关键词，文章给出了一个“分手七步法”。

第一步，做准备。你一定深刻反思，自己究竟为什么想分手。是因为习惯不同还是价值观不同？你要想清楚，你们之间有哪些是无法克服的。

第二步，当面分手。分手的时候，一定要注意你说话的方式。你要用一种对比较敏感的方式来表达，比如“我们好像不太合适了”，而不是“我觉得你怎么样怎么样”。比如“可能你也觉得我们之间的感情不像从前了，我们对彼此的感情不再是平等的”，或者“我希望我们两个都能有新的机会，去寻求更好的感情”。

第三步，说分手，别忘了表扬一下对方的优点，让对方知道，你在某些方面还是非常感谢甚至是欣赏他的。然后再表明一点，尽管你是欣赏对方的，但这些优点，你们之间的感情已经不在了。

第四步，解释分手的原因。你要诚实、冷静，富有感情地说出，是什么让你觉得无法再继续这段感情了。千万别说“你有缺点”，“你整不好”，“你不是好人”，等等。你一定要明确地告诉对方，不能在一起的理由，比如说“我还没有做好长期在一起的准备”。

假如是因为对方某些讨厌的习惯而无法忍受，比如说一件件事情，一直在脑海里挥之不去。然后，你得明白，你曾经做了多少努力，让对方改掉这些习惯，但都没办法。

等对方说话的时候，你要认真地倾听，对方可能会对你的说法做出反驳，或者会很激烈，这些都是正常的。
