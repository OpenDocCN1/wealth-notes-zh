# 今日报告 | 卡路里悖论

多运动，并不一定比少运动燃烧更多卡路里。

—《新科学家》

马徐锐

多运动就能燃烧更多的卡路里？事实上，人体消耗卡路里的方式，有一套自己的算法。

今天的议题分为两个部分：

+   - “卡路里悖论”为什么很反常识？
- 身体的“算法”到底是什么？
- 怎样才能有效燃烧卡路里？

每逢假期，大家都难逃“三产”的魔咒。可能你正在琢磨着，假期过后赶紧多运动动，把这几天的肉减掉，对吧？在大众的健身常识中，想减肥，得靠多运动。

为什么呢？因为运动能够“燃烧卡路里”，也就是消耗热量，进而分解脂肪。健身教练甚至会卖命地告诉你，跑30分钟可以燃烧掉300大左右热量。想燃烧更多的卡路里？那就得跑更长时间。

可是，最新一期的《新科学家》却给出了一个有点颠覆认知的研究发现：你以为多运动就可以多消耗卡路里？错了，一周一七天都跑步的人，燃烧的卡路里，未必会比只跑两次的人多。

是不是有点难以置信？这个“卡路里悖论”比科学家预测的更甚。例如，他们查看了坦桑尼亚平原上的哈德萨人。这些人平均每天要走上10公里进行狩猎采集，可算得是，人均每天消耗一些卡路里，居然只比美国人坐姿多消耗一些能量。虽然他们稍多了一点点——大约26%的运动，但没有带来等值的卡路里消耗。

这实在太奇怪了：科学家一直进一步想说明，身体消耗卡路里的“机制”，让人很难理解，它有一套自己的“算法”。当你的运动量增加时，身体会通过各种机制减少卡路里消耗，甚至刺激各种体内活动以“少耗能”。所以，想要靠运动“燃烧卡路里”来减肥瘦身的话，光靠多运动也不行，你还必须搞懂这套“算法”。

奉上今天的名句：

> Working out a lot doesn't appear to burn more calories than doing a little.

多运动，并不一定比少运动燃烧更多卡路里。

# l “卡路里悖论”为什么反常识？

“卡路里悖论”之所以反常识，是因为它违背了我们的直觉：更多的运动量，竟没有带来更高的热量消耗。这是好比“存了，但没取到钱”——你辛苦了一辈子的辛苦钱，反而要交出一部分，这感觉是不是有点讽刺？

科学家最开始也说不明白，但是这个现象却反复在研究中被发现。其中一个比较典型的案例是，南苏丹开普地区哈德萨人，这个部落的居民至今还过着狩猎和采集的原始生活。为了追逐猎物，人们会背着弓箭每天行走30多公里，他们也不闲着，每天都要从森林里打猎猎物，采掘野果蔬菜，从树上采果实。

就在几年前，纽约圣约学院的跨人类学家赫尔曼·庞兹（Herman Pongtz）的跑到了这里做研究，最初他也是想测量这些部落居民的身体数据。可结果让他大吃一惊——像哈德萨人这样，每天运动量大的人，竟然并没有多消耗大量卡路里。

可数据显示，哈德萨人中，男人每天消耗的卡路里平均只比200大卡，女人平均只比190大卡。这个水平只比那些美国人整整每天开车去上班，坐一整天的白领们高出一二点点。庞兹教授彻底震惊了。

要知道，现在的主流观点可认为，办公室久坐导致肥胖的消耗。要是坐着消耗的卡路里，和在外面跑一整天相比也差不多，那岂不是说明，多运动也没用吗？

在另外一项关于运动和心理的研究中，也出现了一类似的“悖论”。芝加哥大学劳杜卡斯（Lara Dugas）研究了美国，加拿大，南非，牙买加，墨西哥等6个地区接近2000名非裔和南亚裔人的代谢率，并跟进了几年之后的体重变化。

结果显示，运动量和体重竟然没有明显的相等性。那些会做几个小时以上中等强度运动的家庭，反而比那些不怎么运动的人体重增加得还多。这不是很不可思议？

到底怎么回事呢？最初科学家们以为是，因为他们运动多了，吃得更多了。出于补偿心理，吃多了热食，或者更加吃心理性地多吃一些蛋糕，冰激凌之类的高热量食物来犒劳自己，这样运动消耗的热量就全补回来了，造成体重不降反增。

可是仔细琢磨一下，你就会发现，这并不都是他们真的在答案中，为什么同样的消耗量和运动量不成比例的现象。所以，根源还是人体消耗卡路里的方法上。之前人们对运动燃烧卡路里的理解，并不正确。

# l 身体的“算法”到底是什么？

这里，我们先借用一下“算法”的概念，来描述身体燃烧卡路里的底层逻辑。我告诉你们，这是身体的算法和人们想得不太一样，这不是关于“减脂”，而是“生存”。

这是什么意思呢？来看下面这个例子。

2016年，之前我们提到的庞兹教授和杜加卡斯博士联手开展研究，想解开“卡路里悖论”之谜。他们重新检查了实验数据，发现了一个很有趣的“数据”——在实验的初期，那些运动得较强烈的运动员，身体确实能燃烧更多的卡路里。但是，每当大家都坚持锻炼后，那些每周只运动几次的人，在卡路里消耗量方面竟然相差不远。

这说明什么呢？说明着随着运动量的增加，身体在主动降低卡路里的消耗。为了进一步验证，庞兹教授和杜加卡斯博士又一起研究了美国举办的一场超远程马拉松比赛，比较那些选手连续140天，每天都要跑一场马拉松。

他们发现，比赛开始头一个月，选手的新陈代谢还很快，可随后曲线开始趋于平稳，甚至是逐渐下降，为了调节，选手每天的能量需求就降低了。很明显，身体正通过降低新陈代谢的“节能模式”，以便能用更少的能量，来支撑更大的运动量。

可这又是为什么呢？答案是，为了生存，你想，要是运动越多，卡路里消耗越大，那身体可能很快就出现极端饿，给生命带来威胁。身体想办法节能，正是为了保障生存。

有意思的是，在饮食方面，身体也在运用同一套“算法”。这就是为什么有些科学研究说不支持节食减肥，因为饥饿会让身体以为，你正在经历濒危时期，必须开始新陈凋变，甚至，降低你的生存。所以你会发现，节食减肥非常容易出反复，因为食量一多回来就一直留在低水平，你要多试一次，就会一直胖回去。

从进化的角度来讲，身体的这套“算法”没毛病。你可能在想，我运动就是为了减肥，根本不担心能量短缺啊？但是抱歉，身体并不这么认为。人类的身体经过漫长的演化才有了这套“算法”的目的，就是为了保障我们有足够的能量来找到食物，在艰苦的环境中存活下来。它可不管你需不需要吃鱼，吃马肉。
