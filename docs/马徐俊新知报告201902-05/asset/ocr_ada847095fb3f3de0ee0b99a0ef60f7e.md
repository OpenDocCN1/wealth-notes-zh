# 今日报告：智能纹身会普及吗？

智能纹身，将会成为健康意识和自我表达的代言身。

> ——《美国科学院院报》

马俊毅

智能纹身可以像一次性手环那样贴在皮肤上，反映你的各项健康指标。它不仅代表着智能可穿戴设备的最新趋势，还有可能成为人们表达审美趣味的新体验。

今天的议题分为两个部分：
什么是智能纹身？
智能纹身面临着哪些挑战？

一提到可穿戴智能设备，你联想到的可能是智能手环或者智能手表。但《美国科学院院报》（PNAS）最近发表的一篇文章告诉我们，智能可穿戴设备还有另一种可能性——智能纹身。这种智能纹身不仅可以有装饰的功能，还是一个便携式智能医疗设备，可以实时监测你的各项指标，为你的日常生活和医疗保健做出贡献。

智能纹身的出现代表着一种全新的趋势，那就是新一代的科技产品会越来越注重实用性、科技性和审美趣味的结合，给消费带来多元化和个性化的选择。今天，咱们就来讲讲讲这个话题。

# 什么是智能纹身？

这篇文章说，智能纹身最早可以追溯到2011年美国西北大学的研究员研究生电子工程师罗杰·罗杰斯（John Rogers）在《科学》杂志上首次提出了智能纹身的定义。他如是说的：“智能纹身，是一个集成了表皮电子设备的薄膜，这个薄膜包含电子设备、传感器、电源等各种组件，可以收集人体体的各项数据，还能智能备份传输信息；它不仅更轻薄、更便携，还是一种将美学与科技结合起来的科技产品。”

目前有很多公司都介入了智能纹身行业，它们的产品主要两个研发方向，一个是收集人体的健康数据，一个是检测周围的环境变化。

比如说，咱们刚才提到的智能纹身的概念，可以追溯到英国某一家公司。主要研究者罗斯林生物，健康医疗仪器司设备。在他的主导下，这家公司已经推出了一款叫生物邮票（BioStamp）的智能纹身，这就是大家的一个大号的设备，可以及时检测人体的各项健康指标，比如说身体上的含水量、血糖、心率等等，不管是佩戴者还是医生，都能更精确地实时监测身体的状态了。
