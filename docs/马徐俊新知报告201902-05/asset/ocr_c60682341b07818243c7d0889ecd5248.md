# # 218报告 | “打破规则”的成功之道

马骏毅·新知报告

今日报告：“打破规则”的成功之道

你必须像艺术家一样熟练规则，才能做到像艺术家一样去打破规则。

——《企业家》

马骏毅

敢于打破规则的底层，是充分地理解规则，发现规则的局限之点，才能抓住时机开辟新赛道。

今天的议题分为两个部分：

+   1.  以客户为出发点，打破了哪些规则？
2.  以自我为出发点，打破了哪些规则？

我们都成功创业，很多创业者会借鉴前人的成功经验，就是少了多少弯路。不过，最新一期《企业家》杂志做了一期专题，采访了11位成功的创业者，他们之间有一个共性，就是都打破了既有的规则，违背了通行的创业经验，但最终还是取得了成功。

在这些创业者里，有抛弃了社交媒体和大数据，用“发短信”的方式成功做起了餐饮指南应用的创业者；有坚决不利用已有的客户群体的推新产品的实业巨头公司的老板；还有违反了硅谷“先推出最小可行产品做反”的做法，花了三年时间埋头做开发的办公软件设计师等等。

《企业家》杂志的洞见是，这些人并不是“为了打破规则而打破规则”，你会发现，他们其实对规则有着很深的理解和掌握，在此基础上，才能战略性地打破规则，选择一条新的路径。

有句话总结得特别好：你必须像艺术家一样熟练掌握规则，才能做到像艺术家一样去打破规则。

```
Learn the rules like a pro so you can break them like an artist.
```

这句话，也被选为今天的金句。

从这些创业者的故事中，我挑选出了5个最典型的成功案例，分为两类来讲：前者是为完成突破，后者的规则看似相同，但从细致端看，背后的原因也不尽一致，一类是从客户出发，一类是从我自己出发。

# ## 以客户为出发点，打破了哪些规则？

这部分我主要讲了三个案例。首先要说的这位创业者叫克里斯·斯塔格（Chris Sturgis），他打破的规则是“跟随行业大趋势”。克里斯在2014年创立了一家餐饮指南，名字叫The Infatuation，功能有点像我们国内的大众点评，当这些内容营销的普遍做法，是利用Facebook这样的社交媒体投放广告来引流，再通过内容吸引粉丝投放广告“引流”，可克里斯到底没怎么做，他选择的方式竟然是——发短信。
