# 今日报告：教育为什么会导致生育率下降？

由于教育因素的影响，全球生育率下降的速度，可能快于联合国的预期。

——《经济学人》

马修银

《经济学人》认为，决定一个国家生育率的主要因素，是教育水平。

今天的议题分为两个部分：

+   1. 为什么教育会影响生育率？
2. 未来的生育率会比预期的更低

人口负增长，是长期困扰着很多发达国家的问题，如今正在变成一个全球化的问题。而中国在当前老成化的问题也日趋严重。这也是为什么欧洲国家会接收那么多难民，机会生育都低于老龄化，主要原因。一直以来，生育率低于2.1，人口数量就会减少增长。根据最新的数据，中等收入国家的生育率是2.3，而发达国家的平均生育率只有1.7。

对于这种富裕国家的人不爱生孩子的现象，我们一般会归为认经济的禁欲程度有关。因为，通常在经济状况比较好的国家，避孕措施相对比较到位，女性地位一般会比高，这样女孩子对于生育这件事就有更多的话语权和自主权。

不过《经济学人》对这个看法，最近《经济学人》杂志最新刊登了一篇社评文章，叫《A school for small families》，给出了另外的一个观点，那就是决定一个国家生育率最大的因素，是教育。

文章里说道，由于教育，全球生育率下降的速度可能快于联合国的预期。

```
Thanks to education, global fertility could fall faster than the UN expects.
```

这句话也是我们今天的金句

下面我们来详细说说，教育究竟是如何影响生育率的？未来的人口趋势会是什么样的？

# ## 1 为什么教育会影响生育率？

关于这个问题，《经济学人》给出了三个原因：首先，教育推迟结婚缩短了女性生育的时间；其次，教育增加了养育子女的成本；最后，教育变成了人们自我实现的认知。我一个一个来说：

首先，教育缩短了女性的生育时间。
