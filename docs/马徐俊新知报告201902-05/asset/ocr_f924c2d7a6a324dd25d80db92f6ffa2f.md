# 丨手机怎样判断你的心理状态？

借助手机这个媒介，人工智能在心理诊断领域的应用越来越广泛，并且在三个方面取得了突破。首先，研究者利用三种模型：分析数据、确定概率，大致上，人工智能可以从4个指标来判断你的心理状态，让你更全面地了解自己的情绪。然后，通过汇总分析数据，人工智能能绘制热图，让你预测你未来的情绪变化。

我们先来看第一点，看看研究者如何用模型来分析数据。目前人工智能的算法模型已经深入到心理监测和诊断中。研究者通过人工数据，已经逐步将各种偏见主观的判断过程，变得理性、客观化。

卡耐基梅隆大学的路易斯·菲利普·莫伦西（Louis-Philippe Morency）教授和他的团队，把信息分成三个模型。分别是语音模型、视觉模型和手势模型。语音模型是用来处理和语音信息，视觉模型是用来处理面部表情和手势；声音模型是用来处理声音信息。

这三个模型怎么展开协作呢？假设一个人对着手机说了一段话，他使用了一些表情，他说话的语气、节奏、语调，以及面部表情等各方面的数据，都会被提取出来，通过已有的数据对比分析，可以分析出这个人当前的情绪。当数据越来越多，算法越来越准的时候，对于心理状态的判断，就会越来越准确，这是一个不断迭代的过程。

通过一个人的语音语调、语气、表情来判断情绪，对机器来说很容易，这对人类的情感机。但是研究认为，这是相当白痴的。没有正确的方法来训练它，这又与动物学不一样。要说明正确解释这些人的特征，需要一个数据有重复的算法平台。通过这种算法的应用，也让人脑神经越来越精准。

不断迭代的算法，怎么落在手机APP上呢？比如这款，虽然APP后台会分析大量数据，但通过最后的汇总分析，你可以看到观察4个核心的指标，就能全面了解自己的心理状况。

美国有一款心理健康监测应用叫CompanionMx，就是这类手机应用。对于有心理疾病的人，这个应用会收集他们的生理指标，辅助医生做出诊断和治疗。对于心理状态健康的人来讲，这个APP也很实用，它会在侦测到你情绪不佳的时候，对你做出提醒，帮你尽快恢复好心情。

那具体怎么用呢？你可以对着这款应用记录某项日常，这个应用会收集、分析你的这项日常数据，比如你的声音特征，使用的语言特点和你的表情等。尤其是呼吸的音高大小、表情等信息，之后这款应用会把这些信息交给AI，做出分析、给出反馈。

这4个心理指标包括：抑郁程度（depressed mood）、兴致衰退程度（diminished interest）、回避感（avoidance）和疲劳感（fatigue）。在收集了足够的数据之后，这款手机应用还可以画出这4个指标的趋势图，这势图，可以帮助你全面地了解，掌握自己的心理状况，甚至是预测自己未来的情绪变化。

而且，这款应用还有一个“提醒”功能，能帮助你及时发现自己的情绪变化，及时调整。当数据仪检测到你的情绪有低落时，它会提醒你，如果你没有及时响应的话，它会通过一些简单的数据记录来提醒你当下的心情，它会提示你做深呼吸练习，或者起来走一走，来调节情绪。

而对于原本就有心理疾病的人，这款应用会把这些数据反馈给心理师或有帮助的，这些记录与传统的医疗日志类似，帮助医生更早发现问题，更准确地诊断疾病。

咱们常说，不在沉默中灭亡，就在沉默中爆发。其实里面隐含一层意思，也就是说，当负面情绪积累到一定程度时，就会对一个人的心理状态造成极大的破坏。有了这类应用，人们不但可以实时地监测自己的心理状态，及时调整不良情绪，不会让自己的状态走下坡，而且还能够收集自己的情感数据，帮助医生做出诊断，这对于整个心理诊断领域，有更大的意义。

# 丨心理诊疗领域的变化

总的来说，心理状况监测与诊断，正在经历从“听你怎么说”到“看你做什么”的转变，而你的每次使用的手机，就是收集信息最好的媒介。

传统的诊断方法主要靠“听你怎么说”，这内含着主观的判断，没办法保证信息的正确性。你可以看到过问诊式的心理测试，通过回答一系列的问题，比如“你最近的健康质量怎么样”“你是否经常感到压力很大”“你是否总是感觉孤独或焦虑”等，回答完所有的问题之后，后台就会通过分析出一个结果，判断你的心理状态是否良好，有没有抑郁倾向。缺点，用这种方法收集信息有个很致命的弱点，那就是不够客观。

有的人会倾向于把自己想像得比实际状态差，比如问你一个人一天喝多少水，喝几杯咖啡，他往往会刻意夸大，或真实情况有所出入。有的人在描述自己的状态时，会下意识夸大或隐瞒，尤其是那些对情感有心理疾病的人，也就是说，“听你怎么说”，这种传统的收集信息的方法，不准。

而通过手机来收集信息，有效地解决了咱们上面提到的这些问题。因为他做的，是“看你做什么”，追踪的是你真实生活中，行为的数据。这样不仅客观准确，而且，还能与医生沟通，提供更多信息，便于医生做出准确诊断。

科学家们把你使用手机的行为，标记为“行为生物标记”（behavioral biomarkers）。当你玩手机看游戏的时候，眼珠的移动速度、面部表情的变化；当你打电话的时候，你的语调、语速的使用变化；当你发送信息或写文章的时候，敲击屏幕、移动手指的动作，都可作为生物指标。这些进行指标形成数据，恐怕再有经验的医生也没办法完全观察到，有了人工智能和人工智能的加持，大家其实可以借助机器更地了解自己，这是人类进步的源泉。
