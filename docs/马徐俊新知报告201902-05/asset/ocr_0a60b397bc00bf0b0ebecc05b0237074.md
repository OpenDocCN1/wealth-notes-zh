人的年纪越大，大脑功能退化得越严重，其中记忆力减退尤为严重，对理解能力的影响也很大，可能会导致忘事儿，或者丢三落四，甚至出现无法自理的情况。因此，保护大脑活力至关重要。

今天我们就来聊一聊如何保持大脑活力。《科学》杂志（Science）上刚刚发表了一篇研究，探讨了如何保持大脑活力。文章发现，保持大脑活力的关键在于两个方面：一是保持听力，二是保持牙齿健康。

我们的大脑就像一台复杂的机器，需要不断地进行维护。就像汽车一样，定期保养可以让它运行得更顺畅，而忽视维护则可能导致故障。对于大脑来说，良好的生活习惯就是它的保养手册。

# I 为什么要密切关注耳朵和牙齿？

你可能会想，耳朵和牙齿和大脑有什么关系？其实关系很大！耳朵和牙齿健康直接影响大脑功能，尤其是记忆力。听力下降和牙齿问题都与认知能力下降有关。

研究表明，听力损失会增加患阿尔茨海默病（Alzheimer's disease）的风险。这是因为听力不好的人需要更多的认知资源去努力听清声音，从而减少了用于记忆和思考的脑力。此外，听力下降还可能导致社交隔离，而社交活动是保持大脑活力的重要方式。

牙齿健康同样重要。牙周病（periodontal disease）不仅会影响口腔健康，还可能影响全身健康。研究发现，牙周病患者患认知障碍的风险较高。这可能是因为口腔中的细菌可能通过血液进入大脑，引发炎症反应。

# I 三种保持大脑活力的日常活动

第一，运动。有氧运动，如快走、游泳或骑车，可以增加大脑的血流量，促进新神经元的生成。每周进行150分钟的中等强度运动，可以有效降低认知衰退的风险。

第二，学习。终身学习可以保持大脑的灵活性。学习新语言、乐器或技能，可以刺激大脑不同的区域，建立新的神经连接。

第三，社交。与朋友和家人保持联系，参与社交活动，可以减少孤独感，降低认知衰退的风险。社交互动可以刺激大脑的语言和情感处理区域。

# I 两种提升大脑活力的生活习惯

首先，睡眠。充足的睡眠对于大脑的记忆巩固和毒素清除至关重要。建议每晚保证7到9小时的高质量睡眠。

其次，饮食。地中海饮食，富含水果、蔬菜、全谷物、坚果和橄榄油，与较低的大脑衰老风险相关。限制糖分和加工食品的摄入也有助于保持大脑健康。
