# 第十节：风靡全球的爆款长盛不衰密码

每一款产品的生命周期不一样，曾风靡一时的通讯工具大哥大，如今已经是收藏品了。

一诺老师打赌，十年后你家的家具肯定不是今天这样子了，现在一诺老师不用下楼手机就可以打开院子大门、车库门！人在外地就可以开家里门、开关空调、灯光、电器……

各位，未来的家具是智能家具，互联网，大数据融合了。

时代变迁，你怎么看待你今天的生意、每一个产品的不同周期的表现、和你怎么判断你目前的项目暂时处在哪个周期？

接下一诺老师讲的内容对你非常重要，好好听。

第一个周期，叫导入期，就是原来没有这个产品，你是第一个做的、创始人、缔造者，这是第一个节点；

然后进入了成长期，快速增长的周期；

接着进入了成熟期，市场开始稳定；

最后是衰退期，秋后的蚂蚱，行业不好干了。
