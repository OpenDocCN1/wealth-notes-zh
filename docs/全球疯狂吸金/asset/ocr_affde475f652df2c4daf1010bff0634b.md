# 作为一个体验产品，你在设计的时候，首先思考的是这个东西可能是不赚钱的，但是它会帮你建立客户数据库。

你想象一下，就顾客的心理状态来说，你碰到一个陌生人，你不认识他，他也不认识你。

可能是通过广告，通过和别的商家合作，通过业务员陌生拜访，通过电话营销，通过网络，通过其他的一些渠道……

你和他有了接触，但是他根本就不了解你，信赖感也是没有的，你要说服他掏一些钱出来相对来说是比较难的！

# 你先给他一部分价值，先让他感受一部分不完整的价值，先让他体验到一部分好处。

![](bbox=[0.15, 0.57, 0.86, 0.71])

他发现自己没花钱，甚至花很小的钱，没有太多的代价，没有太多的风险，就感受到了一部分价值，发现还不错，然后呢信赖感就有了些，然后你再邀请他买一个小额的，就很容易
