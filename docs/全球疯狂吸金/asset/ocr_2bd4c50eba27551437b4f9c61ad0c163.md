# 第二节：吸金大师是这样炼成的

学习《全球疯狂吸金》请保持大师状态。

什么叫大师状态？

![](bbox=[0.17, 0.298, 0.89, 0.427])

有一位英雄，他找到本武功秘籍《葵花宝典》，翻开第一页，

看到上面写：“欲练神功，挥刀自宫。”

英雄大笑：“哈哈哈，原来成为武林高手如此简单！”

于是很兴奋又很纠结，但为了成为武林高手，于是拿出一把小刀，磨得非常锋利，想着男人要对自己狠一些，于是就挥刀自宫，只听一声惨叫：“啊……”英雄倒在血泊当中……

3 天后，英雄从血泊当中爬了起来，忍痛开始练功，当他翻开《葵花宝典》第二页的时候，看到上面写着：“无需自宫，也能练功！”这时英雄一声惨叫：“啊……”

又一次倒在血泊当中……这一次更痛，心痛！
