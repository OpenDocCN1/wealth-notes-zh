# 第四个杠杆：最简单

人性喜欢简单。

一诺老师在教弟子做顶层设计的时候，天下大事从大处着眼，小处着手，考虑的时候要兼顾每一步，要做长远周全整体的规划，而做的时候要做起来最简单，要分解流程。

所有的事情为什么能做成，是每一步简单动作，链接在一起组成一个复杂的系统。分解每个环节，到每个人都能做成。

如果有一种记忆的方法让你两秒钟轻松记住任何电话号码，你们愿意吗？这是人性！
