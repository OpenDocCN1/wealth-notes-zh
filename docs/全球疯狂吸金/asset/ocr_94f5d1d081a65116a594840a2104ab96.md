# 第二节：到底你的产品适合免费还是收费

假设你卖的东西比较单一，定价比较低，概念比较简单，流程比较短，那你一步法就可以了，你投放广告做宣传，吸金促销，一步就可以搞定，直接成交。你没必要用这两步了。

这就好像你没必要用大炮打蚊子一样，那简直太浪费了。

但是如果你卖的东西定价比较高，流程比较长，概念相对复杂，那你比较适合用两步法：第一步我们不直接卖东西，而是要送东西。

![](bbox=[0.15, 0.505, 0.856, 0.638])

为了给一个理由让你扫码加微信，给一个理由让你注册，给一个理由抓到你的名单，抓到名单以后第二步来做销售。

一般吸金人的做法是这样的——他通过各种手段、资源、渠道、传播的媒介，把自己的品牌名字推到顾客眼皮子底下来。
