# 第十节：在竞争对手的鱼塘疯狂捞鱼(合作篇)

好，一诺老师带你一起来看一下怎么把对手都变成帮手。

有人说：同行是冤家，我恨死他了，恨不得拿刀砍了他！

一诺老师告诉你：没必要的，你的竞争对手他和你一样，他们热爱这个行业，然后他们服务同一群顾客；跟你一样，你们应该可以成为很好的伙伴，但是很多人因为竞争对手打压，所以竞争都要搞得你死我活，死去活来，没有必要的。

你只要找到大家更多的共赢的点，找到更多的合作的点，你会发现这个世界上都是合作伙伴，没有对手。
