# 第九节：如何布局价值千亿生态圈

一诺老师认为：未来所有公司和项目，不是企业之间的竞争，而是生态圈之间的竞争。现在市场估值的时候，如果你是做产品的，估值也就几十个亿；做平台的，估值百亿；做生态圈的，估值能到几千亿。今天的 BAT 基本都是做生态圈布局的。

这几年伟大的习主席在搞一带一路，这也是生态圈啊！

> 未来的竞争是联盟的竞争！
未来的生存靠生态圈布局！
一诺老师

中国政府投一百亿，但是要用我中国指定的供应商，指定的材料，这样一来 80 亿就进入中国人自己的腰包了。过一段时间，好的地段我要让中国企业进来，我投的钱要付利息给我的，也是赚钱的。

过一段时间，升值了，我们可以转让股权，又赚钱了。

一诺老师断言——未来的竞争是联盟的竞争，未来的生存环境要生态圈的布局。
