# 小钱靠努力.大钱靠吸引力 《全球疯狂吸金》 错过这本书.损失十个亿

资扩股的结果是企业获得了资金，而不是企业家获得了资金。

割股套现是企业发起股东转让部分股权给投资著，换取相应资金。投资著是基于原来的股本金来计算其持股比例。

这种融资形式，企业并没有获得资金，获得资金的是企业家(发起股东)个人。

也就是说，投资著收购企业股权的资金流入了企业家个人的账户，而非流进了企业的账户。

股权融资不但是权益与资金的交换，同时也是风险与利益的权衡。投资著虽然分享了企业分配的权益，但同时也分担了企业经营的风险。
