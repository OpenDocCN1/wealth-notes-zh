# 第二节：高端爆款产品畅销秘诀(超级赠品)

高端产品，客户在购买的时候会犹豫，为此，你还要记得设计自己的赠品，就是免费送给客户的产品或者服务。

赠品可以说是一个百搭产品，能够用在你吸金方方面面——你可以把它用在鱼饵产品里，增加对新客户的吸引力；

你可以把它用在销售其他正式产品的时候，增加核心产品的附加值；

你还可以定期通知客户过来领取赠品，当客户过来时借机促销其他的产品。

有人说：“一诺老师啊，我这套东西没卖，我送出去了，这不就亏了吗？”

不要这样想，你要思考：吸金是一个整体的协同作战，是一个协调的工程，不是一每一款产品都要赚钱的，而是整体获利的一个过程。
