# 有很多好处就有很多人！

想要建立系统，就要整合天下资源！

那你准备如何整合天下资源？还用问吗？

> 好处给了谁，谁的资源就能为你所用！
—诺老师

不要说有没有时间，先问问自己有没有给到别人好处！

不要说能不能合作，先问问自己给对方的好处够不够！

不要问如何整合资源，先想想被整合的人有什么好处！

一诺老师常说：关系到位了，一切都不是问题！

这句话改一改：好处到位了，一切都不是问题！

这才是真相！赤裸裸的真理！

所以不要只会说：你真美、好漂亮、好帅呀，整点实在的！

举例：一诺老师的大门旁边永远有几箱水，那时候住在半山腰，很多快递不愿意跑上来，他们抱怨太远！

你想想，人家跑这么远上来，你就一句谢谢？不管用！

一诺老师才不会这么肤浅！直接整点实在的！
