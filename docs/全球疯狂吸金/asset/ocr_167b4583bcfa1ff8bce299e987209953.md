# 第六节：避免爆款恰到好处的三道门槛

进入门槛当中你需要考量 3 样东西：

# 第一个门槛：他要花多少钱

这一款是免费，我一分不收，还是要对方付个运费、付一个成本、付一个定金，还是要付什么？他要花多少钱，还是完全不花，这你要考量一下；

# 第二个门槛：他要留下多少信息

例如某个网站，在线注册的时候，对方又让你留身份证号码，又要留年龄、性别、血型、星座，你一看，烦！

你直接关掉网站走人了。
