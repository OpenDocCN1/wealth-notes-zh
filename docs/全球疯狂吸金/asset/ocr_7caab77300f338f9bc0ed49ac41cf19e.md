# 第八节：本欲擭众生反被众生嘻

来，跟着一诺老师的节奏，我们继续。

有一个小和尚跟师父说：“您总说心想事成，可我咋老是不能心想事成呢？”

师父问：“你想啥了？

小和尚说：“我想要一个冰箱啊，这样施主们供养的水果供品放进去就不会坏，然后我就可以吃啊。”

师父说：阿弥陀佛，善哉善哉！佛祖在圆寂之前，望着来给他送行的徒弟，留下一句千古名言——

इस्संक्रमण के लिएसंवेदनशीलप्राणी ट्रांस जीवहोते हैं

小和尚不理解，一脸懵逼的望着师傅……

师傅告诉小和尚一句话，听懂的顿悟人生！
