# 第一节：如何把对手拉开一个银河系的距离

13 年前，一诺老师的一位弟子做珠宝的，送给一诺老师一枚很大的钻石。

他懒洋洋躺在沙发上，左手拿着茶杯，用嘴轻轻吹动茶水的热气。云雾缭绕中，他右手拿着这枚钻石，凝视着对我说：

一诺老师，您知道吗？作为宝石，必须具备美丽、耐久和稀少这三大要素。而钻石是唯种集最高硬度、强折射率和高色散于一体的宝石品种，远胜过其他宝石品种。

自古以来，钻石一直被人类视为权力、威严、地位和富贵的象征。
