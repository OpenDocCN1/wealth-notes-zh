# 成长期有什么特点？

写下这句话，顿悟真谛！

![](bbox=[0.155, 0.222, 0.86, 0.353])

需求井喷，供不应求，赚钱特别容易。

手机刚普及的时候，做手机生意的人都发了。

十几年前房地产形势好的时候，做房地产的那一批都发了。

如果你是成长期前期进去的，赚钱很容易，这时候你的战略重点是放大，快速的融资，快速的扩张，凡是成熟期赚大钱的品牌，无一例外都是在成长期快速的增长跑马圈地成长起来的。

这叫天时：时势造英雄，英雄亦适时也！

广告投放、原材料囤积、市场扩张、人才挖角、有钱使劲往市场上砸，就这么起来的。不过，大家一看赚钱，就会跟风，在成长期后期，会有很多同行像雨后春笋一样冒出来，随着竞争对手越来越多，市场逐渐被催熟了，这就进入了成熟期。
