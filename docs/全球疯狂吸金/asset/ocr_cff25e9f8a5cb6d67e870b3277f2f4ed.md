# 第六节：鱼儿越肥,钱包越鼓

什么样的鱼最肥？就是高收入人群，你一定要锁定高收入人群！为什么要锁定高收入人群？一诺老师给你 8 个理由！

# 第一个理由：有购买力

因为他们有购买力，能够买得起，而且能够持续买的起；

# 第二个理由：让利给更多伙伴

因为毛利高，你可以让利让给更多人，这样你的合作伙伴会更多，而且合作伙伴的质量也很高，因为他们要匹配你；
