# 第二个关键：选择专业的目标市场

这是一诺老师最重要的“秘诀”之一。

大多数人认为拥有无拘无束的公众吸引力的产品将最可能迈向成功，但是，此观点仍然有不足的地方。

你想想，当公众成为你的市场，你需要有实质性的资源来和市场沟通。为了向公众行销，你可能需要在很多昂贵的大众媒体上刊登广告。

例如，过去的载体在报纸、电视、广播等媒体，现在主流人群扎堆在百度搜索、百度新闻、腾讯新闻……今日头条、趣头条等互联网载体。

当然，吸金高手的首要任务就是，选择你的首要“目标市场”，就是你的鱼在哪里。

如果你喜欢钓鱼，你应该成为热心钓鱼的人。

如果你喜欢演讲，你的目标市场应该是【改变世界】APP。
