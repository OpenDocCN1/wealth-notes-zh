# 第二节：蓝图规划的关键(布大局成大事)

你追钱很累，钱追你很爽！

如何让钱主动追你呢？

你需要做——蓝图规划！

什么是蓝图规划？其源起于”工程学”，本义是统筹考虑项目各层次和各要素，追根溯源，统揽全局，在最高层次上寻求问题的解决之道。

蓝图规划是运用系统论的方法，从全局的角度，对某项任务或者某个项目的各方面、各层次、各要素统筹规划，以集中有效资源，高效快捷地实现目标。
