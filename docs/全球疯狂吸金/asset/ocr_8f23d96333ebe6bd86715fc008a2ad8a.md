# 第六节：整合天下财富的四个杠杆

一个人上山摘桔子，你一天摘不了多少，你需要找一帮人，

可是你发现一群人一起摘的更少，都抢光了。

如果每个人各取所需，你要橘子皮做陈皮，他要桔子瓤做肥料，他要桔子汁提炼 VC，他要桔子籽做种植，这几个人一起上去摘，摘的桔子就比较多，各取所需啰。

合作就像打麻将，你把废牌扔掉，从别人扔掉的废牌里找对自己有利的牌。

![](bbox=[0.17, 0.498, 0.878, 0.628])

是的，你需要的资源早就为你准备好了，他们都可以为你所用，关键是凭什么？只要你学会这一课：《整合天下资源的四大要素》天下资源皆能为你所用！

这四大要素是：最佳利益、最小风险、最简单、最平衡。
