# 第十八节：三招轻松搞定任何鱼塘主

一诺老师有三种合作模式，几乎可以帮你搞定所有鱼塘主的：上策、中策、下策。

说句得意的话，这三招是一诺老师搞定任何鱼塘的独家秘诀，超级杀器，效果之好，超乎想象。

# 首先是上策：收费模式

也就是说，把你的生源当做商品，打包卖给对方，让对方拿着钱、拿着客户资源来跟你合作。

因为对方手里的客户资源也想变现，如果你能证明你的项目更能帮助他变现，那么对方自然愿意加盟合作。
