# 第十节：从明星产品到高端产品的平稳过度

明星产品赢得信赖感之后，这里会有相当一部分高端客户，他们喜欢追求最高品质的、顶级的，而且对价格不敏感。
针对这部分客户，你就可以推荐你的高端产品，也就是：

——利润产品。

利润产品有几个特点：

客户群体高端、价格比较贵、利润空间可观！
一诺老师

一诺老师觉得你有生之年一定要学会卖超高价的高利润产品，这样的产品 3 年不开张，开张吃三年。

一诺老师一个弟子，在北方开了一家婚礼主题酒店。

有一天来了个女孩子，跑过去订餐，原本准备花四万块钱，结果被婚礼策划师沟通完了花了 35 万——结婚的那天，新娘长着翅膀，从半空中飞落下来(酒店舞台上有空中索道、滑梯)，飞落下来一刹那，同时放飞一千只蝴蝶。(童话般)
