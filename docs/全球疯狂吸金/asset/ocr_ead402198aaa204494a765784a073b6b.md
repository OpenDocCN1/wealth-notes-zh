# 第四节：吃瓜群众偷走了你的梦想

你出生在一个吃瓜村，有一天，你想要创业想要成功，结果你身边有个馅子说：“怎么可能？骗人的！不要相信！”

晚上想想，你觉得好有道理哟，他们都是为我好！

于是乎，你就继续跟他们一起吃瓜！

有一天，你听说网络可以赚钱！结果你身边有个馅子，因为他没有见过互联网，就说：“靠！都是骗子！不要相信！”

晚上想想，你觉得好有道理哟，他们都是为我好！

于是乎，你就继续跟他们一起吃瓜！

有一天，你听说通过演讲可以赚钱，馅子知道了，因为他不会演讲，就告诉你：“说话就能赚钱？骗人的！不要相信！”

晚上想想，你觉得好有道理哟，他们都是为我好！

于是乎，你就继续跟他们一起吃瓜！
