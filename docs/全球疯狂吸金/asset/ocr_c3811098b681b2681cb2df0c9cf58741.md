# 第八节：从免费产品到入门产品的平稳过度

# 其次是：入门产品

也就是客户刚进门要推荐的产品。你把最核心的产品(也就是你的明星产品)通过减小体积、减少周期、缩减品质、降低价格、部分切割……做一个微型版就是入门产品。

# 入门产品的重点在于成交，成交比成交额更重要。

当客户花了一点小钱，从中感受到了你的价值和带给他的帮助，发现你是一个可以帮他实现梦想的人，为了得到更多的价值，他就会愿意支付更高的费用来买你的后续产品。

![](bbox=[0.15, 0.54, 0.86, 0.68])

对于一个新顾客来说,第一次生意,成交比成交额更重要。

很多商家巴不得第一单生意就把客户榨的干干净净的，让他全部吐出来。巴不得一见面就卖最终极的产品，最贵的产品。

顾客一看就被吓跑了。
