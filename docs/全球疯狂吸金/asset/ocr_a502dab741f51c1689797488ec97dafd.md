# 第四大终极武器：游戏竞赛

此外，游戏竞赛也是转介绍当中极其有效的妙招。一诺老师的一名弟子从事网上零售酒水的业务，他们设计了一款专供会员玩的在线游戏：酿酒游戏。

![](bbox=[0.18, 0.456, 0.898, 0.586])

这款游戏是一个多人协作的通关游戏，一个人是不能玩的。

过第一关的时候，你就要邀请好友过来注册，协助你一起酿酒。

于是你邀请了 3 个好友分别帮助你采集粮食、发酵、勾兑(游戏中的环节)，用了 3 天的时间过了第一关，酿出了一瓶汾酒。

于是，公司会在一周左右的时间给你寄来一瓶汾酒，酒瓶子上面还有你专属的名字。
