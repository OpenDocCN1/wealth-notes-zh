# 第一个杠杆：最佳利益

在座各位企业家，你们需要思考，你现在的顶层设计，需要哪些人参与，你要满足每个参与方的最佳利益。

每个人不是被你领导，是被自己的价值观领导，员工不是在成就你的梦想，是在成就他自己的梦想，他发现在你的平台上能成就自己的梦想，顺带的替你做点事。

> 你能成就多少人，就有多少人成就你！
—悟老师

每个人都会选择最符合自己最佳利益的行为。

+   ☆员工为什么流失呢？觉得跟你混没前途！
☆客户为什么会被人挖角？别人家好处多！
☆经销商为啥会去卖别人的货？卖别人的更挣钱！
☆银行为啥不给你投钱了？他发现投到别人那里赚钱更多！

把这句话记下来：钱喜欢往大的地方去！

+   ☆为啥厂商不给你供货了？他发现产品交给别人销量更高！

你要反复问自己：今天我的蓝图规划是否满足了每一个参
