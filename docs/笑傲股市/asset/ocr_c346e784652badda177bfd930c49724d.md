这时最好再进一步分析是原材料增加还是成品大幅增加。

（3）关联交易数额巨大，或者上市公司的母公司占用上市公司巨额资金，或者上市公司的销售额大部分来源于母公司，利润可能存在虚假，但是对待关联交易需认真分析，也许一切交易都是正常合法的。

（4）利润造假，对此问题一般投资者很难发现，但是可以发现一些蛛丝马迹，例如净利润主要来源于非主营利润，或公司的经营环境未发生重大改变，某年的净利润却突然大幅增长等，随着我国证券法的实施及监管措施的愈加完善，这一困扰投资者的问题有望呈逐渐好转趋势。

# # 避开“割肉选股”的行为

一部分是出于“永世不得翻身”的恐慌心理，另外也是受别人“割肉”我也“割肉”的“羊群效应”的影响，投资者中有很多人喜欢选择用“割肉”的方式来对待在下跌的股票。面对下跌的股票，“割肉者”既心疼自己的钱打水漂，在实际情况下也只能不得已而为之。综合分析，发现“割肉者”主要存在两种思维。

+   - 第一种思维：买的股票一时没有起色，不如赔钱出局，去追买其他的股票挽回损失；
- 第二种思维：止损出局，在低位介入。

两种思维结果相同，但是出发点却十分不同。第一种思维的出发点是“割肉”的损失能在其他股票上夺回来；第二种思维的出发点是低位介入的股票以后的涨幅能够弥补先前的损失。

殊不知，投资者的“割肉”行为实际上存在巨大的隐患。一次“割肉”无所谓，但频繁地“割肉”，价差损失加上手续费，会使资金遭受严重损失，甚至使本金损耗殆尽。“割肉”跟止损不一样，止损是预先设定止损价位，跌破该价位就出局，目的是减少损失，保全本金。从短期研判，指数存在继续下跌的惯性，但惯性不可能一直持续下去，外围的资金正等着入市抢夺，但贪婪之心想的是再跌一些，来达到用更低的价位吃到跳楼的筹码的目的。一些投资者经常会在股票下跌一段时间，甚至处于底部的时候，由于耐不住性子而“割肉”。一些糟糕的“割肉者”经常会发现，自己忍痛“割肉”带来的结果却是：原先“割肉”的股票后不仅没有继续下跌，反而上涨了很多—原来该股票的下跌仅仅是上沿途上的一次回调。

一些坚定而且稳重的股民，在股票被套牢后也不会轻易选择“割肉”，守上一两年的都有，最后是“守得云开见月明”，忍住了煎熬，保全了本金，获取了较高的收益。所以，建议广大投资者最好不要轻易“割肉”，投资者在割肉选股前考虑清楚：

+   （1）目前大盘走势发展如何，是否还在持续恶化？
（2）自己的股票是否已经处于高位，主力是否有出逃的迹象？
（3）自己的股票在日前价位上是否超过了其真实价值？

如果以上答案都是否定的，则不必为大盘暂时下跌而惊慌失措，对自己看准的股票，更要采取“捂”和“分批建仓”的方法，中长期持有，不送目标利润不罢休。
