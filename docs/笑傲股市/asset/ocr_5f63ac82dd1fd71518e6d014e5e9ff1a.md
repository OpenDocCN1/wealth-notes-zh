# ## 第24章 股市信息是怎样被炒作的

# ### 股市是个讲故事的地方

股市是个讲故事的地方，具体来说是庄家负责讲故事给散户投资者听，利用一个又一个看起来很美、听起来很舒心的故事来作出有利于庄家操盘的投资决策。

对此，很多散户投资者一定会有疑惑：自己明明读了大量的投资书、研究透了大盘，可谓是具备了扎实的投资知识了，为什么还会被庄家蒙蔽呢？

其实，散户投资者是被庄家所描绘的动听故事给迷惑了。在庄家所描述的故事中，散户投资者永远是占拥有利局面的那一方。而实际上呢？并不是，庄家所讲的每一个故事都是从自我利益出发的，对此，散户投资者要认识清楚。

众所周知，庄家坐庄是以赢利为目的的。那么庄家为了实现利润的最大化，一定会竭尽全力使自己手中的股票成为市场的最佳购买对象，使最大多数的散户投资者购买，制造最大程度的供求不平衡状态，从而尽可能提高价格卖出。庄家依靠什么来实现这些目的呢？靠信息，也就是一个又一个故事。而庄家在水市中的独特位置也决定了其在信息方面有着独特的优势，对此，散户投资者一定要做到心中有数。

在题材炒作中，庄家会充分利用信息的优势，为手中的股票编织一个美好的未来，业内称之为“讲故事”。这可以让散户投资者心甘情愿地掏空口袋中的钞票。故事讲得越动听，市场就会相信你有着好的成长性。这样投资者就会跟进，股价就会上涨。所以在很大程度上，成长性 是编出来的。
