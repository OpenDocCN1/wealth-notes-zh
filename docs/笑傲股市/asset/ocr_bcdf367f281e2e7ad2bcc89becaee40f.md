领头羊中国石化（600028）在其上涨过程显现出各个时期的阶段性特征（见图15-1）。如何捕捉领头羊，把握住领头羊的惊人上涨行情呢？领头羊的整个上涨过程大致可分为5个阶段：

+   （1）筑底时期；
（2）涨升时期；
（3）回调确认期；
（4）主升时期；
（5）上涨时期。

下面对每一阶段进行具体分析如下。

# 1. 筑底时期

该过程往往由加速下跌和震荡探底两部分组成，股价在均线系统（15、30、60）之下运行，其特征是股价K线形成各种底部形态，多种技术出现底背离信号，有的技术指标在不同周期呈现出同样的严重超买现象，形成底部共振现象。

# 2. 涨升初期

股价放量向上突破多条均线，成交量连续放大，技术指标形成向上突破态势。

# 3. 回调确认期

股价在60日均线之上振荡回落，成交量相对萎缩，技术指标回落中位线附近，部分指标会在0轴之上走平黏合。

# 4. 主升浪期

股价再次放量上攻，此时的能量要超过启动时的能量，均线系统成多头排列。技术掉头上行至严重超买位置，但是指标的超买对股价已经失去制约作用，股价在技术指标钝化的局面下不断强势上行，均线指标也在黏合后重新向上发散。

# 5. 上涨末期

股价出现放量滞涨，并形成各种顶部形态。成交量出现天量后开始萎缩，5日、10日与20日均线形成死叉。各种技术从高位回落，并出现顶背离信号。

投资者在运用追涨策略投资领头羊的时候，最适宜参与的时间段是领头羊运行在主升浪期的时候，其次是在领头羊启动的初期，即涨升初期。最不适宜追涨的时期是上涨末期。

对于绝大部分技术水平不高的投资者而言，在阶段性底部买入领头羊是不可能的，他们的把握方法只能是在上升的中途买入。

这时的把握要点如下几点。

# 1. 大胆追高

大牛市领头羊一旦步入主升段，就是一大段出人意料的、持续大幅上升的单边市，很少也很难有逢低吸纳的机会，主力是不会故意给机会给你逢低买入的，所以只有追高才能买入第一领头羊。这里准确判断它是大牛市第一领头羊，及已经进入主升段，是十分重要的技术。如果判断错误，会有很大风险。

# 2. 大胆持股

主升段的升幅是十分巨大的，利润也是十分丰厚的。但是要赚到这一暴利，就一定要持久持股。否则像当年不少的投资者买深发展，赚两三成就跑掉了，白白失去了数以百计的利润。当然这里也是有条件的：未见到阶段性顶部。一旦有见顶的迹象，就必须迅速离场。

由于领头羊具有先板块启动而起，后板块回落而落的特性，所以，它的安全系数和可操作性均远高于跟风股，至于收益更是跟风股望尘莫及的。征战股市，选择领头羊，实现收益的最大化。
