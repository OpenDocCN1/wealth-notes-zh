# # 房地产行业

中国房地产市场在持续性调控压力下经历了长期压抑之后，2007 年走出了板块量价飙升行情，而后央行出台的“第二套房”信贷政策终于成为压抑地产股和楼市的最后一根心理上的稻草，引发了地产股的大幅调整。

但投资专家认为，决定房地产需求和价格的根本性因素并未发生改变，短期的调控政策有利于使过热的楼市降温，但不会改变近年底楼市向上的格局，房地产行业的获利水平仍将持续增长，房地产行业未来 15 年的增长速度将远逊 GDP 增长。今后，房地产行业赢利能力将取决于中国经济和国民收入的增长速度，对宏观经济的信心使得投资者依然看好房地产行业的赢利前景。
