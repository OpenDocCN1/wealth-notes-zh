# 第18章 资深投资者避而不开的一些股票

2001年底到2002年，沪深两市中，个股升幅最大的几乎都是些带有重组概念的和扭亏 公司股票。而在2006年的股改中，所有的ST股票都想要重组后股改，这就给本来将 面临倒闭的ST公司带来很大的生存机会。

# 避开业务扩张能力弱的公司股票

是否选择该公司股票，最主要的标准是看其业务扩张能力，如果一家公司的业务发展 连续呈上升状态，表明该公司是一家管理好、业绩好的公司。一家业务扩张能力很强的 公司，它的业务在同类中将处于绝对竞争优势，甚至是处于垄断地位，因此，其业绩将 呈现良性的、持续的上升态势。相应的，该上市公司的股票也将有不错的表现，比如万 科就是一只典型的优质股票，每一年都在上涨，如果按当时的发行价1元计算，到现在 每般翻了300多倍。由此可以看出，选择一家好的上市公司，最好的投资方法就是长期投资。

在证券市场上，众多的投资者看好的一般都是以业绩为主的股票。其实，有一些公司 可能因为刚开始投资，还没有回报，所以导致当年难有利润，这样就要致付得出多，而收入少， 当年业绩出现亏损。但公司一旦到了发展和成熟期，新利润即不断增长。因此，对这一 类的上市公司应采取“放长线钓大鱼”的投资理念，在公司因投资而末产出时，就应该 看好并付诸行动进行投资。其实，庄家可能这时候也会趁机杀人。市场中的一部分人会 借公司亏损，打压其股票，而机构庄家则会反其道而行之。

# 避开名字花里胡哨的公司股票

在投资实践中，有这样一种现象，即一家公司经营状况良好、有着很高的投资价值， 只因为名字单调乏味，结果让很多投资者闻而远之；而一家公司资质平平、投资价值近 乎无，只因为名字取得花里胡哨，却吸引了一干投资者争相买入，并且这些投资者认为， 拥有着别致名字的公司会让他们更有安全感，殊不知，这种所谓的安全感其实是一种错 误的安全感。

对此，世界级投资大师彼得·林奇说道：“对于投资者来说，好公司施乐公司没有起 一个像大卫干式复印机（David’sDry Copbies）这样普通平凡的名字实在是太糟了，因为 果真如这样的话更多的投资者就会以怀疑的态度来认真分析这家公司了。”

似乎，只要公司的名字里有“高级”、“主要”、“微型”等字样，或者公司的名字 中有一个“x”，或者是用首字母组成的神秘缩写的，就会让一些投资者钟情有加。知名 的UAL公司把名字改成Allegis是为了吸引如今追赶时髦的投资者。

但拥有好名字的公司就一定拥有一只好股票吗？对此，聪明的投资者一定要三思，不 要为了名字而购买一只股票。

# 避开“多元恶化”的公司股票

扩张与多元化，一度成为很多国内企业成长的不二法门。不论是民企还是国企，在扩 张到了一定的规模之后，都会走向多元化经营。但不论历史还是现在，都告诫我们：远 征的途中适当歇歇脚，企业才能走得更远；而盲目扩张的多元化，很容易变成多元恶化。

现实生活中，很多公司都做过多元的尝试，与此同时，几乎大部分的危机和衰败都 与多元化战略有关。对此，一位资深的风险投资大师说道：“那些盈利不错的公司之所 以由好转坏，通常由于，不是把赚来的钱用于回购股票或者提高分红，而是把钱浪费在 愚蠢的收购兼并上。”这种一心一意想要“多元化”的公司寻找的是具备以下特点的收 购对象：①收购价格过于高估；②经营业务完全超出人们的理解范围。这两点毫无疑问
