司的卖出信号。具体来说，当以下情况出现的时候，投资周期型公司的股票的投资者就要考虑将股票卖出了：

+   （1）在有利的循环周期快要结束的时候（但是把握起来相对较难）；
（2）宏观经济出现问题的时候，比如产能过剩、物价上涨等；
（3）存货过多，而且无法按照正常情况进行销售和处理存货；
（4）劳资矛盾频繁；
（5）产品的最终需求有减少的迹象，并且还不能确认是否能够停止减少；
（6）费用开支过大。

# # 转型困境型公司

所谓转型困境型公司，是指那些在经营或管理上陷入了困境，还没有看到重新发展的希望的公司。在我国市场上最有代表性的公司是那些ST类公司。这类公司不属于以上提到的任何一类公司，因为它们没有增长可言，也没有周期性因素的存在。转型困境型公司因为在企业运营方面陷入困境，常常显得它们没有任何东山再起的希望。俗话说得好，物极必反，当这些公司到达了最深的谷底的时候，只要有一些积极的因素，就常会使得公司的发展迅速好转，而且重大成功会使转型困境型公司的股票飞涨，投资者和股东的**情绪都会被激发起来。

针对转型困境型公司，投资者需要了解和：

+   （1）公司针对困境打算如何应对？它放弃了那些赔钱的子公司了吗？
（2）公司的业务是否正在往好的方向发展？
（3）公司有没有针对困境而削减成本？
（4）该公司在经营困难时期能否经受住债权人要求还款的打击而存活下来，以及目前公司拥有多少现金，多少债务？
（5）若该公司已经宣布破产，那么公司破产清算偿还债务之后还会给股东留下多少资产？

在投资实践中，为了提高投资的成功系数，投资者还需要了解一个细节，即转型困境型公司的卖出信号。具体来说，当以下情况出现的时候，投资转型困境型公司的股票的投资者就要考虑将股票卖出了：

+   （1）已经克服了所有的困难，偿还了债务，进入了正常经营的时候；
（2）公司的债务持续下降，但是最近的一个季度又增加了上千万元的债务；
（3）存货的增长速度远远超过销售的速度；
（4）目前的收益要大于将来的收益；
（5）大客户具有一定的控制力。

# # 资产隐蔽型公司

资产隐蔽型公司的实际资产在公司的资产负债表上没有完全反映出来，原因是多方面的，或者是财务处理的问题（比如按成本计价），或者是资产升值的诱因不存在等。这类公司长期得不到市场的关注，导致其股价在**一定阶段远远低于其实际价值。因为在其隐蔽性资产得到重估以前，市场对它们的关注很少，在这个时候，占有先天优势或者做了充分调研的人是**有优势的。

针对资产隐蔽型公司，投资者需要了解和：

+   （1）公司的资产价值是多少？有隐藏资产吗？如果有，隐藏资产有多少？
（2）公司有多少债务需要从这些资产中扣除？
（3）公司是否在增加新的债务使资产数额进一步减少？
