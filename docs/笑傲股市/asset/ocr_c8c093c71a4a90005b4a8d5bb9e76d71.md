# 如何审查上市公司

投资实践中，投资者在进行投资决策时，还要对相关的上市公司进行细致、深入的研究。然而，由于各种因素的影响，投资者不可能给每一家感兴趣的上市公司打电话，或者去参观，或者像个老古董一样大门不出二门不迈地去研究这些上市公司的年报和公告。那么，投资者通过什么渠道去了解这些上市公司呢？

为了方便投资者对市场上存在的上市公司有个大致的了解，笔者将各上市公司分为几种类型，并根据其类型特点对上市公司作一个简单介绍，以求能够给投资者的投资决策带来些许帮助。

具体来说，上市公司依据不同标准可以分为不同的种类。对投资者来说，最有价值的一种分类莫过于美国著名基金经理人彼得·林奇的分类方法，即将上市公司分为缓慢增长型公司、稳健增长型公司、快速增长型公司、周期型公司、转型困境型公司和资产隐蔽型公司。

关于对上市公司的研究，总的来说，即针对所有的上市公司，投资者都应该审查其以下方面。

（1）审查公司是否回购自己公司的股票。如果回购的话，则有利于投资者。

（2）审查公司收益增长的历史状况，公司收益增长长时断时续还是持续性地增长。

（3）审查该公司的负债情况和财务实力评级情况。

（4）审查市盈率。审查该公司的市盈率是高还是低，以及与同行业其他公司相比，其市盈率是高达还是低。

（5）审查机构投资者持股占该公司总股本的比例。通常情况下是机构投资者所持的股份越多越好。

（6）审查公司内部人员是否购买了该公司的股票以及购买了多少。如果内部人员也购买了，则有利于投资者。

以上是投资者针对所有类型的公司都有应该审查的内容，下面对各类型公司需要特别审查的内容作详细的介绍。
