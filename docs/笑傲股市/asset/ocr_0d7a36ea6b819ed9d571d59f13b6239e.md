自己买东西的标准或原因是什么，没用的东西再便宜、再好，买了也是浪费，有用的东西如果物有所值，价钱贵点也值，那才是最佳选择。

买“黑马”最大的问题就像生活中盲目买东西一样，或者像盲人摸象一样，只知其⼀，不知其⼆，更不知全貌。选择了黑马，就像是选择了一颗不定时炸弹，随时都有爆发风险的可能，这对于⼀般⽽投资者⽽⾔并不合适。

# 4. 冷门股

股谚云：“冷门股上莫停留。”

依据基础分析的观点，冷门股之所以冷门就是该种股票在市场中流动的筹码较少，外部持有该种股票的不多，因而流通不⾜畅，既然外部流动的筹码较少，想要它上升就不成问题。有些冷门股，⼀般投资者很少持有，持有该种股票的主力做手便可以随心⽽欲，直线下降，持股票如果来不及脱手，等待下一次再动，天知道是何年、何月、何日。而如果投资绩优股，即使行情看坏，仍可以领取股利。

通常情况下，冷门股不会有卖盘的压力，除非公司的管理层见涨心愈，干脆不干了，否则在行情提挈过程中不会出现上档卖压，所以“做”起来，势如破竹，顺畅无比。没有哪个空头做手会笨到去抛冷门股的程度。

因此，⼀般投资者在其投资组合中，无论冷门股的价位调整得如何有吸引力，都应缩减冷门股的持有比重，更不能使其占的比重过大。因为冷门股往上调升时，尽管可入无人之境，升到相当的高度，但⼀旦回落，滑降的速度也相当可观，有时简直像滚体运动，直线下降，持股票如果来不及脱手，等待下一次再动，天知道是何年、何月、何日。而如果投资绩优股，即使行情看坏，仍可以领取股利。

由此看来，投资者最好莫恋冷门股。

股市也有“暗礁险滩”，对这些“暗礁险滩”，我们最好能及早发现，绕道而行，否则⼀不小心撞上，不仅不会在股票投资中获利，反而会葬身股海。

# 选股时具备全球性眼光

股神巴菲特在自己的投资过程中，从来不局限于本国市场上的公司，他会⼀个全球的视野去在全球的范围中寻找适合投资的目标。因为这样，投资者才能够把握住⼀个大格局。

在股票投资过程中，假如你只是想抢个短线赚⼩钱，那么听⼀些小道消息，或追逐⼀些短线热点股就能办到。但是如果你想实现在零风险下放长线钓大鱼，那么选股就要有全球观。

举个例⼦来说，1985 年微软的视窗系统问世，电脑的功能大幅提升。20 世纪 90 年代以后的⽹络技术的突飞猛进，经济全球化的格局终于成型。⼀般的说法，1985 年是经济全球化开始的第⼀年，至今已二十多年，这是经济全球化的第⼀阶段。在这个阶段，中印两国经济起飞，成为全球瞩目的对象。

2001 年“9·11”事件发生后，美联储维持基准利率在 2% 以下达 3 年之久，造成后来资金泛滥的现象。2004 年起才开始升息，不过资金泛滥已造成了原材料价格⼀路上涨。这个巨大的影响导致资源型国家的股市大涨，如巴西、印度、俄罗斯的股市在 3 年内均大涨 3 倍。沪深股市的资源股在全球化的前提下也出现惊人的涨幅，不少资源股上涨 5—7 倍。
