势制定相应策略，做到顺势而为，才是减少危险系数、通过股票投资赚钱的重要法则。

具体来说，投资者应从哪些方面来判断市场的强弱呢？

# 1. 股指走势

大盘的走势曲线是大盘强弱的最直接表现。走势曲线上涨的角度越陡峭，表示多方主动攻击的态度越坚决，力量大，势不可挡，因此大盘走势趋于强劲。反之，下跌的角度越陡，则表示空方的抛售越猛，大盘越弱。另外，走势的波浪形态也可以反映大盘的强弱。

# 2. 成交量

成交量是股市上涨的动力，成交量放大和缩小常常意味着大盘的强弱转换。具体说，当大盘处于缩量盘整时，多空双方处于交战临界点。如果市场成交量温和放大，股价上涨，表明有新的资金进场，量能开始聚集，大盘将转强。涨势末期，当成交量创下天量却不能维持时，表明多头能量消耗大，后续量能无法持续，大盘将盛极而衰，由强转弱。

# 3. 市场对利空或利好消息的反应

大盘处于强势时，人们情绪乐观，遇到利好就兴高采烈，遇到利空则反应冷淡，表现在指数的上就是见利好就上涨，见利空却不下跌。在某些市场特别强势的时候，甚至会出现有利好大涨，出利空小涨，“利空出尽就是利好”的情况。而当大盘处于弱势时，投资者情绪低落，对利好消息反应麻木，乃至产生“逢高减仓”的行为。此时市场将会出现将利好消息理解成“利好出尽就是利空”。相反，弱市中投资者对利空反应则相当敏感，任何利空都会成为大盘下跌的导火索。

# 4. 涨跌停板个股数量

涨跌停板是股价走势的极限表现，因此盘中涨跌停板的股票数量也很能反映大盘的强弱。当大盘处于强势时，涨停（或涨幅超过7%）股票数量明显越多，有时甚至能达到百余家。当数量增加到一定程度时不再增加时，表明大盘强势已尽，即将由强转弱。如果在涨幅榜却看不到涨停个股的踪影，而在榜尾却见到许多跌停（或跌幅超过7%）个股时，表明大盘已明显处于弱势，人们急于出局。

# 了解史上最惨重的股灾

股灾是股市灾害或股市灾难的简称。它是指股市内在矛盾积累到一定程度时，由于受某个偶然因素影响，突然爆发的股价暴跌，从而引起社会经济巨大动荡，并造成巨大损失异常经济现象。这具有灾难的性质，不能与一般的股市波动和股市风险混为一谈。历史上出现了几次非常惨重的股灾，给广大的投资者带来了严重的损失。下面将依次为大家介绍一下：

第一名：1973年中国香港股灾。

当时，“置地饮牛奶”事件成为市场焦点，证券公司日人山人海，人人期望一朝发达，股民把市盈率和资产值都抛诸脑后，疯狂的炒卖，恒生指数于1969年12月29日创下160.05当年新高，其后股市节节上升，1971年9月20日创下406.32新高位，不足两年上升1.5倍。1973年恒生指数于一年内大跌超过九成，数以万计的市民因此而破产，最终造成股市泡沫大爆破。

第二名：1929年美国股灾。

1929年10月24日，星期四。灾难的发生是毫无征兆的，开盘时，并没有出现什么值得注意的迹象，而且有一段时间股指还高举挺，但交易量非常大。突然，股价开始下跌。到了上午11点，股市陷入了疯狂，人们竞相抛盘。到了11：30，股市已经狂跌不止。自杀风开始蔓延，一个小时内，就有11个知名的投机者自杀身亡。当天，换手的股票达到1289460股，而且其中的许多股票售价之低，足以导致其持有人的希望和美梦破灭。
