如果你的分数在 0—55 之间，表明你是一个稳健型投资者，多注重资金的安全性，可选择国债等有固定收益的投资工具；如果你的分数在 55 分以上，那么你属于激进型投资者，愿意承担较大的风险，以期获得较多收益和增值，可选择普通股，尤其是具有成长潜力的普通股。

# ## 注意本金的安全

世界价值投资大师大杰明·格雷厄姆曾说过的一句话，或许会给众多投资者一些启示：“典型的投资者将注重本金的安全；他将在时购买证券，一般将长时间持有这些证券；他将注重年收益，而非价格的迅速变化。”股神巴菲特也曾说过这样的话：“投资股市第一是安全；第二还是安全；第三是牢记前两条。”本金是种子，没有种子便无法播种，更无法收获。在股票投资市场上，保住本金比赚钱更重要。可以说，股票投资前最应该考虑的就是如何不亏损，保住本金，然后考虑如何赢利。

投资者至少要先保住本金，然后再来追求获利的态度，是成功投资者的一大特征。投资者必须本着“不熟不做，不懂不做”的投资理念，专找容易明白的行业来投资。

将保住本金作为第一原则并不是意味着不投资，因为利润和损失是相关的，永不冒险也决定了投资者永远不会赚钱。大牌投资者通常重视的是长期效益。他们不会把他们的每一笔投资都看成离散的、个别的事件。他们关注的是投资过程，而保住本金是这个过程的基础。保住本金已经内化到他们的投资方法中，是他们所做的每一件事的依据。

投资者应该投资于“高概率事件”，而不是投资于其他任何东西。如果投资者投资于“高概率事件”，投资者几乎肯定能盈利。而损失风险微不足道——有时候根本不存在。虽然股市风险是客观存在的，但却能够规避的。因此，掌握避险技巧相当重要。那么，投资者怎样保住本金，避免投资的风险呢？

+   （1）投资自己熟悉的股票：这一道理看似简单，但在实际操作中却很难做到。原因之一在于很多投资者在实写操作中必然会带有过多的主观感情色彩，所以缺乏足够的客观性。表面上看，他购买某只个股似乎有十分充足的理由，但仔细分析，投资者就会发现这些理由都能从一个侧面反映问题，根本经不住推敲。原因之二，面对突如其来的行情，没有一定心理准备的投资者往往经不起诱惑，匆忙参战。作为投资者，对不熟不做的投资理念要多加利用，在操作过程中可以投资一些自己熟悉的公司。熟悉的公司主要分为以下3种：自己所在地的上市公司；自己所处行业的上市公司；基本面比较熟悉易于了解的上市公司。这些公司，投资者自己比较熟悉，容易作出正确的判断以回避投资风险。

+   （2）做中长线投资：中长线投资符合经济和股市发展规律。实践也证明，中长线投资的收益要比短线投资大得多。盲目追涨杀跌的股票，首先是多交手续费；其次，追涨不一定能获利，而杀跌则亏损是必然的。追涨杀跌的结果，只能是一场空忙，甚至严重亏损。

+   （3）看准时机，及时选股：即选择大市、个股调整比较充分的时机入市，避免大市和一个股见顶回调的风险。大市和个股的走势是波浪式前进的，正如大海的波浪有波谷和波峰一样，大市和个股的走势也有底部和顶部之分。当大市和个股在一段时间里有较大升幅时，就算没有政策的干预或其他重大利空，技术上的调整也是必要的。通常而言，升幅越大，其调整的幅度也就越大。当大市和个股上升到顶部时，及时抛出股票，就可以避免大市和一个股见顶回调的风险；而当大市和个股调整比较充分之后入市，风险也就降低了。所以，在营业厅很冷清时买进，投资者可轻松自如地挑选便宜好货；而当营业厅挤得水泄不通时，虽然牛气冲天，市场一片看好，人们争相买进，但投资者一定要果断出手，不仅可以卖个好价钱，而且还可以避免高处不胜寒的风险。
