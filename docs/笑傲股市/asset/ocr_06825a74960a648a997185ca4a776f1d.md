证券交易厅里，传播得最快的是小道消息；投资者相互见面，打听得较多的是“最近有什么消息”；股评家评股，最引人注目的是“最近传闻”……无论是官方的，还是报刊上登的、专家说的、马路上传的，只要有一点影子，都被投资者统统抓来，并据此进行操作。

小道消息满天飞，显然与我国股市信息披露不及时、不全面有关，但也与许多投资者迷信小道消息有密切的联系。一些投资者认为，正式消息一旦公布，机会已去了其意义。只有当消息还处在“蒙蒙状态”时就作出相应的操作决策，才有赚钱的机会，谓之路“蒙胧消息”。当然，在消息还处于朦朦胧胧、虚虚实实的时候即作出反应，一旦与正式公布的消息相吻合，肯定增强了赢利的机会。但是，小道消息由于来源不明，传播不清，其中有相当一部分与事实不相符合，还有为数不少的是庄家故意放的烟雾弹，以致许多误信小道消息的投资者最终落入了庄家的陷阱。

小道消息，之所以能够大行其道，并被一小撮利益集团所利用，与庄家炒作盛行是分不开的。大凡小道消息，最大的欺骗性就在于它总是笼罩着一个神秘而诱人的光环，让无数投资者禁不住一阵冲动。不能否认，有的投资者确实也因小道消息赚过钱，发过财，若非如此，消息也就只能胎死腹中，不会让如此众多的投资者去追逐了。但是，水能载舟，亦能覆舟，不淮不实的小道消息带来的惨痛教训，更是难以胜数。其实，真正传到市场上来，尤其是传到散户耳朵里的所谓“内部消息”，绝对是以谣传居多，有的根本就是庄家骗人的拙劣伎俩。非常简单的道理，在股市这个博弈市场中，散户的胜利，就是庄家的失败。庄家可不是活雷锋，不会傻到还没炒起来就嚷嚷得让大家知道了，再来给你折掎。他们进货绝对是“悄悄地干活”，倒是他们出货时，为了让散户接盘，这才会煞有介事地宣布他们在炒什么股票，或者说某只股票如何如何好，有什么题材，有多好的业绩，如果你信以为真，以为自己发现了一个大金矿，高兴地赶去接货抢货，则刚好中其奸计。

我们不否认某些小道消息有其真实性的一面，但更多的则是不符合事实的。盲从消息，你就永远是庄家砧板上的一块肉。因此，听到小道消息后，投资者要用自己的智慧来应对。

# 1. 冷静，冷静，再冷静

一定要冷静地分析公司提供的财务报表等有关资料，耐心地等待，在没有弄清实际情况时，切不可轻易下手，而应该多方求证，因为对付谣言的最好办法是事实。比如，我们可以向上市公司求证市场传闻是否确实，如果答案是否定的或不明确，便立刻停止买进或卖出；其次可问证券管理机构、交易所等单位来求证市场传播出来的消息的可信性，如果答案仍然是否定的或不明确，则应该密切观察注意该股票的股价变化；再者，如果该股票的价格走势开始呈异常之变化，也应该迅速处理该股票，以免急险愈深，最终导致血本无归。总之，小道消息是非多，我们不能轻易相信，要拿出你买房买车时装的耐心和细心，多加比较分析，绝不能仅仅依据小道消息就轻率地作出决定。

# 2. 离“传闻”远一点

一般说来，股市传闻或马路消息在多头市场出现的时候最为流行。因为在股市形成多头市场时，买气旺盛，一般人又习惯于听信消息而追进，这就间接地助长了该股的涨势，于是乎，原本纯属于虚乌有或空穴来风的传闻与谣言反而因投资者的盲目听从，而达到了推波助澜的目的。投资者则由于传闻或小道消息而获得一两次短暂的利润，进而更加相信市场传闻或小道消息，而不愿花时间和精力去研究上市公司的基本情况了。一两次尝了甜头，以后就会慢慢放松警惕，最终跌入庄家制造的消息陷阱之中。

由此看来，只依据市场传闻来从事买卖股票是极不明智之举。市场传闻或许有其出处，但绝对不能用来做投资股票的依据。因为传闻本身具有“以讹传讹”的不确定性，且很难求证消息的来源，尤其可怕的是如果市场传闻是庄家蓄意制造的陷阱。那么，毋庸置疑的是，听信这些市场传闻而抢进抢出的投资者，都将成为市场传闻的受害者和牺牲品。
