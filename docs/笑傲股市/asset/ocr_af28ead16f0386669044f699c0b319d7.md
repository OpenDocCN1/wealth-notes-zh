换骨。对这一类的股票，投资者也应该加以重视。比如煤业，是很典型的夕阳行业，但是煤业作为资源型的产业，不但受到全球性的资源紧缺的影响，而且也受到国家政策的保护。从2006年开始，全世界的原油价不断上涨，很多行业特别是那些用油量大的生产企业，将面临大的冲击，甚至有倒闭的危险。为了挽救世界性灾难的来临，以“煤代油”将会越来越受到世界各国重视，从而使处于夕阳行业的煤业得以转型。

从行业的属性看，夕阳行业的上市公司往往很难有大的成长性，相反，每年走下坡路的趋势则非常明显，而它们的股票同样会受到市场的打压。但是，从近几年上市的公司看，即便是夕阳行业的公司，其股票上市后仍受到市场的大力追捧，其中最重要的原因就是，公司行业出现新的转变，即公司经过重组。还有一点需要注意的是，在证券市场上，收购重组对象往住就是这些夕阳行业的上市公司。

对于上市的夕阳行业的公司来说，为了更好地发挥证券市场的再融资功能，使公司在同行业中立于不败之地，转变行业属性是夕阳行业公司的必经之路。因此，对于广大投资者来说，选择夕阳行业的上市公司应特别注意这样的问题。

# 选择强势产业

投资者在进行选股时，还应该关注那些强势产业的领头羊，强势产业的股票常常是领导大市的主角，尤其是行业中的老大，往往具有指标作用，这样往往能领先大市获利。通常，在某项多头行情中的领头羊，到大市趋势反转之后，便成为抗跌的好股票。

了解整个国家的经济形势与产业政策，分析哪些行业是目前的经济循环中的强势产业，哪些是夕阳产业，对这些情况应该做到心中有数。例如对于国家产业政策扶持的上市公司来讲，经营上的阻力小一些，获利能力会大一些。另外，在全世界的产业发展趋势中，也可以看出哪些行业是有前途的，哪些行业是面临困境的。一个炒股高手不能对世界经济潮流一无所知，也不能毫不关心国内经济动态，所有这些，其实都是炒股的基本功，这些看起来零碎的没用的知识，到了决定投资方向的时候，其作用可能就是决定性的了。

“买股票就是买未来的前景”是投资者必须树立起的正确观念，对于前景看好的尖端产业具备长远的眼光，对于高科技、高附加值的产业，尤其要加以注意。

投资者应经常去审视各类产业股票的表现形态，将有助于摆脱目前弱势产业的股票，换入强势产业的股票。投资人会发现某一行业的股票常常有某种联动性，如果某产业的龙头股票表现疲弱，则往往会被动其他该行业的股票。同样的，如果某一行业的几种指标股呈强劲走势，则将带动其他同类个股。掌握产业动向，是投资者不可忽略的选股要诀，请记住：那些强势产业的股票是投资人在股市中创造佳绩的资本。

# 抓住行业的“领头羊”

投资者在选择股票时，有个最简单的绝招，那就是选择行业的领头羊。抓住领头羊有以下几方面的优势。

+   （1）在主升浪当中，领头羊一般说是上涨最早、力度最大、幅度最大、回调最少的股票。属于最强势。

+   （2）在反弹浪当中，领头羊一般也是如此。如某一天华新水泥（600801）的表现，就说明了这一点。其他水泥股只是跟风，包括福建水泥（600802）、冀东水泥（000401）等。并且，华新水泥还在涨停板上，而它们已经展开盘中回落，并且不过上涨个百分之二三。

+   （3）从力度和涨幅看，一旦领头羊启动，还是应该跟风领头羊而不是“从属股”。追涨大牛股，不如追涨涨幅已经很大的领头羊更为安全。涨幅略大的，反而比涨幅小的安全。

+   （4）在从属股上跟风，容易吃套。从属股往往是涨幅还没有多大，获利还没有多少，就已经滞涨和下跌了，直到最后连跟领头羊也出货。
