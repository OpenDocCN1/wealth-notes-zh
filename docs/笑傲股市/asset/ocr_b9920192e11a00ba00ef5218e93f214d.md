# # 不要让“羊群效应”发生在自己身上

从前有一位石油大亨死后进入天堂，但是一进天堂却发现已经人满为患、座无虚席，自己没有地方落座。于是他灵机一动，大声喊道：“地狱里发现石油了！”他这一喊，天堂里的人们都纷纷向地狱跑去。很快，天堂里就只剩下那位石油大亨了。可是这时，这位大亨心想，大家都跑了过去，不是地狱里真的发现石油了？于是，他也慌忙向地狱跑去。完全忘了刚才就是自己散布的谎言。

各位聪明的投资者，在笑过之后你应该已经明白了到底什么是羊群效应。羊群是一种很散乱的动物组织，平时它们聚集在一起也只是盲目地左右撞，但一旦有一只羊动了起来，其他的羊就会不假思索、一哄而上，即使它们身边有狼或者不远处有更好的草，它们也毫不在意。羊群效应就是比喻人的这种像羊一样的从众心理。如果羊群效应作用在股票投资市场上，那就很有可能会引发信息追逐、股价的异常波动、内幕消息得不到有效指示等结果，最严重的情况下则可能引发金融危机，对世界的金融系统造成严重威胁。下来来分析一下羊群效应产生的原因和探讨投资者避免羊群效应的影响，为投资者在高风险的市场中提供理性的工具，起到引导投资者理性投资、保护投资者利益的积极作用。

投资者羊群效应产生因素主要有三个方面。

（1）政策信息对投资者造成的影响。我国是一个股票投资市场发展历史较短并且相关制度不太成熟的国家，但是股票市场的运行需要一个良好的政策环境。所以在我国政府的监管干预对维护市场稳定有非常重要的意义。但是如果我国对于股票的政策制定不合理或是透明度太低，政策变动过于频繁的话，那么政府的监管作用不仅有达到预期的效果，反而有可能产生负面的影响，引起市场的混乱。

（2）上市公司的基础信息噪声。投资者在进行股票投资时主要的基本参考依据是上市公司的股本结构、资产状况、盈利能力、成长能力、偿债能力等基本信息状况，这些信息会对投资行为产生很大的影响。因此报告的好坏直接影响投资者的投资决策。所以有些上市公司的管理者为了达到投资者对公司业绩的期望，维护其利益，就大量在参考信息上作假，粉饰公司形象，使得上市公司基础信息失真，从而影响投资者的正确判断。

（3）由于投资者的行为并不是完全理性，因此在决策时，不可能对所有方案进行全面系统的评估，认知过程、情绪过程、意志过程等心理因素往往也会影响到投资者的判断。这些因素使投资者更多地受到市场的主流观点的支配，而忽视市场的基本状况和公司的真实业绩，从而产生投资中的羊群效应。

那么，实际操作中，投资者到底应该从哪些方面入手来避免身受羊群效应的影响呢？具体来说有以下措施。
