# 第 22 章 如何使投资回报最大化

老司机一样丢了对生命。所以就算道路足够宽敞，行车也不要超速，要把安全放在第一位。

在股票投资上也应该秉持这种理念，重视股票交易的安全性。

理解风险对一个投资者而言是至关重要的。市场有起伏，你的任何投资都有可能赚钱或赔钱。这种普遍的投资风险是大众在投资时应当考虑到的。市场普遍风险主要有：通货膨胀风险，指当通胀率上升时，投资的价值会减少。利率风险，指当利率提高时，投资价值会下降。信贷风险，指债务无法被支付。流动性风险，指投资者因为买卖机会太少而无法卖出自己的投资。汇率风险，指一项外汇交易的投资可能因为汇率的波动受损，主要发生在全球和海外基金中。政治风险，因为无法预料的政治或制度变化而使得价值缩水。

股神巴菲特说过：“不能仅仅凭着过去看未来，那样的话图书馆的管理员个个都是大富翁了。”投资者要做到面面俱到，不能仅仅单方面分析市场，要知道投资就是一场战争，要获得胜利就要保存实力，而投资中的实力保存需要安全的保障。

通常情况下，只要投资得当，就能使收益和投入成正比，投资同样的项目，投入越多，最后的收益就越大，但资金投入多少也要靠安全性来保证，万一市场有变，不能坚持下去，就一定要平仓，保存实力。

投资，资本是很重要的，为了保全本钱，安全放在第一位。要知道筹集资本是很困难的，如果投资太过草率和主观，就容易血本无归，一旦亏损后想从头再来，就不是短时间内可以做到的了。

为提高股票交易的安全性，投资者在日常投资生活中，要注意交易的安全问题，尤其是关注网上交易的安全。

网上炒股以其方便、快捷、安全的优势，日渐受到广大投资者的青睐。但网上炒股作为一种新的理财方式，大多数投资者对其缺乏一些较深层次的了解，防范风险的意识相对较弱，有时因使用操作不当等原因，会使股票买卖出现失误，甚至发生被人盗卖股票的现象。因此，掌握一些必要的注意事项，对于确保网上炒股的正确和资金安全是非常重要的。具体来说，要注意：

+   （1）正确设置交易密码；

+   （2）谨慎操作；

+   （3）记得开通电话委托；

+   （4）不过分依赖系统数据；

+   （5）关注网上炒股的优惠举措；

+   （6）注意防黑客防毒；

+   （7）及时查询、确认买卖指令；

+   （8）莫忘退出交易系统；

+   （9）最好能到正规的网站，以免误入钓鱼网站，进入别人的骗局。

# 尽力节约交易的成本

投资实践中，很多投资者，包括股神巴菲特在内的投资大师都“憎恨”缴纳税款和其他交易成本，他们总是巧妙地安排他们的行动以合法实现税额最小化，并节约各种交易成本。对此，约翰·坦普尔顿曾说：“对于一个长期投资者来说，他唯一的目标就是使得税后实际总收益最大化。”约翰·坦普尔顿的目标——使得税后实际总收益最大化——是所有投资者都必须考虑的问题。
