# 避开那些过分依赖大客户的公司股票

投资实践中，投资者在选择股票时，要尽量避开那些过分依赖大客户的公司的股票。因为，如果一家公司把 25%—50% 的商品都卖给了同一个客户，这表明该公司的经营处于十分不稳定的状态之中。投资者如果购买了这类公司所发行的股票，其收益也会随之处于不稳定的状态中，风险极大。

对此，一位资深的投资者说道：“都说背靠大树好乘凉，但一旦这棵大树突然倒塌，那么下面的人不仅没法乘凉，而且还有生命危险。”

举一个例子，有一家公司 A 经营管理状况良好，是 IBM 计算机的主要零部件供应商，可以说，IBM 计算机是 A 公司最重要的大客户。针对这种情况，真正聪明的投资者都不会购买 A 公司的股票。原因何在？因为，A 公司虽然目前的境况良好，但谁也无法预料 IBM 何时会自己生产所需的配件或者变得不需要这种配件也照样能够生产，因此取消与 A 公司的供应合同。这样下来，对 A 公司和购买 A 公司股票的投资 者来说，都是一个大灾难。

除了取消合同的风险之外，另一方面，大客户还拥有很大的谈判优势可以逼迫公司降价和提供其他优惠，这将会大大压缩 A 公司的利润空间，因此购买这种过于依赖大客户的公司的股票几乎不可能获得很大的投资成功。

作为中国移动精密机房空调集中采购最大的供应商之一的依米康，就因过分依赖中国移动这个大客户而深陷应收账款回收风险的境地。

据投资快报分析，在依米康的主要客户名单里，中国移动算是“牵一发动全身”的大客户。数据显示，2008—2011 年近 3 年里，依米康来自中国移动的设备销售收入分别为 2563.02 万元、4463.14 万元和 4503.63 万元，分别占公司精密空调设备销售收入总和的 46.69%、57.42% 和 39.40%，占营业收入的比例为 35.75%、37.09% 和 24.96%。

正是由于对大客户的过分依赖，导致依米康的资金周转情况出现恶化。从近几年依米康的财务指标来看，依米康的应收账款存在回收风险的情况，资金链有紧张的趋势。报告期内，公司应收账款随着设备销售及工程业务规模扩大而增长较快。2008 年末、2009 年末、2010 年末，公司应收账款净额分别为 4415.07 万元、6944.59 万元、9592.22 万元，占总资产额的比例分别为 39.07%、41.22%、44.32%，如果应收账款不能及时收回，则对公司资产质量及财务状况产生较大不利影响。可以想象一下，这对购买依米康股票的投资者来说，负面影响将有多大！

如果失去某一个重要客户将会给一家公司带来毁灭性的灾难，那么，真正聪明的投资者在决定是否购买这家公司的股票时就会非常谨慎。

# 避开扭亏能力弱的公司股票

市场形象对一家上市公司来说极为重要，而衡量一家上市公司的市场形象的重要标志就是“盈利和亏”。如果连续多年盈利，市场就会把其定位为“绩优股”；如果连续多年亏损，市场就会把其定位为“垃圾股”。

因此，上市公司为了维护其在二级市场上的形象，会极力争取利润。但是，任何上市公司都不能保证本公司只盈不亏，因为有太多不确定因素在影响着公司的发展，公司也不可能摆脱环境的影响。因此，盈利和亏损都属正常现象。不过，对于证券市场中的投资者来说，选择亏损的上市公司投资，所谓的风险太大，而选择赢利的上市公司投资，将是明智的。但事实并不像人们想象的那样，买入赢利股，不见得就涨，而买入亏损股也不见得就跌。相反，那些有扭亏能力的上市公司，特别是一些通过资产重组来改头换面的公司，会被投资者视为“宝贝”，而备受青睐。
