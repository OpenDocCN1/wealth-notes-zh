# ## 快速增长型公司

所谓快速增长型公司，是指其速度远超过其他公司，而且往往有一定的持续性，例如思源电气（002028）。

在股票投资中，能寻找到真正属于快速增长型公司进行投资，恐怕是大多数投资者的最大愿望。那么，快速增长型公司又有哪些特点呢？

+   1. 快速增长型公司的规模一般很小，然而增长率却非常高。这就告诉投资者，看一家公司的规模大小，要注意根据实际情况进行判断。例如，一家公司在英国属于规模大的公司，然而在中国却属于小公司；反之，在英国属于小公司，在中国却有可能属于大公司。另外，判断一家公司的规模大小，还要结合行业来看。一般来说，成熟行业的公司规模相对较大，而新兴行业、高科技行业相对来说小公司更多。如钢铁行业中的小公司，在其他新兴行业中很可能就是属于上规模的大公司了。

+   2. 快速增长型公司多处在快速增长型行业中。但是，快速增长的公司与快速增长的行业并不完全等同，也就是说，在快速增长型行业中也会有增长较慢的公司；同样，在增长并不快速甚至停滞行业中，也会有快速增长的公司。

+   3. 高增长和高收益必然伴随着高风险，这也是投资的一个最明显特点。同样，快速增长型公司也相应地较其他类似公司有更大的风险。尤其是那些刚成立不久、被过分吹嘘而又存在资金短缺的公司，风险会更大。

+   4. 股票交易价格的市盈率是否等于或者接近于公司收益增长率。
5. 公司扩张的过程是在加快还是在放慢。
6. 如果你推测某种产品能为公司赚大钱，那么你应该调查研究一下该产品的销售收入在公司整个业务收入中是否占有很大的比重。
7. 最近几年公司的收益增长率。
8. 公司业务是否还有很大的增长空间。

同理，在投资实践中，为了提高投资的成功系数，投资者还需要了解一个细节，即快速增长型公司的卖出信号。具体来说，当以下情况出现的时候，投资快速增长型公司的股票的投资者就要考虑将股票卖出了。

+   9. 股票盈利太大的时候，比如10倍甚至20倍。
10. 在最近的一期中，销售额有所下降（需要具体分析）。
11. 最近的营业情况远远低于投资者的预期且没有适当的理由解释。
12. 高管跳槽到其他有竞争关系的公司。

# ## 周期型公司

周期型公司往往处于周期型行业。周期型行业在经济高增长时，市场对这些行业的产品需求也就高涨，公司业绩改善明显，甚至是100%以上的业绩增长。但当经济低迷时，大部分行业都不会再扩张，对周期型产品的需求也会迅速下降，周期起伏型公司的业绩和股价就会迅速回落。

针对周期型公司，投资者需要了解的是：

+   1. 当公司业绩复苏时应该预测到市盈率将会降低，当公司收益会达到最高峰时投资者应该预期到公司增长周期可能即将结束；
2. 如果你非常了解你持有的周期型公司的行业周期，那么在预测周期波动时就具有了一种优势；
3. 密切关注周期型公司存货变化情况以及供需平衡情况。注意市场上等新的竞争对手的进入，这通常是一个危险的信号。
