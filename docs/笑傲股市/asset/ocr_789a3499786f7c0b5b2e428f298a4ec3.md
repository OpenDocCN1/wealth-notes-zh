不遵循规律，止损动作过于频繁。

对此，有的投资者者说，止损应该常常做，甚至新手投资者可以不限盈利次数，但每周必须做一次止损，跟止损谈恋爱，习惯它了，就不害怕止损。因为止损是交易的一部分。不知道止损容易在一笔中将所有利润全部亏光。

可事实真的是这样吗？

投资专家认为，频繁止损的危害特别大。因为，没有哪个投资者可以承受长期的亏损，更严重的是，当资金量越来越小时，投资者可能会逐渐失去分析和交易的自信心，总是在止损和不止损之间犹豫徘徊，难以制定和执行合理的止损计划。

为了防止这种情况的出现，投资者应在交易任何一个品种之前，首先熟悉其市场规则和价格波动特点，并根据不同的品种制定不同的止损策略和止损位置。并且最重要的是，止损策略和位置一旦确定，投资者务必要严格遵守。

# 规避两个止损误区

股票投资中的止损行为，主要目的是在投资者进行了错误决策后及时终止可能带来的损失。

然而，在投资实践中，出于对损失的本能逃避，很多投资者在面对损失时会出现慌乱的情况，在止损上陷入一些误区。

# 1. 损失可以“拖”回来

投资实践中，很多投资者在遇到损失时，往往会出现优柔寡断、心存侥幸的心态，希望通过拖延来等待行情的扭转，把损失“拖”回来。特别是在遇到一些大损失时，由于心理上难以承受，更希望通过拖延将损失额度降到最低。他们心里虽然已经明白，股价已经跌到了应该止损的价格，但是因为股价仅仅跌破止损价格一点点，就抱着股价能马上涨回来的思绪继续持有，总觉得就跌破了几分钱，不一会儿就能涨回来。然而，残酷的是，往往股价不是如愿的，越跌越多，随着时间的流逝，经过几分钟、几小时、几天、几个月，慢慢地股票价格最后跌得越来越深，等到投资者觉悟时已经不是跌了几分钱，而是跌得惨不忍睹了。

实际上，每一笔交易都有最佳的止损时机和止损点，投资者一旦错过，不仅不能挽回最初的损失，还可能导致发生更大的损失。特别是在逆差操作出现损失的时候，投资者更应该当机立断，果断止损，也就是所谓的“不怕错，只怕拖”。

# 2. 止小损、亏大钱

投资实践中，也有很多投资者在具备一定的投资经验后，往往会高估自己的止损能力，在止损中陷入“止小损、亏大钱”的误区。例如，当损失在 10% 以内的时候能够及时理性的止损，可是当损失超过 50% 的时候却不愿止损。

通常在行情激烈的时候，投资者会出现判断和决策上的混乱，无法及时下达止损指令，而一旦错过了预设的止损点后，又难以执行止损。因为这样的原因而造成更大损失的投资者不在少数。

所以，无论当前的损失有多大，只要达到了预先设定的位置，投资者都应该毫不犹豫地立即止损。止损的效果很大程度上取决于投资者的自律能力，只有及时止损，才能在交易中不断提高投资能力，提高成功系数。
