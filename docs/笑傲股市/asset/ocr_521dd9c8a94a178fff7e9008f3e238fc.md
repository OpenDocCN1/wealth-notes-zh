（3）利好出尽之时，也是弃庄的时机。在股市中，由于信息的不对称性，庄家有时利用掌握的信息在低位开始悄悄进货，并一路推高。等到消息证实时，反而是庄家逢高派发的好时机，这种情况被市场称为“见光死”。因此，当股价已连续上涨非常大的幅度后，出利好消息反而容易形成头部。这时是散户投资者弃庄的好机会。

# 看懂庄家的多头陷阱与空头陷阱

庄家精心布置的陷阱，总会有许多散户投资者稀里糊涂地跳进去。为了最大程度上避免落入庄家的陷阱，散户投资者必须对陷阱有一个正确、客观的认识。庄家的陷阱的本质就是让散户投资者在高位接过庄家的筹码或在低位把筹码交给庄家的心理引导。通常，庄家在设置陷阱的时候充分利用的就是散户投资者的贪婪和恐惧心理。

庄家的陷阱分为多头陷阱和空头陷阱。

# 1. 多头陷阱

多头陷阱在股市中经常遇到。它常常是庄家利用资金、消息或其他手段操纵图表的技术形态使其显示多头排列的信号，诱使散户投资者买入，最终导致在高位买进的散户投资者被套牢。由于它欺骗性大，有不少散户投资者栽了跟头，因此，深入地剖析多头陷阱的来龙去脉，可以让散户投资者规避多头陷阱，从而减少不必要的损失。

所谓“多头陷阱”是市场庄家通过拉高股指、股价，佯装“多头行情”，引诱散户跟进，自己则乘机出货。多头陷阱是市场庄家常用的一种套牛股的方法。

“多头陷阱”通常发生在一种股票新高价成交区内，股价突破原有区域到达新的高峰，然后又迅速地跌破以前交易区域的低点（支撑水准），具体地说，就是大盘指数（或者某种股票价格）创新高后，在其密集成交区内，突破原有区域再创新高，随后突然迅速跌破密集成交区的低点（支撑线）。那些在股指（或者股价）最后上涨时买进的人或在股指（或者股价）突破买进的人，都落入了这个陷阱。陷阱区域里成交量愈多，套牢者愈多。

针对庄家的多头陷阱，散户投资者一定要冷静对待，其总体策略是：在盘面形态或尚未确认的中段整理时，宁可保持观望的态度，待支撑固定后再行做多不迟。否则，多头陷阱一旦确立，必须在原趋势线破位后停损卖出，因为在以后的一段可观的跌势中，做空的利润或许足以弥补做多的停损损失了。

具体来说，散户投资者若不惧落入围庄家的多头陷阱里，应分情况采取不同的策略，即对于短线投资者来说，应尽快出局，而对于长线投资者则首先要仔细分析手中的股票基本面有没有发生实质性的变化。如果公司业绩良好且项目进展顺利，那么就只好长期抗战了。另一个大重点是，要看一看大盘处于个什么样的运行态势，如果大盘并未出现大的下跌，则大可不必惊慌。

另外，对于有些多头陷阱，散户投资者需要了解影响大盘走强的政策面因素和宏观基本面因素，分析是否有实质性的利多因素。假如在股市政策方面没有非凡的实质性利多因素，而股价却持续性暴跌，这时就比较容易形成多头陷阱。

从消息面来看，庄家往往会利用宣传方面的优势，营造做多的氛围。所以，当散户投资者碰到市场利多不断时，反而要格外小心。因为，正是在各种利多消息满天飞的气氛中，庄家资金才能够很方便地出货。同时，散户投资者要冷静地分析市场的资金面。多头陷阱在市场资金流向的表现是，随着股价的持续性上涨，量能始终处于不规则放大之中，有时盘面上甚至会出现巨量长阳走势，盘中也会不时出现大手笔成交，给散户投资者营造出庄家正在建仓的氛围。恰恰在这种氛围中，庄家往往可以轻松地获利出逃，从而构成多头陷阱。
