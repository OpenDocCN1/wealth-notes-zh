# 表 15.6 高位緊密旗形排列的交易戰術

| 交易戰術 | 解釋 |
| --- | --- |
| 衡量法則 | 無。排列可能發生在整段漲勢的中點，你可以藉此衡量向上突破的目標價位，但最好稍微保守一點。 |
| 突破之後買進 | 買點設定在旗形排列向上突破的位置。如果你不能確定突破點，不妨等待價格向上穿越旗形排列的最高價。 |
