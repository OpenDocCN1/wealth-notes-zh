# 失敗案例

如同任何其他型態一樣，旗形與三角旗形也不能完全避免失敗。圖 14.5 顯示旗形排列的失敗例子。旗形排列本身的形狀很標準，由兩條向下傾斜的平行趨勢線界定。成交量也呈現典型的下降趨勢。按照道理，旗形整理結束之後，應該恢復先前的上升趨勢，實際不然，為什麼？可能的原因之一，是旗形涵蓋的期間太長，總共有 26 個交易日。排列期間過長，經常意味著失敗或疲軟的價格走勢（突破之後）。如果旗形或三角旗形的期間超過 20 個交易日，最好不要做爲操作對象。
