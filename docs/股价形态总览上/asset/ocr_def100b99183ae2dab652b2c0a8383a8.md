# 表 5.4 上升擴張楔形的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 向下突破的目標價位爲排列最低點。不要由突破點向下衡量排列的高度，否則會低估目標價位。 |
| 等待確認 | 雖然這種排列向下突破的可能性爲 80%，但空頭部位最好還是等待收盤價正式突破趨勢線。 |
| 部分漲勢 | 在排列發展過程中，如果看到部分漲勢開始向下反轉，可以考慮進場放空。部分漲勢發生之後，通常會立即向下突破。 |

附註：務必等待收盤價突破，然後順著突破方向進行交易。
