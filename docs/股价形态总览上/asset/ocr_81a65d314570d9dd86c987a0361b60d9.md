也可以考慮在此加碼。

兩肩具備支撐的功能。請參考圖 18.7，兩肩的較低者（右肩）成爲 10 月底下跌走勢的支撐。

建立部位之後，停損可以考慮設定在兩肩較低者的下方 $1/8$ 點處。對於成功的頭肩底排列，價格通常不會跌破兩肩的較低者。如果這個停損點與進場點之間的距離太遠，就必須把停損設定在最近支撐的下方 $1/8$ 點處。如果行情朝有利方向發展，應該調高停損點（或停止點）。

# ## 交易範例

某些人認爲老包很倒楣，但他有一位賢慧的老婆，還有兩個可愛的小孩。身爲汽車廠的黑手工人，他覺得生活很美滿，沒有什麼好抱怨的。可是，最近工會決定罷工，這對於老包的儲蓄構成嚴格的考驗，只好想辦法增加一些收入。

自從孩提時代開始，老包就認爲華爾街是一個充滿夢想的地方。當他看到圖 18.7 的頭肩底排列，決定試試自己的手氣。當價格向上穿越頸線的時候，他進場買進，成交價格爲 $16。

經過一個星期，情況的發展還算正常。股價緩步走高，但觸及 $16 \frac { 5 } { 8 }$ 的高點之後就向下反轉。股價回挫到頸線附近，直接買穿頸線而繼續下跌。突然之間，部位發生虧損，老包應該認賠賣出，或者繼續持有，等待股價回升？
