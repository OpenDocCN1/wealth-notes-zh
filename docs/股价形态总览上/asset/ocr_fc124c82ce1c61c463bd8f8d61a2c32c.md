# 辨識準則

所謂「高位緊密旗形」，名稱實在不太恰當，因為排列結構通常全然不像旗形。少數情況下，價格排列確實類似旗形(例如：圖 15.1 的例子)；可是，一般來說，排列初期經常出現短暫的突兀跌勢（持續一、兩天），接著向上反彈，然後呈現下降或水平狀的整理，整理完畢之後，向上突破繼續走高。

這個排列因為威廉·歐尼爾 (William J. O'Neil) 在《股票賺錢術》(*How to Make Money in Stocks*) 一書的推廣而普遍被接受。歐尼爾提出排列的一些辨識特質，內容請參考表 15.1。
