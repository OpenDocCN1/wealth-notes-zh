# 吊人線形的辨識特質

| 特質 | 討論 | | | | | | | | | | | | | | | | | | | | |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 開盤=最高=收盤 | 當天的開盤價、最高價與收盤價必須相同。如果走勢圖採用開盤 / 最高 / 最低 / 收盤等價格，當天的線形類似英文字母 T。 | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |
| 顯著較低的最低價 | 盤中最低價必須顯著低於盤中最高價；這意味著兩個價格的差距必須至少 5%。 | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |
| 發生在上升趨勢 | 這個線形必須發生在價格上升趨勢中。 | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |
