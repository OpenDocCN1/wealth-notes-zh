辨識準則

表 23.1 列示雙角頂排列的辨識準則。請參考圖 23.2 的過線圖，我們希望尋找中間夾著小線形的兩支向上突兀長線形。這兩支突兀長線形必須凸顯於週遭的價格行爲（清楚明確），中間所夾線形的高價也必須遠低於雙角線形的高價。回顧最近一年的走勢，雙角頂排列的兩支突兀線形長度，必須明顯超過其他向上突兀線形。在圖 23.2 中，足以媲美的對手只有 9 月底的向上突兀長線形（至少就圖形顯示的部分而言是如此。）。

表 23.1 雙角頂排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 過線圖，向上 | 在過線圖上尋找兩支向上的突兀長線形，中間隔著另一支線形。兩支突兀線形的長度，至少應該類似最近一年內的長線形長度，而且它們的高點應該遠高於中間所夾單過線形的高點。形狀看起來就像公鹿的一對角。 |
| 突兀長線形 | |
