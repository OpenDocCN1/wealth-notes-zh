# 11 | 追逃：“爱太少”和“黏太紧”

陈海贤 · 亲密关系30讲

欢迎来到《亲密关系》。你好，我是陈海贤。

当亲密关系出现矛盾的时候，如果双方都习惯主动表达指责和愤怒，就容易引起争吵和沟通破裂。而如果一方倾向于攻击反击，另一方倾向于被动逃避，那这两种人就会形成追逃的沟通模式。追逃，就是指会形成强迫性的沟通模式。

你可能会见过这样的场景：

> > 妻子指责丈夫说：“为什么你总是忙忙忙，从来不关心我和孩子？”丈夫却装作无话。

妻子继续说：“你又来了，每次都这样，连话题都不听我！”妻子越说越大声，而丈夫却越来越沉默。

在这样的情境中，一方因为得不到对方的回应而指责他，而另一方通过沉默来逃避对方的指责。就好像在沟通的赛道上，一个人在拼命追赶，另一个人在拼命逃跑。两个人的耐心就迅速被消耗掉了。

如果你去问追的人为什么追，追的人会说，因为他逃避。如果你去问追的人为什么追，逃的人会说，因为她在追。两个人形成了一种相互加强的循环。这就是追逃。

# ## 追逃组成了伴侣的关系模式

在追逃的关系模式中，追的形式有很多种。比如攻击对方，希望对方多跟自己在一起；用批评和指责的方式让对方知道自己的需要；或者用沉默和眼泪让对方多关注自己。

无论哪种形式，**追的本质，就是希望对方能有更多的回应，希望在情感上和对方更靠近。**

同样，逃的形式也有很多种。最常见的形式，就是躲避和沉默。不论哪种形式，**逃的本质，就是回避和对方关系的讨论，来回避情感的矛盾。**

不同“追”和“逃”的组合，形成了伴侣之间的关系模式。

我见过一对夫妻，丈夫在外面做生意，妻子在家照顾双亲。妻子平时在家里不开心了，就会默默流泪。溜到妻子流泪，丈夫不会去安慰，反而会把妻子的眼泪当作是对他的指责。他会说：

> > “现在都挺好的吗，你不要哭，你不要这样，你工作太忙，就不能自己找一些事情做吗？”妻子也默默地解释，就在一旁哭。

我问丈夫：“你妻子在哭什么？”丈夫说不知道。妻子却说：“他总是忙自己的事，从来不关心这个家。”

丈夫为自己解释道：

> > “你看我工作这么忙，也在为家里维持。我的工作是需要保持头脑的理智和清醒。可我没有时间给你打电话，你打电话给我，我也会接啊。”

听完丈夫这么说，妻子好像又不知道该怎么了。她好像觉得丈夫说得有道理，但心里又不是那么愿意接受，于是又默默落泪了。

**妻子的眼泪，就是一种逃的方式。而丈夫看似来说了很多话，其实在情感中，他是逃的。**

很多丈夫用作工作当前挡箭，会说：“因为工作太忙，所以做不到。”、“我这么做，也是为了这个家。”这当然有道理。

可是有的时候，我觉得更顺的照顾也有道理：因为不愿意直面夫妻亲密关系中的矛盾和冲突，自己可以不去回应，也可以有理由不用回应对方。这也是一种逃。

# ## 追逃反映不同的矛盾防御倾向

追逃是怎么发展起来的呢？可以从两个角度分析原因。

**从个人的角度，“追”和“逃”反映了伴侣各自不同的防御倾向。** 当感知到矛盾时，一方希望得到回应，通过拉近和融合来缓解关系带来的焦虑。而另一方希望离得更远，通过回避和疏离来缓解关系带来的焦虑。

**而从关系的角度，夫妻之间的追逃是两个人相互配合的结果。** 正是因为一方的亲近和拉扯，才有另一方的不愿意回应，不敢回应。也正因为一方总是不回应，所以另一方才要不停回应。

很多时候，追逃是从争的模式发展来的。一开始用争吵的模式或者新婚的夫妻，还会力争争气。吵着吵着，就有一个人怕了，觉得这样吵实在太让人心累了，于是就开始回避和沉默。

可是一个人越回避和沉默，另一个人就会指责他。越指责，越回避，形成了恶性循环。

在这种恶性循环中，人们常常认为追的人是强势、控制、缺乏安全感。但却忽略了他们是**害怕进入亲密关系**的人，怕他们常认为逃的人是不进取、不体贴、不解风情，却忽略了**他们心里想的是“不被接受”、“没法成为一个合格的伴侣”**。

# ## 沟通的责任需要两人共同承担

怎么可能打破这种追逃的模式呢？答案是，简单又艰难。

如果在亲密关系中，你是一个追的人，那么**明白，无论怎么逃其实都是没有办法逃掉的。** 因为亲密关系，都没有办法让追的人变成你理想中的样子。而你的逃，只会把对方推开。

而如果你是逃的人，你也要明白，关系的难题是没法逃的。你越逃，这个矛盾只会越大。

听起来简单，可做起来为什么难呢？是因为逃避背后，有人们更隐秘的愿望。

我见过一对新婚夫妻。在卧室里，妻子就抱住丈夫说：“你为什么总是直说不高兴，我想你说话，你总是都不听我讲？”这个妻子在用指责的方式“追”。

而丈夫特别配合地说：“好的，以后我要多听你说话。”

妻子继续说：“就像上次我跟我们公司的朋友说，你记得让我看见。我是需要你提供无条件的支持。你应该多站在我这边。”

丈夫欲言又止，想了想说：“好的，那我以后多支持你。”

看起来丈夫很配合，其实他一直在说的是：“不要再说了，快把这个话题结束了吧。”他在用他的配合逃。

看到这里，我就问丈夫：“你怎么这么快就同意妻子了呢？如果不同意呢，你怎么又经常说‘我不听呢？’”

丈夫很有点委屈：“我是配合我妻子。可是我也不能太多，如果说不，她又会不高兴。我都有点怕她了。”

我就问妻子：“你是想老公怕你吗？”
