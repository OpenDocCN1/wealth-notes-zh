# 01 “我”与“我们”：亲密关系对自我的限制与拓展

陈海贤 · 亲密关系30讲

欢迎来到《亲密关系》。你好，我是陈海贤。

曾有一个同学问我：

> “既然亲密关系意味着相互改变，我能不能守住自己，把我和思想的独立性，如果不进入亲密关系，该怎样保持自我呢？”

我想这位同学的问题代表了很多人对亲密关系的困惑。我见过很多年轻人，受过很好的教育，有不错的工作，交了很好的朋友，也有一些让自己快乐的方法。可是，他们也都有一些困惑。

我采访过其中两位，问他们为什么还没有发展自己的亲密关系。他们说：

> “如果遇到了合适的人，我觉得有亲密关系当然更好。可是现在让我自己去争取，我都没那么大兴趣了。一来没有那么多时间，二来就算现在关系好，将来关系也有这么多不确定，两个人在一起有很多麻烦，更多的是结婚以后，还有两个家庭的矛盾。我现在也还不错，所以可说单身更好。”

某种意义上，他们的选择是有道理的。他们看到了亲密关系的限制，也看到了亲密关系的不确定，所以不想去背负。

但是在我看来，他们太把亲密关系放到我的对立面，其实是一段从“我”到“我们”的旅程。这个旅程既是对自我的限制，也是对自我的拓展。

在这个视频里，我会告诉你进入亲密关系之后，我到底需要做些什么。这先来说，亲密关系对自我到底意味着什么。

# 限制来自于相互影响

首先，亲密关系对自我一定是有限制的。可是这种限制是什么呢？

想到亲密关系的限制，你很容易想到了，有了固定的伴侣，就不能再随意爱别人了。对方的朋友关系有魅力，也跟自己无关了。同时，自己做很多事都没有那么随心所欲了，有时候，需要为对方考虑，再为自己考虑，这是一种限制，对自由的限制。

可是亲密关系对自我的限制远不止于此。

在亲密关系里，人们常常把伴侣叫做“另一半”。“另一半”的说法，好像是说，自己一个人是那么的整的，只有两个人在一起，才是一个更完整的系统。这并非一个隐喻，而是一个事实。

当你进入一段亲密关系的时候，你就不再是一个人了。你进入了一个以联结的、超越个体的、有自己独立生命的系统，并成为其中更重要的一部分。亲密关系意味着从“我”变成了“我们”。

当你从“我”变成“我们”时，你就不再是一个完全独立的人了。对方快乐了，你也快乐。对方难过了，你也伤心。你的危机也会变成他的危机。对对方，你也充满自信，对方尊重你，你又会觉得自己糟糕透顶。

这种影响可以变成善意体谅，相互的滋养，也可以变成敌意的武器，对彼此的击，而你避无可避。

这种相互影响，才是亲密关系对自我最重要的限制。

# 亲密关系拓展自我的三个方面

也许你要问，既然亲密关系对我会有这么多限制，那为什么还要进入亲密关系呢？

这是因为，亲密关系不仅是对自我的限制，更是对自我的拓展。

我有一个来访者，原来是一个很消极的姑娘，她说自己一看到父母在生气、父母给她施压了，就会变得很焦虑，她也会收家务、处理不好单位的人际关系，等等。

父母一直在说她没有说说的是：你是一个长不大的孩子，需要我父母照顾。她也接受自己很像，一是她父母。

后来，她认识了一对朋友。她说：“我男朋友是一个很乐观、很阳光的人。在他眼中我一直自我负责，而是唯一的一个这么认识的人。尽管别人有时候也会说，你没有那么悲观。但别人都只是慢慢地说，只有我男朋友是直着说的。但是，我们之间有很多相似的地方。我不愿意，而是不敢，我总觉得他不理解我，而我父母是理解我的。”

“可是后来有一天，我忽然觉得，我应该听他说，我答应了他说，我应该在在一起的那天开始，他的乐观是一直在染我的，我自己的状态也开朗了很多。我开始做饭、整理家务，慢慢地觉得自己没有那么差。”

这位姑娘受到了男朋友的影响。男朋友的乐观变成了她的乐观，男朋友的能力变成了她能力的一部分。为了男朋友，她愿意开发自己的潜能。这就是亲密关系对我的拓展。

如果你在一段亲密关系中，也可以找找，你一定从自己和身上，找到伴侣的影响。越是长久而稳定的亲密关系，这样的影响就越明显。但这并不是亲密关系拓展自我的全部。

亲密关系对自我有三种拓展：

+   **第一种拓展：适应亲密关系，让自己发展出新的品质。**

也许你听过一句话：进入一段亲密关系，就为人生打开了一扇新的窗户。

对这句话简单的理解就是：亲密关系是为一段路，对方的钱也可以花，对方的经验、知识子也可以变成你的经验和见识。像上面的例子，对方的乐观变成她的乐观。这当然是一种拓展，但这不是亲密关系拓展自我的全部。

亲密关系对我更深刻的拓展是，当你有一段对自我很关键的关系，你必须改变自己，来适应这段新关系。

而在适应关系的过程中，你会增加新的经验，长出新自我。

这种适应也包括对限制的适应。有了固定的伴侣，不能随意喜欢别人了，这是一种限制。但在这种适应限制的过程中，你同时获得了一种品质，叫忠诚。

有了伴侣，你做事很多时候没有那么随心所欲了，需要为对方考虑，再为自己考虑。这是一种限制。但你同时获得了一种品质，叫责任。

这种获得不是来自于限制本身，而是来自于你对限制的“接受”。是这种“接受”把限制变成了一种责任和忠诚，这是原来单身的时候你不会有。

接受亲密关系的限制，就是一种拓展自我的方式。它会让你的心理变得更成熟。

+   **第二种拓展：亲密关系让我获得归属感。**

人需要归属于一个比自己更大的系统，否则会陷入孤独和不安之中。你越对方、越享受这段亲密关系，你获得的归属感就强烈。

在被问到单身和恋爱有什么区别时，有个小伙子跟我说：

> “最大的区别是，无论我在家里面做什么，我心里都知道，有个人会在家里等我。一想到有人在等待我，我的心就变得很稳定了。”

这种“有别人”的感觉，就是一种归属感。同时，由亲密关系开始，到组建家庭，到生儿育女，人们获得了更大的归属感。

+   **第三种拓展：亲密关系让人获得对抗时代的能力。**

怎么说呢？一个人的时候，我们是自私的。两个人的时候，我们就没那么自私了。从两个人的关系到一个大的家庭，我们对爱的感受会减少一些。
