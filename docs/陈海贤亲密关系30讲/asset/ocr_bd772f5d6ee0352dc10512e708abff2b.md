# 22 | 选择：出轨了，还能在一起吗？

陈海贤 · 亲密关系30讲

欢迎来到《亲密关系》。你好，我是陈海贤。

当伴侣遭遇出轨，无论多伤心，马上面临的第一个难题是两个人还要不要在一起？这是一个艰难的抉择。在一场被出轨的人一方会起，伤心又很多的亲密关系伤害。很多人会在这样的过程中走向断绝。

这一讲，我就来讲一下判断出轨后两个人还能不能在一起，建议关系判断哪条路径。

当出轨发生后，亲密关系常常会往三个方向发展。

第一个方向当然是就此分开。

在一起是两个人的事，分开只要一个人下决心就够了。如果出轨方心里只要不想这段亲密关系，或者被出轨方决定，那么这段关系也就结束了。这时候，两个人最重要的课题，就是如何医治关系结束的伤害。

有些时候，因为一方在经济上依赖另一方，或者双方都想给孩子一个完整的家，或者因为家人，社会，舆论的压力，两个人选择不分家，却不想，也不知道该怎么处理自己的伤害。未被处理的伤痛就会变成两个人的巨大隔阂。

有些伴侣为了维持表面的和谐，刻意不去讲出轨的事情，就像房间里放了一头大象，两个人却都不想看见它。但越是不讲，这种事对关系的削弱越大。它会让亲密关系空心化，让两个人越来越难真正接触。

压抑的伤害也会变成关系中的定时炸弹。我看到一对夫妻，关系一直不好。问他们的矛盾在哪里，妻子咬牙切齿地跟丈夫说："你自己想想，我到我生孩子躺在病床上的时候，你是怎么对我的！我当时看着在我床脚的女人打骂你，我知道我们当然是办法，孩子刚出生我们就开始做心理咨询了。但是你别以为这件事过去了，我一辈子都记恨你。" 虽然这件事过去好几年了，可是因为没有讲过，这一辈子就是一直恨着老公。他们从来没有认认真真地讨论这件事，只是把它变成了日常生活中潜在的矛盾。

第二个发展方向，是两个人修复了关系，把出轨变成了他们亲密关系中的一段插曲。

这是最理想的状态，出轨是亲密关系中的重大创伤，但关系又恢复了，并且亲密关系的质量要终终。有时候，一些伴侣反而能够从亲密关系的创伤中复原，觉得对彼此有了更多的了解，两个人的关系反而有助愈合。

修复关系的具体方法，我会在下一讲告诉你。这一讲先说说法，要想修复关系，需要具备哪两个前提条件。

# 修复关系的两个条件

第一个条件是，出轨的一方已经断绝了和出轨对象的关系，并想回归家庭。

关系，出轨的一方还无法切结与另外一个人的关系，或者还一头两占，但事实上并没有，那么双方就无法基于安全感，一直处于一方就有修复关系的基础。

很多时候，从发现伴侣出轨和伴侣分手，是一个不断拉扯的过程。这个过程包括：怀疑，出轨，证实出轨，争吵，对象告回归，原谅，发现对方还在跟出轨对象联系，重新开始争吵，直到一方扬为心感，彻底不再给另一方，两个人才开始考虑下一步。

出轨刚被发现时，出轨方常常会心怀抱，或者带着各种纠缠，难过，愧疚，也，或者至少拖延一段时间。他们常会说"我很重情"，被两边撕碎的痛。

可是他知道，当他想继续着出轨或拖延的时候，他其实已经做出了选择。关系常常在这样的拉扯中，失去了修复的最佳时机。

当然，要断关系回归家庭，对出轨方也不容易。出轨并不会像切个小指头那么简单。

有些外情维持了好多年，和出轨对象有更多的亲密体验。这个时候要切断亲密关系，对出轨方来说是有很大的失去。

可是作为出轨方，他的失落感，也会让人觉得他应该被安抚，就好像少了全世界的对立面，可是没有人去理解他的孤独。这些情绪，都需要他自己的消化。

而且有时候，看到伴侣的自我和不安的眼神，也会怀疑：是不是我和原来的伴侣相比也不够好？回家庭真的是一个好的选择吗？这些不确定和越多，他就越难有信心去选择但重新走。

说得很清楚，如果他真想回归家庭，就需要克服这些困难。

修复关系的第二个条件是，被出轨的一方准备接受这个现实，并愿意重建感情。

同样难被被出轨方克服很多的疑点。首先知道，对方出轨了，我们还能像新恋人的对吗？

很多人初婚或恋爱时没有过这样的简单假设：婚姻或爱情应该是排他无瑕疵的。他出轨，那一定不能原谅他。

而一旦出轨发生了，这种纯洁爱的假设就会被打破。

我的一来访者跟我说："虽然我很想原谅他，可我心里总有一种不安：在恋爱的时候我是独占的，现在他说不完全忠于出轨方出轨，我出轨了，我就难免会觉得不公平。现在我也想叹气叹不了。"

我另一来访者跟我说，我都不知道怎么样，我无法假装这件事没有发生，没法让这事从我们的生活里抹去。

就像我们讲过的一个故事，讲的是一对情侣在花园里种树的时候碰到一只骷髅，他们吓了一大跳，赶紧把树挪走，假装没事。看起来两个人可以重新生活，但是如果两个人心里知道那里有一具骷髅。

我是说，就算是我们选择在一起，我们也知道，花园里骷髅依然藏在那里。我们另一个人是亲密关系的时候，我总是会觉着痛苦。

可是，这样讲来，如果有人再对我说我是亲密关系，我会很震惊，甚至觉得恶心。

在遇到出轨事件之前，他们心里都有关于纯洁爱的假设。他们觉得情侣或伴侣，他们和出轨的伴侣就该情比金坚了，他们也不再可能回到从前，变成一个恩爱夫妻了。这个观念一直折磨着他们，让他们对修复关系充满疑虑。

出轨了，两个人的关系不会再回到从前了，这其实是非常、非常一件事，如果，你讲的话很回到不沟通的状态。可是不这意着就再也不可能成为恩爱夫妻了，只少，可能会变成不一样的恩爱夫妻。

经历了出轨，会让两个人关系里更真实，更真实的人性。可是，真实的人性能长出爱来。如果说纯洁的爱是水晶里养的水仙，那真实的爱情就是泥土里长成的。

出轨是夫妻关系的一个劫，渡过去，关系也许会更强。如果渡不过去，这样的婚姻就注定会失败。可无论如何，曾经的感情都是彼此珍贵的资源，而不能为它被污染了，而变成一个负数。

被出轨方的另一个疑虑，如果我这次原谅他了，他还会再出轨吗？

他真的愿意回来吗？我真的可以再信任他？我不确定第二次，本性难移吗？我可没法承诺永不伤害。

当然这些想法都有道理，原谅也确实是一种冒险。如果不想修复关系，可以完全接受这样的冒险。对于这方关系，我想要的理由已经很少了，我倒有一个乐观的理由：

实际上，大部分人出轨的时候，其实并不知道出轨是什么样子。

他们只看到了门外诱惑的一面，可他们没有真正经历过在那种感情中挣扎，没有经历过偷偷摸摸的焦虑。他们也知道出轨会对家庭和另一人造成伤害，可是很多都是纸上，他们并不知道真实的伤害多么难以承受。

所以，当出轨的人真真切切地经历这一切，感受到焦虑和痛苦时，他们也会是合适的。这也是为什么有时候出轨会实现让人更珍惜自己和伴侣的感情，出轨确实会让，但并不快乐。

出轨的困境是艰难的。要能够做出清晰的决断，需要两个人的努力，也需要小心翼翼的情感建设。有时候修好它就像做手术，

"你们的爱曾经是你那么珍贵的东西，现在它生病了，就放在病床上。就像医生动手去切除感染腺体一样，在用各种器官互换方法感染源，也需要你的伴侣帮可以，你们去一起，让这关系失血。它，现在，是你们一起来救它的时机了。"

这通常就是让出轨婚姻最好的时机，那个最近的伤口，变成了那个伤害到彼此痛苦，而要想挽回这段关系，就要靠这份伤痛来，才能把关系中的这个洞填好。

病是很强的，但并不是所有的病都不可，有病，病就是一种不无关系的态势。
