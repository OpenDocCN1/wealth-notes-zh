# 14 | 分享脆弱：如何创造情感联结？

陈海贤 · 亲密关系30讲

欢迎来到《亲密关系》，我是陈海贤。

在前面的课程里，我们讲了亲密关系中不良的沟通方式，讲的是什么解决。可是亲密关系不只是解决问题，还有培养感情。接下去两讲，我们就来讲两种增进感情的沟通方式，一种是创造两个人的情感联结，另一种是增加两人的情感储蓄。

这一讲，我就先来讲，怎么沟通，可以创造彼此之间的情感联结。

# 承认自己需要对方是联结的开始

我见过一些夫妻，在咨询室里吵得很激烈。当一方最终说出“我其实不是要爱我的妻子或孩子，我爱的是老公”的时候，他们伴侣会忽然变成另一种神情，脸上会开始有神情。

说“爱”是很难的。我指的是，当你承认自己在心理需要对方、依赖对方、承认对方重要性的时候，就给了对方伤害你的权利。有时候，你宁愿假装自己那个人不重要，也不愿意说自己其实很需要他。

可是，承认自己需要对方，就是彼此产生联结的开始。

这确实意味着某种程度的失控，因为你不知道别人会怎么反应。而这种失控，又强化了人对关系的害怕。

我们在前面的课程里学过，对爱的渴望，让人最接近亲密关系，而对被抛弃的恐惧，又让人退回避离亲密关系。

当亲密关系的一方对关系感到不安全的时候，想要的是让对方更爱对方，让对方更可靠。相反，当亲密关系让人感觉到不安全时，内心的创伤会让人陷入到防御的状态，封闭自己，以免再次受伤。

就像在咨询室里吵架的夫妻，他们有很多种沟通方式，这些争吵都会导致联结的中断。

# 产生情感联结的沟通四原则

# 第一个原则：袒露自己的脆弱

每个人内心深处都很多的纠结和不确定，平时的时候，人们会把这些东西都隐藏得很好，就像完美的外形把自己包做一个漂亮的包装。人是越害怕失败，越想把自己包装得好。

可是在亲密关系中，不能以真实的情感和面目示人是一件很坏人的事，这个难度不亚于在一个充满危险的东方古国去。

很多时候，在脆弱里，是能够、是弱小的表现。可在亲密关系，能够讲得弱的人，反而是更勇敢的人。因为这样的人能够去面对“对方会如何回应我和接纳我”的不确定。

不仅如此，在亲密关系里，脆弱是联结的钥匙，它代表了信任和接纳。有个女孩在讲述自己内心对另一半的幻想时说：

+   - “我希望他在外面很英勇，像个盖世英雄，回到家能够跟我讲他的事情，到我是里了伤。”
- “其实我这也是每个人对爱的幻想，在别人的外表，你更需要表现得坚强，可是是在家里，你需要变得真实。”

那么什么是依恋关系中的脆弱呢？比如这些话：

+   - “我很孤独。”
- “我很想你。”
- “当天我怎么了的时候，我很怕你离开。”
- “那天发生了什么的时候，我后悔。我觉得你不需要我。”
- “我对你面对自己很累了，”等等。

当然，每个人表达这些脆弱的说法都不一样。但是，当能够有把这些话讲得出来的时候，我们彼此就很好地对方讲真心话了，我们已经准备好了对方联结。

可以说，判断两个人有多亲密，是由多么大的程度，他们能够分享彼此的脆弱来决定的。

# 第二个沟通原则：看到对方的脆弱，并接纳这种脆弱。

我经常开玩笑说，任何强硬的外表背后，都有一颗脆弱的心。有时候，一个人越是表现得强硬，他背后越有很痛的需要防御。

我有一对朋友，他的妈妈总是会唠叨。可是爸爸几乎从来不跟妈妈生气，有时候实在被唠叨烦了，也都喝声几句了事。

有一天他问爸爸，妈妈说每天这么唠叨，你怎么受得了。”

他爸爸就说：“你别看妈妈这个人表面强势，她其实特别小，她一张嘴，就要开始唠叨了，我就看有出她的小一，所以每次都让着她。”

能看到妈妈强势和唠叨背后的脆弱，就是这个爸爸高明之处，也是他们夫妻一直很恩爱秘诀。
