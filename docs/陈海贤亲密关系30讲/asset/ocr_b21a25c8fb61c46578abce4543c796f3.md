# 20 | 边界：如何在亲密关系中“说不”



欢迎来到「亲密关系」，你好，我是陈海贤。在前面的课程中，我们学习了因为不处理双方的差异，让人们想要改变对方的情况，这会让两人的空间变小。在生活中，还有一种问题如果处理不好，也会让亲密关系的空间变小，那就是双方的边界问题。这一讲，我们就来聊聊如何处理伴侣之间的边界。

人与人之间是有边界的。这个边界通过很多微小的标识，区分了你我，为彼此保留了自我的空间。

+   * 在身体上，你不会和陌生人接触，也不允许别人靠近。皮肤就是你和别人的边界。
* 在经济上，别人不能随意花你的钱，也不能随意动你的东西。所有权利是和你本人的边界。
* 在心理上，有些内心很隐私的事情，并不愿意和别人分享。隐私就是你和别人的边界。

别人的事就是别人的事，有时候你就算再想知道，也是越界了。

别人的情绪就是别人的情绪，你就算再感同身受，也不能替别人感受。情绪的独立，也是和别人的边界。

这些边界是怎么形成的呢？除了法律和社会习俗，很多时候，边界是通过微妙的人际互动来维持的。

比如，有一个刚认识的朋友很热心地举起酒杯邀请你喝一杯。要么是一个热情的同学问：“我能去你家耍耍吗？”这就是一个划定边界的邀请。这种邀请本身并不侵犯边界，因为你可以有选择。

如果说“不”，不好意思，我不喝酒；或者哎呀，我最近还叫我的老师，我听着自然点。嘛，就是划定边界的意思。

可是，如果在拒绝以后，他非要说“你不喝就是不够意思”，或者“我就是要叫你家啊，这样亲切一点，别这么古板哦”，那他就侵犯了你的边界。

> 所以，所谓的边界并不是不靠近，而是在试探新的同时，尊重了别人“不”的权利。

不过你可能会想，亲密关系中的伴侣不也应该亲密无间吗？为什么还有边界？事实上，亲密关系中仍然有很多微妙的地方，需要探讨彼此的空间。

比如，你和爱人是各自保管工资和自己的收入。还有什么收入统一上缴，统一花销？如果对方有好处收入，你会让对方知道吗？还是一定要求你说了？你允许对方有自己的秘密吗？允许自己有独立的异性朋友吗？

这些问题都是亲密关系中的边界问题。它的核心仍然是：既要主动表达“我的”权利，也能够维护自己说“不”的权利。

那么，在亲密关系中说“不”，会影响两个人的关系吗？如果两个人有边界，是不是意味着两个人对这段关系不够投入，甚至怀有二心？

不是这样的。在亲密关系中，边界并不是不能分享，而是有利可分享，也有权利不分享。就像自己的房间安了一个门，可以邀请对方进，也可以不需要门。因为有了这扇门，对方想进来就得敲门，也因为有了这扇门，对方想到就进来，才会觉得更亲近。

# 亲密关系中重要的三种边界

在亲密关系中，该尊重哪些呢？没有固定的答案，这只是共同探讨的结果。但对伴侣所设的各种边界都不一样。但是有三种边界问题如果处理不好，经常会给伴侣带来困扰，需要小心处理。

# 第一个边界是：对方的心理活动。

我见过一对情侣，两人在商场逛街，女生忽然很不高兴，跟男生说：“刚刚你是不是看了那个女孩？”男生说：“我没有啊。”女生就生气了：“你就是看了，我都看见了。眼睛会骗人，但不会骗人家人。”男生说：“我真没有啊，你到底说她是哪个？”女生又说：“看你就看了，你还抵赖！”如果你们已经恋爱或者结婚多年了，也许会觉得这样的场景很眼熟。可是对于刚刚恋爱的伴侣，这就会变成一个危机。在这个场景里，女生想要男生保证她的心理。也不忠于自己，没有任何愧疚。而男生呢，多少觉得女生侵犯了自己的边界。

当然，女生的担心也可理解，在恋爱中，人总会对伴侣是否忠诚的信号异常敏感。

> 可是，无论是你想跟伴侣亲近，伴侣的心理活动就是你的边界。你既不能责怪，也没法到达。

我见过另一对夫妻，丈夫觉得妻子不够理解自己，希望妻子可以找到心理医师。本来这也是件好事，可是当妻子见了心理咨询师，丈夫就会对妻子说：“你这次跟心理咨询师聊了什么？如果妻子不说，丈夫就会生气。”丈夫觉得自己有权利了解妻子的所思所想，妻子却不同意，她觉得，这样丈夫就侵犯了自己的边界。

这个侵犯的背后是什么呢？是希望爱情完全纯粹，没有任何杂念。希望伴侣的想法完全经得起检验。可是，再亲密的夫妻，他们之间的关系也会有一点“敌意”。

就像美国著名旅行大师斯密特说：“结婚四十天，起码经过两次离婚两次决裂。”在死亡前五十天，一段婚姻能维持，全靠避过了这些难关。

你看，如果米契达的妻子要求他把离婚的念头都原本本来告诉自己，那距斯密达斯离婚的次数还得再过两次。

所以，觉得自己有权利知道对方是怎么想的，觉得自己的权利判断对方该怎么做，都是出于“纯洁爱情”的目的，也仍然是边界的一种越界。

# 第二个边界是：伴侣的情感经历。

当你遇到一个中意的人时，你会会自然想知道对方的情感经历。你会在对方心里尊重，最重要的原因想知道对方在这件事上是不是最特殊的人。想知道对方是不是真的爱你。也许，你还想知道对方的情感历史，来判断对方的情感是否可靠。

可是，如果对方说了“不”，那这就是他的边界。这是对方不信任你，而是他在为自己保留空间。
