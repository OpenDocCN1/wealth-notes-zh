# 19 | 悖论：左右为难的改变

陈海贤 · 亲密关系30讲

欢迎来到《亲密关系》，你好，我是陈海贤。

上一讲，我们讲到了改变想要改变对方的关系难题，有时候你不只是不想要改变对方，还想要改变对方的想法、状态甚至整个人，这会进一步扩大死结关系的空间。这一讲，我来讲讲这个问题。

我认识这样一对夫妻。妻子自己有成功的事业，也是非常积极的人。相比之下，他的丈夫有些慵懒。这成了他们之间的一个矛盾。

她经常跟丈夫说：“你回家就躺在沙发上看书，还老改变对方的想法、状态甚至整个人，这会进一步扩大死结关系的空间。这一讲，我来讲讲这个问题。

她经常跟丈夫说：“你回家就躺在沙发上看看书，要么你多去学一点？”

丈夫心里想的是，“好，那就让我改变，那我可不是为了气？”

妻子又进一步质问：“这是你的事，我希望你改变是为了我，不是为了让我自信，你看我什么时候关心过你的‘改’？

这个要求听起来很平常。可是她要求丈夫改变，不仅仅是针对行为的改变，也不仅是更加积极地提要求，而是希望丈夫成为一个更加积极主动的人。

丈夫说：“虽然他想改变，但我看得出来他心里不太高兴。我觉得要改变的还不是他，而是怎么希望他是真正认同，并且心甘情愿地想要去上。

妻子的话透露出了人们对内心的一种普遍想法。那就是，一方面希望伴侣按照自己的想法改变，另一方面，又希望这种改变不是强迫下的产物，而是出于伴侣自己的想法，是主动的、心甘情愿的改变。

# “要求”和“自愿”的悖论

亲密关系中的一个人要求对方改变时，到底在要求什么？其实含有2个层面的诉求：

第一个层次的行为是，希望伴侣作出行为上的改变。

比如多点学东西、多花时间陪伴侣家人，多承担家务。

第二个层次是态度的诉求，也就是希望伴侣重新找到自己的愿望和需求。

所有的改变背后都有需要。当一个妻子要求丈夫多读书的时候，妻子希望，就算丈夫不想改变，他也不能忽略我的要求，或者说认为我的要求是无理取闹。

如果只有第二层次的诉求，两个人的关系还是要有一定空间，只需要一个，放过了，另两个人或者另一方答应了要求，两个人就能化解矛盾，相互享受。可是，改变还有第三个层次的诉求，正是这个层次的诉求，让两个人陷入在右难的状态。

第三个层次的诉求心理活动的诉求，也就是希望对方的改变是心甘情愿的，而不是在要求和逼迫下产生的。

为什么说这个层次的诉求会造成关系的纠结呢？因为这个诉求包含了自相矛盾的悖论。

如果对方面的是心甘情愿的，那你就要放弃改变他的想法和方式。但如果对方是按照你的要求来改的，那就不是自愿。”“要求”这个动作本身，和“发自真心”本来就是自相矛盾。

但小看待这个矛盾，它会变成现实中的困难，成为很多亲密关系纠结的原因。就拿刚才那对夫妻的例子来说，在妻子看来，无论丈夫看书还是不看书，她都不满意。

如果丈夫不看书，那是忽视改变她，当然不满意。如果丈夫想看书了，那是在她的要求下改变，她也不满意，丈夫也会生气：“我都按你要求做了，你还要我怎么样？”

他不知道，妻子要求的，既按她的要求做，又不按她的要求做。这时候，两个人的关系就纠结，就会缺少空间。

# 陷入纠结的三个原因

为什么亲密关系会陷入这样的纠结里呢？

第一个原因是，双方对改变算不算一种付出，有分歧。

按理来算，你希望对方改变，对方做出了改变，他应该让你感激。但很多时候，要求改变的人，并不觉得对方做出改变是一种付出，而本来该读你付出，相反，要求对方改变，反而是自己在付出。

而对改变者不同意这种说法，这种相互不认同就会导致就算一方改变，也不会改变他们的关系。

第二个原因是，如果对方是被要求改变，那提出要求的另一方就会承担“强迫”、“控制”的责任，就好像负了对方。这会生产内疚的情绪。

为了避免这种内疚和自责，人们就会要求对方改变，又希望对方是自发地内心改变的，而非是要被改变。

第三个原因，也是最重要的原因，是爱的两面性。

爱的一方是想要控制，它会让人希望对方按照自己想象去改变。这是很自然的，我们常常需要自己的期待不一样。这背后，是人对安全感需要。

而爱的另一方是放手，因为谁心里都清楚，被要求的改变不是真正的爱。只有自发自愿的改变，才是真正想要，也才是真正理想的。这需要对对方的信任。
