# 29 | 子系统：如何处理婆媳难题？

陈海贤·亲密关系30讲

欢迎来到《亲密关系》。你好，我是陈海贤。

作家六六曾经写过一本书，叫《双面胶》，讲的是一家人的婆媳矛盾如何发展成了家庭的悲剧，本来恩爱的夫妻，因为一次激烈的冲突，儿子在婆娘的怒怼下杀死了自己的妻子，这当然是一种非常夸张和戏剧化的人物，但确实说透了婆媳、媳妇、老公三人关系的困境。

为什么要和媳妇之间的相处这么难？夫妻俩该如何理解当下中一代的夫妻干？这一讲，我就来讲讲这个家庭中的千古难题：婆媳关系。

婆婆和儿子为什么这么难处理？表面的原因很简单，老公是自己的亲生，但是婆是“买”一“送”的。媳妇跟老公之间多少是有感情的，不然也不会结婚，可婆婆跟新女儿之间，很多女性甚至是自己老母亲，并不喜欢自家的妈，而且两个不太爱的人生活在同一个屋檐下，要配合在一起做事，自然就会有很大的问题。

有的人可能会想：一家人要相亲相爱才对，要不喜欢自己家的婆婆，那就是妻子不对，可不是孝顺。

并非如此。如果说，夫妻之间是靠感情联结在一起的，那情况并不理想。那是婆婆和媳妇之间，原本就是讲不讲理的。婆婆和媳妇是要靠尊重规则来维持的，即使彼此不那么喜欢对方，也要保持一份表面的尊重，为了这个家和共同的未来。

可是，有时候保持这样表面的尊重也很难。这背后又有更深的心里原因。

# 婆媳争吵的核心是家庭角色

我见过一个家庭，最初的婆媳和媳妇不佳，一个家庭都平安。可后来有了孩子，婆婆来到家里帮忙带孩子，矛盾开始出现。

媳妇对婆婆每次说孩子有没有吃糖，孩子糖的吃嘛事，教养孩子的方面都很有意见，婆婆呢，看到媳妇的这点意见，心里就就不说，在暗地里跟老公吵。于是，老公就变成媳妇要婆婆：我跟你说这么多儿，你怎么要沉默就沉默呢。家里的老公呢，看到媳妇是关心，有也挑奶奶妈，妻子和丈夫的关系也开始不好。

这个婆媳到底在说什么呢？

当一个家庭有另一个女人出现的时候，两个人之间实际上有一定的竞争关系。婆媳之间最关心的问题之一：谁说了话？谁说了算？谁才是这个家真正的主人？

从这个角度，你可以理解这个媳妇做的所有的事，她是为了告诉婆婆，我才是这个家真正的主人，你得听我的。如果在这件事上，没有得到确认，那么孩子的养育方式，真正的家庭，婆婆该怎么做，以及老公应该听谁的，都会变成争执的议题。

有些婆婆宁愿承认这个规则，你“你的就听你的，听就承认你是我家人”，但并不是所有的婆婆都愿意承认这一点。

一来，家里的老小是自己这么多年拉壮大的，妈妈和孩子的情感不会比夫妻更浅。二来，儿子也不娶了媳妇就会忘了二妈，人们都说养儿媳妇，自己年纪比媳妇大，孩子已经比孩子有经验，我什么都听媳妇的吗？第三，儿子是来带看孩子的，这个辛苦，媳妇还一句感谢的话都没有，还没有埋怨。

婆婆的抱怨也是没有道理。这时候老公在左右看，上帮媳妇，还是该帮妈？

要么老婆上站帮助了妈妈，说：“再叫老太公哦，会话说。‘看具体事项，看有道理帮谁，看起来很聪明，其实是回避了问题。

因为，婆媳问题并不是具体的事情争吵，而是为情和育的是家庭角色，是谁决定这个家谁的主人而争吵？不记具体的事，是什么的事，老公在这个事上有所作为。
