# # 12｜冷战：无言的愤怒

陈海贤·亲密关系30讲

欢迎来到《亲密关系》。你好，我是陈海贤。

在亲密关系中，有时候伴侣会陷入一种这样的沟通状态：两个人都不再去追求情感联结了，都选择被动沉默，都不再拥抱或者亲昵，也不去争吵。语言的交流停起来了，但是情感的交流还在继续。这时候就进入了第三种不良的沟通方式：冷战。

这一讲，我就来讲讲冷战。

# ## 冷战会变成控制对方的手段

我相信肯定经历过冷战。冷战的形式有很多种，但是说到冷战就只有两种：不再有拥抱和亲昵，也会避免目光接触，避免任何情感的联结和沟通，甚至连吵架也不吵。

有时候他会做点其他工作什么都没发生，甚至会和老婆客气一下：“你吃了吗？”“吃了。”“今天过得怎么样？”“还行。”但是尽管客气的话，也是刻意营造心理上的距离感。而正是这种距离感会让伴侣难受。

为什么中断情感联结，刻意营造的疏离感，会成为伴侣传达恨怒和敌意的工具？

> 因为人们知道在亲密关系中，对方需要自己，自己也需要对方，这种需要有时候会变成一种控制对方的手段。

在冷战里，人们是试图通过中断情感接触来告诉对方，“不要惹我，否则我会通过不跟你有重要接触来让你痛苦”。或者“你没那么重要，我没那么需要你”。

时间长了，两个人谁也不想先服软，会怀疑地想，“凭什么要我先进退和你好？为什么要来求你？难道我就比我重要吗？谁怕谁？”

冷战的时间可长可短。一般来说，短的冷战虽然也让人不舒服，但它更像是生活的调剂品。在基调上，彼此还是相互信任。在行事上，双方也有一套不让孩子放大的机制。

我有一个哥们，平时晚上会跟我们一起吃饭，有一天他说，“我要早点回去，我正跟老婆闹脾气呢。”

虽然他回家还是不管老婆说话，但是按时出现在家里，表示自己也无心二，也是他在的这个“动荡”的时刻老婆要传递的重要信息。

很多感受的爱妻在冷战的时候，都会时不时地出一些只有他们彼此能够看懂的“橄榄枝”。当这个橄榄枝伸出来的时候，对方往往会很欣慰地心情释怀。比如，当有人会一做饭，或者某个时候会给你发一条微信“好冷”。

我记得有一次跟爱人闹别扭了，那时候女儿把一个玩具掉到沙发下面，所以女儿拿东西去够，旁边的爸爸说：“去外面拿梯子。”我说：“拿妈妈的手机去够。”

那时候我刚人刚换了新手机，他太爱惜，她哭着看向我。她一说，“不要了”，我一笑着说算了，她一哭，关系就不会冷战了，而是要有很多这样的“橄榄枝”让关系修复正常。

小的冷战里，双方都抱着好的期待，如果事情了结，也会想到对方怎么不去沟通，还不停地使橄榄枝，可是如果冲动持续很长时间，冷战又会变另一副模样。

# ## 回避型的交往模式会屏蔽亲密感

讲逃避模式的时候我说过，当伴侣中的一个得不到情感反馈的时候，会采取迫使对方需求回应，而对方为了回避冲突就会退缩。

但是，回避的一方一直得不到情感回应的时候，他也会产生很大的挫折感。为了逃避这种挫折感，慢慢地，他也开始不追求了。这时候，两个人就进入了一种深层式的冷战：回避式的交往。

与吵架相反，回避式的交往也是一种消极的夫妻模式：一个越来越不想说话，对方也不来劝说。沉默的对峙不会让互信加强，直到回避变成两个人的习惯，沟通反而变成一种不自觉。

> 在回避型的交往里，夫妻不再对对方抱期待，他们都想方法，让对方变得不重要。

回避的目的从警告和惩罚对方，变成了一种让自己心安安分的要求目标。慢慢地，回避型的人会觉察，“我就愿意这样与一方交往”。而另一方常常就是自我满足。表面上不吵了，但实际上的内里都不停着。两个人开始逃避，并逐渐变得冷漠。

这种冷漠是很报复性的。他看到过另一方的爱，有时候丈夫早下班，看到妻子了，就冷冷淡淡打个招呼，有时候连招呼都不打，各自回到了各自的房间。

最开始的阶段，如果丈夫不回家吃饭，会发个简单的短信：“我不回家吃饭了。”“我在加班”之类，妻子也会回复“好。”慢慢地，连发短信都不回也会了。

有时候妻子和丈夫还会一起出去，参加一些家庭或者朋友的聚会。在聚会里，他们也说话，和氛围里说彼此的时候，他们会说那种巨大而沉重的沉默感。

后来他们离婚了。当说起这一段时间的时候，妻子说：

> “离婚是因为我发现自己那时候真是没法拒绝自己。不是反对它，不是恨他，而是让他也在。我需要让他也很强烈。我努力让自己平静，努力忽略这个人的存在。可是只要他一出，发生一些事情，我就会跳起来。如果他不在，我肯定会自在。我就是希望他消失。”

而丈夫也说：“那段时间，我能在公司就坐在公司。我尽量把逃避隐藏起来。一想到家，我没有觉得温暖，只是觉得烦，别人看我们成功家庭幸福，却怎么也不会想到，我其实是一个有家不能回的男人。”

为什么？在亲密关系中，每个人就像是一个接收情感信号的雷达。在关系中，他们会敏锐地接收来自对方的善意，并尝试情感联结。

> 可是，如果双方的沟通一直都充满矛盾，或者双方争吵多，人们就会彼此当作是危险避之不及的压力的来源。这种对焦虑的回避会压制到极致的冷漠。

现实中，夫妻生活会活在一起，没法分离。这时候，身中总会呈现一种消极的情感反应机制：对来自亲密关系中情感压力的逃避。好像有一种情感通道，而他们逐渐关闭了这些情感通道，不再自我觉察和体验身体反应，而会转化为对关系焦虑的结果——身体反应自然倾向于减轻自己所承担的情绪压力。

可是这种身体的适应让人很难接受，就像一个人自然放松的状态变成长期紧张麻木的紧张状态。而长期紧张就是应对可能的危险。更重要的是，情绪与情感通道也，虽然屏蔽了焦虑和悲痛，但也屏蔽了快乐、激情和亲密。

这时候，人就会感觉到麻木、隔离、抑制。这也为什么一些伴侣过长期未解决的矛盾，就很容易导致抑郁。

为什么伴侣会陷入这种习惯性回避模式？

其实很多回避型沟通的背后，经常都有彼此以假设的要强存在。如果这种委却不处理，就会变成一个在心理隐隐作痛伤口，提醒着对方或者自己不行。然后就开始攻击一个人去打击自己的生活。

最初开始这种对抗是有气力的成分在。人们想说给对方：没有你，也可以。可是慢慢被压抑的时候会渐渐变得没有感觉。这时候新的关系就会变成小心翼翼的事。

埋在心底的委屈会变怨恨，而提起它又需要巨大的勇气，甚至会引发激烈的争吵。双方都在努力回避，很多伴侣就这样走远了。
