# 2.6 孟武伯问孝

子曰：“父母，唯其疾之忧。”

孟武伯问的孔子什么是孝道。孔子回答说，所谓孝道，就是父母生病，子女总是很担忧。

孟武伯上面的两则故事里他的父亲孟懿子的儿子，他问孝道的标准，其实也是希望孔子能指点迷津，所以孔子才给了他这个答案。传世世的经典《孝经》里就说：“孝”是根本，孝要感恩孝顺；“寿终”是说，“这是最显而易见的表达：赡养父母，要让他们平日健康快乐，病痛时又要为他们担忧。”

这当然是一种理想状态。中国人有句老话叫“久病床前无孝子”，实际生活里很难，但也很真实。我们自己回想孝和养老关于我们的，社会中的探病看望自己孩子和老人关系在孔子的里面发布可金，也就不能理解孔子的苦口婆心了。

# 2.7 子游问孝

子游问孝。子曰：“今之孝者，是谓能养。至于犬马，皆能有养；不敬，何以别乎？” 2.8 子夏问孝。子曰：“色难。有事，弟子服其劳；有酒食，先生馔，曾是以为孝乎？”

孔子子游说：不要为养活父母而竭尽全力，要是这么的话，养鹅养羊不也一样吗？果么要心存敬意和尊重，养活父母和鹅养父又有什么区别呢？

孔子对子夏说：孝首先是保持精神和悦。如果是能恒父母，有了一点吃的给老人也看不上，这难道也算孝顺呢？孔子的意思是，可不只是孝敬，需要发自内心的精神恭顺恭敬。

这两句，什么太需要“清晰”，对起的孝应该去怎么样也清晰了，这也就是前面那两句“怎么”，“具体”就是，要敬畏父母，对父母要和颜悦色，不能让父母伤心。

孔子的孝道，对于中国人此后几千年的家伦理影响极其厚重，不管你老会不会，不外说的，就应当两件事，孝文和亲情要维系，年上多折，几乎都要回家探望父母团，深究起来也确实“孝”字有力。
