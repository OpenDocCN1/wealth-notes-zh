有人做过统计，在《论语》里，提到“君子”的地方有107次，可见孔子对君子这个培养理念有多重视。可以说，“君子”就是孔子的理想人格路。

# 1. 那么“君子”到底怎么定义？

我还是需要先帮你梳理一下历史脉络。

在先秦， “君子”原本强调的是社会身份，《易经》《诗经》里的君子都是贵族公子，跟它相对的，“小人”就是社会地位低微的阶层。但发展到孔子这儿，他开始为这个身份分层节了一个新的人文含义，虽然“君子”偶尔还是要跟社会地位相连，但更多的时候，它已经变成了一个道德和人文概念。

一部《论语》，如果我们把君子的描述摘选整理出来，基本就是一个君子行为规定清单：追求仁义，讲究中庸，言行合礼，举止温柔，肩负道义，勇敢担当、自我反省……这些全都要有。

# 2. 君子对于中国文化有多重要？

可以说，几千年走过来，中国人的集体理想人格，一直是追随着实孔子最理想的一路演化。什么该做，什么不该做，并没有纸面上的“君子守则”，但大家心里有一张表。而《论语》里就有这个“君子”人格的源代码，甚至孔子自己就是第一个君子原型。

简单地说，孔子的学说，你也可以理解为是“君学”，学习如成为一个道德高尚的合格的人的学问。

所以，以“学而时习之”作为起点，我们开始《论语》的学习。
