# 09|孝道做起来难不难

你好，我是薪心成，欢迎来到我的《论语通读》，我们一字一句，读诵经典。

这一讲，正好可以帮你把孔子的人生做个串讲，接着来了解一个中国文化的核心概念。

+   2. 4 子曰：“吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。” 2. 5 孟懿子问孝。子曰：“无违。”樊迟驾，子谓孔予曰：“孟孙问吾也”我，我对曰：“生，事之以无，无；无，祭之以无。” 2.6 季春问孝。子曰：“父母之仇。 2.7 子路问孝。子曰：“今之孝者，是谓能养。于犬马，皆能养之，不敬，何以别为？” 2.8 子夏问孝。子曰：“色难。有事，弟子服其劳；有酒食，先生。曾是以为孝乎？”

当然这里得提醒一句，别看把字解死了：十年不是一个绝妙的数字，而是一个形容语，理解它的意思就可以了。

接下来，我们一句一句分析孔子的人生轨迹。

**十五志于学，所学的是什么？** 就是你在《学而篇》里学到的“六点”和“六点”，当然还包括你的读书养君子性格这些实际素养，或者说是学礼的起点。注意，十五这个数字，就像前面说的，是大约数的说法，其实孔子正式开始学年的时间要比这个早得多。

一句话，说《学》是来在周会上立正的，那么“三十而立”，我觉得这是孔子对于自己学礼成年的一个总结。

此时的孔子经历了一个长时间的学习阶段，对礼乐已经有了充分的理解和掌握，在社会上立得稳脚倒了！你这个立得住脚吗？怎么理解的？ 看看这个例子就能明白：鲁昭公二十年，齐景公派晏婴到鲁国向孔子问政，而那一年孔子正好三十岁。

**四十不惑。** 从三十岁到四十岁这一段，孔子一直走读书学礼，而他还走出门，向周王室的守藏史（也就是图书馆管理员）老子请教礼，又向著名的政论家家叔孙敬，老子。

到了四十岁的时候，孔子觉得自己对思想更成熟了，头脑中的知识积累和储备已不会让自己迷惑了，他有了自己的判断能力。

**五十而知天命。** 孔子在这段话说自己有足够的阅历和体验，开始知天志和命运有交感。

其实五十岁之前的孔子，虽然一直想着要出仕做官，但真的到了鲁国买手有权的权臣阳货请他出山的时候，他却果断地拒绝了，因为这恰恰是孔子的底线，目耳顺，当他自认出来出仕离开鲁国，孔子才出来做官，那时候他已经51岁了。

**六十而耳顺。** 到底什么叫耳顺？从古到今解释太多、莫衷一是，我觉得形式的解释比较合理：到达这个阶段，听说当然就能听出意思好坏，也能有个判断力，听人说话时就能对不同的评价和议论时淡淡处之、不为所动。

六十岁的孔子干什么呢？如果是用早年，早就退休在家教管管人了。他还会带着列国游历，一路赔给周天子，一路上读书人，还知道的确确实假多少事。甚至有人帮学理学形游列国累其妻丧事家，像“无人是也的流落”一样，听起来很惨。如果一个人真能做到“耳顺”，确实不容易。

**到了七十岁，心也所欲，不逾矩。** 孔子一共活了73岁，70岁其实是他生命最后的光光了。他68岁回到了鲁国门下，跟着季孙氏杀掉了冉有；而孔子去世。69岁，孔子和其子死；71岁，他最喜欢的学生回也死了；72岁，另一个学生卫君在卫国被杀，甚至被剥皮了肉吃。

但在这个时候，孔子却说自己从心所欲，不逾矩，可以说古人到了70岁的岁数原因，怎么理解呢，在古代人到了70岁的岁数原因，经多大风浪，什么都懂。另一方面，我觉得这种高寿也让他对生命的死亡人间世界了，因为死生来，随时可能在面前的死亡。同时也因为对道德的体悟和对天地、人生、生死的相信，内心达到自修和明白。

这种自由和明朗的感觉，《庄子》里有个故事可以帮你理解。高牛解牛 牛，你是否有听说过。

庖丁早先刚进宰牛场的时候，只看见牛，却找不到下刀的地方。这时好比“十岁十五”的青少年们。他经年长年的实践，开始经手十几头牛 几头，见到不几头牛，最后几十年一换，甚至几十年几十年都不杀。

不化刀，切而自开，骨肉分离，肉外入体，都自如的境界。这就是因为他对牛和自身技艺都了然于胸，而反观自身，最终他取得了在这个领域的完全自由。从这个故事，你可以想象孔子在70岁时候的自如状态。
