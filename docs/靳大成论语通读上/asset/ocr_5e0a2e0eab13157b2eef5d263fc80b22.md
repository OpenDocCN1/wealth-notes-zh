# 01 | 《论语》是一本什么书



你好，我是新文文，欢迎来到我的《论语通读》，我们一字一字，品读经典。

第一步，咱们就先来说说《论语》这本书。尤其是相隔两千多年，我们今天该怎么去读《论语》。

《论语》到底是一本什么样的书？在中国，上过学过经的人，大概都知道它是孔子和他弟子的言记语录吧，中国当代读书人的必读书，这么简单的理解当不得实用书，但真正清楚是这么一本不到2万字的小书，可并不容易。

有一个你很熟悉的西方哲学界黑格尔，他对《论语》的评价可不太怎么着。在《哲学史讲演集》里就说过，要是“怎么读？没有读论语的弟子们胡言乱语，中国《论语》的形象和地位还不如孔子。按照黑格尔的意思，《论语》里就是一些不成体系的白话道德训诫罢了，根本是给孔子开了后辈。

不过，在今天，又一个认识又有趣味。新近的一些西方哲学名家，比如美国康奈尔大学汉语言大牛“David L. Hall”，他看到孔子对“仁者”和“合礼”的解释，发现黑格尔的西方认识论为士的哲学完全不是一个路数，《论语》里说的是理性是“审美取向”的，而不是我们通常认为的道德取向。

这是什么意思？

要想解释这句话，我得先举个个《论语》里的例子。有“一个回子”和两个学生各自的人生理想。你看啊，比如《论语》里是曾子、颜回、子路颜回的“三贤”、有子等弟子，都是“贤人”啊，都“各得其所”。这“各得其所”是“审美取向”的意思。

而且我发现，虽然《论语》里孔子很少讲道德训话，但最感兴趣、最擅长且最出彩的讨论其实是“道德”和“审美”。

上面这个说法，你是说对一学一个《理想国》，看看希望用《理想国》来批判《论语》里的道德训诫是“审美取向”的。

《论语》为什么会被完全不同甚至极端对立的两种评价？它到底是一本怎样的书？我想带你回到孔子的一句话：“吾有知乎哉？无知也。有鄙夫问于我，空空如也。”这句话，是孔子对自己“无知”的自谦，但也是他“审美取向”的体现。

若是你第一次翻开《论语》，可能马上会有下面几个问题，我先来帮你把这几个难题打开。这几个问题包括——

+   - 《论语》的目录是怎么看？
- 什么是一句“学而时习之”？
- 解决一个问题：现代人怎么来读《论语》？
- 今天我们就该这么读《论语》。

# ### 《论语》的目录怎么看不懂？

今天让你一次拿起一本书，可能会习惯性去翻一翻目录，这本书的主要内容、基本内容就全部掌握了。但如果你去翻《论语》，可能就懵了。

目录里有一半看上去是人名——“颜渊”“子罕”“卫灵”“公冶长”“述而”等。这些人名，有的像地名，有的像人名，有的像官职，你根本搞不清楚它们是什么意思。

《论语》的目录，其实就是你的“学而”“颜渊”这些“篇”，总共20篇。每一篇里一句或几句独立的话，叫“章”。

为什么会这样？因为秦朝以前的“书”，不是像今天这样印在纸上，装订成册，而是刻在竹简、木片上。

每篇之间，为了便于识别，一般就用开头的两三个字作为标题，比如《论语》第一篇名“学而”，就是取开头的两个字。

# ### 《论语》为什么没法读？

目录翻完，一进入正文，你可能又要头疼了。上一句跟下一句好像毫无关系。

回答这个问题，先得从《论语》的成书过程说起。首先，在孔子的时候，还没有兴起个人署名写书的社会风气。

而我们读到的这本《论语》，其实是在孔子去世后，他的弟子们一起收集编辑的。

所以大致可以想象一下，孔子去世后，弟子们给老师、大家一起来回忆和纪念老师的言行，有的写，有的口述。

他们也没想到这就是《论语》，就一个篇一个篇地往里装，上一篇跟下一篇可能毫无关系。

# ### 《论语》为什么不好读？

今天的人读《论语》，会有很多困难。一方面是对古汉语不熟悉，字音理解有障碍；另一方面，《论语》的句式都是讲习时口述记录的，句子结构松散，很多句子省略了主语，读起来很费劲。

读《论语》最头疼的，就是那些省略主语的句子。比如“子曰：学而时习之”，后面跟的“不亦说乎”，你知道“说”的是谁吗？

# ### 我们今天该怎么读《论语》？

这一讲的最后一个问题：你今天应该怎么读《论语》？在回答这个问题之前，我先跟你讲讲古人的读法。

科举考试从唐代开始，到清代才罢，而《论语》就在《四书》里，是必读的书目。一个读书人，从七八岁开蒙，到二十岁，一生都在读《论语》。

刚开始的时候，老师不讲，就硬背，不懂也不管。但到十几岁，就当考中了，为了中举，还得再读。

清除了洋务运动，有了新式学堂和新式教材，《论语》作为全国通用教材的历史才终结。

古人读《论语》，不是问题，从哪开始读？

我的建议是，你先下一个决心通读一遍，自己读不下来不要紧，我这门课可以帮你。

通读完一遍以后呢？你就可以把《论语》当个词典来用了。

什么意思呢？后世讲修身、齐家、治国、平天下，从下到家到社会、到群体、到国家，最后到个人，这里的各种关系都是人伦的，而《论语》里的这些话，都跟人际关系处理有关。

本书的篇章没有太明确的次序，所以，你可以像一个词典，按上、中、下，随时地取从他人来读。

正是因为抽离了具体的对话语态、人物，《论语》这本书也给你提供了先验的阐释空间，可以拿来对、启迪你自己的生活和思考。

# ### 参考书目

最后我也顺便给你介绍几本帮助读《论语》的参考书。

对于今天的人来说，杨伯峻先生的《论语译注》，钱穆先生的《论语新解》，李零先生的《论语会注》，孙钦良先生的《论语本解》，杨逢彬先生的《论语新注新译》都可以用。

特别是最后一本杨逢彬先生的《论语新注新译》，可以最新版的新纪以来（2005年）学术研究中成果最多、最全面的一本。顺便说其中，杨逢彬先生不是简单的“论语学家”，他的《论语注》和《论语证》，及杨伯峻先生有《论语译注》。
