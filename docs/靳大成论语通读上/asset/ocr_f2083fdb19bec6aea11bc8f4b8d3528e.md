# 用户留言

+   一百个我

《诗经》里像当中的有题，比如《国风·周南·汝蔓》：彼采菊兮，不与我食兮。维子之故，使我不能餐兮！维子之故，使我不能息兮！维子之故，使我不能息兮！自话：‘谁：游头小伙子，为什么和我说话？都因为你的缘故，使我也吃不下去。那个游头小伙子，为何不与我说餐？都是因为你的缘故，使我也睡不着。这啥不像一个怀有少女在跟暗恋抱怨翘头鱼餐点一下也不开窍？这对比让时间所赞赏思，想。国类美诗文清词，我个人觉得更为高妙。

+   佛门门槛

孔子曰：“诗三百，思无邪。不学诗，无以言。”

野有蔓草，零露湛兮。有美一人，清扬婉兮。邂逅相遇，遂往思兮。

野有蔓草，零露漙兮。有美一人，婉如清扬。邂逅相遇，与子偕臧。

这是曹衣，写在与一个零素未闻的清楚，男子在首首章间与女子不期而遇，一见倾心。常记美美草间，和露满美，美地点在常首草的美美间，白合之意，记此浪漫而唯美。出自《郑风·野有蔓草》。

+   李盈

我印象比较深的是诗经国风中的《击鼓》，其中有“于嗟女牛”的“执子之手，与子偕老。”按照我们现在的使用语境，这是一句很浪漫的话，表示想要与爱人白头偕老。不离弃。

但是这句话在诗经原居中，却是一种颇为悲壮的场景。下一句也是与公主和闺房的士兵在一起，而这是“死生“，不离不弃。于此而言，不为信古。”用今天的话说，就是天各一方，后会无期。

《击鼓》不是结婚典礼的祝文，而是征战鼓角下的出征。另一方面体现了战争的残酷和无情，另一方面则表达了对伴侣的集体意识的背离，一句诗通过子小体生理的追求，流露出浓浓的人主主义气息，让人感慨交集。

+   巴吉纳

我比较喜欢《诗经》中两首，分别是《桃夭》《葛覃》。

1. “桃之夭夭，其灼灼其华。所谓伊人，在水一方。”《白草》中，其意，朦胧的雾华，在水一方的白美，这一切构成勾起了我们东方人偏爱的朦胧美。有句古语形容它，这诗妙在若实若虚，意在只可意会不可言传，美得让你无法释美。

2. 言告康诰，淑慎尔思。薄言采芹，薄言采芹，言采其芹。这句话说的我内心常常心潮澎湃，说我想回报家亲。快回去看父母。洗和不清洗不净，回家常去看老人。

如果说《静女》代表的是浪漫主义，《葛覃》则属于现实主义。试想闺女在回家看望父母，要回去看望父母，故放下一切来怎么样？犹如《葛藤》中的一女孩子们，手工作作忙个飞跌，冒雨采葵、喜洋洋。

以上两首都写得非常神佛，雅俗共赏。

+   楚云师

我对诗经的了解不多，只知道它是用无上质朴的笔、血流的写，而它国式于人的时间。类似地事，诗经就像古代人交际的场景，土王臣们的对话，临江湖的春天，不知我的理解是否正确。

+   匣华牟民

关关雎鸠，在河之洲，窈窕淑女，君子好逑。后几首国风和草，满篇生香着春意、最后最美女的在车中生活。

+   冯鸿健

“他山之石，可以攻玉”

看直就抓两个方面，他山之石和创新。所谓创新就是“古为今用，洋为中用”。谁的讲，就是想利用自身发现的方法、技术管理来为“未来”作打算，这不但可以节省时间的人格的投入，还可以节省时间的创新。《诗经》像很多诗家，即在“他山之石”的思路上，根据自身的实际，创造性的利用“他山之石”，固守着古式的创新，可能会造成顽固，不利于自身的发展，与予修行

+   匣华牟民

昔我往矣，杨柳依依；今我思来，雨雪漙漙。这句诗文长的诗，每当我出远道，想到雨水依依，而今天归来时，却下着漫天的大雪。在这里，诗人虽作为世界为我对诗经印象非常深刻，可以与我分享。时光文道的意思。这里的“法难唱啊，他并不说明时间过得飞快，而是说明两个不同时晴的天气。（摘自每天听本书）

+   独行千里

经常听说，不知诗无以言。忘之前对于这句话很怀疑，后是看撒老师的课讲了个万和《万》，原来诗经就于现在的语言使用规范，通过课后的言灵类是流传千古的方格书法，这样既避免了当面冲突的尴尬，也能表达共识。这种是中礼素到影响中人的日常生活，中国人讲的面子，也是其中体现出来。

+   小邱吃

桃之夭夭 与予偕老。我的最爱。朴素的生活，与子偕行。

+   荆阳

我对诗经的了解源于上小学时候的一部电视剧《武林外传》里面有这么一个桥段。曰月同风赋，在现在的苏水条和江便四出了“四出风赋赋，江便风“，江便大举小诗，我是对诗经印象非常深刻，可以与我分享。日同风江江便可见的诗经，在中国人心中的地位及其程度。

说到诗经，我脑子里最经常出现的一句话就是《蒹葭》“ 如江深，如取而藏，”。论读是也用了这句。以我一人整体保持谦恭的态度，面对欲望保持防范意识，对自己独处，要时常不断提醒自我保持警觉，不可中作出，这时这句诗也会以自我独处，另外远虑尽大之时，也会以此为警告告诉自已保持对大自然和神明的敬畏之心。

+   Mr.梁

诗经，如果没有蒹葭苍苍，白露为霜。还首《秦风》。这充满阳刚之气，慷慨激昂的诗。

春风无花：

岂曰无衣？与子同袍。王于兴师，修我戈矛。与子同仇！岂曰无衣？与子同泽。王于兴师，修我矛戟。与子偕作！岂曰无衣？与子同裳。王于兴师，修我甲兵。与子偕行！

其实最早应该是在中学教材，但那时候真是感觉，现在在背诵的情况下，才发现有这首饱含力量的，男精神气概，只见该国篇，这首打胜秦的精神同仇敌忾表现的淋漓尽致。深一步的讲，作诗的目的是为了报王。救报周天子，但正是这样的君后来看首篇救国的军史，后手尖掉了无辜的，百姓致民命的军队，后来支持了王。夫子的悲哀也就在这里。在错误的时代，夫子的伟大也在这里，他在了最好的时间，他在漫漫长夜里留下了一盏火种，后世也看到了光明。
