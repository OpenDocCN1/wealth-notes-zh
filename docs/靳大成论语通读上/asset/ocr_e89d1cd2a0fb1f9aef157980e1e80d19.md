# 本篇总结

学完《学而篇》，你现在已经大概了解了孔子所提倡的修身就是学习的人生模型，明白了自己的目标就是学习，也学会了人生。

至于如何培养，孔子提到了不断学习、少说多学、恭敬，考虑时间、守望，和为亲善等。这些通常是我们父母的期望，也不完全适用，读完《学而篇》，你大致会有自己的取舍了。
