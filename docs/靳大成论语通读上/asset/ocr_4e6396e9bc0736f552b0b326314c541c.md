# 06 | 中国人的基本气质

1.10 子禽问于子贡曰：“夫子至于是邦也，必有闻所谓矣。切其求之：于吏日，不其可也；求之父、乐、和，以比得其。夫子于父之道，其谁异乎人之求之与？” 1.11 子日：在，观其于乡；观其民。三年己改于父之道，可者孝矣。” 1.12 有子日：“礼之用，和为贵。知和而和，不以礼节之，亦不可已也。” 1.13 有子曰：“信足以成于义。不可美也。慕于十目，远道而远之。因不失亲，虽无友如敌，敏乎事而慎于言，有学无道进也，可谓好学也。”

你好，我是新成文，欢迎来到我的《论语通读》，我们一字一句，谈谈经典。

这一讲，你去读很有名的那句“中庸、良、恭、让”，它在别的理解里，这是中国人最应该保持的国民气质。

1.10 子禽问于子贡曰：“夫子至于是邦也，必有闻所谓矣， 子贡曰：‘求之，良、恭、俭、让以得之。夫子之求之也，其诸异乎人之求之与？’”

子禽问子贡说：先生每到一个国家，一定会听到这个国家政治的许多事情，他是打听来的呢，还是人家主动告诉他的呢？子贡回答：先生的是人道、良善、恭谨、俭朴、公正，所以人人都是主动地告诉他，先生这种求问的方式，和别人求的门径，能一样吗？

这段话其实是孔门弟子的公话，是陈氏的官，赞他能把君子的学生。而子贡，名曰端木，子贡是他学生。他名卫国国之人，但开口讲，语言甚精，盛德无友，很善于做外交。

如果你把这段话看作子贡在他自己的生逢乱世，很有特殊的，那 么有没有直接的反映呢？其实是很有限的。他并没有直接回答子禽“这是和”是“和”，而是把先生的形象、作为及给人的印象和影响用描述的一番。

由于孔子具有和睦、良善、谦恭、俭朴、礼让这样的品格，走到哪里都很受欢迎：了解什么的情况，人家都会主动告诉他，甚至有些地方都没有有意见的，别人就主动地讨了。

子贡这话的背后，其实是在调老师的行为的修养。进一步说，我在上一节里提到的“生活实践人追求”君子的最好范例，就是他的老师--孔子。

你在看方面的电影、小说的时候，肯定对“绅士风度”这个词很熟悉，但你忘了没，但们其实也有一个反对的“君子风度”。什么叫“君子风度”？就是这五个字：温、良、恭、俭、让。在《论语》里，它说的是天子的风度。

而站在旁旁旁旁，我觉得我们几乎可以概括中国传统文化理状态下所要塑造的国民基本气质。

我们仔细想一想，今天的中国人，即使在现代社会面对多少欧美同的洗礼，可还是不知不觉地用温、良、恭、俭、让的行为美来追求和评价思想，这不能不说孔子的美门弟子在2000多年前留给我们伟大的遗产。

1.11 子曰：“父，观其志；父，观其行；三载无父于父之道，可谓孝矣。”

孔子说：老父亲在位的时候，看看他的志向；老父亲不世了，就看看他的实际行动。能于三年不改老父孝为治国理想的方针政策，可以算孝子了。

关于这句话，有人都觉得孔子说得很有点绝对，孝道怎么能“三年无父于父之道”呢？不是太死心肠了。甚至什么“父之道”，说法也有点别扭。

我的一种看法就是：这里的“道”，可不是简单的家庭事，说的也是治国安民之事。

需要注意的是，我在这个论里提到过，《论语》是一个上下文的合文全书，这显然导致有些比较生硬的上下，理得容易混淆，像《论语》里的历史事件，为于会把它脱去当时的情境的时候来，就很容易被现代人带入与人之理解的误差。

要知道，孔子所生活的时代，春秋两百多年，其中有三个，天国三十二，诸侯国的三位怎么，最大的儿为三家，家国中这个层面，字样的承，易示的，是历史，社会，孔子是有意而为之。

他想说的很可能，即便他为大夫、家臣、大夫、诸侯位，在父亲去世后接替了位置，执家了大位，他也应尊重父亲的政策。

且不论他的改变要经过试错阶段，不是行得通；就算是行得通，也应该考虑各方面复杂的关系、接受程度、力量的对比、人们认可度。通过几时年的反复尝试、探索、摸索才到达，才有可能实现平稳过渡，达到改革的目的。

所以，在这个意义上，孔子确实是一个文化保守主义者。在处理社会和政治化变革问题上，他属于稳。

1.12 有子曰：“礼之用，和为贵：先王有，期美矣。 小大之节也，有所不行。 知和而和，不以礼节之，亦不可已也。”

有子说：在礼所作用的中，理和调适最为重要。古代王之道，这一点最可贵，不管是政大的事，还是要解决小问题的，都要照顾双方的一个。但是，如果不行不通的地方，为求和气而和气，而不是用礼来节制的时，这是没有法实现的。

有子是孔子的弟子，叫有若，他这句话不难理解，但涉及到贯穿儒家2000多年来的一个关键概念：礼。

在这一讲里，我不准备详细解读“礼”，我希望你关注的有两点：

+   第一，礼的运用，根本宗旨在于达成社会生活的和谐和利益。正是从孔子讲“礼”以后，“以和为贵”这个观念从根本上激发了中国人的心理建构，而与逻辑、礼仪，相融和。哪一场单纯的吵架，最常听见的就是这句“以和为贵”。

第二，你需要注意，有子在这里特地强调，“知”和不是说死板，是研究其要的，不能为了“和”的目的而放弃原有原则和规则，守成底线。

1.13 有子曰：“信不足以立也。不可美也。慕于十目，远道而远之。因不失亲，虽无友如敌，敏乎事而慎于言，有学无道进也，可谓好学也。”

有子说：信字的含义要合子，语言才显得诚。谨慎的态度要求我们于礼，才能做得更，有姻亲关系的人如果亲近，也可以当家族的人。

注意，这里说的“信”，是合大义，这是最简单也，孔子说得很都是人、行、不，比如哪个叫什么名字的，小和人不一样，生女儿没事，却像来了样子，他做那不合常理，结果也合，像这样的例子就不算合大义。

只有符合大义的，才值得我们践行和落实，这个才“信”。虽然“信”“用”都范是子和的信，不是正而偏，但和用道的大范围，需要用大义的，需要用大义的来。
