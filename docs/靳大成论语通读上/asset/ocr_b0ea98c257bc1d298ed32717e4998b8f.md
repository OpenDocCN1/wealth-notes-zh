# 08 | 《诗经》真的思无邪吗

2.1 子曰：“为政以德，譬如北辰，居其所而众星共之。”2.2 子曰：“《诗》三百，一言以蔽之，曰：‘思无邪。’”2.3 子曰：“道之以政，齐之以刑，民免而无耻；道之以德，齐之以礼，有耻且格。”

你好，我是新一老成，欢迎来到我的《论语通读》，我们一章一义，边读我思。

我们经常会看到很多人引用《诗经》，作为《诗经》的整理者，孔子又是如何看待《诗经》的呢？

2.1 子曰：“为政以德，譬如北辰，居其所而众星共之（拱之）。”

孔子说：施政要以道德教化为先。（做到这一点）就像天上的北极星一样，只需自居其位，但所有的星辰都围绕着它转动。

这是一句孔子对国家的建言。其实，北极星是古人环境这个美比，先秦诸子都有论述。源解家这段话，我们只要顺着会道。君王自然如北极星，而法家则法家，又会说成了律令，下策之人有法臣、各习其职，而君王只需要高高在上地控制住力。

但你要注意，孔子这里说的“德”，不同于老子的自然适之，也不同于法家的治术和谋术。孔子说的德，泛指你的民和全社会，认为德政，自然适合统治合适的民，为政者自己得是有道德的人；二、治国应该实施惠民德政。

这里说的有道德的人，不用多说，就是孔子的理想人格，“君子”。那么孔子说的“惠民德政”呢？只要你想我前面讲过的，孔子提倡礼、义、仁、周、公、文、明、武。他在想代尧、舜、大、禹、汤、文、武、周公，以圣君贤相的形象，成为理想政治的立面，直到商汤王朝最后一代到君王的那种倒退面前。

且不管有三千种解释传说历史事实是否相符，至少《诗经》中上古三代的神话，以《诗》为雏形是那个神话的上层文化，是贵族雅歌的儒家礼仪合。而且，从文化思想的视角来看，周公的制礼作乐，从迷信鬼神、直从天命的殷商神主主义倒向德主，进而构筑更为经验性的传统的人性大节，并以此论道德，这确实是种伟大的重大进步。

不过，你得注意一点，孔子这针对当时情况的政治主张，从后到2000多年来《诗》的成长历史，不断地发展，最后摆脱了它们身处的时代，成为一种具有普遍意义的民族统构，在更大的历史的社会文化结构中，对历史生长了巨大的影响。

什么影响呢？它变成了一种思想武器，后世的读书人利用，好高鹜远，彼此以“无颜吾童”或嚣“好谈道义”的“篇”；占道德制高点，从而形成强大的社会压力。

2.2 子曰：“《诗》三百，一言以蔽之，曰：‘思无邪。’”

孔子说：《诗经》三百篇，若用一句话来概括它，就是思想纯正。

“思无邪”这一句，就是孔子对于《诗经》最概括性的判断，是非常有名的一评价。

当然，“思无邪”也不是孔子的原创，而是孔子借鉴《诗》（《颂》里的“舞”（jiòng）这一篇章的一句采头概括诗经的主旨。

我在《学而篇》里讲过，孔子时代知识阶层对于《诗经》的使用，大概和你今天跟人交流的时候为了显示有品位而特别使用成语多多，已经有汉学大家王力《诗》的说法，就已经是有解释各种注释才读懂的情况，所以这句语境差来也就是众无疑，非常简单。

历代学者重视“思无邪”的“思”字，有的说是无解义的虚词，也有的说是思想的意思。不管怎样，对章句的意图影响不大，帽子不必在这个争论头上，重点在“无邪”二字。这是孔子对《诗经》的总体评价。

那么，到底怎么理解这个“无邪”呢？明代的一个儒生这事很有意思，因为他没有明白好多男女放荡思忆思男怨女，朱熹解读，的是“淫者”，不符和符合儒道思想体系，但又不敢说孔子讲得不对，就各种方法来回地圆滑。

我觉得，理解这个“无邪”，得看看相反面是什么？我们今天正邪不二立，邪的反面是正。

孔子评价《诗经》的第一首诗《关雎》，“乐而不淫，哀而不伤”。这说的是，乐，不离开不过分；哀，不是过分。这种情感是符合孔子所定的礼的。但孔夫子对男女放恣交欢没有那么多限制。所以说他也概括《诗经》的态度，赞扬阴阳正正，不过分。
