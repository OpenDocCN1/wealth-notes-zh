# 11 | 孔子的选人标准

![](bbox=[0.1, 0.05, 0.2, 0.08])

你好，我是新大成，欢迎来到我们的《论语通读》，我们一字一句，读懂经典。

这一讲总共讲4章，你会学到很著名的那句“知之为知之，不知为不知？”我还会讲到孔子的选人标准。

> 2.16 子曰：“攻乎异端，斯害也已。”

孔子说：过于严厉地攻击各种异端学说，这是有害的。

我讲的，历代都有争议。在《字源网》里查，异端，《论语》这种金句有很多上下句，这句上下文确实存在多种可能的可能性。回到的意思，从‘攻’ 字看，有攻击的意思，也有专题的意思；斯害也已，可以理解为‘这就是祸害’，但是理解成‘祸害就停止了’ 也说得通。

那么你怎么理解孔子表达的意思呢？到底他是主张对异端打打击，还是容异端思想呢？我当然没法向2000年前的孔子起问，但是我最近自己重新去把这句话查过来，我觉得这才更符合孔子思想中的中庸精神。

这个理解很难，道家有讲非类的话，真正的目标是，都是主张人类是通的，合理的，视野广阔，心能容物，不会执着整天和人反复辩论，争高下了。

如果你你时间、精力甚至头脑明都是放在非之类之中，徒增一分为二，反倒说明自己是不够的，是缺乏对生命本身的体认。这样对有志于为学、为君子的人肯定是有害的。

另外我是提醒，指中，中今天最常用的‘异端’ 这个词，最早出自其实就是这个词，‘异端’ 的意思，你要花些时间问一下历史的话，就会发现没有异端。

自社会，制度独尊的时代，儒家以外的思想似乎都是异端；佛教曾经在中国流传很广，但它自己在信者中就是本‘本端异端’，佛教教义于其他不信者来说就是‘异端’。所以有九十六种异端之说；而对于犹太教来说，基督教当然算异端；对于基督教来说，东教改革后诞生的新教，又何尝不是异端？

人类历史上出现对各种各样‘异端’的打压和禁杀，但另一方面，也确实有很多新的思想和学说，正由于这个角度，不要去过分地纠结，应该说现代人的基本修养。孔子表达的‘异端’思想里其实该得到每一个现代人的重视里。

> 2.17 子曰：“由！诲女知之乎！知之为知之，不知为不知，是知也。”

孔子说：仲由，我告诉你知道的真正意思是：知道就是知道，不知道就是不知道，这才是真正的知道。

仲由，字子路，是孔子最著名的学生之一。子路这个人很豪气、快人《孔子家语》 和《史记》 都记录了最初子路成为孔子的故事。

子路身材高大、勇武过人，头上插着鸡冠帽，脖子上挂着猪獭牙，腰上高扎着大板。瞧不起性格温和的孔子，就着讥笑欺负孔子。为此，子路设计用礼仪让子路来服从，而两个人还没过招，子路就被孔子的威严震慑住了，从此就正式成为了孔子的学生，从此心悦诚服地看着孔子。

这里是子路第一次登坛，孔子直呼其名。以后你听老师，每一次都直呼其名，孔子说在路，这说明了他们的关系亲密无比，同时子路登坛的话，也出孔子思想中的一个重要问题。

前面我学过学与思的关系：“学而不思则罔，思而不学则殆。” 在这一章，又涉及到了学与思的关系。“知之知之，知也知之，虽然只有短短的几个字，简括凝练，内容却非常丰富。

学是一个主动求知和学习，思是批判性思考者，是立志求知和考究的‘知’ ，而‘ 知’ 是孔子所引申的一个意思，就是智慧的‘智’。

所以孔子告诫了弟子一件非常重要的事情：求知的必须真知必须真诚，此外再无其他通向知识、真理与人生意义的大门。只有从根本上认识到自己是无知，是‘一无所知’，你才可能走进真正的知识、真理的大门。

请你注意，在这个简短的对话里，孔子实际上提出了中国思想史中认识论、认识论的两个重要的问题：认识活动最关键的起点，那是什么？一个重要的出发点是‘什么’ 的‘什么’ 是不知？‘什么’ 是永远不能与‘什么’的界限，人类认识活动永远需要回答又永远无法给出最终答案的问题。

> 2.18 子张学干禄。子曰：“多闻阙疑，慎言其余，则寡尤。多见阙殆，慎行其余，则寡悔。言寡尤，行寡悔，禄在其中矣。”

子张学如何在政府官场谋职。孔子说：多听，遇到有争议的部分多保留，少说错的话，能够听到并确定多的部分，就会有少错话；多看，遇到没把握的部分先不做，少做错事；做得少错的话，说错的话，行为少错事，俸禄就在其中了。

这看起来像是在当时的职场谋略的学问，但实际上后世的君子奉行下，早就变成了中国人对人生态度的极致。

这个想学干禄的小伙子就是子张，叫颛孙师，孔子的陈国弟子，这个小伙子有‘野心’，一见到孔夫子就跃跃欲试，准备干一番大事业，这就叫‘学干禄’。

> 2.19 哀公问：“何为则民服？”孔子对曰：“举直错诸枉，则民服；举枉错诸直，则民不服。”

鲁哀公问：该怎么做才能让群众服从呢？孔子回答：提拔正直的人，让他们位居于不正直的人之上，他们就群众就服从；如果把不正直的人置于正直的人之上，人们就不会服从。

这一章的意思，其实可以与联系著名的《出师表》 中‘亲贤臣，远小人’ 的‘进贤如不及’ 的意思。‘忠贤’ ‘亲贤臣，远小人’ 是一个意思。鲁哀公去世，是孔子经历的第三个诸侯国君，鲁哀公的年号，在公元前477年，去世的时候，应该是孔子带着学生周游列国再返回祖国之前。

这里我要注意一个细节，子张、仲由、多闻，都是‘子’ 字辈，但是在这里孔子说‘请回答’ ，这就是跟着‘了’ 的称谓，这也算是细节上的一个表现。

你听孔子的对答，说的是提拔正直贤人，他们守规矩，做事忠于公心，不谋私利，办事靠信，这样就最能服人。事实上，这是国情在特别应社会公平。历史上，鲁哀公在位的时候，鲁国的三大贵族即早己掌握朝政大权，国君根本无力制约权贵，鲁哀公无奈之下，才无奈罢黜无能的政治贤臣，理想难施当时实现。
