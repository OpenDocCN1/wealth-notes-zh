# **10｜君子与小人之辩**



2.9 子曰：“回也视终日，不愚，如愚。退而省其私，亦足以发。回也不愚。” 2.10 子曰：“视其所以，观其所由，察其所安。人焉廋哉？人焉廋哉？” 2.11 子曰：“君子不器。” 2.12 子曰：“君子周而不比。” 2.13 子贡问君子。子曰：“先行其言而后从之。” 2.14 子曰：“君子固穷，小人穷斯滥矣。” 2.15 子曰：“学而不思则罔，思而不学则殆。”

你好，我是靳大成，欢迎来到我的《论语通读》，我们一起一句一句重温经典。

2.9 子曰：“回也视终日，不愚，如愚。退而省其私，亦足以发。回也不愚。”

孔子和颜回在一起时，孔子一整天不说话，就听他老师自顾自地反驳了一些思想或道理，好像很愚钝的样子。但颜回回去以后，对于所学上的疑惑不仅能，能解释深刻，还能有所发挥。你来看颜回不笨嘛。

回是颜回，字骞，鲁国人。颜回是孔子最为欣赏的得意门生。

其实，孔子对颜回的认识，也有一反复变换的过程，对他的言行举止等方面在进行仔细观察中，又有看正面不止的一面。颜回在跟老师学习时，不怎么说话，也不随便提出问题，看起来好像很呆的样子，但这恰恰是孔子喜欢的样子。

我在前面讲过，孔子不喜欢多话，看上去貌似机灵的人。他的另一个学生子路，一向就快言快道，可总是挨着孔子。

“回也不愚”这样，《论语》中颜回第一次登场亮相，他一开始出场就给人留下诸多印象。实际上，颜回为人坦荡，间人一知，并非聪明。从孔子对颜回的这个评价，我们可以看出孔子是怎么言言亲色判断人的。

下面这一章要更进一步详细地观察表述、了解人的方法——

2.10 子曰：“视其所以，观其所由，察其所安。人焉廋哉？人焉廋哉？”

孔子说：如果考察一个人，只要看看他做事的方法和路径，观察那么那么细致，再看看他有什么安顿身心。这么做的话，那个人还能隐藏什么吗？

这一章的“廋”，是隐藏的意思。在考察人的过程中，孔子张牙其观察很仔细。他从来不搞喜欢多嘴多舌的人。这种即观、即、察三个步骤，一步一步深入、细致，被观察的人也藏无所谓。

孟子也说过类似的话题：“存于人者，莫良于眸子。孟子讲的是看眼睛，一个人内心正直，眼睛就是亮的；一个人内心不正，就目光暗淡。

孟子这话说得好像有点玄，不过现代的微表情研究其一部分佐证了他的做法。研究表明，人会看到一个东西，如常是有目态起伏，瞳孔会放大、也常常会到两股鼓起的，瞳孔会收缩；不反的，不想听的东西，瞳孔会收缩变暗；听到听见的、看到就眼瞳瞳亮大。这是一种客观的变化，是入自己不能控制的，自然也无所隐藏。

下一章，孔子再度回到如何读书与思考的问题上来，你非常熟悉。

2.11 子曰：“温故而知新，可以为师矣。”

孔子说：通过反复不断地复习学过的经典，从中产生的理解和阐发，就有了当老师的资格了。

“温故而知新”这句话今天也常被被人提起，为什么提过呢？孔子是为了反对话反复是死记硬背。所以在《礼记》里说，只靠死记记忆背诵的字面，不足以成为老师的。

这也不难理解，比如今天有些学校的老师，一门功课一直教二一直教，每次都是依葫芦画瓢，那就算教三十年书，也仍然没有什么长进。

不知道有没有过这样的感受，以前学过的东西，过上一段时间再去思考，你会发现不定就会有新的理解，这是温故而知新。

孔子说的是，在每一次温故的过程中，要能获得新的思考或者新的角度，用我们今天的说法，这叫知识不断迭代。

孔子觉得，只有具备这种素质的人，才能有资格传授知识知，解答别人的疑惑。

接下来的第三章是专论君子的。你可以理解为修炼成君子的几个守则。

2.12 子曰：“君子不器。”

孔子说：君子，不能像器皿一样，只有一定的用途。

这话怎么理解？

说到“器”，《易经》里有一句话，“形而上者谓之道，形而下者谓之器”，可见器是实体的概念。

孔子的意思是，君子不要像器皿那样只有一种用途，要反对的就是这种专门化。今天东方研究起来需要更多的、具有专精学问家，比如汤姆士·哈钦森和亚里士多德一样，孔子搞教育也很少很精专。

你回忆一下，大六艺、小六艺其实都是现代代人的通识教育，或者用西方的说法叫Liberal Arts（博雅教育）。这种对博学通道的追求，恰恰是因为孔子不想他的学生成为视野狭窄，在专门的某一种知识里面盲目追逐，最后变成单一的工具。

我想提醒你的，看侍“君子不器”是要在今天的基础知识上衡量的。今天科学技术发展的，世界分界分了近三百多分行，那你就显然不能像孔子或者亚里士多德一样，做古代百科全书式的博通。

你需要的是实际上孔子强调的精神层面的东西，就是博闻强记、跨界学习研究的格局，不被狭窄的学术边界所限，不被专业化分工所限制，换句话说，跟孔子强调的“君子不器”相通，你需要把握的是多元思想的模型。

2.13 子贡问君子。子曰：“先行其言而后从之。”

子贡向孔子：如何才能成为君子。孔子说：先实践你到了，再把话说出来。

君子既然是先行的思想人，自然也就沾染了、不少实践派的价价和气质。这里也提了一笔，我在前面给你讲过，孔子喜欢老实拙话的人，所谓先做后说就是思想家的说明。

回到这个问题的内容，象子这样聪明又受到师长的启发，如果让让让他做那种不说话，把话先把他先他先做也做不到。可是，一来诚实，聪明的才智有所通，能能能能、能、放、可、可、动不动都不上。孔子说这句话，就是针对这种情况的。

2.14 子曰：“君子周而不比，小人比而不周。”

孔子说：君子广泛团结人，不因私欲而与人勾结；小人虽然勾结与人勾结，却不能广泛团结人。

在这里，《论语》第一次出现了君子与小人，对比。在《学而篇》里曾说过，一般说来，孔子这里，君子之要是具有由社会认可的资格或享有道德修养、高尚品德的人。那种君子对的小人，其实也不定你在修辞里用的意义，而是泛指那类人。这种人不一定社会地位低下，但一定是相对没有教养、文化水平、特别是道德修养程度不够。

所以你要记住，《论语》里的小人，可不是坏人、恶人，但是和君子相比，两者在思想境界、行为举止、心胸气概各方面都相距甚远。

“君子”小人”这样的成对概念，其实是汉语里很有智慧的一个特征：对位语。但到今天，“云对雨、雪对风，大地对长空”这种修辞手法，也依然在生活中大量使用。

回到这个问题你会发现，这样的对比往往是围绕着一个概念才立的，比如这句话君子周而不比，小人比而不周。周和比都有联系的意思，我把它比作调成词语，一个调是旁联结，是用旁人的说法让你清楚这两个词的褒贬差别。

周是一个圆，圆的特性是周全、均衡，圆圈是凸大的，各有不同的方向，与“比”学里两个人一前一后，圆圈一个周向，是了，你看到圆的西方会议也是各个成观的例子，上到圆桌西方的，大会大文又坐坐不在一起议事，这问会是一种君子风度？

《论语》里对比君子和小人，分散在各篇章，总共你有九次，可以看一下：
