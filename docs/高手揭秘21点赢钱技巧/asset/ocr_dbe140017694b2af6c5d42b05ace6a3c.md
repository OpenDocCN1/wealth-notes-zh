# (1).刻急忽視短期績效表現，選擇持續性好的基金

林區認爲，大多數投資大衆是透過基金過往的表現來選擇認購的；投資人最熱衷的是研究基金過去的表現——尤其是最近一段時間的表現；不過，在彼得.林區看來，「這些努力都是白費的」！這話怎麼說呢？

那些投資大衆通常會選取理柏（Lipper）排行榜上最近 1 年或最近半年表現最好的基金管理人，並將資金投資於這個基金，「這種做法特別愚蠢；因爲這些基金的管理人，通常將大部分資金冒險投資於一種產業或一種熱門類型的公司，並且取得了成功。而在下一年度，如果這個基金管理人不再是那麼幸運，則可能會排到理柏排行榜的最後。」

因此，彼得·林區以爲不要花太多時間去研究基金過去的表現，尤其是最近一段時間的表現。「但這並不等於是應該選擇具有長期良好表現的基金，而最好是堅持持有表現穩定且持續的基金。」
