# 比特幣與大陸幣 恐變一文不值

比特幣（Bitcoin）價格屢創新高，前聯準會（Fed）主席葛林斯潘（Alan Greenspan）也發出警告，比特幣讓他想起美國殖民時期發行的貨幣，擔心最終將會變得一文不值。比特幣週四價格不僅飆過 1.4 萬美元，且一度升破 1.5 萬美元，再創歷史新高。

葛林斯潘接受財經媒體「CNBC」訪問表示，比特幣讓他想起獨立戰爭時期，由大陸會議授權發行的紙幣「大陸幣」（Continental currency），大陸幣於 1775 年發行，1782 年完全失去價值，這期間大陸幣也讓許多愛國人士如美國第一任總統華盛頓買了不少軍備和物資。

當年大陸議會（北美 13 州於 1774 年至 1789 年間組成的聯合議會，爲美國國會的前身）宣布大陸幣爲法定貨幣，其價值在於市場對該幣的需求，而沒有金、銀等商品的支持。葛林斯潘指出，這種貨幣大部分能兌換真實的貨品或服務，但最終將毫無價值。
