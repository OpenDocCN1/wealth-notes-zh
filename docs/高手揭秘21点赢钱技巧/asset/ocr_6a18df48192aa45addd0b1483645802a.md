# 12年前曾交棒 回鍋再創高峰

早在二○○五年，<台積電>董事長張忠謀曾交棒給蔡力行，但碰上二○○八年的金融海嘯，<台積電>瀕臨虧損邊緣，爆發無薪假與裁員風暴，一群被迫離職員工在張忠謀家門口站崗；二○○九年，張以七十八歲高齡重出江湖，帶領公司營運登上歷史高峰，寫下傲視全球半導體產業的<台積電>神話。

過去卅年，張忠謀等於<台積電>的代名詞。<台積電>從沒沒無聞的小公司，以破壞式的創新商業模式，一路茁壯，今年市值甚至一度超越全球半導體巨擘<英特爾>；然而，張忠謀年事已高，接班一直是<台積電>不得不面對的問題。

十二年前、七十四歲的張忠謀安排栽培多年的蔡力行接下總執行長，蔡接棒四年，卻因強勢裁員事件，員工夜宿張家門口，逼得張撤掉蔡力行總執行長的職務；當時消息宣佈後隔天，<台積電>遭外資大賣，股票連兩天重挫，累積跌幅近九%，高盛證券更將<台積電>自亞太買進名單中除名。

因曾經交棒失敗，又擔心流失寶貴人才，張忠謀對於這次接班安排格外小心翼翼，先在二○一二年重啓接班計畫，師法奇異（GE）傳奇執行長威爾許的交棒模式，先選出蔣尚義、劉德音、魏哲家三位共同營運長；之後將退休跳槽中芯，二○一三年，張忠謀拍板「雙執行長制」，由劉、魏擔任共同執行長，以漸進式步伐，為退休做準備。

張忠謀曾說，「最高段的下棋高手可以看到終局」；爲了<台積電>交棒這場棋局，相信他已竭盡全力，做好沙盤推演，才能放心離開一手創立的晶圓代工王國。/2017/10/3*
