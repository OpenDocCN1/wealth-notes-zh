# 黃金沒有任何的經濟效用

不過，巴菲特也挑明的說：有時候，黃金也無法帶來任何經濟的產出：

> 我們在非洲某地挖出了黃金，把它熔化，然後挖了另一個洞，再把它們埋起來；為此，我們還必須付錢請人在四周警戒。這些黃金沒有任何的經濟效用，這種行為令人百思不解。——華倫.巴菲特（Warren Buffett）
