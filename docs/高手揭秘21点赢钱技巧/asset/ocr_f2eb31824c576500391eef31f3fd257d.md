# 不擇手段後 執政者如此取得選舉的成功
這種成功對國家而言 很可能是一種失敗

熊彼特說：「執政者如此取得選舉的成功，這種成功對國家而言很可能是一種失敗。」

經濟學家約瑟夫·熊彼特（Joseph Alois Schumpeter，或譯為熊彼德，1883~1950）說：「民主國家的總理如果成為一位全神貫注於不要摔下馬的騎士，他就難以有一趟美好的旅程；又或者像一個只關切軍隊是否聽命於他的將軍，豈能考慮整個戰略？」

民主政治并意味着人民真正在統治，民主政治的意思只能是：人民有接受或拒絕將要來統治他們的人的機會。民主政治就是政治家的統治。——約瑟夫·熊彼特（Joseph Alois Schumpeter，或譯為熊彼德，1883~1950）《資本主義、社會主義和民主》

# 醫生說只剩5年可活 婦人花光養老金享樂 結果竟是誤診

英國有一位民眾 2016 年就醫時發現罹患失智症，且只剩 5 年可活；於是，她便決定好好善待自己，一口氣花光新台幣 40 多萬的積蓄，安排豪華旅遊行程，沒想到事後——醫生卻說「誤診」，她其實是罹患焦慮和憂鬱症，並非無藥可醫，但花出去的錢已經收不回來了。
