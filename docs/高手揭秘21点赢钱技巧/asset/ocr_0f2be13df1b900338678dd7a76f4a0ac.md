# 老水手見證股市的無常

在人類的行爲世界裡，有一種類似「無動機的惡念」（Motiveless malerty）的東西---那是一種毫無來由的突發邪惡，也是講不出道理的憎恨怨毒。就小的角度來說，它只是惡意的傲慢、官僚習性、或是敵對式的歹念與挑剔的開始：就大的格局來說，那是一種邪惡、仇恨、設計陷害，以及嚴重災難的根源。

在浪漫主義大詩人裡，推柯立芝（Samuel T. Coleridge，1772-1834）的神學與哲學的造詣都很深刻；他寫過許多經典長詩，也都碰觸到了「無動機的惡念」的這個課題，其中又以長達六百多行的《古舟子吟》（The Rime of the Ancicnt Mariner，1798）最堪稱爲代表。
