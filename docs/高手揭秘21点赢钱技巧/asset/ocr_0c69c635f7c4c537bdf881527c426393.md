# 保持領先的方法就是實驗 其他人也會做
沒有實驗就不會進步 停止實驗就會退步

保持領先的唯一方法就是實驗，你不做，其他人也會做。沒有實驗就不會進步；停止實驗就會退步。——湯馬士．愛迪生（Thomas Edison, 1847-1931）美國發明家

> The guilty think all talk is of themselves. ----- Geoffrey Chaucer(1343-1400), British poet

有罪的人，都以為別人在談論他們。——［英］喬叟，英國詩人

有在寧靜的氣氛之中，才能產生真正的歡樂。——羅素
香奈爾的名言：「我沒時間討厭你！」

新任執行長一定會碰到許多的廢柴式批判；最好的回應就是——：

+   1) 若很重要，須舉證否認並立即回應，以免暈染效應。
2) 若只是雞毛蒜皮的吹毛求疵，則完全不必理會。就像時裝大師香奈爾的對治魯蛇挑釁的名言：「我沒時間討厭你！」

嘉柏麗·香奈兒（Gabrielle Bonheur Chanel）(1883~1971)，是法國先鋒時裝設計師，著名法國女性時裝店香奈兒（Chanel）品牌的創始人。

香奈兒的第一家商店於 1910 年在巴黎康朋街（Rue Cambon）
