+   真正的價值投資，是知易行難。

+   賺得清清楚楚的與賺得稀裡糊塗的，從短期來看幾乎有相同的外形：就是「賺錢了」。

+   長線投資完全不需要太頻繁、太勤快的操作。根據一两天的漲跌來判斷下一步如何應對，那是短線投機客的事。從這一點意義上來說，愈勤勞效果反而愈差。

+   睡得著覺的就是投資，睡不著覺的就是籌碼。

+   短線操作，機不可失，並且賺得更多，因為股市永遠有資訊不對稱的時候，提供了很多賺快錢的機會。但是笨人感覺，真正能夠持續地、有效地保持增長，還是價值投資這條路。

# 一個企業：有沒有價值？

面對著證券市場上的風雲變幻，很多投資人都會手足無措、感到力不從心。在這種情況下，投資人想要在投資之中獲利，唯一的辦法就是要對於企業的價值進行徹底的分析，然後針對企業內涵價值的具體情況，做出最終的投資決定，這樣就可以確保自己的能避免損失而獲得成功。————華倫．巴菲特（Warren Buffett）
