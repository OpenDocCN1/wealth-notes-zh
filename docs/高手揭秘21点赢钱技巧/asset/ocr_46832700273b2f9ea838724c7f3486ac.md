# 別管黃金了 包裝成投資產品的鑽石可能比黃金更能避險

每當談到避險資產時，投資人想到的常是黃金或公債；如今新加坡有一家交易所——開始交易以信用卡包裝呈現的碎鑽，提供投資人避開全球風險的另一管道。

黃金僅依據標準重量和純度的兩項標準即可交易；但鑽石則因切割、淨度、色澤和克拉的多重因素而有所變動；這使得鑽石更難以用投資的方式買賣交易。為了解決這個問題，新加坡鑽石投資交易所（SDiX）正推出一項「鑽石條」(Diamond Bullion ) 的投資產品，或一組投資等級的拋光寶石，面額介於約 10 萬美元至 20 萬美元。

SDiX 創辦人兼執行董事長范登伯（Alain Vandenborre）表示：「一顆鑽石和其他資產類是絕對零連動，不論是商品債券和股票。鑽石就是財富的儲蓄，是能避開波動的避險資產。」
