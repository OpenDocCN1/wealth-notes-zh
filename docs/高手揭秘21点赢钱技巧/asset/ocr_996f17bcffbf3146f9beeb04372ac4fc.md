# 為什麼掌握權力的富者 會愈來愈富？ 因為主導分配 愈有錢之後就會更有錢

第五波（未升段）：如果第三波的漲勢很強，那麼第五波就可能短而弱；如果第三波的漲勢頗大，那麼第五波的幅度和時間，通常是短而弱的！有的投資人以為第 5 波的動力十足，漲勢驚人，其實這是一個錯誤的觀念。比起第 3 波來，除非第 5 波出現延長的現象，否則第 5 波是不會那麼強勢的！第 5 波時，同時也是股市心理最樂觀的時候，大部份的分析專家，都不認為空頭市場就要來臨！

多頭上漲走勢，幾乎是欲罷不能；其實，躲在幕後的作手們也不願意小漲就收的；他們想賺的是幾倍的利潤。
