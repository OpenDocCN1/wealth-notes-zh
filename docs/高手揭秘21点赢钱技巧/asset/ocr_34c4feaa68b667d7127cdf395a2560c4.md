# 有錢買不到真心的：李勣親自爲姐姐熬粥

唐朝有個非常重要的政治家、軍事家，名叫李勣，本名叫徐懋功，他出將入相，位至三公，經曆三朝，深得朝廷的信任和重用，被朝廷譽爲「長城」。

李勣除了軍事才能、政治才能之外，他跟朋友、兄弟之間也非常講信義的。例如，他曾跟鼎鼎大名的單雄信結拜爲兄弟。有一次單雄信打仗被俘，李勣就去跟秦王李世民說：「單雄信是好人，非常驍勇，我願意拿我的官職來贖他的命。」但是李世民沒有同意。李勣說：「那好，我不跟你說了。」於是流著淚告退。

單雄信責怪李勣：「我早就知道你不辦實事，就嘴上說說，什麼兄弟義氣，你根本沒有拚命救我。」

李勣說：「我不惜餘生願意跟兄長你一起去死，但兩個原因我沒有辦法去死：第一，我身已許國，我已經答應秦王，要跟他打天下，我不能死；第二，如果我死了，兄長的妻子、兒女誰來照顧啊？」說完李勣拿出刀，割了自己大腿上的一塊肉，交給他
