# 我做決定時，相當重視數據資料，也很依賴直覺，絕不會光靠感情來決定事情

我做決定時，相當重視數據資料，也很依賴直覺，絕不會光靠感情來決定事情。——麥克·戴爾（戴爾電腦公司董事長兼執行人）

事情的真相要用雙手去掌握，光靠閱讀或是用眼睛看是無法瞭解的。——豐田章一郎（豐田汽車公司榮譽董事）

# 捕捉到賺錢的良機

像不定的週期一般，每隔一段時間，證券市場就會爆發貪婪與恐懼的這些情緒傳染病，它們嚴重的影響到股價的漲跌。牛頓就曾經說過：「我可以計算天體的運行，卻沒有辦法計算人心的瘋狂。」

牛頓是科學家，在跨出自己擅長的領域之後……；相對的，巴菲特平日按兵不動，在恐懼來臨之時，他成功的利用這些機會的；因爲好公司還是好公司的，不必怕！

在大多數人貪得無厭時，巴菲特竟然能警覺而感到「不安」，或者是說變得極度的保守。而當大多數投資人惶恐不安時，巴菲特是伺機貪婪起來，或者是說他變得活躍起來，積極的搶進。
