# 百貨公司的第2大業種——餐飲業即將超越化妝品

近年百貨受到網店商務蓬勃發展與景氣不佳雙重衝擊，營收成長動能疲弱；業者透過引入知名或創意餐飲以吸引更多消費者，餐飲漸漸的變成爲百貨業的第 2 大業種，甚至不久就會成爲最大營收來源；業者也坦言，必須要思考餐飲與零售的平衡點。

目前在各主要百貨公司中，化妝品仍是營收比重最高的業種，佔比約 20%，但餐飲卻由 3 年前不到 15%，目前平均約 17% 左右；每年成長幅度更是最高，擠下化妝品的狀況很快會發生。

新光三越執行長副總吳昕陽就說，過去傳統百貨業對餐飲有低毛利、營收比重不能過高的迷思；但引進餐飲美食的最大效益是吸引人潮；集客效應——更已取代化妝品；但餐飲似乎也不能一直擴大，一旦營收比重達到 20%，就必須停止再觀察。

也有業者透露，餐飲的毛利很低，引入過多餐飲會侵蝕到公司獲利表現，去年的毛利已經少了 1%，餐飲變成業種龍頭，「不是好事但卻是會發生的事」，相信各業者都已經開始思考如何去取得餐飲與零售的平衡點。／2017/10/9*
