# 彼得.林區的選擇基金7原則

「共同基金」（Mutual Fund）是美國金融投資界所採用的名稱；如果在英國，用的是單位信託（unit trust），它們的內容是一樣的。所謂的「共同基金」，是由專業的證券投資公司用發行公司股份、或是發行受益憑證的方式，募集衆多投資人的資金，交由專業的機構或經理人負責投資管理運用；所有的投資人共同分享資金成長或損失；並且根據投資比率，共同分攤經營基金所需費用的一種投資理財方式。
