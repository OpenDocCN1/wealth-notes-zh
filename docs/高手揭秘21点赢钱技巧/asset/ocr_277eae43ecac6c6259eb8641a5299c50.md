# 瘋狂就像地心引力一般 讓人們陷入其中

在證券市場上，有些人與瘋狂只有一步的距離，但卻有越來越多的媒體，站在人們的背後，隨時準備伸手一推：

「你要知道，瘋狂就像地心引力，要讓人陷入其中，你需要做的，有時候只是輕輕一推。」這是小丑希斯.萊傑在電影「蝙蝠俠：黑暗騎士」裡，留下的最後一段話，這不禁讓理智型投資人打從心底——打一個冷顫。
