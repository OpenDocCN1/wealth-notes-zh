# 你如何能攀登頂峰呢？

他們所做的是傳教士的工作。試想，如果沒有人為你墊底，你如何能攀登頂峰呢？～華倫.巴菲特（Warren Buffett）

巴菲特是哥倫比亞大學商學院「有史以來」成績最好的學生；他在1951年他獲得經濟學碩士學位。在哥大教授金融的羅傑斯（Jim Rogers）與哥大商學院教務長伯頓（John Burton）都表示：當年巴菲特在葛萊姆的課得了A+的成績；據說，巴菲特也是所有修過葛萊姆課程的學生之中，唯一得到A+的人；不過，這一項輝煌的成績，並沒有留下任何文獻記錄。
