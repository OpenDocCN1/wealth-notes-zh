# 國王、主教、財主：三方博弈 誰輸誰贏？

描述中世紀王國爭霸的奇幻史詩影集《冰與火之歌：權力遊戲》第 5 季，正在網路頻道上熱播，同時創下新紀錄；首集被全球網友非法下載 1300 萬次。

其實全劇的主題意識已在第 3 季展現，情報頭子瓦理斯問「小惡魔」提利昂一個謎語：「國王、主教和財主，三個大人物處於一室，都吩咐站在他們之間的劍客去刺殺另外二人，誰會死，誰會活？」

提利昂說：「當然是劍客，他的劍——有決定生死的權力。」

瓦理斯反問：「若是劍客有權力，那麼我們為何又假裝國王擁有所有的權力？」他接著說：「權力是個很奇妙的東西…人們相信權力在那裡，它就在哪裡，就像變戲法。權力就像是牆上的影子，小個子也可以投射出非常大的影子。」
