一家公司的成功——有沒有被市場快速認同，並不是很
重要；只要公司的內涵價值（intrinsic value），是以令人滿
意的速度成長就好。事實上，較晚的認同是比較有利的，因
為這樣可以給我們充份的機會——以較低的價格投資更多更
好的標的。————華倫.巴菲特（Warren Buffett）

很明顯的，巴菲特並不急於要求市場的認同他所相信的真
理。

# 這顯然是中了圈套！

到了最後，就會走到敏斯基（Hyman Minsky）所說的泡沫的
最後階段：「恐慌拋售」(revulson)；然後，投資受傷慘重，以至
於不再願意參與市場。

經濟學家敏斯基（Hyman Minsky）著有《掌控動盪的經濟》
（Stabilizing an Unstable Economy）中說：經過長時間的經濟快速
成長、低通膨、低利率與總體經濟穩定，孕育著投資人的自滿心
態，並且愈發勇於承擔風險。

不過，金融穩定之後，必然導致接下來的不穩定。金融商品
創新——證券化、未列於資產負債表外的融資，以及其他種種，
再次證明歷史是不斷的重演。投資人就像每秒基所警告的，身處
於不受規範的市場，卻持著过度的信心，這顯然是中了圈套！
