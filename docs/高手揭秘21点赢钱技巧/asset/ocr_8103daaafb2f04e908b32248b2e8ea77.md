# 成功的人不滿意自己的風度 想辦法改善  
失敗的人不滿意自己的影子 求自暴自棄

空頭市場第 g 波的形成，大約是由 5-3-5-3-5 的五小波組建而成；它的價量關係，大多是一種價跌量減的互證關係，一路下滑，難以阻過。

投資人只要把握住下一波的漲跌幅，特別是它發動的前五天進場，就能成功致富。我們的觀念必須修正一下：這古今不同，時移勢異；以前的投資人大多做長期投資，現代投機客的觀念已改——你只要賺取下一波就能成功的！你只要贏得未來的一個月的漲跌幅就能致富的！

緊緊的抓住這空頭市場第 g 波吧！同時關注下一波的空頭第 1 波的發動吧！通常在一個波段走勢的前段的五天進場，獲利最爲優渥！如果這時點沒有把握到，那就等下一回合吧，不必勉強的。

投資人「先下手爲強」真是說得一點也沒錯；早踏出一步的人，就能摘得較大的果實；如果已達到飽和狀態時，才緩緩的踏出腳步，一定會嚐到失敗的滋味的。

每週末遇有暴漲時，賣出持股換現金。不賣出怎會有錢再買進？
