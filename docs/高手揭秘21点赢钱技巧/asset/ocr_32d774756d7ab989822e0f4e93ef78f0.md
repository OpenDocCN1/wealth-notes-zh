# 鮑穆爾定律

普林斯頓大學教授鮑穆爾（William J Baumol）曾提出過所謂的「鮑穆爾定律」，它指的是：如果一種貨物或服務的生產——是與技術進步密切相關，那麼它的價格的長期走勢就會傾向於下滑。

證券市場中的新股，或高科技股，其實也可以做如是觀的。

近年來，美國主要的金融學者，耶魯大學教授席勒（Robert J. Shiller）重建了近百餘年來美國房屋市場的價格模型，發現在1990 年代末期之前，美國的房屋價格、房屋建造成本等，其實都與「鮑穆爾定律」相當吻合。
