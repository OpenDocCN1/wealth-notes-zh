# # 教父退休 富比世：失去巨人

畢生投入半導體業，被譽為「半導體教父」的<台積電>董事長張忠謀宣布明年六月退休。《富比世》雜誌網站以「半導體業將失去一個巨人」（Semiconductor Industry To Lose Titan）爲標題，推崇張對全球半導體業的貢獻。

張忠謀一九五○年代就進入半導體業，一九五八年加入德州儀器（TI）後，努力開疆拓土，<英特爾>、摩托羅拉都曾是他手下敗將。

一九八七年張忠謀創辦<台積電>，成爲全球第一家以晶圓代工爲經營策略的半導體廠，日後更掌握全球晶圓代工市場半邊江山；美國《商業周刊》形容「張忠謀的決定（晶圓代工），成爲半導體產業史的分水嶺。」

IC 之父基爾比（Jack Kilby）一九九八年訪台，肯定<台積電>創新營運模式，是半導體業重大革新。

二○一一年張忠謀獲頒國際電子電器工程學會（IEEE）榮譽獎章，當時《聖荷西信使新聞報》專訪張忠謀，形容他是「穿西裝的科技革命者」，不像蘋果創辦人賈伯斯老是穿著黑色高領毛衣；也不像臉書創辦人札克柏格成爲鎂光燈焦點；更不像總是神氣活現的甲骨文創辦人艾利森。

蘋果前陣子推出新機，中國《東方財富網》稱，掌握蘋果「核心」命脈的並非執行長庫克（Tim Cook），而是八十六歲的張忠謀，因 iPhone X 的 A11 處理器，以及歷代 iPhone 的多個處理器，都是出自<台積電>。／2017/10/3*
