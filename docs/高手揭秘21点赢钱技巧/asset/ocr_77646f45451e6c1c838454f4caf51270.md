# 選擇小型股與成長股

會計師看過去，經理人看在在，領導人看未來。

小 T. 羅. 普萊斯 (T. Rowe Price, JR) 認為防止通貨膨脹，降低購買力的唯一方法，就是投資成長股。他的這個論點是從一系列的文章〈選擇成長股〉(Picking “Growth” Stocks) 中推演而來的，以下是其中的幾段重要摘錄——

在計劃投資方案時，有一點極為重要，就是投資人要在購買股票之前問自己：「我的目的是什麼？」他必須瞭解，除非經歷長期的時間，否則任何股票投資都無法確保資金，而且或許其它的理財方式，更能帶給他穩定的收入。

+   投資人主要有三個目的，第一個是保全資產的價值，第二個是獲得固定的利息收入，第三個是使本金增加。

證券投資必然伴隨著風險，但是程度依證券的種類而異。像短期的政府公債等類型或許很適合用來保全資金，但是不能指望它會產生高額的利潤。

另一種類型，譬如航空公司的股票，雖然可望產生高額的利潤，卻無法確保資金的安全。
