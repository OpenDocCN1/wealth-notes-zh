# 高槓桿操作，引來經濟風暴

雙星多空套利

《經濟學人》(The Economist) 曾經說過：「在大部分時間，人們都沒有注意到信用 (credit) 是像血液一般，流過經濟體系的肺；但當信用停止從市場流向銀行、企業與消費者時；每個人就會都發現（肺部沒血液）了。」

企業不只是「大到不能倒」，有時也「大到無法救」；過度 的高槓桿操作，就會引來五十年一遇的洪水來；只是這些經濟風暴，竟然從五十年一遇，變成三年一遇而已。
