# 要讓事情有效改變 自己必須有效改變
要讓事情變的更好 自己必須變的更好

+   ⊙股民拜大鱷資神；籌碼大鱷索羅斯被大家奉若神明，但每隔幾年他就有傷元氣的時候。

+   ⊙投機真的不敢說仗仗都贏，以投機的方法是很難持續幾十年複利成長的。不像價值投資，一方面可以輕鬆愉快地工作生活，一方面財富還在不斷積累。

+   ⊙我們只能在大危機時找到便宜的好股票買進，然後就可以放心去周遊世界，做自已喜歡的事情。我們公司高管每年都有一兩個月的時間在外旅遊度假，原因很簡單，投資是一項智慧的行為，而不是一種負擔。

+   ⊙買了輕易不賣，賣了輕易不買；看准了才動，看不准就認錯！

+   ⊙波段操作（swing trading）好股太難找，少之又少。

+   ⊙少關注其他人同期在做什麼，只評價自己幹的是不是理智正確的事。

+   ⊙一個真正長期會上升的股票，往往在其他股票上漲時它不漲。

+   ⊙投資，是個人的合國力；其實，也是對一些最基本的人
