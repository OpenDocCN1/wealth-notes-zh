# 小型股的投資報酬率確實是比較高的

成長型股票有時也會表現出特有的風險型態。因為投資大眾總是對於高科技抱著超越理性的熱情，於是成長型股票受到過度的注目；這就像 1990 年代後期的科技股與網路股的熱潮一般；不過，一旦泡沫消散之後，損失就變得很可觀的。

小型股無疑的是會比大型股更具有風險。

小型企業通常是相對的不穩定，並且比較脆弱；更重要的是，小型股的交易量是比較少。小型股在市場裡換手的數量是比較低的；特別是當大盤市場下滑之時，也只有少數投資人願意忍痛斷頭賣出。

在 1929 到 1932 年之間，小型股損失達市價的 85%；而在 1973 年到 1974 年期間，小型股又是一次的慘跌；這一次是跌掉了 58%。

既然如此，那麼投資人為何還要投資小型股呢？

就長期來說，小型股的投資報酬率確實是比較高的。

# 彼得.林區評估公司13條

彼得.林區（Peter Linch，1944~）曾經提到過十三條——他所喜歡去投資的公司的特點；內容是非常有意思的，大家可以背誦下來——：

+   1) 該公司的名字，平淡無奇，滑稽的更好。

+   2) 該公司所經營主業，很常規、很平凡、很平淡，是一些很不起眼的業務。
