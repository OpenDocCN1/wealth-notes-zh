# 看懂走勢圖，就能學會投資

在對走勢圖進行分析之前，你是否懷疑自己、沒有自信？或者有「我做得到嗎？」的疑問？那麼我要先問大家，自己是是否認真想過，有沒有意志去做這件事？因為根據我的經驗，持續努力緊盯股票走勢圖的人當中，沒有不會投資股票的人。後續在第三部，我們會學習分析走勢圖的基本概念；在第四部中，學習如何掌握主力股獲利的核心模式，相信誰都能成為股市高手。

# 做好虧損的覺悟，並用心學習
