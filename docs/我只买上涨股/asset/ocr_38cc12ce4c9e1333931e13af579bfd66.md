# 良好的交易系統＋堅守原則＝持續的報酬

如果對股票不太了解，一開始不建議太執著在獲得報酬上，還不如先學會買賣技術並熟悉它，也就是要找出最適合自己的交易方式，以及在哪一種產業中較容易獲利，這些都要靠經驗累積，同時在確立這一切之後，還需要固守原則的堅定意志。

固守原則就是不管損失多少、報酬多少，都要遵守的自我規範，但就我所知初學者幾乎不會遵守原則，因為初學者們還不瞭解，實戰交易與理論不同，個人的慾望和執迷會導致交易徹底失敗，而高手們通常已經了解這些事實，所以會堅守自己的原則。交易技術與原則相結合，交易系統才得以完成，並由此產生持續的買賣報酬。

初學者如果看到帳面上有一點點損失，就很容易心生恐懼而輕易拋售手中持股，或是會貿然盲目跟進購買其他個股，有人甚至舉債購買。這是新手們共同的心理，脆弱容易受影響、容易崩潰，結果只會造成更大的損失。
