# ◆ 上漲訊號！最高價更新！◆

股價要上漲，最終還是得靠最高價的更新。最高價是指在規定時間內上漲的最高價格。今年以來，最高價格是年初申報後，最近五十二週交易中的最高價，這就叫五十二週高點股票。

更新最高價的股票將超越之前的價格帶，因此受到許多投資者的關注。此外，由於投資者想知道該股的邊際值在哪裡，使得該股股價更容易上漲。一般在更新最高價後會突破壓力線上漲。

線圖上的壓力線指的是之前的高點。高峰時期總是有很多人的成交量是綁在一起的。股票資金被套在高點上的人，在價格上漲前會累積資本，當回到高價時就會盡快獲利了結，因此一般認為買盤很難突
