# ◇  為何投資容易變成賭博？  ◇

股市的特別之處在於如果想挽回失去的資本，不應該把目標放在只挽回失去的金額，而是應該獲得更多報酬才對。舉例來說，投資了一千萬元的資金，結果造成 -10% 的損失，也就是損失了一百萬元。如果用剩下的九百萬元翻本的話，不應只追求 10% 的獲利，而是至少要把目標定在獲得 11.1% 以上的報酬才對。如果將手續費和稅金算進去，那麼目標報酬率還要比 11.1% 更高才行。

大多數的投資者經歷虧損，通常會為了挽回損失而再投資，如此反覆，隨著損失逐漸擴大，目標報酬率越來越難以追上，因此容易陷
