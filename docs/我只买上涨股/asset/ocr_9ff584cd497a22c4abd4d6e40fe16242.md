# ① 開盤交易

指從上午九點開盤起至九點三十分這半個小時。該時段會因為前一天有利多因素的個股，以及其他目的買進及賣出，讓股價會在幾分鐘內暴漲 10%以上等，顯示出強勢動向。通常在初期爆發力上升的個股，隨著時間的推移會逐漸下跌，如果新手不了解情況就進行交易，可能會蒙受巨大損失。相反的，如果初期攻略做得好，可以在短時間內獲得很大的報酬。

# ② 盤中交易

交易時間是上午九點三十分以後，這是一段移動緩慢的時間段。這個時段只有具備利多因素的個股上漲較快，其餘個股走勢緩慢，投資人可以稍微放鬆一些。在這個時間段裡，只要沒有特別的事情，走勢圖通常不會有太大波動，只要掛著想要的價格靜觀其變即可。

# ③ 收盤期間交易

指以當天最後收盤時的價格交易，要進行收盤期間交易可以在大約下午兩點左右開始觀察走勢圖，尋找當天具有意義的線圖形態。這裡所謂有意義的線圖形態，是本書中所指符合購買標準和模式的線圖。再看下午三點二十分到三點三十分之間完成的線圖走勢，用「市價」買進就可以了。

收盤期間交易適合熟悉線圖走勢的人，成功交易的機率會比較高。
