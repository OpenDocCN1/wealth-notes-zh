# ◇ 尋找資金涌入市場的時機 ◇

在股票上，報酬是徹底由市場一買一賣所得的，不是自己創造出來的。在有人買之前，我先以好價錢買，在其他買主蜂擁而至時，賣出去獲得差價，這是股票買賣的基本原理。

不是我先買之後再對別人宣傳，也不是靠傳聞。也並非說是我買了，該公司的價值就會突然提高。只有資金湧入市場才能獲得報酬。

這個概念非常重要，越是投資股票許久的高手，越是能接受市場、防範市場風險。股市好，韓國股市整體上升的時候，我買的股票上升的可能性也很高。這時候，市況分析做得越好，股票報酬率就越高。這種覺悟，是在股票投資中一邊嘗試成功和失敗，買進或賣出許多股
