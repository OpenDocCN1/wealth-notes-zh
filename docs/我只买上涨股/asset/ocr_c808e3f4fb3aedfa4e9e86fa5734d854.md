# ◇ 建構投資組合，培養觀察市場的眼光 ◇

正如前面提到的，新手們不必大量買進個股。重要的是要養成慢慢集中管理一個標的的習慣。如此一來，隨著對股票的熱情逐漸形成，也能培養出對股市的看法。
