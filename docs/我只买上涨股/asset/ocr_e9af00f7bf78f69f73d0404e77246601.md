# ◇ 大衆的期待心理是上漲的主因 ◇

在這裡我所說的價值投資與各位所知道的有一點不同，一般是由一間公司的未來發展來衡量是否具有長時間投資的價值，而我是以「是否有大量資金流入」為依據，判斷這間公司是否具有「日後出現利多」的可能性，藉此來進行投資。

有人會看公司的整體成長或是銷售額的增加來投資，但我们仔細觀察股票上漲的根本理由，第一是預期心理，第二是營業利潤的增加。這兩項當中，讓股價大幅上漲的最主要原因還是「預期心理」，空等公司將來會有利多消息，期盼股票會上漲。因為這樣的預期心理，有很多公司就算現況不好，股票還是不管三七二十一的往上漲。
