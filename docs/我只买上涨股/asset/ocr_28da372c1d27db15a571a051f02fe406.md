同時，逐漸對自己所投資的公司產生信心，這樣就能安心持有很長時間。這種股票投資方法不用花很多時間，對有正職工作的業餘投資者來說，這也是最好的買賣方式。越是採用短線技法的人，越需要豐富的技巧和交易經驗，但如果事先買進主力正在收購的主力股，便可以省略這種努力。

# ◆如何成為最強股市投資人？◆

其實不管怎麼說，能多賺錢才是最好的股民吧？要想做到這一點，就必須每天都能成功實現快速報酬。隨著進場方式不同，所有的買賣手法都可能成為最佳的手法，但無論從時間還是速度來計算，開盤交易都是最好的。

在市場開放的初期，會出現各種資金暫時聚集的現象，甚至可能僅在一分鐘內，股價就大幅上漲20%。開盤交易一般在上午九點三十分之前結束，因此只要集中到這個時間就可以成功交易。以全職投資者的立場而言，這樣的股票投資模式具有巨大的吸引力。但是需要集中注意力，畢竟是一擊求勝負的投資方式，所以要有強大的精神力和經驗，更必須具備知識。不管是模擬投資還是實戰投資，不妨先抽出一些時間，練習一下在這個時間段的買賣。這個時間段最大的優點是完全不受市場的影響，只要熟練掌握技術，就能獲得強而有力的買賣技巧，賺進一輩子的收入。
