# 底部翻身的股票

# ◇ 股價穩定持平，就一定可以買進嗎？◇

那麼，如果像前面說的那樣，只要找出長期價格起伏不明顯的投資標的，就不管三七二十一，買了就放著等就可以嗎？如果股票投資那麼容易的話，就不會有人失敗了。購買長期價格起伏不明顯的標的，並耐心進行長期投資的公式，並不適用於所有股票。先決條件是，受到低估的個股，在價格偏低的位置買入，才能隨著時間的流逝，獲取較大的報酬。簡單的說，我們應該買進價格處於橫盤整理區間，價格偏低的股票。

那麼，現在我們來介紹一下如何從線圖分析中，區分出被低估的股票。請仔細閱讀，務必選擇符合該標準的個股買入。
