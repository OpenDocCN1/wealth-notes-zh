# ### 股票投資者的失敗週期

+   - 第一階段：在買賣失敗後產生找回本金的慾望。
- 第二階段：報酬率必須提高至超越損失的金額，而產生負擔感。
- 第三階段：因高報酬率壁壘導致投資失敗。
- 第四階段：因憤怒和鬱悶，進而追高買進已逼近高點的個股。
- 第五階段：逢高買進可能快速產生報酬但高風險的標的，增加損失的幅度。
- 第六階段：投資資本耗盡後又再重複一至五階段。

我想在股票投資中經歷過類似失敗的人，應該都會認同這個週期。大多數人的投資心理很相似，剛開始以投資為目的，但隨著時間過去，不知不覺投資變成了賭博，無法控制自己的感情，反覆出現盲目跟風追隨他人動向，做出雷同的交易。
