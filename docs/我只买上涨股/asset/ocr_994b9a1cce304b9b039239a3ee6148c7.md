# ◆ 這世上沒有完美的交易技巧 ◆

然而任何技巧都存在著風險，我首先選擇了股價三次觸底反彈的線圖來研究。這種方法是以 K 線圖上的高點為基準，股價若連續觸底反彈三次的話就買進。

從左邊的線圖來看，股價在觸及高點後強力向下探底，之後又短暫回補或反彈。如果這種模式反覆三次，就可以預測此時已真正觸底，可以趁機買進。

這個方法經過幾次驗證，我也曾在實戰上運用過，但實際上這個方法並未讓我取得太大的報酬。雖然有幾次成功經驗，但是超出我預想幅度下跌的次數更多，反而造成更大的損失。透過這個經驗，我了解到我以為已經大跌的個股，永遠都有可能還會再跌得更深。

像這樣體會一種技法帶來的失敗經驗著實慘痛，所以反覆確認和檢視是很重要的。在經歷過那樣的震撼教育之後，也喚醒了是對各種性質走勢圖的認識，記取教訓再按部就班的學習和研究，慢慢地終於獲利上升，選股的命中率也開始提高了。
