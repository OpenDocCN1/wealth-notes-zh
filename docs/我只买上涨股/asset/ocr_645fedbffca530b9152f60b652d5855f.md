# ◇ 第一階段，只買單一標的即可 ◇

如果第一次炒股，最好只買進一個標的。理由不是為了獲得報酬，而是為了培養集中力。根據我的經驗，如果買進多支股票，就容易疏漏各種資訊，例如該公司的市值、財務報表、事業計畫、線圖的走勢等，於是產生看不懂的情況。但是只買一個標的並集中觀察該標的的話，就能夠記下線圖，線圖的走勢就會映入眼簾。此時應該要專注在這個標的上，仔細的研究一番。因此，剛開始炒股的新手，有必要只關注一個標的。

# ◇ 第二階段，買進十個以上的標的 ◇

先買一個標的，對股票的走勢稍加學習之後，再開始真正多買一些標的。當然，買你認為會上漲的個股，十個以上也好，買二十個以上也好。之所以這樣組成投資組合，是為了看到根據市場情況，各標的連動變化的樣子。

應該說，假如在股市中，就只有我唯一買進的那支個股正在跌停板，這樣一來才算走過股市的初生之犢之路。只有經歷過下跌行情，面對股市才能學會謙虛；若是缺乏這種經驗，將會產生無視市場的結果。而如果大量買進各種股票，則可以親眼看到市場下跌帶動整批股票的下跌，和市場上漲帶動整批股票上漲等現象。
