# ◆ 股票投資，最重要的是心緒管理 ◆

在投資股票的過程中，你會發現，心理狀態的管理是最重要的。認為買賣技巧最重要的人，往往是還沒有真正做過股票的人。現在想要學會買賣技巧，其實可說是隨處可得。由於社群網路蓬勃發展，在這個時代，我們能夠輕易掌握各種交易手法。但是在進行交易的過程中，你將真正了解到：比買賣技巧更重要的東西，就是心緒管理。

有時候我們明知當下狀況不符合原則，卻還是會盲目買進，或是因為情緒動搖，而錯過了該出場的時機，於是淪落到被套牢的結果。這些都是包括在心緒管理的領域。

我透過學習來解決心緒上的障礙。失敗的時候會更加認真的分析失敗時的線圖模式。通常，如果在投資中賠錢，人的情緒就會變得急躁，精神產生動搖，這時往往都會試著聽取別人的意見，或者是嘗試花錢來獲得推薦的明牌股票。但是這些最終都無濟於事，所以最終只能由本人多加學習。

當你累積了各種有關股票的技巧和知識後，理性便能戰勝威脅，讓自己更有機會在瞬間做出最佳判斷。所以，我失敗時學習更加刻苦，而最需要注意的瞬間反而是在買賣順遂的時候。如前所述，在股票面前，總要保持一顆謹慎謙遜的心。
