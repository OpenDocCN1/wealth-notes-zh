# 持續與他人交流

前面我們提到關於心緒管理的部分。一個人進行股票投資，總是
非常孤獨和寂寞。如果不和同事或朋友談論股票，建議可在社群網路
中活動。在我建立的社群裡，做股票的人也經常聚集在聊天室，單純
的進行交談。當有人能夠提供指導，也有人會提供慰藉。透過不斷
的交流，讓自己不被孤立的姿態非常重要。此外，能夠獲取多種資訊
的管道也非常重要。我也一直努力讓自己不被孤立，致力於把自己的
想法與人分享。

我希望大家能夠健康而穩定地持續買賣股票。這本書中涉及的
全部內容都是關於降低風險的實戰買賣方法。大部分人會被貪慾牽著
鼻子走。然而，股市是充滿各種情緒的地方，如果不能控制住個人貪
慾，任何人都無一例外的可能會失敗離場。

在股市中失敗的程度，每個人各不相同，有的人可能賠進了一半
的家產，有的人甚至是把退休金通通賠上了。股市就是如此可怕的地
方。但可以肯定的是，股市也是有準備、有訓練的人能夠得以生存的
地方。

我希望透過這本書，讓進行股票投資的各位能夠變得更加堅強，
領悟和學習正確的買賣方向。想要在市面上已經充斥著大量股票書籍
的情況下出版新書，這讓我反覆思考，這本書中究竟應該包含哪些內
容，才能真正幫助讀者。希望本書的內容，能夠讓大家認可我反覆思
