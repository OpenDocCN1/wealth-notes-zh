# ①漲停板買賣法

這是利用股價達到漲停板之後產生的巨大變動性操作的手法，屬於短線買賣技法。漲停只有在強勁的利多因素刺激之下才會發生，一旦出現漲停板，很多投資人都會關注該個股，分析漲停的原因。一般來說，如果出現漲停的原因是併購、FDA 的許可、政府發布政策支持等對公司方面的利多消息，那麼第二天股價繼續強勢上升的情況相當多。
