# ◆ 急於買進容易出錯 ◆

股市新手經常犯的錯誤之一就是急於買進。他們說「要是從明天開始漲怎麼辦？」焦躁不安的心情，讓他們忍不過今天就想馬上買進。但是高手們絕對不會犯這種錯，高手會耐心等到價格來到自己的理想價格為止，為什麼呢？因為這個價位可以實現報酬最大化，同時也可以降低風險。

請看186頁的線圖，仔細看線圖，在箱型槓橫步期間，股價也不會一直往旁邊走，而是以小的規模上下碰撞形成價格。

觀察這張線圖，可以看到三條紅色直線以相同的間隔上平行排列著，下方兩條線由點狀箱體包裹著，形成一個區間，該區間即是應買進區間。如果價格來到這個區間，就可以用低廉的價格買入股票。如果急於進行交易，不在這個區間，你就很有可能會以高價購人股票。
