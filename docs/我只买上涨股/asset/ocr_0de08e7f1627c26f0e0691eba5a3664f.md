# 日常模擬投資

即可進取買賣股票交易或進行模擬投資，
所有用戶皆可免費使用。

參與部分：股票 / 期種選擇權
參與對象：本公司會員（含真實戶、一級白紙戶）
投資時間：可選擇一個月、二個月、三個月
投資金額：一百萬元～一億元
注意事項：模擬帳戶投資交易手續費：0.36% 僅限真實戶
模擬帳戶投資交易：0.000（真實帳戶可用）

# 申請方法

**STEP 01**
會員加入
欲使用本模擬投資系統請先加入會員。
加入會員

**STEP 02**
申請參與
請先設定以下類別：參與部分（股市/期貨選擇權）、投資時間（一個月～三個月）、投資金額（一百萬元～五億元）。
申請參與

**STEP 03**
模擬投資交易
在申請參與期間可利用本公司 HTS、MTS 系統進行模擬投資。
