# ♦ 一味追逐報酬，很容易陷入危險之中 ♦

股票是高风险的投資對象。因為一天的漲跌幅最大在 ±30% 之間。所以一般在買賣股票時，都會買進風險最小的股票。風險小的股票是什麼意思呢？指營業利潤持續發生，負債率低，財務狀況穩定的公司。

但是，在股票市場上，資產報酬率較高，表現較好的公司卻不是這樣的公司。其中有些公司甚至財務狀況不佳。有時候，這些業績不佳，財務狀況也不佳的公司，股價線圖卻顯得亮眼，價格快速上漲。為什麼會出現這種現象？
