# **06 | 董仲舒：汉武帝为什么选择他的儒学？**

许冠君 · 中国文化30讲

![](bbox=[0.05, 0.06, 0.95, 0.08])

前面4讲为你讲述了先秦儒家。虽然他们的思想很根本，但创始时期的先知，其实命运还是很凄惨的。孔子、孟子四处奔走，没有君王听他们进言。一直到汉武帝的时候，儒家登场，独尊儒术，儒学才初步运转。但是，你注意到了吗，汉武帝看上的儒学，并不是孔孟思想，而是儒者荀子这一脉发展下来的董仲舒思想。

有意思的是，董仲舒虽然成了儒家的大功臣，让儒家成了汉朝的官方意识形态，但是后世的儒家们对他的评价并不高，甚至在后来的宋明理学家看来，董仲舒就是儒学的异端。

为什么会这样呢？

# **汉武帝为什么选择董仲舒？**

要回答这个问题，首先要知道汉武帝看中董仲舒的究竟是什么。

秦末的乱世留给汉高祖刘邦的简直是一团烂摊子，人口从6000万减少到1300万，大量的荒地无人耕种。刘邦和他的子孙高帝、惠帝、吕后，只能对内与民休息，对外固守关塞。他们对北方的匈奴好汉们，已经无力抵抗，只能采取一种“和亲”政策，对匈奴称臣，每年进贡大量的丝绸和粮食，以求得暂时的和平。

汉武帝是一个有雄心的君主。在他即位前，国家休养生息，国库储备了大量粮食，人口也增长到3600万。雄心勃勃的汉武帝想要做一番事业，重现汉家帝国的辉煌。

要实现帝国光复和实力复兴，还得有一套治国理政的理论。懂得一定政治学说的知识分子，是政治治理的合法性基础。先秦儒家是政治学说的主要来源之一，它包括两个方面：一是具有治术，二是具有合理性论证。

秦法家当皇帝靠暴力治国，法家治理模式统一了天下，但也导致秦朝迅速灭亡。秦朝二世而亡，给世人一个警示，光靠严刑峻法是治理不了国家的。秦朝法家统治模式已经证明行不通了，得换一种。

但是仅仅靠讲仁政的儒家也不行。先秦儒家那一套，虽然讲仁政，但缺乏制度设计，也不具备解释皇权合法性的工具。所以，汉武帝需要一种新的理论，来为他的统治提供合法性，来解释为什么他是天命所归的皇帝。

你可能会问，为什么汉武帝不选择孔子或孟子呢？

你想想，孔子是平民出身，孟子虽然是大夫，但也只是普通的贵族。他们都没有建立过政权，也没有治理过国家。他们的理论，更多是伦理道德的探讨，而不是政治制度的设计。

而董仲舒不同。他不仅是儒家学者，还是公车上书的人。他提出的“天人感应”、“大一统”等理论，完美地契合了汉武帝的政治需求。

# **“天人感应”的理论建构**

董仲舒的核心思想是“天人感应”。他认为，天和人之间存在着一种神秘的感应关系。天是人格化的，它通过自然现象（如日食、地震、洪水等）来表达对人间的褒贬。

这种理论有一个巨大的好处，就是它既为皇权提供了合法性（君权神授），又对皇权进行了限制（天人感应，天灾示警）。

汉武帝正需要这样一种理论。它既让他能够名正言顺地统治天下，又让他在面对天灾人祸时，有了一套解释和应对的理论体系。

# **《天人三策》的提出**

公元前134年，汉武帝为了了解天下之士对治国的看法，下诏征问：“朕夙兴夜寐，恐惧于斯道不精，欲闻大道之统一。”

董仲舒三次上书，史称“天人三策”。在这三篇策论中，董仲舒系统地阐述了他的思想体系，包括天人感应、大一统、罢黜百家独尊儒术等主张。

董仲舒的“天人三策”，正中汉武帝的下怀。它不仅提供了治国的理论依据，还为汉武帝的集权统治找到了合法性来源。

# **罢黜百家，独尊儒术**

基于“天人三策”的建议，汉武帝最终采取了“罢黜百家，独尊儒术”的政策。

这一政策并非简单粗暴地禁绝其他学派，而是将儒家思想确立为国家的官方意识形态。它在教育、选官、法律等各个领域都引入了儒家的标准。

例如，汉武帝在五经博士之外增设《春秋》博士，并在各地设立学校，推广儒家经典。在选官上，察举制的标准也日益向儒家“孝廉”靠拢。

# **为什么后世儒学对董仲舒评价不高？**

虽然董仲舒为儒学的复兴做出了巨大贡献，但后世儒学，特别是宋明理学，对他评价不高。

原因主要在于，董仲舒的“天人感应”理论带有浓厚的神学色彩，被后世儒者认为是“粗疏”的。他们认为，董仲舒为了迎合皇权，在理论上做出了一些妥协，偏离了先秦儒学的纯粹性。

宋明理学家们构建起了更加精致、更加哲学化的儒学体系，他们将“天”解释为“理”，而非人格化的上帝。在他们看来，董仲舒的理论是低级的、原始的。

# **董仲舒的历史地位**

尽管存在争议，但我们不能否认董仲舒在中国思想史上的重要地位。

他是第一个成功将儒学转化为国家意识形态的人。他不仅影响了汉朝，也影响了此后两千多年的中国政治文化。

没有董仲舒，儒学可能只是一门优秀的私学，而非国教。他搭建的框架，为后世儒学的发展奠定了基础。
