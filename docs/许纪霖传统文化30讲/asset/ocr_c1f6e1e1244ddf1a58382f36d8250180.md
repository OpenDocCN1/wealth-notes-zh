# 穿过表象，抓住结构

你好，欢迎来到《传统文化30讲》，我是许纪霖。

说到中国传统文化，你的第一反应大概便是有诸子百家、唐宋诗词，也有琴棋书画、亭台楼阁，当然也少不了京剧昆曲、古日元相。

没错，它们都属于传统文化。但我这门课，并不一定会给你讲到，因为它们看来只是文化表象，也就是从物质文化呈现出来的结果。如果你对表象文化很感兴趣，不管听哪一讲，都是糟粕，乱花渐欲迷人眼，不知道从何学起。

我要给你的，是一个打通千年历史，站在高处俯瞰中国传统文明的系统性理解。我会用两章系统，从文化的高度解释中国文化成为国家。

一个脉络是精神，解决的是遗留心灵的问题。中国的思想以儒家为核心，其他的思想，包括宗教性文化精神都是互补、交错、共生，形成了文化精神的三个结构：“核心结构”、“互补结构”和“信仰结构”。

另一个脉络是现象，也就是社会文化的问题，政治制度的实践，核心是结构的基本特点，决定了中国文化的命脉。最后一个特质“总体结构”，我会从时间和空间两个维度，为你总结中国文化演进的大规律。

# 传统不是古代的，而是今天的

你可能会说，我是一个现代人，我对那些古老的东西，既缺乏兴趣，但也很怕它。要知道，在进入到文明历史前，我们是没有“传统”这个概念的。

但我想告诉你，你可能错过了更宽广的未来！一个不能只着眼于在古里看不到未来的时代，传统不能成功，更是看不到趋势。

今天最大的趋势是什么？就是中国已经成为世界第二大经济体，我们这是一个带有深厚传统文化底蕴的国家。在这个大背景下，关于文化的一切问题，都有传统的根基。如果你把传统仅仅当过去对传统的理解，你会发现传统是一种活物。事实上，传统是变化的，而且每天都在发生变化，时代对过去，对传统文化的理解也在改变。每个时代都有重新阐释传统。传统并不是古代的产物，而是今天社会的产物，留在我们血脉里的东西。
