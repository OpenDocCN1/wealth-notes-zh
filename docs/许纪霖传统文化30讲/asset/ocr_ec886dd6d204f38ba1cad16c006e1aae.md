# 传统就是留在我们血液里的东西

首先，界定问题，传统到底是什么？事实上，我们怎么理解传统，决定了怎么认识自己。

举个例子，礼貌，这当然是中国传统文化的一部分。但在五四新文化运动中，它被扣上了一个“吃人的礼教”帽子。礼仪真的是吃人的、限制人的“吃人礼教”？宋代以后，礼貌的背文是朱阳理学思想。那理学真的就是“灭人欲”吗？

实际上，理学最初是一种倡导人格独立自律的理学，是承袭孔子的儒学标准来中华文明的一次大突破，那么最朴素的理学，意味着这个文明有现下一个一个的，大器全。但是，理学在现实中的影响，竟然跟它的宗旨完全相反。

那么，今天我们到底应该怎么看传统，怎么看科学呢？100年前，鲁迅说教养孩子，是因为他所处的时代，要摧毁儒家的束缚，跟西方的脚步。但是，这100年来，我们所处的环境，中国的传统，都发生了巨大的变化。如果说用100年前的眼光看待传统文化，就不只误解了过去，也误解了今天的自己。这近几年，中国文化研究者越来越发现，我们不能把传统等同于过去、对比看待西方，传统中有很多观念现代的、西方的思想观念是接洽的。

所以，在定义传统的时候，我赞同美国芝加哥大学的社会学泰斗默顿的说法，他在这一本书叫《社会学原理》，里面有传统的经典定义：“传统是一个社会的文化遗产，是连续三代以上、继续影响当世人生活、并被赋予当价值有意义的文化。”
