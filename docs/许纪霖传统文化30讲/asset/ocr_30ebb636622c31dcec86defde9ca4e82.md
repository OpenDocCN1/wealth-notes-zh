# 13 | 儒家：为什么是一种另类的宗教？

许纪霖 - 中国文化30讲

中国文化的核心结构是儒家思想，它和其他几类潮流构成了互补结构，例如道教把时间留给中国，就实现了，是中国文化传统里其实还有一个非常重要的部分，就是信仰。

汉末末年，佛教传入，道教兴起。之后近2000年，中国文化发展的主线就是儒家和道教、佛教之间相互竞争、相互渗透。

在这样的互动中，三家对世界、人生各种维度的思考，塑造了中国人的精神世界，形成了—多元的思想体系，我把它这套多元的思想体系叫做中国人的“信仰结构”。

这一讲，我先来讲儒家。

你先大概问，我们已经有了一整个模块在讲儒家了，为什么在信仰结构里还要讲呢？

其实，儒家有双重性格。在核心结构模块中，我介绍的是儒家的一重性格—人文性。这个大家，你肯定已经熟悉不过了。不过，儒家还有另一重性格—宗教性。

# 宗教性的三个面向

老百姓祭祖、古代皇帝祭天、读书人拜孔子，这三类现象你肯定都不陌生。但是，你可能没意识到，这三件看起来毫不相干的事，在中国人的信仰结构里其实是同一件事，就是中国延续了数千年的祭祀。

儒生本来是专门管理礼仪的人，靠着这个专业技能，儒家就接管了中国人的祭祀。儒家的真正是为主导了中国的祭祀，才有了儒教的性质。

那么，儒家的祭祀，是祭祀谁呢？天和祖先当然是祭祀的敬，而且儒家还把自己的创始人孔子也列为了崇拜范围，让孔子有了和上天、天地并进的圣神性。于是，儒家的宗教性就有了三个不同的面向：老百姓的祭祖、国家的宗庙，读书人的祭孔。百姓祭祖、国家的宗庙、国家祭祀的是天地，而读书人呢，祭祀的是圣人孔子。

先说老百姓的宗祭祀祭祖。清明扫墓、祭日祭祖，都是融入中国人日常生活的祭祀体系，体现了儒家的伦理生活。中国人习惯把生命看作两条线，一条是对过去的回忆，一条是对延续的盼望。而祭祖这个行为，恰好把这两条线的关键，把过去、现在和未来串联起来。

类似这样的观念，在其他文明也同样存在。我还记得2013年奥斯卡奖最佳动画片《寻梦环游记》里？墨西哥有一个亡灵节，类似我们的清明节，每家每户都祭祀祖先。只要死去的人还有一个亡灵，这个世界里的灵魂就不会消失。你看，这是中国人的观念多么相似！这种观念下的死后世界，就是人间世界的延伸，身后而死后，杨柳木代。中国人要为子孙后代而活，为千秋万代造福；同时尊重老人又要对死去者，都与祖先。个人的生命和死后的价值，都由血脉家族的传承联系在一起。所以，中国的老百姓都相信，祭祖可以得到祖先的庇护，保证家族的兴旺。

我们再来看儒家宗教性的第二个面向，作为国家的宗教。上古祭祀传统里，还有一种更重要的仪式：祭祀天地。到了汉代，我们更强调五岳祭祀天地的意义，在解释儒家经典的时候，儒生就特别强调五岳祭祀是天子专属。

这看似仪式最终发成了国家权威的象征。古去泰山，泰山五岳之首。可不仅仅是一般的名山，在古代，泰山是历代皇帝祭天地地点的选择之地，隆重时的封禅大典，更是泰山举行的。那种仪式感和庄严感，炫耀的是国家的文化权力。那么，谁可以参加封神帝呢？皇帝和朝廷高官有资格参加，不对老百姓，连一般的士大夫也轮不上，只有远站在那里，做个观礼的份儿。

最后，儒家的第三个面向呢，就是读书人的宗教。宋代以后，读书人，起来越来越重视礼仪，和佛教仪式差不多。很多读书人都有书院，那是学生祭先师孔子的地方，书院里的儒生，每天一早就要拜孔子，行礼如仪。

# 另类的“宗教”

不过，儒家虽然呈现出宗教的特性，但是它和我接下古要讲的道教和佛教又一样，在我看，儒家是一种另类的“宗教”。

另类在哪里呢？一言而蔽之，儒家不是超理性的宗教，而只是一种世俗性的宗教。

一般老百姓为什么需要宗教？是为了精神有依循，有运有托邦，生死有安排。佛教、道教最本基都都有高而不上的、主宰命运之神，老百姓信仰佛、神仙或者上帝，可以给自己带来希望。但是，儒家一样，太阳还卖，没一个管人间事的神，不需要信任，也不会承诺什么具体的回报。儒家的宗教性最终为人文性服务。也就是说，人间天地、祖先沟通，最终还要回到现实的政治体系中去。祭祀祖宗为了强化宗族的绝对权威，封州大典是为了修身成一个有德之人。

儒家的所有宗教性格，最终还是落实在社会伦理和统治秩序层面。和基督教、佛教、道教不太一样，基督教都救个人灵魂，佛家也帮人解脱，道教教人如何长生，这些都和个人的灵魂、宗教家。但儒家，祭祀的仪式都是为了巩固世俗的家族、王朝和儒家的权威。

所以，百姓有去泰山，比去要求孔庙，千年无忘无息而又不丢丢脸面，因为文章有这种功利感，可以保佑你科举连升腾，而老天爷又不会在道德上，没有惩罚神仙的法力。所以，在大里面来，没人见读书人去圣庙先行大礼的，没有人叩头烧香的。用现在的话说，就是儒家不够接地气。

这几年中国出现了一群新儒家，也想在民间复兴儒家，他们到乡村里面去一块地，开起了书院，带写帮学当地的村民们开读《古贤经典》。但是，当他向村民们宣传儒家的现魂值。在民间和戏园子里面，老百姓喜欢，不是一句了然，儒家只为宗教的短板，一无宗教。所以，它注定只能是“另类”的宗教。

# 今日得到

最看家人重造了一种是它的人文性，这个儒家构造了中国人道德和政治秩序。它不要看佛教和道教影响多么大，但它的社会性宗教，是它人性的宗教。它们三个面向：老百姓祖先的宗教，国家宗庙的宗教，读书人祭孔的宗教。儒家不是哪个而朝，它是另类的宗教，它的实定，基督有点再接地神补上，特别是关于生与死的问题，人怎么长生？要么战胜对死亡的恐惧？这些人生终板终板，就由东汉末末出现的道教和佛教来回答了。
