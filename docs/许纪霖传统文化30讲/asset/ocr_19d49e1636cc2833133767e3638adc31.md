# 20 君臣关系：为什么会从共治走向专制？

许纪军 · 中国文化30讲
11:05 16109k

先问你一个问题，中国的君主专制是从什么时候开始的？你可能会想，是不是秦始皇开始的？或者到辛亥革命，中国的君主专制是否持续了两千多年呢？

这么理解其实不完全准确。史学大师钱穆先生在《国史大纲》里曾说，中国的政治分为两段，前一段是汉唐宋，是文官跟皇帝共治天下，这个阶段当然是君主专制，不过是开明的专制；后一段是明清，那时候才出现了绝对的君主专制制度。

我之前讲中央与地方关系时提到了周秦之交。其实在中国古代政治当中，还有一个同样重要的宋元之交。从南宋到元朝，中国历史发生了重大的转向。在政治制度上，古代的君臣共治变成了一种大变化，从开明的专制，转向了绝对的君主专制。

这个宋元之交究竟如何发生的？这背后有什么历史逻辑在推动呢？这一讲我要为你分析这个问题。

# 汉唐两宋的共治天下

我们先从秦始皇说起。秦始皇以为只要下面有一批听话、好使唤的官僚，就可以治服天下了。但是，秦二世而亡，让汉朝的皇帝明白了，光有治术不够，还得解决统治的合法性问题，从汉武帝开始，开始重视儒家，实行察举贤良文学制度，于是文官制度，成了皇权的行政支柱。

文官政府的头就是宰相。汉以前，宰相是私人，君主家事和国事。公私不分，所以宰相这个大家长能打理好。

汉宣帝之后就不一样了，国事和家事分开了。家事主要是皇帝自己管，宰相掌朝政，政府管理朝政。重大决策由君权和相权共同行使。这种权力分享权和相权的方式，有点像现代的企业制度。皇帝是董事长，用人权力权，宰相是总经理，负责日常事务。宰相的权力很大，皇帝的命令必须通过宰相的机构才能大政。如说，唐代的时候有规定，军国大事，哪怕是皇帝自个决定，宰相政，决定权大权都握在君权和相权，历史上常常发生宰相和君主的对峙，还留下许多名留传的故事。

汉唐的皇帝为什么不学学秦始皇，给自己留更大的权力呢？非不说，乃宁可有专门技艺之外，最重要的是，在汉唐两朝，君主背后有势力家族门阀的拼打撑腰，君主也得让着点。

到了北宋，虽然有大家豪族了，但宋太祖为了防止藩镇割据，杯酒释兵权，专制的武将，都是听文官，尊重士大夫。从本，君士大，明，士大夫。这都要感谢宋太祖留下的好传统。宋太祖的时候，宰相赵普要提拔某人高人，太祖不喜欢，他能拒绝，赵普不高兴，批评皇帝说：”赏罚分明是古以来的规矩，怎么可以下个人好恶来？“皇帝还是很了，退步。太祖知道，宰相不好，只能摔了。
