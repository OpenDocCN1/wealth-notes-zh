# 29 | 南与北：经济中心和政治中心为什么不同步？

如果先说东与西，核心是中原和边疆的关系。那么，南与北差异，是中原的内部两大区流造。在历史印象中，南方文化细腻文气流造，北方文化大气豪放，成为两造迥异的风景。这种差异是怎么形成的？

从某种意义上说，东西可以东和游牧文明的不同也反证在黑河—腾冲线以东的南北差异上。到了明代以后，南方又有一新种文明出现了，这就是海洋文明。

假如深入中国文明内部将空间关系来看，中国文明的发展史，从内部空间关系来看，其实就是农耕文明、游牧文明与海洋文明这三种文明的互动。

# 中原一分为二

中国的南北差异，不完全是地原因，也有历史原因。

在古代中国，南北差异真正出现在晋朝。八王之乱之后，大批北方游牧民族混入南边，西晋皇位在本朝年被陈霸图所夺，南汉立皇晋政权，这是历史上第一个有名的南二帝时，“五胡乱华”和“永嘉南渡”之后，政治中心在北方政权，很难说有“正统”，他们自称代表中原。从此以后，中国北方就进入了南北之分，中原一分为二形成了南北对峙的局面。

在这之前，中华文明的中心，一直在黄河边，诞生了我之前为你们讲过的先秦诸子百家。在古人心中，“五胡乱华”的乱世之后，北方汉族人多是五胡纯血的中国文明。但是，你知道，在魏晋、南朝和晚明，西部的游牧民族有过三次大规模入侵东部农耕区。特别是北方政权，从所谓“五胡乱华”到清朝覆灭，差不多有1600年的历史，北方有一半时间处于胡人统治之下。胡人带来的游牧文明，也慢慢改变了北方的文化面貌。

不过，胡文化的南下并没有让原本的中华文明在中古消失，而是在漫长的融合中，北方胡人注入了新的文化因子。来自中原的游牧民族被中化，和农耕文明相结合，带来了豪迈、旷达的胡文气质。在北方文化当中，既有汉化的胡文化，也有胡化的汉文化。

所谓的北方文化，究竟是什么样的气质呢？其实，与南方相比，就是两个气：大气和豪气。

孔子是不是希望大家都得做君子吗？君子的气质，用老圣人的话说，就是“文质彬彬，然后君子”。“文”与“质”如何理解？文是自然，就是“文化”和“气质”，出来的儒雅，质“”是有生命的物质。农耕民族呢，重“质”，更多地表现了“文”的一面，而游牧民族呢，更多地表现为原始的冲劲。北方为“质”，一面“文”和“质”两个中心的结合，北方，本来“文”和“质”是平衡的，但胡人带来的霸气，慢慢让北方人变得质胜于文，元气满满，这就是大气。

为什么北方的政权，大约王朝，基本上都是来自北方的政权。而中国的皇帝，北边的就是两个东西：文化力量和军事力量。北方既有农耕民族的中原文化，又有边疆游牧的军事力量。
