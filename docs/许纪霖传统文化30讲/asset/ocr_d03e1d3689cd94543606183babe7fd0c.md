# 【15】佛教：超越生死的秘密是什么？

许言恭 中国史30讲 今天

![](bbox=[0.05, 0.09, 0.95, 0.14])

在信仰问题上，儒家回到死亡，需要佛道来解决死亡。诸佛求道往生，实际上用否定死亡来解决生死问题。但是，死后的世界到底是什么样的，这个问题没办法逃避啊。鲁迅的小说《祝福》里面，祥林嫂就问了个终极问题：人死了之后，究竟有没有灵魂？

儒家、道教都没有给出很好的回答，生死这个终极问题还是要外来的佛教来回答了。

我说这样，并不是说在佛教之前，中国人不考虑死亡。儒家、道教都有自己的想法，但是佛教传入之后，这个问题就成了古代中国哲学和宗教的核心问题之一。佛教的因果报应、六道轮回和解除涅槃的观念，这些对生死终极问题的解答，成为一套非常深刻的系统性解释，重塑了中国人的生死观。

# 佛教的魅力

佛教和道教一样，都是在东汉末年兴起的，只是佛教是本教的，而佛教是外来的。为什么这两大宗教同时出现在东汉？从东汉末年起就群雄割据，正在中国历史上等一个朝代，中国早就像佛、道学家那样互相争吵。官僚制度崩溃，就连士大夫士大夫，都缺乏最起码的安全感。他们的内心充满了迷惘。儒学提倡的那种尊气节风范，人生追求，变得遥不可及，“末路当歌，人生几何，譬如朝露，去日苦多。”你看，就连不一世的太像曹操，在诗歌中也透露出了一丝极度惆怅的情绪。

不过，正是这种人命如草的战乱时代，会让人不由得追求临终的名利精神，也不再关心如传统那样，而是静下心来回归自身和内心，思考一些跟人生有关的哲学问题。你知道，魏晋时期出现了玄学。所谓玄学，就是思考玄妙玄玄的玄学上哲学问题。就是我们道家老子的道路，关心人心里面怎么做求内心的自由。

遗憾的是，中国古代人不怎么擅长抽象思考。就像我前面说过的，“末知生，焉知死”，我们从古就是现实主义民族。外来的佛教刚好填补了这个空白。

任何宗教，包括佛教，在形而上的哲学思考的时候，最终不能绕过神神发端终极问题：死和灵魂。不管佛教的教义如何深奥复杂，都是从这个问题出发。

这是，佛教的创始人释迦牟尼说起。释迦牟尼，早年是一个王子，有一天外出巡游，遇到一个枯槁的老人，旁边有一个在痛苦呻吟的病人，还有一个孩子正在玩耍，还有一个比丘尼的比丘。这让王子又心生现出一个问题：人一生辗转不定，老、病、死，无法止息。那么，究竟是否有救？如果有，终极的圆满又是什么样呢？

据说，他在菩提树下坐了七七四十九天，到了拂晓时分，突然顿悟了，悟到了宇宙和人生的真相，从此成了佛陀。佛陀在印度，就是悟道的人了，超越了生死，名利以及各种欲望和执念，彻底摆脱了痛苦的轮回。

你看，佛陀所觉悟的问题也是中国古人没有思考过，或者说得不详的，这个终极问题几乎可以说涉及所有宗教的必答题，而佛教，有自己的独特回答。

佛教的答案，简单地说就是通过对烦恼、超越死亡，求的是精神的解脱。

你可能知道，在佛教看来，人生就是一个永无止头的苦海，生死死死，为轮回，这是一个痛苦的主要根源，那么如何从这个苦海解脱出来呢？最重要的，是要修佛和明“觉”，顺便说一句，觉这个词现在已经是中国人日常语言，但是在佛教中，汉语中是没有这个词的。

现在问题来了，觉是什么呢？简单地说，佛教的觉，就是意识到个人的心，和宇宙的“同”，就像庄子最后的心意，也是意识到天地和我完全合一。你想，一个有限的，宇宙和无限的宇宙相遇了，岂不是超越了生死，获得了解脱？

这种独特的解释，随着佛教的广泛传播，给中国思想埋下了新的种子。
