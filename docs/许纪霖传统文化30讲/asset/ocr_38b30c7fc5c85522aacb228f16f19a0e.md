# 时间的中国：文明共同体

我相信，你学习这些传统文化，肯定不是为了发思古之幽情，而是为了古希腊浪漫诗的那种生活：认识你自己。

到了异国他乡，别人会问到你：你从哪里来？你是哪里人？你一定会回答：我是中国人！不错，每个中国人内心都有对中国身份的认同。

不过，你有没有想过一个问题：到底什么是“中国呢？”

你可能会觉得这个根本不能算一个问题。是的，今天的人对现代国家的理解是很清晰的，是一个有明确入口、疆域和主权的民族国家。

不过，你知道吗？这样一个民族国家在古代中国并不存在！

何为“中国”，为什么成了一个“谜”？这一课，我就要来与你聊聊这个话题。先来告诉你结论吧：历史的“中国”并不是根据版图或民族来定义的，而是根据文明来定义的，简单说，中国是一个“文明国家”。也是就定前面5个模块与你详细讨论过的，那些特定的思想组织和制度等构成的文明共同体！

# 古代中国不是民族国家

许多未太意识到，我们现在心目中的“国家”概念是从西来的。而从17世纪、欧洲各国打了三十年的战争之后才有的。欧洲各国打了三十年的战，最后打累了，签订了威斯特法利亚和约。原来帝国的世界秩序转向了民族国家的世界秩序。这个体系，给欧洲带来一个巨大的变化，确立了一个重要原则：“一个民族一个国家”。也就是说，国家按照民族的原则建立，每个民族都有建立国家的权利。而所有中国既没有这样的欧洲，今天却有45个民族。这就是民族国家的源头。

假如你用民族国家的概念来理解古代中国，那就错了，为什么？因为古代中国不是一个民族国家。

你可能会说，不是有中华民族吗？但你知道吗，中华民族这个概念，直到晚清，一百多年前，才有梁启超提出来的。他提出这个概念，正是看到欧洲的发达。既然都是一个民族一个国家，那么，中国是一个国家，当然也应该有统一的民族，那就是中华民族。

在近代，中国有汉族、蒙古族、满族、回族、回族，但没有中华民族。古代中国就像三十年战争之前的欧洲一样，是一个帝国。帝国和民族国家不一样，内部包含多个民族、多个宗教。

那么，在古代中国，这些不同的民族、宗教和文化，是怎么整合到一起的呢？

古人用一个概念解决了这个问题。这个概念就是“天下”。

# 胸怀天下

什么是天下呢？

张艺谋曾经拍过一部电影《英雄》，讲得是明暗刺杀秦王的故事。那年我坐在电影院，看到暗明跟秦皇偷偷独白出这两个字，“天下”的时候，就忍不住哭了。秦始皇的想法，秦法家的秦皇“天下”，就是富国强兵，实现霸业，哪里会有“天下”这个概念！

美国著名历史学家霍夫在《书里》说过一句话，天下在“天下”在中国人观念中，是一个价值体，又是一个权力体。我觉得很有道理。

先来看作为“价值体”的天下。明末清初大儒顾炎武，他也说过，“天亡”和“亡天”不一样，“亡国”是改朝换代，“亡天”，意味着文明不存。《大家》不论心还道传，谈到了明廷的遗民，大家不会忘记，还有一句家喻户晓的名言：天下兴亡，匹夫有责。他说的天下，就是作为“价值体”的天下，就是值得追求的普世文明秩序。
