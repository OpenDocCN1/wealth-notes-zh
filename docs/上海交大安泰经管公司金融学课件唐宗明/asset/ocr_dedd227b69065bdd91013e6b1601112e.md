# 市场价值指标的计算

+   - 假设公司总股分数3300万股，年末股价88美元
+   - 股票市值 = 每股88 × 3 300万股 = 290 400万
+   - 市盈率 = 每股价格 / 每股收益
+     - 88 / 11 = 8 倍
+   - 市值面值比 = 每股市值 / 每股账面价值
+     - 88 / (2 591 / 33) = 1.12 倍
+   - 企业价值 (EV) = 资本市场价值 + 带息债务市场价值 - 现金
+     - 2 904 + (196 + 457) - 98 = 3 459
+   - 企业价值乘数 = 企业价值 / 息、税及折旧与摊销前利润
+     - 3 465 / 967 = 3.6 倍
