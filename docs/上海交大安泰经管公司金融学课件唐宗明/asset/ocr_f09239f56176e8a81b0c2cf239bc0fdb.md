# 股权自由现金流与股利、回购

▶ 股利：由于 CF(S)=股利+权益融资净额

所以：股利=CF(S)+权益融资净额

将 CF(S)=CF(A)-CF(B)

带入股利公式

因此：股利=CF(A)-CF(B)+权益融资净额

=企业自由现金流-流向债权人的现金流+股票融资净额

=NI+递延所得税+Dep.-CAPEX-ΔNWC-(I-DebtIR)+权益融资净额

=NI+递延所得税+Dep.-CAPEX-ΔNWC+DebtIR+权益融资净额

▶ 回购：由于权益融资净额=新发行股票-回购

可得：股利=CF(A)-CF(B)+新发行股票-回购

因此，回购=CF(A)-CF(B)+新发行股票-股利

=NI+Dep.+递延-CAPEX-ΔNWC+DebtIR+新发行股票-股利
