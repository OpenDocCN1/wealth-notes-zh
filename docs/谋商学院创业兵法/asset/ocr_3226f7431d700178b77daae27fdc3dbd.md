# 创业选择合伙人的一些问题

如何选择合伙人？为什么我们创业需要选择合伙人？什么样的关系是最适合做合伙人？

我们可以参考一下很多优秀的大公司，最初创业的时候，如微软

的盖茨与艾伦，后来的鲍尔默，苹果的乔布斯与沃兹。这些人都是很

早年的朋友甚至是同学。中国的很多大企业都是家族血缘关系！

为什么是这样的关系？因为创业并不容易，这个过程中会遇到很

多挫折与磨难，一般人不具备大的格局，很容易因为小的利益争吵，

而血缘关系即使再吵，甚至是打架，过后也多半能原谅。这样凝聚力、

就不会出问题，容易成功些。不过也有例外，不能原谅的就夫妻反目， 兄弟成仇了。

现代社会，很多人神经敏感脆弱，一点点小事，都能整的大动肝 火，如果没有什么相当长的了解，合伙人很容易散伙。
