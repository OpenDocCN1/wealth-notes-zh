# ### 心态决定人生

一位哲人说过：“你的心态就是你的主人。”在现实生活中，我们不能控制自己的遭遇，却可以控制自己的心态；我们不能改变别人， 却可以改变自己。其实，人与人之间并无太大的区别，真正的区别在 于心态。所以，一个人成功与否，主要取决于他的心态。社会上有很 多在逆境中拼搏起来的人，都是因为心态好，心的强大。弱者主要是 弱在他的心态。
