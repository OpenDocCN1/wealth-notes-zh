# 让员工自己管理自己

我最喜欢无为而治，我不喜欢对员工做什么规定，不管做什么，我都喜欢让员工自己出方案，定策略，搞执行。因为是他们自己出的方案，定的策略，所以，他们执行得也比较到位。

我曾经见过一个与我想法类似的公司。

他们公司的走廊墙壁上张贴着十几条格言。“没有付出，就没有收获。”“完成工作很难，但有意义；失去工作很容易，但没有价值。”“多一个微笑，少一点矛盾；多一份责任，少一些隐患。”这些格言平实但意义深刻。看署名才知道，格言作者都是该公司的员工。
