# ## 十一点做老板的心法

1. 做互联网生意，自己就是上游是顶点，做传统生意，你很容易在别人的下游。有货款，欠账，烂账，上游企业一倒闭，就砸死一群下游企业。所以，现阶段有智慧的老板都来玩互联网吧。

2. 找人合作，先搞清楚这个人的状态是正在走上坡路吗？如果是上坡路，跟他合作就很容易成功。如果是走下坡路或者维持现状呢？大势已去的人，不跟他玩。
