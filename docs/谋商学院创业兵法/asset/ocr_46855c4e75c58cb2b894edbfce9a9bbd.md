# 想当好老大，就要拿自己人开刀

如果你只知道自己的队员很好，而不能指使他们做事，或者只知道溺爱而不能对他们下命令，大家经常违反你定的规章制度也不能治理，那么你这个队员就成了骑兵，就没法用了。

我们当老大，可以平易近人，可以礼贤下士，但不可骄纵下属。

我们很多人，往往对一个人太好，结果是害人害己，为什么呢？

因为一昧的只有恩，只有爱，却没有规矩，它就会习惯，并且骄纵，认为理所当然。如果你哪天因为公司的发展要把关系调整过来，他就要跟你闹。不听你的，这时候，你就只好放弃他，他没了机会，你自己也白培養他了。

人就是这么贱，一旦习惯了的恩情没有了，就必然成为仇人，你会说，怎么会有仇啊？我又没伤害他，只是停止了恩情而已，是的，对你来说，是只停止了恩情，可对他来说，却是夺走了既有利益。

所以叫恩怨，恩仇，没有恩，就没有怨，没有恩，就没有仇，曾经你给了他多大的恩，就有多大的怨，就有多大的仇。

我们古代那些成大事的将军，就深知这个道理。所以，李靖说：“畏我者不畏敌，畏敌者不畏我。”也就是说，怕我的，才会不怕敌人。不怕我的，就怕敌人。所以，当将军，一定要比敌人更加可怕，才能指挥军队，吹了号角，冲锋陷阵的，不一定会死，吹了号角，不冲锋的，马上砍死，这样大家才听话。
