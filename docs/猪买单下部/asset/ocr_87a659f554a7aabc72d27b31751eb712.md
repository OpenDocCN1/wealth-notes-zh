# ### 第三步骤：二次置换

……春天把换来的广告时段，一半留给自己咖啡厅打广告，一半拿出来换东西。经过谈判，找到一家二手车车行，换了一辆二手保时捷卡宴。春天把这台车买了45万，刚好可以抵解决燃眉之急，资金问题暂时不担心了。

# ### 第四步骤：循环盈利

一方面电视台大力宣传，另一个方面很多送出去的咖啡代用券，年轻人没事就去喝杯咖啡。

各位有没有发现一个现象，人都是什么时候喝咖啡？

周一到周五白天要上班，基本上是晚上吃完饭喝咖啡，喝着喝着，有点饿，但是又不是非常饿，就想着吃点点心，盈利的时候来了……

周六、周日日，上午睡觉，吃完午饭下午去咖啡厅跟朋友聊聊天，聊着聊着，唉，饿了……
