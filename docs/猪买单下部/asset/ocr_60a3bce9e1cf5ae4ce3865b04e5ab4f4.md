# 第15节：空手道借尸还魂亏损中酒店，套现1亿金蝉脱壳

吴凯从穷困潦倒、找不到工作、身无分文到屌丝逆袭没有花一分钱就整合了几十家酒店，当月实现盈利！两年半时间身价过亿，他是如何做到的呢？

让一诺老师跟你一起来见证奇迹吧……
