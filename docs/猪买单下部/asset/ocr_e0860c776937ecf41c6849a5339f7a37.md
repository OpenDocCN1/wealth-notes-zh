# 第 26 节：灯具带销老板疯了，免费送出 1 亿倒赚 3 亿

小虎开了一家灯具公司，专门生产销售灯具，由于传统灯具生意竞争激烈，前几年转型做太阳能，谁知道不止小虎一个人这一想，很多人都这样想，结果太阳灯从短暂的蓝海行业一下子变成红海行业！

面对市场的饱和，小虎使尽浑身解数，最终还是没能突破瓶颈，小虎四处求学，俗话说病急乱投医是逢庙就烧香，小虎到处交学费，钱花了不少，可是市场不但没有做起来，反而越来越难做！
