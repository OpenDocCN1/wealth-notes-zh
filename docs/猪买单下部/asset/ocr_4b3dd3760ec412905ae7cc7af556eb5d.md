# ## 第七个历程：找到高质量人脉

在这里给大家插个故事，一个鬼故事，一诺老师无数次在课程中提起过，不关你相不相信这个世界有鬼，都没关系，因为这是个哲理故事，有可能会决定你命运的故事：

有一个村叫吃瓜村，里面住着很多吃瓜群众，可是吃瓜村有个人却比较聪明，这个人叫——阿明。

夏天的一个傍晚，天气炎热吃瓜村群众就在河边洗澡，阿明也一起下河洗澡，洗着洗着天渐渐的黑了起来，这时候春天准备上去，可是一双毛茸茸的爪子抓住了春天的两只脚，春天用尽全身力气也没能挪动半步……
