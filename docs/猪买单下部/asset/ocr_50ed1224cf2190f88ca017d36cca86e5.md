# 案例：用纸换奔馳

在广东有一个餐厅的老板，叫朱总，朱总不满足自己的现状，总是攀比别人住别墅开豪车，在内心深处不断的告诉自己：

![](bbox=[0.07, 0.26, 0.83, 0.4])

于是不断的参加各种培训，结果效果还是不大，可是朱总就像打了鸡血，就连手臂上都纹了字：永不放弃！

我不建议大家这样做，记在心里就好了，不必要纹在手臂上！后来我才知道他上了我一个好朋友的课程，叫陈老师的课程，陈老师刚刚来到中国大陆的时候，对中国大陆不是很了解，一诺老师是陈老师中国大陆最早的朋友之一，所以一诺老师这位陈老师的激励培训还是比较了解的……

因此朱总被陈老师激励了，整天对着镜子说：“我是最棒的！我是最棒的！我是最棒的！我一定会成功！我一定会成功！我一定会成功！”

可是喊了1年成功了没有？（没有！）
