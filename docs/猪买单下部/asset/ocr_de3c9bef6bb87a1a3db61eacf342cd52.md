# 第四步骤：融资第一桶金

当这一切都达到条件的时候，接下来要干的事情，就是融资，融资是有步骤的，大家千万不要乱来，要按照步骤来：

+   1. 信用卡融资

开始的时候，信用卡不要办理太多张，3张最佳，为啥？因为非常缺钱的人才会疯狂办理很多张，所以一个正常人3张信用卡是合理的。

而且，记住了：信用卡的钱不要乱花，在准备投资之前，千万不要办理分期，一旦分期，银行就会警觉，甚至有些银行认为你可能是缺钱了！！！
