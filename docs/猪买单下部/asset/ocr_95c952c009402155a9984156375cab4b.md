# 第 08 节：健身房免费比收费更赚钱的实操案例

陈坤自幼习武，后来跟着朋友来到广东发展，先在朋友的健身房当健身教练，太太是健身操教练，两个人把一辈子的积蓄拿来开了一家健身房，由于不擅经营加上市场竞争激烈，自己的健身房总是入不敷出、一日不如一日……

不改变就是死，所以陈坤有着强烈的危机感，开始四处寻找最佳商业解决方案。俗话说病急乱投医、逢庙就烧香，陈坤报名了各种成功学、财商、致富学、创富学等大师们的课程，还报名参加了 88 万学费的资本上市课程，可是学来学去都是纸上谈兵，企业不仅没有扭转亏损的局面，反而欠下了银行巨额的负债！
