楚王非常高兴，兑现了承诺，把公主许配给了猪哥哥。

后来楚王问猪哥哥成功的秘诀时……

猪哥哥拿起笔在墙上写下一句话，

![](img/9e495c245c6fc762e84f842b252dc362_568_0.png)

楚国地界出了很多了不起的人物，例如：创立道家学派的老子、爱国人士屈原、抗秦名将项燕、楚霸王项羽、清朝末年大泽乡起义的陈胜吴广、推翻秦朝的汉朝开国皇帝刘邦、后来的明朝开国皇帝朱元璋，也是在楚国地界。

后来就有了“天上九头鸟，地上楚国人。”

现在传的是“天上九头鸟，地上湖北佬。”

不是楚国人奸诈，而是楚国人比较聪明，就像猪哥哥一样，聪明人不是一开始就想要索取，而是想着如何付出！

舍得舍得，大舍大得，小舍小得，不舍不得！

想要收获玉米，首先要在地里种下玉米的种子！

想要收获大豆，首先要在地里种下大豆的种子！

![](img/9e495c245c6fc762e84f842b252dc362_569_0.png)

想要收获任何庄稼，都是同样的道理，必须先要播种，如果你没有收获，很简单，就是因为你没有播种！（付出）

所以春天是农民的儿子，知道种瓜得瓜种豆得豆的道理，于是开始建立信赖感……

春天建立信赖感用了五个方法：

1. 每次学习春天不是学习的，春天是服务的，认真做笔记，把笔记整理出来，然后印刷出来，免费发给每位同学手里，那时候还没有现在的 QQ 群和微信群那么方便。
2. 认证记住每个人的名字，从心理学角度被记住名字的人感觉你重视他，让他感觉在你心中他很重要！因为人总是喜欢跟在乎他认可他的人在一起。
3. 每次开课前打电话给每位同学，告诉他们别忘记哪天开课，挂掉电话发条信息告诉机场、火车站到课程现场的路线。
4. 课程结束后，经常给每位同学打电话沟通，联络感情！
5. 帮助同学设计他们公司的招商和营销方案……

就这样，大家越来越信任春天，在同学们的眼里，春天就是大家长，很付出！在同学们的心里，春天就是力量，就是他们坚强的后援！

## 第九个历程：事实胜于雄辩

春天跟同学们建立信赖感，与此同时也不忘做一件重要的事情——榜样的力量！

春天从小就磨练的脸皮够厚，也不知道什么叫做面子！
