# 第10节：零利润颠覆整个行业狂赚2亿让同行傻眼

齐总在三十年前开了一个装修设计公司，由于做到比较早赚了一些钱。可是十年后，很多人看着眼红也纷纷模仿，加入装修公司的竞争行列，一块蛋糕一个人吃随便吃，两个人分着吃，可 100 个人怎么办？抢着吃!!! 大多数装修行业都死于弱肉强食的市场竞争中，苟活下来的也是奄奄待毙……

齐总做了三十多年了家装行业，不想轻易放弃，于是苦苦挣扎……也不是不学习，也是到处学习，可是面对市场上假大空的课程，齐总是病急乱投医逢庙就烧香，钱花了不少，就是没啥效果……

正当齐总对家装行业失去信心，想要放弃的时候，经过朋友介绍参加了一诺老师的课程，经过一诺老师现场辅导，陈总重新找回了继续战斗的勇气和信心！

但是这个时候的齐总已经满身伤痕，负债累累……
