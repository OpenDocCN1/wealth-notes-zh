# 第二步骤：设立公司

+   1. 小赵以自己的名义注册了贸易公司 (免费注册)。

+   2. 既然开公司，一定要有个办公场所吧，去电子城花 1000 元租一个柜台。

+   3. 把柜台转租出去，让别人来经营电子产品，记住，要和你注册的营业执照范围吻合。这同时要跟承租方谈好，这个店铺对外的名义还是你的，所以营业执照肯定是挂你的，当然了，你会通过其他方式帮助这个承租方卖货，不过卖出去的货，利润要分一半，双赢的情况下，大家都会同意的。

+   4. 紧接着，去银行免费申请一部 POS 机，免费的，为什么要申请 POS 机呢？因为银行看重你的流水，流水证明你有收入，有收入就可以申请银行信用贷款，就是可以跟银行借钱……
