# 前言

大家都知道一诺老师自创立《商业模式》课程起，在教育行业辛勤奉献 18 年，凭借 100% 实战案例教学，不仅桃李满天下，也为社会培养无数弟子，这些弟子都在授课《商业模式》、《顶层设计》、《利他模式》、《免费模式》、《品牌魔力》、《股权兵法》、《融资兵法》、《信用融资》、《营销兵法》、《万能营销》、《魔鬼营销》、《疯狂爆粉》、《超级演说家》等，一诺老师很荣幸能为社会培养这么多优秀讲师人才。

作为《商业模式》、《顶层设计》、《猪买单》等经典作品的始作俑者，一诺老师闭关修炼 13 个月将课程全方位升级，亲自撰写《猪买单》第 1、2、3、4、5、6 本，原打算 6 本合著一部，但考虑大家不方便携带，就分成上下两部。

《猪买单》上部主要是“开悟篇”和“策略篇”两大部分，是企业家实操落地必修的基础课程！

《猪买单》下部主要是“36 头猪”每一头猪是一个案例，每个案例都有实操的步骤、案例解析等实操模型，方便大家学习。《猪买单》下部的头到尾都围绕一个主题，你不用出钱，跟你合作的人也不用出钱，大家都是赢家！是不是很神奇呢？
