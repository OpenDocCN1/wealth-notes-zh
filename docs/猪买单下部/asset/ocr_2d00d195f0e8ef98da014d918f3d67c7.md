# 5. 营销要准

什么意思？

就好像学生喜欢什么？关心什么？你要准确的投其所好！

就像兔子用胡萝卜钓鱼，一个礼拜都钓不上来，结果兔子开始骂鱼，说鱼不识货！鱼听到后很生气，说下次再用胡萝卜忽悠我，我就打扁你！

还有就是，大学生都是青春期，青春期都是视觉型动物，你的图片要选的好，商品和海报要经过专业美工处理过的，这样才会吸引别人眼球。

# 6. 奖品要多

一所像样的大学都是一两万人，这么多人，你结果设置奖品只有 5 名，人家一看，切！这么低的中奖率，还是不要参与了，我没有这么好的运气……

所以大奖要大，小奖要多！这样你才能让更多人参与，从而形成一种快速裂变的效果。

奖品多了，中将人数就增加，才会吸引更多人参与进来……
