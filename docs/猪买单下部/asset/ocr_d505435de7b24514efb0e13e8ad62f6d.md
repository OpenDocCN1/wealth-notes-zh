# 1. 共享客户

这样因为客户都是同一个群体，找来的客户，优先推广十八个托管项目的产品、商机和投资机会。

例如你现在的项目假设跟十八个有 1000 万以上实力的企业共享客户，每个项目公司有 1 千万粉丝，共享之后你就有 1.8 亿粉丝，各位这种裂变就像核武器一样。

# 2. 共同资源

资产管理公司提供办公场地，充分的做到集团化运营，和科学的管理，共享培训导师、共享办公设备、共享顾问团队。

办公场地集中化，场面更大、更气派、更彰显实力！

# 3. 共享资金

例如本次宣传费用 900 万，十八个项目每个才出 50 万，集中资金营销宣传，才能事半功倍！集中优势兵力打歼灭战！

# 4. 降低风险

即使有两三个亏了，资产管理公司从其他项目赚的钱，来补贴这家公司的亏损，就可以起到抗风险的作用。
