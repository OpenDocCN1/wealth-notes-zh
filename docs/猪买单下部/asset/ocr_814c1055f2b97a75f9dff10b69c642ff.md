# 第四把火：现场成交

这客人都到了现场了，关键就在……

活动门口是搞气氛的———模特、木偶人、踩高跷的、猜谜语获奖的，引来无数围观群众，这就是古代人常说的“有钱的捧个钱场，没钱的捧个人场！”

……总之气氛就是塑造两个字——热闹！

这里涉及到客户心理学，大家想想看平时你看到一家店，鬼影子都没有，你会觉得；“咦，人都没有，就我一个人会不会上当受骗呀？”当你到一家店，哇好多人，人气爆棚的氛围会激发客户购买欲望！
