# 第四步骤：追售获利

于是在发货的同时，寄一张销售信……

这份销售信也是穿着《心脏保健手册》的马甲，其实就是卖后续产品的“软广告”，这说来也是文笔了得，客户看到《心脏保健手册》之后，加上“心脏救星”的确管用，就接受《心脏保健手册》的推荐，购买了“心脏护航套餐”，这个套餐定价是 198 美金……

这里特别提醒一下，为了不引起电视台的反感，博士成立了第二家公司——B 公司。在《心脏保健手册》里强调，我们的产品已经够好的了，但是有一家 B 公司的产品质量更好，如果老王卖瓜自卖自夸可能效果不大，可是《心脏保健手册》里推荐别人(还是博士的公司)的产品，顾客就更容易接受……

大家有没有发现，虽然前期每瓶倒贴一两块钱，但是通过追售盈利可以弥补免费产品的成本！

据统计 40%的位顾客，在花 1.99 美金试用“心脏救星”药物有效时，当即下单购买 198 美金的“心脏护航套餐”！

比他们之前预算的 25%的追售成功率高出 15%，因此博士的企业当月就实现盈利……
