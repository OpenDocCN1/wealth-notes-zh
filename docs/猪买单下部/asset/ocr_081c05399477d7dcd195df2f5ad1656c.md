# 这里总结流水五个关键

+   1. 创造长期稳定的现金流

三天打鱼两天晒网的流水，这样的公司饥一顿饱一顿，收入不稳定，银行哪里敢借给你？

例如你是卖电子产品的，三更半夜有钱进账，也不符合实际，因为你又不是夜总会……
