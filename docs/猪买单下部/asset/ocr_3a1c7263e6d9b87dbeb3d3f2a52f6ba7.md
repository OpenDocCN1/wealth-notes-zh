# 第 09 节：借尸还魂倒闭家具厂快速回笼资金实战案例

这个案例一诺老师已经很久没有讲了，有个家具企业由于不适应市场的竞争环境加上市场营销跟不上，欠了一大堆债务，还有员工欠薪导致罢工，导致企业停业，离破产就差一步之遥……后来有个读书人力挽狂澜，把濒临倒闭的家具厂从死亡的边缘拉了回来，7 个月就回笼资金近千万，20 个月扭亏为盈，后来年盈利上亿，他是如何做到的呢？
