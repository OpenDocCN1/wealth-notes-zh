# 第三步骤：直播会销

现在是信赖感严重缺失的年代！

全世界最伟大的营销秘密就是——信赖感的营销！

如何让别人喜欢你、爱上你、对你欲罢不能，是摆在每位企业家面前最重大的任务！

所以当你的粉丝没有给你一分钱，你都愿意为他们贡献知识！相比你的同行啥都没有付出，没有社会责任感，没有使命感的！请想象一下，你的客户内心的信赖感对谁会比较强？

当然是有贡献的人，因为现在最好的营销不是说的天花乱坠，而是输出价值，这个价值可以是快乐、励志、情怀等，例如现在最最流行的——文化营销！

江小白卖的不是酒，是小资情调；

杜蕾斯卖的不是避孕套，是快乐；

褚时健卖的不是橙子，是励志；

华为卖的不是手机，是民族情怀；

所以你卖的不应该只是产品，而应该是产品背后的附加价值！什么价值呢？例如使命、大爱、格局、利他、情怀、励志、情调、快乐、思念、感恩、奉献、付出……
