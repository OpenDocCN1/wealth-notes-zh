# 第二步骤：粘性互动

就是建立信赖感，大家都听过一诺老师讲的【1001 次信赖感法则】的故事，信赖感需要慢慢积累，如何积累呢？

首先你要创造价值！创造被别人利用的价值！

![](bbox=[0.1, 0.31, 0.86, 0.46])

你可能会说化妆品呀！非常好，还有呢？

一诺老师的意思是，除了你的商品之外，还能为他们做点什么力所能及的事情！

例如——

+   1. 大学生成长期可能有心理障碍，你可以免费心理辅导课；
2. 大学生可能需要营养知识，可以免费开营养学；
3. 大学生可能需要演讲口才，可以免费开口才类课程；
4. 大学生可能还需要社交，可以免费开人际关系课程；
5. 大学生可能还需要创业，可以免费开创业类课程；
6. 大学生还需要形象，可以免费开设形象设计类课程；
