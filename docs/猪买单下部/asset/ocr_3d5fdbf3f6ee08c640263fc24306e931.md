# 一诺老师请问大家五个问题

+   1. 通过一诺老师的亲自教练，你有没有可能比你现在多赚一点点？(有)

+   2. 通过一诺老师的亲自教练，即使没有赚到钱也没有任何损失？对不对？(对)

+   3. 既然没有损失，多赚的钱里面，一诺老师只要 3%就满足了，这样的员工，后付工资，无底薪的员工请... 问找到哪里找？而且还是身经百战，辅导无数企业，单单顾问费一年就 300 万，像这样的老师辅导你，你肯定不会吃亏的同意吗？(同意)

+   4. 所以你想不想一诺老师亲自辅导你、训练你、指导你企业的项目落地，给你最实战、最落地、最有效的执行方案！想还是不想？(想)

+   5. 一诺老师实在不明白，除了下雨没打伞脑袋进水的、没有梦想不愿意改变的、没有责任不愿意承担社会使命的、没有格局没有大爱的、故意捣乱、砸场子的，唉，除了以上几种人，请告诉我还有什么人会拒绝 一诺老师帮助他？五体投地跪求答案……
