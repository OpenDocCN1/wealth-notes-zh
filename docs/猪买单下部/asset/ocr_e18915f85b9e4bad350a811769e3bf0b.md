# 第34节：再没人敢这样跟你对赌，最差状况双倍赔你

最近各种老师多如牛毛……

千万不要被一些假大空为了骗取学费的无良培训机构忽悠了，很多人看着别人演讲，于是做个造型，拍个形象艺术照片，偷个演讲稿，就自己号称某某大师、亚洲权威、世界第一、祖师爷、创始人、第一人等雷人的头衔！我呸！

先不问他们的头衔都是怎么来的！

你就看他没有本事，主要看四个方面：

+   第一：他教你成功你看他自己成功了没有？(捂脸)
第二：他教你营销他自己的营销水平如何？(捂脸)
第三：他教你演讲他自己的演讲水平如何？(捂脸)
第四：他教你吸粉他自己又吸了多少粉丝？(捂脸)

所以这就是教育的悲哀！

很多人打着老师的旗号出来四处忽悠！
