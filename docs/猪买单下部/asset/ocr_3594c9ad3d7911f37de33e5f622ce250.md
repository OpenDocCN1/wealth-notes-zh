# 第一：给猪吃干粉

啥是干粉呢？就是猪饲料不要用水拌，你越是想拼命加水，猪还不理你，猪也有脾气，怎么办？顺着猪的脾气呗。给他吃干粉，而且这个干粉里面加盐！

你想呀，这个猪一看，啧啧啧，！服了 U，主人变大方了哈，于是很愉快的想用美食！

·谁知道，越吃越渴！等猪渴的受不了的时候，哈哈哈哈……
