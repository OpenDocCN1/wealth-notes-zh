# 第四个历程：学习改变命运

春天 16 岁在上学的时候, 在自己的内心深处种下一颗种子, 这颗种子就是——我一定要当老板！

春天开始觉得学校教的东西将来不能当老板，于是热心起课外书籍，例如：看了很多伟人传记、晋商、徽商、浙商类的书籍，终于醍醐灌顶，恍然大悟……

春天以前不爱看书，一看书就困，可是研究起商业来，居然可以整夜整夜的亢奋不睡觉……

后来春天带着同学们做了很多生意，几乎没有一次亏钱的，被同学们誉为小诸葛，意思是有头脑，点子多！想赚钱就跟小诸葛合作……

春天不满足于在校期间跟同学们一起做的那些小生意，开始想：我如何才能具备更大的能力？

![](bbox=[0.08, 0.71, 0.83, 0.85])

没有悬念，标准答案是——学习！
