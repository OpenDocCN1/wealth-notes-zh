# 举例：XX 币

老李跟小李找了一个马甲叫——片莎币，简称 PSB。

小李跟老李找了一个著名的村子叫做：吃瓜村

就开始操作了，怎么操作呀？

![](img/9e495c245c6fc762e84f842b252dc362_89_0.png)

媒体的操作手法有两种：

# 第一种就是借势

借用国家法律法规政策或借用名人的影响力。例如大家常见的类型：“小马哥说要消灭现金”、“某某人比较看好 XX 币”

……大家有没有印象？

# 第二种就是造势

主动进行媒体鼓动，各种朋友圈、论坛、微博、甚至新闻上这样宣传：“XX 币是一种投资”、“谁谁投资了 XX 币赚了多少钱”！甚至更有危言耸听者说“XX 币有可能取代 RMB”……

总之，就是制造出种种假象：

1. 合法：谁谁都说（其实是断章取义）这是趋势……
2. 趋势：未来“PSB”会有升级潜力，大家快来买呀……
3. 赚钱：大肆炒作谁谁谁都发了大财……

![](img/9e495c245c6fc762e84f842b252dc362_90_0.png)

这最最关键的就是“赚钱”

于是，老李和小李他们开始在吃瓜村表演了……

老李选了一个马甲——片莎币，简称PSB。
