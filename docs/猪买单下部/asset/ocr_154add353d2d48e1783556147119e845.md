# 第一步：限制名额

他规定，在这届奥运会上，每个行业只选定一个赞助商，且要把赞助商限定在30家以内，做精的同时，还能以此激励企业抬高赞助竞标价格。

# 第二步：限制门槛

尤伯罗斯还设定了一个赞助最低限额：400万美金，门槛提上来，资金也就进来了。
