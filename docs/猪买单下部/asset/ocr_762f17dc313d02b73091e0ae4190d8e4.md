# 艺术猪

# 第22节：艺术培训学校学费全免，却闷声发大财身价过亿

小雪做艺术培训，由于做的比较早，起初赚到一些钱，随着做的人越来越多，导致市场混乱生源越来越枯竭，每个月收入还不够房租人工水电开支的，怎么办？

于是病急乱投医、逢庙就烧香，报名了很多课程，钱花了不少，就是没有花对地方……小雪被市场上各种培训忽悠的眼花缭乱，其实大多数都是假、大、空……

![](bbox=[0.11, 0.61, 0.87, 0.76])

小学一次又一次希望，却一次又一次失望，正当小雪对自己的艺术培训学校失去信心的时候，一个偶然的机会，参加了一诺老师的课程，经过一诺老师的亲自辅导，小雪终于找回了自己的艺术梦想，感觉自己满血复活！
