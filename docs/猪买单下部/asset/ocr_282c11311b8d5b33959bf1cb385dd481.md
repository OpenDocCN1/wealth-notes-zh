# 第四步骤: 免费中介

……任何事业想要成功，就不能脱离群众基础，所以莫总发布了一个恐怖的决定: 地产中介免费！如何免费呢？

举个例子:

你购买一套房子, 500万, 中介费15万, 这十五万给你15万的消费券, 这个消费券在哪儿用呢?

莫总的网上商城: 周围的美容院、干洗店、饭店、宠物医院、汽车美容等等, 都可以消费, 价格不变……
