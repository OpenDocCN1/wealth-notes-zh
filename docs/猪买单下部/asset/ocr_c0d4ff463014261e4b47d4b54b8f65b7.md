# ## 第四步骤：只收五种人

人这一生总是要做点事，不是跟喜欢的人一起做事，就是跟讨厌的人一起做事，但是一诺老师更喜欢跟喜欢的人一起做事，特别是免费的帮助，一年时间，一诺老师不想把时间浪费在不值得帮助的人身上！

例如三国时期蜀国二世皇帝阿斗！诸葛亮都扶不起阿斗！

有些人啊，这辈子都扶不起来，一诺老师何必把时间精力花在这种人身上，与其浪费时间，一诺老师不如把时间精力放在帮助具备成功特质的人身上！同意吗？(同意)
