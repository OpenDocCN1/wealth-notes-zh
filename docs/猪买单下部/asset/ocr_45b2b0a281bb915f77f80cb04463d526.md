# **第一步骤：马甲公司**

沈总注册了一家马甲公司，专门用来做培训。

把保健品公司过户到小舅子名下……

太太说：“你不卖保健品啦？怎么改行做培训了呢？那我们几百万的囤货怎么办？”

沈总说：“太太啊，这就是一诺老师的课程精髓，这招叫做——明修栈道暗度陈仓！”

表面上我们是在做培训公司，但是实际上我们还是卖保健品的……

太太一头雾水的看着沈总……

沈总说：“我们跟减肥、健康、健身培训的客户都是又重叠的对不对？”

太太还是一脸茫然的看着沈总……

沈总说：“听不懂就不要问了，你直接相信我相信一诺老师的方案就行了。”

沈总太太刚想说话……

沈总说：“**相信比怀疑多一次机会，你要相信相信的力量！** ”

沈总太太后来也就没有在说什么……
