# 第五步骤：成功转型

后来王老板看准了一个 APP 的项目，在最初的时候 10 万元天使投资，最后这个项目被风投看上了，王老板在 C 轮退出，投资十万结果 1.3 亿套现出来，当然了，王老板之前投资几十个天使投资项目，都失败了！

然而王老板知道，失败是成功之母！

如果失败 100 次你就可以成功，那现在做的不是想着如何成功，而是想着每次失败都是离成功更近一步！
