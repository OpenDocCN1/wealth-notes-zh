# —— 第198天的知识笔记 ——

不久前我们讨论过一个引发大家争论的话题：鸟类是不是恐龙的后代？

说法一：鸟类和恐龙是有共同祖先的两个分支，恐龙的一支灭绝了，鸟的一支延续了下来；

说法二：鸟类不是恐龙的旁系亲属，现在的鸟是从恐龙演化而来的。

这两种争论直到今天还在iacute;持。

我们今天采用第二种说法来分析一下“为什么今天的鸟类是这样一个形态”，然后从这个分析里，我们重新看一看我们昨天的主题“为什么很多新物种出现以后，难以为继，像流星一样消失了？”

# │ 竹子：草的策略组合

如果我们承认鸟类是恐龙的直系后裔，那么自然会问这个问题：恐龙为什么演化成鸟类，而鸟类又是如何的五花八门呢？

我们暂且把这个问题搁置一下，看看另外一个物种：竹子。

竹子在中国人的生活当中扮演了非常重要角色，无论是在物质生活领域的衣食住行，还是在精神生活领域，都离不开竹子：

竹子虽然不能穿在身上，但是是很重要的家具材料，我们现在使用的竹席，就是竹子做的床上用品，类似的还有竹床、竹椅。

竹子也可以用来吃。在浙江莫干山，不仅仅是在春天，一年四季都能够吃到不同的竹笋。

从竹排到滑竿，竹子还可以用来做交通工具。

中国古代的笔也是用竹子做的，今天的“笔”这个字还是一个竹字头。

虽然竹子在我们生活当中扮演了重要的角色，但我们经常会忘记它是一个什么物种：竹子本质上是草，草本植物，它的很多特性非常像草。比如果笋破土而出时候的照片，如果没有相关参照物，你看着就像是草丛地里冒出来了，只不过比草芽大一点儿。另外，很多草都有节，竹子也有节。

![](bbox=[0.22, 0.00312, 0.95, 0.0043])

我们很少想到竹子是草，因为它的性状跟普通的草非常不一样：一方面，竹子很坚硬，同时它又很有柔韧性，最重要的是，竹子的个儿特别高，这让你根本想不到它是草来。可以说，竹子是草里出类拔萃的一个物种。

竹子的高度、坚实程度、柔韧度都跟普通的草不一样，那么，它这些性状是如何来的呢？简单说，这涉及到一个生态学的常识：一种生物的性状，本质上是一种生存策略，一个物种不过是一系列的策略包，或者说，是一个策略组合，这种策略组合表现为一个性状组合。这种性状的组合使得这个物种跟别的物种不一样，或者它跟它的祖先已经差别很大了。

# │ 纠杀榕：独特的生存策略

我们都知道“大树底下不长草”，就是因为大树把阳光遮住，使下面的草没办法获取阳光。但有一些特殊的草，为了生存下来，选择了一种独特的策略，或者战略，比如在热带雨林里一种特殊的榕树：纠杀榕。

热带雨林里光的渗透率非常低，连2%都不到，那么，当一个物种的种子落到地上，由于它吸收不了阳光，就很难长大，即便努力地长一点儿，也可能很快被消灭在萌芽状态。所以，纠杀榕采取了一种特殊的策略：

+   1. 鸟爱吃纠杀榕的种子，吃完之后，种子就随着鸟粪被撒到了一些树枝上。
2. 纠杀榕的种子就借助与鸟类发芽，一旦发芽，它不往上长，而往下长，从树枝上把根往下延续。
3. 当自上而下的根延续到地下，在地下扎根到足够深的时候，纠杀榕就能吸收土壤中的养分和水分。同时，它在树枝上也是能够吸收到阳光的一个这个时候，纠杀榕才开始发力生长。
4. 纠杀榕借助别的树获取阳光，但是只要有这棵母树在，纠杀榕就不能吸收到足够多的水分和养分——它采取缠绕在大树上生长的方式，最后把这棵母树绞死。

这就是纠杀榕的生存策略。

![](bbox=[0.22, 0.00835, 0.95, 0.010199999999999999])

竹子也 resultante的生存策略：当竹笋破土而出的时候，它面临着非常大的挑战—可能接受不了阳光。所以，在地底下，竹子的根系要非常发达，能够吸收足够多的水分和养分，才能使它以一种冲刺般的速度生长—很多竹笋一天就能够长一米多，几天之内它就蹿上去，避免了自己被消灭在萌芽状态—这就解释了为什么竹子本来是草，但是它能够长那么高的原因：特殊的生存困境逼迫竹子选择了一种生存策略。多个生存策略就是一个策略组合，而策略组合是一种性状组合，竹子也就成了我们所看到的这个样子。

成为一个新物种不难，如何在一个复杂、不可预期的、多变的环境里生存繁衍，对物种来说是一个非常大的挑战。如果你的策略组合不够优化，或者你的策略、你的性状太单一，你就很可能在横空出世之后很快消失—投资的时候讲“投资组合”，做产品的时候做“产品组合”，一个物种的生存要讲“策略组合”和“性状组合”。

# │ 龙：无关联的策略组合

一提到策略组合、性状组合，自然会想到一种特殊的动物，准确地说它不是一种真实的动物，而是一种想象的动物，那就是我们古代神话中的龙。

龙是一个很典型的性状组合：蛇的身子，马的头，鹿的角，鸡的爪子……龙恨不得把十二生肖里所有的属性都集中起来。

应该说，龙是强大的。事实上，中国古人塑造出这么一种想象的动物，就是为了在想象中创造一种全智全能、至高无上、超越所有物种、所有生物的一个霸主，具有至高无上权力的一个象征，但是，这东西在自然界中不存在。

一个物种是性状组合、策略组合，但是，它不是一个筐，不是随便把策略和性状扔到这个筐里，就是一个物种了—各个性状之间是有关联的，都是为了完成一个共同的难题，解决一个战略的困局，才形成了有机组合，而不是一个随意的组合—所以，尽管龙的外貌呈现多样性，它的功能也具有多样性，它呼风唤雨、至高无上，但它是个假的，始终是一个想象的产物。

# │ 鸟：物种延续的策略包

作为恐龙的后裔，所有的鸟都是一种策略组合和性状组合，它的整体性状和策略都是面对它各自的生态位提出的一个解决方案包，或者说，是一个策略包。

老鹰的生态位在高空，所以必须要求它的视力非常的好，这样它才能够在两千米之上看到下面一只兔子在移动；鹰的喙非常坚硬并且具有杀伤力，是带钩的，这也与它的生态位密切相关。
