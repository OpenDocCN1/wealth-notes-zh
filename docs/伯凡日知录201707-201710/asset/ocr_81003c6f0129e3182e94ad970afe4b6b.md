# 垃圾是放错位置的资源

昨天我给大家出了一个题目：别针换别墅里头的机制是什么。理论上，用一个别针之所以能够最终换到一座别墅，无非是在别针和别墅两个相差巨大的价值中间进行场景细分，让每一个场景都可以将小价值显现为大价值。

比如，你拿着一个别针，遇到一个人要打一个非常重要的电话，可是手机没电了。他想把手机卡换到另外一个手机里头，但他急需一个别针。这时候你说，我可以把这个别针卖给你，但这个别针的价格是10块钱。在普通场景里头，这个别针只值1分钱，但是在那个场景里头它就可能值10块钱。新场景导致价值的急剧升值，升值的幅度是1000倍。按照这样一个比例来计算的话，经过若干个场景以后，我们可以想象1000的N次方，这是一个很可怕的算式。这个算式足以解释别针为什么能够换到别墅。

场景切换导致价值裂变，这种现象在日常生活当中很常见。你要扔的废品很可能是别人苦苦寻找的珍品。每个人都自身体带一个应用场景，两种场景之间的巨大差异也就意味着同一个东西的价值的落差。

当然，在现实生活当中，你寻找特定场景的成本是很高的，甚至可能高到你没法操作。但是，互联网是可以迅速地实现场景的切换的。目前，我们已经看到一些借助场景差异激活价值，实现价值裂变的某些互联网产品。比如说闲鱼App，它之所以能够实现双赢、多赢是因为它借助了互联网，使得不同的场景能够在同一个平台上汇聚、相遇，从而导致价值裂变。

# 场景与个人管理

场景这个词的英文叫scenario，有一派曾经影响很大的管理学派叫 情景规划（Scenario Planning），它就是通过对于情景的设想，显现出一个公司或者一个项目、一种组织形态的不同的价值。当它设定一种新的情景、新场景的时候，一个特别重要的公司，或者一个特别有竞争力的公司一下子就变得毫无竞争力了。

我们在商业史上看到了太多这样的事情。当一个新的产业情景出现的时候，原来极具竞争力的企业突然之间完全丧失竞争力，甚至猝死，这样的案例比比皆是。所以，情景规划这样一种管理手段，它主要的操作方法就是创造性地想象一种场景，尤其是让那些固步自封、自得意满、特别自以为是的公司突然之间产生一种破产感，从而激发其变革的欲望。与此同时，它通过设计在新情景，新场景下的应对之策，来帮助企业解决问题。

其实，我们在个人管理当中也可以运用情景规划。几乎每一个人都听说过一种说法叫“忧患意识”。“忧患意识”实际上来源于《易经》。《易经》这个经典的时候，内心里头有一种叫做忧患意识的东西。《周易》说白了就是64个场景，一个人所面对的人生，无论是生活、治国、打仗，还是与人相处，各种各样的事情无非是64个场景当中的其中一个场景。普通人没有读过《周易》，面对一个事情的时候，往往都会凭本能去反应，意识不到当前的场景。张居正每天读《周易》，不是用《周易》来算卦，而是用《周易》来提醒自己，今天、昨天和明天遇到的每一件事情，都要先想这是个什么事，这是个什么场景，表面上是这样，实际上是什么样子的。

当你这样去考虑问题的时候，你就不会简单地说，现在这样做对不对，或者有没有价值。这样做有没有价值不取决于这样做本身，而是取决于这个场景。一个对的行为在一个不对的场景，它可能就是没有价值，甚至是负价值的。

《汤姆·索亚历险记》里的汤姆·索亚没学过《易经》，但是他有一种易经的意思。当他干了坏事，被姨妈恶狠狠刷箍窑墙的时候，他没有做简单的反应，而是能够看破场景，意识到一个场景背后可能存在的场景。当他发现或者重新想象了一个新场景的时候，他就能够找到相应的手段，让同样的资源产生完全不同的价值。

无论是古人的智慧还是今人的智慧，无论是《周易》还是情景规划，都是在提醒我们，没有绝对的价值，只有相对的价值。那个相对是相对于什么呢？就是相对于场景。

# 场景与创新模式

曾经看到过一个故事：一个富豪在玩游艇的时候突然接到紧急电话，他必须要马上从度假地飞回到公司所在的城市。这时候他就面临着一个问题：这个游艇怎么办？很简单的方法是花钱请代驾。有过代驾经验的同学知道，请代驾 byste是不便宜的，所以，你要请一个会驾游艇的人肯定是一笔很高的费用。你之所以会马上想到请代驾，是因为你认为这个场景是唯一的。

其实不是这样。你可以想象，有一些人他们有驾游艇的执照，也有玩游艇的时间，就是没有买游艇的钱；或者曾经有过游艇，后来被迫卖了；或者最近新交了一个女朋友，很想体验一把浪漫之旅。这样的 人是存在的。首先，你想象到了这么一个情景。

第二，你还能够找到这样的人。在通常的技术条件下，你找到这个人的成本是很高的，高到你没办法来执行。但是，借助互联网，借助于特定的场景营造手段，你是可以找到这样的人的。当你有了这个想法的时候，你的思路就从传统的经济转向了共享经济。你可以在某些特定的社区里头发布一个广告说，“现在有一个公司提供一种服务，让那些一直想玩游艇而不得的人能圆自己的游艇梦。目前业务只有A地到B地，刚刚开始这个业务，费用还是比较低的。因为，游艇数量有限，先到者先得。”这样你就找到了有专业执照，而且愿意付钱来驾驶游艇的人。对于这些人来说，你不用考虑他要耗费多少天，你要给他发多少钱工资。他的场景是在度假，而不是在工作。所以如果用这个方法，这个富豪不仅不用花钱去请代驾，还能赚一大笔钱。这就是重新想象场景，重新定义场景，让一个看似价值固化的东西产生价值裂变的一个案例。

还是那句话，创新不一定是创造一个新的东西，比创造一个新的东西更重要的是想象或再发现一种新的场景。当你从一个新角度看一个寻常的场景的时候，你就会发现它已经不再是原来的那个场景。在新的场景里会发生很多很多你想不到的价值增值和价值转换。

我记得有首古诗里有这么一句诗，“陡眼看，乾坤覆载，一幅大寿宫”。意思是说，如果你思绪是那么烦困，或者说不是那么高大上，换一个角度看，天地之间就是一幅大寿宫图，天在上，地在下，乾坤覆盖。那里头生机勃勃，五光十色。我们寻常看天地是一个平常的世界，换一个角度它就是一个全新的场景和情景。就像我们前不久说的，在春天来临的时候，乌语也好、 {@}花香也好，都 {@}一个又一个的营销蝉战，都是一个营销大系统（文末附原文链接）。
