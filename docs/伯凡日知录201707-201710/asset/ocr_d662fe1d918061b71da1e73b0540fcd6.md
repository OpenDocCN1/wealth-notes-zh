# 7.12 | 全或无定律

我一直认为，研究成功学没有什么太大的意义，至少它不太可能成为一个学科；但是研究失败，甚至建立一种失败学，却是挺有意义的事情。因为一个事情要做成，需要所有要素都具备，缺了哪一个都不能成功；而只要一个要素出问题，就足以导致失败。很多成功学的论点都犯了归因谬误的错误，研究失败不能够教你怎么去成功，但是它能够让你更清晰地知道你为什么不成功。

# 要么一切，要么没有

有一句话叫“心存怨气万事衰”，一个人什么气都可以有，但不要有怨气。为什么有怨气就万事都衰呢？我一直想到一个理论来解释这个问题。有—个定律也许跟这个问题有关，这个定律叫“全或无定律”，要么是一切，要么是什么都没有。它不是nothing和everything，它是all or none。

这个定律在很多的现象里都能够验证。比如医学里就有很多这样的例子，哈佛大学有一个教授叫鲍迪奇，他在做青蛙心脏实验的时候发现，如果对青蛙心脏施加的刺激减弱到一定的程度，青蛙的心脏是没有任何反应的；而当刺激超过一定程度时，会引起一定的收缩；但是如果再继续增大刺激的强度，并不会引起更大的收缩。

我们以前讲到过灰度，这个现象看上去有点反灰度。所谓灰度理论是强调取值范围的宽广性，而全或无定律给我们展现的是一个取值范围非常小，类似于非黑即白的一种现象。比如，我们在吃药的时候就符合全或无定律。药品说明书都会告诉你吃药的剂量，如果这个药物本身是有效的，在单位时间里达到一定的剂量就会有效，而没达到剂量就无效。医生告诉你吃五片药，你只吃了一片药，会不会达到了20%的效果呢？不会，它就是零；只有达到了五片，它才会起作用。

# 人为什么会抱怨？

现在我们说回到失败。

失败是一个结果，你发现一些失败的人他常常爱抱怨，“我付出了那么多，怎么就一直不成功？”我记得有一个很著名的失败者，就是诺基亚的末代CEO埃洛普，我见过这位仁兄，他是个职业经理人，一看就不是一个企业家。诺基亚被收购的时候，他说了一句话很有名，“我们并没有做错什么，但是我们失败了。”如果明白了全或无定律，他可能就不那么抱怨了。那些特别爱抱怨的人也不能说他们不努力，他们也做出了很多很多的努力，但是当你的努力就差那么一点点的时候，你这些努力是没有用的。

# “全或无” 的启示

你不知道成功需要哪些要素，但是你全心全意、尽可能地发挥能量的時候，你就可能在不知不觉中具备了这些要素。也就是说，当你总觉得自己不够的时候，就有可能把事情做够；而当你觉得你已经够了的时候，一定还有好多事情你是没有做的。这就是全或无定律给我们的一个启示。

吴伯凡

世界上育两种人，当面对一件事情的时候，一种人关注的是我已经做好了哪些事；另一种人关注的是，我有哪些事还没有做好。我们自己可以反省一下，我们到底是属于哪一种人。大家可以把自己的答案以及自己的反省写下来，我们一起来分享。

全或无定律——All or None Law，要么一切，要么没有。
