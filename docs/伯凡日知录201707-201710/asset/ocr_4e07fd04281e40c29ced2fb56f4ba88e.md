# 1. 服装业是金融业

第一个是关于场景的话题。场景的切换会导致商业模式的变化，同样的产品在不同的场景中所呈现的价值和意义是完全不一样的。比如说服装，从最低的层次上说，服装业是一个制造业...每一件服装其实也与媒体产业...每一个人的服装都是一个随身携带的自媒体，我们通过服装无意地在发布大量的关于我们自己的信息。但是，服装业在最高的层次上，其实是一种金融业。或者说，最高级的服装企业它从事的是一种发行货币的产业，是有话语权的央行，它生产服装，不过就是在印钞而已。

# 2. 感知黑洞

我们上周还讲到了场景是如何影响一个人的教育方式、学习方式的。本周我讲到了一个话题：在一个家庭中，父母与孩子的交流中词汇量的多少直接与孩子的大脑发育程度和学习能力相关。在一个使用词汇量很少的家庭，尤其是那些总是在使用祈使句的家庭里，孩子的自立程度、孩子的感受方式会有什么样的不同。为什么说语言的简化、词汇量的缺乏会导致我们感知方式的贫乏，甚至会造成一种感知黑洞？

# 3. “全或无” 定律

本周我还讲到了一种定律，叫 “全或无” 定律（All or None Law）。我们早就注意到，当高考分数线划定在500分的时候，考0分和考499分是一样的。这个现象里头就包含着 “全或无” 定律。“全或无” 定律在自然界、人身体和社会当中可以说是无处不在。为什么有的人总是感到怀才不遇？为什么有的人怨气冲天，觉得自己很有才，很努力，却总是没成功？这跟 “全或无” 定律有什么样的关系？大家要想象一情景：当一个密码锁的9个数字都已知的...明明已经...当一个密码锁的9个数...的时候，...还是打不开这个箱子？明白了这一点，我们也许就不会有那么多的怨气，不会感到自己怀才不遇了。

# 4. 刺猬效应

本周我还讲到了一种现象：在办公室、在团队当中会存在刺猬效应。一个好的团队里，团队成员之间一定有亲密的关系，而且是那种有张力的亲密关系，因为只有有张力的亲密关系才可能持久，才可能健康。无论是在亲子关系，还是团队成员的关系当中，都必须存在一种必要的张力，那就是掌握亲密和距离的关系。为什么说只有做到亲密有间才可能成就一个团队、一段关系？这就是我这期要说的话题。
