# | 小孩的权力游戏

昨天我们讲到在公司和家庭里都存在的一种现象：为了追求表面和谐，而采取了姑息和贿赂的方式维持，这种现象称为“姑息式和谐”或者“贿赂式和谐”。

这在儿童教育里也是一个非常大的问题。我们在教育孩子的时候，很容易堕入到一种权力的游戏当中：小孩刚出生的时候，可以说是最没有权力的人，他们对一切东西都无能为力，这时候就需要你对他进行无条件的利养输送和让步，因为你只要在某一个点上要强硬，就可能会置于死地。

# | 权力的限制

《道德经》里多次讲到绝对悭和利器是不好的。过去我不太理解，后来才意识到，这是在提醒我们，主动限制自己使用利器、使用杀手锏，或者干脆就搁置自己的杀手锏，才可能面对一个复杂的世界，以一种没有权势，或者弱势的身份去解决非常麻烦的问题。

# | 无权势者的权势

只有从一开始就有意识地限制孩子的权力，不让他陷入到那种“无权势者的权势”的困境中，他才可能开始一个新的游戏——这个新游戏名字还是“无权势者的权势”。但是，这个“无权势者的权势”意义完全不一样：当他面对一个真实世界的时候，由于他手里不拥有杀手锏，他就可以开始一个悄悄培植自己多样化能力的游戏，在他的工具箱、他的能力库里，各种各样的能力会越来越多。

# | 总结

总结一下，孩子的教育无非就是两种选择：

第一种，培养原生态的“无权势者的权势”。不少父母其实是在做这样一件事情“种瓜得瓜，种豆得豆”。当你与孩子之间进行的是这样一场权力游戏的时候，最终孩子就只能是只会玩这种游戏的人。

第二种，另一种类型的“无权势者的权力”。

第二种，另一种类型的“无权势者的权力”。这种游戏的特点是及早减掉孩子的精神脐带，及早给他 在精神上断奶，及早限制他的 各种的权力，给他设置各种权力边界，让他在某种程度上成为一个赤手空拳面对 复杂世界的人。

当他以一个无权势者的身份出现在真实世界的时候，就会逐渐培养自己的多样化能 力，让自己真正拥有靠得住的“无权势者的 权势”。

# I 现代微服私访

虽然国内现在有很多电视真人秀节目，但是有一种我很想看，可一直看不到，那就是国外电视台经常会播的一类真人秀节目——跟踪某个人，在一个特定的时段、特定场景当中展现他们不一样的那一面，让被拍的人在一个时间长河当中，集中展示他们各个阶段的状态，让我们感叹复杂嘛，领悟到很多东西。

好多年前我看过一个这样的真人秀：让一些不是特别大的公司、不是那种已经成为公众人物的老板，以一个普通人身份去自己的公司去应聘，进入到公司某一个不被关 注的部门，然后记录他们一天所做的事情，他们的状态，他们的想法。这真的是很有意思的一件事。

在这个节目里，我们看到一个老板，前一天还坐在自己的办公室里发号施令，叱咤风云，第二天就变成了一个可怜的求职者，勉勉强强通过面试，进入到了公司里，在一个很低的位置上做那些他也许几十年都没有做过的事情。

这可以说是一种现代的微服私访。过去的微服私访是皇帝，今天这些老板的微服私访效果差不了多少，至少可以达到两个目的：

目的之一：通过隐藏身份，暂时放弃自己的权力，接触到真实的世界，获得并且刷新对于真实世界的认知。

这个目的非常重要，老板们习惯了生活在一个玻璃桥子里，整天被人抬轿子，看到的好像是真实的世界，其实已经隔了一层厚厚的玻璃墙，根本接触不到真实的世界。当他们以一个普通员工的身份混到自己公司的时候，就能看到他在老板位置上根本不可能看到的种种的现实。

目的之二：通过隐藏身份，放弃自己的权力来获得并且刷新对自己真实状况的认知。

这个目的更为重要。《大西洋月刊》发表过一篇文章，讲一个个人职务不断增高，当他坐到了CEO位子的时候，有一件一直在发生，但他一直没有意识到：他获得的权力悄悄对他的大脑造成了损伤——他的大脑里有很多暗伤，他自己却一点儿都不知道。

# ｜要合作，不要博弈

作为管理者，使用“远离婚姻式和谐”这个套路合适，但作为员工，如何破这样的局？我的管理者是个非常强势又事无巨细，凡事都要管的女领导，听不进建议，还觉得她自己很聪明。

# 吴伯凡

从这个问题里能看到另外一层意思：这位同学想破解领导的局，或者说，他跟领导已形成了一种“博弈关系”——总以为对方在跟自己出什么牌。

# ｜积极的悲观主义&消极的乐观主义

分享一个我自己关于工作生活的感悟：“用不完也不够用的智慧，浇不灭也燃不起的斗志，消灭了又出现的怪兽。”我这算“消极的乐观主义”吗？

# 吴伯凡

我所定义的“消极的乐观主义”是那种相信“要是怎么怎么就好了”这样一种句式的人。我自己曾经也是这样一种人：

- 当孩子出生的时候，我想“孩子要是3岁就好了”；
- 当孩子3岁的时候，我费了老劲儿带他去找幼儿园，找到了幼儿园以后并没有“好了”，孩子天天不愿意去上幼儿园，要劝他，各种威胁利诱让他去，这时候我“幼儿园毕业就好了”；

所以我们选择一种理论，其实是选择一种心态，选择一种看待世界的取景框。

# Ⅰ 积极的悲观主义=真正的英雄主义

积极的悲观主义，会不会让别人感觉自己有点儿冷漠和消极呢？积极的悲观主义如何区别于“吃不到葡萄说葡萄酸”的偏差型认知呢？

吴伯凡

“积极的悲观主义”的底色是积极的，是乐观的，但是在阶段性的事情上是悲观的。

“吃不到葡萄说葡萄酸”不是“积极的悲观主义”，而是一种常见的自我安慰，或者说得学术一点儿，是一种“因为获得不了某种价值，而对本来追逐的价值进行的贬毁。”这种状态本质上是一种悲观的状态，因为一次偶然的吃不到而对葡萄下了一个全称判断。

我觉得罗曼·罗兰这句被引用了无数次的话，描述的就是一种“积极的悲观主义”：

> 世界上只有一种英雄主义,就是看清生活的真相之后依然热爱生活。

# | 刺猬效应与团队管理

“刺猬效应”来自于哲学家叔本华的一篇文章。他说，两个刺猬在冬天的时候为了取暖，它们就想抱在一起，但是当它们抱得太紧的时候，自己的刺就会刺伤对方。要想愉快地相处，既要取暖，又不能够抱得过于紧，这种状态叫亲密有间。这种“亲密有间”的原则就叫“刺猬效应”。

# | 文饰效应与人才管理

生活中有一种常见的现象：一个人新买了一种东西，他会向旁人不断的强调这个东西是如何的好，如何的物有所值，甚至物超所值。尽管他心里可能觉得买这个东西有点不值，但恰恰是当他心里头越觉得有点不值，或者说付出的成本越高，就越有冲动去合理化他的这个选择。这个现象有人称之为认知失调的平衡，也有人称为选择当中的文饰效应。

# | 禄赋效应与价值管理

对那些没有价值或价值很小的东西，我们常常会出现一种心理状态——当你拥有这个东西的时候，你就会高估它的价值。这就是禀赋效应。

# | 飞轮效应与企业战略

“飞轮效应”的概念最早是著名管理专家和畅销书作家吉姆·柯林斯（Jim Collins）提出的，大家都很熟悉的《基业长青》和《从优秀到卓越》就是他的著作。

1. 无限。要给用户无限的选择。
2. 顶级体验。
3. 最低的价格。

# | 挤出效应与激励

有一派的经济学理论把人的行为动机分成四种：物质利益、情感需求、社交动机和道德承诺。人做出一个行为可能是出于这四种动机当中的一种或者几种。如果你要激励人的某一种行为，这种行为本身应该是由于道德承诺驱动的，但是你的激励方式是物质利益，那么结果很可能会适得其反。

献血为辅，而英国是倒过来的。这就是说，用钱买来的血液其质量反而比不用钱得到的血液质量要低。

因为献血的人由于他不是追求物质回报，他在献血的时候，他的献血行为是出于一种道德承诺，他觉得他在履行一个公民的责任，同时这里头包含着一种情感的需求。而在美国的血液供应系统当中由于他过分地强调了物质的回报，所以向他们提供血液的人觉得这就是一桩买卖而已，一方面他要获取相应的经济利益，同时他对自己血液的质量以及可能引发的恶果他是不太关心的。

对应到企业的激励上，如果企业发布一个措施，谁在周末来加班就给谁发多少钱，也许加班的人会增加，但是真正原来自动加班的人也许他就不会来加班了，或者说现在来加班的很多人，他实际上是为了来挣这个加班费的。老板就不知不觉地把员工的行为动机从道德承诺或者是情感需求和社交动机上，全部切换到物质利益的这个频道上，对公司是很不利的。

# Ⅰ lollapalooza效应与策略

巴菲特的老搭档查理·芒格提出过一个很拗口的一个概念：lollapalooza效应。

简单的说就是：两个、三个，四个……多个作用于同一方向的力量汇聚在一起后，所形成力量不是简单的力量叠加，而是一种巨大的、协同的放大效应。或者说，是多个动向因素的叠加，导致了一个算法从加法变成乘法的跳跃。lollapalooza效应有很多种解释说法，有人把它叫做“好上加好效应”，也有的人把它叫做“核爆效应”，总而言之，就是多要素聚集产生的爆炸性的放大效应。

亚马逊看似不求回报的经营行为，不知不觉在核心业务之外出人意料的形成了三种支柱性业务，云服务+强大的物流体系+越来越好的用户体验，就导致了一种好上加好的效应。

意大利有一个叫马基雅维利的权谋家，他就提出过一条权谋之术，说：当你和你的君主(上司)汇报好消息的时候，一定不要一股脑的告诉他，要一个一个的告诉他，今天告诉一个，后天告诉一个，过几天再告诉他一个，这样，这三个好消息汇聚起来，就会让你上司的心情产生一种核爆效应，他会爽到歪；但你要汇报坏消息的时候，千万不能那样，你要把这几个坏消息合在一起一股脑告诉他，避免了坏消息的核爆效应。

# Ⅰ 全或无定律与成功

“全或无定律”的意思是：要么是一切，要么是什么都没有，all or none。比如高考，分数线是500分，你要么过了，要么没过。如果没达到500分，考499分和考0分的结果是一样的，都是没过。

就好像我们打开一个密码箱的时候，假如这个密码有五个数字，四个数字我们都知道了，只有一个不知道，我们是打不开这个箱子的。不会因为你做对了80%，这个箱子会打开80%。你要关注的是哪个做错了，而不是我哪个做对了。这就是一个全或无定律。

生活中有很多人会抱怨自己怀才不遇，做了很多都不成功，就是因为对全或无定律没有清晰的认识。明白了全或无定律以后，我们身上的怨气就会减少很多，它让我们关注我们哪儿做得不够，而不是我已经做了很多很多。做了很多永远是不够的。

# Ⅰ 沃尔夫定律与学习

这个定律本来是一个关于骨骼成长的定律，意思是说，人体的骨骼如果长时间承受外部的压力，骨头的密度和坚硬程度会增加。

但是这个道理放在学习上也同样适用，他们在本质上都是一个反脆弱的过程。当你不断地挑战自己已有的知识网络，不断寻求危机感，然后再把发现的知识漏洞补上的时候，你的学习能力也会越来越强。

# ｜“新种族”

最近总有人问我对马东和许知远的对谈怎么看，我的兴趣不是他们之间对谈的内容，而是他们的对谈让我想到一个问题：在互联网时代诞生的一种种之为“新种族”的东西。

“种族”本来是自然划分的，不同肤色、不同人种形成了最初的种族。有了种族，也就有了种族主义。“种族主义”是唯种族论，或者说，是对一个种族的特性进行武断的概括、议论等。

我们今天发现，互联网导致了一种不按自然特性划分的种族：从理论上说，有了互联网，一个人可以跟世界上任何一个人交流，但实际的结果并不是天下大同，而是每一个人都能更容易地找到自己的同类。聚集的成本变得异常低，导致了一个又一个的网络族群，或者叫网络部落，动漫、二次元世界的形成就是跟这个有关。

每一个种族或者每一个网络族群都会形成自己的价值观，自己的文化属性。最重要的是，他们对自己的价值观形成了一种坚定的信念和捍卫的冲动，一旦有人触碰这个最关键、最核心，同时也可能是最柔软的价值底线的时候，就引发强烈的反弹，甚至出现剧烈的冲突。

# ｜“特权瞬间”

在社交场合，我们总是能见到不遗余力地向对方索要名片、索要微信的人，然后在另外的社交场合，这些人拿出手机，把这些联系方式向其他人炫耀——在这一方面乐此不疲的人，往往遭遇的是效果甚微。原因跟一个概念有关，我把它称之为“社交力矩”，或者“社交力臂”。

什么意思呢？就是你能够联系多少人、能够接触多少人并不重要，重要的是你能撼动多少人，能让多少人主动和你建立一种有效合作的关系。

# ｜“滚雪球机制”

面对星座大师、算命大师的时候，我们常常感叹“说得太对了，我就是这样的！”——本周的第三天，我们就来谈谈这些星座、算命背后存在的一个我们可能都没有意识到的机制：正向检验策略。

# ｜“单一目标之和=怪胎？”

我们在设定目标，或者在许愿的时候，常常有一种我们没有意识到的机制：凸显单一目标，而把这个目标的背景大大虚化，以至于我们的整个行为都受到这个目标的操纵。

这几天几乎在任何一个社交场合，我都会被问到一个问题：对许知远和马东之间的争论怎么看？

听说是指许知远和马东一起发生的事情，我大致就知道他们会聊什么，以及会聊出一个什么样的结果，但是我没有想到一点的是，它居然引起了这么大的反响。

他们之间的这场争论都算不上是争论，在我看来就是一次交谈，但最后却变成一个标志性事件，而且还引发了轩然大波——今天我不对这个事件具体内容说什么，而是和大家分享一个新概念——新“种族”主义。

# ｜新“种族”主义

“种族”最初的决定性因素是自然原因，简单地说，就是肤色——不同的肤色决定了不同的种族。后来，又加入了许多的文化因素。文化和自然的因素交织起来就形成了一个个种族。

地球上本来有很多部落，当这些部落处在“鸡犬之声相闻，老死不相往来”的阶段，就不存在太明显的种族问题，只有当各个种族相遇的机会越来越多的时候，种族问题才成为一个问题。

今天，随着互联网越来越成为我们生活的基础设施，“种族问题”这个古老的问题就又凸显了出来，出现了一种不是基于自然因素，而更主要基于文化因素的新社会现象：新“种族”主义。

# ｜种族中心主义

美国社会学家威廉·萨姆勒曾经提出一个概念叫“种族中心主义（Ethnocentrism）”：每一个族群都认为自身的族群是万物的中心，而其他的族群都附属于它。

这种“以自己所在的群体作为中心”的现象并不只是在种族问题上才发生，很多问题上也都有表现。

一个特别明显的例子就是世界地图：当我们收集完各个国家的世界地图的时候，就有点儿明白什么叫“种族中心主义”了。比如，找一张苏联的世界地图，它跟俄罗斯的世界地图就是不一样的——每一个团体，每一个集体，每一个族群的人都会自然地把自己作为一个中心视角来看待其他的族群，其他的人种。这种思维方式悄悄成为一种我们天天在使用的视角，但我们不认为我们的视角只是众多视角中的一个，而认为这就是本来该有的，全人类都应该遵循的视角——这就是“种族中心主义”的谬误。

我以前讲过一个概念“再部落化”，媒体使得由一个个部落组成的世界逐渐丧失了各个部落之间的特性：

最初的趋势里，大家看同样的电视、同样的报纸，读同样的书籍，好像生活在一个大同的世界里，但这只是互联网给人的一个印象，而且是一个幻觉。

随着互联网越来越发达，从理论上说，地球上的每个人都可以跟地球上的另外一个人进行互联互通，但事实是上，我们总是“物以类聚，人以群分”，发达的互联互通技术让我们越来越容易找到自己的同类。

# ｜种族分歧背后的价值体系

种族与种族之间的分歧不是一个可以用理性、学术的方法来讨论的问题，它是建立在价值观的最底层，是最基础、最不能触碰的那些东西。这些东西按常理来说，应该不重要，但是当笼罩在一个小事件、小事物之上的是一个巨大价值体系的时候，你触碰到这个东西，也就触碰到了一个你没有意识到的巨大价值体系，麻烦也就来了。

# ｜避免种族和种族之间的争论

我今天讲这些东西是想提醒大家：在我们这样一个“再部落化”时代，或者说，在一种新的“种族”中心主义时代，我们交往的时候一定要注意哪些问题是可以探讨的，哪些问题不仅不能探讨，而且提都不要提。
