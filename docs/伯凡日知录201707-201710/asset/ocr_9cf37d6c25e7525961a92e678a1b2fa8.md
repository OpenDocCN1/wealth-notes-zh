# 第一类：

很多的研发“智能汽车”的公司都是这样在做的：集中了大量的人力、物力研究智能汽车，进行“以我为主”的研发。

比如有一家公司，每天通过几十辆车在路上跑来收集各种数据，获得尽可能多的场景，当数据足够多的时候，就会产生一种“智能”——这个“智能”的核心是数据量——老中医和年轻中医的差别就是数据量的差别，汽车也是——你的汽车是否有足够的智能，取决于你是否获得了足够大量的数据。

# 第二类：

特斯拉。

特斯拉表面是一家汽车公司，但在“智能汽车”这个领域，它越来越是一个大数据公司：特斯拉的研发部门不是用每天多少辆车在路上跑来收集数据，而是每卖出一辆车，就意味着它的数据库的数据会增加。每天、每月、每年都有新增的汽车在为特斯拉的数据库增加数据。“智能”就存在于这些数据当中。

现在，在“智能汽车”这个领域里，谁在智能上更具有优势，一下子就清楚了：特斯拉和所有其他智能车。

总结一下，今天，“智能手机”的竞争已经处于“前一个竞争的尾声”，同时也是“下一个竞争的序曲”。这个行业已经在孕育“新物种”——谁能够在这个新物种的产生过程中扮演关键的角色，谁就是下一轮的苹果。
