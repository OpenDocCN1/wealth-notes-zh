# —— 第186天的知识笔记 ——

前些日子我去外地讲一次小课，人不多，也就是几十个人，基本上都是创业者，而且差不多都是比较成功的创业者，尽管其中成功的程度很不一样。

我发现这里面的两类人，是创业大潮当中一直存在的很不一样的两类人：

创业家。这类人因为创业本身而获得了某种利益、某种名声，以至于所做的事情好像都不过太重要了，他们自己获得了名声，成为名家了。他的企业可能做的并不怎么样，或者可能已经濒临倒闭了，但创业家们成名了。

创业者。这类人已经成为了通常意义上的企业家，他们的企业名气很大，但这类人我们连他们的名字，姓什么叫什么不知道，或者记不住。

特别有意思的是，互动的时候，我发现了一个现象：你从提问的方式里，差不多就能判断提问者的企业做到怎么样的成色，也就是说，问题的品质跟企业的品质非常的对应。

我发现有一个同学提了好几次问题，每一次的问题都提的很深入的，他是在认真听了课程以后，有真困惑、真焦虑、真问题的那样一种提问。这个同学提问的目的很简单，就是如何能解答我的困惑，如何对我真正有用。

还有一类提问者不是这样，他提的问题是为了提问本身，包含着一种明显的挑战性，而且这些问题几乎跟他做企业毫无关系。比如说，他会提一个你在讲案例时的某个小细节，他会说“我听说的细节不是这样的”，或者“我对于这个问题看法不是这样的”——他的提问当中包含着一个“压倒你”的明显诉求，通过反驳你，获得某种胜利感和成就感。

# ｜“语欲胜人症”

这种现象古人给取过一个名字，叫“语欲胜人症”，意思是“说话的时候有一种特别强烈的诉求，总想胜过别人”。

罗辑思维微信公众号上转载过我写的一篇文章《雄辩症》。【雄辩症】的特点就是特别爱提问，但提问不是为了解决问题，而是要证明你的错误。

我们模拟一个雄辩症患者到诊所的场景：

+   医生：你好。
患者：好什么好，我要是好，就不会到你这里来。
医生：好，你请坐。
患者：你不能剥夺我站的权利。
医生：你有什么病？
患者：你只能说我的哪个器官有什么病，你不能说我这个人有什么病。
医生：今天的天气不错。
患者：你只能说我们这个地方的天气不错，南极和北极的天气我想一定不会好。

通过这场对话，医生一下子就能明白这位雄辩症患者得什么病了。当然，这是一个很极端的例子，但我们生活当中时不时都会发现这种病的迹象，在某些人、甚至在我们自己身上都能发现这种苗头。

如果病情不重还不是问题，如果病情很重，就会对我们产生很大的伤害：你这样做会对别人造成很多的不快，但别人可能仅仅认为你是不 Its 会聊天——本来是想好好跟你聊聊天、寒暄寒暄，结果却让人不断碰壁，感觉很不舒服——这其实是一个很小的问题，关键是对你自己的伤害。

为什么这么说呢？简单的说，这种对自己的伤害可以概括为：

你不断寻求无关紧要事情上的荣耀感、成就感，并且被这种快感所绑架，逐渐形成对这种快感的成瘾性依赖，你的人生将成为一场特别荒诞的奋斗——不断寻找各种各样的 小战绩，在这些小战绩上不断寻求虚幻的胜利感和成就感，最终，你逐渐远离，甚至完全遗忘真正的成就和荣耀。

# ｜输家的精神毒品

华为的一个著名理论是：一定不要把那些战略性资源消耗在非战略性节点上。

他们寻求的是建设性，在跟别人沟通、甚至争论的过程中始终 grip住一点：我要的是什么，我要解决的问题是什么。华为人始终不忘这个初衷，将自己的思维和行动聚焦在怎么解决自己的问题，而不是汲汲于小成，在无关紧要的事情上逞口舌之利。

人生其实就是一个选择的问题，你选择了这种快感，就拒绝了另外一种快感，每一种选择都是有机会成本的。

赢家和输家的差别在于，前者选择了一种恰当的能量管理方式，将自己有限的能量用在了真正有价值和意义的事情上，而后者选择了一种自嗨自乐、自鸣得意、自己觉得很有意思，别人觉得很无趣的奋斗方式。这在某种程度上是一种精神毒品，时间久了，就会对此种虚幻的快感有一种挥之不去的欲望——越是不断努力向自己证明自己是一个永远的赢家，在别人眼里，越是一个永远的输家。

我为了验证我的判断，课后向在场的同学了解了一下这些提问的人，他们所做的企业，以及企业的业绩。有意思的是，了解的结果证明了我的预感：问题的品质跟他们企业的品质是一一对应的。

“语欲胜人症”在不严重的时候只是一个小毛病，有时候也能够带来某种愉快。但我们不能沉溺其中。小胜怡情，大胜伤身，樽樽灰飞烟灭，我们千万不要给自己悄悄注射这种精神毒品。

我曾经讲过稠盛和夫推崇的人才等级的标准：

+   三等资质，聒噪才辩；
二等资质，矜落豪雄；
一等资质，深沉厚重。

三等资质的人是很容易发现的，他们聒噪才辩，才华都是在面上的。他们有特长，但不堪大用，可以把他们放在一些特定的岗位上——有些人最容易犯的错就是把这样的人放在特别重要的位置上，因为他们很容易被发现，很容易表现自己，而越高品质的人才，越可能在这个方面有缺陷，显得不那么聒噪才辩，比如最高等级“深层厚重”的人，这样的人才之所以难得，是因为总量本身就少，以及这类人特别不善于表现自己，而只有把这样的人放在最重要的位置上，你的企业才是靠谱的。
