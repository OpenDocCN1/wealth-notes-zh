# I 批评家人格

我们总能听说一些关于员工，尤其是新来的员工对公司战略指手画脚的段子，大多数时候我们都当做是茶余饭后的谈资，但是，大家想过没有：这些我们暂且称为“批评家”的、爱指手画脚的人，他们的特点是什么？他们最适合做什么？一家公司里到底需不需要批评家？

如果是婚姻关系里出现了批评家，或者爱评论的人，那会是什么结果？下周第一天的内容，我们就来谈谈批评家的特点以及批评家和公司、婚姻的关系。

# I 随机应变的智慧

想象一个场景：约翰逊议员提了一个提案，结果新闻媒体对他的这个提案按住不放。有一天早上上班的时候，约翰逊议员发现办公室门口聚着一些人，是几个记者想冲进去当面质问他——遇到这种情况，你会怎么办？惟一防断更微信：696250

一般来说，如果是一个出身很高，习惯于居高临下处理问题的人，他会立即叫来更多的保安把这几个记者拎出去；还有一种方式就是上前说“我就是约翰逊，你们有什么事情找我”，然后利用桌面下的交易把这个事情给平了。但是，约翰逊以他特殊的方式把这些人治得服服贴贴，效果还非常好。

约翰逊的这种处事方法被称为“约翰逊疗法”——能够将一个特别难处理的场景以特有的方式迅速化解——有人形容这种方法是“面对一群扑过来的疯狗时，能在最后一秒让这些疯狗摇尾乞怜”。

约翰逊是怎么做的呢？下周我们会仔细分析约翰逊疗法背后的机智和 Wy 励是什么。

# I 非暴力沟通

2015年是美国的电影小年，但这一年有一部相当不错的电影，叫《塞尔玛（Selma）》。其中有一个镜头：马丁·路德·金带着民权运动的人从塞尔玛徒步向蒙哥马利城进发，其中还包括不少自世界各地的声援者。马上要到达蒙哥马利的时候，马丁·路德·金一行人看见骑着马的警察排成一排在前方大桥等着他们，空气在那一刻都好像凝固了，谁也不知道将会发生什么样的事情。这时候，一个戏剧性的场面出现——警察突然掉转马头朝大桥的方向走回去。带着几分恐惧、几分兴奋、更多是愤怒的游行人群一下子骚动起来。在他们觉得敌人被他们的声势吓住了，想要乘胜前进、不达目的誓不罢休的时候，马丁·路德·金跪了下来，开始祷告，感谢他的上帝，然后静静地站起来，朝着塞尔玛的方向走了回去。周围的人群先是觉得不解，渐渐就有人跟着马丁·路德·金往回走，最后，整个队伍都往回走了。

我们都知道，这是一种【非暴力不合作】。那么，非暴力在我们的沟通中会起到什么样的巨大作用呢？下周你就会听到。

# I 扫除力

垃圾在我们的印象里就是脏的、乱的，但是，我在之前的专栏里说过，垃圾其实是“一种放错位置的资源”。面对垃圾，我们不应该只是一味厌恶，更应该思考一下：垃圾意味着什么？

我们在生产价值的时候是不是一定会产生负价值？面对这些负价值的时候，我们应该做些什么，或者具备什么样的扫除力，才能尽量保证生活的价值属性呢？

物质生活每时每刻都在产生垃圾，精神世界也会产生各种各样我们没有意识到的垃圾。既然我们的认知活动和精神活动都会产生很多垃圾，那么，我们需要怎样的扫除力来让自己的精神生态和精神环境，以及自己的整个精神状态始终保持一种有序性呢？我们下周就仔细感受一下什么叫做“扫除力”。
