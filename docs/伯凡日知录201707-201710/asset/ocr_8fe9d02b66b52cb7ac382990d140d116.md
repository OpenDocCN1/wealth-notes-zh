# 7.3 | 场景转换与价值变异

—— 第153天的知识笔记 ——

最近几个月，我在各种场合都会听到一个非常高频使用的词，叫做 场景。不同的人对这个词的理解很不一样，有时候我会很唐突地问“场景”的人：“你们说的这个场景到底是什么意思？在英文原文中到底是哪个词？”后来我发现，大家往往分歧非常大，有人碰到这个问题的时候甚至有点茫然无知。

最近经过一些思考，我觉得这个词的确确是一个非常重要的概念。互联网今天产生的能量在很大程度上还只是在交易层面的——减少了交易成本，减少了交易中的摩擦，减少了供需之间的信息不对称，所以提高了交易效率。但是，除了在交易领域，它在生产领域对于效率、效果的提高也有非常大的作用。但这往往被我们忽略了。

我们以前讲到过西方拼音文字的起源，最早是埃及人发明了象形文字。象形文字是一种使用频率很低，书写起来也非常没有效率，又不利于传播的一种文字。但是，这种文字对于它的功能来说是足够的，它主要是用在神庙上，在一些宗教的仪式上头刻这样的文字。而当这种文字在传播的过程中进入到另外一个场景时，不知不觉就发生了变异。

当埃及的象形文字传到腓尼基的时候，作为以贸易为生的腓尼基人，他们要经常记账，这种不便于书写的文字就不能够满足他们的需要。所以，他们就对这种文字进行了改造，使它朝着一个易于书写、容易创造新词汇、构成要素简单的一种文字发展。当沿着这个方向走的时候，象形文字就变成了拼音文字。

# 吴伯凡

某个场景下没有价值的东西，换一个场景，就可能会产生巨大的价值变异。

充分的互联互通可以让本来价值固定的东西产生价值变异，这就是互联网的一个重要功能。
