7.24 | 拥抱麻烦

# —— 第165天的知识笔记 ——

我们讲“前摄行为”“场景创新”的时候，都包含一个概念：麻烦。所谓前摄行为，就是在意料不到的情况下，如何采取超常的主动性，以一种新的游戏规则改变整个场景。

# 科学管理=标准化

以前的管理学是生产管理学。泰勒的《科学管理》就是一种生产管理方式。比如一个翻砂工用什么样的姿势拿铁锹，铁锹上东西的重量应该是多少，用哪只手最顺手，当铁砂变成一般砂子时，铁锹的面积就应该是2.5磅，只有在2.5磅的情况下，这个翻砂工的劳动效率是最高的。泰勒的管理也叫“科学管理”。

科学管理直接推导的概念，就是标准化。后来福特的生产方式就是泰勒的延伸。

# 管理是对意外的管理

标准化是，当意外出现的时候，把突发性意外消除，再回归到正常流程。后来出现的管理领域要面对一个新的状况，当意外出现的时候，我们如何管理意外，或者说管理本身就是对意外的管理。意外不再是意外，意外是常态，常态反而是偶然。

意外意味着麻烦，当麻烦出现的时候，通常，本能的尝试方式有两个：1.消除意外；2.顺从意外。今天跟大家分享的，是在这两种方式之外的另外一种方式，这种方式已经逐渐的成为了管理的常态。

# │ 例子1： “意外” 成为美国三大旅游景点之一的渔人码头

美国旧金山的渔人码头，现在是一个美食购物的天堂。除了可以吃（根本不是那里产的）帝王蟹，还可以在那里吃饭、购物、欣赏海景，以及，看海狮。在旧金山渔人码头看海狮是一个必要的项目，你可以任性地在这个繁华的地方看憨态可掬睡大觉的海狮偶尔动一动。

但是，作为美国三大景点之一的渔人码头，出现的时间不到30年。1989年，旧金山发生了造成几百人死亡的6.9级大地震。当地震发生时，渔人码头还只是一个一个装卸木材的普通码头。地震发生以后，不知道是什么原因，码头附近出现了很多鲱鱼，并引来了以鲱鱼为主食的海狮。一夜之间，渔人码头周围出现了很多的海狮。

码头修好准备恢复正常运营的时候，管理者遇到一个大问题：到处都是海狮，货船进不来。怎么样既不伤害海狮，又能恢复码头的运营呢？有一个人就做了一个非常重要的决定，他说：“顺其自然，同时要有作为。”

海狮的特性是很爱晒太阳，他们就利用这点，在码头周围放了一些固定的木排，吸引海狮爬上木排晒太阳，所以，就引来了人们的围观。

随着海狮越来越多，看海狮的人也越来越多，有人就看到了机会，在旁边投资建了海狮馆，介绍海狮的特点，吸引中小学来参观的同时，也有很多成年人一边看海狮，一边了解海狮的各种姿势。

围观的人越来越多，就要解决他们吃饭的问题。码头附近的餐厅就出现了。而有了吃饭的地方，一定会有购物的地方，所以一家接一家的商店就出现了。

现在，当你来到渔人码头，就可以看到享受看海狮，吃海鲜，购物的一条龙服务了。

在这个例子里，不是 sembrano泰勒式线性思维去排除这个意外，恢复到所谓的常态，而是顺应这种意外，敏锐感受到一个麻烦引发的一个机会链条，所以，一种新的商业模式，一种新的业态就出现了。

现在渔人码头创造的价值，比装卸木头的码头创造的价值不知道要高多少倍，这就是拥抱麻烦，顺应麻烦的一个结果。

# │ 例子2： “吃亏是占便宜的开始。”

另外一个例子是稻盛和夫。稻盛和夫创立了2家世界财富五百强公司，救活了一家世界五百强公司。他在有生之年就看到了自己创立的第一家公司“京瓷”成为了世界财富五百强。

我们今天说的是他还创立的另外一家世界财富五百强公司，日本第二电电公司，简称KDDI。

上个世纪八十年代初，稻盛和夫看到了电信的机会，创立了这家公司。应该说这是一个已经相当成熟，有垄断巨头横亘其中的产业，日本的Docomo国营电信公司已经占据了很多的优势。稻盛和夫进到这个行业来的时候，最好的资源根本拿不到。

当时的通信几乎全部就是固定电话。经营固定电话，必须要占据人口密集的大城市，这样电信网络的利用率就最高，销售业绩才越好。但是，稻盛和夫的公司没有机会拿到这样好的资源，只能得到一些小城市，甚至是农村。这就意味着基础设施的成本会很高，当你把电话线牵到一个村庄的时候，你可能要为仅有几十人的用户付出很高的成本。这种情况下，KDDI的经营非常惨淡。

但是，稻盛和夫相信一个道德信条，也是一种商业信条，就是“吃亏很可能就是占便宜的开始，麻烦就是机会。”

他在考虑如何在小城市和乡村做电信运营，如何节约成本的时候，得出了一个结论：只有用无线而不是有线的方式才可能节约成本。一个基站可能覆盖很大一片范围，而牵电话线的成本就会很大。

在Docomo如日中天运营固定电话，无暇去考虑别的业务思路的时候，稻盛和夫开始进入无线通信行业。他用了差不多十年的时间，对无线电话的技术以及运营手段有了充分的了解。

这个时候，电信发生了一个反转，无线电话逐渐成为主流，固话被逐渐边缘化。当Docomo公司开始想着如何启动业务转型的时候，KDDI已经做好了各种的准备，占据了无线通信的先机，获得了爆发式增长。

当意外和麻烦出现的时候，我们首先要抑制自己的思维惯性，抑制自己本能情绪反应，要有一种延迟判断的习惯。在处于被动的情况下，找到一张还没有出现一个机会底牌，你就很可能出现局面的反转。

今天的“管理”，已经转化成管理意外，管理麻烦，或者说如何把意外和麻烦作为常态去拥抱变化，在意外和麻烦当中实现自己的炼金术。
