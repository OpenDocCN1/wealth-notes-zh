本周《伯凡·日知录》的话题是几个相通的关键词：由麻烦而导致的慌乱、迷惘、诡异。我们会通过一系列案例和管理学上的一些概念分享：麻烦对我们有多么重要，混沌和无序在我们的生活当中扮演着举足轻重的作用。

# “久利之事勿为，众争之地勿往。”

曾国藩这句话的意思是，如果你一直在做一件从中获利的事情，就不要再做了，如果一大群人都冲着一个特别好的机会跑过去，你不要跟着跑。

无论在投资领域还是管理一家公司，或者经营我们自己的个人生活的时候，都应该记住这条法则。

人生就像心电图，一帆风顺的时候你也就挂了。

# 灾变导致进化

常识和本能让我们规避、逃避麻烦和混沌，但是当你在逃避的时候，机会、活力也不知不觉离你远去。这不是成功学的说教，我们从很多商业案例里都能很多商业上的突破，很多创新性产品的出现都是因为麻烦和混乱而触发的一种基因突变。

如果我们以一种开放的心胸去拥抱麻烦，我们可能从一个麻烦点发现一个机会链：

旧金山的渔人码头是如何从一个装卸木材的码头成为美国三大旅游景点之一的？稻盛和夫的第二电电公司，以及北极星的沙地摩托车，这些公司、产品是如何能够横空出世的？

一种类似于灾变的东西，导致他们进化成一种新的物种。

# 老教授的书桌

我们在生活中总有一种追求条理、有序、顺利的习惯和冲动。但真实的生活和生命状态，恰恰是一种结构化的混沌。有点儿像一个老教授的书桌，看上去很乱，但混乱中存在着一种隐秘的次序和关联。当清洁女工收拾完桌子的时候，一种井井有条的局面出现了，随之出现反而是一种让我们抓狂的有序和清晰。

本周的话题包括【拥抱麻烦】【第三选择】【真正的生态是如何形成的】【我们为什么要追求结构性混沌】。欢迎大家收听。
