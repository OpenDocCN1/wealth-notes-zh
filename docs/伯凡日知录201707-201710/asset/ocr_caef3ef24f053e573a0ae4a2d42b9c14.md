# —— 第187天的知识笔记 ——

我们前天讲到了【框架效应】，这是专家们在研究运气和成功关系时都爱提到的一个理论。

最近我在读《成功与运气》这本书，老实说，这本书的标题译的不是太好，应该译成《成功与幸运》——因为运气有好运气和坏运气。

我给大家讲过【幸】这个词，所谓【幸】就是得到了你本得不到的东西，或者逃开了你本来逃不过的灾难。不该你得，你得到了。比如过去被皇帝宠幸，是你在众多的同类当中胜出了，而这种胜出不是由你的努力决定的，它是一种飞来横福。还有我们说“侥幸如何如何”，侥幸逃脱等等。

成功本身就是一种幸运。所谓奋斗，所谓创业，能在失败的弥天大网之下侥幸逃脱就是成功。失败是具有必然性的，成功是具有偶然性的。如果我们用这种心来看成功的话，遇到挫折时的心态就会好得多。

# ｜“爱吹牛”的任正非

“幸运”和“幸运感”对于成功的确有很大的作用。前几天我又听到一个朋友在华为的故事，这个故事很多人早就听过：

华为的创始人任正非先生有个“缺点”——“爱吹牛”。他怎么爱吹牛呢？一度他们公司工资只有800块，每个月还要有600块强制入股，只发200块钱。被强制入股的人后来觉得特别幸运，而把那600块要回去的人觉得特别倒霉。

# ｜相信了才能看见

相信和相信是不一样的。世界上现有两种相信的方式，一种是【看见了相信】，一种是【相信了看见】。

# ｜意料之中的出乎意料

大家会问：赢家组和输家组最后都没有看见那根针，为什么说因为相信才看见呢？

讲一个故事大家就明白了：
一个财主有四个非常懒的儿子，他临死时对四个儿子说“我没有给你们留下什么，有一批珍宝埋在咱家田里，你们把它刨出来就够用一辈子了，不种田也可以。”这四个好吃懒做的儿子听了，突然来了精神，因为他们相信珍宝就在自家的地里，于是非常仔细，一点儿不打折扣的以地毯式搜索的方式在田里寻找珍宝，当然，最后还是没找到。但是，既然地都已经全部翻了—遍，那就撒点儿种子……这一年迎来了大丰收。四个懒儿子后来才明白，老爸说的珍宝原来是这个啊！

# ｜幸运的发生机制

有一句很流行的話——你现在的所有努力和成功，都是为了兑现年轻时候吹过的牛。

吴伯凡
