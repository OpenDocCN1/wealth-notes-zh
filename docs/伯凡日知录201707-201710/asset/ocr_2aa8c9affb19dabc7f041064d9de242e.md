# —— 第197天的知识笔记 ——

“新物种”应该说是2017年的一个热词，尽管它的含义不是太清晰，但大家仍会在各个不同的场合<|start|>谈论。

让大家特别愿意谈论“新物种”这个话题的原因，是这一两年来，我们突然感受到很多新玩意儿出来了——人类类近几十年来创造了很多新的东西，但这一两年出现的新东西似乎以前有了明显的不同，比如比特币、无人驾驶汽车、共享单车……几乎每一年都会突然<|start|>出一些来搅局的新产品和商业模式。

有句广告词说得很贴切“它们一出生就风华正茂”——以前的繁荣，在繁荣之前都会有一个比较长的酝酿期，但这两ዚህ年出现的新东西往往出乎我们的意料之外：去年还没听说，今年就闹得轰轰烈烈。当然，衰败起来也是如此。比如共享单车，我们现在在大街小巷、护城河里，甚至马路中间，都能看见车的残骸，这种随处可见的衰败之象就是突然之间大繁荣的一个必然结果。

说到这里，我们就自然会问：到底什么是“新物种”？为什么这几年一下子冒出这么多“新物种”？为什么大家都爱说自己的产品和商业模式是“新物种”？

# ｜寒武纪的启示

今天我们所感受到的“新物种”的爆发，自然让我们想到了科学的十大难题之一：寒武纪的生命大爆发。应该说，这至今还是一个谜。

# 1.大氧化事件

地球的年龄大约是45亿～46亿年。当地球出现了之后，有差不多21亿～22亿年是一片死寂状态，完全没有生命。后来，突然出现了某种异动：大氧化事件。

地球刚诞生的时候不停地在制造各种自然污染，各种二氧化。由于火山爆发等地质运动，导致整个地球表面充满各种有毒有害的污染气体，完全不利于生命的生长。但是在24亿年前，突然出现了“大氧化事件”。

+   24亿年前：
地球的大气中出现了氧气，氧气的含量相当于我们今天空气中氧含量的0.1%。在2亿～3亿年的时间里，这个数字从0.1%上升到了1%。

21亿年前～6亿年前：
氧气的浓度基本处于停滞的状态，也就是保持在相当于今天空气中氧含量的1%这样一个状态。

五六亿年前：
氧气浓度突然增加。这是我们今天最新的对于寒武纪生命大爆发原因的一个解释——之所以出现生命大爆发，是因为氧气含量出现了激增，增加到跟我们今天的空气中氧含量差不多的时候，生命就开始爆发了。

地球长期处于无生命的状态，或者说，只存在种类和数量都很少的生命这样一种状态，突然变成了各种生命形态的大爆发，原因很简单：约束条件消失了。

氧气是生命的一个关键约束条件，一旦这个约束条件发生变化，氧气含量增加了接近100倍的时候，生命就开始了大爆发。

# 2.约束条件的消失

商业世界里出现各种各样的“新物种”，和过去商业受到的那些在我们看来是天经地义的约束条件的消失和削弱有直接的关系。空间的限制、时间的限制、数字技术的出现，导致了很多约束条件的突然之间消失，就出现了我们今天看到的商业新物种的爆发，可以说是各类茧盛开。

但是，我们必须要注意到，虽然寒武纪生命大爆发产生了许多生命形态，但生命大爆发之后，又出现了一个灭绝大潮。原因很简单：氧含量作为一个关键的约束条件消失和大大减弱的时候，生命的孕育成长就获得了一个巨大的空间，导致各种形态的生命出现，但能否在这样一个充满各种物种的世界里活下来，又是另外一回事了——如果只有你一个物种，你是能活下来的，但还有无数物种跟你一样生活在这个世界的时候，一个物种要面对的是一个极其复杂的生态，能否延续下来就成了很大的疑问。

所以，很多新物种在生命大爆发之后不久都消失了——我今天商业世界的新物种已经呈现出了这种趋势：大量的新物种出现以后，没多久就消失了。

# 3.“方生方死，方可而方不可”

我自己有一个癖好就是收集各种“电子文物”，过去一说到“文物”就想到青铜器，但是今天我从柜子里拿出一个东西给年纪小一点儿的人看，他们可能就不知道那是什么东西。在这20年的时间里，我们使用过很多的数码产品。就在几年前，曾经出现过一种叫“电子手环”的东西，现在很多人都觉得很陌生，甚至有的根本没见过，它曾经火爆过几个月，后来就突然就消失了——这种单一功能的产品很快就被其它相对成熟的可穿戴设备所替代了。

“前年还没有，去年刚出现，今年就已经呈现出趋势”的那些新产品和新商业模式，“方生方死，方可而方不可”的新物种在今天越来越多，不值 得惋惜。

物种发展的趋势轨迹就是这样，这个故事已经在5亿年前发生过了。所以在今天，好消息是“新物种会不断涌现出来”，坏消息是“很多新物种会很快消失”。
