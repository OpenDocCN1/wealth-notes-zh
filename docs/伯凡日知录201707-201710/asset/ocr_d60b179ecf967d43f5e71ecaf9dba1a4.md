# —— 第207天的知识笔记 ——

iPhone8的议论很多，关于这个产品现在我不想说太多，这里涉及到了我们以前的一个话题："新种族"主义的产生——以前的种族是按肤色进行划分，而现在的种族是以多种要素来划分的，比如使用不同产品的人就会形成一个"种族"。

"种族问题"一直有一条很重要的原则：所有的判断都不是事实判断，而是价值判断——没得可争论，没得可商量，因为涉及"价值判断"就很容易触到情感底线。

我们今天不对iPhone 8这个具体产品做更多的评价，但我们可以说的是iPhone。

# | iPhone的"颠覆性创新优势"

iPhone在10年前横空出世，完全是作为一个"新物种"出现的，它的胜利在于形成了一种新的产品品类——不是品牌间的简单竞争，而是品类间的竞争。
