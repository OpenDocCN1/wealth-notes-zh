# ——► 第215天的知识笔记 ◄——

华为公司有一句让我特别触动的话："给员工加薪就是占员工的便宜"。

这句话是说，公司通过给一个员工加薪而对他产生的激励，和公司付出的成本之间是不对称的。假设一个员工被加薪2000块，那就可能直接促使了他主动性的发挥，从而给公司创造了不止2000块钱的价值——从这个角度来说，加薪就是占员工的便宜。

不过仔细再想想这句话，就★会发现，这里可能有一些问题，或者说至少有一个限制条件。

# | 激励的边际效应递减原理

《硬球》这本书里有这么一个例子：有一个人很有慈爱之心，他发现公司楼下有一个卖煎饼的老太太，觉得老太太这么大岁数了很有不容易，就在每天上班经过煎饼摊的时候，把一个quarter（25美分）给那个老太太——"勿以善小而不为"，一年过来，他坚持这么做，应该说是很值得赞扬的。

但转折发生在一周年以后。有一天他照例把一个quarter给了那个老太太，却发现老太太以一种质疑和不满足的目光盯着他看。这个人就很奇怪，问老太太是不是自己做错什么，老太太说："我的煎饼现在已经不是25美分了，而是30美分了！"

我们把这个故事做一个抽象：激励或者慈善的边际效应是递减的——你把一个东西给到别人，当成为惯性之后，激励效应会逐渐归零——他已经把这个东西纳入他的正常收入了。

行为经济学家告诉我们：人们对"得到的东西"的敏感程度远远小于对"失去的东西"的敏感程度。

人们不在乎你给过他们什么，而只在于你最近给过他们什么，很多的激励因此就可能变成了"零激励"，甚至"负激励"——所以卖煎饼的老太太对每天给自己一个quarter的人会心生不满，因为她觉得这个人欠她5美分。

上面这个故事告诉我们，激励远不是那么简单的一——"给员工加薪就是占员工的便宜"这句话有很多限制条件。

# | 索取者和给予者

最近《哈佛商业评论》的一篇文章让我对这个问题有了更深入的理解。这篇文章讲了一对概念：taker和giver。

所有的人，包括所有的员工，都可以分成两类：一类叫"索取者——taker"，一类叫"给予者——giver"。

无论你是"索取者"还是"给予者"，并不是说你自己"有意索取"或者"有意给予"，而是说，这是一种习惯，是"习惯性给予"的人和"习惯性索取"的人。

《哈佛商业评论》这篇文章的作者认为，世界上就是这两种人组成的。一个公司也可以把员工分成这两种：

+   给予者——他们习惯性给予，也并不知道自己是一个"给予者"。每到一个地方，"给予者"们就忙前忙后，觉得这些事情都是他该做的——他们就是这个习惯。

+   索取者——就等着别人来张罗。这类人不是一种理性的计较——"我应该少处理，应该多获得"——这些早已变成了一种无意识的行为。

# | 标量和矢量

数学上有一对概念：标量和矢量。

+   矢量：既有大小，又有方向的量。也叫向量。

+   标量：只有大小，没有方向的量。
