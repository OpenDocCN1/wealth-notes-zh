# ｜致命的自负

昨天我们讲到“瓦萨号”船沉没的故事，由此引申出一个话题：当我们造船造物的时候，真正的造物者是谁？

船是大海造出来的，“人造物”实际是“天工开物”，是天在造物。如果忘记这一点就会导致灾难，“瓦萨号”就是最好的例子。我们可以借用咱们克的一个书名来诠释灾难的原因——致命的自负。

今天出现了很多热衷于“新物种”和造物的创业者，他们常常犯这种很明显、低级的错误，比如中国第一家倒闭的共享单车公司。

这家公司在重庆，它在这个地方做共享单车，显然忘记了一个特别简单的道理：是天造物，而不是人造物。

# ｜佛罗里达航空90坠落事件

还有一个事故作为一个案例经常在很多管理书籍里出现，那就是“佛罗里达航空90坠落事件”。

这起空难发生在1982年1月13日，编号为“佛罗里达航空90”的飞机坠落，导致78人死亡。按照惯例，处理这起事故的人找到了飞机的黑匣子，他们在黑匣子里听到了这样一段对话：

> 副机长：看见后面的冰锥了吗？

机长：嗯。

> 副机长：天啊！我们没有办法完全消除这些冰，这样让人很没有安全感……（停顿了一会儿）既然我们都坐在这儿了，就去检查一下上面吧。

> 机长：（没有反应）

【安全带提到进插槽的声音，表明机长准备要飞了】

这就是黑匣子里的录音。

# ｜礼节的灾难

这个案例有各种各样的解读，有人把它解读为一种“礼节的灾难”，就是在等级森严的体系或关系中，处于弱势的一方被迫要将他的信息包装在厚厚的礼节里。因为他不能冒犯强势者的尊严，他要保护自己，不愿意挑起冲突。同时，他作为弱势方还要传递非说不可的信息，于是他就采取了用厚厚的糖衣包裹一个关键信息的方式。最终，这个信息就被 ріка，被强势者自然地忽略——这种状态，被称为“在一个等级森严的组织里的一种自然消音机制”。

# 1. 海因里希法则

我们都听说过的“海因里希法则（Heinrich’s Law）”，是一条由美国著名安全工程师海因里希（Herbert William Heinrich）提出来的关于生产安全的法则。这个法则是说：在一次重大 você 出现之前，会出现29次轻伤或者轻微的事故。而在这29次轻微事故的背后是300个隐患。
