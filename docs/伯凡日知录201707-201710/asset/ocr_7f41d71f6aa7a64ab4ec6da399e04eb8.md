# 一、沟通就是清理障碍

印度有一个神明，你不能忽视，叫做象神。他有两个含义，一个是开端之神，一个是清理障碍的神。他要告诉你：开端就是清理障碍。很多时候，沟通是“为了挖一条沟让它通”。但是，结果变成了树梗，沟通的电阻就最大化了。

我们沟通的时候，要提醒自己：开始沟通的时候，要清理障碍。

我们经常发出的信号中，有一个自带的東西是“噪音”。噪音的含量常常是高于我们自己的想象。比如，我说的每句话，我自己是明白的，但是50%～60%可能是噪音。我觉得是信息，但是大家由于各种原因，产生了误解，觉得是噪音。所以，沟通的时候，开口便错。

今天时间很短，我说一个通过自己的感受得出的结论：你要意识到沟通本身是有原罪的，它自带破坏性，噪音就是分母，沟通是分子。

# 1."口令思维"

沟通无关对错。你的银行存款有一千万，你想把密码设置得高级一点，但其实无所谓，你自己知道就行，不容易被解密就行，密码没有对错，但是一旦定下来就有对错了。我们要有一种“密码思维”口令思维，用最简单的没有意义的字母数字解决最重要的问题。
