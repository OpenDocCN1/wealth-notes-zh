# | “三位一体”理论

昨天我们谈到了“RPV理论”，以及一个和它相通的“三位一体理论”——用这个理论分析很多公司的盛衰是比较管用的。

我们看到一些目前成长很好的公司，企业领导人几乎都是集“圣父、圣子、圣灵”于一身的一任正好也好，马云也好，贝索斯也好，都是将三者结合在一起，既是公司的创始人、主要资源的获取者，同时，又是一个不走样、不打折扣的执行者，最重要的是，他们是整个公司文化灵魂的铸造者。

但这就会出现一个问题：当创始人既是管理者，又是文化价值的输出者、铸造者的话，换一个执行者，可能就丧失了圣父的特性，又丧失了圣子、圣灵的特性。

英特尔就是最明显的例子：当贝瑞特和欧德宁这种偏重于执行和管理的人做了CEO以后，尤其其欧德宁是财务出身，他任职期间，英特尔的业绩是上升的，但他却干了很多很不该做的事情，比如英特尔的移动业务。

![](bbox=[0.35, 0.00128, 0.97, 0.00175])

![](bbox=[0.35, 0.00185, 0.97, 0.00232])

移动业务是一个花钱的业务，在一个财务管理出身的人来看，这个部门就不应该存在。所以，欧德宁的这种态度决定了他的财务业绩非常好——不盈利的部门就不投入资源，甚至把它卖掉。当你卖掉一个亏损的部门，你在财务上是成功的，但也就可能同时丧失了未来。面对重大选择假若舍弃的时候，如果你是单一财务指标的话，这家公司会不可避免地走向衰落。

如果用“三位一体”理论分析目前经营和管理出现困境的那些大企业的话，会发现它们都存在着这样一个问题：公司的管理者也许是一个合格的执行者，但很可能这家公司就不再有“圣父”，更不再有“圣灵”——作为一个优秀的职业经理人，公司在他的任期内业绩可能会不错，但是他会在不知不觉中把一个公司引向末路。

# | 隐性玩家

在“三位一体”里，圣子是看得见的，圣父和圣灵都是看不见的。前几天薛兆丰教授和我建议，应该深入发挥讲一讲一个我提到过的概念——隐性玩家。

# 1.大拇指的故事

“隐性玩家”这个概念我陆陆续续提到了好多次，讲过过大拇指的故事：一只手的五个手指头里，大拇指显得很不重要，但它其实是极其重要的，一旦丧失了大拇指，手能够做的事情其实非常少——这里的“大拇指”是一个象征：我们追溯一个结果的原因的时候，常常会忽略那些起了非常大作用，但是又很不显眼的因素。

# 2.散户的定义

这样一种世界观就导致了相应的方法论：我们可以对“散户”做一个新的定义——所谓“散户”，就是在观察一个态势的时候，根本意识不到真正重要的“隐性玩家”那类人。他们只看到那些显而易见的直接因素，并且相信凭一己之力就可以掌握自己的命运，所以他们上窜下跳、频繁进出、很努力、很奋innt，但是最后就是两手空空。原因在于，“散户”根本不知道自己所置身的这个资本市场里真正的“隐性玩家”是谁，他们甚至都没有意识到这样一点——散户很少意识到庄家的存在，或者说，他们低估了庄家的作用，同时，他们也没有意识到庄家有各种各样的形态、各种各样的身份。有比较容易看到的庄家，更有你完全意识不到但是真正起大作用的那些庄家。只有意识到这些“隐性玩家”的存在，才能够从明局里看到暗局，否则，你的所有勤奋和努力可能都是徒劳的。

# 3.神秘岛

“隐性玩家”这种意识，对于我们观察很多现象是一种有用的思维方式。追溯起来，我注意到“隐性玩家”这个因素与我初中时看过的一部小说《神秘岛》有关。

![](bbox=[0.35, 0.00522, 0.97, 0.00618])

《神秘岛》写的是几个越狱者乘着热气球搞了一次胜利大逃亡，结果热气球越来越瘪的时候，他们就沦落到了一座荒岛上。

《神秘岛》这个故事很精彩，它的主角，工程师史密斯审时度势、深谋远虑，能够在环境极其恶劣的条件下带领身边的几个人化险为夷、绝处逢生、别开生面。

我觉得史密斯这个人最厉害的地方就在于，当他一次又一次通过艰苦卓越的奋斗渡过难关，赢得一个新局面的时候，他并没有陶醉其中，而是排除了“自恋自我”的干扰——我们前面讲过：每个人都有一个损友，就是“自恋自我”——当史密斯在一次又一次的成功之后，站在岩石上吹着风，凛然不动地沉思的时候，他想了很长时间，最后回头跟众人说了一句话：“这是一座很神秘的岛，这座岛上一定有一种我们不知道的力量在起作用。”

史密斯在总结自己每一次成功的时候，发现都有一个隐隐存在的原因被他们自然忽略了——有一种看不见的力量在帮他们。史密斯不认为是自己打败了海盗——他几个人就能够打败海盗，这种胜利他没有归结于是他自己指挥成功，以及自己如何英明神武，他意识到，这个荒诞荒岛的真正的身份是一座神秘岛。

史密斯的这种思路逐渐帮助他把视野引向了这座荒岛的另外一面，别人看不到的那一面，最后他见到了藏在山洞里，一直在帮助他们的那个神秘的尼摩船长。

当然，《神秘岛》是一个文学的故事，但是它对我们有一种提醒：我们在追溯我们所有努力作为的结果的时候，都要als有一种清醒的觉察，那就是我们在努力、在奋斗、在玩儿，但是很可能起关键作用的恰恰不是我们自己。

# | 忽视“隐性玩家”的代价

# 1.懂得敬畏的郭士纳

IBM的前CEO郭士纳，在追溯他的成功的the时候，说了一句很关键的话，那就是“运气”。这个“运气”就是当时的IBM所面对的特定态势：这个产业在那个时候突然发生了一个变化，这个变化不是必然的。如果在另外一种时空里，这个影响IBM命运的最重要的变化不出现的话，IBM当时也就死去了。所以，郭士纳的内心有一种习性的敬畏，或者说，他是看一只手的时候，能够充分意识到大拇指重要性的那个人。
