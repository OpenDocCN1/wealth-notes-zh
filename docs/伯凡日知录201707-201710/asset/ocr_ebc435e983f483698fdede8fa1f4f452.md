# 10.5｜冒险式创新与金字塔原理

# —— 第208天的知识笔记 ——

# 1.重拾智能手机的诺基亚

不久前看到一条新闻：诺基亚准备推出自己的智能手机。

最早的智能手机其实就是诺基亚做的，只不过没有做好阈那个倒霉的CEO斯蒂芬·埃洛普(Stephen Elop)的话说就是：“我们什么都没做错，但是我们失败了。”--今天，诺基亚“在哪儿跌倒，还要在哪儿爬起来”，它又要重新开始做智能手机了。

这个新闻让我想到一个段子：

某人当年因为犯罪被抓了起来，咬着牙不交代，而且态度很不好，瞒骗了很多犯罪事实，被判了很重的刑。十几年后，他刑满释放出来，找到了自己当年的小兄弟说“我熬了这十几年，一直等着这一天，我们要发财了！”然后就找到一个地方，挖出一个箱子，里面装满了BP机——当年，这个人他死活扛着不交代的事，就是他一直等到出狱这一天，把这一箱子BP机卖很多的钱。

要知道，十几年前，连一个BP机能卖4000多块——这也印证了中国有句话“时来铁成金，运去金成铁”。

诺基亚重做智能手机，我不太看好，原因昨天已经讲了：手机这一行业正处于“上一个时代的尾声，下一个时代的序幕”，如果你因为当初的失败耿耿于怀，要恢复昔日的荣耀，那很可能是一件荒诞的事情——即使你把它做得再好，它也已经是一个要灭绝的物种了。

# 2.结束昨日战场的IBM

二十多年前，IBM当时的CEO郭士纳上任以后说，通过他的观察，IBM这家以做PC著称的公司，一定要放弃PC以及相关业务。为什么呢？郭士纳有一句话很经典——我要结束这样一场属于昨日的战争。

的确，即使这个战争继续打，你也只能打出暂时的辉煌。这有点儿像我们看过的一部电影：日本天皇已经宣布投降了，但是有一小股日军不知道这个消息，还在继续抵抗——这是一件很可悲的事情。

现在的一些企业，虽然日子过得不好，但还是重振旗鼓，还在奋力地抗争，说到底，他们在从事的是一场“已经结束的战争”。

# 3.冒险式创新的惠普

这个话题让我想到一家企业，直到今天，去硅谷参观游学的人，不管时间多紧，恐怕还是要到当年惠普创业的那个车库去照一张相——那是硅谷的象征。

![](bbox=[0.18, 0.0028, 0.92, 0.0038])

你有多久没听说过惠普了？这的确是一家人抛<|message|>息的公司。实际上，惠普最近还有一个很好的消息——重新成为了PC业的老大——但意义好像已经不大了。

惠普是硅谷的象征，在IT产业，它一度是创新的代名词。今天惠普的状况可以用一个管理学家的話来形容：一些企业在新的游戏规则中，即使没有马上消失，也已经逐渐变得无关紧要了。

早在七八年前就有人分析过“惠普是如何从一家领袖型企业变成一家无关紧要公司”的一一惠普的创新能力和创新体系之间有一个非常大的冲突，一方面，惠普是一家很能创新的企业；另一方面，它也是一家没有创新体系只有创新行为的公司。

细数起来，惠普一直在进行各种各样的创新——有人给这种创新取了个名字，叫“冒险式创新”——在公司里，不断有各种各样的创新，今天这个人冒泡儿有个创新，明天那个部门又冒了一下泡……整天就在看见公司里不停地在冒“创新的泡儿”，但最终，惠普没有一个创新能力。

有“硅谷教父”之称的杰弗里·摩尔（Geoffrey A. Moore）用了一张图来说明这种“冒险式的创新管理”。

![](bbox=[0.18, 0.0057, 0.85, 0.0066500000000000005])

一张纸上画着有很多的箭头，箭头分别指向各个方向，结果是：等式的右边等于0。

数学老师给我们讲过“向量叠加”的知识：“向量叠加”跟普通的加法不一样，普通加法是各个加数之间的差异不构成问题，它们累加起来形成一个总的得数；而向量叠加是互相抵消的，不同方向的向量加起来就是0。

惠普就是这么一个增长于“冒险式创新”，当然也就相当于“不善于创新”的公司——一个没有创新体系，只有很多创新行为的公司，它的结局就是今天这个样子。

# 4.徒有点子的点子大王

“冒险式创新”本来是一个企业管理、创新管理的话题，但它也跟我们的个人管理有关。

我们生活中经常遇到一些点子大王，他们有各种各样的点子，东一个点子，西一个点子，脑袋特别的灵活。在具体某件事情上，点子大王们总有一些新的想法，但多少年接触下来，你会发现这些人并没有做出什么东西出来，或者说，他们的知识很丰富，会吸收各种各样随处出现的新知识，但这些多向量的知识最终没给他们带来真正认知上的增量，最后的结果很可能是0，或者约等于0——做认知升级的时候，我们不要去做“冒险式”的学习。

# 5.金字塔原理

有人会说“现在是一个知识爆炸，强调跨界、无界的时代，如果你的心智只集中在某一个狭小的范围内，很可能被淘汰”。

这话当然没错，但这里隐含着一个问题：如何协调创意的多样化和专业化——在“乐高式”创新时代，一方面要尽可能增加更多的积木；另一方面，又要避免这些积木杂乱无章，最后什么都拼不出来，这是一个很明显又非常重要的问题。

![](bbox=[0.18, 0.009699999999999999, 0.92, 0.0111])

《金字塔原理》这本书是麦肯锡公司（McKinsey&Company）的一个顾问写的，书上一直保留着一个专家写的推荐语“不读这本书的机会成本非常高”。

进到麦肯锡公司是必须\&要接受这种“金字塔原理”培训的，冯唐在麦肯锡就接受了这种培训。培训以后他说“其实用到100个字就能概括这本书的内容。”

冯唐是这样概括的：任何一个观点都同时包含着3~5个支持性论据，而每一个支持性论据又都同时包含着3~5个支持性论据。如果层层这样细分下来，无论一篇文章也好、一本书也好、一个观点也好，都内含着一个金字塔的结构——很多人的观点要不是就是“不清晰、杂乱无章”，要不是“缺乏深度”，原因就是，他们的观点中没有内含着一个金字塔。

举一个简单的例子，每一天的《彼凡·日知录》的内容都可以一句話来概括，但是这一句话就包含着3~5个相关的论点和论据，然后这3~5个相关的论点和论据又可能包含着3~5个……这样推演下来，就是一个金字塔的结构。
