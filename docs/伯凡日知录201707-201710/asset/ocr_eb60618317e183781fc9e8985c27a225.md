# 吴伯凡

应该说，场景想象能力以及沉浸在想象性场景当中的能力，是有个体差异的。有的人仅仅靠想象就能够进入到一种场景里头，读小说流泪，替古人担忧。但有的人无论如何都达不到让自己沉浸在一个自己不存在的场景当中。我们经常说，同理心，共情力都跟这种能力有关。我们不能强求每个人都一致。

一般来说，有文学气质的人是比较具有场景想象能力的。诗人冰心有一首很有名的诗，她说，我梦梦见到自己是一个<|message|> 零人，也就是梦见自己成了一个残疾人。醒时犹自呜咽，醒来的时候还在哭。因为遗留的深重的悲哀，这一天中，我怜惜遍了人间的孤独者。这一天虽然是梦见自己是一个残疾的人，醒来发现自己不是，但是她突然对身体有残疾的人产生了一种深沉的同情。与此同时，她因为发现自己竟然不是残疾人，也产生了一种感恩和惊喜。所以她因着相形的浓厚的快乐，这一天中觉出了四周的亲爱。突然发现这个世界特别的可爱，自己特别的幸运。

亚当斯密认为，共情力、同理心是一个人道德能力的基础。有道德的人就是那种能够身处地感受别人的痛苦和处境的人。当然这个话不能说的绝对，要不然这个同学说我就了，难道我是没有那种道德能力的我吗？

但有一点，这个能力是可以培养的，虽然它跟我们的遗传、个体差异有关。这也就解释了为什么很多人看了很多书、明白很多道理，但是没办法实质性地改变自己的性格，改变自己的价值观，改变自己的行为方式。因为，一个人的行为常常是在一种场景当中被激活的。正因为如此，有些教育专家认为，真正的商业教育不是在哈佛商学院里面学那些商业课程，而是应该去美国的西点军校，去接受一个真正的军人的训练，在那种环境里你才能真切的感受到什么叫领导力，什么叫决策、什么叫判断，什么叫信念，什么叫团队。有人认为，美国西点军校是资本主义的哈佛商学院。有 一个统计显示，从西点军校出来的成功的企业家和经理人要比哈佛商学院还要多、从这一点上我们也能感受到场景是多么重要，真实的场景是如何真正改变人的。

我建议这个同学，如果你没有那么强的想象力，或者不爱想象力的盘惑，你不妨让自己去进入到一种真实的场景当中。

我记得我读研究生的时候有一个很著名的经济学家，他说，“我现在这么老了，我一直要做一件事情。每个月坐两次公共汽车。你不坐公共汽车，你是不知道老百姓是如何生活的。你也不会知道竟然有那种高高在上的意识，说起话来免不了要妄为其谈。”所以，他每个月用他的两次坐公共汽车的经历给自己冲凉，避免自己虚火上升。我想这也是一种场景教育吧。

吴老师好，场景和生态环境是不是有相似之处呢？

# 吴伯凡

答案是非常相似。什么叫进化？所谓进化就是生物体在它所处的环境当中被激活出某种性状。一个生物体可能有各种的性状，但是它只会在相应的环境当中显现出来。而且，个体差异也非常的明显。
