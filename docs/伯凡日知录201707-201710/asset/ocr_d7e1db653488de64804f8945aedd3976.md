# 没有选择的选择

前几天我又和一个朋友谈到了关于学英语的问题。我们学英语是学关于英语的知识，或者说是学到如何应对英语考试的各种技巧。学英语以后，别的可可能都忘了，但是有一个很重要又很无趣的技能：做选择题实在不知道选什么的时候，就选C！一般也能蒙到一些分。

现在，我们的教育悄悄的给我们的心智注入很多的负资产。比如做选择题这样一种考试方式，就决定了我们的学习和思维方式。我们常常不自觉获得了一种认知：面对这个世界，我们要解决的问题是在有限，甚至是极为有限的选择当中做出一种选择。很多选择都不再是选择，而是按照一种思维惯性去找到所谓的标准答案。一旦我们拥有了这种思维方式，就会有很多的麻烦。麻烦并不存在，是你的思维出现了麻烦。

就像“-Cal马术”，有人给出一个问题，表面上好像有两种选择，但你无论选哪一种都落入到它的圈套。比如，“听说你道德高尚，那么你是否停止打你的父亲？”这种其实是没有选择的选择。

昨天讲到的关于从一个麻烦点发现机会链的问题，这种思维方式的本质是破除你的选择、突破你的选择范围。把一个被你的思维方式遮蔽了的显而易见的选择纳入到你的视野，你会有别开生面、柳暗花明又一村的感觉。这是一个很经典的管理学的问题。

# 麻烦=机会=创新

我们讲过管理学女先知福列特的著名的案例。所谓管理，是在两种好像只能二选一的选择当中找到一种别开生面的解决之道。

一个阅览室里，一部分人要开窗，另外一部分人要关窗的时候，好的管理者会统计要求开窗和要求关窗的人的比例，然后在整个图书馆里按照这个比例设置开窗阅览室和不开窗阅览室，让不同的人各就各位。这个看来不可调和的问题就得到了解决。所以，麻烦点就是一个机会点，或者创新点。

把创新定义为“不可能河上的一座桥”就是这个意思。当屏幕和键盘在争夺地盘的时候，苹果按照这种思路找到了一种解决之道，开发出了触屏智能手机。

# 第三选择=你的睫毛

斯蒂芬·科维的一本书的名字，也是一个概念，叫“第三选择”。在这本书里，他提出的核心观点是：日常生活中和工作当中，我们常常会遇到这样的难题，要么听你的，要么听我的；要么忍气吞声，要么拔刀相向。但是，几乎所有的只能二选一的选择当中，都存在着一个我们没有看到和意识到的第三选择。这个第三选择既不是你赢我输，我赢你输，你输我输，而是你赢我赢。无论是在家庭、还是在公司、企业当中，大量的冲突虽然是常态，但其实是没必要的。

# 突变成为新物种

有一个品牌叫北极星，是一个雪地摩托的品牌，在细分市场里头做的很不错。但是，雪地摩托这种产品决定了它的市场永远很小：首先，它是高纬度地区才使用的一种工具，比如说瑞典、芬兰、俄罗斯、加拿大，只有这些地方的人会在冬天的时候使用这种摩托；其次，这种产品除了空间的有限性，还有时间的有限性，顶多卖半年。但是这家公司由于找到了一个确定的细分市场，所以过得也还不错。

从这个案例里头，我们能够意识到第三选择有多么重要。进化论告诉我们，进化是物种的变异加上自然的选择而导致的一种新性状的出现。当这个性状逐步明显和突出的时侯，它也就成了一个新物种。

吴伯凡

听完今天的课，大家可以问自己一个问题：我自己或者我的公司会遭遇一种什么样的麻烦，能够让我和我的公司变成一个新物种呢？
