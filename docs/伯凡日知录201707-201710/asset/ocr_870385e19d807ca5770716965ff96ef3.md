# | 灭绝物种曾经也是新物种

说了新物种，我就想到了一些灭绝的物种。灭绝的物种当初也是极具竞争力的新物种，比如，恐龙。恐龙显然不是从来就有的，它出现的时候就是地球上的一个新物种。

有點不可思議的是，恐龍的祖先是鳥，或者說是禽類。大家可以想像一下，如果我們把雞或鴨的毛都拔了，放它們在地上走，是不是像微縮版的恐龍？仔細一想，恐龍和雞真的挺像的，它的很多特徵也跟雞一樣，比如雞有雞蛋，恐龍有恐龍蛋。

![](bbox=[0.22, 0.68, 0.92, 0.8])

明明是和鸡鸭同一个祖先，这个强大到让人恐惧的物种又是如何演变成恐龙的呢？

是因为在特定的环境下，它的性状得到了很好的发挥，形成了某种正循环：当这个物种的体型比其它的禽类更大的时候，它获取食物几率就会越大，而获取的食物越多，这个物种的体型就越有可能增加。这种正循环使恐龙的体型越来越大，让它把同根生的那些物种用出去老远。而它的体型越大，获得的竞争优势就越大；竞争优势越大，它的体型就更大。但是这时候，一个恐龙自己没有意识到的危险开始发生了，那就是，如果环境一旦发生变化，它获取食物的途径就没那么容易了。

# | 成也T型车，败也T型车

在商业史 Bücher 也有“恐龙”，那就是已经灭绝了的T型车。我们现在只能够在一些老爷车的博物馆里才能看到这样的车，但在 一百年前，它不是汽车里的某个物种，所有的汽车都是它这样样子。

![](bbox=[0.22, 1.0, 0.92, 0.00115])

1908年福特公司成立的时候，汽车成本很高，只有极少数的富人才能买得起。福特公司靠着它的生产线大大降低了汽车的成本，使得这种本来是奢侈品的东西变成大多数人都能买得起的一种商品，赢得了巨大的市场。

> “今后五十年，我们将在同一种底盘上生产同一种车型，用户可以选择任何颜色的车，只要是黑色。”

# | 戴尔，PC业的“恐龙”

还有就是戴尔。当PC作为一个新产品出来的时候，戴尔以它独特的生产和管理方式，使得这个产品就像T型车一样人人都买得起。虽然没什么特点，但是价格很便宜，让大多数人都能够拥有电脑。

# | “其兴也勃，其亡也忽”的独角兽

这种突然之间起来，又突然之间衰落的现象，是因为新物种性状太单一。特定的市场环境让这种新物种的特 点大行其道，迅速发展起来，但当环境悄悄发生变化的时候，它的单一性状没有办法应对变得越来越丰富的情形和场景，它就一定会出现“脆断”。
