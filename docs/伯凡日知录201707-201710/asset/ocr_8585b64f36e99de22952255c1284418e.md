# I 沸点思维

听说过边际成本和边际收益。第一次听到竟然还有边际竞争劣，这让我联想到老师之前提到的核心优势。刀锋竞争力是个体或组织的“绝技”，只有到了某种极致的场景这种绝技才能被激发出来，并能够取得“决胜于千里之外”的效果。老农民的大数据库是多年实践积累的经验，是对自然环境反复认知辨识后的结论，虽然没有专业的理论总结，但是他们就是依靠他们自己的一套感知系统来做出准确判断的，因此要了解某一具体地方的农业问题，向专家不如问当地的老农。有一个问题想向老师，既然刀锋是整把刀的最边缘的部分也是最关键的部分。我在思考既然我们用刀要用的 是刀锋部分，那除刀锋以外的部分是不是都是废铁呢，它们仅仅是起着“连接”和“代替”的作用吗？我们花在整把刀上的成本，是不是就是只是在为刀锋买单？延伸一下作为个人或企业要有意的培养自己的刀锋竞争力，怎样去均衡刀锋竞争力与其他部分竞争力的关系？

刀锋的确是一把刀最关键的部分，但是刀锋以外的部分并不是可有可无的。刀鞘是实现功能必要而不是充分条件，而刀锋可以理解为这把刀的充分条件。只要这两者合在一起，我们才可能实现自己的目的。可以想象一下，我们能不能用一根细细的钢丝去切东西呢？那会非常的不方便。所以，刀锋之外的部分根本不是废铁。

# I 极端境遇造就极端能力

有个疑问，如果说刀锋能力是平时不断积累培养的，那我没有处于那个极其罕见的情景，该如何培养刀锋能力呢？

# 昊伯凡

随着年龄的增加，我越来越相信人的能力，尤其是人的竞争力要取决于很多机遇。没有处于某种极端的境遇，我们不太可能具有某种极端的能力。即使你很想获得某种独特的极端能力，但由于你所处的场景、环境是一个很平常的环境，你很可能最终没法具备这种能力。
