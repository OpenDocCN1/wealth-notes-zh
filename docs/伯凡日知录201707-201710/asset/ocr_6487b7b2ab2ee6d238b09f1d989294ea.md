# I “外包”的起源

我们今天对“外包”这个概念太耳熟能详了，以至于会认为它一个历史悠久的概念。事实上，“外包”进入管理学的时间也就不 到40年。

最早的“外包”起源于医院的管理。众所周知，医院是一个多工种，而且工种之间壁垒森严的机构。在医院里从事某一个工种的人，可能跟另一个工种是“老死不相往来”的。而其中最明显的例子，就是医院清洁工这个工种。

# I “外包”的追溯

知道了“外包”的起源，感觉它是一个很新的东西，但我们仔细追踪一下就会发现，“外包”是一个很古老的事情，可以说是“世界上最古老的事情”——自从有了人类，或者在还没有人类之前，就有了“外包”——火。

# I 从“外包”的角度看房价

我们从“外包”的角度来看人和世界的话，很多问题也可以更清晰和简单了。

比如，北京市区的房价是十几万一平方米，而郊区的一个独门独院可能也就是十几万，但你不会买郊区的那个房子，原因很简单：房子的价值在于它的“外挂”程度，程度越低，价值就越低。
