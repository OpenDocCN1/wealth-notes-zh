# 预告 | 做不成是不幸，做成了是灾难

预告 | 做不成是不幸，做成了。 ↓

童话故事的末尾都会这么写：从此，王子和公主过上了幸福的生活。而真实的故事常常是倒过来的：王子公主过上了幸福的生活，从此“......”

我之所以想到这句话，是想和大家分享几个概念。

# 一、做积极的悲观主义者

中国古代哲学家庄子曾经讲过“人道之患”与“阴阳之患”，也就是表层的麻烦和深层的麻烦。

事情常常是这样的：当我们把注意力盯着在眼前的麻烦，并试图去解决它，并终于解决的时候，这个麻烦背后的底层麻烦就开始浮出水面了。你会发现，麻烦不仅不会因为我们的解决而就此消失，反而会因为原来麻烦的消失而出现新的，甚至更大的麻烦。

做不成某事叫“不幸”，做成了某事，反而可能成了“灾难”—我们常常没有意识到，消除麻烦的过程其实是制造麻烦的过程。

在一个组织里总会面对各种各样的麻烦，那么，面对这些麻烦，我们要抱着一种什么样的心态，以及怀着什么样的期待呢？

有一种态度叫做“消极的乐观主义”。具有这种态度的“消极乐观主义者”常常使用这样的句子“要是什么什么就好了”，或者“这件事情就过去了”。而“积极的悲观主义者”不是这样，他们不相信麻烦可以消除，而坚信麻烦不仅守恒，还会递增。

用什么样的心态对待好消息和坏消息，表面上是一种心态，其实涉及的是一种管理思维。

# 二、远离姑息式和谐

说到消除麻烦与制造麻烦，自然会想到职业生涯中碰到的升职的烦恼：当你竭尽全力与同事们齐心协力把业绩越做越好，终于获得了领导的赏识，得以出类拔萃、出人头地的时候，随着这个好消息的出现，坏消息也接踵而至。你发现跟你朝夕相处的那些亲爱的同事们突然变了，他们在有意无意地给你制造着各种麻烦。

面对这种情况，我们该采取什么样的解决方案呢？一般常识性、本能式的反应是，采取姑息的、贿赂的方式去维持表面的和谐。你会试图通过各种小恩小惠，通过你可能做出的最大让步，给你的下属提供尽可能多的方便，以求得一个表面的和谐——这样处理问题的方式，是一种姑息式的、迎合式的、贿赂式的方式，它不仅不能解决问题，还会越来越强化你们之间早已改变的关系——这种方式就像吸毒，不断地强化毒瘾，而不是消除毒瘾。有效的处理方式是：如何把他们的心态从“让他们为你做事”变成“让他们为自己做事”，从“以你为敌”变成“以他们自己的危机为敌”，有效地制造某种危机感和紧迫感。

如果你发现你的日常业务，尤其是那些关键业务上离开了谁不行的话，就意味着你的管理出现了重大的问题。管理者首先要解决的是“如何尽可能消除离开了谁不行”的状况，要通过各种手段让那些好像只能够去迎合、去拉拢的员工意识到“没有他也行，甚至更行”，他们就会在这种危机感的驱动下为他们自己做事，当然，客观上也是在为你做事。

# 三、无权势者的权势

说到“姑息式和谐”和“贿赂式和谐”，自然就会想到对孩子的教育。很多家长在养育、教育孩子过程中不知不觉采用了一种迎合式、姑息式的和谐来解决问题。当你采取这样一种教养方式的时候，你就开始了和孩子之间的一场权力游戏：孩子作为一个无权势者越来越发现他的无权势、他的柔弱、他的哭声是能够赢得巨大权势的。这种权力游戏一旦开始，你就在无意当中不断给孩子赋权、赋能，不断强化他的权力欲——这是一种对孩子的情商和智商都会形成巨大伤害的教育方式。

如何告别这种权力游戏，终止孩子无权势者的权势，而让他免受权力的毒害，以及避免权力对他的心智形成持续的损伤，让他获得健全的智力和健全的人格呢？

对家长来说，这是一个严峻的使命。周三，我将就这个问题与大家一起讨论、分享。

# 四、避免认知降级

现在都在说“认知升级”，其实比认知升级更重要、更紧迫，当然又是更容易被忽视的，是“如何避免认知的降级”。尤其是对于领导者和管理者来说，随着权力和资源的增加，他们在遭受一种他们没有意识到的伤害：有研究表明，拥有的资源越多，拥有的权力越大，人的大脑遭受的损伤就越多。

如何避免这种暗伤？如何避免自己在单纯依靠权力解决问题的过程当中，各种能力的迅速退化？这是一个容易被忽略，但是非常重要的问题。

我看过一个BBC的真人秀，让企业老板以普通应聘者的身份去自己公司某个并不重要的部门应聘、上班，然后记录他们在这个部门工作时的种种状态，以及他们的想法。

这种微服私访的方式，不但让老板们获得并刷新了他们对于真实世界，对于自己公司真实状况的认知，而且让他们获得并刷新了对他们自身的认知——这种特殊的场景是一种强有力的检测手段，能够让管理者意识到自己的能力生态出现了巨大的缺失，提醒管理者如何去弥补自己已经严重缺失的种种能力和素质。

上周我们讲到了“幸运”，本周我们换一个角度，换一个话题，关注“不幸”，包括那些我们意识不到的不幸，也包括我们有意给自己制造，但最终对自己有意的那种不幸。
