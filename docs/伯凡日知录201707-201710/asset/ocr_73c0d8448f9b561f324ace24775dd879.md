# 预告 | 场景——别针换别墅的智慧

预告 | 场景——别针换别墅… ↓

本周的《伯凡·日知录》围绕着一个关键词展开，那就是 场景。

眼下，场景是一个很热的概念，我希望本周的分享能够让大家从多个角度，多个层次理解场景这个概念。

当我们提到创新这个词的时候，我们常常想到的是创造新的事物。其实，创新还有一种方式，就是创造新的场景，或者把一个旧的场景转化为一个新的场景，或者是从一个显而易见的场景当中看到很多人都没有看到的一个新的场景。在一个场景里头没有价值的东西，在另外一个场景里头可能就具有崭新的、巨大的价值。

本周我会通过一系列的故事和案例让大家感受到场景的转变，场景的重新定义对于我们创造新的价值有多么重要。

很多年前我们都听说过一个游戏，叫做别针换别墅。一个别针最终能够换到别墅，这里头的发生机制到底是什么？其实还是跟场景有关。在某一个场景里头，价值极低的东西，在一个独特的场景里就会显现出巨大的价值。如果一系列这样的独特场景串联起来，那么一个价值很低的东西最终就会产生远高于它在单一场景当中的价值。别针换别墅的游戏就是这样发生的。

我还讲到了一个故事，一个富翁在外度假，突然接到电话必须要回到公司总部。他不能把这艘豪华游艇扣在这个地方，他除了雇人，请人代驾之外，还有什么样的方法，能让他不仅不花钱，而且还能赚钱，最终还能让这艘游艇安全地回家呢？

我还讲到了一个场景，有个领导新官上任，刚刚进门就看到公司的宣传墙上画了很多针对他的挑衅性的漫画，这就是他的对手想给他一个下马威。面对这种场景，他不仅没有陷入尴尬、丧失尊严，而且还把它变成了一场成功的就职演说。他是如何做到的？

本周还讲到了一个很有意思的话题，就是在猴群里，每只猴子，每天都会花10%到20%的时间彼此梳毛，为对方捉虱子。它们为什么会这样做？这跟社交网络有什么关系？跟邓巴数字有什么关系？

同学们，如果对这些问题感兴趣，请听本周的《伯凡·日知录》。
