# ｜“造型商品”=社交货币

听了“造型商品”之后想问一下，这类玩具是否是另一种类型的奢侈品？是否也是一种社交货币呢？

吴伯凡

应该说，奢侈品本身就是“社交货币”，它是一个面值远大于自身价值的特殊商品，它就是货币。

# ｜“隐性玩家”多巴胺

我对“隐性玩家”的理解是：随机性、不可知性，就像获得诺贝尔经济学奖的理查德·塞勒的“行为经济学”提到的老鼠实验，设计得好的激励和奖励措施，就会让人听你的摆弄，而且你还不自知。每一次新的奖励都会让你大脑再多分泌一次多巴胺，你会一再兴奋——真正的“隐性玩家”是大脑中的多巴胺。

吴伯凡

# ｜“知识包”不是“能量包”

“能量包”能解决物理世界的消耗效率，那么，是否还有“知识包”呢？就是能够解决精神世界的消耗效率，例如从古代的甲骨文、书籍、印刷到现在的互联网，这个过程好像就是“知识包”密度不断增大的发展历程。

吴伯凡

# ｜“最大的风险就是不知道风险在哪里”

在“气候决定战争成败”里面，当“鬼子六”听说比赛的是“狩猎”时，一定窃喜不已——人一旦遭遇自己的强项往往会忘记自己的目标，只顾一味表现。才会导致别人反败为胜。以前有位朋友送给我几句话“泛溪石险人就不慎，终岁不闻倾覆人。却是平流无石处，时时常说有沉沦。”这里所说的应该就是隐藏的暗局：人的主观意识对暗局的把握不准确，导致了失误甚至失败。

吴伯凡
