最近我们一直在讲场景、情景，局面的控制、主宰。很多的朋友给了我反馈，觉得对以前的一些概念，比如说领导力、反常识、反本能有了一个新的认识。好几个同学都跟我提到了乔厂长的那种主宰场景的能力，觉得这种能力非常令人羡慕。关于这个问题，我想从另外一个角度给大家进行一个分享。

# 前摄行为一操之在我一超常的主动性

我们可能都读过那本《高效能人士的七个习惯》，七大习惯当中的第一大习惯，可以说是根本性的习惯，就是“操之在我”。这个词听起来也很抽象，有一些同学可能就没有太多的感觉。

操之在我到底什么意思？这个词在英文当中叫proactive，我习惯于把它翻译成超常的主动性。

为什么要前面加个“超常”呢？就是一般的主动性还不够，它必须是具有让人耳目一新、让人诧异，但是又是的确确是一种真正的主动性的状态和行为。心理学上把这种行为称为前摄行为，Proactive Behavior。

什么叫主动？是在你面对的场景尚未发生之前，你已经定好了行动的准则。你的行为不是对眼前的事态作出了一个反应，而是不管事态是什么，你都有的一个反应。这种反应也可以说是一种面对千变万化中的一定之规的反应。乔厂长之所以能在别人给他难题的场景当中获得主动性，就在于他是一种前摄行为。

前摄行为的通常定义就是：那个行为在一个事态下反过来控制局面，而不是被局面所牵制。

# 例1——“亲爱的，我爱你”

一些心理学的书上都会举一个例子：一对夫妇结婚11年才生了一个孩子。由于妻子把一个应该好好保管的药品放在了桌上，小孩误喝了这个药去世了。在医院的急救室里面，丈夫面对抢救无效的场景的时候，我们都可以想象到他的各种反应。但这个丈夫的反应是一种非常态的，或者说是一种超常的主动性。他对他的妻子说了一句话：“亲爱的，我爱你。”

这是在这个场景当中真正采取主动性的行为，至于其它的行为，不管是痛哭、沮丧、捶胸顿足，还是痛骂妻子等等，都不叫主动行为。

# 例2——“对不起，我现在就打扫”

《遗失的智慧》这本书讲到了一个很著名的案例。在医院的一个病房里头，有一个年轻人受到了重伤，深度昏迷好多天一直不醒，他年老的父亲在照顾他。有一些天，他父亲离开了病房，到楼下去买东西。当他往回走的时候，发现清洁工尼克经过他们房间的时候没有进来打扫，而是直接走到了旁边的一个房间去打扫。结果，这个老人就冲到清洁工面前，非常愤怒地说“你为什么不打扫我儿子的病房！”，而实际情况是，这个清洁工已经打扫完了他儿子的房间。

这种情况下，清洁工的反应通常是这样的：他会非常生气，我打扫了，你没看见，你反过来冲我怒呜，这种蛮不讲理，我要给你一点教训。一旦他是采取这样一种态度的话，一场巨大的争执就难以避免，甚至有可能大打出手。但我们换个角度想：这个老人看见自己生命垂危的孩子生死不明，而且花费了大量的治疗费用的状态下，他做出这种过激行为完全是有可能的。最终，这个清洁工在老人向他怒吼的一瞬间，给了一个我们可以称之为具有超常主动性的反应。这个反应其实很简单，他说，对不起，我现在就打扫。然而，当老人跟着清洁工进到房间的时候，他立即就明白了，这个房间已经打扫过了。但是，清洁工尼克还是认真真的在重新打扫这个房间。老人终于看不下去了，说“对不起，是我的错，你已经打扫过了，我不该对你吼。”

这样一个事件，在短短的几十秒，一个可能导致激烈冲突，甚至大打出手的一个场面，清洁工用了几十秒的时间就完全化解了。尼克的这个行为，我们就可以把它叫做前摄行为，他在事情发生之前已经控制了局面。

# 例3——“你喝茶吗？”

再比如，《遥远的救世主》这本小说里头的主人公丁元英，他的手下因为对他的误解到处寻找他，终于找到了他隐居的地方，敲开他的门。丁元英一打开门，这个人把枪顶在他的胸门上。

大家可以想象一般人的反应会是什么样子，而丁元英给出的也是一种前摄反应，或者叫前摄行为。他非常淡定的，好像这事根本没有发生过一样，手里头拿着茶杯，面带微笑的对这个人说“请进”。然后走进屋子，他拿起茶壶说“你喝茶吗？”用枪抵着他胸门的这个人立即就蒙了。

当丁元英以一种轻松的语气再跟他说了几句话的时候，这个人干脆就把枪放在茶几上了。他为什么会这样？他觉得自己的威慑对眼前的这个人不起作用，所以他就自动的放弃了。

我们想象，当一个人进门就用枪顶着你的胸门的时候，你把他的枪夺过来是一件多么难的事情。而且，随时可能发生意外。但是，丁元英用那么一个四两拨千斤的反应解除了他的武装。这种行为也可以叫前摄行为，当然也可以说这是一种超常主动性的行为，是一种操之在我的行为。

# 《易经》：君子终日乾乾

在《易经》里头有一句话叫“君子终日乾乾”。乾本来就是主动，“天行健，君子以自强不息”，强调的就是主动。乾乾就是自强不息又自强不息，主动了又主动。

在《易经》看来，一个人只有终日乾乾，他才能够面对所有的场景，不管是顺境、逆境，还是困境，他都能够化险为夷，转危为安。儒家理想当中的君子，就是以一种习惯性的超常主动的方式面对人、事。也只有这样一种终日乾乾的态度，你才可能成为场景和格局的控制者、主宰者或改变者。

7.18 | 场景创新

昨天我们讲到了前摄行为（Proactive Behavior），提到《高效能人士的七个习惯》里的第一个习惯叫be proactive，通常译成“应之在我”，或者干脆译成“积极主动”。

积极主动当然是一种好习惯，但听起来却很空洞。积极主动是保持一种前摄性，在问题发生前，能够事先解决它，或者在一个游戏发生前，我就确定了一个游戏规则，当游戏发生的时候，我不是按照这个游戏本身的规则和对方玩，而是用我自主的游戏规则来改变这个游戏。这就是操之在我、积极主动。

# 没有问题孩子，只有问题父母

史蒂芬·柯维(Stephen R.Covey)提到过“问题孩子”这个话题。他认为“没有问题孩子，只有问题父母”。甚至“既没有问题孩子，也没有问题父母，是孩子与父母之间的态势出了问题”。

通常，不负责任的父母，或者说不主动、不是操之在我的父母，他们会不断地从孩子身上发现问题，并试图以自以为是的方法去改变、改造孩子。这类父母表现得越是积极，结果就越是被动。他们改造孩子的过程相当于一个被动顺从某个游戏规则的过程。

# 门只能从里头打开

如何真正的让一个问题孩子没有问题呢？史蒂芬·柯维提出了一个观点：门只能从里头打开。

很多父母发现问题的时候，总是想用各种暴力、半暴力的方式，比如撞开、撬锁，去把门打开，这都是暴力的方式。非暴力的方式是在房间里头的孩子自己把门打开。

让孩子自动把门打开绝非易事。这就涉及到一对概念，权力和影响力。

权力：当面临一个状况的时候，习惯性的用自己的权力或者说是强权、暴力去改变对象，改变现状。

影响力：是用一种软性无形的方式去悄悄影响对方和场景。随着场景发生变化，对象也会发生变化。

# 例子1：谁能脱下他的棉袜

有一个寓言故事。风想把一个人的棉袜吹下来，结果风越大，气温就越低，穿棉袜的人就会把棉袜扣得越紧。太阳加大它的温度和热力的时候，这个人开始冒汗，最后自己把棉袜脱了下来。

显然，太阳不是用一种显而易见的外力把棉袜从这个人的身上脱下来，它采取的是影响力。

# 例子2：是什么让重刑犯感受到了温柔

在澳大利亚没有死刑，这个国家的重刑犯往往都是在其它国家会被判死刑的人。他们的特点冷血无情，凶残，对人充满恐惧和抗拒，不愿意跟人合作，习惯于用暴力来解决一切问题。

虽然他们在监狱里不可能任性妄为，但是当他们面对警察的时候，仍然会采取极其强烈的习惯性抗拒。因此，传统的监狱没办法改造这样的罪犯，他们在监狱里进行改造的结果不过是强化和固化了罪犯的行为模式和心理模式。最后，这些重刑犯要么一直关在监狱里，要么一旦刑满释放回到社会，还会随时有可能再犯罪。

澳大利亚监狱的管理者发现有一个物种跟这些重刑犯很相似，那就是赛狗比赛中被淘汰下来的狗。这些狗一旦在赛狗比赛中被淘汰，为了保证公众的安全，这些狗只有一个命运，就是被注射药物，实施安乐死。

监狱管理者让这些重刑犯去驯养这些狗。当重刑犯看到狗的时候，他们自然而然的产生了一种同病相怜的亲近感。和这些狗在一起的时候，他们的内心也随之发生了一些奇妙的变化。这些从来没有爱心，没有耐心cover的重刑犯，放弃了习惯的某种抗拒的暴力方式，试图用自己的耐心和爱心去让这些狗变得稍稍的驯服。

《小王子》有这样一个概念：当你去养花的时候，花会反过来养你。因为花会调动你平常很少有的那些耐心和爱心。当重刑犯所有的心思都用在如何与这些狗进行有效的交流合作的时候，自己也在不知不觉当中被驯化。驯化的过程也是被驯化的过程。

这些狗尽管凶残，但是它们有一种信任和依赖别人的天性。一段时间下来，桀骜不驯的狗逐渐变得温顺，重刑犯体会到被狗信任依赖的感觉，也明显变得温顺和有责任感。一个他没有意识到的亚自我被激活，持续激活的过程也就是让他自己都感到陌生的亚自我逐渐的被固化、被强化的过程。他们在狗的身上和自己身上同时感受到了一些平时很少有的状态，那就是驯服。

当这些重刑犯服刑期满回到社会的时候，很少有继续犯罪的。这些人在这场游戏当中不知不觉的获得了责任感，懂得用一种合作、顺从的方式去解决问题。他们放弃了与世界，与他人之间的习惯性的对恃和抗拒，感受到了一种新的，非常有效的游戏规则。所以，他们能够用这种新的游戏规则来与他人和世界相处、合作。

这个案例告诉我们：

# 第一：问题不可能由导致这种问题的思维方式来解决

当问题出现的时候，匆忙的去解决问题可能会强化问题，深化问题。正如爱因斯坦说的，“问题不可能由导致这种问题的思维方式来解决”，或者说问题不可能由导致这种问题的游戏规则来解决。这就需要一种场景切换和场景创新的能力。

# 第二：驯化的过程也是被驯化的过程

任何一种驯化都不是单方面的改造和给予，而是一种双向、互动的游戏。在这个游戏当中，驯化者也同时在被驯化。在他们之上有一个更高的东西，那就是左右协调他们之间关系的一种游戏规则，或者说是一种场景。

# 总结

真正能改变一个场景，一个格局，一个事态的不是权力，而是影响力。或者说，是一种在游戏尚未开始之前，已经确立的在这个游戏的规则之上的一个高维的游戏规则。找到了场景就找到了游戏规则，找到了游戏规则，一种新的局面就会出现。

# ｜税是一种特殊的消费行为

在通常的消费当中，我们购买一个产品或服务，它们和价格之间是一一对应的，但在某些消费场景中，我们没办法准确的计量单次消费的价格，也没办法精确的计算每一个消费者的消费量和频率。在这种情况下，我们就会为某些产品和服务，尤其是公共产品和公共服务定出一个统一的价格。不管你消费的频次和数量是多少，你都用相同的价格去购买，这就是税。

# ｜税与商业模式

eBay就是一种税收模式。eBay是一个开放的交易平台，只要在上头出售自己的产品和服务，就会给这个平台交费。出售的产品和服务越多，交的费就越多。在某种意义上，eBay公司就成了一个税收机构。

还有生产移动芯片的高通公司，把某个技术或产品授权给下游客户，然后下游客户根据售出的产品数量给高通公司交费。这种也是“税收模式”。

# ｜富人税

富人税：很多国家都会对富人征收更多的税，企业也会以某种特定的方式对富人征收额外的费用，从富人身上拧到额外的钱。

杰弗里·摩尔（Geoffrey A.Moore）的营销理论中说，任何一个产品刚开始进入市场的时候，都不可避免的只是针对少数人的。这些少数人为什么会为这些性能很低、价格很高的产品买单呢？

# 例子1：汽车是富人的玩具

汽车刚开始出现的时候，是用手工打造的，看上去就像是一辆没有马拉的三轮马车，只不过驱动这辆车的动力是内置在这辆马车上的发动机。从你订购一辆汽车到最终拿到，要花两三年的时间。

这种看上去跟马车没有多大差别的车，最高行驶速度只有15英里，走起来很颠簸，下雨还不能使用。什么人会买它？富人！因为它是一个代表着未来的、新鲜的、少数人才有特权享有的产品。

富人买车的刚需不是代步，而是显示自己的财富和时尚。他们的这种消费行为其实是一种符号消费：作为一种新符号产生的汽车，是一个富人的玩具。

# 例子2：大哥大是“大哥大们”的身份

大哥大是最早的无线便携式的电话，像一块大砖头，很沉，很不方便。拥有这种电话的人必须要雇一个专门的马仔拿着这个电话，走到什么地方一坐下来，马仔马上把电话从桌子上一敲，以表明“大哥大”的身份。

最开始，必须对方有大哥大，你才能够给他打电话，因此使用这种电话的人非常少，使用频率也非常低。但是，大哥大们为了消费这个作为符号的大哥大愿意付出昂贵的费用。

大哥大进入市场的时候是人民币30000多块钱。30000多块钱在上世纪90年代初可以买一套大约40—50平米的房子。如果用性价比来算的话，当年那样一款外形丑陋，性能很低，体验完全跟不上大哥大卖30000多块钱的话，我们今天的一部5000块钱的智能手机有可能折算成1亿多元。而我们今天居然用1000块钱就能买到这样的产品，我们应该从心里头感谢那些富人。

如果没有这些大哥大们购买，这个电话的市场就没法启动。昂贵的价格保证了第一代产品是有利润的。厂商用挣来的利润继续研发，打市场，使产品的性能不断提高，价格不断降低。当用的人越来越多的时候，价格下降，性能提高。大哥大们用那么昂贵的价格来购买这个产品，实际上是在为这个产品交税，也就是“富人税”。

# 例子3：幸好这世界上还是有一些富人的

在传统的消费领域里也存在着富人税的问题。比如说头等舱也包含着富人税。对一个手头没有多少钱的人来说，从A地到B地是他所有的诉求，至于座位是否宽敞，餐食是否高档，空姐是否漂亮等等，可以说都是细枝末节。但是，有一些人为了这一点点细枝末节，为了那1%的性能，他愿意多付出了1倍甚至2倍的价格。他多付出去这个钱，就是富人税。

特斯拉刚刚投入市场的时候，只有很少的人来购买车。它的第一批用户是硅谷的那些非常有钱，崇尚环保，崇尚高科技，对性价比不敏感的人。正是由于这些人为这个刚刚问世的产品交了富人税，才使得这个产品能够一步步成长起来。

# ｜穷人税

穷人税是指，高端消费者不会问津，专门针对低端消费者，也只有低端消费者感兴趣，愿意购买的产品。这些产品的价格很低了，但是它的利润率并不低。

# 产品的性能和价格的“二八定律”：

一个产品，在使用时，最常用的功能占到了80%，不常用的功能占到20%；而在成本结构上，不是不是这样的。比如说电脑，主要使用功能是打字、编辑文档，用很低的配置足以实现了。但是在成本结构上，那些不常用的功能，可能需要很高的配置。这种情况下，你去掉不常用的那20%的功能，产品的价格就不止降低一半了。

因此，即便在电脑很贵的时候，定价在2000元以下的大学生电脑也是可以实现的。这其实也是因为遵循了：低端破环迂回。

一家以“低端破环迂回”做电脑的公司提出了“鞋底鞋帮理论”和“炸弹理论”。

# 鞋底鞋帮理论：

一双鞋的鞋帮坏了，鞋底没有坏，那这双鞋的成本结构是有问题的。作为鞋类产品，鞋底再结实对于消费者是没有用处的，结果成 proofs... 如果鞋底坏了，鞋帮没坏，那么鞋帮就成了冗余性能。最好的状态是鞋帮和鞋底一起坏，那么这个产品里头就没有冗余性能，也没有冗余成本了。

# 炸弹理论：

打牌的时候，如果抓到一个3，你会觉得很沮丧；抓到2个3，心情会好一点；抓到3个3，心情会非常好；抓到4个3，心情会大好。

一个低端的零部件不值钱，但如果所有低端的零部件凑到一起，就会形成一个价格炸弹，产生一种整个产品的价格大大低于同类产品的价值，在市场上就会有非常强的竞争力。

消费者以便宜的价格购入他认为够用的产品，厂商获得了不低的利润。这这“低端破坏产品”，或者“低端镶嵌产品”，就是以向穷人收税的方式在赚钱。

在设计商业模式的时候，要搞清楚，这个产品进入市场是向富人收税，还是穷人收税。如果一个产品既不能向富人收税，也不能向穷人收税，那么它进入市场的前途是令人忧虑的。

吴伯凡

听完今天的分享，大家可以举几个例子，想想那些出现在你脑海里的产品或者品牌，它们哪些收的是富人税？哪些收的是穷人税？哪些因为既收不到富人税，也收不到穷人税，只得自己给自己交税，最后悄悄的从市场上消失了？

# 本周问答 | 静是一种能力

![](img/d67c5f056bd8085d4e954a23126b5c83_28_0.png)

本周问答 | 静是一种能力

这个前提行为是不是一种通用的应对策略？亦或是“对未来的，各种可能性合理估计下的，提前的内心预演？我觉得这种反转局势的本事，要求当事人内心非常强大。有点冒犯的问一句：老师举的例子，好像都是小说或者戏剧里的，就像现实不完美，理想情况都只存在文学塑造中一般。现实生活中有这样大智慧、超主动的例子吗？

吴伯凡

我们讲的“前提行为”不是一种普遍的应对策略，更多是一种应急时候的应对策略。保持超常的主动性，遇事操之在我，可以说是一种普遍的应对策略。为了描述的生动，我举的是一些文学作品当中的例子，在生活种这种例子也很多。

在以前的《伯凡·日知录》里，也提到过一些跟“前提行为”有关的例子。比如“幽默”在一个企业里头的作用，讲到的是海涅在独木桥上遇到了一个甚跟他作对的许莱格尔。许莱格尔说：“对不起，我从来不给白痴让路。”海涅轻松一笑说：“对不起，太巧了，我和你正好相反。”然后就给许莱格尔让了路。

还有一个这两个人之间的例子，有一次许莱格尔在沙龙上看见海涅走进来，就提高了嗓门说：“前几天我去了西西里岛，西西里岛真是一个好地方，那有几乎有全世界所有的动物，但是只有两种动物没有，一样是驴子，一样是犹太人。”因为海涅是犹太人，许莱格尔想借此羞辱他。海涅听后还是开心一笑，说：“那太好了，哦天我们一起去西西里岛，那儿的动物就不全了吗？”这是海涅的幽默，也可以把它理解为一种“前提行为”。

我还讲到过一个著名企业家的例子。有一次他邀请了一批客人，其中有一个人有一种天生的自恋，他抢着说话，不停的讲他自己的过去的经历。在这种尴尬的情况下，这个企业家通常只有2种选择：1. 听任这个人在那儿自吹自擂，自恋的进行表述，形式孔雀开屏的职能。那就意味着浪费大家的时间；2. 打断他说：你不应该总是讲自己，你应该留时间给别人。

以上这两种选择都是不好的。这个企业家就非常主动的进行了第三者选择：当这个人讲到他曾经在花旗银行工作怎么怎么样的时候，这个企业家马上说“花旗银行！太好了！我们曾经跟花旗银行有非常成功合作。”然后他就比较详细的讲了他们公司如何跟花旗银行合作的。从这个企业家的讲述中我们能够感受到这家公司的文化、战略、商业模式到底是什么。这也是一种前提行为。

简单的说，前提行为是不会与对方进行正面的冲突，也不会简单的顺应对方，而是找到了一种操之在我的游戏规则，做自己，控制眼前的这个局面。

关于这个问题，我们下周还会有进一步的阐述。

前提行为，我理解，一是处事不惊，平静对待一切突然发生的事情。所谓静能生智。只要能做到这点，余下的局面应该可以操之在我，兵来将挡，水来土掩。二是充分站在对方角度考虑问题，或者说，把对方所做的一切往善的方面理解，比如，他用枪对着我并不是本意，是有误解，或者被指使等。但一般情况，我碰到类似情景头脑发热，无法保持安静智慧状态，所以想请教老师和大家，如何能在非常状态让自己保持“静”？谢谢！

吴伯凡

很多书都在教我们如何静，如何静能生智。这里有一种误导。
