# 9.4 | 积极的悲观主义者

9.4 | 积极的悲观主义者

# —— 第189天的知识笔记 ——

# | 得不到是不幸，得到了是灾难

上周我们讲到了“幸运”的话题，这周我们换个角度，谈谈“不幸”。毕竟在我们生活当中，人生不如意的事情十之八九，如意的事情十之有二。

你一心盯着幸运事情的时候，就会发现，生活中有太多的不幸了。反过来，如果我们换一种逆向思维，认为人生本来就是各种不幸，偶尔会遇到幸运事情的时候，我们遇到问题可能就不会那么焦虑，那么挫败了。

最近我读了一篇文章，是一个人写他的苦恼：这个人一直想升职，突然有一天，他升职了，本来以为梦想以求的事情终于实现的时候，面对的却是他完全没想到的局面——过去很好的同事，包括平时关系很好的哥们儿、姐们儿一下子对他冷漠了，以前合作很好的同事也纷纷表现出很消极的应付状态，以至于他新官上任，一下子显得自己特别无能。这个人想了很多办法都无法改变这种局面。

这个人面对的其实就是王尔德的悖论：人生有且只有两大悲剧，一是得不到我们所要的东西，二是得到了我们所要的东西——得不到是不幸，得到了有时会是灾难，这是我们常常会遇到的场景。

# | 麻烦守恒定律

什么叫童话？童话就是在故事的结尾总有这么一句诗：从此，王子和公主过上了幸福的生活。

而真实的故事是：王子和公主过上了幸福的生活，从此……所以钱钟书先生说，《红楼梦》讲了宝黛不能终成眷属的悲剧故事，如果它有下一部，那就是宝黛终成眷属的另一个悲剧故事了。

有一个管理寓言，叫“地毯下的蛇”：一个人在铺地毯的时候，发现地毯总是不平，他一气之下就把地毯从地上揭了起来，发现下面有一条蛇——寓言真正告诉我们的是，在不清楚有蛇的情况下，你总会有层出不穷的麻烦，只有把这条蛇清除了，麻烦才会消失。

其实这个故事有一个误导，那就是：管理不是把蛇清除之后一切就都万事大吉了。地毯是铺好了，接下来的你在哪桌子、摆床的时候，又会出来各种各样的麻烦。

我有一个我自创的定律，叫“麻烦守恒定律”：当我们消除一个麻烦的时候，常常也是在给自己制造新的，甚至更大的麻烦。

# 不断消除&不自觉制造

“何处是归程？长亭更短亭。”——作为一个管理者，你要切换一种心态：管理就是“不断消除麻烦”和“不自觉制造麻烦”。

这种情况，哲学家庄子有一个很经典的论述：

> “事若不成，则必有人道之患；事若成，则必有阴阳之患。若成若不成而后无患者，唯有德者能之。”

就是说，当事情不成的时候，会有显而易见的麻烦摆在你面前；当事情成了之后，你会面对一种一直隐藏的，现在突然显现出来的、更复杂、更难解决的麻烦。只有那些有德者，也就是高手，真正的高手，才能做到事情成了但没有后续的麻烦。

这就解释了我们刚才说的那位升职者的烦恼：当他目标明确，也就一心想要升职的时候，他的问题也很明确——如何做出业绩，然后他会跟自己同等级的人齐心协力，好好合作，做出业绩得到领导的赏识和提拔自己。做到这些应该说不容易，但是这还是小困难、小麻烦。

升职的问题一旦解决，一个全新的场景和格局就出现了，这里加入了多种新的要素，态势发生了变化。

生态学讲的是各种生物个体之间、种群内部的态势关系。你觉得麻烦突然出现，是因为你不知道一个变量的出现会导致新的场景，这种场景就是“阴阳之患”——以前是隐藏的，但它更深刻地影响着整个格局。一旦把“阴阳之患”解决的时候，也就相当于你打怪通关了以后，接下来新的这一关麻烦更大，相信玩过游戏的同学都会很有感受。

# | 无穷的后患

我们经常说这事处理不好，后患无穷。现在，我们应该学会“这事处理得好，后患无穷”。这种“后患”的特点是：

+   第一，它是从0到1突然出现的。当然，实际上它不是突然出现的，只不过是从隐性的状态变成了显性状态。

+   第二，解决这种麻烦的难度比你想象的要大得多，它更复杂。

打个简单的比喻，你前面遇到的麻烦是应用软件的麻烦，当你把这个应用软件层面的问题解决以后，你发现进入了操作系统的麻烦——也就是对整个场景产生深刻实质性影响的那种因素，你解决它要付出巨大的努力。

这时候，挑战你的往往不是有没有付出多大努力的问题，而是你有没有用一种新的思维和行为方式来与之相适应。比如，面对升职以后出现的种种麻烦，你用过去对待平级同事的那一套方法，请人喝冰激凌、时不时请人家吃饭、买个小礼物等等，是没办法解决的。

# | 麻烦增加定律

作为一个管理者，或者一个在职业生涯中要不断进阶的人，应该明确的一个法则是：麻烦不仅守恒，而且增加。

王熙凤说得好：“小有小的凄凉，大有大的难处。”当你的能力只是来应对那些小问题，并且做出成绩的时候，这本身就隐含着一种麻烦——你的能力缺失。这也从另外一个角度揭示了“彼得原理”：如果一个公司在激励选拔人才的时候，用“你干得好我就给你升职”这样一种方法，最终的结果是这个人一定会被提拔到一个他胜任不了的位置上来。

这样看来，奋斗就是“自己成为自己麻烦的制造者”——你奋斗就是要解决各种麻烦、消除各种障碍，让自己进入到新的天地、新的境界。而这个你通过奋斗创造出来的新天地和新境界，就是一个遍布着你意想不到新麻烦的场景——太平日子不太平过，你非得要往上升，升到了一个你的能力也许可胜任不了的位置上。

# | 做积极的悲观主义者

这样说不是在打击奋斗者，我们总是要奋斗的，而作为一个奋斗者，一定要具备一种心智模式：做一个“积极的悲观主义者”，而不是要“消极的乐观主义者”。

“消极的乐观主义者”思考问题常常遵循这样一个句式“要是怎么怎么样就好了”，他们相信世界上有一劳永逸的事情，相信世界上所有的麻烦是来自于眼前的某些障碍，而一旦障碍消除，就会进入人间乐土。而那是不现实的，所以才是“消极的乐观主义者”。

“积极的悲观主义者”则认为这个世界，或者生活的世界本质上是悲观的，是동의、麻烦随时在侧、层出不穷、别开生面的。种种制造麻烦的事情，千脆被他们想象成为一个雷区，生活和工作就是一场排雷游戏，你把这一关解决了，下一关等待你的就是更多的、更隐晦的雷，还有各种要你性命的陷阱在等着你。有这种心态的，就是“积极的悲观主义者”。
