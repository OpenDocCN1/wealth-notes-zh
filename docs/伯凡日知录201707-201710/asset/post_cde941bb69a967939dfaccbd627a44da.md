# 1.重拾智能手机的诺基亚

不久前看到一条新闻：诺基亚准备推出自己的智能手机。

最早的智能手机其实就是诺基亚做的，只不过没有做好那个倒霉的CEO斯蒂芬·埃洛普(Stephen Elop)的话说就是：“我们什么都没做错，但是我们失败了。”--今天，诺基亚“在哪儿跌倒，还要在哪儿爬起来”，它又要重新开始做智能手机了。

这个新闻让我想到一个段子：

某人当年因为犯罪被抓了起来，咬着牙不交代，而且态度很不好，瞒骗了很多犯罪事实，被判了很重的刑。十几年后，他刑满释放出来，找到了自己当年的小兄弟说“我熬了这十几年，一直等着这一天，我们要发财了！”然后就找到一个地方，挖出一个箱子，里面装满了BP机——当年，这个人他死活扛着不交代的事，就是他一直等到出狱这一天，把这一箱子BP机卖很多的钱。

要知道，十几年前，连一个BP机能卖4000多块——这也印证了中国有句话“时来铁成金，运去金成铁”。

诺基亚重做智能手机，我不太看好，原因昨天已经讲了：手机这一行业正处于“上一个时代的尾声，下一个时代的序幕”，如果你因为当初的失败耿耿于怀，要恢复昔日的荣耀，那很可能是一件荒诞的事情——即使你把它做得再好，它也已经是一个要灭绝的物种了。

# 2.结束昨日战场的IBM

二十多年前，IBM当时的CEO郭士纳上任以后说，通过他的观察，IBM这家以做PC著称的公司，一定要放弃PC以及相关业务。为什么呢？郭士纳有一句话很经典——我要结束这样一场属于昨日的战争。

的确，即使这个战争继续打，你也只能打出暂时的辉煌。这有点儿像我们看过的一部电影：日本天皇已经宣布投降了，但是有一小股日军不知道这个消息，还在继续抵抗——这是一件很可悲的事情。

现在的一些企业，虽然日子过得不好，但还是重振旗鼓，还在奋力地抗争，说到底，他们在从事的是一场“已经结束的战争”。

# 3.冒险式创新的惠普

这个话题让我想到一家企业，直到今天，去硅谷参观游学的人，不管时间多紧，恐怕还是要到当年惠普创业的那个车库去照一张相——那是硅谷的象征。

![](img/d67c5f056bd8085d4e954a23126b5c83_137_0.png)

你有多久没听说过惠普了？这的确是一家令人唏嘘的公司。实际上，惠普最近还有一个很好的消息——重新成为了PC业的老大——但意义好像已经不大了。

惠普是硅谷的象征，在IT产业，它一度是创新的代名词。今天惠普的状况可以用一个管理学家的話来形容：一些企业在新的游戏规则中，即使没有马上消失，也已经逐渐变得无关紧要了。

早在七八年前就有人分析过“惠普是如何从一家领袖型企业变成一家无关紧要公司”——惠普的创新能力和创新体系之间有一个非常大的冲突，一方面，惠普是一家很能创新的企业；另一方面，它也是一家没有创新体系只有创新行为的公司。

细数起来，惠普一直在进行各种各样的创新——有人给这种创新取了个名字，叫“冒险式创新”——在公司里，不断有各种各样的创新，今天这个人冒泡儿有个创新，明天那个部门又冒了一下泡……整天就在看见公司里不停地在冒“创新的泡儿”，但最终，惠普没有一个创新能力。

有“硅谷教父”之称的杰弗里·摩尔（Geoffrey A. Moore）用了一张图来说明这种“冒险式的创新管理”。

![](img/d67c5f056bd8085d4e954a23126b5c83_137_1.png)

一张纸上画着有很多的箭头，箭头分别指向各个方向，结果是：等式的右边等于0。

数学老师给我们讲过“向量叠加”的知识：“向量叠加”跟普通的加法不一样，普通加法是各个加数之间的差异不构成问题，它们累加起来形成一个总的得数；而向量叠加是互相抵消的，不同方向的向量加起来就是0。

惠普就是这么一个增长于“冒险式创新”，当然也就相当于“不善于创新”的公司——一个没有创新体系，只有很多创新行为的公司，它的结局就是今天这个样子。

# 4.徒有点子的点子大王

“冒险式创新”本来是一个企业管理、创新管理的话题，但它也跟我们的个人管理有关。

我们生活中经常遇到一些点子大王，他们有各种各样的点子，东一个点子，西一个点子，脑袋特别的灵活。在具体某件事情上，点子大王们总有一些新的想法，但多少年接触下来，你会发现这些人并没有做出什么东西出来，或者说，他们的知识很丰富，会吸收各种各样随处出现的新知识，但这些多向量的知识最终没给他们带来真正认知上的增量，最后的结果很可能是0，或者约等于0——做认知升级的时候，我们不要去做“冒险式”的学习。

# 5.金字塔原理

有人会说“现在是一个知识爆炸，强调跨界、无界的时代，如果你的心智只集中在某一个狭小的范围内，很可能被淘汰”。

这话当然没错，但这里隐含着一个问题：如何协调创意的多样化和专业化——在“乐高式”创新时代，一方面要尽可能增加更多的积木；另一方面，又要避免这些积木杂乱无章，最后什么都拼不出来，这是一个很明显又非常重要的问题。

![](img/d67c5f056bd8085d4e954a23126b5c83_137_2.png)

《金字塔原理》这本书是麦肯锡公司（McKinsey&Company）的一个顾问写的，书上一直保留着一个专家写的推荐语“不读这本书的机会成本非常高”。

进到麦肯锡公司是必须 要接受这种“金字塔原理”培训的，冯唐在麦肯锡就接受了这种培训。培训以后他说“其实用到100个字就能概括这本书的内容。”

冯唐是这样概括的：任何一个观点都同时包含着3~5个支持性论据，而每一个支持性论据又都同时包含着3~5个支持性论据。如果层层这样细分下来，无论一篇文章也好、一本书也好、一个观点也好，都内含着一个金字塔的结构——很多人的观点要不是就是“不清晰、杂乱无章”，要不是“缺乏深度”，原因就是，他们的观点中没有内含着一个金字塔。

举一个简单的例子，每一天的《彼凡·日知录》的内容都可以一句話来概括，但是这一句话就包含着3~5个相关的论点和论据，然后这3~5个相关的论点和论据又可能包含着3~5个……这样推演下来，就是一个金字塔的结构。

当然，在每天十几分钟的时间里，不可能不断地把这个金字塔往下延伸，但是如果有...

不断地把这个金字塔往下延伸，但如果有时间的话，它可能会延伸出一本书，没时间的话，金字塔结构的层级就会比较少——一篇文章和一本书的差别，首先就在层级，以及每一层级的支持论点和论据数量的多少上。

当我们对一个人，或一个企业的知识、创新能力进行梳理的话，也都可能画出大小不一的金字塔。而当我们看到这个金字塔之后，第一感受到的是各种各样的论点，这些论点之间是有层级性的。有时候，论点与论点之间好像没有任何关系，但是它受制于这个金字塔结构——只有这样，才可能是一个相对完整的知识体系，或者创新体系。

回过头来看惠普的“冒泡式创新”：它的点很多，但是没有形成优先级，没有形成一个金字塔结构。所以，惠普的整个创新呈现一种“散结构”，而不是形成一个金字塔。

我们今天的“认知升级”，一方面要接触各种各样的知识，避免知识的单一化，追求知识的生物多样性，否则没法应对这个时代；另一方面，所有的知识点必须是在一个金字塔的框架里——如果你的知识点缺乏这样一个金字塔框架的话，那就很危险，你很可能做的是一个徒劳的工作。

“管理”有很多的定义，其中一个是“管理是去掉一切不创造价值的环节”，还有一个定义：管理就是创建优先级。

我们说“一个公司缺乏管理”，其实就是这家公司的行动没有优先级，而我们说“一个人的知识缺乏管理”，就包含两个含义：

第一，知识点中有太多创造价值的环节；

第二，从另外一个角度看，就是“知识之间没有优先级”，不是在一个隐形的金字塔框架下放置不同的知识点，知识变成了纯粹的碎片。

今天是一个“碎片化时代”，无论是知识还是学习方式，都呈现出“碎片化”的特点，你想在这个碎片化时代胜出，唯一的方式是为你的碎片化学习和碎片化知识建立一个金字塔结构。

吴伯凡

今天讲到“金字塔原理”的一个初衷，是希望大家学会用“金字塔原理”来检测和管理自己的知识。大家可以做两个练习，其实也是“合2为1的练习”：

先问自己一个问题：

面对这样一个充满着变化和不确定性的时代，我有什么观点是与众不同的？

练习一：

1.把自己能想出来的不同之处写在纸上，认真多看多想一会儿，可能就开始怀疑自己的这个观点到底有多少“与众不同”，就有可能开始怀疑“我的这个观点也许没有什么与众不同”；2.把这个观点在百度搜索一下。

练习二：

如果真觉得自己的这个观点还是“与众不同”的，那么开始分解3~5个知识性的论点和论据，然后接下来再分再分，分到一个有3~5层的金字塔。

如果这个金字塔能够在纸上写出来，证明你的知识是有成色的。当然，这只是一个检测，大家以后可以把它作为一个固定的知识管理方法，经常性地来检测自己。

# 领导力和管理力的区别是什么？

吴伯凡

+   1. 正确做事 & 做正确的事

“领导力”是一个固定的词——leadership，“管理”我们都称为管理能力。德鲁克对领导和管理有个经典的区别：“领导”，就是做正确的事情；“管理”就是正确地做事。

简而言之，“领导”是在众多可以做的事情当中确定该做哪些事情，所以领导力本质上是一种取舍的能力——表面上是确定该做什么的能力，背后是确定哪些不值得做的。哪怕很有诱惑、马上有利可图的事情都不去做。做真正重要和正确的事情。管理者所需要的能力是如何把一个已经确定的事情做到最好，所以讲“好”，就是成本最小化、效果最大化。

+   2. 方向感 & 驱动力

IBM 前 CEO 路易斯·郭士纳 (Louis V. Gerstner) 对领导力有一个定义，他认为“领导力”包含两个方面：方向感和驱动力。衡量一个领导者有没有领导力就看这两方面的能力。

方向感：在大家都不知道做什么，或者大家对该做什么众说纷纭的时候，领导者有一个方向感能够判众议，带着大家朝正确方向走。

驱动力：当你确定了一个方向，大家都沿着你确定的方向走的时候，你要尽可能提供各种各样的支持和资源，用物质的、精神的、多维度地能量支持大家朝那个正确的方向去做事。

+   4. RPV理论

+   5. 领导力 ≠ 营销力

吴伯凡

关于“领导力”和“管理力”我有一个比喻：领导力是操作系统，管理力是应用软件。

一个手机上应用软件能够顺畅运行，取决于背后的操作系统。打开手机，其实是在使用操作系统——IOS、安卓无时无刻不在运行，但我们往往感受不到它的存在，我们觉得我们用的是那些应用软件，但应用软件能否顺利运行，取决于背后的操作系统能否将整个计算资源做到最优化、最合理的调配和使用。

一个领导者也是一个无我主义者，他输送资源、他鼓励谁都不是根据个人的偏好，而是站在组织和团队整体的角度来看待、来使用、来分配资源的。

中国古人讲，对待孩子要“爱之而勿面”，领导者应该做到“爱之而无勿面”，尤其忌讳把个人感情带入到他作为领导者分配资源的过程当中。如果是这样的话，领导者就会不知不觉变成部分人的领导，而不是所有人的领导，从而使整个组织的资源和能力出现越来越严重的内耗。

领导者具有这样一种等距离的能力，他对待所有人的态度都应该是公正对待，他给某个部门或者某些人分配更多的资源，不是因为他喜欢，而是从组织的角度来看，应该是这样分配的。

总而言之，领导者是一个组织生态的建立者和维护者，他有一个非常重要的责任：维持整体生态的平衡。领导者最忌讳的是他放弃了他作为操作系统的建立者和维护者的身份，放弃了自己作为“看不见的手”这样一个角色，而让自己成为一只“看得见、闲不住的手”去插手各种各样具体的事务，用个人的偏好去决定组织的方向和资源分配。

# 预告｜深度剖析“隐性玩家”

上上周我们讲了“隐性玩家”这个概念，很多同学都很感兴趣，在留言区写了很多自己关于“隐性玩家”的感悟和理解，说得都不错，但是在理解上也有一些偏差，这是因为我讲得不够深、不够细。本周我会展开“隐性玩家”这个话题，深入地分析一下：“隐性玩家”到底指什么？“隐性玩家”是如何深刻影响、改变人类历史发展进程的？“隐性玩家”这个概念以及它的相关思维方式，对我们的生活和工作有什么样的帮助？

# ｜“隐性玩家”的真实案例

第一天我会讲到历史上发生的三个真实案例，我们可以更生动具体地感受到“隐性玩家”是什么，以及它的力量有多大。

在俄罗斯的历史上有两次痛苦的经历：一次是被拿破仑入侵，一次是被希特勒入侵。但无论是拿破仑还是希特勒，最后都以惨败告终，原因到底是什么呢？俄罗斯在与外敌抗争的过程中，始终存在的那个“隐性玩家”到底是什么？到底有多神呢？

道光皇帝的两个儿子，四皇子和六皇子都有可能成为皇位的候选人，其中的六皇子，也就是“鬼子六”，能文能武，足智多谋，却在一场关键的竞争当中被淘汰出局。能力上明显比“鬼子六”差一截儿的四皇子，后来的咸丰皇帝，是如何绝处逢生的？“鬼子六”又是如何阴沟里翻船的？这里有一个很有意思的故事。

通过这3个案例，我们就更能知道什么是“隐性玩家”，“隐性玩家”出手的方式以及出手的能量有多大了。

# ｜能量包

第二天我会讲一个概念——能量包。

“能量包”听起来有点儿陌生，但它影响了人类历史，在人类历史上扮演了非常重要的角色——这一点我会详细地解释。现在可以告诉大家的是，电池就是一个能量包。

有人认为“电池是人类历史上最重大的发明”，也还有一个听起来非常离奇，甚至有点儿怪诞的说法是：人类历史上最重大的发明是干草，也就是晒干了的草。为什么呢？

在古代行军打仗的过程中，马是非常重要的交通、运输、作战工具，而马必须吃草。在那些没有草的地方和季节里如果要打仗，就必须带大量的干草——这些干草就是一个被压缩的能量包。电池也是这样：对于移动电器、数码产品，电池的重要性不言而喻，很多设备的竞争说到底是电池能量包的竞争，也就是电池能量密度的竞争。

这节课我想说的并不只是战争。人类历史的整个进程当中，无论是商业还是军事，以及国与国之间的整体较量中都有一个很重要的因素——能量包——在一直发挥着重要的作用。我还会讲到一个航海史上非常重要的案例，荷兰人就是凭借着一种特殊的能量包成为了“海上马车夫”，在大航海时代称霸全球。

能量包有各种各样的，甚至压缩饼干、午餐肉都是能量包——这一节的内容让我们增加了一个观察历史的新角度，同时也能生动地感受到历史发展的细节。

# ｜造型玩具

第三天我要分享的是：有了“隐性玩家”意识能给我们带来什么样的改变？

有一个朋友最近给我介绍了一种我看不懂的玩具，这种玩具没有任何实际用途，看上去也不好玩儿，它只是一个摆件，单个价格是人民币40多块钱，集齐一套可能要五六百块钱，甚至是超过1000块钱——这个叫“造型商品”的新物种非常的火。

我以前面对这种现象的反应是心生疑惑甚至是抵触，但当我更清晰地领会“隐性玩家”这个概念的时候，我就懂了：如果你不理解一个东西，很可能是因为你忽略了在其中起关键作用，但你又一无所知的东西——造成我们大惑不解的，通常是我们的盲点。

披头士乐队有一句著名的歌词“一定发生了什么事情，到底是什么事儿现在还说不清”——对于看不懂的事物要有足够开放的心态，同时试着去发现匪夷所思现象背后那个我们不知道的原因。

# ｜皮草改变世界

第四天我要讲的一个案例也跟“隐性玩家”有关，是一种奢侈品——皮草。

皮草这种好像很小众的产品，在历史上扮演的角色可非同小可。可以这样说，皮草改变了欧洲大陆，甚至美洲大陆的政治版图，深刻影响了商业史和经济史。我们经常看到这样的标题“XX改变世界”，比如“啤酒改变世界”“八音盒改变世界”等等，这节课我要和大家感受一下“皮草改变世界”。

世界上曾经出现过两个超级大国：苏联和美国。这两个国家的国土面积， 国家之间的对峙、对抗关系都跟皮草有着隐秘但非常密切的关联。总之，这一 周我会通过各种案例、历史发展的关键点，来详细解读“隐性玩家”这个概念，让大家看到历史和商业、军事事件当中最生动、最有趣的细节。
