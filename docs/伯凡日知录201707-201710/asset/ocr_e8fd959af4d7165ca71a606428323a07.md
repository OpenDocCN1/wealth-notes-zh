# 丨“人是生活在自己编织的意义之网上的动物”

以前看“创新”仅仅是看创造发明了什么，现在看“创新”更多是看利用已有的资源进行排列组合产生新的功能。就如人们以前会把怎么吃也长不大的猪杀掉，而现在食物充足了，这种猪经过一系列概念的包装成了宠物圈的新贵，完成了一种从食物到宠物的转型。所以，所谓的“创新”和“新物种”也不一定得是新的事物。旧的事物在新的时代背景下功用发生了变化，就算同样东西在新时代也可以被赋予新的意义，成为“新物种”。就如古代民用陶瓷如今很多成了古董收藏，同样的东西不同时代背景，几乎就是两个物种。也许这就是为什么说：“人是生活在自己编织的意义之网上的动物。”

吴伯凡

这个引申很好地概括了“新物种”产生的真正原因。

地球上最早出现的物质还不是物种，它们往往是单原子结构。后来由于元素种类增加、场景的复杂，使得地球上出现了各种各样指数级增长的物种，它们都是化合而成的。所以在这个意义上，“新物种”越往后越显出一种化合的状态，因此我们今天看到新物种不再是单一要素、功能的承担者，而是多种要素、功能的化合 molecular。

# 丨“天下万物生于有，有生于无。”

鸵鸟在遇到危险的时候会把自己的头埋到沙子里去，这不是因为鸵鸟傻，也不是因为它害怕，而是通过把头埋在沙子里去可以准确地侦察敌情，通过沙子的震动来判断敌人的力量和距离，以便做好应对策略。一个生物的习性和生长模式，主要取决于它的性状组合，而这些性状又是环境所孕育的，物种的进化与演变，都有基因内部最根本的模式，也就是一系列生存策略暗码，无论是杀鸡榜借功乌... 老子在《道德经》中所说：“反者道之动，弱者道之用。天下万物生于有，有生于无。”
