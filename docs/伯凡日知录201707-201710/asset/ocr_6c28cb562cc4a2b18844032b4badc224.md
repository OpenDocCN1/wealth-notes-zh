# I App不能用之谜

前几天我一个朋友给我打电话，说他推荐的一个语音输入软件本来挺好用的，你这话说话它就能够直接把语音变成文字，但居然不能用了。我问他现在在什么地方，他回答刚搬了家，在家里。我一下子明白了，我说，是不是你家的网还没有装好呢？这个语音软件必须联网才能使用，一旦不能上网，这个很好用的软件就不好用了。

这件事让我想到了一個问题，我们人体的很多动作，表面上是受我们自己的意识支配的：我想拿个东西，我的手就伸过去。但在这个过程当中，其实有大量的行为不是由意识控制的，我想让我的手伸过去是一个命令，但手怎么伸过去是需要大量运算的。我们身体进行的大量运算是我们自己感觉不到的。

# I 简单动作背后的复杂运算

医学上有一个案例，一个叫沃特曼的人，他的大脑神经遭受创伤以后，部分的潜意识感知功能就丧失了。在医生的指导下，沃特曼经过多年的练习，终于学会了怎么使用他的手和腿，就是用意识给自己下一个命令“我现在要迈右腿”，等右腿站好，再下一个命令“我现在要左腿”。沃特曼必须看着自己的右腿迈出去以后再下命令左腿，然后用意识来控制迈左腿。这听起来非常费劲，但是经过长期的练习，他学会了。
