# 预告｜重新解读助推理论

今年的“诺贝尔经济学奖”名单公布之后，理查德·塞勒(Richard Thaler)受到了大家的关注。我自己也有一些小兴奋，因为在过去一年的《伯凡·日知录》里，我们曾经多次讲到他的理论：禀赋效应、助推、损失厌恶等等——本周，我会从另外一个角度给大家重温一下nudge（助推）这个概念。

# ｜助推与间谍法则

“助推”的本义是“用胳膊肘轻轻碰你一下”，它是一种反干预的思路，但又不是让你放弃最终的控制，而是让你自愿地达到我所要你达到的目的。

本周的第一天，我会从“间谍法则”的角度来解释“助推理论”。

“间谍”是大家都非常羡慕和崇拜的一个职业，男生女生都很喜欢看这一类的书和电影，但最好的间谍不只是刺探情报，还要影响敌方的决策：他们首先确定一个目标，这个目标是“希望对方能得出一个结论”。之后，间谍会通过不断给对方各种能得出这种结论的碎片信息，预埋各种兴奋点，制造各种惊喜、细节等一系列“精心策划”，让对方在“完全是偶然”的情境下获得这些机会和信息，以为是“自己费尽了辛苦得出的一个结论”。

这个“自己得出的结论”也涉及到“禀赋效应”：人对自己得到的东西会特别珍视——虽然我们知道，这个结论是间谍预先设定好让对方得出的。

“间谍影响对方决策”的过程不仅跟如何写好一个故事有关，还跟我们以前讲过的“第三选择”、“禀赋效应”、“灰度理论”以及“领导力”都密切相关。第一天，我们会详细分析“助推”与这些概念之间的关系。

# ｜助推与开明家长制

有同学问：助推是不是就是领导者用的套路？我认为不是这样的。

首先，“助推”虽然有“套路”的成分，但又不能完全说是“套路”，因为“助推”需要高度的主动性和积极性，仅仅用既定的套路是会被别人识破的。

其次，“助推”也不是领导者专用的——每个人都可以用“助推”，小孩可以对家长用，下属可以对上司用，自己也可以对自己用。

我会讲到一个中国古代的故事：一个小吏如何利用“助推”改正了上司的错误，并得到上司的赏识。

我们常说“最难的管理是管理自己”，因为这是一个没有边界的管理，管理者和被管理者都是你自己。

很多人可能都经历过这样的过程：

+   看了一些心灵鸡汤的书之后，要给自己和解，要放任自己，让自己过得舒服一些儿，不要那么拼；
不断放任自己的时候，问题越积越多——放任的过程是一个让自己更累，各种麻烦不断堆积的过程；
有一天突然受不了，发愿要重振旗鼓，给自己制定了一个严格的章程和计划；
坚持了几天就坚持不下去了。

如何实现“自我管理”和“灰度”、“助推”有关。本周的第二天，我要讲的是“自我管理”的“助推”——我们如何用“助推”，也就是那种温和的“家长制”，温和的“专制主义”，看不见的强迫来被管理者——我们自己悄悄就范，达到目标。

# ｜Giver和Taker

公司人事管理、员工激励都是“管理”非常重要的话题。华为公司有一句听起来非常有魄力的话：给员工加薪就是占员工的便宜。

我们经常看到这样的事实：给员工加了几千块钱的薪水，他也许就有千劢儿，就会创造远不止几千块的价值——这样看来，给员工加薪确实就是“在占员工的便宜”。但我现在认为，这句话也应该有些限制条件——这个限制条件就是我们第三天要讲的话题：你的员工是一个giver-给予者，还是一个taker-索取者。如果不分青红皂白给员工加薪，很可能最后起到的就是负激励的效果。

这里还涉及到一对数学概念：标量和矢量。我们在业绩考核和员工激励的时候，往往只关注标量，也就是“只有大小，没有方向”的量，但实际上，我们更要关注“既有大小，又有方向”的矢量——这可以说是目前人力资源管理中的一个盲区。

什么是索取者，什么是给予者？矢量和标量跟人事管理有什么关系？一家公司应该招什么样的人，激励什么样的人，又惩罚什么样的人呢？

本周第三天，我会通过两个故事来给大家解释这些问题，让我们对激励以及相关激励当中的“标量和矢量”有一个比较新的认识：

+   1. 我亲眼见证过的事：一个转业的武警用了6年的时间，从保安做到了副总裁。
2. 来自《圣经》的故事。

# ｜外包是怎么来的

我们经常说的“外包”是管理学上的一个概念。今天，无论工作还是生活，“外包”对我们的重要性越来越不言而喻，甚至家庭中也出现了越来越多的“业务外包”，以至于有人说“家庭已经出现了空心化的局面”。

“外包”看似是一个非常老的管理概念，其实它进入“管理学”的时间还不到40年。最早的“外包”起源于医院管理当中，第四天，我会比较详细地告诉大家“外包”这个概念是如何形成的。

虽然“外包”的概念是新的，但是“外包”的行为和事实可以追溯到人类历史最初的源头，甚至可以说，在人类出现之前就有了“外包”。

人类之所以成为人类，很大程度上上就是因为有了“外包”——先有“外包”再有人类。这个“外包”就是“火的出现”。

由于火的出现，人类同时拥有了两个胃：

+   一个是我们自身的胃；
一个是“外挂”的胃：火把食物做熟，大大减少了人消化食物所需要的能量，使人类不再需要像其他动物那样，把摄取到的能量中很大一部分用来消化食物本身，节省了消化的能量。人体内这些多余的能量就导致了人类大脑的产生——大脑能耗占人体能耗的25%，如果没有这个“外挂”的胃，也就没有任何类的大脑。

因为有了“外包”，才有了人类——我第四天会详细讲“外包”这个概念。
