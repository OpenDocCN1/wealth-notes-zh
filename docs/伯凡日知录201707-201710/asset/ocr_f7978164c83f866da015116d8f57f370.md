# Ⅰ《新物种的脆断》中“恐龙和鸟类关系”的释疑

前两节讲到了关于恐龙和鸟类关系的问题，其中的一个表述很容易引起疑问，那就是：目前鸟类跟恐龙到底什么关系？

关于鸟类的起源目前有三种论点：

+   1. 普遍的观点是：现在的鸟类起源恐龙。
2. 鸟类起源于槽齿类。
3. 鸟类是鳄类的姐妹群。

我个人比较倾向于鸟类和恐龙都共同起源于槽齿类，也就是说，在恐龙生活的时代已经有鸟出现了。

![](bbox=[0.25, 0.88, 0.8, 0.98])

由于气候发生了变化，体型巨大的恐龙失去了它的生态位，直接灭绝了。但“本是同根生”的分支鸟类，由于体型不大，能够在一个食物不那么充足的环境当中繁衍生息，于是就进化成了今天看到的鸟类。

所以更准确的说法是：恐龙不是起源于鸟类，它起源于看起来更像鸟类的槽齿类。恐龙和鸟类来自同一个祖先。

# Ⅰ独角兽：谨防环境变化

经常看到媒体报道，手机行业利润的90%被三星与苹果霸占，但现在苹果做为一个畅销品，已经不能引领时尚潮流。现在满街的iPhone，都失去了_AVAILABLE的资本，它在创新上越来越弱，或许不久的将来会横空出世一个新品牌来取代苹果。我觉得苹果做为一个独角兽公司，市场份额一直在下滑。老师我不明白的是：为什么这些大公司（诺基亚、HTC、摩托罗拉）有那么多顶级人才，还避免不了迅速的破灭呢？衰败的终极原因是什么呢？

吴伯凡

苹果不是一家独角兽公司、独角兽公司是有专门定义的：

# 独角兽公司：已经完成了创业初级阶段，进入到一个相对稳定的成长期，估值在10亿美元的公司。

苹果的市值好几千亿、已经非常成熟了，它不是“独角兽公司”。

但正如大家都感受到的，苹果的产品正在老化，它的前景变得越来越模糊，尤其是在今天大谈人工智能、大数据和云计算的时代，苹果将走向何方，确实存在很大的疑问。

那么，为什么那些资金、人才都是其他新创的公司无法比拟、看起来非常强大的大公司会突然之间走向衰亡呢？“颠覆性创新之父”、哈佛教授克里斯坦森早就揭示过这个问题：

+   1. 当公司越来越强大的时候，它对环境的判断、假设就越来越固化。与此同时，它的能力也越来越固化。或者更要命的是它越来越单一化。因为它竞争力很强、能够赚到大钱，而强大的竞争力会让它获取更多的资源，更多的资源让它的竞争力就更强，如此往复循环，导致它的能力出现单一化。越强大的公司，越是对环境那些小而细微的变化不敏感。
2. 当细微的变化突然形成了一个明显气候的时候，这个公司的资源库、能力库、基因库里没有与之相对应的能力和基因。那么，不管它的资金多充足，人才多丰富，它业务指向的单一性导致了这个公司本身能力的单一性。因此，当环境发生巨大变化的时候，原来的优势不仅不是优势，反而成了它的劣势。

进化论告诉我们的，任何一种性状，一种功能的强化都同时意味着其他功能的退化和寂缺。所以，表面上是被竞争对手打败的，但真正打败它的是悄悄变化的环境。

# Ⅰ王东岳：递弱代偿原理

我们到底是应该以变化来应对变化，还是以不变应万变呢？如果复杂性是生存和进化的必要条件，那为什么那些单细胞生物是地球上存在最久的生物？

吴伯凡

推荐大家去读一下王东岳先生的《物演通论》。进化不仅表现在生物界、无机界，也表现在人类社会。越是简单 的东西，它 的稳定性就越强；越是复杂的东西，它的稳定性就越弱。

比如，一块石头生命的稳定性就远远大于任何一个生命，不管是植物还是动物的生命周期。石头太单一了，也就特别稳定。越是高级的动物、越是高级的物种、它的内部复杂性就越强、精密度就越高，而精密度越高的东西脆弱性就越强。我们摔一块石头是摔不坏的，但是把手机在地上摔的时候它就很容易摔坏，这就是高级的和低级的差别。这种“越来越先进的过程=越来越脆弱的过程”的现象，就是王东岳先生的递弱代偿原理。

从这个意义上，虽然人类是万物之灵，但我们比那些单细胞动物要脆弱的多。如果真发生巨大环境变化，那么生物等级上较低的动物就容易存活。但是我们作为一个高级生物不能为了存在的长久性而牺牲我们的生物等级。

开个玩笑，一个物种要想留下，最好 的办法就把它做成标本；它在等级上已经降到非生命形态的时候，它一直就停在那儿了。还有我们人类发明的东西，比如技术、产品，这些通更是被套上了一个进化 和创新的红舞鞋，停下来就是死亡。你要不死亡，就要不断地变复杂变精密，而越复杂 越精密，就意味着你越脆弱。这就是物种的命运，也是一个产品的命运。

比如生产手机，就有可能随时被 人给替代，但如果去生产菜刀，被替代的可能性就很小，因为一千年后人们可能还会用菜刀。但不能因为一个产业不稳定、一个行业的风险大，就退回去做那些产品生命周期特别长，科技含量、创新水平不那么强的那些产品。任何一个生态位都被物种所占据，一旦退回去，直接面对的问题就是激烈的竞争。

而我们对竞争的定义很清晰，就是生态位重叠。在重叠过程当中，你随时可能被替代。
