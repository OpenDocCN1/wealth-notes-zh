# | 简单粗暴的语言是一种腐败

丰富的描述性语言对于学识不高的人来说往往显得格外稀缺，他天然在意沟通中的立场，把注意力放在交流的效率上。这并不是不好，只是价值观的选择会让自己无法获得更好更宽广的视野与平台。那些细致入微的感知是需要付出练习的，弱化立场敢感求真。什么样的品质比较容易催生丰富的词汇呢？这是我第一次感受到语言对人心智的影响是如何庞大深远。

吴伯凡

在回答这个问题之前，我想先分享《菜根谭》里的一段话：

> “家家有过，不宜暴怒，不宜轻弃。此事难以言，借他事隐讽之；今日不悟，俟来日再警之。如春风解冻，如和气消冰。”

这段话说的是，家家有过以后，不要立即勃然大怒，不要轻言放弃，不要说断绝什么关系的话作为威胁。这件事情难以说清，就用别的事情旁敲侧击让他明白，他今天不明白，就等着来日再说，过两天再跟他交流。这就像是春风解冻，春天来的时候水面上还结着冰，但是春风一天天地吹，慢慢地冰就化了，这是“和气消冰”——这是家庭沟通的规范。唯一防断更微信: 699250
