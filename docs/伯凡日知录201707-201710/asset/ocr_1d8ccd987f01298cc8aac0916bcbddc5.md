# | “到底是什么在造船”

昨天我们讲到恐龙的后裔和中国神话传说中的龙之间的差异。恐龙虽然灭绝了，但是它的变种、直系或是旁系的后裔—各种各样的鸟，还在这个世界继 Contributing 生存繁殖，原因就在于，鸟在各自的生态位面对真实的场景、真实的挑战给出了相应的生存策略，而一个个的“策略组合”，或者说“性状组合”，也就是一个真实的物种。

中国神话中想象的龙，看上去也是各种“性状组合”，但它并不是一种“策略组合”，而是想象的、没有节制的延伸的一个结果。当然，龙有龙的价值—神话的价值、文学的价值等等，但它不是一个真实的物种。

说到恐龙后裔和神话龙的差别，我想到了一个很著名的论断：“到底是什么在造船？”

这个问题听起来非常荒 😉 当然是人在造船了！但提出这个问题 的哲学家Alan认为，“是 大海本身用它彻底的严谨性选择了 功能适应的船只，摒 弃了不适应者，从而塑造了船只。”— 船不是人造的，本质上，船是大海造的。
