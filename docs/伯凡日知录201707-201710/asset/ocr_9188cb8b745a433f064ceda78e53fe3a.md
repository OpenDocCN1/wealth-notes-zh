# I 同心圆思维

吴老师，您能不能在讲“同心圆思维”理论的基础上，举几个例子？

吴伯凡
一个最直接的例子，《伯凡·日知录》对于我个人来说就是一个同心圆思维。

+   1. 称秤。很多杂货店卖东西都需要称秤，既然做生意需要这样一种设备，那就叫商用机器。
2. 奶酪切片机。大块的奶酪拿过来放在奶酪切片机切成片卖，这是开杂货店必须要用到的。
3. 打卡机。这在当时是比较先进的，但不是电子打卡，是往纸上打孔的机器。

这三个产品是IBM的主打产品。产品看起来很低端，但名字却很高端—国际商业机器公司。这里包含着IBM的一个同心圆结构：这家公司就是生产商业用的设备，虽然现在卖这个产品，但不意味着永远卖这个产品，随着商业环境的变化，肯定会出现新的商用设备或者商用机器。

# I 飞轮效应

成功是不可复制的，飞轮效应固然有价值，可是核心问题在于有多少公司、多少人能熬过最初轮子缓慢启动的过程？为什么大部分会死在飞起来之前，才是更值得研究的，希望能有失败者和成功者的案例对比分析，飞轮效应会更有说服力。
