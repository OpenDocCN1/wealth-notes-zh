# 结束语 | 写给你的一封信

结束语 | 写给你的一封信

小师弟，
你好。

我的心情和语调都有点儿沉重，因为在过去的一年中，我和你可以说是“天天见”。

一方面，我很感激给你这样一个机会，听我在一年里唠叨叨叨一在这个过程中，我得到的远比我输出的要多得多。

我把我已有的知识存量进行了梳理，梳理的过程本身也是一个深化的过程，我获得了很多以前我不曾有过的新知；另一方面，我在输出的同时，也痛感自己的知识盲点和知识漏洞，被迫去弥补这些东西——如果你没给我这个机会的话，我可能连自己的盲点、漏洞在哪儿都不知道。

通过这一年和你的相处，我真正有了一种“得到”感，一种实实在在的“得到”感。当你听到我说这些话的时候，这一年已经过去了。《伯凡·日知录》即将告一段落，此刻我有一种感恩和依依不舍的心情。

说到写信，我自己有一个习惯，每年要写六封信。我们生活当中都有很多重要的人，其中有一个很重要的人是我们最容易忽视的，就是我们自己——我们很少跟自己说话，尤其是以一种促膝谈心的平等对话方式跟自己说话。

+   1. 把厚书读薄：能够把很多的信息和知识，用比较少的篇幅说清楚。如果我们读一本书而不能够最后形成一个真正属于自己的靠谱书评，等于没读。所以，读书的第一步就是要“把厚书读薄”，薄到可能只有一张A4纸。
2. 把薄书读厚：这张A4纸的东西已经是你的了，但它不是你获取知识的全部，它只是形成了某种框架。当把你所看到、经历、获取的诸多知识、信息和体验都置入到这样一个框架当中，才能变成了一本你自己的书，这本书就会很厚。读书不是一次完成的，有些书是一辈子不断地读薄又读厚的过程。
3. 把书读没了：读没了并不是消失了，它的很多东西已经成为你自己的，“日用而不知”，你甚至都不知道它是从哪儿来的。

+   1. 你所面对的世界/局面是确定的；
2. 你是确定的。
