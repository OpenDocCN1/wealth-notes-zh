# | 要对情绪验明正身

“有毒瘾的负面情绪”让我想起自己对女儿犯的一个错，我觉得她发脾气、蔑视恐怖伤都是不好的，高兴快乐就是好的，所以我总想抑制她这种负面情绪。

吴伯凡

我之所以提到“有毒瘾的负面情绪”这个话题，是想提醒大家：要对情绪验明正身。

情绪到底是什么？是一个人的一种工具，是我们来到这个世界上，生存下去必备的一套工具。喜怒哀乐忧思惧、怨恨嗔怒烦、贪嗔痴慢疑等等，这些都是我们在这个世界上必备的工具。

工具本身无好无坏，在使用的过程中，由于场景和使用方式的不一样，才会带来不同的效果。最重要的是，随着时间的延续，一个好的工具在发挥它本该有的正常的功能的时候，悄悄产生了另外的功能。情绪是人的一种软实力，它都是有用，有时候甚至是大有用途的。

# | 成为自己的驯兽师

学习过心理学，首先我知道要接纳自己的情绪，洞察自己的情绪，还要表达自己的情绪，而不是情绪化地表达。我觉得比较多的情况是拼命压制自己的所谓“负面情绪”的人，结果到了一个临界点，不但会爆发出来，甚至会情绪失控——今天老师讲的成瘾是另一个角度。发怒或者悲伤是有正面意义的，但是过度的话就会引起其他问题。

吴伯凡

这个同学的发言引出了一个话题：当负面情绪出现的时候，我们是要去抑制它，还是要让它释放一这是个老掉牙又特别新鲜的问题，是我们每天都要面对的问题。
