# | “好+好=不好”的合成谬误

我几天前跟一个做手机产品开发的朋友聊天，他说：做产品真的是很难，有时候我们团队上上下下都认为的一款特别优秀的产品，拿到市场上以后，效果远不是我们设想的那样，而且还出现了那种我们根本没想到到的缺点——这个缺点只有上市以后，用户反馈回来才能发现，是“出乎意料，又在意中”。当初我们就想如何把这个产品做到最好，如何在几个关键指标上能够做到比业内其他产品明显突出一截。结果这几个关键的指标一合成起来，虽然也能达到一定的正面效果，但却出乎意料地出现了一个反面效果。

比如制造手机，新产品要做到：

+   1. 按照苹果公司的法则：每一代一定要比上一代薄一点。
2. 速度要快，快一点点就彻底改变了大家对这个产品的印象，或者是彻底跑过了同类产品。
3. 外观最好是用一些有质感的材料，不要用塑料。

我们可以想象，你要做这样一个产品：

薄就意味着‘热’更容易传到外面来，摸上去就会特别的烫。这在冬天可能不是个问题，但一到夏天或者在户外，你就很容易发现这个问题。

如果要速度快，就意味着功耗大，功耗大就意味着热量大——这就对散热提出了很高的要求。在一般温度下，散热跟机器的发热能够保持平衡，一旦这个平衡被打破，发热的速度稍微超出了散热的速度，那么这个产品就会很快热起来。

如果你不用塑料材质，那么热传导就会很快。金属传热的速度显然要比塑料快。

所以，一款很好的产品也会出现这样一种意想不到的瑕疵，这可以算是一种合成谬误：几个好东西加起来就成了一个不好的东西，或者出现了明显缺陷的东西。

# | KPI的负面结果

从这个话题我们可以延展到一个大家都特别不喜欢的概念：KPI——关键业绩指标。

“关键业绩指标”是：有一个总目标，然后对这个总目标进行分解，然后再持续分解，分解到每一个环节里要达到的目标，最后汇总成一个总的目标。

很多时候，“整体大于部分之和”不仅仅是指正面效果，负面效果也有可能得到整体大于部分之和，或者还有一种情况：不是线性的相加，而是几种性能、几种指标，合起来就成了一个意料不到的新结果，这个结果很可能是你事先没想到一个负面结果。

以海底捞为例：

为了提高用户体验，海底捞对服务员下了一些关键业绩指标，比如客人的饮料杯到了1/3的时候，一定要给客人续上。如果做不到，那就影响这个月的业绩考核，简单地说就是影响你的奖金。那么，海底捞的员工为了完成这些KPI，就会对不遗余力，因为这直接关系到了他们的收入。

有时候我喝饮料，虽然爱喝，但我也喝够了，我就在喝的差不多的时候放在这儿，但是，服务员马上又给我续上这一杯。我只好勉强喝下去。等喝到还剩1/3的时候，他又冷不防给我续上了一本本来这些关键业绩指标是朝着一个总的目标“优化提高客户体验”制定的，结果反而破坏了客户体验。

# | 单一目标与整体目标的偏差

这是一个什么样的机制呢？概括起来就是：单一目标、少数指标，跟整体目标总是有有一个偏差。

# 1.求死的西比尔

古人就注意到这一点，在希腊神话里，我们经常看到这样的情节：

宙斯虽然是神界一哥，但是是非常好色，是一个花花公子。他一旦跟哪个人界的女子发生亲密关系，就会给这个女子提一个愿望的权利，不管这个愿望有多难，他都可以帮助她实现。

有个女子叫西比尔，跟宙斯春风一度以后，宙斯说你可以但是只能提一个要求。人最重要的要求就是不死，西比尔想了想，提出“我要永生”。宙斯说没问题，让你永生。

一千年以后，宙斯再见到西比尔的时候，发现她已经老得不成样子，萎缩得很小很小，愁容满面。看到宙斯，西比尔苍老的脸上带着怨气和乞求。

宙斯：你还要什么？我不是给了你了吗？

西比尔：我要死！跟你求永生的时候我忘了要年轻。现在我老成这样了，还死不了，求你给我死亡。

宙斯：不行，我只能给一样，现在我也没有办法让你死。

这个结果很讽刺，让人哭笑不得。

# 2.没人相信的卡珊德拉

罗马神话中特洛伊的公主卡珊德拉，神赋予了她预言的能力，但是，她也是只有这个能力，忘了同时索要“人们相信她的预言”的能力。

所以，卡珊德拉说的每一个预言都是对的，但是人们永远不相信她。这是一件多么悲催的事情，卡珊德拉明知道发生的事情，但永远都只能眼睁睁看着一场场灾难来临，而她无能为力。不管她用怎么样的努力，别人都不会相信她——卡珊德拉没办法救苦救难，因为神只能满足她一个要求。

这些神话故事都是一种很好的象征：我们许一个愿望、提一个目标的时候，常常是单一的——我们认为这个目标太重要了，以至于完全忽略了跟这个目标相关的其他因素。而当这个目标实现的时候，往往是一个令人哭笑不得的结果。

# 3.水桶一样的女朋友

有时候由于某种匮乏，由于我们自身的缺憾，我们会对某个目标特别看重。就像周星驰电影里头的一个猥琐男，他很崇拜波霸，于是就说他要找女朋友，三围得是38、38、38——这个猥琐男对38产生了一种强烈的兴趣，以至于当他说三围的时候还是按照胸围的标准在说。可以想象一下，三围都是38的是一个水桶。

# 4.青蛙女友

还有一个很老的笑话，说一个人理想的女朋友，要像蔷薇一样的大眼睛，像朱丽娅·罗伯茨一样的大嘴，爱运动、会游泳……这是一个复合需求，这些需求之间存在着许多我们没有意识到的非连续性，简单地说，就是漏洞。所以，当这个人把这个需求给了电脑，电脑告诉他——青蛙。你提的所有需求：大眼睛，大嘴巴，会游泳都满足，但不是你要的那个东西。

这个老故事可以说明一个新问题：KPI表面上靠谱儿，其实很多时候是很不靠谱儿的，它常常会弄出畸胎。

由于对KPI的不满，一些公司在探索新的管理方法，其中有这个几年越来越热的重要管理方法：OKR。

OKR就是“目标与关键结果”：

O=目标=objectives，一个复合的目标
K=Key Results，复合的结果，关键结果

OKR这种方法能够比较有效地避免KPI导致的畸胎式的結果，避免了你找女朋友找出来的是青蛙。

# | “许愿要谨慎，当心它实现”

当我们向往一个目标的时候，我们的心智有一种自动虚化的技术：微距照相的时候，好的相机<|message|>帮你把周围的都给虚化，这样拍出来的相片很好看；而在现实当中，你把其他的东西虚化是一件很危险的事情。

有一个故事，说有个人给自己设立了一个目标，许下一个愿望——今年一定要挣到100万——这是一个他无比向往的目标，甚至于这个目标之外其他的东西都被虚化了。
