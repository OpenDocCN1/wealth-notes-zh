# ——第181天的知识笔记——

# | 批评家式员工

网上流传一个段子，一个华为的新员工入职不久就写了一篇建议，对华为今后的战略、执行，洋洋洒洒写了一万多字。这个报告后来传到了任正非手里，任正非在上头批了一句话：赶紧把他弄到医院去检查一下，如果有病就治疗，没病就让他走人。

这个段子流传很广，我也问过在华为的朋友是否有其事，朋友说没有这样的事，按华为的规矩也不可能，这是外界想象出来的。

但是，这里就有一個很有意思的問題，那就是：公司到底該不該吸納那些批評家式的員工，或者是初來乍到還沒有開始工作就進入到批評家狀態的員工呢？我估計很多創業者在公司到了一定規模的時候，總能在公司發現那麼幾個批評家，如何對待他們是一個很值得思考的問題。

# | 警惕公司里的批评家

我在美国的《Fast Company》杂志上读过一篇文章——《要警惕公司里的批评家》，里面有一个说法我印象特别深，它讲到伦敦一个很著名的景点名胜，西敏寺大教堂，过去我们把它叫先贤祠，后来译成西敏寺，威斯敏斯特大教堂等，总之，那是一个故去名人汇聚的地方。

先贤祠里什么人都有，你一进去，就能看到牛顿的墓石像挡在路中间似的，还有达尔文的墓等等，英国历史上下各行各业的已故名人他们都汇集在那里，但有一种职业是没有的，那就是批评家。

英国历史上也有不少的批评家，文学批评家、艺术批评家，还有一些政论家等等，那问题是，他们从事这个行当为什么不能进先贤祠？

相亲的时候，未来的老丈人都会问，第一句话“你是什么干的”，第二句话“这行你干到头是什么”——那批评家于到头是什么？我不知道，可能还是个批评家吧。

《要警惕公司里的批评家》里说，批评家并不是一个真正的专业，它是一种比较模糊的身份，最大的问题是没有真正的专业技能和职业操守。批评家的工作用特征是依据规则、理论，对具体的人、事、场景进行居高临下的指点江山式的评判，他们激情有余，理性不够；破坏有余，建设不够，最重要的是，他们的激情和才华几乎全部消耗在评判上，具体做事时，他们已经兴趣阑珊了。批评家的思维模式和行为方式都是动口不动手的状况。

另外，批评家思维方式和行为动机里最致命的是：迅速的谋求显而易见的优势。比如“以爱的名义”实施否认：一般批评或者评论一个什么东西的时候，批评家都以“我喜欢”、“我爱你”的名义来对你进行评估。大家听起来应该有点儿耳熟，我们很多父母都是这样的，以爱的名义实施无情的掌控，即使你已经快40岁了，也还是把你当成是一个孩子，原因就在于他们始终是以爱的名义在对你进行控制的。

批评家总是希望在迅速谋求优势后，迅速获得利益、权势、名声。他们在跟人相处的时候，始终把自己跟别人处于一种不对称的状态中——不是跟你商量，也不是设身处地的去感受你的所有困难、场景，以及只有身在其中才能够体会的种种难处。

所以，批评家是聪明的谏言者，但他始终跟你或者一个组织，处于一种习惯性的游离状态——这个事情本质上是你的，跟我没关系，我之所以来凑和这个事情，是为了谋求我自身的优势，让我显得比你高明——这在批评家心智模式中是永远去不掉的，不然他也不会成为一个批评家。

# | 游离的职业特征

我小时候第一次在书上看到“批评家”这个词时疑惑了半天，有这样那样的“家”，怎么还会有批评家？我们平时最不喜欢老师批评了，批评家居然还能成为家。后来我渐渐知道批评家是什么的，但确实也没有好印象。那到底是为什么批评家不招人喜欢？

有些批评家在某一段时间内声名赫赫，比如一些影评家，美术界里的策展人，还有文学批评家，摄影批评家……最后我自己也干上了批评、评论这个行业。

好多年前我和一个朋友在我们家阳台聊天。我们家前面是北京著名的别墅区。我就感慨，我们也只能坐在我家这个花园洋房里来看别墅的风景了。朋友就说，谁让你是“人家做商业，你做商业评论”——显然，评论这个职业不是一个好职业，它有明显的鸡贼，但身在其中的人又感受不到——这种职业不是在真正做事，它本质上是以游离为特征的。

# | 批评家配偶

有一本讲婚姻的书里说，一般来说，正常的婚姻中，一个人对配偶的负面感受占整体感受的1/5是正常的，如果超过这个范围：

| 负面感受 | 婚姻权力为负规则 |
| > 1/5 | 关系有危险 |
| > 2/5 | 会出现某情绪伤害，以及可能出现怨恨等不同程度的矛盾 |
| > 3/5 | 婚姻容易出现破裂 |
| > 4/5 | 努力去救、如果失败，于是，你会彻底反感对方 |
| = 5/5 | 会感觉对方是粹彻底坏人，甚至，你将把对方视作仇敌 |
|  | 婚姻破裂文 |

事实上，负面感受到3/5的时候，婚姻已经亮起了红灯。

这本书也给出了一个建议：在选择配偶的时候，千万不要找那种有批评和评论习惯的人，不管他看上去有多优秀——批评、挑剔、评判、居高临下是他的一种生存状态，他是不可能因跟你在一起就会改变这一切的。在他拼命追求你的时候，他会有所收敛，但是一旦你们的关系进入新常态，他的真性就会显现出来，他的这种批评家的姿态会让你有身处地狱般的感受，甚至在没有批评你的时候，你都觉得他的双眼在盯着你——他不在身边的时候会形成某种自责，久而久之，你的精神状态就会非常的差。

# | 垃圾也是放错位置的资源

对企业来说，应该尽可能少的雇佣那些批评家人格的人，尤其不能把他们放在重要的位置上，原因是：

+   第一，这样的人遇到事情的时候，首先是评判，而不是投入地去解决事情。除了他自己不干之外，别人在干的时候也会习惯性的在旁边进行指点——做对了，是他指点的结果；做错了，是你没听他的话——这样的人会对企业文化形成一种相当大的破坏力。

+   第二，你永远别指望他做事。我们已经说了，这样的人心智模式和行为动机里都有一种不做事，或者是以“否定问题作为解决问题的最好方式”这样一种态度对待所有的事情。

公司应该远离这样的求职者，一旦发现他是这样的人，要严格限制他的势力范围和活动范围，实在不行，要想办法把他清除出去。

但是，并不是说这样的人是完全没有价值的，这里有些人是非常有才华的。“所有的垃圾都是放错位置的资源”，如果把它放在一个合适的位置，他还是很有帮助的。

这听起来有点诡异，但其实我们生活当中也会这样处理事情，比如有些人显然不是一个合适的配偶，但是因为有明确的边界，他的习惯性干预和控制都无法触及到你，而你还能从他那里获得一些很有帮助的见解和视角。有些时候，批评家站的那个角度，他看到的问题比你身在其中看的清楚。但是，你不要跟他太接近。

公司用这样的人，需要给他一个角色设定，比如公司的顾问，或者是一个编外，在某个项目或者某些时候能够给公司提供参谋和建议。批评家的思想穿透力、观察视角的独特性能够给你提供很好的帮助。

曾国藩有一句话说的很到位：可议事者不可图事。这话的意思是，有的人可以一起议事，但是不可以一起干事，图事的人和议事的人要分开。

虽然批评家不可爱，尤其是近距离相处的时候，但实际上你是不可能真正和他们近距离的，因为批评家的人生、态度是一种习惯性的游离状态，跟他保持一个安全距离的时候，他们的价值才可以显现出来。
