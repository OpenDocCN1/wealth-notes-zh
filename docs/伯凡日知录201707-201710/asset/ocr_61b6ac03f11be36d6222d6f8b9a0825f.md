# | 深沉厚重=但行好事，莫问前程

我们怎么发现一个深沉厚重的人呢？如果我是一个深沉厚重的人，怎么才能让别人发现呢？如果我为了提高被发现的概率而推销自己，我是否降级成了聪明才辩的人？或者，我是否应该先聪明才辩，爬到一个位置，然后再显露絡落豪雄乃至深沉厚重的本质？

吴伯凡

听到这个问题我有一种感觉，陈岩同学也许是个磊落豪雄和深沉厚重的人，但至少他是一个聪明才辩的人——聪明才辩的人的特点就是遇到一个问题能想到很多问题，滔滔不绝地把这些问题呈现出来，然后进行很好的梳理，这确实是一种能力。

但你具有这种能力的时候，你就可能丧失了别的能力，正像罗伯特·弗罗斯特（Robert Frost）说的，“林中两条路，你选择了这条路就意味着放弃了那条。”——一个的人格类型、性格、能力类型，不是摆在我们面前可以随便宜选择的東西，一旦你进入一个路径的话，掉头切换路径的可能性就会比较小。

# | 好好说话，说到点子上

我应该属于那种不太爱表现自己（深沉厚重）的人，很多人和我接触完都会和我说觉得我是一个从容淡定的人。生活中我们的确经常可以看到很多口若悬河，愿意表现自己的人，按照老师的说法，这些人属于三等资质。但是不是有本书叫《好好说话》吗？很多课程也一直推荐演讲能力等等，这个和你说的有矛盾吗？

吴伯凡

没有矛盾。

# | 习惯性防御

我在生活中还遇到一种发问，是一种保护性的发问。有些人会以讨论问题是对他的攻击，会用反问的方式来保护自己，结果是话题无法继续，原有的问题得不到建设性的意见。请老师帮忙分析一下这种保护性的发问应该如何应对？

# | 成熟的沟通

我有点疑惑，我在生活和工作中会不愿意甚至有时会表现出对那些条条的人，智商让人捉急的人的厌烦。我会不愿意和他们有过多交往，甚至有时无法避免要一起工作时，听到他们慢吞吞毫无建设性的发言时，我都会忍不住想打断。老师，我这是什么症？我觉得我这样也没礼貌，该如何更正。

吴伯凡
