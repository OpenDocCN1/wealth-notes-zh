# | 负面情绪上瘾的形成机制

我们之前好几次都讲到了“毒瘾”的问题，这周我会讲到一个让大家可能有点儿�midt 的观点：人体是一座小型毒品工厂。

通常我们想到的吸烟、毒品等，都是来自外部的瘾，还有一种内部的瘾，是我们平常想不到的：我们身体自给自足的一种毒品和上瘾的机制。

为什么“人体是一个小型毒品工厂”呢？

在生活中，我们会受到各种各样的生理和心理创伤。当创伤发生的时候，我们的身体会启动一种保护机制，比如产生内啡肽，阻断和减缓痛苦的传递，还有一种方法是，身体制制造一个新兴奋区让人产生巨大的快感，也就忽略了生理和心理上的伤痛。

但任何有价值的东西都难免会有副作用，造成负价值，这些帮助我们减缓痛苦的物质，就是我们身体自产的“小毒品”，同时借助于这个“小毒品”，我们的身体就会不知不觉形成一种对这种“小毒品”的路径依赖。

有的人很容易陷入到忧伤之中，有人特别爱愤怒，有人特别爱哭…..很多人爱诉苦、爱抱怨…..这些情绪都是一种内在的生产机制，也就是启动了身体里的毒品生产流程——我们通过不流血的伤害来制造毒品，让我们的身体分泌内啡肽、多巴胺等，最终就形成了一种自给自足的、我们又意识不到的特殊吸毒。

之所以再次讲到毒、讲到毒瘾、讲到负面情绪，就是想和大家详细地分析负面情绪产生的机制，以及我们是如何悄悄对负面情绪上瘾，以至于形成了一种在负面情绪中“痛并且快乐着”、乐此不疲的状态——我们是如何染上了一种我们不愿意戒掉的毒瘾的呢？
