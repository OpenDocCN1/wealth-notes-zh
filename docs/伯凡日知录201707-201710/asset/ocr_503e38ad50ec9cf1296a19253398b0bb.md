7.10 | 服装业=金融业

上周我给同学们布置过一道作业题：除了共享经济、闲鱼App，利用场景变换所创造的商业模式还有哪些？我在出这道题的时候就想到了一个我一直很想讲的话题——服装业。

中国是服装业大国，如果从现在开始，全世界的服装企业都停产，那么三年之内，整个世界也不愁没有衣服穿。这就是中国现在的服装业产能。所以，从这个意义上说，中国是一个服装业大国。

但是，服装业跟服装业是不一样的，服装其实是最典型的具有场景性的产品。打开衣柜，不同的服装实际上就是不同的场景。在一个服装业发达的国家里，它能够生产各种各样场景的衣服。

服装业至少可以分成三个层面。

# 1. 服装业与制造业

服装业显然是制造业，它就是制造一个价廉物美、性价比高的产品，让你遮寒、遮羞。这就是服装业最基本的，或者说是最低的层次。

# 2. 服装业与媒体产业

服装业还有第二个层次：服装业是一种媒体产业。每一个服装企业，哪怕是从事纯服裝制造的企业，它也是在从事媒体业。

20世纪原创媒介理论家、思想家麦克卢汉在他的《人的延伸》这本书里头提到了26种媒介，这些媒介当中有些报纸，有电视，还有一种媒介叫服装。因为每一个人所穿的衣服就是一个自媒体。也许你自己没有意识到，但是别人能够从你的服装里解读到许许多多的信息。比如你的世界观、价值观、经济状态、个人品位，甚至是你的 人际关系等等。一套服装所承载的信息远远大于我们自己的想象。你说，“我并没有想发布什么信息”。对不起，服装业也遵守米兰达宣言，你可以保持沉默，但你说的每一句话都将对你不利。你说我不装饰，我不修边幅，不修边幅也是在发布信息。一些相对比较高端的服装企业，它从事的工作其实跟杂志社、报社是一样的。他们设计一些内容，然后借助于工厂，就像报社借助于印刷厂一样，去复制它的产品，然后再借助于发行渠道，最终变成一个媒体终端。所以，比较高阶的服装企业它就是一个媒体公司。

举一个例子，维多利亚的秘密，它每年为什么要花那么多的钱，以那么大的声势在伦敦搞发布会？那就是典型的媒体发布会。它借助于一个刻意营造的场景，把它要表达的信息让所有的人感知到，接下来它只需要做一件事情：大量的印刷、复制它的产品。

服装是一种媒介，并不仅仅是指服装上所传递的信息，超越服装的大量隐性信息也随着服装被发布出来。以维多利亚的秘密为例，它选择了一种内容定位——只为瘦人打造的一种内衣产品，把世界上三分之二的人排除在外了。但是不要紧，当它制造了一个门槛，制造了有限进入这种感觉的时候，就会有很多并不那么瘦的人希望穿上这样的内衣。所以通过制造有限进入的感觉内衣反而制造了极其具有的特权。换句话说，你就买到了某一个身份。也就是说，我们购买服装早已经超出了保暖、遮寒的水准，而是追求一个炫耀、身份的徽章、标签、旗帜。借助于某种服装，我们会获得某种融入感、安全感和优越感。而这种感觉，就是服装公司精心营造的信息，让我们去消费。

维多利亚的秘密还使用了一种手法，那就是礼品经济。礼品经济的特点是：购买者和消费者常常是分离的。购买者购买的是消费者的欢心，而消费者的欢心是很建议价的，这种定价叫情感定价。比如脑白金用的也是这样一种模式。你可能并不认可这个产品，这个产品的价格也可能高得离谱，但是你并不在乎，因为你买的不是这个产品，而是使用这个产品的人的欢心。维多利亚的秘密在做产品发布会的时候，就已经在悄悄地制造一种信息：只有这样的产品才能够赢得你所在乎的女性的欢心，所以男士会去购买这种性价比其实很低的产品。在这个意义上，我们把服装业称为媒体业。

# 3. 服装业与金融业

服装业的第三个层次，就是金融业。

它是一个不折不扣的物理性产品，怎么会是金融业呢？麦克卢汉所列举的26种媒介里头，有一种媒介叫货币。货币是一种特殊的媒体，它承载的信息是一种被认证、被背书的关于信用的信息。麦克卢汉把货币称为穷人的信用卡，也就是一种无记名的信用卡。你拿着这张纸，实际上拿的是一个信用。就那么一张纸，商家就会给你一大堆产品。原因就是他拿着这张纸就可以换很多的产品，所以货币其实是一种关于信用的信息。

接下来，大家终于明白了为什么说服装业是金融业。我们知道，任何一个货币的发行都必须要有 一个央行，我们之所以接受一种货币是因为央行对这张货币背书了。一张美元上面会写 “In God We Trust”——以上帝的名义我们信任这张纸，上面还有财政部长的签名。这些东西都是在告诉你，这是一张值得信任的纸。因为它是媒体，它承载了重要的信息，它的价值就不再是这张纸本身的价值。在美元里头，一美元和一百美元是一样大的，据说一张一百美元的纸的制造成本是6美分，我们暂且相信它是6美分，但为什么一张6美分的纸它值一百美元呢？原因就是它是信息，而不是一个物质。我们看到这张纸的时候，看到的是它的面值，而不是它本身的价值。

听到这里，买过奢侈品服装的朋友就有点感悟了。媒体上经常会说，某品牌服装实际的制造成本只有一百多块人民币，可是它为什么能够卖到四五千甚至上万呢？原因就在于它的价值不是它本身的价值，而是它所代表的这种面值。当你拥有了这个服装的时候，别人认。别人认，这就是它的价值。当你不拥有这个服装的时候，你就被排除在外。或者说，一套服装就是一个票证，拥有了这个票证，你就能进得去某地地方，没有你就被排除在外。

# 那服装业的央行在哪呢？在巴黎和米兰。这不仅仅是因为每年巴黎和米兰都要举行奢华的、声势浩大的服装发布会。还是因为巴黎和米兰已经代表了某种信用，或者说代表了所有人心中都认的一种价值。那么，有这个央行背书以后，从理论上说，这个货币就可以在全世界通行了，剩下的事情那就是印钞了。

以前经常听说LV的包包都是在中国生产的，不过就是人造革，生产成本也是一百多块钱，我们中国人还得跑老远，漂洋过海去香榭里舍大街排着长长的队去买那一个包。原因很简单，我们买的不是包，买的是一种货币。所以，在这个意义上说，服装业就是一个货币体系，或者说是一个金融体系。

我们知道，印刷厂是很容易开的，但是央行是不能随便开的。一个国家的服装业是否发达不在于你有没有那么多的服装工厂，而在于你有没有自己的央行。

如此说来，中国的服装业离第三个层次还很远，在第二个层次上我们做得还不是那么好。什么时候中国的服装业会真正繁荣呢？一句话就是：什么时候中国的服装业从制造业变成金融业，或者说超越印钞业变成一个有话语央行背书的金融业，就迎来了真正的繁荣。

吴伯凡

听完今天的演讲，我希望大家思考一个问题：如果服装是一种自媒体，你想一想你穿的衣服上头哪些是你的签名、哪些是你的封面？在一个看不见的朋友圈里头，你每天在发布什么样的信息？

# 服装业可分为三个层次：

+   1. 制造业。服装业的最基础层级。

+   2. 媒体业。 每个人穿的衣服都是一个自媒体，每一场新装发布会都是一场媒体发布会。

+   3. 金融业。 货币是被认证、背书过的信息，服装也是。背书服装的央行就在米兰和巴黎。
