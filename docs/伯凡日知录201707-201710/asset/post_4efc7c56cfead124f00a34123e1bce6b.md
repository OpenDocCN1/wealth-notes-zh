# ——► 第215天的知识笔记 ◄——

华为公司有一句让我特别触动的话："给员工加薪就是占员工的便宜"。

这句话是说，公司通过给一个员工加薪而对他产生的激励，和公司付出的成本之间是不对称的。假设一个员工被加薪2000块，那就可能直接促使了他主动性的发挥，从而给公司创造了不止2000块钱的价值——从这个角度来说，加薪就是占员工的便宜。

不过仔细再想想这句话，就★会发现，这里可能有一些问题，或者说至少有一个限制条件。

# | 激励的边际效应递减原理

《硬球》这本书里有这么一个例子：有一个人很有慈爱之心，他发现公司楼下有一个卖煎饼的老太太，觉得老太太这么大岁数了很有不容易，就在每天上班经过煎饼摊的时候，把一个quarter（25美分）给那个老太太——"勿以善小而不为"，一年过来，他坚持这么做，应该说是很值得赞扬的。

但转折发生在一周年以后。有一天他照例把一个quarter给了那个老太太，却发现老太太以一种质疑和不满足的目光盯着他看。这个人就很奇怪，问老太太是不是自己做错什么，老太太说："我的煎饼现在已经不是25美分了，而是30美分了！"

我们把这个故事做一个抽象：激励或者慈善的边际效应是递减的——你把一个东西给到别人，当成为惯性之后，激励效应会逐渐归零——他已经把这个东西纳入他的正常收入了。

行为经济学家告诉我们：人们对"得到的东西"的敏感程度远远小于对"失去的东西"的敏感程度。

人们不在乎你给过他们什么，而只在于你最近给过他们什么，很多的激励因此就可能变成了"零激励"，甚至"负激励"——所以卖煎饼的老太太对每天给自己一个quarter的人会心生不满，因为她觉得这个人欠她5美分。

上面这个故事告诉我们，激励远不是那么简单的一——"给员工加薪就是占员工的便宜"这句话有很多限制条件。

# | 索取者和给予者

最近《哈佛商业评论》的一篇文章让我对这个问题有了更深入的理解。这篇文章讲了一对概念：taker和giver。

所有的人，包括所有的员工，都可以分成两类：一类叫"索取者——taker"，一类叫"给予者——giver"。

无论你是"索取者"还是"给予者"，并不是说你自己"有意索取"或者"有意给予"，而是说，这是一种习惯，是"习惯性给予"的人和"习惯性索取"的人。

《哈佛商业评论》这篇文章的作者认为，世界上就是这两种人组成的。一个公司也可以把员工分成这两种：

+   给予者——他们习惯性给予，也并不知道自己是一个"给予者"。每到一个地方，"给予者"们就忙前忙后，觉得这些事情都是他该做的——他们就是这个习惯。

+   索取者——就等着别人来张罗。这类人不是一种理性的计较——"我应该少处理，应该多获得"——这些早已变成了一种无意识的行为。

# | 标量和矢量

数学上有一对概念：标量和矢量。

+   矢量：既有大小，又有方向的量。也叫向量。
+   标量：只有大小，没有方向的量。

假设有两个员工都完成了你交代给他的任务，你要如何对待这两个员工呢？

我在一个"求职节目"的录制现场碰到过一个人，他的经历很有意思。这个人原来是一名武警战士，复员以后就去了一个公司做保安，他用了差不多6年的时间，从保安做到了公司的副总裁。

做99%和101%，数字上只差0.02，在“标量”上差得的确不大，但在“矢量”上，由于箭头方向不一样，可能就造成了本质的差别：

有的员工可能是以“还债”的方式在工作，他自己乐于多做一点儿，总觉得“是不够的”；

有的员工完成了101%，是因为他工作能力很强，“不小心”超额完成了那么一点点；

有的员工只完成了99%，但他有很多特殊的原因，比如他可能还在同时做另外一件什么事情，或者他刚从另外一个部门调过来，不太熟练，但其实他是一个很有潜力的员工，只不过在“标量”上他甚至更差。

种种这些可能的情况，你应该奖励谁，不奖励谁，或者惩罚谁，学问就很大了——我们的HR体系常常忽略这一点。

# 案例二：“你给的是你的1%”

有一个圣经故事，我们抛开里面的宗教信仰，只把它当故事来讲。

耶稣带着他的门徒和一个赞助人——经常给他各种物质帮助的一个人，走到了一个地方，很饿，想找点儿东西吃。

这个地方只有一个门是开着的，耶稣一行人就走了进去，发现这是一个非常贫穷的家庭，一个寡妇带着一个孩子，家徒四壁。

这个寡妇看见耶稣进来，就急忙在屋子里四处找啊找，都找遍了，什么也没有，最后找出一个小瓶，里面装了半瓶橄榄油，她就献宝似的把这半瓶橄榄油给了耶稣了。耶稣对这个寡妇说：“你必得进天堂。”

听了耶稣这话，同行的那个赞助人就很不高兴，他觉得自己给了耶稣那么多东西，那么多帮助，但耶稣从来没跟他说过这样的祝福，这个贫穷的寡妇只给了这么点儿东西，竟然“必得进天国”。

耶稣对这个赞助人也说了一句话“你给的是你的1%”——赞助人是一个富商，而寡妇给的是她的全部，这也是一个“标量和矢量”的问题。

# 有效激励

我们该怎么去激励一个人，奖励真正值得奖励，惩罚真正该惩罚的人呢？

我们如何吸引值得留住，值得培养的员工呢？

我们如何尽可能少地吸引索取者，或者，如何避免公司的制度和文化不知不觉地将“给予者”变成“索取者”，让整个公司都充满着讨价还价的“索取者”呢？

在给员工发放薪酬和奖励的时候，我们首先要明白：他到底是什么类型的员工。

如果他是个“索取者”，就会理所当然地把给他的奖励认为是“自己应得的”，而且，每一次的奖励都会增加预期——当你按照一个客观标准不再给他那么多奖励，甚至不给他奖励的时候，这类“索取者”马上就会觉得是公司亏欠他的。这样，前面的激励就逐渐变成了“负激励”，就像前面故事里那个卖煎饼的老太太一样。这样做的结果就是：不是在奖励勤奋，而是在鼓励贪婪，花的成本血本无归。

对那些“给予者”员工，你给予奖励的时候才会出现某种杠杆效应，激励会让他的工作更积极，更主动，更具有创造性。

所以，“为公司创造的价值远大于你给予他的激励”的时候才可以说“给员工加薪就是占员工的便宜”。

# I “外包”的起源

我们今天对“外包”这个概念太耳熟能详了，以至于会认为它一个历史悠久的概念。事实上，“外包”进入管理学的时间也就不 到40年。

最早的“外包”起源于医院的管理。众所周知，医院是一个多工种，而且工种之间壁垒森严的机构。在医院里从事某一个工种的人，可能跟另一个工种是“老死不相往来”的。而其中最明显的例子，就是医院清洁工这个工种。

# I “外包”的追溯

知道了“外包”的起源，感觉它是一个很新的东西，但我们仔细追踪一下就会发现，“外包”是一个很古老的事情，可以说是“世界上最古老的事情”——自从有了人类，或者在还没有人类之前，就有了“外包”——火。

# I 从“外包”的角度看房价

我们从“外包”的角度来看人和世界的话，很多问题也可以更清晰和简单了。

比如，北京市区的房价是十几万一平方米，而郊区的一个独门独院可能也就是十几万，但你不会买郊区的那个房子，原因很简单：房子的价值在于它的“外挂”程度，程度越低，价值就越低。

原因都在于“外挂程度”：你住在“贵”的地方，生活“外包”的可能性就越大。如果是荒郊野外的一栋房子，它的互联度是极低的，“外挂程度”越低，使这个房子在某种程度上已经不再是一个终端，而只是一个孤岛了。

房子所处的地段决定了它的“外挂程度”，因此房地产的铁律是：地段！地段！地段！一个房子的“外挂程度”越高，就越可能具有超高的价值。

尤瓦尔·赫拉利还说过，“人类的历史就是一部讲故事的历史”，它是正确答案之一，但不是标准答案。我们既可以说“人类的历史是一部能量包的历史”，也可以说它是一部外包的历史——这个句型可以推演出很多很多。

# | 避免“饕餮困境”

听了“企业中的索取者和给予者”之后，我觉得，对于员工的激励，如果是做出了成绩就和一项好的业务，最好是以奖金的形式，而不是涨工资。如果涨了工资，员工容易习惯，而激励的效果会逐渐衰弱，边际收益递减；而给了一笔奖金，会让人感觉更好，等下一次再做出好成绩的时候再奖励——奖金是来鼓励做的好，工资则对应职位信责任。

吴伯凡

这个同学说的很对。激励的时候我们要避免“饕餮困境”。

“饕餮困境”是说，古代传说的一种叫“饕餮”的动物，它吃东西主要是用来长它的肚子的，吃得越多，肚子就越大，胃口自然也就越大——很多“激励”最后没有转化为成本本身的能量，而只是把胃口增大了，或者说，把要求增加了，你无形中给予他的东西变成了让他觉得你欠他一个诱因——这是“激励”中常常出现的一个困境。

# | “人生始于服务, 终于服务”

无论是经营一个企业，还是经营我们自己，我们都要看到那些关键的要素、场景、格局。如果你对场景的判断是错误的，那么你所要求的工具和方法自然就是错误的。极端的情况就是，手里拿一把钉锤，看什么都想钉——表面上我们在解决问题，其实是在制造更大的问题。

# 第二，不仅世界是复杂的、不确定的、模糊的、易变的，我们自己也是。

我曾经讲到过“七个亚自我”，表面上我们是一个完整的自我，实际上我们由七个轮值CEO以不确定的规律轮流执政、轮流出场。正如我们看到的世界是我们不自知自定义的世界，我们的自我也是一个被悄悄定义、悄悄锁定，自己对这种状态浑然不自知的自我。

美国的金鹰集团的教母阿兰德曾经说过：“你对我说，我爱你，我要问的是，你有我吗？”——我们可以问问自己：我在干什么？我在奋斗？我在哭泣？我在悲哀？我olj在愤怒？那个是你吗？你真的有那个“我”吗？

我们的自我很可能是一个股份有限公司，占有一定股份，但可能很小。大量的股份已经悄悄地被一些别的因素所掌控——那些我们不知道的心理病毒、隐性的玩家——我们已经丧失了对我们自我的所有权和掌控权。

“我真的对我的自我有控股权吗？”针对这个问题，我也讲到了很多概念：本能到底是什么，心理病毒、思维病毒，还有微选择、成见、离婚基因、愚人税……这就是我一直在给你分享的第二个问题：意识到自身的复杂性。在你想搞定世界、搞定别人之前，先把自己搞定——你可能早已经搞不定自己了。

# 第三，既然世界是不确定的、复杂的、模糊的，我们的自我也是不确定的，自由意志是不存在或者是很稀薄的，我们对自身的掌控权实际上比我们想象的要低得多，那么，在不确定的世界和不确定的自我之间的那个方法、路径就是确定的吗？

只有少数人能够看到一个高维度、高像素、高色彩丰富度的世界，就像诸葛亮和司马懿面对一个看上去有点荒诞的场景，都看到了明局之后的层层暗局，找到一种方法。

在你没搞定自我之前，即使方法是对的，使用方法的人，也就是你自己没有搞定之前，那个方法也是没用的。只有像王阳明那样能够真正对自我具有掌控权的人，才可能看到真实的世界和真实的自己，找到一个真正有效的方法。

在我和目标之间常常会出现海市蜃楼，会出现望山跑死马的现象，真正有效的策略很可能不是你的本能和习惯思维告诉你的。

我曾经讲到过：走出黑暗森林的实用主义、黄山松、毒蛇的毒液的来历、乞兵思维、非暴力沟通、助推理论与间谍法则……所有这一切都是在提醒我自己和你：真正有效的路径也是易变的、不确定的、复杂的、模糊的、迂回的。

王安石变法为什么失败？孝文帝改革为什么成功？普京、和珅之所以那么有效地处理事情，以相当隐秘迂回的方法达到他们所要达到目标。原因就在于，他们知道一种真正有效的方法，这远不是我们的尝试和本能能胜任的。

这就是我在过去一年反复讲到的“三合一”主题：

+   1. 我们所面对的世界和场景。
2. 我们的自我。
3. 我们为了生存和发展所选择的方法都是具有远超我们想象的复杂性。

只有找到最真实、最关键又最隐秘的那个目标，才可能拥有一enemy真正有效的方法，我们要像老虎和鹰那样，不在非战略性节点上消耗战略性资源。

我们今天的世界有太多的垃圾信息，太多的引人注目，在不断吞噬我们注意力、损耗我们智力资源和知识信息，但我们要学会看到世界的秘密，避免自己成为一个愚蠢的人。

“愚”字是上面一个禾，下面一个心，就是心陷入到一个角落里，狭隘又不能自拔；“蠢”说的是行动，蠢蠢欲动——蠢蠢欲动是无效的行动，是轻举和妄动。

面对这个复杂的世界，我们的认知能力永远是不够的，但我们至少能够有意识地将自己的愚、自己的蠢减少一点儿，在这个险象环生的、充满复杂的世界里少交愚人税。

这就是我在《伯凡·日知录》结束的时候，想跟你说的几句心里话，我在“得到”的第二季课程很快也会开通。

在《伯凡·日知录》这跟跟跑跑的一年里，我得到了很多，有收获，也有教训，我会尽自己最大的努力，把第二季课程的界面做得更加友好，更具有系统化。”形散而神不散”的内容的确给你增加了认知的负担，在第二季的课程里，我会有一个明显的改进。

当然，第二季的内容会跟第一季有比较大的不同。现在课程的名称和内容还没有最终确定下来，想剧透也剧透不了，但我希望我能够在第二季的课程里再见，也希望有更多的朋友加入到我们这个学习和知识的社区，在接下来的一年里，让我们共同成长。
