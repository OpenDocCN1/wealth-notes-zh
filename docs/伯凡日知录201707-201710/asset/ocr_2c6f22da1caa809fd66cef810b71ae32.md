# 周末彩蛋 | “晒出你的知识账本”——第二次获奖名单

这是“晒知识账本”活动的第二个 FEB， 大家的留言依然很踊跃，相信你们在“输出”的过程中一定收获到了新的知识和感悟。

这次我要送的书是《新管理革命》，作者是美国的管理学教授戴维·布尔库什（David Burkus）。这本书是一部很颠覆常识的管理著作，它会从很多意想不到的角度给你解读管理，比如为什么要给离职员工提供奖金，为什么要鼓励员工随心所欲地休假等等。我之前讲过的一部分内容就是受这本书的启发，希望这本书也能给你带来收获。

# —— 获奖同学及留言 ——

基因库的多样性，为有效应对不同场景提供了路径依赖，看完这篇文章我得到了两个点：一是凡事预则立，不预则废。想要完成目标，必须做好事前准备，要让天下雨首先要“制造”乌云。二是看似无用或者不相关的基因，可能在冥冥之中会与场景形成绝妙的匹配，从而诞生出一个新物种，可能会在未来兴起一场“革命”。就拿读书为例，读了很多书积累了知识，虽然很多知识在当下的场景里应用不到，但可能未来某个场景里起到意想不到的作用。所以读书用到时方恨少，这也说明了我们大脑基因库中的知识缺乏，无法应对实际生活中所遇到的各种场景。脚踏实地，不积跬步，无以至千里。转换思维，有则以为利，无则以为用。
