# 周末总结｜考试型学习，让孩子失去的是什么？

提起教育，大家的第一反应基本都是现在的教育存在的一些问题和弊端。教育的问题究竟出在哪里？可以从哪些角度去思考解决？今天咱们从三个问题入手，一起分析一下教育存在的问题及可能的解决方案。

# Ⅰ 问题一：“孩子的起跑线到底在哪？”

我们经常说的一句话就是，不要让孩子输在起跑线上，可孩子的起跑线究竟是什么？如果输了的话，输的是什么？

如果用一句话来回答这些问题，那就是：真正决定一个人的幸福和成就的是一个人的非认知技能，这才是真正的起跑线。而家长不停地给孩子报班学习，把所有的积蓄拿去送孩子进名牌小学、名牌中学、名牌大学，那都是在提高孩子的认知技能，并不能提升孩子的起跑线。

什么是非认知技能？简单说，就是一些无法轻易辨识和测量，但确实对人的幸福和事业有潜在巨大影响的东西。我们可以列举不少非认知技能，但其中有一个非常重要，同时也常常被我们忽视的，那就是社会兴趣或者叫社交兴趣。

所谓社会兴趣，就是对他人总是保持一种合作与建设性的姿态，对与他人的交往、融到一个群体当中怀有深厚的兴趣。如果说我孩子也有几个很知心的朋友、跟我们关系也很密切，这叫不叫社会兴趣呢？这不叫。所谓社会兴趣是，不仅是对所爱的人、亲密的人有直接的感情，而且是对周R的，包括陌生人都有一种不抱直接目的的感情，另外，他还有对现有状况的认可、和对未来状况乐观的憧憬。所有这些加起来才叫做社会兴趣。

大量的统计表明，如果一个人的社会兴趣和愿望充分的话，他的幸福程度和他的事业成就远大于那些社会愿望不足的人。有些人即使凭着某个认知上的特长、专业能力取得了显而易见的成就，社会也给予了他很大的回报，但如果他没有足够的社会兴趣，依然会得不到幸福感，因为人的幸福感的主要来源是人际关系。简单地说，我们可以把社会兴趣的缺乏看作是一个巨大的价值黑洞，这个价值黑洞会不停地吞噬你的各种努力。

举个例子，在一个多子女家庭当中，常常伸手索取帮助的那个人，往往是经济状况不好的人。表面上看是因为他经济状况不好，所以他寻求索取，实际的情况是因为他经常索取，所以经济状况不好。或者说，由于他缺乏合作的愿望和能力、缺乏给予的愿望和能力，更缺乏怯情的能力，所以成为一个会吞噬能量的人。

# 那么如何判断一个人是否有社会兴趣呢？三条标准：

+   第一，当一个人面对问题的时候，他常常想到的是不是跟别人合作？当别人遇到困难时，他是否会习惯性地帮助他人？
第二，在与他人交往的时候，是否一直保持着“给多于取”的倾向或者是习惯，楷怕是在日常平等的交易交换中，他也习惯于让自己付出的大于自己得到的？
第三，在与人交往的过程中，他是否总是试图和对方保持同频共振，而不是自说自话？

这三点总结起来，重点就在于给予。

# 那么，如何建立社会兴趣呢？

最重要的一点，就是要意识到这是一种非常重要，又常常被我们忽略的能力。如果在这这一点上出现缺失的话，那就是一种结构性、基础性的缺失。这听起来像是废话，但我们看很多厉害的人，他们就是有着这样的共同点，他们都对这种别人非常容易忽视的能力极为重视，比如爱因斯坦、范仲淹和曾国藩。

> 爱因斯坦说：“我每天上百次的提醒自己，我的精神生活和物质生活都依靠别人，包括生者和死者的劳动。我必须尽力以同样的分量来报偿我所领受了的和至今还要领受的东西。”

中国历史上位了不起的政治家、军事家、文学家范仲淹也说过类似的话：“吾邀夜就寝，即自计一日饮食奉养之费及所以为之事，果自奉之费与所以为之事相称，则;"><i>...</i>

所以说，父母在教育孩子的时候，一开始就要有意识的让孩子建立一个不等式：给予要大于索取。这是一件供了不起的工程。一旦完成，孩子就会成为一个能制造热辐射的人，无论到哪里都有良好的气场，这比认知技能重要得多。

# Ⅰ 问题二：“为什么不能对孩子实行标准化教育？”

孔子有一个重要的教育理解，就是“因材施教”。孔子的学生五花八门，有杀猪的、有赶车的，各种各样的职业，但他往往是针对这个人，你想干什么，我现在就教你干什么。反观现在的教育我们会发现，不管你是誰，所有课你都要学，因为高考是算总分的。

可问题在于，每个学生适合的教育方式和内容未必相同。德鲁克曾评价现代教育说，现代教育的创立者有一个共同的认知谬误，就是这个世界上只有一种正确的学习方法，这是现代教育的一个前提。为什么会以这样一个东西作为前提呢？原因是现代的学校本质上它是工厂，是工业革命兴起，工厂出现，教育这样一个古老的行业就也开始用工厂的方式，用流水线、分级的、标准化的这样一套模式来塑造人。

# 学习模式分为三种：自学型、对话型、输出型。

比如贝多芬的学习方式就是做笔记，因为他只有通过笔记，他的思维、他的情绪才会调动起来；再比如英国学者培根，他说自己学到的有用的东西都是自学来的，这种自学不是别人讲的时候他仔细听然后做点记录下来，而是一定要自己动手操作，进行模索性的、探究式的学习，听来的东西他没有感觉。

# 表达模式分为两种：阅读型和倾听型。

什么叫阅读型？简单地说是照本宣科型，说之前一定要很清楚地把思路写下来，然后才能说清楚。

所以，在教育孩子或者自我教育之前，要搞清楚最适合的模式是什么。如果你还在不清楚的情况下就随便坐在哪条起跑线上，很可能是瞎跑误工夫。
