# ｜老马识途

有一个成语【老马识途】，意思很简单，姜还是老的辣，老司机的作用不可替代。这成语来自于一个历史上的真事：齐桓公受燕国之邀，去打击入侵燕国的莒族山戎，在行进的路上，一下子不知道往哪走了，于是就有人就想了一个办法，让一匹老马领着大家走出了那个迷局，到达了目的地。

用认知科学的话说，老马的这种认知力是一种下沉到潜意识，或者它本来就只有潜意识的那种能力。

听《伯凡·日知录》的朋友可能会发现一个特点，我经常爱讲动物的故事，这是我给自己定 dun 一个小目标，就是“格物致知”，格动物，格植物，然后从这些动植物的行为和生存方式里感悟到一些比我们人的能力更高超的一种智能。

“我认识的人越多，我就越知道狗的可爱。”听起来好像是一句骂人的话，但是当很多人类世界，特别是商业世界里的现象没法解释的时候，我就越觉得动物的智能要高于人的智能。

# ｜大马哈鱼和小虾虎鱼的超能力

![](bbox=[0.18, 0.0014199999999999998, 0.89, 0.0017])

大马哈鱼是一种非常神奇的动物，它的几个能力至今科学家都无法解释，是一种非常神奇的能力：

+   大马哈鱼从它出生的地方沿着河流一直往外游，游到出海口，进入到海洋；

四年以后，大马哈鱼长大，具有繁殖能力的时候，又游回到它的出生地，不管海岸有多少个河口，它一定能找到它当初出去的那条河，然后沿着这条河一直往上；

由于天气、气候的变化，大马哈鱼回到那个地方的时候，水流可能已经发生了変化，但它能准确的找到它出生的那个地方；

大马哈鱼小时候，在出生地的周围就不停游动，这个游动的过程就是一个扫描和存储记忆的过程，让它在水里就能看到地形，当水退了，这个地方变成水洼的时候，它知道从这个水洼跳到那个地上，再在地上沿着固定的方向跳到另外一个水洼……一直跳、蹦到它出生的那个水洼里。

还有一种跟大马哈鱼有相同能力的鱼——小虾虎鱼，也是在水洼里浅水的地方生存的。水位降低，原来的大湖变成了一个个小水洼的时候，小虾虎鱼也能够找到它当初出生的地方。

# ｜健忘症患者“习惯的力量”

这种能力不仅动物有，人也有。

在《习惯的力量》里有一个著名的病例：有个得了健忘症，甚至认不出他的妻子的。每天早晨，他的妻子都要进行自我介绍，然后告诉他什么东西放在什么地方。但是dj一觉醒来，他又什么都不知道了，又得重新学习。这是一个特别痛苦的过程，这样的人一旦出门会非常危险，他根本找不到自己的家，他的妻子必须天天紧盯着他。

有一天，意外发生了，他的妻子发现他不在家，就非常紧张地四处寻找，最后费了很大的劲儿，终于在一个公园里找到了她的丈夫。这个得了健忘症的人坐在一个长椅上，这个长椅是几十年前他和妻子谈恋爱时经常坐的那把椅子。

这个画面看起来很浪漫，但他妻子关心的是，他是怎么找到这个地方来的，他有没有能力自己走回家去。于是他妻子就尾随在后面，一直跟着他走走走，走回了家。

一个得了健忘症的人，居然能够知道回家的路，这是不是跟大马哈鱼和小虾虎鱼有异曲同工之妙呢。

# ｜刀锋竞争力

通常我们知道自己知道什么，也知道自己不知道什么，我们的知识库有一部分是我们自己能看见的，但还有一部分是隐藏在黑暗当中，我们根本不知道它存在，但是它常常在最关键、最危险的时候支配我们的行为。有些老司机之所以能够在大 стрель的时候急中生智，救自己一命，原因就是他调动了他的暗知识，或者是潜知识。这样的知识在我们的知识的体系当中份额可能不多，但是它的重要性不言而喻。

我们用几倍、甚至10倍的钱去买一辆豪车，往往是因为豪车贵在它有某一个普通车没有的功能。这个功能一般是不常用的，但在极端的情况下使用这个功能就可能救你一命，或者说，它具有一种当别的车完全无能为力时还能发挥出乎意料作用的力量。

比如路虎的一个功能就是，当车陷入泥坑里的时候，你可以通过一根铁链搭在一个大树上，它就能自己把自己给拉上来。这个能力你可能一辈子用不了几次，但是要为这个使用概率很低的能力付出超高的费用，所以它是一种很珍贵的能力。

我们经常说我们有什么能为，但我们忘记问自己一个问题：我们有没有那种派上用场的机会很少，但在某个场景下是极其关键的能力呢？

有没有这种能力，能把高手和低手一下对比出来。包括企业也是这样。

两个企业看上去都差不多，这个企业有的，那个企业看上去也有。但在关键的时候，这个企业就能够完成一个飞跃，那个企业就不行；或者在经济环境特别恶劣的情况下，这个企业隐藏在黑暗中的能力可以发挥作用，让企业化险为夷，别开生面。所以我们讲竞争力的時候要特别留意【边缘竞争力】，或者是【前沿竞争力】，还有一种译法叫【刀锋竞争力】（edge competency）。

![](bbox=[0.18, 0.0092, 0.9, 0.009800000000000001])

一把刀子，它的刀锋是不是处于边缘的？我们也可以说它是处于前沿的。如果我们把企业的能力比喻成一把刀，那么真正管用的，尤其是在紧急情况下管用的，一定是刀锋，尽管它处于很边缘的位置。

我们在不断提高自己能力的时候，要有意识的培养【刀锋竞争力】，或者叫【边缘竞争力】。有了这种能力，你在得健忘症的时候，也还能找到回家的路。

# ｜自下而上的培养

那怎么才能够培养【刀锋竞争力】呢？培养这种能力的過程是极其复杂的，绝对不是一句话能说清楚的。但是，这里可以明确说的是培养这种能力的方向。

现代教育在培养我们能力的时候，常常遵守一种“自上而下”的能力培养方式。自上而下就是首先要学习理论门类里的理论，了解原理，然后再根据原理解决具体的問題。

比如你想了解商业，就去读商学院、读MBA，懂了这样一些道理，你就能做生意、能经营企业了——我们现在的教育就是以这样一个逻辑在进行教学。但真正管用的教育，尤其是培育刀锋竞争力的教育方式恰恰是相反的。它是自下而上的。
