# ｜要合作，不要博弈

作为管理者，使用“远离婚姻式和谐”这个套路合适，但作为员工，如何破这样的局？我的管理者是个非常强势又事无巨细，凡事都要管的女领导，听不进建议，还觉得她自己很聪明。

# 吴伯凡

从这个问题里能看到另外一层意思：这位同学想破解领导的局，或者说，他跟领导已形成了一种“博弈关系”——总以为对方在跟自己出什么牌。

“博弈关系”是在生活工作中都存在的一种关系，但它不是人际关系的全部，除了“博弈”，还有合作的关系，而且，相处之道一定是要用合作关系来涵盖博弈关系，而不是相反。

# ｜“你是一切问题的根源”

吴老师，可否推荐几本分析事件性质的书，比如事件的发生是因为个人性格问题，还是价值观判断问题，或者个人道德问题、个人习惯问题，或者政治问题。

# 吴伯凡

印象当中我是没有读过这样的书的，但我想与这位同学分享一个观点：面对一个问题产生了一种强烈的冲动，这到底是什么原因导致？...你忘记了一点——一事有补，还是无补。你是要解决问题，而不是解释问题。

# ｜积极的悲观主义&消极的乐观主义

分享一个我自己关于工作生活的感悟：“用不完也不够用的智慧，浇不灭也燃不起的斗志，消灭了又出现的怪兽。”我这算“消极的乐观主义”吗？

# 吴伯凡

我所定义的“消极的乐观主义”是那种相信“要是怎么怎么就好了”这样一种句式的人。我自己曾经也是这样一种人：

+   - 当孩子出生的时候，我想“孩子要是3岁就好了”；
- 当孩子3岁的时候，我费了老劲儿带他去找幼儿园，找到了幼儿园以后并没有“好了”，孩子天天不愿意去上幼儿园，要劝他，各种威胁利诱让他去，这时候我“幼儿园毕业就好了”；
- 当孩子上小学以后，我发现问题比想象得要多的多，他整天跟别人打架、偏科……
