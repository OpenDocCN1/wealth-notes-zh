# | 避免“饕餮困境”

听了“企业中的索取者和给予者”之后，我觉得，对于员工的激励，如果是做出了成绩就和一项好的业务，最好是以奖金的形式，而不是涨工资。如果涨了工资，员工容易习惯，而激励的效果会逐渐衰弱，边际收益递减；而给了一笔奖金，会让人感觉更好，等下一次再做出好成绩的时候再奖励——奖金是来鼓励做的好，工资则对应职位信责任。

吴伯凡

这个同学说的很对。激励的时候我们要避免“饕餮困境”。

“饕餮困境”是说，古代传说的一种叫“饕餮”的动物，它吃东西主要是用来长它的肚子的，吃得越多，肚子就越大，胃口自然也就越大——很多“激励”最后没有转化为成本本身的能量，而只是把胃口增大了，或者说，把要求增加了，你无形中给予他的东西变成了让他觉得你欠他一个诱因——这是“激励”中常常出现的一个困境。

# | “人生始于服务, 终于服务”

对有关“taker与giver”的话题，我是深有感触的：硕士应届毕业时，我和全年级40多名同学去一个单位面试。经过一番“群殴”，其他人全部落选，只有我被录用了一一那是一家非常棒的公司，而我也不算是最优秀的。后来，在一个很偶然的场合，我和经理聊起了当初面试的观感，她说我和别的同学最大的区别是，在谈薪水这个环节，别的同学都说自己能力如何强，希望公司给多少的薪水，而我的回答是“我之前实习做过什么，到公司我可以学着做并很快能胜任什么，不直到这能给公司带来多少价值。”——我想，经理当时也许就是从我的回答中判定我是一个giver而最终选择了我吧！

吴伯凡

# | 富有弹性的坚定

我听了“助推理论与开明家长制”很有感触：在国外生活了快20年，深刻体会到，和我们农耕民族不同，商业民族常常和陌生人打交道的过程中，已经形成了一套独特的语言体系。比如说，如果遇到对方说话前后不一致，中国人常常喜欢略带愤怒和攻击性地反问“你不是说XXXXX吗！”，而英文中的说法是“I thought you said.....（我以为你说的是.....）”暗示自己可能是听错了，但对方通常都会明白自己绝对没有听错——这两种不同的方式产生的反应截然不同。

吴伯凡

# | “设计”角度的“助推”

让别人按照自己的意愿做事而不让别人察觉，感觉是根据自己的自由意志做事——这应该就是“助推理论”的“行为设计学”和《强力瞬间》的“体验设计学”。人的行为和体验被认为设计后，我在想人类还有什么不能被设计的？

吴伯凡
