# | “社交杠杆”

生活当中，我们常常看到有些人在各种场合里不遗余力地找各种人要名片、扫微信，然后在另外的场合，这些人会打开自己的微信给别人展示“你看我有谁的微信，我有谁的联系方式”。这在明眼人看来，是一种很无用的行为，哪怕是站在他自己的角度，这也是很无用的一一你认识谁不重要，你有谁的微信不重要，有多少人主动给你发微信才是更重要的事情。

这里就存在着一个很大的认知盲区：“社交力矩”，或者“社交杠杆”。

当我们看到地上有一块大石头的时候，我们显然是接触到了这块石头，但是你能不能把这块石头搬起来，让这块石头发生位移，也就是对这块石头的状态有所影响，那就是另外一回事了。如果你找到一个杠杆，你就能撬动这块石头；找不到，凭你的这点儿力气费再大的劲儿，你也搬不动这块石头。所以，这就有了阿基米德的名言：“给我一个支点，我能撬动地球。”

阿基米德的这句豪言壮语其实是一个很朴素的力学原理：阻力、阻力臂和动力、动力臂之间的关系——动力×动力臂=阻力×阻力臂。

假如你要用杠杆实现“四两拨千斤”，那就意味着你的动力臂的长度应该是阻力臂长度的2500倍。一个人的力量基本上是固定的，你能撬动多大的物体，取决与一个关键的变量：力矩，也就是这个力臂的长度。

在社交中，接触到一个人不重要，你个人的重要性、地位、身份不可能一夜之间有多大的变化，而你能否影响到你接触到的这个人，取决于你的力矩。

# | 特权瞬间

我最近在看《先发影响力》，这本书的作者罗伯特·西奥迪尼，也就是畅销书《影响力》的作者，他说了一个很好玩的一个场景：

罗伯特·西奥迪尼跟一家商学院联系，申请到这个学校做研究。这个商学院给他提供了最好的的条件下：各种各样的设备，最好的办公条件，并且承诺不打扰他。

有一天，西奥迪尼来跟商学院的副院长商量做客座研究期间的琐事，这位副院长非常热情，说：“我有一个好消息告诉你，我能搞到你想要的办公室，电脑的性能比你要求的还要强劲，秘书、图书馆、停车位和长途电话，什么你都别担心，我们全都帮你办好。”

西奥迪尼听了以后就很感激，向副院长道谢，但他自己心里头总觉得有点儿过意不去——这里就要使用专门的词：特权瞬间，也就是在你有很大歉意，不好意思，难为情的这一瞬间，对方是可以行使特权的——于是这个副院长就牢牢地抓住这个“特权瞬间”，接着说：“不过，你也可以帮帮我们，我们刚好缺一个给MBA学院上专业营销课的老师，这事让我很头疼，如果你能任这个课的话，那就是帮了我很大的忙，给了我很大的面子。”

罗伯特·西奥迪尼之所以申请到那个学校去做客座研究，就是想找一个特别清静，不被别人打扰的地方好好做研究、写书。如果要上一门课的话，就得备课，就得给那些刚加入学的MBA用最通常的语言讲那些ABC的东西，这是很需要花费心思的，而且，跟西奥迪尼的研究毫无关系。

但还来不及思考，西奥迪尼就说：“好吧，那好吧。”虽然他答应以后就后悔了——特权瞬间消失的时候，你已经答应过别人了。这个时候，西奥迪尼称之为“特权瞬间”。

“瞬间”的英文是moment，这个词还有一个解释就是“力矩”，力学上所讲的力矩。

可以想象一下，这个副院长如果专程去拜访著名的罗伯特·西奥迪尼，让他在商学院开一门课，那相当于是要撬动一个5吨的石头，完全是不可能的。但是，他给西奥迪尼提供了各种超预期的好处，他的力矩就变得很长，虽然他的力量、身份并没有变，但由于这个力矩很大，所以，副院长就完成了这样一件事情。

很多社交菜鸟不明白的是，遇到渴望结交的一个有地位的人就采取最直接、最本能的方式，其实是最没用的，因为毫无力矩，就像一个人看到一块5吨的石头就不停地搬，是完全搬不动的。因为你的力臂几乎是0，就算是把奶的力都使出来，都没办法影响别人，更没有可能让别人来为你服务。

说到这里，我们也就明白了为什么那些社交场上的交际花和准交际花的社交效果非常差，她们在做的一件事情是不断地传播自己交际花的名声。而跟别人接触的那一瞬间，别人已经在心理上拉黑了她们。虽然每天都在扮演人脉很广的交际花形象，但实际上是没有人脉的，因为她们没有社交力矩，或者说，她们的社交力臂太短。

# | 恋爱中的特权瞬间

“特权瞬间”用的最多的，是谈恋爱的时候。我说一个真实的故事。

主人公是一个非常著名的企业家：这个企业家读大学的时候暗恋上了新闻系的一个女生。这个女生很优秀，而且那个时候新闻系女生很骄傲，不大看得上别的系的男生。但这颗爱情的种子深深地埋在了这个年轻人的心里，当他成为著名企业家之后，心里还是惦记着这个新闻系的女生。

他得知这个女生在某报社工作，然后利用自己的资源，掌握了这个女生到外地采访的所有行程。然后这个女生每次出差进到酒店房间，都看到一床的玫瑰花，而且每一次的颜色还不太一样，花旁边还会放一些巧克力什么的。大概有那么五六次以后，这个企业家精心设计了一个偶遇，他只问了这个女生一句话“玫瑰花你喜欢吗？”——这个女生本来看来一直都很玫瑰花的这个困惑当中，忽然发现这个人就是真命天子啊——这一瞬间就叫“特权瞬间”，无论说什么都是对的。后来，这个新闻系的女生就嫁给了这个著名企业家。
