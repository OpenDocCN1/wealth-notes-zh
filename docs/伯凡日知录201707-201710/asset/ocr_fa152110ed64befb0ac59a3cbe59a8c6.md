# | 牺牲股东利益的亚马逊

昨天我们讲到了亚马逊的飞轮效应，讲到亚马逊从成立开始就力图把自己打造成为一个全球最以客户为中心的公司。这不只是 一句宣传口号，亚马逊用一套的制度和流程，把“以客户为中心”落到实处，有人甚至说，亚马逊是一家拜客户教的公司。

我们说一个公司必须要核心价值观，当你面对几种路途的时候，你如何取，如何舍，那个标准就是你的核心价值观。核心价值观最大的作用是做战略时一个取舍标准。

亚马逊本来也可以通过为客户引流量的方式立即赚到很多的钱，但它不愿意损害顾客的购物体验。为了让用户的购物体验达到极致，它投入了巨大的资源，而这些投入的资源又很难立即得到回报。

比如说，亚马逊为了保证它的会员能够在两天，甚至是2小时之内拿到货，就必须要用大量的资源来优化它的物流体系。与此同时，还要投入大量的资源来优化它的后台，提高交易过程当中的智能性等等。用户得到了好处，却没有为这些好处额外付钱，这样导致的直接结果是：亚马逊不怎么赚钱，长期以来处于一种亏损的状态。

这么说来，亚马逊算是一个对股东不负责的公司：你为了讨好客户，牺牲了股东利益。真的是这样吗？

# | 同心圆思维

![](bbox=[0.22, 1.7, 0.9, 2.4])

同心圆——圆心相同半径不同的圆。

企业通常的经营行为是投入→产出→获得收益。亚马逊的整个经营行为贯彻着一种同心圆结构，也就是同心圆的思维。

亚马逊的投入首先是解决眼下的这个交易。但是，如何让用户的满意度达到最大化，它的投入和产出就会出现一个不对称。用我们以前的概念说，它的经营行为当中_Core_有明显的外部性，它的投入是不进入与客户的交易清单的。从表面上，它的交易是一个小的圆，但是它做的事情是一个更大的圆。

# | 新涟漪效应

我们往水面投一块石子的时候，水面上就会出现一个涟漪，也等同于一个同心圆。

![](bbox=[0.22, 3.75, 0.9, 4.55])

有个效应叫涟漪效应，一般指一个负面的破坏性行为会1

但是我们可以重新定义一下涟漪效应。这个新的定义就是，你的行为可以解决眼前的事 情，但是这个投入会引发额外的效果。这个效果用户是得到了，但是是在交易之外的。从一个单次的博弈来看，这个投入是 不划算的。你做很多事都是在亏 亏事。但亚马逊有一个机制，能够将它投入的成本在当前的这个交易中完成消化，但在消化的过程中会导致微利，或者是亏 损。虽然亚马逊持续投入所引发的效果并 没有为它赚钱，但这些能力却在悄悄的累计。

比如，亚马逊为了优化它的用户体验，不断完善它的物流系统，在持续投入的过程中，它的物流系统与 其他公司相比，已经有了明显的竞争优势。我们把这样的一种现象称为“能力溢出”。

又比如，亚马逊为了让它的用户体验到一种极致服务，设立了会员制度，亚马逊会员能够享受两天、甚至2小时到货的好处。为了实现这个目的，亚马逊做了很多的事情，吸引了越来越多 的用户加入，现在，它的会员有6000万人。

事实上，亚马逊的物流服务和云服务越来越超出它原有的范围，成为一种公共服务，一种“自来水业务”，每一个人 都可能需要，每个人都离不开它：

+   1. 亚马逊物流为其它的商家，包括在亚马逊开店的第三方商家提供服务。这个边际成本很低的。本来是一个辅 助性的业务，逐渐就变成了一个可以进入交易体 系的一个业务。\n2. 亚马逊云服务也是这样，本来是为自己服务的，但是为了优化服务体验，云服务的能力就越 来越强大，就形成了一种独立的业务能力，最后成为一个独立的业务板块。

# | 同时包含当前和未来的生意

亚马逊这种从外部性向内部性转换的逻辑，和高手们下棋的情形差不多：

高手们 下棋的时候，表面上是在应对当下的这一 步棋，但在这一 步棋里也存在一个同心圆结构，或者说有一个涟漪效应，既是为应对和解决眼前的 问 题，也是为未来布局。

当亚马逊专心致志把眼前的业务做到最好的时候，它悄悄培育出来一种另外的能力，它的经营行为当中都包含着一种同心圆结构，或者说它的效果是超出它既有的业务之外的。所以，亚马逊的生意是一个同时包含着当前和未来的生意。

我们不太容易看见未来的那个维度，但随着时间的 变化，随着能力和资源的积累，那些超出当前业务的能力和资源开始显 现出来。这就是我们今天看到的亚马逊的竞争优势。

# | 做别人看不到的事

德鲁克说过，什么叫伟大的事业？伟大的事业就是你为一件事情付出的努力当中，至少有一半别人是看不到的，或者说是当时看不到的。

亚马逊的经营行为当中总是包含着外部性，也就是说它在任何一个交易当中总是做了一些白干的事，一些亏事，一些不能够回 报的事。这恰恰就是亚马逊跟很多公司最不一样的地方。

当我们还把亚马逊定义为“一个在网上卖书的公司”、“一个卖很多商品的网上零售公司”的时候，它一边把这些既有的显而易见的这些业务做到极致，一边悄悄的在生成不止一个的另外的业务。

贝索斯甚至不在股东会上提网上书店和网上零售的业务，他认为亚马逊业务的三大支柱是：

+   1. Prime，会员服务；\n2. marketplace，为第三方的商家提供的服务；\n3. 云服务。

贝索斯认为的这三个支柱性业务都是在亚马逊显而易见的业务之外悄然形成的，就像珊瑚岛的形成：慢慢在水底下聚集，终于有一天露出了头。亚马逊的价值就在于，它付出的至少有50%别人没有看到的努力终于在今天开始露头了。

# | 够是永远不够的

拜客户教的亚马逊公司为了给客户提供超值和超预期的服务，做了很多很多的事，这些表面上好像是白做的事情使它在既有的业务之外形成了自己的新业务板块。我们可以预见，亚马逊现有的核心业务的比重在它的整体业务中将越来越小，这是一种不是转型的转型。

专注于跟前事情的同时，不动声色的做面向未来的事情，亚马逊以它的独特的方式解决了月亮和六便士的问题：六便士是它的核心业务，钱很少，在它把六便士的业务做到极致的时候，逐渐的在接近月亮。所以，我们把亚马逊的这样一种经营方式称为“同心圆思维”。
