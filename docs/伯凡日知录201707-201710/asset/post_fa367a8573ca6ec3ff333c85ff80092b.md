# | “到底是什么在造船”

# ｜天是董事长，人是CEO

事实上，中国传统思想对于“到底谁在造船”这个问题已经给出了非常明确，也非常深刻的答案。

《天工开物》这本书，本来说的是很实际的事情：如何造出各种各样的器具，是一本工科生读的书。而实际上，这本书在讲，是天的功夫在开发物种，表面上是人在造物，实际上是借助于天工在造物。

还有一个类似的成语“巧夺天工”：我们做一个事情要做得足够的好，就是把天做的工作变成你的工作。也就是说是让大海造船，而不是你来造船。

类似的说法也有很多：说一个东西完美，把它形容为“天造地设”；某种联盟特别好，叫“天作之合”；中国传统思想中特别强调“天人合一”，这个“合一”不是让天来合人，而是让人去合天。

人可以做工作，但是你的工作一定要配合天的工作，你顶多是一个执行者：天是董事长，人是CEO，这个关系千万不能颠倒。

我们做一个事情的时候，不是自己在做这个事情，而是在“替天行道”。我们的工作类似于天职，是天赋予我们的一种智能、一种责任。用这样的一种思路做出来的东西才可能是留得住的。人算不如天算，人做不如天做。

所以，我们读到Alan“到底是什么在造船”的时候觉得很精彩，而熟悉中国传统哲学就知道，他的这种理念并不是原创。我们一定要记住古人的提醒：我们造物其实是“天工开物”，做事不要沉浸在自己的想象当中，不要以为创意就是天马行空。最好的作品，最好的产品都是巧夺天工的产品。

模块式创新，乐高式创新，在某种程度上也是一种“巧夺天工”的思路：很多的要素、功能、性状已经悄悄地出现，我们要做的是如何把这些已经出现，但并非由我们造出来的东西集成，做一个不断优化的性状组合，这才叫“新物种”。

# | RPV分析法

上周我们讲到了一个关于公司DNA的理论：一个公司的基因是由决策权、激励机制、组织结构和信息传递方式组成的。如果你要投资一个公司，或者你正在创立一家公司，这是一种分析公司价值的方法和很好的检测手段。

本周我会再给大家讲一种类似的分析方法——RPV分析法。RPV，分别代表了一个公司的资源、流程和价值观，这三者代表了三种决定公司现状、公司运营状况，以及公司未来成长性的三个基本因素。我会通过一些例子，让大家认识到这三个东西之间的关联，尤其是其中特别重要的一一价值观，它是一个企业是否值得投资，是否具有成长性一个非常重要的因素。

与RPV分析法相关的，还有一种类似的观察企业的方法：看企业内部有没有一个“三位一体”的东西，公司是否是“三位一体”的。

“三位一体”本来是基督教的说法：圣父、圣子、圣灵。一家创业公司是否具有成长性，一家成熟的企业是否能够持续成长，在很大程度上取决于这个公司是否具有这种“三位一体”的特征。

圣父：是一个企业的最初确立战略、获取资源的人；

圣子：是执行者，企业需要一个强有力的执行者；

圣灵：是在公司的成长、运营、发展过程中是否]有一种一以贯之的愿景、使命、价值观，面临重大决策的时候能够依据特定的价值观，特定的产业洞察，甚至是按照独特的产业理解做出自己的决策，而不是根据那些短期利益做决策。

我们会以英特尔为例，讲到企业的“三位一体”是如何决定企业的兴衰、命运的——我们在观察很多企业的时候，用“三位一体”的视角来看，往往就会非常清晰了。

# | 公司DNA理论

上周我们讲到一个观点：要识别一个公司的DNA要看四大要素——决策权、激励机制、组织结构和信息传递方式，其中最重要是“信息传递的方式”。无论对一个创业型企业，还是一个成熟企业，甚至一个已经成为巨无霸的企业，都可以从这四个点来进行分析。公司推行的某种变革都是围绕着这四大要素在进行变化的，如果一个公司在这四个点上发生了明显的蜕变、退化、变质，那么这个公司就已经不再是原来的那家公司了，它的DNA已经变了。

“公司DNA理论”是分析企业价值的一种方法，对投资者非常有用。这一类的方法有很多，我还见过一种很特别的分析方法：分析公司董事会里的男女性别结构。如果一个公司的董事会和管理层完全是男人掌权的话，这家公司不管业绩再好都不能长期持有，因为它阳气过重，就可能会导致“？”——这是美国一家投资机构创立的一种理论，据说对于投资者非常有用。

# | RPV分析法

今天我们讲的“RPV分析法”，也是分析公司价值，分析公司健康程度和它运行状况的一种方法。

R-P-V 的三个英文字母，分别是 Resource（资源）、Procedure（流程）和 Value（愿景、价值）这三个词的缩写。

# 1.Resource——资源

巴菲特说“我投资一家公司，不要仅仅看它是否在赚钱，而要看它是如何赚钱的。”——这句话的意思就是，有什么并不是最重要的，是什么更重要。

如何判定一个公司是什么呢？从这三个方面我们就可以判定它的资源是什么，这个资源包含有形资源、无形资源；过去的资源、现在的资源和未来的资源；资源的好处，以及资源本身对企业的限制——你拥有了某种资源，就可能不具备另外的资源，在很多时候，资源过度充反而是一种诅咒。

比如“荷兰病”：荷兰本来是一个很有竞争力的国家，但由于他们资源匮乏，匮乏到连国土都要向海洋要地，最后，成了“海上马车夫”，曾经一度统治世界。这个时代结束以后，荷兰人也发展出很多的产业，但荷兰人最终发现了石油资源——这本来是一件好事，但由于过度充足的石油资源，使整个国家的竞争力萎缩——因为石油太好赚钱了，其他的产业自然就萎缩了。

再比如，一个国家如果房地产特别赚钱，那么事实上，房地产就对其他的产业产生了一种明显的挤压、摧毁作用。现在，俄罗斯就得了“荷兰病”——由于俄罗斯的石油和天然气资源非常丰富，这个国家的很多产业就出现了明显的萎缩，甚至消失了。甚至一旦石油市场出现什么问题，俄罗斯的经济状况就会遭遇到很大的挑战和危机。

# 2.Procedure——流程

流程也很重要，我们经常会见到资源丰富以后导致创新乏力，导致这个国家缺乏竞争力。

“北美和南美的差别”是：南美资源非常丰富, 各种的矿、森林、稀有的植物资源等等，但同时，丰富的资源导致了南美的整个管理创新和技术创新的萎缩——一个公司的管理体系、流程、制度非常重要。

# 3.Value——价值、价值观

Value是价值，广义的Value包括我们通常说的愿景、使命、价值观。一个公司有没有一种超越时代、可以贯之的愿景和心气，是否拥有一颗超越金钱之上的大目标——这个大目标和使命感使得这个公司在面对一个重大决策，进行单一决策的时候，选择了A而不是B——如果没有明确的价值观、愿景和使命的话，肯定会选择眼下有利的，时间久了，这个公司也就渐渐丧失了目标。

尤其当公司穷的时候，大家还有干劲，公司不穷了，管理人员也不穷了的时候，你还如何往前走？企业初创阶段，大家天天加班，到了一定时候，很多关键岗位上的人已经拥有几辈子都花不完的钱的时候，你要怎么给他一个加班的理由——这里的价值观就显得非常重要了。

# | “三位一体”理论

# 1.神秘的数字3

RPV这三个东西是决定一个公司是否强盛、是否长治久安的三个重要要素。

3其实是哲学和宗教上的一个很神秘的数字。中国道家讲“道生一，一生二，二生三，三生万物。”西方文明里也很崇尚3，比如基督教讲“三位一体”——圣父、圣子、圣灵。我曾经推荐过一本书叫《三位一体：英特尔传奇》，讲的就是英特尔的发展。英特尔从一家很小很小的公司，在比较短的时间内成为一个行业的开创者，并在相当长的时间里一直是这个行业的领头羊，原因就在于它拥有一克“‘三位一体’的东西。

# 2.三位一体：英特尔传奇

在《三位一体：英特尔传奇》的作者，著名科技记者、传记作家迈克尔·马隆（Michael S.Malone）看来，英特尔的三个创始人恰恰代表着“三位一体”：罗伯特·诺伊斯、戈登·摩尔和安德鲁·格鲁夫，这三个人分别就是英特尔的圣父、圣灵、圣子。

英特尔最早成立的时候只有两个创始人：诺伊斯和摩尔，他们本来想取一个跟惠普差不多的名字，把他们两个创始人的名字合起来作为公司的名字。刚开始想叫“摩尔诺伊斯（Moore·Noyce）”，但在英文当中，这听起来是一个很不好的说法——更多噪音（more noise）。后来，他们偶想去就取了一个集成电路专业术语中的前几个字母——英特尔。

大名鼎鼎的安德鲁·格鲁夫并不是创始人，他是英特尔的第一个员工。但他通过自己的努力，最后证明他对英特尔产生了重大影响，在某种程度上，是决定了后来英特尔命运的一个人。所以，罗伯特·诺伊斯是英特尔的圣父，而安德鲁·格鲁夫是英特尔的圣子，戈登·摩尔是英特尔的圣灵。

为什么说安德鲁·格鲁夫是英特尔的圣子呢？基督教的“圣子”，也就是耶稣，他既是上帝的儿子，又是上帝本身——我们看不见上帝，但是能看得见一个有形的，他的儿子。

那“圣灵”是什么呢？是你看不见、摸不着、作为这三者灵魂存在的一——因为戈登·摩尔提出了很重要的“摩尔定律”，英特尔就成了拥有这个行业理论的公司，整个行业的理论都是他们提出来的。

后来，我们看到了英特尔的盛衰，它的发展、兴盛、衰落都是因为三种角色齐全或者缺位造成的。

我们今天讲的RPV分析法，和“‘三位一体’理论”，是一致的：圣父就是R，资源，提供了这个公司所有有形、无形的资源；然后要有一个非常强硬、执行到位的管者，同时，这家公司还有它一以贯之的理论和价值观。

吴伯凡

大家可以用这个“‘三位一体’”理论来分析一个自己知道的公司：它的圣父是谁，它的圣子（执行者）是谁，它有没有一种一以贯之的价值观（愿景、使命），如果这三样都齐全和健康的话，这家公司就是一个生命力旺盛的公司。
