# ｜框架理论

日本的“经营之圣”松下幸之助每次招人的时候，都会问求职者一个同样的问题“你觉得自己是一个幸运的人吗？”

他为什么问这个问题呢？因为他认为，如果自己的公司里都是觉得自己很幸运的人，这个公司才会健康的成长。

松下幸之助的思想的背后有一个他自己可能都没有意识到的理论——框架理论。

“框架理论”跟摄影有关。当摄影师拍摄一个实景的时候，他会精心的取景，从一个客观的场景当中截取他认为最符合他的标准、他的价值的那一部分景物——从这个意义上说，任何一种摄影都是拿真相在撒谎。

“框架理论”后来成为了一种传播理论。所谓“新闻传播”，表面上是在报道真实发生的的事，但你为什么选取这样一个事件登在你版面有限的报纸上呢？在报道这件客观事件当中，你无意当中采取的取舍标准已经悄悄的对这个客观事实进行了PS。

事实上，人的感知行为、认知行为都是在不知不觉之中，用自己内在的框架给现实动了手脚。听起来极其客观的表述是一种不自觉的作弊。我们每天都在用这样一种方式看着我们周围的世界、周围的人和我们自己。

在一群岁数大的人当中，有的人会说“我一天比一天老了”，这种人无意当中选择了悲观主义的框架；而另外一种人会说“我过的每一天都是我生命当中最年轻的一天”——这两种人都没有撒谎，他们的表述如此不同的差别就在于所依据的框架不一样。

如果你太太怀孕了，你就会发现街上有好多孕妇，这并不是因为街上的孕妇增加了，而是你选择了一种新的框架。

《伯凡·日知录》本周会分析框架对个人有什么样的影响，我们在提升自己认知的时候，如何给自己的框架做一些改进和手术，已经这样做的结果会是什么样的。

# ｜语欲胜人症

前一阵我给一些创业者上课，发现了一个现象：这些创业者提问的特点跟他们所经营的企业特点非常相似，他们问题的品质跟他们的经营品质非常的对应。

事后我做了一些调查，发现那些总是以一种理性、建设性态度提问，以解决自身面对的问题和困惑为诉求的创业者，他们企业都经营的不错；而提另外一种问题的人，他们的企业都存在着明显的问题——他们提的问题更多不是关于他们企业的问题，而是包含着某种明显的挑战性。这种挑战性往往都是肢解性的，他们在提问当中获得了某种战胜被问者的快感——这种现象古人叫“语欲胜人症”，现代人叫“雄辩症”。

雄辩者之所以在非关键性的节点上不断的谋求快感，是因为他们并没有在关键性问题上取得真正的成就感和荣耀感。他们被这样一种琐屑的、肢解性的快感所绑架，最后忽略，甚至完全遗忘什么是真正的成就和荣耀。这种挑战的姿态，固然让周围的人感到不愉快，但真正的受害者是他们自己。

《伯凡·日知录》本周告诉你：雄辩者为什么会被这样的快感所绑架，这种快感形成的机制是什么，以及它的危害。

# ｜幸运的发生机制

从框架理论我们引申出另外一个话题——幸运。如果你选择了幸运的框架，你的内心会形成一种幸运的滚雪球效应，你会不断的、不自觉的寻找证明你幸运的各种事实。同时，对那些不幸运、不愉快的事事实来越具有一种忽略的能力和习惯。

有一句话说“我们现在的奋斗都是为了兑现小时候吃过的牛”。吹牛和吹牛不一样，有一种以虚荣为基本诉求的吹牛，还有一种更接近于愿景——当你不断向别人表述你的愿景的时候，你就把自己陷入到了一场自己没意识的赌局当中，也就开始了一场滚雪球的游戏。

世界上 साथ दो种相信，一种是“看见了才相信”，还有一种是“相信了才看见”。当一个人沉浸在他自己的愿景，或者越来越不自觉、非常幸运的被幸运感所绑架的时候，他也就进入到了一场幸运游戏当中。

假戏真做，弄假成真，让一个听起来很不靠谱的豪言壮语，最终成为现实，这就是幸运的发生机制。

# ｜幸运、努力和天赋的关系

如果从幸运的角度看自己的话，我们会发现人生就是一场幸运的奇幻之旅：我们的生命开始于一个亿分之一的幸运游戏，你在只有亿分之一的成功率中胜出，接下来，穿越无数偶然，一步步走到了今天——说到底，生命是一场开始于幸运游戏，尽可能让这场游戏持续得更久一点儿的奇幻之旅。

《牧羊少年的奇幻之旅》讲的就是这样一个故事：一个少年在大树底下做了一个梦，梦见了遥远的金字塔有一个宝藏。他梦醒之后，卖掉自己的羊，历经千辛万苦去寻找宝藏。一路上历经千难万险，九死一生，在接近金字塔的时候，少年落到了一群盗匪的手里，他无意当中听见了盗匪的谈话，这才知道他历经艰辛找到而没有找到的宝藏原来是在他的出发地，也就是那棵树下埋藏着。

这个故事是一种启示，它告诉我们构成我们生命的是三样东西：天赋、努力和幸运。最初游戏当中已经出现的这三样东西会一直伴随着我们的一生，缺一不可。

突如其来的幸运很可能是一场空头支票，关键在于你如何通过救赎、努力、凭着你的天赋将这个空头支票变成一张实实在在的支票。

这就是本周《伯凡·日知录》要和大家分享的四个话题，道理也许大家都懂，但真正要明白这个道理是要在一个个的案例故事和场景当中去感受的。
