# ｜太阳马戏团：马戏界的“四不像”

看过马戏的人总会觉得太阳马戏团的演出有点儿四不像。大家都知道四不像这种动物，它学名麋鹿，但因为它长的像马又不是马；长着角，看上去像鹿，细看又不是鹿；尾巴看上去像驴。像这样的同时它又不是这个，应该说是一种很奇特的物种。

类似的物种还有角马，它虽然叫马，但在动物分类上却属于牛；这种非牛非马的物种还有一个名称叫马羚。

# ｜龙：“四不像”神兽

自然界里有很多奇珍异兽都具有这种四不像的特点，还有就是世界上很多民族象征着吉祥神圣的神兽，看上去也跟四不像差不多，比如麒麟，你说它像什么？还有最虚无缥缈的龙，它又像蛇，又像马，它的爪子像鸡等等，龙是一个组装件。

人们之所以把龙这样四不像的动物作为神兽，一方面因为它集中了各种动物的特性，在古人的想象当中，这种特质应该是具有神力的；另一个重要方面，是因为它很稀缺。

# ｜亚马逊：企业界的“四不像”

现在商业世界的很多公司和产品都越来越具有四不像的特点，比如手机，说它是电话吧，它又有许多电话不具备的功能。我曾经把它叫做“数字化瑞士军刀”，因为它是各样功能的集成，虽然名字还叫手机，但早已不仅仅是手机了。

还有一个“四不像”，就是亚马逊公司。说它是网络零售企业，它现在又花大价钱在收购或者自己开设地商店。最有意思的是亚马逊的云服务（AWS），是云服务的头号玩家，它的业务总量比其他很多公司加起来的还要多。

从这个意义上说，亚马逊早就不是一家B2C，而是一家B2B企业。它也不再只是一个网上商店，而是一个真正的高科技企业。

还有一点，亚马逊的老板杰夫·贝佐斯（Jeff Bezos）玩火箭发射，虽然这不属于亚马逊的业务范畴，但这个人的商业思维里就好像有一只“四不像”，从而造就了亚马逊这种很跨界，让人摸不着头脑，又非常有竞争力的企业。

# ｜太阳马戏团：商业新物种

我们把手机这样的产品叫做“产品的新物种”，亚马逊这样的企业叫做“物种式的企业”。太阳马戏团也是这样一种具有四不像特征的商业新物种。

马戏团是演出行业里一个细分的产品，这个行业因为2个克服不了的缺点，通常都经营惨淡：

# 缺点一：成本太高

马戏团的成本很高，除了大象、老虎、狮子……各种各样动物的饲养成本，还有这些动物去到各个演出点的高额运输成本。所以，马戏团的票价虽然贵，但它本身并不赚钱。

# 缺点二：消费低频

还有一个收益上的问题：马戏团是典型的低频产品。一个个人一辈子看马戏的次数很少，普通的人一辈子可能只有两场马戏，一次是你爸爸带你去，一次是你带你儿子去。很多人小时候看过马戏，那么除非他有孩子，否则即便马戏团再来他所在的城市，他也不会去看。

虽然表演内容可能赚一点点钱，但是低频、成本又高，导致马戏行业基本保持“吃不饱、饿不死，不死不活”的状态。

来自加拿大的太阳马戏团不想在这个行业里这么费劲的生存，它想搞点新意思，或者说，它想成为一种新的物种。那它是怎么做的呢？

+   1. 改变了行业习惯和假设
人们看马戏，就一定是看动物的吗？本质上说，人们就是图一个乐呵。如果换一种思路，想象出人们在这个而易见的需求背后另一种没被满足，但实实在在存在的需求，就可以看到别生面，异军突起，改变马戏团的行业习惯，

+   2. 改造产品
太阳马戏团对自己的产品做了一个改造，分为四个步骤：

+   1)删除：大幅度减少动物的驯养数量
一般马戏团动物是主角，人是配角，而太阳马戏团人是主角，动物是配角。这些配角动物呢，还都是一些更易于驯养，易于运输的小动物。这样，它的成本就大大幅度降低了。

+   2)减少：不再需要马戏明星
太阳马戏团不再设置马戏明星，而只需要那些有表演天赋、水准不错、名气不大的演员。这样，它既保留了马戏的特点，又大大减少了传统马戏表演的特点。

+   3)增加：马戏演出成为真正的主角
传统的马戏里，马戏演员发挥得空间很少，他们主要是跟动物合演，配合观众互动，极少的发挥一下自己的表演天赋。太阳马戏团大大增加了演员本身的戏分，将动物变成了类似于伴舞、活跃气氛的角色。

+   4)创造：不断增加传统马戏没有的新元素
太阳马戏团增加了很多的歌舞表演。这种歌舞表演和一般的不同，它让动物参与其中，带有更明显的喜剧色彩，使整个表演氛围非常活泼，让观看者从头到尾都很享受。

最重要的是，大象、老虎能表演的动作也就那几个，动物能玩出的新把戏非常有限，而人的表演是可以常常换新的。

太阳马戏团每年演出近600场，经常是一天两场；它每个季度的节目都不一样，受众的范围也随之逐步扩大。

现在，在众多马戏团还在继续惨淡经营的时候，太阳马戏团的收益大大提高，成本大大降低，它实现了从高成本到低成本，从低频到高频，从呆板单调的表演到生动活泼喜闻乐见的演出的转变。太阳马戏团成为了全世界最赚钱、最受人欢迎的马戏团，一个新物种就这样诞生了。

# ｜总结

通过太阳马戏团的例子，我们清楚了几点：

+   一、新物种就是新的性状组合；

+   二、新物种往往带有某种跨界的性质，它是把分属于普通物种的某些性状集合起来，成为好某个带有四不像性质，又能自然组合为一体的一种物种。
