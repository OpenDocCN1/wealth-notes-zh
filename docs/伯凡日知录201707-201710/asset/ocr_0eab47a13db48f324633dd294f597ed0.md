# 本周问答｜灰度观察，黑白决策

本周问答｜灰度观察，黑白...

我是从事首饰行业的，老师说的这3点，我觉得在首饰上也共通：第一层，基本保证人对贵重金属储值的需求，现在，黄金产业链大部分还是在这个层次上。第二层，是对个性的表达，这层也是我最喜欢并且拥有同样观点。首饰，是应该表达一个人的个性的存在。第三层，是奢侈品。我对这三层的理解，应该是商业上的价值。如果论艺术价值，可能最有艺术价值的是第二层，老师觉得呢？

吴伯凡
奢侈品首饰跟首饰不一样。中国的首饰业和国外的首饰业也同样存在着一个生态位巨大的差异。可以说，中国的首饰业现在很做做到第三个层面，也就是“真正的作为一个金融产业的层面。”

尽管贵金属本身就带有了金融属性，但是我们说的金融属性是指它作为一种通行的社会货币，或者说社交通货。在这一点上，中国的首饰业、珠宝业还远没有达到这个水平。

举一个例子，我们不说具体的品牌名称，它的珠宝、首饰之所以卖出比中国的普通首饰要高出很多的价格，原因是在于，它已经形成focus

这里才是我们所说的金融属性。其原因就在於，它在某种程度上成为一个话语央行，并且通过这个话语央行的背书，使得它的面值远高于这个产品自身的价值。

所以，我认为最高的值还不是第二层，而是第三层。

我现在和主管相处的不都好，因为她强势，我看到她就害怕。她安排某工作的事情太多，我和她沟通很少，每天最多只有30句对话。我工作灭也很容易出现错误，她看到我这样，也很无奈。有时候，我很紧张，都不敢说话，如果她外出办事，我就觉得解脱了。和她一起办公，每天都是高度紧张，被她训的时候大脑一片空白。这样一直恶性循环，我很压抑，越想把工作做好越会出现错误。现在很想辞职，不知道该怎么和她相处。

吴伯凡
很想辞职就是不想跟主管相处吗？这个同学苦恼的就是，她已处于一种“以祈使句为主要表达方式”的沟通场景当中。如果我们认为这也算是一种沟通方式的话。
这个同学的问题简单地说，就是“我如何能够从一种祈使句的沟通场景当中破局，变成一种真正的沟通。”

俗话说“一个巴掌拍不响”，一种沟通语境的形成肯定不是一个人能够掌控的。如如何把你的极其被动的处境变成一种你能够获得主动权的场景，或者说，你如何把你的客场变成你的主场，这是一个很难的问题。我们在下周一讲到的就是这样一个话题，希望会对你有用。

全和无，黑和白，还有灰度，这三者在我们生活的世界里究竟怎么均衡呢？这让我想到哲学里的量变和质变的关系，有些事物是量积累到一定程度产生了质变，但那些没有产生质变的事物会分为两类：第一类，是事物量变没有达到质变的要求，但它的状态是处于质变的，就好像打游戏会有一个进度条，大家起码能看到进度。第二类，是事物只会无限接近质变，但它的状态却永远没有变，就像打了半天游戏没打通关，进度条仍然是0，非生即死，没有半死不活。
那我们怎样了解自己做的事情是第一类事还是第二类呢？有些人可能一遇到第二类事情就会轻易放弃，因为看不到反馈的进度条，每次达不到目标都是0的结局，请问怎么才能让这些人跨越从0到1的门槛呢？

吴伯凡
关于灰度与非白即黑的关系，我们以前讨论过很多次。有一句话叫“灰度观察，黑白决策。”，就是说，我们在决策的时候是不能够搞灰度的，但是你观察的时候，要充分意识到你所面对的要素和场景的复杂性。但是，不管你多么细致的感受到场景的复杂性，你必须要做一个决策。

比较糟糕的情况是“黑白观察”，事实上，有很多人就是这样一种状态：观察的时候特别简单，但是到决策的时候它又变得非常复杂，永远在那儿纠结，永远在那儿犹豫。“当断不断，反受其乱”<|start|>

讲到进度条的问题，应该说，进度条现在已经成了我们的一种世界观了。我们因为打游戏太多，或者你的生活世界里被游戏所主宰的时候，这世界可能就被游戏化了。但世界本身是不会被游戏化的，只不过是你观察的方式游戏化了。这个时候会对我们的这种观察方式，或者说你的这种游戏化的世界观，对我们的工作和生活产生很负面的影响。而我们自己往往又察觉不到。

不管是生活还是工作，我们是很少能够看到一个进度条的，或者这个进度条有，但是它需要你调动多方面的认知能力、感知能力，你才能够知道你的进度是什么样子。这里的关键是，哪些事情是属于“非白即黑，非0即1”的，或者说，哪些事情是非连续性的，哪些事情是连续性的。

雇人的时候我们说“与其教火鸡爬树，不如雇一只猴子”。如果做一个事情你选择的对象错了，你就可能在教火鸡爬树。这可能有一个进度条，但它是一个“进展极其缓慢，甚至会停滞，永远都不能动”的进度条。如果你做这样一件事情，还不如干脆放弃。这个时候，做一件事情就变成了雇一只猴子，或者其它。如果你雇到的是一只猴子，事情就是1；如果你雇不到一只猴子，不管你雇到的是猪还是火鸡，都是0。

这么说吧，在用人的事情上，应该更多的采取非连续性思维。它是说CEO要把40%的的时间用于找人，否则会用100%的的时间去收拾烂摊子。在你雇不对人的情况下，一切的努力可能是一个看似有进度条，但是不可能有结果的状态。

至于如何判断哪些是能够实现质变，哪些是永远不可能实现质变的，你不可能在任何一本书或一个大师那里找到答案。在你没有拥有找答案的能力之前，这个答案是不存在的。

我们之所以讲到“全或无定律”，只是给大 家一种提醒，或者说是一种提问的框架。当你没有完成，没有实现一个目标的时候，有两种可能：
一种是你付出了努力，但是没有付出足够的努力；还有一种是你所设定的那个目标很可能是一个永远达不到的目标。
