# | 发现暗局的能力

前几天我在外地碰到了一个《伯凡·日知录》的同学，问我说：吴老师，你讲的那个明局、暗局，似乎挺有道理。我就形成了一种习惯，老想发现暗局，但是发现不了，看到的都是明晃晃的……暗局怎么发现啊？我怎么能有司马懿和诸葛亮的智慧？一个事情发生之后第一眼就能看到背面的东西，不看正面就看背面，不看明局就看暗局，怎么样有这种能力呢？

这确实是一个问题：明局和暗局是事实，但如何从明局里发现暗局却是一种能力，需要天赋，当然还需要天赋之外的训练。

“如何获得对于暗局的洞察”，我们面对这个问题立即会想到该如何增加自己的能力，其实换一个角度来看，这种思维方式是印度人最擅长的，佛教也特别擅长。

# | 意识的搜索引擎

我之所以讲到这个，是因为最近老有人问我，他们算命遇到了大师，遇到了高人，特准，这到底是怎么回事？关于算命的算我不懂，不好妄议这种行为，但我可以说的是，我们思维方式当中很有多障碍、好多自带的bug让我们特别容易相信别人对我们的判断——这个判断本身的真实都很难说，但是我我就觉得说得很对。

# | 正向检验策略

“正向检验”是指，为了判断一种可能性是否成立，人们一般会寻找他说中而不是漏掉的东西，寻找他所证实而不是证伪的地方。甚至包括对预言家、算命先生，我们都存在着“正向检验”这样一种判断。

# | 反向验证能力

+   1. 制造一个谎象，引导侦探和警察朝一个方向想
2. 侦探和警察又发现一个谎象（这个谎象其实他是有意留下的），进一步证实了他们的判断
3. 发现一连串这样的证据和谎象，把侦探和警察带到老远老远的地方去
4. 狡猾的罪犯得以逃之天天
