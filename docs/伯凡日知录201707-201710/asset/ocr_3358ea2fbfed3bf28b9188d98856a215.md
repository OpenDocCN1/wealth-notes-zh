# 8.10 | 猫的动与静

# —— 第176天的知识笔记 ——

#  | 上蹿下跳的猴子

前几天和一个在二级市场上做投资的朋友聊天，他说这几年最大的收获就是明白了一个投资要点：如何从动到静。

在我们的想象当中，这些在狼嘴里头抢肉的人，他们一个最重要的素质就是动手要快，要敏捷，要随时注意各种动向。我这个朋友刚开始入这个行的时候，也总是提醒自己，一定快！快！快！要眼勤、耳勤，尽可能从各个渠道获取信息，让自己始终保持一个活跃的状态。

当然，他后来逐渐发现这种状态不是活跃，而是上蹿下跳。他的一个师兄告诉他，你想要在这个领域干出点成绩，一定 それ…

#  | 定才是目的

在《传习录》里，王阳明说，为学的功夫就是要达到像猫的那种状态，静不是目的，动也不是目的，定才是目的。动亦定，静亦定。

#  | 卫兵的静止

做到动也不难，做到静也不难，做到静的时候能够保持一种活跃状态，才是最难的。有位禅师叫一行禅师，也曾经讲到过这种状态，叫“卫兵的静止”。

#  | 知行合一

我的这个朋友又告诉我，他最近一两年都在读王阳明的《传习录》，他发现王阳明是一个非常奇特和矛盾的人物。一方面，这个人是一个典型的儒家正人君子的形象，另一方面，这个人有一点那儿气，或者说是有一种极其灵巧，极其机敏的东西。

#  | 下学而上达

我们很多人都有认知恐慌，唯恐自己的认知不够，在这样一个知识爆炸的时代被淘汰，于是在不知不觉当中去交各种的认知税、愚人税，老实说，这种认知没有太大的价值，因为你没有做到知行合一。认知本身就是一种行动力，或者说是一种面对世界保持高度的主动性。

吴伯凡

听完今天的节目，大家可以思考一个问题：我们每天学的这些知识，有哪些是属于下学，从这些下学里头，我有没有上达的愿望，我在多大程度上将这些可编码的，可转述的，可购买的知识转化成不可转述，不可编码，与自身的行动力结合在一起的默会的知识或者叫非认知性技能。
