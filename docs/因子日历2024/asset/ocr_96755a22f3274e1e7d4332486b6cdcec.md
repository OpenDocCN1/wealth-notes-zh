# 买卖委托价格比率

高频因子-流动性类

```
PIR_t = (P_t^{WB} - P_t^{WA}) / (P_t^{WB} + P_t^{WA})
```

```
P_t^{WB(WA)} = (∑ w_i × P_{i,t}^{B(A)}) / (∑ w_i)
```

# 其中

+   ① P_t^{WB(WA)} 为衰减加权委托量；
② P_t^B 和 P_t^A 分别是 t 时刻的买一和卖一的委托价格；
③ w = 1-(i-1)/5 、 i = 1,2,3,4,5。

# 说明

PIR 为买卖委托价差与其和的比值，从价格的角度描述了买盘的压力。

邱卉伦, 2023, 高频选股因子分类体系, 中信证券。
