# 盈余可预测性

财务质量因子

```
X_{j,t} = φ_{0,j} + φ_{1,j} X_{j,t-1} + v_{j,t}
```

```
Predictability = sqrt(\hat{σ}^2(v_j))
```

# 其中

+   ① 对年度收益进行一阶自回归 AR(1)，回归的误差方差的平方根即为可预测性衡量指标；
② 年度收益 X_{j,t} 可以取每股收益、净利润等指标；
③ 自回归滚动窗口可以取 10 个财年。

# 说明

Predictability 取值越小，盈余的可预测性越高。
