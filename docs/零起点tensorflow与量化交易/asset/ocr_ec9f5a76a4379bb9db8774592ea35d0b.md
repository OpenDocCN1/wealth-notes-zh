# **1. 回归算法**

回归算法 (Regression Algorithum)，原本是统计学中的主要算法，目前已纳入统计机器学习中，用于估计两种变量之间的关系的过程。当用于分析因变量和一个或多个自变量之间的关系时，该算法能够提供很多建模和分析多个变量的技巧。
