在以上输出报表中，包含了多种金融指标参数。

- **Total Return**，总回报率。
- **Risk-free rate**，无风险利率。
- **Sharpe Ratio**，夏普指数。
- **Sortino Ratio**，索提诺指数。
- **Calmar Ratio**，卡尔马比率。
- **CAGR**，年复合增长率。
- **Max Drawdown**，最大回撤。
- **MTD**、**YTD**，月度、年度指标。
- **Mean**，平均值。
- **Vol**，波动率。
- **Best Day (Month)**，最佳交易日（月）。
- **Worst Day (Month)**，最差交易日（月）。
- **Win**，获利。

其中，主要的金融指标参数如夏普指数、索提诺指数、最大回撤等，还提供了年均、月均、日均三种不同时间周期的指数。
