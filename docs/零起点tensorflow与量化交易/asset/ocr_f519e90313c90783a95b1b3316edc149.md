从图5-11 和输出信息可以看出，epochs 参数取200以后，epoch_acc 都是一样的，即都为88.75%，不过训练时间越来越长。

本书教学课件中的案例通常都采用 500 轮迭代，不过 mlp01 模型简单，epochs 参数取 300 即可，以节省程序运行时间。

300 这个数值，就是我们通过 ai_mx_tst_epochs 函数找到的 epochs 优化参数。ai_mx_tst_epochs 函数的源码位于 ztools_tq 模块中，也很简单，就是一个 for 循环，请大家自行分析。

在第4组代码中，其实通过了三组不同的参数优化测试。

```
df2=ztq.ai_mx_tst_epochs(fm_x,ft_q,df_train,df_test,nepo_ chs=100,ns1ze=1 28，ky0=5) #df2=ztq.ai_mx_tst_bs1ze(fm_x,ft_q,df_train,df_test,nepo chs=300,ksize=8 ,ky0=5) #df2=ztq.ai_mx_tst_kacc(fm_x,ft_q,df_train,df_test,nepo chs=300,nsize=128)
```
