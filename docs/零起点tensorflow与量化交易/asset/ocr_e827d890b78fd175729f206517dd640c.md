# ## 2.4.2 resample 函数

tick2x 函数位于 ztools\_tq 模块的核心部分，使用的就是 Pandas 的 resample 函数，有兴趣的读者可以直接查看相关源码。

在 `resample` 函数接口参数中，`ktim` 表示时间频率。常用的时间频率符号有：

+   A，year

+   M，month

+   W，week

+   D，day

+   H，hour

+   T，minute

+   min，minute

+   S，second

在 `ktim` 参数中，代表分钟的符号有两个，即：

+   T，minute

+   min，minute
