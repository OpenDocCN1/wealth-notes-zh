# 案例 9-1：数据更新

如果是回溯分析，只采用历史数据，则一般不需要数据更新环节；如果是实盘分析、实盘交易，那么每次在运行程序前都必须进行数据更新。

数据更新是实盘分析、实盘交易和模拟分析最大的不同之一，有时即使有完整的量化回溯系统以及相关案例，也无法进行实盘分析，获取每天最新的推荐产品，就是因为没有在运行量化回溯分析程序前更新数据。

● 股票日线数据更新。
