```
#1 下载股票实时数据文件
rss=zsys.rdataReal

#默认下载 5 分钟分时数据
xtyp='5'
print('xtyp:', xtyp)
```

设置数据目录、参数等，其对应的输出信息如下：

```
rs0: /zDat/real/
xtyp: 5
```
