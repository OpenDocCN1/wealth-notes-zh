# （2）门限循环单元

门限循环单元（Gated Recurrent Unit, GRU）模型类似于LSTM 模型，也是循环神经网络的-种变形，如图 B-26 所示。

![](bbox=[0.26, 0.5, 0.76, 0.75])

GRU 模型是LSTM 的一种轻皇级变体，它有一个更新门（Update Gate），没有输入门、输出门和遗忘门。该更新门既决定来自于上-一个状态的信息保留多少，也决定允许进入多少来上-上-层的信总。
