# 2. 设置量化策略函数

第 4 组代码如下：

```
#4 set_BT.var
print('\n#4, set_BT.var')
qx.preFun=zsta.lstm010_dpre(…………………)
qx.preVars=[10]
qx.staFun=zsta.lstm010
qx.staVars=[1,0,1,2]
```

设置量化策略函数。其中：

+   - qx.preFun——量化分析数据预处理函数，本案例中使用的是 lstm010_dpre 预处理函数。

+   - qx.preVars——预处理函数的参数变量列表。

+   - qx.staFun——量化分析策略函数，本案例中使用的是 lstm010 策略函数。
