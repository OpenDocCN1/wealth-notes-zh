第 3 组代码如下，下载指数数据。

```
# 3 下载指数实时数据文件  xcod='000001' #上证指数 df2=zdwdwn.down_min_real010(rss,xcod,xtyp=xtyp,fgindex=True) print('\nxcod:', xcod) print(df2.tail()) hdr,fss='K线图-'+xcod,'tmp/tmp_'+xcod+'.html' df2.index=df2['date'] zdr,drDF_cdl(df2,ftg=fss,m_title=hdr)
```

以上代码用于设置指数代码，下载实时数据，并绘制对应的 K 线图。

因为是下载指数数据，down_min_real010 函数中的 fgindex 变量参数赋值为 True。

需要注意的是，为便于区分，指数实时数据文件都是使用“inx_”作为文件名开头的。
