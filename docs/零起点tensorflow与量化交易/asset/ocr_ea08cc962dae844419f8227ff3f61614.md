df\_xed\_xtyp2 函数，把数据分为上涨、下跌、平稳三种类型。

df\_xed\_xtyp2 函数的 API 接口如下：

```
df\_xed\_xtyp2(df\_train,df\_test,kmnd='3',k0=99.5,k9=100.5,  
senType='ktype',senPrice='price\_change')
```

它提供了多种数据分类方法。

+   kmnd=2: 上涨、下跌两种类型模式。

+   kmnd=3: 上涨、下跌、平稳三种类型模式。

+   kmnd=n: n 种类型模式。
