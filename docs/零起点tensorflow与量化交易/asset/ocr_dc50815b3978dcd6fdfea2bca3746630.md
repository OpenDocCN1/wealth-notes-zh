如果大家使用小显存的 GPU 显卡，则可能会出现 GPU 内存不足的错误。大家可以减少 batch_size 单轮迭代输入数据的尺寸，同时降低迭代轮数，以减少模型训练时间，但最终模型的测试精度可能会有所降低。
