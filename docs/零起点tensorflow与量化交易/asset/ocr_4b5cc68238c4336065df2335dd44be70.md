Keras 模型可视化的第二种方案，是调用内置的 plot\_model 函数。plot\_model 函数可以生成类似于流程图的图像模型。plot\_model 函数需要 graphviz、plotdot 等模块库的支持。

以下代码采用图形模式输出模型结构。

```
plot_model(model, to_file='tmp/model01.png')
plot_model(model, to_file='tmp/model02.png',show_shapes=True,
show_layer_names=True)
```
