# 32、案例分享：喜立滋啤酒“50年的完美演绎”广告

亲爱的朋友：

喜立滋啤酒的案例已经家喻户晓，许多人也因为这个案例而受益。也许你已经听说过这个故事 N 遍，但并没有多少人真正见过其广告的真面目。

在那个时候，喜立滋啤酒在啤酒品牌中排第 5 位，并且正深陷泥潭。直到他们聘请了霍普金斯后，才帮其完全转变。

在那时，每一个啤酒制造商都宣称他们的品牌是“最纯的”。但是消费者想：“谁在乎呢。”直到霍普金斯通过他魔术般的方式最终解释了“纯”的真正意义所在。
