# 提高感知价值的元素

+   增加免费的礼品。

+   买一赠一。

+   把多种产品捆绑在一起，以一个相对较低的价格（比每个产品的零售价要低）。

+   解释说明为什么你的产品或服务，比其他竞争对手的产品或服务更优越的具体好处，和新颖独特卖点是什么。

+   解释你的产品很耐用，并为此做出证据（可以使用多长时间）。

+   具体描述，当用了这个产品之后所得到的详细的好处。

# 降低风险的元素：

+   提供最有力的保证。

+   提供给免费的或者低价的续期保证。

+   提供免费试用。

+   提供低价，大众都支付得起的付款方式。

+   提供一个按效果付费的方式。

+   先用后付款。

+   售后跟踪服务。

+   快速，高额的投资高回报率。

+   用事实证明来证明产品或服务的使用效果。

+   请其他的人来证明使用效果。
