# 第99课：资本战略规划

# 一个清晰的资本规划

一诺老师研究发现，如果你要走资本化的路线，就必须有一个清晰的资本规划，包括：

+   1. 清楚地知道自己要用钱；
2. 清楚地知道为什么要用钱；
3. 清楚地知道什么时候要用钱；
4. 清楚地知道需要用多少钱。

拿一诺老师前面讲到的滴滴出行来举例子。通过这个列表可以发现，滴滴出行就非常清楚自身的发展需求：

+   1. 知道自己要用钱，及早地开始准备融资；
2. 知道自己融资是为了开拓市场；
3. 知道什么时候开拓到多少市场；
4. 知道把这些市场打下来，需要用多少资金。
