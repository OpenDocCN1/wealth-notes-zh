# 做法1：权威影响力背书

权威影响背书指的是，找一些有权威或者有影响力的人或机构来给自己做个见证。包括一—

+   (1)该领域的权威专家

研发产品的权威专家，认可产品的权威专家等。

很多牙膏的广告，都会有个牙科专家在为产品说话或者用该产品做实验。
