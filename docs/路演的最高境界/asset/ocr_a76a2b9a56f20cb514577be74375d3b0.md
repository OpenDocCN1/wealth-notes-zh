# 快速扩张，三轮融资

2004年2月17日，马云在北京宣布，阿里巴巴第三轮融资8200万美元，软银牵头出资6000万美元，其余2200万美元由富达、TDF和GV出资。

这笔投资是当时国内互联网企业获得的金额最大的一笔私募投资。

三轮融资过后，阿里巴巴的持股结构改变为：马云及其团队占47%，软银占20%，富达占18%，其他几家股东占15%。

三轮融资合计1.12亿美元，并没有改变马云在阿里巴巴的大股东地位。
