# 第23课：信用背书1

背书能增加客户对我们的信度

信用很好了解，背书是什么意思呢？金融领域的背书，指的是——找人或找机构给自己做担保的行为。

住一老师逮句说，桶悟商业真诗！

> 就是请自己以外的名人，
为自己的项目做个见证！

—诺老师

客户要购买一件新的东西最容易有不安全感，我们要把这种不安全感去除，让他产生信任感，所以要做信用背书。

有很多的路演，不是产品不够好，也不是成交方案不够诱惑，而是因为客户不相信演说者说的话。

他不相信，你说什么都充满怀疑。

在构建信任这个环节，我们要借助一切有影响力的元素，来为我们做信用背书，增加客户对我们的信度。
