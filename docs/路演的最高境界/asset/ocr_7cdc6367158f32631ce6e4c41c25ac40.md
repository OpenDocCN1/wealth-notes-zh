# 如何成交投资人

在人与人之间的沟通方面，一诺老师概括了三句话：

+   (1) 人所欲，勿施于人。

+   (2) 人之所欲，施之于人

+   (3) 授之以欲，成之于人。

这三句话，简单来说就是：

+   (1) 不要给别人不想要的东西。

+   (2) 给别人需要的东西

+   (3) 让他产生某些需求，并通过你来满足这些需求。

要与投资人成交，就要先弄清楚投资人的需求，思考一下他为什么要投资你。
