# ④价格分解

有人去买剪刀，A商店卖8元，B商店卖10元。

这客户就说B商店的剪刀贵。

B商店的老板说：“这把剪刀是帮助你做生意的，一天帮你赚20元，一年帮你赚7300元。这把剪刀才卖10元，多划得来。

而且，8元的剪刀只能用两年，平均一年4元。

我的剪刀卖10元，但可以用三年，平均一年才3.3元，很明显我的比A商店的便宜啊。"”

顾客最后购买了B商店的剪刀。

B商店的老板用了两个技巧:

前面是塑造价值，卖的不是剪刀，而是赚钱的机会；后面是价格分解，分解到1年才3.3元。
