# 赚平台规模的钱

任何一个单位、机构、平台，只要流量大了，就可以赚平台影响力的钱。

比如商场、广场，火爆的电视节目、媒体、公众号、网站、APP等，你会发现有很多商家找它们合作，投放广告、赞助、冠名等。其实这也是一种共享客户资源。

还有一样东西也非常值钱，叫做“大数据”。

> 你拥有多少粉丝，就拥有多少财富！
