# 天使投资人选项目的标准

# (1)熟悉的领域

对于熟悉的领域，投资人会更了解里面的需求、运作方式、成功的关键点，所以投资自己熟悉的领域会更有安全感。

# (2)未来趋势

符合未来趋势的项目，当然是天使投资人最感兴趣的。这些项目可能还没成型，有比较大胆的想法。

记住一诺老师这句话，商业真地！

要让投资人看到未来无限的可能性！

—一诺老师

# (3)分摊风险

天使投资人投的项目比较多，而且一般额度不会特别大，这样可以分散他们的投资风险。
