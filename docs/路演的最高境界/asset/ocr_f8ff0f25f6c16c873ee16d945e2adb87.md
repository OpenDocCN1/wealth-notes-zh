# 我们要面对谁来路演

一诺老师在本书所探讨的资本路演的对象，主要分为个人投资者和机构投资者。

个人投资者包括家人、朋友、同学、同事等，他们的投资决策更多取决于对你的信任与支持。

而机构投资者又可以分为天使投资、风险投资(俗称VC)、私募股权投资(俗称PE)，他们的投资决策则更多取决于对创业项目的一系列理性的分析判断。

其实天使投资某种意义上也属于风险投资，相比起风险投资，它介入更早，风险更大，回报也有可能更高。
