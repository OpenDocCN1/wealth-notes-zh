# 案例一：1500亿元的资产

很多人对1500亿元并没有什么概念，我们不妨这样表达假设你买彩票中奖，中一次是500万元，每天中一次，中间还不能有周六日休息，也要连续82年中奖才能拥有1500亿元。

在2016年初，1500亿元相当于一个新浪的市值，超过网易，超过9个搜狐、3. 5个奇虎360。
