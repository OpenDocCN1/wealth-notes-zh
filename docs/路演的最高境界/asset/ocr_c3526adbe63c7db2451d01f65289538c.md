# 第一个版块：项目价值7 · 客户见证包装

客户见证包装，也是一种自我证明和实力展现，主要表现

为:

+   (1) 都有哪些人在使用我的产品/在我的店里消费。

+   (2) 都有哪些人代理我的产品/加盟我的项目。

+   (3) 他们都有什么样的感受。

对这些客户见证的包装可以通过资料的方式呈现出来，也

可以在招商过程中，请他们现场分享。
