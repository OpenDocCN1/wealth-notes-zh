# 小米的融资历史

2010年4月，雷军及其团队、晨兴创投、启明创投投资创立小米；当年完成A轮4100万美元融资，公司估值2.5亿美元

2011年12月，小米获9000万美元B轮融资，估值翻了4倍，达10亿美元。

2012年6月底，小米宣布C轮融资2.16亿美元，此时估值为40亿美元。

2013年8月，D轮融资完成，估值已达100亿美元。

2014年12月，小米完成第五轮11亿美元融资时，估值为450亿美元。

2017年12月，有投行给小米开出高达1000亿美元的估值。
