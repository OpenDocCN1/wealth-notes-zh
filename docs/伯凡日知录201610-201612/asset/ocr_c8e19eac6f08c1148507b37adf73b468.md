# 潜水艇战略

在竞争如此激烈，商业模式被copy、被征用的风险越来越大的情况下，我们要学会低调，学会隐藏自身的动机，不要过早地把自己放在一个跟在位企业形成明显竞争的位置上。

![](bbox=[0.06, 0.15, 0.92, 0.25])

# 例子1：华为手机的流行

华为他刚开始之所以低调，他就是完全依托于运营商的。

华为宣布做手机之前早就在做手机了，他为运营商提供设备，运营商分发华为手机。但那个时候我们都不知道华为在做手机。所以，你以为华为做手机时间很短好像，一下子做到第一了，其实是潜伏了很久的。

![](bbox=[0.06, 0.45, 0.92, 0.55])

# 例子2：滴滴的窘境

滴滴收购了优步（中国）的滴滴，有市值估值350亿美金，现金储备60亿美金的时候，他觉得大功告成，但开始猛拼命地涨价，要把自己原来付出的那些东西要以最短的时间捞回来，让自己迅速实现盈利，但却面临四面楚歌的状况。

因为他已经背离了用共享经济的模式在现有的这种个人出行的市场之外，再开辟一个新市场的初衷。现在他是在既有的市场上切下一大块蛋糕。他实际上已经跟现有的出租车公司形成了完全正面的竞争，而且他再也不是一个作为共享经济代表的企鹅，他有可能成为一种高度垄断的，而且体量非常庞大的一个怪兽、一个巨无霸，这个时候各个方面的利益相关方都不愿意了。

要学会潜水艇战略，不最终接近目标绝不露头，学会在大象踩不到的地板缝里头生存，学会在他的眼皮子底下生存，同时又让他根本意识不到你的危险，甚至意识不到你的存在。
