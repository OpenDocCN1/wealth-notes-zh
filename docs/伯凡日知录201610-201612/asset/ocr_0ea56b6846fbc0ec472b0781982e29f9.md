# —— 知识笔记 ——

有一阵曾经很流行看三维立体画，就是一张纸上有那些你不知道是什么样的图案，你要调整自己的眼睛，进行对眼最后你就能马上看到一个别有洞天的世界。明明是平面的图像，但里头看到了一个立体的世界，由此我想到了动物世界，也想到了人的世界，还有我们的思维世界。

# 动物世界

| 生存空间

狗在一个没有空间的地方开拓了一个空间，而且这个空间在不断地膨胀，过去是人和狼之间没有任何缝隙的，它在这个缝隙里找到一个巨大的空间，狼面临灭绝，而狗口在爆炸。

当熊猫的祖先从北往南迁徙的过程中，找到了一块既像南方又像北方的那么一个地方，它找到了一巨大美好的生存空间，但是它自己不知道，那是一个能够让它的物种销摧灭绝的一个大陷阱。

| 感官

+   1. 狗的各种感官非常的灵敏，但是它的视觉是有问题的，狗看到的世界是一个黑白世界。因为它长期在夜里看家护院、观察敌情，只需要有很灵敏的听觉以及能够分辨出形状和移动久而久之，它的眼晴进化或者说简化为一个黑白的世界。

+   2. 青蛙的眼睛，它只能够看到动态的事物，静态的它就是看不到的。原因很简单，它这种方式最有效率地让它捕捉到它要吃的东西。

人的、动物的，所有生物的感官不是用来认知世界的，而首先是用来让你更方便的、更有效率的生存的。

| 桥-立交桥

![](bbox=[0.2, 0.0039700000000000004, 0.82, 0.00467])

二十三十年前，有一些外地的司机到北京来以后，最让他们头疼的就是北京的立体交叉桥——立交桥。因为他以前走的桥都是二维的桥，从一端到另一端，只有长短，甚至是宽度他都不太考虑。当他来到一个立体交叉桥的时候，那他真的是晕了，很多的外地司机到北京第一件事情就是要学会认知升级，从原来的二维世界进入到三维世界。

# 降维打击

例子1：蚂蚁的世界大战（比喻）

高维打低维，如果两个蚂蚁王国在进行一场第几次世界大战，一个人不小小心走过来，一脚踩上去，数万兵马一脚之间踩死，假如它们有宗教，它们一定是对一个它们不理解的那个灵异世界的一种想象，蚂蚁的牧师肯定跟它们这些蚂蚁的教民在讲，在我们这个世界其实还存在着另外一种我们完全不知道的，但是偶尔我们能感受到的巨大的力量，它一旦降临，我们的整个世界就会坍塌，所以我们要心存敬畏，我们要仰望星空等等。
