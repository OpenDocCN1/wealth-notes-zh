销售半径。从长安到现在的伊斯坦布尔，过去叫君士坦丁堡，那6500公里，在这一条不可能有路的地方，居然出现了一条路。这就是我们全世界人民都知道的丝绸之路。

# 2.商人对利益的追逐

它不仅仅是运送丝绸的，这条路上出现了许多驿站，汉帝国和罗马帝国，本来是老死不相往来的。因为有利可图，商人们开辟了这条路，商业，贸易也因此发达。

对利益的追逐是历史和文明的一个动力。

有了这条商贸之路，中国就跟世界互联互通了。有人甚至说，丝绸之路是一个在互联网出现之前的一个互联网，它把中国、西域、印度、中亚、中东和欧洲连接起来了。有了这条路，人类在交通和通讯极其落后的情况下，人类拥有了一个互联网。

# 世界互联互通的三次浪潮

第一次浪潮：丝绸之路的开通，西边的食物就传进中国。带胡字的食物，比如胡桃，胡椒。四大发明，通过这条道路就传到了西方。

马克思甚至认为，中国的四大发明对于欧洲的演进起到了相当关键的作用。有了炸药，欧洲从冷兵器时代进入热兵器时代。有了指南针，欧洲才有了航海，欧洲才有了大航海时代。

第二次浪潮：哥伦布发现新大陆，以西和番冠名的食物，比如说西红柿也叫番茄，番就是国外的，传进中国。

第三次浪潮：大航海时代，世界因此互联互通。

# 蚕与禅

佛教发源于印度，没有丝绸之路，佛教不会那么早的传到中国来。佛教传入中国以后，在印度本土就逐渐的消亡了。印度人大多信奉印度教，信佛教的人微乎其微。佛教后来从中国又传到了日本，传到了朝鲜。这样说来，没有小小的这一条蚕，就没有佛教的那个禅宗的那个禅了。

在世界上影响这么大的一种宗教，连乔布斯都无比痴迷的那个禅，如果真的追溯起来的话，还是要归结我们中国的这个叫蚕的小虫子。

蝴蝶效应，蝴蝶在亚马逊森林抖动一下翅膀，在美国的得克萨斯州就会形成一场龙卷风暴。在这个意义上说，蚕在文明史上也具有一种蝴蝶效应。

蚕吐出了一条路，一条影响人类文明进程的路，特别值得一提的是，有一座城市也是因为蚕，因为丝绸之路而出现、繁荣的。这座城不大，至今也就是十几万人口，但是它在在中国，甚至是世界文明史上是具有举足轻重的地位的。
