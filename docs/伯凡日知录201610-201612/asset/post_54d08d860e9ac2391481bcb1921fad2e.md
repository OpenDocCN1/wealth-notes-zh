# 11.16 | 格局与空间的关系

# —— 知识笔记 ——

高手之间的较量，是在暗局上的较量，是在这个局的反面，或者是在实实在在眼见为实的这个局的空白处，形成的一种暗局较量。

# 空城计的三个版本

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_43_0.png)

## 版本一：诸葛亮智取司马懿

诸葛亮和司马懿都是高手，高手对于明局是自动忽略的，他们的较量就是暗局的较量。

明局：这是一座空城

暗局：城内设有埋伏，诸葛亮气定神闲在城楼上抚琴，为了诱惑司马懿攻城。

司马懿的行动：司马懿反本能的思考，既然诸葛亮设下了伏兵，那我就偏偏不中计，赶紧撤兵。

结果：诸葛亮不费一兵一卒，就把司马懿大军挡在了城门外，且让司马懿撤退。

## 版本二：司马懿看穿诸葛亮底牌

司马懿看出了其中有诈，诈中又有诈，这个空城计不过就是诸葛亮的无奈之举。

明局：城是空城，诸葛亮是虚张声势。

暗局：因为有诸葛亮，司马懿才有价值。一旦他把诸葛亮消灭，他的使命就完成了。可能这一场胜仗打完之后，他就立即回到曹里。

结果：司马懿撤兵，保全自己地位。

## 版本三：诸葛亮是大赢家

诸葛亮之所以设这个空城计，是因为诸葛亮知道司马懿的处境。

明局：城是空城，司马懿要攻城

暗局：司马懿既要打诸葛亮，又不能把他消灭，司马懿要养寇自重，维护自己的生态，保护自己的生存空间。

结果：司马懿撤兵，且得到了一个在曹操那里说得过去的理由，诸葛亮不费一兵一卒成功保城。

这个故事足以让我们体会到，为什么说高手之间的对局不是在对明局而是在对暗局，是局中有局，层层迭迭的暗局。

真正的赢家就是在层层迭迭的暗局当中，掌握着真正底牌的那个人。这个故事又一次验证了我们前面说过的，竞争既是实力的竞争，更是格局的竞争。

# 局和空间的关系

局这个字，简单地解释就是一个空间。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_43_1.png)

例子：下棋

当我们开始下棋的时候，从理论上讲，整个棋盘上的空间都是你的；但是当两个人开始对弈的时候，棋盘这个空间就属于双方。我们说“将”军，把他给将军死了，是因为他没有空间了。下围棋，也是一个空间争夺战。围棋刚刚开始的时候，你可以随便在哪个地方下，但最后的结果是你没地方落子了，那你就输了。

博弈的最终结果就是，让这个理论上属于你的这个空间真正属于你，同时让对方丧失所有的空间。让自己的生存空间最大化，让对手的生存空间最小化。

从生态学的角度看，所谓竞争叫生态位重叠。重叠以后就是我把你清除出去，这个空间是我的，你出局。所以竞争的胜利叫让你“出局”，这个局不属于你。

我们说这个人有格局，这是从他的素质从他的能力讲的，其实这个能力和素质最后会表现为一个结果，就是你掌握的局都成为你的。

“相由心生”，外在的空间有多大，取决与你内在的空间有多大。内在的空间就是你内心的格局有多大。你内心的格局是小的，你外在的格局，也就是最终竞争的那个格局，不可能是大的。

# 心智带宽

带宽是一个通信学的术语，就是在单位时间点中，从这个信道上，传输信号的量的大小。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_43_2.png)

把带宽推而广之，一条道路也可以有带宽，两车道、四车道、八车道、十车道，这也可以叫带宽。带宽越大，流量也就越大。

一般说来，带宽越大，流量越大。但实际上，天天饱受堵车的苦的人不会同意这个观点。我们经常会看到，在一个八车道的路上堵的水泄不通。当车的数量越来越大，道路的闲置面积越来越小的时候，整个流量也会变小，我说的是流量，不是车的数量，直到闲置面积为零的时候，整个流量也就是零，尽管这条路上全是车。

我们经常说这个人脑子快，那个人脑子慢，其实更准确的说法是，那个人脑子的流量大，那个人脑子的流量小，一个人的心智带宽里头，它有比较多的闲置面积；另外一个人，被各种各样的观念所堵塞。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_44_0.png)

例子：同一块木板的不同状态

这是法国哲学家帕斯卡尔举的一个例子，他说当一块木板放在地面上，一个人从木板的这一头走到那一头，轻轻松松；但如果是把这块长长的木板放在两座楼之间，或者是放在两个山峰之间，让这个人去走，他可能会寸步难行。

不是他的腿出了问题，而是他的脑子出了问题，是他的心智带宽出了问题。从理论上来讲，带宽不会减少，但是，这个时候，他的脑袋里头有大量的杂念。对风险那种强烈的意识，已经占据他大脑绝大部分带宽的时候，他的大脑连同他的腿就僵化，就停滞不前了。

一个人格局不大，其实就是心智带宽不够，就是心智的空间不够。而心智带宽不够，导致决断力、自控力、行动力大大降低，心胸的堵塞和狭窄，导致他眼前的空间和格局的狭窄。

# 勇气与格局

在空城计这个故事里，我们首先想到的是“谋”，其实，比谋更重要的是“勇”，“有勇有谋”。好多时候，由于勇气的缺乏，导致我们的判断力、决断力下降。诸葛亮面对千军万马，一个人带着两个童子，在城楼上气定神闲地弹琴，这个时候最重要的是勇气。

我们中国说的一句话，是勇气跟一个个人智能之间的关系——“艺高人胆大，胆大艺更高”。我觉得这句话也可以倒过来：因为胆大，所以艺就更高；艺高，胆子更大。

> “勇气”其实就是一种对过度风险意识的过滤能力。

# 11.17 | 鲍尔默、乔布斯、库克，谁是最杰出的CEO？

# —— 知识笔记 ——

CEO的本意是首席执行官，他是一个执行者；但是在美国的公司里，90%的CEO都同时是董事长；在欧洲的公司里头是倒过来的，只有10%的董事长是CEO。也就是说在绝大多数美国企业里头，战略的制订者与战略的执行者是同一个个人，这就不难理解美国公司的创新性，或者说他们对创新的看重，是远远高于欧洲国家的。

蒂姆·库克是苹果的CEO，乔布斯也是苹果的CEO，但这两个人的差别是显而易见的。

研究创新问题的作家史蒂夫·布兰克写了一篇文章《为什么说鲍尔默就是另一个鲍尔默》，在这篇文章里他花大段的时间分析鲍尔默这个人。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_45_0.png)

鲍尔默是比尔·盖茨的继任者，当年他也创立了一家自己的公司，比尔·盖茨觉得鲍尔默公司的产品对微软的产品有威胁，比尔·盖茨最常使用的策略叫一百万美金策略，就是那些小公司刚刚起来，他看出你有颠覆我的苗头，我就出一百万美金把你给收购了。比尔·盖茨花一百万美金把他的公司给收购以后，也把鲍尔默招进公司，委以重任。做到最后，比尔·盖茨从微软的CEO的位置上退下来的时候，鲍尔默接任了。

# 鲍尔默是个杰出的CEO吗？

明局：从“实”的角度，从财务上、从帐面的角度看，鲍尔默是一个杰出的CEO：在2002年，他接任比尔·盖茨成为微软CEO的时候，微软的年利润是90亿美金，而2014年当他从CEO位置上退下来的时候，微软的年利润是220亿美金，公司的利润提高到原来的两倍多。

暗局：从非帐面的角度看，鲍尔默是一个不及格的CEO。14年时间，他也交上了一份隐性的成绩单，这个成绩单简称“五连败”。

第一败：搜索引擎领域，微软是很早就做搜索引擎，叫Bing（必应），但Bing无论是从产品的角度，还是从市场份额的角度来看，它远远不及Google的搜索引擎。

第二败：智能手机领域，投入了巨大的资源，甚至收购了诺基亚，但是几乎是完败给苹果。

第三败：操作系统领域，当年，微软跟Intel之前形成的那个隐形联盟就叫Wintel，就Windows加Intel。它导致了双方都实现了行业垄断。譬如说最重要的软件Windows，最重要的硬件微处理器，这分别被这两个公司掌握着95%的市场份额。可是在今天的后PC时代，很多人都不知道Windows是什么。据最近调查中国新增的网民95%都是通过手机上网的，他们根本不知道Windows是什么东西，一个小镇青年都知道安卓，但是他不知Windows。

第四败：媒体开发领域，媒体开发当然既包括内容也包括社交媒体。曾经一度，MSN是非常重要的一個社交媒体。MSN既是一个即时通讯软件，它也是一个网站，但是今天MSN对于我们很多人来说都是一个遥远的记忆了。广大用户在不知不觉当中，把MSN给遗弃了。

第五败：云技术领域，完全败给了亚马逊。亚马逊从一个网络书店，变成今天云计算的顶尖的公司。

微软在这五个领域都失去机会了，这五个领域正是我们现在竞争得如火如荼的领域，尤其是在云计算、人工智能，这些方面，亚马逊和Google已经远远地走在了微软的前面。有一个数字听起来匪夷所思：在PC时代，微软的Windows的市场份额是95%，在移动终端，Windows的份额是1%，几乎可以忽略不计。

衡量一个CEO，是不是一个杰出的CEO，是不是一个合格的CEO，不在于他在任期间的业绩，而在于他卸任以后十年的时间，这个公司的业绩。

所以斯蒂夫·布兰克评价鲍尔默的业绩的时候，说他给微软带来了再也回不来的14年。

怎么算一个合格的CEO，怎么才算一个杰出的CEO呢？

你除了为公司挣钱之外，你是否为空公司挣得了未来？甚至有人说得更极端，CEO的职责就是推动变革，就是在公司现有的战略、现有的商业模式、现有的市场、现有的产品之外，开创新的战略、新的商业模式，和新的产品市场和服务市场。

# 为什么说乔布斯是最杰出的CEO？

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_45_1.png)

他让苹果实现了战略和商业模式的三级跳。

第一跳：2001年，推出了iPod这个产品，这代表着一种新的商业模式。乔布斯把苹果从一个专门销售电脑的公司，变成了一个出售音乐的公司，出售内容的公司。当你使用这个硬件的时候，你要不断地从苹果购买音乐，它成为全美最大的音乐销售公司。

第二跳：2007年，推出了iPhone这个产品。苹果从一个电脑公司，从一个内容公司，又变成了一个移动终端变成了一个手机公司。PC的厂商要么已经死去，或者已经半死不活，无缘从PC固定的终端转换成熟动终端；苹果公司不只是拿到了移动互联网时代的船票，它开辟了移动互联网时代。没有智能手机，我们很难想象移动互联网市场的大繁荣。它进入了手机而且重新定义了手机。

第三跳：2008年，APP Store的问世。没有APP Store，没有这种应用商店，智能移动手机能够做的事情是非常少的。它给了我们每一个用户重新定义自己手机的机会。

它不仅仅是不断推出自己新的产品，最重要的是它一直在引领这个时代，其他公司的业绩标准只能是——你在多大程度上模仿得象苹果。

# 蒂姆·库克是个成功的CEO吗？

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_46_0.png)

明局：从公司的销售业绩来看，从公司的市值来看，可以说蒂姆·库克让苹果达到了顶峰，它的最大市值的时候，是七千多亿美金，它的现金储备，突破了两百亿美金的大关，蒂姆·库克也是一个杰出的CEO，他也交出了一份漂亮得令人发指的成绩单。

暗局：5年的时间，他推出一个产品，iWatch。5年，苹果公司现在员工数量超过11万，但未来会怎么样？再过5年它会是什么样？仅仅拿iPhone这个产品来说，它已经不再是领先者了，有很多的功能很多的体验它是在走在后头是跟别人学的。

苹果现在的业绩仍然不错，但是，它其实得益于一种市场惯性。但是当我们问未来的时候，我们不知道，蒂姆·库克也不知道。

# 企业继承者的宿命

国外的商学院有一门专门的课程叫，succession，就是继承；企业的创始人，凭借他们强烈的创新意识和超强的执行能力，以及战略勇气，开辟了一个盛大的局面。一个战略家要真正取得成功，必须要依靠于他手下有强有力的执行者。

继任者和创始人的不同之处：

+   1. 继任者是一个执行者而不是一个企业家。
2. 创始人“做正确的事情”，开创了一个盛大的局面。而继任者只需要凭借超强的执行力“正确地做事”，他就能够将企业实际上还没有发挥出来的潜能发挥出来。
3. 创始人是从零到一，继任者是从1到N。

执行者最害怕的就是不确定性，执行者的使命就是是搞定一个事情，就是消除不确定性。

一个人喜欢与不确定性打交道，与风险打交道，他其实是在开拓自己的心理空间。当你对不确定性，对风险，本能地规避的时候，你的心理空间在悄悄地萎缩而不自知。

# Exploitation和Exploration

这两个词念起来看起来都很难，但意思大不一样。

Exploitation，可以把它翻译成利用、剥削、压榨。

+   1. 它是面对不确定性的，面临着巨大的风险的。

# “相由心生”

“相”是物理世界，你看得见，摸得着的东西；“心”，是看不见的东西，或者说，物理空间决定于心理空间。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_46_1.png)

例子：刘小光与15位顶尖高手对弈

刘小光（九段）和研究生院挑了15个顶尖高手下棋，桌子围成了一个圆圈，把刘小光团团围住。还没开始下呢他就被围住。刘晓光让每个人五颗子。这些顶尖高手们把五颗子摆好了以后，刘小光好像例行公事地跟他们下棋，他根本是不加思考，一手拿着一盒围棋，另一只手就象农民插秧似的，挨个放。我就当时觉得奇怪，他动不动脑子他下这个棋？半个小时之后，差不多一小半就下不下去了，40分钟以后，全军覆没。

这些聪明的同学当在布局的时候，他们一定会认为他们布好了一个天罗地网，只等刘小光来落网；但是他们只是看到了有形的空间，看到了一个明局，他们在营造一个明局，刘小光看的是暗局。

所以，你在明处，他在暗处，你的胜算真的是不大。

王立：有格局的人和侠肝义胆的人有什么关联？侠肝义胆好像比较多来形容英雄，但中国的英雄都是悲剧人物，而有格局的人似乎都是后人的评价，而英雄都是当世的评价，怎样看待这样的问题呢？

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_47_2.png)

吴伯凡

说到格局，我不敢使用像“侠肝义胆”这样道德色彩浓厚的词，因为我只是从理性、利益的角度来分析有格局的人的“算法”。我们习惯性认为，有格局的人是那种不愿意计算的人，“精于算计”只是用来形容那些小气的、没有格局的人的。事实上，有格局的人恰恰是善于“算”、精于“算”的人。算即筹划、谋划。《孙子兵法》中有“夫未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也。多算胜，少算不胜，而况于无算乎。吾以此观之，胜负见矣。”

算计的“算”，筹划的“筹”，都是古代的计算工具，都是用竹子做的计算工具。所以这两个字都是竹字头，尤其是“算”上面是一个竹字，下面其实是一个工具的“具”，（“算，从竹，从具”）。算，也叫运筹，军事将领的主要工作就是“算”，“运筹”。刘邦夸张良的风范的时候说“运筹帷幄之中，决胜千里之外”。这里所说的“算”、“运筹”，显然已经不是纯粹的计算行为，它更接近于战略管理。

应用数学的一个重要分支学科，研究的是如何将生产、管理等事件中出现的问题加以提炼，用数学方法进行解决，这门学科就叫运筹学。运筹是从大视野和整体格局上进行“算计”，进行“计算”。我们通常所说的算计之人，即没有格局之人，就是缺乏大视野和整体格局视野的算计者，他也在“算”，但是他没有大视野，没有整体的格局。所以在日常生活中，没有格局的人常常被形容为“会算小帐，不会算大帐”。简单地说，有格局的人就是始终以大视野和大格局为参照系的精打细算。有格局的人并非没有企图，没有目标，只不过他的企图和目标不是一眼就见到底的，他的目标很大，大到不那么直接，不那么明确，或者说，他的目标是非线性的。我们可以借用哲学家康德的一句话来形容有格局的人的企图和目标——“无目的的合目的性，无功利的合功利性”。

对一个事态的判断，对利害的取舍，无格局的人习惯于眼见为实的直接判断和取舍，有格局的人往往是“延迟判断”，因为他相信“效果延迟”是事情的常态。

“效果延迟”是《第五项修炼》里的核心概念。在彼得·圣吉看来，真正有效的思考都是“系统思考”，随生随灭、就事论事的思考不过是于事无补的杂念和小聪明，这种小聪明只能找到“症状解”，找不到“杠杆解”。

“症状解”和“杠杆解”的最大的差别就在于，“症状解”给出的是直接解决的方案，但是它解决不了真正的问题；“杠杆解”是一种间接的解决方案。我们看到一块石头的时候，用手去搬，是“症状解”；用一个杠杆，下面垫一块石头作为支点，去撬动它，是“杠杆解”。“杠杆解”显然是不直接的，但是它的解决的力度、它的解决的效果，那是“症状解”完全不可同日而语。

如此说来，所谓有格局，就是懂得、擅长“系统思考”，找到“杠杆解”。

说到这里，大家也就明白我只说“有格局”，不说“侠肝义胆”了。我也喜欢“侠肝义胆”，但我在这里想和大家探讨的不是英雄，不是勇，而是谋，不是岳飞，而是兴周八百年之姜子牙、兴汉四百年之张良之类的人。
