# 本周问答 | 创业，找到痛点就能成吗？

本周问答 | 创业，找到痛点...

鄄谢键：原来这个状态，老师把它称为再部落化，的确深有共鸣，再部落化现在的发展趋势如此之甚，是否可以思考一下在这方面的创业呢？

吴伯凡

其实这个问题应该这样问：不是说我们看到了再部落化这种现象去创业，而应该说，再部落化已经成为我们创业的整体的背景了。在一个大众市场上去占领一个市场的那种概率现在越来越低，也就是说机会点不再呈现正态分布。

我们中国人吃东西喜欢吃带馅儿的，不管馅大馅小，就是说精华的部分它是在中间的。玩对冲基金的人老是忽悠我们说：一般的基金就是个包子，有面儿<|message|>，有馅儿，有的投资基本上不赔不赚，有的要赔，有的要赚，这就是一般基金的基本收益是比较低的；对冲基金呢，是只要馅，不要外头的那个面儿。

其实玩对冲基金的朋友说的这种论调，在今天对我们创业是一个很大的启示。过去我们经常听到有这种说法：全中国有13亿人，如果你占有一个百分之一的市场就是一千三百万，很大的数；还有的这么说，全中国13亿人，一人给你一块钱就是13亿；这种说法其实是一种自娱自乐的创业理念，不可能有全中国人民排着队一人给你一块钱这种事情。

中国还有一种食品，有些人吃过，有些人没吃过，叫葡萄干面包。葡萄干面包你想吃到更多的葡萄，你就要吃更多的面包，它是相对均衡地分布的。我们创业的机会到底是馅儿还是葡萄干面包？在我看来，这种大众的市场也就是葡萄干面包的市场，今天越来越小，逐渐地要绝迹。

这一点我小时候就有体会，就是很小的时候，看到一些大孩子大人们在那里摸鱼，我们觉得也很兴奋，也要跟着去摸鱼；但是你毫无经验，总觉得鱼就是分布在水塘或者水田里头，你让自己以最快的速度摸到更多的地方，你碰到鱼的概率就会更多，更努力地在那里摸，摸半天毛都摸不到。鱼它不是呈均衡分布的，有经验的人他是知道鱼爱待的那个窝的，所以人家都摸了小半桶了，你一条鱼都摸不到。

我们今天创业的时候，首先要有一个观念，就是机会是不均衡的，不要搞地毯式轰炸，碰概率。所以再部落化成为我们今天创业的一个基本的前提和背景，其实今天我们在网红经济里头已经能够看到一点再部落化创业的雏形。当然有些网红是速生速死的，就是今天红明天不一定能红，但是他们好像天生就明白这种再部落化的思维，别指望你红透半边天，你红透半边天，那半边天也还没有红透，事实上这个世界上不再可能有红透半边天的事情了。

你就是要找到一个看似狭窄，其实进去以后别有洞天，就像陶渊明笔下的武陵人，那个渔夫，进到一个洞里头，“初极狭”，刚开始非常的狭窄，穿过这个洞口的时候，豁然开朗、阡陌纵横的一个世界，那就是桃花源市场，我们一般把那种作叫桃花源市场，其实就是一个部落，生活在桃花源里的人其实就是跟外面很大的世界完全隔绝的、“不知有汉、无论魏晋”的一个世界，人家生活得非常好。

我说我们的市场将会变成越来越多的联合酋长国，没有大众市场，只有联合酋长国，这些联合酋长之间可以形成某种联合，但是他还是酋长，他的下面有他自己的部落。

关于痛点的问题

风尘一彦：找到不同部落的痛点。

吴伯凡

关于痛点我也想说一下，这个词现在越来越流行，创业就是找痛点。这里是很容易引起误解的一个地方，你以为你找到了一个痛点，你就可以创业了，但是这个痛点只是一个点。我们在地图上发现一个点的时候，你如果把比例尺再扩大，你会发现那是一个阡陌纵横的地域。

你在地图上，打开中国地图，北京就是一个点，但是你再扩大的时候，北京那就是二环三环四环五环六环七环八环，就是在各个环路，它的生态是很不一样的，过去有“西富东贵南穷北杂”的说法，现在有种说法就是，在北京，北五环跟南二环的地价有时候是差不多的，甚至是更贵。

你以为找到了北京，实际你并没有找到。其实我们到北京要找地方，一定要 在北京的哪一个点。我记得好像是毛主席说过一句话：北京，其实不存在北京，只有大栅栏，只有王府井。他的话 翻成我们今天的话就是没有点，只有一个地图，这个地图里，如果这个比例尺 越大，你发现的一个点实际上是一个巨大的面。在这个点里头，一旦放大的话，就会发现密密麻麻的，位置、资源、态势、需求等等，都非常不一样的点。
