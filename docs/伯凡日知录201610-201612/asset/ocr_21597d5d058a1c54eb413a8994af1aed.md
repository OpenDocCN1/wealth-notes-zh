# —— 知识笔记 ——

华为是中国企业的骄傲，是少数真正让国外的企业感到害怕、感到胆寒的中国企业。华为创造了一个或多个神话，但是无论是中国人还是外国人，他们都不太理解华为不像一个中国的公司。

世界上的三种创新：

+   1. 颠覆性创新，这个东西没有，弄出来一个东西，把你前面的东西都连锅端。美国人特别擅长。

+   2. 维持性创新，这个东西已经有了，在这个基础之上不断改进，精益求精，做的比别人要好的多得多。这种创新德国、日本比较擅长。

+   3. 山寨式创新，这个东西已经有了，但是我要一旦做这个东西，我就也给你连锅端，这叫山寨式创新。它结合了颠覆性创新和维持性创新的优点，做了一种创新。中国比较擅长。

华为越来越像一个同时具备颠覆性创新和维持性创新的企业，在中国这个不是太注重以技术来作为公司成长根基的土壤里，出现了一个这样的企业，大家有点不太理解。

# 影响华为的李一男

1994年，任正非认为华为既无技术又无管理。当年是两者都没有，今天华为是两者都有了。其中有一个可能大家很容易忽视的原因：华为如果没有李一男可能就不是今天的华为。

很多华为的老员工提到李一男这个名字他们就不太舒服，当有人发了一条关于李一男被收审的消息以后，有一个华为的资深员工评价到——格局决定结局。

李一男是个技术天才，少年得志，15岁上大学，大学毕业以后进到华为，27岁就是华为的高级副总裁，主管华为技术，华为当时为数不多的核心技术都在他的掌控之下。任正非把他当亲儿子一样看待。

任正非就是搞发明出身，他很崇尚技术。任正非有一句话叫：我对贝尔实验室的感情超过我的爱情。这样一个孩子，年纪轻轻这么有技术天才，他非常喜欢他。

![](bbox=[0.12, 0.00317, 0.92, 0.00335])

华为的灾难：

华为的竞争对手为了围剿华为，给李一男大笔投资，让他成立一个在业务上跟华为完全重合的公司。他成立了港湾公司，把华为的技术骨干以双倍甚至三倍的工资给挖过去。当时在华为内部士气极其低落，没有被李一男挖走的技术人才，自己觉得特别没面子。

电信设备行业是一个高技术含量的行业，港湾公司由于掌握了不少技术，很快对华为形成实质性的威胁。后来任正非调动了一切可以调动的资源，最后将港湾公司收购，李一男又重新回到华为。但是这个事情对于华为来说，是一场大灾难，虽然把港湾收购了，但是元气大伤。

灾难的作用：

任正非意识到技术有多重要，对技术的管理有多重要。从那个时候起华为就开始系统性的建立公司的研发和创新能力，而不是把少量的技术掌握在某一个或两个人的手里。

后来华为在技术上的竞争力是一种体系化的技术竞争力，华为为建立这样的一种体系花了大量的时间，投入了巨大的资源，所以华为的研发费用如此之高，华为的管理体系如此之严密。

当任正非要引入IBM的IPD，就是集成产品开发这样一个体系，建立这个IPD管理体系用了整整十年的时间。

他提出：当你入这个管理体系的时候，所有你感到不适应的都是你的问题，而不是这个体系的问题。如果你觉得不适应，那你就削足适履，这是一种决绝的勇气。

一种新的管理体系进来，它会造成很多的不方便，会触及很多人的利益，会给很多人找麻烦。但你不经过这种痛苦的蜕变期，你是不可能掌握这套体系的。
