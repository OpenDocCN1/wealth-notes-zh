# 周末福利 | 真正的爱情会让你觉得“不配”（文末有一首曲子）

周末福利 | 真正的爱情会让...

超清醒：饥饿营销的例子越来越多，消费者也能看出其中的套路。而且现在商品和品牌非常丰富，消费者非常容易找到一个替代品，如果长时间买不到，很快就去隔壁家了。那品牌就失去一个用户，那作为营销方，到底该如何把握这个度？

吴伯凡

的确本周我提到了饥饿，提到了小米的饥饿营销，但是这可能是我自己说得不清楚。我并不是在强调星巴克的饥饿营销，事实上星巴克也没有太做什么饥饿营销，我要说的是一个自绝于平庸、自绝于常规的产品，要让消费者有一种不配的感觉（你不配享受这个东西）。当然不配最直接的是你没钱，但很多时候不是没钱，你有钱你也觉得自己不配，那才是商家营造出来最好的“不配感”。

按照阿德勒的说法，我们人类所有的行为都是围绕着两个词在展开，一个是自卑，一个是超越。我们每个人都会感到自卑，所谓自卑就是对自身身份、能力、地位置下那种一种强烈的意识，或者说对自身不完美的强烈意识，在这个意义上说每个人都是有自卑感的。有人说皇帝自卑感，皇帝的自卑感可能比所有人都大。因为自卑所以要超越，一些商家懂得这一点，努力地在制造一种门槛，努力地让消费者觉得自己有点不配这个产品。这跟爱情是一样的，真正的爱情都有某种不配感，你之所以爱一个个人往往是因为你觉得你不配他，你越觉得自己不配就越爱他，越爱他又觉得自己不配。制造这种不配，制造一种你意识到或没有意识到的自卑感，从而让你产生一种你意识到或者没有意识到的想攀附他、接近他，从而达到能力和身份的自我超越，这是我们消费行为当中一个很隐秘的机制。

如果仅仅是做饥饿营销，有意地把销量缩小，吊大家的胃口，那种做法其实只是一种术。饥饿营销只是一个表象，只是一个浅的不能再浅的术，我们做市场如同滚雪球，滚雪球首先那个小雪球要足够的结实，别滚半天滚着滚着自己那个小球破了、散了，你滚不下去。我们要把雪球滚大，第一是把那个小球程得足够坚实，用黏雪，不要用粉雪，裹成一团，在一个长长的斜坡上，注意是长长的斜坡，一要长，二要是斜坡，只有是斜坡你才会省力，只有长滚到的雪太足够的多，往下滑。斜坡虽然重要，但是最初那个小雪球的黏性，它是否有足够的坚实度，这是更重要的事情。

要想把握饥饿营销的度，我觉得最好的办法就是不要总是把心思放在饥饿上头，要让你的产品真的能够让人产生一种不配的感觉，而且是持续的不配。这一代产品出来有好几个哇点，哇哇哇，再一代产品出来，两代产品之间的学习曲线很陡峭，几乎能达到30%以上，甚至达到45%，那是最好的，这个时候你不饥饿也能营销。反过来如果你的产品本来就是一个平庸的产品，你不过就是在做各种噱头，就像马三立相声里头说的那个卖偏方的故事，花了一块钱买了一个偏方，那个偏方纸包着，白纸包里头放了一个红纸包，红纸包里头再包一个绿纸包，绿纸包里头包一个黄纸包，黄纸包里头再包一个黑纸包，一打开那里头写着两个字——“拧搓”。那个偏方本来是人家买一个如何搔痒的偏方，结果弄了半天你在“术”上那么费神费力，但最后那个方子确实平庸的不能再平庸的两个字拧搓，那最好不要去做这样的营销。

今天是周末，送大家一个福利，是一首曲子，这首曲子我非常喜欢，我也和很多创业的朋友一起听这首曲子。至于这首曲子的名称以及我为什么要喜欢这首曲子，暂且不表，大家先听一听，祝大家周末愉快。
