# 本能的作用

本能让生物能面对场景能快速做出反应，这是他们生存下来一个关键因素。

+   1. 人类生存，依赖于感官这种简单的报警系统

+   嗅觉: 觉得难闻，不用懂得化学，也不会继续闻

+   视觉：看到某些动物感到害怕，不用探明究竟，也会远离它

+   味觉：觉得难吃，不用懂得成分，也不会继续吃

+   2. 动植物生长，遵循经济和简单原则

![](bbox=[0.1, 0.00125, 0.93, 0.00148])

植物：

大的花，通常不怎么香。它在视觉的吸引上有优势的时候，就不用嗅觉来吸引昆虫。

小的花，颜色暗淡的话，它一定会很香，它要用这种嗅觉上的优势来吸引昆虫给它授粉。

![](bbox=[0.08, 0.00202, 0.95, 0.0023])

动物：

长角的动物，它不是食肉动物。

因为如果牙齿足够锋利的话，你就不需要角，就能捕杀猎物。

但我们人在看到一个丰乳肥臀的女性时，不会想这些。

例子3：花为什么漂亮，闻起来香？

为了吸引昆虫过来授粉。一旦授粉以后，花的颜色和花的香味就是多余的了，花就会迅速的枯萎、凋谢了。
