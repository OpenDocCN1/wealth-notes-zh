# 彼得·蒂尔

他讲黑帮文化，他的一切东西都好像有一个标签，就是异类，追求异类，要剔走偏锋，要做不一样的事情，一定不要做大家都觉得对的事情。一个人有什么观点，你听起来突兀，但是你了解他的经历、他的身世，你就能够大致了解了，你会发现他的好多理论其实是君子自况。实际上说的一个很怪异的理论，其实说的是他自己的经历。

+   1. 信仰天主教

彼得·蒂尔一岁的时候，他父母带着他从德国移民到美国。在德国那个地方是个新教国家，他们家是信天主教的，在美国信天主教的人也非常的少，因为美国也是一个新教国家。美国历史上的总统都是新教徒，只有一个是天主教徒，这个人还没做完他的总统就游戏结束了，他叫肯尼迪。所以在美国天主教徒本身就是显得有一点异类（所有的宗教都是平等的，我们不去褒贬。）

![](bbox=[0.05, 0.00171, 0.95, 0.00184])

+   2. 同性恋者

彼得·蒂尔还有一个身份就是同性恋者，当然这个同性恋有人说是亚文化，我看在美国有些地方已经是主流文化了。他生活在湾区（旧金山湾区）。今年我6月份在旧金山的大街上看见两边那个彩旗，我这个人对亚文化特别的无知，我就问他们说，这是要接待外宾吗？他们说不是，七彩旗就是旧金山同性恋的一个盛大的节日。

![](bbox=[0.12, 0.0022, 0.9, 0.00235])

+   3. 跨界创业

他是斯坦福大学毕业，学法律、学哲学，后来他没当上律师，也没当上法官，他自己创业，创立了PayPal（贝宝），贝宝比支付宝要早，应该说支付宝是中国的贝宝。

他创立了这家公司，后来这家公司又卖给了eBay，然后他就去从事投资，我们中国人称他为硅谷创投教父。他在投资领域的确是好像没有失过手。他50万美元投过Facebook，赚了25000倍，他是Facebook第一个投资人。后来他又投了马斯克的SpaceX，还投了Yelp，就是美国的大众点评网，也投了领英（LinkedIn），都是很成功的投资。

+   4. 逆向投资

｜注重硬件

他虽然在硅谷，但是他始终是保持一种异类的姿态，他一直在攻击硅谷，他觉得硅谷太注重软件，不注重硬件，只有硬件才真正能改变世界。他无意当中说出了一句真理，说出了一个趋势，事实上这些年来美国的IT界、互联网界，已经显出一个明显的趋势，就是从软到硬，我们发现Google公司越来越硬了，微软这家软的不能再软的公司现在也推出了各种各样的硬件。他看不起那种软 licence 的互联网公司，比如他很瞧不上Twitter，他说我们本来要的是一辆会飞的汽车，结果却得到了无聊的140个字。听他这种话就能够看出他这个人的性格。

｜支持川普

当川普同志宣布竞选美国总统的时候，他在硅谷第一个站出来支持川普。硅谷的人都是非常恨川普的，支持川普使得他在硅谷变成了过街的老鼠人人喊打，他一点都不在乎。他自告奋勇，充当川普在旧金山地区的竞选代表，到处去发表演讲。

你想在旧金山那个地方，你去对那么一个很奇葩的人去摇旗呐喊，你的神神经应该是很坚硬的。但是他毫不不在乎，一如既往地支持川普，所以当川普最后获胜的时候，他发表了一篇热情洋溢的演讲。他认为川普是真正再关心实际问题的人，是抓住问题本质的人，当美国国民一年的医疗费用涨了80%的时候，希拉里在讨论变性人该上男厕所还是女厕所，他觉得很多政客们讨论的问题，包括投资界、产业界的人讨论的好多问题可以用两个字来概括“扯淡”，很不幸或者很幸运的是他又赢了，他是一个典型的逆向投资的人。他总是看好别人不看好的事情，义无反顾地投身其中。
