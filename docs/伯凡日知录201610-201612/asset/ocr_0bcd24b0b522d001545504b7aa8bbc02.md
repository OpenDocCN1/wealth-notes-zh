# 本周预告｜聊一聊“迭代”

![](bbox=[0.08, 0.38, 0.14, 0.42])

本周预告｜聊一聊“迭代”

大家好，昨天我们让大家听了一首曲子，这首曲子叫波莱罗，是法国作曲家拉威尔的作品，之所以让大家来听这首曲子，是因为我们本周的话题跟这首曲子有一种深度的相关。当然也许只有在听完本周的节目之后，我们才 E会明白我为什么要让大家来听这首曲子，希望大家在听完本周的节目后，在知几局里头好好地讨论一下。

我们本周的话题实际上是跟创业和产品开发的方法有关，我们从爱因斯坦小时候做的三个小板凳的故事讲起，详细地解释了什么叫做迭代。

最近一两年大家都在说迭代，但他问到什么叫迭代，大家可能会有这样的感觉，你不问我的时候我还明白，你要问我它是什么的时候，我好像有点不明白了。

我们本周就从各种各样的案例、故事以及管理学的一些知识点来解释什么叫迭代。为什么说迭代是通过拥抱失败而避免致命失败的最好方法？为什么说没有蓝图、没有路径规划的迭代才是真正有效的行动逻辑？为什么说战略只能是手艺，而不是规划？人不能够学会游泳再下水，所以迭代是一种虽然不那么炫酷，但是卓有成效的行动逻辑。我们也讲到了一种常见病拖延症，为什么说那种总是渴求从0到1的完美主义是拖延症真正的病源？《从0到1》的作者彼得·蒂尔为什么极力反对迭代的方法，而主张创业就是从0到1，他的观点到底有什么漏洞？为什么说阿里巴巴、亚马逊的成长历程本身就说明创业就是从0到1，也是从1到N的过程？从长时段来看，从0到1的奇迹，从局部来看往往是从1到N。商业上的诸多重大突破往往像草丛里的冬瓜，表面上看是横空出世，其实是潜滋暗长出来的，我们怎样才能让自己的公司拥有那种潜滋暗长而又横空出世的新业务、新模式、新产品呢？我们如何让自己和自己的公司表面上是一直在做同一件事情，而却持续地创造从0到1的奇迹呢？欢迎大家收听本周的《伯凡·日知录》。

徐1— 15 现在都在说迭代，产品的快速迭代，知识的迭代升级等等。迭代到底是什么？我总， 可能就是立即行动的意志力。彼得·蒂尔所说的从0到1，引发了我另外一种思考，就是他反对迭代的概念基于埃隆·马斯克的“第一原理思维”，为什么马斯克敢把电动车做成跑车？他有一段阐述--“我们运用‘第一原理思维’而不是‘比较思维’去思考问题是非常重要的。我们在生活中总是倾向于比较—别人已经做过了或者正在做这件事情，我们就也去做。这样的结果是只能产生细小的迭代发展。‘第一原理’的思考方式是从物理学的角度看待世界的方法，也就是说一层层剥开事物的表象，看到里面的本质，然后再从本质一层层往上走。”

但我认为，从0到1和迭代之间并不矛盾，前者回答了找回“根本问题”和“根本原因”的思路，后者是具体行动的策略，而且迭代的这种比较思维仍然重要，其重点在于找到“例外”。法国科学家庞加莱有一段话：“正是例外让事情变得重要起来。我们不去寻求相似，我们尤其要全力找出差别，因为它们最富有启发性。”

所有的创造都有着相同的 Fecha：由一个问题引向一个对策，在引出下一个问题的渐进步骤。想在某一领域成为专家，或者想拥有自己独树一帜的技能，其实就是在这样一次一次的迭代过程也演化出来的。这也是回答了阿里巴巴和亚马逊的成功，不仅仅是“从0到1”，也是“从1到N”的过程。你不会一开始就做的很好，但只要你开始去做，慢慢增加自己迭代的次数和频率，你也可以成为一个优秀的创新者。12-18 16:17:23
