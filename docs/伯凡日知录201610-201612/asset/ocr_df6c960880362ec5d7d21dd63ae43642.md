# 本周问答 | 如何提升自己的格局？

王立：有格局的人和侠肝义胆的人有什么关联？侠肝义胆好像比较多来形容英雄，但中国的英雄都是悲剧人物，而有格局的人似乎都是后人的评价，而英雄都是当世的评价，怎样看待这样的问题呢？

![](bbox=[0.08, 0.78, 0.12, 0.82])

吴伯凡

说到格局，我不敢使用像“侠肝义胆”这样道德色彩浓厚的词，因为我只是从理性、利益的角度来分析有格局的人的“算法”。我们习惯性认为，有格局的人是那种不愿意计算的人，“精于算计”只是用来形容那些小气的、没有格局的人的。事实上，有格局的人恰恰是善于“算”、精于“算”的人。算即筹划、谋划。《孙子兵法》中有ut 一句很著名的话：“夫未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也。多算胜，少算不胜，而况于无算乎。吾以此观之，胜负见矣。”

算计的“算”，筹划的“筹”，都是古代的计算工具，都是用竹子做的计算工具。所以这两个字都是竹字头，尤其是“算”上面是一个竹字，下面其实是一个工具的“具”，（“算，从竹，从具”）。算，也叫运筹，军事将领的主要工作就是“算”，“运筹”。刘邦夸张良的风范的时候说“运筹帷幄之中，决胜千里之外”。这里所说的“算”、“运筹”，显然已经不是纯粹的计算行为，它更接近于战略管理。

应用数学的一个重要分支学科，研究的是如何将生产、管理等事件中出现的问题加以提炼，用数学方法进行解决，这门学科就叫运筹学。运筹是从大视野和整体格局上进行“算计”，进行“计算”。我们通常所说的算计之人，即没有格局之人，就是缺乏大视野和整体格局视野的算计者，他也在“算”，但是他没有大视野，没有整体的格局。所以在日常生活中，没有格局的人常常被形容为“会算小帐，不会算大帐”。简单地说，有格局的人就是始终以大视野和大格局为参照系的精打细算。有格局的人并非没有企图，没有目标，只不过他的企图和目标不是一眼就见到底的，他的目标很大，大到不那么直接，不那么明确，或者说，他的目标是非线性的。我们可以借用哲学家康德的一句话来形容有格局的人的企图和目标——“无目的的合目的性，无功利的合功利性”。

对一个事态的判断，对利害的取舍，无格局的人习惯于眼见为实的直接判断和取舍，有格局的人往往是“延迟判断”，因为他相信“效果延迟”是事情的常态。

“效果延迟”是《第五项修炼》里的核心概念。在彼得·圣吉看来，真正有效的思考都是“系统思考”，随生随灭、就事论事的思考不过是于事无补的杂念和小聪明，这种小聪明只能找到“症状解”，找不到“杠杆解”。

“症状解”和“杠杆解”的最大的差别就在于，“症状解”给出的是直接解决的方案，但是它解决不了真正的问题；“杠杆解”是一种间接的解决方案。我们看到一块石头的时候，用手去搬，是“症状解”；用一个杠杆，下面垫一块石头作为支点，去撬动它，是“杠杆解”。“杠杆解”显然是不直接的，但是它的解决的力度、它的解决的效果，那是“症状解”完全不可同日而语。

如此说来，所谓有格局，就是懂得、擅长“系统思考”，找到“杠杆解”。

说到这里，大家也就明白我只说“有格局”，不说“侠肝义胆”了。我也喜欢“侠肝义胆”，但我在这里想和大家探讨的不是英雄，不是勇，而是谋，不是岳飞，而是兴周八百年之姜子牙、兴汉四百年之张良之类的人。

如何提升自己的格局，提升自己看到暗局的敏感力？是否可以通过刻意练习达到？

![](bbox=[0.08, 0.00375, 0.12, 0.0038])

吴伯凡

回答了上面的问题，这个问题就容易回答一些了。既然格局与系统思考，与杠杆解有关，那么我们就可以有意识地养成系统思考的习惯。我说到了空城计的故事，这个故事是虚构的，跟诸葛亮交锋的不是司马懿，而是张郃，我只是借这个故事简略地说明“局中局”、“计中计”的复杂性。华容道的故事是真实的，同样也能说明暗局的重要性。我简单分析一下华容道中的几个暗局。

华容道，明局就是曹操落荒而逃，最后逃到了华容道，这是他的必经之路。

诸葛亮预计到他会走这条路，但是派谁去抓曹操呢？如果是一个头脑简单，只要求执行力，而不注重战略洞察力，不注重战略性解决问题的 人，他就会派张飞去，因为执行力很强，他看到曹操就会大喝一声，上去就把曹操的首级给取下来，这样会坏了大事。因为既要捉曹操，但是又不能把曹操杀了。
