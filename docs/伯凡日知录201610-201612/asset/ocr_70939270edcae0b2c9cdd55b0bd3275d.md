# 阿里集团的 “大白兔”

马云在公司有一项重要的任务，就是杀掉公司里的大小白兔。

![](bbox=[0.1, 0.75, 0.95, 0.91])

什么是大白兔？

公司里人缘特别好，特别会处事，但是特别不能干事的人。大白兔为了保住自己的地位会培养很多小白兔，招来一些无用之人。

大白兔的天敌是谁？

任何动物都有天敌，一旦没有天敌就会有灾难性的情况发生。在澳大利亚曾经有过兔灾，那个地方狼很少，好事者弄了几只兔子过去，因为没有天敌，它就发展得特别快，草原被搞得一塌糊涂，各种兔子洞，兔子跟羊争草吃。澳大利亚也不敢随便从国外引进狼，因为不知道引进的那个天敌到那个地方又会是什么样子。后来他们采取了一个很简单粗暴直接有效的办法，就买了很多的铁丝网铺在草原上，草还可以生长，但是兔子就出不来了。

英吉利海峡的一个的岗哨，每天有人轮岗，岗哨其实没有作用，却保留了140年。

+   2.神秘的宫女

在《武媚娘传奇》中有一個情节，因为皇宫维修墙壁，在走廊转角处安排了一名宫女，提醒过路的人当心墙壁。但墙修好后，不再需要人提醒，这个职位被保留了几十年，也无人过问。
