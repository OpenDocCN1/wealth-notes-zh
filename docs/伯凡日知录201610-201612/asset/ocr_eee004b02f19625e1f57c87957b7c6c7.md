# 辅助性服务：

当人跟狼去争夺猎物的时候，作为人的狩猎的一个辅助性的角色，利用嗅觉追踪动物。兔子几个小时之前从这儿经过，它一闻它就能闻到，它能把人带到那个兔子窝去。

由于长期在黑暗当中做一个守望者，它的视觉就发生了变化。晚上，看不见颜色，它需要捕捉的信息是关于形状和动态的这种信息，所以狗在进化过程中逐渐变得只能看见黑白两种颜色，狗的世界是一个黑白世界。

# 狗为什么那么“好”

狗在被人类驯化过程中经历了人为选择，那些又像狼又像狗的动物，生下了一窝小动物之后，人类会把那些性情比较猛烈的摔死，把那些对人非常温顺，非常忠诚，又对猎物非常凶猛的小动物留下来。经过三十代，它的性状就会固化。

因此，现在的狗才具备了忠诚、敏捷等很多很好的品质。

# 狼与狗数量对比

狼非常凶悍，经常抱团作战，但随着人的地盘越来越大，现在已经是一种濒危动物。电影《狼图腾》找不到足够多的狼，总共就七匹狼，所以画面不好看。

狗的数量一直都在增长，有数字统计美国人每年的狗粮消耗量可以养活所有非洲饥饿的难民。

狗是一种非常成功的物种，原因就在于它选择了一个独特的生态位，找到了蓝海市场，而且能够跟强势的物种形成战略联盟。这种蓝海加上战略联盟，使得这个物种到了无往不胜的地步。人类的人口在大城市已经出现下降的趋势，且人口增长的速度远比不上狗口膨胀的速度。这样看来，狗的生存策略是不是非常的成功？
