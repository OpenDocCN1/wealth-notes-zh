例子：亨氏番茄酱的升维战略

亨氏番茄酱当年在销售的过程当中，经过猛烈的营销战以后，到了一个销量之后增长就变得非常平稳，甚至停滞不前。要想让自己的销量增加，沿着同样的思路再继续广告力度、营销力度去做的话，收效可能是很小的。

# 对产品重新定位：

+   1. 他们发现小朋友过生日的时候，最兴奋的是到蛋糕店，让那些做蛋糕的叔叔阿姨在蛋糕上写上 “Happy Birthday” ，甚至是写上他的名字，还画个小红心，画几朵花，那个画笔里的材料其实是一种有颜色的奶油。这种特殊的笔让亨氏公司的人立即产生了灵感。

+   2. 他们制造了一种番茄酱画笔，小朋友不仅在生日的时候体会那种快乐，平常就可以能享受到这种快乐，而且可以自己拿着那个画笔涂鸦。这种像画笔一样的番茄酱推出以后大受欢迎。

+   3. 一个意外的好处，人的口味是在六岁以前基本上定型的，如果你在小时候老吃一种东西，他就会形成一种强烈的味觉记忆，说白了那就是一种 “瘾”。你生在湖南，渐渐你就会对辣椒有一种 “瘾”，如果你在小时候经常吃比较多的番茄酱，你一辈子番茄酱的消费量要比别人大得多。所以麦当劳、肯德基里再狭窄他要搞个儿童乐园，让小朋友经常去，不仅仅是赚你今天的钱，还要赚未来的钱，他不是房地产公司，但是他让你永远在那儿交接揭。

亨氏公司做的这样的事情，其实就是一种升维。普通的人只看到了 “吃” 这个维度，没有看到 “玩” 这个维度，更没有看到塑造人的消费习惯这个维度。当你发现这几个维度的时候，这样做事情那就叫杠杆解，而不是症状解。

销量如果停滞了，就拼命地打广告，这叫症状解；

销量停滞了我用另外的一种方式，我用升维的方式，以很小的成本实现巨大的收益，这就叫杠杆解。

# 为什么会 “穷” ？

很多商业模式的缺陷其实是一种隐性的缺陷，它不是没有找到需求、痛点，而是它没有找到多维度痛点。当你沿一个维度进行努力的时候，你很快就面临一个边际效应递减的问题，你投入的很大，你的投入在增加，你相应的收益在减少。

这个时候你要考虑到对客户的价值主张和卖点的升维，如果做不到这一点你就会陷入到你自己没有意识到的一种懒惰当中。你越来越勤奋，但是发现自己越来越穷。

这个穷首先是结果，就是收益的递减，但根子是在于你的方法 的 “穷” ，黔驴技穷的 “穷” ，是方法的 “穷” 导致结果的 “穷” 。

# 关于学习小组：

《伯凡日知录》的Slogan是：自我迭代者的学习小组。

“得到” 的APP现在已经上线了一个叫 “学习小组” 的功能，这为了让大家除做一个倾听者之外，还要做一个发言者。

以前，我们的学习小组其实只是一个 “一点对多点” 的传播方式，大家的发言我能够看得到，但是其他的同学看不到。有一个谜语叫 “人人都能做，但不能看着做” ，那说的是做梦。

现在，学习小组变成了 “多点对多点” 的一个知识社区，人人都能发言，而且能看到大家发言。

在学习小组，大家可以自由地讨论问题，相互提问，相互回答问题。

看到有些特别有意思的问题，我肯定会当仁不让在那里，也会加入到大家的七嘴八舌里头来。

我们的学习小组就是一个有活力的，没有主角，但人人都是主角的这么一个好地方。
