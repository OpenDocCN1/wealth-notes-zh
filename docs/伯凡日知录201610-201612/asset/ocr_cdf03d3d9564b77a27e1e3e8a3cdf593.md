爱因斯坦的三个小板凳

在德国有个小学，这个小学的班上有一个傻孩子，5岁才 fio? 他家里人都非常担心，（5岁都不会说话，智商肯定是有问题），突然有一天他开始说了，家里人总算心里一块石头落地，后来把他送学校，但还是很笨，反应特别的慢。

![](bbox=[0.22, 0.95, 0.95, 0.0011799999999999998])

有一次老师布置了手工课作业，到交作业那天，有的人剪出了一朵漂亮的纸花，有的人用木头做出了 一把手枪等等。轮到这个笨孩子交作业的时候，他有点踌躇，在老师逼迫的目光下他拿出了他的作业，一个特别难看的小板凳。老师看到的时候非常的生气，但又不好说得太刻薄。他拿起这个小板凳对班里的同学说：“你们见过有比这更难看的小板凳吗？”这个笨孩子很沉着，应该属于一流人才，受到攻击时不反应。他就很平气和地弓下身子，从他的那个桌子底下说：“有的有的。（他拿出一个板凳）这是我昨天做的，（然后再拿出一个板凳）这是我前天做的，这两个小板凳比手里这个还难看。”当时那个老师有点愣住了，他一下子停止了对这个小孩的攻击。这个小孩叫阿尔伯特·爱因斯坦。

长大后他送给人类三个类礼物：一，狭义相对论；二，广义相对论；三，光的波粒二象性原理。

我现在来复述这篇课文的时候，我心里想的是一个词——迭代。

# 什么叫迭代？

准确的解释是在重复当中快速地改善、快速地消除已经发现的瑕疵和毛病，每一个版本好像是没有多大的变化，但实际上每一个版本都在改进。你用这个有缺陷的产品去跟客户对话，让客户来告诉你问题在哪里，这样你就获得了对于客户需求、对于市场的认知。然后把这些认知转化为你改进产品的依据，这样一点一点地改进，这是一种产品创新的方法。

如果你的产品发布出来的时候，你都没有明显地看到你产品的缺陷，证明你发布这个产品已经太晚了。

# 迭代的定义：

学术化的定义：以最小的代价、非致命的失败迅速地、持续地改善你的产品。

生活化的定义：早失败、快失败、常失败，在失败中快速改进。

迭代的英文iteration，是指有点嘟嘟囔囔、吞吞吐吐、犹豫不决地说出你的话。然后别人听见以后会反问你：“你说的意思到底什么？”然后你针对这个疑问，你再进行澄清、进行解释。别人还是可能没有听懂，你继续解释，直到别人听懂为止。iteration的意思是这样一个重复地说，但是每一次重复当中都是有改进地说，他不是一次性地说完，不是脱口而出，不是金句。rapid iteration这是我们今天创业的趋势。

# 创业是挣钱还是挣认知？

《精益创业》有一个很核心的观点：你创业的时候千万别首先抱着赚钱的目的去创业。

+   1. 以赚钱为目的去创业，本身这个立意很平庸，或者说是比较没差异化的。

+   2. 当你抱着赚钱的目的去创业的时候，你实际上是冲着结果去，你都根本不知道前面的过程是什么。赚没赚到钱只是一个结果，关键是在前面的产品你做了些什么，所以你应该少想钱的事，多想认知。

你发布一个产品，哪怕是第一次发布1.0版的产品，你其实是在表达你对客户需求的认知。但这个认知有效还是无效，你自己是不知道的。

| 猜想与反馈

科学研究是首先提出猜想，然后再提出反馈。反馈倒了就证明你这个猜想有问题；反馈不倒证明你这个是对的。

猜想和反驳不是一次性完成的，他是不断地提出猜想，然后不断地提出反驳，最后在这种反驳当中立于不倒的那个东西就叫科学。但科学今天不被反驳倒，不一定说明天就驳不倒。我们现在说嘲笑博导（博士生导师），博导一驳就倒，其实科学它常常是一驳就倒的，正是在那种驳倒的过程中当中建立你的认知和权威。

# 一个产品怎么才能不是去挣钱，而是挣认知？

把你的产品作为你的认知，作为你科学研究的一个实验放在市场上，让用户来反驳你。用户有各种各样反驳的方式，有直接骂你的，有拒绝你的，还有一种我们特别害怕的，就是根本不理你的。

我们在做产品的时候，不要等到这个东西已经自以为做完美了才拿向市场。丑媳妇怕见公婆的这种心态不能够去创业，你是丑媳妇就是丑媳妇，你先让市场来检验你，你是丑小鸭你就放到市场上，天鹅它不是一天变成的。

迭代其实就是一个挣认知的过程。

![](bbox=[0.22, 0.00658, 0.95, 0.00715])

创业者应该学会写自己的知识日记，写你对客户的需求、对市场认知的日记，每天或者每周、每月都可以写下这样的总结，分成两段——

第一段，从前我认为……

第二段，没有人告诉我……在你发布产品以后，你发现的那 些新认知

你不断地去写这样的知识日记，你挣的认知就越来越多了。
