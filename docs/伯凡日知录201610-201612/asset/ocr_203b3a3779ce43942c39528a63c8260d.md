# 洗脑与观念病毒

制造观念病毒跟洗脑不同，用买房装修来打比方，洗脑只是开荒的阶段。先把房子收拾干净，最重要的是往里面装东西，如果被装进去的是观念病毒，相当于把你的整个操作系统的源代码改了。然后就用不着每一步输入命令，你也会心甘情愿去做一些事情。

![](bbox=[0.22, 0.00155, 0.78, 0.0018700000000000001])

政府严厉打击的那种传销组织，其实他不是在洗脑，他是在往你的大脑中装源代码。

传销很多时候很邪教类似，邪教也可以说是一种宗教，只不过是一种邪恶的宗教。

马克思有一段话很经典：

> 宗教是无情世界的情感，是被压迫生灵的叹息，宗教是人民的鸦片。

# 痴 癫

例子2：痴迷的“痴”

有一本书叫《迷恋》，它认为品牌最高的境界就是让你达到一种痴迷的状态。

“痴”这个字，简体字的“痴”上面一个“病”，下面是个“知”，病态的知识。

繁体的痴，是“癡”，上面是“病”，下面是“疑”，怀疑的“疑”，“癡”更接近于痴的本意。

就是当一个人开始怀疑一个东西的时候，他的信息收集方式，他的刺激接受方式是排他性的。只要跟我的欲望、跟我的判断相关的我都接受，不相关的我一律排斥。

例子3：星巴克宗教

星巴克咖啡店相当于在一个教堂越来越少、越来越冷落的时代的一个替代性的教堂。

那些人走进星巴克，是带着某种敬拜和朝圣的状态，同时还有某种排他性的状态，也就是说你不进来这个咖啡店是你的不幸，那些进到那个里的人都觉得自己是一种豪召的感觉，具有一种选民意识，就是他是被遴选的，被召唤的那样一种状态。
