# 例子3：星巴克宗教

星巴克咖啡店相当于在一个教堂越来越少、越来越冷落的时代的一个替代性的教堂。

那些人走进星巴克，是带着某种敬拜和朝圣的状态，同时还有某种排他性的状况，也就是说你不进到这个咖啡店是你的不幸，那些进到那个人都觉得自己是一种豪召的感觉，具有一种选民意识，就是他是被遴选的，被召唤的那样一种状态。

品牌追求病毒式营销，将观念病毒植入到人们的头脑当中，以实现品牌的三个功能，市嘲能见度、价格不敏感度和用户忠诚度。

这样做无可厚非，因为有市场在随时做调控。

你可以在所有的时候蒙骗一部分人，你可以在某一段时间蒙骗所有的人，但是你不能在所有的时间蒙骗所有的人。

# 例子4：企业的“内品牌”

内品牌是指企业对于内部员工的这种感召力。

很多公司对他们的员工也在实行一种病毒式的营销和病毒式的品牌传播，它所达到的效果其实跟市场品牌是一样的，让员工进入一个狭窄的、单一的思维通道，对公司、对雇主产生一种完全排他性的认可。

我们连续几天都是在谈寄生虫、谈病毒，谈一种无形控制，目的其实只有一个，就是让这个东西在我们的头脑当中挂一个号。

艾滋病毒之所以可怕，是因为它把人体的整个免疫系统摧毁，让你的免疫系统丧失功能，对它丧失识别能力，更不用说抵抗能力。

病毒并不可怕，最可怕的是对病毒失去识别和抵御的能力和愿望。

当我们意识到我们的周围观念病毒满天飞的时候，我们就有一种起码的清醒，有了一种起码的反思能力。
