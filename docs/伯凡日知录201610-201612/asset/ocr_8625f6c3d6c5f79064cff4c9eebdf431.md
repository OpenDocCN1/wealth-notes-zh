# —— 知识笔记 ——

两千多万年以前，由于地球的气候变暖，有一些熊可能是因为怕冷的原因南迁，走到了秦岭，那里是中国南北分界线，气候特征既像南方又像北方。

那里纬度比较高，但又生长着只有低纬度地区长得一种植物，竹子。

熊来到这，看到这一片大竹海，它们的生存习性就发生了改变。

第一，因为有吃不完竹子，所以它就吃竹子，别 perceive 都不吃了。

第二，因为冬天也有的吃，它们就不冬眠了。

与熊猫的生活习性相关的3个数字：

+   16，熊猫每天要用16个小时吃竹子。
17，熊猫吃进去的竹子只有17%被吸收。
18，每天成年熊猫要吃18公斤竹子。

熊猫只吃两种竹子：undy 竹、箭竹。

竹子的特点：

+   1. 一片竹林都是由一个母竹长出来的，所有竹子的寿命与母竹的寿命一样。
2. 竹子一生只开一次花，结一次果。一旦一个竹子开花，所有的竹子都要开花，开花就意味着这片竹子大面积的集体性的死去。

# 熊猫遭遇的困境

+   1. 食物单一：竹子集体死亡，熊猫没有食物，它们就会饿死。

有一首歌叫《熊猫咪咪》的歌词，

竹子开花，咪咪躺在妈妈的怀里数星星。

星星，星星多美丽，每天的早餐在哪里。

这是一首义演时唱的歌曲，科学考察队在在一大片死去的竹海里头发现百多具熊猫的尸体，因为竹子集体死亡，熊猫没有食物，它们全部饿死了。

2. 繁殖能力低

熊猫每天花大量的时间在吃，消耗很多体力，加上食物单一，导致熊猫完全失去性欲。

沈鸿飞写过一篇文章叫《大熊猫看小电影》，为了提高它们的繁殖能力，让它们有欲望交配，就给它们放以前拍下来的熊猫交配的那些电影。

熊本来具有的非常强悍的生存能力和非常具有应对性的生存策略在熊猫身上逐渐地退化。能力缺失，生存路径单一，战略缺乏弹性。与此同时，一个表面上好像很稳定的生存环境，它实际上是有 一个大周期的。当这个大周期一旦来临的时候，也就 是说新竹子和老竹子青黄不接的时候，那 灭顶之灾就来临了。

一件事情，一种资源，表面上看是福音，但是这种资源它会暗中绑架你，让你悄悄地形成一种路径依赖。而一旦这个路径发生改变，或者塌陷的时候，一下子就会陷入到危机，甚至毁灭性的危机当中。

# 警惕颠覆性创新

颠覆性创新就是连锁端式的创新。这种创新一旦出来，不是来抢你蛋糕的，不是来分你蛋糕的，它是把你的整个蛋糕给拿走的。

在各行各业，我们今天都可能遇到这种颠覆性的创新。就是你常年累月，靠山吃山，靠水吃水的那个好像亘古不变的那个资源突然有一天没有了。尤其是一些垄断企业，垄断其实是一个福音，谁也不能够进到你地盘来，但是在这样一个天堂般的环境里头，你是在经历一种叫无痛截肢的一种手术，你是感觉不到这种痛苦。当你知道的时候，而当你知道的时候，一切都晚了。
