# 多维的世界

有时候我们说要开阔视野，要拓展自己的空间，要从一个边缘人变成一个中心人，这些说法里头都隐含着一个概念——二维。

当我们说进步的时候，常常是一维的。

点就是零维，没有长宽高，线是一维，面是二维，体是三维。好多时候我们是零维的，我们只是在一个点上，痛点、爽点、槽点，点是一个零维的。如何从点拓展为线，从线拓展为面，从面拓展为体，三维世界，如果再加上一个时间维度，那就是四维。

量子力学描绘或者说承诺了一个多维度的世界。量子力学的“弦论”，听起来像一个音乐学的名词，其实弦论认为，这个世界其实是十一维的，我们四维都很难想象，而且我们经常是处于二维的世界，要不就是一维的世界。

# 两本与维度相关的书

![](bbox=[0.3, 0.00175, 0.68, 0.0022])

1. 哲学家马尔·库塞的一本书，书的名字有很多译法，有译成叫《单向度的人》，有的译成叫《单面人》，我觉得就可以把它译成叫“单维人”，就是只有一个维度的人。马尔·库塞他告诉人们，从表面上看现代社会是比古代社会更进步了，但他看来进步就是一个单维的，从A点到B点，那就是一个单维的进展。

![](bbox=[0.3, 0.00275, 0.6, 0.00315])

2. 陈丹青有一个散文集叫《退步集》，这是一个很酷的名字。就是说人都在讲进步，他在讲退步，实际上他讲的退步就是说我拒绝你的这种单维世界的衡量标准，我要佯守我一个多维度的世界。

# 拒绝各种单维标准

我们要学会，你要活得像个人样，你就要拒绝各种单维标准。

+   学校里的考试分数高低；
工作以后按钱多钱少；
颜值高低；
年纪大小；
……

马尔·库塞发现，这些维度放在一起，表面上是多个维度，其实是一个维度，都可以折算成一个东西——钱。

颜值，归根到底还是面子，有的人要夸耀自己年轻，是因为在这个人格市场，这个价格要比那个价格高。所以如果我们生活在这个一个单维的世界里头，自己觉得很爽，不停地在进步，对那些退步的人、不进步的人、不长进的人非常的鄙视。但实际上在这个世界上，你觉得别人不如你，很可能就是人家没有按照你的这个维度在生存。
