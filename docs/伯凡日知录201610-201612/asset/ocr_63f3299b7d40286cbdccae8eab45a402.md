# 吴伯凡

在股市当中，真正赚钱的，是那些深诸人心的弱点的人。所谓人心的弱点，其中有一个很重要的因素就是本能。看见大家都在买的时候，自己赶紧去买；看见大家逃的时候，大家赶紧去逃。

从众是在人类长期的演化过程当中形成的一种能力，当你看见别人在奔跑的时候，你赶紧要跑，不要等后面的老虎上来的時候才來跑。这种本能，使得我们没有葬身虎口；那些没有这种本能的人、没有这种习惯的人，他的基因没有保存下来，他已经留在虎口里了。

我之所以说我们应该反抗本能，不是不说所有的本能都要反抗，而是要反抗那些具有非常大的普遍性，可以说人人都有那样一种本能。

在炒股的时候，在股市上我们都要问自己一个问题：我们的知识、信息跟别人都是一样的，我们的反应模式跟别人都是一样的，你就别指望，你的结果是跟别人不一样的。股市永远是10%、5%的人，在赚那90%、95%的人的钱。

所以，巴菲特说的别人贪婪我恐惧，别 人恐惧我贪婪，其实贪婪和恐惧都可以说是一种本能，而关键在于，是别人贪婪的时候，大多数人贪婪的时候，我去恐惧，而当大多数人恐惧的时候，我去贪婪。

所以，反本能的话题，其实是一个提高竞争力的话题。如果我们面对一个机会，所凭借所依靠的都是与生俱来的内部反应，都是一种默认程序，但这种默认程序，所有的人都是一样的话，那你已经自己把自己放逐到沉默的大多数中了，你已经把自己放逐到乌合之众当中了，而所谓乌合之众，就是数量巨大的、完全听任本能、被寄生虫式的病毒式的观念完全搔布，而自己还觉得自己是在追求个性，实际是上极度不自由的那样的一群人。

如果我们置身于乌合之众这个群体当中的时候，我们别指望自己成为赢家，我们经常说散户思维，所谓散户思维，就是思维模式几乎完全受本能操作，而且，几乎是完全同质化的那样一种思维模式。

明净天空：伯凡老师，想请教一个问题：本能是长期进化 spline of ...

# 吴伯凡

区别很简单，本能是共通的。食色性也，这是本能；从众，这是本能；大家都恐惧的时候，我也恐惧，大家都贪婪的时候，我也贪婪，这都是本能。

性格是属于个人的。性格和本能相同的地方，它们都是一种默认程序，都是一种固定的反应模式，但本能是更基础性的，几乎是人类共通的那样一些反应模式，性格是带有很明显的个人化色彩。

孔夫子说，性相近，习相远，他所说的这个“性”，比较接近于我们说的本能。小孩生下来，他就会吃奶，那就叫性。但是每个人，后天的际遇后天的环境不一样，因为后天的际遇和环境的不同，而导致的不同，那叫习。他说性相近，习相远。

但对于个人来说，长期养成的习惯，近乎于本能，它是一种个人型的本能。所以有一句话说习惯成自然，这就是两者之间的差别。

我们之所以讲这些话题，就是想跟大家分享一个感悟，如果我们以资产管理的态度，来反省我们的行为动机和行为动力的話，我们或许就会对自己的现状，以及自己的方向，未来的方向，有一个清醒的判断，我们的净资产到底是多少？

有时候由于负资产太多，债务太多，我们又没有意识到那是负资产，没有意识到那是债务，更没有意识到有些债务是高利贷，我们很努力地做一些事情，结果年底一核算下来，发现自己根本就没有赚到钱。这也是为什么我们经常听到这样的感叹：为什么我这么努力，但是我还是这么穷？我们应该象《肖申克的救赎》里的主人公安迪那样，他是一个对自己拥有的资产、对自己的自由和非自由的状态，有非常清晰认识，并且是尽可能地努力去赎回那些债务，让自己真正获得自由的人。

阿佳：是不是先有一点点对某事物的欲望，才会被植入那个某观念病毒？

# 吴伯凡

答案是肯定的。传播、植入病毒，其实就是讲故事，讲故事的能力。一个故事，既是无中生有，又能让祢相信，怎么样才能做到这一点？用《道德经》里的話概括就是，虚实相生，有无相乘。

很多的谣言之所以传播度特别地广，它因为里包含着某些显而易见的、你已经知道的那些事实，再借助于这些事实，它才可能将谎言编织进来。

我们编草席的时候，竖向的叫经，横向的叫纬，经纬交织，就成为一张草席。编一个谎言编一个故事，它的虚幻的东西跟它实际的东西，是交织在一起的；光有虚，是不可能成为一个好故事的，它不可能植入到我们的头脑当中的。
