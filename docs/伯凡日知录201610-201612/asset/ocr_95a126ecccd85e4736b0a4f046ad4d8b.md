# 无感的营销

过去我只是认为，做传统媒体的人，日子越来越不好过；现在才发现，搞传统营销的人，日子更难过。

传统营销说白了就是吵闹。就是光说不练叫假把式，光练不说叫傻把式，既说又练叫真把式。用德鲁克的话说：企业只有两大使命——创造价值和告知价值。前面叫创新，后面叫营销。

现在搞营销的人突然发现，砸了那么多的钱，不仅没效果，甚至还出现负效果，大家都在苦苦地思考，为什么不管用呢？这有点像面对叛逆的孩子，父母无奈的那种状况。其实我觉得，有可能的话，听听我们前两天讲的那几件事，他们可能就明白一点了。

原来的那种营销方式之所以管用，是因为企业面对的是一个解部落化的世界，而在不知不觉之间，解部落化被再部落化所替代了。

例子1：群内的无效广告

在群里发放软广告，大家一眼就能识别，群主就可能说，“再发同类信息，踢无赦”；就算群主是你的好哥们儿，他不踢你，也根本没人看你的东西，无人喝彩，无人评论，连骂你都没兴趣。

# 批量投放-精准营销-消费者洞察

｜批量投放：

过去的营销，说是传播，其实就是“播”，就是一点对多点的撒种子，撒网。“传”的功夫做得很少，你撒下去就好。就批量投放，地毯式轰炸，算概率，这一万个人里，我把一个营销炸弹扔过去，总有百分之几的冤大头会中招，用这样一种方式批量投放。

｜精准营销：

后来搞精准营销，就在找人群，什么是对我感兴趣的，什么不是。满大街求爱，见女的就挪不动步，那种方式发现不管用的时候，就开始琢磨，留什么样头发的女生，穿什么鞋、戴什么手环的女生，可能是我的菜，也可能我就是她的菜。这种就叫“精准投放”。

# 部落的自动拉黑、屏蔽和拒绝

｜自动拉黑和屏蔽

TED里有一个很牛的大叔，讲我们看到的世界并不真的是那个样子，叫“眼见非实”，在里头他有一句话叫“We are blind to our blindness。”我们对我们的看不见是看不见的。

![](bbox=[0.07, 3.6, 0.95, 4.4])

例子1：父母想通过微信观察孩子动态

+   1. 专门为你注册的微信。他偶尔在那上头说几句正确的话，让你觉得开心，其实人家根本不用那个，他只是定期更新一次，逗你开心而已。

2. 分组，分组可见、分组不可见。你还在对他进行归类，他早已经把你给归类了。所以你自己还发个朋友圈，要注意身体就搞那些养生的东西，要奋发图强就搞那些心灵鸡汤，想让孩子无意当中看到，把那些你直接不好跟他说的啰嗦告诉他，他第一是不让你看他的朋友圈，第二是不看你的朋友圈。
