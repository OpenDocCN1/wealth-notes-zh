# 动物的智慧

斑马躲避狮子的追捕是用了《道德经》的反经，反过来 xem，少则得，多则惑，我永远坚持多，把捕猎的狮子陷入惑的状态，迷惑的状态，我永远不上你的当，我永远不落单。

动物捕食猎物的程序：

+   1. 先冲过去让整个兽群和鸟群一下子陷入惊慌和散乱当中，
2. 以最短的时间识别孤独的个体。

![](bbox=[0.08, 0.00125, 0.92, 0.00158])

例子：狮子捕食羚羊

狮子在捕食羚羊的时候，它会花很长的时间在旁边观察，谁是其中的老弱病残者。我记得有个纪录片是这样说的，狮子是识别猎物品质的高手，它在静静地观察，它要选择那些最容易犯错的个体。一旦它识别这些个体，它就发动进攻，它发动进攻的直接目的不是去捕杀猎物，而是让那些个体的猎物犯错，一旦它们犯错，那将是它们一生犯的最后一个错误。

![](bbox=[0.08, 0.0020800000000000003, 0.92, 0.00242])

例子：鸷鹰捕猎

北美有一种猛禽叫鸷鹰，它捕杀猎物的时候也是采取这样一种方式，鸷鹰喜欢以鸽子为食，鸽子都是群飞的。据说它的飞行速度是鸟类里头最高的，但是即使是这么快的速度，它首先要做的是冲散这个鸽群，然后在这个鸽群里头寻找那些犯错误的个体。它们都没读过《道德经》，但是它们都懂得少则得，多则惑；而斑马没有读过《道德经》，它能反过来 xem，我永远不要在猎物的眼前显示为个体，永远保持是一个群体。

# 曾国藩的成长史

说到曾国藩，大家都会觉得他是儒家思想的典型的卫道士，其实曾国藩从一个自我评价智商中等偏下，每一次的考试侥幸过关居然做到后来官至一品的人，成为很多伟人和属绅都膜拜的偶像。在我看来，最重要的原因不是因为他尊崇了儒家的思想，而是他无意当中遵循了道家的思路。

曾国藩的成长史，其实就是一个做减法的历史。他做减法，不是在他的资源和能力上做减法，而是在他的视野和目标上做减法。

# | 天生恶疾

他生下来就浑身长疥，这种病一旦发作，有点生不如死的味道，挤出来浑身都在渗血，但关键是有地方你挤不着。每当难受的时候，他就蹲在那个装着盐水的水缸里头，用那个盐水蘸它，免得去挠了。基督教神学里头有一个分支学科叫疾病神学，说一个人的成圣之路往往是跟一种疾病相关的，我们从中国那些武侠小说里发现一个规律，好多有这种盖世武功的人往往是因为他的某个缺陷。比如说像花满楼那样的，因为他看不见，所以他的嗅觉，他的其他的感知能力非常的强。

曾国藩由于有这个病，他就远离了我们普通人很难远离的几样东西：

+   1. 不能喝酒；
2. 他是湖南人，甚至不能吃辣的，只能吃特别清淡的东西；
3. 最重要的是不能近女色，因为这个疥疮般的身体会把任何一个女孩子都吓走的。他官越做越大，但是应酬越来越少，应酬要出去就是要喝酒，就是要各种花天酒地，他是没办法去接触的。所以他的日程是非常简单的，也是非常固定的，日记一天不落。

他的家书一封都没缺，读曾国藩的家书的时候全读得起来，原因是他写完一封信，他还要抄一遍存档，他真的有那么多时间。这个减法就是大自然，老天给他的这个病，让他被迫做了一个大减法。

# | 人生中的急刹车

曾国藩这个人智商不高，情商也不高，他在跟人相处的时候很让人讨厌的，年轻的时候，比如说同朝为官，一起合作搞一个什么项目的时候，因为皇帝比较信任他，所以遇到一点什么事，他动不动就参上一本，有时候他能参到你立即完蛋，立即就削职为民，他有这个本事。很多人都不喜欢他，处处给他设障。
