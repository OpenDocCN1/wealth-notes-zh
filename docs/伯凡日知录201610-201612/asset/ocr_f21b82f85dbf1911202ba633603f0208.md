# 例子2：乐队拒绝音乐节的颁奖

摩登天空的创始人沈黎晖举了一个例子，说有一个音乐节要给某个乐队颁一个奖，结果那个乐队不去，再三央求，给奖人家不要，乐队是摩登天空的签约乐队，所以最后就好求到他的头上来了。乐队一开始跟他说：“关键是我们不会假唱，他们那个舞台是只适合假唱的舞台，第一我们拒绝假唱，第二支是他们那种设备也不行，播出来的假唱的声音也很差，所以我们就不去了。”

后来那边把设备搞到最好，完全可以做到不假唱的标准后，乐队才说出真实原因。

他说说：“我们说不想假唱只是一个借口，我们就觉得跟他们不是一路人。我们参加过他们的一次活动，结果他们把我们乐队的名称都报错了，我们几个傻乎乎地被他介绍为另外一个乐队的名称，站在台上一个个跟傻子似的，我们当时就发狠说再也不参加他们举办的音乐节了，也不领取他们颁发的任何奖。”
