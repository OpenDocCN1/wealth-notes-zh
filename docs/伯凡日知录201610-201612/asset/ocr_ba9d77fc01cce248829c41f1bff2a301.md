# 本周问答 | 每个人都可能变成混蛋

飞翔的小猪：怎么才能够提前预防混蛋进入团队、用先进的管理手段能杜绝吗，还是只能事后清除？

吴伯凡
混蛋就像细菌一样，像病菌一样，有时候是防不胜防的。没有一个混蛋的额头上他写着那两个字。有很多，甚至是一些招聘的高手，常常都会中招，遇到那种面试王，表现特别的好，进来以后你才慢慢发现有问题。尽管这样，还是有一些手段的，当有人要进到你的团队里头来，你要记住几个原则。

第一，雇佣性格，培养技能。千万不要因为他的技能特别好，你就什么都不顾了，你雇佣的是他的性格。我们经常会犯这样的错误，雇佣技能，培养性格，性格是没法培养的。很多公司搞很多的，天天在那喊口号，举举头，其实你是很难改变一个人的。千万别寄希望于你能够把一个混蛋改造成非混蛋，所以事先这根弦要绷紧。他是混蛋还是不是混蛋，他是一个混蛋还是一个好人。

第二，你可以做一些基本的测试，一般asshole的人，他在说话，办事上有一个特点，面对一件事情的时候，如果出问题了，他特别习惯于把问题推给别人。一个事情做成了，他特别乐意把成绩归功于自己，很多跨国公司他们有专门类似的问题进行诱导性的提问。就是有意地诱导你去说你的前同事的坏话，前领导的坏话。一般这个问题一旦提出出来，有的人眼睛就放光，就滔滔不绝，这样的人一般你要慎重。当然他如果不是一个面试王，他有太强的应试技巧，具有反侦查能力的那种人，只要不是那种人，他一般对这样的问题，他对于记人小过，发人阴私的事情，他不是太敏感，应该招这样的人，眼睛里比较少的看到别人的问题。

其实混蛋自己知道自己是混蛋的，有一句话说，最坏的人他也暗地里佩服好人。混蛋在公开场合从来不承认自己是混蛋，但是他自己心里头是清楚的。当一个人意识到自己有很多问题的时候，同时他又要尽力去掩盖的时候，他会有一个非常自然的心理倾向，就是在别人身上出现问题。当他在别人身上出现问题的时候，他有一种快感，就是他有一种释然的感觉。而且他的整个的思维不自觉地就变成一种意识雷达，去搜寻别人的问题。这不是他有意的，他的整个的思维习惯会容易形成这样一种模式，如果他对别人的问题特别敏感，对外在的环境特别挑剔的话，那证明他内心的问题是不小的。可以做这样的一些测试。

尽管我们可以做很多的防范，但是你很难彻底的过滤这种很糟糕的人进来。因为混蛋也是个动态性概念，他是在特定的场景下发作出来的。其实我们每个人身上可能都混蛋的成分，没有特定的场景，我们可能就没有发作出来。可以说混蛋这种东西就相当于一种心理上的癌细胞，他有的人这种癌细胞越来越多的时候，它聚集癌块。其实我们每个人都有癌细胞的，但是不是每个人都会得癌症的。

如果他进到一个公司来以后，他有某种场景会诱发他内心的那种癌细胞，心理癌细胞会发作。所以事先的防火墙要有，事后的病毒的查杀机制也是需要有的。

超哥：一个人从最初立下汗马功劳到关键时刻起到重要作用。但最后却变成了混蛋，这主要是个人原因还是公司原因？

吴伯凡
都有。前面我们说了，很多时候是特定的场景诱发了我们内心的那个巨大的负能量诱发了我们的心理上的那些癌细胞。

有一个问禅师的笑话是这样说的，说我我有老婆，我也有一个女朋友，女朋友对我特别的好，非常温柔，非常宽容，善解人意，怎么就使劲找缺点都找不到出来。我家里那个老母虎我的每一天的精神早餐和晚餐都是河东狮吼，她不骂人，不开口。面对这种情况我该不该跟她离婚，来娶我这个女朋友。禅师告诉他，说不要信任在野党。她这个在野的时候，她都是很好的，她一旦修成了正果，她以前对你的所有的好它都变成高利贷。

这就是典型，这是特定的场景导致的。比如说这个人没那么大功劳的时候，他还是一个很好的人，居功自傲。我们说能够居功不自傲，那是要很大的修为的，他确实是很有才能的人，确实也做出了很大的贡献，但是人总容易高估自己的付出，低估自己的回报。心里有怨气，开口成戈矛，就是出口，他的话就开始横着出来了，做事情开始横着做了。那他的混病毒就开始发作了。所以他有后天的原因，当然也有他个人的天性，甚至是有父母传导给他的基因，以及他在此之前，他的各方面的修养。
