# 本周问答｜规划派和进程派需要分不同场景来应用吗？

本周问答｜规划派和进程派...

我是奶爸2：规划派和进程派需要分不同场景来应用吗？还是任何一派都可以面对所有场景。

忘掉各个！：老师！是先定战略，然后在不断的迭代？还是在迭代过程中摸索战略？想听听您的高见！

吴伯凡

我给大家介绍了规划派和进程派，或者叫过程派，我觉得规划派主要适用于事后的总结，不能够做事前的指导。有一句话是用来否定那些喜欢做战略规划的专家们，说所谓战略不过就是一个好运气，但是过后你需要用各种思想的美图秀秀对他们进行包装，最后就总结出了一个事后才能够认识到的战略，然后把时间调换一下。当初某人就是高瞻远瞩，制定了一个伟大的战略，按照这个战略路径一步步走向了辉煌。

我自己倾向于任何战略都是一个进程，都是一个过程性的认知和进化，也可以说它是一种迭代的产品。当然这只是笼统的这样说，事实上我们在一个进程当中逐渐地认知战略、确定战略的过程，其实开始就包含着某种规划的成分，或者说包含着某种猜想的成分。我们不可能在毫无规划、毫无设想的情况下就起步，只不过这样的猜想、这样的规划，它只是一个起点。

法国哲学家帕斯卡尔说，思想就像河流，是一条流动的道路，不是我们踏上它，而是我们在河流上，它会把我们带到我们觉得未知，其实又是我们希望想到地方。所以在这个意义上，道路到底是你走出来的，还是你在一 alleen流动的，像河流一样的道路上，它把你带到那去的呢？在我看来两者都有，一旦你踏上了一条你认定的道路，你就在相当程度上身不由己了，你在这条道路上随机应变，最终出乎意料又在意中达到你的目标。

说到这里我想给大家介绍一个概念，这个概念简称OODA循环，这本来是美国空军的一个中校，他发明的一种训练方法。这个中校很传奇，他是在美国空军里专门训练飞行员的，他有一个很神奇的地方就在于，每次他和他的学生在实际的演练当中，他都把自己放在一个不利的位置，让自己的学生处于一个有利的位置。在空战当中不利的位置就是你处于对方的前方略低的地方，这个是非常容易遭受打击的，所以作战的过程当中一定要避免自己进入到一个死亡区。他在带学生训练的过程当中，他首先让自己处于一个不利的，非常容易受到攻击的位置，但是经过40秒之后他又回到了有利的位置，而他的学生不知不觉地又处于极易受到攻击的位置。这些学生们大惑不解，他是怎么做到的，40秒钟的时间他就像一个魔术师一样，让自己的位置从不利变得有利，而反过来让我们从有利的位置不知不觉地到了一个非常危险的位置。后来他告诉他的学生，他用的是他根据长期的经验总结成的一套方法，这个方法就叫OODA循环。

第一个O就是Observation，就是观察，就要看你在什么位置，对方在什么位置，也就是为了达到知己知彼的目的你要观察。

第二个O是Orientation，定位，就是在这这种态势下，你应该到一个什么位置，同时要让对手处于一个什么位置，你要想什么办法把对方不知不觉遇到那个你希望的位置上去，这叫Orientation。

第三个字母D就是Decision，决策，当你在观察定位之后马上做出一个决策，我是用什么样的方法，用强攻的方法、用火力侦察的方法，用什么样的招逐渐地让他就范。这个决策一旦做出，接下来就是第四个步骤，A就是Action，就要采取行动。

这是分解起来是四个阶段，但是这四个阶段要尽可能的短。事实上他总是把40秒钟的时间分成四段，每一段是10秒钟，也就是说在10秒钟之内他要完成OODA这样一个过程，当10秒钟过后进入下一个10秒的时候，通过行动进一步观察到你的意图、你的偏好、你的优点和缺点，也就是说这个循环本身又变成了一个观察，又开始了第二个循环，OODA，然后在第三个10秒之内再循环一次，到第四个10秒的时候，通过他的OODA循环就把你逼到一个死角里头去。而他的学员在40秒钟的时间经常是根本没有完成第一个循环、甚至有的人还一直是处于观察阶段，还只是停留在第一个O，连第二个O都没有能实现，那就更谈不上决策和行动。所以这里头这个OODA循环其实就是一个快速迭代的过程。我们的行为其实都是从观察到行动，但是这个周期一定要短，通过从观察到行动的过程变成又一次观察的起点，这样他就在最短的时间内完成了四个循环。

用我们前面说到的概念就是他赚到了更多的认知，就像我们做企业的时候，我们不仅要追求利润额和利润率，而且要追求周期循环的次数。如果说一个产品的利润只有2%，但是你是一个月循环一次的话，你就能够赚到很多钱，有的人好像利润是10%，但是他需要一年来循环的话，他挣的钱远远没有你的多，所以我们用OODA这个循环，我们可以挣到更多的认知。

OODA循环可以说是一个典型的迭代的过程，在某种程度上他是在规划，他事先对你有一个初步的设想，但是他不把这种设想作为他行动的唯一指南，他要开始对你的观察、定位、决策、行动，在行动当中进一步地观察你。所以他既是过程派，也是规划派，这两者交织在一起就是一个有效战略的形成和实施过程。所以借用我们前面的话说，战略其实也具有波粒二象性，如果你从规划的角度来说，他的的确确有规划的成分，但是他本质上是一个在进程当中逐渐找到，或者说是在进程的过程中不断地观察、规划，用行动去证实和证伪自己的设想，从而迅速地调整自己的策略。

所以在一个真实的场景当中，不可能通过纯粹的规划来解决问题，也不可能通过纯粹的随机应变，没有方向的，像开卡丁车一样的碰来碰去来实现一个战略的。这个问题我们就回答到这里。
