# 例子1：出租车与杂货店

出租车这个行业，原来是金饭碗，永远不愁没生意，永远是卖方市场。但是半路上杀出个互联网。原来很好做的生意不知道怎么就不好做了。

开杂货店的朋友，你会突然也一天发现，以前一直在光顾你的那些恩客们，就逐渐的是很漠然的走过你的店门口，看都不看你一眼。

我们今天的商业环境不止熊猫型企业要遭遇颠覆性创新，任何行业都有可能遭遇颠覆性创新。

哪怕企业一直是在很竞争性的环境里生存，只要竞争的背后的操作系统改变了，生态系统改变了，那我们赖以生存的根基也就没有了。尤其是对于那些一直活得很好的企业来说，大家记住两句话：

一切福音都是诅咒。
