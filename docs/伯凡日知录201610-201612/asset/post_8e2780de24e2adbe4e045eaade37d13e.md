本周我们谈的话题与星巴克有关。

关于星巴克，太多的人聊了太多太多，连我本人以前也聊过星巴克。

前不久我去了一趟西雅图，大家知道西雅图是星巴克的总部，这个城市让我觉得特别有意思，在某种程度上说它比硅谷更有意思。

中国的创业者们如果要到美国去朝圣，除了去硅谷，也应该去一趟西雅图。这是一个有点奇怪的城市，它处在美国的边缘，在美国的西北角，已经临近加拿大，但是在这个看似边缘的城市里头竟然出现了好多的商业巨头。

这些商业巨头有一个特点，那就是他们都在自己所处的行业拥有垄断优势。

这些公司的名字是大家耳熟能详的，微软、波音、亚马逊、星巴克。

本周我就以星巴克作为一个案例、作为一个引子，谈一些与创业有关的话题。

为什么星巴克在一个看起来已经完全饱和的咖啡市场上，竟然能够开辟出一个全新的市场？

在此之前从事咖啡产业的，要不就是开一家和几家咖啡店，要不就去制造速溶咖啡，但是没有人想到开咖啡店也能够像雀巢咖啡那样，成为一家全球的巨头。

讲星巴克案例的时候，我们免不了会提到以下这些关键词：边缘、异类、密谋、封闭，这些词合到一起会让我们想到一个词，这个词是星巴克创业、成长以及其独特的文化和产品体验的DNA。

这个词是什么呢？

# —— 知识笔记 ——

西雅图是一个特别神奇的城市，身处美国是一个边缘城市，在美国的西北角，接近加拿大，城市氛围像加拿大一样安静、闲适，但在这么一个很安静的城市里却出现这么多的商业巨头。

以西雅图为基地的公司，我们知道的都是大家伙，这几个公司都有一个特点——垄断，它能够在一个行业里头占到非常大的市场份额。

+   波音
微软
亚马逊
星巴克

亚马逊，美国互联网的四巨头，而且我相信它很快能成为全球市值最大的互联网公司，它的总部是在西雅图这么一个安静的地方。

# 星巴克的生存之道

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_82_1.png)

星巴克第一家店是1971年成立的，原来是一个卖咖啡豆的店，很有趣的是我发现与星巴克的第一家店相隔有几个铺位的也有一个店，我看见那门口写着一个牌子，创立于1975年，比星巴克晚了四年，那个店是卖酒、也卖咖啡豆这么一家店。现在，旁边这家店，还是一家小店。而星巴克已经在40多年的时间里，成为全球最大的咖啡连锁店。

与咖啡有关的生意的三种业态：

+   1. 速溶咖啡，可以批量生产，可以触到每一个零售网点，加上品牌的号召力，你就可能成为一个全球化的公司，就像雀巢这样的公司。
2. 开单店或者开一些连锁店，这个在美国早就有了。
3. 卖咖啡豆，相对数量比较少的，但是我们一直在存在

关于咖啡你能想到的业态也就是这三种，而星巴克它居然做成了一个全球化的公司，甚至有人把有没有星巴克作为这个城市是否现代化、是否国际化的一个标准。

# 星巴克的三个关键词：

+   1. 边缘

凯文·凯利在他的《失控》里提到了一个，我把它称为K九条的东西，创新九律。

其中一律就是边缘创新——专家不看好，律师看不懂，但是在你接触的人群当中发现有一股暗流好像对这个东西很感兴趣，但是大多数人是没有看到的。你只有主动地置身于这样肥沃的、充满机会的边缘，你才可能做出真正的创新，你才可能获得一个高的成长。

每个动物都是起源于一个细胞、一个受精卵细胞，从一个细胞变成一个生命体，中间的机制就是裂变，1变2、2变4、4变8，一直到512、1024，关键就是裂变机制。星巴克那么一家小店，那么一个细胞居然最后变成了一个巨无霸。

《圣经》里耶稣说要走窄门，不要走宽门，宽门上人多必致死亡，你们要走窄门，可是走窄门也是死亡。

选择第一条路，做速溶咖啡，看似可以做大，已经成大气候的这些巨头已经把你的路牢牢地堵死，因为你的品牌、你的运营能力完全没有可比性。

选择第二条路，自甘你做一个小而美的、快乐的、安静的一个小店，那就意味着你永远是在一个少有人光顾的角落里做着养活自己的生意。就像是星巴克旁边的那家不知名的小店，从1975年开到现在，绝大多数的创业企业除了死掉之外，最好的结局就是能够做到几十年不倒，那已经是不错的结局了。

+   2. 异类

二者之间似乎没有第三条路可走，但星巴克找到了一条路。

你要成为异类，你要做咖啡店，你卖咖啡豆，想全球扩展，你跟他们有什么不一样？

用彼得·蒂尔的话说，如果你说不出来你到底有什么不一样，那答案只有一个，那你就是0，永远是0，你没办法完成从0到1的突变。有了这个1，也就是那个细胞，你才可能发育成一个生命体，这个从0到1的机制就是异类。

# 星巴克的logo

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_82_2.png)

我们通常说星巴克的创始人叫舒尔茨，他不是那家店的创始人，那是1984年才加入星巴克，但是的确是他缔造了星巴克。星巴克的logo演变过程中核心的东西一直没变，就是那个海妖的图，这个海妖叫塞壬，希腊神话当中的塞壬王。

塞壬的歌声，只要她一唱歌，水手们就会被她的歌声所迷倒，自愿去把自己送上去让她当早餐和晚餐吃掉。

这个店的创始人从他开业的第一天他有一个理想，就是我的这家店要像海妖一样具有不可抗拒的魔力。当星巴克选择塞壬作为自己logo核心要表的时候，就意味着它对咖啡有了重新定义。

# 对咖啡的重新定义

｜ 产品定位

咖啡在西方人的生活当中就是一个日常的饮品，不管是速溶咖啡、路过这家店去喝一杯咖啡、买咖啡豆，都是一种日常消费。

星巴克它要赋予咖啡一种日常的特性，这个特性就是与咖啡有关的“瘾头”，让消费者对它有一种成瘾性的依赖，而且是不二选择，一旦你选择了它你就很难切换到别的上面，因为别的咖啡的味道里头缺少一种味道，而只有星巴克能够在咖啡里头加上这种味道。

｜ 两种茶

“柴、米、油、盐、酱、醋、茶”的茶；
“琴、棋、书、画、诗、酒、茶”的茶。

两种茶的差别就在于前者无道，后者有道。

茶有道，君子不喝无道之茶。

星巴克要把咖啡赋予一种道，咖啡之道。有了这种道，它就会对某一类人群形成一种强烈的不可抗拒的魔力，就像水手对于海妖塞壬没有拒绝的能力一样。

# | 用户定位

星巴克对它的核心人群有一个定义，就是不是那种随随便便轻慢喝咖啡的人，而是爱咖啡、懂咖啡、知道咖啡最细微的味道，所以他离不开咖啡的那样一种人。

基于这些诉求，他们就要为这个店取一个名字。

美国有一部小说叫《白鲸记》，美国的伟大作家海明威认为他是美国最伟大的小说家——麦尔维尔的一部小说。那里头有一个大副，我们说每遇大事有静气，他是每遇大事喝咖啡，他遇到特别危险、特别复杂问题的时候，他会在甲板上静静地喝一杯咖啡，然后站起来——“主意有了”。

这个大副的名字叫Starbuck，喝这个咖啡的人叫Starbucks。

只有这样一类人才配得上喝我的咖啡，我不是针对所有人的。

他的异类就在于它不是像雀巢咖啡，像那些街上随处可见的那种咖啡店一样争取每一个可能上门的顾客，而是只针对那些懂咖啡的人。

这些人相当于咖啡的发烧友，这些人至少有两个特点：第一是狂热，第二是真懂。这就是星巴克从一开始他们要做出一杯不一样的咖啡出来，他要做一件现有的与咖啡有关的企业做的事情都不一样的事。

星巴克早起的用户有一种带有强烈的优越感的异类，我干的这件事，我消费的这件产品意味着我跟你们不一样。

这个词是来自于基督教和犹太教，选民，上帝的选民，上帝只拣选了这一群人，这些人跟上帝之间有一个盟约关系，所以基督教的《圣经》叫旧约和新约，旧的盟约和新的盟约，它是有一种秘密约定的状态。这样的人在面对所有人的时候，他们有一种独特的优越感，甚至当他们很倒霉、很受挫败、受到打击的时候，他们都觉得你们不配，只有我配，“被追逼的人有福了”，我之所以被追逼，是因为上帝拣选了我。这里头就是一种强烈的有优越感的异类意识。

# 3. 密谋

在星巴克看来，他们的员工一定是深刻地认同公司这样一个主张，就是做不一样让人发狂的咖啡。换句话说他们在密谋一件事情，走到一起来搞事情的人。

他们的员工不叫员工，叫伙伴。

星巴克内部的文化说点难听一点，有点像传销组织，虽然它不是在做传销，但是它的员工之间的关系、公司的氛围有点像传销组织内部那样一种准宗教式的状态。

# 例子：员工评分奖金

有一个员工中了彩票，他非常自然地把他中的这个彩票跟全店所有的伙伴分享平分，这样的事情没有宗教性的狂热，你是很难做到的，他们对自己的使命以及跟这个组织之间的关系，有一种教徒跟教会之间的关系。

由一群准宗教式的人做一种可以把其称为咖啡宗教的事情，它不是在已有的市场蛋糕里头切下一块，而是做一个新的蛋糕，这个新的蛋糕就是一群在人群当中跟别人不一样的人。

它不是在争市场份额，而是在争钱包份额，就是说我不是要增加更多的人来我这儿，而是要争取一个来我这儿多次，最多一个月来18次这样的人。

一般的做 法是增加17个人，它不是，它要增加一个人来18次。

# —— 知识笔记 ——

当我们提到边缘、异类、密谋、封闭的时候，就会想到一个词，这个词就是黑帮。

彼得·蒂尔在他的《从0到1》这本书里讲到了创业与黑帮文化之间的关系，这个词也开始流行起来。其实我们说的黑帮，黑帮文化，我们也只是在比喻的意义上、引申的意义上使用黑帮这个词。

黑帮首先他当然是封闭的，他不可能把他要干的事情跟所有人说，参加黑帮的人，他一定属于社会的边缘人群，他们干的事情一定是很异类的，同时他们都是悄无声息地搞事情。

在人类文明史上有 一个民族是很符合这几个特点的，边缘、异类、密谋、封闭，这就是犹太民族。

# 黑帮博物馆

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_84_2.png)

这个博物馆也就是拉斯维加斯的历史博物馆，一个因黑帮而诞生的城市。

最早的这个黑帮我发现它的名字发音后面都带“o”的，那个名字让你都想起阿尔·帕西诺，演教父的那个人，带这种名字最多的是意大利人。

意大利人到美国来，就意味着他们是异类，因为美国是新教徒的地盘，而意大利是天主教的大本营。在美国一直到现在，WASP的传统一直存在。

| WASP

White Anglo-Saxon Protestant的简称，白人、盎格鲁撒克逊、新教徒，WASP价值观是美国的上流社会主流价值观。

在这些主流的WASP眼里头他们就是边缘的、就是异类的，也找不到正经的工作，所以他们就像小强一样总是在阴暗的角落里头谋生存。哪是主流人群不愿意去的地方，最苦的地方、最脏的地方也就是他们生存的地方。

想起意大利我们就会想到黑手党，就想起美国那些黑帮老大，黑帮一定是在主流和精英不愿意去的那些地方滋生起来，哪怕是在一个很主流的城市。比如说芝加哥是一个主流城市，但是芝加哥也有边缘的地方，那些地方就有黑帮。

# 犹太名族

犹太民族，首先他人数很少，第二他历史非常悠久，一直在受迫害、受打压，甚至遭受毁灭性的打压，但是他们都能够生存下来，他们具有像小强一样的生命力。

在欧洲的历史上反犹是个传统，原因有多种多样，基督徒认为是他们把耶稣杀了，所以主流人群就不喜欢他们，他们没有自己的国家，他们到处流窜，为很多国家制定了法律不允许他们拥有土地，犹太人是没有土地的。这本来是一个诅咒，传统社会没有土地也就没有财富，但是犹太人恰恰是在没有土地的情况下创造财富，那就是经商，尤其是从事金融业。

# 拉斯维加斯的历史

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_84_3.png)

处在边缘位置，美国的内华达州在地图上 一看就是一片沙漠，沙漠里是不可能有财富的，也就是说摆在他们面前的就是三个字——不可能，创业其实就是将不可能变成可能。在拉斯维加斯这一片沙漠里头，它居然开出了财富之花。

在既无天时又无地利，也无人和的地方，你突然发现这个地方有另外一种天时、另外一种地利、另外一种人和。

+   1. 意大利人来到这里，这个地方突然通铁路了。
+   2. 在离拉斯维加斯不远的地方出现了一个大工程，那就是著名的胡佛大坝，修胡佛大坝需要大量的青壮年劳动力，胡佛大坝的建造过程也就是拉斯维加斯这座城市的建造过程。
+   3. 大量男性劳动力涌向这个地方，他们首先是挣到了钱，同时他们身上还有没有发泄完的力比多，这个力比多发现在最常见的两种方式，一个是黄，另一个是赌。
+   4. 有钱人都爱去古巴找天上人间，但卡斯特罗发动古巴革命，一下子把这些腐朽的、肮脏的东西，一夜之间给铲除掉。美国的富人们没地方可去了，只好到拉斯维加斯这个地方来，对拉斯维加斯又是一次推动。

# ｜反脆弱

反脆弱就是说一个生命体、一个组织，在他不断受到打击的时候，他并不会衰亡，反而会越来越强大。

在犹太人历史里头我们看到了同样的故事，上帝为你关上一扇门，就会为你打开一扇窗，这是创业者，也就是说揍身或者被迫进入到一种绝境的人才会体会到的一种境界，别有洞天、别开生面的境界。

强大的生命力常常是跟外界加给你的压力相关的，不把你逼到绝境，你就不可能体会到什么叫绝处逢生。

# 星巴克与黑帮

星巴克做咖啡其实是一种自我放逐、自我迫害，是带有某种自虐的性质，他不去做那种速溶咖啡、不开家咖啡店，非得做一件这个行业以前根本没有过的事情，也就是一个从0到1的事情。这就是黑帮的特点，黑帮干的是一件外界不容许他做的事情，他做事的时候处处是障碍，而且是明摆着的障碍。如果你是一个悲观主义者，你不可能去干黑帮的事情，因为这件事情本身就是一个不可能的使命，就是一个不可能完成的任务。

在脆弱和强韧之间，他被迫找到了第三条道路，就是越是被迫害、越是被追逼就越是强大。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_85_0.png)

上宗教课的时候，老师问你怎么看犹大？

这个吊儿郎当的学生歪着头顺嘴说了一句还行。

老师一下子气坏了，你既然说犹大还行。那你说说为什么他还行？他这时候突然灵机一动说，没有犹大耶稣就不会被抓住，就不会被送上十字架，没有十字架基督教就不存在，连logo都没有，所以我觉得犹大还行。

# 这段话里头包含了某种真理——

+   1. 基督教影响了人类两千多年历史，对他做出最大贡献的竟然都是他的敌人，就是罗马总督彼拉多，然后是犹大，正是这些人使得基督教才成为基督教。
+   2. 在后来的历史当中，基督教一直是在迫害中成长，罗马一直迫害基督教300年，但最后不仅把他们消灭掉，反而最终他们实现了逆袭，成为了罗马的国教，然后向全世界蔓延。

这些组织他能够迅速地将某种负能量转化为对他们生长的正能量，所以有人说在宗教里头有一个逻辑炸弹，就是你不迫害他、不打击他，他就慢慢慢慢地消失，但是你只要一打击他，他就会强大。我们看宗教史上的的确确存在着这种现象。

一个处于边缘，并且有强烈的优越感、使命感的异类人群当中是很容易滋生一种创业激情的，这是普通的创业团队很难具备的一种生长机制。

星巴克不是黑帮，他没有受到谁的打击，但是他是一个自我设限的公司，他给自己设置了很多很多的障碍和边界。比如说普通公司总是希望自己客户越多越好，他要争取的是那些异类人群，争取那些把咖啡当成是一种发烧行为的人群。

星巴克不走宽门，去走窄门。不走宽门，不走人人都知道应该走的那条路，甚至不走少有人走的路，他走没有人走的路。这是在咖啡这个行业里头居然能够走出来，从一家小店变成一个庞大跨国公司一个很重要的原因。

# 星巴克发现的全新路径

喝咖啡绝不仅仅是一种味觉体验，它包含着嗅觉，甚至是视觉和听觉。星巴克营造的这种体验用通信学的术语来说就是多信道全息化体验，它是多信道的，它是触及到各个感官的。

烘焙咖啡豆的时候，那种声音对于咖啡发烧友来说具有一种强烈的诱惑。

磨咖啡豆的时候，散发出来的气味，也成为咖啡体验的一部分。

喝咖啡的时候你常常会想到一些事情，想到以前喝咖啡的时光，所以星巴克把光线、把音乐放进咖啡店里。

# 羊群效应

星巴克在成长的过程当中，还发现了这个行业以前从来没有人体会到的一种效应，羊群效应。就是当少数人津津有味、如痴如醉地去消费一种东西的时候，首先会引发其他人的好奇，其他人会对他们产生一种艳羡，一种充满着好奇，想尝试一下的那种羡慕之感。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_86_1.png)

例子：汤姆·索亚刷篱笆

汤姆·索亚因为调皮，姨妈为了惩罚他，让他在星期天把他们家的木篱笆全部刷上油漆，一般的小孩认为这是件苦差事，一定会唉声叹气，百般不愿意。但深谙人心的汤姆·索亚他不这么干，他认真真地刷那个篱笆。

那些小孩刚开始是嘲笑他的，“我们星期天可以自由地玩耍，而你被迫在那劳动改造。”他好像完全听不到这些小孩在说什么，认真真在那刷，刷完以后还退几步看一看，再上去再补两下。

当他这样无比投入地做这件事情的时候，其他小孩的想法就开始变了，“这里头一定有我们不知道的某种乐趣。”然后就求他让他们也刷两下。他完全置之不理，继续在刷他的木篱笆。

后来聚集的小孩越来越多，都觉得这是一件不可思议的事情，都想去尝试一把。最后汤姆·索亚让他们用玩具、吃的东西来交换刷篱笆的权利，而且每个人只能刷一点点。

那些小孩都回去把自己的玩具和吃的东西都拿来给他，轮流排着队，轮流在那刷，帮他把那个活干完了。他自己就坐在大树底下静静地吃着水果，玩着他们的玩具，看见他们在那帮他干活。

![](img/bc3c2bdeca06cc5ba1cdbd464e67d8e2_86_2.png)

马克吐温说：“当一个事情摆在你面前要求你必须干的时候，那叫苦差”，比如说在烈日炎炎之下让你去干农活，你肯定是不愿意的，但是你总能看见在烈日炎炎下打球的、跑步的、登山的人，因为他们干这样一件事情，首先他觉得我是跟你们不一样的。其次他们都有一种隐秘的受虐的快感，因为他觉得自己跟普通人不一样，所以他受到的折磨、苦痛也是一种特权。这样一种特权感会像毒气一样扩散，让其他人着迷。

星巴克后来的爆炸式增长，跟核心人群的痴迷引发的吃瓜群众大量地涌进有很大的关系。这也是如果你不去尝试第一步，后面的那种别开生面的景象你是不可能看到的。

所以禁忌、封闭、密谋、高门槛反而成为一种巨大的诱惑，禁忌即诱惑，欲擒故纵。星巴克用这样一种边缘、异类、密谋、封闭的方式造就了一个大市场。所以在这个意义上说，星巴克的成功也是一种黑帮文化的成功。

# 打造产品的魅力

几年前我写过一篇文字叫《产品六度》，说的就是卓越产品打造的六个阶梯。里面写到了一点，真正高明产品经理和营销经理会通过有意制造障碍来增加他产品的魅力。

罗马有一句谚语叫“禁果分外香”。禁忌在很多时候就是诱惑，你要让你的产品产生一种魔力，像海妖似的魔力，让客户产生一种飞蛾扑火的冲动，你就必须要制造某种障碍，或者说让客户有某种自卑形移的感觉，觉得自己不配，越不配越迷恋。

中国的好多企业是不太注意这一点的，在美国这样的事情比比皆是。

苹果，它常常是通过制造某种障碍，有意地排斥某些人，有意地给你制造一种不方便，同时让那些圈内人，让那些已经在使用这个产品的人产生某种优越感，让这些人看着那些麻瓜，看着这些吃瓜群众。就像木心说的那句话，“我悲哀地看着你们这些不知道悲哀的人们”，这种“逍民意识”实际上是一种市场和营销的催化剂。
