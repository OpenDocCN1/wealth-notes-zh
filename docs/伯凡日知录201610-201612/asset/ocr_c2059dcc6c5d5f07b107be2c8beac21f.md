# 本能是什么？

+   1. 本能是预装在我们身体里的一套功能系统

小孩，生下来就懂得吃奶。

小狼，天生会朝狼窝爬，往高处爬。

+   2. 本能是一种自动化的模块，意识自动化的反应

![](bbox=[0.03, 1.05, 0.88, 1.5])

例子1：

现在，当你看见几个人快速地从你身边跑过去，你会想跟着跑，再多几个人，你就马上就跟着跑。

因为，人类早期在渔猎时代，一个人快速奔跑意味着被野兽追击，如果不跟着跑就会被野兽吃掉。只有那些跟着跑的人，才能幸存。

+   3. 本能相当于基础设施，可以让我们少走弯路

有句话叫：“不要重新发明轮子”。在做新的创新时，利用已经有的技术模块和创新模块，更有可能获得高收益、低成本的创新。

# 本能在管理中的运用

+   1. 重视本能的力量——无论是在管理自己还是在管理别人，不要跟本能作对

![](bbox=[0.03, 2.6, 0.88, 3.0])

例子1：青蛙背蝇子的故事

蝇子去找青蛙商量，说你把我背到对岸去。青蛙怕被蝇子蛰，不干。那个蝇子答应绝不蛰青蛙。因为青蛙一死蝇子也会被淹死。

青蛙一听，觉得很有道理，就答应了。

结果游到了河的中间，蝇子还是蛰了它。

思考：为什么蝇子还是会蛰青蛙？

+   2. 利用本能的力量——在特定的场景发挥巨大的潜能

![](bbox=[0.03, 3.85, 0.92, 4.35])

例子1：破釜沉舟

部队渡过一条河去进攻，到了对岸以后，把做饭的锅砸了，把船也砸了，没有退路。

就是利用人在极端危险的情况下，调用你所有的能量，战胜对手，在一个险恶的场景里胜出。

![](bbox=[0.04, 5.05, 0.97, 5.7])

例子2：“李广射虎”

李广在夜里，他看见前面趴着一头大老虎，危机之下，拔出箭来就射过去，结果发现不是老虎，是一个石头，但箭已经射到石头里了。到了白天的时候，他想拔出箭来再次射，怎么都射不进去了。

因为在那种危机的情况下，他调用了巨大的潜能，一旦认识到没有危险，就调用不了这个潜能了。
