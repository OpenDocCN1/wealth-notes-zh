# 怎样管理自己的本能？

![](bbox=[0.07, 0.33, 0.12, 0.36])

怎样管理自己的本能？

# —— 知识笔记 ——

我们要管理一个东西，要看清它是什么样子，最好是能够测量它。

管理自我，要把你自我里的某个东西拿出来，抽身出来看着它，你才可能管理它。

![](bbox=[0.15, 0.85, 0.85, 0.95])

格林斯潘的红颜教母安-兰德：

当你说“ 我爱你 ”的时候，你要明白你有我吗？只有有“我”的人才有权利说爱别人。

如果你只是被本能驱使，你可能你不是“我”，你是随便一个人。

管理本能的方法：

+   1. 意识到它的存在，要有预见性
2. 本能还没有被激活前，动用理性做决策
3. 采取措施，把本能关进笼子里

![](bbox=[0.18, 0.0017800000000000001, 0.78, 0.00195])

例子1：发脾气的“妈妈”不是“妈妈”

我有一个朋友，她知道自己脾气大，于是她对她的孩子说：

> “妈妈在对你发脾气，在骂你的时候，妈妈已经不是妈妈了。这个时候你要记住一句话，当我对你发脾气的时候，你就不断地说‘妈妈，我爱你’，这时候真正的妈妈就回来了。”

![](bbox=[0.04, 0.0025800000000000003, 0.96, 0.00285])

例子2：尤利西斯与塞王

尤利西斯的船队必须要经过两个岛，其中一个会在海水涨潮时形成巨大的漩涡，船很容易被卷进去，船毁人亡。

另一个岛，有一批长得非常的漂亮，歌声极其迷人的海妖，叫塞王，男人們一旦听到这种歌就会情不自禁地登上那个岛，人一上去，它们就把人给抓住然后吃掉。

尤利西斯命令自己的船员把他绑在桅杆上，叮嘱船员经过两个岛时，他说的任何话都不要听。尽可能远离带漩涡的那个岛，一直往前走，直到听不到歌声，再把他放下来。

![](bbox=[0.04, 0.00373, 0.96, 0.004])

例子3：王戎识李

王戎和小伙伴们看到路边一棵长满了李子的李子树，其他小伙伴马上跑去摘李子。他非常淡定的站在那儿。大人问他：“你为什么不去摘李子？”他说：“这棵树长在大路边，有那么多李子，如果李子要是好吃的话，肯定早就没有了，既然有那么多李子还在树上，那一定是很難吃的，所以我不去摘。”

果然，摘下来的李子又酸又涩，大人都夸王戎聪明。

在股票市场上，稀缺的不是技巧而是心法。

要避免自己站到那90%的人群当中，而是站到那10%的，5%的人中。

![](bbox=[0.15, 0.00525, 0.85, 0.00555])

没有本能，我们在日常生活中根本没办法趋利避害。

但“任何福音都是诅咒”——

本能是最好的东西，如果我们懂得如何去对待它，如何去运用它。

本能又是 最坏的东西，如果我们不能够认清它的面部，我们盲目地受它的驱使。
