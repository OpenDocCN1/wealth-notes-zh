# 管理学的两种风格

直接派：直接直奔问题而去，单刀直入解决
问题。

间接派：又叫体系派，通过系统化的努力，多个要素的叠加，从而解决问题。

两派具体怎么做事：面对小贩来抢食堂的生意

俞敏洪（体系派）：改进质量、降价、教育、恐吓

俞敏洪妈妈（直接派）：把栅栏变成墙

![](bbox=[0.07, 0.67, 0.99, 0.8])

例子1：看到星空你想到什么

有一天晚上福尔摩斯带着华生刃郊外去宿营，福尔摩斯就把华生给推醒了。

福尔摩斯：“你现在看到了什么？”

华生：“我现在看到了星空。”

福尔摩斯：“那意味着什么？”

华生：“从神学上看这个星空代表着上帝创造宇宙的构思是如何宏大；从哲学上看那就是宇宙是如此浩翰，又是如此有序；从文学上看那一颗颗星辰都代表着一个个的神，满天其实都是诸神。”

福尔摩斯实在受不了了，“你这个笨蛋，我们的帐篷被别人偷了。”【思考】：为什么华生会想到上帝和宇宙？

# 排名第一的管理理念——No Asshole（不要混蛋）

什么是“混蛋”？

混蛋就是公司中的搅局者

![](bbox=[0.07, 0.8, 0.99, 0.92])

例子1：地毯下的蛇

地毯下有一条蛇，一块新地毯，怎么也铺不平。

如果你不知道地毯底下有一条蛇，不把它清除出去的话，一切努力都是白费。

说明有了Asshole，事情总是搞不定。创业团队中有了Asshole，而你不知道或者害怕把它清除出去的话，你这个创业项目差不多也就失败了一半。

吴伯凡

No Asshole 是管理学中的第一原则，如果把它忘了，你做的一切努力也就
不重要了。
