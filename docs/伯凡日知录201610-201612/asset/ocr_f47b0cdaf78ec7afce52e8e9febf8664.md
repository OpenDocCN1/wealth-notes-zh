> “路漫漫兮其修远兮，吾将上下而求索。”

一般作文到结尾的时候，大家喜欢加上这么一句，显得很有文化，又很励志的样子。前不久我才发现，我对这句话是个误解——

以前我一直以为：这个路漫长，那么我还是要坚定不移地沿着这条路走下去。

其实不是这样的，我突然明白屈原要说的它是个升维，说这个路是修远，很长很长，但是我不想去走，我不想沿着这条路一直走下去，我要上下而求索，那是另外一个维度了。

# | 上下求索跟线性的移动不一样

白居易的《长恨歌》里头就有一句话，叫“上穷碧落下黄泉，两处茫茫皆不见。”

地面上已经找不到杨贵妃了，就到天上去找，然后到地下。

古人认为地下还有一个世界叫“黄泉”，这就是一个升维了。就是当我在一个二维的、二次元的世界里头找不到的时候，我要到一个三次元的世界、三维的世界去找。

屈原的这句名言，我们就可以把它理解为，我们如何去升维，当你在一件事情上非常的努力，但是始终没有结果，整天在渴望着干货，无数的干货都让你一次次的惊喜，又一次次的失望的时候，我们是不是该想一想，我们是不是跟驴子和蚂蚁一样了，我们能不能像屈原那样，在路漫漫兮其修远兮的情况下增加一个维度，上下这个维度，上下求索。

例子：小偷在哪里

我们在电影里头时不时会看到这样的情节，一个主人怀疑自己的屋子里头进来了小偷或者隔壁老王，他就会到处找，首先找衣柜，然后找床底下，到处找，还是没找着，又很失望、又很庆幸地坐在沙发上，以为这事儿就结束了，然后关上门离开。一个镜头小偷在屋顶上，梁上君子就是这样来的，就是梁上君子藏在房顶上。在我看来这个主人之所以蠢，就是因为他不会升维，他在二次元的世界里头找答案、找结果，但是他不能够上下求索，把头抬起来其实这个答案就找到了。

# 做学问、做事业的三境界

+   一、立目标的阶段，踌躇满志，“昨夜西风凋碧树，独上高楼，望断天涯路。”

+   二、求索的过程，“衣带渐宽终不悔，为伊消得人憔悴。”想成名成家的人都会经历这样一个阶段，但是有很多人最终未遂，原因就是他只是在一个低维的世界里头消得人憔悴。

+   三、众里寻他千百度，蓦然回首那人却在灯火阑珊处。百度公司的名称就是从这儿来的。

搜索其实还是一个二维搜索，众里寻他千百度，不一定是蓦然回首，在同一个维度蓦然回首就能看见的，有时候抬头看一下或者低头看一下，你可能发现这个答案和方案就在你最忽视的地方，你之所以找不到它，是因为你沉迷在一个低维度。
