# —— 知识笔记 ——

大熊猫，我们叫熊猫，在我们中国的台湾地区不把它叫熊猫，叫猫熊。其实叫猫熊这个名字更准确，因为大熊猫本质上是熊。

要了解大熊猫的话，就要了解它本来的出生，也就是熊。

# 熊的几个特点

![](bbox=[0.06, 0.9, 0.95, 0.98])

1.喜欢待在高纬度地区

北极熊生活在冰天雪地的北极，北美灰熊生活在加拿大高纬度地区。

2.体型很大

动物的体型大有一个好处，就是谁都不敢惹它，这是好处。坏处是因为它体型大，它必须摄取大量的能量，它才能活下来。所以一般的动物，它的体型足够大的时候，它就自动地降纬生存。

![](bbox=[0.06, 0.0015, 0.95, 0.00165])

降维生存：

处在食物链高端的动物，在食物链的低端生活。

比如，大型的哺乳动物，好几吨重的大象，它处在食物链的高端，没有人能吃它。但它不在食物链的高端生活，它吃草。草，植物，处在食物链的低端，通常它是其他动物的食物。

# 熊的生存智慧

![](bbox=[0.06, 0.0022299999999999998, 0.95, 0.0025])

1.开源

熊是杂食动物，食肉之外，它还吃水果，吃干果，还偷蜂蜜吃。还有熊会捕鱼，在海边实在找不到东西吃了，它吃蛤蜊。

在大马哈鱼回游的季节，好多的灰熊就会站在那个瀑布的旁边张大着嘴巴，在大马哈鱼跳龙门时就跳到它们嘴里。

熊的嗅觉非常灵敏，狼比狗的嗅觉要灵敏，熊比狼的嗅觉还要灵敏。

当它来到海边什么都没有的时候，它能闻到藏在地下30到40厘米的蛤蜊。

![](bbox=[0.25, 0.0033799999999999998, 0.75, 0.0035499999999999998])

2.节流

在冬天连草都没得吃的时候，熊选择冬眠，节省体能。

> 笛卡尔：不能改变世界的次序，就改变自己的欲望。

![](bbox=[0.06, 0.00408, 0.95, 0.00435])

3.熊是复合型人才

熊会跑步、游泳、能直立行走，手还很灵巧。

如果真找不到东西吃的时候，在离海岸不远，如果有个岛的话，它会游到那个岛上去找吃的东西。

它要摘果子吃，去偷蜂蜜的时候，直立让它能够得着。

它一方面凭借硕大的这个身躯占领了一个非常好的“生态位”。与此同时，它又避免了这种大身躯带来的能量供给不足的种种挑战。
