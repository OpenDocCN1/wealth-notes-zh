# 硬通货

我们只要做的是跟钱打交道的事情，现金是最好的，因为它的流动性最强，在整个市场上市它的带宽是最高的。小偷他最喜欢偷的是钱，偷家具、茅台酒，他需要转换，有折现值还麻烦。

货币是一种特殊的商品，是叫做一般等价物的商品，它隐含的交易的频次是最高 的。

做人做到极致就是一张票子，现在也叫什么男票、女票的，我很反对这个词，你把你的男朋友叫男票，这个票是可以通用的，流动性太高。我说的是做人最高的境界是个硬通货，不管是在熟悉的人当中，还是在陌生的人当中，大家都认你。

例子：郭靖

在整个武林市场 上，郭靖就是一个硬通货，他虽然那么傻，但几乎是人见人爱。

+   1.界面友好

他像钱一样，界面很友好，见谁都是久仰久仰，然后第二句是，可是你辈你到底是谁啊？这种话很蠢，但这句蠢话他是真情流露，一般有心机的人只说前半句，久仰久仰，后半句是不会说的，那是犯傻，但是后半句很管用，表明他是一个傻到极致的，心机等于零的人。

+   2.注意力和欲望的覆盖的范围也很小

他的注意力和欲望覆盖的范围也很小，脑子不够用，这样最大的好处就是他对有些招是无感的。黄老邪吹魔笛废他的武功，他听不懂音乐，废不了。曾国藩他的上半生就是一个好为 人师的人，很讨厌。郭靖是好为人徒，见庙烧香，见到岁数大一点的，甚至岁数很小的人都恨不得叫人家师父。他的规则特别简单，简单到极致，《道德经》里头反复讲的一个道理，就是以简驭繁。

# 做企业就是做品牌

品牌不是品牌部门的人做的，一个企业你在经营，就是在做品牌。

见面就是要扫微信、发名片不是在打造自己的品牌。打造品牌，你说的每一句话，你做的每一件事情，你的一举一 笑都是在做品牌。你说我不说话，不说话你的品牌就是 eds巴，做人其实就是在做品牌，做企业也是在做品牌。

从消极的意义上讲，它就符合那个米兰达宣言，尤其是在今天这个网络时代——“你可以保持沉默，但你说的每一句话都将作为呈堂证供。”其实你保持沉默也是选择了沉默，那你也就选择了跟沉默相关的品牌，所以我们时时刻刻都是在做品牌。郭靖在做品牌，杨康也在做品牌，每个人你做任何一件事情的时候，都在自定义自己的品牌，当然我们经常是没有意识到这一点。

# 品牌和声誉

个人品牌，我们一般都把它叫口碑，这个人口碑不好，这个人口碑特别好。有人说互联网时代品牌已经没什么用了，品牌是工业时代的产物，互联网时代品牌指数应该被声誉指数所代替。

品牌是定价，有的一些公司做的产品不怎么好，但是多少年前建立了那么一个品牌，它还有一个所谓的品牌惯性，定下来，它相当长的时间是定在那儿的；

声誉指数像股价，今天是个价，明天是个价，上午是个价，下午是个价。

声誉，就是我们昨天说的那个“名”，莎士比亚说的你可偷我的钱，你不要偷我的名，这个名一旦被偷，我就是真的是 一贫如洗。你的名声相当于一个能量的发射源，你的能量的大小决定了你这个场域的大小，我们经常说这个人有没有气场，这个人有没有场面，这个人的格局大不大等等，其实都是你在过去的行为，你在跟别人打交道的过程当中，形成的一种无形的资产，或者说是一种特殊的社交货币。

# 时延

直接互惠和间接互惠，间接互惠和直接互惠最大的不一样是，它是一个多次博弈的交易系统，就是你的投入和产出是效果滞后的。用一个比较时髦的话说，投入和产出之间是有时延的，现在通讯里头讲时延，它的效果是延迟的。小气和大气，有格局和没格局的最重要的差别是，一个是关注直接互惠，另一个是关注间接互惠；一个是只关注在一次性交易当中获利的大小，一个是每一次的利益交换当中，既是在完成当下的这个交易，同时也是在为后续的交易做准备。

如果为后续的交易做准备的话，你就必须要求接受这样一个事实，你眼下做的这个投资，它的回报的大小，以及回报的时间是不确定的。但是只要你持续地进行投资，而不是单次结算的话，你最终的回报率是 很高的。
