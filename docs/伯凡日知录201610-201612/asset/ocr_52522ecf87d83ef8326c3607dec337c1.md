# 本周预告 | 聊一聊“熵”

![](bbox=[0.08, 0.158, 0.12, 0.175])

本周预告 | 聊一聊“熵”

本周的《伯凡·日知录》围绕着一个字来展开。

前几天碰到一个华为的朋友，他说：“听说你最近在看大量的我们任总的内部讲话，在研究华为的经营哲学。如果用一个简单粗暴的说法，你认为华为的经营哲学和管理哲学到底是什么？”

我说了四个字：“在商言熵”。

那个朋友听到这四个字，一脸失望的表情。我告诉他，我说的在商言熵，第二个熵是带火字旁的熵，这是一个不太常见的字。它是一个物理学热力学的概念。在我看来，任正非所有的管理哲学都是跟这个字有关。

熵是什么呢？关于熵的定义，大家可以详细地听《伯凡·日知录》，简单地说，熵就意味着次序的衰减，意味着无序，意味着混沌，甚至意味着死亡。

无论是一个人还是一个企业，一旦诞生，都是处在一个看不见的一条传送带上，这个传送带可以用“熵”来命名。这个看不见的传送带会让我们在不知不觉当中通向混沌，通向无序，甚至通向死亡。我们能够做的事情就是如何反方向地行走和奔跑，如何反抗熵，如何制造一种叫做负熵的东西。熵可以说是一个隐性的魔鬼，随时在侧，我们无法最终摆脱它。我们只能用各种的方法和手段倒行逆施，如何尽可能地避免被熵这样一股巨大的暗流所裹挟。

关于什么是熵，大家可以在网上找到很多的资料去了解。管理学的创始人德鲁克第一个把熵的概念引入到管理学，在他看来，每个企业在它的诞生之日就得了一种叫做熵的病。所谓管理就是用一套体系化的方法去治疗熵这样一种疾病，让组织尽可能的远离混沌，趋向有序，让组织不断地获得一种生命力。

熵这种病有各种各样的症候，企业的领导者和管理者的使命就是要识别和警惕、防范各种形态的熵对组织的持续的损害，永远没有尽头的救赎。

企业和个人的熵是如何形成的？

熵又有哪些很难识别，但又我们必须得防范的形态？

我们又用什么样的方法和手段来治疗熵带来的种种的疾病呢？

请大家收听本周的《伯凡·日知录》。
