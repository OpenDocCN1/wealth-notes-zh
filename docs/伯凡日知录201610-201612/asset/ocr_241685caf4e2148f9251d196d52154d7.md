# 暗文化

罗胖说：现在世界，同性恋已经早就不是一个很敏感的话题了，甚至有点反转，就是在好多圈子里，你不是也得装着是，要不然你显得很异类。

我们习惯于把它称为亚文化，就是在主流文化之下的，另外一个层级的文化。亚文化这个词已经非常流行了，我倒想到了另外一个名称，是我自己生造的，叫“暗文化”，就像物质之外有暗物质一样。

亚文化是大家都显而易见的，而且在公开谈的一种文化；还有一种文化是它存在，但是我们根本不知道它的存在，在特定的圈子里头它也非常的热闹。

罗胖说，在同性恋亚文化里，还有一种更小众的但是也不可小视的一种现象，叫恋老族，就是一些年轻的小伙子，对岁数比较大的老同志有一种特殊的感情。他们经常会聚在一起，经常把他们敬爱的这些老同志的照片晒出来，据说他们也有自己的贴吧，有自己的一套社交媒体。

男同性恋下面有这么一个特细分的市场，这种现象，对很多人来说可能是一个亚文化当中的亚文化，藏在深处的深处，我们不妨把它叫作“暗文化”。

# 部落化-解部落化-再部落化

# | 部落化

“部落化”，Tribalization，分散的个体由于要建立一种协作关系网络，他们形成相对稳定的小联盟，互相帮助，彼此协作，形成的这种部落。这样的现象在原始社会就已经发生了。

再后来，文明社会里头也有很多很多的部落，有些我们知道的什么王国，最早也就是一个部落。欧洲有很多小国家，小到令人发指，比如：圣马力诺、列支敦士登、安道尔、马耳他。它们就是当年在中世纪的时候，遍布欧洲的那些小国家的活化石、遗迹。

这些国家其实再往前追溯，可能就是一个部落，由于基督教的出现，由于民族国家的出现，一些小部落就逐渐地消解了，它们被并入一个更大的组织，比如说一个介于正式与非正式之间的什么撒利曼帝国、神圣罗马帝国，后来，就是一个个民主国家。

# | 解部落化

由于一个统一的文化出现以后，一些部落性的文化被消解，这样的过程，叫“解部落化”，Detribalization。解部落化伴随着现代文明的整个历程。除了政治意义上的解部落化，还有文化意义上的解部落化。

![](bbox=[0.13, 0.00329, 0.92, 0.004])

例子：同一个时间看同样的内容

在中国各地，虽然过的是同样的节日，但是每个地方的风俗习惯是很不一样的。但是有了电视这种媒体以后，就出现了一种在媒体、在文化上的解部落化过程。

比如说春节，春节就是看春晚；元宵节就是看元宵晚会；中秋就是看中秋晚会……这样一种解部落化，在现代社会当中非常普遍的。

现在我们使用同一个社交媒体的时候，差不多同一时间看到同样的新闻，今天有一个新闻，整个屏幕都是关于这个新闻种种着调和不着调的说法，哪怕你进到群里也是在谈论这样的事情。从这个意义上讲，互联网的确具有一种解部落化的功能。

那些互联网的预言家，那些未来学家都认为，互联网将导致进一步地解部落化，但是20多年过去了，我们今天回头看，互联网只是在非常有限的意义上实现了解部落化。
