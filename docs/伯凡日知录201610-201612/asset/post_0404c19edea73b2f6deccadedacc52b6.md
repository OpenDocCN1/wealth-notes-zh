
# 关于学习小组的名字：

我给我们的小组，取名叫“知几局”。

+   1. “几”这个字在古代汉语里，是一个看上去很简单，其实也很高深的一个字。《道德经》里有一句话“上善若水，水利万物而不争，处众人所恶，而几于道”，所谓“几于道”，就是跟那个微妙的“道”能够实现某种同步，那样的话你就会一窥天机。我们平常只是说知道，知几与知道相比，知几是一种更深度的认知。

+   2. 中国古代有一个史学家叫刘知几，他写过一本史学名著叫《史通》，他认为我们读历史，不仅仅是要知道历史的事实，要知道历史的那种微妙的机制、微妙的那个玄机，要在众多的纷繁复杂的事情背后，看到贯通所有事件的那个机理，那个逻辑。只有做到这样的人，你才能够通。在彼此不连贯的事件当中，你能够打通这些事件，这个背后隐秘的关联就叫“几”。中国的历史学家的最高理想，就是要透过众多的历史现象，而寻找贯通所有历史现象的那个逻辑。

+   3. 司马迁有一句话，叫“究天人之际，通古今之便，成一家之言。”，我希望我们的《自凡·日来说》也能够在1%的程度上达到这样一种状态，我们知道的不仅仅是事实，而是逻辑，这个逻辑就叫“知几”。

+   4. “知几其神”，是指人能够预知事情萌发的细微迹象，就能够以神道相通。

机会就是大家都还没有看到，而你看到的那种东西。彼得·蒂尔在《从0到1》里头讲过，创业就是要发现秘密，那个秘密其实也是“几”，这个词“知几其神”出自《易经》，在《周易》的《系辞传》里头有这么几句话，“子曰：知几其神乎，君子上交不谄，下交不渎”，就是跟比自己高的人交往的时候不去谄媚，比自己地位低的人不去羞渎人家，不去轻慢人家。“其知几乎”，你只要保持这样一种平常心，你才能知道那个微妙的逻辑，你才能知道人与人相交往的时候的那个秘密。

# —— 知识笔记 ——

低维度的物种没办法想象、感知一个高维度的世界。

一个拥有高维度感知的物种，它就具有一种巨大的优势，能够对低维度的物种进行打击，它获得的竞争优势不是量的优势，而是质的优势。

例子：瑞士钟表业的绝地反攻

石英表是日本人发明的，是日本生产...的公司，为了迎接1964年的东京奥运会，研制出了比机械钟表更准确的一种计时钟表。石英表作为一种成熟的商品在70年代崛起，瑞士的钟表业感受到了巨大的威胁。

相对于机械表，石英表有许多的优势：

+   1. 准确度高
2. 使用方便，不用每天上发条，不用担心不戴手表，它就停止运转
3. 价格优势

瑞士钟表业的处境，就像今天有很多生产传统产品，遵循传统的商业模式来生存的企业，一下子受到了互联网的冲击一样。

瑞士钟表业的困境：

他们也想过打价格战，想过生产石英表来跟日本企业进行对抗，但在瑞士这个高福利国家里生产成本很难降下来。如果在石英表这个领域跟日本企业进行竞争的话，他们既无技术优势，也无生产的优势，更没有成本的优势。

# 瑞士钟表业的英雄人物——尼古拉斯·哈耶克

# 一、局势判断

他知道瑞士生产石英表的成本非常高，如果仅仅是从钟表的基础性能（计时）去跟日本企业对抗，就会被陷入比拼性价比的泥潭里，自己没有胜算的可能。

所以他要重新发现、重新定义手表。

# 二、文化优势

哈耶克生活在欧洲，他拥有一种独特的优势，在我们今天看来那就是文化优势。

当日本经济崛起的时候，在欧洲就出现了一些人，对日本的经济形态进行攻击。其中攻击最厉害的就是法国人，法国人说日本人只是一种“经济蚂蚁”。他们只会干活，不会享受，不懂得在工作和金钱的世界之外还有另外的世界。

法国人以他们惯有的文化优越感对日本进行攻击，其中最常使用的词就是“蚂蚁”，蚂蚁是一个低维的物种，现在看来蚂蚁这个词相当的准确。一方面以法国为首的欧洲人对日本的经济形态、对日本的生活方式进行抨击、进行批判，同时他们更加强意识到了自己的生活方式、自己的生活世界以及产品形态的文化优势。

# 三、找到石英表的新维度

哈耶克从法国的时装里找到灵感，他请来法国的服装设计师跟他们自己的设计师一起来对他们生产的廉价的石英表进行设计，让石英表拥有一个新的维度——时尚。

女性爱戴首饰，但是不太爱戴手表，很多人甚至认为幸福的标志就是不用看手表，手表在她们眼里头是一种束缚，甚至是社会地位低下的一种标志。

Swatch公司让每一块表的外型、颜色，跟某一款服装、跟某一类服装进行一种深度的勾连，找到手表跟时装之间的适配性，无形当中手表就获得了时装的功能。

# Swatch的特点

+   1. 成为时装的一部分，成为一个服装组合的点睛之笔。
2. 跟随时装的诡谲和节奏，在春季和秋季分别推出多款的Swatch表。
3. 按照时装行业不成文的规定，不断地推出新款，来让你的原有款式强行折旧。（后来PC制造业也学会了时装业的这个诡谲，隔一段时间推出新款，强制让旧款进行折旧，包括我们现在的手 机业，也都是吸收了时装业的诡谲。）

Swatch公司把手表从一个耐用消费品，改造成为了一个时尚产品。他们对产品进行了重新定义，让手表获得了一个新的维度——时尚。这样女性在一生当中，甚至是在一年当中都要戴各种不同的表，因为她们经常要换不同样式的服装，所以她们就会随之连带地去变换她们的表。

日本的那 些石英表虽然是价格便宜，性能也很好，但是它不入时尚女性的法眼。由于增加了这个维度，所以就是在日本人发明的石英表这个产品领域，Swatch实现了高维打低维。

# 四、找到机械表的新维度

哈耶克在中东黎巴嫩出生的，他从中东文化中得到灵感。找到机械表的新维度——奢侈品。

中东是宗教色彩非常浓厚的国家，有很多的男士尽管是腰缠万贯，但是他们必须身着他们的传统服装，他们服装的变化程度是很少的。如果你想标示自己的身份，和其他人区别开来，仅仅是通过服装是不够的。

男性爱戴手表，很少戴首饰，在某种意义上说手表就是男人的首饰。

那个时候的瑞士手表价格体系还是比较混乱的，很多品牌的表，哪怕是老牌的手表，工艺精湛、制作精良的那些手表，跟相对普通的表在价格上并没有完全的区分开来，甚至在设计上也没有明显的差别。

首饰的特点就是，它要让人一眼就知道它的价值，把手表做成一个首饰的话，就必须要对手表的设计下大工夫，其次就要在价格上做严格的区隔，这样戴不同手表的人，他所彰显的身份和地位就完全跟别人区别开来。

# 男士的机械表的奢侈品逻辑：

+   1. 它的实用功能在整个的价值份额当中占的比例是非常非常小的（所以，手表计时的功能在手表的整体功能上越来越不重要。）

2. 价格是价值的一部分，价格就能把我和其他人区别开来，当我戴上它的时候也就是标识着我进入到一个特殊的圈层。

Swatch集团进行了大量的收购，形成了一个完整的产品组合。这样我们就看到一个以生产比较廉价的石英手表著称的Swatch集团建立了一个有巨大的价格落差，有丰富的产品形态的机械表产品体系。

首先我们可以说维度这个话题肯定跟佛教的世界观有一定关联，尽管我聊的时候并没有特别提及这种关联，佛教里头有一个很核心的思想就是我们所感知的世界，我们的感官是不足以感受我们所在的这个世界的。在这个世界的真实角色就是盲人，盲人摸象这也是佛教故事，还有苏东坡，特别喜欢谈“佛”谈“禅”的苏东坡写过一篇叫《日喻说》的文章他里头讲到了一个故事。

一个人生下来眼睛就看不见，所以他不知道太阳是什么，他就问身边的明眼人，能看见这个世界的人。你们说的这个太阳到底是什么样子？

别人告诉他，说太阳像一个铜盘。我们有视力的人一听这话觉得很形象，像一个铜做的盘子，这个盲人就让人拿了一个铜盘，自己把那个铜盘敲了几下。

有一天他就听见庙里头在敲钟，他说这是太阳，别人告诉他这不是太阳，太阳它是有光有热的，太阳有点像蜡烛，它散发着光、散发着热，他觉得他自己明白了，他就搂着一根蜡烛。有... 苏东坡说太阳跟铜盘、跟钟、跟箫隔得太远了，但是这个盲人不知道它们之间的差别。

在苏东坡看来我们很多人其实就是这样一个盲人，我们只知道事物的某一个特性，我们就以为我们知道了这个事物，太阳的确是铜盘，它只是其中一个很小的维度，它的形状像，但是其它地方是完全不像的。由于我们只是抓住某一个单一的维度，我们就没办法认识世界，最要命的是我们是盲人，但我们不知道我们是盲人，还是那句话，we are blind to our blindness，所以我们就坚定地认为我们感知的这个东西就是客观的，别那样子说是胡说八道。这就是佛家讲的“执”，法执、我执的执。

这个叫“燕儿”的同学，她的逻辑我有点不明白，说她觉得这是个伪命题的原因就是因为，这不就是佛教说的微尘和大千世界的关系吗？因为是这个，所以它是伪命题，我不是太明白这个逻辑，但是她想说的大就是小，小就是大，没有什么一花一世界，一叶一菩提，所以维度这个概念应该说是一个伪概念，不能说是伪命题。大小之辩，中国古代的知识分子对大小之辩也是很着迷的。

阮籍说：“自小视之，则万物莫不小；由大观之，则万物莫不大。”

如果从大的角度来说那些夭折的小孩子其实也是寿星，他们活得比那些朝生暮死的虫子寿命要长得多；如果是从小的角度看，彭祖，据说活了800岁的彭祖，那也是幼年夭折的。如果从大的角度来看，一根毫毛也是大的；如果从小的角度来看，泰山也是小的。如果从同一的角度来看它都是毛发，如果从分别的角度来看这是胡子、那是眉毛，这是古人特别喜欢用的一种相对主义的论证方法，用相对主义的论证方法模糊、消解所有事物的差异。

张子曾经说，中国，就是当时中原这个地方，中国如果在海内，在这个世界上，在这个宇宙当中，不就是像一粒小米在一个大仓里头吗？太仓就是国家的粮仓。

关于小米这个话题很多人都接着说，辛弃疾有一句话：“泰山毫末，从来天地一秤米。”泰山和一根毫毛之间没有什 么差别，天地也不过就是一粒米那么大。

这样一种世界观是要提醒我们，我们要切换角度看世界。就连照相机还有一个焦距的问题，我们观察世界、感受世界的方式常常是没有焦距的，我们从一个角度看到了一个什么东西，我们认定它就是那样的。如果陷入到这样一种状态，我们就会陷入到一种“愚”的状态，愚蠢的愚，这个字上面是个呆、下面是个心，愚就是我们的心被限定在一个角落里头，我们自以为看得真真实切，实际上我们看到的其实是一个极其片面和错误的世界。

但是我讲维度的话题不是要跟大家谈佛谈禅。我只是想提醒大家，在我们的日常生活中，在商业竞争当中，有些时候争的不可开交的事情，换一个维度来看完全是无意义的争。 我们提到的蓝海战略就是不跟你的同行一般见识。当我们陷入到一种苦不堪言，又好像津津有味的一场争斗、一场竞争的时候，能不能抽身出来想一想，这个争斗真的有意义吗？当你增加一个维度的时候，发现这些争斗没有意义。

当我们从较低的维度能够上升到较高的维度看我们生存状况的时候，我们就能够获得两种状态：第一是敬畏，第二是包容。

当我们有一个认知的时候，我们知道这种认知还有升级的可能，有可能我们看到的真真切切的局面、境况其实是一个幻象，所以我们要对未知世界，对我们还没有感受到的，但它的确确实存在的那个世界要... and humble...

还有一个心态就是包容的心态，包容不是说我明不同意你的观点，我就忍气吞声，包容是你不同意别人的观点，但是你知道他为什么那样认为。这个时候你知道他处于另外一个维度的时候，你很少有去据理力争的这样一种动机和愿望了。自然会有一神自由主义者常常推崇的那种心态，我不遗余力地反对你的观点，但是我要誓死捍卫你说话的权利。

举一个很俗气的例子，我们如何看待钱，我们如何去得到钱？

在对待钱的态度方式上至少有四个不同的维度，我把它概括成争、挣、赚、来。

1. 争钱，所谓争就是在一个存量上，你尽可能地多得一点点。你去买菜的时候，你钱已经花出去了，你非得要卖菜的人再给你两根葱，这个利益是你争来的。

这也算是一种获取财富的方式，争取自己的利益也没什么错，但是如果你一直停留在这个维度上的话，你对于钱的认知，你对于挣钱的方式，可能你自己就不自觉地陷入到一种认知和行为的误区里头了。

2. 挣钱，挣钱就是通过自己的努力在增量上去获得财富，这叫挣钱，你越来越习惯，越来越认识到钱是挣来的时候，你去争的热情就会减少，更多的热情是投入到如何通过自己的努力去获得自己的财富。

3. 赚钱，简单地说就是让钱为你去工作，有一些人由于把热情都耗在菜市场多要几根葱上头的时候，他们不知道钱本身是可以为你工作的，这就叫赚钱。

4. 来钱，来钱是好像你没有工作，但是那个钱自动地来，其实它不是白来的。用我们以前讲到的内部型和内部型那一对概念来说，就是你在交易合同当中没有特别标明的那些成本和价值。简单地说是在以前你已经付出了很多，但是在交易当中有很多你付出的成本并没有兑现为价值，但是随着时间和场景的变化，这些在交易当中没被标识出来的成本和价值逐渐地显现出来。

我们为什么说要让自己的认知、要让自己的行为升维呢？

原因就是低维的东西容易绑架我们，容易让我们去从事那种低品质的勤奋，你也付出了很大的热情和努力，但是你做的效率和效果很低，反过来当你在一个更高的维度来看待一件事情，并采取相应行动的时候，你的效率和效果就可能要好得多。

面对我们眼前的这个世界，我们一方面要 Sunshine 秉持一种放达的心态，我们生活当中常常会有那些当时看事大如天，过后想细枝末节的那样一些事情，我们要避免自己被某种场景绑架，我们就需要增加自己的思维和行动的维度。

在这个时候我们就不能和稀泥了——“大和小没有什么差别，长和短也没有什么差别。”凯恩斯说我们不能总是从长远看，从长远看我们都是要死的，你被这样一种心态所掌控的时候，那当然就不存在着低维和高维的差别了。说白了得和失都是一样，活着和死去也是一样的时候，当然我们就不需要什么一维、二维、三维这样的区分了。

郭宇飞：咱得到APP很大程度上是一个提供干货的平台呀，这跟您的想法岂不是有点矛盾？

吴伯凡

我在提到干货的时候有一句话，我之所以说干货有毒，我想强调的不是干货本身有毒，而是我们总是期待简单的答案、快捷的解决方式这样一种心态本身是有问题的，一旦你总是在期待干货的时候，证明你已经陷入到这样一种心智模式当中。这种心智模式的背后其实就是两个词，一个是惰性，一个是贪婪，我们希望用最简单的方式解决问题的时候，我们希望得到那种一句顶一万句答案的时候，我们应该反省一下，关于这个世界那些简单的答案真的管用吗？

如果我们已经对于干货有一种强烈饥渴的时候，我们也许应该切换一下自己的心智模式。尤其是当你在创业的时候，那些简单明了的答案，那些看似一抓就灵的方法和手段，很可能把我们带到沟里去。

当然话要说回来，生命苦短，人生如白驹过隙，我们要有效率地去寻找答案、寻找解决方案。所以干货还是需要的，但是我只是想提醒自己，也提醒大家，干货里头有太多的伪干货，看似干货实则是水货的那些东西一定要有警惕，要不然时间长了，我们就会被干货所误。

“得到”这个平台是一个求知求真，帮助我们实现认知升级的一个平台。如果我们真的想求知求真，实现认知升级的话，我们应该有那样一种心态——“无诮于势力，无望其速成。”任何升级不管是产业升级还是认知升级，其实都是一个艰难的蜕变的过程，就像蝴蝶从那个蛹里头蜕出来那样的艰难。如果一个升级完成的是那么的轻松、那么的简洁明快，很可能那是一个伪升级，一段时间过后，我们可能会发现我们其实是在原地踏步，就像我们讲到的那个被主人蒙上眼睛的驴子，自己觉得自己走了千万里，其实一直围着磨盘在转。

阿亮：吴老师，上周您提到人生要做减法，少则得多则惑，要追求目标的单一性。本周又强调要多维思考，那这两者之间该如何平衡？

# 吴伯凡

这个问题很尖锐，你一会儿说要做减法，一会儿又要做加法，这到底是怎么回事。

我们简单地说，单一的维度上我们要学会做减法。面对很多机会的时候我们应该想一想，这些机会是不是同质化的，在同一维度的。如果我的目光持续被不同的机会所吸引的话，最后很可能是小猫钓鱼，很可能是猴子掰苞谷那样一种状态。

机会好像很多，自己也很努力，但是最终的结果常常是一无所获或者所获甚少。与此同时我们也该想一想，在眼前的这些机会之外，或者在另外一个象度、另外一个维度上还有没有机会。其实很多企业的转型都是告别单维的商业模式，而敏锐地发现另外一个维度的利润区，比如说阿里巴巴本来是做电商的，支付只是电商的一个辅助手段，但是后来他们敏锐地发现支付是阿里巴巴商业的另外一个维度，也就是金融的维度。所以阿里巴巴的战略从只有电子商务这样一个维度升级为既做电子商务也做网络金融，甚至整个公司战略的重心逐渐向金融倾斜。

一门心思、一根筋有时候是一种美德，脚踏实地、心无旁骛地做一件事，但是 一根筋有时候也会误了我们。就像我们经常讲的那个记者的故事，总编派他去采访一场婚礼，不一会儿他灰溜溜回来了，总编问他你为什么这么快回来了？他说婚礼没办成，所以我就回来了。总编就非常生气，婚礼没办成那才是更大的新闻。

我们以前经常用脑筋急转弯来形容这样一种思维方式的转变，其实转弯只是在同一维度上，车转弯的时候是在一个二维的层面上，比转弯更重要的是你能够从原来的那个维度上上升到增加一个维度，与其说是转弯，不如说是升维。

来来克克：维度有穷吗？如果是无限的，是不是有时反而应该降维才能幸福？

# 吴伯凡

首先应该说维度是有限的，不是无穷的，哪怕是弦论说的那十一个维度，那它也是有限的。但是我们不能简单地说降维才是幸福。在古希腊的哲学里头有一个很著名的争论，是猪在泥坑里打滚是最幸福的，为了得到幸福我们是否要让自己变成一头猪，在那么不好的环境里头我们也能得到快乐。

很多的幸福论都是反对这种降维的思路，相反他们都认为升维才是真正幸福的，原因就在于人的需求是多维度的。

有时候单维上的满足不仅不能够让你产生真正的满足感，反而会让你产生前所未有的空虚和痛苦。

画家吴冠中说，我们中国文盲已经不多了，但是美盲特别的多，对我们很多人来说认识文字的眼睛是有 的，但是认识美、发现美的眼睛是没有的。

作家木心说的更极端，他说文盲有救美盲没救。文盲上一个月 的扫盲班你就不再是文盲，但是一个人不大可能在短时间内让自己拥有一双发现美的眼睛。所以木心有点清高地说，我悲哀地看着你们这群人不知道悲哀的人们。

没有钱的人是都知道自己没钱的，我们对某件事情不懂的时候，常常是不知道自己不懂的，至少我们是不懂到底有多少不懂。只有当我们真正懂了一件事情的时候，我们才能够明白我们当初有多么不懂。所以在一个低维世界里头最大的危险就在于，你不知道自己是处于一个低维的世界，你对自己的根本性缺失是毫无感觉的。

# 关于知道有四个状态：

+   1. 不知道不知道，这是最低的境界，不知道，而且自己不知道不知道。\n2. 知道不知道，我虽然不知道，但是我已经知道自己不知道了。\n3. 知道知道，我知道了，我也知道自己知道了。\n4. 不知道知道，我已经知道了，但是我甚至不知道自己知道，那样一种状态，那种知道才是真知，它是一种溶化在身体里头的知识和记忆。

我们经常说老司机，老司机就是那种不知道自己知道，遇到什么事情是不知道自己知道该怎么做的 人。遇到事情他一定知道怎么做，但是他自己即使做出来了，他往往是不知道自己为什么要这么做。

我们经常讲认知升级，其实也是一种知识维度、感知维度的升级。
