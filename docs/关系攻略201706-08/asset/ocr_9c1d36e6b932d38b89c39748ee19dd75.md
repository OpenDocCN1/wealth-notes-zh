# 《为什么不要“随便找个老实人嫁了”》

好多女生喜欢说：“找个老实人嫁了。”

更有的令人发指：“随便找个老实人嫁了。”

最要命的是，有人是真的相信可以随便找个老实人嫁了。

所以，我想再带你复习一下，老实人是什么人？以及为什么不要嫁给老实人。

老实人大概是这样的：

+   读婴儿的时候中等或者中偏下；
30岁了，几乎没谈过恋爱；
内向，羞涩；
话少沉默；
不太会社交；
吸引异性比较困难；
有一份工作，收入不高，但很少失业。
