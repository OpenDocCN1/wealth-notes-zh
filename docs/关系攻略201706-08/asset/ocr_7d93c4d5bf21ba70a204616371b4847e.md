# C.少东家型的二把手

少东家和鬼副长、管家婆都不一样，他只要学习、成长、显示出活力来就够了。如果你遇到这样的二把手，相处可能就是一个问题。

因为少东家往往还有需要学习和改善的地方，做事业可能偶尔还有情绪化的地方。
