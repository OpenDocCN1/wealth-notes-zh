被关羽要的大傻子，未免太可惜了。

# 吕蒙怎样变成了终身学习者？

吕蒙以前是个武将，三十多岁了发奋读书——他可能是最早的终身学习者。

吕蒙当兵都是托的关系，他姐夫是孙策手下的“别部司马”，那时候周瑜才两千兵，别部司马也就是个营长级别。

吕蒙是个穷人，有尊严的男人都不会去依赖出嫁的姐姐，但是吕蒙知道自强自立。

十五六岁，就私自跟着姐夫一起出去打怪，剿个山贼，弄点战利品。姐夫回去告诉老太太，说他去打仗了，老太太要骂他，他说：我们家这么穷，不打仗怎么摆脱贫穷？

“且不採虎穴，安得虎子？”（吕蒙身上有三个成语，另外两个是“士别三日当刮目相待”和“吴下阿蒙”。）

# 如果这么成长下去，吕蒙只是一个聪明的莽夫，他识字不多。

建安十五年（210年），吕蒙32岁，孙权劝吕蒙读书，吕蒙说自己工作忙。孙权说不是要让他当博士：“但当涉猎，见往事耳。”粗略看看，明白一些历史旧事就好了。

这个32岁的汉朝人白天练兵，晚上念书。

# 聪慧早熟者的优势：

+   1. 他们往往家庭出身都不错，这让他们受到良好的教育，同时有更多机会结交到有实力的朋友。\n2. 他们是对自己要求严格的人，如果有的时候不能控制自己的骄傲和情绪，就容易受到伤害。\n3. 职场上的资深员工如果对你的评价不够好，你就一定要更加紧密地靠近你的主公。\n4. 绝对的忠诚，要顺服和爱戴你的领导，杨修却是反例。

# 后发觉醒者的优势：

+   1. 克服自己放弃的念头。\n2. 读书和学习什么时候都不晚。\n3. 除非你准备转行，不然就重点关注对你的事业有用的内容。\n4. 随着年纪渐长，你的智力根本就不会下降，你的经验会让你更善于处理情结和情境。\n5. 成长之后，我和你关系不错的上级（鲁肃比如）聊聊，展示出你的进步。

孙权的哪句话：“但当涉猎，见往事耳。”
这是成年后用碎片时间学习进步的一个真谛：
要把握精神和原理，活学活用，积极行动。
