# 198、为什么创业者要只认钱？

①创业者，什么都要自己管，除非您的公司做大了，才要别人管。一般情况下，您招聘过来的、跟着您混的人，都比您差很多。他们没什么大事，不要相信他们能赚钱。您把自己的资产让他们管，后果就是亏本。

②您完全可以根据自己的感觉随意开除他们，您这样干了，公司还能正常运转，就证明您是一个合格的老板。如果，您开除一、两个人，公司就不能正常运转了，恭喜您，您已经是一个大老板了。

③创业者，要杀伐果断；创业者，只要认钱，只认今天赚了多少。按照法律规则玩就行了，其他的话，不用多说。

④真正聪明的人，一眼就能看透哪些人值钱，哪些人不值钱。从一开始，就杜绝跟没钱的人在一起。如果您真做到了这一点，您就懂道了。
