# 106、为什么做什么都需要有耐心？

①有耐心的人机会多些，比如，一篇文章，有的人没耐心逐字逐句的读。就比如，我收费教人学习互联网营销，发给他们的东西，都是我提炼出来的精华，大部分人也没耐心、逐字逐句的阅读。结果，就错失了很多好的知识点，错失知识点，就错失了赚钱的机会。

②恋爱当中，当我们碰见一个合适的人，我们可能在一次争吵中，就散伙了，以后再也找不到这样合适的人了。少了隐忍，少了耐心，人生就得多靠些运气，人生活得就粗糙了。

③做项目过程中，有些人会提出无理取闹的要求，您没耐心带人做好，这个单子可能就黄了。而且别人还会漫骂您，说您坏话。

④耐心决定您愿意在一件事情上投入多少，耐心也是您的人际关系好坏的一个指标。

⑤没耐心的人，连小孩子都教不好。

⑥没耐心的人，连一本书都读不好。

⑦耐心，决定着您的命运的质量、您事业的质量，甚至，您爱人的质量。
