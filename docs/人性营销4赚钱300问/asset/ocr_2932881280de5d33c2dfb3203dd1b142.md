# 273、怎样保护好自己的钱财？

+   ① 不开公司，把钱浪费在员工身上。 ② 不乱搞男女关系，把钱浪费在这上面。 ③ 不住豪宅，不买豪车，把钱浪费在奢侈享受之上。 ④ 绝对不赌博。

做到这几点，只要能赚钱，身价随随便便过几百万。熬几年社保，北上广深，就买房子了。您能做到以上几点，我们再来谈谈社群赚钱。不能节约钱的人，不配拥有金钱，即使是拥有金钱，金钱也会快速消失。

节约用钱是光荣的。乱花钱、浪费钱是通格。钱太多的人，可以有通格。我们这种普通人，还是要精打细算的节约。

节约是美德。喜欢浪费钱的人，都是白痴。真正的高手，都是勤俭节约的。一个喜欢浪费钱的人，终究是不配拥有金钱的。
