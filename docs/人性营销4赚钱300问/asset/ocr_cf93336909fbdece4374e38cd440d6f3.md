# 241、怎么算有钱？

①算不算有钱，看您和谁比，看您生活在什么地方，看您的消费能力。当然，也看您对物质的消费态度。

②有的员工一个月 3500 元也能过。有的人，一年几个亿的收入，也跟啃饭没什么区别，狼狈得很。

③有没有钱，还跟您的赚钱方式有关系。有些赚钱方式，让您觉得几千万的利润，都是小钱。而有些赚钱方式，让您一天多赚 20 块，您就高兴得跳起来。人之贫与不肖，在其所处耳。

④不过，人在年轻的时候，还是应该见识大海。如果您不能在大海生存，您也见过猛兽，再去那些小池塘里当霸王吧。

⑤不过，每个人都应该尽可能的提升您的收入，因为这是您的生存条件的上限。
