# 196、创业要第一时间找投资人吗？

①一般建议大家不找投资人，也不借钱，就靠自己的原始积累来创业。

②创业，并不是钱越多越好。创业，其实有钱不是最重要的。有智慧，会销售，知道自己应该干啥，钱才会进来，才是最重要的。

③很多人以为自己不能创业，不能做企业，是没有钱，其实不是。是自己缺乏营销能力、渠道能力、产品能力、服务能力、组织能力。初期资金，只是创业中的一环。

④小钱、自己的存款、很少一部分，就可以开始经营一个小项目、一个小产品、一个小服务了。

⑤投资人的钱，拿着，其实会给您带来无形的压力。投资人的钱拿着，会左右您的决策。开始创业，一个人做生意最好，自己想了自己干。
