# 6、生活的关键是什么？

+   ① 早起早睡，非常重要。早上5点就要起床，洗漱完毕，工作。
② 倒两杯开水，工作吧。边喝边工作，读书或者写作。
③ 人应该工作。幸福来自于勤奋工作，多生孩子。
④ 不要交往低级的人，不要交往负债的人。就是连自己都养不活、没本事赚钱的人，不要交往。
⑤ 不要交往心情不好的人。当您交往多了低级的人，您的面相会变得非常差。
⑥ 只交往积极向上、努力工作的人。对自己朋友圈没有筛选、对自己交往的人没有筛选的人，会倒霉。

# 7、为什么您听过大师的道理，还是过不好这一生？

+   ① 首先，您听过大师的道理，您依然穷，对不对？您觉得是大師错了？其实大师没错，是您自己没有落实而已。
② 听道理，是不能赚钱的，只有身体力行才能赚钱。
