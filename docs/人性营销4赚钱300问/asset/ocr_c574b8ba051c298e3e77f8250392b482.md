# 105、坚持的意义是什么？

①任何长久的成功者，都是坚持者，能持续对一件事情保持行动、高度的热情。

②大部分人没什么成就，就是因为只干三天、三周、三个月，就想见到效果，当不知，任何项目都是要时间积累的，而且是长时间的积累。

③打工的，从来没有自己坚持去做一个项目，故而他们的眼界是短视的，干几个月见不到钱，就继续打工了。

④一件事，只有您多坚持一会，您才会发现这件事的关键，您才会理解做好这件事的技巧。没有持久战能的的人，混得好的可能性很少。

⑤就说写文章，但凡网络上有点名气的大V，都是常年写作的。极少有人写几天，就出名的，就有高收入的。

⑥只有那些一直坚持有好的作品输出的人，才会笑到最后。
