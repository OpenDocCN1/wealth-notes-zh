# 255、什么是资产？

+   ①能给自己带来现金收入的是资产。
②什么负债？钱出去了，每个月都在出去，这个就是负债。
③绝对不允许自己长期负债。
④最高明的人，能在几个月之内，把负债变成现金流人。
⑤您有一个女朋友，天天都让您的现金流出，则，您的女朋友是您的负债。高明的人，会把女朋友变成资产。愚蠢的人，把女朋友变成负债。
⑥富人喜欢一定要竭尽全力的让现金流进来。穷人则无所谓，每当月底，穷人发现现金枯竭，等着下一次工资，或者收入。穷人因为不在意自己的现金流入，也不会开发一些现金流入，所以只能终身贫穷。
⑦高手不是太关心自己到底有多少虚幻的资产，而是关心自己的现金是不是进来了。
