# 17、为什么要以苦为乐？

①人生蛮苦的，您必须努力揽流量、搞单子、聊客户，才能赚钱，不管您愿意不愿意。

②您觉得苦？把这个苦当成乐吧，以苦为乐，当成习惯。

③赚钱，一直与客户聊天，确实很辛苦，那又能怎么办呢？您必须这样做。要是有可能，您还要发动您家里人这样做。不过可惜，大多数人都懒惰，做不到刻苦。

④所以，凡是有钱人，都不会同情某些懒汉、不赚钱的人。说白了，不赚钱就是懒惰的代名词而已。
