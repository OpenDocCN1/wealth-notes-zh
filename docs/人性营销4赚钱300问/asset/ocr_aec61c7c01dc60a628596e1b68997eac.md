# 65、精明的老板都干啥？

+   ①能一句话说清楚您是干什么的，一句话说动顾客购买。
②竞争的本质是盯着顾客，不是情敌。死死盯住盈利点。
③以强胜弱，干自己能力范围内的事。能胜利才出手；能接受失败，才能胜利。
④管理团队，建立自然生态系统，优胜劣汰。亲力亲为，是自己给自己打工，赚自己的血汗钱。懂得支配人，支配资源。
⑤懂得建立个人品牌、文化品牌、产品品牌，用品牌赚钱。

# 66、什么样的人适合发财？

+   ①永远有方法，不达目的誓不罢休。
②您有什么资源可以被别人利用，同时利用别人的资源。
③在互联网上不断的释放价值，做信息的传递。
④选择互联网教育、知识付费项目，成本低，传播广。
