# 38、我的梦想是做讲师

学员：

陈老师，非常感谢，在生命最低谷时期遇见您。我是个做事很专一的人，06年开始做餐饮，一直做到现在。我的梦想是做讲师。我到处寻找机会，我努力赚钱，但是我不会守钱，被人前后坑了100多万。

学习您的《老板心法》，发现我的思路出了错。我以前总是那么自信，只要我努力，钱不重要。浪费，乱买东西，我可以赚，钱花了就去，拼命买一些没有用东西。现在想想好蠢，同时不保护好自己的钱。

人生没有如果，只有结果和后果。我这3年遇人不断，被坑那么多。如果2018年遇到您，可能不会被坑那么惨。

老师您书中很多内容读得我一把鼻涕，一把眼泪，此刻也一样，但是我开心，至少余生遇见您，和优秀的企业家们一起修心，一起传播陈老师方法。
