# 190、如何通过管理的模式赚钱？

+   ①我必须把自己变成一个管理者，通过管理的模式去赚钱。

+   ②我的目标，不是自己赚钱，而是我带的人赚钱。

+   ③我要通过管理解决一切问题。我每天都必须不断的学习管理，合理的，把它系统用到我的工作当中、我的合伙人当中。

+   ④我的目标，是帮助我的合作者成功。

# 191、人上一百，形形色色，怎么管理？

+   ①人上一百，形形色色。有些人没有格局、气量，没有智慧，看不到未来。有些人有心机、有反骨，很正常。

+   ②一个人有未来，是因为他各方面都是正的。他能知道仁义值千金，他能理解金钱如粪土。

+   ③只要大家按照规则来玩，什么都会有。但是有些人是天生的小人，他们不懂配合、付出，不懂得大格局。这些人也不会有什么跟随者，也不会有财路。
