# 43、如何做一个不开心的人？

①跟蠢货交往，您的人生就会特别不开心了。

②您可以做一些低收费的服务，甚至搞一些免费的服务，这样，就能吸引到很多贪图便宜的层丝。这些层丝没什么能力，天天跟您理论，讲些恶心的话题，这样，您就会不开心了。

③不要买房子，没女人跟您，您绝种了，这样，您就不开心了。

④不要努力工作，没什么收入，吃碗酸菜鱼，您都要考虑半天。因为一碗需要 80 元，您吃不起，您就不开心了。

⑤脾气暴躁，不为别人考虑，人际关系恶化，这样，您就可以不开心了。

⑥天天在家睡觉，天天向亲人、朋友、爱您的人不断的索取。他们不给您钱，就微信漫骂，电话漫骂，这样，您的亲戚朋友，都不开心了，您也就 intentions 不开心了。

⑦不搞 36 循环系统，混吃等死，啥也不做，企图天上掉馅饼。最后您发现，天上没掉馅饼，这样，您也会不开心的。

做好以上 7 点，您就可以不开心了。
