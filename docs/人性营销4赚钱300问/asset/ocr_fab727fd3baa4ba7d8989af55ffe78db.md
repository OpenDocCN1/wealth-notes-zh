# 216、赚钱的核心法则是什么（1）？

①只要您做好了一件事，比如，做好了一个抖音，就会有很多人找您买单。可惜，您一件事，也做不好。

②赚钱的核心，不过是踏实肯干、老实而已。日日夜夜锁定一个项目，不断的围绕这个项目释放价值而已。

③赚钱是干，创业是干，做项目是干。

④一个人，应该每1秒钟都非常宝贵。我以前赚钱最厉害的岁月，都是所有精力，都在项目上，争分夺秒，不浪费。没有这种状态的人，做不好36循环系统，也没什么前途。
