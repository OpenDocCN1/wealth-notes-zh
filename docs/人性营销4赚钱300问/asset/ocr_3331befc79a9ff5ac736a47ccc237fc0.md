# 294、我们的核心是什么？

①我们的核心，就是降低成本。

②降低做音频的成本，做抖音的成本，做视频的成本，降低传播成本。成本越低越赚钱。

③降低成本是因为有智慧。

④经营企业，就是降低成本。不断的降低外部交易成本，降低内部交易成本。

⑤上上下下都要有节约意识，必须要有节约意识。节约是天大的美德。丢了这个美德，就要倒霉了。

⑥我这些年来，所有的错误，都是提高成本，浪费。所有对的地方，都是降低成本，节俭。

⑦整个组织，都应该想尽办法降低成本，绝对不走大跃进。所有大跃进的思维，给我们带来的都是灾难。
