# 47、如何让自己的人生跌入低谷？

+   ①您要跟骗子交往，也就是这个骗子三番五次的骗您，骗您几年，您还跟他交往。

+   ②骗子骗您一次，您还相信他，骗您两次、三次、四次，您也相信他，您就是永远相信骗子，永远给骗子机会。骗子骗您钱财、时间、精力，您就给。这样，您就会破财，甚至破产。

+   ③买一些没有价值的奢侈品，买回来，就卖不出去了，就跌值的东西。有了钱就去买，尽量买。

+   ④招聘一些不赚钱的员工。自己赚了钱，就发给这些员工，给他们交五险一金。没事就带他们去旅游，去吃饭、去玩。尽快把自己的钱都花光。招聘一些，您说了啥，他们也听不懂、不执行的员工。然后，您还不开除这些人。员工睡觉，您也别管，让他继续睡。

+   ⑤不要锻炼身体，让自己身体越来越差；经常熬夜，让自己的头发都掉光；不孝敬父母，跟父母吵架。

+   ⑥不努力做工作，做服务，让客户都把自己吵闹。不尊重人，让别人都成为自己的仇人。
