# 252、为什么有些人一直贫穷？

①太多人想得到，却不想付出代价，捡着天上掉馅饼。

②付出，是赚钱的第一核心要素，只是大多数人都不愿意付出，认为付出难，付出痛苦。

③不愿意出钱，也不想意出力，故而，只有一直贫穷。

# 253、习惯不赚钱会导致什么？

①一个人越不赚钱，他就越理所当然，继续不赚钱。

②一个人越是赚钱，他就懂得，必须要赚钱，必须要努力奋斗，必须要给自己争取一个未来。
