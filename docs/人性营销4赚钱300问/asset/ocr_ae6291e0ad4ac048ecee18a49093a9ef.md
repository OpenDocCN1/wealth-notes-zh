# 298、我相信什么？

+   ①我们就是要踏踏实实一步一个脚印，锁定一个关键词，比如情感、恋爱，一干就是一辈子。
②创业，主要踏实肯干，而不是成天幻想。只要天天干活的人，都能赚钱。
③不得不承认，这个世界上，确实有人很聪明。他们能在短时间里事业成功，就是所谓的赚到大钱。但我们不是那么聪明的人，我们只能靠实在的干。
④我认为，普通人创业，赚钱的核心在于，踏实+坚持锁定一个项目干活+团队+有人指导+融入一个社群。
⑤融入一个社群，靠群体式的力量+智慧，去做一个项目。这样，对于普通人来讲，成功率会高很多。
⑥我还是如同既往的干36循环系统，也带着大家干36循环系统。
⑦我相信复利，相信量变引起质变，相信踏踏实实干活，而不是空想。
