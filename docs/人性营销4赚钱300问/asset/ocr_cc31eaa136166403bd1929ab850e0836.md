# 89、如何满足虚荣心？

①虚荣心每个人都有，但是要靠自己的钱、自己的能力去满足自己的虚荣心。

②向男人要钱，不算本事，除非别人心甘情愿给的。您主动要钱，就掉价了。

③向父母要钱，满足自己的虚荣，不给就闹，就发脾气。当您成年了，您就不应该这样做了。

④虚荣是好的，您自己去激励自己，自己去赚钱，自己去努力，而不是投资感情、投资亲情，甚至借钱去满足自己的虚荣心。

⑤关于整容，您是怎么样，就是怎么样，没必要弄虚作假给自己来一刀，满足您的虚荣。这种虚荣，显得愚蠢了。
