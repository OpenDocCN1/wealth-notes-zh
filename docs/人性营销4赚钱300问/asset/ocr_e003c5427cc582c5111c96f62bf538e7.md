# 195、为什么要搞原始资金积累？

①首先告诉大家，互联网自媒体时代，其实，您不需要有多少钱，就可以创业。文章、视频、音频，抖音发，今日头条发，贴吧发，全网推广，您就可以赚钱。可以搞社群，可以搞教育培训，也可以贩卖一些实体东西，甚至可以给人做代理赚钱。

②但是，您若真想创业，做一个企业，您必须要有原始积累。养成赚钱不花钱的习惯。对的，您没看错，首先，不要交往乱花钱的女朋友。有些女人花钱很厉害，思维模式是，花了就会赚更多。 她们会把钱拿去买这些烫用的包包、首饰、衣服，浪费掉辛辛苦苦赚来的钱。其实，不要做奢侈生活享受的消费。很多人没有富，但是呢，赚了点小钱，就开始享受生活，结果，浪费掉了可贵的原始资金积累。

③原始资金的积累，可以用来养员工，可以用来慢慢发展自己的团队。有了团队，就有了自动赚钱机器，您的力量就会越来越大。富人思维模式是用原始积累建立资产，这些资产慢慢给自己带来无限的现金流。而穷人不注重积累原始资金，打造自己的资产，那么赚再多的钱，也只能白白流失、贬值、浪费。
