# 116、创业的本质是什么？

①创业的本质，是比其他人更会管理时间了。您的时间在哪里，成就就在哪里。

②现在讲碎片化时间，大家记住，不要让自己的时间被碎片化了。碎片化，是很难做出成绩的，应该让自己的时间整块整块的使用到自己的项目上。

③要学会拒绝别人浪费您的时间。比如，别请您喝酒、吃饭，或者做些对您没什么好处的工作，都要拒绝掉。因为，这什么也不能给您带来。

④管理好时间的核心，其实是放弃。您必须懂得放弃一些人、一些事、一些想法，还要扛得住诱惑。只锁定自己的项目、自己的事业，长此以往，您就会有成就。
