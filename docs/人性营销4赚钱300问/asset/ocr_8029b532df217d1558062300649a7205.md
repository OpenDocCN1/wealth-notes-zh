# 8、什么是心灵美？

①心灵美很复杂，不是多少人想的心肠好就可以。

②实际上富人欣赏的心灵美，是素质。综合素质，需要文化知识做底蕴。

③缺乏科学文化知识和社会经验的心灵美，没啥价值。

④一般人自认为的好心、良心，也没什么用。您的素质不够，不懂道理，做不好事情，对很多事情一窍不通，您也干不出来什么好事。您的良心，也就没有Speed什么价值。

⑤一个好心人、有良心的人，必须是一个有综合素质的人。
