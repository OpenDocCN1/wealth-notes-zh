# 前言

一个无能的人，年轻的时候靠体力、靠年轻还能够混混日子，年纪大了，上有老，下有小，就会过得很凄屈。再一个，因为自己的无能，也教育不出什么有用的儿女后代，老了的时候，儿女都不肯养这样的“无能的父母”，这种事情在中国

赚钱，不光是为了自己，首先是为了父母不再吃苦，安享后面的人生。老年的时 候能够有钱，享受晚年，能够健康的活着，多活七十年。贫穷的人的父母大多数都是短命的。

其次，是为了自己的妻儿，不受经济压迫，不为了几个钱在社会上奔波，有心停下来欣赏这个世界。

最后，是在赚钱的过程中，成就自己的事业，成就自己的人生。

所以，无论男人，还是女人，必须会赚钱，能赚钱、赚很多的钱，这是人生的使命，勇敢的扛起来吧。抱怨父母已经没有什么用了，他们已经尽力了。世界从来都不公平，这种不公平是代代相传的，父母又去抱怨谁呢？既然我们明白了，那么我们就靠自己攀登上自己想要的王座吧。

送几句话给大家：工作必须努力，做事必须用心，创业必须成功，因为我们的父母不是大富大贵，我们没资格继续贫穷，已经贫穷够了。

最后，希望《赚钱心法 300 问》能帮助到大家！
