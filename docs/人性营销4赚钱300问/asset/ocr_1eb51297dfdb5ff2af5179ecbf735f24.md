# 21、打翻身仗最难的是什么？

①有些孩子，真的那么贫苦，一点钱都没有，启动资金都没有，电脑都没有。只有201个破手机，工资也没有，房租都交不起。赤贫状态，这种人，想要翻身，是非常非常困难的。

②有时候，也有非常大气的人，我想救他们，但这种人环境太差，真想起来，其实非常难，非常难。有时候，心地善良、老实，也解决不了问题。

③物质的贫穷 + 智慧的贫穷 + 精神的贫穷，想要翻身，真是难之又难。

④物质的贫穷，不是真恐怖。最恐怖的就是精神，就是智慧的稀缺、不具备。这样的人，想要打翻身仗太难了。他们根本就玩不懂抖音，玩不懂视频、音频，更加没有营销思维。

⑤我们只有骗出命来搞，抢知识，才会成功。这必须要耐心，必须磨练心智，真的好难。

⑥要聪明、智慧、肯拼，还要听话、照做、执行，才能改变命运。
