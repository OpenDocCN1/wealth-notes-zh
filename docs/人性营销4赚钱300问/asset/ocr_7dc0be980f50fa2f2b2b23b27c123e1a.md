# 71、如何进行整体式推销？

+   ① 高手做生意，搞传播，一定不是自己一个人搞的。
② 高手会迅速的传播自己的产品，一定是通过一群人，去宣讲自己的产品。
③ 在微信里不断的更新如何做这个生意，怎么做。价格、服务、背景介绍、一系列的介绍，不断的拉新，不断的做新的代理，如此，日日夜夜的循环下去，就能带动更多的人参与到这个游戏中。
④ 高手，永远是大数据局的销售模式，永远是群体式、整体式、联动式、循环式的销售。
⑤ 永远去找更强的人合作，让更强的人参与这个游戏。
⑥ 当您具备了高手的思维，然后具备高手的行为 ľ，您就会赚钱。

⑦ 作为一个新人，我希望您们一个一个的营销，去积累自己的客户、粉丝。作为一个老手，我希望您们在积累粉丝的同时，还能积累粉丝周围的人。
