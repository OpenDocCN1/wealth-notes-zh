# 12、人类的历史，就是争取利益的历史

人是为自己的利益而奋斗的，也代表自己的利益发声。扩大利益的方法，就是联合。联合更多的人，就能扩大自己的利益。为少数人奋斗，是脱离群众；为多数人奋斗，是群众路线，是群众基础。

互联网经济的本质是少了很多压迫的环节，故而生生不息，故而有利可图。环节少了，赚钱就多，大家就开心，所以做生意，就是要环节少，然后还有群众基础。

群众基础越大，力量越大，但是，必须要带着这里面部分人发财，也就是中小企业老板。这些人要发财才行，这就属于做精准流量的范畴，还要不能得罪大量群众基础流量。这样做，力量是最大的，也能吃饱。
