# 292、我讲课的目的是什么？

①我讲课的目的，是让我社群里的所有人，都发挥出来自自己应该发挥出来的力量，把本就有的本事发挥出来。

②把本来就有的时间用来执行 36 循环系统，而不是浪费时间，没有什么收获。

③我记得国外有个企业家讲过一句话：每一步骤都必须赚钱。我改一改：每一秒钟，都必须释放价值，吸引粉丝，然后才有机会做变现。

# 293、我们社群追求什么？

①我们整个社群追求什么？追求时时刻刻都在释放价值，都在搞营销，都在帮助粉丝。
