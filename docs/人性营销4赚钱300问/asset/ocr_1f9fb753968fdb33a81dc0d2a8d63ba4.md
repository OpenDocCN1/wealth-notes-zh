# 76、您是不是老实人？

+   ①老实人是踏踏实实做事、不偷奸耍滑的人。

+   ②老实人是讲真话、不作假的人。

+   ③老实人，其实都有很多人喜欢，都有很多人愿意跟他合作。如果您在生活中，并没有多少人喜欢您，并没有多少人愿意跟您合作，说明您不是一个老实人。

+   ④真老实的人，无论是事业，还是人际关系，还是社会地位，都会非常好。

+   ⑤大多数人说自己老实，不过是无能的借口、不想干活的借口、不做事的借口。彻彻底底的一个失败者，往往喜欢说自己是个老实人，这样，他就占到道德制高点，认为自己输了还理所当然，求得跟他一样心理的人共鸣。不要用虚伪的借口，说自己是老实人了，很多人不配使用这个词。
