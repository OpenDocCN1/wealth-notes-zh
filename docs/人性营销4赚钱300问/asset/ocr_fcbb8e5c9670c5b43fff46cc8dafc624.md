# 人性营销系列

学营销，就进《陈老师方法 72 大营销系统》读书社群！

![](bbox=[0.23, 0.215, 0.702, 0.495])

陈老师读书社群和老板社群，研究的是三大管理哲学思想、陈老师方法，也就是价值 + 营销。三大管理哲学思想统领《陈老师方法 72 大营销系统》，以及营销系列、赚钱系列、讲师系列、老板系列、恋爱系列。三大管理哲学思想本头就是王道思想，而营销是术，这道术一体结合，就自成一体，成为最强大的营销学。

陈老师方法 72 大营销系统，是教老板做营销的，做自媒体、互联网营销，做品牌营销的。每一个系统都是教老板们如何做自动成交的。也就是教您安身立命、赚钱的本事、营销的本事、把事业做大做强的本事。
