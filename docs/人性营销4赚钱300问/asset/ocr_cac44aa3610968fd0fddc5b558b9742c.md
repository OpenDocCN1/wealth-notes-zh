# 179、创业者的目标是什么？

①刚创业的时候，人越少越好。老板先做业务，先搞清楚钱是怎么来的，而不是盲目的扩大规模，招聘员工。

②不要以为员工、合伙人、其他人会自动赚钱，只有老板知道如何赚钱。老板的目标，就是带着所有人，跟著自己只做一件事情。或者做品牌化，内容运营，做流量，做变现。或者做营销，卖产品，卖服务。反正，所有人都必须在老板的思维模式下，只做一件事。
