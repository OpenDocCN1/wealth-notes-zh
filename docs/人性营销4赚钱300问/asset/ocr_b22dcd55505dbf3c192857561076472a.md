# 1、人 ocurrir什么最重要（1）？

①交友。人是会被朋友影响的。
您交往的人，喜欢欺骗、不诚信，慢慢的，您也会变成那样。
您交往的人，好逸恶劳、贪慕虚荣，慢慢的，您也会变成那样。
一个智慧的人，应该一开始，就交往一个有素质、有道德的人。
远离那些具有腐败品质的人。

②读书。人一定要日日读几本好书。
我的策略，就是日日读书，情绪越来越好，事业也越来越好。

③努力赚钱。钱可以说是非常非常重要，过分点说，是一切的根基。但是大家不喜欢这样讲，觉得这样丢脸、无耻，心里只有钱。
很多人高尚的说："钱不是一切，钱不重要。" 但是等他们想要钱的时候，却没钱。
对于故视钱的人，我们要远离。我们就是竭尽全力的工作，拼命奋斗，为的就是多赚些钱，让自己以及跟自己具有核心关系的人，生活过得好些。

④照顾好自己。人首先要照顾自己的健康，照顾自己的金钱，照顾自己的情绪、自己的父母。人不是先去照顾别人的，比如，照顾您的女朋友、您的员工、您的同事。不要讲我伟大的话题。
