# 112、如何讲话？

①只讲人好话，不讲人坏话，路子宽。

②您说人坏话，在教育人、在帮助人，但是，大多数人不识好歹，会找您麻烦。您没必要浪费自己的时间，去得罪人。

③除非跟您很亲近的人，自己的核心团队、自己的亲人，您有必要去批评、教育。其他人，您就别去批评、教育了。

④讲话，只讲真话，不讲假话。有些真话得罪人，就沉默，不讲就行了。

⑤讲话是用来赚钱的，不赚钱的话，就别讲了。

⑥赚钱不是一个狭义的概念，让身体更健康，也是赚钱。
