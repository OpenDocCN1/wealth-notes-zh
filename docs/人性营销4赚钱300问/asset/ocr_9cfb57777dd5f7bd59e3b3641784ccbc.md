# 203、什么是奋斗？

①所谓 的奋斗，只是为了生存，希望能够拥有更多的食物，好让自己生存下去，希望自己有更好的生活罢了。

②想过更好的生活，有什么错误吗？看不出这有什么错。所以，大家努力的去做抖音吸粉，去做喜马拉雅等课程吸粉。

③变现、赚钱才是最重要的，这是我们所有人的唯一出路。

④但是，一切必须通过自己的努力得来，而不是去坑蒙拐骗得来，那不是奋斗，那就是犯罪。
