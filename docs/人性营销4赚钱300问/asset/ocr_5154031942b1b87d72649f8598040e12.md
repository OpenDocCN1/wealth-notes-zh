# 206、钱可以买到感情与人心吗？

①当您特别贫困的时候，您感觉很温暖，因为大家都一样穷。

②若是有一天您富了，您给以前的人钱财，您会发现，您买不到人心与感情。他们甚至还会诋毁您，恶心您。

③这个时候到底是怎么回事？其实，是您的阶层提高了，您还在以前的阶层玩，是您错了。

④您是什么阶层，就到什么阶层去玩。切莫用金钱去买比您阶层低的人的感情与人心。

⑤做一个好人，是用心态、态度、尊重、礼貌、公平合理的人格去做的，而不是用金钱去收买。

⑥用金钱收买的人心与感情，甚至是爱情、亲情，都是恶心而无意义的。
