# 90、创业者要远离什么样的人？

①不诚信的人。骗子是最恐怖的，骗您时间，骗您钱，毫无价值。
一般情况下，一个骗子，您跟他交往的时候，一开始，您就会发现，他就是一个骗子。但是，您可能觉得，他总是有地方，您可以利用，所以就长此以往的交往下去，最后，损失惨重。高手与普通人的区别在于，高手不贪利，知道骗子是个隐患，于是，干脆一开始，就不交往。

③一个人不能给您赚钱，您就不要大把大把的砸钱在他身上。
这也是规律。除非，您能看透这个人的品行。这个社会上，确实有高手是这样的，普通人没这个本事。普通人，大多数都是给别人造成了损失，而不能对别人贡献什么。所以，一开始，您就要明白，不要把钱砸在别人身上。有钱，砸在自己身上，自己的父母身上，与自己有血缘关系的人身上。
