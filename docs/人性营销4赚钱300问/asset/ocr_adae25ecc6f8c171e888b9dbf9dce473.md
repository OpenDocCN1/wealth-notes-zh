# 214、赚钱的秘密是什么（3）？

①不外乎，就是一辈子只做一个项目，一辈子只锁定一个关键词。

②我们柴一点，绝对不多元化。踏踏实实干项目，干 36 循环系统，以后什么都有了。没有项目，没有出单，没有收入，一无所有。

③没有什么，比一辈子锁定一个项目、一个关键词、一个社群更重要了。没有什么，比执行 36 循环系统更重要了。

④只要您聚焦，只要您开始努力工作 3 个月，然后，您有了收入，您才会愉快。否则，您就一无所有。

# 215、赚钱的逻辑是怎样的？

①长期坚持聚焦一个环节。

②时间长了，大家信任您了，会产生复利效应。

③赚钱，不过是一直谈业务，一直释放价值，一直找客户而已。

④赚钱，不过是讲清楚了，客户买单而已。
