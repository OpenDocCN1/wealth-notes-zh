# 113、您擅长什么事情？

一个人只有做自己擅长的事情，才能做得非常好，而且能持续一辈子。我擅长什么呢？

①我擅长打游戏，我读高三的时候，就开始玩《传奇私服》。那个时候，我根本不知道什么是官方服务器，我眼中只要是个游戏就行了。我玩《传奇私服》的时候，基本都是那个游戏里的名人，我主要玩战士。

②后来我玩了《魔兽世界》，我主要玩盗贼。我玩游戏的唯一目标，就是击杀玩家，不管是大号、小号，我都喜欢在背后捅他们几刀，直到他们都躺下，变成尸体为止，我才默默的滑落着，守护着他们的尸体。

如果可能，我愿意玩一辈子游戏。玩游戏，也可以做代练，打等级、搞工作室、倒卖金币、账号，也是一个暴利的生意。只是会被官方打压，不过，某坐上，做这种生意的依然爆满了。

③我是一个喜欢哲学的人，喜欢读书。中国古代经典、西方牛人写的商业理论，我都读。读了就分享。我也有很多微信、QQ群、QQ空间、其他社媒体平台上的粉丝。我的粉丝也不断的在分享我的哲学思想。

④我大多数时候都在读书，少数时候，在写作、创作。
