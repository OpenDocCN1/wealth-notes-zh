# 34、赚钱的本质，就是收单子

# 学员：

陈老师，我天天去研究干货，讲了一两个月，没人买单。我今天把您的营销话术抄下来，放手机上边，讲几句书里的内容，就去念一段您的营销话术，居然就出单了，太神奇了，直接问也是只有七八个人。

# 陈老师：

赚钱很容易，只是大部分人都听我的课，也不认真，不听指挥，只会蛮干。你们的秉性注定你们这些人无论如何都赚不到钱。社群废物第一人，可怕得很。也就是，我说的任何一句话，他都听不懂，做不到，不知道我在说啥。社群里还有很多这种废物。其实，只要稍微用点心，用点头脑，把我讲的营销话术＋留人话术＋营销逻辑＋广告干货＋潜营销、品牌营销，这些东西都上去，就能赚大钱了。只是，并没有多少人愿意听到我到底说了啥，可耻。

注意，赚钱只跟广告、营销逻辑、推销有关系。这玩意弄不明白，不赚钱。赚钱的本质，就是收单子。
