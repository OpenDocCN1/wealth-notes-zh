# 299、如何分配利润？

公司的成本、利润，都核算到个人，杜绝大锅饭。每个人成本、利润都要一清二楚。

+   ① 每个人吃了多少钱、住了多少钱、花了多少钱的成本，支出了多少钱，都明确记录，平摊到个人，是可以每天都看清楚个人账目的。

+   ② 每个人产生了多少收益，都明确记录。也就是这个人为公司赚了多少钱，明确记录。

+   ③ 这个人的收入 - 成本 = 毛利润。

+   ④ 毛利润的一半，用来发展公司，扩大生产。毛利润剩下的 一半分为红。

+   ⑤ 分红的 70%，分为干活的人。30% 分红为资本分红。

+   ⑥ 我干活了，最多只分这个人的 10%，为体力、智力收入。

+   ⑦ 欢迎所有人进行资本投资，来分剩下的 30%。资本投资，也就是按比例分这 30%。比如，我投资 20 万，您投资也是 20 万，那么，这 30% 就分 15%。人多了，以此类推，给所有人资本投资的机会，投资过后，不能撤资。

+   ⑧ 记账方法，是完全到个人的，也就是我们要每日记账，而且要让每个人看到自己的支出与收入。
