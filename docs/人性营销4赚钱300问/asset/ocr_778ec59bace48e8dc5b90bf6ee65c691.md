# 107、为什么做事要找方法？

①赚钱是有方法、有套路的，这是一门技术，跟玩游戏一样。您必须模拟高手，模拟会赚钱的人的套路、思维模式。

②恋爱也是有方法、有套路的。您不懂，您可能跟我有个兄弟一样，永远迈不出第一步。

③吃饭也是有套路、有方法论的。怎么吃，一天吃几顿，都是有方法论的。

④睡觉也是，我以前听了某位大佬的话，在车上也睡觉，经常抽空时间睡觉，结果，精神不好了。反倒是，我白天不睡觉，晚上睡得沉，结果，精神非常好。

⑤这世界上，万事万物都是有方法论的，有些作家写作为什么那么厉害？因为他们的写作是套路化、方法论化的。而我们普通人写的东西为什么没人看？那就是因为我们自己是瞎写。

# 108、为什么要总结？

①总结能让人知道自己的成绩，而不只是一味的干活。
