# 34、为什么很多人被割韭菜？

①不是您愿意不愿意的问题，而是您根本不学习，导致了智力落后。

②落后就要挨打，互联网上也是这样。

③互联网时代，您不懂粉丝，不懂互联网营销、朋友圈营销、自媒体营销，视频、音频营销，您注定只能被割。无论您愿意不愿意，反感不反感。

④这就是一个高智力碾压低智力的时代，而且是从互联网上直接碾压。

⑤好在什么呢？好在，您可以通过学习，不被人收割，反而可以释放一些价值，让自己盈利。

⑥缺乏耐心、没有阅读力、不能安安静静地把材料变成视频的，不能玩视频平台、音频平台、社交媒体、朋友圈的人，都会变成扎扎实实的韭菜。

⑦缺乏学习能力的人，不会拥有这个时代的智力资产、社交资产。

⑧我们之所以能在互联网上生存，甚至赚一些资金，就是因为我们有整合价值的能力，有释放价值的能力。任何人，如果愿意干、愿意学，也可以拥有这个能力。
