# 189、为什么普通人做不了管理？

①看得起小钱，小钱也要赚，大钱也要赚。小钱赚多了就是大钱。用管理的心态去规避风险，踏踏实实每天出单。不出单的人，都不是好人。

②靠组织赚钱，靠管理赚钱，靠多人合作模式赚钱，但也只锁定一个关键词。关键词锁定多了，保证不赚钱。

③打造自己的组织，这就是优秀的管理者。打造组织是一个非常困难的过程，您必须判断出来谁最优秀，谁可以给您赚钱，谁是亏本货。

④普通人的内心世界，是没有办法打造组织的，因为他们讲情感，不讲金钱。一个 人必须得非常理智，才能做好一个管理者。

⑤那些不能带来利益的人，应该清理掉，开启除。但普通人的思维模式、行为模式认为这是残忍的。所以，普通人做不了管理者。
