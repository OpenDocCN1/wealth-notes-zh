# 44. 一辈子跟您学习，
把这笨笨的浆糊脑袋洗洗

学员：

太感谢陈老师，现在我找到喜欢的事业，一辈子只在这条道上走。我鞠点，一条道走到黑，一条道走到亮，我相信陈老师。就像我开旅店一样 06-14 年亏亏赚赚，一报 40 万左右，14-19 一直赚，一家开 3 家。没有智慧，坑害的鬼也来了，好在，遇见陈老师大爱，有使命的老子。这个不用投资，一辈子跟您学习，把这笨笨的浆糊脑袋洗洗。

《老板心法》中您写到，只有当您层次高点的时候，那个阶层的信念才是可靠的。从底层爬起来的孩子，最可怜的是什么，就是他已经经历了世界的恶，然后才能品味到世界的善。前天，坑我的人又像以前一样，打感情牌还是坑我，我直接挂黑。昨天清理电话手机号码 2486 个，现在只剩 98 个了，做减法系统，我鞠，我照做，一点点去做。

老师我再请一本《老板心法》给孩子。我父母没有教我穷人思维、人性，即使我努力，仍然被社会上的错误思维坑完了。孩子在老家，以前不听话，以前我找不到她没有办法。她回家，我偷偷
