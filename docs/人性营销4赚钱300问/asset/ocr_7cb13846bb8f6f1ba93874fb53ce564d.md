# 14、为什么说命运在您自己手中？

②您必须接近富人，因为财富和机会都在富人手里，一不小心，漏给您个机会，您就改变命运了。

③其实我们每个人都可以改变自己的命运。可惜，每个人都有借口，对自己不够狠。

④疯狂的锻炼身体，疯狂的工作、阅读。在互联网上，您总是能找到机会。

⑤但大多数人都是犹豫，今天跟明天一天样，所以，无所渴改变。年纪大了，就后悔，就是这样了。很多人就是这样。

①我们可以把自己的工作，安排得井井有条，也可以无所事事，让时间过去，而一无所有。

②每天早上 5 点起来，就可以开始研究传播学 + 广告学。

③可以形成文字 + 视频，不断的传播。

④当然，您也可以睡觉，什么也不做，挣不到钱。

⑤赚钱，总还是靠毅力，靠持续工作的。慢慢的，有钱了，体系打造好了，才可以做出来一个自动赚钱机器。
