# 72、用人的核心是什么？

+   ① 用人其实就是用管理人才。
② 用管理人才的前提是识别人才。
③ 识别人才的前提是招聘人才。
④ 用人是最大的学问，会用人者，什么都有了。
⑤ 我认为，用人的核心，是自己是个人才。您自己不是人才，您很难辨别出人才。您自己不是人才，人才也不会跟您。
⑥ 您自己是人才了，我们才能谈你的善良、诚恳、信任、知人善任等等道德问题。

# 73、如何激励员工拼命干？

+   ① 一种人拿底薪，无提成。一种人，高提成，接近无底薪。
② 跟员工签字画押，写好方案，让员工反复确认，多次签字。这样，来激发有些愿意拼命的员工。不愿意拼命的员工，慢慢也就离开了，或者被开除了。
