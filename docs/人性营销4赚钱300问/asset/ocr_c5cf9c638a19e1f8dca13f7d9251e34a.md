# 115、什么是企业？

+   ① 企业就是运营一群人，去做一些事。我专业运营一群人，跟我做读书社群和老板社群、情感项目、教您做抖音项目。
② 我们只搞 36 循环系统，日日夜夜干活。
③ 创业刚开始，团队很困难，因为大家都不赚钱。所以，我不建议多人上场。我就建议一个人上场，赚到钱了，再带一个人，慢慢带。走慢点，走稳点。
④ 创业是要有理论的，所以我认为聚焦理论最了不起，锁定一个项目，一个极小的点，一直干，一般都能活下来。有方法论，有理论，有干劲，成功水到渠成。而没有方法论、理论的人，即便是相反有干劲，也很难。创业很难，应该找一个靠谱的理论。
