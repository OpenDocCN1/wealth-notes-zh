# 87、如何不再懒惰？

+   ①给自己定一个目标，洗脑自己，要达到这个目标。
②找一份能赚钱的工作，或者兼职，不断的做。
③您可以立刻去码字，规定自己每天写三万字。
④写作可以洗脑自己，比阅读的功效还好。
⑤找一件可以帮助人的简单的事情，不断的去做。比如，在网络上写作帮助人。懒惰的人，大多是因为自己找不到简单的事情做。
⑥找到这件简单又可以帮助人的事情，重复做，形成习惯。这样，您就懒惰不不了了。把懒惰的时间都换成钱。
