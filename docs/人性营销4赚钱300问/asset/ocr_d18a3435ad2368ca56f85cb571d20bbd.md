# 6、利出一孔，力出一孔

利出一孔，力出一孔，就是我们只能做一个项目，只能做一个点。产品组合、业务规划，利出一孔，力出一孔，只锁定一本书、一个项目，卖产品矩阵。这样，我们应该会获得极高的收入。

我们的产品组合，就是我们的书籍、陈老师读书社群、老板社群，就是我们的产品组合。

我们解决的是老板做抖音的问题+情感问题，主要是分享这个简单的模式，在这个点上猛攻就可以了。

我们企业、我们社群的社会责任，是教老板做抖音，做互联网营销，做情感项目，讲书籍，这就是我们要实现的社会责任。

互联网是无边界的，成本极低，所以，又能给我们带来一个规模效应+品牌效应。

大家要决策一个项目，做到彻底的聚焦，也就是你的卖点只能是唯一的。我们的流量渠道只是抖音视频、直播。我们的变现方式，就是陈老师读书社群，进群分享。
