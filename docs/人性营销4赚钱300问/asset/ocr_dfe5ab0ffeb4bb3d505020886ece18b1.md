# 84、爱发脾气是怎么回事？

①有脾气不是什么光荣的事，不是:什么特长。有本事、有能力，才算光荣。

②发脾气，本身是一种性格缺陷，是一种智力缺陷。高手，应该 是想办法解决问题，而不是发脾气。

③发脾气，是一种无能为力的表现。我观察过一些富人、一些穷人，我发现，穷人经常面对弱者、面对爱自己的人肆无忌惮 的发脾气，喜欢伤害自己的人，甚至自己的父母。而富人，性格 更好，更不容易发脾气，即使是自己受到了损失。

# 85、为什么不要抱怨？

①不要抱怨自己出生农村、苦。要自己去城市里打拼，去改变。

②不要抱怨自己父母没本事。要自己去努力工作，跟著社会 趋势，去改变自己的命运。
