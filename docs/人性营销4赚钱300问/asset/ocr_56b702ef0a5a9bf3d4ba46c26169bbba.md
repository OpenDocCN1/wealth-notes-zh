# 102、什么叫做事能力？

+   ① 优秀的人，就是拥有高尚的品格、有做事能力的人。
② 很多人对做事能力不理解，做事能力，就是赚钱能力。
③ 什么是赚钱能力？就是银行卡里的数値、您的现金、您的资产，就是赚钱能力的体现。
④ 优秀是可以衡量的。不能衡量的优秀，都是骗人的。
