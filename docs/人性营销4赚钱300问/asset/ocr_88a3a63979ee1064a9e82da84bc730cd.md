# 44、何为倔子?

①倔子，就是那种不释放价值，不努力帮助别人，而直接推销的人。这样的人，就是倔子。

②真正的高手，就是不断的为社会做出贡献、呕心沥血的释放价值、整合好东西、释放出去、自动成交的人。

③倔子，一上来，就推销东西。显得恶心，显得尴尬，显得您不想搭理他。

# 45、如何变成一个倔子?

①物以类聚，人以群分，首先，您要找到一帮倔子，并且学习他们。倔子一般是低收入人士，或者无收入人士。比如，只会睡觉，只会看电视剧，只会逛街，只会吃饭。找到这样的人，然后复制他的人生观、道德观、思维模式与行为模式。

②不讲信用，蛮不讲理。比如，答应别人的事情不去做，不断的找借口不执行。让稍微有点本事、有点财力的人都离开自己。
