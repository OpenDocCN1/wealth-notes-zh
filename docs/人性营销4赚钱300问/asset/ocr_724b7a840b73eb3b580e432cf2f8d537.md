# 1、我们指挥的就是经济战争

商业，就是我们的一个政治、战争游戏，当然，也是战略、战术的游戏。

做社群，是做政治，做经济。政治上正确，经济上强有力的流量、变现，也就是搞视频、直播，搞陈老师读书社群、老板社群，进行变现。唯有变现，经济力量强大，我们才能生存。

教人做抖音，不过是找到各种各样的方法、商业模式、变现途径。陈老师读书社群，就是一个非常好的变现途径。书籍内容，也是一个非常好的变现途径。

出个别政策是解决不了问题的，要从根本上解决问题，不是一两个政策能行的。

谁有话语权，谁的权利就更大。谁有经济权利，谁的权利就更大。本来，社会对比的就是经济权利，所以我们要找最赚钱的项目，做流量、变现。
