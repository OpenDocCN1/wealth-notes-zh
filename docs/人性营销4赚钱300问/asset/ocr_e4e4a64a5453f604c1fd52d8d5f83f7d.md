# 56、如何判断一个人的思维模式是正确的？

①每天，能给自己带来一定的收入，才是聪明的。带不来收入，都是没有意义的。

②乞丐说的要是TTL的，为什么他还没钱，还当乞丐？判断正确的人，早就会发财了，不可能没钱啊！

③金钱和权力，是正确解决问题的报酬。凡是没钱的人，就证明他的思维模式、行为模式是错误的。

④我们想挣钱，我们就要用正确的理论指导自己。所以我的创业理论，就是聚焦理论 + 行业赛道。

# 57、我们应该跟谁学？

①判断正确就会有钱，判断错误就会没钱。

②张三有钱，就证明张三的判断是正确的；李四没有钱，就证明李四的判断是错误的。

③谁有钱，我们跟谁学，做谁的思考，于谁的项目。
