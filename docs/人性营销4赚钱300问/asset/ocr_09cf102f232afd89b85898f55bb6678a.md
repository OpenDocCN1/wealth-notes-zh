# 181、管理是不是就是都让别人干？

①我妈妈去买纸，总是买些便宜的，我用着非常不爽。后来我就自己在某平台买原浆的纸，用起来，就非常爽。从妈妈买纸，到我买纸，经历了3年多，我才学会。

②我以前做项目，很多事情，都交给员工去做，交给同事去做，交给合伙人去做。有些东西做的我心里很不爽。然后，我现在也学会了自己去做。

③我以前学的管理思想是，一切让别人干，别人干好了就行了。我现在的管理思想是，我就自己干，我自己干好了，收入增加不少。

④我发现理论体系与实践体系完全是两回事。当然，我的精力也会用来不断的培养团队，培养大家做讲师，搞视频、搞音频、搞转化，提升整体社群收入。
