# 35、何为韭菜？

+   ①不愿意学习，以为自己能保护自己的资产，岂不知，社会在变，会以各种各样的方式割您。

+   ②一个人，只要不学习，就会被割韭菜。没有人可以逃脱这个宿命。

+   ③做视频，做音频，就是割那些刷手机的人的韭菜。

+   ④营销不过是智力收割。

+   ⑤您要么加收入割，要么被收割；要么当韭菜，要么割韭菜。

# 36、您是真懂还是假懂？

+   ①其实懂得都沒有用。您懂得为什么没用？因为您的现状，就是您懂得东西兑现的价值。

+   ②您要想混的更好，您现在懂的东西，都是没用的。

+   ③现在懂的东西，只能导致现在的结果。要想混的更好，就必须懂得原来不懂的东西。
