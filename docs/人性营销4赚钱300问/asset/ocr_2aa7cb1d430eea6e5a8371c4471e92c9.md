# 35、有人骂我，我也很开心啊

# 学员：

老师您做个好人、说实话，都这么难。那個骂人的 人太可恶了，您太不容易了。

老师，学生无能，没能帮上您！但是学生希望您开心，因为您救了多少人的视椎和痛苦，而让他们快乐起来了。那些骂您的人配不上您：您是天使，他根本离您十万八千里，够不着。老师，我说这么多废话！只要您开心就好，致敬！

有人骂我，我也很开心啊。他们偏执、愚昧，也说明我做的不 是足够好啊。一般情况下，骂我的人，过得都没我好，让他们 嘴巴上爽爽吧。毕竟，我已经这么有思想、有经济能力，他们骂我，我为什么要生气呢？
