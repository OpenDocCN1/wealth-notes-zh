# 82、人们喜欢什么人？

+   ① 善良的人，也就是人畜无害。这样，别人才愿意接触您。
② 讲信用，您说了的，就去做。让人们看到您去做，人家就会信您。
③ 乐于助人，也就是您天天都在帮助人。别人接触您，就能受到您的帮助，别人就开心。人都是趋利避害的，天下熙熙皆为利来，天下攘攘皆为利往。
④ 教人赚钱，给人最先进的赚钱秘密，让人生存。这样的人，大家也喜欢。
⑤ 教人养育后代。聪明人，最喜欢干的事情，就是养育后代，这是生物的本能。
