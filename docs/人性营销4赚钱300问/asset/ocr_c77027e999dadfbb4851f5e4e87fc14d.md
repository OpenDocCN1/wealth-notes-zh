# 67、为什么一定要做好公司？

公司做好就是对起所有人，一定要做好公司。

①互联网完全可以干零成本的生意，或者低成本的生意，成本不用投入太大。最低成本运营自己的生意，才是聪明人。

②流量，与内部文案系统，做到极致，自然赚钱，没有悬念就直接能赚钱。

③创业不容易，带着小伙伴们努力工作，不容易。我们出来混社会，很多人不给我们脸，但我们自己要给自己长脸。有的人问我要尊重，我想，没什么尊重的。尊重就是自己踏踏实实努力，不断的做好自己媒体创业，如此而已。

④有能力搞团队化运营的，就搞团队化运营。有能力搞公司化运营的，就搞公司化运营。起步创业，自己一个人就行了。

# 68、创业者如何养员工？

①我从来不建议一个创业者上来就养员工，慢慢来，比较快。
