# 77、格局是什么？

+   ① 格局就是您遇到挫折，无所谓的心态。

+   ② 格局就是您的高度与宽度，您能容忍一些普通人容忍不了的事情。

+   ③ 格局并不是您的智商高、情商高，而是您为了最后的成就，愿意牺牲什么。

+   ④ 有格局的人，更加有战略眼光，也更容易笑到最后。小事业靠聪明、勤奋，就能做到；大事业，就一定要有格局。

# 78、什么人是有格局的？

+   ① 一个人不喜欢赚钱，是不负责任的体现。

+   ② 有格局的人就有事业。没有事业，说自己有格局都是骗人的。

+   ③ 有格局的人，必定运气好，跟随的人多。
