# 93、工作是什么？

①很多人不理解为什么要工作？工作就是您的生命本身，您不工作，就没钱赚。

②工作能让您身体健康、心理健康。有个美丽的小女孩，老板养着，自己不用工作，忧郁了。

③工作能让您的头脑灵活。

④工作能锻炼您的交际能力，处理问题的能力。

⑤生命在于运动，而工作本身就是一种运动，不管是脑力，还是体力。您不工作，您基本就废了。

⑥工作是上帝赋予人类最美丽的礼物。工作使人快乐，特别是当您认真工作，有收获的时候。工作的过程，已经足够迷人，足够让人心醉。工作的结果，更会使人会心一笑，当然，您要认真工作。

⑦工作可以让人养家糊口，结婚生子也有底气。
