# 86、做人为什么不要优柔寡断？

③不要抱怨自己的女朋友丑，那是因为自己没经济能力，“购买”不起漂亮的女朋友，或者说，自己配不上漂亮的，要努力去改变。

④不要抱怨自己的员工没本事，不努力。求之于势，不责于人。本质，是自己的策略、战略、思维有问题。

⑤当您收起来抱怨，学会去思考、去改变，您的人生就会变得越来越美好了。

①想好了就去干，不管是工作，还是项目，就立刻去干。

②优柔寡断，浪费时间，一晃，一年过去了；一晃，年纪大了，一事无成。

③人比的不是懂多少道理，懂道理当然重要，但只有去行动，才会变现。

④不要跟优柔寡断的人做朋友。创业、打江山，跟优柔寡断的人一起 Man is 必定您一事无成。
