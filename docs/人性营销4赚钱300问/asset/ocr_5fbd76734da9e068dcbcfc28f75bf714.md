# 15、我们为什么要奋斗？

①我们这些人吧，除了赚钱，没有其他出路可走，也是蛮悲哀的。

②穷真'是太恐怖了。不会打造赚钱机器、公司，也太恐怖了。这会让人累死，人生活得极其没效率。

③经济基础决定上层建筑；经济基础决定别人瞧不瞧得起你，决定你说话是否受人重视。这就是为什么我们一定要朴素、努力、踏实奋斗的原因。

④您没有资金，没有成就，您的话，别人就不重视。假设您是个亿万富翁，甚至几十亿的富豪，您说话，别人就重视了。

⑤别人想学您的思想致富，别人想从您这里得到其他好处。总之，您富有，就证明您聪明、您优秀、您好。

⑥所以，我们要勤奋创业，踏实致富，做好社群营销创业、产品创业、服务创业。
