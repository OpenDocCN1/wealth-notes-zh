# 209、什么等于金钱?

+   ① 名声 + 变现 = 金钱。
② 营销 + 产品（或服务、鸡汤） = 金钱。
③ 美言可以市。这个“美”字特别有意思，其实互联网时代，不管是什么言，美言、丑言、恶语，都可以市。市场太大，需求太大。只要懂得传播、营销、大众心理，就可以用卖“言”。

# 210、财富来自哪里?

+   ① 对于普通人来讲，就是靠自己勤俭节约。
② 雷军说，要趋势。李嘉诚说，要取势。目前，互联网的势头在哪里？不过就是核心的几个短视频平台罢了。所以，找到短视频平台，去搞 36 循环系统，时时刻刻，锁定短视频。我们自己也在做短视频，当然也有钱赚。
③ 当您赚到了数百万，您又失去了一些钱，您才懂得节约，您才能懂得保护自己的钱。您才会慢慢明白，有些人别交往。
