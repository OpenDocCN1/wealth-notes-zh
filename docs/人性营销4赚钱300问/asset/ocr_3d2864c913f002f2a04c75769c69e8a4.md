# 58、哈是草根的唯一出路？

①社会上优秀的人很多，到处都是比我厉害的人。

②我怎么才能变得厉害？通过管理，通过不断的做服务，带领一大帮人跟我一起做事。

③我以前是靠营销赚钱，现在我想靠管理 + 营销赚钱，靠服务赚钱。我尝试着做成一个服务型的公司，带领一大帮人跟着我赚钱。

④我要加大力度学习，每天早上，就是不断的学习音频、视频、书籍，然后看看如何融合到自己的管理中。我认为管理可以解决一切问题。

⑤早睡早起、锻炼身体，努力工作，这是我们这些草根唯一的出路吧。打造团队工作，通过管理工作，通过成就他人工作。
