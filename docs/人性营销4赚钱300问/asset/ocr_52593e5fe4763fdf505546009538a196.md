# 27、为什么说农村小孩子，想在北上广深立足，其实有一定难度？

① 家里没钱，没背景，买不起房子。其实，按道理来讲，房子还是蛮便宜的，几十万、几百万，就能买。如果是首付的模式，就更便宜。只是农村大学生，想筹齐这点钱也有难度。

② 大家想要出人头地，唯一方法就是做项目。前几年实体项目有得赚，现在根本没什么钱赚。

③ 现在突破的模式，就是玩社群营销，玩自媒体创业，玩知识营销，这样赚钱快点，可能容易突破。
