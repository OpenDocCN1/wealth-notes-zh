# 第二，大面积的做软广告，多渠道的做广告。

有些时候，广告的投入，比做产品还重要。老板应该亲自抓广告，公司必须有广告专业的人才，而且不只是一个。老板还应该组织大家每天学习10分钟到20分钟广告学、营销学的内容。水滴石穿，这个团队的营销能力一定会与日俱增。

# 第三，重视客户服务，必须要亲自去看顾客与营销人员的对话交流。

要教大家如何做客服。营销人员接电话的时候要听，要思考，甚至要做好笔记。接下来与营销人员沟通如何能让客户买单。话术是在实战中天天优化的。
