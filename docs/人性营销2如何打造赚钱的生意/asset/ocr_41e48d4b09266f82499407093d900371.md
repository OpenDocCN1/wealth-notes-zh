# 23、企业 的命脉

创业者刚开始做一个业务做不起来，一般情况下就是营销不到位。营销是企业的命脉，如果你完全不会做营销，你就直接叫卖你是什么产品或者服务的就行了。天天叫，总是有 人买的。

小企业刚开始的时候，必须专心致志的为客户服务，不需要复杂的 管理，不用思考战略，甚至未来，就真诚的为客户创造具 体的价值就行了。战略、未来这些东西，是当你公司盈利了、稳定了，再思考的问题。

**聚焦到极致，只做一件事，这样的成功几率就大点。**现在互联网的出现，让一个企业只做一件小事变得更加现实，而且通过互联网可做全国的生意，也就是说，虽然你聚焦了一件小事，但你有海量的客户，也能支撑你做强做大。

一个企业要走得远，有质量还是根本，基本功扎实才有未来。
