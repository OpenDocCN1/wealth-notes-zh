# 第三，要习惯性的找一帮人来帮你干活。

别人能干的话，自己不要去干。把时间、精力投入到别人不能替代你的工作上面。只做关键性的工作，你的收入就会越来越高。

# 第四，在一个地方赚到钱了，就一直用老方法、老套路在这个地方赚钱。

不要认为还有其他更好的方法、更好的项目。换来换去，你就会发现你把自己弄得不赚钱了。

# 第五，永远不要去仇恨你的竞争对手，甚至永远不要去报复任何人。

因为这除了浪费时间以外，你什么也得不到。现代社会是有法律的，如果你控制不了自己，出现了一些过激行为，你是会受到法律制裁的。我们的做法很简单，就是把所有的精力投入到自己的业务上，让自己赚到更多的钱。

# 第六，投资大脑。

你能赚到钱，不是因为你有钱，而是因为你的头脑越来越聪明，这就需要你不断的投资自己的大脑。钱是不会赚钱的，只有有本事的人才会赚钱。
