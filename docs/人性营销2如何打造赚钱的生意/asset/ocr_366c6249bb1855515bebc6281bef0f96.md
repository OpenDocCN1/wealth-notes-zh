# 9、有本事的人不断的追求简单

我们能创业成功，一般都是九死一生，失败过好几次，不断总结经验。终于，我们在某个领域、某个具体的产品上赚到了钱。

有了钱，我们当然开始招兵买马，扩大团队，研究新产品，挑战新的难题，想赚到更多的钱。这就是大部分老板的思路。可大部分老板夜以继日的干，发现他们非常努力，公司并没有扩大，甚至有走下坡路的趋势，自己赚来的现金不但没有增长，反而有耗光的危险。很多老板百思不得其解。

为什么自己努力了，尽力了，反而公司干不大？其实是方向错了。用钱招聘优秀的人才肯定没错，夜以继日的疯狂工作也没有错，错在哪里呢？错在研究新的产品、挑战更难的项目。
