# 18、你收集的案例，就是你的生意

人是环境的产物，我们脑袋里的思想是我们接触到的信息的产物。

我们天天收集佛珠、佛牌的 QQ广告、微信广告，我们就会去搜索这种生意。搜索半个月下来，我们就收集了这个行业上百个文案、上百个竞价单页。我们对这一个行业熟悉了，我们就可能去进货，然后通过各个自媒体平台卖起来。

我们收集股票软文、股票培训、股票书籍，淘宝上所有的股票视频资料，我们都买来看。我们就可能开始卖股票软件、搞股票培训，我们也可能投资股票。

人就是环境的产物。人脑摄取什么信息，就有什么样的人生。我是看了一本书，讲销售可以赚大钱的，我才走上了业务员之路。我是与很多老板接触过后，他们悠悠我创业，我才开始创业的。
接触什么样的人，什么样的信息，成就什么样的 人生。
