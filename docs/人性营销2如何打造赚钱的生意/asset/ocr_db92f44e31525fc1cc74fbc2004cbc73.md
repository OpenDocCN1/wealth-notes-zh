# 17、不要让投资变成亏钱的游戏

对于大多数人来讲，是没有办法进入专业的投资机构去训练自己的投资头脑的，也没有办法接触到很多可以投资的项目、投资的企业，或者可以投资的创始人。

投资这个游戏，是最高端的赚钱游戏。于是，这个游戏也是最赚钱的游戏。对于不理解投资这门商业活动的人，就成为亏钱最厉害的游戏了。

有些拆迁户，或者是某些原因获得一大笔钱的人，想进入投资这个领域，想靠投资赚钱，于是去买了各种股票、债券。这无疑是最愚蠢的投资。为什么这么说？因为这些东西都是高手玩的，甚至是内部人玩的，不是一般人可以玩得的。智力不够、财力也不够，故而叫做散户，说白了，就是让人宰的。

假如你真有雄心进入投资这个领域，你是要经过很多困难的，也是要磨炼一番的。
