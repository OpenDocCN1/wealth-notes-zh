# 第二，九零后是指尖上的一代。九零后是互联网的一代，他们从出生就开始接触到互联网。

在对待互联网的态度上，九零后群体普遍对于互联网产生了新的依赖。同时随着年纪的增加，九零后对网络作为工具的应用也越来越娴熟。九零后群体正在过着一种链接的生活，即随时随地的上网生活，高度的依赖网络。他们中有四分之三的人，网龄超过五年，平均每天花费百分之十八的时间上网，而一般中国城市居民平均只花费百分之十三的时间在网上。而且这个数字会逐年增高。

对于他们来讲，互联网已经不仅仅是一个工具，而是一种生活方式。九零后群体将会是移动互联网发展的关键人群。据九零后的数字生活研究报告显示，受访的百分之八十六的九零后都是通过手机上网。
