# 21、一个成熟的人讲的每一句话，都是对自己有好处的

你想在网络上形成品牌，你骂人也可以，炒作也可以，但我建议你只宜传正能量。只帮助人，不要与人结仇，不要说别人坏话。一个种什么因，就得什么果。

比如，别人错了，你就骂别人，别人不舒服，也会让你不舒服。而且脏脏的词语会进入你的记忆，会污染你的头脑。

我以前就喜欢骂人，结果，别人就想尽办法骂我，我的生活也就会被这些骂我的人影响。所以，以后，别人错了，我是不会指出来的，我只讲好话，只讲正能量的话，只讲对别人、对自己都有好处的话。这样，所有的人都会说你好。

做慈善的、做公益的，都是这种套路。这种套路，对自己非常有利。一个成熟的人，讲的每一句话，都是对自己有好处的，都是增加自己收入的，绝对不会快意恩仇，去得罪人。
