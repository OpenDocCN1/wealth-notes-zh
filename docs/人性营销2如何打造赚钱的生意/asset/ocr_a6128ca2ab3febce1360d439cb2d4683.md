# 第二，创业是否要放亲家族成员、亲戚的加入？

现在有一个现象，很多年轻人都不太愿意接受家族成员加入，以至于发展到一个观念，连朋友都不能一起创业了。
这其实是一个误区。

纵观整个亚洲地区，日本、韩国、泰国，许多的家族企业都发展得很好。我们中国的家族企业也发展得很好。

创业本来就很难，家族兄弟有个好处就是信任成本低，打断骨头连着筋，吵得再凶，还得和好，遇到困难也会非常有凝聚力。而与外人创业，大吵一架过后，估计就散伙了。会出现打不得，骂不得，说都说不得的情况，交流不能彻底。有点饿了，又老是勾心斗角，争权夺利。而且彼此间经常杯疑。这都是创业的时候的致命问题。可能开始走得顺，有起色了，但也会因为这些问题被搞死。
