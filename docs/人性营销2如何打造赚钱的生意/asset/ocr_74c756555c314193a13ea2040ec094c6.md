# 9、企业家要学的是帝王术

一定要把自己的精力放到那些最能产生效益的地方。企业家、老板，是我们最应该关注的人群，他们为这个社会做了非常大的贡献，我们理应帮助他们出谋划策，帮助他们把事业做得更好。他们才能解决更多社会问题，为社会提供更多的工作岗位。

企业家要学的是帝王术，是法家思想，是儒家思想。只有把中国的文化母体学好了，才能理解中国人，才能把生意做得更好。

老板的脑子里，永远是团队赚钱模式，永远是打造一个强有力的组织，而不是个人英雄主义。

现代社会，确实靠个人就能赚到几千万，因为有互联网，有投资，有金融工具，个人发家致富变得更加容易。但想要赚到大钱，还要习惯性团队奋斗，团结一切可以团结的力量，一个人始终是有缺陷的，团队就可以做到没有缺陷。
