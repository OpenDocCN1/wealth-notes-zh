# 7、知名度就是金钱

互联网上可以用软文、视频、图片、语音去推广。推广是有技巧的，你不要讲些与产品无关的事情。你要做的一切，就是让用户记住你的产品名字，记住你是卖什么的。

看看脑白金的广告，你肯定能记住这是脑白金。这就是成功的广告。蚂蚁金服在北京地铁打广告，什么内容也没有，就是让大家记住“蚂蚁金服”这个名字，这就是高手的招式。
