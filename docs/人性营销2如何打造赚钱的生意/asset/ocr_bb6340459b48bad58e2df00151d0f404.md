# 7、做自媒体的六条注意事项

如何做自媒体爆营销？

第一，自己的品牌名一定要是简单好记的中文。

不要用英文，也不要用数字，因为大家记不住。我们知道的非常好的品牌名，比如苹果、比如老干妈、比如巨人集团，都是非常好用的中文短语。只有当别人记住我们的时候，人们才会买我们的产品。

第二，在互联网上发文章、视频，引导别人如何找到我们，引导别人如何注意我们，引导别人搜索我们，加我们的微信。

你不引导你的粉丝，你的粉丝永远不会加你的微信与QQ号。你的每个发声渠道都要加上自己的姓名。最大的品牌，就是你的名字。

第三，做电商、做微商，都是做搜索，所以，你最好学习一下 seo 的基本概念，知道什么叫长尾关键词，什么是转化关键词，什么是泛词。搞清楚什么叫全网营销。
