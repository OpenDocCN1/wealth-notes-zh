# 20、客户的需求才是我们的指南针

对于很多企业家或者是初级创业者来说，都想知道策略是什么？要么买了很多书籍，要么在网络上搜索高人的视频，要么进入 MBA 里去学什么 Debugging。学来学去，以为自己懂了很多，其实啥也没懂。可以说，大部分人理解的策略，只是自娱自乐，自己有点优越感而已。

策略并非神祕。策略就是做好一件小事，而这件小事顾客需要。把这一件小事做到极致，用自己的资源把这一件小事做好过后，客户选择我们的服务与产品。

你只需要做好现在手上的工作，能赚到钱，然后把这个工作不断的优化，赚到更多的钱，把生意做得更大，随着客户的需求跑就行了。根本不需要谈什么策略。
