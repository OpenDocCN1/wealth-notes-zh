# 1、互联网时代老板经营思维的转变

如何在互联网时代当老板？

**第一，无缝连接。**
建立一个 QQ 群，把所有团队成员都拉进去，老板讲什么，团队成员都知道；团队成员讲什么，老板都知道。互联网时代的企业，必须是无缝连接的。

**第二，审核工作。**
互联网时代，老板做好审核工作，包括各个模块的员工做的工作。比如，一篇文章，老板是要去审核的，这代表整个公司的价值观，也代表整个公司的形象。老板去审核，质量就会越来越高，老板不审核，质量就会越来越差。大家也不会重视，团队就赚不了钱。

**第三，团队模式招聘。**
招聘模式是团队招聘，不老板一个人说了算。人事面试过后，由相关的用人主管面试，最后老板去面试。
