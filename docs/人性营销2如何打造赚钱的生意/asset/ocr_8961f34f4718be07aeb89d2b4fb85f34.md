# 3、你所看到的一切，本质上都是广告，都是消费信息

很多人找不到项目，我告诉大家找项目的方法。

举例：我们打开天涯任意一个板块，我们都能看到热帖。
你耐心的读一读这个热贴，找一找发布起来的联系方式、资料什么的，你或许就发现了他的QQ、微信，然后你加过去，一般情况下你都可以看到对方的身份信息。没错，这就是一个项目。

同样的方法，可以在当下火热的小视频平台，比如，抖音、快手，甚至音频平台，如喜马拉雅FM，找到项目。
天下熙熙皆为利来，天下攘攘皆为利往。你所看到的一切，本质上都是广告，都是消费信息。无利不起早，没有人会干不赚钱的事情，特别是高人。

能把一个帖子或者视频炒热的人，其实都是做项目赚钱的，也就是说凡是在网络上入我们眼的帖子或者视频，十有八九就是一个项目。
