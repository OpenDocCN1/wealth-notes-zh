# 40、你们必须尊重我讲的棒喝式教育，这是我们社群的战略

# 学员：

您的学员您教她，有些需要她自己去动手做的，自己去查的。
都是成年人了，老大每天那么忙，您怎么好意思说让老大仔细讲给您的学员听呢？咱群里有 3000 老板，耍是啥事都找老大，估计老大都不知 道累成什么样了，关键是老大真的忙不过来。
我的大部分知识都是自学的。

# 陈昌文：

不是忙不过来、忙得过来的事情。你们必须尊重我讲的棒喝式教育，这是我们社群的战略。我怕你们做好了人不说，破坏了我们的战略。

法不轻传，道不贱卖，医不叩门，师不顺路，千金不传无义子，万财不渡忘恩人。

我们的态度，必须明确宣传给所有粉丝，这种模式是拒绝巨婴，我聪明人的。
