# 21、商人的天职就是赚钱

经商时间长了，起起落落，收入有高有低。讲过情怀，也讲过现实。刚创业的时候，非常痛苦，感觉挣钱遥遥无期，钱太难赚了。所以，给别人修过电脑、贩卖过二手电脑、镣由器、二手家具，搞过装修，搞过心理咨询，弄过弱电装修，搞过培训。

总之，只要感觉有希望挣钱的法子，我都去试了，还是苦于挣不到钱，但路却越走越顺利。后来，有的项目就开始赚钱了，而且越来越多，甚至是大赚特赚。人也比较开心，比较兴奋，认为自己无所不能了，讲话也比较<|start|>癫狂了。

有一次，我去见一个亿万富翁，我非常憨张地告诉他，没有1万块钱一小时，根本请不动我。我为什么这样讲话呢？因为我以前是一个非常普通的打工仔，突然有了点小钱，就不知道自己是谁什么了。当我讲完这句话的时候，这个亿万富翁完全不理我了，处于无视我的状态。我忽然感觉到我有点 brag 衡量不清楚自己的轻重了。
