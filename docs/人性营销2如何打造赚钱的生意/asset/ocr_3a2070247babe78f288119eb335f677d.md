# 8、什么才是好广告

无论是任何时代，只要经商，广告都是重中之重。现在尤为重要，是因为物质极大的丰富，竞争极其激烈，你的广告更加要像一把狙击枪，必须在顾客脑中留下一个记忆点，让顾客购买产品。

广告的目的不是写得多优雅，不是让别人称赞这个广告有多好。广告的目的ā是让大家听完、看完之后，愿意去买广告的产品来一试。

雅典时期，有两个著名的政治家。一个政治家演讲完了，大家都大呼，讲得真好。另一个政治家讲完了，没有人说这个政治家讲得好，但所有的人都开始群情激奋，准备好要去战斗了。显然，我赞同演讲完就让人去战斗的演说家。
