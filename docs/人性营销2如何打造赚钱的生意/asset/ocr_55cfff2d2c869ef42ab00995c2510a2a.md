# 5、创业需要不是资金，而是资源

创业需要启动资金吗？我一直强调人要善于思考。以前在深圳，我认识一个朋友，这个朋友也是个穷苦的打工仔，然后他在老家有一个高中同学，跑过来找工作，工作没找到，就住他家里。可是这个同学身无分文，白吃白喝很多天了。这个时候，这个朋友的女友，包括他自己，就不给这个老家来的同学好脸色看。

然而这位远道而来的高中同学依旧没有找到工作，要么是找到了，看着薪水也不想去干，但是天天白吃白喝，自己脸面也快挂不住了，他就到各个高楼大厦里去晃荡，消磨时光混日子。看到了垃圾桶里有非常多的订餐传单，他就开始收集，只要是这种订餐的传单他就收集，一天下下来，收集了 400 多张，然后就找把刀，把传单下面的电话给拆了，用笔公正的写上自己的电话。
