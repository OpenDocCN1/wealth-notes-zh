# 8、规模才是真正的优势

规模才是真正的优势。想要挣大钱，就必须有规模。不管是网络上的规模，还是线下的规模。总之，我们必须想尽办法的做大规模。

华为、阿里巴巴、京东、腾讯、顺丰，之所以有钱，就是他们的人多，他们的规模大。所以，我们必须想尽办法做大规模。

我们要把钱分出去，依此吸引更多的人参与到我们的项目中来。我们要包产到户，如此，每个人就会拼命的干活，因为他们都是为了他们自己干活。如果他们不愿意干活了，损失最大的也是他们自己。我们必须设计一个这样的模式来盈利。

一个企业中，我能拿走10%的利润就就行了，我不企图拿走太多的利润。我的目标是做大规模，我的目标是以剩余的90%去吸引更多的精英跟着我们一起奋斗。
