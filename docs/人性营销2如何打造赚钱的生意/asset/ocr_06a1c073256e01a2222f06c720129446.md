# 3、创业成功的三个关键点

创业成功的三个关键点。
第一，必须做自己爱做、喜欢做、擅长做的事情。

并不是说你有一个好点子，或者听到别人说一个好创意，或者在一个好行业，你就能做好企业。而是你是一个做做这件事、爱这个创意、爱这个行业的人。

创始人必须与公司是深深链接在一起的，创始人认为公司就是自己的生命，他除了做公司，对其他事情不感兴趣了，他才能做好这个企业。

怎么判断你是不是在做你热爱的事情呢？一提起这个企业、这个创意、这个行业，你会喋喋不休、动力十足。你所有的时间都泡在了这个企业里。你吃饭、洗澡，甚至睡觉都在想这个事情，就如同我以前玩魔兽世界一样，脑子里天天都想游戏里面的技能、人物、装备，不想房屋都难
