# 13、最快赚钱的逻辑

赚钱的逻辑理论，搞透彻了，就赚钱；没搞透彻，就不赚钱。
先有理论后有钱，没有理论的军队是愚蠢的军队，没有理论的赚钱人，在那里按照自己的思路瞎干，可能一辈子都不赚钱。

赚钱的思路很简单，别人有什么赚钱的项目，直接复制过来，不要不好意思。但是复制完了，并不是工作就结束了，我们还要持续的优化，持续的改进，最终做到青出于蓝而胜于蓝。

复制别人的东西一定要仔细，别人的原创，你要多研究研究，找出这个项目为什么能赚钱。不要只能复制表面，不能复制其精华。要抄一个非常简单的项目，这个项目，就一个步骤，或者最多两个步骤就能赚钱，我们才抄。凡是复杂的项目，我们看都不多看一眼。
