# 26、商业上最重要的两条游戏规则

首先来讲，你会为了自己的利益着想，别人也一样。很多人讲贡献，讲雷锋精神，实际上真让他让出利益来，是不现实的。

每个人，都想以最小的成本获取最大的利益。每个人都有一个可以收购的价格，如果价格足够高。

当今社会，做企业、创业，如果你不想以悲惨的结局收场，你必须想通和看透，并且接受与面对市场上的游戏规则。我总结了两条最重要的游戏规则。

第一，市场上的运作，根本就没有所谓的道德与不道德，只有合法与不合法。不要被道德绑架，凡是从道德层面去攻击竞争对手的人，都是极其幼稚与无聊的弱者。

在商业上，如果对方使用手段赢了你，但只要他不犯法，他赢了你，你就是输家，你就必须出局。简单来说，商业上只有赢家与输家，没有道德与不道德。
