# 第四种方式是自己做老板。

靠操心费力、冒险挣钱，不倒闭能够赚到钱，生意亏损倒闭，就会自动一分钱都没有。这种赚钱方式成功概率是5%。

# 第五种方式是结婚。

找有钱人结婚，立刻让自己变成有钱人。这种方式对自身素质和先天资质（漂亮或者长的帅）要求很高。

# 第六种方式是刻苦读书，把经济规律搞明白，掌握了社会规律，靠智力赚钱，智力也是资源。

# 第七种方式是上大学。

学历高了，找个好工作，不过成本比较高。

# 第八种方式是当牛做马。

打工族，大多数人是这样赚钱的。

这八种赚钱方式，我只推荐普通人用第四种，也就是自己创业当老板和第六种刻苦读书，提高自己的智力赚钱。因为这看似有难度，实际上是最简单的，只要你有毅力一直干下去，总会致富的。
