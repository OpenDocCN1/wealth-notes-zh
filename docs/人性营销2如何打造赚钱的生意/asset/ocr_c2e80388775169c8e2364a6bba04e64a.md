# 10、只有业务极其简单了，员工才能干得好

我们要竭尽全力的把公司的业务变得极其简单。每一个来应聘的人，我们只需要一句话，就表达出来我们是干什么的了。我们卖的具体产品是什么？让应聘者马上就认识到我们的产品。然后告诉应聘者，我们如何干，可以把这个东西卖出去。

比如在网络上发帖子，可以卖出去，操作要极其简单。然后再告诉应聘者，你卖出去一个产品，可以获得多少提成。让应聘者心满意足，知道自己卖出去了，有提成，而且是高提成。让应聘者自己去盘算自己一天能够多少提成。

只有我们公司的业务极其简单了，员工才能干得好，才愿意干。如果公司的业务太复杂，愿意干的人就特别少，能干好的人也特别少。
