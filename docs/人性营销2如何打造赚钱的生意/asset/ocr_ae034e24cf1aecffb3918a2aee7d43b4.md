# 9、微商营销的 5 点经验

微商营销的 5 点经验。

第一，想要持续性的吸粉，你必须要有个特长，这个特长要持续性地对别人有帮助。

比如，你会讲如何混社会，你会讲如何赚钱，你会讲如何创业，你会讲如何做微商。反正，就是必须对大家有好处，大家才会持续性的关注你。

商业的本质是交换，我们必须拿出我们有的与客户换钱。

如果你没什么特别的，你要想尽办法弄一个特别的技能出来。你甚至可以分享你的成长经历，如果能激励到别人，也是有用的。

第二，脑袋里必须有货。

想要做好吸粉，你脑袋里必须要有货，这就要不断的学习。自己脑袋里的东西迟早会转化成金钱，永远不要怕白学了。
