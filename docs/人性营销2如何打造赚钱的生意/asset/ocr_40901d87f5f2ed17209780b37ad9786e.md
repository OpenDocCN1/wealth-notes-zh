# 30、为什么不要收客户的红包

我们在经营自己的业务、事业的时候，由于干得太好，总是有会人给我们红包。现代社会，发红包非常方便，要么 QQ 发，要么微信发，要么支付宝发。养成熟习惯，不要收任何人的红包。为什么呢？

1、我们要养成习惯，只靠自己的业务、服务、产品赚钱，利出一孔。

如此，我们才会专心致志地做服务。服务好了，我们自然能赚到更多的钱。收红包，把人收 reconfig 懈了，收小气了。

2、我们要赚的是大钱，不是这种红包式的小钱。

几十块钱、几百块钱，只是浪费我们的时间而已，并不能让我富贵。所以，有人发给你红包，一律不收，一律拒绝。

3、收红包，会把人养成索取型的人格。
