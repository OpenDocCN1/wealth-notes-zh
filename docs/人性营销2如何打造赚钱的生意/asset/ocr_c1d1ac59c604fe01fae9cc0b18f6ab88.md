# 第三，要有助人心态。

要想吸粉，还必须要有利他心态，就是你一直在帮助你的粉丝。你不要只会推广你的广告。你只要不断的帮助粉丝，总是有一些粉丝会为了获得服务而付费的。

很多人非常急躁，不愿意付出，直接发广告，就想让粉丝买单，这基本上是不可能的。朋友圈没有利他心态，你一定是玩不起来的。

# 第四，亲民。

吸粉的东西不一定要求高大上，亲民最重要，一定要让你的粉丝懂你在说什么。千万别让粉丝来理解你，粉丝没有心情，也没有义务来理解你。他们理解不了你，只会拉黑你。

# 第五，打造信任感。

如果粉丝问你的产品或者服务多少钱，怎么卖的时候，尽量用语音回答，千万不要只会打字，打字没有什么信任感的，而语音有信任感。

如果可能的话，养成打电话的习惯，养成接粉丝电话的习惯，这样成交率就会高很多。当然要注意有些人是故意来搞乱的，他们不会买单，他们是来浪费你的时间的。所以，要严格控制与陌生人的通话时间，比如3分钟就必须挂电话。
