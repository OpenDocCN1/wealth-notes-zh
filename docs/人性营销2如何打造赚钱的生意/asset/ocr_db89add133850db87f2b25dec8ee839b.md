# 如何复制别人的项目呢？

一定是找 seekers 他最赚钱的那个点去复制。如果他经营的业务比较多，都在赚钱，你不要全部复制，只复制其中一个最有前途的业务就行了，然后把这个业务做精、做深。赚钱不在于做得多，而在于与精、深。

很多人创业之所以难，就在于想自己搞一个新东西出来，或者想颠覆别人。其实新东西都有老东西作为原型，而颠覆都来自于微小的创新。你在一个点上探索，改进的时间长了，自然就变成了新东西，也能颠覆原本那个项目了。
