# 五、组织团队跟着你一起搞原创。

一个人的智慧是会枯竭的，但是群体智慧是不会枯竭的。一个人也很難保证每天都有一个量，每一个人都会疲惫。你搞久了，就不想干了。但是一个团队就能保持每天都有非常大的量的原创。

你这个团队里的人不行了，你又可以通过招聘模式，招到新人来搞。所以，如果你想搞原创，你必须上团队模式，这样才能持续不断地生产出原创赚钱。

# 六、选定一个原创的主题，就永远不要换了。

所以，一开始，你就必须选择一个非常大的市场，不要做了几年，发现赚不了大钱，又想换一个主题搞。这样就非常浪费时间。一个主题，持续不断的做，做上 10 年，成为亿万富翁不会太难。
