# 第二个坑，随便找合伙人。

开始的时候，你根本不用找合伙人。其实核心合伙是最难找的，这靠缘分，也靠平时积累。如果实在找不到，不要强行找。先自己找个零成本的项目干起来，项目活了，每月的收入突破几万块了，这个时候可以采取招招聘员工的方式来扩大团队。

甚至，你的项目赚钱了，你也有说服力了，你就可以说服同事、同学、亲戚来给你当助理，一起创业。

# 第三个坑，股份平分。

创业的时候，股份不要平分，甚至你可以先谈股份，就是给跟你做事的人高提成就行了。最好采取独裁主义，权力都在你自己手里，好管理，也很灵活。

什么事情都商品著来看下，就是效率。大多数人都是普通人，他们的头脑里想出来的主义根本就不赚钱。而且想法根本就不值钱，有了想法，能倾而舍的干起来，才值钱。
