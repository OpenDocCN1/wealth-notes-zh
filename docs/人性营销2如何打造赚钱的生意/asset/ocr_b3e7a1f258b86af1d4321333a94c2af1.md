# 12、战略与产品的关系

赚钱，最主要的是要具体的出招。

任何一个赚钱的人，必须做具体的事情。只要这个人不做具体的事情，任他再聪明，都是狂妄。

战略、定位、具体的产品与服务，是一回事。具体的产品与服务，是战略的落地，是定位的体现。假如一个公司把搞战略的、搞定位的、搞产品的、搞服务的人分开，那么这个公司就是瞎搞。

不存在一个人懂战略，不懂服务，另一个人懂服务，不懂战略。懂战略的人，必须提出具体赚钱的产品和具体赚钱的服务。要提出具体产品与服务的人，必须提出战略。

我讨厌一个人说大方向定了，就好办了，还以为自己为公司做了很大的贡献一样。为什么？因为大方向定了，其实什么都不是，因为知道这个方向的人非常多，只有提出具体的产品
