# 4. 推广——推广团队

都是口碑传播。任何一个行业，总有一个企业是做到了口碑传播的，这其实就是要求你的产品与服务真的是好到家。我们现在做互联网生意，口碑传播更加是重中之重。

我做任何项目的推广策略都是花钱，花钱请人或者花钱砸广告。我的逻辑是，能上钱的不上人，能用别人的事情，自己就别上。

钱不值钱，别人的不值钱，最值钱的是自己的人与自己的时间。老板不要亲自去推广产品，老板要经常培养公司的推广团队。

经常有老板想来拜访我，或者想请我去给他们公司团队做培训，我从来都是拒绝的。因为我有功夫给他们员工讲课，还不如培养自己公司的员工。我有闲情去跟这些老板聊天，还不如看几页书，或者花时间跟公司的核心员工聊天。

总之，推广就是能花钱就花钱，不能花钱就用别人，别人才行再上自己的人。我的任务就是培养公司内部员工。

把握好这四点，做任何项目都能得心应手。
