# 左長黑右長紅

# 定義

左邊下跌幅度達2.5%以上中長黑K線，右邊上漲幅度達2.5%以上中長紅K線，2根K線構成下跌低點或底部反轉向上型態，2根K線必須為中長的實體，可以有小的上下影線。

![](bbox=[0.7, 0.5, 0.88, 0.63])

# 解說

走勢下跌中，昨天是長黑K線，但今天收盤卻是一根並肩的長紅K線，很明顯的，昨天空方強力下跌的力量，今天被多方完全克服。這是股價下跌轉折向上的一組K線基本型態。
