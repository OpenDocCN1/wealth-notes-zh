# 元素2：收盤價

+   1. 當日多空雙方經過一天的決戰後，最後的結果價格。

+   2. 以收盤價為界線，收盤價的上方視為空方力量的範圍，收盤價的下方視為多方力量的範圍，依此可看出當日多空勢力的強弱，並可預測明日開高或開底的意圖。
