# 訣竅 5：何時是空頭走勢的進場做空時機？

+   高檔出現頸部完成確認的下跌黑 K 線，股價收盤跌破頸部盤整下頸線時。

+   下跌途中，反彈後再下跌的黑 K 線，股價跌破前一日最低點時。

+   下跌中續勢盤整完畢，股價收盤向下跌破盤整區時。

# 訣竅 6：空頭交易的規則

+   進場：收盤前確認股價跌破前一日最低點時放空。

+   停損：進場當日 K 線股價的最高點（不能超過 7%）。

+   續抱：每天收盤前檢視股價，沒突破前一日的最高點時續抱。

+   出場（回補）：收盤前確認股價，突破前一日最高點時出場（回補）。
