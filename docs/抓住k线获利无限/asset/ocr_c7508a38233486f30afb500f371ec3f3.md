# 祕訣3：何謂真封口和假封口？

+   • 向上跳空缺口，如果股價在近
日內拉回，出現帶大量的實體
黑K線，收盤到缺口下沿或跌
破缺口下沿，稱為「真封口」
（回補）。

![](bbox=[0.64, 0.22, 0.88, 0.37])

+   • 向下跳空缺口，如果在近日
內，股價回升出現帶大量的實
體紅K線，收盤到缺口上沿或
突破缺口上沿，稱為「真封
口」（回補）。

![](bbox=[0.64, 0.41, 0.88, 0.56])

+   • 向上跳空缺口，回補缺口的
黑K線，留有長下影線，或者
回補缺口呈現帶大量紅K或量
縮，容易是假封口（回補）。

![](bbox=[0.64, 0.59, 0.88, 0.74])

+   • 向下跳空缺口，回補缺口的
紅K線，留有長上影線，或者
回補缺口呈現帶大量黑K或量
縮，容易是假封口（回補）。
