# # 第2篇 中紅和中黑、小紅和小黑K線

# ### 認識中紅K線

# ### 定義

開盤與收盤上下幅度達2.5～4.5%、開低走高的實體紅K線，而且是不含上下影線的實體K棒，即使有，也只能有很小的影線。

# ### 解說

中紅K線，當天開盤是最低價，然後買盤拉抬，最後上漲約2.5～4.5%，到當天最高價收盤，所以當天是多方中強。
