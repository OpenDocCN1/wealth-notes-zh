# 定義

上影線很長，至少是實體的2倍以上。小的實體在下方，實體可以是紅K或黑K。

# 解說

在多頭上漲或反彈走勢中出現倒錘線，是容易轉折向下變盤的訊號。在下跌走勢或多頭回檔出現倒錘線，是容易轉折向上變盤的訊號。

# 精通

出現倒錘線，一定要用第二天的K線來確認，否則在上漲中只能解讀為遇到大壓力，在下跌中只能解讀為出現上攻力量。從次日開盤走勢，可以看出是往上還是往下轉折。

在多頭上漲出現倒錘線：

+   1. 次日開低向下，收盤低於倒錘線實體下沿，可確認為轉折向下。如倒錘線當天或前1、2日出現大量，更可確認為反轉。

+   2. 連續出現2根倒錘線，其中出現爆大量，或者第2根倒錘線跳空向下，更能確定走勢是反轉走跌。

+   3. 出現2根倒錘線，即使次日再上漲，高點也不會太多，謹放假過高、真拉回。
