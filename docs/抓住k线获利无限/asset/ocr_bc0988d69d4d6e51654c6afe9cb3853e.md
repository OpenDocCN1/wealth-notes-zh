# 高檔3根K線轉折向下的變化組合

# 組合 2 ：孤島夜星

+   1. 上漲高檔或空頭反彈出現中長紅K線，次日出現向上跳空的變盤線，如果第3天出現往下跳空下跌的中長黑K線，稱為「孤島夜星」組合。

+   2. 出現「孤島夜星」組合，是強烈向下反轉的訊號，如果同時出現大量或爆大量，反轉更確認。

+   3. 變盤線越多，反轉下跌後力道越強。

+   4. 出現「孤島夜星」組合，在多頭上漲趨勢中表示將強力回檔，多單要出場。在空頭反彈時，將繼續下跌，要把握做空。
