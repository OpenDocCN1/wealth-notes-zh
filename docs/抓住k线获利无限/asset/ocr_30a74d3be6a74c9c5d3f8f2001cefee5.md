# 第2章 解讀K線密碼

4.平盤附近盤整再上漲，盤整後尾盤向上拉到漲停板。

![](bbox=[0.16, 0.24, 0.62, 0.52])

資料來源：富邦eO1電子交易系統

第1圖是主力一開盤就急拉到漲停板鎖住，第4圖是主力在接近收盤時急拉到漲停板鎖住。從這兩檔股票的K線，可看出主力的企圖是於開盤時或收盤前急拉，目的都是不希望有太多散戶跟進，如果當天是多頭起漲的進場位置，要立刻買進。

第2圖是主力先下殺，散戶看下跌而不敢進場，同時洗出一些不安心的籌碼，再快速拉漲停板，這也是主力強勢的表態。

第3圖表示籌碼不安定，開盤漲停板後立刻打開，再迅速下跌到平盤，上下拉鋻，出現的是長上影線的K線，要看位置及成交量，才可確定可否介入。
