【解析】司马懿是三国后期著名牛人司马懿的哥叔。此人智慧超群，其权术能力的核心就是对事情发展的预判。通过严密的权谋预判推理，让司马朗乱世中保全了家族。我们坐下来细细分析其中的内涵：

# 一、司马朗权谋预判的三次行动

+   1、预测到众人董卓必有战。

董卓的所作所为已经触动了众怒，其形式已经箭在弦上，彼此的矛盾已经到了不可调和的角度，必然有爆发的时候，所以，司马朗料定，董卓会和其他的势力对抗，从而引发战争。且董卓自己的势力单薄，必然失败，所以司马朗，通过行贿的手段，果斯的回老家，走上策，摆脱了矛盾的漩涡。

+   2、预测到会战会出现的地点。

既然董卓要和对抗势力必然一战，会在哪里交锋，战场会出现在哪里，司马朗提前推演战争会出现在洛阳的东边，这里具备了双方对持的要素。而而司马朗认为自己的老家就在这个兵家混战的地方，所以果斯在没开战前把家族带走，抛开很多人不愿意搬家的惰性。

+   3、预测到安全自保地点所在。

既然要搬家，搬到哪里，天下之大，何处安家，司马朗选择了黎阳。这个地方离自己老家并不太远，且有姻亲关系，还有足以自保的所控兵力。有这三点，黎阳是个不错的选择，于是司马朗果斯的把整个家族迁出。和平的地点，足够的关系，自保的力量，三合一的选择，体现了司马朗的眼光。

# 二、司马朗三次猜测成功的背后原理是什么？

+   1、预判矛盾所在。

权谋预测不是算卦，而是推理，基于矛盾变化的推理。首先就要找到矛盾双方的问题所在，如果是不可调和，非此即彼，且势力相当，那么实力相当不可调和的矛盾，必然一战。所以，分析矛盾的所在和性质是我们预测的第一步。

+   2、预判矛盾趋势。

既然矛盾迟早会爆发，那么爆发矛盾的走向会是什么，如果立即爆发，爆发点会在哪里。双方会有什么动作。要设身处地的去对双方的策略进行分析和对筹码所在进行研究，以及弱点防御能力评估。只有这样，才能再描述出来清晰的未来图。

+   3、预判矛盾反应。

面对这个即将爆发的矛盾，熟悉了趋势，我们最重要的就是对矛盾发展趋势做出反应。首先看这个矛盾的发展对自己有没有好处，自己能不能浑水摸鱼，如果对自己没有好处，就要想办法所在能不能提前解决，如果无法提前解决，就看能不能远离，最大程度减轻。
