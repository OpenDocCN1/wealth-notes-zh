翼芮可以说是夷吾后来得能够称王的第一功臣，没有翼芮的战略决策选择梁国，也就不会有夷吾的事后陈宫。翼芮的战略谋划，完美无缺，走一步看三步，翼芮看了哪三步？

+   1、看发展。

做任何事情，不能只看眼前，要看到事情的发展。怎么才算看到事情的发展呢，那就是你走完这一步，对手会如何走，他会如何应对，这就是看的第一步。因为权术博弈过程是双方的，不仅看你如何走，而是看你走过之后，对方会如何反应。翼芮看到了夷吾和重耳都逃到翟，那么对手的晋献公会不惜代价。

+   2、看变化。

不仅仅要看到定数，还要看到变数。夷吾在和自己的老爹对抗的过程中，是一分钱的优势都没有的，不死就是最大的胜利。所以这就要看到变化，如果晋献公不在了，会有个什么样的状况。毕竟一个人的死亡是最大的权利变数。翼芮看到了晋献公死后，姬媫和自己的儿子奚齐是控制不住局面的。

+   3、看准备。

既然未来有一天有机会，这就要为可能的机会做出准备，而不是盲目的等待。翼芮让夷吾选择在梁国做准备的根据地，是对的，有信息，有安全，有可能借助的力量。所以在奚齐被权臣巫杀掉后，夷吾能够第一时间，借助秦国的部队来实现自己的上位，这在逃亡的一开始就已经布局好的。

# 三、这样的权谋思维深度对我们的职场有什么启示？

+   1、重在保全。

当你无法和强大的势力对抗，什么都不占有优势的时候，这时候保全实力才是最重要的。我们在职场经常会遇见，自己不喜欢的领导，虐的我们体无完肤，这时候，选择示弱。保全就是最大的胜利，任何盲目的对抗都会让自己失去所有资源和未来的机会。

+   2、等待变化。

现在没机会，不代表未来没机会，任何的都是变化的。所以，一时的不得已无需灰心，留得青山在不愁没柴烧。现在没机会，未来有机会，时间是最大的变数。所以，我们只是暂时的没有成功，怎么能够说这就是失败呢。夷吾也是暂时的没成功，未来的王位在等着他。

+   3、筹备资源。

机会是给有准备的人的，如果你只是在盲目的等待机会，等待天上掉馅饼，那么可以说这样的人会失败一辈子。因为真的机会来的时候，你用什么去抓住呢，判断出未来格局的变化，并为之做出准备。这才是积极地应对之道，这才是成功面对失败之道。

走一步看三步，这样才能从容规划未来要走的路。相对比下，重耳的逃亡就没有一个主线，到处游走，盲目逃亡，所以，当真的机会来了，首先邀请重耳回国，重耳却不敢回来，因为自己没有任何的势力支持，没有做出准备，只能眼睁睁看着夷吾先行地走向王位。
