势者心理很难接受身份的改变，因为职场的不平等，最终往往情感关系的破裂。从这一段通鉴的材料里，杨慎矜把自己的表侄王铤安排在自己身边，看看这个关系是如何走向恶化的。

+   1、直呼其名

杨慎矜是王铤的表叔，一直以来就是直接喊王铤的名字。所以在官场，杨慎矜也是表达亲密而直呼其名。但是，这就让王铤心理很不舒服，让他在职场丧失职业荣耀性。在职场，我们也是如此，不愿意喊自己的亲戚或是同学的职务，而是喊其名字，这会让被喊的人心里很很不舒服。

+   2、侵犯利益

杨慎矜仗着自己是王铤的表叔，资历比他老，自然而言的就会无形中侵犯到王铤的利益，觉得，我多拿点或是你就该在利益面前对我做出让步，这种心态下，杨慎矜占去了本该属于王铤的职田，尽管这个利益不是很大，但是这个让王铤更加不舒服。

+   3、揭露隐私

杨慎矜和王铤的父亲关系好，所以知道很多王铤的隐私，而王铤的母亲出身低贱，杨慎矜应该是没把这个事当回事，随意的就给说出去了，这样身为高官的王铤像赤裸的站在别人面前被人点评一样，心里极端的不舒服。我们在职场也是常犯这样的错误，无意间暴露熟人隐私，让别人不快。

+   4、心理压迫

正因为，王铤能够进入御史台，是杨慎矜推荐的，而又是他表叔，所以，杨慎矜在王铤面前有极强的心理优势，这样王铤一直都抬不起头，这种无形的心理压力，让王铤怎么都不舒服，头上压着大山一样。只有把杨慎矜弄走，自己才有解放的感觉。

+   5、站队需要

杨慎矜和权倾一时的宰相李林甫，发生矛盾，王铤就面临站队的问题，一边是自己的表叔，自己的职位也是他引荐的，如果不果断的撕咬杨慎矜，自己就会被其牵连，给一个让自己内心不爽的人陪葬是王铤不愿意做的，所以，果断充当李林甫的急先锋，和杨慎矜划清界限，成了主要方向。

杨慎矜把自己的表侄推荐到自己的身边，本想让其成为自己的政治势力，但是却没有想到，这个表侄王铤非但不感恩，反而逐步的走向对立面，成了打击自己的急先锋，这样的情况其实很难避免，唯一能够做的，就是不让亲戚或是朋友成为自己的下属，他们内心很难转变角色，所以也就难以相处，就会给自己带来这样那样的麻烦，尤其是自己政治失意的时候，这些人为了划清界限，会更加手狠。
