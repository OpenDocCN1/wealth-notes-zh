个人势力相当，未来可替代性太强，所以，这就是矛盾的对立和不可调和，必然有斗争的一天，不如提前下手。你身边优秀的同事，现在关系不错，但是未来出现岗位空缺，必然你争我抢，立即翻脸内斗，到那时，为时已晚。

+   2、渔翁得利。

自己和别人不可调和的矛盾，要提前下手，才能保证自己的利益，但是如果发现别人的矛盾所在，这个时候就要学会利用别人的矛盾，为自己谋利，要么顺手牵羊，要么浑水摸鱼，利用他们之间的斗争，为自己争取好处。职场最常见的就是，有些人不满领导，将要集体拍桌子，这时候，就需要利用出卖、告密来谋取自己的利益，获取领导的信任。

+   3、隔岸观火。

如果不是自己的矛盾，别人的矛盾自己也利用不了，还有可能引火烧身，这时候最佳的策略就是采用隔岸观火的办法。找一个安全的地方待着，避免城门失火，殃及池鱼。比方说，高层领导内斗，这时候，最佳的策略就是谁也不参与。如果一旦站队，自己又不是人家的心腹群体，最大的可能就会被人当枪使。我们要利用弱势矛盾，回避强势矛盾，这是职场的安全之道。

# 权谋家培养心腹梯队人才的步骤！

【出处】《三国志》44 卷 《蜀书》14 《费祎传》

【原文】先主立太子，祎与允俱为舍人，迁庶子。后主践位，为黄门侍郎。丞相亮南征还，群僚于 数十里逢迎，年位多在祎右，而亮特命祎同载，由是众人莫不异观。亮以初从南归，以祎为昭信校尉使吴。孙权性滑稽，诸葛恪、羊街等才博果辩，论难锋至，祎辞 顺义笃，据理以答，终不能屈。权甚器之，谓祎曰：“君天下淑德，必当股肱蜀朝，恐不能数来也”。还，迁为郎中，亮北住汉中，请祎为参军。建兴八年，转为中 护军，后又为司马。

【译文】先主立刘禅为太子，任费祎和董允为舍人，又升为庶子。后主刘禅继位后，他们任黄门侍郎。丞相诸葛亮南征回朝，群官到都城外几十里处迎接。其中大多数官员比费祎年长且职位尊贵，但诸葛亮却只命费祎与自己同乘一车，从此众人莫不对费祎另眼相看。诸葛亮刚从南边归来，任命费祎为昭信校尉出使吴国。孙效能说会道，他手下的诸葛恪、羊街等人，知识广博，才能卓越，善于辩论，论辩质问言辞锋利，而费祎与他们谈论时，却滔滔不绝，含义深刻，据理回答，对方始终不能使他服输。孙权十分器重费祎，对他说：“你是天下具有美德和才能的人，必定会成为辅佐蜀国君主的重臣，以后恐怕不能常来了。”费祎回蜀后，升为郎中。诸葛亮北驻汉中时，请费祎任参军。建兴八年，费祎转任中护军，后又任司马。
