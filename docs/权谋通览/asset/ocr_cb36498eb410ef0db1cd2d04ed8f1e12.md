# 说服引导术！

【红楼梦 118 回】却说宝玉送了王夫人去后，正拿着《秋水》一篇在那里细玩。宝钗从里间走出，见他看的得意忘言，便走过来一看。见是这个，心里着实烦闷，细想：“他只顾把这些出世离群的话当作一件正经事，终久不妥！”看他这种光景，料劝不过来，便坐在宝玉旁边，怔怔的瞅着。

宝玉见他这般，便道：“你这又是为了什么？”宝钗道：“我想你我既为夫妇，你便是我终身的倚靠，却不在情欲之私。论起荣华富贵，原不过是过眼烟云；但自古圣贤，以人品根柢为重——”

【权谋解析】贾宝玉在看《庄子》的《秋水》篇，马上就要科举考试了，贾宝玉依然心思在佛道上面，不思功名。已经成为贾宝玉妻子的薛宝钗希望劝说贾宝玉走仕途，走一个正规社会的儒家道路。但是如何说服不变成吵架，薛宝钗使用了说服引导术。权谋网详细分析下这个权谋招数：

+   1、薛宝钗看到贾宝玉没有看考试的书籍，而是在看出世离群的书籍，心里十分不满。作为一般人，内心一定火冒三丈，直接就会激烈的对抗语言，都什么时候了，你还看这种书，你怎么这么不负责任，你还是男人嘛，我嫁给你，就是想有个依靠，你竟然如此烂泥扶不上墙，我当初真的是瞎了眼。贾宝玉立即就会讽刺，你不就看上我们家有钱，看不惯你走？两个人不欢而散。其实现实中大多数夫妻都是如此的，都会站在自己的立场对方不断的抱怨指责，吵架升级。

+   2、薛宝钗毕竟大家闺秀，又具有权谋智慧。她尽管心里不舒服，但是并没有直接指责。而是静静的坐在贾宝玉的身边，看着他。这就是凝造了一种平静的谈话环境，能够让彼此心平和的进入到一个谈话的阶段。而且没有上去就进入一个批判或是指责的谈话定性。而是从两个人的关系娓娓道来，我嫁给你就是想把你当成依靠，不仅仅是情欲之私。这就把贾宝玉推向了一个重要的位置，唤起他内心的责任感。然后又说，自己让你考功名并不是看重金钱，荣华富贵不过是过眼烟云，然后转入一个理性说服。

+   3、这一段对话，其实就是说服引导术，其中韵味妙不可言。很多人说服别人，往往直接进入说服状态，你该如何如何做，但是说服别人放弃自己的行为，是有挑战意味的，如果不能在谈话之前做好引导，那么，被说服的人，信息接受，心理就会极端的不舒服，情绪反应就会很激烈。两个人谈话往往都还没有开始，就已经火药味浓厚，接下来也就没有了谈话的基础，再好的话，也都说不出来。所以，薛宝钗，从自身入手，示弱增加贾宝玉的责任感，又避免自己被错误认为是爱财，从强调人品，切入，让贾宝玉不能不接着听。
