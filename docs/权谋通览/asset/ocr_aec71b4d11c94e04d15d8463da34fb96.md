莫过于救主，这个功劳很大，足够分量；其次，不需要资源支持，因为是自己设计的，没有风险，全程可控；最后，能够让吾彦的勇敢当众展示出来，让大家心服。

经过上述的分析，我们能够看出来，领导想提拔谁，就会让谁做出成绩，而不是谁做出成绩提拔谁，这个顺序不能搞错。懂得这个权力原理，做领导就会更加顺畅。作为下属，也就知道什么才是我们努力的方向。

# 蹭热点是出名的捷径！

【出处】《晋书》第 57 卷 列传 27

【原文】马隆，字孝兴，东平平陆人。少而智勇，好立名节。魏兖州刺史令狐愚坐事伏诛，举州无敢收者。隆以武吏托称愚客，以私财殡葬，服丧三年，列植松柏，礼毕，乃还，一州以为美谈。署武猛从事。

【译文】马隆，字孝兴，是东平平陆人。年轻时智勇双全，喜欢建立自己的名气与节操。魏国的兖州刺史令狐愚犯罪被杀，整个兖州没有敢为他收尸的人。马隆凭借武官的身份假称是令狐愚的门客，用自己的钱财将令狐愚装殓下葬，并且服丧三年，在令狐愚的坟地种上松柏，葬礼完备才回家，全兖州把这件事传为美谈。让他暂时代理武猛从事。

【解析】马隆是西晋初期的名将，这个人有勇有谋，采用了蹭热点的权谋技巧，快速完成了自己的名声积累，从小人物，进入了公众视野。权谋网给大家分析下其中的智慧要点：

# 1、寻找热点

东平在魏晋时期是兖州下辖的一个县，马隆是这个小县城的人，想出名进入公众视野难度很大。于是，积极的寻找热点来借势。而此时，当时的省委书记令狐愚犯罪被杀，无人收尸。可以说，这是那时候最大的热点，所有的目光都聚集在令狐愚后事的处理上。谁能够完美的利用这个事件，谁就能吸引到全州人的目光。任何的公众事件，都有机会被人借势吸引流量。

# 2、蹭上热点

想蹭上这样的热点，是有风险的，一般人都怕牵连到自己，这的确是是需要智慧和勇气的。不过，本身你一无所有，大不了回归原点，如果成功，则收益巨大，所以，普通人应该是具有风险偏好才能成功。而马隆，就借口是令狐愚的门客，捏造了和省委书记的关系，然后借机给其下葬。在这种危险的时候，没人会怀疑这个关系的真实性。收尸的冒险行为，一下子就让人知道了马隆这个人。

# 3、转化名声

作为普通的聪明人，收尸埋葬，也就结束了，这个历史上类似的事很多。就此止步的话，可能会吸引名气，这个并不能把名气转化为名声。马隆作为权谋家，走出了更加绝妙的一步，就是“服丧三年，列植松柏”踏踏实实的做了一场完美的行为艺术。为了主人，马隆表现出的恩忠，让所有人都认为，这样的人，可信，可用。谁不想有这样的下属？从名气转化了名声。回去后，就成了新省委书记的属官。
