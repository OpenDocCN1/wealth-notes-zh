# 论功行赏的权谋艺术

【出处】《史记》 晋世家

【原文】从亡贱臣壶叔曰：“君三行赏，赏不及臣，敢请罪。”文公报曰：“夫导我以仁义，防我以德患，此受上赏。辅我以行，卒以成王，此受次赏。矢石之难，汗马之劳，此复受次赏。若以力事我而无补吾缺者，此受次赏。三赏之后，故及子。”晋人闻之，皆说。

【译文】随从文公逃亡的无能之辈壶叔说：“您三次赏赐功臣都没有轮到我，请问我有什么罪过。”文公回报说：“用仁义教导我，用道德、恩惠规劝我，这应受到上等赏赐。用行动辅佐我，终于使我获得成功，这应受到次等赏赐。承担弓箭的危难，给我立下汗马功劳，这应受到再次等赏赐。假如只是用劳力侍奉我，而没有弥补我的错误，这也应受到再次等赏赐。这三次赏赐完了，就会轮到你。”晋国人听到文公的话，皆大欢喜。

【解析】每个最高领导，在创业成功，打下江山的时候，都需要论功行赏，对追随自己的人奖励，也是为自己打下统治的根基。很多人处理这件事做得并不好，让功臣伤了心，让自己的江山功败垂成。刘邦就曾经在论功行赏的时候不及时，差点搞出兵变，在张良的指导下，封了最痛恨的雍齿，才算是，平息了大家的舆论，让大家觉得刘邦不是个忘恩负义，过河拆桥的人。但是纵观整个历史，只有晋文帝说出了论功行赏的次序和标准。现在权谋网给大家解析如下：

+   1、夫导我以仁义，防我以德患，此受上赏。

能臣，这是为自己出谋划策，从无到有，整体勾画布布局的人。这样的人是首功，因为一个人整体的战略布局和方向，这是最为重要的。他们为谋划成功承担着重大的风险，可以说是同党，这样的人，一荣俱荣，一损俱损，所以，最大的风险，最大的功劳。

+   2、辅我以行，卒以成王，此受次赏。

忠臣，这是说长期追随自己的人，指哪打哪，忠心不二的人。这类的人，通常来说，不参与谋划，只是参与执行，是一个值得信任 and 托付的忠臣，他们不能够出尽奇谋，或尽力天功，但是却能够荣辱与共，不离不弃，这种追随，列为次功。

+   3、矢石之难，汗马之劳，此复受次赏。

功臣，这是说的，立功的人。关键时候能够顶的上去，平时没有什么表现或是表现的很平庸，但是在关键的战役，关键的时候，不畏艰险，不惜性命，勇于前进，勇于立功，这样的人，在战场上的拼杀，一次次的立下汗马功劳，这样的人，是第三等功。

+   4、若以力事我而无补吾缺者，此受次赏。

内臣，领导的身边的人。没功劳，有苦劳，没苦劳有疲劳。为领导服务，贴身伺候的人，没有变节出卖和背叛，兢兢业业的做了自己该做的，这类人“在三赏之后，故及子”这可以说是自己要安抚的外界的最后一批人，这上述的四类人都是必须安抚的利益群体。

+   5、最后封的是自己家人亲人友人。
