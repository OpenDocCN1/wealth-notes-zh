【背景】齐桓公与管夷吾连语三日三夜，字字投机，全不知倦。桓公大悦。乃复斋戒三日，告于太庙，欲拜管夷吾为相。

【解析】这是齐桓公任命管仲之前的最后一次谈话。这次谈话，看似很不合理，但是却蕴含着巨大的政治暗语交锋。君权、相权自古以来就是互相争斗的，而它们能够成为千古佳话，是因为彼此划定了权力边界。

+   1、齐桓公这句话很有意思，直接告诉管仲，好田，好色。好田可不是种地，而是打猎的意思，好色都明白，直白点说齐桓公的意思就是“我喜欢游玩和女人，你说我能不能做个好领导吧？”

+   1、大家都喜欢游玩和女人，但是齐桓公还这么问，其实不仅仅是告诉他的个人爱好，而是要管仲表态，我对治理国政没什么欲望，但是我又想控制权力，你说我能不能做到？还有就是你是不是会对我的个人生活指指点点，弄个忠臣一样天天要求励政？

+   2、管仲其实听明白了齐桓公的话，于是管仲直接把话题引导到了，“你不干活可以做个好领导，但是如果你不知道贤人，不用贤人，不让贤人适当的职务，不让小人制衡，这才行。”管仲隐含的告诉了齐桓公，你想当甩手掌柜还要控制权力，你只能用我，而且只能用我一个，不能找人制衡，这样才行。管仲向齐桓公表达了自己的权力独任的需求，如果你不用我，你就不能尽情的投入到自己的爱好中去。

+   3、表面上看似一个说自己喜欢泡妞打猎，一个说要重用贤人。其实本质都是权力划分，这是通过暗语来试探，因为权力的事情很敏感，所以只能通过暗语来交锋，来试探彼此的权力边界，试探结束后，管仲不管齐桓公的私生活，齐桓公独任管仲执政。

在职场其实很多政治暗语，大多都是涉及权力的，因为权力是最敏感的，不能够公开的谈论，如果公开，其实难免会陷入僵局，让大家没有后路，你猜的懂，大家都是聪明人，你猜不懂，那么不好意思，你还不适合玩政治。
