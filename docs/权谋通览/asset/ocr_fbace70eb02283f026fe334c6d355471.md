# 高力士的固权术，权谋型秘书的核心秘密！

【出处】《资治通鉴》第 213 卷 唐纪 29

【原文】高力士尤为上所宠信，尝曰：“力士上直，吾寝则安。”故力士多留禁中，稀至外第。四方表奏，皆先呈力士，然后奏御；小者力士即决之，势倾内外。

【译文】高力士尤其被唐玄宗所宠信，唐玄宗曾经说：“高力士值班，我睡觉才安心。”所以高力士多数时间留在宫中，很少到宫外的府第居住。各地上报的表奏，都要先呈送高力士，然后上奏唐玄宗。小一点的事，高力士就自己决定了，他的权势超越了所有内侍外臣。

【解析】高力士是历史上有名的大太监，曾经几句话就扳倒了，唐玄宗的心腹王毛仲，从此不可一世。高力士获取信任后一直保持着权力高位，主要是采用了三大固权术：

# 1、多留禁中，稀至外第

高力士赢得唐玄宗的信任，谋取了权力之后，几乎寸步不离的待在皇帝身边，表面上是对领导的忠诚，到最后，高力士不值班，领导都不安心。其实这是高力士最为权谋的地方，高力士独自霸占权力，自然会得罪很多人，一旦稍微离开皇帝身边，免不了就会被人在皇帝面前说坏话。高力士自己做的这些坏事很可能就会爆发出来，最终自身难保。何况唐玄宗本身不是昏庸之君，查实后，必然不会留有情面，但是，高力士不会给任何人单独接触皇帝的机会。直到伺候唐玄宗睡了之后，自己才休息，别人谁也不会当着高力士的面来说坏话。

# 2、四方表奏，先呈力士

高力士的敌对派，如果不能直接面对面的给皇帝进言，自然会想到写文字，上奏，不过这个高力士也早就想到了，高力士几乎垄断了皇帝要看到了所有的信息。其实，这就是信息枢纽的控制，任何秘书工作都是这么玩的。因为领导很忙，每天会听很多人的汇报，至于安排谁，不安排谁，看什么文件，几乎上都是由秘书来直接安排的，所以，秘书会把自己认为有利的文件放在最上面，对自己不利的几乎就留置或是让领导最累的时候，最没心情的时间看。还有汇报的时候，同样可以采用这个招法。赵高就是故意让秦二世玩耍的时候，让李斯来汇报工作，让秦二世对李斯讨厌，最终，李斯被杀。

# 3、小者即决，势倾内外

对于小的事情，就不用麻烦领导了，高力士随即就代替领导拍板了，表面上没什么，这是分担了领导的工作，让其从繁琐的事物中解脱出来，其实这个行为非常可怕。记得有这样一个段子，刚结婚时候，妻子对老公说，以后家里的大事，你决定，小事我来决定。但是结婚三十年，没发生过大事，因为妻子眼里所有的事情都是小事。因为高力士，是首先看表奏的，事情是大是小，这个几乎没有什么标准，还不是高力士自己就说了算。举国大事能有几个？还不是日常事务占领导工作的绝大部分？所以，有这个“小者即决”这个上方便剑，自然能够权倾内外。
