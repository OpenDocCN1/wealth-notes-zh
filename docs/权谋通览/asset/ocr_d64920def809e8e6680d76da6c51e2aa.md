# 贪还是不贪，大功之人必须做出的选择！

【出处】《资治通鉴》第 118 卷 晋纪 40

【背景】刘裕（南朝宋开国皇帝，此时是东晋太尉最高权臣）北伐，派出在关中有威望的王猛之孙王镇恶，灭亡后秦。

【原文】癸亥，泓将妻子、群臣诣镇恶垒门请降，镇恶以属吏。城中夷、晋六万馀户，镇恶以国恩抚慰，号令严肃，百姓安堵。九月，太尉裕至长安，镇恶迎于渊上。裕劳之曰：“成吾霸业者卿也！”镇恶再拜谢曰：“明公之威，诸将之力，镇恶何功之有！”裕笑曰：“卿欲学冯异邪？”镇恶心贪，秦府库盈积，镇恶盗取，不可胜纪；裕以其功大，不问。或谮诸裕曰：“镇恶藏姚泓伪辇，将有异志。”裕使人视之，镇恶剔取其金银，弃辇于垣侧，裕意乃安。

【译文】癸亥（二十四日），姚泓携妻子儿女、文武百官，前往王镇恶的大营投降，王镇恶把他们交给下属官吏关押。长安城中的汉族人和民族人共有六万多户，王镇恶宣扬东晋的恩德，加以安抚，号令严明，百姓安居乐业。九月，太尉刘裕抵达长安，王镇恶在渊上迎接。刘慰劳他说：“是你帮助我完成了霸业！”五镇恶再拜谦让说：“全仰赖您的英明指挥和威望，各位将领的努力，我有什么功劳！”刘裕笑着说：“你难道要学习冯异吗？”其实，王镇恶一向贪财好利，后秦府库仓储十分丰富，王镇恶私自盗取的财物，不计其数，刘裕因为他的功劳很大，所以不予过问。有人向刘裕诬陷王镇恶说：“王镇恶私藏姚泓的御用辇车，可能会叛变。”刘裕派人侦察。原来，王镇恶剔取了辇车上的金银珠饰，然后把辇车抛弃到城墙外面。刘裕这才安心。
