【解析】孔子在《论语·里仁》中写到“君子喻于义，小人喻于利。”意思就是“君子眼里都是道义，而小人眼里看到什么都是利益。”可以说，这段话，代表了中国几千年来的利益观，只要你谈利益，不管你是谁，你都是小人。这种君子和利益对立的思维方式，让中国人在利益面前都显得很是谦虚。尤其是政治家不是道德模范，在面对巨大利益的时候，更不可能为了面子而放弃，如何避免掉入“利益小人”的伦理陷阱呢，权谋家找到了一把破解的钥匙，那就是“三让而受”：

# 1、作为下属要主动为领导谋取利益

符健利用后赵主石虎死后的政治混乱控制了关中之地，但是却没有一个合法的政治名分。

于是符健左长史贾亥硕等请依刘备称汉中王故事，让他学习刘备的做法，自己上表请求封号，这个政治举动让符健大怒。从表面看来贾亥硕让领导很是不满，充满着政治风险，其实本质上不是那么回事。作为下级，维护领导利益，为领导争取利益的过程中，都会出现这种情况，因为领导的怒是为了表达自己不是小人，自己并不是看重利益，这不是怒给下属看的，而是给大众看的。

# 2、领导的拒绝利益的同时需要暗示

但是这样面对自身利益发怒的领导真的是道德模范，还是为了避免小人陷阱的政治策略呢？如果大家都觉得领导真的就是心底无私怎么办？这岂不是玩崩了？所以，为了避免这种状况，符健派出了自己的心腹梁安，暗中鼓动贾亥硕再次给领导上尊号，明着当然是正气凛然，毫无利益专门利人，暗着就要私下沟通，有一个正确的引导。很多初级领导都是在这里玩错的，就是没有私下沟通和暗示，表面又表现的特别的愤怒，让下面的会错意，最终领导一肚子无名火，骂下届条。

# 3、形式上一定要表现出被迫和无奈

作为下属一定要主动揣摩领导的需求，尤其是个人利益的需求，这个领导都羞于出口，必须有所属积极主动的为领导谋取，这时候，第一次有人提出利益的时候，一定要严历拒绝，这样才能显示出领导的君子气度，但是同时也要对维护自己利益的下属，在另外的环境里和颜悦色，或是私下找人沟通，有一个正确的引导。这样多次拒绝，给大众形成一个被迫无奈的政治心理，自己没有考虑自己的利益，都是下属为了自己的富贵，强制把黄袍披在自己的身上的。

符健通过自导自演的双簧战略，最终获得了自己想要的政治利益，这里要特别提示的是，这个利益提出的人，在表面上一定不是自己的政治派系的人或是平时交往很少的人，这样显得更加真实，如果是自己的心腹梁安或是自己的亲戚提出，效果就会大大减少。第二，在领导自己谋取利益之后，要有一致性，不能立即封赏这个人，不然会给人一种漏出狐狸尾巴的感觉。这个利益提出者，也就是本文里的贾亥硕，不能立即得到利益回报，或是不能明面上有利益回报。

看完上面的这段话，很多人会认为这个利益提出者是领导自己挑选的，其实在真实的职场，都是自己跳出来的，主要是这下属，看到新领导实力强大，自己想转换阵营，再或是揣摩
