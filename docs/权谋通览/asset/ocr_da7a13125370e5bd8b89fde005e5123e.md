很多社会老年人，积攒了一辈子的财富，都被很多人利用各种手段，明的暗的坑走了。这些韭菜命的人，你的同情，不会换取他们的安全。

经过上述的分析，我们能够看出来，这五个方面，从各个角度能够卸下权谋家做事的手段上的道德感。

# 诸葛亮认错的 rhetoric 解析

【出处】《三国演义》 第 96 回

【原文】须臾，武士献马谡首级于阶下。孔明大哭不已。蒋琬问曰：“今幼常得罪，既正军法，丞相何故哭耶？”孔明曰：“吾非为马谡而哭。吾想先帝在白帝城临危之时，曾嘱吾曰：‘马谡言过其实，不可大用。今果应此言。乃深恨己之不明，追思先帝之言，因此痛哭耳！’大小将士，无不涕涕。

【解析】挥泪斩马谡，这是众所周知的经典剧目，但是这个背景，我们应该知道，就是诸葛亮任人唯亲，放弃使用经验丰富的王平和魏延，启用毫无实战经验，刚愎自用的马谡，导致了第一次北伐的重大失败。若不是空城计的险棋，诸葛亮自身也差点丧命。组织的大失败，谁来担责？自身权威的丧失，如何重建？悠悠舆论，如何扭转？这些问题无不压倒诸葛亮的心头。战无不胜，算无遗策的诸葛亮，面对人生第一个挫折，该如何应对？诸葛亮的这段话术，破解了失败难题，可以说经典至极，权谋网现在揭示其中的奥妙：

+   1、掩盖自私心理

诸葛亮和马谡的关系很好，不惜刻意栽培，这次战斗的失败，大家内心都会指向诸葛亮任人唯亲，私心太重而导致的错误。但是，通过借助刘备之口评价马谡“言过其实，不可大用”这就把大家认为的原因指向了马谡的言过其实，诸葛亮只是识人不明的错误而已，诸葛亮成功把自己私心解脱了出来。

+   2、转移舆论焦点

失败后，舆论焦点都会集中在诸葛亮的身上，但是通过指出先主刘备的英明预见，从而转移了大家的舆论焦点，对对失败的抱怨，变成对刘备的佩服上来。用一个正面的故事掩盖了失败的情绪，这其实也是偷换概念的一个方法，这样诸葛亮从舆论的漩涡中解脱出来。

+   3、重塑组织权威

拉出刘备这个大旗，其实还是为组织打气，潜在重塑自己的权威，强调自己和刘备的关系，以及自己的合法性，不是自己打仗的战略错误，而是战术细节上没有听刘备的安排，避免了大家质疑主动挑起战争的战略质疑。这样的安排，让诸葛亮从战略失败中解脱出来。白帝城临危之际，哪有闲工夫去评价马谡啊，而且先主也不会预料马谡能够成为大将超过魏延和王平。具体这段话，先主刘备说没说过，权谋网倾向于，是诸葛亮自己的托辞而已。这样的话术使用，其实并非诸葛亮的发明，而是早有案例。韩非子在《内储说上*七术》中引用的春秋郑国的故事这样写道“子产死后，游吉不敢严厉执行刑罚，郑国青年拉帮结伙成为强盗。盘据在蓺谷之泽中，即将给郑国造成祸害。游吉率车骑和他们开战，打了一天
