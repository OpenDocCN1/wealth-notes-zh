# 孔子传授给白公的造反技巧1

【出处】《列子》《说符篇》

【译文】白公问孔子说：“人可以和别人密谋吗？”孔子不回答。白公又问道：“如果把石头投入水中，怎么样？”孔子说：“吴国善于潜水的人能把它取出来。”白公又问：“如果把水投入水中，怎么样？”孔子说：“淄水与渑水合在一起，易牙尝一尝就能辨出来。”白公说：“人本来就不可以为别人密谋吗？”孔子说：“为什么不可以？但只有懂得语言的人才能这样说吧！所谓懂得语言的人，是指不用语言来表达意思的人。争抢鱼虾的沾湿一身，追逐野兽的跑断双腿，并不是乐意这样干。所以最高的语言是不用语言，最高的作为是没有作为。那些知识浅薄的人所争论的都是些枝微末节。”白公不能阻止自己叛乱的念头，终于死在浴室中。

【权谋解析】白公想政变造反，于是求问于孔子。这段对话，直接代表了孔子的权谋智慧！

# 一、白公的求问阴谋方法的权谋技巧

+   1、直接询问被沉默拒绝

白公直接询问，让孔子救他政变技巧。这个给孔子出了难题，权谋的技巧，如果公开说出去，说的明确了，会被人误解这个人原来这么阴暗，一定要防着。如果说得简单，又被人说，你这个人 的智慧也不过如此。况且，孔子也不想蹚浑水，你成功尚可，不成功，岂不被拖下水？孔子直接反对，也不行，白公这种阴暗的心态告诉你了，你反对，你一定是反对派，你会不会告密，你知道的多了，要先除掉你。白公，可能转身就会杀了孔子，以防泄密。所以，孔子选择沉默。

+   2、间接询问撬开了孔子

白公一看，直接询问，孔子顾虑过多，就变换了询问的方式，采用了政治上通用的手法，打哑谜的方式。这两句哑谜很有难度，权谋网在此破解下。白公问，我直接找人明说造反如何？孔子说，你这样会被人告密的。白公又问，那我偷偷的暗示他们加入造反如何？孔子说你会被高手提前识别的。孔子通过打哑谜告诉白公胜，你只要有动作，要么内部人告密，要么外部人找到蛛丝马迹，这都不是上策，都可能暴漏，而导致政变的失败。孔子没有回答造反，而是用举例说明，毫无把柄。

+   3、反问孔子有没有办法

白公的两个方案统统被孔子拒绝，依然不甘心，你说这都不行，怎么才能行呢？如果孔子，不复答，就会被认为你就会否定，你也不是什么高人，孔子既然回答了上述的询问，就不能不给出方案，白公的询问技巧通过迂回的方式得到了孔子的答案，尽管白公没有使用孔子的方案，但是这个询问的技巧值得我们学习。孔子给的答案就是，要学会利用利益形势而不是利用言辞策动。孔子的这段对造反的回复，堪称他的谋略经典。本质的方案就是利用你不得不做，而不是说服你做，才是安全策反上策。
