# 面对天上掉馅饼，是机遇还是陷阱？最核心的是如何消化！

【出处】《资治通鉴》第 96 卷 晋纪 18

【原文】代王拓跋觚之弟什翼犍质于赵，觚寝疾笃，命诸大人立之。觚槐卒，诸大人梁盖等以新有大故，什翼犍在远，未未可必；比其至，恐有变乱，谋更立君。而觚姊弟屈，刚猛多诈，不如屈弟孤仁厚，乃相与杀屈而立孤。孤不可，自诣邺迎什翼犍，请身留为质；赵王虎义而俱遣之。十一月，什翼犍即代王位于繁畴北，改元曰建国；分国之半以与孤。

【译文】代王拓跋觚的兄弟拓跋什翼犍到后赵做人质，拓跋觚病重，命令诸大人立拓跋什翼犍为王。拓跋觚死后，诸大人梁盖等人认为国家新有重大丧事，拓跋什翼犍离得远，来不来不可确定，等到他归来，恐怕会有变乱，因此提议重新立君。而拓跋觚的弟弟拓跋屈，刚猛多诈，不如拓跋屈的弟弟拓跋孤仁厚，于是共同杀死拓跋屈，立拓跋孤为君。拓跋孤不同意，自己到邺去迎接拓跋什翼犍，请求自己留在后赵为人质。后赵王石虎认为他有道义，把他和拓跋翼犍一同遣返。十一月，拓跋什翼犍在繁畴以北即代王位，改年号为建国。又分出国土的一半给拓跋孤。

【解析】天上掉馅饼的事情，普通人遇见之后，肯定欣喜若狂，面对这样的飞来横财，很多人认为这是自己的人生机会，是自己几辈子修来的福气，撞上大运了，但是在现实中，几乎上都是陷阱的代名词，很多人都是因为这样走向了被骗的深渊。所以但凡有点社会知识的，都会当然的拒绝这种诱饵。但是这样往往又错过了应该有的机会。然而，权谋家，对于这样的馅饼，不会欣喜若狂，同样不会避之不及，而是审时度势，把馅饼留下来消化了。

拓跋孤，鲜卑族，十六国时期代国平文帝拓跋郁律第四子，老大是拓跋觚、老二是谁？应该是拓跋什翼犍，拓跋觚的弟弟。老三是谁？应该是拓跋屈。本来代国王这个位置，无论是采用游牧民族的兄弟共还是中原模式的父死子继，都轮不上拓跋孤出来做代王，但是因为拓跋觚的意外因病离世，拓跋屈被杀，拓跋什翼犎在外国做人质，让他有了机会。称王是所有男人的梦想，而拓跋孤也不例外，但是他是非常冷静的，没有贸然接受这个位置，而是通过自己的努力，做到了吃饼吐核的目的。权谋网详细分析这其中的门道：
