西汉末年，各路军阀混战，军队来来往往，老百姓生死无着，谁能够取得胜利，就是要老百姓主动选择要追随的军队。对于有政治理想和严明纪律的队伍，有更大的可能成功。但是道听途说，不如亲眼一见。主动迎接军队，能够近距离观察这支队伍的纪律，军事装备，士兵面貌。

# 2、服从获得好感

任何组织和人都是如此，顺我者昌，逆我者亡，军队来了是需要就地取粮的。你主动来归顺，站在了军队的一方，和这些人立即交往，那么接下来，就是这些队伍抢东西，也因为自己的归顺，少去很多麻烦，那些不主动的，必然是要受到打击和清剿的，态度不好，军队不会手软。

# 3、主动依附强者

再弱的军队，也比老百姓强。主动的和军队站在一起，主动的归附，成为军队随从的一部分，这其实是一种寻求保护的木能。数百万人望风归顺，其目的也是这个逻辑，我打不过你，我就想和你站在一起，成为强者的一部分。“父老、童稚，垂发、戴白满其车下”越是弱者，越是明显。

这段通鉴的材料，我们能够看出，老百姓不傻，不是因为热爱军队，不是因为别人动员，而是基于自己的利害计算。这种其实是一种权谋的思维方式，就是要通过积极的接触，来近距离观察，确认是不是强者。主动迎接，依附强者，顺从强者，给他们想要的政治面子，这才是王道。职场中也是，要通过近距离接触领导，去发现他能不能成功，如果是个手腕很高的强者，无论喜不喜欢就尽早归附吧。争取好的态度，这才是生存的智慧！

# 三招搞定混乱局面——破解众人闹事的智慧！

【出处】《资治通鉴》 第43卷 汉纪35

【原文】郡国群盗处处并起，郡县追讨，到则解散，去复屯结，青、余、菌、冀四州尤甚。冬十月，遣使者下郡国，听群盗自相纠，五人共斩一人者，除其罪；吏虽逗留回避故纵者，皆勿问，听以禽讨为效。其牧守令长坐界内有盗贼而不收捕者，又以坐捐城委守者，皆不以为首，但取获贼多少为殿最，唯蔽匿者乃罪之。于是更相追捕，贼并解散，徙其魁帅于他郡，赋田受禀，使安生业。自是牛马放牧不收，邑门不闭。

【译文】各郡、封国的盗贼处处并起，郡县追击征剿，军队到吋盗贼就散开，军队离开后又重新屯聚集结，青州、徐州、菌州、冀州四个州尤其厉害。冬季，十月，朝廷派使节到各郡、封国，听凭盗贼们自相检举攻击。五个人共同斩杀一个人，免除五个人的罪。即使官吏畏怯逗留、逃避、故意放纵盗贼，也一律不追究，允许以擒贼讨贼立功。州、郡太守、县令县长在所辖界内有盗贼而不拘捕，或因畏惧懦弱弃城放弃职责的，全都不予处罚，只看捕获盗贼的多少来排列先后名次。仅对窝藏盗贼的人才加罪。于是，大捕盗贼，盗贼全部解散。把他们的头领迁徙到其他郡，给他们土地，供应粮食，使他们安心生产。从此以后，放牧的牛马晚上不用牵回，城门夜间不用关闭，一片升平景象。
