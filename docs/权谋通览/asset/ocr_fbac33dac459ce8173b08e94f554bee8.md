【解析】面对领导的问话，再小的事情也是大事，因为领导要的不仅仅是结果，还有你在这个过
程中，所表达出来的重视态度。这个态度，在领导眼里，远比结果重要得多。

# 1、一般人反应

很多人在职场对领导的指示敷衍了事，以为汇报了结果就完成了任务。作为没有经过权谋
训练的一般人，面对汉武帝问，有几匹马拉车，其实内心绝对是不满的，会想，“这么幼
稚的问题还问我，你没长眼睛？”然后很不情愿的回答，“六匹马。”

# 2、权谋家对策

而权谋家却不同，他们知道，权力无小事。即使是小事，只要领导重视，就要当成大事来
抓。所以，石庆立即下车，从头到尾一一数了数马匹，然后郑重的态度，举手回答“有六
匹马”。在这个过程汇中，石庆表现出严谨，恭敬。

# 3、背后的原理

汉武帝看不出有几匹马吗？其实这就是个权力测试，看看你对领导命令的态度。通过这个
小事，看看你在回复的过程中，所表现出的对权力的尊重。职场上，很多人都抱怨不被重
视，怀才不遇，殊不知，小事你都做不好，领导会把大事交给你？

结果重要吗？重要。但是相对于结果而言，领导更加看重下属对权力的态度。如果做错了，
但是非常尊重权力，那么领导会包容，会给更多的机会。但是如果即使得到了好的结果，
对领导态度冷漠漠视，那么最终也不会有什么好果子吃。职场，态度重于一切！
