# 造反失败的根本原因！

【出处】《晋书》第58卷 列传28

【材料】《周鲠传》

周鲠字彦和。常默念其父的遗言。当时中原丢官失守逃避祸乱来南方的人，很多都官居显要之位，控制着吴地人，吴人非常怨恨。周鲠趁此想起兵，秘密勾结吴兴郡功曹徐馥。徐馥家有武装，周鲠叫徐馥假称其叔父周札的名义聚合兵众，喜欢生事作乱的豪客观士不约而同地投奔他，以讨伐王导、刁协为名。孙皓族人孙弭也在广德起兵响应他。徐馥杀吴兴太守袁瓖，拥有几千兵力，准备推举周札为首领。当时周札因病回家，听到后大惊，于是向义兴太守孔侃报告变乱情况。周鲠知道周札不赞同，不敢发兵。徐馥的党羽害怕，攻打徐馥，杀了他。孙弭的兵聚也溃散了，宣城太守陶默消灭了他们。元帝因为周氏世代都是豪门望族，为吴人所尊奉，所以没有追根问底治罪，安抚他们如同从前。周鲠被周札责备，失意回家，淫放放纵，常对人说：“人生能活几时，就图个痛快罢了。”死在临淮太守任上。

【解析】周鲠是西晋晋西将军周处之孙，他的父亲周札，在世时受司马睿和北方士族猜忌，密谋反叛未遂，抱憾而死，临死前对儿子周鲠说：“杀我者诸伦子，能复之，乃吾子也。”“伦”是吴人对中原人的称呼。所以，有了父亲的遗言，周鲠处心积虑想找机会造反。这是他造反从策划到失败的全过程，其经验和思路以及失败的教训都值得我们研究学习。

# 一、周鲠能够策动造反的综合条件

# 1、权贵矛盾

当时中原丢官失守逃避祸乱来南方的人，很多都官居显要之位，控制着吴地人，吴人非常怨恨。这个权贵矛盾就是动乱能够起来的核心基础，任何动乱之源必然是矛盾尖锐化的结果。其实社会矛盾积累到一定结果，都会有一个总的爆发。作为革命家，就要准确的找到这矛盾，加以利用。

# 2、基础实力

只有矛盾的话仅仅是一堆待燃烧的干柴，这个需要有一把火来点燃，而基础的武装就是这把火。周鲠找到徐馥就是看中的私人武装，这就是点燃革命的火源。无论是徐馥出于私人利益，还是韦史留名，被周鲠激发出的野心，让他果断的杀了吴兴太守吴劭，宣告反叛。

# 3、散碎势力

孙皓族人孙弭也在广德起兵响应，孙浩大家都知道，是三国时期吴国的末代皇帝，他的族人趁机骑兵响应。其实任何时候，一旦战火点燃都会有很多人出来，趁火打劫。这些散碎的势力，如果不能够为了共同的目的先联合在一起，很快就会被各个击破。
