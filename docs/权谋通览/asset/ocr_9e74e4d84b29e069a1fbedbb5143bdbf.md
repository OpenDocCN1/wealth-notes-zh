# 领导“引蛇出洞”除掉反对派！

**【出处】** 《资治通鉴》第 159 卷 梁纪 15

**【原文】** 东魏仪同尔朱文畅与丞相司马任罝、都督郑仲礼等，谋因正月望夜观打毬戏作乱，杀丞相欢，奉文畅为主；事泄，皆死。文畅，荣之子的也；其姊，敬宗之后，及仲礼姊大车，皆为欢妻，有宠，故其兄弟皆不坐。

**【译文】** 东魏仪同尔朱文畅和丞相司马任胄，都督郑仲礼等人，打算趁正月十五的晚上观看打毬戏的机会谋反叛乱，杀掉丞相高欢，推举文畅为主上；事情泄露以后，他们全被处死。文畅是尔朱荣的儿子；他的姐姐原来是敬宗的皇后，现在与郑仲礼的姐姐大车都是高欢的妻。她们受到高欢的宠爱，所以她们的兄弟都没有受牵连。

**【解析】** 在历史的字里行间，初读没有什么，但是细品，却发现，无不让人有毛骨悚然的战栗感。这一段文字，就是平淡的记录中隐藏着巨大的阴谋！帝王的冷酷权谋，被演义的淋漓尽致，又被掩饰的毫无痕迹！

+   1、像这样谋反的大事，能够联络的都是极度信任的人，如果按照权谋家，持术不持情的观点，能够聚集起来搞政变的，都应该是和敌人有深仇大恨的，要么是和自己有深度的亲情关系。但是，就这样严密的事情，如何就泄密了呢？泄密的这个人必定是深度的参与、知情人。但是结局却是“皆死”，也就是一个没剩下，这就意味着这个泄密的人也在其中。

+   2、高欢是东魏的权臣，皇帝的废立都是他说了算，他的儿子纂权建立了北齐，他此时是东魏的大丞相。我们看下这个谋反的名单里，有个特殊人物，那就是任胄，他是丞相的司马，这就意味着，他本人和丞相是亲密的上下级关系。而其他的，比如尔朱文畅和郑仲礼都是高欢的小舅子。这些小舅子是亲戚带来的关系，可能内心并不亲近高欢，但高欢的丞相司马，这样长时间权力信任，怎么可能叛变？

+   3、其实最大的可能就是，高欢对自己的亲情任胄，实施苦肉计，故意当众制造矛盾。根据，敌人的敌人就是朋友的这基本政治原则，这些反对高欢的人就会找到他作为同盟，任胄得知这些造反的人了有这一个阴谋政变之后，立即告密。高欢，立即就采取了行动，把所有的涉案人员都斩杀了，把自己的反对派一网打尽。但是很多人会有疑问，为什么任胄实施“周瑜打黄盖”这样的苦肉计，一样要死？
