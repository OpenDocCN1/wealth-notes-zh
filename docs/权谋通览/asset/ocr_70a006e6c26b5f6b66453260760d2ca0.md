自身违规，看唐玄宗会不会保护自己。一旦皇帝这次为自己撑腰，别人以后都惹不起他，自然能够对别人颐气指使。

# 2、京兆尹为什么要奏报给唐玄宗

作为捕盗官，按照道理而言，对付一个侏儒是没有问题的，不能打，不强壮，你还捕个什么盗啊，但是为什么这个捕盗官，没打赢侏儒，核心就是打狗看主人，捕盗官惹不起侏儒，恐惧背后的唐玄宗，于是当下忍住了，回头走正规程序。直接告官到京兆尹，让自己的领导处理。

京兆尹面对捕盗官递上来的案子，其实事情简单，如果不是顾虑黄扁瓜这个身份，直接按照程序抓来就行了。但是京兆尹不是普通的官，如果直接按程序处理，皇帝要人怎么办？如果不处理，睁一只眼闭一只眼，被皇帝追究失职怎么办？只能上报，怎么做，让自己处理吧。

# 3、唐玄宗处理侏儒时的利益算计

当黄扁瓜对唐玄宗讲完自己为什么迟到，唐玄宗内心一定是矛盾的，一方面，他喜欢这个段子手，还能当拐棍使用，所以，他就说，如果这捕盗官忍了，唐玄宗自己也就没有必要追究了。毕竟不是大事，如果捕盗官没忍，那么这个事情，就按程序来，毕竟唐玄宗并不是昏君。

唐玄宗在面对自己个人兴趣爱好和组织规则发生冲突的时候，唐玄宗很明显选择了直接杖杀这个侏儒，也就是乱棍打死。这也是司马光把这故事写进通鉴的教育意义，之所以打死，而不是暗示有关部门从轻处理。目的就是给其他身边人看的，避免这些人狗仗人势，也是给历史看的，自己是明君。

# 4、这个侏儒如果想不死该怎么办

很大层面这侏儒本来也不应该是主动测试，而是仗着领导的喜欢，对别人很是嚣张，自然觉的自己能够有人撑腰。如果京兆尹，不汇报给皇帝，而是直接把黄扁瓜给抓了，那么，皇帝就会想，打狗还要看主人，你这是挑衅我的权力边界，我自己的人我怎么处理都行，但是你不能主动做。

按照权力的心思，如果黄扁瓜被直接抓了，直接动皇帝的人，会被皇帝护犊子。但是这种情况下，黄扁瓜想自己不死，最佳的策略，就是给唐玄宗讲完这个故事，解释对方的嚣张，然后主动去投案自首，这样能够照顾到法律程序，这样就不算仗势欺人，一个争道也不至于死。

经过上面的分析，黄扁瓜死的很惨，这个结果可能是他想不到的。但是黄扁瓜想弄权，只能这么做。为什么唐玄宗不念及一点的感情，他认为自己怎么在唐玄宗眼里也有点价值。如果是一般的皇帝，可能黄扁瓜窃权就成功了，可是他遇见的是开元年间的唐玄宗，一个依靠政变上位，除掉姑姑，逼退爸爸的皇帝。他会念及感情？对领导的性格和处世手腕研究不清楚，半把刀子的权谋水平，只能命丧黄泉！
