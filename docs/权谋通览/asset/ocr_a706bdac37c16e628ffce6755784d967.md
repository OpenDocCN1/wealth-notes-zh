谍纵称落后套了了外部政治的保护，利用户籍内部牵制了刘裕。这个只能是找到了所有的有利条件，但是自身的实力建设才是最重要的。仅凭依靠自己的能量积累，显然是十分缓慢的。因此必须借势才能快速的增加自己的势力，借历来都是快速发展的最佳捷径。而东晋原有的桓玄家族势力是最需要拉拢的，于是桓谦就进入了谍纵的视野。

# 二、谍纵的用人策略

众所周知，桓玄建立的大楚政权，是被刘裕推翻的，桓玄家族是东晋的大家族之一，桓谦是桓玄的堂弟。直接利用桓谦的政治影响力，是谍纵的主要心思。但是有这几个问题：

+   1、首先，必须从新赋予桓谦政治影响力。

谍纵想利用桓谦，就必须把他的加盟消息作为重大的新闻给宣传出去。只有让所有怀念桓氏家族的人都知道桓谦在这里才行，于是桓谦四处走动，不断和过来追随的人交往，逐步的形成势力。

+   2、其次，必须自己控制而不被桓谦利用。

看着桓谦一步步借助自己的地盘不断的做大自身实力，这对谍纵无疑是一种政治压力。如果任其发展，非但自己不能利用桓谦打击刘裕，反而会被鸠占鹊巢，成了桓谦的盘中菜。

+   3、最后，如何利用和防备之间取得平衡。

如何利用桓谦的影响力而又不被其反噬呢？这就需要谍纵做出平衡。于是谍纵想出了最佳的策略，那就是直接软禁了桓谦，反正所有人都知道他在西蜀，但是不让他接触人，完美平衡。

# 三、姚兴的先见之明

可能谍纵一开始也没有真的想去软禁桓谦，而桓谦也不认为自己本来是去加盟合作的，自己的价值还没有彻底发挥出来就会被控制起来。但是姚兴为什么就能准确预言呢？

+   1、首先，政治原理。

“小水不容巨鱼”，每个组织都希望有人才加盟，尤其是有极强能力和才华的人加盟，但是真的人才来了，小的组织往往都会对人才猜忌，这不是叶公好龙，而是领导缺乏驾驭能力，组织缺乏平台资源，同时缺乏容纳能力。所以，真正的人才去了小组织，也是不会被真的重用的。

+   2、其次，条件分析。

姚兴知道“小水不容巨鱼”政治原理，于是就开始给桓谦分析双方条件。“若纵之才方自足办事，亦不假君以为鳞翼。”这就明确的指出，谍纵个人能力不强，强的话也不会用你，现在你这么强，用你，他接纳你也是个 大问题。只要符合政治条件，政治原理就不会变。

+   3、最后，得出结论。

姚兴指出了政治原理，分析了政治条件，自然得出了未来的政治结局。所以，让桓谦“宜自求多福。”其实这是姚兴要提醒桓谦在构建政治势力的时候，一定要谨防谍纵的恶意。但是此时姚兴并没有给出具体的手法，而只是给出了祝福。究其原因，也是不想打击桓谦的积极性，不想泼冷水，自己做恶人。
