苻坚不清楚，也不会心里不开心，可能还在为自己的慷慨大度而自豪。但是窦冲挑破这个事实真相之后，又没有给苻坚解决方案，这让领导很是不舒服，苻坚内心其实对窦冲非常的怨恨。

很多时候，领导已经犯了错误，我们作为下属，最好不要指出，不管对错，不然你让领导很尴尬，不好下台。如果你揭露出来，领导会找机会收拾你的。比如《皇帝新装》那个童话故事，最后喊出皇帝没穿衣服的那个小孩子，他得到的不会是奖赏，而是会认为是小疯子，被杀掉，领导的面子比对错更重要。

# 2、让姚苌对窦冲记恨

本来姚苌开心的接受了这个尊贵的位置，内心即使有野心，此时也是偷偷的开心，因为没有被苻坚警觉。但是窦冲这句话，会让姚苌特别的不舒服。这样会让苻坚后悔，或是警觉，无论什么情况，对姚苌而言，都会认为窦冲是在给自己制造麻烦。表面上，窦冲维护了皇帝苻坚的利益，其实无形中伤害了姚苌的利益。如果窦冲不是姚苌的政敌，此举就是一个得罪人的事。没有任何收益的情况下，给自己树敌。姚苌就会记恨在心，以后有机会是会报复窦冲的。

所以，我们在职场，维护一个利益的时候，不能够只看眼前对错，要看到自己的举动，会影响到谁的利益，这个人的能力和能量如何，如果是能力很强，能量很大，这无疑是得罪不起的，这会为自己无形中树立政敌。尤其是自身没有个人利益的时候，更要看清楚会影响到谁。

# 3、自己没有任何利益

窦冲真的是豆虫啊，说这句话，得罪了两个人，而自己没有得到任何利益。很多人会问，这个豆虫该如何说才是对的呢，其实，此时无声胜有声，不该说话，但是如果非要说的话，就是，直接拍苻坚的马屁，“恭喜姚将军，贺喜龙骧将军，圣上把自己最为珍惜的名号赐给你，说明对你特别看重，别辜负了圣上的良苦用心。这也是我们大秦之福，这次南征，一定能够一战而胜。”这不仅仅是拍了姚苌的马屁，让他很开心，而且侧面点出了苻坚的用心，这样都开心，窦冲自然也会得到认可。

听起来是不是很违心？其实并不是，大战在即，重要的不能祸乱军心，应该把焦点放在好的方面，而不是那些子虚乌有的方面，让大家不开心，而且这里还特别点醒姚苌不要辜负皇上的良苦用心。也算是做了提醒，和给他上了道德枷锁，这是个皆大欢喜的局面。

经过上述的分析，我们能够看出来，职场说话一定要思考这句话，背后的利益关系。能给谁带来利益，说是能够伤害到谁的利益，如果伤害到了谁的利益，自己能不能控制住接下来的局面。不明白利益，只看对错的话谈，注定让自己走向深渊。说话的时候，尤其要记住，领导的面子比对错更重要，不要让他陷入尴尬，这样自己即使是对的，也没啥好果子吃。
