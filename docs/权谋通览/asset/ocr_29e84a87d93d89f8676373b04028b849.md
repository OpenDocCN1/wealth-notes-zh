商鞅变法，第一步就是徙木立信。任何一个当权者必须首先树立自己的诚信，晋文公刚刚得国不久，对自己的军队还没有威信，通过这次用兵，故意三日为限，给军队一个明确的信号，自己领导说了算，以后奖励也是会说说了算的，将来还有很多仗要打，大家就有了建功立业的动力，愿意追随。

# 2、对自身，用信示贤

“信，国之宝也，民之所庇也，得原失信，何以庇之？所亡滋多。”晋文公向天下人展示了自己的价值观，在他心里，把信用当成立国之宝，在得到利益和自己承诺冲突的时候，选择承诺。这样就树立起一个明君的政治形象。更具体的塑造了一个政治家的外在形象，所以这个故事历史传颂至今。

# 3、对外敌，用信示由

原国是准备投降的，被打败而投降，是个很没有面子的事情，尽管原国和晋国的实力相差甚远。所以，当晋文公诚信撤军的时候，给了原国一个投降的高大上的理由。我们不是因为怕你而投降，而是仰慕你的诚信是个明君而归顺，尽管本质一样，但是效果确实天差地别。

很多朋友会说，你多想了，人家晋文公就是这样的人，《左传》、《国语》确实不载，对原国使用诚信的权谋手法给台阶下，但是在《东周列国志》中说是赵衰出的这个用信示由的权谋计谋，贾志刚《说初春秋》说是狐偃出的，不管谁出的，这就是个心理计算的过程，而不是真的诚信。晋文公不仅仅是这一种计算，其他的说法太过单一，权谋网指出的这三点，才是晋文公权谋心思的全面所在。
