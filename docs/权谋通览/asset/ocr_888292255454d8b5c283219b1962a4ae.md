“臣闻其将屠者子，贾竖易以利。” 这两句话，不单单显示了，张良的情报能力，知道对手的将领的出身家事，而且还深刻揭示了张良的洞悉人性的能力。知道屠夫的儿子从小接受的是利益至上的价值观，可以用钱拿下。不过司马光在资治通鉴中把这段话给删除了，权谋网推断可能有三个原因，一个是司马光查明了当时守将的身份，不是屠夫之子。一个是，他思想儒家，不想让看书的人看到人性的阴暗面，还有可能是，写书的时候，身边有这样出身的人，怕被误解为影射。

# 3、兵者诡道

“原沛公且留壁，使人先行，为五万人具食，益为张旗帜诸山上，为疑兵。”孙子兵法中写了诡道十二术“故能而示之不能，用而示之不用，近而示之远，远而示之近，利而诱之，乱而取之，实而备之，强而避之，怒而挠之，卑而骄之，佚而劳之，亲而离之。” 张良使用了虚张声势的手段，让守关的秦军误以为刘邦的实力强大。很多人认为做人要诚实，要把真实的一面示人，其实在职场，大家都是竞争关系，你不知道什么时候会有人算计你，所以学会伪装，是职场第一课。

# 4、不择手段

“令郦食其持重宝啖秦将” 这段话，不仅仅是张良对人才的准确认知和使用，知道只有郦食其有胆量且口才好，能够完成贿赂这个行为。不择手段就是为了能够完成目标，使用任何的手段。很多人认为打仗就是要硬碰硬，靠自己的实力，玩行贿手段，太无耻下作，属于胜之不武。很多人会马上说不对啊？没人这么想，打赢就行。其实你看看自己在职场，是不是认为靠工作靠实力升职才是本事，那些靠溜须拍马上位的人都很无耻，胜之不武呢？做人不开窍，这也就是很多人职场不成功的原因。

# 5、出其不意

“此独其将欲叛耳，恐士卒不从。不从必危，不如因其解击之。” 这段话不仅仅反映了我们刚说的，张良对人性的洞悉，而且是使用了孙子兵法说的“出其不意，攻其不备。” 这个看起来很简单。但是这背后的思维逻辑很可怕。一是道德观，这样出尔反尔，在普通人眼里，这就是小人。一是手段观，手段太过于残暴，既然能够和平解决，为什么还要杀人。人家都和解了，并没有伤害的意图，而张良却为了主动权，持术不持信，不能给敌人伤害的可能，提前就杀了潜敌。

后来的各大决战中，张良的手段机会都是在上述的思维逻辑下布局生成的。刘邦和项羽的鸿沟议和，项羽撤退时，立即被撕破协议，背后追击，这不是也是立即翻脸的延续？而同样的派郦食其去说服齐国投降，而没有给韩信下达停止进攻的命令，齐国放松警惕后，韩信直接灭了齐军的主力，让齐国再也没有翻身的筹码。和这个让秦将放松警惕之后，立即掩杀，是不是依然很相似？张良计谋背后的思维逻辑，就这么几点，配合文中说的，擅用情报，知人善任，不惜重宝。何事不成？
