# 10.7.2 AR(p)平稳性检验

要想使用AR(p)模型进行拟合和预测，首先要检测时间序列是否平稳。这里先介绍一下如何判断AR(p)模型是否平稳。我们先假定序列是弱平稳性的，则有如下公式：

+   - E(r_t)=μ
- Var(r)=γ₀
- Cov(r_t,r_{t-1})=γ₁

其中，μ和γ₁都是常数。

因为a_t是白噪声序列，因此有如下公式：

+   - E(a_t)=0
- Var(a_t)=γ₀
- Cov(r_t,r_{t-1})=γ₁

根据公式（10-1），两边同时求期望值，可以得到：

E(r_t)=φ₀+φ₁E(r_{t-1})+⋯+φ_pE(r_{t-p})
