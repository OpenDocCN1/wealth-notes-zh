# 3.std

std函数用于计算数组的标准差。函数的第二个参数可以用来选择不同的维度进行计算。std既可以作为一个函数，也可以作为数组的方法来调用。示例代码如下：

```
x = np.arange(1,100,1)
x.std()
Out[12]: 28.577380332470412
```
