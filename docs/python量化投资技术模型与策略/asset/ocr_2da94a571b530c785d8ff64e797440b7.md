在获得的结果当中，数组的第一个数为卡方分布的自由度估计，第二 个第三个为中心值和scale。

# 7.dist.mean

dist.mean用于返回分布的均值，一般调用方法为

dist.mean(*args,loc=0,scale=1)。示例代码如下：

```
stats.beta(1,2).mean()
Out[60]: 0.3333333333333333
```
