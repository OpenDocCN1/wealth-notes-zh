+   - on_bar：回测收到新的K线时调用，实盘由on_tick调用，通常是在这里编写策略主逻辑。
- on_order：收到委托回报时调用，用户可以缓存委托状态数据以便于后续使用。
- on_stop_order：收到本地停止单状态变化时调用。
- on_trade：收到成交时调用。

- short：卖出开仓。
- cover：买入平仓。
