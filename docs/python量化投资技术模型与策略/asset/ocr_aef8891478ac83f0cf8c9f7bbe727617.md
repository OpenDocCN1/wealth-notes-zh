# 9.10 影响期权价格的因素

有6种因素会影响股票期权的价格，具体列举如下。

+   - 当前股票价格S₀。
- 执行价格K。
- 期权期限T。
- 股票价格的波动率σ。
- 无风险利率r（例如1年期国债利率）。
- 期权期限内预期发放的股息。

前4项是决定一个期权价格的主要因素，后两项一般没那么重要。不过，对红利（股息）高的股票来说，股息率可能会有相当大的影响。

为期权定价，最常用的公式就是布莱克-斯科尔斯-默顿（Black-Scholes-Merton）定价公式：

c=S₀N(d₁)-Ke^(-rT)N(d₂)    (9-10)

p=Ke^(-rT)N(-d₂)-S₀N(-d₁)    (9-11)
