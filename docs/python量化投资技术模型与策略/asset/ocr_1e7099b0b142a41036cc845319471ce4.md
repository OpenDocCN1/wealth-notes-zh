# Mean function

The mean function of a GP can be interpreted as a "prior guess" at the form of the true function.

```
In [24]: # Generate mean
def quadfun(x, a, b, c):
    return (a*x**2 + b*x + c)

M = Mean(quadfun, a=1., b=0.5, c=2.)
```
