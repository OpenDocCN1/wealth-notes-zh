# 10.9.4 建立ARMA模型

下面用10.9.3节计算出来的阶次（2，3）来建立ARMA模型，并利用拟合的模型进行预测，示例代码如下：

```
rtn=df.rtn.values

# 测试集长度
t_len=20

# 测试集
train = rtn[:-t_len]

# 训练集
test = rtn[-t_len:]

# 拟合模型
order = (2,3)
arma_model = sm.tsa.ARMA(train,order).fit()

# 获取对应的预测值
predicts = arma_model.predict(len(rtn)-t_len, len(rtn)-1, dynamic=True)

comp = pd.DataFrame()
comp['original'] = test
comp['predict'] = predicts
comp.plot(figsize=(10,5))
```
