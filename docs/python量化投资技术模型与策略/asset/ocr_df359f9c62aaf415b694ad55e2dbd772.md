对于之前提到的夏普率最大化的规划问题，读者可以尝试解决。

最终的closed form solution结果如下：

w* = (Σ)⁻¹ μ / 1′(Σ)⁻¹ μ

其中，μ为各项组成资产的风险溢价收益，Σ为溢价收益协方差矩阵。
