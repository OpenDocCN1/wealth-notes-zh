# 1.偏度

skewness代表分布的偏度特征，偏度描述的是一个分布的“不对称性”，其计算公式为：

skewness = E\left[\left(\frac{x - \mu}{\sigma}\right)^{3}\right]

为了理解不对称性，我们先来看几个对称分布，示例代码如下：

```
import seaborn as sns
import numpy as np
x = np.random.normal(size=10000)
sns.distplot(x)
```
