histogram2d(x,y)可用于计算2维的直方图数据。可以 Probabilistic parameters
bins来定义直方图的箱体数。bins既可以是一个整数，也可以是一个包含两个元素的列表，分别表示各维度的箱体数。

下面来看个相关的示例，同样，首先生成两个随机数组，代码如下：

```
import numpy as np
x = np.random.normal(size = 100)
y = np.random.normal(size = 100)
```
