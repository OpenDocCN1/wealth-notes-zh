# 3.1.2 选取数组元素

有时候我们需要选取数组中的某个元素，在NumPy中可使用下标来进行选取，下标是从0开始的。示例代码如下：

```
In[25]: a=array([arange(1,5),arange(5,9)])
In[26]: a
Out[26]:
array([[1, 2, 3, 4],
       [5, 6, 7, 8]])
```

在这里，我们创建了一个2×4的数组。元素的示例代码如下：

```
In[27]: a[0,0]
Out[27]: 1
In[28]: a[0,1]
Out[28]: 2
In[29]: a[0,2]
Out[29]: 3
In[30]: a[1,3]
Out[30]: 8
```

对于数组a，只需要用a[m,n]选取各元素即可，其中m和n为元素的下标。
