有了df，我们就可以使用多个基于DataFrame的内建方法了，下面来看看相关的示例。

按列求总和，代码如下：

```
df.sum()
```

输出结果如下：

```
A      0.241727
B     -0.785350
C     -0.547433
D     -1.449231
dtype: float64
```

按列求均值，代码如下：

```
df.mean()
```

输出结果如下：

```
A      0.030216
B     -0.098169
C     -0.068429
D     -0.181154
dtype: float64
```
