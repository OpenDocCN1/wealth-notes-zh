```
c = ws['A4']
```

在获取了一个cell对象之后，就可对其进行赋值操作了，代码如下：

```
c.value = 'hello, world'
```

单元格对象都有相应的数据格式，比如为变量赋值日期格式，格式就是'yyyy-mm-dd h:mm:ss':

```
import datetime
ws['A1'] = datetime.datetime(2010, 7, 21)
ws['A1'].number_format
```

输出结果如下：

```
'yyyy-mm-dd h:mm:ss'
```

```
ws['C1'] = 0.1
ws['C2'] = 0.1
ws['C2'].number_format='0%'
wb.save('format.xlsx')
```
