```
In[19]: s=pd.Series([1,2,3,4],index=['a','b','c','d'])
In[20]: s
Out[20]:
a    1
b    2
c    3
d    4
```

在这里，我们将索引定义为a、b、c、d。这时也可以用索引来选

取Series的数据，代码如下：

```
In[21]: s['a']
Out[21]: 1
In[22]: s[['b','c']]
Out[22]:
b    2
c    3
```

对Series进行数据运算的时候也会保留索引。示例代码如下：

```
In[24]: s[s>1]
Out[24]:
b    2
c    3
d    4

In[25]: s*3
Out[25]:
a     3
b     6
c     9
d    12
```
