例如，寻找A列中值大于0的行。首先，生成一个布尔数组，代码如下：

```
df.A>0
```

输出结果如下：

```
2016-01-01    False
2016-01-02    False
2016-01-03    True
2016-01-04    True
2016-01-05    True
2016-01-06    True
2016-01-07    True
2016-01-08    False
Freq: D, Name: A, dtype: bool
```

可以看到，这里生成了一个Series类型的布尔数组。可以通过这个数组来选取对应的行，代码如下：

```
df[df.A>0]
```
