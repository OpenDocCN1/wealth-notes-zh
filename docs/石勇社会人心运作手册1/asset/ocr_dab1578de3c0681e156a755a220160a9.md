# （5）相同的心灵气质会互相吸引

第五种心理同盟跟心灵气质有关。

相同气质的心灵吸引相同气质的心灵，不同的心灵气质则会相互在心理上拉开距离。

你在生活中可能能够感觉得到，对于某些人，无论是明星，还是你接触过的人，你确实从内心里很讨厌，甚至你说不出理由是什么。是“三观”不一样吗？并不仅仅是，有时候甚至不是。

比如，你是一个不装，不喜欢咋咋呼呼，在网络上玩流行词，动不动就“网红”就“打卡”，深受消费主义洗脑的人，当看到某些人这样玩觉得很时尚时，你并不会觉得这很好玩。而且你可能认为这些人挺装。你和他的交往，只局限于表层，你发现这些人根本不可能向你敞开内心。你倒是很喜欢对人敞开内心，但是，往往受伤。

如果要静下心来，你可以体验得到，你和这类人，在内心深处，根本不是一路人。你们在这方便，是无法形成相互支持的，你们不可能是心理同盟。

同时你也能发现，这个世界有些人和你一样，也天然讨厌装，装的话会有压力——道德压力和心理压力。这些人和人交往时，也喜欢简单直接，不玩弯弯曲绕。如果他感觉你好像也算友好，他也想向你掏心掏肺，而不喜欢把真自我藏在角色后面，或以假自我来面对别人。

有些夫妻在结婚前，沉浸在心理结构表层的愉悦中，和社会条件的相互匹配，认为婚姻还不错。但是，相处一段长时间后，社会条件的匹配已经意义不大，心理结构深层次的东西也暴露了出来，其中的一方会发现对方其实很陌生，大家并不是一路人。那个时刻，会涌上一种失落感或遗憾。他或她会感觉到，在心灵气质上，双方并不是心理同盟。
