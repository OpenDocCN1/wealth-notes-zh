# 12、格商在社会阶层竞争中的“次级淘汰”

一大批人连格商都不想起动一下，没有格商的基础性，确实是没有办法的事情。不过，还有另一大堆人，起动是没有任何问题的。他们具备格商的基础性。换句话说，还是有一定的精神能量，让他们能够起动格商。

比如，很多人都会在中小学阶段认真读书，然后考上大学。或者在工作时，是认真的，也在学各种知识。

也因此，他们基本避免了被淘汰在社会底层的命运。

但是，在这个过程中，有一些人坚持不了多久，就受不了了，就容易切换到心理来玩，因为仍然是发泄心理能量最爽。他们一年可以换几次工作，做一件事没多久就放弃，学知识也只是想找“知识的感觉”，热衷去各种装，连买杯奶茶都可以排几个小时的队……

所有这些，都是想切换到心理来玩的表现，尽管可能加上了各种时尚热点和价值观念的包装，比如所谓的“佛系”“自我”，把自己归入某一类“粉”，就是包装。

包装有几个意思：给假自我打扮；合理化；在社排上自我提拔。

但明眼人可以看出来，这些人虽然具备格商的基础性，但却缺乏格商的终极性。支持人格的精神能量，也就一般般。
