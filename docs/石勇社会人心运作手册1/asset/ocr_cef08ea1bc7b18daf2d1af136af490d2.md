# # 3、如何判断大势？

下面我们分别来讲。

先说对势的判断。

萧何、曹参为什么不敢当带头大哥？是因为无法判断总的趋势，对沛县起义的那一帮人所代表的势也没有十足的信心。

黎元洪为什么开始不敢坐湖北军政府都督的位置，连说“莫害我，莫害我”？同样是以为大势还在清朝一边，没法未卜先知地看到推翻帝制、各省独立、建立民国这样的天下大势。

搜狐没有看到移动互联网的趋势，诺基亚没有看到智能手机的趋势，也是如此。

我们没看到大势的第一个重要原因，是社会是高度复杂的，远不止一种势，而是 N 种，我们搞不清楚哪一种势最终会怎样，甚至都不一定能够看到关键的势。

用革命领袖恩格斯的话说：“历史是这样创造的：最终的结果总是从许多单个的意志的相互冲突中产生出来的，而其中每一个意志，又是由于许多特殊的生活条件，才成为它所成为的那样。这样就有无数相互交错的力量的，有无数个力的平行四边形，而由此就产生出一个总的结果，即历史事变，这个结果又可以看作一个作为整体的、不自觉地和不自主地起着作用的力量的产物。”

换句话说——

+   （1）有无数种势。
