# 10、利益同盟和心理同盟不是纯粹的

这个社会，或者说这个世界，有一些人、群体、组织、国家，确实是纯粹的利益同盟或心理同盟，比如大家就是奔着利益结成同盟的，没什么感情、理念、信仰可谈，用过去的一句话 说，谈这些虚的东西就伤钱了；或者，大家就是奔着感情、理念、信仰而来的，彼此之间要谈钱，谈利益分配，就伤感情了，至少有点不好意思。

但这个世界当然不会这么纯粹。有更多人、群体、组织、国家，彼此之间不是纯粹的利益同盟或心理同盟，而是利益同盟-心理同盟或心理同盟-利益同盟。

利益同盟-心理同盟的意思是，以利益同盟为主，同时又是一个心理同盟，但心理同盟是为了利益同盟服务的，是为了更好地粘连利益同盟。比如，两个人合伙做生意，搞得有感情的样子，他们的感情并没有独立的价值，是为赚钱服务的。一旦他们两个人在利益分配上谈不到一起，可能就会闹翻，所谓的感情也就不复存在了。

心理同盟-利益同盟的意思是，以心理同盟为主，利益同盟为辅，利益同盟好像是为了更好地服务于心理同盟，做大这个同盟。但我说的是“好像”。虽然你是以心理同盟为主，但一旦也形成利益同盟，利益同盟在服务于心理同盟的同时，也具有了独立的意识。搞不好，它也会把自己做大，最终，这个心理同盟-利益同盟，一样会因为利益分配谈不到一起而崩溃。
