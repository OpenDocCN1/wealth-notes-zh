这些人完全不懂，一般情况下运作关系是有前提的：合法性。比如要提拔你，比如要把你安排到这个职位，得有可以说出来显示合法性的理由。关系在很多时候，只是在符合条件和内在实力的基础上，可以拿到台面上去说点什么东西，从而让我们后面要讲的心理同盟-利益同盟或利益同盟-心理同盟内的成员，获取某种优先权或独占权而已。

# ## （4）社会资本：一个人的社会 IP

社会资本是一个很社会学的概念，有点复杂，但我们并不需要搞得这么复杂。通俗点说，就是一个人在他所处的结构社会位置中，所具有的影响力、话语权，可交换资源的能力，是一个人的社会 IP。

这个社会 IP 之所以有影响力、话语权，可交换资源，就在于它具有某种合法性，既让人有所敬畏、忌惮，又让人信任、认同。

前面所讲的嘉靖皇帝朱厚熜，本来只是一个皇族，是兴献王朱佑杭的儿子，朱佑杭受封就藩在湖广安陆，朱佑杭死后，朱厚熜也就继承了他老爹的地位。

朱佑杭又是谁呢？是成化皇帝朱见深的儿子。朱见深死后，继承皇帝位的是朱佑杭的哥哥朱祐檏，是为弘治皇帝。而朱祐檏死后，传位给了儿子朱厚熙，是为正德皇帝。

就是说，朱厚熜和朱厚熙共有一个祖父，他们是堂兄弟。但是，皇帝的传位，因为祖父朱见深是传给朱祐檏这一宗的，而不是传给朱厚熜家，按理没朱厚熜什么事。

关键是，朱厚熙继承皇帝位后，特别喜欢玩，非常夸张，还专门修建了一个豹房来玩，30 岁时就死了。他并没有子嗣。
