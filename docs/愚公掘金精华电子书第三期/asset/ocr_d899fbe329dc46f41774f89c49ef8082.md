# ### 1.向上汇报的常见问题

**【准备不充分】**

日常工作中，缺乏一些工作总结和思考，缺乏一些资料的整合，领导突然说下周要做项目汇报。这时候就突然临阵磨枪，通宵达旦。
然后过程中发现各种数据缺失、进展缺乏汇总、项目好坏不知道何故、未来该怎么做更是“丈二和尚摸不着头脑”。
