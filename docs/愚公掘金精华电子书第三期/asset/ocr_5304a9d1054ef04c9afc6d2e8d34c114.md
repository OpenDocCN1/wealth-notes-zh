# 一、我的时间算得准确么，真的是这样的吗？

为什么我会第一个先给大家抛出这样的问题？

你会发现你做很多很多的TODOList，90%都是没法当日事当日毕的。你做了很多的时间规划，永远都是变化赶不上计划，难道不是么？

继续摊牌。浪费时间的三大元凶是：你根本就不了解自己的时间、你天天就干点杂活、你一个劲给你自己加事情。

好，回来，简单说一下这三个元凶。

你根本就不了解自己的时间：你真以为早上处理个微信消息只有10分钟？其实处理着、处理着，20分钟，30分钟，1小时，2小时过去了。
