# 【花爷】我是如何看待三胎政策的

作者：花爷梦吃换酒钱

都在调侃三胎政策，花爷来认真讲讲我的看法。

我们做运营的时候，常常会做一个“推”的动作。比如你是卖汽车的，那你的用
户，可以粗暴分成几个档次。

+   - 0档：一辆车都没有的。
- 1档：有一辆经济适用车型的。
- 2档：置换了舒适豪华车型的。
- 3档：有多款车型的。
- 4档：有多款豪华车型的。

这么分肯定不精准，先凑合看。

面对不同类型的用户，你会怎么运营？你努力让一辆车都没有的人，一下子买多
款豪华车型吗？肯定不行啊，没人买。

一般来说，运营都是努力把用户“推”到下一个阶段。

你一辆车都没有，我先推动你去买一辆经济车；你有经济车了，我推动你换量豪
华车；你有豪华车了，我推动你买多种车型，适用多种生活场景......

用户所处的阶段，可能会跳跃性成长（比如第一辆就买豪华车），但很难一步到
位，得一档一档的往下推。
