# 一、关于搜索排名与权重的秘密

我们首先要搞懂笔记搜索排名的底层逻辑。

当用户想买点啥、或者犹豫去哪儿，他会先用百度或其他引擎搜索某个关键词了解。搜出来的内容排名越靠前，曝光量越大，也越容易主导这个用户的消费决策。
