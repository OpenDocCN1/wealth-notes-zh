我做IP当时考虑了两个方向：

一个是从我自己主业和专业出发，毕业以来我一直在云计算、企业服务领域领域，从工程师到产品经理到产品战略和商业化，自己经常也上各种峰会论坛演讲，在垂直领域积累了一定的知名度度。如果把这些做成内容，受众就企业客户，但内容专业性较高，我一个想破圈的人，也并不想老用公司积累的知名度做IP，所以相对圈子会比较局限。

另一个方向，也是现在我走的的定位，做这个斜杠、职场破圈相关，这一类内容更to C ，更大众了，面向的问题也更有共性。
