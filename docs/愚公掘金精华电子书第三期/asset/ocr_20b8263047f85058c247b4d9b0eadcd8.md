实科普、通俗且专业的内容就会非常有感染力。这里重点强调一下：真实、真诚、利他，带货只是顺便的，这种心态一定要有。就像我们在一篇回答里写的那样：恰饭归恰饭，良心归良心，当我们的观点转换过来了，带货就自然而然了。有些小伙伴说，我想短平快怎么办？直接投知+走付费流量。

# 4.略高于读者的认知是必要元素

对于一些观点性的问题，需要我们有比较明确的立场和观点，并根据我们的立场和观点进行作答。对于这类问题常常一个问题下很多回答都是同质化的，所以要有意识的和别人错开核心点，常常和大众或常规性认知略有不同的观点，或者略高于读者的认知。但是认知超过太多也不好，不容易引起共鸣，比如向坤老哥去年在知乎复盘自己创业过程的一篇文章，我看了评论区的，这就是超出大家认知太多的文章，很多人会觉得你在吹牛。甚至，一些乍一看有些擦边的观点比较容易火起来，但前期不建议大家过多回答观点性的问题，意义不是很大。

# 5.情绪引导是爆文的人工干预剂

很多高质高赞回答，创作者在文章的开头、结尾和正文中都是有意识的进行情绪疏导和引导，引起读者的情绪共鸣，这样才能引发读者的下一步动作，比如点赞、关注、收藏等，所以我们要根据文章内容进行有效引导。我们在进行情绪引导时，主要要进行积极情绪互动，同时不要过于频繁的引导，表情包、搞笑型的互动引导效果最佳，大家多去研究
