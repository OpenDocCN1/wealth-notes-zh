# 观点

百科介绍说：

一指观察事物时所处的立场或出发点二指专指政治观点，从一定的阶级利益出发所形成的对事物或问题的看法三指从一定的立场或角度出发，对事物或问题所持的看法

因此，今天很舒服是我对今天气温的一种感受，一种看法，所以这个 是观点。回到第一个问题：

**1）首先是项目真实情况（不容有报喜不报忧的情况）**

我们第一部分介绍，就要将项目本身的真实情况去讲出来。比如今天投入了6个人，当前进展30%，预算花了100W，覆盖到了了10W个用户，转化了1000个用户来购买。

这些就是事实，是项目本身的进展，大家一开始要重点介绍。再用严谨的逻辑来串联起来的话，那就是：你在什么时间/环境、做了什么事，产生了什么效果。

专业术语再来解释一遍，那就是请遵循STAR原则，如下：

STAR原则 S（situation）情景，我是在什么情况下干的这件事 T（task）任务，我的任务是负责干嘛 A（action）行动，我做了哪些
