# 使用工具的第一阶段：直接使用成熟SCRM平台

企微运营离不开工具，为尽快用上SCRM工具、降低人力投入，我使用的第一个SCRM是供应商提供的。挑选SCRM工具的4个小技巧：

+   ① 在使用之前确认更换SCRM工具的成本，我用的工具如果更换的话可以说是零成本；

+   ② 降低封号等风险，确定使用的SCRM是在企微的开发规则内合规进行；

+   ③ 进行试用，判断SCRM是否能满足基本运营需求；

+   ④ 了解清楚哪些数据是在不使用SCRM后，能同步到企微中的，我用的只同步标签，标签是我最看重的沉淀，对我来说这作为过渡的工具，已经足够了。

我最开始使用的SCRM工具包括7个主要功能：

+   ① 数据分析：昨日关键数据、用户增长趋势图、用户消息处理情况

+   ② 企微号：用户管理、标签库、用户扩展、群发、自动回复、聊天记录查询、朋友圈

+   ③ 企微群：群数据、群管理

+   ④ 话术素材：话术库、素材库、知识库

+   ⑤ 营销引流：红包、活码、海报和小程序引流

+   ⑥ 电商运营：绑定电商店铺、了解订单

+   ⑦ 云平台：同时登录多个企微号，进行沟通
