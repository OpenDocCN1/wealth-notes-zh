# 六、推广返佣链接

可以看到，目前的链接有三种形式：

口令红包：美团链接可以直接在微信端打开、饿了么需要复制口令到淘宝打开或者复制链接到浏览器打），所以不建议推广饿了么口令红包。

二维码链接红包：美团外卖红包二维码可以直接长按识别打开、美团也支持图文链接转发；饿了么的二维码链接均为小程序

小程序码红包：主要是饿了么在使用

综上：美团红包无限制，口令红包、图文红包链接、二维码海报均可直达红包领取界面、饿了么尽量推红包小程序。

选择适合自己的获客方式
