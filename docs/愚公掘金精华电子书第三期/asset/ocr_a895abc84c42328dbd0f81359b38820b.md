# 1、开始前准备

+   1.公司资质

**原因：** 需要注册服务号，所以需要公司资质，可以用公司也可以用个体户

**工具：** 【阿里云】

**操作：** 直接搜索“工商注册”第一个进去，9.9元注册个体户，所有套餐都不选，付费9.9即可，注册过程中代办公司可能会要求你开税务代办等套餐，就说都是0报税，不需要这些服务

**时间：** 3~5天

**成本：** 代注册9.9元+执照到付成本（因地而异）21元=30.9元
