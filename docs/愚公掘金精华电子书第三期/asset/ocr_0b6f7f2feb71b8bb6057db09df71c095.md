# ## 2. 域名备案

**原因：** 前期用不到，是为了后面做活动防封

**工具：** 【阿里云】、【腾讯云】、【华为云】均可

**操作：** 以阿里云为例，直接在平台上选择购买域名相应选项，挑便宜的买就行，买好后需 2-3 天才可备案，备案直接在淘宝买备案号（腾讯云也可以直接在淘宝买授权码），不用买服务器，关于域名备案的完整流程可以完全参照阿里云内教程，这里就不再赘述

**时间：** 3-5天（可与其他进程同步进行）

**成本：**

阿里云：域名 8 元 + 备案号 1.32 元 = 9.32 元

腾讯云：域名 8 元 + 授权码 13.99 元 = 21.99 元
