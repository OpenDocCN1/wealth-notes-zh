# 使用工具的第二阶段：打通产品数据和群内用户数据

社群用户数量少的时候，我都是在与用户的交流中一一询问用户账号昵称或ID（大家可以理解成知识星球的昵称或编号），然后再去后台查询用户信息，为用户打上对应标签或昵称备注以便增加对用户的了解。
