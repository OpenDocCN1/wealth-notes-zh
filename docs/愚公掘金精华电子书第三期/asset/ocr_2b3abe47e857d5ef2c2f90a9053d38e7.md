# 一、为什么要去做抖音？

这个话题我想大家看到过无数次，无论是出于什么原因，答案也都大同小异，那我就来表达一下我自己最真实的想法。

想通过抖音获取大量的公域流量，完成闭环，同时倒逼自己输出，学习，成长，跟上时代。

这个生态体系应该是这样，抖音是流量大平台，微信号，视频号，公众号，属于私域流量，通过抖音导流到私域进行转化变现，大部分行业都适用这个体系，只要需要和人打交道的生意，都需要用这套流量闭环。
