# 及时复盘，就是纠偏的关键一环。

如果你能坚持每周复盘，就会有 52 次拿出 GPS 和卫星地图，面朝目标，重新调整路线的机会。

对关键项目进行及时复盘，总结经验和教训，才能有效避免在同一个坑里，反复失败。
