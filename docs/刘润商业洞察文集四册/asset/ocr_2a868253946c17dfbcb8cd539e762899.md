# 016篇：“培训”的商业本质到底是什么？

去年 11 月 13 日，我在有幸受邀参加“2020 国际培训产品博览会”，会上分享了我对培训行业的一些看法。

分享的主题是：培训的商业本质。

我自己是商业顾问，做咨询，做培训。也很高兴能和一些同行，以及想进入这个行业的人一起交流。

培训别人的 人，如果自己不懂培训的本质，会是一个很大的挑战。

在培训行业，大多数人都认为应该是“种下栖桐树，引得凤凰来”。

但是这几年，我发现的现象却是，满地都是栖桐树，天上却找不到几只凤凰。

培训的平台很多，但是好的培训课程，却相对少。

我们应该专注做什么？培训行业的未来是什么？

我在分享中，用了三个对比，讲了讲我的理解。
