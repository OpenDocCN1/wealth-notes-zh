# 因为没有人愿意慢慢变富

前两天，进化岛社群一位同学向我提问，这个问题很有代表性。

他做了一款食品。感觉不错，想卖给饭店，但是总怕饭店不接受。

于是想，要不要自己开连锁加盟饭店，这样就可以要求他们必须卖自己的东西了。

我个人建议他，专注做好这款食品。不要贸然开饭店。

如果开饭店，那就算好好开饭店，不要以强行卖这款食品为目的，而开饭店。

为什么？

我们把做食品叫做 A，开饭店叫做 B。想用 B 带动 A，通常是因为对 A 没有信心。

A 的价值，可能只有 0.8，或者 0.6，所以想用 B 来拉动。

可是，开饭店可能并不比做食品容易。没开过饭店的人开饭店，B 的价值，可能只有 0.6，甚至 0.4。

那么，现在就好理解了。

这位同学做了这么复杂的事情，最后的价值是 A x B = 0.6 x 0.4 = 0.24。
