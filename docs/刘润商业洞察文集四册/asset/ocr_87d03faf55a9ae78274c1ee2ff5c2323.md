# 最后的话

如何判断做的事情有没有前途？工作值不值得做？

判断行业是在哪个“点线面体”上，判断公司适不适合自己，判断岗位是不是在核心位置。

如果你觉得很好，应该祝贺自己，然后更加从容、勤奋地努力。

如果你觉得不够好，应该要及时做出调整。

最后还想多说一点，换的时候，记住一句话：

换行不换岗，换岗不换行。

如果都换，对行业不了解，对岗位也不了解，工作就需要从头做起，会很麻烦。

希望这篇文章，可以帮助你做一些判断，能够帮助你做出一些更好的选择。

祝，成长，并成功。
