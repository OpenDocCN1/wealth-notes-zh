变量，是节点；因果链，是线段。

但线段有头就有尾，能量从头传到尾，就结束了。

那如果，我们把结尾和开头也用一条因果链连接起来，形成闭环呢？

这就形成了一个“回路”。

回路有两种，一种叫做增强回路，另一种叫做调节回路。

# 什么是增强回路？

两条“增强”，或者两条“减弱”的因果链，首尾相连，形成一条“回路”，就是“增强回路”。

# 其中，因增强果，果又增强因，叫正向增强回路。

# 因减弱果，果又减弱因，叫负向增强回路。

![](bbox=[0.188, 0.962, 0.865, 0.001042])

比如，你越有知识，积累新知识的能力就越强；积累新知识的能力越强，

你就越学富五车、才高八斗；然后就更能理解新知识。

如此不断增强。这就是一条正向增强回路。

比如，你越有信用，别⼈越愿意和你合作；别⼈越愿意和你合作，你就能积累更多的信用；
