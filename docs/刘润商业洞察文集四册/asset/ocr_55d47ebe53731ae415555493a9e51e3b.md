# 承认错误，是什么意思？

你可能是企业的创始人、高管、管 理者，尽管你高高在上，但不代表你永远正确。

# 开放，是开放信息，开放心态。

很多管理者经常觉得自己员工“傻”。对业务一无所知，对业务一窍不通。

但你要知道，员工的无知，是管理者的失职。

因为你掌握更多的信息，知道更多的情况，他们不知道。他们不了解相关的信息，当然就没办法理解业务。

# 所以，开放就是允许他们提问，甚至允许他们挑战你，允许他们提出尖锐又恰当的问题，让他们获得足够的信息。
