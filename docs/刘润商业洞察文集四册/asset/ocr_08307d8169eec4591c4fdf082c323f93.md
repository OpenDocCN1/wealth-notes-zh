# 009篇：越是经济寒冬，越要理解什么是经济周期

这个冬天，是真的有点冷。

改革开放 40 年，我们国家的 GDP 增长了 33.5 倍，年均增长 9.5%。

其中很长一段时间，年均 GDP 增速超过了 10%。

那 2018 年呢？

6.6%。

2019 年呢？

2019 年，第一季度增长 6.4%，第二季度 6.2%，第三季度 6.0%。

有人预测，第四季度，甚至会跌破 6。

我们国家今年 GDP 的增速，将会成为 1991 年至今的最低点。

明年，也许会更低。

企业们都觉得，寒冬来了。

可是，你知道吗？

很多发达国家同期的 GDP 增速，其实比我们国家要低得多。
