## 019篇：为什么赚钱这么难？

真正大智慧的人，往往都很“笨拙”。

## 因为没有人愿意慢慢变富

前两天，进化岛社群一位同学向我提问，这个问题很有代表性。

他做了一款食品。感觉不错，想卖给饭店，但是总怕饭店不接受。

于是想，要不要自己开连锁加盟饭店，这样就可以要求他们必须卖自己的东西了。

我个人建议他，专注做好这款食品。不要贸然开饭店。

如果开饭店，那就算好好开饭店，不要以强行卖这款食品为目的，而开饭店。

为什么？

我们把做食品叫做 A，开饭店叫做 B。想用 B 带动 A，通常是因为对 A 没有信心。

A 的价值，可能只有 0.8，或者 0.6，所以想用 B 来拉动。

可是，开饭店可能并不比做食品容易。没开过饭店的人开饭店，B 的价值，可能只有 0.6，甚至 0.4。

那么，现在就好理解了。

这位同学做了这么复杂的事情，最后的价值是 A x B = 0.6 x 0.4 = 0.24。

还不如只做好食品。

这就是我们常说的：把驴板绑在一起，也成了航空母舰。

那人们还常说：强强结合嘛？是的。

强强结合指的是 A>1，B>1。比如 A 是 1.5，B 是 2，这时你得到的价值是 A x B = 1.5 x 2 = 3。

这就是强强结合。

但这有前提，就是 A 和 B，都要大于 1，也就是说，都是强者。

当你对 A 没有信心时，也就是 A<1 时，是没有办法通过一个可能更 niez 的 B，来拉动的。

你最重要的工作，是把 A 做好。

一堆上游下游的二流公司，不但不会结合出一流公司，还会把大家都变成三流。

为什么赚钱这么难？因为没有人愿意慢慢变富。

聪明人都在苦修参功夫，千锤百炼“A”这个核心内核。

很多同学经常会问，我这份工作做的不很好，想要放弃，想要换个行业从头再来。

实际上，这个想法是非常有投机性和危险的，因为放弃了自己多年的积累，等重新开始。

在你原来擅长领域的周边找机会，往往成功概率更大。

也有很多同学，想做一件事时，初始收益不明显，就觉得这件事情不值得做，放弃了这条路径。

其实，这也是非常不理智的。

不能在一个方向上形成可叠加的进步，就难以完成有价值的积累。

真正大智慧的人，往往都很“笨拙”。

都在苦修基本功，苦练真功夫。
