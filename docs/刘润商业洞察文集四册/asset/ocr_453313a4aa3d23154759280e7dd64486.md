# 如果你和你老板一起坐出租车，你坐哪？

你应该主动坐在副驾驶。

5 人座的车，右后座是最尊贵的位置。把这个座位留给老板，让他觉得舒服。

# 如果是你老板开车，你坐哪？

你还是应该坐副驾驶。

如果你坐在后排，那老板成了你司机，他可能会不舒服。

# 如果老板开车，你上级也在，你坐哪？

这个时候，副驾驶成了剩下的座位里，最尊贵的位置。
