# 搜索路径：被“需求”激发的购买路径

要看明白这个问题，我们首先要理解，消费者购买产品的三条路径：搜索路径，内容路径，和社交路径。

一个个来说。

首先，什么是搜索路径？

家里洗衣粉没了。你去超市买。整个超市走一圈，没找到。问服务员。服务员说，就在前面第三排货架上呀。你走过去一看，果然在那里。然后，你在几个洗衣粉品牌里比较parate比较去，选了一个大牌，买了走人。

注意，你的整个购买行为，是从一个明确的“需求”开始的。

因为这个需求，你去搜索，比较，然后产生购买。这就是搜索路径。
