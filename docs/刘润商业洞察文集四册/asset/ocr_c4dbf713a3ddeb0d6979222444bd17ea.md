# 利润，是收入的质量。

如果你去看每年福布斯世界 500 强名单，按收入排名，在很长一段时间
内第一名都是沃尔玛。

但是大家其实并不最关注收入的排名。大家最关注什么呢？

# 关注市值。

今天市值最高的公司是苹果。

市值来源于利润。

苹果公司的收入虽不如沃尔玛，但是他的利润要比沃尔玛高很多。

# 所以，利润，是收入的质量。

你接着问一开始那个企业家，你今年利润有 6000 万，那你给员工发奖金了吗？

他回答，还没有。因为利润虽然有 6000 万，但是账上没钱啊。客户的货款还没打给我，账上的现金也都去进货了。

你看，虽然在财务报表上，他的利润有 6000 多万，但是他账上其实并没有现金流。

即便账面上赚了那么多利润，但是利润还没有变成现金进入他的账户，想用暂时也用不了。
