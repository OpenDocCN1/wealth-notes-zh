那人们还常说：强强结合嘛？是的。

强强结合指的是 A>1，B>1。比如 A 是 1.5，B 是 2，这时你得到的价值是 A x B = 1.5 x 2 = 3。

这就是强强结合。

但这有前提，就是 A 和 B，都要大于 1，也就是说，都是强者。

当你对 A 没有信心时，也就是 A<1 时，是没有办法通过一个可能更 niez 的 B，来拉动的。

你最重要的工作，是把 A 做好。
