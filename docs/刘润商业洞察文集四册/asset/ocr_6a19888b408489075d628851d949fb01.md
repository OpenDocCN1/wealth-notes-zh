# 之所以对谈佳芬老师，是因为当今时代红利渐渐消失，潮水逐渐退去的背景和现状。

想要在潮头吃立不倒，企业家实力很重要，企业家精神也很重要，佳芬老师作为老一辈企业家的代表之一，她在光明的故事就显得尤为珍贵。

她刚到光明时，就经历生死未定的时刻，那时正是国企改革浪潮的开始；站稳脚跟后，也经历光明从上海走向全国的偶然和艰难；开疆拓土的路上，如何培养像虎狼之师一样的子弟兵队伍，成为头发的难题……

老一辈企业家谈起过往的故事，有一种久违的年代感，也有一种挥之不去的回忆感。在这些故事中，我们年青一代也许能够体会那个时代的企业家精神、城市精神、时代精神。
