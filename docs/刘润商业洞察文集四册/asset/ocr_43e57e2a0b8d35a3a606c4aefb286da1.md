# 那柔性生产怎么做到的？

通过模块化设计。

原来洗衣机是由几千个零部件组装起来的，海尔现在不这么干了，它把几千个零件分成 25 个模块。

前门是个模块，有红、黄、蓝等颜色可供选择；烘衣功能是个模块，可以有也可以没有；控制面板可以选择是电脑面板或者机械面板。

设计好模块之后，消费者可以对这些模块进行选择，在天猫旗舰店下单，定制的需要被派发到生产线上。

机器人就可以按照订单，在同一条流水线上，生产不同的洗衣机。

这样实现了洗衣机的定制化。

因为模块化，才实现了柔性生产，实现了定制。

最近，我带领问道中国的学员，参观了两家制造业的企业，一家是"上汽大众"的柔性工厂，另一家是做厨具的"我乐橱柜"。

# 他们都在做 C2B 反向定制化生产。

比如，上汽大众有 C2B (Customer to Business, 即消费者到企业) 的网站，油漆、轮子的轮毂有多种选择。
