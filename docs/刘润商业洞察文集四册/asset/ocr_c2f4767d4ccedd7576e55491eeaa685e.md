# 去掉了库存。

零售有一个特点，就是不能准确地预测未来。

像服装行业，为了给面料和成衣生产留出时间，品牌商往往在今年春季，就要预测明年春季流行什么样的衣服。

但是，哪个款式、颜色、尺码好卖？能卖多少？这些都无法准确预测。

这就带来了库存问题。

# 现库存，一是占用资金，二是卖不掉怎么办。

# “反向”本质就是：我彻底干掉了成品库存。

去掉了库存资金占用，减少风险，同时资金的利用率也大大提高。

比如，红领西服，先收款再生产，消灭了库存，成本大大下降。虽然直接制造成本比成衣高 10%，但是因为减少渠道，消灭库存，总体成本约只有成衣的一半，所以纯利润率能达到 30%。

再比如，我乐橱柜的板材是原料库存，但是没有成品库存。

板材原料可以根据消费者的喜好灵活组装处理，减少库存风险，而如果是一大堆成品在仓库，没卖掉风险太高了。
