# 如果责任太大，就会导致消极怠工。

只有任务，没有利益，那么就不会有人执行。只有任务，没有权力，没有资源，巧妇难为无米之炊。

所以，磨洋工就是大多数人的理性选择。

# 如果权力太大，就会有权力寻租。

只有权力，责利不清，那么手里几百万的审批权，几千万的签字权，就会导致寻租。

舞弊，贪腐，就是这么来的。

坐在这样的位置，别说尽心尽力，有时连独善其身都很难做到。

# 如果利益太大，就会有斗争冲突。

利益独大，没有什么责任，就是我们说的“好差事”。

这种肥缺，大家都在盯着。每天就是资源争夺，互相使绊子，组织会陷入极大的内耗。

陷入内卷的组织，很难有真正的战斗力。

所以，管理最基本原则和心法，就是责权利对等。
