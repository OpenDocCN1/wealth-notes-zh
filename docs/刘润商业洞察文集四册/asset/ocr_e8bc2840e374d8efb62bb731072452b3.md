# C2B

理解 C2B 之前，需要先了解什么是 B2C。

B2C，是指商家（Business）直接面向消费者（Consumer）销售产品和服务，是最常见、最基本的商业模式。

把这一模式放到线下，就是超市、商场、购物中心；把这一模式放到线上，就是当当、京东、天猫。

但如果把 C 和 B 调换位置，变成 C2B，就会发生本质改变。

从 B2C，到 C2B，是从产品等需求，到用需求找产品。这是企业按照消费者的需求提供个性化产品与服务，是对传统 B2C 模式的根本性颠覆。
