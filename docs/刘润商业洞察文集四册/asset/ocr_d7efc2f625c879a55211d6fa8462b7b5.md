# 最后的话

2020 年，是魔幻的一年。

除了触底反弹，除了业务增长，我开始不断思考，我自己的定位。

我一直说，CEO 的职责是，取之于势，不责于人。

对外，我的工作，是不断发现新机会，寻找新资源，制定匹配的战略，给团队赋能。

对内，我只做 3 件事：1、制定责权利；2、坚守价值观；3、做一只安静的内容奶牛。

我有自己的性格，我有自己的偏好，我有自己的问题。

但是，我会坚持做好一只头狼该做的事情：对外寻找更大的战略赋能，对内建立更好的工作氛围。

今天这封信，就是为这个目的而写。

我希望你能清楚地知道，我的思考，公司的方向，团队的管理方式。我也争取在每一年相交之际，用邮件的方式向你报告我的这些想法，以供你判断，这不是一家值得继续携手并进的公司。

如果你认同，那么，让我们一起在这个巨大不确定的世界中，携手创造那个确定的 2021。
