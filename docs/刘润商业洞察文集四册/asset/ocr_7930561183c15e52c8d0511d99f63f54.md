# 企业如何进行招投标？

在企业，为了防止腐败，超过一定金额的项目，往往都要进行招标。

参与招标的企业，至少要有三家。 企业招的“标”，通常有两种：

一种叫 RFQ (Request for Quotation)。报价请求。我有方案了，你们出个价吧。

一种叫 RFP (Request for Proposal)。方案请求。我有个想法，但我不知道怎么做，你们提个方案吧。

在 RFP 中，通常又要招两个标：

一个叫“设计标”。这个系统，你打算用什么逻辑实现？有什么功能？界面长什么样？

决定好之后，付给中标的公司一笔费用。

然后，再招一个“实施标”。你们谁能把这款设计落地？谁的技术实力强？谁的服务更好？

同样，为了防止腐败，设计标和实施标，不能由同一家公司来做。
