# 现在你可以有两种方案供选择：

第一种，杭州买房。总首付不低于 50 万，购买总价 150 万左右的二手房屋。具体地段选在杭州武林 CBD 核心区，以西湖文化广场为中心，原则上半径不超过 3 公里。单价在 3~4 万左右的房子。有合适的房源就及时拿下，2002 年以后带电梯的新型社区、次新房。不要对楼层朝向面积户型过于挑剔。因为力量有限，地段最重要。只要户型不畸形，没有明显遮挡，就基本可以。

商业按揭贷款 110 万左右，30 年等额本息方式还款，月供约 5837.99（元）。加上房屋租金，对你没有压力。

第二种方案，燕郊买房。其它没有什么变化，只是把具体区域选择到燕郊来。

# 两种方案的优劣：

杭州租金更高，同时可能可以提取公积金或者用公积金贷款（和商贷的利率差可以基本忽略不计，不算这个小账）。

燕郊可能涨幅更大，但是租金更低。

两者权衡，我个人更建议燕郊。因为，年轻人要激进一点，以尽快做大资产为首要目的。不要一下子只奔自住目标，最快的距离不是直线是曲线。
