# ### 追宗思源

所谓“经济乘数效应”，就是别人生产一根筷子，只需要 2 分钱，我们因为成本高，变成了 1 毛钱，5 倍乘数。为什么成本高？大家自行脑补。显然，这种模式是不可持续的。它会表现为：
产能全面过剩；
债务无穷积累（主政者只把债务不断留给后人）；
成本无限提高。
即使没有贸易战，内部危机也会必然发生。
而此番贸易战的本质，不是顺逆差问题，而是发展模式之争，是“华盛顿共识”还是“北京共识”的问题。
