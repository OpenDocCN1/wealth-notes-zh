# ## 3. 做大资产与价格偏高的矛盾取舍

买房最基本技巧：1选择自己能够买得起又有购房资格或不限购的人口长期流入、营商环境较好区域；2在此区域内，选择市场价或略低于市场价的房子；3尽可能通过最低首付和最长年限等额本息还款方式把资产做到最大。
