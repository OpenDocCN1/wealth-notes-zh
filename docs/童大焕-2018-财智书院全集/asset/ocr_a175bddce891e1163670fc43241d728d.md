# 童大焕一2017.5.11日~5.14

这是一个颇具挑战性的题目，我姑妄写之，你们姑妄看之。结论很重要，推导的方法和工具更重要。

哪里房价高？首先是同地段同类同级房屋的比较，而不是均价比较，这个必须先明确。同时这篇文章只说最高，第二三四位不说。

我将从以下5篇文章及其它有关收入、气候两方面一共7大方面提供的数据，来包抄这个问题。

1《最新富豪榜“泄露”的秘密：北京成过去十年最大赢家、天津顶级富豪竟不到重庆四分之一！》（2017-05-10 智谷趋势）：

日前，“2017新财富 500 富人榜”发布，新经济富豪强势崛起，房地产风光不再，制造业韧性十足。正如《新财富》杂志所言，一定程度上，中国的富豪榜，长得越来越像美国了。

2007 年时，前十大中国富豪中，来自地产界的竟然高达7人。前8大富豪中，除了第5位的施正荣属于制造业，其余全部是房地产大亨。而到了2017年，前十大富豪中至少有6位来自于新经济。无论是马云的阿里巴巴，还是王卫的顺丰、马化腾的腾讯、丁磊的网易、雷军的小米、李彦宏的百度，都是这个时代发展和变革的反映。

前十顶级富豪所在地，北京成最大赢家，浙江（杭州）表现也不俗，上海、江苏被甩在身后。曾经上海、江苏各有2名富豪进入前十，而目前十大富豪中，再也没有上海、江苏的影子。

此外，同样是 2017 前十大富豪，马云的阿里、马化腾的腾讯、丁磊的网易，虽然总部不在北京，但没有谁敢不重仓北京！

即便是新经济制造业都极为强势的广东，到了2017年，中国前十大富豪中，也比 2007 年时少了2位。曾经广东拿下6个席位，而今为4个。

美的的总部落依旧在顺德，其他9大富豪企业的总部，除了杭州，全部在北京、广州、深圳一线城市。这是中国各类资源越来越中心化汇聚的体现。

分地区看 2017 上榜富豪数量，广东 114 人、北京 84 人、浙江 63 人、上海 58 人、江苏 33 人，位列前五，五地的名次与去年相同。
