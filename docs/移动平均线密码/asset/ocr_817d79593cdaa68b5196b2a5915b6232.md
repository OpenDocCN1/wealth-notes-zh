# 穆斯克的回應 讓<特斯拉>市值蒸發20億美元

向來都和華爾街分析師保持良好關係的<特斯拉>（Tesla）執行長穆斯克（Elon Musk），這次法說會卻變了個樣，不過這也讓他付出慘痛的代價，<特斯拉>的盤後市值瞬間蒸發 20 億美元。

<特斯拉>原本昨（2）日發表的財報結果還不錯，也承諾會解決 Model 3 的生產問題，股價表現波動不大，但是穆斯克之後的法說會卻意外擺了個大架子，拒絕回答分析師各種有關未來獲利遠景的問題，使<特斯拉>投資人罕見給了他差評，<特斯拉>盤後股價因此大跌 5%，市值崩跌 20 億美元。

以下為穆斯克法說會與分析師對答的節錄～：

+   ⊙<特斯拉>將今年的預期資本支出從 34 億美元調降至 30 億美元，財務長 Deepak Ahuja 解釋，公司將簡化自動化方法和削減基建經費，分析師問：「所以你們哪些部分會特別需要資本？」

穆斯克答：「不好意思，下一題。這問題又蠢又無聊，一點也不酷。麻煩下一題。」

+   ⊙分析師問：「到底有多預購 Model 3 的人真的有去領車？」

穆斯克答：「對不起，這些問題太枯燥了，我聽了很想死。」

+   ⊙Ahuja 回答分析師問題時提到<特斯拉>的電池在業界是「最佳等級」，穆斯克打斷他的話說：「是最佳。沒有等級。在最佳這個等級裡只有一家廠商。」／2018/5/4
