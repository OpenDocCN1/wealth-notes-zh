# ## 【5 日線滑落 60 日線：死亡交叉】

5 日線滑落 60 日線，是「死亡交叉」的一種，線形發出「賣出」的訊號。空頭市場將要來臨，投資人應斷然的賣出手中的持股，不要猶豫。

一般說，這是下跌第三波的「再跌段」的下降。

太陽既會升起，就會下山；下山之後的黑夜，月亮會躍然而起，取而代之，成爲世界的主角。這是大自然的運行之道；景氣循環也是這樣子，股市也是這樣的週而復始，只是有人「抄底」了，有人「斷頭」了。
