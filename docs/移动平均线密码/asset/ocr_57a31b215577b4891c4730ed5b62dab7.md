# 投資人的頭號大敵

投資人的頭號大敵——並不是股市本身，而是自己；即使你擁有超級的數學、金融、財務會計知識；但是，如果你無法控制自己的情緒；那麼，你也是不可能在投資的過程中獲利的。——華倫.巴菲特（Warren Buffet）

# ＃．費雪（Philip A. Fisher）的8點要訣

+   1. 必須經過勤奮不懈的努力，誠信正直，才能在股市中投資成功。

+   2. 一定要盡快地承認自己所犯下的錯誤，力求改進。

+   3. 選擇一家成長的、具有前景的公司，做為投資目標；並且能阻擋新加入者分享其高成長的獲利。

+   4. 堅持自己判斷的勇氣，不盲從、也不排斥主流意見。

+   5. 追求資本的大幅成長，應把配股配息的股利看淡一些。

+   6. 集中全力購買——那些因為市場誤判而失寵的體健公司。

+   7. 充份把握好的投資機會，在股價偏低時，集中資金在最有利可圖的出色公司上面。

+   8. 抱牢自己手中的好股，直到發生根本性的改變，或公司成長率已不再高於整體經濟了。
