著鼓其如簧之舌的本領，使他人信以爲真，而加以購買，支持或追隨，事後終於發現吃虧上當者，都可歸爲「騙」——像是：

+   ·某男子以結婚爲許諾，在得手後逃之夭夭；
·神棍術士以風水改運爲許諾而讓婦女獻身，這些都是「騙色」。

+   ·或者是像某些商人的假造赫赫的學經歷，讓別人在輕信之餘而購買其可疑的商品；
·賣場將油魚混冒圓鱈而販賣；
·或将逾期商品換個新標籤再繼續陳列出售；

+   ·江湖女子編造可憐身世，要別人爲其贖身還債，錢財到手後杳如黃鶴一般的失蹤。
·許多人以國稅局退稅、或電信局退費等名目，然後利用他人善意的無知——而將別人戶頭裡的金錢據爲已有

以上的型式，統稱是「騙財」。

至於從事政治活動者，以激情不實、或是不能履行的主張，甚或刻意編造的虛假故事及表演，而讓他人信以爲真並加以支持者，則是所謂的「騙選票」。

「騙」這個字從馬從扁，扁是偏側的意義記號，因此「騙」這個字本來是指「從旁邊上馬」的動作姿態，而到了明清兩代，今天所謂的「欺騙」這種意義才完全取代了它的本義。
