# 達文西密碼

> 我們要小心別讓冒險犯難的精神失去了，像是對知識的飢渴，或是果斷的去探究我們本身能力的極限。——美國總統雷根（Former President, Ronald Reagan）

2004 年時，《達文西密碼》這部小說稱霸美國暢銷書排行榜，駁斥或聲援的相關書籍也在市面湧現。這種「達文西熱」，在十九世紀後期的歐洲也出現過。但是，2004 年前後的達文西熱和十九世紀的熱潮，正好成為對比：二十一世紀對人類淪喪信心，便將達文西視爲探索宗教的路徑，從世俗回歸信仰；十九世紀的歐洲卻對前景樂觀，便將達文西視爲發掘人類潛力的跳板，從信仰奔向世俗。
