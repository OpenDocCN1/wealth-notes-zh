# 20日移動平均線（月線）
（多空指標線）

> “Home, Sweet Home” must surely have been written by a bachelor. ----- Samuel Butler （甜蜜的家庭》的這首歌，一定是單身漢寫的。——山繆爾.巴特勒

20 日移動平均線，因爲不長不短，所以就成了技術分析的「多空指標」；這意思就是說，20 日移動平均線上揚，就代表股價的趨勢（Trend）向上，而 20 日移動平均線下跌，就代表股價的趨勢（Trend）走空。它是短線投資人從事波段操作的多空指標，買進賣出常常是以它的依歸。

一般說，如果股價滑落 20 日平均線，表示目前的技術面已經轉壞，投資人手中的持股可以考慮暫時出脫。

相對的，如果股價突破（Breakout）20 日平均線，表示技術面已經轉好；投資人的持股可以續抱或是加碼買進。

當 20 日移動平均線由平向上走時，技術面是由空轉多，中期的行情看好。

當 20 日移動平均線由平向下彎時，技術面是由多轉空，中期的行情看壞。
