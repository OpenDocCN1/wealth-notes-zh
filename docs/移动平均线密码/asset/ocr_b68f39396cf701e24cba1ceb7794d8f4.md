# 賈伯斯的三個故事

賈伯斯到史丹福大學的畢業典禮演說全文

賈伯斯（Steve Jobs）是電腦業界的標準人物，他從小被加州一個工人家庭收養，只讀了一個學期的大學。1976 年，二十一歲的他與史帝夫.沃茲尼亞克合作，在自家車庫裏成立了蘋果公司。

1983 年，賈伯斯邀請約翰.史考力出任蘋果執行長，並推出第一台麥金塔電腦，引發很大的迴響。但不到一年即遇上電腦產業的蕭條，史考力接管了公司，將賈伯斯趕出蘋果。

之後，賈伯斯創立 NeXT 電腦公司與皮克斯動畫工作室，推出全球第一部 3D 立體動畫電影《玩具總動員》，十一年後被迪士尼收購，賈伯斯因而成為迪士尼的董事會成員與最大個人股東。

隔年，蘋果電腦收購 NeXT，賈伯斯重回蘋果掌管大權，推出 iMac，令陷入財政困難的蘋果起死回生。之後又推出 iBook、iPod、iTune 等產品，廣受好評。

2004 年，賈伯斯罹患胰臟癌，開刀治療後恢復健康，身為虔誠佛教徒的他，也對生死有更深刻的體會。
