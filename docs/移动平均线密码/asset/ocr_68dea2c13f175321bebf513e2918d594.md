股價在大漲表現過後，往往陷入長時間的整理，七個月是平均來看；在整理期間，痛苦的套牢族——逐漸不堪忍受，而將股票認賠殺出……；大戶逐漸的以低價取得這些股票，儲蓄了來日上漲的動能。

「乖離率」(Deviation Ratio)，簡稱 BIAS，是描述價格與某種天期的移動平均線的相距的遠程序度。這 BIAS 指的是相對的距離。這乖離率的計算公式與參數如下：

```
N日乖離率 = $\frac{當日收盤價 - N日移動平均價}{N日移動平均價}$ × 100%
```

如果我們用字母與符號來表示，就是如下：

```
BIAS(N) = $\frac{C_n - MA(N)}{MA(N)}$ × 100%
```

在上述的公式之中，分子是價格（股價的收盤價）與移動平均價的絕對距離，它是可正可負的；在除以分母之後，就得到相對的距離。

另外要注意的是，移動平均價是一元時的相差 0.1 元，與移動平均價為 10 元時的相差 0.1 元，是有不同的，這時除了考慮絕對距離之外，還要考量相對距離的。

# 乖離率的參數

在乖離率（BIAS）的公式中，含有參數的項目只有一個，就是移動平均線 MA。因此，MA 的參數，也就是乖離率（BIAS）的參數——也就是說，乖離率的參數，就是移動平均值的天數
