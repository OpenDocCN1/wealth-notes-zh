# 財測太過於短視 巴菲特沉重呼籲：別再提供

「股神」巴菲特和摩根大通執行長戴蒙（Jamie Dimon）在《華爾街日報》專欄聯名撰文，向上市企業提出呼籲，「別再提供每季財務預測」，理由是如此舉——會扼殺長期投資與經濟。

兩人主張：「季度財測重視短期獲利，這種關注並不健康，忽視了企業長期策略、成長及永續性。」

巴菲特和戴蒙是財金界泰斗級的人物，2人強調，向華爾街透露財測數字，會影響管理層的決策優先。他們補充，為了達到財測數字，企業會遲疑於科技、雇員及研發支出，但有時季節因素難免影響財測，是管理者難以掌控的因素。

戴蒙一直對財報過多的揭露事項及短視不滿，摩根大通2月的投資人會議，他就要求企業停止提供財測，強調獲利本就難以預測，會誘使企業美化數字。巴菲特也呼應，強調財測會導致企業的不當行為。

兩人還說：短期獲利的達標壓力，導致過去20年美國上市公司的數量下滑。它們的說法是：「短視傾向的資本市場，令有長期目標的企業不想上市，剝奪了經濟的創新與機會」。

根據波士頓非營利團體 FCLTGLOBAL 在 2017 年的報告，財測會導致企業未來投資不足（under-invest），抑制獲利成長。

該報告說，2016年約3分之1的 S&P 500 企業有發布財測，從 2010 年的 36% 略降；包括聯合利華、臉書、葛蘭素史克藥廠和英國石油等企業，都不再發季度財測，以未來數年的展望取而代之。／2018/06/07
