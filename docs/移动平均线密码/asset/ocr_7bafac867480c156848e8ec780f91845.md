進」的訊號；如果收盤價由上而下滑落移動平均線，那是代表「賣出」的訊號。或者是說，價格在移動平均之上，則是做多；價格在移動平均之下，則是放空。

一般說，投資人的操作金律如下：

+   (1).如果該日收盤價超越前 N 天期的平均價，那麼就補空而做多，或進場買進績優股現股。

+   (2).如果該日收盤價滑落前 N 天期的平均價，那麼就翻多而做空，或賣出持股，出場休息。

+   (3).要注意的是，這 N 的參數的設定與系統的敏感度息息相關。如果 N 設定得很小，那麼這是一種快速系統；快速系統可以在小型的波動走勢中獲利。例如期貨市場上常用的 4-9-18 日三種均線，或是股價的 5 日均線，那麼系統不斷的與均線纏繞在一起，容易發出趨勢（Trend）反轉的訊號，當然錯誤的訊息 (whipsaws) 也較多。

+   (4).如果你把 N 參數設定得很大，這就屬於一種慢速系統；它在明顯的走勢中可以獲利。例如 N=30，那麼錯誤的訊號可以降低，但卻又延誤了進場／出場的時機。

一般說，移動平均的期間長度 N，應該是市場循環長度的一半；循環是指由谷底到谷底。例如，如果循環長度是 28 天，也就是說，從谷底到谷底的時間是 28 天，那麼應該採用 14 天的移動平均。

爲了避免無謂的誤判，這些交易人還注意到移動平均線的發展方向必須與穿越的方向相同，這才是有效的突破。
