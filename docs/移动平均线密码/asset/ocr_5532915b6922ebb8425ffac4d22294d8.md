# 當沖分時線的乖離率

在當日沖銷中，也可以成功的運用乖離率賺錢的！

如果設定「五分鐘移動平均線」已經形成頭肩底，這時配合乖離率的使用，勝算是相當大的。負乖離率在最大之後的開始縮小的時點，就是進場買進的最佳時機

當「五分鐘移動平均線」由下向上突破「10分鐘移動平均線」時，就是當沖進場買進的好訊號。

因此可見，乖離率的時間運用，是可大可小的；小到分時線的運用，大到週線與月線都可以搭配。
