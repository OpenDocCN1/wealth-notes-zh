# 企業主分為「創業者」和「繼承者」
中國大陸年輕企業家 未加強技術創新

〈中國家族企業年輕一代狀況報告〉2017/12/4 在北京發布，調查報告顯示，大陸年輕一代企業家所管理企業，經營績效要高於年長一代企業家，在企業發展思路上，更願意選擇擴張戰略。

本次報告以 45 歲爲界，小於 45 歲（含 45 歲）的企業主稱爲年輕一代企業家，大於 45 歲的企業主視爲年長一代企業家，並進一步將企業主分爲創業者和繼承者。
