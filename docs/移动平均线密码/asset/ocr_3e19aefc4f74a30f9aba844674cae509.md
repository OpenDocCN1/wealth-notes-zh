# 在正確的時點買進或賣出

李佛摩爾（Jesse Lauriston Livermore）反覆不斷強調：「重點不在於你買得有多便宜，而是在正確的時點買進或賣出。」操盤手必須持續的關注股價的變化；耐心的等待趨勢發動之後才進場；並且在趨勢結束之後就退場。

# 股價超越5日平均線

如果當日收盤價穿越5日平均線的是漲勢的「中長紅線」，那就當然的敲進。

如果當日收盤價穿越5日平均線的是觀望的線型，那就暫緩下注。因爲這可能只是一種雜音。

如果當日收盤價穿越5日平均線的是跌勢的線型，那可能只是一場假突破（premature breakout）罷了，多作交易無益，所以暫緩進場。

融資融券的投資人，在股價超越5日平均線時，回補先前放空的空單，或是進場買進建立新的多頭部位。
