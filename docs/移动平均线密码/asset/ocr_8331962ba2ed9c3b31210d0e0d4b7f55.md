# 當天上掉下黃金時

全球證券市場上每個月都上演著大漲大跌的把戲；那些推升的人，大多是先知先覺的大股東等人；證券市場上每個月也都上演著大跌的把戲，嚇得散戶無厘頭的倉惶逃生；其實，在大跌與大漲之間，是有黃金屋的。

例如，在無厘頭的大跌日之中，買進跌幅最深的績優股，然後在一週之內拉回賣掉、或是在大漲之日再賣掉，是可以賺到錢的；因爲它是天上掉下的無厘頭黃金，所以也不會像金融海嘯那般的重；重點是你能不能接得住而已。
