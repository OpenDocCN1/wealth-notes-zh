# 女秘書模仿律師老闆投資 賺到2.7億

美國有一名女秘書 模仿律師老闆投資 賺到2.7億台幣

紐約一名法律事務所秘書西爾維亞.布魯姆（Sylvia Bloom），在同一家法律事務所工作了67年，96歲才退休，退休後不久便在2016年過世，她靠著模仿律師老闆投資，賺進900多萬美元（新台幣2.7億元），但生前守口如瓶，從沒讓親朋好友知道，直到她在遺囑中將大部分遺產捐出作為獎學金，身家才曝光。

布魯姆的外甥女珍.洛克辛是布魯姆的遺囑執行人，她回憶說：「布魯姆那時候當祕書要包辦老闆的生活大小事，包括個人投資，所以當老闆要買某一檔股票時，她會幫老闆買，然後自己跟著買同一檔，只不過數量少些，因為她領的是祕書的薪水。」

布魯姆在三家證券公司和11家銀行的財富總額超過900萬美元。由於布魯姆從不談論她的身家，就算對密友也一樣，所以親朋好友在她過世後才猛然發現她是富婆。洛克辛回憶，她自己的反應是「哇我的天！」
