舉債經營是標準的「兩面刃」;這意思就是說，適度的舉債，可以充裕公司的營運資源，為股東創造更大的利潤。但是過度的舉債，可能陷公司於險地。

# 股價滑落5日平均線

如果當日收盤價滑落5日平均線的是白線漲勢的「中長紅線」，可以稍作觀望，或是參考其他的指標。

如果當日收盤價滑落5日平均線的是觀望的十字星線型，那就停損出場。

如果當日收盤價滑落5日平均線的是下跌的「中長黑線」，股價即有可能一瀉而下，應立刻停損出場，並且休息一陣子。

融資融券的投資人，在股價滑落5日平均線時，回補先前做多的多單，或是進場賣出放空，以建立新的空頭部位。

# 確認與背離

股價與5日平均線一起下跌，兩者互相「確認」（confirmation），可以賣出持股。

如果股價下跌，而5日平均線上揚，這是形成所謂的「背離」
