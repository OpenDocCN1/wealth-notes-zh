# 使用技術分析的人不是『投資人』？

葛萊姆（Benjamin Graham）的《智慧型投資人》（The Intelligent Investor）在談到——支持使用這些技術方法的人時說道：

> 由於他們所做的事與本書所使用的『投資人』一詞無關，所以我們略而不提。——葛萊姆（Benjamin Graham）

《智慧型投資人》一書是葛萊姆將《有價證券分析》一書重編簡化——以方便閱讀與瞭解的簡易版。
