# # 青蛙效應

19 世紀 1，美國康乃爾大學做過一次著名的煮青蛙實驗；經過精心的策劃安排，他們將一隻青蛙丟進煮沸的油鍋裡，這隻反應靈敏的青蛙在千鈞一髮的生死關頭，突然用盡全力，一下子躍出了使牠葬身的油鍋之中，而跳到鍋外的地面，安然逃生。

半小時之後，牠們使用一個同樣大小的鐵鍋；這一回在鍋裡放滿了冷水，然後把那只死裡逃生的青蛙又放到鍋裡；這隻青蛙鍋裡面觀賞的來回的遊客；接著，實驗人員悄悄的在鍋底用炭火慢慢加熱。

青蛙不知究竟，悠然的在水中享受著「溫暖」，等到牠察覺到鍋裡的熱度已經使牠熱到受不了時，必須奮力一才能活命之時，一切爲時已晚；牠欲躍乏力，全身癱瘓，呆呆地躺在水裡，終於葬身在熱鍋裡面。
