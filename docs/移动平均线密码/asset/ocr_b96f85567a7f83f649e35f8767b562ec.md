用寓言的形式，去介紹基本理財的原理，並以黃金代替現代的貨幣。

全書共有十一章，介紹怎樣透過一些有效的方法，去累積自己的財富？書中提出一個有效的方法，就是把每月收入之十分之一儲起來，留待將來之用。透過時間的增長，把這些開始時——看似不重要的小錢，怎樣變成重大的財富。這個就是先付給自己 (Pay Yourself First) 的原理事。

要累積財富並不在於知道有多少投資理論，而是要有決心及實行起來。如果由少年開始實踐這個方法，會比年老之時才實行的效力大得多。全書只有一百多頁，文字比較簡易及容易了解，原因之一，這是一入門書籍，給予大眾看的；其次是這本書的前身，其實是銀行及保險公司所派發的理財小冊子。因爲這些小冊子大受歡迎而且易讀，因此最後才結集成書。

書中有些章節的題目相當吸引，例如《七項治療瘦小荷包的方法》及《黃金的五項定律》，單看題目已覺得有趣。

而七項治療瘦小荷包的方法，包括～：

+   ①.每月把收入十分之一儲起來；

+   ②.控制消費；

+   ③.通過投資令財富增長；

+   ④.防止財富損失；

+   ⑤.擁有自己的物業；

+   ⑥.保證未來收益

+   ⑦.增加自己的賺錢能力。

這些方法是簡單而常見的，但亦屬知易行難。
