# IKEA組裝家具 是婚姻殺手？

IKEA（宜家家居）組裝家具可能害夫妻失和？心理學者指出，在組裝家具過程中容易引起夫妻爭吵，美國加州洛杉磯大學的心理學者、女教授杜瓦索拉（Ramani Durvasula）更稱 IKEA 的一個組合櫃爲「離婚製造機」，因該家具需要兩人協力組裝，複雜的過程容易導致夫妻吵到離婚。

爲甩掉惡名，IKEA 最近研發出新設計，把入榫技術應用於裝嵌，令組裝家具變得更容易快捷。

由於不少人搬新家或重新裝潢時，喜歡逛 IKEA 尋靈感，當情侶逛到廚房區，免不了討論以後誰做飯，逛到兒童房又討論起生育問題，等到真買回家組裝，又開始吵架。一項調查顯示，17%的人曾組家具組到吵架，反觀買東西時吵架的人僅 6%。

有鑑於複雜組裝容易令伴侶反目，IKEA 於是開始研究新的入榫技術，近日推出「讓伴侶和睦相處」的家具，希望不必動用一口螺絲、金屬及細件零件，便可組裝家具。

新設計除了方便組裝外，亦令裝嵌時間大減，過程由 24 分鐘縮減至 3 分鐘。德國著名設計協會還頒發紅點設計大獎（Red Dot Awards）予 IKEA。／2017/03/09*
