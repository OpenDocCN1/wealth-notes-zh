時候持相反的論調；特別是在交易員、散戶投資人（Individuals）或企業之間，總會有各種聲音影響到整個市場。如果大眾的看法都一樣，市場就不會有波動或變化。所以在多頭市場（Bull Market 牛市）時，只有「憂慮之牆」才能提供指數修正後再度攻頂的動能與力量的。

如果我們將整個市場動能看成是由許多不同的、有時甚至看法相互矛盾的混合體，就不難瞭解到爲什麼當整個市場似乎有志一同的朝一個方向移動，會突然有另一個強大的力量將態勢拉往反方向。

# 6個食坐養生法：防病抗老 大大降低罹病率

+   1. 選擇當季清爽的菜色：以蒸煮、川燙、清炒的食物爲主；並且蔬菜比例要高，肉類以限一份爲原則；或是完全的素食。

+   2. 選擇當季水果：水果購買的管道多，外出時可攜帶方便食用的水果，像是芭樂、香蕉、番茄等等，適時補充維他命C。

+   3. 避開麵包、炒麵、大亨堡等等：那是一些營養單一，並且高油、高鹽的食物；它們對於慢性病患者不分不利。

+   4. 坐姿不僵硬：適時的移臂走位；坐著的時候，可提醒自己，保持挺胸縮腹的姿勢，那有助消除腹部脂肪，或防止腰痠背痛。

+   5. 吃太飽就不坐：吃飽之後，應起身走動至少 15 分鐘，避免馬上坐著不動，避免脂肪堆積與影響末梢血管血液循環。

+   6. 疲倦時不算提神飲料來硬撐：疲倦時應適時休息，或是避免在極度疲倦時，還強迫身體運作。
