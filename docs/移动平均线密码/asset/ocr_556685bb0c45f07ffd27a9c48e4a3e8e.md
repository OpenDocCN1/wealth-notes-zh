# 不必火中取栗

市場之中瀰漫著很多的迷湯，像是「火中取栗」之類的話就是。

富貴穩中求就好了！不必講什麼「富貴險中求」的話！有的公司的業績忽上忽下，看似得了躁鬱症一般，通常這種股票的下一步都是打入全額交割股之列。

便宜的股價，並不能保證公司不會倒的。

市場之中，有一派人愛看趨勢，還有一派愛看價值。但是看趨勢有一個缺點就是，愈會漲的個股，你就愈樂觀；愈會跌的個股，人們就愈悲觀。

相對的，如果你是看價值投資的人，愈跌你就愈覺得便宜了，愈漲你就覺得貴了！
