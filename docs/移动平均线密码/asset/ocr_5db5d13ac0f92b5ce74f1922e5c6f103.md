# 移動平均線的類型

—————沒聽說過的公司股不買，不知道公司產品的也不買

投資不是賭博，而是一種經濟行爲，只要努力就會有收獲，這是日本股神是川銀藏先生說的話。

交易人因爲持股時間的長短，可以分成幾種——

+   ①「當日沖銷交易人」(day trader)：當天或幾天之內進出。
②波段交易人 (Swing trader)：在幾個星期或幾個月內進出。
③「數十年交易人」(decades trader)：像是巴菲特的那種持股數年或數十年之久的投資人。

# 依時間長短的分類

短天期的移動平均線，可以分成：5 日移動平均線、10 日移動平均線、12 日移動平均線。

中天期移動平均線，可以分成：(1).20 或 24 日移動平均線：月線，也被看成是技術線的多空指標，相當的被技術分析師們所重視。(2).30 日移動平均線；(3).60 日移動平均線：「景氣線」或是俗稱為「生命線」。
