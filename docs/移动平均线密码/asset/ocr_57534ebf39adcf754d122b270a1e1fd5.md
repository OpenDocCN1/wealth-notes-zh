# 要預測什麼時候會發生

——奧瑪哈先知：投資之神

我覺得要預測會發生什麼事情比較簡單，要預測什麼時候會發生是很困難的。——華倫.巴菲特（Warren Buffett）

隨著美元一路下貶，股市高手巴菲特又新添一個封號--炒匯高手。由於美國雙赤字問題嚴重，國際美元疲弱不堪，2004 年下半年跌勢更趨沈重，迭創新低，兌歐元甚至一度跌破一・三三美元歷史新低價。美元一路探底，也應證巴菲特不但是股債投資大師，預測匯率走勢的精準度也相當犀利。他兩年前即透露生涯首度介入國際匯市，開始建立美元空頭部位，而看空美元的理由就是美國迅速膨脹的貿易赤字。
