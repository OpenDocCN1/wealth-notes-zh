雖然快速系統與慢速系統，各自適用於不同的市況；不過根據統據資顯示：在大多數的情形下，慢速系統的表現優於快速系統。

# 股價與短期均線

如果投資人採用的是非常短期的均線，例如 5-10 天的移動平均線，那麼價格會與均線緊靠在一起，經常發生穿越的現象。這樣的性質實在是有利有弊。因爲太過敏感的短期均線，使得交易訊號發生的頻率明顯的提高，因此而誤判下注的機會也大。同時，交易人所付出的交易佣金也會大幅的增加！

相對於「長期均線」來說，「短期均線」比較容易提供「假訊號」，但也能夠提早發出訊號；換句話說，移動平均線愈敏感，它就能夠「及時」的提供訊號；不過，也可能發生參差反覆的情況。

# 假訊號是天敵？

假訊號——是順勢交易系統中的天敵！

快速交易系統中，行情經常出現某種大幅的趨勢（Trend）走勢的交易訊號，但又立即折返忙煞了交易人，這是使用順勢系統的夢靨。而在短期快速交易系統中，這種現象時常發生，所以稱作是「反覆」（whipsaw）。
