# 有錢人都想知道自己的缺點

+   有錢人的思維
請占卜師幫自己看看有什麼不好的地方！

![](bbox=[0.36, 0.15, 0.62, 0.5])

很多有錢人經常請人占卜。只不過，和一般人不同的是，他們都希望占卜師告訴自己有什麼地方不好。比起好的地方，他們更想知道不好的，跟一般人相反。

為什麼呢？因為有錢人和成功人士的周遭，越來越多阿諛奉承的人。他們非常清楚願意勸諫自己的人越來越少，進而察覺到危機，因此想從客觀的角度找出不好的地方。我覺得有錢人能如此積極地進行危機管理，真的很厲害。
