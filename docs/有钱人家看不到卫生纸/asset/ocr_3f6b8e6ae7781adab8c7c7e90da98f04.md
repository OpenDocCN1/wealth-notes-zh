# 有钱人乐於分享

和有钱人聊天非常愉快，因為他們告訴我很多事情。和他们聊天，不但擴展了我的視野，也讓我度過非常刺激的時光。  某一次我問道：「為什麼這麼親切地告訴我這麼多呢？」有钱人這樣回答：「好事情当然要跟大家分享呀！」  他們明白人無法一個人獨自活下去的道理，所以重視與人之間的關係，以朋友多多益善為人生哲學。  而另一方面，讓人覺得惋惜的人，都是不懂得感謝的人。他們認為全部都是自己的功勞，所以不覺得別人幫了什麼忙。因為財源源自於人緣。過得自我中心，做什麼事情都容易碰壁。

有钱人看得到衛生紙，没錢人在冰箱貼紙
