# 有錢人刻意不察言觀色

有錢人不察言觀色是理所當然。即便是聚餐等情況，到了決定好要回家的時間，以一句「那我先走囉」回家去，漸漸的周遭其他人也會默認「那傢伙只要時間一到就會回去」。有錢人的自我管理就是做得這麼好，所以生活才不會走調，也不隨波逐流。

例如，有位知名的棒球選手，即便參加聚餐，回到家後也一定練習揮棒，每日的功課絕不懈怠。因為持續就是力量。把規律的生活視為理所當然的有錢人，其實出乎意料的多。
