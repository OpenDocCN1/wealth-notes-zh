# 有錢人用畫和植物裝飾東邊

東邊可以帶來成長、活躍、新穎的能量，若在东邊放置具有相同含意 的東西，例如成長中的植物、充滿活力生氣的畫等，可以放大效果。

配合各個方位的含意和能量，放置相同或相似的物品效果佳。例如，裝飾畫掛在哪都可以，但是配合方位裝飾相同特質的畫，效果更好。而在容易帶來厄運的北邊和東北邊，則適合用明亮的畫趨吉避凶。
