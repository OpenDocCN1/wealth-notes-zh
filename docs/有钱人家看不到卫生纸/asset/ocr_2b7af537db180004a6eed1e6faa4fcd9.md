# 有錢人一拿到名片就馬上稱讚

有錢人另一個打招呼的技巧是，一拿到別人的名片就馬上稱讚。例如：「這個名字好棒喔」－真是有品味的名片耶」。繼之就是先稱讚，然後才問「您是住在○○嗎？ 」之類的問題。

稱讚可以卸下方防，使之後的溝通更加順暢，也能讓對方記住你。

無論是銷售商品，還是銷售服務，其實都是在銷售自己。而在交換名片的瞬間，就可以給予對方好印象。
