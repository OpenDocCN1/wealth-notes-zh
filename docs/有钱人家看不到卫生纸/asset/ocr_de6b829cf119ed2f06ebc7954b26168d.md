# 有錢人香氣飄溢

有錢人對味道很敏感。他們一定會注
意到好聞的氣味，然後說：「這個味道好
香。－而且，每個有錢人都有各自喜歡的味
道，房間都飄溢著香氣。

這個跟整潔很重要的想法有關。有錢人
明白，大家會把錢花在讓自己舒適的地方，
整潔就是其中之一。

例如，同樣是去吃飯，髒兮兮的餐廳和乾
淨的餐廳，大家應該比較想把錢花在乾淨的餐
廳吧。不管料理再怎麼好吃，髒兮兮的地方實
在很難讓人甘願掏錢出來。

只要味道好聞，人一旦心情愉快就願意
花錢。有錢人明白人這種微妙的心理。
