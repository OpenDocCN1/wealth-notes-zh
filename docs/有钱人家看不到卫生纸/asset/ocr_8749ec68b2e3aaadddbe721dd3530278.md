# 有錢人喜歡乾淨整潔、
討喜且憨直的人

事業成功、成為有錢人的人，他們
明白人生是別人決定的道理。

例如，即使舉手說：「我想做那項
工作！」對方未必願意讓你做。這是很
簡單的道理，即便不斷以「我自我」來
強調自己，或是不斷推銷自己「這麼努
力」「多麼有才華」，只要對方不願意
委託，工作就不會上門，當然也就賺不
到錢。

說得極端一點，只要付錢的人不喜歡
你，就沒有意義，再怎麼努力也沒用。
