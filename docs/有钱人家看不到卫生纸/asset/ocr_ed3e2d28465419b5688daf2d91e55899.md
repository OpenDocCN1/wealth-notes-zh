# 國分利治小檔案

EARTH 控股有限公司董事長。經營知名連鎖髮廳「EARTH」，日本共有 223 間分店，員工超過 2800 人。國分從美廊學徒開始做起，拚命工作十幾年幾乎沒有休息，30 歲時自立門戶創業。37 歲參訪美國的大型美髮沙龍時大為感動，回日本後以獨特的加盟連銷制度，使業績飛快成長。視「不統一樣準，只培養風格」「打造百年老店」為座右銘，以培養經營者為目標。

# 風水近乎完美的豪宅！

占地面積300多坪，三層樓建築，16間房間，國分住在十億日圓的豪宅。首先，玄關和停車棚面向東南邊的設計就100分！大量的吉氣從寬廣的入口進到房子裡，可以獲得最佳的能量。

二樓客人專用的浴室比自家的還大且豪華，從這裡可以看出有錢人想讓人開心的精神。此外，工作上多以女性客人為主，所以對國分而言，象徵女性的南邊是重要的方位，而南邊的每個角落都非常乾淨，這點也做得非常好。
