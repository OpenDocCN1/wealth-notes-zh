# 有錢人家北邊沒有玄關

都會大廈的格局大多是南陽台、北玄關。其實北玄關同樣也有身邊的人來來去去、不穩定的問題，因此需有相應的對策。

例如，幫北玄關掛上顏色明亮的門簾，放置鏡子，玄關門墊使用溫暖的顏色等，添加明亮且溫暖的要素。此外，玄關也跟工作運有關。不打掃的話，會對工作造成妨礙。為跟工作有關的地方增添生氣，工作運應該也會跟著扶搖直上。
