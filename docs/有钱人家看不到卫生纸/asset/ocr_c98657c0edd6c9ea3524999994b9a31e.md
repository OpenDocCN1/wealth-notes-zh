# 有錢人享受頭銜

有錢人的思維

+   - 明確知道自己的角色和目的，
  然後全力以赴！

![](bbox=[0.25, 0.15, 0.7, 0.5])

這是某間麵包店女高層的故事。那位女高
層在還是店員的時候，曾經因為小失誤而被麵
包師傅臭罵。據說她那時很不高興，覺得那些
人根本不懂銷售端的辛苦。結果麵包師傅跟她
說：「因為我們的工作是做麵包，而你們的工
作就是賣麵包啊。」於是她下功夫在麵包的陳
列和文宣之後，業績開始蒸蒸日上。她把那些
知識和技巧傳授給其他分店，職位也逐漸越爬
越高。
珍惜自己的頭銜和職位，盡自己的本
分。當她察覺到這道理之後，工作越做越開
心，彷彿變了一個人。
