# 有錢人房間
和思維的共同點！

你覺得有錢人是怎樣的人？

你是否覺得有錢人活在不同的世界，認為他們彷彿是住在遙遠國度的人，自己跟有錢扯不上邊呢？

至今我占卜過四萬人以上，也幫不少有錢人算過命。另外，因為電視節目的關係，我也拜訪過多戶上億豪宅，察覺到有钱人有不少共同點。

雖然我遇到的有錢人常說：「我不太懂風水」「我對占卜沒興趣」，但很妙的是，每個有錢人家裡的風水都很好。

我和有錢人聊天時，經常會覺得有錢人講的話都一樣。聊到關於工作的 事，也能深體會到「原來如此，就是因為有這樣的思維，才成為有錢人的啊！」
