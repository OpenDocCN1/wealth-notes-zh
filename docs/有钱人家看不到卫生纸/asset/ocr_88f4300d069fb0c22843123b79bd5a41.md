# 有錢人的思維

衣服積太多，便難以下決定。

為節省猶豫的時間，
買新衣服就把舊衣服丟掉！

![](bbox=[0.22, 0.07, 0.85, 0.47])

西和丟舊東西的循環，不會去思考要怎麼穿撘。

當然，有些有錢人可能非常喜歡衣物，對自己的美感有信心，擅長穿撘。

但大多數的企業經營者都說：「我沒有美感，所以交給專業的來。」他們的想法是，自己做不來的、不擅長的事情就交給別人，盡可能把煩惱、猶豫的時間節省起來。

他們重視穿著打扮，是為了他人著想的貼心，而非對衣服的執著和物欲。

當衣服完成了任務，就一件一件把它們丟掉，買新衣服也能讓心情煥然一新。果斷且有行動力是有錢人的特徵。

所以，如果家裡有衣服超過兩季以上都沒有穿的話，就把它們統統丟掉吧。
