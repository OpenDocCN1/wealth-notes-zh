# 没钱人家裡窗簾横桿用來晾衣服

![](bbox=[0.15, 0.07, 0.75, 0.5])

脱贫思維

濕衣服、髒衣服遮住窗戶，

吉氣就進來！

有些人會把衣服一整排晾在窗簾的橫桿上，這也是沒錢人常做的事。

在風水學，想讓氣的流動變好，就必須有充足的陽光和新鮮的空氣，而窗戶是一大重點。如果吊掛洗好的濕衣服，會讓房間變得潮濕，如果掛髒衣服，房間的空氣就會變髒。而且，用衣服遮住窗戶，對空氣的流通本來就不好。

再者，就使用方式異於原本的用途這點來看也不好。窗簾的橫桿是用來掛窗簾的。衣服若不穿就收納好，晾乾了，就應該收起來。有些人會從晾乾的衣服裡找要穿的衣服，但這種方法其實出平意料的沒效率。
