# 沒錢人的東西很多

我拜訪過不少有錢人和沒錢人的家，發
現幾個一眼就可以辨別兩者的地方，其中一
個就是人越窮，東西越多。

首先，有錢人家的東西收納得很好，藏
在看不到的地方。另一方面，沒錢人家經常
亂七八糟。看得到的地方都是滿滿的物品，
資訊氾濫。

據說，相對於有錢人平均擁有七千項物
品，沒錢人平均擁有八千到一萬三千件物品。
沒錢人覺得東西可能會派上用場，所以
總是丟不掉；有錢人則認為有需要的時候再
買就好，沒用的東西就丟掉。有錢人的想法
是，東西少效率才好，物少輕便有餘裕，才
能把時間用在將來的事業上。
