# 沒錢人家裡東西直接放地上

沒錢人的房間最常見的，就是東西沒有放在正確的地方。例如，電視機直接放地板，吹風機躺在地上……

最讓我覺得誇張的，就是把電鍋直接放在地上。地板容易積灰塵，紙屑垃圾也會直接掉落。把每天都要吃的重要米飯放在腳邊，實在是大對不起食物了！

食物是對未來的投資。不珍惜食物，就等於不珍惜自己。

認為東西可以用就好、對物品的態度隨便的人，可能也會用相同的態度對待他人。

人都想生活在適合自己的地方，所以請把東西收納到正確的位置。
