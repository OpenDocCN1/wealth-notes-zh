# 有錢人的口頭禪：“我只是運氣好”

我常聽到有錢人說：“自己只是運氣好而已。”這樣說的演藝人員尤其多。因為他們知道許多人比自己有才華，也看過許多才華洋溢、比別人加倍努力，卻沒有成功的人。

有顆感恩的心，認為一切都是受到大家幫助的人，能招來好運。因為感謝之情，別人感受得到。運氣是一運來好氣，想要有好運氣，就必須毫不吝嗇地報恩。
