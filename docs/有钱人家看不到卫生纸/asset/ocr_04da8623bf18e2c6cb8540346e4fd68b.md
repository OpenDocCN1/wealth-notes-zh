# 有錢人的月曆一年比一年大

讓月曆一年比一年大，是我自己實際執行，而收入也真的增加的方法。剛開始我是使用小月曆，當年收逐漸增加之後，便跟著增加月曆的尺寸。這是讓自己意識時間寶貴，數字很重要的方法，明白這樣的道理，就能夠逐漸成為有錢人。

時間等於生命。有錢人之所以不浪費時間，是因為不想浪費生命。因為生命有限，所以全心全意，預測未來，持續不斷挑戰。這就是有錢人。
