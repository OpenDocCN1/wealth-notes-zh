# 有錢人經常旅行

+   有錢人
的思維
跳脫日常的經驗，
讓想法變得柔軟有彈性！

![](bbox=[0.18, 0.18, 0.75, 0.5])

有錢人假日都在做什麼呢？就我所知，有錢人經常旅行，喜歡海邊或山上等大自然的人特别多。曾經有人說：「旅行是為了體驗不便的感覺。在旅行地點的各種不便，能讓自己重新體會日常生活有多麼便利。」的確，體驗未知的文化和大自然，對事物理所當然的看法就會產生改變。在旅行地，能提供人許多改變觀點、轉換想法的契機。旅行不是有錢人的專利，旅行也能招來好運。跳脫日常可以讓心情煥然一新。心情一變，「一氣」的流動就會變。也就是說，旅行可以改變運氣。而且新的經驗能豐富人生閱歷，讓僵固的頭腦變得柔軟有彈性。
