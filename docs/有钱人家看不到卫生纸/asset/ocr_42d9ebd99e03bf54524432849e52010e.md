# 有錢人用紅色和橘色裝飾東邊

東邊和東南邊是太陽升起的方位，和明亮有活力的紅色性質相投合，讓方位和顏色的性質和諧一致，可以使運勢節節高升。使用象徵太陽的橘色也不錯。

雖然說東邊適合紅色，但不可以使整個房間都是紅色。能量太強，會太出風頭，失去平衡。

取得平衡對人類而言很重要。自我意識太過強烈，與他人的衝突就會跟著增加。所以，尤其是比較強勢的人，顏色的裝飾只要稍微點綴就好。
