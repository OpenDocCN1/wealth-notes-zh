# 有錢人在東南邊放置吉祥物

東南邊為人類帶來源生、成長、發展的力
量，放置跟自己的興趣或喜好有關的東西，
可以帶來活力和幹勁，讓自己快速成長。把
跟自己不斷努力的事情有關的物品、喜歡的
吉祥物，或是看了心情就會愉快的東西放在
東南邊，能帶來正面的效果。

東南方適合擺放能量石之類的物品，可
以增加活力與生氣。東南邊和南邊為陽氣和
陽光進入家中的方位，因此這兩個方位最好
有窗戶或玄關。每天早上打開東南邊的窗
戶，讓早晨的新鮮空氣進到房間裡。

如果東南邊為牆壁，就以鏡子或間接照
明代替太陽照亮房間，放置植物或空氣清淨
機製造新鮮的空氣。
