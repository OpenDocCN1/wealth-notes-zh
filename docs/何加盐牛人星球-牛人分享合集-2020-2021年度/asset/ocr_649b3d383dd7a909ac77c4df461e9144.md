# 第四点是给予对方选择权。

有时候想要说服一个人不要做某件事情很难，那这时不如给他充分的选择权，让他自己决定不做。

举个例子，女儿有一次跟我说她不想上英语课，不想学英语，中国人为什么要说英语，她就是不要学。这时，如果我去跟她讲学英语多么有用，必须得学，她肯定听不进去。于是，我就笑着嘻嘻地说：“好啊，你可以不上英语课，但是如果去上学的话，学校有英语课你又没法不上，要不然这样吧，你不去上学了，咱就在家里呆着，自己想学什么就学什么，完全自己做主，多好啊！”女儿一下子懵了，默默地走了开。过了 toast，她跑过来，扭扭捏捏地跟我说：“妈妈，我想了一下，我还是去上学吧，学英语其实也没那么难以忍受”。

# 第五点是把自己的目的转化为对方的利益。

这个意思是说我们在说服他人的时候要从能给对方带来什么好处的角度去说。比如，你想结交一位牛人，第一次给他发消息，不要光想着我希望能够认识你，我需要你的帮助，而是要告诉他我能为你做什么，我能为你提供哪些价值。

不要觉得大佬们这么厉害，我这么普通能为他做什么，大佬也是人，他的需跟我们并没有太大的区别，都符合马斯洛的需求理论。

关于马斯洛的需求理论，有些人对它的理解可能有误区，以为都是先满足了下面低层次的需求才会产生高层次的需求，其实不是这样的，这些需求是同时的，没有先后之分，不然我们没法解释会怎么会出现雷锋。有些人他自我实现的需求已经得到了充分的满足，那么他对于生理的、安全的这些低层次的需求的要求就没那么高了。

对于大佬来说，告诉他你能为他带来什么价值，对方才会有想要和你结交的动力。

再比如，我想催客户尽快敲定合作，尽快付款。我会告诉他“我要帮顾问的时间，咱这边如果能够稳定下来的话我把能力最好最有经验的顾问留给这个项目，如果拖得久了，他们都去别的项目了。”当然，我说的这些话都是真的，这是前提。这样在对方听起来就是在为他们考虑，催合作、催款这件原本比较尴尬的事情也变成了是对对方利益的关心。
