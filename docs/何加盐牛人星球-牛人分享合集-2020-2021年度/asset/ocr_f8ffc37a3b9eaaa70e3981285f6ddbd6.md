# 什么是绩效

+   > 绩效是员工、部门或组织的活动所带来的经济产出。
> 华为绩效指的是绩效结果导向。
> 绩效考核就是要给绩效结果一个公证的评价和合理的定级，所以绩效就是为客户创造价值。


# 绩效不是过程、不是行为、不是能力

+   - 大量做事、努力、苦干
- 完成任务、速度
- 有热情、干劲、学习能力
- 对工作超负荷投入
- 管理方法
- 善于发现问题


# 而是绩效结果

+   - 营收增长、成本降低、客户满意度、交付准时率、质量达标率
- 业绩完成量/达成率达成率 vs 承诺
- 个人能力达成目标/达标
- 客户满意度提升、团队贡献价值
- 创新成果、制度完善


华为的绩效，首先对绩效的定义大家都了解，就不再解释。这里重点讲下华为的绩效导向是责任结果导向，所谓的责任结果导向是什么？其实它重点还是在员工是否在自己的岗位上能对应的履行他的责任和对应的能力将他所承担的职责做出有效的产出，真正的为客户创造价值，真正的为团队做出贡献。

在华为很多时候讲的是贡献，你个人的贡献，特别是个人对团队的目标贡献，当然如果是非销售岗位，衡量比较简单，如果是非销售岗位特别是后勤人员岗位，感觉评价贡献是很臒的，所以这类岗位盯住一个关键点，就是这个员工的岗位职责是什么？他在这个岗位上应该做些什么事情，然后他所对应要做的事情是不是做到位，就是说他是否不仅做出了自己本岗位职责所要求的工作职责，还完成了超过这个岗位职责更多的内容。那这样的员工华为是非常喜欢的。而这个导向就是责任结果导向，确切来讲，就是拿最后的业绩/工作目标来说话。

在华为，高层主要是 KPI 考核，涉及目标分解，但对很多基层员工其实很多工作没法量化，那就没法量化就不能考核了吗？不是的，他是能够考核的。很多企业都想学习华为，都想知道华为的绩效管理到底是怎么做的。
