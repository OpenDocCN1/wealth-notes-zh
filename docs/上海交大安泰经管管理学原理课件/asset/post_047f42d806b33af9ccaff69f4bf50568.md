
## 三、决策追踪与调整的程序及方法

### （二）决策追踪与调整的方法

**1. 基于组织决策的追踪与调整方法**

- （2）雷达图，又称蜘蛛网图。雷达图主要应用于企业经营状况如收益性、生产性、流动性、安全性和成长性的评价。

![图 5-6 雷达图方法示意](img/fb58d24fa7baa8c67e846e92bd02df61_257_0.png)

- （3）趋势图，也称统计图或统计图表，是以柱形图、横杆形图、曲线图、饼图、点图、面积图等统计图形来呈现某事物或某信息数据的发展趋势。它用来显示一定的时间间隔内所得到的测量结果。以测得的数据为纵轴，以时间为横轴绘成图形。
  - 趋势图的主要用处是确定各种类型问题是否存在重要的时间模式，这样就可以调查其中的原因，从而找到决策追踪与调整的方向。

**2. 基于个体决策的追踪与调整方法**

- （1）鼠标实验室：这是一种追踪被试信息获取过程的研究系统。随着计算机的普及，基于鼠标所处位置代表了大脑当前处理内容的假设，一种可以在计算机上通过鼠标移动研究信息获取问题的研究——鼠标实验室应运而生。

- （2）眼动技术：理论基础是眼脑假设，即眼睛正在获取的信息和大脑正在加工的信息是一致的。即使人们在转移注意力时眼睛的注视位置不一定发生变化，但在处理复杂信息时，注视点的变化和注意力的转移是耦合的。因此，眼动数据可以为决策追踪与调整提供稳定可靠的信息获取方面的数据。

![](img/fb58d24fa7baa8c67e846e92bd02df61_260_0.png)

- （3）决策移窗技术：研究者首先在屏幕上，以遮盖方式呈现M个备选选项在N个特质维度上的信息。当被试决定获取某条信息时，只需持续注视对应的单元。当眼动仪捕捉到注视点时，系统程序将自动撤掉该单元上的遮蔽，呈现单元内信息。当被试不再注视该单元时，信息被重新遮蔽。在实验进行过程中，眼动仪持续记录被试的眼动编号，包括注视点、眼跳、注视轨迹、瞳孔大小等。每个信息单元及选项和特质标签，均可以作为兴趣区。

## 第6章 组织战略规划

### 有效的战略

有效的战略是在组织和环境与组织和战略目标之间实现卓越协调的战略。

![](img/fb58d24fa7baa8c67e846e92bd02df61_263_0.png)

### 战略的构成

- 独特竞争力是指组织在某些方面做得特别好。
- 战略范围是组织在其中竞争的市场的区间。
- 组织资源配置的计划——如何在各个竞争领域中分配自己的资源。

![](img/fb58d24fa7baa8c67e846e92bd02df61_264_0.png)

### 战略的制定和实施

- 战略制定是同组织战略的创造和决定有关的过程，关注战略的内容。
- 战略实施是组织内进行战略运作或实施的方法，关注战略的过程。
- 战略制定阶段决定战略是什么，而实施阶段则关注战略如何实现。
- 预定战略是为了实现某一具体目标而选择和实施的规划。
- 应急战略是在没有使命或目标，或者不顾原来使命和目标情况下的一种行为模式。是组织还没有确定其战略的情况下进行资源分配。

### SWOT分析

| 要素 | 内容 |
|---|---|
| 使命 | 组织基本的目的 |
| SWOT分析 | 制定支持使命的战略 |
| 内部分析 | 优势（独特竞争力）、弱势 |
| 外部分析 | 机会、威胁 |
| 好的战略 | 能够支持使命同时又发挥组织的优势和机会，化解威胁，避免劣势 |

### 评估组织的劣势

- 组织劣势是那些无助于组织选择和执行实现其使命战略的技能和能力。
- 如果组织无法实施其竞争对手们所实施的战略，则该组织就陷入了竞争劣势。

### 评估组织的机会和威胁

- 组织的机会是带来更高绩效的因素。
- 组织的威胁是阻碍组织绩效进一步提高的因素。

![](img/fb58d24fa7baa8c67e846e92bd02df61_271_0.png)

### 波特的基本战略

- 追求差异化战略的组织寻求通过产品或服务的品质同竞争对手区别开来的政策。
- 实施总成本领先战略的组织试图通过将成本降到低于竞争对手的水平来获得竞争优势。
- 追求集中战略的企业专注于某一具体的区域市场、产品线或购买群体。

![](img/fb58d24fa7baa8c67e846e92bd02df61_273_0.png)

| 战略类型 | 定义 | 例证 |
|---|---|---|
| 差异化 | 独特的产品或服务 | 劳力士(手表)、梅赛德斯—奔驰(轿车)、尼康(相机)、Cross(书写工具)、惠普(小型计算器) |
| 总成本领先 | 降低制造和其他成本 | 天美时(手表)、现代(轿车)、柯达(相机)、比克(书写工具)、德州仪器公司(小型计算器) |
| 集中 | 集中于特殊的区域市场、产品市场或购买群体 | 蒙雅(手表)、菲亚特、阿尔法罗密欧(轿车)、Waterman(书写工具)、Fisher-Price(小型计算器) |

### 米尔斯和斯诺战略概念类型

**组织的战略类型**

- 前瞻者
- 防卫者
- 分析者
- 反应者

**米尔斯和斯诺概念类型**

| 战略类型 | 定义 | 案例 |
|---|---|---|
| 前瞻者 | 以创新和增长为导向，寻求新市场和新的增长机会，鼓励承担风险 | 亚马逊、3M、Rubbermaid |
| 防卫者 | 保护当前市场，保持稳定增长，服务于当前的顾客 | 比克、eBay、Mrs. Fields |
| 分析者 | 适度强调创新以保持当前市场和当前顾客的满意度 | 杜邦、IBM、雅虎 |
| 反应者 | 没有清晰的战略，视环境变化作出反应，随波逐流 | 国际收割机公司、Joseph Schlitz啤酒公司、凯玛特、沃德百货连锁店 |

### 构建公司层战略

- 追求单一产品战略的组织只制造一种产品或服务并且只在单一的地理性市场上进行销售。

- 多元化：对组织涉入不同业务的数目以及这些业务之间的关系的描述。

- 相关多元化：组织所经营的业务、实施相关多元化的相关性基础产业或市场间存在某种关系。

- 不相关多元化：企业经营着相互之间没有逻辑关系的多元业务。

![](img/fb58d24fa7baa8c67e846e92bd02df61_275_0.png)

| 相关性的基础 | 案例 |
|---|---|
| 相似的技术 | 飞利浦、波音、西屋电气、康柏 |
| 共同的销售和营销技能 | RJR 纳贝斯克、菲利普莫里斯、宝洁 |
| 共同的品牌名称和商誉 | 迪斯尼 |
| 共同的顾客 | 默克、IBM、AMF-Head |

### 实施公司战略

- **后向垂直整合：** 企业开始经营原来由其供应商所经营的业务。
- **前向垂直整合：** 停止向顾客销售，改向顾客的顾客销售的组织实施的多元化。
- **兼并：** 两家组织规模相当时的收购。
- **收购：** 企业被一家大得多的组织购买。

![](img/fb58d24fa7baa8c67e846e92bd02df61_276_0.png)

### 企业多元化的管理

**业务组合管理技术**

多元化企业决定进入哪个业务以及如何管理这些业务才能令公司绩效最大化。

**波士顿矩阵**

根据特定市场的增长率和组织在这一市场中的份额进行评估。

### 波士顿矩阵

![](img/fb58d24fa7baa8c67e846e92bd02df61_278_0.png)

- 发展策略：适用于“问题”、“明星”；
- 维持策略：适用于“金牛”；
- 收获策略：适用于“问题”、“狗类”、处境不佳的“金牛”；
- 放弃策略：适用于“问题”、“狗类”。

### 通用矩阵（通用电气业务筛选法）

- 竞争地位：强
- 行业吸引力：高、中、低
- 增长与发展战略
- 维持或有选择地发展战略
- 停止、转移、撤退战略

![](img/fb58d24fa7baa8c67e846e92bd02df61_279_0.png)

### 国际战略与全球战略

- 国际企业可以运用国内企业所不具备的方法提高效率。
- 地点效率，将自己的设施放在世界上任何可以获得最低的制造和分销成本的地方。
- 通过实现规模经济降低生产成本。
- 通过扩大它们在每个国家里的产品线，国际企业可以实现范围经济。
- 全球战略是将全世界看成一个单一市场，它的主要目标是创造出能够满足全球顾客需要的标准的商品和服务。
- 实施跨国战略的企业试图将全球企业的全球规模效率同多国企业的本地响应的优势结合起来。
