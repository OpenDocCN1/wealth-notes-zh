# 定量分析的管理理论

管理科学 + 运营管理：

+   - 管理科学主要关注数学模型的建立。
+   - 运营管理帮助企业更有效率或更有效能地提供生产和服务，用于解决范围极其广泛的问题。

表 2.4

定量分析管理理论

|  |  |
|---|---|
| 概要 | 定量分析管理理论关注于将数学模型和程序应用于管理情境。管理科学研究开发数学模型支持决策和问题解决。运营管理关注将管理科学更加直接地应用于组织管理。为了向经理们提供信息，企业需要开发管理信息系统。 |
| 贡献 | 开发了复杂的定量分析技术帮助决策。
模型的應用提高了人们对复杂组织程序和情境的理解。
在规划和控制程序中非常有用。 |
| 局限 | 不能充分解释或预测组织中人们的行为。
数学的复杂性可能掩盖其他重要的管理技能。
模型假设的假设是不现实的或无法实现的。 |
