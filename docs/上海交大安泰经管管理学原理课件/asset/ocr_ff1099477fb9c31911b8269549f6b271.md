# 表 2.1

# 古典管理理论

|  |  |
|---|---|---|
| 概要 | 古典管理理论开拓了两个方向的研究。科学管理专注于组织内的雇员，研究如何提高其生产率。科学管理的主要先驱人物是泰勒、吉尔布雷斯夫妇、甘特和爱默生。行政管理专注于整个组织，研究提高组织效率和效能的方法。行政管理理论的代表性理论家有法约尔、厄威克、韦伯和巴纳德。 |
| 贡献 | 为后来的组织理论的发展打下了基础。
确立了直到今天仍然有效的重要的管理过程、职能和技能。
强调管理是科学研究的有效对象。 |
| 局限 | 适用于静态和稳定的组织，难以应用于今天变化的和复杂的组织。
所提出的普遍准则往往并不适用于所有的组织。
尽管某些作者(例如吉尔布雷斯夫人和巴纳德)注意到人的因素，但古典理论总体上是将雇员看成工具而不是资源。 |
