# 人力资源管理的法律环境

# 公平就业法

《1964 年人权法案》第七条, 禁止在雇佣关系的各个方面实行歧视。

《雇用年龄歧视法》, 禁止对 40 岁以上雇员的歧视。

《1965 年 11246 号总统行政令》, 要求同政府有合约的雇主参与平权行动( affirmative action )。

《怀孕歧视法案》, 禁止歧视怀孕妇女。

《1974 年越战退伍军人重新适应援助法案》, 将平权行动扩展到越战退伍军人。

《美国残疾人法案》, 禁止歧视残疾人。

《1991 年人权法案》, 更利于雇员以歧视为由起诉雇主, 但限制了雇员胜诉后可以获得的惩罚性赔偿。

# 报酬和福利

《公平劳动标准法案》, 规定最低工资, 每周工作超过 40 小时必须支付加班工资。

《1963 年公平报酬法案》, 规定男女同工同酬。

《1974 年雇员退休收入保障法案》, 规定组织如何管理养老基金。

《1993 年家庭和医疗假期法案》, 要求雇主为雇员家庭或医疗紧急事件提供 12 周无薪假期。

# 劳动关系

《全国劳动关系法案》, 又称《瓦格纳法案》, 规定了雇员建立工会的程序, 要求组织同合法成立的工会进行集体工资谈判。

《劳工—管理人员关系法案》, 又称《塔夫特—哈特利法案》, 限制工会权力并且规定了在工会组织的活动中管理层的权力。

# 健康和职业安全

《1970 年职业安全和医疗法案》, 对安全的工 作条件作出规定。
