# 1. 情境领导模型

+   > 提出者：保罗·赫塞、 肯尼斯·布兰查德
+   > 主要观点：有效领导和无效领导的差异并不是领导者的行为本身，而是领导者行为和实施情境的匹配。

![](bbox=[0.08, 0.38, 0.38, 0.78])

| 下属成熟度 | 对应特征 | 领导方式 |
|---|---|---|
| R1 | 成熟度低。既不愿意，也没有能力承担分配的工作任务。 | S1 |
| R2 | 成熟度较低。愿意从事分配的工作任务，但不具备完成工作的能力。 | S2 |
| R3 | 成熟度较高。具有从事分配的工作任务的能力，但却不愿意去做。 | S3 |
| R4 | 成熟度高。既愿意也有能力去完成分配的工作任务。 | S4 |
