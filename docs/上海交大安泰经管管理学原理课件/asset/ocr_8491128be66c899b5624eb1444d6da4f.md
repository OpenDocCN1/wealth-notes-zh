# 第六节 管理控制的信息技术

# 信息与信息技术

信息是经过加工处理后对组织管理的决策和目标实现有参考价值的数据。信息技术是对信息进行采集、传输、存储、加工、表达和应用的各种技术的总称，主要包括计算机技术、通信技术和传感技术。

+   企业
+   - 供应链管理信息化（SCM）；
+   - 生产过程信息化，如物料需求计划（MRP）
+   - 营销与服务信息化，如客户关系管理（CRM）等
+   - 管理过程信息化，如管理信息系统（MIS）、企业资源计划（ERP）等

+   政府
+   - 政府间的电子政务（G2G）
+   - 政府对企业的电子政务（G2B）
+   - 政府对公民的电子政务（G2C）
