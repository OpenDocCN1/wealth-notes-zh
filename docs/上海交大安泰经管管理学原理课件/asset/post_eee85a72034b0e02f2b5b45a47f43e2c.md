## 二、层级整合

### （二）组织设计中的集权与分权

|  | 集权 | 分权 |
|---|---|---|
| 定义 | 决策权集中在组织高层的一种权力系统 | 决策权分散在组织各部门的权力系统 |
| 优势 | 容易协调 | 参与性强，有利于增强归属感、认同感。 |
| 问题 | 决策所需时间增加，影响决策的效率和质量；影响下属部门管理者归属感和认同感。 | 协调困难。 |

## 二、层级整合

（二）组织设计中的集权与分权

+   影响分权的因素包括：
+   - 组织规模：组织规模越大，越需要分权决策
+   - 政策的统一性：政策统一可以使用集权的方式进行层级整合
+   - 成员自我管理能力：知识经济时代，学习型组织分权程度较高
+   - 组织的可控性：下级能够正常履行职责，同时上级对下级的管理不致失控
+   - 组织的发展阶段：不同阶段需要及时调整

## 二、层级整合

### （三）组织设计中的授权问题

影响授权有效性的因素主要包括：

+   - 授权内容：过多，影响管理者权威；过少，不利于下属积极性发挥，不能减轻管理者的负担。
+   - 信息的共享程度：为接受方决策提供支撑。
+   - 授权者的主观态度：权力观、授权意愿、责任心等。
+   - 接受方的条件：与授权内容相关的知识、能力、经验和责任心等。
+   - 隐含的奖励：物质+精神层面。

直线和参谋的角色可以转换

## 三、直线与参谋的整合

### （一）直线与参谋的关系

+   - 直线管理人员与参谋人员之间的区别：

|  | 直线管理者 | 参谋人员 |
|---|---|---|
| 职权性质不同 | 拥有直线职权 | 拥有参谋职权，依附于某一个直线部门 |
| 设置方式不同 | 按组织层级自上而下逐级设置 | 按照专业需求设置 |
| 在决策中的角色不同 | 与其岗位相适应的决策权 | 建议权 |
| 考核标准和待遇不同 | 取决于所在组织层级、职位和绩效 | 由所提供的建议、服务的价值决定 |
| 所承担的责任不同 | 做出决策并对决策的结果负责 | 不承担决策结果的责任 |

## 三、直线与参谋的整合

### （二）直线与参谋的整合方法

+   1. 慎重对待参谋的设置
+      ◆ 提高直线管理者的综合能力，适当控制参谋的规模
+      ◆ 重视参谋对工作的适应性
+      ◆ 重视参谋的来源。参谋可能来自组织内部，也可能来自组织外部

+   2. 明确职责关系
+      ◆ 明确各自的职责关系。
+      ◆ 完善直线管理者与参谋的沟通机制

+   3. 授予参谋必要的职能职权
+      ◆ 为了有利于参谋发挥作用，克服直线管理者非理性因素的影响，组织可以在必要时授予参谋部分职能权力。

## 人力资源管理的法律环境

## 公平就业法

《1964 年人权法案》第七条, 禁止在雇佣关系的各个方面实行歧视。

《雇用年龄歧视法》, 禁止对 40 岁以上雇员的歧视。

《1965 年 11246 号总统行政令》, 要求同政府有合约的雇主参与平权行动( affirmative action )。

《怀孕歧视法案》, 禁止歧视怀孕妇女。

《1974 年越战退伍军人重新适应援助法案》, 将平权行动扩展到越战退伍军人。

《美国残疾人法案》, 禁止歧视残疾人。

《1991 年人权法案》, 更利于雇员以歧视为由起诉雇主, 但限制了雇员胜诉后可以获得的惩罚性赔偿。

## 报酬和福利

《公平劳动标准法案》, 规定最低工资, 每周工作超过 40 小时必须支付加班工资。

《1963 年公平报酬法案》, 规定男女同工同酬。

《1974 年雇员退休收入保障法案》, 规定组织如何管理养老基金。

《1993 年家庭和医疗假期法案》, 要求雇主为雇员家庭或医疗紧急事件提供 12 周无薪假期。

## 劳动关系

《全国劳动关系法案》, 又称《瓦格纳法案》, 规定了雇员建立工会的程序, 要求组织同合法成立的工会进行集体工资谈判。

《劳工—管理人员关系法案》, 又称《塔夫特—哈特利法案》, 限制工会权力并且规定了在工会组织的活动中管理层的权力。

## 健康和职业安全

《1970 年职业安全和医疗法案》, 对安全的工 作条件作出规定。
