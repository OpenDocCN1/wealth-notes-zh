# 技術分析非常深奧。或許還會有新發現！

在活用費波那契數列和黃金比例的技術分析，除了費波那契回調，還有從時間軸用費波那契數列計算行市變動的「費波那契時間周期」；和從某個價格畫出趨勢線，跌破那條線後，接著用費波那契數列預測反轉點的「費波那契扇形線」；利用圓弧的「費波那契弧形線」等。

有興趣的人不妨進一步研究看看。依照公司股票不同，比起基本的費波那契回調，或許會發現股價直接反應的情形。

至此介紹了各種技術分析，不過除此之外還有許多分析手法，全新的分析手法也會陸續發表。技術分析非常深奧，我自己也還在進行研究。假如你發現了全新的技術分析，到時候請偷偷地告訴我吧！
