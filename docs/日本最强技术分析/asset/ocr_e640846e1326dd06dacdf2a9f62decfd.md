# 了解K線是技術分析的第一步。

把紗線當成芯，由做成圓柱狀的蠟製成的蠟燭，從古希臘、羅馬時代便已知存在，據說日本是在奈良時代從中國傳來。在時光流逝的現在，蠟燭仍被用於生日、聖誕節蛋糕等喜事，或災害等時候的照明。即使演變成數位社會，仍扮演著照亮人們生活的燈火的角色。形狀和亮度經點燃後使蠟燭的長度改變，於是被比作表示股價上升、下跌的「K線（蠟燭線）」。

東京證券交易所在東證1部、東證2部、東證Mothers等市場，2021年2月時有超過三千七百五十家企業上市。

此外在美國，世界最大的證券交易所紐約證券交易所（NYSE），和以新興企業為主的納斯達克（NASDAQ）加起來，有超過六千家企業上市。

要對這麼多公司股票進行技術分析時，正是以「走勢圖」作為主體。雖然走勢圖有好幾種種類，不過最流行的是「K線圖」，想必大家都曾看過。目前在海外也被稱為「Candlestick Charts（燭台圖）」，受到廣泛使用。
