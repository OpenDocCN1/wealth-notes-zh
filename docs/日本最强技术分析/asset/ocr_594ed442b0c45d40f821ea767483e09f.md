# 日本製造的一目均衡表。

「一目均衡表」這個名稱很獨特，有種復古的感覺呢。一目均衡表即使名稱古老，在技術分析卻擁有高知名度，受到廣泛活用。

一目均衡表的理論完成於昭和時代初期。東京新聞的前身都新聞，有一位筆名為一目山人的幹部，和許多工作人員耗費數年歲月完成了這個行市分析手法。在日本國內的個人投資者之間也頗受歡迎，歐美也出版了一目均衡表的解說書，它也是受到許多基金經理人支持的技術手法。一目均衡表是因為行市能一目了然才如此命名。

在技術指標之中，K線、移動平均線、布林通道等是以時間及時間順序作為分析要素，一目均衡表也納入這個群組。它以時間論、波動論、值幅觀測論（也叫做水準論）所構成，從作為段落的價格變化發生的日期計算特定的基本數值等日數，這是能預測將來變化日期的技術分析。

這個觀點認為「行市在買方與賣方的均衡崩潰時會大幅變動」，根據的理論是「買賣勢力其中一方若能掌握優勢，就能一眼得知行市變動」。
