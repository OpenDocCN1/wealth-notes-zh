# ◇極陽線、極陰線等

此外，暗示行情混亂或轉換的K線，還有「極陽線」（小陽星）、「極陰線」（小陰星）、「蜻蜓十字線」、「墓碑線」、「影線等長線」、「一字線」（四價合一K線）等。

「極陽線」是蠟燭的實體和上下影線都很短，會在行市的轉換點或股價變動加速時出現。含有儘管猶豫卻對上升抱期待感。雖然「極陰線」表示失望感之中的猶豫，但還是行情疲軟走在前頭的狀態。上影線下影線都沒有的一條橫線「一字線」（四價合一K線），開盤後既不上漲也不下跌，交易也很少，暗示著完全沒有氣勢。

說明到這邊，讀者應該也注意到了，K線能分類成「暗示上升」和「暗示下跌」，以及「暗示行情混亂或轉換」這3種模式。
