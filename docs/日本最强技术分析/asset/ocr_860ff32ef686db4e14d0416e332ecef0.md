# 湯和行情都是適溫最好？

人有各種喜好。有的男性像和流一樣喜歡豐滿一點的女性，也有女性喜歡瘦削的男性。話雖如此，要是過胖或過瘦，這個人的健康會令人感到擔心。任何事都不要太過度，以長遠的眼光來看，體重適中或許比較好。

關於行市和股價也一樣。有個行市用語是「金髮姑娘市場」（＝適溫市場）。這是指行市處於不會過熱，然而也不會太冷的適度狀態。這種狀態對股票市場和投資者來說都不算愉快吧？

順帶一提，這個「金髮姑娘市場」用語的由來是，童話《三隻熊》裡登場的金髮姑娘從熱湯、適溫的湯、冷湯之中選了適溫的湯的故事。果然容易下嚥的適溫的湯比較令人滿意呢。
