# POINT

過去最高價和52週最高價是許多投資者注意的關卡，因此必須留意。

是說，就算以一句話說「技術分析」，也有各種種類。行市一開始有動作，就有往一定方向移動的習性。還有目的是看清市場整體方向性（趨勢）的「趨勢分析」，和通知「過度上漲」與「過度下跌」的「振盪分析」。

這時重點是，在活用技術分析的投資中，盡量不要反映自己太過主觀的情緒，按照過去的經驗法則投資。沒有任何根據，僅憑自己的感覺或印象思考：「應該會再上漲」或「差不多要止跌了」，是非常危險的事。雖然往往覺得：「我用多少價格買進，所以如果不回升到多少就沒有獲利」，不過你買進時的價格等，「關行情啥事？」根據趨勢分析和振盪分析等，盡量機械式地投資才是重點。
