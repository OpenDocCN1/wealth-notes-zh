# 移動平均線是趨勢分析的代表。

在開頭的漫畫中，和流在所屬的營業部業績在平均點以下，因而感到焦急。由於難為情地露出苦笑，他被部長叱責，簡直是禍不單行。低於一般的平均點以下的業績，果然身為業務員大有問題。

業績亮眼的前輩未咲「激勵」煩惱的和流。她的建議是「總之先把超過平均點當成目標」。和流找到平均點這個目標，勇往直前地推銷，超過目標平均點。收到這個結果，和流被部長稱讚，他對於工作的幹勁更加提高了。

任何事超過或低於平均點十分重要，這會成為分歧點。低於平均點時要把平均點當成眼前的目標值；超過平均點時要當成跌停的基準，避免低於它。此外，和流藉由超過平均點，整體的平均點也會上升，也有提高水準的效果。如此注意平均點是非常重要的是。

這裡舉出的平均點，在投資的技術分析相當於「移動平均線」。

移動平均線在英文稱為Moving Average，經常取西洋文字的字首標示成「MA」，請記起來吧。
