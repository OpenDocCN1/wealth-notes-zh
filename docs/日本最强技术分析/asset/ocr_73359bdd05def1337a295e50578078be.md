+   - 布林通道的算式

+   1. 標準差的算式

標準差=√(n天內的收盤價-n天內的平均值)的平方的總和÷n天

+   2. 布林通道的算式

±1σ=n天的移動平均±n天的標準差
±2σ=n天的移動平均±n天的標準差×2
±3σ=n天的移動平均±n天的標準差×3

+   - 關於價格收在通道內的機率
