# ○ 買賣信號比移動平均線更早出現

![](bbox=[0.09, 0.08, 0.89, 0.4])

比SMA的黃金交叉、死亡交叉，利用EMA的MACD在較早的時機出現買賣訊號。

在K線圖上的SMA，由於黃金交叉和死亡交叉出現較晚，所以利潤無法如想像中提高。但是，在訊號比較早出現的MACD，這也有可能變成「騙線」。

所謂騙線是指即使根據技術分析出現買賣訊號，之後的股價卻與訊號指示的方向反向移動。不只MACD，對於所有的技術指標都可說是如此。

雖然深入研究一種技術指標是好事，不過過於相信單一一種指標有可能導致重大失敗。把MACD的黃金交叉（死亡交叉）當成第一買賣點，移動平均線的黃金交叉（死亡交叉）當成第二買賣點進行交易或許比較好。
