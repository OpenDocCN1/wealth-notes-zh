# ○ 頭肩頂

![](bbox=[0.31, 0.08, 0.9, 0.28])

低於頸線時，正式轉為下降趨勢。頭肩頂完成！

![](bbox=[0.27, 0.31, 0.85, 0.45])

頭肩頂由三個突起和兩個凹下所形成，呈現正中間的突起為最高的形狀。兩側的突起是肩膀，正中間的突起看起來像頭，因而有這樣的名字。在日本由於很像在釋迦左右配置菩薩的三尊像，所以也稱為「三尊頭」。

走勢圖形成最初的突起後，會形成更新突起最高價的頭肩頂的頭。更新最高價時表示仍有上升的氣勢，不過和上次的返回最低價幾乎等價，或者下跌至更低後買壓會變強。之後，雖然反彈卻未更新上次的最高價（頭），向下突破連接最初的返回最低價和下
