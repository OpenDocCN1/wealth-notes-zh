# 從通道的寬度、傾斜和收縮判斷行市的趨勢與力道。

在這個單元將會介紹知名的趨勢分析工具「布林通道」。布林通道由移動平均線和標準差構成，藉由表示移動平均線的線和位於上下，表示市價變動幅度的線（通道）進行投資判斷。

「價格大半收在這個通道（帶子）裡」，是應用統計學的指標。

在布林通道，通常是在K線圖上畫出5條線。線條由上至下為+2σ（sigma）、+1σ、移動平均線、-1σ、-2σ。藉由這5條線構成的通道幅度、傾斜與收縮判斷行市的趨勢與強弱。此外還有加上±3σ，以7條線構成的例子。

前提是，股價收在布林通道±1σ的範圍內的機率約68.3%、收在±2σ的範圍內的機率約95.4%、收在±3σ的範圍內的機率約99.7%。

超過正負2個標準差的股價是異常值。
