
# 了解K線是技術分析的第一步

把蠟線當成芯，由做成圓柱狀的蠟製成的蠟燭，從古希臘、羅馬時代便已知存在，據說日本是在奈良時代從中國傳來。在時光流逝的現在，蠟燭仍被用於生日、聖誕節蛋糕等喜事，或災害等時候的照明。即使演變成數位社會，仍扮演著照亮人們生活的燈火的角色。形狀和亮度經點燃後使蠟燭的長度改變，於是被比作表示股價上升、下跌的「K線（蠟燭線）」。

東京證券交易所在東證1部、東證2部、東證Mothers等市場，2021年2月時有超過三千七百五十家企業上市。

此外在美國，世界最大的證券交易所紐約證券交易所（NYSE），和以新興企業為主的納斯達克（NASDAQ）加起來，有超過六千家企業上市。

要對這麼多公司股票進行技術分析時，正是以「走勢圖」作為主體。雖然走勢圖有好幾種種類，不過最流行的是「K線圖」，想必大家都曾看過。目前在海外也被稱為「Candlestick Charts（燭台圖）」，受到廣泛使用。

除此之外，歐美經常使用「折線圖」或「條形圖」。「條形圖」是在連接最高價與最低價的K棒，開盤價在左側、收盤價在右側，分別以小幅度的線條標示。與K線的差異是，實體的部分為線條，只有這點差別，憑直覺就能看懂正是優點，也稱為K線。

「K線圖」在之後介紹的技術分析都會使用。並且，了解K線在技術分析可說是「基礎中的基礎」。

K線有陽線和陰線這2種，並且由實體和影線構成。

在開頭的漫畫，未咲的一天使用內心的晴雨表表示喜怒哀樂的程度。雖然睡眠品質不好，但是作了享受馬爾地夫之旅的夢，迎接還不錯的早晨，但是在公司犯了錯被部長叱責，心情跌到這一天的谷底，不過下班後品嚐義大利料理和唱KTV，心情來到最高潮。然後心情愉快地就寢。

如果把這一天換成股價用K線表示，K線的白線就是「陽線」（上升）。反之，如果心情比早上起床時更低落，就是黑線「陰線」（下跌）。和未咲的心情晴雨表一樣，企業的一天、一週、一個月的股價動向正是以一目瞭然的K線表示。

K線有兩種，收盤價比開盤價高時以白色表示的「陽線」；和收盤價比開盤價低時以黑色表示的「陰線」。開盤價和收盤價以四邊形圍起來的黑白部分叫做「實體」。並且，從實體往上面延伸的線是上影線，反之從實體往下延伸的線就是下影線。除此之外還有「十字線」。

### ○ K 線圖的例子

![](img/300d6743e3871fdc0ea17875b15acce5_35_0.png)

在陽線和陰線連續畫出來的K線圖，上升是往右上，低價告一段落的形狀。下降則是相反。如果陽線、陰線的長度都成長，上升、下降的角度就會變大。

另外K線的期間，若是短期買賣就採用短時間；如果是長期投資，則採用長時間。最流行的是以一天劃分時間的線，這叫做「日K」。在東京證券交易所從上午九點開盤到下午三點收盤的期間會形成日K的K線。

除了日K，觀察中長期的市價變動時，一週的K線是週K、一個月的K線是月K、一年則一般使用年K等。

除此之外，也有以時間劃分的K線，如一分鐘、五分鐘、三十分鐘等以分為單位細分的K線是分K；如一小時、四小時等以小時為單位細分的K線則叫做小時K。重複超短期買賣的交易人，會活用這種分K和小時K。

順便一提，股市走勢圖一般以白色和黑色的K線描繪。如果是黑白的走勢圖，幾乎統一為陽線是白色、陰線是黑色。不過，以彩色畫面顯示，在電腦或手機上看到的走勢圖的K線，顏色會變成紅色和綠色的彩色走勢圖。

例如在外匯走勢圖，有以「陽線為紅色、陰線為綠色」描繪的情況，也有以「陽線為綠色、陰線為紅色」描繪的完全相反的情況。一般而言在日本，主要採用陽線為紅色、陰線為綠色，不過在海外，陽線是表示安全的綠色、陰線則是表示危險的紅色，相反的情形很多。

在前文也有提到，在歐美主流的「條形圖」沒有用顏色區分，直向的柱狀就是股價的高低幅度，開盤價和收盤價以左右的短橫線記載。不過，K線圖、條形圖等任何一種走勢圖都是由左向右移動，這點沒有不同。

### POINT

- K線超級棒，一眼就能讓人看出當日股價的變動。
- K線的「期間」要依照交易的長度靈活運用。
- 記住K線的3種基本模式。

那麼，從這裡開始將以黑色與白色的股價K線為前提繼續說明。

K線是將一定期間的行市的四個價格（開盤價、最高價、最低價、收盤價）以一條棒狀表示。將K線排列出來，就能明白行市的狀態與走向，這個走勢圖就是K線圖。

或許大家感到意外，其實K線是在日本江戶時代誕生，起源於日本的傳統表示方法，這是日本原創！目前在海外也廣泛地使用。江戶時代的日本，糧食的期貨行市領先世界誕生發展，K線在這種背景下誕生。這是日本的先人創造出來的圖表，因此請自豪地活用吧。

行市由買方和賣方各自接觸完成交易（買賣），並且形成各種形狀的K線。而K線有基本的形狀。就是「陽線」、「陰線」、「十字線」。

首先「陽線」，是以「收盤價」超過「開盤價」的形式結束時形成的K線，顏色以「白色」等表示。從交易開始到交易結束的期間，表示最終買勢很強烈。

另外，買勢強烈、買勢愈大，K線的實體就愈長，會變成之後解說的「大陽線」。

另一方面，「陰線」是以「收盤價」低於「開盤價」的形式結束時形成的K線，顏色以「黑色」等表示。從交易開始到交易結束的期間，表示最終賣勢很強烈。此外賣壓愈大，K線的實體也會愈長。

並且，和黑白的蠟燭一起出現在蠟燭上下的「影線」，就是構成K線的要素。

雖然「上影線」表示依照買勢在最高價買進，卻因為賣勢的阻力被推回迎接收盤價。向上延伸的影子線愈長，暗示了賣壓愈強。雖然「下影線」表示依照賣勢在最低價賣進，卻因為買勢的阻力返回價格迎接收盤價。

另一方面，「十字線」也叫做「開盤收盤等價線」（有時也標示為「夕陽明滅」），黑白K線的實體部分是橫線，如同字面的十字線，為開盤價和收盤價等價的情形。這是買方和賣方的勢力均衡的狀態。

十字線在高價區出現時，暗示著買方的氣勢被賣方擋住，轉為下跌。相比之下，在低價區出現的十字線，被理解為賣方的氣勢被買方擋住，暗示著轉為上升。另外，十字線向上延伸的上影線較長時表示上攻乏力，向下延伸的下影線較長時可視為強力阻止下跌。

因此K線的「蠟燭」和「影線」，不只是表現出行市的上升下跌，可以說也表現出行市的心理狀態。

漫畫中未咲與客戶對話時犯了錯，被客戶和頂頭上司部長責罵，內心的晴雨表暴跌。之後，晚上女生聚會時氣氛熱烈，晴雨表突然反轉上升。以K線來說就是加上「下影線」的狀態。

另外，當天帶著最好的心情回家後，內心平穩下來，到心情愉快地就寢的過程加上「上影線」，表示以陽線結束。

# 了解K線9種型態的意義

K線由實體和影線結合的9種型態為人所知。

### ◇小陽線、小陰線

- 「小陽線」是K線的實體較短，雖然買方與賣方不相上下，但價格稍微上漲的狀態。連續出現後可以期待變成「大陽線」。
- 「小陰線」則是，雖然買方與賣方不相上下，但價格稍微下跌的狀態。連續出現後可能變成「大陰線」，需要警戒。

### ◇大陽線、大陰線

- 「大陽線」是K線的實體比起其他的明顯較長，在走勢圖上很顯眼的陽線。實體的長度的標準為，平常的價格範圍5倍以上。暗示著賣方的氣勢減弱，之後買勢依然持續。
- 「大陰線」具有和大陽線相反的意思。暗示著賣方的氣勢強烈（買方的氣勢減弱），之後賣勢依然持續。

### ◇上影陽線、上影陰線

- 「上影陽線」是指K線擁有較長的陽線。上影陽線在高價區出現後，暗示著轉為下跌。雖是代表買方勝利的陽線，但可解釋為賣方的阻力較強，無法成長。反之在行市的低價區出現時，暗示著轉為上升。
- 「上影陰線」是較長的陰線。這也是假如在行市的高價區出現，便暗示著轉為下跌。暗示著在低價區持續下跌。

### ◇下影陽線、下影陰線

- 「下影陽線」是較長的陽線，在低價區出現時被視為暗示轉為上升的信號。這種情況下買方的阻力強，可理解為最終買方獲勝。
- 「下影陰線」是較長的陰線，在高價區出現時，暗示著轉為下跌。雖然買方遇到阻力，但最終解釋成賣方的勝利。另一方面在低價區出現時，暗示著從最低價反彈。表示雖然是陰線，但買方的阻力很強。

### ◇十字線、開盤收盤等價線

十字線、開盤收盤等價線，在前面已經解說過了，不過在行市「行情混亂」的場面、在基本的「暗示轉換」的局面中會出現。十字線之中稱為「影線等長線」的K線，上影線和下影線一樣長，會在行市的轉換點或加速時出現，傾向某一邊時可能大幅變動。除此之外，下影線長、上影線短的等時線是「蜻蜓十字線」；反之上影線長、下影線短或是沒有的等時線則是「墓碑線」。

### ○ 9 種基本的 K 線

![](img/300d6743e3871fdc0ea17875b15acce5_44_0.png)

除了K線的這9種基本型態，K線實體的長短，或是與實體結合的影線的位置與長短，使得K線的形狀很有特色。在下面將會介紹，用有趣的名字會比較容易記住，來學習各種K線的意思吧！

### ◇光頭陽線、光頭陰線

- 「光頭陽線」也叫做「光頭光腳陽線」，是沒有上下影線，實體比較大的陽線。開盤價就是最低價，買方不允許賣方創造低於開盤價的最低價，也不允許從最高價推回，收盤價就是最高價，是非常強勁的K線。從一直線延伸的K線，可以期待之後買方的氣勢仍會持續。
- 「光頭陰線」擁有和光頭陽線相反的性質。也叫做「光頭光腳陰線」。這是沒有影線的大陰線，暗示著從一直線的下跌，之後賣方的氣勢仍會持續。順帶一提，沒有影線的K線稱為「光頭」。

此外，雖然開盤後以一直線形成最高價，不過在收盤時稍微下跌，表現出形成收盤價的市價變動，比較大的陽線加上上影線的蠟燭叫做「開盤光頭陽線」，反之則叫做「開盤光頭陰線」。

### ◇極陽線、極陰線等

此外，暗示行情混亂或轉換的K線，還有「極陽線」（小陽星）、「極陰線」（小陰星）、「蜻蜓十字線」、「墓碑線」、「影線等長線」、「一字線」（四價合一K線）等。

- 「極陽線」是蠟燭的實體和上下影線都很短，會在行市的轉換點或股價變動加速時出現。含有儘管猶豫卻對上升抱期待感。
- 雖然「極陰線」表示失望感之中的猶豫，但還是行情疲軟走在前頭的狀態。
- 上影線下影線都沒有的一條橫線「一字線」（四價合一K線），開盤後既不上漲也不下跌，交易也很少，暗示著完全沒有氣勢。

說明到這邊，讀者應該也注意到了，K線能分類成「暗示上升」和「暗示下跌」，以及「暗示行情混亂或轉換」這3種模式。

依照暗示的強弱順序排列，可分類成暗示上升的K線有「光頭陽線」、「大陽線」、「下影陽線」、「下影陰線」；暗示下降的K線有「光頭陰線」、「大陰線」、「上影陰線」、「上影陽線」；以及暗示行情混亂或轉換有「極陽線」、「極陰線」、「蜻蜓十字線」、「墓碑線」等。

### POINT

- 擁有各種面貌的K線，性質也是五花八門。
- 依型態或出現的位置暗示著上升或下跌。
- 掌握基本，活用K線。

開頭的漫畫中，未咲作了享受旅行的夢，在內心的晴雨表數值「50」起床。之後工作上犯錯被部長叱責，內心的晴雨表數值暴跌到「20」。然後，在女生聚會度過開心的下班後時光，心情興奮，內心的晴雨表數值暴漲到「100」，就寝前興奮的心情也因收看YouTube平靜下來，在內心的晴雨表數值「80」就寢。

如果套用在股價的K線，與前一天相比略高在早晨開盤後，雖然發生問題變成陰線，卻以大陽線反擊，從最高價以保持穩定收盤的形式結束。在日K的K線，可說是毫無疑問的陽線。假如未咲在工作上沒有犯錯，K線應該會變成大陽線。

未咲就寢時想著「希望明天也是美好的一天」並且入睡。「明天也是……」因為這一天是陽線，所以對明天充滿期待。不只人們的生活，K線也反映出市場心理等而形成。

如同以上，K線不只股價與行市的狀況，也暗示了今後行市的方向。但是，任何事都沒有絕對。在K線圖也會出現「騙線」（市價變動沒有按照技術指標的訊號）。雖然K線有上升或下跌等信號，理論不通也是當然的。把責任推給K線也沒用。K線從江戶時代就是為人熟悉的行市分析手段，至少在這個背景下，它的确具有相應的說服力。

搭配多條K線就能分析行市的模式，應用這個方法，還能進行「酒田五法」這種技術分析，這是由「三山」、「三川」、「三空」、「三兵」、「三法」這5種基本模式所構成，不過先理解一條K線是十分重要的事。任何人都能學會並且分析K線。

K線圖在長久以來廣受支持的背景下，藏有與行市奮戰的先人的智慧。

- K線圖是任何人都能學會的先人的智慧。

# 幸與不幸，總是輪流造訪

有個故事成語是「夫禍之與福兮，何異糾纏」。意思是禍（＝不幸）與福（＝幸福）就像纏繞製作的繩索般輪流來訪。「塞翁失馬焉知非福」這個故事成語也幾乎是相同意思呢。

「人生有起有落」，有好的時候，也有不好的時候。不只人生，關於日常生活、工作、身體狀況、心理狀況或運氣等也可謂相同。事物必定有「波浪」。有一天這樣短時間的波浪，也有一個月、一年、或者五年、十年這種長時間的波浪。一邊重複小波浪和大波浪，一邊上升或下降。經濟和股票房市也有許多這種波浪（＝週期），可活用於分析和投資。

縱使人生走上坡，處於所向無敵的狀態，要是太過得意忘形犯了一點錯誤，或是發生倒霉的事就會感到沮喪，大家有過這種經驗嗎？人生在走上坡時也能碰到小小的下跌波浪。其實，在股價也會發生同樣的情形。

股價絕對不會完全不下跌，持續上漲，或是反過來完全沒有反彈，持續下跌。此外，當然也不會完全沒有起伏，持續維持同樣的價格。縱使長期來看大幅上升或下降，期間也會反覆上下波動。

「趨勢線」是藉由掌握這樣上下波動的傾向，理解股價上升、下降的趨勢，活用於交易的技術分析方法之一。在這個單元，將會介紹根據趨勢線的技術分析方法。

# 在技術分析的世界，超重要的「趨勢線」

不只技術分析的高手，就連幾乎不在意技術分析的投資者也會無意中盯著看，趨勢線就是如此重要的技術分析。它可以分成三種類型：畫出股價上下的波浪逐漸上升的「上升趨勢」，和同樣畫出上下的波浪逐漸下跌的「下降趨勢」，以及雖然上下波動卻在一定的線條內持續市價變動的「平穩趨勢」。

在開頭的漫畫中提到的未咲的伙食費，花得較少時是一天800日圓、870日圓、890日圓，慢慢地增加。不僅如此，花得較多時是一天1200日圓、1250日圓、1270日圓，也是逐漸提高，整體而言伙食費逐日增加。換言之，這種情況下伙食費是「上升趨勢」（對於想要設法控制支出的未咲來說，伙食費處於上升趨勢不是一件好事）。

![](img/300d6743e3871fdc0ea17875b15acce5_58_0.png)

![](img/300d6743e3871fdc0ea17875b15acce5_58_1.png)

那麼，首先來檢視上升趨勢中的趨勢線。在上升趨勢畫出的上下波動的最高價部分（以未咲的伙食費來說就是 1,200日圓、1,250日圓、1,270日圓），用一條線連接起來就叫做「高價壓力線（壓力線）」，這是從暫時價格上升再度轉為下降的基準。在上升趨勢，上漲的波浪接近高價壓力線，或者在接觸時，股價傾向於容易回落。因此，上升到高價壓力線附近時可視為賣出的時機。

那麼，首先來檢視上升趨勢中的趨勢線。在上升趨勢畫出的上下波動的最低價的部分（以未咲的伙食費來說就是800日圓、870日圓、890日圓），用一條線連接起來就叫做「低價支撐線（支撐線）」，這是從暫時價格下降再度轉為上升的基準。在上升趨勢，下跌的波浪接近低價支撐線，或者在接觸時，股價傾向於容易反彈。因此，下跌到低價支撐線附近時可視為買進的時機。

### ○ 上升趨勢

![](img/300d6743e3871fdc0ea17875b15acce5_59_0.png)

順帶一提，搭上上升趨勢買進叫做「順勢交易」。低價支撐線在推測順勢投資的買進時機時非常有效。

上升趨勢中如果股價低於低價支撐線，就是趨勢轉換的預兆。會變成暗示上升趨勢結束的最初的訊號。

如果用人生來比喻，工作順利，私生活也是，明明結婚等喜事臨門，卻因為生病或受傷等，齒輪開始往不好的方向轉動……大概像這種感覺吧。這種時候不要冒險，靜觀其變才是明智之舉。

股票投資也是同理。持有的公司股票股價低於低價支撐線時，開始研究暫且拋售股票或許比較好。當然，光憑低價支撐線並不能完全掌握股價的趨勢。由此身體狀況（股價）突然恢復，回到原本上升趨勢的例子也是有的。它終究只是一個訊號。
