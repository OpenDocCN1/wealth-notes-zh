# 葛蘭碧八大法則 8 個買賣重點

# 買進訊號

1. 移動平均線在有一定程度的期間下降後變得平穩，或者稍微轉為上升基調的狀態，股價由下往上穿過移動平均線時。

3. 股價向下突破處於上升趨勢的移動平均線後，再度上升時。

![](bbox=[0.25, 0.18, 0.78, 0.38])

2. 雖然股價往移動平均線大幅正向乖離後下跌，不過沒有跌到移動平均線，再度上升時。

4. 股價在下跌基調的移動平均線下方，大幅乖離時（可期待自律反彈）。

# 賣出訊號

8. 股價在上升基調的移動平均線上方，從移動平均線大幅乖離時（可能回跌）。

6. 股價向上突破下降趨勢的移動平均線後，再度下跌時。

![](bbox=[0.25, 0.57, 0.78, 0.79])

7. 雖然股價往移動平均線下方大幅乖離後上升，不過沒有到達移動平均線，再度下跌時。

5. 移動平均線在有一定程度的期間上升後變得平穩，或者稍微轉為下跌基調的狀態，股價由上往下穿過移動平均線時。
