# ○ 慢速隨機指標

![](bbox=[0.08, 0.075, 0.88, 0.41])

RSI 在 20% 以下，「Slow% K」由下往上穿過「Slow% D」的黃金交叉出現是買進的訊號。

RSI 80% 以上是超買區。「Slow% K」和「Slow% D」的死亡交叉出現是賣出訊號。

快速隨機指標正如其名，對行市的變動敏感地反應，而且買賣訊號頻繁出現。雖說適合短期投資，不過騙線很多正是其缺點。

慢速隨機指標果然正如其名比較慢，因而比起快速隨機指標買賣訊號出現的頻率減少。但是，騙線也因而減少。雖然慢速隨機指標是為了彌補快速隨機指標的缺點而設計的，但最近運用慢速隨機指標的情形也變多了。在此將解說慢速隨機指標的用法。
