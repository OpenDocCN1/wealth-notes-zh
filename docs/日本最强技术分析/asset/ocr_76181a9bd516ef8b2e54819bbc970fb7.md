# ◇上影陽線、上影陰線

「上影陽線」是指K線擁有較長的陽線。上影陽線在高價區出現後，暗示著轉為下跌。雖是代表買方勝利的陽線，但可解釋為賣方的阻力較強，無法成長。反之在行市的低價區出現時，暗示著轉為上升。

「上影陰線」是較長的陰線。這也是假如在行市的高價區出現，便暗示著轉為下跌。暗示著在低價區持續下跌。
