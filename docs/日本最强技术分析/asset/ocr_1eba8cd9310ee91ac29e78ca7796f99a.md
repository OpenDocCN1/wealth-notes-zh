# 後記

# 「戰勝市場的投資者都知道」

在本書介紹了具代表性的技術分析（走勢分析）。每種技術分析用來預測股價方向或趨勢轉折點時都非常可靠。在使用各種技術指標的過程中，應該會遇見喜歡的指標。不過它們各有優劣，或許也會碰上「騙線」。因此，正如本書也有提到，實際投資時建議並用多種技術指標。

此外，例如藉由日K圖進行交易時也是，首先顯示月K、週K圖，掌握是否為長期的趨勢之後再進行投資判斷，便能做出準確性更高的交易。

其中也有人否定技術分析：「技術分析只是結果論吧？」不過，觀察過去的傾向進行買賣的投資者非常多也是事實。

因此，了解占多數的投資者的傾向十分重要。在本書的Part 1也有寫到，因為股價的變動是由人氣投票決定，所以若能採取和其他大多數投資者相同的投資行動，搭上浪尖，就會有好結果。而且，多數投資者所有的投資行動會顯現在走勢圖上。
