## 黃金交叉比移動平均線更快出現！

接著來看K線圖上描繪的SMA和MACD變動。正如本單元一開始說明的，MACD在移動平均線中也是以EMA為基本，所以會根據最近的市價變動敏感地反應。這意味著比起SMA，MACD的買賣信號較早出現。

所謂騙線是指即使根據技術分析出現買賣訊號，之後的股價卻與訊號指示的方向反向移動。不只MACD，對於所有的技術指標都可說是如此。

## 找出對該公司股票而言，最好的技術指標。

MACD在市價變動出現清楚的趨勢時，是精確度很高的分析手法。因此獲得許多投資者支持，但它也有弱點。那就是股價以一定的價格範圍上下波動，處於區間市場或三角形態等狀況下有效度就會下降。因為MACD對於看清趨勢很有效，所以趨勢減弱，或是平穩趨勢時，就不太能發揮它的長處。

但是，這種情況只要搭配對區間市場較強的其他技術指標即可。若是MACD，與振盪型技術指標（判斷股價超賣、超買的指標）RSI搭配的契合度比較好。關於RSI將在Part 9詳細敘述，因此建議一併確認。

無論哪種技術指標都一樣，依照公司股票揭示適當買賣時機的指標將會改變。有時候某個公司股票MACD上的訊號揭示了最佳買賣時機，而有的時候某個公司股票使用其他技術指標比較好。

另外，明明以前某種技術指標完全適用，經過一段時間後卻有可能不再如此。要解決這種問題，得確認多種技術指標。並且，不妨調查每種公司股票在哪種技術分析的有效度比較高。

也許這些作業的確很麻煩，不過這也是為了自己的投資。在網路證券等提供的資訊工具，很多可以從K線圖跳到多種技術走勢圖，因此熟悉後就能在短時間內確認。

占卜有占星術或塔羅牌占卜、姓名判斷、手相或面相等許多種類。還有解夢或動物占卜等類型。雖然我對占卜不是很熟悉，不過每種占卜都有各自的長處與特色，無法斷言哪一種最準。依照占卜時機或想占卜的內容也會有所變化。

技術指標也有類似的一面，無法斷定哪種技術指標是最好的。但可以透過比較目前為止的股價變動和多種技術指標看清。「這個公司股票MACD的訊號和買賣時機完全重疊呢！」建議像這樣判斷。

# 從通道的寬度、傾斜和收縮判斷行市的趨勢與力道。

在這個單元將會介紹知名的趨勢分析工具「布林通道」。布林通道由移動平均線和標準差構成，藉由表示移動平均線的線和位於上下，表示市價變動幅度的線（通道）進行投資判斷。

「價格大半收在這個通道（帶子）裡」，是應用統計學的指標。

在布林通道，通常是在K線圖上畫出5條線。線條由上至下為+2σ（sigma）、+1σ、移動平均線、-1σ、-2σ。藉由這5條線構成的通道幅度、傾斜與收縮判斷行市的趨勢與強弱。此外還有加上±3σ，以7條線構成的例子。

前提是，股價收在布林通道±1σ的範圍內的機率約68.3%、收在±2σ的範圍內的機率約95.4%、收在±3σ的範圍內的機率約99.7%。

超過正負2個標準差的股價是異常值。

例如，車子的道路上行駛的車道是固定的。打瞌睡蛇行或逆向等是會上新聞的問題，大部分的駕駛都會留意安全駕駛，行駛在固定幅度的車道內。

股價也一樣。平時是在一定程度的幅度（通道內）反覆上下波動，即使超出也遲早會回到原本的通道內。

如同前述，股價收在±2σ的範圍內的機率約95·4%，因此超過就是相當罕見的情形，是某種異常值。如果比喻成駕駛車輛，便是打瞌睡開車等超出車道的情況。這種駕駛行為絕對不行。大幅超出車道，只有下高速公路的時候。

### POINT

股價收在±1σ的機率約68・3%、±2σ約95 ・4%、±3σ約99 ・7%。

### 布林通道的算式

1. 標準差的算式
   標準差=√(n天內的收盤價-n天內的平均值)的平方的總和÷n天

2. 布林通道的算式
   ±1σ=n天的移動平均±n天的標準差
   ±2σ=n天的移動平均±n天的標準差×2
   ±3σ=n天的移動平均±n天的標準差×3

### 關於價格收在通道內的機率

| 收在布林通道的範圍 | 機率 |
| :--- | :--- |
| ±1σ | 約 68.3% |
| ±2σ | 約 95.4% |
| ±3σ | 約 99.7% |

雖然算式如同上圖，不過不用想得很困難，當然也不必計算。現在網路證券的資訊工具就能輕易顯示。如果有在意的公司股票，只須輸入四位數的公司股票代碼就能看到資訊。

要使用多久期間的移動平均的數值，雖然依照短期買賣或中長期投資等投資態度而有所不同，不過假如是日K，如5天或25天等，盡量是較多投資者看的數值比較好。數值設定也是利用資訊工具選擇，或是只須輸入即可。瞬間就會顯示在電腦或手機畫面上。

和其他振盪型或趨勢型的技術分析不同，布林通道也能活用於「順勢交易」和「逆勢交易」。它是十分方便的技術分析，因此有非常多投資者活用。那麼，接下來解說實際的用法和重點。

## 搭上行市趨勢的順勢交易型。

首先解說我最信賴的，一種叫做「波動突破」的順勢交易型的用法。代表性的例子是，在脫離穩定行市的時機買賣的手法。布林通道在行市的動作貧乏時通道的幅度會變窄，行市的動作激烈時通道的幅度會變寬。

通道的幅度變窄時要注意市價變動，收盤價超出±2σ後，就老實地跟隨趨勢進場。此外，通道幅度狹窄的時期愈長，之後突破時的市價變動就愈大。

### ○布林通道（順勢交易型）

![](img/300d6743e3871fdc0ea17875b15acce5_144_0.png)

在順勢交易型的波動突破，股價以收盤價穿過±2σ時，換言之，出現異常值時要跳上去，因此或許感覺和之前的解說略微不同。

然而，判斷的時機終究是布林通道的通道幅度收縮、變窄時。股價在這種局面穿過±2σ，可以估計接下來行市會增長勢頭，通道幅度變寬。

雖然上圖是波動突破的例子，不過通道收聚後從穿過+2σ開始通道幅度變寬，可知股價沿著+2σ的線條持續上升。結算的時機是，股價以收盤價低於+2σ時，或通道開始收聚時。

### POINT

股價持續穩定，通道幅度變窄就要注意。
以收盤價穿過±2σ時順勢交易進場。

活用趨勢通道，鎖定趨勢發生時的一時下跌。

前述的波動突破，是快速掌握行市的轉換點，搭上上升或下降趨勢的投資手法。這股趨勢持續時，股價會在移動平均線與±2σ線，或是±1σ線和±2σ線之間反覆上下波動，並往趨勢方向移動。

K線沿著±2σ的線條並排的狀態叫做「趨勢通道」。趨勢通道出現時，就鎖定一時下跌進場。

在區間市場鎖定過度上升與下跌逆勢交易。

最後介紹在布林通道的區間市場的逆勢交易。這裡的思考方式，要變成在開頭的漫畫中介紹的車輛行駛。複習一下，股價收在通道內的機率如同下述：

- 收在布林通道的±1σ的範圍內的機率→約68・3%
- 收在布林通道的±2σ的範圍內的機率→約95 ・4%
- 收在布林通道的±3σ的範圍內的機率→約99.7%

換言之，突破 ±2σ 是非常罕見的例子，也是異常事態。抓住這個時機逆勢交易進場，等待股價回到正常值。雖然在外觀也是非常簡單明瞭的逆勢交易手法，不過必須注意「一定要在股價持續穩定的區間市場活用」。因為正如在波動突破和趨勢通道解說的，在股價的方向（趨勢）明確的局面中，穿過 ±2σ 的例子並不罕見。

如果顯示到機率 99.7% 的正負 3 個標準差，準確性就會提高。

作為區間市場時的逆勢投資活用之際，把從 +1σ 到 +2σ 分別想成低價支撐線（支撐線）和高價阻力線（壓力線），股價從 -1σ 跌到 -2σ 就是買進點，從 +1σ 漲到 +2σ 就判斷為賣出點。在技術分析的工具等一般顯示到 +2σ，不過顯示到機率約 99.7% 的 ±3σ，到達 +3σ 逆勢交易的話，準確性就會更加提高。

當然，因為±3σ的出現率很低，所以很難出現買賣的信號。因此，在-2σ試探買進，股價繼續下跌觸及-3σ時決定逢低買進攤平成本，這種想法也是可行的。

### POINT

在股價持續穩定的區間市場逆勢交易活用。觸及±2σ後逆勢交易進場。

移動平均線幾乎呈水平狀態，觸及±2σ時就判斷為買賣時機。

在獲利了結的同時，結算時機也是根據信用交易「賣空」（信用出售）的機會。賣空是利用股價下跌瞄準收益的投資手法。像這樣在區間市場，輪流站在買賣的位置來回瞄準盈利也行。

提案者自己否定在逆勢交易活用。

附帶一提，布林通道是美國人約翰·布林（John A・Bollinger）先生所設計的技術分析。到目前為止他來過日本好幾次，我也曾經和他一起 吃過飯。他是十分親切，有紳士風度的人。

布林先生對於自己提案的布林通道的活用，說：「在逆勢交易不應該使用。」在逆勢交易的用法，因為觸及高價阻力線和低價支撐線的±2σ，雖然在 外觀上也很單純，不過有時也會出現許多騙線。 即使在區間市場貫徹活用，行市也會從穩定情況 上下大幅變動，這也能夠預想得到。

股票與外匯，或者波動率（價格變動率）高的加 密資產比特幣等，有時候果斷撤退也很重要。別 想要一攫千金，和行市長期打交道，留意長期 的資產運用吧！

## 日本製造的一目均衡表。

「一目均衡表」這個名稱很獨特，有種復古的感覺呢。一目均衡表即使名稱古老，在技術分析卻擁有高知名度，受到廣泛活用。

一目均衡表的理論完成於昭和時代初期。東京新聞的前身都新聞，有一位筆名為一目山人的幹部，和許多工作人員耗費數年歲月完成了這個行市分析手法。在日本國內的個人投資者之間也頗受歡迎，歐美也出版了一目均衡表的解說書，它也是受到許多基金經理人支持的技術手法。一目均衡表是因為行市能一目了然才如此命名。

在技術指標之中，K線、移動平均線、布林通道等是以時間及時間順序作為分析要素，一目均衡表也納入這個群組。它以時間論、波動論、值幅觀測論（也叫做水準論）所構成，從作為段落的價格變化發生的日期計算特定的基本數值等日數，這是能預測將來變化日期的技術分析。

這個觀點認為「行市在買方與賣方的均衡崩潰時會大幅變動」，根據的理論是「買賣勢力其中一方若能掌握優勢，就能一眼得知行市變動」。
