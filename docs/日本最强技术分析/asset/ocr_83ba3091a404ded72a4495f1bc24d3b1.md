# 幸與不幸，總是輪流造訪。

有個故事成語是「夫禍之與福兮，何異糾纏」。意思是禍（＝不幸）與福（＝幸福）就像纏繞製作 的繩索般輪流來訪。「塞翁失馬焉知非福」這個故事 成語也幾乎是相同意思呢。

「人生有起有落」，有好的時候，也有不好的時 候。不只人生，關於日常生活、工作、身體狀況、心 理狀況或運氣等也可謂相同。事物必定有「波浪」。 有一天這樣短時間的波浪，也有一個月、一年、或者 五年、十年這種長時間的波浪。一邊重複小波浪和 大波浪，一邊上升或下降。經濟和股票房市也有許多這 種波浪（＝週期），可活用於分析和投資。

縱使人生走上坡，處於所向無敵的狀態，要是太 過得意忘形犯了一點錯誤，或是發生倒霉的事就會 感到沮喪，大家有過這種經驗嗎？人生在走上坡時也 能碰到小小的下跌波浪。其實，在股價也會發生同樣 的情形。
