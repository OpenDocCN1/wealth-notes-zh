# | 下周预告：互联网时代的领导能力

下周，我们将进入个人篇的最后一周，我会和大家分享下互联网时代，5个对于领导力最重要的部分，不要错过。

领导力：专 >>> 通过放弃关注大部分的事，只“选择性注意”少部分的事，从而提高其成功率的能力，它被很多人认为是领导力的重要组成部分。

领导力：小 >>> 我创业时别人给我的重要建议，要勇于把企业做小而不是做大。你对资源的投入，决定了你要走的道路。通过变小，获得专注。

领导力：变 >>> 人天生会追求确定性，习惯把经验当真理，把流程当圣经。但互联网时代充满不确定和复杂性，想修炼领导力，先要有颗变革之心。

领导力：快 >>> 速度快、灵活、周期短。觉得值得干，就立刻启动“计划、执行、检查、纠正”四步法，快速行动。用内部的快响应外部的变，才能抓住机遇。

领导力：远 >>> 社会变化越来越快，经验不再来自于过去，而是来自于正在发生的未来。培养对未来的远见、判断和预测能力非常重要。要向年轻人学习，要勇于尝试新事物，让未来扑面而来。

已经要接近200期了，如果你一直跟随着学下来，此刻，你该为自己的坚持鼓掌；如果你中途放弃过，现在又迎头赶上，也很好。吴军老师说过一句话，我非常认同，人生是一个持续时间特别长的比赛，比赛进行到半场的时候，很多对手就弃权了，或者失去了比赛资格，剩下的就是赢家。希望我们能继续陪伴着走完这260期，一起见证更大的进步。

减法创新的案例有很多，比如“单反相机-傻瓜相机-手机摄像头”这种创新思维，在产品研发领域和服务领域也可以有好的应用。

去年我服务的一家新式餐饮公司，老板通过低温恒炖的新方法开发了180多道菜，后来，我们换了一种方式，找到客户最常点的5样，每月只供应5道菜，按月更新菜谱。一方面集中采购大大降低了采购成本，另一方面，很多客户被吸引着每月都要到餐厅来消费，尝试新菜。我们还策划了学习班，让客户每月学习5道菜；因此锅具的销售额大幅度提升；同时，餐厅闲暇时间里也有了大量的课程收入。做了减法，反而使餐厅大幅度盈利。
