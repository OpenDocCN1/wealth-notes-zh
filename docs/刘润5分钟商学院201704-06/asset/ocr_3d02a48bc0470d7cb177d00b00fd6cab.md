# 一、提问的方式，主要有两种：

+   1、开放式提问。

答案以回答人的想法自由发挥。

+   2、封闭式提问。

销售过程中应该尽量采用这种提问方式，答案只有A或B，两种答案我们都预先设想好，无论对方选择两种答案中的哪一种，都是我们想要的结果。

# 二、提问的内容：以销售为例，可以从那几个角度提问。

+   1、问开始。

可以以客户的第一次开始进行提问。例如您是首次购车吗？您是第一次来到我们展厅吗？您是第一次了解我们别克轿车吗？

+   2、问兴趣。

问到客户的兴趣爱好，更能引发客户积极地聆听和回答。例如：我看你穿得这双足球鞋不错，很喜欢足球运动吧？

+   3、问需求。

您一定遇到了大型停车场找不到车的情况吧？有了安吉星一扣就迎刃而解了，您只需要拨打安吉星客户服务电话，就可以使车辆鸣号和双闪，这样就可以轻松找到您的爱车了。

+   4、问痛苦。

到了夏天坐到酷热的车里汗流夹背地打开车内空调降温一定很痛苦吧？我们配置了远程启动功能，只需在车外轻轻一按，便可启动车辆，空调自动打开降温。这样再坐在车里，温度适宜，很棒是不是？

+   5、问快乐。

平常驾驶时要是能边开边享受顶级剧院的音效那一定很棒，您说是吧？我们这款车配备了BOSE5.1声道豪华音响，就能给您带来这样的感受。

+   6、问成交。

刚刚给您做了这么多介绍，您也亲自试乘试驾体验了，既然感觉这么好，今天要不然订一台？

# 三、在提问过程中我们应该注意以下问题：

+   1、问简单容易回答的问题。要让客户容易回答，易于理解的，问题太复杂，客户一头雾水，听不明白，更是无从回答，这样的答案对于我们也都没用。

+   2、要问答案是“是”的问题。引导客户说，是，有科学统计，连续问七个答案是“是”的问题，再问第八个问题时，顾客的回答也会是“是”，在惯性的作用下，错误的东西你都会坚持。

+   3、从小的（局部）“是”开始问。从局部开始，客户更容易接受。

+   4、要问一些引导性的、约束性的、二选一的问题，让客户在这些必须选择的选项中进行选择。

+   5、事先想好答案。无论客户回答哪种我们都有应对。

+   6、能问的，尽量少说。让客户跟着我们的思路进行思考，而不是销售顾问自己在说，客户其实却并不关心。
