# 加餐丨别错过52次向商业偶像偷师的机会

![](bbox=[0.27, 0.16, 0.32, 0.2])

他们中的每一个，都是市值几十亿的著名公司的CEO或者负责人。

平时，我们几乎只能在报刊杂志上听到他们一点点点的思想分享，现在，我努力把他们邀请到咱们的专栏《5分钟商学院》里担任客座教授。每周六，和同学们坦诚分享他们对行业未来趋势的判断、对过往决策的复盘，满满干货，你千万别错过。

# 这么做有两个目的：

+   1、让你提前了解未来的行业趋势。
每一位公司老大都是手握资源、身居高位的人，他们能够从一个很高的维度，来分析行业的未来趋势。如果你能从中抓住和自己相关的商业机会，提前储备、布局，就很可能获得更大的成功。

+   2、让你感受并养成更高维度的思考视角。
每个公司都是面对着巨大的市场压力和业绩指标，摸爬滚打地一步步向前，我们请来的每一位公司老大也都是身经百战。听他们和你说，自己当初遇到了什么问题，怎么解决的，哪些坑千万要避开，如果有下次怎么会更好，相信可以培养你们的战略意识和决策能力。

# 来看之前客座教授的分享：

> 创业是团队过去资源的总爆发。
一个团队在创业前，如果在所在领域有足够积累，对产品和业务模式有深刻认识，会有很大优势。
——李创威，真格成长基金管理合伙人

> 我们把一个买家从诞生一笔钢材交易到整个完成的过程拆分为13个环节，深入每个环节研究，探寻哪个环节可以用互联网替代，切中需求。
——王东，找钢网创始人兼CEO

> 线上已经过了高速的增长期，现在线上和线下的获客成本到了一个同样的临界点，拼的是谁的效率更高。未来5年，品牌都会走 legitimacy 线上线下融合这条路上。
——方建华，茵曼品牌创始人

> 过去我会直接和团队说，咱们这么干吧。现在，我抛出题目讨论，启发每个人思考，一旦把你要做的变成大家要做的，形成共识，后面就是全心全意做了。
——陈葵，前Twitter大中华区董事总经理

> 今天的很多组织中，员工不但要自行负责，而且要“管理上司”，上级成了下级必须去调动和管理的资源。因此，每个人都要学习成为领导者、管理者和决策者。
——王欣，德鲁克管理学院院长，微软中国区前副总裁
