# 宝宝，你好！

今天，我在得到上的专栏《刘润·5分钟商学院》的订阅人数，突破了10万人。在这个媒体们都疯狂追逐10万+的时代，一个付费的专栏，一个追求自我提升、鼓励反求诸己的专栏，一个不迎合热点、趣味、八卦的严肃的商业专栏，能得到你们的信任，激发10万次自愿付费，更重要的是承诺一年的时间，允许我陪伴，共同进步，我真真切切地感到受宠若惊。

在《刘润·5分钟商学院》突破“付费10万+”之际，我想与你分享一点点我的感受。

2016年4月，罗辑思维北京办公室。罗振宇老师对我说：我知道你是很知名企业的商业顾问，是一些大企业家的教练，给很多商业精英们讲课，时间很宝贵，但是，我想邀请你做一件真正的大事：每天写1篇专栏，每周5天，全年52周，一共260期不断更地，给更广大罗辑思维求知好学的小伙伴们，分享你的商业洞察。

你知道我当时的感受吗？我确实被吓到了。每天1篇，全年260期，这可不是一个小的承诺啊。万一有一天，我有事呢？万一有一天，我没有灵感呢？万一有一天，我生病了呢？万一有一天，我就是什么都不想做呢？

和菜头老师当时也在，他非常体贴地安慰我说：你可以的，你可以的，你可以的。

在去机场的路上，我灵机一动，对着手机说了一个观点，录成了5分钟的音频，发给了罗振宇老师。我想，我每年要在全国做100场演讲，什么大场面没有见过，只要我想的比说的快，这5分钟，应该可以随时随地，张口就来吧。

然后，我就被罗振宇老师温柔地、克制地，骂得狗血临头。他给我讲了翰林院伺候皇上读书的姿态问题。意思是说，别以为你是大学士就了不起，你要有把听众都当皇上的心态，这事才能做成。

我受了很大的刺激，于是 在办公室里闭关15天，绞尽脑汁，终于把自己那点所学，整理成了一张精确到每天讲什么的，体系化的课程表。我决定，分4个季度来帮助“皇上”搭建对商业的认知框架：
