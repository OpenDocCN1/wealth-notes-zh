# 周末小结｜为什么你听了那么多道理，依然过不好这一生？

《5分钟商学院》的同学们，

大家周末好！

这两周，我们一直在强调一句话，想法产生行为，行为产生习惯，习惯产生性格，性格改变命运。想法、行为、习惯、性格、命运，这5件事情中，如果非要拎出一个最重要的抓手，那一定是习惯。

想法是一念而起、一念而灭的，它存在于思考脑中，就算你的想法非常正确，但促成行为之前，想法是没有任何意义的。这也是为什么很多人都会有这样的感慨：你听了很多道理，依然过不好一生，因为你并没有把想法变成行为。

但只变成行为还不够，行为是通过思考脑做的事情，一个人一天的行为中，大约只有5%是靠思考脑驱动的，而其它95%的行为都源自于习惯，靠反射脑来驱动。只有当你不断练习，让行为变成习惯，才能真正改变你自己的东西，才能真的影响一辈子。

所以说，习惯是最难最关键的点，但一旦你养成了一个好习惯，就相当于你把一个正确的逻辑，写入了反射脑中。未来，一些别人看起来非常痛苦的事情，于你，就是自然而然的反应。你不但在做自己，你还成为了更好的自己。

日拱一卒，百日之后，就不可小视。当你养成了几个优秀的好习惯，你就可以过好这一生。

# ｜本周留言精选

“双赢”思维与伯凡老师的内容可以结合起来考虑：

一个人格局不大，其实就是心智带宽不够，就是心智的空间不够。而心智带宽不够，导致决断力，自控力，行动力大降低，心胸的堵塞和狭窄，只考虑自己的成本最小，收益最大化，最终是他眼前的空间和格局的狭窄。而在一个生态中，利益分享是生态的驱动力。所谓的生态优势，其实就是懂得利益分享，懂得化敌为友，懂得尊重别人的利益，尊重别人的地盘。你在活的时候别人也能活。最后，最终的成功不取决於你消灭了谁，而取决于你团结了谁。

分享一件去年发生的“小事”。女儿下幼儿园，告诉我今天老师教要分享。我在聆听时，正好碰到邻居送给了她一个苹果。女儿二话不说，马上就咬了一大口。这时，我脑海里马上浮现一种感觉，刚才她还在说分享，现在有苹果就只顾自己……我正准备想办法教育她，女儿突然把苹果伸到我的面前说，爸爸，我帮你试了试，这个苹果很甜，你可以吃了。

我突然意识到，臆测是多么可怕，在没有充分了解孩子意图前，我就盲目判断，差点伤害了这个小天使，瞬间让我觉得自己很愧疚。

在我们的生活和工作中，存在大量臆测的伤害。不管任何事情，要先了解对方的真实意图，再让对方了解自己的真实意图，知彼解己。

以前药房做优惠活动，从主持人、活动策划、赠品和DM单的发放，全部都是自己的员工来做，大家都是学医学药的，虽然心和累的，但效果不明显。现在会请专业的主持人活跃氛围，品牌厂家参与活动策划、提供多样的活动，重点供应商提供赠品，有一些还是常用的厨房用品和日用品，DM单都请专门的团队投送入户。由于他们的专业和精准，加上品牌厂家和重点供应商的资源，活动效果非常地好，销量是平日的好多倍，利润率还都不错。这正是药房明白了尊重观点的差异，感激团队的多样性，通过合作，我们找到了共享的目标，找到了“1+1>3”，不要单干，要合作的“第三方案”，即统合综效。

看完刘润老师关于优秀者七个本能的解读，我想，真能练就这“七种武器”的人是凤毛麟角的。我的理解是，应该经常反过来思考和提醒自己。那就是低效能人士的七个习惯：消极被动、没有目标、来者做啥、非赢即输、自我中心、管中窥豹、经验主义。先从避免陷入低效能困境中开始。

多说一句，所有的“坚持”最终会击败你，只有你根本不需要“坚持”这个概念，仅仅是认为这种高效能的人生非常“有意义”，你就开始锤炼你的“七种武器”了。

以前有个脱口而出的口头禅“不会呀”“不是的”，习惯性反驳习惯性指责，曾有一段时间觉得自己很直爽。现在回想真是可笑。为了改掉这个习惯，有很多次都是强忍着硬把话憋回去，确实很不舒服。有个说法是，当一切都太顺利的时候，就一定会出现问题。舒适区
