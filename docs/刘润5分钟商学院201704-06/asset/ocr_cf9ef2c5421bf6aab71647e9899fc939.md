# 小结：认识GTD

GTD，是一套“让大脑用来思考，而不是用来记事”的时间管理方法，通过借助外部工具，比如印象笔记，第一，清空大脑，把所有事情，100%放入收集篮；第二，处理收集篮，把事情用删除、归档、将来/可能、等待、下一步行动、项目的办法归类；第三，随时回顾、每天回顾、每周回顾，从分类中提取需要完成的事情，然后，行动。

使用GTD的方法，可以让你心中无事，从而再忙也不焦虑，专注于思考和解决问题。
