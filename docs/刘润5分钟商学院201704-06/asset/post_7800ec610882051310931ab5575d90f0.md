很多人都很好奇，作为一个管理实战派的杰出代表，他有什么独特的管理经验，外企和民企的管理模式上究竟有何区别。这周，我们换了一种特别的方式，邀请“得到知识新闻工作室”专访了这位大牛，干货满满，分享给同学们。

# 1、知识新闻工作室：您在惠普工作了很多年，也在民企工作过，您觉得它们最大的差别在哪里？

孙振耀：我在惠普25年，在民企10年。在我看来，外企是组织文化，它的决策模式更多是按分工来的、分层授权。它是典型的网状模式，有一套固定的流程、制度和企业文化，规则摆第一。员工之间各自专注自己的工作，该我担责的就我担责。

民企则是老板文化，决策模式是老板拍板，更多的是伞状的指挥模式，老板是原点，其他人都是点对点、对老板负责。决策很快，行动很快，但员工的主动性较弱，担责性也比较弱，要靠老板去推他。

外企到民企，是两个完全不同的土壤。如果说对民营企业的老板们有一些建议，第一个，管理不能落后，但是也不能过度。什么叫过度？你的商业模式还不清晰，你整个团队加一起就几十个人，要上制度、要流程，就很没必要。

创业有三个阶段：创业刚开始，强调的是执行力和团队的奋斗精神，要不断试错、不怕失败。慢慢地做到一定阶段，就要开始总结经验、规范流程、讲究战略，就不能说再无知无畏地试错了。再继续做，你就要开始搭建体系了，要有职能分工了，要开始引入流程。企业的发展是有阶段性的，不同发展阶段要解决的问题会很不一样，不要讨厌管理，也不要复制，要去辨识。

样，不要过度管理，也不要复制，要去辨识。

第二，不仅要重视制度，也要重视制度背后的配套文化。

经常和一些中小民企的老板见面的时候，听到他们抱怨说企业的KPI定得不好、跟KPI相关的考核方式定得不好。其实根本的问题可能不在KPI身上，而在于你这个团队是怎么认识KPI的，你们对KPI的理解是什么。不仅要有制度，还要有制度配套的文化，这是一个系统工程。建议老板们除了引入方法论解决某个点的问题，还要搭建一个完善的系统来解决面的问题。

而且，民企本身可能是综合环境变换的问题，更多地去做事件性管理。有事解决，没事也不会说开会。外企会更强调短期、长期都是要解决的。

# 2、知识新闻工作室：您觉得对于一个管理者来说，应该具有什么样的能力或素质？

好的管理者应该具备三种能力，经营、领导跟管理。

经营就是看机会。我30多年前开始做经理的时候，老板就告诉我公司，对经理的要求是有看水晶球的能力，就是要有预见性，能够判断出来未来要发生什么事。然后就可以提早处理。

# 3、知识新闻工作室：您做过多年的外企高管、现在又在自己创业，过去的经验对于您的转型，那些是优势，那些是包袱？

孙振耀：创业跟做职业经理人有非常大的不同。对我个人来说，我过去的成功经验，其实对我创业是一个包袱。

# 周末小结｜掌握这4个商业工具，做人群中的领先者

《5分钟商学院》的同学们，

大家周末好！

本周四晚上，我在得到APP做了一场主题为“掌握这4个商业工具 做人群中的领先者”的直播，感谢2万多名热爱学习的同学同时在线、全程参与。我在后台看到了非常多的留言，一些同学说因为各种原因没能及时看到，很希望能够有机会回看这次直播，我特别要到了这场直播的完整文字记录，经过梳理后，供大家复习回顾。

主题：
+ 1、如何判断一个商业点子是否可行？
2、创业期、成熟期、转型期的公司，怎么激励团队最有效？
3、如何通过写作、演讲这2个利器构建个人影响力？
4、哪些工具，能让你的工作效率瞬间倍增？
5、我是如何分配精力和经营人脉的？

# 直播要点回顾：

+ 1、判断一个商业点子是不是可行，最基础的逻辑，就是消费者有没有因此而获益。大家要记住这一点，刚需一直在，看你有没有用一种创新的方法去满足了这个刚需，是不是对商业的链条做了或大或小的优化。

2、当你有了一个商业点子，首先要做一个基础的判断，你这个点子到底是创造价值的点子，还是传递价值的点子。

如果是传递价值环节，你要思考的最重要的逻辑，就是如何降低行业的定倍率。反过来你在创造价值里面，你核心的逻辑应该是定价权，你是不是能用创新的方法在你的商品上获得定价权，你能做出别人做不出来的东西。

3、企业和员工的基本关系，其实从来没有变过，叫做基于价值的合伙关系。只不过，它随着不同的时期所体现的形态是不同的。第一种我们称之为叫利益共同体。第二种叫做事业共同体，第三种叫做命运共同体。在不同的阶段要用不同的激励的手段。

4、成熟期，就是商业模式、产品、盈利能力已经基本确定了，已经有了一套相对靠谱的流程和方法了，这时候你就不需要给员工以所谓的股份和结果的激励，一定就要对行为进行奖金激励了，比如说用工资+奖金+期权+分红+提成。

工资是付给责任的，责任越大的人，工资应该越大。奖金是用来激励额外的绩效的，期权是用来激发这个人的潜力，让他想办法设法地让整个公司增值，他是从未来的增值里面获益的。分红是整个公司一整年的业绩，是整个公司赚的钱，他可能就不仅局限于自己目前的工作了。提成和奖金有一点类似，但是不同。提成是在创业的早期用来激励销售行为的，但奖金是在成熟期用来激励行为的。

5、如果你想获得更大的影响力，有两个大规模杀伤性武器一定要学会用：演讲、写作。演讲能让你的信息能最全面地传递给公司尽可能多的员工，或者传递给整个市场。写作虽然失去了一些现场感，但它的影响力可以跨越时间。

6、写作有三个心法：
a.价值感。任何一篇文章、任何演讲，都在回答三个问题，what，是什么。why，为什么（这事的动机）。how，怎么做。如果 你 核心讲 what，你通常是一个教科书式的东西，字典式的东西，如果讲 why，你很容易讲成心灵鸡汤，但如果你讲 how，你就很有可能变成一个方法论，变成一个价值感特别强的东西，你要对这一点有清晰的想法。

b.结构感。第一步做场景导入，让他觉得这事就在自己身边发生。第二步打破既见，让他感觉这事看来我以前的理解不对，让他明白读这篇文章的动机。第三步讲核心逻辑，用故事的方式讲清楚这事到底是怎么回事。第四步叫举一反三，告诉他怎么做，让他感觉到价值感。第五步做总结，其实我今天讲的这三件事，这两个金句，你带走，放在你合适的大脑中的存储区。

c.对象感。训练对着镜头像对着一个具体对象在说话的感觉，用你取代大家这个词，让别人感觉这是专门讲给我听的，我应该从中有所收获。

总结起来，就是站在对方的角度去思考，而不仅要站在自己的表达角度去思考。

7、讲故事，演讲的时候，逻辑感和线条感是特别重要的。首先提一个问题，然后讲原因，给解决方案。表述逻辑一定是线性的逻辑，一步一步的扣下去。

8、君子性非异也，善假于物也。优秀的人跟你之间其实没有那么大的差别，最大的差别在于他懂得使用工具。你要想比别人变的优秀，不仅仅是你的思考能力，还在于你对工具的使用能力。比如，用邮件、日历、Evernote印象笔记，把所有记事的事情全部都放在大脑外部，让自己回归思考。再比如，我出门会带一个三折的蓝牙键盘、一个手机支架、这样随时就可以写东西了。

9、所有的人脉都是建立在你自身的价值之上，都源自于你自身的价值输出。人脉是你能帮到的那些人，而不是那些能帮到你的人。持续的给予价值，是更新、积累人脉的唯一方法。

10、一定要对自己有严格的自律，用这种自律做在你的产品上，死磕你的产品，死磕你的效率，死磕你的创新，你在商业世界里面才有可能无往不利。

在这堂课上，从企业所处发展周期开始，分享这四个管理逻辑：

第一，企业生命周期。这个世界上有放之四海而皆准的管理方法论吗？这世界上有能帮助企业基业长青的战略和组织吗？为什么管仲，陶朱公的企业，没有活到今天？企业的发展有三个阶段：创业期，成熟期，转型期。我将在这个部分，帮助大家定位自己的阶段，并寻找合适的管理方法。

第二，创业期管理。为什么小米说没有KPI，罗辑思维说没有组织架构，很多创业者甚至说他们痛恨管理？创业期的企业真的不需要管理吗？那他们需要什么？创业者成功，到底是靠努力，还是靠运气？我会在这一部分与大家分享，创业期企业的成功特征。
