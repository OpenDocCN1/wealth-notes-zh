# 得到专栏·5分钟商学院

主讲人：刘润

![](bbox=[0.07, 0.68, 0.15, 0.73])

刘润

你身边有哪些同理心爆表的案例，或者用来训练同理心的喜好方法，可以与大家分享吗？来和我一起过过招吧。

6月3日，《刘润·5分钟商学院》“管理篇”的第二场线下大课，将在北京举办。上一次商业篇课程的北京场，我们准备了200个位置，结果几天时间票就被抢光了，很多同学托关系找到我希望能够多加一些位子。这次的北京场，我特别请得到同学们找了一个更大的场子，目前已经售出400张票，还有最后一百张票，想要参加此次面对面线下大课的同学们，要抓紧了。

如果说“商业”是讲如何对外，“管理”就是讲如何持家，两者缺一不可。在此次管理篇的大课中，我会和大家分享四个方面的逻辑：

第一，企业生命周期。这个世界上有所之四海而皆准的管理方法论吗？这个世界上有能帮助企业基业长青的战略和组织吗？为什么管仲，陶朱公的企业，没有活到今天？企业的发展有三个阶段：创业期，成熟期，转型期。我将atalg在这个部分，帮助大家定位自己的阶段，并寻找合适的管理方法。

第二，创业期管理。为什么小米说没有KPI，罗辑思维说没有组织架构，很多创业者甚至说他们痛恨管理？创业期的企业真的不需要管理吗？那他们需要什么？创业者成功，到底是靠努力，还是靠运气？我会在这一部分与大家分享，创业期企业的成功特征。

第三，成熟期管理。企业越来越大，这到底是好事还是坏事？哪些创业期要的聪明、抖的机灵，必须被抛弃？游击队如何变成正规军，狩猎如何变成农耕？战略必须流程化吗，流程必须工具化吗？我会在这一部分与大家分享，参天大树，和破土幼苗，到底不同在哪里。

第四，转型期管理。没有成功的企业，只有时代的企业。这就像人一样，死因各不相同，但死是必然的。健康长寿，不代表永生；医疗先进，不代表免死。那应该怎么办？我会在这一部分与大家分享，真正的转型，重获新生，到底怎么做。
