本周的周末小结，我特别为你整理了12条即插即用的管理准则。管理不易，但如果你能点燃大家、让大家心服口服、进而创造出一个齐心的精锐部队，你会爱上管理的。

+   1、作为管理者，你必须赋予每一件事值得做的意义，花时间和大家说明意义，而不是告诉大家：这是命令。如果员工觉得一件事不值得做，就不会把它做好。

+   2、为了提高效率和控制大局，上级只保留处理例外和非常规事件的决策权和控制权，例行和常规的权力由下分分享。

+   3、要通过改变自己的方式，改变别人。管理里面从来没有“你应该怎么样”，更没有“他应该怎么样”，只有“我应该怎么样”，凡事要反诸己。

+   4、如果现有的可选方案能满足最基本的满意标准，就不要再寻找更优方案。因为大多数情况下，信息是不完备的，人是有限理性的。

+   5、选人时，态度和能力，哪一个更重要？西方主流企业界会建议你：雇佣态度好的人，然后培养他们的能力。对于态度差，能力强的员工，严格限制使用。

+   6、激励因素用多了，员工会感觉“我应得的”。换成一些偶然、不可预测的激励，还有对比产生的幸福感，让员工感觉“太好了”，才能真正被激励到。

+   7、想留住优秀员工，要给员工提供多种“职业生涯”的选择。对压力过大的员工，帮他找到平衡点；对认为能力在别处的员工，允许转岗；对业绩突出、众望所归的员工，给予晋升奖励。内部流动的可能性越大，外部流动的可能性越小。

+   8、那种“大家好好干，我不会亏待大家的”模糊说法，对员工很有激励效果。奖金、晋升等激励方案，一定要和绩效清晰关联。

+   9、成为经理后要要有“打妖怪你去，背黑锅我来”的心态。除了教练之功，所有的功劳，都要推到员工身上；除了法纪之过，所有的过错，都要揽到自己身上。

+   10、管理者也是一个工种。10个人放一起，不经管理，可能只产生3个人的价值。管理者要让他们因为协作产生10甚至15的价值，并因此拿走2~3个人的收益。

+   11、经理收入通常比员工高，是因为他们懂得把目标翻译成任务，把结果翻译成实现结果的过程。没有包工头的分解力，就不会有CEO的领导力。

+   12、一旦成为管理者，你就被插上了“管理之刺”。你和员工之间要保持合适的距离，亲密，但不无间，才是最好的关系。如果达到了对一群人特别好，这群人经常围绕在身旁，就可能只了解了单方面的信息，产生错误判断。

我们是服务行业，同理心很多，比如给客人倒水，杯子最好放回他刚才的位置，因为不知道他是习惯哪只手；如果是女士，要给她吸管喝水，因为怕唇膏沾在杯子上不好；如果客人点菜时间长，说明他有选择方面的障碍，有可能菜单设计指向性不够好，我们要适当给他做介绍，如果他结账时看结账单时间长，一定是他不满意，觉得花钱不值，等等等。

希腊德尔斐神庙门楣上的铭言：人啊，认识你自己吧。正确的认识自己是一件很难的事情。在现实生活中，你认为的自己，别认认为的你，客观的你，这三者经常是不一致的。我们都是按自己认为的那个你来生活。心理学中有一个名词叫：自我预言。是指人会不自觉的按自己的预言来行事，最终令预言发生。鉴于此，我们应该秉承两个原则：一是不要给自己贴标签，这会固化自我；二是以开放的心态面对未来，因为自我认知，实际上是会动态变化的。

最近听每天听本书《巨人的工具》中提到，前美国海豹突击队员杰克·威林克说，真正的自由是自律，你要对自己的世界拥有极端的所有权。他每天早上4点45起床，为自己制定面各种限制、各种固定流程，防止自己意志力有不必要的消耗。之所以每天那么早起，让他有一种优势感。他认为他有一个在暗处的敌人，未来某一天要和它搏斗。假想敌人是他的长期目标，每天严格的要求是自控力训练和减小短期诱惑。
