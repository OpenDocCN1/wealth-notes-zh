# 留言精选

徐1一 51
《高效能人士的七个习惯》乍一看是鸡汤类读物，但仔细琢磨，这本书其实是讲述管理自我的工具书。看完刘润老师的这七个习惯——更应该是优秀者的七个本能的解读。我想，真能练就这“七种武器”的人是凤毛麟角的，能将这里面几个做到超过80%的人就已经很不错了。我的理解是，应该经常反过来思考和提醒自己。那就是低效能人士的七个习惯：消极被动、没有目标、来啥做啥、非赢即输、自我中心、管理贫乏、经验主义。以这种“原则为中心”的态度来养成一种生活和学习方式，才是最重要的。
