# 周末小结 | 《5分钟商学院》的正确使用姿势

《5分钟商学院》的同学们，

大家周末好！

本周，咱俩专栏的订阅人数突破了10万人，再次多谢每一位同学，感谢你们愿意给我一年的时间，允许我陪伴，共同进步，我真真切切地感受到受宠若惊。未来，我必将用最优秀的内容，继续为大家服务。

我也在后台看到了很多新同学的留言，不少人在问，现在加入，怎么追赶进度？怎么学习最高效？

# 攻略1: 先在大脑中建立一个学习体系

建议订阅专栏的同学们，先回到专栏的第一篇文章，“人人都是自己的CEO”，文章末尾有最新课表，建议你把它打印出来，对照着学习查看。

仔细梳理：每天内容是有内在逻辑的

我会先从日常现象入手、破除俗知俗见、为什么这么干不对；然后用一个极具说服力的案例、带出核心逻辑；再举一反三、告诉大家怎么用；最后把所有关键点用一两句话说清楚，帮你把概念存在大脑中最合适的地方。

即学即用：遇到问题，回到当周内容查看

每周的5个概念，是围绕同一个学科进行展开，把这个学科讲深讲透。遇到一个问题，记得回到相关的那周，找到对应的方子和药材，从这里快速拿走解决问题的方案。特别提醒，要学习用关联、整体、动态的方式思考问题，学习把兵器组合使用。

重点领悟：4个体系全面修练

我把全年260期内容分成了4大体系：第一季度讲商业，教你最经典的商业概念；第二季度讲管理，教你最有效的实战管理方法；第三季度讲个人，教你怎样让自己变得更值钱；第四季度讲工具，就是如何借助外力、提升前三者。这其实也涵盖了一个现代人和企业外部、企业内部，和自己沟通交流的几个不同维度，希望大家能够不偏废地全面训练自己。

# 攻略2: 新同学如何追赶进度？

先听当天上新的内容。

每周5个经典概念，每周日～周四晚上22点准时更新。建议先听音频、再看文章、之后结合自身经验回复留言、查看其他同学的精彩留言。学这个专栏时，一定不要错过的是每天的留言部分。不同行业的同学们贡献了很多有价值的思考、分享了很多精彩案例，我也精选优质留言、也会逐条进行回复，相信可以加深你对每天话题的理解。

留出学习时间追赶进度。

每天固定留出一线学习时间，从头听3篇内容，听音频、看文章、看精选留言，追赶进度。日拱一卒、持之以恒。试着养成一个习惯，把你觉得有收获的内容分享给同事、身边朋友，试试在3分钟之内，用你的语言，把你学到的知识讲给别人听，那些你讲不明白的地方，或者别人听不懂的地方，就是你理解的薄弱点。记下来，重新理解后，再复述。老同学们也可以用这个方法复习。

利用客座教授、锻炼CEO视角

每个周六，我都会邀请一位著名公司的CEO或者负责人担任专栏的客座教授，和同学们坦诚分享自己对行业未来趋势的判断、对过往决策的复盘，目前已经邀请了30多位商业大咖，满满干货，建议新同学们有时间好好看看这部分内容。

# 攻略3: 每部分怎么学更高效？

4个体系的内容，学习方法其实有很多区别。

商业篇的内容，在英文中叫做Business knowledge，学习方法主要靠记忆。这个东西我以前不知道，现在知道了，记住就行了。

管理篇的内容，在英文中被称为management skill，它是一种技能，没有办法仅通过记忆学会，必须通过在日常工作中练习才能习得。这就好比，你光知道抛球的4个步骤还不够，必须通过练习才能抛好球。

而个人篇，更多是态度Attitude层面，它的学习方法主要是感悟，在人生经历中间被点醒、被触动，它更加难学，是用心来学习的。我会在文章中告诉大家how（如何实现），怎么能够做到积极主动、怎么能训练自己做到以终为始，希望能够帮助大家把这些态度层面的东西变成习惯。

但学会一个知识可能需要4天时间，习得一项技能可能要4个月，改变一个态度却可能需要4年、40年，确实不容易。咱们一起努力。

除了要学习知识、技能、态度，我们还要向他人学习、在实践中学习。所以，在日常的课程之外，我还特别为大家准备了一年8场的线下课学习机会。每个季度结束，我会利用线下课对这个季度的内容进行一个总结提炼，理出逻辑主线，同时加入很多案例分析，升级拓展出更多内容，帮你强化巩固这部分的知识体系，以备你随时调用。

而且，来自全国各地的精英同学也会齐聚一堂，面对面地分享交流自己的实践经验和学习心得，也会因此结成更紧密的学习和分享小组，大家一起更快成长。
