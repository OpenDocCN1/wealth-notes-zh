# 你的人生有四分之三是霉运

+   第一，就是大吉大利、一帆风顺、水涨船高，我们称之为：吉。

+   第二，大凶大恶，运气很坏，称之为：凶。

+   第三，事情的发展有忧虑、烦恼，称之为：悔。
