# 标题视觉化钩子

尽管有创意很好玩，但是不一定总有效。可能往往越是好玩的东西，越不容易成功。有创意的文案尤其如此，文案可能过于新潮，读者甚至看不到在卖什么。

在涉及到图形以及视觉效果，更容易出现这样的问题。

我真诚地建议，图形应该用来强调一些关键点以及关键看法，让它们变得要点清晰，格式漂亮，能吸引顾客眼球。图形设计的基础或垫脚石应由无填充颜色的空格，颜色，线条，纹理和形状的使用构成。

# 文案撰稿人的引物设计

几个简单的设计理念能够对你的标题，以及销售起到巨大的作用，有助于极大地提高潜在客户转化率。

设计一个能在视觉上产生跳跃感的标题。

+   把标题设计成大字号的黑体字，让所有人都能够一眼看到。设计一个不和谐的对比。让标题给人产生视觉冲击……就像减速带一样，让人不可能忽视。

+   用照片或卡通画强化标题，为标题增加视觉趣味，从而增强标题对正文的支持。把你的标题和戏剧性的视觉效果相结合，从而让潜在客户更容易想象和理解你的产品好处。

+   让你的标题成为文案中最直观，最显眼的元素。标题的外观或设计往往应该是文案中最醒目的。把你的标题看作是一个醒目，大胆的介绍，明确、简洁地吸引读者的注意力，并引导其继续阅读。

+   有效的利用你的空间。对于小空间广告，一个醒目的标题应该占据大部分空间。让引人注目的标题在你的广告，或营销资料中占据比较大的空间。让其明显到无法被人忽视。

+   把你的标题放在一个插图框、标题栏或气球等图形中。这些图形能抓住人的眼球，很有可能能够引发人们的极大兴趣。这种方法能给任何标题一个吸引顾客眼球的机会。
