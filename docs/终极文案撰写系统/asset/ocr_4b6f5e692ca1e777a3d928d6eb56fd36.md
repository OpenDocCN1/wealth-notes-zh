# 步骤#15：总结组合

完成上面的销售流程，就到这一步了。

你一定要按顺序学习，因为它们是相互支撑的……能够从逻辑上，以及情感上引导你如何把自己的基本提议呈现给读者。

在这一步，你已基本完成心态上的准备，准备好说服潜在客户 的工具，并且深刻地理解，为潜在客户呈现你的产品或服务细节所需要的东西。

我会总结我们在以上所有课程中 学到的内容，可以强化你的记忆，你能够学习得更快，而且理解的更深刻。能够迅速激发灵感，产生头脑风暴，从而找到为你 自己撰写文案最有效的表达方式。

不要担心—这些都 在 CD 上以简洁的方式为你做了解释。

有些营销人，一提到“销售”就恐惧——因为他们很困惑，觉得自己永远 也无法掌握这门艺术——你将学习到的是……让顾客极度渴望购买的秘诀。简单，且易操作。而且，使用效果非常好。

你要清楚，你想要进行什么样的营销活动？想采用那种传播媒介？

比如：你想直接投放广告，还是联盟合营；是一步销售，还是通过引导式，采用多步销售。你是采用电子邮件，还是宣传单，广播，搜索引擎营销，微信……等等。

不同的方式所撰写的内容和组合的结构会有不同；

你要了解你的销售系统，清楚各个销售方法的局限性以及要求（视频下载 时间，垃圾邮件过滤，广告的俳句规范，模糊搜索引擎错误）。清楚你的潜在 客户对时间，长度以及态度的期望……成本及规则……

大胆的去组合，修正，测试使用吧！
