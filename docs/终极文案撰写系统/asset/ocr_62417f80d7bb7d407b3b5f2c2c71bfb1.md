# 步骤#9：编故事

用你自己的语言，创作你的故事。经验丰富的营销人，尤其是线上营销人员——称之为“价值百万美元的一步”。

为什么？

因为……如果你之前没有注意到，你现在一定知道……大多数高端的成功企业家，在自己写的所有东西里，都有一个可辨认的“声音”。

它是态度，个性……以及信誉的组合。

所有一切融合成了经典的销售术。

结果：你在你的利基市场上占据了更好的位置，成为了“能够为人们排忧解难的人” …因为人们对你的内容更感兴趣，更相信你，更充满激情，你提供的资源将是他们所希望的，也是最精彩的。

市场上充斥着许许多多各式各样的内容。

大部分都被忽视了。

一旦你为你独特的声音中注入生命的活力，你将能引起所有目标受众的兴趣（甚至是信任。）
