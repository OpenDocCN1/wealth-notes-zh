# # 步骤#3：市场调研

记住，每一步骤都是建立在前一个步骤基础上的。这个步骤，市场调研，是以下所有步骤的基础。

不要让“调研”两个字吓到你。十几年来，我一直在帮助人们克服他们对深入调研市场那种与生俱来的恐惧。

一旦你拥有了下面的指导，调研将变得简单直接。

大多数营销人员都忽略了这一步，结果，对接下来所做的一切工作结果都产生了致命的影响。在我刚开始从事这行早期，我就意识到，花一点点时间来调查市场“背后的故事”，就像拥有了一个秘密武器。

你将比其他任何人对发生的事情都会有更好的了解——包括市场以及你的潜在客户的生活。

在这一部分，我将揭示把这些精湛的技巧运用到你的“电梯聊天”中有多么简单……这样一来，你就可以和任何人快速、高效地交流。告诉他们你提供的是什么产品，为什么他们应该了解你的产品。

你所做的所有其他增加销量的方法都要从这一步开始。

再说一遍，市场调研很简单。只是大多数营销人员不知道应该调研什么，不知道从哪里调研。

在听了这一部分的CD后，你将掌握能够在你做的任何事上帮你，从而获得利润的先进知识。

完成练习至关重要，因此，这不仅仅是要灌输在你脑海里一些“理论”。相反，循序渐进地学习，仔细思考你学到的东西，思考你在有关你的市场的“问问题，找答案”中的发现，你很快就会非常擅长做市场调研。
