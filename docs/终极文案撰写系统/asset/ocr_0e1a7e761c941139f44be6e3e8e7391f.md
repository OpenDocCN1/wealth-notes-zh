# # 步骤#2：营销心态

这是我最喜欢的 “文案撰写” 准备步骤。

如果你手里有你的潜在客户需要或应该拥有的产品，那么你应该想尽一切办法，让人们看到你的销售信并接受它，因为你能让他们的生活更好。

有好的产品，但是要知道好的产品不会自己销售自己，营销墓地堆积着很多优秀的产品，因为没人知道怎么销售它们。

每当我把杀手级销售术语的一些基础知识 “灌输” 给销售人员时 (无论是菜鸟，还是郁郁不得志的老手) ……他们的眼睛都会闪闪发光。

和其他能力相比，要想赚钱……学习并成为你需要成为的人，来说服潜在客户购买的能力……能够为你做其他事情，铺平道路。

很多营销人销售东西，都拖泥带水，效果也不好。

在我整个事业生涯，已经让很多人都改变了态度，塑造了正确的心态。

开始，可能会让你感到惊讶，但是它确实非常有威力。

然而，一旦你明白了其中的奥妙……你将永远摆脱无力的销售说辞。

它将发挥真正的作用。
