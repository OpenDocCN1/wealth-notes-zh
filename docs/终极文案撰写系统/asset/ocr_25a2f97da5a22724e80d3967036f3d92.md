# 步骤#4: 制定 USP

几乎任何读过关于市场营销书籍的人，都会碰到有关 USP 的理论。

就像我在 CD 里说明的，我很快发现对 USP 的“传统”定义对一般企业家或小公司所有者并没有多大作用，因为他们只是想在自己的市场上找到有利位置，然后赚一大笔钱。

因此，我十几年来一直在研究 USP，并在真实的世界中进行测试。

然而，我使用的 USP 和“传统的”USP 是截然不同的。当你试图弄明白你在市场中的位置时，用我的 USP 理论，它非常容易操作。

不明白自己在市场中的位置就去做市场营销，相当于在黑夜中盲目前行。

然而，一旦你完成了这个练习……“你在利基市场”中的位置之迷将被揭开……

你就可以确定自己所属的位置……

……或者去重新定位，找到利润更高，更有趣的利基市场。

它将你远离所谓的专业理论……把真实有效的营销方法运用到你的营销中。
