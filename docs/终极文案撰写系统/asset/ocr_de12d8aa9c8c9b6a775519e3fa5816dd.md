# NOTES

顾客恐惧的8种表现形式：

+   1.  害怕买贵了
    2.  害怕让人笑话
    3.  害怕买到次品
    4.  害怕买到的不是最好的
    5.  害怕买了个用不着
    6.  害怕产品并不像他们说的那么好
    7.  害怕没有保证(售后)
    8.  害怕无法获得退款 (如果买错了怎么办)

顾客成交的21条文案要点：

+   1.  强调激化自己
    2.  永远遵守AIDA法则(注意力、兴趣、欲望、行动)
    3.  测试标题
    4.  确定产品的UPS
    5.  描述产品对顾客的好处、价值
    6.  减字
    7.  文案内容要详尽,包含所有要点
    8.  引起共鸣、呐喊
    9.  陈述产品最大好处
    10. 小标题引起顾客要问的问题
