# 步骤#4: 你的 USP

# 练习:

用我在 CD 中讲的方法做以下练习。用 5-10 分钟时间，撰写你的 usp。

你的 USP:

定位自己，让你在利基市场中脱颖而出，从而达到销售目的。

+   - 销售调查（人们购买的真正原因）……

+   - 枯燥vs. 迷人

+   - 并非全部都关于你……

+   - 不是说你在卖 “什么”……

+   - 而是你卖的 “东西” 能给你的客户带来什么。

+   - 要提供 “令人高兴的东西”: 更快、更简单、更轻松、价格便宜、物超所值、内部资讯、特权、奢华、吹嘘的权利。

+   □ 记住: 你需要立即向多疑的读者证明一切。

+   □ 考虑使用不是很深奥的词汇。

+   □ 不要弄得太深奥，用具体的事实来解决问题。不要担心要怎么样才能 “讨好” 人，只要把事情尽量说明白。

+   □ 新手公式: “我们帮助 (这类人) …获得了这些 (好处) …变的更好。”

+   □ 定位关注: “…比 (竞争对手或普通人) 更好。”
