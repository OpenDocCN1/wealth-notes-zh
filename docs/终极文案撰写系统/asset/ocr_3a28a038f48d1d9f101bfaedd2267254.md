# # 35 种促使顾客行动的文案

销售信的目标是让客户行动起来，所以尽量使你的广告文案看起来简单、无风险，以促使人们采取下一步行动。

# ## 不要畏缩不前！

我看到很多销售信只是给客户列出了电话号码，认为如果人们感兴趣的话会打电话。错了！你应当牵着人们的手并让他们拿起电话…现在就下订单…无论你是否愿意。

做个有力的结尾，如下面的例子：

+   1. 赶快回信订阅吧，然后自己判断下，和这个免税的少量费用相比，这个（书名）是不是物超所值呢？
2、免费提供！
3、要订购吗？请把你的折扣卷邮寄过来，非常感谢！
4、今天的投资将会给你带来超额的回报，使用这些技术所为你带来的利润可以为你创造成千上万，甚至几十万的美元，以至于更多。这取决于你，今天就订购吧！
5、很明显，在我公司承担一切风险的情况下，我在“无情的”的试图吸引你来参加我们的课程，我不是为了白自赚你`$$$$`，恰恰相反，因为我知道没有我们独特的点子，有效的方法和法则，你们当中的很多人（包括你），都不可能让企业（或办事处）最大限度地利用和发挥潜在的利润和成长空间，获取到最大的利润。
6、核实一下。我把一期的刊物作为免费礼品送给你，以便你认识它并试用一设没有任何附加条件。我敢肯定你肯定会感到非常满意。如果我说对了，你等下就可以订阅，当然我们不会强迫你。不管怎样，不必现在做决定。等你收到免费的期刊再说吧！
7、我希望你现在就行动。在封底内页填空，再把它放到贴好邮票的信封里，欢迎回寄到《团队的名称》。
