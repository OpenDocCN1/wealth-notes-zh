# # 步骤#12：促使行动

在销售文案中，最常见的错误之一就是忽略了去提醒消费者下订单。很多企业费尽心思为其产品编造精彩的故事……去勾起消费者最初始的欲望……觉得这样就可以了，他们永远都不尝试去达成交易，这让人感到很惊讶。

你可以“忽悠”潜在客户，让他对你的提议非常渴望，特别想了解更多信息，更多细节，更多例子……你提供的所有东西。

但是，如果你无法“达成”交易……你只能得到这么多。一个充满渴望的，积极的潜在客户。不购买你的产品的潜在客户。

生意上的成功是基于创造客户的。好的销售策略，只能让人们想购买。但是，优秀的销售策略，能让顾客理性以及感性方面都产生变化……唯一想做的决定就是购买。

好广告的重点就是达成交易。你开公司是为了做生意，而不是为了占用办公场所。你在公司里是为了赚大钱的。

销售的艺术就是达成交易的艺术。让顾客下订单，汇款给你。在一天的工作结束时清点现金。其他一切都是这个结果的前奏。

当我撰写销售文案时，通常会使用4个基本“工具”来促使行动。

然而，这4个“工具”是我发现的最强大的手段，能够激发潜在客户内心深处，无限的欲望……并且，能够彻底打动他的心……让他不做人购买决定，就无法入眠。

整个广告活动（像线上使用的非常成功的“销售”流程）几乎完全依赖于这个呼吁。没有这一步，你的广告带来的销售额就会大大降低。然而，如何实施这一步，也是一门艺术。

本节的练习，将会成为你私人“策略包”中最有效的销售工具之一。
