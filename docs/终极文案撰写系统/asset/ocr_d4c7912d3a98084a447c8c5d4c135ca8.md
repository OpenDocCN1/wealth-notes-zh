# 请先阅读以下内容……

亲爱的朋友：

这个系统是我精心设计的，能够被你的大脑以特别的方式“吸收”。

你可以按照自己的节奏学习。可以快速学习。也可以慢慢学习。

这就是CD和手册的魅力所在：你可以不断回放，不断复习，直到你满意为止……如果需要，你也可以重读。

如果你能够按照自己的节奏学习它，我相信你也一定会很喜欢。

在开始之前你应该注意以下几点：

+   1. 每个部分都是建立在前一部分的基础上的。所以，我建议你先聆听CD上的介绍。时间不长，它将帮助你，它将有助于你对后面内容的理解和吸收。

+   2. 然后，开始听第一张CD（名字为“写作思维”），用心聆听整部分吧。如果需要，可以记笔记-手册中有几页空白页，你可以在上面记笔记。（也可以帮你记录“学习进度”。）

+   3. 手册中有我使用的所有ppt……因此，你不用每一张ppt都做笔记。你只要集中精力听我讲的就可以了。即使在你不听CD的时候，如果你需要，你还可以在手册中学习。

+   4. 在这个手册中，你可以查看到不同类型的广告样板。因此，你会更加了解某个广告的背景，明白我为什么选择了该广告，以及该广告是如何“大展身手”，带来成功的销售的。

+   5. 在听完“写作思维”这部后，你可以暂停，然后开始做练习。

+   6. 没有时间限制，你可以在任何时间完成这个练习。

+   7. 练习对加深你对这个清单的印象起关键作用。它能够帮助你理解如何完成每一点。（学习做什么是一方面，从书本以及演讲中都能学到。但是，要想真正记住它，你需要拿起纸笔……写下来。）
