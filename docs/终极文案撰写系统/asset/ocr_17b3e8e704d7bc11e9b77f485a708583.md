# 这都不重要

因为，想要拥有勇猛卓越的格斗能力，只需几个简单且容易掌握的秘诀即可。尤其是徒手套斗，以及持刀或持棍格斗。

当我说这些话的时候，大多数人都不相信。所以我会向他们证明。

也会向你证明。只要一分钟后。

情况是这样的：那些在菲利克斯背后嘲笑他的女孩儿是脱衣舞女……她们在洛杉矶最出名的黑帮飞车队脱衣舞俱乐部工作。好吧，不是最出名……而是最危险。洛杉矶最危险的俱乐部。

你的俱乐部里同时聚集了无赖的黑帮飞车队的人和陪酒脱衣舞女，
你有麻烦了！

菲利克斯走了进去，他想找一份保镳的工作。大家都当着他的面笑了。那些脱衣舞女还在背后打赌，每人压20美元，赌他能坚持多久。以前这里的那个保镳体型是他的两倍，是一个训练有素的拳击手……那个可怜的人第一次工作一小时后，就躲在人行道上，哭的像个小孩。

俱乐部里3个最健壮、最邪恶，疯子似的黑帮飞车队员决定好好整治一下菲利克斯，手段要比上个保镳更毒辣。他们希望他受伤，并立即离开这个俱乐部。因为这个矮小的人竟然觉得能够做这里的保镳，这让他们感到自己受到了羞辱。

这里最瘦小的黑帮飞车队员也有200英镑，拥有结实的肌肉。那三个人都手持博伊刀（猎刀的一种），并且准备用它攻击菲利克斯。

他们喜欢看到别人痛苦。

接下来发生的一切，成了洛杉矶的神话。贝弗利希尔斯(美国加利福尼亚州西南部城市)的人都听到了这个故事。矮小的菲利克斯，看起来就像是一个小孩子盯着3个愤怒的公牛似的，只用47秒就结束了“格斗”。
