# # 步骤#7：标题

说到标题， 很多老师都会“滔滔不绝”……但是真正的技巧一定要经过实践的检验……并且由专家进行测试。

我们在本节中将讨论如何有效地拆分，改写，以及撰写标题。

这不是理论。这是已经证明有效的核心策略，来帮助你弄清楚要写什么以及如何写。里面收集了很多已经证明有效的标题。

标题在提升销量中起着至关重要的作用。它们形式多样，如邮件中的主题，视频的名称，面对面销售时的开场白。

然而，人们在如何撰写一个好的（更不用说优秀的）标题上，都有误解，这真是罪恶。

在这里，你将对标题中需要写什么，有一个深层次的理解。

只要了解这一个内部知识，就可以让你撰写任何东西都变得简单得多。

再多花一点时间真正强迫自己不断练习，将会让你撰写标题更得心应手，从而撰写出人们都想阅读，真正的杀手级标题…….让你的潜在客户在阅读完标题后，热血沸腾。
