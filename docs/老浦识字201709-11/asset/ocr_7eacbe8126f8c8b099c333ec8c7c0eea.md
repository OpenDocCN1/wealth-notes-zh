中国也叫中华，中华族，中华人民共和国。

“中”字我们已经了解了，古人生活在黄河流域中原地区，他们认为这是天下的中心，由这个中心地区向外扩展，所以叫中国，中华。那“华”是怎么回事？

# **1. 华的原意是树上开的花**

我们在【花】那一期也已经了解，华的甲骨文是一棵树开满花的样子，原意是树木开的花。

金文对甲骨文进行了规整。
篆文仍然是树上开花的造型。
有的篆文加上了草字头，成为繁体“華”的原型。

“華”字在隶书阶段分化出“化”字。

由于华的原意是木本植物的花，所以引申为光彩、光辉、华丽、豪华，在文章中形容漂亮花朵，花草。古人也用来形容花白头发的“多情感英歌，早生华发。”这是苏东坡的名句。

# **2. 中国为什么叫中华**

距今大约一万到七千年前，在今天的陕西、甘肃地区，生活着一些母系氏族的族群，其中有以农业为生的华族和以采集狩猎为生的宵族，两个氏族的青年男女在清水河边弹歌取乐，戏水欢聚，互相通婚，生的孩子由母亲的氏族抚养。两个氏族后来合并为华宵氏，华宵氏的氏族首领相传踩了雷兽的脚印，生下了中国的人文始祖伏羲和女娲。于是这位华宵氏就成为中华民族的“始祖母”，后来的神农、黄帝都是这一繁衍的。

于是，这个民族就称为中华民族。

![](bbox=[0.1, 0.00103, 0.9, 0.00115])

华宵氏为什么用“华”作氏族的名称呢？有人说是因为华宵族在华山（hua）山脚下。其实了解“华”字的原意就很容易理解，华族是木本植物的花朵，指明这个氏族的生活方式由狩猎采集过为农业种植，是中国农业社会的开端，唯一断更微信：699250

相传华宵氏埋葬在今陕西省西安市蓝田县焦塬镇老坳村，附近有半坡遗址和一段热播电视剧《白鹿原》的故事发生地，有兴趣可以去怀古探幽。

![](bbox=[0.1, 0.00131, 0.9, 0.0014299999999999998])

华还应引申为丝绸服装，即华服。

由于率先进入农业社会，并且相传黄帝的妻子嫘祖发明了丝绸纺织，文明程度明显高于周边蛮夷，所以称为华夏。华是看华服，夏是大人，意思是强大的文明部族。

华宵、华夏、中华，就是这么沿革下来的。

# **3. 华表的来历**

说到中华，我们总是会想到天安门前的华表，觉得华表和天安门前一起，是祖国的象征。

![](bbox=[0.2, 0.00165, 0.8, 0.0017800000000000001])

华表古叫诽谤术，是上古君王尧设立的“意见箱”，在一个木头柱子上横杆一块木牌，树立在交通要道上，征集群众意见，古代帝王在宫殿前建立这样的柱子，表明自己纳谏。

诽谤原来是个褒义词，古代大臣上奏折说希望君王“开诽谤之路，纳忠谠之言”。“意是接受不同意见。后来词性演变，称为不实之词。

天安门前后各有一对汉白玉华表。华表顶上蹲着的动物叫石吼（hòu），是神话传说中专登高山望远的北方食人之兽。下面横插玉板，柱身雕刻云纹。华表与天安门同建于明永乐年间，迄今已有500多年历史。

# #### 总结一下

+   1. 华的原意是木本植物的花朵，引申为光彩、豪华；
2. 之所以叫中华，是因为中华民族的始祖华宵氏民族叫华姓，诞下伏羲和女娲，使中华民族延续至今；
3. 华夏之华是丝绸华服，象征文明；
4. 华表是尧设诽谤术征集群众意见沿革下来的。
