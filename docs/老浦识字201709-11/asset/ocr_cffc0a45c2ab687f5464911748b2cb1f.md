# 识字卡片

汉字从甲骨文出现现在已经有三千多年历史了，字的含义会发生变化是很自然的，有些字虽然变化不大，但很有趣。

# 1.睡的原意

比如“睡”字，篆文 [睡] 是目字旁 [目] ，表示人的眼睛。右边是下垂的“垂” [垂] 。垂的甲骨文 [垂1] 是树枝挂着果子因而下垂的状态，“目”和“垂”合起来，表示眼皮下垂，在打瞌睡。

# 2.最有名的打瞌睡

史书记载最有名的打瞌睡是秦孝公，当时的卫鞅，也就是后来的商鞅通过关系来觐见秦孝公，谈他的治国方略。

插一个小知识，卫鞅不姓卫，而是姓公孙，鞅是他姓，意思是卫国人，人们就都叫他卫鞅，因为他的脸。后来他在秦国立了功，秦孝公把於、商十五县封赏给了他，所以“号为商君。”后世也称他为商鞅了。

《史记.商君列传》记载：

孝公既见卫鞅，语事良久，孝公时时睡，弗听。

说谈了很久，孝公直打瞌睡，听不进卫鞅的长篇大论。这是卫鞅第一次觐见秦孝公的情形。

这次见面很失败，秦孝公理应推荐宠臣景监，景监又去埋怨卫鞅，卫鞅说那就再谈一次，还是不对路。第3次去谈，孝公觉得有点意思，就又给了卫鞅一次机会。这次：

卫鞅复见孝公。公与语，不自知矇（xī）之前于席也。语数日不厌。

谈得非常投机，秦孝公不仅没有打瞌睡，而且听的竟然不知不觉身体往前凑近，跪坐的膝盖都出了席子，一连谈了好几天。

为什么会有这么大的差别？原因是卫鞅以前谈的都是马上传见效的“霸道”，而后来谈的都是马上能够见效的“霸道”，所有的当政者都希望在自己任上建功立业，百年以后的事就顾不上了。这样的执政思路，从商鞅变法就一直延续下来了。

睡字打瞌睡的含义一直沿用到宋代，欧阳修的《秋声赋》就有：

童子莫对，垂头而睡。但闻四壁虫声唧唧，如助予之叹息。

这是欧阳老夫子在听到窗外秋天的风声，发了一通感慨啊，而小书童已经低着头在打瞌睡了，只有秋天特有的蛐蛐的鸣叫，让秋夜的感慨更加寂寥。

现代汉语睡眠、睡觉就不仅仅是打瞌睡了，那“代”字里面的意思用什么字呢？用“寐”，在古书里面躺在床上睡觉。梦寐以求、夙兴（xīng）夜寐（起早晚睡）、夜不能寐、都是用的古文。

# 总结一下

+   1. 睡的原意是打瞌睡，和今天的字义有区别；
2. 秦孝公听卫鞅的百年大计打瞌睡，听马上见效的霸道却兴致勃勃，说明急功近利是古今通病；
3. 古代表示睡觉的字是“寐”。
