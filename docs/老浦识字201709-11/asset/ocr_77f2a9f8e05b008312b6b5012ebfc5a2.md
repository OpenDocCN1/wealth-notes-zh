# 170【问答】牵着大象的鼻子是什么字

欢迎来到《老派学字》，今天是本周的问答时间，我来为你解答一下本周的思考题。

跪坐是古人日常的坐姿，有个甲骨文“䇂”像主干“丌”、“𠫓”围着食物“”相对而坐，彬彬有礼地一同进餐。请你猜猜，这是什么字？

**老浦**

答“饎”和“乡”都对，原意就是相向而食，后来分化出“公饎”的“饎”和“乡亲”的“乡”。

（㧐）解牛生剔解效

简化字方便了书写，但容易造成理解上的歧义。请你分析一下，斗室、斗士、星斗、奋斗都繁体字来写，应该怎样写。

**老浦**

斗(dǒu)室，表示像斗那么小的屋子；门(dòu)士，门的原意是两人打架，门士是战士，应该用“鬥”；星斗(dǒu)，是指北斗星，是星之指所有星座；奋斗(dòu)，是奋斗努力，应该用“鬥”。

（松）松树为什么会松呢

![](bbox=[0.05, 0.77, 0.9, 0.9])

古今字义不同的字还有很多，比如鸡汤的“汤”；金文“𦈘”左边是“水”“氵”，字旁，右边是一个“𠬰”字，“𠬰”是“阳”的本字，现在请你分析一下，“汤”的原意。

提示一下，成语“扬汤止沸”、“赴汤蹈火”都是“汤”字的原意。

**老浦**

汤的原意是温泉，后指热水，汤汤、赴汤蹈火都是热水的含义。现在有些地方名还用的古文原意，比如北京的“小汤山”，就是指这里的温泉。

（鼽）打鼾是哪种鼾

![](bbox=[0.05, 0.00107, 0.9, 0.0012])

有个字本意也是面部器官“𩢝”，请你猜猜看这是什么字？

**老浦**

是耳而且的“而”，是面颊上的毛，也就是大胡子。准确地说，是下巴上的毛。

而，下巴上的毛；頣，颔下之毛；𩳏，嘴周围的毛；髭(zī)，上嘴唇上面的毛。
