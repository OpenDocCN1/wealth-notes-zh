# 132 [问答] 东床快婿怎么来的

欢迎来到老谭识字，今天我来解答一下本期考题。

打击乐器我们学习了鼓，现在有一个字形，也用作打击乐器，你猜猜看，这是个什么字？提示一下，张艺谋曾经用它很出风头，也很很。

老谰
这是缶，瓦器，用来盛酒，民间老百姓的兴起，也用来敲击高歌。是一种粗黑的乐器。

2008年奥运会开幕式，张艺谋设计了规模宏大的击缶舞，可惜第一，这样的瓦器原本是不登大雅之堂的，蔺相如曾经以命相抵，逼迫秦王击缶，用以羞辱秦国。击缶实在算不上中国文化的情价。

第二，张艺术用的所请缶的原型是湖北曾侯乙墓出土的青铜乐器，缶，缶有夹层，夹层里面放水，缶里面放食物饮料，这就是古代的冷藏设缶，并不是乐器，也不能敲击，所以我说张艺谋用缶击出风头，其实也是出槊，要是他听过《老谭识字》就好了。

咱们这次谈东字，东道主里引申出主人的含义，房东、股东等等。古代还有“东床”这个词，你能说说这是什么意思，并且说说他的来历吗？

老谰
东床指女婿，典故来自《世新说雅量》：

> 郗（郗鉴）太傅在京口（今江苏镇江市），遣门生与王（王导）丞相求女婿。丞相语郗信：“君往东阿，任意选之。”门生归，郗曰：“王家诸郎，亦皆可嘉，闻来觅婿，咸自珍饰，唯有一郎在东床上，坦腹卧，如不闻。”郗公云：“正此好！”访之，乃是逸少（王羲之），因嫁女而焉。

后称人婿为“令坦”或“东床”，此比。
坦腹是典型的魏晋风度，自然、坦荡、孤高自许、不顾顾蜉蜉。

你看这个字，是一只鸟，被一只手抓住了，猜猜看，这是什么字？

老谰
这是“只”，原意是抓住了一只鸟儿，表示单独一个。繁体字“隻”还可以看出原意，简化学就看不出来了。
顺便说一下，抓住一只鸟是“只”，抓住两只鸟呢？也是一个字，这是“双”，繁体“雙”。

手持物品可以组成很多汉字。这个字形是手持“肉”，你猜猜，这是什么字？

老谰
这是无的有，古代肉食是很珍贵的，手持一块肉，那就很容易啊，有了。所以有的原意是持有。

和鸟有关的汉字非常优美，你看这个字，鸟儿仿佛正在展翅飞翔。你猜猜，这是什么字？

老谰
这是燕子的燕，突出了长尾巴和剪刀形的尾羽，是不是很优美传神。
