# 识字卡片

![](bbox=[0.05, 0.08, 0.95, 0.28])

有用户问，为什么咱们《老谭识字》的文稿中“一隻憂鬱的台灣鳥”用“台”而不是“臺”，原因是这样的：台湾的“台”作为“臺”的异体字可以通用，我们现在使用的“台”也是一个古字，汉字简化方案把亭臺的“臺”、台階的“儃”和颱風的“颱”合并成了“台”。

在古代，“台”和“臺”是两个完全不同字的。

# 高高的臺

先说“臺”，篆文 是“高” 的简省下面一个“屋”，屋是矮房子，下面一个“至”，“至” 甲骨文原意是一个箭头 倒立于一横上面，表示到达。“屋”俺懂下一个至，表示到达目的地睡觉休息的帐篷，后指提供休息的房子。

“高”加上“屋”，表示可以住人的高大建筑，也就是有人驻守的高大瞭望建筑。

《说文解字》：臺，观堂的高台。是高耸出地面的四方高大建筑。

臺的本意是高大的建筑物，亭臺楼阁就是这个“臺”。

![](bbox=[0.05, 0.65, 0.95, 0.73])

《江南春》杜牧

千里莺啼绿映红，水村山郭酒旗风。

南朝四百八十寺，多少楼台烟雨中。

杜牧的这首《江南春》是典型的诗中有画，红花绿树映着江南山村的酒旗，鸟儿在林间鸣叫，而江南的佛寺楼臺，都在一片烟雨蒙蒙的雾气之中若隐若现。生活在江南，经历过楼臺的同道对此情景一定很亲切。这里的“楼臺”，就应该是“臺”。

公共场所一些高出地面的建筑也就称“臺”，如臺、舞臺等。

后来一些做毯子用的器物也称为“臺”，如灯臺、锅臺、畳臺、窗臺等。

# 臺和当官的挂上了关系

由于臺是高大的建筑物，有些官署也就以臺来命名，汉代有御史臺、兰臺，御史臺也是中央监察机构，兰臺是中央档案典籍库。

由于臺是官署名，对人的尊称也称臺：

+   - 古代下属称呼上级为“宪臺”、“臺察”；
- 朋友间尊称为“兄臺”、“臺下”；
- 而“臺臣”、“臺官”就成为谏官、御史的别称。

# 又造了一个樓

汉字进一步细分，一些桌子类器物，就另造带木字旁的樓，如写字樓、梳妆樓，那首诗“琵琶本无树，明镜亦非樓。”指的就是梳妆樓。

台的原意是胎，也是住宿名

台，金文 上面有个“人” ，是倒写的“孳”，表示母亲所怀的孩子。下面一个“口”形，表示母亲的胞胎。

台，在古代是星宿的名字，三台是一组星星的名称，古人认为对应着人间三公。

周朝时候，“三公”是指：太师、太傅以及太保，是朝廷地位最高的官职。所以“台辅”就是代官尊称，一般“台”是对方来信的尊称，比如你可以写“台翰敬悉，不胜荣幸。”

# 又造造了一个颱

汉字进一步细分，用“台”，加上“風”新造“颱”台，特指海洋热带风暴。

# 总结

+   1. 臺的字形是有人值守的高大建筑，原意是瞭望台。

2. 有些公共建筑高出地面也称臺，如讲臺、舞臺；有些坐的器物也称臺，如灯臺、窗臺。

3. 汉字细分，把与桌子有关的器物新造字“樓”，如写字樓、梳妆樓、欄樓。

4. 有些官署也称臺，汉代有御史臺、兰臺。

由于官署名，所以对上级的尊称为臺，如宪臺，朋友台兄臺。

5. 台的原意是“胎”，是母親中的婴儿，天上的一组星星称为三台，对应人间的三公。由于三公是朝廷最大的官职，所以后世也尊称宰相为台辅，对方的来信尊称台翰。

6. 用“台”，加上“風”，新造“颱”台，特指热带风暴。
