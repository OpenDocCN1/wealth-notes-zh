# 190【怜】“怜”字居然与“鬼”有关

我写稿的这天，是西方的万圣节，各种装神弄鬼。有些家长挺担心，怕这种洋鬼子文化带坏了孩子的心理。其实咱咱们中国古代也有很多鬼的形象，比如“钟馗捉鬼”，钟馗本身就是鬼的代表。

我请教了心理学家半金仪老师，她告诉我：所有这些闹鬼的风俗，都反映了人类对死亡的恐惧，怕鬼，就扮成鬼，和鬼混了一夜的话，不就化解了对鬼、对死亡的恐惧了吗？

# 怜就是“见鬼”的心情

这个节日让我想到了一个汉字，可怜的“怜”，这个字和鬼还真有密切关系。

怜的会文** [image: ancient character] **，上面是“焞”，下面是“心”，表示这是一种心情。

《说文解字》说：怜，哀也。从心。焞声。

意思是说怜是哀伤的心情，焞是声符。

“焞”应该是声符加上意符。

我们来看看“焞”的会文** [image: ancient character] **，上面是由两个“火”构成的“炎”** [image: ancient character] **，表示很像火一样的亮点，下面是一双脚步** [image: ancient character] **，表示行走。像火一样的小点可以自己行走，这是什么东西？

在农村生活过的同学一定见过，这是磷火，也就是鬼火。晚上路过坟地，这种人和动物的尸体腐烂时分解出的磷化氢可以自燃。蓝绿色的火焰星星点点，十分吓人。

“焞”的本意就是磷火，鬼火，古人看到这样的火点，想起逝去的亲人，心中很是怜惜，这就是加上“心”字后成“怜”的本意。是不是和鬼有关？

# “秦人不怜”的故事

《战国策·秦策一》中有一句话：“商君归还，惠王车裂之，而秦人不怜。”

意思是说支持商鞅变法的秦孝公死后，惠王继位，很多人劝说惠王说：‘现在国内妇女孩、儿童都说商君的法令成王，而不说是大王的法令。这样，商君成了主人，而大王反变为大臣了。’就是劝说惠王。

商君害怕诛杀，想返回魏国。秦人不许他出境，走投无路，只好返回。惠王以车裂的极刑处死了商鞅，而秦国人并不表示同情。

一个变法功臣，将秦国治理的“道不拾遗，民不妄取，兵革大强，诸侯畏惧。”却遭到这样悲惨的结局，为什么“秦人不怜”呢？

《战国策》的回答是：“刻深寡恩，怼，恃以强毅之耳。”意思是：过于强势，寡恩，没朋友，没有民心。

# “怜”引申为爱

怜由怜哀引申为怜爱，可爱。在古文中，爱的含义有的则多一些。《战国策·触龙说赵太后》中赵太后问：“丈夫亦爱怜其少子乎？”说男人也爱怜小儿子吗？这里的爱怜，不能理解为喜爱并怜惜，而是 珍惜爱护的意思。

在唐诗宋词中，“可怜”两字连用，有可爱、可惜、可爱的含义。

白居易《长恨歌》中“可怜光彩门前生”是可羡慕的意思。

陆游《示儿》中的诗句：“可怜身上衣正单，心忧炭贱愿天寒”这是可爱的意思。

怜字的会文** [image: character '怜' in seal script] **，把“心”挪做偏旁，基本继承了会文的字形。

而隶书** [image: character '怜' in cursive script] **，对笔画进行了简化。

到了楷书** [image: character '怜' in regular script] **，原来的“焞”就变成了“米”了。

需要说明的是，简化字采用的“怜”自古就有，是憅的异体字，** [image: character '怜' in running script] ** 这是宋代理襄的行书。

# 总结

+   1.怜字来源于古人见到磷火，想起逝去的亲人产生的怜惜心情；

2.怜字引申为爱，并且这个含义在古文中使用的更多一些；

3.怜字的字形在演变中失去了磷火的线索；

4.简化字采用的“怜”自古就有，是憅的异体字。
