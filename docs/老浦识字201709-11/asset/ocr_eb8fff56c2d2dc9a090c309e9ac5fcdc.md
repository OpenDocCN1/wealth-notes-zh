# 206【问答】寻章摘句老雕虫，晓月当帘挂玉弓

![](bbox=[0.15, 0.25, 0.85, 0.42])

思考题：

唐代李贺一首《南园十三首之六》

> 寻章摘句老雕虫，晓月当帘挂玉弓。
不见年年辽海上，文章何处聚秋风？

我请你分析一下这里“章”的用法。

答案：

这是李贺自嘲的诗句，说自己这只只会粘贴复制，这里摘一章，那里弄一句的老书虫，每天读烂读书，又有什么用处呢？国家的边疆处处烽烟四起，文章又有什么用处呢？这里的“章”，仍然是章节的意思。

# — 鳏 —

![](bbox=[0.15, 0.82, 0.85, 0.97])

思考题：

由鱼组成的字都很有意思，上次我们猜了打酒的渔，这次你再看看这个字：[鱼形图标]

鱼形下面有一个口形，口形我们已经很熟悉了，所以你请结合以前所学，分析一下这个甲骨文。

答案：

这个字形是“鳏”，口形是巫师的方法，占卜、施法的结果是大鱼，鱼是丰饶美味的象征，所以这个字的原意是美好，后用作地名。山东的朋友可以注意一下这个字。

# — 衽 —

![](bbox=[0.15, 0.00134, 0.85, 0.00149])

思考题：

衣字组成的字都很有意思，这个字形[衣形图标]也是一种衣服，你分析一下这是什么字？

答案：

这是裘皮的衣服“裘”，在“衣（衣）”外面增加了一些毛屯，表示皮毛外面的裘皮衣服。

# — 寡 —

![](bbox=[0.15, 0.00176, 0.85, 0.00191])

思考题：

我给了一段老子在《道德经》三十九章中说的话：

> “故贵以贱为本，高以下为基。是以侯王自称‘孤’、‘寡’、‘不谷’。此非以贱为本耶？”

春秋时期诸侯自称寡人，但是楚王自称“不谷”。而较弱的诸侯自称“孤”。老子通过这些君王的谦称，讲了一个什么道理，对我们的人生有什么启发呢？

答案：

高贵是以低贱为根本的，高处是以低处为根据的。君王自称“孤”、“寡”、“不谷”，难道可以从贱为贵的高贵为本吗？

老子告诉我们，身处高位恰恰要把自己放到低处，身份高贵要懂得让自己低贱，低贱是本，高调张扬是害。老子的观点，我们可以从很多品格高贵却谦虚谨慎的名人身上得到印证。
