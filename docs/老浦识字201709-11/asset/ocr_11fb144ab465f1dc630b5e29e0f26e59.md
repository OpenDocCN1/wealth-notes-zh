# 154【令】命令的令为什么会成为敬辞

# 识字卡片

![](bbox=[0.1, 0.25, 0.85, 0.4])

主持人朱军曾经犯过一个常识错误，在节目中对嘉宾说：“在这里，首先对家父前些日子的过世表示深切的哀悼。”这句话当时引起了轩然大波，你怎么能称别人的父亲为“轩父”呢？

其实也不能怪朱军，我们这一代人基本没受过传统礼仪教育，在正式场合难免露怯。正确的说法是称自己家里人为家父、家母、舍（shè）弟、舍妹，称别人家里人为令尊、令堂、令郎、令爱。“家”“舍”是谦辞，“令”是敬辞。

“令的”本意是冷冰冰的，它为什么会成为敬辞呢？

# 1.令的原意

“令”和“令”在甲骨文里是同一个字，令上面面有个月三角形字，下面一个跪坐的人形。原意就是发号施令。

《说文解字》：令，发号也。意思是声发布命令。

但是却如何解读上那个月三角形，专家们的观点并不一致。有的解为倒看的“口”，表示说话、发声；有的解为房屋，在房屋中正确施令地下令；有的解为“今”，令的意思是木铎（duò），也就是木头做的铃铛，古人摇木铎召集众人发布命令。

古文字学家罗振玉认为令是“集众人而命之”，上面的三角形字符号是集合的意思。

我个人是认同罗振玉的解读的，由三角形字组成的字，都有集合、聚合的含义。比如原意众议的“会”，原意乐队和声的“和”。

金文的令和甲骨文形基本一样。

篆文将金文的“人”形写成。隶书进行了简化。

# 2.令的引申义

令的本意是发布命令，引申为法令。老子在《道德经》中说：

> 法令滋彰，盗贼多有。

意思是制定的法律条文越来越多，盗贼反而越来越多。这个“法令”就是法律条文的意思。

发号施令，自然引申为发布施令的人，引申为官名。比如县令是县级地方长官。中央首长官尚书令、中书令等。

# 3.令如何变得美好

中国是个农业社会，非常重视农时，24节气都是根据农时制定的，孟子说：

> 不违农时，谷不可胜食也；数罟（gǔ）不入沴（wù）池，鱼鳖不可胜食也；斧斤以时入山林，材木不可胜用也。

意思是如果不耽误农业生产季节，粮食就吃不完。密网不到池塘里，鱼鳖之类的水产就会吃不完。按一定的季节入山伐木，木材就用不完。

孟子在这里反复强调的就是农时，对于农业社会而言，农时就是不可违背的命令，因此，农时又称为节令、时令。

白居易有诗：

> 时令一反常，生灵受其病。

遵守农时、时令，粮食丰收就有保障，因此令就成为美好的事物。《诗经·大雅》：

> 如圭（guī）如璋（zhāng），令闻令望。

圭、璋都是古代非常贵重的玉制礼器。像圭和璋一样，比人的气质高雅，仪表拜昂。“令闻”是美好的名声；“令望”是美好的仪仗受人景仰。有美好的名声和品德，使人们愿意追随。这里的令，就是美好的含义。

因为是多么美好，令人尊敬的，所以就用为敬辞，用于对对方的亲属：对方的父亲叫令尊，母亲叫令堂。

# 总结

+   1. 令的原意是集众人发号施令，引申为法律条文，进一步引申为官名；
2. 农业社会农时不可违，是不可抗拒的命令，因此时又称为节令、时令；
3. 遵时令是丰收的保证，令由此有了美好的含义；
4. 由于令美好、威严的内涵，于是被用为敬辞。
