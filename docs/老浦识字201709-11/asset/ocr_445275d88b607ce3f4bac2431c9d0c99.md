# 文字原意：

甲骨文的赖是布雷贝名贝两个部件，表示债未还...为财物依仗依持，均为债得余业，进而引申为依恃。《老浦识字》“得到”App出品

老赖是当代社会的奇葩，明明自己过着花天酒地的生活，却偏做欠债不还。赖在现在是个贬义词，赖皮、赖账，都不是什么好字眼。

但是我们从古文里还是能看出不一样来，比如依赖、仰赖、赖以生存，都不含贬义。那赖最早是什么意思呢？

# 1.赖的原意

赖的甲骨文有两个字形，分别是![image](https://i.imgur.com/placeholder_image_2.jpg)和![image](https://i.imgur.com/placeholder_image_3.jpg)，是两个贝壳装在一个布囊里，贝壳是古代的钱币，布囊里装两个贝壳，表示装满了口袋，代表收获、赢家。

金文![image](https://i.imgur.com/placeholder_image_4.jpg)对甲骨文进行了简化，仍然是布囊里盛着贝壳。

还有的金文![image](https://i.imgur.com/placeholder_image_5.jpg)把布囊变形为“束”![image](https://i.imgur.com/placeholder_image_6.jpg)，右边是一个驮着贝壳的人形“负”![image](https://i.imgur.com/placeholder_image_7.jpg)，仍然是背负装满贝币的赢家。

篆文![image](https://i.imgur.com/placeholder_image_8.jpg)承接金文字形，进行了规范。

隶书![image](https://i.imgur.com/placeholder_image_9.jpg)，楷书![image](https://i.imgur.com/placeholder_image_10.jpg)字形变化不大。

![](bbox=[0.1, 0.9, 0.9, 1.0])

赖的本意是盈利，引申为利益。

《国语·齐语》中描述商人：

> 相语以利，相示以赖，相陈以如贾。

意思是商人们相互谈论的是盈利，相互展示的是利益，相互探讨的是经营之道。这里的“赖”，意思是利益。

拥有如此多的钱财，自然值得依靠，所以赖字引申为依靠、凭借、依赖、仰赖、赖以生存、百无聊赖等等，都是此意。

# 2.人生赢家怎样变成无赖

你还记得我们在【颠】字中遇到的情况吗？颠的本意是顶端，但古人认为，顶端必然跌落，所以颠直接引申为掉落、颠倒。

赖字也是如此，古人认为，依靠钱财、仰赖权贵必然败落，败然人地位低下，所以赖引申为刁钻泼辣、不讲道理、游手好闲、行为不端的人：赖子、无赖。而这样的人，欠钱不还是必然的，所以欠钱就称为赖账。

人生赢家翻手跌落，成了无赖。

不过别忘了，汉语还有呢称用法，就是用最狠的字眼表达亲昵。辛弃疾有词：

> 大儿锄豆溪东，中儿正织鸡笼。最喜小儿无赖，溪头卧剥莲蓬。

这里的无赖，实际上是可爱的意思。

# 总结

+   1.赖的甲骨文![image](https://i.imgur.com/placeholder_image_12.jpg)![image](https://i.imgur.com/placeholder_image_13.jpg)原意是装满贝币的囊袋，表示盈利、利益；
2.由利益，引申为依靠、依赖；
3.古人认为，依赖必然导致败落，依赖钱财权贵的人，人品也不高明，所以引申为行为不端的赖皮；
4.无赖仍然可以活用为可爱。
