# 145【问答】为什么花落了要说花谢

“花谢花飞飞满天”，“林花谢了春红，太匆匆”。说花落好理解，为什么花落要用“谢”字？你来分析一下，这是怎么回事？

**老浦**

谢字的甲骨文，*偷*，是双手持着席子的会意。坐的地方有单独的席子，也就是席位。

古代君王请大臣坐下，大臣会双手持席辞退，这个礼节叫“谢”。这种礼节一般用于隆重的祭祀礼仪中，后世已经不用了。后引申为大臣辞职、告别，以及逝去、凋落，再进一步引申为感激、酬谢。

花谢的谢，就是用了凋落的含义。

今天“谢”的字形是篆文变形的结果，

![](bbox=[0.07, 0.54, 0.9, 0.68])

华是树木开的花，用“木”作基本字符的汉字有很多。这是“木” *树*，下面增加了三个圆点 *木*，你来猜猜看，这是个什么字？表示什么意思呢？

**老浦**

*木* 是“本”字，根本的本，原意表示树根。

欧阳修在《与高司谏书》中有“自足下为谏官来，始得相识。悠然正色，论前世事，历历可听，褒贬是非，无一谬说。”请通读全文，分析一下文章中“侃”的用法。

**老浦**

这是欧阳修非常著名的一篇文章，从容不迫地痛骂了小人。注意这句话的后文，在“侃然正色”的后面，是说这位高司谏谈论以前的事物是非很分明，侃侃而谈，显得很正直。而这样的描写正是为后面斥责他小人做了铺垫：道理你都懂，谈论前朝不相干的事是非很分明，但在现实中，却对范仲淹这样的贤臣落井下石。“是足下不复知人间有羞耻事尔。”这句温文尔雅的骂人话把小人永远钉在历史的耻辱柱上。这个“侃”，还是从容不迫侃侃而谈的原意，但在本文中却有强烈的讽刺意义，勾勒的伪君子小人嘴脸栩栩如生。

禾是农业社会非常重要的字，用“禾”为字符组成的字有很多。这是一个甲骨文字形 *禾*，禾 *禾*，下面有一个人 *人*，这是个什么字呢？

**老浦**

这是“年” *禾*，人 *人*，背着谷子 *禾*，将收割下来的谷子搬运回家，表示这是谷物成熟的的时候，过年了。

斤 *斤* 的原意是斧头，那这个字为什么会被借用为计量单位呢？你来分析分析。

**老浦**

石斧是人类最早的工具，也是生活最常用的工具，所以经常被用来交换，是最早的货币。由于过于沉重，被贝壳取代。也是由于它的重量，同时它是人人都认识的通用物品，就被借用为计量单位，斤。
