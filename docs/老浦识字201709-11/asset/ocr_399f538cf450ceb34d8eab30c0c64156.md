# 总结一下

+   1. 纠的原意 是绳索交缠在一起，纠缠、纠结都是这个字的意思；
2. 由于纠在一起，引申出约束、督查；
3. 由于古代有用绳索校正木头的工艺，引申出通过束缚来改正错误的意义，即纠偏。
