# 识字卡片

学习汉字，探寻甲骨文原意，是一个探险寻宝的过程，常常会有发现奇珍异宝的惊喜。这次讲解的“任”就是这样一个汉字。

# 1.任是男人

甲骨文的“任”是单人立加上一个工具的工。工是古代的劳动工具，有的甲骨文写作，有的金文写为。可以想象这是一种沉重的工具，可以夯道，也可以劈砍，这肯定是强壮的男人的工具。因此，任的甲骨文原意就是男人，引申为承担、负担。

![](bbox=[0.1, 0.61, 0.9, 0.75])

任是男人，但甲骨文的“男”不是一个田加上一个表示力量的犁铧吗？

专家考证，商代的男人写作“任”，周代以后写作“男”，想想这也合理，既然男人确立了父权，男人要有担当就成为那个时代的主流，而周代确立了以井田制为基础的农业社会结构，那么开荒垦殖，日出而作日落而归的耕作就是男人的主要工作了。从“任”到“男”，可以看出时代的变迁。

金文的“任”延续了甲骨文字形，有一种写法增加了表示货币的“贝”，表示用钱雇佣工人劳动。

![](bbox=[0.15, 0.92, 0.85, 0.94])

明白了任的原意男人，引申为担当，后面的用法就晓畅了。首先就是职责，是使命。“天将降大任于斯人也，必先苦其心志，劳其筋骨。”然后是委托工作，承担使命，比如任命、委任、任人唯亲。进而被活用为副词，前任、经历。
