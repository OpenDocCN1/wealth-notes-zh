# ### 1.克是坚硬的肩膀

克，是一个语感上有点软字的字眼。

**《说文解字》说：**

克，肩也。象屋下刻木之形。

意思是说是克肩膀拱东西，字形像在房子下刻木头。字义是胜任。

看“克”的篆字形 ![篆文“克”](<bbox>0.40,0.51,0.50,0.52</bbox>)，的确有点像一

个弯腰驼背扛东西的人形，所以《尔雅》解释这个字为“能也”，就是说肩膀够硬，扛得住。

# ### 2.克是顶盔携（guàn）甲的战士

但是甲骨文可看不出肩膀扛东西的意思。

甲骨文的“克” ![甲骨“克”](<bbox>0.28,0.60,0.40,0.63</bbox>)，上面是一个大头

甲 ![甲骨“大头甲”](<bbox>0.14,0.63,0.20,0.64</bbox>) ，下面是一个曲线，曲线上面有一个膝盖骨 ![甲骨“膝盖骨”](<bbox>0.65,0.63,0.70,0.64</bbox>) 。

有的甲骨文 ![甲骨“克”加两点](<bbox>0.24,0.65,0.45,0.67</bbox>) 在上方加了一个点

，这究竟是什么意思呢？

用肩膀顶起下面那个膝盖骨肯定勉强，有人说这是杀人祭天的酷刑。还有人说这是用石斧攻击野兽的意思。

要搞清楚这个字形，我们可以把这个甲骨

文分解一下。这个有鼓包的字符 ![甲骨“鼓包字符”](<bbox>0.65,0.71,0.70,0.73</bbox>)

是什么意思呢？

![](bbox=[0.31, 0.75, 0.7, 0.8])

甲骨文又有一个相似的字符

是

金文 ![金文字形](<bbox>0.34,0.80,0.48,0.82</bbox>) 增加了一个“爫” ![金文“爫”部](<bbox>0.58,0.80,0.70,0.82</bbox>) 即

手的象形，表示用手处理牲畜的皮革。看来

“克”的下部是披皮的缩写。

那上面的“口形” ![甲骨“口形”](<bbox>0.38,0.84,0.48,0.85</bbox>) 怎么理解？

再来找一个相似的字符，这是甲骨文“肙”

![甲骨“肙”](<bbox>0.20,0.86,0.35,0.88</bbox>)，即保护头部的头盔。

古文的甲胄，甲是身体的护甲，胄是头盔。

这个字上部 ![甲骨“上喿”](<bbox>0.38,0.88,0.45,0.90</bbox>) 是头盔的顶端，有羽

毛装饰。下部 ![甲骨“下喿”](<bbox>0.38,0.90,0.45,0.92</bbox>) 是同（mào），这是

“胄”的本字，表示帽子，合起来就是保护头

部的头盔。

“克”字的上部应该就算是“胄”的缩写。胄加

上皮，合起来表示保护战士的盔甲。

我们再来看另一个甲骨文“克”的写法

![甲骨“克”之二](<bbox>0.14,0.96,0.30,0.99</bbox>)，这是一个戴头盔的人手持武

器“ ![武器象形](<bbox>0.38,0.99,0.48,1.01</bbox>) ”，一个顶盔携甲手拄戈矛的

战士形象。

这就清楚了，克的原意是戴青持戈的战士

，是胜利者的形象，所以克就是战胜，克敌制胜。

从克的甲骨身穿戴来看，这是一个防守的姿态。克服、克敌、克服困难、克己敬礼、克己复礼，这些用法都是防守的意思。但是，攻克、克复、克扣这些用法就纯粹是进攻型了。在上千年的使用中，词性会发生变化。

# ### 3.克通“剋”

在古文中，克和剋通假互用。《史记·李斯

列传》中就有：

> > 更有司，平斗斛度量文章，布之天下，以
> 树秦之制。罪五类。

这是李斯在被秦始皇赐下狱以后写的申诉

状，意思是说我要有罪，然后罗列自己的功

绩，其中就有一条更平斗斛，这是秦统一制度下，让全国度量衡、文书、法令统一标准。

“剋”是更，就是变，是改变，画成文字，变革书写的文字，就是指用秦文统一文字。

由“剋”这样的通假，就引申出奇巧、刻薄的

含义，如克薄、克心、克苦，进一步引申出

克期、克宁克宁这样限定时间、空间的用法。

最后，由这样限定时间、空间的含义，活用于

为小的重量单位“克”。克就是一个规定好的

很小的单位。

# — 总结一下 —

+   1. 克的甲骨文字型 ![甲骨“克”](<bbox>0.24,1.30,0.35,1.31</bbox>) 为一个顶盔携
甲，持戈抗敌的战士，寓意战胜；
2. 克在使用过程中，既有防守型，克制，克
己复礼，也有进攻型，攻克，克敌，
词性发生变化；
3. 克和剋通假，引申出奇巧、刻薄的含义；
4. 引申为最小的计量单位。
