# 怜

![](bbox=[0.08, 0.54, 0.92, 0.65])

思考题：

火在古代是非常重要的物质，甲骨文与火有关的字有很多，都很有意思。你看这个字形“  㞢 ”，是一个人跪坐人形头上有一团火，你猜猜，这是什么字？

答案：

这是明亮的“光”，用一个头上有火的人形表示光亮，这应该是一个巫师在做法，火把的光亮把巫师照亮的十分神秘。

# 圣

![](bbox=[0.08, 0.82, 0.92, 0.92])

思考题：

会听能成为圣人，那话多呢？这个字形“  〤 ”是一个人四周有四只张口，你猜猜，这是什么字，提示一下，和我们互联网上的一个现象有关。

答案：

这是喧嚣的“嚣”，中间是“页”，表示一个人挽着耳朵，四周有四张口，口表示人多嘴杂，意见不一，喧嚣吵闹。这很像互联网上的键盘侠，吵闹却无知。
