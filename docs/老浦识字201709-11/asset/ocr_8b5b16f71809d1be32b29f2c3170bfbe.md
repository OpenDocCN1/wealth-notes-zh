# 137 【距】由鸡爪产生的距离

老浦提醒：订完专栏后，文章中的象形文字可敲可见，放大来看，细细品读。

# 识字卡片

| 字形演变 | 拼音 |
| :--- | :--- |
| [甲骨文小篆楷书行书等] | jù |
| 距 | 距距 |
| 金文隶书 | 距 |

**文字原意：**
[小篆] 甲骨文、金文、小篆、隶书、楷书、行书等字形的演变过程。

美学上有一个原理：距离产生美感。比如欣赏珠穆朗玛峰要远远而观赏，身处其中是会很可怕的。空间上如此，时间上也是如此，比如大人对童年具有美好记忆，那是因为这个时间段有太多的美好记忆。但是，人是时间距离的“距”会舒适地发现，距的原意居然和鸡爪子有关。

# 1.先认识巨

**距的金文：**
[金文字形] 左边是一个足字旁，右边是一个“巨”。

**巨的甲骨文** [甲骨文字形] 原是木匠手里的直角曲尺，是徒（巨）的原字。

古代木匠的一个核心工具是放样，即将小尺寸的设计放大成为实际操作的墨线，而曲尺就是放样工具，由此引申为巨大。

古代绘画伏羲女娲图中，伏羲手持的就是圆规，女娲手持的是曲尺，寓意没有规矩不成方圆。

![](bbox=[0.15, 0.52, 0.85, 0.62])

# 2.距就是鸡爪子

足字旁加上巨，原意是公鸡鸡爪后面凸起的小爪子，叫距爪，也叫蹙（cù）爪，可当作攻击用的武器。由于距爪与其它爪子永远是分开的，所以有抗拒、排斥的含义。

# 3.距也可指整个鸡爪。

《左传.昭公二十五年》记载：

季、郈（hòu）之鸡斗。季平子给他的斗鸡安上了盔甲，而郈昭伯则给他的鸡戴上金属的爪子。（后来谁赢？当然是有进攻性金属爪子的鸡赢了配备防御型盔甲的鸡。）

![](bbox=[0.15, 0.78, 0.85, 0.84])

由于距的原意是鸡爪后面的距爪，所以它首先引申为钓鱼工具的倒刺。

《淮南子.原道》：

> 引玄鱼临于渊，钩而不得盈卵，虽有钩针芒，微锐毒苦，加之 詹，鼷鼯之兽，就不能网兽（qu）争也。

> 说在江上钓鱼，鱼很多但天多钩子不满一篓子，即使有很利的鱼钩和锋利的鱼钩倒刺，加上毒，鼷鼯这样的毒鱼钩高手，也不可能和渔网竞争。

又由于距是指鸡的鸡爪子，所以就有了抗拒、抵御的含义。

《论语》里记述了一个小故事很有意思：

引吉子之武城，弦歌之。

夫子莞尔而笑，曰：“割鸡焉用牛刀？”

子游对曰：“昔者偃也闻夫子曰：‘君子学道则爱人，小人学道则易使也。’”

子曰：“二三子！偃之言是也。前言戏之耳。”

孔子的学生子游做了武城这个地方的行政长官。由于武城是鲁国边陲的一座城市，人们尚未开化，比较粗俗。子游到任后，致力于礼乐教化的教育工作，经过了几年努力，自己感觉悟理的功夫，就特意邀请子来到武城去观览。子子带着弟子们进入武城，就听到弦歌之声。琴歌是一种很正派、礼乐教化的，即弹着琴歌唱学生阅读。孔子就笑着说：“杀鸡何用宰牛的刀呢？”

子游马上解释道：“老师，我记得以前听人家这么说，君子学礼乐，就能爱人；小人学礼乐，就容易使唤。”意思是这是您老人家自己的管理思路啊。孔子说这话并非真的，我刚才那句话不过是同他开玩笑罢了。

汉代的王充在《论衡·问孔》中评论这件事：

孔子笑子游之谈，子游引前言以距孔子。

意思是子游用孔子自己的话驳斥孔子，师生由此有了距离。由抗拒，引申为距离。

# 总结一下

+   1. 巨大的巨 [甲骨文字形] 原意是木工用的曲尺，用于制作大样工具，引申为巨大；
2. 距离的距 [金文字形] ，巨加上足字旁起，原意是公鸡鸡爪子后面凸起的小爪子，叫鸡距，通常都是鸡爪子的凸起小爪子与曲尺很像，引申为鸡爪；
3. 由于是鸡爪子的后部，活用于钓鱼、倒刺；
4. 子游用孔子自己的话驳斥孔子，师生由此有了距离，由抗拒，引申为距离。
