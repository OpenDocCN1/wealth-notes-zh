# 197【流】一个我们今天无法理解的习俗

![](bbox=[0.0, 0.15, 1.0, 0.45])

昨天，咱们分析了江苏扬州大明寺平山堂的“风流宛在”牌匾中的“在”。今天咱们来认识“流”。

# “流”字表现了一个远古习俗

“流”没找到甲骨文，这是战国时期的全文字形【插图：流水及人形】，是水中一个大头朝下的“子”【插图：古代“子”字形】，水里面有一个孩子，这代表里是什么意思呢？

一种解释是水中的虫子，虫子被水冲向表示水的流动。

一种解释这是羊水，婴儿出生，伴随羊水降生。

还有一种解释是古代有把初生婴儿放水中漂流，观察其浮起的状况，以决定是不是可以养活、养育的风俗。

《说文解字》的解释是：流，水行也。意思是水的运动，并没有解释那个大头朝下的“子”。

这几种解读都还存在疑问，第一种说是虫子，难以想象。其实河里漂浮的可以有很多东西，如果表示水流很急，虫子太不显眼。

第二种解释是生孩子，甲骨文中有专门表现生孩子 的汉字，这是“㚢”【插图：甲骨文字形】，表示用手分开产道。

这是“毓”【插图：甲骨文字形】，表示成年妇女的“母”身下一个大头朝下的“子”，合起来表示婴儿出生，下面那三点是羊水。

![](bbox=[0.2, 0.84, 0.8, 0.95])

这是收录在我的新书《话说汉字》中的作品，表现了汉字中孩子从怀孕到出生一直到受教育的过程。其中有些字体我们有提到，请你找出来，看看自己还记得哪些。
