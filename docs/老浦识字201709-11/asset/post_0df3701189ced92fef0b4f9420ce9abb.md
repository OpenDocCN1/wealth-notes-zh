## 1. 夺的原意

夺的金文是一个衣服的“衣”，衣里面包着一个“雀”，也就是小鸟。而衣服的外面，有一只“手”。古人抓小鸟，藏在衣服里，碰到一个不讲理的，伸手从衣服里抓出来，抢走了，这就是夺。

篆文将金文的“衣”写成“大”，具体演化过程见下图。

![](img/49696776a6cb1fac221b4a6b437da7b9_0_3.png)

《说文解字》：夺，手持朱（zhū）失之也。意思是夺是手持鸟儿被抢走了。好容易抓了只小鸟，多高兴的事，愣让人生抢走，这是夺的原意。

## 2. 夺怎样成为定夺

先讲个故事。中国古代有个制度，叫丁忧，就是父母去世，在朝廷做官的人要回家守孝三年。如果皇帝认为你很重要，要求你留下为国效力，叫夺情，意思是为了国家利益委屈了你的孝心。

历史上最有名的夺情是张居正，当时他刚刚当上首辅，正要积极推行酝酿已久的改革，正赶上父亲去世。神宗皇帝夺情请他留下来，张居正本人虽然反复上本要求回乡，其实心里也不想去。在皇权社会，以孝治天下，不执行丁忧制度是很严重的道德瑕疵。所以很多人公开反对夺情。神宗皇帝动用了廷杖，才平息下来。

张居正夺情有两种严重后果，一是神宗皇帝认为大臣提反对意见是故意找打，博取名誉，所以后来对大臣的各种反对意见一律置之不理。二是张居正心态发生了巨变。由于被夺情得罪了绝大部分朝臣，自己在道德上声名狼藉，这就让张居正破罐破摔，在个人自律上完全放纵，贪污受贿、奢靡享受全来了。他回乡居然使用32人抬的大轿，里外套间，咸戚光宗派宗兵护送。历史学家普谥认为，夺情固然有利于张居正改革，却也改变了张居正的心态。

这就是汉字定夺的道理。决定一件重大事情，一定会有所取舍，决定一方面，就意味着放弃另一面，所以有定，就有夺。张居正夺情保住了官位，实行了改革，这是取，但此举对立了朝臣关系，失去了道德制高点，反而让他破罐破摔。世上万物都是这个道理，抢了人家的小鸟，占了便宜，却也失去了别人的友谊和信任。这就是定夺这个字用法的道理。

## 总结一下

- 1. 夺原意是抢夺别人的小鸟；
- 2. 古代夺情是皇帝出于国家利益考虑，取消官员丁忧，丁忧就是回家守孝3年；
- 3. 张居正被夺情后，名誉受损，心态发生很大变化，说明了定夺就是有所取舍，有定必有夺的道理。

# 131 【奋】奋斗就要挣脱束缚

老潘提示：订阅专栏后，文稿中的象形文字可戳可点，放大来看，细细品读。

## 识字卡片

![](img/49696776a6cb1fac221b4a6b437da7b9_1_0.png)

我们学习了夺取的夺，是把藏在衣服里的小鸟抢走。汉字中还有一个字，金文字形和夺很像，意思却完全相反，这就是奋斗的奋。

## 1. 奋的原意

金文奋斗的奋和夺一样，外面是衣服的“衣”，里面也有一只小鸟，不同的是，夺是衣服外面有一只“手”，表示从衣服里把小鸟抢走，而奋斗的奋是衣服外面是广阔的田野，合起来，表示小鸟挣脱了衣服的束缚，在田野上奋飞。

![](img/49696776a6cb1fac221b4a6b437da7b9_1_1.png)

想象一下，小鸟挣脱出来的一瞬间，一定是拼尽全力的。所以奋字就有了奋飞、振奋、激奋的含义。

《史记·高祖本纪》记载：

> 秦末，怀王与诸侯约，先入定关中者王之。当是时，秦兵强，常乘胜逐北，诸将莫利先入关。项羽怨秦破项梁军，奋，愿与沛公西入关。

意思是说秦朝末年时，怀王和诸将军约定：先进入关中的人可以称王。关中是指在函谷关、大散关、武关和萧关之间陕西地区，自古称天府之国。那时候，秦朝的兵马很强大，经常乘胜追赶打败的人。

诸将军没有人认为先入关是有利的，只有项羽怨恨秦军打败过项梁的军队，十分激奋，自愿和沛公向进入关内。

这个“奋”，既有激奋的含义，也有斗志昂扬的激奋含义，可以想见项羽的状态。

## 2. 奋就要挣脱束缚

然而我们看金文的奋，是挣脱衣服束缚的小鸟。这告诉我们，奋斗的前提是挣脱束缚。

讲个自己的故事吧。我曾经长期从事电视节目的策划工作，央视《艺术人生》、凤凰卫视《一虎一席谈》都是当时的作品，但栏目录制过程中，常常感觉嘉宾不能把自己策划的重点表达出来，于是就有心自己去主持。但是我知道自己说话毛病很多，一个央视的老导演也是好朋友对我说：老潘你语速太慢，吐字也不清晰，甚至有点结巴，吃不了开口这碗饭。

我自己明白，之所以有这些毛病，是自己害怕、紧张。最典型的案例就是在家网站采访瓦尔德尔，全程都在抖腿，被网友发现痛骂。我拜自己的学生编导为师，练习讲话。为了克服心理障碍，反复提示自己：你是人来疯，是最会表达的。经过反复锤炼，现在真成了人来疯，不怕当众表达了。

我的体会，自卑就是束缚自己的衣服，这样的束缚，也许来自外部，也许来自不理解你的家庭，更多的是来自对自己的成见。要想奋飞，就要挣脱观念的束缚，战胜内心的怯懦，超越自己。

## 总结一下

- 1. 奋的原意是鸟儿挣脱猎人的束缚在田野奋飞；
- 2. 由于挣脱束缚的爆发力，就有了奋飞、振奋以及激奋的含义；
- 3. 奋的原意告诉我们，奋斗，就是不断挣脱束缚的过程。

# 133 【复盘】和吃有关的汉字（下）

上周我为咱复盘了三个和吃有关的汉字：米、青、盐。今天咱接着说另外四个：酱、醋、茶、食。

咱们开始。

## 第一个汉字：酱

甲骨文的酱是一个大鼎加上右上角的一个夕，这里表示肉，只表示木片，合起来是用木片搅拌鼎中的碎肉，发酵成为糊状的肉酱。那时候的酱是通过滴肉发酵，是王贵族涂专享的奢侈品。

说到酱这个字，有个好玩儿的事我想和你分享。

人们都以为了，现在人物质条件越来越好，吃的东西也越来越丰富，肯定比古代人讲究多了一些肉。还真不是。你看《周礼》就记载了一些肉品：鹿肉酱、鹿肉酱、猪肉酱、牛腿肉酱、蛤蜊肉酱、鸡蛤肉酱、兔肉酱、雁肉酱等等，不同的酱搭配不同的主食，孔子也是“割不正不食，不得其酱不食”啊，非常详细讲究。

![](img/49696776a6cb1fac221b4a6b437da7b9_3_1.png)

字源演变：醬 -> 酱 (jiàng)

## 第二个汉字：醋

“醋”最早的象形字是篆文。

篆文的醋左边是一个酉，酒的意思；右边是昔，表示过去。这个字形揭示了醋的来源，它是酒在自然环境中由于微生物的发酵作用而变酸形成的。

醋在古代叫“酢”（zuò），酢字出现在周代以前，西周室中可以有“醋人”，专管王室中新制供应。

说克“醋”的汉字，再和你讲一个有趣的典故，为什么形容女人妒忌会吃“醋”呢？

这个典故是这样的。

唐太宗为了笼络当朝宰相房玄龄，下令赐给他美女，为他纳妾。但房玄龄坚辞不受。

唐太宗知道，唐玄龄不是不想要，而是不敢要，他家夫人出了名的厉害，不可能同意房玄龄再纳个小妾。

于是唐太宗让人给房玄龄的夫人送去一壶毒酒，说要么同意纳妾，要么喝毒酒。

房玄龄夫人也真是刚烈，把那壶酒一口喝下。

结果那壶酒不是毒酒，而是香醋。

从此，吃醋、醋坛子就成为女人妒忌的代名词了。

![](img/49696776a6cb1fac221b4a6b437da7b9_3_2.png)

字源演变：酢 -> 醋 (cù)

## 第三个汉字：茶

“茶”是比较晚出现的，甲骨文、金文甚至篆文里都没有“茶”，小篆有茶，上面是草字头，下面是“余”。

不对啊，茶的下面是一横，而“余”下面是两根脚。

没错，这是“荼”（tú）字，就是最早写的“茶”。

茶是多种植物的泛称，泛指能够解毒的植物，包括茶叶。

今天的“茶”，是“荼”的俗写字，一直没沿用到今天。

![](img/49696776a6cb1fac221b4a6b437da7b9_3_3.png)

字源演变：荼 -> 茶 (chá)

## 第四个汉字：食

甲骨文的食，是一个有脚的容器豆，表示装满食物，上面一个盖子，两个点，表示热气。合起来表示热气腾腾的食物准备好了，可以吃饭了。

这种食容器盛着什么样的食物呢？是混合着小米、蔬菜和碎肉的粥或饭，也就是肉羹。

中国历史上有一个出名的白痴皇帝，西晋惠帝司马友。这是一个锦衣玉食，从来不知民间疾苦的公子哥，有一年，全国闹饥荒，老百姓没饭吃，饿死无数。这个皇帝听了大臣汇报后，感到很奇怪，竟问侍臣：“老百姓既无饭吃，何不服肉糜？”荒废的这话就成为千古笑话。

![](img/49696776a6cb1fac221b4a6b437da7b9_3_4.png)

字源演变：食 (shí)

# 134 【具】具备与具体

老浦提示：订阅专栏后，文稿中的象形文字就可点开，放大来看，细细品读。

## 识字卡片

![](img/49696776a6cb1fac221b4a6b437da7b9_4_0.png)

故人具鸡黍，邀我至田家。
绿树村边合，青山郭外斜。
开轩面场圃，把酒话桑麻。

这是我最喜欢的诗句之一，重阳佳节，阳光晴好，约五至六友，到农家炖鸡共酒，喝小酒，人生幸福，不过如此。其中，"具"很重要，故人、鸡黍、小酒、菊花，当然还有绿水青山，缺一不可，都要具备。

- 1. 具的原意是大鼎已经摆放妥当

甲骨文的具是双手托举着大鼎，意思是盛宴最重要的器具：大鼎已经摆好了，万事具备，就将开席了。

金文把双手放到了鼎下面，恭敬的意思更加清晰。

篆文把鼎写成了贝，害得许慎老先生在《说文解字》中解释：

> 具，置也。从升（gōng），从贝省。古以贝为货。

意思是具是很多人一起放置。字形采用"手"和"省"所省略的"贝"合义。因为古代人们将"贝"视作货物的象征。

这是礼器，不是贝，必须是鼎。因为鼎在古代社会中处于中心位置，庙堂祭祀中，鼎是国家权力的象征。而在贵族宴会中，钟鸣鼎食，鼎是宴会规格的定位，所以，摆好了鼎，就是摆好了中心最重要的器具，具备齐全了。

具的本意是供置、陈设，引申出配备、详细的含义，进一步在文字中表示开列、陈述的含义。比如具体、具文。

- 2. 真正的具备是具有最重要的东西

《墨子·公输盘》记述了一个故事：

公输盘为楚国设计制造了云梯，打算进攻宋国。墨子听说了这件事，赶了十日十夜，来到楚国。他先见到了公输盘，说服了公输盘。再见楚王，又在道理上说服了楚王。

但是楚王说，公输盘已经为我把云梯造好了，不能不打啊。

意思是万事已经具备，该打还得打。

于是墨子和公输盘进行了历史上著名的虚拟攻防战。墨子用腰带模拟城墙，木片为虚拟的兵器，公输盘攻，墨子守。公输盘用了九种不同的方法，墨子一一化解。

没办法，公输盘说，我知道怎样打败你，但我不说。

墨子说，我也知道你想怎么对付我，我也不说。

楚王说的是什么情况，啥意思？

墨子说，公输盘最后一招无非是现在就把我杀了。但我要告诉你，我的弟子禽滑厘等三百人，已经在宋国城上防守好了，你就是现在把我也杀了也没用。

最终迫使楚王放弃了攻宋的想法。

楚王以为具备了当时最先进的工程器材，打下来国易如反掌，但他并没有意识到，公输盘只是一个工匠，他的武器也要有好多将军和强悍的军队啊。他具备的，并不是"具"的那个最重要的大鼎，有云梯也打不赢。反观墨子，不仅有丰富的实战经验，还有一支300人的团队，这才是墨子的核心竞争力。

现实生活中，我们经常会看到创业者具备了很多有利条件，核心产品、市场、平台和资金，但往往以失败告终。追溯原因，恰恰是不具备最核心的竞争力。每个创业者在策划项目的時候，在摆出诸多有利条件后，都该问问自己，你真的具有别人无法取代的独特优势吗？你具备操作项目的能力吗？你的团队得力吗？

## 总结一下

- 1. 具的原意是摆放好祭祀或宴会最重要的器皿大鼎，引申为具备、具体等含义。
- 2. 墨攻的故事告诉我们，真正的具备是摆好了大鼎，有着最重要的核心能力，那些取巧的一招鲜未必能够成功。

# 135 【婚】结婚就是发昏吗

老师提示：订阅专栏后，文稿中的象形文字可戳可点，放大来看，细细品读。

## 识字卡片

![](img/49696776a6cb1fac221b4a6b437da7b9_5_1.png)

有人说，结婚的婚是个昏字，古人结婚都是在黄昏时分，也有人说，古时候是抢婚，把女人打昏抢走，所以结婚就是发昏。

## 1. 到底么么个昏法

篆文的婚，确是女字旁加一个黄昏的昏。

**《说文解字》：**
婚，妇家也。

**《礼》：**
娶妇以昏时，妇人阴也，故曰婚。

**《说文解字》**说：婚是妇人归家，也就是说到女人有了家就有了妇人归嫁。古代礼法认为，娶妻应该在黄昏时分，因为女人属阴，所以叫“婚”。

古时候婚礼的确在黄昏举行，仪式以后就烧灶火了的，大家现在一般在中午举行，不过，黄昏举行婚礼并不是‘婚’的原意，因为这个婚只是篆文形、和全金文字形完全两码事。

## 2. 婚和昏无关

全金文的婚这个字形有点怪，有人解读是‘间’的变异，意思是说古代黄昏抢婚，女人在屋里紧张地倾听。详见下面的演变图：

![](img/49696776a6cb1fac221b4a6b437da7b9_5_2.png)

文字学家王国维认为，婚的左边是“爵”字的变形。爵是青铜铸造的酒器，用于祭祀、宴会等正式场合。字形的演变详见下图：

![](img/49696776a6cb1fac221b4a6b437da7b9_5_3.png)

“婚”左边像有一个人手举全爵，右边一个形，这是“取”的减写。

取的甲骨文是手抓住耳朵。在远古氏族战争中，人们会割下敌人的左耳来表功。娶家的娶就是‘取’的旁边加个‘女’，表示抢来的女人。“婚”字里面的“取”，表明这个用爵饮酒的仪式是干于娶的。

有的金文简化了全爵，增加了“女”，合起来表示手持全爵娶妻。

这全说把女人打昏抢来是结婚的说法是对的了？

抢亲是对的，打昏就算了。

## 3. 婚是一种仪式

从古金文字形分析，“有“取”的确是抢婚风俗的体现。我们在【嫁】这一期里介绍过，进入父系社会后，男人为了争夺延续血脉的权力，改原来全婚为抢婚，把女人抢回来，就等于抢到了子女的优势权，抢到了姓氏延续的权力。现在的一些少数民族地区的婚姻中，还保留象征性的抢婚形式。

那全文的婚字里全爵的形象怎样解释呢？王国维认为，“古者女归，迎以亲之。”意思是说古代女人刚到夫家，夫妻举行隆重的仪式。

那这什婚礼是什么礼呢？白川静认为，这是“三酣（yín）之礼”。

饭是吃饭，婚礼仪式上，新郎新都要反复三次共同进食，醴（yín）是拿全杯以酒漱口，也是重要的礼节。这种礼节，叫“共牢而食，含盥（jìn）而酳（yín）。”

> **《礼记·曾礼》：**
妇，婚嫔以入，共牢而食，含盥而酳，以合同、同亲、以亲之也。

这段话的意思是新娘来到，新郎行礼引入，举行“共牢而食，含盥（jìn）而酳（yín）的婚礼仪式，表示夫妻一体，平等相待，和睦相处。

“牢”是用于祭祀的牲畜专门圈养起来的建筑，所以祭祀仪式也称牢，有牛的叫太牢，没有牛的叫少牢。这里“共牢而食”是一只小羊。共牢表示新郎新娘一起来象征性地吃小动物的仪式。

含盥（jìn），是，刮开一半来盛水，两个水结合起来，象征夫妻结合。含（jìn）而酳（yín），就是共同全爵饮酒的仪式。

![](img/49696776a6cb1fac221b4a6b437da7b9_5_4.png)

这样看来，婚的意义就很清楚了，表示象征性进食、饮酒的结婚仪式。

## 4. 日本的结婚仪式保留了古礼

白川静说，三飱（yín）相当于日本婚礼仪式的“三三九度之礼”。日本传统婚礼是在神坛中举行，先修妆（fú），即用清水洗手，象征洁净身心，然后由神职人员举行清祓（fú）仪式，以扫除新人及其客身上的不洁。饭后就是三献三杯，新郎新妇轮流三次，每次三杯一共九杯。这就是“三三九度之礼”，“三三得九”，九次交杯代表长久永远，白头偕老。

我觉得日本的这个仪式应该是保留了古吉古的婚礼仪程，清祓仪式也有着重文化的遗存。当然他们也也有西式穿婚纱的婚礼仪式，和我们一样。

## 总结一下

- 1. 婚的原意是共牢而食，含盥（jìn）而酳（yín）的婚礼仪式，以示尊重；
- 2. 《说文解字》关于黄昏婚的解读是基于篆文形，不是全金文意；
- 3. 抢亲上古民俗的确有，但“婚”的含义不是暴力，而是彬彬有礼的仪式，表示夫妻一体，和睦相处。
