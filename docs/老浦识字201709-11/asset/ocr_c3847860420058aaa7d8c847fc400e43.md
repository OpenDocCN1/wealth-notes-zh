“一隻蔓蟮的台灣烏龜。”我们接着看这句话较劲，看看有多难。这次来着着乌龟的“龟”。

繁体乌龟的“龜”笔画多的让人眼花，但是对于《老谱讲汉字》的用户来说，这个字非常好写，比简化字还好好写。我们从头说起。

甲骨文的“龟”是一个典型的象形字，是乌龟的俯视图，长长的脖子从龟背向上伸出，两个爪子萌萌地露出来，仿佛在慢慢爬行。

金文的“龟”改成了侧视图，基本就是我们今天的儿童简笔画，远远的背壳，四个小爪子，小尾巴俏皮地耷着。

这似乎不好写字，尤其是篆文，笔画越来越多多了。

# 龟是“龟蛇”合体的汉字

别急，我们来分解一下这个字，你就会发现这个字不仅写起来简单，而且可以上溯到中国传统文化中一个重要的概念。

我们先把乌龟的头部分写下来，再把它中间的两个竖笔写下来，这是个什么字呢？是“它”，咱们以很多次碰到过这个字，最近的一次我们在思考题“池”字还说到“它”，这个字形后来分化出“它”、“也”、“虫”，本意是蛇的意象。

对，我们先写一个代表蛇的“它”，再写一个乌龟头的侧视图，再加上两个小爪子，就完成了。篆字如此，楷书繁体字“龜”也是这样写。

繁体字“龜”实际上是两个字：代表蛇的“它”和“龟”的侧视图。龟和蛇有关吗？

# 龟蛇合体—玄武

对，这是龟和蛇的合体，传说中的四灵之一玄武。

![](bbox=[0.25, 0.73, 0.75, 0.8])

玄武是古代神话传说中的灵兽，属于传统文化中的四象之一，风水里面讲究左青龙、右白虎、前朱雀、后玄武。玄武的造型就是一条蛇盘在乌龟身上，方位属于北方，属水。

为什么是两个动物叠在一起？原来古人误以为乌龟本身没有生殖能力，要和蛇交配才能繁衍，所以让它们在一起，起“龟蛇交尾”的生殖。又由于龟的寿命很长，因此它又是长寿的代表，龟鹤延年。

在道教中，玄武的地位很高，被称为真武大帝，受到顶礼膜拜。

这个时候你再写一遍“龜”字，先写“它”，在画 上龟壳和龟足，一个代表玄武的“龜”字就完成了。

# 龟崇拜

中国人对龟的崇拜由来已久，传说女娲补天，最后是用四只龟足支撑起天的四个角。
