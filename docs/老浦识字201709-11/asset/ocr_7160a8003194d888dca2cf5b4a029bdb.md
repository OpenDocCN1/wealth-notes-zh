# 193【鱼】康熙把繁体字“魚”写错了吗？

网上关于花港观鱼的石碑有两种说法。

+   * 第一种：花港观鱼四字 是乾隆皇帝 当时下江南时所题，其中的“鱼”字，繁体写法是四点“灬”之俗称。乾隆认为三点，代表水，四点为火。繁体“魚”字底部的四点，本为火形，寓意百姓生活风调雨顺，江山稳如太平。

+   * 第二种：花港观鱼四字为 清康熙皇帝 手迹。康熙一生崇信佛教，向有“佛爷”、“善人”之称。然而，在汉字里，三点为水，四点为火。繁体“魚”字底部的四点，本为火形，鱼遇水而生，遇火必死。

皇帝不忍见鱼死，便将碑文中“魚”字底部的四点改成了三点，意在让鱼永远欢快地生活在水里，以示皇恩浩荡，泽被万物之意。这也给后人留下了一段有趣的典故。

以上是原文粘贴，网上的帖子不严谨，一块御笔题写的碑，怎么能是谁写的都搞不清楚呢？其实这很简单，找一个清晰一点的大图，放大看题款就不行啦。

我是这么做的，石碑右上角的题款是：康熙三十八年三月十二日，看来这是康熙的手笔。

“魚”字下面是不是“灬”

那这个“魚”字是不是康熙皇帝带有超前的动物保护理念，出于慈悲心理特意把四点的“灬”写成三点的“氵”呢？

古人造字，为什幺要把鱼架在火上烤呢？

我们来看看甲骨文。

甲骨文 魚 有几十种写法，可见在远古，鱼是非常重要的食物。这些写法都是鱼的象形，简笔画，用线条勾勒一条大鱼的轮廓，没有“灬”的痕迹。

金文“魚” 魚 的写法同样也有好几十种，这是其中的一种写法，仍然是大鱼的象形。

有一种 篆文 魚 把鱼尾巴写的像“灬”，这个写法 魚 更像“灬”，这是文字由象形向符号化发展的结果。

这是马王堆帛书，也就是隶书 魚，可以看到“魚”字下面的四点是怎样演化过来的。

魚 这是我们练书法经常临习的汉《乙瑛碑》中的字，可以清楚地看到，鱼尾以渐消去，变成了四点。

好了，现在清楚了，“魚”字下面的四点来自鱼尾巴的变形，和火没关系。

汉字的四点表示火呢？

确实有些汉字下面的四点是“火”演化过来的，如： 炏 是双火；烈 是火烧烤骨头等等，汉字逐渐抽象化，用四点代表了火。

这件事还是告诉记者们，不能用现在的字形去揣度古原始的含意，正如你不能用孔子后离去猜测孔子的长相。

用三点是不是皇恩浩荡？

还有一个问题，康熙写“魚”的三点算不算错，恐怕是有意的。

我们在上一篇谈“避”字的时候说过，汉字手写体有很多不同的写法，出现异体字往往以名家大师为标准。“魚”字在康熙皇帝之前有写着三点的吗？

我们翻开《书法大字典》查一查。

+   这是王羲之的写法：魚 两点。

+   这是欧阳询的写法：魚 三点。

+   这是赵孟頫的写法：魚 四点。

+   这是文徵明的写法：魚 一横。

+   这是苏轼的写法：魚 写成了“大”字。

可见，用毛笔手写鱼字，下面的四点是可灵活处理的，和什么好生之德、皇恩浩荡无关。

多说一句，近年来在一些旅游景点的说明和一些自媒体文章中，对康熙皇帝颇多加美则多写少写，会不会是受了戏说的电视剧的影响，把专制帝王浪漫化了？请你自己思考。

# 总结

+   1. 鱼的字源是鱼的象形，和“灬”无关；
2. 手写体“魚”下面的四点有多种写法，写成三点与所谓“皇恩浩荡”无关；
3. 不能用简化字的字形去倒推字源，也不能用现代标准字体去衡量古代手写体的对错。
