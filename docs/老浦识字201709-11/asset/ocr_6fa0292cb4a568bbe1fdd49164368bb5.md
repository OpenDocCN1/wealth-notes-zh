# 识字卡片

![](bbox=[0.1, 0.32, 0.9, 0.38])

字源演变：lian

文字原意：它是殷末时期新造的字，左边是代表人体器官的月字旁，右边是代表头部器官的监（jiān）。在古文中，脸是代表整张脸（包括下巴、腮等）。

脸面，对于一些人来讲那是要命的事，所以，打脸，就成为现在网络使用频率很高的词汇。对于我们现代人而言，脸就是整个面部，包括所有五官，但是在古人看来，脸其实不是面部的全部。

# 1.脸的原意

脸（liǎn）在《说文解字》里都没有，是中古时期，也就是唐宋时期才新造的字。左边的“月”字旁，表示这是人体的器官，右边的“监（jiān）”的意思是众人聚集，在这里特指眼睛下面颧骨那一部分。《韵会》：

> 脸，目下颊上也。

温庭筠《菩萨蛮》：

> 凤凰相对盘金盏，牡丹一夜微香雪。明镜照新妆，鬓轻双脸长。

这是温庭筠14首菩萨蛮词组的第七首的上片，讲的是—个女孩思念恋人的情景：金线绣成的凤凰盘对相叠，绣成的牡丹好似一夜微香，格外的雍容鲜艳。新妆后在镜子里照看，只见双颊消瘦，鬓发轻舞薄如蝉翼。前两句是写景，金色的凤凰，鲜红的牡丹花，而衬托出由于思念而日渐消瘦的面庞，而鬓边的发丝轻轻飞舞，仿佛女孩子思念恋人的思绪。这里的“双脸”就是颧骨这一部分。

相同的用法还有北宋词人晏殊《破阵子》的下片：

> 巧笑东邻女伴，采桑径里逢迎。疑怪昨宵春梦好，元是今朝斗草赢，笑从双脸生。

说在路上碰到邻居家采桑女，笑得如此开心。是昨 天晚上 做好梦了吗？原来是刚刚和小伙伴斗草游戏赢了，那纯真的笑意从眼下浮现出来，真是美好。

脸是古代女子涂胭脂的地方，所以，诗词中常有“红脸”、“鹅脸”、“胭脂脸”这些描写。

# 2.脸上的部位都叫什么

在古文中，脸的整体叫“面”（miàn），是人脸的轮廓，里面有个眼睛，代表五官。“人面桃花相映红。”就是这个含义。面部也可称“颜”，三军过后尽开颜。

眼睛上部，发际线以下是“额”，额头。也叫“题”，指人头的正面，特指额头。

脸的两侧从眼下到下颌部分，叫“颊”，面颊，就是面中之颊，是面的两侧。

脸下面，也就是颧骨部分以下，叫腮，也叫“颐”，颐后来引申为保养，颐养天年，颐和园。

再往下，耳朵下面的骨头，叫“颌”，颌骨，也就是下巴骨。

再往下，是下巴，古文言为颏（kē）。

再往下，下颌下方，脖颈（gěng）上方的部分，叫“颔”（hàn），颌骨，指点头表示恭敬，或点头表示答应。颔首低眉，形容低着头，显得很谦恭恭顺的样子。

现代汉语就没有这么细致了，统称脸。

# 总结一下

+   1. 脸的原意是眼睑以下颧骨部分，古人在这里施胭脂；
2. 宋词中碰见“脸”，都是特指颧骨的这一部分，整个面部是“面”字；
3. 古人对“脸”分的很细，从上到下分别是额或题、脸、腮或颐、颊、颌、颏、颌；
4. 现代汉语将面部统称为脸。
