# 171【题】金榜题名与额头

老潘提示：订阅读专栏后，文稿中的象形文字可戳可点，放大来看，细细品读。

# 识字卡片

![](bbox=[0.1, 0.11, 0.9, 0.28])

参加过高考的人，都经历过题海战术。题几乎是所有考生的梦魇。可是你知道题的原意竟然是人的额头吗？

# 1.题是额头

金文，左边是“是非”的“是”，右边是表示头部的“页”，是“题”的本字。是，上面是日省，下面是止，表示向正确的方向发展，原意是正直。表示端正的“是”和表示头部的“页”合起来，表示头部的正面，特指额头。篆文，承续了金文的字形。

![](bbox=[0.1, 0.43, 0.9, 0.52])

古书里有“雕题交趾”的说法，雕题，是在额头上刺青。南方有的少数民族，比如蛙龙族，有在脸上、尤其是额头上刺青，用以辟邪。美观。原意是由于长期赤脚走路，大脚趾分得很开，两脚并在一起仿佛能够相交，也指南方少数民族的特点。后来交趾指今天的越南。这里的“题”，很明确是指人的额头。

# 2.题是高端

由于额头是人脸最上端、最显眼的位置，因此引申为物品的前端或顶端。

孟子曰：

说大人，则刍之，勿视其巍巍然，常高欲切，榷题（cui ti）数尺，我得志，弗为也。食前方丈，侍妾数百人，我得志，弗为也。后来饮酒取妍，得田邑千乘，我得志，弗为也。在彼者，皆我所不为也；在我者，皆古之制也，吾何畏彼哉？

孟子曰：“向权贵进言，要藐视他，不要看他那高踞高在的样子。殿堂几尺宽，屋檐几尺宽，我要有得了志，就不这么干。面前摆满美味佳肴，侍妾有数百人，我要有得志了，就不这么干。饮酒作乐，驰骋打猎，就千乘方土跟田，我要有得志了，就不这么干。他们的所作所为，都是我所不愿干的；我所愿干的，都是符合古代制度的，我为什么要怕他们呢？”

这里的“榷题”，就是房子的前端，即房檐。

# 3.题是最上面的字

由前端，进一步引申为标题、题目。

北宋词人晏殊是个神童，有一次皇帝在宫廷对于余名学子考试，《宋史》记载：晏殊从容镇定，援笔立成。后来皇帝复试诗、赋、论，晏殊看了题目说：

臣尝练习此题，请试他题。

意思是“我自己练习的时候温习过这篇赋，请出个题。”高中还不高，讲究的就是押题。一旦押中，欢呼还来不及，哪敢让考官换题啊。这境界，实在差的太远了。

由题目，引申为书签、标签、标志，进一步引申为奏章。如：题骈是奏本弹劾，题本是上奏章，题请是上奏呈请。这些用语在现代中文中还有的使用。

# 4.题是正式的文字

秦篆是正式文字，所以一些正式的书写也就叫题目了。如题款是在书画上署名或题字。题诗是写书面语、题字是墙壁上写字。题署是书写文书封简，也叫签署。题壁是在墙壁上题诗写字，苏轼的诗：

横看成岭侧成峰，远近高低各不同。不识庐山真面目，只缘身在此山中。

标题叫《题西林壁》，就是题写在庐山西林寺墙上的。

金榜题名是正式公布的榜单，古时候是读书人的梦想。

# 总结一下

+   1. 题的原意是人的额头；

2. 额头是人脸上端的显眼位置，引申为事物或物品的前端、上端；

3. 由上端，引申为标题、题目，进一步引申为奏章；

4. 由奏折是正式文字，所以正式文字也用“题”，如题词、题诗、试题、金榜题名。
