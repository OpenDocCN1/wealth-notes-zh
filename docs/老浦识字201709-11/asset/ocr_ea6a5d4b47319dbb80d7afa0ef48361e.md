字“一隻鬱鬱的台湾烏鴉。”较前最后一字，乌龟的“乌”，这个字虽然不常写，却也很有意思。

乌鸦的大嘴和眼眼睛

乌也是一个象形字，金文字形 (icon) 就是一只大鸟，和金文“鸟” (icon) 的区别主要是突出了硕大的鸟嘴 (icon)，表示这种鸟有别于一般的鸟，是乌鸦的象形。

篆文字形 (icon) 是将“乌”字字形中表示眼睛的一点指导符号去掉，表现这种鸟浑身黑色与羽毛中不容易分辨出黑色的眼睛。想想着，乌鸦最大的特点并不是鸟嘴的巨大而是通身皆黑。

太阳鸟的悲剧

乌鸦在古代神话传说也是神鸟，传说太阳中有三只鸟，所以古代常常以用“乌”作为太阳的称呼。如：乌阳是太阳，乌轮是日轮，乌始是旭日，乌照是日光，乌飞兆走是时光流逝，红日暗没是日落等等。

![](bbox=[0.1, 0.38, 0.9, 0.41])

《楚辞·离骚》中有这样的记载：“尧时十日并出，草木焦枯。尧命羿射十日，中其九日，日中九鸟皆死，堕其羽翮，故留其一日也。”这记引了后羿射日的传说，说尧帝时十个太阳一起出现，草木枯焦，尧帝就命令后羿射下太阳，结果射下九只三只鸟，特意留下太阳维持宇宙正常運行。古人想象中的太阳，就是有三个爪子的乌鸦。

怎样沦为不吉利的象征

和龟一样，乌鸦从太阳神鸟沦为扫把星，这是怎样发生的呢？

是因为它黑。由于这种鸟遍身黑色羽毛，自然引申为黑色。乌黑、乌亮、乌衣、乌贼、乌龙头、乌纱帽、乌烟瘴气等等。

也是由于黑色，引申为没有、不存在：乌有。《史记。齐世家如传》中说：“乌有先生者，乌有是事也。”

古代用黑色和白色代表死亡，乌鸦全身黑色，叫声难听，更重要的是，乌鸦嗅觉灵敏，能闻到腐肉的味道，在古代成了战争尸横遍野、赤地千里的经典场景，所以人们常常感觉乌鸦不吉利。

枯藤老树昏鸦，小桥流水人家，古道西风瘦马，夕阳西下，断肠人在天涯。乌鸦的形象构成了经典的凄凉场景。

简化字的“乌”与古代造字原理一脉相承，与“鸟”的区别在于少了眼睛，但字形的美感上，还是欠缺了一些。

→ 总结 ←

+   1. 乌的原意是乌鸦的象形；
2. 乌在远古是太阳神鸟，后羿射日剩下的就是这样的三足神鸟；
3. 由于乌鸦遍身黑色羽毛，引申为黑色，进而引申为没有的事，乌有；
4. 象征死亡的乌黑，沙哑的叫声以及常常出现在古战场尸体旁边，构成了乌鸦不吉利的印象，逐渐成了不吉利的象征。
