
# 175【涔】流泪和流涕原来是一回事

痛哭流涕是眼泪鼻涕一起流吗？不是，痛哭流涕的“涕”在古文中是眼泪而不是鼻涕。

### 1. 涕的原意是眼泪

金文的“涔”上面是“雨”，表示水，下面是“米”，表示像米粒一样的泪滴，米的右边是“弟”，弟的本意是射鸟弓箭“弭”。“弭”上有缠好的丝线，表示有条理，有次第，在这里表示眼泪不断地次第流下，本意就是眼泪。

篆文去掉了“雨”，并将金文的“米”写成“水”。

隶书进一步简化，成为我们今天使用的字形。

很明确，涔这个字的造字原意就是眼泪。《诗经·卫风·氓》中有诗句：“不见复关，泣涕涟涟。”这里的泣涕涟涟，很明显是眼泪。这是表现爱情的诗句，上下文是这样的：“乘彼垝垣，以望复关。不见复关，泣涕涟涟。既见复关，载笑载言。”意思是说看见倒墙的墙头，眺望复关的方向。看见了不见复关方向的心上人，眼泪直流。看见了心上人，就又是说又是笑。这是多么纯真的情感啊。

我们现在还在用的成语痛哭流涕、破涕为笑，都是原意。

那鼻涕是什么字？

是“泗”，《诗经》中有“涕泗滂沱”这样的诗句，毛传在注解中说：“目自曰涕，自鼻曰泗”，就是说从眼睛里流下来的叫涕，从鼻子里流下来的叫泗。

《庄子·马蹄》：“天加之以衔勒，齐之以月题。”请解读“月题”。

月题是马额头上的月牙形装饰，后借指马。衡是车辕前面的横木。扼是马马颈的柔术。这句整体的意思是：马本来是在大自然中是自由自在的，后来人给它装上了束缚它的装具，装饰上貌似漂亮的饰品，马于是就非常难受，与人对抗，这都是伯乐的事。庄子的思想是给马东来，让马漂亮，会让马暴露。圣人的快乐思想同样是给人束缚，只会使人玩弄智巧，追名逐利，让社会更糟。

### 【题】金钩题字与额头

古“池”词义经常变化，池，池，是池塘。但是在上古，池河意思是《礼记·礼运》有一句话：“大人世及以为礼”，城郭沟池以为固。请你根据“池”的象义文字和这句话分析一下“池”字的意思。

池由“水”和“它”构成，“它”的原意是蛇，表示这是像蛇一样的水系，特指护城河。《礼记》的这句话是说现在“大人”也就是城市世家，并用礼法来维护，修建高高的城墙和深深的护城河来守卫。其实池塘本是池的引申义，现在本意已经不用了。成语“金汤城池”还是原意。

# 177【恨】原本并不激烈

这是唐代诗人白居易的《长相思》，描写了一个女子斜靠在小楼上，面对涛涛江水思念亲人的情景。其中，思悠悠，恨悠悠的“恨”感到有点违和，由爱生恨是人之常情，但从全诗的意境看，女子还不是如此激烈的感情啊。

### 1. 恨其实是怨

其实，在古文中，恨的用法原本就不是我们现代汉语这样激烈：仇恨、愤恨，而是埋怨、幽怨的意思，和“怨”的用法正好相反。

恨的篆文是“心”字旁，表示一种心情。一个“艮”。艮的甲骨文是“自”下一个和目相反方向的人，表示向后看。金文字形把眼睛斜竖起来，进一步强调向后看的含义。

艮的原意是回头瞪眼，和“心”合起来表示一种幽怨、遗憾的情绪。咱们开头白居易的诗“思悠悠，恨悠悠”用的就是原意。

恨在古文中主要是遗憾的意思。《史记·淮阴侯列传》中，韩信被项羽为大将早，刘邦郑分析形势，在韩信与项羽的缺点和刘邦的优势以后说：“大王之于武关，秋毫无所害，除秦苛法，与秦民约法三章耳，秦民无不得欲大王王秦者……大王失取入汉中，秦民无不恨者。”

这里的“恨”，就是遗憾的意思，说刘邦约法三章，秋毫无犯，秦朝都城的老百姓都希望刘邦能够称王，却被项羽排挤到汉中，老百姓都很遗憾。

《说文解字》：恨，怨也。说恨就是怨。《荀子·尧问》中有这么一句话：“处官久者士妒之，禄厚者民怨之，位尊者君恨之。”

意思是说当官时间长了知识分子忌怨你，发财了老百姓恨你，官当大了君王怨你。这里的恨，是情绪最轻的字眼。

### 2. 怨其实是恨

在古代，恨的程度比怨轻，实际上是不满的意思，仇恨的意思用怨，不用恨。

《史记·信陵君列传》有个故事：秦国新任宰相范雎（jū）原来是魏国两个官员的门客，被国魏国齐坏起兵围魏救齐国差点被打死，“以怨魏齐外交，秦王闭关，于是要发兵伐齐，率兵围困大梁。这里的“怨”，是仇恨的意思。

信陵君魏公子无忌招贤纳士，门客三千，名声很好。他曾经礼遇了看门人侯赢和屠夫朱亥，秦国攻打赵国，信陵君很想发兵救赵，但魏王担心秦国通敌部国，不敢发兵。信陵君决定豁出去了，带着门客一百来辆战车去拼命，临走向侯赢辞行，不料侯赢只是淡淡地说好好您去吧，老夫没法跟行了。信陵君走出几里路越想越闷，自己曾经如此厚待这位隐士，怎么就要撒手说死了，这么老爷子这个态度，越想越气，返身回来。问，侯先生：“公子往而臣不送，以是知公子之反也。”您出发死而为臣不送，知道您心中不满。这里的“恨”和前面的“怨”正好相反，是不满的意思。侯赢给信陵君出了一个妙计，让信陵君请求魏王的宠妃如姬偷出虎符，调动十万大军营救赵国，并推荐屠夫朱亥随行，击杀了不肯听命的将军，成功为赵国解围。这就是历史上著名的“窃符救赵”的故事。

现在，恨字的感觉更强烈，恨之入骨、怀恨在心。而怨则感觉激烈程度减轻，埋怨、幽怨。

- 总结
  1. 恨是心加艮，艮是回头瞪眼，恨的原意是遗憾；不满；
  2. 古文仇恨的含义是怨。信陵君窃符救赵的故事中同时出现了“怨”和“恨”，和现代汉语的用法正好相反。

# 178【yúliù】没头脑的小鸟不靠谱

**字源演变：**

| 甲骨文 | 金文 | 篆书 | 楷书 | 行书 |
| :--- | :--- | :--- | :--- | :--- |
| 缺 | 鸟 | 粤 | 138 | 翠 |

**文字原意：**

这个形象是小鸟丰满起来展翅飞翔，同时是高空风声的象声词。

【《说文解字》“羽列”APP出品】

### 1. 翠很飘逸

汉字很美，有的造型直接就是艺术品，你看这个字形，多有动感，这个字的另一种写法也很美，这是“翠”字，是小鸟羽毛丰满，展翅高飞的樣子，你看高扬起的翅膀，多么有力，而翅膀下面有两条斜杠，是翅膀带起的风声，因此这也是高空风声的象声词。

《庄子·齐物论》有言：“而独不闻之翠翠乎？”这里的“翠翠”，就是风声，高天上的风声。

### 2. 翠很空阔

现在“翠”这个字已经不单独使用了，由于展翅高飞，所以由这个字符组成的汉字都有着蓝天白云的空旷辽阔。

例如:
- 加上宝盖头翠落的“翠”，就是空虚无形的意思；
- 加上水字旁的“翠liáo”，就是清澈的样子，“源于其清”；
- 加上竖心旁的“翠liáo”，就是依赖的意思。

李商隐有一句话：“楚雨含情皆有托，漳滨卧病竟无翠。”就是说他的雨水都有所寄托，自己生病时最依赖亲昵，人在生病的时候感情上最依赖亲昵，李商隐的“翠”字，把那种无所依凭的感觉写得很传神。

### 3. 翠是错误

有意思的是，“翠”的展翅高加上表示语言的言字旁，“”，竟然是差错、违背的意思，这是怎么回事？

仔细看“翠”的字形，你会发现一个奇怪的现象，那就是字形的鸟儿没有脑袋。大概是表示这时候的小鸟在没头没脑的乱飞。

说出来的话好像没头脑的鸟一样乱飞，靠谱吗？

这就是谬论，这样办事就会出谬误。

### 4. 希腊神话里的“翠”

这让我想起一个希腊神话故事。

伊卡洛斯是艺术家代达罗斯之子，代达罗斯计划把鸟儿的羽毛用蜂胶粘在一起做成翅膀让上天空逃走，伊卡洛斯一起兴致勃勃地帮助父亲，于是父亲决定带着儿子一起飞走。

“你要当心”，父亲叮嘱伊卡洛斯，“必须在半空中飞行，如果你飞得太低，羽翼会碰到海水，沾湿了会变得沉重，然后会被拖入大海里；要是飞得太高，翅膀上的羽毛会因靠近太阳而着火。”

两个人鼓起翅膀渐渐地上升了天空，父亲飞在前头，伊卡洛斯兴高采烈，羽翼在飞翔很快，开始拍手拍。他纵跳着羽翼朝高空飞去，他飞得太高了！强烈的阳光融化了封蜡，羽毛开始松动、完全敞开，从他的双翼上飘落下去。不幸的孩子一头栽落下去，掉在汪洋大海中。

这个故事其实反映了人类最原始的梦想：像鸟儿一样生出翅膀飞起来。

而伊卡洛斯的故事故表现了人类的轻狂付出的代价，当然是有极限的，不能太高，也不能太低。

而汉字“翠”所表现的，其实也是这个道理：像没有头脑的小鸟一样乱飞，这样说的话是错的，这样的空间“翠”是空洞落落的，这样的心情“翠”是依无依靠的。

- 总结
  1. “翠”的原意是小鸟羽翼丰满开始展翅飞翔，同时也是高空风声的象声词；
  2. 由翠组成的汉字都有空阔的含义，如寥、涤、修；
  3. 翠的字形是没有脑袋的小鸟，寓意乱飞，所以加上言字旁表示错误谬误。
  4. 希腊神话伊卡洛斯装上翅膀飞翔海而亡，反映了人类飞翔的梦想，表现了人类轻狂付出的代价，而“翠”，与这个故事表达的意思是一样的。

# 179【鬱】忧郁的“鬱”真的那么难写吗？

**字源演变：** yù

**文字原意：** 甲骨文“郁”是“林”字（森林）与一个跪坐人形结合，表示人躲在林中；后来演变为“鬱”，增加了香草和酒坛，表示酒香浓郁。

一隻鬱鬱的台灣烏鴉。你用繁体字把这句写一百遍。

这是一遇繁简之争就会被搬出来的杀手锏，这句话还可以无限延长出很多笔画繁复的汉字，以证明繁体字的确是该淘汰了。

这其实是一个伪命题，因为你把输入法设定为繁体，键盘输入，速度和简化字一模一样，不存在方便不方便的问题。至于你喜欢不喜欢这个字，那是个人爱好的问题了，有什么必要争论呢？

不过我们还是来找一个难的字来认识一下，忧郁的“鬱”。看看听了《老浦识字》以后，这个字难道难写。

### 鬱的原意是欺负人

甲骨文郁是在一个树林里一个人大大咧咧地踩在一个人 的身上，表示踩踏、欺负人。在这样一个密林里被人压迫，受欺负的人当然感到郁闷，所以引申为塞、怒、郁结、郁闷。还有一个甲骨文形更加明显，同样是在树林里，一个人骑在 下面的人身上 或 就像俗话说的，骑在人家脖子上胡作非为。

另一种甲骨文是调制香酒的过程

到了周代，这个欺负人的字和“壸（chang4声）”组合起来了，壸是一个盛酒容器的形状，中间的小叉子表示香草，小点表示酿酒的后果，意思是祭祀用的香酒，引申为茂盛。

这两个字组合，用踩踏的含义，表现了制造香酒的工艺：把香草捣烂，即踩踏，煮出汁液来调和已经酿好的香酒，使其味更加浓郁。于是形成了一个新的字，这就是“鬱”了，同样引申为茂盛、浓郁的含义。

### 篆体的“鬱”

篆字鬱把这个过程更加细致了，同样是在林子里，上面的人形变成了一个陶罐缶（fou4声），表示装酒的器皿，下面的缶还在，增加了三笔刻划，表示香气。而这个香气，被一个秃宝盖封住了。

这个字叙述了这样一个过程：将香草和粟米混合、捣烂，装入陶罐酿造，然后封口，以免香气逸出，然后存放在树林里，供祭祀和隆重的宴套使用。现在我们说的特别难写的繁体字“鬱”，基本延续了篆文的写法。

郁字的本义是制造香酒，香气浓烈，引申为茂盛、富含有香气。古人在使用这个字的过程中，当然会感到物极必反，于是，这浓郁的香气也引申为腐臭。

《荀子.正名》中说：“臭、美、芬、郁、腥、臊、酸、臭，以鼻辨。”这里的“郁”，就是腐臭的含义。

这样把气味闷起来，当然就引申出心情烦闷、忧愁、郁结。

### “鬱”的简化字：郁

为什么简化字是“郁”这样的写法呢？

其实这个郁郁 是古代的一个地名，是今天的陕西省咸西县，由于读音相同，简化字用这个字来代替笔画繁复的“鬱”。

### 写一个字，讲一个故事

现在我们再来讲一遍这个“鬱”字：

你来着一个树林，发现一个陶罐“缶”，揭开盖子，里面是香草“艹”和米“米”酿成的美酒，用勺子“舀”尝了一口，香气“三撇”扑鼻，感觉真是寻到宝了。

当然，你要急着写报告正郁闷，直接用键盘敲出来即可。

- 总结
  1. 郁的第一个甲骨文本义是在树林里一个人踩在另一个人身上踩踏欺负，下面的心里很郁闷；
  2. 郁的第二个甲骨文增加了表示祭祀香酒的壸，表示捣烂香草，煮成汁液，调和香酒，使之气味更加浓烈；
  3. 郁的本意是祭祀用的香酒，引申为浓烈的气味、茂盛、物极必反，又引申为腐臭、阻塞，进而引申为心情郁闷。
  4. 繁体字的写法笔画很多，但内涵丰富，应验了你陈寅恪的话：每解读一个汉字，就是解读一部文明史。

# 180【忧】什么事情这么挠头

接着看“一隻憂鬱的台灣烏龜”这句话，憂愁的“憂”。

汉字象形简单，会形简单，就是简单画呗，但是对于抽象的情绪怎样表现呢？站在古人造字的角度，怎样表现忧愁的感觉呢？

你想想来，我们发愁会怎样表现呢？抽烟喝酒，来回踱步，还有，也许会下意识地挠挠头发。

> 李白说：白发三千丈，缘愁似个长。
> 杜甫说：白头搔更短，浑欲不胜簪。

说的都是在挠头。而忧愁的忧，甲骨文的字形正是古人在挠头。

### 憂就是挠头

憂，甲骨文是一个人双手拖面，步履沉重地来回踱步的样子。金文增加了一个大脑袋，抬起一只手，正在挠头。这不正是我们愁绪满怀的样子吗。

篆文用“页”来规范头部，增加了“心”，表示这是心理活动，恢复了“止”，表示步履沉重，一个忧心忡忡，步履沉重的形象跃然纸上。

忧的原意就是愁闷、忧虑、担心。

隶书基本承续了篆文的字形，上面是代表头部的“页”，中间是“心”，下面是侧着的“止”，表示行走，踱步。后来一直使用的繁体字“憂”，是这样的字形。

《汉字简化方案》用“忧”字合并“憂”字。

简化字的“忧”为什么和“憂”字形差异这么大呢？

### 忧是怨恨

原来“忧”这个字形也是古代就存在的字形。

篆文是一个竖心，表示和心情有关，旁边是“尤”，原意为突出的，格外的，特别的。例如：尤物是绝美的女子；完全没有道德底线叫做无耻之人。引申为怨恨、归咎。什么意思？说人怨恨归咎。和“心”合起来表示一种特别、抱怨的心情。

> 《说文解字》：忧，心動也。和发愁的“憂”不是一回事。由于发音相同，笔画较少，就把“憂”合并为“忧”。

### 忧国忧民

“憂”本来是一个略有褒义的宇。

《孟子·告子下》：“然后知生于忧患，而死于安乐也。”这段话是在那段著名的“天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤”，之后，意思是说人忧愁使人生存发展，安逸享乐使人萎靡死亡。
