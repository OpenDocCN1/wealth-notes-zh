# # 富 章

# ## 201【章】文章可以通天吗？

在山东曲阜孔庙，有一副对联：与国成纬，安富尊荣公府第；同天并老，文章道德圣人家。

上联中的“富”字少上面一点，宝盖头成了秃宝盖。下联中的“章”字下面的一竖一直通到上面。

有个帖子说：错字的妙处在于，“富”不出头，意思是“富贵无头”；“章”字下的一竖出头，则表示“文章通天”。

不用说，这又是文字游戏，有想把字写错，形成新的趣味。这里涉及两个字：“富”和“章”，富字比较简单，咱们先说“富”。

# —— 识字卡片：富 ——

![](bbox=[0.1, 0.59, 0.9, 0.85])

家里有酒才叫富

富文是“宀”下面一个“畗”。“宀”是个代表房子的宝盖头，里面有酒缸。

古代生产力低下，粮食产量有限，只有丰收，有剩余才能酿酒。因此家里有酒象征丰裕，这就是富的原意。

“富”字在篆文印章中是有秃宝盖的写法的，目的是让印面美观。

楷书、行书中也一直存在有秃盖的写法。

这是唐代柳公权的楷书：富

这是唐代陆柬之的行书：富。这属于书法家的艺术处理，不能算错。

# —— 识字卡片：章 ——

![](bbox=[0.1, 0.00149, 0.9, 0.00175])

再说“立早章”就外行了

咱们再来说说“章”。

我们平常会说“立早章”，但这个字的原始含义并不是“立”加上“早”，而是“音”加上“十”。上面表示乐音的“音”，下面是表示长度的“十”。“十”在甲骨文就是一竖，后来才加上一横。

“十”是十个数中最大的数，也就是音乐中结束的部分，本是祭祀音乐中一个乐段的结束。

在古代，祭祀是非常庄严的仪式，每一段音乐都有相应的舞蹈。在周代的雅乐中，歌颂美的乐段叫《大章》，表示这一乐段是最重要的部分。

苏轼在《赤壁赋》中有“诵明月之诗，歌窈窕之章”，就是用“章”字的本意。

由乐章，引申为文章的段落。

《文心雕龙》：“积句而成章，积章而成篇。”比较清楚地说明了篇和章的关系。

由文章的段落，引申出显、明确的含义，即“彰”。

《淮南子》：“钟之与磬也，近之则钟磬音充，远之则磬音章。”说钟和磬作用不同，钟的声音远，磬的声音传得远。这个“章”，实际就是“彰”。

由彰显，引申为标记，印章、图章。

说说错别字的问题。我们已经看到金文的“章”部一竖是贯通的，《说文解字》定型为“音”加上“十”部，那一竖的贯通就同时存在。

这是汉代的《乙琰碑》：章

这是王羲之的行书：章

所以从书法的角度，这一竖贯通上去并不是曲阜孔庙的发明。不过把这两个字的特殊写法对应，的确很妙。

# —— 总结 ——

+   1.“富”的本意是房子里有存酒，说明粮食丰收，家境富裕；
2.“富”的宝盖不加点，自古就有这样的写法，不能算错；
3.“章”的原意是祭祀音乐的段落，引申为文章的段落，章节。再引申为彰显，最终引申为标记，印章、图章；
4.“章”字下面的一竖从贯穿写法到不贯通，但在书法上有一种存在贯通的写法，所以贯通的一竖不是孔府的发明。
