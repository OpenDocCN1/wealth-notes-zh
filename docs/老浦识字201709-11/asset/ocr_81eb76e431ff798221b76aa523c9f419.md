# 1.“乳”的原意

甲骨文的“乳” [甲骨文字形] 是一个跪坐的女人环起双手，形成一个温暖的环抱 [甲骨文环抱字形] ，环抱里是一个张着口的孩子，就像嗷嗷待哺的小鸟 [甲骨文字形] ，在母亲的怀抱里幸福地吃奶。

![](bbox=[0.3, 0.615, 0.7, 0.67])

秦竹简文是秦小篆之前的篆文，字形 [秦简字形] 去掉了环抱的双臂，换成一只手套着孩子的头，身体简化成一个优美的弧形，这是母亲乳房的象形。

篆文 [篆体字形] 基本承接了秦简的字形。

隶书 [隶书字形] 进一步简化，成为我们今天使用的字形。

# 2.“乳”的引申义

> 《说文解字》：乳，人及兽生子曰乳，兽曰产。

《说文解字》的解释是生孩子，这应该是“乳”的引申义。

乳的本意是哺乳，自然引申出奶汁的含义。乳汁，乳酪，乳脂、乳香、乳臭未干。

同样由于哺乳的含义，引申为女性胸部分泌乳汁的腺状器官，乳房、乳腺。

莫言有一部小说《丰乳肥臀》，这是农村传统完美女人的标准，表示这个女人的生殖能力强大。

哺乳的原意还引申为哺乳期间的动物。《荀子·荣辱》：“乳羔（zhī）犹虎，乳狗不远逐，不忘其亲也。”

最悬野猪，乳彘是哺乳期间的野猪，出于保护孩子的本能，这时候的母猪可以很虎搏斗。 而哺乳期间的母狗也不会离开很远，以照顾孩子，这些都是动物亲情的表现。

所以要注意，《庄子》中：“禽剑鸣声，卢如乳虎”中的虎不是小老虎，而是哺乳期间最凶猛的母老虎。

![](bbox=[0.2, 0.98, 0.8, 0.001035])

同样，在现代汉语中，代表哺乳期间的小动物，乳猪是小猪，乳燕是小燕子。

乳，这个代表母性的汉字，是最温暖的汉字。

# 总结

+   1. 乳的原意是人类哺乳,是会意字，字形就是母亲温暖的环抱；
2. 哺乳，本意引申出与哺乳有关合：乳汁、乳房，进而引申出生孩子；
3. 哺乳还引申出哺乳期间的动物：乳虎、乳彘、乳狗等等，这不是指吃奶的小动物，而是指哺乳期间的动物，和现代汉语的用法不一样。
