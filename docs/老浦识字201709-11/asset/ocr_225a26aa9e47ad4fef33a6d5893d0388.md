# 182 [问答] 优和虑分别代表了什么？

欢迎到你《老浦识字》，今天是问答时间，我来为你解答一下本周的思考题。

甲骨文“艮”分化出很、恨、很、狠三个字，请你分析一下另外两个字的含义。

老浦

都是回头瞪眼，“恨”是加上双立人，双立人是行的简写，表示道路、行为，“恨”的原意是违逆、不听从小。猴加上犬字旁，表示相斗，形容凶恶，好勇斗狠。

![](bbox=[0.2, 0.38, 0.85, 0.52])

甲骨文鸟的形象字形很多，这个字形是一只长尾鸟，旁边有一个指示符号，你来猜猜，这是什么字？

老浦

这是“风”，用长尾鸟长长的羽毛来展现风的效果，指示符号像船帆，表示风的力量。

![](bbox=[0.2, 0.67, 0.85, 0.78])

商朝超级好酒，所以甲骨文关于酒的很多，这里有一个字形，是一个跪坐在人酒坛旁，酒坛上还有三个点，请你猜猜这是什么字。提示一下，和咱们今天讲的这个“誉”有关。

老浦

这是配合的“配”，原意是配酒，中国古代的酒是粮食发酵产生的，酒精度很低，祭祀的时候会用专用的茅草过滤，为了增加香气会用草调配，因为古人认为香气会令鬼神祖宗高兴。

![](bbox=[0.2, 0.95, 0.85, 0.00103])

高级文字能够精准表达事物非常细微的差别，汉字无疑在这方面及其传神。

这是一个大篆字形，由“虎字头”和“思”组成，猜猜猜猜这是什么字，并分析这个字与“疑”、“忧”的微妙区别。

老浦

这是忧虑的“虑”，虎字头表示危险的大事，这是面临危机的思考。“疑”是大概念的考虑，担忧。“忧”是比较极端的情绪，忧愤；“虑”是面临危机的思考。

现在这里有一个汉代的“花钱”，是当时用来辟邪、表示吉利的不流通的货币，相当于咱们今天的纪念币，请你猜猜这是什么字。

![](bbox=[0.15, 0.0014, 0.85, 0.0015])

老浦

这是“唯言知足”四个字，它巧妙地利用了铜钱的方孔做四字共用的“口”字。

背面的字是常规的“长乐”。
