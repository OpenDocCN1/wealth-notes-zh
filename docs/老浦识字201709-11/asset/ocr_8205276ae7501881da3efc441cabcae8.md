# 164【问答】什么东西是向下生长的

欢迎来到《老蒋讲字》，今天是本周的问答时间，我来为大家解答一下本周的提问哦。

吹是跪坐的人形张嘴打哈欠，这种跪坐的人形有很多字，这里有一个字形，从甲骨文到金文是这样的：

![](bbox=[0.1, 0.16, 0.9, 0.18])

你来猜猜看这是个什么字？

老播
这是“欠”，表现一个人囫囵嘴巴地大放厥词，原意是“恣（zì）态”，后借用作“不在前面，不稳重”，即“次、次品、次等”等。

![](bbox=[0.05, 0.24, 0.95, 0.34])

在高州时期，货币是贝币，所以与货币有关的事都是贝字旁，如货、财、贸等等。而钱是金字旁加上两戈相击的“金”。臧也是秦代出现的字，请你分析一下这个字的含义，为什么仙儿的刀就就臧藏呢？

老播
贝代表货币，而“臧”是两戈相击，表示贝戈相斗以后的碎片。碎片就是小，和贝合起来表示价值很低，引申为卑下、低贱。

![](bbox=[0.05, 0.41, 0.95, 0.51])

波和漂都是把水抛出去，漂的甲骨文是水字旁有个鸟巢（），也就是“沔”。请你分析一下，这两个字的微妙区别。

老播
漂是水淋到鸟巢，星星点点滴下来的状态，表示用水往地面上洒开来打扫房间。《说文解字》的解读就是“浑”，意思是清洗。漂字治家很古早有“黎明即起，洒扫庭除，要内外整洁。用字都是原意。漂和泼的区别是，泼是没有控制的把地面淋湿，而漂是猛力向外、有控制。一个有控制向外，一个无控制向外。

![](bbox=[0.05, 0.58, 0.95, 0.68])

“信”和“任”可以连用，组成“信任”这个词。【信】我们以前也学过，你可以点击文末的延伸阅读讲义一下，然后请你分析一下，这两个字的差异。

老播
信任者的内心，有担当，引申为信任。信是巫师在神前的誓言，信誓旦旦，由于有神灵作证，誓言保证会被执行，引申为诚信。信任有两个：一个是自身有能力去承担获得信任，自证；一个是自身有力，来从外部获得信任的力量。

![](bbox=[0.05, 0.75, 0.95, 0.85])

生是小苗向上生长，这里还有一个甲骨文（），它是向下伸根的，请你猜猜，这是什么字？

老播
这是“才”的字，横画表示地面，横画以下表示向下伸发的根系，横画以上部分表示草木正生刚发出的嫩芽，在古汉语中必通“才”和“材”。它告诉我们，要想成才，必须得根基扎实。
