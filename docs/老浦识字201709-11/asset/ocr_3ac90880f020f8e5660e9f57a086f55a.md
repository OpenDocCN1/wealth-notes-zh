# 1.“解”的原意

但是“解”的甲骨文却一点诗意都没有，甚至有点血腥。甲骨文（image_link_placeholder）是双手（image_link_placeholder）握着牛角（image_link_placeholder），下面是牛（image_link_placeholder），表示把牛角从牛身体上拆卸下来，解牛。取牛角，是刮牛最后一道工序，表示拆解完成。我们都学过《庖丁解牛》，用的就是解的原意。

金文（image_link_placeholder）的字形承续了甲骨文。篆文（image_link_placeholder）把手改为“刀”（image_link_placeholder），表示用刀片解牛，原意不变。

![](bbox=[0.1, 0.46, 0.9, 0.55])

解的本意是分解动物。古丁解牛由于对牛的结构了如指掌，游刃有余，目无全牛，踌躇满志。这些成语都出自庄子这个名篇。由分解动物，引申出不同的含义，也形成了不同的读音。

# 2.“解”的多种读音

读解（jiè）是原意和原意最直接的引申，解体引申出离别、分开，土崩瓦解。然后由有一个重要的引申：宽恕、土崩瓦解。解绳就是解、释放，引申出解释、了解、和解、解放、解冻、解缆、解药、解气、解释等。

读解（jiè），唐时举进士的人由地方推荐发送入京称“解”，由此引申为押送犯人时戴的枷锁；押送犯人的路上有开水给犯人冲凉，第二天又故意给犯人一双新草鞋，让犯人折磨得够够。在野猪林要不是鲁智深相救，林冲命丧在这个两个解差的水火牢下了。这个解，其实也是由解绳、解束缚引申过来的。

读解（xiè），这是通松弛的僻，假肢假解，就是日夜都不松懈。这个读音，旧时指杂技表演的各类身手，特指骑在马上表演的手；束缚、紧张、赛马驰骋。使浑身懈开、就是要用尽了浑身解数。

在用作姓氏时也是xiè这个读音，《水浒传》中的解珍、解宝，当代歌手解晓东都应该读这个音。

# 3.为什么上厕所叫解手

元朝末年，战乱不断，加上水旱灾，老百姓死亡，真是赤地千里，荒无人烟。而山西地区由于比较偏僻，受到战乱的影响比较小，人口相对富盛。明朝政府就有计划组织移民，把居民从山西迁到原来很繁华但人民力少地区。主要迁往北京、河北、河南、山东、安徽、江苏等18个，500多个县市。迁移长达50年之久，经过上百年的辗转迁徙，繁衍生息，而今全球及有华人的地方就有大槐树移民后裔。

官府在广济寺集中移民，并给所迁之民以耕牛、种子和路费。寺旁老有一棵“问身数图，荫遗败政”的老槐。当地官府人员在树下为被征之民办理手续，登记造册，按名地点，然后发给一些物品。所以大槐树就成为移民的象征。

移民是被迫迁徒的，为了防止逃跑，路上老百姓都被绑起来的，需要上厕就喊官兵解手，解手就是这么来的。定居后下，解手这个专门的词，作为时代记忆被保留了下来。据说，背身的习惯也是这一历史事件的遗存，喜欢背手思考的人，可能就是大槐树下的移民后裔。

# 总结一下

+   1. 解的原意是解牛，引申出分解、离散、分开；
2. 由解手绳结，引申出脱离、释放的含义；
3. 解是多音字，读解（jiè）是押解护送到处，释放，读解（xiè）意思通解，同时指马戏表演的招式。姓氏也读这个音；
4. 解手这个词来自明朝初年迁山西大槐树移民，因马被绑起来被迫迁徙，被绑住手，上厕所时喊绑着官兵“解手上的绳索”，后来“解手”的用法被保留下来了。
