# 200【问答】“明”写成“日月”是对的吗？

![](bbox=[0.1, 0.22, 0.9, 0.35])

**字源演变：**
**第一声 di**
甲骨文
小篆
隶书
楷书

**思考题：**
《史记·孙膑传》记载：齐国孙子自田忌曰：“君弟子重射，臣能令君胜。”田忌信然，与王及诸公子逐射千金。
及临质，孙子曰：“今以君之下驷与彼上驹，取君上驷与彼中驹，取君中驷与彼下驹。”既驰三辈，而田忌一不胜而再胜，立得王千金。
请分析“君弟重射”当中的“弟”的用法。
**答案：**
这个弟还是读“次”第的读音。意思是：您就按照次序，把大上的赌注下。所以这样就是以引起注意。

**思考题：**
表示房屋中间柱子的甲骨文 咱们以前讲过，你还记得这是什么字，怎么解读吗？
**答案：**
这是“余”，是地支的其中中间支撑房顶的木柱，古时候“余”在甲骨文中就是表示支撑房顶的木柱，后来借余来表达自己的谦辞。

这是弱“孺”的“孺”，意思就是由于多胞胎导致孕妇的身体，本来是虚弱。

**思考题：**
咱们在正文中没有分析过“院”，“完”咱们分析了，左耳刀以前和“限”字是相见的，现在请你分析一下，“院”字怎样理解？
**答案：**
左耳刀，由“阜”（fù）变形而来。“阜”本义为土山、悬崖，在这里代表围墙。围墙围起来的相面，表示有围墙的建筑，后引申为寺庙、官署、学校。

# · 冬 ·

![](bbox=[0.2, 0.0016, 0.8, 0.0017])

**字源演变：**
**冬 dōng**
甲骨文
小篆
隶书
楷书
**思考题：**
在“明日犯粗的别部字”那个帖子里，还有个“出现次数最多的错字”，明天的日月“明”写成日目。《老渊解字》有一篇专门解“明日”，但没有涉及这个日月“明”字算错字吗？现在你来分析一下，“明”算错字吗？
**答案：**
在《“明”解》那一期中，甲骨文明有两种写法。
一种是“囧”加“上”，表示地穴式建筑天窗照进来的月光。
另一种是日月同，表示日月同时出现在夜空的时候的意象。
所以后世一直都存在日囧和日月明加日并存的局面。
就栖书写者，囧加月是通假，“月”加“日”则是加月的简称，不能算错。
