# 151【款】大款会款款而来吗

老铺识字：订阅专栏后，文稿中的象形文字可戳可读，放大来看，细细品读。

# —— 识字卡片 ——

![](bbox=[0.2, 0.33, 0.75, 0.42])

款代表钱，而且是大宗的钱，所以商业经营付钱叫打款、付款，借钱叫贷款，民间把有钱人叫大款、款爷。

但是很奇怪，款字不仅没有铜臭味，还有很多美好的用法，比如感情好叫深情款款，风度好叫款款而来，服装样式叫款式，文人书画签名叫落款。款的用法真是多样。

# 1.款的原意是烧柴祭天

款的甲骨文 左上边是“木” ， 木的下面是表示祭祀的“示” ，木上的木头与祭祀有关；右边是表示手的“又”，合起来表示用指搭建木柴堆，焚木祭天。

还记得咱们以前学过的“柴”字吗，还有“帝”字，都是古人用香木焚烧后祭天，祈求香烟甘霖的隆重祭天仪式。现在藏族地区还保留着焚烧松柏，用烟祭祀山神的煨桑仪式。

![](bbox=[0.2, 0.82, 0.8, 0.9])

款的原意是用木柴祭天，表示虔诚、恭敬。由于香烟袅袅上升，所以也有缓缓上升，从容不迫的含义。

金文 把手形换成表示吟诵的“欠”，表示向天祈求，祭天的原意不变。

篆文 承续金文形制。篆文异体字 中的“木” 写成“出”。

隶化后楷书 则将篆文字形中的“出” 写成“土”。

《说文解字》对款的解释是：款，意有所欲也。

意思是说款的意思是内心有所欲求。这显然是根据篆文形制 做出的分析，“示”上面是“出”，旁边是表示吟咏的“欠”，是巫师祈求神灵，表达人类欲求的意思。可惜这不是甲骨文原意。

款的原意是用柴祭祀，虔诚地祈祷咏叹，就有了真诚、深情的含义。

# 《史记·司马相如传》

谒（yè）款天神。

款款深情、款款而来，都有这个意思。

唐代元稹《冬日忆蔡》：吴宫夜长宫漏款，帘幕重重灯焰暖。这样的描写，描写吴王宠幸西施，整夜欢愉的场景。“宫漏款”，是指漏壶里计时时的沙漏缓缓地流动，这里的款，就是缓慢、从容的含义。

# 2.祭祀之款如何成为青铜器上的款识 (zhì)

款字源于柴燎祭祀，有真诚祈求的含义。而在古代青铜器上，有些会铸造上一些文字。古代把铜称为金，所以这种铸造在青铜器上的文字就叫金文。金文的内容一般都是说明铸造这件器皿的原因，讲述青铜器的功绩，天子赏赐的荣誉等等。这些青铜器都是用来祭祀的，这些文字和柴熏的青烟一样，都想要向上天、祖宗表达祈求的，和款识有同样意义，所以这些文字就叫款识。

![](bbox=[0.2, 0.00172, 0.8, 0.0018])

正式的、真诚的文字叫款识，那么缔结盟约、同样需要警告上天的条约文字就叫做条款。

公文、书信最后郑重的签名，就叫做落款。

大宗钱币往来，必须要有字据，字据上必须有落款负责，所以，大宗钱币往来的钱就叫做款项，引申为大宗金钱的代名词。

# —— 总结一下 ————

+   1. 款 的原意是用柴祭祀上天，所以有虔诚、缓慢的含义；

+   2. 青铜器上的铭文同样用于祭祀，因此被称为款识；

+   3. 款识是真诚郑重的文字，所以盟约文字叫条款，字据签名叫做款；

+   4. 大宗金钱往来必须有字据，字据必须有落款表示负责，所以大宗金钱就叫款项，由此款项引申为大宗金钱的代名词。
