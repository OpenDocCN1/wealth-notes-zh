# 152【问答】赖原本是个美好的字

《三国演义》为了树立人物形象，常常张冠李戴。刘备的形象很仁厚，所以就给他戴孝服。刘审之的形象仗义，（三国演义）中还有一些张冠李戴的事，比如《草船借箭》，描述诸葛亮用计向曹操“借箭”，挫败了周瑜的暗算。你知道草船借箭真正的主人公是谁吗？

+   老浦
草船借箭真正的主人是孙权。据《三国志·吴书·吴主传第二》裴松之注，建安十八年（公元213年）正月，也就是赤壁之战以后五年，曹操与孙权在安徽巢湖一带对垒。初次交战，曹军大败，于是坚守不出。一天孙权乘轻舟从濡须口闯入曹军前沿，观察曹军部署，孙权的轻舟行进五、六里，曹操见孙权整肃威武，嗔然曰：“生子当如孙仲谋，刘景升儿子若猪狗一样！”一种记载是曹操下令不得轻举妄动，故走了孙权。还有一种记载是曹操下令弓箭齐发，射击吴营。不一会，孙权的轻舟因一侧中箭太多，船身倾斜，有翻沉的危险。孙权下令调转船头，使另一侧再受箭。孙权鼓乐齐鸣，安全返航。

李斯为统一文字第一，他创立的篆文也称为小篆，这里有一篇李斯书写的《峰（yì）山碑》，你来分析一下，对比甲骨文、金文，小篆有什么特点？

+   老浦
1.小篆第一个特点是符号化，很多象形会的特征在这里消失了，成为整齐划一的符号，这也是文字发展的必然。

2.字体大小均一，笔画粗细相同。

3.笔画间隔均匀、协调、上下松不紧。

4.用小篆某一文字写得有失，小篆失去了甲骨文、金文的古朴天真，象征含意，显得呆板。因为笔画过于均匀，缺乏个性，所以很快就被更加自由的隶书和更有艺术性的楷书、草书取代。

5.由于小篆均匀标准的特点，十分适于印章，直到今天，印章还在使用这种字体。

“纠”和“绳”是近义词，古文也有纠绳连用的，表示盘查纠正。绳的篆文 **绳** 是左边一个绞丝旁 **纟**，右边一个“黈（min’）” **屯**，黈是青蛙。请你分析一下这两个字的区别。

+   老浦
黈是蛙类，跳跃有力，声音洪亮，所以有“用力，努力”的字义，绳强调这是像青蛙那样有力量壮壮麻麻，比纠字更强调力量。

+   老浦
甲骨文是用青铜刀契装在龟甲兽骨上的，由于材质有限，所以甲骨文都是刚硬的直线。金文是在铸造青铜器之前，用毛笔先在内模上写好，然后用青铜刀把文字挖成浅槽，浇铸成模具，在挖造青铜器时，浇钢铜汁成器。由于是浇铜而成，所以线条
