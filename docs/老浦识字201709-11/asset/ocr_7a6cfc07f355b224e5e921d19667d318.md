# 156[控]控的关键在于引而不发

# 识字卡片

控现在是个挺新的字眼，有什么爱好就是什么控，比如我们人人都是手机控，意思是说大家被手机控制住了。

# 1.控是拉弓射箭

控的原意和射箭有关。篆文的“控”![](.../images/045b826c0a128396856c3638150a5b7b.jpg)是提手旁![](.../images/8d1f0e2f86a35a00e24d2371b539f65f.jpg)加上一个空气的空![](.../images/d1d0b6b0e2b1496a0822826851f28523.jpg)，空是虚无、穷尽的意思，拉开弓弦必须穷尽力量，而思维也必须虚心穷究，进入到空的状态，因此控的本意是拉开弓弦，引而未发，引而未能那个瞬间。你一定记得我们在谈“引”字的时候，谈过“弓”![](.../images/8499425027574871402e5b5d02408296.jpg)，那是把箭搭上弓弦拉开的一瞬间，控则是拉开以后停下来瞄准。

《说文解字》：

控，开弓也。

![](bbox=[0.3, 0.53, 0.7, 0.62])

控和引实际上是一个动作的两个阶段，所以这两个字也可以互换，控者引也。

# 2.控者是伸展委屈

控者引也，而段玉裁在《说文解字注》中说：

> 施弦于弓曰张，钩弦使满，以竟矢之长曰张。是谓之引。

意思是说引是张，张是把弓弦拉满。控由于有引的意思，就引申出控告的含义。因为人体屈曲，委屈肯定难捱，伸展开张就会释然，控是引，是开张伸展，控告就是受到委屈以后控诉的伸展，所以控告引申为控诉、控诉。

控制也是引的引申。勒马止步，和拉开弓第一样，都是引的动作让马止步。控，就引申为拉住马缰绳控制住马的意思。

# 3.高明的控制是引而不发

《三国演义》有七擒孟获的故事，说的是当时蜀国属地向南边睡有少数民族叛乱，诸葛亮接受为了马谡（su）“攻心为上，攻城为下，心战为上，兵战为下”的策略，七次抓获诸葛亮长孟获，又七次释放了他，直至孟获心服口服。

这种服人心方法说明是“控”字引而不发的最佳例子。引，就是说以武力为前提，不服来战，战则胜之。但并不赶尽杀绝，直到你心服口服。

这当然是《三国演义》小说的演绎，但真实的历史也确实如此，诸葛亮通过军事征服加上攻心策略，成功平定西南少数民族叛乱。平定以后，不留守，不运粮，让少数民族高度自治，保证了边境的安宁。所以至今云南、缅甸地区还有诸葛亮崇替，可以说诸葛亮是解决少数民族矛盾最成功的代表。清人赵藩在成都武侯祠有一副你颂诸葛亮的对联：

能攻心则理自消，从古知兵非好战；

不审势即宽严误，后来治蜀要深思。

![](bbox=[0.1, 0.95, 0.9, 0.98])

对联意为：用兵能攻心，反叛就会自然消除，从古至今，真正善用兵者并不好战；不审时势，政策或宽或严都将会差错，后来治理蜀地的人要深思。控，要有高度的智慧。

我常常想，要是美国人好好学习这副对联，反思也不至于越反越惑。

# 总结一下

+   1. 控的原意是拉弓射箭引而未发；
2. 由人体的屈伸，控引申为控告、控诉；
3. 由引的原意，引申出勒紧马缰；
4. 诸葛亮七擒孟获是引而不发控制局势的典型。
