# 识字卡片

这次来日本，在参观位于京都的伏见稻荷神社的时候，禅师现见这个是神社正在进行盛大祭仪式，神职人员先是进行一番祷告，我注意到一个神父手持带树叶的大树枝四处挥动，口中念着词，显然是进行清戏，意为祛除邪气，祈祷吉祥。

重头戏是燃火仪式，塔殿中央的台地上早已堆好捆扎成方盒形状的稻谷和木柴，当他们点燃柴堆的时候，冲天盖起的白烟令人十分震撼。

![](bbox=[0.1, 0.39, 0.9, 0.45])

白烟是神友们不停洒水的结果，在火堆正中，一个神父手握人们祈福的木签，恭敬地行礼仪以后，投入火堆。自古以来人们就相信，火一方面能够清洁空气，祛除邪气，另一方面能够把人们的祈愿通过香烟上达天听，焚烧了许愿的木签，就等于向上天表达了心愿。

这样的仪式中国商代就有过。以前我们讲过“柴”，这些平常烧火做饭的树枝原意是用于燎祭的香木。

燎的甲骨文 是“木”的周围有很多小点  ，表示火星和烟雾，下面是“火”  ，正是表现焚烧柴木燎祭上天的意思。

燎祭是远古时期极其重要的一种祭祀神灵的仪式，是氏族的头等祭祀典礼祭祀上天，祈求雨水，保佑风调雨顺。

在祭祀仪式上，不仅焚烧木柴，还会放上玉帛、牺牲，出土的高古玉器常常带有被火焚烧的痕迹，就是燎祭的标志。我们在谈柴字的时候谈到古代表焚烧柴木祭祀神明，是燎祭最高等级的代表。古代典籍还记载皇帝登基、到泰山祭天，都要举行燎祭仪式。

日本神道大极是祭祀稻谷神，清拔祈祥，保佑家庭幸福、身体健康、商业兴旺。

在咱们中国西藏，至今还有松柴祭祀的习俗，叫做煨桑。煨桑就是用松枝松枝架起的需高坛祭天地的诸神。松枝用松枝、柏枝、椐枝，献酒供茶，敲钟百言，添嘛呢祈轩。

据说在煨桑的过程中产生的烟雾，不仅使凡人有舒适感，山神也会十分高兴。

# 燎的金文

燎的金文  和甲骨文区别不大，仍然是火烧木柴。

篆文  在火和木柴之间，增加了“日”，这时候字义已经发生了变化。

> 《说文解字》说：“燎，烧田也。”

意思是说燎是放火烧田，一方面开荒，刀耕火种，一方面焚烧后的灰烬是草木灰肥料。所以燎引申为大烧的火，这也是星星之火可以燎原的含义。

唐代杜牧在《阿房宫赋》中说：“‘一发’可以燎阿房。”意思是说一支火把就能把阿房宫烧掉，也是星火燎原的意思。

燎的隶书  把“火”用作偏旁，成为我们今天仍然在使用是字形。燎字进一步引申，为表面的火，如liáo 3声），比如眉毛被燎了，加羊肉食烤毛，脚上打了燎泡等。而庭燎，是指在庭院中用火把照明。

# 总结

+   1. 燎的原意是焚烧柴木祭祀，在古代，这是最高等级的祭祀仪式；

2. 在日本神社、我国藏族地区，仍然保留了焚烧木柴产生白烟祭祀的仪式，用以清祓污秽，祈福迎祥；

3. 燎字后用于烧田，引申为大烧的火，继而引申为表面的火。
