3.广东省无领导面试尚处于发展阶段，培训机构的竞争格局还没有完全形成，考公学习体系也仍存在值得进一步钻研的空间

# # 2.如何进行引流转化

# 2.1 选择什么渠道

市场上永远不缺好的内容，缺的是好的渠道。在正式投入宣传之前，我们做了几件事：

+   对所了解的渠道做了简单分析，制定了相应的策略

| 渠道 | 特点 | 策略 |
|---|---|---|
| 抖音 | 娱乐化内容为主，适合碎片化时间消遣娱乐 | 不适合作为宣传阵地 |
| 快手 | 地域性较强，主要以生活化的内容链接用户从而给到用户情绪价值，“老铁文化”浓厚 | 不适合作为宣传阵地 |
| 小红书 | 高粘性、高互动值重于年轻的女性的内容平台，强调真实，具有精致、高审美等特征待 | 需要持续输出内容，本次不参与 |
| b站 | 年轻一代高度聚集的视频平台，内容创作更偏向创意趣味性 | 不适合作为宣传阵地 |
| 微博 | 具有强大的“转发”功能，可以让信息在不被宣传的情况下快速传播，比较容易产生意见领袖 | 发起超话主题争取主持人 |
| 贴吧 | 围绕某个“吧”聚集的有相似兴趣或是需求的人群，用户较为集中，用户发帖功利一致，制造内容的门槛较低 | 寻找有需求的帖子进行跟帖 |
| 知乎 | 以“问答/话题”为基础，关注话题的用户都是需求导向的用户，触达更精准 | 以上岸考生视角发布备考经历 |
| 论坛 | 与贴吧类似，但渠道更小众，流量或许不大，但竞争相对也小 | 发布拼单/求资讯的帖子 |
| QQ群/微信群 | 精准聚集具有需求的一群人，自发讨论、邀请，并且是私域生态，转化链短 | 点评野场，展示教学专业性 |
