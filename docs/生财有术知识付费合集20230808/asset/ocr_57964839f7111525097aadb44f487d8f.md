于是我到处搜罗小红书的引流方法，但是几乎每一个都是有风险的。最后我确定了3个较为安全的引流方法。

# 1，直播引流。

这个引流方法算是最安全的，具体的操作方式就是，建一个小红书小号，在首页发布一篇带有自己微信号的笔记，然后在直播的时候，小号在直播间发弹幕。接着本人在直播间说“想要学习的小伙伴可以看XXX（也就是小号的名字）”

这个方法效果还可以，亲测一场直播下来，场观20的情况下，引流10人左右没问题。

# 2，大小号配合引流

这个情况就是有人私信的时候，我会转发小号的笔记，或者用小号主动私信这个私信我的人，让他看我第一条笔记。

# 3，图片手写微信号引流

这个很好理解，就是手写自己的微信号，然后拍一张照片，发照片给主动私信的人。

我交替着用这三个方法，目前账号挺安全的，没有啥违规情况出现。
