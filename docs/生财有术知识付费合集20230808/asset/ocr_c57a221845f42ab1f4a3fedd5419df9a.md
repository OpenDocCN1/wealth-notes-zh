# 醒醒同学🏷️
📍 #优势咨询日记

一个人感受到价值感要么来自关系，要么来自工作上的反馈，教练这个职业同时具备两个要素，做的好时价值感能飙到外太空。做教练2年了，还没厌倦。

昨天给一昊解读，我开玩笑说：真是一言不合回家继承家产啊。他和我讲，学了很多东西还是感觉怪怪的，接手家里的生意后优化了效率，降低N倍的成本，但为什么总感觉最近两年不得劲呢？

我们聊到他是怎么帮朋友一晚上搞定行业报告不以为然时，在每个对话当口给他反馈“思维和行为是如何产生的”，解读进入了心流状态。他也明白了自己到底是怎样的，擅长什么。祝福他再下一城！

一昊的文字，我有点受宠若惊，自觉功力还不深厚，来日方长，5年10年后再看吧。

如果把优势解读比喻成打麻将，那么优势报告就是你的底牌，我是旁边那个能看到你的底牌怎么打上优势，怎么打上劣势
