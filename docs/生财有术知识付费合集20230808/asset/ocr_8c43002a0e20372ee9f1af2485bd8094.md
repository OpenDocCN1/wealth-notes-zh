# 七、啥是好企业？

茅台。毛利。净利。溢价。库存。很多企业的问题是库存贬值。没有数字化运营的话很难确定他的库存要保持多少。生产和零售端的平衡点很难。

你的公司具不具备长期产生现金流。

支不支持你的毛利率长期稳定在30@%。

支不支持你的库存率一直维持在一个维度。
