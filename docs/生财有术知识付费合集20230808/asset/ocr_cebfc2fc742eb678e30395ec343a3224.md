# 试看只是吸收，拔高是了解你的问题

![](bbox=[0.52, 0.2, 0.85, 0.26])

所以，我会直接约个时间和学员「语音沟通」，让学员短时间学到一些东西，让他们了解我的能力。

我一般会问问学员之前是怎么备考的，是自学，还是报了下线班，是初学，还是想拔高，然后我会就某个具体的面试题型，短时间讲解应该怎么架构一道题，怎么展开一道题，现场传输一些面试干货。

这样就会让学员现场学到一些价值的内容，让学员通过沟通直观了解我的能力，这样一通操作下来，基本就可以顺利成交。
