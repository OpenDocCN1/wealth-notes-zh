# 二、规划与设计课程

其实我并不觉得“规划”这个词用在这里合适，因为并不是一开始我就想好了五套课程怎么做，它们更像是“生长”出来的。

# （1）课程设计制作方法

第一套课程，取名《PS 亮化效果图制作技巧全解密的》，这个名字我琢磨了好些天才定下，

“全”：代表课程内容全面且多，事实上也的确如此，一共 68 个视频，8 大不同场景的案例，外加从业这几年自己制作整理的 30 多个 G 的独家素材材料库，毫无保留地全部给到。

“解密”这个词也很好，有神秘感，让人向往去获得。

那课程到底是怎么设计出来的呢？

其实就是围绕一个核心的“认知方法论”来打造的，后面几套也是同样的方法和思路。
