# b.达人选品法

通过火爆的品A，筛选出头部落单的达人，使用飞瓜对达人号进行带货分析，找到他们正在带的其他品如品B品C，再进行线索追踪。

找到延伸的品后，有可能这个达人对该品的出单销量并不理想，那我们可以继续回到【商品搜索】这个功能栏去寻找品B品C的头部落人，按照这个逻辑就能一路往下延伸，尽可能去挑选更多达人喜爱的品。

这个选品法的核心逻辑是把众多达人的选品化为己有。
