别扯什么“严师出高徒”，当个领队/志愿者/助教，咱就是严师了？况且，换个更尊重对方的做法，也没有多难，反倒更能给对方勇气，比如“做这个的时候，关注到这个方法可能会比较好。那关于这一点你是怎么考虑的？”下次想要骂志愿者/船员的时候，不妨试试别那么居高临下地评论、指责，而是更平视地沟通，相信会有不一样的效果。

| 你 · 讯息 | 我 · 讯息 |
| :---: | :---: |
| 断定的 | 委婉间接的 |
| 客观的 | 主观性的 |
| 逻辑理性的 | 带有情感感受性的 |
| 评论性的 | 参与性的 |
| 居高视线 | 平行视线 |

3、不直接教导：上一次大航海，我们队最让我自豪的一点，是几乎每位志愿者都做到了“八仙过海各显神通”，每个小组都有自己独特的玩法，而且最后都出来了让人眼前一亮效果。为什么我们队志愿者都这么有想法？因为我真的尊重他们的想法，鼓励他们大胆去尝试；而不是指示一个接着一个，搞得他们除了听从指挥，别无他法。

前文中聊过我对大航海的理解，它不是福特汽车厂里拧螺丝的活儿，大家乖乖听指挥干活儿就能有好的产出；而是一件非常重要的挑战，要充分发挥大家的积极性、创造性，才可能有新的突破。作为领队/志愿者，我真的觉得引导和鼓励，才会带来更多的惊喜。

|  | 讲授法 | 教练法 |

| 正确答案所在地 | 教师（上司）手中 | （客户）部下手中 |
