# 2.5 入局B站的建议

最后，对于入局B站，我有三个建议：

1.做真实的自己，与用户深度链接。不需要去建构假太空的人设，而是让自己的热爱去吸引同频的小伙伴。表达自己真实相信的观点，没有对与错，更多是自我的真实展现。

2.公域转私域做起来，让好的用户逐步沉淀在自己的私域当中，把B站作为商业化版中一个灯塔的存在，吸引同频热爱的小伙伴加入，散发出一个个很强烈的信号。

3.理解B站的生态，去看更多的内容，感受里面的弹幕，评论和玩梗的氛围，融入每个圈层，不要太在意每个用户对你的差评，持续做自己爱做且擅长的内容，只有热爱和专注才能走得长远。
