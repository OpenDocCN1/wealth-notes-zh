# 杨晶晶

每天都是这样的，十几项工作挨个过。当然也有完不成的时候，但是会尽最大努力。

有小伙伴咨询我时间管理的问题，说脑子惦记很多事，总是无法付诸实施。

我说：写下来，预估时间，然后模块化管理，如果上午能有空闲20分钟，就去做一件20分钟之内能做的事儿，然后把它划掉。妈妈时间都严重碎片化，如果每次还要去想应该做什么，大概率是这个时间就在“想”中度过了。我以前上班的时候要挤时间学习，就是这样管理时间的。

小伙伴又说啦，把要干的事情都写出来，如果干不完，会很自责。

我说：那就建立一套合适的自我反馈机制。如果我完成1件事，就给自己打60分，完成两件，80分，完成3件100分，完成4件就是附加分。剩下那些没做完的，只是为了提醒我自己明天别忘了。如果1件都没干，那就还是反思一下好了。
