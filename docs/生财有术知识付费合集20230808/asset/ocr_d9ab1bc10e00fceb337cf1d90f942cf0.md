# 第四，变现话术怎么说。

我的成交话术有这三个阶段。

+   第一 主动询问账号情况

+   第二 指出账号目前存在的问题，并且说明适合的服务，诊断or陪跑（提到价格）

+   第三 营造自己很忙的氛围，这样既可以快速结束聊天，也能让别人知道不能白嫖

其实成交话术是其次，最重要的还是朋友圈的打造。
