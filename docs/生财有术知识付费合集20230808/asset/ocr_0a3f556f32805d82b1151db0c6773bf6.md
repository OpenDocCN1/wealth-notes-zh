# 二、制作封面、详情页

封面、详情页建议用图片展示。使用创客贴、稿定设计等在线设计工具制作，有课程详情页模板。封面和详情页是非常重要的一个环节，是给学员的第一印象，一定要好好设计。

好好设计并不是说要做得天花乱坠，而是让用户清晰地、一眼就能找到他想要的答案。

好的详情页应该包含以下内容：

+   - 课程解决的是什么问题

+   - 学完以后会怎样？

+   - 都学习那些内容？

+   - 为什么要跟你学？

+   - 秀肌肉（讲师个人实力）

+   - 秀案例（学员评价等）
