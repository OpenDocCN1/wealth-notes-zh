# # 1、你身边是谁，决定你成为谁

有一本著名的书叫《富爸爸 穷爸爸》基本上讲的就是，如果你来自贫穷的家庭或许你可以奋斗一生，并且努力挣钱，但终究还是一无所获。

但如果你来自富有的家庭，也许你可以愚昧一生，但仍然可以是人生赢家。

过去我曾做过很多浅层的一些行为，比如刻意练习改变思维，刻意去做某些动作。

实质上思维、认知并没有发生实质结果改变，只是一些堆量的结果的。

这个实质改变，其实还是自己的潜意识。

举个例子，我们工薪阶层出身，从出身就被父母、亲戚灌输的要找一个工作，去打工就是意识层的东西。
