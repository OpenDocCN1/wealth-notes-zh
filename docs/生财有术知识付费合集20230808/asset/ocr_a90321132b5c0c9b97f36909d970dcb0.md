# 过去：一直在学习，却感觉不到明显的进步

过去这十几年，我和大部分成年人一样，越来越感到缺乏学习的内在动力，没有确定的学习目标，一开始自己是沉浸在各种网络和媒体的狂轰乱炸中，每天刷着手机上被大数据推荐来的泛滥信息而不自知。随着全球数字化进程加快，各行各业和周边环境都瞬息万变，危机感常使我焦虑不安，中途也有过各种形式的学习，但不是太片面或琐碎，就是缺乏自己的深度加工过程，学习往往变成了理论的灌输，实践起来总是有一种“臣妾做不到”的感觉。

# 现在：学到的一切都运用于实际，生活具有了鲜活的意义

加入匠心之后，我的学习目标感，学习的持续动力和思维的逻辑条理性都有提升，青艳老师的专业和无私，社群小伙伴们的积极和包容，时时带给我向上的力量，逐渐建立起好的学习习惯，更重要的是，有理论有实践有反馈有复盘，我的学习在不知不觉中就完成了闭环。正如青艳老师在课程中说的：感觉好才能做得好。
