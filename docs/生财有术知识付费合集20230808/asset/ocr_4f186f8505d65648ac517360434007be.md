先分享一个简单的自查公式，相同人数的朋友圈，当所有人卖同一个还算可以的产品时，不同人的朋友圈内容质量和频率共同影响了我们能收多少钱。

+   高质量 低频=有钱赚

+   高质量 高频=赚翻了

+   低质量 高频=被删除

+   低质量 低频=少钱赚

这里说的质量不是说文字写的多么华丽、专业，而是是否能让人听进去、听得懂、触动得了人，且和你要卖的产品和服务是相关的，看是否有人持续点赞、评论。

高频和低频不用说了，是发圈频率。

如果还是普通人甚至是素人，我们至少绝不要低质量 高频，**努力朝高质量 高频努力**，参考我的好朋友梁靠谱女士，没有一个人逃得过她朋友圈。
