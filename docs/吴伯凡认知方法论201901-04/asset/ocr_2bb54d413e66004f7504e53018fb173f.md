# 特别放送 | 一份清单：
那些能提升认知的书和
电影

吴伯凡

今天特别放送一份清单，是课程前三模块中提到的，有助于提升认知的书和电影（影视作品）。其中绝大部分都不是难啃的大部头，比较轻松，但也许会对你的一生产生重大的影响。而且这份清单中的内容都非常精彩好看，即使看过了，也非常值得在空闲的时候反复品读回味。

你也可以在App里搜索书或电影的名字，查看相关的课程来辅助理解。
