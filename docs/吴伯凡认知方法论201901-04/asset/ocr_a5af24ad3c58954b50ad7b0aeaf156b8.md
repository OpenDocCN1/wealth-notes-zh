# 故事一定包含着事故

1.意外：故事的第一个要素

我们常常说生活中充满了故事，那些告诉你怎么写故事的书首先会告诉你：故事的第一个要素就是“意外”。

比如，有一天你要到南方出差，买了飞机票，搭乘某趟航班到了目的地，办完事情待了两天又坐某趟航班回来了——这显然不是一个故事，这里没有任何意外。

故事一定要有意外：你订了某趟航班，结果由于某种原因取消了，这就是一个“意外”。但仅仅是“意外”还构不成故事。意外发生，又一条线被展开了，比如航班取消，你寻找另外一个航空公司的一趟航班，但买票的时候发现票全部被卖出去了。正当你绝望地要离开，有个人来退票了一—当意外出现了一个别开生面的节点，这才是故事的开始。

一句话：故事一定要有意外，而意外的发生是一个别开生面的故事线的起点。
