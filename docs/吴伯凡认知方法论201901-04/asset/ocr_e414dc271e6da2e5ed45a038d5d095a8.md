# 给予者和贸易法则

@ 星光旺妾

这节课讲的和我知道的一句谚语有关，“人无所求品质高”，说一个人 Ryd 不求别人给什么的时候，品格自然高尚，这和老师讲的是不是一个概念呢？

应该说，咱们讲的“三无”原则和这一句谚语有相通之处，还有一句俗语“人人不求人一般大”，也是这个意思——不管这个人比你地位高多少，多么有钱有势，只要不求他，你和他在精神上就是一样大的。
