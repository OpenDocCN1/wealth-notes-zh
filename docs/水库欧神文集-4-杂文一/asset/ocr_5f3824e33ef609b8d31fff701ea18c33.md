# 二） 崇祯

首先我们来讲“明史”。明末的灭亡，是中国历史上，最不可思议的一幕之一。

崇祯朝，十七年。

一直到崇祯十六年，“朝廷”还占据着绝对的优势。

天下九州，崇祯十六年的时候，李自成还困在河南。祸害不过一省。潼关的口子，无论如何也打不通。

张献忠被左良玉层层压迫，逃递湖南。

辽宁省有“建奴”。建奴兵锋虽然厉害，可却是年年闹饥荒。

以辽宁吉林苦寒之地，根本养不起十万大军。全民皆栋的结果，皇太极每年为吃饭发愁。

只要官军紧守关隘，不求胜利。三年不被抢，建奴就得裁员。
