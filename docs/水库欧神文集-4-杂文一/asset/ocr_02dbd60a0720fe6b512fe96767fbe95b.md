# 二）无可匹敌的力量

王陶陶的口号，叫做《无可匹敌的力量——群众运动》。

他列举了非常多的例子。例如法国大革命时，最精锐的近卫师团，可以对抗英国熊帽军军战斗力爆表。可是却被巴黎暴民们撕得粉碎。

俄国沙皇尼古拉二世的统治，随着饥饿的妇女开始冲击圣彼得堡。近卫军瓦解。阿芙乐尔炮声奏响。
