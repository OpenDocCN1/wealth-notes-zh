# 都市民宿完全不赚钱

就和黄焖鸡米饭一样，提供的是千篇一面的住宿产品。
而屌丝消费者，关心的唯一就是价钱。

淘宝网上的“小 c”店，铺天盖地。简单计算有几千万家。
开淘宝赚钱了？No，马云爸爸赚钱了；
你们的盈利，都交马云“排序保护费”了。

同样的道理，如果说有“短租平台”剥削民宿业主，肥了平台饿死房东。那精准指向“都市民宿”。

你提供的是毫无差异性的产品。
每一个城市，都有数以万记的分租房东。
他们或许仅仅是普通白领，或许是退休夫妇。仅仅想“分租”一个房间，赚取一些额外收入。

他们并没有自己的房间特色，也没有流量渠道。
甚至连细心的打扫，都做不到。

这些“都市民宿”高度依赖平台市场。平台推荐哪家，哪家就有订单。
相应地，利润也被平台褥毛拔得精光。
最后只剩一个辛苦钱，平衡在房东愿不愿意“贴补家用/增添麻烦”。
