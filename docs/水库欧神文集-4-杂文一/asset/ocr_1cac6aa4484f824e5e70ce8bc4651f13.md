# 一言以蔽之

中国民主制度，尤其是人民代表制度的优越性主要体现在两点。

+   1：人民代表制度选上来的代表可以是坏人，而且发言也是很容易被公认是坏人，同时他完全代表自己的小群体，根本不用太考虑外界无关的评论，他的核心依然支持而且会更加支持他。

+   2：没有竞选，至少是没有强烈的全局竞选，商业介入也非常少，即便能介入也不划算。同时投票周期不算长而且比较隐秘波动大，所以根本是以前的利益怎么来就怎么说，管你三七二十一我先吃饱再说。
