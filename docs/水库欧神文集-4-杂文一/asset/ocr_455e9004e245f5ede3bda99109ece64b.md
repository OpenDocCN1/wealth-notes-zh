# 秦时明月汉时霜 ------ 我的租客孔二狗

去年春节回家去文中的主人公家去玩时,无意中翻开了他那本满称你市黑社会形成法字典影,感慨颇多,从第一页翻起,看到最后一页:

不变的东西有二样。1,这位社会大哥一直坐在最中间,2,拍照片时这群流氓头子都笑的像朵花,,灿烂极了。

变的东西有三样。1,照片上每年的人都不一样,摆摊的人或许是因为被杀了或者是为被正法了或者是为跑路了或者是因为正躺在医院里或者是因为在服刑或者是因为换病了,2,影像我越往后翻,觉得里面的人的眼神越来越复杂,尽管他们都笑的很开心,3,从深蓝的确良布料中山装到深蓝色毛料中山装到白色中山装,然后再白衬衣大红领带到最后的黑西装西领带,衣服越来越讲究。简直就是一部我国男性正装 20 年的演变史。

像期里 90%的人我都认识,他们的人和事我都如知道个大概,看到有些人我想落泪,看到有些人我觉得惋惜,看到有些人我觉得不齿。从那天起,我决定写点东西。

先贴一段正文,这是孔二狗在写《黑道风云二十年》时的开场白。

抹过苍白的页册,这些人这些事,似乎也过去了许多年。

所以我决定把他们写出来,在这一光年的距离,留下一点记忆。
