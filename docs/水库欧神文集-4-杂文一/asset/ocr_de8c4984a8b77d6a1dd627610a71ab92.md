# 二）模型

“人民币对外升值，对内贬值”
“大排面迟旱涨到 30 元一碗”。

今天社会上对于“外汇储备”的关注，可以上溯至我在 2004 年天涅写的一篇文章 2004-07-31：《人民币面临巨大的贬值压力》 $ ^{[2]} $

在文中，我们提出了一个模型：

+   - 人民币被低估
- 西方社会要求人民币升值
- 人民币坚持不升值
- 西方美金通过各种渠道进入中国，兑成 RMB
- 央行被迫吃进 USD，印刷 RMB，增加 M2
- M2 增加，房价大涨

在 2001 年末相互捧持时，全社会的 M2 仅仅才 11 万亿。
截至 2017 年春，全社会的 M2………

呢，M2 数据已高度造假。表外资产不计其数。我们改用另一个数据：金融 业总资产。

目前这个数据是 260 万亿。

+   - 16 年翻了 25 倍
- 平均每年+21%
- GDP 每年+9%
- 缺口每年+12%

在过去十六年中，京沪深宁等大城市，房价涨了 15 倍左右。

从 6000~7000 的水平线，一路涨到目前的 100000+

相应的，则是被折磨得麻木不堪的中产阶级。
一辈子的积蓄，只能够买个一室户。

当这股力量太强，太长，太折磨之后。
