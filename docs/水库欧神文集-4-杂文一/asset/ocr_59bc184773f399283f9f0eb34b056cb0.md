# 三）下里巴人的女性

在现实生活中，一个“凯珍”这样的女性，绝不会有着倾国倾城的美貌。

她很可能长着猪肥的4分脸，啤酒肚的小腹。

绝不会有“我见犹怜”的优雅，而可能是举止粗俗，谈吐庸俗。

当她12年后，年老色衰，在一家不入流歌厅献艺。也只会唱同一首歌。

更有可能，是坐在粉红色灯管的洗头颅房。

在你的心目中，除非家里缺一个清洁打扫干粗活的阿姨。否则你的人生，绝不会和她产生交集。

车是我妈给的，房子也是。我俩父母都是普通人，最大的愿望是孩子有一份坐办公室的工作，风吹不着，雨淋不着。但其实这个愿望也没实现。我常看着安全帽站在路边指认工人树。

如果算准点，我俩的工资足够生活。而且结婚收到十几万礼金后，我以为至少能逃个两三年。谁知，不到一年，我的闺女就来到了这个世界上。

生孩子之前的儿女，虽然都贵精，可毕竟次数有限。等生完才明白，原不过这几日用品，才是最烧钱。因为它是加速性消耗。100多一包。平均每天要买20多块。

其它硬件也不能委屈了，婴儿床要高景观，带小伞和脚蹬，3000元，婴儿床要实木无甲醛的。商场特价的，也是3000多。几百块的仿品婴儿床，据说可以模仿妈妈的子宫，把宝宝全方位包裹进去，不买个独特安感感。一块软软的安抚巾100块。据说孩子握在手里就像抓住妈妈的手。

不要是天底下以为这就是全部，我光逛超市。横看时就圈了2000多块钱的。还有各种玩具和婴儿用品。孩子一岁半前都是口腔期，要通过咬东西认识这个世界。都买食品级的硅胶牙齿玩具，小一块正常。

就这样，女儿出生10个月后，结婚时收到的礼金已经一点不剩了，我们成了实实在在的空囩人口。最近，身边的人都在劝孩子报早教班。一节课接近200块。我的钱包实在太不够花。想了想。只好再洗多下几单绘本，准备自己在家教了。
