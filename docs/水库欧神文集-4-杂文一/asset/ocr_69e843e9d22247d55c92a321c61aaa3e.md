# 选美

MartinParr在耶鲁的演讲中指出：“我从来没有遇到过一个支持退欧的人，正像在座的各位大多数没见过川粉一样。”一语成谶。

我是一个温和的精英主义者。人类历史反复表明，知识人在一个开明的社会中永远负有特殊的职责。一个受过良好教育的人，其政策主张常常更具有理性。我相信普罗民主，但是我更相信开启民智。而在教育事业中，知识人依然是中坚力量。作为耶鲁人，我不避讳我作为知识精英的自豪。如果没有天生斯文的气概，华夏文明恐怕难以坚持到今日。而西方文明之所以能在近二百年深重的灾难中不绝如缕，也正是依靠了深厚的知识人传统。真正的知识人应该 有对民意说“不”的勇气。川普的胜选并不说明我们错了，只是说明我们的任务有多艰巨。

真正可怕的，不是美国的川普和日本的安倍，甚至不是俄罗斯的普京和朝鲜的金正恩。真正可怕的是我们作为知识人，丢失了为人为学的方向，是我们不再敢择善固执，或者是在中产阶级的舒适区中产生智识的惰性。与其躲在象牙塔中哀号，不如切实反思：我们为抵御全球变暖做了什么？我们为保障性少数群体的权益做了什么？我们为非洲和海地的饥民做了什么？我们为纽约贫民窟的孩子们做了什么？因此，我也要说一声：“战斗刚刚开始，战斗下去！”

我们来回想一下。假如你在加州读大学，遇到班里教授们哭泣，女生们哭泣，女生最容易学舌的政治论调是：

> “我不能想象一个受过教育的人，会投票给这种侮辱女性，种族歧视，LGBT歧视的人。川普上台会导致大屠杀，迫害少数民族，导致全球经济大衰退”。
