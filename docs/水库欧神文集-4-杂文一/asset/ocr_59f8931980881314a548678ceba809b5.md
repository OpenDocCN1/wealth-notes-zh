# 当我们叹息着观看历史；

+   •  之前二千年，儒教
•  中间 50 年，空白
•  之后一千年，新教

这一个波澜壮阔的大时代。只有我们这一代中国人，才生活在“旧教已断，新教未立”的争鸣期。
泪流满面。

目前的国际形势很清楚。中国国力暂列第二。而美国老大已经明确表示“收缩”，再也无力承担全球警察任务。

在我们有生之年，会看见几场战争，以及中国的战争胜利。
随着差不多时间窗口，“国教”的建立。
中华民族，将会陷入狂热。并且深深地以“中华民族”为荣。

就像灯塔国吸引全世界的“软实力”一样。全世界的年轻人会仰慕至强者。
强国+胜利+新教共同体。中华民族，会达到极盛。
不是外教同化中国。
而是中国同化外教。只要你一直强，一直保持军事胜利。“中国新教”就可以传播。

然后，随着所有的一神教一样。“国教”的本身，会导致僵化腐朽陈旧。
渐渐的不和时宜。
直到下一个一千年。
