# 民宿到底赚不赚钱 #F2350

一）民宿

本周一，《财经郎眼》邀请我作为经济学家。对话讨论“民宿”行业。

郎教授举了一个数据，大约75%的“民宿”是不赚钱的。真正赚钱的，反而是“民宿登记”发布平台。类似小猪短租，蚂蚁短租，甚至携程，美团。

这个话题，正落入我下怀。如果别的学者来讲，用的不是marketing 分析方法。那哥哥可真是拍案而起，抢答发言了。

“民宿”到底赚不赚钱。首先这个问题，问得就不对。好比温州客炒房套牢了，就赖水库亏钱。这能是同一样东西么？

同样道理，泛泛指的“民宿”，那也是外行人的说法。赚钱与亏钱，重要的不是“民宿”，而是细分市场。

大致来说，整个“民宿”市场，至少可以分为四个子类：

+   1）乡村/旅游客栈
2）都市贫民/背包客
