# 四）陈庆之

于是呢，陈庆之就带了 7000 个士兵，和北海王元颢高高兴兴地上路了。

按照后期晚清宫场的风气，遇见这种情况，最佳的做法，应该是走出 50 里，挖一个坑，把元颢给埋了。

然后回去向皇帝禀告，“北海王没福气啊，刚走出国境，就暴病身亡了”。

不是微臣不努力，是他没福气啊。
