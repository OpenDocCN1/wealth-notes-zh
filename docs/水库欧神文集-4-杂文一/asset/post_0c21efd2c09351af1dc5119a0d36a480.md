# 赴澳大利亚难民为求入境放火烧船 2名妇女被淹死

http://www.sina.com.cn 2001年11月09日11:41 新华网

新华网堪培拉11月9日专电 澳大利亚官方9日宣布，一只开往澳大利亚的非法移民船起火，船上难民弃船逃生，结果造成两名妇女溺水身亡。

这艘印度尼西亚船只共载有158名难民和4名船员人员。澳大利亚海军官方称，在靠近澳大利亚西北海岸的地方，船上的难民蓄意放火烧船。除两名死者外，其余人均被救起。

据悉，该船曾接到一只海关船的警告，不要进入澳大利亚水域。据一份伍伦贡地区递交国防总部的报告称，“火势发生后，船上的非法移民陷入恐慌，并冲向右舷，造成船身倾斜15到20度。”

该船在阿什莫尔礁海域沉没。官方表示，“救援过程中，两名从水中救起的妇女，被发现已没有心跳。”

另据报道，由于澳大利亚8月份出台的新政策禁止海上非法移民进入其境内，已发生多起难民故意破坏船只、寻求庇护的事件。10月，另一只前往澳大利亚的印度尼西亚非法移民船在爪哇附近沉没，共造成370多人死亡。(完)
