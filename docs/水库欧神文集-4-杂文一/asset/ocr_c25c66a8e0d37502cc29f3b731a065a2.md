# 比特币的价值何在？

有人的地方，才有价值。技术本身没有价值，价值存在于消费者心中。

所以这个问题的回答应该是：二派都是正宗的比特币。

二派分享了比特币的 IP。

好比以前比特币的 IP（品牌价值）是 15 亿。拥有 100W 用户。

30%的用户，信奉原教旨主义。只接受原汁原味的比特币。

70%的用户，信奉少壮派。接受扩容后的比特币。

那么，整个“原咪币”系统，30W 人分享￥4.5 亿品牌 IP

整个“改良币”系统，70W 人分享￥10.5 亿品牌价值。

有人的地方，就有江湖。

或者说，你只要想一想，原本价值 70W 元的 6888 8888 号码，在“电话号升位”之后，价值如何变化，就知道了。
