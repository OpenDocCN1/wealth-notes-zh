# 二）抚养比

上一篇《二性关系梳理 #F770》 $ ^{[1]} $ 写完之后，在 Shuiku.net 的讨论中。有人说：

“就我了解的来看，宋基本是古代生产力最发达的”

我回答说，绝对不可能。唐 < 宋 < 明 << 清。

纯以国力而论。清朝至少是唐朝的五倍。

其判断标准是什么： [闲杂人口抚养能力](blue_link)。

裹小脚一般认为起源于五代的李煜。但是有宋一代，裹小脚并不普遍。
