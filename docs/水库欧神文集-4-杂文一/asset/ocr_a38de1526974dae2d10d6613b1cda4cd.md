# 一）欧洲崛起

冬川豆老师主要鼓吹的是基督自治。
上一篇节，我们讲的是中国的帝制+儒家+等级制。这是伴随中国人，中华文明三千年的事情。所以大家十分熟悉，十分容易理解掌握。
在西欧，他实行的是另外一种社会秩序。

西欧基本上没有一个统一的“大三角”。而是分割成N个小三角。彼此之间都是独立的。象征着西欧小国林立。
在“小三角”的内部，还有小三角。意味着西欧每一个国家内部，他也不是一个彻底的。
