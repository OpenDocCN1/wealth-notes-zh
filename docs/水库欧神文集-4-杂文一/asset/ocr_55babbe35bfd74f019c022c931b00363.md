# 《中产阶级如何保护自己的财富》书评

# 需要保护的部分为什么是中产阶层？

看有中产阶级，大部分是白领的薪有所有，水涨船高，可真正有产阶层的积聚其实很低，我们大部分中人都中产阶层。

以2015年中科院报告为据，中国城市中低收入阶层占32.2人，也就是说中产阶级占进入已达到了16.42%。

通常新阶层的有中产阶标准是：

1. 生活有质量；
2. 25到45岁；
3. 有大学学历；
4. 专业人士和企业家；
5. 年收入1~6万美元。

按照新班子的野生标准观，在中国，月收入5k~31k，年收入0.7~37.2万属于中产阶级；月收入0.7k、收入0.7~1万属于中产阶层；月收入高于3.1万、年收入大于37.2万属于中产阶层，属于收入阶层。

无论从哪种方式推算，保守估计，中国的中产阶级在6亿以上。

这么大的人群，由于很多原因，每年的财富是以2%的速度消失（注意是消失），而70%的财富增长都集中在占比超过22%的速度增长。财富是缩水，面对这种现状，我们能怎么保护自己的金融资产，如何使我们财富长期做大？应该这么做。

才能不再面临会流的风险，可以毫无疑问地说中产阶层在？

《中产阶级如何保护自己的财富》，就是把中产阶层应该买的一本书。

# 我们需要什么样的经济学著作？

经济学不是高架上层的理论和数，也不是常常为最高阶层分权分配公式定理，经济学是每一列日常常识的理论及结合，从最普通的学习过程中，第5就可以获取知识。也可以推导出最佳制度。只是多数的人，必然是推成经济学原理的。

学习经济学，才能对财富的退退，这是我们学习西方经济的书，也正确的道路。

我们要读什么样的书，才能找到我们追求的道路上，实现等自由？

传统经济类书籍常把的字家分为三类：

江格申汉（多读有‘投机’头的人）、李亚（从事于以有‘原理正确的学者’，为自己赚钱）、亚尔（专业打假）

这些人的财富来源主要是靠投机和忘忘的收入，这收人门几乎都可以复制。

而真正掌握有能的人，从最学空中神偷，只能忙去律师，没有时间或没有高收益。

中国有一句话，叫作马大发财，这句话就是真正不富的。为什么没有富强的原因。

真正有价值的经济类投资作，要做到如下几点，通俗易理、逻辑自洽、有用有特、符合现实、这四点。能类于大部制，高富帅的有投资理论。那么如何同时符合投资做到这四点呢？只需要一个条就注释。

作者到底有没有钱？
