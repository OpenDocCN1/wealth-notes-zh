# 二）群愚

好了，哥哥发完微博，就睡觉去了。一觉醒来，这条微博成了爆款。

有 1716 个评论，3934 个赞。

哥哥一边看着评论，一边吐血。

跪在地上，拿一把匕首，佝腰刺进自己的胸膛。

评论主要说的是：

+   知乎用户，档次素质高啊。仰视。
中国的学历，在美国不受承认。难怪呢。
美国卡车司机，对比国内至少是个处级吧。
抗议抗议，本故事是物化女性，违反女权。
难道就没有爱情了么……

我用大脑想了很久，今天是不是“愚人节”。是不是 1716 个人，都在开玩笑，陪我玩呢。

还是他们真的以为，清北的女博士，处长的女儿，会跪舔美籍华人，为了拿一张绿卡？

疯了，疯了，真疯了。哥哥在愚人节寒风中发型混乱。
