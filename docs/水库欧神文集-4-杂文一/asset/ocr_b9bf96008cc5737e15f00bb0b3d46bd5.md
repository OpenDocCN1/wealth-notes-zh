# 日本进入“低欲望社会”

日本国立社会保障与人口问题研究所发布的一份调查报告说，日本18至34岁女性中，有39%的人还是处女。这一数字足以让许多男人而感到惊讶与欢欣。而还有一个数据，同样会让人啼笑皆非，在18至34岁的日本男性中，“童子身”的比例也高达36%。

调查报告显示，18岁至34岁的女性中，有一半人没有男朋友。而在35岁至39岁的年龄段中，有26%的女性和28%的男性从未有过性经验。

34岁以下的女性处女率达到40%，这一比例就很能说明，日本女性并不是像AV片中渲染的那样开放与随便。但这一数据也说明，日本社会确实已经进入了“无欲望社会”，或者说是“低欲望社会”。
