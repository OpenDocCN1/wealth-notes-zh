# 四）除虫

除了电力，你还需要解决淡水的供应。需要兴建自己的水净化厂。

除了水电煤这些基础设施，无人岛还有一个极为可怕的障碍：虫子。

1950年代，为了巩固国土边疆，曾有大量的战士干部，驻守在海疆岛屿之上。他们留下了大量的访谈笔记，闻之色变的，就是“虫子”。

看似坚固的泥土下方，其实是被完全蛀空的。密密麻麻十几米，不知有多少蛰人的怪兽。可以象潮水一样来围攻你。

这种“除虫”的活，非得要极为专业的队伍，花上大量的时间根除。又是一笔天文数字支出。
