# 第四卷基督自治

世界上可以选择的“政体”不多。概括来说，无非奴隶制，君主制，贵族共和制，计划经济，民主制，神权宗教首，和以上的一些混合交叉变种。

每一种政体对应一种宗教。宗教的作用，是给统治加以解释。并设定一些社会人相处的基本框架。
