# 是什么让你坚定了你的有神论观点?

遥香
笑话笑话爱好者。不友善用户，公司号称不搜搜我文章了，详细看简介

本来不想回答这个问题的，因为我真的不算严格意义上的有神论者。
不是任何宗教的信众，虽然任何宗教里包括了科学教，我属于伟大的不可知论者的一系。
之所以开了这个回答，是因为这个问题下面各种飞面神教的一帮邪教徒影响到我吃饭的心情了。

首先来陈述一下立场：这些科学教信徒不研究、不思考、不论证、不做实验，仅仅是把他人研究出来该他们这些科学家观察得到的结论弄出来当信仰崇拜，从而通过“自己的信仰”是被有限的教义论证过的，而别人的信仰是没有论证过的来获取冠冕上的优越感的做法。在我看来，和垃圾没两样。为什么特妹的这句话要说的那么难听那么长呢？是因为这样一句话下来，脑子不够用的就可以看不到下面的内容了……

当然了，我也没指望和这群科学教徒有多深入的交流，你们懂的，就和其他宗教一样，我们不兼容和狂信徒说话，他们的思维和处理方式都是一样的：天上地下谁敢指嘴，俺说话绝对对，说不对就不对，完全忽略掉了这个世界的现实情况是：任何一种确定的、观察到到的证据背后本身都具有不确定性。因为观察的数据是有界的。

我举举个例子：
有一个数列，科学家通过有限的技术，观察到了数列的前面7个数：1、2、3、4、5、6、7
然后科学家说：我们有证据证明前7个数是自然数列。
一个哲学家说：这个自然数列后面必然必须有 118……
科学家的做法：我们正在假设自然数列是处数，直到我们发现了：有的存在。这种方法应该是效率最高的方法，至少这种方法可以解决第一到第7个自然数的问题，但是并不证明这个数列本质上一是是自然数列，也不能证明看个数列第8个数一定不是 -1。
但是狂信者们是这样的：你这个回答没有 -1 不可证伪，不可证伪不代表着真回复，而是代表着你愚蠢的，竟然相信不可证伪的事情。我看你多聪聪哈哈哈哈哈哈哈。我信飞天神教教呢！
