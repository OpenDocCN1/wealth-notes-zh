# 亲身经历过的觉得最讽刺的事情是什么？

赵俊

Busch.、古青等 4735 人赞同了该回答

曾经在西北某市工作。职业原因，常常带着客户去不可描述场所娱乐。

市里某个场所里面有一支著名的“维族娘子军”。成员都是白皮肤高鼻梁的维族姑娘，颜值很高，而她们的另一个招牌就是有求必应。百无禁忌，全部满足。

生意非常好，每次去都要预约。客户们也特别喜欢。不管是天南海北哪里来的人，只要接待就必去这里。

去得多了，和姑娘们都熟，常常一起开玩笑聊几句天。有一次下午两三点过去，听她们议论说刚上班就很忙，没来得及吃饭，又不能离岗，很饿。我就说要我去给你们买点牛肉面水果？她们马上都不说话，我知道可能怕有忌讳，又强调了一遍：“要不你们点菜，我来送餐如何？”

领头的一位一脸鄙视的说：“你们汉人碰过的吃的都脏，我们不吃。”

天底下的事，**最怕的就是“不讲道理”**。

你和他说规矩，他不听。不听不听就不听。不在一个频道。那你怎么办。来“文”的没法玩。

**讲不听怎么办，讲不听只能揍了。**

拳头是最好的道理。揍到你求饶了，你自然就乖懂事。

可是在平等民主的国度里，你没法这么做。没法揍。

在英法等各国，早已经把“人权”提高到了一个非常非常高的标准。某些国家，甚至连死刑都取消了。

**“高人权制度”必须适用于君子之国。**

人的国度里，跑进来一群蟑螂。

对蟑螂也要用律师和心理医生好好哄着。对蟑螂也不能判死刑。

明明是你的制度失败呀！
