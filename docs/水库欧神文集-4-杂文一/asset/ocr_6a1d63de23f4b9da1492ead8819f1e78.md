# 四）禅宗

说起中国的思想史，⼀般都说是儒释道。
说起佛门的主要思想，在中国流传的主要是禅宗。
禅宗讲究的是“顿悟”。⾃唐初⼀经⾯世，⽴即横扫⼤江南北，连续超越法华宗，净⼟宗等老牌宗派。
其影响之深远，延续⼀千多年。⽬前中国⼤地上仍以禅宗为主。
禅宗为什么会兴起。把他放在“儒教”的⼤框架中，就不难理解了。
儒教讲究“等级制”，整个社会象个金字塔。皇室和宫⼠缙绅⾼⼭。
但是在任何⼀个社会，“向上”的通道永远是要存在的。否则底层的人就会感觉痛苦不堪。社会也不可能凝聚和稳定。
对于“向上”的通道，西⼠主要是举孝廉。到了唐初，从李世⺠⼿⾥开了中国制度性的“科举”。
科举之伟⼤，用多少词也形容不完。科举的重要性，也不用我赘述。
每⼀种社会秩序对应⼀种宗教。
禅宗就是建⽴在“科举”制度上，对其解释，并予以信服⼀种宗教。
中国有⼀句⽼话，叫作“朝为归⾕郎，暮登天子堂”。说的就是科举。
科举其本⾝，哪怕你昨天是个落第秀才。⼀夜之间⾦榜题名，戴红花游市河，三元高中就成了状元。
与此相对应的，是“禅宗”思想。
禅宗讲究的是顿悟。不需要任何积累，哪天你被雷劈中，灵韵顿开，顿时就有了⼤神通。据说当年六祖甚⾄不识字。
这种思想，简直就是为“考状元”的人度⾝定做的呀。
禅宗讲究“顿悟”。顿悟的另一⽅⾯，则是不可以血统继承，也不能师徒继承。
哪怕你被雷劈中，但你不能保证下⼀次谁被雷劈中。
不能保证你的⼉⼦，或者你的徒⼦，也能“顿悟”。因为顿悟是灵⽓，不能学习。
