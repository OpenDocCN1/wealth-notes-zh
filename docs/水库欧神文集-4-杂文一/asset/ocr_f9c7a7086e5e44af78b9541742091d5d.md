# 三）重骑兵

“中原缺马，草原缺铁”这样的局面，维系了近一千年。
相对来说，还是缺铁比缺马更严重一点。
所以在中原王朝和漠北的对抗之中，呈现着“一面倒”的压制态势。

铁制铠甲和骨簇箭头的对抗，其差距是代际的。
班超曾经得意地说，在征服西域的战斗中，一个汉族骑兵可以对抗五个西域武士。
如果西域人经汉族人军阵训练的话，一个还能对抗三个。
