# 而你可以做什么呢，你只能流淌着口水，看别人发财

那天我在飞机上，突然领悟到了一个道理。

其实 99%的人，是根本参与不到“新经济”竞争中的。

你看似“燃点”。其实这种活，只有 papi 酱可以做，只有罗振宇可以做，只有雪梨可以做。

能够创业的人，有一个共同的技能点，他们都是“边缘人”。

社会上 99%的人，体面的身份都是“正兵”。

（不是混乱）

正兵的意思，个个都有有头有脸的职业，都有体面的工作，在“社会秩序”中找到自己的位置。

是原有体制的一份子。

而这样的人，是有可能“创业”的。至少是有可能，参与到“新经济”的。

你既没有随机应变的资源，也没有破釜沉舟的决心。

+   你原本是一个成功的销售经理。如果你突然转行去做跨境电商了，那你以前的客户关系怎么办？
你在以前是一个受人尊敬的人民教师，改行去当直播了，那你的师道尊严怎么办。
你以前是一个高阶位的外企白领，大伙吆喝你去西藏买地。你能全身心“燃烧”，去那里开个火锅城，小饭馆么。

你做不到的！你割舍不了这一切，最多也就买了地，扔在那里囤积。

燃烧生命的活，“正兵”干不了。
