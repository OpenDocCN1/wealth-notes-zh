# 三) 社会规则

* 本段绝大多致怨在，在《论儒、法、禅宗、基督教和道教的复兴》#10 一文中已有阐述。请参阅前文。

“马恩列斯毛”，马克思为什么要排在列宁、毛泽的前面。因为马克思的确是要比列宁、毛更更重要。

当你打开电视，里面在放一个综艺节目。
美国所有的综艺节目，都不可以嘲笑黑人。也不能嘲笑 LGBT。这叫做“政治正确”。

而政治正确的原因，是因为这帮黑人没有工作，又没有社会地位。所以他们很会“搞事”。所以你一个政客演讲，拉选票的时候。黑人完全可以进来大闹会场，反正他们闲，边缘人也不怕坐牢。

因此任何政客都不愿意得罪黑人。久而久之，就形成了“黑命贵”运动。「Black Lives Matter !」自己搜词条。

在东方国家，是没有这种事情的。我们有一样东西叫“人民民主专政”。开 G20 你要是敢闹场，保证让你去青海搬砖。

“黑命贵”的原理核心，还是因为欧美是“民主国家”。甚至可以说，现代欧洲美国的一切病症。包括黑人，拉美裔，伊斯兰，LGBT，艾滋病，反核，动物保护主义，环境保护主义，福利社会，养老金危机，医疗保险失控，低生育率，高失业率…………………一切一切的麻烦，都是来自于“民主制度”。

> > 而民主制度更深一层的原因，在于欧美精英放弃了自己的责任。

“搞政治”是一件非常辛苦的事情。如果你生活在猎猎丛林的东方，则政治人物分分钟有掉脑袋的风险。

相比之下，欧洲的政客就轻松多了。欧洲政客几乎不需要承担任何指责。他们上台时，可以推脱说是选民的选择。他们下台时，同样可以推脱为选民的选择。政客们自身呢，政客没有任何错。
