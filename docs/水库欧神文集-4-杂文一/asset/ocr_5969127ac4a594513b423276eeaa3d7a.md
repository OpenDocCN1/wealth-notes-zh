# 那么，嘉靖搞那么多事，究竟是图什么呢。

一开始，群臣们浑浑噩噩，谁也不知道皇帝的心思。

一直到嘉靖二年，有一个七品小官，不入流的老腐儒张璁，突然闪电悟中，顿悟“妙法”。

张璁拉着他的好友桂萼，一起上书：“大礼仪好，坚决支持嘉靖皇帝决策”。和文武百官唱反调。

![](bbox=[0.15, 0.23, 0.85, 0.43])

于是张璁一路升官，三年之内，从不入流的留守刑部主事，居然直接做到大学士三辅。

七年之内，做到了宰相首辅，百官之首！

大明有祖制律令，非庶吉士不得封相。庶吉士的意思，除了状元，榜眼，探花，以及进士榜少数几名恩科。其他地都不算“管培生”。

终大明一朝，只有嘉靖朝拥有二位“进士宰相”。张璁，夏言。
