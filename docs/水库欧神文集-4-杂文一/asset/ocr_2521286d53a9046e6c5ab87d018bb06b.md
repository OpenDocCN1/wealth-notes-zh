# 海岛奇兵中的军事原理 #F1400

本篇是军事

我花了整整一年的时间，来玩《海岛奇兵》和《部落冲突》。究竟学到了些什么。

# 一）战斗力

俺少年读书，很多问题不甚得解。也没有明师教我。

譬如说，教科书描述“封建时代”的消亡，标准说法是“大炮的出现，彻底废平了领主们的城堡”，国王剿平各地的诸侯。

可是到了 1914 年，“德法”之间打一战的时候，著名的凡尔登要塞。德国人准备了 24 万吨炸药，亲王领队，“大贝尔塔炮”都上了。1000 门大炮同时齐射。

要塞弹弹灰尘，纹丝未动。

俺当年读到此时，我就在想，不知道凡尔登要塞，是用什么材料建成的。
