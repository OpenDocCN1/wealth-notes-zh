# 國軍虐狗殘忍致死 蔡英文：看了很難過，國防部應妥善處置

2016/05/27 22:21:00

政治中心／綜合報導【00:18更新】

國軍今（27）日爆出殘忍的集塵虐狗致死案，影片曝光後，軍方遭到各界撻伐。對此，目前人正在巴拿馬出訪的總統蔡英文，聽到消息相當訝異，她指出「這個真的很不好，大家看了都很難過，我想國防部會做適當的處理。」

# 士兵虐殺小白 許常德痛批國防部可以收了

2016/05/28 05:48:00

娛樂中心／綜合報導

海軍陸戰隊士兵爆出集體虐殺流浪狗「小白」，消息傳出後引發各界撻伐，國防部27日晚間公布虐處名單，也同步在「國防部發言人」臉書粉絲團貼出致歉聲明，但愛狗人士今（28）日仍發起「著白衣悼念軍中受虐犬，國防部負」的活動，音樂人許常德更直言國防部可以收了！

許常德說，國防部的爛是國家的浪費！養一群缺德缺格又無法打仗的軍人。當畜兵的都知道，這是個無法打仗的無社會！連民众海邊都無法預防，國防部可以收了。

資深歌手黃郁蒼也在臉書貼出一張圖片宣告，「小白不再有苦…天使回到天堂了。」
