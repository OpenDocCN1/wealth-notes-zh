# 二）速度

《[考试才是不公平](#)》#X54 这篇中，桃军师跳出来，大喊了一声：“<span style="color: red">所有人的上升速度，V 相等</span>”是<font color="red">不公平，不可能，不正义的</font>。

这下子，可算是捅了马蜂窝了。

56000 阅读，刷出了 450 评论，占比 0.8%，这是非常非常高了。

而且很多 985 留言激动，情绪紧张。触及利益比触及灵魂更艰难。

有些事，正着讲时，你可能难以理会。但我们反过来讲，如果世界上真的实现了“V 速度相同”，一个乞丐的儿子，和一个将军的儿子，拥有同样的上升机遇，那会发生什么情况。

这样的国家，在地球上真实存在。它的名字，就叫做“美利坚”。
