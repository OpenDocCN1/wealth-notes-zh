# 忠诫背后的利益算计

【出处】《资治通鉴》第186卷 唐纪二

【原文】 徐世勣据李密旧境，未有所属。魏徵随密至长安，久不为朝廷所知，乃自请安抚山东，上以  为秘书丞，乘传至黎阳，遗徐世勣书，劝之早降。世勣遂决计西向，谓长史阴翟郭孝恪曰：“此民忠土地，皆魏公有也；吾若上表献之，是利主之败，自为功以邀富贵也，吾实耻之。今当籍郡县户口士马之数以启魏公，使自献之。”乃遣孝恪诣长安，又运粮以饷淮安王神通。上闻世勣使者至，无表，止有启与密，甚怪之。孝恪具言世勣意，上乃叹曰：“徐世勣不背德，不邀功，真纯臣也！”赐姓李。以孝恪为宋州刺史，使与世勣经略虎牢以东，所得州县，委之选补。

【译文】 徐世勣占据了原属李密的地盘，没有归附任何人。魏徵随李密到长安，很久朝廷也不知道他是谁，于是自己请求招抚潼关以东地区，高祖以他为秘书丞，乘驿站的传车到黎阳，致书徐世勣，劝他尽快投降唐。徐世勣于是决定向西投降，对长史阴翟郭孝恪说：“这里的百姓和土地，都是魏公的，我如果上表献百姓土地，是利用主人的失败，当作自己的功劳求得富贵，我深以为耻。现在应当登记郡县的户口、士兵及马匹的数目，上报魏公，由他自己献上。”于是派遣郭孝恪到长安，又运粮食供给淮安王李神通。高祖听说徐世勣的使者到长安，没有给皇帝的表章，只有书信给李密，非常奇怪。郭孝恪陈述了徐世勣的意思，高祖于是感叹道：“徐世勣不违背道德，不求功劳，真是个 好臣子呀！”赐他姓李。以郭孝恪为宋州刺史，让他和李世勣策划处理虎牢以东地区，得到的州县，委任他们选补官吏。

【解析】 李密是瓦岗军的首领，失败后投降给唐高祖李渊，这一段就是旧部如何利用旧资源的问题。

+   一、权谋心思，是自身利益最大化的反应

+   1、魏征的借花献佛，上位技巧

魏征跟随李密进入到了最大的唐朝创业团队，但是因为李密的不受重视，自己也就籍籍无名，如何能够获取自己在新组织里的位置，让自己上位，这就需要为组织增加利益。而把之前的徐世勣说服归队，这就能够增加自己在新组织中能量的最便捷的方案。徐世勣是李密的老部下，李密的存在，也就在合法性上，说服徐世勣是个很简单的活动。魏征没有坐以待毙，积极地转化旧资源。

+   2、徐世勣绕道上表，自保技巧

徐世勣本来自己能够主动的上表给唐高祖李渊，把投降的功劳给自己，他没有那么做，而是把所有的材料给了李密，让李密交给李渊，获得了李渊和李密的双重好感。其实背后是徐世勣深刻的利害计算：一来，如果徐世勣自行上表，绕过李密，同朝为官，李密高于徐
