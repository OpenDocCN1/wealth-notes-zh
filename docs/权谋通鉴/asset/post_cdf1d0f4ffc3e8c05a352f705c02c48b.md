
# 一、文帝的利害计算

### 1、萧摩诩必须释放原因

权力考虑的不仅仅是已发生的事情该怎么处理，还要考虑，处理后会有什么样的影响。所以，隋文帝考虑的不仅仅是萧摩诩被儿子造反要连坐的问题。而是更要考虑，如果处理掉萧摩诩会有什么结果。首先是自己会失去这个心腹爱将，天下此时并不太平，还在用人的时候；其次是萧摩诩如果被杀，会激发更多的军变，因为其在军中的势力会内心不安，从而可能造反加入对手阵营；更为重要的是，最后一点，江南举兵作乱的实力，打着萧世略的旗号，本身可能就是一箭双雕，一来利用萧摩诩的号召力，二来可以假借皇帝之手除掉萧摩诩。所以，基于这三点考量，隋文帝要赦免萧摩诩。

### 2、为萧摩诩开脱的理由

权力的心理计算，并不能公开示众，所以必须有个能够服众的理由为萧摩诩开脱。这个理由其实很难找了。萧世略江南兴兵作乱，板上钉钉，隋文帝还是从年龄这个角度打开了口。萧世略年龄不到二十，年龄小，肯定是被其他人蒙蔽胁迫了，用现在的术语，就是萧世略是未成年人，认识不成熟，造反并不是其主观意愿。既然是被胁迫的，自然不应该牵扯到萧摩诩。这个理由真的是难为隋文帝了，现在领导想为犯大错的下属辩护也会说，他主观恶性不强，受其他人胁迫，身不由己。找到了理由，就可以要赦免萧摩诩，隋文帝没有太多的考虑，就通过权术准备直接释放。

### 3、最终采用了法律程序

隋文帝直接赦免萧摩诩，受到主审法官赵绰的抵制，这是法律和权力的对抗。隋文帝想利用权谋手段，找借口让赵绰下去吃饭，从而避开直接冲突，但是赵绰坚持下，皇帝不得不让步，采用了第二套方案，就是直接授权大理寺，通过法律程序来赦免萧摩诩，而不是自己通过权力赦免。看起来效果一样，都是萧摩诩被释放，但是多了这个让大理寺法官为其特赦的程序，就大不一样了。这是采用的合法手段，合法程序，赦免的他，权力披上了法律的外衣。这样既保证了法律的稳定性，又让权力的意图得到了执行。这样表面是法律战胜了权力，其实是法律只保留了程序。

# 二、赵绰的法律思维

### 1、违法必须追究

为什么赵绰这么坚持追究萧摩诩呢？有可能是赵绰和萧摩诩不和，找到机会置其死地。但是，本质上是作为法官的他，认为法律必须示范效应，如果这样造反的人都不处理，以后其他人造反，还要不要连坐？如果有的要，有的不要，以后工作就不好做了。

### 2、权力让位法律

在赵绰的坚持下，权力让位法律。其实法律代表着长期的整体的利益，而权力是着眼于当下的现实和特殊情况。如何在稳定性和灵活性之间找到平衡点呢？通常都会在制定法律的时候，留下例外条款，通过法律自身的调节，来贯彻权力意图，而不是让权力直接干预。

### 3、保证形式合法

法律分为实体正义和程序正义，法官追求的是实体正义，这样能够保证真的贯彻法律；但是如果不能的话，也要退而求其次，保证在形式上合法。就算是做做样子，走走过场，也要让法律看起来起到了效果，这是法律的底线。这个底线不存在了，也谈不上法律尊严了。

# 三、权力和法律协调

### 1、法律必须稳定

法律在组织中的表现就是自己订立的规章制度。这些规章制度，必须有一定的稳定性，才能被遵守，被执行。如果这个经常变，也就不能指导未来的行为，大家就会无所适从。领导自身不维护制度的稳定性，随意执行的话，很快，这个规章就成了废纸。

### 2、权力面对变化

但是，规章制度是死的，而组织的事情千变万化。如何让自己设定的规章制度，不会成为自己权力的绊脚石呢？这个就需要界定权力和制度的边界，以及提前设定调整的方法。通行的惯例就是首先私下协调酝酿，然后召开全体大会，利用少数服从多数的基本政治规律来协调变化。

### 3、权力大于法律

其实，上述的都是正规军的玩法。现实中，很难遇见这样的领导以及如此坚持的执法者。从职场权谋角度而言，永远都是权力大于法律，你不听话，我自有办法收拾你。从整体利益而言，权力思考的维度要大于法律思考的维度，权力思考会更加贴近现实。所以，权力的话，是第一位的。

经过上述的整体分析，大家要自己做领导的要记住一句话，就是办事，一定要披上合法外衣，非到万不得已不要动用权力。如果动用权力，就首先利用大家集体决议为外衣。明白了这个手段的先后顺序，组织的稳定性和灵活性就真正结合起来了！

> 组织动乱之源——势均则斗

【出处】《资治通鉴》180卷 隋纪4

【原文】巨光曰：昔羊仙伯周恒公： “内宠并后，外宠贰政，嬖子配嫡，大都偶国，乱之本也。”人主诚能慎此四者，乱何自生哉！隋高祖徒知嫡庶之多争，孤弱之易摇，曾不知势钧位逼，虽同产至亲，不能无相倾夺。考诸辛伯之言，得其一而失其三乎！

【译文】臣司马光曰：从前宰伯劝告周桓公说：“内宠姬妾地位与皇后相等；外宠重臣与皇帝一样也可发号施令；庶子与嫡子相匹敌；大的都城与国家的势力相匹敌。这都是动乱的根本原因。” 作为人主如果真能在这四方面慎重从事，动乱怎么能自动发生呢？隋文帝只知嫡、庶之分容易出现纷争，皇室的地位孤立微弱容易动摇，却不懂得诸王的势力与皇帝势均力敌就会危逼皇位。虽然一母至亲骨肉，也不能免于相互倾轧夺权。考察宰伯的这些话，文帝只吸取了一点而丢掉了另外三点啊！

【解析】一个组织为什么会乱？很多人都在寻找其根源，因为知道了根源就能够提前预防，让组织保持稳定。而司马光在《资治通鉴》中，引用《左传》的一段话，揭示了一个组织祸乱本源。仔细分析，觉得精武之极。

# 一、常见的动乱四种形式

- 1、内宠并后

宫廷权斗，一直都是当下的热门戏，甄嬛传、步步惊心等，都是这类的权谋大戏。因为，中国古代的政治大多是用后宫争宠衍发出来的。武则天就是王皇后为了制衡萧淑妃而从感业寺拉回来的，然后武则天争宠击败了王皇后，导致了唐朝最大的动乱，换成了周朝。可见，家庭内斗，对事业的影响极大。

- 2、外宠贰政

权臣，近臣，通过屏蔽主上的耳目，操纵政治的变化，获取利益。可以说，主上的权力，无形中被下放了。一旦一个人能够影响到政策权力走向，可以说，这个人无论什么位置，都具备了君主的权势。李林甫就是攫取了唐玄宗的权力而权倾朝野。不专宠、不专信、不专听，才能不失去权力。

- 3、嬖子配嫡

接班人的斗争，历朝历代不断，因为太子一直称为国本。嫡长子，就因为生的早，就该做这个位置吗？有才的其他皇子，不服。唐高祖就是在李建成，和李世民之间，徘徊不定，最终李世民做大，先发制人，发动了玄武门之变，逼迫高祖退位。

- 4、大都偶国

地方势力做大做强，就想自己拍板抗衡中央。唐朝后期的藩镇格局，不就是安禄山、史思明地方势力做大了，就有了抗衡的野心，闹起动乱。动乱的过程中，地方的势力做大，最终解体现了唐朝，进入了长期的割据期间。

# 二、这些动乱的内部本源规律是什么呢？

- 1、信任资源的均势

后宫争宠的事情、皇子之间斗争的问题，这都是一个感情问题，感情的核心还是信任的问题。更加信任谁？如果平均分配了这个信任资源，他们就会引发内斗，让自己后院起火。

- 2、权力资源的均势

在朝堂之上，把自己和权臣形成势均力敌的地位，这样其实是对权力的分割，会让下面的人无所适从，自己乱了自己的权力平衡。

- 3、经济资源的均势

经济资源的平均分配，让大家充满了野心。只有势均力敌的时候，大家才会有斗争之心。权谋网说过“邪心诱于可欲”，只差一步才会胜出，才最能激发人的斗争欲望。

# 三、权谋名词“势均则斗”给我们什么启示呢？

- 1、如果想制衡，就让他们分成两派。因为他们斗来斗去，自己才会安全。很多政治家都会把自己的手下分成两派，互相牵制。
- 2、如果想制造混乱，就要使用均势的办法，让其内斗，只有不断地内斗，搅乱浑水，才能够有机会，以患为利。
- 3、先消除混乱，就要剪除平均实力，让他们没有野心，即使有野心也没有支持野心存在的势力。不要只扶植对抗一派势力，这会让自己成为斗争对象，要扶植两派，才会稳定。

所以经过上述的论述，我们记住这个“势均则斗”。但凡强弱一定，或是格局分明，大家也就不需要斗了。均势下，要么你自废武功，寻求自保，要么奋发进取，灭掉对手，没有第三条路。不存在自己又有实力又安全的这个状态，这是权谋家对势力判断的时候要注意的。

# 职场收拾对手就三大手腕

【出处】《资治通鉴》180卷隋纪4

【原文】初，尚书右丞李纲数以异议忤杨素及苏威，素荐纲于高祖，以为方行军司马。方承素意，屈辱之，几死。军还，久不得调，威复遣纲诣南海应接林邑，久而不召。纲自归奏事，威劾奏纲擅离所职，下吏案问；会赦，免官，屏居于鄂。

【译文】当初，尚书右丞李纲因为几次有不同意见违逆了杨素和苏威，杨素就向文帝推荐李纲，让他作刘方的行军司马。方方懂得杨素的用意，他侮辱冤屈李纲几乎致死。方方军队返回，李纲很久得不到调动。苏威又派李纲到南海应酬处理林邑方面的事务，很久不召回他。李纲自己返回汇报情况，苏威就弹劾李纲擅离职守，将他交给司法官员审讯治罪。正逢大赦天下，李纲被免去官职，隐居在鄂县。

【解析】每个人在职场都有自己看不顺眼，动不动就和自己作对的，这时候很多人想到的就是直接对抗，但是这非权谋家所为。真正的权谋家，收拾对手，让其生不如死的招数，其实就是三大手段。杨素通过对付李纲，弄得他生不如死，权谋网具体解析下。

# 一、杨素收拾李纲的三大手法：

- 1、穿小鞋

杨素自己并没有主动出手收拾李纲，而是，还积极主动的推荐他，做了刘方的行军司马。这么做，就是让对方有机会，用权力给李纲穿小鞋。方方自然上路，所以，不断地利用各种机会，利用职务之便，让他受辱，最后让李纲感觉生不如死。

- 2、冷板凳

让李纲不调动，且在南海很久不召回。让你常年出差，在自己环境不熟悉的地方，坐冷板凳，和家人长期分开，在领导眼里久不出现。这样在不受重视的地方，让你自生自灭，完全没有了脾气，你还找不到对方的弱点，说自己被陷害。

- 3、抓小辫

杨素目的就是激发他内心的不满，等他犯错。当李纲擅离职守的时候，立即出击，李纲被抓住的小辫子。通过合法的手段，让他受到惩罚。要不是因为国家大赦，什么时候能够出来，都还是问题，出来之后，李纲只能隐居在小县城，毫无作为了。

# 二、李纲在职场做错了什么

### 1、李纲树敌太多。

李纲凭借自己的力量和很多人对抗，不仅得罪了杨素，还得罪了苏威，把领导身边的人，都得罪完，你自己如何去对抗一群势力呢？失去援手，自己就会孤立无援。

### 2、李媚媚主无力。

李媚媚主无力，尽管维护了组织的利益，揭露杨素等人的恶行。但是这对皇帝并没有什么好处，也没实际意义。所以李纲被边缘化的时候，皇帝想不起来他，也就对他没啥帮助。

### 3、李纲自身犯错。

那么多人在虎视眈眈，但是都只能利用权力、利用工作、利用小动作，还不足以有大杀招，但是李纲自己被逼着犯了错，这就被人直接用规则，给打下去了，自身辩护都不行。

# 三、李纲和杨素的斗争对我们职场的意义是什么？

### 1、敌人要选一个。

我们选择树敌的时候，千万不能扩大打击面。每次只针对一个，能够提高胜率，且不会扩大化，一旦扩大化，就可能被众人攻击，自己腹背受敌。

### 2、要有自己盟友。

李纲没朋友，皇帝身边，一个替自己说话的人，都没有；自己跑过来汇报，被人抓住了把柄，为什么没朋友呢？这就是平时不善于交际，大家没人帮。

### 3、谨小慎微无错。

想斗争别人，就一定要谨小慎微，在打败别人之前，自己不能犯错。如果这个时候犯错，就是授人以柄。自己会被人抓住这个缝隙，永不翻身。

所以，权谋网认为，杨素收拾李纲的手法，可以说，是职场收拾对手的常用手法，一切都是按照规则玩的，还都一点不犯错。这就是高明之处，你只能恨他，但是你却无力反抗。

# 好下属的三个权谋标准

【出处】《资治通鉴》181 卷 隋纪 5

【原文】蕴善候伺人主微意，所欲罪者，则曲法锻成其罪；所欲宥者，则附从轻典，因而释之。是后大小之狱，皆以付蕴，刑部、大理莫敢与争，必禀承进止，然后决断。蕴有机辩，言若悬河，或重或轻，皆由其口，剖析明快，时人不能致诮。

【译文】裴蕴善于观察以迎合皇帝细微的心思和意图。炀帝要加罪的人，裴蕴就曲解法律以编造成罪状；炀帝想要赦免的人，裴蕴就附和炀帝意思，从轻解释典章法律，因此就将人释放了。此后大大小小的刑狱之案，都交给裴蕴办理。刑部、大理寺都不敢与裴蕴争论，必定要秉承裴蕴的意图来衡量法律，然后才决断案件。裴蕴机智、善辩，说起话来口若悬河，犯人的罪过或轻或重，都凭裴蕴的一张嘴。他剖析、解释问题明快敏捷，当时的人都不能把他问住。

【解析】如何做一个好下属，是个大问题，这是职场人必修的头一课。但是一个权谋家做下属，却有自己独特的标准，裴蕴就是这么一个标准的权谋下属。权谋网认为，这三个标准是：

- 1、善于揣摩领导细微心思。

作为一个权谋下属，组织利益不在考虑范围之内，完全把领导的个人利益当成自己工作的最高标准，因为自己的升迁、荣辱都在领导的直接控制下。好下属，都是领导筛选出来的，不是培养出来的，领导的心思你自己猜。这样领导既能够享受到好处，又不用自己担责任。所以权谋家，要维护领导利益，善于揣摩他的心思，这是工作的首要任务。

- 2、完全执行领导精神意图。

猜到了领导意图，当领导意图和组织标准发生冲突的时候，作为权谋家，自然不会维护组织的利益，而是把领导的利益放在首位。所以，领导不喜欢的，找证据，也要收拾掉；领导喜欢的，就想办法开脱，把领导的精神意图，完全贯彻下去，这才能获得领导的青睐。尽管，领导是组织的最高代表，但是领导的利益和组织利益并不一致。产生冲突时候，组织利益靠后。

- 3、执行结果不给领导麻烦。

曲意逢迎也是看功夫的，如果只是一味的徇私枉法，导致民怨沸腾，给领导麻烦，自然是走不远。如果能够把一切都弄得合情合理，最起码表面上说的过去，这个领导是喜欢的。这就是小人和权谋家的区别，小人只看结果，而权谋家兼顾手段。所以裴蕴，很多人都问不住他，专业知识过硬。专业级替领导作了黑活，而无不掉手段之忧。

所以，作为手下的三个权谋标准，领导心思是要通过揣摩得到的，领导利益高于组织利益，办事讲究手段不给领导找麻烦。懂得这三点，一个好的下属，基本到位了。

# 忠诫背后的利益算计

【出处】《资治通鉴》第186卷 唐纪二

【原文】 徐世勣据李密旧境，未有所属。魏徵随密至长安，久不为朝廷所知，乃自请安抚山东，上以  为秘书丞，乘传至黎阳，遗徐世勣书，劝之早降。世勣遂决计西向，谓长史阴翟郭孝恪曰：“此民忠土地，皆魏公有也；吾若上表献之，是利主之败，自为功以邀富贵也，吾实耻之。今当籍郡县户口士马之数以启魏公，使自献之。”乃遣孝恪诣长安，又运粮以饷淮安王神通。上闻世勣使者至，无表，止有启与密，甚怪之。孝恪具言世勣意，上乃叹曰：“徐世勣不背德，不邀功，真纯臣也！”赐姓李。以孝恪为宋州刺史，使与世勣经略虎牢以东，所得州县，委之选补。

【译文】 徐世勣占据了原属李密的地盘，没有归附任何人。魏徵随李密到长安，很久朝廷也不知道他是谁，于是自己请求招抚潼关以东地区，高祖以他为秘书丞，乘驿站的传车到黎阳，致书徐世勣，劝他尽快投降唐。徐世勣于是决定向西投降，对长史阴翟郭孝恪说：“这里的百姓和土地，都是魏公的，我如果上表献百姓土地，是利用主人的失败，当作自己的功劳求得富贵，我深以为耻。现在应当登记郡县的户口、士兵及马匹的数目，上报魏公，由他自己献上。”于是派遣郭孝恪到长安，又运粮食供给淮安王李神通。高祖听说徐世勣的使者到长安，没有给皇帝的表章，只有书信给李密，非常奇怪。郭孝恪陈述了徐世勣的意思，高祖于是感叹道：“徐世勣不违背道德，不求功劳，真是个 好臣子呀！”赐他姓李。以郭孝恪为宋州刺史，让他和李世勣策划处理虎牢以东地区，得到的州县，委任他们选补官吏。

【解析】 李密是瓦岗军的首领，失败后投降给唐高祖李渊，这一段就是旧部如何利用旧资源的问题。

- 一、权谋心思，是自身利益最大化的反应

    - 1、魏征的借花献佛，上位技巧

    魏征跟随李密进入到了最大的唐朝创业团队，但是因为李密的不受重视，自己也就籍籍无名。如何能够获取自己在新组织里的位置，让自己上位，这就需要为组织增加利益。而把之前的徐世勣说服归队，这就能够增加自己在新组织中能量的最便捷的方案。徐世勣是李密的老部下，李密的存在，也就在合法性上，说服徐世勣是个很简单的活动。魏征没有坐以待毙，积极地转化旧资源。

    - 2、徐世勣绕道上表，自保技巧

    徐世勣本来自己能够主动的上表给唐高祖李渊，把投降的功劳给自己，他没有那么做，而是把所有的材料给了李密，让李密交给李渊，获得了李渊和李密的双重好感。其实背后是徐世勣深刻的利害计算：一来，如果徐世勣自行上表，绕过李密，同朝为官，李密高于徐世勋，之后李密收拾徐世勋，是很简单的事情；二来，表现的对旧主的忠诚，这种品质是任何领导所喜欢的。

    - 3、李渊赐姓徐世勋，拉拢技巧

    李渊面对这样一个忠于旧主，并且收到自己麾下的人才，李渊从最开始的不理解，到后面的惊叹，这个情绪的波动，直接对徐世勋有了极大的好感，赐姓和提拔都是为了拉拢徐世勋。这样的手法有两个好处，无视李密上表，依然把好处给了徐世勋，承认了徐世勋的功劳；二来做出了示范，让所有人都向徐世勋学习忠诚。徐世勋把李密当成了忠诚的道具，李渊没有赏赐李密也是为了削弱他的势力。

- 二、归顺计策，多重利害计算做出的动作

    - 1、为什么徐世勋没有主动归顺

    面对自己占有的这块地盘，徐世勋肯定自己是守不住的，早晚就要有归顺。按照逻辑，李密已经投降到了唐朝，自己主动归顺，就行了。但是那样让唐朝得到的太容易，自己就越是身价。所以，被动的等待有人来谈判，自己能够获得更多的主动权和关注度，能够要求更多的交换筹码。

    - 2、徐世勋让李密上表还有深意

    表面上，徐世勋是忠诚于李密的，其实这个恰恰是陷害了李密。李密杀了合伙人翟让，徐世勋经常讽刺李密。李密当初让徐世勋镇守黎阳，就是为了边缘化，冷落徐世勋。这时候，通过李密上表，会让李渊内心认为李密还有影响力，有自己的势力，不能不除掉。最深的借刀杀人，历史也是如此发展的。

    - 3、徐世勋给李神通送粮是后手

    徐世勋给李神通送粮的这个情节一般会一眼带过，恰恰这个动作是权谋心思的深度表现。因为徐世勋派郭孝恪去上表的，让李渊和李神通解释，绕道上表的目的。如果李密从中作梗或是贪为己功，徐世勋就没有任何证据证明自己的诚意了。送粮给李神通，证明自己是真心的归顺，展示主动性，留下行为证据。

- 三、错误举动，李密不知不觉走向毁灭路

    - 1、没有重视老部下魏征的需求

    魏征跟随李密到唐朝投降，李密获得了魏公的称号，而李密却没有照顾到自己兄弟魏征的感受。魏征内心一定是埋怨的，但是又不能发泄出来，只能自己独立谋求上位。魏征不再需要李密的时候，其实他们之间的关系也就结束了。你不照顾兄弟，别人也就不会再听你的了，李密失去了亲情。
