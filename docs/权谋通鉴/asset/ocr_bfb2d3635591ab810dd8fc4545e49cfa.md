这个问法，其实生活中也很常见，比如下班前，老婆给你打电话，问你晚上想在家吃饭，还是在外面吃饭？表面是征询你的意见，其实这是想和你出去吃饭，要是真的想在家吃饭，还用问你？平时都是在家的，就是既定的。既然问了，就是想出去。这时最佳的答案就是“这么好的机会，当然出去吃饭了，想吃什么，地方你订。”其实很多权谋智慧，用在生活中，照样畅通无阻。

# 权力交接期的君臣博弈

【出处】《资治通鉴》279 卷 后唐纪 8

【原文】蜀卫圣诸军都指挥使、武信节度使李仁罕自侍宿将有功，复受顾托，求判六军，令进奏吏宋从会以意谕枢密院，又至学士院供草麻。蜀主不得已，甲寅，加仁罕兼中书令，判六军事；以左匡圣都指挥使、保守节度使赵延隐兼侍中，为之副。

【译文】蜀国卫圣诸军都指挥使、武信节度使李仁罕自侍是宿将有功劳，又受先帝遗诏辅政，希求让他总判六军，指使进奏吏宋从会把他的意图传告枢密院，又到学士院探听诏书起草的情况。蜀主孟昶不得已，甲寅（十七日），加封李仁罕兼任中书令，判六军事；任用左匡圣都指挥使、保守节度使赵延隐兼任侍中，做他的副手。

【解析】权力交接的时候，是一个组织最不稳定的时候，旧臣和新君之间不可避免的会有权谋博弈战。蜀主孟知祥去世后，把位置传给了孟昶。而李仁罕作为接受遗诏辅政，一场权谋大戏展开。

# 一、李仁罕的权力算计

# 1、能量对比

权力交接时期，之所以敏感，是因为新君即位后，权力控制没有完成，这时候能量最弱，新君所期待的是稳定，快速的形成自己的权力班子。相对而言，这时候权臣力量最大，之前还有老皇帝压着，不敢有作为，现在自己是功臣宿将，没人能够控制。李仁罕此时能量最大，必然有非分想法。

# 2、风险计算

李仁罕在自己实力占优的情况下，就想借机要挟领导来实现自己的权力进阶。这时候孟昶如果不就范的话，要鱼死网破。李仁罕利用自己的辅政大臣的政治影响，以及手里的军事势力，从政治和军事上都能够做出绝对的应对。

# 二、李仁罕的运作手法

# 1、李仁罕的顾虑

李仁罕顾虑的，不是得不到这些权力怎么办，因为新主孟昶绝对会屈服，李仁罕最大的顾虑就是，如何施压之后，大家的关系不是很僵化，毕竟以后还要继续合作下去，自己造反的可能性也不是很大，善后之最大的顾虑。
