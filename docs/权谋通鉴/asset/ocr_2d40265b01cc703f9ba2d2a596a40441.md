# 7、成为有能力的下属，在制衡结构中如何应对？

+   1、受宠内很多子手，是领导故意安排的。

每个有能力的人，在领导眼里都是不安全的，随时可能就会让他失去权力，但是又不能不用能人，那组织如何发展？在组织发展和权力稳定的矛盾平衡中，领导就必须挑起亚下属派别斗争，很多子手不是来自你的对手，其实是来自领导谋谋心思的故意安排。

+   2、你斗倒了对手，其实你自己也就输了。

是不是你觉得你打败了对手自己就赢了呢？恰恰是错误的，你把对手打败了，你就打破了组织的内部平衡。你显示了自己的势力，其实就是威胁了权力的稳定。既然没有人能够制衡你了，领导也就不敢用你了，你也失去了存在的可能。

+   3、只有对领导忠心耿耿，才能立于不败。

在这种制衡结构下，作为下属，不能下斗，但是如何又能让自己舒服点呢？那就是你要明白，你的对手不是别人，而是领导的权力安全感，如何让领导获得权力的安全感才是你要考虑的本质。那就是，信任，通过不断的忠诚表演，你获得的信任越多，权力就会越大。不信任你，就可以制衡约你。

经过上述的权谋网分析，我们能够看出来，中国式组织形态是三角制衡的模式，让权力安全和组织效率达到最佳平衡的模式。在这种结构中，你只有更多的忠诚，才能获得信任，才能过的更好。
