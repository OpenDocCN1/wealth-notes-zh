# 温峤的自保术——亲近、疏离还是出卖都是手段

【出处】《资治通鉴》第 93 卷 晋纪 15

【1】当初，明帝亲近信任中书令温峤，王敦不满，谁准温峤出任左司马。温峤便假装勤勉恭敬，治理王敦府事，时常私下出些主意来附合王敦的欲望。

【讲解】王敦对温峤不满，并没有采用直接对抗或是陷害的手段，而是利用权力把他调职为自己的副官。让自己的不爽的人做下属，这是权谋型领导最常见的做法。历史上李广就把曾经欺负自己的霸陵尉尉调至军中，做自己的部下。霸陵尉到了军队，李广立即就杀了他。所以说，温峤几乎上是凶多吉少。不过，他明知自己不被信任，出现错误，会立即被斩杀，但是他却反人性的深度伪装了自己。温峤态度上对王敦勤勉恭敬，办事上就兢业业，还主动为其私利出谋划策，为自己争取到了一丝自由的空间。权谋高手之间很少采用对抗手段，越是矛盾重重，表面越是恭敬，这样才能为自己争取时间或是空间，避免过早的直接对抗，而丧失自己仅有的本钱。

【2】又与钱凤结为深交，为钱凤扬名，常常说：“钱凤满身活力。”温峤素来有善于知人、褒奖后进的美名，钱凤甚为喜悦，尽力与温峤结好。恰逢丹杨尹的职位空缺，温峤对王敦说：“丹杨尹守各京城，这种咽喉要职您应当自己遴选人才充任。恐怕朝廷任用的有的人不会尽心治理。”王敦颇以为然，问温峤说：“谁能够胜任？”温峤说：“我认为没有谁能比得上钱风。”钱凤也推荐温峤，温峤佯装推辞。王敦不听。

【讲解】这里面有三个点：首先是温峤知道钱凤是王敦的心腹，于是使用各种手段与之深交。权谋家的交往和普通人不一样，并不是以个人的喜好来交往的，而是以利害关系角度来交往的，和你交往对我有什么好处，或者是能够避免什么坏处。温峤主动接近钱风，就是为了避免自己被他陷害。其次，温峤为了讨好钱凤，不惜没有底线的溜须拍马，利用自己长期打造的善于知人和褒奖别人的名气，来给钱凤扬名。钱凤作为小人，缺乏威望，自然对这些吹捧很是受用。权谋家为了实现自己的目的，都是善于伪装的，包括语言上的言不由衷。而很多道德之士，大多耿直，不愿意讨好别人或是违背内心，最终被陷害，而实际上对坏人毫无伤害力。最后一点就是，对于丹阳尹这个位置，温峤其实是进退自如的，推荐钱凤去做，这样恰好能够调虎离山，分化王敦的势力，还能够利用空间距离的阂隔，来背后陷害钱风。而如果自己能够去做丹阳尹，恰好能够摆脱王敦长时间的监控和压制，能够实现鱼入大海，自由自在。可以这么说，推荐自己的对手去外地赴职，表面是重视推荐，
