# 三、内乱的避免

# 1、理性

赵主父之所以因为内乱被围死，一切的起因就是，没有客观理性的去对组织权力合理的分配，而是依照自己的好恶来决定的。好恶的不稳定，所形成的势力也就不稳定。所以避免内乱最首要的就是对下面，所形成势力的强弱、归届、能品都要有理性的认识。

# 2、果断

犹豫不决给了双方势力希望，从而激发了矛盾。这一点上，曹操做的就比较好，一旦选定了曹丕做接班人，就没有再留下曹植的势力，于是快速的，残酷的剪除了曹植的组织派系。维护了身后的稳定，在客观上，因为曹植没有了组织实力，失去了竞争能力，也保住了性命。

# 3、集权

赵主父的死，就是面对两个儿子的势力斗争内乱的时候，没有任何的反制力量，也就是说，赵主父自己已经失去了权力，没有人再追随拥护即将老去的赵主父。任何时侯，权力必须集中在自己手里，即使培养接班人，最高的权力也必须自己一手独拿。失去权力，意味着死亡，这样的历史一再重演。

所以经过权谋网上述对赵主父的分析，我们对比，玄武门之变李世民先发制人的胜利、曹操果断除掉曹植势力的稳定身后局面、以及因为袁尚袁谭的内斗而让袁绍庞大的势力消失殆尽，无不在各个层面来证明内乱的成败得失。学习好这篇文章，对内乱，大家会有一个好的认识。
