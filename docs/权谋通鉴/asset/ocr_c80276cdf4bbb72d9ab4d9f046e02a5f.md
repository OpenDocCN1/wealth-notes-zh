重要人员的核心原因。自从冯子琛成了右仆射之后，获得了对皇帝的直接汇报关系，尽管和士开还是位置比他高，但是已经不能直接卡冯子琛脖子了。

# 2、有根基

冯子琮光有和领导的直接汇报关系，能够直接影响决策还不够，还需要有自己的根基。他兼任吏部尚书的职权，让他能够凭借自己的影响力安插自己的人，形成势力。在职场，一个人权力大不大，不仅仅是职权赋予的，还要有影响力，而这个影响力的来源就是，手下有多少人是你自己提拔的人，这些人围绕在自己的身边，权力行使的时候，才能畅通无阻。所以，冯子琮，能够利用吏部尚书的权利不断地自行引荐，自行操作人事任命的权力，就形成了以自己为核心的派系。

# 3、有关系

职场上，只有关系也不行，没有关系也不行。关系只是稳定剂，没有进取力，只有关系，也只能夹着尾巴做人。但是如果只有位置和势力没有关系，那么这个位置和势力是不稳定的。随时可能被人当成潜敌给掰掉。冯子琮是太后的妹夫，所以能成为吏部尚书，但是这个还被和士开直接管着，不能不听话。但是有了位置和势力之后，和太后的关系就能够稳定自己的位置，不被其他人觊觎。因此，当冯子琮凑够了这权力的三大要素之后，立即就拥有了野心，不再服从和士开的管理。

冯子琮跪舔和士开，但是自己一旦拥有了三大权力要素之后，立即就和和士开有了矛盾。因此作为领导，想控制下属，就不能让他拥有这三大要素，不然就是养虎为患。但是作为上级领导，也可能用这个手法，让手下的人分裂。比如皇帝，如果故意提拔冯子琮和和士开互相制衡，这就是个正确的招法。秦昭襄王，就是利用这个招法不断地提升魏冉手下的白起，逐步的让白起和魏冉产生了制衡关系，从而把魏冉手里的权力给收了回来。

# 稳定人心的政治表演

【出处】《资治通鉴》173卷 陈纪7

【原文】甲午，周主入邺。齐国子博士长乐熊安生，博通《五经》，闻周主入邺，遯令扫门。家人怪而问之，安生曰：“周帝重道尊儒，必将见我。”俄而周主幸其家，不听拜，亲执其手，引与同坐；赏赐甚厚，给安车驷马以自随。又遣小司马唐遵和中书侍郎李德林宅宣旨慰谕，曰：“平齐之利，唯在于尔。”引入宫，使内史宇文访访问齐朝风俗政教，人物善恶。即留内省，三宿乃归。
