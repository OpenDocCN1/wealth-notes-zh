是不是人家做的呢，如果没有见证人，自己有理说不清，这就难了。这时候，就需要有一个第三方的在场证人，自己不说，让第三方来说，证明力极强，让目标百口莫辩。

# 二、自残伤害术的几个操作难点

+   1、公然对立的关系。

公然对立的关系，才能让自残的布局，更加完美。这是一个人的动机问题，如果你们之间不是公然对立的关系，还是表面的好朋友关系，即使真的下毒，别人也未必就信，动机的公然性。

+   2、第三方权威证人。

为什么第三方的证人呢？这样能够更加的客观，如果是自己人，即使来作证，可信度也会很低。而对方的人也不会给自己作证。所以第三方的证人，要借用他的眼睛。

+   3、无情的自残表演。

政治权术很多时候就是一场表演。这个需要纯熟的演技，无论是李世民的吐血，还是武则天杀女后的微笑，这都是需要极强的心理素质，极高的表演才能的。

# 三、这对我们的职场有什么启示？

+   1、权谋家手段无情且凶狠。

权谋家不仅仅对别人无情，在利益博弈的关键时期，如果损害自己小利益而获取未来的大利益，照样出得了手。对自己狠的人，才是真的狠，才能真的成为大权谋家。

+   2、对立后不要私下再接触。

既然对立了，为什么还要私下接触？如果你不是做鸿门宴，准备动手，就不要给自己设下瓜田李下的嫌疑。不然出事后，你自然是第一怀疑对象。

+   3、作为领导要学会鉴别术。

作为领导，其实对自残陷害术，很难识别。因为大家不相信，人会为了权谋利益，这么拼，竟然能够自残。因为很多人，都会把生命健康，放在权力之后，但是权谋家从来都不走寻常路。在权谋家眼里，权力就是一切。不过说起来，识别也很简单，就是看谁最后受益。谁受益胜出，就能看出来这是人为铺设的局。

权谋网一直强调，所有权术都是反人性的，这里的自残陷害术展示的淋漓尽致。不是每个人，都能够走“非常道”的，所以成功的道路并不拥挤。很多人觉得我心设那么狠，我做不出来。好吧，你在基层老老实实呆着，等待着被收割，也不是坏事。
