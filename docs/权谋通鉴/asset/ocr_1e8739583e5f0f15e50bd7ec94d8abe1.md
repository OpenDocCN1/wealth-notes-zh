# 三、权谋家的道德给我们的职场启示

# 1、权力面前无朋友

走向职场，彼此之间其实无形中就有了阶级，尤其是当职位空缺需要竞争上位的时候，昔日的朋友，立即就变成了互相攻讦的对手，平时随便的闲聊，都能成为攻击的工具。谁先在权力前面明确自己的敌人，谁能够最大的程度获得成功。

# 2、利益面前无感情

职场不是学校，这不是谈感情的地方，如果有人和你谈感情，说明，他谈感情会对自己有利益，把感情当成了实现利益的工具。所以，当你还在在为是不是替老板着想，感激知遇之恩时候，人家就是利用你感恩的心，在盘剥你的青春，让你多干活少拿钱。

# 3、大局面前无小节

一将功成万骨枯，所有能够做成大事的人，都是踩着别人的肩膀上去的。所以牺牲点小人物，或是让一部分小人物承担改革的代价，成为垫脚石，接盘侠，是极为正常不过的。如果你不忍心让别人为你付出牺牲，那么你就会成为别人的牺牲品。

写了这么多，是不是感觉很阴暗，背后起凉风。但权谋网认为真相就是真相，正如昨晚和朋友交流说的同样，刘邦不是流氓，刘邦和大家的道德观不一样而已。李世民虽然杀兄屠弟，但只要胸怀天下，心有所徭，能够开拓贞观之治，照样是被人敬仰的好皇帝。

# 两个权谋角度看“泄密”事件的操作

【出处】《资治通鉴》第 210 卷 唐纪 26

【原文】是时，宰相多太平公主之党，刘幽求与右羽林将军张睦谋以羽林兵诛之，使睦密言于上曰： “窦怀贞、崔、岑羲皆因公主得进，日夜为谋不轻。若不早图，一旦事起，太上皇何以得安！请速诛之。臣已与幽求定计，惟侯陛下之命。” 睦上深以为然。泄其谋于侍御史邓光宾，上大惧，遽列上其状。丙辰，幽求下狱。有司奏： “幽求等离间骨肉，罪当死。” 上为言幽求有大功，不可杀。癸亥，流幽求于封州，张暐于峰州，光宾于绣州。

【译文】这时，宰相大多数是太平公主的党羽，刘幽求与右羽林将军张暐谋策划调集羽林兵将他们一网打尽，并让张暐秘密地对唐玄宗说： “窦怀贞、崔、岑羲等人都是依托太平公主才爬上宰相职位的，他们时时刻刻都在策划如何作乱。如果陛下不早点除掉他们，一旦事变突然发生，太上皇怎么能平安呢！请快点诛杀他们。臣已经与刘幽求定好了计策，就只等陛下下令了。” 唐玄宗认为他说得很好。但事后张暐将这一计谋泄露给了侍御史邓光宾，唐玄宗知道以后十分害怕，急忙将刘幽求等人的罪状开列出来上奏了太上皇。丙辰（十九日），刘幽求被逮捕下狱。负责审理此案的官员上奏道： “刘幽求挑拨离间陛下骨肉，应当判处死刑。” 唐玄宗又为刘幽求等人向太上皇求情，说刘幽求为大唐朝建立过大功，不能判处死刑。癸亥（二十六日），唐睿宗将刘幽求流放到封州，将张暐流放到峰州，
