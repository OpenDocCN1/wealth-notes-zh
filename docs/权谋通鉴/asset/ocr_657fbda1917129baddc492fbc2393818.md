# ### 最好的造反理由——清君侧

【出处】《资治通鉴》 第217卷 唐纪33

【原文】会有奏事官自京师还，禄山诈为救书，召君诸将示之曰：“有密旨，令禄山将兵入朝讨杨国忠，诸君宜即从军。”众愕然相顾，莫敢异言。十一月，甲子，禄山发所部兵及同罗、奚、契丹、室韦凡十五万众，号二十万，反于范阳。

【译文】这时有入朝奏事官从京师回来，安禄山就假造救书，把将领都召来告诉他们
说：“皇上有密诏给我，让我率兵入朝讨杨国忠，你们应该听我指挥随军行动。”众将领
听完后都十分惊愕，相看而不敢反对。十一月甲子（初九），安禄山率领所统辖的三
镇军队及同罗、奚、契丹、室韦兵共十五万人，号称二十万，在范阳起兵反叛。

【解析】一个人想造反，不仅仅是有军事实力就行了，而且要在政治上站住脚，才能够让别人有一个追随自己的正义的理由，通常造反的高手都是采用清君侧的这个借口，因为这个借口，真的是造反最完美的借口。原因有三个：

+   1、针对大众：用奸人作为切入点，能够号召民众。

杨国忠是个大奸臣，任人唯亲，拉帮结派，排挤贤能，早已是民怨沸腾，接到所谓的密旨，皇帝被奸人蒙蔽架空，需要解救。没有人不对除掉奸人，更能激发大家内心的不满了，所以，以反对领导身边的奸人为借口，能够号召起最多人的统一战线，隐藏自己的目的。

+   2、针对自身：手下人反对领导，需要合法理由。

毕竟都是一个组织的，自己造反上司，如何维护自己的手下的组织伦理？自己如何让手下人，有个合法的理由和自己一起？这就需要说这是最高领导秘密安排的，这样在表面上依然是，听从最高权力的，这是合乎组织上下级伦理，合法的行为。

+   3、针对部下：调动大军减少阻力，直接裹挟大众。
