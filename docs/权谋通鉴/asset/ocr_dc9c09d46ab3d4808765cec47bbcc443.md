做了决策，也会能够找到好的方法赢得胜利。对他这样的怀念，其实也是推卸责任的核心，这次失败就是，他死的太早了，死得早是个客观的原因。如果不死太早就不会有错误，大家都没责任，还能展示怀念人才。

# 3、然后对这个人公开悼念

如果只是说说而已，这个影响力太小了，因为传播效果不好，没人敢去议论这件事情。但是如果公开做了悼念活动，李世民是直接做了三件事，少年祭祀，恢复名誉，赏赐家人。把一个人失败的责任承担问题转化为了一个怀念人才的问题。从失败的责任，变成当初如何会成功的问题。

# 三、作为领导人都无法避免错误，李世民这段故事，给我们什么启示呢？

+   1、权力不仅仅是承担当下错误的问题，还是未来你如何指挥的问题。

自己的决策错误，极大的会影响权威，如果你再次公然的承担错误，权威就会直线下降，不但成了别人攻击你的理由，还会影响你未来的指挥能力，会被人猜疑。所以，不是领导不承认错误，而是权威和承认错误相比，权威高于一切，权威关乎着自己地位的稳定。

+   2、推卸责任的时候，一定不能有具体的利益损失人。

作为领导推卸责任，给别人承担的话，这会引发示范效应，因为作为领导，滥用了权力，让现实中的人来背锅，肯定大家不服。这样就会动摇了自己指挥的根基，手下不服，不仅仅是威望的问题，而是以后自己的行为如何能够服众呢？所以，具体的错误，一定不能有具体责任人。

+   3、把一个错误的处罚行为，变成了鼓励的行为。

出现错误惩罚，是一个消极的心态，而对正确的行为奖励是个积极的心态。唐太宗在失败后，利用这次机会，倡导大家都要向魏征学习，争取以后不再犯同样的错误，一来推卸了责任，二来奖励了好的行为，最后还不损失权威，皆大欢喜。

经过上述的分析，权谋网认为，而对一件事情，并不是非此即彼，非对即错的二元对立问题，而是要在这些两难的境界中，找到第三条路，来平衡彼此各种利益。这就需要我们不断地提升自己的权谋智慧，不断地寻找各种更好的方案。
