# 由果寻因的权谋推断术

【出处】《资治通鉴》第 80 卷 晋纪 2

【译文】冬季十月，晋朝征召北大将军卫璀迁尚书令。当时，朝廷上下都知道太子糊涂愚蠢，不能负起王位继承人的重任。卫璀每次想向晋武帝陈述这件事都没敢开口。后来，有一次陪晋武帝在陵云台宴饮，卫璀假装醉了酒，跪在晋武帝的床前说：“我有事情想向您启奏。”晋武帝说：“你要说什么？”卫璀欲言又止一共三次，趁势用手抚摸着床说：“这个座位可惜了。”晋武帝明白了他的意思，也顺着他说道：“你真是大醉了。”从这以后，卫璀对这件事不再提起。晋武帝把东宫的官吏都召集到一起，为他们设宴，他把尚书决定不下来的事情密封起来，让太子决断应如何处理。贾妃听到这个消息非常恐惧，就借助外人代替太子回答问题，引用了很多古义。给使张泓说：“太子不学，这是陛下所了解的，但是答题引用许多古义，这必然会引起陛下对起草人的责问，反而更增加了太子的过错与不足，倒不如直以意思来回答问题。”贾妃听了非常高兴，对张泓说：“你这就给我好好地答题，我和你共享富贵。”张泓立即动手准备草稿，让太子亲笔抄录下来，晋武帝览之后非常高兴。先拿给卫璀看，卫璀局促不安，众人于是知道了卫璀曾经说过太子的坏话。贾充秘密派人对接妃说：“卫这个老奴才，差点破了你家事。

【权谋解析】这一段虽几百字，但是权谋内涵十分丰富，现在逐个解析出来，分享给大家。

# 一、卫璀的犹豫进谏术

# 1、进谏环境选择

整个组织都知道太子的智商有问题，但是没有人直说。卫璀压抑不住自己的忠心，想说，但是顾虑很大，毕竟，更换太子，涉及到方方面面的利益。卫璀只能选择一个非正式的场合，以避开大家的注意，且采用了醉酒后这个假装意识模糊的状态下，掩饰自己进谏的行为。

# 2、进谏话术安排

如果卫璀很直白的进言会让领导反感，他采用了暗示的策略。先欲言又止，想为组织好，又怕领导不开心的矛盾状态，让领导知道他是冒着风险和勇气的。然后得到允许后，又采用第二步旁敲侧击说“可惜了个位置”，等领导明白了他的意思之后，立即停止，实现了目的，点到为止。

# 3、进谏之后掩饰

通常情况下，很多人，进谏之后，看不到结果后就会不断地增加力度，不断地给领导多次说明，但是卫璀没有在之后采取任何的动作，一来自保，以免被太子背后的势力警觉；二来，既然知道皇帝的态度了，自己也尽到责任，也就问心无愧。卫璀不再提及此事，目的就是掩盖自己之前的行为。
