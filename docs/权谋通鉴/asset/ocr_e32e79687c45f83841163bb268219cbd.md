【译文】汉主刘曜回到长安，定都于此，立后妃羊氏为皇后，羊氏就是过去晋惠帝的皇后。刘曜曾经问她：“我比起司马家的孩子怎么样？”羊氏说：“陛下是开基的圣主，他是亡国的昏君，怎么能相提并论！他贵为帝王时，只有一个夫人、一个孩子和他自己三个人，竟然都不能庇护。我在那时实在是不想活了，以为世上的男人都是这样。自从做了您的妻子，才知道天下真有大丈夫。”刘曜非常宠爱她，羊氏常干预国事。

【解析】羊献容是历史上一个传奇的皇后，一生五度六嫁。除了美貌之外，其智慧亦有过人之处。上面这段材料，就集中体现了羊献容的驭男术。

每个人都有自己的历史，大多不是和自己的初恋结婚，被问及前任和现任的对比，是每个人的心结。尤其是男人，对女人的前男友更加关注。我们详细分析下羊献容的精妙回答：

一、羊献容的回答分为三个部分

# 1、何可并言

“陛下开基之圣主，彼亡囹之暗夫，何可并言”。男人心里是想和其前任做对比，内心充满着嫉妒之心。但是羊皇后，是个聪慧的女人，直接就否定了可对比性。首先从根源上满足了男人的虚荣。也为下面的话，做了立论。

# 2、总不能庇

“彼贵为帝王，有一妇、一子及身三耳，总不能庇。”接下来这句话，羊献容，没有从吹捧的角度，来说现在的你多么的优秀，而是说，前任连基本的家庭和自己都不能保护。从最根本上，作为一个男人都不够格，就别提其他的了，从人性上否定是最坚决的。

# 3、始知丈夫

“妻子尔时，实不欲生，意谓世间男子皆然。自奉巾栉已来，始知天下自有丈夫耳！”羊献容，通过对比，来直接拔高现在的丈夫。侧面吹捧汉主是真正的大丈夫。这样让男人心里极度的舒服，这是从人本性着手的赞美。真男人，是对男人的最好的评价。

# 二、羊献容这段回复的台词高明在何处？

# 1、没有放在平等地位对比

如果放在同一个层次做对比，无论你说什么，都会激发男人的醋意。因为他会在潜意识里认为你是通过对比优劣，他稍微胜出而已。是数量级的超越，而不是质量级的超越。

# 2、没有对身体之物做对比

羊后的高明在于，没有通过身外之物的荣华富贵，聪明智慧或是功名利好，等做对比，而是从作为一个男人的角度直接否定了前任。这就是潜在的对汉主说，我看中的是你的人，不是你的钱。
