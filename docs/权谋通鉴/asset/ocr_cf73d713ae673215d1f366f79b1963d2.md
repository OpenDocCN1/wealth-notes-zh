# 二、王祝的心态及其行为

# 1、拒绝的心态

王祝内心其实是看不上王琪的，你是什么东西。我未来是国家的宰相，就你，想凭几顿饭，趴在地上磕几个头，就想和我建立深度的关系，这绝对是个亏本的买卖，所以，为了避免日后的麻烦，果断拒绝。王祝拒绝的心态有两个，一方面是性格原因和王琪不合，另一个方面觉得合作对自己而言吃亏。

# 2、拒绝的方法

很明显，我们从故事中看到，王祝是个高智商低情商的人，人品不错，但是缺乏权谋智慧，缺乏拒绝的技巧，即使心里再不愿意，人在屋檐下不得不低头，这句古训都不清楚，当众让王琪下不了台。导致了关系极度恶化，其实稍微虚与委蛇就行了，过了王琪的地盘该如何还如何就行了。

# 3、低情商后果

王祝低估了王琪当下的势力和小人心态，君子大多对小人的恶劣手段预判不足，以为别人都和他一样的光明正大。这时候王祝还没有到任中央，还没有成为宰相，被搞死之后，朝廷自然会持平，又没有必要为一个没有什么实力的人，和地方节度使发生矛盾。于是，王祝死了自死。

# 三、王祝被杀的职场教训

# 1、拒绝的背后是面子

权谋家拒绝别人，权谋网讲过，通常是拖延式拒绝，条件式拒绝等，之所以如此不能直白，关键就是考虑到别人的面子和感受。如果一个人直来直去的把自己的意图都写在脸上，表面上做人耿直，其实是让别人尴尬，这就是在潜在树敌。职场很多所谓的好人，都是不给人面子之后，不知不觉中树敌的。

# 2、考虑到相对的实力的

人与人之间的关系，核心的就是利害的计算，长远利益是一个方面，但并不是永远都有效。王祝长远看，自然看不上王琪，但是就眼前而言，王祝还在王琪的地盘上，毫无防御能力，这就要考虑到当下的伤害。权谋家的计算方式，是先算最坏的局面能否承受，然后再看未来的好处如何实现。

# 3、永远不要低估小人

你是一个有底线的人，但是别人却不一定。你不会使用的手段，或是你看不上 的手段，不代表别人不会使用。所以，永远不要站在自己的角度去判断对手的手腕。很多正人君子打不过小人，原因就是在手段上自缚手脚。所以想成就一番事业，就必须要能低估小人的凶残。
