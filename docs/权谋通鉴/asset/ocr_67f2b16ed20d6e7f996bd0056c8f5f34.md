# 谗言兴起的本质原因

**【出处】** 《资治通鉴》22 卷 汉纪 14

**【原文】** 上用法严，多任深刻吏。太子宽厚，多所平反，虽得百姓心，而用法大臣皆不悦。皇后恐久获罪，每戒太子，当留取上意，不应擅有所纵舍。上闻之，是太子而非皇后。群臣宽厚长者皆附太子，而深酷用法者毁之。邪臣多党与，故太子誉少而毁多。卫青死后，臣下无复外家为据，竞欲构太子。

**【译文】** 汉武帝用法严厉，任用的多是严苛残酷的官吏；而太子待人宽厚，经常将一些他认为处罚过重的事从轻发落。太子这样做虽然得百姓之心，但那些执法大臣都不高兴。皇后害怕长此下去会获罪，经常告诫太子，应注意顺从皇上的意思，不应擅有所纵容宽赦。汉武帝听说后，认为太子是对的，而皇后不对。群臣中，为人宽厚的都依附太子。而用法严苛的则都诋毁太子。由于奸邪的臣子大多结党，所以太子说好话的少，说坏话的多。卫青去世后，那些臣子认为太子不再有母亲娘家的靠山，便竞相陷害太子。

**【权术解析】** 每个人，在职场就会不断的，面对别人的进谗和攻击。很多时候，大家面对谗言都有破解回击的欲望，但是很少人去反思谗言兴起的根源，只有从根源处，发现问题，才能断掉谗言。

汉武帝一直护着太子，但是为什么，大家还是在不断地构陷太子呢？原因有三点：

+   1、得罪既得利益派

汉武帝手下任用的大多是酷吏，这样的人不是一个，而是一个势力最为强大的既得利益群体。这些人，能够看到，如果未来太子上位，这群人也失去了所有的政治资源，自己的前景堪忧。尽管太子没有具体某个人，为敌人，但是却是以一个改革者的形象出现的，要改变政治利益。所以，得罪了当下最有实力的官僚群体，这些人，只有搞掉太子，才能保住位置，所以这是兴起谗言的基础。

+   2、亲己派无战斗力

亲近太子的这些宽厚的人，都不善于结党。这类人，大多是我行我素。没有形成战斗力。这群人，尽管觉得未来太子继位，会对百姓不错，但是他们却没有去想，他们最大的敌人是谁，阻力在哪里？而太子，在面对皇后的劝谏，也没有警觉，以为汉武帝，是信任自己的。但是他并没有想过，自己统治是没有基础的，是需要有一个亲己联盟的。自己的派系没有战斗力，也就不会让反对派有所顾忌。
