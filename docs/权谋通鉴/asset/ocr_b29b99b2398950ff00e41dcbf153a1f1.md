的计谋，少做迟疑，杀他的就不是王敦而是明帝了。很多权谋高手都是王敦这样，通过给对手的亲情好处，制造他们之间的隔阂，从而成功离间其内部关系。韩非子在《六微》篇中也描述过类似的故事：楚王派人到秦国去，秦王很尊敬这位使者。秦王说：“敌国有贤人，就是我国的祸患。现在楚王的使者很能干，我很担心。”群臣劝谏说：“凭大王的圣明和国家资财的丰富，而没笼楚王手下的贤人，大王何不与他深深地结交，暗中加以笼络呢？楚国以为他被外国利用，一定会处罚他的。”

【总结】温峤是自保全的高手，上述的这整体的故事，表现出三大方面，首先是，通过讨好强势，服从别人自保，让王敦和钱风没有继续加害；其次是，通过公开矛盾，疏离关系，避免被钱风在背后做小动作陷害；最后是通过出卖王敦依附更大的势力，自保。所以说，自保全并不仅仅是沉默不言，忍气吞声，服从这个路径，还有公开矛盾，还有立即出卖。其主旨目的都是让自己处于安全之地。不能不说，温峤权谋大师级人物，值得我们深度学习！

# 职场中信任才是一切

一个人在职场中最重要的核心竞争力是什么？很多人认为是自己的业绩，自己的工作能力，其实这个大错特错，职场的唯一核心竞争力是上级领导对你的信任关系，没有这个一切都是扯淡。先别急于辩驳这个观点，先看看《资治通鉴》第97卷，晋纪19中的这个故事：当初，后赵领军王朗对后赵王石虎陈言说：“隆冬雪寒的季节，太子却让人砍伐修建宫室的木材，沿济水运送而来，参与劳役的人有数万，呼嗟叹息之声充溢道路，陛下应当乘出游时加以制止。”石虎听从。太子石宜发怒。适逢火星在房宿，石宜让太史令赵揽对石虎说：“房宿是天王，现在火星停留于此，祸殃不小。应当用显贵大臣中姓王的人承当罪责。”石虎说：“谁能承当？”赵揽说：“没有比领军王朗更显贵的了。”石虎心中爱惜王朗，让赵览再说其次的人选。赵揽无法回答，于是说：“其次只有中书监王波了。”石虎于是下诏，追穷王波从前评议送矢给汉国，自取其辱一事的原委，处以腰斩之刑，连同四个儿子，将尸体丢入流水。不久又怜悯王波没有罪过而遭极刑，追赠为司空，封王波孙子为侯。通过这个极端的职场故事我们能够看出三点：

+   1、职场中每个人都处在利益漩涡的中心。天寒地冻的时候，太子搞大型工程，弄得民不聊生，王朗为了维护老百姓的利益，让当时的皇帝石虎制止了。这无形中就触动了太子的利益，太子必须搞掉王朗。现实职场中就是这样，你尽责任就可能得罪别人的利益，你不尽责任，尸位素餐，领导不满意。所以说，有人的地方就有江湖，就江湖的地方就有纷争，你在利益漩涡，就无可避免争斗。

+   2、只有和领导之间的信任关系才是一切。
