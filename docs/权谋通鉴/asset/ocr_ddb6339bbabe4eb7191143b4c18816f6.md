# 释疑术——破解被猜疑的学问

【出处】《资治通鉴》第 264 卷 唐纪 80

【原文】睦州刺史陈询叛钱镠，举兵攻兰溪，镠遣指挥使方永珍击之。武安都指挥使杜建徽与询连姻，镠疑之，建徽不言。会询杀吏来奔，得建徽与询书，皆劝戒之辞，镠乃悦。建徽从兄建思诬建徽私蓄兵仗，谋作乱；镠使人索之，建徽方食，使者直至卧内，建徽不顾，镠以是益亲重之。

【译文】睦州刺史陈询背叛钱镠，率兵进攻兰溪，钱镠派遣指挥使方永珍率兵前去攻打陈询。武安都指挥使杜建徽与陈询是姻亲，钱镠怀疑他，杜建徽不辩解。恰巧陈询的亲情属吏前来投奔，钱镠得到杜建徽给陈询的书信，都是劝告陈询改过的话，钱镠这才喜悦。杜建徽的堂兄杜建思诬陷杜建徽私自贮备兵器，阴谋作乱。钱镠派人前去搜索，杜建徽正在吃饭，使者径直进入卧室搜查，杜建徽毫不顾忌，钱镠因此更加亲近推重他。

【解析】无论是在官场还是在职场，总有被猜疑不忠心，要背叛的时候，这时候，被猜疑的很多人心存不满，于是走向了一个错误的道路。如何摆脱自己的嫌疑，的确是个大学问！

# 一、杜建徽摆脱嫌疑三招！

# 1、对领导不辩解

面对自己的姻亲背叛，自然而然的杜建徽不能摆脱嫌疑，这时候，如果主动去找钱镠辩解。不仅仅毫无用处，反而会加重领导的反感。因为即使以后证明没有和姻亲有关联，钱镠也会认为，杜建徽内心不满，潜在的也证明领导认识错误。无论是内心不满，还是证明领导有错，未来杜建徽都不会有前途。

# 2、对嫌疑巧劝戒

对于背叛领导这个姻亲，以前绝对是有苗头的，如果杜建徽只是口头的劝诫，这以后谁知道呢，所以，通过书信的方式，而且是大量书信，为自己留下书面证据。这里要说明的是，为什么不主动说自己有书信劝戒呢，这样做会有反作用，领导会认为，发现了苗头，你为什么不检举，你想为他遮掩嘛？

# 3、对监察不顾忌

杜建徽正在吃饭的时候，面对检查表现的从容而不抗拒，一来表现出自己的内心的坦荡，二来表现对领导没有对抗情绪。即使没有错误，你抗拒检查，这本身就是错。所以这之后，钱镠对杜建徽更加看重，面对猜疑，稍有抗拒，不管你是不是犯错，领导会认为你内心有不满，这样对领导不满的人，不能用。
