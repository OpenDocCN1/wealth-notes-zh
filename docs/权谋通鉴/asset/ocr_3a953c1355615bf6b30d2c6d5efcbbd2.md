# 吕布战略决策成败评析——危机中如何定谋

【出处】《资治通鉴》第 62 卷 汉纪 54

【译文】广陵郡太守陈登举领广陵郡郡兵作为曹操的先锋，进抵下邳。吕布亲自率军，屡  次与曹操交战，全都大败，只好退守城池，不敢出战。曹操写信给吕布，为他陈述利害，  吕布恐惧，打算投降。陈宫说：“曹操远来，势不能停留多久。将军如果率领步、骑兵屯  驻城外，由我率领剩下的军队在内守城，如果曹军进攻将军，我就领兵攻击他们的后背；  如果曹军攻城，则将军在外援救。不过一个月，曹军粮食吃光，我们再三反击，可以破敌。”  吕布同意，打算留陈宫与高顺守城，自己率骑兵截断曹军的粮道。吕布的妻子对吕布说：  “陈宫与高顺一向不和，将军一出城，陈宫与高顺必然不能同心协力地守城。万一出现什  么问题，将军要在哪里立脚！而且曹操对待陈宫犹如父母对待怀抱中的幼儿，陈宫还会弃  曹操来投靠我们；你待陈宫并未超过曹操，就把全城交给他，抛别妻儿家小，孤军远出。  如果一 having 有变，我难道能再做你的妻子吗？”吕布就打消那个计划，偷偷派遣部下官员许  汜、王楷向袁术求救。袁术说：“吕布不把女儿给我送来，理应失败，为什么又来找  我？”许汜、王楷说：“您现在不救吕布，是自取败亡。吕布一败，您也就要破了。”袁术于是  整顿动员军队，声援吕布。

【解析】人生的路很长，但是关键时候就几步，尤其是到了危机的时候，如何决策，这是  考验一个人的谋略水平的，因为其他时候，还有改错的机会。而到了最后关头，一步错，  就会万劫不复。通过对吕布最后的谋略分析，来给大家一丝启示！

# 一、吕布屡战不胜的情况下有三条路可选

# 1、投降

吕布一直想做一方诸侯，如果此时投降，自己多年来的独立性就会消失殆尽，自己的武装  就会被直接收编分解。一个做老板的人，从此只能做打工者了。这种转变，大多数人无法  做到，落差太大。再一个，失败多次，此时投降过去，也不会受到什么优待。吕布投降无  异于，政治生命的终结。

# 2、死战

陈宫给出的计谋，就是通过分兵，疲敌之计。通过拖延时间，来消耗曹操的粮草。看似毫  无漏洞的计谋，其实是大问题的。那就是，外敌强大的情况下，内部是要分裂的。历史  经验一再表明，在实力相差悬殊的时候，弱势方内部问题就会激化，没有人愿意陪着去死。
