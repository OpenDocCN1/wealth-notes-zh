很多人认为自己对领导有功，和权力的关系很好，就能躺在之前的功劳簿上，够靠这个吃一辈子。其实这是个很错误的心理，权力从来不看你之前做了什么，而是看你之后还能为什么做什么。毕义云并没有认为有对皇帝的拥立之功，就肆无忌惮了。权力只看重来，而不是怀念过去。

2、权力不限于领导本人，还在于谁能够直接影响他的决策。

自己不能够继续为权力提供更多的服务和贡献，这就意味着，权力关系的逐步丧失，这时候，就要发现谁能够继续为领导提供服务和贡献，这样的人就要结交，因为，尽管这个新上位的红人权力不大，但是它能够直接影响皇帝权力决策，必须结交。要么自己持续为权力服务，要么结交持续服务的人。

# 二、处理和同僚的关系

# 1、善于结交

任何一个人想成就事业，就必须和同僚保持友好的关系，这样不单单是不树敌的原因，还有能够凝聚更多的势力来为自己服务。所以毕义云和同样有对皇帝拥立之功人，结交成为联盟，巩固自己的权力。一定要和领导身边你的人搞好关系，不管自己的地位有多高。

# 2、善于抛弃

当毕义云得知和士开和自己的同党关系不睦的时候，果断的抛弃了和这些之前同党的联合，毫无顾虑的通过行贿、出卖而转换自身的阵营，同新红人重新结党，而不是为了维护旧利益关系，对抗新的关系。争取新关系比挽救老关系要简单的多，抛弃同党毫无心理障碍。

# 三、处理和内心的关系

# 1、能够做大，也能够做小。

可以这么说，毕义云的地位远远在和士开之上，但是和权力的亲密关系却恰恰相反。毕义云能够屈尊向和士开行贿结交，这就充分的说明了，毕义云不看重自己的地位、自尊，而是完全以权力的亲密关系为标准指导自己关系的，谁和权力亲密，谁地位高。

# 2、能够高调，也能够忍耐。

毕义云拥立皇帝登基，和其他功臣结为同党，是何等的风云人物，但是一旦看出来，皇帝对他们这群人稍有不满的时候，就明白了，未来的位置岌岌可危。于是，主动巴结朝廷新贵，让自己立即外放做刺史，逃离是非的漩涡，能够在地方低调忍耐，不在乎眼前得失。毕义云能够官场不倒，就在于他紧紧抓住了权谋决策的核心，以权力亲密度为方向，毫无感情羁绊，内心没有尊卑束缚，位置能上能下，这样的人，不成功都难！
