书谢罪。刘秀下诏书回答说：“将军对于我，从道义上讲是君臣关系，从情义上讲就像父子，你有什么嫌疑而要害怕！”

【解析】皇帝对有能的人心理是矛盾的，一方面自然希望用的人有能力，能够把工作做好；另外一方面，又怕有能力的人有野心，最终尾大不掉。这有矛盾的心理，自古以来就有“用人不疑，疑人不用”的说法，但是这个并不是解决的方案，帝王权术，成功的解决了这个问题，就是边用，边敲打。

我们通过东汉光武帝刘秀驾驭冯异的权谋，来解析这个敲打术的玩法。

# 一、奏章的来源和攻击点

# 1、写奏章的人的三种心理

面对冯异把关中地区治理的这么好，写奏章的人，有三种可能心理，首先就是彼此不一个派系，看不得你做的好，就想没事找事诬陷你；其次是感觉你有这个造反的实力，提醒刘秀，这是讨好立功的心理；最后就是可能是职责所在，本质工作就是监察百官。

# 2、最大可能的是授意表演

上述的三个心理是孤立的站在上奏章的人本身推理的，但是，还有一种可能就是，这是光武帝授意有关人士起草的，面对日益做大的冯异，皇帝主动提出来，不合适，这就需要有人给个由头，来可进可退的敲打冯异。这样的授意的好处，就是有了切入的点，显得不唐突。

# 3、奏章攻击点的整体设计

这个奏章别看十几个字，可以说是面面俱到，因为攻击了三个重要的点，对上有重权“异威权至重”，对下有民心“百姓归心”，自己有野心“号为咸阳王”。这就各个方面指出了冯异造反的可能性，而且绕开了冯异的工作成绩。把工作能力问题转化为权力野心问题，历来攻击对手无不如此。

# 二、面对攻击奏章的心理

# 1、如果很信任

面对这个攻击奏章，如果刘秀很信任冯异，最简单的方法，就是当场驳斥上奏章张的人，然后再派人告诉冯异这件事情，表明上下无猜，可以安心工作，我绝对的信任你。

# 2、如果不信任

如果不信任，觉得自己无法驾驭冯异，或者是准备除掉他，这时候，刘秀就会把这个奏章暗地里压下来。不动声色，然后找借口让他回来汇报工作，然后拿出来，当庭对质，直接杀掉。

# 3、如半信半疑

如果半信半疑，这时候，就不能直接表现自己的信任，或是不信任，这就需需要把信直接给冯异看，用来敲山震虎，投石问路，来一次火力侦察，看冯异的反应。
