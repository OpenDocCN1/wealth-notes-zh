# 一、抱怨的产生的原因是什么？

抱怨一般来说，来自三个方面：

首先是同向比较，片面的认为别人不如自己，而比自己的待遇好，心里不满。刘文静觉得裴寂能力不行，不如自己，但是他不想下，为什么人家裴寂能够上去。仅仅是因为业务能力和领导的关系也是一大方面。

其次是期待落差。自己认为自己的功劳很大。认为应该得到更多的待遇，刘文静一直躺在之前的功劳簿，你的待遇不是源自之前你做过什么而是你未来能做什么。自己的付出觉得和得到的不成比例，这时候期待落空，陷入抱怨。

最后是怀才不遇。认为自己有能力，领导看不出来，认为领导有眼无珠，认为自己缺乏一个一展抱负的平台和机遇。每天不思进取，不是为了改变自己实现自己而努力，而是处处喝酒闹事，发牢骚。作为一个下属要明白，所谓的才华，必须首先的要让领导认可。不被认可的才华，都是想当然。
