# 1、看能力

我们预测一个人，首先要看一个人他拥有什么能力。他必须把自己的精力和智慧聚焦在一点上，才能让自己拥有突出的能力。这个突出的能力和社会的匹配程度，决定他能攀爬的高度。

# 2、看关系

光有能力是不行的，一个人必须和周围的人产生互动。如果有好的关系，那么这就能够拥有很多助力，能够走得很远。如果产生不良互动，那么周围都是阻力，很难走太远。

# 3、看资源

有能力，有关系，你绝对能起来，但是你沒有资源，就需要多年的积累跟等待。没有资源会放慢你崛起的速度，不楚就像段子里说的，我奋斗了18年才和你坐在一起喝咖啡。

经过权谋网上述的分析和研究，大家能够看出权谋人性预测术的核心内容，就是从这三个方面对人性予以预测的。大家用来观摩周围的人，应该会立即产生预测力。

# “以求卒中”的权谋技巧

【出处】《资治通鉴》138卷 齐记4

【原文】魏主自发平城至洛阳，霖雨不止。丙子，诏诸军前发。丁丑，帝戎服，执鞭乘马而出。群臣稽颡于马前。帝曰：“庙算已定，大军将进，诸公更欲何云？”尚书李冲等曰：“今者之举，天下所不愿，唯陛下欲之。臣不知陛下独行，竟何之也！臣等有基意而无其辞，敢以死请！”帝大怒曰：“吾方经营天下，期于混壹，而卿等儒生，屡疑大计；斧钺有常，卿勿复言！”策马将出，于是安定王休等并股勤泣谏。帝乃诩群臣曰：“今者兴发不小，动而无成，何以示后！朕世居幽朔，欲南迁中土；苟不南伐，当迁都于此，王公以为何如？欲迁者左，不欲者右。”安定王休等相帅如右。南安王桢进曰：“‘成大功者不说于众。’今陛下苟辍南伐之谋，迁都洛邑，此臣等之愿，苍生之幸也。”群臣皆呼万岁。时旧人虽不愿内徙，而惮于南伐，无敢言者；遂定迁都之计。
