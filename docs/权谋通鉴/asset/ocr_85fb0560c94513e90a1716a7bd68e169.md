拍马屁的手段自古以来，花样翻新，层出不穷，但是能够面对，一碗陈年类便酿制的黄龙汤，一般人真的是无法接受，想想这个场面都让人作呕。但是这种极端的反人性，反生理的手段，所以才成了最高境界。所以，这一关都过了，还有什么手段使用不出来呢？

# 3、舆论灾难

拍马屁这总事情是瞒不住的，短时间就会不胫而走，不然也不会写在资治通鉴里，千年之后，还让后人观摩学习。一旦传出去，周围的道德价值观并不能接受，背后遭到指指点点很正常。这就需要不在乎舆论，只在乎在领导眼里的位置。权谋家都是不在乎周围人怎么看的。

# 二、拍马屁有三大风险

# 1、领导鄙视

再有一个同样的故事，《资治通鉴》205卷：宁陵丞庐江郭霸以谄谀干太后，拜监察御史。中丞魏元忠病，霸往问之，因粪其粪，喜曰：“大夫粪甘则可忧；今苦，无伤也。”元忠大恶之，遇人辄告之。郭霸作为省部级的高官了，还这样尝粪拍魏元忠的马屁。但是魏元忠，非但知不领情，还大恶之。

# 2、人格丧失

吃粪污这样的举动，立即会被传播开来，被人当成茶余饭后后的笑柄。魏元忠到处传播逢人便说，这样郭霸的名誉直接扫地，无人格尊严可言。在众人眼里就是一个无底线，无原则的小人，没有人愿意让自己的人格被人贬低，自尊受到伤害。

# 3、群体孤立

一旦被定为小人，立即就会被群体所孤立。作为君子的人，大家鄙视这样的小人，不愿意与之交接。而其他的小人呢，并不会同类相惜，而是觉得这是争宠的行为，既然你这么无底线的争宠，那不能不孤立你，陷害你，除掉你这个竞争对手。所以做阿谀的小人，容易获群体孤立。

# 三、给我们的职场启示

# 1、研究好领导

同样是尝粪的行为，为什么讨好和士开就成功了，而郭霸讨好魏元忠就失败了呢？这个差别就是，没有研究好领导的特点。和士开有很多养子，很受用大家的奉承。而魏元忠是个政治家，还有一半的军事作风，讨厌这类小人，所以，郭霸失败。研究好领导，投其所好，马屁才能成功。

# 2、私下里表现

为了降低舆论和被孤立的风险。拍马屁的行为最好在两个人单独相处的时候。只要领导受用就行了，公开场合的这类尝粪的事情还是尽可能的避免，毕竟周围的卫道士还是很多的。能够私下，绝不公开，能够人少处，绝不在人多处拍。
