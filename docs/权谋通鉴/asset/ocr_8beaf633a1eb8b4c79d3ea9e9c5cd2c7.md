# 1、萧摩诩必须释放原因

权力考虑的不仅仅是已发生的事情该怎么处理，还要考虑，处理后会有什么样的影响。所以，隋文帝考虑的不仅仅是萧摩诩被儿子造反要连坐的问题。而是更要考虑，如果处理掉萧摩诩会有什么结果，首先是自己会失去这个心腹爱将，天下此时并不太平，还在用人的时候；其次是萧摩诩如果被杀，会激发更多的军变，因为其在军中的势力会内心不安，从而可能造反加入对手阵营；更为重要的是，最后一点，江南举兵作乱的实力，打着萧世略的旗号，本身可能就是一箭双雕，一来利用萧摩诩的号召力，二来可以假借皇帝之手除掉萧摩诩。所以，基于这三点考量，隋文帝要赦免萧摩诩。
