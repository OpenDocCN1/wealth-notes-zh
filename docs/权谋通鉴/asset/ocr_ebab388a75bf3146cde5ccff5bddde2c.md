# 动机解释是破解小报告的法宝

【出处】《资治通鉴》255卷，唐纪71中的这个故事：

【译文】高骈的侄子左骁卫大将军高渥，陈述吕用之的罪状，状纸达二十多篇，秘密呈交高骈，并且哭着说：“吕用之在内假借神仙鬼怪，迷惑您的耳目，在外则盗用节制权柄，残害地方百姓；将领军官都惧怕大祸，而不敢说话。随着时间的推移，吕用之的羽毛将要丰满，翅膀要硬起来，如果不把他铲除掉，恐怕高家世代的功劳，在一个早晨就会败落下去！”于是情不自禁地痛哭起来。高骈说：“你是喝酒过多了吧！”叫入把高渥搀扶出去。第二天，高骈把高渥的诉状展示给吕用之看，吕用之说：“高渥曾因手头拮据请求救助，没有获得准许，所以对我怀恨在心。”吕用之顺便拿出高渥原来亲手写的几封信呈送高骈。高骈十分惭愧，于是禁止高渥随便出入；一个月后，让高渥去掌管舒州事宜。

+   一、高渥的小报告错在了哪？
