【总结】这个假太子事件，成功的让隽不疑脱颖而出。核心的原因就是大家迷茫于是非的标准的时候，他选择了权力标准。职场有是非观念的人其实很难走的远，一个简单的例子，在职场有人和上司争论，你认为这个人对的，支持了他，这就无形中得罪了上司，你上司眼里就是权力的反对者，很难有好果子吃。职场的对错，是不讲对错标准的，就讲权力标准，你要在们辩论时支持上司，维护权力，这才是正确的选择，你才能快速的得到领导的赏识。所以在职场讲究对错，本身就是一场灾难！

# 行私心于无形——如何巧妙地打赏自己人

【出处】《资治通鉴》第 31 卷 汉纪 23

【原文】上以赵后之立也，淳于长有力焉，故德之，乃追昱其前白罢昌陵之功，下公卿，议封长。光禄勋平当以为：“长虽有善言，不应封爵之科。”当坐左迁巨鹿太守。上遂下诏，以常侍阎，侍中、卫尉长首建至策，赐长、阎爵关内侯。

【译文】汉成帝由于在立赵飞燕为皇后这件事情上，认为淳于长帮了大忙，因此十分感谢他，所以特意回顾传扬他之前建议撤销昌陵的功绩，让公卿讨论封淳于长爵位。光禄勋平当认为：“淳于长虽然有好的提议，但是还是不符合封爵的规定。”平当因此被贬为巨鹿太守。于是汉成帝下诏书说，因为常侍王閬、卫尉淳于长率先提出至善的建议，赐予淳于长和王閬关内侯。

【解析】作为一个组织的最高领导，有时候个人利益和组织利益是不一致的。他们需要维护自己的私人利益的人，如何公开的用组织的方式，来赏赐自己人，这是很费心思的。权术思维，就是如何在思维的窄缝中找到最佳路径！

+   一、汉成帝为了奖励给自己办私事的淳于长有三道难关要过

+   1、不能用真实的理由

如果直接封赏，说淳于长帮助自己，在立赵飞燕做皇后的事情上，有了大功劳，这个理由，立即就会让自己陷入舆论的漩涡，作为皇帝，为了女人而奖赏帮自己做私事的人，这会让自己的帝王形象大为贬损，所以，必须找到一个非私人的理由。

+   2、要能够控制住舆论

真的对组织有功，直接奖励无可厚非，但是通常这类人，就不会有大的功劳，找个小的理由直接奖赏，不是不行，而是大家会议论纷纷。反对的阻力会很大，所以这就需要枪打出头鸟，把反对派直接镇压了，这就能够公然表达态度，别人也不敢公开讨论了。

+   3、要做好表面的工作

如果就直接奖赏一个人，会被人抓住把柄，作为领导最起码的表面工作要做好的。这就需要掩饰好自己的目的，需要给大家一个自己没有私心的交代。搞政治，无论私心如何，在表面都不能有瑕疵，表面工作是政治家的基本要求。
