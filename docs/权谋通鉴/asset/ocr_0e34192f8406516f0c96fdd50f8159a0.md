【译文】司马懿诸诸葛亮相持了一百多天，诸葛亮多次挑战，司马懿就是不出兵。诸葛亮就把妇女使用的头巾、发饰和衣服送给司马懿，司马懿恼羞成怒，上表请求出战。明帝派遣卫尉辛毗执持节符为军师来节制司马懿的行动。护军姜维对诸葛亮说：“辛毗持节符来到，贼军不会再出战了。”诸葛亮说：“司马懿本来就无心作战，所以一定要请求出战，是向部众表示敢于用武而已。将领在军中，君主的命令可以不接受，如果他能制胜我军，难道还要远离千里而请求作战吗？”

【解析】对于权谋家而言表达能力是基本能力之一，因为相当一部分计谋，都需要做样子让别人看，并且特殊情况下，还需要有其他角色配合加入，给大众呈现出来一场大戏。常见的就是红白脸的配合技巧，来对目标产生影响。

# 一、司马懿面对诸葛亮的激将术的尴尬处境。

# 1、司马懿受到侮辱必须出战。

部队最讲究的就是血性，所以激将法一般来说都比较好使。面对来自对手的侮辱，如果不出战，不仅仅是自己的情绪不能接受，另外一个，主帅如果被羞辱而无动于衷，以后大家会认为司马懿无勇气。一个没有勇气，怯懦的人，如何带兵？

# 2、司马懿从战略上又无法出兵？

诸葛亮的战略重在速决，因为他的粮草问题一直是个大问题。而司马懿坚守战略，就是最佳的战略。如果出兵就中了诸葛亮的计策，自己也违背了兵法说的“将不可怒而兴兵”的原则。所以不能违背战略，让情绪主导理性。

# 二、如何展示自己的勇气主战又不出兵呢？有什么方案？

# 1、自行宣讲。

司马懿如果把队伍的战略讲出来，让大家必须克制等等，这样说出去，其实真相有时候并不为大众所能理解，大家都认为你在找借口掩饰，你的忍让会让人觉得无能。

# 2、向上请示。

最好的策略就是司马懿所采用的办法，把问题推出去。向领导请示，表达自己的主战的欲望，而让领导的意思压制住众多人的悠悠之口，让大家认为主帅是主战的，有勇气，责任是国家的。

# 1、真相不能压制情绪。

群众要的不是真相，而是情绪的迎合。因为任何理性的行为都不适合大众的宣讲。大众群体的性格就如女人的性格，只能疏导情绪，无法沟通理性。所以，面对下属的情绪，最好的办法，就是从自身转移出去。千万不要和大众讲道理。
