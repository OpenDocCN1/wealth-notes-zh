力不说，还让人反感；另外一个方面就是，用人如器，无论是小人还是君子，都要利用其本性来为我所用。

# 2、大势

禹浚九川，障九泽，因其势也。我们经常用的词汇叫做权势，其实就是你个人无法对抗的力量，社会中的大势就是权力。这也有两方面的意思，一个就是不要对抗权力，对抗权力你只能被权力所打倒。大禹的父亲，鯀，就是想用堵的方式治水而失败。另外的就是改变自己顺应权力，因其势的本意就是如此。

# 3、天时

你个人再勤劳，冬天地里也长不住庄稼。科技再发达，孕育孩子，也不可能三个月。因此时这个要素，对我们来说有两重意义。一个就是在正确的时间做正确的事，上学的时候就好好学习，工作的时候，努力工作，每个阶段做每个阶段要做的事情；另外，很多事情，需要时间的积累，不能急于求成。

# 4、人心

汤、武轩天下而攻桀、纣，因其心也。这个人心也是分为两个方面，一个是自己内部的人心聚合，是不是能够团结一致，凝聚大家的共识和利益；另外一个方面是，对手的内部是不是离心离德，人心散乱，怨声载道。以有道伐无道，这才是人心向背的根本所在，得人心者得天下。

一个人想成就大事，必须是，基于上述的四大外部因素的控制和使用。很多鸡汤文章或是成功学的文章，都片面的强调，个人奋斗的努力因素，这个很片面。小事还行，大事就必须顺其自然。比如马云，如果现在让他创业，也不可能再做一个淘宝，大企业家都是时代的产物。
