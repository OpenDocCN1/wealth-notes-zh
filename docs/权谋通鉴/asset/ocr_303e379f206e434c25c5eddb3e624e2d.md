# 顶级权谋测试之“反言测试”

【出处】《资治通鉴》第265卷 唐纪81

【原文】全忠尝与僚佐及游客坐于大柳之下，全忠独言曰：“此木宜为车载。”众莫应。有游客数人起应曰：“宜为车载。”全忠勃然厉声曰：“书生辈好顺口玩人，皆此类也！”车载须用夹榆，柳木岂可为之！”顾左右曰：“尚何待！”左右数十人持言“宜为车载”者，悉扑杀之。

【译文】朱全忠曾经与属官及门客坐在大柳树下面，朱全忠自言自语地说：“这株柳树适宜于做车载。”属官没有响应。有几个游客起身响应说：“适宜做车载。”朱全忠勃然大怒，声音严厉地说：“书生之辈喜好顺口附和以玩弄人，都像这样！车载必须用榆木制作，柳木岂能制作！”环视左右的人说：“还等待什么！”左右数十人，拉出说“适宜做车载”的门客全部打死。

【权术解析】权谋集大成宝典《韩非子·内储说上》：“倒言反事，以尝所疑，则奸情得。”翻译过来意思就是说用倒话做反事来测试怀疑不决的事情，就可以了解奸佞的情况。后梁太祖朱全忠，深得权术三昧。这个案例就是经典的反言测试。注：车载（gù），指车轮中心插轴的部分，泛指车轮。

# 一、当朱全忠说过柳木为车载的这个明显错误话的时候，该如何回答？

1、不说话。

文中朱全忠身边的属官都是没有响应的。可以这么说，在官场，宁可不做，不能做错。不做，只是被认为是庸官。做了可能会犯错，事情不明白、不明朗的时候，不做表态，可以说是最安全的选择。当然这也是进步最慢的招数，你不能揣摩上意，自然也就不会快速迎合权力而进步。

2、说假话。

看出领导错误了，然后自己就说假话，迎合领导，拍马屁嘛。但是文中，大家看出来了，凡是拍马屁的，都丢掉了自己的性命，朱全忠用这样的“反言测试”引诱，身边阿谀之徒主动现形，给身边那些有歪心思的小人，一个极大的震慑。

3、纠错话

那我们不提假话，直接指出领导错误，行不行？这个自然不行，风险更大。如果，领导真的不知道柳树不能做车载，你直接指出错误，那么，你会当众让他下不来台。有损权威的事情，领导心里会极不舒服。如果领导知道，柳树不能做车载，你主动唱反调，他会觉得你很卖弄，不尽心。
