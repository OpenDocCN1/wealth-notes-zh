右大使。萧宝寅得知这一情况，认为是来收拾自己，特别害怕，长安的轻薄子弟又劝说萧宝寅起兵。郦道元到了阴盘驿，萧宝寅派手下的将领郭子恢去攻杀了他，收葬了他的尸体，然后上奏朝廷说是被秦地的鲜卑人所杀害。

【解析】很多人在职场斗争失败，大多都是因为权力评估的不准确。对彼此之间的权力对比产生了误解，郦道元表面上赢得了对元悦的权力斗争胜利，而实际上转身就遭到了对方的暗算，而且想报复都不一定能够找对人。权谋网就这个案例分析权力斗争中，分析力量评估的三大难题：

# 1、权力的对错性

郦道元认为自己从法律上抓到了丘念的错误，并且可以动用自己的合法权力，直接先斩后奏，而且还就此，牵连弹劾丘念的主人元悦。郦道元对自己权力的评估采用的是对错的公式。自己做的对，就比元悦的权力大。其实，大家都知道，权力讲究的是势力而不是规则对错。谁的势力大，谁就能最后胜出，而胜出者，就是对的，郦道元错误的评估了自己手里的权力对错。

# 2、权力的明暗性

表面看杀个丘念没啥，一个被宠幸的小人物，但是他背后站的是汝南王元悦，而郦道元也没有把汝南王放在眼里，但是他不明白，汝南王背后支持的势力是最高的权力领导者，胡太后。所以权力评估很容易出现错误，究其原因就是，你只能看到表面的关系，而很难看到背后的各种关系和势力。这种背后势力发挥力量的时候，都有各种各样的伪装，并不会公然出现，对暗中的权力难以客观计算。

# 3、权力的复杂性

权力斗争并不是一场战斗，而是一次次的斗争，而且还有多方势力的变量参与。复，就是多次斗争。杂，就是多参与者。元悦没有能保护丘念，失败了一局。但是通过运作背后的势力胡太后，认命郦道元为关右大使。表面上是给郦道元升了官，但是，这次权力斗争新的一局里，元悦引入了即将造反的，萧宝寅，借助萧宝寅的手杀了郦道元，而萧宝寅又嫁祸盗贼所害。对第三方利害人，无法估计。

经过上述的分析，我们能够看出来，权力斗争之所以难以估计，源于权力斗争势力的判断难度。上述三个因素，很难客观的估量，一个无法客观判断彼此手里权力的大小，也就对斗争的结果无法预测。郦道元就是错误的评估了权力，赢了一局，而输了人生！当权者发起斗争时，一定要切记！
