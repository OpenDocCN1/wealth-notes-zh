# 三、后发制人的权术原理

# 1、避其锐气

面对强势对手，要尽最大的能力拖时间，尽可能避免决战的来临。硬件改变不了的时候，要利用一切机会改变软件层面，不能改变对手的兵力就改变对手的士气，不能改变对手的能量，但是能够让其没有计谋变笨。所以，一切的目的，就是让他变的四肢发达，头脑简单。

# 2、保存实力

避免正面决战，要利用局部优势，局部战场，一点点的吃掉对手，因为任何时候，都要谨慎，对于强者而言，失败，试错，都还继续有机会，但是作为弱者，机会只有一次。一旦被人抓住一次机会攻击，自己就丧失了继续博弈的机会。所以，一切的目的就是要珍惜自己仅有的一次机会。

# 3、寻隙待变

老虎还有打盹的时候，任何的强势，都是相对的，每个人都有自己的缺点、弱点、盲点。这对强势一方而言，寻找不到这些点的时候，就不能主动出手，而找到强者的薄弱环节，这个是需要时间的。毕竟这些人，都会极深的隐藏自己。所以，一切的目的就是要找到对手的致命弱点。

经过上述权谋网的技术分析，我们能够看出来，弱者必须后发制人，原因就是他只有一次对决的机会，所以要求在没有找到对手的弱点之前，不能轻举妄动。而出现弱点之后，必须立即尽全力，一击必杀，曹操的官渡之战，吴国的赤壁之战，弱势方，无不都是如此的策略。所以，后发制人是弱者的斗争战略。这也就是太祖说的，先战略防御，然后战术相持，最后战斗反攻。

# 权力障碍必须提前清除

【出处】《资治通鉴》第69卷 魏纪1

【原文】初，封本罗侯寇氏之子，汉中王初至荆州，以未有继嗣，养之为子。诸葛亮虑封刚猛，易世之后，终难制御，劝汉中王因此际除之；遂赐封死。

【译文】当初，刘封本来是罗侯人寇姓人家的儿子，汉中王刘备刚到荆州时，没有儿子，收刘封为养子。诸葛亮认为刘封傲慢固执，性情凶悍，顾虑在刘备去世后，不能控制他，劝刘备借此机会，将他除掉；刘备便命刘封自杀了。

【背景】征南将军夏侯尚、右将军徐晃和孟达一起袭击刘封。蜀上庸太守申耽背叛刘封，投降了曹军。刘封被击败，逃回成都。
