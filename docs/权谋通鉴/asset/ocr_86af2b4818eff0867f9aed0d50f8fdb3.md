自己的事业能够做到多大，载入历史，成名成家这就是自己奋斗的终点。白铁余做到了。

# 1、根据地

有地盘，这个是必须的，获得资源时候的地盘和未来做事业的地盘是不一样的。白铁余各处宣传收费的地方和后期作为基础的平成县不一个地方，我们创业也是如此，自己起家的事业，和能够成就大事的事业不一致，雷军不也是从软件起家，后来却把手机作为自己事业的平台。

# 2、置百官

有了地盘，就必须开始打造自己的地盘了，以前的小打小闹，都需要摆脱了，自己曾经借助的宗教或是势力也都需要摆脱了，需要打造属于自己的品牌。称帝是个必然的程序，所谓缓称王的策略是多方势力斗争的时候的权宜之策。如果没有多方势力，第一品牌，就是号召力。

# 3、攻城邑

成就自己的时机终于来了，白铁余开始攻打城邑，尽管很快被灭掉了，但是白铁余牢牢占据了资治通鉴好几百字，进入了历史。攻打城邑，其实就是制造更大的影响力。创业领域也是，要制造影响力，就必须进入重大项目，民生项目，没有这些，就谈不上事业。

很多权谋网的朋友看这段历史，觉得白铁余就是个不自量力的跳梁小丑，其实我们细想，一个人，吃好喝好，还没事攻打什么县城，这不是找死，我觉得他就是想进入历史，想出名而已。他做到了。以光明皇帝的名义进入了历史，尽管不被承认，但是没人能否认他的存在。白铁余缺的其实就是一个外部动乱环境而已。

+   【出处】《资治通鉴》203 卷 唐纪 19

+   【原文】有飞骑十余人饮于坊曲，一人言： “知别无勋赏，不若奉庐陵。” 一人起，出诣北门告之。座未散，皆捕得，系羽林狱。言者斩，余以知反不告皆绞；告者除五品官。告密之端自此兴矣。

+   【译文】有皇帝侍卫军士飞骑十多人在街巷聚会饮酒，其中一人说： “早知道没有什么功劳赏赐，还不如侍奉庐陵王。” 其中另一人离座，到北门告发，饮酒的军士还未散去，全部被捕获，关入羽林军监狱。结果，说话的人被斩首，其余的人因知道谋反而不告发被判处绞刑，告发的人授给五品官。告密之风从此兴起。
