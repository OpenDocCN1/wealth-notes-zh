# 3、穷奢极欲而人不非

中国人历朝历代都认为有钱人为富不仁，横征暴敛，但是看看郭子仪的收入“月入俸钱二万缗，私产不在焉；府库珍货山积。”没有人去举报贪污受贿，没有人去敌对仇视，为什么这样，这必然是人家应得的，而且是公开透明的。公开透明，来路合法的财富，被人家所敬仰而无人非议。这个奢侈的生活方式，没人指责，高调炫富而且安全无忧这又是何等的境界。

# 二、权谋家人生成功的三大标准

# 1、健康长寿

养生有术。古代医疗条件，卫生条件，生活条件都不是很好，而郭子仪久经沙场，而且能够活到85岁，不仅仅是古代，就是现代。无疾而终，到85岁，都是困难的。那个人70多岁不是药罐子，病秧子，而郭子仪这样的长寿，说明对身体保养很有研究，很有控制和讲究。

# 2、子女显贵

治家有道。子女不孝，子女无能，子女凋零，都是无法控制的事情。但是人家郭子仪，多子多福，八子七婿均是朝廷的显贵。这样的家庭生活，又该是如何的幸福。一个人优秀不重要，重要的是家教有方，能够让让自己的子女都能够在有家的家风，这是幸福生活的保证。

# 3、富有天下

赚钱有方。高工资是一个方面，另外一个方面就是人家的私产，这说明人家除了工资之外，还能经营有方，把自己的钱变得更多，合法的投资经营，让财富裂变。郭子仪不仅仅有治军的能力，还有经营的能力，这样的人放在任何朝代都应该是让人举国羡慕的。现在能够做到这三点的也就李嘉诚吧。

# 三、郭子仪作为最成功的权谋家对我们有什么启示

# 1、知道领导要什么

领导要的东西永远只有两种，“又红又专”，就是有极强的专业能力，且对领导忠心耿耿。没有领导喜欢无能的人，也没有领导会容纳野心的人。所以郭子仪不单单是打仗是好手，能够打的赢，替领导解决最难的难题，还十分听话，而且执行毫不讨价还价。领导会不喜欢？

# 2、懂得手下要什么

为什么郭子仪的手下都这么听话，而且出名的人很多。这不仅仅是郭子仪识人有术，而且是给手下立功的机会，把功劳让给手下。作为部下对上级其实无非是两个要求，一个能够实现自己的机会，能够公开展示自己的才华。有本事，不给你机会，有功劳，被上级拿走，谁还会听话？
