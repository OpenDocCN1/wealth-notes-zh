发制人了。三国的夷陵之战，是吴国以少胜多和刘备的对决。其中陆逊的智慧，是我们对弱者后发制人取得胜利的研究范本。

# 一、为什么不能直接交战？

+   1、备是狺虏

对手性格狡猾。知己知彼百战不殆，而对于面对的是刘备这样的权谋家，硬碰硬的话，会被其设计欺骗。对于那种心眼多的人，必须要以不变应万变，一旦跟随，可能随时被坑。狺虏，这个词用的好，一个是狡猾，一个是凶狠，这样的人，没实际的摸清楚之前，怎能轻谈攻击。

+   2、更尝事多

对手经验丰富。刘备是最老牌的军阀，从灭黄巾军开始就一直再各处征战，和各路人马交手，最终拿到了益州作为自己的称帝地盘，所以，从无到有的刘备，作战经验丰富。摸不清楚刘备的战术前，轻举妄动，会被引诱。

+   3、其军始集

锐气正盛，即使硬碰硬，也会杀人一万自损三千。这对弱者而言，犹如和龙王比宝，拼消耗不是弱者的手腕，宁斗智不斗勇也。所以，面对强敌，必须要避免无把握情况下的决战。只能一点点的分割消耗，等待强者的转化。

所以，我们判断对手是不是强大，主要看，对手的权谋，经验和能量。如果这三点对比比自己强，就必须选择后发制人。

# 二、后发制人的出现的时机？

+   1、不得我便

弱者的主要宗旨就是，先不败而后求胜。保存自己的实力，对手对自己无能为力的时候，说明他的能量已经发挥到极点了。捞不到便宜，这说明，我们自身防御的优秀，以及对方所有的能量已经动用完毕，大家处在了能量的均势上。这一点是从能量转化对比来说的。

+   2、兵疲惫沮

士气是个大问题，长时间的持久相持，士气必然下降，必胜的意志也会动摇。强势而占不到便宜，这就是物极必反，大家就有强而转弱的趋势，意志力就会放在找机会进攻上，而自认为强大，就会疏于防御，容易找到薄弱的防御点进攻。这一点是从弱点暴露来说的。

+   3、计不复生

对手找不到更好的计谋来进攻，这让他们的智力也就发挥到了极限，也就拿不出新的阴谋诡计了，这时候就不怕被引诱了，被欺骗了，能够在交往中识别所有的权术谋略，对手的经验，计谋也就不能称呼为优势了。他们对我们透明了，而我方还没有暴露。这是从策略明暗来说的。

所以，等待对手对我们无能为力的时候，就是我们寻找对手漏洞，一击必杀的时候。
