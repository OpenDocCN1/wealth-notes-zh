产生直接对抗，和鱼朝恩当众闹翻，如果不发脾气，和颜悦色，又会被鱼朝恩当成深不可测。在现场被人家训诫，如何才是正确的反应呢？其实进入被测试状态是没有解的。真正的高手是不会在被动局面下寻求答案的，而是应该一开始就伪装起来，跪舔对手，麻痹让他失去警惕。只有这样才能够获取信任，而不会进入到测试状态。彼此的对立状态，其实怎么做都是下策，完美的就是让对手感觉不到敌对。

高手处理问题，上策是不让问题产生，中策是找到最佳答案，下策是被动应付。权谋家唯一能够被对手识别出来的，就是深度理性对情绪的控制，因此，权谋高手眼里，稍微表现出普通人的情绪，还是能够有一定伪装色彩的。老子说，反者道之道，用现代话来说，就是通则的例外。别人都情绪化，你就理性，别人都理性，你就情绪化。把情绪和理性都当成工具驾驭，这才是权谋精髓所在。

# 让你不爽而又无法改变的事实，只能赞同

【出处】《资治通鉴》 第224卷 唐纪40

【原文】甲午，郭子仪禁无故军中走马。南阳夫人乳母之子犯禁，都虞侯杖杀之。诸子泣诉于子仪，且言都虞侯之横，子颐诛遣之。明日，以事语僚佐而叹息曰： "子仪诸子，皆奴材也。不赏父之都虞侯而借母之乳母子，非奴材而何！" 

【译文】甲午（十九日），郭子仪下令禁止在军营中无故驰马奔走。郭子仪的妻子南阳夫人奶妈的儿子触犯禁令，都虞侯将他用乱棍打死。郭子仪的几个儿子在他面前哭诉，并且说都虞侯专横，郭子仪狠狠地训斥并赶走了他们，第二天，郭子仪跟属僚们说起了这件事，并且叹息道： "我的几个儿子都是当奴的材料。他们不赞赏父亲的都虞侯，而是痛惜母亲的奶妈的儿子，不是当奴的材料又是什么呢！"

【解析】想象一下，如果你是郭子仪，面对这个场景你该怎么做，一边是哭哭啼啼的儿子们，一边是严格执法的亲信武官都虞侯。我敢说，这个绝对是个头疼的问题，咱们推理下郭子仪的心理计算过程：

+   1、 妻子奶妈的儿子，与郭子仪自己是平辈的人，把他安排在自己的军中，照顾的味道就特别的浓，这也说明感情是非常不错的。现在他被杀了，自己如何对妻子交代，妻子又如何对自己的妈妈交代？执法遇见熟人，历朝历代都是个头疼的问题。

+   2、 郭子仪的几个儿子都来哭诉，这说明，他们还是重感情的，说明平时关系不错。可是，这样的哭诉，对郭子仪形成了巨大的压力，要求处理都虞侯，这怎么可能？如果处理了都虞侯，整个军营众目睽睽，都看着呢，以后谁还会遵守军令？自己的威信何在？

+   3、 我敢说，郭子仪肯定想，有本事，你们几个直接去把都虞侯杀了，一来给这个亲戚出了气，二来，禁止驰马的军令又没有被违背，大不了，按规定来，给你们一个斗殴的军事处分就行了嘛，你们自己不下手，把难题踢给我，真是混蛋。没胆子，还没智慧。
