在手下达命和自己利益时，刘邦还是选择利益。

# 二、刘邦和滕公的对与错。

+   1、刘邦在危险的时候推子女下车。道德上的下策，但是确是权谋上的上策。表面上，推下去，孩子会死。其实不是，项羽抓了他们也不会杀，因为这是和刘邦谈判的筹码。而如果在一起都没跑出去，必然都会被杀。对刘邦而言，只要自己活着，孩子其实就是安全的。刘邦的老婆和老爹都被抓了，还不是安全无恙的最后被送回来？取舍之间，必须理性。道德和权谋有时候就是这么尖锐的对立着。

+   2、滕公救人，做人上无可厚非，事后也赢得了吕后的感恩。但是，在当时那时候，最大的价值所在就是保住团队的主帅。孩子可以再生，但是主帅不在了；整个汉王组织就结束了。滕公其实最佳的选择就是，前两次推下去的时候，应该救。一个纯利益计算的人，领导也害怕，所以，救两次体现自己的情感。但是后面就不该救了，这时候体现自己维护大局，听从指挥，这是作为一个手下的本分。

+   3、事后，逃离危险后，刘邦没有再提这件事。滕公救了刘邦及其子女。刘邦在处理时没有奖励也没有处罚。刘邦可能认为功过相等。但是事实上，从纯权谋家的管理手腕而言，作为组织老大的身份，对滕公的抗命做出处罚，而以私人身份对滕公救自己的孩子表示感谢。功过分明，公私分明。能够维护管理，也能够保护感情。混为一谈的功过相抵，不再言语，不是最佳策略。

# 三、刘邦和滕公的举动，对我们职场管理的现实意义

+   1、什么时候都必须理性计算，在极端情况下依然如此。
作为一个管理者，必须极度的理性，任何夹杂感情的决策，都可能是错误的，表面上的道德感，其实会给整体上带来无法估量的损害。电视上经常会看到因救人而失去了更多的同志，因小失大，不能果断的止损，因为局部失去了整体。刘邦这种极端情况下，依然保持理性，这令人敬佩。

+   2、对于自认为上级错误的命令，自己指出后，无效，就要听话。
《礼记》说“父母有过，谏而不逆”说的就是自己的父母有过错，可以提意见，但是不能忤逆。对于领导的错误决策也是一样，自己要做的就是提醒，如果他不听，不要忤逆。因为作为手下最重要的就是执行命令；而不是自认为正确就去抗命。职场很多人，都自认为正确，和老板抗争。领导权威何在？

+   3、公私分明，利益和听话之间，不能混为一谈。
对于手下好心办坏事的很多，或是不听话但是维护了领导的利益，这时候，在管理中千万不能混为一谈。对于维护了组织的利益，这个要奖励；但是不听命令，或是擅自作出命令，这行为绝对不能姑息。决策权，永远都不能假手与人，必须维系权力威严，无论何时。
