不满情绪的人，利益受损的人，是第一类被策反的对象。这种内隙只是被压抑着不能爆发而已。

# 2、所忌

“处罗侯者，摄图之弟，妇多势弱，曲取众心，国人爱之，因为摄图所忌，其心殊不自安，迹示弥缝，实怀疑惧。”摄图之所以忌讳自己的弟弟处罗侯，原因就是这兄弟有替代自己的资格，而且正在收买人心，一旦有能力自身的位置就会不保。潜在替代者这就是第二类可离间对象！

# 3、首鼠

“阿波首鼠，介在其间，颇惧摄图，受其牵率，唯强是与，未有定心。”可以这么说，职场上这类人最多，首鼠两端，没有定心，唯强是与。因为他们不是摄图的嫡系，有好处轮不上，处于边缘化的一类人，这样的人，也有自己的利益需求，不过是不太明显，这是第三类可鼓动的对象。

三、给我们的职场启示如下：

# 1、密运筹策

对付强者绝对不能硬碰硬，能够不明着干就不要明着来，最佳的策略就是把直接的对抗变成计谋的博弈。使用文伐的手段，秘密的下手。要学会转换战场，选择自己的优势领域或是选择对手的弱势领域来斗争，这样的策略事半功倍。

# 2、远交近攻

远交近攻，被秦国的宰相范雎提出来之后，就一直被当成计谋宝典来用，这里有两个要点，一是身边的敌人要首先除掉，这是对自己危害最大的，远一点的可以徐徐图之。二就是让自己的敌人腹背受敌，双线作战，强敌内部的能力被分解。

# 3、离强合弱

谁是我们的敌人谁是我们的朋友，这是革命的首要问题。所以想搞定强者，就要对自己的盟友有战略选择，这就是离强合弱，不管是不是友好，都要把盟友的强大给消耗了，这样合作中，自己才不会被吞并，才能保证主动权和既得利益。联合弱者，自己才能斗争后，占有最大的成果。

经过上述权谋网对这段材料的解析，我们能够看出来，如何打败比自己的强大的敌人，从战略上，战术上，无非就是上面的这些东西，只要细细的品味透，就能够成功。隋文帝也就是采用了这个战略和战术，很快就打败了强大的突厥，成为了统一的大帝国！
