一个人你再有多本事，你能做多大概呢，你能有多少时间呢，你能多完美呢？所以，想成就事业，就必须调动更多的人参与自己的事业和梦想，把他们调动起来，只有把别人的能力发挥出来，自己从专业能力变成组织管理能力，才能够做大，做强。

# 3、虚己受人克制表现。

太多的人觉得自己比别人强，有表现欲，其实你要知道，你不是在手下面前展示才华让他们崇拜的，而是让他们发挥自身能力给组织干活的。你想让别人干活，就必须压制自己干活的欲望，让别人好好的发挥他们的能力，个人的优秀和领导一个优秀的组织是截然不同的。

# 三、我们在职场该如何做？

# 1、成就大事靠的是领导能力。

什么是大事，就是众人的事。既然是众人的事，那就需要让很多的人参与进来，而不是让自己去做所有的事情。而这些事情，恰恰需要的是组织管理能力，而不是个人工作能力。很多人错认为，有专业能力就代表有领导能力，所以栽倒在这里。

# 2、领导靠成就别人成就自己。

作为领导的评价标准早就不是你自己有什么业绩，你多能干。而是你培养了多少人跟你干，你让他们发挥了多小的能力，你通过他的成功，来证明自己的成功。做领导的标准是组织成功，他的能力是服务性的，而不是奉献型的。

# 3、要让自己能力和想法匹配。

如何去追求自己想要的成功，就是让自己的能力和自己的欲望匹配起来。这就需要找到方法，虚己受人就是开出的最好的药方。谦虚的听取各方面的意见，发挥别人的作用。不要认为，自己有本事，就该成功，一个人的成功是用人的成功，而不是个人才华的展示。经过上面的分析，权谋网认为，一个人之所以不成功，就是能力不匹配，标准不适应，方法没找对。只有能力、方法和标准三合一，才能够得到我们想要的。
