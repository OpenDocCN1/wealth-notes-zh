还有精神层面的折磨。没事打打草，对我方来说，成本很低，但对敌方来说折磨很大。

+   2、和瞎天过海的区别。很多人会认为，第二天早上，张巡出击和前一天晚上应当做一并讲。这是瞎天过海，其实这个理解是有偏差的。如果张巡，每天晚上都这样戒备，后来尹子奇，不再为这个警备，不当成回事了，这时候夜里头袭击，这才算是瞎天过海的计谋。瞎天过海，本是“常见则不疑”。而张巡确是在尹子奇疲惫之后，白天出击。属于疲劳后，避实击虚。惊扰就是为了产生疲惫，疲惫后出击。

# 二、打草惊蛇，意在“蛇”！

+   1、目标暴漏。张巡不认识尹子奇，如何在战场上让主将暴漏。张巡用射蒿草的办法，让士兵把这个消息主动传递给主帅，从而识别出来了尹子奇的所在。这时候，张巡，用蒿草，作为“打”击工具，而这些士兵就是“草”，惊动了尹子奇这个“蛇”，通过打击小人物，引出背后的大鱼。通过信息传递的路径，识别了后面的人，这个谋略极为高妙。

+   2、和抛砖引玉的区别。很多朋友会认为，这不是抛砖引玉么，其实抛砖引玉，是设置诱饵，把其勾引出来。比如如果张巡通过故意丢盔弃甲，引来地方的主动抢掠，这时候，尹子奇出来指挥，这才能叫做抛砖引玉。抛砖引玉，是需要诱饵的。而这里张巡没有诱饵，而是让士兵产生误判而已。张巡的蒿草射敌，极为高妙的找到了目标。

# 三、打草惊蛇，在职场的运用。

+   1、以虚耗实。

美国当初和苏联开展军备竞赛的时候，美国发布虚假的星球大战计划，让苏联信以为真。苏联在外太空的投入，大大拖垮了国家的发展。从而后期产生了政变，苏联解体。

职场上也是，通过不断地散布虚假消息，让目标不断地树敌。比如，你告诉目标，某某在背后说他的坏话，或是目标被老总痛骂之后，你告诉他是某某告密。这样，虚假的消息，让目标处处为敌，让其草木皆兵，从而消耗了他的群众基础，未来他也就没人支持了。

+   2、假打测试。

古代有个谋杀破不了案，办案人怀疑是通奸谋杀，一时找不到这个女人的情夫。于是把这女人抓来，关了三个月就放了。然后派人偷偷跟踪，果然，这个女人出来就去找情夫了，情夫暴漏而被抓。

职场也很常见这种假打测试。因为你不熟悉身边的这些草，是你自己的人，还是对手的人。这时候，你就释放一些虚假准备斗争的信息，看看这个消息会不会泄露。如果泄露，说明，释放信息对象，就不是自己人。职场斗争，正式开展之前，必须要要把目标的其他暗线全部摸清，才不会被出卖。

所以，权谋网研究张巡这两个特殊的打草惊蛇的案例对我们是很有帮助的，有时候我们在意的是，草；有时候在意的是，惊；有时候在意的是，蛇。一个计谋要在理解内涵的情况下灵活运用，才能够不断地提升自己的权谋，不能都只限于表面的理解。
