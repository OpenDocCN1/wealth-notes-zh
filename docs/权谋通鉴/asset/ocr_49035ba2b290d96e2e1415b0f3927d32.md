所以说，权谋网认为，一般职场流星都是主动踩中了三大雷点，领导关系、同事关系、红人关系。对领导时刻保持上下级关系的意识，对同事保持简单的职场工作关系，和领导身边的红人建立起私人关系。只有如此，才能把自己变成职场恒星，而不是转瞬即逝的流星。

# 组织利益和领导利益并不一致

【出处】《资治通鉴》隋纪一 177卷

【原文】高颍先入建康，颍子德弘为晋王府记室，广使德弘驰诣颍所，令留张丽华，颍曰： “昔太公蒙面以斩妲己，今岂可留丽华！”乃斩之于青溪。德弘还报，广变色曰：“昔人云，‘无德不报’，我必有以报高公矣！”由是恨颍。

【译文】隋高颍先进入建康，当时高颍的儿子高德弘是晋王府记室参军，杨广就派他驰马来见高颍，传令留下张丽华，高颍说：“古时候姜太公尚蒙面斩了殷纣王的宠姬妲己，今天岂能留下张丽华！”于是将张丽华斩于青溪。高德弘还报杨广，杨广脸色大变说：“古人云：‘无德不报。’我一定有办法回报高公！”因此杨广忌恨高颍。

【背景】张丽华，美女外加才女，善解人意，是南朝陈后主的爱妃。

【解析】在面对组织利益和领导利益冲突的时候，如果你选择维护组织利益，伤害到领导的利益，而在领导想收拾你的时候，你所维护的组织，却不会站出来，保护你，替你说话。看完这个案例，要扪心自问三个问题！

+   1、组织利益和领导利益哪个大？

很多人从小接触的教育，就是集体利益大于个人利益。对于个人利益凌驾于集体之上的，都深恶痛绝。所以，很多人都认为，组织利益，必须是大于领导利益的，但是这个观点正是很多人职场不幸的总根源。领导的利益才是最根本的利益，因为领导得到了好处才会提拔你才会给你加薪。

+   2、维护领导利益的是不是小人？

很多人觉得，我们维护领导的个人利益，从内心而言是抗拒的。因为，大多数人认为，职场都是平等的，我干活你给工资，我要是替你服务，维护你的个人利益，这是不平等的，自己的自尊心很排斥。且和从小受的教育相违背，认为不好好干活，只拍领导马屁是小人。但是领导才是你的饭碗。

+   3、出错时候组织会不会保护你？

很多人都有自己内心的对错标准，认为，只要做了对组织有意的事情，自己就应该得到好处，其实不尽然，老板的利益或是上级领导的利益和组织的利益并不一致。尤其是出错的时候，领导要找机会收拾你，而这时候，得到好处的组织是极端缺位的。
