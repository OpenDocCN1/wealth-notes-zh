# 领导发火该如何应对？

【出处】《资治通鉴》第 42 卷 汉纪 34

【原文】帝好图谶，与郑兴议郊祀事，曰：“吾欲以谶断之，何如？”对曰：“臣不为谶！”帝怒曰：“卿不为谶，非之邪？”兴惶恐曰：“臣于书有所未学，而无所非也。”帝意乃解。

【译文】刘秀喜好运用隐语或预言占验吉凶的图谶，和郑兴讨论到郊外祭祀的事，说：“我想用图谶来推断，怎么样？”郑兴回答：“我不从事图谶。”刘秀发怒说：“你不从事图谶，是认为它不对吗？”郑兴慎惧，说：“我未学过图谶之书，并没有认为它不对。”刘秀的怒气才消。

# 1、刘秀喜欢图谶的原因

古代方士或儒生编造的关于帝王受命徼验一类的书，多为隐语、预言。刘秀的身份是没落的贵族，尽管身世可考，但是基本上和平民差距不大。而刘秀喜欢图谶的原因，绝对不是为封建迷信，而是这是他需要这个来证明自己并不普通，是天命所归。这样才能有比别人高的威望，这是权力基础。

# 2、刘秀忽然发火的原因

郑兴对图谶的态度，让刘秀忽然间发怒，原因就两个，一来是觉得，郑兴潜在质疑自己的合法性；二来是对郑兴抗领导的决策命令，阻碍了权力的畅通性，所以基于自己的地位和权力两个层面的触动，刘秀立即发火，这是对郑兴的震慑，也是对其他人的警示。

# 3、刘秀怒气消失的原因

郑兴是个聪明人，没有在刘秀固定的思维范围内，在对不对的环节上纠缠。因为这个问题如果做成主观题，就错了，你认为不对，和领导不一致，你认为对，那你为什么反对？所以，只能变成客观题，我没学过图谶，所以不知道，并不是认为不对。完美解决了刘秀发火的原因，躲过一劫。
