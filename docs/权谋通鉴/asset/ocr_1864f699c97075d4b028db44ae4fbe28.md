出宫上朝。生下儿子赵何后，便废去太子赵章，立赵何为太子。吴娃死后，赵主父对赵何的偏爱也逐渐减退，又可怜起原来的太子，想立两个王。他总是犹豫不决，所以引起了内乱。

【解析】作为一个领导，在统御下属的时候，喜欢将其分成两派，让其内斗，这样就能处于平衡居中地位，维系权力稳定，不被架空，不被蒙蔽。但是如果是在继承人方面，或是最高权力上，采用分割的话，就不是内斗而是内乱了。赵武灵王，一代雄主，饿死沙丘宫，不能不让我们对其深刻的分析。

# 一、内乱的起因

# 1、爱怜转移

赵主父先立了太子赵章，后来又因为喜欢吴娃，又立了吴娃的儿子赵何。看似没什么，其实这个不仅仅是换个人的问题，因为每个人成为储君，身边都会依附一帮势力。这一帮人一旦占了队，就很难再次转换门庭。赵主父换人的同时，无形中形成了两大势力。

# 2、两王分立

两王分立的想法，其实是给了双方的合法性希望。让各方都不想放弃机会，原本压抑的派系，内心其实都燃烧起来，都想让自己所站的这一派上位，因为这个随之而来的都是财富和名位。所以，赵主父两王分立的想法，刺激了两大势力的矛盾。

# 3、犹豫不决

赵章和赵何都拥有了自己的势力，且双方因为利益的对立而矛盾一触即发。这个矛盾之火一旦点燃，就必须果断的解决，不然会愈演愈烈。因为最高权力只有一个，根本就无法调和。赵主父面对矛盾，犹豫不决，导致了矛盾的爆发。

# 二、内乱的根源

# 1、两派均势

两派一旦不分上下，形成均势，就不能用和平手段解决，因为谁都无法说服谁，谁也无法控制谁，在面对机会均等的机会下，谁都不肯低头，这时候，只能凭拳头、凭智慧、凭运气，拿出来较量一下，让历史自身做出选择。

# 2、不安全感

一方成功上位，而另一方就必然会被当成隐患消除，一旦失败，就会一无所有，别说维持现状，生命能不能保住都是问题。所以每个派系的人，都没有了后路。一旦走向夺嫡道路，其实就要一抹黑走到头，所以都会采用极端的方式。

# 3、先发制人

既然失败的后果极其严重，那么在智力、暴力和运气都均等的情况下，想赢，就要先下手为强。谁出手越早，谁就能占有先发制人的时机优势。谁下手晚，就会形成被动局面，从而导致失败，所以，内乱都会提前爆发。
