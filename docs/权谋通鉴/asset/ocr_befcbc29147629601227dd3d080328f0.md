控制信息，让所有的东西在眼前透明，这就需要建立特务机构，专门负责情报的刺探工作，还要发动大家的力量告密，就能形成天罗地网。专职和兼职的配合，情报就会完美。间谍不仅仅用在敌人身边，自己人也是需要的，这是信息建设的必要手段。

# 2、监察测试

制定规则，就是为了规范人员的相应行为，但是如何发现是个大问题，很多人太能伪装了，做的也太隐蔽，无法发现，这时候，明着用规范，暗着就要用权术，利用权术，倒言反事，挟知而问，韩非子的七术重点研究的就是这块，用规则和权术来驾驭群臣。

# 3、分权制衡

独任就会被架空，这是不变的道理。所以权力最讲究的就是权力的制约和平衡，依赖互相的监督分权来实现权力的稳定，任何组织不分两派，都无法实现权力稳定，所以不管什么样的感情和信任，都不能违背权力分权制衡的原理。

# 三、组织控制的阴暗真相

# 1、任奸

想搞到情报，知道每个人的隐私，这个活，一般人不干的，只能找到小人来做。所以使用小人、奸人，成了领导的不二之选。任奸这是商鞅提出来的，好人是干不了告密这样的事情。所以职场里，经常见到，小人的飞扬跋扈，通过告密上位的不计其数。

# 2、把柄

使功不如使过。没事抓点小辫子，关键时候还是有用的。故意引诱他犯错，然后敲打使用，这个招数君子是做不来的，而领导之所以被人诟病，原因也是，使用了那些阴暗的拿不出门的权术，来控制人员。人性的阴暗，不能不用权术。以情管人，从来都是虚幻的，幼稚的。

# 3、内斗

制衡就会引起内斗。所以，差不多的稳定组织，都有内斗的情况，窝里斗常被说成是我们民族的劣根性，其实任何一个组织都是这样，说好斗点叫做竞争。不内斗，就必然外斗。但是外部危机的转移，对权力来说是有风险的，所以内斗最稳定，无风险。

所以，权谋网认为作为一个组织的老大，要控制信息、控制行为、控制权力，本身就是要用小人、抓把柄、搞内斗。看似邪恶，其实是控制的需要。
