比如这段材料，把势均则斗的用法淋漓尽致的展示了出来，那就是，“外示优崇，实分其势。”这就是权谋钥匙，通过这个钥匙，我们能够打开另一段材料。能够明白背后的规律。我们再看《资治通鉴》唐纪12的一段材料，大家能看出来什么？

春季，正月，甲戌（十二日），唐朝廷任命吐蕃禄东赞为右卫大将军。太宗嘉许禄东赞善于应对，欲将琅琊公主的外孙女段氏嫁给他为妻，禄东赞推辞说：“臣在本国中自有妻子，是父母为我聘娶的，不能够抛弃。而且我们的赞普首领还未曾迎娶公主，陪臣我怎么能敢先娶呢？”太宗更加赞赏他，然而想要以厚礼隆恩加以抚慰，他最后还是从没有从命。

如果不知道外“示优崇，实分其势。”这个权谋钥匙，我们就很难理解，禄东赞为什么会拒绝。

# 一、我们同这个权谋钥匙分析下唐太宗的心理

+   1、禄东赞是吐蕃的大将军，是吐蕃的二号人物，唐太宗必须拉拢实权派。
这样的人物，作为唐太宗一定要拉拢，把这样的军事人物争取过来，这对未来和平是有好处的，毕竟未来吐蕃发动战争的时候能够，有一定的阻力。

+   2、通过各种明的暗的拉拢，能够离间禄东赞和赞普的关系。
赞普远在吐蕃，不了解远在大唐的情况，回来之后，看到自己的手下，获得了那么多的好处，自然内心里不舒服，而且女人还不像其他的财宝，禄东赞能够转交上去，女人交不上，赞普会记恨。

+   3、通过厚礼隆恩的方法，能够刺激禄东赞的野心。
一个权臣如果能够在外围找到支持的力量，这会极大的刺激他的野心，因为拥有足够的力量叫板自己的老大，才会有不臣之心，导致吐蕃的内斗。
