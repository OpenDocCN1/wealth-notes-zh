来给皇帝台阶下，来维护皇帝的权威。他没有说自己做的事情不对，而是承认采用了错误的无礼的方式。

# 3、拓跋燕精于展示政治胸怀

古弼这个能臣是聪明的，为组织提供了价值，维护了权威，又主动认错，即使拓跋燕心里再不爽，也必须展示胸怀，来原谅古弼的政治举动。是拓跋燕采用这个“过程不重要，重要的是结果”的借口，只要有利于国家和百姓，可以坚持自己的想法，展示组织利益高于自身权力的政治家胸怀。

看似一个皆大欢喜的解决，古弼实现了目的，拓跋燕树立了纳谏的形象。其实这对古弼是有后遗症的，皇帝尽管不会处罚他，但是内心确不会喜欢他。这样的人，生命无忧，毕竟懂得维护权威，但是不会被重用，也不会再给大的机会和平台。最终的结局就是昙花一现，在一个比较低级的岗位上终老。

# 帝王三怒——不懂上意身竟死

【出处】《资治通鉴》129卷

【背景】沈怀文一开始是皇帝的亲信，但是后来不断的直言冲撞皇帝，几次被皇帝警告。并且沈怀文不合群。皇帝喜欢聚众饮酒，沈怀文竟然不喝。由于沈怀文不能让孝武帝称心如意，他下令把沈怀文安排到晋安王刘子勋那里去当征讨参谋长（征虏长史），并兼任广陵郡太守。秋去春来，沈怀文又会出现什么事呢？结果灭门。

【原文】怀文诣建康朝正，事毕还，以女病求申期，至是犹未发，为有司所纠，免官，禁锢十年。怀文卖宅，欲还东，上闻之，大怒，收付廷尉，丁未，赐怀文死。怀文三子潨、渊、冲，行哭为怀文请命，见者伤之。柳元景欲救怀文，言于上曰：“沈怀文三子，涂发不可见；愿陛下逮正其罪。”上竟杀之。

【翻译】沈怀文从广陵回建康参加朝廷举行的岁首年会，事完之后孝武帝刘骏命他返回，可是沈怀文因女儿生病请求延期，就一直没有动身。这件事被有关部门（有司）发现，免除了沈怀文的官职，且十年内不得参加政治活动。他将自己京城里的房宅卖掉，准备回到老家吴兴去。孝武帝听说后，怒不可遏，下令逮捕入狱，三月二十七日，刘骏恩准下令让沈怀文自杀。沈怀文的三个儿子（沈潨、沈渊、沈冲）听到这一消息后，一路哭着找关系救父亲，一些人看到他们兄弟如此孝顺，都为他们兄弟难过。就在这时，遇到了一个好**心人柳元景，他想救沈怀文，就对孝武帝说：“沈怀文的三个儿子，悲痛难处，请求陛下快点为沈怀文的案子定性。”孝武帝还是杀了沈怀文。

【解析】皇帝对于沈怀文的直谏很是反感，于是多次警告无效的情况下，直接调出了中央，皇帝眼不见心不烦。但是接下里沈怀文的行为，让皇帝逐步的升级愤怒，导致沈文身亡。

+   1、沈怀文因为女儿有病拖延回广陵的时间。
