1. 控制权就是一切。

人事权、奖罚权、分工权，这样的三个权力，如果假手于人，天长日久就会大权旁落。很多人做老大，不知道这三点权力的重要性，免不得权力被一点点的蚕食和掏空，等明白过来的时候，手下的人都不听话了，自己也不能够控制了。

2、不该做的不要浪费时间。

每个人的精力有限，尤其做老大，整个组织每天事情一大堆，你不可能都全部的参与处理，这就需要放弃那些非权力性的工作。控制住自己的干事欲望，决不能在不该做的事情上浪费自己的精力跟时间，这样才能劳逸结合，抓大放小。举手之劳，非权力，不为也。

3、人才最重要的是忠心。

能不能干活，能干多少活，重要，但是不是特别重要。原因就是组织发展是个问题，但是权力稳定是最大的问题。做领导每天要考虑的就是权力的稳定，所以对人才的忠心就越发看重中，所谓的忠心就是绝对的透明和服从。

通过上述的研究和分析，我们能够看到，权力的本质是什么，作为老大最重要的工作就是维系权力和巩固权力，其余的工作，都是可以放手的。不懂这个，就会走极端。要么完全陷入事务，犹如诸葛亮，累死；要么完全放手，玉石一样，大权旁落，被扫地出门。做老大的切记！

# 成功潜力测试——郭泰三激魏昭

+   【出处】《资治通鉴》五十五卷

+   【背景】魏昭少年天才，后来在东汉京城洛阳做大官。郭泰东汉名儒。

+   【原文】陈国童子魏昭请于泰曰：“经师易遇，人师难遇，愿在左右，供给洒扫。”泰许之。泰尝不佳，命昭作粥，粥成，进泰，泰呵之曰：“为长者作粥，不加意敬，使不可食！”以杯掷地。昭更为粥重进，泰复呵之。如此者三，昭姿容无变。泰乃曰：“吾始见子之面，而今而后，知卿心耳！”遂友而善之。

+   【翻译】陈国少年魏昭向郭泰请求说：“教授经书的老师容易遇到，但传授做人道理的老师却难遇到。我愿意跟随在您的身边，给您洒扫房屋和庭院。”郭泰许诺。后来，郭泰曾因身体不适，命魏昭给他煮稀饭。稀饭煮好以后，魏昭端给郭泰，郭泰大声喝斥魏昭说：“你给长辈煮稀饭，不存敬意，使我不能进食。”将杯子扔到地上。魏昭又重新煮好稀饭，再次端给郭泰，郭泰又喝斥他。这样一连三次，魏昭的态度和脸色始终没有改变。于是郭泰说：“我开始只看到你的表面，从今以后，我知道你的内心了！”就把魏昭当做好友，善意对待。

+   【解析】这个故事是个很经典的传统故事，叫做魏昭尊师。讲的是魏昭为了求学对老师的尊重，其实从权谋角度来说，是老师对学生的一种潜力测试。
