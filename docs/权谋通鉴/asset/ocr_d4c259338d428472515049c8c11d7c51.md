# 1、挑战权威

有些人当众和领导拍桌子，或是质疑领导的某些行为，很多人还自以为高明，其实这个大错特错，在领导眼里，事情的对错是另一方面，你的行为对权力的威望提出挑战，事情就出现了微妙的变化，领导从事情本身，转至权力的维护上了。所以，任何时候，都要首先维护权威，注意身份。

# 2、对抗命令

有些人自以为是，对上级的领导选择性的执行，认为对的就做，认为不对的就拖着，或是对抗，这绝对是错误的，君以令为主，无论对错，并不是你一个下级来判断的，你只有执行命令的份，对错的评价是有比上级来做的，你去对抗命令，领导立即就会发火。

# 3、自以为是

很多人自认为能力强，不请示汇报，自己做主。这是对权力的无视，任何领导都不会容忍。做对了，能忍着，做错了，立即发火。马谡失街亭，被拒着指挥军大败，忍耐力极强的诸葛亮，也是破口大骂，立即发火，马谡就是自以为是代表。

# 三、郑兴做法对我们有什么启示？

# 1、领导发火不能辩解

任何人面对领导发火，大多都是采用辩解性质的反应，指出对方的错误，或是辩解自己的正确，真本身的行为属于火上浇油，不仅仅是事情的错误问题了，还变成不从不敬，叛变。

# 2、争论最忌人身攻击

很多在和领导争论的时候，就会有意无意的升级话题，从事情本身，变成了人身攻击，你就是对我有意见，你就是看不起我，你这个人一直都是小肚鸡肠，场面一发不可收拾。

# 3、回应领导要能客观

辩解挑战权力升级矛盾，对抗攻击人身升级矛盾，但是我们如何的处理呢，那就是立即让自己服软，找个客观的理由先缓解当下的情绪。“我不清楚，我立即去查”，“的确有问题，我找时间专门汇报”。

经过上述的分析，我们能够看出来，我们在领导发火的时候，一定要首先，不要火上浇油，避免升级矛盾，找个客观冷静的时间，再和领导解释，这才是应对领导发火的主道！

# 虚让——中国人的面子游戏

> 【出处】《资治通鉴》第 42 卷 汉纪 34

> 【原文】盗杀阴贵人母邓氏及弟，帝甚伤之，封贵人弟就为宣恩侯。复就就显侍中兴，欲封之，置印绶于前。兴国让曰：“臣未有先登陷阵之功，而一家数人，并蒙爵土，令天下觖望，诚所不愿！”帝嘉之，不夺其志。贵人问其故，兴曰：“夫外戚家苦不知谦退，嫁女欲配侯王，取妇眄眇公主，愚心实不安也。富贵有极，人当知足，夸奢益为观听所讥。”
