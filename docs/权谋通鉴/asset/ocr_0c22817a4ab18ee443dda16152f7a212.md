# 面对天上掉馅饼，首先要考虑风险

【出处】《资治通鉴》第八卷 秦纪三

【原文】陈婴者，故东阳令史，居县中，素信谨，称为长者。东阳少年杀其令，相聚得二万人，欲立婴为王。婴母谓婴曰：“自我为汝家妇，未尝闻汝先世之有贵者。今暴得大名，不祥；不如有所属。事成，犹得封侯；事败，易以亡，非世所指名也。”婴乃不敢为王，谓其军吏曰：“项氏世世将家，有名于楚，今欲举大事，将非其人不可。我倚名族，亡秦必矣！”其众从之，乃以兵属婴。

【译文】陈婴这个人，是过去东阳县的令史，居住在县城中部，为人一向诚信谨慎，被称为长者。东阳县的年轻人杀掉了县令，相聚得两万人，欲拥立陈婴为王。陈婴的母亲因此对陈婴说：“自从我作了你们家的媳妇以来，还不曾听说你的祖先中有过地位显赫的人。而今突然获得大名垂，不是什么好兆头。不如依附归属于他人，这样，事情成功了，仍然得以封侯，事情失败了，也容易逃亡，因为不是世上被指名道姓的人物。”陈婴于是不敢称王，对他的军官们说：“项姓世世代代为将门，在楚国享有盛名，如今想要办大事，将帅就非这种人不可。我们依靠名家望族，灭亡秦朝便是肯定的了！”他的部下听从了他的话，就让部队归项梁统领。

【解析】自己好好的，忽然被邀请去做别人的老大，面对这个天上掉下的馅饼，一般人，就会把持不住，丧失自我，进入危险，而陈婴在母亲的指导下，完全消化了这个馅饼，这个权术谋略。我们分析下陈婴的思考推理过程：

+   一、陈婴从权术角度是如何想的。

+   1、陈婴被拥立其实是傀儡。

东阳的年轻人杀掉了县令，啸聚了20000多人。这其中绝对不是自发的，而是有人组织指挥的，所以，陈婴被拥立，其实权力也不在自己手里，这个就好比项梁拥立赢心做楚王一样，名义的领导，其实还是傀儡。陈婴如果单独做老大，绝对会失去控制权。

+   2、陈婴不做老大于自保。

陈婴母亲说的话，就是你做老大之后，其实就没有了退路。原因就是，不具备统一天下的能力，如果自己还独立称王，会被认为是有野心的人，一个有单干野心的人，很难做人家的手下，即使做，也会被怀疑动机，当成潜在威胁。
