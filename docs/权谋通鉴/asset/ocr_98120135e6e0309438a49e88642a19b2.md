在军中效力，仰仗陛下的神灵，获得大胜，全都是诸位校尉奋力作战的功劳。陛下已增加了我的封邑，我的儿子还在襁褓之中，并无功劳，陛下却要划出土地封他们三人为侯，这就不是我效力军中，鼓励将士奋力战斗的本意了。”汉武帝说道：“我并没有忘记诸位校尉的功劳。”于是，封护军都尉公孙敖为合骑候，都尉韩说为龙候，公孙贺为南侯，李蔡为乐安侯，校尉李朔为涉织侯，赵不虞为丑随成侯，公孙戎奴为从平侯，李沮、李息及校尉豆如意都被封为关内侯。

**【解析】**一个人带领自己的团队，取得了成功，给组织获取了极大的利益，这时候，领导要表扬。很多负责人，面对表扬，回复的毫无章法，要么是只顾着自己谦虚，抹杀了手下的功劳；要么是自己无视手下，贪功；要么是对上级领导，露出骄傲情绪。所以，面对领导的表演，也是有套路，的这个其实在我们很多官场都在使用，屡试不爽。而卫青的这段回答不长，但是堪称经典。

+   1、首先把自己的功劳归结于幸运。

卫胄头一句话虽说“臣幸得待罪行间”他的意思说，我很幸运能够在这个位置。这首先，就会让别人很舒服。因为，如果不把功劳说成幸运，其余的同事会怎么看你，就你比人家牛？中国组织就是这样，嫉妒贤能，把自己的功劳说成幸运，本身就是在职场不刺激大家的敏感神经。

+   2、其次就是说得到了领导的支持。

所以第二句，卫青就说了“赖陛下神灵”这就是要把功劳首先说成是领导关怀和支持下才有的，无论做出了什么成绩，首先就要有感恩的心，就是领导的支持。这样，能够让领导认为你居功不傲，能够可客观的认识自己，这样会让领导很舒服。

+   3、第三部分就是说全仗兄弟的努力。

说完领导，就要说兄弟们的功劳了，如果这时候不说兄弟们，的支持，会寒了兄弟们的心，接下来的日子，没人会继续支持你。所以卫青说“军大捷，皆诸校尉力战之功也。”把自己的功劳说成幸运，把实际的功劳说成是兄弟们的努力，大家的功劳被认可，心里舒服。

+   4、第四部分就是对自己奖励的谦虚。

“陛下幸已益封臣胄；臣胄子在襁褓中，未有勤劳，上列地封为三侯”这时候无论封赏了什么，都要觉得超过了预期。这样，一来表示谦虚，二来表示感谢。这对领导的赏赐是个正面的感恩回应，我没做出什么成绩，仅仅的一点幸运，就获得了太多，实在是不应该，这就是个态度。

+   5、最后指出自己立功其实内心想法。

一定要把自己行为的目的，说的高大上。“非臣待罪行间所以劝士力战之意思也”我参军不是为了这赏赐，但是手下这些赏赐而是为了作为榜样，激励大家能够走得更远。如果太多的话，就违背了本心。这样的收下赏赐，既展示了高风亮节，又能体谅领导。
