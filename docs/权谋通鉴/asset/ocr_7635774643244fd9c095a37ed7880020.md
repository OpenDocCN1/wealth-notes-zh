# 先罚后准——权谋本质就是玩平衡

【出处】《资治通鉴》140卷 齐纪六

【原文】丙戌，魏主如邺，阼至相州刺史高闾之馆，美其治效，赏赐甚厚。阾数请本州，诏曰：“阾以悬车之年，方求衣锦，知进忘退，有尘谦德；可降号平北将军。阾之老成，宜遂情愿，徙授幽州刺史，令存劝两修，恩法并举。”

【翻译】丙戌（二十日），北魏孝文帝到达邺地。孝文帝多次来到相州刺史高闾的官舍，赞美他治理本州的政绩，并且给予特别丰厚的赏赐。高闾数次请求孝文帝让他回到本土幽州去做官，孝文帝因此而发布诏令：“高闾以该告老退休的年龄，方才要求衣锦还乡，他这样只知进而不知退，实在有损于谦德，所以降其封号为平北将军。他是朝廷中年龄和资历都相当老的大臣，应当顺应他的心愿，所以调任他为幽州刺史。这样做可以既满足了他的请求，以示朝廷之恩，又起到劝善存法的作用。”

【解析】权谋就是玩政治平衡，在权、情、法，三者之间寻求平衡点。作为权谋大师的北魏孝文帝，就对这个事情玩的炉火纯青。面对高闾的回乡做官的请求，完全体现了这一点！
