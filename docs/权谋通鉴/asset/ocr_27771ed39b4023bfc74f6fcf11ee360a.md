然心肚痛楚，吐了几升血，淮安王李神通搀扶着他返回西宫。高祖来到西宫，询问李世民的病情，命令李建成说：“秦王平素不善于饮酒，从今以后，你不能够再与他夜间饮酒。”

【疑点】看似平淡无奇的一段，描写了李建成想毒杀李世民，未成，而被老爹责骂。但是仔细再看就会感觉疑点重重，首先是吐血数升，权谋网笔者自学中医多年，一看就是胃出血的症状，和中毒无关，这不是中毒的征兆。第二，李建成自己在酒桌上如果下毒的话，太不符合逻辑，自己给自己难堪。第三，立即通知了皇帝，并让李神通做了证人，人证物证俱全。

# 材料二

【出处】《资治通鉴》唐纪 15 第 199 卷

【原文】后龙虽丧，然上未有废意也。会昭仪生女，后怜而弄之，后出，昭仪潜扼杀之，覆之以被。上至，昭仪阳欢笑，发被观之，女已死矣，即惊啼。问左右，左右皆曰：“皇后适来此。”上大怒曰：“后杀吾女！”昭仪因泣数其罪。后无以自明，上由是有废立之志。

【译文】王皇后虽然失宠，但高宗并没有废后的想法。正巧此时武昭仪生下一个女孩，皇后怜爱她并逗弄她玩，皇后走出去后，武氏趁没人将女孩掐死，又盖上被子。正好高宗来到，武氏假装欢笑，打开被子一同看孩子，发现女婴已经死了，武氏大声哭闹。问身边的人是怎么回事，身边的人都说道：“皇后刚刚来过这里。”高宗勃然大怒，说道：“皇后杀了我的女儿！”武昭仪借机哭泣着数落其罪过。皇后无法申辩，高宗从此有了废皇后立武昭仪为后的打算。

【疑点】武则天这段故事，相对于李世民那个故事更加直白明显。但凡学习过权谋的人会有疑问，这不是嫁祸术或是栽赃陷害么？这是有细微差别的。自残陷害术，损害的是自身，指向的是第三方的信任关系。而嫁祸或是栽赃，都不是自身的祸。而是第三方的祸患，指向目标，工具不同，指向不同。

【权谋解析】李世民是损害自己的身体，武则天是损害自己的女儿，来完成自残这个行为。从而让皇帝，产生了对对手の怀疑，以及对自残者的同情。

# 一、我们分析下其中的权谋套路

# 1、制造接触环境

这个私下接触的环境，必然是以对手为主场的，让自己处于弱势或是失控的状态下才行。这样的环境才是一个适合布局的环境，只有这样的的自残才更有说服力。

# 2、实施自残行为

自残的行为，必须和目标的举动相配合。你请我喝酒，我就吐血。你单独看我女儿，我就弄死他。这个行为，要做的迅速和隐蔽。慢了，明了，就会赔了夫人又折兵。
