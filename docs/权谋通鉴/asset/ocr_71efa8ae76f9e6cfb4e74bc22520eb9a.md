而看不起魏知古的忘恩负义，想要罢黜他的职务。姚崇坚决地请求玄宗不要这样做，他说：

“此事乃是臣的两个儿子有罪，破坏了陛下的法度，陛下赦免了他们的罪过，臣已经是感到万幸了；如果由于臣的缘故而斥逐魏知古，天下的人们一定会认为陛下是在偏袒臣，这样会累及圣朝的声誉。”唐玄宗沉吟了很久才答应了他的请求。辛亥（二十五日），魏知古被免去相职，改任工部尚书。

【解析】本来魏知古检举姚崇纵容儿子不法的行为，看似无解的攻击，在姚崇的三步话术之后，反倒站在了道德制高点，让魏知古成了被厌恶的对象，姚崇如何做到的，其中的权谋韵味，非常给力：

# 1、姚崇转换战场的攻击应对术

皇帝看似无意的一句话，让权力敏感度极高的姚崇，立即知道了皇帝内心想说什 么，于是，立即透明化，原原本本的就把事实说了出来。说出事实后，姚崇对皇帝的思维进行了干扰，把关注点引向了魏知古不感恩的潜在语境下。在皇帝表示要处理魏知古的时候，姚崇进行了求情，恰恰这个求情，让皇帝下定决心，要处理魏知古。因为这个求情，加重了姚崇和魏知古的道德水准的对比。姚崇看似无意的三句话，其实都是进行设计的，稍有差池，就是身败名裂。顺利的从对自己的指责，转变成了魏知古忘恩负义的焦点转化。如果姚崇隐瞒或是辩解、或是指责，任何一个常规化的动作，都会万劫不复。

# 2、皇帝处理魏知古的帝王心术

皇帝为什么本来想处理姚崇，为什么转身收拾了举报人魏知古呢？帝王心术其实在这里起了很大的作用，首先，皇帝并不在乎姚崇的儿子是不是违法，而是看姚崇是不是对自己坦诚和透明。因为作为领导内心对于下属的贪赃枉法都是司空见惯的，他们没有利益洁癖，领导最看重的，是可以控制，你只要公开透明，这个就能够容忍。而表面上魏知古在维护法律，其实，皇帝看重的是一个 人的做人。尤其是领导身边的人，做人第一位。唐玄宗政变起家，看惯了的唯利是图的人，只有觉得感恩的人才会是忠诚的人，一个不感恩，自己恩师都出卖的人，应该就是个不忠诚的人。所以，很是厌恶。

# 3、魏知古该使用职场举报术

魏知古因为自己在人情和法律之间选择了法律，多么的一个大义灭亲的举动，后来竟然变成了忘恩负义，剧情转变的有点匪夷所思。究其原因，不是魏知古做出了什么，而是没有说对话，魏知古该如何利用这次机会扳倒姚崇呢，权谋网为其设计了一段话术，绝对刀刀见血 “ 皇上，姚崇的儿子向我求官，我不能不告诉你，他的违法行为，但是姚崇曾经对我有恩，怕别人说我忘恩负义，我几天都没有睡好，我还是觉得，维护皇上的规矩最重要，我希望皇上能够看在姚崇为国家做出贡献的份上，减少对他的追究。”这段话，其实和姚崇一个模板，先透明自己的关系行为，然后维护皇上，最后加重道德对比。
