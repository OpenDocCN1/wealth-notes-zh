# 2、中策，一如既往

这段通鉴没有说宇文测.txt是个什么态度。其实没有态度就是态度，一如既往的做自己该做的事情。自己的行为得到领导的认可，说明之前做的是对的。坚持自己，以不变应万变，让领导摸不清自己。

立即上表宇文泰，感谢他对自己的信任，愿意为其肝脑涂地，不辜负这段信任。不论是自己想聚集势力造反，还是不想，这都会延缓时间，麻痹宇文泰，感恩宇文泰，自己未来路更好走。

所以，经过权谋网对上述各种人的分析，我们能够看出来，这个告密的杀与不杀。背后有着深度的计算，被告密者和领导之间的势力对比，彼此的信任程度，告密者自身的身份，都有着莫大的关系。所以，学习权术，要精通到每个细节，不然看似同样的手法，导致结果极大的不同。

# 政治行为动机不明，都会被误读

【出处】《资治通鉴》第160卷梁纪16

【原文】东魏大将军滑浚使大都督高岳救彭城，欲以金门郡公潘乐为副。陈元康曰：“乐缓于机变，不如慕容绍宗；且先王之命也。公但推赤心于斯人，景不足忧也。”时绍宗在外，滑欲召见之，恐其惊叛；元康曰：“绍宗知元康特蒙顾待，新使人来饷金；元康欲安其意，受之而厚答其书，保无异也。”乙酉，以绍宗为东南道行台，与岳、乐偕行。

【译文】东魏大将军滑浚派遣大都督高岳去援救彭城，并想让金门郡公潘乐担任高岳的副手。陈元康对滑浚说：“潘乐反应比较迟缓，不能随机应变，不如慕容绍宗；何况让慕容绍宗去对付侯景也是先王高欢的命令。您只要赤诚对待慕容绍宗，侯景是不足为虑的。”当时慕容绍宗正在外地，滑浚想召见他，但又怕他受惊起疑心而反叛；陈元康对滑浚说：“慕容绍宗知道我陈元康特别受您的照顾和优待，最近他又派人来馈赠我黄金；我为了让他放心，便接受了这些黄金，并在给他的回信中厚谢了他，所以可以保证他不会有的想法。”乙酉，东魏让慕容绍宗担任了东南道行台，使他与高岳、潘乐一起去援救彭城。

【解析】东魏权臣高欢刚刚过世，大儿子滑浚刚刚继承权柄，而对侯景的叛乱，用谁担任主帅，产生了君臣博弈。
