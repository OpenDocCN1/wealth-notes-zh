# 二、皇帝和太子妃的博弈

1、皇帝出题测试太子。

皇帝其实也是很明白太子的智商是有问题的，但是太子背后的势力太大，于是当众出题来测试太子，这个其实就是想利用这个公然的考试，来压制悠悠之口。并不是想单独考察太子智商。真的想测试，不用这样的阵势，私下直接问几个问题就真相大白了。表面是测试，本质是压制。

2、贾妃暗中谋划应对。

出题考试，而不是当众对策，这本身就是给一个作弊的机会。贾妃反应极快，立即找人提刀，给出了一个好的答案，这中间，张泓的直言，让贾妃发现，张泓是个人才，反应快，有智谋，且能够精通人心，并顾忌到多方的利益。于是，立即画大饼给张泓，把优秀的人才拉扯到自己的旗下，承诺共富贵。

3、张泓的正确的反应。

张泓看到贾妃找人代笔的答案，立即就找出了原有很有深度的答案的错误，一个是不符合太子口吻，加重错误；二来，会暴露出代笔人，有无谓牺牲。最后就是因为一个公然的作弊，会让皇帝当众出丑，皇帝也没有台阶可下。所以换成简答直接的答案，就完全解决所有问题。

# 三、贾充由果寻因的权谋推断术

1、皇帝把测试结果拿给卫瓘看

皇帝一开始，在卫瓘进言的时候，为了保护卫瓘，替他掩饰，说“你真是大醉了”，之后也没有说，但是最后报考试的成绩，当众让围观看，这一点，看似没有问题，但是卫瓘立即感觉到了局促。因为卫瓘心里有鬼，所以怕别人看出来。

2、贾充的权谋智慧非常的到位

贾充是个大的权谋家，贾充应该是做了这样的判断，为什么突然皇帝要测试太子，为什么又把太子的成绩让卫瓘看，卫瓘的反应为什么不自然，这样几个行为链接在一起，合理的推断就是一个，就是立即判断出，卫瓘早起进言过。这种细微的判断，就是权谋智慧的结晶。

3、贾充立即定义了潜在的对手

通过皇帝和卫瓘的异常行为，推断出卫瓘不是支持太子的人，于是直接定义了潜在敌人。然后立即对贾妃报告了这个异常情况，贾妃就是贾充的女儿。所以，有其父必有其女啊，立即和卫瓘对立起来。卫瓘掩饰的那么好，就被皇帝的一个小动作，出卖了。

经过权谋网上述的分析，我们能够看出来，不管你掩饰的多好，如果你面对的是一个超强的权谋高手，有一点点的异常，都会被抓住，从而暴露自己。所以，研究权谋，就是要训练自己这种判断力，不然你被人攻击了，你还不知道，贾充能够混那么高，不是简单的小人所能涵盖的。
