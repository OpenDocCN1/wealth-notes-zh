【译文】隋朝晋州刺史皇甫续将要赴任，在向隋文帝辞行时叩头行礼上言平定陈朝有三条理由。隋文帝问具体情况，皇甫续回答说：“第一是以大国吞并小国；第二是以有道讨伐无道；第三是陈朝接纳叛臣萧岩等人，我们师出有名。陛下如果命将出师，我愿意效微薄之力。”隋文帝对他加以慰劳，然后让他赴晋州上任。

【解析】《礼记·檀弓下》：“师必须有名。”就是攻击对手必须有充足理由，对内能够凝聚力量，鼓舞士气，对外能够代表天意，解民倒悬。历朝历代这些借口千差万别，权谋网但是总结起来无非就这三个。

# 1、天道规律

“大吞小，一也。”真正的借口就是没有借口，以大欺小，弱肉强食，本身就是自然的规律。比你大，就要欺负你。你阻碍国家的统一，你阻碍自然趋势，这本身就是逆潮流而动，抗拒潮流，就是违背自然规律，这个借口本身就是最霸气的。你不听我的，就是错。

# 2、吊民伐罪

“以有道伐无道。二也。”如果从实力上不能直接碾压对手，那么就要争取民心的支持，直接动摇对方的基础。孙子曰“昔之善战者，先为不可胜，以待敌之可胜。不可胜在己，可胜在敌”。只要对方无道，我们就能够以此为借口，吊民伐罪，解民倒悬。你做错了，我就有资格惩罚你。

# 3、报仇雪耻

“纳叛臣萧岩，于我有词，三也。”你对我有错在先，你对不起我，那么我对你实施报复就是合情合理，清朝开国皇帝努尔哈赤起兵的时候，就以“七大恨”为借口，来造反明朝，摆脱其管辖，凝聚力量，这就是报仇雪耻借口的集大成。你对不起我，我也就不需要顾愿你！

其实借口这个东西，就是个道德外衣，内核还是实力所在。有实力了，什么借口找不到。不过是为了让自己吃相看上去更美。代表天道与正义，代表人心和道德，借口不能不用，但也不能仅看到这些借口，实力和借口都需要，缺一不可，不可顾此失彼！
