# 三、郭子仪的权谋高明在何处？

1、熟悉人心和事情的发展规律

郭子仪熟悉女人的轻浮，熟悉卢杞内心的敏感，知道皇帝可能的猜忌，同时知道，轻浮的女人和敏感的卢杞绝对会有矛盾，知道卢杞事后会发达，会疯狂报复，知道皇帝实际上处处在暗地收集自己可能引起猜忌的行为。作为权谋高手就要熟悉人，熟悉事。

2、知道如何合理调整自己行为

为什么郭子仪都是和身边的女人一起接待宾客，为的就是给人一种假象，自己属于胸无大志。贪图享乐的人，让皇帝放心。面对卢杞，怕引起矛盾而让女人回避，女人其实就是郭子仪身边的道具。而这些真人版道具，被郭子仪拿得起放得下。

# 四、郭子仪对卢杞这个故事，给我们职场什么启示呢？

1、没事切勿嘲笑残丑之人。

残丑之人，不仅仅体现在外形，内心也会因为社会的大环境与舆论而让其变的冷漠和敏感。一般情况下，社会不会给这类人太多的机会，但是如果这类人没有自暴自弃，而是逆流而上，会极端的冷酷。会更没有底线。所以友善的对待这类人，会较少祸根。

2、打击别人不能只看眼前。

你觉得得罪罪你了，你又如何？你不我，但是大家一定要记住，每个人都有高潮和低调的时候，而在低调的时候，你就会发现平时你得罪的人，都会出来落井下石。所以，我们一定得记住，社会是动态的，是发展的，不能只看眼前，而顾及以后。

经过上述权谋网的分析，我们能看出来，平原看和齐顷公都是对人没有预知，更无应对手段，而导致引火上身，而郭子仪权术思维，不仅看到了潜在的矛盾，而且看到了矛盾的发展，在此基础上，又做出了行为的调整。这就是走一步看三步的深度，不能不让人佩服。

# 成功权谋家的三大标准

【出处】《资治通鉴》 第227卷 唐纪43

【原文】辛丑，汾阳忠武王郭子仪薨。子仪为上将，拥强兵，程元振、鱼朝恩谗毁百端，诏书一纸徵之，无不即日就道，由是谗谤不行。尝遣使至田承嗣所，承嗣西望拜之曰：“此膝不于人若于年矣！”李灵曜据汴州作乱，公私物汴者皆留之，惟子仪物不敢近，遣卫送出境。校中书令考凡二十四，月入俸钱二万，私产不在此。府库珍货山积。家人三千人，八子、七婿皆为朝显官；诸孙数十人，每间，不能尽辩，领之而已。仆固怀恩、李怀光、浑皆出麾下，虽为三公，常顾指役使，趋步于前，家人亦仆视之。天下其身为安危殆三十年，功盖天下而主不疑，位极人臣众不疾，穷奢极欲而人不非之，年八十五而终。其佐官，为名家甚众。
