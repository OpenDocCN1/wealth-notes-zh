好，总有人会站出来做文章，通常是从权力角度入手，说其抗命，但是邢密已经做了解释，再有就是从方案本身来攻击，邢密也做了解释。潜敌无从下手，于是采用了，第三种方案就是领导心理不爽的时期，旧事重提。利用领导不爽，换个事搞你。但是邢密没有直接抗辩，而是通过其人之道，行贿小人解决。

# 二、抗命话术的逻辑结构是什么呢？

+   1、提供自己的方案

记住，否定别人一定要有建设性的意见，因为提一大堆问题，指出这不行那不行，谁都会，为了否定而否定的人很多。而你想抗命领导的意见，一味的拒绝会让领导觉得你是没有诚意的。如果带有不同的方案，这才是就事论事的态度。

+   2、表明自己的心迹

一定要对自己的动机解释，这样做的目的不是为了自己的私利，而是为了组织的整体利益。为了组织的整体利益，自己宁愿牺牲自己，去承担责任，这是自己的态度和心迹不是为了对抗，而是站在了不同的高度看问题。自己不是怕责任，而是怕组织损失。

+   3、支持领导的选择

如果领导非要这样做，那就自己坚决的执行，个人身份来实现对权力的顺从。这个并不是逼迫领导，而是提供三种方案供领导选择，坚决执行、个人执行或是不再执行，让领导说了算。一个指令在领导眼里其实有三重含义，任务的目的、个人的态度以及权力的畅通。个人身份支持权力，表达权力尊重。

# 三、邢密的抗命对我们职场的启示！

+   1、不要盲目的执行命令

为什么不能够盲目的执行命令呢，因为你不知道是不是陷阱任务。有可能通过这件事情，你失败了，自己人头不保。但是如果自己通过上述的三段话术，即使失败了，自己也没有责任。摆脱了干的话是陷阱，不干的话是抗命的尴尬。

+   2、不承担责任下继续干

个人身份参与执行，这是邢密的核心秘密所在，我不承担领导责任，你让我干啥我干啥。“臣所领兵，乞尽付中山，任其处分，臣止以单骑随之东西。”我不贪恋权力，不是不听话，仅仅是认为方案的不正确而已。个人对组织领导完全服从，层面指出自己是为了组织利益考虑，而不是个人循弱私利。

+   3、提前预防别人做文章

普通人会选择直接掰辩，本来让领导就心理不爽了，越是掰辩，就越是对你不爽。邢密是知道权谋的，既然小人来中伤，那么就用另外的小人来解决问题。很多人要明白，你这个辩论赢了，那么旧事重提，依然能够收拾你。所以从根本上解决问题最重要，高手也要善于行贿。
