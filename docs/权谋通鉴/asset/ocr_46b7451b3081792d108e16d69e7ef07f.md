真是这样，假使他们想要做天子，天下怎么会是你家的呢！”代宗安慰劝说一下番，让公主回去。郭子仪听说此事后，将郭曖囚禁起来，自己入朝等待代宗的惩处。代宗对郭子仪说：“有一句俗话说：‘不痴不聋，当不了家长。’儿女闺房中的话，哪值得去听呢！”郭子仪回家，打了郭曖数十大棍。

# 【解析】

这段历史材料，就是著名经典剧目“醉打金枝”的故事原型。郭曖是郭子仪的第六子。这个故事中体现出的人生智慧，值得我们品味学习。

+   1、夫妻之间吵架，恶语相加，本是常态，但是郭曖在冲动中忽略了一个事实，妻子的身份，不仅仅是自己的老婆，更是大唐的公主。“别老仗着，你老爸是皇帝说事，我爹不想当而已。”一句大不敬的话说出口，公主尊严和地位受到了本质的挑战。我敢说，公主飞奔入宫时，郭曖就后悔不已了。

+   2、唐代宗面对公主来哭诉告状，顿时陷入了一个困境。如何定性这个事件，维护权力秩序的话，就必然要严肃处理郭曖，但是之后呢？他们小夫妻以后就结束了，而且和大将郭子仪也就有了隔阂。如果不把这个事情当回事，以后尊严何在？感情和政治糅合在一起，让人头疼。事儿不大，性质大。

+   3、唐代宗竟然在女儿面前承认，“如果人家郭子仪想做皇帝，这江山是不是咱家的还真不好说”又说了一大堆劝慰的话，让升平公主回去了。看似大度的背后，其实皇帝是把这个难题当成皮球踢给了郭子仪。皇帝心里想：郭子仪，你们家牛啊，我承认，那你回来给我个交代吧？

+   4、郭子仪得知这件事情之后，立即明白皇帝的心思，你不处理郭曖就是等着我来表态。于是立即，将郭曖囚禁起来，自己入朝等待代宗的惩处。这个举动，就是自认其罪，他明白皇帝的困境，需要给皇帝一个台阶下。皇帝主动处理会尴尬，但是被动处理就简单多了，把决定权交到了皇帝手里。

+   5、郭子仪主动请罪其实就是在权力秩序上维护了皇帝的尊严，皇帝也就没有必要继续深究下去，于是就把这个事件定性为家事，限制了事件的再度升级。说出了一句老老百姓的俗语“不痴不聋，不作家長”当家长的就是要难得糊涂，小孩子闺房内的事，咱们就别挽和了。

+   6、皇帝原谅了郭曖，作为一般人，就会松了一口气，人家都不追究了，也就万事大吉了。但是郭子仪就是郭子仪，一个权谋高手，出现了神补刀，回家依然把郭曖毒打一頓。你作为皇帝大度可以不追究，但是我作为家长就不能不表态。一来消除皇帝的芥蒂，二来给公主面子，三来警告郭曖管住嘴。

+   7、事情圆满的解决了，公主的面子找回来了，皇帝也没有了尴尬，郭子仪也没有被猜疑，郭曖也为自己的口无遮拦承担了代价。这一切，都是源自皇帝踢皮球的智慧。因为无论皇帝如何处理，都会处于下策。而把问题踢给郭子仪，这个问题就能够进退自如了。
