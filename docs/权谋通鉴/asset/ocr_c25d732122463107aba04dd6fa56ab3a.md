# 阴谋和背叛的权谋原理

【出处】《资治通鉴》 119 卷 宋纪一

【原文】秃发檀之死也，河西王蒙逊遣人诱其故太子虎台，许以悉禾、西安二郡处之，且借之兵，使伐秦，报其父仇，复取故地。虎台阴许之，事泄而止。秦王炽磐之后，虎台之妹也，炽磐待之如初。后密与虎台谋曰：“秦本我之仇雠，虽以婚姻待之，盖时宜耳。先王之薨，又非天命；巡令不治者，欲全济乎孙故也。为人子者，岂可臣妾于仇雠而不思报复乎！”乃与武卫将军越质洛城谋袭炽磐。后妹为炽磐左夫人，知其谋而告之，炽磐杀后及虎台等十余人。

【译文】当初，南凉景王秃发檀被毒死后，北凉河西王沮渠蒙逊派人引诱南凉太子秃发虎台，承诺把悉禾、西安二郡借给他，并借给他军队，让他去讨伐西秦，为父报仇，光复故土。秃发虎台暗地里答应下来了，后来消息泄露，只好作罢。西秦王乞伏炽磐的王后，是秃发虎台的妹妹，所以乞伏炽磐对待秃发虎台仍跟从前一样。但是秃发王后却与其兄秃发虎台秘密策划说：“秦国本是我们的世仇，虽然结成了姻亲，也不不过是一时权宜之计。先王的死，不是寿终天年，临终吩咐不要治疗，于是，他们与武卫将军越质洛城共同策划谋杀乞伏炽磐。秃发王后的妹妹是乞伏炽磐的左夫人，她知道了秃发王后的阴谋后，报告了乞伏炽磐，乞伏炽磐于是斩杀秃发王后、秃发虎台等十余人。

【解析】阴谋和背叛一直是权谋的重大主题，不过是在宫廷中表现的更加突出和尖锐。短短的这段文字，在最为隐蔽的阴谋策划中，展示出了，手下人的背叛，妻子的背叛，亲人的背叛。

一、最隐蔽的阴谋，最信任人的背叛！

1、虎台为报父仇，借助北凉蒙逊的兵力和地盘，准备攻击西秦。一个极可能成功且相当隐蔽的阴谋，却因为背叛而消息泄露。尽管资治通鉴没有说谁泄露的，但是我们能够推理出来。北凉蒙逊方面，出借地盘，士兵，可以说，如果计划得到实施，完全的受益方，坐收渔人之利，北凉这一方不可能有人背叛。而虎台却不一样，他们家族和西秦有很多不清不楚的关系不说，而且，仅凭这点实力无法真的取得胜利。虎台想发动战争，就必须和自己最亲近的人商量。而这些人，面对不可能打赢的战争，内心自然没底。也就不想为了虎台报仇而赌上自己的命。阻止这场阴谋，就能保全自己，所以手下人直接出卖了虎台，本来一个简单的借兵偷袭，转瞬间，因为自己信任的手下泄露而失败。

2、尽管炽磐是自己的丈夫，但是秃发王后，依然选择和虎台密谋，准备刺杀炽磐，这样的女人自己都把婚姻当成权宜之计，办事自然不择手段。本来这个阴谋的可操作性很强。让自己的亲妹妹，左夫人也参加了密谋。但是没想到的是，这个左夫人，却出卖了自己的姐姐和哥哥，直接导致了失败不说，且秃发皇后和秃发虎台因为妹妹的告密，而被斩杀。自
