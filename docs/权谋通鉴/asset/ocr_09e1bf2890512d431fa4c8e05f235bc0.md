他又说：“陛下在内心回避正确的道理，而求助于佛寺这种外物，听从身边的人的错误主意，损害了帝王的宏大谋划。我暗自替陛下感到痛惜！”代宗对他的上书不作任何答复。

【解析】面对下属提的意见，领导的态度在普通人非黑即白的思维方式下，只有两种答案：要么支持，要么反对，但是在中国领导身上，还有第三种，那就是不置可否。通过这个通关案例，权谋网来解析下这个管理艺术背后的原理：

# 1、鱼朝恩的拍马术

每个人都会对已故的母亲追思，皇帝也不例外，章敬太后是唐代宗的生母，而鱼朝恩，却把赐给自己的庄园改造成寺院，来给太后祈福，这怎能够让让唐代宗内心欢喜。而且这个章敬寺修建的极为宏伟壮丽。鱼朝恩做了皇帝想做，而又不好意思做的事情，毕竟这个花费巨大。鱼朝恩承受了众多的反对之声，相当于替皇帝背了黑锅，鱼朝恩这个举动，拍马屁非常到位，获得了领导信任。

在职场，领导的个人欲望和组织有时候是不一致的，在组织利益和个人利益冲突的时候，大多数领导都想选择个人利益，但是却不好明目张胆的来，这时候就需要有人站出来，主动做领导想做，又不好意思主动做的事情。这样就缓解了领导的尴尬，让他摆脱管理困境，又实现自身利益。

# 2、高郢的正确建议

高郢提的建议，站在组织角度，说的非常好，他从三个方面说的，首先是，祈福不能伤害到老百姓的利益，这样对祈福本身不利，违背了祈福初衷；其次，因为修建寺庙对人民驱使，导致怨声载道，对统治不利；最后就是要让皇帝吸取梁武帝的教训，不要伤害自身形象。只有节俭，才能才是圣王的作为。高郢的建议，没有被采用，但是却被作者司马光长篇选取，这也表达了，司马光的认可。

在职场，这类的人非常多，毕竟天下是天下人的天下，公司也是大家的公司，都想让组织走在一条正确的道路，但是，我们要学会兼顾各种利益，要知道领导的个人利益和组织利益的不同，单纯的只维护领导利益，那是小人，只维护组织利益，这是愚人，只有兼顾多方利益，才是高人！

# 3、代宗的领导艺术

对于高郢的多次上书，讲的非常有道理，而唐代宗也不是昏君，他内心清晰的知道，这些事情的影响和后果，而且同时，他也希望自己对母亲的追思和祈福能够实现。如果直接反对高郢的正确建议，这将对忠臣的一个打击，对以后工作不利，如果支持高郢，这对自身利益是个损失，给母亲修建个寺庙都实现不了，做皇帝还有什么意思。所以，不反对你说的，又不想照你说的做，只能不回复。

在职场，很多人觉得给领导提意见，领导没回复，认为是自己没有说清楚，于是就会和高郢一样反复的上书，这其实犯了大忌，领导没有义务对你的建议做回复，要知道，不回复
