委交杨邵、郭威，各部的事务委交苏逄吉和苏禹珪。这二位宰相处断事务，都根据自己的想法，不拘泥于旧有的典章制度；虽然事情没有耽搁滞留，但他的任用舍弃、罢免升迁，只是随心所欲。后汉高祖正依靠、信任他们，没有敢说的。苏逄吉尤其贪婪奸诈，公开索取钱财，毫无顾息。

【解析】贪污历来被老百姓所痛恨，民间也在传播古代领导杀贪官用贪官的权术理论。但是没有几个从贪官的角度来思考，这样高位的人为什么衣食无忧，还会公求钱财，无所顾避？其实他们有自己的苦衷，因为在这个位置，你不得不贪，不贪其实也就坐不好这个位置！

# 1、自保的需要

后汉帝国初创，让苏逄吉和苏禹珪做宰相，这时候不可能拘泥旧制，所以二人快刀斩乱麻，任用舍弃不走程序，快速的识别运用人才。这时候，可以说大权在手，快速的政治运作，自然会积累大量的威望，这时，如果不选择公开贪污，去冲抵政治威望，皇帝是不放心的。越是权力大，越是要贪污。汉朝萧何在后方大权在握的时候，不断积累威望，刘邦也是不舒服，所以自污是宰相避免猜忌的法宝。

# 2、黑手的需要

皇帝让释放囚犯祈福，而苏逄吉直接杀了这些人。按照道理而言，这人违背皇帝的意思，是走不到宰相位置的。但是一步步高升，这说明，领导是让苏逄吉做黑手的。皇帝也是需要小金库的，自己搞钱不方便，于是通过宰相之手，做黑活给自己利益输送，这是历史上常见的事情。和珅大部分收集过来的钱，还是用于乾隆皇帝几次下江南的花费。自己不给上级输送利益，何来位置稳定？

# 3、自利的需要

宰相的位置，一人之下万人之上，很多人盯着，所以以自己和所有人斗，智力显然是不行的。皇帝也不会让你太久在一个位置形成势力，所以，高位，本身就是一个很短的事情，这时候不为自己未来做考虑，怎么对得起自己多年的奋斗，怎么回报跟随自己的人，所以，既然权力在手的时间比较短，就必然会快速的变现。让自己多年的忍耐快速回报，自利也是对下属的一个安抚。

所以说，为了行使权力，而不影响皇帝的威望；为了保住位置，替皇帝做黑活积攒小金库；为了感恩，下属多年追随能够有个回报，是个人通过简单的利害计算就能够搞明白该如何做，所以宰相贪污，更多的并不是为了自己，因为能到这个位置的人，按照马斯洛的理论，早就脱离了基本生存的思考范围。到了一个自我实现的层面，真的欲望强的人也上不去。其实一切都是围绕权力安全，让领导放心，让位置稳定，让下属好用。这才是他们不断的公开贪污的目的，皇帝所以才越用越放心。
