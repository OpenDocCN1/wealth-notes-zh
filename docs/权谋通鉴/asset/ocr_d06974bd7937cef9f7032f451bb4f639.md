# 2、犯错测试

宋齐丘刚上位几个月，就让自己的亲吏夏昌图，贪污官府的钱，这个显示的极不合理，他们这么高的位置了不缺钱，而且刚上位没几个月，就这么明目张胆，其实这是宋齐丘的犯错测试，目的就是测试领导对自己的包容度，人哪有不犯错？真正的领导对自己的心腹都是非常有包容度的。

职场中会不时的初现困难任务，很多领导都会美其名曰，打压担子，培养锻炼，很多人搞不清楚，是领导对自己栽培，还是让自己做陷阱任务，借着栽培的名义来盘剥自己，其实这个用犯错测试就能解决，他不断地允许你犯错，就是培养你，如果不允许犯错，每次都敲打，没有包容度就是利用你。

# 3、远离测试

宋齐丘测试出领导对自己还是念及旧情的，但是面对犯错测试的时候，领导却公事公办了。没有了包容，相当于不会真正的放权，于是宋齐丘就拿出了第三大测试，就是称病辞职，这其实就是远离测试，看看你对我是不是还有依赖度，如果你在乎我，就不让我走，不过南唐主态度很明确，你走。

远离测试其实就是我们常说的，闹情绪，摆挑子，下属希望看到的就是领导主动找过来，驱寒温暖，然后强调非你不可的重要性，请你回去。情感交往中，女人也是往往找借口发脾气，不理你，看看你会不会主动过来道歉，哄她，这时候不管有理没理，主动要求复合，就是依赖度的测试。

历史上远离测试是用的最多的，比如项羽怀疑自己的心腹亲信范增，范增就拿出了远离测试，说，天下的大事基本定了，接下来你自己干吧，请求回家乡养老。本意也是想项羽挽留他，谁知道，项羽直接同意了，走到半路就心情郁闷防病而死。明白这三大测试，你就能确定你在对方心里的地位，下属对领导的权力测试，女人对男人的情感测试，无不一一个道理。都是弱者无法明说，又想知道自己在对方心里的位置。所以，明白了这三大测试，可以说，在职场中，生活中，都特别的重要。
