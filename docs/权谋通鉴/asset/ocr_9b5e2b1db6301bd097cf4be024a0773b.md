高家是不是知情，是不是也想造反，唐高宗就需要通过他们来处理高政，来测试高氏家族对现在皇帝的态度，通过他们的行为，才能知道他们的忠诚度。

最后，唐高宗站在了道德高度拥有了二次裁判权。

高家如果不杀高政，说明，高氏家族对当今皇帝没当回事，可以下手收拾了，不需要顾虑。而他们杀了高政，又让整个高家都陷入了道德困境。不管杀不杀，唐高宗，都能够下手收拾高氏家族，于是直接都贬官了。绕了一大圈，其实还是得到了把高政杀了，家族的人贬官这个法律后果，但是却成功的规避了各种难题和压力。

# 二、其次看高氏家族的自保术

+   1、为什么必须杀掉高政。

高政被牵连到谋反罪，自古以来，谋反罪都是十恶不赦的大罪，这个罪是要灭族的。既然皇帝没有直接按法律手段来，高家已经明白，这就已经很给面子了。如果不杀掉高政，这说明他们对皇帝不忠心。需要高家自己动手处理高政，来表达态度，因此必须杀了高政。

+   2、为什么集体杀掉高政。

家族势力，从来就是一荣俱荣，一损俱损。所以杀高政是家族的事情，而不是高真行自己的事情。所以高家各个势力都要参与，才能都摆脱参与谋反的嫌疑和自己对唐高宗的真心，以及同犯罪分子彻底划清界限。

# 三、高政选择如何死才能最大的玩转残局

+   1、高政除了死，还有没有其他的策略？

高政是太子的厨师长，属于肥差级别，这样的工作应该是铁关系才能拿到的。而政治家族的孩子多，一般都是政治押宝，谁那里都放一个，以后谁成功，家族都能保全，所以高政应该是在执行家族的意图。但是押宝失败后，高政只能通过死，来划清和家里的界限。如果自己逃跑，或是自杀，都不能让自己和家族脱清关系，所以只能选择让家里人杀。所以高政回去后，一进门的情景应该是高政早就预料到的。

+   2、为什么高政不言语不反抗

高真行直接割喉，不能让其发出任何的声音和言语。原因就是无论说什么，都可能被人误读。无论说什么，高家都会无言以对。高政最后都没有发出声音，没有留下一句话，也没有反抗。他的价值就是回到家被大家一起在门口屠杀，完成自己最后的价值。整个家族，完成了一场心照不宣的政治表态。没有解释，没有责备，没有忏悔，也没有温情，一切以残酷的方式收场。

权谋网曾写过政治表态学，但是那只是通过自己的语言和行为表态，但是这次确实需要残酷的、需要借自己亲手杀亲人的血腥虐杀，来完成表态，应该是无出其右的。历史的短短一百多字，展示了人性的残酷。
