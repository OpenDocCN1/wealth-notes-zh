【权术解析】这个事件的背景，就是太平公主控制了朝堂，几乎架空了唐玄宗，而这时唐玄宗的实力还不是很强大，于是谋求政变，除掉太平公主。然而该绝密的计划，却泄密了，面对泄密，唐玄宗展开了权谋角度的应对。权谋网从两个角度系统展开分析：

# 一、被动泄密后的权谋策略

# 1、泄密后不能心存侥幸

唐玄宗得知这一绝密事件泄密后，如果心生侥幸，觉得太平公主不一定会知道，寄希望于侥幸，绝对不是权谋家所为，权谋家从来不把希望寄托在别人手里，立即就必须往最差的方面想，往最差方面想的结果，就是必须要主动权放在自己手里，无论何时，权谋家都在争取先手，控制主动权。

# 2、泄密后立即划清界限

既然你泄密了，那么不好意思，你就自己承担责任，不管你出于什么目的，你自己来承担责任，别怪我无情。权谋家，面对出现意外的时候，绝不引火烧身，不管你之前和我什么关系，第一时间划清界限。很多人出现意外后，感情用事，不能主动断臂，导致被牵连，因小失大。

# 3、泄密后必须主动揭发

如果只是划清界限，落井下石的话，这个只是下策，只是置身事外，但是如何利用这个事件， prop自己的影响降低到最低，这就需要立即揭发。主动揭发，还能够变害为利，进一步获取主动。把造反的性质变成了离间亲情，控制了舆论的走向，同时因为主动也保护了泄密的人不被杀。

# 二、主动泄密角度的权谋术

# 1、主动割肉麻痹对手

泄密后的被动应对，展示了唐玄宗的应急能力。但是我们学习权谋不能只从一个角度来品评案例，这个还有一种可能，就是唐玄宗主动泄密布局的，这样能够让太平公主觉得，唐玄宗，自己的人敢攻揭发，可见其自认势力太小，从而放松警惕，觉得唐玄宗会消停一段时间，对紧接着的政变没防备。

# 2、试探别人周围反应

唐玄宗主动揭发了自己人之后，太上皇交给有关部门审理，很快死刑的决定就下来了，很明显，这些人并不是唐玄宗的人。这时候有没有其他人出来求情或是打击，也是一个自伤行为带来的一次公然测试。测试了谁到底是自己的人，或是是不是对手的人，这是政变前的关系摸底，政变时谁该死的问题。
