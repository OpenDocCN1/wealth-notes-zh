职场还有一群小人，唯利是图，会立即以牺牲自尊的办法，找到领导道歉，一把鼻涕一把泪的哭诉，自己之前是被逼的，希望能够谅解，我就是条狗，你原谅我，能够展示你的宽大胸怀。打我会脏了手，你就把我当成屁放了吧。缺点是软骨头没自尊，让别人看不起，这个需要强大的心理支持。

# 二、权谋家完全是不走寻常路，三步权谋成功化敌为友

普通人的三种做法，都是弊大于利的，而权谋家不为也。能不能化敌为友，转患为利，这是权谋家要做的事情，吉温给出了最佳的答案。巧妙的三步，成功化敌为友，令人惊叹。

# 1、找势力

弱势群体是没有资格谈判的，只有实力均衡的人，才有谈判合作的可能。吉温首要找到的是能够控制萧灵的势力。只有这样，才能够拉平之间的位阶。吉温知道高力士能够控制的住萧灵，就提前出现在高力士的家中，等待萧灵的出现。当然这个需要情报、人脉的支持。

# 2、扯虎皮

高力士和萧灵都是职场混的老手，都是权谋毒辣的人，如何能够瞒得住高力士，能够狐假虎威的、不动声色的借势，吉温采用了搞偶遇和以退为进的策略，让高力士自然而然的主动向萧灵介绍了他们之间的关系。高力士这无形中、无意间就给萧灵一个暗示，吉温是我的人，你不能动他。

# 3、给台阶

很多人走到扯虎皮这一步，认为已经能够高枕无忧了，觉得有上级给自己撑腰，自己什么都不用怕，但是借来的势力还是转化为实际的关系才牢靠。于是，吉温主动向萧灵示好，表明自己不是私怨而是公事，之后愿意配合工作。给了萧灵震慑之后，又给了面子，让其有了台阶，双方和好。

这三步成功的，让吉温和萧灵化敌为友，可为高妙。巧借势，暗威胁，给台阶。
