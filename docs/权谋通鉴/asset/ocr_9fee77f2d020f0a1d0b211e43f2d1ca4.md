能够面对困难和危险的。宗室如磐石也是这个意思。

# ## 2、必树异姓以明贤贤

自己人总是有限，人才的数量就更少了，只用自家人的组织陷于情感和利益的矛盾冲突更多。所以只有使用外人，才能够严格的执行规章制度，才能够不断地提升发展，才能够让组织进入发展的快车道。不断吸纳新人的组织，才是成长的组织。

现代企业，如果只是家族企业，情感辈分代替管理，各个占据高位。错综复杂的企业内部关系，这会让人才望而却步。只有平等的对待人才，让他们能够占据在应有的位置发挥他们的作用，组织才能不断地前进。不明确自己重用人才的组织，是做不大的。

# ### 二、专用偏任一方的坏处。

# #### 1、亲亲之道专用，则其渐也微弱

很多人只用亲戚朋友，这样的组织发展会非常的缓慢，而且做不大。因为人才的限制，不能够拥有快速的学习能力，不能快速的自我净化，这样的组织，死于内耗的很多。没做大恰恰没事，而做大了，分家内斗，就会开始。利益分配不公，就是内耗。这样的基于感情的组织，做大其实就是魔咒，做大了，就崩盘了。

# #### 2、贤贤之道偏任，则其敝也劫夺

如果组织内没有自己的亲人、亲信，而只用那些有才能的人，这些人都是基于利益关系而聚拢在一起的，一旦企业出现困难，出现阶段性周期风险，就会利益分崩离析。这样通过招聘过来的人才结构的企业，一直发展可以，失败，就会有人背后捅你。基于利益的组织，困难就是魔咒，困难了，就崩盘了。

# ### 三、用人的背后原理

# #### 1、用亲在于稳定

基于情感能够稳定。一个组织首先就是考虑稳定，因为没有稳定的根基，一切建立在沙滩之上，随时就会崩盘，没有稳定就谈不到发展。所以，如何稳定一个组织，根基的建立绝对不能全在利益之上，还应该包括感情。有人说，我们建立在共同的理想之上，这个其实就等于建立在虚无之上。任何的统帅，都是要建立自己的亲兵的，无亲不稳。

# #### 2、用贤在于发展

基于利益就能发展。一个组织必须不断地拓展自己的资源，这个就需要人才。《六韬》说过 “以财启众，以众启贤，以贤启天下” 这就是说，有钱，就能招来很多人，这么多人里面，就能找出优秀的，然后使用优秀的人，做出更大的发展。所以，用贤人，目的就是快速的应对世界。所以任何的领导都是爱惜人才的，无贤不展。

任人唯亲，还是任人唯贤，答案出来了，权谋网认为，就是不可偏废，需要并用，缺一不可。这就是中国的管理智慧，不偏不倚，不走极端，亲贤共用。
