# 【译文】

起初，在唐玄宗定诛斥韦后之计的时候，王皇后参与了很多秘密的策划，到了玄宗即位几年以后，皇后姿色渐衰，玄宗对她的宠幸也大不如前。此时武惠妃颇受玄宗宠爱，心里便有了夺取皇后之位的企图，王皇后对此心中不平，常常对玄宗出言不逊。玄宗对皇后越发不满，暗地里与秘书监姜皎商议，打算以皇后无子为借口将其废黜，姜皎将玄宗这番话泄露了出去。继任的濮王李昕是王皇后的妹夫，便将此事上奏给玄宗。唐玄宗很生气，宰相张嘉贞迎合玄宗的旨意，便罗织而成姜皎的罪名，声称：“姜皎妄谈吉凶之事。”

甲戌，姜皎被处以杖刑六十，流放钦州，姜皎之弟吏部侍郎姜晦也被贬为春州司马；姜氏家族的亲属党羽之中还有几个被处以流刑或死刑的，姜皎在赴钦州的途中死去。

# 【解析】

一、一个女人都会面临失弛的局面，失去宠爱，无意是失去了生活的意义，总的来说，无外乎三大原因。

+   1、色衰

每个女人都抵抗不住岁月的流逝，但是每个阶段的女人都有其独特的风韵，年少时的清纯可爱、中年时的温柔体贴、晚年时的雍容华贵。但这一切其实不仅仅靠外貌，最重要的是智慧，皇后早期和唐玄宗共谋，让皇帝觉得是贤内助，收获的赞许。如果知道色衰是早晚的事情，就需要加强智慧。多帮出主意，多帮衬，唐太宗的长孙皇后，唐高宗的武则天皇后，无不是靠智慧立足。而作为皇后，竟然在自己已经不擅长的方面和年轻的武惠妃去斗，岂不是以弱攻强，这不是智慧，是白痴，焉能取胜？

+   2、不逊

毕竟一起经历过很多，作为男人，即使不喜欢了，不爱的，也不至于走到极端，顶多是无视，或是忽视，但是，很多女人最终还是因为自己心里的不良情绪，推动男人，从无视到愤怒的加速进化。皇后无法调整新阶段的现实和内心的落差，不是表现更加温柔，而是不断的抱怨，这样本来就不好的关系，更加恶化，唐玄宗，本来在她身边都体会不到快乐了，到现在为止，进一步体会到了不舒服，这个不逊的态度是对抗而不是缓和，本身就不能掌控自己的命运，更加失去了所有。

+   3、无子

不孝有三无后为大，这是普通家庭，但是即使贵为皇后，也不能不面临生育的问题，武则天之所以能够最后君临天下，原因还是自己有四个儿子护卫着。母以子贵，这是谁都无法改变的自然法则。现在社会也是如此，有自己的儿子，男人离婚可能考虑的更多，但是如果没有孩子，还相处不愉快，女人老了，不用说，已无维系的必要，必须离婚。王皇后，没有孩子这个硬伤，在唐玄宗最后下手处理的时候，没有任何障碍，无需任何情感受外的顾虑。
