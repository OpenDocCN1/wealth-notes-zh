# 二、后汉隐帝在这件事上犯了什么权术错误？

# 1、赏罚无度。

后汉隐帝，完全按照郭威的要求去进行赏罚，完全没有一个赏罚的标准，什么样的人该奖，该奖多少，这都是要有标准的，按照赏罚的标准办事，就不会让郭威钻了空子，而没标准，都凭郭威的建议，让皇帝的奖罚权完全丧失。一个组织避免被别人私自施恩，就必须制定好自己的奖罚标准，完全按标准来，这才能避免被人利用组织的钱，收买人心。

# 2、丧失决策。

郭威建议隐帝应该奖励这个，奖励那个，其实这完全是越权的行为。郭威只能私下建议，呈报每个人的功劳材料，至于奖不奖，何时奖，怎么将，领导没有询问，就直接发表决策性建议，这个很明显是越权。任何人公开提出决策性意见，都是侵犯领导权的行为。因为，领导办了，你落好处，不办，得罪众人。这是逼领导不得不决策，而隐帝丧失决策权而不知。

# 3、权力迟钝。

权力敏感的反面就是权力迟钝。面对郭威这样大功高胜归来。这本身，郭威已经功高震主。隐帝首先要考虑的就是明升暗降，立即思考消除他的兵权和威望，维护自己的权力稳定。而隐帝不但没有这么做，反而不断地帮他赏赐别人，隐帝对权力和民心的走向，毫无敏感。等让郭威做大了，再去讨伐，果不其然，自己丢了江山，而郭威成了后周的开国皇帝。

# 2、独自接受奖励是被孤立，避免功高震主。
