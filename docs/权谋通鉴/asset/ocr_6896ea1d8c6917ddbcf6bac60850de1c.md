崔逕的行为非常的诡异，犯了三大错误，首先违背节制，其次擅自发兵，第三就是单骑走还。很多人会想这是贪功冒进，但是后期看作为总指挥的李崇带领都没打赢，崔逕能够打赢？而且，自己违背节制即使打赢也会军法处置，为什么崔逕要打这样一场必输的战争？

# ## 2、行为动机推理

表面的失败，并不重要，重要的是背后的重大利益。人的动机要么趋利，要么避害。趋利动机 的话，可能是通过这次失败，把很多军费据为己有，通过失败来抹掉亏空。要么是避害，就是他和李崇等不和，怕被上司挖坑直接做死亡任务，被陷害，不如直接失败，可以 保命回家。

# ## 3、失败通盘算计

可以这么说，崔逕绝对不是一时的冲动，而是通盘计算的结果。因为这个布局最大的核心点就是如何让自己摆平失败。从材料中我们能够看出来，他用女妓和田产，行贿元义，让自己没有治罪。这说明，他知道，元义能够搞定这件事，而且自己对价码早有准备。只要能摆平后果，那么做什么都不用怕。

# ## 4、失败掩盖陷害

职场中常见的就是这种现象，被上级或是同僚陷害，不得不做一个陷阱任务。这时候不做不行，做了更不行。这就需要用小失败，中断项目，自己违规被处理，不再执行任务。小 失败避免了被陷害的苦肉计。比如酒驾被拘留，这样会被给处分，但是任务就会被他人接手，避免自己被更深陷害。

# ## 5、失败背后真相

崔逕在众目睽睽的情况下，用失败的方式贪污军费，这个操作难度极大。如果被李崇陷害，为什么事后李崇不同样行贿元义，痛下杀手？应该是大家都不想打仗，故意让崔逕失败，大家都有借口回军了。尽管崔逕失败，大家都认为这是看到战机，勇气可嘉的表现，给皇帝做了个表演。

当然，到底为什么让崔逕做出这样匪夷所思的举动，已经不得而知，权谋学习不是研究真相，而是研究可能性，我们能够看到的可能就上述三种。我们学习研究这种可能性，就是学习这种处理问题的思路。能够在未来的职场中指导具体工作，这就是我们学习通鉴的最 终目的。
