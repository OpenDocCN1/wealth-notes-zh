有信任才能够得到资源，但是只有自由掌握了资源才能够获得造反的条件。时溥是利用把队伍拉到半途中，从地域上，监控上摆脱了支详的控制，对资源有了最后的裁决权，这时候，也就具备了造反的可能性。所有的权谋家，想造反上位就必须获取资源的控制，有了这些，就有了造反的力量。

# 二、造反上位术的过程

# 1、假令

造反上位，如果直接宣布是自己的想法，很多人会被认为是裹挟，不会顺利的追随。但是如果利用信息的封闭，假借命令，就能让很多人，不知不觉间听从指挥，从而跟随自己。兵法一直讲，不能让他知道为什么，听命令就行了。这是第一步，能不能站住脚，就看这个假命令的合理性。

# 2、合兵

时溥第二步就把能够制衡自己的陈蕃的力量拉拢了过来，组建了统一战线。无论是不是心甘情愿，这个招数是极为正确，因为如果自己不能联合到大数的力量，那么自己胜算就会极低，这个工作应该是时溥很早就开始展开，把所有可能的阻力，都提前化解掉。

# 3、虏掠

两支部队顺利的会师，合并一处，这时候就开始虏掠。这一个动作看似残暴，但是这个步骤必须做，不能缺少。原因有三个，首先解决了自己的后勤问题，这是带领一批人造反的命门问题；其次两支队伍进行了融合，不再是独立的两支队伍；第三是士兵参与了虏掠，有了好处，士气上涨。

# 三、造反上位的善后

# 1、逼退旧主

造反已经手握重兵，实力强大了，这时候就要解决自己老大的问题，没有采用开打，而是采用逼迫的办法。“众心见迫”用大家逼得，不是我的原因。犹如后世的黄袍加身，自己被迫的，没办法。让支详自己交出了权力，算是一场和平的交接。

# 2、合法安民

时溥用支详的印信正规途径上表，让自己获取了国家的正式任命，这对整个徐州地区的人民也算是有了个交代。时溥尽管是用重兵获取了权力，但是却没有用武力解决问题，而是采用了政治手法，来处理问题，这是一个权谋家成熟的表现。很多人迷信武力，看似短平快，实际后患无穷。

# 3、除去同伙

当支详交出权力的一瞬间，其实时溥和陈蕃的合伙关系就已经走到了尽头，权力是不允许分享的。两个人就已经是敌对关系了，所以，时溥想揽权，就必须除掉陈蕃，于是采用了螳螂捕蝉黄雀在后的计谋，借助陈蕃在七里亭伏击支详的时候，时溥也就利用陈蕃脱离
