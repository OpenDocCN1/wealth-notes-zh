# 破解威胁的核心权术

【出处】《资治通鉴》第十卷 汉纪二

【原文】楚军食少。项王患之，乃为高祖，置太公其上，告汉王曰：“今不急下，吾烹太公！”汉王曰：“吾与羽俱北面受命怀王，约为兄弟，吾翁即若翁；必欲烹而翁，幸分我一杯羹！”项王怒，欲杀之。项伯曰：“天下事未可知。且为天下者不顾家，虽杀之，无益，只益祸耳！”项王从之。

【译文】楚军粮食短缺。项羽很是担忧，便架设肉案，把刘邦的父亲放到上面，通告汉王说：“今日你如不赶快投降，我就煮杀了太公！”汉王道：“我曾与你一起面向北作为臣子接受楚怀王的命令，盟释结为兄弟，因此我的父亲就相当于你的父亲。倘若你一定要煮杀你的父亲，那么望你也分给我一杯肉羹！”项羽怒不可遏，想要杀掉太公。项伯说：“天下的事情不可预知。况且有志争夺天下的人是不顾及自己家人的，即使杀了太公也没有什么好处，不过徒增祸患罢了！”项羽依从了他的话。

【解析】五代的时期的政治不伪善，冯道，在其权谋宝典《小人经》里说了一句千古名言“无羁无耻，荣之义也！”无羁无耻，就是没有任何约束，也没有任何底线，这样的人才能成功，这说话其实就是刘邦的真实写照。刘邦面对项羽拿着自己老爸的人质威胁，从容破解了危机。我们分析下期中中的奥妙！

# 一、化于无形的人质危机？

+   1、项羽的人质威胁

项羽威胁刘邦，是用刘邦老爸的性命作为威胁的筹码。在项羽心理，刘邦不可能不在乎自己的老爸，毕竟人的亲情，可以说是人世间最伟大的情感之一。项羽觉得击中到了刘邦的软肋，作为一般人，内心就会服软，被握住把柄。人质的威胁不在于外人，而在于被威胁人的内心的价值平衡和选择。

+   2、刘邦的从容应对

刘邦作为中国最具智慧的权谋家，在第一时间做出了选择。老爹的命一毛不值，项羽你爱怎么处置就怎么处置。如果真的杀了煮成粥，我也要尝尝。你杀人无耻，我要分一杯羹，我比你更加无耻。你用亲情要挟我，我就用无底线应对你。你是绑架者，我是流氓，半斤八两，你看怎么办。

+   3、项伯的背后解释

项羽把刘邦当成了普通人，所以要挟失败，项伯是个明白人。项伯讲了三点，可以说揭示了所有威胁人，心理的基础。首先，天下不知道发展到什么地步，要给自己留个后路，凡事不可做绝；其次，为天下者不顾家，这些追求天下的人，早就度过了情关，哪还有什么普通人的道德软肋；最后就是，你杀了对自己却没有好处，而坏处不少，图什么？项伯从
