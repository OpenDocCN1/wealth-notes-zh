# 1、于翼犯了三大错误

首先，秦州都督作为渭州刺史的上级，发出让于翼立即救援的指令，而他却拒绝执行上级的命令，这个极为不妥，不管事后的结果如何，抗拒命令这个行为，就是错的。其次，被吐谷浑攻击的三个州，因为没有外援，在抵抗之后，也会对他心存埋怨，以后同僚关系极难相处。最后就是，坏坏的示范效应，以后于翼自己怎么带兵，大家是不是都可以从自己判断的角度来拒绝你的命令？

# 2、于翼的自以为聪明

于翼能够准确的判断出吐谷浑军队的作战特点，对其军事行动也能够准确的预判，这一方面确有才华。但是一个人的聪明不仅仅在于处理事情上，而是做事做人的方方面面，还要精通领导心理，还要人情世故。只有都考虑到才是一个真正聪明的人。杨修就是例子，精通办事的方法，但是却不了解曹操的权力心理，从而被杀。做事能不能做对是一个智商方面的问题，懂不懂权力是情商方面，所以于翼是自以为聪明，将埋下杀身之祸。

# 3、如何面对错误决策

于翼明知如果执行上级的错误决策，将会兴师动众，带来不必要的损失，面对这个错误的决策如何做，才能够既不违背权力的意图，又能够维护组织不受损失呢？那就是派一小部分部队立即上路，慢慢走。即执行了上级指示，又不带来损失，这就是执行的艺术。在现场，听不听话是一码事，如何做是另一码事。即使事情做对了，你不听话；这样犯的错，比做错事还要大。下属要学会在执行上做文章，而不是直接拒绝命令。

明知不可为而为之，其实要的就是个态度，秦末农民起义时候，张耳陈馀是好朋友，陈馀在赵国被秦军围困时候，向张耳求助，张耳知道，自己的那点兵如果去救，就会是以卵击石，救不出人，还会平白无故的损失，就不去救。但是事后，陈馀被项羽解困出来之后，立即跟张耳反目成仇。这个故事和上述讲的其实是一个原理，就是你救不救是个态度问题，能不能成是另外一个问题。大家对这个态度特别看重，职场尤甚。
