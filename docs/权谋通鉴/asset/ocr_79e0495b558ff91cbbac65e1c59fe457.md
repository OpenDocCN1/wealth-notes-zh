【译文】臣司马光曰：从前宰伯劝告周桓公说：“内宠姬妾地位与皇后相等；外宠重臣与皇帝一样也可发号施令；庶子与嫡子相匹敌；大的都城与国家的势力相匹敌。这都是动乱的根本原因。” 作为人主如果真能在这四方面慎重从事，动乱怎么能自动发生呢？隋文帝只知嫡、庶之分容易出现纷争，皇室的地位孤立微弱容易动摇，却不懂得诸王的势力与皇帝势均力敌就会危逼皇位。虽然一母至亲骨肉，也不能免于相互倾轧夺权。考察宰伯的这些话，文帝只吸取了一点而丢掉了另外三点啊！

【解析】一个组织为什么会乱？很多人都在寻找其根源，因为知道了根源就能够提前预防，让组织保持稳定。而司马光在《资治通鉴》中，引用《左传》的一段话，揭示了一个组织祸乱本源。仔细分析，觉得戍武之极。

# 一、常见的动乱四种形式

+   1、内宠并后

宫廷权斗，一直都是当下的热门戏，甄嬛传、步步惊心等，都是这类的权谋大戏。因为，中国古代的政治大多是用后宫争宠衍发出来的。武则天就是王皇后为了制衡萧淑妃而从感业寺拉回来的，然后武则天争宠击败了王皇后，导致了唐朝最大的动乱，换成了周朝。可见，家庭内斗，对事业的影响极大。

+   2、外宠贰政

权臣，近臣，通过屏蔽主上的耳目，操纵政治的变化，获取利益，可以说，主上的权力，无形中被下放了一旦一个人能够影响到政策权力走向，可以说，这个人无论什么位置，都具备了君主的权势，李林甫就是攫取了唐玄宗的权力而权倾朝野。不专宠、不专信、不专听，才能不失去权力。

+   3、嬖子配嫡

接班人的斗争，历朝历代不断，因为太子一直称为国本。嫡长子，就因为生的早，就该做这个位置吗？有才的其他皇子，不服。唐高祖就是在李建成，和李世民之间，徘徊不定，最终李世民做大，先发制人，发动了玄武门之变，逼迫高祖退位。

+   4、大都偶国

地方势力做大做强，就想自己拍板抗衡中央。唐朝后期的藩镇格局，不就是安禄山、史思明地方势力做大了，就有了抗衡的野心，闹起动乱。动乱的过程中，地方的势力做大，最终解体现了唐朝，进入了长期的割局期间。
