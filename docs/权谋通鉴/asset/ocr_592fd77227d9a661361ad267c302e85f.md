成为元徽攻击元深的工具。元融和裴衍自身没好处，还要得罪人，这就被人当枪使了。职场中，被动当枪使，大多是如此情况，领导内斗，无形中不得不做出选择。

# 2、被人当枪使的尴尬困境

元深和元融被人当枪使，尴尬处境，主要是体现在三个方面：首先是，这个监督是胡太后元深和元融被人当枪使，尴尬处境，主要是体现在三个方面：首先是，这个监督是胡太后命严，让潘在监督，真正执行，这就会被元深错认为，是这两人自己的个人行为。元徽得了好处，这二人成了背锅侠；其次，元深是他们的顶头上司，私下监督，必然会露出马脚。很快就能够被元深发觉，一旦发现，会被当成异己，而提前被收拾掉；最后就是，自己不会得到元徽给的好处，有害而无利。

还有一个更深层面的算计，这二人是同时得到密令的。谁都不知道对方是不是元深的人，如果另一个人提前告知元深，出卖自己，那么牺牲的就是自己。被打击的就是自己，二人不可能同心，成为同盟。

# 3、被人当枪使的破解方法

既然自己没有得到元徽的好处，还极大概率承担不利的风险，那么谁都会做出摆脱这个尴尬处境的选择。如何完成胡太后的目的，让元深不背叛，又让自己处于安全的地位。可以说，元融和裴衍是费尽脑子去寻找答案的，于是采用了直接向元深公开密令的方法。

胡太后让其私下监督，但是二人直接把密令拿给元深看。好处有三，第一是元融、裴衍表明了自己的立场，不是元徽的工具，你们之间的帐自己算；第二，胡太后让我们监督你，因为你有异心，这也是一个震慑性警告，大家都防着你，你别妄动，完成任务；第三，一起公开也避免了二人之前的互相出卖。

上述的分析我们能够看出来，有些矛盾，不是不想参与，就能够避开的。直接把成为枪的身份公开，告诉对方，让其了解，自己的此举并非情愿，也是表明一种态度。同时要注意的是，队友之间并非一心，人心隔肚皮，很可能会被对方出卖。所以，选择坚决执行命令，认为没人知道，也是作死之道。
