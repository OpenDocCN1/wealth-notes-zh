# 2、完美的行为举动

# 3、成功后价值展示

其实这种场景很熟悉，最早项羽说过“富贵不归故乡，如衣绣夜行，谁知之者！”，任何人成功后，都想回到故里让所有人都知道自己的成功，满足自己的炫耀心理。被剥夺齐王身份，改封楚王的韩信，为什么能坦然接受没有兵权的楚王，其根本原因是，韩信是楚人，楚王这个位置，更能满足韩信的衣锦还乡的心理，韩信也是提拔了当初让自己钻裤裆的市井无赖，重赏了给自己饭吃的漂母，指责了不能有始有终对自己的亭长，韩信的话术和行为没有石勒表现的高超。毕竟石勒是皇帝，而韩信只管军事。
