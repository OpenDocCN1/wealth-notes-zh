是真的愿意为自己的牺牲，愿意主动承担责任。如果同意这样做，通过苦肉计能够识别真正的亲情。唐玄宗掌握实权之后，当初苦肉计的这几个人，都获得了极大的待遇和尊崇。

# 三、多角度去思考权谋案例

# 1、偶然事件的应对术

这是一个偶然事件，在突发事件面前，最考验智慧。这时候面临著，各种决策，战略上是不是采取主动，战术上是不是揭发，情感上是不是敢于舍弃。这需要在应对突发事件的时候，必须选择自保，抛开所有的顾虑，留得青山在不愁没柴烧。从这个故事学习唐玄宗的应急智慧。

# 2、必然事件的布局术

但是如果我把这个事件看成唐玄宗自己主动布局事件的话，我们能够极大的拓展我们的思维深度，那就是弃卒保车的苦肉计。主动的阃臂自宫，让对手产生麻痹，以为短时间不会第二次发起攻击，恰恰一场大的政变在酝酿。从这个角度我们能够抛开表象，偶然之间必然化，找到更多智慧。

# 3、普通事件的攻防术

太平公主和唐玄宗的斗争，这就是个普通的政权斗争事件，这既然是普通的事件，我们就需要研究其中他们对手之间的正确攻防。我们看到唐玄宗的一些列的操作，但是太平公主却只是通过有司的主动参与判死刑，却没有主动发难。最好的策略是在唐玄宗求情之前，立即主动哭诉，要求维护国法，杀人。

一个权谋案例，权谋网认为不能只看表面的展示，而是要多角度吸取营养，其实，还有一个隐藏的主角，太上皇在面对这样一个事件的应对之策是什么？他该如何面对儿子的这个举动，他这样做，能不能维护太平公主和唐玄宗斗争的平衡？他的失策的地方是什么，这都是很有意思的思维拓展。所以，我们还要看到没出场的人，他们对利益变动的对策，这样才能全面。

# 权谋交锋之政治打狗术

【出处】《资治通鉴》唐纪二十七 211卷

【原文】崇子光禄少卿彝、宗正少卿异，广通宾客，颇受馈遗，为时所讥。主书赵诲为崇所亲信，受胡人赂，事觉，上亲鞫问，下狱当死，崇复营救，上由是不悦。会曲赦京城，敕特标诲名，杖之一百，流岭南。崇由是忧惧，数请避相位，荐广州都督宋璟自代。

【译文】姚崇的两个儿子光禄少卿姚彝和宗正少卿姚异，平日广交宾客，收受了许多礼物，受到当时人们的非议。主书赵诲受到姚崇的亲近信任，他接受胡人的贿赂被发觉，玄宗亲自审讯，罪当处以死刑，姚崇出面营救，唐玄宗因此不高兴。恰巧赶上因特殊情况赦免京城的在押罪犯，唐玄宗在赦免敕书中专门标出赵诲的名字，另处以杖刑一百，并流放岭南。
