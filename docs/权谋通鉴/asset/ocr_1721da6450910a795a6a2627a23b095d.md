# 二、专权测试的过程和结果。

+   1、秦二世先笑而后不语，应该是知道了自己的势力，大家的态度，以及赵高的能量。自己 已经被架空而无可奈何。说了又能如何，颜面在一个游戏中丧失，自己尚能够有个台阶下， 直接撕破脸，自身还会陷入险境。胡亥此时表现的很聪明。

+   2、群臣的三种态度，沉默不语、认鹿为马和马就是马，三种态度。而这三种态度的背后， 其实就是心理站队：中立、站在赵高一方、站在皇帝一方。而站在皇帝一方的等于是站在 了赵高的对立面。只有当众测试，才能更加真实的测试群臣，也震慑了秦二世胡亥，这也 是自身实力的宣誓。

+   3、把站错队的都逐个的解决了。反对自己的，一个不能留。但是我们看到，那些沉默不语 的都还在。这个结果也是赵高思考平衡的结果，你不反对，就是支持，因为你不可能把所 有人都除掉。毕竟要的是权力，只要听话，不反对，接受专权，都能够保留。

# 三、专权测试对职场的启示。

+   1、要对测试保持警觉性。

职场有很多潜规则，很多时候不会明确的问你态度，人都会伪装自己，只会设法在你没有 防备和两难的时候，让你做出选择。这时候其实就是测试，表面上的答案都是错的，一定 要保持警觉，知道他测试的是什么，想要什么结果？如果真的认为是表面的鹿或是马，这 就是政治幼稚了。

+   2、不想违心就保持沉默。

专权测试中，一部分人，没有说话，做了一个没有选择的选择，这个中立的态度，并没有 受到打击，所以，我们面对专权中的两难测试，宁愿不做，也不能做错。因为做出了错误 的选择，会给自己最差的效果，而我们保持沉默，也是一个自保且不违心的方法。

+   3、领导喜欢服从到盲从。

很多人说，领导喜欢服从的人，其实这个还只是说对了一半，领导喜欢服从的程度达到盲 从的人，完全放弃自己的理性判断，完全唯领导马首是瞻。这样的指哪打哪的人，完全不 去考虑对错，只考虑领导的人，才能够真正的成为心腹。

经过权谋网上述的分析和研究，大家能够看出来，权臣都必须通过这样的一个当众无理测 试，让你在两难中做出站队选择。答案尽管很痛苦，但是很明显，你知道你该站在哪个位 置。任何时候，依附强者，都是弱者的不二选择。
