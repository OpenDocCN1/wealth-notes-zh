# 权谋家上位的标准范本

【出处】《资治通鉴》第254卷 唐纪 七十

【原文】武宁节度使支详遣牙将时濬、陈瑶将兵五千入关，讨黄巢，二人皆详所奖拔也。濬至东都，矫称详命，召师还与瑶合兵，屠河阴，掠郑州而东。及彭城，详迎劳，犒赏甚厚。濬遣亲亲说详曰："众心见迫，请公解印以相授。"详不能制，出居大彭馆，濬自留守务。瑶谓濬曰："支仆射有惠于徐人，不杀，必成后悔。"濬不许，送详归朝。瑶伏甲于七里亭，并其家属杀之。诏以濬为武宁留后。濬表瑶为宿州刺史，瑶到官贪虐，濬以都张友代还，杀之。

【译文】唐，武宁节度使支详派遣牙将时濬、陈瑶率领军队五千人进入关中讨伐黄巢，二人均为支详所奖励提拔的将领。时濬来到东都，假称支详的命令，将军队召还与陈瑶合兵一处，在河阴大肆屠杀，劫掠郑州后向东走。回到彭城，支详出来迎接慰劳，犒赏丰厚。时濬派亲信对支详说：“受兵众的拥戴被迫充当军府总统领，请你解下节度使的大印授予时濬。”支详不能制止，只好搬出军府居在大彭馆。时濬于是自掌武宁军留后事务。陈瑶对时濬说：“支仆射对徐州人有恩惠，不杀他，一定会后悔的。”时濬没有同意，将支详送回朝廷。陈瑶在七里亭埋伏甲兵，杀支详及其家属。唐僖宗颁下诏书，任命时濬为武宁军留后。时濬上表请任陈为宿州刺史，陈瑶到官后贪鄙暴虐，于是时濬另派都将张友替代陈瑶，陈瑶回到徐州后被时濬杀死。

【解析】一个权谋家，经过长时间的隐忍、表忠、结党，最终获取领导的信任，得到了一定的资源，这时候，完成了初级阶段后，就需要完成翻身上位的工作。而时濬一个完美的上位程序，堪称范本级的操作，我们仔细阅读后，叹为观止。

# 一、造反上位术的条件

+   1、获取上级的信任。

为什么我们学习权谋首先研究韬晦术，原因就是，还弱小的时候，一定要低调隐忍，表现的自己很听话，有能力，忠诚没有任何野心。伪装自己做一个领导眼里的乖乖狗，只有这样，才能够获取领导的信任，没有领导的信任，就没有获取资源倾斜的机会。时濬做到了这样的伪装，才能够一成为心腹牙将。

+   2、获取上级的资源。

成为了心腹，进入了领导的视野和小圈子，这才会有获取领导资源的机会。任何的危机都是心腹攫取资源的机会，没有危机，就不会打破现有的利益格局，就不会让领导释放资源，所以，要善于利用好每次危机让自己挺身而出，时濬就是利用了黄巢造反的这个机会，获取了属于自己的队伍。
