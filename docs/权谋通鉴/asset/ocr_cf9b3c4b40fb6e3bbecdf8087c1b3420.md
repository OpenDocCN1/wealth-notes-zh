# 拍马屁的三重境界

【出处】《资治通鉴》唐纪 11 第 195 卷

【案例一】安州都督吴王李恪多次出外狩猎，对当地居民造成危害，侍御史柳范上书弹劾他。丁丑（二十六日），李恪因此被免官职，削减食封三百户。太宗说：“长史权万纪事奉我的儿子，不能匡偏正讹，论罪当处死。”柳范说：“房玄龄事奉陛下，还不能阻止陛下狩猎，怎么能只怪罪万纪呢？”太宗勃然大怒，拂袖而去。过了不久，太宗单独召见柳范说：“你为什么当面羞辱朕？”答道：“陛下仁德明察，我不敢不尽愚忠直谏。”太宗高兴了。

【案例二】霍王李元轨喜欢读书，谦恭谨慎，举止合体。做徐州史，与处士刘玄平为布衣之交。人们询问刘玄平霍王的长处，玄平说：“没什么长处。”问的人觉得很奇怪。玄平说：“人有短处才能见到他的长处，至于说霍王，没有短处，我怎么能说出他的长处呢！”

【案例三】侯君集坐马的前额被虫子咬伤，行军总管赵元楷用手指沾脓，用鼻子闻其臭味，御史上奏弹劾赵元楷谄媚，降职为梧州刺史。

【权术解析】无论是职场还是官场，拍马屁这个绝技，一直被正直人士所鄙夷，却被很多有心追逐成功的人，当成法宝。而权谋家都是人性的高手，所以对拍马技巧不能不深入研究，直接恭维，吹捧，这种低级的肉麻手段，有点层次的人领导都不会接受，只有做到下面的三种境界才算是高手。

1、直接赞美目标的最得意处

案例一中，柳范一句“陛下仁德明察，我不敢不尽愚忠直谏。”一句马屁的话，就转危为安。这直接体现了，柳范不仅仅是个能臣，在拍马屁的技术上也是炉火纯青。柳范的这个马屁就是拍马屁的第一重境界。直接通过自己的行为赞美目标的最得意处。
