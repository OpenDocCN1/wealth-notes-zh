没有了。

# 3、失本

“作为救书及攻讨使印，募乡丁及旁侧士卒以攻德州。众既乌合，动辄溃败。”蔡京不愧为权谋家，在最后垂死挣扎的时候，还能够使用手段，得到了最后的本钱。但是他不仅仅没有利用自己最后的本钱，好好经营，而是直接去打正规军，失去了自己唯一能够翻身的机会和本钱。

# 4、失友

“往依桂州，桂州人怨其分裂，不纳。”蔡京没有了百姓，没有了队伍，没有了本钱，只要之前还有朋友，就不至于走投无路，但是现实很残酷，显然蔡京平时并没有给自己多铺路，在自己去桂州的时候，没有被接纳，没有朋友可以投靠。自己没能力了，也没有外援，也就真的再无实力。

# 5、失上

如果失去一切，你还有领导支持你，你还有更大的资源支持你，你还有最后的希望。但是“敕贬崖州司户，不肯之官；还，至零陵，敕赐自尽。”皇帝很愤怒了，对他的失败，还是给了一个机会，而最后的机会，他竟然不肯听领导的话，最终被赐死。蔡京自己堵死了自己所有的生路，走向了人生的尽头，一样不缺的完美展示了什么叫做完败。

# 二、蔡京的五大失败背后的逻辑是什么？

# 1、失下

把自己的老百姓和部下都得罪了，失去了自己控制的根基，没有了根基，也就失去了凭借和羽翼，落地的凤凰不如鸡。自己管理无能，被人逼宫，这都是失去警觉的结果。

# 2、失中

失去朋友和同僚。出奔，没有人收留，平时蔡京没有为自己留下任何的后路。与人为善，平时多栽花，少栽刺，多交朋友，在困难的时候，才会有别人帮助，而不是落井下石。

# 3、失上

领导的话，你都不听了，其实蔡京的命也就失去了存在的意义了。没有上级的支持，也就走到了尽头。可以这么说，蔡京，失去了根基，失去了同僚，都没有丢命，但是不听话，被赐死，这才是致命的。

# 三、这样的一个完美失败的范本给我们什么启示呢？

1、不得罪领导，所有的错误都不致命。你失去的再多，都不会是致命的。你在职场犯了无数的错误，得罪了无数的人，其实这都不很重要，只要你还有领导支持你，你就永远屹立不倒，这是最主要的矛盾。

2、平时不给自己留后路，会走投无路。
