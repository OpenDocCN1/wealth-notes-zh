# 萧鸾两次调虎离山除对手

【出处】《资治通鉴》139卷

【原文】周奉持舅弟挟势，陵轢公卿。常舆单刀二十口自随，出入禁囷，门卫不敢诃。每语人曰：“周郎刀不识君！”鸾忌之，使萧谟、萧坦之说帝出奉叔为外援。已己，以奉叔为青州刺史，曹道刚为中军司马。奉叔就帝求千户侯：许之。鸾以为不可，封曲江县男，食三百户。奉叔大怒，于众中攘刀厉色；鸾说谕之，乃受。奉叔辞毕，将之镇，部伍已出。鸾与萧谟秘敕，召奉叔于省中，殴杀之，启云：“奉叔慢朝廷。”帝不获已，可其奏。

【翻译】周奉叔倚仗自己的勇武和与皇帝亲近，有恃无恐，凌辱欺侮朝中公卿百官，通常身后跟随二十个带刀侍卫，出入于皇宫禁门，门卫敢怒而不敢言。他还经常对人讲：“我周某人的刀可是不认人啊！”萧鸾对他特别忌恨，指使萧谟和萧坦之去游说皇帝，让把周奉叔弄出朝廷，安排到外地去，作为外援。己巳（二十三日），下令周奉叔为青州刺史，曹道刚为中军司马。周奉叔来见皇帝，请求封自己为千户侯，皇帝准许了。萧鸾却不同意，只封他为曲江县男的爵位，食邑三百户。周奉叔大怒，站在人群中挥刀喊叫，表示不满，萧鸾反复劝谏告说，他才接受了。周奉叔辞谢完毕，将要去青州，部下人马已经出发了，萧鸾与萧谟称皇帝有令，把他召到官署中来，殴打他，直至丧命，并启奏皇帝说：“周奉叔傲慢朝廷，因此处死。”皇帝不得已，只好认可他们的奏章。

【解析】周奉叔是皇帝亲信，且手握兵权，对萧鸾未来的控制朝政形成了极大的阻力。于是萧鸾为了除掉周奉叔，两次使用了调虎离山的计策，终于孤立了周奉叔，把他和自己的势力隔离开，除掉了。

调虎离山，同样的计谋两次不同的使用，精彩纷呈，代表了萧鸾的权谋手腕炉火纯青。

1、第一次调虎离山，切断了周奉叔和上级的联系。孤立他，让其失去联盟。

萧鸾要除掉周奉叔必须首先切断他和皇帝的联系，把他调离权力中心，离开了皇帝的视野，不在皇帝的眼皮底下，就好下手了。什么样的借口，能把皇帝和自己的亲信分开，萧鸾是动了脑子的，这个借口必须是分开才有利于上级。于是找到了一个让他做皇帝外援的借口。皇帝年轻且放纵，手下人多不服，如果有人造反，将会束手无策，让周奉叔出外作为外援，有意外的话能和皇帝里应外合，这个理由，符合皇帝自身安全的借口。于是皇帝派周奉叔离开。执行说服任务是另外两个被萧鸾策反的皇帝的文官亲信。他们不是可能获利者，所以皇帝容易相信，如果是萧鸾自己，皇帝就会怀疑是不是萧鸾有自己的想法，消减自己的羽翼。

2、第二次调虎离山，切断了周奉叔和手下的联系。隔离他，让他失去基础。

切断了周奉叔和上级的关系之后，没有了外在的保护，而周奉叔自己的势力还很强大，必须切断他和下级的联系，才能完全的孤立起来。
