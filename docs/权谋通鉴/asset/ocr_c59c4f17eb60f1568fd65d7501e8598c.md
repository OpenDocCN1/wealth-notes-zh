# 权谋家的政治表演秀

【出处】《资治通鉴》 第 192 卷 唐纪 8

【原文】畿内有蝗。辛卯，上入苑中，见蝗，擿数枚，祝之曰：“民以谷为命，而汝食之，宁食吾之肺肠。”举手欲吞之，左右谏曰：“恶物或成疾。”上曰：“朕为民受灾，何疾之避！”遂吞之。是岁，蝗不为灾。

【译文】长安地区出现了蝗虫。辛卯（十六日），太宗到玄武门北面的禁苑，看见了蝗虫，拾取几只蝗虫，祷祝说：“百姓视谷子如生命，而你们却吃它们，宁肯让你们吃我的肺肠。”举手想吞掉蝗虫，身边的人劝谏道：“吃脏东西容易得病。”太宗说：“朕为百姓承受灾难，为什么要躲避疾病！”于是吞食掉蝗虫。这一年，蝗虫没有成为灾害。

【解析】作为权谋家为了扩大自己亲民的影响力，会做出很多权力行为艺术，这就是我们通常说的政治表演。政治表演的目的，是塑造自己的公众形象。这个不是现代才有的，李世民就是这样一个高手。政治表演有三个特点：

1、政治性

政治表演和其他表演重大的区别是其政治目的。以农业立国的古代社会，蝗灾是大的灾难。李世民通过当众痛恨蝗虫继而吞食蝗虫，向公众传递了一个，上级领导与民共难的形象，这为提升大家的抗灾的信心注入了力量。

2、传播性

如何再能够让这个政治表演得到高效的传播呢，这个新闻点很重要。俗话说，狗咬人不是新闻，人咬狗才是。李世民作为一个皇帝，每天锦衣玉食，而此时，竟然当众把大家认为的脏东西直接吃掉了。具备了极大的反差和新闻点，让老百姓广为传播。

3、高尚性

李世民要是一话不说，直接把蝗虫塞到嘴里吃掉。大家还不知道怎么回事，就下肚子了，很多人会疑惑，领导还有这爱好？脑子是不是傻了？所以，吃蝗虫动机一定要表达出来。表达出动机之后，准备吃了，有人进行了发问，“容易得病的”李世民果断的拔高了其高尚政治意义。

记得某领导在禽流感的末期，当众吃鸡肉，就是类似的政治表演。李世民的这场政治表演，获得了亲民的形象，吃几只蝗虫就达到了极大的传播效果。所以说，政治家大多是表演艺术家，不懂得演戏，很难走向巅峰。
