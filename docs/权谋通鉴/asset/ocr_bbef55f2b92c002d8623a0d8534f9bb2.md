# 职场潜敌联合下的权力绞杀

【出处】《资治通鉴》第 34 卷 汉纪 26

【原文】丞相孔光，自先帝时议继嗣，有持异之隙，又重忤博太后指；由是傅氏在位者与朱博为表里，共毁谮光。乙亥，策免光为庶人。以御史大夫朱博为丞相，封阳乡侯。

【译文】丞相孔光，自先帝讨论立皇位继承人时，就对定陶王持有异议，因而与傅太后和哀帝有嫌隙，后来又大大违逆傅太后的旨意。于是傅氏在朝廷任官的人，与朱博内外勾结，共同诋毁孔光。乙亥（十九日），哀帝下策书罢免了孔光的官职和爵位，贬为平民。任命御史大夫朱博为丞相，封阳乡侯。

【解析】职场斗争非常的残酷，越是往上走，你遇见的潜敌就越多。不管你多么有有能力，一旦你的潜敌达成合意，就会形成权力绞杀，再强大，也会防不胜防。孔光为何陷入权力绞杀呢？

+   1、与上有隙

职场中，任何一个人的失败，其实最大的隐患就是和上级领导有了间隙。一旦彼此不再信任，有了隔阂，那么这个隔阂就会不断地扩大，直到不可收拾。作为有能力的大臣，因为当初不支持哀帝继位，后来也被哀帝不信任。权力不信任，不管你多有能力，都没有用。

+   2、与势重忤

后宫不能干政，一直都是政治的原则，因为后宫只是和权力有亲属关系，而不是直接的政治领导。孔光不听后宫的话，很正常，本身太后就不是孔光的领导。虽然从职位上孔光可以不听太后的，但是太后有巨大的政治势力，一旦违背，就会被势力攻击。对于没有权力但有势力的，你也得罪不起。

+   3、与下挡路

孔光太有能力了，自己占据宰相的位置，让很多人不舒服，因为职位只有一个，而谁都想坐上去，所以下面的人都很能够爬上去的人，都会把孔光当成敌人。只有想方设法把孔光扳倒了，他们才有机会。朱博就充当这样的权势的打手，最终谋取了自己的利益。

作为一个身居重位，既有才能，口碑又好的孔光，如果单一的势力其实极难扳倒，但是一旦上中下三方联合绞杀，那么再强大也极难自保，所以越是高层的人，下场越是很惨，其根本原因就是，不知不觉之间敌人太多。
