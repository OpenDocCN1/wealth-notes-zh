# 二、面对指责，陈平都采用什么权术招数？

+   1、重新定义标准。

每次交锋，其实首先就要确定什么标准。比如对忠诚的定义，领导理解的忠诚，和员工理解的忠诚是不一致的，首先确定了忠诚的定义，大家才能去讨论，什么是忠，什么是不忠。但是大多数人，都在用自己的标准去辩论，导致对牛弹琴，表面热闹，实际离题万里。

+   2、重新定义价值。

合作的基础是价值，人家要不要你，道德是个层面，但是本质还是价值所在。通俗的讲，你有没有用，无论别人如何说，自己就只强调自己价值，这是立足的核心。如果在多个点上反击，就是模糊自己的定位。只能不断地强调一个点，才能形成冲击力，带给对方思考。

+   3、重新定义动机。

行为一旦确定，行为本身，不能辩解，任何试图改变模糊自己行为的事情，都会让自己的动机被人怀疑。所以，自己要首先定位自己的动机。让别人无法在动机这个可变因素上利用。不可变的因素无需解释，只要控制住自己的可变动机，就不会被误解。

# 三、这段材料对我们有什么职场启示

+   1、老板要知道自己要的是什么

一个人有时候，奔跑的久了，就不知道自己为什么而出发了。所以，要时刻的视觉化自己的目标，不断的强调自己要的是什么，要去哪里。如果你要的是办事的人，就不要吝啬自己的交换，如果你在乎的是道德，那么你开公司干啥？赚钱才是硬道理。

+   2、如果给钱少，员工就会自寻门路

一个工作的工资如果不能够让他体面，富足，那么如果恰好还有权力，不贪污，这个可能性就很小。如果只是用道德的要求，这个很难长远。朱元璋时期，无论对贪污的处罚多么残酷，都不能让低收入的官员停止贪污。

+   3、忠诚在职场启示是相互的

很多老板都在片面的强调忠诚，让手下人忠心，听话，这个是片面的。忠诚应该是相互的，老板只有让其感觉到了主人公的温暖，员工才会把组织当成家。古代强调忠诚的背景是家天下，君臣如父子，领导是把手下当成儿子看待的，起码表面忠诚是这个前提。
