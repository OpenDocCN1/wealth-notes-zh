任何高层的人为其说话，为其传递消息，可见，尽管檀道济有极高的军事能力，但是结党 的能力却很差，运作关系的能力也很差，不结交皇帝身边的人，什么时候，都犹如被人蒙 了眼睛。

# 3、领导不信

檀道济在领导病危的时候，近一个月时间，毫无作为。不能够了解皇帝让他来的目的，以 及未能说服领导及其身边人，解除对其的不信任，同时也未能策动边区动乱，让皇帝不得 不放他回去抵抗边境敌军。檀道济也未能自己放弃威胁的能力，主动解除军权，三招一个 都没用到。

# 二、刘义康的权谋手腕！

# 1、除潜

权力心思的核心就是权力安全，为了避免出现危险，都会先发制人，不给其任何机会。所 以，除掉潜敌，是权谋家通行的手腕，不管你现在有没有危险，未来可能有，就算。所以， 檀道济被杀，不在于其做错了什么，而在于他具备了威胁权力安全的能力。

# 2、除后

杀了檀道济，还不算，而且直接把檀道济整个家族灭绝了。天朝的权力政治从来都是斩草 除根的，究其原因，就是都知道风水轮流转，不知道什么时候，自己树立的敌人，就可能 背后来捅刀子。而且越是往上走的人，敌人越多，只能采用灭绝政策，才能身后无忧。

# 3、除根

檀道济，人是死了，但是势力根基还在，很可能他们的部下，因为主帅被杀，激发内心恐 怕被牵连，而惶恐不安，会成为最大的不稳定势力。于是把他的两个核心心腹，薛彤，高 进也都杀了。也就避免了他们以复仇为口号造反，或是投降敌军给自己带来麻烦。

# 三、我们从中学到什么？

# 1、领导眼里，权力安全大于组织安全

自毁长城，领导其实内心都不傻，都知道檀道济这类军事天才的能力，但是领导眼里权力 的安全大于组织的安全，其内心的计算是，组织的安全，是虚无缥缈的，不确定的，但是 内部的权力威胁，确是明确的，人都会先把明确的危险而消除掉。至于未来不确定的危险， 是比较次要的。

# 2、结交权贵，高层关系大于工作能力

有能力和能不能安全，是两码事。一个人越是有本事，越是要结交高层关系，或是领导身 边人的关系，这是给自己安插耳目，给自己带来第一手的信息，能够关键时候给自己美言 几句，高层领导的动态，是一个组织最为核心的权力信息。不知道这些，永远无头苍蝇一 样的盲目。
