# **你不能不知的职场六大敏感点**

【出处】《资治通鉴》第76卷 魏纪八

【原文】中领军许允素与李丰、夏侯玄友善。秋，允为镇北将军、假节、都督河北诸军事。帝以允当出，诏会群臣，帝特引允以自近；允当与帝别，涕泣欷。允未发，有司奏允前放散官物，收付廷尉，徙乐浪，未至，道死。

【译文】中领军许允平时与李丰、夏侯玄交好。秋季，许允任镇北将军、假节、都督河北诸军事。魏帝认为许允应当离京外出，于是诏令群臣集会，魏帝特地把许允拉到自己身旁谈话；许允在与魏帝告别时，泪流满面哀叹着不忍离去。许允还没走，有司就奏告说许允以前曾随便散发官用物品，于是就把他逮捕交付廷尉处理，后又把他押送到乐浪，还没有到达就死在路上。

【背景】李丰和夏侯玄密谋诛杀司马师，事发后被诛杀。魏帝曹芳已被司马师控制为傀儡。

【解析】许允如果精通自保术，本不至死，可是许允触碰了几乎所有的政治敏感点，最后不能不被司马师除掉，不能不死。详细分析其中的权术内涵：

一、许允步步都踩到了官场的六大敏感点。

1、关系敏感。

许允平时和李丰、夏侯玄关系密切，而李丰和夏侯玄已经因为造反被诛杀。这个时候，许允的关系就很敏感了，和这些造反的人平时交往密切，即使没有证据参与行动，也能够让司马师，内心嘀咕了。许允和上级反对的人关系不消不楚，这就是触碰了关系敏感点。

2、身份敏感。

许允镇北将军、假节、都督河北诸军事，这是个相当敏感的身份和职务。因为当时曹魏的首都在邺城，就在河北的地块上，环卫京都。这样的军事大员，本身就是一个很敏感的身份，一举一动其实都代表着无穷的政治意义。即使你内心没有什么，但是你传递出的信号却不一样。

3、交往敏感。

许允和皇帝曹芳走的很近，而且还表现出和皇帝秘密谈话，依依惜别，曹芳此时已经成了傀儡，司马家族的野心已经逐步的暴露。很明显，谁亲近曹芳，谁就是在和定时炸到交往。和司马家族讨厌的人交往，这就是一种刀尖上跳舞的敏感交往，让人不能不往坏处想。

4、时机敏感。

在李丰和夏侯玄刚被诛杀不久，这个政治敏感时期，且在于即将离开，外出镇守的这个时间点，许允和皇帝密切交往的举动，无形中扩大其中的政治含义。这就是我们平时说的：敏感时期，往枪口上撞。正在抓典型，你做出头鸟。
