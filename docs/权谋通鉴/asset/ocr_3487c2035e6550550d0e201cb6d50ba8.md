# 二、皇后被人暗算缺乏权谋

皇后对自己定位不明确，缺乏自保的智慧，且被人家一步步的引导到陷阱中，几句话而丧失了性命，原因有三点：

+   1、皇后的敌人是郭夫人而不是皇帝。

皇后如何保证自己的地位呢，一般来说有四个，让自己的儿子做太子，比如西太后慈禧。或是对皇帝执政方面有帮助，比如唐太宗的长孙皇后。再或是不断的给皇帝推荐美女，没有专宠，自己的地位就能保证。还有就是除掉任何专宠有威胁的人。最为简单的就是除掉专宠的人。武则天除掉萧淑妃，就是排除了这个隐患。所以毛皇后要找机会除掉郭夫人，而不是向皇帝表达不满。

+   2、皇后表达嫉妒之心是败笔。

女人善妒，千古不变，对稀缺的性资源不能不争。但是越是吃醋，越是，让男人觉得自己很累，作为毛皇后，如果你不能得宠，那么最好的策略就是静静的呆着，不犯错，就能保证自己的位置。要有战就战死，如履薄冰的心态。顺着男人，起码不被讨厌。而不是表达不满，让皇帝更加的厌恶。现代婚姻中想保住家庭，不是对出轨的男人横加指责，而是更加的顾好，也是如此。

+   3、皇后被引导进入陷阱。

皇帝已经说了，不准泄露这次宴请。意味着，不让毛皇后知道。因为不是皇后自己的亲情传递的消息，所以只传递了一半，就是昨晚皇帝和郭夫人欢宴。而没有告诉她，皇帝已经明令禁止让她知道。如果皇后知道皇帝的意思，绝对就不会这么往枪口上撞了。因为皇后的信息不全，所以被蒙蔽，煽动妒火，让她走进了陷阱，从而失去了性命。不加甄别的消息，有时候看着是为你好，其实就是陷阱。

# 三、魏明帝为什么为一件小事杀了毛皇后

魏明帝对帝王术运用的极为到位，从毛皇后的一个简单的问话，发现背后的暗线间谍，于是果断的杀伐决断，处理了隐患。

+   1、失宠和管得太多是基础。
