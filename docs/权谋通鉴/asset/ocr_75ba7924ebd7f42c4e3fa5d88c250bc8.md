这不是表达恨，这是让李世勋牢记自己的誓言，你不能背誓，这是单雄信唯一能够设置的牵制能力了。

# 三、李世勋和单雄信的生死之交给我们的职场启示

+   1、不要随便随便的承诺。

李世勋当初的誓同生死的承诺，当时在一起的时候，做到不难，但是形式变化之后，让自己承受了绝大的誓言的压力，如果没有这个誓言，求求情，不成，自己又没什么压力，还能换取单雄信的友情。这个死后，即使做了这么多，也没有看到一句感谢，还埋怨，这就是承诺的后遗症。

+   2、不随便相信别人承诺。

单雄信，相信自己的好兄弟能够搭救自己，给自己生的希望，所以希望越大，失望就越大，本来觉得死不了，但是却还是要被砍头，这就是相信别人的承诺，给自己带来更大的痛苦，如果没有承诺，没有生的希望，也就不会那么痛，该死，死了就死了，但是觉得能活，而死，更痛。

+   3、一定要逼着别人承诺。

当然作为权谋家不相信承诺，也不随便承诺，但一定要学会逼着别人给自己做出承诺。这样就能够给他们再加上一条道德枷锁，增加他心里背叛成本。这样的成本低，效果好，所以盟誓成了权谋家常用的手段，单雄信逼着他割肉而不阻止，就是想逼着老李再次套上道德枷锁。

这个是两个相互盟誓的好兄弟的结局。老李解下了一个道德死环，又被单雄信套上了另一个死环。单雄信，通过指责，验证了老李的努力，通过吃肉，加深了另一个誓言。这样的权谋高手，我相信，他的内心是不相信李世勋的，如果真的是好兄弟，其实就说一句话就够了 “谢谢你兄弟，我知道你尽力了，以后我把所有亲人都交给你，照顾好你嫂子和大侄子，我有你这样的兄弟，死而无憾。” 但是，单雄信没有说出这样的话，满心的恨，离开了这个世界。临死还权谋了一把。
