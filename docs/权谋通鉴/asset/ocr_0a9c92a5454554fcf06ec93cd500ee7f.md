# 二、这三条路的背后都有个人私利的计算

# 1、虚假的声援

袁术内心对于吕布的反复无常，极为讨厌。因为有共同的敌人曹操在，不能不选择联合。但是其内心还是不情愿，于是采用坐山观虎斗的策略。口惠而实不至，声援可以说在春秋战国时期非常普遍的计谋。这类计谋，只能对内部打气使用，对外毫无时机用途。因为，失败时援兵永远都不会来！

# 2、背叛的代价

陈宫在曹操东征徐州的时候，和曹操的好朋友张邈联合造反，直接抄了曹操的后路，差点要了曹操的命，为此后来曹操屠杀了张邈的三族。此时投降陈宫面临的不仅仅是失败，而是背叛的代价。陈宫为了自己避免受辱，反正都是死，不如死战。这是他个人的算计和吕布无关，死战还有活的可能。

# 3、生存的危机

破坏死战之策计谋的是吕布的妻子，他指出，陈宫和高顾不和睦，内斗的利害，又另外，指出陈宫有背叛的前科，不足以在关键时候信任。其实，如果换成其他人围攻，陈宫可能背叛，但是面对的是曹操，这个前科恰恰会让陈宫无法背叛。女人认为，自己过的好，才是根本。死战，玩命的事不能干！

# 三、吕布最佳的应对危机的方案只有一个

# 1、无羁无耻

都到了生命危机的阶段了，也就不要在乎什么面子尊严了。很多人面对失败，都有着不切实际的幻想，这时候，任何人不会帮你，即使出现在你身边，也是为他自身考虑。吕布就是没有从自己的私利角度去考虑，都是听别人的，危机阶段，谁都不要信，只有无羁无耻的心态，才能走出心理束缚。

# 2、保存实力

识时务者为俊杰，留得青山在不怕没柴烧。自己的实力能保存多少就保存多少。吕布远比刘备强大的多，但是刘备在徐州几次都没有守住。什么都不顾，什么妻儿老小，什么铁杆部下，关键时候的一匹快马，比什么都重要。只要曹操不死，这个共同的敌人还在，吕布就还利用价值。

# 3、走为上策

可以说，打的赢就打，打不赢就走，没有什么是不能放弃的。关键时候，舍不得东西，会让你失去的更多。事实也证明，吕布最后被包了饺子。固守孤城，焉能不败。带着高顺张辽和自己的铁军陷阵营一起走才是人生最大的本钱。因为关键时候，能为你考虑只有你自己，本钱在，一切都能赚回来。
