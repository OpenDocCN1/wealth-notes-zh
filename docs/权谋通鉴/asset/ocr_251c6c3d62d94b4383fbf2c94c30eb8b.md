# 2、不 求 回 报

政府一再询问，不为做官，不为解难，一无所求。真正的是一个善良的付出，而不是利益的交换。一个不看重自身利益的人，才能够在人格上受到尊重。可能一个商人，物质富裕之后，就想青史留名，或是洗去铜臭。但是无论如何，卜式，在物质富裕后选择了正确的方向。

# 3、明白大局

汉武帝是个扩张性的人才，雄伟伟略，但是打仗是要花钱的，手里的资金一直处于紧张状态。此时国家的大局，就是能够调动社会的整体财富，来实现大帝国的梦想。而卜式，能够认识大局所在，能够支持大局，这样的人极具战略眼光。卜式不仅仅是对经济，对国家战略也是洞若观火。

# 二、为什 么 汉 武 帝 会 这 么 提 拔 卜 式？

# 1、汉武帝需要经济人才

汉武帝搞国家专营，提拔桑弘羊，重用张汤，期间还出现了千古名著《盐铁论》，这就说明，汉武帝的扩张政策，文景时期积累的财富已经不够用，继续寻求新的增长点，提升国家的收入，所以，此时汉武帝喜欢能够搞到钱的经济人才。

# 2、汉武帝需要树立榜样

不用说，国家来钱最快的方式就是征税和摊派。征税很大层面触动的是最大广大老百姓的利益，会民不聊生，引发内乱，是个弊大于利的办法，而摊派，基本上动的都是有钱人，这类人，钱多，且不会激发社会大层面矛盾。但是很多人就是不拿，隐瞒瞒报，而卜式，恰恰做了表率，符合摊派正能量。

# 3、有钱人做官不会贪污

岳飞说过，文官不贪财，武官不怕死，天下太平。任何领导都不喜欢手下人贪财，但是通过严格肃贪成效也不是很大，但是我们从侧面想，如果一个不缺钱的人，出来做官，不就不贪污了么？一个富裕的人出任官员，追求的名，也就不会贪污了，无形中调节了政权结构。现在西方富翁治国，就是如此。

# 1、无 私 付 出 ， 才 是 大 回 报 的 基 础。
