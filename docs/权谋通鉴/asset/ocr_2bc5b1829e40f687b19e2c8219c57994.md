变得部分不多，这就是我们的另外一句老话“江山易改，本性难移”，熟悉一个人的本性，就能对一个人做出命运预测。

一、权谋家大多预测能力极强，究其本质原因，就是对人性的洞悉。对人性熟练把握，就能对事件的发生发展做出预测。而这段材料，王弘的惊人的预测能力，就是他对他人性格的把握。

+   1、王僧达张狂性格。

王僧达的两个表现，一个是扮装小老虎，一个是打坏别人蜡烛做的凤凰。活跃中带有害性，这样的人自我意识比较强，且不在乎别人的感受，在维护自己利益方面会极端自我，所以容易崛起。但是崛起之后，又会因为这个性格得罪很多人。昙花一现的人物，极度自我，侵略性强。

+   2、王僧绰谦虚性格。

王僧绰也是两个表现，一个是用蜡油捏凤凰，一个是被损坏后不比较。捏凤凰是个艺术性追求，一个人能够对美好的东西不断研究，且在别人打击的时候，保持情绪稳定。这就是一个完美型内敛的性格。有追求，且谦虚，这样的人，会因为价值和谦虚有很多朋友。

+   3、王僧虔平衡性格。

王僧虔也是有两个表现，一个是玩棋子，一个是叠很高且一次成型。玩棋子是个博弈性的性格，能够叠棋子很高，说明了他对平衡的把握能力。平衡就是非孤立的看待问题，能够兼顾各方面的情况，这是当官的基本素质，利益计算和平衡把握。

二、从下面三大层面能准确的预知一个人。

+   1、自我追求，决定高度。

他们三个人，各有追求，一个装小老虎，一个玩蜡油，一个玩棋子。每个人有自己喜欢的游戏，这就是一个人内心的映射，内心喜欢的事物，决定了一个人的高度。追求自己表现，还是追求艺术表达，还是追求博弈对抗，这都会影响到，他能够达到什么样的层次。

+   2、互动能力，决定长度。

每个人能通过自己的努力，达到一定的层次。但是如果不善于和外界的互动，或是找不到属于自己合适的互动方式，那么决定了一个人能够走多远。他们互动方式有代表性，一个具有侵略性、一个具有承受型、一个是平衡型。

+   3、出身平台，决定速度。

王弘是谁？出身琅琊王氏，东晋王导是他的曾祖父。东晋是王与马共天下，身世显赫，所以这三个孩子，能够一开始就拥有极高的出身，有更大的平台。所以，才能够让他们在最快的时间内，走向属于自己的舞台，加速他们的成功。获得成就需要，自己能力，处理与环境的能力，在什么平台资源下拥有这些能力。
