# 3、承诺富豪高回报

# 4、行贿关键的人物

# 5、获取位置后封刺

等自己走到了关键位置，有了实际的权力，这就能够通过各种官场手法，来获取利益，回报当初的投资人了。每个权谋家走向位置之前，都会有这样的竞争，而走向位置之后，又必须善后当初的黑幕，有的只谈投资回报，有的承诺政策支持，而有的权谋家直接灭口 的都有。

# 2、投资看人格

这个人必须有一定的诚信，有过长时间的考察，不然，投资上位之后，投资家的风险依然很大，要么承诺的回报没有执行，要么还会有被灭口的危险，所以，政治交易是个高风险，高收益的事情，对于阴暗的人，投资是要慎重的。
