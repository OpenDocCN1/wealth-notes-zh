【译文】陈宣帝一心认为河南很容易平定。中书通事舍人蔡景历规劝说：“军队劳累将领骄傲，不宜穷兵远攻。”宣帝大怒，认为是破坏大家的斗志，把蔡景历派出去担任豫章内史。他还没有出发，有紧急的奏章弹劾蔡景历在中书省有贪赃行为，声名很坏，因此被免去官职，取消了爵号和封地。

【解析】每个人在职场都有讨厌的人，但是如果你特别想扳倒的这个人，是领导身边的红人，位高权重，且又人品极佳。各个角度都找不到攻击的点，这时候该如何是好？这时候，最好的办法，就是等待机会，使用职场绝学，落井下石的方法，能够一举拿下。

中书通事舍人蔡景历，是中央掌管机要的第一秘书，人品能力，都无可非议，仅仅因为一句话，被直接踢出中央，扳倒蔡景历的这个紧急弹劾奏章，就是那块落井的石头。想操作好这个计谋，需要注意如下的三个权谋要点：

+   1、什么样的陷阱能够扔石头？

这个井必须是自己掉进去的。

蔡景历是因为谏言阻止北伐，被认为是破坏大家的斗志，而被陈宣帝发怒处分的，这坑是蔡景历自己掉进去的。我们在运用落井下石这个计谋的时候，一定要记住：如果是别人陷害的，一定不能妄动，因为，别人陷害，跟风的话，有可能在事后被认为是同党，而可能受到牵连。因为这类领导身边的红人，被别人陷害，很难一次性被击败。如果打不倒，自己扔下的石头风险极大。

+   2、扔石头的最佳时机在何时？

上级领导已经做出相应处分。

领导发怒，很可能是情绪化的产物，事情过了之后，很可能就不了了之了。在领导发怒的时候，切记不能在旁边煽风点火，这样对于多疑的皇帝，立即会把注意力放在你的动机上，早了，导致弄巧成拙。出手的时候，必须是坐实处罚了的。陈宣帝已经对蔡景历做出了踢出中央的决定，这时候，还未执行的，这是追加处罚的最佳时机，等走了之后，晚了，就不能趁热打铁。

+   3、扔出什么样的石头砸最狠？

其石头必须不能牵扯到领导。

大家都看到了，这个紧急的弹劾奏章是从其“赃污狼藉”入手的，这就是在其做人上泼脏水。很多人会觉得，领导不喜欢他的，能够把之前他做的事找出漏洞攻击。其实这个恰恰错了，一来，很多事情无法立即核实，二来他做的事情会牵扯其他人，第三有可能会替领导背的黑锅。所以，从人品入手，不用核实，又没有阻力，还能够避免触动领导最隐藏的内心。看似不重的石头，恰恰砸的最狠。

需要注意的是，明朝徐阶扳倒大权臣严嵩的时候，就没有采用贪污的这个点，因为很多钱，表面是严嵩贪污的，其实是他为皇帝做了利益输送，这个指责，恰恰能够让皇帝同情和保护
