# 2、让亲屢派出来诉苦

然后就有自己的亲屢派的代表，出来诉苦，讲述大家的痛苦，希望能够停止。这时候，他代表了民意，且把民意限制在了一个合理表达的空间。因为这是他们对内心诉求的表达，如果不是孝文帝自己安排的人，很可能就不是诉苦，而是发怒了。这在开会的时候，常用的定调子的技巧。

# 3、让实力派出来求和

有人出来诉苦求情的时候，孝文帝衽出了一个折中方案，就是自己真实的目的。这个时候，大家面临的是一个两难的选择，要么很痛苦，要么更痛苦。大家都在犹豫中，这时候就需要有人站出来引导表态。实力派出来，当托，直接诱导了大家的选择。

# 三、孝文帝这次迁都的权谋，对我们有什么具体的职场启示呢？

# 1、期望值的调整是个大的管理技巧

比如公司每年都发 5000 元奖金。但是如果今年只想发 1000 元，大家就会心存怨气。但是如果提前说，公司效益不好，会裁员，有一部分人要开除，这一下子就打下去了期望值。然后过几天说，大家没功劳还有苦劳，暂不裁员，取消一切奖金。最后，宣布给奖金 1000 元时员工是欢呼的。

# 2、只有使痛苦更加真实才能够让步

每个人让他让步，其实无异于与虎谋皮。因为利益的让出，不是小事。而只能在过程中，让他真实的感受你的态度，他不断加深的痛苦，你才能在坚持的背景下，一点点的让步。让步早了，效果不佳。让步晚了，可能会谈崩，大家形成对抗。

# 3、要照顾各路线派的反应引导发展

任何一个大事件的初现，都会众说纷纭，或是均不表态，搭顺风车的思想。这样不利于控制事态的发展。这时候就要暗地里安排各类代表，有序的表达，能够不混乱，又能引导大家的思维风向，这就需要高超的权谋布局。

经过权谋网对孝文帝迁都的这个步骤和布局的研究，我们能够看出来，想做一件大事，不暴露自己的真实目的，一步步，引导群臣进入自己预设的发展中去，这不仅仅是计谋问题，还有布局问题，以及表演问题。这样的一条计谋，就解决了迁都大事，值得我们不断地揣摩学习。
