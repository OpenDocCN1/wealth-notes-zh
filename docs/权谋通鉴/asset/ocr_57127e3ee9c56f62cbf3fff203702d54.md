人，培养成自己的嫡系，还能公开表达自己的无私，还能分化杨纬内部，可以说，极为智慧。

# 三、布局法烧冷灶

+   1、很难说，权德舆和徐晦不是串通好的，两个人是好朋友，而权德舆太常卿，正三品的部长级干部。面对自己的七品好友徐晦，如何让他能够进入皇帝的视野，采用烧冷灶，展示忠诚情谊，这个招法，也是极大的可能。两个人对杨凭被贬这个事件，自我炒作。

+   2、这个布局法烧冷灶，是极具权谋的，就是烧冷灶不是为了获取杨凭的好感，而是利用杨凭这个事件，展示徐晦的个人品质，对杨凭废物利用了一把。展示完个人品质，再有权德舆利用事件的热度，和关注度，汇报给皇帝，并美言几句，让皇帝对杨晦有好感，毕竟每个人都喜欢忠诚度的人。

+   3、把杨凭冷灶捎给皇帝看，这个招法新颖独特，不然，权德舆如何能有机会把徐晦推荐给皇帝呢，两个人关系越是好，就越不能推荐，毕竟结党之嫌不可避免。但是通过事件来推荐给皇帝，美言徐晦，恰恰自己是好友的身份，能够说明真实情况，相当自然且又不显示自己的结党嫌疑。

这个权谋角度可以说，千古独步。权德舆帮助徐晦，其实也是为自己潜在的结党铺路子。毕竟自己的好朋官做得越大，对自己而言势利就越大。

经过上述的权谋网的分析，我们能够完美的梳理出来，一个关于烧冷灶的烧法。利害法，是低极人对高极人的烧法；借势法，是高极人对低极人的烧法；布局法，是同级好友之间的烧法。利用好每一个机会，展示自己的才华，投资给有才华的人，这就是一个真正的权谋家所为。
