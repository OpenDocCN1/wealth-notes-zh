# 2、冷板凳

让李纲不调动，且在南海很久不召回。让你常年出差，在自己环境不熟悉的地方，坐冷板凳，和家人长期分开，在领导眼里久不出现。这样在不受重视的地方，让你自生自灭，完全没有了脾气，你还找不到对方的弱点，说自己被陷害。

# 3、抓小辫

杨素目的就是激发他内心的不满，等他犯错。当李纲擅离职守的时候，立即出击，李纲被抓住的小辫子。通过合法的手段，让他受到惩罚。要不是因为国家大赦，什么时候能够出来，都还是问题，出来之后，李纲只能隐居在小县城，毫无作为了。

# 二、李纲在职场做错了什么

# 1、李纲树敌太多。

李纲凭借自己的力量和很多人对抗，不仅得罪了杨素，还得罪了苏威，把领导身边的人，都得罪完，你自己如何去对抗一群势力呢？失去援手，自己就会孤立无援。

# 2、李媚媚主无力。

李媚媚主无力，尽管维护了组织的利益，揭露杨素等人的恶行。但是这对皇帝并没有什么好处，也没实际意义。所以李纲被边缘化的时候，皇帝想不起来他，也就对他没啥帮助。

# 3、李纲自身犯错。

那么多人在虎视眈眈，但是都只能利用权力、利用工作、利用小动作，还不足以有大杀招，但是李纲自己被逼着犯了错，这就被人直接用规则，给打下去了，自身辩护都不行。

# 三、李纲和杨素的斗争对我们职场的意义是什么？

# 1、敌人要选一个。

我们选择树敌的时候，千万不能扩大打击面。每次只针对一个，能够提高胜率，且不会扩大化，一旦扩大化，就可能被众人攻击，自己腹背受敌。

# 2、要有自己盟友。

李纲没朋友，皇帝身边，一个替自己说话的人，都没有；自己跑过来汇报，被人抓住了把柄，为什么没朋友呢，这就是平时不善于交际，大家没人帮。

# 3、谨小慎微无错。

想斗争别人，就一定要谨小慎微，在打败别人之前，自己不能犯错。如果这个时候犯错，就是授人以柄。自己会被人抓住这个缝隙，永不翻身。

所以，权谋网认为，杨素收拾李纲的手法，可以说，是职场收拾对手的常用手法，一切都是按照规则玩的，还都一点不犯错。这就是高明之处，你只能恨他，但是你却无力反抗。
