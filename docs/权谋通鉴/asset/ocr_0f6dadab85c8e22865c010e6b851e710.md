# 2、权力让位法律

在赵绰的坚持下，权力让位法律。其实法律代表着长期的整体的利益，而权力是着眼于当下的现实和特殊情况，如何在稳定性和灵活性之间找到平衡点呢，通常都会在制定法律的时候，留下例外条款，通过法律自身的调节，来贯彻权力意图，而不是让权力直接干预。

# 3、保证形式合法

法律分为实体正义和程序正义，法官追求的首就是实体正义，这样能够保证真的贯彻法律，但是如果不能的话，也要退而求其次，保证在形式上合法。就算是做做样子，走走过场，也要让法律看起来起到了效果，这是法律的底线，这个底线不存在了，也谈不上法律尊严了。

# 三、权力和法律协调

# 1、法律必须稳定

法律在组织中的表现就是自己订立的规章制度，这些规章制度，必须有一定的稳定性，才能被遵守，被执行，如果这个经常变，也就不能指导未来的行为，大家就会无所适从，领导自身不维护制度的稳定性，随意执行的话，很快，这个规章就成了废纸。

# 2、权力面对变化

但是，规章制度是死的，而组织的事情千变万化，如何让自己设定的规章制度，不会成为自己权力的绊脚石呢？这个就需要界定权力和制度的边界，以及提前设定调整的方法。通行的惯例就是首先私下协调酝酿，然后召开全体大会，利用少数服从多数的基本政治规律来协调变化。

# 3、权力大于法律

其实，上述的都是正规军的玩法，现实中，很难遇见这样的领导以及如此坚持的执法者，从职场权谋角度而言，永远都是权力大于法律，你不听话，我自有办法收拾你。从整体利益而言，权力思考的维度要大于法律思考的维度，权力思考会更加贴近现实。所以，所权力的话，是第一位的。

经过上述的整体分析，大家要自己做领导的要记住一句话，就是办事，一定要披上合法外衣，非到万不得已不要动用权力。如果动用权力，就首先利用大家集体决议为外衣。明白了这个手段的先后顺序，组织的稳定性和灵活性就真正结合起来了！
