# 3、明其为贼，敌乃可服

对整体打击污蔑对手而言。每次对决的时候，双方都会推出十大罪，十大恨什么的，目的就是对敌人的舆论打击，精神摧毁。战争不仅仅是武力的对决，更是民心的争取，明确对手贼的身份，能够更好的打击敌人内部的自信，能够更多层面的摧毁敌人。

# 二、道德制高点背后的原理

+   1、目标远大，不为私利。

凝聚人心的目标，必然带有普世的价值观，能够唤起人们内心的美好向往。如果仅仅是为了一己之私利，必然丧失团队的凝聚力，你的个人好生活干我一毛线的关系，但是为了我们大家的事，我会出手。

+   2、好人坏人，煽动情绪。

老百姓的是非观并不是理性的判断，而是情绪的带动，大众眼里没有是非，只有好坏。要么是好人，要么是坏人。给他们一个对手是坏人的理由就够了。无须解释太多。他们要的不是证据，是借口！

+   3、立体攻击，瓦解对手。

打击对手，不仅仅是无力层面的摧毁，还要从精神层面瓦解。四面楚歌，可以说，把歌曲作为瓦解楚霸王部队的利器，历史上真的没谁了。摧毁肉体、精神、社会舆论，全面瓦解对手。
