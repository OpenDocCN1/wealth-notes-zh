豫州府治成皋去了。司马消难堂弟的儿子司马珪任尚书左丞，与御史中丞毕义云有嫌隙，毕义云派御史张子阶到北豫州收集道路传闻，打探消息，去了后先把司马消难的典签官和家客监禁起来。司马消难感到害怕，秘密地命令他所亲信的中兵参军裴藻假托私事请假，抄小路入关，向北周请降。

【解析】司马消难政治敏锐度这么高，早就预知了齐主的昏废，“阴以自全为计”提前做好了准备，但是他为什么，逼走了自己的老婆，不解释收留高涣传闻，放任侄子和权臣有嫌隙，这不是自保啊，这是自杀之路，诸多疑点，感觉司马消难的自保行为南辕北辙，蛮的要死，其实我们深入研究之后，就会发现，这些看似违背常理的权术战法，恰恰是高明的权谋：

# 1、逼走公主，是为了切断身边的耳目

文宣帝高洋是高欢的次子，而司马消难的媳妇是高欢的女儿，这个关系，一眼就能明白，司马消难是皇亲国戚，如果有丝毫的反叛之心，就会被告密，毕竟人家兄妹情深。如果司马消难，想摆脱高洋的监视就必须切断耳目，那就意味着摆脱公主。所以以感情不和的借口把媳妇打发了。拔出了自己身边的钉子。为了自保，在感情和利益之间，选择了利益。

# 2、高涣传闻，是制造公开的对立舆论

高涣被文宣帝所猜忌，被追杀，他的逃跑传闻应该是假的，司马消难为了自保也不可能收留高涣，但是为什么不解释这个传闻呢？很显然这个假新闻就是司马消难散播出去的，看似自杀的行为，其实是做给北周看的，如果没有这个虚假消息，他以后逃亡投降的行为，怎么摆脱道德枷锁？作为皇亲国戚，直接跑过去北周，如何被人家信任？假新闻有惊无险，也能够引导舆论。

# 3、利用嫌隙，为自己投靠北周找借口

毕义云派御史张子阶到北豫州收集道路传闻，打探消息，谁给他的权力，直接就把司马消难给囚禁起来了呢？这个风险不大？敢直接在调查阶段就敌对，查无实据怎么办？其实这个是被司马消难利用了，他并没有被囚禁，而是一个直接投靠北周的借口而已。这样北周能够深度信任自己，尽管是皇亲国戚，其实已经被列为追杀对象，生命岌岌可危，投降是真实的，不是造假，要取得北周的接应。

# 4、自保方向，投降北周就是他的战略

很多初级研究权谋的，认为自保就是韬晦，低调做人，拉拢关系，不和人发生矛盾，其实这只是个常用战法，一旦你被人盯住，即使你再韬晦，人家也不会就这么轻易的被糊弄过去，唯一能够做的，就是摆脱这个环境，从北齐这个整体环境中逃离出来，投降北周。敌人的敌人就是朋友。所以，既然北齐要搞他，他就必须投降到北齐的对手北周那边，这就是司马消难的战略。
