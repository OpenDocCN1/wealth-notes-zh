这个事情，皇帝发怒，原因是皇帝的命令不被执行，导致沈怀文直接免官和十年内不得从政。

皇帝的心思是什么？就是皇帝让你去广陵是为了给你警告，让你明白你之前的行为不合上意。给你处罚，只要改过，还有回来的机会，但是你就着不走，被认为是对上级处罚的一种消极抵抗，所以皇帝发怒了。

+   2、被免官后，沈怀文卖了房子准备回老家。

这时候，皇帝怒不可遏，抓他入狱，沈怀文在错误的道路上又走了一步。

为什么皇帝怒不可遏，原因是，你现在不仅仅是消极对抗而是不合作的态度了。对皇帝的处罚无视。没有一点痛苦、悔改、思过的行为，这让皇帝认为打击过轻，没有起到警告的后果，自己的话被无视了，所以加重处罚。

+   3、几个儿子的营救，成了推动沈怀文死亡的最后根稻草。

为什么三个孩子的痛苦救助，和柳元景的说情没能打动皇帝？他们根本就不懂权术，不懂为什么皇帝一步步的加重打击，越是这样做，离死亡越近，原因是沈怀文一直没有承认错误，没有表现出面对打击的痛苦，如果就此放了沈怀文，皇帝没有台阶可下，他们之间的对抗皇帝就彻底失败了。另外一方面，皇帝看沈怀文的能量极大，既然不为己用，留着也就不是好事了。第三杀了他也对其他的不听话的手下一个震慑和警告，求情的越多，级别越高，皇帝就越是没有面子，皇帝会认为你在展示自己的能量，这是叫板威胁的行为。

【启示】作为下级，应该迎合上意，和上级的爱好保持一致，不唱反调，不然会被当成另类而被排斥。面对上级的打击，最不该做的就是没事人一样不在乎，消极对抗，最好的就是应该表现出悔改、痛苦、难受的状态，只有这样才不会加重打击。沈怀文不懂皇帝心思，导致在错误的道路上越走越远。

# 晋升的权谋道路

一个人现在职场晋升其实道路并不多，普通人眼里无外乎两种，第一就是好好努力工作，通过自己的能力和业绩取得上级的认可，晋升；第二条路，就是通过服务领导，拍领导的马屁，获得领导的青睐，信任，从而晋升。

但在权谋家眼里，不用有业绩，因为业绩太辛苦，不用拍马屁，拍马屁，太没有人格尊严。权谋家有所属于自己的第三条道路，那就是权力制衡道路。

先看一下《资治通鉴》宋纪十五里一则经典的故事：

“萧道成为襄阳是北方的军事重镇，张敝儿地位低微，又没有威望，不打算让他据守襄阳。但张敝儿不断请求，对萧道成说：“沈攸之在荆州，你知道他将来会干出什么勾当，不让我去建立内外夹攻的局势，恐怕对你并没有益处。”萧道成会心微笑，不再言语。三月，己巳（初四），朝廷任命骁骑将军张敝儿为统领雍、梁二州诸军事，兼雍州刺史。”
