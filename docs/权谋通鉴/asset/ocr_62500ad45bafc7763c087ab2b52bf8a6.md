# 二、政治稳定术背后的原理是什么？

+   1、给大众安全感。

约束自已的士兵，对老百姓秋毫无犯，让社会按照旧例快速的恢复到原有秩序。这样社会稳定了，大家内心才会有安全感，有了安全感，才不会动乱，才能让他们安定的过自已的生活。

+   2、给领导安全感。

打赢了胜仗很多人，都会内心的骄狂，对上级领导就会忽视，认为自己的功劳大的不行。其实领导一方面希望手下立功，但是又怕功高震主，所以，献给本身就是对领导的尊重。尊重领导，才能获得支持。

+   3、给战犯安全感。

对战犯区别对待，大部分都不再追问，这是对战败的士兵一个安全感。如果处理牵扯的面多，会逼着这群人，再次造反为匪。成了最大的政治不稳定因素。杀主帅震慑，放大众维稳。
