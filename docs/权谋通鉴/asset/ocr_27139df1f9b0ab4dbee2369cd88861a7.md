的拍，效果极佳。

这种间接推拉式的拍马屁方法，适应那些清高的人，正直的人，这是第二重境界。很多文人都喜欢这拍马方法，就是自己见到某个领导，然后就在第三方面前说，自己在领导身边受到了多少的学习，得到了多少指点，让自己受益匪浅，醍醐灌顶云云，这样再次传播到领导耳朵里，彼此都会很受用。

# 3、侧面赞美目标的身边事物

如果你身边的人，都直接恭维领导，出了门，大家都在说领导的好话，直接的间接的，都有人下手拍了。如何，在拍马屁的人群中突出出来，这个是是需要费脑子，费工夫的，不过中国历史上总有高人，已经找到了拍马屁的最高境界，就是案例三中，赵元楷的做法，从领导身上转到他身边的事物上。

赵元楷是真的拍马，领导喜欢的马，自己就伺候的比较好。这就向领导表明了，在领导面前的臣服，不仅仅我对你恭恭毕毕，就是你身边的任何事物，我都能够照顾得到。这种爱屋及乌，恭维及马的角度，让领导心里会更加舒服。即使赵元楷被弹劾，但是侯君集心里绝对是舒服的。

尽管是拍马有风险，想拍需谨慎，但是通过上述的三个拍马的案例，我们能够看出来，拍马屁也是个技术活，直接追捧早已过时，不断地扩大拍马的层次，也是需要不断地钻研的学问，本文也只是通过简单地案例指出三重境界。具体的招法，还是需要大家不断地深入学习和研究的，只有如此才能大成。

# 创业与守成孰难？

【出处】《资治通鉴》唐纪11 第195卷

【原文】甲寅，上问侍臣：“创业与守成孰难？”房玄龄曰：“草昧之初，与群雄并起角力而后臣之，创业难矣！”魏徵曰：“自古帝王，莫不得之于艰难，失之于安逸，守成难矣！”上曰：“玄龄与共取天下，出百死，得一生，故知创业之难，征与吾共安天下，常恐骄奢生于富贵，祸乱生于所忽，故知守成之难，然创业之难，既已往矣；守成之难，方当与诸公慎之。”玄龄等拜曰：“陛下及此言，四海之福也。”

【译文】甲寅（初九），太宗问身边大臣：“创业与守成哪个难？”房玄龄：“建国之前，与各路英雄一起角逐争斗而后使他们臣服，还是创业难！”魏徵说：“自古以来的帝王，莫不是从艰难境地取得天下，又于安逸中失去天下，守成更难！”太宗说：“玄龄与我共同打下江山，出生入死，所以更体会到创业的艰难。魏徵与我共同安定天下，常常担心富贵而导致骄奢，忘乎所以而产生祸乱，所以懂得守成更难。然而创业的艰难，已成为过去的往事，守成的艰难，正应当与诸位慎重对待。”玄龄等人行礼道：“陛下说这一番话，是国家百姓的福气呀！”
