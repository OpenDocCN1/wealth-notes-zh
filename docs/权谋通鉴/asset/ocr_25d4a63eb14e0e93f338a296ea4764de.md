可能通过其他的手段来解决危机，这就会出现不可控的因素，导致失败。

# 2、断绝后路

一定要避免出现其他的援助者，让别人渔翁得利。这就要断了目标所有的后路，这样掠夺者才能够获得更多的谈判筹码，获得超高的抵押，为后面的低价收购打下基础。

# 3、避免激化

既然是掠夺，那么就一定要注意到狗急跳墙，鱼死网破的最差局面。热播电视剧《人民的名义》山水庄园掠夺大风厂就是如此手段，但是因为工人集体闹事，功亏一篑。导致政治激化，掠夺失败。

经过权谋网上述的分析，我们能够看到这个掠夺式创业手法的原理，用兵法讲，就是，趁火打劫，声东击西，上屋抽梯。一连串的兵法权谋之后，就把别人的资产超低价置换到掠夺者手中，完成侵吞成功。

+   【出处】《资治通鉴》第156卷 梁纪12

+   【原文】魏窦泰奄至尔朱兆庭，军人因宴休惰，忽见泰军，惊走，追破之于赤岭，众并降散。兆逃于劣山，令左右西河张亮及苍头陈山提斩己首以降，皆不忍；兆乃杀所乘白马，自缢于树。欢亲临，厚葬之。慕容绍宗捋尔朱荣妻子及兆余众诣欢降，欢以义故，待之甚厚。兆之在秀容，左右皆密通款于欢，唯张亮无启疏，欢嘉之，以为丞相府参军。

+   【译文】北魏窦泰（高欢手下将领）率领军队突然攻到尔朱兆大本营的厅堂，军中的人因为正在摆宴而疏于防守，忽然看见窦泰的军队，连忙惊慌地逃跑，后来在赤岭被窦泰追上击溃，不是投降就是逃散了。尔朱兆逃到荒山中，命令在身旁侍奉的西河人张亮以及仆隶陈山提砍下自己的头颅投降，张亮与陈山提都不忍心这么做。尔朱兆就杀掉自己所骑的白马，自己吊死在树上。高亲自来到尔朱兆自杀的地方，为他举行了隆重的葬礼。尔朱兆在秀容的时候，他的近臣们都悄悄地由高欢表示投靠之意，唯独张亮没有写信联系。高欢对他很赞许，任命他为丞相府的参军。

+   【解析】马伯庸在《风起陇西》这本书的后记里写道“身为一个阴谋论者，我的信条是：历史上每一件事都有一个内幕，如果没有，那么就制造一个出来。对于小说来说，其实历史的真实性并不怎么重要，重要的是要有意思。我喜欢阴谋史观，不是因为那更接近于历史的真实，也不是因为那更能反映出人性的暗面，只是单纯对于这种体制式的诡计与内幕有着叶公好龙式的兴趣罢了。阴谋对我来说，有着一种别样 的美感与质感，流光溢彩的政治殿堂中隐藏的黑暗，才是最富魅力的宝藏。”
