有主管人员。如果不紧急，就必须汇报，听从上级的安排，由上级来处理。

# 2、组织危机

这个必须处理的事情，是组织危机，如果是鸡毛蒜皮的事情，或是不是重大危机，这个也不能行事专擅的权力。韩非子讲了这样的故事来说明问题【从前韩昭侯喝醉酒睡着了，掌帽官见他冷，就给他身上盖了衣服。韩昭侯睡醒后很高兴，问近侍说：“盖衣服的是谁？”近侍回答说：“掌帽官。”昭侯便同时处罚了掌衣官和掌帽官。他处罚掌衣官，是认为掌衣官失职；他处罚掌帽官，是认为掌帽官越权。不是不担心寒冷，而是认为越权的危害超过了寒冷。】重大价值抉择下，才能越权。

# 3、必赢把握

越权的事情，必须有必成的把握。这样在越权和价值挽救之间领导才能很好的判断。但是如果，又是越权，又没有完成危机拯救，不但破坏了权力规则，还给组织带来了另外的损失。这就是双重违规。这就必然在事后受到重罚。

# 三、给我们的职场的深刻启示

# 1、立功机会转瞬即逝

辛昂按照官场正常的条件下升迁是很难的，论资排辈的环境下，很难找到机会。所以面对这样立功的机遇并不多，辛昂果断抓住了这个稍纵即逝的战机，成就了自己，得到了渠州刺史的位置，摇身一变，成了一方诸侯大员。职场也是如此，机会不多，抓不住，就很难快速跃迁。

# 2、风险机遇同根而生

这个重大的机遇的背后是重大的风险。首先是生命危险，辛昂是个组织后勤的文官，带兵打仗是个专业的技术活，弄不好就会丧命。其次是军事风险，如果攻击反叛者打不赢，再损兵折将，后果会非常严重。最后是政治风险，本非职权内的行为，弄不好官位就丢了。

# 3、知识能力提前储备

招募组织军队，带兵武力平叛，这不是一个文官的能力范围，但是辛昂能够快速的组织起三千人的军队，加倍赶路，直接出其不意的攻击敌袭，顺利平叛，这就是他业余时间积累学习的结果，关键时候用上了，在职场也是如此，不要只搞本质工作，还要积累储备对组织拥有的其他知识。

经过上述的分析，我们要深刻的记住，这个先斩后奏的三个个人条件和三个外部条件。只有这六个条件全部具备了，才能够越权而为，不然就是“越官则死”，司马懿在没有授权的情况下平叛孟达，也是同样的内部和外部条件，这需要我们对比赛学习。
