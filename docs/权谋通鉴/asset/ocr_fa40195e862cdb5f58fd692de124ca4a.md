+   二、王承丕在叛乱的裹挟过程中，出现哪些失误的举动：

+   1、没有当众宣称是孙钦主谋的。

想裹挟孙钦加入反叛，就必须当众宣布这一切都是孙钦的意思。即使孙钦反对，公众也会认为他们是一伙的，有口说不清，才能够拉他下水。给他一个抹不掉的污点，后期也不会有人相信他。应当打着孙钦的旗号来赏赐士兵和释放囚犯。

+   2、不熟悉孙钦的性格收买失败。

当孙钦让王承丕拿出诏书的时候，他竟然说“我能致公富贵，勿问诏书”，这个回复相当的低劣。一来是他不熟悉孙钦需要的是什么，二来这样一个没有具体内容的空头支票缺乏吸引，最后就是没有支付期限而缺乏诚意。

+   3、对孙钦的意外举动缺乏预案。

裹挟孙钦，自然人家不会情愿参与造反的事件，孙钦逃跑是个必然的心理反应。王承丕必须先行限制孙钦的自由，而从这段资料，我们看出，对孙钦缺乏控制，并且让其顺利逃跑，且逃跑后，王承丕没有利用释放的囚犯和奖赏的兵卒对抗。必须战前动员，成为利益同盟，告诉他们，不得不到了都会失去。

+   三、王承丕如果再来一次，他应该做出如何的操作裹挟术：

+   1、杀死郭延钧之后，必须立即控制孙钦。

王承丕，想裹挟孙钦，就必须在刺杀的时候立即控制孙钦，只有控制孙钦，才能利用他，把改变的行为嫁祸给他。挟持孙钦，是最重要的手段。不控制孙钦，就会被反噬。对孙钦而言，必须杀掉王承丕才能自证清白。所以孙钦一旦逃跑，就必然要杀掉王承丕。

+   2、立即用孙钦的名义对外发布各种命令。

王承丕杀掉郭延钧，立即“赏士卒，出系囚，发电戎”这是对的，但是应当当众以孙钦的名义，这样给大家的误解也是孙钦杀了郭延钧，也是孙钦给了大家好处，这样就会增加以后孙钦的辩解成本，或是增加朝手下心腹对孙钦的敌对情绪。

+   3、派人用孙钦的名义向上级领导提要求。

王承丕必须立即用孙钦的名义向蜀王提出要求，离开蜀王对孙钦的信任，给大家一个假象，孙钦利用禅行的时机自行造反。王承丕成的话，能够裹挟孙钦，自己成为实际的老大。或者是成功嫁祸给孙钦，自己报了私仇。这是一箭双雕的策略。
