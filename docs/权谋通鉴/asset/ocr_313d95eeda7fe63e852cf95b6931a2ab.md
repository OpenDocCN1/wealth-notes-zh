# 1、组织不会替你说话。

郑崇为了维护大汉帝国这个组织的利益，维护汉家制度，不惜违背皇帝的命令和太后的意愿。这在组织里太常见了，究竟是组织利益大，还是领导利益大？很多人从小接触的教育就是组织利益大于个人利益，整体利益大于局部利益。但是我们真正的走向社会后你会发现，你所维护的这个虚构的组织，当你自己受到具体人迫害的话，组织不会出来帮助你，挽救你。永远记住这个权谋原理，组织不会替你说话，替你说说话的，还是具体的人，你为了虚构的组织得罪具体的人，你只能处处艰难。

在职场很多人，为了组织的利益和领导争的而红耳赤，觉得自己很高大上，其实已经深深的埋下的隐患。很多人说，不这样组织何来前途，其实你还是想想你自己的前途比较实际。

# 2、你得罪了具体的人。

在组织内，利益就这么多，你维护一方的利益必然会抵拮另一方的利益。你维护的利益，如果得罪的利益是具体的人，那么，你就会得罪具体的势力，而被不断的攻击。权谋原理是，永远不要得罪比自己强大的势力，无论你什么理由。其实你无需横顺，组织利益和领导的个人利益并不一致。领导对组织的整体利益都不在乎，你在乎什么呢？封侯的事情，拿的是国家的官帽子，给的是领导的亲戚，又不是拿你的利益送人，你激动个什么呢？只要不触动自己的利益，无需出手。

在职场，很多人操闲心。看不惯一些现象，或是替别人说话，从而得罪领导。不是你的利益，你主动招惹领导的反感，有害处而无利。做好自己的工作，维护好自己的利益，少管闲事才是稳定之道。

# 3、阻碍了权力的畅通。

郑崇的谏言，并没有改变皇帝做出的决定。理由，就是太后的这句关键的话，你做为皇帝还需要被下顾控制么？这句话说的一针见血，领导的权威何在。你阻止领导的权力行使，你说了算，还是领导说的算。阻碍权力的畅通性，是职场大忌之一。太后的话，让皇帝骑虎难下，她没有围绕改不改封侯的条件，替自己辩护而是指出郑崇侵犯了皇帝的权威。问题变成了，不是有没有资格封侯，而是不封，皇帝茫无而子，这就触动了皇帝内心的权力动脉。

在职场，你觉得得在和领导争论组织的当下利益或是长远利益，殊不知，领导却不这么看利益问题，而是认为你不听话，想收拾你。不是你答案错，而是你不给他面子，不尊重权力。

经过上述的分析，我们能够学到，任何时候都要维护领导的具体利益，和自己利益无关的事最好不出手，不要反对领导，因为你觉得是利益问题，其实这背后是权力问题。在职场上混，不懂权力问题，那么你就永远不会被权力所喜欢。
