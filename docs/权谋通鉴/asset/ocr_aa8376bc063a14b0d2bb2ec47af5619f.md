悉委于道。帝尝访以军谋，对曰：“征伐大事，在圣心独断。臣书生，惟知谨守历代成规而已。”帝以为然。道尝称疾救退，帝使郑王重贵诣第省之，曰：“来日不出，朕当亲往。”道乃出视事。当时宠遇，群臣无与为比。

【译文】八月，辛丑（初三），后晋高祖任用冯道守职司徒兼侍中。壬寅（初四），后晋高祖下诏：中书省掌印大权只交给宰相，从此事无大小，都要交给冯道办理。后晋高祖曾经把关千用兵的谋略征询冯道的意见，冯道回答说：“征伐是国家的大事，取决于圣上意志的独断。我是个书生，只知道谨守历代的成规而已。”后晋高祖以为他说得对。冯道曾经称病要求退职，后晋高祖让郑王石重贵到冯道的府第探视他，并说：“明天还不出来，朕就要亲自去请他。”冯道这才出来视事。当时的宠遇，群臣没有能同他相比的。

【解析】冯道，五代十国的传奇人物，一生历经五朝十二帝，可谓真正的官场不倒翁。权谋家无不对冯道深有研究，权谋网通过这一小段材料，窥一斑而知全豹，把冯道的核心权谋解析给大家：

# 一、明确自己的权力

很多人在职场不明白自己的权力，不知道自己和领导的边界所在，不是权力越界，就是行为犯上。而冯道很清楚自己的身份，自己再大的官也是为领导服务的，不染指决策，自己做好执行，这是对权力的尊重，对身份的明确。职场人切记，任何之后，有领导在，你都没有决策权。

无论多高的位置，你在领导面前都是搞执行工作的。

# 二、明确自己的工作

“征伐大事，在圣心独断。臣书生，惟知谨守历代成规而已。”冯道自己的工作是宰相，但是自己定位在书生，就是不涉及军旅之事，而且只谨守历代成规。这就是说，他内心对自己的工作极为明确，不贪权，就会让领导安全，谨守成规，自己不依照自己的主观做决定。

无论多大的权力，你都要找到成规而不是主观决定。

# 三、明确自己的做人

冯道重要的还是会做人，知道以进为退的道理，借有病来退职，这就是向领导表明自己无意于贪婪权势。不留恋权力，这是没有野心的表现，所以皇帝才不断的挽留；第二个就是工作能力强，面对事无巨细的事务能够游刃有余，没有给领导找麻烦。

无论是什么身份，领导最喜欢的还是有能力无野心。

经过上述的权谋网的分析，从权力层面、从工作层面、从做人层面，分析了冯道的成功之道。表现的没有野心，一般人会懂。但是，很多人会有疑问，为什么领导咨询自己的意见为什么不说，为什么要墨守成规，其实这都是涉及到自己人生安全的问题。不涉及军事，领导就放心，不去创新，就不会被认为有私人心机，冯道的核心秘密其实就是两个字“自保”！
