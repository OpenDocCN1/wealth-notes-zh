
## 3、失本

没有了。

“作为救书及攻讨使印，募乡丁及旁侧士卒以攻德州。众既乌合，动辄溃败。”蔡京不愧为权谋家，在最后垂死挣扎的时候，还能够使用手段，得到了最后的本钱。但是他不仅仅没有利用自己最后的本钱，好好经营，而是直接去打正规军，失去了自己唯一能够翻身的机会和本钱。

## 4、失友

“往依桂州，桂州人怨其分裂，不纳。”蔡京没有了百姓，没有了队伍，没有了本钱，只要之前还有朋友，就不至于走投无路，但是现实很残酷，显然蔡京平时并没有给自己多铺路，在自己去桂州的时候，没有被接纳，没有朋友可以投靠。自己没能力了，也没有外援，也就真的再无实力。

## 5、失上

如果失去一切，你还有领导支持你，你还有更大的资源支持你，你还有最后的希望。但是“敕贬崖州司户，不肯之官；还，至零陵，敕赐自尽。”皇帝很愤怒了，对他的失败，还是给了一个机会，而最后的机会，他竟然不肯听领导的话，最终被赐死。蔡京自己堵死了自己所有的生路，走向了人生的尽头，一样不缺的完美展示了什么叫做完败。

# 二、蔡京的五大失败背后的逻辑是什么？

## 1、失下

把自己的老百姓和部下都得罪了，失去了自己控制的根基，没有了根基，也就失去了凭借和羽翼，落地的凤凰不如鸡。自己管理无能，被人逼宫，这都是失去警觉的结果。

## 2、失中

失去朋友和同僚。出奔，没有人收留，平时蔡京没有为自己留下任何的后路。与人为善，平时多栽花，少栽刺，多交朋友，在困难的时候，才会有别人帮助，而不是落井下石。

## 3、失上

领导的话，你都不听了，其实蔡京的命也就失去了存在的意义了。没有上级的支持，也就走到了尽头。可以这么说，蔡京，失去了根基，失去了同僚，都没有丢命，但是不听话，被赐死，这才是致命的。

# 三、这样的一个完美失败的范本给我们什么启示呢？

1、不得罪领导，所有的错误都不致命。你失去的再多，都不会是致命的。你在职场犯了无数的错误，得罪了无数的人，其实这都不很重要，只要你还有领导支持你，你就永远屹立不倒，这是最主要的矛盾。

2、平时不给自己留后路，会走投无路。

一个人无论做什么，都需要居安思危。反者道之动，你不可能永远在高位，不低潮。这就需要狡兔三窟，在风光的时候，安排好后盾，才能够有备无患。不能到失败了，才知道没有未雨绸缪。

3、你可以失去所有但是不能失去本钱。

没客户，没团队，这都不重要，只要你还有本钱，你就能够东山再起。吸取所有的教训，找个地方疗伤。但是如果盲目的，处于情绪中，消耗掉唯一的本钱，也就只能任人宰割了。经过权谋网对上述失败标本的研究，我们能够看出来，失败并不可怕，怕在全盘崩溃，怕在没有抓住主要矛盾，怕在没有未雨绸缪。研究了这种失败的范本，会对大家的职场未来有帮助。

# 拉垫背和拖后腿的背后是深深的自保算计

职场中有这样的一类人，他失败的时候，拉你做垫背的；你成功的时候，他拖你后腿。职场中面对这样的小人，有时候真的是无可奈何，但是从权谋角度而言，你就会发现，这类自保的策略，竟是这样的有效和常用，我们不能不深刻的研究其权术内在的规律。

我们先看《资治通鉴》第 252 卷，唐纪 68 中的有趣的两个故事：

【材料一】丁丑（二十四日），王昙卒兴元、资州、简州之兵三千余人进军于毗桥，与南诏军前锋遭遇，王昙出战失利，退保汉州。当时成都军民日夜盼望援军的到来，而窦滂自以为所领定边军辖地尽失，希望西川也相继失陷，以便分担和减轻自己的罪责，因而每有援军自北而至，即往游说：“南蛮兵众多于官军数十倍，官军远道而来，疲惫不堪，最好不要贸然前进。”唐援军将领听后都狐疑不敢进。

【材料二】起初，朝廷派颜杓庆复往救成都，而命宋威率军屯于绵州、汉州作后坐。但宋威乘胜先至成都城下，破南诏蛮军所立战功最多，遭到颜杓庆的妒嫉。南诏蛮军乘夜逃走后面，宋威令士兵赶紧吃饭，企图追击蛮军，成都城中的战士也想与自北而来的唐军合势共同追击，颜复行文给宋威，收夺其兵权，令宋威归汉州据守。南诏蛮军退至双流，被新穿水阻挡，一时造桥不成，军队狼狈拥挤失去控制，三天后才造好桥，得以通过新穿水，其兵甲器物衣服很多都遗弃于路上。蜀中人士对颜杓庆不准宋威追击蛮军的举动极为痛恨。

通过两段故事，我们深刻的做下背后的权谋心理分析：

# 一、为什么失败了要拉人垫背

1、每个人都无法避免的会有失败，很多人会想，说个对不起，道个歉，大不了接受惩罚不就行了。其实不然，因为你在职场明着暗着，都有很多潜在敌人或是对手，都在虎视眈眈的看着你，就等着你失败，然后狠狠的踩上一脚。所以说这不仅仅是个责任承担的问题，而是不被深刻加害的问题。

2、中国自古讲究，法不责众，就是犯错的人多了，从法律问题就变成了政治问题，或是社会问题了，作为领导者，不可能全部都惩罚，所以，要把自己的错误变成一群人的错误，学会升级错误，小事变大事，领导就不能过重的追究自己的责任了。毕竟不是自己的个案而是机制或是环境问题。

3、你一个人犯帮，没有几个人给你开脱，唯恐被你的错误所牵连，但是如果把更多的人都拖下水，这就不一样了，这些一起犯帮的人，就会形成巨大的势力，且每个人背后都有错综复杂的背景和利益关系，这就能够为避免惩罚动用更多的资源和关系。从根本上进一步弱化自己的斗争投入。

# 二、为什么别人成功要拖后腿

1、心理的需要。中国式的心理从来都是“不患寡而患不均”，大家都穷没什么，但你有钱，大家就必须伤害。职场也是如此，大家都平庸着，没事，但是你如果自己立功，没我们的份，这就不行了。我不成功，我也不能看着你成功，你成功了，我就会被比下去，这会刺伤自尊，所以要拖后腿。

2、利益的需要。一个人在组织里立功，这个最大的合法性。无论什么情况，组织都会认可，给予嘉奖。如果立功的人，再懂点权谋术，立即有可能飞黄腾达，被快速的提拔上去。职场里，资源就这么多，位置就这么多，不现在拖后腿，等你上去，就无法竞争了，所以提前就要解决。

3、争宠的需要。领导喜欢什么样的人？就是能够为其解决问题的人。立功就是快速进入领导视野，踏入晋升快车道的最佳手段，所以，不能给你这样一个机会。至于下面的老百姓是不是高兴，这个不重要，关键是不让他争取领导高兴，领导的高兴不高兴才是大事。

# 三、上述材料给我们什么启示

1、要学会利益均沾。你自己成功了，如果你不考虑别人的感受，想把所有的功劳都揽到自己怀里，那么你就会发现，很多人都在给你设绊子，职场就是“贪独功，则无功。”

2、要远离失败的人。失败的人，能够远离尽量的远离。这个和很多人的价值观不相符合，同情弱者，觉得我们应该帮助，其实相信或帮助这类人，会让你沦为一样的人，永远和成功者在一起。

3、看重事后的格局。权谋家对事情的思考都不局限于当下的对错或是好坏，都是着眼于未来事件的发展，提前动手，而很多小人，也都擅长这个，在萌芽下解决未来的问题。

经过权谋网上述的分析，能够看出来，我们其实无法避免职场上身边出现这样的人，即使我们自己不这样做，我们也要学习这些人的手段，为己所用，想要在职场胜出，你只能熟悉小人手段，然后做的更狠，小人才不敢继续算计你。手段没有对错，如果弃之不用，有时恰恰自缚手脚，难有大成就！

# 权谋家上位的标准范本

【出处】《资治通鉴》第254卷 唐纪 七十

【原文】武宁节度使支详遣牙将时濬、陈瑶将兵五千入关，讨黄巢，二人皆详所奖拔也。濬至东都，矫称详命，召师还与瑶合兵，屠河阴，掠郑州而东。及彭城，详迎劳，犒赏甚厚。濬遣亲亲说详曰："众心见迫，请公解印以相授。"详不能制，出居大彭馆，濬自留守务。瑶谓濬曰："支仆射有惠于徐人，不杀，必成后悔。"濬不许，送详归朝。瑶伏甲于七里亭，并其家属杀之。诏以濬为武宁留后。濬表瑶为宿州刺史，瑶到官贪虐，濬以都张友代还，杀之。

【译文】唐，武宁节度使支详派遣牙将时濬、陈瑶率领军队五千人进入关中讨伐黄巢，二人均为支详所奖励提拔的将领。时濬来到东都，假称支详的命令，将军队召还与陈瑶合兵一处，在河阴大肆屠杀，劫掠郑州后向东走。回到彭城，支详出来迎接慰劳，犒赏丰厚。时濬派亲信对支详说：“受兵众的拥戴被迫充当军府总统领，请你解下节度使的大印授予时濬。”支详不能制止，只好搬出军府居在大彭馆。时濬于是自掌武宁军留后事务。陈瑶对时濬说：“支仆射对徐州人有恩惠，不杀他，一定会后悔的。”时濬没有同意，将支详送回朝廷。陈瑶在七里亭埋伏甲兵，杀支详及其家属。唐僖宗颁下诏书，任命时濬为武宁军留后。时濬上表请任陈为宿州刺史，陈瑶到官后贪鄙暴虐，于是时濬另派都将张友替代陈瑶，陈瑶回到徐州后被时濬杀死。

【解析】一个权谋家，经过长时间的隐忍、表忠、结党，最终获取领导的信任，得到了一定的资源，这时候，完成了初级阶段后，就需要完成翻身上位的工作。而时濬一个完美的上位程序，堪称范本级的操作，我们仔细阅读后，叹为观止。

# 一、造反上位术的条件

1、获取上级的信任。

为什么我们学习权谋首先研究韬晦术，原因就是，还弱小的时候，一定要低调隐忍，表现的自己很听话，有能力，忠诚没有任何野心。伪装自己做一个领导眼里的乖乖狗，只有这样，才能够获取领导的信任，没有领导的信任，就没有获取资源倾斜的机会。时濬做到了这样的伪装，才能够一成为心腹牙将。

2、获取上级的资源。

成为了心腹，进入了领导的视野和小圈子，这才会有获取领导资源的机会。任何的危机都是心腹攫取资源的机会，没有危机，就不会打破现有的利益格局，就不会让领导释放资源，所以，要善于利用好每次危机让自己挺身而出，时濬就是利用了黄巢造反的这个机会，获取了属于自己的队伍。

3、支配资源的自由。

有信任才能够得到资源，但是只有自由掌握了资源才能够获得造反的条件。时溥是利用把队伍拉到半途中，从地域上，监控上摆脱了支详的控制，对资源有了最后的裁决权，这时候，也就具备了造反的可能性。所有的权谋家，想造反上位就必须获取资源的控制，有了这些，就有了造反的力量。

# 二、造反上位术的过程

## 1、假令

造反上位，如果直接宣布是自己的想法，很多人会被认为是裹挟，不会顺利的追随。但是如果利用信息的封闭，假借命令，就能让很多人，不知不觉间听从指挥，从而跟随自己。兵法一直讲，不能让他知道为什么，听命令就行了。这是第一步，能不能站住脚，就看这个假命令的合理性。

## 2、合兵

时溥第二步就把能够制衡自己的陈蕃的力量拉拢了过来，组建了统一战线。无论是不是心甘情愿，这个招数是极为正确，因为如果自己不能联合到大数的力量，那么自己胜算就会极低，这个工作应该是时溥很早就开始展开，把所有可能的阻力，都提前化解掉。

## 3、虏掠

两支部队顺利的会师，合并一处，这时候就开始虏掠。这一个动作看似残暴，但是这个步骤必须做，不能缺少。原因有三个，首先解决了自己的后勤问题，这是带领一批人造反的命门问题；其次两支队伍进行了融合，不再是独立的两支队伍；第三是士兵参与了虏掠，有了好处，士气上涨。

# 三、造反上位的善后

## 1、逼退旧主

造反已经手握重兵，实力强大了，这时候就要解决自己老大的问题，没有采用开打，而是采用逼迫的办法。“众心见迫”用大家逼得，不是我的原因。犹如后世的黄袍加身，自己被迫的，没办法。让支详自己交出了权力，算是一场和平的交接。

## 2、合法安民

时溥用支详的印信正规途径上表，让自己获取了国家的正式任命，这对整个徐州地区的人民也算是有了个交代。时溥尽管是用重兵获取了权力，但是却没有用武力解决问题，而是采用了政治手法，来处理问题，这是一个权谋家成熟的表现。很多人迷信武力，看似短平快，实际后患无穷。

## 3、除去同伙

当支详交出权力的一瞬间，其实时溥和陈蕃的合伙关系就已经走到了尽头，权力是不允许分享的。两个人就已经是敌对关系了，所以，时溥想揽权，就必须除掉陈蕃，于是采用了螳螂捕蝉黄雀在后的计谋，借助陈蕃在七里亭伏击支详的时候，时溥也就利用陈蕃脱离

自己队伍的机会，直接回途中，伏击软禁了陈蕃。之后找了个贪污暴虐的借口合理的杀掉了，和平的解决了同伙。

在七里亭是有深意的，首先是让支详脱离了自己辖区，时溥没有管理责任；第二在老百姓眼里支详合理的消失了；第三让陈蕃也短暂的被调虎离山，脱离了自己的队伍，便于下手。走的再远一点控制度就下降了，而陈蕃也不会就带一小部分人出行。当陈蕃伏击除掉支详的同时，他自己也被时溥伏击。

# 四、造反上位术给我们的教训

1、防止部下从狗变成恶狼

支详的两个心腹牙将，集体造反。敌人没打，反而挥师返回，支详没有了武力防御，只能用物质收买，采用缓兵之计。但是时溥和陈蕃不是见钱眼开的小格局的人，要的就是权力。支详，因为信任，放弃了控制和反制的能力，让自己养的狗变成了白眼狼。所以什么时候，都不能丧失反制能力。

2、阶段变了就看谁出刀快

陈蕃的权谋相不时溥差了几个等级。合作关系，随着外部矛盾的终结，必然走向决裂。这时候，谁首先认识到阶段的转变，谁出刀快，谁就占有优势。而就在陈蕃伏击支详的瞬间，其实他和时溥就已经势不两立。此时不下手，后期时溥会花费大的成本来除掉陈蕃。选择回来路上伏击，才是最给力的。

3、造反黑活不能自己下手

作为权谋家尽管自己已经到了无恶无耻的境界，但是公众的舆论还是要顾是的，还是要考虑政治影响的，必须让自己站在道德制高点。黑活什么的必须由别人来做，圣人之道阴，高手都是在幕后操纵。所以尽管时溥内心早就想除掉支详，但是自己却不说，让别人来做。

# 五、这对我们职场有什么启示

1、权谋家身上没有情感束缚

很多朋友都会说，时溥面对对自己有提拔之恩的老领导，为什么这么狠心，难道就毫无感恩之心么，非要夺权后杀掉么？其实《小人经》说的好“小人行怀不感恩，达则背主。”小人是不会让情感来束缚自己的，只有这样 的人，才能够保持决策的足够理性。

2、准确捏握矛盾的阶变化

一个一起造反闹革命的战友，转眼间，就成了你死我活的敌人，很多人无法接受这一点。但是《小人经》写道“物异而情易矣”，事情变了，手法也要变。具体问题具体分析，如果固守原有的老思想，自己就会看不清形势的变化，而被人背后插了刀子。

3、除掉对手要用大众化借口

# 顺坡下驴的中国式智慧

【原文】凤翔行军司马李昌言将本军屯兴平。时凤翔仓库虚竭，犒赏稍薄，粮馈不继，昌言知府中兵少，因激怒其众，冬，十月，引军还袭府城。郑畋登城与士卒言，其众皆下马罗拜曰：“相公诚无负我曹。”畋曰：“行军苟能戢兵爱人，为国灭贼，亦可以顺守矣。”乃以留务委之。即日西建行在。

【译文】唐凤翔行军司马李昌言率本部军队屯驻兴平。当时凤翔仓库已尽虚竭，给军士的犒赏较之先前稀少，且粮不运继，李昌言知道凤翔节度使府兵员很少，故意以粮饷减少激怒其部下士兵。冬季，十月，李昌言率领其本部军队回凤翔，袭击军府。凤翔节度使郑畋登上城楼向城下的士卒喊话，士兵们都下马向郑畋下拜，说：“郑相公确实没有背弃我们。”郑畋说：“行军司马李昌言如果能聚集军队爱护人民，为国家讨灭盗贼，虽夺得节度使旄旗，也可以说是顺守。”于是委李昌言为凤翔留后职务，自己立即出发西赴成都行宫。

## 2、内外交困

每个优秀的人，在组织危机的阶段，都会面临内外交困的状态。一来，既然是危机，就是外部的困难极大，失败了，自己会被追究责任；二来，如果你打赢了，内部小人又会恐惧你立功，不断地中伤你，掣肘你，指责你有野心等。郑畋面临的就是外部有黄巢大军，内部是田令孜小人掌权。

## 3、保功远过

一个人在职场，必须展示自己的价值，没有自己的价值，就没有组织地位。但是如果功劳太大，就会物极必反，让其他人不舒服。所以，职场的高手都是在展示价值，和远离贪功以及可能的失败之间寻找平衡。郑畋已经抵抗了黄巢一个阶段了，有巨大功劳，接下来可能失败，需要见好就收。
