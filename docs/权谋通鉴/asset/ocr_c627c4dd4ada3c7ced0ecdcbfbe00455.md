他乘用。又派小司马，唐道和去北齐的中书侍郎李德林的住处宣读圣旨加以慰问，说：“讨平齐国后得到的利益，就在于得到你。”带李德林进宫，派内史宇文昂向他请教北齐的风俗政教，人物的善恶。留他在门下省，住了三个晚上才让他回家。

【解析】随着北周国主顺利的攻克了北齐的首都邺城，北齐也就亡国了。军事占领之后，如何在政治上快速站稳脚跟，是北周国主必须面临的首要任务。于是北周国主进行了稳定人心的三大政治表演：

+   1、亲善姿态： 稳定儒生

北周国主“重道尊儒”的政治形象宣传是很到位的，北周国主，进入北齐首都后，立即去拜访了，国子博士熊安生，而且给了熊安生极高政治地位和待遇。这个首先拜访最高教育机构的总长，目的就是安抚知识分子，能够更大程度的稳定知识分子的阶层。北周国主表达自己不是暴力征服，而是重视文教。

+   2、合作姿态： 稳定官员

通过正式的手续，去李德林家里宣读圣旨慰问。并且说出了千古名言“平齐之利，唯在于尔。”我征服齐国得到的最大的好处，不是国土，不是资产，不是美女，而是你李德林这个人才。这对官僚阶层也是一个重大的信号，新政权并不准备踢掉所有的官员，而是进入新的合作状态。

+   3、顺从姿态： 稳定风俗

稳定了中高层之后，就要稳定基层老百姓了。对于这类人，其实谁当官都一样，关键是不打扰他们日常的生活，稳定大家的风俗习惯不变，就不会有问题。于是请李德林直接进宫，让宇文昂直接讨教。北周国主没有直接去拜访李德林，见他和熊安生的待遇为什么不一样呢？原因就是官场讲究阶层秩序。

北周国主上述的稳定人心的三大政治表演，用个人的姿态，表明了好文重教，为最有能量的中产阶级，做出了亲善姿态；然后公开颁布圣旨，拉拢官僚阶层，做出了合作姿态；最后三天三夜详细询问国家的风俗，表达了顺从的姿态。并没有强制推行自己的风俗管理百姓。这个顺序也很重要，首秀送给熊安生，也是表明自己的不功利化，还能树立政治形象；然后用正式的文件，表达爱惜人才，拉拢实力派，给他们定心丸；最后推及到最广大的老百姓。征服后的这些表演秀，直接就稳定了被征服的北齐。
