这就是为了控制他们这些核心人员出现状况。危机应对，第二步就是立即加强核心人员的控制。

+   3、控制核心资源护命门

封闭消息，控制核心人员，之后，就需要立即看守自己的核心资源，刘氏没有选择硬碰硬，而是，立即谋划“保军以还”保全自己的队伍，回到自己的地盘，这样自己就能够有本钱，以后还有机会报仇。在别人地盘，不立即摆脱危地，就可能有更大的损失。危机应对第三步，在危机中保护命门。

# 三、危机应对术对我们的职场有什么启示呢？

+   1、保持镇定

泰山崩于前而色不变，麋鹿兴于左而目不瞬。任何时候，作为最高领导都不能乱，只有自己镇定，军心才会定，任何的消息都会成指数级的扩张，而且都会走向反面，所以控制信息，控制情绪，这就需要极高的心里素质，只要主心骨在，大家都能看到成竹在胸，就不会恐惧。

+   2、控制内部

堡垒都是从内部攻破的，外部的危机，再可怕不会致命，最致命的就是内部的人员利用外部的混乱，捣破坏，捣捣鬼，所以，出现危机的时候，控制内部稳定，是第一要义。把内部人的野心给镇压住，不会出现雪上加霜的局面，可以全心应对外部，而不需要担心内忧外患，腹背受敌。

+   3、保护命门

危机出现，就怕的是祸不单行，一定要首先看守住自己的命门，让损失降低到最小。因为危机无论来自何处，我们都要知道先让自己处于不败之地。然后再谋求翻身，如果不护住命门，那么以后东山再起的本钱都没有，图一时之快，失未来之机。

经过权谋网对善用计谋的刘氏应对危机的手法进行分析，大家能够看到，危机最大的敌人，不是危机本身，而是在不明状态下，稳定内部关系是第一要义。很多人偏离了这个内部关系，而着眼于外部，这是极为错误的，内部稳定了，就不会腹背受敌，就能够找到机会最大的保全。
