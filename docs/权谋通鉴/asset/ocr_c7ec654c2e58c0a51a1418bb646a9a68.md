# 贬低对手也是分阶段的

【出处】《资治通鉴》第 81 卷 晋纪 3

【原文】帝从容问散骑常侍薛莹孙皓所以亡，对曰：“皓昵近小人，刑罚滋滥，大臣诸将，人不自保，此其所以亡也。”它日，又问吾彦，对曰：“吴主英俊，宰辅贤明。”帝笑曰：“若是，何故亡？”彦曰：“天禄永终，历数有属，故为陛下禽耳。”帝善之。

【译文】晋武帝私下询问散骑常侍薛莹，孙皓为什么会亡国。薛莹回答说：“孙皓亲近小人，任意地施行刑罚，大臣和各位将领，人人都不能自保，这就是孙皓灭亡的原因。”又一天，晋武帝用同样的问题问吾彦，吾彦回答说：“吴君王才智出众，辅佐的大臣贤能聪明。”晋武帝笑着说：“要是这样，为什么会亡国？”吾彦说：“天赐的福禄是永久的，天命有新的归属，所以才被陛下所擒。”晋武帝赞赏他的话。

【解析】我们小时候上学时，都学习过《水浒传》里鲁智深三拳打死镇关西这篇文章。这篇文章很有意思，就是鲁智深打镇关西的时候，骂他，“你是个卖肉的操刀屠户，狗一般的人，也叫做镇关西？”等以后行走江湖的时候，却到处说，我三拳打死了镇关西。一开始不承认，后期却到处说人家是镇关西。为什么呢？其实原因很简单。阶段变了，对手收拾后，对手能力越强，自己也就越牛。熟悉了这段，我们再分析上述的这段资治通鉴的内容，就很容易的能够猜透晋武帝的帝王心思了。

1、晋武帝问孙浩为什么会亡国，目的是想如何？

我们普通人回答领导的问题，都是一根筋，问什么就按照理解回答什么，其实作为权谋高手，在回答问题之前，都会比普通人多个程序，那就是先考虑“领导问这个问题的目的是什么”只有知道了，领导问这个问题的目的，你才能回答出正确的问题。晋武帝不是在询问孙浩的失败原因，他想通过对对手的定义来展示自己的成功。所以，薛莹回答的真实的原因，皇帝并不高兴，没有猜对心思。而吾彦猜对了，孙浩非常有实力，不过天命不是他的，你才是真命天子。这个马屁拍的曲径通幽，领导很满意。

2、评价对手其实是需要分阶段的，不同的阶段目的不同。

如果对手还存在，这时候就不能给他什么高的评价，那样的话，会长他人志气灭自己威风。要极尽抹黑之能事，如此才能提高我方内部的信心和瓦解对手。但是如果对手已经被我们打败了，这时候，就不能继续这么干了，就要对敌人做很高的评价。原因有两个，一个是，展示自己胸怀。另外一个就是，对手实力强大，才能显示出来自己的能力。评价不会是一成不变的，而是不同的阶段，有不同的妙处，其目的都是为自己所用。

3、很多人会说，这么复杂，我们如果短时间猜不出领导心思怎么办？

其实你如果不学权术，你很难在短时间之内找到相应的答案，没有准备的事情就很难做到完美。但是也不是没有办法，我们在回答问题又猜不透领导心思的时候，就要把拍马屁放
