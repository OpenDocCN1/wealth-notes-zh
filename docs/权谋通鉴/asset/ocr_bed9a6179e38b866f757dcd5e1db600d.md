# 一、面对皇帝被杀，马仙琨的政治选择难题

# 1、马仙琨能投降么？

投降是讲究时机的。如果在局势不明朗的时候投降，或是在对手最困难的时候投降，会得到极大的待遇。三国时代贾诩带领张绣在官渡之战的关键时候投降了曹操，曹操丧子之痛都忘了。但是如果你投降在局势明朗的阶段，可以说，在敌人眼里一毛不值留条命都已经是宽大了。而此时马仙琨就是在皇帝已死，本身能力也无力反抗挣扎多久的阶段。如果此时投降，也会被人看不起。

# 2、马仙琨不投降行么？

皇帝都不在了，你坚持下去，除了身死家灭之外，什么好处都没有，每个权谋家的行为都是经过精确计算的，不投降这样的愚忠，绝对不是这类聪明人想做的。所以不投降绝对不能做，这样毫无意义的抵抗没有任何意义。三国时代，关羽水淹七军，庞德誓死不降，被杀，被曹操列为功臣，而于禁投降被羞辱，原因是因为，背后的主人还在。马仙琨不投降，背后没有主人支持，所以投不会有道德问题。

马仙琨不是萧衍的嫡系，而且，之前也没有提前做投资，所以，无论是感情牌还是站队牌都没有可打的。但是萧衍即将称帝，马仙琨作为旧朝老臣，如何能在新朝站住脚，唯一的就是打忠诚牌。自己如何做才能展示尽忠诚旧主，又能讨好新主，这是个难题。不过马仙琨的政治表演极为到位，成功的破解了这样的难题。
