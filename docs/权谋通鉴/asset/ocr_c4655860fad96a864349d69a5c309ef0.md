己的亲妹妹出卖了自己。妹妹并不认为自己的幸福在利益之上，炽磐死了，她也就成了寡妇。但是如果告密，除掉王后，左夫人自己就能顶替上位。左右选择，还是选择了出卖自己的亲人，一场内部的政变又宣告失败。因为自己的亲人出卖而失败，秃台的外部谋划，和内部政变都失败。

# 二、外部的战争谋划和内部的政变谋划，都失败在告密。

# 1、外部的阴谋被手下人出卖。

想策划一场外部的阴谋，就必须和自己手下人商量安排，这时候，就要让自己的亲信，参加谋划。但是，这个外部阴谋的风险极大。这些亲信如果没有被断了后路，或是更高的诱饵让 其不计生死，这些人，都会在最关键的时候因为自己的利益而变节。没有人愿意，平稳的生活不过，去选择一个几乎必死的阴谋。所以，在策划外部阴谋的时候，不要给这些人背叛的时间和机会，立即行动，裹挟他们。手下人的出卖，会让他们阻止战争，自己又因为告密而拥有了重新站队的机会。

# 2、内部的阴谋被最亲人出卖。

想策划一场内部的阴谋，就必须和自己亲人联系，这时候，参加的人，敌对的人，彼此关系都千丝万缕，你不能确信谁能够变节，告密。你能做的就是尽可能的让最少的人知道真相，知道真相的都是能够获得巨大利益的。如果自己人在事变后，会可能伤害到其个人利益，那么这人就可能变。有人会问，都是死丈夫，为什么秃发王后就不怕，而妹妹左夫人就怕呢。因为炽磐死后，王后成了太后，有了实权，而妹妹却要沦为寡妇，无所依靠。

# 三、阴谋和背叛对我们当下职场的启示

# 1、要考虑到风险收益的比重。

所谓的忠诚就是背叛的筹码不够。阴谋的风险极大，相当于以卵击石的方案，手下人，收益极小，这时候，很难阻止他们不会趋利避害。所以，策划一个外部阴谋的参与人，一定要断了他们的后路，直接的捆绑在一起，让他们无法背叛。

职场中你想让一个人给你冒险，用利益的方法很难奏效，只有裹挟的方法最为合适。

# 2、要考虑到事后利益的变动。

不仅仅是考虑到现在的利益，而且要考虑到，阴谋之后的利益格局，即使现在对他有好处，但是阴谋之后的收益变少了，你也没法控制她不在关键时候背叛。所以，策划一个内部阴谋的时候，一定要给她很大的未来利益承诺或是保证。

职场中你想在公司内部搞点小动作，这时候，感情再深也没用，只有许诺极高的未来利益才行。

经过权谋网的分析，我们能够看出来，如果我们想策划一场阴谋，对外部的信任的人来说，裹挟能够保证不出卖，最内部的亲人来说，利益承诺最重要。如果不了解这个背叛的基本权谋原理，那么，阴谋中不被背叛是很难的。
