# 杀人立威的三种权术策略

《资治通鉴》唐纪十七卷：

【原文】欲以其婿京兆杜怀恭偕行，以求勋效。怀恭辞以贫，贿之；复辞以无奴马，又贿之。怀恭辞穷，乃亡匿岐阳山中，谓人曰：“公欲以我立法耳。”闻之，流涕曰：“杜郎疏放，此或有之。”乃止。

【译文】李勣让他女婿京兆人杜怀恭同行，以便建立勋勤。杜怀恭以家贫为理由推辞，李世答应供给他；又以无奴仆马匹为理由推辞，李世又答应供给他。杜怀恭无话可说，便躲进岐阳山中，对人说：“李公想把我作为施法的靶子。”李世听说后，流泪说：“杜郎散漫不知拘束，这是有可能的。”便没有再要求他同行。

【解析】将军出征，第一件事情，就是肃整军纪，建立君威。在历史上，无非就是杀人立威，但是杀人是技术活。杀人，重要的是杀亲，杀贵，杀首。

杀亲：孙子训练一群宫女，没人听话，杀了带队的两个大王的爱妃，下面的人立即听话了。关系最好的人，都杀了，其余的人也就没有了幻想。

杀贵：司马鞭苴，杀掉皇帝的亲贵监军，庄贾，这是借口他违反军纪，杀掉最高的权力的人。最大的官都杀了，谁还不担心自己呢，基层的人都能感受到了压力。

杀首：也就是杀头一个犯错的人，如果第一个就放过了，后面也就没有在乎纪律了。曾国藩，就是在第一次战斗失败后，杀掉了，不救罗泽南的金松龄。金松龄第一个人触犯军令，尽管很多人求情，但是还是杀掉了。

所以，站在一个将军的角度，立军威表面是大家都不听话的被动的举动，是对纪律的严肃性的尊重和支持。实际上，很多时候，都是有意为之，或者说都是在开始就在安排这样一个可以杀的人。

如果说杀人立威，这是法律是纪律，但是一开始就准备要杀掉的人这就是权术。

我们看上述《资治通鉴》，杜怀恭和李勣这一对翁婿对立威的认识。

1、我们先看李勣的角度想。

表面上就是说，让自己的女婿参加军队，准备打仗，给其机会立功。其实真的是包藏祸心的，首先，从杜怀恭要东西可以看出，李勣平时对自己的女婿是不好的。如果好，还会要这个东西；其次，是要什么给什么，为什么就这么顺畅，目的就会让人担心，因为如果说参军能够得到高官，那么给这些干嘛，去了直接啥都有了，而提前给这些，恰恰说明，有问题；最后就是当女婿逃跑，说出就是准备拿自己人开刀的话之后，李勣不再逼着出征了，问题就是，为什么李勣不再要他去，证明自己不是为了立威呢，自己不去证明却放过他，根本的原因，就是杜怀恭识破了之后，再用他立威，也就失去了意义。
