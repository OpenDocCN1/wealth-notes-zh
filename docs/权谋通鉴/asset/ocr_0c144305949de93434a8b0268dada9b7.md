# 如何应对领导发脾气做的错误决定

【出处】《资治通鉴》第194卷 唐纪10

【原文】上或以非罪怒宫人，后亦阳极，请自推鞠，因命囚系，俾为申理，由是宫室之中，刑无枉滥。

【译文】皇上又一次因李迁怒到一个没有过失的宫人身上（要治他的罪），长孙皇后也假装（对这个宫人）发怒，请求皇上让她自己来申理宫人，得到皇帝许可后命人把这个宫人先关起来，等到皇上的怒气消退了，然后慢慢地向皇上陈述道理。因此内宫里边，没有冤案和滥用刑罚的事。

【解析】人都是有情绪的，再理性的人都有发脾气的时候。领导在情绪的状态下做出非理性的错误行为，也是常见的职场状况。作为领导身边的副手，如何应对这种局面，长孙皇后对李世民的这个手段，对我们很有启迪意义。

一、长孙皇后面对的难题是什么

+   1、李世民发火的时候，情绪激动，任何的对抗行为，都会激化矛盾。不能在发火的时候进谏，阻止李世民的错误决定。

+   2、如何保护没有犯错的宫女，不能让领导的错误决策，再直接犯下执行错误，让局面滑向更差的局面，以后不可收拾。

+   3、如何不当及领导的权力尊严，又能够保护无辜宫女，还能让自己不牵扯其中或是被认为是冷漠的观望，双方平衡和保护自己的利益不影响，这都是核心难题。

二、长孙皇后采用了三步策略

+   1、首先和领导的情绪调到了一个频道。

任何人发火的时候，对抗都会激化矛盾，只有和他情绪调到一个频道，才能够最大程度的缓解对方的情绪。只有在一个情绪频道了，而不是对抗拆解，才有可能解决问题。

+   2、其次立即请求执行领导的这个命令。

这是核心点，长孙皇后立即请求让她来亲自处理这个宫女，这就是控制了事态的发展。把未来发展的节奏掌握在了自己手里，如果换人来执行，就会失控。

+   3、最后就是等领导冷静后慢慢地解释。

当领导自己冷静之后，这时候回归理智，换个环境，就能够心平气和的解决问题，通过缓兵之计，徐徐图之，这时候能够通过执行层而纠正错误。

三、这个以柔克刚的办事手腕，对我们有什么启示呢？

+   1、任何时候都不要对抗对方的情绪。

一个人在情绪的状态下，都不会听进去对方的意见，所以，无论对错，除了顺从之外都不要有任何的动作，否则就是火上浇油。
