【权术解析】熟悉三国历史的朋友，都会对曹操赤壁之战失败后，哭奉孝的这一段，记忆犹新。《三国志》中《魏书·程郭董刘蒋刘传》原文是这样写到：“后太祖征荆州还，于巴丘遇疾疫，烧船，叹曰：“郭奉孝在，不使孤至此。”

现在我们再回头看看资治通鉴这段材料里，唐太宗李世民的这句话 “魏微若在，不使我有是行也！”

李世民和曹操都在失败后，做了同样的动作 “叹” 然后说了同样的话 “若 XX 在，不会让我如此！”

表面上看，这是在失败的时候怀念了人才。其实这段话，本质上是领导自己面对失败后的标准动作，这样能够缓解自己的错误带来的权威丧失。

# 一、领导人作出决策失败后，该如何缓解尴尬，让自己权威不至于丧失？作为领导可能有三种办法。

# 1、罪己诏。

作为一个领导人，力排众议，做了一项重大决策，然而，这个决策却在执行中，给组织带来了巨大的损失，这时候，出现了错误，很多正直的领导，都会公开做个检讨，独立承担自己的错误。表面上，虚怀若谷，能够承认错误，其实这是有损于威望的。这个事情，以后随时会被人拿出来说事。

# 2、推过错。

并不是所有的领导都会抛开面子而承认错误的。大多数人，都是会选择推卸责任，把失败的责任，推给前方执行不力的将领。让责任有具体的执行人来承担，这样的好处就是自己把责任推得一干二净，但是后遗症就是，你伤了自己部下的心，别人即使口头不说，但是内心也是对领导不满的。

# 3、怀旧人。

如何在不损失自己威望，又能够不推责于将领，且这个失败的责任还能找个台阶下，这个难题需要多角度的平衡。曹操和李世民，作为权谋大师采用了同样的办法，如果当初有人劝谏我，就不会出现现在的失败了，然后对死去的这个人一番的怀念，失败的责任推给了一个提前死的人。

# 二、采用怀念旧人推卸责任这个权术，需要三个步骤

# 1、找到一个有威望死去的人

魏征在历史上就是以劝谏而出名的，如果我们只局限在魏征身上就看不出这个奥妙了，因为，三国里郭嘉，郭奉孝并不是劝谏出名的，而是谋士。这就说明，这个人是什么职位并不重要，重要的是，他的影响力足以承担这个责任。
