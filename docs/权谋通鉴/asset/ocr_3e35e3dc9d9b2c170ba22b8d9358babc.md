# 鼓励互斗，但是不能打破平衡

【出处】《资治通鉴》第 201 卷 唐纪 17

【原文】吐蕃与吐谷浑互相攻，各遣使上表论曲直，更来求援：上皆不许。吐谷浑之臣索和贵有罪，逃逸吐蕃，具言吐谷浑虚实。吐蕃发兵击吐谷浑，大破之，吐谷浑可汗笱钵与弘化公主帅数千帐弃国走依凉州，请徙居内地。上以凉州都督邢仁泰为青海道行军大总管，弘化公主帅数千帐弃国走依凉州，请徙居内地。上以凉州都督邢仁泰为青海道行军大总管，弘化公主帅数千帐弃国走依凉州，请徙居内地。上以左武卫大将军苏定方为安集大使，节度诸军，为吐谷浑之援。吐蕃禄东赞电青海，遣使者论仲琮入见，表陈吐谷浑之罪，且请和亲。上不许。遣左卫郎将刘文祥使于吐蕃，降玺书责让之。

【译文】吐蕃与吐谷浑互相进攻，各派遣使者到唐朝上书辩论是非，轮番向唐朝求援；唐高宗都没有同意。吐谷浑大臣索和贵犯了罪，逃奔吐蕃，详尽地报告了吐谷浑的情况。吐蕃于是发兵进攻吐谷浑，吐谷浑被打得大败，可汗笱钵与弘化公主率领数千帐离开国家，投奔唐朝凉州，请求移居唐朝内地。唐高宗任命凉州都督邢仁泰为青海道行军大总管，率领右武卫将军独孤卿云、辛文陵等分别屯兵于凉、鄯二州，以防备吐蕃。六月，戊申（二十六日），又任命左武卫大将军苏定方为安集大使，调度约束诸军，作为吐谷浑的后援。吐蕃禄东赞屯兵青海，派遣使者论仲琮到唐朝朝见唐高宗，上表陈述吐谷浑的罪恶，而且请求与唐朝和亲。唐高宗不允许，派遣左卫郎将刘文祥出使吐蕃，颁用皇帝的印章封记的文书责备吐蕃。

【解析】如果把这段看过三个国家之间的交往，你会看不出什么门道。但是如果你把吐蕃和吐谷浑堪称两个有实力的部门经理，把皇帝看成公司老板，这个案例就简单多了，也就成了职场最常见的情景。

一、我们做下职场情景还原：

经理 A 和经理 B 两个人一直在职场斗来斗去，互相揭发对方的违规吃回扣的行为，唐老板，似乎对此很不乐意。有一天，B 经理的一个下属，把一份揭发 B 的社会上违法的证据黑材料，送到了 A 经理这里。这样，A 经理通过社会上的关系，直接让 B 进拘留所待了几天。A 觉得，既然领导不管，我就自己解决，这下子能让 B 直接辞职走人了，自己似乎赢了一局。但是到了公司忽然发现，唐老板，对 A 忽然间发了怒火，拍桌子。A 直接就蒙了，平时斗你不管，为什么这个时候你不管 B，却对我发火。B 的违法材料在这里，唐老板几乎没看，直接撕碎扔进了垃圾箱，找了个借口，就给了 A 一个处分。A 就想知道，唐老板是怎么想的？为什么如此反常行为？
