到的活路。让大家自己选，刺激需求之后，让众人自己找答案。唯一的答案，那就是造反。

2、谁来办？
既然要造反，这就要引导，谁来领导这个造反的队伍。高欢道：“造反乃迫不得已之计，但应推举一人为首领，谁能担当呢？”众人共推高欢为首领。高欢没有自己说要当首领，让大家自己说，自己被动接受，这样才会显得自己承接了民意，是被动接受的，是你们选的我。

3、如何办？
欢曰：“尔乡里难制。不见葛荣乎；虽有百万之众，曾无法度，终自败灭。今以吾为主，当与前异，毋得陵汉人，犯军令，生死任吾则 可；不然，不能为天下笑。”众皆顿颡曰：“死生唯命！”既然你们选择我，那就要听我的，于是乎，本来是高欢要造反，现在成了大家要造反，让高欢来领导。

# 三、关键要点

# 1、封闭信息

大家之所以被蒙蔽，最重要的原因是高欢伪造了两个文件，这样大家无法识别真相，完全的信息不对称的情况下，刺激出内心的绝望。几乎所有的权谋布局，就是尽可能的减少变量，让被控制的人完全失去耳目。一旦成为信息孤岛，就什么都好操作。

# 2、堵死退路

如何引导大家的需求呢，不是告诉他该做什么，而是堵死所有的可能的退路，扼杀掉所有的选项，让他自己去选我们给其留下的唯一道路。比如我们的推销，为他们的迫切需要，从被动到主动的过程。人都会是相信自己的选择，而不是被人强制灌输。

# 3、情绪刺激

众人的情绪如何被真的调动起来的呢，孙膑与尉景不断的请求延期，迟迟不肯走，然后在逃行的时候，这些人带头失声痛哭，立即就感染了这种悲凉的情绪，再通过高欢的情绪加强，“我们都是失去故乡的人，情谊如同一家”最终让大家做出了造反的决定，这是临门一脚。

高欢通过这一些列的表演和设计，原本是高欢主动的推销的事情，变成了大家迫切需要的。如何让马儿喝水呢？不是按下去强灌，而是喂它一把盐！先刺激需求，他们自己会主动寻 求满足，只要引导好，一切会按照我们设计的方向前进，知道这些也就悟透了推销的奥秘。
