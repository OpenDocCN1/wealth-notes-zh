# 2、不听权力的话必须被调离

# 3、让法大于权力的人搞监察

监察御史是八品，这件事情之后，唐高祖指示要把他提拔一级成为七品，表面上是鼓励了李衮立，其实是让他离开了执法者的位置，最终综合权衡，成为侍御史，也就是搞百官的监察工作，这个官要求能够严格执法，而且不怕得罪人，且不是有油水的衙门。这是这类人最好的归宿。

经过权谋网上述的分析，我们能够看出来，在普通领导眼里认为权大于法的才是人才，这样能够贯彻自己的意图。而在高级别的领导眼里，无论是权大于法还是法大于权，这两类人都是人才，关键是要放在合适的位置，所以，大众眼里的非此即彼的思想要剔除，组织中并不是单一价值观，而是如何有用如何来。
