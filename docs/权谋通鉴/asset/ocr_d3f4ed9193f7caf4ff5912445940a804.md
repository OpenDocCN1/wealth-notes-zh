# 做领导如何面对自己犯的错误——借坡下驴的智慧

【出处】《资治通鉴》第 91 卷 晋纪 13

【原文】张茂筑灵钧台，基高九仞。武陵阎曾夜叩府门呼曰：“武公道我来，言‘何故劳民筑台！’”有司以为妖，请杀之。茂曰：“吾倍劳民。曾称先君之命以规我，何谓妖乎！”乃为之罢役。

【译文】张茂修筑灵均台，台基高九仞。武陵人间曾夜间叩击张茂府门，大声呼叫说：“武公张轨派我来说：‘为什么扰劳百姓修筑此台！’主菅官员认为这是妖人，请求把闫曾处死。张茂说：“我的确使百姓辛劳，闫曾假称先君的意思来规劝我，怎能说是妖孽呢！”于是为此停止工役。

【解析】每个做领导的人，都不会保持完全正确，当出现重大决策失误的时候，涉及很多人利益的时候，如何停止这个错误，还不能产生前后不一致，落人口实，被人指责，有失威望，这就需要借坡下驴的智慧。

张茂修筑这个巨大建筑，一开始绝对是自认为各种条件都适合，但是随着时间的推移，外部条件的变化，或是自己主观认识的逐步清晰，再或者是矛盾的聚集，继续修建已经不再合适，如何下台，是个做领导的大课题。我们分析下这个巧妙的权谋手法：

+   1、领导自己不能主动终止这个项目。

一个组织最怕的就是朝令夕改，这会让下面的人无所适从，而且会极大的丧失领导自身的威信，没有任何的领导人会主动认错，如果不提前设置替罪羊，或是集体决策推卸责任的话，自己尽管认识到错误了，也不能主动去承担这个错误。这就需要有一个合适的第三方来提出终止。

+   2、提出终止这个项目的人要很特殊。

提出这个项目终止的人，不能是利益的相关方，而且这个人提出意见之后，他不应该是受益人，这是对提出终止项目的人的身份要求。因为如果是利益的相对方提出来，自己就改变了决策，这无形中也是彰显了自己的错误。如果对方获利，会影响到以后再有错误，会鼓励这样人的对抗意识。

+   3、自己通过原谅这个人而展示胸怀。

有了提出终止意见的人，在提的方法上，一定要采用一个错误的形式，武陵人间曾用了装神弄鬼的方式。这个错误方式很有妙处，这样，他不会因此获得威望，而且，张茂原谅他，展示胸怀，反而会弥补，自己错误的决策而带来的威望损失。威望这边损失，一定要从另一个地方找回来。
