# 帝心难测——是无情还是真爱

【出处】《资治通鉴》第 238 卷 后晋纪 4

【原文】唐主幼子景遏，母种氏有宠，齐王璟母宋皇后稀得进见。唐主如璟宫，遇璟亲调乐器；大怒，谪让者数日。种氏乘间言，景遏虽幼而慧，可以为嗣。唐主怒曰：“子有过，父训之，常事也。国家大计，女子何得预知！”即命嫁之。

【译文】南唐主的小儿子李景遏的母亲种氏受到南唐主的宠爱，而齐王李璟的母亲宋皇后很少有机会能得到进见。南唐主到李璟的宫中，碰上李璟在那里亲自调弄乐器，大为恼怒，责备了他好几天。种氏便借此机会进言，说李景遏虽然年幼，但很聪明，可以继承皇位。南唐主发怒说：“儿子有过失，父亲教训他，这是正常的事情。国家的大谋略，女人怎么能参谋过问！”就下令把种氏嫁出去了。

【解析】这段文字如果不细细品味，很难触摸到南唐主的内心。

首先会第一感觉就是，帝心难测，伴君如伴虎，昨天还有宠爱，今天就被踢出宫。其次是感觉到，南唐主的政治敏锐度，妇女不能干政，果断处置。最后就是感觉，皇帝向大众表明，自己批评李璟并不是要换太子，位置稳定，别人别借机离间。

一、但是如果仔细阅读原文，就会感觉，这里面有二大疑点

1、疑点一，既然是有宠，绝非一日的感情，就因为一句话就失宠？之前的恩爱都是镜花水月？人非草木孰能无情，这也不算是什么大的过错，不喜欢，直接外放就不行了？汉文帝的母亲薄姬不受宠，也是被刘邦放外，史有先例。

3、疑点二，这也是最大的一点，就是这个女人既然不喜欢，触犯了禁忌，打入冷宫即可，为什么让他立即嫁人，自己喜欢的女人，还有过温情，就这么赐给别人？男人的占有欲，这里失效？立即嫁人不需要物色人选？这么快看来是早有准备。

二、找到一个答案能够把所有的疑点解释完毕，这才是真相

1、这个真相，并不是南唐主不喜欢种氏这个女人，而是真的太喜欢她了。种氏的儿子年龄太小，即使上位，也无法在五代时期这种乱世生存。而能够把南唐江山继承下去的，还是需要年长的皇子。但是问题来了，既然不能够够做继任皇帝，母亲这么受宠，南唐主，自己死后，他们母子两个的命运可想而知。刘邦的宠姬戚夫人和儿子刘如意，在刘邦死后的悲惨命运就是前车之鉴。如何保全他们母子的命运，在自己身后让他们安全的生活，这才是南唐主要考虑的。于是找个借口，把种氏打下去，让大家知道失宠了，没有了威胁，而且还赶出宫，不让敏感身份，被皇后报复，宫廷里日后有意外。还有就是直接嫁人，找人保护起来，也不会有衣食之忧。如果不是皇帝的刻意安排，谁敢玩皇帝的女人？一个改嫁
