# 底层逆袭的三大权术步骤

【出处】《资治通鉴》第 267 卷 后梁纪 2

【原文】吴越王镠尝游府园，见园丁陆仁常树艺有智而志之；及苏州被围，使仁常通信入 城，果得报而返。镠以诸孙畜之，累迁两府军粮都监使，卒获其用。仁常，睦州人也。

【译文】吴越王钱镠曾经到府园游玩，看见园丁陆仁常种植花草树木有智谋，就记住了他； 等到苏州被围，让陆仁常送信到城里，果然得到答复就回来了。钱镠把陆仁常收作孙子教 养，屡次升到两府军粮都监使，终于派上用场。陆仁常是睦州人。

【解析】作为底层的人的逆袭，想突破自己的原有基层，真的相当的难，但是只是难而已， 从权术角度而言，只要做好三大步骤，是能够实现的。

1、进入领导视野

成功学有句话 说“想成功就和成功的人在一起”可是，人家成功的人为什么要和你在一起。 你凭什么？任何一个基层的人往上爬，都很难。找到属于你的贵人，然后通过各种手段接 近他，进入他的视野。历史上有的人通过养马进入领导视野的，有的通过做饭进入领导视 野的，有的通过弹琴进入领导视野的。而本文陆仁常是通过给领导做园丁，种植花草而进 入领导视野的。

想成功的捷径的第一步就是先接近，无论采用什么手段，接近贵人，这是一切可能的开始。

2、寻机展示才华

接近领导之后，就要不断地收集领导的个人爱好、生活习惯、工作风格、用人特点、当下 困难等，给领导建立起大数据，熟悉他的方方面面，然后让自己做针对性的自我价值提升， 这个提升包括业务方面、包括对人性的熟悉和自己口才等各种方面，然后要寻找一个适当 的机会展示自己的才华智慧，让领导对你有个深度的认识。为什么机会很重要，因为有其 他人在场，可能会给你阻力。

破格提拔会触动很多人的利益，所以一定要在展示的时候减少任何能够影响领导的人。

3、通过难题测试

被领导看重之后，是不是真的有才华，有能力，领导不会轻易的给基层人直接的提拔的， 必须通过测试，检验是不是真的具有能力。钱镠派陆仁常去完成送信任务，这样危险掉脑 袋的任务，一般人会谈条件，会推脱，这不是自己的本职工作，但是陆仁章毫无条件的完 成任务，这就让钱镠直接把他放在了自己的人才序列，之后逐步的培养提拔。

面对领导安排下来的非本质的困难任务，这其实是一个巨大的测试，只有通过测试，才会 完成逆袭。
