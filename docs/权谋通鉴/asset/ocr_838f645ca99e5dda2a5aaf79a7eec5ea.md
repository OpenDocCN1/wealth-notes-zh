# 收买人心的三大招数

【出处】《资治通鉴》288卷 后汉纪三

【原文】戊戌，郭威至大梁，入见，帝劳之，赐金帛、衣服、玉带、鞍马，辞曰：“臣受命期年，仅克一城，何功之有！且臣将兵在外，凡镇安京师、供亿所须、使兵食不乏，皆诸大臣居中者之力也，臣安敢独膺此赐！请遍赏之。”又议加方镇，辞曰：“杨位在臣上，未有茅土；且惟馗之臣，不可以弘㬭为比。”九月，壬寅，遍赐宰相、枢密、宣徽、三司、侍卫使九人，与威如一。帝欲特赏威，辞曰：“运筹建画，出于庙堂；发兵馈粮，资于藩镇；暴露战斗，在于将士；而功独归臣，臣何以堪之！”

【译文】戊戌（二十七日），郭威回到大梁，入朝拜见后汉隐帝，后汉隐帝慰劳他，赐给他金帛、衣服、玉带、鞍马。郭威推辞道：“臣接受命令一年，只攻克一座城，有什么功劳！而且我率领兵马在外，保卫、治理京城，供应军需物品、使军粮不缺，都是朝中众位大臣的力量，我怎么敢独自接受这些赏赐！请分赏给大家吧！”又建议加授他藩镇，他推辞道：“杨位置在我之上，尚且没有兼领藩镇之地；况且惟馗近臣不可以与史弘㬭相比。”九月，壬寅（初二），通赏宰相、枢密使、宣徽使、三司使、侍卫使九个人，与郭威一样。后汉隐帝想特别赏赐郭威，郭威推辞道：“作战的运筹策划，出于朝廷；发兵运粮，依靠藩镇；野外战斗，在于将士，而把功劳只归我，为臣的怎能受得了！”

【解析】收买人心，是每个想成就事业的人无不擅长的主要权术。郭威出征攻打李守贞前，权谋大师冯道曾经建议“守贞自谓旧将，为士卒所附，愿公勿爱官物，以赐士卒，则夺其侍矣。”意思就是说，要学会，用公家的钱来为自己施恩，建立威信，郭威理解了精髓。

郭威收买人心的招数，我们分析下：

一、郭威身为大将，胜利后三大招数收买人心。

+   1、不贪财务

收买后方人员。后方支持的是一大群人。郭威首先把自己的物质赏赐，分给了这些搞后勤的人。这些背后的无名英雄们，本来就是本质工作，没有什么功劳。这时候忽然得到了好处，自然心向郭威，认为这个人不错，能够体恤别人。

+   2、不贪官职

收买上级领导，近臣。自己被封大官，立即说杨位、史弘㬭的好处，一个是比自己高的官，一个是比自己亲的人。这就避免了自己被其他的势力和皇帝的亲信所陷害。给了别人尊重，从而避免背后进谗。他们也会认为郭威会来事，眼里还有别人。
