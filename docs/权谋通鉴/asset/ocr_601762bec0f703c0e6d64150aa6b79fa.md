# 领导对贪污视而不见的根本原因

职场上贪污这种丑陋的现象，被人深恶痛绝，很多人认为领导不知道，下面这些人 的小动作，其实作为领导对这种现象，洞若观火，不处理贪污，其实背后有更深的权 力心思。

《资治通鉴》第 157 卷，梁纪 13，记录了这样一段故事，深刻的反映了领 导的心思：

**【译文】** 行台郎中杜弼发现文武百官中的许多人在位时都贪污公家的财产， 就将这一情况告诉了丞相高欢，请他好好管一管。高欢说道：“杜弼你过来，我对你讲 吧！天下的官员贪污公家的财物，很久以前就已经成为一种习俗。眼下都督、将军们 的家属多数在西魏的关西地区，宇文黑獭经常对他们进行招抚和引诱，从他们的内心 来说，以后是离开还是留在这里都还确定不了；江东地区还有老头儿萧衍，他专门倡 导推行儒家礼乐，以致中原地区的士大夫们产生向往之情，认为他那里才是正统之所 在。假如我操之过急地整顿法制，不采取宽容态度的话，那么都督、将军们都得归 附宇文黑獭，士大夫们全去投奔萧衍，人材都失去了，还怎么成为一个国家呀？你最好 暂且等待一段时间，我不会忘掉你的提议的。”

**【解析】** 高欢之所以能够成为东魏的大权臣，为未来自己的北齐帝国打下基础，不是没有道理的，因为他对人性了解的纯熟，对贪污有着自己独到的见解：

+   1、天下贪污，习俗已久。

很多人对权力有个误解，就是认为最高权力，能够为所欲为，其实恰恰相反，最 高权力，要顾忌的方方面面的利益关系，而且有 时候，不能不为了长远的利益关 系对现有的不良现象忍让包容。这就是常言说的，水至清则无鱼。也就是说，任何一个 组织都不能完美的，大多带病生存，只要主流是好的，很多问题在发展中就会解决，如 果太较真一些个细节，恰恰忽视了大的发展。

眼里揉不进沙子的人，嫉恶如仇的人，几乎在社会上不会有成就，但凡有成就的 人，都是用人之长，容人之短，贪污捞钱，是很多人的短处，想干大事，重大节。

+   2、若正纲纪，人物流散。

一般人认为，一个优秀的组织必须有铁的纪律。其实没有人真的喜欢铁的纪律。尤 其是一个还是创业的组织，外面的各种诱惑极多，很多人，如果捞不到钱，还要受到很 强纪律的约束，这就会无形中在和人性做对抗，这就是逼着他们跳槽。很多组织失败， 就是因为，一开始就走正规化的道路，纪律条文一大堆，其实正规化是逐步完成的，随 着组织的稳定和发展完成的。

外围存在极强的竞争环境，单纯的靠理想纪律很难凝聚人心，开更多的工资，组 织创业初期，也不可能，只能泥沙俱下，只要不太过分，睁一只眼闭一只眼，让其各显 其能。

+   3、尔宜少待，吾不忘之。
