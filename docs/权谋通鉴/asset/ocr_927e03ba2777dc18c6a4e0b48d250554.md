# 三、仔细分析这段历史事件之后，我们得出相反结论的启示

1、我们不能只看当下是不是承受痛苦，而是要用发展的眼光看问题。权谋家的计算深度绝非普通人可比。他为了长远考虑，才让其宠姬承受当下痛苦，良苦用心，犹如父亲训斥打骂儿子，表面是让他当下不舒服，其实还为了他将来考虑。

2、任何反常的背后，其实都有更深的思维逻辑。南唐主，不仅仅是保护了自己心爱的女人，又树立了自己高大上不让女人干政的政治形象。尽管会被后世说自己翻脸无情，但是这种评价对帝王而言，毫无价值。秦始皇的爷爷安国君，宠爱的华阳夫人没有子嗣，不惜过继子碓为养子，保全华阳荣华。

经过上述权谋网的分析我们能够知道，受宠的女人在皇帝生前的幸福是一样的，万千宠爱于一身，但是皇帝死后，却各自命运不同，没有远虑必有近忧。当然汉朝赵飞燕没有子嗣，也是借助自身宠爱拥立汉哀帝，但是哀帝早死，且赵飞燕没除掉摄政王政君，最后不得不自杀。历史上唯一做的最好的就是南唐主的布局，无论身后何种政局，种氏都是幸福的，这才是男人最细腻的内心，最具权谋的表现。
