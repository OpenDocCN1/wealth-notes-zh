# 二、创业能够成功其实是看这三种密码

# 1、有凝聚力的团队

作为创业组织或者是一个团队，最最重要的就是有一群价值观一样的团队，只要有人，就能够不断地走向成功。看看哪个成功的团队不是有自己的几十杆枪在手，团队是做老大的第一密码。所以任何的企业家，无不把管理、价值观、企业文化放在第一位，失去了凝聚的团队，成功可能性就小很多。

# 2、所在市场的优势

有些团队组织尽管很烂，人浮于事，但是还是不死，就是处在一个垄断的，或是区域垄断的市场。有了垄断的市场，这个强大的优势，还是能够活下去的，这就是市场环境的优势。一个企业的发展，无不想占据垄断的地位，让别人难以入侵。

# 3、自己依靠的关系。

在中国办事，大家很都清楚的。任你本事再强大，都干不过过硬的关系。所有的招投标，大项目，背后都有各种复杂的背景关系在运作。如果你没产品、没技术、没团队，这都不重要，只要你有强硬的甲方关系，资质可以借，公司可以挂名，产品可以合作，有关系就有一切。

# 1、做老大时刻要衡量自己手里还有什么牌

做老大，每天都要关注自己手里筹码的变化，要不断的加强手里筹码的分量，这才是自己最为核心的资源。至于具体的客户啊、产品啊、研发啊，这都是手下人要做的事情。
