# 三、苏威的相关反应的正确性：

# 1、沉默不语

而 against 高频的辞职，苏威并没有提出任何意见。职场上就是这样，潜在牵扯到自己的事情，最好的策略就是以不变应万变。因为你的任何举动，都可能被人反向解读。挽留高频会被认为是虚伪。主张同意，会被认为小肚鸡肠，排除异己。职场上只要不是明确针对自己的事情，都不要主动发言。

# 2、同心协力

苏威面对再次恢复官位的高频，心里立即就明白了，隋文帝是想他制衡自己，如果对抗，肯定完不成自己的目的。而且高频这一退一进，隋文帝还点明了，对自身的推荐之恩，更加的保持恭敬。所以苏威采取了合作的策略，打不倒高频，就不报这个想法了。

高频以退为进的政治策略，被隋文帝识破，然后将计就计，让其先退后进，和苏威形成制衡，同时，又对苏威暗中进行的野心压制。最终导致了君臣和谐的局面，每个人都明确了自己的定位和在此彼此心里的位置，又不失大家的和谐关系，这就是高层政治高手的，精彩权谋交锋。

# 领导猜疑下属的原因及其处理手法

【出处】《资治通鉴》第 175 卷 陈纪 9

【原文】广州刺史马靖，得岭表人心，兵甲精练，数有战功。朝廷疑之，遣吏部侍郎萧引观靖举措，讽令送质，外托收督赋物，引至番禺。靖即遣子弟入质。

【译文】广州刺史马靖，在岭表地区深得人心，手下兵强马壮，屡立战功。朝廷因此猜疑他，派吏部侍郎萧引前去观察他的动静，并含蓄提出让他向朝廷送交人质，对外做是督促岭表地区蛮、等部族向朝廷交纳的财物。萧引到达广州治所番禺后，马靖立即遣送子弟入朝作为人质。

【解析】作为一把手，对权力是没有安全感的，对于优秀的人才既爱又恨。爱是因为，优秀的人才能够为组织作出贡献，能够为自己带来利益；恨的是，如果放手使用，又怕其有野心，最终造成成为自己最为强劲的对手。历朝历代所有有权谋家无不秉承着韩非子提出的“持术不持信”的权力信条，把具备造反实力的人，统统的控制起来，才能够防患于未然。

+   1、马靖之所以被猜疑，因为他具备了五大要素！

一个人之所以被猜疑，因为他具备了五大要素，而马靖竟然全部具备。

首先是位置偏远。马靖在广州，这是离朝廷较远的地方，他的一举一动不能随时监控在领导视野之内。有小动作，也不能及时发现和控制。领导通常而言会把危险份子，放在身边监控。

其次，他是刺史，属于地方军政一把手。具有独立的人事权财政权，这是独立的物质条件。
