在朝堂之上，把自己和权臣形成势均力敌的地位，这样其实是对权力的分割，会让下面的人无所适从，自己乱了自己的权力平衡。

# 3、经济资源的均势

经济资源的平均分配，让大家充满了野心，只有势均力敌的时候，大家才会有斗争之心。权谋网说过“邪心诱于可欲”，只差一步才会胜出，才最能激发人的斗争欲望。

# 三、权谋名词“势均则斗”给我们什么启示呢？

+   1、如果想制衡，就让他们分成两派。因为他们斗来斗去，自己才会安全。很多政治家都会把自己的手下分成两派，互相牵制。
2、如果想制造混乱，就要使用均势的办法，让其内斗，只有不断地内斗，搅乱浑水，才能够有机会，以患为利。
3、先消除混乱，就要剪除平均实力，让他们没有野心，即使有野心也没有支持野心存在的势力。不要只扶植对抗一派势力，这会让自己成为斗争对象，要扶植两派，才会稳定。

所以经过上述的论述，我们记住这个“势均则斗”但凡强弱一定，或是格局分明，大家也就不需要斗了。均势下，要么你自废武功，寻求自保，要么奋发进取，灭掉对手，没有第三条路。不存在自己又有实力又安全的这个状态，这是权谋家对势力判断的时候要注意的。
