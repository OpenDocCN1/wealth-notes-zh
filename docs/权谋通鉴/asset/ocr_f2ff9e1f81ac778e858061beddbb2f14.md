李衡得罪了琅琊王，弄得人家，惹不起躲得起，自己搬走。而琅琊王忽然因缘际会成了皇帝。李衡的角色极度尴尬。

# 1、李衡的困境有何计策？

李衡面对自己得罪的琅琊王，有上中下三策：下策就是无动于衷，心存侥幸心理，很多人大多就是这样的缩头乌龟，跑没勇气，认错伤自尊，苟延残喘而已；中策就是逃跑，李衡的妻子劝他不要跑，核心的不是无颜见中原人，而是他作为一个文官，和武将不一样，没有任何资源，即使跑过去，魏国也不会待见他，这只是能够活命而已；而上策就是，习氏的这个策略，公开认错，送名给琅琊王。

# 2、这个上策有什么条件？

这个上策使用的前提条件，就是领导刚刚上位，权力不稳定，且好名。如果面对的是一个睚眦必报的领导，或是面对的是一个逐步自己积累做大的人，你就是主动承认错误，他也会找机会除掉你的，刘邦原諒雍齿，齐桓公原諒管仲，和齐桓公原諒寺人披，都是刚刚接掌政权，需要图名，求稳定。

# 3、这个上策有什么步骤？

这个上策的步骤，其实就是两大步，主动自责，然后公开上书。主动自责是需要有具体行动的，最好的就是搞成行为艺术，把自己关押到监狱，然后公开上书。这样能让人知道你的悔过诚意，也能够逼着走向道德困境，让领导不得不考虑自己的形象。公开挑明矛盾，公开自责，让对手不能不展示胸怀。

# 4、这个上策有什么好处？

这个上策的好处，就是自己的价值能够反向映衬领导的胸怀，成就他的名声。张绣杀了曹操的儿子和侄子，可以说血海深仇，但是在官渡之战的最后时候，张绣在贾诩劝说下，自己投奔过来，曹操也是说，你的到来成就了我的名声。所以说，每个人都有每个人用处，找到领导的需求点，很重要。

# 5、这个计策在职场用处？

学习历史的故事，目的就是为我所用。职场面对自己得罪的人成为领导，自己公开负荆请罪，摆一桌酒菜，这样把矛盾公开化，自己公开道歉，尽管违背人性，但是，这样恰恰能让对方因为刚刚当上领导不好下手，能够侥幸的逃过一劫。不过如果不成，最好的办法，还是走，最好还是试试上策再走。

经过权谋网的上述分析，我们能看出来，权谋就是反人性，不但不跑，反而主动迎合，这样的举动，在某种程度上都是在逼迫上司到一个道德困境。不过后遗症还是很多，除非自己老实实的，接下来，做狗，不断地舔舔，让他不断地满足当初失去的自尊，不然也是会逐步的找个借口被收拾掉的。那我们研究这个案例有什么用呢，就是每个事情，都有上策，不能每次都要选择逃避，可以尝试各种方法。
