承诺的枷锁，是权谋家必备技术。

李世勋和单雄信友好且同乡，当初有誓同生死的誓言。而现在李世勋拥有大功，而单雄信是阶下囚，李世勋并不想陪他去死。但是又不愿意违背誓言，让其他人看不起，让别人评价自己不是言行不一致的人。所以，必须解开这个承诺的环，让自己不死又不违背道义和舆论。于是，采用了三步策略！

# 一、李世勋解开承诺死环的三大步骤！

# 1、穷尽能力

“请尽输己之官爵以赎之，世民不许。世勋固请不能得，涕泣而退。” 李世勋尽了自己最大的能力，愿意捐献所有的财富换取单雄信一命，多次请求，他尽了自己最大的努力，而没有营救成功。给别人的看法就是，自己尽力了，但是天不遂人愿，错不在己。

# 2、尽力补偿

“但既以此身许国，事无两遂。且吾死之后，谁复视兄之妻子乎” 李世勋认为，我既然救不了你单雄信，但是我可以尽力照顾好你的妻子儿女，这样最大层面的给你补偿，也算是仁至义尽，不能算是我对不起兄弟，这种补偿从世道人情上也说的过去的。

# 3、情感表达

尽力、尽心、但是却还没有尽情，所以李世勋割下一块自己大腿上的肉，“使此肉随兄为土，庶几不负昔誓也”自己作为兄弟，这样的行为，足以说明自己的尽情，把兄弟情演绎到如此地步。他算是给所有的其他朋友，一个交代，我该做的都做了，我并不是不愿意一起死，而是没有办法。

# 二、单雄信面对困局的权谋心思

# 1、当初应该是分头押宝的政治策略。

为什么好兄弟却不在一个阵营？原因还是他们之间的政治押宝策略。因为王世充和李世民，当时的状态下，平分秋色，谁也不知道最后谁得到天下，这就需要多方押宝，谁赢，他们兄弟都能分到一杯烫。单雄信期待，李世勋兑现当初承诺。从记载中看不出单雄信感恩，只是认为理所当然。

# 2、指责测试李世勋是否尽最大努力。

“我固知汝不办事”，面对李世勋的努力，单雄信并不感谢，还说了句指责的话，“我就知道你办不成事”这是单雄信无奈的选择，在当时作为阶下囚的状态下，他不知道老李是不是努力为自己求情了，一面之词怎么能够信呢，通过指责他，就是在测试他的反应，看看是不是真的尽力了。
