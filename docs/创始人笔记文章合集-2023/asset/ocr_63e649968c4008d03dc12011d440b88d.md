# 04

耶，这个事情，有没有更好的处理办法？

万叔说，短期无解，长期有解。

短期的解法，无非是两种。

要么打你柏噢芜、想维稳的痛点，把事情弄大；要么忍气吞声，走利益共同体的路线，希望你好了以后，能兑现承诺。

长期来看，像深圳公交集团一样，明确产权，要求利润，在前期能力不足的情况下，给予优惠，配置人才，找一帮海盗式，不要命博一个机会的人，用认知撬动资源杠杆，顺一波跨越阶级可能性。

成了，利在千秋。败了，也约定保住了底线。
