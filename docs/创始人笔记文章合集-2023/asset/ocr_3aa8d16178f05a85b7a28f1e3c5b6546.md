# 01

遇事，喜欢琢磨

从小，万斌就喜欢琢磨。

万斌经常给人分享的一个故事。

小时候，1 年级数学班选拔考试，老师给一个小时，让我们从 1+2+3......+100.

有的小伙伴，拿着铅笔，就开始计算。

也有小伙伴，面露难色，坐万斌后面那个小胖子，十个手指骰完以后，唯一一声哭了。

万斌没动笔。

一想到，要加 100 次，一次都不能错，心里犯怵，也有点打退堂鼓。

老师看见万斌眉头紧皱，一个字没写，也不放弃，拍肩问道：万同学，在想什么？

万斌撑着一张稚气的脸，说，老师，我在想，你为什么，要我们算这个。

然后，万斌敏锐的察觉到，老师脸上面露欣喜。
