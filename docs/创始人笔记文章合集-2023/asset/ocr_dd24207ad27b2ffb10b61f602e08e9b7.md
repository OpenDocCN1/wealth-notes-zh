# 02

故事 2：服务的一家电商客户，之前在淘宝上开店。差不多就是万叔和前女友做电视购物那会。

做了几年，业绩一直比较稳定。

后来对接上两头，一头是凭借自己深耕的资质，打通了京东自营的供应渠道。

另一头是凭借渠道优势，拿下了一个头部品牌的电商代理权。

很有意思的逻辑，凭借品牌的代理，拿到了大渠道的供货权，又通过供货权背书，拿下了更大的品牌代理。
有点左脚踩右脚上天的意思。

就 3 年时间，打通了任督二脉一样，业绩提升了 10 倍，成为行业的头部之一。
