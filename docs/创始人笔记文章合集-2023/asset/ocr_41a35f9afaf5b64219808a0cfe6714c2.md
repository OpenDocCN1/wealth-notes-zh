# 揭秘：用利益的视角，看茅台冰淇淋的热销

原创 万叔 创始人笔记 2023-06-24 22:02:21

大家好，我是创始人万叔。

我的同行刘润，前几天发了一篇文章，讲茅台冰淇淋。

因为茅台董事长丁雄军，在茅台冰淇淋发售一周年之际，宣布冰淇淋战略大获成功，一年卖到1000万杯。

什么概念，如果按照零售价平均66一杯来看，这一年的营业额6个亿，超过了哈根达斯中国、超过了雀巢冰淇淋，直通雪糕刺客钟薛高。

润总从茅台品牌、价格锚定、炫耀属性几个方面，分析了茅台冰淇淋成功的秘密。

在我看来，都是瞎扯淡。
