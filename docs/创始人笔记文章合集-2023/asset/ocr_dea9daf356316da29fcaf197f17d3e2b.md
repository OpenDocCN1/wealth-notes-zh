# D4

那普通人，该怎么样自我提升？

去模仿比你高的人，尤其是，模仿他们的思考逻辑和过程。

乔布斯说，他愿意用自己所有的财富，换取和苏格拉底一下午的谈话。而谈话的意义，就是学习他人思考的过程。

找一些和自己同频的，有上进心的人，一起进步。

这样的同频，更容易拉近距离，共同监督进步，一个人走得快，一群人走得远。

并且，少关注尤其是模仿一些，更低层次的人。

他们会把你拉到同一个层次，然后用丰富的表演经验同化你。

正因为反人性、反本能，需要放弃情绪化，所以艰难。

阶级跃迁，这条少有人走的路，才如此精彩。
