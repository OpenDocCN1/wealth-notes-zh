# Baseline Thinking Methods.

主要是用在商业咨询上的。

用法是，在思考、判断任何事情的时候，要拉一条基准线。

这是万叔做咨询以来，脱离感性认知，进入理性认知，最重要的一个方法。

举个例子。

你老婆跟你说，今天天气真热。

什么意思？没概念。

加一句，今天比昨天高了 8 度，我昨天穿毛衣，今天穿单衣。

就有概念了。

那个毛衣，和没说出来的，昨天的温度，就是基准线。
