# 04

说回苹果。
从商业顾问的视角来看，这家企业从战略到执行，强得可怕。
默认构建软硬件一体化的生态。
默认打造排他差断的应用商店市场，收取 30% 的苹果税。
默认研发芯片，用手机级的芯片工艺，应用到笔记本上，做出了极为领先的 MACBOOK。

![](bbox=[0.2, 0.44, 0.91, 0.75])

这些差断、生态化、自研替代，都是常见的企业战略。
但绝大部分企业，因为这样那样的原因，做不全，也不愿意去做，
这样的生态——大家只想赚钱而已。
任何一个，放在其他公司上，大概率可以吹一辈子了。
而在苹果身上，随随便便，就数出好多个。
以及要来的苹果混合现实眼镜，可能创造出无与伦比的用户体验，
然后收取极高的硬件利润，和应用商店分成。
是战略结构级别的，遥遥领先。
