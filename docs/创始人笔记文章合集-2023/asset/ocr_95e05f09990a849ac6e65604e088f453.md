# 05

所以最后无论是弗洛伊德家人，还是黑人群体，都得到了更多的关注，更多的利益。

日本这事，也是一样，几个国家越想把声音压下去，我们就越应该把事情闹大。

闹得越大，最后的补偿就越高。

你要明白，噢怕你是个温和的人，你认为这个事情危害不大，或者真相是什么样的，这不重要。重要的是，什么是对我们，对国家，最有利的策略。

而争取这种利益，甚至都不需要你付出什么成本，只要舆论扶托起来，就行。

互联网上声讨的声音，一浪高过一浪，不少放大危害、声情并茂、民科研究的视频，都得到了百万、千万播放量，没被搁置。也说明了，决策者的态度。

如果可以，最好是去英文世界，去 INS、Twitter、FaceBook 上，去讲 GT 事，发讨论，把火烧到日本工业、日本的国家信誉上。真正的报复，不是以头抢地的儒夫之怒，也不是杀他全家的匹夫之怒，而是抢钱抢粮，打击他的生巵，抢占他的生态位，造成经济衰退，社会动荡——因为做了错事，未来没有希望。
