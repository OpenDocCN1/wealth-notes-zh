# 04

当然，很多职业，同时存在几种属性。
比如，我是大公司的咨询顾问，我到底是要追求跃迁，还是要追求专业能力的提升？
涉及到多重属性的，也有一些方法论、和定位方式，确认主属性，因人而异。
但我们不是教科书，所以不追求大而全，追求真实、有效。
不过，总体方向是不会变的。
引用行为经济学家代表人物，丹尼尔·卡尼曼的话，在不确定中找到确定性，理解并规避人性的弱点，做正确的事，就能稳步走向成功。
