# 02

今天聊这个话题的原因，还是和阶级、趋势有关。
在电影《孤注一掷》里，王大陆有个倍投法，说我只要输了，就加倍，我的本金保证我能加倍 12 次。
任何一次赢了，就能连本带利的赢回来。

![](bbox=[0.22, 0.35, 0.92, 0.62])

这里的本质是什么？
本质就是，不断提升博弈的势能，用更高的势能弥补前面的错误。
用资源改善胜率。
只要你的本金、资源足够，这就是个好的策略。
为什么我当时亏钱后，还能放弃投资，继续干事业。
因为那个钱，太夸张，太快了，快到我的消费、认知结构，都没有跟上来。
如果当时钱全部取出来，过几年奢靡的生活，估计再往后，就很难回去。
后来我看谢利弗·弗莫尔的书，《股票大作手回忆录》，这哥们也是多次破产，多次又东山再起。
