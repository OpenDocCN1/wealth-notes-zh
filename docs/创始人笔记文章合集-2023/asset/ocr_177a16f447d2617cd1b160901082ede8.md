# D2

实际上，每个人都有成功的可能性。

万般是做咨询交付出身的，所以把专业能力看得很重。

这既成就了之前的成功，你的交付是稳定的，是值得信赖的，同时也错过了很多其它的机会。

比方说，之前尝试过写文章，写什么呢？咨询专业的文章。

结果没有人看。为什么？

市场太小，用户基数太小。

后来找到了流量的打法，用咨询与管理的视角，去剖析热点话题，提升个人成长和认知，才站住定位。

商业的源头不是你有什么东西，而是市场、需求端需要什么东西。
