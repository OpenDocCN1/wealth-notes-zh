# 发展方向：在珠三角以外的珠三角市场，走高周转速度型路线，快速回笼资金，降低开发风险，确保不沉淀资金

# 高周转速度型路线构成原因

+   - 深土资源部分集中要求
  - 深圳目前有26.5%的土地在布在深圳以外的珠三角市，而目前这些城市大都是四线城市。
- 目标市场需求
  - 由于在三四线城市的人口将，这区域城市形成基础以刚需产品为主。
- 快速回笼资金，降低开发风险
- 有助于提升企业的成本控制能力及促使完善精细化体系

“利润与周转兼顾”，通过深耕外市场的高周转项目开发，来弥补各项住宅开发业务持续的资金滚动
