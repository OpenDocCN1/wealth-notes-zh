# 以药养医

过去因为限制，医生的价值创造和价值评价严重不匹配。
但医生是个专业领域，需要提高和普及。
如果所有人都很穷，医生相对好一点，那其实是没有问题的。
但问题是，医生很穷，但上游的药品、器械、流通，先发了大财。
