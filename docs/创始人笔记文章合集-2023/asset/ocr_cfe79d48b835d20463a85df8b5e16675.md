# 瞄准视频号的细分赛道

很多人说，我之前在厂里就是一颗螺丝钉，也没什么很出众的地方。

自己做的事情和能力拿出来讲也没什么作用，都是一些很常规的事，那么，我会有创业的机会吗？

他就是从互联网大厂出来，直接瞄准了视频号的主要受众群体，30~50 岁-fashioned 的依赖女性。

我问他，你以前做过、类似的业务和生意没有。他笑笑嗔的回答，没有啊。

这真的就是，从外部的趋势机会，和自身的资源禀赋，做的业务战略。

当然了，这个自身的资源禀赋是指广州拥有全国甚至全世界最大的，化妆品供应链体系。

搞定了供应链，另外一端就疯狂的去搞流量。

借助微信视频号这波红利，和包括万磁在内的，大多数人，我会什么就做什么不一样。

他是一一人们需要什么，我就做什么。

像极了当年五菱宏光喊出的口号。
