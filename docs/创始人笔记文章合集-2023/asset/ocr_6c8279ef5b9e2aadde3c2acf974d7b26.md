# 04

所以，出了问题，如何划分责任，如何找到正确的负责人，本身也是一门学问。

谁做什么事，承担什么责任；创造什么价值，拿到什么奖励

作为一个管理者，一开始的时候想清楚，很重要。

把这个作为基准线，向所有人阐释清楚。

如果最后，因为出了事，做了管理动作，就是事先就说好的，只是按规矩行事。

不会因为前面说清楚，就被迫于道德的压力，做出偏离意志的决策。

而如果我不想处理你，网开一面——你也可以清晰感受到，这是清晰的基准线之上，对你的宽容。
