# 3、提升认知是成长的根本。

从过去的债权，到未来的股权，从中央机构的变革，多去琢磨琢磨，尤其是，这事儿与我有什么关系？我能从中看到什么机会？

不要总看肤浅的，宏现的东西，研究一个东西，就想办法搞透，比别人深一层，比别人多一层。

然后把这些观点，当成生产力工具，发布出去，让更多人看到，撬动更多的资源，链接、合作，成为跃迁的养分和台阶。

房产、医疗、互联网、咨询服务……任何一个行业，只要摸清了核心玩法，都有巨大的机遇。
