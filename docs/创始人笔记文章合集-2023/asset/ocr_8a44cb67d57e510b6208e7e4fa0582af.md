# 06

我这是从哪里学来的？

一个刘润，是我们这一行的流量大佬。

他一个人借别人办公室一张桌子起步，到现在公司人也不多，但每年做到几千万上亿的利润，让我见识到了流量的威力。

他把自己的时间，通过授课、写书、做演讲的方式，分成可复制的无数份，低价卖给需要的人。

一个小马宋，也是野蛮生长起来的。

他也不做低价单品，而是提高单价，做精品。

但他借助互联网放大势能，把价格推高，极限利用时间，精英团队+重点交付的商业模式。

他谈的那些东西，在很多搞营销的人来看，觉得都是老生常谈，没有太多牛逼的东西。

我经常问这些人，你觉得他不厉害，为什么他拿到的结果，比你大？
