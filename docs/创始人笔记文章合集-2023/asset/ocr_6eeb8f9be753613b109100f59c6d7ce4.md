# 又一个漂亮姑娘，职场遇到了瓶颈

原创 万极 创始人笔记 2023-07-29 21:01:51

大家好，我是创始人万极。

周末接了一个付费咨询，职业生涯方面的。

HR 问了一个很常见的问题，她的职业生涯感觉到瓶颈了，怎么破？

本身这类咨询，从收入角度来讲，性价比是不高的。因为不可复制，而且不能保证效果。

所以，几年钱缺钱的时候，做过这么一个宣传，后来就放弃了。

但是因为是认识几年的朋友，也知道我几年前，曾有过这么个业务，所以不好意思拒绝就接了。

HR 面临的，是这么个情况。
