# 最后 一 地 鸡 毛。

比如万叔从 2014 年开始，就呼吁说计划生育，要提前放开，提前做准备。

当时好多人拿各种难听的话，试图证明万叔是个傻子，人口会爆炸啥的。

结果去年计划生育任务（人口 0 增长）完成了，又是那群人，开始慢慢悲观了，觉得 10 年少一个河南省。

这些人，都是线性思维，觉得我今年工资 5K，明年涨到 6K，后年涨到 7K……所以万事万物都应该是这样的。

生物学上，有一个重要的概念叫负反馈。

说人话就是，多了就少点，少了就多点。

任何趋势，都大概率是一条前期陡后缓的曲线。
