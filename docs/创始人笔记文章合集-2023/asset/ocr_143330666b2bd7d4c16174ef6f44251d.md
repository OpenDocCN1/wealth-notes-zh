# 02

万叔是白羊座，小时候到处乱窜，从来不喝热水。

大冬天，外面下着雪，万叔从缸里舀起冷水就喝。

也不是没听说喝过热水，但是一喝热水，脑袋就开始冒汗。

为啥，年轻，身体扛得住吧。

后来去外地读书，家里寄了三七粉，让泡水喝，说活血补啥效果好。

万叔泡了几次水，喝完以后感觉手掌发麻发热，像极了小时候看电视的时候，真气涌到双手，要发出龟派气功的感觉。

那珍贵的中药材，就闲置了。

万叔讲这几个故事，其实只是要说明一个简单的道理。

同一件事，对不同人，产生的边际效应不一样。
