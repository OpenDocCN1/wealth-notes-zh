# 04

如果做不到，还有没有别的办法，提升单次胜率？

但也不是没有办法。

找合作伙伴，分层承担风险。

比如把 990 万收益期望的选择权，100 万卖出去。

只要我的人足够多，总有愿意冒险的人，想博一把的。

如果你觉得，100 万少了，万叔我还想多赚点，极限能卖到多少钱？

理性情况下，极限就是卖到 990 万。

超过这个极限，就是非理性的决策，需要找到特定的人，俗称冤大头。

要注意的是，到了这里，就不是你一个人的游戏了，需要有买卖双方参与，体现出了链条的重要性。
