# 第二，制造信息茧房，避免直接接触。

我外公去世的时候，为了避免刺激情绪，几个老人，拉着外婆在屋里聊天。

聊什么呢？就是很随意的拉家常。

后来才知道，这是老一辈的智慧，不让当事人，接触过于伤害的事情，避免触景生情，影响身体。
