# 3、缺乏持续进化的能力

比如你开一家店，赚钱了，然后你就觉得，可以复制，开到 100 家店，就 100 倍收益。

这是很多人路演、见投资人的想法。

但能力、资源要求，完全不一样。

开单店，你起早贪黑，精缩成本，勤劳一点，就以实现盈利。

但连锁店呢？

需要的是供应链、标准化流程、人力资源体系、股权分红体系……

你说我从来都没听说过啊！

那你的天花板，就限于一家店，或者两家店了。

职场也是一样。

自己做销售，和培养、组织、推动下面的人做销售，自己做销售管理，是不一样的能力需求。

都需要你持续进化。
