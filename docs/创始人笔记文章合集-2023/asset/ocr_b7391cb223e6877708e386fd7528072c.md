# D2

除此之外，还有其它驱动行业发展的关键因素。

花西子、完美日记、以及一众国货品牌，都集中在16、17年爆发式成长。

如果你那时候问万科，为什么这类会会出现爆发式增长。

可能回答不了你。

但随着认知的提升，现在我可以比较好的跟你解释。

这是因为供应链升级、资本驱动、流量阵地转移，三者结合的结果

供应链倒先讲了，现在我们处于绝大部分行业供给过剩的时代。

而资本驱动，流量转移这两者，就很有意思。

而那一批国货的兴起，典型的公式就是，精心包装的故事+无处不在的营销+直播间收割完成闭环。
