# 另外一个特点，超导体 会产生抗磁性。

什么意思呢？一般的磁铁，无论怎么细分，总有南极和北极。

你用同极去接触，就表现出来相互排斥的特性。

你用不同极去接触，很快就会吸到一起。

但超导体不一样，他产生的抗磁性，无论哪个面，都会表现出相斥。

![](bbox=[0.2, 0.65, 0.79, 0.86])

使得在一定磁场下，超导体是可以悬浮起来的。

如果还记得阿凡达的朋友，里面人类去进攻阿凡达星球的原因，就是星球上有数不清的超导材料。

一座座超导体组成的山，整个悬浮起来。
