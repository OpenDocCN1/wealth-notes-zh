# 为什么冷链物流不发达？

因为造价投资贵。

# 为什么造价投资贵？

因为回本周期长。

# 为什么回本周期长？

因为老百姓没钱，出高溢价购买新鲜的意愿，不高。

这些规律，都是跟 GDP 增长，经济发展有关，不以人的意志为转移。

所以，很多营销号告诉你，穷人思维怎么样，其实都是错的，是因为穷，很多的想法、欲望、视野，被压制了。

你用这个思路去想，为什么刺激消费刺激不起来，真是因为很多人家里都没钱了。
