# 分化和洗牌

可能包括我自己在内，绝大多数人，都没有经历过经济周期。所以这次的经济下行，大家很难受，很多不适应。

经济下行，不是一艘航母直接沉到水里，不是的。

是分化，尤其是中产阶级的分化。

我在之前的文章里，写了美国、日本、那些先发的国家，高速增长结束以后，都是分化趋势。

不止是人，包括房子，也在分化。

广州今年二手房挂牌数量，超过历史警戒线，未来大部分人要面临的，是房子几乎只剩下消费属性，跟买车一样，租房成为生活的一种选择。
