# 05 | 变化与恒定：化学变化遵守的基本法则是什么？

孙亚飞 《化学通识课》3课时

你好，欢迎回到《化学通识课》，我是孙亚飞。

上一讲，我们讲了化学反应的第一条定律，知道，了化学反应平衡，是一种动态的平衡。既然如此，那我们就扣住动态的过程中，去寻找底层的本体呢？抓个在哪儿呢？

这就是今天，我们来探讨的问题。

上一讲，我们提到一个案例，就是每个人的骨骼，每10年就会被更换一次。

其实，不只是骨骼，我们身体具体部位的细胞，也在一直进行着新老接替。细啊，可以从宏观到微观，都是不同的老房子。所以从原子层面上的话，这一寸存在的人，到下一刻，就已经不是他你了。

于是，也就有了那句著名的仙论：人不能两次踏入同一条河流了。的确，人在流动，河流也在变。

“白其父者而河之，则天地曾不能以一瞬”。更不要说踏入同一条河流了。

但是，把一个思想用到生活中，就会出现新的问题，比如，一个人在犯了刑事案件，被警察抓获，能不能到此理由为自己辩护呢？换句话说到，警察看到的那个罪犯，跟当时作案的人，还是同一个人吗？

这些问题在化学看来，其实很容易解决。

---- 1 ----

你老是经常看足球，就会发现，在足球场上，每一个运动员虽然不停地运动，但是也要遵循很多技术规范。普通人看来，可能只是乱跑乱踢，可实际上，球员都对对方门前的门，但是对于运动队来说，不管怎么跑，球是不能越位对方的，一定有一个内在的恒定，而后，后卫跑到了门方了，那你在球队门前的位置，就由中场球员把他暂时顶一会儿。

化学过程也组如此。

所以，足球比赛一样，不管化学变化怎么进行，要寻找其中恒定的要素。那么，化学是如何实现的呢？

这是一个递进的过程，我们分别到物质、质量和能量三个阶段谈一谈。

**化学是恒定在恒定不变的物质，这现象是数学家对圆的理解。**

自然界中，圆形的东西太多了，比如行星轨道，小到盘子的边沿，也可以说是圆形的。

你或许还知道，在数学定义里，圆是在平面内，一个定点为距离的所有的点集合。这个定义也是圆的作用原理。

![](bbox=[0.05, 0.9, 0.95, 0.97])

然而，无论我们怎么努力，都可能在自然界找到“不”完全符合数学定义的圆，甚至于是说，“圆”都只在人脑的定义中相同的定义。

古人也曾尝试过这种方法理解自然。比如古希腊德谟克利特的“地心说”模型中，就看到圆的影子，将行星轨道想象为纯粹的圆。

这种种“设计”的完美度，也成了后来一些人对造物主的猜测与赞美。但是，随着观测精度提升，人们发现，可观测现象往往是复杂的，纯粹的数学定义并不能展现它们的全貌。

同样的问题，在化学中更为突出。但和天文不同的是，化学现象在微观尺度下进行的。

去时候的人，没什么观察手段，自然规律就更是**。由此，很大一部分，他们的解决办法是**随机，并在此定义了一类恒定的物质——元素。

从字面上来看，“元素”也是根本的意思。它的英文element，有元素，理念的意义。在放射性现象发现之前，元素一直是物质世界相对稳定不变的基本单位。

它虽然是化学术语，但是在生活中，你可能会听到。

比如，美发顾问Tony老师也许会告诉你，今天做的这款发型具有洛可可可设计“元素”。再比如，钢弦音乐的家是“铁”，“元素音乐”就很欢迎，碳素纸的碳就是元素的。

这两种元素的区别在于，做完的发型呢，你找不到某被划为“洛可可”的质，而在碳素墨水，却真有的碳元素可查，这是物质里面的元素。你最终发现，元素这个模型是正确，具体内涵我们在后面再展开。

不管是到墨汁中被吸到了笔里，还是被写到纸上面去，也不管是被吸干了，还是被洗去——墨汁中的碳元素是保持不变的。它在光谱上的特征数符不变，我们就可以去追踪它，研究它。

从这个例子里我们就可看出，碳元素，其实就是碳素墨水恒定的抓手。而这就解决了物质恒定性的问题。

---- 2 ----

解决了物质问题，就好比是足球场上的人恒定性的，大家一开始是11个人，但是每个人的位置和实力都不同，所以还要进一步量化，用技术统计去评判。

对化学而言，这个技术统计，指的是质量守恒定律。

质量守恒定律的发现，现在有很多说法，公认的一种是，俄国化学家罗蒙诺索夫奠定了基础，而法国化学家拉瓦锡最终证实了这一条定律。

在他们之前，别说是普通人了，即便是牛顿都很难说“质量”，还和打过半字道理的大科学家吗。

我可不是说牛顿不天才，只能说在牛顿生活的年代，人们还未能真正理解元素。而元素的作用实在是太重要了。牛顿其实是把物质的量当作了质量。

而在现代科学中，物质的量就是粒子的数量，它和物质质量不同，间由元素作个桥梁。不同元素的质量不同，所以数量和物质的质，才需要的定。

这就很像你在地铁里看到的载重显示，一方面规定了重量，可承量100公斤，这就相当于物理的质的量；另一方面又规定了最多承了13个人，那就相当于微观的数量，这里的桥梁是人。

物质的数量可以保持恒定，这是很容易理解的，就像一加一等二，是个数学问题。但是真量的人并非是这样，也就是说化学在球场安排11个人都是平衡，也很难赢比赛。

同样，化学反应着起来十分复杂。在不理解元素的前提下，铁和铁的关系都很难说清楚。从表面上来，铁变成铁锈以后，重量轻了；木头烧了以后变成灰，就是变轻了。

因此，在质量守恒定律确立之前，化学反应不认识原，在世上神，像魔法一样。谁会计为巫师也遵守物质守恒定律呢？

但是，当有了元素不变的概念以后，确立“质量守恒定律”，就只是时间早晚的问题了。

与此结伴而来的，是化学进入了定量时代，化学工业也就此补上了最要的一块基石。

如果没有这些，在化学工业中，我们得计算每一个化学反应中，反应物生成物，再加上操作的复杂因素。那么科学问题，也就是纸工业。什么叫物质算呢？就是计算出每一个反应过程种反应物和产物的量。

更为重要的是，现代人的思维也由此发生了很大“革命”。

质量不变，反过来也加强了物质不灭的概念。物质不会凭空消失或产生，这不是恒概念，而是基于事实基础。

由此，很多像类也失去了藏身之处。撒钱成丹，点金成术之类的故事，现在也只是文艺作品的桥段，没人会计较。但在古代，这些都可能是形形色色的看功夫。
