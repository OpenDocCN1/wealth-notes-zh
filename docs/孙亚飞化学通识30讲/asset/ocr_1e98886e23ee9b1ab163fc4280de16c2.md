到这里为止，是关于酸碱模型最完整的解释。了解了这三个层次，我们就可以回答这一讲开头提出的问题：酸性为什么容易被这种学科提出？

这是因为，酸碱模型一再扩展，也产生了一个致命的缺点，当然，这个不是模型的致命缺点，而是模型理想化程度很高的致命。就是说，什么事都可以用二元分类方法来解释。对客观世界进行二分划分，这是常见的辩证思维。

不过，辩证的辩证、范畴不可或缺了，否则二元思维的基本特征就圆满不失。

> > 任何-概念，基本上都会对范围作一个明确的界定，比如我们前面谈到的那个酸碱理论，范围是氢离子浓度大。在化学上，讨论的对象永远是非常确定。

一旦有人把酸碱模型的适用范围扩大到生命体，就不具备讨论的基础了。

酸碱体质的伪科学性，就是这么来的。酸碱体质的核心观点，认为人体分为酸性和碱性，酸性体质容易生病，碱性体质则是健康的，多吃酸性食物，就会变成酸性体质，所以为了健康，我们要多吃碱性食物。

生命体当然也是化学物质构成的，但是生命本身，还有很多其他的生理作用是不可忽略的。

可能说的，你还不太容易理解，那我们举个简单的例子。

根据生理酸，我们可以把入分为男性和女性，而这里重重证明很多，比如染色体不同，或者女可以怀孕男异生，能等。这些都是我们熟悉的二元命题，但它只局限在生理方面。

如果在社会学层面解释男男女的差别，比如放弃男性应该事业活动，女性指发女性应该做女性应该得到更多的顾等，女性应该当家庭主妇，这类说法就站不住脚了。

> > 酸碱体质的骗局，就是同样的套路，它把酸碱的学科性质-过，过过 这就是酸性或碱性体质这一概念，通过酸性或性化成酸或男性强就是一个性质。

唯一的同的是，对于性别问题，绝大多数人都站面了，但是对于酸体质这样的化学模型，真正知道的人却不妨多，只是被简单想象又复现。

多说一句，对于非专业人士而言，识出伪模型的科普文章，也是全人重要的。

一句话总结就是：多看事，少就思，紧扣定义分析，不跨域应用。

# ## 总结

+   1. 酸碱模型的第一层次，是看物质的pH值，也就是氢离子浓度；
2. 酸碱模型的第二个层次，是看这种物质是直接释放氢离子；
3. 酸碱模型的第三个层次，是看电子的位置，这真正连接了结构和化学性质的关系；
4. 酸碱模型有科学性，也很容易听懂，但它讨论的对象始终固定在非生命体中，范围一旦扩大到生命体，就不具备讨论的基础了。这也是酸碱体质是伪科学的根本原因。
