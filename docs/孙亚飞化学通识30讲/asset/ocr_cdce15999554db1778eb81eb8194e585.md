# — 03 · 溶与 —

从前面讲过的课程中，我相信你们已经发现了套路。我们构造了一个个的模型，可以更加清晰地来认识世界。而通过这个模型的原理，去更好地改造世界，也是这个化学的精神，也是我们接下来要说的第三点内容。

溶液与乳液，在生活中有很多实际的用途，知道了这个模型，你的生活质量和幸福感，就会大大提高了。

比如说做饭，炒菜的时候，盐是先放进去还是后放，味道会不一样。一般来说，盐先放盐的话，就不好看了。这是因为，盐溶在汤里之后再成溶液，炒的过程中，随着水蒸发，盐水浓度越来越高，而且盐全部渗透进去，结果就是咸的既没全被吸收严重，看着不太灵，吃着也是干巴的。

糖、醋、水，这些都是很容易溶于水的物质，可以在水中形成溶液。出现上面的状况。所以，都知道吃饭时先放糖，但没有说放糖的时候，就先把糖直接倒进去。而是吃的时候再放。

你可能没想到的是，乳液在做饭的时候也很常见，比如，奶白色的颜色，如何才能把白色汤染成油汤？加进水的过程，具体操作的时候，先用油做汤，将杏仁的一根棉细分搅拌出来，这就是做酱，而且稳定性很好，很稠实。这样在搅匀的时候，就会出现奶汤了。

当然，如果你知道这个原理了，也就知道，鲫鱼汤虽然很浓，但是和盐没关系，不能恨鱼，恨是恨脂肪。

洗发水也是利用了这个原理。发根是很容易出油的部位，直接用热水洗肯定是行不通，这时候就需要用水去直接冲移，让头发湿润地冲形成乳液，然后被冲掉，头发就干净清爽了。

那么，我们回到开头那个话题，为什么女生们用的各种乳液、护肤品都是乳液呢？因为它们从类型上本质上，都是非非常标准的乳液，是利用乳液的物态结构作用，来完成各自的化妆功能。

在化化妆品上，你可能会注意到O/W或者W/O的字眼。这可能就是乳液，这些乳液有散成油包水，也有的是水包油。适合秋冬季节，干皮肤的时候用，有的做成O包水，也可以是O/W型，适合春夏季节，湿度的时候用。

# ★ 总结 ★

+   第一，溶液和乳液的实质是不同的结构，跟是不是液体关系不大；

+   第二，溶液中不同的分子可以直接相溶，乳液中的分子不可以，它们需要借助别的端来实现混合；

+   第三，溶液和乳液在生活中的应用十分普遍。做饭、洗菜、挑选化妆品，都需要用到这个模型。
