# 口诀：

完全在于“隆”与“屈”的把握，要练好“隆”必须在“宏观微观说话术”下功夫，“宏观微观说话术”打好基础，表现权威就是“隆”，指点迷津就是“屈”。再依此编排出步步夺心的“千——问”之术。

# 例子

| :--- | :--- |
