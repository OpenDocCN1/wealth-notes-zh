# 格局兵阵

格局兵法最重要口诀：我讲了这句话，或作了这个行为后，谁有主控权？如何看出谁有主控权：

+   谁向谁证明自己？

（A 向 B 证明自己，____有主控权，谁要谁的接受）
（B 希望 A 接受自己，____有主控权，谁需要谁）
（A 让 B 觉得 A 很需要 B，____有主控权，谁顺着谁的意思）
（A 在审定 B 的资格/条件，____有主控权，谁在审定谁）
（A 顺着 B 的意思，____有主控权）
