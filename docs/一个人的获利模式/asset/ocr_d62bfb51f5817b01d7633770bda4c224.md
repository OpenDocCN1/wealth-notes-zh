巴克斯體認到，雖然他喜歡軟體科技，但目前的工作做起來足夠的流動性，他需要更多的人實際往來。後來他跟雇主討論他的狀況後，轉接到另一個可以傳接電腦技術給其他員工的職位，工作滿足感立即提升。這個經驗讓巴克斯深切了解，關鍵資源如何與他個人商業模式的其他元素交互作用，相互影響：

# 興趣、專業與能力

在電腦方面，巴克斯有興趣，也有着長及能力，這些是重要的關鍵資源；也因此，直到他對全職工作徹底灰心之前，他都不覺得有自己探索的必要。且他開始深思，就發現了其他重要的興趣、專長與能力，特別是引導（facilitating）與教學（instructing）。這些關鍵活動在他先前的工作中都付之關如，使得牽絆和不滿等「軟」成本提高了。

# 個性

巴克斯知道自己個性中 有「程式設計師」 的常規型 那一面，但他也發現了自己 的社交傾向 稍微超越了他的常規型偏好。單純的程式設計工作讓他沮喪，因 為工作環境只符合了他個性的某 一面，即偏向制式、組織化且可預測的常規 傾向。

# 控制點

巴克斯喜愛玩電腦，卻從未認真地把自己定位為程式設計師，反而是同學、教授和同事情的美和肯定，幫他打造出「巴克斯是程式設計師」這塊招牌。這些啟動加上科學系統的一紙紙聘書，使得他自然地接受了「程式設計師」的這個身分，而沒有再去細想其他方面。接受這個定位，讓巴克斯把他的微問題歸結於外控點（雇主），而不是內控點（由於自己認識不足，造成關鍵資源與關鍵活動的搭配失當）。
