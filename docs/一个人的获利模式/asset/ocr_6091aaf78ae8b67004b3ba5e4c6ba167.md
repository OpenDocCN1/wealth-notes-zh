# 發現自我

「大部分的求職者找不到夢幻工作，並不是因為就業市場的情報不足，而是因為他們對自己的認識不夠。」四十年來最暢銷的就業指南《這樣求職才能成功》（What Color is Your Parachute？）的作者迪克·鮑利斯（Dick Bolles）說。夢幻工作很少是透過傳統求職方式得到的，它們更多是「創造」出來、而不是「找到」的。要有這樣的創造，需要很深入的自我認識。

然而，就像攝影師安迪拍的例子一樣，會開始認識真探索自我、省思職涯，通常都是因為面臨危機，例如失敗或創業失敗，要不然一般人很少會不斷地往內在探索，鏡子待你像大迴避自我中心。但鮑利斯不這應該認為，因為這幾週的探索，為的是要發掘「這個世界最需要我貢獻的是什麼」。 

此外，在危機發生前深沉入自我省思，不管是對你、對雇主或是對顧客來說都很有利。消極面而言，它能防止身心狀態因工作而耗竭，以及避免夢想破滅；積極面來說，當你處於滿足的狀態中，更能夠發揮所長去幫助他人。

然而，如果沒有危機當頭的迫切感，我們要如何進行有意義的自我反思呢？
