# 意識的力量

重點來了：重新設想現實，可以改變現實。

你所認知的任何事情，包括你的觀察、你的愛情、你的家庭和朋友，未必是真正的現實，賞，而只是你對現實的「理解」。這個理解只代表現實的一種可能性，只是我們觀看椅子的幾十種不同觀點之一而已，不是獨一無二的箇相。

顯然，我們感官所體驗的這個世界不是真實的，而是如同旁觀在《Are You Ready to Succeed》一書中所說的：

我們創造了這個世界，我們一種一瓦把它建造出來。我們按照我們的心智模式（mental model）設想出世界的模樣，然後再聽命行事地在其中生活。由此之後，我們照常過日子，未曾了解我們的心智模式只是建構在某種看法上，並非真相與事實。

問題在於，我們總是假設我們所理解的實相（如同內在對話一再強調的：「我的事業面臨失敗」、「老師討厭我」、「忌妒我的同事爭功 svo...）

疑過」等等），就是真正的現實。
