# 神祕的一句問談

以下是具有近乎神奇力量的問話，可以從臺灣通用的對話中，誘導出深人究辦；「關於……還有什麽是我應該知道的嗎？」

例如，以229頁艾美麗為例，她應該在訪談將結束時問瑪莉蓮：

「關於在貴公司這樣的組織中進行永續發展相關活動，還有什麼是我應該知道的嗎？」

為何這句問話如此有效？因為大多數專業人員冀對於自身領域的挑戰、機會及地落浮沉，都潛藏著所謂的「偏好理論」（pet theory），只要有機會，他們都很樂於分享這些看法。你只需要像個獵裝的獵隼般設個疑問、提出邀請，你們訪談對象將會不會分享其他的寶貴經驗及情況見解。
