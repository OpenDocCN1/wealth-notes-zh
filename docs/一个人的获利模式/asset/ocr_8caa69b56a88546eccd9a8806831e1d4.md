# 執行秘書

潔（Jet Barendregt）是資誠聯合會計師事務所（PwC）歐洲分部一位資深合夥人的執行秘書。

隨著業務成長，資誠新增了一些類似職位的職位，但新人流動率很高，她發現不僅要負責帶新人，甚至還要扛下更多的責任。在公司待了十年後，她雖然成為公司不可或缺的一員，卻覺得自己已有的專業及價值被視為理所當然。

因此，當老闆宣布搬遷辦公室，而且這會大幅增加她的通勤時間時，她決定要離開自己的個人商業模式。

她離開資誠並設立一家處理個人的服務公司，完全透過電子郵件、電話、Skype和雲端工具來服務客戶。她的關鍵創新及變動是「收入與好處」這一欄：用收費來代替薪水。

今天，潔必須通勤，有更多的時間分給小孩和追求個人興趣，而且收入比在資誠時高出三倍。此外，她還可以選擇客戶。「我的經驗顯示，你可以在增加收入的同時，還能降低成本。」她說，「所需要的只是承諾、信任，以及正確的商業模式。」
