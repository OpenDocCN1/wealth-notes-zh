# 如何測試你的商業模式

請跟你的潛在顧客會面，以便測試你在個人商業模式中所做的假設。如果對方的修建議確實有必要，請回去修正九大要素中相對應的部分（這就是前面提到的轉向）。然後再與其他潛在顧客重複這個步驟。

![](bbox=[0.49, 0.62, 0.57, 0.68])

一旦你的商業模式以可調整到定位後，要測試著去把它「賣」給顧客，來驗證它是否可行。如果顧客不買，你要 nt 測試著轉向（pivot），用他們不買的原因來修正商業模式。等到有顧客願意買單了，就表示你更賺錢是被公司鎖取雇用，只要你成為準創業伎者，準備尋找下一個顧客了。
