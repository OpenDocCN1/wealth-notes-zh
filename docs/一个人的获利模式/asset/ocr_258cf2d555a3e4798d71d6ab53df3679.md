# 你如何向客戶傳遞價值

# 問題

# 解決問題的起點

你提供的服務有哪些元素被顧客視為最有價值？

問顧客這個問題，他的回答可能會出乎你意料。把上一頁的顧客診斷問題再想一遍。

你的價值主張是否幫助顧客處理他們最重要、最需要完成的工作？

你是真的了解、抑或是只憑測這些工作？你能重新設想、重新定位或修正你的關鍵活動，讓它更聚焦在價值主張上嗎？

你能透過不同的通路來傳遞價值主張嗎？

你的顧客偏好現有的通路嗎？你能調整價值主張去適應其他不同的通路嗎？你的價值主張能否從服務轉為產品，以建立一個規模化的商業模式？

你樂於傳遞你的價值主張給顧客嗎？

若是，很好！若否，請重新檢視關鍵資源並考慮大幅整修你的商業模式。
