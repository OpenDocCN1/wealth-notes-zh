
# 關鍵活動

## 你做哪些事

關鍵活動（你做哪些事）是由關鍵資源所驅動的，換句話說，你所做的事情，自然跟「你是誰」有關。

想想你在工作中應該執行的主要任務，然後填入關鍵活動區塊裡。請記住，關鍵活動指的是那些你需要為顧客執行的各種價值或心智上的活動，但它們無法用來描述你的價值主張。

即便如此，為了要繪製你個人的商業模式圖，列出這些特定的任務仍然是一個值得你考慮的方式，同時也能幫助你深入考慮更關鍵的價值主張。

現在就列出這些任務。它們也許只有二或三個，但也可能有大、七個或更多。要提醒你要列出你母親必須做過的每件事都列出來，只要列出真正重要的活動即可，也是能夠凸顯你不同於其他人的那些工作。

# 目標客層

你要幫助的是哪些人

接下來，將目標客層（你要幫助的是哪些人）加到你的個人商業模式圖上。回想一下先前提到的，上述的「顧客」有兩種：一種是那些付費過的，所謂「顧客」有兩種：一種是那些付費買好處的人，另一種是那些不用付費就能獲得好處的人（因為有第一種顧客的資助）。

以個人角度來說，你的顧客或者客戶就包括了那些在公司裡必須仰賴你的協助來完成工作的 人（如果你是自由工作者，可以直接將自己願為公司，所服務的對象就是顧客）。

這包括你的老闆、直屬主管，以及其他直接影響你薪資的那些人。他們 收你的工作、同寮公司支付報酬給你，因此他們形成了一組顧客。

所以，請在目標客層的那個區塊中，寫下你直屬主管的名字。

請再想想，你還要對哪些人報告或負責？把他們的名字或角色也寫在同一個區塊中。

然後回過頭來再想想：在工作上擔任了哪些角色？是否也為組織裡的其他人提供服務？是否將工作交接給同事（以接續完成）？

哪些人在工作上需要仰賴你的協助，或因為你的工作而受惠？這些人也許不是直接給你報酬的人，但是你之所以能持續拿到薪資，取決於你的整體工作表現，也就是你「服務」特定同事項的品質。

比如說，如果你是IT部門的員工，就代表你必須對所謂的「內部顧客」了解得很清楚！在公司裡面，還有其他人或其他部門，是你應該視之為「顧客」的嗎？也許是某個專案領導人或是其他專案成員？如果有的話，請把他們的名字寫下來！

接著，你要考慮的是那些與公司往來的企業，也就那些使用你公司的服務或購買你公司的產品的客戶。你有直接跟他們打交道嗎？即使沒有，你也可以將他們視為你的目標客層。此外，你有跟公司內部任何的關鍵合作夥伴配合過嗎？或許他們也值得列在你的顧客清單上。

最後，想想那些你因工作而間接服務到的處大社群，包括了社區或城市，或是因相同的商務、專業與興趣而聚集的團體，以上這些也可能是你的目標客層。

# 價值主張

你如何幫助（顧客）

現在該來定義一下你所提供的價值了。所謂「價值主張」，就是你如何幫顧客完成他們原本要做的工作。如同前面所說的，這是在思考你的職業時最重要的一部分。

定義價值的一個好方法，就是問自己以下這些問題：顧客「雇用」我去執行什麼工作？如果我完成這項工作，顧客會得到什麼好處？

就以我們先前提到的捷飛絡為例，這家公司的價值主張，並非我們表面上看到的、輕鬆更改機油（關鍵活動）的工作；而是由專業人員提供協助所需來的種種好處：解決車子的問題、避免劈割り、減少麻煩。

理解關鍵活動為顧客提供了哪些價值，是個人商業模式最重要的部分。

無論是組織或個人的商業模式，實務上最容易搞錯誤的，就是把關鍵活動當成價值主張。因此，思考所從事的工作或所提供的服務時，要把服務的「內容」和顧客因此得到的「好處」區分清楚。比如說，祕書的工作（關鍵活動）不外乎安排主管的行程、協調會議（人事時地）、處理文書行政等，而其提供的價值主張則是讓老闆（顧客）在日常行政上無後顧之憂，可以專注在營運上。

# 通路

別人怎麼知道你的 & 你透過何種方式服務

一旦你能清楚定義目標客群和價值主張，就已經完成給個人商業模式的大部分工作了。按下來，我們要繼續來關心其他部分。

在這項中，我們要談的是商業術語「行銷流程」(Marketing Process)的五個階段。要描繪這五個階段，最恰當的方式是詢問以下這些問題：

+ 1. 潛在顧客如何發現你能如何幫助他們？
+ 2. 他們如何決定是否購買你的服務？
+ 3. 他們將會用何種方式購買？
+ 4. 你將如何遞交顧客所購買的服務或商品？
+ 5. 你將如何追蹤以確保顧客滿意？

想要定義通路，最直接的方式就是問你自己：你要「如何遞交」顧客所購買的服務或產品，其中可能包括： giao 書面報告、畫面訪問、談、程式放在伺服器、畫面或線上簡報，或是重輔運送實體商品。

但是，就如同上述的五個階段所呈現的，以通路這個要素而言，更有而且重要的議題是：如何讓潛在顧客知道你這個人，以及你的價值主張？是口耳相傳？網站或部落格？文章或演講？電話拜訪？電子郵件或線上討論區？還是廣告？

通路對於個人商業模式相當重要，原 於：1) 你必須定義「如何幫助顧客」(價值提案)，才能向他們傳達這項服務；2) 你必須傳達「如何幫助顧客」，以銷售你的服務；3) 你必須銷售「如何幫助顧客」，以獲得報酬。

# 成本結構

你需要付出什麼

成本是指為了工作所付出的時間、精力及主要的金錢支出。

列出每一項尚未回收的「硬」成本，例如：

# 姓名：馬克·戴辛格 (Mark Degginger)

## 人物：廣志 AE
個案研究：成本結構
問題：關鍵活動成本

「當馬克（Mark Degginger）走進我的辦公室時，整個人散發的感覺強烈地告訴我說：他找不到工作了。」喉嚨的問題法則、芙加（Fran Moga）說。「他的情況很糟，有六位數的年薪、漂亮的房子和一艘小艇，卻必須每天拋棄著去上班，還得用長時間的午餐來撐過難熬的下午。」

「他在一家非常獲利等向的廣告公司工作，工作壓力很大而且競爭殘酷。他還有背痛的毛病，明白此我年輕，看起來卻比我老。」

「最大的問題是，雖然他很能幹，但他的工作卻違背了他的核心價值。他擁有各種成功的標記，但想追求的，卻是更高尚的理想。」

「所以，有一天我問他：『為什麼你還要繼續做這樣的工作？你曾經想過你要付出的代價嗎？』他什麼都沒說就離開了，但下次見面時，他似乎想通了。『我付出的代價包括關係、健康，還有生活沉悶。』他說。」

「再見到馬克時，他還沒開口，我就知道這事情改變了。他看起來神采奕奕，整個人也變輕鬆了。」

「我問他：『你好嗎？』他說：『非常好。』已經辭掉廣告公司工作，他，在和妻子達成共識要簡化生活後，目前在一家非營利組織工作，負責培訓弱勢及殘障人士。他的收入比以前少很多，但快樂卻比以前多很多。』

# 即使是顧客，也有他們該做的事

## 人物：
博士生

克莉絲（Chris Burns）是個新聞工作者，有扎實的訓練及媒體經驗，她一路看著傳統出版業的商業模式（包括她所服務的公司）衰敗下來。當她被資遣時，她已經在念博士班，目標是在取得學位後改行當教授。

基於對企業永續這個研究主題的興趣，同時也經由博士班教授職員網路的協助，克莉絲找到了一份兼職工作：替教授編輯學術論文。出版宣告的，她發現自己非常喜歡這樣的工作。

有一天，她體認到自己真正的工作不單只是個編輯，而是更有價值的事：「讓顧客的論文能順利在首屈一指的學術期刊上發表。」所以，她決定大幅調高自己的鐘點費，並且把查找資料的研究時間也納入計費。

結果呢？她有了更多的顧客。

回顧收時路，克莉絲指出自己原先的商業模式犯的兩個常見錯誤：

## 貓把關鍵活動當成價值主張

克莉絲貓把編輯及改寫的工作（關鍵活動）當成自己為顧客提供的價值。她應該站在一個制高點跳脫求看，先界定顧客需要達成的工作，再從那個任務來定義她所提供的價值。

## 貓把所有任務都攬在自己身上

起初，克莉絲把案子一手包，將所有事情都攬在自己身上，反而使她的工作被顧客窄化成「潤飾及改寫」。當她開始提高顧客，發表論文是他們自己的任務，而她是協助他們完成任務的人，她的價值及聲譽才能得以攀升。
