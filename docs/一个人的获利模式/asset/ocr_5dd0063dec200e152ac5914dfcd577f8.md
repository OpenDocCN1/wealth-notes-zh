# 品牌或身分地位

有些公司提供的價值是幫客戶打造尊爵不凡的形象。全球各地都有人願意高價購買路易·威登（Louis Vuitton）的奢侈皮件及其他時尚產品，就 是因為為 LV 將品牌打造॥成品味高尚、著重以品質的形象。

# 降低成本

有些企業可藉著幫其地公司降低成本而增加營收。例如，大部分的公司會發現，與其自行購買並維修電腦伺服器和高端電腦信設備，更划算的做法是外包給第三方遠端伺服器（雲端服務）廠商。

# 降低風險

企業型:nil的客戶當然想降低風險也很有意，尤 其是與投資相關的風險。例如 如 IT 市場與顧問公司顧問（Gartner），便藉由銷售研究報告和諮詢服務來幫其他公司項增加科技支出的潛在效益。
