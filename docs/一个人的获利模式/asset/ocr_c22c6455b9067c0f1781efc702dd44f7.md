# 通路

# 別人怎麼知道你的 & 你透過何種方式服務

一旦你能清楚定義目標客群和價值主張，就已經完成給個人商業模式的大部分工作了。按下來，我們要繼續來關心其他部分。

在這項中，我們要談的是商業術語「行銷流程」(Marketing Process)的五個階段。要描繪這五個階段，最恰當的方式是詢問以下這些問題：

+   1. 潛在顧客如何發現你能如何幫助他們？
2. 他們如何決定是否購買你的服務？
3. 他們將會用何種方式購買？
4. 你將如何遞交顧客所購買的服務或商品？
5. 你將如何追蹤以確保顧客滿意？

想要定義通路，最直接的方式就是問你自己：你要「如何遞交」顧客所購買的服務或產品，其中可能包括：¿ giao書面報告、畫面訪問、談、程式放在伺服器、畫面或線上簡報，或是重輔運送實體商品。

但是，就如同上述的五個階段所呈現的，以通路這個要素而言，更有而且重要的議題是：如何讓潛在顧客知道你這個人，以及你的價值主張？是口耳相傳？網站或部落格？文章或演講？電話拜訪？電子郵件或線上討論區？還是廣告？

通路對於個人商業模式相當重要，原<|message|>在於：1) 你必須定義「如何幫助顧客」(價值提案)，才能向他們傳達這項服務；2) 你必須傳達「如何幫助顧客」，以銷售你的服務；3) 你必須銷售「如何幫助顧客」，以獲得報酬。
