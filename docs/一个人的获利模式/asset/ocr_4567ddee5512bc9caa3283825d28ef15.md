# 問題

# 解決問題的起點

你樂於服務那些有的顧客嗎？

若是，很好！若否，想像一下你「理想」的顧客具備了哪些特質。你能在目前的工作領域發現這些樣的人嗎？如果不能，考慮修正你的商業模式圖吧！

你最重要的顧客是誰？

說明為什麼這個顧客如此重要，他帶來的是否直接利益或間接利益？還是兩者都有？適合他為他提供新的或獨特的價值主張嗎？

這個顧客真正需要完成的任務是什麼？他也沒有更上層的理由或動機需要用到你的服務？比如說，你的直接顧客是否為另一個更大的、任務更重要的顧客提供服務。

你是否可嘗試重新設想、重新定位或修正你的價值主張，以協助你的顧客成功達成更大的任務？

服務這個顧客所需費所費不賺嗎？倘候這個顧客讓你抓狂嗎？

服務這個顧客的成本（包括間接成本），是否高到很不值得？收入（或好處）是否太低？放棄（或放棄）這個顧客的後果，你能承擔嗎？檢視價值主張、成本及收入與好處相關的診斷問題，以找出答案。

你的顧客是否把需要完成的工作和關鍵活動混為一談了？你自己呢？

有時候顧客自己未必能清楚界定什麼是需要完成的工作，你能幫助他們界定清楚嗎？不合格提價？若是，能否重新定義或修正關鍵活動以大幅提升價值主張？

你需要新的顧客嗎？

若是，考慮把你的顧客關係從維繫（retention）改成吸收（acquisition）。你需要進行更多行銷或業務活動嗎？有必要增加進貨方面的能力嗎？是否需要改造關鍵合作夥伴？是否需要花大功夫讓你吸收新顧客的關鍵合作夥伴？
