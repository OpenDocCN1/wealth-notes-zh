# 63

| 團隊研究：目標客層 | 人物：婚禮攝影師 | 摘要：重寫客戶的故事 |

崔娜（Trina Bowerman）參加了「個人商業模式」的工作坊，在上亮商業模式之後，她去到講師面前，說她實在找不到講師才講的話，但不知道如何套用在自己身上。

> 講師問：「你從事的是什麼樣的工作？」

她回答：「我是婚禮攝影師。」

「所以，你是用照片來講述婚禮的故事。」

「嗯，從某方面來說……算是吧！」

「那麼，除了婚禮之外，你何不嘗試看看去講述其他故事呢？」

停了片刻，崔娜說道：「謝謝你，今天晚上我會興奮得睡不著了。」
