# 顧客關係

組織必須清楚定義目標客屬所偏好的關係維持形式，例如：是不是個別服務？自動化或自助式？單次服務或會員式？

此外，組織也必須清楚顧客關係的主要目的和策略：是要爭取新顧客？維持既有顧客？還是從現有顧客中獲得更多收益？

以上不論是哪種策略，都需要與時俱進。以行動通訊產業為例，早期 的電話公司為了開發新顧客，通常採較積極的手段（例如提供免費手 機）。然而，當市場漸趨成熟，他們會轉而將重點移到留住現有客戶， 並設法提高每個顧客的平均收益。

還有另一個重點：現在有更多公司（像是亞馬遜、YouTube、Business ModelYou 及 LLC）會跟顧客一起創造產品或服務。
