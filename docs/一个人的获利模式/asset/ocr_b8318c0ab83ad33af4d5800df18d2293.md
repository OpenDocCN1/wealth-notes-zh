# 收益流

組織必須：1) 找出每個且標<|start|>顧客真確意付錢購買的價值；2) 用目標顧客偏好的方式接受付款。

收益流有兩種類型：1) 由顧客支付的一次性收益；2) 透過產品、服務或售後服務持續收取的經常性贌用。以下是幾個特定類型的收益流：

# 資產銷售

這是指顧客購買某項資產品的所有權。例如豐田（Toyota）銷售汽車，顧客購買後，就可任意駕駛、轉賣、拆卸，甚至毀損。

# 租賃

這種方式是指顧客付費取得在一個固定期間內，其項特定資產的獨立使用權，例如飯店房間、公寓或是出租汽車。承租人不必負擔所有的全 部成本，而出租者則享有經常性收益。

# 服務使用費

這種收益流是透過顧客使用某種服務的「量」而產生的，用越多就付越多。例如，電信公司依據使用時間計費；物流配送公司根據包裝分量收 多。
