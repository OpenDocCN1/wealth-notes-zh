# 把自己推銷給決策者

相中潛在顧客後，你的首要目標就是跟該組織的決策者面談，向他推銷你的個人商業模式。盡量透過人脈去創造見面機會，並在會談過程中，以專業態度將重點放在你能幫對方的地區。你但目標當然是說服對方成為你的客戶，萬一對方回絕，你也可以得知問題出在哪裡，並重新調整你的商業模式。

# 網路行銷人員

![](bbox=[0.57, 0.09, 0.73, 0.21])

畢業後，查理·霍恩（Charlie Hoehn）發現自己的「菜市場」企業學位根本找不到工作。與其從友人的人脈下手，他選擇直接面晤標準階層人士：他拿起電話打給素不相識的暢銷作家和自己仰慕的製作成人，提供免費的網路行銷服務。這個策略奏效了，而且很快就遇遇到「有給職」，他的客戶現在包括行銷大師賽斯·高汀（Seth Godin）、暢銷作家姬瑟薇·西·費里斯（Timothy Ferris）及塔克·麥克斯（Tucker Max）等人。

甚量透過最友善的推薦人來接近策者。即便你的人脈圈中沒有直接為潛在顧客工作的 人，至少現在你應該對目標產業有了足夠了解，也與那個圈子的人更接近距離了。

從另一個角度來說，未經任何人居中介紹，直接而勇敢的與決策者接觸，也有可能是最有利的選擇，但這牽涉到產業的性質與每個人的個性。

一旦能跟決策者聊緊上，你可以採用以下類似的說法：「我認為你有一個明顯的機會可以 ______ ，而我正好有一些你可能覺得很給力的想法，可以見面談嗎？」

如果到目前為止，你一直都能夠按照商業模式的測試原則進行，獲得對方的溫暖回應應該不會太困難。

無論你採用何種方式來跟決策者接觸，來 自全美營銷商協會（National Sales Executive Association）的這份調查結果都可能改變你的行為：

+   • 2%的銷售在第一次接觸成交
• 3%的銷售在第二次接觸成交
• 5%的銷售在第三次接觸成交
• 10%的銷售在第四次接觸成交
• 80%的銷售在第五到十二次接觸成交

所以，不要因為你的第二次、第三次或第四次嘗試無功而返就放棄，鑽而不捨才能贏得機會。
