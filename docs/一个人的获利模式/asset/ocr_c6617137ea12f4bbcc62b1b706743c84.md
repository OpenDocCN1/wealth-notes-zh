# 目標客層

目標客層是一個組織之所以存在的最重要原因。倘若沒有付費的顧客，沒 有組織能夠長期生存下來。

每個組織都為一個或多個特定的目標客層服務。

所服務的對象若是組織機構成員，就是「企業對企業」（b-to-b）；若是消費 者，就是「企業對消費者」（b-to-c）。

有些組織會同時服務「付費」和「非付費」的顧客。舉例來說，大部分的 贅費用戶並沒有支付任何費用，但是如果沒有這些數以百萬計的非付費用 戶，險善就無法銷售服務給廣告主或市場研究機構。因此，一個商業模 式是否能辦成功，非付費顧客也是非常重要的因素。

# 有關目標客層必須記住以下幾點：

+   • 不同的顧客會需要不同的價值主張、通路，或不同的顧客關係。
• 有些顧客要付費，有些則不必。
• 組織從某個特定的目標顧客所獲得的收益，往往比某些他們的目標客層要多 很多。
