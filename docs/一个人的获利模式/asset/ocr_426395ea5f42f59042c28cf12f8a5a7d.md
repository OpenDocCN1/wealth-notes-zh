# 案例2

我開了一家公司，專門替想要進軍亞洲——尤其是日本——的企業做市場研究
究與顧問。辛苦工作了六年之後，有人要用一筆好幾百萬美元的金額收購我
的公司。還對我來說，是想都沒想過的一件事，我歷跟不曉得原
來還有「賣公司」這回事。

總之，賣掉公司之後，我還剩三筆房貸，存了孩子們的教育基金，帶著全家
人去旅行，然後把剛下的錢拿去做最安全的投資。但即便如此，我仍覺得面
對一個人生問題：這輩子，按下來怎麼過？

而且，正因為我已經卸下經濟上的重擔，不必再為了餬口而工作，這個問題
也顯得格外重要起來。在尋找答案的過程中，我越來越明白一件事情：工作，
不只是為了賺錢、獲取財務上的獨立而已。

我相信大多數事業成功的創業家，都有同樣的體悟。我跟好多同樣賣掉公司
的創業家聊過，他們出售的金額有高有低，從一、百萬美元到超過四千萬美
元，但是沒有一個人告訴我，他們工作的最重要目的是賺錢。

通常，那種一心只想賺大錢的人，很難保持經營的熱情，因此遇到困難往
也很難撐下去。相對的，成功創業家比較感心的是如何為顧客創造價值。要
知道，創業精髓的關鍵不在於你，而在於你是否能有效地面服務顧
客。
