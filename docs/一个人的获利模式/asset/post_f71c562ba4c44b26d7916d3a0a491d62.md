
# 計算每年的價值

許多公司無法準確地衡量每一種產品在公司的價值和成本，假設公司的毛利率是40%，如果員工作為單個工... [1]?

Q：為了要支付4,000美元的月薪，公司必須創造多少銷售額？假設所有報酬項目是新成本的25%。

# 為什麼公司通常應該

業界有一種試算方式：不管員工薪資多少，公司都必須多創造兩倍於該員工薪水的營收。這就像是一條既定律。

因此，雇用一名年收入48,000美元的員工，公司需要增加96,000美元的業績來消化他的所有人事成本。

不過，這個基礎定律會隨著產業及毛利率而異，比如說，有某些員工的人事費可能需要三倍於年薪的業績才能消化。

# 你對組織的價值

請想想自己一點，如果你自認應該年薪60,000美元，最好能打開心自問一下：

雇用我就可以持續為公司帶來每年120,000至180,000美元的營業額嗎？

當你考慮經營一家企業所需的成本，以及決定價錢後所隱含的這點，就很容易理解為什麼物價會如此昂貴了。

收入來的錢減掉支出付出去的錢之後所剩下的部分（可能為負值）。

# 損益表 Income Statement
企業或組織在一段期間內收入及費用的匯總，通常以一季或一年為期。

# 銷售額 Sales
銷售商品或服務所得到的錢。

# 收益 Revenue
銷售額加上利息、租金、權利金或其他非勞動所得。

# 毛利 Gross Margin or Margin
營收減去銷售成本（商品或服務成本），通常以占銷售收入的百分比表示。

# 銷售成本 Cost of Goods or Cost of Sales
出售商品或服務的直接成本。

# 損益平衡 Breaking Even
總收入（收入來的錢）等於總成本（付出去的錢）。

# 總薪資成本 Fully Loaded (Salary) Cost
雇用一名員工的全部成本，除了薪資外，還包括勞健保、退休金及法定稅費等。

多年以來，賽德常與朋友深入討論資源回收與垃圾處理，她們都非常關注環境議題，還把兩人對話搞笑地命名為「垃圾話題」。後來當賽德從客戶服務訓練師的工作被資遣時，她認定「垃圾話題」應該不只是打發時間的消遣，而是她每天的工作。她決心找到能教別人如何做資源回收的工作，也就是她口中「能產生影響的工作」。

賽德立即開始測試這個全新的個人商業模式。
她無法找到顧客願意付錢來做資源回收的訓練，所以她重新檢討她的計畫，並在有機超市的熟食部門找到工作，以便增進處理廢棄物的相關可靠知識。
由於她跟任何資源回收的組織都沒有往來，所以她親自製作了一款「垃圾話題」電話卡，用以說明自己的人生目標。

隨著一個組織對她的「垃圾話題」產生興趣，賽德依據產業專家的回饋來重新調整她的商業模式，也參與跟自己目標接近的專案。終於有一天，引起了市政府單位永續發展小組的善意回應。

現在，賽德已經如期成為一名全職的資源回收協調員，在住家附近的城市快樂工作。

如果你像賽德一樣，正在規模重大的搬遷換換，那麼測試商業模式的要素及可行性，是非常重要的。在紙上作業階段，個人商業模式的要素中包含許多未經驗證的假設：對你來說是做好的事，但未經測試，能否幫助到別人，不是你說了算。

想知道你的個人商業模式是否行得通，可以去找你的「潛在顧客」來測試。最好的測試方式，就是仿效一般企業測試新產品或新服務模式的方法：與潛在顧客對話。

我們建議採用創業大師史蒂夫·布蘭克（Steven Blank）發展出來的客戶開發方法論，他描述如何找出顧客需求，並讓他們願意花錢購買。這個顧客開發能重複運用的過程之所以重要，是因為很多公司（以及不成功）的創業者）在還沒徹底了解顧客之前，就全心全意在開發及銷售商品或服務了。

例如，當摩托羅拉（Motorola）還沒搞清楚顧客是否需要一個全球衛星電話系統前，就浪費了50億美元（對，50億）開發及推出通訊服務系統「銥計畫」；同樣的錯誤也發生在RJR納貝斯克公司，他們在Premier和Eclipse牌無煙香菸上損失了4.5億美元：這個點子不抽菸的人喜歡，問題是他們的顧客（抽菸的人）根本不在乎。

聰明的創業家會徹底測試及評估組織的商業模式，然後才進行動員。我們如果學習他們的方法來驗證個人的商業模式，成功機會也能大大提高。

# 如何測試你的商業模式

請跟你的潛在顧客會面，以便測試你在個人商業模式中所做的假設。如果對方的建議確實有必要，請回去修正九大要素中相對應的部分（這就是前面提到的轉向）。然後再與其他潛在顧客重複這個步驟。

![](img/495607eaa94eb1caeeb01e66aa6c08a9_226_0.png)

一旦你的商業模式調整到定位後，要測試著去把它「賣」給顧客，來驗證它是否可行。如果顧客不買，你要測試著轉向（pivot），用他們不買的原因來修正商業模式。等到有顧客願意買單了，就表示你的商業模式被公司選取雇用，只要你成為準創業職者，準備尋找下一個顧客了。

![](img/495607eaa94eb1caeeb01e66aa6c08a9_226_1.png)

![](img/495607eaa94eb1caeeb01e66aa6c08a9_227_0.png)

要發掘顧客，得從布蘭克所謂的「走出辦公室」開始，生涯專家稱之為「建立人脈」。他們其實說的都是同一些事：跟潛在顧客、專家，或是能幫你引見其他的人脈關係建立並紮根，並透過雙方面對話來了解你的商業模式能否行得通。

記住，個人商業模式圖的九大要素中，很多都是你單方面的假設，都需要經過顧客檢驗，例如：

+   • 倘若要提供你所承諾的價值，顧客對你擁有關鍵資源及／或關鍵合作夥伴是否信任？
• 顧客在乎你想幫他們代勞的工作嗎？他們會願意為這項的協助，付出你在收益欄上填寫的代價嗎？（例如營銷，她一開始根本找不到這樣的顧客）

+   • 你急於得起來執行這個商業模式所需要的成本嗎？
• 顧客希望透過什麼管道得到聯繫及服務？你提出的顧客關係模式適當嗎？

要回答上述這些問題，唯一的方法是親自前往潛在顧客工作和生活的地方，跟他們面對面。

有效發揮潛在顧客的關鍵，在於避免「推銷」。雙方會面的重點，應該從客戶的觀點來驗證你商業模式裡的假設。如同布蘭克所說的，不要說服顧客去接受你認為他們所面臨的問題與機會。

從友善的第一次接觸開始：跟家人、朋友、鄰居、同事、教友或專業組織的成員談談，或者跟你人脈圈中的任何人聊聊。告訴他們你正在根據新目標調整整體業務生涯。

問問他們是否認識可能對你的目標有興趣的人，盡可能蒐集更多的人名和聯絡資訊，這些新得到的人名都是你的推薦人。接著，瞭解你的新推薦人。關係的基本原則是：對方若是非朋友的朋友，至少也是透過認識的人居中介紹。要避免「陌生拜訪」，坊間未經任何人介紹就直接找上對方。

# 第一次接觸的說法

深吸一口氣，拿起電話，當試以以下的說法：

「瑪莉蓮您好，我是艾美麗，是奚涉莉介紹我跟您聯絡的。我的專業是物流通管理，最近對在公司內部做保護回收及永續發展很感興趣。我對您是這方面的專家，所以想請教您跟負責公司是如何處理這方面的議題。不知道您下週是否方便撥出20分鐘，我們一起喝杯咖啡，也許週二或週三下午？」

大多數的專業人士都喜歡和其專業人士討論有共同興趣的話題。所以，請拿起手機打個電話，設定會面事宜。如果對方有所猶豫或詢問細節，向他們說明跟你見一面的好處：「我認為你可以就永續這個議題提出精闢見解，而我也樂於分享一些原始觀點和個人觀點。不知您下週二或下週三傍晚方便見個面嗎？」

如果對方同意，當下就設定見面時間。如果不同意，請他推薦適合人選，並感謝他撥出時間。然後，繼續打電話給下一個。這就是你要做的事情。許多人覺得這項工作電話似乎很痛苦，然而，如果你能堅持即使或甚至很痛苦，好事就會發生。打個10通電話，

這裡有一些提示句，可以讓你跟訪談對象迅速開始討論，並協助你了解對方個人或公司的商業模式：

「請問你的是如何進入__________領域，又是什麼領域帶領你進入__________公司？」

「你的投資目標是__________，請問你要如何避險？」

「在__________方面，最能配合你的困難和顧慮？提供所需資訊，還需政府或在什麼？」

「你對間廣蓋率高效率？」

如果運氣好，你的訪談對象可能會提及（或甚至提供）他正在進行的工作、關鍵夥伴，或其他商業模式的其他層面。若是如此，你可以進一步釐清一些問題並重述對方的想法，向對方確認（之所以要現在釐清，其組織）的商業模式有多少可行性。

是因為接下來的關注點會放在研究上，而並準備與這個客戶合作案件，而不是再去回想他說過什麼）。同樣的，對方也可能會詢問你的價值主張為何，或商業模式中的其他層面。

假如雙方相談甚歡，你可以擬提出合作的建議。如果能進行到這一步，表示你可以用開始更深入談話內容，包括更專業的說明你將如何提供協助，以及計酬收費方式（參考第8章）。

如果你覺得書面提案比較合適，可以告訴你希望給你書面提案的機會。要展現你對潛在顧客的目標有高度興趣，並把它自己定位為解決方案的一環，這樣做將會拉近你和潛在顧客的距離。

每次會面之後，仔細思考你所學到的。如此一來，你會更清楚自己的（以及訪談對象或其組織）的商業模式有多少可行性。

# 神奇的一句問談

以下是具有近乎神奇力量的問話，可以從台灣通用的對話中，誘導出深入探討；「關於……還有什麽是我應該知道的嗎？」

例如，以229頁艾美麗為例，她應該在訪談將結束時問瑪莉蓮：

「關於在貴公司這樣的組織中進行永續發展相關活動，還有什麼是我應該知道的嗎？」

為何這句問話如此有效？因為大多數專業人員都對於自身領域的挑戰、機會及發展浮沉，都潛藏著所謂的「偏好理論」（pet theory），只要有機會，他們都很樂於分享這些看法。你只需要像個獵裝的獵隼般提出疑問、提出邀請，你們訪談對象將會不自覺分享其他的寶貴經驗及情況見解。

# 關鍵的決策

你本來想成為正式員工或外包人員，卻可能 會在測試個人商業模式時發現，或許開創新 事業才是你更好的選擇；反之，你原本有心 創業，但可能發現屬於員工的選擇更適合於你目前 的條件。

無論是哪一種情況，你都要面臨創業與否的 抉擇：應承受風險開創事業，還是選擇在 大組織中尋求適合自己商業模式的位置？

這個問題其實已經超出個人商業模式的範 疇，但是我們還是在此提供兩個想法：1)在決 定開創自己的事業之前，可先去閱讀創業 教父麥克．葛伯（Michael Gerber）早年的著 作《譯：創業的迷思》（The E-myth Revisited）。2)大部份的人會發現，閒人和專業上的成功，並不是非創業不可。 （但話說回來，會看這本書的人不在這些「大 部份的人」之中！）

# 如果你個人的商業模式得不到共鳴， 怎麼做？

當你分享自己的商業模式時，你的聽眾是否 全神貫注、坐直脖子？如果不是，有幾個因 素需要你再多踩踏一下。

你的商業模式是否有強烈的感染力？如果沒 有，請確保自己所使用的語言文字必須簡 單、易懂，而且在你所針對的專業環境裡是 合宜的。有時候，好的文章會達到戲劇性 溝通效果。

你的商業模式能否處理真正的經濟問題或機 會？很少有組織會單純區分為社會或政治理由 而花錢，請重新思考你的商業模式如何協助 客戶的經濟層面。

你對你的商業模式有足夠的信心而且令人信賴 嗎？顧客對你的動機、經歷、專業及能力 （關鍵資源）是否有信心，認為足以用來實現 你的商業模式？如果你不確定潛在顧客看你，開口問對方吧！

2. 安排限制資源會面
3. 提供協助該組織完成特定工作

想研究你相中的潛在客戶，有以下幾個途徑：參加商展或產業活動、跟專家或分析師聊聊、拜訪「鄰近」產業的公司行號，以及閱讀相關產業的專家著作或熱門出版品。你們的目標是把自己放在潛在顧客的位置，學著透過他們的眼晴來看世界及你自己。

然而，你的中心還是要放在你的「祕密武器」上，亦即你理解、描述及分析商業模式的能 力。要了解你的潛在顧客，有什麼方式會比繪製商業模式更合適？

> 知識獲取「的入資料」

美國證券交易委員會有一個電子化數據收集、分析及檢索系統（EDGAR數據庫），包含很多上市公司的資料，是投資人、MBA、產業專家的私房寶庫。但台灣的官方機構，除了冷冰冰的財報（雖然很重要）外，並不容易找到我們想要的產業資訊，因此直接用Google公司名稱、產業或專業領域搜尋而更容易下手，另外也可用前面提到的人脈方法，找到內行人當面請教。

從幾個可能客戶中，你可以挑選一、兩個為他們繪製商業模式圖，並試著新增、移除、擴展或減少九大要素的內容。

盡量將價值主張定義得越簡單明白越好，並且找出哪個要素可能是痛點。想像這些客戶可能面對的競爭壓力，他們可能調整商業模式來有效面對嗎？（有時候，他們的競爭者可能也是好的潛在客戶。）

一般來說，財務是大家普遍的痛點：大部分的約束都希望增加收益或降低成本。盡量把雇用的你的所有好處理量化（可以不用太精準），強調你的個人價值主張為對方帶來那些正面經濟效益。

當你為潛在顧客繪製商業模式圖時，可以把你能幫助他們做的那個工作（同時也是對方必須完成的工作）當成起點，然後再一個個倒推出來：什麼價值主張可以協助這個客戶完成這項工作？你可以從哪些關鍵活動來提供這些價值主張？你有必須具備的關鍵資源嗎？如果沒有，能從關鍵合作夥伴那裡取得嗎？你能否說明外部力量會如何影響客戶的商業模式嗎？你能幫他們調整嗎？現在或許商業模式圖發揮他的思維力量，看它能為你的潛在顧客以及你自己分析到什麼程度。

# 把自己推銷給決策者

相中潛在顧客後，你的首要目標就是跟該組織的決策者面談，向他推銷你的個人商業模式。盡量透過人脈去創造見面機會，並在會談過程中，以專業態度將重點放在你能幫對方的領域。你但目標當然是說服對方成為你的客戶，萬一對方回絕，你也可以得知問題出在哪裡，並重新調整你的商業模式。

# 網路行銷人員

![](img/495607eaa94eb1caeeb01e66aa6c08a9_235_0.png)

畢業後，查理·霍恩（Charlie Hoehn）發現自己的「菜市場」企業學位根本找不到工作。與其從友人的人脈下手，他選擇直接面晤標準階層人士：他拿起電話打給素不相識的暢銷作家和自己仰慕的製作成人，提供免費的網路行銷服務。這個策略奏效了，而且很快就獲得「有給職」，他的客戶現在包括行銷大師賽斯·高汀（Seth Godin）、暢銷作家姬瑟薇·西·費里斯（Timothy Ferris）及塔克·麥克斯（Tucker Max）等人。

儘量透過最友善的推薦人來接近決策者。即便你的人脈圈中沒有直接為潛在顧客工作的 人，至少現在你應該對目標產業有了足夠了解，也與那個圈子的人更接近距離了。

從另一個角度來說，未經任何人居中介紹，直接而勇敢的與決策者接觸，也有可能是最有利的選擇，但這牽涉到產業的性質與每個人的個性。

一旦能跟決策者聊緊上，你可以採用以下類似的說法：「我認為你有一個明顯的機會可以 ______ ，而我正好有一些你可能覺得很給力的想法，可以見面談嗎？」

如果到目前為止，你一直都能夠按照商業模式的測試原則進行，獲得對方的溫暖回應應該不會太困難。

無論你採用何種方式來跟決策者接觸，來 自全美營銷商協會（National Sales Executive Association）的這份調查結果都可能改變你的行為：

+   • 2%的銷售在第一次接觸成交
• 3%的銷售在第二次接觸成交
• 5%的銷售在第三次接觸成交
• 10%的銷售在第四次接觸成交
• 80%的銷售在第五到十二次接觸成交

所以，不要因為你的第二次、第三次或第四次嘗試無功而返就放棄，堅持而不捨才能贏得機會。
