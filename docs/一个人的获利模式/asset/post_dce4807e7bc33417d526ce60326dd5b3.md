
# 幫助他人，也幫助自己

# 人物：部落客

「多年來，我一直是個強迫性消費者」J.D.羅斯說，「當我跟老婆賣下一座有百年歷史的農莊時，終於踢到鐵板，把錢花光了。」J.D.的工作是銷售（工業用）特製頑皮紙盒，但他焉終熱中於自己成為作家寫作，現在他破產欠債，決定要重新改造自己。

他閱讀手邊所有關於個人理財的出版品，整理成一篇文章〈慢慢變有錢〉（Get Rich Slowly）發表在他的部落格上。這篇文章加上J.D.個人親身實踐的承諾，在網路上引起了讀者的共鳴。一年後，他推出了以「慢慢變有錢」為名的個人理財部落格。「一個人可以靠寫部落格養活自己，這是我從來沒想過的事。」他回想，「我那時的想法只是想幫別人。」

但是網路上市收入成長了，然後「慢慢變有錢」的盈利追上了他在紙盒公司的薪水。於是，他決定採用新的個人商業模式，辭掉工作，成為專業的部落客。「那是我一生所做的最好決定，」J.D.說，「我還清債務，還有了存款，同時也幫助了其他人。」

然而，每週七天的工 作排程，以及與大萬多名讀者的頻繁互動，讓J.D.幾乎爆肝，也導致「慢慢變有錢」的品質受到了影響。他想到個人的商業模式有調整的需求，於是找來了一位事業夥伴，同時也雇用了一些寫手，讓自己可以「繼續掌舵，但不用再跑船兼水手」。這些變動增加了他的財務成本，但顯著降低了他的工時與壓力，讓他有餘裕寫書，進一步提高收入與成就感，同時部落格的訂閱人數也持續成長。現在他，享受著與家人朋友更多的相聚時間，也一償他遊歷非洲、歐洲和世界各地的旅遊夢想。

「是個人商業模式圖幫了我。我們腦中都曾閃過想做什麼事的念頭，卻沒能馬上記下來。」他說，「當你將它們寫下來，就能留住這些念頭，商業模式圖...」

# 核算你的事情

第1章省過。所有組織都需要一套有效的商業模式。「有效」的意念是：現金流入多於現金流出（至少也要做到收支平衡）。這幾乎適用於所有企業和個人。本章將協助你掌握關鍵方法，了解潛在客戶如何評價你的服務。

企業使用損益表來追蹤績效，將所有銷售以及支出項目列表。損益表幫助組織了解經營狀況，並保持有效運作。

雖然很少人把正式的損益表用在自己身上，但大部分的人會使用類似的收支衡量工具。 例如，人們會檢查存款餘額及薪資收入，以應付帳單及預算支出。

現在，我們先來看看損益表運用在個人身上的例子，然後再去了解同樣的概念如何運用於企業。

# 艾塞莉的所得

艾塞莉（Emily）是大陆鞋业公司的供应链分析师，月薪 4000 美元。付完每个月帐单后，  她剩下 450 美元可以存在投资帐户裡。 请問，有誰認為每個個月存 450 美元算厲害 的？請舉手！

雖然 450 美元看起來不多，但用商業術語 來說，那可是超過 11% 的利润（450 除以 4000）。很少公司可能保有收入的 11% 做為利润。信不信由你，从百分比来看，艾塞莉的 利润率比世界上大多数的公司都高！

事實上，「利润」二字往往被誤解了。很多人 印象中所謂的利润，不是二手手指專業務員把 一部剛買的高價質給購車新手，就是銀行理專 鼓勵不懂得投資的客戶買高風險的連動債券。

# 利润与盈余

利润（profit），简单说是收入减去支出费 用后的净额。以艾塞莉来说，她的利润就是 努力工作、诚实缴税、扣除所有生活开销之 后的金额。她之所以会有利润，是因为她最 責的服务顾客。對她而言，有利润是重要 的，否则要如何存退休基金，或准备足够的 錢供孩子上大学？

经营一家公司也一样，如果不能创造利润， 試问要如何有钱投资新设备或雇用新员工？

如果创造的收入刚好刚好用来支付所有的费用， 没有剩下分红（这裡利润為零的情况，商 业術語稱為「损益平衡」），对個人或組織而 言，都只能図個勉強苟延残喘而已。

雖然「利润」和「盈余」指的是一件事，不 過我们認為為「盈余」比較精確。絕大多数 的企业就跟艾塞莉一样，努力经营、专注於 創造盈余。當公司有盈余，me会拿來配發 給股東、再投资或是還債務。

拿個人與大企業相比，你會覺得不恰當嗎？ 放心，你不是唯一這麽想的人！即使在資本 主義的世界裡，很多人還是認為，一個人 的職業生涯和工作目标，跟一般企業的商業 行為是截然不同的。

某種意義來說，的确如此，人和企業確實不 同。然而，員工、承包商、約聘人員，其實 都和企業一家樣，都是在「銷售」服務給客 戶，用商業術語來思考这些工作關系，其實 大有用處。

本書的核心觀點，就是把我们自己想成一 人 公司：一家同時為所属組織及自己創造盈餘 的公司。

接下来，議我们來討論關於一個人的資金流 入與流出。只要懂得一點簡單的數學，就能 打开你的限制。

# 損益表

損益表從上至下共有三個類別：(1)收進來的錢、(2)付出去的錢及(3)剩下的錢。用商業術語來說，這三項目分別叫做銷售額、費用，以及盈餘。

簡單吧？
一般來說，企業每年至少會編製一次損益表，用來：

+   - 描述獲利績效
- 尋找（有無）過高的成本
- 分析銷售額在不同時間的起落

當然，企業的損益表比起簽署的個人收支要複雜多了。不過，這只是因為公司有更多的費用項目、稅賦等林林總總的開支，而且這些內容在我們建構個人商業模式時都都可以很開心地忽略。不管是公司或個人，基本公式其實是一樣的，就是：

銷售營額（營收）- 費用 = 盈餘

參考右頁「公司如何運用資金」，你就會了解損益表的思考模式適用於任何組織，無論是否營利、非營利或政府都一樣。

# 實收薪資的
真正意義

看看右欄下面艾蜜莉的個人損益表，請留意她真正拿到手的實領薪資（take-home pay）是 2,880美元，比起她的薪資總額（gross salary）4,000美元明顯少了很 多。扣繳稅額、社會保險以及其他醫療保險等扣繳項目就占了 1,120美元。

我們可以把這筆 1,120美元的扣繳項目視為一種「收入成本」，是艾蜜莉為員工及美國公民所必須支付的費用（身為員工，她享有健康保險及退休福利；身為公民，她享有警察、消防、教育及其他公共服務）。

就艾蜜莉的立場來說，扣繳的錢越少、實領到的錢越多，她當然越開心，但如果她沒有選擇餘地：如果她要以員工身分賺取收入（並且和稅捐機關保持良好關係），她就必須接受稅費福利等各種扣繳項目。因此對她而言，所謂「收入成本」就占了薪資的 28%。

現在，請注意，我們接著要來探索實領薪資的真正意義。

艾蜜莉可以用來支付她所生活開銷的錢是 2,880美元，而不是 4,000美元的薪水。這個明顯的事實，是了解基本商業運作（以及如何決定薪資）的關鍵，讓我們來解釋一下：

就好像艾蜜莉一樣，公司支付各種開支的錢必須須來自「實領薪資」——亦即扣除所有創造營收所必須投入的成本費用後，所剩下來的資金。

# 驚人真相

大腳鞋業從購買製鞋原料開始，每雙鞋子必須先花成本約3美元。
接下來，將原材料組裝成鞋子，每雙大約需要花4美元。
再來，將做好的成品運送給零售商，平均每雙鞋子大約需要花1.50美元。
因此，每雙鞋子從原料、製作到運送至可以銷售的場所，總共需要花費8.50美元。如果零售商向大腳鞋業以每雙22.50美元的價格購入，那麼大腳鞋業可以從每雙鞋子「賺」到14美元。

這筆錢（14美元）稱為（單位）「毛利」，代表的是售價扣除必要的製造、運輸成本後，大腳鞋業所拿到的錢。從某種意義來看，這是大腳鞋業公司的「實領薪資」；銷售金額的62.2%（毛利率）。（零售店家會再以每雙的售價39.95美元賣給消費者，這是另一個故事。事了，我們略過不談。）

然後，大腳鞋業會用每雙14美元的單位毛利（「實領薪資」）去應付各種開支。

倘若經過完善的規劃與執行，並且完全售出所有商品，那麼就像艾蜜莉一樣，大腳鞋業最後也拿得到一筆盈餘（用剩的錢）。
這裡我們先來回顧一個關鍵點：大腳鞋業用來支付員工薪資和其他費用的錢，都來自於公司的毛利或「實領薪資」。
因此，要支付艾蜜莉每月4,000美元的薪水，大腳鞋業就必須創造額外的4,000美元「實領薪資」（毛利），對吧？
由於大腳鞋業只能從零售商支付的金額中保留62.2%的毛利，所以要賺取4,000美元的毛利，就必須創造出6,429美元的銷售業績（6,429美元的62.2%正好是4,000美元）。

用這個方法，你很容易就能算出用來支付任何額外費用（例如薪資或水電）所需要增加的銷售金額：只要把費用金額除以毛利率就可以（4,000除以0.622等於6,429）。

想像你願意拿 4,000 美元的月薪為大腳鞋業工作。除了你的薪資以外，公司還必須支付各種員工福利項目。事實上，典型的美國公司會另外支付員工薪資總額 17% 到 50%，用來繳交健康保險、法定退休基金以及失業保險等費用。因此，讓我們假設大腳鞋業這部分支出率是薪資的 25%。這表示大腳鞋業實際要為你支付的人事成本，是每個 月 5,000 美元。

首先，為了付你薪水，公司必須產生更多的現金收入，這筆錢要遠遠超過你實際領到的薪水。

這筆錢是如何計算出來的？

+   1. 4,000 美元用來支付你的薪水。 2. 月薪 4,000 美元的 25%（即 1,000 美元），用來支付上述的各種福利項目。 3. 4,000+1,000=5,000（美元）

記住，5,000 美元只是大腳鞋業為了雇用你一個人，每個月必須準備付出的 人 事 成本。這個數字不能全部反映大腳鞋業為了雇用你、所必須賺取的銷售金額，因為公司要能繼續營下去，需要更多的銷售金額。

其二，所有要付給你的錢，源頭都是來自消費者，而不是公司。

雇用你這個員工，意味著公司光是要支付你的薪水，每個月就得賣出總價 8,036 美元的鞋子（5,000 美元除以 0.622 等於 8,036 美元，算法請參見第 216 頁）。

所以，你要如何幫公司達成目標？

商業模式思考的一個概念是：任何一位員工價值值多少錢，要以他最終能提供給顧客的價值來衡量。

當一個組織決定是否雇用你，所以要考慮的是：你可以提供給顧客的價值，能否大於雇用你所要支付的人事成本。

如右頁圖「員工如何拿到薪水」所示，為了要發放 4,000 美元的月薪，公司必須鞋子的總收入要超過這個金額的兩倍。請注意這張圖中的兩件事。
