# 客戶經理

關鍵研究：顧客關係

標題：語言溝通的力量

潔西 (Jessica Ho) 任職於一家辦公及紙類用品製造商，一開始從事的是業務工作，分配給她的客戶中，包括了辦公用品連鎖店史泰博 (Staples) 和 OfficeMax 等幾個美國<|message|> 大客戶。然而，工作了幾個個月，她還在為如何發展良好的顧客關係傷腦筋，於是透過老闆的居中牽線，她向腳踏車綾綺米·懷利 (Jim Wylie) 尋求協助。

一開始，吉米就把問題聚焦在商業模式圖的「顧客關係」一項上。他發現潔西言行舉止對人客歉，也損長口語溝通，但拜訪了顧客戶取得或履行訂單外，她平時很少打電話給他們。潔西承認自己是「數位時代世代」，覺得電子郵件比較自在，不習慣價面對面或電話交談。

吉米建議她只要有機會就會用手機打給客戶，潔西從了他建議。很快的，潔西與客戶的關係就升溫了。打電話往往會讓潔西情緒更容易進展，而且氣氛會更融洽，有利於進一步的會面商談。
