# 接觸的人，生
俗語的心

當稅務會員會師凱洛忍不住低聲說話時，在偷聽就執業的心裡及嘆詭謔師席蒙斯只能一臉同情地微笑看著她。
席蒙斯先生剛問了他的客戶一個觸發情緒的敏感問題：「小時侯那個自動自發、充滿熱情的女孩，後來成了怎麼樣的人？」

席蒙斯表示，這樣的場景年復一年，已經重演過無數次了。
凱洛和其他人類似的情緒反應，背後的原固是什麼呢？席蒙斯解釋：
……來找我求助的客戶皆普遍都做一種想汰磨，就是還在他們完成學業、建立家庭、買房買車或是爬上高階主管之前，就直覺的認定自己「應該」如何過日子*。
席蒙斯這樣描述他的客戶：「因為自己的愚味或錯誤而錯過了人生真正的召喚，所以被殘留的意志煎熬著」。
換句話說，人們相信自己注定要遵循一條特定的、能夠發揮所長並感到滿足的生涯路徑，但往往無法找到。

為什麼大家會這麼想？

收到上天的旨意，要求(使徒)把單奉獻於傳遞基督教義。根據席蒙斯的說法，召喚的概念即使在非宗教領域也說得通，甚至持續擴張因覆許許多現在的工作者。席蒙斯描述這類的因素：
……往往被自己未實現的期望所折磨，期待生命的意義能在特定時間點以決定的形式顯現，使我們得以永久免於困惑、忌妒及後悔*。
