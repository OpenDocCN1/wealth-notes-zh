# 測她的商業模式

# 人物：資源回收協調員

賽德·康妮莎（Cyd Cannizzaro）終於釐清了她的人生目標：幫助他人學習資源回收並妥善處理垃圾。

多年以來，賽德常與朋友深入討論資源回收與垃圾處理，她們都 pcs 關注環境議題，還把兩人對話搞笑地命名為「垃圾話題」。後來當賽德從客戶服務訓練師的工作被資遣時，她認定「垃圾話題」應該不只是打發時間的消遣，而是她每天職。她決心找到能教別人如何做資源回收的工作，也就是她口中「能產生影響的工作」。

賽德立即開始測試這個全新的個人商業模式。
她無法找到顧客願意付錢來做資源回收的訓練，所以她重新檢討她的計畫，並在有機超市的熟食部門找到工作，以便增進處理廢棄物的相關可靠知識。
由於她跟任何資源回收的組織都沒有往來，所以她親自製作了一款「垃圾話題」電話卡，用以說明自己的人生目標。

為了知道在資源回收界建立個人商業模式有哪些必要條件，她開始參加綠色產品的會議、固態廢棄物處理的公共論壇，以及社區資源回收的聚會。

隨著一個組織對她的「垃圾話題」產生興趣，賽德依據產業專家的回饋來重新調整她的商業模式，也參與跟自己目標接近的專案。終於有一天，引起了市政府單位永續發展小組的善意回應。

現在，賽德已經如同期成為一名全職的資源回收協調員，在住家附近的城市快樂工作。
