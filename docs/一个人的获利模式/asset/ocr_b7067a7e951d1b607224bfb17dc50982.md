# 把「弱點」變優勢

# 人物：
綠色大俠

政治上的他，未必人人喜愛，但這位美國前副總統是我們這一章絕佳的例子。因為不管是重新檢視人生目標、觀點或身分認同，他確實成功做到了全盤翻新個人商業模式。

高爾的自我改造，開始於他在2000年美國總統大選落敗之後。當時，他贏了超過50萬的選民票，卻在佛羅里達州一場些微差距而重新計票的法律爭議中，被最高法院裁定輸給對手小布希。公職夢碎的高爾感嘆：「政治已成為需要容忍詭詐及操弄薄通策略的事務了。」他成立了電視關係網Current TV，決心要讓「電視民主化」。其使用著自製內容(user-generated content, UGC)的商業模式，在2002年的有線電視市場成了了革命性創舉。基於長久以來對環境議題的熱情，高爾又創立了一個基金會，專門投資有志於基於經濟與環境永續發展的企業。

2006年推出以全球暖化為主題的環保紀錄片《不顧面的真相》(An Inconvenient Truth)，為高爾的生涯帶來高峰，同時也贏得了奧斯卡金像獎最佳紀錄片。身為政治人物，高爾舊門了30年宣揚臭氧層對地球的破壞，並沒有獲得多大回響，而一個全然的個人商業模式卻讓他差成了日標，不僅引起全世界注意，也讓他轉型為引導環境議題的一顆耀眼超級巨星。

# 高爾成功翻新個人商業模式有幾個因素：

+   - 重新聚焦於核心興趣：高爾對環境議題的熱情，原本是政治人物的弱項，卻成為他非官方公民身分的 Zusammens 最大優勢。
- 幫助更多客戶：高爾把他的客戶群延伸到美國以外的地區，選有非政治性的新部門。
- 採用新通路：影片、DVD 和出品，把高爾的價值主張從服務轉換為產品，因而可以接觸到更多人。
