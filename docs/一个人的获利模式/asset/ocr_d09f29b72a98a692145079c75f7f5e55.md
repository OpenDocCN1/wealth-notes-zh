# 雲端管理平台創辦人

# 你的封面故事

+   1. 我接受《哈佛商業評論》採訪，該成功建立「人際網」（internet of people, IoP）的經過，將與人相對應的各種工作與生活需求連結在一起。

+   2. 目前台灣近六成企業都忽略管理系統的重要性，但大型管理模組所需費用驚人。通常只有大企業用得起，98% 的中小企業很難有升級機會。於是我和朋友創立「華雲」（2017年更名為Mayo），目標是讓企業不花錢就能使用最先進的管理模組，並透過app實施行動管理。

從開始提供人員資料庫庫庫起，陸續推出企業入口網站、招募服務，進而發展出員工福利、團購等社群功能，最後串聯成一個可以滿足員工各項需求的IoP體系。目前這個平台已占據80%企業工作的屏幕，成為他們不可或缺的工具。

+   3. 「簡上評價現了許多意想不到的創新模式，顧擬了整個個人資源管理相關產業，為這個封閉已久的領域開啟未來。」

我設定的商業模式，從免費提供基礎管理框架來快速擴大企業會員開始，藉由系統平台導入顧問服務及各專業模組年費（如招募、薪資、訓練、福利等）來獲利。隨著會員人數達到一定規模，開始經由多樣化服務（包含團購、訂餐、廣告等）增加多元化收益。

> 「世界上最可怕的事，不是你遭遇的挑戰有多麼殘酷，而是你失去了信心不前進。只要你真正想完成一件有意義的事，自然會有貴人出現，幫助你走到目的地。」
