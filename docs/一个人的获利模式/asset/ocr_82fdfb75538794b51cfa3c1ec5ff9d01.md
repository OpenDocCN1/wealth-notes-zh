# 你做哪些事

關鍵活動（你做哪些事）是由關鍵資源所驅動的，換句話說，你所做的事情，自然跟「你是誰」有關。

想想你在工作中應該執行的主要任務，然後填入關鍵活動區塊裡。請記住，關鍵活動指的是那些你需要為顧客執行的各種價值或心智上的活動，但它們無法用來描述你的價值主張。

即便如此，為了要繪製你個人的商業模式圖，列出這些特定的任務仍然是一個值得你考慮的方式，同時也能幫助你深入考慮更關鍵的價值主張。

現在就列出這些任務。它們也許只有二或三個，但也可能有大、七個或更多。要提醒你要列出你母親必須做過的每件事都列出來，只要列出真正重要的活動即可，也是能夠凸顯你不同於其他人的那些工作。
