# 我要展開的計畫

我常常在想：要如何拋開身外之物，活出真正的自己？後來我接觸到了克里希那穆提（Jiddu Krishnamurti）的作品，這位印度哲人長在東方與西方都受過教育，我認為他對於處會變遷、人際關係的主張，應該讓世界更多人聽到。因此，我決定加入「克里希那穆提基金會」，一起推廣他的理念。

這是一個，接下來要做什麼？買一棟小房子自住。我的葡萄牙文會接下來的第三年，我會在那裡熱烈內在買一棟小房子自住。我的葡萄牙文會明顯進步，足以幫助要進軍美國市場的巴西企業，我會用剛學習的故事技巧，與他們建立合作關係。閒暇時間，我會去當義工，幫助騎動的巴西人改善他們的生活。
