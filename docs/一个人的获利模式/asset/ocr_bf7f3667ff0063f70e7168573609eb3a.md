# 價值主張

我們可以把價值主張想成是：一套產品或服務為目標客戶所創造的價值或好處。而提供高價值的能力，就是顧客選擇這家公司、捨棄別家公司的關鍵理由。

以下舉幾個例子，說明有哪些元素可以為消費者創造價值：

# 個格

顧客往往會為了省錢而選擇其他服務。拿 Skype 為例，就以其他電話公司低廉的價格，提供國際電話點打服務。

# 價格性

節省顧客的時間或減少麻煩，是一項重要的優勢。例如在美國，經營影片和電玩自動租借服務的紅盒 (Redbox)，就選在人潮多的地點（如超市）放置自動租片機。對許多用戶來說，紅盒提供了最方便的租借和歸還服務。

# 設計

許多顧客會願意為了某個服務或產品的出色設計而多花一些錢。例如，猶如公司推出的數位多媒體播放器 iPod，無論是做為行動裝置或是音樂下載／聆聽整合服務的一環，漂亮的設計都讓它能比競爭者的產品貴上許多。
