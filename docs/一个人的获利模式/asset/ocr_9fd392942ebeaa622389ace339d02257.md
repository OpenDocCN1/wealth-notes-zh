# 九大要素如何相互影響

評估你對九大要素所做的變動，是有一個有趣又有某些複雜的過程，因為所有要素都被此相關，環環相扣：改變一個要素的某個項目，同時也必須更動另一個要素的內容。我們在第2章談及組織商業模式圖時曾稍微微接觸，在此將針對變動部分及由此產生的影響，進一步深入探討。

請先想像一下「收入與好處」要素的一個常見問題：收進來的錢不夠用。想要增加更多錢，你會需要(1)吸引更多/更好/不同的顧客，或(2)提供更強/不同/更高的價值主張。

在表格中加上新顧客，夠簡單了，不是嗎？但是，你不能期望新顧客會自動冒出來。新顧客通常需要額外的行銷或業務活動，因為你應該在「你做哪些事」那一列的「新增」或「擴展」格子中，寫上行銷或業務活動。

假設你決定透過增加新顧客來增加收入，你可以回到前一頁的表格，在「新增」那欄下或「擴展」格子中，寫上行銷或業務活動。
