# 姓名：亞德里安．海恩斯
(Adrian Haines)

135

在亞德里安需要策劃工作時，馬克鼓勵他要強調的是，他的目的和圖書館的需求有多麼契合，而不要太強調技術層面。亞德里安透過他個人的商業模式圖，認識他重新提出的人生目標與開啟了許多自己或許成成長的可能性。例如，從以往到現在，他有許多客戶都是博物館，所以他有一個強大的人脈網絡，讓他可以在中型或大型博物館得到管理階層的職位。

在本書要出版時，亞德里安正要去面試新孺職位。無論他最後會走上哪一條路，他都已經真正懂得「目標可以延展能力，誰能發光」的道理。

當你著眼於價值和目標，而不是技術與能力時，你會驚訝地發現，在你的專業上有許多可能性能選擇，而這正是你轉換跑道起點。
