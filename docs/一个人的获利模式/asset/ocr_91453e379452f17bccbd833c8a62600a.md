# 關鍵的決策

你本來想成為正式員工或外包人員，卻可能 會在測試個人商業模式時發現，或許開創新 事業才是你更好的選擇；反之，你原本有心 創業，但可能受屬於人的選擇更適合予你目前 的條件。

孤論是哪一種情況，你都要面臨創業與否的 抉擇：應承受風險開創事業，還是說法在 大組織中尋求適合自己商業模式的位置？

這個問題其實已經超出個人商業模式的範 疇，但是我們還是在此提供兩個想法：1)在決 定開創自己的事業之前，可先去閱讀創業 教父麥克．葛伯（Michael Gerber）早年的著 作《編譯：可能是《創業這條路》（The E- myth Revisited）》。2)大部份的人會發現，閒 人和專業上的成功，並不是非創業不可。 （但話說回來，會看這本書的人不在這些「大 部份的人」之中！）

# 如果你個人的商業模式得不到共鳴， 怎麼做？

當你分享自己的商業模式時，你的聽眾是否 全神貫注、坐直脖子？如果不是，有幾個因 素需要你再多踩踏一下。

你的商業模式是否有強烈的感染力？如果沒 有，請確保自己所使用的語言文字必須簡 單、易懂，而且在你所針對的專業環境裡是 合宜的。有時候，好的文章會達到戲劇性 溝通效果。

你的商業模式能否處理真正的經濟問題或機 會？很少有組織會單純區分為社會或政治治理由 而花錢，請重新思考你的商業模式如何協助 客戶的經濟層面。

你對你的商業模式有足夠的信心而且令人信賴 嗎？顧客對你的動機、經歷、專業及能力 （關鍵資源）是否有信心，認為足以用來實現 你的商業模式？如果你不確定潛在顧客<|start|>看你，開口問對方吧！

# 開路「凱爾曼儀表」

簡．金莫（Jan Kimmel）擁有物理學位，是 個經歷豐富的廠場女性，在被公司資遣後， 決定她的新的商業模式式結合財務及營運。她 說這兩個專業應該同時考量，但卻很少被相 提並論。應該是，她地址新的標籤沒能引 起訪談者的共鳴。

於是，她說了「一段讓人印象深刻的自我介 紹，言語簡略卻直指核心：

「我是個財務抓漏專家，擅長抓出公司財務 系統的漏洞與阻礙，並跟營業部門一起合作 修復，以保持利潤流暢。」

簡．金莫的比喻也許聽起來有點老套，但卻 獲得製造業者的共鳴。現在她為一家高精密 製造商服務，清楚她負責的工作是什麼？財 務營運。
