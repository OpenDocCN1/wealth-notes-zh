# 成本結構

取得關鍵資源、執行關鍵活動、與關鍵夥伴合作，都會產生成本。

創造並饋價值、維持顧客關係、產生收益，全部需要成本，而清箋界定關鍵資源、關鍵活動及關鍵合作夥伴之後，成本就能大致估算出來。

「規模化」（Scalability）是一個關於成本效益和商業模式的重要概念。能夠規模化，表示一家企業可以有效處理擴增的需求，亦即能夠同時服務更多顧客卻仍須維持性品質。如果以財務角度來看，能夠規模化，意味著每個服務一個顧客的額外成本是下降的，而非上升或不變，此時企業就能有規模經濟（Economy of Scale）。

軟體公司就是規模化的一個好例子。一旦研發完成，程式就能夠以低廉的成本複製及配銷。於是，為一個下載載模式的新增顧客服務，所產生的費用幾乎是零。

相反的，顧問公司和專人服務的企業則很難享有規模經濟。這是因為每多服務客戶一小時，就會得多消耗服務者一個小時的時間，亦即每多服務一個客戶所增加的額外成本是固定的，而非下降的。單從財務角度來看，能夠規模化的商業模式更可能吸引投資者。
