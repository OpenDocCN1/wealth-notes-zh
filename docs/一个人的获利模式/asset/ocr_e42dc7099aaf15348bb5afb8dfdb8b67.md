# 回憶磁鐵能力

隱藏題：
人物： 歷史學家
亞德里安．海恩斯（Adrian Haines）相信歷史的力量。他研究所修的是中世紀歷史，畢業後一直都在博物館或相關的組織工作。五年前，他搬到阿姆斯特丹郊區去從事他夢想中的工作：與博物館、圖書館合作，協助出版商設計並發想新型態的歷史書。 然而隨著口子一天天過去，有兩件事情始終因撐著他，讓他警覺需要刷新自己的生涯模式。
首先，他的雇主對數位出版及社群媒體給終奚不足前，讓他深感挫折；其次，他妻子想念城市生活，渴望搬回市區居住。
接著，亞德里安發現國立圖書館正在招聘「數位化專案主管」，他覺得這個職位完全符合他的專業和興趣，不過他也知道自己缺乏在大型官僚體制下工作所需要的管理技能。於是，他向論壇成員馬克求助，全盤思考自己的個人商業模式。
馬克首先觀察到，亞德里安太專注於細節，特別是他很在意自己是否有專業及管理技能來從事新職務。於是，他建議亞德里安也重點放在目標和價值主張上面。
幾經思量，亞德里安認識他的價值主張以及真正的熱情所在，就是「將歷史從來諸高聳的博物館和圖書館解放出來，讓任何人都能分享」。這幾個深刻見解，讓他看清了自己為何會對目前雇主感到沮喪，同時也精確描繪了他一向秉持的信念：歷史不能透過印刷或實體物件被吹責，也可以經由數位媒體被傳達。
