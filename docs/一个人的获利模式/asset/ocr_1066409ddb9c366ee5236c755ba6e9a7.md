# 姓名：史提夫·布魯克斯
(Steve Brooks)

| 人物： | 關鍵活動： | 探索： |
| --- | --- | --- |
| 工程師 |  | 從培養能力轉變為創造價值 |

從我念書剛開始上班那幾年，我一直很認真培養自己的能力，但總覺得自己懷才不遇。畢業後我名列前茅，連拿了兩個電機碩士學位，在海軍當過核子工程師，等等上了MBA，但體管我這麽努力，仍然沒有遇到理想的工作，感覺自己就是個普普通通的工程師。

為了增加成就感，我一直不斷尋求各種方法，終於找到了「一個人的獲利模式」，我畫了自己的商業模式圖，立刻就發現問題在哪裏了。我終於明白，我只顧著培養自己的能力，卻從來沒想過這些能力可以用來幫助哪些人。當我看著「你做哪些事」、「你要幫的是哪些人」這兩個欄位時，我竟然想不出可以填上什麼。

不過，要從原先專注於培養能力轉變為專注於創造價值，卻是一段痛苦艱難的過程。這也是為什麼「一個人的獲利模式」會讓此商業模式圖式更複雜。無論如何，這張圖幫助我找到了自己真正有熱情、有興趣，而且能同時幫助別人 的事。

再加上我現在當爸了，我還在思考要如何仿效好好這個角色，要如何跟老婆分工，例如我應該也學做那些我原本不熟悉的家事嗎？我猜想，應該絕大多數當爸的人都在想同樣的問題。此刻，我正在為新增加的爸爸角色重新填寫一份商業模式圖。
