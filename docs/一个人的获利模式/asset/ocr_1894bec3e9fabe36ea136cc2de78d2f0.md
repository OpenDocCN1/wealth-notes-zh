# 個案研究：關鍵合作夥伴

# 案例：顧及内部夥伴的合作感受

強恩（Jon Taylor）是個有20年經驗的業務代表，負責把塑膠原料賣給產業內 的客戶。他在管理客戶上享有極大的自主權，能夠自行設定價格與付款條件， 也很少提報銷售活動有關的内部報告。不過，當他的公司被一类大型的 國際公司收購時，這一切都改變了。

在這個新的大型組織中，強恩發現他的行事風格激怒了某些同事。這些同事 負責提供行政與行銷支援給業務人員，把報價及付款條件的指導原則交給業 務員，要求他們提交活動到文件以便監控銷售行為，並向管理層報告。

強恩重新審視自己的個人商業模式，意識到這次收購帶來了一批新的内部關 鍵合作夥伴，而這批新同事和外部客戶對他的成功都有一樣重要。同時他也解 釋到，自己不容許別人問題的行事風格已經過時了。

於是，他決定開始提交活動報告給新的内部夥伴，並且常常和他們及業務經理 電話聯繫。這些銷售單的行為改變讓他的同事們感到驚喜，也得到了他們的支 持與配合。
