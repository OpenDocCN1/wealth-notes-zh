# 推薦序

在人生很多事情中，許多人年輕時會有自己的夢想和人生規劃。然而，大部分人往往流於空想而未有坐言起行。當我們到了一定年紀，很容易因一支歌曲或一部電影，就觸動內心深處的遺憾或懷念。本書的作者奉勸青年人，務必充實自己，把握當下任何機會和資源，別退縮或過於保守，把握機會，當機立斷。縱使萬一失敗也要汲取難得的經驗，成為你生命中的許多養分。那麼，人生就不會白費，今生也會無悔。事業發展如此，投資理財也是如此。本書的作者Starman，絕對是我們的典範楷模。

本書作者是在我的朋友圈子中罕見的英雄才俊，行文流暢，能將複雜概念化繁為簡，讓時使人神馳。作者主張現金流為王，介紹了自己身體力行、在日常生活中的一些可行的操作方法。全書富有多地色彩，雖然不是一部文藝作品，但其中許多文章寫得生動活潑，真實勵志，內容豐富，有理有據，而且文筆優美，是一部可讀性甚強的好書，我十分喜歡，也全力推薦給你。
