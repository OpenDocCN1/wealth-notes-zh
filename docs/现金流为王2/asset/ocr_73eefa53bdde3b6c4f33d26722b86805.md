# 後記

寫一本書不容易，要寫一本好書更難。從來沒有想過出書的我，在偶然的機會下好不容易才出了一本，本只想過一下作家癮就算。但在《現金流為王》出版後，收到不少讀者的電郵，在網上亦看到不少人在討論，發覺不少人都只將焦點放在「招式」之上。這驅使我下決心撰寫本書，希望更深入地解釋和補充上一本書所講的投資技巧背後的理念。

儘管近一年公司進入了另一個新的里程碑，業務非常繁重，但寫這本書的過程我是真的非常用心；對自己的思路和组织要求很高，寫作過程必須將自己關在書房中進行，否則我那兩個「天真活潑」的小孩會不停纏著我嚷著要跟我玩耍，嚴重影響思路。

《現金流為王》和本書所寫的並不是點到即止的「資訊」，也不是單一的投资「技巧」，而是比較深入、以概念性為主，同時又非主流的投資思維，涉及的解釋比較多，如果讀者只看本書的部份，不容易吸收到我想表達的整套思想，甚至會產生誤解。其實，吸收所有知識都一樣，課堂學的不一定是正確，權威說的不一定是絕對，大家需要是一個具批判性的獨立思維。

在閱讀本書時，我希望大家能讀到當中的心法，明白箇中的投資理念，沒有「心法」的「招式」只是虛招。不同層次的人會看到不同的東西，一般人只會看到招式，甚至只會 challenge 招式。沒有內功，只一味「抄考」回來的招式都只是虛招，退潮時便知誰人沒穿泳褲。
