# 慣性槓桿的危機

在現時的情況下，投資者特別是多年來慣常使用槓桿的投資者，必須好好讓腦袋清醒一下，強如資深的專業投資者、大型對沖基金都需要留意，切勿墜入「慣性槓桿」的陷阱。所謂慣性槓桿，是指慣性地把注意力集中在槓桿後的資本回報率，而忽略長遠平衡槓桿風險的投資策略。

有人會問，為何保守如一些家族基金，投資時仍會使用槓桿？為何大型對沖基金都使用槓桿？因為基金成立的目的是要「跑」，生生不息，停下來基金就會失去本身作為「投資機器」爭取投資表現的功能。基金是沒有選擇，我們是個人投資者，卻有得揀。零/ 低槓杆狀態可以為自己保留實力，待機會來時再啟動槓杆投資。既然如此，投資者又何必急於無時無刻保持高速的「動態」？

筆者夠膽說，目前市場大部分使用槓桿的投資者，當中不乏私人銀行的一眾「貴客」，都是槓桿上癮，沒有「靜態」理想狀態的目標思維。這班投資者會令市場加速進入非理性的資產追逐狀態，當經濟危機到來時，便會加大市場去槓桿時的影響和痛楚，大家不得不小心。
