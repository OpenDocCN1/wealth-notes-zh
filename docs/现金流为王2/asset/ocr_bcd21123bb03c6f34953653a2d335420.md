# **「系統」的背景與原理**

《現金流為王》提到筆者當年決定辭職創業去尋找理想，為了安頓好家庭，便積極做好資產配置，創造一個具穩定現金流的被動收入組合（Passive income portfolio），以應付家庭每月的經常性開支。

當時計一計數，一個有小朋友的中產家庭的基本開支，包括供樓、養車、工人、長老、水電煤、管理費、差餉、小朋友學費、興趣班、食飯、基本娛樂、醫療保險、家中雜費等等，每月六至八萬元已是相當基本（當然，不同家庭的開支會有所不同，有多有少，然而重點不在於數字）。意識到擁有一個能持續穩定產生現金流的被動收入組合，對每一個人來說都是相當重要，否則只能一世困在老鼠籠內，永遠不能做自已真正想做的事情。
