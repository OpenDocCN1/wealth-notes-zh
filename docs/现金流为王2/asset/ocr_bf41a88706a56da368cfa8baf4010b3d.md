# 第五章：現金流的極至──資本化與證券化

除了從投資者的角度，一些持有房地產物業的上市企業，亦需定期對旗下未出售的資產進行價值評估，並以「按市值計價」(Mark-to-market)的方式入帳，評估出來的資產價值稱為公平值（Fair value）。當中不少房地產企業、房地產信託基金也是採用「現金流資本化」的方法去評估其「市值」。

資本化率可以理解為市場對某種資產的要求回報；從財務的角度，可以理解為折現率 (Discount rate)，將未來產生的持續現金流折現為現值，從而得出資產的估值。兩者的概念其實是類似的。

不論從企業或投資者的角度，如何定立資本化率可以說帶點藝術。資本化率定立時，需要考慮企業或投資者本身的資本／資金成本（Capital cost）、內外部融資成本、資產折舊（導致貶值）、資產產生現金流的穩定性和增長能力等內部因素。外部因素則包括加息預期、通貨膨脹等等。

我們投資一隻房地產股票或 REITs，不得不看其使用的 Cap rate（不同的 REITs 在進行估值時所採用的 Cap rate 也有分別）。由於資本化率具有很高的敏感度，在估算房產價值時對結果會產生乘數效應，採用不同比率所得出的結果將會相差很遠。如果一間企業透過調低 Cap rate 去提升資產的估值，從而粉飾業績，大家要留意。

例如，新鴻基地產（0016）評估落成的投資物業所用的 Cap rate 是 5.2%，相信也是考慮了上述的因素。由於旗下大部分是已改造的商場物業，增長較尚有改造空間的展展（Cap rate 4.8%）低，因此亦較為合理。
