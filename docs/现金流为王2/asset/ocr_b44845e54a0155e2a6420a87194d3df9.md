# 第一二章：如何構建收入系統

能自動流入村莊，只要有水流進來，便能为他帶來源源不絕的收入，更重要的是這源源不絕的收入與他所需付出的工作時間，完全沒有直接關係。

這個故事不是想鼓勵大家從此不去工作，而是希望大家明白每個人的時間資源都是有限的，若某收入是透過時間來換取，那麼收入也必然有限，而且可能收入愈高時間愈少。要知道有錢沒時間，或是有時間沒錢，兩者都是沒有意義的。

# 財務自由的真正意義

就像我們上班，上一個月班就能賺取一個月工資，當生病了不能上班，就沒有收入，這是絕大多數人的生活常態。但是，如果你有不同的是收入管道，上班賺取的工資已不是你唯一的收入來源，即使退休了，不上班也有其他的管道收入。例如你投資開了一家食店，請了經營團隊為你營運，你每月需要支付經營團隊工資，但買回了自己的時間，因此你可以運用多出來的時間去建立另一條收入管道，如建立一個投資理財組合。

慢慢地你會發覺，每一條收入管道不需要打理，都能賺取可觀的利潤，關鍵在於一段時間後它能自動運作，儘管利潤多分一點出去給予以你的經營團隊，又或者是這只是一個「賺取」的投資組合，只有現金流但沒有爆發性收益，但只要它能穩定自動運作，不用你去操心，這等同買回自己的時間，這樣你才有心力去做其他事情或再建立更多的收入管道。只有這樣，你的管道收入才能做到多元化。因此，所謂的「財務自由」，關鍵不在於「財務」，而在於「自由」。
