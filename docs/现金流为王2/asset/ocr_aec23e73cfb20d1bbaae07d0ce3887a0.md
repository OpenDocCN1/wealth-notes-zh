# 投資「系統」的四大重點

筆者是首個提出以REITs配合債券建立投資組合系統的「散戶」，但其實重點不在於這兩種投資產品，而是其背後的核心理念。只要明白箇中原理，其實組合可以千變萬化，只要運用相同原理，按個人對不同投資項目（如ETD、ETF、優先股、物業等）的認識水平，應用於不同的投資產品，也能產生相同效果。有些投資者可能以優質高息股／價值股替代REITs，有些會以其他固定收益投資替代債券。

筆者之所以選擇REITs + Bond，原因很簡單，主要是因為筆者對金融和地產熟悉，就地取材地選出兩種有互補特性的投資產品來組合。因此此產品不是唯一，也不是最主要的重點，最重要是：1、投資者對產品本身是否有深入的認識；2、不同產品之間又是否有互補且有穩健現金流的特性；3、然後再看其中一種產品是否有槓桿操作的空間；4、最後就是整個組合的營運技巧與風險管理。一個投資組合系統是否成功，背後的營運管理哲學才是關鍵。
