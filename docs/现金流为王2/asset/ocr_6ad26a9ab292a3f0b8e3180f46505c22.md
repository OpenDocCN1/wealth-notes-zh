# 3.6
「防守」才是
最強的「進攻」

曾有不少讀者問我的投資組合是否只是經常提及的 REITs、債券和房地產項目，每次我都笑著回答「當然不是」。事實上，
作者在博客內提及得較多的「REITs + Bond」組合，只是其中
一個主要能產生穩定現金流的「永續投資引擎」。這個引擎無
需要入電油，靠的是生生不息的投資現金流為引擎注入能量。
正如前文所解釋，現金流收入是投資資產的產物，現金流再投
資時是資本，資本投資能持續產生現金流的資產，令這個投資
引擎得以自給自足，永續發動。

我在博客中、書中有不少篇幅提及「REITs + Bond」組合，
又以不同層次深入解釋該組合背後的原理，因為我認為我的
「REITs + Bond」組合是一個值得讓大家參考的投資模式，當
中涉及的投資理念，我個人認為為有一定的啟發性和參考價值，
包括不同投資產品的優劣互補、槓桿的使用、再投資的力量、
資產累積後自然去槓桿等等。
