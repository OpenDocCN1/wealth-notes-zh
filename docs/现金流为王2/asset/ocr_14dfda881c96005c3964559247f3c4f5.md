# # 「貪心」與「知足」的藝術

《現金流為王》出版後，一直收到不少讀者的問題，比較常見是「現在美國已進入加息周期，債券和REITs 都是對息口敏感的投資產品，現在才入市是否已經水尾？」、「在進行REITs + Bond 投資時應該用多少槓桿？」等。

看到這些問題，令筆者感覺到部分讀者都將焦點放在「招式」上，因為大家都希望從書中得到即時的「成效」，急急腳要抓緊時間投資，部分讀者甚至只希望筆者提供一個最佳的投資平台和提供自己的portfolio，讓其可以即時複製，然後便大功告成。當然筆者並不會答應，如果投資是這樣簡單，筆者根本用不著花時間和心機，用不同的層次和角度去講解組合設定背後的理念，倒不如直接將自己的portfolio資訊和各個投資平台資料清楚寫出來，然後在博客定時更新就可以了。投資是一門學問，同時也是一門藝術，「招式」（投資工具）需要配合「心
