# 1.3 利用管道建立系統

成功建立了一條管道後，你就會擁有一項被動收入，但這是不足夠的，因為若管道淤塞了，收入就會停止繼續流入。一項收入，不管是主動還是被動，比例過分集中便是風險，財務上稱為集中風險（Concentration risk）。因此，人有需要建立多條管道，使被動收入多元化。

然而，建立一條管道所耗費的精力、時間和資本太高了，要獨立地建造多條管道所犧牲的成本實在巨大。因此，我們必須好好利用第一條管道去建立第二條管道，再利用已建的管道去建造更多的管道，前題是管道與管道之間必須全部接通，意味著管道之間的結構是互相關連，互相補充。一個結構上互相關連、互相補充的多元管道，是為一個「系統」。
