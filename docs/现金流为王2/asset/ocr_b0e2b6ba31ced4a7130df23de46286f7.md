# ## 4.1 投資，
## 要有可槓桿的選擇

累積財富的關鍵只有一個，就是累積資產，而在累積資產的漫長過程中，關鍵就是要現金流。只有現金流才能在累積資產的過程中進行「再投資」（Re-investment），使投資雪球有「動能」，不停自我滾動。然而，若希望以現金流投資去累積資產從而致富，整個投資的過程就不能完全沒有槓桿，而關鍵在於使用槓桿的時機（Timing）和比例，其次是運用槓桿的收放技巧。這就是槓桿的藝術。

對於初階投資者，我會強調「複利」，因為這是作為任何投資者都需要去認識的一個重要概念；對於進階投資者，我會強調「槓桿」，因為除「複利」以外，「槓桿」才是真正致富的關鍵。
