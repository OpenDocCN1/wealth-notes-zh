# 第五章：現金流的控管……資本化與證券化

筆者正在實驗中的方法，是以一上市公司發行特殊「可換『資產』債券」（Convertible Bond），收購上述有現金流但缺乏流動性的資產，同時分拆該資產（將資產分成多個獨立契單位），並以該資產抵押予債券持有人。債券假設為三年期，利率為8%p.a.，債券到期時，投資者可選擇不贖回本金，而可以選擇直接獲得／以大折扣購入上述已拆售的資產，當然換「資產」的誘因是該資產升值。通過這方法，這資產便能成功被證券化。上市公司遇到好的項目，其實也能透過以上的方式將未落成、即將拆售的資產證券化，並將集資所得專項用於項目的開發。

筆者目前正努力研究執行，如成功，這將會是我個人事業上的一大里程碑，到時再与大家分享。
