# 實質財富累積 要抵銷通脹

單純以現金流投資去累積資產可以防守，但難以致富，原因很簡單，假設你買入高息股票，每年回報率 6%，根據 72 法則，資產需要 12 年才能翻一倍，即使回報提升至 8%，也需要九年時間，而這已包含了「再投資」的複息力量。對一般人而言，這個財富累積的增長速度尚可接受。

然而，在經濟自然增長的情況下，銀紙會隨時間貶值，主因是通脹因素。由於金錢本身只是交易媒介，是虛無的，投資的實際回報，特別是對於長遠的投資，不應只用「名義概念」 (Nominal concept)，而應該應用「實質概念」 (Real concept)。正如專業投資者評價一隻基金的表現時，會將基金表現與市場基準 (Benchmark) 作比較，而不是單純以基金的絕對回報率去評定。

對於一般個人投資者，我們可以用另一種方式去實際判斷自己的投資表現，就是投資回報對購買力。假設每年通脹 2%，銀紙的購買力每年便下跌 2%，而且銀紙的持續貶值也有複息效應，以「金錢」計價的資產帳面上雖然每年回報 6%，但若計及 2% 的購買力損失，實際上每年的淨累積財富只有 4%，因此實質財富需要 18 年才能翻一倍。
