投資，而由於銀紙長遠貶值，資產長遠升值，投資賺錢後必須將沽套現的資金重新投入其他資產，才不會被時間將你的資產購買力吞噬。不論是新投資或再投資操作，投資項目的投資比例也應儘量投入值得累積的資產為主，從而實踐投資是為了「賺資產」而非「賺錢」。投資要認清「目的地」。

# 自行構建完美的「資產」組合

以上概念十分重要，投資者很多時候以為自己知道，實際上可能只是知半解。有些人或會認為這些概念不重要，無須過分嚴謹，就由得它含含糊糊就算了，十年過去後，可能會發覺自己明明投資有「技術」，為何身家就是給懂得累積「資產」的普通人比下去，甚至遠遠拋離。

這單純是 2. 有效資產 和 3. 值得累積的資產 在市場上並不難找到，然而同時具備兩者特質的資產卻不容易找。雖然要找到能定期產生高現金流回報，同時其整體收益 (Total Return，包括現金流和資本增值) 的資產項目不容易，但我们卻可通過精明的資產配置方式，結合不同資產的特性，自行構建能同時滿足 2 和 3 的投資組合。

筆者提出的「REITs + Bond」投資組合就是一個例子。會選擇以 REITs 和槓桿債券去建立自己的投資組合，是基於兩種資產的不同特質性，而兩者的優劣能夠做到有機互補。
