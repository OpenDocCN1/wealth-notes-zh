# 7.4 認清何謂「加息」

分析加息對經濟，以至資產市場的影響前，我們需要先知道所謂「加息」，實際上是加甚麼息？美聯儲又是通過甚麼手段達到「加息」的效果？儘管大家每天都在談論「加息」這個議題，但相信大家對以上兩個問題都未必清楚。

所謂「加息」，其實加的是美國聯邦基金利率（Federal Funds Rate, FFR），亦即是美國銀行隔夜同業拆息（銀行與銀行之間互相借貸的利率）。有別於中國對利率的直接操控（直接對市場給予一個指導利率），聯儲局開會決定的其實是 FFR 的目標，說是一個「目標」，是因為聯儲局一般會透過市場操作去影響銀行體系儲備（Reserves），以確保 FFR 實際水平與目標相若，因此多年來美聯儲的零息目標其實是0%–0.25%的區間。
