該債券為浮息債券，票面利率以三個月倫敦同業拆息（3M Libor）為基準加400點子或4%，債券收益每三個月重新確定一次，對上一次定息日為5月21日，當時三個月Libor為2.533125%，因此債券的總收益固定為6.533125%。下一次定息日為8月21日，如期內利率上升，假設屆時三個月Libor升至3%，則債券的總收益會同步上調至7%（3% + 4%）。

筆者所用的其中一間私人銀行，能夠提供60%的融資率（LTV），意味只需40元的資本投入便可買入100元的債券，槓桿比率為1/40% = 2.5倍。融資利率為COF + 1%（不同銀行的COF有異，但大致與Libor相若），可選擇7天 / 14天 / 1個月 / 3個月的利息期，利息期愈短，利率愈低。為了對應該浮息債券的利率重置日，投資者可選擇同為三個月的利息期。債券的下一次定息日為8月21日，假設投資者於同一天買入債券，同時選擇三個月的利息期，債券下一次的利率收益重置日與貸款的利率成本重置日，將會為同一天。融資成本為3% + 1% = 4%，而債券收益率為7%，槓桿操作下的套利息差將會固定為3%。
