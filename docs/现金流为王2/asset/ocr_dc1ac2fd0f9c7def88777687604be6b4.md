# 盈透證券（Interactive Broker，IB）

對於一般大眾投資者，筆者建議大家可以先開一個盈透證券戶口，開戶口基本上沒有門檻，存入數萬港元便可開戶。盈透證券是一個自動化的證券戶口，可供交易的產品種類眾多，交易覆蓋全球24個國家共100多個市場中心。通過一個IB全能賬戶，即可進入股票、期權、期貨、外匯、債券、交易所指數基金（ETF）及差價合約（CFD）的交易。

其最大優勢在於融資利率超低，主流貨幣歐元、美元、日元，也只要1%多一點的年化利息。不管你買的是甚麼股票，不管你借的是甚麼貨幣，都可以外匯操作換成利率超低的貨幣，以便投資者以最低的融資成本進行槓桿投資。

操作方面，在盈透證券買入股票，如果本幣不足就會自動融資，融資額會變成負債，這些負債按照當天盈透證券的利率來計算，按天計息，一月一結算，也是一個月的利息滾存到總負債裏面，自動展期，相當方便。

盈透證券另一個優勢是交易手續費便宜，每股只需0.005美元。唯一缺點是它比較少亞洲區的證券選擇，例如內房債券就未能在盈透買入。

# 私人銀行（Private Bank）

私人銀行是一個高門檻、但非常有用的個人融資平台。對大部分私銀客戶來說，私人銀行是一個高級理財平台，原因是私人銀行提供360度多元化、多功能的理財服務。
