# 3.4

從收入、有效資產、
資本看現金流

香港首富李嘉誠先生終於正式宣佈退休，各大報章紛紛報導李
生的金句和發跡史，在在其中一篇報道中，李嘉誠談到成功之道
在於「一定要有現金流」。他回想「以往從事塑膠花製造業時，
親身體會到現金流是主宰公司命脈的因素，一直銘記於心中」。

傳統以來，只有做生意的人才知道現金流的重要性，一般投資
者卻對此忽略。對生意人來說，現金流是血液，不管這盤生意
的盈利有多強大、公司的盈利能力有多強，如果沒有現金流，
就會即時死亡。

一般投資者沒有這個概念，原因是大部分投資者拿來投資的資
金只是閒置資金，即是「閒錢」，並不是他們產生收入來賴以
為生的方式。收入的產生不外乎主動和被動，前者靠勞力，後
者靠投資。社會上大部分人的主要收入來源為主動收入（靠工
作、勞力換來的收入來源），因此大部分人根本沒有想過現金
