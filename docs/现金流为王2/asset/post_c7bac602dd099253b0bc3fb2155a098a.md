
時的流動性，大大降低了整個集團資金鏈斷裂的風險。另一方面，若其中一條管道有良好的拓展機會，其他管道亦能提供及時和靈活的資金支持。

簡單而言，一個「系統」比多條獨立的管道更優勝，其優勝的地方在於前者擁有更大的「流動性緩衝」（Liquidity buffer），使管道能經得起市場波動所帶來的考驗。與此同時，波動亦代表著機會。由於「系統」擁有多元的流動性互補機制，使其更有條件在波動的市場中抓緊突如其來而且難得的投資機會。

下一步，我們一起開始學習如何去構建自己的「管道系統」。

## 第二章 建立有效「系統」的考慮

### 「系統」的背景與原理

《現金流為王》提到筆者當年決定辭職創業去尋找理想，為了安頓好家庭，便積極做好資產配置，創造一個具穩定現金流的被動收入組合（Passive income portfolio），以應付家庭每月的經常性開支。

當時計一計數，一個有小朋友的中產家庭的基本開支，包括供樓、養車、工人、長老、水電煤、管理費、差餉、小朋友學費、興趣班、食飯、基本娛樂、醫療保險、家中雜費等等，每月六至八萬元已是相當基本（當然，不同家庭的開支會有所不同，有多有少，然而重點不在於數字）。意識到擁有一個能持續穩定產生現金流的被動收入組合，對每一個人來說都是相當重要，否則只能一世困在老鼠籠內，永遠不能做自已真正想做的事情。

![](img/28586c71c5408626f3973d2458a73d64_40_0.png)

面對這個未來只會有增無減的開支，我們要做的不只是去努力創造收入，更重要是構建一個能產生現金流且持續增長的「收入系統」，而筆者的「REITs + Bond」（房地產信託基金 + 債券）投資組合是一個例子，希望大家不要將焦點單純放在「工具」之上，更重要是去了解建立這個系統背後的理念，然後大家便會明白組合內運用不同操作的原因，進而不同的市況下，均能因應市場的變化與自己的情況作出最佳調節，創建真正屬於自己的投資系統。

#### 為何選擇「REITs + Bond」？

《現金流為王》提到筆者的金融資產被動收入組合——「REITs + Bond」，基本原理如下：

- 債券以短債為主，一般不長於三年，會利用債券本身的倉值（LTV）做槓桿投資，增加回報率。倉值的意**思**是銀行提供的融資額，以買樓的按揭成數概念去理解會比較容易：若銀行對某債券提供70% LTV，意**思**等如買樓做七成按揭。

- 所謂槓桿投資債券（Bond Leveraging）是指買入一隻債券後，將之抵押予銀行，利用銀行低息融資的優勢，根據該債券的融資率向銀行貸款，借回相當部分的資金，將套現出的資金再度買入該債券，如此類推，反覆操作。

- 當然實際操作上比較簡單，假設債券票面息率為5%p.a.，債券的融資率為80%，私人銀行的融資利率1.5%，買入債券時就只須支付20%資金即可買入該債券。

![](img/28586c71c5408626f3973d2458a73d64_41_0.png)

如此，20元的資**金**，就可以買到 100% 面值的債券，其餘 80% 由銀行融資，計算槓桿比率就是 1 / 20% = 5 倍，淨回報率超過 18%。當然，筆者一向不建議用盡槓桿，但即使不用盡槓桿，要做到淨回報 10% 以上也不難。以上做法就等同套息交易 (Carry Trade)，借入低息資金，買入高息資產，從而套取當中的息差。有關槓桿操作，會於稍後篇章作更深入講解。

至於筆者的 REITs 組合一般不做槓桿，因為想利用其價格波動性 (Volatility) 較低及高倉值（即高融資率）的優勢，作為槓桿債券組合的有效緩衝 (Buffer)，並作為滿足臨時現金需要的「提款機」，提升整個投資組合的資產流動性及穩健性。

要做到「REITs + Bond」組合有足夠的防守力，首要記住債券組合槓桿不用盡，REITs 組合的緩衝要充足，這樣才能令組合立於不敗之地。

基於債券一般每半年只派息一次，因此債券組合本身設計是分散買入最少六隻不同派息月份的債券，使債券組合每月均會收到債券利息，達至每月出糧的效果。債券利息每月有多有少，筆者會用於再投資優質、前景看好且平穩增長的 REITs 組合，如領展 (0823)、置富 (0778)、越房 (0405) 和持有又一城的新加坡豐樹信託 (Mapletree Greater China Commercial Trust ; SGX : RWOU) 等，而 REITs 組合亦會定期每半年派息一次，因此整個組合便形成了一個擁有穩定現金流的投資組合系統。

### 投資「系統」的四大重點

筆者是首個提出以REITs配合債券建立投資組合系統的「散戶」，但其實重點不在於這兩種投資產品，而是其背後的核心理念。只要明白箇中原理，其實組合可以千變萬化，只要運用相同原理，按個人對不同投資項目（如ETD、ETF、優先股、物業等）的認識水平，應用於不同的投資產品，也能產生相同效果。有些投資者可能以優質高息股／價值股替代REITs，有些會以其他固定收益投資替代債券。

筆者之所以選擇REITs + Bond，原因很簡單，主要是因為筆者對金融和地產熟悉，就地取材地選出兩種有互補特性的投資產品來組合。因此此產品不是唯一，也不是最主要的重點，最重要是：
- 1、投資者對產品本身是否有深入的認識；
- 2、不同產品之間又是否有互補且有穩健現金流的特性；
- 3、然後再看其中一種產品是否有槓桿操作的空間；
- 4、最後就是整個組合的營運技巧與風險管理。

一個投資組合系統是否成功，背後的營運管理哲學才是關鍵。

### 2.2 「REITs＋Bond」組合的五個重點

筆者必須再三強調的是，這是一個組合系統。單獨地投資REITs或單獨地以槓桿方式買債券，基本上已與「REITs＋Bond」投資組合提出的核心理念和背後的營運管理哲學完全不同。

「REITs＋Bond」投資組合的投資操作中，提出的重要投資理念包括：

- **槓桿**：以槓桿方式投資有效資產\*，從而帶來高現金流回報；
- **再投資**：現金流是再投資的條件，再投資含復利力量和分散投資的機會；
- **累積資產**：以槓桿投資產生的現金流，長遠不用槓桿去累積「值得累積的資產」**；
- \*有效資產：指能於一段時間內持續地產生現金流收益的資產。詳情請見第三章。
- \*\*值得累積的資產：指能於指定時間內產生現金流收益、其產生的整體收益會隨時間有所增長，且增長速度比通貨膨脹快的資產。詳情請見第三章。

- **去槓桿**：以「加槓桿」去開始，「去槓桿」為目標，組合長遠方向是去槓桿。
- **自我優化**：投資組合的自我運作須能隨時間自我優化，所指的是包括：1、組合的價值增長層面；2、風險系數層面。去槓桿和風險分散（Risk diversification）正有助降低風險系數。

基於上述的五個重點，才能總結出「REITs＋Bond」投資組合是一個長遠能自我優化的投資系統。單純地以槓桿投資債券或投資房託基金，絕對不能做到相同的效果，意義上亦與上述組合操作的原意大相逕庭。

### 「駕駛」你的投資組合

槓桿和復利力量是投資回報的助燃劑；分散投資和去槓桿則是組合風險的緩衝。投資組合是一部汽車，投資者就是司機。汽車起動時需要動能，因此需要以高轉數產生足夠扭力，汽車才能向前行，正如投資組合一開始時需要足夠「扭力」去起動，這是為何我會提倡投資一開始需要有槓桿。

起動後，仍需要一些「動力」去推進汽車向前加速，這是為何投資組合需要不斷的再投資，而再投資帶來的復利力量就是「動能」，使汽車產生速度。當汽車已經在公路上有了速度地行駛，這時汽車已有了動量（Momentum），無需再維持高轉數（加槓桿）去產生強大扭力。汽車有了向前的動量，我們只管控制好軚盤方向，而這時駕駛的專注力應放在腳掣（Brake），而非油門。

這好比當投資組合經過一段時間的操作後，除了利用再投資的複利效應去維持一定的車速外，更重要的是利用再投資去做好穩健的資產配置，不用槓桿地運用新動力（新增的現金流）再投資長遠值得累積的資產，專注自己的投資方向，並在面對不同的路面情況（市況）時，去控制和調節車速。

大部分的投資者「駕駛」投資組合時，只注重速度（預期投資回報），而忽略了風險因素，如方向錯誤或遇上突發事件如黑天鵝等。事實上，投資的關鍵是要方向正確，盡量避免走錯路，不然只會想快得慢，更浪費了燃油。投資如駕駛，在有了一定的速度後，穩健和方向比起純粹的速度更重要。

### 有關債券投資的補充

![](img/28586c71c5408626f3973d2458a73d64_47_1.png)

筆者選擇債券，其吸引的地方是定息回報，以及可槓桿操作。一般而言，高評級的債券回報低，低評級的債券回報高。另一方面，高評級或高質素的債券，銀行給予的融資率較高，反之亦然。

債券可槓桿操作的特點讓投資者可選擇高評級、穩健的企業債券，再利用槓桿操作提升資本回報率，使本身低收益的高質素債券，同樣能定期產生高收益的現金流回報。

投資者要留意的是，高質素的債券不一定有高評級，而投資高評級債券時，也不代表可以放一萬個心，連公司最基本的財務報表也不看。債券的評級與質素，兩者之間沒有絕對必然的關係。債券評級始終僅供參考，投資者不宜過分依賴評級。

### 「無評級」債券可能更吸引

筆者甚至會專門留意一些沒有評級的債券，因為高評級債券的收益必然不高，錯價的機會較低。相反，沒有評級的債券，如果發行人資產負債表健康，有償債能力，可能更「抵買」。

有些債券沒有評級，可能因為企業本身具一定實力或背景（國企／央企、主權基金如淡馬錫系統內的公司），或發債的總金額不高，而獲取評級機構的評級需要成本，所以這些不愁投資者的發債企業為了節省成本，在發行債券時索性不尋求評級。由此可見，沒有評級不代表信貸基本質素欠佳。

事實上，有不少香港大型藍籌公司所發行的債券都沒有信貸評級，但其信貸質素不容置疑。個別公司因技術性和結構性因素而未有尋求評級，如和黃、恒基，原因是如要獲得較佳的信貸評級（如「投資級別」或以上），發行人可能需要訂下一些約束條款，控制企業自身的信貸質素，以保障債券持有人。一些企業可能因應業務擴張而希望維持信貸狀况的靈活性和容限，因而放棄獲取信貸評級。

基於上述因素，我們不能排除沒有獲取評級的企業所發行的債券是高質素及穩健的。定息回報和可槓桿操作這兩個特點讓投資者可選擇高評級、穩健的企業債券，再利用槓桿操作提升資本回報率，使低回報的高質素債券更具吸引力。

### 因時制宜 重新部署

面對利率開始正常化的趨勢（雖不意味著低息環境的離去），加上債券市場的轉變，以槓桿投資債券獲取「暴利」的時機已經過去，債券投資者的心態必須重新調整。2008年金融海嘯後，市場利率維持在極低水平，加上內地房地產市場發展蓬勃，但又遇上融資困難的問題，境外發債變成了內房企業融資的主要手段和渠道。面對高回報的內地房地產項目，內房企業不惜以高成本發行高收益債券，吸引投資者認購。對投資者而言，市場歷史性的低利率跟內房的高收益債券簡直是絕配，投資策略可以同時做到「獲取暴利，亦求穩健」。挑選有國企背景的內房國企如中海外（0688）、優質內房民企世茂房地產（0813）、具大型央企背景的中信泰富（0267）等所發行的債券來投資，槓桿後的投資年回報率一般高達2x至30%。

![](img/28586c71c5408626f3973d2458a73d64_49_0.png)

投資，一定要順勢而行。目前美國開始走出零息年代，利率在正常化過程中，內地實行去槓桿，加上中央多項管理內房企業的措施，令市場投資環境開始轉變，債券投資是時候慢慢回歸其「保守」的傳統功能，對債券投資的預期收益回報需要降低。「槓桿」在投資債券操作中的角色，需要由「放大投資金額」改變為「備用信貸額度」，以為投資組合預留流動性作主要功能。投資者要做到因時制宜，方能立於不敗之地。

對筆者而言，債券最吸引的地方是定息回報及可槓桿操作，然而，槓桿操作的前提是息差。在目前資金成本高昂的情況下，只能找高回報的債券來投資，如內房價和城投債*，變成了以風險換取回報。若不使用槓桿，投資債券的資本回報率會下降，投資者入市投資債券時，必須要降低預期回報的要求。從資產配置的角度，對於收息一族或較年長的退休人士而言，債券投資仍是可取的選擇，惟投資債券的策略要以穩健為主。

筆者近兩年已沒有增加債券的持倉，原因是難以選擇優質又高息的債券，最後在一年多前，債券到期的到期，未到期的都已全清倉。以目前市況，投資債券需要更為謹慎，考慮到加息等因素，應該以年期短的債券為主，同時可選擇投資浮息債券，以對沖利率成本上升的風險。如投資或手持定息債券，在目前市況應該開始減低槓桿，盡可能將銀行提供的融資額作為備用緩衝，投資者對回報率的要求應合理地降低，切勿盲目追求資本回報率的極大化。

\*即城市投資債券，是指中國地方政府融資平台發行的債券，用以支援城市發展。

### 2.4 浮息債券 應對利率上升

市場利率風險上升，債券價格就會下跌，原因是現有債券的相對回報（Relative return）下降，但也不代表所有債券下跌的幅度都會一樣，例如年期短的債券、浮息債券所受的影響相對會較少。所以在預期利率將會開始回升時，選債技巧十分重要。專業投資者會分析浮息曲線（Yield curve）、預測利率走勢、加息幅度、分析加息對經濟的影響、通脹預期等因素。因此，利率風險同時會導致債券價格的波動。

利用槓桿投資債券，先天結構上有一個問題——利率和收益不匹配。由於融資利率一般為浮動利率（以COF / Libor / Hior 為基礎利率），而市場上大部分債券為固定收益債券，因此，當利率上升時，套息空間便會收窄。在面對利率正常化的加息環境，除儘量挑選年期較短的債券外，槓桿投資債券時一般可採取兩種方法，對沖利率上升的風險：

- 1. 買入利率掉期，鎖定融資利率（固定融資利率 vs. 固定收益回報）；
- 2. 投資浮息債券（浮動融資利率 vs. 浮動收益回報）。

以上兩個方法實際上都是解決「利率和收益不匹配」的問題，將利率和收益變為匹配，而無論利息上行或下行，息差依然不變。

#### 何謂利率掉期？

利率掉期交易（Interest rate swap，IRS）是掉期交易最常見的一種。利率掉期交易合約首先確定一個名義本金（Nominal principal），在合約時間段中，其中一方同意定期支付另一方以固定利率（Fixed rate）計算的現金流，另一方則同意定期支付以現時浮動利率（Floating rate）計算的現金流；浮動利率一般以倫敦同業拆借利率（Libor）作為基準。

假設槓桿債券的貸款利率是Libor+1%，由於Libor是浮動的，如果市場加息，Libor會上升，借貸成本就會上升，但息差1%是不會改變，變的只有Libor。為對沖Libor上升風險，投資者可買入利率掉期。根據利率掉期協議，投資者會定期以固定利率去換取浮動利率的現金流。投資者所收取的浮動利率現金流，就會用來支付銀行貸款的浮動利率貸款。因此，對投資者而言，無論市場加息與否，投資者實際只需要支付一個定息的貸款成本，因此期內的利率風險可以說是完全對沖，浮動的貸款利率得以鎖定。

當然，買入利率掉期是有成本的，特別是在市場預期加息的情況下，溢價便會愈高，但其好處是讓投資者「計到數」。若融資利率加上利率掉期溢價，相對於債券的固定收益回報仍然有一定空間，那麼投資者在預期加息的環境下，仍然可考慮是否以掉期投資債券。

#### 浮息債券操作示範

在加息的環境下，債券的價格會受到不利的影響，然而浮息債券能為投資者提供與市場利率掛鉤的利息回報，當參考市場利率（一般為Libor）上升，利息回報便會同步增加。因此，浮息債券類別可以對沖利率波動風險，適合有意投資債券、同時希望避開利率風險的投資者。

該債券為浮息債券，票面利率以三個月倫敦同業拆息（3M Libor）為基準加400點子或4%，債券收益每三個月重新確定一次，對上一次定息日為5月21日，當時三個月Libor為2.533125%，因此債券的總收益固定為6.533125%。下一次定息日為8月21日，如期內利率上升，假設屆時三個月Libor升至3%，則債券的總收益會同步上調至7%（3% + 4%）。

筆者所用的其中一間私人銀行，能夠提供60%的融資率（LTV），意味只需40元的資本投入便可買入100元的債券，槓桿比率為1/40% = 2.5倍。融資利率為COF + 1%（不同銀行的COF有異，但大致與Libor相若），可選擇7天 / 14天 / 1個月 / 3個月的利息期，利息期愈短，利率愈低。為了對應該浮息債券的利率重置日，投資者可選擇同為三個月的利息期。債券的下一次定息日為8月21日，假設投資者於同一天買入債券，同時選擇三個月的利息期，債券下一次的利率收益重置日與貸款的利率成本重置日，將會為同一天。融資成本為3% + 1% = 4%，而債券收益率為7%，槓桿操作下的套利息差將會固定為3%。

#### 慎防補倉風險

槓桿債券操作原理，以上述例子，其實是買入一隻7%回報的債券，將之抵押予銀行，利用銀行低息融資的優勢，借出60%資金，再將借出的資金再次買入該債券，再將債券抵押予銀行融資，將套現出的資金再度買入債券，如此類推，重複操作。當然實際操作不用這樣複雜，買入債券時直接只須支付40%資金，就可以買到100%面值的債券，其餘60%由銀行融資，槓桿比率就是1/40%=2.5倍。以上做法就等同套息交易，借低息資金買入高息資產，從而套取息差。

假設融資成本為4%，買入7%回報的債券抵押予銀行，以4%成本套現60%資金。如用盡2.5倍槓桿，即可將原本7%年回報提升至11.50%。

槓桿債券最大的風險是，當利率上升，融資成本增加，使息差收窄，最壞情況是利率倒掛，即融資成本比債券收益高，槓桿部分便會造成虧損。與此同時，債券價格也會因為利率上升而下跌，增加了投資者的補倉風險。而更嚴重的是，當利率上升時，以上兩個問題會同時發生。

由此可見，利率上升是槓桿債券投資者的最大敵人。在預期利率上升時投資債券，要規避利率上升所衍生的風險，最有效是選擇浮息債券。原因是當利率上升，浮息債券的收益率也會同步向上調整，因此能夠有效抵銷上升的融資成本。此外，由於浮息債券的收益率與利率是同步的，浮息債券的債券價格在利率上升時也會受到較少影響，潛在補倉風險也較低。
