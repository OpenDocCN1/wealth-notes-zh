# QE 毒癮難戒又危險

因此，不論聯儲局以何種方法去加息，也必須配合縮表來同時進行，貨幣政策正常化的過程必須與減少資產規模來配合，否則聯儲局加多次息也無助收緊市場的流動性，資產價格只會一直繼續上升，製造真正的資產泡沫。當經濟衰退來臨時，資產價格和息口均處於高水平，資產泡沫在高位爆破，到時所造成的影響更嚴肅。

筆者很早之前的文章也曾說過，QE 猶如吸毒，很難回頭，要回頭過程亦相當痛苦。這三輪 QE 的影響，除了完全改變了聯儲局一直以來慣常的貨幣政策操作，亦扭曲了全世界經濟體的金融生態系統，同時亦使聯儲局難以用傳統 OMO 的方式去調控市場利率。當資產負債表過分吹大了，所有傳統的貨幣政策都已經難以產生效用，想再以傳統的貨幣政策去正常化已扭曲的金融生態系統，難矣，要做卻必須要用新藥。正如長期吸毒的癮君子想戒毒，絕非易事。
