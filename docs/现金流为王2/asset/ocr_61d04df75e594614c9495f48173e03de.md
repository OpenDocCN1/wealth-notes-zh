# **資產「升值」的**
**意義何在？

不論是個人理財、投資、資產配置，抑或營運一間公司，現金流都是最重要的元素。對一個企業而言，不論該公司每年有多豐厚的盈利，年賺純利以十億計，帳面擁有過百億元資產，只要沒有持續穩健的現金流入，就代表沒有良好的資產流動性。當市場系統性風險（Systematic risk）來臨時，儘管實力強橫的大企業也有可能周轉不來，當資金鏈斷裂，企業便面對破產倒閉的風險。
