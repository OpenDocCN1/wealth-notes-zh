# 第六章：認同實踐與意識整合

# 6.5 迷你倉市場
整合下的機會

自2016年中迷你倉大火事件後，公眾及相關政府部門對工廈迷你倉的消防問題更關注。不同部門，特別是消防處，針對消防安全問題進行研究，並多次修改現有條例去規管迷你倉運作。及後消防處更頒布最新的「迷你倉條例」，要求儲存倉之間的間距不少於2.4米，即相等於一般超市三倍的走廊闊度，單是根据此要求，當時市場上所有迷你倉都已經違規。據了解，相關部門僅給予一段時間的寬限期，迷你倉經營者須在寬限期內清拆或改建所有迷你倉，否則相關部門將會發出清拆令並罰款。

新條例令迷你倉市場發生了重大轉變，以時昌迷你倉為首的迷你倉業界面臨結業的危機。業界反映，若遵從最新的條例，倉內實用面積將下降三至四成，儘管加價三成，也未必能夠填補少收的租金。而且清拆或改建所有迷你倉涉及一次性巨額成本，這迫令不少迷你倉經營商選擇結業。隨著政府部門給予的
