# 有現金流．才有時間值

正如筆者經常見，投資回報＝資本×回報率×時間。真正懂得投資的人，是利用時間為資本增值，收益取決於時間，而非市場因素。時間可準確計算，市場因素卻不能。只有重視現金流的投資者，時間才是他們的朋友，時間對他們來說才有價值（時間值）。

搞不清收入、有效資產和資本概念的投資者，他們看不過現金流的價值。他們一般依靠資產的價格升值（市場因素主導），以及靠工作、勞力換來的主動收入，被動收入比例極低，以緻他們不得不繼續工作，以時間和勞力換取金錢，而時間則不會恆常而主動地為他們創造收益。這是大多數香港人的通病，通病都輸了「時間值」，要知道「時間值」包含了複利的力量，大部分香港人損失的實在太多了。

當大家了解收入、有效資產和資本的概念，便明白投資需要資本，資本是由現金流轉化而成，而現金流由有效資產所產生，有效資產的累積需要有資本，資本是由現金流轉化而成……投資的關鍵在於多元化收入，要令齒輪不停轉動，不能或缺的就是現金流，缺乏現金流，資本、資產、收入都會乾涸，當齒輪不再轉動，投資組合就不會繼續自然成長。

看通了，投資的關鍵是現金流，一盤生意的血液是現金流，資產價值的起源也是現金流。
