# 投資需要「不記名」融資平台

舉信用卡的例子是想說明任何一個人都擁有信貸額，亦即是個人的融資能力。而香港的金融機構在決定是否借錢給你之前，會先審查你的信貸紀錄，包括審查你的環聯信貸報告 (TransUnion，簡稱TU)，而每一個借過錢的人，理論上都有一份TU。當你申請貸款時（例如樓宇按揭或汽車貸款，甚至是新信用卡），銀行或財務機構會參考你的TU內的信貸評分，以評估你個人的「財務誠信」和了解你的借貸情況，包括你的信用卡借貸、私人貸款、按揭、車會等所有借貸項目均一目了然。在金管局嚴格收緊信貸的今天，過度信貸的情況相信難再出現。

除了個人TU，個人借貸能力主要取決於個人的入息水平。在金管局收緊信貸下，入息供款比率的壓力測試十分嚴緊。年青人要買樓上車，前題是對先搞好自己的信貸記錄和提升自己借貸能力。

對於已買樓人士，在現今世代想靠靠不斷買樓，然後以一折二、二折四的傳統方式致富已不可能，原因是政府推出的辣招稅和金管局對非首置的信貸收緊。投資，我們需要尋找「不記名」（不記錄在TU）、沒有壓力測試的「融資平台」，為我們的投資更有效地釋放流動性。想獲得槓桿的選擇權，又要控制使用槓桿時的借貸成本，我們必須準備多個不同的融資平台。
