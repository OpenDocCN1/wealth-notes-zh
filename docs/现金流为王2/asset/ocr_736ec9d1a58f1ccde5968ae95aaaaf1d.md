# 知己知彼 掌握心理

一向隨身帶備支票的筆者當然早有準備，一面見二話不說單刀直入談條件，每月23萬租15年（比美心原來的租金還高，而之前的租約是12年），隨即準備好支票。業主一聽到15年便說太長了，不可能！筆者為不讓他有太多時間考慮，速戰速決：立即開另一張支票遞向他：「24萬一個月，十年約。」業主聽到後，表情開始有點軟化，但仍搖頭晃腦說十年太長了，卻一邊伸手接過支票，明顯是難抵金錢的誘惑。支票是三按一上（按金加上期）合共96萬，準備充足的經紀同事早已在旁準備好臨時合約，即時簽署成交。就這樣，這一宗十年租約的deal僅用了20分鐘便完成了。一步出大門口，落到樓下，同事即問時間我為何這麼有信心，大拿拿廿幾萬一個月，你不用先回公司計計劃？我說不用，我心裏有數。

青山道與大南西街交界人流極旺，原來的美心餐廳佔地約8,000呎，包括了座位及廚房，但門口僅在青山道的一小角，其他對外全部密封。筆者一直認為若將青山道一排非結構牆身全部打開，將之變成數個小街鋪，其價值和租金定必大大提升，而將工業地廠改為街鋪，只需向地政總署申請短期豁免書（Short-term Waiver）即可，每月僅需按改變用途單位的地面面積（Floor area）補回差價費用，然而工業變成零售街鋪的價值提升，以建築面積計算遠比只按地面面積補價的費用高，從而能做到強化資產（Asset Enhancement），從而提升租金（Yield Enhancement）的效果。
