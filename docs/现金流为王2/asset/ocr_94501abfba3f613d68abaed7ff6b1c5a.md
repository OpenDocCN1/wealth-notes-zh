# ## 2.4 浮息債券
### 應對利率上升

市場利率風險上升，債券價格就會下跌，原因是現有債券的相對回報（Relative return）下降，但也不代表所有債券下跌的幅度都會一樣，例如年期短的債券、浮息債券所受的影響相對會較少。所以在預期利率將會開始回升時，選債技巧十分重要。專業投資者會分析浮息曲線（Yield curve）、預測利率走勢、加息幅度、分析加息對經濟的影響、通脹預期等因素。因此，利率風險同時會導致債券價格的波動。

利用槓桿投資債券，先天結構上有一個問題——利率和收益不匹配。由於融資利率一般為浮動利率（以COF / Libor / Hior 為基礎利率），而市場上大部分債券為固定收益債券，因此，當利率上升時，套息空間便會收窄。在面對利率正常化的加息環境，除儘量挑選年期較短的債券外，槓桿投資債券時一般可採取兩種方法，對沖利率上升的風險：
