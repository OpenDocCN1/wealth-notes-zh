面對這個未來只會有增無減的開支，我們要做的不只是去努力創造收入，更重要是構建一個能產生現金流且持續增長的「收入系統」，而筆者的「REITs + Bond」（房地產信託基金 + 債券）投資組合是一個例子，希望大家不要將焦點單純放在「工具」之上，更重要是去了解建立這個系統背後的理念，然後大家便會明白組合內運用不同操作的原因，進而不同的市況下，均能因應市場的變化與自己的情況作出最佳調節，創建真正屬於自己的投資系統。

# 為何選擇「REITs + Bond」？

《現金流為王》提到筆者的金融資產被動收入組合——「REITs + Bond」，基本原理如下：

債券以短債為主，一般不長於三年，會利用債券本身的倉值（LTV）做槓桿投資，增加回報率。倉值的意息是銀行提供的融資額，以買樓的按揭成數概念去理解會比較容易：若銀行對某債券提供70% LTV，意息等如買樓做七成按揭。

所謂槓桿投資債券（Bond Leveraging）是指買入一隻債券後，將之抵押予銀行，利用銀行低息融資的優勢，根據該債券的融資率向銀行貸款，借回相當部分的資金，將套現出的資金再度買入該債券，如此類推，反覆操作。

當然實際操作上比較簡單，假設債券票面息率為5%p.a.，債券的融資率為80%，私人銀行的融資利率1.5%，買入債券時就只須支付20%資金即可買入該債券。
