# 1.1 你想得到何種「收入」？

![](bbox=[0.1, 0.09, 0.35, 0.3])

股神巴菲特（Warrant Buffett）曾經說過：「如果你沒有找到一個當你睡覺時還能賺錢的方法，你將一直工作到死。」

內地有一名詞叫「睡後收入」，意思是指睡一覺醒來就有的收入，概念與被動收入一樣。其實內地和香港的打工仔普遍都一樣，窮一生精力，以努力換取收入，以時間換取金錢，大部分人都不能做到「時間」和「金錢」兩者兼得。要做到兩者兼得，收入長遠必須透過構建一個「系統」而產生，而非單純以勞力和時間來換取。「系統」可以是一個商業模式（Business model），或者是一個投資組合（Investment portfolio）。以下看看不同人擁有的不同收入種類：

+   1. 擁有「系統」的資本家：睡後收入（睡眠後就有的收入）
2. 一般打工仔：稅後收入（賺到錢還要繳足稅後才屬於自己的淨收入）
