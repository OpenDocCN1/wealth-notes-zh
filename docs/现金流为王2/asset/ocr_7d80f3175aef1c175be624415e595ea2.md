# 後記

有朋友說一開始讀筆者書時感覺似是一本工具書，但看畢全書就發現當中包含了「招式＋心法＋哲學」。我很高興讀者讀到了一點點的哲學味道。事實上，工具書本來就不是我想寫的書類。很久以前有另一間出版社曾與我洽談過出書事宜，希望筆者寫某些特定的投資工具，這與我出書的目的不同，因此最後婉拒了。

《現金流為王》和本書完整地記錄了我的投資路心路歷程和一路過來所運用的投資思維，我自己也看著看著自己的思維在人生的不同階段一直轉變。因此，這可以說是一本我走到此刻，看回頭時，以我今天的思維重新編寫的一本投資札記。

承蒙各位不嫌棄我的長篇大論，一直花時間閱讀至此。最後，希望本書能夠為大家帶來一些啟發，刺激大家對投資和嘗商的另類思考。

歡迎大家在我的博客閱讀我的文章，或通過電郵或社交網站與我交流。祝大家都擁有一個富足的人生！
