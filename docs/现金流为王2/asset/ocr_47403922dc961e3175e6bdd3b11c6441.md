# 4-3 槓桿前先要「融資平台」

從理財角度，要做好資產配置，我們必須要有潛在的槓桿能力，有助投資組合發揮更高的收益，同時為投資組合保留更多的流動性，有效把握一瞬即逝的投資機會。為此，我們須要擁有不同的「融資平台」。所謂「融資平台」，即能夠提供低廉成本融資的信貸渠道。

首先，我們知道投資需要要有「槓桿選擇權」，即有條件隨時隨地對所投資的資產使用槓桿。這取決於兩個因素：

+   1. 投資的資產是否有「可槓桿」的空間？換句話說，該資產能否被廣泛接受為抵押品，並能輕易取得融資？
2. 投資者是否擁有合適的「融資平台」？

以上兩個因素決定了投資者對資產的可槓桿操作能力——融資成本和最高槓桿成數。
