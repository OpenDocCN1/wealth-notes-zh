# 投資債券 須考慮發行者資產

特別在現時這個風高浪急的市場下，債券孳息率已大不如前，債券孳息率低亦意味著債券的價格昂貴。以前孳息率超過10%的內房公司，現在發行的債券孳息率只有5至6%，這並非因為企業的信貸能力有所改善，而是因為收益率差價（Yield spread）收窄，意指企業債收益率和零風險資產收益率（Risk-free rate）的差距正在不斷減少。

投資債券盡量避免投資業務經營能力主導的公司，也不應期望公司業績有亮麗的增長，有此期望者，應該買股票。投資債券，投資者是債主，不應與公司共存亡，在最壞的情況下，即使公司盈利能力轉弱，基本面情況轉差，投資者都可以獨善其身，於債券到期時安全取回本金。這就是作為債主與股東的最大分別。

因此，投資債券時應考慮公司目前持有多少資產，除償債能力外，更應考慮公司是否持有「極具價值」或高流動性、高變現能力的資產，然後就是看公司的債務水平，因為其他債主都将有可能就是你的「競爭者」。所以，投資者如希望長線投資債券的話，應更注意公司的資產基礎、資產本身的性質和資產價格的穩健性。從此角度出發，REITs Bond（房託基金發行的債券）其實也是個不錯的選擇。
