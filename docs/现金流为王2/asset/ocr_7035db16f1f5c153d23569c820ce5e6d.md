# 樓市的購買力來自再融資

正如今天香港的樓市，金管局再次出招限制按揭成數，其實最大影響的是再融資。金管局的出招是有道理的，在住宅供應不足的情況下，市場的潛在參與者要買樓都是鬥購買力，而現時今日鬥購買力已經不再是講人工的高低，也不是講儲了多少錢。

由於香港樓價多年來不知上升多少倍，大部分香港人的購買力其實是透過再融資去釋放物業的資本增值部分，使未實現的盈利轉化為現金流，然後現金流成為新資本，再投資買入其他物業資產。遊戲規則已變成「在資產不停升值的情況下，擁有愈多資產的人就能融資更多的資金去買入更多的資產，然後資產繼續升值」。無窮的「升值＋再融資」的購買力，不停去追逐有限供應的住宅物業，結果會如何，應該不用我多說。

# 追逐資產升值 忽略資產重量

香港入憑投資住宅賺過錢的人不計其數，他們甚至身邊的人都受到了根本性的影響，在他們眼中投資的邏輯就如他們買樓一樣，「買入資產等升值，加按套現再投資」，時間長了，他們便愈儲愈多「重資產」，但都忽略了現金流的重要性。筆者一位讀者曾經郵寄諮詢意見，其手持的八個物業總資產達八至九千萬，但每月淨現金流入竟不足兩萬元。這是典型的重資產格局，重磅到勁都動不了。
