# 推薦序

汪敦敬
祥益地產總裁

我經常強調「影響樓價最大的因素是貨幣」，當中是包括了匯價及資金流。

多年來，樓價升幅往往和資金增加的倍數成正比。本來，匯價升跌也是左右樓價升跌的重要因素，但是 2009 年後的環球量化寬鬆令資金氾濫，過量的資金不单令資產價格上升，香港更脫離了聯繫匯率的規限，長期進入「悠長的低息年代」，也凌駕了匯率，樓價進入了長期上升軌，果然是「現金流為王」！

香港在 2016 年的英國公投後幾天就成為了西方的資金停泊池，短時間內要面對 7,000 億港元的資金涌入，執筆寫此序言的時候，剛好美股連續數星期面臨下跌的調整，若美國市場出現泡沫爆破，那麼資金應走去哪裏停泊呢？

既然現在是「資金流為王」的年代，誰人能夠透徹掌握到資金流的財技、理論基礎及能提供運用現金流的方案？很欣賞 Starman 的著作，掌握到重點，深入淺出。我推薦各位閱讀《現金流為王 2》一書！
