# 以管道建立管道

由於建造一條獨立管道的成本浩大，若我們能夠利用第一條管道的基礎，包括已建管道分佈的地理位置，和已創造的流水（被動收入）去建立另一條管道，所開拓的新管道就能去到更遠，且能到達其他人更難去得到的新領域，建造時間和成本亦能大大減低。做事實懂得善用手中已有的資源，而所得的成果必須能夠累積。這將大大節省一個人努力所需付出的時間，達到事半功倍的效果。

此外，能利用已建管道的這流水，亦有助降低建造新管道的資本開支（Capex）。利用投資收入再投資，這就是再投資操作（Re-investment），當中的複息效應應大大加快「系統」建立的速度。當你的管道愈來愈多，「系統」就會逐漸形成，你更可利用新增的流水收入，直接收購別人的獨立管道，然後與自己的管道「系統」接上，用最短的時間將規模擴充。由於它在別人手中只是一條獨立管道，但落入你手中卻是「系統」一部分，能收到 $1+1=3$ 之效，這就是協同效應（Synergy Effect）。
