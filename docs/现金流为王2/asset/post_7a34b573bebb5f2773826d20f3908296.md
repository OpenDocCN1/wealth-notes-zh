## 3.2 嚴謹對「資產」下定義

明白累積資產的概念後，你不會再期望利用重複的交易，不停買入和賣出資產去賺取金錢回報，因為賣出資產獲得金錢後，儘管能賺取利潤，但若找不到更好的資產進行配置，最後只有兩個選擇：一是持有長期貶值的現金，等待更好的投資機會，然而等待是一種成本，會一直輸掉時間值，還要不知等待的時間有多長；二是被迫急於買入質素更差的資產，這種做法比等待的風險更高。現實生活中，不難發現有不少散戶出售資產賺了少許利潤後，持有現金一直輸時間值，最終按捺不住再入市，胡亂買入其他資產，結果得不償失。

這解釋了為何富人与窮人的差距會隨著時間愈拉愈闊，原因是兩者投資的思維和方式不一樣。富人投資的方式是買入資產，資產產生現金流，現金流再投資資產，從而導致長遠累積資產的目的；而後者投資的目的是純賺錢，然後等下次機會再投資，再賺錢。兩者的分別是，後者的投資方式欠缺連續性，投資與投資之間嚴重輸掉了時間值。長期下去，兩者的差距會大到難以想像。

### 分清三種「資產」

作為一個投資者，必須將自己的思維和層次提升。因此，在執行理財計劃或資產配置前，首先要將「資產」的定義界定清楚，深入了解「資產」的概念，才能作出理性而全面的投資決定。

筆者「資產」的概念大致可分為三種：

- 1. 廣義資產

  又稱會計資產（Accounting Assets），指會計學上對資產的定義：一個人所擁有的所有經濟物品／資源，並能以貨幣單位衡量的，均稱為資產，如銀行帳戶上的現金存款、樓宇住宅物業、一張桌子或椅子。只要產權能清晰界定，都能稱為一個人／一間企業的資產。

- 2. 有效資產

  廣義指凡能於一段時間內持續地產生經濟收益的資產，均能稱為有效資產（Effective Assets）。從資產配置的角度，筆者一向要求收益是能具體地「計到數」的，因此筆者將有效資產定義為凡能在一段時間內持續地產生現金流收益的資產，才稱為有效資產。正如《富爸爸，窮爸爸》作者羅伯特．清崎對資產的定義是：當持有一項物品，這物品會自動使現金流向你的口袋，就是資產。債券這種「工具資產」便是一例。

- 3. 值得累積的資產

  除於指定時間內產生現金流收益外，其產生的整體收益會隨時間有所增長，且增長速度比通貨膨脹快，這才是我們長遠值得累積的資產。還記得前文提到投資或資產配置的最終目標並不是「金錢」，而是「資產」？投資過程中，資產價格上升，沾出（註：应为「抽出」或「賺出」，OCR「沾出」可能是「抽出」之誤，語境為從資產中取回現金，修正為「抽出」）資產所賺取到的「金錢」並非投資的最終目的，因為投資是長途賽，你不會賺了一次錢後就停下來永遠不再投資，而由於銀紙長遠貶值，資產長遠升值，投資賺錢後必須將沽套現的資金重新投入其他資產，才不會被時間將你的資產購買力吞噬。不論是新投資或再投資操作，投資項目的投資比例也應儘量投入值得累積的資產為主，從而實踐投資是為了「賺資產」而非「賺錢」。投資要認清「目的地」。

### 自行構建完美的「資產」組合

以上概念十分重要，投資者很多時候以為自己知道，實際上可能只是知半解。有些人或會認為這些概念不重要，無須過分嚴謹，就由得它含含糊糊就算了，十年過去後，可能會發覺自己明明投資有「技術」，為何身家就是給懂得累積「資產」的普通人比下去，甚至遠遠拋離。

這單純是 2. 有效資產 和 3. 值得累積的資產 在市場上並不難找到，然而同時具備兩者特質的資產卻不容易找。雖然要找到能定期產生高現金流回報，同時其整體收益 (Total Return，包括現金流和資本增值) 的資產項目不容易，但我们卻可通過精明的資產配置方式，結合不同資產的特性，自行構建能同時滿足 2 和 3 的投資組合。

筆者提出的「REITs + Bond」投資組合就是一個例子。會選擇以 REITs 和槓桿債券去建立自己的投資組合，是基於兩種資產的不同特質性，而兩者的優劣能夠做到有機互補。

### 3.3 投資「有效資產」的心態與考慮

從「REITs＋Bond」投資組合的例子中，我們可以看到債券其實只是一個會產生現金流的「工具資產」（有效資產的一種），本身並沒有資本增值的作用，因此債券並非長遠值得累積的資產。

對於投資「工具資產」如債券，投資者的目的必須十分清晰，就是要安全、穩健地賺取它的高現金流回報，取其風險低、高現金流回報的好處。因此，筆者認為投資債券一定要持有至到期的心理準備，不論你使用槓桿與否，總之投資者必須設定自己有能力持有債券至到期日取回本金，這是rule 1。

#### 投資債券 須考慮發行者資產

特別在現時這個風高浪急的市場下，債券孳息率已大不如前，債券孳息率低亦意味著債券的價格昂貴。以前孳息率超過10%的內房公司，現在發行的債券孳息率只有5至6%，這並非因為企業的信貸能力有所改善，而是因為收益率差價（Yield spread）收窄，意指企業債收益率和零風險資產收益率（Risk-free rate）的差距正在不斷減少。

投資債券盡量避免投資業務經營能力主導的公司，也不應期望公司業績有亮麗的增長，有此期望者，應該買股票。投資債券，投資者是債主，不應與公司共存亡，在最壞的情況下，即使公司盈利能力轉弱，基本面情況轉差，投資者都可以獨善其身，於債券到期時安全取回本金。這就是作為債主與股東的最大分別。

因此，投資債券時應考慮公司目前持有多少資產，除償債能力外，更應考慮公司是否持有「極具價值」或高流動性、高變現能力的資產，然後就是看公司的債務水平，因為其他債主都将（註：「將」多餘，刪除）有可能就是你的「競爭者」。所以，投資者如希望長線投資債券的話，應更注意公司的資產基礎、資產本身的性質和資產價格的穩健性。從此角度出發，REITs Bond（房託基金發行的債券）其實也是個不錯的選擇。

### 3.4 從收入、有效資產、資本看現金流

香港首富李嘉誠先生終於正式宣佈退休，各大報章紛紛報導李生的金句和發跡史，在其中（註：OCR「在在其中」重複，修正為「在其中」）一篇報道中，李嘉誠談到成功之道在於「一定要有現金流」。他回想「以往從事塑膠花製造業時，親身體會到現金流是主宰公司命脈的因素，一直銘記於心中」。

傳統以來，只有做生意的人才知道現金流的重要性，一般投資者卻對此忽略。對生意人來說，現金流是血液，不管這盤生意的盈利有多強大、公司的盈利能力有多強，如果沒有現金流，就會即時死亡。

一般投資者沒有這個概念，原因是大部分投資者拿來投資的資金只是閒置資金，即是「閒錢」，並不是他們產生收入來賴以為生的方式。收入的產生不外乎主動和被動，前者靠勞力，後者靠投資。社會上大部分人的主要收入來源為主動收入（靠工作、勞力換來的收入來源），因此大部分人根本沒有想過現金流對投資的重要性，總之投資能產生即時收益就好了，收益指的是總收益概念（Total Return），而沒有現金流價值的概念。

#### 「收入」須是現金流

在進行更進一步分析前，宜先再定義一下「收入」。收入是以持續流動狀態呈現的一種收益，所以收入必須是一種現金流。資產的升值，既非持續，又非流動，因此並非收入。

以上並不是艱深複雜的概念，但必須嚴謹看待。事實上，大部分人也搞不清資產和收入的概念，往往將資產值和收入混為一談。混亂和含糊不清的概念往往直接影響投資行爲，對長遠的人生投資計劃影響深遠，不得不正視及及時糾正。

- 收入：持續現金流收益。
- 有效資產：能持續產生現金流的資產。
- 資本：用作投資／買入有效資產的現金流。

收入、有效資產和資本是投資者必須認識的基礎概念，值得留意的是它們都有個共通點，就是三者都必須要有現金流。

資產升值了，只屬帳面，如不能將升值部分轉化成現金流，就永遠不能將升值部分轉化為新資本進行再投資，買入更多不同的有效資產，長遠為投資組合產生出更多的持續現金流收益（收入）。

#### 重資產 如現金流黑洞

香港大部分人都沒有搞清楚上述的概念，因此儘管他們沒有良好的「產融結合」工具（或因為不重視現金流而從沒有計劃去構建一個「產融結合」的平台），仍然都只繼續集中投資低現金流收益的物業資產。他們不介意現金流收益低，只期盼資產繼續升值，為他們帶來資本增值的帳面收益，誤以為帳面的升值是收入的一種。結果，一段長時間過後，他們滿手都是低現金流收益的物業資產，並會因為資產價格的升跌而影響投資情緒。

只累積不會產生或產生低現金流的資產，現金流只會愈來愈少，那些重資產就像黑洞一樣將現金流都吸收，這就是物業資產的特質。要必須（註：語序調整，改為「必須」）配合再融資（Re-financing），將升值部分轉化為現金流，成為再投資的資本，血液才不會隨時間流乾，投資雪球才不會停下來。

相反，投資及累積「有效資產」（會持續產生現金流收益的資產），現金流會愈來愈多，而新增的現金流能成為新資本不斷進行再投資，再不斷持續累積「有效資產」產生更多的現金流，形成資本雪球（Capital Snowball）。

#### 有現金流．才有時間值

正如筆者經常見，投資回報＝資本×回報率×時間。真正懂得投資的人，是利用時間為資本增值，收益取決於時間，而非市場因素。時間可準確計算，市場因素卻不能。只有重視現金流的投資者，時間才是他們的朋友，時間對他們來說才有價值（時間值）。

搞不清收入、有效資產和資本概念的投資者，他們看不過（註：应为「看重」或「看見」，OCR「看不過」語意不通，结合上下文「看不見/不重視」，修正為「看重」或「看見」，此处取「看見」之近義，或原文為「不看重」，OCR「看不過」可能是「不看重」之誤？ 字形：「看不過」vs「不看重」。 不相似。 可能是「看不懂」？ 也不像。 結合「依靠資產價格升值...被動收入比例極低...不得不繼續工作」，這裡是在說他們「不重視/不看見」現金流的價值。 修正為「看不見」或「不重視」。這裡修正為「不重視」）現金流的價值。他們一般依靠資產的價格升值（市場因素主導），以及靠工作、勞力換來的主動收入，被動收入比例極低，以緻（註：「致」多餘，刪除）他們不得不繼續工作，以時間和勞力換取金錢，而時間則不會恆常而主動地為他們創造收益。這是大多數香港人的通病，通病都輸了「時間值」，要知道「時間值」包含了複利的力量，大部分香港人損失的實在太多了。

當大家了解收入、有效資產和資本的概念，便明白投資需要資本，資本是由現金流轉化而成，而現金流由有效資產所產生，有效資產的累積需要有資本，資本是由現金流轉化而成……投資的關鍵在於多元化收入，要令齒輪不停轉動，不能或缺的就是現金流，缺乏現金流，資本、資產、收入都會乾涸，當齒輪不再轉動，投資組合就不會繼續自然成長。

看通了，投資的關鍵是現金流，一盤生意的血液是現金流，資產價值的起源也是現金流。

### 3.5 輕資產／重資產 的投資模式

筆者經常說「重資產、輕資產」，其實是形容一個商業模式。在新經濟模式的趨勢下，輕資產遠比重資產的商業模式「值錢」，從資本市場的市盈率 (P/E ratio) 便能夠反映出來。

事實上，「重資產」、「輕資產」並不是一個財務概念，財務中只有固定資產和流動資產、有形資產和無形資產的概念，輕資產和重資產其實是一個「策略性」(Strategic level) 的概念。一般而言，重資產主要是指固定資產集中、資本密集 (Capital intensive) 的商業模式，如機械、鋼鐵等行業，這類行業需要大量的資本投入；而互聯網、電子商貿、中介代理等領域的固定資產相對較少，資本投資入（註：「入」多餘，刪除）亦相對較低，其營運模式我們稱為「輕資產模式」(Asset-light Strategy)。

#### 資產輕重看效率

要判斷輕資產還是重資產的商業模式較好，首先我們需要思考一下哪種模式的創造價值能力、效率比較高，當中我們需要同時考慮資本投入的因素。一個特別重要的指標就是「資產產生價值」的能力。從經濟、財務的角度，一般會以經濟附加值（Economic Value Added，EVA）作為判斷資產創造價值能力的指標。

經濟附加值是企業在一段時間內的稅後營業淨利潤（NOPAT）與投入資本的資金成本之差額。也就是說，價值一元的資產所產生的淨利潤，與相同金額的銀行存款或債券利息相比，如前者較後者低，那就不如把錢直接存入銀行或者購買國債算了，無需投入龐大的資本，辛苦經營，而只為換取較低的利潤。簡而言之，這是機會成本（Opportunity cost）的概念。

因此，假設利潤相若，從資本密集性（Capital intensity）的角度，輕資產比重資產模式更有效率，原因是前者能以較少的資本投入換取相同的利潤回報。這是為何輕資產模式的企業在資本市場上較「值錢」，這同時也含蓄（註：应为「蘊含」或「暗示」，「含蓄」用詞不當，修正為「蘊含」）著輕資產企業的潛在增長能力更高，因為它的成長並不全純依靠資本投入，而主要是依賴非資本投入的經濟價值創造能力，這也就是營運模式本身的價值。

作為資本家，除了企業營運團隊的營運能力，更關注的其實應該是企業的商業營運模式，因為這決定了一項投資的資本回報率。要極大化資本回報率，就是要在最短的時間內，以最少的資本賺取最高的回報，這也就是資本運作的真諦。

同樣道理也可應用在個人投資。從資產配置的角度，也可分為輕資產和重資產的投資模式。重資產指資本密集、回報率和流動性偏低的投資物。所有資產都有「重量」，愈「重」的資產，就愈難轉身，意味著其流動性偏低，同時其現金流回報（Investment yieild）（註：「yieild」拼寫錯誤，修正為「yield」）普遍也偏低。長時間累積重資產，最終會使投資組合的重量不斷增加，形成現金流黑洞，將資本和現金流都吸收，最終形成「死亡鏈結」（Hardcore），使投資齒輪停止轉動。這是大部分只會買樓收租的香港人面對的問題。隨著政府辣招和按揭成數的收緊，只懂買樓的投資者最終會陷入重資產的hardcore，而原因是他們根本沒有做好資產配置。

#### 營運模式重要過重量

要為重資產投資組合減磅，可以通過融資解決，這是為何筆者常說投資重資產必須要結合融資手段，做到「產融結合」，從而釋放資產的流動性，利用槓桿將資本回報率提高，同時也能夠使資產的升值部份轉化為現金流，再投資不同的資產類別，做到分散投資，將投資重量分散到不同的投資品種，達到資產配置平衡和現金流多元化的目的。

筆者一直採取輕資產的投資模式，但這並不代表我不投資物業磚頭。輕資產抑或重資產，關鍵其實不在於投資物本身的「重量」，而是經營個人投資組合的「營運模式」。看通了，投資，就是講求資本運用的效率，及資產配置的平衡。

### 3.6 「防守」才是最強的「進攻」

曾有不少讀者問我的投資組合是否只是經常提及的 REITs、債券和房地產項目，每次我都笑著回答「當然不是」。事實上，作者在博客內提及得較多的「REITs + Bond」組合，只是其中一個主要能產生穩定現金流的「永續投資引擎」。這個引擎無需要入電油，靠的是生生不息的投資現金流為引擎注入能量。正如前文所解釋，現金流收入是投資資產的產物，現金流再投資時是資本，資本投資能持續產生現金流的資產，令這個投資引擎得以自給自足，永續發動。

我在博客中、書中有不少篇幅提及「REITs + Bond」組合，又以不同層次深入解釋該組合背後的原理，因為我認為我的「REITs + Bond」組合是一個值得讓大家參考的投資模式，當中涉及的投資理念，我個人認為為（註：「為」多餘，刪除）有一定的啟發性和參考價值，包括不同投資產品的優劣互補、槓桿的使用、再投資的力量、資產累積後自然去槓桿等等。
