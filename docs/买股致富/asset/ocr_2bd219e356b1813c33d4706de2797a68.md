# 第2章 股票增值如何達到最大？

有足夠的其他資產來防護財務緊急事故，那麼，尤其是他還年輕的話，他或許會決定，如果遇到一家前景光明的企業傑出主管，他應該承受巨大風險，等待這位以前不知名的企業主管獲得金融界認同後，原已算是豐厚的投資獲利，將可因為本益比急遽改變而再翻漲數倍，這麼一來，便會為他帶來難以置信的利得。

至於大戶投資人，選擇就更簡單了，他們已擁有足夠的資產來大幅提升生活水準，因此，以這種幸運地位來看，沉重的投資虧損可能危及這種地位，因此他應該集中投資在各式股票的組合，包括類似10年前的先鋒金屬，以及現今的先鋒金屬。然而，還要參考其他多種變數來做最終決定，例如，他多有錢（也就是他可以虧損多少，而不致衝擊他的生活水準），以及他多渴望財富進一步大增（也就是他的年齡、他是否迫切希望為子女預留大筆財產等因素），他或許會決定把少數部位配置在類似先鋒金屬草創時期的股票。無論如何，不管這名個人投資人的投資策略為何，如果他了解當中所牽涉的因素，便可以做出更明智的決定。如果他明白這項總是遭到忽略的基本事實：本益比變動是和獲利變動同樣巨大的投資力量，可造成股價大幅波動，如此一來，他在評估特定情況發生的可能性，以及決定這種情況是否符合他的需求時，便能占據更有利的位置。
