# 投資人與金融業該前往何處？

我在《非常潛力股》一書裡，稱這個方法為「閒聊」（scuttlebutt）。它是要利用跟一家公司有過往來的人士，幾乎都會知道的有關於該公司的大量資訊，這些人士包括客戶、廠商、競爭對手，以及政府或大學的研究科學家，還有以前的員工。他們通常會知道大量有關往來公司的優點；更重要的是，他們也知道缺點。這種線民之中，或許有1、2位說的話可能充滿偏見及誤導。然而，用這種方法收集資訊的人，如果可以聯繫到足夠的消息來源，並明確告知對方想知道的事情，以及為什麼想知道的理由，就會得到想要打聽公司的明確情報。

為什麼用這種兜圈子的方式去收集資訊是很重要的？因為唯有用這種方法，跟一家公司沒有關係的人，才能十分清楚地掌握該公司內部狀況，才能在好不容易聯繫到想投資公司的高層時，知道該向他們詢問什麼資訊。這些公司的高層或許極為坦率，願意言無不盡地回答所有問題。然而，基於他的職業道德，除非有人詢問他，否則哪裡會有公司高層會主動透露他公司的缺點？舉例來說，公司財務長會不會在跟投資人士訪談時主動告知，公司為了培養一些傑出研究科學家所花的大筆銀子都白白浪費了，只因為研發主管與銷售副總裁之間的關係極為惡劣，導致這些所費不貲的產品開發投入，雖然製造出精妙的產品，但其潛在市場卻極為渺小，根本無法為股東創造利益？當然，這種重要資訊絕對不會自己
