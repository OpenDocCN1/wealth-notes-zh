# 投資人與金融業該前往何處？

個人偏見而產生錯誤答案的機會。換句話說，這套系統不僅可以更快產生答案，還可產生更多答案；更重要的是，它產生正確答案的機率也將增加。在投資業，唯有正確答案才能創造報酬率；其他的答案，則是減損正確答案所創造的利潤。

然而，如果這個方法在理論上具有巨大潛力，實際執行時必然要歷經千辛萬苦，才能藉由它創造可觀的成果。而這個領域出類拔萃的人， vốn就不多，因此很難找到足夠的人數，可以組成一支均衡的團隊。唯有嘗試錯誤，才能知道可能發生的陷阱，舉例來說，一位團隊成員或許地位崇高，備受同儕敬重，在無人策畫的情況下，他的看法通常主導局面。然而，在這套系統下，他的判斷或許不會像在現今方法下那麼好，這是因為他不再跟所有過去研究的公司主管有個人交情，許多這些公司可能都不在他自己的地區內。我認為，總有一天，這個問題是會解決的，投資業將發展出方法，以今日無法想像的效率，為客戶提供買進、持有與賣出股票的正確建議。然而，在這種發展的初期階段，需要摸索如何合作協調，所以剛開始的時候，這套系統的總人事成本，不僅可能比現今的方法更昂貴，初期的績效也可能令人失望。
