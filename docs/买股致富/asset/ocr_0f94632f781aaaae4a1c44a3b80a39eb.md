# 第3章 投資人與金融業該前往何處？

密切關係，許多大型投資銀行對某一類公司都極為了解。它們經常有一名合夥人加入公司董事會，這種人脈可以產生真正有價值的投資建議。同樣地，許多大型股票經紀商，撇開它們擔任投資銀行家的時候，是擁有足夠的客戶資金，或是擁有它們在某家公司富裕合夥人的資金，因此，可能也掌握相同的內部訊息。許多股票經紀商，也有合夥人或主管在擔任公司董事。

與此同時，投資銀行家兜售自己的商品，或股票經紀商為了佣金而推薦不必要的交易，這種既得利益的程度，在每家金融公司之間可能很不相同。同一家公司裡，不同的人會有更大的差異。許多金融業人士並未忘記我們一開始談到的 3 個基本觀念，也就是如果他們為前來尋找理財建議的人好好服務，業務便會成長；否則，業務是不會成長的。這些人或許跟那些短視的同事一樣，渴望提升自己的獲利，但他們對某項交易似乎符合客戶利益的重視程度，會勝過他們是否可為自己賺到立即的佣金，或更多佣金。他們這麼做，並不是因為大公無私，而是因為有足夠的遠見，知道想成功的話，必須好好服務他們的客戶。他們知道，唯有時間才可以為他們的工作打分數，而這將決定他們未來的業務是多是少。
