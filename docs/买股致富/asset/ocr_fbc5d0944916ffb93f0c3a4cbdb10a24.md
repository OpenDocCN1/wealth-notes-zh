# 推薦序

# 被驗證了半個世紀的投資智慧經典

作者菲利普·費雪（Philip A. Fisher）是我相當崇敬的投資家之一，他自 1928 年開始了投資生涯，見證了上一世紀美國股市的繁榮發展，1958 年他的著作《非常潛力股》（Common Stocks and Uncommon Profits）在全世界的投資圈獲得高度的重視。我接觸到他的投資哲學是在 1999 年，十分熱愛他的投資智慧，猶記當時自己用電腦將費雪的許多投資智慧語錄彙整在 Word 上列印出來，有空便時時拿出來翻閱，作為我在投資思考上的重要基石。

《買股致富》（Paths to Wealth through Common Stocks）是作者繼《非
