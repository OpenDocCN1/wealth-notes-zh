# 第3章 投資人與金融業該前往何處？

資人客戶的利益。他們不像投資銀行家為了顧及既得利益，而推薦買進他們手上持有的一些股票；他們不像經紀商依賴佣金過活，不必顧慮買進或賣出的金額。那麼，為什麼還是有那麼多投資人找不到讓他們滿意的投資顧問？

實際上，全國各地有些投資顧問（有些稱為專業受託人）表現稱職，符合這 3 項基本觀念。就像其他主要族群都有的情況一樣，一些人做得不好，主要是因為個人缺乏能力，這些人一開始就不該進入這一敘。然而，我想，在這個重要族群中，有 1/3 的人多半是因為他們的工作方法和公司規模，而沒有達到該有的績效，而且，我相信，也沒有達到投資人應有的適當期待。許多投資顧問公司的規模都很小。如果分析它們員工（扣除純辦事員）的工時，我想就可以了解許多事，可以看到他們每星期的工時花在 4 個不同項目，這 4 個項目可能是：

+   1. 拜訪客戶或潛在客戶、跟他們講電話，或分析客戶的個人投資清單。

+   2. 閱讀公司公開財報、金融期刊，或是參加證券分析社團的正式會議。這些不僅是所有金融業都可以取得的資訊，而且立場大多偏向公司，因為公司本身就是新聞發布來源。有關公司不利的情況通常被輕描淡寫，或是避而不談。
