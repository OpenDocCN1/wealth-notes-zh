# 第3章 投資人與金融業該前往何處？

就選股準確性對投資顧問與客戶的高度重要性來看，令人驚訝的是，許多個人與投資機構似乎不花時間去檢查與核對建議買進的正確性，反而花許多時間去跟客戶推銷這些未經充分調查的證券。他們花在精進投資方法，好確定建議買進的股票是真正誘人的時間，甚至更少。然而，挑選傑出投資標的所用的方法是卓越還是差勁，這之間的差異，在短短10年間，便可能造成投資顧問與他的投資客戶是發財還是失敗。
