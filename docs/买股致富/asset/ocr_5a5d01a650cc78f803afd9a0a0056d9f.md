# 第2章 股票增值如何達到最大？

著在他財務能力範圍內善待員工，提供各種可能的福利。員工很快便感受到了，生產力也隨之提升。後來，公司業務蒸蒸日上時，發生了另一件事，跟他贏得顧客尊敬的事件同樣戲劇性，卻是一件悲劇。他派一名員工開著公司車輛出差，在公路上，對向行駛的一輛車失控，兩輛車對撞，雖然先鋒金屬公司沒有過失，這名員工卻因此喪生。

羅賓森知道自己並不想做這件事，但還是覺得有必要立刻打電話給那名員工的遺孀，她有 3 名學齡前子女。羅賓森沒有法律上的賠償責任，然而，他跟她說，公司覺得應該對該名員工的子女負起責任，並立刻成立一個信託基金，由公司出資，讓他們不但可以讀到高中，還可以讀到大學。

這件事迅速傳遍工廠，之後，還在家戶之間流傳。先鋒金屬員工與其他人都認為，這是一家值得效忠的好公司：你隨時都能得到良好的待遇，公司在意外發生時也會照顧你。從那一天起，先鋒金屬的員工離職率就一直低於業界平均水準，隨著事業擴張，公司不再需要隨便招募人手。公司的政策，是隨時在找尋可以升遷的人，而在急速成長之下，公司有許多升遷機會，這家公司的每個職位都有許多應徵者，要找到合適人選完全不成問題，而且，只有最具潛力的人員才會被聘用。
