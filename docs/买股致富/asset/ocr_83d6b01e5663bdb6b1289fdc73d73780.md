# 投資人與金融業該前往何處？

出版《非常潛力股》（Common Stocks and Uncommon Profits）產生了一項意想不到的結果，就是我開始深入思考過去 2 年來最讓投資人擔憂的事情。這是因為幾乎從出版那天起，便有以前不認識的人登門拜訪、打電話和寫信給我。他們大多數都有很想問的問題，這些問題五花八門，但我最常被問到的問題是：「我一直在尋找可以信任的人，我找不到任何人真正了解他自己推薦的股票。我想花錢買這種服務，你可以告訴我應該去找誰嗎？」

即使全國各地不斷有人問我這個問題，我無意暗指現在的投資業無法
