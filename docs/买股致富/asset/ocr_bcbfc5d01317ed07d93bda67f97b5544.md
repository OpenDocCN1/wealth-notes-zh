# 投資人與金融業該前往何處？

碼要有 10 萬美元的資產，才能讓他們的工作獲得報酬，因此，也不會廣泛開發這個大眾市場。

為什麼這些經紀商和投資顧問的收費這麼少？我認為，主要是因為很多顧問的績效實在太差，一般投資人不願再付更多的費用。但假設投資人相信顧問工作很有水準，雖然以我自己的經驗可能不具指標性，因為我並不服務一般民眾，我發現，一旦投資人確信他看到了投資績效，就不會不願意支付較高的費用。為什麼？如果在很長的年間，一個人或一個機構持續創造比大盤指數高出 50% 或 100% 或 150%，為什麼投資人會反對支付比現今投顧或經紀標準費用高上數倍、卻仍只占操作績效很小一部分的費用？

如果真如我所料，未來金融公司會花費更多立即的資金支出，才能取得基本資料，以妥善處理投資人的股票部位，但工作水準會改善很多，金融公司收取的費用因而大幅增加，也是完全合理的。我認為，最近一些主要投資銀行股票經紀商，在它們一般的經紀費用之外，另外收取投資顧問費，這種趨勢會發展成愈來愈大的規模。假設（而且是基本的假設）服務水準好到值回票價，我認為這個趨勢很符合各方的最佳利益。隨著趨勢發展，將來收費將多到一定程度，足以讓銷售人員去向散戶投
