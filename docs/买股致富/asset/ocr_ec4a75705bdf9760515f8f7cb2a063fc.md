# 第3章 投資人與金融業該前往何處？

家銷售他手上原已持有的證券，就像批發或零售烘焙店出售店內的麵團產品一樣。一家公司可能想透過增發新股來募資，或是一名大股東可能想處置部分或全部的持股，投資銀行家便會支付現金，跟那家公司或股東買下股票，然後再蕇售或零售出去。假如在投資銀行家試圖賣出時股票上漲，他便多賺到利潤；如果股票下跌，他便減少獲利或虧損。無論如何，就像其他銷售商，在賣掉股票之前，投資銀行家都背負庫存價值波動的風險。

相反地，股票經紀商單純是買家或賣家的經紀人，他拿到客戶的買單或賣單，在上市股票交易所或店頭市場（over-the-counter），他會針對想買進或賣出這些股票的其他人，根據買方與賣方所提出的最 佳價格來撮合交易。因為他只是單純經紀人，沒有投資銀行家持有庫存股票的資金成本與風險。至少在理論上，他不必付薪水雇用銷售這些庫存的銷售人員，因此，股票經紀商的佣金，只占交易總額的極小比率。舉例來說，紐約證交所（NYSE）委託買進 100 股價格 50 美元的股票，佣金是 44 美元，不到總交易金額的千分之 9。相較之下，若是上市股票，投資銀行家可以合法收取這個比率的 2.5 倍或 3 倍，作為他處理這一批股票的「價差」（spread）。若是首度進入金融圈的公司股票，他可以收取 5% 到 15%。當然，以新發行的股票來說，他的收費一定要能支付他在證券
