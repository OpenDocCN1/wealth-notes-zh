# 第5章 1960年代的主要成長產業

「鋁」這第一個成為重要產業的工業金屬，自60年前開始應用於商業後，數十年來不斷成長，這種成長已遠遠超越美國工業的整體速度，所有跡象都顯示，這個產業將維持高於平均的擴張速度。「鎂」是第二個出現的「輕金屬」，也享受到類似的迅速成長，未來10年的前景，同樣令人振奮。在1950年下半，先是鈦、鋯，後來是鈹，逐漸吸引投資目光，因為原子、航空、飛彈和化學加工等成長領域的特殊需求顯示，這些金屬的特性將具有龐大市場。鉬和鈮或許會在1960年代加入這份名單，如果人們對如何用較低成本提煉這些金屬的成本，以及對較容易的鍛造方法，能有更多了解的話。誰能說出哪一種今日不具商業意義的其他金屬或其他物質，不會成為明日科技的迫切需求？誰能說出哪一種可以成為重大的投資標的？
