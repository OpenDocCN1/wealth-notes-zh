# 股票增值如何達到最大？

沒有什麼誘因像以前那麼拚命工作。

像這樣的一人公司，假如能出售股權的話，頂多只能賣出他每年盈餘的 2 倍或 3 倍（註②）。這家公司有太多風險，卻沒什麼前景。現在，我們來看史密斯醫師的這名友人，也就是賣掉鋼板廠 45% 股權的人。實際上，這名鋼板廠老闆瓊斯賣出這些股票的價格根本不好，外傳的高價，完全是因為瓊斯是個大騙子。由於那是一項私下交易，沒有紀錄可以公開，瓊斯極度誇大他得到的賣價，其實，買家羅賓森只用不到 4 倍的本益比來購買他的股票。
