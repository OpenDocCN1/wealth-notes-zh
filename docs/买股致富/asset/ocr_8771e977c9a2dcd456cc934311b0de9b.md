# 第3章 投資人與金融業該前往何處？

議一些交易，便能做出決定。其他人可以去找認識這名投資專業人士的客戶打聽，他們或許是在社交場合中認識，或許也是在投資業工作而認識的。

第 2 步，詢問有可能納入考慮名單的理財顧問的基本投資哲學，也就是他打算為你做什麼，以及打算怎麼去做，刪除那些長期目標跟你不一樣的人。就像《非常潛力股》主要只是我自己投資哲學的簡介，以及我認為最適合大多數（未必是全體）股票投資人的哲學，在這裡沒必要一一重述。然而，我要再重述一遍在那本書說過的話：雖然我認為，這是由股票獲利的最理想方法，卻不是成功的唯一方法。重要的是你挑選的投資人士是否同意我的長期目標和方法，而是他有自己的明確目標；最重要的是，他們的目標符合你的目標。

第 3 步，詳細詢問你考量的顧問人選，或是他們的公司，如何取得據以提出投資建議的資料。找出他或他的公司，如何跟他建議你買進的公司保持聯繫，不只是現在，還有在你買進之後，以及你持有的期間。觀察他或他的公司是否仔細分析管理階層因素，而不是依賴整個金融圈都可以看到的公開財務報告（這些是結果，而不是原因）。記住，搶在金融圈知道之前得到重大訊息，才是獲得重大獲利或避免重大虧損的最大
