# 小事但不完全是瑣事

現在來得更重要。然而，幸好現在連一點點跡象也沒有。直到那種情況發生之前，因為不喜歡政黨政治前景而賣出好股票的投資人，可能重蹈新政（New Deal，註⑰）初期一些極富裕與成功的共和黨投資人覆轍，當時他們太過憂慮新政府，以致忽視那個時期的好機會。他們完全錯估了形勢，那些他們只是稍感不滿的部分法條，卻施以強烈的反對。譬如關於普通股所有權的法案，只因可能受特定立法影響而膨脹，因此就被全然反對。如果將來又選出一個溫和反商的政府，這種影響力交錯的組合，或許又會捲土重來。
