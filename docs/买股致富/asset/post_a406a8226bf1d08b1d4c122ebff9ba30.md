
拿到這些合約。然而，如果一家電子公司可藉此培養寶貴的民間業務知識，而不只是口頭說說，可能會被視為有潛力成為優秀電子股，值得密切研究它是否也符合成功投資的其他重要特質。

很多時候，電子公司管理階層會驕傲地告訴投資人，他們的業務均衡分布在政府與民間業務。乍看之下，這種分散化好像很有好處。這種分散化，如果無法滋養民間業務，或許與沒有分散化的公司相比，具有一些穩定的優點。然而，電子股投資人絕對不能忘記，為求最大的投資吸引力，公司這兩種業務不但應該互有關聯，管理階層還必須設法運用軍事技術來推動民間業務。

以國家安全的觀點來看，很幸運的是，今日的複雜電子科技有時可以達成這點。以美國面臨的危險來看，我們的習慣與政治，使得最傑出的工程師與企業人士，眼前只看重設計一款更好的捲髮器或烤鬆餅機，而不是攔截與摧毀敵人導彈的新系統，這真是一件可怕的事。這些專家本人，將擁有捲髮器或烤鬆餅機的設計專利，如果機器很好用，他們會從中獲利。成功的飛彈攔截系統，不僅可以拯救 500 萬人的生命，還可嚇阻潛在敵人發動類似的攻擊。然而，在完成寶貴的國防裝置研發後，設計所有權不屬於研究的公司。在完成競標之後，生產合約，也就是按照我們老舊的軍事採購理論，應可「彌補」幾乎沒有利潤的政府研發合約，可能會被別家公司拿走。而且，最後標到生產合約的公司，經過重新協商之後，幾乎必然得到很不穩定且獲利率超低的業務。簡單來說，雖然由國家利益來看，飛彈攔截系統極有價值，改良版捲髮器沒有價值，但對公司來說，即使是最微不足道的消費品市場，也勝過為政府工作，相同的業務量與工程研發能力，就能創造更多、更安全的經濟報酬。在這種體系下，如果無法偶爾由軍方電子研發工作得到額外民間業務的好處，將會有更多最優秀的工程與管理階層人才，由飛彈攔截系統流向捲髮器。因此，就結果來說，不可能有政府不花任何成本的系統，因為軍方工作無論如何都要做，而且確實要在最需要的地方，吸引到更多頂尖人才。所以，在 1960 年代，那些有高等電子技術的人，將和 1950 年代後期一樣，在軍方與民間電子專業知識密切相關的企業，有機會為它們的股東做出巨大貢獻。

## 3. 這家公司的重要產品線是否能建立起公認的科技優越性，讓顧客不會只是因為價格優惠，便去購買知名度較低的其他產品？

尤其是在與生產儀器相關的電子業領域，但不局限在這個領域，這兩種條件的結合將對投資人極有好處。產品品質極為重要，很少顧客願意冒著新品牌或二級品牌表現不好的風險，只因為這個新品牌或二級品牌的價格比較便宜，比方說，低了 10% 或 15%。因為超過這種幅度的價格優惠，不太可能達到損益兩平，通常很難用大幅折價，來對抗既有的高效率生產商，畢竟，它們可能已具備大量製造的成本優勢。

這些情況都可能存在，若是兩家以上大型生產商在產品品質的地位相當，對電子股投資人就沒什麼意義了。然而，有時在最複雜、最難生產與服務的產品裡，某家生產商會被公認是品質最好的，在這種情況下，該檔電子股的地位將出現變化，可能促使股價大幅上漲及本益比提高。想了解這點，我們必須談談大多數電子股的基本投資特色。那就是它們具有遠高於平均水準的成長潛力，同時，也有遠高於平均水準的風險，在無預警之下，競爭可能干擾成長，甚至嚴重到危及整個投資。不過，偶爾當一家公司得到這樣高的品質名聲時，其他廠商就愈來愈難跨入，電子股的一般投資特色便開始改變。成長因素或許還是跟以往一樣重大，但假設公司管理階層有眼光，不犧牲品質，而持續大力提升產品，風險因素便會降低。如果這發生在有卓越成長前景的企業，便可構成絕佳電子投資的種子。

1950 年代的熱門電子股 Ampex 公司，或許可視為是最好的範例。

以先前提到其他電子投資標準來看，Ampex 這家公司的表現十分突出。但在我看來，除了成長率很高、事業管理優良、工程能力傑出，以及政府與民間事業關係良好之外，Ampex 股價的高本益比，還可以歸功於其他因素。在該公司的大部分儀器項目，顧客絕對不會在品質上冒險。在這部分的產品線，其他人很難挑戰該公司的品質聲譽。只要這種情況維持下去，相較於電子業往往風險偏高，該公司很有機會保住這個活絡成長領域的龍頭地位，而由於競爭干擾的風險偏低（跟大多數電子公司相比），高本益比是有道理的。

許多無法理解為何某些電子股本益比高到不合理的投資人，如果記住一項基本觀念的話，就可避免嚴重估算錯誤。在這種成長熱絡的領域，免於重大競爭干擾，是決定合理本益比的重要因素，其重要性相當於成長曲線。

## 4. 這家公司的銷售與行銷能力強不強？

雖然其他事情也很重要，但在所有的製造業中，構成一項理想投資的主幹，主要在於 3 項基本優越性，分別是：
- ①比大多數競爭對手更有效率地銷售與拓展銷售的能力；
- ②生產能力，也就是能比大多數競爭對手生產出更好、更低價的產品；
- ③研發工作不僅可穩定協助改善既有產品，也可在該公司足以勝任的領域，開發出賺錢新產品的能力。

這些同樣適用於其他產業和電子業，因此，從另一個觀點來看，在討論電子股的投資特色時，格外強調銷售能力或許看似不合邏輯。然而，就像我在談到電子股研究時提到的，對投資人來說，在這個高速前進的產業「研發」扮演了主要角色，勝過許多其他產業，但是，基於另一個很不同的理由，我相信電子股投資人應該要更重視一家電子公司的銷售能力，遠超過考慮其他類股時投入的注意力。

這個理由，要回溯到絕大部分電子公司都發源自聯邦政府。我很清楚，電子公司要持續取得重要的政府業務，需要某種銷售能力。然而，我相信那是很專業的銷售技能，相較於在一般商業管道行銷的高明技能，向國防部銷售的技能雖然更容易培養，但是在我看來，本質完全不同，由銷售觀點來看，政府銷售的豐富經驗，並無法建立一家公司的民間行銷技能。

換句話說，在大多數產業，如果一家公司沒有強大的銷售組織，通常無法成長。精明的投資人很少會受這種公司的吸引，這些公司也不常出現所謂「成長股」的高本益比。但在電子業，這種公司如果有充份的工程研發能力，也可以成長到可觀的規模。靠著工程研發能力，這種公司甚至有時可取得一些大公司顧客的重要業務。然而，我相信，挑剔的電子股投資人，應該要避開這類公司，因為政府業務享有「今日來，明日去」的惡名。從電子股投資最要緊的是防範銷售前景突然變化的這個角度來看，最重要的莫過於投資一家已建立行銷組織、能在迫切需要時找到大量潛在顧客的公司。不論這類組織是這家公司自己的銷售人員，或是外部行銷人員，例如獨立製造商的代表，都不重要。重要的是，參與的個別單位，不論是公司員工或外部人員，都是精挑細選、受過訓練，明白該公司需求，而且該公司知道如何在需要新銷售概念時，透過他們迅速確實得到新想法。

只透過檢視資產負債表和損益表，是無法讓投資人得知這些事情的，政府與民間業務比率的粗略數據也不行。然而，挑選在這個科技躍進產業不斷保持領先的電子股，沒有幾個因素比銷售這點更重要。許多電子公司都是由具高度創新工程技術的個人創立及主持，這類人才幾乎對生產與研發工程同等關心，因此，生產方面的業務，很少會不受重視或了解。但除了一些特例，這些傑出的工程人才卻對銷售並沒有什麼興趣，他們對如何建立行銷領導能力，沒有直覺式的了解。因為表面上看來，擁有優秀工程師卻沒有優秀銷售部門的公司，有一段時間對電子股投資人或許仍很有貢獻，很多 人便容易持續忽視長期下來，有個優秀銷售部門的重要性。等到數年後，沒有忽視這方面的電子股投資人，或許會獲得極為豐盛的報酬。

## 製藥業

另一個在 1960 年代讓投資人充滿希望的主要成長領域，是製藥業。人類對抗以前幾乎無能為力的疾病，例如白喉或小兒麻痺症，已大有斬獲，不難想見至今仍危害人類與寵物身體的各種疾病，以及許多心理疾病，若出現有效或更好的治療，就會立即出現強勁需求。以現代來看，直到二戰期間與之後幾年的一些驚人發展，而成功研發出抗生素之後，這個產業才算成熟，製造許多這些神奇藥物的生產技術臻於完美，使得這些藥品的價格，可以在大眾市場銷售。基於這個領域最關鍵的技術突破之後，將隨即造成巨大市場，經營良善、合乎道德的製藥公司，花費在銷售的費用，足可媲美最傑出電子公司用來尋找新的、更好產品的費用。除非所有的跡象都出錯，製藥業將為警覺的投資人，在 1960 年代創造一些可觀利得。而這個多采多姿的領域，有什麼投資特點？

就科學上來看，製藥業類似工業化學業，藉由化學製程，把一些分子重組成具指定特性的其他分子，或是把原子和相當簡單的分子，組合成較複雜、具一組指定特性的物質。換句話說，即使製藥業製造的分子，通常比化學業的產品較大，也較複雜，但以技術來看，這兩類產品之間的差異很模糊。

然而，從投資觀點來看，它們的情況其實相當不同。製藥股的投資特性介於化學與電子股之間，而基於價值成長速度，以及我認為它們大多具有高度風險，製藥股的投資特性更貼近電子股，而不是化學股，儘管製藥業與化學業的技術較相似。我已經指出，在化學業，一旦一項重要產品通過測試工廠階段，通常需要數百萬美元資金與很多時間，來設立生產該產品需要的複雜工廠。最好的化學工程，也只能偶爾提升傳統的1美元工廠資本創造1美元年銷售的比率。相反地，在製藥業，滿足全國市場所需的設備，通常可以很快設定，而且成本相對低廉。因此，製藥業並不存在化學業那種艱難的實體壁壘，可快速利用一項新產品，以及迄今仍大量銷售的競爭對手產品，可能同樣快速沒落。

此外，雖然許多人或許不同意，但我相信在這個隨時都可能出現技術急速落伍的領域，仔細檢視大型製藥公司的產品結構便可看出，它們在這方面的防護，遠較一般人想像得少。許多製藥公司的大量銷售額，來自少數幾項重要產品。況且，這些重要產品通常占總獲利的比率更高。因此，被競爭對手淘汰掉一項或兩項重要產品，可能會重創製藥公司的獲利能力，股價也會跟著下跌。

雖然這些基本情況，跟我在電子業提到高成長高風險相似，有其他因素可略微抑制成長率與風險因素，使得狀況不像電子公司那麼極端。例如，就美國來說，影響人類健康的新產品，在獲得美國食品藥物管理局（Federal Drug Administration, FDA）許可之前，是無法上市的，這表示公司要提交許多臨床資料，而這很耗時費時間。在有充分時間預警下，競爭對手可採取措施來因應情況。同時，我們必須記得，大多數藥物的真正市場，是由美國與海外數十萬開立處方的醫師來決定。這麼龐大的人數當中，必然包括許多隨時都在找尋更好治療方式的醫師，這些醫療界人士會歡迎那些被證實可改善治療效果的新藥。但在龐大的執業醫師之中，也會有很多明白各種強力新藥涉及的風險，而偏好使用舊藥；因為通常會有某位病患在未知理由下，出現藥物不良反應，即便眾多其他人並沒有不良副作用。最後要說的是，有些醫師使用舊藥好多年了，對調配藥方極為熟練，他們會猶豫要不要使用尚未習慣的新藥，即使新藥或許更好。基於這些理由，製藥業的經驗是，有價值的新藥，很少能快速取得與其藥效相稱的市占率。同樣地，在技術上完全過時的藥，幾乎必然會以相當穩定的速度，繼續享受數年的銷售成績，儘管會低於新競爭藥品出現在市場上之前的速度。

還有一個因素，也會讓製藥業的競爭步調，不像電子業一些部門的技術競爭那麼嚴重：一般醫師都忙到不行。每一週都有許多新藥上市，其中很多都做出誇大的藥效宣示，醫師根本不可能有時間掌握他專業領域所有的製藥發展與藥效宣示。他會從技術報告或醫學期刊廣告獲得一些新藥資訊，他或許也會由製藥業所謂的「細節人士」（detail men）得到部分資訊，這些細節人士是各家藥廠雇用的銷售代表，負責拜訪醫師，讓醫師掌握該公司產品線的重大發展。然而，大部分醫師沒有時間會晤所有人，只會約見少數新藥推銷員，因此，他們挑選少數推銷員見面。挑選的基準無疑有一部分是根據新藥推銷員的性格，還有一部分，是該名醫師以前對新藥推銷員任職的製藥公司的看法。這種影響往往讓信譽良好，並有一支訓練有素推銷員隊伍的大公司，享有一些競爭優勢。在一定程度上，它也可以阻止新上市的藥品，產生合理預期中應有的突然競爭效應。

站在投資人的立場，除了推銷員部門的規模與地位之外，一家製藥公司與另一家公司相較之下，建立新藥市場的能力，並沒有如穩定開發新藥的研究能力來得重要。一家製藥公司的推銷員，必須接觸的醫師種類太多，也太不同了，其中牽涉的技巧既不簡單，也不便宜。如果新藥在醫療與經濟上都很重要，公司可能嘗試去說服最知名的專家，請他們試用新藥及報告臨床發現，他們的心得之後經過精心撰寫會發表在醫學期刊及製作成小冊，連同免費樣品，郵寄給數萬名醫師。有時小型製藥公司不僅缺乏行銷能力來吸引獲取市占率必須要做的最大宣傳，甚至可能也缺乏財力。

總結來說，這個產業必定會急速擴大規模，因為在 1960 年代，尋找化學手段來打擊疾病與健康問題，會有愈來愈多進展。但在這個產業，沒有什麼內建穩定器可減緩突然漲跌的風險，甚至最重要的是，一家公司的新發現，可能危及另一家公司的重要市場，在這樣的領域，投資人要怎麼做，才能從中獲利？

有兩件事，是投資人可以做的。第一件，是只買進最優良的大型藥廠，像是默克（Merck）或先靈（Schering），它們結合傑出研究部門與優於平均的行銷能力，並在醫療界享有高度名聲。在整個領域擴張之下，具備傑出研究能力的這些公司，同時還擁有這個產業能做到最廣泛的多角化商品，會發現它們創新的利得，將遠超過其他公司競爭性技術突破

## 其他有趣的產業

二次大戰以來，薪資一直穩定上漲。在這個背景下，一家公司若是可以讓相同數量的員工，做出更多或更好的工作，而推出新產品，便可能十分值得投資。基於這個理由，1960年代可能吸引人的投資機會清單，若不加上機械業，便不能算完整。

一家績優機械公司的基本情況，跟績優化學、電子或製藥公司沒什麼不同。在這些產業，生產、銷售與研究的優越性加總起來，便構成決定投資會有多成功的要素。然而，在這個框架下，有兩件事是投資人在調查機械公司的發展潛力時，必須特別考慮的。這兩個條件，適用於機械業的重要部分，也就是協助留存紀錄的文書工作，往往被稱為辦公室設備業，以及提高生產線產能的設備生產公司。

第一件事，是這家公司是否努力持續改善自家產品，使顧客渴望更換以前購買的產品。除了一些特別的例外，機械業並未享有許多其他產業的優勢。其他產業可確定既有顧客會不斷跟它們做生意，因為它們的產品若不是立刻用完（像是食品、化學品或紙張），就是每隔一段時間必須補充（例如紡織品、油漆塗料或輪胎），儘管時間週期或許長一點。一些機械設備因為移動的關係時常碰撞，使用一定時間後便會耗損，而需要更換，即使時間週期比較長，汽車是其中最重要的案例。然而，機械業大多數產品的設計是要在一個定點使用，無法承受這些特殊的損害。雖然主要零組件會磨損，必須更換，但大多數文書設備只需更換一些關鍵零組件，便可使用很長的時間，這表示大多數機械製造商的銷售，只能依賴兩個市場。其一是機械製造商服務產業的規模擴大，所以它們的顧客會想購買更多相同的設備，只有在偶爾的情況下，一家機械生產商才會幸運地服務到一個不斷擴張、為它提供成長市場的產業。因此，機械生產商的市場成長幾乎一定要依賴第二個市場，通常也是更大的銷售來源，就是開發比既有機械工作成本更低或工作效率更好的設備，這正是為何挑選員工有能力不斷創新產品設計的公司，攸關機械股投資能否在一次性上漲之外，還能長期創造更多價值。

想投資機械業各領域的投資人，要特別注意的第二件事是，這家公司的產品售後服務能力。除非它們時常被碰撞，大多數機器可使用很長一段時間，但很少有機器在長期使用之後，不會耗損一些零組件或需要調整，許多機器十分複雜，使用者本人在這種時候無法進行維修。在廣大的地區維修機器，有些公司的地點遠離生產設備的工廠，因此可能很困難及費用昂貴。然而，如果售後服務做得不好，經常會造成顧客抱怨，以致危及業務的穩健；相對地，如果售後服務做得好，不但可讓顧客與公司密不可分，成為有利未來機械銷售的手段，還可以透過維修服務費與銷售備用零件，創造穩定收入的來源。它也可以成為阻撓競爭對手跨入這個領域的手段，因為妥善的售後服務，大幅提高跨入機械業的初始成本。基於以上理由，密切研究售後服務的組成，是考慮投資機械股的人的一大重點。
