# 製藥業

另一個在 1960 年代讓投資人充滿希望的主要成長領域，是製藥業。人類對抗以前幾乎無能為力的疾病，例如白喉或小兒麻痺症，已大有斬獲，不難想見至今仍危害人類與寵物身體的各種疾病，以及許多心理疾病，若出現有效或更好的治療，就會立即出現強勁需求。以現代來看，直到二戰期間與之後幾年的一些驚人發展，而成功研發出抗生素之後，這個產業才算成熟，製造許多這些神奇藥物的生產技術臻於完美，使得這些藥品的價格，可以在大眾市場銷售。基於這個領域最關鍵的技術突破之後，將隨即造成巨大市場，經營良善、合乎道德的製藥公司，花費在銷售的費用，足可媲美最傑出電子公司用來尋找新的、更好產品的費用。除非所有的跡象都出錯，製藥業將為警覺的投資人，在 1960 年代創造一些可觀利得。而這個多采多姿的領域，有什麼投資特點？
