# 第2章 股票增值如何達到最大？

羅賓森和布朗接下兩份這些新金屬與合金的小型鑄造合約，兩份合約都賠錢了。然而，他們由此了解 到，有哪些既有設施可用在這些新材料，以及如何設計他們需要但尚未擁有的專業設備。購買這些設備，幾乎耗盡公司的資產和融資能力，然而，他們總算得到設備了。

接下來的一年，他們賺到的錢很少，但他們得到愈來愈多如何加工這些金屬的知識，這個領域充滿問題，因此周遭的人似乎都不想理睬。隨著他們增長知識，業務量也增加，公司開始有了為數不多的利潤。
