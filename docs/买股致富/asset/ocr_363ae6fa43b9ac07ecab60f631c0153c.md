# 預測 1960 年代的關鍵影響

設法削減庫存總量，理由不難察覺：維持庫存的成本太高了，只因為未來的物價水準終將升高便囤積存貨，太不划算了。

想清楚了解這件事，我們不妨仔細檢視這些成本。首先，被過多庫存綁住的資金，原本是可以賺到利息的。如果手頭沒有閒置資金，則必須靠借貸來買入多餘庫存，這種成本甚至會更高。其次，還要計入倉儲或儲藏這些多餘庫存的成本，以及火災、竊盜或其他損失的保險成本。接著，還有地方不動產稅，不論在一年中何時持有這些庫存，地方政府皆會課稅。最後，就某些商品來說，可能因為時間流逝使商品實體受損，或是有些商品因為潮流風格或技術的改變，導致商品變得沒價值的危險。

基於這些理由，即使美國自二戰以來便有通膨以及對通膨抱持警覺，卻找不到任何傾向顯示企業會以囤積商品庫存作為通膨避險之用。這種偶爾發生的預先買進，幾乎都是出於擔心物資短缺（如同韓戰初期），或者，擔心特定商品價格上漲，但從來都不是因為擔憂通膨。有時，即使特定商品即將溫和漲價的消息已經宣布，也不會刺激企業預先買進，因為與負擔庫存的費用相比，漲價的幅度微不足道。
