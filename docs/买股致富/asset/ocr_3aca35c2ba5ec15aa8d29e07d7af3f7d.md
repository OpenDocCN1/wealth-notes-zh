# 小事但不完全是瑣事

比一些否決票更可能改變管理政策。

簡單來說，投資人完全是為了自己著想，而拋售一家經營不善的公司股票，此舉壓低了該公司股價，並加劇投資圈對管理階層的不良觀感。不過，投資人的賣股行為或許在無意間對管理階層形成真正的壓力，如果有足夠人數也這麼做，便會形成一股真正的力量。另一方面，投資人死抱股票而去否決管理階層的提案，即使有許多人也這麼做，通常都是螳臂擋車，他無法改善自己的投資局面。或許這就是為什麼儘管表決權討論得沸沸揚揚，並在新股公開說明書等刊物占據大篇幅，「市場的冷血判決」卻認為它們毫無實質價值。如果你懷疑這點，不妨查一下過去40年的各種案例，同一家公司同時發行兩種股票，股票幾乎完全相同，唯獨因為表決權信託安排或其他法律機制，讓其中一種股票不具有效表決權，另一種則有。具有表決權的股票幾乎從未因表決權而享有更高市價，這兩種股票，就報價來看，通常是可直接互換的。

或許，成功投資人就這整件事所能學到的是：「如果深入探究，你便會明白，股東與公司的關係，以及公民與所在地或國家的關係，基本上不是相似的。」以上說法一點兒也不正確。忽視公司表決權的性質吧！因為無論怎樣，它們跟投資人未來的財富毫不相干。專注在傑出的管理
