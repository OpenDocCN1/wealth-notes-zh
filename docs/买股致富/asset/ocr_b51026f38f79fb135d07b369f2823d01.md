# 第3章 投資人與金融業該前往何處？

和另一名所謂專家撰寫的幾份報告。我對那家我很熟悉公司的報告感到索然無味，報告內容是偶爾打電話給管理階層，以及對該公司有粗淺認識的人都知道的事。我接著看另一份報告，裡頭的那家公司我並不熟悉，所以請教了在那家公司任職的朋友，對那份報告有何看法。他把報告拿給該公司數名高層主管看過，大家一致認為，報告內容是外部人士對該公司隨便研究一下，就可取得的相關知識，毫無可取之處，報告並無深入分析。我決定不要跟做這種膚淺工作的投資專業人士攪和在一起，雖然可能會被認為粗魯無禮，我決定在下次那位代表來拜訪的時候，就這麼回答他，才不會讓大家浪費時間。不過，由於我覺得對方相當真誠，不願意傷害他的感情，當這位仁兄再度造訪，我有些憂慮。在盡可能委婉表達我的想法之後，出乎我意料地，他竟然咧嘴大笑，他告訴我，他正好對自己任職的公司，有相同的看法，他覺得跟只會糊弄的人在一起，是沒有前途的，因此已經辭職了，來拜訪我不是為了做生意，而是要請教我應該去哪一家好的投資集團應徵工作！

簡單來說，在跟一名納入考量的投資顧問談話時，要注意他的工作品質，而不是數量。你或許對任何一家公司都沒有足夠的了解，無法判斷他提供給你的報告品質如何，但你或許（和我一樣）有位朋友在這些公司擔任高層，可以替你判斷。
