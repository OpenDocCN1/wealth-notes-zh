# 小事但不完全是瑣事

選出公司董事會。在法律上，公司董事會是公司最高權力核心。董事會任命所有重要主管，包括總裁，董事會也決定大部分的重大決策。

基於這些理由，這種表決權從表面看來，對投資人具有實質意義與價值。金融界表面上似乎證實了這點，因此，在證交會要求大多數新股發行時所公布的公開說明書，必須說明證交會認為這些股票最重要的資訊。任何不同於標準表決權模式的做法，必須在這些公開說明書詳加解釋。同樣地，許多雜誌報導和一些書籍已探討過這個主題不同層面的對與錯。舉例來說，吉伯特兄弟（Gilbert Brothers）多年來因為改革一些公司慣例而聞名全國，他們倡導的改革，大多直接或間接與股東表決權有關。

我接下來要說的，不該被解釋為我認為即使是在表決權領域，吉伯特兄弟等大多數改革者都不是完全合宜。在某些例子，像是他們倡議取消交錯任期制的董事會（少數公司仍保留這種保障管理階層的機制），他們的意圖似乎相當正確。我想說的是，為什麼對遵守穩健投資慣例、自行處理投資的投資人來說，表決權這種事完全不重要。
