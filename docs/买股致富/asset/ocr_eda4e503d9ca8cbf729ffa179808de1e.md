# 投資人與金融業該前往何處？

好的業界人士，或是更多做得普普通通的，年復一年地為自己賺進大把銀子。只要股市維持榮景，就沒有誘因去嘗試大刀闊斧的改善。大家強烈認為：「只要現況一切都很好，為什麼要沒事找事，單單只是有可能多賺一點，而去採取不同的做法？」

這不代表只能指望漫長熊市來打破投資業的榮景，才會刺激這個產業出現大幅改變。打前鋒的金融領導人，可能隨時都會發揮他們的才智，開發出終將主導著發掘未來熱門投資的技術。儘管我能指出投資業應該走向何方，但不代表我可以預測會花 2 年或 12 年達到目的地。

了解這整件事情的第一步，是明確知道全體投資人對投資顧問業有何要求。除了專業投資人士以外，只有極少數的股票買家覺得有能力自行管理投資，這類投資人唯一需要的協助，只是股票經紀服務。但絕大多數人有興趣的，實際上只有一件事：他們想打交道的那些顧問，必須充分了解自己推薦的那些股票，且這些股票在一段合理的時間內，會表現得跟這些顧問描述的一樣。

令人訝異的是，在現今的時代，大多數投資人在這方面十分理智，或者，也許該說是老練。但仍有一些人希望投資顧問告訴他們哪一檔股票
