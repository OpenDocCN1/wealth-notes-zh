并非是每个人都有笔记本电脑，而且也不可能随时携带在身边，备一个小笔记本和一支笔，在坐车的时候、等人 canine的时间、吃饭的过程，往往是观点最为频发的时刻，不要让脑中突然闪过的念头滑走。

# 阅读其他内容时

这个在前面讲过，看一篇文章时，你常常会写上赞成或反对的意见，有感而发，往往寥寥几句，或者在读书的时候，常常看到一些重要的话，你要默记并消化它，不如拿起笔，敲起键盘，自己把它加深一遍，加入自己想到的例子、自己的看法，新的文章也就诞生了。

# 网上写作论二十三：写作素材从哪里来

通常在需要写作指南性内容的时候，你需要素材。而指南性内容被流传的时间很长久，可以源源不断地为你带来影响力，甚至，人们把你当做专家。

我建议你采用小型课程的形式，这样人们容易把你当做老师。如果你撰写了这方面的小型课程，可以免费或者收费，你更加可以和我合作，集中推出这些课程，我不建议你写几十万字的内容，最好精简到三五万字，一门课程只是集中地去解决一个问题足矣。课程写得好，我可以帮助你联络相关媒体，为你开辟专栏或讲座，也可以安排出版社为你出版发行。

朱则荣语：尽快不要以网上的内容作为你的素材！因为这些内容网上到处都有，形不成你的特色。

# 到书店去

到书店去仔细看看吧，无论种花养草，还是茶道品酒、或者是管理营销，你总能发现不少的书籍，有很多书的内容都非常系统，你可以买一些进行参考，围绕“网站的模式选择”、“企业策划案例”等等，形成你自己的专题，当然，尽量不要去抄书。

# 到图书馆去

图书馆里藏书丰富，你要常去，能找到各种不同的答案。孔子当年的职位相当于国家图书馆、国家档案馆的馆长，所以能写出《论语》；而李敖常常坐在书堆里，朱则荣曾花了九年时间读掉了六十麻袋的管理资料，所以文章顺畅，能很快的写出许多有深度东西。

# 去采访高手

准备一支录音笔，为了解决一些问题，去联络一些高手，分别地拜访他们，将谈话内容录下来再进行整理；或者备一个DV，去录下他们的看法，编辑一下，就成了你的视频课程。采访，往往也是你直接获得那些高手宝贵经验的一个捷径，同时快速地增加了你的人脉。
