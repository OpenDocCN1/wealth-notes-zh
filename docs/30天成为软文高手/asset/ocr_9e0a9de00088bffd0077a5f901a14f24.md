# 温州华特—别克君威香车爱侣摄影大赛

为推动新君威上市后，在温州市场的品牌和销啓，增加新君威的关注度和曝光率、促进销量，利用温州新闻网等进行合作，有关公司启动了提升别克品牌和温州华特汽车的知名度的行动方案。

该活动主要契合温州人结婚、订婚需要买车这一风俗习惯，针对特定适婚男女进行活动宣传。提升别克新君威在温州结婚购车市场做出更好的成绩。
