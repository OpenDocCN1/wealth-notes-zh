# 自动销售！

# 网站是怎样订阅的？

Google 提供了一款免费工具：Feedburner。网址：http://feedburner.google.com

Feedburner 是一种 RSS 内容邮件订阅工具，使用 Feedburner 后，你可以在你的网站上放置一个“订阅”按钮，当你的网站访问者留下他的电子邮件以后，每当你的网站或博客更新，就可向读者自动寄发更新文章，不断地将客户拉回到你的网站，也不断地让潜在客户看到你的内容。
