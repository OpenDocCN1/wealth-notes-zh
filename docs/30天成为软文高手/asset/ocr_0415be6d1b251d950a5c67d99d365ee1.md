# 一、现行经营趋势测算

以现行经营策略。

卓学网盘网站访问量
每日 10000IP
付费用户/访问者
成交率在 0.1-0.5%
日营收
500-2000 元之间

注册用户（免费试用）
每日 10000 人次
付费用户/注册用户
成交率在 0.8-2%
日营收
3000-7000 元，约 5000

用户成交比率中，月付费用户、年付费用户、高额付费用户比率为 3：5：2，即每 10 人中约 3 人使用月付费，5 人使用年付费，200-500 元用户为 1.5 人，500 元以上用户 0.5 人。
