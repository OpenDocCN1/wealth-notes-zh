# 朱则荣软文问题集（三）

# 开始你的写作

问题 1：开始写作时有什么特点？

答复：大家刚开始学写软文，或者已经有了一些经验，这个时候的写作，是以模仿、加工、整理为主的。这样，才能快速的出软文。

包括写作大师鲁迅，也是天天搜集整理资料，天天看书，然后把整理的素材，加上一定的润色，这就成为文章。

问题 2：我个人专业是传播学，软文怎么写，是不是要更多的去考虑受众的心理？有效传播？

答复：不必考虑受众心理和有效传播，只要你的文章有实质性内容，发表在能够被转载的网站上或比较热门的论坛上，就容易被传播出去。

问题 3：是不是公司里面应该专门配个软文写作的

答复：文案，就是这种专职工作。

问题 4：一个品牌网站如何用软文推广商品？

答复：看他们的新闻和文章，研究一下，你就能掌握规律了。

软文是推广的敲门砖，好的软文就是好的敲门砖，是一个切入点。其实创业就是这样子，办一个公司，正常情况下两三年才能稳定，七八年才能成功。

急不成的。但是，如果把眼光放长远一点，用软文打品牌，花个两三年持续写软文打品牌，成功指日可待。

问题 5：把别人的原创文章修改成自己的伪原创，这样好吗？

答复：看你情况，我个人不建议，因为写作是你自己努力的结果，如果总是想省事，可能影响你在写作方面的能力发展。
