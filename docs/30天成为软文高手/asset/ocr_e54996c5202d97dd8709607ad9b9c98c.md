# 用软文推广网站

对于中小用户，用软文推广网站，多数则ad于锁定一些关键词，围绕这些关键词产生内容。由于该系列软文在网上进行了快速扩散，因此在一定领域影响了网上的读者。比如，“软文”这个词，你在网站查找相关的网站内容时，从这些网站上可能都会阅读到“朱则荣 软文”，可能有一百个涉及“软文”的网站或频道，那么这些网站或频道上，都会出现你。

今天的互联网，尽管信息量庞大，但大家都缺原创的文章，因此你撰写的无论涉及某一方面，都可能有数以百计的相关网站联合转载。一旦你在写，并有意地进行传播，那你的内容就是有目共睹，它拥有潜在的被客户信任的价值，它所产生的是“捕捉客户的诱饵”。

比如你是一个“管理培训”的经销者，当你写一篇关于“管理培训”的文章时，发表在网上，别人认为重要，就会进行转载，大约在三天至一周内，这篇文章就会在数十个甚至数以百计的管理网站、商业论坛中出现。当有人想了解管理培训，或参加管理培训时，他认同你的观点，他认为你是专家，就会通过文章中的链接，或者在网上搜索你的名字(网站名称)来寻找你。给你自己创造了很多资源合作、客户接洽的机会。而大量的撰写，则会创造大量优质的客户，他们怀有目的而来，对你的产品感兴趣，或者愿意花更大的代价来购买你产品，他们甚至会提供很多一起合作开拓市场的机会给你。
