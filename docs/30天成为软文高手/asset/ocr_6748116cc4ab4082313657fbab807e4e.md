# 五、硬新闻与软新闻

硬新闻：主要为重要的时事新闻，是人们在报纸头版或网站头条看到、在广播电视新闻节目一开始听到的，战争、政治、商务、犯罪等经常是硬新闻的内容。它具有时效性，争议性，影响广泛，通常硬新闻单刀直入，为的是让读者尽可能快地掌握重要信息。

软新闻：通常是以专题新闻方式，许多报纸和在线新闻网站另外开辟专题栏目，登载生活时尚、居家生活、艺术娱乐等消息。大报甚至分专题开辟每周栏目，如食品、健康、教育等。新闻则往往从一则轶闻或实例引出故事，为的是引起读者兴趣，或者引导读者的生活方式和消费。

# 五、软文写作两大原则

+   1、始终提供对人们有益有帮助的正确内容信息。\n2、比照新闻从业道德，遵守公正自律。

# 六、软文五大立场

+   1、准确：确保传递出去的信息真实、可靠、具有价值。\n2、精确：精确锁定目标读者群体，陈述简洁、解释清楚、数字说话。\n3、推荐：的确值得认真地将信息推荐给社会公众。\n4、说服：强有力的说服力、证实性，解决疑难、消除疑惑。\n5、朴实：淳朴诚实、质朴笃实、朴素真实、踏实可靠。

# 五、软文写作的要点

+   1、准确的时间、地点、人物、事实、原话、功能、应用，反复核实。\n2、恰当溯源，要确定信息的来源的真实可靠。\n3、完整。一篇文章应回答读者或观众的一个准确问题，包括了阙述、证明、记录、例证等正确使用。\n4、保持中立。必须始终站在读者的立场和角度，用读者的兴趣、观察立场和思考方式来说清楚问题。\n5、客观。除专栏文章、专家观点等要善于使用情感和个人观点以外，软文撰写者尽管不加入自己的看法或观点。\n6、主题简洁、明确、条理清晰、有理有据，重点突出。软文也要直奔主题，说法明确，不要试图强行绕弯。\n7、删除一切废话废字，保持文章紧凑有力、干练简洁，没有陈词滥调和多余废话。\n8、除非综述，一篇文章只说明一个问题，多个观点多篇分述，软文的王道是以量取胜。
