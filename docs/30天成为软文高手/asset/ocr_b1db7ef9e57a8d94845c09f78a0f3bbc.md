# 软文与 SEO 的区别

# 软文与SEO是网站推广的两大方式吗？

答：不是。软文与SEO是两个完全不同的概念，它分属于两个不同的阵营，有着完全不同的发展轨迹。SEO的发展史不过10年左右，而软文的发展史却长达几千年。我们从两者的发展和市场规模来研究。

# SEO的发展和市场规模

1997年前后，以美国为首的互联网站发达国家开始出现了提供搜索引擎优化相关服务的机构，国外的网站也在那时开始意识到搜索引擎优化对于网络营销的重要性。SEO是搜索引擎的伴生品，尽管SEO在国外已经是一门相当正规、成熟的行业，有大批的专业的公司，专业的技术人员在为广大客户网站提供全方位的搜索引擎优化服务，但实际上，SEO的市场是非常狭小的，从业公司大部分是小公司。

以2008年度为例，全北美一年的SEO支出只有14亿美元。据SEMPO：2008年度北美广告主搜索引擎营销支出数据，2008年度北美搜索营销开支为134亿美元，2009年预计上升到147亿美元，长期预测到2013年搜索营销开支达261亿美元。这其中，在2008年度：付费排名的广告支出占88%（约$119亿美元），自然排名优化支出占11%（约$14亿美元），搜索引擎营销技术支出占1.1%（约$1.4亿美元）。需要注意的是：SEO的支出，较2006年的11.8%出现下降。

SEO之所以市场狭小，一个主要原因是很多人认为SEO就是“钻搜索引擎的空子”，它是一种投机取巧之术。SEO一直饱受这种争议，因此大型、中型的企业不愿在这方面投资，从长远发展来看，SEO很难发育成大的产业，它只能长期寄生在搜索引擎的发展史中，而且还永远带有一些灰色的、负面的阴影。

# 软文的发展和市场规模

软文的发展长达几千年的历史。只要有人交流的地方，有文字传播的地方，就可能存在软文。例如李白的著名诗篇中写道“长相思，在长安”，就把一个世界之都——长安城的品牌给推广了，这首《长相思》存在了上千年，也就把长安的神韵传递了上千年。杜牧的《游明》中写道：“借问酒家何处有，牧童遥指杏花村”，杏花村是山西汾酒的一个品牌，由于这首诗，在一定程度上也就形成了今天的山西杏花村汾酒集团。
