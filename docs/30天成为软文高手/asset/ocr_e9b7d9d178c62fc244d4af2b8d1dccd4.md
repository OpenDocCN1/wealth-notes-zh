# 网上写作论之三十一：快速写作手法之曼陀罗发散

当你不会写文章的时候，你可以借助于工具，让你起步的阶段变得轻松。

见过九宫格吧，就在下面的图，中国人把它叫做九宫格，最早用于人像绘画，我记得那时将一张有标有九宫的蒙板，放在照片上，把要画的头像分解成九份，对照着九份中的第一处细节，逐步去画，天安门城楼上的毛泽东像，就是用这种方法绘制出来的。画人像很難，所谓失之毫厘，差之千里。

在国外，这个格子叫“曼陀罗”，最早用于记事。我将其引伸到帮助你写作的工具中：这是让思维流畅无阻、纵横驰骋的方式。

# 第一种写法：指南文章

假如你现在要写一篇：“如何建立声望”的文章，那你就在图中的最中间写上“如何建立声望”，接着，你可以在网上查“如何建立声望”，那么就出现一大堆的文章。

接下来，你就知道了，阅读那些不同的观点，将你理解到的最重要的观点，用你的话写在一个格子中，给文章起个名字：“站长如何建立声望”，或者“建立声望的八种方法”……文章就出来了。

对于从来没有过写作的人来说，这种方法最快，而且这种文章始终有人去阅读，转截效果也非常好。

再从搜索上输入一个词，“声望”，你又会发现许多新的搜索结果，许多不同角度的文章，自己去整理吧，删、删、删，把废话全删掉，只保留最精简的内容，你的语言就会精妙了。

# 第二种写法：评论文章

同样在最中心的一格写上“声望”，后面可以加两个字“好处”。

去网上查相关资料，在其他几个格子里，加上两个例子，两个格子里写上你的看法。

得，一篇文章又出来了。
