# 问题8、做流量 软文与SEO 哪个更为重要性，做站靠的是勤奋的写作、炒作还是靠强大的SEO？

答复：萝卜青菜，各有所爱。就看你自己的兴趣主要在哪儿，想重点发展什么。

事实上，软文的最大作用既不是销售，也不是直接产生业务收入。而是宣传。你想想党的部门，为什么只有宣传部和组织部这两个部门，宣传部是干什么的。所以说，软文宣传，才是长期的一个性工作，所有的企业，不可能一夜发家，都是要到二到三年业务才能成熟起来，到七至八年才能取得大成功。宣传的最主要目的，是为了这个。当然，考虑小站长和网站经营的切实需要，我们今天特别突出了软文的直接销售作用。
