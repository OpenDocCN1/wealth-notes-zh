# 八、炉火纯青

李白斗酒诗百篇，是每一个写作者的至高追求。

需要时间：十年至三十年

+   1、 在写作水平上，达到文笔精深，挥洒自如，下笔万言，笔下千秋。写作时连删稿也不必打，此时的写作已经是随意而写，随心成文，飘逸洒脱，可以开创出独有的写作风格，更可能成为数以万计的写作者崇拜学习的宗师泰斗。

+   2、 在营销上，你很可能创造出 GOOGLE 式的营销奇迹，因为你的公司最重要的核心营销武器将是极其发达的通讯社模式，极低成本的文章传播将会取代耗资巨大的广告投放策略，在整个互联网上下，正所谓：小网抄大网，大网抄于你。这种境界，有心人自会深入体会。

> 朱则荣语：同志们，软文宣传大行其道的时刻开始了，这一座电焊焊从钢铁互联网的大时代到来​了，让我们齐头并进马往直前，果断拿起你手中的笔，坚决敲起你身前的键盘，用文章冲锋陷阵，用软文攻城掠地，翻江搅海，聊做山河。
