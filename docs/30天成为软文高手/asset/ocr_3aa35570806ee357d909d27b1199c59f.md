# 网上写作论之三十二：快速写作手法之脑图思维发散

练习一段时间的曼陀罗式写作之后，你可以使用更高级一点的脑图写作了。人的大脑，忽尔忽西，你往往不知道该写些什么，我教你一种脑图写法，就是利用大脑的思维方式，来界定写作方向，这种方式最适合写大批量的相关主题的文章，或系列课程。
