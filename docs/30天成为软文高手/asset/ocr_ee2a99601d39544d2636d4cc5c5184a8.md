# 朱则荣软文文集（四）

# 软文品牌栏目策划

今天翻阅一则旧文，是有关“新华在线”信息服务业务的一个简要新闻介绍，文中称：新华在线核心业务是信息资源的收集、整合、加工与传播，其系列产品包括《媒体专供》、《PDA短讯》、《证券专供》和《WTO特供》等主打产品。

由此，我们来考虑一下原创内容网站的主打产品品牌问题，究竞原创内容网站该如何发展，该提供怎样的资讯内容服务，该如何实施这些内容业务？

标准定位：互联网内容服务商(ICP)

原创内容网站大多以提供信息资讯内容为主，少虽网站提供专业的内容讨论或评论，由于他们的原创内容较多，习惯上被称为原创内容网站，随着百度与GOOGLE等搜索引擎崴全面加重对原创内容网站的权垂，内容的原创性和独有性使这些网站纷纷受益，越来越多的网站正在倾向于向原创内容网站方向发展。

事实上，它们就是ICP的其正含义(Internet Content Provider，ICP)，即互联网内容服务商。

# 朱则荣：为什么对原创内容网站实施的主打品牌栏目策划

大家经常会访问央视、凤凰卫视等电视节目，人们不仅仅熟悉这些电视媒体本身的品牌，更熟悉的是这些电视台所制作的众多节目品牌，如：CCTV的《经济半小时》、《百家讲坛》、《同一首歌》、《中国财经报道》、《探索发现》，如凤凰卫视的《世纪大讲堂》、《鲁豫有约》、《锵锵三人行》、《名人面对面》等等，等等。

换言之，这些电视媒体在内容制作上，并非“一锅粥”地安排记者、编辑、制作人员在一起工作，而是大抵编导人员被分解成一个又一个小组，为电视媒体建立起多个著名的电视节目品牌，除了电视台本身的栏目制作，一些电视台的外部人士也会组建公司，单独制作一些品牌电视节目，出售给电视台，例如《中国娱乐报道》节目就是外部公司制作，出售或以贴片广告等方式占领多家电视台的主要频道。

我们现在的问题是，是否能将上述策略应用在原创内容网站的策划上，使我们每一个略有实力的原创内容网站，能够遥略地打造出一些猗红互联网的名牌栏目，即节省了编辑成本，也加垂了推广效应，使网站不仅拥有更精彩更精致的内容服务，又扩大了生存空间和赢利空间。
