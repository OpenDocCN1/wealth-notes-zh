# 朱则荣软文问题集（五）

# 软文的推广

问题 1：软文往哪里发？

你写的软文是关于哪方面的，就往哪方面发，比如你的网站是军驹网站，你的软文肯定是军驹方面的，当然发到军驹类的网站和论坛了。

如果你发到站长网，就不合适了，因为这站都是站长，没有多少人关心军驹。

问题 2：我是旅游类网站，需要宣传自己的站，怎么做效果更好？

答复：有很多的旅游新闻网站，你的内容要往这些网站发，比如你采访旅游界的名人专访，就可以发给一些大的旅游类网站，另外，你要加入一些旅游网站的站长排、猫排群，广交这方面的朋友，一篇软文写好后，通发给这些网站。

问题 3：选择在一些论坛、博客中发表我站内的文章，再加上自己的链接，但是收效甚微，有什么更直接的方法呢？

答复：因为你的软文不够水平，大的网站不用你的软文。比如你做酒店预订，但在酒店类网站领域，交的朋友比较少，所以限制了你的活动范围。

要向大站挺进，要结交更多同行的朋友

问题 4：要向大站挺进，要结交更多同行的朋友，这个跟写软文有什么关系？

答复：媒体获得更多的媒体资源，也就是说，有更多网站能给你发软文。

我打一个比方，我是做培训的，我多结交几个作培训类网站的，我的软文，是不是可以让他们帮我发在他们网站上？相互合作！

问题 5：大的门户站软文怎么发上去？收费吗？

答复：你要研究同类的网站，发表在哪些网站上的内容，会被其他网站快速转载。

比如，我们写企业管理类的文章，不必先在新浪、和讯等网站上发夹，我们只发表在一个不起眼的网站上：中国管理传播网。这个网站很不起眼，但管理类的大站都从这里转载文章。
