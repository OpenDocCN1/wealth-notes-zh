# 通讯软文

# 什么是通讯软文

通讯是最常用、最常见的写作方式，主要用来报道消息、动态、人物。企业和组织、报刊及电视一般都建有通讯员队伍，用来进行基层报道。

样例一：

# 卓学课堂：推出气候变化主题网站

卓学课堂最近推出了一个综合介绍“应对气候变化问题”的主题网站，以使公众更加便利地获得相关知识和信息。

这个网站网址是 http://www.zhuoxue.org。登陆这个网站可以获得国际社会及中国对气候变化问题的努力、相关报告和资料。近年来，气候变化日渐成为全球关注的问题，很多商级别的国际会议都将气候变化列入讨论日程。

样例二：

# 社交网站组织用户参与线下活动

社交网站 Going 网站目前组织了两场集会。他们的集会吸引大批年轻的专业人士，让具有相同窝好的行家上网联谊，同时七嘴八舌对商家品头论足，例如批评那家餐厅的侍者态度差、食物难以以下咽。一位参加者称：‘...很高兴，我们能如此一拍即合，踊跃参加表演或一起聚餐’。

Going 网定位为一种“社交活动行事历”(social-event calendar)，架结各种社交活动信息，并鼓励会员事先透过网络互相接触，并且让他们上传活动的照片和描述。Going 网站提供更丰富的行事历功能，以便会员举办各式各样的联谊活动，从烤肉节到慈善募款活动，不一而足。
