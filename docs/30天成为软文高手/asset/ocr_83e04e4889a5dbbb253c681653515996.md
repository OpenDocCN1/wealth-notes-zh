答复：要善于“搭桥”。别人可能不 knowing 你，也不知道你的公司，但每个人都会有一些崇拜的人，都知道一些他自己认为比较牛的公司。

当他在你的文章和网站上，看到他自己崇拜的人、比较牛的公司似乎和你有一些联系，他心里就会想：“哇，原来谁谁谁居然也是你的客户”。顺带亲，他就从心里佩服你了。

# 问题6：写软文 究竟有没有捷径？

答复：有！就是学习方法，一开始需要临摹碑帖，开始写的时候，也需要模仿一些写作手法。这样学习速度最快。

只是目前可供临摹的软文范本比较少，加上没有经验的人很难总结出写法的规律，因此许多人想学写软文就比较困难了。

# 问题7：如何让文章看起来很有逻辑性

答复：凡事先说一二三，这就是说穷。

写了开头以后，直接就写第一、第二、第三。

# 问题8：我写完文章以后，总不能冷静地去重新审稿，还有骄幸的心理，这是不是一种缺点？

答复：不是。买一台激光打印机，买一箱纸，一千块钱上下。

写好了就打印出来，修改一下就行。

主要原因：网上阅读，思维处在跳跃状态，往往一眼扫过内容，思维反应跟不上阅读速度。而纸上阅读，是正常速度，逐字逐句，思维反应低于阅读速度，可以引发许多新的思考。

# 问题9：作者应该站在什么角度去写

答复：第三方立场。而不是你自己。尽量不要在文章中出现“我”。要用某某说，某某认为，某某人，某某公司来代表。

而某某实际上就是最好的软文主角。

之所以用第三人称，主要是因为网上传播的特点，很多网站在转载时，会掐头去尾，作者信息面目全非。
