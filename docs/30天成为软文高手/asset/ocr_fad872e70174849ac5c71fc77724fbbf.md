# 朱则荣软文问题集（六）

# 软文培训现场提问

问题 1：软文如何分类？

答复：软文的分类，各种分法不同，我根据大家需要参考的写作方法，分了二十多种，也就是说，有二十多种写作模板，可以供你去你参照学。

问题2：做流量 软文与SEO 哪个更为重要性，做站靠的是勤奋的写作、炒作还是靠强大的SEO？

答复：比如：消息软文、事件软文、观点软文、问题软文等等。就象学书法都要临摹碑帖一样，写软文，同样可以有样板可以参考，快速学习。

问题3：写好的软文，如何用标题让此软文吸引人

答复：朴实一些。比如“什么是电子商务”、“软文写作的十种功效”，这些标题的转载率和搜索量最强。你可以注意一下当地的地方报纸，转载最多的都是技巧和方法类的小块文章。再者，如果要写作标题，建议你研究一下《参考消息》，上面有很多非常容易吸引人的标题范本，你把他们摘要一下，就能找到规律。

问题4、请问朱则荣老师这次讲座本身就是一篇软文吧

是，最好的软文其实就是你自己。软文可以为你打名气，而名气的背后什么都有了。就象有位科学家，制造出了一种产品之后，就不做销售，他天天到处去上课，去讲学。

问题5、写软文是否要自己经历过的经验写出来？

答复：这是写手刚刚写作时的方法，实际上，软文要重点谈的是自己的观点和看法、自己对事物的分析。谈经历过的经验，效果不强，而且你也没有那么多经验可讲。
