# 寻找转载源头

转载的源头通常不是论坛，而是与你有关的各种行业网站，以投稿的方式，与他们联络，如果你的稿件很多，你可以发邮件，打电话，与他们建立内容合作关系。

# 注意百度新闻源

百度会从 1000 多个网站抓取新闻，每五分钟一次，查询一个网站是不是在为百度提供新闻搜索结果的时候，随便找一篇该网站上的文章，将它输入在百度新闻搜索框中，看一下出来的搜索结果的后面，有没有这个网站的名称，如果有，就是新闻源，如果没有，那就不是。

通常，能为百度提供搜索引擎结果的网站，都是某一领域的重点网站，同行的人会从这里转载内容。

# 关于论坛上转载的解释

小型论坛就不要考虑了，根本不可能出现转载，只找大站，找人多的地方。但是，论坛上发帖、回帖的人都比较多，就跟挤公交一样，你的势力很弱，扔上一两篇根本起不到什么作用，除非大批量的发原创稿，引起版主的重视，有很多文章被列入推荐或者精华，这样的文章转载机率大一些，没有被列入的文章，很难被转载。

# 另一种传播形式

你要尽一切可能将文章出现在那些大一点的站点上，如果实在办不到，只能栖息在论坛时，采收另一种方式：将文章制作成电子书，比如《养猫指南》、《激光仪器最新技术文章》等等。

将他们发在迅雷、eMule 等下载网站和电子书网站上，另外，在行业论坛上发帖子让你同行的人下载。

注意：文章中尽可能不要加网站、QQ 等任何联系方式，很容易被当作广告，联系方式可以放在电子书里。
