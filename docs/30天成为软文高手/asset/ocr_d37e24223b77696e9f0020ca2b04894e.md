# 典型故事：格兰仕“豆腐块打天下”

关于格兰仕微波炉的报道在报纸上经常可以见到，你很难说这不是软文。在各类报纸经常报道“格兰仕微波炉产销 量世界第一，通过规模利 润将单品利 润降至最低，形成垄断”。这些新闻直接威慑竞争对手：不要轻易降价，你杀不过我；也威慑想进入此行业的企业：千万别进入，你将会血本无归。企业的威慑性软文基本上企业不需要花费多少费用，只要主动联系媒体、或召开新闻发布会即可，但却奠定了一个企业的市场 Beef 地位，将对手抛之于后。

# 豆腐块打出天下

格兰仕集团的创始人梁庆德，从做鸡毛掸子起家，当初只是拥有有7个人的乡镇小厂，一手奠定了微波炉市场领导者地位。在20世纪90年代，当时的多数中国老百姓还不知道微波炉为何物，梁庆德认为，只要自己首先发动攻势，就能在未来的微波炉市场中取得先入为主的优势。基于这个战略构想的指导，格兰仕发动了一场规模浩大的微波炉“启蒙运动”。

格兰仕最初成立时，没有多少钱打广告，就找人专门写软文，搞了个“微波炉做菜1000法”，在全国几十家地方小报上登，后来全国报纸都在疯狂转载这些豆腐块式的小文章，没过多久，就有300多家报纸在转载这个。一招奏效，格兰仕联合了150家报纸，以合办栏目的方式，做成豆腐块大小的知识窗，系统介绍微波炉的好处、选购、使用、菜谱、保养方法等。新闻媒体的大规模普及教育，迅速产生连锁反应，有关微波炉的文章铺天盖地。随后，格兰仕又组织国内专家编写微波炉系列丛书，免费赠送100多万册；精心制作数百万张微波炉知识光碟免费送出，使微波炉概念得以迅速普及，格兰仕品牌也随之叫响全国。
