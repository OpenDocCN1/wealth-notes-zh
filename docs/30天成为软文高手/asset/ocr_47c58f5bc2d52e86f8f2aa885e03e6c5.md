# 软文成名术

# 软文的强大价值是奠定品牌

世界上有人地方，就有人想要说话，而说话本身就是一种软传播。所要说话，很可能就来自于听说、看到、感觉到。

“你知道世界上最好的搜索引擎是哪一个吗？”

“我听说......”

“我想买一身不错的西装。最好的牌子是......”

“这个地区最好的律师是......，他去年承接了 100 多件成功诉讼。”

这些听说、看到、感觉到的，正是以软文为源头。Google 的图片搜索网页在很多年以前，曾经一直打着一句话：“世界上最好的图片搜索”，百度的网站上有很多年写着一句话：“世界上最大的中文搜索”。当这句话被重复了一亿次，人们承认了这个说法，于是，数以百万计的人向其他人重复介绍这句话。

机敏的企业家清楚自己要做什么，他们向世界反复宣布着自己创造的概念。我们可以认为：软文的强大价值是奠定品牌。

一是个人品牌，二是企业品牌，三是国家品牌。人们借助于大规模的软文，将一个人的名字、一个企业的名称、甚至是一个国家的特征，向整个世界兜售。

最著名的人物，肯定频频出现在媒体面前；最著名的品牌，肯定让你天天看到这个牌子在重复出现；最著名的国家，肯定在不断地制造概念和事件，吸引全世界的记者和媒体去报道它。

# 用软文打造个人品牌

你可以不开公司，但无法阻止你的财富象滚雪球一般增长。名气与收益常常是对等的，名气的背后，常常是巨额的财富，或者是极为强劲的社会资本，而社会资本随时可能转化为财富。

成为公众人物可能比较困难，但成为一个有名望的专家，则显得非常容易。

成为有名专家的好处是，在这一个领域，你无可匹敌。人们出于信任你的专业水准，愿意将大笔的生意交给你来做，正因为人们信赖专家，所以整个领域或市场的资源、资金都会向你靠拢。如果你在这个领域中没有名气，那么一切与你无缘。
