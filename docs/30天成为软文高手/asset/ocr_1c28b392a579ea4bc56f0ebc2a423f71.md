# 五、用软文进攻市场

软文品牌推广策略，带有明确的市场进攻性。除适用于产品和企业自身的宣传推广外。更应采取一定策略，用一定的“由头”来快速建立市场影响力，完成市场覆盖。

策略一：可以采取“百万经理人网盘赠送计划”，即向职业经理人、企业管理者、中高级白领等，经信息验证后，赠送为期一年的网盘使用时间。采取这一策略，主要是让使用者向网盘中大量存储资料，在他们存储了一定数量、规模的资料后，使用时间到期，就不得不购买付费服务。操作要点是：赠送期不能太短，如果仅仅赠送半年或更短使用期，用户会感到时间很紧，还没有存入多少资料，就要停止使用，他们会非常谨慎使用，以免重要资料发生丢失。该策略也适用于设计师、艺术家等重度网盘用户，网盘经营的关键是用户大量向内存储重要资料，后期就不得不被动使用，而且长年持续使用，如果用户没有存入多少重要资料，他随时会放弃使用，转向其它品牌的网盘。

策略二：“卓学网盘杯”网上书画交易心得大赛、“卓学网盘杯”互联网设计师名人大会、“卓学网盘杯”网络作家成名奖……公司应开展多项与直接目标客户对接的赛事活动，与专业网站合作，向行业用户大量渗透品牌影响力，定向捕捉专业用户。操作要点是：先入为主是捕获专业用户的最佳方式，举办赛事，提供奖金和奖品只是一种策略，最主要的目的是在庞大目标客户中奠定卓学网盘的专业级顶尖形象、定向市场地位，催使行业用户大量使用，并规模扩散，最终黏附这些领域的大量用户，成为这些行业用户唯一的或首选的网盘服务商，这种选择通常是排它性的，而且这些客户能够成堆成片开发。它有一个蝴的基础，一旦某一行业用户超过10000人使用了某一种品牌的服务，那么会在行业用户的聚会、讨论、交流中，大批地成倍增加付费客户，年年占据行业的市场地位。
