# 网上写作论二十九：网上写作要点

# 段落段一点分段多一点

+   1、网上阅读，不象在书上阅读，大段地文字，人们不愿意往下继续看，每段的文章最多在一百字上下，不过再长了。

2、很多人喜欢写长篇大论，四五百字挤在一块，访问者阅读起来会很难受。

3、不能象写诗一样，有太多行，这将大大降低人们的阅读兴趣。
