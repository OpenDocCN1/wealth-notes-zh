# 网上写作论之三十三：在网站和博客上的特殊设置

# 文字要用大字体

现在网站设计者习惯将网页中的正文字体放成 14 镑，低于 14 镑阅读起来就会吃力，在 CSS 设定下，14 镑字体看起来方方正正的，不会因浏览器的字体大小变化而变化。但实际上，14 镑并不是最佳的字体大小，长期下去，会对患有近视、 Auf 护眼、老花眼等略有视力障碍的人加重影响，此外，很多人不常使用电脑的人，常常看一会儿就会感到头晕眼花，也和常需采用 14 镑字体有关。

16 镑字体是最佳大小，阅读的人看起来不累，联合国、香港、台湾的网页大多采用 16 镑字体。在国内，只有 IT 写作社区等少数站点采用 16 镑作为正文字体，他们的设置者应该是对研究过“网页无障碍阅读”方面资料的。

作为站长和博客的操作者，你应该注意这个问题，16 镑应该作为一种标准。如果你不知道 16 镑，在网站或博客的内容发布系统中，选中小型字体。

一个遗憾：国内对无障碍阅读方面的研究比较少，16 镑字体的设置，无论在 DR 中，还是在内容编辑软件上，16 镑字体都不能象 14 镑那样显得方方正正。台湾网站在这一点上做就得很不不错。

# 不要在正文区加底色或底图

白底黑字最容易让人阅读，人们也最习惯。除非是为了特殊情况，比如某个活动的专题、广告页面，为了吸引人们的注意，可以使用底色，但文字与背景应该对比鲜明，除此之外，就不要在整个网站或博客上使用了，即使你的文章再精彩，也不会有人喜欢总耽在你那里，因为他的眼睛会很疲劳。

# 网页朴素、简洁一些

你知道人们最喜欢看什么样的网页吗？我告诉你，纯文字！就是什么背景、图片都没有的网页。不信地话，你可以自己去做试验。这是因为人们在电脑前，面对着大量花花绿绿的网页，眼睛太受刺激，需要找个清静点的地方休息，这就像你在屋子里呆久了，要出去感觉一下绿色植物一样，简单的网页是对眼睛的放松。
