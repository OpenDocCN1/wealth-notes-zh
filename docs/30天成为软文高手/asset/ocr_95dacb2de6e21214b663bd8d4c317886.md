# 事件说明

金龙鱼引领健康潮流，积极推动食用油科技发展。

金龙鱼第二代调和油全新上市，引爆中国食用油第二次革命。

食用油品质的全面提升、人们生活糸质和健康的全面升级，二代调和油满足人们对更健康更美好生活的追求！

为全面普及 02 健康调和油，满足广大消费者的健康需求。
