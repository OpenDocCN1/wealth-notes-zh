# 接二连三的注意

如果你每天能这样坚持地在推出三五篇，不出一个星期，就会在一些网站和论坛上成为知名人士，大家都喜欢看你的东西，所有人都会认识你。

# 而更重要的是，撞车的现象会出现

网上有很多人有他自己独立的圈子，有他每天必访问的网站和论坛，如果你的文章都是围绕某一类的主题，比如这一周谈论的都是关于网站经营方面的，那么就会有很多人转载、摘录你的文章，张贴到他们自己那个圈子里去。

如果张三刚刚转载完你的一篇，抬头一看，李四怎么又从其他地方转载来你的一篇文章，他们心里会怎么想？你即使从来没有名气，他们也知道你的影响力了。在他们眼里，你很快就是声名鹊起，成为一个专家。

唉！原来那就是朱则荣，不多久，一个又一个圈子里的人都知道你了。
