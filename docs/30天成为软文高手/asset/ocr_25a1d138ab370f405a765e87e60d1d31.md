# A 管理模式媒体策略：豆腐块引发的火煳

A 管理模式当年的火热，也是用豆腐块的文章迅速出击，在《中国企业报》、《厂长经理日报》等各种商业媒体上，A 管理模式全面设置合作栏目，每篇五、六百字，连续刊登。

# GOOGLE 媒体策略：垄断媒体引发扩散

GOOGLE 宣称自己从来不刊登广告，靠着网友间的影响力传播，但实则，GOOGLE 的媒体策略有苟明显的人为操作痕迹。例如 2003 年新浪科技频道上，在国际互联新闻中，每十篇中至少有七篇足关于 GOOGLE 的报道，他们以大笔的金钱砸开各种主流媒体，然后大大小小的网站转载抄袭；很多人 Shelby 网上写东西的时候，就不由自主地在文章中引用 GOOGLE。再比如 GOOGLE 的产品推广策略，其产品五花八门，这些产品都被放在实验网页上，任由人们去使用、评价，互相介绍，然后从中找出热门产品。再其次：GOOGLE 善于制造神秘，故意制造出一些概念，引发人们去猜测、讨论。

# 什么是软文

除政治、军事、经济、犯罪、民生、社会问题以外的新闻、评论、文章通常为软文，如艺术、娱乐和生活方式都被视为软文。

# 软文三层论

朱则荣认为，软文分为三层，软文运作的核心，实际是集中在第二层软文。

一层软文大抵来自原始的稿件和素材，包括企业基本资料、领导人观念、技术改进记录、产品使用技巧、服务应用样例、研究报告、用户证词、客户讨论、管理思路、服务小故事等等，是企业原生的基础性素材。它们可能并没有进行过任何加工整理，散落于企业的点点滴滴、日常动态。但正是由企业不注意收集这些原始素材和基础性材料，最终导致在宣传推广时言之无物，没有准确的落脚点和事实做为依托。
