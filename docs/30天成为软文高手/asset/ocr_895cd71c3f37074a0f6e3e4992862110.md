# 网上写作论二十六：噢，原来那就是朱则荣！

文章在网上的传播速度是非常快的，如果你的观点足够地引人注目，足够的对他人有启发，这就足够了，但你必须把它做成短篇，这是一个很奇妙的变化。我说了很多次，只写 600 次上下短篇。

# 排山倒海之势

物以类聚，人以群分，在网上，有很多网站接受投稿，他不会给你提供稿费，但却可以將你推火。

你也可以把文章张贴到众多著名的论坛。但最引人注目的，就是某个网站的首页突然出现三、五篇，三、五篇地出现以你为标题的文章，看过其中一篇的，会打开其他几篇进行阅读，你可以将文章分成一二三四五，也可以每篇单独标题。

例一，一连串的文章标题：

朱则荣：批判长尾理论握持管理批判的权杖

朱则荣：营销补课时光倒流一百年

朱则荣：掉头吞管理把老祖宗的泥胎打碎

朱则荣：进退惟谷小型企业的崩溃之密

朱则荣：独立领导人未知世界的统率者

例二，一连贯的文章标题：

销售网站迷途中的清醒(一)

销售网站迷途中的清醒(二)

销售网站迷途中的清醒(三)
