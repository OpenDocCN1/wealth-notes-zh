# 用软文推广网站

# 明确你的网站名称

用软文推广网站，网站名称直接关乎推广效果，由于中国互联网上，多数网站和论坛不许使用网址，因此网站名称的应用更为关键。

1、创造一个关键词。让你的网站名称成为一个关键词，在用软文推广时，网民或感兴趣的用户可能用网站的名称直接在搜索引擎中进行查找。但是在推广前，必须做一些准备，确保你的网站名称在搜索引擎中几乎没有搜索结果，或者能够排名第一位，否则别人无法快速使用你的网站名称找到你的网站。示例：开心网、开心农场、创新工厂、卓学管理学派等都均可能是一个新的关键词，通过制造软文，让人们进行搜索。

2、创造一个简称。用单词、字母进行组合的名称，有时也便于创造搜索结果，字母长度最好不宜超过五个，或者字母与数字进行组合。例如：EHT800、SEO、CCTV、CCNIC。

3、使用通用名做为网站名称。这类网站名称，通常使用某某网、某某站，由于这类名称本身由热门关键词组成，利于在搜索引擎中的排名，但是如果搜索引擎上已经存在同类网站名称时，则不易使用。示例：站长网、站长站、公司网、跨国公司网;或者使用“名称+属性”，如卓学创业网、三五域名网、长江威容网等。

4、用软文制造影响力。这类网站，一般用软文推广的不是网站，而是有意地让大型门户网站、专业网站和媒体来报道该网站，使该网站看起来更可信、更有地位、更有声势，利于让客户信任、进行融资或上市等活动。你可以观察到有许多网站都有“媒体报道”这一栏目，或者将媒体报道提至网站首页，以便让访问者确信。采用这种推广方式，对网站名称没有太多要求，适用于任何网站名称。

总体而言，用软文推广，一般很少使用比较热门的搜索关键词做为网站名称，比如创业网、鲜花网、周公解梦，叫同样网站名称的网站数以百计千计，它过度依赖搜索引擎，没有必要用软文推广。
