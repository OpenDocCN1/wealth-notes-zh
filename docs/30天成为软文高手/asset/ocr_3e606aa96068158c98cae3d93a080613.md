# 个人操作版：为什么你的名气大

你不一定了解什么足营销，你可能根本不懂什么足搜索引擎，但是，你必须让自己成为网上的一个焦点！

在过去的时候，你写过不少东西，自己的心绪、感受、一些见解，但并没有多少人注意到你，ocalypse唉心了；也许，你从来就没有写过几篇，但若有着那寥寥无几的读者，引发不起你写作的兴趣，你根本提不起精神去写。其实最关键的，你没有掌握覆盖的神来之笔。

文章在网上的传播速度是非常快的，如果你的观点足够地引人注目，足够的对他人有启发，这就足够了，但你必须把它做成短篇，这是一个很奇妙的变化。这一点我说了很多次，每篇文章只写几百字，关键是量。

# 排山倒海之势

物以类聚，人以群分，在网上，有很多网站接受投稿，它们不会给你提供稿费，但却可以将你推火。

你也可以把文章张贴到众多著名的论坛。但最引人注目的，就是某个网站的首页突然出现三、五篇，三、五篇地出现以你为标题的文章，看过其中一篇的，会打开其他几篇进行阅读，你可以将文章分成一二三四五，也可以每篇单独标题。
