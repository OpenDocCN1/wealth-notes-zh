# 网上写作论之三十五：写作是一生的财富

和练习写字一样，你当年没有少下功夫，我已经很多年不用笔，但也时不时不白觉地想拿起笔，去写两下，就象写一笔好字的能力，虽然很多年不去写，但拿起笔来不会生疏，它与你的生命融合成一起，没有人能夺得去，也不会因为年龄的增长而遗忘。

写作是一门功夫，也是相伴你一生的重要财富，要下功夫，就需要十年如一日的苦练。

# 人们之所以写不好文章：

第一：是不下功夫去认真地练，没有耐心儿十次、儿百次去地雷体投稿，其实，当你这样努力去找的时候，总会打动编辑的，即使文章质量不好，他也会帮你修改，有了第一次的发表，接下来发表速度就会明显加快，可能一、二 Shab中一篇，坚持下去就会每发必中。

第二：我不建议一开始向小报、小站投稿，那些编辑的水准不高，你很难将自己的文章磨炼成精品，直接找最有名的大报、大站去投，等你的文章能接二连三被刊登出来的时候，几乎在中国，没有什么媒体能够难住你了，你的文章可以轻松地出现在任何一个著名的媒体上。而小报、小站就成了小菜一碟，反之你练习写作的过程将会很漫长，失败率很高。

第三：人们从一开始老想要写长篇大论，言多必失，思路混乱。你要注意长期的宜将文章控制在 500-600 百字，不要多也不要少，几乎所有的媒体都喜欢 800 字以下的短篇。短篇易写，发表率最高。

第四：这绝对不是文学！书店里最热门的是经济管理类、外语类、计算机类图书，其中，经济类最为畅销。那些诗歌、小小说等纯文学类的图书已经被扫到角落里去了，纯文学作家尽管比较有名，但数量少之又少，几乎所有的媒体，都不喜欢这些无病呻吟的诗歌散赋。相当年，秦人尚武，不重文艺，而七国的人则迷恋在诗文曲调之中，故，秦国能统一天下。在今天这个经济飞速增长的社会，经济已经成为惟一的主调，挣钱成了人们摆在眼前最迫切的问题，并不是那些文化瑰宝不好，而是此刻去谈邪们，不合时宜。

写作就是写作，已经和文学扯不上多少关系了，你的文章只要条理清晰，结构紧凑，观点独到，没有废话，就足够了，而且在五、六百字的内容里，不需要什么文学的修饰，讲几句道理，写几句看法，加几个小例子，就 OK 了。只要你下功夫，写起来并不难，快的话，下功夫去使劲练习一两个月，很可能就开始有文章发表了。

写作中的常见弊病是：前言不搭后语，废话太多，口诺话的东西太多，文章主题跑题，没有条理，话讲不清。写完之后仔细检查一下，让朋友帮你看一下，有没有这些问题。没有就可以往出扔！
