# 十五、在新闻中不要擅自议论

应该客观地撰写新闻。报道中不要提出判断或定论。诸如此类的字眼“&ouml;、我们、我的、我们的”最好不用，除非是作者正在直接引用别人的话。在新闻中对人、地方和事情的好恶褒贬必须出自事实而非作者的观点。

不合适：他做这工作很称职。合 适：他毕业于密执安大学，有十年工作经验。
不合适：一项有趣的节目已经准备好了。合 适：节目如下。(让“有趣的”东西自己说话
不合适：：证人撒了谎。合 适：原告<|start|>师说证人撒了谎。
不合适：他跳楼自杀了。合 适：他坠楼身亡，验尸官认定是自杀。
不合适：市莱克先生和夫人的爱子，6岁的小布莱克今天去世。
合 适：6岁纳杰尼，布莱克今天去世，他是W，布莱克先生和夫人的儿子。
不合适：法官告诉我(告诉记者)此案不予受理。
合 适：法官说此案不予受理。

# 十六、新闻文体的紧凑感

必须写得清晰、紧凑。这种复杂的报道需要精心构思、组织，以保证各个分离的部分能有机地结合在一起。例如在一场雷电大作的暴风雨中，有下列事发生：

+   - 一个闪电击中一座五层砖楼。
- 闪电和狂风的力量使此楼的端倒塌。
- 塌下的墙砺在一辆路过的汽车上。
- 年轻女驾驶员被砺死。
- 另外二人受伤。

一定要对事实、结果行分析，挑选最重要、最具价值的报道点。
