# 多研究关键词

关键词研究，将平衡你的软文关键字。如果你不希望自己写的文章所要体现的关键词被搜索引擎忘记，那就要多注意关键词，以及关键词的搜索结果。当一个关键词有 80 多万页的结果时，你的文章关键词排名将比较困难。

# 找到更好的软文写作观点

写好软文，需要大量的新动态、新事件、新观点进行触发。你可以使用百度新闻或 Google 资讯的订阅功能，定阅一些指定的关键词，每天定时发送到你的邮箱。比如你的网站是关于“科学家”的，那么订阅“科学家”这个关键词，随时帮助你产生更为快速的写作灵感。世界上没有几个擅长软文写作的人是在“闭门造车”，他们通过大量阅读指定内容的报纸、新闻信息，来触发大量的写作灵感。
