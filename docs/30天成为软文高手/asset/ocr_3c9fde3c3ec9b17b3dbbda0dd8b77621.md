# 每段中间空一行

写文章时，一段文字写完，敲一下回车，空出一行，再往下写，注意这个特点！上小学时候，老师教过你每段起首空两个字，你养成了习惯，但在网上，你要养成每段中间空一行的习惯，这是为了人们在电脑面前眼睛比较累，需要用分段让他稍稍放松一下。

# 要用短句

写作时，不要写了几十个字，才加上一个标点，和上面每行分段的原因一样，减轻读者的阅读负担，因此，尽可能让一句话变得短一点。

# 不要使用长文

记住，每篇文章 600 字上下，最长不能超过 1000 字，要养成习惯。

# 网上写作论之三十：网上写作应注意混个脸熟

不要把你的网名或笔名变更换去，固定地使用一个。

+   1、在文章的标题之前，加入自己的网名或笔名。
2、向其他网站或论坛发文章时，对方的管理员一看见你是你的，就不会多作打扰，很可能赏识，
3、你会拥有一些固定的读者，他们一看见你的文章，就会阅读，也会捧场。
4、在名片上印上自己的网名或笔名，出外聚会、活动时，容易沟通。
5、你维文章能够积累起一定的人脉，常阅读你文章的人，会对你非常熟悉你，办任何事情很方便。
6、向著名媒体投稿时，对方编辑一看见你的名字，熟人的稿子会先上，这是规绅。

# 少挂 QQ、MSN 等聊天工具

+   1、QQ、MSN 一有响动，你的写作思路就会被打断，回头再往下写时，你就不知道下面该怎样写了。
2、与其在 QQ、MSN 上睡饥，不如去写文章，反正一样是打发时间。
3、文章所产生的效果，会象病毒一样扩散，其影响力，远远高于 QQ、MSN 上网友的数倍不止。
