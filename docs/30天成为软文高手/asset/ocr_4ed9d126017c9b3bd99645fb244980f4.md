# 八、网页截图工具

推荐使用：SnagIt

SnagIt 是一个非常强大的屏幕截图工具。Snagit 可以捕获网页、屏幕、窗口、客户区窗口、或用鼠标定义的区域图像，图象可被存为 BMP、PCX、TIF、GIF 或 JPEG 格式，也可以存为系列动画。

使用注意：默认象素为 96，安装以后，先要进行设置。

推荐使用：Windows 中自带画图工具

+   1、打开“所有程序——画图”。
2、按电脑屏幕上的“Prtscn sysrq”键，截取屏幕，在“画图工具”上选择“粘贴”，然后“保存”。
3、用 Photoshop 裁切、修正图片。
