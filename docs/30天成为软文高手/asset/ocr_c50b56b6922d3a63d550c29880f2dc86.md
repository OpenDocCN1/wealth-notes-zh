# 少使用动画

运动速度太快的图片和 FLASH，易刺激人的眼睛，难受，如果遇上那些老趴在网上的，他巴不得立即离开你的网页，当他看到那些动画时，看上一眼，他的眼睛就极力想去避免再去看到它，这是人的本能。因此，尽量不要用动画，即使有，也要平滑、缓慢一些。

# 网上写作论之三十四：调整流量的秘方

# 定期将旧文重新提起

新的文章不断在写，旧的文章不断被淹没，你应该定期地写一篇纲要式的文章，把所有写过的相关主题的文章，整理出来，链接在同一篇文章中，这些旧文就会不断地发生作用，而不是被沉没。这篇新写的纲要式文章也会被其他网站、博客转载，新的流量会源源不断地被引入。

# 定期整编主题式的目录

对于博客来说，网站的首页是否有目录，相当重要，能够吸引访问者深入阅读。现有的博客在设置上，都将栏目列表放在左侧或右侧中间部位，处在人们并不顺手的位置上。而你所要做的，就是应该尽可能将他们中相同主题的内容，编写成一篇，而一篇之中，可以进行分支，把它放在首页，每位访问者都会喜欢的。

对于网站的站长，走入了一个长期使用程序做站的怪圈，从来不去精心地编写这样的内容，有价值的文章常常被遮挡住。不需要多，花上三天的时间，如果你能够认真把网站内容整理一下，编出十篇这些围绕某一个主题文章的新文章，你的流量将会有明显的提升，因为人们很方便地在一篇文章里就找到很多他需要的内容。

我记得 2001 年时候的中国计算机报 CCID 光 formes 中，就很擅长编写这样的 小主题，现在可能难以找到了。

# 文章中加入延伸阅读

例如在一篇的文章中间部位，写上以前所写过的文章，把他们串起来，让访问者不断在你的网站上深入访问。
