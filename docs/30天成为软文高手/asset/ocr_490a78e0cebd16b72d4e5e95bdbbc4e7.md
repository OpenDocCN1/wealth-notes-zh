# 例二，一连贯的文章标题：

卓学管理学派：销售网站迷途中的消磺(连载一)

卓学管理学派：销售网站迷途中的消磺(连载三)

操作要诀：在其他网站和论坛上发表，每天所发的篇数最好不要超过五篇，而且每一篇要有实质的内容、见解，否则，会被当作灌水贴，被管理员无情地删除。如果是你的博客，那么现在就动手，将你的博客上原来的杂草全部消除，清空你的博客，按这种连串文章的方式，准备上三五十篇，再重新发布你的博客。否则，你不会有什么影响力的。

# 接二连三的注意

如果你每天能这样坚持地在推出三五篇，不出一个星期，就会在一些网站和论坛上成为知名人士，大家都喜欢吞你的东西，所有人都会认识你。
