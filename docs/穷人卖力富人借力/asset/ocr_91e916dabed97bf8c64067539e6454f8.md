# 借别人的信用去借钱，用借来的钱建立自己的信用

> 在追求财富的路上，在创业过程中，缺少资本并不要紧，只要 你善用自己的头脑，就一定**能像路维格一样**，通过一个 “借” 字，为自己赚来亿万财富。

在这个世界上，金钱虽然不能买到所有东西，但我们不得不承认，大 部分东西是钱可以买到的，而大部分的麻烦也是钱能够解决的。在现实生 活中，真正压在我们头顶上的大问题其实只有一个，那就是——如何才能够 赚到钱！

用钱赚钱远远比卖力赚钱要容易得多，而且要多得多多。很多时候，富 人只需打一个电话，就能赚到穷人一整年的收入。

任何想要创业的人，都免不了要先准备创业的资本，而资金就是创业 的一个必不可少的资本。但对于穷人来说，赚钱可不是一件容易的事。穷 人想要完全靠工作来为自己筹集第一笔创业资本更是难上加难。更重要的 是，对于创业者来说，机遇是一闪而逝的，当你发现了一个好项目，一个 有发展潜力的商机后，如果不果断出击，抓住机会，可能就会落入别人手 里，而你只能扼腕叹息，无可奈何。
