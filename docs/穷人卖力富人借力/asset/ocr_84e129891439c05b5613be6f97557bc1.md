# 穷人卖力
富人借力

岁那年，宗庆后被组织安排到浙江舟山填海滩，一去就是整整15年。回到杭州之后，宗庆后成了一所小学的校工，一干就是近十年。

对于清贫安稳的生活，年近四十的宗庆后并不满意。1987年，宗庆后和两位退休教师一起，通过各种方法，借了14万元，组办了一个经销部，主要负责给附近的学校派送文具和棒冰等。

在这个过 程中，宗庆后发现，很多孩子都有食欲不振和营养不良的情况，这让家长们十分头痛。宗庆后敏锐地感觉到，这是一个巨大的商机。1988年，在宗庆后的提议下，经销部开始给一些工厂加工口服液。积累了一定经验后，1989年，娃哈哈营养食品厂正式成立。很快，他们开发并推出了解决孩子不愿意吃饭等问题的娃哈哈儿童营养口服液。投放市场后，该产品一炮而红。到1991年，创业仅三年的娃哈哈营养食品厂产值已突破亿元大关。

试想一下，年近四十的宗庆后如果没有借来那14万元的创业资金，而是依靠他做校工的微薄工资，他这一生还能有创业的机会吗？如果没有尽早创业，宗庆后能有发现儿童食品市场这一商机的机会吗？即便发现了，他能率先抓住这一商机吗？

富人擅于“借”，穷人却总指望自己“攒”。于是，富人借到了资本，借到了机会，从而为自己筹措到了成功的砝码。而穷人呢？攒走了机会，攒走了岁月，最后握在手中的，也只剩下那些省吃俭用挤出来的微薄积蓄。

富人与穷人不同的行为模式实际上正是不同的心态与思维导致的。在穷人眼中，不管是金钱、人脉还是权利等，统统只不过是财产罢了，借来的，挥霍完了，总担忧着还不上；而对富人来说，不管是金钱、人脉还是权利等，都是能够用来创造收益的资本，借来了，就能利用它赚取更多的
