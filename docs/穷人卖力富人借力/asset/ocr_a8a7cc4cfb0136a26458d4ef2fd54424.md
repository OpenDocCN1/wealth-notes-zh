对创业抱有过多的幻想，在踏上这条路之前，先确定自己是否能够承受其中的压力与痛苦。

从以上几点可以看出，最好的朋友不一定就无法成为最好的搭档，前提是必须能把生意和情感完全分开。生意归生意，以合作伙伴的形式去相处，把一切该清算的资产都算清楚，再把一切应该建立的规则都完善起来。如果能做到这几点，最要好的朋友，也能成为最优秀的搭档。

选择合作伙伴对于创业是否能够成功是至关重要的。那么，在选择合作伙伴的时候，哪些问题是需要考虑的呢？

+   1. 良好的道德品质。正所谓“小胜凭智，大胜靠德”。一个有着良好道德品质的人，才懂得在创业初期为伙伴提供理解、包容、支持以及信任。

+   2. 达成一致的理念。作为一个团队的成员，达成理念方面的一致是非常重要的，否则就算当下不说，以后也会成为争执的根源。

+   3. 互补性强。一个优秀的团队，其成员之间的关系应该是相互依存、相互补充的，这种互补主要体现在工作能力、背景、性格以及社会资源等方面。

+   4. 踏实肯干。很多人以为创业一定是件轰轰烈烈的事儿，但实际上创业有时候比你想象的要无趣得多。决心自己创业的人，一要能吃苦，二要踏实肯干。选择搭档也是如此，绝不能与那种不切实际、不肯埋头认真做事的人为伍。
