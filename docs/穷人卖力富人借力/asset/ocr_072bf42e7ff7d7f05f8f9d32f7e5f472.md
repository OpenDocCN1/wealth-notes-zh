# 维护好“信用招牌”，更容易借钱赚钱

越穷的人，越要懂得重视自己的信用，越要学会用好自 己 的 “信用招牌”，因为这是帮助你改变命运、脱贫致富的唯一资本。

如今，信用作为一项重要资本，已经和我们的工作、生活都 产生了密切联系。良好的信用不仅能让我们取信于人，还能为我 们创造可观的经济效益。

湖北嘉鱼县潘家湾镇东湖村是湖北有名的“信用村”。一般 来说，银行都不太敢贷款给农户，因为很多农户的信用意识并 不强，贷款给农户，很容易产生坏账、烂账。但东湖村的农户 例外，潘家湾镇信用社为该村农户推出了农户联保贷款，不仅 给了农户们极为优惠的贷款限额、还款期限和还款利率，还为 农户们实现了完全零抵押贷款。

众所周知，无论干什么事情，资金都必不可少。农户们也 是如此，每年无论是种地、养猪还是养鱼，都需要启动资金， 资金越多，所能发展的生产规模也就越大，收益也就会越高。 因此，信用社给农户们的贷款可以说帮助他们创造了极大的经济 效益。

为什么东湖村的农户能够得到如此优待呢？信用社为什么愿 意以如此优惠的条件给这些农户办理贷款呢？
