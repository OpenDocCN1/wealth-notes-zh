# 穷○卖力
富人借力



左右逢源，进退自如，上不得罪于达官贵人，下不失信于平民百姓，中不招妒于同行朋友，行得方圆之道，人缘大树枝繁叶茂，那成大事一定不在话下了。”胡雪岩强调的“人缘”，其实就是我们今天说的“人脉”。

也许是因为许多成功学都在强调人脉所能带来的好处，因此有相当一部分人对人脉的积累存在严重的误解，总是将人脉与直接的联系在一起，带有极强的功利性。这也是社会上总存在着一种人，常常带着极强的目的性和功利性在与人交往的原因。

人脉其实就是一种人际交往，但很多人把这个概念看得很特殊。在这些人眼里，人脉就像是一场生意，在建立之初，就要考虑到其所能带来的回报。因此，这些人在建立人脉关系时，常常会考虑的一个问题就是，这条人脉是否能够为自己带来利益、权势等显性资源。

人脉的贵重不只是与金钱或权势挂钩的。好的人脉，能为你带来的好东西数不胜数。一个对你有益的朋友，能够在生活上给予你良好的引导和及时的帮助，我们说这就是好的人脉，虽然这位朋友未必能帮你平步青云；一个能在思想和感情上给予你慰藉和帮助的人，同样也是你的好人脉，他未必能为你带来巨额财富，却能让你的人生、事业更上⼀楼层。

如果你将人脉看作是一种功利性的东西，与任何人交往都带着明确的目的，必然会成为别人眼中的“势利眼”。试想一下，你会愿意和一个“势利眼”交往吗？会愿意为一个“势利眼”提供帮助吗？己所不欲，勿施于人。

“有心栽花花不开，无心插柳柳成荫。”这是人脉关系中十分常见的一种现象。有时候，当你带着极强的目的与别人交往时，未必能得到自己想要的东西；但有时候，你无心的举动反而能为带来意想不到的收获。
