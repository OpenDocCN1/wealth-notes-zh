# 智能制造的理解

## 智能制造范式

- 第一阶段 数字化制造

在制造技术和数字化技术融合的背景下，通过对产品信息、工艺信息和资源信息进行数字化描述、集成、分析和决策，进而快速生产出满足用户要求的产品。

- 第二阶段 网络化制造

从本质上讲，它就是“互联网+”制造，在国外也被称为“smart manufacturing”，是在数字化制造的基础上实现网络化，使用工业互联网、工业云技术实现联通和集成，同时还具备一定的智能。

- 第三阶段 智能化制造

智能化制造的主要特征表现为通过智能装备深度学习、增强学习、迁移学习等技术的应用，是新一代人工智能技术的创新和与制造业的融合。使知识产生、获取、应用和传承效率发生革命性变化，显著提高创新与服务能力。

推进制造强国战略，就要推进制造业高质量发展，而制造业的发展要依靠科技创新，智能制造则是制造业高质量发展和科技创新的交汇点，是推进制造强国战略的主攻方向。

## 智能制造系统的概念

任何制造都需要有一个制造系统来完成，推行**智能制造**必须构建一个智能制造系统。与传统制造相比，其增加了一个由各种各样的软件集成起来虚拟的信息系统，这个时候物理系统实际上不是简单的机器，都是一些包括智能机床、智能机器人或专用的智能装备，它们两者之间的融合就构成了一个“**信息物理系统（CPS）**”，它是智能制造系统的核心。是通过虚拟的信息系统与实体的物理系统深度融合和精准映射，创建出虚实合一的信息物理系统，两者实现实时同步。

**信息物理系统，是智能制造的核心**

1. **智能制造的本质特征**
2. **智能工厂，智能制造的精髓**
3. **精益生产，智能制造的基石**
4. **实体制造，智能制造的本质**

**最终目的：**
提高生产效率、减少资源消耗、提升产品质量、降低生产成本、提高企业效益。

**让明天更美好！**

## 企业数字化转型面临的普遍问题

1. **观念难转变，思想不统一**

不同部门有不同的认知和理解，有不同的利益诉求，从而使得部门之间难以达成一致的目标，采取统一的行动。

2. **数字化人才缺口大，成本高**

- 紧缺既懂数字化技术，又懂业务的“桥梁型”人才；
- 数字化人才培养成本高，企业留住人才难；
- 缺乏岗位人才模型，现有员工与岗位、业务匹配低。

3. **基础水平差，缺乏有效方案**

- 绝大多数企业仍处于自动化、信息化水平，数字技术供给不足，数据采集难；
- 业务与技术两层皮，无法满足企业实际需求。

4. **转型路径不清晰，缺乏连续性**

- 缺乏系统性战略规划，缺乏清晰的战略目标与实现路径；
- 前期资金投入大，效果不确定；
- 急于求成，短期内看不到效果，就会动摇转型的想法。

5. **运营体系缺失，系统分散**

- 多数企业仍处于数据应用的感知阶段而非行动阶段；
- 系统之间相互独立，缺乏整合性，“数据孤岛”现象严重，数据无法支撑决策。

# IO-Link技术

21

- 什么是IO-Link？
- IO-Link是独立于总线的通信协议，它通过点对点连接来自传感器和执行器的过程数据，以及以需求为导向的参数化和诊断数据。
- 3线的普通电缆即可实现上层控制器与传感器、执行器的点对点通信。
- 类似于工业自动化领域的“通用USB”接口。
