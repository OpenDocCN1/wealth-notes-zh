# 3、背后财政的利益问题

国家此时的政策是房住不炒，意思就是你买房可以，但是限制二手房的交易和流动，所以我们在房地产的二级市场经常看到二手房交易困难。限制新房出售年限，限制二手房贷款，更有激进的地区，直接取消中介，这都是为了限制二手房。目的其实还是推行新房的销售，只有新房的销售，才能推进土地增值，才能维持地方政府的土地财政，如果都去买二手房，国家不赚钱，红利都被私人房东赚走。而如果开征房产税，二手房抛售，新房无人买，土地自然卖不出去，土地卖不出，政府就没钱。

所以，无论是实际操作的难度，以及法律法规的支持，还有背后的政府利益，都不可能让房地产税落地。所以，大家寄希望于房地产税能够降低房价，几乎是不可能。

△萧何自污，刘邦不会不清楚，但为什么依然信任他呢，不是因為萧何懂权谋或者不懂权谋，而是大家通过这种交手，彼此确认了相应的边界，都踏实。

△运用权谋一定要因时、因地、因人而异，切不可囫囵吞枣，一概而论，如果不顾客观情况，只顾按照固定的模式我行我素，这无异于缘木求鱼，守株待兔，真正成功的人，无一不是对症下药，相机而行，不同的时势，使用不同的方法。

△政治斗争的战场是激烈凶险的，置身其中者，犹如在浩渺无际的大海上航行，必须把握好方向，善于识别激流和暗礁，敏于预测风云和雷雨，灵活机动地应付各类情况，才能避免于覆舟之险，胜利的达到终点。

△如果组织里面多头管理，蕴笨的人会伺候两个婆婆，左右为难，而懂权谋的下属通常会利用信息优势，在不同上级之间套利。领导层之间的缺乏信息沟通和充分协调的情况下，就很可能被信息优势的下属所操控，导致下级领导升级的局面。
