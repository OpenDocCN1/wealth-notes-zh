# 第五章 强与弱



强与弱，包括量的多少和质的优劣。

这一矛盾范畴在各种社会活动中的表现是多方面、多层次的。就个人而言，它表现为物质力量的强弱和精神力量的强弱。物质力量是人本身所固有的参与社会活动的各种体能，精神力量则是人的思想趋向、文化水平和心理素质的总和。人的因素就是物质力量和精神力量，或者说 是心与力的有机统一。当然，作为权谋主体考察强弱，还必须注意到以下几个方面：①显现的和潜在的；②静态的和动态的；③自身的和对比的。因为强弱不仅是表露在外部容易感觉到的，而且是隐藏在内部不易感觉到的；不仅是处于相对稳定状态的，而且是不断发展变化的；不仅是权谋主体自身的力量对比，而且是权谋双方的力量对比。所以，只有通过全方位的考察，才能够准确地把握强弱及其对比。

权谋双方的强弱对比是一种客观存在。无论是权谋主体，还是权谋客体，都有自己的长处和短处、优势和劣势。长处、优势是强项，短处、劣势是弱项。权谋主体要想处理好强弱的关系，就必须在认识自身和对方的优劣长短的基础上，作出正确的抉择，采取有效的行动，使我之强变得更强，我之劣转化为优，进而达到预期的目的。

# 一、说长短 话巧拙

俗话说：“卤水点豆腐，一物降一物。”世间万物既然有一长，就有一短；有一强，就有一弱，那么，身具长处，总能克制短处；保持强项，总能战胜弱项。基于这一原因，权谋主体在处理强弱关系的时候，就先认识到自身的长短优劣。
