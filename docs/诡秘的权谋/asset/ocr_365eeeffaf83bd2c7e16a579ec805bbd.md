# 一、昭义怀远

义者，宜也。所谓“路见不平，拔刀相助”，所谓“可以托六尺之孤，可以寄百里之命”，都是对义之精髓的生动写照。总之，临危受命，不计得失，为朋友、为知己、为了某种信仰和理想，可以赴汤蹈火，以至于牺牲自己的生命也在所不惜，这便是义的基本精神。“义”历来被看作同“利”相对立的范畴，所谓“君子喻于义，小人喻于利”，义不言利，利不涉义，二者似乎水火不容。义利之辩，聚讼数千年，以至于当今之世，它的幽灵仍在徘徊。

从更为高级的层次上说，义与利并非水火不容。义中有利，利中有义。
“义”是对他人的“利”，“利”是对自己的“义”，此其一；其二，即便是对他人有利的“义”，也并非对自己全然无利，何况往往失当前之利而得长远之利。譬如，战国时期孟尝君的食客矫命焚券，义感辞地，虽失当前之利，但日后孟尝君婴相归辞，辞地百姓不但毫无冷淡之意，反而扶老携幼，远道叩迎，这义换来的不是利吗？义既然能征服人心，它就一定能为人们带来利益。所以，以义感召，不仅为正统的儒家所倡导，也成为谋略家们在政治、军事、外交以及其他领域时所时常运用的手段。

春秋时期，晋国派简吴率军讨伐鲜虞，兵临鼓城（今河北晋县），便以重兵将城围住，鼓城危在旦夕，人心惶惶。此时，城内有人愿作内应，叛城降晋，简吴却一口加以拒绝。左右部将困惑不解，问道：“免去将士攻城之苦，何乐而不为？”简吴答道：“我曾听叔向说，位居高位的人爱憎分明，慎言谨行，少犯错误，人民才能有所敬畏和依归，国家也将无事不成，无往而不胜。假若有人叛卖了我们的城池，我们一定憎恨他；如今有人要叛卖他们自己的城池给我们，我们反而就表示欢迎，这实际上是奖赏我们所憎恨的行为。所以，我的主张是有力则进，无力则退，不能为了得到城池就舍大义于不顾而采用奸邪的办法。否则失去的将会比得到的更多。”继而把叛逆者送交鼓城正法。围城三个月后，城内又有人请求投降，简吴接见了城内的部分百姓，然后说：“我看城内有粮可食，还是继续守下去吧！”简吴此举更激怒了左右将士，他们纷纷质问简吴：“能马上得到的城池你不要，屯兵城下，旷日持久，劳民伤财，如何向国君交代？”简吴回答说：“这很好交代。得到一个地方而鼓励当地百姓的怠惰之情，那还要这样的地方干什么用？还不如让他们仍旧保有城池。轻松得到的城池是难以长久拥有它的，不作殊死奋
