# 诡秘的权谋

第一章 远与近

全然无缘，他们于社会生活可谓超而不脱、远而不离，往往通过自己的“代言人”间接地参与社会的政治生活、经济生活和文化生活。他们往往随着社会的兴衰时隐时现，飘忽不定，由此披上了一层神秘的色彩，因而被人们称为隐士。

隐士大都才智超群，道德高尚，但他们却决不出来做官，他们对朝廷采取的是不合作的态度。在社会发展的关键时刻，他们也可能通过培养学生或者为代表着社会发展方向的某一英雄人物出主意、想办法等方式，为时局的发展助一臂之力；但他们不计名利，目的一经达到，便远走高飞、无影无踪了。这种超脱名利的博大胸怀既赢得了世人的敬慕，同时也引起了某些当政者的不满，因为他们需要这些德才俱高的人的合作——而这些隐士往往采取不合作的态度。在我们看来，当政者能够劝说这些清高的隐士出来做官，当然是当政者“圣明”的具体表现；劝不动这些隐士出来做官，转而采取顺其自然的态度，更是当政者胸襟宽广的表现。但古代的当政者并不都这么看，他们中的某些人不能容忍隐士的不合作态度，历史上著名的姜太公吕望就杀了一位名叫华士的隐士，理由是其君既不愿做天子的臣子，也不愿做诸侯的朋友。于此可见，不计名利，与世无争，也并非意味着进入了世外桃源，无任何忧患可言；同时，道家思想以及以道家思想为基本处世原则的隐士并不因当政者的好恶而改变初衷，隐士仍然历代不绝，我行我素。

遁世不易，入世也难。面对庞大而复杂的社会，人们如何在社会的大网络中找到自己应处的位置确非易事，此其一；其二，那些凌驾于众人之上的当政者表面看来出入仪仗，颐指气使，但他们深重的忧患意识却为一般人所不及。因为我们不但面临着自己的入世问题（他们毕竟也是社会的一员），还面临着别人的入世问题，其核心是如何处理“德”与“才”的关系。孔门学人子夏说：“大德不逾闲，小德出入可也。”他主张用人应从大处着眼，不可求全责备。魏武帝曹操“唯才是举”的求贤令古今闻名，他的意思，不管偷鸡的，摸狗的，我用得上，都可以过来，余者不谈。他真是求贤若渴，饥不择食。“大德不逾闲，小德出入可也”的用人原则虽然为大多数人的理智所接受，但由于心理和情感的作用，人们往拘泥于“小德”，从而陷入“德”与“才”的纠结中不能自拔。由此，“疑而复任”、“任而复疑”并因此演化成的悲剧不胜枚举。

与此相反，那些能够高屋建瓴、扬长避短，使“三教九流”各得其宜的圣人贤者才不失为大政治家的手腕。

太公吕望被封到齐国去做国君，齐国有位叫华士的人德行高洁，但他既不愿做天子的臣子，也不愿做诸侯的朋友，由此更赢得了齐人的赞誉。太公曾三次派人召请他出来做官均被拒绝。太公无奈，便派人把华士杀掉
