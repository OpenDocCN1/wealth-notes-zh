# 第九章 直与曲诡秘权谋

言行风马牛不相及，实际上恰似一座沟通人们心灵的桥，把本来有一水之隔的行为紧密联系来。 “条条道路通罗马”，不走这条走那条。一个聪明有头脑的人，面对各种棘手难做的问题，往往会通过间接路线，取得预朋的成功。

燕昭王想招揽天下贤士，去请教郭隗。郭隗告诉他说： “成就帝业的国君，对待贤士如老师；成就王业的国君，对待贤士如朋友；成就霸业的国君，对待贤士如臣下；至于亡国的君主，则把贤士当仆役。大王倘能广造国内贤士，亲往谒见，天下贤士得知，就会纷纷归附燕国来的。”昭王忙问先见什么人合适呢？郭隗回答说： “我听说古时有位国君，以千金求马，三年没有买到。近侍自荐前往，三个月后用五百金买得一匹死马的骨头，回来报告。国君大怒说： “我要的是千里马，你买这些马骨头千什么？”近侍回答说： “买马骨头就花费五百金，天下人必定认为大王求马是真心诚意。千里马马上就会得到的。”因此在一年之内就买到好多匹千里马。现在大王招募贤士，就从我开始吧！我这样的人倘能得到重用，那些比我强的人，必将不惧千里而来投奔燕国。”于是，燕昭王为郭隗建筑宫室，把他当作老师对待。这一消息传到各诸侯国后，邹衍、剧辛分别从齐、赵投附燕国，还有许多贤士也争着到燕国来。

在传统社会里，人才是封建帝王治国安邦的工具，因而通常被喻为“千里马”。郭隗讲的故事给人们一种启示：只要真心诚意去做，就能够赢得信誉；只要赢得信誉，就能够做得称心如意。用五百金买回一架马骨头，进而换取许多千里马。这实在是抛金引玉，而不是抛砖引玉。燕昭王心里明白，对郭隗以老师相待，是广揽人才的一条间接路线。天下贤士有谁不羡慕郭隗的待遇？有谁不敬仰燕昭王这般圣明？因此，他们在心灵上与燕昭王相通，纷纷来投奔燕国，也就在情理之中了。无怪乎有人评论说：“郭隗明于致士之术，便有休休大君气象，不愧为人主帅。”
