# 七、三十六计、百战奇略与智囊

![](bbox=[0.0, 0.12, 0.16, 0.31])

中国传统文化，就它的价值取向、传播方式而论，可以划分为两大类：显文化和隐文化。以“仁义道德”为核心的正统文化，是前者的骨骼；以权诈诡谲为内容的非正统文化，是后者的血肉。在整个传统社会里，显文化为社会提供了一套社会理想、人生目标，以及达到这种理想、目标的途径，始终被人们所接受；隐文化则为社会提供了一套社会法术、人生权谋，以及利用这类法术、权谋的条件，也始终被人们所接受。这两大类文化形态，代表着传统文化的两种传播方式：一明一暗，一浮一潜。仅就统治阶级而言，它们又担负着两种社会职能：一是牧师的角色，一是刽子手的角色。我们所论述的权谋，可以说完全属于隐文化的范围。

汉代以后，在传统社会意识形态领域内，已经形成一种比较稳固的统治思想。各类权谋尽管在社会生活当中仍被广泛的运用，在一定时期内还有不少新的发明，但是，作为一种隐文化，因其价值取向不合所谓“圣人之道”，与占统治地位的儒家显文化大相径庭，所以在理论方面历来颇受冷遇，不为那些正统学者所重视，以至于两千年间留下来的比较有社会影响的权谋著述，寥寥无几。

《三十六计》堪称时下流传最广的一部专门论述权谋的读本。作为一个词语，“三十六计”源出《南齐书·王敬则传》，而后大约在明清之际，适才积累成册，而其作者已不可考证。这部著作将权谋分为六套，即胜战计、敌战计、攻战计、混战计、并战计和败战计。每一套又各分出六种权谋：胜战计分瞒天过海、围魏救赵、借刀杀人、以逸待劳、趁火打劫、声东击西；敌战计分无中生有、暗度陈仓、隔岸观火、笑里藏刀、李代桃僵、顺手牵羊；攻战计分打草惊蛇、借尸还魂、调虎离山、欲擒故纵、抛砖引玉、擒贼擒王；混战计分釜底抽薪、浑水摸鱼、金蝉脱壳、关门捉贼、远交近攻、假道伐虢；并战计分偷梁换柱、指桑骂槐、假痴不癫、上屋抽梯、树上开花、反客为主；败战计分美人计、空城计、反间计、苦肉计、连环计和走为上计。全套共有三十六种权谋。每一种权谋的解说词，都是以传统的阴阳八卦理论为依据的，也就是根据阴阳、八卦、六十四别卦、三百八十四天的宇宙认识图示，来阐释每一种权谋的矛盾对立及其相互转化。所以说《二十六计》在思想内容方面多少带有一定的朴素辩证法的色彩。
