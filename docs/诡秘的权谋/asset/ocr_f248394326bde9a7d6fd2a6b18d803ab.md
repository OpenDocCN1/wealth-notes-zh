# 绪论

# 诡秘的权谋

明创下汗马功劳。这部著作按照战争双方的政治、经济、军事和自然诸条件，把历史上的战争（主要是战役）分为一百个类型，逐自加以论述，指明它们在实际运用中所必须掌握的要领。在理论方面，作者吸收了《武经七书》及其他一些军事著作的战争观点，运用和发挥了“上兵伐谋”、“因敌而制胜”、“先胜而后战”、“致人而不至于人”、“必死则生，幸生则死”、“见可而进，知难而退”、“兵贵神速”等一系列军事谋略思想。在材料方面，作者汇集了先秦至五代1600多年间散见于各种史籍的著名战例，将这些战例分别编入每一种权谋的后面，作为对有关论点的具体注释。正是把理论与史料结合在一起，《百战奇略》才成为一部有血有肉、颇受世人青睐的军事权谋著作。

《智囊》是中国文化史上搜罗最富、篇幅最大的一部谋略故事汇编。编著冯梦龙，为明代著名的文学家，世情小说《三言》的作者。他以“不唯其人唯其事，不唯其事唯其智”为宗旨，从先秦迄明初间经史百家、稗官野史之中，搜集出一千多条以智取胜的事例，经过分类编排而成《智囊》一书。这部书将谋略分为十部：“上智”是经国大略；“明智”是远见卓识；“胆智”以胆略见工；“捷智”以敏捷夺人；“察智”是洞察秋毫；“术智”是随机应变；“兵智”是治军用兵；“语智”是妙语绝论；“闺智”是妇女心计；“杂智”是小人伎俩。每一部又分若干类：上智有“见大”、“远犹”、“通简”、“迎刃”，明智有“知微”、“忆中”、“剖疑”、“经务”，察智有“得情”、“诘奸”，胆智有“威克”、“识断”，捷智有“灵变”、“应卒”、“敏悟”，术智有“委蛇”、“缀数”、“权奇”，语智有“辩才”、“善言”，兵智有“不战”、“制胜”、“诡道”、“武案”，闺智有“贤哲”、“雄略”，杂智有“狡黠”、“小慧”，凡二十八类。在主客体方面，人物多种多样，有帝王将相，有凡夫走卒，有毫毫耆老，有弱妇幼童，较之其他著作更具有代表性。

这些著作以其鲜明的特点和成就，对于我们进行权谋研究无疑具有不小的参考价值。不过，我们应该看到，它们在理论观点、编纂方式上，还存在有许多无法掩饰的缺陷。《三十六计》说到底不能算做一部完备的权谋著作，只是对各类权谋的一次部分归纳；就每一个权谋而言，有的拘泥于成语定名，不免牵强附会，有的名异实同，造成全书结构的重复现象。《百战奇略》所论述仅限于冷兵器时代的作战问题，而不曾涉及社会生活的其他层面；因为对战争缺乏总体性的认识，在具体剖析各种军事权谋的时候，就没有处理好战略、战术和战斗技能诸关系的问题。《智囊》所揭示的谋略分类，有的根据权谋主体的言行心态，有的则参照不同的权谋场，实在没有一个统一的标准；同时对每一个事例既没有具体的概括，在编排时又没有时间顺序，因而通篇显得比较杂乱。更为甚者，这些著作提供给人们的，都只是每一个权谋的表象，也就是简单的形而下的描述，至于每一类权谋之间的内在联系，却缺乏较深入的探讨，因而无法形成一种形
