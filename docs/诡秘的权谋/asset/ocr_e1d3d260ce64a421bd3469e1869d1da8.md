# 第五章 强与弱

# 诡秘的权谋

李信草职，并亲自去见王翦，向他表示歉意，请他领兵出征。王翦坚持说非 六十万人不可，秦王政反问说：“历来打仗很少超过十万人的，如今虽然兵 马有所增加，也不至于要用六十万人吧？”王翦解释说：“现在围攻一座城， 也许要费几年工夫，打来之后又要派兵驻守，几十万人哪够分配呢？再说楚 国地大人多，只要楚王一声令下，动员一百万兵马也不太难。我说六十万还 怕不太够，再少就难以成功了。”秦王政听了，称赞王翦经验多，见识广，答 应照他的意见办。王翦带着六十万大军，来到天中山（在今河南汝阳）安营 扎寨。楚王负刍闻报，立刻派项燕、景显各领二十万兵马，前来迎战。于是王 翦下令全军将士加固堡垒，在酒足饭饱后跳远、跳高、扔石头，锻炼身体，对 于楚军的挑战，根本不予理会。过了好久，项燕觉得秦军可能是来此驻防 的，也就不再重视秦军的行动了。当楚军戒备松弛的时候，王翦指挥秦军如 排山倒海之势，向楚军发起总攻。楚军仓猝抵抗，被打得一败涂地，结果项 燕、景琪自杀，楚王负刍被俘。王翦迅速占领楚国属地，凯旋回朝。

秦楚之战是秦统一六国战争中一次较大规模的作战。秦王政在吞并韩、越，重创 燕国之后，急于灭亡楚国，因而无视楚国地广兵多，难以速胜的实际情况，轻率 地决定以二十万兵力攻楚，结果遭到失败。经过这次失败，秦王政承认了自己的 失策，接受了王翦的作战计划，为攻楚纠集了优势兵力。王翦作为一名统帅，不 仅在战略决策上老成持重，没有必胜的把握而不出战，而且在战术方面不急于 同楚军正面硬拼，反客为主，吸引楚军主力来攻；当楚军求战不得，弱点暴露无 遗后，实施连续的追击战，很快灭亡了楚国。

在这里我们还要谈到“连环计”。这是三十六计之一，其具体含义是：敌方 兵多将广，就不能与他们硬拼，应该使他们自相钳制，以削弱其力量。《三国演义》第四十七回“庞统巧授连环计”，给我们描绘了一段很精彩的故事，这也可 能就是“连环计”的发源处。
