# 诡秘的权谋

第四章 真与假

这是生活中的小幽默。秦桧在国家生活中也不乏恶作剧般的权谋，虽获一时之
宜，却难收长远之功。

秦桧当政时，一个时期曾经缺乏现钞，致使商品难以流通，造成大量积
压。杭州府尹曹泳焦急万分，便来向秦桧告急；秦桧便说：“这很好办。”当
即把文思院官叫来，吩咐说：“刚才接到圣旨，准备变易钞法，你们按过去
来锡的成色造一缮呈上用来以便定夺，现钞全部废除不用。明天中午一定要
把样钱铸出来。”院官领旨后，立刻命工匠连夜赶铸。富家权贵闻讯后，急
忙拿出自己的积蓄抢购物品，致使物价暴涨，现钞充斥市场。等文思院官把
新样钞呈上后来，就再也没有下文了。

这种以假充真的权谋在国家政治生活和经济生活中的运用同它在战争中的运
用，其整体效应有着明显的不同。其运用于战争，能获一时之宜的一般也能收长
远之功。像李广惑敌，刘邦诈降，一时之宜既得——保存自己，长远之功可
收——给对方造成了变幻无常、难于预测的印象，而这正是兵家所欲达到的目
标。兵家无常轨，比如背水阵既为兵家所忌，又为兵家所用。政治生活和经济生
活则不然；它以稳定为要素，贵在以信示人。像秦桧变钞之谋，虽得一时之宜，但
一代权相失去信誉，不良后果可想而知。孙膑和司马懿假痴之谋又当别论。宫廷
斗争类似两军交锋，你死我活，贵在保存自己；只有保存自己才有长远之功可
谈。

诈伪之谋在政治斗争中并非全不可用，关键在于拿得起，放得下，说得圆，
理得通。

该如何处置，陈平反问说：“这件事有没有其他人知道？”刘邦答：“没有。”
陈平又问：“韩信是否知道？”刘邦答：“不知道。”陈平又问：“高帝的精兵
同楚国比较起来如何？”刘邦答：“不如楚国。”陈平又问：“陛下的将领带
兵作战有能超过韩信的吗？”刘邦答：“不如韩信。”陈平进一步分析说：
