# 第八章 刚与柔

![](bbox=[0.0, 0.0, 0.4, 0.06])

清代康熙、雍正年间，阁老张廷玉在家乡桐城修盖相府时，因三尺地盘同邻人发生了争执，双方相持不下，官司打到县衙。张家总管立刻写信给京城里的相爷，俱实以告，并希望张廷玉给知县打招呼予以关照。张廷玉看了家信，略微思索，在原信上写了一首诗，便将原信寄回。他写的诗是：“千里求书为道墙，让他三尺又何妨。长城万里今犹在，谁见当年秦始皇。”张家总管读了这首诗，便立刻吩咐让三尺出来。邻人见张家突然让出三尺地来，反而觉得难堪，也后退了三尺。两家互让得六尺巷道，被人誉为“六尺巷”。

这是以柔克刚。以柔克刚的权谋之运用，要求权谋主体必须有幽远的胸襟。唐人张籍路过汾阳王旧宅，不胜感慨，题诗道：“汾阳旧宅今为寺，犹有当年歌舞楼。四十年来车马散，古槐深巷暮蝉愁。”汾阳王郭子仪是唐代中兴名将，“安史之乱”，唐廷式微，郭子仪驰骋沙场，力挽狂澜。所以在他告老以后，皇帝赐给他一个汾阳王府。兴工之时，他闲来无事，工地地上去转，吩咐泥工把墙壁砌得矮些实些。这位泥工对郭子仪说：“我家祖孙三代在长安做泥瓦工，不知盖了多少府第，只见主人更易，还未见房屋倒塌的。”言者无意，听者有心。郭子仪听了这话，拄着杖走了，再也不闻不问。

芸芸众生，不为利来，即为利往。而一旦通达世事，便不再患得患失。即便把王府建得固若金汤，到后来还不是“古槐深巷暮蝉愁”？清人张廷玉回家人书“千里求书为道墙，让他三尺又何妨”，也颇具幽远豁达的胸襟。单从行文看，其所以“让他三尺”虽出于“长城万里今犹在，不见当年秦始皇”的今昔之感。但客观上却收到了欲予反得的效果。两家为三尺地盘诉讼于官，自然是互不相让所致。即使知县有畏张家权威，令其胜诉，邻人也未必能心服；更何况邻人既然敢于抗衡相府，当然非等闲之辈，鹿死谁手尚难预料？处于如此难解难分的胶着状态，解脱的最好办法就是激流勇退，以柔克刚。老子说：“将欲取之，必固张之。将欲弱之，必固强之。将欲废之，必固兴之。将欲取之，必固与之。是谓微明。”这是人世万端的一般法则。任何事物都是相对的，都会向其相反的方向转化。张廷玉让而反得亦是此理。

海虞严相公欲在城中营造一座宅院，大量已毕，恰有一民宅错入其间，使严宅不能成方圆。那家人以卖酒和豆腐为业。司工以优厚代价恳请他们搬迁，遭到严词拒绝。严相公泰然自若，吩咐司工说：“没有关系，先营建其余三面。”开工以后，严相公又命每日所需酒和豆腐一律从这家购进，并提前付给他们钱。这家店面本钱不多，人手又少，供不应求，严相公便募人来做帮手。随着工程的进展，工人的增多，小店获利也随之增多。店里的粮食
