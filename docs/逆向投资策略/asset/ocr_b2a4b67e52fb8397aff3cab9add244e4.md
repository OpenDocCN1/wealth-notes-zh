# 第4節：使用投資人過度反應假說成功的機率為何？

# 研究發現

講到這個，我想一定會有一些耳語，而事實正是如此。市面上充斥各式各樣的投資寶典，大家吹捧的投資法也各自不同。有任何逆向策略能長期戰勝市場的真實證據嗎？確實有的。

基於我們41年來對Compustat資料庫裡1,500家大型公司股票的報酬率研究，我們發現逆向策略勝過市場的機率，在任何一個季度大約都是六成。而拉斯維加斯和大西洋城的賭場以對他們有利的規則大撈特撈，贏錢機率也才5%至10%。使用逆向策略贏過大盤的機率甚至比賭場還高。待我們仔細研究這些機率，我猜結果會讓你大吃一驚。
