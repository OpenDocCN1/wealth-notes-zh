# 3. 2006至2008年房市泡沫與市場崩盤

大家現在對2000年代初期到中期發生的房市泡沫已知之甚詳。金融體系與諸多機構不當行為的交互作用，超出本書的範圍，此處我們只簡單介紹效率市場假說在這場巨大泡沫推波助瀾的部分，這次危機除了為禍更烈，跟長期資本管理公司的情況沒什麼不同。

1987年崩盤和長期資本管理公司倒閉後，投資機構囫淪盲目相信波動性是最後的風險衡量，次貸和其他劣質住宅房貸擔保證券（residential mortgage-backed securities, RMBS）*的槓桿雖然高到不像話，所學盡是效率市場假說與資本資產訂價模型風險說的基金經理人或風控部門，仍不怎麼在意。當然，流動性也不足介意。房貸的類型何止千百種，債信品質好壞落差很大，但整體來說，流動性都不好，因為一檔產品通常包含一系列最好的AAA評等到最差評等的住宅房貸擔保證券，大多需要下很大功夫來粗估價格，經紀商通常有不小的買賣價差區間。雖說如此，波動性仍是最後的風險因子，而且當房價持續上漲，波動率其實相當低。
