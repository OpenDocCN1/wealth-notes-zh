# 學到什麼？

讀者現在可以自行判斷效率市場假說在以下方面的假設真實性：

+   - 流動性。
- 槓桿。
- 波動率和報酬率的相關性。
- 波動性是否長期穩定。
- 理性的投資總是會讓價格保持正確。

效率市場假說和資本資產訂價模型的理論支柱看起來都可以打掉重建了。效率市場假說當道這麼久以來，市場還有經濟因此招引的大禍可說歷歷在目。

然後呢？難道我們就不進市場投資了，錢都藏在床底下？效率市場假說讓無數投資人做了糟糕的決定，但並不是沒有更好的方法。現在我們通過了黑武士這關，從效率市場的深淵脫身，我敢打包票，當你知道方法，市場上有的是一大好機會。

而第一步我們要用心理學和逆向操作策略來精進自己，有了這些準備能讓我們一勞永逸的解決掉效率市場假說的糾纏。
