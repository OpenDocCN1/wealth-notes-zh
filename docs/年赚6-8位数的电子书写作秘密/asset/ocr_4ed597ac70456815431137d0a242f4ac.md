# 2）在淘宝店自动销售

使用淘宝店铺平台的旺旺自动回复系统销售。首先，你需要有个淘宝店，在系统设置留言里输入你要下载的链接和密码（把电子书上传到百度网盘）。买家付款拍下后，系统会自动发送下载链接到买家的旺旺聊天窗口。买家直接打开下载就行。
