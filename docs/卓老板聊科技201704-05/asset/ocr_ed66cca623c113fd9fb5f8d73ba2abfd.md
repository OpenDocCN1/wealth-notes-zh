# 「与卓老板相识的一年」征文

渐进社，你好！

亲爱的1917小组成员，你好。我是《卓老板聊科技》产品经理康觉心。当你看到这封信时，《卓老板聊科技》已经陪伴你11个月了。

在这段日子里，我们了解了许多有趣的人。比如女画家Concetta Antico拥有4种视锥细胞，她看到的世界比我们看到的更偏黄偏红，正好她的职业是画家，所以我们才得知世界上还有4种视锥细胞的人存在。还有物理学家费曼，他是个特别闲不住的人，好奇心又重，总想各个领域都研究研究，他在普林斯顿工作的时候，总是和别的学科的教授一起吃饭，因为这样可以讨论到不同的话题，他还把这些故事写在了自己的自传《别闹了，费曼》里。

我们还紧跟时代步伐，学习了当时的各种热点知识。比如朱诺木星进入轨道，我们学习了朱诺号的构造，了解了它在太空中经历的各种险情，顺带还补充了木星的知识。当我国第一颗量子卫星升空时，我们学习了什么是量子纠缠，什么是量子保密通讯技术。

除了上面说到的两点，我们还破除了很多谣言。比如水素水杯并没有养生美容功能； Fukushima核电站并没有发生核泄漏；红糖不补血；红皮鸡蛋没有比其他鸡蛋更有营养；藿香正气水不能治中暑，反而会加重中暑病情。

我们还给许多没有答案的问题找到了答案。比如人为什么会感觉发冷？人为什么会上火？脱发了怎么办？

……

作为1917小组成员的你其实也知道，上面说到的这些内容只是《卓老板聊科技》1年内容里的冰山一角。我们更系统的知识是从“癌症系列”、“大脑与神经系列”、“城市生活水系列”、“登月系列”等长篇系列内容里得来的。这些内容不仅丰富和健全了我们的知识结构，还潜移默化地培养了我们的科学素养。在《震撼了我的一封读者来信》里，我们已经深深地感受到了科学素养的重要性。

如今，《卓老板聊科技》还有1个月就要跟大家说再见了。（别担心，卓克老师还将继续和「得到」App合作，给大家带来更多精彩内容，请期待~）

在本季内容的最后1个月里，我真诚地希望大家能把这1年的学习心得和感想成文发给我。我将在每周日的19:17把大家的文章更新在专栏里，作为我们专栏“毕业季”的一次大庆典，让我们用行动和感动为这一季画上全满的句号吧。
