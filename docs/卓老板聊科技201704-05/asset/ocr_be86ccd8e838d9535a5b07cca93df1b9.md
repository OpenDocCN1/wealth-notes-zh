# 小蚂蚁成长宣言

本期的内容，时间跨度长，涉及的物理概念多，对于普通读者来讲，理解起来难度较大。但至少有2个方面的启发：

+   1.对于探索未知的态度。人类的发展史，也可以看做是对宇宙万物探索的历史，正是因为一部分不知疲倦、不怕艰难、对世界充满好奇心的人的存在，人类的科技水平才能不断向前发展。在此过程中，即使有很大比例没有得出有效成果，甚至走错了方向，也为后来人提供了极具价值的参考。

+   2.对于多重维度的思考。熟悉刘慈欣的科幻小说《三体》的人，或许更容易理解卓老板提到的9维空间，及站在3维空间看2维空间的情形。不管是在商业现场，还是个人成长，打造或整合多维优势，都是很有必要的。站在更高的维度思考问题、解决问题、参与竞争，就更有可能获得主动、抢占先机，最终赢得更大的利益分配权。
