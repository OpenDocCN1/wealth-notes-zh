# 用户留言

语言文化里的人，不需要了解另外一种语言文化，就能理解和使用数学符号，从这一点来说，科学家追求的是更加普遍、适用范围更广的东西，即符号，数学不是一种语言，而是一种符号，语言也是一种符号。

这么来看，具备科学理性的人，一定是会使用符号的人。数学，这种符号具备规整秩序的美，具有其他符号不具备的直观性，直观这个词可能不准确，语言图画不管多么清晰，或者受限于图画的固有形式，或者只能凭借语言而与自己过去的经历关联起来想象，所以，都做不到数学符号所展示的这种抽象直观。说到直观，我们通常就是理解成形象的、具象化的，甚至等同于图画的性质，而很难想到 直观也可以是抽象的。
