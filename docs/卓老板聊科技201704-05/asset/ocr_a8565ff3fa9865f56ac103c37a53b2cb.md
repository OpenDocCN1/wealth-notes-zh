# 问答：价值观过于多元，是不是不好？

小象象：樊登老师，很多时候我觉得自己价值观过于多元，有时自己会觉得同一件事情各方的意见都有道理。价值观多元是否意味着没有价值观？这样会不会很不好？

价值观过于多元，是不是不好？

樊登

对各种东西都信，好过什么都不信。

孔子说：“我则异于是，无可无不可。”就是说，没有什么一定要坚持的信仰和原则，一切东西都遵循天理而来就行。所以孔子生活得特别活泼，也不需要一天到晚“言必信，行必果”，这并不是君子所为。

所以你不用担心自己听着什么都对，判断的核心在于这件事是不是符合你的良知，千万不要非得让自己信一个什么东西，那样的话特别容易被人洗脑。只有像邪教那样的东西才会让人非要相信什么，就算是你不接受，也会通过重复一万遍的方式来让你被迫接受。保持对什么都理解、接受，并且愿意思考，好过对所有东西都怀疑、排斥。所以，中国人学孔子是最对的，要找到解决问题的“天道”，正所谓“朝闻道夕死可也”。这样的话，你会觉得没有那么多束缚，生活中都是新发现，以及开心愉悦的感觉。
