# 给你的一封信

亲爱的1917小组成员，你好。按照本专栏的原定计划，昨天便已经完成了这个专栏的更新。在过去的一年里，感谢你选择了《卓老板聊科技》，也感谢你一年来的支持与陪伴。

最近，在后台的留言中，我也感受到了成员们的不舍。虽然不再更新《卓老板聊科技》的内容，但是留言我还是会看的，也会及时回复。

目前呢，我正在紧锣密鼓地筹备第二个专栏《卓克·科学史》。

《卓克·科学史》大约在7月底上线，在新专栏上线之前，我会每周在《卓老板聊科技》里向你汇报我的筹备情况，所以本专栏在《卓克·科学史》上线之前，不停更。

从下周开始，我们专栏的更新时间和内容将改为：

+   周一 《卓老板聊科技》专题

+   周三 《卓克·科学史》筹备情况汇报

+   周五 1917小组成员学习心得交流

给了你和其他成员们承诺，对自己也是一种激励。为了能在《卓克·科学史》里为大家带来更成体系、更省时间的知识服务，我要死磕自己去了，也希望你能支持我7月份的新专栏《卓克·科学史》，谢谢。

祝安好！

2017年5月27日
