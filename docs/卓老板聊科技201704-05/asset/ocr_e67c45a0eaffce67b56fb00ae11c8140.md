# 问答：传统武术的实战能力怎么样？

最近太极拳和搏击的PK战比较火，对于战况不知道卓老板怎么看传统武术的比赛呢？

传统武术的实战能力怎么样...

太极拳和搏击的PK想必大家已经关注过了，有很多听众要我说一说，那我就聊一聊。

第一个角度是从生物的角度看争斗的发生，资源竞争是打斗产生的根源，比如食物、水、交配权、领地，但是只要你看过动物世界或者Discovery，你就会发现，动物之间发生矛盾后，绝大部分采取的都是恐吓和威胁，做出错张声势的样子，比如猫头鹰会突然把毛都炸起来，体型一下增加好几倍，或者是弄得尘土飞扬，彰显力量，又或者是发出巨大的声响。

不论对方是不是同类，大多数动物采取这种策略就已经可以为一场争奇战下一个句号了。那种把对方至于死地的争斗不能说完全没有，但不是很普遍，灵长类动物中也是这样的。所以我要说的是，不拿武器，赤膊上阵，全力攻击，以造成对方失去意识甚至杀死对手为目标的行为，这并不是动物界常见的行为。
