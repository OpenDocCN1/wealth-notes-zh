# 专题 | 关于癌症，你必须了解的3个知识点

# 癌症1: 从放射疗法看癌症治疗

1896年伦琴发现了X射线，特斯拉又发现X射线对人体细胞有伤害，所以X射线就被应用到了癌症治疗上，医学上一门新的治疗方法，放射肿瘤学就诞生了。

后来居里夫妇用沥青提炼出放射放量更强的镭，它放出的是γ射线。X射线和γ射线本质上都是电磁波，但是γ射线能量强的多，最弱的γ光和最强的X光的辐射强度一样。因此，很多医生觉得γ射线是一个比X射线治疗癌症更好的放射性工具。

从1910年开始到1940年的30年里，医院的放射科开始出现了很多粒子物理实验室才会出现的名词，比如粒子回旋加速器、中子束、线性加速器。医生和护士把病人台上担架，安置在高压氧舱里，把门一关，然后放射科医生启动加速器，对肿瘤进行辐照。治疗完再降压，然后送回ICU。

现在，放射疗法最先进的是质子放疗，碳离子放疗，也就是用质子和碳离子照射肿瘤部位。质子放疗和其他射线最大的不同就是健康细胞损失少。

比如说肿瘤在胰腺，γ射线从肚子照过去，先穿过皮肤细胞，再通过脂肪组织，甚至一部分胃和小肠，然后才能照射到胰腺上的肿瘤，整个路途中都在释放能量杀灭沿路组织，到达了肿瘤后实际能量还远远低于刚刚进入身体的时候，最大部分的能量都用来杀灭沿途无辜的细胞了。但是质子射线和γ射线不一样，它们在进入身体后15cm后才开始释放最大的能量，之前释放的能量强度只有最高百分之二十出头。

病人一般经受这样一轮治疗都非常虚弱，但也有很多肿瘤因为这样集中的照射而被摧毁了。有的时候医生为了保证效果甚至加大照射剂量，病人皮肤会被烧出痕迹，甚至失明，但更严重的问题在于，这些射线在杀灭癌细胞的同时也严重影响了周围正常细胞，正常细胞受到影响后也会癌变。

放疗这把双刃剑有时候杀灭癌细胞，有时候制造癌细胞。自此，癌症的治疗好象进入了死胡同。直到在1940年后另一个治疗分支，也就是化学疗法开始展现实力了。

# 癌症2: 从化学疗法看癌症治疗

有人曾经这么评价过用化学药物治疗癌症的难度，就好像让你找到一种化学试剂，它恰好可以溶解你的左耳，又恰好可以保证你的右耳完好无损。这段话最浅显的让我们明白了癌细胞和正常细胞的差别是多么小。

化学方法治疗癌症是从战争时期的化学武器里找的灵感。当时杀伤人数最多的化学武器是芥子气，后来两位美军研究人员发现芥子气杀哺乳动物的白细胞。他们在1942年还给一位患了淋巴瘤的患者注射过芥子气，结果淋巴上的肿块奇迹般软化干瘪了，不过药一停，这些淋巴又会重新硬起来。

在那个时期，对DNA和抗生素的研究也有了很大的突破。当时的医生从治疗癌症出发，希望能找到一种药，通过破坏DNA来杀灭癌症。还有一部分研究癌症的人从细菌分泌的物质中提取出一种放射菌素D，这种成分对癌症也有不错的杀灭作用。所以1960几年，对癌症的治疗方法是一边注射化学毒素，一边照射γ射线。

也是这时，辽宁的奉天医科大学毕业的一个学生李敏求在美国国家癌症研究所发现了绒毛促性腺素与癌症的关系。这种激素只要在血液中就可以精确的测量出来，他跟踪了一段时间激素和氮甲嘌呤的变化（氮甲嘌呤是一种DNA的毒素），发现只要注射氮甲嘌呤，绒毛促性腺素就下降。

李敏求想要验证自己的想法，便在那些已经几乎痊愈的胎盘癌患者中挑选了几个，继续注射大量氮甲嘌呤。这违反了医学伦理道德，所以他被美国国家癌症研究所开除了。但4个月后，故事发生了反转，那批被认为已经痊愈的胎盘癌患者，一部分人复发了，还有一部分没有复发的，没复发的全部都是在李敏求的试验中过量注射了氮甲嘌呤的患者。

到此，人们第一次意识到，已经被定位痊愈的癌症患者，再进行一个疗程的治疗，其实是必须的。

# 癌症3: 关于癌症的3个“不”

# 1.不用非得仔细检查，找出癌症

人们身体中存在癌细胞是大概率事件，解剖学发现，40岁-60岁的男子，平均1/3的人有前列腺癌，到85岁的时候75%的男子有前列腺癌，80岁以上女性67%的人有乳腺癌。他们没有查出来，只是因为没有影响到生活质量。

# 2.就算早点查出癌症，也不一定有助于延长寿命

美国预防服务工作组评估从1986年到2005年这20年里，因为在PSA筛查中发现自己有前列腺癌，进而去接受手术，化疗，还有因为手术导致严重并发症比如精液中有红细胞，或者丧失生育能力的人越来越多。有100万男性因检查结果是阳性而去各种治疗，而这些治疗导致了5000人死于手术，1.7万人有严重的手术后的并发症。平均来看，PSA检测并不能延长整体人群的寿命，和前列腺癌对人体的损害是差不多的，而且还平添了治疗的痛苦和费用。

# 3.不要过度筛查，拒绝精准医疗泡沫

我们应该调整思路，把“不健康，身体有问题”，作为一种常态来接受。我们身体的图纸是十几万年前留下来的，使用寿命30年，现在因为科技发展，一下都要靠着80年使用，所以后面50年必然要面对各种问题。如果过度担心问题出现，检查和治疗可能会降低生活质量。
