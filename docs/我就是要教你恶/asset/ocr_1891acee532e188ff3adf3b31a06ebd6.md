# 第十四章 如何建議上位者？用他們的觀點

並用比較唬人的顛覆性掌調來寫（而不只是單純實開學問與說教），才更容易聽得進去。

假如《君王論》是徹頭徹尾的政治諷刺傑作，遊走於玩笑與嚴肅之間（許多早期讀者是這麼認為的），那麼許多謎團就能解開了。例如書裡為什麼會有兩種不同的論點？為什麼內容模稜兩可到令人惱怒？而且最大謎團的是：這傢伙十五年來，竭盡心力捍衛人民主政的共和國、避免梅迪奇家族復辟，怎麼可能才出獄幾個月就改變立場，寫了一本出色的諫言書，教導君主如何強化對佛羅倫斯的掌控？而且，他的下一本著作《論李維羅馬史》（可能在《君王論》完成後沒多久，就開始寫了），更是毫不避諱自己偏好共和制，使得這個最大謎團又變得撲朔迷離了。

不過，只要讀者沒被作者的裝傻詭計騙到，或可能闖出一君王顧問」這張面具背後，有股可疑的「共和國味」。他在《君王論》開頭聲明，因為他會在其他著作探討共和制（可能就是《論李維羅馬史》），所以本書就「略過不談」；但他其實食言了，因為《君王論》整本書一直在回頭談共和制、人民與自由。每當他提到冷酷和控制欲強大帝論點，想藉此掩蓋掉上述議題時，它們反而越浮上檯面，並且威脅著君王：如果不關心人民與自由，就會有大麻煩。

此外，馬基維利也沒漏掉自己被倉促解散的民兵團，以及他的老論點——強大的國防必須仰賴正義。他告訴讀者：軍隊之所以強大，並不是靠金錢與龐大的人數，而是激勵將士，讓他們願意奮戰至死；唯有政府給予將士真正的利益（舒適的生活、民眾的尊敬、甚至是參政權），他們才有動機守護政府。假如《君王論》中那個不願道德的鄉野論點，是想激勵君主累積更多權力，那麼比較低調的論點（或許為馬基維利的內心話，只是披上了麵皮），就是在暗示：守序的共和國比較強盛、安全，也比較符合人類的天性。
