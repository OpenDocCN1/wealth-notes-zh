
# 第十一章 人說狐狸狡猾，因為他識破人類的陷阱欺詐

如果佛羅倫斯使者只會對他拍馬屁、假裝承諾效忠，保證會徒勞無功。馬基維利現在已經悟出一個道理：使者要開放、坦誠才會得到好結果，而不是擺出一副姿態的雙面人模樣，心口不一。這道理非常重要，因為有些人雖然很聰明、玩弄兩面手法，卻讓君王完全對他們失去信任，所以他們之後永遠無法再協商了。尤其當你要對付切薩雷這種多疑的君王，就更該懂這個道理。

所以，身為一位專業的外交官，馬基維利不會刻意掩飾自己的感受。這種切薩雷才會信任他，進而表現出真實的想法與意圖。假如馬基維利把這次對談，當成兩位謹慎的國家發言人在鬥智，那兩人都會感受到彼此之間的不信任。因此有些事情還是要記住：你要當一隻能看穿陷阱的狐獅，也要當一隻能威嚇貓群的猛獅。

### 人類說狐狸狡滑——因為牠識破人類陷阱

民間傳說與許多羅馬作家，例如西羅、賀拉斯（Horace）、尤維納利斯（Juvenal）都把狐狸描寫成狡詐的動物。如果他們沒說錯，那博日亞父子就是不折不扣的狐狸。馬基維利日後說道：「教宗歷山六世除了騙人，其他什麼事都不做、什麼事也不想。當他越信誓旦旦承諾某件事，就代表他越不會遵守這件事。我從來沒看過這種人！」雖然，切薩雷的功力還差他爸爸一截，但他也是個高明的掩飾者。

其實，人類天生就喜歡占人便宜。真正的狐狸（也就是有毛皮與尾巴的那種）並沒有示範怎麼說謊、欺騙，甚或捕捉獵物：牠們的天賦是識別陷阱，避免落入圈套，而人類鮮少有這種天賦。身為一個使者，就必須從狐狸身上學到這種才能——尤其是面對這種擅於欺騙的君王時。因此，想對抗切薩雷的狡詐（企圖靠誘捕，吞噬他人的狡詐），你就需要另一種狡猾，藉此看穿詭計、花香巧語與冠冕堂皇的誓言。假如這位博日亞家的君王，是一隻積極好鬥的狐狸，符合大家對狐狸的刻板印象，那麼馬基維利就是另一種狐狸，更接近真實狐狸的天性：為了達成目標而採取守勢，不用真槍實彈，而是以機智武裝自己。

十月七日，馬基維利一抵達伊莫拉，就聽到一個轟動的消息：切薩雷的前盟友、蒙費爾拉托公爵收復了烏爾比諾；這麼城的市民不想淪為切薩雷或教宗的附庸，於是主動叛變，才能如此輕易的攻陷下來。面臨如此窘境的切薩雷，當然更不希望佛羅倫斯投靠這群叛徒。馬基維利見此良機，便直奔宮殿，連衣服都沒換。

他不久之前才來過這間觀見室，當時卡特琳娜為了要阻擋切薩雷的威脅，在此處與她的米蘭籍顧問召開緊急會議；現在，這些華麗的廳堂都落入切薩雷之手。馬基維利出示證件，而切薩雷認出之前見過這位祕書，也就熱情相待。馬基維利按照上級吩咐，一開始先提到背叛切薩雷的盟友，以及佛羅倫斯政府，希望與切薩雷、教廷維持良好的關係。他說：「我的領主說，法國的盟友就是我們的盟友。」

切薩雷感謝佛羅倫斯的友善之意，他語帶堅定地說：「其實，我一直都希望與貴城的大人們建立友誼。如果我沒辦到這點的話，那八成是他人的惡意所導致，不能都算我的錯。」

馬基維利之前就聽過這套說詞。先前佛羅倫斯領地遭入侵、面對阿雷佐等城鎮背叛時，切薩雷就表示全都是維特羅佐的獨斷之舉，並且對於自己的盟友如此恣意妄為，感到非常震驚。六月在烏爾比諾的時候，弗朗切斯科主教就繼續追問他：「可是維特羅佐只是個年輕人，您難道不能管管他嗎？」

切薩雷則替自己辯護：「他是我的親信，但我不知道他干涉了你們跟阿雷佐之間的事。維特羅佐跟你們有私仇，是因為你們殺了他弟弟啊！」當然，這種說詞不足以解釋：為什麼堂堂指揮官，連麾下一個傭兵隊長都管不了？結果，維特羅佐惹出一堆事情卻沒被逮住，而切薩雷只會「震驚」而已。

不過，教宗之子這次經歷過損失後，比較深思熟慮了。於是，他想出一個更具說服力的答案：「祕書先生，有件事我從來沒跟別人說過，但我就老實跟您招了吧。這件事是關於我進軍佛羅倫斯的計畫。」看到切薩雷準備要透露機密的樣子，馬基維利也專心聆聽，配合對方的演出。不知道是因為切薩雷正處於人生低潮，還是因為馬基維利官階較低、與他年紀相仿（兩人只差七歲），比起上次召見弗朗切斯科主教兩人，他這次對馬基維利親切多了。

「我怎麼不想進軍佛羅倫斯，所以極力抵抗此事。自從我們拿下法恩扎，並打算攻打波隆那之後，維特羅佐與奧西尼家就一直纏著我，要我通過佛羅倫斯返回羅馬。而我拒絕他們，因為這違背了教宗陛下的旨意。可是，當我向陛下宣布這個決定時，維特羅佐竟然跪到我腳下，求我一定要取下佛羅倫斯。他向我發誓，絕不會以暴力傷害貴族及其周圍的鄉下。即便如此，我也沒有顧及他和其他哀求者的意，可是他們再三懇求，最後我只好讓步。但我要他們發誓，絕不以暴力傷害貴國，也不准討論要讓梅迪奇家族復辟。」

馬基維利日後寫道：「公爵是出了名的有戒心，但在必要時候還是會開口。雖然，他說的是義大利語，而且是從母親那裡學來的羅馬腔，但是講話的速度卻快如閃電，像西班牙人一樣。他知道，當別人有理由懷疑他時，唯有開誠布公、侃侃而談，任由對方審視事件的細節，才能贏取信任。看來，他從小就懂得用這招擺脫嫌疑。」

切薩雷繼續喋喋不休：「不過，如果可以選擇的話，我還是想藉親近佛羅倫斯來獲利，所以有機會與貴國建立友誼，當然求之不得！」他又講了一大堆藉口：他從來沒讓皮耶羅·德·梅迪奇遭到自己的管轄；奧西尼家與維特羅佐想攻打佛羅倫斯或皮斯托亞，請他批准好幾次，但他都沒允許。「正好相反，我拒絕他們千百次，好讓他們知道，假如找你們麻煩，我就會修理他們！」他也命令維特羅佐從阿雷佐撤軍，甚至還帶著自己的部隊，逼近維特羅佐位於卡斯泰洛城的要塞，藉此威脅他。

「你想了解真相對吧？現在知道維特羅佐為什麼對我不滿了吧！」至於，奧西尼家企圖說服佛羅倫斯加入叛軍，就表示一定有人散布謊言，說教宗想奪走奧西尼家的財產。「所以，他們就加入那個在馬焦內成立的『輸家聯盟』。不過，這些行為只更加證明他們遠比我想的還愚蠢，因為法王還在替我撐腰，教宗陛下也依然健在，他們竟然挑戰這種時候來傷害我！要知道，法王與教宗早在我背後燃起熊熊烈火，不管敵人揚起多少洪水，都澆不熄！」

最後這句話，深深烙印在馬基維利的腦海裡。假如這兩顆火種，除掉其中一顆、或是全部除掉，那切薩雷的烈火是否就會劈啪一聲，然後熄滅呢？

講完藉口之後，切薩雷接著提出請求（也可以說是開條件，因為從語氣聽來，他好像還是比佛羅倫斯佔上風似的）。「我無法針對盟友的不當之舉向你們賠罪，因為您的領土還沒付我薪餉，相信之前的會面都講好了吧？！現在正是付清這筆款項，並跟切薩雷建立友誼、再用正式條約鞏固它的好時機；倘若領主打算再次拖延付款期限，切薩雷又突然跟奧西尼家重修舊好的話，機會就要溜走了。況且，切薩雷和奧西尼家和好的主要條件，是同意讓梅迪奇家族復辟。如果真變成這樣的話，屆時佛羅倫斯又要像之前一樣，面臨各種妒忌與困境了。」

馬基維利聽完後，擺出一副對切薩雷的提議很有興趣的樣子，並想進一步刺探是什麼樣的條約，但切薩雷沒有再提細節。事後，他寫信給上級：「公爵閣下看起來非常想跟您簽條約，儘管我努力打探他更深層的想法，以及條約的具體內容，但他卻一直講些籠統的話，不想細談。」馬基維利想稍微提醒一下切薩雷：搞清楚，你目前的處境可是很不穩的。於是，他故意問切薩雷：「為什麼您的前盟友，這麼快就把烏爾比諾奪回去了？」

「我沒有很在意這個問題耶！」切薩雷回答：「就算烏爾比諾現今在敵人手上，我也沒忘記怎麼把它要回來。」接著他又補充：「我之前就是做人太厚道，對那些事情都不重視，結果害到自己！」馬基維利猜想，他不重視的應該是設法得到新屬地的支持，也就是贏得民心；比起這種苦差事，切薩雷更重視的是打勝仗、搶地盤，而且也知道該怎麼做；不過，怎麼保住地盤與勝利，又是另外一回事了。

### 好運能攻略城池，品德才保住地盤

突然成為君主的人，很快就會失去自己的地盤，除非擁有高尚的品德，才能立即知道怎麼留住手中的機運。像切薩雷就不知道，如何保住烏爾比諾和留住盟友，導致這些盟友反而威脅到他，以及他不牢靠的地盤。或許他還年輕、可以學習，但幾乎沒有人能滿足野心，並同時保有政治家的特質：勤奮、有遠見、能讓人自願支持他。

馬基維利離開觀見室的時候，內心已經十分篤定：近期的衰事把切薩雷嚇壞了，因為之前他的運勢是持續上漲的。馬基維利相信，切薩雷還是有自信再打勝仗，但他話實在太多也太過興奮；身為祕書，馬基維利必須於信中小心傳達自己的判斷。除此之外，最近這些事務讓切薩雷與教宗相當緊張，所以任何從羅馬涅寄出的信，都會比以前更認真的攔截與檢查。

這次，馬基維利決定將所有長談內容，一字不漏的向上級報告，而不是只講重點。「這樣請位大人才方便下整體判斷。」他要讓上級彷彿置身於伊莫拉的觀見室，並且親耳聽到切薩雷的話，說維特羅佐與奧西尼家，是怎麼催促他違反舊約、執意進軍佛羅倫斯；而且切薩雷沒發現到，抱怨這群人反而讓他看起來很軟弱、很好操控。

有些佛羅倫斯高官十分昏庸，無法體會切薩雷的辯解透露出至少弱點，因此需要弗朗切斯科主教與其他審慎之人，幫助他們讀懂句子間傳達的訊息。他們假如「聽到」切薩雷無意間自曝其短，就一定能掌握到重點：切薩雷可能說謊，並樂於放任盟友進軍佛羅倫斯；要不然就是所言為真，也就是確實努力制止過他們，但這也代表他是一個無能的領袖。不管是哪種情況，他的解釋都無法讓人相信，他能確保佛羅倫斯的安全。

伊莫拉的街道並不平靜。馬基維利聽說切薩雷麾下有些部隊，已經威脅要發起叛變。他寫信給上級：「我們看到他的敵人全都武裝起來，準備要燃起大火。當地人都是徹底愛國的羅馬涅青年，他們受到很糟糕的對待，因為切薩雷總是愛自己的兵馬，更勝愛當地人。」切薩雷與他的顧問雖然虛張聲勢，卻明顯被逼到角落了。假如叛軍動作夠快，說不定還會入侵整個羅馬涅，粉碎博日亞父子的雄心抱負。所以，現在正是佛羅倫斯要求的大好時機。

但就算切薩雷本人很弱，他還是能依靠超強的朋友與親戚，替自己作戰。馬基維利首次親見後才過兩天，切薩雷就再度召見他，說路易十二已經答應出兵支援、攻打波隆那。「看吧，祕書先生！」他說：「您想想看，未來我打仗的時候，會有多少法軍支援我！請您告訴您的領主，我還不打算放棄這一切。假如他們能迅速表達理解之意，我就樂意與他們當朋友；假如不能，那我只好不理他們，到時候就算我快溺死了，也絕不考慮跟他們做朋友。」

接下來的幾天，切薩雷又收到更多好消息。他麾下兩名最優秀的西班牙籍隊長——雨果·德·卡多納（Hugo de Cardona）與米蓋爾·德·科瑞拉（Miguel de Correda）——（不顧切薩雷的撤退命令）拿下了幾座遭叛軍攻擊的城鎮。這完全又是切薩雷另一次好運，而非他審慎計畫的成果。十月十二日，馬基維利親見他的時候，他得意洋洋的問候馬基維利：「你看看，現在跟我作對的人有多倒楣！」

切薩雷顯然興奮過頭了，咯咯笑說維特羅佐染上熱病，帕歐羅·奧西尼（Paolo Orsini）得到壞血病，拼命抓自己身上的血流，而奧西尼家族已經在乞求教宗的原諒——看來切薩雷依舊吉星高照。根據馬基維利在伊莫拉的所見所聞，切薩雷的權力大半憑著僥倖和運氣，絕非有什麼遠大的計畫。沒錯，他確實持續獲得法軍的奧援，但他無法讓自己的將士聽令（雖然到目前為止他們都很忠心）；擁有攻占、威嚇城市的人馬及大炮，卻似乎缺乏贏得民心的政治技巧。這樣看來，他有能力在義大利或其他地方，建立一個持久的國家嗎？這端看他的品德而定。對馬基維利來說，每個政治家都得接受這個真正的考驗：好運能幫你攻城略地，品德能幫你保住地盤。

切薩雷的祕書阿加皮托（Agapito），就到處吹噓自己的主子有多好運。過去幾天切薩雷時來運轉後，阿加皮托跟馬基維利說：「公爵榮光加身，運勢極佳、百戰百勝。」他的言外之意是指，佛羅倫斯的領主或其他人夠聰明的話，絕對會想搭這臺順風車，分享命運女神福爾圖娜（Fortuna）恩賜的好運。

千萬別把自己的安全，託付給隨命運擺布的人——假如阿加皮托不曉得這個道理，那他又更加愚昧了。當大家說某人很幸運的時候，意思是有好事發生在他身上，但無關乎他的功績或計畫。命運女神非常隨興，有些人明明不該有此等好運或壞運，但就是光臨在他們頭上。

切薩雷在攻城略地時非常幸運，因為教宗借法王一個人情，所以他幾乎未用出任何力。如今，面臨背叛的盟友，運氣再度站在他這邊——他什麼都不用做，光靠法國部隊與梵蒂岡金庫內的錢，就能將他從叛軍的魔掌中救出。但路易國王可能會再度冷落他（之前國王的态度就已經陰晴不定了），而且教宗總有一天會過世。真要說的話，歷任教宗之死其實比一般人來得突然、神祕，而他們生前建立的霸業，根基都非常脆弱，只要風一吹就會連根拔起。

切薩雷的朝臣或許相當得意，因為主子如此幸運，再加上法國與羅馬的奧援，讓他的鬥魂持續熾熾、不斷發射炮彈。然而，當馬基維利聽到這位君王（或其他君王）受好運眷顧，或是在信件、詩句、書籍中提及他們時，「好運」或「幸運」兩字的警告意味，其實多過於讚美。假如某人非常幸運，你就不能相信他的成功，或把一切賭在他身上；倘若某人靠著努力、才智、謀略，以及對人性的深入理解，而獲得成功，你就能信任他——馬基維利認為這些特質，包含在「品德」的完整定義裡。

然而到目前為止，切薩雷幾乎沒展示出這些特質，因為他不需要它們。這就是仰賴運氣的壞處所在：你會太慣於藉他人之力取勝，因為這些人直接將兵器與金錢端到你面前，你就不必培養自立自強的特質；也因此，你絕對不會花費心血建立自己的軍力。當被籠絡後，假如有一天靠山不再給你靠，或是撒手人寰，那你之前所有的成功將會毀於一旦。

### 別追隨因機運而掌權的人

當馬基維利思索切薩雷的生涯時，腦海裡浮現了一連串的對比。地盤（或其他種類的權力）不是藉他人之力獲得，就是靠自己；不是靠運氣，就是靠品德。人們將上述那些值得讚揚的特質，稱之為「品德」；有些特質為普遍適用，有些則跟特定活動有關。例如「意氣風發」與「驍勇善戰」，對軍事指揮官而言相當重要，但羊毛商人就不需要這些特質。切薩雷無疑是意氣風發、驍勇善戰之人，但他必須盡快培養其他品德，才能保住自己的地盤。馬基維利在《君主論》中強調，一位貨真價實、品德高尚的領導人，都有項必備特質，那就是獨立自主。

品德高尚的政治家會透過紀律、遠見、組織技巧，以及展現出來的價值獲得成功；仰賴好運的人，則憑藉他人的武力與金錢。很明顯的，切薩雷是屬於後者──靠父親的機運與外國軍力的協助，獲得地盤。除此之外，優秀的領導人還有另一項特質，就是耐心。品德稱王者雖然權力得不易，但一旦掌權就能輕鬆守成，因為他們努力證明自己能治理國家，藉此贏得眾人支持。

至於只靠機運稱王者，一開始確實會輕鬆許多，掌權之路並沒有太多阻礙，可是當要鞏固權力時，所有困難都會一口氣冒出來，因為這些魯莽的野心家，鮮少花時間替自己的國家打好基礎。因此靠機運稱王的人，其政策都非常善變、甚至瘋狂，行為舉止就像沒人能阻擋他一樣，等到迎接首次失敗後，就會喪失所有信心，好像這是異常現象似的。

相比之下，品德高尚的君王就比前者更穩定、更值得信任。他們不會因為成功而自大，也不會因為失敗而氣餒；無論運氣變好、變壞，他們的心智都不會動搖，更無懼於命運女神的力量。

所幸，教宗的幸運之子還有機會培養高尚的品德，假如他不培養，那這對每日臣服的鬧劇會怎麼收尾，就很好預測了。因為單靠運氣的人，其殞落的速度就跟崛起的速度一樣快，而且還是從令人暈眩的高處落下，摔個粉身碎骨、血肉模糊。只要回顧一下古代歷史，便能略知一二：

亞歷山大與凱撒在世的時候，都過得很快樂，但其中一位抵達不了他垂涎的海灣，另一位慘遭屠殺，渾身是血的倒在敵人的陰影中。

> 亞歷山大大帝征服八名印度部落，卻以失敗告終，而他遲疑的表現就是波斯海；凱撒則是遭到元老院成員暗殺身亡。

十月十七日，也就是馬基維利與切薩雷初次會面的十天後，切薩雷再度召見馬基維利。「我的密探寄了一封信給我，說奧西尼家很樂意跟我重修舊好……」他擺出一臉嚴肅的表情，好像這個誘人提議令他很為難一樣：「但前提是，我得同意攻打威尼斯或是佛羅倫斯。祕書先生啊，您看看我人有多好，願意跟您分享這則消息！當然啦，我這麼做也是因為我相信您的領主，會很樂意當我的盟友！」

馬基維利的腦海裡，早就將切薩雷的施壓策略，依友善程度的高低排列好了。他心想，眼前三招還算滿友善的，所以暫時不用太擔心，便感謝切薩雷心胸如此寬大，願意分享這則訊息。隔天，他寫信給上級：「我會繼續盡力贏得公爵閣下的信任，這樣才能和他熟絡交談。」馬基維利在信中，通常會記下冗長的對話，但實際上公爵並沒有講任何重要的事。有時，切薩雷似乎想表現出隨和、老實的樣子，算是反駁「狡狐」的罵名。然而有時候，他單方面的喋喋不休又像個圈套，散發著醞熱氣息、纏著獵物打轉，直到他們難以下氣、無法回話、逃不出那既空洞又具有控制欲的聲音。

尤其，他最愛批評不久前還是朋友的敵人。「祕書先生，不是我在吹噓，那幫人還有什麼希望？拿我們跟他們比較，不就很清楚了嗎？至於他們一致盛讚的維特羅佐：……哈哈！」他大笑道：「那傢伙整天只會哀號病很痛苦，然後把事情推得一乾二淨！他其實只會兩件事：破壞毫無防備的鄉下地方，還有背叛別人！」

切薩雷一定多少知道，別人怎麼在背後說他；又或者，他沒有大家想像的這麼狡猾。馬基維利的兒子，而他自己也是個厲害的騙子，但從他的表現看來，遭人背叛好像真的嚇到了他、甚至傷到他一樣——他背後有這麼多勢力、權力在撐腰，怎麼還有人敢背叛？看過他的反應，就連馬基維利都差點要同情他了。有些人一開始贏得太輕鬆、受到太多幫助，之後遇到困難的話，他們往後的人生會變得多艱苦？

### 倚靠機運者，意圖必飄忽

雖然切薩雷一直在嘮叨他的敵人，還有他怎麼看穿他們的詭計，但馬基維利還是無法從他或其他人口中，得知他到底要議和，還是要攻打佛羅倫斯？宗主不斷寫信給馬基維利，催他多挖些有用的情報，馬基維利只好回答：「在這座宮廷內，我們絕對打聽不到真正的祕密，每件事的保密工作都做得滴水不漏。」

不過，他倒是聽過別人竊竊私語（雖然不是很確定），說切薩雷的西班牙部隊，在烏爾比諾附近吃了大敗仗。

有一天，切薩雷又召見了馬基維利，對他提出要求：「請您告訴貴國政府，派十支騎兵隊來協助我。然後告訴他們，我準備跟他們建立穩固的同盟關係，這樣他們就能取得我的支持與好運。」之後，馬基維利立刻把這個訊息傳達給上級：「我恐怕沒辦法再幫上什麼忙了，您最好派一位正式的大使前來取代我，而且其聲望與分量都必須比我還高，還要知道怎麼跟法國打好關係。現在我必須儘早返家，否則我的私生活就快要毀了。」

瑪莉塔的哥哥寄了一封信給比丘吉歐，問他那個「四處流浪」的妹夫，到底何時才要回家？「她說她不想自己寫信，還一副大驚小怪的受傷模樣，因為你答應她八天后就一定回家。所以，我要藉惡魔之名、拜託你快點回來，要不然她的子宮會很難過！」比丘吉歐拜託自己的妻子蕾珊娜，幫忙照顧獨守空閨的馬基維利太太；最近，瑪莉塔才剛生下第一個孩子，是個女兒，取名為普莉梅拉娜（Primorata）。

雖然瑪莉塔怒火中燒，卻還記得替老公買件新衣，而比丘吉歐會幫忙寄給馬基維利。至於安東尼奧先生，又再度在辦公室撒野了；同事都罵馬基維利，因為他長期不在辦公室，結果讓我們落到這樣的下場！阿戈斯蒂諾就責備他：「你看看你的靈魂，就這樣麼四處飄蕩，結果讓我們落到這樣的下場！整個總理署內，我只希望你做我的主管、跟我一起打拼，就算你有膽子做那些蛇蠍般的事，我也……」
