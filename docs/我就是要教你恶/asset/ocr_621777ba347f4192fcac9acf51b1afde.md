# 馬

基維利過世後，西元一五二七年開始的新共和國，只勉強撐了三年。之後，帝國與西班牙聯軍包圍佛羅倫斯，長達十個月（西元一五二九年十月至西元一五三〇年八月）之久，使這個政權畫下句點；而佛羅倫斯維持三百年以上的獨立共和制政府，也就此告終。

亞歷山卓此時二十三歲，被指派為新政府（支持帝國）的領袖；西元一五三二年，皇帝封他為佛羅倫斯公爵。舊共和國的存續期間為西元一四九四年至一五二二年，非常短命，而梅迪奇家族統治佛羅倫斯的時間，總共長達一百年之久；不過直到現在，這個家族才有了正式的貴族頭銜。雖然他們成為貴族，卻不再是自由的佛羅倫斯人，而是隸屬於哈布斯堡王朝。

梅迪奇家族統治的新時代，並没有比較平靜與守序。克勉教宗於西元一五三〇年之後，選了亞歷山卓擔任政府領袖，並讓伊波利托當樞機主教，因此亞歷山卓與堂弟伊波利托（前佛羅倫斯政府的_name義領袖_）的對立，又更加嚴重了。五年後，伊波利托去世，謠傳就是亞歷山卓謀殺他，因為亞歷山卓怕被堂弟揭露弊端。
