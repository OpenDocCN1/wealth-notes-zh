# 第十三章 人民願為自由而戰，政客只想保住財產

# 黨羽發動政變，梅迪奇成功復辟

八月三十一日早上，朱利亞諾·德·梅迪奇⁸進入佛羅倫斯。朱利亞諾現年三十三歲，比馬基維利年輕十歲，成年生涯都在羅馬、威尼斯與其他各個義大利宮廷中度過，他甚至還在巴爾達薩雷·卡斯蒂利奧內（Baldassare Castiglione）的《廷臣論》（Book of the Courtier）¹⁸亮相過，感覺很友善。現在，他剃掉拿坡里風格的鬍鬚，穿上平民穿的樸素衣裝，不過他的黨羽還是把他當君王一樣迎接。不久之後，他到哪裡都會有武裝保鑣隨行。

這座城市已經接近無政府狀態。西班牙部隊湧進佛羅倫斯，拿著從普拉托搶來的戰利品，想賣給富裕的佛羅倫斯人，而群眾無首的殘存政府，完全無力驅逐他們。根據蘭杜奇的日記記載，只要聽過普拉托大屠殺的民眾，都認為西班牙人比惡魔更殘忍，所以當地的男孩子就會挑釁這些西班牙兵，並偷走他們的馬；此外，阿諾河上還飄著幾具外國人的屍體，他們都是被年輕幫派所殺。

行政官害怕西班牙指揮官報復，於是將幾個惡棍送上絞架，反而導致局勢更加混亂。之後政府還出一位新的旗官，不再是終身職，任期十四個月。
