# 第九章 朕告了我的國，只算計、沒道義

結，而他們的旗官提議休戰，女性則大聲慘叫以表示抗議。
與此同時，佛羅倫斯的民眾湧進街道與廣場，高聲尖叫、相互擁抱。馬基維利因為身兼第二總理與十人戰爭官的祕書，所以參加了一連串決定未來市政發展的會議。佛羅倫斯現任旗官說道：「維特利隊長似乎已經替共和國收復比薩，所以我們該來想：身為勝者，我們能提出什麼條件？」

八月二十四日，彩繪雕像「因善魯內塔聖母」（Ora Pro Nobis Mater）被隊伍搬運至聖菲利斯教堂（Chiesa di San Felice）...幾百年來，佛羅倫斯都很崇敬這尊代表天主之母的雕像，並且在危機之際祈求它的避邪力量。而在出佛羅倫斯之後的路上，一枝橄欖枝剛好落在「聖母」斗篷的星星上——這是和平的微兆。隔天，馬洛咨總理提出一份關於當前情勢的報告：物資補給的狀況非常良好，比薩應該是癈中物了。

然而，四天後佛羅倫斯的軍隊長官，從比薩城外的軍營捎來警戒信。原來，整支步兵團因為某種致命的熱病而停擺，而且病情傳染得很快。某位生病的長官被送回家，政府派了兩位市民代表去接他的位置，結果他們全在當週死亡。九月四日，佛羅倫斯政府命令維特利撤營停戰。民眾聽到這個消息後氣炸了，政府則不懂：一切戰況看似都順著佛羅倫斯的意，怎麼會發生這種事？而且在軍隊染病之前，維特利的人馬為什麼沒有立即攻進比薩，並占領它？

替維特利辯護的人說，隊長按兵不動是合情合理。因為他的部隊缺乏砲彈，所以可能想等新一波的補給到來後再進攻，這樣就能減少傷亡並快速取勝。但沒想到熱病侵襲了整座軍營，維特利沒有足夠的健康士兵能夠調度，就連他自己都生病了。

不過，對於抱持高度盼望、卻在一夕之間夢碎的民眾來說，這個理由還不夠好。佛羅倫斯的長官
