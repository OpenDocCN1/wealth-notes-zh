# 第十二章  覬覦他人財物，將在不安中失去一切

己，城市就比較難以攻陷。然而，馬基維利現在並不想說太多，因為皮耶羅旗官不太可能說服他的貴族同事，要建立強大的護國軍隊，就必須讓貴族與勞動階級近乎平等；他若是真的這樣講，馬基維利的改革夢很快就會破滅了。

所以，馬基維利打算從小處著手，例如：「如果你確保人民能領到高薪（而且是準時給付），他們就值得你信賴。除此之外，還要讓這支新的民兵團成為正義的楷模，因為我們的城市現在非常缺乏正義——也就是一個人無論貧富、貴賤，都享有同樣的獎賞與懲罰。軍力與正義是所有國家的基石，應建立法律，明確規定何時、如何懲罰士兵或指揮官的不當行爲。另外，罰則要嚴格、公平的施工於所有將士（無論其官階或人脈），並告訴他們，這支新民兵團無法容許賄賂和賣人情。只要有這種正義，將士就比較能服從命令，也能讓整支軍隊服從；倘若沒有正義，就等於沒有軍力。」

馬基維利告訴皮耶羅旗官：「與此同時，我們也能向人民推展我們的計畫。假如民眾支持，貴族就無法扼殺它。」嘉年華的季節就快到了，馬基維利命令指揮官準備大型操練，要在佛羅倫斯民眾面前表演。他說：「給這群多疑的都市人看看，他們『粗俗』的托斯卡尼鄉親有什麼真材實料！我們要證明嚴格的紀律與正確的政策，可以將伐木工、養豬農變成一流戰將！」

二月十五日，四百位農民兵伴隨鼓聲，行軍至領主廣場，令群眾看得目瞪口呆。每位士兵都頭戴白帽、身穿白色背心與紅白相間的緊身褲，外頭再罩上鐵製胸甲。有人手持長矛，其他人則拿著火槍。他們的面孔有老有少、有胖有瘦、有白有紅，但全都很嚴肅。有些觀眾試圖挑釁他們，但他們的眼神完全沒有任何閃爍、惱怒與一絲偷悅；無論高舉武器、擺動身體還是踏步，全都整齊劃一。這種效果既美麗又令人迷惑，就像看到劣質材料製成的物品，透過藝術家之手重新雕塑，散發出隱藏的效果。
