# 我就是要教你惡

相比之下，品德高尚的君王就比比前者更穩定、更值得信任。他們不會因為成功而自大，也不會因為失敗而氣餒；無論運氣變好、變壞，他們的心智都不會動搖，更無懼於命運女神的力量。

所幸，教宗的幸運之子還有機會培養高尚的品德，假如他不培養，那這對每日臣女的鬧劇會怎麼收尾，就很好預測了。因為單靠運氣的人，其殞落的速度就跟崛起的速度一樣快，而且還是從令人暈眩的高處落下，摔個粉身碎骨、血肉模糊。只要回顧一下古代歷史，便能略知一二：

亞歷山大與凱撒在世的時候，都過得很快樂，但其中一位抵達不了他垂涎的海灣，另一位慘遭屠殺，渾身是血的倒在敵人的陰影中。
