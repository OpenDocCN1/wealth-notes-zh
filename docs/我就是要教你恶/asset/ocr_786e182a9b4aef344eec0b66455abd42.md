# 我就是要教你惡

# 羅

倫佐去世不久後，馬基維利從西元一五一二年盼到現在的機會，終於來了。這些年他試過各種方法，想跟梅迪奇家族談論政治，但所有提議都被拒絕、避開或「禮貌性的忽視」；不過至少這幾年來，他們對他的意見也漸漸沒那麼排斥了。

現在，良教宗指派他的堂弟——樞機主教朱利奧，領導佛羅倫斯政府。民眾厭惡羅倫佐的獨裁統治，其中有許多人還實踐托利煽動他的野心，所以教宗急於安撫他們。教宗希望朱利奧廣邀優秀人才（包括對梅迪奇政府抱持敵意者），與他們私下聊聊佛羅倫斯的未來。教宗與朱利奧曾要求這種人才提出具體的改革計畫，並承諾盡可能採納。受到推薦的對談人選當中，就包括馬基維利。

馬基維利立刻開始製作企劃書，而他的年輕好友普諾比（也是《論季維羅馬史》的獻書對象之一）也受邀（或是主動）草擬一份。普諾比跟馬基維利的意見不一定相同，所以馬基維利想藉著交流，測試自己的理念是否可行。於是他草草記下一些想法，然後發表給路易吉、普諾比與其他同圈子的好友，請他們評論一番。

他想知道，對於擁有特定歷史、偏見與焦慮的佛羅倫斯人來說，最適合什麼樣的制度？改革後的佛羅倫斯，貴族與平民的權力該如何分配？旗官該擁有什麼權力、任期應該多長？還有一個最棘手的问题：梅迪奇是否該重啟大會會，因為這才 是平民政府真正的象徵和運作方式？馬基維利懇求他的朋友：「告訴我，我的建議是否過於大膽？論調是否會惹怒梅迪奇陣營內的人？」
