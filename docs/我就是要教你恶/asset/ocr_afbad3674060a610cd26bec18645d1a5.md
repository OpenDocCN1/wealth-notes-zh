# 第十章 勸諫時，得把自身想法說成「消息來源透露」

教官凡尼，不斷懇求教宗這麼做。這位大使還保證，梅迪奇家族聯盟，會做出什麼事來？不過，這張「博日亞牌」對法國與佛羅倫斯都有用，可以警告他們，藉此讓他們彼此間的關係更緊密。因為只有恐懼，才能重新凝聚疏遠的同盟關係。「我聽完上述這些消息後，覺得班像那位『最神聖教宗陛下』的陰謀，於是，我決定找迪．安博思閣下談談。」

宮廷現在又往東轉，駐留在都爾（Tours）。

十一月二十一日，也就是馬基維利離開佛羅倫斯整整四個月後，再度拜會迪．安博思主教。此時，主教已經逐漸敞開心胸，面對這位來自佛羅倫斯的奇怪年輕人——他沒有名門子弟的貴氣，言詞卻十分大膽；他的自信來至於睿智的判斷，而非出身或官階。馬基維利說：「陛下要小心，別讓任何人毀了他的義大利好友。」於是，他跟主教達成默契，主教允許他提出建議，只要別害犯人就好。事實上，主教覺得他的想法還滿有趣的。而馬基維利認為，法王與佛羅倫斯人目前的一切作為，令他聯想到羅馬人或馬其頓人做過的事。

馬基維利建議（他忘了稱呼「陛下」，有點太直接了）：「我覺得法王最好學習以前的君主，了解如何在異邦建立勢力——削弱強權、安撫臣屬、留住盟友。」迪．安博思聽了很好奇，但還是裝出一臉沒聽懂的樣子。於是，馬基維利放慢語氣，改以主教平常的思考方式切入目前的話題：「最重要的是，法王應該要小心，別讓其他君主在義大利行使與他同等的權力。因為在義大利這塊土地上，足以和法國匹敵的勢力，並非佛羅倫斯（因為這座城一看就知道威脅不大），而是其他一直想支配整個義大利的強權。」
