# 第十二章 覬覦他人財物，將在不安中失去一切

由，而懷疑新事物，既然如此，就要給他們理由相信你。

馬基維利問新兵：「他們怎麼了？難道是怕沒時間工作？還是怕拿武器？」他們含糊回答：「有些人應該是不想放親友不顧吧！」接著，又有人講白：「他們大多是怕名字一交給你，就要申報財產，這樣可能會多繳稅！」馬基維利則安撫他們：「我們徵兵只看年齡，不問財產多寡！」就這樣，大家的疑慮一掃而空，又有更多人放心來報到。

馬基維利寫信給十人戰爭官：「多數人似乎都很渴望從軍，因為他們希望拿下期盼已久的勝利。」「他參加各地民兵團分部的就職典禮，結合了傳統宗教與民間的祈福，神職人員與非宗教的權威人士都有參加。除此之外，馬基維利還親自設計了典禮流程，並指示當地官員，每年度舉辦兩次。首先，該地區的所有人（不分男女老少）都要參與特別準備的神聖彌撒，接著由當地官員宣讀士兵的責任，以及逃避責任會受到的懲罰，並告誡他們要維持團結與忠誠。然後，士兵會一個接著一個，在衆人面前把手放到《聖經》上，宣誓遵守這些神聖的承諾。

然而，某些地區的徵兵工作又特別艱困，例如迪科馬諾區（Dicmano）就無福徵召，拒絕與鄰鎮居民一起受訓，因為他們自古以來就是死對頭，或者是某人的爺爺先冒犯對方，使得雙方爭執到現在——雖然已經忘記到底在爭什麼，但總之就是不可原諒。因此，馬基維利只好用盡他的遊說技巧，來平息這些反抗。他會見鎮上代表，耐心向對方解釋：只要服役情況良好，就能獲得額外的津貼與減稅，就連罰刑都能赦免；反之，堅持不接受徵召者，就必須繳納巨額罰款。
