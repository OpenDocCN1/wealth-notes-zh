# 第十一章 人說狐狸狡猾，因為牠識破人的陷阱欺詐

一樣婊你！比亞吉歐也為了這些事在生你的氣，不斷的唸你、罵你、詛咒你，但同時他也覺得少了你，所有事情都沒有意義了！’從這段話就可以看出，佛羅倫斯人不但擅長透過讀美來責備對方，還擅長藉由責備來給予讚美擁抱。

十月底，馬基維利得到可靠消息，說切薩雷跟他的盟友要復合了。馬基維利很怕他們和解，會對佛羅倫斯共和國造成致命打擊。

或許，切薩雷最後會禁不住奧西尼家的懇求，讓他們的親家——梅迪奇家族在佛羅倫斯復辟。之前教宗之子就暗示過，這是他們祕密計畫中的一環，因而增添了馬基維利的焦慮。然而與此同時，切薩雷卻又再三發誓：‘我絕不允許貴城受到損害，就連一根汗毛都不會動到！’

馬基維利聽到，越來越多民眾在討論這件事情，但他同時也聽到更多消息，說公爵的臣子私下都在批評群叛徒。因此，他在最新的信件上報告：‘他們嘴巴上說討論和平安約，實際上卻在準備戰爭。’他打探切薩雷身邊一位多嘴的保鑣，結果那位保鑣告訴他：‘就我所聽到的消息，公爵想報復那些危及他領地的人，所以和談並非真心。’

切薩雷只花了一點時間，就收復了烏爾比諾。但接下來，法國要他克制野心，他只好承諾停止征戰。馬基維利寫信給上級時，謹慎的表達樂觀之情：‘或許，公爵正在學習如何克制欲望，因為他知道命運女神不會讓他全贏。’自從十月以來，切薩雷宮廷所在的城鎮擠滿了士兵，民眾的話題都是法國部隊，以及教宗的銀行帳戶。可是現在有消息傳出，說切薩雷考慮建立一個新國家。切塞納城，
