# 第十七章 天下無道，我們能有的作為

西元一五二四年二月，他邀請重要人士參加一場奢侈的宴會，並在宴會上向這群客人提議，他們應該要求伊波利托·德·梅迪奇（七十三歲，教宗的堂弟朱利亞諾的私生子）有資格擔任所有的公職。因為只要他們提出這樣的正式請求，感覺就像民衆想擁戴一位梅迪奇君王；如此一來，伊波利托這種「公然藐視法律」的出身，就能夠「稍做合法一點」

維托利是新任教宗邀請的客人之一。以前，他都避免與梅迪奇家族有所衝突，現在他比較能適應權力帶來的現實，好幾年來他都再三告訴馬基維利：「我們夢想讓世界變得更有道理，但終究只是一個場合。」「可是在這次宴會上，他終於反抗了。現在，佛羅倫斯的失望情緒已經夠具有威脅性、中產階級與窮人越來越窮、富人也因為權利遭到剝奪而憤怒。

因此，維托利提醒克勉，偉大的羅倫佐死後，事態是怎麼發展的：民衆一開始很平靜，但他兒子皮耶羅所處的政府，盡是貪戀權力的腐敗人士，以及唯命是從的走狗，讓人民的不滿情緒大爆發。這兩件事情，只差在皮耶羅不像伊波利托年代這麼小，也不是私生子，而當時的教宗也沒有給他這麼大的權力與特權。之後，還發生薩佛納羅拉的預言、法軍來襲，以及梅迪奇家族的流亡。因此，教宗陛下真該避免歷史重演才對。

然而，克勉與他的親信還是贏得在場大多數人的支持，因此伊波利托成為實質的君王（只差沒有正式頭銜），由非佛羅倫斯出身的樞機主教──西爾維奧·帕塞里尼（Silvio Passerini）輔佐他統治佛羅倫斯，而帕塞里尼在西元一五二四年五月，由教宗任命為佛羅倫斯總督。
