平沒動半步。薩佛納羅拉的信徒大叫：「你們看！這就是上帝的徵兆，薩佛納羅拉修士真的是神聖先知啊！」但另一派人馬則反駁：「這個徵兆，代表他用了巫術或其他黑暗力量，阻止這場審判，因為他怕被揭穿是騙子！」最後，領主們起身走進領主宮，人潮也就散去。

日記作者蘭杜奇，一直到最後都死忠擁護著薩佛納羅拉，他當時也是廣場上滿心期待的觀眾之一。他記載：「道明會修士虎頭蛇尾的離場，使眾人騷動不已，他們對先知已經失去信心。」而薩佛納羅拉的敵人抓住這個機會，譭謗他並挑釁其追隨者，當修士走回修道院的途中，雖然有市政府跟私人的部隊在周圍保護，但他還是受到暴力對待。

在《君王論》中，馬基維利就藉此點出，任何靠預言來贏得支持者的人，會遭到什麼問題。就跟任何不靠官職與軍隊，就坐擁強權的人一樣，當民眾不再相信薩佛納羅拉，他就被自己創造的新秩序給毀了；既無法鞏固信徒，也無法說服不信者。幾天後，佛羅倫斯人才得知，法王查理八世於修士對決的當天駕崩。薩佛納羅拉修士之前宣稱，查理是上帝派來解放佛羅倫斯的人，但他卻沒預知到查理之死。

# 兩派人馬暴動衝突，拳頭決定法律「正義」

到了聖枝主日（Palm Sunday）⁴，也就是修士那場「無火審判」之後隔天，薩佛納羅拉的敵人闖進教堂，許多信徒試圖逃跑，卻都被打傷。不久之後，全城就進入武裝衝突的狀態。「環同志」率領一羣暴徒，前往聖馬爾谷修道院。途中，有越來越多男子與小孩加入他們，拿石頭丟那位「騙子修士」。
