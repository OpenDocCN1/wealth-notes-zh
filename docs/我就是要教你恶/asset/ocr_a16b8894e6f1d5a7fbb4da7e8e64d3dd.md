# 翻譯成拉丁文。

貝納多以及部分智者認為，最優秀的古代歷史學家與哲學家，反而比當代的作家更活躍、更具實用價值。他們之所以偉大，是因為他們擁有後輩無法比擬的清晰思路，能提出、探索那些持續存在的基础問題：該怎麼組織，才能達到最好的共享生活？該如何維持政治秩序穩定，同時確保人民的安全與需求？為什麼被領導人或平民，會同意那些使地方政治腐化的行動？平民該如何及早發覺腐敗的徵兆，並在「被毒殺」之前恢復正常狀態？

雖然這些問題都是出自古代的雅典與羅馬，但完全說中了當前佛羅倫斯人的焦慮，因為財富、血統與社會的極度冷酷無情，似乎比法律更具權威性。不過提出這些問題的作家，給的答案都不簡單。羅馬的李維與希臘的修昔底德（Thucydides）所著的史書，以及柏拉圖的哲學對話，都從許多角度來思考。根據他們的描寫，人類天性曾經是坦率且令人振奮的；他們表示，人類智慧提升許多的生活品質，然而粗心、贪婪和自我否定，卻又讓脆弱的人為秩序崩壞，傷到毫無防備的人們。

不過，這些古代作家並沒有自認為是專家，教導讀者誰對誰錯。他們筆下的歷史與對話，描繪出政治生活的戲劇面，沒有小心翼翼地說：「這做得真好！」「那真是場災難！」；反而字裡行間散發出睿智與真誠，充滿了機智的弦外之音。他們隱藏自己的觀點，或是只給一點暗示，藉此強迫讀者自己思考，從而對政治圈有更正確的判斷——尤其是君主統治下的民主制度，和從各個面向襲來的政治詛令。

馬基維利遲早會深深愛上這些寫作傳統，他非常推崇這些古人對於人類福祉，所投注的心力（而且跨越時空）；他們勇於遠離當時的派系之爭，從各種角度探討功過與失敗；渴望不僅是在生前留名
