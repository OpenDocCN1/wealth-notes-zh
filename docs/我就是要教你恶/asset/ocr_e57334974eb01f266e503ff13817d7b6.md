# 我就是要救你戀

維利說笑時會發出嬌媚的笑聲，只需要用白皙的手指撫觸馬基維利的衣袖，就能讓這個已經乾枯的老頭重燃情欲，但令他著迷的可不只有這些。其實，茒貝拉是一位天賦異稟的音樂家，歌聲宛如天籁，而且還會寫詩。她與自己的班子在馬基維利的戲劇換幕間獻唱；歌詞是馬基維利想著茒貝拉所寫，而曲子則由知名情歌作曲家 - 菲力普·維德洛特 (Philippe Vertelet) 操刀。

茒貝拉與馬基維利熟識之後，就向他傾訴，她夢想有人贊助她的音樂，這樣她就能以藝術家的身分獨立生活，而不必再用她不太熟悉的「藝術」來娛樂男人；馬基維利對此感同身受。因為在簽下《佛羅倫斯史》的合約前，他的作品賺不到半毛錢，十年來只靠家族的農場養家。於是他在答應茒貝拉，會將她的計畫推薦給佛羅倫斯最有利的金融界人士。而菲利波！與維托利交情甚篤，之前曾經在財務上幫助過馬基維利，這次他也答應與茒貝拉見面，但他只對她的作品恭維了幾句，並沒有真的贊助多少。

即便如此，茒貝拉還是願意讓馬基維利親近自己——這還真是奇蹟。十年前，馬基維利曾經跟維托利提過自己已不經意的幻想，當時「愛」等於「淫欲」，一切都只是遊戲，但如今「愛」的意義已遠比以前豐富。

「你會了解到，『愛』這個小賊是怎麼束縛住我的。這些束縛太過強烈，令我完全喪失重獲自由的渴望，也無法構思任何脫困的方法；它們在我心中纏繞、糾結，如果不照這樣過活，我恐怕會很痛苦。」「看來，他沒有因為年紀而變得節制。
