# 第十一章  人說狐狸狡猾，因為他識破人的陷阱欺詐

在這個時代與土地上，專制者會持續面臨到陰謀與叛亂，偏偏切薩雷的行為就像個專制者。他的顧問或許會建議，為了避免臣民疏遠，應嚴加管控奸臣的行為，以及決策時暗藏的风险，但他充耳不聞。除此之外，他不但沒有管控將士，反而還寵溺他們，隨便給士兵薪饷──就跟凱撒一樣（這位英雄也是切薩雷的名字由來）。

十二月二十日，一群法國軍官湧進切薩雷親見室前的等候室，而當時馬基維利也在宮廷內。他們用非常急促、大聲的音調喧鬧著，表情與手勢看起來相當憤怒。不久之後，他們離開了等候室。

馬基維利立刻拜訪一位較熟悉的法國聯絡人──迪．貝拉男爵（Dieu Bellaise）。男爵告訴他：「陛下已經命令，所有法國臣民與部隊離開此處。一看來有幾位法國軍官，遭受到切塞納周圍的鄉民突襲，所以認為這裡不再安全。其他法國軍官也告訴馬基維利：「鄉下地方對切薩雷公爵的敵意正在升溫中，他們受夠這麼多士兵了。」

切薩雷或許是一位速戰速決的征服者，但他再次證明自己不太懂政治手腕。首先，他最親密的盟友背叛他；再來，他的法國部隊（他得以盛氣凌人的主因）也棄他而去。他不斷強調自己的權力已經穩固，國家也打好基礎。然而，每次盟友替他打造美好的開始，他最後都一定會搞砸。看似無法領悟政治的第一守則：假如你沒給別人信任你的理由，他們就不會支持你；少了別人協助，你所有的堡壘和高貴頭銜，全將化為烏有。君王最該做的是得到人民的信任與支持，否則一旦身處逆境，就沒救了。
