# 我就是要教你惡

# 為

為了維護個人行為與正當的經濟交易，貝納多會據理力爭，好為兒子樹立一個榜樣。不過佛羅倫斯的領袖與其子嗣的行為準則，卻又是另一種截然不同的典型。

在晚年動筆的《佛羅倫斯史》（Florentine Histories）當中，馬基維利回憶起童年時的佛羅倫斯：「當時的佛羅倫斯青年，比平常更放縱，在服裝、宴會與其他炫耀行為上揮霍過度。年輕男子在娛樂與女人上，花費許多時間與金錢；他們會研究如何打扮得光鮮亮麗、談吐得聰明機智，因為只要擅長以伶牙俐齒嘲弄他人，就會有睿智的形象，並獲得較高的尊敬。『因此，每個人都追求這種風氣，而不願對公聚造成的後果。馬基維利聲稱：『而且這種風氣，又被米蘭公爵的弄臣給火上加油。』馬基維利上述提到的米蘭公爵與他的夫人，是佛羅倫斯新領結──二十二歲的羅倫·德·梅迪奇的客人。他們就像征服王國一般，帶著精心打扮的扈從橫掃了整座城市。他們作客的這段期間，麾下弄臣在街上大搖大擺的走，完全不尊重其他路人，也不讓路給老人家或女士──幾乎是把他們推開，卻不道歉。當謠言從梅迪奇宮（也就是公爵夫妻暫住的地方）傳開後，民眾的怒氣高漲，而且到了十分危險的地步。馬基維利回憶道：『當時發生了一件前所未見的事情：教廷嚴令四句禱詞（Lore，又稱為「大齋期」）不可食肉，但公爵的臣子卻完全不尊重教廷與上帝，全部都吃肉。』沒有人敢指控羅倫侍佐，以及涉及這次毀潰的家族，而且羅倫侍佐也沒有阻止這件事。
