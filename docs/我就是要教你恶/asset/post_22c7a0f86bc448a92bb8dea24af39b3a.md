一樣婊你！比亞吉歐也為了這些事在生你的氣，不斷的唸你、罵你、詛咒你，但同時他也覺得少了你，所有事情都沒有意義了！’從這段話就可以看出，佛羅倫斯人不但擅長透過讀美來責備對方，還擅長藉由責備來給予讚美擁抱。

十月底，馬基維利得到可靠消息，說切薩雷跟他的盟友要復合了。馬基維利很怕他們和解，會對佛羅倫斯共和國造成致命打擊。

或許，切薩雷最後會禁不住奧西尼家的懇求，讓他們的親家——梅迪奇家族在佛羅倫斯復辟。之前教宗之子就暗示過，這是他們祕密計畫中的一環，因而增添了馬基維利的焦慮。然而與此同時，切薩雷卻又再三發誓：‘我絕不允許貴城受到損害，就連一根汗毛都不會動到！’

馬基維利聽到，越來越多民眾在討論這件事情，但他同時也聽到更多消息，說公爵的臣子私下都在批評群叛徒。因此，他在最新的信件上報告：‘他們嘴巴上說討論和平安約，實際上卻在準備戰爭。’他打探切薩雷身邊一位多嘴的保鑣，結果那位保鑣告訴他：‘就我所聽到的消息，公爵想報復那些危及他領地的人，所以和談並非真心。’

切薩雷只花了一點時間，就收復了烏爾比諾。但接下來，法國要他克制野心，他只好承諾停止征戰。馬基維利寫信給上級時，謹慎的表達樂觀之情：‘或許，公爵正在學習如何克制欲望，因為他知道命運女神不會讓他全贏。’自從十月以來，切薩雷宮廷所在的城鎮擠滿了士兵，民眾的話題都是法國部隊，以及教宗的銀行帳戶。可是現在有消息傳出，說切薩雷考慮建立一個新國家。切塞納城，[footnote: 3] 位於羅馬涅的城市。

# 法律之前，君王不該害怕「殘暴」的臭名

設立了一個法庭，負責管轄切薩雷在羅馬涅的新領地，而這個計畫是由安東尼奧·德爾·蒙特閣下（Antonio del Monte）主導——馬基維利向領主保證，這位先生的學識與品德都勝過切薩雷。

在《君王論》中（此書為馬基維利出訪切薩雷的十年後寫成），馬基維利教導君王該怎麼辦，才能保住剛獲得的地盤。他在想出那些著名的格言時，並不只有想到切薩雷這位君王。但對馬基維利來說，切薩雷是個很棒的個案教材：剛崛起的君王因為缺乏根基與分枝，所以國家一定相當脆弱，除非他很快就領悟到，建立穩定國家需要先打下重要的基礎，例如完善的法律與軍力，才能準備好命運的降臨。

然而到目前為止，切薩雷只在乎軍力，而且他的軍力既不完善，也並非為他所有。不過現在，他至少在自己的都城內，設了一個完備的法庭，打算把法庭的領導者定位成教宗的使者，並且原諒烏爾比諾與其他反叛城市的居民。當君王面對抱有敵意的人民時，是無法全身而退的，因為對方人多勢眾。不過，目前至少可以確定：切薩雷在當地民眾心中，地位並不穩固。當然，有些人厭惡切薩雷推翻的舊統治者，所以這些人在短期內，會將切薩雷捧成解放者。但假如他沒有再進一步改善人民的生活，很快就會失去民心。

而現在，他指派一位最能幹的西班牙籍副官——拉米洛·德·洛可（Ramiro de Lorca），作為羅馬涅的總管。拉米洛通曉軍事防禦，而且對怠惰者與背叛者不留情面，因此在部隊具有極高聲望。

# 第十一章 人說狐貍狡猾，因為牠識破人的陷阱欺詐

說誰能讓陰謀者不敢亂來，還能讓羅馬涅的富裕城市繳稅給羅馬，那就是拉米洛了。馬基維利認為，君王不該害怕染上「殘暴」的臭名——假如懲罰逃稅與犯法的人也算殘暴的話。像這種愛發牢騷、說君王殘暴的民眾，反而偏愛過於軟弱與腐敗的君王，因為他們不會強制懲罰違法者（包括其親友在內）；因此，沒有時間聽這些民眾抱怨的君王，才是馬基維利心目中的英明領導者。他心想，切薩雷受到幾個比自己年長、睿智的顧問指導，說不定就能從他們身上學到幾分道理。

《君王論》中提及，審慎的君王深知如何赢取臣民與盟友的信任。若要贏得信任，其行為就要始終如一，避免善變、虛偽等臭名。馬基維利懷疑切薩雷這般性情，能否領略此道理——鮮少有人接受的善意後還背叛你，因為那實在太卑鄙了。不過，從他的行爲可以得知，老是靠同一招贏得輝煌勝利的人，要他改方法可說是難如登天。

# 第十一章 人說狐狸狡猾，因為他識破人的陷阱欺詐

在這個時代與土地上，專制者會持續面臨到陰謀與叛亂，偏偏切薩雷的行為就像個專制者。他的顧問或許會建議，為了避免臣民疏遠，應嚴加管控奸臣的行為，以及決策時暗藏的风险，但他充耳不聞。除此之外，他不但沒有管控將士，反而還寵溺他們，隨便給士兵薪饷──就跟凱撒一樣（這位英雄也是切薩雷的名字由來）。

十二月二十日，一群法國軍官湧進切薩雷親見室前的等候室，而當時馬基維利也在宮廷內。他們用非常急促、大聲的音調喧鬧著，表情與手勢看起來相當憤怒。不久之後，他們離開了等候室。

馬基維利立刻拜訪一位較熟悉的法國聯絡人──迪．貝拉男爵（Dieu Bellaise）。男爵告訴他：「陛下已經命令，所有法國臣民與部隊離開此處。一看來有幾位法國軍官，遭受到切塞納周圍的鄉民突襲，所以認為這裡不再安全。其他法國軍官也告訴馬基維利：「鄉下地方對切薩雷公爵的敵意正在升溫中，他們受夠這麼多士兵了。」

切薩雷或許是一位速戰速決的征服者，但他再次證明自己不太懂政治手腕。首先，他最親密的盟友背叛他；再來，他的法國部隊（他得以盛氣凌人的主因）也棄他而去。他不斷強調自己的權力已經穩固，國家也打好基礎。然而，每次盟友替他打造美好的開始，他最後都一定會搞砸。看似無法領悟政治的第一守則：假如你沒給別人信任你的理由，他們就不會支持你；少了別人協助，你所有的堡壘和高貴頭銜，全將化為烏有。君王最該做的是得到人民的信任與支持，否則一旦身處逆境，就沒救了。

在切薩雷的短暫統治間，羅馬湖人遭到嚴酷的對待，因此希望獲得補償，但從沒想到補償方式是這樣。這位君王能憑心情，隨意成就或毀掉一個人；能滿足人民需求，卻同時恐嚇他們。這次廣場上戲劇性十足的舉措，可能是稀世政治天才的妙計，也可能是身陷麻煩的新君王，在絕望之下做出的行為——這是馬基維利日後在《君王論》中的描述，藉以凸顯其中的兩面性，讓讀者自行判斷。

而現在，他則是向領主報告這個看法，讓他們自行判斷：他到底是吹捧過頭？還是在表達懷疑？切薩雷公爵的運氣、靈魂與超乎常人的自信，都堪稱前所未聞，任何想要的東西他都可以弄到手。此外，他依舊保持著神祕感、讓人猜不透他的下一步。他的祕書一直告訴馬基維利（而且口氣有點失望），他每次都不先提計畫，直到要執行時才告訴他們。因此，若我提供的資訊無法令諸位大人滿意，還請您見諒，切莫責怪。因為在大部分的情況下，連我自己都不滿意。」馬基維利寫道。

在德國與外交上，切薩雷雖然稍微展現了謀略，但一個月後就全忘光了。隔天，也就是一月一日，馬基維利聽說，維特羅佐與費莫昨晚就被吊死了。奧西尼家的帕歐羅與格拉維納暫且保住一命，可是，當歷山教宗在羅馬逮捕了枢機主教——吉安巴蒂斯塔·奧西尼（Giambattista Orsini）之後，兩人還是慘遭毒手。至於吉安巴蒂斯塔，則於二月二十二日死於聖天使城堡[footnote: 8]，可能為切薩雷或他父親下令毒殺。

現在這位「新凱撒」，把軍隊轉向佩魯賈與西恩納——這兩座城市分別由巴格里安尼與佩楚奇統治，他們是切薩雷僅存的前叛變盟友。馬基維利跟著軍隊一起走，一路上發現切薩雷軍隊的狀況很糟：他們睡覺時，如果有塊薄布可以墊在地上，就該偷笑了。此外，由於大雪紛飛、在鄉下被攔路搶劫好幾次，害得信差都不敢送信。

一月的第二週，切薩雷召見了馬基維利幾次，請他說服佛羅倫斯領主協助攻打西恩納，把佩楚奇趕出去；他還特別強調，這傢伙跟這座城都是佛羅倫斯的強敵。「我想你家領主，應該很樂意護我這個好友——羅馬涅的公爵，來統治西恩納吧？」接著，他用同樣的語氣補充：「如果某人身本身就是個背信忘義之徒，那就不必對他誠實了。 」

# 我就是要教你忍

馬基維利聽完後，向上級報告：「他的語氣非常強烈。假如他說的是實話，那我們就能暫時安心，但如果是在說謊，那就更可怕了。」「西恩納位在托斯卡尼、於佛羅倫斯南方約七十二公里處，而切薩雷羅馬涅的領地，則在西恩納、佛羅倫斯的北方。換句話說，佛羅倫斯夾在切薩雷與佩嘉奇中間，實在有夠驚人。馬基維利寫道：「根據我的推斷，假如公開攻下西恩納，就會認為等待已久的機會終於到來——那就是攻打佛羅倫斯。」

幾週之後，謠言就傳遍了羅馬與佛羅倫斯，說切薩雷的軍隊已經占領丘西（Chiusi）、皮恩扎與其他西恩納的領地。聽說軍隊抵達某座城鎮時，發現只剩下兩位老翁跟一羣老婦人，其他人全都逃光了。於是士兵綁住老婦人的手，還在她們腳下點火，逼她們說出錢財的藏匿處；結果她們拒絕，最後被活活燒死。接著，士兵洗劫房屋、拆掉屋頂和樑柱、打破門窗，還把酒桶打開到處潑灑，然後點火燒光一切。

一月底，馬基維利的請求終於被聽見了：領主派了一位正式大使來宮廷，他可以回家了。到了春天，佛羅倫斯再度活在恐懼中。沒錯，維特羅佐已死，法王也不再支持切薩雷的霸業，但博日亞父子仍然在西班牙招兵買馬，因為西班牙國王看到法王在義大利占盡便宜，非常不想輸給他。與此同時，佛羅倫斯的市民代表聽到消息後，督促政府該為即將發生的戰事做準備。

有些市民很樂觀，堅持教宗已經承諾放過此城，其他人則反駁：只要跟歷山教宗比，鬍子看起來都變誠實了。而終身旗官皮耶羅，則堅定的要大家冷靜：「我們的騎兵與步兵都很精壯，人民的士氣也因此提高，所以要更努力維持住士氣。」
