# 推薦序二

# 書看完後別放在書架顯眼處，而是藏在心中

要成為一國之君、擔任位高權重之臣，或是當個企業經理人及決策者，義大利軍師馬基維利的
《君王論》，應列為必讀著作。如果馬氏仍安在，他應該如厚黑教主李宗吾般，建議讀者把這
本書擺在不顯眼之處，否則別人會恐懼你正如法炮製的對付他。

馬基維利並非奉功利主義為圭臬，而是由於他曾目睹不諳統御之道的君主，下場多半悽慘無比。
人們雖口口聲聲希望見到仁政，但他們多半不了解，若一廂情願當個爛好君主，後來恐淪為亡國奴。

當時義大利強國間的合縱連橫變化不斷，僱兵軍團經常在一夕之間轉換陣營，地方政府也常在數
週間建立或垮臺。眼見衆多分分合合，馬氏得到一個結論——「所有具備武力的先知皆獲勝利，缺乏
武力則遭慘敗。」(All armed prophets have conquered and unarmed ones failed.)
