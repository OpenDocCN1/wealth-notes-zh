# 我就是要救你惡

號 (Heparo)。戰爭才打兩個月，就有人因它而死。到了九月底，史卡拉（Scala）醫院住滿了瘟疫患者。這種病迅速傳遍全城，也傳進軍營裡，沒人知道它發生的原因，以及治療方法。民間認為這跟日蝕或月蝕有關，而部分有錢人堅信，瘟疫是透過窮人飢餓、汗穢的舉止傳染的。所以，他們很希望上帝在懲罰窮人時，能憐憫誠實、勤奮的中產階級。

義大利有許多了解其他疾病的醫生，店裡也有琳瑯滿目的藥，其中某些藥如同萬靈丹。但瘟疫就像在嘲弄他們的科學知識一般——古代的藥和現代的藥都不管用。目前，只有兩件事很清楚：它容易傳染，更容易致命。十四世紀時，瘟疫害死了佛羅倫斯三分之二以上的人口。當時已知最有效的疗法是隔離，只要某人疑似染上瘟疫，醫生與政府機關就會建議他們自行隔離，讓越多人遠離患者家越好，病患也盡量別跟他人接觸、別在他人張開嘴巴時呼吸等，以免傳染給別人。

這對有錢人來說比較簡單，因為他們的房子比較大，或者有好多幾棟。而患病的窮人都擠在狹窄的住所，就比較難隔離。有些人還能蹦蹦的去走佛羅倫斯的醫院，其他人（有些是小孩）則因家庭過度擁擠而被趕出去，最後橫死街頭。

在溫暖的夏季，貝納多會花更多時間在城外的別墅，跟佃農商議事情，和他們一起去鎮上的市場買賣食物、木材與小豬。四月二十七日星期一，也就是聖母百花聖殿謀殺案的隔天，貝納多在記事本很平淡的記下一些事：他的佃農賣了兩隻公牛給鄰鎮的人，但其中一隻又老又疲憊；日子還是一樣在過，價格與商品品質總有新的爭議，尚待解決；農夫與地主還是可以往返於城鄉之間。
