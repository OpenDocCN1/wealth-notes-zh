# 第九章 誤害了我的國，只算計、沒道義

就是文明之死，也能解釋像羅馬如此偉大的城市，為何最終還是會潰落。

無論佛羅倫斯的人民做了什麼（或沒做什麼）來阻止這種腐敗，明星隊長維特利之死，又替這個草創共和國不光彩的歷史，添加了一個汗點——而且它無法被遺忘与原諒。佛羅倫斯本來就有一群宿敵，正拼命利用醜聞來對付她，如今她又多了一個致命的新敵人：維特羅佐。他誓言用弟弟與自己的精良部隊，傷害佛羅倫斯並幫助它的敵人。與此同時，梅迪奇家族和他們在威尼斯、羅馬的同黨，以及教宗的兒子切薩雷，聽到消息後全都摩拳擦掌、喜不自勝。

+   11 羅馬的貴族和平民在歷經長期鬥爭後，協議組成一個十人委員會，進行立法並掌握最高權力。而時任執政官的克勞狄也成為該機構的領導者，他同意讓平民出身的人也有機會擔當公職。但是，隨著時間推移，該委員會變得越來越專制。歷史學家猜測，可能正是克勞狄對權力的欲望，導致該委員會在公元前四四九年垮臺。
