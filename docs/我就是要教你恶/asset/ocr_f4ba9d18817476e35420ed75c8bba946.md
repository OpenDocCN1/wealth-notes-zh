# 第十六章 想計論時事？先評議歷史

其他幾位歐里切拉利園的年輕人，包括巴蒂斯塔與路易吉，也都是他的同夥。他們三位成功逃出城外，但其他人就沒這麼幸運了：路易吉的某位堂兄弟被逮捕入獄，而他們的朋友傑考波·迪亞切托（Jacopo Diace）也被逮捕，並供出了陰謀者的意圖。最後，兩人都被判死刑，並於六月七日遭斬首。政府命令贊諾比與路易吉必須在三日內向行政官報到，否則將會視為叛徒。假如他們不從，就會被判煽動叛亂罪，以及蓄意殺人未遂，只要任何人出錢、或用其他方法幫助他們，皆必須受罰。剛好就在此時（西元一五二二年六月初），托圖在病床上逝世。他是馬基維利摯愛的弟弟、這幾年來僅存的手足，支撐他度過許多難關，結果竟然比他早走；而現在，陪他消磨下午時光的好友，不是失去性命就是身陷險境──以上總結加起來，讓馬基維利痛徹心扉，遠勝過輩子所承受的所有悲傷。幸好，他雖然跟這群好友走得很近、以前也跟弗朗切斯科主教交情深厚，但這次他沒有涉險或遭到逮捕。四年後，其中一位共犯──尼可洛·馬特利（Niccolò Martelli）證實，贊諾比曾經想邀請馬基維利加入他們。

不過，最後他被朋友勸阻，畢竟馬基維利與其他人不不同的是，他會引起太多的懷疑，因為大家都知道他「不是梅迪奇彆門的朋友」。雖然，馬基維利完全不知道他們的計畫，但幾位參加花園討論的史書作者，都說馬基維利的理念，對陰謀者造成重大的影響。因為他試圖讓年輕人看見共和國的優點，並謹慎的暗示所有王國的缺點。那麼，他是否助長年輕人心中陰謀的念頭？

的確，他花了很多心力談論陰謀，而且陰謀也是《君王論》與《論李維羅馬史》中，占最多篇幅的。

> 紀念在彌撒中舉行聖體聖事【聖體禮】，將耶穌的聖體與聖血奉獻出去這件事。
