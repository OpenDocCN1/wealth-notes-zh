# 第十七章 天下無道，我們能有的作為

家族目前在佛羅倫斯處於弱勢，而且，法兰西王國索瓦與哈布斯堡王朝（Habsburg）崛起到法國北部，當時領土涵蓋今荷蘭、比利時、西班牙、奧地利，等於包住法國）的皇帝——查理五世形同水火，可能會在義大利掀起風暴。所以馬基維利力勸他，唯有受過精實訓練的部隊，才能保障佛羅倫斯的利益，而且這座城的利益也與教宗自己的利益密不可分。

克勉回答：「如果要成立民兵國，我們或許得先從佛羅倫斯以外的地方開始。」他無須多言，馬基維利就心裡有數了：佛羅倫斯市民正處於不滿的狀態，用他們組建民兵，對梅迪奇政府來說太危險了。但他們倒願意在羅馬渾水摸魚，因為這個地區特別容易披異邦入侵。圭恰迪尼目前是該區總督，最近克勉還指派他擔任教宗軍隊的副官。於是，教宗建議馬基維利：「你去跟他（圭恰迪尼）商量一下，再回來跟我談吧！」

七月，馬基維利前往羅馬涅，試圖說服圭恰迪尼支持他的計畫。他們倆先吃喝喝、召妓娛樂一晝之後，才開始談論芭貝拉，以及佛羅倫斯市民的不滿。現在，舊有的法律都被藐視，議會也不再召開，外國大使只跟伊波利托、以及梅迪奇宮內的樞機主教談事情，而且這群主教課稅都隨自己高興。然後克勉的外交政策，又讓事態更加惡化（而且是超級惡化）。

該年稍早，神聖羅馬帝國的查理五世從法國手中奪走米蘭，而現在他們掌控了米蘭與南方的拿坡里。法兰王法蘭索瓦向教宗施壓，請他加入「反哈布斯堡皇帝聯盟」，成員有英格蘭、威尼斯與米蘭公爵。然而，教宗非但沒有加入，還在西元一五二五年四月一日，與查理麾下的總督簽訂條約；這個條約等於讓查理皇帝成為托斯卡尼的主子，同時也代表梅迪奇政府與法國變成敵對關係——然而，法國以前都是這座城的盟友。
