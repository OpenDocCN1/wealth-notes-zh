# 我就是要教你惡

政敵（不管對梅西奇復辟的看法如何）都不禁有點擔心，旗官的政權會被暗中推翻。就在比薩之戰即將結束之際，馬基維利與皮耶羅旗官會面時，發現他莫名的樂觀；這位旗官承認：「我知道我沒處理好這件事，但假如我們在此案爆發之後，就立刻通過更嚴格的法律，那麼我的政敵鐵定會拿這點清擊我。從今以後，他們會稱呼我為暴君，並在我死後廢除終身旗官這個職位。」

馬基維利領悟到，事到如今再爭辯也太遲了，因為傷害已經造成，而且旗官也不會改變他的做法；他認為只要大家熟悉他，就絕不會懷疑他有暴君般的野心和自信只要憑著時間、善良與機運，就能消除嫉妒，而不造成任何醜聞、暴力與騷亂。馬基維利日後寫道：「可是他不知道，人不能等待時間證明，光只有善良是不夠的，機運有好有壞，惡意也永遠無法平息。」某一天（日期不詳，或許是皮耶羅旗官還在世的時候）馬基維利寫了一篇諷諧短詩，語調雖然深情，卻又帶點惱怒：

皮耶羅·索德里尼死去的那一夜，他的鬼魂來到地獄之口。

普路托大吼：笨鬼，你何必下地獄？跟其他嬰靈一起上去雲端（Lindo）！¹

16 雲端是地獄的邊緣。安置耶蘇基督出生前逝去的好人，耶穌基督出生後從未接觸福音的遊者，以及夭折的嬰兒（嬰兒不會犯罪，但還是有人類的原罪）；這些靈魂雖然不能上天堂，但並非邪惡，所以也不會受到懲罰。而普路托則是羅馬神話中的冥王。詳見第八章。
