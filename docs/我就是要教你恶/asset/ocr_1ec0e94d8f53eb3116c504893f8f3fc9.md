# 我就是要教你忍

元一四七八年四月二十六日，接近正午時分，佛羅倫斯最大的教堂──聖母百花聖殿（Cattedrale di Santa Maria del Fiore）正在舉行大彌撒（Olla Mass）。來自各個階層的外國訪客與當地人，約一萬人左右，全聚在雄偉的圓頂拱門之下。羅倫佐走進教堂，步向祭壇附近的榮譽寶座，後頭跟著他的弟弟──十五歲的朱利亞諾。朱利亞諾頗受年輕男女愛戴，相形之下，他哥哥越來越高。大家當然很歡迎這種「平衡」，長者都稱他為「金童」。

他已經與美麗的菲歐麗塔．格里尼（Fioretta Giorgi）訂婚，而菲歐麗塔已經懷有八個月的身孕，肚裡的孩子就是日後的樞機主教─朱利奧．德．梅迪奇，馬基維利會在未來與他交手好幾次。眾人的目光本來望向祭壇上唱詩的神父，現在則直盯著本城第一家庭的孩子不放。朱利亞諾旁邊站著兩位穿著體面、年紀與他相仿的青年，並時不時在他旁邊親暱的推擠、打鬧，他們是朱利亞諾的好朋友─貝納多．班迪尼（Bernardo Bandini）與弗朗切斯科．帕普（Francesco Pazzi）。

數年之後，馬基維利回顧上述的這些時刻，他覺得最令人不安、且極為古怪的，就是緊接著發生了又快又狠的刺殺事件，而事發之前，凶手竟然還擺出一副彬彬有禮的虛偽模樣。

當時，弗朗切斯科與貝納多帶領受害者走向謀殺現場，他們從梅迪奇宮官接走朱利亞諾，在前往教堂的路上與他暢談詩文與藝術，將一切陰謀都隱藏在虛偽的友誼之下。他們故作親暱的撫摸著朱利亞諾，實際上是想摸摸看他的披風下是否有武器。
