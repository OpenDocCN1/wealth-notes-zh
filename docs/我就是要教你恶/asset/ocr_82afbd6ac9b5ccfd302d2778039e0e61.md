# 我就是要教你惡

# 脣亡齒寒卻不能選邊站

馬基維利聽完後愣了一下，才恍然大悟背後大有文章——她最初要求重簽合約、嚴格的軍事訓練、街上的刀光劍影、朝廷鬼祟的眼神與緊張的聲調……這些所代表的涵義。

雖然，她一直把自己的榮譽掛在嘴邊，但她其實不怎麼在乎，更不在乎誰（佛羅倫斯跟米蘭）開給奧塔維亞諾的價碼比較高。她只想保住地盤，因為她害怕自己快保不住了。而且，威脅還不是來自法國，因為路易國王想要的是米蘭，不是弗利或伊莫拉這種小城邦。

她害怕的人叫做瓦倫提諾（Valentino）公曆。沒有人將這名字大聲說給馬基維利聽，不過當他站在人群中欣賞部隊時，鼓聲之下一直有人在咕嚕著──他是歷山教宗的私生子。雖然一切都尚未確定，不過羅馬一直傳來消息，說教宗為了教廷的利益，打算發動一場新的聖戰；不過，歷山六世並不打算派十字軍去耶路撒冷，而是想把兒子切薩雷·博尼亞（瓦倫提諾公爵）送到羅馬涅北部幾天，收復當初反叛教宗的城市。

全基督教世界都聽過切薩雷的大名。他爸爸讓他在十八歲就當上樞機主教，就跟喬凡尼·德·梅迪奇被提拔為樞機主教一樣，而且切薩雷還剛好跟喬凡尼同年。幾年後，教宗的另一個兒子胡安（Juan）慘遭謀殺，雖然大家都懷疑是他弟弟切薩雷所為，但沒有人正式指控過他。
