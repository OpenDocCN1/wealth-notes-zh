# 西

元一五二五年一月，群衆聚集在佛羅倫斯某間別墅的外面。屋主是出身寒微的富人—傑考波·菲爾康尼提（Jacopo Falconetti），朋友稱他為「製磚者」（Il Fornasago）；他舉辦宴會時準備的菜餚，可說是托斯卡尼數一數二的。幾年前他冒犯了權貴，被逐出城外。但現在，菲爾康尼提已經結束流放，為了慶祝重獲自由，他想在佛羅倫斯辦一場十幾年來、也是共和國成立以來最棒的派對。既要吸引各階層的客人、又要炒熱氣氛，那麼這個派對的主秀，最好主打他好友的喜劇新作——而這名好友正是馬基維利，《曼陀羅》的作者。

馬基維利現在已經五十六歲，難以相信自己如此走運。他這輩子從來沒受過這麼多讚嘆與關注；西元一五〇九年，他在民兵與外交方面貢獻許多心力、替佛羅倫斯收复比薩，但也没有像現在這麼火紅。菲爾康尼提不惜砸下重金，讓這部新劇本成為史上最傑出的大戲；他還請工人把花園鋪平、當作舞臺，還請來高人氣的雕刻家兼畫家—巴斯蒂安諾．達．聖加洛（Bastiano da Sangallo），因為故作莊重的樣子，也被人戲稱為「亞里斯多德」，設計舞臺布景。

菲爾康尼提寄出上百封邀請函給佛羅倫斯人，而且不分貴賤，從平民到權貴都有受邀，當然也少不了幾位梅迪奇家族的成員。某位朋友告訴馬基維利：「你這齣喜劇已經聲名大噪，不僅紅遍全托斯卡尼，還一路紅到倫巴底去了！」他還說，每個人都耳聞馬基維利與他的劇本，將在這場聚會上市為萬眾矚目的焦點，而且別墅主人為了上演這部戲，甘願動用所有財富、房屋與土地。「這種待遇通常只有君王才有！」
