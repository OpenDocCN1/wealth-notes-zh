# 我就是要教你懲

這本小冊子充滿了他對偉大領袖的盛讚（不管他們野心多高、成就多大、多狡猾、多殘酷），令人驚奇……甚至是驚嚇。不過，當你讀得更仔細點就會發現，這些讚美都伴隨著使其「打折」的隱藏警告。

就以現代君主的典範——切薩雷來說好了，馬基維利在書中把他捧得比誰都高：「我很難責怪他。因為他為自己的權力打下這麼好的基礎（雖然難免有些背叛與謀殺之事），卻被強大的厄運給擊垮。唉，可憐的切薩雷！這就是殘酷的命運女神對於世事的影響力，竟然連最偉大的君主都難以倖免。」

這本書花了很多篇幅談論切薩雷的生涯，卻滿是使好評價打折的影射。或許馬基維利不會直接責怪他，但會把他當成「次等君王中的最高等」；所謂「次等君王」就是依靠靠機運（跟其他人借錢、借軍隊、背後有家族撐腰），而非自己的武力與品德。這類君王的權力竄升得很快，卻也垮臺得很快。馬基維利說，沒錯，切薩雷之所以會失敗，「只不過……是因為他父親驟逝，這是他的第一次厄運，之後又遭遇第二次厄運，也就是挺錯人當教宗。

但你要留意到諷刺之處：儘管他為了自立自強而欺騙、謀殺與實行其他使前途看好的舉措，其失敗還是全靠在靠教宗（也就是靠他人的武力與機運）而定！所以，馬基維利詳細描述切薩雷的生涯，絕對不是什麼勵志的成功故事。在這段故事中，切薩雷機關算盡，只為了守住爸爸送給他的地盤，而且總是用金錢與「其他人的武力」（一開始用爸爸的兵，後來則跟法王、西班牙借兵）來辦事，但這一切都無法為他帶來保障。
