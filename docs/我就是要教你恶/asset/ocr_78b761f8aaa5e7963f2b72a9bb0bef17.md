# 馬基維利的童年時期，貝納多把大部分時間花在兩個地方：一個是在聖安德肋的農場，用嚴謹、明智的方式（就跟他對付尼可羅堂弟，以及那位逃逸的屠夫一樣）處理佃農的問題，另一個是泡在羅馬史裡，替李維寫索引。

這份索引是一長串按照字母排列的古代人名列表，包含希腦、羅馬、迦太基（Carthage）與敘利亞的名人、統治者或政治家：亞基斯（Ages）與克里昂米尼（Cleonomenes）、卡米盧斯（Camillus）與費邊。馬克西穆斯（Fadius Maximus）、漢尼拔（Hannibal）與哈斯德魯巴、巴卡（Hasdrubal Barca）、那比（Nabi）、西庇阿（Scipios）、羅馬最後的國王塔奎尼烏斯（Tarquinius），以及最初的國王羅穆盧斯（Romulus）。

幾年後，他兒子馬基維利的著作，將會為這些名字注入新生命。他記錄這些名人的功績，通常都帶有煽動性的色彩，挑戰傳統概念對這些人的定位————是英雄還是梟棍？是農家還是讕家？例如，羅穆盧斯因創立羅馬王國而遠近馳名，屠夫羅莫洛的名字就是出於他。但馬基維利指出，羅穆盧斯將與自己同名的城市，打造成成人獨裁的王國，而非採行共和制；他還殺了自己的兄弟瑞摩斯（Remus），以便獨攬大權。接著，馬基維利指出這個行為所帶來的的情況：握有半專制的權力，比較能從頭建立一座新城市；但只要國王統治著羅馬，政局就會不穩定。

這也難怪，當國家由一個人獨攬大權時，國內總會爭端四起，每個野心勃勃的貴族、企業家與軍人，都想成為最高領導人。最後羅馬人終於想通了，不再把統治權交給國王，而是打造出一個完美的政治藝術————共和制。馬基維利在《論李維羅馬史》中寫道：「共和制遠比君主制更能遵守協議。因為這種平民政體能帶來較長久的安穩，犯的錯也比君王少。」假如羅穆盧斯不堅持獨攬大權，羅馬早
