# 我就是主要教你惡

# # 時

問為西元一五一三年十二月，也就是馬基維利獲釋九個月後。現在他大多數時間，都待在佩庫西那聖安德肋的鄉下住宅內，陪伴妻子瑪莉塔與孩子。八月初，瑪莉塔生下一名女婴（可能是他們第三個或第四個孩子），但這孩子卻在三天後去世。馬基維利有幾個小孩夭折，包括大女兒賈莉梅拉娜，雖然死因不明，但馬基維利之後在信上提到孩子時，都沒有大女兒的名字。幸好，十歲的貝納多與他弟弟盧多維科都平安長大，身體健壯；接下來幾年，家裡又增添了兩個健康的男丁—皮耶羅與杜多，最後是女兒巴奇娜和么兒托圖，在他晚年時親到。

自從惨遭開除、禁止進入領主宮之後，馬基維利已經不想在佛羅倫斯久留；現在最好低調一點，避免新的統治者來找麻煩。他對朋友說：「我應該買幾隻雞，然後站在路旁的胡桃樹下，懇求路過的旅人，告訴我佛羅倫斯與羅馬的消息。」「八月，他寫信給外甥喬凡尼：「我身體還好，但其他方面一點都不好。我已經不抱任何希望，只求上帝能幫助我。」「十年前，馬基維利的同胞面對切薩雷大軍，只能無助的祈求上帝憐憫；現在他同樣失去所有希望，只能無聲質問蒼天。不過除了上帝，他還有一位摯友作為支柱，那就是維托利。

從炎熱的夏季、秋季到現在冬月初，他每天都在期待好友的來信。喬凡尼教宗（現為良十世）當選的前幾週，維托利就受指派、為出訪教宗的佛羅倫斯大使。現在，他常從羅馬寫信來（而且內容很長），馬基維利再回信給他。

當時，馬基維利歷經諸多煎熬，都是靠這些信撐下來，才不至於被憂鬱擊垮。當維托利聽聞好友遭到逮捕，並受到拷問時，內心痛苦萬分；因為馬基維利的弟弟托圖，曾被一位僧差到羅馬求助，但他無能為力。於是，他在信上寫道：「這些日子以來，我對別人沒什麼用處，甚至對自己也沒什麼用
