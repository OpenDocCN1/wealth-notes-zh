# 第十四章 如何建議上位者？用他們的觀點

沒有像馬基維利一樣，堅持自己是地位卑微者，渴望成為君王的奴才。

多數當代的佛羅倫斯人若是讀了這本書，應該會看到它有一個大膽、刻意的裝傻之處——共和國的領導人並非正式的君王或君主，但馬基維利還是稱呼他們為「君王」，藉此狡猾的協穿他們的假面具。雖然梅迪奇寄家統治的佛羅倫斯，依舊假裝自己是共和國，但馬基維利表達服從時，卻隻字不提共和國。他暗示讀者：梅迪奇家族希望民眾把他們當君王擁戴。而這種表達手法，反而比直接指控他們僞善，還更有力道。

只要是熟知馬基維利的當代讀者，都知道他以往怎麼評論梅迪奇君王，所以，讀到書中那些看似拍馬屁的弦外之音，必定會感到困惑。再怎麼說，這個馬基維利曾經非常放肆，主動寄了一分份忘錄，給當時尚未成為教宗的喬凡尼主教，建議別輕信幫助他家子復辟的貴族，此外還要透過人民來建立新政府；而且這個馬基維利，在背負謀反嫌疑並遭受酷刑後，又寫了幾首放肆的十四行詩，向朱利亞諾抱怨自己遭受的不公平對待，還必須忍受牢房的惡臭。

而現在，他又寫書給朱利亞諾（或是羅倫佐，兩位都是毫無政治歷練的年輕人），但是筆調比以前更得體——就像對強大的君王、羅馬皇帝或暴君進言一樣。難道從未向金錢、權力低頭的馬基維利，終於破功了嗎？難道《君王論》代表他準備好改變政治色彩、放棄向當權者大膽進諫，希望梅迪奇家族消除疑心，讓他重回佛羅倫斯政治圈？
