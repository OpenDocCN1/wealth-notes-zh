# 奉命前往盟軍陣營看人臉色

一抵達軍營，馬基維利跟他的旅伴立刻就覺得有麻煩了。無論是站崗的衛兵，還是帶領他們去營地的士兵，都對跟他同行的兩位佛羅倫斯長官——弗朗切斯科·德拉·卡薩（Francesco della Casa）與盧卡·德格里·阿比奇（Luca deli Albizzi）很沒禮貌。營帳外頭聚集了一些衣衫不整的紅臉男子，他們蹲在那裡，並用奇怪的拉丁語調，嘰哩咕嚕的說著阿爾卑斯腔的日耳曼語，偶爾還夾雜些粗俗的法語。馬基維利跟他的長官一安頓下來，比薩戰役的法軍指揮官—博蒙特（Beaumont）助爵，就立刻派軍官來報告情況，說瑞士與加斯科涅（Gascogne）2部隊的不滿情緒正逐漸高漲，還聲稱佛羅倫斯還沒付薪水給他們。

馬基維利、阿比奇、卡薩與博蒙特一起用餐。他是一位好相處的貴族，無論在軍功與個人修養方面皆無可挑剔，所以曾在法國大使館見過他的佛羅倫斯大使（如皮耶羅），就請求他擔任法軍指揮官。他向馬基維利表示，自己已經盡力安撫將士，也相信佛羅倫斯官員能像他一樣盡力。博蒙特巧妙的建議：「給他們多點酒喝或許會有幫助。將士有足夠的麵包，但他們一直抱怨沒酒喝。我想，假如把他們的酒杯裝滿，就會消解彼此之間的不滿情緒了吧！」
