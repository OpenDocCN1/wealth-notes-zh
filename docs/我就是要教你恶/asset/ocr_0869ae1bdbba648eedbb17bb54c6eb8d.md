# 第十三章 人民原為自由而戰，政客只想保住財產

+   6 希臘神話中會噴火的怪物的國王娶在一起叫作辭職。他也絕對不聽從；但假如是佛羅倫斯人民要他離開，他樂於從命。

接著，他召集所有議員，向他們提議：如果他下臺能讓民眾開心，而且也認為此舉能帶來和平，那我就主動告老還鄉吧！結果全體議員一致回絕這個提案；他們甚至願意為了捍衛他的職位，犧牲自己的性命。
