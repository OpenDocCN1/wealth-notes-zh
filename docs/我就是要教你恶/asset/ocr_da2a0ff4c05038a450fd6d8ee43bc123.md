# 第二章 上學受教育，是爲了服從還是質疑

在一開始就是共和國了。

接下來是羅馬將軍費邊，李維與馬基維利都認爲他是英雄。當北非迦太基的漢尼拔進軍義大利，強迫羅馬人出戰迎擊時，費邊不跟他玩這一套——他發明了一種全新、另類的戰法。他不跟龐大的非洲軍隊正面交鋒，而是尾隨其後騷擾他們；只要迦太基人在哪裡紮營，他就把那裡的農作物與牲畜全部毀掉。

大多數羅馬人都嘲笑他的計謀，因爲這些人想要出城與入侵者一較高下，卻沒想到這樣做會血洗整個義大利半島。他們說費邊是膽小鬼、"拖延者"（_gongolo_），但他的策略奏效了。這個方式讓敵軍挨餓，一點一滴消磨他們的鬥志，使得入侵者也只能被費邊這種比較沒膽、但更有效的戰術給牽著鼻子走。

貝納多打的「戰爭」，雖然風險沒那麼大，但他之所以能成功搞定堂弟跟曆夫，也是因爲他跟費邊一樣，願意長期抗戰、努力壓抑自己內心的衝動。馬基維利非常推崇這位偉人的特質，因此在往後許多的重要場合，例如幫助自己的城市對抗切薩雷的威脅，或是努力說服市民，徹底改革無力的軍事防禦等，他都效法了這些特質。

馬基維利會建議你，不要被某人訂下的腐敗規定給牽著走，就算它是城裡最重要的規矩，或是你只能藉這個規定證明自己是贏家，也不能因此屈服。你最好訂下自己的規則，並照著這個規則走。如果你為了打败好員鬥狠的蘇夫，而把自己降格為跟他同樣的水準，那真的是天下第一蠢蛋。或許結果是你贏，但也會變得跟他一樣無腦。過沒多久，稍微比你聰明的人就會打敗你。
