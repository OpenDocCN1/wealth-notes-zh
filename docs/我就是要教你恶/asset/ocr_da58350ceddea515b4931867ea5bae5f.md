# 第九章 厲害了我的國，只算計、沒道義

旁邊還點了一支火把，好讓大家都看得見。這則消息引起全義大利的憤慨，就連某些佛羅倫斯人都非常震驚。馬基維利的忠實副手比亞吉歐，就在日記中寫道：“一到到各種折磨後，我們的隊長被斬首了，但他完全沒有承認任何罪狀，所以不像是個沒信念的人。維特利隊長是備兵役的優秀人才，在比薩之戰也表現得很出色，最後竟落得如此下場。 」

之後，領主接獲報告，說盧卡發生了憤怒的抗爭――這座城是佛羅倫斯境內最挺比薩的城市。盧卡的總理祕書寄了一封信給比薩的要人，結果遭到攔截、轉而送到馬基維利的桌上一  他的桌上已經有一整堆可疑的信件。

馬基維利看完信後，提筆回信給那位盧卡的祕書，內容可以看出他的憤怒且酸味十足：“我真是大開眼界！像你這麼認真的人、位居這麼重要的職位，居然能夠輕信、並散播這麼多不利於佛羅倫斯的惡意謠謗！你向你的老相好比薩道賀，因為根據你的判斷，比薩已經贏了，而且各方指責全都會落到我們頭上。我們還真得好好謝你！你散布最卑鄙的謊言，說帕克羅．維特利借錢給我們的市政府，所以政府用計把他殺掉，這樣就不用還這筆債了。

「你這隻可憐蟲（馬基維利的損人功力也是一流的）難道沒發現，這反而證明我們的市政府無罪，而且同時在指控維特利嗎？假如他真的借我們錢，那麼他就是個惡棍，因為這筆錢只能靠非法手段或受賄取得。不管他是否希望成功攻占比薩、是否被佛羅倫斯的敵人收買、是否因為不適任而無法成事等，我們的戰事都因為他的錯誤與疏失，而蒙受無止境的陰影與禍害；所以，他理應接受無止境
