# 第十六章 想評論時事？先評論歷史

拉那時這麼大。雖然兩人意見有分歧，卻一致看衰已經變成名副其實王國的佛羅倫斯。

馬基維利講起他寄給朱利奧與良教宗的企劃書；雖然這兩位當權者吹噓自己的改革計畫，卻沒有進一步的動作。雖然圭恰迪尼比馬基維利年輕，卻遠比他厭世。他說：「不管這個世界、還是諸位君王，都不再是應有的樣子，而是現在這副德行。不過我很好奇，你為什麼想寫史書？」

「因為我缺錢啊。」馬基維利說道。

他在歐里切利園裡，提出佛羅倫斯史的初步構想，讓年輕的好友們興奮至極，於是某人（可能是愛慕關係的巴蒂斯塔·德拉·帕拉（Battista dela Palla））就建議他，可以靠這本史書賺點錢。

於是，巴蒂斯塔前往羅馬，跟良教宗與朱利奧提到這個構想。「他（巴蒂斯塔）說教宗很樂意幫助我。」馬基維利告訴圭恰迪尼。然後，良與巴蒂斯塔聊到《曼陀羅》時，良要求在羅馬上演這部戲，巴蒂斯塔則保證已經安排妥當，演員也都排演完畢，絕對會讓觀衆超開心。

不久，馬基維利受邀替自己草擬一份傭金合約，至於金額高低則由他的新雇主決定：佛羅倫斯大學（Studio di Firenze）。
