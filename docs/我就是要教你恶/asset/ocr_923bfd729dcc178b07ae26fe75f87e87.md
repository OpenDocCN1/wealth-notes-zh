# 我就是要教你惡

這樣不管是誰獨自亂叫，都不會有人聽到……

只要發表誠實言論的異議人士，全都被趕出佛羅倫斯。現在出人頭地的，都是最嘈雜的長舌精與馬屁精。—「我們向彼此說謊，並開始相信自己的謊言。—他們滿嘴陳腔濫調，完全沒有營養，只做他們認為自己知道的事，所以必須沒來由的一直獻殷勤，奉承自己與主人。由此可見，如果要寫東西給這些人看，就必須採用他們的觀點—就算作者的目的是想改變這個觀點，也必須如此。

從『騙子』就能看出一些蛛絲馬跡，知道馬基維利為什麼要那樣寫《君王論》。《騙子》的主述者與主角都是馬基維利，他將自己化作騙子，試著讓自己適應早該習慣的奇異新世界，並為求自保混入騙群當中。現在，他已經快不認識自己了，但他又怎麼可能像以往一樣，不停指出不愉快的真相？在騙群中，只要誰說出不舒服的真相，就會遭受排擠、成為當今世界的叛徒，因為騙群所在的這個世界，是唯一的世界。真相，總會讓說出它的人變成眾矢之的。

# 強權衝突下，一定要選邊站

他跟維托利或大多數人不同，絕不放棄自己的對話習慣、或不切實際的政治理想。不過，他還是想把這些人拉回現實，而不是乾脆隱居冥想、不問世事、像古代被皇帝打壓的臭臉羅馬哲學家：所以他需要一點幫助。首先，「偉大的天使—維托利能否讓馬基維利的弟弟托圖，納入教宗的麾下？由於托圖的國際貿易事業經營得十分失敗，所以他打算改行當神父。
