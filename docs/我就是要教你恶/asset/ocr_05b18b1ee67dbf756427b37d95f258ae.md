# 佛羅倫斯選出一個讓法國滿意的元首

當明顯〕。過了幾週，也就是十二月中時候，佛羅倫斯終於派正式的大使前來宮廷，馬基維利長達五個月的煉獄之旅，也畫下句點。他的擊友寫信來說，佛羅倫斯正在下大雪，屋顶與地上的雪很快就融成水，孩子則堆了許多「雪獅」。

隔年，佛羅倫斯的外敵又帶來更多恐懼。西元一五〇一年四月，切薩雷攻陷了羅馬涅境內的法恩扎，他的軍隊還開始包圍波隆那；但法王並不支持攻打這座城，因此他只好挑選其他獵物。首先，他攻打比薩南側的皮奧恩比諾，然後繼續往南拿下卡普阿（Cara）。該城有位當地市民名叫法布裏吉歐（Fabro），做內應開了城門，結果軍隊一進城就把他處理掉，接著還殺了三千多名軍人，貴族、平民、神父、僧侶與修女都無一倖免。除此之外，被軍隊發現的女性都遭到殘忍的對待。

因為沒有城牆保護，全義大利的鄉下人都恐懼到極點。西元一四九四年，當數百名法軍與大炮進入義大利時，至少最後都還有遵守協議，或是打破協議前會事先找好藉口。然而，切薩雷連假裝都省了，並在他那位最神聖父親的護航之下，打破所有協議；他跟他的爪牙維特羅佐都摩拳擦掌，準備替被草率處死的維特利復仇，並誓言讓佛羅倫斯人受苦。
