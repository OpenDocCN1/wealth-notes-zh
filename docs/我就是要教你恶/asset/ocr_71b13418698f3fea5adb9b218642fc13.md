# 第八章 法律有兩套——給自己人、給敵人

仰較強烈，他們崇拜、愛慕著聖人基督，但基督的形象卻鮮少出現在馬基維利的著作中：就算出現了，也只是把他描寫成一個宗教創始人。而且，他雖然是出自善意創辦了這個宗教，卻不食人間煙火，後來的追隨者很快就因為派系之爭，腐化了他原本的教誨。

馬基維利偏愛的宗教，是沒有一“派系”（sect）之分。他用這個字（而且總是帶有嚴厲批評的味\道），來形容那些充滿爭議的政治、宗教團體。其中，最糟糕的教派是主張，人需要了解自然與超自然方面的真理。可是，我們沒有這種真理，也永遠無法獲得它，就算我們無法從神的旨意中領略、行事（因為人類的心智太軟弱，無法接受這些命令，甚至不知道這些旨意是否真實存在），但這不代表人類沒有穩固的道德標準。

對馬基維利來說，一個適合人類心智發展的宗教，最重要的是，向他人展現出正確的行為與道德觀。這就是為什麼當年人類想要懺悔，最佳的方式就是以慈善之心引導同伴，正如他在懺悔布道中所堅稱的。只要仔細研究人類對於人性的互動與反省，就能悟出舉世通用的不變真理；史書對於這種研究是一大助力，而戲劇、詩詞與寓言也是，你不用受過特別的教育或具備知識技能，就能欣賞它們。

我們不斷修正自己的道德觀，每天都會問：為什麼我們自己或他人的行為，會受到讚揚或責罵？至於創造與監聲人類的上帝是否存在，馬基維利並沒有明講，頂多暗示：如果我們的理解，告訴我們某些行動值得讚揚，而其他行動應受責備，那麼你相信[有一種更高等的力量，能夠擔保這些判斷]，也算是合理的。
