# 第八章 法律有兩套——給自己人、給敵人

之後，薩佛納羅拉修士被吊刑（hanged）。拷問了好幾次；約十五年後，馬基維利也會遭遇到此酷刑。最後，薩佛納羅拉痛到求饒，承認所有加諸於他的指控。他的供詞之中，部分純粹和宗教有關，與其說犯法，倒不如說在道德上有罪：例如他想造成教廷分裂，所以騙大家自己已是上帝派來的先知，而且無論是言語還是行動，都是為了自己的世俗野心，而非上帝的永恆榮耀。

新政府希望藉由公開這些供詞，來驚醒全城的民眾，消除信徒的幻覺，讓他們接受政府給的「新現實」。其中，有些供詞就在大議會當中宣讀，唸給心碎的薩佛納羅拉支持者聽。蘭託奇在日記中寫道：「宣讀整明的時候，我在現場。看到一位偉人因為謊言而倒下，令我悲痛不已。佛羅倫斯正在期待一個新的耶路撒冷，希望它能帶來正義的法律、輝煌的發展與正常的生活。」

但如果他們想一勞永逸的處理掉這位修士，而且是在佛羅倫斯而非羅馬，還是必須靠法律來定罪。所以，他們說服薩佛納羅拉，要他承認一切罪刑，包括想掌控佛羅倫斯的政府機關；為了壯大自已而主導整個陰謀；在聖馬爾佗修道院建立非法的秘密團體；利用間諜獲取政治機密；贊助一支私人軍隊保護自己，代表他準備要用武力对付他的敵人，最後攻下這個國家；還與外國君王密謀，希望打造一個世界級的教會，以反叛羅馬。

對於上述這些罪行，只有死刑是唯一的判決。但是，其他兩位修士是否該跟他們的首腦同罪，還是新上任的政府該放他們一馬，好展現自己的慈悲？政府為此召開了會議，而多數市民代表6 將犯人的手繫用繩子綁於背後，繩子另一側則綁在一蓋類似沉重板的機竅上頭，接著這條繩子會將整個身體拉離地面，把手臂扯到脫臼。7 新耶路撒冷指的就是耶穌再來時，新天、新地的首都所在。
