# 第十六章 想評諭時事？先評諭歷史

從來沒提到陰謀、或是馬基維利對於流亡好友的擔憂。但討論到馬基維利的兒子與外甥的問題時（而且信是用拉丁文寫的，並不尋常），維托利的語氣就好像在隱約安慰馬基維利，因為後者痛失歐里切拉利團的聰明孩子。

「馬基維利吾友，別為我們的兒子賠操心。」「維托利寫道，雖然他只有女兒。」「隨著年紀變大，我們也越來越陰鬱、龜毛，但我們卻忘了自己年輕時，也沒比兒子好到哪裡去啊！所以就別拿無法改變的事，來折騰自己了。」「這封信上有一行字提到「你兒子盧多維科」，以及「你姊姊的兒子盧多維科」，但馬基維利的姊姊只有喬凡尼這個兒子；而花團文人數的另一位朋友菲利浦，也曾在信上告訴馬基維利：「別拿兒子當暗號。」「無論維托利那封信是否用了暗號，或是傳達了什麼訊息，它的疑點還在於用拉丁文寫成，以及其他的古怪之處。「你必須記得，兒子帶給你什麼樣的喜悅與好處，別老是抱怨他們沒盡責任、不守規矩，因為這樣抱怨，只會讓你活得非常折騰與焦慮。」「如今，寶諾比、路易吉與巴蒂斯塔四處奔波，雖然有時會聚在一起，但通常都分散在各處，例如盧卡、詩人阿里奧斯托（Ariosto）的故鄉——加爾法尼亞納（Garfagnana）、威尼斯和法國。法王法蘭索瓦付錢請他們做反梅迪奇的內應，而當內應是很危險的，有時還會被逮；所以佛羅倫斯的親朋友擔心他們，也是很合理的。
