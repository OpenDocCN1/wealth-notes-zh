# 第七章 貧富差距下，人民寧可選擇侵略者給的自由

言。最直言不諱、也最受尊敬的貴族之一皮耶羅·卡波尼（Piero Capponi），沉不住氣地问道：「我們到底還要忍受這種小鬼頭組成的混蛋政府多久？」
之後，領主頒布了一項公告，強迫所有居民都要提供法軍食宿。國王的檢查員在大大小小的房屋附近徘徊，只要能住宿的就用粉筆做記號：家人急忙把女孩子送到修道院、或城外的親戚家。十一月五日，領主沒有經過梅迪奇家族的許可，就派了四位大使拜訪查理國王。其中，有位使者完全背離了外交慣例，因為他既非政府官員，也不是佛羅倫斯出身的人，他是來自費拉拉的修士——薩佛納羅拉，因為在民間最具體權威，又被視爲上帝的忠實僕從，因此當屏中選，領主希望他能夠抗衡法王。
這些大使既沒有勘查別進入佛羅倫斯，也沒有勸他歸還皮耶羅給他的要塞，不過他們確實得到國王的承諾：軍隊會以友善的態度進城。最起碼，現在這個協議是由遞任的佛羅倫斯代表敲定，而不是由任性的皮耶羅說了算。
十一月八日，皮耶羅騎馬回到佛羅倫斯。聽到他不在城內的這段期間內，發生了什麼事之後，他把甜食扔出屋外，還施捨了幾瓶酒給民眾。隔天，當他和武裝護衛試圖進入領主宮時，發現領主將他鎖在街頭，還在門口設置守衛。而在領主宮內，皮耶羅的政敵正敲著鐘，請所有男女老幼走出家門，歡慶他們新贏來的「自由」。
之後的一小時內，整個廣場都擠滿了市民與武裝士兵。叫喊聲從街上與住家的窗戶傳出來，越來越大聲：「人民與自由！人民與自由！」（Popolo e Liberta! Popolo e Libera!）接著又有一項新公告，禁止任何人幫助或教唆皮耶羅。另一項公告則宣布，只要有人痛宰皮耶羅，即可獲得兩千達克特
