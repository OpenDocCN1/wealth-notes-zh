# 第四章 胜利若是没有带点敌意，无法维持和平

# 我就是要教你忍

西元一四七八年四月二十六日，接近正午时分，佛罗伦斯最大的教堂──圣母百花圣殿（Cattedrale di Santa Maria del Fiore）正在举行大弥撒（Olla Mass）。来自各个阶层的外国访客与当地人，约一万人左右，全聚在雄伟的圆顶拱门之下。罗伦佐走进教堂，步向祭坛附近的荣誉宝座，后头跟着他的弟弟──十五岁的朱利亚诺。朱利亚诺颇受年轻男女爱戴，相形之下，他哥哥越来越高。大家当然很欢迎这种「平衡」，长者都称他为「金童」。

他已与美丽的菲欧丽塔·格里尼（Fioretta Giorgi）订婚，而菲欧丽塔已经怀有八个月的身孕，肚子里的孩子就是日后的枢机主教─朱利奥·德·梅迪奇，马基维利会在未来与他交手好几次。众人的目光本来望向祭坛上唱诗的神父，现在则直盯着本城第一家庭的孩子不放。朱利亚诺旁边站着两位穿着体面、年纪与他相仿的青年，并时不时在他旁边亲昵的推挤、打闹，他们是朱利亚诺的好朋友─贝纳多·班迪尼（Bernardo Bandini）与弗朗切斯科·帕普（Francesco Pazzi）。

数年之后，马基维利回顾上述的这些时刻，他觉得最令人不安、且极为古怪的，就是紧接着发生了又快又狠的刺杀事件，而事发之前，凶手竟然还摆出一副彬彬有礼的虚伪模样。

当时，弗朗切斯科与贝纳多带领受害者走向谋杀现场，他们从梅迪奇公馆接走朱利亚诺，在前往教堂的路上与他畅谈诗文与艺术，将一切阴谋都隐藏在虚伪的友谊之下。他们故作亲昵的抚摸着朱利亚诺，实际上是想摸摸看他的披风下是否有武器。

马基维利说：「这件事真的值得记下来，因为如此浓厚的恨意与犯罪意图，居然能掩盖在深沉的心机，以及顽固的意志之下。」虽然弗朗切斯科与贝纳多要将朱利亚诺送上绝路，但在途中他们都精明笑着逗他开心。更荒唐的是，朱利亚诺跟他哥哥都知道，帕普家族与其他许多佛罗伦斯人（包括当时的教宗庇护四世（Pius IV）都恨透了梅迪奇家族政治，但两人却没采取任何防护措施。虽然他们知道帕齐家的复意，却不柏忧死，因为他们坚信假如敌人想颠覆政权，必定会透过政治阴谋而非暴力。所以，罗伦佐与朱利亚诺不在乎自己的人身安全，还假装跟敌人友好。若事件发生之后，九岁大的马基维利从别人口中听到这个消息，那还真是个值得谨记的教训——利用虚伪的友情，以及暗藏其中的陷阱。

本来是欢欣鼓舞的三人组，其中一位突然传出痛苦的呻吟。「贝纳多先刺穿朱利亚诺的胸膛，接着弗朗切斯科全身撞向朱利亚诺，让他遍体鳞伤，再疯狂痛殴他。弗朗切斯科被怒气冲昏头，打人的力道之大，连自己的腿都受到重伤。」马基维利总是忍不住描写这种讽刺的景象，因为人之常情就是如此：当我们以盲目的怒火攻击别人，通常也会伤到自己。

朱利亚诺死于非命，而旁观者看到某人用刀子刺伤罗伦佐的脖子。之后，罗伦佐立刻消失在众人眼前，在一群亲信的保护之下逃进圣器室，为了安全起见还上了锁。等到他们听见外头比较安静了，才让罗伦佐回到现场；他只受到轻伤而已。

数小时内，这个消息就传遍了整个佛罗伦斯。「杀人犯！叛徒！」上千人涌入帕齐家的数栋住宅。弗朗切斯科一丝不挂的被拖下床，吊死在主教高大的窗子上，旁边还挂着比萨大主教等人的尸体。杰考波·帕齐（Jacopo Pazzi）试图逃亡，却很快就被逮到并送回佛罗伦斯，受到众人的谴责，他在朱利亚诺谋杀案发生的四天之后，也被吊死了。杰考波的尸体起初埋在祖坟里，但不久之后他就被逐出教会，跟其他驱逐者一起埋在城墙外。

接着，由肮脏的青少年组成、常在佛罗伦斯街头游荡的帮派，又把他，并用尸体敲响已经废弃的帕齐宫门铃。最后，他们终于玩腻了这种惊悚的娱乐，便将尸体丢进阿诺河，高唱：「杰考波阁下，顺着阿诺河而下。」这具残破的悲惨尸体一直漂到比萨这么远，途中都还有人从桥下看到他。

# 掌权的时候别装得像我平民，才安全

马基维利在各种著作中，都一再提到阴谋与其风险。其中一个最大的风险，是成为目标的君王，在事发后总会获得更大的权力，而且好人经常变成坏人。罗伦佐因为弟弟遭到杀害，感到满腔怒火与悲痛，所以个性变得毫不留情。他在三天之内处死了七十多人，其中有些人是无辜的。接下来的几周内又死了许多人，有些有经过审判、有些则无。如今，武装部队不分昼夜在街道上巡逻，没有人敢在晚上九点后出门。夜夜安静到令人发毛。

杀死朱利亚诺的凶手，故作亲跃的将他送上绝路，也暴露出梅迪奇家族的策略有致命的弱点。即使外表伪装成和蔼可亲的平民，但行为还是像君王一样，而这在敌人眼中，就是暴君。维持共和国的平等表象或许是睿智之举，但到了某个时点，就会有人看穿你，并因为你误导大众而憎恨你。或者，有人看到你把它本性藏在如薄纸般的伪装背后，反而会利用这虚假的友善来伤害你。所以，假如你想要绝对的权力，最好是承认真相，而且宣截了当的行动；君王、暴君，随大家怎么叫，这样还比较安全些。如此一来，你出城、拜会商业领袖、与家人上教堂时，就能带着武装保镖随行。领主（Signora），就允许罗伦佐这样做。从那时起，他进城都有十二名士兵配剑陪同在旁，而他的微笑，却遮不住内心的忧虑与警惕。

佛罗伦斯深陷于集体惊吓与恐惧之中，后来便传出一则消息：不久之前，才公开与罗伦佐吵的思想教宗，在背后支持（也有人说是煽动）着帕齐家的阴谋。佛罗伦斯人的暴力报复，给教宗许多能向佛罗伦斯宣战的藉口（其实许多人怀疑他不管如何都会宣战）。

像罗伦佐这种非宗教的君王，居然为了替朱利亚诺复仇，连捕枭极主教（包括一位教宗的姪子，当时他跟梅迪奇家、帕齐家一起待在教堂里），并用死主教；杀害神父并肢解尸体，将其尸拖行游街；还不分黑白的屠杀市民，这些绝对是不当行为。

马基维利生动的记载下恩迫的官方辩词，同时暗中谴责两方。教宗是个僞君子，这把怒火是他自己煽动的，如今却要浇熄它。不过，佛罗伦斯人确实做了那些事情──尽管没必要。他们选择嗜血的复仇，正好照着教宗的意思走，让他有藉口攻打他们的城市。

由于只有米兰提供协助，加上没有常备军，佛罗伦斯人只好雇用佣兵来打仗。除了少数贵族受派到战场上担任军事长官，其余的佛罗伦斯人都待在家里，试着照常过活。每天，传令官都会给出最新的战况消息，例如：敌军洗劫佛罗伦斯领地周围的城市、把男女老幼绑在柱子上烧死，或是直接烧了他们家。因此，佛罗伦斯附近村子的大批难民，会在拂晓时猛敲城门，他们带着一大群小孩与破烂的家当，祈求能够进城。

接着有个东西饒来，市民对它的恐惧不下于攻城的军队：瘟疫。佛罗伦斯人称它为「死亡的符号 (Heparo)。战争才打两个月，就有人因它而死。到了九月底，史卡拉（Scala）医院住满了瘟疫患者。这种病迅速传遍全城，也传进军营里，没人知道它发生的原因，以及治疗方法。民间认为这跟日蝕或月蝕有关，而部分有钱人坚信，瘟疫是透过穷人饥饿、汗秽的举止传染的。所以，他们很希望上帝在惩罚穷人时，能怜悯诚实、勤奋的中产阶级。

意大利有许多了解其他疾病的医生，店里也有琳琅满目的药，其中某些药如同万灵丹。但瘟疫就像在嘲弄他们的科学知识一般——古代的药和现代的药都不管用。目前，只有两件事很清楚：它容易传染，更容易致命。十四世纪时，瘟疫害死了佛罗伦斯三分之二以上的人口。当时已知最有效的疗法是隔离，只要某人疑似染上瘟疫，医生与政府机关就会建议他们自行隔离，让越多人远离患者家越好，病患也尽量别跟他人接触、别在他人张开嘴巴时呼吸等，以免传染给别人。

这对有钱人来说比较简单，因为他们的房子比较大，或者有好多几栋。而患病的穷人都挤在狭窄的住所，就比较难隔离。有些人还能蹦蹦的去走佛罗伦斯的医院，其他人（有些是小孩）则因家庭过度拥挤而被赶出去，最后横死街头。

在温暖的夏季，贝纳多会花更多时间在城外的别墅，跟佃商议事情，和他们一起去镇上的市场买卖食物、木材与小猪。四月二十七日星期一，也就是圣母百花圣殿谋杀案的隔天，贝纳多在记事本很平淡的记下一些事：他的佃农卖了两只公牛给邻镇的人，但其中一只又老又疲惫；日子还是一样在过，价格与商品品质总有新的争议，尚待解决；农夫与地主还是可以往返于城乡之间。

而现在，这个村子感觉比城内安全，甚至对女性来说也是如此。但到了七月，这片田园风光就被毁掉了。战争如火如荼的展开，佛罗伦斯雇用的佣兵驻扎在圣卡夏诺，离马基维利家的别墅很近。既然村里到处都是士兵，女性出门办事就不再安全了。在七月底的时候，贝纳多记录道：「某位佃农有两个男亲戚，问我能否让他们的妹妹珊卓（Suz）跟我的妻小住在一起，如此才能保护她。我回答说，虽然这会造我的一些困难，但为了让他们心安，我还是答应让她免费吃、喝、睡。不过，他们若是乐意，她可以帮我家打杂。」战争从冬天一直打到隔年春天。

少许的道德哲学，能够让贝纳多保持神志清醒。他在西元一四七九年四月写道：「我去圣母门（Arte di Porta Santa Maria）还书给书商乔凡尼·迪·弗朗切斯科（Giovanni di Francesco）。」这些书当中，有亚里斯多德的《伦理学》（Ethics），以及几本西塞罗的著作。道德哲学是战争下的产物，尤其是内战，也就是与我们的同胞对战：在太平时期，我们一定会把它们当成朋友、同路人，大家彼此扶持。

然而，当一切事物都攸关生死的时候，人们就会分不清是非黑白：不管怎么做，只要能带来胜利或是能生存下去，理由就足够正当了。对于身处于战火中的人来说，生存似乎比分辨是非、正邪更为重要，可是，他们是对的吗？就算这次我方赢了，倘若我们对于是非对错，无法与敌人达成共识，那还能维持安全与和平吗？马基维利在《君王论》并不这么认为，他说：「胜利若是没带点敬意——尤其是对正义的敬意，就不算是确切的胜利。」

# 名医不一定能治病

六月三十日，贝纳多从圣安德肋回到城内住处的路上，感到身体不舒服。他试图压抑对于染病的恐惧，但他如今已年过五十，期待自己活久一点根本是种奢侈。不过，他想到他还有两个未婚的女儿，未来的生活也还没有安定下来（不过他对女儿的嫁妆倒是投资得很谨慎），而且两个年幼的儿子也需要爸爸的指引，这些就是他活下去的理由。

到家之后，他拜托巴托洛蜜亚替他准备一间隔离用的房间，并叫仆人请来鲍宁席格纳·马基维利（Battisterga Marchifili），他是贝纳多的堂兄兄弟，年纪与贝纳多相仿，也是他最亲密的朋友。之后，贝纳多不在一般的房间吃晚，而是直接躺在隔离的新牀上。

鲍宁席格纳一来就接手医疗事宜，病弱的贝纳多给他一份尿液样本，还赏了他一枚硬币。为了避免传染，他们透过贝纳多房间窗户的木条来沟通。巴托洛蜜亚与十四岁的普利玛薇拉，则在客厅焦虑的等待医生来访。家中较年幼的孩子早在一个月，就送到遥远的乡下，由巴托洛蜜亚的兄弟乔凡尼与其妻子照顾。贝纳多还记得道别的情景：他与巴托洛蜜亚汇了一辆騷车，塞满了食物、衣服与寝具，让乔凡尼能够颜外应付这三个小孩。贝纳多答应给乔凡尼六浦多耳（Ducato）2的小麦（替小孩做面包用）、一只干燥羊腿、两瓶醋与两瓶橄榄油，以及一点酒钱。

在接下来的几周，许多医生都造访了马基维利家，用尽各式各样的疗法。有一种汁液是治疗瘟疫的常用药物，就是将琉璃苣与牛吉草的小蓝花，同砂糖一起磨碎，再掺入其他成分：海珊瑤、珍珠、宝石粉、金或银……看患者能负担到什么程度。但因为贝纳多很穷，也非常怀疑这些疗法，因此他采用比较简单的疗法——全身涂满药膏，切开脓瘡让它们的流乾。医生替他放血，给他吃带有苦味的芦荟，以及糖类药剂（掺了蜂蜜的芳香药剂）。

但在这段时间，每个来看病的医生都漫天喊价，甚至连理发师与医师、药剂师属于同一个公会，有权提供药物治疗，他们使用另一种疗法，是将祖母绿或煤色的甲虫〔cantalile〕放在患者左腿上的三处。不过，这些疗法一定有部分产生功效，因为到了八月，贝纳多就脱离险境了。但是，他没有时间享受痊愈这件事，因为他的症状减轻之后，却换其他亲戚染病。

首先是一位堂弟一年仅二十岁的桂多·马基维利（Guido Marcavalli），与马基维利四子同名，请求贝纳多（还在康复中）帮他立遗嘱并担任公证人，以及安排妹妹阿朵拉（Adora）的婚事。接着，桂多的某位叔叔也出现了瘟疫的症状。

最惨的是鲍宁席格纳，这几周不断的进出贝纳多的病房，完全没照顾到自己的健康。后来，贝纳多付钱，请两位织布工邻居以及一位佃农，去见证鲍宁席格纳的最后遗言；因为除了他们，没有人敢接近因瘟疫而垂死的人。贝纳多写道：「我在此记下主历一四七九年八月五日，鲍宁席格纳逝世，留下两个儿子——巴蒂斯塔（Battista）与皮耶罗（Piero），以及妻子梦娜·安东尼亚（Monetta Antonia）。」

瘟疫造成这么多人丧命，加上战争开销越来越高，罗伦佐已经逐渐失去弟弟被杀之后，人民所给予的支持。因此，他决定前往拿玻里，说服斐迪南王（King Ferrante，思维导图承攻打佛罗伦斯的主要盟友）停战；结果出乎大家意料，斐迪南竟然同意了，罗伦佐也再度成为英雄。在此之前，战事虽在持续进行，但公开訾议竊伦佐的人可不少，他们说：「他为求自保而出卖了祖国，让佛罗伦斯境内的城镇落入敌人之手。」然而，当竊伦佐成功取得停战协议之后，风气变成：「在佛罗伦斯，事情是以结果判断，而非他人的忠告；因此舆论整个转向，每个人都把罗伦佐捧上天。」

但马基维利指出，佛罗伦斯人太早下定论了，因为罗伦佐谈和的举动反而激起新的暴力冲突。恩道教宗对于盟友拿坡里竟然与佛罗伦斯交好，感到十分生气；另一方面，佛罗伦斯的盟友威尼斯，则抱怨自己被排除在这次和谈之外，结果他们反过来攻打佛罗伦斯，还加入恩道教宗的圣战，想把佛罗伦斯打到跪地求饶。

后来，马基维利把这件事当成例子，说明判断政策最好不要看方法与听忠告，而不只是追求结果，而且也别太早评论任何政策是否成功，因为政策一开始的成效大家都看得见，因而获得盛赞（尤其是大胆、惊人、高风险的政策），但背后所暗藏的危险，可能会让共和国毁灭。不久之后，那群把罗伦佐捧为外交天才的佛罗伦斯人，又再度转向，说他创造的和平反而催生出新爭战争。

罗伦佐与其亲信对这些批评的回应，是缩编政府，人数比当时几个主要议会的成员还少。他们组织一个仅由七十位市民组成的新议会，并赋予它决定重大事务的权力，取代了之前提供咨询的较大议会。这个改革极度符合体制，让本来想终结梅迪奇家族统治的人打消了念头，但这个做法却无法阻止盛怒的外敌，其制造的威胁。马基维利写道：「每个人都笃定，我们的城市从未像现在一样、深陷于失去自由的危机中。」

不过，眼看新战事即将爆发，佛罗伦斯却躲过了最坏的状况，有人说是个大奇迹，马基维利则说这是一场意外，并非佛罗伦斯伟大领袖的功劳，纯粹只是侥幸。因为，土耳其国王穆罕默德（Mehomet the Great [注]）最近攻打希腊的罗德岛（Rhodes），遭到当地民众的顽强抵抗，让他觉得很丢脸，因此决定一定要在其他地方打胜仗，于是他将目标转为意大利。

他攻打东南海岸的奥特朗托（Otranto），把该城洗劫一空、杀光了所有居民，并在港口周围建立一座要塞，还派军队到乡下去烧杀抢掠。这件事使得拿坡里的斐迪南王派遣使者，前往意大利与欧洲全境，恳求大家协助共同对抗这个敌人。别浪费时间与资源在自家附近的小仇恨上，大家要同心协力对付这个异教徒！

这个转折刚好救了佛罗伦斯。根据马塞维利的记载，挽救罗伦佐伟大领导者名声的，并非他精明的外交手腕，而是土耳其人。马塞维利在晚年，不断警告人们要小心江湖郎中，因为他们只会给你带有甜味的药物，或是夸你的脑袋放血，让事态更加恶化。他在《骗子》（The Ass）一诗中宣称：

> “用这种手段承诺他人和益者，总是能取信于人，而人们对医生抱持此等信任；看来众多职业当中，就只有医生靠病人来过活。”

巧合的是，“梅迪奇”这个字也是“医生”的意思，根本就在鼓励佛罗伦斯的作家，好好利用这种恶毒而微妙的美丽语——这也是马塞维利的最爱。有些人挂着医生的名声，却几乎不懂得治病；有些人一度被捧为共和国的救星，但仔细端详的话，就会发现他们竟是最腐敗的傢伙。

# 第五章 挑战「点个就搞定事情」的人，证明我们品德比较高尚

# 佛

罗伦斯人习惯自我保护、说出模棱两可的话，这是全欧洲与黎凡特（Levant）1都知道的事。有一位名叫阿拉瑞诺（Aramno）的犹太神秘主义者，造访过此时的佛罗伦斯后，用希伯来文写道：「所有的佛罗伦斯人都倾向用矛盾的讯息来沟通。他们有两种说话方式：口语隐讳的智慧，以及肢体动作的涵义。他们的行动与言词相互矛盾，唯恐对自己所说的话感到心虚。他们透过影射的方式，谈论隐藏的事物，小心保护自己的灵魂，并掩饰内心真正的想法。」

教育程度最高的佛罗伦斯人——也就是阿拉瑞诺暗譏的对象，是从古代作家中学到这种暧昧的艺术，这些作家有许多是最近才被西欧重新发现、广泛研究。在散文《年轻人该怎么做读诗》（How the Young Man Should Read Poetry）中，普塔塔克（Piracco），住在维阿帝國的希腊人，也是马基维利喜爱的作家之一）说道：「年轻读者应该要仔细留意，诗人是否留下线索，以暗示他其实不喜欢自己所表达的情感。」

马基维利很快就注意到，古代这种在言词与写作方面，既吊人胃口又难以捉摸的方式。他在《论李维罗马史》中，针对专门奉承权势强大之人的书籍，提出了基本的阅读法则：「不管是谁，在听到凯撒（Caesar）2特别受到作家称颂的时候，都不该被其光彩欺骗。因为那些称颂者都想沾他的光，而且也受到罗马帝国压迫太久，无法自由发表意见。」某些人类史上最伟大的诗词与史书，包括罗马诗人维吉尔（Virgil）与李维的作品，都在作家可能遭到放逐的时代所写下（甚至更糟，只要你看起来不像在质疑当权者，就会被放逐）。
