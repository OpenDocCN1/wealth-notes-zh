# 我就是要教你們惡

心如梨世仇之火熄滅，他們就會窒息的死。「然而，皮耶羅旗官的反對者卻跨大這些難處：「農民組成的軍隊，有什麼好期待的？他們天生就愛違反秩序，沉迷於乏腦綠豆的爭執中。」「馬基維利則想告訴這群唱衰者，他們所謂的「天性」，其實是長期下來的習慣與風俗所致；這可以改變，只是有點困難。不過，只要鄉下地方有建立民兵團的經驗，就會了解其中的益處，居民也就更願意從軍。

但皮耶羅旗官告訴馬基維利：「我們真正的問題不在鄉下，你或許能組成全世界最強的農民軍，但目前的狀況是，有幾位達官顯貴還是不敢武裝都市民眾。」「馬基維利回覆：「那就展現給他們看，讓他們知道自已放棄對人民的期望，是多麼短視而糟糕的態度！人民現在不值得信任，的確不令人意外，因為我們所謂的『大人物』，不但的信任他們，還鄙視他們！假如這些大人物能提出效忠佛羅倫斯的好理由，那他們的表現一定不貪眾望。

「事實上，只要給人民安定的工作，並讓他們參與重大市政，就會贏得眾人尊敬，他們也會成為最頑強的守護者；只要給他們越多權力與尊敬，他們就越會守護你的安全與自由。那些懷疑我們的人，真該回去參考一下歷史：只要曾予窮人平等的權利（包括擔任高官的公平機會），那座城市就是最強的。羅馬在被皇帝統治前，曾進行過一項改革：平民出身的人才可以與貴族一同位居要職；也因為這樣，這些平民的品德就跟貴族一樣高尚，整座城市也因此品德而壯大。「

馬基維利在日後著作中，再三強調上述這個概念。強大的軍隊與堅固的高牆，不足以讓國家強盛；人民的态度才是領袖權力（國力）的關鍵。因此，軍事改革必須與社會、政治改革並行，讓所有市民生活無虞，這亦是城市軍力的重要基礎之一。只要市民的生活自由、安定，受人尊重並尊重自
