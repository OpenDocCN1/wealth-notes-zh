# 第三章 爸爸欠稅，家族黑五類，怎麼翻身？

蓋出如此氣派的住所。他以挖苦的語氣道：「所有社區與市民都幫了他一把！其他有權勢的市民都在儉效盧卡，就算他們蓋的宮殿沒有他大，論暴力與貪婪的程度，卻完全不輸他。相信就算沒有外敵來犯，這座城市也被自己的市民毀了。」

這些事件過沒多久，貝納多就娶了巴托洛蜜亞·德·奈利。巴托洛蜜亞是寡婦，前任丈夫來自於貝尼基家（Beni），這個家族以批評梅迪奇家族聞名；其中有許多人，都跟吉羅拉莫的兄弟一起被流放。貝納多的記事本提到，西元一四五八年時他們欠的稅特別重——吉羅拉莫與他的兄弟就是在這年被判流放，而貝納多與巴托洛蜜亞也在這一年結婚。

雖然，這些債可能是貝納多從父親與叔叔那裡繼承而來，但也可能是梅迪奇家族懲罰批評者的方式——用無力繳納的重稅，以及禁止擔任公職，來折磨他們和其親朋好友。

我們不知道貝納多是否因堂哥的政治傾向而受害，但可以確定的是，他在二、三十歲時體驗過梅迪奇寡頭政治的「恐怖」（這兩字是馬基維利的形容），這也能解釋他為何完全避開權勢強大的政治圈與法律圈。而在馬基維利小時候，有人再度對梅迪奇的政權發動突襲，為這座城市釀成大禍，也使得貝納多這種低調的市民，更抬不起頭來了。
