# 佛

羅倫斯人習慣自我保護、說出模棱兩可的話，這是全歐洲與黎凡特（Levant）1都知道的事。有一位名叫阿拉瑞諾（Aramno）的猶太神祕主義者，造訪過此時的佛羅倫斯後，用希伯來文寫道：「所有的佛羅倫斯人都傾向用矛盾的訊息來溝通。他們有兩種說話方式：口語隱諱的智慧，以及肢體動作的涵義。他們的行動與言詞相互矛盾，唯恐對自己所說的話感到心虛。他們透過影射的方式，談論隱藏的事物，小心保護自己的靈魂，並掩飾內心真正的想法。」
教育程度最高的佛羅倫斯人——也就是阿拉瑞諾暗譏的對象，是從古代作家中學到這種曖昧的藝術，這些作家有許多是最近才被西欧重新發現、廣泛研究。在散文《年輕人該怎麼讀詩》（How the Young Man Should Read Poetry）中，普塔塔克（Piracco），住在維阿帝國的希臘人，也是馬基維利喜愛的作家之一）說道：「年輕讀者應該要仔細留意，詩人是否留下線索，以暗示他其實不喜歡自己所表達的情感。」

馬基維利很快就注意到，古代這種在言詞與寫作方面，既吊人胃口又難以捉摸的方式。他在《論李維羅馬史》中，針對專門奉承權勢強大之人的書籍，提出了基本的閱讀法則：「不管是誰，在聽到凱撒（Caesar）2特別受到作家稱頌的時候，都不該被其光彩欺騙。因為那些稱頌者都想沾他的光，而且也受到羅馬帝國壓迫太久，無法自由發表意見。」某些人類史上最偉大的詩詞與史書，包括羅馬詩人維吉爾（Virgil）與李維的作品，都在作家可能遭到放逐的時代所寫下（甚或更糟，只要你看不起來像在質疑當權者，就會被放逐）。
