# # 走老運不是因為當官，而是做戲

馬基維利的名氣響徹全城，生計有了著落，但他的名號不再是肩負國安重任的官員，而是喜劇作家。他的戲劇正視人類的錯誤，他喜歡把同胞推到地獄邊緣——所謂的「地獄」，就是你逾越了自然與文明的秩序，或是沒阻止其他人逾越時，所遇對的後果。佛羅倫斯需要馬基維利；他是這座城內最受人喜愛的告誡之聲，也是最具娛樂性的神諭。

他在梅迪奇家族心目中的地位也比以前好，這多虧了他超人氣的戲劇、讀者眾多的《戰爭的藝術》，以及有地位的好友相挺：丰恰迪尼、菲利波與他哥哥羅倫佐，還有維托利。而他的《佛羅倫斯史》前八冊也即將完成，這本書大部分都是：在聖安德肋的房子裡寫的；馬基維利連續好幾週都躲在此處，避免城市的喧囂打擾。他寫信給婁舅：「我會替你的問候農場裡的雞。」「接著又寫信給圭恰迪尼，說他寫到梅迪奇家族的權力、重回舊共和國時代時，心裡有點掙扎。『我願意出最多十索爾多( 500 )，2 ，請你來這裡替我審稿，因為我快寫到某些細節了，但又不想冒犯到付我薪水的人。』

他的恐懼很合理。因為這部史書的後半部，微妙且輕聲的批判當今梅迪奇統治者的祖先（有點類似無法自由評論皇帝的古代史學家），可謂操作。馬基維利對於科西莫、羅倫佐的功績，雖然給予應得的讚譽，但他也描寫他們的家人，是怎麼透過毫無節制的貸款與開銷、和遊走在法律邊緣，來培養

+   1 與克拉麗斯·德·梅迪奇結婚的那位。他們家族的銀行是佛羅倫斯最大的銀行之一。

2 葵大和貨幣單位。
