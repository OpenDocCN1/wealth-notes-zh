# 第十四章 如何建議上位者？用他們的觀點

家族的福氣。「為什麼就這維托利，都跟其他人一樣忙著靠狡詐與乞求，來爭得一席之地，而不是選擇智慧、價值與審慎的判斷？」馬基維利發現自己的朋友圈當中，有人（有些還是他最好的朋友）跑去拍梅迪奇家族的馬屁，還貸款給他們、費盡心思拉近關係。他很難責怪這些老友，因為他們現在面臨的世界就是如此，不管他們喜不喜歡，况且或許自己也得面對這個世界。無論是他們，還是馬基維利自己，只要在這個新世界沒有容身之處，就會淪為無名之輩——也就是大家常說的「没用」；畢竟除了眼前的這一個政權外，沒人能夠看到、碰觸到其他世界。馬基維利想透過他們的角度來觀察事物，同時著手一項新計畫：一本談論君的書。他終究還是要寫給「這種人」看——只在乎當前的成就，而不顧遙遠的未來；認為「現實」就是今天看到、體得到的事物，而非長期累積的人類需求、傾向與思維。可是，這些隨時間累積的要素，很快就會發威，將更嚴苛的現實加諸於你那短暫而膚淺的現實。這些人會說〈有時候維托利也差點說出口〉：「放棄你的共和國幻想！放棄你的羅馬美夢（這座城市早期尚未被不公不義、野心給腐化）——擁抱當下的現實吧！你應該做的，只在該說話的時候說話，而且只說讓君王開心的話。讓自己也變得溫順，就像貓群中的貓子一樣。」大約在同一時間，馬基維利開始撰寫《讋子》一詩，宣洩出對這種態度的失望之情：小鼺子四處跑，牠們要吵就一起吵，
