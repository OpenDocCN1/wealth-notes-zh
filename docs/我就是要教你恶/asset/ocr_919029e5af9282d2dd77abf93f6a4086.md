# 第十二章  餵餵他人財物，將在不安中失去一切

《十年記》傳達的政治訊息是：佛羅倫斯人與其他義大利人，都該為自己的防禦事務負責。他們近期的失敗，不能怪自己倒楣、暴露在外國的掠食者之下，而是要歸咎於自己的決策錯誤。假如他們能面對這個不舒服的現實，或許就還有機會为自己挺身而岀。

馬基維利開始寫這首詩的時候，很努力在擬定補救方法，並希望透過《十年記》，將補救方法推廣給佛羅倫斯市民。除非義大利人有自己的軍隊，要不然現狀不會改變太多。西元一四九四年來發生的各起事件，已經讓馬基維利打定主意要喚醒他人，讓他們跟他一樣頓悟。他盼望佛羅倫斯市民能組成民兵團，卻直到前陣子都被人當成白日夢；不過現在，城裡幾位最有權力的人士，都開始力挺他的想法。馬基維利經常跟弗朗切斯科主教談到這個想法，而主教不但被這位年輕朋友的自信給打動，也很佩服他的細緻觀察，於是將他的想法轉達給哥哥皮耶羅。

由於近期在比薩戰役中遭遇諸多災難，皮耶羅旗官開始認真考慮馬基維利的軍事計畫。切薩雷一世，佛羅倫斯人經歷了一批傭兵隊長，想再試試自己的手氣，看看能否拿下比薩。他們先派出幾帆船封鎖海路，讓比薩得不到支援，接著又花了一大筆錢，想將阿諾河沒斷，切斷比薩的補給線；這項計畫徵求最頂尖的工程師來著手設計，連達文西都來參一脚，不過他並沒有獲選，馬基維利負責監督這項計畫。但因為建築師嚴重低估了工程規模，以及其所需要的原料與人事費用；同時，政府並沒有這麼多的錢可花，民眾也失去耐性，因而徹底失敗。
