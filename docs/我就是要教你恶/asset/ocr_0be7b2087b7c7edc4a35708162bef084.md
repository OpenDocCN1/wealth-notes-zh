# 我就是要教你惡

謠、中傷西恩納或威尼斯是一回事，但在教宗陛下與其法國同盟間惹事生非，又是另一回事——尤其是前這位還是紅袍主教。雖然有上述的顧慮，不過馬基維利早在宮廷內打聽過一些訊息，知道迪．安博恩打定主意、想成為下任教宗。而且所有消息都指出，他跟現任教宗歷山處得並不融洽。

於是，主教粗魯的回聲：「陛下是最為審慎之人。他消息靈通卻極為慎重，才不會笨到被義大利人的奸計所騙！」他還特別強調「義大利人」；兩人都知道這指的是誰，因為教宗並非義大利人。「但既然你想給陛下建議，就應該親自進諫。」幾天後，馬基維利終於被召見了。他開始說道：「敝國大人之所以沒有依陛下所願、給您答覆，是因為敝國邊界有切薩雷的常勝大軍，隨時可能進犯，所以领主被迫投入龐大的國防開銷。

「此外，切薩雷一直威脅要攻打佛羅倫斯，而且不是用他的軍隊，是借助陛下您的軍力，他還誇耀自己的後臺很硬。親愛的陛下，除非您阻止他，否則後果將不堪設想。」

法王聽完後，用令人放心的語氣回道：「我們已經寫信給駐紮於義大利的軍官了（而且還一式兩份），假如切薩雷對佛羅倫斯或波隆那，有任何圖謀，這些軍官就會揮軍對抗他。從這點來看，你們安全無虞，不用擔心。」

馬基維利想喚起法王的野心，但他不知道效果是否有如預期。如果路易想在義大利事務上，扮演不捲入紛爭的仲裁者，卻還給教宗與他兒子權力，讓他們得以挑戰他，那就太愚蠢了。其實對馬基維利來說，他希望義大利人別再被這兩股邪惡力量所害──也就是想支配他們所有人的教宗，以及異邦強權。
