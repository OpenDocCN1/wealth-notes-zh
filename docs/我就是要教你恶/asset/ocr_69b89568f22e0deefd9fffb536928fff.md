# 我就是要你惡

排一個房間，讓芭貝拉陪陪那些修士，假如他們沒有爲她瘋狂，那我這次演出就不收錢！——可是政治卻打壞了他們的計畫。

西元一五二六年一月，也就是表訂演出日期的前一個月，克勉教宗因爲急事把圭恰迪尼召回羅馬。克勉的外交政策反覆無常到危險的地步，而圭恰迪尼這次要負責「最新版」的舉措：「組聯盟對抗查理五世。然而，克勉先前才剛簽約立誓，跟這位皇帝結盟。

西元一五二六年初，馬基維利與圭恰迪尼、菲利波等朋友，整天都在討論教宗。自從克勉突然「換邊站」之後，他們都很擔心他會直接把佛羅倫斯與義大利送進墳場。馬基維利與圭恰迪尼都認爲，克勉一開始朝所向無敵的皇帝投降懷抱，的確是不智之舉；但做出協議後，卻又在最糟糕的時刻打破它，就是最不審慎的政策——這一點馬基維利已經講了好幾年。當一個人的立場搖擺，他就不可能安全，所以現在沒人敢相信這位佛羅倫斯籍的教宗——皇帝不相信，法國與其盟友也不相信。

克勉教宗沒有擬定確切的計畫，就輕易改變立場、疏遠了所有人，使得義大利暴露在敵意之下，內部既不團結、外部也沒有盟友。而圭恰迪尼現任克勉旗下最重要的談判代表，只能向馬基維利傾訴心中的絕望：「我不知道該如何是好！我沒看過有人大難臨頭，卻不想點辦法來保護自己；但我們是例外——毫無防備的站在半路上，眼睛睜看著災難來襲。兩人都同意，假如喬賈撲向義大利，那義大利人就不能因喪失主權而抱怨，因爲他們沒有爲此而戰，只能怪自己喪權辱國。「我們早就已經棄械投降、把脖子洗乾淨等死了！」
