# 第十三章 人民願為自由而戰，政客只想保住財產

二月十八日，城內的公告員宣布取締到一項陰謀，其目的是暗殺朱利亞諾和推翻政府。主謀帕歐羅·伯斯寇利（Paolo Bozzoli）、阿戈斯蒂諾·卡波尼（Agostino Capponi）都已經遭到拘留。而現在，政府又發出一份逮捕命令，搜捕對象是馬基維利，因為他們在陰謀者的口袋裡搜出一份名單，上頭寫了二十個共謀嫌疑人名，而馬基維利的名字排在第七個。於是，衛兵來到馬基維利家，把他押入巴傑羅的大軍；而此時，瑪莉塔正懷著第三個或第四個小孩，不確定以後是否能再見到丈夫。

馬基維利一丝不掛，面對準備要審問他的人（身穿黑衣黑帽）。他的手臂被綁在背後，繩子的另一端繫在一臺拷問機上，這臺儀器會把他拉離地面，他的手臂也被肢鋸一扯，而肩膀脫臼。審問者總共問了六次：「為什麼你的名字在名單中，排得這麼前面？」馬基維利一直回答自己不知情。他的確認識那張名單上的名字，但他沒有跟他們同夥，也從未和他們談論過梅迪奇家族的事情。肩膀痛苦不堪的他，在冰冷的牢房裡待了三週，不知道接下來會遭遇到什麼事。

獄卒告訴馬基維利，伯斯寇利與卡波尼已遭斬首。而他人監後沒幾天，就聽到城裡的鐘聲敲響，宣布教宗猶利二世已死，死因據說是發燒。這個教宗總是怒氣沖沖，所以被自己一槍死「好像也挺合理的。當馬基維利的手指恢復到可以動之後，他要了紙筆、草草寫一封緊急信，給腓托利與他的弟弟帕歐羅，求他們證明自己的清白，但是沒有回音。於是，他又寫了三百十四行詩給朱利亞諾，不過與其說是真的要寄給他，還不如說在宣洩情緒：

朱利亞諾，有人在我腿上綁了一副腳鐐，然後用繩子把我吊起來六次。
