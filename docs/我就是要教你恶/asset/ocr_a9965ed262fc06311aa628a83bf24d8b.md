# 我就是要教你惡

西 元一五〇四年末，馬基維利在詩作《十年記》中，以旁觀者的角度，考察過去十年來，義大利的紛亂政治發展。他現在三十五歲，身兼人父與公務員的身分，負責在外交與國防事務上，協助擬定攸關生死的決策；不過由於無力償還父親的債務，他不能擔任行政官、直接走決策。但他還是忍不住審視他人做的策略，並發現他們常無法切中問題要害，因此不斷重複同樣的問題。

他的詩是直接寫給同胞看的，整篇都在說「你們佛羅倫斯人」，自從西元一四九四年後，做了哪些事讓自己更安全？或者沒做到哪些事，結果陷入危機？到了西元一五〇四年，維特羅佐、歷山教宗、與皮耶羅．德．梅迪奇都去世了（皮耶羅於該年一月，在戰場上溺死），而切薩雷的狀況跟死亡沒什麼兩樣。

雖然佛羅倫斯的致命敵人一個接著一個倒下，但《十年記》要求佛羅倫斯人，必須用誠實、自我批判的精神，來研究這座城近期的歷史。它說：「如果你覺得一小群仇敵垮臺，是很幸運的事，能讓你更安全，那請你先檢討一下自己。因為這種想法就像天氣放晴後，你就覺得以後永遠不會下雨一樣。當我們義大利人自相殘殺之際，更強大的異邦勢力將會揮軍至此，讓義大利人死無全屍。

十年來，命運女神仍未心滿意足，祂不會替義大利的戰爭畫下句點，也不會根絕眾多肆虐的疾病。

而各王國與勢力，更沒有團結一致……
