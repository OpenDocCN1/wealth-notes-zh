# 我就是要殺你惡

或許有人認為，這是明智的國安政策，但馬基維利在《君王論》與《論李維羅馬史》都持相反看法。如果你想維持國家長治久安，唯一的正確方法就是武裝你的人民，並且維持他們的滿足感；用人民的善意保護自己，總比要靠堡還安全。所以當有人說，某個統治者用要善意保護自己，就是在影射他不信任（或無法信任）自己的人民能保護他；他只依靠近庸國或國界外的朋友。

然而，上帝與好運還是最著顧羅倫佐，因為他的所有事業最後都繁榮興旺。如果我們以政治家為個人生存，檢視他採取的行動所造成的影響，來衡量他是否成功，那麼羅倫佐無疑能獲得盛讚。但我們還是懷疑，他去世之後，好運是否還會留下？就算少了他也能支撐這座城市？同時也會質疑，一個奠基於某人機運的國家，真的算安全嗎？

尤其在他晚年時，好運似乎用盡了，令他走向生命終點的過程又長、又痛苦。「在羅倫佐逝世前的那段日子，重病折磨他到痛苦不堪，難以忍受的胃痛壓垮了他。最終，他於西元一四九二年四月去世，享年四十四歲。他的死亡必定會造成極大的災難，因為天國已經出現諸多極為明顯的預兆。」
