# 第十四章 如何建議上位者？用他們的觀點

事物，馬基維利與維托利的意見可說南轅北轍，於是《君王論》的結尾就拿這點來做文章。

馬基維利先說：「面對厄運時，最高尚的反應就是堅守自己的信念，並盡力重建世界秩序。」接著，維托利與其他沒自信的佛羅倫斯人，就會跳出來說：「唯有改變想法與信念，以適應時局淪變——也就是屈服命運，才能獲得最大的成功！」這或許是在測試讀者，在讀過前面幾章之後，有沒有領略本書的寶貴教訓：比起短暫的趨勢或好运，踏實的武裝與品德總是比較可靠。

維托利答應馬基維利：「我會把你的信轉交給教宗或朱利奧。朱利奧看來就快當上樞機主教了。」維托利知道政府當局會讀信，所以替無端遭受排擠的老友，寫下一些「推薦文」：「馬基維利，我得告訴你一件事，請相信我不是在拍馬屁：人海茫茫，無論是誰都會選延許多人，但我見過的人當中，就屬你最有判斷力。」

# 沉默不會讓異議者安全，唯有……

秋季已過，冬季降臨聖安德肋。馬基維利焦急的等待維托利或上帝，替自己的心靈沙漠捎來一些甘霖，讓他知道自己這幾年來的貢獻，並沒有被遺忘，就算是君王統治佛羅倫斯，他也依舊能夠有一份心力。以前貝納多會在這座鄉下住宅，花上好幾週跟佃戶商議事情，並販售羔羊、小豬、瓶裝的酒和油；馬基維利則從父親那裡學到，如何管理這塊小小的地產，以及如何遠離世界的腐敗（這對馬基維利來說更有用）。
