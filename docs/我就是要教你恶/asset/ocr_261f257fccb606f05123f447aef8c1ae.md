# 第二章 上學受教育，是為了服從還是質疑

（這是一種內在的榮耀），也希望在死後能夠留下足跡、幫助後世。在讀完那些著作後，馬基維利開始認同他們對於教育意義的理想：建立質疑一切的自信與心靈，不在乎他人的權威，所有事情都要說說靠自己理解。
他在《論季維羅馬史》中主張：“最好所有事物都要自己推論一番，這樣在為任何見解辯護的時候，才能夠講道理，而不是用權威或力量使人屈服。”從馬基維利的生平著作就可以看出，他是個「強迫性質疑者」。在他那個時代，別人會理所當然地接受某個見解，但要他信服的話，必須有明確的證據與好理由（而且他還會鼓勵其他人一起學他）。
長期以來，佛羅倫斯人與其他義大利人都重用傭兵來打仗，而不相信自己的同胞能夠披掛上陣；這種看法就受到馬基維利的質疑。多數古代作家以及當代學者都說，平民政體比貴族與君主統治還不穩定；即便這群擁護者的見解，承襲自好幾百年來的經驗，馬基維利還是推翻了他们。日後，他向更謹守傳統的好朋友弗朗切斯科·維托利（Francesco Vettori）說道：“任何人只要依照別人的意思來行動，他將一事無成，因為一個人的想法不可能與其他人一致。不相信自己的判斷的人，就無法守護自由；他們會飛奔至貪戀權力者的懷抱中，而後者非常樂意替他們下判斷。”當馬基維利面臨生涯最嚴重的危機時，他發現最好的抗憂鬱法，就是與古代好友對話。西元一五一一三年，他寫信給維托利：“我在古人的宮廷中，靠著精神糧食來滋養自己，也相信我就是為此而生。我不會羞於與他們對話，他們也會出於好意而回答。”在他們的陪伴下，他忘卻了佛羅倫斯近期事件帶給他的一切傷痛、受傷的自尊，以及貧窮。有他們在，他無所畏懼，連死都不怕。“我把自己完全化作他們。”他們舉的例子與反思永遠不會過時，因為正如馬基維利在《論季維羅馬史》觀察
