# 兩大致命錯誤種下敗因

接著到了八月二十一日，他們聽到可怕的消息：救廷與西班牙正在佛羅倫斯進軍中。由於西班牙部隊餓到絕望，便開始暴力入侵農田與鄉村，劫掠、屠殺、強姦樣樣來；事到如今，佛羅倫斯市民才後悔自己太小氣了（其實這還不是第一次）。政府召開緊急會議，旗官懇求增列預算，其中有些預算通過之後，就拿來徵召大批士兵。佛羅倫斯周圍的鄉下人遺棄了家園、全部湧進城內，而且人數日日增援，直到在城牆周圍排了超過一百五公里；他們互相推擠，希望能帶著超載的推車與騾子，擠進城門。

城內頓時擠滿飢餓的逃亡鄉民，使得皮耶羅旗官與他的支持者擔心，梅迪奇家族會利用這種恐慌，煽動人民作亂。討論過後，領主同意採取極端的緊急措施，所以約有五百名達官顯要，因為有幫助梅迪奇家族復辟的嫌疑，而拘留於領主宮。大約在同一時間，馬基維利在菲倫佐拉（Fierozola）率領了兩千名精兵，計畫要與其他部隊集結，避免敵人更加逼近，其他部隊長官還滿有信心的，士兵的鬥志也相當堅定，可是指揮官與市民對於部隊的集合地點，卻有不同的意見。
