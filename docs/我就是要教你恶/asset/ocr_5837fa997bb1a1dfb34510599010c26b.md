# 我就是耍教你憑

別說讓自己一起跟著惡作劇。沒想到圭恰迪尼卻說，他已經寫信給卡布里的院長：「我跟他說你是一位傑出的人士，他就反問我說你哪裡傑出？我覺得我應該賣點關子，讓他想破頭，卻又得對你畢恭畢敬。所以，在你還沒穿幫之前，就好好利用我這份讚譽吧！」

馬基維利回答：「一定會、一定會，而且我衷心盼望這次任務結束後，能跟大人您再共度一晚。祝您萬壽無疆，政權千秋萬世！」雖然這項任務令人厭煩，但若能藉此機會交到這位優秀的朋友，那事情再怎麼荒謬都值得。

圭恰迪尼在馬基維利認識的人當中，待在政治圈的時間是最久的，不過他不太敢表達自己的想法，就只對極少數人暢所欲言，而他信任的「少數人」是誰，相當容易就能分辨出來，顯然馬基維利就是其中一個。他們當時，在享用過豐盛的羅馬渥科料理，以及好幾瓶當地美酒之後，發現彼此都很喜歡戳破帶著假面具的人——尤其是神職人員的假面具。
