# 第九章 侵害了我的國，只計算、沒道義

奇之一，也是這座半島上最凶惡的統治者之一。卡特琳娜是米蘭公爵加萊亞佐·瑪利亞·斯福爾扎（Galézzo Maria Sforza）的私生女，而他就是在西元一四七一年，造訪佛羅倫斯的那位米蘭公爵，他間接導致馬基維利家附近的聖神大廳遭到燒毀。卡特琳娜十歲時，就嫁給吉羅拉莫·里亞里奧（Girolamo Riario），他是教宗思道四世的外甥（不過也有可能是親生兒子）。

馬基維利忍不住記載：「思道家住了兩個男孩，其中一位就是里亞里奧，每個人都認為他是思道的兒子；不過思道卻用其他更體面的姓氏，來掩蓋這件事，就和其他教宗與偉大的人一樣。」因為嫁給里亞里奧，卡特琳娜獲得「伊莫拉（Imola）領主夫人」「與「弗利伯爵夫人」這兩個頭銜。之後，里亞里奧因爲一場陰謀失去了性命，卡特琳娜就負責治理兒子奧塔維諾（當時年紀還很小）的領地。

接著，她愛上了自己的馬夫賈科莫·費奧（Jacomo Feo），並祕密結婚，結果丈夫也被設局殺害；第三任丈夫則是喬凡尼·迪·皮耶弗朗切斯科·德·梅迪奇，出身梅迪奇家族的平民支系，於西元一四九八年去世（不過這次是自然死亡）。這段婚姻關係，也讓佛羅倫斯與弗利城、伊莫拉城建立了穩固的友誼。
