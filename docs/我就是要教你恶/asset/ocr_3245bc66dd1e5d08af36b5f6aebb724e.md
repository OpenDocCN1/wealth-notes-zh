# 第十二章 覬覦他人財物，將在不安中失去一切

許多孩子，還只能靠狗肉與老鼠肉勉強維生，所以他們一定會乞求政府跟敵人議和，或是威脅要叛亂——可能甚至更糟。
假如比薩跟其他城市一樣，這個策略就無效了。但是，它經歷了十四年的戰爭，早已成爲一座截然不同的城市。戰鬥、困頓、長期沒肉可吃、只靠極少數物果腹、一夕之間失去家园、小孩死於戰爭或飢餓⋯⋯這些，都成了他們的日常生活；孩童從小就要學習忍受艱困、男孩與女孩都會怎麼殺人，而且不會因爲想到自己可能戰死，就覺得氣餓。當少數幾位大膽的市民開始提議投降，年輕幫派就會用武器讓他們閉嘴。
佛羅倫斯有一間鄉下的教堂，接著比薩人會在那裡剁掉戰俘的生殖器、塞回他們口中，然後割下耳朵、挖掉眼珠，再剁碎這些器官。比薩人並沒有否認這種傳聞，因爲他們知道，落水狗就是要飼嚇人才能存活。
三月，馬基維利收到十人戰爭官寄來的緊急訊息，要求他前往比薩南邊的皮奧恩比諾城。比薩政府已請求皮奧恩比諾的领主傑考波·迪亞皮安諾 (Jacopo d’Appiano) ，擔任和平談判的調解人；現在，迪亞皮安諾寫信給佛羅倫斯，說有一大羣比薩人聚集在他的宮廷裡，因此力勸佛羅倫斯派幾個值得信賴的人，聽聽這些比薩人的想法。
