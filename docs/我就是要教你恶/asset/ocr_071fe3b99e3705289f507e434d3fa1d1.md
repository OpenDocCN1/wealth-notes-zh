# 我就是要教你惡

再提供資源給比薩，比薩就不會變成收容好戰者的瘋人院，屆時我們倆必能「相互理解」。

到了夏季末，佛羅倫斯的市民代表要求對比薩進一步施壓。儘管斯托羅齊家族與梅迪奇家族之間的婚約分出勝負。與此同時，強硬的字眼不斷出現在軍事會議上：「現在是憤怒的時刻，不是展現胸襟的時候！」除非拿皮帶勒緊敵人的脖子，否則他們是不會減少的！這場仗如果合乎正義，就該用盡一切必要手段獲勝，沒入會責怪你；就算不是，我們也應採取各種方法，來解決這些爛攤子！

會議中較為謹慎的發言者，例如皮耶羅·圭恰迪尼，只好提高嗓門讓大家聽見：「假如比薩遭到施壓而身陷絕望，其支持者可能會挺身而出，讓事態更加惡化！法王已經抱怨，我們的圍城戰術讓當地居民挨餓，也相當不人道，相信他的言語會激勵我們的敵人。「然而皮耶羅旗官心意已決，只要這一仗打贏，他就能在內政部為動亂之際，贏得大費心。」

比薩人若是寧願餓死在城牆內，也不要投降的話，那就讓他們餓死吧！八月底，皮耶羅旗官寫信給馬基維利：「我們這群官員都覺得，破壞敵城的速度太慢了，所以勸你採用最迅速、最能減少敵軍顆粒的戰術，結束掉戰事。如果你辦得到，絕對會受眾人稱讚！」

身為九人民兵官與十人戰爭官的秘書，馬基維利負責的任務是，摧毀比薩周圍鄉下那些尚未受戰火摧殘的農作物；他跟大多數人的想法一樣，覺得也該贏下這場本來贏不了的戰爭，因為它為共和國帶來不少禍害。日後（那時共和國已不存在），他回顧這一切艱鉅工作時，更清楚體會到正是佛羅倫斯與比薩的戰爭，降低了共和制存續的機會。「佛羅倫斯花太多經費在戰爭上，卻毫無成果。為了支應龐大開銷，就必須課重稅；一旦如此，人民就會爭吵不休。」而現在，他們必須迅速取得勝利。只
