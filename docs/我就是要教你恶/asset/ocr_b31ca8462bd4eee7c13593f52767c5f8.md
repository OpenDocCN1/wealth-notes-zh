# 父親堂哥叛變失敗，全家族列為黑名单

馬基維利在《佛羅倫斯史》回憶道，當時的政局令人憂心。西元一四三四年，科西莫在佛羅倫斯取得政權後，希望間接掌控政府，而不犧牲合法的表象。因此，他最喜愛運用他的財富與人脈，確保城內行政官的候選人全是自己的支持者。而且令佛羅倫斯貴族驚訝的是，這些忠心的人都來自中、低階層。他們感激科西莫提携自己，所以不管科西莫偏好什麼政策，他們都會捍衛到底。到了西元一四五五年，許多上層階級的顯要人物（包括一度支持科西莫的人），對於政府內潛藏這麼多的平民，都表達強烈的反對。

馬基維利說，科西莫僞裝事不關己，繼續扮演守護平民利益的角色，他就是靠這一招爬到現在這個地位。然而，當所有達官顯貴找上科西莫，乞求他大發慈悲，讓他們（連同科西莫自己）遠離平民的掌控時，科西莫卻又同意讓這些達官顯貴推動新法規、變成由少數人管理政府——講白一點，就是寡頭政府，而非平民政府。

因此，吉羅拉莫很快就成為反寡頭派的領袖，強烈批評當權派在議會的行為。他宣稱：「我們的城市正是因為分歧而垂病不起，市民分裂成少數派與多數派，兩邊都一心一意要摧毀對方。難道你們當真期待透過加深分歧，來治療這場病？團結才是解藥，唯有兩派公平分配權力、公職與議會，我們才能團結。我嚴正譴責那些想讓權力由少數人獨占的傢伙，就是你們在撕裂我們的城市！」
