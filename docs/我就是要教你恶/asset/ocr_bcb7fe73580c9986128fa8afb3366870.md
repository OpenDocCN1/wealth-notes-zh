# 第十一章 人說狐狸狡滑，因為他識破人的陷阱欺詐

由，因為我的部隊夠多，而且你們的敵人都變成階下囚啦！喔，對了，我還有個特別的請求，希望您的上級幫我逮捕烏爾比諾公爵，因為他可能會逃進佛羅倫斯境內。

在德國與外交上，切薩雷雖然稍微展現了謀略，但一個月後就全忘光了。隔天，也就是一月一日，馬基維利聽說，維特羅佐與費莫昨晚就被吊死了。奧西尼家的帕歐羅與格拉維納暫且保住一命，可是，當歷山教宗在羅馬逮捕了枢機主教——吉安巴蒂斯塔·奧西尼（Giambattista Orsini）之後，兩人還是慘遭毒手。至於吉安巴蒂斯塔，則於二月二十二日死於聖天使城堡，可能為切薩雷或他父親下令毒殺。

現在這位「新凱撒」，把軍隊轉向佩魯賈與西恩納——這兩座城市分別由巴格里安尼與佩楚奇統治，他們是切薩雷僅存的前叛變盟友。馬基維利跟著軍隊一起走，一路上發現切薩雷軍隊的狀況很糟：他們睡覺時，如果有塊薄布可以墊在地上，就該偷笑了。此外，由於大雪紛飛、在鄉下被攔路搶劫好幾次，害得信差都不敢送信。

一月的第二週，切薩雷召見了馬基維利幾次，請他說服佛羅倫斯領主協助攻打西恩納，把佩楚奇趕出去；他還特別強調，這傢伙跟這座城都是佛羅倫斯的強敵。「我想你家領主，應該很樂意護我這個好友——羅馬涅的公爵，來統治西恩納吧？」接著，他用同樣的語氣補充：「如果某人身本身就是個背信忘義之徒，那就不必對他誠實了。 」
