# 我就是要教你惡

人聞問，顯然切薩雷已經對佛羅倫斯失去興趣。

領主一直抱怨馬基維利的信寫得太少，讓他們搞不清整狀況，而馬基維利回應的口氣，讓其中幾

位領主覺得相當傲慢：「我已經告訴過你們，最近公爵的言行非常隱密。我不想淨寫些幻想故事，所

以花一些時間研究其他相關的事情，而且已經很努力把時間花在刀口上了！現在的事實是，我很難觀

見到他，因為他只接觸對自己有（或看起來有利）的事物，完全不信賴他人。」「於是，馬基維利再

次請求上級讓他回家：「我待在這裡不但對共和國沒有任何幫助，還把自己的身體搞壞了。我發了兩

天高燒，全身上下都不對勁。」而他的同事則告訴他，瑪莉塔經常寄信給總理署，問他什麼時候會

回家？

整整兩週，馬基維利連起床都有困難；他的身體忽冷忽熱，還咳出痰來。馬基維利已經十天沒跟

切薩雷對談過了，因此他決定趁還能走動時再試一次，結果這次竟然立刻就被召見。當天是十二月五

日，他已經離開佛羅倫斯兩個月了。他們倆聊了一整個小時，不過都在講些瑣事；公爵一直吹噓自己

多麼重視佛羅倫斯，例如他想替他們拿下富人雲集的比薩（這對一個軍事領袖來說，是多麼榮耀的

成就！），還有盧卡這座「叛徒巢窟」（曾幫助比薩抵抗佛羅倫斯），以及皮斯托亞與西恩納。

古代的歷史學家與哲學家認為，這種無止境的征服欲望就像令人致命的癲頭，例如希羅多德筆下

的波斯人、修昔底德與柏拉圖筆下的雅典人、以及季維與塔西陀筆下的羅馬人；他們都在短時間內獲

得幅員遼闊的帝國，接著卻因為貪圖太多而噎死。一旦群體或個人開始貪心，習慣吞下遠比必要數量

更多的食物，就會發現不再繼續吃就活不下去，儘管他們知道自己可能會噎死。或許，切薩雷會因為法

王與幾位睿慎顧問的督促，而想努力戒掉老毛病，但也可能死性不改。
