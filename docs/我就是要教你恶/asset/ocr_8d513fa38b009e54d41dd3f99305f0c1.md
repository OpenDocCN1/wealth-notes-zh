# 第七章  貧富差距下，人民寧可選擇侵略者給的自由

里昂（Lyon），當作談判回應。

眼看佛羅倫斯民眾既擔心又憤怒，領主只好召開緊急會議。有少數領主替梅迪奇當家找藉口：皮耶羅與拿坡里國王之間有家族關係，所以他不可能放任法軍將自己的親戚掃地出門，更何況，這些親戚對他搖搖欲墜的政權來說，是最有力的支柱與後盾。但多數領主都認為，面對無法與之作對的大軍、卻不開路讓他們通過的話，簡直是瘋了──别忘了查理國王指揮著全世界最龐大的軍隊。

有些民眾指出，佛羅倫斯完全沒有自己的軍隊，而拿錢幫他們打仗的傭兵，對法軍新形態的作戰方式也毫無經驗。事實上，因為這些傭兵並非为自己的國土與家人而戰，所以會盡可能避免全面衝突，反而偏好使用迴避與包圍的方式，並且用鈴鼓製造巨大噪音、吹刺耳的小哨子來威嚇敵軍。然而，『法式戰爭』會使用駭人的炮陣，讓數千具殘破的屍體散落在燒盡的戰場上，並且使所有城市陷入一片腥風血雨之中。假如，佛羅倫斯為拿坡里國王踏上前家性命，下場就會是如此。

西元一四九四年九月初，法王查理八世經由蒙特熱內夫爾（Montgerau）迳軍義大利。軍隊約有兩萬五千名士兵，還有同等人數的隨營人員陪伴──廚師、醫生、馬夫、軍樂家、朝臣、搬運補給品的僕人、妓女與其他表演藝人；這是義大利土地上從未見過的景象。

到了九月中旬，南方拿坡里國王的艦隊慘遭殲滅。十月四日，另一批從法國來的大使造訪佛羅倫斯，給領主最後一次讓這座城市安然無恙的機會。
