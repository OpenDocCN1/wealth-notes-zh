# 我就是要教你怒

通。馬基維利的僕人抱怨，部隊在晚上急著尋找食物與住處，會把其他人都推開。上百名士兵（或許多個）不但行軍時缺乏秩序，還會恐嚇當地人、騷擾婦女，並且偷走雞、鵝。切薩雷有個屬下透露，公爵帶了他所有的法國部隊一起前往切塞納，其實這就是他全部的軍力。

這個消息讓同行的使者議論紛紛：他帶這麼多士兵到底要幹嘛？統治者在自己的領地內移動，為什麼要帶上這些全副武裝的人？有人猜測（包括馬基維利），切薩雷想用這些部隊對付帕歐羅、維特羅佐，以及其他害他差點丟掉地盤的人。可是這些人現在都是盟友，除了一起簽約立誓外，還得到他爸爸——教宗的祝福。

不過比起目標本身，切薩雷採取的手段反而更令馬基維利傻眼。假如你剛稱王沒多久，而且臣服的地區都還沒信任你，你會選擇帶著上百位軍紀渙散的將軍，任由他們踐踏這些地區的田野、城鎮與酒館嗎？馬基維利十分佩服伊莫拉人民的耐心；好幾個月以來，他們都不斷的抵抗羣外部部隊，以及其粗暴的行為，而且還得忍受食物與其他必需品短缺，因為切薩雷的將軍把一切都吃乾抹淨，連骨頭都不放過。當部隊抵達切塞納之後不久，當地人立刻與他們爆發衝突，因為公爵與部隊來到這裡之後變本加厲，比在伊莫拉時更誇張，只顧自己開心、完全不顧當地居民的感受。

「如果人民對君主釋出自意，君主就無須害怕自己的國家。倘若人民抱有敵意或恨意，那麼他就該恐懼所有人、事、物。守序的國家與睿智的君主，會盡全力思考該怎麼滿足人民，並讓他們持續滿意，因為對君主而言，這是最重要的事之一。」羅馬正在衰敗時（當時有許多帝王想稱帝，撕裂了這個高尚的共和國），君主必須取悅將士而非人民，因為它比人民更有可能傷害他。「但現在，除了土耳其國王與蘇丹（Sultan），之外，所有君主都要取悅人民而非將士，因為人民的力量勝過將士。」
