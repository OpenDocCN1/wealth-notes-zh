# 我就是要教你惡

配這座城市的富裕商人認為，有些事情比捍衛自由更重要，而且他們也不信任受過武裝訓練的人民。但事實上，你們看看，這種政策為我們造成什麼後果！假如隊長是由自己的市民擔任，那麼整維持特的離開，以及因法律秩序過早腐敗、與黎繞於佛羅倫斯中的惡臭等問題，都可以避免。我們應當有一支自己的軍隊，並由市民嚴格管控。

馬基維利現在還不知道，他雖然只是個祕書、沒有顯赫的家世或有力的人脈，但他能夠實現上述這個理想。他目前只體認到，假如不快點整頓佛羅倫斯那破爛不堪的國防，共和國就會因自己造成的傷害，而流血致死。光是這兩年間，就發生了三起重大叛國罪案：擁護梅迪奇的陰謀者（就是上訴彼鼓回的那五個人）、薩佛納羅拉修士，如今是維特利；而且，每個案子的起訴手段，都比前一個更可疑。

這三個案子的起訴人都以「出於必要」為藉口，宣稱那些人都對共和國造成明顯的威脅，所以一旦面臨這種威脅，就不能太顧慮平常的法律程序與被告的權利。不過，馬基維利厭斥這些藉口。他想起古羅馬有個案子，羅馬人也是以國家必要為由，否認了阿庇烏斯·克勞狄（Appius Claudius）的上訴權。11 馬基維利承認：「克勞狄作好犯科了，一輩子，受到任何懲罰都不為過。不過，為了懲罰犯人而觸犯法律，並非文明之舉；無視法律程序，對某個特定案件或許有益，卻也因此樹立了壞榜樣。如果有人出於善意，破壞政治與法律秩序，那麼之後就會有人以善意為藉口，惡意的破壞它們。」
