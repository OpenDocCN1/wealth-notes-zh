# 我就是要教你惡

人脈。他的史書並不偏袒任何一方，既沒有把佛羅倫斯早年共和國時期，吹捧成自由與正義的黃金年代，也沒有怪罪梅迪奇家族從人民手中竊取政府。這部史書就像一面極度誠實的明鏡，映照著所有佛羅倫斯人；每個篇章都像戲劇場景般栩栩如生。

世世代代，市民奮力追求自由，卻又很快就被自己的人性弱點拖垮——例如渴望支配他人、不願與敵對陣營分享權力、無法看穿偽善的表象、只寄望上帝或其他高人拯救自己等。就跟其他偉大的古代史書一樣，馬基維利的史書所告誡的教訓，適用於任何時代。他把歷史當成良藥，消除讀者的傲慢、對於人性的天真，以及聽天由命的想法——人類事務無法由我們的智慧來管理，只能交給天命，然後或上帝。

而現在，他寫信給圭恰迪尼時，可以這樣署名：「尼可洛·馬基維利，歷史學家、喜劇作家兼悲劇作家。」因為根據他的史書記載，「偉大的羅倫佐」的逝世是一大悲劇；但也有一些事件，促使他寫出喜劇《曼陀羅》、《君王論》中那些看似冷血的建議。將這段歷史收尾之後，他打算開始撰寫偉大的羅倫佐死後發生的紛亂：西元一四九四年法軍進犯、薩佛納羅拉、博日亞父子、比薩戰爭，以及皮耶羅旗官；這些事件都是他親眼目睹、親耳聽見的。他覺得寫這個部分應該要加新對手，於是請菲利波幫忙跟委託人（也就是教宗）協商一下。

如今，朱利奧已經成為教宗克勉七世（Pope Clement VII）。雖然梅迪奇家族在佛羅倫斯越來越不得人心，但他們在梵蒂岡依舊好運到令人難以置信。良教宗去世兩年後（加上教宗亞德六世也很短命），樞機主教選出良的堂弟朱利奧，接替教宗的位置。然而，克勉教宗並沒有為佛羅倫斯帶來多少祝福，反而成為史上最糟糕的政府。

祝福，反而成為史上最糟糕的政府。
