# 如何評斷統治者的功過？要塞

接近三月底，也就是喬凡尼升任樞機主教後不久，羅倫佐前往佛羅倫斯城外、位於卡勒吉（Corse）的別墅，他因為胃痛的關係都快癱瘓了。接著，死亡的預兆開始一一出現：領主宮的後院養了幾隻獅子，當作這座城的吉祥物，結果其中一隻被其他幾隻咬死了；四月五日晚間十一點左右，一道閃電擊中了聖女萊伯拉大（Sibergo）教堂（聖母百花聖殿即建於此上）的穹頂，力道猛然到毀了尖塔一大半，讓所有人都驚嘆不已。因為，在事發之前完全沒有下雨的徵兆，天空亦萬里無雲。

事件發生的三天後，羅倫佐的朋友在卡勒吉幫他辦理後事。他比一般人早衰好幾年，因此他花了很多時間，思考一個令所有統治者焦慮的問題：當我過世之後，人們會怎麼說我？評價會褒多於貶嗎？
