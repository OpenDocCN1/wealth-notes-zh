# 第三章 爸爸欠稅，家族罵黑獨，怎麼翻身？

落於起伏丘陵上的一座山峯。如果想抵達古代的伊特拉斯克（Etruscan）城，必須先沿著一條漫長而蜿蜒的路前進，而且越接近城門坡度就越陡。通過較低的城門之後，會抵達一個人廣場，它覆蓋於一座大型建築物，以及其锯齿狀斜塔的陰影之下；而那座大型建築物就是政府的宮殿——普萨里宮（Palazzo dei Priori），托斯卡尼最古老的市政廳。

它比佛羅倫斯的領主宮（Palazzo della Signoria）2還小，但沃爾泰拉對它的「輩分」，以及自己的古老血統，都感到非常自豪。羅倫佐取得佛羅倫斯的統治權之後，短短幾年內就與沃爾泰拉爆發衝突。當時，沃爾泰拉周圍的鄉村挖出鑛藏之後，佛羅倫斯的投資人急著想全數收購，他們有梅迪奇銀行在背後撐腰，而這部銀行獨占了該地區的鑛藏。沃爾泰拉人為抗抗議，認為這些礦產應該屬於市民的公共財產。不久後，抗議惡化成暴力衝突，而派駐於沃爾泰拉的佛羅倫斯代表，則害怕自己性命不保。於是，羅倫佐召集議會決定是否宣戰。
