# 我就是要教訓你

勢是持續上漲的。馬基維利相信，切薩雷還是有自信再打勝仗，但他話實在太多也太過興奮；身為祕書，馬基維利必須於信中小心傳達自己的判斷。除此之外，最近這些事務談讓切薩雷與教宗相當緊張，所以任何從羅馬涅寄出的信，都會比以前更認真的攔截與檢查。

這次，馬基維利決定將所有長談內容，一字不漏的向上級報告，而不是只講重點。「這樣請位大人才方便下整體判斷。」他要讓上級彷彿置身於伊莫拉的觀見室，並且親耳聽到切薩雷的話，說羅特羅佐與奧西尼家，是怎麼催促他違反已見、執意進軍佛羅倫斯；而且切薩雷沒發現到，抱怨這群人反而讓他看起來很軟弱、很好操控。

有些佛羅倫斯高官十分昏庸，無法體會切薩雷的辯解透露出自少弱點，因此需要弗朗切斯科主教與其他审慎之人，幫助他們讀懂句子間傳達的訊息。他們假如「聽到」切薩雷無意間自曝其短，就一定能掌握到重點：切薩雷可能說謊，並樂於放任盟友進軍佛羅倫斯；要不然就是所言為真，也就是確實努力制止過他們，但這也代表他是一個無能的領袖。不管是哪種情況，他的解釋都無法讓人相信，他能確保佛羅倫斯的安全。

伊莫拉的街道並不平靜。馬基維利聽說切薩雷麾下有些部隊，已經威脅要發起叛變。他寫信給上級：「我們看到他的敵人全都武裝起來，準備要燃起大火。當地人都是徹底愛國的羅馬涅青年，他們受到很糟糕的對待，因為切薩雷總是愛自己的兵馬，更勝愛當地人。」切薩雷與他的顧問雖然虛張聲勢，卻明顯被逼到角落了。假如叛軍動作夠快，說不定還會入侵整個馬涅，粉碎博日亞父子的雄心抱負。所以，現在正是佛羅倫斯要求的大好時機。
