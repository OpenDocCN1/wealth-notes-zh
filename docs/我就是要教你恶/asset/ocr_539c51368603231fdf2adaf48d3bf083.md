# 第十一章 人說狐貍狡猾，因為牠識破人的陷阱欺詐

說誰能讓陰謀者不敢亂來，還能讓羅馬涅的富裕城市繳稅給羅馬，那就是拉米洛了。馬基維利認為，君王不該害怕染上「殘暴」的臭名——假如懲罰逃稅與犯法的人也算殘暴的話。像這種愛發牢騷、說君王殘暴的民眾，反而偏愛過於軟弱與腐敗的君王，因為他們不會強制懲罰違法者（包括其親友在內）；因此，沒有時間聽這些民眾抱怨的君王，才是馬基維利心目中的英明領導者。他心想，切薩雷受到幾個比自已年長、睿智的顧問指導，說不定就能從他們身上學到幾分道理。

《君王論》中提及，審慎的君王深知如何赢取臣民與盟友的信任。若要贏得信任，其行為就要始終如一，避免善變、虛偽等臭名。馬基維利懷疑切薩雷這般性情，能否領略此道理——鮮少有人接受的善意後還背叛你，因為那實在太卑鄙了。不過，從他的行爲可以得知，老是靠同一招贏得輝煌勝利的人，要他改方法可說是難如登天。

若想組織一個國家，領導者就必要必須為人正直、信守承諾，只要有人犯法，不管是朋友還是惡棍，應以同樣的嚴格標準懲之；然而，暴力的君王本身就心術不正。正直之人即使知道，旁門左道能达到良善結果，也會盡量避免；但邪恶之徒不會因為稱王而開始為善，因為他的權力就是靠不當手段取得，怎麼可能用它為善？假如切薩雷是少數奇葩，很快就會修正目前極為危險的路線（而且不光是嘴巴說說，還要實踐），那麼他的品德就得以及時彰顯出來，否則再過不久就無法挽回了。
