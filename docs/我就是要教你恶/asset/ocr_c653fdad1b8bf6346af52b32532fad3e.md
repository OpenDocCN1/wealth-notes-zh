# 我就是要教你惡

光輝一般，令人折服。

馬基維利日後寫道，這才是真正的戰爭藝術。它所仰賴的知識，比一般的軍事技能更深層、更具哲學性：不管特定人士（或普遍人性）有什麼缺陷，好的法律與制度都能掌管這些，並培養其品德；這些品德會令你恨意外──或許連他們自己都很意外。

除非必要，否則人類絕對不會為善，如果飢餓、貧窮會令人勤奮，那麼法律就能讓他們善良。一般來說，人確實是善變、不知感激的僞裝者與掩飾者，習慣閃避危險、渴求利益；但是，技巧高超的軍師會教導他們紀律，並貫徹賞罰分明的觀念，使他們成為一支誠實、英勇的軍隊，既不會被拿來對付達官顯貴，也不會創造出暴君，因為他們是由法律與秩序賦予，背後還有本城、屬城市民的支持，所以絕不會隨便傷害他人。

義大利的君王、佛羅倫斯的富人都將自己脆弱的軍力，歸咎於那些不知感激、善變、難以駕馭的人民，但它們真該以自己為恥，並领悟問題不是出於缺乏精兵，而是自己本身；他們對人類的可能性格缺乏想像力，也就不了了解人民建軍的重要性。而現在，連最卑微的旁觀者也終於見識到，出身低賤的人也能磨練出高尚的情操：真正的高尚並非來自於名門血脈，而是人類的想法與努力。

之後，官員開始解釋這支鄉下民兵團如何運作，雖然他們都是士兵，但不往在軍營，而是繼住在家裡，平時也照樣維持生計，只有偶爾必要時才會現身。「政府命令數千人必須照這樣服役，如此一來，我們就不需要外國傭兵了。大家也都認為，這是佛羅倫斯政府有史以來最好的安排。」關杜奇在日記上寫道。
