# 我就是要救你罪

哲學家與文學家（他們宣稱這些布道的淵博學識，媲美大學的授課）全都在一起聽講。羅倫佐麾下的幾位智囊，例如：皮科．德拉．米蘭多拉、波利齊亞諾、費奇諾都成了聖馬爾谷修道院的常客。

紳士與窮人、雜姦者．與處女，全都被薩佛納羅拉的字句震懾住，也因為神祕的同伴情誼而聚集在一起。「所有人都難逃一死，不管是大師、青年、富人、後男美女還是強壯的人，最後都會化為惡臭與塵土。而誰的人生會留下最嚴重的惡臭？就是那些假裝遵守神聖秩序過活的人：神父願意只為了一點小錢，就赦免富人最黑暗的罪恶，同時卻用地獄之火威脅窮人，必須奉上週的生活費，來請求赦免。而你們，就跟羅馬一樣！跟羅馬一樣！整座神聖之城都散發出地獄的氣息！」

「假如上帝容許政府首腦有野心、縱欲以及其他邪恶，那我相信，祂的懲罰就不在遠處。」換句話說，暴君的时日不多了。不過，當修士提到「政府首腦」時，並沒有指名道姓，所以他的數千名聽眾可以自由猜測：他是在講一般的的情況，還是專指我們的政府、暴君、首腦？這種隱晦曖昧難辨，而且指控的力度，有時更勝於明確的字句。

不過，羅倫佐倒是任由薩佛納羅拉任意傳道，因為就是他在西元一九九〇年的時候，邀請這位道明會修士來佛羅倫斯的。不久，薩佛納羅拉的布道就吸引了大批聽眾，所以強硬的封他的口可能過於魯莽。米蘭多拉與波利齊亞諾都向羅倫佐保證，薩佛納羅拉修士是個好人，他的宗教教義也是有益的，因為現今的人們只顧著追求物質生活；多數人是出於必要，但也有人出於不健康的競爭心態，它就像傳染病一樣感染我們的社會。不管是富人、窮人，還是在兩者之間搖移不定的人，如今都已精疲力竭，所以除了物質之外，他們還渴望其他事物——偉大的城市需要偉大的道德良師，也就是上帝的使者，來補足政治領袖的智慧。
