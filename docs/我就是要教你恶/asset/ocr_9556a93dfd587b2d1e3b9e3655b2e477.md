# 我就是要教你忍

馬基維利聽完後，向上級報告：「他的語氣非常強烈。假如他說的是實話，那我們就能暫時安心，但如果是在說謊，那就更可怕了。」「西恩納位在托斯卡尼、於佛羅倫斯南方約七十二公里處，而切薩雷羅馬涅的領地，則在西恩納、佛羅倫斯的北方。換句話說，佛羅倫斯夾在切薩雷與佩嘉奇中間，實在有夠驚人。馬基維利寫道：「根據我的推斷，假如公開攻下西恩納，就會認為等待已久的機會終於到來——那就是攻打佛羅倫斯。」

幾週之後，謠言就傳遍了羅馬與佛羅倫斯，說切薩雷的軍隊已經占領丘西（Chiusi）、皮恩扎與其他西恩納的領地。聽說軍隊抵達某座城鎮時，發現只剩下兩位老翁跟一羣老婦人，其他人全都逃光了。於是士兵綁住老婦人的手，還在她們腳下點火，逼她們說出錢財的藏匿處；結果她們拒絕，最後被活活燒死。接著，士兵洗劫房屋、拆掉屋頂和樑柱、打破門窗，還把酒桶打開到處潑灑，然後點火燒光一切。

一月底，馬基維利的請求終於被聽見了：領主派了一位正式大使來宮廷，他可以回家了。到了春天，佛羅倫斯再度活在恐懼中。沒錯，維特羅佐已死，法王也不再支持切薩雷的霸業，但博日亞父子仍然在西班牙招兵買馬，因為西班牙國王看到法王在義大利占盡便宜，非常不想輸給他。與此同時，佛羅倫斯的市民代表聽到消息後，督促政府該為即將發生的戰事做準備。

有些市民很樂觀，堅持教宗已經承諾放過此城，其他人則反駁：只要跟歷山教宗比，鬍子看起來都變誠實了。而終身旗官皮耶羅，則堅定的要大家冷靜：「我們的騎兵與步兵都很精壯，人民的士氣也因此提高，所以要更努力維持住士氣。」
