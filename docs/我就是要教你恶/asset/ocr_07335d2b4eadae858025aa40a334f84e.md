# 第十三章 人民原為自由而戰，政客只想保住財產

路易這時已經鬼迷心發了，馬基維利評論：「他無論清醒時想的，還是睡覺時夢到的，全是教宗對他的惡意——但也都是他自己幻想的。現在別無他法，只能求法王別學他的死對頭那樣（心中沒有任何尺度）行事，而是慎重權衡接下來的每步行動。」之後馬基維利又覲見國王，說教宗的軍隊已經占領反叛的摩德納城；他特別指出，這次占領行動使得教宗逼近佛羅倫斯，情勢非常危急。

不久後，羅柏泰特把馬基維利叫進辦公室，跟他說：「看來，教宗陛下需要被痛罵一頓！」他一邊大笑，一邊拍馬基維利的肩膀，好像在暗示：「別擔心，我們很快就要去痛罵他了！」

正當他們要舉杯慶祝，有位畫家拿著迪．安博思主教的畫像進來；主教看起來既神氣又威風。「喔！我的恩師！」羅柏泰特大嘆：「假如您還活著，應該會在羅馬支援我們的軍隊吧！」接著他舉杯說道：「敬我們最愛的樞機主教，願他的靈魂安息，也願他於塵世的苦難，化作永恆的自由。」馬基維利一口把酒乾了。他也很懷念迪．安博思的直率作風與明確判斷，而法王就是少了他的輔佐，才變得如此迷失。

「我們所有人，都強烈感受到主教不在了。」羅柏泰特哀嘆道：「陛下不習慣注意細節，於是忽略了它們，但該提醒他的臣子，卻又沒有做到應盡的職責。」
