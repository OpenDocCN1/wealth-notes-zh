# 第七章 貧富差距下，人民寧可選擇侵略者給的自由

提出一個條約草案：佛羅倫斯須支付二十萬達克特，並讓皮耶羅復辟，否則法王將在一陣號角聲中，血洗這座城市。大多數的市民代表都覺得进退兩難，如果他們拒絕國王的條件，就會有大批民眾出來抗戰，這些民眾早就準備好保護自己，也渴望出力拯救這座城市。可是，那幅景象在城內的貴族眼中，比法軍的勒索更嚇人。

馬基維利不禁認為，這些光鮮亮麗的大爺寧可賠光銀行裡的錢、活得像奴隸一樣，也不想讓白嫩的脖子暴露在敵人的刀下。然而，只有一個人除外。

這個人就是皮耶羅・卡波尼。他平靜的說：「既然最接近基督的陛下不想跟我們和談，那我們只好用其他手段來搞定一切。你們敢吹號角，我們就敢敲鐘！」語畢，他便撕毀法軍的條約，走出會議室。他的同伴全都嚇壞了，站著好一陣子，不確定剛剛是否看錯。可是回過神之後，就紛紛響應他。

查理似乎已經察覺到，大規模的叛亂正在醞釀中。他嘆道：「唉！卡波尼啊、卡波尼，你這隻愛聽話的闍雞！」（All’Otario Claparo, vous êtes un Claparo mut！）現在這位國王也只能擺出微笑，表示願意再談。這讓馬基維利對卡波尼衷心讚揚：「他在國王面前，撕毀那份奪走家鄉自由的條約，就等於光靠一己之力，攬起了其他市民捨棄的事物。單憑這一點，你就該讚揚他。卡波尼沒有因法國的傲慢與力量，或懦弱的同伴而膽怯。佛羅倫斯之所以沒有淪為法國的奴隸，全是他的功勞。」
