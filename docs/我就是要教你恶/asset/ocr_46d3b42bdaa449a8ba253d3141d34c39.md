# 第十一章 人說狐狸狡猾，因為他識破人的陷阱欺詐

過兩天，切薩雷就再度召見他，說路易十二已經答應出兵支援、攻打波隆那。「看吧，祕書先生！」他說：「您想想看，未來我打仗的時候，會有多少法軍支援我！請您告訴您的領主，我還不打算放棄這一切。假如他們能迅速表達理解之意，我就樂意與他們當朋友；假如不能，那我只好不理他們，到時候就算我快溺死了，也絕不考慮跟他們做朋友。」
接下來的幾天，切薩雷又收到更多好消息。他麾下兩名最優秀的西班牙籍隊長——雨果·德·卡多納（Hugo de Cardona）與米蓋爾·德·科瑞拉（Miguel de Corred）、[主動]（不顧切薩雷的撤退命令）拿下了幾座遭叛軍攻擊的城鎮。這完全又是切薩雷另一次好运，而非他審慎計畫的成果。十月十二日，馬基維利親見他的時候，他得意洋洋的問候馬基維利：「你看看，現在跟我作對的人有多倒楣！」
切薩雷顯然興奮過頭了，咯咯笑說維特羅佐染上熱病，帕歐羅·奧西尼（Paolo Orsini）得到壞血病，拼命抓自己身上的血流，而奧西尼家族已經在乞求教宗的原諒——看來切薩雷依舊吉星高照，根據馬基維利在伊莫拉的所見所聞，切薩雷的權力大半憑著僥倖和運氣，絕非有什麼遠大的計畫。沒錯，他確實持續獲得法軍的奧援，但他無法讓自己的將士聽令（雖然到目前為止他們都很忠心）；擁有攻占、威嚇城市的人馬及大炮，卻似乎缺之贏得民心的政治技巧。這樣看來，他有能力在義大利或其他地方，建立一個持久的國家嗎？這端看他的品德而定 對於馬基維利來說，每個政治家都得接受這個真正的考驗：好運能幫你攻城掠地，品德能幫你保住地盤。
