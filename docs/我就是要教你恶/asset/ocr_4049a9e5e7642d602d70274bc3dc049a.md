# 第三章 爸爸欠稅，家族黑五類，怎麼翻身？

湯馬索不只是第一市民，也是所有第一市民中的最優秀者，他的審慎與權威不只聞名於佛羅倫斯，連全義大利的君王都知道。他答道：「你說這是大勝利，在我看來卻是大失敗。假如你靠協約與協議贏過沃爾泰拉，就可以從中得到優勢與保障。但既然是你用武力掌控它，那麼在動盪之際，它一定會帶來弱勢與麻煩；而在和平之際，它則會帶給你消耗與損失。」

羅倫佐從奮奔的青年，成長為成熟的領袖，被奉為「偉大公」（in Magnifico），但他在馬基維利的《佛羅倫斯史》中，依舊是一位複雜而矛盾的角色；他擅長散發出「虛假的善意與光彩」，掩蓋自己暴虐的本性，而這也成為這類政治家的最佳範本。

# 家族欠稅、父親低調，馬基維利求官無門
