# 第六章 如何判斷一個領導者的功過

+   1 藝大列东北部城市。
2 天主教托鉢修會的主要派別之一。

薩佛納羅拉的祖父與父親都是費拉拉的宮廷醫師，所以他在富裕的家庭中長大。不過，他厭惡宮廷生活，因此年紀輕輕就遁入修道院，尋找更深層的真理。之後，他來到佛羅倫斯，發現這座城裡的人受到財富與世俗野心駕心，而且看起來似乎不擔心自己的心靈狀態。不過在這當中，有越來越多出席薩佛納羅拉的布道，流下悔恨的眼淚，不斷渴求他對他們說：「佛羅倫斯人，回到基督最簡單、最簡樸的生活，並且替其他人指引正途吧！」連貴族的妻小，甚至是貴族本人，都會不斷回來聽講，在群眾中爭奪最好的位置，讓薩佛納羅拉責罵他們與其同類：「你們這些商人、銀行家，以及被金飾珠寶壓到喘不過氣的貴婦們，總是認為錢可以買到一切。你會付錢給畫家，把你最愛的自己與兒女畫成聖人。難不成你真的相信，聖母瑪利亞的衣裳跟她的畫像一樣？拜託你們抹掉這些淫穢的畫像吧！與其累積財富或打造巨大的宮殿，還不如把自己的性命託付給基督。」
這位「窮人的守護者」，在所有階層中都吸引到大批聽眾。他說：「富人說，窮人遭受苦難只能怪自己，但這是錯的，因為富人會剝削窮人，令他們作惡，還迫使他們生病、偷竊與賣淫。你認為有钱人會私下做善舉、扶助窮人？請再仔細想想吧！富人野心勃勃的計畫，反而令窮人更窮。這群大户用低價，買了窮人的土地與店家，等於是利用別人的貧窮，誇大自己的虛榮與奢侈。惡魔會利用權貴壓迫窮人，讓窮人無以為善。」
