# 我們！

馬基維利日後指出，不管這般恐懼是真是假，民眾都找到理由來質疑維特利的善意——就算他是全世界最誠實的人也一樣。一個傭兵再怎麼值得信賴，都會因為其工作的本質而被雇主懷疑。因為，他不是為自己的祖國打仗，所以他既不受這個國家，也不會為此國的勝利冒險。他唯一想把仗打好的動機就是薪水，可是就算打輸了，薪水也還是照領。假如一個人是為了錢打仗，那麼當第三方不希望他的雇主贏，因而開出更高的價碼時，他鐵定也會被收買。

但傭兵隊長還有個最讓人懷疑的地方：假如他們贏了，就有可能將勝利大軍掉頭回來，攻打雇主的國家。事實上，義大利近期的歷史就出現了幾個令人擔心的例子。像佛羅倫斯就沒忘記斯福爾扎王朝的創始者──卡特琳娜夫人的祖父弗朗切斯科（Francesco），就是傭兵，被米蘭雇用來對抗威尼斯。結果他不但打敗威尼斯軍，還順便征服了米蘭，讓自己成為公爵。

如今，佛羅倫斯請來了維特利──最謹慎、名氣也最響亮的傭兵，但他不管做什麼都得不到民眾的信任。假如他攻打比薩失敗，他們就會懷疑他收錢放水；假如他打贏，就要祈求他大發慈悲了。因為他們沒有自己的軍隊，所以，正如馬基維利不久之後所說，不管哪一種結果，雇請傭兵的做法都讓這座城深陷危機。

況且，佛羅倫斯付錢請外國人打仗，但他們的敵人（比薩）是準備要為自己而戰，而且只靠自己。馬基維利說，比薩人的決心與自信，讓打算征服他們的人自尊心受損。比薩人一直記著過往的自由國度，這些記憶宛如失去摯愛般的敏感與苦澀，全部點滴在心頭。全盛時期的比薩曾經容納了五萬人以上，比同時期的佛羅倫斯還多；但到了西元一四九四年，也就是臣服了一百年之後，人口只剩下一
