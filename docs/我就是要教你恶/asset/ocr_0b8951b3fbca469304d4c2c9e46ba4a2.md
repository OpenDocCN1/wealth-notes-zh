# 第十章 勸諫時，得把自身想法說成「消息來源透露」

但馬基維利不太想當法國人。這段期間，他草草記下一些怒火中燒的格言，抱怨一點都不友善的東道主：

法國人愛錢更勝嗜血。

逆境時，他們卑躬屈膝；得勢時，他們傲慢無禮。你如果能撐過他們第一波怒火狂攻，就會發現他們憂鬱消沉、完全提不起勁，就像嬪兒們一樣膽小。

這些話主要是在損那些宮廷內的男爵與樞機主教，以及戰場上的指揮官。即便他討厭這些法國紳士（起碼跟義大利紳士一樣糗），也還是對他們的組織技巧聊表敬意。這個「流動式宫廷」，正是法國良好秩序所產生的奇蹟，而馬基維利把它記錄下來（其實他什麼都記）——義大利人（起碼佛羅倫斯人）真該從他身上學習一、兩招，因為國王帶著四百位弓箭手，其中有一百位是蘇格蘭人；他的步兵衛隊則由一百位日耳曼人組成，他們身穿國王侍從專屬的緊身衣褲，負責提供移動式宮廷的落腳處，而且做事非常有效率，當宮廷裡的大批人馬抵達新地點時，會發現住處早已完全安排好——連享樂用的「小姐」都準備好了。

此外，為了消除其他房客與旅館老闆的不滿，他們會支付一筆舉國通用的公訂關稅，而且每天都固定支付一點房錢，並特別指示每個房間都要有一張床與一張沙發；每位房客每天都要支付一筆固定費用，用來更換寢具與採購調味品。而寢具每週最少要更換兩次，房間要掃乾淨、床也要鋪好。
