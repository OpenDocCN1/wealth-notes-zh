# 我就是要教你惡

僅對米蘭主張統治權。然而，此舉等同向法王宣戰，因為路易國王是米蘭的現任統治者。佛羅倫斯非常仰賴法國盟友，因此這則消息讓他們非常憂心；皮耶羅旗官本來想派馬基維利擔任使者，卻遭到否決，只好改派大家支持的年輕貴族維托利。除此之外，教宗猶利二世基於對法國的敵意，選擇在背後支持日耳曼，使得兩方的衝突一觸即發。於是，在眾人強烈反對下，馬基維利收到祕密指示，前往馬克西米利安的巡迴宮廷，與維托利會合。

通過倫巴底（Lombardy），s的時候，馬基維利被法國官員攔下，受到嚴厲的審問—佛羅倫斯政府對皇帝的立場為何？為了保險起見，馬基維利銷毀了身上所有的官方信件（包括藏得很好的一份）。接著，他在南提洛（Sömiatal Tro），6的波札諾城（Brga），找到皇帝的宮廷與維托利；他們透過中間人觀玩了皇帝幾次之後，寫了幾封信寄給上級，其中有些訊息都特別加密碼過。

最常規的訊息加密方式，就是密碼。寫信的人會先用日常語言寫下訊息，再把每個字母換成不同的字母或符號，藉此轉為密碼。其中，密碼「金鑰」是由佛羅倫斯總理署掌握管掌，它得先由公證人背書其真實性，再鎖進保險箱裡。因此，旅行中的使者必須將金鑰背下來，或是把它藏在身上較安全的地方。在寫密碼信時，可以就想保險密的部分，加一些兒扯淡或日常瑣事，以誤導想破解的人：

十字戰爭官大人⋯⋯Io bo bo ba法H115600⋯⋯⋯⋯2 03 795953⋯⋯⋯⋯這實在相當愚蠢，對著相信世間有美德的人「打蛋蛋」（Beatino tlo beast），7⋯⋯⋯⋯不斷有士兵來到此地，有時成雙成對，有時則一次來四位到六位步兵，之後全都要派去特倫特（Trent）。8人數超乎大家的預期。
