# 第六章  如何評斷一個領導者的功過

# 相信梅迪奇家族？抑或支持薩佛納羅拉？

隨著十六世紀將至，佛羅倫斯人眼前出現兩條救贖之路。第一條是梅迪奇家族的機運，他們以昂貴的代價，換取與梵蒂岡之間的關係；羅倫佐最近才剛把女兒瑪德蓮娜（Matilda），嫁給諾森八世（Innocent VIII）的兒子，以說服這位教宗讓他的青少年兒子——喬凡尼、德·梅迪奇擔任樞機主教。對於這件事，馬基維利挖苦的評論道：「一個男孩在十四歲就能爬到這麼高的位置，還真是史無前例！就像是一道具通天堂的階梯，讓他們家能夠高過俗世的凡人。」

至於第二條路則是薩佛納羅拉，他指引人民往完全相反的方向，遠離金權王朝、大銀行家的宮殿，以及腐敗到骨子裡的羅馬教廷。就像羅倫佐爬到權力過高的地位，薩佛納羅拉也在佛羅倫斯的政治圈異常突起，這兩人對於馬基維利的政治思想都產生深遠的影響，並形塑了他的未來生涯。

西元一四九二年三月，十六歲的喬凡尼正式獲准加入樞機團（Sacred College of Cardinals）。他在菲耶索萊得到紅帽s之後，騎著驢子進入佛羅倫斯，大街小巷、家家戶戶都充滿著喜悅之情。豪宅與店家的窗戶上高掛寫著「帕萊」（Pallo）的旗幟。以往從來沒有任何佛羅倫斯籍的樞機主教，受到此等待遇，好似他是外國君王或教宗一般。
