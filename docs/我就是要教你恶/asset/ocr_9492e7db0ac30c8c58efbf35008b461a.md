# 我就是要教他惡

然而，《曼陀羅》中的陰謀者以及盧克雷齊亞，跟上述高潔的古羅馬人天差地遠。布魯圖斯的陰謀是要替女子的貞潔復仇，反觀佛羅倫斯這些人的陰謀，卻是要侵犯女子。羅馬的盧克雷齊亞受到玷汙後，屈辱難當，寧願自殺也不願苟活，如此高尚的情操，使她之後成為新共和國的象徵創始者。可是在《曼陀羅》劇末，佛羅倫斯的盧克雷齊亞卻失去妻子的貞潔，從此過著暗中通姦的生活。

《曼陀羅》就跟《君王論》一樣，呈現各種有創意的詐欺手段，就像送給觀眾一面照妖鏡，讓他們瞧瞧虔誠與體面的表象背後，藏了什麼真相。有幾個觀眾或許會猜想，卡利馬可假扮成醫生、使用有毒的解藥，跟佛羅倫斯那群自命為「衰敗的共和國救星」之人，是否有共通之處？而且，「梅迪奇」原本的意思就是「醫生」，與主角假扮的職業一樣；當然，也有可能只是巧合而已。而盧克雷齊亞的丈夫尼西亞閣下（Messia Nigra），聽完卡利馬可這庸醫的提議後，半信半疑的反駁：

昨晚我跟幾位醫生聊過。其中一位說我該去聖菲利波（San Felippo）、另一位說我該去波雷塔（Portella），最後那位說我該去維拉（Villa）。他們對我來說，就像一群醜陋的鳥兒（Uccellai），也被拿來形容帶來惡兆之人）。

坦白說，這些醫生根本不知道自己在做什麼。

假如，戲中角色會時不時表達出馬基維利的心聲，那麼鐵定是由被戴綠帽的丑角—尼西亞閣下負責這個部分。因爲他的名字和抱怨，都讓人聯想到作者本人。
