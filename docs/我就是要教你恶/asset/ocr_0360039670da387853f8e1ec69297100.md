# 偽裝的友誼難長久，閹雞拯救佛羅倫斯

一週過後，這種集體偽裝出來的友誼終於破局了。年輕人開始在法王過街的時候，模仿駝背來挑撥他。當地人與士兵發生了幾場小衝突，雖然都被平定，但佛羅倫斯各階層的人都受夠了，他們準備背水一戰。男男女女抄起手邊的武器，在每個街角堆起木頭，這樣就能立刻在街上設置路障。

十一月二十四日，所有民眾把自己鎖在房屋裡，有些人甚至開始從窗戶向法軍扔石頭。法王只好待在梅迪奇宮裡，不敢像平常一樣去領主管用餐。

有人說：「我們的勝算太低了！」他們有兩萬人以上的大軍，我們卻只有幾顆石頭跟幾片木頭而已！」而馬基維利則在《君王論》中，解答這項疑惑：「為什麼大衛覺得有機會戰勝歌利亞（Goliath），？因為他打從心底為自已而戰，而且一旦知道對手比他強得多，他就更努力的打；更重要的是，他用自己的破爛武器戰鬥。當他拿起掃羅王（Saul）給他的武器，頓時發現鬥魂被這些借來的武器扼殺了。所以，他寧可用自己的彈弓與刀子應戰，就這樣把巨人給殺了。']
