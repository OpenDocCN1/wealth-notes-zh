# 第十五章 不當官怎麼改變國家？寫作

這座城內，每個人身上都有一堆屎，而且完全不重視品德。我可是拉肚子拉到快脫肛了，才終于學到一點教訓。告訴你吧，假如靠品德過活，那我只能在寒冬中挨饑、受凍啦！
在城內沒有地位的人——甚至是像我這種地位的人，連狗都懶得吠。但我不在乎別人怎麼想，也不依靠任何人。話雖如此，我還是希望大家別亂傳我的話，否則我會被課重稅，或是猶如芒刺在背！

結果，這齣喜劇大受好評。這位作家五十歲，瘦弱蒼白、頭髮比七年前失勢時更灰白了些，但其他地方都沒改變；他步上舞臺，朝觀眾鞠了個躬。回顧過去七年，馬基維利可以說自己沒有處度過危險，但他沒辦法靠自己賺錢，也無法在公爵舞臺上活躍；不過現在，至少《曼陀羅》替他贏得大眾的關注。他的劇本和身為劇作家的名氣，很快就傳遍了全義大利；良教宗希望這齣戲能在羅馬上演。而馬基維利與他的朋友則開始擬定計畫，把這次成功當成墊腳石，賺進一點錢與獲得些政治恩惠。

西元一一四八年十月，也就是羅倫佐的婚宴過一個月後，羅倫佐在蒙泰菲亞斯科內（Montefiasco）會見叔叔良教宗。此次參訪讓原本盛傳的猜測又甚囂塵上，甚至在他從法國回來之前，許多人就把擔心他會請求教宗允許，讓自己的權力更加絕對。議言指出，法國王室已經同意這項計畫，因為羅倫佐的妻子有法國貴族的血統，而且羅倫佐也極力表現出想守護法王的利益。
編年史作者對於羅倫佐公開想討論什麼事，出現了不同的記載。菲利波·德·泰爾利（Filippo Tedini）
