# 第十章 勸諫時，得把自身想法說成「消息來源透露」

無關也要寫，因為再小的事情都可能至關緊要！
其實，馬基維利還滿喜歡隨時收集情報的，如果他有錢的話，當然樂意多寄一些消息回去。日後，他建議一位出使西班牙的同胞：「出發之前，不要收集出使國的情報，還要儘可能掌握義大利境內的事件。但你收集到的情報，可能有對有錯（而且就算現在誤判，未來還是有可能發生），這就要靠你自己判斷、權衡了。你可以善用最近真相的情報，至於其他情報就略過吧！謹慎的外交官，每天都會記錄下學到的事情，接著花時間審視各種消息與謠言，再花八天至十天的時間，從龐大的資訊中挑出最合理的內容，集結成一封信。」

所以現在，馬基維利決定儘可能多打探消息（反正他也沒別的事可做），其中第一個要摸清楚的，就是義大利人在搞什麼鬼。宮廷裡四處都有義大利人，每個都對法國頻頻示好、巴結法軍，只是諂媚的程度不同而已。

馬基維利寫信給領主，說這裡有一位維特羅佐派來的使者爆料：不管教宗跟他兒子最後是否向佛羅倫斯宣戰，維特羅佐都打算血洗這座城市，替自己的亡弟報仇。

說到教宗，歷山六世也派了幾位大使，向法王施壓，希望他准許切薩雷繼續四處征伐。但是，法王當初薩雷是小鬼頭玩弄，這樣博日亞父子，就不會妄想自己的權力能與他匹敵。這裡大多數人都說，法王覺得幫這對父子拿下弗利與伊莫拉，已經是仁至義盡了，不過他目前還是會盡力滿足教宗的渴望。

歷山六世原名為羅德里哥．博日亞，兒子是切薩雷．博日亞。
