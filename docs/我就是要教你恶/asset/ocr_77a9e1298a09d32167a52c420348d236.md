# ## 致謝

寫本書對我而言是全新的挑戰。有許多人替我維持進度，使本書順利出版。羅斯蒙·巴雷特 (Rosemund Bartlett) 散發我展開政治哲學的冒險，也讓我嘗試寫出一本更接近傳記的馬基維利書籍；我的經紀人凱瑟琳·克拉克 (Catherine Clarke) 是最棒的，無須多言；文倫·連恩出版社 (Allen Lane) 的編輯——湯姆·潘恩 (Tom Pane) 與約瑟芬·葛雷伍 (Josephine Greywood) ，依照我的期望，讓這本書變得更好讀，可謂勞苦功高；如果還有任何錯誤，由我負全責。

感謝伊恩·夏皮洛 (Ian Shapiro) 提供豐富的佛羅倫斯研究文獻——由耶魯大學麥克米蘭中心 (Macmillan Center) 資助；理查·杜古德 (Richard Dungood) 的銳利目光以及編索引的技巧，提升了最終成書的品質。此外，我還要感謝艾倫·連恩出版社的沙拉·黛 (Sarah Day) 與伊莎貝爾·布雷克 (Isabel Blake) 、W.W.諾頓出版社 (W.W.Norton) 的編輯瑪莉亞·瓜那史切利 (Maria Gunnaschelli) 與其助理奈森尼爾·丹奈特 (Nathaniel Dennett) ；我的從意大利文翻譯員——羅倫佐·麥透利 (Lorenzo Matteoli) 、伊蓮娜·貝泰爾 (Ilena Bertel) 、艾美·布洛克 (Amy Bloch) 、安德莉亞·桂迪 (Andrea Guidi) 、約翰·納傑米 (John Najemy) 、格雷琴·班納 (Gretchen Banner) 與李德·班納 (Rreed Banner) 。最後一如往常，我要感謝愛人派屈克 (Patrick) 。
