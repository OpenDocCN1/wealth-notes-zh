# 西

元一四九一的冬天實在太冷，阿諾河都結冰了。白天大家在河上玩球，晚上則在冰上生火。佛羅倫斯的北方，從菲耶索萊到穆傑羅（ Mugello），橡樹與栗樹都因為冰風暴的關係連根拔起，橄欖樹與果樹的樹枝也都被折斷。木頭斷裂的聲音之大，使得剛好經過的人以為世界末日要來了。接著，冬天褪去，又到了舉辦嘉年華的時刻。鄉下人穿上最稱頭的衣服進城，暫時把煩腦拋在腦後一、兩天；年輕人成群在街上徘徊，渾身散發著肉欲；遊行隊伍與盛大的表演伴隨著鼓聲、笛聲與喇叭聲，好不熱鬧。

這次嘉年華的花車比以往都少。如今羅倫佐親手計畫最精緻的表演，連劇本都自己寫，所以就連盛會中最不敬的部分都重新調整過，以尊敬這位「主子」（Signore）。不過，人民倒是很喜歡這位領袖，既能寫出與農民、男性生殖器有關的下流歌曲，也能用拉丁文寫出在豪門間流傳的高雅詩句。

其中有一場表演，氣色紅潤的男人扮成農夫的妻子，向佛羅倫斯的女士叫賣鄉下的農產，並且用拉丁文告訴他們「該怎麼吃」（這是羅倫佐寫的）：

首先將這顆水果拿在手上。
剝皮使其露出果核，並張嘴咬它。
懂方法的人，就完全不會弄痛它。
