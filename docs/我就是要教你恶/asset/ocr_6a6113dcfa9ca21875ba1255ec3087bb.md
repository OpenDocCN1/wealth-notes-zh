# 我就要教你惡

路程。白天爍爍難耐，他得忍著反胃在馬背上，彈下，還有蚊蟲飛進他的眼睛；晚上只能在硬床上小睡片刻，老鼠的吱吱聲與攀爬聲不絕於耳。

有天早上，馬基維利發現他的新靴子被咬爛了，還滿是大便。而裝衣服（觐見國王用）的行囊也被咬穿，裡頭還被幾群老鼠占據。這次他終於忍無可忍，對看顧衣服與行李的僕人大罵，因為他們最起碼也該知道，靴子要放在高處的架子上，而非地板上！馬基維利將這些鳥事都詳實記錄在《出使法國須知》（Notes for One Going Ambassador to France）裡，告誡讀者要特別小心食物與老鼠。他寫道：

> 「這種動物既小隻又可笑，但給我了我很慘痛的經驗。'

更糟的還在後頭。就在他們進入法國後不久，有件事迫使馬基維利兩人必須停下腳步，接下來的路途中因而延誤。馬基維利兩人寫信給領主，報告這件「出乎意料的事故」，卻沒說發生了什麼事，只說他們必須替換從佛羅倫斯帶來的所有東西：衣服、馬匹與僕人。也許他們在路上遭搶，或是粗魯的僕人．在偷了馬匹與財物後逃之夭夭。不管如何，七月二十六日，他們在失去行李的窘境下抵達里昂，卻被告知宫廷已經遷至其他省城了。

真是個天大的壞消息——代表兩位經驗不足的使者，要忙的事情可能超乎預期。假如他們沒被延誤，就能早點遇見一、兩位與國王、國王顧問都維持良好關係的佛羅倫斯大使，並在他們的陪伴下，拜訪位於里昂的宫廷。而且，大使也能帶他們更順利的走訪鄉下，還能幫忙處理各種尷尬場面，並負

責會議中的各項談判。不過現在，他們恐怕得自己扛下這次的外交行動了。
