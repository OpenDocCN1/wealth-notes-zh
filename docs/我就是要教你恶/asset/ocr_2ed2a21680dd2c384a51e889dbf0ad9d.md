# 我就是要教你惹

大家都記得，羅倫佐與皮耶羅的妻子都出身於名門奧西尼（Ozoni）家，她們都反共和國，並造成動盪的世襲關係；不過，卡特琳娜跟她的子孫都被認可為佛羅倫斯市民，所以她可以嫁給喬凡尼。

卡特琳娜雖然是個女孩子，她的父親卻經常帶她去打獵，因為他認為，孩子的教育除了拉丁文與詩詞之外，也要習武——這比較像是知名傭兵在教小孩。二十歲的時候，她雖然懷孕七個月，卻全副武裝，騎馬橫越台伯河（Tiber），指揮丈夫（吉羅拉莫·里亞里奧）的軍隊攻占教宗的要塞——聖天使城堡（Castei Sant'Angelo）。

當恩道教宗過世之後，里亞里奧擔心自己的貴族頭銜，以及財產都被新教宗奪走，於是在選新教宗時，他在卡特琳娜的協助下，保住了一切財產。里亞里奧被暗殺的時候，密謀者將年輕的卡特琳娜與她的孩子（當時她有六個小孩，包括九歲的奧塔維亞諾）抓起來關。不過，他們萬萬沒想到，攻下弗利城竟然那麼困難，因為城主與他的手下都對伯爵夫人忠心耿耿，拒絕把這座城市交給篡奪者。

密謀者害怕自己得不到民眾的支持，只好求卡特琳娜說服那些人投降。她回答：「我盡力而為，但你們要讓我一個人進城跟他們談。為了表示誠意，你們就把我的孩子當人質吧！」於是，刺客就讓她進城。

根據馬基維利的記載：「她一進城，就用各式各樣的刑罰替丈夫報仇，還威脅陰謀者納命來。當密謀者威脅要殺掉小孩的時候，她居然猛力掀起裙子，露出私密處大喊：『來呀！反正我有本錢，可以再多生幾個！』」然後，陰謀就這樣瓦解了，卡特琳娜的孩子都飽受驚嚇，但性命無虞。她將任何跟此次陰謀有關的人、教宗旗下的總督、覺得可疑的教士全部都打入了大年；密謀者家族中的女性，則全被禁錮、監禁起來；接著命令手下劫掠、燒毀犯人的房子，並將他們的財產分給窮人。
