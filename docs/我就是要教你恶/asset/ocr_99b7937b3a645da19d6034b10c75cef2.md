# 西
元—五〇二年十月初，馬基維利出差前往羅馬涅。他只告訴瑪莉塔：『我這趟要去八天。』因為切薩雷又有動作了，而且比之前更直接威脅背到佛羅倫斯。九月，市代表委員召開一個危機處理會議，決定等切薩雷的新宮廷一安排好，就派一位「優秀人才」拜訪他。表面理由是恭喜他近期打勝仗，同時確保，佛羅倫斯的傭兵能安然通過他的地盤，前往黎凡特；但實際上，這名使者必須盡其所能，判斷切薩雷對佛羅倫斯有何居心，並試著讓他遠離這座城。於是，有人推薦馬基維利。

其實當年夏天，馬基維利與弗朗切斯科主教一同前往烏爾比諾時，就已經跟切薩雷交手過了，而且他還把切薩雷說的話詳實寫在信上。主教也支持讓馬基維利拜會切薩雷，因為他認為馬基維利非常擅長判斷人心，既不會被三寸不爛之舌所騙，也不會被對方的壓倒性勝利給震懾。除此之外，馬基維利能很快抉摸透切薩雷的本性，讓上級知道：這條伙是有辦法對付的。

先前，在烏爾比諾與切薩雷會面時，他站在弗朗切斯科主教身旁。會面地點在某宮殿內的金色大廳；這座宮殿與其城市都是切薩雷靠背叛盜取而來。馬基維利在會談中全神貫注，記下他聽到的每一個字，這樣他與主教坐下來寫信的時候，就能準確記錄會面時的對話。切薩雷說：「我很清楚，貴城並不怎麼喜歡我，還罵我是刺客。」

主教立刻否認，但這位年輕的公爵（年紀幾乎只有主教的一半），卻露出睿智的笑容，謎起他的小眼睛。「我很清楚。」切薩雷又說了一次——這是他的口頭禱。「你們很謹慎也很了解我，所以就就長話短說吧。我不喜歡你們的政府，對它也沒信心；這個政府一定要換掉，這樣貴城才會信守跟我的承諾。假如再不換的話，你們很快就知道，我不會讓貴城精心如意。」
