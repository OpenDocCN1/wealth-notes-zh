# 第九章  厲害了我的國，只算計、沒道義

蘭，協助盧多維科公爵防禦敵人。除了他們之外，還有五十個弩手同行，陣仗也同樣驚人。

對馬基維利這個外人來說，他們看起來像是支紀律嚴明的頂尖部隊。之後他四處打聽才知道，原來這批人為卡特琳娜親自訓練與命令。看來夫人不只騎勇善戰，還懂得用兵；她知道謹慎訓練與秩序的重要，單憑士兵的凶猛與頑強是成不了大事的。

但想成為好君王，光具備全方位的軍事技巧還不夠。根據馬基維利收集到的資訊，他很懷疑卡特琳娜的政治技巧能否媲美她的武勇，因為她的統治並不得民心。人民抱怨，她不斷對她懷疑的批評者課徵重稅（或使用其他更糟的方式）；鄉下人不相信她會在戰爭之際保護他們，因為她跟米蘭走得太近，而米蘭與法國是敵對狀態。

她的要塞確實堅固，把守的騎士也很忠心，這的確不容易。大家都還記得幾年前，有人起義反抗她的丈夫，她很幸運的逃進要塞，並保住性命。但她會一直都這麼幸運嗎？假如有個強大的異邦人來到此地，答應人民把她趕走呢？「讓君王在國內屹立不搖的，不是要塞，而是人民的意志。所以，我总是忍不住怪罪那些信任要塞、卻沒考慮到民怨的人。」馬基維利說道。

幾天后，領主終於寄信來了。他們願意調整合約上的薪資，從一萬達克特調升至二萬兩千達克特。

於是馬基維利趕緊衝進宮裡，向夫人報告這個好消息。

卡特琳娜很滿意，也願意接受這份新合約。不過，她接著又提出一個更大的要求：「為了讓奧塔維亞諾有個正當理由，派遣到你家大人的麾下，為了表示你們比之前更信任我的統治，我覺得佛羅倫斯應該要正式立約，捍衛我的領土完整。我當然相信你家大人，不須正式結盟或訂下義務就會這麼做，就跟過去一樣；但為了我的榮譽，我還是非常希望能有正式的承諾。我相信他們不會拒絕我。』
