# 我就是要教你忍

# 四

元一五十六年，馬基維利的《君王論》雖然尚未出版，不過書稿已經在朋友之間流傳開來，而且還傳到更遠的地方去。維托利是否有進行那掙彎抹角的計畫，把這本書獻給羅倫佐、或是其他梅迪奇家族成員？我們並沒有這方面的紀錄。而且更可惜的是，我們也不知道維托利或馬基維利的其他朋友，對這本書的想法如何？他們是否覺得它能讓作者復職？

但只要想到，此時梅迪奇政府多麼不信任馬基維利，你就會覺得，不太可能有人在考量馬基維利的利益後，還鼓勵他把這本書獻給佛羅倫斯的統治者，畢竟書中狡詐的兩面寫法背負了太多風險。讚貶的馬基維利祕書，提供建議給有理想抱負的君王，教導他們如何爬上共和國的權力頂點；他承認，確實有不少人利用暴力與欺騙爬到頂點，而且還沒有受到懲罰。例如：用得體的外表粉飾內在的野心；用錢就要用得慷慨、大方；賄赂是取得權力的最簡單方法；盡可能遊走於貴族與平民之間的野支持，這樣一來，他們很快就會把你拱上雲端，讓你取得絕對的權力。不過馬基維利指出，選擇其他比較乾淨、文明的方法，能夠維持住名聲。

所有建議都是一本正經的口氣，但還是有些露骨的影射梅迪奇家族的行爲——因為他們的作風正如馬基維利所言。接下來，就是平靜卻鄭重的警告：“當然，一旦你爬上了頂點，就得面對一大堆新問題。雖然共和國被竊取了，但人民永遠不會忘記他們之前的自由，也會開始恨你。但別擔心，假如你夠幸運，取得的國家是基於『人類難以理解』的理由而存續下去，那麼掌權就輕鬆多了。我再明白一點，那就是基於『基督教國度』的理由；這些國度總是既安全、又快樂，因為根本不需要人類的審慎來支撐。”
