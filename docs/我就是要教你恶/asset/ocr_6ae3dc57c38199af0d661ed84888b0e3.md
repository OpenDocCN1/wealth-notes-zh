# 敵對勢力攻擊馬基維利

西元一五〇一年十二月，菲莉波結束流放之後，請求聽見佛羅倫斯领主，而領主被他說的話嚇呆了：有位與他同行的女士，謠傳正在策劃陰謀，打算刺殺皮耶羅旗官。除此之外，還有個從波隆那來的男人，已經向佛羅倫斯城內的梅迪奇親屬提議行刺，並獻上各種暗殺方法。自從菲莉波去年吃到苦頭之後，就盡量不讓自己遭人懷疑，行為處事更加透明。他坦承，有幾個佛羅倫斯人確實在煽動外地的陰謀者，但他不願意透露姓名。

這個謠言很快就傳開，說菲莉波一到這裡陰謀，就立刻去見他的岳母—阿方西娜．德．梅迪奇，跟她爭論該怎麼辦。但她與喬凡尼主教對此事到底知情多少，目前依舊不明。此案沒有任何佛羅倫斯人被起訴，但政府之後就公告了嚴格的新法律，懲罰與梅迪奇家族打交道的人。馬基維利從很久以前，就開始協助擬定這些法律；自從斯特羅齊家族與梅迪奇家的婚事之後，他就不停的敦促旗官通過新法。

與此同時，想把馬基維利踢下臺、不讓他發揮影響力的運動，也越演越烈。西元一五〇九年十二月二十日，一位蒙面人在兩位證人陪同下，找上某位政府公證人，聲稱馬基維利目前擔任的這些官職，已經觸法了。「信上說因為你父親的緣故，所以你並不能擔任這些官職。」這或許在暗示貝納多欠稅，但也有可能在講貝納多是私生子的謠言。
