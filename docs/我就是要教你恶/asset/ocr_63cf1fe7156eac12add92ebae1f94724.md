# 第十章    勸諫時，得把自身想法說成「消息來源透露」

接下來，換迪．安博恩開口：「你們的長官被綁走，誠然不是件愉快的事。但你們也知道，瑞士兵就是愛勒索人；既然雇用了他們，就早該有心理準備。否則這次圍城失敗，除了陛下 的部隊有過失之外，你們的領主也難辭其咎。」馬基維利和卡薩想要反駁，但國王直接打斷他們：「翻舊帳沒什麼意義。既然兩位都來了，我們應該討論這場比薩戰役要怎麼打下去。我為佛羅倫斯的諸位大人付出甚多，相信他們一定不會因此打退堂鼓。」

卡薩答道：「我們沒有接到這種命令，因為我們不算正式的大使，只是這起不幸事件的見證人。如果單純問個人意見的話，我們認為佛羅倫斯市民眾已經相當厭戰，哀悼不斷加上敵人衆多，都讓他們筋疲力盡。人民已經完全喪失信心，也沒有力氣再發動戰爭了。不過……」他換了比較輕快的語氣，繼續說道：「只要陛下替佛羅倫斯恢復比薩，我們的一切付出就算有了確切的收穫。如此一來，想必我們的領主就會公正、充分的補償陛下，所付出的所有心血。」

根據馬基維利兩人下午回給上級的報告，當國王與其他在場人士聽到上述回答時，全都驚叫出聲，心中暗罵：「你們打比薩，還要全靠陛下出力？這哪門子鬼話！」路易沉默了一下，之後冷冷的說：「你們應該很清楚，如果我自己想要比薩——更別說其他托斯卡尼城市，我早就先打贏了。」他繼續冷冰冰的說：「不過呢，我當然更希望履行條約上的義務，讓比薩回歸你們的統治。」
