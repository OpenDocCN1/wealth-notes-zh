# 第十一章 人說狐狸狡猾，因為他識破人的陷阱欺詐

耶羅·德爾·尼洛（Pío del Río）也寄來一封信，其說法與托圖差不多：「我跟病患一起說話、吃飯與睡覺的次數，大概夠我死二十次吧！我很想說，這種事在人的一生當中總會發生個幾百次，假如你光是這樣就被嚇倒了，那你根本就不叫馬基維利！」

「沒錯！我就是在此勸你，因為你需要被人激，所以請你像個男人吧！」尼洛不客氣的寫道，不過他最後又補充：「好啦，告訴你一個令人振奮的好消息：你有兒子了！我從來沒看過這麼活潑可愛的小嬰兒！」一看到這裡，馬基維利頭上的愁雲慘霧一掃而空。小嬰兒取名為貝納多，以爺爺的名字命名。接著，他又打開更多信，字裡行間全都是祝賀的話，把自己幻想要的名譽全都「治好」了。

—位朋友寫道：「你不太真的没偷情，因為這小傢伙長得跟你一模一樣！就連李奧納多·達文西（Leonardo da Vinci）都不可能畫得這麼像！」再來又是比亞吉歌：「感謝上帝，母子均安。可是你不在家，她真的很痛苦。我的天啊！根本沒人能夠安慰她、讓她冷靜下來！」

馬基維利沒想到瑪莉塔竟然難過成這樣，反而讓他想逗逗她，於是她寫了封信給老婆：雖然這些從家鄉寄來的信，讓他再度鼓起勇氣，但他一時半刻還是回不了家，只好要求上級加薪。

「我之前都不知道羅馬物價這麼貴，但我現在說給妳聽。除了日常開銷外，我還花了十八達克特買了一匹騾子，又花十八達克特買一件絲絨上衣；一件西班牙披風要十一達克特，一件大衣要十達克特，所以我出差的總開銷是七十三達克特。此外，我住的酒館每天房錢是十卡利尼（grini）$^{12}$，還有兩位僕人和前文提到的騾子陪著我。像我這個年紀的男人，應該要力爭上游，而不是落於人後。

$^{11}$ 西班牙王國統一後的第一個國王。

$^{12}$ 中世紀西班牙大幣的一種貨幣。
