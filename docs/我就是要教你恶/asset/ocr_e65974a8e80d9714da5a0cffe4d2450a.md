# 第四章 廢利若是沒有帶點敵意，無法維持和平

時的教宗思想四世（Pius IV）、都恨透了梅迪奇家族政治，但兩人卻沒採取任何防護措施。雖然他們知道帕齊家的復意，卻不柏憂死，因為他們堅信假如敵人想顛覆政權，必定會透過政治陰謀而非暴力。所以，羅倫佐與朱利亞諾不在乎自己的人身安全，還假裝跟敵人友好。若事件發生之後，九歲大的馬基維利從別人口中聽到這個消息，那還真是個值得謹記的教訓——利用虛偽的友情，以及暗藏其中的陷阱。

本來是歡欣鼓舞的三人組，其中一位突然傳出痛苦的呻吟。「貝納多先刺穿朱利亞諾的胸膛，接著弗朗切斯科全身撞向朱利亞諾，讓他遍體鱗傷，再瘋狂痛毆他。弗朗切斯科被怒氣沖昏頭，打人的力道之大，連自己的腿都受到重傷。」「馬基維利總是忍不住描寫這種諷刺的景象，因為人之常情就是如此：當我們以盲目的怒火攻擊別人，通常也會傷到自己。

朱利亞諾死於非命，而旁觀者看到某人用刀子刺傷羅倫佐的脖子。之後，羅倫佐立刻消失在衆人眼前，在一群親信的保護之下逃進聖器室，為了安全起見還上了鎖。等到他們聽見外頭比較安靜了，才讓羅倫佐回到現場；他只受到輕傷而已。

數小時內，這個消息就傳遍了整個佛羅倫斯。「殺人犯！叛徒！」上千人湧進帕齊家的數棟住宅。弗朗切斯科一絲掛掛的被拖下床，吊死在領主教高大的窗子上，旁邊還掛著比薩大主教等人的屍體。傑考波·帕齊（Jacopo Pazzi）試圖逃亡，卻很快就被逮到並送回佛羅倫斯，受到眾人的譴責，他在朱利亞諾謀殺案發生的四天之後，也被吊死了。傑考波的屍體起初埋在祖墳裡，但不久之後他就被逐出教會，跟其他驅逐者一起埋在城牆外。
