# 我就是要教你惡

恐懼，但他如今已年過五十，期待自己活久一點根本是種奢侈。不過，他想到他還有兩個未婚的女兒，未來的生活也還沒有安定下來（不過他對女兒的嫁妝倒是投資得很謹慎），而且兩個年幼的兒子也需要爸爸的指引，這些就是他活下去的理由。

到家之後，他拜託巴托洛蜜亞替他準備一間隔離用的房間，並叫僕人請來鮑寧席格納．馬基維利（Battisterga Marchifili），他是貝納多的堂兄兄弟，年紀與貝納多相仿，也是他最親密的朋友。之後，貝納多不在一般的房間吃晚，而是直接躺在隔離的新牀上。

鮑寧席格納一來就接手醫療事宜，病弱的貝納多給他一份尿液樣本，還賞了他一枚硬幣。為了避免傳染，他們透過貝納多房間窗戶的木條來溝通。巴托洛蜜亞與十四歲的普利瑪薇拉，則在客廳焦慮的等待醫生來訪。家中較年幼的孩子早在一個月，就送到遙遠的鄉下，由巴托洛蜜亞的兄弟喬凡尼與其妻子照顧。貝納多還記得道別的情景：他與巴托洛蜜亞匯了一輛騷車，塞滿了食物、衣服與寢具，讓喬凡尼能夠顏外應付這三個小孩。貝納多答應給喬凡尼六浦多耳（Ducato）2的小麥（替小孩做麵包用）、一隻乾燥羊腿、兩瓶醋與兩瓶橄欖油，以及一點酒錢。

在接下來的幾週，許多醫生都造訪了馬基維利家，用盡各式各樣的療法。有一種汁液是治療瘟疫的常用藥物，就是將琉璃苣與牛吉草的小藍花，同砂糖一起磨碎，再摻入其他成分：海珊瑤、珍珠、寶石粉、金或銀……看患者能負擔到什麼程度。但因為貝納多很窮，也非常懷疑這些療法，因此他採用比較簡單的療法——全身塗滿藥膏，切開膿瘡讓它們流乾。醫生替他放血，給他吃帶有苦味的芦荟，以及糖类藥劑（摻了蜂蜜的芳香藥劑）。
