# 第九章  厉害了我的國，只算計、沒道義

幫他一樣，冥冥之中全都替他實現了願望。他放棄紅帽的那一天，法王路易十二就賜他瓦倫提諾公爵的頭銜。這不是因為切薩雷有什麼豐功偉業，而是想藉此舉，換取他爸歷山六世的同意：取消法王路易與查理八世（已故）妹妹之間的婚約──因為這位女孩據說不孕，還長得很醜。

如今，在歷山六世與心懷感激的法王力挺之下，瓦倫提諾（義大利人習慣用這個名字稱呼切薩雷）可能會像隻餓壞的野獸，撲向羅馬涅，拿現任統治者塞牙縫，而卡特琳娜夫人無疑會成為第一批受害者。但弗利城內，沒有人跟馬維利講這件事，他的上司在信裡也沒提及此事。他們當然希望，教宗的計畫就像薩納羅拉火葬後的油膩骨灰一樣，乾枯之後隨風散去。假如他們繼續這樣想，那不久之後，佛羅倫斯又要每天活在恐懼之下了。

馬基維利這輩子聽過不少散布恐的謠言，因此他的疑心已經成為直覺反應，使他不會過度誇大那些發生率極低的威脅。然而，在聽過教宗的相關消息，以及看過其政策後，他合理推測：教宗是不會放過羅馬涅的。假如切薩雷奉領法國、教宗聯軍攻打卡特琳娜，那麼，佛羅倫斯或許是他的下一個目標。

不過，現在他們都維持著外交假象──沒有來自羅馬的威脅；歷山教宗是最令人尊敬的守護者（不管對義大利、基督教世界，甚至對全人類來說）；卡特琳娜夫人無懼於任何人，連教宗都不怕。
