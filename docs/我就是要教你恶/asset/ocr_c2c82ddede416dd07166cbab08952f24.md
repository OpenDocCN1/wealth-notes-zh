# 我就是要救你惡

同事互助的紀錄。馬基維利告訴維托利：「這段政權交替的『快樂時光』，我們都很想念你的陪伴。最近，我們每天都去拜訪女孩子的香閤，藉此『恢復活力』。昨天我們才在珊卓·迪·佩羅（Sandra Di Rao）的家中，看到因普魯內塔聖母，搬進城內。為感謝謝上帝施恩典於枢機主教，讓他們選出佛羅倫斯出身的教宗，以及要贏得聖母的持續施恩，最慷慨的海迪奇家族贈送九件最華麗的新披風給她，其中七件都是以金色綫子編織而成——這些銀行家就跟以往一樣，有錢什麼都買得到。所以，我就在慶典上繼續無所事事，享受餘生，才會覺得這只是夢境一場。」「雖然這些字句看似樂觀，不過每個人都可以看出，馬基維利被時局的演變嚇傻了，儘管知道崩毀的舊世界已不復存在，卻還是渴望能在其他方面延續下去。馬基維利在鄉下住了幾個月之後，每次短暫重返佛羅倫斯時，都覺得自己快認不出這座城市了——以前他把它稱為『祖國』（Patria）。也許，他的父親貝納多見過這座城最壞的時刻，但當時從自由的共和國變成有一家獨掌權，其過程是逐漸演變的，而非一夕變天。除此之外，自西元一四九四年來，共和國存續的十八年間，民衆已經越來越習慣在街上挑剔政策、閒聊一些大人物的癖好，而且經貿口無遮攔。

所以，無論法律是否允許人民暢所欲言，或是對隨便散布謊言、誹謗者審判與施加懲罰，民衆都敢大聲議論；平時他們會爭論，國家是否應該保護市民，以免在公、私領域遭受言語冒犯，或冒犯是否有輕重之分。可是自從梅迪奇復辟之後，這些吵雜、情緒激動、有時還沒什麼道理的爭論，全都從廣場與酒館消失了，取而代之的是和平與寧靜。

在改變不久後，有人就因為用不敬的字眼批評梅迪奇家族，而被判放逐十年，並禁止踏入佛羅倫斯方圆三公里以內；這其實就是在殺雞儆猴，只可惜馬基維利太晚學乖了。
