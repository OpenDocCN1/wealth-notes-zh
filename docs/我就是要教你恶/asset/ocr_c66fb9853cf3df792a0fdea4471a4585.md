# 第九章  脣害了“我的國”，只算計、沒道義

一開始，卡特琳娜試圖藉由低稅率來贏得民心，因為她已故的丈夫對土地與商品都課徵重稅，才會樹立了危險的敵人。可是，當她的第二任丈夫又遭惨陰謀殺害（而且目標本來也有她），她復仇後便決定改為鐵腕統治。雖然，她在平民與外國人之間皆享有極高的聲望，可是貴族與中產階級卻滿懷那殘酷的作風，他們不滿為了資助她野心勃勃的建築計畫與國防需求，而必須繳納重稅。雖然，國防需求不斷增加是外患所致，但國內有許多人在等待時機罷黜她，也是原因之一；不過她似乎不在意。

# 希望結盟卻在邊界製造糾紛

聽過以上這些傳聞（好壞皆有）之後，馬基維利更渴望拜見這位知名的伯爵夫人，也想聽聽她的鄰國與臣民，對她的統治有什麼看法。這是他首度有機會，近距離研究一位君王風格的統治者——而不像梅迪奇硬要裝成第一市民。卡特琳娜是位成熟的君王，也是具有王者頭銜的統治者，能全憑自己的意識制定、扭曲與打破法律。況且，馬基維利這位研究對象剛好是位美女，讓這次任務又更刺激了些。

這次任務確實需要加點刺激，因為它實際上超級無趣。一年前，佛羅倫斯人雇用伯爵夫人的兒子——十九歲的奧塔維亞諾擔任傭兵隊長，協助收复比薩。不過，他才幫了一下子就中止合約，因為他抱怨薪水太少。但幾個月後的現在，卡特琳娜又希望佛羅倫斯能借助奧塔維亞諾的力量，不過開出的條件也與之前相同。而馬基維利的任務，就是要表達佛羅倫斯的善意，又要砍低奧塔維亞諾開出的薪水條件。
