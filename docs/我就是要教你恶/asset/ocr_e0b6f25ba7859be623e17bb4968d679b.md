# 第八章 法律有兩套——給自已人、給敵人

「有人說，他祈求上帝給個徵兆，藉此集結信眾，讓他們更努力守護他。看來，他似乎很怕新領主（已經選出但尚未公布）全是他的反對者。」

新領主包括九位成員，上頭還有一個政府領袖，名叫「正義旗官」（Commander of Justice），每兩個月由民眾票選一次；不過其他行政官的任期都比較長，約六個月至八個月左右。過去三年來，領主大都是薩佛納羅拉的朋友，他們替他防備教宗，即便下了封口令也能繼續布道。馬基維利暗示，假如新政府對這位修士充滿敵意，那他就玩完了。

薩佛納羅拉把人人分成兩等：上等人（也就是他自己跟他的信徒）為上帝效命，下等人（也就是他的敵手）則為惡魔效命。而他近期的講道有個特色，讓馬基維利覺得對這城市是場大災難：他的浮誇之詞，本該用來維護市間的和平，卻隨時隨流逝而挑起對立。他把整座城市分成善人與惡人、天使與魔鬼，讓這座城的靈魂身陷於神聖（甚或致命）的掙扎中。馬基維利說：「既然他都已公開宣戰了，那還談什麼和解？這就是我們跟他們的對決，必定會有一方（也就是全城一半的民眾）敗北。

薩佛納羅拉為了更加弱化敵手，指出人民間的不和，會造成暴君崛起、燒毀我們的家園。」這又是一招廉價的演說技巧，靠著危言聳聽，讓暴徒渴望「戰」。『站在我這邊發動攻勢，否則你的國家就會被劫掠！』這句話對於民眾素質尚未穩固的共和國來說，實在太有效了！「馬基維利向戰友貝奇眨了眨眼，繼續說：「可是這種話講太多，民眾也會開始起疑：雖然他們比以前更接近天堂，但他也越來越像暴君。」
