# 第十三章 人民願為自由而戰，政客只想保住財產

幾週後，馬基維利寫信給一位匿名女士，談到他對這些事件的看法。「皮耶羅旗官和那群向他提

供建議的人，全都自信滿滿、精神抖擻。儘管有人建議，該趁機讓事態往和平方向發展，旗官卻又

再推託。」

而在幾年之後，馬基維利對旗官好友、大多數佛羅倫斯市民的評斷，又更加嚴苛：「西班牙願意

做出一些退讓、不強求滿足所有願望，就已經算佛羅倫斯大勝了！」所以我們應該妥協，同意納貢

並放棄效忠法國，以換取最重要的事物——自由；它是共和國存亡，以及阻擋梅迪奇家陰謀的必要支

柱。可是，人民開始驕傲起來、拒絕與西班牙達成協議，並犯下了政治、戰爭方面最常見、也最致命

的錯誤——當人民不懂得節制自己的期望，並同時衡量自己的能耐，就死定了。由此可見，勝利、或

錯誤的勝利期望所帶來的傲慢，會令人貪圖「不確定的更大好處」，反而失去「已經確定的好處」。

果然，慘痛的代償很快就降臨了。八月二十九日，飢壞的西班牙軍開始大肆破壞，但君主不是固

若金湯的佛羅倫斯城，而是普拉托城。佛羅倫斯想讓敵軍饑到撤退，卻產生反效果——飢饞讓敵軍變

得更加暴力。根據馬基維利的記載：「西班牙人當天就占領了普拉托城，在城內恣意搔掠，還屠殺了

大批老百姓，慘不忍睹。死亡人數超過四千人，剩下的則被抓起來，然後在各種手段的威脅之下，支

付贖金。就連教堂內的修女都難逃此劫，慘遭強姦與劫掠。」

儘管佛羅倫斯城的周圍部署了數千名士兵，但民眾一聽說普拉托城的慘況之後，都開始害怕下一

個目標會輪到自己。馬基維利聽到消息後，便快馬奔回佛羅倫斯城，發現頭髮灰白的旗官竟異常冷

5 位於佛羅倫城西邊二十二·五公里處。
