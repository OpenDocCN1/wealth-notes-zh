# 第八章 法律有兩套——給自己人、給敵人

土二與他的共犯。

薩佛納羅拉最死忠的信從（包括那位日記作者蘭杜奇），當時都在修道院裡，蘭杜奇說假如他沒有從迴廊逃走，搞不好會被殺掉。之後政府宣布，只要抓到薩佛納羅拉，並将他移送當局，可獲得一千達克特的賞金。霎時間，整個局勢變了。昨天政府的軍隊還護送薩佛納羅拉回家；但今天，他與信徒就不能指望政府保證了。本來愛叫嚷的支持者，因為害怕性命不保，全都閉緊嘴巴。而他幾個主要的黨羽，則試圖躲起來。

晚上六點左右，一群人湧進領主廣場。他們衝進瓦樂利（擁護薩佛納羅拉派的領袖）的宮殿，開始燒殺擄掠。瓦樂利的太太在樓上往窗外一看，就被十字弓的箭射中，當場斃命；瓦樂利的孩子與保母也被打傷；至於瓦樂利自己，則被人從背後追殺，最後鏃刀劈開了他的腦袋。痛下殺手的人，就是八個月前在瓦樂利施壓之下，惨遭處決者的親戚。

接著，這群暴徒又去劫掠帕歐羅安東尼奧的家。根據馬基維利記載，攻擊者在屋裡找到了帕歐羅安東尼奧的弟弟。此人正是弗朗切斯科・索德里尼——備受尊崇的沃爾泰拉主教，同時也是馬基維利日後最重要的政治導師。弗朗切斯科在聽到嚷吶、發項騷動後，依舊保持冷靜。他立刻穿上最高尚的服裝，再披上主教的法衣。接著，他在這套「基督盔甲」的保護之下，現身對抗武裝暴徒，並出言阻止他們。
