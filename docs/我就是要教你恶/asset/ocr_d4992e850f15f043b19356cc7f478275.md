# 我就是要教你怨

至於佛羅倫斯方面，托圖為了幫他可憐的哥哥多擠點零用錢，而掀起了全面抗爭活動。到了九月初，馬基維利收到一封信，說他的薪水加到跟卡薩相同了。「我連續十五天，不分晝夜的糾纏他們，爭取協助！」托圖寫道。他糾纏的人包括阿比奇，以及其他賞識馬基維利的行政官。

在百無聊賴之中，總算來了一點慰藉。比亞吉歐寫信給馬基維利，分享最近發生的事：領主與十人戰爭官，請比亞吉歐誦讀他自己寫的信，結果他們對這些信讀譽有加。「這件事讓我超開心的，我還得絞盡腦汁想出幾句話，來確定自己有沒有聽錯！」

除此之外，他還寄了其他消息來，但都不是什麼好消息。例如，位於比薩周圍的佛羅倫斯城鎮與堡壘，有越來越多都落入敵人手中；皮斯托亞（Pisa）處於極度動盪的狀態。另一位同事安德烈·迪·羅莫洛（Andrea di Romolo），在比亞吉歐的信裡加了附記，請馬基維利早點回家。最近他們下班後，经常在比亞吉歐家開派對；就連壞脾氣的安東尼奧先生，偶爾也會來參加。

「我們跟他開玩笑，說他需要要女人來溫暖他、陪他做床上運動，結果他看起來就放鬆了些。說到女人，比亞吉歐跟我都曾看過你女友，從沿著阿諾河和恩麗橋（Cane）旁邊那棟、有美味佳餚的房子裡，開窗探出頭來，一副為情憔悴的樣子。不過，假如你一直不回來、讓她失去耐心的話，也不用太擔心啦！因為看在上帝的份上，我們會幫你找到其他刺激的樂子──只希望你回來時，別太「法國化」囉。
