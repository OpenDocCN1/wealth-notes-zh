# 第十三章 人民願為自由而戰，政客只想保住財產

辦公室裡，只剩少數幾個官員，會友善對待他和遭到放逐的旗官，現在會議上都是梅迪奇家族的崇拜者，他們不想跟馬基維利，以及他親近的同事打交道；而馬基維利跟十四年交情的老同事，再也不能開玩笑了，即便只是自嘲，若被其他人偷聽到，都會懷疑他們是否居心不良。

所以日復一日，馬基維利就像一臺需要外力驅動的機器人，沒有靈魂、感受或創造力，只是發揮自己的功能，處理桌上堆積如山的工作；明明前幾天在同樣的地方，他的敏銳、審慎、嚴謹、幽默、忠誠、經驗，以及對改革的奇想，全部讓自己的城市受益良多。
