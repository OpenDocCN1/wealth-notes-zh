# 第十一章  人說狐狸狡猾，因為他識破人的陷阱欺詐

實的樣子，算是反駁[狡狐]“臭名。然而有時候，他單方面的喋喋不休又像個圈套，散發著醞熱氣息、纏著獵物打轉，直到他們難以下氣、無法回話、逃不出那既空洞又具有控制欲的聲音。

尤其，他最愛批評不久前還是朋友的敵人。「祕書先生，不是我在吹噓，那幫人還有什麼希望？拿我們跟他們比較，不就很清楚了嗎？至於他們一致盛讚的維特羅佐：……哈哈！『他大笑道：』那傢伙整天只會哀號號病很痛苦，然後把事情推得一乾二淨！他其實只會兩件事：破壞毫無防備的鄉下地方，還有背叛別人！」

切薩雷一定多少知道，別人怎麼在背後說他；又或者，他沒有大家想像的這麼狡猾。馬基維利的兒子，而他自己也是個厲害的騙子，但從他的表現看來，遭人背叛好像真的嚇到了他、甚至傷到他一樣——他背後有這麼多勢力、權力在撐腰，怎麼還有人敢背叛？看過他的反應，就連馬基維利都差點要同情他了。有些人一開始贏得太輕鬆、受到太多幫助，之後遇到困難的話，他們往後的人生會變得多艱苦？
