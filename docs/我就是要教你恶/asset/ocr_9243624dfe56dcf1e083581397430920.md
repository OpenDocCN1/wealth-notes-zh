# 給他們權力與尊嚴，他們就會守護你的安全與自由

經過一年多消磨意志的討論之後，皮耶維決定要大膽行動。他打破慣例，刻意不跟市民代表進行初步協商，就直接去說服領主與十人戰爭官，要求在鄉村實施首次徵兵。西元一五〇五年末，十人戰爭官派遣馬基維利，前往山岳林立的穆傑羅與卡森提諾地區，開始徵召與訓練士兵。

馬基維利在每個鄉鎮的例行公事都差不多，不過每個鄉鎮的反應都不同，十分有趣。每個鄉鎮都一定有個小小的中央廣場，再加上一座教堂、一座市政廳，以及一座擠滿鎮民的市場，他們在這裡販賣蔬果、酒、橄欖油與牲蓄。馬基維利會先拜會當地的官員，把新的手寫徵兵令交給他們。接著，該地鎮長就會盡可能召集鎮民，宣讀重要資訊：

> 每年十一月，行政官都會從其行政區中的十五歲至五十歲男性，挑出合適的人選清單。若官員刻意遺漏任何人選，將受吊刑兩次與罰款。被徵召者若因體弱而無法服役，或有其他合法的免役理由，可在一個月內申訴。
