# 第九章 厝害了我的國，只算計、沒道義

大家只記得他這個特長。他有一本記事本，除了寫下家務事之外，也記錄了佛羅倫斯與義大利的政治事件。他希望總有一天，能將這記事本升格為佛羅倫斯的史書，並以總理署內部人員的角度來呈現。除此之外，他也會寫詩（比馬基維利的詩更親暱、更深情）（表達對妻子費耶卓（Gasina）的愛意——無論她在世時，還是她早逝之後。）

馬基維利的另一位副手——阿戈斯蒂諾·維斯普奇（Agostino Vespucci），很快就對政治軼聞的一面感到厭煩。雖然比茹吉歐與馬基維利都沉浸其中，希望能為了同胞的利益與自身的榮耀，從此工作中學習，但阿戈斯蒂諾會去欣賞私人收藏的藝術作品，然後在書齋（看他當天帶著哪本書）的空處，抄下自己的評論，藉以稍微拋開日常工作。

日後，他認出了達文西名畫《蒙娜麗莎的微笑》的模特兒，就是麗莎·喬吉多（Lissa del Giocondo）；西元一五○三年，他把這項發現記在西塞羅《書信集》（Letters）的空白處，因而聞名於世。他寫信給馬基維利：「比茹吉歐還真可憐！他就像荷馬（Homer）史詩裡的好心人普羅忒西拉與斯（Protesilaus），他在特洛伊戰爭中，是第一個跳下希臘戰船的人，也是第一個陣亡的人。」由於家世顯赫，阿戈斯蒂諾不必認真看待安東尼奧這種平民或佃農出身的人；換句話說，社會階級勝過官階。
