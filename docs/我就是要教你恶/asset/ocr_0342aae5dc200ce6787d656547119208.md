# 第十七章 天下無道，我們能有的作為

派兵往南通過羅馬涅與托斯卡尼，並一路強渡掠掠。到了四月初，皇帝麾下的將軍——查理．德．波旁 (Charles de Bourbon) ，率領一萬四千名日耳曼傭兵，攻擊波隆那附近的地區。

教宗完全沒阻止這支直奔佛羅倫斯的無情大軍，不過馬基維利跟羅托利說，這支敵軍毫無紀律，只知掠奪不知作戰。但他也絕望的表示：「我們面臨的最大威脅不是來自他們，而是來自我們自己，來自義大利人的怠惰。」即便如此，馬基維利還是囑咐他朋友（與其他佛羅倫斯人）要反抗。他寫道：「你們若能武裝自己，在比薩、皮斯托亞、普拉托與佛羅倫斯建立頑強的防禦陣線，藉此讓敵人吃虧的話，那代表還有機會自救。接著，你們就能說服敵人談條件；這些條件對你們來說應該會相當慘痛，迫使你們必須讓步——但起碼不會要你們的命。」

十五年前（西元一五二二年），西班牙襲擊普拉托之前，馬基維利也是這樣建議皮耶羅旗官。「當你只剩下最後一絲希望，就別再賭錯氣，而是透過妥協來減少損失，盡量保護你能保住的事物；而現在失去的事物，之後可以再補回來。」當時皮耶羅拒絕妥協，導致佛羅倫斯落入了君王的手中。但這次，事情可以有不同的發展。

馬基維利還待在羅馬涅的反帝國軍隊中，不過他每天都寫信函給佛羅倫斯城的朋友，並焦急等待防備敵軍的相關消息。馬基維利不在的時候，由大兒子貝納多（跋耶跋喬貝納多一樣，頭腦冷靜、井井有條）監督城牆的擴建，但市民已經開始陷入恐慌；他們派人去梅迪奇宮求請顧，要求這座城也應該有軍隊。而在貝納多的幫助下，瑪莉塔維持了家裡的氣氛。
