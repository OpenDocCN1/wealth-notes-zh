# 第十四章 如何建議上位者？用他們的觀點

# 兩面寫法，教你為王的同時諷刺你

透過這本書，馬基維利就可以讓「馬基維利祕書」的經驗延續下去，在大家忘記這些經歷、和馬基維利本人之前，他希望大家都知道他自己是一位審慎的政治家。他回想過去十五年來，觀察過的領袖與戰將，以及他們的作風、功績與過錯，接著將這些人的功過，全都攤在自己的書頁上——包括薩佛納羅拉、卡特琳娜、法王路易十二、切薩雷、維特利、維特羅佐、「雙面教宗」歷山六世，以及魯莽的「恐怖教宗」猶利二世。

他在書房內安靜的寫作，身旁有古人陪伴。李維、塔西陀、色諾芬（Xenophou）、普魯塔克……個個都是頭腦清晰的賢人，見證過羅馬與希臘的自由之死——比近佛羅倫斯的衰敗更爲殘暴。在內容架構成形之後，他心生一個惡作劇的念頭：等到這本書完成、並交由朋友檢查語句是否得體後，他要無比謙卑的，將這本書獻給梅迪奇的新君王。如此一來，這位君王就會想起被放逐的馬基維利，其實通曉政治、知識淵博，或許對自己以及整座城市都大有助益。

現在，馬基維利已經學會不去教訓君王該怎麼做，而是自由發揮自己的老伎倆——「兩面寫法」；以前在寫外交信的時候，這招還挺管用的。他假扮成冷血顧問，教導新統治者怎麼利用其他君王、外國人與臣民，滿足自己逐漸高漲的野心。不過，當他描寫自由人民如何對侵犯自由的人復仇時，字裡行間所散發出的熱情，簡直快把書頁燒掉了。馬基維利藉著這本書玩弄讀者、測試他們看穿第一印象的能力，並在故作正經的語句中，偷加一些狡獪的趣味……這些都讓他玩得很快心。幽默可以治癒他受傷的心靈，而拿君王開玩笑，更是最有效的良藥。
