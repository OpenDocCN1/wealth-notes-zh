# 第五章 挑戰「點個頭就搞事情」的人，證明我們品德比較高尚

+   3 位於旁羅倫斯北邊。

蹟都沒有留下紀錄：沒有任何文獻證實馬基維利是否在念大學（或念什麼學科），也沒有其工作經驗的相關證據，直到他快三十歲的時候，寫了兩封狂妄、挑釁的信，他的名字才重新出現在歷史上。西元一四九七年，馬基維利家捲入法格納聖母鎮（Santa Maria del Fages）的教區教堂的傳檄權糾紛。他的對手是高貴、富裕的帕齊家——其財產與市民權利在數年前就恢復了。
二十八歲的馬基維利，早就準備好要對抗帕齊家的主張，他草擬一封信給樞機主教喬凡尼·羅培茲（Giovanni B. Lopez，亦即負責裁決此案的人），把窮困的馬基維利家塑造成正義一切的受害著，表達他們為了權利不惜浴血奮戰的決心，剛好能彌補社會地位的不足。他用戲劇性的沉著語氣，告訴樞機主教：「無論高貴、風采與財富，我的家人完全不覺得自己遜於那群自以為擁有權利的人。沒錯，任何人只要以公正的尺度，來衡量我們家與帕齊家，就會發現我們的心靈遠比他們更自由、更良善。－我們們在此處首次見識到，馬基維利如何搖穿優越感（只來自出身與人脈）所帶來的自豪——這也是他一生的最愛。共和國家該政治平等，但每個人都想與他人比較社會階級。佛羅倫斯人就跟多數共和國（無論古今）的人民一樣，非常著迷於社會階級。從馬基維利的《佛羅倫斯史》中，就展現出官方希望這座城市不要有貴族存在，但這種理想卻又因為某些市民渴望比別人高等，而大打折扣。
他們喜愛爭論，哪些貴族該列入最偉大的家族、哪些職業會讓人淪落為「次等人」（Persona infore），甚至變成「最低賤的平民」（Ultima Paxe）。然而，佛羅倫斯人民最痛公開蔑視的，不是衣衫襤褸的中產階級或窮人，而是所謂的「新貴」——直到最近，才從無名氏，變成有權有勢的暴發
