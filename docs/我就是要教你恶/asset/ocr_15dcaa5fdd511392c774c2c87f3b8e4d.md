# 第十三章 人民願為自由而戰，政客只想保住財產

迪南組成「神聖同盟」(Holy League)，準備向法國和其盟友對決，而該同盟的其中一個目標，就是要摧毀佛羅倫斯政府。

因為猶利教宗不再信任弗朗切斯科主教，所以當喬凡尼主教提出對佛羅倫斯事務的建言時，就越來越容易被採納。十二月中旬，猶利教宗把所有佛羅倫斯教士逐出教會，並禁止他們參加彌撒，直到明年春天為止。結果，戰爭真的開打了。只要法軍打勝仗，佛羅倫斯人就會點篝火慶祝。四月，他們聽說法軍捕獲了喬凡尼主教，將他囚禁於帕維亞（Pavia）2；兩個月後，也就是六月，他們又聽說梅迪奇主教逃跑了。

然而，接下來的消息卻越來越糟。米蘭背叛法王，迫使法軍必須撤出該城；接著，教宗的部隊占領了波隆那。七月中旬，領主收到猶利二世的信，說是要給佛羅倫斯人民看的：信上要求正義旗官及耶羅馬必須辭職，假如他拒絕的話，整座城就會付出慘痛的代價。與此同時，教宗與西班牙的部隊在卡多納總督（Cardona，隸屬斐迪南國王）的指揮下，聚集於佛羅倫斯的領地周圍。
