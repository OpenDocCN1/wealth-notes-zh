# 第十七章 天下無道，我們能有的作爲

此起非預謀的起義，令維托利、菲利波與其他們的共謀朋友都相當驚訝。本來為了組織起義而小心擬定的計畫，也全部泡湯了。一切都發生得太快，所以城門與領主官邸都沒有衛兵。雖然圭恰迪尼對教宗很失望，但他畢竟還是克勉的副官，他派兵是為了替城市抵禦外敵，而不是煽動反梅迪奇的叛亂；因此起義後不久，他就帶著一支教宗步兵的分隊進城（而且沒人攔阻他們），護送年幼的梅迪奇男孩回家。

圭恰迪尼並沒有依照往例嚴厲的報復叛徒，而是與維托利簽定了些協議；因此，參與起義的人都沒有被追究責任，而梅迪奇政府停擺了一陣子之後，又重新執政；但這個政府並沒有撐太久。因為帝國軍並沒有攻打佛羅倫斯，而是迅速朝著羅馬前進；到了六月六日，帝國軍劫掠了這座聖城，可說是有史以來最血腥的攻擊行為。飢餓的日耳曼士兵一邊大喊：「略德教宗萬歲！」「Marie Luttard」一邊砸毀聖物，並洗劫住家、商店與銀行。

佛羅倫斯的商人與銀行家損失慘重，把這筆帳全算在教宗頭上（教宗已被帝國軍俘虜），因此就讓梅迪奇家最忠死的朋友，都轉而反抗追不得人心的政府。三月底，菲利波被釋放後，在羅馬慘遭劫掠的期間來到佛羅倫斯，與維托利、維托利的姊夫卡波尼、路易吉、圭恰迪尼等人合作，計畫第二次驅逐梅迪奇家族。因為最強的武器——人民，已經站在他們這邊，此外還有第二強的武器——菲利波的妻子克拉麗斯。

克拉麗斯上次成為政治風暴的中心，已經是快二十年前的事。當時她還只是個小姑娘，為了讓家人能夠結束流放，而答應那場充滿爭議的婚姻；不過，她現在三十四歲，還是十個孩子的媽。她坐著轎子前往娘家——梅迪奇宮，要求以和平的方式，結束梅迪奇家族對佛羅倫斯的統治。負責保護伊波
