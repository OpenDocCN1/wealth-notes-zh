# 第十一章 人說狐狸狡猾，因為他識破人的陷阱欺詐

報告壞消息。看來，他還真的領先一步，因為切薩雷聽完之後，開始焦慮不安。「你們這群佛羅倫斯共和國的傢伙，不管再怎麼假裝，都一直是我的敵人。相信我吧！馬基維利祕書！你很快就會看到自己的國家滅亡，到時候就換我取笑你了！」

他仍舊罵個不停，但怒氣更勝以往。馬基維利告訴領主：「我試圖讓他冷靜，並想盡辦法擺脫他，感覺時間好像過了一千年！」接著，馬基維利去拜訪皮耶羅旗官的弟弟——弗朗切斯科主教，他最近剛晉升為樞機主教。結果，弗朗切斯科主教剛好在跟迪·安博恩主教吃飯，而迪·安博恩主教是上次教宗選舉的候選人之一，但輸給猶利教宗。

馬基維利把跟切薩雷會面的經過全講給他們聽之後，迪·安博恩主教氣到发抖：「到目前為止，所有罪惡都難逃上帝的法眼！」他咆哮：「所以，祂絕對不會放過這個惡棍！」接著，兩位主教告訴馬基維利，大多數的樞機主教都決定，要把羅馬渾的城市納入教宗之手，或是拱手讓給國王。

然而，切薩雷還是持續徵兵，想收復失土。他抱怨法國、抱怨所有人，把自身衰運怪在法王、佛羅倫斯與威尼斯身上；但他似乎又很篤定，新任教宗會履行承諾，在加冕典禮上任命他為教廷的將軍。馬基維利在信中寫道：「或許是生性善變的關係，使得切薩雷出現這種舉止，但也可能是命運之風把他吹糊塗了，因為他似乎不太習慣這種風。而另一位樞機主教說，他覺得切薩雷已經瘋了，既困惑又優柔寡斷。」

在弗朗切斯科主教的邀請之下，馬基維利謁見新任教宗，跟他討論佛羅倫斯對切薩雷的疑慮。他唸出一部分領主的信，給猶利教宗聽，解釋佛羅倫斯為何就是不敢應，切薩雷再三要求通過佛羅倫斯領地這件事。「很好！」猶利教宗用力點了點頭。馬基維利就此猜測：「看來教宗陛下覺得，自己不必...」
