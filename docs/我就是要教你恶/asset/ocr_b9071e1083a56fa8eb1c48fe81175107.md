# 君主如何獲得對方的忠誠？

西元一四七九年末，佛羅倫斯的軍隊終於離開馬基維利鄉間別墅附近的軍營。其中一部分的軍力前往東南方的屬城阿雷佐，另一部分前往西邊的恩波利（Empoli）與比薩。貝納多鬆了一口氣，記下他們的離去；這是他的日記中唯一直接提到的時事。根據他的紀錄，這些軍隊有些曾駐紮於聖安德肋，而且他們的隊長皮耶羅·達·卡塔金（Piero da Cargnano），還曾經借住過貝納多的房子。羅倫佐發起的戰爭還沒結束，但起碼已經遠離馬基維利家附近了。
