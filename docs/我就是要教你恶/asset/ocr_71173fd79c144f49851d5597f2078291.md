# 我就是要教你怒

佛羅倫斯的重要人士（包括維托利）都建議克勉，應該站在皇帝查理五世這一邊，這樣雖然很沒 有榮譽感，但比較安全。他們指出，佛羅倫斯的領地沒有自己的軍隊，所以龐大的帝國軍可以輕易毀 掉這座城。「迫於現實，我們只好臣服於皇帝。」但馬基維利否定這種聽天由命的理由。他告訴圭恰 迪尼：「如果問題出在我們沒軍隊，那我們就來建軍！」維托利的用意本是好的，他希望盡可能守護 佛羅倫斯的政權，但這些年來他都太過謹慎，只顧著適應其他人的機運，卻不願自己創造命運。 因此《君主論》提到，應試圖說服注重現實的宿命論者，就算個人或國家目前處於弱勢，也不該 放棄採取大膽、獨立的手段來拯救自己。「許多人都覺得，世事是由機運與上帝決定，人類不可能 靠自己的審慎來修正它。可是如果這樣想，就真的沒救了。」有這種看法的人，認為向當今的現實低 頭、任由命運擺布，才是明智之舉。馬基維利承認：「有時我思考這個問題，也有幾分同意他們的看 法。根據我的判斷，命運女神確實裁定了我们半數的行動，可是另一半她交由我們自己決定，這樣我 們的自由才不會被消滅。」

我們無法精確衡量這些事物，因為命運與自由沒辦法靠經驗累積，我們既無法觀察它們，也無 法透過質量、運動來計算它們。就算有人能證明，命運是九九%的影響力，加上一%的自由（或更 少），但這微小的一%依舊留下了空間，讓我們自行決定是否行動，行使名為「審慎」與「自由」的 力量，讓我們更有秩序。

事實上，最值得讚揚的人造傑作（例如建造大城市或是維護它們），都是在選擇空間較少的情況 下出現。因為，此時大家都必須更耗費心力，才能克服障礙。「所以他們應該永不放棄，隨時抱持希 望。只要有希望、不向命運低頭，不管遭遇什麼艱難，都能找到自己。」
