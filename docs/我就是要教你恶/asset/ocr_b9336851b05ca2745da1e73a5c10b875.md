# 我就是要教你忍耐

戶。貝納多的朋友史卡拉就是一例，他出身於鄉間小鎮科萊（Cole），是磨坊工人之子，後來到佛羅倫斯勤奮苦讀；他的博學與自我精湛的慾望，都令科西莫印象深刻。如今，他是共和國總理，本市最重要的職位之一。

馬基維利很早就知道，他們家在哪種一絲不苟的階級裡，處於什麼樣的位置。馬基維利家既不是貴族，也不像多數佛羅倫斯市民一樣是“次等人”，而是中階的資產階級（Propriato grasso）。但

從馬基維利第一批留存至今的信中，清楚展現出即使家族的地位平庸，也拒絕遭受到“豪門”（grand）恐嚇。他發誓：“精力充沛的馬基維利家，絕不容許比我們低下、並視為敵方的人，拿我們的戰利品裝飾他自己，並無恥的吹噓他的勝利。”

他在另一封信（用拉丁文所寫）又宣稱：“如果我們家是一群侏儒，正要攻擊一群巨人，我們一定會挑戰‘點個頭就能立刻搞定所有事情’的人，來證明我們的品德比對方高尚。”最後，馬基維利家贏得好這場官司，也稍稍證明他一再於作品中提到的重點：弱小的家族、個人、城市與人民，永遠不該害怕對付那些貶低他們、或是搶奪他們事物的惡霸。就算在某些戰鬥中會輸，但他們會對自己付出的努力感到驕傲，並且讓壓迫者更難過。
