# 民兵計畫重啟，但不在佛羅倫斯

《克麗賓婭》盛大首演之後的數週，馬基維利詢問維托利（已成為梵蒂岡的特別使者），什麼時候該前往羅馬，把他的史書獻給教宗？「前幾天教宗陛下剛好在打聽你的事，還問你的曠世巨作完成了沒？」維托利回答。「我跟他說我讀了一部分，內容保證他滿意。教宗就說：『那他應該來一趟，我覺得他的書應該能帶來很多樂趣，讓人願意去讀。』但你先別急著來。克勉現在有很多煩惱，每天的心情都很難捉摸，而我不希望你空手而回。」
