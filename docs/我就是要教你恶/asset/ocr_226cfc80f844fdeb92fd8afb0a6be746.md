# 我就是要教你惡

馬基維利造訪切薩雷期間，就經常用這種語調寫信給上級：「公爵展現出空前的好運，以及超乎常人的精神與自信，認爲自己能滿足所有的欲望。」讀淺的讀者會覺得這是種高度讚譽，公爵的密探說不定還會回報主子：馬基維利還真是您最忠實的僕人！但馬基維利在總理署的朋友，以及弗朗切斯科主教，都知道當馬基維利說某人是命運的寵兒，表示那個人的成功根本毫無根據，而「超乎常人的自信」更是一種愚蠢的自負；當馬基維利說某位從政者「精明」，也絕非恭維，因爲對馬基維利與許多古代作家來說，「精明」（而非「審慎」）的政治家就是狡猾的投機分子，完全不懂如何建立長遠的秩序。
