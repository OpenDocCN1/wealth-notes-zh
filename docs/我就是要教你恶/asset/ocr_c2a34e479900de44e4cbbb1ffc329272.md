# 第十七章 天下無道，我們能有的作

馬基維利從來就不相信皇帝的雄心壯志。他告訴圭恰迪尼：「查理五世的帝國，是一股可惡、危險且令人恐懼的勢力。—比較安全的賭法，就是日以繼夜，努力重拾老盟友—法國的信任。一年前，法王蘭索瓦與宿敵查理交戰，結果戰敗被俘，目前囚禁於馬德里。馬基維利說道：「我們應該好好安排，這樣法王一逃出來就有教宗可以依靠，而且憑教宗的權力與口才，一定能讓法王不計前嫌（教宗背叛），並展現出義大利全境都在反抗帝國。」

假如，佛羅倫斯與教宗無法贏回法國的善意，馬基維利覺得只剩兩個選項。他告訴圭恰迪尼：

「我們可以試試佛羅倫斯的老招—用錢收買，但我個人認為可行性不高，除非我看走眼，要不然法王拿完我們的錢，一定會順便取走我們的命。其實還有一個更好的辦法，就是我們認真武裝起來，自立自強。」教宗與佛羅倫斯可以採取主動態度，強硬要求義大利其他地區組建民兵；而面對這麼可怕的共同敵人，使得他們終於有機會建構義大利共同防衛線。馬基維利告訴圭恰迪尼：「我們應該即刻實施這項計畫，別等法國答應了。管它是明目張膽還是背地偷來，反正我們一定要建軍，否則某天早上醒來，就會發現一切都沒了！」
