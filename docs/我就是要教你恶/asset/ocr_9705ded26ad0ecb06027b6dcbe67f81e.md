# 外患可以帶來內部團結

於同一個公會，有權提供藥物治療，他們使用另一種療法，是將祖母綠或煤色的甲蟲〔cantalile〕放在患者左腿上的三處。不過，這些療法一定有部分產生功效，因為到了八月，貝納多就脫離險境了。但是，他沒有時間享受痊癒這件事，因為他的症狀減輕之後，卻換其他親戚染病。

首先是一位堂弟一年僅二十歲的桂多·馬基維利（Guido Marcavalli），與馬基維利四子同名，請求貝納多（還在康復中）幫他立遺囑並擔任公證人，以及安排妹妹阿朵拉（Adora）的婚事。接著，桂多的某位叔叔也出現了瘟疫的症狀。

最慘的是鮑寧席格納，這幾週不斷的進出貝納多的病房，完全沒照顧到自己的健康。後來，貝納多付錢，請兩位織布工鄰居以及一位佃農，去見證鮑寧席格納的最後遺言；因為除了他們，沒有人敢接近因瘟疫而垂死的人。貝納多寫道：「我在此記下主曆一四七九年八月五日，鮑寧席格納逝世，留下兩個兒子——巴蒂斯塔（Battista）與皮耶羅（Piero），以及妻子夢娜·安東尼亞（Monetta Antonia）。」
