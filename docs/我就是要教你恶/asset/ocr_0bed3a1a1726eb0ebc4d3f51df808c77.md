# 別冀望哪「一個人」能改革腐敗

雖然馬基維利年事已高，但跟花園好友討論如何改革梅迪奇政府時，他的舌頭就跟在〈論李維羅馬史〉裡、替共和國辯護時一樣辛辣。在年輕朋友的回憶中，西元一四九四年的共和國是一場令人傷神的騷亂，危機接踵而來；長輩則抱怨，讓大眾參政實在太瘋狂了。年輕人表示：「君主主政或許不太好，但根據我們最近的經驗，共和國（尤其是人民主政的共和國）也好不到哪裡去！」馬基維利承認，回顧佛羅倫斯近期的歷史，這的確是事實。「但我判斷事情的時候，不會只問某段時期、某個地方的經驗，能讓我們學到什麼？我還會問：在理想狀態下，事情可以怎麼發展？」他認為政府英明與否，不只是誰主政（平民？君主？還是少數幾個號稱英明的人？），還得看有沒有法律，能夠避免任何個人、階級或黨派支配他人；他在〈論李維羅馬史〉中，進一步提出支持此論點的理由：「長期存續的君主共和國，都必須受到法律規範。因為任性妄為的君主是瘋狂，而任性妄為的平民是愚蠢。」他告訴半信半疑的年輕聽眾與讀者：「假如你要從秩序敗壞的群眾，以及毫無紀律的君主之間選一個，那該選哪個其實很明白：沒有法律約束的君主，絕對比同樣條件下的平民更善變、更魯莽、更不受威脅。況且，平民野心太大，你尚能曉之以理；倘若君王野心太大，你就只能勸戒了。」「可惜，這番話沒能說服他的朋友，於是他『命令』他們：「如果有什麼疑慮，就狠狼質問我吧！」〈論李維羅馬史〉就跟〈君主論〉一樣，遊走在驚定與猶豫之間，好像作者在模擬一段實況對話，或許也是在呼應、預測歐里切利園這樣常客的質疑。假如君王睿智、善良到超常人的程度，
