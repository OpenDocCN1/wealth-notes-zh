# 我就是要教你惹

們有必要留下來。第一，這些老兵服役這麼久，直接解傭他們未免過於殘忍；再來，這些同袍也說，

如果沒有這些優質的老兵輔佐，他們就會不知道該如何是好。

接著，他向各城鎮的行政官、市議會喊話：有一封從蒙特普齊亞諾（Montepulciano）寄來的

信，說馬基維利發揮最大的努力，激勵著聚集在一起的市民，並用最充分、最有力的理由保證，不管

在當下、還是更糟糕的狀況下，都沒什麼好怕的。

「沒什麼好怕的。」日後，他想起這句滿懷希望的話，迴盪在簡樸的市政廳與狹窄的市民廣場

中。但實際上他其實並不清楚，自己是否真的相信這些民衆。一方面，敵方軍力過於強大，已經夠令

人害怕了，更糟的是，他們的法國盟友妄因為軍力損失與糧草不繼，已經撤離了北義大利；但另一方

面，如果你希望軍隊戰勝，就必須讓他們相信自己會贏。這份自信是來自武裝精良、紀律嚴明，以及袍

澤之情。士兵要英勇、守紀律，而好的指揮官能造就這種士兵。然而，每個審慎的指揮官都知道，再

強的軍隊也可能因為某個意外敗北，例如戰略失策、時機抓錯、天公不作美，或是疾病突然爆發等。

馬基維利回想起，此番巡視後的幾個月，不斷努力建構的世界竟分崩離析，便不禁懷疑起自己

當時他應該要更害怕這些變數才對。遭法國遺棄的佛羅倫斯，幾乎毫無勝算。不過馬基維利猜

想，部隊大多狀況良好，說不定市政府也會同意多徵一些兵，擴大士兵部署的範圍，於是就和其他長

官一起來要求增加經費。可是到了七月底，皮耶羅旗官來信：「市民只同意再增加幾百個步兵，所以你

們就湊合著用吧！」
