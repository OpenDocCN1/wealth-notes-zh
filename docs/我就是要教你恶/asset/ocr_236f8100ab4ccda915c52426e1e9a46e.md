# 第三章 爸爸欠稅，家族黑五類，怎麼翻身？

多閣下不用這個資歷多賺點錢？當時的公证人只要辦事妥當，就能過上非常舒適的生活。只要他背幫富商、大銀行家的繼承人調解紛爭，他在稅務機關的聲譽很快就能洗白。連史卡拉總理都將貝納多的法律知識與智慧捧上了天，既然是如此出色的法學家，為什麼堅持低調生活？

原因出自於貝納多的二堂哥吉羅拉莫．馬基維利，佛羅倫斯政界老一輩的人都記得這號人物。馬基維利家族現在鮮少提到他，但永遠不會忘記他。事情發生在二十年前，也就是貝納多剛完成法律訓練的時候。當時，吉羅拉莫和他的家人就住在貝納多的隔壁，也同樣屬於馬基維利住宅區的一部 分。他是貝納多的二堂哥，比他大十二歲左右。吉羅拉莫完成職業教育之後，繼續研讀艱深的課程 （貝納多之後也踏上同樣的路），並於佛羅倫斯的大學，教授法律與法學；不久後，他就成為城裡最受尊崇的法律專家之一。

當時的統治者經常延攬他擔任委員會的成員，處理敏感的政治問題。當吉羅拉莫的年紀達到擔任公職的資格時，他就投入了政治圈。西元一四四○年代至一四五○年代，他擔任過許多職位，針對敏感的外交議題給政府建議，也以使者的身分造訪過其他義大利城市，測試它們對佛羅倫斯的忠誠度。據說他全力保護佛羅倫斯的利益，也能公正判斷國內事務，就算面對黨羽的敵意，也絲毫面不改色，以完美的外交技巧努力工作，在敵我之間找出妥協的方案。

+   3 起源於義大利的建築形式，指在建築立面的外側修建走廊，走廊一側有柱子。
4 跟貝納多的兒子同名。
