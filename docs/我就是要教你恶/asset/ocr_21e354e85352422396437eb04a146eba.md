# 第十二章 顛鎩他人財物，將在不安中失去一切

無論你希不希望讀者查覺隱藏的訊息，娛樂他們一下倒是無傷大雅。

這沒什麼好講的。Habo Bino Broca Bro do do do do do……然後有幾個無賴，塊頭跟騅子一樣大，那諾克竟然跟我的大腿一樣粗，準備進攻那些可憐的宮女，諸位大人必定為之驚嘆……。

維托利就這麼看著馬基維利的胡搞公文，簽上一僕人弗朗切斯科·維托利」。當然，收信人一定知道信是馬基維利寫的。當訊息很緊急的時候，最好予以加密，並透過其他手段寄送，因為太明顯的密碼信，絕對會落入專業破譯員的手裡，因而延誤遞送。有些人會使用隱形墨水，或是把訊息寫在劍鞘內側；要不然，也可以把訊息藏在狗狗的項圈裡，或是自己最私密的部位。之前，馬基維利與維托利就收過一塊麵包，裡頭藏著寫有訊息的羊皮紙。這種寄送法有缺點，因為麵包必須先浸水再曬乾，所以取出信件時已經變得零零碎碎，只有四分之一能讀。

除此之外，也有使用一般語言與字母的加密法，但是字詞的原意會替換成隱藏的意義，只有「該讀的讀者」才能看懂。例如：寫信的人會用「畫眉鳥」代表武器，「絲絨披風」代表法王，「灌腸」代表威尼斯；或者他想表達意見、卻又不能太張揚的話，也會用一下老技——兩面性。
