# 我就是要教你惡

警告過他們：「見到極權主教的時候，拜託、千萬別質疑他的判斷。如果他決定要做任何事，儘管同意就是了。畢竟到最後，你還是得遵从主教閣下的想法。」馬基維利兩人直接走進迪、安博思的辦公室，盡力介紹自己，還因為沒有領主的正式推薦信而致歉。卡薩依照慣例道：「我們任務成敗與否，全仰賴主教閣下了，因為您是唯一替敵國政府辯護的人，敵國的大人也極度信任您。」

主教不耐煩的回答：「你是想來翻比薩軍營的舊帳嗎？我們還以為這件事已經過去了耶！」

「不，我們一起去找陛下聊聊如何？」「迪·安博思年約四十歲，比馬基維利大二十歲。他的鼻子與臉部都很瘦削，乍看之下會以爲身材很苗條；但他從椅子上站起來的時候，紅袍下頂著一顆圓滾滾的大肚子。

國王吃兕晚餐後，先去小睡片刻，不久就召見馬基維利他們，而在場的還有迪·安博思、法國將軍佛利蒙德·羅柏泰特（Engelbert Roussan），以及幾位在阿比奇被俘時，駐紮於該營地的義大利士兵。卡薩用拉丁語包辦了大部分的開場白，而馬基維利注意到，即便是博蒙特與迪·安博思這些法國貴族，在說古代通用語（拉丁語）時的口音與文法都很怪。於是，他草草寫下：「他們簡直在侮辱羅馬人的語言與聲響！」此外，還記下其他關於「法國人天性」（GermanicGrain）的短评。

卡薩以佛羅倫斯的角度，重述軍營裡的那起憾事。他用字非常謹慎，避免指控遭到義大利背叛，畢竟主嫌怨他們共患一處。接著，輪到馬基維利發言——說到這起暴力、惡名昭彰的佛羅倫斯官僚绑架案，他可是最重要的目撃證人。國王一邊聽、一邊皺貌回應。他比迪·安博思年輕個幾歲，而且看起來決心昭告天下：他非常認真看待自己的責任。可能是天性如此，也可能是後天培養出來的氣質。總而言之，他跟堂弟查理八世相當不同，查理是個急脾氣年輕人，總是隨便便做出承諾，又隨便打破它。
