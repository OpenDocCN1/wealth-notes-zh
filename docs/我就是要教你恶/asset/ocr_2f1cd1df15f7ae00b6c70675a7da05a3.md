# 第四章 勝利若是沒有帶點敵意，無法維持和平

則說這是一場意外，並非佛羅倫斯偉大領袖的功勞，純粹只是僥倖。因為，土耳其國王穆罕默德（Mehomet the Great [注]）最近攻打希臘的羅得島（Rhodes），遭到當地民眾的頑強抵抗，讓他覺得很丟臉，因此決定一定要在其他地方打勝仗，於是他將目標轉為義大利。

他攻打東南海岸的奧特朗托（Otranto），把該城洗劫一空、殺光了所有居民，並在港口周圍建立一座要塞，還派軍隊到鄉下去燒殺搶掠。這件事使得拿坡里的斐迪南王派遣使者，前往義大利與歐洲全境，懇求大家協助共同對抗這個敵人。別浪費時間與資源在自家附近的小仇恨上，大家要同心協力對付這個異教徒！

這個轉折剛好救了佛羅倫斯。根據馬塞維利的記載，挽救羅倫佐偉大領導者名聲的，並非他精明地外交手腕，而是土耳其人。馬塞維利在晚年，不斷警告人們要小心江湖郎中，因為他們只會給你帶有甜味的藥物，或是誇你的腦袋放血，讓事態更加惡化。他在《騙子》（The Ass）一詩中宣稱：

> “用這種手段承諾他人和益者，總是能取信於人，而人們也對醫生抱持此等信任；看來眾多職業當中，就只有醫生靠病人來過活。”

巧合的是，“梅迪奇”這個字也是“醫生”的意思，根本就在鼓勵佛羅倫斯的作家，好好利用這種惡毒而微妙的美麗語——這也是馬塞維利的最愛。有些人掛著醫生的名聲，卻幾乎不懂得治病；有些人一度被捧為共和國的救星，但仔細端詳的話，就會發現他們竟是最腐敗的傢伙。
