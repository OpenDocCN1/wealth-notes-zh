# 管理有四重境界

最高境界：看清楚每一个人本来的特长，优势，将就每个人的特长优势来做事。使他的特 长符合企业的发展，其实，我们在招聘的时候，就要选好相应特长的人来傲他们相应的岗 位，超神经的企业就是这种。

差一点的境界：用利益诱惑员工，比如我们骑在驴子背上，驴子不走，我们拿个竹竿，前 面吊一个红萝卜。驴子要吃红萝卜，永远向前跑。给他一个目标，把利益摆在他面前。这 就是用梦想，用画饼的艺术来管理团队，管理企业。很多伟大的企业实际上就是这种模式。
