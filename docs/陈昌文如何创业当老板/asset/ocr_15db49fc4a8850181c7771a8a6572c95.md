# 正面引导与乐观心态对事业的影响

大凡成功者，基本都是乐观主义者，在任何艰难困苦的环境下， 他们都会认为有希望，并且终究能获得成功，而失败者，往往都是只 能看到缺点，看到阴暗面，嘴巴里吐出来的话，几乎都是悲观的东西。

乐观主义者，总是能在失望中找到希望，并且不断的放大希望， 抓住每一个机会往前走。而悲观主义者，总是从希望中，找到失望， 最后鼓动大家啥也别干，不如等死。
