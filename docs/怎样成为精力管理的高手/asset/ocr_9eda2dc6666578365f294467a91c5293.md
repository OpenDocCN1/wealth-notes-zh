# 1. 精力管理的金字塔模型

精力的核心是什么样的一个状态？你可以接触过这样的人，或者你自己就是这样的人：

+   - 每天总是精神焕发、目光锐利、走路都非常快。
- 做事总是条理清晰、效率惊人，工作事业就像开挂。
- 心态乐观豁达，遇到困难也不焦虑。

这种人在你位子上一般是能干或者领导。我们说的管理精力的人，就是想成为这样的人。

# 精力好是不是天赋

在古代有很多有名的人物精力旺盛，甚至“体力”这个词都是因为他们而来的。这个人可能是：项羽或者。

你可能不太熟悉这两个名字，但是“面壁慧光”这个名字你可能听说过。据惠能说的角和光。

“精力”这个词最早出自《汉书·宣传传》，原文是这样写的：

> “能好学，家贫，常从以供粪，尤精力过人。”

什么意思呢？

就是匡衡家里很穷，白天帮人在地里种地，没时间看书，到了晚上还要苦读，他也可以偷偷邻居家的光来读书。最后，他成了西汉的宰相。可见他的精力不是常人，超过了一般的人。

你可能也想，精力好是不是天赋？

我可以明确告诉你，不是。

因为我我自已以前就是精力不好的人，但是通过精力的管理，做到了现在的我这样子。

所以只要学到一个管理精力的方法，变成自己的工具，就一定可以改变自己的。就好像你的身体在地板上，只要你掌握了训练的方法，那么你的一切都能改变。

# 怎么管理精力

该怎么做？精力管理有一个金字塔模型，你该去做到它了。这个模型，如果你了解了这个模型，你知道我们应该怎样去有计划地改善自己的精力了。

# 金字塔模型第一层——体能

如果说汽车只需要一种燃料，那就是汽油，或者是电也可以带电。但是人的精力却是四层组成的。

第一层是体能，是金字塔的最底层。

精力产生的前提就是机能的完整性。可以说体能和精气神，体能就是汽车发动机的马力一样。

为什么体能好的人精力会更好呢？

因为现在的医学发现，体质好，尤其是心肺能力特别强的人，大脑的血氧、供能、供糖都会更好。所以对于脑力工作者来说，长期锻炼工作也不是很费劲。

举个例子，全世界最出名世界级五百强CEO当中的高级职业者，不一定锻炼，即便很多名校，或者美国陆军军事训练，就是他们常说的西点教官。

高来年研究这个问题，他访问了数百名顶尖精英人士的CEO公司，询问了这些高管为什么他们后来的工作最有帮益。这些毕业生提到最多的是四点。

+   - 第一是对于战略的学习；
- 第二是纪律性和团队意识；
- 第三是对于目标感的培养；
- 第四是对于健康的自律和体能训练。

所以在好的体能是精力充盈的基础，也是我们未来选择的影响。体能就锻炼的健身技巧，饮食营养、运动方式、睡眠质量都有关。我在前面的课程里面会从这几个方向给你相应的提升方法。

# 金字塔模型第二层——情绪

情绪精力的影响，你肯定深有体会，比如说当早上起来刷到一件特别气人的事情，心情大坏，一天都感觉精力被抽空。

但是结果有一天会看到一件不关的事情，觉得很难受，一整天都提不起劲，干什么事情都没有心情。现在公认啊有大量的证据表明，情绪对人的记忆、认知、决策力都有影响。

有一点我要说一下认识，积极的情绪有很多的作用。比如说开心、焦虑、抑郁，这些人的情绪和睡眠不好，经常抱怨等，为什么你总是干出这么优秀的作品？是不是负面情绪有时候也会有作用？

我不知道你有没有过同样的问题，但还真不是没有。从医学界的研究，研究人员发现，他们的情绪波动对这些人的研究报告，很正常。但很快大家会释怀。很舒服。

但这话说，他们不认同是，很多时候的时候并不处于情绪非常高涨的时候，处于正面情绪非常高涨的时候。

换句话说，虽然他们经历了很多事情波动，但是真正有改变、有产出的时候是情绪都是好的时候。

所以说积极正面情绪是精力输出的保障。

打个比方，体能好比汽车发动机的动力，情绪好比发动机的火花塞。没有积极的而，再好的马也无法启动了。

# 金字塔模型第三层——注意力

注意力能让我们精力有一个有效的结果，创造出更有价值的结果。

好比汽车行驶的道路，不管你的马力多强，火花塞多响，如果车辆行驶在正确的道路上，走到不了终点。

所以说注意力心理上的心力学家米哈里早就说过，注意力是所有拥有自主控制的最重要的资源。

它已知你的大脑与外部世界建立的一条通道，即所谓信息，也反过来塑造我们自己。没有注意力的能力，我们没有办法发起和无法创造意义，注意力也比较好的发散或者长和塑造。

举例来说，我在试手里面提到的那位同学，其实大家都知道大就是注意力好，他做任何一直是一心一意专注力比较的人，能够专注在自己事情，他的事情非常的了，但是看你典型的问题，我想举手表示一下。

我可能还自己再用“我有多有效管理”来表述，我自己的，比如时间四八分，多屏多开，看书和做PPT，和实际同步记，发现说，如果用我们打个比方，现实比较喜欢双屏和双脑，或者看文章。

但是如果说到影响注意力有挑战的事，在就只是挑战，比如说我想我解答问题，或者要考虑企业的人，比如说一我解决疑问，或者要考虑到别人进行一个重要的谈话，这种事情往往都是不太好的。

所以说，我如果没有进行注意力改善的这种训练的话，或者今后你听不到我来给你这份门管理的建议。

# 金字塔模型第四层——意义感

这是我从业sense of meaning翻译过来的，也就是我们从生活的意义到底是什么。

意义感是人最基本的意义，是驱动我们做事的底层逻辑，是人的操作系统，是精力的最终来源。

为什么有意义感的人精力充沛呢？我告诉你一个哈佛的非常棒的故事，李修雅是我们港大学的同行，以前科技创业者。

如果说一个你可以听到呀，玩《战争雷兽》这个游戏的，你应该听过SKY这个名词，SKY就是李修雅的名字，SKY现在是WCG魔兽竞决赛的职业玩家，人称“人皇”，也就是他玩玩游戏玩得最好。

我跟我SKY聊过的成长经历，我猜是双一手，以前跟李修雅学的，但是成了职业选手之后，还成了世界杯，我觉得太神奇了。所以说他他，也是全做做到顶的。

他发现说，职业游戏选手每个练功小时的职业运动员和上班族，每天要十几个小时，机器里面坐一整天，比如说打散局的速度，占耗点提注意力，每分钟几万次，很多时间都是练技能，他几年时间中间训练。

他大部分的人根本坚持不了，他有一个弟弟他也去他那里学，然后退出了，所以玩职业的人全世界只有几千万，也是成功的是概率极小。

这让我也想起，读大学的时候可能你跟我一样，也会去看比赛，网吧打开游戏过，但打开以后要多的时候发现觉得很空虚，精神头也不好，根本没法坚持。

但是为什么SKY能够十几年一直打游戏这件事，那么高难度的训练，最近地世界竞技行业？首先，SKY在游戏当中找到了意义，我找到了生命能解释意义的地方。

他完全给他一次到哈尔滨训练就过游戏的时候，他也非常安静。当他感受到这个完全就是为所想要的了，后他从小小玩到大，意思的是天数，后者从他们为了职业选手，代表国家，代表国家，更让自己有了意义。

现在他也自己推广严谨游戏竞技运动，都能够有的天赋的青少年，职业选手就是职业运动员，那么就是没有天赋的人，游戏竞技是一种体育精神的表达，他太没有任何的意义。

所以我想说：

> “知道生命的意义，才能够忍受一切。”

有意义感的人，就像航海的时候能够看见灯塔，并且能够见到目的地，会在生命中立定巨大的能量，产生动力。

医学士证表发现，生活中有强烈意义的人，患阿尔茨海默症的征临床中比无意义感的要素2.4倍，很多人甚至没有表现出认知能力，但却一直非常人，没有表现出。

所以我们精力管理的金字塔模型里面，意义感是最顶层的那一层。
