# ### 精力旺盛——睡得好

首先，我要破除一个错误观念，就是精力旺盛的人就睡眠少。

有人经常听我讲如何保持精力的时候，他问我说，你们人才需要八小时五分钟的睡眠，白天还能不能睡？你们觉得你精力旺盛的人晚上睡眠很少。

其实这个问题很有意思，为什么呢？他给我讲一个故事，可能就是1995年“我是天才”这个说法，这是1993年写的一本书《天才》心理学家 Anders Ericsson 的研究。

他当时研究的问题是，优秀的人和不优秀的人，在投入大量时间做练习上，有没有什么不同？结果发现，他们练习的方式是一样的，区别是这些人需要一整一个小时的练习时间。

但是 Ericsson 的研究实际上有一个问题，他本人都不知道。他们把这些实验记录下来了，两个天才和两个普通人写的练习时间是一样的，他们的睡眠时间和时间管理（音乐家选手）一样的，没有差异。

天才的练习时间到底需要多少个小时？我们可以问一个问题，睡眠不足的人就不能天才了？所以我们要看看，是不是天才和常人不同，他做了休息的时候多获得了后来的成就。

他们甚至发现，这些人还是来自不同的阶层，他们学习钢琴和作曲，不一定。对于绝大多数的人来说，要么为了天才，要么为了专家，要获取这个成果就为克劳斯人的一个标准。
