# # 【试听】你为什么需要管理精力

你好，我是张思源，欢迎来到我的得到精选课《怎样做为精力管理的高手》。

先介绍一下我自己，我毕业于北京协和医学院，获得预防医学博士学位，后来在美国的约翰霍普金斯大学获得公共卫生与管理管理的双硕士学位。约翰霍普金斯的公共卫生学院在学院是排名第一的。

我创办了一个互联网医疗的平台，叫做“杏树林”，为很多医生和个人的提供力人生和精力管理的指导。

我自己帮过很多的上市公司董事长、投资人和企业家，帮助他们提高自己精力水平。

你可能听过我的另外一门得到课程，叫《怎样健康活过100岁》。如果说我专门写的是给你的爸爸妈准备的，那这一门课就是给你准备的。

你可能会想，我“为什么需要专门门精力管理的课程？”原因很简单，就是当你的精力水平越来越跟不上工作和生活的要求了。

医学上发现，成年人的精力水平在30岁以后是逐年下降的。

举例来说，人的大脑里有一个组织，叫海马体，它是负责我们的短期记忆的。过了30岁以后，每年，海马体要萎缩0.5%，这也是为什么很多人上了年纪记忆力就变差。

但是，事业、家庭和个人对你的要求却是不断增加的。

你可以问一问你，在过去的三年里面，你的工作和学习的要求是变低了，还是变高了？

你还可以问问自己另一个问题，过了三年里面，你的精力水平越来越低下来了，还是越来越下降了？

如果你发现你的精力是在不断下降，而事业对你的要求又是不断上升的，那么中间迟早会出现一个缺口。

人到中年就会缺这个缺口的人，我们早就已经把它叫做“中年危机”。

在“中年危机”，如果你不采取措施去补缺口，努力去提升自己的精力水平，那你永远也无法弥补这个缺口。

为了提高精力水平，你可能听说过或者尝试过各种各样的方法，比如时间管理、番茄工作法、GTD工作法等等一大堆。

你可能发现问题有一些改善，但是没有得到根本的解决，对吗？

因为时间是一个恒定的资源，我们每人每天都有24个小时，除去睡觉有8个小时的时间，可能你自己支配的时间只有16个小时了。所以时间其实是被管理的弹性非常少。

我们的目标不是延长这16个小时的时间，更重要的是在这16个小时内的状态。

我打一个比方，假如我们每人都会是一台汽车，我们的人生就像是一场拉力赛。

时间管理是去安排我们每天跑的日程，而精力管理就是提升汽车的状态。

如果你的这台车的状态本身就不好，各种爆胎、漏油、发动机动力不足，那么你是很难取得这场比赛胜利的机会的。

我不知道你有没有遇到过下面这些问题，这些问题基本都是精力不够导致的，也是我想通过精力管理帮你解决的问题。

+   * 1. 觉得自己体力下降了，一大早有时候都犯困。
* 2. 体重法控制，喝酸奶、啤酒肚、脸肚肚子都长肉。
* 3. 想想多，多想一点活力，但是又觉得工作太忙，没有精力。
* 4. 觉得工作压力太大，每天都考核KPI，焦虑、紧张，晚上睡不踏实。
* 5. 发现自己记忆力下降了，看一份报告要做完事情，然后一剩看，玩一会儿游戏，做一下又去别了自己也控制不住自己了。
* 6. 有时候甚至觉得自己每天生的命是被别人控制的，忙于奔命，体会不到快乐，甚至有时候觉得生活都没有意义了。

这些问题都是精力管理可以帮到你解决的。人的精力水平其实是有很大的潜力，只要你掌握了方法，练下去，就能不断提升和提高它。
你也能为精力充沛、行动灵活的人。

我先讲一个我自己亲身经历的故事，你也可以看看精力管理是怎么样改变了它，我相信你一定可以改变你。

2008年我从协和医学院博士毕业以后，去美国的约翰·霍普金斯大学，在接下来的一年半之内读了两个硕士，公共卫生和工商管理。

在那期间，为了不给家里增加负担，我还每天一开时间去餐馆打工，赚生活费，所以力其实是非常大的，每天除了睡觉，几乎所有的都是学习的，而且还觉得不够用。

我自认为自已已经是一个很用功的学生了，而且我在约翰大学的时候是一个优秀的学生，但是在那一年半里面，我竟觉得我的精力根本不足以达到学校的要求。

当时我发现我自己有一个同学，新加坡的一个医生，姓黄，我们俩就是他同学学力的一个。

他当时已经40多岁了，他不仅读书好，是我们班里成绩最好的学生，同时还继续边读地从事着新加坡的全职工作。他是新加坡军队里当过急救系统的医生，有两个多个下属，非常忙。

更离谱的是，后来我到他家做客，发现他还有三个女儿，最小的那个女儿才刚出生。所以他还要花很多时间和他太太一起照顾那三个女儿。

我当时觉得自已简直都被他给惊着了，我觉得自已已经很用功的学生了，居然还遇到了比我要高一档的人。

我当时觉得特别好奇，所以我去请教他，这三件事情，每一件在他看来都是一个全职的工作，你是怎么做到的？

在一个晚上，他载我开车，认认真真地听了我很多的问题，包括每天吃什么，每天学什么安排他，学习怎么安排，工作效率在哪里怎么样，睡觉怎么做，他讲了一周很多很好的东西，最后他跟我说：“兄弟，我给你介绍一个方法，叫精准锻炼，我打比分，你现在的状态非常难打败你的业余选手。

虽然你的自我感觉还可以，但是你没有备法，而且你没有受过专门的系统的训练。

而且我的状态非常像NBA的业余球员，在我们新加坡，因为人多、地少，所以需要每个每个人的精力，要把每个人的潜力发挥到极致。

所以从入伍的第一天开始，我们就会接受精力管理的训练。

他那天晚上之后，我才知道，哇，原来精力管理和效率水平可以有这么大的区别，而且很多东西都是可以训练系统地来提高的。

当时我的状态他找到了一种救命稻草，所以我就很认真地跟黄同学学他的方法来练习，发现真的有效。

在霍普金斯的两个学回来变得轻松起来，而且获得了全优的奖学金，我还代表了我们班的毕业生毕业演讲。

2009年冬天，我毕业的时候，当时正是金融危机，美国失业率高居的时候，很多同学都找不到工作，我居然是我们队唯一一个拿到工作Offer的人。

2011年年底，我回国选择了创业，现在已经有7年的时间了。虽然越来越忙碌，但是这一套方法，我一直在不断地坚持，不断提升自己。
