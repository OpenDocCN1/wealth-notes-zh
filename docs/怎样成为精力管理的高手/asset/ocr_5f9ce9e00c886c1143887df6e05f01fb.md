# 昼夜节律和内在平衡节律

我前面举个例子，不知道中午会不会觉得很困。一定都是中午。中午我们在中午饭之后没什么感觉有关？我们为什么困？吃饭和犯困之间有没有关系？

在回答这个问题之前，我要先跟你介绍一下，我们有两套节律，一个是24小时周期那个，叫昼夜节律（circadian rhythm），另一个叫平衡节律（homeostatic rhythm）。

这两个节律共同作用，形成了我们的睡眠状态和困倦感。

昼夜节律比较好理解，就是人以规律周期中受太阳天亮的变化，主要受体内，24小时为一个周期。

你可以把它想象成生物钟，太阳一下来，想睡觉，太阳自然起就醒。

平衡节律主要受光照、体内激素分泌和温度的影响。

平衡节律，主要受觉醒和睡眠时间影响，也可以说，睡觉越久、越晚睡、越难越感觉累。

打个比方，平衡节律就像一个池子，你的能量就像池子里的水，刚开始睡觉，池子水满满的，你觉得精力很好，可以随便使用。

但你用得多，池子水就少，让你困得越来越厉害，好好好。

在一天中，晚上12以后，昼夜节律会让我们慢慢清醒，但平衡节律还在让我们感觉困，这矛盾就累。

在下午2、3的时候，我们会有一个困倦的状态，但内平衡节律还在让我们有清醒的倾向，两者矛盾，我们精力状态不好。

也有说法，这种两个共同作用下会得病。

有一种方法可以帮你避免这两个节律，减少白天犯困。比如你早上多晒点阳光，白天多晒晒，等等。

你也会发现，这两个节律都跟睡有关，为什么下午还会犯困呢？

我要告诉你，昼夜节律和平衡节律，加上饮食的作用，会像我们下午的睡眠的一个重要原因。尤其是高碳水化合物的饮食，比如米饭、面条。

为什么因为高碳水化合物的食物容易变成熟糖，让你越来越困。

血糖上升后，会刺激大脑分泌更多的血清素，让你更想睡觉，进一步加剧睡眠压力。

因此，想解决下午困的，就一定要注意自天的饮食，维持血糖的稳定。
