# 我的晨间七件事

早上起床以后，我会固定做七件事，这会让自己精力充沛，心情满满地出门。

第一件事，我躺一会儿，会在床上做一些简单的活动，包括双手双膝、梳头发、会做腿的拉伸。

这个过程其实是帮助热身，可以让人体先动起来。

我在做这些事的时候，我会用脑子回忆一下昨晚会什么样的梦，因为在做梦的时候，我们的潜意识其实是在工作的。

这个过程会有一些想法、信念、在潜识里被表达出来，自己也会梦见的，其实也是在发现自己的潜意识。

第二件事，我起床以后会一分钟把被子叠好，床整理好。

我知道很多人既不爱叠被子，也不整理床。为什么我还要花一分钟两分来做这件事呢？对我来说有两个好处。

+   * 第一，给我的心理形成了一个暗示：我马上就起床了，我可以起床工作、行动。

+   * 第二，我每天会很整洁地工作和生活。

第三件事，我会喝一杯温水，大概有600毫升左右，相当于一整瓶矿泉水。

一大杯水量能够激活我的身体，同时补充水分，让我的头脑达到清醒的状态。

因为睡眠以后，已经有七八个小时没有喝水了，身体其实是处于一个缺水的状态，所以这个时候，补充大量的水分会很滋润身体的身体。

第四件事，我会用自己不常用的那只手去刷牙。

我是右利手，就是平时是用右手的，所以我用左手去刷牙。同时，我会换两个新牙刷站立着刷，自己不常用的那块区域，可以帮你激发大脑非正常的功能区。

第五件事，我会做很简单的热身练习。

我会让自己的身体和头脑能够尽快启动起来。这大概花个10到15分钟的时间，在这10到15分钟里，我会在脑子里把今天最重要的事情标上下来，我会去想着怎么去想象，这三个目标完成之后的快感和快乐。

第六件事，我会准备一些比较健康的，营养率高但是热量的早餐。

我自己吃的早餐包括全麦的面包、牛奶、蓝莓和酸奶，或者牛奶、水果和蔬菜混合在一起。早餐要吃得很好，不要光吃碳水，比如米饭、馒头、面条这类热热量特别高的食物。

这七件事情做完了，如果快的话只需要半个小时，完成之后就会觉得自己身体已经被充点满，会有一种非常充沛、充沛的精力去应对一天的活动。

# 我的工作日安排

做完这早晨的七件事，我的一天就正式开始了。

在去办公室的路上，我会在脑子里面回想，提醒我一下，今天最重要的那三件事是什么，并且会仔细地确定这些任务的过程。

我会一起走路，爬楼梯到办公室。到了之后，我会立刻开始做这件事，并且不会打开邮件或者微信去阅读一些被动地回复。

从最重要的事情开始，并且45分钟为一个循环，45分钟以后，我会有个5到10分钟的小休息，做一些身体的训练，或者在办公室里走一走。

到午饭的时候，我会很有意识选择中午吃什么。

吃饭的顺序一般是先吃大量的蔬菜，比如吃整颗的圆白菜，或者是大量的绿叶，然后吃鸡蛋肉或者鸡蛋白，再吃碳水或者一些杂粮，比如吃面条，再补充一点碳水化合物，比如米饭或者面条。

我之前讲过，我的饮食，中午是以大量的蔬菜加蛋白质，补充少量的碳水化合物的，所以午饭以后，我不会躺倒，我会到下午去走一走，打一个电话或者整理一下今天工作的进展。

我一般都选择走路接打电话，也可以增加自己运动的机会。

下午的时候，我仍然会以45分钟一个循环来进行，因为每天下午还会给自己安排一个休息，我会在会议间隙做一些简单的拉伸，比如开会前或会后，或者在会议的时候做一些简单的拉伸。

我也会在下午工作的间隙打开我的奇妙清单，回顾自己哪些事情已经做完可以划掉，哪些事情还没有被完成。

我每进入这45分钟的循环，就不用去思考自己要做什么，只需要专注去做即可。

下班之前，我会在脑里再重新过一次今天制定的目标是否已经完成。如果还没有完成的话，自己也会看一下是把它带回家做，还是第二天再想着做。

# 我的睡前七件事

晚上回家和家人相处完以后，我在睡觉之前也会做七件事情，而且这七件事是相对应的，这会让我得到更好的休息。

+   * 第一，我会花几分钟做一个冥想，让自己安静下来。

+   * 第二，用热水冲个脚，很多时候是和家人一起去泡的。

+   * 第三，把第二天早上要喝的汤准备好。

+   * 第四，回顾一下自己今天的三个目标有没有完成。

+   * 第五，花一点时间看一些目标，看看自己重要事项和时间的匹配是否是一个合理的花费。

+   * 第六，在第二天的日历记录下一个简单的想法，看看有什么事情是更让人兴奋。

+   * 第七，把自己要看的书放在床头，上床了以后，阅读30分钟，然后睡觉。

每天早上和晚上的这个小习惯，其实是自己可以制定的习惯，你可以好好地把它利用起来。一旦形成了习惯，形成好的习惯的闭环，这样才能不间断地提升你的效率和精力。
