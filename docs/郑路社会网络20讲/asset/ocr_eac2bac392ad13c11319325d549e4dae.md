# 什么是网络？

简单来说，网络的构成有两个要素：

一个是节点，英文叫node；

另一个是节点和节点之间的连接，英文叫tie。

节点，一般指的是行动者，比如个人、群体、组织，也可以是城市或国家。

连接，是反映的节点间的某种互动关系。最常见的人的关系有：由此构成朋友圈、讨论网、拜年网等等。

在更加宽泛的意义上，网络的研究可以看成是一 切行动研究的学科。从信息服务、情感支持、资源往来、信任与资信的流动，到情感的传递、创新与文化要素的扩散，都可以作为网络分析的对象。

# 什么是网络视角？

首先，网络科学强调连接的重要性。

也许会讲，在现实世界中的每个个体 相互影响、不是孤立存在的。举个 例子， 在很多学科的论述里面，个体之间相互影响的 事实在很长一 段时间却被忽略了。

例如，我们熟知的经济学中的“理性经济 人”，假设每个人都是以追求个人效用最大 化为目的“原子化”的人。但其实，最真实 的不是这样的。
