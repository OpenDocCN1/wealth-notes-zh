# 社会网络的历史里程碑

我们来看看网络科学发展史上的那些里程碑事件。

1932年，美国社会学家莫雷诺（Jacob L. Moreno）研究了一群小学生。他在背后画一张桌子，让他们对小朋友和对女生的在线图，表现出门户若开、小窗对开、小窗对开分析的先河。从此，社会学家开始用视觉的、定量的方式，来分析人际网络。

然后，1959年，匈牙利数学家埃尔德什（Paul Erdos）和（Alfred Renyi）发表了一篇论文。他从数学的角度研究随机网络，提出了生成随机网络的方法。这个理论后来拓展到复杂网络研究的基准，你看，数学又参与进来了。在数学界传奇人物，Erdos是一个传奇人物，他始终没有博士学位，但却是最高产的数学家，一生发表了1500多篇论文。

我们再讲到1965年，在那一年，哈佛心理学家格力玛拉斯（Stanley Milgram）做了一个实验。他找城市选了296个人，请他们各自向一个陌生人发一封信，平均只需转手6次，就可以寄到一个指定的陌生人手里，我们叫“小世界”。并且明显到这个实验之后，让我们在更大一点范围内，人与人之间的距离没有想象中的那么大。

另外一件传奇的事情发生在1978年。那一年，社会学家格兰诺维特发表了一篇论文，叫做《集体行动的门槛模型》。这篇论文，我们在“门槛模型”部分介绍过。它提出了行为在网络上扩散的机制。这是第一个解释网络现象的理论模型。有了这个模型，传播学、计算机、数学等学科的广泛引用，产生了深远的影响。

转眼又到了1999年，物理学家Barabasi和Albert研究发现，计算机网络、电力传输线网络、互联网页的联系、好莱坞明星的演出，这些网络都具备一个特征，那就是节点分布。人们第一次意识到，原来真实世界中形形色色的网络，都遵循着同样的规律。

别管我们是社会学家、心理学家、数学家、物理学家，我们讲这些故事，是想大家来关注在自己的领域里面研究网络现象。在没有任何学科之前，各自都是孤军奋战。

# 一门新学科的诞生

但是，到了21世纪的时候，奇妙的事情发生了。人们环顾四周，突然觉得，居然有这么多学科的人们都在研究网络现象，而且，不同领域的理论之间没有太多共同性。

因此，2005年，美国军方在华盛顿召集了各个领域的顶级专家，成立了一个委员会，专门研究网络的基础理论。你会发现“网科学”这个名称，就是在这次会议上诞生的。

从此以后，每年上亿美元的 nghiên cứu经费，被投入到这个学科的研究中。年轻大学、创新大学的各所大学的系主任，争斗网络科学的学术角色。各学科的中介点。各个领域的专家开始用同一概念和工具，来研究各种各样的网络现象。

从来没有哪个学科，能够吸引这么多领域的专家投身其中。也从来没有哪个学科，能够凝聚这么多的共识，来推动一门新兴学科的发展。

当这些来自不同领域的专家彼此连接以后，就产生了奇妙的化学反应。人们发现，网络的视角和方法，对很多生活具有极强的解释力，在各个领域都有很强的应用价值。

+   - 生物学家用它来研究菌群的传播；
- 传播学家用它来研究谣言的传播；
- 管理学家用它来研究公司里的利益联结；
- 商学院教授用它来研究创新的扩散；
- 反恐专家用它来研究恐怖分子的集结；
- 土木工程师用它来设计交通网络……
