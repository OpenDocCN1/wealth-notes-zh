# 今日得到

我们来总结一下。今天我们学习了一点的关系，比较了**同质地**和**异质地**这两类关系的区别。

我们不妨把朋友和搭档关系看作**横向**上的连接，这种连接更容易在相似素质的人那里得到建立起来。对于**纵向**关系的连接，则性连接会更加**随意**、**质量更高**。

而对于**异质地**的连接，例如商业合作和科学研究等，**异性**的连接更加有利，更加有利于个人的长期发展。多样的、异质性的社会关系有利于我们接触到更多的机会，并重新**记录**思考问题的方式。

简单说，要满足**情感需要**，**同质**性连接更好；要想**成长**，实现自我挑战的目标，异质性连接更有助手。所以，我们要扩大交友交往的“**同质地**”的潜能，跳出自己圈子，拥抱异性，就会拥有更多的机遇。
