# 今日得到

最后，总结一下今天的内容。今天我们讲了一个概念，叫做多重网络，这个概念告诉我们：

首先，网络总是重叠的。网络会因社会关系随时间的发展而变化，**新的**网络会取代旧的旧的。

第二，原来有机会，存在于网络切换的过程之中。与**其他人**半生交情、网络里真正交情、**其他人**、交情变弱、**在**新的网络里建立起自己的竞争优势，占得先机。

第三，企业创新发展的本质是穿越多个网络，个人成长也是如此。发现是网络切换。
