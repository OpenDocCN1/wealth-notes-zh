# 6. 民宿网站入驻

我在节假日的时候会接到旅行的团单，而且一般都是 2-3 起的。

针对游客主要入驻了市面上的平台，比如途家 / 美团民宿 / 爱彼迎 / 小猪民宿等，流量比较大的是前 3 家，另外每个平台都多开了 2 个以上房源，可以理解为多了一份曝光。
