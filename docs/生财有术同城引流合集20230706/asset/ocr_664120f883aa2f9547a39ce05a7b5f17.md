# 二、抖音本地生活业务的起源、发展阶段和现状

抖音本地生活有几个大的时间节点，到现在为止发展了近两年时间。

# 1、抖音POI引爆店码技术，抖音本地生活业务全面爆发

抖音本地生活的起源，来自于抖音在2018年9月，第一次测试推出POI，瞬间把一个餐饮 门店推火了。

很多朋友包括我自己其实刚开始都不知道这个POI到底是什么，这是一个很专业的术语， 听起来很高级。

其实POI（Point Of Interest）就是兴趣点，具体体现为抖音视频上显示的地理位置，也是 抖音同城生活的流量入口，当创作者发布视频时挂上门店的POI时，其他人刷到这个视频 后，对这个地方感兴趣的用户可点击视频下方的链接直接进入门店信息页，了解门店的 地址、营业信息、优惠券领取等，这个现在已经很常见了。
