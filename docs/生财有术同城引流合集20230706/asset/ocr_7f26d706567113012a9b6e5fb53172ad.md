# 一、抖音号发什么内容

民宿酒店是酒店行业里面比较细分的一个品类，这些年也比较潮流。

民宿酒店吸引人的地方，一般都是因为它的地理位置、周边的风景以及酒店的环境非常独特和美好。

所以，抖音视频要把这些独特的、美好的、令人向往的东西拍出来，而且要拍的高清、唯美。

城里人，厌倦了钢筋水泥，高楼大厦，对大自然就非常向往，想去看看，想去体验下亲近大自然的感觉。

像@抖宿，它的视频就是一个大自然的搬运工，把你带入到大自然的环境中，它把酒店和大自然的风 
景融为一体，展现出来，另一个有意思的点，这类视频往往少不了美女，美女映入大自然的美景中， 
美女+美景，让人无限向往。

正因为要体现大自然风景，所以视频都是选的旅游地，这个在视频的合集里就可以看到。

总之，视频从几个方面会让你有一种想去看看，想去住住，想去体验大自然的感觉或冲动。
