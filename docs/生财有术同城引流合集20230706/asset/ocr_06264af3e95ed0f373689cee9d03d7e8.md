# 方向一：全城寻“侠”记

——打造最热销剧《鱿鱼游戏》之线下小龙虾版本《小龙虾游戏》

![](bbox=[0.15, 0.19, 0.6, 0.3])

> 创意阐述：
结合当下最火的韩剧《鱿鱼游戏》，将丹虾的小龙虾背景和特色卖品等融入趣味游戏中，游戏设置：1. 2. 3水头人，测虾争夺奖等，并将最高奖设置为“今年吃小龙虾零干载”。【音克】，在全城发起“全城寻‘侠’记”活动，邀请100位食客若前来参赛，打造全城热点大事件。

传播节奏：
1、前期：发布缩饰视频全城寻“侠”，引发潮仔
2、中期：活动打造大事件营销，抖音、小红书等渠道传播，并将新品带出。
3、后期：开环宣传，进行活动卡牌投放，收割热度
*因为疫情原因游戏可以延期。

# 事件策划

# 方向二：丹虾“红衣行动”

——只要你穿红衣，免费为你送龙虾饮料

![](bbox=[0.15, 0.49, 0.6, 0.68])

> 创意阐述：
“丹虾”的丹字又指“红色”的意思，结合丹虾的名字在11月发起为期1个月的“红衣行动”。活动规则为只要身穿红色衣服进店品尝丹虾双拼套餐，即可免费送 上龙虾饮料。

传播节奏：
1、前期：在公众号发起活动，引发期待
2、中前期：kol跟koc或喜路人穿红衣试探视频发布，引发潮牌，提升销量。

营销事件的策划有几个角度去构思或者是提升。

第一就是你的想法和雏形从哪里来，如果我们不是大的营销策划公司，做这一块是非常吃力的，我的建议是需要及时抓抖音以前官方策划了那些很成功的事件营销，做一些留档，随时根据客户和季节的属性做一些匹配、调整，那这些就是你的一项很重要的能力。
