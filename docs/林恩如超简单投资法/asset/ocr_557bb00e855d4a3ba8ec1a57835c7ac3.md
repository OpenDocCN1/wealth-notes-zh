# ◎ 橫切線

第三種「橫切線」則是運用在局勢不明的盤整狀態，趨勢線的畫法是找出連接股價波動的高點，兩點相連，若此線呈現水平狀走勢，就表示該檔股票正處於盤整，暫時不宜買入，應等到行情走出方向之後再進場也不遲。

![](bbox=[0.2, 0.29, 0.73, 0.46])

趨勢線可以幫助判斷股票是否適合進出場或持續持有，當畫出趨勢線後發現股價呈現向上攀升就表示行情持續中；當趨勢線呈現下降走勢，就表示股價正在下跌；若趨勢線呈現橫切線，就表示該檔股票正進行盤整，可以等待盤整結束，突破橫切線出現明顯趨勢後再擇機進場。
