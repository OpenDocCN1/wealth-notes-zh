# Q7 如何判斷趨勢線？

A：趨勢線分為上升趨勢線、下降壓力線與橫切線，其中，上升趨勢線是指股價在過去某一時間內往上走，找出連接股價波動的低點，兩點相連，畫出股價趨勢，中間不能有K棒穿越趨勢線，若發現趨勢線往上，就表示股價正持續攀升。

反之，下降壓力線是指股價在過去某一時間內往下走，找出連接股價波動的高點，兩點相連，畫出股價趨勢，中間不能有K棒穿越趨勢線，若此一趨勢線往下，就代表股價正形成持續走弱。

另外，第三種趨勢線是橫切線，是指局勢不明的盤整狀態，趨勢線的畫法是找出連接股價波動的高點，兩點相連，中間不能有K棒穿越趨勢線，若該線條呈現水平狀，就表示股票正處於盤整格局。
