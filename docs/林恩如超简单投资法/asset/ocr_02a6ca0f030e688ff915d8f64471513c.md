# 開始聰明理財
選對股是关键

在理财过程中，选股始终是我们遇到难题时的重要依据之一，选股过程中，如何选到一只能够长期获利的股票？我们首先要做的，便是找到真正有价值的公司。

要衡量一家公司，可以从多方面入手。公司所处的行业是否具备吸引力，公司的产品、服务是否具有较强的竞争力以及公司的财务表现是否良好。

衡量一家公司的基本指标有很多，其中，市盈率是一个比较常用、也比较重要的指标，通常用「P/E」来表示。

公司未来的业绩，是影响当前股价的因素之一。如果未来的业绩不及预期，股价就会下跌；反之，如果未来的业绩超出预期，股价就会上涨。因此，投资者要关注公司未来的业绩。

估值高低，要看未来，要看公司未来的现金回报与今天的股价相比，是否划算。估值高低，要看公司未来的成长性。
