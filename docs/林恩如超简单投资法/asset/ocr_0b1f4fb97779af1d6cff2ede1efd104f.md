# 方式 1  定期定額，懶人投資法

定期定額又稱為「懶人投資法」，是指每隔一段時間投入固定的金額做投資，定期定額不必在乎進場時機，也不用在意市場價格波動，只要每隔一段時間，通常是以一個月，若金額太小可採 2 個月或一季執行一次，固定投入成本即可。

# 平均分散成本

由於定期定額是每隔一段時間就投入一筆資金，因此可能買在相對低點，也可能買在相對高點，但可以平均分散成本。由下圖的元大台灣 50（0050）歷年走勢圖可以發現，即使股價走勢有高低起伏，但透過定期定額投資，就可以避免單次就買在相對高點的風險，以及買在相對低點的風險。
