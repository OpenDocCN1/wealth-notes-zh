# 選你所愛，愛你所選

在開始接觸投資時，一定或多或不少會接觸各種投資訊息，像是財經新聞、親朋友好分享、網路文章等，建議在理財投資這條道路上，你必須建立好一套適合自己的投資策略，從頭到尾貫徹執行，不中途中隨意更換方式，反覆執行才能看見成果。
