# ### LESSON 05

# # 賺多少資產，
# 才能實現財務自由？

「一位富翁到一座小島度假，認識一位靠著小船捕魚的漁夫，當時他問漁夫為什麼不換一艘大船捕魚來賺取更多收入？漁夫反問他為什麼要這麼做？

富翁說：『这样就可以賺更多錢、買更多船、擁有船隊捕更多漁獲，甚至創立公司賺更多錢享受人生呀！』但漁夫卻滿足的說：『我現在每天捕魚，晚上回家陪伴妻小，就已經在享受人生啦！』而富翁回答：『也許你已經滿足現狀，但這卻只是我人生的一部分。』」

# ## 全方位財務自由，享受快活人生

上述故事中兩位主角的生活形成對比，富翁因為擁有足夠的時間與錢財，所以可以到處度假遊玩；而漁夫因為沒有累積足夠的財富，只能日復一日的出海捕魚，晚上回家陪伴妻小，過著如同上班族的生活模式，簡單來說，他必須賺取生活所需，沒有選擇權。
