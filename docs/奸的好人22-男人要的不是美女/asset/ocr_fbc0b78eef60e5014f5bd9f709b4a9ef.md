# 男人這東西，成熟或無知？

![](bbox=[0.75, 0.15, 0.86, 0.22])

從前，有個王子要從 3 個女人中選 1 個做未來皇后，不知怎選。父王給了他一個貼士：『給她們每人 5 千元，看她們怎樣運用，再做出選擇。』

王子覺得這方法不錯，就給女生們每人 5 千元。

一個月後，王子召見她們。問第一個女人，她說：『你那 5 千元還是原封不動，我是個幫丈夫精打細算的女人。』

第二個女人說：『我這一個月把钱花在美容和裝扮上，我是一個能讓老公在所有人面前最有面子的女人。』

第三個女人說：『我用你的錢去投資，現在已經有一萬五千了，我是一個能幫老公賺更多錢的女人。』
