# 女人絕情，男人多情

![](bbox=[0.72, 0.15, 0.82, 0.24])

陳老闆突擊我的家，邀請我吃宵夜，我說：「雖然我很大吃（胃口大），但我也不想繼續大吃，否則真的變成李大屎怎麼辦！」

陳老闆心事重重，我怕他向我借錢，馬上掏出錢包，打開給陳老闆看說：「忘記放錢進荷包，等下你付錢，請我喝飲料就算了。」

陳老闆無奈的同意了，可能陳老闆看到我的情況，不好意思開口，所以沒有提借錢一事。

以上情節是虛構的，只有陳老闆突擊我的家是真實的，請我吃宵夜是真的，其他都是我編出來的廢話。

陳很無奈，嘆了一口氣說：「女人真的很絕情，女人不像男人那麼多情……。」
