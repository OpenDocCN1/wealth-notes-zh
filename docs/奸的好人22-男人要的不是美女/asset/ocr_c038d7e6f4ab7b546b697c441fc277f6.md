# 無形的性感

有一次，我和一班朋友在咖啡廳談著佛教修行的話題，但我的視線一直被鄰座的一個女生牽引。剛開始我也不知道到底她有甚麼吸引力，她的樣貌不差，但不能說是漂亮，而且身材胖胖的。理論上她這類型女人應該不會吸引我的注意力，但事實上我的眼睛卻一直情不自禁地看過去。她穿著密實，而且幾乎沒甚麼胸部可言，我卻覺得她很性感。

她讓我在和朋友聊天時聊得很分心，心神蕩漾得蠢蠢欲動，同時又要很辛苦集中精神來和朋友們深入的討論佛法，春心和自律的煎熬簡直是讓我就要盧脫了。她整個人看起來，可以用兩個字來形容：很媚。跟她同台喝茶的男士們，都被這女生吸引住了。

我觀察了超過半個小時，才開始明白這個女生無形的性感。
