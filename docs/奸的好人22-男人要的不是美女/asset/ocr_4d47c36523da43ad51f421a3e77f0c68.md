# 綁住男人心

男人是種多情的動物，很多女人深明此理。於是在一段關係中，很多女生會去管制男人的去向，巴不得拿一條繩來綁住男人，但往往適得其反。與其說這是你愛與關心的表現，倒不如說是你害怕與無安全感的表現。

事實上，你越信任他，他越不想令你失望；你越要管他，他才越要隱瞞。並且，要換掉麻煩纏身的女人，實在太容易了。

最近和舊學員Josie吃飯，她和我分享了一次和男友過生日的經過，我聽後立刻大讚，她果然學懂了，知道如何留住男人心。

話說Josie和男友一起同居，卻從不要求他打卡，男友不在的時候，Josie自己懂得約朋友找節目，上課給自己增值。Josie保留了自己的生活，更讓對方沒有壓力，兩人相處得很舒服。
