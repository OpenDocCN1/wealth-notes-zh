# 解決兩大難題

在解決難題之前，你要認清自己的目標，如果你的目標是不想他與同事曖昧來往，你就先想想有什麼方法可以解決。若真的沒有方法，才預備使用吵架。為什麼我說預備呢？因為在吵架之前是有事情要做的，你最好首先冷靜向他提出你的想法，若他還是不改，你再用憂鬱的心情向他提出想法。

請注意，你是要表達不開心，而不是去埋怨。如果你打算指出他的錯誤，男人只會用理性去辯解，去說服你是錯的；但不開心是感覺，他不能用理性說服你，只能接受他令你不開心的事實。

如果仍然沒有效果，你就要用吵架的藝術。由於你之前已經表達過不開心的感覺，你亦經常向他說：「再這樣我們又會吵架的，我不想這樣。」所以他不會覺得你是無理取鬧的女生，而他的潛意識也有預備
