# 真心誠意沒有用？

![](bbox=[0.73, 0.15, 0.86, 0.25])

我從小到大也認為，只要你是一個絕世美女，任何類型的男士也可以手到拿來。我想，每個女士或多或少也有過類似的想法，對嗎？但事實上我很肯定的告訴你，男人要的，並不是美女。

二十五歲的我，正值花樣年華，有不少人認為我樣子甜美，而且笑容燦爛，拍拖次數應該不少。但我坦白告訴你，可能你不會相信，我只有過一次戀愛經驗，而且歷時一年，最後無疾而終。很可笑對嗎？我自問外表不算差，但我竟然連一個男人也留不住。

當時我總以為我不夠漂亮，因此男友離開我。所以我搜尋各大論壇。試盡各式各樣方法美容護膚化妝，花費鉅額金錢購買療程 …… 沒錯，我的確稍稍變得接近「美女」這個詞了，可惜我夢想中的男士大概還在月球背面吧。
