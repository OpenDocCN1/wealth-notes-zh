# 男人花心的秘密

男人並不傻，相反的，男人往往比女人更理智。長得漂亮一點，我們無疑會對你的印象加分，但也就僅此而已。如果你明天愛上了別人，我們只會覺得有點可惜，卻不會傷心。吸引力是流動的，如果雙方沒有建立到一個關係，要轉移喜歡另一個人，實在太容易了。

吸引力的作用，是把對方留下來和你建立關係。《禁書》1就提及過逆向合理化和流沙效應的應用。舉個例子，寵物狗和人建立感情，重點不是牠有多特別多可愛，而是相處越久，你付出了越多的時間和精神照顧牠，你就會越重視牠。建立關係也是一樣，最重要的不是你做了甚麼，而是他做了甚麼。有沒有投放過，有沒有投入過。

+   1  禁書是香港第一本完整透視戀愛心理學的書籍，集合中、港、台、星馬，十三位華人最頂尖情感專家，共同研究的戀愛解密集鉅獻。
