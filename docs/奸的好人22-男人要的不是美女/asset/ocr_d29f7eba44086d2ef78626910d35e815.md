# 女士約會 Dos & Don'ts

![](bbox=[0.68, 0.14, 0.83, 0.24])

“女為悅己者容”，聽起來總有點彆扭；倘若換成“女為己悅者容”，雖不被學者認同，卻話粗理不粗。

準備赴約的女士們，又該到“喬裝”自己的時候了。為了留下完美的第一印象，總會把自己“大喬”一番，但效果卻答不上比例，因為那往往都不是自己最熟練的妝容，正所謂“出其不意，必自斃”，其實“小喬”一下，效果就已經很搭配。

彩妝“以少取勝”，才能留下你最想顯露的第一印象，而不是“噢，她化了個貓眼妝，唇色也很大膽”之類的精闢形容。總的來說，唇色和眼妝是男士們分辨女孩子頂著個大濃妝的根據。希望約會對象更關注自己獨特的個性，那就該把注意力，放在如何將肌膚“喬”得更光鮮亮麗，看上去靠譜了，交流起來也如意多了。
