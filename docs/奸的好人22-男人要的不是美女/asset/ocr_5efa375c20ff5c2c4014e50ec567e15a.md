# 附錄

據此種種文獻，配搭上現代儀態理論，我們「統 一」發現：原來古今中外，說起吸引男人有媚態的美 女，其目光和肢體語言都不是「直接」呈直線的，都 是「間接」式的有技巧地「斜視」和肢體語言呈「曲 線式的挪動」。

曾經很多大陸的女讀者問我：「男人是不是視覺 動物，男人是不是都是貪新忘舊……」

我多番的告訴大陸女讀者，我是男人，我覺得男 人都很膚淺，男人不但是「視覺動物」，更是「觸覺 動物」；視覺的缺口可以借媚態攻破，觸覺可以靠「不 經意」的觸摸推倒圍牆，其次，才是「放風箏」的相 處哲學。

因此，女人應當以「媚態」來「修飾」自身，靠 「觸摸」來與屬意男人「社交」，最後當以「放風箏」 哲學，以一放一收的招數「管理」感情。
