# 關於作者

總策劃 尹思騰 Instant

香港創業家、作家、顧問、全球天才會 Mensa 成員。

自 2006 年起創業，曾創辦業務包括市場推廣，商業研究，私人會所，兩性關係，銷售培訓等。曾獲邀至馬來西亞、臺灣、北京、武漢等地作公開演講。

Love decode 創辦人，曾帶領中國、台灣、香港、星馬 12 位星級情感專家團隊，創立戀愛解密學，研寫《禁書》、《惡魔獸示錄》等暢銷售，指引無數男女和夢寐以求的戀人甜蜜交往。

Instant 認為人生就如遊戲，每一個關卡都是一場挑戰。因此創辦真人娛樂遊戲《逃出香港》及《Mr.Escape》，並將其業務帶至澳門、星馬、加拿大等地。

曾於《3 週刊》撰寫專欄，曾接受美國《CNN》、加拿大《CBC》、法國《AFP》、臺灣《東森電視臺》、上海《星晨電視臺》、《TVB》等媒體採訪報導。
