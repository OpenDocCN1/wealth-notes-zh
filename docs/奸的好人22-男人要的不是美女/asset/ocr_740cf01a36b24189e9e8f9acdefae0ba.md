# 男人的愛情 女人的事業

![](bbox=[0.7, 0.16, 0.82, 0.26])

有很多女生問我，Ray，你事業那麼成功，生活又那麼忙碌，而且在花花綠綠的商業世界裡，那麼多誘惑，為什麼跟嫂子依然可以那麼恩愛？

這是很多女生都想知道的答案，讓我現在告訴你。

男人的最大福氣就是：在商業世界辛勞打拼過後，回到一個充滿愛的家。當一個男人在事業、金錢什麼都沒有的情況下，找到一個無條件願意跟著你捱的女人，這一點已經足夠男人為你停留。

男人在創業事業上的成敗，賭上的不只自己的人，還有另一半的人生。每個男人在成長過程當中，被教導要堅強，要養家，要守護家人。

男人總是不甘示弱，但又有多少女人了解男人的心情？
