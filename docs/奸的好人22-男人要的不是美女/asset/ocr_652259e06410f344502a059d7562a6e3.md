# 讓他主動來表白！

![](bbox=[0.68, 0.16, 0.8, 0.24])

Chloe 是個很純真可愛的女生，戀愛拍拖經驗不多，拍拖兩次，被騙命中率是 100 巴仙。

對，就是兩次都遇人不淑，一個是有婦之夫，一個在交往期間出現了小三。她從此發誓，要專心工作，向男人和兒女私情說 Bye Bye。

但今次 Chloe 破浪喜歡上了一個條件很不錯的男生，身高 1 米 8，濃眉大眼，很有素質的陽光男孩，而且自己創業，品牌在香港有數家分店。

「雖然我每天早上下班都會收到他的 Whatsapp 訊息，但現在很多男生啊，都不會只追一個女生。條件比較好的男生，甚至同時間跟好幾個女生在交往呀！」Chloe 快樂地跟我分享了沒多久，還是忍不住說出了憂慮。
