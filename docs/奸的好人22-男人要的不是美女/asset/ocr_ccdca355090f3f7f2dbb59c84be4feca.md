# 快樂自在的女生，最吸引男人

記得有一次鄭匡宇博士邀請我去台灣講課，在旅途中我們意外認識了一對日本的女孩子，但是她們不會說中文，我也不會說日語。很多人覺得我們會因此錯過，但重點來了，這個女孩子長得不是非常漂亮，但是我們還是相處得非常愉快。

很多女生會沒頭緒，和喜歡的男人約會時該說些什麼？但她們不知道的是，其實沒有言語的時候，也可以輕鬆愉快地約會。約會很多時候是一個氣氛，吸引男人可以是一個很簡單的狀態。

有些女生心態悲觀，因為一些很小的事情就非常著急，整天埋怨一些雞毛蒜皮的事情，這樣子就算她長得再漂亮，男人也會覺得很難受。或許，你遇過這種女生，她們長得並不漂亮，在開始階段也沒有很多人追求，但，很多男人卻在相處時徹底愛上了她。你有沒有想過，到底是為甚麼？
