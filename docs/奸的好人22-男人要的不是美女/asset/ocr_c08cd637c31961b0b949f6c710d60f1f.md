# 男人都很花心嗎？
怎樣對付他？

![](bbox=[0.72, 0.16, 0.84, 0.24])

如果有一天，你在朋友的聚會中遇到一位男仕。無論外表內在都是你想要的這杯茶，不過你在朋友口中得知，他是一個花心男，在過去一年他交過不少女朋友，數量可用一輛16座位的公共小巴才足以盛載。但重點是，他也對你主動出擊，發放綠燈訊號，你會選擇放棄？還是繼續前進？

很多女生在這種情況下都會選擇放棄，原因是怕男方太花心，看不到未來而終止。但如果我告訴你，即使面對花心男也有方法令他對你死心塌地呢？當你的未來再一次打開了曙光，你的選擇還是放棄嗎？要知道，一生中適合你的茶其實並沒有很多杯。

如果男生一生的事業是工作，女生一生的事業就是愛情。當你將愛情視為事業，你就要相信愛情可以掌握在自己的手上。
