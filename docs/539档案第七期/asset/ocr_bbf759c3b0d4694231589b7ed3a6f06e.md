# 如何提高孩子的词汇量

文字是思想的浓缩。它铿锵有力，能让孩子更理性地思考，让他更好地表达自己的思想，更有力地说服别人认同他的观点。因此，孩子学习的单词越多越好。

# “让我们学习撰写一个更强有力的句子”

翻到任意一页。随机选择一个标题或句子，读给你的孩子。例如：

“美国队进攻曼联队。”然后，问你的孩子，看他是否能用更强有力的句子，表达同样意思。

例如，你的孩子可能会说，“美国队把曼联队打得落荒而逃”。鼓励他使用生动的词语激发听众的兴趣。敦促他经常使用刚学到的更有力、更复杂的词汇，从而将它们牢记于心。每个周日，花2—3分钟时间，来做这个游戏。
