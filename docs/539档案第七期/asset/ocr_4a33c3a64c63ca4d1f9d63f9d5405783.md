# 如何为汽车估值

确定一辆汽车的价值，就像其它许多你无法亲自判断其价值的必需品一样。如果你想要在家里安装一套新的供暖系统，你首先要写一些你可能会关心的事项。然后，根据这些事项要点进行对比。

通过分析，你确定了每家公司提供的产品和价格的大概情况。然后，你根据列表上的数据进行逐一对比。如果所有的好几家的产品品质都一样，但是价格不同，你自然会购买价格低的那一家。在确定好自己满意的产品质量后，接下来，就只需要考虑价格了。

分析汽车的价值也是一样的方法。首先，是一个简单的比较。看在特定的价格下，你能买到什么样的车——简单对比一下参数——以及你对车的其它一些要求——他们是大厂家，还是只是组装商——现在开这种车的人多吗——如果多，有多少？查看有关这辆车的一些纪录，查看它的实用性。换句话说，把这辆车的参数和别的车进行对比。之后，你自己就能确定在特定的价格下，购买哪辆车最好。

把1600美元的威利斯-奥佛兰52，和市场上2500美元的车进行对比，你将会看到这台1600美元的车，和那些2500美元的车性能几乎一样。我们随意抽取任何一辆2500美元的车的规格做个对比。首先是将轴距，然后是发动机——马达——轮胎尺寸——传动装置——内外饰件，等。

将1600美元的威利斯-奥佛兰52的这些参数与之一一对比，看威利斯-奥佛兰52是否在哪个方面无法与2500美元的车匹敌。买车，不能根据价格判断它的品质。而要看你购买的车的价值，事实，以及真实的数据才能决定它的内在价值。事实是评估一辆车的价值的唯一标准。
