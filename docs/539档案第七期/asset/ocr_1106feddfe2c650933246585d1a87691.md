# “不要因为变老而苦恼，这是很多都没有的特权。”

虽然老年有一定的缺点，不过，你对老年的看法可能过时了。如今，很多老年人——超过 1500 万已经 65 岁，甚至年龄更大的老年人——享受着旅游、娱乐，身体健康，获得了许多满足。

想在退休后过得充实，幸福，你现在就应该开始计划了——在你过 65 岁生日之前，就应该开始计划——为你的健康，经济条件，以及你在社区内想扮演的积极角色。

对于一个健康的老人，一定要定期做健康检查，合理饮食，养成良好的卫生习惯，培养业余爱好。

饮食多样化。肉、奶、蛋、家禽、鱼、蔬菜、水果、面包和谷物食品都适量食用，能帮助你保持身体良好的新陈代谢，维持正常体重。时刻牢记远离垃圾食品。

规律的运动，良好的睡眠，定期放松娱乐，会对你的行为和心情带来很大的好处。比如，有规律的锻炼对提升肌肉力量，改善血液循环都有好处。医生会帮助你制定一个计划，帮助你拥有良好的身心状态。

如果你没有有价值的业余活动，任何时候，都不可能幸福。因此，培养爱好或参与社区事务，来活跃思维，让你接触到各个年龄段的人。培养新爱好一个方法，就是参加成人教育课程。
