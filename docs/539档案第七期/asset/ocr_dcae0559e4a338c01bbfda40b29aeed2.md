# 一笔来自过去承诺的付款，更坚定了这个寡妇对美国商业诚信的信仰

# 给每个买车家庭的一封信

来自：伊丽莎白·巴顿太太
波塔基特，罗德岛

我丈夫良好的判断力，在他死亡后几个月，再次得到了证明。几年
前，他买了一辆新车。一个精彩的故事由此发生了。

汽车经销商向我们推荐购买通用 C.I.T.的保险，因为 C.I.T.时间采购计划的很多好处，以及 C.I.T 作为最大的汽车金融公司的良好声誉，我丈夫同意了。

几个月后，我丈夫去世了。我必须承认，从此以后，我一个人承担汽车贷款会很艰难。支付贷款 9 个月后，我接到了当地 C.I.T.办公室经理打来的电话。他给我带来了一个好消息，更坚定了我对美国商业诚信的信仰。我不得不抵押房屋，支付第 9 期汽车贷款，由阿瑟·巴顿房地产开具汇票。一个店员注意到了这点，把它拿给经理。经理看到后，马上打电话给我。

好消息是，我不仅不用再承担任何汽车贷款——而且，C.I.T.将会快速为我退还亚瑟死后，我支付的所有费用。我之前好像忽略了 C.I.T.时间采购计划的信贷人寿保险。然而，如果买车的人去世了，这种保险将会为你支付剩下的费用。

结果：C.I.T.给了我无负担权利，以及一张 747.99 美元的支票，这是我在亚瑟死后支付的全部费用。

我知道了任何经销商，都可以推荐顾客购买 C.I.T.时间购买计划。根据我的经验，我要把它推荐给任何购买车辆的人，以便享受保护。
