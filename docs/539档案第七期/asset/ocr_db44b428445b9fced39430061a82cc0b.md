# 高级经济学家说，现在消费者购买真钻石，可能会受骗！

一位受人尊敬的钻石、黄金、白银、硬币，以及其他珍贵的宝石（被称为“硬通货”）的权威专家 J.C.瑞沃最近表示，“如果你购买的是一颗小钻石——少于 2 克拉——并期望它升值，你一定会失望的。”

经济学家指出以下几点原因：1、转售二手钻石的人很少；2、如果你向珠宝商或其他经销商转售二手钻石，他们将支付只有当前零售价值大约 30%的费用；3、新 Van Pler 仿钻，即使没有真钻石好，在视觉上也没有区别，而价格只有价格虚高的真钻石的一小部分。

> “浪费辛苦赚来的钱，购买高价钻石，真的没有任何实在意义，简直就是在浪费钱。” 瑞沃说道。
