


# 衰落的俄罗斯，屈辱的生意

260819 猫哥星球

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

给大家讲一讲中俄关于西伯利亚2号线的谈判过程。这个事件是一个很好的案例，从这个案例可以看出俄罗斯目前衰落到何种地步。我甚至有一种错觉：这场谈判好像我们拿到的是19世纪俄国与满清谈判的剧本。

西伯利亚2号线，前期谈判卡点是线路走向问题。我们想直通，俄罗斯想经过蒙古。

俄罗斯经蒙古的诉求有两种考量：一个是经蒙古线路更短，建设成本远远低于其他选项；一个是希望通过这条管道对蒙古进行利益捆绑。

一直磨到2026年，中方总算是同意了经蒙古的线路，但是也有条件：过境费全部由俄方支付（每年大概7.5亿美元），中方不管，唯一承诺就是中方在购买俄方天然气价格折扣中适当考虑给俄方以补贴。线路问题解决了，西伯利亚2号线应该很快可以谈妥吧？

但是变数又来了。7月在与俄方谈判中，中方给出一个按照外媒报道描述为羞辱性的报价，这个报价就是50美元/千立方米！并且中方明确提出，必须按照这个价格为基础才能展开谈判。如果俄方不同意这个价​​格基础，那么谈判无限期搁置。

![](img/882223639c19ecabb2c3862c9d55c1b8_0_0.png)

大家是否知道这个50美元是啥概念？过去俄罗斯卖给西欧天然气价格是420美元，卖给我们西伯利亚1号线是250美元，卖给好得穿一条裤子都嫌肥的白俄罗斯价格是120美元。

只有在卖给国内俄罗斯普通人、在财政付出巨额补贴情况下才是50美元。要知道，俄罗斯把天然气开发出来并且运输到中方边境，这个成本都是120美元。

不仅是50美元这个报价，中方还叠加了两个条件：

- 其一，全部人民币结算（西伯利亚1号线是50%人民币结算）。
- 其二，每年买多少气，中方根据自己需求来定（西伯利亚1号线是中方每年必须购买380亿立方米，本来俄方期望中方每年要保证购买500亿立方米）。

那么问题来了，中方为什么在西伯利亚2号线开出一个50美元羞辱性的报价？原因分为两个层面：战略与战术。

首先是50美元价格绝不可能成交，中方真正希望的成交价格大致在125美元左右。

战略原因就是现在俄罗斯很虚弱，不但需要卖气给财政救命，而且再不卖气自己的气田就要废掉了，而中方目前是全球唯一可以增加500亿立方米的客户，记住，唯一。

战术原因就是三点。

- 其一，锚定效应。俄方希望价格按照1号线250美元的基础来谈，中方一下子将锚定标准拉到俄罗斯民用气价格标准（100美元以下），不但大幅度降低俄方心理预期，同时也是对俄罗斯的一种极限施压（特朗普默默点了一个赞）。

- 其二，就是重置定价公式。过去一号线定价公式是油气价与亚洲油气溢价挂钩，现在中方提出我们不搞这一套，给出的定价公式是：俄国内价＋合理运费＋管道折旧分摊（原料价逻辑）。

50美元对标俄国内补贴价，就是在说你欧洲那套垄断租金别搬来亚洲，按你自家卖国内的价格加个运费就算了。公式一旦重定，未来30年长约都按新公式走，比单年单价重要十倍。

- 其三，给俄方还价的空间。50美元低到羞辱级，俄方绝对不可能接受，但正好给双方预留了空间。中方开了个离谱价，然后俄方驳回，经过艰苦谈判双方在120—135美元成交。

若中方直接开120美元，俄国内民众会骂为什么比1号腰斩还低。开50美元，俄方驳回时，中方后续让步也是给俄方一个台阶。50美元是战术羞辱，不是真正的目标。

顺便说一下，为什么要搞这个战术羞辱？

俄罗斯对中国长期是分层外交。在涉华核心利益上，俄罗斯从来都是表达坚定支持立场，比如台湾问题，俄罗斯的表述是全球独一份。

但是在非核心利益上，俄罗斯从来小动作不断，在缅甸、在越南、在南海、在图们江，俄罗斯搞出无数小动作。某种意义上，这些小动作也可以理解为对中方的战术性羞辱。

中方对此也是同样回报。在涉俄核心利益上，比如乌克兰问题，中方从来没有谴责过俄方。西方给中方施加这么大的压力，中方也坚定要与俄方保持正常贸易。

但是在俄气的经济利益层面，中方开出上述条件也算是小小报复一次。对于普通人，可能关注点是价格，但是站在中方立场，全人民币结算、要多少买多少（不要照付不议）同样是重点。为何？首先给大家解释一下什么是照付不议。

这是天然气长协经典条款，意思是你买不买、提不提，都得按合同最低量付钱。

例如：中俄若签2号线，俄方要每年500亿立方米、30年、照付不议，即哪怕某年中国需求不足，当年只提了300亿立方米，剩下200亿立方米没提，也得按500亿立方米全价付款。

卖方（俄气）拿这个无条件付款承诺去银行质押融资，就能覆盖250亿美元管道建设沉没成本，但是对买方压力比较大。西伯利亚1号线合同（2014年签）里有照付不议，中方接了，因为当时欧洲还是俄气大买家，中方气源单一。

2号线中方要废掉这个条款，因为现在中方是唯一超级买家，而且现在俄罗斯特别虚弱。当然，中方也有现实考量。2号线建设周期6年，即便2026年达成协议，也要2032年后才通气。中国天然气需求2035年左右见顶，2号线价值在补2026—2035年国内天然气增量。2035年后中方天然气需求是逐年下降的，所以废掉照付不议，不仅自己未来可以从容挑选全球买家，还可以以此为筹码施压俄方换取其他领域的好处，比如你不在我周边搞小动作我就多买一点，你搞小动作我就少买一点。

现在中俄关于2号线谈判基本搁置，但是时间是中方的朋友，越拖下去，对俄越不利，对中方反而有利。为什么？

首先是俄罗斯现在财政很困难，急需这笔购气款回血。然后就是欧洲断气后西西伯利亚气田被迫放空烧气或封井，时间拖久了，西伯利亚气田产能持续不可逆地衰减。

最后就是外部政治因素。举个例子，近日美国参议院通过一个法案，授权总统谁买俄油俄气就对谁加征100%关税，并且直接点名中国。这个法案一旦在众议院通过，特朗普大概率会签字（给自己增加权力，傻子才不签）。

如果这个法案通过，就是中方在谈判桌上对俄方最好的施压筹码。你看看，我要买你的油与气要承担多大的政治风险？所以你的价格还要给出让步。

这种情况下俄方是没有还价的能力的。所以，如果俄方今天签，可能价格是130美元；真到了老美法案通过，这个价格至少还要让步20美元。

其实目前俄方已经放风准备接受130美元左右的价格，但是中方执意废掉照付不议，对于俄方而言确实太难受了，所以还想争取一下。

但是时间拖下去对俄方是很不利的。如果在2027年达成协议，预计还能达成125—130美元左右价格，另外估计能给一个300亿立方米的保底购买量；如果拖到美国那个法案通过，估计就要到110美元了；拖到2028年，预计就是105美元以下了（与中东国家签订了长期协议），保底购买量也会下降。

顺便说一下，老美那个法案通过实际影响也不大。特朗普现在不敢对华加征100%关税，去年试过，很快就妥协了，反而这个法案是中方对俄谈判最好的筹码。

最后再多啰嗦几句。中俄在处理地缘政治冲突上完全是两个极端。俄罗斯面对地缘政治冲突直接就是用军事怼上去，也就是很多网民推崇的所谓“打得一拳开，免得百拳来”。

而中国呢？面对地缘政治冲突往往都是克制处理，搞得一些小国都要蹬鼻子上脸了。这种模式被很多网民定义为怂，明明中国军事力量比俄罗斯还强大无数倍，好不好？为什么不教训一下这些小丑？

但是一个硬、一个所谓的“怂”，最后的结果是什么？是俄罗斯被全世界孤立，拿着全世界最硬的硬通货——天然气资源，基本是快要跪着求我们购买，而我们反手给俄罗斯开出的却是羞辱性的三件套！大家想一想这是为什么？改天详细讲一讲其中的门道。
