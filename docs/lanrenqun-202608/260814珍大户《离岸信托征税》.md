# 提问

珍大户，大户你好，想问下7月24日财政部和税务总局发布的离岸信托个税新规，对那些资本大佬有什么影响，影响多大，是洒洒水补交下税款，还是把桌掀了不让玩了？

对国家来说有什么意义？谢谢。【帖子编号1088】

离岸信托收税这个文件主旨，就是离岸信托要收20%税。但实操起来有很多细节，比如，第一个问题：假设军总在创立大米之前，用开曼群岛注册的方式持有的初创股权。

请问这部分能收到资本增值的税收吗？你会发现以前能避税，后来6月份出了对外投资的规定后，【帖子编号1079】跨境投资监管收紧等政策解读，国人直接持有的海外资产，包括开曼群岛的股权，都开始要交20%的税了。

第二问，假设军总突然意识到，直接持有股权避不了税，那么装入信托呢，就等于不是自己持有，而是信托财产了。

以前是收不上税的，现在有了7月24号这个补丁，又开始收上税了。

第三问，假设某底捞某勇夫妇看见了，发现当中国人已经没办法避税了，开始更换国籍，把所持有的股权装入信托。

这种情况要不要收税？你会发现，有CRS税收居民认定，只要赚的钱大部分从中国赚的，哪怕你是外国人，也要开始收税了。

第四问，假设雷总和勇总都发现，只要在中国经营，哪怕国籍变了也没法避税，于是雷总去印度开厂了，勇总去纽约开店了，请问这时候还能收到税吗？

目前各个补bug的规定中，体现出来的态度，大概就是——你的原始资本是从中国出去的，在海外经营运营产生的收益、增值，子子孙孙无穷尽也，一定会收税的。

现实中，实操层面可能还有难度，但法理上已经开始要这样了，后面理论上只要中国军力和控制力越来越强大，基本可以连带着收到巨大的海外税源。

只要你是中国人出去的，或者外国人曾经在中国赚到了钱带出去的……讲到这一步，大家再想想影响有多大？

但问题来了，国家下棋，基本上走一步望三步。

现在的一串政策下来，真的只是为了那些有海外信托，或者前些年转移财产出去的人吗？如果只是这样，格局小了。

大家回想十五五规划。我提到过，十五五规划里有讲，要开始尝试资本项下的自由流动（就是资本、纯粹钱的自由兑换、资本自由进出）。

以前国内钱出去是不准的，会严格审批，性质上算是资本外逃。因为国家知道，出去了基本就成鱼入大海，再也无影无踪了，没有能力管到海外。

而开始敢要尝试资本自由流动的话，其实前提条件就是，开始感觉有能力管到海外了。

其次，我们前面讲海洋经济的时候，一路在讲，国内开始要有意识地推动资本走出去，出去买矿山、矿井、港口、码头、土地、林地、股权、专利……想让国内的资本大规模地走出去，如果能力上管不到，税收都收不到，那么就是财政衰落，国内财权式微，开始不断地有海外资本巨头成长起来，名义上似乎是中资，但实质上因为管理不到，就类似于，要么发展成日本和韩国的那种财团、权力大于国家；要么更严重的，像缅甸太子集团那种性质，开始变成海外的土皇帝。控制力无非体现在两个方面——能否管得住钱，能否管得住人。

我们看到的，无论是6月的境外投资管理规定，还是7月的信托收20%税，都是为了未来大规模资本走向全球，而提前谋划的管住钱的手段。

他需要知道你手里有多少钱，全部在监管范围内。分账比例，基本定成二八开。而后续，怎么管住人？制定法规和制定制度，是需要时间周期的。

我推测最近三年，可能都在谋划怎么管住钱。再往后，后续的计划和补丁肯定会开始往“怎么管住海外的人”去走的。要有覆盖全球大部分的长臂管辖权力，要有覆盖大部分国家合作的全球缉拿能力，要有对危险分子的极端惩戒能力——远程打击、定点消灭。

也要有轻柔的微小惩罚能力——罚款，对海外的治安处罚、行政处罚、谴责、扣护照等等。我也没什么额外的建议，因为大家只能接受。

况且二八开也不算太疼，至少比国内个税税率低多了。

对已经事业成功的企业老板、创业者来说，可以思考一下你的事业有没有出海的可能性。

对找工作的年轻人来说，需要看到下一个10年，中国资本全球化的趋势。这个趋势下，会带来很多新增的工作、就业乃至创业的机会。

我们圈子里大概刚建圈子前后，19年左右就叫大家不要再学建筑和会计，说过剩行业。还有不要学外语。

这些领域的存量人才，大家注意选定一片区域或者国家：建筑类的去学当地的施工标准、建筑法规；会计类的去学一个能跨国工作的能力，证书提前考一考。

外语类的尽量跨行到跨国法律或者跨国专业领域的翻译上。当兵的、准备退伍的，用不了几年就能看到，会开始出现各个国央企大集团招聘退伍兵海外驻扎的安全、维保类岗位，也是可以考虑的。

## 承包大棚种小番茄

因为现在有AI了，所以我直接问了一下AI：

1. 大棚的面积一般多大？  
   答：一般1亩到1.5亩。

2. 小番茄亩产一般多少斤？  
   答：如果非无尘玻璃、无土栽培、智能温控这种技术，只是普通的大棚种植的话，一般单季亩产6000到1万斤。

3. 大棚租金一般多少钱？  
   答：山东地区一般2000~5000元每亩每年。

4. 其他成本多少钱？  
   答：苗种、肥料、农药、地膜、人工，一般1.5~2万元每年。外加病虫害防治、灌溉管道更新，可能还要增加5000到1万元。总成本每亩在3~5万元每年。

5. 小番茄批发价多少钱？  
   答：普通小番茄收购价约在2.5~4.5元每斤，可按3.5元每斤平均计算。如果是品质极高的糖度口感番茄，收购价可达6~8元/斤。

6. 上面提到的品质极高的、收购价6~8元的小番茄，成本会上升吗？  
   答：苗种钱翻倍。有机肥和特种肥每亩增加1万元。需要额外精准控水控肥，人工摘除多余的花穗和弱果，采收更仔细，综合人工成本比普通番茄高30~50%。

此外，为了保证口感糖度，亩产需要强行减半以上……

我不知道上面AI给的信息对不对，但是上面一问完，明显跟你提问里给的信息有很大的出入。

你说单个大棚投资20万元，这意味着这个大棚难道不是普通的一亩大的，而是单棚5亩以上的？

其次，单棚30万元收入，按3.5元每斤批发价，一个棚需要8.5万斤果子；又或者出售价格非常高，用你们门店零售价来做收入？

所以，你给的数据是有异常的。建议你三思后再决定。

另外，上面是从数据角度分析的，如果单纯从投资角度，依然是有不合理之处的：
