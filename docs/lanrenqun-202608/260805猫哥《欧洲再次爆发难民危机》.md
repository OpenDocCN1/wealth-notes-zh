# 欧洲再次爆发难民危机

260805 猫哥

整理：公众号懒人搜索，懒人专属群精选

2026年7月末，六万非法移民从摩洛哥涌入西班牙北非飞地休达。休达人口才八万，一下子涌进六万人，几乎压垮了这座小城。

休达市长直言，城市快崩溃了。这是2015年后欧洲最大的难民危机。

那么，这是怎么回事？

导火索是西班牙最高法院的一次裁决。2024年，一名阿尔及利亚难民游泳进入休达，被西班牙国民警卫队遣返。难民提起诉讼，声称西班牙政府的举动违反了《外国人法》。

《外国人法》第十附加条款规定：当移民试图翻越休达或梅利利亚陆地物理围栏时，可以当场遣返，不用走司法程序。这是边境管控的执法依据。

阿尔及利亚非法移民找到了漏洞，《外国人法》只是规定移民翻越陆地物理围栏时可以遣返，没说海上到达的移民也可以遣返呀。

2026年7月8日，最高法院裁定，海上到达的移民，不能当场遣返，必须走司法程序。

![](img/f090bd3e558cb0c321c1070eb4c278c8_0_0.png)

其实，一个非法移民，哪有能力找到法律漏洞，病因在西班牙执政联盟。

西班牙执政联盟，由工人党和汇总运动组成。工人党欢迎移民，但没那么极端，工人党席位数不足，无法组阁，找了“汇总运动”联合组阁。

“汇总运动”是一个大帐篷联盟，包括西班牙共、绿党等十多个白左政党，几乎全员白左，主张废除边境管控，《外国人法》的漏洞就是他们发现的。

诉讼从一开始，就得到了“汇总运动”的支持，裁决带来的后果，是遣返难度大增。

以前抓住非法移民，当场让你滚，现在，只要你从海上来到休达，不能当场让你滚了，得走司法流程。

在NGO的教导下，全世界的非法移民，都学会了怎么应对司法流程，比如，他们会扔掉一切身份信息文件。

你说默罕默德是尼日利亚非法移民，让尼日利亚政府来把人接走？不好意思，西班牙政府拿不出证据，证明穆罕默德是尼日利亚人。

因为扔掉了身份证、护照、驾照，就连穆罕默德这个名字都不知道是不是真的。

没有两三年，司法流程走不完。不走完司法流程，非法移民就能呆着，还有权申请“工卡”，一旦申请成功，就能留下来工作。

消息很快传遍世界，非法移民们高兴坏了。

只要游泳进入休达，起码一两年不会被遣返，几万名非法移民蜂拥而至。西班牙政府被迫紧急增援三千兵力，才勉强控制了局势。

2015年难民危机后，欧洲建立了非法移民防御机制，核心是立即遣返。西班牙的《外国人法》第十附加条款，就是2015年通过的。

有立即遣返机制运作，非法移民的数量勉强能控制。对这个条款，白左们非常痛恨，一直想废除，西班牙最高法院的裁决，打开了潘多拉魔盒，等于把欧洲的难民防御体系撕开了一个大洞。

非法移民先跑西班牙，再经西班牙进入欧盟各国，会成为一条“成功路径”。休达在短短几天内，就濒临崩溃，算是打了个样。

本次裁决的影响，可能极其深远。

休达难民危机后，意大利立刻宣布，暂停和西班牙的《申根协定》一个月，对从西班牙乘飞机或轮船抵达意大利的非欧盟人员，进行严格检查（意大利和西班牙陆地不接壤）。

简单来说，以前你向西班牙申请了“申根签证”，可以自由出入其他欧盟国家，基本不受检查。意大利暂停后，你想进入意大利，就得接受严格的盘查。

《申根协定》的内容是人员自由往来，各国大幅降低边境检查的强度，是欧盟存在的重要基础之一。

自生效以来，极少有国家暂停《申根协定》。

2015年难民危机，欧洲各国也只是加强检查，没有暂停《申根协定》。

2020年疫情暴发后，欧洲各国为了阻止疫情传播，也曾加强边境检查，依然没有暂停《申根协定》。

那么，意大利的反应为什么这么大？

意大利总理梅洛尼作为极右翼，不欢迎非法移民，而西班牙首相桑切斯，长期批评梅洛尼在海上遣返非法移民，两人一直不对付。

但梅洛尼的举动，不能完全说是落井下石，如果非法移民大量涌入西班牙，势必外溢到其他国家。而《申根协定》又规定各国要减少边境管控。

这样，非法移民就会从西班牙，进入意大利。

意大利的态度是一个缩影，8月1日，欧盟27个成员国中的22国领导人签署联名信，对休达发生的难民危机表示严重关切，要求西班牙阻止偷渡者。

剩下的4个国家，也就是法国、葡萄牙、卢森堡和爱尔兰也不完全支持西班牙。如果西班牙不能解决问题，会有越来越多国家暂停和西班牙的《申根协定》。

前面说过，《申根协定》是欧盟存在的基础，如果各国纷纷暂停《申根协定》，重启严格的边境管控，欧盟这栋大厦的地基就严重动摇了。

同时，难民危机还会影响欧洲的政治生态。

2026年下半年，瑞典、拉脱维亚、保加利亚都将举行大选。

2027年，举行大选的欧盟国家更多，也更重磅，包括法国、西班牙、波兰、意大利这四个核心国家，还有芬兰、斯洛伐克、希腊和爱沙尼亚。

合计十一个国家，要举行大选，接近欧盟成员国数量的一半。

2015年后，欧洲极右翼崛起，但大部分极右翼只是参政（进入议会），距离执政还有距离，建制派的联合围剿，导致许多极右翼政党虽然得票率第一，但无法单独组阁。

只有梅洛尼等少数极右翼，实现了执政。可即便梅洛尼也不得不改变部分极右翼主张，因为欧盟大部分国家，依然是建制派执政。

全得罪了，代价太大。欧洲极右翼需要一个契机，一个让他们完成从参政到执政转变的契机。

本来欧洲社会就被俄乌战争、疫情等各种困难折腾得半死不活，大家日子不好过。

非法移民大量涌入，将是欧洲极右翼的大选福音。

想想看，还有什么议题，能比非法移民更吸引人？

非法移民会和你争夺福利、工作，还有各种资源，绝大部分平民的利益，都会受到损害。很多日子人未必赞成极右翼的全部主张。

但非法移民不受控制的后果显而易见，当广大日子人的利益受到损害，在愤怒情绪下，大概率倒向极右翼。

接下来，事态如何发展，要看桑切斯的智慧。他必须想方设法压制住联合执政的“汇总运动”，分化瓦解也好，威逼利诱也罢，总之不能再让“汇总运动”搞事情。否则，欧洲极右翼将真正登堂入室。
