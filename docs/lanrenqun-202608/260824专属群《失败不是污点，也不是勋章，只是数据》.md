


# 失败不是污点，也不是勋章，只是数据

260824

整理：公众号懒人搜索，懒人专属群精选

今天先请你做一个简单的测试。想象，在一场体育联赛里，不管是足球、篮球，还是乒乓球，把所有选手的所有比赛场次加在一起。请问，是获胜的场次更多，还是失败的场次更多？

其实答案并不难，是一样多。因为一个队赢，就必然有另一个队输，而平局没有输赢，不计算在内。因此，从整体上看，输赢的场次一定一样多。

很简单对吧？但是，关于这个问题，有人专门做了一个测试。结果发现，被测试的大多数人都认为，输球的场次是比赢球的场次少的。当然，发起这个测试的人做了一点小设计，让受试者尽可能用直觉作答，而不是深入思考。具体的设计咱们就不展开说了。

这个测试出自去年《人格与社会心理学杂志》上刊登的一项研究，研究者叫劳伦·埃斯克里斯-温克勒，是西北大学凯洛格商学院管理与组织系的助理教授。研究的题目叫“The Failure Gap”，失败缺口。研究人员调查了大约3000名参与者，让他们估计三十多个领域里，各种失败出现的概率。

![](img/3de33eeb4124cdbbc5786952a1108e86_0_0.png)

注意，这里说的“失败”，不是专指创业破产或者人生挫折，而是泛指事情没达到当事人预期。包括，药吃了却没效果、学生没能按时毕业、机场安检漏掉了危险物品、一段关系结束，以及前面提到的一场比赛输掉，等等。

研究者再把人们的估计，与真实统计数据做比较。

结果发现，在大量不同领域里，人们都系统性地低估了失败的数量。比如，真实灭绝的物种数量，大约是人们意识到的三倍，也就是，每灭绝三个时，多数人觉得只有一个。再比如，机场安检漏掉的危险物品，大约是人们以为的五倍，每漏掉五件，人们以为只漏掉了一件。

失败的真实发生率与人们想象的发生率之间的距离，就叫“失败缺口”。你可能会说，这不就是乐观偏差吗？人总愿意把世界想得好一点。

还不太一样。乐观偏差大概说的是，我们容易低估坏事发生在自己身上的概率。比如觉得自己不会生病、不会失业、不会遇到事故。

而失败缺口说的是，即使问题与自己无关，即使是在判断整个社会，即使答案可以通过简单逻辑推出来，我们仍然会觉得，失败应该是少数。也就是说，多数人并不只是高估自己的运气，而是对这个世界究竟有多少事情会出错，缺少起码的现实感。

那么，这种错觉是怎么形成的？研究者认为，关键原因之一是我们平时接收到的信息，本来就不是现实的完整样本。研究团队分析了超过两百四十万篇新闻报道，结果发现，相对于现实中的发生频率，失败获得的呈现，明显少于成功。一家公司完成融资，是新闻；一家同样规模的公司悄悄停止经营，未必是新闻，除非这家公司本身名气就很大。

有人可能会说，不对啊，我们经常看到新闻里全是坏消息，那新闻怎么还会低估失败呢？

因为“新闻很负面”和“新闻准确呈现了失败的发生率”，是两回事。一次后果严重、场面戏剧化的事故，可能被连续报道好几天，让人觉得世界充满危险；但与此同时，数量更庞大、过程更普通、没有什么戏剧性的失败，压根不会进入报道。

换句话说，新闻可以在情绪上非常负面，但在统计上依然漏掉大量失败。除了新闻之外，社交媒体、消费点评网站，还有各类信息渠道上，失败被提及的概率都要比成功低。这也是为什么你打开朋友圈，总是觉得别人的生活都很精彩，好像只有自己最无趣。

那么，对失败率的低估，会产生什么实际后果呢？最直接的结果之一，它会影响我们对待失败的态度，不管失败的人是自己还是别人。比如，一项任务，100个人里只有2个人没有完成。这时你看到其中一个失败者，可能会想：别人都做到了，为什么偏偏是他不行？是不是能力有问题？是不是态度有问题？

但假设同一项任务，100个人里有60个人都没有完成。这时你首先会问的，通常不是“这60个人怎么都不努力”，而是：是不是任务的设计有问题？资源是不是不够？流程是不是有缺陷？

你看，基准率一变，因果解释就变了；因果解释一变，责任分配和解决方法也会跟着变。这就是失败缺口最明显的影响，当我们低估一种失败有多普遍时，就会高估失败者个人应负的责任，低估环境、流程和支持系统的作用。在前面的研究里，当人们知道了真实的失败率之后，普遍变得更加“宽容”，相比于“苛责”，变得更倾向于“给予支持”。比如，教育工作者对停学等严厉处分的支持下降了，管理者更愿意延长新生儿母亲的带薪休假。

注意，这并不意味着，只要一种失败或者错误很常见，个人就不需要承担责任。闯红灯的人多，不代表闯红灯就是对的；一个流程里频繁出错，也不代表每一次疏忽都值得原谅。

失败缺口真正提醒我们的，是判断的顺序。在评价一个人之前，先问这种失败的基准率；在追究个人责任之前，先检查是否有大量相似的人在同一个地方出错。不要拿结构性高发的问题，对个人做诊断。

听到这，有人可能会说，既然失败比我们想象中更常见，那是不是失败也没有那么可怕？是不是失败之后，人自然会吸取教训、重新振作，最终走向成功？

根据研究者的统计，未必。做“失败缺口”研究的这个学者，在2024年还发表过另一项研究，名字叫《被夸大的失败益处》。

研究团队做了十一项调研，包括很多问题，比如，一个人在职业资格考试中失败后，下一次通过的概率有多大？一个人在遭遇心脏疾病或者药物过量之后，改变生活方式的概率有多大？一个人犯过错误之后，真正吸取教训的概率又有多大？

结果发现，人们普遍高估了失败之后出现成功的概率。我们总觉得，一次沉重的失败会让人警醒，会逼着人认真反思，会让人下一次做得更好。但实际的传导链条经常是，失败会伤害自我评价，会让人不愿意重新查看反馈，不愿意回到让自己受挫的现场。

你看，把这两项研究放在一起，会得出一组很有意思的结论。

一方面，失败比我们以为的更常见。另一方面，人从失败中自动吸取教训的概率，又比我们以为的更低。

换句话说，我们同时抱有两种错觉：第一种错觉是，别人很少失败，所以我失败一定说明我不行。第二种错觉是，失败自然会带来成长，所以跌倒了也没必要反复回看脚下的泥坑，要把目光放到未来。前一种错觉，会制造羞耻和苛责。后一种错觉，会制造放任和浪漫化。

从这个角度看，一个更成熟的失败观，不是“失败没什么”，也不是“失败是成功之母”。而是：不要羞耻化失败，也不要美化失败。失败需要被看见，更需要被处理。

那么，具体怎么做？我们从相关的研究里，整理出了这么几个行动方向，供你参考。

第一个，用问题替换结论。下次当你因为一件事没做好，开始怀疑“是不是就我不行”，这时先别急着下结论。先问另一个问题：和我处于同样条件、同样阶段的人，完成这件事的比例到底有多高？这里的关键是“同样”。第一次负责复杂项目，不能拿自己和做过十次的人比；刚开始运营账号，不能拿自己和行业头部比，得把参照系校准到真正相似的人身上。

然后再把结果和诊断分开。“项目失败了”是结果，不是原因。复盘的时候，要逼自己回答一个更具体的问题：这次是哪个环节出了问题？是当时信息不够？是对市场的判断错了？是执行没跟上？

第二个，在开始之前就设置检查点。失败缺口会让我们倾向于把计划建立在“事情大概会顺利”这个假设上。面对这个情况，有一个流传很广的方法，叫“事前验尸”。做法很简单：在项目启动之前，先假设它三个月后失败了，然后问：最可能是因为什么？最早会出现什么信号？一旦看到这个信号，我们就该调整或者停下来。

这样做的目的，是把失败从“事后才知道的结果”变成“事前可以管理的风险”。真正危险的不是失败本身，而是信号早就出现了，但没人注意到。

第三个，让失败留下记录，而不是只留下情绪。对个人来说，失败之后可以问自己：我当时是怎么判断的？真实情况是什么？哪个信号被我忽略了？

对团队来说，季度汇报不能只展示“完成了什么”，还要记录：尝试了多少次，多少事没达到目标，失败集中在哪个阶段，哪些是正常的探索代价，哪些是可以预防的重复错误。

管理者真正要做的，是降低报告失败的代价，同时提高隐瞒问题和重复犯错的代价。开放讨论失败，不是取消责任，恰恰相反，只有失败能被说出来，责任才能被放到真正应该承担它的地方。

最近网上有句话很流行，叫，“那不是我的黑历史，那是我的来时路”，说的是人面对过去的态度。但是，今天的研究想说的也许更冷静一些：那些过往的失败，既不必被污名化，也不必急着美化。它们首先是数据。

物理学家理查德·费曼说过：“第一原则是，你不能欺骗自己，而你恰恰是最容易被自己欺骗的人。”从这个角度看，面对失败，真正重要的不是替它取一个更好听的名字，而是让它成为一个数据样本，用来校准你的思考、判断和行动。
