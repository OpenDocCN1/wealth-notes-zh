




# 长江存储上市怎么看？

长江存储上市怎么看？说实话，我是觉得很夸张。

**1. 发行市值与利润**

公司一季度的利润有330亿了，当然这里面有110多亿的利润回转，扣除掉这个因素之后再考虑上今年半导体应该还是一个上升的趋势，也就是说今年年内利润很可能有900~1100亿。

**2. 市值空间测算**

按照它330亿的募资金额来算，上市估值在2700亿到3300亿。而上市之后给予多大的市值空间呢？我算了一下，长鑫科技按照今年的利润来算，市盈（PE）在27倍。

长江存储相对于长鑫来说，本质上也就是NAND相对于DRAM赛道来讲，前者的护城河相对要浅一些，竞争对手相对要多一些，竞争格局要差一些（前者全球大概有6~7个玩家，后者全球只有4个玩家）。所以市盈率哪怕给低一点，就给今年20倍的PE，那么也有2万亿。如果乐观一点，考虑到长江存储有独特的堆叠专利，给到25倍PE也不是不行，那就是2.5万亿。

![](img/124ca0a7a5ab9bad3c4976abfe5a6a2d_0_0.png)

那你想想它的涨幅是多少倍？理论上是6~7倍。

**3. 中签吃肉**

那么这块肉可能比长鑫其实还要大，太夸张了！而且本身募资额也高，330亿。金额大一点的散户基本上是稳稳中，然后我们机构这边，中签率90%。算出来收益非常夸张，很有可能能给我们带来稳定的1%收益率。所以说，长鑫加上长存这两个，再加上宇树科技，今年加起来可以稳定带来2%的收益率。你存款一年才多少？也就2%。所以说，股市今年下半年的科技肉吃得是很肯定、很舒服。

**4. 对板块预示**

今年一季度毛利率接近80%，净利润率70%。这是什么概念？在现在中国整体的宏观环境下，这就是暴利中的暴利！赚钱能力堪比茅台。关键是茅台没有增长呀，没有想象空间，但AI是真的有。

所以说，把这一份财报拿出来，估计对下周的A股又有一个提振，特别是科技这一块，你甭管和自身有没有什么护城河，有多少价值，反正牛神鬼马都得出来亮个相。当然，股价我只是说一说我的看法，不代表它就应该涨或就应该跌。咱们也不是短线选手，只是觉得市场可能会炒一波。

但问题在于，这样的利润可能并不具有可持续性。回到2023年，公司的毛利率也只有5%，看纯利的话肯定是亏钱的。当然，这是一个周期底部，不仅是长存，其他的美光那些都在亏钱。

未来来讲，短期内可能不会出现周期到很底部、以至于大家都亏到不行的局面，现在这些存储厂也在想办法签长单，但问题是它们也不可能持续维持这么高的利润率。

如果产品的单价腰斩，未来利润率有可能下降到20%，那么利润其实就要缩减到1/3。原来一年赚1000亿，可能接下来一年就只赚300亿。那个时候你再拿2~2.5万亿来算，估值就偏高了。

当然，A股在这种超景气区间一向是今朝有酒今朝醉，管他喵的以后如何。所以也不矛盾，继续奏乐继续舞。
