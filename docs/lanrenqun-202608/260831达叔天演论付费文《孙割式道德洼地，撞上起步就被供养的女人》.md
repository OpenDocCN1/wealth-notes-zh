# Part1 注意力

## 赚钱的本事

医疗说，最近在投资圈，出了一个超级大瓜。

那个号称坚决不给女人花钱的男人，写了六千字长文，复盘了自己的明星女友，睡也睡了，想把钱再也要回来。很有想象力。

你早期接触过币圈，读者里也有币圈的人，你钱还被女人管着，你怎么看这个事？

达叔说，我谈了一个初恋，就结婚了，对女人和情感类的问题，不太懂。但对研究赚钱的事，很感兴趣。孙割是怎么赚到那么多钱的？起步是，注意力套利。

孙割1990年生在青海西宁，父母离异，少年没人管，沉迷网游，成绩四百来分，最多考个三本。起点比达叔还低，我从骨子里就非常能理解，他对这个世界的野望和愤懑。

2007年，他17岁，拿了新概念作文大赛一等奖。

韩寒和郭敬明，都靠这个奖项崛起，是达叔同龄人，特殊时代的产物。

这种人怎么拿奖？他自己说，那篇获奖作文，是研究透了历届评委口味，按需投喂。

17岁，当别人还在懵懂无知时，他就懂了商业底层规则，顾客爱看什么，我就生产什么。

绝大部分人，一辈子都参不透这层窗户纸，天天以自我为中心，在网上嗷嗷叫。孙割靠这个奖进北大，中文系待不住，转历史系，再去了宾大读法律。

第一桶金，是在2013年，押注比特币和特斯拉，赶上第一轮牛市，23岁身家过千万。

小钱就是赌，大钱才求稳，孙割知道自己起点低，起步就是豪赌。赚到了第一桶金。真正的暴富，在2017年。他搞了个波场TRON，白皮书被曝抄袭以太坊，代码被骂山寨，本质是个空气币。但他掐准了时间，赶在国内七部委叫停ICO的前一天，募了7000万美元。

监管要求清退，他表面退了，实则把筹码收回自己手里，一个人控了60%以上的币。

2018年初，币价从0.01美元，拉到0.2美元，涨了200倍。

散户高位进场，他在最高点一次性抛掉60亿枚TRX，套现3亿美元。庄家出完货，币价暴跌20%，后面一路阴跌。币圈从此叫他，孙割。

他赚的钱，从不创造的增量，都是把别人口袋里的钱，通过信息差、控盘、舆论，装进自己兜里。

这种人，天生就适合生活在边缘地带，灰色区域，一个是监管空窗期的红利，一个是人性里贪婪的周期。在正规市场里，他这么搞，早就被抓去踩缝纫机了。

他从第一天起，就站在了监管、散户的对立面。美国SEC起诉过他操纵市场，他花钱和解。国内他几乎不敢回。绝大部分炒币的人，都很低调，甚至比特币的创始人是谁，都没站出来承认。

别人都在怕，在躲，就他极其高调，摸索出了自己的商业模式。他从20年前，就研究作文评委的口味，研究币圈韭菜的心理，研究巴菲特午餐值几个热搜，研究特朗普喜欢什么。

他的赚钱方法论，一直都没变，找到观众的爽点，把注意力变成钱。在孙割的账本里，争议不是成本，争议是流量，流量就是资产。黑红，也是红。

拍下巴菲特午餐，借口肾结石放鸽子，上热搜。花620万美元买根香蕉，当众吃掉，上热搜。买下特朗普币最大持仓，混进总统晚宴，上热搜。

现在告前女友，写六千字小作文，还是上热搜。别人低调，是别人不需要流量，不敢要流量，这是一种普通人能理解的逻辑。

孙割有独特的哲学、商业模式，他的资产，一半是币，一半是注意力。

你骂他，他就更红，你越骂，他越有筹码，变成反脆弱系统了，没几个人有这种心理承受能力。

# Part3 输赢

## 法律背后

从法律上看，孙宇晨能打赢么？他主张的是3000万彩礼，以结婚为目的，婚没结成，按司法解释，彩礼可以要回来一部分。

他手里要有转账流水，要有能证明“以结婚为目的”的东西。聊天记录、订婚证据、父母账户收款。如果这些坐实，返还彩礼有依据，这是他能拿回一部分。

但景甜方全盘否认恋爱，定性这是碰瓷。孙割自己那篇长文，也写着纯属虚构，小说不能当证据。如果最后证据不足，他输了，那就更难看。

第一，自己割了20年别人，最后被女人收割了，还是自爆的；第二，自己标榜“不给女人花钱”，那是欺负前女友、欺负信任你、爱你的女人。
