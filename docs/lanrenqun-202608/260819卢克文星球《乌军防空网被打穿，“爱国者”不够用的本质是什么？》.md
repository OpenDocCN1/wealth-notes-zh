# 乌军防空网被打穿，“爱国者”不够用的本质是什么？

260819 文/卢克文工作室嘉宾 云梦竹

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

最近，乌克兰的防空网在俄军的猛攻下，被直接打穿。

俄军投射的28枚导弹全部命中基辅，乌军防空网无一拦截，乌官方将原因归结为美制“爱国者”拦截弹断供。

但这场惨败的根源，不只是弹药匮乏那么简单。“爱国者”成为摆设，本质上是整个西方军工生产正面临前所未有的危机，而这种危机，正在催生一种别样的战争形态。

# 1

2026年8月1日，俄军向基辅及周边发射了27枚弹道导弹，仅拦截成功1枚。

几天后，也就是8月5日，俄军发射了24枚弹道导弹和4枚“锆石”（Zircon）高超音速巡航导弹，乌防空部队未能拦截其中任何一枚，拦截率直接来到了0%。

怎么看待这个数据？

去年7月份，俄军总计发射6245架无人机、198枚各类导弹，根据战后数据统计，乌军利用拦截或电子压制成功击落了89%的无人机和61%的导弹。

![](img/840bb4061708c98e57dbd1ca97d519c4_0_0.png)

从这个数据的对比中，我们可以看出，乌军防空系统正面临崩溃。

泽连斯基多次公开表示，俄军弹道导弹突防时，乌军因为爱国者拦截弹已经完全打空，只好眼睁睁看着目标落入基辅及关键基础设施。

截至今年上半年，乌克兰拿到手里的拦截弹，只有去年同期的三分之一，但俄军弹道导弹的每月投送量，却达到了去年同期两倍以上。

虽然泽连斯基还在努力向美国争取拦截导弹，但现在的情况懂的都懂，美国自己还要在中东对付伊朗，地主家也没余粮了。

根据CSIS（战略与国际问题研究中心）防务预算与军工评估报告，自2000年代PAC-3拦截弹开始量产至2025年底，美军历史上累计接收的爱国者PAC-3交付总量约为2350枚。

减去在中东的消耗和给乌克兰的援助，美军自己手中还有800枚左右，另有300-400枚老旧的PAC-2拦截弹，即美军现在手里也就1200枚左右爱国者。

如果按照两枚拦截弹拦一发弹道导弹的打法，只需要齐射600枚导弹，就能一次性耗干美国全部的爱国者弹药。这个齐射规模，不足亚洲某大国火箭军首轮齐发量的三分之一。

看到这里，估计有读者会问了，既然美军弹药已经降到红线了，那你赶紧扩产啊。

对此，洛马也是一把辛酸泪。

爱国者要实现“撞击即摧毁”毫米级精度，关键在于弹头周围的姿态控制喷管、雷达导引头和电动舵机。这些高频微调部件极其依赖钐、钴、钕、铁、硼等永磁体，其中添加的镝、铽等重稀土是耐受超高温的硬性材料，目前几乎完全依赖中国供应链。

中国对稀土出口进行管制后，全美仅有少数工厂能够生产这些材料，准确来讲就一家，不但产量只有中国的1%，而且从下订单到交货需要18至24个月。这就导致洛马即便拼命生产，每年也只能提供约650枚爱国者。

日本是正儿八经掏了23.5亿美元买战斧导弹，单价比美军自用还贵一倍，但就因为美军库存不够，说延期交付就延期交付，日本一句话没说，默默承受了一切，更不要说连吃带拿的乌克兰了。

那乌克兰能不能自己生产爱国者呢？很难。

生产爱国者所需要的零部件，依旧得从西方进口，产能限制依旧存在。乌克兰又处于战区，会导致爱国者的设备合同、保密流程都更加复杂，本来爱国者就涉及上万个零部件，乌克兰要和供应商一家一家地沟通，过程难以想象的复杂。

退一万步讲，哪怕乌军现在拿到足够的爱国者，它的拦截率也上不去，因为俄军导弹的突防能力也在大大变强。

从去年10月开始，俄军就对“伊斯坎德尔-M”（9M723导弹）的末端控制软件和飞行轨迹进行了重大升级，导弹在进入末端下降段时，不再遵循传统弹道，而是执行剧烈的侧向抖动、末端拉升或更陡峭的垂直俯冲。

军迷估计发现了，俄军末端的攻击模式，跟钱学森弹道是如此相似！

国际战略研究所直接说，这就是俄军利用临近空间的气动特性，将钱学森弹道降维应用在战术导弹上，从实战结果来讲，突防率立竿见影。

大家千万不要小瞧这个变动，传统反导系统是基于“卡尔曼滤波”预测抛物线轨迹的杀伤链，在面对“非线性末端变轨”时存在致命的时间延迟。

当爱国者面对钱学森弹道的轨迹时，其反导雷达和计算中心必须重新估算目标的加速度向量，这会直接导致脱靶，而且在末端变轨和拉升，不仅会打乱火控计算的轨迹，还会迫使爱国者拦截弹进行极限转向，一旦自身推进剂耗尽、姿态喷管剧烈变动，会导致拦截几何构型在物理上变得不可恢复，继而无法精准拦截。

请注意，钱学森弹道不是不可拦截，更准确的说法是，钱学森弹道会使敌方成功拦截的概率不断降低，拦截成本大大增加。

这也是为什么2025年7月，乌军爱国者还有61%的拦截率，到了2026年初，拦截率就只剩下25%左右。这个拦截率，哪怕美国把全部库存送过来，按当前俄军打击强度也只够打两个月。

所以从当前战争情况来看，利用爱国者进行拦截这条路基本上走不通了。

# 2

爱国者拦截神话的破灭，不只是俄军技术进步那么简单，而是新的军工生产逻辑对旧军工体系的降维打击。

大家想想，在1991年海湾战争、2003年伊拉克战争中，爱国者还拥有碾压级的优势，比如伊拉克战争期间，美军仅消耗158枚爱国者，就创造了拦截率96%的神话，那为什么在伊朗战争中，美军消耗上千枚拦截弹，结果第五舰队总部差点被人扬了呢？

为什么差异就如此巨大呢？

我们先弄明白，这96%的拦截率是怎么来的。

爱国者和以色列“铁穹”系统的拦截逻辑，从来不是“来一枚拦一枚”，而是依托先进的相控阵雷达与火控计算机，进行高速弹道解算，自动过滤掉因落点偏差过大而坠入荒地或水域的无效目标，只对威胁到核心资产和人口稠密区的弹药实施引导拦截。

在海湾战争时期，伊拉克发射的“飞毛腿”及其改进型“侯赛因”弹道导弹，圆概率误差（CEP）高达数百米乃至数公里，100发导弹经历数百公里的飞行后，能够命中高价值目标的导弹本来就没几枚，美军只需发射极少数拦截弹就行了，所以造就了早期的“防空神话”。

但最近几年，受益于某亚洲工业国家的民用消费电子、新能源汽车与物联网爆发和产能外溢，高精度惯导系统（INS）和战术级制导组件这些曾被极少数强国严密管控的战略物资，变得廉价且极易获取。

比如传统的军规光纤陀螺，其静态姿态精度在每小时0.01度-0.1度之间，不仅受到西方严格管控，且市场价格高达2-5万美元。

而华强北随处可见的工业级MEMS惯导模块，在集成三轴陀螺仪、三轴加速度计与地磁计，板载卡尔曼滤波算法的情况下，静态姿态精度可以达到每小时0.05度，不到2000美元就能买到。

在卫星导航领域，过去依赖欧美高精板卡（如NovAtel或Trimble）实现多频RTK战术定位，一块板卡要2000到6000美元。但现在，深圳制造的民用全系统全频点SoC模组，不仅支持双天线厘米级RTK测向，还自带抗干扰算法，价格只要200-500元人民币。

同样，在末端制导方面，过去传统巡航导弹的数字景象匹配（DSMAC）计算机和红外导引头动辄数万美元，现在一块主控芯片加上成像器件，1000元人民币就能搞定。

民用消费电子市场极其残酷的竞争，意外击穿了高精度微机电与微电子的技术与成本壁垒，使高精度MEMS惯导、抗干扰多模卫星定位模块、民用光学匹配算法得到普及，结果是，简易组装的无人机与巡航导弹，其圆概率误差轻易收窄至5-10米以内。

进攻方打击精度的跨越式提升，直接摧毁了传统防空系统的过滤机制。之前1000发导弹最多命中10发，只要20发拦截弹就能100%拦截，但现在1000发导弹能够命中800发，同样的拦截率却需要至少1600发拦截弹！

爱国者在俄乌和中东战争中被如此快速地消耗，就是因为俄罗斯、伊朗的导弹打得太准了。

同样的道理，俄罗斯和伊朗利用技术优势突破爱国者防空网络，乌克兰也借助扩散的电子工业技术，用无人机、星链等在陆地上摧毁俄罗斯的装甲集群。

先进电子工业的技术扩散，使高精度空袭武器从精英走向平民、从昂贵走向廉价，空袭成本变得极其低廉，使爱国者防不胜防。

但是，战争不会因此结束。

首先，被炸掉高价值目标，不意味着任何一方就要因此投降。

双方可以利用无人机和廉价导弹，不断对敌方的后方进行对等杀伤，摧毁对方的能源、交通、通信、物流中枢，直到一方的内部矛盾彻底爆炸，财政流尽最后一滴血，战争潜力被彻底瓦解为止。

其次，工业和技术的扩散，使军事组织不再依赖专业节点，很难出现“一战定胜负”的局面。

二战时，苏德都把赌注押在东线交通枢纽库尔斯克，因为在装甲时代，失去铁路枢纽，坦克就等于废铁，最终苏德在此展开了决定命运的坦克会战，一战定胜负。

但你看今天的俄乌战场，巴赫穆特也是顿涅茨克北部的交通枢纽与后勤基地，乌军丢失巴赫穆特后，依旧保持了作战强度，因为无人机能够摧毁坦克，交通节点的战略权重大大降低。

最后是武器操作门槛的降低，廉价平民武器逆袭，对传统精英式武器进行了降维打击。

中世纪重装骑兵、现代主战坦克、隐身战机、爱国者导弹，都是典型的精英式武器，造价高昂、操作不易，必须由大国生产，武器高度集中在少数精英阶层。

在精英式武器主导战局的时代，战争可以轻易实现速胜，因为只要一方的昂贵尖端武器报废，战争基本就结束了。

而长矛、燧发枪、现代自动步枪、无人机等廉价平民武器，成本低廉、易于大规模生产、操作门槛极低，使任何一方都能最大限度动员普通平民参与，结果是整个战争的周期被无限拉长。

一名训练两个月的无人机飞手，可以击溃一个训练八年的装甲车组。武器操作门槛的降低，使战争双方都可以最大限度动员普通民众参与战争。

于是我们才会看到，俄罗斯的火炮、坦克产能虽远胜乌克兰，却没能速战速决；美国即便在常规军力上对伊朗形成百倍优势，也无法一击必杀。

我们没有看到“一战定胜负”的大决战，只看到绵延的、脉冲式的、无休无止的冲突。

这种战争形态，不是新事物，只是一种人类古老战争形态的复活，中国和世界历史上比比皆是。

《学习时报》指出，在慢性战争中，低成本持续消耗成为主导，当防御方的消耗速度显著高于进攻方时，战场上的经济效益便发生了根本性逆转，这种以“慢”耗“快”、以“廉”耗“贵”的手段逻辑，使得战争在资源层面变得难以持续，却恰恰成为“慢性战争”得以长期延续的内在动力。

所以，是技术下沉带来了装备革命，装备革命又改变了战争形态。

今天决定战争终局的，不再是少数尖端装备的代差，也不是天才将帅的智慧，而是最普通民众的生产能力、组织能力和战斗意志。而今天击溃对手的方式，也不是前线某次血淋淋的决战，而是彻底拖垮对方的社会基础。
