# 前言

你们催的八月秘籍来了。

整个七月做科技的应该能感受到2015年那一波的刺骨疼痛。

七月最后一天，受美国行情影响，科技高开，我特别在微博上提醒了一下，劝大家要警惕高开低走，果然，下午科技开始哐哐砸了。

作为一个资深老韭菜，过来人，我是非常理解大家对所谓利好的那种执着，对亏损的不甘心，但是，这是生活，是市场，各人有各人的不甘心，市场是冷漠且无情的，不会因为你有多痛苦而改变什么。

这么多年的市场经验，让我学会了一件事：并不是所有的坚持都有意义。方向错了，越是努力，越是糟糕。

所以八月我们最要紧的一件事，就是捋一捋方向！

在这里我依旧坚持看法：科技依旧是主线，市场上资金充裕，牛市依旧还在！

![](img/29c9d672a9b2400b1d0d773ddc9d561d_0_0.png)

7月份的美联储议息会议之前，各种声音都在那里说，美联储要加息，收紧流动性去应对通胀问题。

美联储难道不知道这波通胀是怎么起来的？

根本原因就是老美非要去打伊朗，于是伊朗封锁了波斯湾，全球能源供应因此出了问题，原油及其相关产品价格大涨，传递到消费端，那就是通胀。

加息能解决霍尔木兹海峡跟曼德海峡的运输问题吗？

加息能让交战双方不去摧毁对手的能源设施吗？

都不能，反倒会让老美自己的财务成本飙升，进一步推动通胀。

美联储的主席好歹也是精英阶层，这么简单的道理他一定明白，但死鸭子嘴硬，做戏要做全套，还要搞几个群演出来搅局，这就是所谓三个有投票权的跳出来坚持加息的闹剧了。

白宫已经说了要提高美债上限，现在大家都知道，美国是不可能还得起债的，也不打算还，无非是强撑着咬牙还利息罢了。

去年美债利息支出9700亿美元，今年预估最少是1.04万亿美元，最近美债收益率飙升，市场预估有可能利息支出会超过1.35万亿美元，今年美国预估财政收入是5.2万亿左右，真要再加息，请问美国政府能扛得住吗？

都不需要具备很高深的金融知识，懂点基本常识就该明白，老美现在唯一能做的就是赶紧找借口，想办法去降息印钞，否则国库没钱开支，帝国就要趴窝了。

马斯克搞政府效率部玩节流那是假的，老老实实地把国债利率降下来，一年省它1万亿美元是真的。

所以为什么美国不肯降息呢？

我们看看过去几年，老美急速降息，疯狂印钞都得有个前提，那就是经济真出大事了，什么次贷危机、新冠疫情，美股动辄跌到熔断，债券市场各种崩盘……

所以从这个角度来看，我是认可高志凯教授对美国要搞金融危机的判断。

不出事，怎么好找借口去降息印钞？

扛到现在，老美已经扛得很辛苦了。

但我一直又认为，这一次老美不会主动挑起金融危机去销账，道理很简单，它以前是全球霸主，地位不可动摇，假摔一下，还能轻松爬起来，拍拍身上的灰，继续玩下去，但现在，它还是那个霸主吗？还有所谓不可动摇的地位吗？一旦表演假摔，很有可能是真的摔倒，再也爬不起来了。

不降息是为了维护美元的地位。

但我的老粉丝都知道，国际货币的地位，不在于你账房先生有多会腾挪表演打算盘，而在于你老美的军事力量有多强悍。

六零年代老美被越南战争搞得灰头土脸，法国人就敢跳出来挑衅美元的地位，开军舰往回拉黄金，最后导致黄金美元体系破产。

想想看，如果当年老美在越南大杀四方，顺利平推，法国敢这么干嘛？

到八零年代，苏联被阿富汗战争拖死，要死不活的美元立刻就崛起了，通货膨胀也稳住了，空口信用也立住了。

如今是什么时候？美国的武力连中东一个小小的波斯都没办法震慑住，支撑美元流通的国际主航道说断就断，中东的原油已经默认了多币种结算，美元还剩下什么呢？

08年次贷危机爆发，老美无限印钞等于是货币违约，大家都还得捏着鼻子认美元信用，敢于当刺儿头的卡扎菲被老美给弄死了。

现在再爆发一场次贷危机级别的金融危机，还是从美国本土先爆发的，啥都不用说了，第一个保不住的一定是美元信用。

这么简单的逻辑，美联储那帮人肯定不会不懂的。

讲真，老美真的有08年的狠劲，18年、20年，甚至是23年，早就有一波超级金融危机爆发了，但老美没敢动手，每次有点苗头，立刻就上印钞机，迅速压下来。

所以这也就很容易解释，为什么美联储满嘴跑鹰，但行动上却鸽得不行，因为鹰是演技需要，鸽是真实生活。

只要美国国内顶级精英们一致希望维持现状，不要爆发金融危机来影响美国的地位，那么人家自然有各种办法去稳住泡沫。

最近这几天，老美那边科技大厂各种财报让人看得眼花缭乱，不管你信不信，反正财报告诉你，AI投资虽巨大，但人家已经靠什么云业务之类的，实现了业绩高速增长。

这差不多印证了我之前在这里写的，老美为了不让AI泡沫爆掉，肯定会各种想办法，编造数据来证明应用端出结果了。

恒大暴雷告诉大家，不要信什么国际会计师事务所的节操，只要钱给够了，节操是随时可以扔的。

我一直都说，很多业绩和数据都是从结果倒推出来的，你想要得到一个好的结果，超出市场预期，那么倒过来去编这个需要给公众看的数字，这又是什么很难的事吗？

老美最擅长搞所谓吃屎的业绩，大家都是AI圈的，彼此互相购买商品和服务，打开报表，大家都赚钱了，业绩好得不要不要的，但实际上呢？

可以这么说，这一轮AI引领的科技革命，最后能赚到AI钱的，肯定不是美帝那一群所谓的科技巨头们。

但硅谷跟华尔街现在只有硬着头皮去吹自己有美好的未来，没办法，美股真的不能崩，整个美国都被股市给绑架了，一旦美股崩掉，在内是老百姓的压力，在外是美元霸权的衰退，无论是美联储还是白宫，都不敢承担这种后果。

为了保住美股，美联储说不定9月份就要找个借口降息，用各种工具偷偷往市场里灌水。总有人说这一轮所谓的美元加息缩表周期，我们只看结果，哪有加息缩表搞出来的通缩引发全球性的资产价格暴涨？合理吗？

23年硅谷银行暴雷，老美搞了定性的债券融资工具，到底规模有多大，到现在都被含糊其辞。你只看美联储资产负债表似乎缩表了，但人家玩的是会计游戏，表外的负债到底又多了多少，有人给统计数据吗？

现在老美已经走上了一条只能无限债务扩张的不归路，一旦真的退一下，立刻就各种死给你看。

不要看美联储说了什么，要看它做了什么，处在什么样的位置，从这个方向去判断未来的货币政策，你就会认同我的看法：美国会用各种方式方法，不断地用各种你搞不明白的手段去灌水，好维持股市的泡沫。

从某种意义讲，懂王之所以非要跑到中东搞事情，也是存心去推高油价，好用通胀去稀释债务。

6月份油价跌破70，美伊和谈立刻就破产了，没有人觉得这波打得莫名其妙吗？

市场没办法紧缩，流动性依旧以各种方式溢出，甚至老美为了让小弟本子能持续给资本市场输血，美联储亲自下场把日元的汇率给救起来了，这是怎样的一种国际主义精神啊！

股市不是经济的晴雨表，但一定是流动性的晴雨表，大家都这么卖力去保护流动性，那么短期内，市场也没可能会崩掉的，在大方向上，大可不必担忧。

市场的主线依旧会是科技，没办法，现在也只有这个故事能讲得通，并且讲起来大家还爱听，但可以肯定，从前无脑炒硬件的时代已经彻底过去了。

周末AI圈最大的消息是DeepSeek V4正式版发布，只需要20W左右就能做本地部署，这意味着什么？

这种模式发展下去，美帝的那些巨头、云厂商们用AI牟利的模式要被颠覆掉了。

闭源大模型为什么现在遭抵触呢？很简单，你用它的模型，它偷你的数据，Anthropic都已经有受害者联盟了。之前美股里的软件股大跌，那是因为封闭模型叙事下，默认大家都要把自己的数据放在大模型公司的平台上，它吃掉你的数据，然后自己就能做定向工具，软件公司的传统模式会垮；但现在开放的模型越来越先进，以后也会成为主流，那么企业凭什么不去做本地部署，保护自己核心数据资源呢？

其实这个逻辑在6月底就已经开始在发酵了，表现就是软件股已经没怎么跌了。到7月份，美股AI硬件暴跌，软件反倒是大幅反弹。

中国的科技发展一点点地在敲掉美股所谓牢不可破的AI盈利模式。

想想看，为什么今年AI硬件能涨成那个样子呢？本质上是我们跟着纳斯达克走。

老美科技巨头为了坑对手，纷纷跑去疯抢AI硬件，主打就是我不管我用不用得上，只求你买不到，所以在谷歌地图上你能看到很多算力中心还是个空壳子，甚至连个空壳都没有，但奇怪的是，AI硬件供应商的货，甚至下几个季度的货，都被大厂们给锁死锁定了。

这里所谓的业绩增长到底有多少是真实反馈，有多少是虚火烧起来的，市场是不管的，反正流动性充裕，反正想炒，那就抱团在硬件方向疯狂往上炒。

一开始是估值修复，接着是超预期，最后就是局部杠杆上、流动性集中的整出来的杠杆牛。

如果只看AI硬件这一波走势，跟15年的杠杆牛其实是如出一辙。

如果仅从逻辑上推断，我认可AI硬件需求激增，未来行业发展前景巨大，但现在的问题是，由于流动性扭曲、杠杆资金集中，导致板块透支了未来N年的成长。

一旦市场证明，从前那种美帝引导的AI基建投资模式有可能要玩不动了，第一就先杀了预期，然后多杀多，杠杆踩踏。

经历了七月惨烈的下杀，杠杆资金已经卸得差不多了，但你以为就这么结束了？

还记得15年杠杆杀完了之后杀的是什么？

没错，开始杀估值了。

市场从来都是两个极端，要么极端的过热，上头就是无脑看多，多头的心气被杀之后，就会陷入到另一个怪圈，极度地往下看空。

我们之前也分析过，这波市场是不愿意跌的，科技硬件现在非常尴尬，除了少数硬核科技，没有背上历史负担，比如说新上市的那些，其余的，都被坑得挂得高高的，上面的套牢资金一层层，这么短时间的下杀是不可能杀尽套牢盘。

那么咋办？只能冷处理，挂起来，用时间来解决问题。

八月份科技硬件是不太可能继续像7月份暴跌，毕竟这波杠杆比起15年全民杠杆牛还是要温和太多，该爆仓的，已经爆得差不多了，但坏就坏在爆仓的不够多，所以向上阻力很大，向下的话，在不破坏大盘的情况下，也没办法再狠狠地下杀了。

那么大概率是在这里磨底，或者说是做一个阶段性的底。

7月31日高开我就跟大家说了，高开必低走，因为在这个位置，这个时候，一旦大涨，立刻就有大量的资金要趁机跑路。

跑路的多，敢过来接飞刀的少，能稳住已经不容易了，不要指望还有什么大涨上去的可能。

当然了，AI硬件里面一样也会有结构性的行情，毕竟AI这个大方向是行情未来的主线。

大家要分一下蹭热度跟有硬核实力的差别。

但无论如何，在现在这个时间段里，试图跑到AI硬件这个方向里去搞刀尖舔血的钱，那都是非常危险的。

因为现在硬件行情在杀估值期间，还伴随着很多能颠覆原有格局的消息。

比如说7月底传出来我们能小批量量产DUV光刻机了，这就直接杀穿了所谓芯片价格会继续暴涨的预期，因为我们技术突破意味着产能未来很快会起来，美帝卡不住我们扩产的脖子，那么供需关系很快就要扭转，是不是预期要继续被狠狠地杀一下？

比如说传出来长鑫很快会量产DDR6的消息，这说明什么？说明东大各种存储芯片的先进产能有可能超预期爆发，那些靠着囤积芯片发财的所谓芯片企业商业模式彻底要被打回原形。

赌存为王，存储价格能永远坚挺的那一批人也会很快被市场往死里锤。

倒不是说未来AI发展不需要存储，而是本波段存储的逻辑彻底被推翻了，国内的真龙头也会被全行业给拖下来的，只能用时间换空间，等待下一波AI技术爆发带来新的机会。

总结就是AI硬件未必没有第二波的机会，但第一要等时机，第二要看自身的成色，凑热闹的、蹭热点的，大概率6月底那里就是长期顶部了。

我们之前分析过，中美都会尽力去维持住AI行情，现在要给资本市场讲通的故事就已经不是大厂烧算力搞基建了，而是AI终于在应用上能出成果了，什么企业对AI的需求激增，AI业务未来灿烂光明的前景。

不画这个大饼，请问资本市场还会往里面投钱吗？

这波美股也开始在炒AI应用。

个人认为AI应用可以重点留意三个方向：

1、国产软件。

软件上半年属于超跌了，其实从7月开始，软件板块已经开始大幅反攻，很多个股已经走出了底部形态，大家可以多加留意。

细分方向有两个，一个是跟模型相关的，接下来大概率还会有一些新的国产模型出击，吊打美国的闭源大模型。之前市场聚焦在硬件上，这个方向几乎没有资金关注，现在炒不了硬件，在底部的相关票多少是盼来了机会。

二是数据安全，最近美股安全相关的公司被市场追捧，很简单，未来AI应用越是广泛，部署AI的企业越多，越是要担忧安全问题。最近不是发生了几起有名的AI攻击新闻吗？接下来大概率还会有更多，AI应用越是广泛，相对的安全需求越多。

2、AI与工业自动化。

这个我一直在提，我们是制造业立国的国家，AI产业革命跟制造业升级是紧密相关的，这个方向上的个股也是长期萎靡，但谁能说它不是未来的方向呢？

我认为在东大，这才是物理AI的主打方向。

3、机器人。

七月初机器人走势非常好，很可惜，被AI硬件一起带崩了。八月机器人第一股宇树机器人IPO，起码在上半个月，这个方向是很有话题、很能吸引资金跟风的，至于到下半个月还能不能延续行情，那就要具体问题具体分析了。

还有一个可能的方向就是AI手机，OpenAI在试图偷苹果的技术搞硬件开发，大模型公司做梦都想搞点跟硬件结合的项目来做，目前为止，除了机器人就是手机了，但凡爆点消息，多少也会炒作一下，个人认为有机会，但缺乏持续性。

八月份还有一个大方向就是储能。

为什么我从七月份就开始提储能呢？一是因为我们公布了“十五五”能源规划，按照规划，未来我们对储能的需求量是非常大的。

除此之外，因为中东局势不稳，全世界都在设法去拥抱新能源，减少对传统能源的依赖，那么配套就需要更多的储能设施。

这里的底层逻辑是全球能源供需关系新平衡。

当然了，有可能也会带动一下新能源整个行业往上走走，曾经的赛道，现在也成了老登，但超跌终究会带来机会的。

继续关注创新药，这里是有实实在在的业绩支撑的，并且还有巨大的想象空间，国内CRO的市场份额还在持续增长。当然了，你说有可能会面临老美那边的政策打压，但个人认为这并不是什么大问题，毕竟真实的需求在那里，资本自然有办法去搞定监管的。

大家可以去看看创新药ETF，其实从六月开始，就已经开始企稳反弹了。

这个方向一直是很有市场号召力的，个人认为这个位置、这个时间问题不大。重点关注一下券商板块，特别是优质大券商。

最近监管开始严查券商违规，往往市场底伴随的都是最后一波利空，大家可以反过来想想，违规的券商要被政策出清，那么好的券商呢？

是不是会拿到更多的份额？再看看最近这段时间的成交量，券商的业绩是不是已经有了实打实的提升？
