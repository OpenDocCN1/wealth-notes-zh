# 许家印被判无期，有什么考虑？

260824 文/卢克文工作室嘉宾 概略北方

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

8月20日，随着法槌重重落下，许家印终于迎来了他的结局：

无期徒刑，剥夺政治权利终身，没收个人全部财产。

满屏都是大快人心、罪有应得，叫好声铺天盖地。但如果你耐下性子，仔细阅读一下这次的判决内容就会发现，这次的宣判，并没有那么简单。

因为，这并不是一个简单的企业经营不善破产案，而是一场蓄谋已久、手法隐蔽，且破坏力惊人的经济犯罪。

今天，我们就来看看这份判决书背后的隐情。

# 1

法院在判决中开门见山地指出，恒大集团、恒大地产及许家印的犯罪行为“犯罪数额特别巨大，情节特别恶劣，造成特别重大经济损失，社会危害特别严重，应当依法严惩”。

以往的经济犯罪，能称得上一个“特别”就很恶劣了，皮带哥名不虚传，一口气凑了四个。

那么许家印到底干了什么呢？也许判决明确的罪名，可以一窥端倪。

首先，就是非法吸收公众存款罪、集资诈骗罪。

这两个罪名，是有细微区别的。

前者是你承诺保本付息，向社会不特定对象吸收资金，但你可能主观上还是想拿去投资赚钱还给大家的，只是最后亏了。

而后者，则是你从一开始，就不打算还，或者明知窟窿已经大到根本填不上，还在用新钱还旧账，主观上具有“非法占有”的目的。

一般情况下，同一个非法集资行为，不会同时定集资诈骗罪和非法吸收公众存款罪，只定集资诈骗罪一罪。只有前后两段独立行为、犯意发生转变，才会两罪并存、数罪并罚。

也就是说，一开始恒大财富非法吸收公众存款，可能还真是正常经营。

但到了后期，许家印明知恒大即将爆雷的情况下，依然动用集团资源，承诺8%甚至10%以上的高息，向社会推销其“理财产品”，那性质就变了。

这些钱，并没有投入任何有回报的项目，而是用来填窟窿了，甚至用于支付早期投资者的利息，来维系这个庞氏骗局。

更恶劣的是，在彻底暴雷前夕，许家印等高管却利用内部信息优势，提前兑付了自己的本息，顺利逃顶，这性质太恶劣了。

可以说，几万个因为恒大而支离破碎的家庭，是把许家印推向无期的重要砝码。

第二，欺诈发行债券罪。

法庭查明的事实是，2019年至2020年期间，许家印直接授意、指使恒大高管，通过提前确认收入等财务造假手段，虚增了惊人的5641亿元营业收入和920亿元利润，这个规模在A股历史上前所未有。

拿着这些用假账堆出来的“完美财报”，恒大转身就在境内发行了208亿元的公开债券。

老百姓一看，恒大一年赚百亿，买它的肯定稳赚不赔，然后就被骗了。

许家印作为恒大的绝对控制人，不仅是知情者，更是整个造假工程的授意者甚至策划者，那么毫无疑问，迎接他的必然是顶格处罚。

第三是单位行贿罪。

行贿罪我们都听过，但什么是单位行贿罪？

很简单，行贿罪的主体是个人，而单位行贿罪的主体是公司。

你以为恒大总负债2.39万亿，那些金融机构的风控人员都是吃素的？并不是他们看不出风险，而是恒大通过行贿把风控搞定了。

很多时候，不仅仅是直接送现金和豪车，恒大还非常擅长搞“隐性输送”——比如让金融机构高管的亲属在恒大挂职拿百万年薪，比如低价将恒大的优质商铺半卖半送给关键人物，甚至安排专机陪同相关人员去海外潇洒。

单位行贿罪虽然最高刑期通常不如贪污受贿重，但它的社会危害性极其巨大。

因为许家印用几百万、几千万的贿赂，撬动的是几百亿、上千亿的金融资源，并将所有的坏账风险转嫁给了全社会，这种恶劣的行为，必须重判。

第四，伪装的职务侵占与挪用资金。

这两年全网都在问一个问题：恒大亏了那么多，许家印和丁玉梅过去十几年分走的500多亿现金去哪了？这笔钱能不能追回来？

说实话，这笔钱追回来的难度极大，因为在公司法的框架下，公司有利润，大股东按照持股比例拿分红，只要程序合规，就是合法收益。

但这次的判决，显示了司法的强大穿透力。

因为你许家印用来分红的所谓“利润”，根本不是公司真实赚来的钱，而是通过虚增收入做出来的“假利润”。

拿假利润去进行真分红，这就意味着，许家印分走的这500多亿现金，本质上是购房者交的预售款，是银行发放的贷款，是供应商垫付的工程款。

作为公司董事长，利用职务上的便利，把这些本来不是利润的钱，通过做假账的方式，以“分红”的名义非法占为己有，那在刑法上，就是标准的职务侵占。

明确了这个法律定性，判决书里那句“没收个人全部财产”以及“对违法所得继续追缴”，就有了坚实的法理依据。

许家印以为用离婚就能斩断追溯，法律直接把分红的源头定性为犯罪，那你还有啥话说？皮之不存，毛将焉附？

把上面这些理清楚后，我们就可以回答一个问题了，为什么量刑是无期。

很多人觉得不解恨，觉得他害了这么多人，怎么不判死刑？也有人觉得，作为企业老板，无期徒刑是不是太重了？

说实话，过去十几年，基于“少杀慎杀”的司法原则，我国刑法逐步取消或限制了绝大部分非暴力经济犯罪的死刑适用，“无期徒刑”基本上已经是经济类犯罪刑罚的天花板了，就算许家印是数罪并罚，顶格也就是无期徒刑了。

本来吧，如果许家印能积极退赃、挽回损失，或者有重大立功表现，法院在量刑时可能还会酌情从宽。

但许家印的所作所为，可以说是抗拒到底。

在2020年至2023年长达三年的时间里，国家给了恒大机会去“保交楼、化风险”，但许家印表面上喊着“绝不躺平”，背地里却在加速资产转移，一边向有关部门隐瞒真实的债务底数，一边试图通过美国法院申请破产保护，企图利用长臂管辖来对抗国内的清盘。

既然你毫无悔过之意，那就没有什么可以减刑的情节了。

所以，无期徒刑的判决，不轻也不重，非常精准，刚刚好。

# 2

好了，许家印无期，罪有应得，但这并不是全部。

因为无数人关心的并不是许家印判多少年，而是自己的钱，什么时候能要回来。

很多人一看“恒大被罚88.2亿”“许家印被没收个人全部财产”，都有点慌，钱都被罚没了，那我们的钱不就更没戏了？

不用担心，因为判决书里还有一句话：“退赔损失优先于罚金刑、没收财产刑的执行”。

按道理来说，国家罚款优先级高于一切，恒大剩下的和清盘的资产，国家有权先划走。

但这次，国家主动往后退了一步。

这说明，国家在意的并不是那点罚款，而是保交楼、保民生，恒大剩下的钱，要优先赔给老百姓。

我们来算笔账，恒大如果清盘，能清出来多少钱？

目前恒大地产集团合并总资产是1.47万亿，当然这只是账面数，刨去虚增的，现有土地+在建工程，应该值个9000亿左右，扣除保交楼、抵押、工程款之后剩余可分配资产大概有个5000多亿。

这些钱如果全能清出来，可能会按照下面的顺序来分。

第一顺位，应该是那些没拿到房子的购房者；第二顺位，是被拖欠工资的建筑工人和底层供应商；第三顺位，是那些买了理财产品的个人投资者。

这一点就凸显出中国和美国的不一样了，在美国，华尔街的金融游戏要是玩砸了，肯定是普通人承担代价，但在中国，国家的罚金可以先挂在账上，但老百姓的钱，必须优先保障。

那么问题来了，这些钱不够啊，剩下的怎么办？

这就呼应了前文提到的许家印“职务侵占”和“挪用资金”的赃款了，在国际司法中，就适用于“犯罪资产追缴”。

有了这一定性，中国就有合法的理由去追缴海外赃款，丁玉梅几亿元的豪宅也罢，信托账户里几十亿美金也罢，都经不住一层一层穿透，只要动用国家力量，拿回来还是有希望的。

那那些拿了恒大商票的中小企业呢？他们怎么办？

这些企业涉及的人数少，但金额巨大，无数供应商拿不到材料款，商票成了废纸，老板本人成了老赖。

这次判决，也给了他们希望。因为在清查恒大资产的过程中，不仅在追海外的钱，也在深挖恒大内部高管的隐蔽腐败。

那些恒大区域老总、项目经理，当年卡着供应商的脖子吃拿卡要，甚至自己成立皮包公司倒卖商票。

现在，这些钱，也全都在“继续追缴”的范围之内。

虽然我们承认，这些上下游供应商想要百分之百拿回全款，难度依然非常大，但在“退赔优先”的大原则下，随着恒大剩余优质资产的重组变现，以及追回来的赃款陆续到位，这些处于崩溃边缘的中小企业，至少能按比例拿回一部分救命钱，不至于血本无归。

这就体现了司法部门在处理这种带有社会风险案件时的考量，惩罚罪犯固然重要，但更重要的，是尽可能地弥合社会的创伤。

说到底，我们是社会主义国家，信奉的，是人民至上。

任何资本，无论你包装得多么高大上，无论你认识多少达官贵人，只要你敢骗老百姓的钱，那国家绝不答应。

随着一纸判决，许家印的时代，终于落幕了，曾经的万亿帝国彻底崩塌，大梦一场，满地鸡毛。
