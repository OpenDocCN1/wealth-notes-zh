




# 买房还是租房

260826 珍大户

整理：公众号懒人搜索，懒人专属群精选
懒人微信：lazyhelper1

昊天提问：大户，想咨询买房还是租房的问题。

我现在住在父母名下的房子，在北京西城广外系小两居（我和我爱人都工作在西城，都是公务员），我父母（已经退休）住在我名下的房子，在海淀邮电大学旁边是老塔楼小三居（90㎡，厨房、卫生间特小那种，预计能卖400多万）。

我后年有生二胎的打算，所以有了让父母住回西城，把海淀房产卖掉，我再在附近买一套大三居（售价大概在800到900万）的想法。因为已经有户籍，我不关注学区房。现在手里存款只有100万。买房的话，就必须置换，背上贷款，夫妻一人的工资基本也得还贷。如果租房的话，我和我爱人的公积金就能覆盖70%左右的房租，但是不稳定因素多一些，有可能各种换地方。

我也看了租售比，在广外这边一般是1.5到2左右。

我还在想是不是向外面一些地方买房，但是我和我爱人现在的宝宝都在西城南边（也就是老宣武）上班、上幼儿园或者未来上学，路程上是我最大的顾虑。

因为要宝宝的计划比较稳定，还要关注孩子们未来上学问题，所以就比较犹豫，不知如何抉择。而且现在是买房的好时候吗？心里确实纠结，特向大户提问。感谢。

![](img/c5a1d4fa91ae9d01b720be8a65d60c2b_0_0.png)

回答：

同是一线城市，除了北京之外的其他一线买房还可以，北京还是不建议。因为疏散非首都功能的方向还在持续发力，北京的房价上不去的。你们家都是公务员，工资又不可能大涨。真买房的话对你的风险太大了，稍微下降点就十年工资跌没了。所以建议再租几年。
