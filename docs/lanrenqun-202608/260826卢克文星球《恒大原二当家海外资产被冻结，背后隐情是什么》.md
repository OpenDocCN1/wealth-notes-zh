# 恒大原二当家海外资产被冻结，背后隐情是什么

260826  
文/卢克文工作室嘉宾：概览北方

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

8月20日，深圳中院法槌砸下，许家印一审被判无期徒刑，没收全部个人财产。

而与此同时的美国加州，恒大前董事局副主席、行政总裁夏海钧，正坐在自己的豪宅里惬意地看着电视，他是唯一一个未归案的恒大前高管。

只不过，他惬意的日子，可能维持不了太久了。

因为香港高等法院已经下发全球玛瑞瓦禁令，冻结其名下最高600亿港元的资产。

那么，夏海钧从哪弄到这么多钱？这些钱能追回来吗？

# 1

首先，我们要简单了解一下夏海钧这个人。

和许家印这种草莽出身的土老板不同，夏海钧是个妥妥的精英出身，经济学博士，大厂履历。2007年，许家印三顾茅庐把他挖过来，看中的就是他懂实体，也懂资本运作。

可以说，恒大后来那种“高负债、高杠杆、高周转”的经营模式，以及在海外大规模发行高息美元债，都是夏海钧的手笔。

也正因为如此，他太清楚恒大的风险了，所以早早就开始给自己安排后路。

早在2011年左右，夏海钧就弄到了加拿大国籍。为啥选这里？或许因为加拿大没有和中国签引渡条约，这就是他最大的护身符。

而且，在恒大工作的15年里，夏海钧坚持不担任任何一家恒大核心主体公司的法人，每次都把机会“让”给了别人。

这是高风亮节么？这是提前规避风险，所以，这次夏海钧的名字并没有出现在恒大案的宣判名单里。

到了2021年下半年，恒大暴雷前夜，夏海钧以“去香港和国外与债权人谈判”为由，离开了内地。

这一走，他就再也没回来。

而且在这期间，他以极快的手法，抛售了自己手里的恒大物业和恒大汽车股票，外加面值过亿美元的恒大债券，合计套现超过11亿港元，然后辞去了恒大的所有职务，人间蒸发。

夏海钧去哪了？

美国。

早在2011年，夏海钧就在美国加州橙县的尔湾花120万美元买了一套房子。这个地方治安好，私立学校顶尖，是全美著名的华人富豪隐匿地。

恒大暴雷后的2022年，他又掏630万美元在这里买下第二套豪宅。到了2023年，恒大已经进入清盘倒计时，夏海钧依然有闲心花1450万美元买下一栋新的豪宅，以及4辆汽车。

当然，这些资产写的都是他老婆何昆的名字，和自己做了隔离，因为在一些国家的法系中，债权人追索债务时，仅限于债务人名下的财产。

哪怕如此，夏海钧仍不放心，在外面又加了一层隔离。

2023年12月1日，就在他刚买完豪宅不到1个月，何昆就火速设立了一个名为“新生活可撤销信托”的家族信托，把这些资产都放了进去。

这就是夏海钧的底气：我是加拿大国籍，住在美国，钱在老婆名下，大头装在美国信托里，你管不着我！

2024年6月，香港高等法院其实已经对他下发了“全球玛瑞瓦禁令”，明令禁止他转移资产。

但他根本没当回事，在冻结令生效后的两年时间里，夏海钧居然在冻结令眼皮子底下，通过各种隐秘渠道，向其他账户违规转移了7800万美元资金！

他的日常消费水平极高，单单是2025年这一年，他用一张美国运通黑卡，就刷掉了30万美元。

最离谱的是今年6月，当时香港法院每个月只允许他支取5万港元作为“基本生活费”。

按理说，这笔钱不少了，但夏海钧受不了，他向法官申请，要求把每个月的生活费从5万港元涨到33.5万港元。

理由是什么呢？

夏海钧列了个清单：我儿子读的是美国顶级的私立学校，一年学费要一两百万。我在加州的别墅要交高昂的房产税和物业费。而且，我女儿需要购买Dior的手袋，这是我们家“合理的家庭支出”。

他甚至特意强调：“我并非一般的破产人士，我有权维持过往作为恒大总裁的生活水准。”

拿着普通老百姓买烂尾楼的血汗钱，去给女儿买Dior包，还嫌法庭给的5万块不够花？

香港高等法院特委法官高浩文（也是黄之锋藐视法庭案的法官）公开怒斥夏海钧：“我不相信你！”然后驳回了夏海钧的请求。

生活费之争算是告一段落了，但这并不代表结束，因为追偿诉讼仍在进行中。

那么，被夏海钧卷走的钱，能追回来吗？

# 2

在这里，需要先纠正一个小误区。

普通人看到新闻说“夏海钧被香港法院冻结600亿港元”，第一反应往往是：卧槽，他贪了600亿！

其实并不是。

恒大清盘人起诉夏海钧等7人，是要追讨他们在2017到2020年间合谋搞走的大约60亿美元的不当股息和薪酬。

而法庭冻结的600亿，只是香港法院给他设定的“诉讼保全上限”，不代表夏海钧真的有600亿。

诉讼保全上限的意思是：无论你在哪里，只要你实际控制的钱，在这个数额之内，谁也不许动。

据目前的报道来分析，夏海钧的钱大概在几十亿人民币左右。

可是这些钱都在他美国的老婆和信托手里，能追回来吗？

这个时候，就要看安迈（A&M）的清盘团队本事了。

安迈来自香港，是世界有名的清盘公司之一。瑞幸咖啡重组案、赌王何鸿燊家产案，就是安迈办的。

清盘这种事情很难，指望那种拿死工资的人没戏。

但如果把清盘的钱分给安迈一部分，就不愁安迈不卖力了。你指望夏海钧一个人去对抗一个专业的法律机器？他扛不住的。

而且，大家要明白，追赃里最难的一步是什么。

不是对方转移资产，而是你根本找不到钱在哪，或者证明不了这钱是他的。

所以第一步，就是锁定何昆的哪些钱跟夏海钧有关。

这就不能不提一个概念了——Chabra管辖权。

Chabra管辖权源自1992年英国的一个案子。虽然Chabra并非被告，但是其名下资产实际上由主要债务人实质控制或属于其实益财产，所以法院对非被告的Chabra也签发了冻结令。

Chabra管辖权的精髓在于，不看这笔钱法律上挂在谁的名字下，法庭只看这笔钱的“实益所有权”到底归谁。

何昆作为一个没有对等巨额合法收入来源的家庭主妇，她买豪宅的时间节点，跟夏海钧在恒大巨额违规分红以及套现离场的时间高度吻合，还不能说明问题吗？

这就好比你抢了银行，把钱塞进你老婆的口袋，难道警察就不能查你老婆了？

至于具体有多少钱，你去问那些房地产公司、信托公司，人家肯定不会告诉你。

不得不说，清盘人找了个好律师，他翻了美国法典，找到了第28编第1782条（简称1782程序）。简单来说，就是一个专门为协助外国法庭和原告在美国境内收集证据而设立的法律工具。

目前，清盘人已经到内华达联邦地区法院，发起了1782程序的单方面申请。

内华达州是美国著名的避税天堂和信托隐匿地。接管人发现，夏海钧表面上把信托设在加州，实际上可能暗中把信托的服务提供商、代持的空壳公司，甚至离岸账户，藏在了内华达。

所以，就可以依据1782程序，要求美国联邦法院配合，调取夏海钧名下信托机构、商业代理人以及开户金融机构的所有底层流水和受益人底单。

因为有美国法律做依据，那些银行和信托公司为了自保，只能把夏海钧的资金老底交得干干净净，信托里的资金流向、资产清单，都曝光在了清盘人面前。

然后，清盘人就发现了突破口。

中国的一些富豪啊，你说他老谋深算吧？他相信信托可以保住财产。你说他天真吧？他又往往对信托百般提防，哪怕搞了信托，也不愿意放弃控制权。

你可以看看何昆那个信托的名字，“可撤销信托”。可撤销，意味着他随时可以把资产拿回来自己花。

那么清盘团队就有理由认为，夏海钧对这个信托拥有实质控制权，这就是个伪装成信托的私人提款机。

据此，2025年8月，香港高院行使Chabra管辖权，把何昆也追加为第八被告。然后判决何昆名下总计2400万美元的美国房产、四辆豪车，以及那个“新生活可撤销信托”，也作为被冻结对象。

下一步，一旦法庭走完认定程序，就将进入强制执行阶段。

加州尔湾的豪宅挂牌拍卖，几千万美元的固定资产很快就能变现，然后直接打入香港清盘人的专户。

至于信托公司在银行里的现金和股票，可以直接指令金融机构划扣就行，根本不需要夏海钧本人签字同意。

当然，恒大留下的窟窿两万多亿，从夏海钧那里追回的钱只是杯水车薪。

但这几十亿哪怕只追回来一半，能让多少个停工的楼盘重新转起来？能给多少个濒临破产的包工头结清救命的工程款？

更深远的意义在于“杀鸡儆猴”。只要这次能把夏海钧的海外金库彻底端掉，就是给所有还在观望，甚至打算模仿的资本大佬立下了一个规矩：

卷走老百姓的钱跑到海外享福的时代，已经彻底翻篇了。我们追到天涯海角，也要让你还钱。

所以，别着急，这场跨国追赃，咱们能赢，让子弹再飞一会儿。
