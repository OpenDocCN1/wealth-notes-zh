2026年7月，国务院批复《扩大消费“十五五”规划》。促消费，国家发文件很多次了，过去这类文件基本都是老三篇：促消费、发券、以旧换新。

但是这一次不一样，因为在具体任务中，将促进服务消费的提质惠民排到第一条。

这是一个重要却容易被忽略的信号。因为不是简单的排序调整，而是国家层面对消费战略级的转移。从财税的角度，甚至可以这样理解：从过去依赖一次性产品转移的商品税，转向依赖持续复购体验的服务税。

公众号以前想过，但落地很难，而现在，有了AI这个工具的介入，让这件事具备可操作性以及财政级的想象力。下面就给大家详细拆解一下。

首先，为什么会有商品到服务的战略级转移？

原因很简单，商品消费是有天花板的。你发券也好，以旧换新也罢，消费者买一台冰箱与手机，几年都不会更换或者复购。

某种意义上，发券与以旧换新就是提前释放未来的购买力而已，很难从根本上解决消费疲软的问题。

但是服务消费不一样，服务卖的是专业、时间和情绪，这个是可以大量复购并且没有天花板的。参考美日，它们在跨越人均GDP 1.5万美元的门槛之后，普遍出现一个特征：商品消费社零占比逐年下降，而服务消费占比逐年上升。目前服务消费占比普遍在60%—65%左右。

而中国2025年全国人均服务消费占比为46.1%，与它们相比差距将近20%。这个20%的差距，就是这份文件希望努力弥补的空间。那么具体怎么干呢？

# 一、大规模用AI工具，把服务消费从非标品变成能复购的标准品

服务消费在市场上一直有三个拦路虎：

- 一是非标品，通俗理解就是不同老师上课，质量天差地别。
- 二是信任成本高，退费难、商家跑路维权难。
- 三是交付贵，人力边际成本压不下来。

规划里就是让AI给教育、医疗、文旅、体育、养老赋能。不是卖AI给你，而是用AI把这些领域的非标服务拆成标准化模块，顺手解决上面三个痛点。

说几个场景可能更直观。

教育培训，从请老师补课变成给某个AI工具交年费，以后作业批改、答疑、辅导全标准化，还能达到名师水平。

医疗，推AI医生进家庭，平时一般问诊咨询和慢性病管理都靠AI医生。这既能促医疗服务消费，又把医生大量低效时间释放出来去做科研和复杂病例。

文旅，推出沉浸式演艺和数字文博会员。

还有养老，社区养老嵌入AI照护监测，用户打包订阅，解决子女不在身边、护工磨洋工的痛点。

归纳就是用AI工具，把人力交付的边际成本曲线压平，商家可以像软件一样一次开发、持续订阅，让AI服务遍地开花。

当然国家也会出力，比如规划提到的消费领域国家AI应用基地建设、AI消费应用开放清单，就是推动上面这些场景快点落地。

# 二、扫除制度层面的阻碍

服务消费复购率再高，也怕两件事：牌照办不下来，退费没保障。

规划第四、第五部分全在堵这个漏洞，包括：

- 清理营业性演出、赛事、民宿的不合理限制，推首演地负责制、一站式审批。
- 建立预付式消费监管服务标准、信用评价体系。
- 落实带薪休假和中小学春秋假，给复购腾出时间。
- 文旅、体商融合业态准入互认，文旅局、商务局、体育局联合发许可。

这些事看起来碎，本质是把系统环境成本降下来。

以后城市之间比的不再是谁消费券发得多，而是谁把办一场沉浸式演艺，加托育、加康养、加AI问诊的成本压得更低，数据互通更顺。

资料群pep854，哪个城市把审批流理顺了，服务消费就往哪聚，跟着来的就是那个城市更高的服务型税收。

过去我多次说过，咱们消费疲软有个重要原因，就是财税体制深度绑在生产端，促消费对地方来说是负担而不是收入。国家现在把服务消费当扩大消费抓手，更深一层意思是推动一场从产权转移税到体验订阅税的转型。

过去商品消费交的是一次性产权转移税，卖台车收一次购置税、增值税、消费税，明年不换就不收，而且消费地很难征税，税收大头在生产端。

服务消费交的是持续体验订阅税：康养月费、课程年费、文旅季卡、AI调用费，年年续、年年抽，形成类订阅制税基。而且大多数消费地和企业所在地重合，地方这钱袋子的积极性就有保障了。

按规划2030年目标，社零六十万亿，服务消费占比从46%提至50%以上，也就是服务消费规模约三十万亿，比2025年增加六到七万亿。

按5%—8%综合税负倒推，是每年三千到五千亿级新增可税流水。而且不是卖地那种脉冲式收入，是跟着人口老龄化和收入升级持续滚的复利税基。

这笔账对国家意味着，地产下行后内需窟窿这么填，国家给出的办法就是把国民生命时长做成税基。居民买服务就是买时间，国家从中抽一道持续税，这是工业时代财政到数字时代财政的过渡。

现在问题来了，过去为什么不搞促服务消费，为什么是“十五五”这个节点？因为三个条件同时成熟了。

第一，商品消费见顶，地产链去杠杆，地方急需非土地税基。过去地方卖块地就赚几个亿，来钱太容易，根本没动力搞服务消费。

第二，人均GDP过了1.2万美元，服务消费的收入弹性进入陡峭阶段。收入每涨1%，服务消费能涨1.3%—1.5%。

第三，AI大模型、机器人、可穿戴设备，把非标服务标准化的成本打到了可以商用的门槛以下。

这三个条件缺一个，规划里就只能写“加快发展现代服务业”这种空话。“十五五”是第一次国家把AI加服务形成了落地稿。

说白了，过去房地产、冰箱、彩电的黄金二十年，是国家靠卖东西一次性抽租的二十年。

接下来的二十年，增长点不在商品端，而在课堂、诊室、剧场、健身房、养老院里那些被AI重新打包的时间。

规划把服务消费置顶，不是临时抱佛脚促内需，而是承认一件事：当商品碰到人口天花板，只有把人的生命周期做成能计价、能复购、能征税的现金流，内需引擎才能换个曲轴继续转。

AI是黏合剂，制度是润滑油，城市竞争是压力机，三者合力，把卖东西的财政，慢慢转型为卖时间的财政。
