# 第一，是安全考虑

（无论是政治安全还是国家安全）。

前几个月北京有一次小型事故，大概好像是一个50多岁的男的，不想活了，有点抑郁吧，然后开着飞机把北京一个楼给撞了。因为时间隔了挺久，我具体信息记不清了，大概可能跟海里只隔几公里或者十几公里，对飞机来说，反正就是一脚油门的事。以后随着无人机时代、随着家用小型飞行器普及（我们讲低空经济的时候讲过这个趋势，还讲过对农村土地10年后的影响，可以回顾），所以某些布局势必要提早开展，否则到时候就难了。

并且大家想想，以后国内会越来越参与国际外交，就像今年上半年，基本上外事接待每周都有，都没停过。

北京土著，三天两头被堵在家门口出不去，买各种快递进不了京，生活也受影响。

所以疏解掉非首都的功能，其实是把企业和居民往外搬迁，只保留北京的政事、外事、会议，国家及国际治理的职能。

# 第二个问题

大家猜猜，明明在北京生活和工作会经常遭遇不便，但为什么总有那么多企业愿意留在北京？

其实存在一定的原因，就是方便政商关系，能够保持一定的政策敏感度，一些内部消息流通得更便捷。

但这个过程中一定会涉及到腐败的问题。

这几天国家还在审议《反跨境腐败法》，针对的是拿到钱后外逃的问题。

大家再想想，我们前面讲信托20%税的帖子里，当时我说过，先开始管钱，后面要逐渐开始管人，早晚会建立全球管人的能力。

而现在追逃，则是最有理由的建立跨境缉捕的一步。因为理由无比正当。而这一层跨境合作建立之后，后面渐渐也就有了合作模板，可以再开启其他的合作。

《反跨境腐败法》是堵住去路，让拿了钱的跑不掉。

而疏解北京的非首都功能，则是想要堵住来路，干脆不要有拿钱的起点。算是给政商关系做一层避嫌吧。
