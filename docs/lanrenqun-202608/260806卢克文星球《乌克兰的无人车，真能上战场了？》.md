


# 乌克兰的无人车，真能上战场了？

260806 文/卢克文工作室嘉宾 云梦竹

整理：公众号懒人搜索，懒人专属群精选  
懒人微信：lazyhelper1

最近，西方媒体疯狂报道，乌克兰的无人战车，在一次乌东阵地突破战和金本沙嘴登陆作战中，摧毁了俄军阵地，而且还提供了现场录像。

随后泽连斯基在社交媒体上高调宣布，这是历史上第一次，在没有步兵的情况下，由无人平台摧毁了阵地，而且乌军实现了零伤亡！

那么，事实真是如此吗？无人战车到底能不能改变俄乌的战场格局？

# 1

我们先看看最近西方媒体放出来的实战画面。

战线数十公里之外的地下指挥方舱内，乌克兰第三突击旅NC13小队的老兵，正紧盯着屏幕上的实时画面。

他们通过操作手柄，让指令穿越层层中继，连接到乌东前线那几台满载炸药的无人地面车辆上。

一场针对俄军三处前沿阵地的爆破作战，正在紧锣密鼓地推进。

![](img/ed7c1c1b360c6b660accfe7540db4a04_0_0.png)

只见乌克兰老兵指尖微转，无人车辆即刻行动，依托上方侦察无人机回传的实况画面，碾过弹坑与灌木，向俄军阵地迅猛突击。

俄军士兵给这种噪音微弱、红外特征极低的小车起了个名字，叫“无声的死神”，因为它们常常逼近至十米范围才能被发现。

等俄军发现时，一切都晚了——无人车辆瞬间爆炸，之前需要数十人牺牲才能夺取的阵地，被乌克兰夺回。

不久后，乌军第123国土防御旅第1无人系统营又使用无人水面艇将一挺机枪武装的地面无人车运至黑海俄占区金本沙嘴，成功登陆并执行战斗任务。

但说实话，这些画面的宣传意义大于实际意义。

很多自媒体没有提及一个事实，早在无人车辆袭击俄军阵地之前，该阵地的守军火力点已经被三架光纤无人机摧毁了。

所以真相其实是：这块阵地实际上已经被光纤无人机清理完毕，而无线遥控的无人车，不过是踩着安全通道进去“收人头”的，表演感极强。

请大家记住一个简单结论：如果你看到战场上无人机到处飞，还出现了无人车，只能说明一件事，这里根本不是实战场地，或者是已经打完了。

我们可以从新闻画面中发现一个细节：这两场战斗，乌军无人车都需要依托侦察无人机回传的实况画面，才能有信号中继。

为什么呢？因为地面环境远比空中更复杂，由于山丘、建筑物、树木甚至是高耸的野草遮挡，无线电信号会发生剧烈衰减，操控员驾驶无人车，往往开出去几百米就会失联。

所以，想要使用无人车，就必须依托无人机进行通信中继和实时画面回传。

但是，在俄罗斯的电磁干扰下，乌克兰要怎么让这些无线传输的无人车，丝滑突破密集的防护网络，摧毁俄军阵地呢？

很难的，俄罗斯也不是吃素的。

在实战中，俄军会先压制和摧毁乌军发出的任何无线信号，让无人机变成睁眼瞎，而依赖无人机进行信号中继的无人车，直接就变成玩具车了。

在经历了长达数年的战争之后，俄乌双方针对无人机的电子能力一直在螺旋式上升。

俄乌开战初期，乌军依托Space X的星链终端撑起了整个战场网络，俄军立马搞出了“白芷”机动定位系统，能够在180度扇形区域内探测并锁定10公里内的星链终端，同时处理至少64个目标的坐标。

到了2026年，俄军对Volna Kupol Garant电子战系统进行了实战部署。这套由六辆拖车搭载大型天线组成的装备，专门对着星链终端所在的频段发射强干扰信号，单套可压制近20平方公里。

然而这套系统自身也在发射电磁信号，极易成为乌军反辐射无人机的目标，俄乌双方就在这种猫鼠游戏中不断转换猎人与猎手的角色，导致双方电子战能力都不断提高。

至于电子干扰方面，俄罗斯研发了智者-3B和波力斯卡等系统，在前线大面积发射高功率伪随机噪声，干扰GPS卫星信号。

面对乌军不断更换FPV操控频率，俄军开发了宽频段扫描干扰仪，能实时监测附近电磁信号，并在发现乌军无人机通信频段时，快速进行定向压制，乌军也同样使用西方电子武器进行反制。

一句话，在俄乌这种电子战强度已经拉满的地方，如果连无人机都没有生存空间，无人车就更没有生存空间了。

所以既能让你稳定拍摄并回传画面，又能顺利抵达目标的无人车作战，必然发生在双方电子对抗相对真空的地段，或者是乌军精心挑选的“表演”窗口。

既然表演意味更强，为什么乌克兰还要作这场秀呢？

# 2

乌克兰疯狂推动无人车产业，其实也是形势所迫。

2023年，乌克兰得到了大量人力与物质补充，泽连斯基却极力削减正在巴赫穆特作战的93、92、24等老牌劲旅，将全部豹2坦克、布雷德利战车及数十万生力军，倾斜给毫无实战经验的新建北约旅。

泽连斯基和乌军高层认为，新组建的部队没有旧苏军战术思想的羁绊，全员接受西方教官的直接培训，能更好地发挥西方重装备的北约战术功效。

就是这个决定，让乌军经历了惨痛的损失。

北约旅在2023年夏天的南线大反攻中被俄军一波带走，大量豹2与布雷德利被摧毁，但也是这个决定，意外逼出了乌克兰的无人车产业。

根据《华盛顿邮报》，当时乌克兰老牌单位一天的弹药配给只有上千发，不到俄军的五分之一，而且大量新兵被送往北约旅，老牌单位人员缺口极为严重，甚至出现了缺编40%的情况。

在人员与火力全面不足的情况下，巴赫穆特守军的补给线被俄军炮火和FPV无人机封死，第93旅等老部队的基层官兵被迫想办法自救。

怎么自救呢？他们和民间工程师联手，用农用履带和民用电机拼凑出最早的地面无人运输车。结果，这些简陋的“土制”小车意外有用，竟承担了前线80%以上最危险的运输任务，极大地降低了前线乌军补给线的伤亡。

南线大反攻的惨痛教训，让乌克兰内部分裂成两派：以参谋部为代表的传统派，坚持维修并重整重型装甲部队，而以时任副总理兼数字转型部长费多罗夫为首的“无人作战派”，认为未来作战属于无人装备。

费多罗夫利用官方防务科技集群Brave1这一平台，大量吸纳前线无人车方案，推动形成了标准化无人车生产体系。

在其接任国防部长之后，又开始推行极其激进的采购政策。费多罗夫在国防部任期内，挪用了原本计划维修坦克、采购弹药和重建步兵旅的资金，仅仅2026年上半年就一口气签下了2.5万辆国产地面无人车的巨额合同。

得知坦克、弹药和人员工资被挪用后，乌克兰国防部与总参谋部关系迅速激化，费多罗夫与乌克兰参谋长瑟尔斯基的关系也形同水火。

前文提到的乌克兰第三突击旅NC13小队，就是乌克兰无人作战力量的坚实追随者，乌克兰大量无人车辆都是在该小队的组织下进行战场检测的。至于123国土防御旅，在半个月前转型为无人机旅。

这两场无人车辆参与的作战，都发生在费多罗夫与瑟尔斯基的权力斗争期间。泽连斯基让这两支队伍出镜，立场非常明显。

对于乌克兰而言，无人作战部门的强大也是被逼出来的选择。

当前乌克兰的人力资源已非常匮乏。2026年初，费多罗夫向议会提交了一份报告，称约20万军人擅离职守，逃避征兵者高达200万。俄媒统计的数据更严重，2026年前5个月，乌军擅自离队案件达47098起，同比暴增83.9%，日均超过310人脱队。

与此同时，针对征兵人员的袭击从2022年的全年5起，飙升至2026年前4个月的117起，乌克兰老百姓看见征兵车，甚至想直接动手。

表面上看，是乌克兰的兵役制度僵化，但本质上看，还是缺人。

俄乌双方在前线均维持着数十万大军，但俄军的兵源比乌军充沛很多，可支撑俄军实行退役轮换制度，俄军士兵服役一年就能回家过正常日子。乌克兰这边根本没有轮换一说，许多2022年入伍还活下来的老兵，至今无法退役。

对乌克兰年轻人而言，他们走进征兵站的那一刻，拿到的就是一张单程票，除非重伤，否则几乎没有活着回家的可能。

费多罗夫全力押注无人作战，初衷就是希望通过无人车降低一线人员的压力，腾出名额让部分老兵退伍。

经过四年战争，乌克兰人已经陷入极度厌战的情绪。

基辅国际社会学研究所的数据显示，2022年冲突初期，即便俄军气吞万里如虎，也仅有10%的受访者接受“弃地换和平”，82%的人坚决反对任何领土妥协。

而到了2026年2月，40%的受访者表示，只要获得可靠的国际安全保障，愿意放弃顿巴斯地区以换取长久和平。

费多罗夫的无人化路线，恰好顺应了大多数乌克兰人“不想死又想赢”的心理。

所以费多罗夫被解职后，乌克兰多地爆发了大规模游行，他们喊的口号就是：“费多罗夫会导致更多俄罗斯人死亡，瑟尔斯基会导致更多乌克兰人死亡。”

最后，泽连斯基在两难中选择站队无人机路线。

今天，包括中美在内的主要国家，其实都在推动无人车研发。但是几乎所有国家给无人车的定位都是配合有人部队行动，唯独乌克兰国防部的计划，是要用无人车辆取代人。

但是乌军的无人车，目前真正能够承担的还是运输职能，和大号遥控车没有本质区别，离取代人这个目标还远着呢。

经过最近两场战役的宣传叙事，无人车显得可以独自承担突击作战职能了。瑟尔斯基知道其中的水分，痛斥“把100万人的军队换成无人机，这是拿乌克兰的人民和领土做赌博！”

乌克兰这场无人作战豪赌的终局是什么，我们还无法下结论。

但泽连斯基很清楚，在乌克兰人心崩溃的边缘，他唯一能做的事，就是拼命维系这个“以机器换人命”的脆弱梦想。
