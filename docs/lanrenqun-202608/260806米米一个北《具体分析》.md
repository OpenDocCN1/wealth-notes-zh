# 一、算力板块短期调整无需过度悲观，中长期产业逻辑未被破坏

近期算力赛道受海外BIS政策消息影响出现阶段性回调，从产业基本面来看，本次市场情绪存在过度恐慌，其实经过整个七月，产业泡沫基本上被消化！

第一，AI产业真实需求持续爆发，高性能算力硬件供给缺口长期存在，供需失衡的底层关系没有改变；

第二，上市算力租赁企业二季度财报已经验证行业盈利拐点，利通电子、智微智能、行云科技、协创数据等多家企业业绩预告实现利润大幅增长，行业正式进入利润加速兑现周期；

第三，海外相关管制政策落地、执行流程存在多层主体、地域、客户限制，实际落地执行难度较大，很难对国内算力产业形成实质性冲击。

当下国内算力产业已经进入黄金发展周期，核心支撑来自国产大模型商业化落地提速。

以智谱为代表的本土大模型，代码编写、智能代理等实用能力持续迭代，Token调用量、企业付费收入ARR迎来指数级增长，持续拉动算力租赁需求上行。

从产业链细分环节拆解机会：

1. CPU：AI推理场景打开全新增量，海外服务器CPU价格持续上涨、交付周期拉长，国产CPU厂商迎来放量窗口期；
2. GPU：国内各大科技企业、大模型厂商逐步完成国产芯片适配，本土芯片产能持续突破；
3. 服务器/机柜：超节点架构成为行业标配，算力需求向上传导，带动服务器、机柜硬件需求同步回暖；
4. IDC智算中心：国产算力设备批量上架，各地智算中心招投标项目增多，IDC现货、招标报价同步走高。

算力租赁属于已经被错杀的板块，核心稀缺属性长期不变。一方面，高端GPU硬件迭代周期长，短期难以快速扩产，供给瓶颈支撑算力租赁价格稳步上行；另一方面，北美头部算力租赁企业盈利、融资数据持续向好，国内具备稳定货源、优质客户资源的企业已经实现稳定盈利。

# 二、算力租赁行业核心景气逻辑：三重红利打开估值空间

## 1. 供需缺口长期存在，行业进入量价齐升周期

全球头部云厂商持续加码AI算力资本开支，海外头部算力企业订单积压规模达数十亿美元，同时锁定长期电力配套资源，充分验证行业超级景气周期。

算力租赁已经成为AI产业的“包租公”赛道，稀缺算力资产持续溢价。

## 2. 商业模式升级，盈利天花板大幅抬高

行业从传统单纯赚取硬件租金差价，迭代为“租金+Token收益分成”模式。

算力服务商能够共享大模型商业化变现收益，行业整体利润率存在大幅提升空间，有望重塑全赛道估值体系。

## 3. 长期锁价长协落地，企业现金流确定性拉满

头部算力企业陆续签订2—3年长期合作订单，业绩预期清晰。

以行云科技为例，手握百亿级综合授信与地方专项产业资金，先后落地大额长协订单，与机构客户合作规模从10亿扩张至30.5亿，2026年上半年净利润同比大幅增长，业绩弹性充足。

同时，行业涨价逻辑具备持续性：国内大模型推理需求爆发，Token使用量两年间规模成倍扩张；海外算力厂商已上调高端GPU租赁价格30%，企业客户愿意支付溢价锁定稳定算力资源。

# 三、行业细分案例梳理（仅作产业业务举例）

1. 全产业链布局龙头：行云科技，具备硬件采购、自建机房、长期大客户资源、电力配套完整链条，是A股中业务结构贴合海外成熟算力租赁企业的标的；

2. 大额长协落地企业：宏景科技、利通电子。

宏景科技落地国内万卡算力集群+Token分成新模式；利通电子与互联网大厂签订50亿长期算力协议，机房出租率锁定至2027年；协创数据、润泽科技持续落地政企算力订单，业绩稳步释放；

3. 赛道新入局标的：润建股份、彩讯股份、东阳光，持续探索Token工厂分成创新商业模式，具备长期产业增量预期。

除算力主赛道外，六氟化钨出口价格年内涨幅超312%，下面是数据！

国内现货价格同步翻倍增长：

1. 出口端：1月六氟化钨出口单价69美元/公斤，5月上涨至211美元/公斤，同比暴涨312%；
2. 国内现货：5N级高纯产品6月报价1670—1810元/公斤，同比上涨232.7%；6N级产品两个月价格从90万元/吨冲高至220—300万元/吨，涨幅超190%；7N高端产品长协价格达到330—360万元/吨。

而算力租赁和六氟化钨价格上行是完整上下游产业链关系，一层扣一层，逻辑环环相扣，这里简单说明：

算力租赁扩张 → GPU/HBM需求大增 → 晶圆厂大量采购六氟化钨 → 供需缺口拉大，价格暴涨。

算力租赁：AI产业链下游应用层，做服务器出租、大模型算力服务；六氟化钨是AI产业链最上游芯片原材料，是制造算力硬件必不可少的耗材。

算力租赁行业持续扩张是六氟化钨需求爆发的核心底层驱动，二者分处AI产业链上下游，产业景气度长期共振；短期盘面存在板块轮动分化，但底层供需逻辑深度绑定！

# 六、行业潜在风险提示

1. 国内大模型商业化落地进度不及预期，下游算力需求增速放缓；
2. 行业新玩家持续入场，算力租赁行业竞争加剧，压缩企业盈利空间；
3. 科技企业下游资本开支收缩，算力采购预算下调；
4. 海外贸易管制政策持续收紧，对国内硬件采购形成限制。
