# 国家级金融智库对股市的真实判断，说清了关键问题

本文选自《政经参考》第169期，完整的课程在专属群内连载中。今天我们谈一个关于中国股市的权威报告。报告来自国家金融与发展实验室（NIFD），这个机构非常出名，它隶属中国社科院，是2015年中央批准的首批25家国家高端智库之一，也是其中唯一的金融专业智库，为国家制定货币金融政策和宏观经济政策服务。这个机构关于资本市场的报告，尤其值得关注。

报告的名字叫《2026年上半年股票市场分析报告》。报告客观翔实，非常有解释性。

比如，关于股市的分化，报告直接指出：

2024年9月24日出台本轮股票市场的刺激政策，9月26日上证指数收盘正好是3000点。以当时上证3000点作为基准，到今年6月30日为止，有1400余只股票超过了3000点对应的价格，主要集中于与半导体和AI算力有关的股票。有4000多只股票价格低于2024年9月26日对应的价格，占所有股票的74%。

报告说：这个结果可能颠覆很多人的想象。在大多数人的印象当中，2024年9月24日之后，政府出台了一系列刺激股市的政策，对应的股票市场指数均出现较大幅度的上涨，市场已经实现了所谓的“慢牛”走势，但真实情况是，超过70%的股票的价格是下跌的。

所以我们今天就看看，国家金融领域最权威的专业智库对今年股市的判断是怎样的。

我将分三部分来讲：首先，上半年股市的情况到底是怎样的？其次，这一现状背后的原因和机制是怎样的？以及，国家权威智库对下半年股市的判断是怎样的。

好，开始吧。

# 分化和现实

我们先来看看上半年的数据情况。

报告指出，今年上半年，科创50指数上涨了64.3%，创业板指上涨35.8%，沪深300上涨7.55%，上证指数上涨3.2%。但同期，在主要指数上涨的同时，全A中位数指数下跌了31.2%。简单说，这意味着如果你没有买到少数大涨的科技股，那你大概率已经亏了30%以上。个股统计情况也比较一致，今年上半年上涨的股票1697只，下跌的3770只，下跌的大概70%。指数的平均性掩盖了这一点。

另外，市值层面，风格从去年的小市值切换到了中大市值，500亿到1000亿元市值组涨了32%，而30亿元以下的微盘组由涨转跌，原因是并购重组政策收紧、新股发行加快，壳的价值和稀缺性都贬值了。

而从领涨领跌的品种看，今年涨幅前20的股票，涨幅区间在400%到800%之间，主要集中在电子、通信、半导体、新材料和AI算力方向。而跌幅前20的股票（剔除退市和ST），跌幅都达到了50%以上，其中不少股票还出现在去年的涨幅榜上。换句话说，市场的主线在一年内快速切换。

# 看懂两大股力量

那么，是什么因素把这么多钱挤到一条赛道上去的？我认为报告给出了两股力量，这两股力量的叠加，才是理解今年以来股市的关键。

第一股力量，是公募基金极致的“抱团”现象。

报告指出，二季度公募的持仓集中度出现了跳跃式上升。前十大重仓股的持股市值环比增长了51.5%，占全部A股持股市值的比例接近三成；而剔除前十大持仓之后，其余股票的持股市值反而是下降的。也就是说，增量资金几乎全部涌向了头部股票。

行业层面更极端，公募基金在电子和通信两个行业的合计持股市值，从一季度的1.09万亿元增至二季度的2.26万亿，一个季度就大增107%，占全部A股持股市值的比例从28.9%升到54.8%，单季提高了近26个百分点。

从公募重仓股的名单看，一季度公募的前十大重仓股，还横跨锂电、白酒、有色、保险、医药等不同行业，但到了二季度，前十大重仓股，除了少数还持有宁德时代，其余几乎全集中在AI硬件产业链上。二季度新进入前十大的是北方华创、兆易创新、东山精密、源杰科技，被挤出去的是贵州茅台、紫金矿业、中国平安和药明康德。

机构抱团这件事在A股不是新鲜事，但抱团之后往往就会迎来大跌。报告把历史上的几轮拉出来比了一下：

- 2007年三季度抱团金融和地产，持仓集中度达到了38%；2008年9月之后，金融、房地产类股票大跌超过60%。
- 2015年一季度机构抱团TMT，持仓集中度达到了46%，创历史峰值；2015年6月，TMT行情走到了终点，板块股票下跌幅度均超过50%。
- 还有2020到2021年机构抱团食品饮料。2021年一季度末，白酒板块在公募重仓股中占据了绝对主导地位，然后，是2021年之后白酒板块持续5年下跌。

报告说，每一轮抱团行情均以股价大幅度下跌收场，基金投资人遭受损失。

为什么公募抱团的结果往往会带来板块的大幅下跌？我的看法是，这背后其实是公募运作机制中一套环环相扣的自我强化机制：

第一道环是考核方式。

虽然短期排名被弱化了，但它却没有消失。这意味着，如果一只股票所有同行都在买，而你不买，它涨了你就跑输，规模会流失，位置可能不保；反过来，如果大家都买了它，而它跌了，你跟着跌，排名其实并不受损。所以从基金管理者的角度出发，跟随抱团是更安全的选择。集中不是因为所有人都看好同一个方向，而是因为不跟随的代价太高。

第二道环是资金的正反馈。

公募抱团推高股价，股价推高净值，净值带来排名上升，排名上升又带来渠道推荐和新投资者的大幅申购。新申购的钱进来之后，基金经理要么继续买入原有持仓，要么加仓同一批股票，因为在建仓周期里，买自己已经研究过、且正在上涨的股票，是阻力最小的路径。于是新钱又推高了股价，循环重启一次。每转一圈，持仓更集中，净值更好看，风险也更大。

第三道环是被动产品的助推。

主题ETF资金进来要按规则买入成分股，不看估值。所以当散户看到AI主题赚钱效应、买入主题ETF时，这笔钱是加大流向抱团股的。报告特别提到，二季度出现了主动基金、主题ETF和融资资金同时重仓同一批科技股的现象，三路资金指向同一个方向，看起来是共识，实际上是把所有鸡蛋放进了同一个篮子，而且其中一个篮子还加了杠杆。

第四道环是筹码结构的变化。

当各大机构持仓占到一只股票自由流通盘的很高比例，市场上可交易的筹码就变薄了。这时候，股票行情对边际资金就会极度敏感，少量买盘就能推动大幅上涨，但同样的道理，少量卖盘就能砸出深坑。这时候市场其实已经进入到了一个过度集中、没有承接的状态，这个状态下，甚至不需要有利空消息，只要买盘停下来，价格就会撑不住，股票就会开始下跌。

第五道环就是自我加速。

股票下跌导致公募基金的净值下跌，净值下跌可能会导致很多投资者赎回，赎回是刚性的，基金经理只能卖出持仓变现；而他持仓最重的，恰恰是那些筹码已经很薄的抱团股，卖出直接砸出下跌。这是上涨那个循环反过来跑一遍，但速度会快得多。

这一整套逻辑就是为什么公募抱团后，往往都会以板块大跌收尾的核心，原因就在于资金结构的集中和拥挤。监管层显然也看到了这一点，6月12日，中国证券投资基金业协会出台了《公开募集证券投资基金主题投资风格管理指引》，针对基金的风格漂移做出了规范。

接着说报告中解释分化的第二股力量，也是报告重点提到的，准“平准基金”的大额赎回。

上半年宽基指数基金出现了大额赎回，报告判断赎回主体应该是以汇金为主的准平准基金。根据报告的测算，一季度，汇金等相关主体已经减持了约1.18万亿元，且高度集中在沪深300等核心宽基上。与此同时，报告还测算了汇金持仓占比超过50%的ETF申赎净流入日度累计，这一数字在2025年12月31日是正的7596亿元，但到2026年6月30日，变成负的7460亿元，半年之间减持了约1.5万亿的ETF。ETF的整体数据也印证了方向，上半年ETF数量在增加，总规模却在下降，其中宽基ETF规模大幅下滑，而主题和行业ETF在增长。

这里需要把ETF赎回的机制讲清楚，ETF赎回不是把份额卖给另一个投资者那么简单，而是用份额换回一篮子成分股。拿到股票的机构会在二级市场卖出变现。所以一笔宽基ETF的大额赎回，最终会转化成对沪深300、上证50这些成分股的真实抛压，而且可能是几十上百只股票被同时卖出。

这就解释了一个看起来很矛盾的现象：为什么低估值蓝筹越来越弱，而估值已经很高的科技股反而越来越强。

按常理，蓝筹便宜就应该有资金去买。但赎回是在卖出蓝筹的一篮子股票，这会直接压制蓝筹的价格；价格持续走弱之后，其他市场资金会有意避开这一块，导致它进一步低迷、屡创新低；而市场的资金又总要找出路，于是更加向科技股集中。

现在，我们把公募抱团和准平准基金赎回这两股力量放在一起看，上半年的分化的市场结构就清晰了：一边是承接盘在撤出，一边是主动资金在挤向单一赛道。K型的两端，各有一只手在推。

# 下半年怎么看

那对于下半年股市的行情，报告是怎么看呢？

报告构建了一个指标，就是用“前5%的个股成交额占市场总成交额的比重”这个指标，来衡量风险程度。根据报告的统计，这个指标超过45%之后，通常容易出现物极必反的拐点。2014年底、2015年初、2021年初，这个指标都超过了45%，随后也都迎来了显著大跌，而今年6月，这个指标已经达到了48.9%。这个指标可以是一个观察点。

另外，对下半年，报告还提示了两个关键变量。

第一个是美国AI股价泡沫破灭的风险。

报告的判断很明确：到目前为止，美国的AI产业还没有形成商业闭环。龙头企业的利润增长在很大程度上依赖关联交易。这个循环在融资顺畅、数据中心持续推进的阶段是能自我维持的，但它的前提是股价不能停、融资不能断、终端付费要跟上。一旦其中任何一环松动，收入预期和上游硬件需求会同步承压。

第二个变量是准平准基金的动向。

报告说，从最近两年的股市运行看，以汇金为主的准“平准基金”对市场的影响不可忽视。上半年准“平准基金”采取了巨额赎回操作，下半年它们的策略，应该密切关注。

而理解了上半年，能帮我们更好地判断下半年。
