# 003 改掉坏习惯，节约时间

做内容输出，是非常占用时间的，我最爱看的电视剧小说都被我放弃了，节约了时间就有了时间写文案。

# 004 水滴石穿，坚持是最大的能量

开始不会写，写两条改两条，后来写得多了有感觉了，每天稳定三条、5-10 条逐渐加量，会发现，坚持的能量比你想的大。

# 005 先完成，再完美

我很多学员觉得写的不好，不敢发，想要等练好的时候再发，但事实上如果你不发出去永远都不可能写好。

# 006 正反馈，有动力
