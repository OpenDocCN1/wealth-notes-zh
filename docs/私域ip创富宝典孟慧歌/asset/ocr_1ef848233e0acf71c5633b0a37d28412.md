# 001 善用费曼学习法

为什么要讲稿，那就一定要说《费曼学习法》，就是把自己学过的东西再讲给别人，可以演讲可以文字，通过以教为学的方式，达到提高自己知识储备量和内化知识的目的

# 002 如何获取讲稿的内容？

可以选择读书的方式，也可以把别人的分享/听到的课程/学到的直播干货等归纳一遍，复刻出来读完了再通过讲述的方式让知识真的成为自己的。

# 003 讲稿的场域有哪些？

用社群、朋友圈、直播间或者线下演讲等方式，达到提高影响力的目的。
