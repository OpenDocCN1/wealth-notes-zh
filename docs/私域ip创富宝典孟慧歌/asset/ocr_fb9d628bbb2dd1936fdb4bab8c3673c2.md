# 【017】如何提升直播间表达力？

“说服是用一种更好的思想改变人们的世界观”。演讲不但可以用在舞台上，还可以用在直播间，一切可以让你公开表达，影响他人的地方。

**001 打破框架，重新建立你的框架**

演讲的核心，是说服，说服的核心，是要让听众认为Ta过去的思维是错误的，而相信你的。把你的思维装进Ta的大脑里，建立新的思维框架。

**002 你的直播间该讲什么？**

①前言——明确要讲的主题

②背景——为什么你讲的这个问题很重要

③内容核心——绘声绘色的描述你的重点

④实践意义——用它会对听众有什么好处

⑤结论——收尾，让听众回去执行

**003 学会铺陈**

铺陈是一种很重要的战略策略，在直播间不要干扁的讲出你的观点，可以用一种更合理的比喻或语言策略让你的结论更合理。
