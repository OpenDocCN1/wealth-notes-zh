# 005 宁可精细，不要宽泛

其实社群、直播、销售、一对一、短视频等等板块我 都会，但当时我只选了朋友圈这个细分作为切入点， 为什么？是因为越精细的定义用户范围，市场份额增 长就会越快。

# 006 选择基本需求

不要在某一方式上专业，因为这样行业一旦没了，你 就没了。要基于人性需要的基本需求，比如哪天朋友 圈没了，但是文案技能是通用的。越是基础需求，这 份技能越是不会让你没饭吃。
