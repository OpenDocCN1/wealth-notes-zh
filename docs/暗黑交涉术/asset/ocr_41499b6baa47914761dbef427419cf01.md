# 讓對方覺得自己很特別，他就會降低戒心

除了未公開發行的股票，另外像是黃金、鑽石、寶石、贛岩氣等天然資源開發權，或是國內不易變換現金的外幣交易等，都被當作「我會跟你高價收購！詐騙」的題材。

這種詐騙的重點是，「只有特定的人才會收到簡介」、「只有你才有購買權」，像這樣令對方感覺自己很特別。

這正是戴爾卡內基的著作《人性的弱點》當中所提到的「使人產生重要感」。
