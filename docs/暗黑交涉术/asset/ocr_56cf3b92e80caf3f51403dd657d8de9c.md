# 話技巧

㊄「好ㇿㇿㇿ！喔！我想，您之後找到想做的工作，一定會很賣力工作對吧！」

受到稱讚的男客人一臉暗爽的表情。就在這時，那個女推銷員馬上接著問：

㊅「對了，您有訂做過西裝嗎？」

㊆「喔，沒有耶。」

㊇「這樣啊，我覺得您應該要有一套穿起來合身的訂製西裝比較好。」

最後，那位女推銷員還向男客人強調西裝的必要性，同時成功說服他以每個月刷卡繳費的方式買下三十萬日圓的昂貴西裝。
