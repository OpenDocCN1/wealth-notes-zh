# 反覆詢問對方容易認同的問題，促使對方作出明確的行動

轉換成當事者的觀點，引導出消費者的主動意願，這樣的手法制於各種買賣交易的場合。最簡單易懂的例子就是，電視購物。

起初，先把商品講得有多好多棒，讓觀衆聽著聽著產生興趣。然後，螢幕上秀出「接受退貨」這行字，電視購物專家接著說「請您試用看看，如果不滿意，我們會退貨一之類的話。看到這兒，觀衆心想「好像可以試一試」，於是打電話訂購商品，做出具體的行動。觀衆從原本只是在看電視的旁觀者，變成以自己的意思做判斷，決定購買商品、簽約，這正是典型的範例。
