# 交渉或商談陷入僵局，不妨轉換問題切入點，引導對方思考

買賣交涉時，因為很想達成簽約的目標，視野會愈來愈狹隘，容易導致情況僵持不下。此時，不防暫時遠離目前的話題，試著以社會或國家的大觀點來重新思考。「你覺得今後日本的經濟會變成怎樣？」「貴公司往後打算採取的經營策略是？」在對方腦中導入整體局勢，從大觀點再次思考對簽約遲疑的真正理由，然後消除那個瓶頸。
