# 藉由非黑即白的極端思考、對立思考，操縱人心
「二選一」的威力，讓人陷入思考的盲點

+   - 詠讚案例：懷抱明星夢試鏡，花了十五萬買到的教訓……
- 詠讚技巧：活用理想與現實的對比，誘導對方照自己的意思去做
- 商務場合應用：將事物一分為二，深入分析對方的想法，規劃縉密的銷售戰略

# 建立信賴關係後，刻意變得冷淡，令對方回心轉意
為什麼「猛烈進攻」後「退守」能抓住客人的心？

+   - 詠讚案例：猛烈的質疑攻勢，反而令人退避三避……
- 詠讚技巧：進攻後故作冷淡，對方反會回心轉意
- 商務場合應用：表現冷淡之前，務必先讓對方感受你的誠意

# 冷靜接受對方的批評，利用接話的時候，鬆懈對方的警戒心
「但是」、「不過」、「可是」……詐騙集團的禁用詞

+   - 詠讚案例：已經警覺對方是詐騙集團，為何還是被騙？
- 詠讚技巧：面對批評的言論，先退讓一步，取得信任
- 商務場合應用：簽約前刻意讓對方說出疑慮，釋出不安，就能減少解約可能性
