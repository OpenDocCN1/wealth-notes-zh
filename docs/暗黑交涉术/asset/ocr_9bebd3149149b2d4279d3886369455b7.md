# 面對批評的言論，先退讓一步，取得信任

商场上也是如此，做生意一定会听到客户的批评挑剔。

这时候，交涉的成功与否取决于你的态度。当客户不肯接受我方的意见时，「不对，不是那样的！」「可是，那是因为○○○○……」有些人会忍不住想反驳，但那么做无法让事情圆满解决，甚至可能导致交涉破裂。

面对批评的言论，请先退一步。那么做并非委曲求全，而是要让对方觉得你有在让步。这么一来，对方会认为自己的反驳回压住了你，心生满足。殊不知你正准备全击。

而且，展现退让的态度也能取得对方的信任，使谈话顺利进行。过去我曾在客户时遇到所谓的高手。那时我生气地向对方抱怨产品与服务的不周全，但对方并未立刻反驳，而是先说「感谢您宝贵的意见」、「您说的对一，将我的怨言照单全收，然后才继续接话。这样的应对方式，客诉的人会觉得自己吐为快，自然会心平气和地听对方解释。
