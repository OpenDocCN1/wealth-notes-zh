# A.1.4 T+1 制度

我国实行的 “T+1” 制度本质上是证券交易交收方式，使用对象有 A 股、基金、债券、回购交易，是指达成交易后，相应的证券交割与资金交收在成交日的下一个营业日（T+1 日）完成。
