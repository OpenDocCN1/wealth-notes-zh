# 图 4-8 RSI 函数定义

在 TA-Lib 中，RSI 函数入参 2 个：收盘价和统计周期，默认周期是 14，出参是 RSI 值。定义函数 rsi 入参是周期数 n 和 array（默认值 temprana False）。调用 TA-Lib 的 RSI 函数计算均线。若 array 为默认值（即 False），则只计算最新的 RSI 值，否则输出所有 RSI 值。

```
def rsi(self, n, array=False):
    """RSI 指标"""
    result = talib.RSI(self.close, n)
    if array:
        return result
    return result[-1]
```
