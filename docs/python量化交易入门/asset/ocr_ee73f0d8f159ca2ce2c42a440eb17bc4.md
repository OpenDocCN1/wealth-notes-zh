# Python量化交易

2018年年末，vn.py项目终于有了第一个长期支持的稳定版：v1.9.2 LTS，杨飞的这本书记可以说是正好解了整个vn.py社区的燃眉之急。作为vn.py项目的作者，深知社区对于项目最大的不满可能就是文档资料的缺乏了：一方面因为项目之前处于快速迭代中，很多功能特性尚未确定下来，另一方面比起写文档（或者组织写文档），我自己本身更乐意写代码。

本书从量化交易的概念引入开始，插一句，里面写的量化先驱们的故事很好看，将手把手、细致入微地教会你安装和使用vn.py，最终引出本书的核心引擎——深入的交易策略研发开发方法（而不仅仅是简单地举例子）。我相信，无论对于量化交易的入门者，还是已经在用vn.py实盘操作并且希望进一步提高的资深用户，都能从此书中找到自己所需要的内容。
