# 1. 参数优化设置

本次优化目标是夏普比率，需要优化的参数只有两个，分别是金肯特纳通道的回望周期和通道宽度。注意 runParallelOptimization()函数会调用 CPU 的所有线程去进行并行优化，缩短优化所用时间，缺点是电脑会变得非常卡顿。

```
# 优化配置
setting = OptimizationSetting()              # 新建一个优化任务设置对象
setting.setOptimizeTarget('sharpeRatio')      # 设置优化排序的目标是夏普比率
setting.addParameter('kkLength', 8, 16, 1)    # 增加第一个优化参数 kkLength
setting.addParameter('kkDev', 1, 1.8, 0.1)    # 增加第二个优化参数 kkDev

# 执行多进程优化
import time
start = time.time()
```
