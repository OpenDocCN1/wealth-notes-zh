# 1. TurtleResult 类

用于计算单笔开平仓交易盈亏，是海龟策略中判断 “上一笔赢利当前信号是否无效” 的基础，其函数如下。

+   ○ __init__(): 初始化单位头寸、开仓均价、平仓均价和单笔开平仓交易盈亏数。○ open(): 先计算开仓累计成本，然后统计开仓平均成本。○ close(): 缓存平仓均价，统计单笔开平仓交易盈亏。
