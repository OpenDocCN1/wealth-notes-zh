+   - IF888：主力连续合约，对价格拼接进行了 “平滑” 处理，即以主力合约切换前一天（T-1 日）新、旧两个主力合约收盘价做差，之后将 T-1 日及以前的主力连续合约的所有价格水平整体加上或减去该价差，以 “整体抬升” 或 “整体下跌” 主力合约的价格水平，成交量、持仓量均不调整，成交额统一设置为 0。
- IF99：指数连续合约，由 IF 股指期货全部可交易合约以累计持仓量为权重加权平均得到的。
