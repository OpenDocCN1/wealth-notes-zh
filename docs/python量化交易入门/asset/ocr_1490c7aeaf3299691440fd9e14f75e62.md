# 9. 显示前 10 条成交记录

成交记录会保存在成交字典（tradeDict）中，通过查询成交字典可以得到交易时间、多空方向、成交价格和成交数量等信息。

```
for i in range(10):
    d = engine.tradeDict[str(i+1)].__dict__
    print 'TradeID: %s, Time: %s, Direction: %s, Price: %s, Volume: %s' %(d['tradeID'], d['dt'], d['direction'], d['price'], d['volume'])
```
