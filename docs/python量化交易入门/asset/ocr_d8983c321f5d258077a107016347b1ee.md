# 2.9.3 多个图的绘制

（1）创建画板：

```
fig=plt.figure(1)
```

（2）在画板里建立若干个画纸（子图）。在画纸中，subplot()方法的括号里包括三个数字：前两个数字代表要生成几行几列的子图矩阵，第三个数字代表选中的子图位置。例如：subplot(2,1,1)生成一个 2 行 1 列的子图矩阵，如图 2-21 所示。

```
#创建画纸，并选择画纸1
"""
等价于 ax1=fig.add_subplot(211)
"""
ax1 = plt.subplot(2, 1, 1)

#在画纸1上绘图
plt.plot([1, 2, 3])

#选择画纸2
ax2 = plt.subplot(2, 1, 2)
#在画纸2上绘图
```
