# 2.3.2 第三方库的函数

这里运用 2.2.4 节用过的例子来说明如何调用第三方库的函数。首先用 import talib 调用金融库 TA-Lib，再结合 TA-Lib 自带的函数 talib.SMA()来定义新的函数 SMA。

```
import talib
def sma(self, n, array=False):
    """简单均线"""
    result = talib.SMA(self.close, n)
    if array=True:
        return result
    return result[-1]
```
