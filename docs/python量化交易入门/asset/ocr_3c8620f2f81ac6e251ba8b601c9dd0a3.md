# 5.4.2 策略代码解析

# 1. 策略参数

金肯特纳通道指标初始化天数是 11 天，调用 K 线管理模块中 TA-Lib 库定义的函数可以计算出均线和 ATR 指标，进而得出金肯特纳通道的上轨和下轨，代码如下：

```
def keltner(self, n, dev, array=False):
    """金肯特纳通道"""
    mid = self.sma(n, array)
    atr = self.atr(n, array)
    up = mid + atr * dev
```
