基于 TA-Lib 库内置的 AROON 函数，在 K 线管理模块中构建应用于 K 线时间序列的 AROON 函数，代码如下：

```
def AROON(self, n, array=False):
    """Aroon 指标"""
    aroondown, aroonup = talib.AROON(self.high, self.low, n)
    if array:
        return aroondown, aroonup
    return aroondown[-1], aroonup[-1]
```
