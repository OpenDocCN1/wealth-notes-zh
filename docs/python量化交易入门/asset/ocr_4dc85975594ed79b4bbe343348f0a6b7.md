# 2.9.1 用列表绘制线条

利用列表定义 x 轴和 y 轴，再用 plt.plot()来绘制线条，如图 2-16 所示。

```
import matplotlib.pyplot as plt

#第1步: 利用列表信息来定义x和y轴坐标
x = [1, 2, 3, 4]
y = [1,4,9,16]

#第2步: 使用plot绘制线条
#第1个参数是x的坐标值,第2个参数是y的坐标值
plt.plot(x, y)

#第3步: 显示图形
plt.show()
```

![](bbox=[0.24, 0.46, 0.725, 0.725])

同时，plt.plot()可以设置三种线条属性，属性状态分别如下。

+   o color：线条颜色，值 r 表示红色（red）。
 o marker：点的形状，值 o 表示点为圆圈标记（circle marker）。
 o linestyle：线条的形状，值 dashed 表示用虚线连接各点。
