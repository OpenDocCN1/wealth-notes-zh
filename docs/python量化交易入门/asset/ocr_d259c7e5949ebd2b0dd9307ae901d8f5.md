# 2. 上海期货交易所

上海期货交易所（以下简称“上期所”，英文缩写为 SHFE）于 1999 年 9 月在上海正式运行。主要交易品种为金属期货，同时也涉及能源期货和化工期货。合约为品种代码（小写字母）+年份+月份，部分合约如下。
