# 5.2.5 滚动回测

以 3 年为滚动周期，步进是半年，对 20100416 至 20180101 区间进行滚动回测及参数优化，并且收集表现最好的前 3 组优化参数。

通过对历史优化参数的统计分析来预测未来的优化参数。其选择标准如下：

+   • 近年参考权重大于远年。
• 若优化参数整体变化不大，则取众数。
• 若优化参数整体发生变化，则在近年区间取众数。
• 若前一年参数发生剧烈变化，则对该区间进行更为细致的滚动回测和参数优化。
