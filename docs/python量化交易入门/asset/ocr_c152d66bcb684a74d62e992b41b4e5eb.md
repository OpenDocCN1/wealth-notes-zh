定义函数 sma（注意，这里函数名称是小写），入参是周期数 n 和 array（默认值CntFalse）。调用 TA-Lib 的 SMA 函数计算均线。若 array 为默认值（即 False），则只计算最新一条均线的数值，否则计算出所有均线的数值。

```
def sma(self, n, array=False):
    """简单均线"""
    result = talib.SMA(self.close, n)
    if array:
        return result
    return result[-1]
```
