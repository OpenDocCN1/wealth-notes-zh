# A.2.3 期货交易策略

# 1. CTA 策略

商品交易顾问（Commodity Trading Advisor，简称 CTA）是指通过为客户提供期货、期权方面的交易建议，或者通过受管理的期货账户参与实际交易，来获得收益的机构或个人。传统意义上，CTA 基金的投资品种仅限于商品期货，但近年已扩展到包括利率期货、股指期货、外汇期货在内的几乎所有期货品种。CTA 基金因为很好的业绩稳定性，以及与其他策略的低相关性，赢得了快速发展。总体而言，CTA 基本上能够分三大类，其中包括，趋势跟踪约占 70%，均值回归占 25%左右，逆趋势或趋势反转占 5%左右。

# （1）趋势跟踪策略

趋势跟踪策略是基于市场并非有效的假设，基本面变化的信息需要一定的传递时间，资产价格不能立即反映基本面的变化，价格向合理方向逐渐变化的过程所表现出的趋势。与正态分布相比，资产收益率的分布通常具有“尖峰肥尾”的特点，“肥尾”提供了趋势跟踪策略的收益。趋势跟踪策略的赢利与市场的波动性密切相关，在一定程度就是“追涨杀跌”的策略，通过快速止损实现“亏小赢大”的局面，从而在整体上获利。
