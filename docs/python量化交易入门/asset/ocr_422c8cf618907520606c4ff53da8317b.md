# 1.1.1 量化交易的概念

在回答“为何选择量化交易”这个问题前，先理解量化交易的概念。

严格地说，量化交易是运用复杂的统计学方法和数学模型，从庞大的历史数据中海选出能带来超额收益的多种“大概率”事件以找出规律、制定策略，并且能用数据模型验证、固化这些规律和策略，然后用计算机来严格、高效地执行之。
