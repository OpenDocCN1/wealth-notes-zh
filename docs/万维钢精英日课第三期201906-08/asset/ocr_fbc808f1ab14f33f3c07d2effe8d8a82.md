今天我们把里吉尔的《生活黑客》这本书讲完。

我注意到咱们得到的很多读者最想要的是可操作的方法，简单就是说你就直接告诉我该怎么办吧。《生活黑客》这本书的确讲了很多“怎么办”，但是这本书的副标题很有意思，叫“系统化生存及其反对者”——里吉尔不但介绍了方法，而且介绍了人们对这些方法的反对意见。

如果这个讲法让你感到无所适从，说我到底该不该学习这个方法呢？我认为你不论是读书还是做事的功夫都不够家。

讲一个方法的同时明白对这个方法的反对意见，这才是正确的讲法。

这就好像卖药得给人标明所有的副作用一样。世界上并不存在什么有效而又完整的方法，其中包含一系列的“if……then……”条件语句，告诉你在这种情况下你就应该这么办，在那种情况下你只需那么办。事实上那种的世界也没意思。

# 1.斯多葛哲学

是的，就连一向提倡技术和算法的生活黑客们，也需要一点哲学。生活黑客倒是缺少人生意义，“加州意识形态”已经给他们提供了人生意义，那就是要通过工具和技术手段破解人生的各个系统，让自己活得更自由，要对生活有一种掌控感。但是生活黑客意识到，生活中有很多事情是不可控的。怎么面对人生中的失控和失望呢？

# 2.个人操作系统

斯多葛哲学非常契合黑客的精神。我们前面说了，黑客精神包括理性、实验、系统和个人主义。

# 3.冥想的功效

如果说斯多葛哲学是生活黑客的个人操作系统，来自佛学的“正念冥想”就是生活黑客的功效增强工具。
