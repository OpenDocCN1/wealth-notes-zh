# 来自日课：站在西方的观念上理解西方

读者 L.J.:

万老师，我觉得西方现代社会似乎有一种“科学迷信”，也可以说是一种科学崇拜，包括我们国家也有这种现象，就是没有被科学证实和加持的事情就像表示嗤之以鼻，但从就没有知道到底什么是科学，如何判断科学是否科学以及科学的边界在哪里。以为于是我经常听到旁边人说别人“这不科学，这是迷信，这是误解。”请问万老师您觉得这种科学崇拜有什么问题吗？作为普通人如何识别科学、信仰和迷信？

万维钢

我没有观察到普通的“科学迷信”现象。现代社会都尊重科学，这不是科学迷信。事实上西方现代社会不但没有科学迷信，而且宗教的势力还很强。美国公立学校不允许传教，但是有些学校为了照顾宗教情绪，是不教达尔文进化论的。宗教人士可以和科学家公开辩论，而且往往是科学家输。单纯以权威性而论，世界上科学地位最高的就是中国。

我猜你所反感的，应该是那些没有思考，单纯站队、甚至打着科学的旗号党同伐异的人。这样的人其实也不是很多，只在网上能碰到。

科学本身并不是一套信仰系统，并不直接告诉你“世界的真相”是什么，科学只是一套用理性探索世界的方法——而探索出来的结论，是可以修正和改变的。从这个意义上来说，所谓“信科学”本身就是个不科学的说法。正确的态度是相信科学方法，而不是信仰科学结论，更不是崇拜某个科学家。

我来打个比喻。假设有A、B、C三人——
A说，“我相信中医，我自己的病就是中医治好的！”
B说，“哈！你这个无知的人！中医不科学！你说这个话应该感到<|message|>！ ”
C说，“你这个结论站不住脚。要知道有些病不治也能好，相关性不等因果性，我们必须用随机试验的科学方法来证明中医的有效性。而鉴于中医界总是拒绝做科学实验，我个人倾向于不相信中医。”

# 来自日课：一神论高在那里

读者 cheny159508906：

上帝有一个能力相当的敌对头撒旦，这不就是两个神吗，为何还可以说是一神论？

万维钢

撒旦并不是上帝的“对等实体”。关于撒旦到底是什么，我看过好几种说法。有的认为撒旦是堕落的天使，而我们知道天使最多只能算是上帝的手下，那么撒旦最多就是一个反抗者。犹太教的观点则认为撒旦并不是一个实体化的存在，它其实指的是人性中恶的一面，是个抽象概念。

# 来自日课：雅典修炼系统

读者 Gnoloayoul@坐忘：

万老师，请问能把雅典修炼系统和“格物致知”相提并论吗？

万维钢

这是一个非常有意思的问题。“格物致知”出自儒家经典《礼记·大学》，是人生成长路线图的一部分，格物致知，后面是诚意、正心、修身、齐家、治国、平天下。其他都容易理解，唯独这个“格物致知”，后世的人都说不清它是什么意思。
