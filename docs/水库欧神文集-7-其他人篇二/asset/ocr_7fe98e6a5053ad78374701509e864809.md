本文聊聊 2019 年最热电影《小丑》，没有关键剧透。这部电影没有复杂的情节，真正吸引人的地方是演员出色的表演。正因如此，看完本文也基本不影响观影体验，读者大可放心阅读。

# 一、反超级英雄

自 1940 年代随着蝙蝠侠登陆漫画作品，小丑一次次被演绎，成为电影史上最著名的反派。《蝙蝠侠：黑暗骑士》中，希斯·莱杰饰演的小丑杀人不眨眼，极尽癫狂邪恶，令人不寒而栗。今年杰昆·菲尼克斯在电影《小丑》的表演，则被认为是创造了新经典。电影上映后，很多人说：杰昆·菲尼克斯预订了明年的奥斯卡影帝。

《小丑》的剧情很简单：亚瑟·弗莱克是哥谭市落魄的社会底层，他的工作是扮成小丑在商店门口举着促销牌子。亚瑟患有精神疾病，要接受心理咨询和定期服药，服药使他常常不可自抑地大笑。由于这个疾病，他受到排挤和打压，生活苦闷。令人苦恼的是，亚瑟的梦想是当一名笑星，疾病使他注定无法成功。在经历一连串被侮辱与被损害后，亚瑟·弗莱克放弃幻想，成为真正的暴徒“小丑”。整个城市，亚瑟这样的人并不少，哥谭陷入火海。
