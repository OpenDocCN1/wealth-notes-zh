# 2）职业道德

没有职业道德的，又岂止微信公众号。

如今这年头，艺人被质疑演技不好，要吐槽说：

> “我们每天都在努力进步的，你们看不见吗？”

腾讯娱乐：现在外界对于青年演员的演技讨论也很多，你有感受到压力吗？

关晓彤：我觉得有些人就是站着说话不腰疼吧。因为我们是青年，我们也在不断学习。只要自己有心，我觉得，每个青年都应该允许“犯错”，再进步的。只要你有心，去努力，我相信有一天大家都能看得到你的付出，至于现在每天在网上整天diss这个diss那个的那些人，他们每天做成什么样还不知道呢，干嘛还质疑别人呢。我相信我们所有的青年演员，以后有这个实力，今后成为中国电影人、电视剧人的中坚力量。

腾讯娱乐：这段话说得真有一个样柱的使命感啊。

关晓彤：我刚说完都觉得自己特别有使命感哈哈。我就想代表，也不能说代表吧。我就是想替我们青年演员们说一句话，我们都在努力进步的，可能大家看不到但是我们确实一直在努力的。如果非得天天质疑的话，还是先看看自己吧！
