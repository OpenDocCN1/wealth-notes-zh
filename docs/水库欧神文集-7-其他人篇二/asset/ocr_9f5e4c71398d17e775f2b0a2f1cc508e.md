# 印巴分治后遗症

1947年印巴分治，孟加拉成为这场“南亚大分家”的前线。真纳领导的印度穆斯林联盟（穆盟），其政治目标是在全印建立统一的穆斯林国家：巴基斯坦。这个将成立的国家名字，由几个穆斯林邦首字母组成——然而都在西北地区，人口众多但面积狭小的孟加拉邦，并不占主要地位。这为将来孟加拉的地区埋下了伏笔。

印巴分治是史上最剧烈的国土割裂行为，而国土划分最焦点的地区，分别是旁遮普邦和孟加拉邦。这两处都是穆斯林聚集区，数量占略多（穆斯林在旁遮普的占比为57%，在孟加拉为54%），然而这两地却是印度“精华”之所在。旁遮普邦是印度的粮仓，孟加拉有黄麻和加尔各答。尼赫鲁怎么可能把这两地完全拱手让出呢？最终划发方案出台，两地都被一分为二，两国各领一半。
