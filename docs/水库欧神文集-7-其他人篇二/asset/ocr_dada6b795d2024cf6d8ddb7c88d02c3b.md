# 江湖卖艺三不朽 #X70

一）云卖艺

好像很久以前就有一种说法，网络主播做的其实是云卖艺的行当。
但卖艺的方式，其实远远不止于此。
连阔如写《江湖丛谈》，开篇就说：

江湖上有卖刀剪梳篦的，卖面药膏的，虫子药牙疼药眼药的，打把势卖艺的，说评书唱声的。

但我怎么看，这江湖过了一百年，分明还是那个老样子嘛。

所谓卖刀剪梳篦，无非生活用品。
如今女孩子要出去逛街吃下午茶了，也要点开几个美妆博主种草个粉底，顺便听家居生活号的话，买罐香薰蜡烛回家。

香面药膏虫子药牙疼药，都可划入排忧解难范畴。
特别是人的钱一多，就要投资理财，不然眼看着仓库里金币银锭蒙尘，晚上就要像牙疼刀伤般睡不着觉，觉得浪费了时间，错过了财富。
于是股市点金，房产囤砖，各路招数令人心头发痒，总想要试一试的嘛。
这药用到创伤伤口上，说不定就伤痛立消，平复如初了呢？
