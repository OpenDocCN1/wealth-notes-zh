# 2）造神秘决

想要成为一名“寿司之神”，重要的根本就不是做出最好吃的寿司。

世界上，根本就没有所谓“最好吃的寿司”。

海货这种东西，贵在鲜活甜美。只要用料足够新鲜，烹饪又不太过分，都能做到好吃。

给章鱼按摩，令肉质更松软，也许是合理的做法。

但说整个市场只有一条能用的鲈鱼，说是夸大其词，已经是客气的评价了。

更重要的是，人的口味，本就各不相同。

米饭的软硬干湿，鱼肉肥瘦熟度，都是见仁见智的事情。也许二郎认为的完美，样样不合你的口味。

世界上，根本就没有所谓“最好吃的寿司”。

通观全片，寿司之神、大米之神、鲈鱼之神、厚蛋烧之神、烤海苔之神们只做了一件事情：

在各种莫名其妙地方讲究莫名其妙的细节，树立莫名其妙的规矩，并营造出一种“我最内行最专业”的气氛。

店铺内一定要只容得下十个人，没有饮料没有小菜。

不能点单，预约要至少一个月后。
