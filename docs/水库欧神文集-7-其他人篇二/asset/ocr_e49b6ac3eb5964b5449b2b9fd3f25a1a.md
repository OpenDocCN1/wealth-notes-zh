# 二、宗师之境

在《庆余年》小说中，叶轻眉没有从神庙来到这个世界上之前，没有大宗师。\n叶轻眉将神庙的秘籍，其实就是几个方向的研究成果带到这个世界后，就出现了大宗师。

粗看之下，好像大宗师的出现和叶轻眉带出来的神庙的秘籍有关。

但是小说里面，大宗师顾颉说，他能成为大宗师和剑决无关，不是靠这些东西，是靠自己悟出来的。

这个事情我们看看主角的经历就知道了。\n叶轻眉给自己的儿子留下了上下两本无名功诀。\n还有人告诉他，这个霸道真气，以前有一个人练成过。

以前是谁练成了呢？\n就是皇宫里面的神秘人。

四顾剑几次入宫行刺庆国的皇帝，都铩羽而归，皇宫里面的真气太强。
