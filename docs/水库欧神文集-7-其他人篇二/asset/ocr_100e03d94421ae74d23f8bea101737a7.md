# 二）低美感社会

中文互联网世界一根筋的思路，实际上一以贯之，隐现在各个生活层面。如果不是广泛覆盖，就不能说是普遍真理。t-1 一定是越简洁普适越对的。

比如前几天，我吐槽一张杂志的封面“低美感社会”。

有朋友拍了部分内页照片给我。

![](bbox=[0.21, 0.19, 0.79, 0.72])

照顾版权，照片不放。

就我看到的照片来说，里面大致是狠狠吐槽网红脸、穿人字拖踩五星级酒店地毯、裸女和土味神仙雕像、奇葩丑建筑沈阳方圆大厦。

最后正义高喊：“人民需要首席审美官”。

看得我一阵一阵头皮发麻。

别的不说，小编行文已经完全失去去气神闲，有种尖酸气急败坏感了。

比如“踩着人字拖忘情踩踏五星级酒店的高级地毯”
