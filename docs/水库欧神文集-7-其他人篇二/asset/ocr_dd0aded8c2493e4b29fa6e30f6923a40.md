# 2

比尔·盖茨经常来中国参加活动。我在媒体行业工作时，曾两次近距离面对盖茨（很遗憾，唯一的采访机会由同事完成）。面对这位地球上的最杰出的企业家。心怀敬仰的同时，不免还是有些遗憾。因为他这两次谈话的观点，我都不赞成。

一次是他对机器人时代的到来感到忧虑。盖茨认为：机器人会抢工人的饭碗，造成大量失业。当时我心里说：“按照这说法，盖茨先生不就造成人类历史上最大失业潮？多少传统文书、会计、画图纸的，不都是被计算机时代消灭？他每天都活在内疚中吗？”

盖茨自己大概是想明白的：计算机创造的就业，远多过消灭的就业。生产在发展，技术在进步，就业有什么可担心呢？计算机如此，机器人也一样，何必杞人忧天。想到这里，我不免一笑。没过多久，又传出比尔·盖茨主张“对机器人征税”的说法。首富沦为笑柄，让人一叹。由于是众所周知的谬见，我就没写文章评论。
