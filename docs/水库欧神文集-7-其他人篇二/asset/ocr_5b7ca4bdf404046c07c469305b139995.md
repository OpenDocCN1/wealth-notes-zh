# 三、财富的主人

事实上，财富是一个动态的概念。
财富非常严苛的挑选它的主人。

财富实际上相当于一个水池，有水流进来，有水流出出去。
你要一直保持流入的水量大于流出的数量，而且要高出一定的比例。
你还要有合适的水池来装水，否则水会在不知不觉中渗漏出去。

比如说，100万，这个水池就好找，1000万，也还可以，1个亿的水池就不容易找了。

网上有个段子，就是讲暴富之后的：
你是暴富了呀，可是你也失去了一样宝贵的东西，那就是烦恼。

完全不是这样的。
既然要维护这个财富的水池，一个富人是不能停的。

我们一个个例子递进，先从我们熟悉的开始。

我们很多人都有20万，光看这个数字是没有任何感觉的。
那么如果我们将这20万换成物品呢？
比如说，你拿这20万买100部手机。
这个时候，感觉就完全不一样了。

100部手机，那是什么概念，那是密密麻麻的。
如果你是手工来做的活，每台手机你装应用，装SIM卡，关键是坏了你还得修。
维护这100部手机，就够让人受的了的。

如果，我们说，那你这100手机，要保持不贬值。
