# 资源是逐级解锁的。

当然， 长的丑的，五音不全的，就别去做直播了，搞直播只能来“左手画个龙”， 除非是 可以搞出别的创新。

但是每个人都是自己的资源，比如各种兴趣爱好 。

在做 的过程中，不懂就问，慢慢就成半个专家了。

这不就变成资源了吗？

那么如何开始呢？

最好是从 文字 自媒体开始。

从自媒体开始，并不是说一直做自媒体 ，做自媒体就是先打个基础。

将来自媒体做的不错，可以转型到其它领域。

因为做自媒体有几个好处 ：

+   - 培养网感，了解用户需求，提升运营能力。
- 积累资源，扩大人脉
- 获得影响力。

最开始不要想着赚钱，而完全是凭兴趣，由兴趣到副业，再由副业到主业。

在长期积累资源后，可能来一个风口，你就起飞了。

今天 带大家鸟瞰一下这个流派 ，其它的以后再讲。
