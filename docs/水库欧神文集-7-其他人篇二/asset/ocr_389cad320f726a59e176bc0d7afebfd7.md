# 找工作时单位普遍要求 35 岁以下，那 35 岁以上的人都干嘛去了？

别笑，我一邻居45岁，以前在电厂给董事长开车，老领导退休，新领导找借口打发了他，他在家靠老婆养着，缺钱了就去干几天代驾。平时就接送老婆孩子。

我辞职一年了，在家种花种菜养猫狗，靠老公活着。

钱不够花，只好想办法挣钱，公司不要我这种专业知识尚可，但心眼太多的上年纪的人，怕不好管理，我又没背景当公司的吉祥物，只能自己想办法自己干了。

以上都是实话。
