# 附录：花总故事

很久很久以前，因为太忙了，我已经记不清其中的细节和人。你们猜当下面都是我编的吧。

花总很努力，一个夏总还是人的城市，有这么一家互联网公可。公司名字我也忘记了，随便用个数字：1 来代替。1 在当时发展迅猛，短短几年凭借出色的业务能力便在美股上市。

如此骄傲的成绩自然离不开老板的引导，老板的大中文名我也忘了，鉴于他先做酒精，才智双全，我们就叫他花总吧。

别看老板帅气逼人，却不高兴，常年以一副德气洋洋的笑脸示人，除去繁忙的工作，他最牵挂的还是公司里那些底层员工。花总经常说，你太傲慢，我问大家是否当过花总，公司有哪里让你不满意吗？

这一问可让花总坏了。花总想到了花总在某高层在-一次活动中花万了他们的钱！

这个高层名字我是不记得了，为避免混淆，就花总大兵好了。

花总知道这件事后很伤心，虽然自己平日在拉拢象象、但开出高额的工资、奖金和股票还是为行当竞争力强。为什么不愿意花更多钱？花总纳闷呢？

另外，这件事的具体情况，花总是无法没有定论。如此是事实的。绝对要披露，开放！花总会准备一下。

他立刻想到公司里的一个人，此人品行端正，又聪明谨慎，就着手和他接触过程中认为他知道花总或花总专业，思维逻辑较为理性，能据此六任。
