### 一、承担风险

回顾一下，上一篇《财富的进化天阶》，我们讲的其实就是两个字：限制。

你都搞不清楚限制是什么，又何谈去解开限制呢？

大家都知道，老板肯定是比他的员工拿得多的。

有人就讲了，你这是瞎说，有人打工做到打工皇帝，比绝大部分老板赚得都多。

那么请问，打工皇帝是为谁打工呢？

打工皇帝能力未必比老板差。

孙悟空把活都干了，唐僧啥也不管。

诸葛亮把活都干了，刘禅啥也不管。

那么老板为什么比打工皇帝拿得多，凭什么，为什么？

从打工皇帝进化成老板，到底是什么限制？

一个非常通行的说法就是：**老板承担风险，打工的不承担风险**。

这个说法过于简略，以至于让人迷惑不解。

什么叫承担风险？

有人就说，你们搞房子，也没看见房东跌死，你们承担了什么风险？

一个大公司，运行得好好的，老板日常事情都不管，就是决策决策。

这些决策方案，也是下面高管报上去的。

老板就是做个选择题，在各种方案中选一个。

选择题难不会做？

老板到底承担了什么风险？

### 二、外部压力决定生存技能

这个情况，在自媒体这个行业尤其明显。

大家知道，做个自媒体，门槛是非常低的。

谁都可以注册一个账号，然后就开始写稿就行了。

所以，总有人觉得自己也能做。

我有个朋友就是做这个的，手上有各种奇奇怪怪的账号。

他手下有个聪明能干的小伙，带着2人，从零做起了一个账号，开始赚钱了。

然后小伙就找我朋友说：

这个账号，从文案策划，短视频拍摄剪辑，运营推广，都是我们做的。

所有的技能我们全部都会，公司几乎没有管过什么。

那么能不能把这个账号卖给我，我带着这2人做。

我朋友笑眯眯的说：

要买呢，你们肯定是买不起的，要不这样，这个号就租给你们做。

我呢，也不发工资，啥也不管，你们就交点分成给我就行了。

过了几个月，小伙跑回来了，做不下去了，要回公司。

我朋友就问，怎么啦？不赚钱？

小伙就说了，不是不赚钱，是整天担惊受怕啊。

细说下来是这样的。

以前很多事情都不用想，反正干活就是了，旱涝保收。

每个题材，以前是选好，上级批准一下就行了。

要是真做砸了，最多公司批评、罚款，不担心做不下去。

现在每天睁开眼就是赔单。

每次都要担心这个题材会不会火，会不会被封。

一旦搞砸了，还要给客户赔钱。

万一账号挂了，先别说自己，跟着自己吃饭的兄弟怎么办？

所以，还要面对未知的恐惧。

关键的是，自己是最后兜底的人，后面退无可退。

没有上级汇报，没有任何人可以商量。

连泡个温泉，都想着这些事情，每天焦虑不堪。

女朋友觉得自己像变了一个人一样，脾气暴躁。

想来想去，这是何必呢？还是回来干最划算。

这件事情一过，我那朋友公司的其它小组，都老实了。

我就问那朋友，万一那小伙自己做起来了呢？不是军心动摇？

我那朋友说：这就是我能做老板的原因，能判断这种风险啊。

这么多公司都有做自媒体的部门，有几个里面的员工出来做成了咪蒙？

老板的专业是：**做正确的事，并且承担风险和后果**。

员工的专业是：正确做事，不承担风险和后果。

这就是两个完全不同的工种。

有句话叫做：

**不要用自己的业余去挑战别人吃饭的专业**。

别人都拿这个吃饭了，这种专业程度必定是无可匹敌的。

什么样的外部温度就会孵出一个什么蛋。

有什么样的外部压力，就会演化出什么样的技能。

每个人精力都是有限的，在不同的环境下就演化出不同的长板。

蝙蝠长期生活在傍晚、洞穴这种暗黑环境，就进化出“回声定位”，眼睛退化。

老鹰长期生活在高空，就进化出锐利的眼睛，没有“回声定位”功能。

老板就是演化出判断风险，承担风险这种技能的物种。

员工就是演化出把事情做好这种技能的物种。

长期下来，员工做老板很难，老板做回员工也很难。

公司垮了，员工可以换个地方打工，老板却没有地方可去。

### 三、中产无法感受外部压力

中产最大的问题就是无法感受外部压力。

无法感受外部压力，就不会进化出相应的技能。

在一个大企业，分工是非常细的。

市场外部的信息被层层打开，可以尽情的享用。

经过层层过滤，每个人得到的都是一点点信息。

甚至这个信息根本上就是错误的。

![](img/ef1c5244d092b8b29b53a68870574480_977_0.png)

![](img/ef1c5244d092b8b29b53a68870574480_977_1.png)

你就算是到了很高的职位，你对市场依然是不了解的。

你就算是技能非常全面，也没有任何环境让你接触到做老板的条件。

你的进化方向，是企业的岗位职责决定了。

你就是不停的强化岗位职责，搞人际关系，你才能活下去，进入下一关。

《列兵和你座》，你的目标是下一个更高的职位，一个完全不同的岗位职责。

力量来自于谁，你就为谁负责，谁就会优化你。

你的力量来自于上级，你就按照上级的要求进化，否则你活不下去。

长此以往，你发展出来的技能就是一堆职场技能。

离开职场这个体制，你的技能就一无是处。

能走到最高层，全权负责的人少之又少。

于是中产又找了一条路，就是各种课程。

中产特别喜欢报各种课程，似乎学了课程就能发财了。

如果你想通过各种课程学会，那是不可能的。

你要学会跨栏，那得自己去找栏。

刘翔的教练是擅长教跨栏，而不是擅长跨栏。

很多教金融课程的是擅长教金融，而不是擅长金融。

这根本就是完全两个不同的工种。

同时会这两种技能的人是非常非常少的。

最最关键的是，你打工，你有退路，你就不会全力以赴。市场上高手如云，都是全力以赴的。你不全力以赴，你就不可能长出你的长板，杀出重围。

所以，你永远无法进化成一个老板，除非你亲自去做。

### 一、硬币的正反面

内部我们调侃 yevon_ou，都这么长时间了，怎么还不长记性呢？

自媒体规律：

- **功能性命能看懂的，10W+。**
- **小学生能看懂的，5W+。**
- **初中生能看懂的，3W+。**
- **高中生能看懂的，非常干，要么就是沉淀，要么就是辱骂举报。**
- **大学生能看懂的，你咋不去写论文呢？**

你说，你怎么能提“熵”这个概念呢？

这是初中水平才能看懂嘛，幸好没提“耗散结构”。

水库粉丝还算水平高的。

全网的情况更加堪忧，有些财经号阅读量很大，其实就是一个财经口水娱乐圈。

重点是娱乐爽文，阅读量当然高了。

真不是我非要和一些本科生说成是小学生，现实就是这种情况。

本来上学就没学多少东西，还是错的。

等到不需要上学了，第一件事情就是忘掉这些痛苦的回忆。

**30 岁之后个个原形毕露：十年寒窗，一夜忘光。**

大部分行业也不需要任何本科知识。

比如说你要做一个码农，只要初中水平就行了，除非是非常特别的算法岗位。

那为啥知名互联网公司还要招本科及以上呢？

当然，要想发财，那就是另外一个话题了。

关于这个话题，网上讨论来讨论去，总结出一个稳定性和可能性的规律。

什么意思呢？

你十年寒窗苦读，选择了一个稳定的工作，比如体制内、大公司。

那么这种选择有足够的稳定性，但是缺少发财的可能性。

但是如果你选择小公司或者白手起家创业，需要冒险，有发财的可能性，但是失败的概率其实更大。

你看到的那些发财的，其实是小概率事件，大部分人都失败了。

那么，一个年轻人该如何寻求突破？

我的看法，当然与这些看法很不同。

稳定性和可能性其实是一回事，是一枚硬币的正反面。

稳定性不就是可能性的一种特殊状态嘛？

就是变化的可能性空间比较小。

- 即使外部发生很大的变化，系统也不会偏离稳态结构。
- 因为无论是朝哪个方向变化，可能性都非常小。

比如，外面风口一个接一个，你还在做那份996的工作。

对于生存来说，稳态结构当然是更有利的。

任何已经活下来的生物，其结构必然是稳态的，否则早就被消灭了。

大部分“人”都选择了稳定的工作，这不是没有道理的。

财迷要发财的话，就不能太稳定，需要一些可能性。

那么这两者之间如何平衡呢？

既然我们知道两者是一枚硬币的正反面，那就真的有办法。

### 二、相邻可能空间

可能性面临的最大的问题，就是有很大的概率踩到坑。

我们以一个扫雷游戏来说明如何处理这种情况。

![](img/ef1c5244d092b8b29b53a68870574480_983_0.png)

可见，这中间有三个区域。

第一个区域，是已经探明的部分。

这个部分，就相当于一个稳定工作，没有什么大坑，但是你也发不了财。

第二个区域，是没有探明的部分。

这个部分，就相当于一些人创业，上去点一把，可能点出一大片，但是更大的概率是踩雷。

你不信试试。

第三个区域，则是这两个区域“相邻”的部分。

这个部分就比较有意思了。

这个部分的特点是可以透过“已知来推断未知”。

周边的那些数字，就是告诉你有哪些是雷，有哪些不是雷。

有一些部分还是要靠运气，但是有很大的部分都是可以推断出来。

这中间还有很多定式技巧，比如121之类。

正常的扫雷，也是这么玩的，因为这可以极大的降低你踩坑的概率。

这个做法叫做“相邻可能空间”（adjacent possible）。

你获得的任何可能性，大概率是从和你相邻的空间得到的。

你相邻的资源，决定了你的未来。

“相邻可能”就是未来的影子。

在现实中，不是扫雷，不会踩到一个坑就会死，可能会有损失。

只要不死，所以这种方法就非常有效。

以地产为例。

大城市的市区对应的就是那个已经探明的区域。

周边没有空地，太稳定了，就丧失了可能性。

你要买市区的房子，只能说淘淘笋盘，抓到一大片机会的概率比较小。

新区呢，新区就是落到那个未探明的区域，可能性太多了。

你很难判断它能不能搞起来。

周边的空地实在是太多，需要投入的资源太多了。

每一任领导一个想法，想法一变，又耽误好久。

如果新区离原来的老城比较远的话，很难利用老城市的资源。

新区一开始啥也没有，人口不会向那个方向去，几乎很难搞起来。

这些新区，我就不点名了。

我们常常说地铁终点站附近机会比较大。

这个区域就是典型的“相邻可能空间”。

不是所有地铁终点站附近都能搞起来的。

首先，你要明确城市的发展方向。

如果，城市的发展方向和终点站完全相反，那机会就不大。

这种地铁终点站完全是为了通勤的，没太大的意义。

有潜力的地铁终点站一定是要很方便的通过市区的，这样市区人口才可能过来。

其次，地铁终点站附近是不是已经有了一个区域中心。

因为有了一个区域中心，这个区才会重点发展这些区域。

这样外来人口才会因为这些比较好的就业、教育资源涌过来。

所以，最后你还要看看外来人口涌入的入口是否存在。

一旦城郊变成市区，那个升值就不是一点半点的。

当然，这只是一个例子，你可以用这种方法找到别的潜力区域。

硅谷的生长，也符合相邻可能的理念。

### 三、人生的亚稳态

说到硅谷，我们讲一个 IT 行业的例子，说明一下什么状态是最佳的。

因为 IT 行业演化比较快，可以在很短的时间内看到决策是不是有效的。

大家都知道安卓吧。

这个上面最早采用的开发语言是 Java。

这个 Java 的版权，属于 Oracle 公司。

谷歌在明知可能有版权风险的情况下，采用了 Java。

后来安卓做成了，Oracle 公司就把谷歌给告了。

庭审的时候，当初作出这个决定的安卓架构师有段话特别有意思。

他说他为什么要做这个决定？

因为在当时的情况下，没有别的选择。

原因很简单。

因为产品要抢占先机，你不可能重新搞一个开发语言。

你平台是新的，语言也是新的，鬼知道你是谁啊。

没有开发者愿意去开发的。

你只能选择一个已经存在的最广泛的编程语言，才能把开发者吸引到这个平台。

这就是典型的新平台+老生态的组合，是一种“亚稳态”。

这个在 IT 行业，并不是新鲜事。

在以淘宝为例，最开始的淘宝并不是阿里的人自己写的。

他们的选择是先买了一个老外的软件，尽管这个软件很垃圾。

为什么要这么做？

并不是阿里的人写不出来。

而是从 0 到 1 的探索，要踩的坑实在是太多了，花费的时间太长了。

你是来赚钱的，又不是来搞研究的。

既然市场上已经了有类似的软件，何必再重新造轮子呢。

有了一个软件，在这个基础上做新的需求，就容易多了，那怕是个垃圾。

这个软件在淘宝平台的开发中，逐步被替换掉了。

这个软件就是一个“脚手架”。

这样的例子还有很多人，比如说微软起家的 dos 系统，最早也是买的。

所以说，白手起家，最大的坑就是“白手起家”这四个字。

东南亚的富豪，没有一个白手起家的。

白手起家，你面临的可能性空间太大了，踩到雷的概率极高。

我的建议是尽量避免从 0 到 1 这种事情。

最开始，一定是利用已有资源，在边界部分寻求突破。

我们应该将自己的人生有意识维持在一种“亚稳定状态”。

亚稳定状态=一个稳定的核+相邻可能空间。

比如说，家里有人有一份稳定工作，另外一个人就去找一些可能性的机会（牛魔王专业推荐副业）

比如搞搞房子之类的。

稳定态到升级成一个更高级的稳定态很难，但是亚稳定态机会就比较大一些。

因为亚稳态是进入下一个相邻可能空间的必要状态。

我们都是在尽可能扩大自己的相邻可能空间。

如果你盘算了一下周边的资源，空间比较小的话，那就要换换地方了。

否则，你的未来基本上都是可以看得见的。

### 四、近代西方崛起的根源

相邻可能空间是模式升级的一种重要手段。

因为相邻可能空间连接着另外一个相邻可能空间。

- 很多人说古代中国是“内卷化”，其实西欧一样是“内卷化”。
- 西方解决“内卷化”靠的是地理大发现，而不是工业革命。

这是一个典型的相邻可能的例子。

不要看后面什么哥伦布发现美洲，麦哲伦环球航行。

其实最开始，就是 1415 年，葡萄牙的亨利王子跟随父亲在一天之内攻占了北非的城市休达。

![](img/ef1c5244d092b8b29b53a68870574480_987_0.png)

那个红色的点就是休达自由港，就是那个“核”。

当时的背景是这样的，慕斯林非常强大，向西欧扩张。

西欧则穷的一塌糊涂，内卷化死锁，无法升级成更高的模式。

从经济角度看，十字军（1096 年-1291 年）是一种试图打破内卷化的努力。

十字军虽然在那耶撤冷建立了很多公国，最后都失败了。
