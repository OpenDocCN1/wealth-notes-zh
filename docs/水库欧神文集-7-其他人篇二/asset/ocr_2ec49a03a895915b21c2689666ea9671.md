# 一座鼠患严重的城市

美国总统特朗普的推特素来火爆。前段时间他和众院民主党人卡明斯发生口角，引发了一场“地域冲突”。卡明斯是众议院监督委员会主席，长期以来，他一直批评特朗普的边境建墙政策。7月，此人竟宣称特朗普女儿伊万卡、女婿库什纳有不法行为，要发起调查，这一举动彻底惹怒总统，于是推特上连骂数天。

特朗普称：美国边境墙工程虽然拥挤，那也是干净高效、管理良好。而卡明斯所属的巴尔的摩选区，是一个“令人作呕，老鼠横行的地方，整个美国没有比这里更加糟糕。正常人都不會选择住在这种鬼地方”。

总统大开“地图炮”，许多人纷纷中枪，其中就包括民主党领袖佩洛西（她就是巴尔的摩人）。更重要的是，巴尔的摩是一座以黑人为主体的城市，虽然特朗普什么也没说，几乎所有人都指责他“种族歧视”。前总统奥巴马和夫人就在第一时间抗议。《巴尔的摩太阳报》为此写了一篇社论，大骂特朗普，说“宁有几只老鼠，也别当一只大的”。为了回骂总统，居然把老鼠的事情接了下来。
