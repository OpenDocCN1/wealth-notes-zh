# 你的妈妈老泪纵横：儿啊，好好的大公司不干，去弄什么房子啊。

老父亲几个月不和你说话，和你冷战。

我不是劝你辞职，而是心态。

所谓，从A8.2到A8.5，关键的不是什么技能。

刘若英告诉你秘诀：**想要问问你敢不敢？**

你要有种“退无可退”的心态，以搞房子生活的心态，不赚钱就去死的心态。那个时候，你自然不再矫情，老实妥妥盘，做好每一笔贷款。人自然变得非常的谦卑，如履薄冰。

**强大的压力之下，各种技能自然就进化出来，变成了长板。**

只是以搞房子举例，所有的老板都是这样的。

# 四、结语

如何跨越财富的进化天梯？
一种情况是上面有人拉你，但是这种情况很少。
第二种方法当然是学会感受外部真实的压力，学会承担风险。
长期压力之下，化蛹成蝶，进化出翅膀，飞过去。

你看着老板好像没做什么，没承担什么风险。
不过是别人每次都选对了而已。
能选对，本身就是一个非常非常稀缺的技能。
所有的成功都是迫不得已，无路可走。
