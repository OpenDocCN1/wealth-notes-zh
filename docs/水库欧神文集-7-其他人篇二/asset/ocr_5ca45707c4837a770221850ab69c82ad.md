# 2）子路侵官

春秋之时，季孙做鲁国的相国，子路做郓邑的长官。
季孙要求民众，五个月之内挖一条长沟。子路欲行仁道，于是拿出自己的俸米来，做成粥饭，邀请挖沟的人到路边来吃。

孔子听到这件事情，便派子贡赶到现场。
但子贡此来，并不是为表彰子路。
而是当场倒掉了粥饭，砸毁了锅碗，质问子路：“拥有民众的人是鲁国的君主，你干吗要给这些人饭吃？！

子路的脾气，向来是急躁的。闻听此言，非常恼火，问孔子道：

“我跟从老师你，所学的就是仁义。仁义，不就是与天下人分享自己拥有的东西。”
“现在我自己的俸禄，分给大家吃，有什么不可以。老师你根本就是妒我我行仁义！”

谁知孔子听了也大怒：

“什么是礼玩，礼玩是BOSS爱天下一切，诸侯爱自已境内的人民，大夫爱职权能覆盖的范围，士人爱自已的家人。”
“过了你应当负责的部分，就叫‘侵’。”
“你给人吃饭，就是爱人。鲁国的人，自有鲁国的国君去爱。你却替国君去爱人，这就是‘侵’！”
