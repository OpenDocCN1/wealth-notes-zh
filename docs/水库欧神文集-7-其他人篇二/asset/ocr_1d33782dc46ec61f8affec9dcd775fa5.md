# 一）白鸟

如果把知乎当成故事会，它是很好的本消遣杂志。

有人讲了日本“白鸟由荣”的故事，号称20世纪最传奇的越狱囚犯。

白鸟由荣是一个窃贼，某次入室盗窃过程中，因为发生争执，而杀害了房主。白鸟自首入狱。

当时日本的监狱，对犯人还不甚人性化，打骂吐痰都是常事。

白鸟是杀人犯，看守的脸色自然不会很好看。冬天想要一床御寒的棉被，也耍不到。后期更是被戴上二十斤重的手铐脚镣，24小时全程监视。

于是白鸟一不高兴，就越狱。铜墙铁壁，也逃得出来。
