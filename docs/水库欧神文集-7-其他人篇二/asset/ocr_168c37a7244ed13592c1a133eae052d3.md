# 谁在保护女性，谁在伤害女性#W26

先从最近滴滴重启顺风车引起的风波聊起。

前两天滴滴顺风车重启运行，规定男性夜间打车为 23 点前，女性是夜间 20 点前。规定一出台，跟炸了女权主义窝一样，“歧视女性”的说法在微博漫天飞。这种指控当然很无稽。

滴滴是一家商业公司，面向整个市场赚钱，有什么必要故意得罪女性群体呢？说起来，滴滴用户的女性群体比例一直都是略高于男性。

这家公司的总裁柳青本身是杰出事业女性的代表，她有什么理由出台歧视女性的政策？

答案显而易见，甚至可以说，所有人都很清楚：为了安全。

此前顺风车下线是因为女乘客遇害，滴滴遭受了极大的安全压力。当时这家公司处于生死边缘，断臂求生，一举将顺风车停掉。但顺风车需求如此巨大，对滴滴的出行体系如此重要，恢复上线是迟早的事情——此举也有利于民。经过一年多调整，这才重新上线。

滴滴上线后，想要最大限度地确保安全，只能在危险系数最高的地方下功夫。以最小影响的措施，最大程度提高安全性。

滴滴的做法是：女性用户在晚上 8 点之后，就别再乘顺风车。当然，还有其他的选择：可以乘坐出租车、快车、礼橙专车、豪华车...
