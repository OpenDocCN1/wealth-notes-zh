# 二

原始社会，人们当天采摘的果实、狩猎的动物，数量可怜，基本上要全部用来满足当前消费，如此，基本上没有时间、精力去发明、制造、提升迂回生产的工具。

今天运气好，多采摘了十几个野果、多追到一只山鸡，明天可以不去打猎了，终于有了一点时间来制作工具。这点时间来之不易。没有更多闲暇，谁会去观察矿石，琢磨金属工具？
