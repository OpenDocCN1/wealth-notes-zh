# 2） 公平

知乎 er 最喜欢讲的，是“富人阶层垄断教育资源”。

减负都是骗人的。

当学校无法提供廉价达标的教育资源，高考的目标却没有变，负担便转移给家长。

只有有经济条件的人，才上得起私立学校，供得起名师补习班，顺利升入名牌小学，初中，高中，掌握伪楚与南宋之间的区别。

像是玩一场“是男人就下 100 层”的游戏，层层跳跃，最终跳龙门成功。

其他人的孩子，便只好沦为平庸，吞下固化的苦果。

而这是不公平的。
