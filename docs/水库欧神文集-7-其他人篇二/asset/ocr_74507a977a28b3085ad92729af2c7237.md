反正外行人刘润听了，一样会拍手叫绝，赞叹“专业的力量”。

![](bbox=[0.09, 0.1, 0.65, 0.33])

这个现象，在香水营销界表现得淋漓尽致。
皂香花果美食调甘苦调，本来就那么几个明显的香型分类。
但是有一种职业叫“香评人”。他们的日常工作是买来大堆香水，细细试闻之后，微博上写一篇又一篇“香评小作文”。
这种“小作文”的特点是，运用了大量的比喻，文笔优美，描摹出美好的画巷。

> “仿佛轻轻洒落一阵雨滴，然后散发出泥土的芳香。这时水生莲花的主调慢慢进入，在黑夜里散发幽幽的白光，却没有属于花朵的甜腻，而只有一丝清冷的手指。”

# 孤儿怨

虽然寺庙洗礼，但我终究还是回到灰暗的屋子，推门而入
尘埃在阳光下斑驳零散，轻颤得犹如一丝游魂，壁画的木
框散发淡淡古老的香味，我取下了壁画燃烧，看着它烧成
灰烬，我倒头睡在陈旧的床上，闻着潮湿的枕头，不知时
光

+   - 前调：焚香、麝香
- 中调：檀香木、薄荷乳香
- 后调：柠檬

点评：孤冷潮湿的味道，很冷冽孤单，用森林深处的房
子，摇摇欲坠的木楼梯，潮湿久无人用的枕头形容不过
分，需要细细品味，但是有一种越闻越沉浸其中的感觉，
很上瘾，合适一个人

不推荐盲撸，不是大众香调，不适合活泼果香少女

你虽然完全不知道在描写什么样的香气，也不觉得“掺了泥土的雨后台气”和“普通的雨后
香气”有什么区别，却被带着进入了“解读的空间”，真的觉得这香气非常高级优雅。
哪怕实物闻起来无比难闻，你都不会觉得这是香水品牌的骗局，而只会觉得自己不懂欣赏，
品味已经被那些太过谄媚的商业香驯化了。
