# 关于声援华为的通知

集团全体員工和合作伙伴：

+   即日起，集团发布如下规定，以表示对华为的支持：
1. 公司所有相关产品设计，优先使用华为海思的芯片方案。
2. 员工个人购买华为和中兴手机，公司给予市场价格的10%的补贴。
3. 员工购买苹果手机，按照市场价格，公司给予100%的处罚。
4. 公司办公电脑等设备，停止采购美国品牌。
5. 公司及员工购车，停止采购美国品牌。
6. 公司员工取得出口美国的订单，给予双倍提成奖励。
7. 代理商取得出口美国订单，给予双倍返利奖励。

以上规定，为期三年，特此通知！

梦派科技集团有限公司
