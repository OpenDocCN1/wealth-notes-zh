# 杨超越：我没有闪光点 但觉得自己注定不平凡

4) 木匠学

锥子脸曾经是上不得台面的。全村人围在一起看一台电视时，大家迷恋的是刘晓庆，赵薇，陈红，蒋勤勤。

大眼圆脸，樱唇甜笑，喜气洋洋。蒋勤勤太好看了，琼瑶赠名叫“水灵”。

范冰冰尖下巴，“媚气重，没福气”，演了多少丫鬟，狐狸精，小三，打工妹。

然而，后来，不知从什么时候，开始流行锥子脸、小v脸。无数女星突然被铺天盖地嘲“脸大”，“肉脸”，“不上镜”，“没下巴”。

于是人心惶惶，连老脾家暴戏美女都去削骨，整个娱乐圈的女明星，都失去了下颌角，或下巴上凭空多出两支玻尿酸，变成朱元璋。
