# “缘”是偶然，还是必然？

我曾经和一个朋友试图翻译“缘”这个字的英文，在着实下了一番力气之后我们发现，这个字实在太难翻译了。“缘”本身的含义就是矛盾的：在某种意义上，它带有命定的意思，同时又带有随机和偶然。

我有一个朋友，出于一个在我看来很不可思议的原因选定了他的结婚对象。他一直不知道和谁结婚好，在他正懊恼的时候，恰好在大街上碰到了一个以前的同学。而这个同学，他在之前的生命当中一共碰到过四次，都是在逛庙会、逛王府井商场这种极其偶然的场景下，而且俩人没有任何约定。在倍大的北京发生这样的事，他就觉得这一定是有一种命定的东西，于是就选择了跟她结婚。

# 相遇的六个偶然

昆德拉在《生命中不可承受之轻》里提到了六个偶然：男女主人公的相遇要经过六个偶然，也就是六个节点。每一個节点都存在着至少两种选择——你选择了其中一种，到了下一个节点，再选择其中一种……经过六次这样的选择，导致一个结果。这个结果一旦出现，双方都认为是命定的东西，而事实上，整个过程都是偶然的。

+   1. 女主人公特蕾莎的小镇有人得了脑膜炎，需要一位医生。如果没人得病，这个故事就不会发生。\n2. 男主人公托马斯所在的医院有一位特别擅长治这个病的医生，但这位医生那天犯了坐骨神经痛，动弹不得，就派托马斯到小镇上去治病。如果这个医生不得坐骨神经痛，这个故事也不会发生。\n3. 托马斯代替这个医生到这个小镇出诊，要找一家旅馆住宿。镇上有五家旅馆，托马斯选择了其中一个。大家可以算一下托马斯的这个选择包含着多少种可能性。\n4. 住进来之后，托马斯饿了，他可以选择去旅馆的餐厅吃饭，也可以选择去别的地方吃饭，但他选择在这个旅馆的餐厅吃饭。\n5. 这个餐厅里有很多的服务员，但是恰好是女主 人公特蕾莎给托马斯提供了服务，他们就这样认识了。\n6. 托马斯诊治完病人以后，距离火车出发的时间还有点儿长，他就在街边草地上的一个长椅上开始看书打发时间。特蕾莎的家就在这附近，恰好她在回家的路上经过长椅，他们又见面了——如果没有这次见面，这个故事也就结束了。
