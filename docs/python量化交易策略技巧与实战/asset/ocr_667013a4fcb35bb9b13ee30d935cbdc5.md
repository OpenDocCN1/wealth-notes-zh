# 4.2.3 无限循环

通过设置条件表达式永远为 True，可以实现无限循环，下面通过实例来说明。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python4-7.py”，然后输入如下代码：

```
num = 1
while num == 1:  # 表达式永远为 True
    mystr = input("请输入一个字母 :")
    print ("您输入的数字是：", mystr)
```

单击菜单栏中的“Run”→“Run Module”命令或按键盘上的“F5”键，即可运行程序代码，这时显示“请输入一个字母：”，随便输入一个字母，就会显示该字母，并继续“显示请输入一个字母：”，这个程序将这样无限循环运行下去，如图 4.7 所示。
