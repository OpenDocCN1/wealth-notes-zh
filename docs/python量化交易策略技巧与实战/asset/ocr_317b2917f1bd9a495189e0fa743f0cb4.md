第一，如果 step 参数默认，默认 1；如果 start 参数默认，默认 0。

第二，如果 step 是正整数，则最后一个元素（start + i×step）小于 stop。

第三，如果 step 是负整数，则最后一个元素（start + i×step）大于 stop。

第四，step 参数必须是non零整数，否则显示异常。

需要注意的是，range()函数返回一个左闭右开([left,right))的序列数。例如 range(4)，显示的是 0、1、2、3，没有 4； range(2,5)，显示的是 2、3、4，没有 5。

print("遍历数字序列:")

    print(a)
