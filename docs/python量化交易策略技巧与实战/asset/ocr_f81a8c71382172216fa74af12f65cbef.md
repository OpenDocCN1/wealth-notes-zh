# 2) 关键字参数

关键字参数和函数调用关系紧密，函数调用使用关键字参数来确定传入的参数值。

需要注意的是，使用关键字参数允许函数调用时参数的顺序与声明时不一致，因为 Python 解释器能够用参数名匹配参数值。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File” → “New File”命令，创建一个 Python 文件，并将其命名为“Python5-9.py”，然后输入如下代码：

```
#可写函数说明
def printinfo( name, sex,age, score):
    "打印任何传入的字符串或数值"
    print ("名字: ", name)
    print ("性别: ", sex)
    print ("年龄: ", age)
    print ("成绩: ", score)
    return
#调用 printinfo 函数
printinfo( age=18, name="张红",sex="男", score=89 )
```

单击菜单栏中的“Run” → “Run Module”命令或按键盘上的“F5”键，即可运行程序代码，结果如图 5.12 所示。

# 3） 默认参数

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File” → “New File”命令，创建一个 Python 文件，并将其命名为“Python5-10.py”，然后输入如下代码：

```
def printinfo( name,score ,age = 13 ,sex = '女' ):
```
