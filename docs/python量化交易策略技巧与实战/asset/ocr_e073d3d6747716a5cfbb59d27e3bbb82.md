```
df.iloc[行位置,列位置]
df.iloc[1,1]            #选取第二行，第二列的值，返回的为单个值
df.iloc[[0,2],:]       #选取第一行及第三行的数据
df.iloc[0:2,:]         #选取第一行到第三行(不包含)的数据
df.iloc[:,1]           #选取所有记录的第二列的值，返回的为一个Series
df.iloc[1,:]           #选取第一行数据，返回的为一个Series
```

显示第三行和第四列的值，代码如下：

```
df.iloc[2,3]
```

```
dataframe1.ix[1,1]
dataframe1.ix['a':'b']
```
