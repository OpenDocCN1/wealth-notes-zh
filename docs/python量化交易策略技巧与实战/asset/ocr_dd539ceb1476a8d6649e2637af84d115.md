# 1) 严格的纪律性

量化交易有着严格的纪律性，因为只有这样才可以克服人性的弱点，如贪婪、恐惧、侥幸心理，以及克服认知偏差。一个优秀的投资方法应该是一个“透明的盒子”，所以投资者的每一个决策都应该是有理有据的，特别是要有数据支持的。

假如有人问你，某年某月某一天你为什么购买某只股票，你就可以打开量化交易系统，系统会显示出当时被选择的这只股票与其他的股票相比在成长面、估值、资金、技术、买卖时机等方面的综合评价情况。这个评价是非常全面的，比普通投资者通过拍脑袋或者只看某一个指标确定的决策更具说服力。

# 2) 完备的系统性

完备的系统性具体表现为“三多”。首先是多层次，我们在大类资产配置、行业选择、精选个股三个层次上都有模型；其次是多角度，量化交易的核心投资思想包括宏观周期、市场结构、估值、成长、盈利质量、分析师盈利预测、市场情绪等多个角度；最后是多数据，即海量数据的处理。

人脑处理信息的能力是有限的。当资本市场只有几十只股票时，定性投资基金经理是有优势的，因为他可以深刻分析这几十家公司。但当资本市场有成千上万只股票时，强大的定量化交易的信息处理就体现出它的优势了，即它可以捕捉更多的投资机会、拓展更大的投资机会。

# 3) 妥善运用套利的思想

量化交易正是寻找估值洼地，即通过全面、系统性地扫描并捕捉错误定价、错误估值带来的机会。定性投资的大部分时间都是在琢磨哪个企业做得比较好，那只股票可以挣钱。与定性投资不同，量化交易的大部分精力花在分析哪里是估值洼地，哪只股票被低估了，然后买入被低估的股票、卖出被高估的股票。

# 4) 靠概率取胜

靠概率取胜表现在两个方面：一是定量投资不断从历史中挖掘有望在未来进行重复的规律并且加以利用，二是在实际操作股票的过程中，运用概率分析来提高买卖成功的概率和仓位控制。
