# 9.3.2 流通市值选股技巧

流通市值，是指在某特定时间内可交易的流通股股数乘以当时股价得出的流通股票总价值。在中国，上市公司的股份结构包括国有股、法人股、个人股等。

目前只有个人股可以上市流通交易。这部分流通的股份总数乘以股票市场价格，就是流通市值。

# 流通市值选股实例

成功登录 JoinQuant 聚宽量化交易平台后，单击导航栏中的“策略研究”→“研究环境”命令，打开研究环境页面。双击“量化选股”文件夹，然后单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“流通市值选股”，然后输入如下代码：

```
import pandas as pd
dataframe1 = get_fundamentals( query(valuation).filter(
valuation.circulating_market_cap > 15000
)
, date='2018-08-01')
dataframe1['code']
```

valuation 为市值数据表名；查询条件为流通市值大于 15 000 亿元；查询时间为 2018 年 8 月 1 日。单击工具栏中的 运行 按钮，运行结果如图 9.10 所示。
