# 8.2 attribute_history()函数的运用技巧

attribute_history()函数可以用来查看某一只股票的历史数据，并获取这只股票的多个属性，其语法格式如下：

```
attribute_history(security, count, unit='1d', fields=['open', 'close', 'high', 'low', 'volume', 'money'], skip_paused=True, df=True, fq='pre')
```

需要注意的是，在获取天数据时，不包括当天的數據，即使是在收盘后。还需要注意，默认值是跳过停牌日期的。

> 提醒: history()函数可以获得多只股票的信息，但只能是一个字段的信息；而 attribute_history()函数只能获得一只股票的信息，但可以是这只股票的多个属性。

attribute_history()函数也有7项参数，其中 count、unit、fields、skip_paused、df、fq 参数与 history()函数相同，这里不再赘述。而参数 security 是用来设置股票代码的。下面来看 attribute_history()函数的应用实例。

创建一个 Python 3 文件，然后输入代码如下：

```
import pandas as pd
dataframe1 = attribute_history('000009.XSHE', 3, '1d', ['open', 'close', 'high', 'low', 'avg', 'low_limit', 'factor'], True, True, 'pre')
dataframe1
```
