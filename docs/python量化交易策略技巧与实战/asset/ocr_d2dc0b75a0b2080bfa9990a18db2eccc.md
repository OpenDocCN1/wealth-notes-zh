第五，长期大通道向下，即大趋势向下，如果此时短期小道通反弹到顶部，往往会再次下跌，并且很可能是快速暴跌；如果快速下跌后，又慢慢下跌到长期大通道底部，出现底部形态，这时反弹的可能性就会大增，可以轻仓短线参与，但一旦上涨到长期大通道上沿附近，要及时卖出。

第六，长期大通道向下，而短期小通道向下穿透长期大通道，此时多为暴跌过程，有反弹可能，但下跌过程将会持续，不宜立即建仓，应慎重。待长期大通道走平且有向上趋势，短期小通道回头向上穿回时，是较好的低位仓机会。

第七，当长期大通道长期横向走平时，为盘整行情，价格沿长期大通道上下震荡，此时为调整、建仓、洗盘阶段，预示着一轮行情的出现，短线炒家可逢高抛 董，逢低买入。以短期小通道强力向上穿透长期大通道，且长期大通道向上转向，表明强劲上涨行情开始；以短期小通道向下穿透长期大通道，且长期大通道向下转向，表明下跌将会持续。
