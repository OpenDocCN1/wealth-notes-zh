# 10.3.5 WR 指标函数

WR 指标，即威廉指标。在 Python 量化交易策略中，WR 指标的语法格式如下：

```
WR(security_list, check_date, N = 10, N1 = 6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 N1 分别表示统计的天数 N 和统计的天数 N1。

返回 WR 和 MAWR 的值，返回类型与 MACD 指标相同，这里不再赘述。

WR 指标用法具体如下。

第一，WR 指标波动于 0~100，100 置于顶部，0 置于底部。

第二，WR 指标以 50 为中轴线，高于 50 为股价转强；低于 50 为股价转弱。

第三，WR 指标高于 20 后再度向下跌破 20 时，卖出；低于 80 后再度向上突破 80 时，买入。
