```
def inner():        # 自定义嵌套函数
    nonlocal num      # nonlocal 关键字声明
    print("nonlocal 关键字声明，在嵌套函数中调用 num 的值，其值为", num)
    num = 100         # 重新为 num 赋值
    print("重新为 num 赋值后，其值为", num)
inner()              # 调用嵌套函数
print("调用嵌套函数后，num 的值为", num)
outer()              # 调用自定义函数
```

在这里可以看到，首先自定义函数 outer()，然后在函数 outer()中嵌套函数 inner()。在嵌套函数 inner()中使用 nonlocal 关键字声明，这样嵌套函数内外变量 num 的值将联动更新。
