## 10.3.5 WR 指标函数

WR 指标，即威廉指标。在 Python 量化交易策略中，WR 指标的语法格式如下：

```
WR(security_list, check_date, N = 10, N1 = 6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 N1 分别表示统计的天数 N 和统计的天数 N1。

返回 WR 和 MAWR 的值，返回类型与 MACD 指标相同，这里不再赘述。

WR 指标用法具体如下。

第一，WR 指标波动于 0~100，100 置于顶部，0 置于底部。

第二，WR 指标以 50 为中轴线，高于 50 为股价转强；低于 50 为股价转弱。

第三，WR 指标高于 20 后再度向下跌破 20 时，卖出；低于 80 后再度向上突破 80 时，买入。

第四，WR 指标连续触底 3~4 次，股价向下反转机率大；连续触顶 3~4 次，股价向上反转机率大。

## 10.3.6 CCI 指标函数

```

顺势指标 CCI 用法具体如下。

## 10.4 压力支撑指标函数运用技巧

压力支撑指标的图形区，分为上限带和下限带。上限带代表压力，下限带代表支撑。其指标图形特点是股价向上触碰上限带会回档；股价向下触碰下限带会反弹；不同指标有不同含义。

## 10.4.1 BOLL 指标函数

BOLL 指标，即布林通道线指标。在 Python 量化交易策略中，BOLL 指标的语法格式如下：

```
Bollinger_Bands(security_list, check_date, timeperiod=20, nbdevup=2, nbdevdn=2)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 timeperiod、nbdevup 和 nbdevdn 分别表示统计的天数 timeperiod、统计的天数 nbdevup 和统计的天数 nbdevdn。

返回上轨线 UB、中轨线 MB、下轨线 LB 的值，返回类型与 MACD 指标相同，这里不再赘述。

BOLL 指标用法具体如下。

- 第一，股价上升穿越布林通道线上限时，回档概率大。
- 第二，股价下跌穿越布林通道线下限时，反弹概率大。
- 第三，布林通道线震动波带变窄时，表示变盘在即。

## 10.4.3 XS 指标函数

XS 指标，即薛斯通道线。在 Python 量化交易策略中，XS 指标的语法格式如下：

```
XS(security_list, check_date, timeperiod = 13)
```

各参数意义与 MACD 指标相同，这里不再赘述。

返回 SUP、SDN、LUP、LDN 的值，返回类型与 MACD 指标相同，这里不再赘述。

在薛斯通道中，股价实际上是被短期小通道包容着在长期大通道中上下运行的。其基本买卖策略是当短期小通道接近长期大通道时，预示着趋势的近期反转。在上沿接近时趋势向下反转，可捕捉短期卖点；在下沿接近时趋势向上反转，可捕捉短期买点。研究薛斯通道线可以在每一波行情中成功地逃顶捉底，寻求最大限度盈利。

XS 指标的用法具体如下。

第一，长期大通道反映该股票的长期趋势状态，趋势有一定惯性，延伸时间较长，反映股票大周期，可以把握股票整体趋势，适用于中长线投资。

第二，短期小通道反映该股票的短期走势状态，包容股票的涨跌起伏，能有效地滤除股票走势中的频繁振动，但保留了股票价格在长期大通道内的上下波动，反映股票小周期，适用于中短线炒作。

第三，长期大通道向上，即大趋势总体向上，此时短期小通道触及（或接近）长期大通道底部时，即买压增大，有反弹的可能。而短期小通道触及或接近长期大通道顶部，即卖压增大，形态出现回调或盘整，有向长期大通道靠近的趋势。如果 K 线走势与短期小通道走势亦吻合得很好，那么更为有效。

第四，长期大通道向上，而短期小通道触及长期大通道顶部，此时该股为强力拉长阶段，可适当观望，短期转平转头向下时，为较好出货点；在穿透区为风险区应注意反转信号，随时出货。

![](img/e6d4c365781f4dd8cb814bd56923b0bc_271_0.png)

第五，长期大通道向下，即大趋势向下，如果此时短期小道通反弹到顶部，往往会再次下跌，并且很可能是快速暴跌；如果快速下跌后，又慢慢下跌到长期大通道底部，出现底部形态，这时反弹的可能性就会大增，可以轻仓短线参与，但一旦上涨到长期大通道上沿附近，要及时卖出。

第六，长期大通道向下，而短期小通道向下穿透长期大通道，此时多为暴跌过程，有反弹可能，但下跌过程将会持续，不宜立即建仓，应慎重。待长期大通道走平且有向上趋势，短期小通道回头向上穿回时，是较好的低位仓机会。

第七，当长期大通道长期横向走平时，为盘整行情，价格沿长期大通道上下震荡，此时为调整、建仓、洗盘阶段，预示着一轮行情的出现，短线炒家可逢高抛，逢低买入。以短期小通道强力向上穿透长期大通道，且长期大通道向上转向，表明强劲上涨行情开始；以短期小通道向下穿透长期大通道，且长期大通道向下转向，表明下跌将会持续。

## 10.5 量价指标函数运用技巧

量价指标是将市场中公众对股票追涨的热情进行量化。股市若要形成一波多头行情，必须要有相应的活跃程度，也就是必须有一定的成交量，而这些成交量又必须要有大量散户参与，若没有散户帮助庄家接下股价上涨过程中的解套盘及获利盘，大多数庄家就不可能顺利拉高股价。而且股价拉高后若没有散户接盘，主力就无法兑现炒作利润，其炒作也就毫无意义了。

## 10.5.1 OBV 指标函数

OBV 指标，即累积能量线。在 Python 量化交易策略中，OBV 指标的语法格式如下：

```
OBV(security_list, check_date, timeperiod=30)
```

各参数意义与 MACD 指标相同，这里不再赘述。

返回 OBV 的值，是一个字典（dict）类型，与 MACD 指标相同，这里不再赘述。

OBV 指标用法具体如下：

- 第一，股价一顶比一顶高，而 OBV 一顶比一顶低时，暗示顶部即将形成。
- 第二，股价一底比一底低，而 OBV 一底比一底高时，暗示底部即将形成。
- 第三，OBV 突破其 N 字形波动高点的次数达 5 次时，为短线卖点。
- 第四，OBV 跌破其 N 字形波动低点的次数达 5 次时，为短线买点。

## 10.5.2 VOL 指标函数

```

各参数意义与 MACD 指标相同，这里不再赘述。

返回 VOL 和 MAVOL 的值，返回类型与 MACD 指标相同，这里不再赘述。

VOL 指标用法如下。

- 第四，观察成交金额的变化，比观察成交手数更具意义，因为成交手数并未反应股价涨跌之后所应支出的实际金额。
