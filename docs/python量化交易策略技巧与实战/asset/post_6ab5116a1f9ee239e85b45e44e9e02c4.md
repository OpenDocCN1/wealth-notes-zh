## 9.5.2 总资产净利率选股技巧

总资产，是指某一经济实体拥有或控制的、能够带来经济利益的全部资产。一般可以认为，某一会计主体的总资产金额等于其资产负债表的“资产总计”金额。

总资产净利率，是指公司净利润与平均资产总额的百分比，其计算公式如下：

总资产净利率=净利润÷平均资产总额×100%

其中，平均资产总额=（期初资产总额+期末资产总额）÷2。

总资产净利率反映的是公司运用全部资产来获得利润的水平，即公司每占用 1 元的资产平均能获得多少元的利润。总资产净利率越高，表明公司投入产出水平越高，资产运营越有效，成本费用的控制水平越高。

## Python 量化交易策略的技术指标函数运用技巧

技术指标通过对原始数据（开盘价、收盘价、最低价、最高价、成交量、成交金额、成交笔数）的处理，来反映市场某一方面深层的内涵，这些内涵是很难通过原始数据直接看出来的。技术指标能客观地反映某些既成事实，将某些市场的数据形象化、直观化，将某些分析理论数量化和精细化。因为技术指标可以提供具体量化条件，所以通过它可以实现量化买卖，使技术指标在量化交易中应用最为广泛。

本章主要内容包括:
- 量化择时概述
- 趋向指标函数运用技巧
- 反趋向指标函数运用技巧
- 压力支撑指标函数运用技巧
- 量价指标函数运用技巧

## 10.1 量化择时概述

量化择时，是指利用数量化的方法，通过各种技术分析的量化分析，找到自选股中股票的买点和卖点时机。在各种技术分析中，技术指标是非常重要的量化分析手段，也是最常用的量化分析工具。

目前，应用于股市的技术指标有几百种，按照不同的计算原理和反映状况，可大致分为 4 类，分别是趋势指标、反趋势指标、压力支撑指标、量价指标，如图 10.1 所示。

![](img/e6d4c365781f4dd8cb814bd56923b0bc_250_0.png)

### 1）趋势指标

趋势指标是识别和追踪有趋势的图形类指标，其特点是不试图猜顶和测底，如均线指标、MACD 指标等。

### 2）反趋势指标

反趋势指标，又称振荡指标，是识别和追踪趋势运行的转折点的图形类指标，其特点是具有强烈的捕顶和捉底的意图，对市场转折点较敏感，如随机指标 KDJ、强弱指标 RSI 等。

### 3）压力支撑指标

压力支撑指标，又称通道指标，是试图通过顶部轨道线和底部轨道线捕捉行情的顶部和底部的图形类指标，其特点是具有明显的压力线，也有明显的支撑线，如 BOLL 指标、XS 指标。

### 4）量价指标

量价指标就是通过成交量的变动情况来分析捕捉价格未来走势的图形类指标，其特点是以“成交量是市场元气”为依据，揭示成交量与价格涨跌的关系，如 OBV 指标、VOL 指标等。

## 10.2 趋向指标函数运用技巧

趋向指标是投资者最容易在市场中获利的方法，也是股票、期货、外汇市场中著名格言“让利润充分增长，限制损失”的真实反映。

### 10.2.1 MACD 指标函数

MACD 指标，即平滑异同平均线。在 Python 量化交易策略中，MACD 指标的语法格式如下：

```
MACD(security_list, check_date, SHORT = 12, LONG = 26, MID = 9)
```

各项参数意义如下。

参数 security_list：股票列表，可以是一只股票，也可以是多只股票。

参数 check_date：要查询数据的日期。

参数 SHORT：用来设置快的指数移动平均线，默认为 12 天。

参数 LONG：用来设置慢的指数移动平均线，默认为 26 天。

参数 MID：用来设置离差平均值，默认为 9 天。

返回 DIFF、DEA 和 MACD 的值，返回类型为字典（dict）：键（key）为股票代码，值（value）为数据。

MACD 指标用法具体如下：

- 第一，DIFF、DEA 均为正，DIFF 向上突破 DEA 时，为买入信号；
- 第二，DIFF、DEA 均为负，DIFF 向下跌破 DEA 时，为卖出信号；
- 第三，DEA 线与 K 线发生背离时，为行情反转信号；
- 第四，分析 MACD 柱状线，由红变绿（由正变负）时，为卖出信号；由绿变红时，为买入信号。

> 提醒：DIFF 线，是指收盘价短期、长期指数平滑移动平均线间的差；DEA 线，是指 DIFF 线的 M 日指数平滑移动平均线；MACD 线，是指 DIFF 线与 DEA 线的差，用彩色柱状线表示。

### 10.2.2 EMV 指标函数

EMV 指标，即简易波动指标。在 Python 量化交易策略中，EMV 指标的语法格式如下：

```
EMV(security_list, check_date, N = 14, M = 9)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M 分别表示统计的天数为 N 和 M。

返回 EMV 和 MAEMV 的值，返回类型与 MACD 指标相同，这里不再赘述。

EMV 指标用法具体如下：

- 第一，EMV 由下往上穿越 0 轴时，为中期买入信号；
- 第二，EMV 由上往下穿越 0 轴时，为中期卖出信号；
- 第三，EMV 的平均线穿越 0 轴，产生假信号的机会较少。

需要注意的是，须长期使用 EMV 指标才能获得最佳利润。

### 10.2.3 UOS 指标函数

UOS 指标，即终极指标。UOS 指标的语法格式如下：

```
UOS(security_list, check_date, N1 = 7, N2 = 14, N3 = 28, M = 6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N1、N2、N3 和 M 分别表示统计的天数为 N1、N2、N3 和 M。

返回终极指标和 MAUOS 的值，返回类型与 MACD 指标相同，这里不再赘述。

UOS 指标用法具体如下：

- 第一，UOS 上升至 50~70，而后向下跌破其 N 字曲线低点时，为短线卖点；
- 第二，UOS 上升至 70 及其以上，而后向下跌破 70 时，为中线卖点；
- 第三，UOS 下跌至 45 及其以下，而后向上突破其 N 字曲线高点时，为短线买点；
- 第四，UOS 下跌至 35 及其以下，产生一底比一底高的背离现象时，为底部特征。

需要注意的是，以上各项数据会因个股不同而略有不同，请投资者利用参考线自行修正。

### 10.2.4 GDX 指标函数

GDX 指标，即鬼道线。GDX 指标的语法格式如下：

```
GDX(security_list, check_date, N = 30, M = 9)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M 分别表示统计的天数为 N 和 M。

返回济安线、压力线和支撑线的值，返回类型与 MACD 指标相同，这里不再赘述。

GDX 指标，是一种用技术手段和经验判断来决定买卖股票的方法。GDX 指标对趋势线做了平滑和修正处理，更精确地反映了股价运行规律，即当股价上升到压力线时，投资者就卖出股票；当股价下跌到支撑线时，投资者就进行相应的补进。
