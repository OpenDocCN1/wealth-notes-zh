# 3.7.3 位运算

位运算符是把数字看作二进制来进行计算的，位运算符及意义如表 3.6 所示。

# 表 3.6 位运算符及意义

| 位运算符 | 意义 |
|---|---|
| & | 按位与运算符：参与运算的两个值，如果两个相应位都为 1，则该位的结果为 1，否则为 0 |
| | | 按位或运算符：只要对应的两个二进制有一个为 1，结果位就为 1 |
| ^ | 按位异或运算符：当两个对应的二进制位相异时，结果为 1 |
| ~ | 按位取反运算符：对数据的每个二进制位取反，即把 1 变为 0，把 0 变为 1 |
| << | 左移动运算符：把 “<<” 右边的运算数的各二进制全部左移若干位，由 “<<” 右边的数指定移动的位数，高位丢弃，低位补 0 |
| >> | 右移动运算符：把 “>>” 左边的运算数的各二进制全部右移若干位，由 “>>” 右边的数指定移动的位数 |
