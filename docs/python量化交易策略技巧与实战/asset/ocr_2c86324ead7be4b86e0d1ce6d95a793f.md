# 10.2.3 UOS 指标函数

UOS 指标，即终极指标。UOS 指标的语法格式如下：

```
UOS(security_list, check_date, N1 = 7, N2 = 14, N3 = 28, M = 6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N1、N2、N3 和 M 分别表示统计的天数为 N1、N2、N3 和 M。

返回终极指标和 MAUOS 的值，返回类型与 MACD 指标相同，这里不再赘述。

UOS 指标用法具体如下：

+   第一，UOS 上升至 50~70，而后向下跌破其 N 字曲线低点时，为短线卖点；
第二，UOS 上升至 70 及其以上，而后向下跌破 70 时，为中线卖点；
第三，UOS 下跌至 45 及其以下，而后向上突破其 N 字曲线高点时，为短线买点；
第四，UOS 下跌至 35 及其以下，产生一底比一底高的背离现象时，为底部特征。

需要注意的是，以上各项数据会因个股不同而略有不同，请投资者利用参考线自行修正。

# UOS 指标函数实例

双击“量化择时”文件夹，单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“UOS 指标函数”，然后输入如下代码：

```
#导入 technical_analysis 库
From jqllib.technical_analysis import *
# 定义股票池列表
security_list1 = '000001.XSHE'
# 计算并输出 security_list1 的 UOS 值
uos_ultiInc, uos_mauos = UOS(security_list1,check_date='2018-08-01', N1 = 7, N2 = 14, N3 = 28, M = 6)
print("平安银行的终极指标 UOS 的终极指标值：",uos_ultiInc[security_list1])
print("平安银行的终极指标 UOS 的 MAUOS 的值：",uos_mauos[security_list1])
```
