# 量化交易平台

当前，市场上比较流行的量化交易平台有很多，如 JoinQuant 聚宽、UQER 优矿、RiceQuant 米筐。这些平台提供的服务大体类似，但在细节上又有所不同。量化交易平台的服务本质在于通过封装好的回测函数和金融数据库，帮助投资者快速地实现量化交易策略编程和回测。本书以 JoinQuant 聚宽量化交易平台为例来讲解量化交易。
