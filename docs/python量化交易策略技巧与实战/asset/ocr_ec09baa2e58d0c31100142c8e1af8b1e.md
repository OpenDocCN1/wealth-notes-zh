其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 timeperiod 表示统计的天数。

返回 EXPMA 的值，返回类型与 MACD 指标相同，这里不再赘述。

EXPMA 指标用法具体如下：

+   第一，EXPMA 一般以观察 12 日和 50 日两条指数平均线为主；
第二，12 日指数平均线向上交叉 50 日指数平均线时，买入；
第三，12 日指数平均线向下交叉 50 日指数平均线时，卖出。
