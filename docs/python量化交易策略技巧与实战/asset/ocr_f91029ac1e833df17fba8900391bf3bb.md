# 12.4.1 什么是人工神经网络

神经网络是一种运算模型，由大量的节点（或称为神经元）相互连接构成。每个节点代表一种特定的输出函数，称为激励函数。每两个节点间的连接代表一个通过该连接信号的加权值，称为权重，这相当于人工神经网络的记忆。网络的输出因网络的连接方式、权重值和激励函数的不同而不同。网络自身通常是对自然界某种算法或者函数的逼近，也可能是对一种逻辑策略的表达。
