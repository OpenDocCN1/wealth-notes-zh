# 10.4.2 MIKE 指标函数

MIKE 指标，即麦克支撑压力线。在 Python 量化交易策略中，MIKE 指标的语法格式如下：

```
MIKE(security_list, check_date, timeperiod = 10)
```

各参数意义与 MACD 指标相同，这里不再赘述。

返回 STOR、MIDR、WEKR、WEKS、MIDS、STOS 的值，返回类型与 MACD 指标相同，这里不再赘述。

MIKE 指标用法具体如下。

第一，MIKE 指标共有 6 条曲线，上方 3 条压力线，下方 3 条支撑线。

第二，当股价向压力线方向上涨时，其下方支撑线不具有参考价值。

第三，当股价向支撑线方向下跌时，其上方压力线不具有参考价值。

MIKE 指标函数实例

双击 “量化择时” 文件夹，单击 “新建” → “Python 3” 命令，新建一个 Python 3 文件，并将其命名为 “MIKE 指标函数”，然后输入如下代码：

```
#导入 technical_analysis 库
from jqllib.technical_analysis import *
# 定义股票池列表
security_list1 = '000001.XSHE'
# 计算并输出 security_list1 的 MIKE 值
stor1, midr1, wekr1, weks1, mids1, stos1 = MIKE(security_list1,check_date='2018-08-01',timeperiod = 10)
print(stor1[security_list1])
print(midr1[security_list1])
print(wekr1[security_list1])
print(weks1[security_list1])
print(mids1[security_list1])
print(stos1[security_list1])
```
