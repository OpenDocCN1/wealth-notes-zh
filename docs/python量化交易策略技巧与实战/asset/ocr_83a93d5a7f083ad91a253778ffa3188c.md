# 1.1.6 为什么要学习量化交易

很多投资者可能会觉得，我做的是基本面分析，是做价值投资的，量化交易跟我有什么关系呢？即使你从没听说过量化交易，也可能是一名出色的投资者。但是，随着市场和技术的发展，无论是投资者还是证券公司等中介公司，对量化交易有所了解还是非常有必要的，因为它在发现新的空间和机会、优化当前的投资策略，以及降低交易成本方面都起着非常重要的作用，如图 1.1 所示。

# 1) 发现新的空间和机会

无论采用何种投资策略，决定成败的重要因素之一就是面临的竞争。在 1996 年，投资者几乎都在数波浪，很少有人关心公司的基本面。四川长虹（600839）、青岛海尔（600690）等上市公司，利润持续翻番，市盈率却是個位数。到上市公司进行调研，都不知道你来的目的，开股东大会也见不到几个股东。那时候确实是做价值投资的好时候，因为几乎没有竞争。

目前，很多人都是价值投资者，大家都在研究财务报表、进行公司调研。很显然，价值投资的竞争已经非常激烈了。而量化交易还处在初级阶段，虽然有些人在进行这方面的尝试，但整体而言，规模还相当小，还有很大的进入空间。尤其是推出股指期货之后，更是扩大了量化交易策略的应用空间，提供了新的可能性。可以说，目前中国进行量化交易所面临的竞争还是比较小的，这就给量化交易者提供了发挥空间和机会。

# 2) 优化当前的投资策略

当前最成功的量化交易基金——“文艺复兴”（Renaissance Technologies）的创始人詹姆斯·西蒙斯（James Simons）说过，那些从事量化交易的数学家和物理学家，最大的贡献并不在于他们所掌握的理论知识，而是他们所带来的科学精神。投资者需要知道的是，绝大部分的量化交易策略实际上都是源于已有的策略。但是，当你必须把一项投资策略的所有方面都以量化的形式加以确定的时候，就不得不对这项策略的各个方面进行更深入的思考。
