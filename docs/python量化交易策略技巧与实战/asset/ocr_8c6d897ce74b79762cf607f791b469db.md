# 4.2.6 break 语句

使用 break 语句可以使流程跳出 while 或 for 的本层循环，特别是在多层次循环结构中，利用 break 语句可以提前结束内层循环。

需要注意的是，如果从 for 或 while 循环中终止，任何对应的循环 else 块将不再执行。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File” → “New File”命令，创建一个 Python 文件，并将其命名为“Python4-10.py”，然后输入如下代码：

```
for letter in "Python":     # 第一个实例
    if letter == 'h':
        break
    print ('当前字母为 :', letter)
var = 10                        # 第二个实例
while var > 0:
    print ('当前变量值为 :', var)
    var = var -1
    if var == 5:
        break
print ("程序运行完毕，再见! ")
```

单击菜单栏中的“Run” → “Run Module”命令或按键盘上的“F5”键，即可运行程序代码，结果如图 4.10 所示。
