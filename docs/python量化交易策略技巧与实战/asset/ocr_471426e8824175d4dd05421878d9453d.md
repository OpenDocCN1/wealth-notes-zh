# 1) 必需参数

必需参数须以正确的顺序传入函数，并且调用时的数量必须和声明时的一样，下面举例说明。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python5-8.py”，然后输入如下代码：

```
#可写函数说明
def printme( str ):
    #打印任何传入的字符串
    print (str)
    return
#第一次调用 printme 函数，带有参数
printme("第一次调用函数!")
#第二次调用 printme 函数，没有参数
printme()
```

在这里可以看到，先定义一个含有必需参数的函数，第一次调用函数时带有参数，会正确显示；第二次调用函数时，没有输入参数，就会显示报错信息。

单击菜单栏中的“Run”→“Run Module”命令或按键盘上的“F5”键，即可运行程序代码，结果如图 5.11 所示。
