# 14.7.3 编写交易函数

交易函数，即每周检查一次，如果发现有新的医药股的市净率低于原有的股票，则予以换仓，具体代码如下：

```
def trade(context):
    if len(g.stocks) > 0:
        code = g.code
        # 如持仓股票不是最低市净率的股票，则卖出
        for stock in context.portfolio.positions.keys():
            if stock != code:
                order_target(stock,0)
        # 持仓该股票
        if len(context.portfolio.positions) > 0:
            return
        else:
            order_value(code, context.portfolio.cash)
```
