while 循环语句同样需要注意冒号和缩进。另外，在 Python 中没有 do...while 循环。

```
n =int(input("请输入一个大于 0 的整数:"))

```

# 4.2.2 while 循环使用 else 语句

在 while...else 语句中，如果条件语句为 False 时，则执行 else 的语句块。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python4-6.py”，然后输入如下代码：

```
count = 0
while count < 12:
    print (count, " 小于 12，正在运行 While 循环语句")
    count = count + 1
else:
    print (count, " 等于 12，即已运行到 While 循环中的 else 语句")
```

单击菜单栏中的“Run”→“Run Module”命令或按键盘上的“F5”键，即可运行程序代码，结果如图 4.6 所示。
