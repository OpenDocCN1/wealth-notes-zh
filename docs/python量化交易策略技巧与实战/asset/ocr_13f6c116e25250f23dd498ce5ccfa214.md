# 10.3.3 RSI 指标函数

RSI 指标，即相对强弱指标。在 Python 量化交易策略中，RSI 指标的语法格式如下：

```
RSI(security_list, check_date, N1=6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。

参数 N1 表示统计的天数 N1。

返回 RSI 的值，返回类型与 MACD 指标相同，这里不再赘述。

RSI 指标用法具体如下。

第一，RSI>80 为超买，RSI<20 为超卖。

第二，RSI 以 50 为中界线，大于 50 视为多头行情，小于 50 视为空头行情。

第三，RSI 在 80 以上形成 M 头或头肩顶形态时，为向下反转信号。

第四，RSI 在 20 以下形成 W 底或头肩底形态时，为向上反转信号。

第五，RSI 向上突破其高点连线时，买入；RSI 向下跌破其低点连线时，卖出。
