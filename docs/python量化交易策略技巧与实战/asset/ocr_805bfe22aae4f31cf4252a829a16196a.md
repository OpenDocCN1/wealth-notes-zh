# 9.4.4 动态市盈率选股技巧

动态市盈率，是指还没有真正实现的下一年度的预测利润的市盈率，其计算公式如下：

动态市盈率=股票现价÷未来每股收益的预测值

动态市盈率和市盈率是全球资本市场通用的投资参考指标，用以衡量某一阶段资本市场的投资价值和风险程度，也是资本市场之间用来相互参考与借鉴的重要依据。
