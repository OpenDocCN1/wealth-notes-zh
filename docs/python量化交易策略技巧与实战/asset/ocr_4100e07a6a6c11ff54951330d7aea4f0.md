些宝贵经验往往是无法通过计算机语言描绘的。

第四，时间周期不同，如 5 分钟、30 分钟、60 分钟、日线、周线、月线，交易系统给出的交易信号可能会完全不同，投资者应当根据交易品种的特性选择不同的时间周期，并且应当严格按照交易系统选择的时间周期进行交易。

第五，参数调整是决定交易系统成败的关键，因为没有任何一组参数适合所有交易品种。要根据交易品种特性不断地进行磨合、测试，找到适合该交易品种的参数，并且在今后交易过程中还要根据市场变化不断加以修正。

第六，量化交易系统体现了投资者的交易思路和风格，但它只是交易的辅助手段，投资者才是交易的主体，不能本末倒置。只有将交易系统、风险管理、资金管理相互结合，才能发挥其最大功效。
