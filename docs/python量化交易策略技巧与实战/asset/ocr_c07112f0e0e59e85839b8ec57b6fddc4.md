而是一个市场共识。比如网络概念，在网络成为概念之前，涉及互联网的股票充其量只能称为一个板块，是一种中性的界定，但成为概念后，含义就变了。概念是一个更为积极、含义更为肯定的投资共识。投资者会对概念类股票的产业背景、投资机会及未来的前景，进行非常细致的分析研究并对其产生极大的信心。
