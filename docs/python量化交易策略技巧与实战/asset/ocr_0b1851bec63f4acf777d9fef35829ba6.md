# 1.1 初识量化交易

量化交易在国外已有 30 多年的历史，在这些年的交易当中量化交易的业绩相当稳定，得到了越来越多交易者的认可，市场规模不断扩大，甚至有超过非量化交易的趋势。

# 1.1.1 什么是量化交易

量化交易是指投资者利用计算机技术、金融工程建模等方法，对自己的交易策略进行定义和描述，以帮助投资者形成交易决策，并且严格按照设定的规则去执行交易（买、卖）的一种方式。

量化交易可以帮助交易者制定交易决策、减少交易成本、套利和风险对冲，还可以帮助交易者在做市商时实现报价。

# 1.1.2 量化交易与算法交易

在当前的金融市场中，听到“算法交易”的次数可能比听到“量化交易”的次数还多。一般来讲，这两种说法是可以替换使用的，因为当前最流行的量化交易策略基本都属于算法交易的范畴。

但是，量化交易和算法交易还是有区别的。算法交易通常是高度自动化的交易，也被称为“自动交易”或“黑匣子交易”。

需要注意的是，当我们说“算法交易”时，并不是泛指所有高度自动化的量化交易策略，而是专门指那些持有期很短、交易比较频繁的交易策略，甚至专门指那些以降低交易成本为目的的交易策略。

所以，本书讲的量化交易，范围比较广，不仅包括算法交易，还包括自动化程度不算高和交易频率也不是很高的其他交易。

# 1.1.3 量化交易与程序化交易

如果单从字面上来说，程序化交易是指所有高度自动化的量化交易策略，包括算法交易。在很多情况下，人们也确实是这么用的。不过，纽约交易所对程序交易有专门的定义，是指同时涉及 15 个及以上的证券、总交易额至少为 100 万美元的电子交易。而这类交易很大一部分都是套利，因此当人们说程序化交易时，往往特指套利交易策略。
