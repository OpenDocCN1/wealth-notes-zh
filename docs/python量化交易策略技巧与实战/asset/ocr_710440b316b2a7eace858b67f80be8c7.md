# 8.6 get_index_stocks()函数的运用技巧

get_index_stocks()函数可以获取一个指数给定日期在平台可交易的成分股列表，其语法格式如下：

```
get_index_stocks(index_symbol, date=None)
```

# 8.6.1 各项参数的意义

get_index_stocks()函数有两个参数，分别是 date 和 index_symbol。

# 1) date

参数 date 是一个字符串（如“2015-10-15”）或 datetime.date/datetime.datetime 对象。参数值可以是 None，此时使用默认日期，这个默认日期在回测和研究模块上有些区别，具体如下。

回测模块：默认值会随着回测日期的变化而变化，等同于 context.current_dt。

研究模块：默认值是今天。

# 2) index_symbol

参数 index_symbol，是指指数代码。这里支持 600 种股票指数数据，包括指数的行情数据和成分股数据。常用指数代码及意义如下。

+   000001.XSHG: 上证指数。
000002.XSHG: A 股指数。
000003.XSHG: B 股指数。
000004.XSHG: 工业指数。
000005.XSHG: 商业指数。
000006.XSHG: 地产指数。
000007.XSHG: 公用指数。
000008.XSHG: 综合指数。
000016.XSHG: 上证 50。
000042.XSHG: 上证央企。
