# 13.3.3 因子的 IC 分析

IC 是 information coefficient 的缩写，IC 代表了预测值和现实值之间的相关性，通常用来评价预测能力。取值为-1~1，值越大，表示预测能力越好。

IC 的计算一般有两种方法，分别是 normal IC 和 rank IC。normal IC 是因子载荷与因子收益的相关系数；rank IC 是因子载荷的排序值与收益的排序值的相关系数。JoinQuant 聚宽量化交易平台计算的是 rank IC。

由于单日 IC 的波动较大，1 天 IC 中还提供了 IC 的月度移动平均线作为参考，即 22 日移动平均线。
