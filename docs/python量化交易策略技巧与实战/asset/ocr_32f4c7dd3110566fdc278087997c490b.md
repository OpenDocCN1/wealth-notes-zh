# 3.8.2 代码注释

Python 中单行注释以#开头，实例如下：

```
print ("Hello, Python!")  # 第一个注释
```

多行注释可以用多个#号，还有'''和"""：

```
# 第一个注释
# 第二个注释
'''
第三注释
第四注释
'''
"""
第五注释
第六注释
"""
```
