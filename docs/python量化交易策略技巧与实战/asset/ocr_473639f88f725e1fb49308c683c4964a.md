# 图 12.21 神经网络数据已准备好

接下来导入需要的数据包，再创建和训练神经网络，训练样本的特征是根据 2013 年 9 月 6 日至 2018 年 8 月 27 日每一天的之前的交易日的收盘价计算的简单移动平均线指标、加权移动平均线指标和动量线指标，训练样本的标签是 2013 年 9 月 6 日至 2018 年 8 月 27 日每一天的涨跌情况，涨是 True，跌是 False，测试样本是 2018 年 8 月 28 日的 3 个指标及涨跌情况。

最后输出的是测试样本中的判断误差，由于只有一个测试样本，如果神经网络的判断结果和真实涨跌情况相同，则输出 0%，并显示“预测正确！ ”；如果神经网络的判断结果和真实涨跌情况不相同，则输出 100%，并显示“预测错误！”，具体代码如下：

```
#导入需要的数据包
from pybrain.tools.shortcuts import buildNetwork
from pybrain.supervised.trainers import BackpropTrainer
from pybrain.structure.modules import SoftmaxLayer
from pybrain.utilities import percentError
#创建神经网络
fnn = buildNetwork(trndata.indim, 5, trndata.outdim, outclass=SoftmaxLayer)
#训练神经网络
trainer = BackpropTrainer(fnn, dataset=trndata, momentum=0.1, verbose=True, weightdecay=0.01)
#训练一次，可以通过括号里面的数字调节训练的次数
trainer.trainEpochs(1)
# 计算预测误差，这个是误差，不是预测准确率，0 表示预测对了，100%表示预测错了
tstresult = percentError(trainer.testOnClassData(dataset=tstdata), tstdata['class'])
```
