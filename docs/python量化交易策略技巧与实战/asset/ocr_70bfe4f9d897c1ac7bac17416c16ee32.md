# 3.3 Python 程序的编写

单击桌面左下角的 “开始” 菜单按钮后，单击 “所有程序” 命令，即可在 “开始” 菜单栏中看到 “Python 3.7”，再单击 “Python 3.7”，即可看到 Python 自带的开发软件 IDLE 菜单命令，如图 3.14 所示。
