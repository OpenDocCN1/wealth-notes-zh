# 2.2.1 高质量数据和强大的研究平台

对于个人或者中小机构来说，收集、处理、维护大量历史数据的成本是比较高的，而且数据需要实时更新并反复清洗，所以能够提供全面的、高精度的各种市场数据是对量化平台最基本和最关键的要求。JoinQuant 聚宽量化交易平台拥有 2005 年至今完整的 Level-2 数据和上市公司财务数据，其中包含完整的停牌、复权等信息。另外，JoinQuant 聚宽量化交易平台的数据完全免费，并且其每年投入近百万元用于数据的购买、加工和存储。

JoinQuant聚宽量化交易平台免费提供基于 IPython Notebook 系统的研究平台，提供分钟级数据，采用 Docker 技术隔离。相较于 IPython Notebook 系统其资源独立，安全性更高、性能更好，且同步支持 Python 2 和 Python 3 程序。
