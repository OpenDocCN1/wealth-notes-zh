# 11.5.3 Sharpe（夏普比率）

Sharpe 表示每承受一单位总风险会产生多少超额報酬，可以对策略的收益与风险进行综合考虑。

Sharpe 的计算公式如下：

Sharpe = (R_p - R_f) / σ_p

各参数意义如下：

R_p 表示策略年化收益率；

R_f 表示无风险利率（默认值 감 0.04）；

σ_p 表示策略收益波动率。

在“回测详情”页面中，单击左侧列表框中的“Sharpe”选项，即可看到 MACD 指标量化交易策略的“Sharpe”信息，如图 11.19 所示。
