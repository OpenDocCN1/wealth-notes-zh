# 11.5.2 Beta（贝塔）

Beta 表示投资的系统性风险，反映了策略对大盘变化的敏感性。例如一个策略的 Beta 值为 1.5，则大盘涨 1% 的时候，策略可能涨 1.5%，反之亦然；如果一个策略的 Beta 值为 -1.5，说明大盘涨 1% 的时候，策略可能跌 1.5%，反之亦然。

Beta 的计算公式如下：

```
Beta = βₚ = Cov(Dₚ, Dₘ) / Var(Dₘ)
```

各参数意义如下：

+   Dₚ 表示策略每日收益；
Dₘ 表示基准每日收益；
Cov(Dₚ, Dₘ) 表示策略每日收益与基准每日收益的协方差；
Var(Dₘ) 表示基准每日收益的方差。

> 提醒：如果 Beta<0，投资组合和基准的走向通常是反方向的，如空头头寸类。如果 Beta=0，投资组合和基准的走向没有相关性，如固定收益类。如果 0<Bета<1，投资组合和基准的走向相同，但是比基准的移动幅度小。如果 Beta=1，投资组合和基准的走向相同，并且和基准的移动幅度贴近。如果 Beta>1，投资组合和基准的走向相同，但是比基准的移动幅度大。
