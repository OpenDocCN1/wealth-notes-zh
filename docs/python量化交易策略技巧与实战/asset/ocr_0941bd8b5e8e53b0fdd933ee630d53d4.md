神经元细胞网络中细胞间的联系错综复杂。神经元细胞网络综合每个细胞的成果，最终完成了非常复杂的任务。

# 12.4.3 人工神经网络的基本特征

人工神经网络的基本特征有 4 项，分别是非线性、非局限性、非常定性、非凸性，如图 12.16 所示。

![](bbox=[0.35, 0.259, 0.655, 0.412])

图 12.16 人工神经网络的基本特征

# 1) 非线性

非线性是自然界的普遍特性，大脑的智慧就是一种非线性现象。人工神经元处于兴奋或不兴奋两种不同的状态，这种行为在数学上表现为一种非线性关系。具有阈值的神经元构成的网络具有更好的性能，可以提高容错性和存储容量。

# 2) 非局限性

一个神经网络通常由多个神经元广泛连接而成。一个系统的整体行为不仅取决于单个神经元的特征，而且可能主要由单元之间的相互作用、相互连接决定。单元之间的大量连接可以模拟大脑的非局限性。

# 3) 非常定性

人工神经网络具有自适应、自组织、自学习的能力。神经网络不但处理的信息可以有各种变化，而且在处理信息的同时，非线性动力系统本身也在不断变化。通常采用迭代过程对动力系统的演化过程进行描写。

# 4) 非凸性

一个系统的演化方向，在一定条件下将取决于某个特定的状态函数。例如，能量函数，它的极值与系统比较稳定的状态相对应。非凸性是指这种函数有多个极值，故系统具有多个较稳定的平衡状态，这将导致系统演化的多样性。
