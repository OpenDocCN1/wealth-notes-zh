本书记用的是 Python 3.7.1，即单击 “Windows x86 executable installer” 超链接，弹出 “新建下载任务” 对话框，如图 3.2 所示。

![](bbox=[0.32, 0.16, 0.71, 0.31])

图 3.2 “新建下载任务” 对话框

单击 “下载” 按钮，开始下载，下载完成后，就可以在桌面看到 Python 3.7.1 的安装文件图标，如图 3.3 所示。

![](bbox=[0.45, 0.4, 0.58, 0.52])

图 3.3 安装文件图标

双击 Python 3.7.1 安装文件图标，弹出 “Python 3.7.1 (32-bit) Setup” 对话框，如图 3.4 所示。

![](bbox=[0.27, 0.59, 0.76, 0.82])

图 3.4 “Python 3.7.1 (32-bit) Setup” 对话框

提醒：在这里要选中 “Add Python 3.7 to PATH” 复选框，这样就可以把 Python 3.7.1 添加到 Path（路径）存储在环境变量中。
