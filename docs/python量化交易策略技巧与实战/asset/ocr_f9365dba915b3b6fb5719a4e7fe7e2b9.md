# 3.5 Python 的基本数据类型

Python 的标准数据类型只有 6 个，分别是数值、字符串、列表、元组、集合、字典。相对于 C 语言来讲，Python 的数据类型很少，但该有的功能一个不少。即使 C 语言的代表作链表和二叉树，Python 同样可以轻松应对。下面先来讲解一下 Python 的基本数据类型，即数值和字符串。

# 3.5.1 数值类型
