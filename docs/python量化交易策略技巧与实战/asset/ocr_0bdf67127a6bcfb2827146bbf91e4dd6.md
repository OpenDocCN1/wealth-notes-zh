# 3) Numpy序列数组

arange 函数与 Python 中的 range 函数相似，但 arange 函数属于 Numpy 库，其参数依次为：开始值、结束值、步长。另外，可以使用 linspace 函数创建等差序列数组，其参数依次为：开始值、结束值、元素数量。

成功登录 JoinQuant 聚宽量化交易平台后，单击导航栏中的“策略研究”→“研究环境”命令，打开研究环境页面。然后单击“新建”→“Python 3”命令，就 خدمة新建一个 Python 3 文件，并将其命名为“Numpy 序列数组”。

在单元格中输入代码如下：

```
import numpy as np
numy1 = np.arange(1,120,4)
print("利用 arange 函数创建等差序列数组：",numy1)
print()
numy2 = np.linspace(0,8,20)
print("利用 linspace 函数创建等差序列数组：",numy2)
```
