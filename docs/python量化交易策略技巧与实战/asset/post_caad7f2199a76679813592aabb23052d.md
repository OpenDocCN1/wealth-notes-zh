## 8.4 get_fundamentals_continuously()函数的运用技巧

get_fundamentals()函数只能用来查询某一交易日的股票财务数据信息，如果要查询多个交易日的股票财务数据信息，则要使用 get_fundamentals_continuously()函数，其语法格式如下：

```
get_fundamentals_continuously(query_object, end_date=None, count=None)
```

各项参数意义如下。

参数 query_object: 一个 sqlalchemy.orm.query.Query 对象，可以通过全局的 query 函数获取 Query 对象。

参数 end_date: 与 get_fundamentals()函数中 date 意义相同，即查询日期。

参数 count: 获取 end_date 前 count 个日期的数据。

get_fundamentals_continuously()函数的返回值是一个 pandas.Panel。

> 提醒：从性能方面考虑，返回总条数不超过 10 000 条的限制。也就是说，查询的股票数量 count 要小于 10 000。否则，返回的数据将不完整。

下面举例说明 get_fundamentals_continuously()函数的应用。创建一个 Python 3 文件，然后输入代码如下：

```
import pandas as pd
q = query(valuation).filter(valuation.code.in_(['000001.XSHE', '600000.XSHG']))
panel = get_fundamentals_continuously(q, end_date='2018-01-01', count=5)
panel.minor_xs('600000.XSHG')
```

利用 query 函数调用平安银行（000001）和浦发银行（600000）的财务数据信息；然后再利用 get_fundamentals_continuously()函数获取结束日期为 2018 年 1 月 1 日的最近 5 个交易日的数据信息；最后利用 panel 对象输出。

## 8.5 get_current_data ()函数的运用技巧

在回测时，有些数据在一个单位时间（天/分钟）是已知的，例如涨跌停价、是否停牌、当天的开盘价等，这些数据可以通过 get_current_data()函数获得。该函数的语法格式如下：

```
get_current_data(security_list=None)
```

参数 security_list 用来设置股票代码列表，默认值是 None，代表当前 universe 中的股票。

该函数的返回值是一个 dict 对象，dict 对象的索引是股票代码，dict 对象的 value（数据）具体如下：

```
high_limit           # 涨停价
low_limit            # 跌停价
paused               # 是否停止或者暂停了交易，当停牌、未上市、暂停交易时返回 True
is_st                # 是否是 ST | 包括 ST、*ST
# 当天开盘价，分时回测时可用；天回测时，由于是集合竞价后下单，并不知道开盘价，所以不能使用
day_open
name                 # 战略现在的名称
industry_code        # 战略现在所属行业代码
```

需要注意的是，为了加快返回速度，返回的 dict 对象里面的数据是按需获取的，dict 对象初始是空的。当使用 current_data[security]时，该 security 的数据才会被获取。另外，返回的结果只在当天有效，不能储存。

get_current_data()函数的实例代码如下：

![](img/e6d4c365781f4dd8cb814bd56923b0bc_216_0.png)

```
set_universe(['000001.XSHE'])
def handle_data(context, data):
    current_data = get_current_data()
    print(current_data)
    print(current_data['000001.XSHE'])
    print(current_data['000001.XSHE'].paused)      #查询股票当天是否停牌
    print(current_data['000001.XSHE'].high_limit)  #获取当天的涨停价
```

## 8.9 get_all_securities()函数的运用技巧

get_all_securities()函数可以获取平台支持的所有股票、基金、指数、期货等信息，其语法格式如下：

```
get_all_securities(types=[], date=None)
```

### 8.9.1 各项参数的意义

get_all_securities()函数有两个参数，分别是 types 和 date。

### 1）参数 types

参数 types 是列表类型，用来过滤 securities 的类型，列表元素及意义如下。

- stock: 表示股票类型，即显示所有股票信息。
- fund: 表示基金类型，即显示所有基金信息。
- index: 表示指数类型，即显示所有指数信息。
- futures: 表示期货类型，即显示所有期货信息。
- etf: 表示 ETF 基金，即显示所有 ETF 基金信息。
- lof: 表示 LOF 基金，即显示所有 LOF 基金信息。
- fja: 表示分级 A，即显示所有分级基金的 A 份额的信息。
- fjb: 表示分级 B，即显示所有分级基金的 B 份额的信息。
- open_fund: 表示开放式基金，即显示所有开放式基金信息。
- bond_fund: 表示债券基金，即显示所有债券基金信息。
- stock_fund: 表示股票型基金，即显示所有股票型基金信息。
- QDII_fund: 表示 QDII 基金，即显示所有 QDII 基金信息。
- money_market_fund: 表示货币基金，即显示所有货币基金信息。
- mixture_fund: 表示混合型基金，即显示所有混合型基金信息。

需要注意的是，types 为空时，返回所有股票信息，但不包括基金、指数和期货信息。

### 2）参数 date

参数 date 是日期类型，一个字符串或 datetime.datetime/datetime.date 对象，用于获取某日期还在上市的股票信息，默认值为 None，表示获取所有日期的股票信息。

get_all_securities()函数的返回值是 pandas.DataFrame 类型。
