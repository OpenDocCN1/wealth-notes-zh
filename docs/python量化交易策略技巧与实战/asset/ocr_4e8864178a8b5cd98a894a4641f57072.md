# 4.3.2 元组

Python 程序设计中的元组与列表类似，不同之处在于元组的元素不能修改。另外，元组使用小括号（()），列表使用中括号（[]）。

元组创建很简单，只需要在括号中添加元素，并使用逗号隔开即可，具体代码如下：

```
tup1 = ("Google", "Baidu", 2017, 2018)
tup2 = (1, 2, 3, 4, 5,6,7,8,9 )
tup3 = "a", "b", "c", "d","f","g"      # 不需要括号也可以
```

可以使用下标索引来访问元组中的值，也可以使用中括号来截取字符，还可以利用 for 循环语
