# 10.3.4 OSC 指标函数

OSC 指标，即变动速率线。在 Python 量化交易策略中，OSC 指标的语法格式如下：

```
OSC(security_list, check_date, N = 20, M = 6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M 分别表示统计的天数 N 和统计的天数 M。

返回 OSC 和 MAOSC 的值，返回类型与 MACD 指标相同，这里不再赘述。

OSC 指标用法具体如下。

+   第一，OSC 以 100 为中轴线，OSC>100 为多头市场，OSC<100 为空头市场。
第二，OSC 向上交叉其平均线时，买入；OSC 向下交叉其平均线时卖出。
第三，OSC 在高水平或低水平与股价产生背离时，应注意股价随时有反转的可能。

提醒：OSC 的超买、超卖界限值随个股不同而不同，投资者应自行调整。
