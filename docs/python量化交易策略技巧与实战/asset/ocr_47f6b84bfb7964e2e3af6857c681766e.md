在“我的因子”页面中，单击“新建因子”按钮，就 piso可以新建一个因子，然后编写 Python 代码，具体如下：

```
from jqfactor import Factor
class MONEY(Factor):
    # 设置因子名称
    name = 'ma'
    # 设置获取数据的时间窗口长度
    max_window = 1
    # 设置依赖的数据
    dependencies = ['money']
    # 计算因子的函数，需要返回一个 pandas.Series，index 是股票代码，value 是因子值
    def calc(self, data):
        ma = data['money'].mean()
        return zscore(ma)
# 标准化函数
def zscore(series):
    std = series.std()
    mean = series.mean()
    return (series - mean)/std
```

第一行代码： from jqfactor import Factor，是指从 jqfactor 模块中导入 Factor 类。其他代码与前面讲过的代码基本相同，这里不再赘述。
