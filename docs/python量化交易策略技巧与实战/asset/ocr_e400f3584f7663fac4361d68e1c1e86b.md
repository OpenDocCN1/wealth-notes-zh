# 5.1.3 三角函数

三角函数及意义如表 5.3 所示。

# 表 5.3 三角函数及意义

| 三角函数 | 意义（返回值） |
|---|---|
| acos(x) | 返回 x 的反余弦弧度值 |
| asin(x) | 返回 x 的反正弦弧度值 |
| atan(x) | 返回 x 的反正切弧度值 |
| atan2(y, x) | 返回给定的 x 及 y 坐标值的反正切值 |
| cos(x) | 返回 x 的弧度的余弦值 |
| hypot(x, y) | 返回欧几里得范数 sqrt(x*x + y*y) |
| sin(x) | 返回 x 弧度的正弦值 |
| tan(x) | 返回 x 弧度的正切值 |
| degrees(x) | 将 x 弧度转换为角度 |
| radians(x) | 将 x 角度转换为弧度 |
