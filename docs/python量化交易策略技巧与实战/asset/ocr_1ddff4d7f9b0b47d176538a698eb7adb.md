# 1.1.4 量化交易与技术分析

投资者很容易把量化交易和技术分析联系在一起，事实上，在量化交易中会使用一些我们常用的技术指标，而在技术分析中也会使用很多量化指标。而且，相当一部分量化交易策略和技术分析一样，都是依赖于对价格、成交额等交易信息的分析。不过，量化交易与技术分析还是有区别的。

首先，有些技术分析方法很难被量化。例如，图形分析是技术分析的一个重要部分，可是有一些图形很难被量化定义，如波浪。因此，这些技术分析手段就无法应用在量化交易中。

其次，量化交易并不仅限于技术分析涉及的交易信息。例如，基本面的信息数据，如收入、利润、购并等公司基本面信息，以及利率、通胀等宏观基本面信息，都可能被量化交易策略参考。

因此，量化交易和技术分析的关系是既相互重叠又相互独立的。

# 1.1.5 量化交易与人工交易

量化交易与人工交易的对比，如表 1.1 所示。

# 表 1.1 量化交易与人工交易的对比

|  | 量化交易 | 人工交易 |
|---|---|---|
| 纪律性 | 忠实地执行设计者的思路,不存在主观情绪的影响,纪律严明 | 主观情绪化,恐惧、贪婪、赌气等人性弱点容易导致交易变形,纪律性较差 |
| 精力 | 只要计算机正常、电源正常，不知疲倦 | 需要睡觉、吃饭、离开计算机;长时间在计算机前imeters不利 于身体健康 |
| 效率性 | 理论上,从判断到下单瞬间完成,可以捕捉到突发行情 | 从决定到执行需要几个步骤,至少需要30秒,难以捕捉突发行情或捕捉的时机不好 |
| 系统性 | 严格按照既定的一套或多套操作方法交易,可能判断系统优劣,并进行改进 | 随意性较大,很难评估优劣,对订单的处理“艺术性”更强 |
| 可控制性 | 风险、胜率、回测率等可以根据历史数据来检测。在实际使用中根据设定的参数,风险是明确的。只要系统严谨,失控的可能性很小 | 风险不太明确,有失控的可能 |
| 可复制性 | 盈利模式可以无限复制,即“一劳永逸”。在时间上可以复制以往的成功模式;在空间上可以在无数个账户上复制成功模式 | 经验的形成需要足够的交易次数,并且只有交易员具备超强的心里素质时,以往的盈利模式才有可能复制。另外,一个交易员人工可操作的账户有限,所以空间上复制盈利的能力较差 |
