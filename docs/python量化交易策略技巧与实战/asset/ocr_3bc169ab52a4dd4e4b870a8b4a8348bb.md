# 3.6 Python 的变量与赋值

变量，是指在程序执行过程中其值可以变化的量，系统为程序中的每个变量分配了一个存储单元。变量名实质上就是计算机内存单元的命名。因此，借助变量名就可以访问内存中的数据。

# 3.6.1 变量命名规则

变量是一个名称，给变量命名时，应遵循以下规则：

+   - 第一，名称只能由字母、数字和下划线组成；
- 第二，名称的第一个字符可以是字母或下划线，但不能是数字；
- 第三，名称对大小写敏感；
- 第四，名称不能与 Python 中的关键字相同。

关键字，即保留字。Python 的标准库提供了一个 keyword 模块，可以输出当前版本的所有关键字。单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后输入如下代码：

```
import keyword
```

首先导入 keyword 模块，然后按“Enter”键，再输入如下代码：

```
keyword.kwlist
```
