# 4.2.4 for 循环

for 循环可以遍历任何序列的项目，如一个列表或者一个字符串。for 循环语句的一般形式如下：

```
for <variable> in <sequence>:
    <statements>
else:
    <statements>
```

单击 “开始” 菜单按钮，打开 “Python 3.7.1 Shell” 窗口，然后单击菜单栏中的 “File” → “New File” 命令，创建一个 Python 文件，并将其命名为 “Python4-8.py”，然后输入如下代码：

```
names = ["周文康", "王佳欣", "王可亮", "张平", "李硕"]
for x in names:
    print( x )
```

单击菜单栏中的 “Run” → “Run Module” 命令或按键盘上的 “F5” 键，即可运行程序代码，结果如图 4.8 所示。
