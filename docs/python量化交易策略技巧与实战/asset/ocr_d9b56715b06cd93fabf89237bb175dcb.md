# 9.4.3 市现率选股技巧

市现率是股票价格与每股现金流量的比率。市现率可用于评价股票的价格水平和风险水平，市现率越小，表明上市公司的每股现金增加额越多，经营压力越小。对于参与资本运作的投资机构来说，市现率还意味着其运作资本的增加效率。
