# 9.2.3 净利润同比增长率选股技巧

净利润，是指企业当期利润总额减去所得税后的金额，即企业的税后利润。净利润是一个企业经营的最终成果，净利润多，企业的经营效益就好；净利润少，企业的经营效益就差。它是衡量一个企业经营效益的主要指标。净利润同比增长率的计算公式如下：

净利润同比增长率=（当期净利润-上期净利润）÷上期净利润的绝对值×100%

成功登录 JoinQuant 聚宽量化交易平台后，单击导航栏中的“策略研究”→“研究环境”命令，打开研究环境页面。双击“量化选股”文件夹，然后单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“净利润同比增长率选股”，然后输入如下代码：

```
import pandas as pd
```
