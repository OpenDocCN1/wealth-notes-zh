# 3.7.2 赋值运算

赋值运算符及意义如表 3.5 所示。

# 表 3.5 赋值运算符及意义

| 赋值运算符 | 意义 |
|---|---|
| = | 简单的赋值运算符 |
| += | 加法赋值运算符 |
| -= | 减法赋值运算符 |
| *= | 乘法赋值运算符 |
| /= | 除法赋值运算符 |
| %= | 取模赋值运算符 |
| //= | 取整除赋值运算符 |
| **= | 幂赋值运算符 |

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python3-6.py”，然后输入如下代码：

```
a = 36      # 为三个变量赋值
b = 12
c = 0
c = a + b
print ("a + b 的值为: ", c)
c += a
print ("c += a 的值为: ", c)
c *= a
print ("c *= a 的值为: ", c)
c /= a
```
