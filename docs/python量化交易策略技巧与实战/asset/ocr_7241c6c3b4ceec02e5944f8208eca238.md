```
Bollinger_Bands(security_list, check_date, timeperiod=20, nbdevup=2, nbdevdn=2)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 timeperiod、nbdevup 和 nbdevdn 分别表示统计的天数 timeperiod、统计的天数 nbdevup 和统计的天数 nbdevdn。

返回上轨线 UB、中轨线 MB、下轨线 LB 的值，返回类型与 MACD 指标相同，这里不再赘述。

BOLL 指标用法具体如下。

+   第一，股价上升穿越布林通道线上限时，回档概率大。
第二，股价下跌穿越布林通道线下限时，反弹概率大。
第三，布林通道线震动波带变窄时，表示变盘在即。
