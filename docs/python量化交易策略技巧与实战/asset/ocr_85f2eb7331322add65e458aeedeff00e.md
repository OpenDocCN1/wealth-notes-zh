安装时，可能会没有选中 “Add Python 3.7 to PATH” 复选框，即没有把 Python 3.7.1 添加到 Path（路径）并存储在环境变量中，所以这里做一下讲解。

在环境变量中添加 Python 目录，有两种方法：一是利用命令提示框；二是利用计算机属性设置。

# 1）命令提示框

单击桌面左下角的 “开始” 菜单按钮，然后在文本框中输入 “cmd”，如图 3.7 所示。
