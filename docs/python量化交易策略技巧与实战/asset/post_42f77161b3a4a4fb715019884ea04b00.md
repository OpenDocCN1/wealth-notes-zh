## 10.2.5 DMA 指标函数

DMA 指标，即平均差指标。DMA 指标的语法格式如下：

```

```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N1、N2 和 M 分别表示统计的天数为 N1、N2 和 M。

DMA 指标用法具体如下：

- 第一，DMA 向上交叉其平均线时买入；
- 第二，DMA 向下交叉其平均线时卖出；
- 第三，DMA 的交叉信号比 MACD 略快；
- 第四，DMA 与股价产生背离时的交叉信号，可信度较高；
- 第五，DMA 和 MACD 两者构成一组指标，互相验证。

## 10.2.6 JS 指标函数

JS 指标，即加速线。JS 指标的语法格式如下：

```
JS(security_list, check_date, N = 5, M1 = 5, M2 = 10, M3 = 20)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M1、M2、M3 分别表示统计的天数为 N 和 M1、M2、M3。

返回 JS、MAJS1、MAJS2 和 MAJS3 的值，返回类型与 MACD 指标相同，这里不再赘述。

JS 指标是衡量股价涨速的工具，JS 指标上升表明股价上升动力增加；JS 指标下降表明股价下降压力增加。

- 第一，如果加速线在 0 值附近形成平台，则表明既不是最好的买入时机也不是最好的卖出时机；
- 第二，在加速线发生金叉后，均线形成底部是买入时机；
- 第三，在加速线发生死叉后，均线形成顶部是卖出时机。

## 10.2.7 MA 指标函数

```

```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 timeperiod 表示统计的天数。

返回 MA 的值，返回类型与 MACD 指标相同，这里不再赘述。

MA 指标用法具体如下：

- 第一，股价高于均线时，为强势；股价低于均线时，为弱势；
- 第二，均线向上上涨，具有助涨力道；均线向下下跌，具有助跌力道；
- 第三，两条以上均线向上交叉时，买入；
- 第四，两条以上均线向下交叉时，卖出；
- 第五，移动均线的信号经常落后股价时，若以 EXPMA、VMA 辅助，则该情况可以得到改善。

## 10.3 反趋向指标函数运用技巧

反趋向指标，又称超买超卖型技术指标。对某种股票的过度买入称为超买，反之，对于某种股票的过度卖出则称为超卖。反趋向指标属于分析大势的一种技术分析指标，它的主要用途是，判断大势的涨跌形势，使股市潜在的趋势清楚地表现出来。

### 10.3.1 KD 指标函数

KD 指标，即随机指标。KD 指标的语法格式如下：

```
KD(security_list, check_date, N=9, M1=3, M2=3)
```

各项参数意义如下。

参数 security_list: 股票列表，可以是一只股票，也可是多只股票。

参数 check_date: 要查询数据的日期。

参数 N: 统计的天数为 N。

参数 M1: 统计的天数为 M1。

参数 M2: 统计的天数为 M2。

随机指标 KD 的返回值是 K 和 D 的值，是一个字典（dict）类型，其中键（key）为股票代码，值（value）为数据。

KD 指标用法具体如下。

- 第一，指标 > 80 时，回档概率大；指标 < 20 时，反弹概率大。
- 第二，K 在 20 左右向上交叉 D 时，为买入信号。
- 第三，K 在 80 左右向下交叉 D 时，为卖出信号。

提醒：KD 波动在 50 左右的任何信号，其作用都不大。

### 10.3.4 OSC 指标函数
