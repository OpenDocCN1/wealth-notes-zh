其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M 分别表示统计的天数为 N 和 M。

返回 EMV 和 MAEMV 的值，返回类型与 MACD 指标相同，这里不再赘述。

EMV 指标用法具体如下：

+   - 第一，EMV 由下往上穿越 0 轴时，为中期买入信号；
- 第二，EMV 由上往下穿越 0 轴时，为中期卖出信号；
- 第三，EMV 的平均线穿越 0 轴，产生假信号的机会较少。

需要注意的是，须长期使用 EMV 指标才能获得最佳利润。
