# 14.1 MA 均线量化交易策略实战案例

MA 指标是反映价格运行趋势的重要指标，其运行趋势一旦形成，将在一ess时间内继续保持。趋势运行所形成的高点或低点又分别具有阻挡或支撑作用，因此均线指标所在的点位往往是十分重要的支撑或阻力位，这就提供了买进或卖出的有利时机，均线系统的价值也正在于此。下面利用 MA 均线指标来编写一个量化交易策略，实现当价格高于 5 日均线平均价格 10% 时买入，当价格低于 5 日平均价格 90% 时卖出。

# 14.1.1 编写初始化函数

成功登录聚宽 JoinQuan 量化交易平台后，单击导航栏中的 “策略研究” → “策略列表” 命令，打开 “策略列表” 页面，如图 14.1 所示。
