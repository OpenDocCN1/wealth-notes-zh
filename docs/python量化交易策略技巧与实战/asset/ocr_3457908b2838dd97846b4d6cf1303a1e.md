图 12.18 中左边的箭头模拟神经元的输入信号，右边的箭头模拟神经元的输出信号。神经元主要做了两部分的工作：首先对输入信号进行综合，其次对综合后的信号进行处理，并得到输出信号。

信号综合常用的方法是 Sunderland 输入信号进行加权求和；信号处理常用的方法是通过 sigmoid 函数对信号进行处理。sigmoid 函数的表达式为 g(z) = 1/(1+e^(-z))，sigmoid 函数如图 12.19 所示。

![](bbox=[0.34, 0.215, 0.69, 0.39])

sigmoid 函数的处理结果和真实神经元的处理结果比较类似（sigmoid 函数值集中于 1 和 0，对应于神经元细胞的兴奋和不兴奋状态），而且 sigmoid 函数根据函数值可以很容易地得到导数值。
