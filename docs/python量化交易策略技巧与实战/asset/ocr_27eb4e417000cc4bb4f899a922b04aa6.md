```
if  表达式1
    语句1
elif 表达式2:
    语句2
else:
    语句3
```

if语句的执行具体如下：

如果“表达式1”为 True，将执行“语句1”块语句；如果“表达式1”为 False，将判断“表达式2”；如果“表达式2”为 True，将执行“语句2”块语句；如果“表达式2”为 False，将执行“语句3”块语句。

提醒：Python 中用 elif 代替了 else if，所以 if 语句的关键字为 if、elif、else。

另外，还要注意以下三点：

第一，每个条件后面要使用冒号（:），表示接下来是满足条件后要执行的语句块。

第二，使用缩进来划分语句块，相同缩进数的语句在一起组成一个语句块。

第三，在 Python 中没有 switch-case 语句。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python4-3.py”，然后输入如下代码：

```
age = int(input("请输入您的年龄： ")) #调用 input() 函数，并把函数返回值转化为整型
print("")                                   #打印一个空行
if age < 0:                                 #如果输入年龄小于 0，显示 “对不起，年龄不能小于 0！"
    print("对不起，年龄不能小于 0!")
elif age >0 and age<=6 :                  #如果输入年龄在 0~6，显示 “您好，您还是一名幼儿！"
    print("您好，您还是一名幼儿！")
elif age >6 and age<=11:                  #如果输入年龄在 7~11，显示 “您好，您还是一名儿童！"
    print("您好，您还是一名儿童！")
elif age > 11 and age<=15 :               #如果输入年龄在 12~15，显示 “您好，您还是一名少年！"
    print("您好，您还是一名少年！")
elif age > 15 and age<=25 :               #如果输入年龄在 16~25，显示 “您好，您是一名青年人！"
    print("您好，您是一名青年人！")
elif age > 25 and age<=65 :               #如果输入年龄在 26~65，显示 “您好，您是一名成年人！"
    print("您好，您是一名成年人！")
else:                                      #如果输入年龄大于 65，显示 “您好，您是一位老人！"
    print("您好，您是一位老人！")
```

单击菜单栏中的“Run”→“Run Module”命令或按键盘上的“F5”键，即可运行程序代码，并提醒你输入年龄，如果你输入 4，即可显示“您好，您还是一名幼儿！”；如果你输入 45，即可显示“您好，您是一名成年人！”。在这里输入 17，即可显示“您好，您是一名青年人！”，如图 4.3 所示。
