# 10.2 趋向指标函数运用技巧

趋向指标是投资者最容易在市场中获利的方法，也是股票、期货、外汇市场中著名格言“让利润充分增长，限制损失”的真实反映。

# 10.2.1 MACD 指标函数

MACD 指标，即平滑异同平均线。在 Python 量化交易策略中，MACD 指标的语法格式如下：

```
MACD(security_list, check_date, SHORT = 12, LONG = 26, MID = 9)
```

各项参数意义如下。

参数 security_list：股票列表，可以是一只股票，也可以是多只股票。

参数 check_date：要查询数据的日期。

参数 SHORT：用来设置快的指数移动平均线，默认为 12 天。

参数 LONG：用来设置慢的指数移动平均线，默认为 26 天。

参数 MID：用来设置离差平均值，默认为 9 天。

返回 DIFF、DEA 和 MACD 的值，返回类型为字典（dict）：键（key）为股票代码，值（value）为数据。

MACD 指标用法具体如下：

+   第一，DIFF、DEA 均为正，DIFF 向上突破 DEA 时，为买入信号；
第二，DIFF、DEA 均为负，DIFF 向下跌破 DEA 时，为卖出信号；
第三，DEA 线与 K 线发生背离时，为行情反转信号；
第四，分析 MACD 柱状线，由红变绿（由正变负）时，为卖出信号；由绿变红时，为买入信号。

> 提醒：DIFF 线，是指收盘价短期、长期指数平滑移动平均线间的差；DEA 线，是指 DIFF 线的 M 日指数平滑移动平均线；MACD 线，是指 DIFF 线与 DEA 线的差，用彩色柱状线表示。
