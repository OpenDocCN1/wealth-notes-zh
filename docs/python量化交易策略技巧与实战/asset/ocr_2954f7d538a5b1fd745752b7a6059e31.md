# 1）Bar 的概念

在一定时间段内的时间序列可以构成一根K线，单根K线被称为Bar。如果是一分钟内的Tick序列，即构成一根分钟K线，又称分钟Bar，如图11.8所示。如果是一天内的分钟序列，即构成一根日线K线，又称日线Bar，如图11.9所示。

提醒：Bar 就是价格在时间维度和空间维度上变化构成的数据单元。

# 2）频率详解

当选择“每天”频率时，算法在每根日线Bar上都会运行一次，即每天运行一次。

当选择“分钟”频率时，算法在每根分钟Bar上都会运行一次，即每分钟运行一次。
