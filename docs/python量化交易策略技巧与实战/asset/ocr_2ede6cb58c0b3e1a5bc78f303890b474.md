# 10.2.4 GDX 指标函数

GDX 指标，即鬼道线。GDX 指标的语法格式如下：

```
GDX(security_list, check_date, N = 30, M = 9)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N 和 M 分别表示统计的天数为 N 和 M。

返回济安线、压力线和支撑线的值，返回类型与 MACD 指标相同，这里不再赘述。

GDX 指标，是一种用技术手段和经验判断来决定买卖股票的方法。GDX 指标对趋势线做了平滑和修正处理，更精确地反映了股价运行规律，即当股价上升到压力线时，投资者就卖出股票；当股价下跌到支撑线时，投资者就进行相应的补进。

# GDX 指标函数实例

双击“量化择时”文件夹，单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“GDX 指标函数”，然后输入如下代码：

```
# 导入 technical_analysis 库
from jqdata.technical_analysis import *
# 定义股票代码
security_list1 = '000001.XSHE'
security_list2 = ['000001.XSHE', '000002.XSHE', '601211.XSHG']
# 计算并输出 security_list1 的 GDX 值
gdx_jax, gdx_ylix, gdx_zcx = GDX(security_list1, check_date='2017-01-04', N=30, M=9)
print(gdx_jax[security_list1])
print(gdx_ylix[security_list1])
print(gdx_zcx[security_list1])
# 输出 security_list2 的 GDX 值
gdx_jax, gdx_ylix, gdx_zcx = GDX(security_list2, check_date='2017-01-04', N=30, M=9)
for stock in security_list2:
    print(gdx_jax[stock])
    print(gdx_ylix[stock])
    print(gdx_zcx[stock])
```
