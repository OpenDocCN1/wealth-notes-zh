# 10.5.3 VR 指标函数

VR 指标，即成交量变异率。在 Python 量化交易策略中，VR 指标的语法格式如下：

```
VR(security_list, check_date, N=26, M=6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。

参数 N 和 M 分别表示统计的天数 N 和统计的天数 M。

返回 VR 和 MAVR 的值，返回类型与 MACD 指标相同，这里不再赘述。

VR 指标用法具体如下。

第一，VR>450，市场成交过热，应反向卖出。

第二，VR<40，市场成交低迷，行情冷淡，反而应反向买进。

第三，VR 由低档直接上升至 250，股价仍未遭受较大阻力，此为大行情的前兆。
