# 11.5.7 Benchmark Volatility（基准波动率）

Benchmark Volatility 用来测量基准的风险性，基准波动率越大代表基准风险越高。

Benchmark Volatility 的计算公式如下：

Benchmark Volatility = σₘ = √( 250/(n−1) Σᵢ₌₁ⁿ (rₘ − r̄ₘ)² )

各参数和意义如下：

rₘ 表示基准每日收益率；

r̄ₘ 表示基准每日收益率的平均值 = ln Σ i = ln rₘ；

n 表示基准执行天数。

在 “回测详情” 页面中，单击左侧列表框中的 “Benchmark Volatility” 选项，即可看到 MACD 指标量化交易策略的 “Benchmark Volatility” 信息，如图 11.23 所示。
