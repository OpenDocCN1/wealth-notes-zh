# 2.10 量化交易策略的模拟交易

模拟交易的数据与实盘数据完全同步，可以通过模拟交易进一步检验策略的有效性。

# 2.10.1 新建模拟交易并运行

单击导航栏中的“策略研究”→“模拟交易”命令，进入“模拟交易列表”页面，如图2.43所示。

![](bbox=[0.106, 0.283, 0.868, 0.466])

在模拟交易页面中，单击“新建模拟交易”按钮，弹出“新建模拟交易”对话框，如图 2.44 所示。

![](bbox=[0.328, 0.544, 0.646, 0.809])
