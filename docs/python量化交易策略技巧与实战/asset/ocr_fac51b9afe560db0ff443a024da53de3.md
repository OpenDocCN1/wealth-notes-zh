查理·芒格也强调要以“清单”的形式来进行投资判断，而这些都是与量化交易类似的原则。当你还不具备巴菲特和查理·芒格那样理性判断的功力时，了解量化交易的原则可以帮助你有效地提高当前投资策略的合理性。

实际上，有研究显示，整体而言基于客观性标准的交易策略，比人工判断的交易策略能创造更多超额收益。当然这并不是说让你完全放弃主观判断，毕竟有些东西是很难以量化的。但是，学习量化交易的策略可以帮助你重新思考现有投资策略的各个环节，帮助你判断哪些地方可以更具备客观性，从而减少主观判断产生的错误。同时，也可以让你更加明确，哪些环节是真正依赖于你的主观判断能力的。

# 3）降低交易成本

对机构投资者来说，除了前面对所有投资者都适用的两个原因，还有一个更直接的原因，那就是量化交易策略可以帮助机构投资者有效地降低交易成本。

对于拥有大量资金的机构投资者来说，自己的买单和卖单对市场的冲击产生的流动性成本是一项重要的交易成本。而量化交易的一个重要功能就是通过特定的算法有效地减少自己的买卖委托对市场产生的冲击，以降低自己的交易成本。

据统计，2018 年中国基金的平均周转率为 2.9 倍。假如交易成本平均降低 0.1 个百分点，就相当于多增加了 0.1%×2.9=0.29%的收益率。而在基金排行榜上，这可能意味着好几位排名的差异。实际上，如果策略得当的话，能降低的交易成本很可能不止 0.1 个百分点。
