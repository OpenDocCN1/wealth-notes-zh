# 10.5.2 VOL 指标函数

VOL 指标，即成交量指标。在 Python 量化交易策略中，VOL 指标的语法格式如下：

```
VOL(security_list, check_date, M1=5, M2=10)
```

各参数意义与 MACD 指标相同，这里不再赘述。

返回 VOL 和 MAVOL 的值，返回类型与 MACD 指标相同，这里不再赘述。

VOL 指标用法如下。

+   第一，成交量大，代表交投比较热，可界定为热门股。
第二，底部起涨点出现大成交量（成 handshake），代表攻击量。
第三，顶部地区出现大成交量（成 handshake），代表出货量。
第四，观察成交金额的变化，比观察成交手数更具意义，因为成交手数并未反应股价涨跌之后所应支出的实际金额。

# VOL 指标函数实例

双击“量化择时”文件夹，单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“VOL 指标函数”，然后输入如下代码：

```
#导入 technical_analysis 库
from jqllib.technical_analysis import *
# 定义股票池列表
security_list1 = ['000001.XSHE','000002.XSHE','601211.XSHG']
# 输出 security_list1 的 VOL 值
VOL1,MAVOL11,MAVOL12 = VOL(security_list1, check_date='2018-08-01', M1=5, M2=10)
for stock in security_list1:
    print(VOL1[stock])
    print(MAVOL11[stock])
    print(MAVOL12[stock])
```
