# 11.5.4 Sortino（索提诺比率）

Sortino 表示每承担一单位的下行风险，将获得多少超额回报。

Sortino 的计算公式如下：

Sortino = (R_p - R_f) / σ_pd

各参数和意义如下：

R_p 表示策略年化收益率；

R_f 表示无风险利率（默认值为 0.04）；

σ_pd 表示策略下行波动率。

在 “回测详情” 页面中，单击左侧列表框中的 “Sortino” 选项，即可看到 MACD 指标量化交易策略的 “Sortino” 信息，如图 11.20 所示。
