# 1）降低交易费用

算法交易的策略之一是将大单指令拆分为若干个小单指令渐次进入市场，这样就可以避免大量资金同时进入市场使交易价格和交易费用提高。所以，量化交易可以降低交易费用。这个策略的成功程度可以通过比较同一时期的平均购买价格与成交量加权平均价来衡量。

# 2）套利

典型的套利策略通常包含三四个金融资产，如根据外汇市场利率平价理论，国内债券的价格、以外币标价的债券价格、汇率现货及汇率远期合约价格之间将产生一定的关联。如果市场价格与该理论隐含的价格偏差较大，且超过其交易成本，则可以通过四笔交易来确保无风险利润。股指期货的期限套利也可以用算法交易来完成。

# 3）做市

做市就是在当前市场价格上挂一个限价卖单或在当前价格下挂一个限价买单，以便从买卖差价中获利。

# 1.3.4 各种套利交易

套利交易是指利用相关市场或相关电子合同之间的价差变化，在相关市场或相关电子合同上进行交易方向相反的交易，以期望价差发生变化而获利的交易行为。套利交易模式主要有四种，分别为股指期货套利、商品期货套利、统计套利和期权套利，如图 1.6 所示。

# 1）股指期货套利

股指期货套利，是指利用股指期货市场存在的不合理价格，同时参与股指期货与股票现货市场交易，或者同时进行不同期限、不同（但相近）类别股票指数合约交易，以赚取差价的行为。股指期货套利主要分三种，分别是期现套利、跨期套利和跨市套利。
