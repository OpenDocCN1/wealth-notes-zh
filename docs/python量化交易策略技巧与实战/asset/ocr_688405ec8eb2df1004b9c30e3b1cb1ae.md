```
MA(security_list, check_date, timeperiod=5)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 timeperiod 表示统计的天数。

返回 MA 的值，返回类型与 MACD 指标相同，这里不再赘述。

MA 指标用法具体如下：

+   第一，股价高于均线时，为强势；股价低于均线时，为弱势；
第二，均线向上上涨，具有助涨力道；均线向下下跌，具有助跌力道；
第三，两条以上均线向上交叉时，买入；
第四，两条以上均线向下交叉时，卖出；
第五，移动均线的信号经常落后股价时，若以 EXPMA、VMA 辅助，则该情况可以得到改善。
