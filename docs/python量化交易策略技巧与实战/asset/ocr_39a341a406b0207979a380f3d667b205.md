# 11.5.6 Volatility（策略波动率）

策略波动率用来测量策略的风险性，策略波动率越大代表策略风险越高。

Volatility 的计算公式如下：

Volatility = σₚ = √( 250/(n−1) Σᵢ₌₁ⁿ (rₚ − r̄ₚ)² )

各参数意义如下：

+   rₚ 表示策略每日收益率；
̄rₚ 表示策略每日收益率的平均值=ln Σ i=ln rₚ；
n 表示策略执行天数。

在 “回测详情” 页面中，单击左侧列表框中的 “Volatility” 选项，即可看到 MACD 指标量化交易策略的 “Volatility” 信息，如图 11.22 所示。
