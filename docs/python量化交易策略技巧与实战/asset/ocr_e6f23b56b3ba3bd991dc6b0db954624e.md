# 11.1 量化交易策略回测的流程

量化交易策略回测流程具体如下：

第一，利用 Python 编写好量化交易策略，选择要操作的股票池，实现 handle_data 函数。handle_data 函数每个单位时间会被调用一次，即如果按天回测，则每天调用一次；如果按分钟回测，则每分钟调用一次。

> 提醒：一个量化交易策略一般情况下包括 4 个函数，分别是初始化函数（initialize）、开盘前运行函数（before_market_open）、开盘时运行函数（market_open）、收盘后运行函数（after_market_close）。为了简化编写，一个简单的量化交易策略，只需有两个函数即可，一个是初始化函数，一个是 handle_data 函数。

第二，选定一个回测开始日期和结束日期，再选择初始资金、调仓间隔（每天还是每分钟），然后就可以开始回测了。

第三，通过选择的股票池和日期取得股票数据，然后每天或者每分钟调用一次 handle_data 函数。同时 handle_data 函数获取现金、持仓情况和股票在上一天或上一分钟的数据。在 handle_data 函数中，还可以调用其他函数获取任何几天的历史数据，然后投资者根据数据做出调仓决定。

第四，下单后，交易软件系统会根据接下来的实际交易情况处理订单。

第五，下单后，可以调用 get_open_orders 函数取得所有未完成的订单，调用 cancel_order 函数取消订单。

第六，可以在 handle_data 函数里面调用 record()函数记录某些数据，这样会以图表的形式显示在回测结果页面中。

第七，可以在任何时候调用 log.info/debug/warn/error 函数来打印一些日志。

第八，回测结束后，会画出收益和基准收益的曲线，列出每日持仓、每日交易和一系列风险数据。
