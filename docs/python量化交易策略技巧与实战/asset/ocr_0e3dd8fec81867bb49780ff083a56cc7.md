# 表 4.5 元组的函数名及意义

| 元组的函数名 | 意义 |
|---|---|
| len(tuple) | 元组元素个数 |
| max(tuple) | 返回元组元素最大值 |
| min(tuple) | 返回元组元素最小值 |
| tuple (seq) | 将列表转换为元组 |

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python4-16.py”，然后输入如下代码：

```
tuple1 = (5, 4, 1,12,36,99)
print("元组中元素的最大值: ",max(tuple1))
print("元组中元素的最小值: ",min(tuple1))
print("元组中元素的个数: ",len(tuple1))
print("把元组转换成列表，并显示: ",list(tuple1))
print("把列表转换为元组，并显示: ",tuple(list(tuple1)))
```

# 4.3.3 字典

从某种意义上来讲，字典和列表是相似的。字典使用的是（{}），列表使用的是（[]），元素的分隔符都是逗号（，）。不同的是列表的索引是从 0 开始的有序整数，并且不能重复；而字典的索引称为键，虽然字典中的键和列表中的索引一样是不可重复的，但键是元素。字典中元素的任意排列都不影响字典的使用。

字典的键，可以是数学、字符串、元组等，但一般用字符串来表示，键与键值之间用冒号（:）分开。创建一个字典，代码如下：

```
dict1 = {'姓名': '张平', '年龄': 12, '年级': '6', '学习成绩': '优'}
```
