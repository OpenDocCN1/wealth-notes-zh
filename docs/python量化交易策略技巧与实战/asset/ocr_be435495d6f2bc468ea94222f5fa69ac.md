# 9.2.2 营业收入环比增长率选股技巧

营业收入环比增长率＝（本期营业收入－上一期营业收入）÷上一期营业收入×100%。

需要注意的是，环比增长率是相对于上一期的数据，而同比增长率是相对于上一年度的同一期的数据。

# 营业收入环比增长率选股实例

成功登录 JoinQuant 聚宽量化交易平台后，单击导航栏中的“策略研究”→“研究环境”命令，打开研究环境页面。双击“量化选股”文件夹，然后单击“新建”→“Python 3”命令，新建一个 Python 3 文件，并将其命名为“营业收入环比增长率选股”，然后输入如下代码：

```
import pandas as pd
dataframe1 = get_fundamentals( query(indicator).filter(indicator.inc_revenue_annual > 900), date='2018-08-01')
dataframe1['code']
```

indicator 为财务指标数据表名；查询条件为营业收入环比增长率大于 900，即 indicator.inc_revenue_annual > 900；查询时间为 2018 年 8 月 1 日。需要注意的是，这里只显示选出的股票的代码。
