第二种情况：图 12.5 中同样有 A、B、C 3 个超平面，和第一种情况不同，这次 3 个超平面都很好地完成了分类，那么哪个是正确的超平面呢？

![](bbox=[0.36, 0.16, 0.68, 0.36])

图 12.5 第二种情况的超平面

对此，我们需要修改一下之前的描述：SVM 算法选择的是能更好地分类两种数据的决策边界。在这里可以看到，无论是星还是圆，它们到 C 的距离都是最远的。因此，C 就是我们要找的最佳决策边界，即正确的超平面。

提醒：为什么要选择边距更远的超平面？这是因为这样的超平面更稳健、容错率更高。如果选择 A 或 B，那么后期继续输入样本时，它们发生错误分类的可能性会更高。

第三种情况：如图 12.6 所示，试着用第二种情况的结论做出选择。

![](bbox=[0.36, 0.57, 0.68, 0.76])

图 12.6 第三种情况的超平面

也许你会选择 B，因为两类数据和它的边距离 B 更远。但是其中有个问题，就是 B 没有正确分类，而 A 正确分类了。那么在 SVM 算法中，正确分类和最大边距究竟哪个重要呢？很显然，SVM 算法首先考虑的是正确分类，其次才是优化数据到决策边界的距离。所以，第三种情况的正确超平面是 A，而不是 B。
