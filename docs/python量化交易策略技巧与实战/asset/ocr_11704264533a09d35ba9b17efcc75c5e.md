# 10.5.4 MASS 指标函数

MASS 指标，即梅斯线。在 Python 量化交易策略中，MASS 指标的语法格式如下：

```
MASS(security_list, check_date, N1=9, N2=25, M=6)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N1、N2 和 M 分别表示统计的天数 N1、统计的天数 N2 和统计的天数 M。

返回 MASS 和 MAMASS 的值，返回类型与 MACD 指标相同，这里不再赘述。

MASS 指标用法具体如下。

+   第一，MASS>27 后，随后又跌破 26.5，此时股价若呈上涨状态，应卖出。
第二，MASS>27 后，随后又跌破 26.5，此时股价若呈下跌状态，应买入。
第三，MASS<20 的行情，不宜进行投资。
