# 10.2.6 JS 指标函数

JS 指标，即加速线。JS 指标的语法格式如下：

```
JS(security_list, check_date, N = 5, M1 = 5, M2 = 10, M3 = 20)
```

其中，security_list 和 check_date 参数与 MACD 指标相同，这里不再赘述。参数 N1 和 M1、M2、M3 分别表示统计的天数为 N1 和 M1、M2、M3。

返回 JS、MAJS1、MAJS2 和 MAJS3 的值，返回类型与 MACD 指标相同，这里不再赘述。

JS 指标是衡量股价涨速的工具，JS 指标上升表明股价上升动力增加；JS 指标下降表明股价下降压力增加。
