# 10.3 反趋向指标函数运用技巧

反趋向指标，又称超买超卖型技术指标。对某种股票的过度买入称为超买，反之，对于某种股票的过度卖出则称为超卖。反趋向指标属于分析大势的一种技术分析指标，它的主要用途是，判断大势的涨跌形势，使股市潜在的趋势清楚地表现出来。

# 10.3.1 KD 指标函数

KD 指标，即随机指标。KD 指标的语法格式如下：

```
KD(security_list, check_date, N=9, M1=3, M2=3)
```

各项参数意义如下。

参数 security_list: 股票列表，可以是一只股票，也可是多只股票。

参数 check_date: 要查询数据的日期。

参数 N: 统计的天数为 N。

参数 M1: 统计的天数为 M1。

参数 M2: 统计的天数为 M2。

随机指标 KD 的返回值是 K 和 D 的值，是一个字典（dict）类型，其中键（key）为股票代码，值（value）为数据。

KD 指标用法具体如下。

第一，指标 > 80 时，回档概率大；指标 < 20 时，反弹概率大。

第二，K 在 20 左右向上交叉 D 时，为买入信号。

第三，K 在 80 左右向下交叉 D 时，为卖出信号。

提醒：KD 波动在 50 左右的任何信号，其作用都不大。

# KD 指标函数实例

双击“量化择时”文件夹，单击“新建” → “Python 3”命令，新建一个 Python 3 文件，并将其命名为“KD 指标函数”，然后输入如下代码：

```
# 导入 technical_analysis 库
from jqdata.technical_analysis import *
# 设定股票列表
security_list1 = ['000001.XSHE']
# 计算并输出 security_list1 的 KD 值
K1,D1 = KD(security_list1, check_date='2018-08-01', N=9, M1=3, M2=3)
```
