# 2.8 编写 Python 代码来创建量化交易策略

图 2.37 “选股总结”对话框

前面讲解了如何利用向导式策略生成器创建量化交易策略，下面讲解如何通过编写 Python 代码来创建量化交易策略。

单击导航栏中的“策略研究”→“策略列表”命令，进入策略列表页面，然后单击“新建策略”按钮，弹出“新建策略”菜单，如图 2.38 所示。

图 2.38 “新建策略”菜单

在“新建策略”菜单中包括股票策略、期货策略、融资融券、多因子策略、组合策略、场外基金模版，以及空白模板。新建策略即投资者自己编写 Python 代码来创建策略。

单击“股票策略”命令，就可以帮助建立一个股票策略，并看到该策略的基本代码，如导入库代码、初始化函数代码、开盘前运行函数代码、开盘时运行函数代码、收盘后运行函数代码，如图 2.39 所示。
