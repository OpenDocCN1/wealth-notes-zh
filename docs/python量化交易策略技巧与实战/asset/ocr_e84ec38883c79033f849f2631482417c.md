# 4.3 Python 的特征数据类型

Python 有 4 个特征数据类型，分别是列表、元组、字典、集合，下面将对其进行具体讲解。

# 4.3.1 列表

在 Python 中，是用中括号（[]）来解析列表的。列表中的元素可以是数学、字符串、列表、元组等。创建一个列表，只要把逗号分隔的不同的数据项使用中括号括起来即可，具体如下：

```
list1 = ["book", "desk", 2015, 2018]
list2 = [1, 2, 3, 4, 5]
list3 = ["x", "y", "z"]
```

可以使用下标索引来访问列表中的值，也可以.El用中括号的形式截取字符，还可以利用 for 循环语句来遍历列表中的值。

利用下标索引可以对列表的数据项进行修改或更新，也可以末使用 append()方法来添加列表项，还可以使用 del 语句来删除列表元素。

单击“开始”菜单按钮，打开“Python 3.7.1 Shell”窗口，然后单击菜单栏中的“File”→“New File”命令，创建一个 Python 文件，并将其命名为“Python4-13.py”，然后输入如下代码：

```
list1 = ["book", "desk",2015, 2018]

print("列表中的第一个值, list1[0]: ", list1[0])
```
