顺势指标 CCI 用法具体如下。

第一，CCI 为正值时，为多头市场；为负值时，为空头市场。

第二，常态行情时，CCI 波动于±100；强势行情时，CCI 会超出±100。

第三，CCI>100 时，买入；直到 CCI<100 时，卖出。

第四，CCI<-100 时，先卖出；直到 CCI>-100 时，再买入。
