# 13.3.4 因子的换手分析

换手分析，即换手率分析。因子 的换手率是在不同的时间周期下，观察因子各分位中个股的进出情况。例如，某因子第一分位持有的股票数量为 30 只，一天后有一只发生变动，则换手率为：1÷30×100%＝3.33%。

因子换手率分析的价值体现在两个方面，分别是因子稳定性的体现和衡量交易成本，如图 13.13 所示。
