另一个亟待解决的问题是，像 Z=X²+Y² 这样 的新特征是不是都得由我们手动设计？答案是不需要，SVM 算法中 有一种名为 kernel 的函数，它们能把低维输入映射进高维空间，把原本线性不可分的数据变为线性可分的数据，我们也称它们为核函数。

> 提示：核函数主要用于解决非线性分离问题。简而言之，它会自动执行一些非常复杂的数据转换，然 后根据你定义的标签或输出，找出分离数据的过程。

# 12.2.4 支持向量机（SVM）的优点

SVM 算法的优点有四项，具体如下。

+   - 第一，SVM 算法效果很好，分类边界清晰。\n- 第二，SVM 算法在高维空间中特别有效。\n- 第三，SVM 算法在空间维数大于样本数的情况下很有效。\n- 第四，SVM 算法使用的是决策函数中的一个训练点子集（支持向量），所以占用内存小，效率高。

# 12.2.5 支持向量机（SVM）的缺点

SVM 算法的缺点有三项，具体如下。

+   - 第一，如果数据量过大，或者训练时间过长，SVM 算法会表现不佳。\n- 第二，如果数据集内有大量噪声，SVM 算法效果将不好。\n- 第三，SVM 算法不直接计算概率估计，所以需要进行多次交叉验证，代价过高。
