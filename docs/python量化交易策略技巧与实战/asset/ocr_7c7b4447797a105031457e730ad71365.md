# 11.5.8 Max Drawdown ( 最大回撤 )

Max Drawdown 描述策略可能出现的最糟糕的情况，即最极端的亏损情况。

Max Drawdown 的计算公式如下：

Max Drawdown = Max( Pₓ − Pᵧ ) / Pₓ

其中，Pₓ, Pᵧ分别表示策略某日股票和现金的总价值。

在 “回测详情” 页面中，单击左侧列表框中的 “Max Drawdown” 选项，即可看到 MACD 指标量化交易策略的 “Max Drawdown” 信息，如图 11.24 所示。
