# 14.3 MACD 指标量化交易策略实战案例

MACD 指标是股市中最经典、最常用的技术指标。下面利用 MACD 指标来编写一个简单的量化交易策略，实现 DIFF、DEA 均为正，DIFF 向上突破 DEA 时，买入股票；DIFF、DEA 均为负，DIFF 向下跌破 DEA 时，卖出股票。
