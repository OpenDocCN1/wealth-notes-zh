# 5.2.1 自定义函数的定义

在 Python 中，自定义函数的规则如下：

+   第一，函数代码块以 def 关键词开头，后接函数标识符名称和圆括号（0）。
第二，任何传入参数和自变量必须放在圆括号内，圆括号内可以用于定义参数。
第三，函数的第一行语句可以选择性地使用文档字符串，以存放函数说明。
