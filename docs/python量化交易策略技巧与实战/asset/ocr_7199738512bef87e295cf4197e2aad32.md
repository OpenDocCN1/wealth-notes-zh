# 12.2.3 核函数

前面讲的都是在原始特征的维度上，能直接找到一条超平面将数据完美地分为成两类的情况，但如果找不到呢？这就要引入黑科技，即核函数。

如图 12.7 所示，该如何找超平面呢？

![](bbox=[0.315, 0.25, 0.658, 0.444])

图 12.7 找不到一条超平面将数据完美地分成两类情况

在图 12.7 中目前只有 X 和 Y 两个特征，为了分类，我们可以添加一个新特征，即 Z=X²+Y²，并绘制数据点在 X 轴和 Z 轴上的位置，如图 12.8 所示。

![](bbox=[0.317, 0.552, 0.655, 0.746])

图 12.8 绘制数据点在 X 轴和 Z 轴上的位置

数据点被“震起来”后，星和圆在 Z 轴上出现了一个清晰的决策边界，它在图 12.8 中表示为一条二维的线，这里有几个注意点：

+   第一，Z 的所有值都是正的，因为它是 X 和 Y 的平方和。

+   第二，在图 12.7 中，圈的分布比星更靠近坐标轴原点，这也是它们 Z 轴上的值较低的原因。
