# 3.10 真正的价值，是满足人的本性

人的痛苦，在于控制不了自己的人性的。您若控制不了自己的人性的，那么，就由能控制自己人性的人来控制您，您就会被消耗，您的生命能量就会被消耗，您的人性就会被人利用，结果就是您的资金以及生命的流逝。

简单地说，我为什么在《陈昌文方法 72 大营销系统》里单独开发一个形象营销系统？因为人性如此，人们喜欢美女，喜欢珠光宝气，喜欢帅哥，喜欢成功。所以，您必须注意自己的形象。您注意自己的形象，粉丝就买单；您不注意自己的形象，粉丝就不买单。商业，不过就是研究人性，研究人的本能。

高手，每句话、每个动作，都是针对人性去设计的。一切都必须是商业思维，一切都必须是现金思维。一切都必须变成商业，变成现金。变不成现金、商业，一切都是错误的。
