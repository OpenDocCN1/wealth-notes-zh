# 6.8 穷人周围一般都是穷人， 富人周围一般都是富人

穷人喜欢跟穷人呆在一起，并且他们会认为穷人跟富人都一样。富人则不然，他们知道，跟穷人呆久了，就会变穷。富人知道穷富圈子的价值。穷人没富过，不懂。

穷人周围一般都是穷人。上穷人的学校，做穷人的运动，读穷人的书，形成穷人固有的思维模式。

富人周围一般都是富人，做富人的运动，比如高尔夫，不到十岁，就带着他们打高尔夫，接触企业家，读管理类的书籍。形成富人固有的思维模式。

富人赚到钱后，不会搞丢自己的钱，不会交往坏人，浪费自己的钱。穷人赚到钱后，经常搞丢自己的钱，乱花钱。富人与成功的、积极向上的、聪明的人交往。穷人与消极的、堕落的、懒惰的人交往。
