# 4.3 成功，是反人性的

人穷，大多是因为自己聪明。一个人聪明了，人品往往会出问题。人品出了问题，这个钱就來不了，努力也没用。人越穷，就会越聪明，越自我，越出格，越不懂规矩，越见不得高山，越容不了人，这种人，就算再努力，也没有任何意义。

陈昌文老板社群里能赚钱的人，都是憨厚老实之人，他们懂得起码的规矩，他们心里有一杆秤。看似别人会赚钱，其实是别人心里有规矩，有礼仪，尊师重道而已。至少也要假装尊师重道啊。您装也得装像啊。社群里也有很多人，一直在顺着自己的性子搞，故而几年了，收入都不会增长，他也很努力。所以我基本不太喜欢聪明的人，有些人只是看似聪明而已。我只喜欢傻的、憨的、笨的，喜欢干活的人。我只喜欢那种谦虚的人。聪明的人，基本都不谦虚，赚几个小钱，自以为是，就啊瑟了，就开始欺师灭祖，得志猖狂。
