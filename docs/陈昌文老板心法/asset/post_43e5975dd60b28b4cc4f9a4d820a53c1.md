
# 第七章 老板心法之社群思维

一个会社群营销的人，一定可以改变自己的命运。——陈昌文

## 7.1 人必须干自己喜欢的事情，然后把这件事用商业经营的手法链接，建立一个商业正向循环

兴趣是最好的老师，要围绕兴趣接触人，接触事情。通过互联网的模式，搞一个大大的圈子。这里面就有很多的商业机会。不要老想着赚钱，而是专注一个兴趣点，把这个兴趣点扩散到整个互联网，圈到一大片粉丝，商业模式自然会出来。

一切只按自己的兴趣办事，一切只为自己的爱好。

浩然正气，全凭感觉，委屈自己毫无意义，生命变得没有意义，即便是为了财富、权力，都是没意义的事情。要自己感觉舒服才有意义。只为兴趣、爱好而生。一切凭着浩然正气去做事。

什么快乐干什么，不快乐的事情不要干，不快乐的人不要聊，不要浪费时间。然后把自己的快乐嫁接在商业上，这就是完美的人生。

人只有干自己喜欢的事情，才能从始而终，热火朝天，否则，这个人难，会断断续续的，会朝三暮四，见异思迁，不能形成复利效应。人必须干自己喜欢的事情，然后把这件事用商业经营的手法链接，建立一个商业正向循环，这样就能做大，做好、做强、做一辈子。

社交媒体时代、短视频时代，企业越做越小，一个人的销售力比一个公司、一个大公司都强大。个人品牌时代会到来。前面这些年，都是一些聪明人自己悟出了要搞个人品牌，靠着个人品牌赚到了很多钱。接下来的直播时代、短视频时代、社交媒体时代，将进入人都是个人品牌的时代。某几个网红，已经证明了这件事，这种模式成本低，利润高，以后，会有更多的企业家、创业者会采取这种低成本营销销售模式。

不要觉得自己的条件差。任何人的条件都不差，无论您是生活在偏僻农村，还是富贵城市，只要您利用您周围的一切，认认真真地去对待，您都会获得不错的回馈。某网红在大山里，照样赚很多，这就是不怨天。任何一件小事做好了，都能彻底改变您的命运，您别以为机会少，机会其实很多。比如，您玩好了您的手机，或者玩好了视频，或者直播，甚至文字。奇怪吧？别说没机会，每个人都拥有太多的机会，只是您并没有沉下心来做好您力所能及的这件小事。

任何人都有机会变成很厉害的人物，厨师可以，摄像师可以，种地也可以，写文章、做直播也可以。下学而上达，您得做好您手上的事情，上天才会给您更多的机会。您不愿意做好您手上的事情，您就想走向人生巅峰，迎娶白富美，大概您是痴心妄想。不想做好现在手上的小事，则一辈子不会再有其他机会。

努力提升自己的能力，钱就越来越多。不要担心自己穷，要去提升打造团队的能力、营销的能力、变现的能力。能力提升了，财富自然来了。没事了，闲着了，就去苦练自己的能力，演讲能力、写作能力、做视频的能力、哲学思辨能力，当然还有道德文章能力、尊师重道的能力、善良的能力。能力涨一分，名声会涨十分。这个世界上，没有多少真正下苦功夫提升自己能力的人，大多数人都在求虚名，所以，您若有务实提升自己能力的思想，您就会超过大多数人了。能力比吹牛重要，虚名不能让人成长，真正的修炼自己的能力才会成长。高手不断地修炼自己的能力，日日精进，实至名归，但也不是说不搞营销，不做流量了。要并驾齐驱，既修炼自己的能力，又疯狂搞流量。

流量对应虚名，而能力对应变现，两手都要抓，两手都要硬，必须完成这个工作。

功夫都在平时，平时下了苦功夫，有了真本事，遇到任何事情都不会慌张，包括什么经济危机，什么市场下跌，都无所谓得。平常下了苦功夫，余粮多着呢，几年不赚钱都无所谓，平常没有违法犯罪，也没人能找到您的漏洞，这才是企业家要修炼的。人这一生，确实选择大于努力，赛道不对，您再努力也就那样了。

好在互联网时代，您可以大面积宣传，也许一个小点，别人看不起的赛道，宣传下去，却可能有意想不到的收获。

但人并非有才华，有能力就能成功，还必须有规划、有节奏、按规掂量自己能吃多大的饼。若是不懂这些道理，即便是有很大的才华，也可能翻船。

何为千里马？能日日夜夜地去干，能按部就班地干，按自己的节奏、能力去干，锁定目标不放松地去干。这种人，即便是没有什么才华，也能走得很远，称其为千里马。人生是一个马拉松，您必须从一开始就明白，不到最后那一刻，就不能盖棺定论。猛一时不算猛，乱猛不算猛，一辈子拉长来看，您的成绩在哪里？这才是您要关注的，不谋全局者，不足以谋一域。

## 7.2 道多了，就无道了。走一个道，才能悟道

人这一辈子，选好了一个项目、一个人群，找到一群志同道合的人，就不要变了。一直干，干到天荒地老。使命不要变，手段、平台可以换。手段是灵活的，目标不要老是换。做流量的平台可以换。大多数人不愿意从一而终，总是觉得还有更好的项目，还有更好的捷径，结果换来换去，浪费了时间。要多想想，怎么把手上的事情做好，这个最实在。

何为战略家？不是研究未来做什么，而是研究现在做什么，才有未来。战略家，不是放弃现在，研究未来的人，而是把现在要做什么研究到极致的人。

我碰见一个企业家，他就是喜欢做现在的事情，他说，现在的事情做好了，自然延伸出来未来的盈利模式。现在没做好的人，无论他如何研究未来，就算真被他碰上了，他也没有实力去做。

人为什么喜欢换项目？因为人觉得现在我做不好，我换一个就能做好了，自己不愿意下苦功夫去死磕工作，不愿意把工作做到极致，总是想着别的地方更好。换一个新项目，又重复以上想法、动作。其实一个人的未来，是因为他现在的工作做好了，才有未来。这可以说是最快的道路。您在您熟悉的地方都干不好，凭什么换个不熟悉的地方，您就干好了？

一个企业，只要锁定主业，锁定自己擅长的，就不缺流量，不缺转化。合作伙伴都熟悉，自然是有钱赚的。没有可能没希望，没有可能做不出来。最怕的就是您二心二意。

我对陈昌文老板社群内部学员的要求就是，只要您坚持儒家思想：

- 1、做人踏踏实实；
- 2、一句假话不讲；
- 3、只认认真真地做项目；
- 4、搞流量，搞转化；
- 5、踏踏实实跟一个老师，从一而终；
- 6、不骄傲、谦虚、低调，一直拼命干活。

那么我们就是老干妈，我们就能给自己打下铁壁江山。我们就是华为，我们不需要上市，也不需要融资。在这里的人，都会发家致富，都会君临天下，而别人都不知道我们很厉害。这就是我们的哲学，我们衣锦蔽体。什么意思？里面穿绫罗绸缎，外面套一件破烂袍子。

营销哪里需要虚张声势？君子怕的就是名声太大，而没有实力。您们严格按照我这个价值观去干，富贵唾手可得。

一个人的事情，只能有一件，不可以有几件。网络上，到处都是生意，到处都有生财之道。您必须理解利出一孔，力出一孔。如果您能找到 2 个以上的地方都生利，证明您根本不理解聚焦。您这个人活得累，收入也不会怎么高。高明的人，就是只有一件事，一个谋生的本事。人的金钱是建立在自己的能力、圈子、人脉上，不要去找机会，实际上从来没有机会。您有多大的资源、能力，这本身就是您全部的机会，这是向内求的根本。一个真正聪明的人，是不会去进入自己不懂的领域，或涉足多个项目。

机会是要一直深入，才会抓到的。不深入，则抓不到机会。

我们是商人。商人是什么？商人就是找到最好的东西，改编一下，扔出去。一门深入，长期熏修。制心一处，无事不办。商人，是用最小的利益、最小的风险，获取最大的利益，疯狂的提升效率，然后又不违规，出单最重要。做生意，成本要小到极致。然后，在一个点上，不断地深挖，不断地输出，不断地引流，不断地变现。这才是高明的生意。

做好一件事、一个项目、一个点，别人再找您做什么，您就别做了。一辈子追求在一个点、一个项目、一群人、一个老师身上，走一个道。道多了，就无道了。走一个道，才能悟道。自己有一个项目了，就一直研究，深入自己的项目就行了，别成天找机会。重视短期利益，而不是长期利益，今天能干啥？活在当下最重要。能把现在的事情做好的人，才算高人，不要吹嘘未来，未来不可知。那些有未来的人，也不过是现在的事情做好了，做到极致了。锁定一个项目，不断地培养团队，就能赚钱。要彻底投入一个项目，要精气神、灵魂都投入进去，猛干，就能赚钱。如果您极度认真，就一定有利润，您会想到办法赚到很多钱的。

君子忧道不忧贫。找到一个道，坚定地去做好，去实现。而不是成天抱怨、不爽。不跟无关的人、不在自己道上的人多说一句话、一个字，不合作，只管实现自己的道。实现自己的道，则什么都有了。

时间线拉长，其实我估计最多就是一年，您就开始飞黄腾达了。在这个互联网社会，只要您找到一个道，不断地营销、变现，您大概率都会超越很多人。

只谋道，不谋利。在道中，就有利。不要跟蠢人讲什么利，也不要听蠢人的。自己懂道，有志向，去实现就行了。少跟社会上其他人交流，没什么意义，想想自己的道，去实现就行了，以免被引导偏了，变成了韭菜。

走大道，走简单的道，圣人说什么，我们就干什么，别找秘密，别找秘籍，人一辈子做好小事就行了。要听圣人的言论，圣人说什么就是什么，别反驳，别多嘴。做好小事，认认真真地去干，您自然就成长、成就。为什么您不相信简单、直白的大道理呢？说白了，还是您太聪明了。每天不听圣人的言论，是罪过，每天不按照圣人说的去做，老是以为有个什么特殊的秘籍，走个什么捷径，走个什么小道就会成功，这是愚蠢至极。

一心一意的做好自己的事情，什么都好了。认认真真搞自己的业务，认认真真卖自己的产品，认认真真优化自己现在的事情。搞聚焦系统，只做一件事，把一件事做透彻，什么都好了。只做一件事，才能做到精益求精、炉火纯青。做多了，什么都干不好。没有任何意义。在一个环节上下功夫，以工匠精神做好一个环节。不用找其他的机会，现在的事情做好，就是大机会。

人只应该关心自己的工作、自己的组织、自己的团队、自己的事情，做好自己的事情，才算高人。在自己的项目上，自己的组织里，抓住核心关键点，然后把这个核心关键点做到极致，不断地优化这个核心关键点，您就会一日千里。保护好自己，管理好自己，做好工作，就行了。不要去管别人的事情，做好自己手上的事情就行了。

要集中精力工作，而且把工作当成一种修行，您的工作就能做好，然后就有回报。当然高手是要不回报的，而只是日复一日的做好工作，因为工作本身就是幸福，就是回报。修行的本质，就是绝对唯一的追求一个信仰，修行修的就是专注力。专注在自己的工作上，自己现在这件事上。

专注力可以随时随地的培养，这样您就进入心流状态，极度认真的工作，非常愉快。如果您不培养您的专注力，那么，您慢慢的就变成一个精神废物了。专注力，是一个成功者的基本素质，希望您从现在开始就培养自己的专注力，进入心流状态。当您极度专注，进入心流状态的时候，您不想有成绩都难。（见《陈昌文方法72大营销系统》心流营销系统）

竭尽全力地工作，您就会感到工作很轻松，比如，我专注于写文章，我就不怕一会儿还有很多事情，我会发现我能轻松地征服我的工作。

人要集中精力去干，才能征服自己的工作，否则，就会怕工作。唯独有把工作做好了，做到极致了，超越所有同行了，成为行业领袖了，我们才能获得不可思议的回报。工作做不好的人，不配拥有美好的人生。

老板要让所有人工作，工作，不断地工作，而且要集中精力的工作，只有这样，才能致富，这是领导者的责任。人可以去玩，但是工作的时候，务必高度集中精力。在当前社会形式下，我还是希望您集中精力做互联网赚钱。时间过的很快，我希望您拼命工作，珍惜时间，而不是荒废了。

世界很大，但是那不属于您。属于您的，就是您的手能够摸到的地方，思维能够改变的地方。向内求，是王道思想。经营好您拥有的，您就会拥有天下；经营不好您拥有的，您拥有的就会失去，也发挥不出来效力。您去关心您没拥有的事情，纯粹是皇帝不急太监急。

## 7.3 一个会社群营销的人，一定可以改变自己的命运

一个会社群营销的人，一定可以改变自己的命运。

一个会社群营销的企业家，一定可以让企业在移动互联网时代、短视频时代获取成功。不会的，可能就享受不到社群营销的巨大红利了。其实很多企业，大型企业，有敏锐度的企业家，都应该实践社群营销，这个东西很厉害，可以打造网络品牌，营销。

在一个流量渠道上不断地死磕视频、直播、朋友圈营销，这是现代互联网社会的营销，社群营销是当下最凶猛的营销，没有之一。

社交媒体是用来包装自己个人品牌的。

视频平台、直播平台，是用来矩阵传播自己个人品牌的，这就是 20 年的生意模式。

互联网的生存之道，就是聚焦一个小项目，不断地做营销。当今企业的转型之路，就是社群营销、互联网营销，还有大多数人看不起的某种营销。

在垂直细分领域做到第一名，吸引很多被动流量，找到自己的优势。

比如，我是社群营销专家，我做社群营销很牛 B，然后就卖这个社群营销给企业家就行了，然后成为这个行业的第一名就行了。

比如，我专业做美女老板社群营销，专业做成功美女老板社群营销圈子，这个圈子非常小，但是深入专研，里面还是有一点点利润的。

垂直细分第一名，才具有品牌效应，也是个休老板、普通老板在当今互联网时代崛起的重要打法之一。一个行业太成熟了，也就没什么利润了。要选择一个打击面广的领域，也就是各位老板都需要的一个点，然后这个点又没少数人去关注，您去做好，然后做好这个点，为这个社会做贡献，做到极致，您的收益就不会低，比如社群营销教学。

任何一个项目里面都大有文章，就说社群营销这件事，您真的是细心研究，努力去做，一直去做这个环节，您名气就会越来越大，越来越具有品牌效应，赚到的钱会让令您自己大吃一惊。

要深入，而不是浅尝辄止，其实，就一个差异化营销，您天天讲，天天做，您会发现其中的奥秘真是博犬精深，玄妙精微。从您的语言到服饰、首饰、行为、视频、直播，都可以搞差异化营销的，就这个东西，就可以开一堂课程，专门讲。然后获取大量经济利益。思想对了，赚钱就没那么难了。

想拥有什么，您就踏踏实实地照着那个方向去做，然后，您就会拥有那些东西。不要急，一步步地去做，该来的，都会来。有些事情，您必须做，您若不做，后果会非常严重。比如，做网络营销，重要的就是精准粉丝，重要的就是垂直细分，而您不做这个，您逃避这个问题，那么您就没有收益，就会日日徒劳。每个老板都必须清楚，您必须在网络上做流量，必须做变现。不做这个动作，就会饿死。不做这个，只做其他无关紧要的事情，您就会一无所有，市场是检验真理的唯一标准。

有个大咖说，产品比营销重要，这是外行人的讲法，产品只是营销的一部分，营销包括什么？

1. 产品。
2. 价格。
3. 促销。
4. 渠道。

说产品比营销重要的人，属于对营销还没入门，对生意还没入门，犹如说手机上的屏幕比手机重要一样。
