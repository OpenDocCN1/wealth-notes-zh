# 4.6 陈昌文内部讲话：你明白营销是一门苦力活，你就能做好

现在社会跟古代社会不一样的，跟农业时代也不一样，每个人本质上都是智力劳动者。任何一个行业都需要智力的，连送快递都需要智力。所以说实际上我们每个人，无论你是一个人还是十个人，你都在做管理。管理本质上都在管理自己。你在我们群里，你也是。你的一言一行都对其他人有影响，所以你要给别人带去好的影响，积极的影响。你如果说了一些话，让别人不积极了，消极了，那么其实你这个人就是罪大恶极。

子路问政。子曰：“先之，劳之。”请益。曰：“无倦。”

就是说先之，先付费给你。先之，你先去干，你要以身作则。
