# 4.2 仳者，以财发身，这就是天下归心的模式

人为什么要尊师重道，这其实也在打造您的个人品牌。所有高手，都必须打造一个尊师重道的个人品牌，古代高手如此，现代高手如此。您也许没有多少能力、才华，您至少要打造一个尊师重道的个人品牌，这非常重要。憨厚而虔诚、尊师重道的个人品牌，就是一个金字招牌，将为您吸金无数。

这个世界上，也有很多有才华的人、牛人，现代社会就有几个这样的人，他们太蠢了，他们给自己打造的是欺师灭祖的个人品牌。这个个人品牌一出，则天下人日日骂，月月说，年年怼，他们的事业还能辉煌，还能发展？愚蠢得不可思议。我们每个老板既是学生，也是老师，您还带着一帮人呢，您表现出不尊师重道的个人品牌，则您下面的人什么想法呢？他们自然也跟着您学习欺师灭祖的样子。您的未来还会好吗？
