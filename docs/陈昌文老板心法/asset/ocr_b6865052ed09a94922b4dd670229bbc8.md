# ## 7.1 人必须干自己喜欢的事情，然后把这件事用商业经营的手法链接，建立一个商业正向循环

兴趣是最好的老师，要围绕兴趣接触人，接触事情。通过互联网的模式，搞一个大大的圈子。这里面就有很多的商业机会。不要老想着赚钱，而是专注一个兴趣点，把这个兴趣点扩散到整个互联网，圈到一大片粉丝，商业模式自然会出来。

一切只按自己的兴趣办事，一切只为自己的爱好。

浩然正气，全凭感觉，委屈自己毫无意义，生命变得没有意义，即便是为了财富、权力，都是没意义的事情。要自己感觉舒服才有意义。只为兴趣、爱好而生。一切凭着浩然正气去做事。

什么快乐干什么，不快乐的事情不要干，不快乐的人不要聊，不要浪费时间。然后把自己的快乐嫁接在商业上，这就是完美的人生。
