# 5.3 高手知道人世间什么最重要

1、权力。拥有权力，则可升官发财。权力是很多人的追求。求权者，比求软妹币高明。

2、软妹币。软妹币可以兑换一切，没错，可以兑换一切。不要告诉我，软妹币有些东西兑换不了，好像您没有软妹币可以兑换一样。软妹币唯一不可以兑换的，就是贫穷。

3、美色、帅气。没错，人生最大的捷径，不过是打扮而已。任何人，只要找个造型师，天天打扮，这个人的人生就会开挂。这是任何人，都可以触摸到的秘籍。只是，您们太懒了不愿意做。
