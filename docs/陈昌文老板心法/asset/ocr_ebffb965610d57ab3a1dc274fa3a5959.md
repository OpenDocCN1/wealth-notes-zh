# 5.1 任何事，高手只为利益而奋斗

如何才能成为牛 B 的人？成为成功的人？不要做没价值的事情。任何事，高手只为利益而奋斗。大多数人鄙视只为利益奋斗的人，于是，他们人生没了目标，玩游戏，看网页，变得越来越蠢。聪明人懂得一个道理，每时每刻，都是打造自己的自媒体账号，打造自己的团队，谈业务，不断地释放价值，粉丝越多，买单的人就越多。聪明人永远在搞营销。蠢人，浪费了自己的时间，然后堕落社会底层，还成天骂骂咧咧的。

何为聪明人？聪明人都是时时刻刻在给自己干活。

何为蠢人？蠢人就是他也知道他在干啥。

聪明人，总是会不断地帮助他人，帮的人多了，别人就帮他。

蠢人呢，总是在不断地得罪人，得罪的人多了，别人就联合起来搞他。所谓：“得道多助，失道寡助。”
