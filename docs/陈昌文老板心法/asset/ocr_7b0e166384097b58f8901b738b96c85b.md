# 2.3 巧言乱德，小不忍则乱大谋

隐恶扬善，我认为这个观点有很大的问题，要让恶的也让入明白，善良的当然我们要学。否则，很多人不知道这个社会是丛林社会，有很多坏人，他就会上当。大多数人的财富，就是被那些恶人给诓骗了。要知道有些人恶，要知道有些人善。分得清楚善恶，这个人才过好人生。我觉得，现在的问题，就是讲恶的太少，导致很多人成了被人割的韭菜。

有些人很会说话，巧言乱德，为达到目的，坑人也在所不惜。这种人，我们不要跟他们交流 说话。我们有时候善良，可能是为了帮助某些人，但某些人就借着您的善良，采取巧言乱德，进行糊弄您，给您造成损失。所以，不要跟喜欢把黑的说成白的，把坏的说成好的人交往。大家心里都有一杆秤，您糊弄谁呢？

有些人为了目的，不择手段，为了自己的利益，愿意坑害别人的利益，这种人，往往能说会道，巧舌如簧。他们糊您的，是无关紧要的；
