# 一切问题的本质，都是智力低下；一切税收，都是智商税

社会很有意思，我们不断地奋斗，最终是为了猎杀那些享受者。那些享受者现在很嚣张，要不了多久，就枯萎了。人类的进化，是因为有了思维，有了思想，这个东西，可以猎杀只靠基因生存的人。大家都苦过，不过是为了消化道以及欲望的舒展。这就是丛林社会。所有的思想，不过是为了最好的渔猎。

社会就是丛林法则，每个人都在玩拟态，残忍的吸引那些充满欲望、贪吃的人，然后，他们的生命就消失了。我们也不过是强强联合而已。愚蠢的思想造就愚蠢的人生；合乎天道的思想，造就强强联合的人生，而这些合乎天道的思想的基因，就会被留下来。其他的基因都进了消化道。人类的文明，只是让基因的消失变得优雅了点，变得文明了点。

## 金钱是什么？

金钱是一种游戏代币，跟《魔兽世界》《传奇》一样，跟梦幻西游一样。能玩游戏的人，能仔细体会游戏里的游戏币的人，就能体会现实世界中的金钱。游戏里，那是一个加速的金钱游戏而已。钱最终会变得没意义，最终会以物易物，或者用另一种资产代替。这是任何一个朝代与游戏的轮回。在一个游戏里，出规则来限制强者，这种游戏我从来没见过。而现实社会，却有人这样想，要限制强者，让弱者得利。这个社会，不过是一款角色扮演的大型在线游戏罢了。

一些人以为的资产，在我眼里分文不值。现金才是真理，甚至贬值的现金，有人偷的现金，才是真理。一项资产，没有流通性都是骗鬼的，我的智力低，我只能理解现金有流通性。而且，我搭建的体系，也只产生现金。员工是负债，工资开除意义不大，而且每个月都要发出去，这种商业模式非常愚蠢。至少对我来说是这样。我刚创业的时候，是靠着想象，学电影呢，学电视剧呢，这让我好大喜功，亏损了不少。真实的创业逻辑是靠体会的。为什么赚钱难？因为现实是要靠真正的智力推理。一个人不听任何人的话，而有头脑进行推理，这个人就可以成为一个不错的创业者了。

一个人的思想有漏洞，他赚到的钱，也会灰飞烟灭。

产品与服务的本质就是购买理由。任何人都不知道自己要干啥，要买啥。您让他干，他就干；您让他买，他就买。这就是人类社会。每个人都在缘木求鱼，每个人都在盲从。任何人都是机械的。觉者是少数。一切都是条件反射。

不同阶层，有不同阶层 的角度；

不同阶层，计算模式不一样。

本质是智力阶层不一样。显现的是权利、金钱、暴力阶层不一样。人与人沟通为什么那么难？因为宇宙中任何一个点都不重复。没有一个点，可能理解另一个点。除非此人成佛，是一个全息概念，则可能理解所有点。

每个人都在述说别人听不懂的真理。每个人都很委屈别人不明白自己。高手理解这个思维模型。于是，高手只管述说，别人听得懂，听不懂也没关系，只要您的声音够广阔，就能吸引到很多人来听，声音本来就可以同质化一些人，反正他们的脑袋不装这个，就装那个。您给他们装进去就行了。装的越多，您就越牛 B。怎么装？如何装？这是一个技术问题，是一个宣传问题。解决这个问题，就能解决金钱权利、暴力，一切资源问题。

### 1.1 人与人之间的差别，就是能量层级的差别

这个世界上，有小人，有坏人，我不是批评他，这没什么好批评的，因为每个人的能量等级不一样。有些人的能量等级低，他生来就是做坏人的。这个世界上为什么有坏人？就是因为天本来就要生坏人，就跟生蘑菇一样，有些蘑菇是垃圾蘑菇，有毒的、害人的。我们人也是这个样子，有些人他天生就是坏人，有些人天生就是只索取，不回报。他为什么只索取，不回报？因为他体寒，他本来就是阴邪之人，这个是他的性。

坏人的能 和好人的能 是不一样的。但坏人是不是就做不了大事？不是的。他也可以做大事，并不是说坏人就不会赚钱。坏人可以赚很多钱，也可以做很大的事情，而且也可以有很多追随者。看看历史，就知道了。一正一反，威力都很大，这个叫阴阳之道，一阴一阳之谓道。这些都是天机，社会宇宙的运行法则。

### 1.2 身心不二

人的心理、言语，是跟其生理基础相关的。有什么样的身体，就有什么样的精神与心理，就有什么样的能量级别、能量场，就讲什么样的话语。

身体差的人，心理差，事业差，讲出来的话就差。而讲话差，没格局、搞破坏的人，本质是其生理有病，故而心理、精神就有病，讲话就有病。生理有病，心理有病，写出来的文字、讲的课程，就有病，一体同源而已。这就是身心不二的核心。身体与心理、精神是合二为一的，也就是人与人之间是没办法相互改变，而只能是相互选择的。您没办法改变谁，除非他能疏通经络，改变身体状态。身体状态改变了，则心理状态改变，讲话模式就改变了。

那些意识层面出错的人，大概率都是心理、生理出错了。故而，修身最为重要。修身、齐家最为重要。人的身体修好了，则精神、言

谈、格局自然就出来了。阴寒之人，就是身体有毛病的人。他的父母家庭有毛病，父母没有能量，故而子女也没有能量。这子女就是阴寒的人，陌人与其相处就是有损于自己。而老板，需要是有格局之人，需要的是有太阳心态、有光芒的人。这跟阴暗小人是两种不同的人。

一个家庭的病来自于遗传，也来自于家族的思想体系 生活习惯的传承。所以，父母有的病，心理、生理、精神健康状态，大多会延续到子女身上。各位，不仅仅是基因的传递，也不仅仅是文化的传承，是全方位的传承。所以，不行的父母培养出来的孩子，要小心了。他笑起来，跟他爸爸差不多；他笑起来，跟他妈妈差不多。他的脸庞跟他父母差不多。接下来，惊悚的事情来了。他的病，心理 生理、精神的病，也跟他父母差不多，这就是全方位的传承。

真相让人惊悚。大多数人都不能靠近真相。我们讲我们观察、研究、推理的逻辑世界，就会有一大帮人感觉到恐怖。对不起，我只靠近真理，研究真相。其他的一切，我不喜欢。我必须研究真相，尊重真理，学以洞身。

您是佛，才到我们这里来，叫万佛朝宗。您是高人，才到我们群里来；您是牛人，才到我们这里来。不是说您是个能量极低的阴寒之人，我来服务您。我不与您链接的。

您是什么角色？您是神，您就进到我们这个圈子里，我们神交；您是仙，您就进到我们这个圈子里，我们仙交；您是圣人，我们就圣交；您是君子，我们就君交；您是贤人，我们就贤交。您是阴人，您不要跟我们交，因为杂交过后品种不好，对吧？

所以营销观念要讲明白，您这一辈子就会顺得不得了。您赚钱也顺，做事也顺，顺得不得了。您把这个用到谈情说爱当中，您交到的人都会特别的好。这个需要智慧，不要老是自我感动。拒绝某些人的钱，才能赚大钱。

玄学不是比哲学更厉害，而是有些人听起来觉得玄，但听得懂的人听起来一点都不玄。听不懂，就觉得有点玄。玄之又玄，众妙之门。

### 1.4 价值观营销，吸引到的是对应能量等级的人

什么是价值观营销？就是我们跟人交流的方式是这样的：我的价值观是这样、这样的，您认可吗？而且我们永远是这样的，才能获得价值观营销的复利效应（见《陈昌文方法 72 大营销系统》关于价值观营销系统和复利营销系统的篇章）。儒家思想是价值观，营销方法也是价值观。就像乔布斯一样，他做“苹果”就是要与众不同，改变世界。您是追求的与众不同，改变世界，OK，您跟我是一伙的，您买“苹果”；您不是，OK，您不要买“苹果”。

少则得，多则惑。您老是想把什么都说服了，多则惑。古人是真智慧啊，大家都能把这些东西搞明白，那真的是不得了。这个都是顺水推舟的大道，就是说赚钱是不需要费力的，不需要出力的。出力、

费力，他就不赚钱了。就是说您做的不对，您说服别人这件事情特别累， 您就赚不到钱，而且还会赔本。我的态度是，我不说服您的，您爱听 不听。

这是君子之道，圣人之道。君子之交淡若水。小人之道路是去舔 别人，承诺别人，把别人糊弄进来。君子之道是平淡相交，好坏自己 承担。道义相交就是好坏自己承担，您不要跟我扯犊子，但是这个道 还不够高，更高的是佛祖之道。什么叫佛祖之道？就是您来送我钱， 叫香火钱。您免费赠送我的，无偿赠送我的。

这个就象商鞅去找秦孝公一样，传了他几个道，帝道、王道、霸 道、强道。这个秦孝公他听不懂啊，讲帝道我不听。什么叫帝道、王道、 霸道？滚。老子要当强盗。好，商鞅就给他上强道。商鞅这个人也是 您要什么，我就给您上什么菜，反正老子的菜非常多。这个人是特别 的厉害。

我们在外面讲课，是为了吸引同频的人，不是为了教谁，也不是 为了改变谁。这是最深刻的道家思想。我们收人是您爱我吗？您爱我， 才来；您不爱我，就不要来。人，往外面推，则人越推越多。反之， 越拉越少。您真的优秀，就一定有很多人给您付费。我的书籍里面的 东西，您拿过来用就行了，您不优秀也没有关系，书籍优秀就行了。 这叫搬运系统，这叫照本宣科系统，这叫听话照做执行系统。
