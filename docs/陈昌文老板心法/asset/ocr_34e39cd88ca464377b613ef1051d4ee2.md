# 4.1 陈昌文老板社群四句口诀

一个正常人，合于道的人，活在世界上是舒服、喜悦的，吃饭、睡觉、干活，都感觉到身体舒服。如果您感觉不到舒服，不会珍惜、享受您的生命，则，证明您不在道中，您这个人活得有问题。别着急，大多数人都有问题，能达到这个境界的是极少数人。不过也很容易，起居有常，饮食有节，自然就做到了。如果能锻炼身体，要不了几天，您就进入这个道。如果您能尊师重道，孝敬父母，友爱同学，那您就更厉害了。不过难。您想生活、身体、身心灵都爽吗？想的话，就按照这个做吧。大部分人一辈子也体会不到愉悦的活着。
