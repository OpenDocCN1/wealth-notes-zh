# ### 7.3 一个会社群营销的人，
一定可以改变自己的命运

一个会社群营销的人，一定可以改变自己的命运。

一个会社群营销的企业家，一定可以让企业在移动互联网时代、短视频时代获取成功。不会的，可能就享受不到社群营销的巨大红利了。其实很多企业，大型企业，有敏锐度的企业家，都应该实践社群营销，这个东西很厉害，可以打造网络品牌，营销。

在一个流量渠道上不断地死磕视频、直播、朋友圈营销，这是现代互联网社会的营销，社群营销是当下最凶猛的营销，没有之一。

社交媒体是用来包装自己个人品牌的。

视频平台、直播平台，是用来矩阵传播自己个人品牌的，这就是 20 年的生意模式。
