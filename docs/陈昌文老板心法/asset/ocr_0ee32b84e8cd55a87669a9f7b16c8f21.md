你都不干，人家都不会干。但是每个人有分工，这个社会不可能所有人都去送快递，不可能所有人都去开饭店，也不可能所有人都去玩抖音，其他事情不干了。也不可能所有人都去搞制造业，也不可能所有人都搞教育，这是有分工的。组织有分工，社会有社会的分工，我们也是一个小组织，个人有个人的分工，但是你也也要身体力行的让别人知道你在干活。

自己要努力干，还要让别人知道。为什么？因为我们要劳之，我们要教育别人努力干活，就这两招。

+   第一招叫自己努力干活，

+   第二招叫别人努力干活。

只要别人努力干活，他对你就有好处。很多人不理解，你看我们是做社群的。那么服装厂努力干活，他对我们也是有好处的，衣服会变得便宜。农民努力干活，他对我们也是有好处的，食物也会变得便宜。社会会变得更美好。你千万不要以为别人干活跟你无关。
