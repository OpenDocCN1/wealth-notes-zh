# ## 6.1 穷人的思维模式是打工，富人的思维模式是投资

穷人和中产阶级为钱而工作，富人让钱为他们工作。

穷人的思维模式，是为钱工作，为别人工作。穷人的工作模式是，为工资工作，为老板工作，为小钱工作，为短时间的钱工作。穷人的模式是打工，埋怨。穷人保守着自己的工作，天天盯着工资，只知道挣小钱，只知道存钱、花钱。穷人被失去金钱的恐惧，被情感牵引。穷人的情绪、感情左右了自己的人生。他们怕自己独立去做项目，于是他们只能获得一份工资。

富人的思维模式是，让钱为自己工作，打造一个赚钱的系统，打造一个赚钱的项目。富人的工作模式是，为自己工作，为未来工作，让人跟着自己一起做项目，让钱为自己工作，给别人发钱，让别人为自己工作。富人以只能拿一份工资为耻辱，立定志向，必须自己做事业，绝对不拿工资，哪怕饿死。
