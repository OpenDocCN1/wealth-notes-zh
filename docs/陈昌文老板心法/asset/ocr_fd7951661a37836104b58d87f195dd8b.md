# ## 6.3 穷人用钱买没用的东西，富人用钱买资产

越穷，消耗越大。越富，消耗越小。

穷人用钱买没用的东西，消费了，就消费了，就没有了。富人的钱，是用来投资的，富人购买的是资产，资产产生现金流，是增值的。最重要的资产，是先进的思维模式。

穷人喜欢买奢侈品，看了电视剧、电影，以买奢侈品为荣。奢侈品最大的消费者，就是这些无脑穷人。富人则不然，富人看这些喜欢买奢侈品的穷人，跟看白痴一样，不过继续洗脑他们，让他们的虚荣心大增，继续买这些毫无意义的奢侈品。富人头脑清醒，知道什么是应该买的，知道在什么时间点、资金应该投入到什么地方。到最后，实在是富得没办法了，不乱花，也不知道干啥了，乱花极少一部分资产去买点奢侈品。而穷人呢？从一开始，就把资金投入到虚荣心上面，把自己的未来都变成了奢侈品。一个小年轻，习惯性购买奢侈品，只能证明其智力低。现在有一群人，天天就知道旅游，大吃大喝，喜欢
