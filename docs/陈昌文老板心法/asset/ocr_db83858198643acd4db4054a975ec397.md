# ### 1.3 老板，是需要能量等级高的人

老板，是需要能量等级高的人。比如，陈昌文老板读书会、陈昌文老板社群，也只收阳气重、身体好的人。阳气重的人更阳光，更愿意付出，更努力，积极向上。这是一种定位，不是什么人都收。只对接神人，只对接天生能量强的人。上帝的归上帝，凯撒的归凯撒。您想做个好人，但最终您会发现，有些人的属性就是恶狼、猛虎、毒蛇、黑洞。您拯救不了他们，您也做不了地藏王菩萨。或许宇宙就是同频的人适合在一起，物以类聚，人以群分。

如果您服务错了对象，则您的脸色，以及五脏六腑都会不舒服，而且没什么财运，人也会越来越倒霉。所以不要链接低能量的阴人，否则您的能量就会越来越低。要链接高人，比我们更厉害的人，我们的能量就会不断地增强。任何跟我们做业务链接的人，必须是真心实意的人，必须是高尚的人，必须是好人。
