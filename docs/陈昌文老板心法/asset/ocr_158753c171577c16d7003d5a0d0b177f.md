# 3.7 宿命是人知道差距后，而不努力去改变

变成一个神的唯一方法，就是工作，工作，还是工作。

比如，搞流量，变现，陈昌文老板社群里的知识、文化，您拿去卖，换成钱，您就是神；换不成钱，您狗 P 不是。您表达对了就行了。随便您怎么表达，这里面有金子，自然有人能看见。金子这玩意儿儿，不在乎花纹，不在乎形状，只要是金子就行了。陈昌文方法、儒家思想，这东西就是好东西，总有人识货。我们只有一个卖点，锁定老板、企业家，锁定社群头子、微商头子。我们的所有语言系统，只锁定社会上的成功者。只有成功者，才能理解我们社群的价值、书籍的价值。只有本来赚钱就厉害的人，才会喜欢我们。

喜欢加入高质量社群的，都是些高质量的人。普通人不愿意付费学习，所以，普通人的命运越来越差。只帮老虎长翅膀，不帮老鼠吃皇粮。价格是区分人群的最好砝码。

人的精力是用来赚钱的，也就是用来搞业务，搞流量，搞变现的。
