# 5.4 高明的人换阶层

所有的事情，都是升级圈子而已。

什么人最有财富，我们就用什么人的思维模式来过日子。思维模式、思想，决定一切。思想 + 思维模式，最具有价值。大部分人不这个道理。真正的高手，是修炼内功，内功精深，然后拈花飞叶，皆可伤人。高手是不需要从底层往上爬的。
