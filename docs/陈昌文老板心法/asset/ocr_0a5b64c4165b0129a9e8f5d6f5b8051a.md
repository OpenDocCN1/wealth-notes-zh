# 1.2 身心不二

人的心理、言语，是跟其生理基础相关的。有什么样的身体，就有什么样的精神与心理，就有什么样的能量级别、能量场，就讲什么样的话语。

身体差的人，心理差，事业差，讲出来的话就差。而讲话差，没格局、搞破坏的人，本质是其生理有病，故而心理、精神就有病，讲话就有病。生理有病，心理有病，写出来的文字、讲的课程，就有病，一体同源而已。这就是身心不二的核心。身体与心理、精神是合二为一的，也就是人与人之间是没办法相互改变，而只能是相互选择的。您没办法改变谁，除非他能疏通经络，改变身体状态。身体状态改变了，则心理状态改变，讲话模式就改变了。
