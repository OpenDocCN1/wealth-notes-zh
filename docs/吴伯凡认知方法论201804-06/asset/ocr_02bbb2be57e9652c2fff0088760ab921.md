我相信不少朋友都会给出一个答案：16。而且最有意思的是，如果有人在旁边说“你为什么要填16呢？”你会反问“难道不是吗？”

但问题是，这个模式也是错的。

大家再仔细看一下第三行，不是9、10、11、12，而是9、11、10、12——我之所以会忽略这么一个微小但极其关键的差异，是因为你既有的模式不倚索形生成那判断，已经在规范你的感知了。

# 每一个人的世界都是自定义的世界

一代又一代的哲学家都提到过类似这样的一個判断：我们对世界的认知并不是世界本身的样子，而是我们把自己的认知模式投射到世界，对世界做了一种整理。

打个比喻，世界就像一堆书，你自带的分类法把这些书进行了分类，你看到的世界是由你自己建构出来的世界。

1000个读者有1000个哈姆雷特，1000个人就有1000个世界，每一个人的世界都是他自定义的世界。当你对世界下判断、表述你看到的世界的时候，你表述的不是世界本身，而是你的世界观。

最有意思的是，当我们把我们的思维模式投射到客观世界的时候，是在一瞬间自然而然发生的，我们甚至毫无觉察。所以我们会觉得，不是我们把自己的模式投射到世界，而是世界把它的样子呈现给了我们。

日常生活中，我们常说要耐心地聆听别人对某个事情的表达，因为重要的不是听他告诉你世界是什么样子的，而是在他对世界的述说中，已经悄悄地把他的世界观和盘托出了。

每个人对一件事情、一个人的评价，其实跟你要评价的人或事情关系并不大——他说的是他自己。

《小马过河》这个寓言就能帮我们明白这一点：这条河是什么样子的，不能简单地只让结论，还要看这个结论是谁说的——松鼠说的河和老牛说的河，是不一样的一条河。

# 思维模式左右着我们

回到我们今天的数字游戏。

在看到这些数字，同时给出答案的时候，你和这个图的关系不是没有，但关系更密切的是你和你自己。

如果你给出了16这个答案，首先意味着你给出了一个错误的答案，其次是你还非常认可这个答案，在别人不同意这个答案的时候，还很不服气，觉得很委屈。原因是什么？

你是在捍卫你的立场，或者说，你被感染的某种思维模式在捍卫它自己。

就像我们感冒打喷嚏的时候，并不是你在打喷嚏、你想打喷嚏，而是你自带的病毒让你不得已打喷嚏。比如在一个重要的场合，你肯定知道不应该流鼻涕、消眼泪、打喷嚏，但是你控制不住，因为你已经感染了病毒。

思维模式左右着我们，而我们常常不自知，以为那就是我们自己。

你不是你的思维模式，就像一个手机或者一台电脑，它装上什么样的软件，就怎么运行。你不能说，这个电脑或者手机就是这样的。

如果你想改变这台电脑或者手机，就重装系统或者卸载一些软件，装上新的软件——如果不这么做，它就还是同一台电脑或者手机。

# 不堕入障碍

大家都很聪明，我相信给出16这个答案的人并不多，那就祝贺你越过了一个很可能掉进去的陷阱。

所谓优势、成功，就是能够不断地绕过陷阱。

优势从来不是不遇到陷阱的能力，而是绕过陷阱的能力。最重要的优势是，不是你有意绕过陷阱，而是你的某些能力跟这个陷阱没有发生关系。

有一本基督教灵修学的书里有这么一句话：当你遇到障碍的时候，说明你跟这个障碍是有缘的。

但有些人跟某些障碍是无缘的，比如遇到一条大河，你过不去，但是是雄鹰对于这条河是没有感觉的，因为大河对它不构成障碍。真正的认知优势，是不堕入那些很多人都觉得是障碍的障碍。

# 显而易见的答案一定不是答案

在这个数字游戏里，有些人一上来就不会想到16这个答案，因为他对自己有个警醒：他始终意识到，自己所看到的这个世界可能不是一个真实的世界，至少不是唯一的世界。这种人似乎天生就具有一种识别漏洞的能力，或者说，他们对陷阱有一种天然的警晕意识。

英特尔的前CEO安迪·格鲁夫讲他偷渡经历的时候说，“在偷渡的过程中，只要一碰到顺利的时候，我就会特别的警醒，反而在特别困难的时候，觉得比较安心，心里充满了安全感。”因为一旦顺利起来，他就会本能地想到“是不是已经有人知道我们的计划了？我们是不是正在顺利地绕过一个小陷阱，以便顺利掉进那个大陷阱里去呢？”

这就像在梦里，有的人知道自己在做梦，能够对当前的情况有一个识别和警醒，他能找到通向另外一个世界的秘密通道，尽管它很狭窄，很不显眼。这个通道通常叫“虫洞”。

“虫洞”，简单地说，就是对于缺乏认知和辨识能力的人来说，万万不可能的一个路径。而对于有认知和辨识能力的人来说，“虫洞”又是一条捷径，甚至能让它从这个宇宙穿越到那个宇宙，从这个时空穿越到那个时空。

能够找到这个数字游戏正确答案的人，是避开了那些显而易见的陷阱的人，或者对那些上来就可能虏获人的病毒具有免疫能力的某些人。他们本能就知道，显而易见的答案一定不是答案，显而易见的战略一定不是战略。只有这样，才可能玩接下来的游戏。

而掉进16这个陷阱的人，并不一定就没有计算和观察能力。但所谓失败，就是不再有机会。

我在《伯凡·日知录》里讲过“明局&暗局”，你首先要看一看，这个所谓明局的背后到底是什么暗局：这些数字之间的关系到底是什么，出题人的真实意图是什么，要问的问题是什么——你连问的问题都不知道，怎么能找到一个正确的答案？

德鲁克说，一个领导者如果只有一个能力的话，那就是提问的能力——提正确问题的能力，是让我们避免掉进陷阱的一个很重要的前提条件。

这并不是一个特别复杂的数学题，就是一个数字游戏，我们以它为案例，是想从解决问题的过程中让大家感受到“什么是有效的认知”“你的认知之所以无效是因为什么”。秘密越来越多，奥妙越来越多，疑问也会越来越多。
