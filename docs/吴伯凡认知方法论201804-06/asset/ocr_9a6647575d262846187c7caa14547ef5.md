# 007 | 所有物种都是残障者

这是我们第一模块第二单元的第三节课。

上节课讲到的“蓝黑党和白金党之争”，让我想起了平常争论中的一句非常尖刻的话：你怎么能活到今天呢？——这是我们觉得一个人不可理喻的时候，会说的一句很刻薄的话。

这句话本来是朱元璋说的。有一个朱元璋认为愚不可及的人，在他眼里这个人是“投降也得杀，不投降也得杀”。在这个人投降以后，请求朱元璋说，“能不能不杀我？”朱元璋觉得这个人简直蠢到家了，就说了这句话，“你怎么能活到今天呢？”潜台词是，这点局势你都看不出来，你怎么能活到今天呢！

这个故事里隐含着一个大自然的法则，或者说进化论的法则：

任何物种都是有缺陷的，如果一个物种的缺陷相对于环境会形成致命障碍，那这个物种就不存在了；如果一个物种活了下来，那么一定是因其它的缺陷不足以妨碍它的生存。

# 不足以妨碍物种生存的缺陷

我们回过头来看“蓝黑党和白金党之争”。人的视觉为什么有这样的差别呢？原因很简单：这样的差别不妨碍这个物种的生存。
