# 005 | 认知越狱与双环学习

上周我们围绕着“子宫”这个关键词，给大家建立了一个认知升级的心理基础，那就是想要认知升级，就要有勇气拥抱痛苦。本周是课程的第二周，也就是预备课程的最后一周，下周开始，我们就将进入第一模块的学习。

本周，我们要进入一个新的话题：什么是思维越狱。

前不久，我和一个非常狂热的认知升级者聊了几句话，能感受到他确实对“让自己的认知升级”有一种强烈的渴望。

我：看了罗胖的跨年演讲，你印象最深的是什么？

他：老实说，好多东西现在都有点儿忘了，但有一个东西我一直忘不了，就是屏幕上有一个阿拉伯数字8，不停地在那里循环，不停地在转啊转啊。

![](bbox=[0.16, 0.68, 0.97, 0.78])

这个屏幕上不停旋转的8，说的其实是一种学习的状态：我们的学习分为“单环学习”和“双环学习”。

# 1. 单环学习

“单环学习”是说，你已经逐渐形成了一个认知框架，然后你会寻找各种各样的证据和理论，不断丰富这个认知框架，使你的知识变得越来越丰富。一旦遇到问题，你就能够对问题有一种敏锐的把握，即刻用你现有的这种思维方式来识别眼前碰到的問題，从而寻求解决之道。
