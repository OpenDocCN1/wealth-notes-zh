第7天的预备课程，我们接着昨天的数字游戏继续说。

昨天数字游戏的答案，相信很多同学都算出来了，是18。

得出正确答案的关键，是想明白出题人要问的问题是什么。正确的问题生成之前，答案是不存在的。

回顾一下我们这些天讲的内容，就会对认知状态的母体、子宫等等的特性有了一个基本的认知：所谓子宫、母体，就是没有问题、让你提不出问题、不成为问题的地方，你没有任何要解决的问题，你的认知就是0。

# 什么是Matrix?

在《黑客帝国》( Matrix)这部电影里有一个细节，Trinity，也就是那个叫“三位一体”的女孩儿，把尼奥带到了一个类似于夜总会的地方，在他耳边说：

> "什么是Matrix? 正是这个问题驱使着我们。我们之所以会认知，是因为你隐约约看到了不对劲，这个不对劲就集中在Matrix上。"

这就回到了我们早该跟大家交代的一个问题：什么是Matrix?

Matrix有两个意思：

+   一个是母体、子宫，或者说是一个让所有问题都不成为问题的地方；
另一个是“矩阵”，也是数学上的概念。

所谓“矩阵”，是由两个维度构成的一个格局。有一种管理方式叫“矩阵式管理”，意味着用两条线来进行管理。

“矩阵”是在线性的方式的反面，或者说，是你在现有这个维度之外又有了一个新的维度，而不是跟已有维度平行或者重合。

Matrix指子宫，“不成为问题的问题”的时候，就是一个平行的、单维的世界。与此同时，Matrix也是一个矩阵。

我们会注意到一个事实，《黑客帝国》里的尼奥本来也不叫尼奥，他在母体世界里的名字叫Mr. Anderson，安德森先生。当他是安德森的时候，他就是一个正常上班工作的人，就是普通人看到的有志青年安德森先生。

但是，母体的管理者、机器人们特工史密斯发现，安德森先生还有一个身份：所有涉及到计算机犯罪的问题，安德森先生全都参与了——他一直在追踪一个问题：他生活着的这个世界背后是什么东西在掌管？

在母体的世界里，安德森先生是极少数意识到这是一个程序化世界的人。普通人因为不知道，而幸福、快乐、单向度地生活着。但尼奥到达了这个认知，所以他既是安德森，也是尼奥，他是一个矩阵——只有到达了这样一种状态，他才可能从这个舒服、平和、非常正常的生活里逃离出来。

# 庄家&散户

我们用一些简单的概念来让大家更清楚地认识这种状况。

如果你炒过股，你就了解，这个世界上 dauert 两种人：散户和庄家。

散户：在母体里不自知的人，他时刻刻在被操纵，但是自己根本不知道。

庄家：一方面，他是玩家，是跟广大散户打成一片的人；另一方面，他是一个Matrix，是一个矩阵，跟散户们完全不一样——他是制定规则的人，让散户舒舒服服、安安逸逸、心甘情愿地被套牢，被卖了还要帮他数钱。

庄家就是“非常得意地看着这群不知道悲哀的人们（散户）”的那种玩家。散户和庄家的最根本的差别就是认知上的差别，他们一个是线性的，一个是矩阵的。

# 苏格拉底的故事

乔布斯曾经说过“我愿意用我所有的财富获得一个机会——与苏格拉底交谈一个下午。”

当代哲学家认为《黑客帝国》( Matrix) 这个电影讲的其实是一个关于苏格拉底的故事。

苏格拉底从一个角度来说，就是一个平常人，他在雅典既不是大官，也不是贵族。据说他整天在街上向大家问一些问题，永远在提问问题，然后通过提问，让你把杂散的思维聚焦在一些你必须关注的问题上。

苏格拉底的提问还有一个特点——不给你答案，只让你直面一个个问题，然后自己去得出一个你会得出的结论。

苏格拉底的提问叫“辩证法”——这个词我们太熟悉了，但往往忘了它本来含义：通过辩论来证明一个东西。

如果乔布斯真有机会借助时光机器，用他的财富换取见苏格拉底一面的机会的话，我相信苏格拉底也不会告诉他什么结论，而只会是向他提一些问题。因为实际上，答案都在你心里，只不过它藏在一个你不知道的“子宫”里，他要想办法让你自己得出那个答案，否则，你就永远不知道你还有这个能力。

所谓“认知”，就是提问；所谓“非认知”，就是不成为问题。

所以，苏格拉底是一个极普通又最不普通的人。

有人去德尔斐神庙问先知，“谁是雅典最聪明的的人”，先知回答：“苏格拉底是雅典最聪明的人。”但是，苏格拉底说：“我一点儿都不比别人聪明，我其实什么都不知道，但有一点，我唯一知道的是我不知道，而所有其他的人都认为自己知道。”

不知道，又知道自己不知道，这就是一个矩阵。

苏格拉底不断提问，就是不断给你增加认知的台阶，让你自己爬上去，看到一个真实的世界。

# 洞穴比喻

但是，苏格拉底的命运非常悲惨，他试图让雅典人知道自己不知道，最后被指控为扰乱人心，判了死刑。他的学生柏拉图后来写了一个寓言——洞穴比喻，成为了哲学史上的经典：

一群生活在洞穴里的人，从出生就在这个黑暗的洞穴里，他们的腿、手，甚至膝子都被铁链绑着，不能朝别的地方看。他们的后面是一堆火，前面有一堵墙，因此他们只能看见墙上有些多影子。洞穴人觉得那就是真实的世界，他们不知道这个真实的世界就是他们的影子——我在前面说过，我们对世界的看法，好多时候不反映世界，只反映我们自己的状况。

一天，有一个洞穴人不知道怎么挣脱了铁链，他发现了一个秘密通道，我们也可以把它叫“虫洞”。这个人一下子就意识到，自己生活的那个世界是如此的狭小，他第一次看到了：世界不是火光映照的幻影，而是太阳普照下的万物——他看到一个真实的世界。

我不知道当这个洞穴人爬出洞穴的时候，有没有人像《黑客帝国》里的莫非斯一样对他说“欢迎来到真实的世界”。洞穴人看到这个世界之后，就有了一种渴望，那就是重新回到洞穴里，把其他人的铁链砸断，让他们从这个洞穴里，或者说，从这个“子宫”里逃离出来，飞跃那个不成问题世界，来到真实的世界。

但是，最后的结果是：其他人认为这个洞穴人是在扰乱次序，把他打死了。

柏拉图用这一个寓言讲述了苏格拉底一生的悲剧，《黑客帝国》讲的也是这么一个故事。
