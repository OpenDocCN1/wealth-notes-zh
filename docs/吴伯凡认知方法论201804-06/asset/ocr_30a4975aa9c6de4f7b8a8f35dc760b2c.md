# 生活里的 “归因谬误”

1.

我前几天去一个城市出差，接待我的老同学问了我一句活，“你这次想去吃哪家饭店呢？”我说，“那就取决于你跟谁有仇了”。

这个对话的背后其实有一个梗：我去那个城市一共也就是三次四次，每次去我这个同学都请我吃饭，然后没多久，我去吃过的那家餐厅就倒闭了。

第一次是偶然，其二次又是这样，第三次还是这样……如果一个事件反复出现了三次以上，就完全没办法忽略了，而且，或多或少会形成某种“因果”的解释。

可能有同学会说，“我们现代人都很理性，不会去相信这些东西”，但这种“归因谬误”往往在理智上明知道没有道理，你却还是会相信。

2.

另外一个朋友跟我讲的一个招聘经历也很有意思：他碰到了一个各方面都非常优秀的人，打心眼里想把他招过来，但在他要下决心的时候，突然留意到一些细节——他问这个受试者，前几次工作变换的原因是什么，结果发现，受试者离职的原因都不在他自己，而是公司倒闭了，也就是说，旧公司倒闭后才换了一个新单位，然后新单位就又倒闭了……

想到这个细节的时候，我这个朋友就非常纠结和怀疑。最后的结果是，他没有要这个人。

我这个朋友应该是相当理性的一個人，但他还是非常理智地犯了一个“归因谬误”。

3.

还有一个段子也能说明一些问题：有三个从前工业文明来的人一起坐电梯。他们上了电梯以后，因为是第一次坐，所以都在想办法让自己能从低处移到高处。一个选择了不停做俯卧撑；第二个选择了原地跑步；而第三个人选择了不停撞电梯梯箱的墙。

最后，电梯上去了，这三个人都觉得电梯之所以能上来，是因为自己的努力——事实上，电梯上来跟他们一点关系都没有。

这种情况也是“归因谬误”，虽然很愚蠢，但事实上，“归因谬误”和“归因偏差”在我们的生活当中随处可见，我们经常会犯类似的错误。

# “因果”里的“归因谬误”

宗教上也讲“因果”，比如佛教对于“你怎么看现在的情况”这个问题，会告诉你：你所有的这些只是一个结果，是你在前世或者今生之前干的那些事情导致了现在的情况，你想接下来或者下辈子活成什么样子，就要从现在做起，积累各种各样的因。

“菩萨修因不修果，俗人修果不修因”——“因果”的概念可以说是我们认知世界的一个非常重要概念，这里包含着大量的“认知谬误”。

我刚才举的去哪儿吃饭的例子虽然是一个玩笑，但在历史上有很多有影响力的人物或者事件，往往就是因为某种“归因谬误”造成的。

# 两种“归因谬误”

1. 第一种归因谬误：“雄鸡一啼天下白”

“归因谬误”细分起来有两种：一种谬误是一个事件跟另外一个事件的出现不存在任何的关联，它们唯一的关联就是一个先发生，一个后发生。

为什么会把一个事件归结到毫不相关的所谓“原因”呢？一个很常见的解释就是“它反复出现”，比如“雄鸡一啼天下白”。

每到快天亮的时候，公鸡都会叫，这是公鸡的一种自然反应——它睡醒以后就只要叫，就像有时候人睡足了也喜欢唱歌一样。公鸡高歌一曲，天接下来就亮了，昨天如此，今天如此，可以推测明天也是如此……所以，我们就会认定公鸡的歌唱是天亮的原因。

2. 第二种：按开关是电灯亮灭的主要原因

除了第一种“归因谬误”之外，另外一种“归因谬误”我们几乎每天都犯，但自己却不知道。

比如揿下开关，房间的灯就亮了，再揿一下，又灭了——我们认为，“按开关”是灯亮和灯灭的原因，这也许说也没错，但是，这种归因里包含着一个我们自己不知道的谬误：灯亮和灯灭其实是由许多我们不知道的要素造成的。

# “保持谦卑是智慧的开始”

在前面的课程里我们讲到过一句话，“认识到自己的无知是智慧的开始”。听完今天的课，大家可以从一个全新的角度来理解，为什么知道自身局限、保持谦卑是智慧的开始。

这节课的思考题很简单：大家可以随便找出一件和自己相关的事情，仔细想一想，追溯原因的时候，我们找到的那个原因真的是原因吗？

# 划重点

> 归因谬误有两种：一种是把毫不相关的因素当做原因；另一种是把原因之一错当原因的全部。无论是分析成功还是失败，我们都应该避免归因谬误。
