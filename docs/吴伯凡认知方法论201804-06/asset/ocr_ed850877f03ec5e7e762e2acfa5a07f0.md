# 问答 | 如何超越单环学习，实现双环学习？

问答 | 如何超越单环学习，... ↓

本周同学们提了很多问题，大部分与单环学习和双环学习有关。大家的困惑在于：如何超越单环学习，实现双环学习？

双环学习，其实也可以理解为熟悉的区域和不熟悉的区域都要不断学习的过程。我自己也有这种学习模式的问题，对自己喜欢的专业领域就不厌其烦地精研，但对自己不喜欢的领域也不够重视，这是思维模式固化吗？

吴伯凡

可以这么说，它是思维模式固化的一种表现，也是思维模式固化的一种原因。

这种在自己熟悉、喜欢的领域不断加码的行为，有一个专门的说法，叫做“认知的自动化”所绑架。

# 1. “熟练的无能”

有人在分析刻意练习的时候提到过一个外国教练，说他在中国执教的时候发现，中国的球员掌握了一种技能以后，就会乐此不疲地做。

比如说篮球运动员，假如他投篮很准，他就会总是练习投篮，3分球，越来越精准。但是，一旦上场，他的这些技能就完全用不上了，好像变成了另外一个人。

原因是什么呢？因为他喜欢一种舒服的方式，而不是一种受挑战的方式。只要有人在他前面晃，他的所有远距离投篮技能就立即失效，陷入到一种恐慌的状态。这种现象在日常生活当中，是非常多的。

# 2. 如何从单环到双环？

在商业上，我发现我观察的企业越多，看到的陷入“单环学习”、“熟练的无能”的状态的企业就越多。

# 3. “四道坎”

前几天在一个活动中碰到了著名作家，现在也是非常成功的经理人冯唐先生。他说他在计划写一本书，他在麦肯锡工作的时间超过了十年，他想把自己在这十多年的时间里，悟到的真正麦肯锡方法，给大家用清晰生动的语言描述出来。
