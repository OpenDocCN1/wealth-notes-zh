# 魔窟中的幻想

二三十年前，我看过一部让我印象深刻的国产电影，相信很多人都不知道这部电影。故事的主人公叫“小萝卜头”，这是一个我们很多人都听过的名字——导演大胆编了一个关于小萝卜头内心世界的电影。

小萝卜头在监狱出生长大，他一直希望有一天能到监狱外头去，但是他的爸爸妈妈都在监狱里，他的世界就只能是一个监狱的世界——于是他就对外面的世界有了各种各样的想象，这部电影就叫《魔窟中的幻想》。

小萝卜头的这种想象，以梦境的形式出现，在电影里，他想象自己走到了监狱外头，可是那个外面的世界，还是个监狱，也还有岗楼，有各种各样的编码。小萝卜头走到哪儿，所有的规则都和监狱里一样。

小萝卜头生活世界决定了他的想象力，尽管孩子的想象力应该是非常发达的。现在很流行一句“贫穷限制了你的想象力”，事实上，很多东西都在限制我们的想象力。

# 南柯一梦

有一个很有名的中国古代故事，传说唐朝动平郡有一个游侠之士叫淳于棼，他们家还不错，有一个院子，院子里头有一棵古槐树。

有一天中午，淳于棼坐在槐树底下睡着了，做了一个梦，梦见自己成了槐安国南柯郡的太守，槐安国国王还把小公主也嫁给了他。淳于棼为官二十年，生活非常的幸福，后来因为起了战乱，他防守不力，被逐出了槐安国。
