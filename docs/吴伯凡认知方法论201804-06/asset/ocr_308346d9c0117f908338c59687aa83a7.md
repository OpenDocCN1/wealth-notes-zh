# 从微不足道的细节里发现秘密

在电影《三傻大闹宝莱坞》里，男主人公本来在女主人公眼里是一个不成熟、调皮捣蛋的白痴，但在他们的第一次对话中，漂亮的女主角（Pia）一下子就沦陷了，原 исче? 男主人公看见Pia戴了一块很破、很旧、很不值钱的手表，就发生了下面的对话：

男主人公：你这块表是你妈妈留下的吧？

Pia（非常吃惊和激动）：你怎么知道的？

男主人公：那天在你姐姐的婚礼上，你打扮得光鲜亮丽，但是唯独戴着这样一块表。那个时刻是你们家最高兴的日子，所有人都聚在一起，但是我知道你妈妈去世了，所以你戴的这块表会是谁的呢？

Pia听了这个回答，一下子就招架不住了。

这个过程就是一场黑客攻击；从一个很小的、微不足道的信息里发现重大的秘密，通关，直达底层，直接进入对方的底层数据库。

# 快速认知的机制

我们都希望自己有这样一种能力——以刷卡般的速度发现真相。但是，获得这种能力谈何容易。在生活和工作当中，经常制造真相乍现的瞬间是很值得嘉慕但又极难的一件事情。

怎么才能获得这种能力呢？还是要回到我们前面的话题：认知是一种产品，这个产品是你整个认知流程和认知设备决定的。

+   1. 从玩具望远镜到军用/天文望远镜

好多年前我第一次拿到军用望远镜看远处景色的时候，才知道我以前玩的那些玩具望远镜是多么简陋。后来，我又在朋友家里看了一次天文望远镜，那又是一种境界。

可惜的是，我们的认知水准常常停留在玩具望远镜阶段而不自知。因为认知能力是一种内置的望远镜，你也不知道是军用的、天文的，还是玩具的。按照“达克效应”的理论就是：当你玩玩具望远镜的时候，你是不知道你玩的是玩具望远镜的。

怎么才能让你的认知能力变成一个军用望远镜或者天文望远镜呢？

总的答案就是：升级。但这太抽象了，要回答这个问题，还是要溯我们认知过程和认知机制。

+   2. 麻瓜：散漫的认知目标

在本单元的第二节课里，我们讲到了福尔摩斯第一次见到华生的时候，脱口而说他“是从阿富汗回来的”，这让华生非常吃惊。其实还有一个关于福尔摩斯的桥段，在《伯凡·日知录》里我和大家讲过，如果把这两个桥段连在一起，就能够感受到认知的某种机制：

福尔摩斯和华生到郊外去野营，半夜，福尔摩斯把华生推醒了，说，“你现在看到了什么？”华生就说“我看到了星空”。福尔摩斯又问，“那意味着什么？”华生就分别从天文学、神学、哲学、文学……各个维度都说了一遍。最后，福尔摩斯说，“华生，你这个白痴！我们的帐篷被别人偷了！”

这个例子让我们发笑之余，也给了我们一个启示：当你的认知目标非常散漫的时候，你是很难看到关键真相的。
