# 声音从何而来？

先问大家一个问题：

森林里有一棵大树突然倒了，假设当时没有人在场，那它还会不会发出“轰然”倒地的声音呢？

很多同学看到这个问题马上就会说，“这样的问题还值得问吗？人在不在那个地方，树不都是照样发出声音吗？”

其实有很多有意思的问题，但就是因为我们常常这样不假思索地做出常识反应，就把问题包含的一些要素给没忘了。

我们来分析一下“声音”是怎么回事：

①声音源的振动引起介质振动→②到达人的外耳廓→③传到内部鼓膜，引起鼓膜振动（我们的中耳内部还有三块听骨连接了鼓膜与耳蜗，它们起到了杠杆放大的作用，放大的幅度差差不多是10~18倍）→④传入内耳，内耳的振动使耳蜗的液体出现波动，并以此推动纤细的毛细胞像旌杨柳一样摆动，对应的毛细胞因此产生容易被大脑识别的声音电信号→⑤大脑对这些电信号进行处理→⑥我们听到了声音。

这是一个很专业的表述，大家不一定要知道其中的具体细节，但有一点是肯定的：
任何感知都是一个极其复杂的生产和信息处理系统。

森林里的一棵大树有没有“轰然”倒地，它背后的原理很简单：树倒地会发出振动，但如果没有我们的耳朵、耳廓、中耳、内耳、毛细胞产生的电信号，以及大脑翻译处理这些电信号，那么，大树的倒地就没有声音。

有一个很通俗的例子：“跳舞”这件事对男女女人都存在，但如果他们不在一起跳舞，“双人舞”就是不存在的。

# 任何认知活动都是双向互动行为

我们说到“认知”，想到的就是“我认知”，“我跟什么东西之间发生了某种关联，而形成了某种化合物”，但实际上，任何认知都不完全属于你，就像琴声不属于你的指尖一样。认知的场景和通道不一样，你得到的认知也是不一样的。

吴伯凡

有一个企业家说他不愿意招MBA学生，因为他认为“读MBA的人天天在学校里学的是如何打开一瓶水，而到了企业的时候，他连竟然在哪个好都找不到”。大家可以回想一下，自己生活当中是否犯过这样的错误：“认知”是一个双人舞，而我们不自觉地陷入到了独舞的状态，以至于碰壁还不知道为什么，甚至把所有的问题都归结于环境和他人。

划重点

> 认知不是独舞，而是一个双向互动的过程。当认知的场景和通道发生变化时，你获得的认知也会发生变化。
