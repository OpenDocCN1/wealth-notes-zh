# 技术的施工不能改变认知能力的缺陷

大家可能听说“装备制造工业”，它们生产基础性的大型“生产资料”；还有一些企业生产“生活资料”，像锅碗瓢盆，包括手机等；另外有的企业既生产“生产资料”，也生产“生活资料”，比如华为，既做基站设备、网络设备，也做“手机”这种终端设备。

我们用装备支撑我们的感知是很恰当的。比如手机是一个生活资料，从一个特殊角度看，它是我们生活的一个装备；还有手表，我小时候看到手表的前面是一个表盘，后面有一个小小的指南针，觉得很神奇——这么一个小东西，既能知道时间，又能知道方位——从哲学上讲，手表是同时具有感知时间和空间的工具，它弥补了我们的感知和认知能力的不足。

> 正如麦克卢汉（Marshall McLuhan）说的：
所有的技术和媒介都是人的延伸——首先，它是人感知的延伸。在没有技术的年代，人类曾想象出各种超乎人类感知和认知能力的感官/认知设备，比如“千里眼”和“顺风耳”。而超人的感知和认知能力的极端，就是全知全能的“上帝”。

现代技术的发展路径就是越来越让人具备“过去想象中上帝才具有的能力”，比如手机，让我们和千里以外的人说话，能看见万里以外的人和景物。

但是，不管技术多么发达，人所具备的认知和感认知仍然是有缺陷的。

比如我们可以超越空间，甚至在某种程度上借助大数据技术为预测未来，但我们不能把时间变成“双向”的一一时间只能是“单向”的，我们不可能回到原来的时间去，虽然各种科幻小说都在描写这种反向的穿越。

或者我们可以从一个更大的视野来看：人都是残疾人。人捏写出的“神话”本身就是残疾的——是有缺陷的人想象出一个“没有残疾和缺陷的实体”。

# 一切的认知能力都是缺省状态的

除了人以外，自然界的各种生物，植物也好、动物也好，都是“残疾的生物”。

为什么好好的一个人就是残疾的？老虎豹子那么凶猛，怎么就是残疾的？老鼠都能感受到地震，怎么能说它是残疾的？

我们是用一个全知全能的参照系来定义一个物种是残疾的。

在以前的课程里，我们提到过蝙蝠和蛇，它们的“特异功能”是以其他功能的丧失或缺省为代价的。

# 1. 缺省和默认

Default，中国最早从事计算机研究的人把它翻译成“缺省”，但后来有人认为这是一个错误的译法，应该译成“默认”。

你想一下，在装一个软件的时候，一般有2个选择：01.缺省（默认）安装：计算机预置了一个配置，直接安装就可以；02.自定义安装：增加或减少某些功能。

“缺省”和“默认”表面是矛盾的，其实并不矛盾：任何一个物种，不仅仅是人，它们的感知能力都处于一种缺省状态，都是有缺陷的。很多动物能感受到的东西，人感受不到。

默认就是缺省，缺省就是默认。因为“缺省”是一种常态，所以我们不觉得它是缺陷。

基督教里“原罪”本来意义是“与生俱来的缺陷”。无论是人，还是蚂蚁、狮子、老虎，甚至鹰，都有“与生俱来的缺陷”的。而由于它的“与生俱来”，它就是“默认”的。

“原罪”的背后是一种谦卑意识：你要意识到自己能力的缺陷，不要认为它是完美的。当你得出一个认知，获得一种判断，甚至采取一种行为的时候，你要意识到这个东西本身是带残缺的。很多时候，因为是“生来如此，一直如此，习以为常”的，我们就不觉得它是残缺的，默认为它是正常的。

所以，一切正常的，其实都是不正常的，看似完美的东西，都自带缺陷，只不过看你有没有意识到而已。

# 2. 猜想与反驳

上面的这种意识直接导致了一种科学理论：猜想与反驳。

“钟型和云型”这对概念是卡尔·波普（Karl Popper）提出来的，他还有一个非常重要的理论——证伪主义。

“证伪主义”指：任何一个科学、判断，其实都是一个猜想。这个猜想是有缺陷的，它就是等待着被证伪的。当一个东西反复通过各种途径都没法证伪的时候，我们就认为它是科学，是对的，实际上，它只是“尚待被证伪”的。

“欧几里得几何学”是科学，同时它也是一 个“尚待被证伪”的猜想；“牛顿力学”是 科学，但它也是一个“尚待被证伪”的猜 想。所以后来，爱因斯坦的物理学颠覆或 者说补充了“欧几里得几何学”和“牛顿力 学”所代表的西方经典自然科学。

那么，是不是爱因斯坦就永远是对的呢？显 然不是。不管哪一种科学和理论，都是“尚 待被证伪”的一种猜想。

作为本单元的第一课，我要告诉大家的就 是：

我们在追求一种更优越认知的时候，一定要有一个默认前提——任何认知都是有“原 罪”的，都是等待被证伪的一个判断——哪 怕你从各个角度试图对它证伪，但也没办法 证明它错误的时候，它也是一个有缺省的认 知。
