# 问答12 | 事物的钟云二象性

# 拒绝做“万金油式的人物”

您说“世界上{}有两种残化，一种是因为不断优化而导致的，还有一种是’你并没有一个不断优化的能力，在哪方面好像都还’可以’，我想问一下’在哪方面都还’可以’为什么是一种残化呢？

吴伯凡

在公司里，如果领导说你是一个“万金油式的人物”或者是“一个板蓝根式的人物”，你会怎么想？

“好像都还可以”也就意味着真正关键的时候你都不能可以。这和我们以前讲到的“刀锋竞争力”有关：一把没有开刃的刀，你觉得它是一把残化的刀呢？还是一把优化的刀？

如果你在公司里成为一个万金油，也就被定义成了另外一种角色——备胎，实在没人的时候，你才可以上。比如你负责在单位里修电脑，你就会说“重启”，你做的主要的事情就是说一句“重启一下试试看”；如果你是一个医生，你就只会告诉别人“多喝水”——这是一种看不出缺陷，但是存在着巨大缺陷的角色。

# 证伪主义：“相对主义悖论”的一种

“证伪理论”是否也是尚未被证伪的科学？

吴伯凡

这句话问得很哲学，这里涉及到哲学里一个很重要的问题——相对主义悖论。当你说“一切都是相对的”这句话的时候，你觉得这句话成立吗？如果一切都是相对的，这句话本身就不成立。

用比较学术化的话说就是：任何一个“全称判断”不能够以自身为子集。一个“全称判断”表达的是对一个集合的判断，但是它自身不能够成为这个集合的子集。

# 任何企业都有“阴阳”两面

企业经营是否全部都是不确定、无法预估的？在企业经营当中仍然存在着那些“钟的面相”：1.企业就是创造价值和传递价值；2.管理就是去掉一切不产生价值的环节；3.商业就是高效率打败低效率——这些不变的商业原理，和云型的企业家是否矛盾？

吴伯凡

正如我们课程里讲到的：钟型和云型是两种分类。有些事物是具有明显确定性的，而有些事物是具有明显不确定性的，但世界上所有的事物，应该说都包含着“钟和云”两种特性。

借用物理学的说法就是“事物的钟云二象性”：从不变的角度看，它总能有不变的成分在；从变的角度看，它总能有变的成分——在一个具体的事物当中，这两种特征的配比程度不一样。

《金刚经》有云“一切有为法，如梦幻泡影，如露亦如电，应作如是观”。
