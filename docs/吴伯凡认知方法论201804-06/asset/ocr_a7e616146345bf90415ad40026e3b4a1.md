# 认知升级中的“设计论”&“演化论”

这两个都是“承先启后”的问题：“承先”就是这个问题里包含了我们以前讲到的一些内容，“启后”是我们以后还会讲到一个非常重要的话题——认知升级过程当中是“设计论”还是“演化论”，或者说是“进化论”？

+   1. 设计论

想要获得很好的认知，你要自己设计出来，要不断地增加你的武器库，让你的工具箱尽可能完全、有用、完善。“工欲善其事，必先利其器。”——如果要把事情干好，就要尽可能地让你工具全和有用。
