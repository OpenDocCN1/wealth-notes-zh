# 获奖留言

我订阅了十几个专栏，而且坚持每天跟着学习，还认真做笔记，结果发现过了poque... 效果也不好。

现在，我采取“主题复习法”，第一遍先认真学懂，过一段时间再按照某一个主题，综合几个专栏老师围绕这个主题的相关知识讲解进行复习，并且加上延伸阅读。我发现这种方式的学习效果很好，有些知识点感觉已经入脑入心，随时可以拿出来用了。

来自：知行合一-1｜建立神经元间的高带宽专线

很巧的是，王煜全老师专栏这一周正在讲“云计算”。王老师讲的是狭义上的云计算带给我们的好处，各种生活及工作的便利。这边老师用“云计算”这个概念，再加上“同步”这个概念，一下子就让我理解了“云”和“端”之间的关系。仅仅改变“端”是没有任何作用的，决定最终表现的还是我们自己建立的那个“云”。

那么，决定“云”的质量和功效的主要因素，应该有三：存储能力、计算能力，以及与端之间的联系带宽。

“存储能力”就是指，我们在云上所存储的知识性的内容有多少。前两天罗胖也提到，对知识性的东西，现代人似乎过度依赖于网上搜索了，但是在自己的脑海里，也就是自己的“云”里，却连基本的相关概念都没有，也就产生了一个“盲维”。在你面对搜索框的时候，你连“搜索什么”都会完全没有概念。所以，应该在自己的“云”上建立一些关于基本知识的“线头”，在需要的时候，沿着这个“线头”进行搜索，就可以得到自己想要的答案了。云的存储能力就是指的这些“线头”的数量。

“计算能力”，我的理解就是，线头与线头之间关联度的建立。越是能够在看起来没有关系的线头之间，建立一定强度的关联，遇到问题时候的计算能力就越强。

至于与“端”之间的联系带宽，则是从“知识”到“技能”的一个转化效率。这个也许可需要反复练习，使得一些存储在“云”的内容，内化成自然驱动“端”的ROM内容，从而提高整个系统的作效率。

来自：知行合一-3｜同步：云的状态决定端的状态

# 其他精彩留言

我发现自己貌似每年，都会强烈地觉得自己半年前的所作所为很幼稚、可笑、荒谬。听了这堂课明白了，原来是自己在成长。只是我反思的速度和次数太慢了。

今天老师所说的“完成循环”，进入下一循环，反思，再循环，这其实就是一种我们常说的“迭代”。我们做的产品需要不断迭代，自己的能力见识也需要不断迭代。
