# 盲眼钟表匠的“进化逻辑”

要怎么分析“云型事件”的原因呢？如果不能把“云型事件”的要素提取出来，那我们怎么去迭代、改正和进步呢？

这个问题答案也许在“进化论”里：所有的物种都不会把事件的要素提取出来，然后再迭代和进步。在特定的场景下，由于特定的生态位触发了各种性状而产生了不同的物种。物种是在特定的场景、环境和生态位中，通过与环境不断博弈去迭代和进化的。

我们可以简单地用道金斯的著名命题“逻辑就是盲眼钟表匠”来进行说明：他是一个钟表匠，眼睛还是瞎的，可以说，他面对的是一个充满不确定性，但好像又有某种确定性的场景——双目失明的钟表匠不是自上而下设计出来的，而是自下而上摸索出来的——我们不可能先把要素提取出来。

“云型事件”和“钟型事件”就像“光的波粒二象性”，这个世界两面中的一面是“云型的”，充满着不确定又好像有某种确定性的东西。

# 世界的算法：简易和变易之间的关系

只有透过千变化的现象，找到不变的算法、方程式，才可能认识这个世界。“不变的算法”跟“云型事件”是否冲突呢？

这不是一个容易回答的问题，如果真要找答案的话，我建议大家读一读《易经》，这本书讲的是这个世界的算法。

这个世界的算法，一方面极其复杂，另一方面又极其简单，简单到“易”。“易”有几个含义：①日月为易，一阴一阳，构成这个世界所有算法的基础——这是“不变的算法”；②“易”又是变化的意思，是变易的。

我们面对的世界同时具有云和钟的特征，简单说，就是“没有说明书的世界”。我们跟世界打交道的时候，有一种本能需求：希望找到一份说明书，这样就能很容易操作。可以说，这是人类一个根深蒂固的愿望。

但问题在于，你没和世界打交道之前是不可能找到这个说明书的，即使给了你一本说明书，你也看不懂那本“天书”。

这就像电器说明书，特别简单，但我们往往是摸索着学会了使用这个电器的时候才能真正看得懂这个说明书——这就是世界的算法，它的变和不变，也就是“简易和变易”之间的关系。

正如这个世界有“云的面相和钟的面相”，“不确定性的面相和确定性的面相”，人也有两类：“寻求确定性的人”和“容忍确定性，甚至去拥抱不确定性的人”。前者是工程师，后者是企业家。

中国古代是沒有企业家和工程师之分的，但也有类似的分类。唐代一个和尚就写过一副对联——“尘土十分归举子，乾坤大半属偷儿。”

什么意思呢？尘土和乾坤是对立的，尘土构成我们这个世界，而乾坤是天地的要素，但尘土不是天地。这个世界的两类人，一类跟尘土打交道，一类跟乾坤打交道：

跟尘土打交道的是“举子”，就是通过严格的科举制度，一步步答题升到一定位置——用今天的话说，叫“技术官僚”。

和乾坤打交道的充满着不确定性的是“偷儿”，他们不是按部就班、有一定之规的，而是随机应变、始终把不确定性作为常态。今天看来，企业家都是“偷儿”，他们面对一个复杂世界，每天遇到的情况都是千变万化，充满不确定性和危险的，得和失是没有规律的。

这两类人实际上也代表着两类心态，这两类心态可以用钟和云来代表：

技术官僚、工程师、理工男面对的世界是一个“钟型世界”，或者说，他们乐于面对的世界是“钟型的”。遇到问题的时候，他们总希望有一个说明书或者操作手册，否则他们就会很纠结。这类人有一种固执的愿望：学会游泳之后再下水。而在学会游泳之前，他们要找到一个游泳的操作手册，然后再去学游泳，最后才能下水。

“偷儿”的逻辑是：不相信这个世界有一个操作手册，这类人只是跳到水里去——先下水再学会游泳。

# 预兆思维：始终不认为眼前的局势是最终的局势

老师，圣地亚哥这么坚信“预兆”，他怎么确定这不是自己的认知偏误？他怎么去确定这个梦是“信息”而不是“噪音”呢？老师不是也说过，朝着错误的方向竭尽全力努力也是一种失败吗？

提这个问题同学依据的是“钟型思维”，而不是“云型思维”。

预兆是什么？预兆是一种思维方式，也是一种面对世界的方式。

我们可以用莎士比亚的一句话来对预兆做一个定义：所谓“预兆”，就是一切过往皆为序章。也就是说，无论你眼前是天崩地裂也好，旗开得胜也好，这个局面都是一个序章——“序章”是证据还在，但真正的戏还没有开始。

当圣地亚哥的第一桶金被别人骗走以后，他认为这是一个“预兆”，或者说，这只是一个“序章”——老天爷要把他过去挣的钱全部清空以后，才能让他开始新的征程。

所以，圣地亚哥的态度就成了一种“可能性的艺术”：他把眼前这个让他郁闷、沮丧，甚至崩溃的世界始终看成是一个充满着各种可能性的事件，所以，他才不会怨天尤人，不会为自己失去的那笔财富陷入绝望的深渊。

所谓“预兆思维”，就是始终不认为眼前的结局是最终的结局，而只是一个开始；始终保持着“对世界的不确定性和可能性完全敞开”的心态，只有这样，认知才可能不断拓展。

至于信号和噪音，那是投身到接下来的剧情中，通过不断碰壁和试错去发现的。就像生物演化的过程，不是按照一张设计蓝图来决定自己长成什么样，而是长成什么样，取决于跟环境的博弈——没有事先知道的信号和噪音。
