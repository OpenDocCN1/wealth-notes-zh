# 获奖留言

这个“刀锋竞争力”和“眼力见儿”，我的理解就是透过现象看本质。

老师前几周课提到的“降低噪音”、“刻意练习”、“T型认知树”等都是最终能实现“眼力见儿”的必要的认知过程：

+   “降低噪音”可以让我们的内心过滤不必要的无用东西，更容易看到本质；
“刻意练习”is让我们把偶然看到事物本质的本领，通过大量的实践练习真正地成为一种本领；
“T型认知树”能让我们遇到瓶颈的时候，通过宽广的知识面，把瓶颈通过其他途径来突破。

所以说能达到所谓的“眼力见儿”不是一朝一夕的事，我们每学到一个技能都是达到最终结果的一个环节，但我们本身是不知道的，等我们最终拥有获得结果的能力时，回头一看原来我们的努力都不是白费的。

日积月累，终入化境。

《道德经》讲的就是“天下万物生于有，有生于无”。“无”是一种看不见，但起决定作用的东西。

不知有多少同学的妈妈喜欢吃鱼头，我的妈妈就喜欢，但是我稍大一点，就知道了，妈妈吃鱼头，或许不是一开始就真的喜欢，而是为了让我们多吃肉鱼，才选择吃鱼头，妈妈吃鱼头，是看得见的“有”，对我们的爱，才是驱动她吃鱼头背后的“无”。

来自：“无中生有”的认知2 | 设计中的设计

看完今天的内容，认真思考了所谓“眼力见儿”到底是什么，我认为那是环境对人的塑造。换言之，你身处什么样的环境，就会有对应的眼力见儿。

比如一个画家绘画水平比普通人好，主要是由于他眼睛所能观察到世界的角度和深度都超过普通人，他能看到，或者说留意到普通人忽略的东西。这是由于他画多了，观察得多了，比普通人练习得更多，在绘画方面思考得更多所导致的。

同样的，久居官场的人多数城府，商海沉浮的人自然精于算计，他们在各自的领域总能看到比普通人更多的东西，也就是所谓的“有眼力见儿”。

那么，如果想获得某种方面的“眼力见儿”，其实也有一个比较简单的方法，就是让自己置身于相应的环境中。从一开始的小菜鸟任人宰割，到万人敬仰的大神，不同的人根据禀赋的高低会花不同的时间，但是无论如何都会有所成长。

# 其他精彩留言

今天的课让我想起了王阳明的“致良知”理论。

我记得，阳明先生把“致”解释为“提炼”，他说我们每个人一生都在提炼良知。他还作了个比喻，把提炼良知比睛为提炼黄金，并且纯度越来越好。

他说，像孔子、孟子一生内心提炼的良知黄金可以达到一千斤，纯度达百分之九十九以上，普通人可能一生只有一斤，纯度也只达到百分之八、九十以上，但我们也要为提炼这样的良知而不懈努力。

听了这节课，我是否可以这样理解，每个 人内心提炼的良知就是在不断锻造自身的“刀锋认识能力”，而且当“纯度”很高后便会产生“刀锋竞争力”，去感知那些“看不见的东西”。

来自：“无中生有”的认知1 | “眼力见儿”与刀锋竞争力

求缺，就是要有取舍，在生活中什么都想要，最后是什么都得不到。每个人时间、精力都是有限的，只有把它用在自己的兴趣、天赋等可能会有一番作为的地方才有最大意义。如果平均分配在每一个自己觉得需要的地方，那么不但会活得很累，而且一无所得。

每个人都应该越活越明白，明白自己的“使命”，然后去完成它，完善它，做到极致。

来自：“无中生有”的认知3 | 求缺的能力

多年前，《读者》上刊登了一篇文章，叫做《阳光不锈》，题目很诗意，这份诗意是由残缺所造成的，因为，完整的现实是“阳光不锈钢”这个毫无美感的名字。

就像断臂的维纳斯，残缺正是无限想象带来的艺术之美，如果失去的手臂以任何形态回来，人们只会因其完整而遗憾，而不是欣喜。后来，对于残缺，对于失去，总会有更多的包容，那句讲俗了的老话“最美的永远是得不到和已失去”，也是一种残缺之美。

来自：“无中生有”的认知3 | 求缺的能力

这和一句口头禅“听话听声音”的道理相似，也就是弦外之音，这可能也是一种高手的体现。

昨天，到一对夫妻朋友家吃饭，媳妇做了五六个菜，看上去特别好吃。当老公吃了其中一个菜时说：“哥们儿，天气热，弟妹是在提醒让我们要多喝水。”说着，拿起啤酒就与弟妹和我举杯。弟妹举着酒杯说，“干杯，溶解溶解”。

当时，我可真是佩服，怪不得他们那么幸福。如果老公直接说：这菜也太咸了，要馋死人吗？那老婆的反应可能会是：爱吃不吃……不可想象，那是多么糟糕的场景。

常言说：话有三说，巧说为妙。还有在薛老师的经济学课第18讲中也说：能够进行逆向思考的人很少，道出了最为本质的生活幸福真谛！

来自：“无中生有”的认知4 | “苟且”构成了“诗和远方”

今天的课让我想到了《雍正王朝》里的两个故事。

在追缉国库窃银的问题上所有人都知道得罪人，没有人干。可是鄂先生却让雍正干，原因就是如果谁雍正都不干，皇上连一个分忧的儿子都没有了；在处理刑部冤案的时候，恰恰反了过来。很多人认为这是扳倒太子的好机会，都鼓动八爷干。这时鄂先生却不让四爷干。因为扳倒太子将不会容于皇上，不容于天下。

能从事情发展的要素去判断全局，这种能力一般人具备不了。在这两个事件中，大多数人都忽略了他们最不能忽略的人，那就是康熙皇帝怎么看，怎么想，他希望他的儿子做什么。

当把事情要素都结合起来，站在更高的角度去考虑问题，我想我们会得出不一样的结论。
