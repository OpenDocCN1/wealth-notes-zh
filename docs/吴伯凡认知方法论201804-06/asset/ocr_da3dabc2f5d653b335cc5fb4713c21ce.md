# 获奖留言

自暴自弃、及时行乐的生活方式治好绝症的例子是一个偶然现象，因为稀缺反而让人容易记住去研究。太多未治好的例子在我们看来已经是脑海中必然的结果，反而觉得没什么价值。

但是换一种可能性，如果大家都这么做治好了绝症，那可能就是一个方法了。

偶然现象的背后有许多必然性，而这些必然性是和很多交织在一起的因素有关，是心态，是身体素质，甚至是身体基因的某种原因，这个我们不得而知。

今天老师提到的例子，让我想起吴军老师说的一个“老军医看病”的例子，当时医院判断病人快不行了，家属让老军医再看看，老军医竟然出乎意料地减少了很多药，这个谬误在当时西医观念中完全颠覆认知。结果，那个病人不仅活了下来，还活了好多年。

这背后的原因是药对于人来说是良药也是毒药，而治病是个系统的事，要考虑诸多因素。如果单纯点对点，没有形成系统的矩阵思维，思维只能在平面上思考，无法找到立体因素中的原因点。老军医因为具有立体的思维点，找出了原因，让病得以治好。

失败与成功都有很多原因，但导致失败的是很多原因组合在一起，原因的叠加并不是简单的1+1等于2，也许两个因素加起来等于3，加速了失败。生活中必须系统看问题，保持谦逊，因为我们很多时候真的很无知。

来自：天赐良机从何而来2 | 结果 = 一连串的事件

当我们自以为自己很努力地多次做某件事情仍然遭遇失败的时候，看到周边和自己相同时起点的他人却轻而易举地做到，如果把这当成钟型事件，自己很可能会自暴自弃，而如果能认识到这其实是云型事件，那么自己会更有动力去发觉、询问其中的具体因索。

引用吴军老师专栏的一段话，“寒窗苦读只是一种读书态度，这种态度是好的，但是社会竞争是一种非常复杂的长期系统性竞争，寒窗苦读是成功因素之一，和经济条件好、智力高、出身好、长得美一样，都只是其中的一个变量而已，而命运是多个变量互动的结果”。

来自：天赐良机从何而来3 | 钟型事件与云型事件

交流是给自己定位一个参考系，那么交流就是找不到参考系或者找错参考系。横向互联是接受改良、是开放，纵向互联是自我革命。

我们熟知的刻舟求剑就能很好地说明这个道理。

船舶对船上的人是正确的参考系，对流动的水和掉进水里的剑就是错误的参考系。丢宝剑的人不听同船人的提醒，失去了横向互联的机会，自己又认识不到落水的宝剑不随船走，失去了纵向互联的机会。

所以，需要有多样性，有了多样性的量，才能横向迭代认知，还需要有独立性，有了独立性的质，才能纵向迭代认知。

# 其他精彩留言

这让我想到了经济学价格原理。

人们总会认为价格是贪婪的商人决定的，但价格其实是市场来决定的。人们只看到了商人对商品的定价，却看不到商人其实是在考虑消费者的需求，并进行市场调研之后，才最终决定的价格。

来自：天赐良机从何而来1 | 两种因果谬误

从前从来没有仔细想过“归因谬误”这个词，大多时候都把“归因谬误”认为是“偏见”或“习惯性想法”，却从来没有想过仔细分析原因的来源和组成，现在仔细想了后有种细思极恐的感觉，我们一直都有很多问题，只是我们从来没有仔细思考过，好可怕。

对于这个问题我的感受是，因为人脑有一种天然的填补机制，遇到不完整的东西会自动补全，同时人类是一种情感丰富的动物，遇到问题时会天然地首先出现情感的表征体现，这时候理智就更加难以介入，所以我们只有在学习认知方法论的时候才有机会系统地思考自己的这些问题。

就比如说，我很多时候在与别人合作时，一旦另一个人表现不好，或者态度不友好，我的大脑就会自动补全对他的各种看法，其实这件事情也许只是时间太紧张，难以会出问题，每个人都不可避免，但是由于你平时对他的某些问题很关注，就是情感上有偏见，这个时候就会自然而然地觉得他出错是故意的。这种问题真的是细思极恐，如果我们不针对性地进行分析和修正，以后的工作生活都会有坏的影响。

来自：天赐良机从何而来1 | 两种因果谬误

今天说的因果让我想起来前节目提到的牵涉性癌痛。

表面上看导致这个癌痛的原因很明显，但用医学的角度看它并不是这样。转换了观察事物的维度自然会得到不同的结果。

原因和结果并不一定是简单的线性关系，有时候我们错把相关性当成因果性。

来自：天赐良机从何而来2 | 结果 = 一连串的事件

吴军老师今天的专栏文章专门讲了“谋事在人，成事在天”，我觉得把吴老师的两个观点放在一起看，非常有收获。

“谋事在人，成事在天”强调我们要客观地对待想要做的事情，对未来有敢梦之心。同时，不要“不尽人事就光抱怨天命”。

“天赐良机”告诉我们“良机”根本不是天赐，是“心怀天赐的期待”，自创一切，努力达成结果，才会成就“良机”。

恰好这两天高考，不禁想起自己高三那会儿，也是心怀大学梦，但从未盲目地等待过任何机遇。因为我明白，唯有日复一日地努力，唯有你自己，才能成就想象中的你。
