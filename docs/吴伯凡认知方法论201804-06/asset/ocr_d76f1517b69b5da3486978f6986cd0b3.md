# 世界的两种意义：劳动&游戏

大家都玩过游戏，玩完游戏之后我就在想：我既要付出精力，还要付出银子，通宵达旦玩游戏到底是为了什么呢？毕竟也不像加班，还有人给加班费。

为什么要去做这么一件好像没有收益，还要全身心努力的没有意义的事情呢？因为世界上存在着马克·吐温区分过的两种意义。

第一种意义：劳动

比如你在山崖上采药，就是“劳动”。而你之所以在烈日炎炎下去爬山攀岩，是为了采药，这个目的是一个外在的目的，你的回报是一个外在的回报。

第二种意义：游戏

另外一些人在烈日炎炎下攀岩的劲头，比采药的人还要大，那种叫“游戏”。所谓游戏，它有一个内在目的，它启动的是一种平常工作生活中未被启动的，或者说是沉睡的力量和冲动。

“游戏”也有一个目标，但在你和这个目标之间s有一个距离，或者说一个张力。消除这个张力达到那个目标以后，你就会产生一种快感。这个目标是内在的，不需要外在的回报。

# "完形冲动"

哲学史和美学史一直在探讨“人为什么会有游戏冲动”。“格式塔心理学”（gestalt psychology），也叫“完形心理学”，比较好吃解释了人的游戏冲动，以及由游戏而得来的快感。

现在你可以在纸上画两条并排的线，这两道线之间的间隔不要太大。如果你让别人来看这两道线的话，他们很容易认为这是一条线，只不过中间“断了”。而且你很容易有一种冲动，想把两条线中间的空白给连上，使它变成一条线——儿童更有这样一种冲动，他们不能忍受那种缺陷和不完美——这就是“完形冲动”。

我们今天再来讲“完形”，是要让大家知道：人有一种内在的完成冲动，当某种状态或情形显现出了某种不完整、不不满，或者是某种混乱的时候，我们有一种内在的冲动要让它完成、完整，让它从混乱恢复有序。

“格式塔心理学”认为，我们的认知里包含着两个因素，其中一个是张力，或者叫矛盾/欠缺。

矛盾和欠缺形成了一种张力以后，自然会调动、刺激、激活我们认知当中的一种能力和偏好——去完成它。

这也是我们自带的一种负熵本能：熵是混乱、无序、欠缺的，而负熵就是反熵增。当我们的这种能力被调动激活，开始运转，最终达到目的的时候，我们就产生了一种快感——游戏的快感。

一个游戏，我们极其娴熟或者彻底通关之后，就没有再玩下去的欲望了，这时候我们会说“没意思了”，这个“没意思”就是它丧失了张力，也丧失了激活我们认知和行动能力的的功能。这个时候，我们的完形冲动和完形能力就自然休眠，表现为一种无意义感。

# 舒适区、焦虑区和学习区

也可以用我们以前讲过的舒适区、焦虑区和学习区的这个理论来看“完形冲动”。

如果一个东西混乱缺少到让你焦虑而无处下手的时候，是没办法激活我们的完形冲动或者游戏冲动的；而它相当完整有序的时候，也没办法激活我们的完形冲动。只有对象既有序又无序，既缺少又完整，在缺少和完整、混乱和有序之间形成了某种张力的时候，我们的认知才会被激活。

如果难度太大，我们的认知会休眠；如果这难度太小，甚至没有难度，我们的认知冲动也会自动休眠。

学习就是这样一种介于舒适区和焦虑区，把我们休眠沉睡的认知能力唤醒，并发挥作用的过程。

+   原始舒适区=零认知，舒适但是没有快感。
焦虑区=各种各样的痛感，引发我们的焦虑。
学习区=由痛感开始，我们内在的认知能力被调动以后，对痛感的降服和战胜。

# 经典案例：西北航空的logo

理论都是乏味的，我们讲一个案例。

假如你是一个设计师，接到一个任务，为美国西北航空公司（Northwest Airlines）设计一个logo，这个logo要出现几个要素：①西北Northwest，②航空。

好的logo不仅要用字告诉别人“这是西北航空公司”，还要用一个非常鲜明的视觉形象。

如果做加法的话，又要西，又要北，又要航空…..可能堆了一大堆要素，看上去又杂乱又各自夺。

有一个设计师接到这个任务以后，冥思苦想了好几天，终于发现“最好的方案就是最简单的方案”。

![](bbox=[0.28, 0.00625, 0.88, 0.00735])

把英文字母W切下去一小块（W是英文当中的West的首字母）——你看到的是一个不完整的W，但是你又能一眼就看出是W，这就是一种“完形冲动”；

+   切完了W以后，这个logo又包含了一个非常醒目的N（North的第一个字母）；
边上又有一个三角形，是一个罗盘、指针的标志（罗盘就直接联想到“飞行”），恰恰指的还是西北方向。

这个简单的图形，不仅是用字母，而且是用一个视觉形象，非常准确地告诉你——这是西北航空。

这可以说是世界上最简洁又非常完整的一个logo，是设计中的经典，或者说是“设计中的设计”，是“从无中生有出来”的一个完美案例。

# 求缺：避免“画蛇添足”

有个笑话说，一个秀才写了一首诗，“月光一片照姑苏”，县太爷没有什么文化，他觉得这首诗写得却片面，让秀才改。

+   秀才：为什么要改呢？
县官：月光怎么能只照姑苏呢？肯定照了更多其他地方。
秀才：您说怎么改？
县官：应该是“月光一片照姑苏及其它各地”。

在我们自己身上也常常会出现这种画蛇添足——由于求全，反而把一个事情搞砸的事情屡见不鲜。

曾国藩说，“小人求全，君子求缺”。求缺的能力是非常重要的一种能力，而画蛇添足是一种常犯的错误。

吴伯凡

听完今天的课，大家可以问自己一个问题：我有没有犯过那种因求全而画蛇添足的错误？有没有求缺的意愿和能力？
