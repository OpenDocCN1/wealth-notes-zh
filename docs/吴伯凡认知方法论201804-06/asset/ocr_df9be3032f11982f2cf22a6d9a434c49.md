# 过敏与“溢情”

听了“无中生有的认知”的第二课“设计中的设计”以后，我想到了自己的父亲，他是一个敏感的人，对环境和他人的情绪变化察觉很快，也能够作出比较恰如其分的回应，但他更倾向于过分解读他人的言行，并把他收集到的信号全部与自己联系起来，最后得出的结论就是“有些人看不上他”，尤其在他喝多了以后很明显。老师今天说的“眼力见儿”与“过于敏感”是完全不同的概念，前者基于事实判断和逻辑推理，而后者大多数时候是基于个人经验的主观的判断。但在生活中，对我们一般人而言，如何区分二者呢？毕竟能抽身事外来看待当下不是所有人都能做到的，又或者说我们自身的直觉以及经验本身，就是构成“眼力见儿”的基础，我们要做的就是“去伪存真”吗？

吴伯凡

大家应该都知道英国著名小说，简·奥斯汀的《理智与情感》——我一直认为这是一个很糟糕的译名，它原来的书名是“sense and sensibility”，我认为准确的翻译应该是“深情与溢情”。

这本书的主人公是两姐妹：姐姐是一个深情的人，但拙于表达，非常含蓄；而妹妹是个溢情的人，有感觉，但她的感觉过度敏感，很容易陷入到溢情当中。

在我们生活当中经常需要make sense——对周围世界、对他人的 一种非常密切的感受力和洞察力，但我们又不能陷入到那种“过敏”的溢情状态——这不是“理智和情感”的问题，是“深情和溢情”、“感觉和过敏”的问题。

生活当中，我们比较难于在“感知”和“过敏”之间划一道分界线：过敏的人往往在某些事情上确实有比别人更敏锐的察觉力，但是这种“过敏”说到底，是一种“对敏感性的滥用”。因为没有一种东西来节制这种过敏性，使得它因为某个很小的变化刺激就能引发一个特别夸张的反应，或者说，感觉里的杠杆太大，从而导致了感知的变形。

那怎么才能既有丰富深刻的感知力又避免过敏呢？我们不能简单地归结到基因，这中间很重要的因素就是“节制”。

“节制”不仅是“少花钱”，它的另一个意思是：有感知的时候，不要放任这种感知。从一开始你就要学会猜想和反驳，要具有一种“反驳机制”。

“过敏的人”从来没有“反驳机制”，当他产生某种感觉的时候，不是用他的感受和证据来反驳自己，而是尽可能去搜索各种各样的“证据”来强化自己的感觉，坚定地认为自己的过敏是一种真实感觉。

另外还有一点就是：“过敏的人”往往是“以自我为中心”的人，不太听得进别人的话，也不太在与别人交往中修正和迭代自己的感知，以至于把“钻牛角尖”变成一种常态，最后使自己整个陷入到感觉泛滥的状态。

# “极致和求缺”是同一回事

听了“无中生有的认知”的第三课“求缺的能力”以后，我想问一个问题：不断地在发现问题、解决问题中循环，是不是也是一种“求缺”的过程呢？

我们说做产品、服务要做到极致，老师也讲到了蛇的极致与弹性，“极致与求缺”是矛盾的吗？或者说它们本来就是一回事？

吴伯凡

“求缺的过程”就是一种“反完美主义”的过程，更准确的说法是“拥抱”、接受和承认这种缺陷，而不是规避、无视、有意去掩盖这种缺陷。

如果我们认为自己做的事情不可能做到完美，反而会很坦然；而如果你高悬一个完美的目标，就会对手自己的缺陷有一种畏惧、退缩的感觉。

# “行动上的完美主义”和“精神上的完美主义”完全是两码事：

行动上的完美主义：承认缺陷的情况下，通过不断的认知循环和迭代，接近“完美”，同时也认识到“这个完美是很难以达到的”——这是一种健康的心态。

精神上的完美主义：事先高悬一个完美的东西，用这种完美性来苛责自己当下的行为，使得自己要么是拖延，要么是回避，要么是固步自封——本来是不完美的，但粉饰自己的这种完美性，从而导致一种认知和行动上的无能。

我们在《伯凡·日知录》里讲过“蛇的极致和弹性”，这里有一个前提：蛇是残体动物，它的眼晴是极度近视的，还没有腿脚，又不像蝼蛄这样的爬虫什么都可以吃——蛇不能“降格以求”，它必须要吃活体动物——所以，蛇是一个生存非常艰难，又自带明显缺陷的动物。在这种情况下，它不在某一个路径上“极致”，就没有活的可能性。所以，“蛇的极致”是因残缺而导致的一种极致。

“极致与求缺”并不矛盾，它们本来就是同一回事。
