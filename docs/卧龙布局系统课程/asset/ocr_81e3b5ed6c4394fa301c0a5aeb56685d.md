# 2, 必须要有流程

第一步；第二步；第三步；…… 事无巨细，流程越清晰，细节越到位，越容易实现落地。。

即使你目标定位，搭建框架，以及按思路堆做的很好，有了层次，如果不能再层次中填充细节，所讲的技巧，内容，文案，广告，等，你仍然做不好营销

因为你无法落地。目标，换位，框架，层次，层次细分，相互关联，我们需要在这个基础上，进一步落地细节，细节越清晰，越容易落地。

如：第一步：发文案 2，文案模板 3，发到 Qq 群，贴吧，还是哪里？

引流中：客户来了，如何黏住，让客户得到什么价值，传递什么解释方案。

# 3, 必须要有全局观念

任何布局一定要有风险意识，做好全局风险把控。

没有 2 层防火墙的布局尽量不要做。懂的舍，懂的分钱，懂的让利，从全局层次把控风险。

做任何事情，和目标，最可怕的不是困难，阻碍，而是本质上最大的风险意识。

记住一句话：人性中风险恐惧是美好，梦想的 5 倍。——此比例，经过科学验证，无可置疑。你只需要记住即可。人性很多时候，不行动，最害怕的就是恐惧，对未来的不确定性。因为：成为一个好人不容易，成为一个坏人，成为小偷，懒人，跳跑等太容易，我们是而者的 5 倍+。切记，切记。
