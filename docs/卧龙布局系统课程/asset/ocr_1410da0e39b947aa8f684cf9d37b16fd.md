# 即将龙营销咨询：《布局系统》速成班内容

布局系统之：方程式思维，是我们布局框架的基本逻辑，非常重要。不会搭建框架，就很难学会布局，我这里不再ing再次强调方程式思维的重要性了。

肯德基为何可以很快复制，几千家肯德基那？如何能达到标准化，流程化？——这就是把一个事情，方程式化了。

第一步：+第二步：+ 第三步：=炸鸡，如果你还不懂，就像算数，1+1=2 形成一个万能的方程式。

然而在中国传统的菜品，几乎没有任何一个老板和行业，可以把炒菜做成标准化，一个口味，一个样子这样的流程，标准。

然而肯德基为何可以做到？（因为流程简单？）

为什么可以复制，完全一样一样的肯德基鸡，汽水，等标准化。就是因为利用了方程式思维，进行流程化作业。

对于方程式，甚至一个框架，刚开始我们可能就是单纯的思考，进行复制。可能复制的条件，环境，以及各方面因素有限。

那么这个问题如何解决？

# 方程式思维 5 大法则：

+   1, 写出基本规律的方程式

如：从 1+1=2 那么可以得到：1+1+1=3 或者 1+1+1+1=4 一个基本小万能的公式。通过一个基本的方式，先写出一个可以复制的是框架，然后立刻可以模仿复制，而不是盲目的不知道对方套路是如何玩的，这是大部分人一辈子的误区。
