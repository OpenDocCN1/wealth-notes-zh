#  Invent：可怜，同情心。


还是：可怜，获取同情心。

记住：任何本质规律不会变。而我们今天上面这个案例的核心就是：可怜，同情心。

不论是采取什么方式，是打断腿，挑断筋，只要越可怜，越容易让人产生同情心，就是我们本质诉求的一个卖点。

化妆也好，伪装也好，找理由也好，借助外部工具，弄一个假肢，或是买点真的血，酒在某些地方，达到本质规律：可怜，同情心，就ktrum可以了。同样可以获得想要的结果。

同样有些人利用了营销思维，先给价值，而后获得别人的同情心。如：在红路灯给别人擦车，擦了几下，然后车主会愿意给钱，而且还会说谢谢，售后服务很好。顺便送个祝福什么的。

举一个生活小例子，一个孩子，硬是不听话，我晓得这个孩子最喜欢吃糖，那么通过换位思维，就知道如果想要他听话，给他想要的糖，那么他就会去做什么。

这样一个孩子，你只要给他一颗糖，叫他去给你拿牙签，他马上就去，如果你之前没跟他说明白他能得到的好处，他也不会给你好处。更不会愿意按照你的意愿去行动。

记住：你给他最最想要的，他就会给你想要的。这就是本质规律，任何时候永远不会变。

我在举出一个例子。

一个顾客问：“你这里有什么鼠标，都什么价位？” ,普通情况下会说：“20元至50元都有，你要哪个？”

顾客又说了：“有什么区别？”
普通情况下我会说：“20的一般，50的比较好用”

然后顾客看看，漠视说：要20个就好了。

这时候，如何才能让顾客要50的呢？就要通过换位思考了。为什么不选择20的，而选择50的呢？

我把方向引导到50元利润更高的产品销售，而不是利润较低的20的。

顾客问：“有什么区别？”
销售员如果这样说：“50元的，用起来非常稳定，质量非常好，速度快，手感也好，给人很刺激的享受。而20的，比较普通，没有经过特殊处理，鼠标有时候会迟钝，耐用性差，有时候用起来不理想”

如果是我个人；嗯，那就买个50的。
