# 农耕思维方程式

种地思维第一步：1，确定要种啥？橘子，苹果，桃树，还是花朵培育，等。

确定种啥？在营销中可以理解为，我们的目标，选的方向是什么，简单讲，我们最终要卖什么产品。因为最终的开花，结果，是果实。

是实产品，虚似产品，实物产品。又或者技术，服务，培训，梦想，概念，资本运作，金融玩法，等。

第一步：模糊的说法叫一个想法，清晰的来说叫格局，小格局叫目标，大格局叫战略。

如果你只是一个单纯想法，并且不确定要种啥？这个时候，你永远在局外徘徊。想进入局，事事目的性，目的性很强。当然了世界还oun一种局最厉害，那就是无局。

全心全意做好一件事情，不追求失败与成功，就认真做好一件事，这就是最好的局了。世界上面最大的无私是自私，世界最好的局事无局。

确定第一步，具体要做什么，种植什么，是橘子，还是黄瓜，还是其他。那么我们将进入第二步骤。

种地思维第二步：选择种植种子的，合适的环境，土壤，以及灌溉方便，收割方便，运输等多层次进行思考。
