# 陌龙营销咨询：《布局系统》递成功内容

促销前——促销中——促销后；

前期话术——中期话术——后端话术；
前端利润——中端利润——后端利润；

前端让利——中端溢利——后端暴利；

前期广告卖点——中期广告卖点——后期广告卖点；

活动前期——活动中期——活动后；
……太多，太多营销中常用的框架节点。

因为一场活动下来，不可能我们只是单纯的做一个活动。而是要以一套思考框架，理清我们活动前期的套路，以及活动中期如何？活动后期又将如何？

通过全局于心，方能运筹帷幄。

为了更好的了解布局，我这里强烈推荐各位先看《天道》这部电视剧，其次是《三国演义》，而如果想要更进一步学习你应该看《朱元璋》这部电视剧。

通过换位，焦点，方程式等，多重思维，进行思考角色定位，做法，思考方式，那么更有助于我们整体布局，打开天眼，做到运筹帷幄之中最值得我们学习的三分电视剧。

一部好的电视剧，胜过无数个鸡汤剧，我个人非常喜欢推理，喜欢猜疑，喜欢步踩，喜欢流程，喜欢模板，更喜欢营销策划，最大的痴迷就是读书，思考，这么多年这是给我最大的收获的四个字了。

对于《天道》这部电视剧我个人看了不下7遍，对于《三国演义》我个人看了不下4遍，而对于《朱元璋》我个人不下看了5遍左右，每一次看，每一次领会，都会有很多布局，推理，思考，换位，以及管理，做人，做事，方面的一点感悟。

当然了，我的学习方式，不见得一定适合你，找到一个适合自己的学习方式，最佳的就是找到自己的兴趣点，然后去放大，那么你将收获很大。
（朱元璋是个厉害的人。他的缜密思维可以算到极致。连每个人的当下情绪都在计算之内，让叶小明，林雨绸这种聪明人的反应都在他的导向上）
