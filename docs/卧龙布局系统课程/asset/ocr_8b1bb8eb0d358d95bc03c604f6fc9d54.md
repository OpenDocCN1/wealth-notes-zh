# 卧龙营销咨询：《布局系统》速成班内容

言归正传，我们正式进入我们【布局系统】之【方程式思维】

开始学布局，如何搭建框架？

对于现在学习的是方程式思维：首先我讲一个故事，我从高中的时候，我就有这样的意识，每次看到一个东西，我会进行总结，归纳，并组成一个通用的万能模式。这也是为何我写书，每一个都尽能模式的本质原因。

比如：我们小时候去钓鱼，我们要怎么做？

+   1, 鱼饵 2, 鱼钩 3, 鱼竿 4, 人力, 物力, 资源 5, 位置, 环境, 平台

用什么鱼饵，钓鱼不同，想调什么鱼，就用不同的鱼饵。如：想钓鲫鱼就用红蚯蚓。而如果要钓混子鱼，那么我们就需要用玉米粒泡酒的玉米粒。

如果对于家装行业老板，他们最想要什么？

——用焦点思维找到 20 个以上的理由。

+   1, 人性都喜欢赚。如果我们有一个 3 天帮他赚 300 万的策划方案, 案例。他会不会动心？

+   2, 人性都喜欢更轻松, 更简单, 更快速的方法。 3 天锁定 1000 家客户, 引爆后续 500 万利润的源头。这样她会不会心动？

+   3, 人性都喜欢找捷径, 喜欢听成功的故事。 因为每当听到别人成功的故事, 就以为自己也能照着故事成功。 可不可以打造这样几个, 非常成功的故事。 如：他是如何做家装年入千万的？

如果有, 直接利用。 如果没有, 怎么办. 各位?

+   1, 你可以考虑整合一些家装成功的人过来。

+   2, 你可以打造, 假装制造这一批成功故事出来。

+   3, 你可以设计一个系统, 有系统, 组织, 圈子, 推送案例通过一些真实性, 可靠进行打造 真正盛利的一个故事。

记住一点：所有的营销设计流程, 方程式。都是围绕人性设计。

人性喜欢听成功案例, 我们就多讲成功案例。
