# 陆龙营销咨询：《布局系统》達成斑内容

第三步：选种子客户
第四步：第一次接触
第五步：培育，教育客户，逐步建立嫁接信任。
第六步：有了足够信任了，我们种植的东西，就等待开花，结果，收获果实了。

这个时候，我们进行放出消息，要搞产品活动，或者预售某个产品，或者新产品发布会的等要出来。产品开花还不行，还要最重要的是上粉，要给他们希望的种子，要给他们梦想，和灵魂。

上粉也可以理解为：给让客户期待的赠品，送出去超值的赠品，让客户感觉超值。

另外成交的时候，客户还会有疑问，需要打药，就是做疑问咨询，解决客户所有的疑惑，风险，以及要购买的理由，和要享受的售后服务等。

为了更好的开花结果，我们可以施肥，就是成交催化剂，限定数量，人数，产品数量，赠品数量，预售数量，来打造这样一种快速成交的紧迫感，危机感，进而让消费更加快速。

记住这几句话：

+   1, 在没激发痛点，撕开伤口之前一定要做什么狗狗底促销。
2, 在没建立信任前，千万别提什么产品，什么套餐，或者活动。
3, 在没激发梦想的情况下，千万不要预售产品，或者某个新产品。
（激发痛点，建立信任，激发梦想，包装形象）
4, 在没放放风险ian机制导入，和卖点之前，千万不要进入紧急销售状态。

营销就是一场游戏，一场心理游戏，心理博弈的游戏，同时也是全心全意为消费者着想的游戏。
