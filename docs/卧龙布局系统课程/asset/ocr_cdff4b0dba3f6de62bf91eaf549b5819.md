# 卧龙营销咨询：《布局系统》速成班内容

其中趣味用的就是：他们店最拿手的一道蒸香鸡，价值 68 元。只要到店里，就可以通过活动券，就可以免费领取一份。

就这样一个卷，送出去。送了几十万张。收回来的大约有几千张。

而活动中期：人流来了，如何让人流留下来，并产生购买？以及如何让客户，进行口碑宣传，增加活动的效果？——人来了，就采取充卡锁定的模式。

是朋友圈转发？还是来个代金券什么？或者一卡通用的模式？

而活动后期：我们又如何让客户留下他们的联系方式，进行好后期大数据整合推广那？以及活动抽奖，做游戏，折上折，大奖有你等。

以及活动结束后，如何对接客户质量，以及负责各种售后，和其他人流等问题。因为单纯的思考一个大活动问题，很难解决真正的本版问题。如果你也在郑州，可以去趣味体验一下。
