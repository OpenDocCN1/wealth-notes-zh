# 马龙著销售咨询：《布局系统》速成班内容

他的机会就来源于。一位泰国的顾客给他一份当地的食材，说是一种泰国人最爱喝的汤，叫冬阴功汤。她回家后用这些食材做了汤，喝汤的一刹那，她陶醉了，为什么不放糖会有酸味？不放精盐会有鲜味？不放糖会有甜味？因为它们全部是用食材做出调味，酸味来自柠檬，提鲜的是鱼精，糖是椰树糖，香是柠檬叶的香、茅草的香，全部是植物做出来的美味，不是穷刨出来的。

就这样一个动作，她决定放弃原先的调味料，开始经营东南亚新鲜的食材。——她确定了这样一个小目标：

怎么样才能在北京也能喝到这样的冬阴功汤？

到了泰国，张小华去了曼谷郊区的一个普通农贸市场，走进市场的那一刻，看到琳琅满目的各种海鲜、香茅、咖喱、兰香叶……琳琅满目，她一家一家的问，一家一家比，最终找齐了当地制作冬阴功汤的全部食材。

她在当地进了一批新鲜食材带回国内，她把这些食材装成一小包一小包地送给大家，每个小包里面都装着泰国青柠檬、小红葱头、柠檬叶、香茅、南姜，爱吃辣的还会加小米辣椒。她还把做法写在 A4 纸上，写完了复印很多份，带给一位原客，她就笑呵呵的讲一遍道，“要不要尝尝东南亚的酸辣汤？”

泰国沙拉汁中有 13 种食材，她大模吃出了 10 种，然后就靠着从泰国进口的食材各种试，最后的配方是把南姜、柠檬叶、香茅等这些食材碾碎，像酵素一样盖起来让它们自然发酵，基本一晚上就试出来了。

既然确定了一个小目标，就要把这个汤做到极致。客人家人不吃辣，但北方人爱吃辣，张小华就自己研究了一种辣椒酱。她想了各种各样的配方，辣椒、菜籽油、花椒、麻椒选的都是最好的产地，然后，先炒花生米、鸡肉碎，放少量的油炸一下，然后小火熬辣椒油，放花椒麻椒，炸一段时间和后捞起来，再放辣椒，慢慢熬，熬完了再倒回去重新熬，一共七个小时。
