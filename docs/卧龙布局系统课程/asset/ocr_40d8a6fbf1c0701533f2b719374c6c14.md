提升利润点=降低成本+增加客量+增加客户消费次数+增加客户消费金额+客户参与渠道（裂变，合伙人，众筹，天猫活动，异业联盟...）+客户终身价值；

单从第一项：降低成本 我们一定可以想出不少降低成本的办法。只要你用心去想，想不出来的去看同行案例，去找同行经理拜师，贿赂，等。都一定可以找到几个解决办法。

+   1, 人工成本 可把原来的固定薪资改为，无底薪+高提成。或者部分底薪的改为，无底薪制度。但是给予比较高的提成。这样做的目的，可以大大提升员工的能动性。

+   2, 产品滞 vim成本 把销量最好的产品，放c 最显眼的地方。把滞销的，可以尽快打折销售，促销。等。

+   3, 产品供货成本 采取多加商铺联盟进货，批发商铺，或 oem 定制，等。来降低产品的成本。

4, 节约水电，物料的发放。比如：传单被客户扔了，员工要捡起来，重复使用。而不是任由大海漂泊。等一些小的成本细节。都可以作为降低成本的小细节。

这里，只要你认真去发现，都至少可以找出 3-5-10 个方法，而且立刻可以落地的小方法。看似简单，但几乎 80% 的人从没有这么想过，思考过，更别说落地地诃回事了。
