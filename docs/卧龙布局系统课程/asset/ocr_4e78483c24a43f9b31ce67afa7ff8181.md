# 卧龙营销咨询：《布局系统》速成班内容

同样，在我们层级划分过程中，仍然还有一部分 vip 客户，对产品，或服务，有着更高的要求，有定制化，个性化，专业化，高贵，荣耀，荣誉，炫耀，炫富等各方面需求。

以及灵魂，性感，别致，高雅，脱俗，脱离产品本身的一种更高层次的产品或服务享受。

那么这个时候，会有一小批人继续选择我们的顶级服务和产品，是我们个性化，别致化，高端化的一种灵魂，精神的享受和非一般的待遇。

如果单纯的设置一个产品，没有主产品，副产品，核心产品，利润产品，升级产品，豪华产品，这样一个多层次链接，那么一个企业很难真正做到利润最大化。

去过天津，的，在天津吃过煎饼果子的摊位，很有意思。

煎饼果子在普通人的眼里，就是白面+鸡蛋，摊上面糊。然后加上饼饼。即可。但是如果有机会，你去天津，天津的人对煎饼果子的吃法，简直把层次<|message|> 用上了天。

他们的煎饼果子有：

+   1, 绿豆的煎饼果子
2, 葱花煎饼果子
3, 鱼子酱煎饼果子
4, 黑豆
5, 杂面煎饼果子
6, 糯米的煎饼果子
7, 紫薯的煎饼果子
……

大概一共把煎饼果子划分为 12 个煎饼果子类型，还是一个小摊位，即使是一家这么做就算了，我发现好多家都是这样。真是把煎饼果子玩到了极致，吃到了层次的顶级。但是在外省很少看到这样的风景，唯有在天津才能目的这种差异化。

在营销布局中，会遇到很多类似这样的节点，非常重要。
