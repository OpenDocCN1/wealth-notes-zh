# 卧龙营销咨询：《布局系统》速成班内容

任何一个布局，起初头脑里面，一定是一个模糊的想法，只是部清晰而已，所以我们要搭建一个框架，那么对于布局有个整体框架进行了了解，全局于心，这就是框架的重要性了。

层次思维解决节点：搭建节点框架，进一步优化框架。

节点也是框架的一种形式，是对框架的一种优化，更准确，更有思路的针对问题，布局框架。

今天我们主要讲解【细化思维】，有目标，有换位思考，有了框架和层次，那么我们下一步就是细化落地的注意事项了。

任何高大上的理论，如果无法落地，那么这个学习，都将毫无意义——wolong

执行细化5步骤：

+   1, 市场调研，情报监控，极致市场。

对于布局细节，最靠谱，最先要做的，是市场调研，是我们所有布局的第一要义，没有数量级市场调研=项目失败；

所有营销方案制定和落地，都一定需要高手级市场（市场调研），不了解情况，就制定方案的营销人都是扯犊子。

对于此，我这里总结了一下市场调研的基本方法；

对内市场：财务数据+员工反馈数据+自身观察留痕数据+托托来体验反馈数据。

对于企业内部，知己知彼，至关重要，擒外必先安内，我们第一要义是调查企业本身的整体运营情况，是否有不到位的地方。

因为我们有一次给一家公司做策划，做了一场营销活动，营销设计的很完美，但是活动出去了，客户来了，结果员工们却无法解决一些客户的问题，导致客户来了也无法成交的情况。

对于前期，对于企业销售人员的培训，话术训练，和路演，等非常重要，后来每次做营销策划，我们都会先考虑从内解决本问题，而后从外部解决，外部问题，那么自然不会遇到今天这样的情况

+   1, 公司的服务是不是可以提升？
2, 公司的办事效率是不是可以该提升？
3, 如何激发现员工自动自发把爱给客户？
4, 去体验竞争品是如何做的？ 如何管理？ 有什么问题，自己有没有？ 有什么优势，可以借鉴？
