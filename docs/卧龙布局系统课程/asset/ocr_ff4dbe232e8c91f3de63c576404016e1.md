# 阳龙营销咨询：《布局系统》速成班内容

来自河北的刘先生是一家餐馆老板，大家都知道，近期河北连续暴雨，<|message|>来忽视，很多人因此流离失所。

刘先生的餐庁位于灾区，但他有先见之明，提前一个礼拜将物件进行转移，可以说，他没有任何损失。

刘先生告诉访问记者，他今年39岁了，5年前一直没有任何成就，没有婚姻，整天混吃混喝。由于家庭不大好，他已经做好就这样过完一生。

采访中刘先生表示，以前他从不相信神佛，他不相信有谁能够来拯救他。但自从五年前，他前往洛阳打工，结识了百慕居士，一切都改变了。

百慕居士是一位修行多年的得道师父，见到刘先生时，居士称他有贵人相，但体内五行欠缺，故此一直难以起色。如果将体内五行补齐，其贵人之相必然归来。

这里一定要记住：讲故事最具催眠效果。没有任何人不喜欢故事。而且故事，最能让人记忆深刻。

在我们销售领域，以及招商领域，或者培训市场，都有这样一个故事。但是只不过他们把故事转换成了现场【客户见证】更具说服力。

还有就是通过销售的形式这样讲：某某厂家、老板，他们一直在用我们的产品，效果非常好，而且还省钱。你看看这是他们与我们签订的合同。
