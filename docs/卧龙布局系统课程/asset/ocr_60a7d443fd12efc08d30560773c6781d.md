# 卧龙营销咨询：《布局系统》速成班内容

所以，在我们设计营销方案的时候，首先要明白，我们提升的目标是什么。

有人脑子一热就说：我要提升利润，提升客户量。
如果我们要提升客户量，什么动作都不要做，我们恨尽一切办法，看到底有哪些方法可以提升客户量？

能不能找出 ск来？ 客户从哪里来？ 无非线上+线下。

线上有那些方法？ 微信，陌陌，贴吧，今日头条，微信合伙人，微信代理，赶集，58同城，点餐平台，旅游平台，其他....

线下有哪些方法？ 诱惑吸引，免费，充值回头客，锁销，转介绍，会销，广告，口碑，其他... 异业联盟，代理，渠道...

没有捷径，所謂捷徑，都是騙人的。

如果你还是不清楚怎么做。 你把同行前3名的所有线上线下玩法，都罗列出来。 有一个，罗列一个。

什么，求佛，上香，问仙人，找大师，大多数情况下得到的除了自慰意外，可能让你距离你的目标反而越来越远。

作业：

+   1, 对于找客户 线上有哪些方法？
   要求 20个以上。
2, 对于找客户 线下有哪些方法？ 要求 20个以上。

找到你行前前3名或前10名所有的线上、线下的玩法，动作，进行解析，倒推。

拿出：纸张+笔 写下来。 没有写的，助理可以随时清理。

这里我送大家一句话：我们做任何生意，你务必需要明白你想要的结果是什么，你想要达到什么目标
如果你想要吸引客流，流量，那么你不应该参加各种所谓大湿的培训，而是要购买一些有关客流的书籍，以及相关资料，或者找一个获取客流的实操老板，都是可取的。

你如果想学商业模式？
你什么都不要做。 先把所有 30岁以上有实操经验的，有关商业模式的书籍，相关资料，视频购买过来，看一下，然后自己做一个总结。 再结合一些案例。那么所有的商业模式，你会一次性能看清。
