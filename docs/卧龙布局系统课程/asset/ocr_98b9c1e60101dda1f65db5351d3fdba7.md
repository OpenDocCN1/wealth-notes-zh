# 卧龙营销咨询：《布局系统》速成班内容

因为脑袋里是空白的，懵逼的状态。不知道从何入手。

可以看出来，我们至少能找到 5-10 个以上的方法。那么能不能找出 20 个以上方法？在聚焦这个问题情况下。答案同样毋容置疑，完全可以。

我们现在用焦点思维找到了线上 20 个方法+线下 20 个方法；如果你企业有员工，可不可以让每个人去找 20 个方法，每个人都索想 20 个。那么我们一定可以找到 40 个方法。

如果我们写出来，我们会发现，一定有重叠的部分。那么你会发现，在这个世界上对于引流，从线上—线下。那什么时候有其他方法了。　不管是所谓口碑介绍，宗教推荐，这些特殊的，最后完成也是在线下。

既然我们找到了这些方法。我们应该怎么办？　因为目前线上和线下已经成为了不可分离的一部分。任何一个节点都不能单独存在。

所以，很多做实体的老板，一定要思考：如何从线上otel到线下。如何从线下转移到线上一个交叉引流，留客，引爆转介绍客户，后端等一系列，价值贡献，闭环，金融等。

如果你是单纯做线上，没有实体，不需要实体链接，可以不去做这个作业。

我家里开了一个实体店，是做烤鸭生意的，一天能销售大概 200 多只烤鸭。　然后从线上订单烧了么，美团外卖，大众点评，这 3 个团购，点餐平台，他们获取了不少利润。

线上订单大概每天有 20-30 个。一个订单，至少要抽取几乎 17% 左右的平台利润。

简单讲，你一只烤鸭卖出去，从店面。　平台要抽取 4.25 元的利润。
