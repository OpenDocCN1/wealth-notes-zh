# 卧龙营销咨询：《布局系统》速成班内容

任何产品，任何人，包装大于形式，只有第一印象，感觉上，征服对方，让对方不可思议，惊奇，惊讶，甚至非常好奇，那么我们的目的就达到了。比如：一个电影的宣传片，一次电话营销的开场白，一次华丽的相亲，一次愉快的购物……

如果一个宣传片，不能使人震撼，那么售票就几乎无缘了，即使内容非常给力，也无异于痴人说梦。

现在：不是酒香不怕巷子深，这个世界上，永远不缺聪明的人，是金子不一定会发光，因为一直在巷子里，巷子太深，根本发不了光。即使发光，也是有限的。

播种后，种子来到我们鱼塘，我们就要施肥，浇水。虽然我们辛辛苦苦买了种子，但是不施肥，不浇水，同样，也产不出果实。我们就要释放价值，让对方感觉来到地方了。如果没价值，就不会发芽，种子就跑了，就完了，就离开我们了，那么怎么来产生果实？

所以，要想让种子存活下来，成为一个我们一个客户的种子，我们就要释放价值，从生活上，情感上，事业上，言传上，心灵，格局，思维等让其提升，赚到价值。

如果对方就会有亏欠感，种子也有灵性，也会对你有所回报。第一步没完成，就收割，那么无异于路上遇到一个人，就要不要洗头膏，这样的营销销售。就不属于营销范畴了。

当然了有些人学了点照明，拔苗助长，价值还没释放多大，就说我是来帮助大家的，同样遭受冷门。各自自卖绝终不如让种子自己感知，自己选择生长，付出一定会有收获。不付出一定不会有收获。

种地思维养五步：剪枝/继续施肥/打药/除草  让种子生产到初，中级别，经过一定时间段的继续培养，培育。

经过第二次接触，第三次接触，慢慢的对方会了解，认可，支持你，并且你给对方解决很多问题和疑惑，就会建立很多信任和无形的价值。形成依赖性。黏性也会大提升，也会关注你的动态，一表一 Determinant。

这个时候，因为第一次破冰早已经完成，很多人才会向你很多行业问题，来让你帮他除草，打药，看病等各种问题。

任何行业，都会有这样的疑问，不论是卖设备，房产，以及销售，产品本身，都会经历这样的一个阶段。这个时候，对方不排斥你，已经渐渐信任你，并且动找你帮他解决疑问和困惑。那么也是建立信任最快的方式。这个时候，也是让客户了解你，给客户安装软件，教育客户的最好时候。

客户会问？你们为什么价格那么贵？都有什么效果？同行的很多，我也迷惑，怎么区分真伪？你们给我什么建议？太多，十万为什么，但是你大概总结一下，你会发现，客户所有的问题，基本都是雷同的。
