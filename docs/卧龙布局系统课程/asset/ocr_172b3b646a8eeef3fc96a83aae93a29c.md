# 卧龙营销咨询：《布局系统》速成班内容

既然我这里教你给你，那么只要你私下去用笔+纸张，去练习，一定会有巨大的收获，而且立刻可以用的思维。

随时随地思考，于小事看道，于小局看法，于小人看佛，关注思考生活中的任何难题，疑惑，不论任何人，事，物，哪怕是别人骗人的招数，都值得我们用焦点思维和换位思维，去深入骨髓，破解密核。

我们目前学有焦点思维+换位思维。那么今天我就交给大家如何搭建框架，建设框架？

这里我送给各位 2 个字: 如果你真正能够领会，并学会以致用。那么你就可以少交学费，爱钻钱，而且做事情也会有一些自己的思路。

——一个人是否有能力，有多大能力，也体现在这 2 个字。如果你能把这 2 个字，真正搞懂，并迅速落地，那么无疑，很多所谓大师级别人物，直接别我们秒杀，并一眼看透他的玩法。

这 2 个字到底是什么？ 为什么那么神奇....
他可以让你少奋斗几年，你只需要掌握这样一种能力。

这 2 个字就是：复制

记住：一切事物都是从复制开始的，一个人的聪明程度和能力，经验，在一定基础上取决于一个人的复制能力的强弱。懂了就懂了...

比如：在充电宝刚刚上市之初，并不广为人知。这个时候，我有个朋友看到这个充电宝，觉得应该市场很大。但是这个充电宝只是在本地区推广，销售，并没有推广开。而他看到这个充电宝，迅速直接复制了一个充电宝，而且注册了商标，比这个刚开始做充电宝的铺货量更大，而且铺设的渠道，在全国范围，大范围招商，加盟。
