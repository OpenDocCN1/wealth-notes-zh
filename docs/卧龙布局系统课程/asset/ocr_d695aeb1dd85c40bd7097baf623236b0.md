# 卧龙营销咨询：《布局系统》速成班内容

言归正传，我们开始我们本周布局局第一次课程【焦点思维】

人在成长的过程中，起码会经历 3 个阶段。

第一阶段，看山是山，看水是水。
第二阶段，看山不是山，看水不是水。
这三个阶段，是山是水也好，不是山不是水也罢。

相由心生，可见之物，实为非物，可感之事，实为非事。

布局虚实，皆有发生，道是什么，说不清，到不明白，布局就是道落地的一种方式。

同样，我们看电视剧也有三种境界。

+   1, 看电视是电视剧。
2, 看电视不是电视剧。
3, 看电视还是电视剧。

第一种：属于娱乐 decorr，<|message|>... 往往是大多数人的真实写照。

第二种：属于看电视是有思维，思考在其中，就会其中电视剧的剧情，进而引生生活，思考自己的人生的一种感悟发生。

第三种：看电视，还是电视剧，更深层次，不单纯看电视剧了，而是看导演，演员，以及制作成本，预算，预售，发行量，收益等，进行估值电视剧的盈余。

同样，我们看一个经典案例，生意谬误，也有三种境界：

+   1, 看案例是案例
2, 看案例不是案例
3, 看案例还是案例

对于第一种：我指的是，很多看案例，就想着找跟自己行业一样的，比如自己是做服装的，就想找一些餐饮案例，自己是做餐饮的，就想找一些餐饮成功案例借鉴。

这种状态，属于看案例，仅仅是看案例。 一般大部分人看了案例，就是单纯，复制，模仿，照抄。

第二种：我们看案例，不是案例，而是学习这个案例，背后的基本规律，背后的基本原理，通过方案式思维写一个通用框架出来，用焦点思维+换位思维，持续破局。改造到我们的生意，生活去。

有一点用处，我就用一点，不管是什么案例，都可以很快进的用到我们的生意中去。
