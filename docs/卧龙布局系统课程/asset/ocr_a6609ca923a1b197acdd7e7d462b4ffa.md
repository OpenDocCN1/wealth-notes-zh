# 卧龙营销咨询：《布局系统》速成班内容

终于，有一天，渔夫遇见一个老人，问道：“我的技术很好，我亲手交给儿子，为什么儿子还是不得其所哉？ 究竟哪里错了，到底哪里错了....”

老人一语道破天机：“你以为很简单的事情，他们之所以做不到，你必须让他们亲自体验，体验失败，痛苦，体验外部风险，只有从体验，实操中，方可领会你的大道理。不然他们终身也不会明白”

更多内容，去体验，去实操，应用，总结，发生，你将有一个不一样的布局思维。

如果你也有孩子，请多让他们体验过程，而不是事事操心，放开心，让他们去做，不见得你做的差。如果你认为有些理论难以实践，应用。这是非常正常的，因为，我个人几十年总结的经验，如果你一把学会，我想这个世界就没有普通人了。
