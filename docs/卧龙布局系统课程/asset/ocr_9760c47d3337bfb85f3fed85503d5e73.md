# 卧龙营销咨询：《布局系统》速成班内容

经过第1-2步骤，确定了种植的产品，以及选择合适的土壤，便于收获的平台，那么我们进入下一步。

第三步骤：选种 因为市场繁杂，选择一个合适的种子或种子非常关键。

在我们营销思维中分好几种说法，可以叫产品，也可以叫客户。今天我们暂且把种子比作客户。

对于选择客户，客户会在那个平台出现，哪里我们的精准用户最多，以及种子的生存环境，消费习惯，文化境界，格局，等，都要着手要了解，进行市场调研。如果你不懂，最好找一个同行，或者业内专业玩家去市调。

我们要去谈判，要去做比三家，要确认什么样的种子/客户，才是我们真正需求的，而不是什么客户都抓，那样等于“对牛弹琴”即使付出再多的努力，也是无用功。

可以通过操作3个平台，进行做试点，然后确定我们的种子客户到底是什么样的，经常在哪里出现，有什么习惯，最想要的是什么，最恨的是什么，以及他们深爱，最痛快的痛点事什么？

我们前期可以把种子客户分为四类：A类 潜在客户 B类 意向客户 C类 普通客户 D大客户 E垃圾客户，直接删除。

通过细分，有针对性分析客户群，作出相应的方案。

学道，悟道，领悟道，道是什么，看不清，说不明白，布局就是道落实的一种形式。

种地思维第四步：翻地/挖坑，播种，施肥，浇水。完成种子的第一次生根发芽。

在营销中我理解为，在种子客户要吸引到我们轨迹中，要做一些提前的准备。翻地，挖坑，就是种子客户包装前的一种套路。

比如：我们如果要把客户导入到微信，或者导入 QQ 这种黏性很高的成交平台，又或者线下的会议营销，招商会议等。多重形式，都是种子导入之前做好的准备。

无论是线下，还是线上，包装这个环节，缺一不可。任何售钱的产品，不是你说的售钱，也不是说你真正价值多少钱，第一面，一定要给人感觉，你到底值多少钱。

记住：是感觉

第一眼：让别人震撼，让别人不可议义，甚至让对方好奇的拿来看着，这是所有成交第一面接触包装必须具备的，一个前提。
