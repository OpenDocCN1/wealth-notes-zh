# 第二章 培训

# 一、培训目的：

培训目的可概括为：培训思想、业务、管理三过硬的干部和骨干，提高分支机构的战斗力。

# 二、培训对象

+   1、新员工；
2、新的市场策略、战术执行参与人员；
3、开发新市场人员；
4、跟不上市场发展需要的员工；
5、其他需要培训的员工。

# 三、培训内容：

+   1、企业文化；
2、工作制度、工作纪律；
3、产品知识；
4、营销知识；
5、不同岗位的业务知识与实战交流。

# 四、培训形式：

+   1、全员培训；
2、部门培训（根据总体计划，分阶段、部门进行培训）；
3、传帮带（骨干带队，现场言传身教）；
