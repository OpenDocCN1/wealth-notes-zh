# 卧龙营销咨询：《布局系统》速成班内容

我们昨天给各位又布置了一个作业，很多人没有完成。 不过课程还要继续。

因为我们即使想法很多，20个方法，不可能完全践行，必须找出 7个立刻可以执行的方法，然后写下具体方法和策略后。

最后我们要做的，再继续从7个方法中，找出1-2个，记住是1-2个方法，去真正落地执行，立刻嫁接到我们生意中去。所有的方法，用好1-2个即可。找到最容易去实施落地。

最简单的，往往就是最有效的。越复杂，越难以形成规模。

记住：一定要时刻，无时不刻，在思考，我看到任何一个事情，人，事，物，环境，甚至小孩子，的一个动作，我都会思考背后的行为动机，任何行为背后一定有动机。切记，切记。

另外我们要多懂长解读，高手的玩法，才会学到的更多。因为高手一定是非常善于布局的。

用焦点思维去破局：破解同行业领袖的玩法。

而，普通人的玩法，因为无规划，不清晰，我们即使解读了，学到的东西也不会多，只会越来越少。 越解读，反越容易易乱， 发他明白可以玩的更好，为何却迟迟不动那。
