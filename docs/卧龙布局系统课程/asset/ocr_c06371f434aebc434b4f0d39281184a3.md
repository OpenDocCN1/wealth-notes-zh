# 卧龙营销咨询：《布局系统》速成班内容

这里我举一个例子《爱情公寓》这部电视剧，前2季度的电视剧，几乎收不到太多收视率，导演很是头疼。

![](bbox=[0.13, 0.27, 0.89, 0.68])

最后找到一位营销人，营销人给出一个建议：让其抓住最佳的笑点进行先前测试。---提前测试，是所有营销人，成为高手的捷径。

北京国丹白癜风广告用过一个宣传片，前期的宣传目的。是5秒钟的一个时间层次，重复了3遍北京国丹白癜风医院。其首要小目标，先建立一个认知度。

因为大众对北京国丹白癜风医院，并不熟悉，甚至非常陌生生的一个概念，如果单纯的上来就比较传统的广告，是不适合采取的。为了让我们更熟悉，建立一个认知度，也是知名度，破冰的一种概念，而采取的这样一个多次重复的宣传片。
