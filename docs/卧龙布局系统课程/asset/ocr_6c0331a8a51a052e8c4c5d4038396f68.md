# 郜龙营销咨询：《布局系统》速成班内容

一线环境，造就一线人才，二线环境，造就二线人才。具有读书习惯的家庭，那么定然容易营造读书、通古博今的一种氛围，那么孩子，以及子孙都容易受其影响，被动的话会起书来。

@所有人 如果我们各，没有这样一个环境，我想各位有没有必要去更改一下家庭文化墙，不管是什么文化，必须传递一种思想，信仰，或者哲学。这样对于你个人，以及孩子都是非常有帮助，而且影响终身的。

说起空位换位，维度思考。同样一个人，在有音乐的能量场和没有音乐的能量场，是完全不一样的。就像家庭有看书的习惯和无看书的习惯均有不同。都在无形之中影响我们的身边的人，进而影响一个人的生活，看法，见识，格局，思维方式，做事方法……

说起空位换位，就像炒房子，做生意，从国外生意引进国内，国内生意，引入国外，或者一线二线比较火爆的项目，引入到二线，三线城市，而后再次引入四线、五线城市。

3, 角度 （点-个体；线-团队，人群；面-组织，机构；体——国家，战略；）

一个人，是一个点。2个人可以组成一个线，3个人可以组成一个团队。多个团队，可以组成一个组织。多个组织，可以组成一个机构。多个机构，可以而后可以组成一个国家。
