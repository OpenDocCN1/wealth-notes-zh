# 3，优化(极致优化，持续升级)

对我们的测试文案，标题，以及内容，进一步更加极致的优化，是下一步更应该做的事情。

优化流程，优化文案，优化话术，优化成交方式，付款方式，等。一系列动作，行为。

# 4，放大（把握一个技巧放大，更多地方发挥价值）

最简单的就是最有效的，通过，市调，复制，测试，优化等多重动作。那么我们每一个步骤所做的动作，可以认为几乎都是有效行为。

完成1-4个基本执行细节，那么我们就可以完美去放大到任何地方了，只要有人存在，有人可能看到，就可能产生流量，产生价值。

对于优化流程：比如我们把推广分为流量，成交。A为流量，B为成交，在恒大地我给他们销售主管提议了一个建议：

让A去拉着房的人，其次让B去负责成交。

因为A流量，进来，只需要普通的人，普通的员工，就可以完成拉人看房的目的。然对于成交这个动作，因为关系到培训，销售话术，以及销售方案和个人经验，成熟度都都有莫大关系。我们让更专业，成交率更高的人，直接负责成交。而推广拉人的，只让他们负责推广。

那么这样一个流程优化，看似很简单，却大大的节省了大量时间和精力。以及整体的成交效率。

有些人，如：小白，小创业者，喜欢模板，推广。
而有些人，如老手，则喜欢思路，思维，方法。

对于两者，我们要针对点不同，其给予的基本落地方式不同，来解决层次的不同需求。
