# 归龙营销咨询：《布局系统》速成班内容

这个电影的，因为我认为动作片电影几乎没有什么好看，学习意义不大。

但是这个吴京的故事，的确刷爆了我的朋友圈。我们就应该总结一个方程式，学习一下吴京的成功。

那么很显然，这个吴京一定有背后公司公司，推广/他的个人故事，而且也付费给一部分媒体进行励志故事的讲解。

至于为什么这样讲，几乎每天我都看到腾讯新闻推送一篇《吴京——战狼2 票房逆袭 8 亿元，10 亿元 15 亿元 20 亿元》

如果他没有付费，为什么会这样推送呢？其实励志的故事比广告还 TM 有效。

其实很多做微商的，以及做培训的，如果他们要做推广，我的建议是：你不如讲一下自己怎么逆袭成为百万元翁，甚至亿万富翁的。你把这个故事讲出去，就会有很大部分人跟你学习。——但是你要是单纯做广告，效果绝对很差。

首先我们先做一个分解：《战狼2》为什么传播到我们朋友圈。说起讲励志故事，吴京绝对不是第一个。成龙也是讲励志成功故事的典型代表人物之一。
