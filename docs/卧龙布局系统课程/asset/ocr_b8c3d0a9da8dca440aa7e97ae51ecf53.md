# 卧龙营销咨询：《布局系统》速成班内容

术之后。

一个人选择在烤面馆的门口，租了一个小地方，开始卖烧饼，一天能赚 200 元左右。5 年之后，这个朋友终于攒够了几十万，就开了一个店。一起卖烧面和烧饼。

然而同样一个朋友，他学习了这个烧饼技术，他并没有去向他一样去卖烧饼。而是选择租贵了一个地方，开始做烧饼技术培训。刚开始，他也不知道怎么去做，就模仿别人做小吃培训的做法，做买夹模培训的玩法。慢慢，一个月有几十个学员，到几百个学员。

刚开始是自己来教。后来学员多了就请了师傅和很多血烧饼技术的徒弟，一起加入这个阵营，开始让他们做技术培训，而自己抽出更多时间，去学习，管理，广告，营销，就这样 5 年后。自己身价很快达到了千万富翁。

同样 2 个人，为何有如此差距呢。 我个人把他定义为，赚钱的轨道是不一样的。也可以这样讲，卖实品的，永远不如卖技术的轻松，赚钱。可能你没有意识到，也没有总结过，希望各位私下一定要做一些分析。会发现这个会非常神奇。同样，卖技术的，不如卖培训，卖代理的。

你技术再厉害，卖的地方有限。而培训领域，是人人都趋之若鹜的地方。比如；因为人性都想成功。没有钱想成功，有钱的想更成功。——培训市场，永远缺市场。可以这样讲，培训行业，永远是蓝海行业。
