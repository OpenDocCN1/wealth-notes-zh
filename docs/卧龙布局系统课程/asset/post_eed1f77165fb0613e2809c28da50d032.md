# 卧龙营销咨询：《布局系统》速成班内容

1, 多 Logo 店招牌设计，周边商业氛围越热闹，则 Logo 越多，这样越能吸引别人注意力。

![](img/97ae2452ff6b1bbbd43c7dcd5c97346c_27_0.png)

2, 周边商业氛围越简单，则 logo 数量越大，只因视觉干扰因素少

3, logo 形式多种多样，甚至设计一座门；

![](img/97ae2452ff6b1bbbd43c7dcd5c97346c_27_1.png)

4, 一个大 logo+若干个小 logo

![](img/97ae2452ff6b1bbbd43c7dcd5c97346c_28_0.png)

5, 大面积玻璃橱窗做立面，通透性强，对外而言，能吸引食客的注意力，对内而言，给食客更佳观景平台。

![](img/97ae2452ff6b1bbbd43c7dcd5c97346c_28_1.png)

6, 外墙或广告牌多用暖色调，大面积红底色+金黄色搭配，烘托餐厅气氛，勾起食客就餐欲。
