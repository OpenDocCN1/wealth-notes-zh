# 卧龙营销咨询：《布局系统》速成班内容

方程式思维最厉害的，当你分析过很多行业玩法，同行玩法，可以迅速可以搭建一个自身可以复制的框架，来布局自己的框架，是布局中的框架，非常重要。——而不是始终徘徊在局外，忙不知，对方核心结构是什么样子的一种迷惑。

更多时候，不是你不知道，不明白，不理解，而是个人本身没有静下心来，去焦点思维问题，去真正深度思考一个问题，屏蔽一切干扰的情况下。那么你一定会收获太多东西。

如果这一块解决了，那么最好的方法就是去体验，体验，如果是你会怎么操作。或者去市场调研这样一类人群，做一个市场调研报告出来，至于送点礼物，礼品什么，获得真实可靠的效果，就不是很难得问题了。

【预算《想达到的效果》】人性喜欢把自己看到总是后面的效果，而别人看到的却一直是前者。以小额投入，撬动超 n 倍的回报，这就是太多人想要的，也是招商的核心密码。

看似 2 个简单的图片。其实就暴露了人性的本质。所有招商的核心，也在于上面这 2 个点。

对于营销也是如此。客户不是嫌贵，更不是没钱，即使去借点回来，或者候家资产去整合，只要你能满足他最想要的价值，收钱就会容易的很多。

如果没有塑造价值，画饼，造梦，从感受上，知觉上，认知上，以及实际结果上，让对方认为他的选择是对的。

那么你不卖给对方，对方很可能因此后悔一辈子。
