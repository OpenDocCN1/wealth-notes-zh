# 卧龙营销咨询：《布局系统》速成班内容

我想大部分是局部思考，从来没有一套完整的思维模式，进行深度的思考。必须要养成一个习惯，关注行业前几名高手，多思考他们的布局玩法，用方程式思维思考，你会立刻学到至少 100 倍数一样的收获。本句话，并不是夸大，只有体验，思考，实践过，才有发言权。

送各位同学一句活：于小事看道！ 于小局看法！ 于小人看佛！

这是一位高人送我的一句话，一定要注意这句话。切记，切记，非常重要。

于小事看道！——哪怕一个很小的的事情，日常吃饭，局桌，撒尿，等，都能从小事情中，领悟做生意，以及很多看似很大的道理，万法归一，本质规律不会变。

钓鱼-鱼塘营销； 养鸡——牧场营销； 种地——农业营销； ……

于小人成佛！——简单讲，看一个人能不能成佛，即使很小的人物，只要他能保持心静，心无旁骛，善心善待每个小生物，在某种程度上，已经成佛。而不需要去刻意去修练这样一个成佛的境界。

于小局看法！——法是机制，是游戏规则，是操纵保持人，事，物，保证在我们正确的轨道之上制度。

如果你被某个东西骗了，那么你可以迅速学会游戏这个游戏规则，看透背后机制，那么同样也可以骗很多人。——对于灰局，暂不建议去布。

什么：恋爱成衣，牧场模型，农业思维，等，本质规律都是一样。都是从日常生活小事中生发，看着得到的各种容易理解的高大上理论。因为这 3 句话太重要，请多思考几遍。

那么怎么把小事中的现象，抽象总结出来？ 又怎么做到，把小事中的规律性抽象总结出来？

建议各位阅读以下《万能营销模式》这本书的内容，大部分都是营销布局总结的一种利用。仔细阅读多次，我想会收获很多。

另外最重要是，个人时刻保留一个随时思考，人，事，物的一种习惯。至关重要。 前期依靠自身理解先写一个小方程式，而后经过很多案例的再次优化，那么通过第一次经历，第二次就会容易一些。 分析的越多，收获越多。

95%以上的人，几乎都喜欢吃现成的，从来不会思考背后的本质规律，更不会找更多案例，再次总结，优化，是个人做事习惯的一种缺陷。
