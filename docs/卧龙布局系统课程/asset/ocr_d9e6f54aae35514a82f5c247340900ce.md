# 郝龙著销售咨询：《布局系统》速成班内容

除了线上，影院发行渠道之外。剩下就是线上付费会员平台购买，播映权，使用权。聚合系列，北京文化，和瑞文化等各大公司，都可以把他们手中的平台资源，对接百度影视，爱奇艺，ppt,优酷，乐视，等各大在线视频网站和电视平台。

这些线上渠道+线下渠道，只能是一个推荐，播放的作用。并不能带来足够好的口碑和足够的181影响力。

简单讲，其实有很多电视，电影，几乎任何一个稍微有点资源的人，出版发行的电视，电影都可以轻松获得这些渠道。并不是太难。然而每天更新的新电影+新电视剧也奇的多。那如何从这些电影，电视剧中脱颖而出就成了一个要思考的问题。

如果一部新的电影比如《美人鱼》《我不是潘金莲》都必须经过持续炒作，才能继续引爆票房。不然很快就会沉大海。

然而《战狼2》这部电视剧，同样也需要炒作。那么一般都是怎么炒？

很简单：利用预言思维。即便票房没有达到40亿，我们先说已经达到了40亿，或假装到40亿（刷票房+刷单一样的），那么在影视界以及媒体作用下，就会疯传。为何《战狼2》会火火。这也是每个人心里世界的一种从众效应的激发。
