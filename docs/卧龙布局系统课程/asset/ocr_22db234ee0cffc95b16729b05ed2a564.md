# 卧龙营销咨询：《布局系统》速成班内容

现在留给各位10分钟时间，每个人去看一下这个故事。 然后可以思考一下我上面这个问题，进行回复。——不要单纯看故事，要看背后的原理。 是我们本次课程最大的意义了。

我们首先看一下2012年北京均价在2.4万×150m2＝360万元。

简单讲，这位女士，至少要在10年平均要赚36万元。2004年，三源里菜市场迎来改造，更换了地面瓷砖；2008年奥运会前又全部换成大理石，并完善了下水道；

门面不断升级改造的结果，就是附近过来买菜的外国人越来越多，甚至占据了客流的1/2。2008年，泰国前总理谢玛诗华，非常意外地提出要去三源里菜市场“放熘旅游”。

我们可以简单看到，在2002年-08年，她一直跟其他商户一样，单纯就是买菜卖菜的。

这里用去了6年的时间。 这个阶段，往 Strange 线不会很多，最多一年10几万的收入算是不得了了。
