# 郝龙著销售咨询：《布局系统》速成班内容

如果他能在创业开始菜之前，学过布局，先市调一下市场周围都有聊些人，有聊些需求，那他就可以提前知道聊些市场更适合这个菜市场，聊个更有利可图。

因为大家都是卖菜，如果我也是卖萝卜，白菜，青菜，西红柿，都一样。就没有差异化，最后的利润一定是大家一起瓜分。客户数量就那么多，他在别处买了番茄，白菜，就不可能再次从我们这里买。

去年，张小华还在泰国买了一个农场，专门种植香茅、南姜、柠檬叶，还有芒果，供应国内的食材。

现在，很多明星都会来她的店买食材，卧小春经营的餐厅就从她店里买的胡椒粉，她觉得她卖的胡椒粉非常地道，没有任何添加剂。

林依轮也会经常来她店里买一些东南亚的香茅、柠檬叶、南姜，还有一些香料、中草药，有时拿着很大的罐子来装。谢霆锋在《十二道锋味》里面做沙沙，面条也是从她这里买的。在张小华看来，明星和其他顾客并没有什么不同，大家都是热爱美食的人，喜欢食材最天然的味道。

她未来的计划是，准备把一些东南亚食材通过淘宝等互联网平台卖向全国，另外她还准备和人合伙开一间专卖进口食材的超市，把真正天然的食材介绍给更多消费者。

对于张小华的成功。 不在于他熟了 10 年卖菜，也不在于个人运气。

我认为他的成功在于：1，迎合了市场趋势（使他比较多） 2，把一件事情做到极致的功夫（把产品做到极致，就能脱颖而出） 3，稍微会一点营销投资策略。
