# 第四章 渠道策略

+   一、标准：小型城市只允许一家经销商
二、要求：
1、所有办事处和二级代表处要把和经销商拟订的合同等有关资料传回管理中心审批。
2、合同原件完成要寄回总部。
3、任何办事处和低级代表处或个人都不允许以任何名义跟经销商签订合同，否则视为欺诈行为。

+   三、经销商的要求：
1、在本地区有固定的销售网络，并有相对营销能力。
2、信誉好，实力强，销售网络广。
3、选择经销商应以国营为重点，私营次之。
4、与政府部门（工商、技监、防疫站等）关系好。

四、现有市场中进步经销商的实例分析：
现有十三个分公司中，只有 无锡、嘉兴、宁波、沈阳选定了唯一经销商，而且选择了一个基本符合以上五点要求的经销商（指市区，不算周边）这四个地区的零售价比其他几个城市要稳妥。其他 9 个城市经销商为 2-5 个，当酸白金成为当地畅销产品时，出现了以厂商的价格想象，造成终端位混乱。即零售商到一个经销商处批发多种大量产品时，其中最贵卖的是酸白金， 经销商为了赚其他产品的利润，有可能将酸白金原价批发给零售商，造成批发价的混乱；零售商为了促销，也可能降低零售价，造成零售价的混乱。虽然选好家经销商有价位稳定、积极性高、渠道流向较为明显等优点，但也有 Frozen 密切面窄等缺点。在经销商铺不到货的终端，分机机构业务员要主动帮消费者补货，业务员罐输货一定要从经销商处提货，分机机构<|start|>停止向终端出货。
