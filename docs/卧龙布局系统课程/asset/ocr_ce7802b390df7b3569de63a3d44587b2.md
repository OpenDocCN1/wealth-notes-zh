# 卧龙营销咨询：《布局系统》速成班内容

计划前——计划中——计划后；

如果一个人要想减肥，就要做好层次思维，如果刚开始就想直接减成胖子，无异于痴人说梦。

那么如果我们按照减肥前期——减肥中期——减肥后期，这样一个步骤，条例，确定需要做什么，注意什么，以及随时监控，就会比较容易。

层次划分越详细，越能更清晰的布局我们的目标。

有人说有多大能耐做多大事情，但是很多人对层次，对未来，过去，现在一无所知，是非常可怕的，如果人能提前从过去，从现在知道未来的结局，和计划，那会不会就很明确要做什么层次。

我们2017年已经过了大半，可能今年很多人定了小目标，或者梦想，或者一个想法，那么是否已经实现？

这里做个调查，已经实现的可回复 2 没有的可回复 3

就在昨天，我们做了一个统计，今年我个人的目标几乎已经全面完成。足足节省了 4 个月半的时间。对于没有达成的，可能有多个方面，具体原因，我这里就不一一讲解到底为何。如果您感觉您的目标特别吃力，也不知道方向是什么，建议您可以多看看《万能通灵模式》这本书。

不知道每一步该怎么走。都可以使用一些信念策略，预见卡，环境，以及能量场，等多方面的透灵落地策略。可以帮你更容易达成我们想要的目标。

对于写这件事，我不是给别人看的。更多是给自己看的，其次是为了下一代埋下思维的伏笔。

而对于让一部分人接触这些思想，就是进一步改进，落地，升级的一种方式。

凡是预则立，不预则废。层次的利用。是从全局角度思考，划分，优化，和设置标准的 一种形式。但是如果你从未学过层次思维，很难有这样的境界和想法。

比如：我如果让某个员工做安排他做一件事情，我会说：第一步，做什么？第二步，做什么，如果遇到什么问题，第三步，又该做什么。这就是一个层次思维最简单的利用了。

当然了，日常用语，比如解读一个问题，一个案例，我也会按照层次进行划分，引流前——引流中——引流后……

事前——事中——事后；
