# 卧龙营销咨询：《布局系统》速成班内容

营销有层次：陌生——了解——好感——情人——伴侣；

比如：

![](bbox=[0.16, 0.22, 0.5, 0.65])

这样也是简单一个层次思维的利用。生活中的层次思维屡见不鲜，但是往往只是看，但从来没思考过，为什么这样划分，定位，分析，解读，领会，学以致用。

又比如我经常会有这样一层次：售前——售中——售后，进行设计售成交流程。

层次思维就是教你划分层次，让条理更加清晰，而创造的。比如：我培训员工会让其这样做。你今天上午务必把这个封面设计好。下午你把客户联系方式整理一下。晚上可以整理一下合同，做一个全面反省，顺便让黄月给你培训培训。

看起来简单的一句层次利用。给对方已经做了条理，如果你不给他设定这样一个时间安排。他可能一个封面，设计一天。这样的效率就是非常低。

层次思维：还指的是，做事情，会发展到哪一个层次，进行预言，或者预演，进而如果倒推，逆势布局。达到我们想要的结果，是布局又一个关键的思维模式。至关重要。

必须有一个清晰的思路层次，以便获得更好的计划，更好的完成布局目标。而不是上来，就想吃个饼子。

必须具有层次思维，第一步怎么做？第二步怎么做？第三步怎么做？
