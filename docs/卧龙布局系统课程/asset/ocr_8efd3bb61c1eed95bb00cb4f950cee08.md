# 卧龙营销咨询：《布局系统》速成班内容

然而你一味的去求别人，永远不会有独立思考的习惯，这是很可怕的事情。

去年我给个人订了一个小布局一个字“悟”卖10000元，能实现吗？ 我们内部群，很多都见证了。 这个小目标，很快就实现了。

学会布局，其实，并不复杂。

（逆向思维） 在什么条件下有人会买？ 进行焦点思维20个以上。

+   比如：如果不满意，可退款11000元。赠送：落地营销咨询10万元的落地咨询。如果收入没有提升30%+，随时退款。

我有个同样做策划的朋友，“4”个字卖了400万，奠定领导了一个行业，那个牧场老板非常高兴，至今为止，觉得买值了。

西贝烩面 大家应该知道。

每一个赞扬背后都有两个“慕名而来”，而每一个抱怨背后有100个“弃你而去”。经营“转告”，何其重要！

分享经营转告的方法之一，“占便宜，占大便宜”。如，郑州76人老烩面。15元一碗，但76年的人吃烩面2元，是不是占了大便宜？

他就会因为占了这个大便宜而赞扬和传播一下，带来两个“慕名而来”。这样一来全郑州76年的人都成为了他的免费业务员。

点到为止，不懂怎么用到自己公司，这里布置一个本群小作业从15个角度用焦点思维写出你经营转告的方法，让顾客成为你的免费业务员。
