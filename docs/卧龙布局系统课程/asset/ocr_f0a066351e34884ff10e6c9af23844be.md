# 卧龙营销咨询：《布局系统》速成班内容

记住一句话：这个世界不需要万能工、什么都会的人、意味着什么都不会。往往是把一件事情做到极致的人，最后都成为了某个领域的佼佼者。

王健林一生只专注于房地产。\n马云一生只专注于做淘宝，阿里。\n姚劲波一生只专注于做分类网。\n乔布斯一生只专注于做好一款手机。\n....

对于复制，这里简单举一个例子，可能生活中你看过很多案例，我这里简单说一下马云，马云的成功开始：搭建阿里巴巴线商平台，而后就是到处找风投，找投资人。

而后的而后，就是不断地处说，演说，演说让今天不电子商务，明天将无商可务，不论白天，黑夜，刮风下雨，马云一直在讲互联网创业，说的更明白一点，随时随地在成交。

然后，如果让你去复制，一定无法复制，只能借鉴一些能被我们所利用的，进行转换，时间，角度，所处的环境，以及拥有的资源，想办法那些好的我们可利用？

首先，要成为一个营销高手，我们跟马云学到第一点：就是要随时随地成交。

马云到任何地方一定会把 80%的时间，用于讲解：阿里巴巴为什么可以成功，淘宝是怎么成功的。

而后 20%随地随地讲个人理念，企业价值观，远景，梦想....\n所以要学会营销，最先做的不见得是学习，也不是学布局，而是学会成交。

而成交的本质又是什么？当然是价值交换。\n你如果无法给别人提供价值，无论是精神上，学习上，生活上，物质上，娱乐上，吃穿住行，穿，玩... 给别人贡献价值，而且是随时随地贡献价值，那么你学会赚钱就太难了。

更别说成为真正的营销高手了。记住：任何营销高手，先学的不营销。而是销售。

销售是营销的开端。学销售比学会营销更重要。懂了就懂了....

从朋友圈的一个说说，从你分享的一片日志，电子书，以及你看的一部电视剧，或者你头脑发生的一个思想，都可以传递出去，或者你觉得任何有价值的东西，都可以拿过来，经过杂交，优化，或转换成自己的思想，进行传播出去，那么你传递价值的同时，那么自己就是最大的收获，其次，更多人也会愿意因为你的价值而更喜欢你。
