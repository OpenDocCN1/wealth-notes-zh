# 卧龙营销咨询：《布局系统》速成班内容

等，要，靠，毁了很多人的 一生。 我这里强调，先挖掘自身最大的潜力，而后我们可以用借助局外去辅助，只有这样，才是本质，才有根基。才能长的更青，即便有那一天，倒下，也可以很快站起来。

出去看看别人如何玩的，如何解决问题的？ 然后空杯心态，向同行学习，向跨界行业学习，甚至跟一个植物，蚂蚁学习。都是局外的一种学习。

然后从局外，看局内，你会看到自己到底是什么东西，到底在什么水平。然后你知道下一步该做什么了。

空杯心态，时常每周，或者每月，给自己一个放空的机会，想想自己是什么东西，很重要。而不是一直在当下的环境，圈子，工作，或者生活中一直当戏笼根。

破局：（反向思维）目标？提问？

——为什么要这样做的20个理由和好处？
——我以破局只破行业前三名，只破顶级高手的局——找到原理，本质，自己生发出来的，耶那么就可以用到无数个行业中去。

记住：一个阶段只有一个重点，人不可能一个时间同时做好两件事，一次只做一件事，做完一件再做下一件，如果你能把自己定焦思考维上，其它一切都是辅助或补充，此时你不会不知道怎么做了。而迷茫了。

很多人讲：关键要善悟性，什么是悟，如果你能举一反三，举二反六，这就是悟性。

太多人不喜欢自己动脑筋，一味依赖别人，稍有不满意，就埋怨开来。所以这就是当下为何进步非常慢的本质原因。

没有专注力的人生，就似佛大睁着双眼却什么也看不见。

你的目光在哪，你的人生就在哪。焦点思维就是教你瞬间成为顶级高手的核心法宝。

为了更好的学习系统布局思维，我再次强调，一定要看《天道》这部电视剧。利用焦点思维分析关键人物。

你会更了解什么叫运筹帷幄，什么叫高人，什么叫不是人的神人，只是思维方式，思考角度，层次不同而已。

看一部好的电视剧，跻足看几百部肥皂剧，我个人看了至少7遍，包括最近我个人再次分析，又领悟了很多新的东西出来。
