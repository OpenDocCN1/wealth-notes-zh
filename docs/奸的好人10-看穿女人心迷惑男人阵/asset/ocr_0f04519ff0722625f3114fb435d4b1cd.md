# 后记

在春秋时代，魏文王找天下第一名医扁鹊医病，魏文王见到扁鹊后，急问：「我听说你们是医药世家，兄弟三人都是当今的三大神医，到底谁的医术比较厉害？」

扁鹊说：「大王，大哥医术最好，但最没有名气；二哥医术排第二，名气也是第二；我医术最差，可是名气最响亮，名气是天下第一。」

魏文王听了之后，一面疑惑：心想：「岂有此理！这个扁鹊勾魂手段可挺厉害的！」

因此，不得不放下身段向扁鹊问道：「扁神医，为什么会如此呢？医术第一，名气最差；医术最差，反而是名气第一呢？你不要用权谋手段耍老子了；有话直说吧！」

扁鹊眨一眨眼说：「大王，扁神医不敢耍权谋手段，我是实话实说，我想指出天下苍生没有慧眼，才有如此一说啊。」

魏文王更加好奇地说：「神医，此话怎么说呢？」

扁鹊叹了一口气说：「我大哥医病，是看到病人病情还没发生之前，就出手给予食疗医治了，因此被医好的人都看不到大哥的功劳；但，二哥医病是在病情刚刚发作时才出手，所以很多人以为他只能医疗比较轻微的小病；我即看不出病情还没有发作前的症状和病情刚刚发作时的切入位，我只知道在病情爆发之后，需要做大手术时才出手，所以我用了很多古灵精怪的医疗手法，因此，很多人会错觉我的医术高明，所以名气最大。」
