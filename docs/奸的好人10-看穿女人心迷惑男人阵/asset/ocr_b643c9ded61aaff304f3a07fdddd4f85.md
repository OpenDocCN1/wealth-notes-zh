多一件！

在那个场合之中，赞美对方任何事，原来是可以很受用的；因为我看到那女人开心得像小鸟一样，而我的朋友也顺势搭住她的肩膀！

想不到，原来运用语言技巧，男人是可以很容易结识得到陌生女人的！

诸位读者，你们可要留意我这位朋友的点穴神功，他点的两道甜穴就是「品味」，如果你要赞美女人的发型，你可以先赞美说：「……你的发型很美，你是给那位发型设计师 SET 呢？」（注：这句「假问赞美法」是间接赞美她的手艺等同设计师，有设计师的 taste。）

接着，我的朋友出了第二招赞美法。

过了一会，只见我的朋友在不远处望向我，对着那女人说：「我在未过来之前，我的朋友说你人长得很漂亮，尤其是你那双大眼睛，真的很吸引人！」

这一招就是「借人」赞美法，例如，你看到李老师时，你可以说：「李老师，我听城邦集团的老大何飞鹏说你的头脑很像黎智英，对出版界的见地颇有黎智英的本色，又有偏向虎山行的枭雄作风。」（注：假设，李老师认识何飞鹏，这种「借人赞美法」总比说：「李老师，你的头脑很厉害，生意做得很大」强得多。）

同样的，如果我的朋友就这样说「你很美丽」，肯定不会得到她的注意。但他「借」用了我来赞她，然后又具体的说出「大眼睛」，令到这句说话的效果完全不同。

那次，看我朋友的现场示范，真让我大开眼界，也让我明白到，原来要善于把妹游戏，其实是不困难的，最重要的是你够胆量，敢说赞美的话，多用「假问赞美法」和「借人赞美法」。

# 「没想到」这三个字的威力

我还想分享，我的朋友还有成功的一幕，就是当他和那女人谈话途中，突如其来地说：「没想到你这么健谈！」（注：亦可用「想不到」）

只见那个女孩马上流露出不能置信的眼神，我马上留意到，如果只是「你这么健谈」这句话，一点意思也没有，没有什么特别，可是一旦加上「没想到」这三个字，就产生了威力，明明一句很普通的话，突然之间变得很有感染力。

理由很简单，因为「没想到」暗喻着：「我已经以为你很好，想不到你比我想像中的更好，你比我意料之外的更好。」
