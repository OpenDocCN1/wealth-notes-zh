# 龙大师的回应

「港男，港女」近期在香港的确引起很大的回响，我不会偏袒任何一方，因为两方面都有自己的论点。首先说说「港男」，因为比较简单。

其实评论港男，只有一个字：「钱」。 

我从未见过有钱的香港男人会被说成港男，因为有钱的男人，女朋友只会多到无从考虑要选择谁，而不存在「我追人，没有人理我」的问题。

我们常说「他是一个有条件的男人」，你若进一步细问，「有条件」是什么意思，不言而喻，「有条件」多指事业有成就，换言之是有经济基础的男人。

我们也听过一句话「穷心没尽，色心又起」来形容没条件的男人。

大家可要留意喔！有条件首要的重点是经济，其次为谈吐技巧、社交手腕，再次之才是相貌等。

我不是说，有钱一定可以追得到任何女人；但反过来说，如果一个男人没有钱，肯定很多女人都追不到。

我们也要明白，一个男人即使没有钱，相貌普通，但不能没有谈吐的技巧。
