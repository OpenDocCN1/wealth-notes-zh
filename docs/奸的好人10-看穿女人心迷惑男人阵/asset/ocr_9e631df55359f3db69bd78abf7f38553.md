# 男女关系是否只建立在「钱」这个基础上

# 找到真爱的女人

这个话题很有趣，也有许多顾客或朋友问过我，就是「钱是不是维持感情最重要的东西？」

其实钱真的不是万能，但没有钱就万万不能。这个道理似乎从一开始就没有变过。

我们从一踏出家门开始，每件事都离不开钱：吃饭，买衣服，看电影，全部都是和钱有关。

有一些女人，她们觉得钱并不一定是万能，她们只想着：「只要能跟他在一起，有他爱我就已经足够了！」

这些女人，她们觉得钱不是最重要，是因为她们没有尝过贫穷的滋味。

她们可能并没有想过，她们自己也是人，是人的话就离不开人的基本生理需求，可能会省吃省用，但怎样也还是需要花钱——这是人的定律。

我举一个朋友的例子，或许更能令你体验以上的看法。

她最近在谈恋爱，有一个男人追求她。这个男人对她很好，她觉得自己找到了真爱。

# 真爱与假名牌

在她生日当天，男朋友送了她一份礼物。她打开一看，哇！原来是劳力士手表，是一个最时兴的款式，她看得出，价钱很贵。

她不停地说：「你不用送这么贵重的东西给我！」但心里却很开心，甜丝丝的，她说因为男朋友送了这么贵重的手表给她，代表他很爱她。

男朋友送贵重的手表给女朋友，本来是没有什么大不了的事情，这个故事还有下文。

一个月之后，我的朋友在早上上班时，发觉手表的金属外圈有些褪色。

她很奇怪，因为这只手表戴不到一个月，怎么会有褪色的情况？

于是她就拿去手表店修理。表匠只看了一眼，就对她说：「小姐，这手表是假的，那当然会很快就褪色了！」

她简直不能相信自己的耳朵，回到家后，就对她的男朋友大兴问罪之师。
