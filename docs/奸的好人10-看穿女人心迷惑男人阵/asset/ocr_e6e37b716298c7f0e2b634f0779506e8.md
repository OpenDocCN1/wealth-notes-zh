# 两个半不离婚的男人

我也听过另一位女性朋友 M 小姐告诉我，她很清楚自己要怎样的男人。

她说，她可以上个星期跟某男人上床，同居一星期后，一发现不妥就一脚踢开他，没有任何眷恋——当然这也只是从她口中所听到的話。后来我收到「情报」，M 小姐讲到做到，不是说说而已——她固然也是个美人儿。

我曾经问她：「怎样的男人你才会一脚踢开？怎样的男人你不会一脚踢开？你判断的标准是什么？」

她笑笑说：「天底下只有两种半的男人，即使搞婚外情，很有可能也会得到女人的原谅，不会离婚。」

我好奇地问：「两种半？」

「第一种男人，他们搞婚外情，离婚机率最低的是政治人物，通常太太都会替他们站台，昭告天下说，原谅了自己的丈夫。即使像希拉里，只是在白宫罚克林顿睡沙发，虽然还在众幕僚前狠狠掴了克林顿一巴掌，但到最后还是昭告天下，他们夫妻俩没有事了，她已经原谅了丈夫，不离婚。」

「第二种男人，是超级大富豪，但是超级大富豪离婚的机率还是比政治人物高，不过与普通家庭相比，大多数富豪太太应该还是会选择不离婚……」

「为什么还有半个？」

「普通人家，中产阶级家庭，女人没有任何本事，没有任何的经济能力，只能依赖丈夫生活；若女人能有些许本事，可以不必靠丈夫，通常离婚率会提高，所以我将完全依赖丈夫生活的女人算为半个。」

# 钻石与名牌包判断法

我听了她这样说之后，即问：「你的意思是不是说，判断的标准是凭他有没有钱？」

她笑眯眯地告诉我她跟男人相处之后，会冷眼旁观，会知道他有没有钱，方法很简单，从他出手买什么礼物来判断即可。

「女人看到两样东西，眼睛会发亮、瞳孔会放大。」她继续发表她的看法。
