# 兴趣越多就越好

# 龙大师的回应

这个分享很好，当中涉及多种技巧在内，我就逐一解释一下。

人与人之间，共同兴趣是很重要的，你可以磨利自己的武器，就是有多样的兴趣，这样在和异性交往时，无论对方有何种兴趣也好，你也可以马上对上频道，拥有共同话题。

即如我，兴趣甚多，投资、看书、读小说、看电影、写 blog、摄影、计算机、当老饕四处找美食，每样都会涉猎，你想说什么话题，我就和你说什么，这些就是加大自己筹码的武器了。

另外，性格温和及有立场，说话有技巧也是很重要的，绝不会附和或模棱两可，男人最忌讳没有立场，摇风摆——我想说，这种男人不交也罢。

女人，最重要的是温柔及说话斯文，不要麻烦及不要烦人，这点是很重要的；最怕是有女人常问「你爱不爱我」及常想一些不切实际的东西来要对方符合她的要求，我很想说，这些女人很快就会被男友抛弃。

如想相恋之后感情成功，一定要交往前弄清楚对方的年纪、兴趣、背景、性格，自己再想清楚，是否适合可以发展下去。

自己提高自己的筹码，同一时间去扫描对方是否适合自己也是很重要的——其实，在一开始的时候，你要在未交往之前掌握对方的资料，从而知道自己想要的东西。

这些看似很简单，每个人也会做的事情，但实质未必有人会做的。因为有时候太过直接问对方，只会给对方觉得你「麻烦」。

# 探听对方年纪

想知对方年纪有多大，你不要问「你几多岁」，而可以说：「你今年是否要拜太岁？听说属牛，羊，狗及马今年犯太岁呢！」

如对方是正常人，想着和你进一步交往，一定如实告知；如果对方支吾以对，那你可以一脚伸开他，因为这未必是你交往的对象。
