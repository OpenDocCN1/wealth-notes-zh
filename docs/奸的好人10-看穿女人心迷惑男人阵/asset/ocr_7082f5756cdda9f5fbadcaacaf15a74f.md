# 相爱之后就要划清界线

我有一位朋友每次将女人追到手后就会说：「我是一个事业心很重的男人，所以我经常会忽略身边的女人……」

然后又告诉女方，他希望彼此有私人空间与各自的私隐，他不希望女人太过干涉他的财务与事业，朋友这样做的目的很简单，就是得手之后跟女方划清界线，让女方知道彼此不能跨越的界线是在那里。

当然，他说这些话是看时机，但这个时机绝对不能等到热恋过后，一定要在彼此「一日不见如隔三秋的热恋期」。

相爱之后，懂得划清界线的男人，是有条件的男人。

女人，你当然也可以反向操作，只要你能把持着自己，当男人迷恋上你时，尤其尚未发生任何肉体关系时，只是你给予他牵手，承认了他是你的男朋友，你就要马上跟男人划清界限。

有的男人会跟我的朋友相反的方向，他会对「正追求中」的女人说过去的感情伤痕，比如对女人说：「……当黑夜的来临，我倍感寂寥，因为我刚和女友分手，当时正下着倾盆大雨，偏偏在这个时候，我的汽车抛锚了，我学着拖车，孤独站在路边又冷又饿……」

哇，简直像电影中的情节，每次分手时总是倾盆大雨。

还未相爱，即诉说「苦情」，是希望女人看到他的「痴情」！

回想自己追求女人的经验，我应该很少说这种故事，我不是划清界线者，也不是诉说苦情者。虽然我不是「滾女王」，但很奇怪的是，我从未有追求女人的苦恼，到了今天我结婚了，我还是说一句风凉话，我看中的女人，没试过追不到。

正如我的太太形容我是很喜欢讲话的人，尤其是喜欢讲故事。打个比方，我追求她时看到大概三个月大的女婴，在我面前「啊~」了一声，我就说：「人的声音开口第一声就是啊~」就在那刻，电视正播放香港的电视连续剧，有一和尚念了阿（哦）弥陀佛，我就将电视看到的画面，连接起刚说的话，说：「刚才电视中，那位和尚念阿（哦）弥陀佛，他是念错音的，哦音是向下的，是下坠之音，啊是人类开口的第一音，是向上的，就像女婴刚才啊~啊~啊~，这就是第一音……」
