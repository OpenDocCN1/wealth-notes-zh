# 「善意的谎言」令你增强运势

我们做人不要自大，但很重要的一件事情，就是做人也不用太谦虚。

在感情生活之中，真真假假，假假真真，所有的事都对自己伴侣讲谎话当然没有好处，但也不用太过诚实，有时候「善意的谎言」反而会增强你的感情运势。

尤其是在未开始拍拖的时候，你更不能每事都如实告之。

一来不好玩、二来诚实并不能为你的感情加分。反之，你若能把握上一篇告诉你划清界线的方法，更能提高你的价值，为你的感情「加温」。

当双方约会的时候，无论男女，都要好好的炫耀自己一下，让对方不自觉地为你加分，更加快速的爱上你。但炫耀自己的方法要有两个方向，第一是「做人不要太过自大」，第二是「恰如其分的炫耀」。

我先说第一个方向「做人不要太过自大」。

有一次我为顾客看风水。顾客本是开车前往，看完之后，她主动说要送我回办公室。那里的环境偏僻，我也乐意有「顺风车」接送我回去。

我们去到了停车场，就见到女顾客的房车。那是一部十年的欧洲车，在我来说已经够看头，车身保持的极好，看起来也觉得很新。

女顾客突如其来对我说：「龙大师，真不好意思，我开的是一部比较旧的二手车，希望你不要介意！」

我能搭顺风车已经很开心了，哪会计较是什么车呢？我马上对她说：「不要紧，有顺风车坐，我已经觉得很方便了，况且你的房车也不差呀！」

女顾客的这句说话，令我有所启发：就是女客人的房车根本不是如她说的那么旧，而她却事先谦虚一番，或许这番话可能是客套话，但我觉得她用得恰到好处。
