# 有钱人的男人在感情上解决九成的问题

# 心乱如麻的女人

网友 A 的分享

「龙大师，我男朋友是从事地产工作的，现在市场不景气，他就是不肯转行，说可以再试一下，平时他只是一个星期打一至三次电话给我，见面亦是一至三天。」

「他的工作时间很长，大部份时间都是我放工后在他家中 đẳng他。可能是这个原因，我们的感情日渐淡泊，他也变得不想和我沟通，有时我很躯（生气），但他不知我躯什么，很多东西都不和我说。而且我的家人也会给他压力，他自知无钱，一直也不敢对我有任何正式承诺。」

「昨天他终于和我开口希望大家冷静一下，想想我们是否能继续下去。他说我们之间有很多问题，我自己也分析过，其实都是因为无沟通而引起的。他又说不想一直拖住我，觉得我应该要找过一个更好的人。」

「我再追问下去才知道，原来他在外面认识了另外一个女人，认识了一个月，他对那个女人有好感，不过他未和那个女人表白，但他说现在对我不能一心一意了。所以想和我分手。」

「我现在的心情很乱，不知怎样做才好，我好钟意他，不过他似乎已经变心。其实平时我们相处都有些问题的，他会因为不想吵架而逃避，也不会主动解决问题，我就算对他说我有什么不满意，他都不理我。所以我很躯，但他就说我无理取闹，野蛮。到现在他才和我说我们之间有问题，我不明白为何当初他不立刻解决問題，反而要今天和我说想和我分手。」

「我说我不介意他现在无钱，我问他想几时结婚，他说可能要三十一或三十二岁，其实我都想等他，因为我对他有信心，所以我才一直捱到现在，我家人一直都反对我们在－起，因为他无钱啊。」

「但他现在竟然为了想追另一个女生而想同我分手，我们拍了三年拖！平时他对我都不算太差，不过我是觉得他好像不太重视我，有时电话都是我打给他，他就说无所谓谁致电给谁。」
