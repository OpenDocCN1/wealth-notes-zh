# 若即若离的真正意思

# 将对方的要求看成是「神的旨意」

有网友来信赞赏龙大师，其中以「神的旨意」印象最为深刻，而她也能够切切实实的应用在自己的感情生活之中。

「神的旨意」，其实是一种思想上的变换，如果你的女朋友或男朋友提出一些你觉得不太同意的要求的话（例如你想吃日本菜，你女朋友提议去吃西餐），你只要想着这是「神的旨意」，安心接受就可以了——是令自己不和对方吵架，不发脾气的一大技巧。

这位网友来信问我，怎样为之「若即若离」，因为她觉得爱男友就是爱男友，很难突然投入，然后又抽离。

此话差矣！

如果男女感情做不到「若即若离」的境界，那肯定会是大输家，因为人有两个本性：习惯及懒惰。

一样东西，偶然发生一次是好，天天发生就会成为习惯，而且，人是要被逼迫的，人总需要有压力，没有压力，人就不会想东西。

我想说，龙大师每天都开开心心，但龙大师长期都是生活在巨大的压力之中。
