# 框架规限的诚意

# 龙大师的回应

其实这个情况正是「皇帝不急，急死太监！」。

我常说，一个人的行为，谈吐，就会表露了自己心里的真正想法。

你想想，如果你约一个朋友，一个礼拜打电话邀约一次，约了半年你的朋友还是说：「我没时间，改天再约」，那你会有什么想法？

一个女人，单方面打电话，send SMS，送礼物，却永远收不到对方关心，这又有何暗示？

真相是，时间过去了，什么也得不到，到时青春失去了，本钱没有了，时间也不能回头。

每事都无十足把握时，我们可以将眼前看到的和知道的事情汇整，作一个分析，然后作出一个最好的决定。

即使做错决定，也不必自责，发生意外是常有的事，问题是：你现在所作的决定，是否是最好的决定？

这个个案，我觉得可以用一个时间框架来规范着，例如两年，三年等等，而且可以在不同的时间订下不同的目标，这样路会好走得多。

例如一年后的一月份，要储存足够的钱买结婚戒指，或，一年后的六月份，要储存足够的钱买求婚戒指……等等。
