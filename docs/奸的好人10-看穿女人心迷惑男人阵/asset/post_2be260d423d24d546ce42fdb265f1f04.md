我估计你应该听过很多次「英雄难过美人关」这句话吧！

要清楚表达自己的意思难不难？

所谓的表达就是要言之有物，不停地举例子，令人想象意会得到，绝不能含糊。

以看电影为例：与其说自己喜欢看电影，不如说喜欢看恐怖片——这还不算是好的表达能力，不过已经算得上是言之有物了。

你再感受一下，与其说自己喜欢看恐怖片，不如说出「午夜凶铃」、「诡丝」之类的电影名称——举了例子之后，是不是比较容易想象呢？

嘿嘿，你千万不要以为我在教你跟女人搭讪聊天时，跟对方大放厥词聊电影，你可别会错意啊。

### 女人最喜欢什么话题？

根据 James Houran 与 Caroline Watt 研究，男女搭讪聊天，有四个是最常见的话题，分别是：嗜好、电影、旅游、书籍。

有上千页的研究报告，数据显示着：不同的聊天话题将产生不同的成功率。

谈电影的话题，想再见面的男女不到百分之九；
谈旅游的话题，想见面的男女是百分之十八。
为什么如此呢？
答案很简单，频道不对、品味不对也！
百分之四十九的男人喜欢动作片，但只有百分之十八的女人喜欢动作片；百分之二十九的女人喜欢歌舞片，偏偏喜欢歌舞片的男人只有百分之四。
研究还发现，一般男人的开场白都非常闷，也很肤浅，比如喜欢说：「你常来这里吗？」「你是做哪个行业呢？我是文学博士兼机械工程师……」「你喜欢看什么电影？」「平时会有什么嗜好？」
有一个绝对残酷的事实告诉你：「男人跟女人说话只有三十秒的时间，女人会凭着这三十秒的时间判断想不想与你继续交往下去。」

### 实质说话训练法

许多求姻缘，向桃花运程的男人听了我的口技理论，很喜欢问：「龙大师，到底要如何提高我的『口技』呢？」

说穿了，表达能力不佳其实就是说话时欠缺「实质」。

什么是说话缺乏「实质」呢？

一位明星与妓女发生关系后，经纪人阻止明星与妓女继续交往，他们俩发生争吵，明星指着经纪人的鼻子说：「我对这位妓女是真心的，我想进一步跟她发展，我不怕流言中伤，我不怕传媒报导，真爱是需要胆识、勇气和力量的——」

经纪人冷静无情地打断对方，用没有表情且平淡的声调说：「你只是说了三组意义相同的名词。」

训练说话要有「实质」的方法很简单，说些很实在、不含糊、大家都认知的东西，你会发觉，你的表达能力会很快就提升。

譬如说，你跟对方说：「我带你去 x 电影院看电影，x 电影院座位很舒服。」表面看来这句话很实在，不过却很含糊。

你若不要含糊，则需要将 x 电影院的特色说出来：「在九龙有一家法国人经营的 x 电影院，那里的音响设备是 PXVC 系统（虽不含糊了，但 PXVC 系统不是大家都认知的东西），置身在 PXVC 音响系统，连蚂蚁爬行和汗水滴在地上的微弱声音，我们都能听得到（大家都知道蚂蚁爬行和汗水滴在地上的声音是听不到的）。」

对方愿意跟你交往的话，很可能会说：「哇，这么夸张，如果看恐怖片，不是吓死人了吗？」

再多一个例子，对方若读过《有钱人一定有偏见》，你不要说我也很喜欢这本书来附和对方，你要有深入的阐述，你应该说：「我最喜欢《有钱人一定有偏见》里面两个章节即是〈不一样的奢侈〉，这里说出了追求人生的意义其实是一种奢侈的想法，想塑造自己跟普通人不一样而已，至于〈十年人事几翻新〉，使我联想到《巾帼枭雄》柴九常常挂在口中的一句话：人生有多少个十年……」
