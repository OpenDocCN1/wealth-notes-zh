# 一段说个不停的爱情

我问太太，我追求她的时候，我是说什麽话题呢？我的话题偏什麽方向？

她告诉我，总之很多话题，不会停的，有一次，我们俩聊个通宵，再去吃早餐。

我们第一次出国旅游，我从马来西亚的吉隆坡谈到泰国，当时是由我驾车。至于是什么话题，她不记得，她认为我就是喜欢说个不停，还有，我经常会有很多问题，她的意思是无论是看过电影、电视连续剧、书本，我将许多联想到的问題，都提出<|start|>来与他讨论。

我问她：「是做讲师前，还是做讲师后才养成这个习惯？」

她告诉我，未做讲师，追求她的时候，我就是这样。

譬如我邀请她出席一个宴会，入席后看到桌子上有一对很长的公筷，我轻声在她的耳边说：「看到这双筷子你想到什么？我想到一个神仙故事，在很久以前有一个天国，那里的神仙吃东西时，他们用的筷子很长，新报到的神仙，不懂规矩，吃飯用长筷子夹菜。结果就是因为筷子过长，没有办法放到嘴里，后来他旁观其它的神仙吃饭，才发现原来用长筷子夹菜，不是夹给自己吃的，是夹给同桌对面的那位神仙吃的，这就是爱啊！等一下，你要记得夹菜给我吃喔！」（注：说这类话题，如果她不是佩服你的女友则很危险了）

有一年，我问她：「今年是鼠年，你知道十二生肖内，为什么没有猫吗？」接着我会告诉她猫怕鼠患，愿意留在人间；结果老鼠升天后，猫还继续留在人间的故事，然后将我第一次送她回家，愿意留在她的公司等她下班连接在一起，自此，她替我起了一个外号：猫猫。
