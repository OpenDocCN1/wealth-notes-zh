# 看穿女人心、迷惑男人阵

她说：「男人的头脑有加没有减，有乘没有除，男人追求女人时，若没有把妹手段，情愿出双倍的价钱来表示自己的诚意。」

这一招该怎样用呢？

比如去到某家名牌店，对某名牌装成爱不释手，摸了又摸，拿在手上，然后拉一拉那位男人的手臂说：「哇！这个不错哦！你看，适合我吗？」

假如男的扮大方地说：「要是你喜欢，我送给你啦！」

女人这时就可以轻轻拍一拍他的肩膀，半开玩笑地说：「我没钱吗？干嘛要你送？又不是跟你很熟！你又不是我什么特别要好的朋友，快说，你有什么企图。」女人可以借机轻轻推一推男人的头说：「你，你不要胡思乱想啊！」

接着，女人对男人任何的回应都给予不屑的冷漠一笑。

她目的是暗示男人，你跟我还有很远的距离，女人看到对自己有意思的男人，尤其在购物时，时时挂在口中的就是：「你不是我特别要好的朋友」，只要给予适当的触摸，基于人性本贱的原理，当女人刻意拉远距离时，男人就越想靠送礼拉近距离。

呵呵，你看，没买这本书的男人多活该，有购买这本书的女人多幸福啊！

接着，将该名牌拿在手上，这时女方要暗地里注意，男人会不会很有度地说：「我帮你拿。」

如果男人有这举动，代表着他要付钱了，女人只需要将东西交在男人手上即可，再去选购其它名牌。
