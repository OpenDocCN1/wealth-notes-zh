# 让女人不耐烦的对话

男人，你再看看网友 Jeans 说给我们听的一则笑话：
很多男人自以为有深度，其实无聊到不行。
举一位跟我相亲的主任级外科医生的对话为例，博大家一笑：

男：你好，我们约在那里见面？
我：你方便就可以，我都无妨，我不吃牛肉跟香菜，其它什么都吃（切中要点）。
男：基本上我每天都跟我妈吃饭，所以约喝茶就好，我觉得喔，某某茶坊还不错……叽啦叽啦叽啦……总之还不错。

我：没问题，你决定就好。
男：请问你的头发是长，还是短？（如果塞嗄几句才切到这话题也就算了，没有，完全没有，他切换话题都很突兀）

我：属于长发。
男：有多长呢？
我：不长不短，恰巧到肩膀。（心中觉得真怪了，明天见面不就知道了Orient？电话中如何问得清楚？）

男：那请问您平常都穿什么衣服？
我：裙装裤装都有，裙装居多。
男：那都是多长的裙子？
我：一股而言都是及膝。（要不要我写一份统计表给你？）

我：Volvo。
男：车子的型号呢？
我：S80。
男：排氯量多少？1600CC？
