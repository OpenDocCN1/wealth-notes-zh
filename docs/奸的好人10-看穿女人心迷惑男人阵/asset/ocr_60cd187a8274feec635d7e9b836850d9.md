# 龙震天序

我与李民杰老师的缘份，始于两年之前。那时候，尚未认识李老师。

某天在书店闲逛，无意中看到李老师的第一本「好的好人」系列著作《勾魂夺心洗脑催眠》，驻足一看，半个小时随即匆匆过去。

为什么这个人的文笔那样吸引人？为什么这个人的文章，这么有令人想深入阅读下去的冲动？

当下就将《勾魂夺心洗脑催眠》这本书买下来，回到写字楼（办公室）精读研究。

第二天，迫不及待再度回到书店，一口气买下李老师所有的其它著作。从那时候起，我因此而开始研究权谋术。

后来在书中发现，李老师也有个人网志的经营。于是就开始和李老师对谈。

就这样一谈就是半年。半年后，趁着李老师有机会来香港出差，就抓紧机会和李老师吃饭。

那一晚深刻记得，我们相约在香港铜锣湾时代广场吃饭。当天我们约定七点整会面，一向很怕迟到的我，已经准备好准时到达；没想到李老师比我还早，六点半已经打电话给我，说他已经到了。我心想：「李老师对人真的很有诚意呀！」

那晚相谈甚欢，大有「相见恨晚」的感觉：就这样，我们的关系已经建立。

在李老师回国后，我们持续通讯大概有一年的时间；而在那一年之中，我开始在自己的网志撰写有关男女感情的文章，没想到大受欢迎。

我说「没想到」的原因是，在香港，撰写男女感情文章的作者大多是女性，「没想到」身为男性的我，写男女感情文章也大有市场。

可能因为工作的关系，每天接触大量各行各业的客人，男人或女人都有，他们都有不同程度的感情问题。接触多了，了解多了，自然观察得到很多增强桃花运的秘诀。

因此，产生「将这些心得写在网志上让每一个人都获益」的想法。

也因为我这个人比较实际，分析力强，所以专于整理客人的资料，也很容易
