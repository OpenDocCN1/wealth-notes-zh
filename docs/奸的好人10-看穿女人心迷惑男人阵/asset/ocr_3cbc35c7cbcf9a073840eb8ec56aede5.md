# 吞噬女人心·迷惑男人阵

清朝的鬼才李渔也说：「看到窈窕美女而动心，并希望娶得美貌的妻妾，只是恢复人类原有的天性，即使圣人再生，也会同意我这句话，不会认为我这个说法不道德。」

我估计你应该听过很多次「英雄难过美人关」这句话吧！

美女固然也喜欢俊男，但在现实的世界为什么很多美女身边的男人，相貌都普普通通呢？我们也听过女人规劝女人时说：「小心男人的花言巧语、油嘴滑舌、甜言蜜语……」

言下之意说明了男人与女人要「擦枪走火」，则须凭男人「口技」了——男人靠的是表达能力和说话技巧，而不是相貌。

从这个推论，我们也发现：原来男人的内涵是跟他的「口技」息息相关，换句话说，男人的「口技」了得，很容易让女人极端偏见地错误判断他是有内涵的人。

但我们又发现有些人很有表达能力，有些人则说了很久还未能清楚地交代自己的意思。

要清楚表达自己的意思难不难？

所谓的表达就是要言之有物，不停地举例子，令人想象意会得到，绝不能含糊。

以看电影为例：与其说自己喜欢看电影，不如说喜欢看恐怖片——这还不算是好的表达能力，不过已经算得上是言之有物了。

你再感受一下，与其说自己喜欢看恐怖片，不如说出「午夜凶铃」、「诡丝」之类的电影名称——举了例子之后，是不是比较容易想象呢？

嘿嘿，你千万不要以为我在教你跟女人搭讪聊天时，跟对方大放厥词聊电影，你可别会错意啊。

# 女人最喜欢什么话题？

根据 James Houran 与 Caroline Watt 研究，男女搭讪聊天，有四个是最常见的话题，分别是：嗜好、电影、旅游、书籍。

有上千页的研究报告，数据显示着：不同的聊天话题将产生不同的成功率。
