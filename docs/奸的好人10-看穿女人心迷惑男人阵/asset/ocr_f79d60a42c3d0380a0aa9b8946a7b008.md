# 探听对方是否已结了婚

最简单是看有否戴结婚戒指，另一方面，可以用「假定法」，即是一开始时假定对方结了婚而问一些问题，来等对方否认，如对方否认，目的已达到。

你可以问：「你太太（或你女朋友）是否和你做同一类型的工作？」

然后瞪大眼睛留意对方反应，我想说的是，如果你突如其来的问一些很贴身的问题时，大多数人都会如实作答，如口是心非的话，则很容易给人看穿。

# 探听对方性格

这个就比较复杂了。因为性格确是需要时间来捉摸的，不是说出来就可以了。就算对方说「我没有脾气」或「我很容易相处」或「我很有主见」，这其实并不代表什么，可能事实是完全相反的，因为人在自己说自己的时候，通常会把一些优点加于自己身上，这并不回信呢。

这情况不如说出 C 句：「你喜欢吃什么？」很多时候已可看出大部份的东西了。

对方第一次可能会答「无所谓」。这是正常的。

你可以说：「我也没有所谓，那你想吃什么？」

如对方还在说：「我什么都可以」的话，可证明对方不是一个很有主见的人。

你要记得一句说话，就是女人永远喜欢听亲切而有力的「来！让我们去吃云吞面吧！」——这样会显得男人更有主见。

女人不是想听由礼貌，但软弱无力的「吃什么都好，随便你，我吃什么都可以。」
