# 一人少一句

两个人吵架，都一定是两个人一同吵才可以的：正所谓一只手掌拍不响，如有任何一方不出声，或不停表示歉意，就 会少了很多吵架的机会。

我和龙嫂，从不吵架，我看到龙嫂发脾气，心里只觉可爱，温柔地道：「你又发脾气啊？」

龙嫂在九成九的情况下都会笑出来。这是对手任何女性都有效的，因为当你这样说的时候，从心理的角度来说，九成九的人都会想是自己乱发脾气在先，对方是会回心想着是自己的错，当然你在说这句话的时候所用的语气也很重要，有留意到吗？我是用温柔的语气来说出这句话，如果你是用咆哮的方式，那只会火上加油吧！你看看，只要你说一句，立即化干戈为玉帛，何乐而不为？

或者你也可以用许冠文在栋笃笑时教的方法，老婆很生气，老公则说，等等再发脾气，接着老公说，先坐下来，然后扶老婆先坐下，之后，再说，再等多一会才发脾气，很快你就可以发脾气了，说完老公冲去厨房拿一杯茶给老婆，再拍一拍双手，对老婆说：「老婆，可以了，你现在可以骂我了，你可以发脾气了！」

据说，这个方法很奏效呢——道理很简单，老婆气消了。
