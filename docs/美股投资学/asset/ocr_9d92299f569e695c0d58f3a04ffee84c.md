# 未來展望

後疫情時代，加速了所有產業的數位轉型，餐飲業也是如此。在新冠肺炎疫情的影響下，許多實體店面被強制關閉，或禁止在室內用餐而改為外帶，卻因此大幅提高了App網路訂餐、顧客忠誠計畫與外送服務的普及程度，讓顧客可以更方便、更快速地享用餐點，並藉由數據分析來提高產品質量與顧客滿意度。
