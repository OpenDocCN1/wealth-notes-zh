投資人可以不斷提出問題，靠自己對公司的認知來回答，就會發現過程中搜尋資料的精準度也會大幅提升。舉例來說，一家具有轉機題材、營運狀況逐漸改善、轉虧為盈的公司可能就會衍生出下列的問題：

+   * 問：為什麼上一季發生虧損？
* 答：產品銷量未達預期。

+   * 問：為什麼產品銷量未達預期？
* 答：因為不受消費者青睞。

+   * 問：為什麼不受消費者青睞？
* 答：因為公司沒有做足充分的市場調查、產品設計不符合消費者需求、行銷方式錯誤。

+   * 問：那要怎麼解決？
* 答：端視公司目前提出的調整方案為何。

+   * 問：這種現象是一時的還是永久的？
* 答：要判斷公司股價是否被低估，未來是否有可能重新振作。
