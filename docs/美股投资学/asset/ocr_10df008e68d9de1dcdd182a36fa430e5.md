# 別讓錯過美股成爲遺憾

安納金◎(^一個投機者的告白實戰書^ 暢銷財經作家)

在我一九九七年開始踏入國際金融市場之初，美國股市就是我第一個接觸到的市場，而且讓我大為驚豔！因為無論在產業深度或廣度以及可選擇的標的，美股都是目前全世界第一大市場，不可勝數的證券代碼，有些只有一個英文字母（例如「C」是花旗集團、「F」是福特汽車、「T」是AT&T、「V」是VISA），有些則多達五個字母，不像台股證券代碼是按照不同產業類別以數字編號。美股龐大而複雜的世界，讓第一次接觸到美股的我覺得好浪漫，但也很迷惑。
