# 視覺化的分析網站・Guruocus

Guruocus 網站有免費與付費兩種版本，若是使用免費版本，財報只能看到四年的數據，重要指標的長期數據大都無法查詢，是網站的缺點之一。不過優點是，進入個股介紹頁面後，網站會將當前公司各項指標數據以視覺化的方式，與過去的歷史平均值及同產業平均值進行比較，並提供個股評分參考。下面是網站中幾個好用功能的介紹。
