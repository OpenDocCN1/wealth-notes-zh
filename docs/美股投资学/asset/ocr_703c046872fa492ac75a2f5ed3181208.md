# 美股券商比較

目前投資美股主要有兩種方式，第一種是直接在海外的網路券商開立帳戶，另一種則是由券商提供的複委託服務，即投資人不需要在獨立海外帳戶，而是委託國內券商幫你買賣國外的股票，好處是如果原本就有買賣台股，國內券商大多提供複委託服務，開通手續簡便。投資人可以根據自己的需求，選擇最有利的券商來進行交易。

以我常用的網路券商來說，主要有盈透、德美利（TD Ameritrade，簡稱 TD）與複委託帳戶，主要的差異在於手續費、可交易商品與融資成本。

# 主要特色

由於美國許多券商包括德美利、第一證券（Firstrade）與嘉信證券（Charles Schwab）都已經實施買賣股票、ETF 零手續費的服務，新手投資美股時，建議從這些低手續費的券商開始，降低自己的交易成本。

而不敢把資金匯出至國外銀行的投資人，可以選擇台灣券商的複委託服務，雖然手續費較高，至少早早買早享受，優先享受股價上漲的好處，一旦開始從美股中獲利，相信就有充分的動機去找尋更好、CP 值更高的服務。關於券商特色比較請參考表 1。
