# Total Return Calculator（總報酬計算機）

在Dividend（股息）頁面下方有「Total Return Calculator」功能，可以計算出持有該股票（含資本利得與股息收益）的總報酬，頁面右側還顯示了殖利率走勢圖。殖利率的計算公式是股息除以股價，當長期穩定配息的公司殖利率來到高檔或低檔時，可能代表股價被低估或高估。
