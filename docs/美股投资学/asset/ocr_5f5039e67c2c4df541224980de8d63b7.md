# 尋找不被時代淘汰的王者

擁有競爭優勢的公司可以在市場上持續獲利，並且為股東帶來超額報酬。除了前一章討論的公司以外，投資人還可以關注另一個族群，作為資產配置的選擇之一，那就是「股息成長股」。有投資台股的人要找到高殖利率的股票不難，但要找到像美股一樣，數十年來年年持續調高股息的公司幾乎沒有吧！股息成長股指一間公司除了配發股息給股東外，每年還會提高股息的金額，讓投資人除了享受股價上漲的資本利得，還可以累積股息的複利效果。舉例來說，蘋果公司二〇一九年每股發放〇・七七美元的股息，二〇二〇年發放每股〇・八二美元的股息，較前一年成長了六・五％。從二〇一六至二〇二〇年這五年來看，蘋果公司每年都提高了股息金額，平均每年成長率約一〇％（參考表 14）。對股東來說，持有的成本價格是固定的，但每年的收益持續增加，總報酬率也提升。對我來說，股息就是一個「獲利優先」的概念，當你支付價格（即成本）買進一家公司的股票時，除非賣掉股票才能換回現金，
