# 二、互補者：當兩項商品或服務搭配在一起，能讓兩者變得更具吸引力且發揮更大的價值，我們就可以稱兩者之間為互補品。例如蘋果以外的手機搭配AirPods系統、智慧型手機與手機內的晶片、高速網路與雲端行業的髮展趨勢等，都是很好的例子。

# 三、供應者：供應者代表兩者之间存在著相依關係，彼此互為合作夥伴，共同創造雙贏的局面。譬如品牌如果沒有製造商的支援，即使品牌形象做得再好，也沒有產品可以賣給顧客。供應鏈如果沒辦法正常運作，就會造成企業無法進行銷售，連帶影響到整體的營收表現。例如2020年爆發的新冠肺炎疫苗，許多企業的供應鏈因為受到停工與封鎖的關係而無法生產出貨，造成整個生產到銷售的運作都受到影響。
