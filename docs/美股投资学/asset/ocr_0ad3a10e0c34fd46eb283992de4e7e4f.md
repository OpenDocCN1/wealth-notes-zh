# 年報：10-K（美國公司年報）、20-F（非美國公司年報）

在每一個會計年度結束後，美國證券交易委員會要求美股上市公司依照公司規模大小，必須在六十至九十天內提交年報，也就是10-K，非美國註冊、但在美國掛牌上市的公司則需提交20-F，內容包含公司業務、組織結構、財務報表與管理層的薪酬分配等資訊，是幫助投資人進行決策的重要依據。

想要認識一家公司，最好的方式就是從閱讀一家公司的年報開始。由於每一家公司的描述都相當完整詳細，就好像幫自己上了一堂商業分析課，增強商業思維與財務思維。
