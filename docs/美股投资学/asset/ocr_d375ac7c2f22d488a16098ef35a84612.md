# 財務狀況

Praxo 的收費方式是按照「企業支薪的員工數量」去計費。雖然中小企業的員工數很少，但美國的中小企業數量其實相當多，而 Praxo 選擇從這個市場出發，不與行業中的領導者直接競爭是相當聰明的選擇。

在二〇一〇年時，Praxo 的營收僅五千七百萬美元，到二〇一九年已經接近七．四億美元（參表 23），營收成長相當快速。驚人的是，最近五年的營收平均每年都成長三七．四％，符合高速成長股的特質。
