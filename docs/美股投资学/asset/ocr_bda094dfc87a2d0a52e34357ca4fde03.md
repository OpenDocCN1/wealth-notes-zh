# 重大事项报告书：8-K

當公司有任何重大事件或公司內部變更，包括收購、破產、董事辭職或會計年度變更等事項需通知大眾時，就得提交重大事項報告書（8-K）。上市公司直接藉由 8-K 報告重大消息與異動，如此能與投資人有更好的溝通，避免媒體誤導與內線交易嫌疑。

# 内部人持股变动书：Form 4

公司董事、高階主管與其他任何擁有公司一○％股權以上的股東，在買賣股票後兩天內，皆應提供內部人持股變動書（Form 4）給美國證券交易委員會。
