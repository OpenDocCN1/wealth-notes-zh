# 總體經濟

〔總體經濟循環〕指的是經濟循環，是觀察景氣變化的指標，投資人可以針對目前的總體經濟狀況做出自己的持股配置。經濟衰退時採取防禦策略，將資金配置在穩健、抗跌的資產上；經濟成長時則採取積極策略，找到最強勁的產業與公司來投資。

世界最大避險基金「橘水基金」（BridgeWater Associates）創辦人瑞．達利歐（Ray Dalio）在《大債危機》（Principles for Navigating Big Debt Crises）一書中提到，一個經濟的循環與一國的債務管理有極大相關性，長期循環可以橫跨七十五年以上，短期循環則每十五年會發生一次重大危機，重塑整個經濟體系，進行資源的重新分配。而這個時候就是投資人創造財富的最佳機會。
