# 掌握未来语言，IT从小抓起

传统的背诵和记忆的训练虽然能够扩大 working memory（工作记忆），有助于思考深度的拓展，但在知识可以被体外存储的互联网时代，教育的首要导向是面向未来，学习并掌握IT语言。

IT编程作为一门语言，需要从小接受训练。从小学开始实行IT编码教育的印度，在全世界拥有最多的成功进入欧美企业的高层人才。相对欠缺的中国若想在未来世界里头赶上，需要改革教育——从中小学开始学习IT，适应未来，同时带来毕业即就业的社会效益。

# 自己动手，改造世界

未来教育的另一个导向是目标导向。

目前的新趋势是，教育的目标应该是能够自己动手去改造世界，即STEAM，指的是掌握了 science（科学）、technology（技术）、engineering（工程）、art（艺术）、mathematics（数学）这五门技能的人，在工作当中发现问题时，能够巧妙地解决问题，甚至更进一步地利用解决问题的方法进行创业或者推动整个社会的进步。这样才会有归属感，世界当然就会越来越美好。所以目标导向，让每个人从小锻炼发现问题、解决问题的能力。

# 热爱才能付出，兴趣铸就成功

第三个是兴趣导向的教育。

被反复提及的一万小时理论给我们一个启示，即随着社会进步，科学知识越来越深入，每个人学到的知识越来越复杂，想要成为某一方面的专家，需要付出常人不可及的努力。那么怎样才能愿意去下工夫学习呢？只能是因为热爱。因为热爱所以我们才甘愿历经艰难，甘愿付出辛苦，有这份热爱才有可能成就可以因此未来兴趣导向的教育非常重要。

总结来讲，教育需要三种导向——未来导向、目标导向和兴趣导向。

# 通识教育——信息素养+关键思维

除了各个导向，作为基础的通识教育也是必要的。随着信息量的增长越来越快，社会的变化越来越多，通识教育主要注重两个能力。

其一是信息素养，即对各种信息的判断能力——当信息极大丰富时，能够判断哪些是真，哪些是假。尤其是在大量碎片化的信息里构建自己的知识系统，一言以蔽之就是透过现象看到本质。这叫做信息素养，即 Information Literacy。

其二是 Critical Thinking，即关键思考能力（在国内被翻译为“批判性思维”）。意为如何能够更加理性、辩证地发现问题所在。

# 了解自己，掌握未来

有了这两方面的能力，通识教育还需要什么呢？了解我们自己。

人是唯一能够深刻了解自己的动物。曾经流行的《人体使用手册》一书中指出，只有对自己的行为、思维有充分的了解，才不会把自己给“用坏”。而《象与骑象人》一书则将个体比作象和骑象人的组合——理性的人通过各种努力让感性的大象按自己的设定走。

但事实上，不存在一个完全理性的骑象人，不存在一个完全理性的个体。因此了解自己的非理性部分就相当重要了。未来的教育一定要使得我们对自己的理解达到一个更深的程度，才能更好地掌握自己的未来。

# 理性的人工智能，感性的大数据

人类虽然是感性动物，但似乎理性正在逐渐胜出，尤其是在人工智能时代。但是实际上就是在这样的时代背景下，感性有了更大的价值，经验也更显宝贵。

善于利用对手感性弱点制胜的李世石在 AlphaGo面前一筹莫展，这是理性对感性的胜利。但是，纯粹理性对商业决策无益——人工智能时代，即使有了大数据，也需要人来窥探数据背后的规律、商机。反之，再有用的数据也只能被埋在数据堆里无人问津。

大数据背后的意义往往是对行业有非常深入了解的专家才能掌握，因此在人工智能时代其实经验更加宝贵，专家知识更加稀缺。

# 科技工具助攻教育，传统文化等待发掘

最后，与教育工作者探讨一些现实问题。

我认为，教育是有优胜劣汰的，传统的教育能不能得到好的传承是由两方面决定的——其本身的内容是不是在未来依然有价值？如果有价值却没人学习，就该反思是不是教育工具、方法过时了？或者内容的表现形式过时了？能否用更好的工具（如说虚拟现实）使得内容更加吸引人。

教育工作者的任务就是让大家对能在未来有价值的教育内容产生热情。很多时候，别急着埋怨对方不学，而要探讨是不是自己没有充分利用好好的工具。

另一个就是教育的核心问题——要不要继承传统文化。我认为，真正吸引人的东西不会消失，尤其是传统文化。不光是中国，全世界的传统文化都展现了回归的趋势。如何从全世界共识性的神话当中去挖掘其背后的意义，从古老的传统当中找到隐含的智慧。这些会是传统文化长盛不衰的核心。
