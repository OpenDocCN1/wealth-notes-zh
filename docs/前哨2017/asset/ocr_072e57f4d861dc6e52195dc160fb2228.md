# 技术撑腰，行业领跑

在此前的CES系列报告中曾向您介绍过，中国在无人机领域一马当先，而民族品牌大疆更是被誉为无人机领域里的苹果。接下来就为您介绍大疆。

在今年的CES上，大疆其实并没有推出新款无人机。2016年3月底，推出了一款名为Phantom4的无人机，接着在9月底推出了一款名为Mavic的消费级无人机，便宜而小巧。无人机领域暂时蓄力不发，大疆貌似“不务正业”地在CES展上推出了一款手持式的摄像设备——手机云台，将手机架设在云台上，具有防震防抖功能，成像效果可以媲美专业的摄像机。

其实云台一直就是无人机的重要技术之一，此次大疆把这一技术延展至手机，是踏实的一步，也证明其在此项技术上的不俗实力。

不仅是云台技术，无人机行业所需的很多重要技术细节上，大疆都处于领跑地位。

# 技术完备，静待应用爆发

无人机的通讯距离可以达到几公里，飞行高度可达到几千米，覆盖面很广，再加上摄像头的精度越来越高，人工智能程度也越来越高，图形处理能力越来越好，未来的发展潜力是非常巨大的。关键的爆发点在于找到巨大的应用需求。

以上就是今天给大家介绍的无人机产业的概况，基本的结论就是，随着大疆对技术的不断深化，并且进一步贴近大众，无人机应用普及已经指日可待。明天为您解读大疆和其对手的竞争。
