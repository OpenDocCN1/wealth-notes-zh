# 什么是绿色农业？

上一次世界范围内的农业变革发生在1930年至1960年期间。当时以美国Norman Borlaug博士为代表的科学家们发现并推广了具有高产、抗病特征的矮秆小麦品种，同时把机械化灌溉系统，化学合成的肥料和杀虫剂引入农业生产。结果使得全球范围内（特别是墨西哥、印度等发展中国家）的粮食产量大幅提高。

从那以后，这一整套农业体系被继承下来，成为全球70亿人赖以生存的基础。直到今天，人口持续增长和生活水平改善的愿望要求农业提供更多粮食。但是在一些地方，由于过去几十年的农业化肥滥用，粮食本身已经不再安全，生态系统变得支离破碎。所以，下一次农业变革毫无疑问将会以安全绿色为目标。

简单来说，绿色农业就是通过环境友好方式生产出大量健康的食物。但是，这绝对不是朝着所谓的完全有机食品的方向发展的。在未来农业中，转基因作物仍然会占一定比例，而且种类会逐步增多。因为正如上面提到的，转基因作物拥有巨大的市场需求。但是化学农药、化肥的使用量会逐步减少，有可能会完全消失，取而代之的是更加环保的新技术。

比如土壤微生物可以杀死潜在的病菌、害虫从而代替农药；也有微生物可以帮助农作物吸收土壤中的营养成分，从而代替化肥。随着机器人和人工智能的进入，农业生产所需的人力资源会进一步缩小。通过新一代室内培养设备，食物的大规模标准化产出变得非常有可能。

同时，基础研究也会不断产生新的成果。本周在《给植物升级》的文章中，给大家介绍的“超级光合烟草解决了植物防晒过程中的光能浪费问题”，理论上它可以使得所有植物的有机物产量增加20%。未来10年里，一定会有产品化的农作物利用此项技术提高产出。而对于光合作用的优化设计还远远没有达到科学家的预期，未来可以突破的空间还很大。

# 应该如何利用类似Phytech的高科技对中国农业进行升级改造？

目前在美国大概有80多家农业类的初创公司，涵盖了精准农业、智能农场管理、无人机和机器人辅助、智能灌溉和新一代室内种植、养殖系统等几大方面。而中国农业的首要问题就是如何生产安全放心的食品。正如王老师一直提倡的积木式创新理论一样，我认为，改善中国农业现状最好、最直接的方法就是和初创公司合作。

和美国不同，中国农民并没有属于自己的土地，他们也不确定是否明年还会耕种同一块地、种植同样的品种。即便是短期租用，个人也不太可能拥有几十、上百亩的土地。这些因素就决定了中国农民不可能为最先进的科技买单。所以政府部门应该起主导作用，根据当地的实际需求，适当引入新的科技成果为农民服务。

举个例子，一家名叫Trace Genomics的公司提供土壤测序服务，只要花费199美元，就可以分析你进行种植的土壤里有哪些病原菌存在。和往年相比，如果某种病原物数量减少或者不太可能造成危害，那么就完全没有必要再使用针对它的农药，从而减少了对环境的破坏，也降低了农民的成本。与此同时，国内的畜牧养殖企业也可以考虑引入高科技。

比如一家名叫Mastiline的初创公司推出了可以监控牛奶质量的设备，通过随时检测牛奶中的体细胞数量，能够在早期发现患有乳腺炎的奶牛。这就不需要等到奶牛出现症状才开始采取措施。既能够保证牛奶的质量，也能够最大程度上减少给奶牛使用的抗生素。
