# 尾声｜和你聊聊“前哨”的三个发心 [附彩蛋]

聊聊我做前哨的三个发心

# 王煜全

今天挨愧应该前哨团的答疑时间，回答这一周的用户问题。但今天是前哨团第一季的最后一期内容，所以我来回答一个大家普遍会问的问题，就是“为什么要做前哨这个节目”。

坦白的讲，我跟很多朋友都讲过，我们做投资和别人不一样，投资的时候，我们不光要看项目、研究市场趋势、还要顾及“投后”事宜，也就是帮助我们投的国外企业跟国内的企业做对接，帮助他们做战略调整，获得更好的发展，不是投完了就撒手。所以在做了前哨之后，忙得我甚至都有点儿不适应。

最早期胖在介绍前哨的时候也说过，我们不是为了钱，坦白讲，做前哨这个项目确实没有做投资的回报好，所以如果是为了钱，我继续做投资就好了。

那为什么还要做呢？我很多朋友都想知道。

那我就跟大家讲讲，其实是因为我有三个发心。

# 第一个发心:我有了一个大大的发现

# 第一点：全球创新的模式正在变化

我们是在国内外做风险投资，就发现创新的模式正在变化，以前都是大企业主导创新，要建立研究院，孵化出创新成果，然后再把研究院里的成果在企业里进行产品化，最后进行全球营销，这是传统大公司的创新模式。但现在，一些个人创业者组缉一个很小的班子也能做创新了，因为他们用了“积木式创新”这种思路，一个小公司只需要打造自己的一张长板，然后和研发伙伴合作研发，和设计伙伴合作设计，和生产伙伴合作生产，和销售伙伴合作销售就可以了，也就是长板和长板的合作。这样的话，原来大公司拥有的所有的职能，就被一个小公司用协作的方式式做到了，正是这种模式的出现，造成了现在全球科技创新的井喷。

所以，我们一直强调，今天的创新绝不仅仅仅在硅谷，也绝不仅仅是互联网，而是在全球。如果我们只盯着硅谷，就会出现创新的整个浪潮。

# 第二点：中国有机会参与这次全球性创新

我们发现，现在中国正处于一个分水岭上，如果我们往前走一步的话，就有机会参与这次全球性的创新。但是如果我们停步不前的话，不去做全球化，不去和国际的这次创新对接的话，我们将会失去以前的胜利成果。中国经过三十年的努力，制造业现在走到了世界最前沿，大规模的、开放性的、复杂性的产品制造，中国全球独步，没有第二家。但这一轮的创新主体是小公司，它们没有太大的可能性主动来中国，如果我们不主动走出去，就会出现错失这次创新科技升级的机会，制造业也会再次落后。

所以，坦白讲，我和“得到”，和“罗辑思维”的合作，我是非常感谢罗胖，感谢脱不花的。因为，他们给了我们这样一个平台，能够让大家，让更多的人来了解全球的创新的变化和中国的机会。

以上就是我的第一个发心，是因为我们有一个大大的发现，需要赶紧传递给国内的人们，因为中国的经济走到今天，是我们每个人努力的成果，如果我们能够再进一步，每个人都会过得更好。但是，如果我们错失了机会，我们可能每个人都会退步。所以，我希望中国的经济因为我们看到了这个发现，积极地去争取这个机会，而变得更好。

# 第二个发心：我个人有一点点小小的野心

我原来在中国做了20多年的咨询工作，给华润做过战略咨询，帮助他们进入医药领域；给华北制药做过咨询，帮助他们调整全国的市场战略；给中国移动做过咨询，移动梦网全盛那几年，我们是背后几乎唯一的支撑公司。正是以上这些经历，让我们有机会从“产业协调”的角度去思考问题。

我们发现，中国有两种人，一种是打枪的，但打中了也不是他自己瞄的；另一种是画圈的，看到别人打在了哪，就画个圈说他早知道会打在这儿。这什么意思呢？其实说白了前一种人只会低头拉车干活，却不抬头看路，也就是不能高瞻远瞩的做规划；而后一种人不能脚踏实地，认真做事。

那有没有又高瞻远瞩，又能脚踏实地的呢？

当然是有的，比如说阿里巴巴，十几年前，马云就在讨论如何能够让电商惠及所有的商人，让天下没有难做的生意，这是他的梦想。现在流行一句话是“梦想总是要有的，万一实现了呢？”但我相信，马云能够走到今天，肯定不是因为当初有梦想，因为有梦想的人太多了，而是他知道怎么能脚踏实地地实现自己的梦想。从一定意义上讲，实现梦想的能力比拥有梦想更重要。

对我而言，我在做咨询的时候也是公司的创始人和负责人，也是在做企业，所以我尤其就能够体会到理论和实践结合是多么的重要。所以，我们就格外地希望中国新一代的企业家，能够真正做到理论和实践结合。

我们常说，未来的企业没有不是科技企业的，也就是说科技会渗透到任何一个企业当中去，任何一个企业不用科技，竞争力就够强大。

那么如何使用科技，如何能够利用科技来实现企业的腾飞？

我们坚定地认为，掌握先进科技的企业家是最先进的生产力，这些人也是理论和实践的最佳结合点。现在国外的科技企业家们慢慢地在形成自己的体系，理论和实践结合得很好。所以，我们看到了这个机会，不光是自己去投资，也不是带着中国的企业家去看看，我们还和国内的经济学、理论家去合作，大家把理论和实践结合在一起总结，做到尽可能的惠及更多人。因为，一个人成功只是一个成功，但是如果能把这个成功者的成功因素上升成理论，上升成系统，就能让更多的人，甚至带动一批人来成功，这才是我们希望的。

所以，我和北大的薛兆丰老师，也是咱们“得到”平台最受欢迎的专栏之一“北大经济学课”的主理人薛老师，连续组织中国的企业家、投资人去海外看看国外的科技创新。去年我们更是邀请到了周其仁老师跟我们一起去看，他们的参与都使得我们的理论系统更扎实。我们希望中国新一批的企业家，能够在国际化和科技化的平台之上，理论和实践彻底的结合，成为国际型的企业家。

# 第三个发心：希望创造一个美美的未来

周其仁老师一直引用美国著名的投资人彼得·蒂尔在他的著作《从0到1》的书里面写的观点，就是认为这个世界上的国家，各国的人从观念上能分成四类：美国人是明确的乐观、欧洲人是不明确的乐观、还有一些地方的人属于不明确的悲观、而中国是明确的悲观。里面有句话很有趣，说全世界都认为中国将统治世界，但只有中国人不相信。

但我的理解是，其实中国人正在慢慢的从骨子里变得明确的乐观。因为几乎身边所有人都认为自己的明天会更好，认为中国的经济明天会更好。而美国，现在变成了不明确的悲观，因为虽然不是所有人都不乐观，但是很多人都对未来感到迷惘。

那么，这种明确的乐观有什么好处？
