# 组织4项前哨特别行动

# 1.美国科技创新考察行动

2016年夏天，王煜全带领美国科技创新考察团，在美国走访考察知名企业、科研机构、大学院校，参加科技创新领域大咖的访谈、研讨和交流，为你发来28份（6月15日~7月13日的文章）最新的考察报告。这次行动真正把全球科技前沿的发现和洞察呈现在你眼前。

# 2.CES展报道行动

2017年1月4日~8日，第50届国际消费电子展（CES）在美国拉斯维加斯举行，王煜全专门奔赴展会现场，为你发出15期（1月5日~1月19日的文章）前方报道，包括新应用、新趋势、新技术以及代表企业和人物。CES展是预测未来科技领域的窗口，也是分析未来市场趋势的机会。

# 3.硅谷考察行动

2017年初，结束CES展的行动，王煜全组织的前哨访学团进一步前往硅谷，拜访一系列高校和科技企业，为你发来4期（1月20日~1月23日文章）硅谷探访报告，帮你建立对“产业研究”的深度理解。
