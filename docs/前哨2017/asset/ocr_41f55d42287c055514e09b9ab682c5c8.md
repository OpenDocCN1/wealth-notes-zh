# 一家做压缩空气储能的企业

新能源电厂与传统电厂的区别：发动的时间和强度不可控，无法预期新能源的波峰与波谷，因此需要电网尽可能稳定。

一般情况下，新能源（风能、太阳能等）是无法预期的，因此便需要一个储能方案，在能量释放较多时，将波峰进行储存；在能量释放较少时，再把原先储备的能源释放出来，将波谷填上。这样，新能源电厂便能够稳定地对外提供电能了。

随着新能源电厂的不断建设，储能的需求不断增长，而新能源电厂本身的建设也很昂贵。迄今为止，太阳能发电的成本依然高于火电，再加上昂贵的储能成本，很显然是没有竞争力。所以，新能源发电最重要的是要便宜。

基于以上的背景，Lightsail公司便提供了压缩空气的储能方案，相当于让新能源电站发电后将其压缩进空气罐中储存起来，等到需要释放能量的时候再用压缩空气带动活塞，从而产生电能。也就是从电能到压缩空气，再从压缩空气到电能的两个转化。

# Lightsail的企业优势

Lightsail的方案是如今新能源储能在全球最便宜的一个方案

因为它只涉及到压缩和解压缩空气而已，不涉及其他复杂的化学反应。整个机制也是以机件的运动为主，不涉及复杂的电池结构。而且它电池的维护也比较便宜，不存在渗漏以后对环境造成污染的危险。

# 市场极其巨大

据国外预测，未来的新能源电厂会变得非常普及，而为新能源电厂配套储能本身就是一个万亿美元的市场。

# 拥有众多知名投资人

Lightsail的投资人包含了大家熟知的彼得·蒂尔（《从零到一》的作者），微软公司的创始人比尔·盖茨，Khosla Ventures（美国非常著名的风险投资基金）等，也正因为Lightsail的市场机会巨大，因此吸引了如此多名鼎鼎的投资人的加入。

# 神童创始人 Danielle Fang

![](bbox=[0.15, 0.00235, 0.9, 0.00265])

Lightsail在美国格外出名还有另一个重要原因是它的创始人，Danielle Fang，虽然是一位华裔女性，但在加拿大出生、长大，并且行为、性格、思维习惯已经完全西化。她算是一个神童了，12岁便读了大学，在12岁之前，也是一个喜欢长时间泡在图书馆研究最深奥图书的小孩。

12岁进入大学，17岁便完成课程，考进了全球最著名的高校之一，普林斯顿，攻读热力学博士。不过她在完成博士学位的半路选择了撇学创业。而Danielle的聪明之处恰恰在于，她了解美国成功的创业企业都是 BT 吴 double 长制（首席科学家贡献科技，CEO负责将科技落地成产品）。

Danielle 有非常清晰的自我定位，她知道自己会是一个非常棒的科学家，但没有太多CEO的企业经营经验。所以，她从普林斯顿赖学后，并没有急急忙忙建立自己的公司，而是选择了去硅谷打工，寻找最合适的合伙人。

在硅谷打工了一年半以后，她找到了现在的合作伙伴，Steve Crane，原MIT的毕业生，两个人一拍即合决定创业。所以，虽然Danielle Fang因为她的神童背景在国外得到了广泛报道，但是实际上她是公司的首席科学家，而公司CEO其实是Steve Crane。

# Lightsail的双赢

双长制结构是容易将科技实现产品化的，但科技创新的路途充满艰辛。

虽然Lightsail的方案最便宜，但压缩空气储能一直都面临着转化率不高的 Vindyk。国内也有做压缩充气储能方面研究的公司，转化效率只是百分之二十，而Lightsail其实已经把压缩空气储能做到了60%，这甚至是世界级的记录。而Lightsail团队仍不满足，希望做到更高。

在2015年，我曾带队Lightsail公司团队来到中国，介绍给了很多中国新能源企业，根据多家企业的反馈，发现能源储备方案的市场需求是非常明确的。

但由于Lightsail团队太追求完美，至今仍未交付产品。

虽然如此，但Lightsail公司也不是完全没有收入，在研发储能方案的过程中因为需要配套储存空气的大罐子，由于罐子既贵又笨重，且不方便使用，所以他们干脆自己研发了利用碳纤维缠绕做出来的储存空气用的罐子，既轻便又结实。

结果阴差阳错的发现空气罐本身也有不小的市场，最近甚至拿到了上千万美元的订单合同，因此这家公司是有足够的资金支持，使自己的研发能够做下去，也能够追求自己心目当中的那个完美的。

有时候，创业是存在一些小矛盾的。一方面，很多创业者都是偏执狂，追求完美，正如intel的创始人之一，安迪·格鲁夫著作的图书——《只有偏执狂才能生存》；另一方面，创业是现实的，市场以成败论英雄，必须拿到收入利润才能活下去。

而Lightsail无疑是幸运的，当它在储能上追求完美的同时，在储能罐中却收获了一个小市场，以至于它能够持续走下去。祝福Lightsail，希望它能够为新能源进一步贡献自己的力量。
