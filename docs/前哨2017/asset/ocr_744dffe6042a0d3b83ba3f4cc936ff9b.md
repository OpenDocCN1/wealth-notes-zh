VR来袭，重新定义人类生活

王煜全

今天给大家带来我们CES展介绍的第13期，在CES展会上容易被忽略的一个领域——游戏机。当然，我们指的是火爆异常的VR（虚拟现实）游戏。

以下是干货笔记，完整内容欢迎收听音频。

# VR开道，游戏先行

在今年的CES展上，VR（虚拟现实）相关的产品数量有限，如头盔等可穿戴式设计也于稀一律。更重要的是，其计算能力依然有瓶颈，因此今年可以说是虚拟现实应用的小年。

在智能家居方面，22年前，比尔·盖茨的著作《未来之路》，就设想了智能家居的蓝图，之后的谷歌收购Nest，也是旨在智能家居。然而多年过去，VR技术越来越成熟，智能家居却还是未能普及。关键的原因就在于没有好的应用支撑，有劲无处使。

也就是说，VR技术需要更直接地与市场需求相结合，找到能够一即即燃的引爆点。因此，在未来VR的推广上，对需求的挖掘依然是一个重要的主题。

就目前的形势来看，虚拟现实的一个应用与市场需求结合较好的热点，是游戏。

# 游戏VR化，平台成焦点

众所周知，游戏因平台不同玩起来有不同的体验，而游戏生产商也会根据平台的不同特性作出不同的游戏适配。简而言之，平台是游戏的关键。

此前，游戏主机在电玩平台中占据压倒性的优势地位。专有的游戏机，如Xbox，Wii，任天堂，包括Play Station这些耳熟能详的产品，都是专有的游戏主机。

随着VR的热潮，游戏平台也到起了支持虚拟现实的东风。比如微软明确提出在今年会推出支持VR的游戏机版本，Play Station则先人一步已经支持了VR。而20年前，推出过VR游戏机，但是惨遭失败的任天堂，则compression着卷土重来，要再度推出VR游戏机。因此，游戏平台的VR化，是今年值得期待的转变之年。

# 微软出手，Windows 10支持VR

多年之前就淡出CES展会的微软，在近几年悄然回归。今年更是乘着VR大热的东风，借王牌产品Windows操作系统，霸气回归。

微软在此次CES展会期间推出了支持虚拟现实的windows10操作系统，支持虚拟的触控，甚至包括头部的位置跟踪，风光无两。更有甚者，传言微软还可能会推出游戏专用电脑，直接在VR和游戏平台两方面打出一套组合拳。

# 平台之争，电脑借VR反攻？

由于市场份额的差距，游戏内容的开发商更专注在为游戏主机做适配上，电脑一直处于劣势。现在，随着VR时代对硬件支持的要求提高，拥有更强大的计算能力和图形处理能力的电脑，可能借助虚拟现实技术，在游戏领域实现翻盘。

# 巨头玩跨界，华为仍需提升

一项新技术的诞生和成熟，往往会改变某个行业的形态，甚至会促使其他领域的公司借用这项技术试水新的领域。VR技术就有着这样强大的吸引力，而这次勇于尝试的公司，来自中国，它的名字叫华为。

# 硬件助推，VR带动周边

如前文所述，VR技术需要更强大的硬件作支撑，才能一飞冲天。目前，配合VR技术的硬件产品纷纭出炉，为虚拟现实的生根发芽提供了良好的土壤。

未来的VR技术需要一整套对环境具有感知能力，并可以供第三方来开发和调用的设备，完善类似的周边也会进一步助推VR技术的成熟和普及。

# 内容带动产业，VR重塑体验

总的来说，硬件逐渐就位之后，有望在2017年下半年看到在内容领域出现一些VR的游戏精品。而精品游戏的推出，可以进一步拉动整个虚拟现实，甚至整个游戏产业的未来发展。因此，在2018年，我们有望看到整个虚拟现实硬件加软件的清晰的未来发展路径。
