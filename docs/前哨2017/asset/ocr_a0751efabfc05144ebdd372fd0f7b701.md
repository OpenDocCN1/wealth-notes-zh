# 传奇人物Carlos Ghosn

演讲者Carlos Ghosn，是一个非常传奇的人。生于巴西的一个黎巴嫩家庭，在法国长大。

在雷诺汽车公司接连亏损的时候接手了雷诺的CEO职务，而且很快使雷诺扭亏为盈。

帮助雷诺和日本尼桑公司缔结了战略联盟协议，并实现了交换持股。

同时担任尼桑公司的董事长兼CEO，也同时出任了三菱公司的董事长。

也就是说，他是三个大汽车公司的董事长，也兼任两个大汽车公司的CEO。

Carlos Ghosn掌握多国语言，永远精力充沛。他在法国的绰号是Le Cost Killer，意思是“成本杀手”，正因为他把所有不花花的钱都省掉，将利润提高，才使得雷诺迅速扭亏为盈；在日本他赢得了另一个雅号Ice Breaker（破冰者），因为尼桑当时受制于等级森严的日本传统文化，死气沉沉状况，Carlos Ghosn成功地把奖励机制和奋斗精神引入了尼桑公司，很快使经营业绩有了明显的改善。

所以Carlos Ghosn是汽车领域的一个新传奇。当然，他还有另一个绰号——“7-11”，也表明了这个传奇为什么能够实现，因为他每天都从7点工作到11点，而且一周7天都不休息，他的敬业精神和充沛精力成就了汽车领域的新传奇。

# 未来汽车产业三大方向

Carlos Ghosn说了很多有道理的东西，但大部分内容我在前几期已经和大家分享过了，也就意味着没有太多的新东西。Carlos强调未来汽车产业主要是三大方向：

# 1、电动车

电动车能够真正地实现零排放。德国计划2030年将不再出售燃油车辆，全部改为纯电，到2050年要实现整个汽车产业的零排放。

Carlos认为全球范围没有这么乐观，2030年全球的汽车销售应该有25%是纯电的。

# 2、自动驾驶和无人驾驶

人工智能是几乎各个车都需要的系统，2017年我们只能预期二级，三四级的车应该比较罕见。虽然特斯拉声称能达到三级，但由于激光雷达这样的核心器件问题，我们在判断自动驾驶车辆级别时，应当稍微保守一点。

尼桑强调未来一定是无人驾驶，但它目前推出的新车型依然还是自动驾驶，ProPILOT意思是专业的导航者，还是只起到辅助作用。新车展示中，不仅展示了自动驾驶，还展示了车内交互功能，例如尼桑公司和微软合作，利用微软的语音交互系统Cortana小娜，为用户提供语音互动服务。

但我认为它们的双工智能和其他车企相比略有逊色，例如NVIDIA已经可以捕捉车内人的动作，包括面部、眼神，甚至通过读唇来增强互动；而德国大众也在CES现场提出了更好的标准——人和车的直觉式互动，意思是人不需要学会复杂的操作技巧，下意识的动作，车也是能够完全理解的。5人笔记

# 3、车联网

Carlos认为到2025年，所有的车都会联网，并且会出现大量的共享服务。

尼桑为此和日本的互联网公司DeNA（迪娜）合作推出了无人驾驶汽车的研究计划。预计到2020年，会有100台无人驾驶出租车上路进行试商用。一旦试商用成熟，商用的扩展会非常快。所以我们还是强调2020年应该对所有的自动驾驶来说是个关键节点。

# 2017年款Leaf

尼桑一直以来是电动车的领跑者，Leaf是其2010年12月推出来的第一款车，至今为止在全球卖出了25万辆，保持销量第一。按Carlos的说法，他们已经积累了超过30亿公里的行驶里程，所以就电动车的经验而言，他认为自己甚至超过了特斯拉。

2017年推出的新Leaf定价3万美金，和特斯拉的Model 3价格（3.5万美金）接近。但Model 3声称续航里程大约200英里，而2017年款的Leaf续航里程是107英里，基本只有Model 3的一半。

但根据特斯拉官方的说法，你要拿到Model 3的新车要等到2017年下半年，甚至有很多认为，所謂下半年意思就是要到2017年年底了，也就是说，至少在这个空窗期，Leaf还是有市场的。

# 我总结出的問題

# 1、光会干不会说是不行的

Carlos Ghosn是一个非常实干的人，但是在今天这个时代，光能干不能说是不行的。尤其现在的企业家，作为企业的代言人你要会讲故事，要能够传递信号。例如我们之前介绍的Under Armour的CEO Kevin，他很会讲故事，会让消费者明白自己的定位，能够在消费者心目当中占据到一席之地，才能实现成功的销售。

所以，一个好的CEO光会说不会干不行，光会干不会说也不行。现在对CEO的要求越来越ve多，这也反映在薪水上，他的薪水里甚至包含了好多“广告费”。因为现在越来越多的公司CEO都承担着做广告的任务，如果你不会说话，这广告肯定是做不成功的。

# 2、光强调管理不能解决技术升级问题

Carlos作为拯救了雷诺和尼桑的传奇人物，现在他碰到了一个技术大交接、大转换的时代。

例如之前介绍过丰田章男出任丰田公司电动汽车事业部的总经理，明显是整个公司的CEO兼董事长，为什么非得出去任一个事业部的总经理呢？因为他意识到未来的大趋势一定是纯电动，所以此举是为了推动丰田更快地向电动车转化。而尼桑虽然是最早推出电动车的，但是现在电动车的研发明显滞后，这几年的成长速度实在太慢了。

会降低成本、会做公司重组、会激励人心是不够的，到最后竞争比的是技术优势。所以还要能够痛下决心，加大力度创新，使更新的车型能够更早推出。

# 3、2019年将是关键点

对我们来讲，这其实也留了一个悬念，我认为对小型车而言，2019年会是关键的一年。按Leaf以前的经验是两年一个提升，2017年款并不惊艳，2018年也未必能有很好的作为，那么我们接下来将期待2019年它能推出什么样的新车型，能不能有大的飞跃，能不能加入200英里俱乐部，这都值得我们期待。

整个演讲背后折射出来的是Leaf的产品销售正在下降。虽然它已造了不错的成绩，是至今为止销售最好的电动车，但是其实它这两年销售在下滑。
