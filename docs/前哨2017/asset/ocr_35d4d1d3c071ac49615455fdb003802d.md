# 装备3项科技创新理论武器

# 1. “积木式创新”

用搭积木的方式与外部企业合作，迅速获取发展所需的资源，以实现企业的高速发展。这种协作的模块化，因为是“即插即用的”，是提升社会生产效率的重要手段。

# 2. “新木桶理论”

企业和个人的水容量取决于长板，因为它不再是自己组成木桶，而是和其他长板协作。

# 3. “一千小时领先理论”

信息不对称在消解，行业经验成为公共知识，用1000小时把不同产业和领域的知识串联，即可成功实现突破。

# 3项理论的应用

这3个理论是“前哨”的行动理论基础。前哨深度解读的科技行业，多数都是通过积木式创新的方式，通过学术界和产业界的联合或者组建企业间的创新协作系统，实现科研成果转化。当你积累足够对科技的认识，掌握行业的洞察，采取行动的指导理论就是把自己的能力模块化，找到并强化自己的长板优势，参与社会协作，了解科技领域和不同产业的信息，打造个人的多维竞争力。
