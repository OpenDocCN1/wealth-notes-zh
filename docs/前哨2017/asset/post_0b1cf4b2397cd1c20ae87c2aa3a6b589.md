# 传奇人物Carlos Ghosn

演讲者Carlos Ghosn，是一个非常传奇的人。生于巴西的一个黎巴嫩家庭，在法国长大。

在雷诺汽车公司接连亏损的时候接手了雷诺的CEO职务，而且很快使雷诺扭亏为盈。

帮助雷诺和日本尼桑公司缔结了战略联盟协议，并实现了交换持股。

同时担任尼桑公司的董事长兼CEO，也同时出任了三菱公司的董事长。

也就是说，他是三个大汽车公司的董事长，也兼任两个大汽车公司的CEO。

Carlos Ghosn掌握多国语言，永远精力充沛。他在法国的绰号是Le Cost Killer，意思是“成本杀手”，正因为他把所有不花花的钱都省掉，将利润提高，才使得雷诺迅速扭亏为盈；在日本他赢得了另一个雅号Ice Breaker（破冰者），因为尼桑当时受制于等级森严的日本传统文化，死气沉沉状况，Carlos Ghosn成功地把奖励机制和奋斗精神引入了尼桑公司，很快使经营业绩有了明显的改善。

所以Carlos Ghosn是汽车领域的一个新传奇。当然，他还有另一个绰号——“7-11”，也表明了这个传奇为什么能够实现，因为他每天都从7点工作到11点，而且一周7天都不休息，他的敬业精神和充沛精力成就了汽车领域的新传奇。

# 未来汽车产业三大方向

Carlos Ghosn说了很多有道理的东西，但大部分内容我在前几期已经和大家分享过了，也就意味着没有太多的新东西。Carlos强调未来汽车产业主要是三大方向：

# 1、电动车

电动车能够真正地实现零排放。德国计划2030年将不再出售燃油车辆，全部改为纯电，到2050年要实现整个汽车产业的零排放。

Carlos认为全球范围没有这么乐观，2030年全球的汽车销售应该有25%是纯电的。

# 2、自动驾驶和无人驾驶

人工智能是几乎各个车都需要的系统，2017年我们只能预期二级，三四级的车应该比较罕见。虽然特斯拉声称能达到三级，但由于激光雷达这样的核心器件问题，我们在判断自动驾驶车辆级别时，应当稍微保守一点。

尼桑强调未来一定是无人驾驶，但它目前推出的新车型依然还是自动驾驶，ProPILOT意思是专业的导航者，还是只起到辅助作用。新车展示中，不仅展示了自动驾驶，还展示了车内交互功能，例如尼桑公司和微软合作，利用微软的语音交互系统Cortana小娜，为用户提供语音互动服务。

但我认为它们的双工智能和其他车企相比略有逊色，例如NVIDIA已经可以捕捉车内人的动作，包括面部、眼神，甚至通过读唇来增强互动；而德国大众也在CES现场提出了更好的标准——人和车的直觉式互动，意思是人不需要学会复杂的操作技巧，下意识的动作，车也是能够完全理解的。5人笔记

# 3、车联网

Carlos认为到2025年，所有的车都会联网，并且会出现大量的共享服务。

尼桑为此和日本的互联网公司DeNA（迪娜）合作推出了无人驾驶汽车的研究计划。预计到2020年，会有100台无人驾驶出租车上路进行试商用。一旦试商用成熟，商用的扩展会非常快。所以我们还是强调2020年应该对所有的自动驾驶来说是个关键节点。

# 2017年款Leaf

尼桑一直以来是电动车的领跑者，Leaf是其2010年12月推出来的第一款车，至今为止在全球卖出了25万辆，保持销量第一。按Carlos的说法，他们已经积累了超过30亿公里的行驶里程，所以就电动车的经验而言，他认为自己甚至超过了特斯拉。

2017年推出的新Leaf定价3万美金，和特斯拉的Model 3价格（3.5万美金）接近。但Model 3声称续航里程大约200英里，而2017年款的Leaf续航里程是107英里，基本只有Model 3的一半。

但根据特斯拉官方的说法，你要拿到Model 3的新车要等到2017年下半年，甚至有很多认为，所謂下半年意思就是要到2017年年底了，也就是说，至少在这个空窗期，Leaf还是有市场的。

# 我总结出的問題

# 1、光会干不会说是不行的

Carlos Ghosn是一个非常实干的人，但是在今天这个时代，光能干不能说是不行的。尤其现在的企业家，作为企业的代言人你要会讲故事，要能够传递信号。例如我们之前介绍的Under Armour的CEO Kevin，他很会讲故事，会让消费者明白自己的定位，能够在消费者心目当中占据到一席之地，才能实现成功的销售。

所以，一个好的CEO光会说不会干不行，光会干不会说也不行。现在对CEO的要求越来越愈多，这也反映在薪水上，他的薪水里甚至包含了好多“广告费”。因为现在越来越多的公司CEO都承担着做广告的任务，如果你不会说话，这广告肯定是做不成功的。

# 2、光强调管理不能解决技术升级问题

Carlos作为拯救了雷诺和尼桑的传奇人物，现在他碰到了一个技术大交接、大转换的时代。

例如之前介绍过丰田章男出任丰田公司电动汽车事业部的总经理，明显是整个公司的CEO兼董事长，为什么非得出去任一个事业部的总经理呢？因为他意识到未来的大趋势一定是纯电动，所以此举是为了推动丰田更快地向电动车转化。而尼桑虽然是最早推出电动车的，但是现在电动车的研发明显滞后，这几年的成长速度实在太慢了。

会降低成本、会做公司重组、会激励人心是不够的，到最后竞争比的是技术优势。所以还要能够痛下决心，加大力度创新，使更新的车型能够更早推出。

# 3、2019年将是关键点

对我们来讲，这其实也留了一个悬念，我认为对小型车而言，2019年会是关键的一年。按Leaf以前的经验是两年一个提升，2017年款并不惊艳，2018年也未必能有很好的作为，那么我们接下来将期待2019年它能推出什么样的新车型，能不能有大的飞跃，能不能加入200英里俱乐部，这都值得我们期待。

整个演讲背后折射出来的是Leaf的产品销售正在下降。虽然它已造了不错的成绩，是至今为止销售最好的电动车，但是其实它这两年销售在下滑。

# “奥斯本效应”发威

每当一种新型的产品即将上市的消息被放出，拥有潜在购买力的用户会被其优越的性能吸引，放弃购买市场上现有的产品，转而持款观望。
在客观上会造成现有产品的销售疲软甚至下滑，从而做到“兵马未动”，角逐已开。
这一现象，被分析人士称为“奥斯本效应”（Osborne Effect）。
2016年，在核心竞争集中于小型车方面的电动车领域中，也出现了这样的效应——此次CES展中并未现身的特斯拉公司于2016年3月31日推出的Model 3，无心有意地抑制了尼桑Leaf的销售，成为2016全年汽车产品的话题之王。

Model 3的特点十分明显，主要集中于两个方面。
一是技术性能的绝对优势——零到百公里加速小于6秒甚至4秒，续航里程直逼215英里。
二是价格的亲民路线——Model 3在价格上一改Model S“曲高和寡”的窘状，向着亲民的普及路线迈出了一大步。

然而，将话题热度变现为销售数量，特斯拉仍需下大功夫。Model 3一经推出即获得近40万辆的订单，压力不可谓不大。其宣称的2017年生产10万辆，2018年生产30万辆的计划，实现起来仍有不小的难度。

# 群雄逐鹿，传统车厂发力

传统车厂在电动车小型车领域的专注度远不及特斯拉，但2015年和2016年作为其觉醒和展示肌肉的元年，还是充分体现了大厂的优势。
和尼桑Leaf一样遭受特斯拉Model 3“奥斯本效应”杀伤的雪佛兰痛定思痛，于2016年底推出了电动小型车产品Bolt，续航200英里，性能接近Model 3，价格同样定位于亲民。

虽然在冲产量和订单上，暂时不能全面扭转局势，好在对手的对手就是朋友，各大传统车厂都纷纷加入了这场围绕小型车的混战。
比如福特公司也推出了名为“福克斯”的小型车，日本的丰田公司也携旗下产品PRIUS（普锐斯），在北美红销的余威之下，进军小型电动车领域。甚至还有欧洲的奔驰、宝马参与，以及尼桑的跟进发力。这些在传统汽车行业拥有固定领地与不俗影响力的品牌，裹挟着资金、生产链和技术的优势，一起向特斯拉发起了追逐战。

这样一来，在性能价格甚至订单数量上都强人一头的特斯拉，由于生产能力的拖累，很有可能在Model 3等待交付的2017年、2018年，甚至2019年，遭到“奥斯本效应”的反噬和各大车厂火力集中的围剿，从而丢分失地。

前景难测，市场和生产的双重压力
在油价持续走低、甚至在未来几年内预期持平的前提下，特斯拉的Model 3还需要应对主要的目标市场——美国的汽车文化的狙击。
众所周知，美国人爱大车。近年油价持续走低的大前提下，前几年迫于高油价转投低油耗的小型车的美国消费者，已经开始悄然恢复对大车的热爱。这一点在特斯拉公司的Model S在美国东西海岸的销售中出现“东冷西热”中有着清晰的体现。

同时，全力吞下大单的Model 3不仅需要面对本身的订单需求的生产压力，更困难的是，为了应对在2017、2018和2019三个年度可以预见的激烈竞争，特斯拉的Model 3需要超额完成销售任务才能实现最终的盈利。
而此时特斯拉在收购、融资中挖出的大财务大坑也开始显露负面影响。
可以说，对于Model 3、对于特斯拉，2019年是决定命运的一年。对于电动车小型车这个领域，2019年也是激烈厮杀和势力重整的一年。

# CES展·第12期 | 家电领域的跨界竞争

家电领域的跨界竞争

# 王煜全

今天是CES展会报道的第12期，给你介绍一下我在CES展会上了解的智能家电。

在CES消费类电子产品展上，家电一直唱主角。从最初的音响到黑白彩电，最终主要以电视作为家电特色，在CES展会上延续至今。

以下是干货笔记，完整内容欢迎收听音频。

# 非电视家电亮点平平

先从非电视的其他家电谈起，它们普遍亮点不多，也没有太多科技含量值得炫耀。值得一提的是以下几个产品：

- 1. 集成了亚马逊语音Alexa的LG冰箱，外形特色是冰箱门呈透明状，但受质疑的点在于用语音控制冰箱，让冰箱帮忙下单购物似乎并不是人需要；
- 2. LG品牌的草坪机器人；
- 3. 松下公司发布的桌面伴侣机器人，类似前几天介绍过的Jibo机器人，是从社交机器人思路入手的一款产品。

通过以上几个产品可以看出，目前智能家电领域确实存在着跨界竞争的局面，想要抢占家用市场的社交机器人公司也正面临着家电公司的阻击。

# 从历史上的电视看产品规律

虽在家电领域的亮点不及其他领域那么多，但是电视依旧成为了家电领域的最大亮点，不容小觑。近几年，电视产品的更新迭代甚至有了规律可循。借2012年的CES展会作为依据，看看这几个电视热点分别面临着怎样的结局：

迅速变热——
2012年，三星推出了55寸的OLED液晶屏电视。如今，五六十寸的电视几乎成了客厅的标配。

慢慢消失——
2010年前后，裸眼3D电视企图进军家电市场，但最终无论是3D电视还是3D内容，都没能被大众接受，以至于慢慢淡出了公众视野。

重新出现——
还有一种现象是“换药不换汤”，名词一直持续不变地推广，内容一直在迭代。例如，智能电视。过去在智能电视的推广上强调它的应用安装，三星公司的电视甚至能够整合上万个app供大家下载，相当于将pad和手机上的播放模式转移到电视上。现在，智能电视重新热了起来，从强调app下载转移到了语音互动、智能搜索、丰富的网络内容上，相当于智能电视和网络电视的合体。

# 今年的家电领域热点

迅速变热——

屏幕更大、图像更清晰的4K高清，它比曾经的HDTV清晰度更高出了一个量级，需要更高的带宽。谷歌公司在CES展会前迅速推出了VP9新格式，支持4K高清。

4K高清技术普及的同时也需要电视屏幕的进一步增大。这次CES展会上出现了120寸的超级大电视，这些大电视不仅尺寸在增长，也越做越薄，方便安装。预估也会变成客厅里的标配。

为了解决4K高清的普及，内容上也需要下不少工夫，LG邀请了著名内容提供商Netflix的CEO前来介绍他们在4K高清内容生产上的计划，他们将开始提供4K高清版的视频内容。

三星公司推出了QLED量子点电视，使清晰度更加饱和、更加真实地还原色彩。QLED的主要竞争对手是OLED，而索尼公司正式宣布加入OLED阵营，推出了OLED电视。两大阵营的角逐，让未来更加扑朔迷离。

中国的电视机厂商也在积极筹备，海信也宣称2019年会推出QLED电视。另一个显示屏的大厂商LG推出了一个完全不同的技术，Nano cell（纳米细胞技术），但它究竟会是未来趋势还是昙花一现，有何作为还需继续观察。

慢慢消失——

最早的电视是显像管电视，中间凸起；后来演变成液晶屏电视，大平板；如今又有 人认为平板不够好，要做曲面屏。我认为这个技术的适用性并不大，在多人同时观看时，曲面屏反而有副作用。因此，我认为曲面屏还是一个噱头，昙花一现的产品，用户未必会买账。

慢慢被普及——

Smart TV（智能电视）和过去的智能电视不同，更强调对内容的操控，使用户有更大的选择权，自主选择自己想看的内容。

# 多方向逐渐开始

后台系统之争

当Smart TV变成一个大潮流时，后台的操作系统之争愈演愈烈。

如今的操作系统思路分别是：

- a.最流行的是谷歌Chromecast，主要使用者是三星公司。
- b.另一个是WebOS系统，由于系统比较老旧，它的开放性可能会受影响，主要使用者是LG公司。
- c.中国的海信和TCL公司选择和日本的操作系统公司合作，叫Roku。使用的是开放的操作系统Linux，被经过大量改动，因此也会受到一定的影响。

总而言之，虽然在后台操作系统上谷歌更占优势。但目前仍是一个群雄割据的阶段。

当电视屏幕提供商发现自己对操作系统有一定的控制力和选择权时，会倾向于设置自己的特色操作系统，以实现对底层更好的控制，因此在未来几年，操作系统还不容易被统一。

由于操作系统的不确定，亚马逊、Nexflix、Hulu、HBO等内容提供商纷纷向智能电视转型，提供订阅包，里面的内容可以随时下载，随时观看。但为了适应不同规格的智能电视，也需要开发许多不同版本，所以，电视最终能否统一到某个操作系统上，还需要拭目以待。

语音交互界面之争

前台争夺也同样激烈，尤其是在2017年的智能语音控制领域，不过这个领域的争夺会有提前落下帷幕的机会。如今，CES展会上，亚马逊公司的语音控制系统Alexa基本做到了一枝独秀。

和谷歌的Google Home相比，亚马逊在应用结合上做得更好，系统能够更好地接洽到亚马逊自己的服务中。

在人工智能时代，最好的人工智能并不一定是技术，而是和应用结合的最紧密的数据。而在离应用更近的维度上，亚马逊确实有着得天独厚的优势。

内容提供商之争

其中，苹果的Apple TV一直表现不错，而亚马逊、Netflix等其他内容提供商也不甘落后。

未来决定电视产业的究竟是谁，依旧充满了悬念。但随着各方竞争的加剧，消费者终将是最后的受益者。
