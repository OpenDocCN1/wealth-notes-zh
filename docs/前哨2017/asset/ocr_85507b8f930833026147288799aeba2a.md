# 参观展会知识清单

说说我另一个印象最深的模块——阿拉加CES展。

事前收集资料：

+   （1）之前的信息。该展会过去几十年的趋势、潮流。
（2）当年提前发布的参展信息。是否有专用APP、公众号等，通过里面的分类了解热点、商家信息。APP的新增模块能给你带来惊喜。
（3）以特殊身份参会。媒体人、分析师、咨询公司在参会的时候有特殊待遇。例如注册免费、专门的媒体室、高速宽带、优先获得会议信息等。

会场注意事项：

+   （1）关注Keynote Speech。发言人往往是有实力的大牛，他们会展示整理好的数据，很多观点都具有非常强的 indice。很多主题发言席位是先到先得，不能预定。
（2）关注产品。从实用性的角度分析，一个产品是否有成熟的市场、可以大力推广了；它背后的技术到底是什么；核心技术是被公司掌握还是个人；核心技术有没壁垒；市场前景如何等。根据这些标准能够判断一个产品是否优秀，市场是否迅速打开。
（3）分析公司。大公司一般不是新概念的开创者，但是它是新概念会不会火的指示剂。
（4）关注产业。通过对公司（包括上游的公司、各个应用的公司）的连续观察，来判断这个产业到底处在什么点上。产业发展的几个阶段：核心技术成熟（代表性产品出现）和引爆大量跟随者（大量应用普及）。

# 王老师的心得：

+   （1）看展览时心中设数。事先积累足够多的知识，目的是能够看到变化，看到变量。对市场上过去、现在报道的东西充分了解，直觉的判断是基于大量既有知识积累造成的，发现与你预料的不太一样，就要认真看。
（2）保持对新产品的高度好奇心和对产品市场影响力的判断。“市场感”——一个新产品出来时，你甚至可以判断它会夭花一现，还是会迅速火爆占领市场，甚至长久不衰。
（3）充分了解产业规则。
    a.消费品是否能做好，依赖于它对产业链的控制程度。
    b.产业渗透的难易程度和产业链瓶颈。我们必须要知道，产业链格局和产业各方关系中，谁是领导者，谁是控股者，才知道一个科技是不是有机会能够迅速占领市场。
    c.量产能力。量产能力代表科技实力。
    d.市场的接受难度。
（4）关于产业规则的总结。要通过产业链控制程度、产业渗透难易程度、产业链瓶颈、量产能力、市场的接受难度几个角度判断一个产业。
