# ——► 比特币的优势 ◄——

之前我推荐过，如果手里资金不太充裕的情况下，理财可以选择比特币。很多前来的朋友听了我的建议都买了，过去这段时间确实涨得不错，现在看起来应该都是翻倍的。

但需要给大家一个提醒，当初建议大家购买比特币是从长期的角度来考虑的：比特币能够和各种虚拟经济、虚拟交易相关，实际上是非常理想的跨国货币、无国界货币。尤其将来跨国生意越来越多，跨境电商能否用比特币结算，这都有很大的想象空间。

# 学会避险才能学会投资

我一直强调，除非你是真正的比特币玩家，比如美国很多大基金会，它们募集的目的就是炒比特币，因为它们有雄厚的财力，也有专业人士帮判断比特币走势。但如果你不具备这样的条件，理论上讲，投资的第一原则就是避险，先学会避险才能学会投资。

所以我给大家一个建议，既然已经都涨得翻倍了，你可以尽量出一部分比特币，把你的成本先收回来，剩下的那些到底还是跌，我觉得对你来说都是赚了，赚多赚少心里没负担，这是一个很好的理财方法。
