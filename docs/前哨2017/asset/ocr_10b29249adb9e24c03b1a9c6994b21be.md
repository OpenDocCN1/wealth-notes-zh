# 前哨小议 | 关于人工光合作用的补充

王煜全

本周四，汪博士带来了人工光合作用领域最新的科研信息，不少前哨朋友提出了一一些好问题。今天，汪博士将针对以下几个问题作解答。

人工光合作用的终极目标就是直接利用太阳能产出液态燃料，这个目标谁定的？为什么不能是晒晒太阳填饱肚子？植物能做，为什么动物不能做？

首先在科学研究里面，一个课题的研究目标并不是谁动嘴巴定的，这是一个百花齐放，思想自由的领域。至于这个目标，是基于现今社会的发展程度，能源利用的基础设施以及整个全球市场决定的，因为只有这样才能既保证一个可持续发展的社会，又能达到利益最大化。

至于为什么动物不能做光合作用，这个问题建议你了解一下进化论，食物链的上端消耗能量的速度之快，是光合作用的速度不能满足的。

去西藏旅游的时候看到在内地被大家弃之不用的牛粪把在藏民那里是很的燃料，看完今天的文章我在想是不是有一天我们也会为我们有更多的二氧化碳而兴奋，因为我们有更多的原料来源。

人工光合作用的目的之一是减少二氧化碳的净排放，利用已有的二氧化碳为原料制备燃料，燃料被利用之后又会排放二氧化碳，这样形成一个循环。基于这样一个能源系统，大气层中的二氧化碳将不会增加，已有的高居不下的二氧化碳将会被地球的生态系统慢慢地消耗，理想状态下，环境会逐渐变好。

所以说，我们不希望看到大量的二氧化碳，当然，大量的二氧化碳会更加刺激我们在这个领域的研究。

今天又是眼界大开，以前从来没有认识到什么是人工光合作用。文中提到第二种二氧化碳+水+太阳能→碳氢化合物+氧气，及生产汽油的新方式。

这个方式也面临两个难点：二氧化碳还原反应的催化剂和水的氧化反应的催化剂。这就是说：对于真正的技术实现还有很漫长的一个过程。

因为一是实验室的技术还没有成熟——找到低成本且有效的催化剂，第二，此类行业以前应该是没有太类似的吧，如果是新兴行业，量产化的过程会不会更慢？

很棒，你已经领会了人工光合作用的研究内容。但是需要注意的是，人工光合作用的决速步骤不在量产化这一块，而在于催化剂。

至于类似的产业还是有很多的，只不过不是超大规模的化工产业。如果有兴趣你可以关注一下德国的巴斯夫公司的相关产业，有很多产品是通过电化学方法制备的，包括电化学氧化，还原，已经可以实现量产。比如他们用电化学的方法可以小批量生产高纯度的盐，碱金属等等。

电化学对工业设备的要求很低，不需要高温高压，也不需要石油工业的大型蒸馏塔，所以决速步骤不在量产化这一块，而是寻找成本低且活性高，并且稳定的催化剂。有了高效的催化剂，用电化学实现量产就不是问题。

水不就是H2O吗？水被氧化太违背我们以前学的物理化学知识了。那人工光合作用的储能效率，和光伏电池有多大区别呢？

所谓的氧化反应，是指某元素的电子被夺走了。水里的H是 +1价，O是-2价，-2价态的O上面的电子是很容易被夺走的，只要有氧化性够高的物质存在。所以并没有违背任何原理。

关于储能效率的第二个小问题很好。这是很混淆人的问题，首先，储能的过程不一样，人工光合作用是将太阳能储存在化石燃料里，而光伏是将太阳能转变成电能。两各者有优缺点，现如今市场上的光伏板的效率在15%左右，而人工光合作用还没有市场化，虽然效率还很低，但是理论上来讲，只要有很的催化剂，能量转换的效率是可以达到光伏的水平的，甚至更高。

同时，由于光伏板产电不稳定，储存难，产生的电不容易并入现有的电网等缺点也限制了其应用。所以说，如果人工光合作用能够成功地达到一个可以接受的效率，那么应用起来就极其简单了，对市场的吸引力也就越大。

人工光合作用：首先使用半导体将太阳能转化为电能，然后水和二氧化碳在电能以及催化剂的作用下，生成类似石油的合成物。人类似目前很像一个富二代，祖辈积累了大量的能源，我们现在就劲地使用，但坐吃山空，能源越来越少，创造能源迫在眉睫。

汽车使用汽油比使用电池显然更方便，如果人工光合作用可以大规模使用，那么特斯拉一类的产品估计要死掉了。人工光合作用中最重要的就是高效催化剂，请问你们是怎么寻找催化剂的，用到人工智能了吗？

首先我同意石油产品是最便捷的能源，相比电池，能量密度高很多。所以你加三分钟油能够开几百公里，但是充电一整天可能也就北京绕一圈。

关于我们是怎么寻找催化剂的，这个问题非常好。这也是我们研究的关鍵，首先我们会测试很多材料，看看哪些材料是有活性的，然后研究这些活性材料的催化机理，从而总结一些规律，从而推测催化活性是由哪些部分决定的，这样就为设计下一代催化剂打下基础，然后不断地重复这个过程，直到找到好的催化剂。人工智能目前还没有用到，但是很多系统的化学化工的电脑运算应用还是很有用的。
