# 用户留言

已有棋谱的学习，掌握了下围棋的思想，通过不断的学习和演练，在极短的时间里，达到了围棋职业九段的水平，其学习速度之快、效率之高是人类无法超越的。

接下来大家想一下，如果机器能够学会下围棋，那么还有什么技能是机器没法学会的呢？律师、会计、医生、翻译、教师（单纯知识类的）、股票交易员、新闻编辑、……。

如果某一项工作也是基于IF…Then…的模式，if和Then后面对应的知识来自于已文字化的内容（如书本、网络等），同时该项工作的成果可以通过电脑进行存储并展现，那么这项工作机器做起来就一定比人更有效率，相应的成本也更低。

之所以出现机器能够替代人的事情，是因为IT系统这种机器在记忆（存储）、推理（逻辑判断）方面的能力要远超人类。再加上机器现在又学会了学习。很多人也许会学习（记忆）知识，但不是所有人都会学习。

在未来不是一台机器替换一个人的工作，而是一套系统替换一个工种的工作；不再是一个人失业的问题，而是一种职业消失的问题。

也许有人说我有些危言耸听了，但以上的结论仅仅是我基于目前所看到的现象做的一个推理，不愿意看到的不表示将来就不会发生。我想说的其实是，对于技术的发展速度和演进趋势有时候是我们没法想象的，对世界保持一颗警惕的心、对周围的环境保持敏锐的感觉、对未来保持乐观的心态，也许才是将来我们能够适应环境的办法。

爱，或者不爱，她就在那里，不悲不喜。
