# 应用爆发，指日可待

基于昨天的解读，很多朋友希望了解无人机的未来市场。坦白说，这好比你抱谠基亚预测App Store的诞生，极难做到。

应用市场拐点的出现，取决于现有的市场参与者。具体到无人机领域，非大疆公司莫属。可喜的是，大疆已经全面包揽了个人级、偏专业的消费级、专业级的市场。

# 中国玩家

除了大疆，中国还有很多出色的无人机制造商及相关产业参与者，各具特色，互有长短。

亿航——
比如说在2016年的CES展上大出风头的亿航，公布了全电动的自动驾驶载人飞行器，虽然只是一个演示，续航时间非常短，且更更多是低空飞行，但说它是中国在无人机领域又另一个世界级水准的无人机公司并不为过。

零度智控——
名气稍逊的零度智控在历经一系列的转型后终于在2016年进入消费级无人机市场，其产品被广泛应用于测绘、安防、影视、农业、电力、科研等专业领域。同时，在消费者领域里面，零度智控也有布局。

在无人机领域，中国的制造商占了半壁江山，并且产业链也在逐渐完善，势头喜人。需要警惕的是，高科技产业会面临冷热周期，发展迅猛的中国无人机行业需要做好度过市场严冬的准备。

# 海外竞争者

那么无人机行业在海外都有哪些参与者，其技术优势与研发方向集中在哪里呢？

Parrot——
中国无人机行业在海外的主要竞争对手，就是法国的Parrot。Parrot由车载信息娱乐系统的制造转向无人机是在2010年，第一个做到消费级无人机用手机操控。加上与苹果的强强联手，可算是娱乐、消费级无人机的领头羊。

3D Robotics——
另一个放弃消费级无人机领域的美国无人机制造商就是3D Robotics，它曾是北美最大的消费级无人机的制造商，然而在过去一年已经从领军者沦落到了挣扎求生的地步。

Intel——
但是，在无人机领域，作为硬件提供商的国外参与者还是有很多巨头的。比如Intel，采用红外激光技术，推出了能够有效提高精度的RealSense体感系统。2016年8月，Intel发布了面向开发者的Aero无人机，虽然可以满足开发者的调试，但主要还是为开发者提供硬件支持。

# 各具特色，暗藏变局

从整个布局上来说，虽然国外无人机厂商基本放弃了整机生产，尤其是消费级市场。但是在后台的硬件布局上还是颇具实力。中国无人机虽然全面占领了终端产品，但在元器件上处于明显的劣势。未来的市场局势，尚不能武断定论。
