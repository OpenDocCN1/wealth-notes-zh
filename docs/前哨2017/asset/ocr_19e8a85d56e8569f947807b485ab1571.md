减轻冲击。

类似这样的产品怎样才能免于被模仿山寨呢？这就涉及到行业认证了。

比如Active Protective这款产品，就在积极地申请FDA的认证。FDA（美国食品药品监督管理局）是国际医疗审核的权威机构，类似于Active Protective这样有医用价值的产品一旦获得机构认证，即相当于获得了一个效果出色并且免费的广告。消费者谁不愿意选择头顶专业认证的光环、更令人放心的产品呢？这样，Active Protective这类产品的“软壁垒”就很坚固了。

# 我的总结

首先，在社会生活的真实场景里发挥功效，是目前和将来人工智能的一个趋势、主题。

其次，智能产品从精巧的技术设计到获得巨大的社会效益之间，需要精准的市场定位以及产品壁垒的加持。

在Eureka Park展馆里看到的众多创意，甚至本次CES展上的大部分产品，都紧贴着这样的理念，为人工智能的社会价值，尽心尽力地做着诠释。
