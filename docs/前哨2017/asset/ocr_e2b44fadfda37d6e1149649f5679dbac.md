# 前哨小议｜关于超高分辨率显微技术的补充

王煜全

本周温博士给大家带来了超高分辨率的显微技术，今天针对几个关键问题，在此作了相关补充。

超高分辨率显微镜的成本高在哪些方面，如何降低成本，为什么培养这方面人才比较困难？

超高分辨率显微技术包括了显微镜本身和后期图像处理。显微镜本身除了成像理论在快速发展和应用外，还需要很多高质量的组件，如相机，镜头，自动对焦，激光排列等等。

后期图像处理软件与成像理论相匹配，不断挖掘最合适的算法来增加信噪比。这个过程中需要工程，数学，计算机几门学科的协作以及生物医学的需求推动才能不断改进和创新。

同时，由于生物医学的研究手段还主要集中在生化方面，显微技术如何作为一种有力证据来主导生物研究还在发展中，所以超分辨率显微技术尚未作为生物研究的常用手段而大规模降低成本。

然而它的商业化是非常迅速的，仅仅几年的时间，大公司的显微镜已经开始更新换代，小型创业公司也开始了低成本的超分辨率显微镜的开发，所以随着该领域的竞争加速，成本应该会逐步下降。

也因为这是一个新技术，所以全球只有有限的几个顶级实验室在开发，培养的人才较少。但随着越来越多计算机，工程以及生物物理专业人才的加入，这项专业的人才培养会更成熟。

光学超分辨率显微镜除了在活细胞影像上有优势外，还有什么优点和应用方向？是否可以用于农业研究，疫苗研制，纳米机器人的开发中？

现在的光学超分辨率显微技术主要优势是在活细胞延时成像，三维成像和深层组织成像上。

这些都是电子显微镜不能完成的。例如由于蛋白被荧光标记，这种显微镜可以检测到表皮以下10微米的信号，从而达到活体成像，使实验条件更接近生理状态。

再如用多种荧光同时标记不同蛋白可以研究单分子水平的蛋白间相互作用，为药物机理的研究提供便利条件。

理论上，只要是研究细胞内分子水平的变化，超分辨率显微镜都是很好的工具，当然可以用于农业研究。疫苗研制可能更多的是测序以及结构分析，尚不清楚其应用方向。纳米机器人主要需要工程和材料学，用于观察的显微镜不太适用。

超分辨率显微镜与普通光学显微镜或电子显微镜有何异同？可否利用人工智能自动分析读片？

在应用上，超分辨率显微镜与普通光学显微镜的区别主要在于分辨率的不同，普通光学显微镜分辩的物体小几十倍的东西都可以看得清。当然其原理，组件，分析过程，样品制备都是有区别的。

电子显微镜也是用于观察细微结构，但它的分辨率是几纳米，比超分辨率显微镜要高。但是电子显微镜的样品制备要求较高，一般是已经固定的标本，因此不能观察生理过程，只能观察样品表面。对蛋白的标记也很有局限，不能同时观察几种蛋白的相互作用。

人工智能的迅速崛起确实带给很多学科新的发展。现在的细胞分析软件就是用比较简单的人工智能来分析细胞形态达到计数目的。因此，人工智能用来自动分析图像和在大规模筛选中药片是完全可能实现的，也是技术发展的必然。生物技术相关领域需要大量数据分析人才的加入，来加速推动生物医学的发展。
