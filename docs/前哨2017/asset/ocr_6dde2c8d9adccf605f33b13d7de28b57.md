# 周末问答｜前瞻性思维与预测未来

前瞻性思维与预测未来

王煜全

今天周末问答的话题主要围绕我前面讲过的前瞻性思维和如何预测未来。

以下是于货笔记，完整内容欢迎收听音频。

请问煜全老师，如何培养前瞻性思维及方法？是通过学习，按照书本的步骤方法一步一步修炼达成，还是需要有特殊天赋？或者应该具备什么样的条件、机遇、运气？

王煜全

我认为培养强大的预测能力包括两个部分：

第一，姿势正确，即认知升级，拥有正确的思维方式。

不仅要看强调基础批判性思维、认知升级的书，也要看预测方面的专业书，推荐《超预测》《信号与噪声》。

《超预测》认为人和机器都能预测未来，尤其在数据充 خبر的单项领域，机器已经超过人类，但在相对复杂的环境之下，人类依然强于机器，并且通过训练，一部分人可以拥有很好的预测能力。《超预测》认为如果你想预测更准，对外应当只表达概率。但我认为，我们在锻炼预测能力时尽量不表达为概率，以此避免为自己预测失败找借口。

《信号与噪声》更为专业，作者是我非常推崇的Nate Silver，由于连续两次准确预测美国大选而成名，但这次预测特朗普失败后，Nate Silver通过长篇分析失败原因得出结论——当预测的影响因素太多而数据又不够充分时，用数据计算容易出错。这也体现出人在缺乏数据的复杂情况下依然可以进行决策的优势。

第二，“唯手熟尔”，在姿势正确的基础上不断练习。

关于前瞻性经营，有几点疑问想请教，新技术和产品方向是需要群策群力讨论出来，还是市场或产品单方面主观判断？如何提升预判准确度？什么阶段可以认定某个前瞻性部署已失去投入的意义，或者某些部署已到关键点需要全力支持？

王煜全

不能把新技术和新产品混为一谈。

新技术的趋势和时点，通过正确的分析方法可以得到。群策群力更好，即拥有群体智能collection intelligence。群体智能可以采用众多方法，例如Delphi法；但如果没有方法，就会变成群体愚蠢collection stupid。

对于新产品，预测不是主要的，更重要的是判断。了解用户需求分成两大流派，一派靠数据，另一派靠直觉。例如乔布斯就是通过直觉反推其他人的需求，从而做出产品。我认为，不管哪个流派，只要有正确方法都可以达成，包括直觉也需要锻炼，最后把自己修炼成高手才是最重要的。我认为，万变不离其宗，最后万法归一，才是高手。例如一战时，通过看到敌方阵地有猫判断出敌方指挥官在现场。

判断时点非常重要，我会在未来六周的产业理解时间里，为大家详细讲述如何预见未来、经营未来、布局未来。尤其在“预见未来”部分，我会介绍如何判断科技成果的时点，欢迎大家持续关注。

这种前瞻性经营到底是由谁来推动？直觉告诉我，这种前瞻性思维只有创始人或者CEO层级的人，才能够去推动，那么对于大部分不是创始人，也不是高管层级的人来说，这样的思考会有什么样的帮助吗？会不会只是有助于我们去挑选自己的职业或者公司、行业呢？

另外一个问题，前瞻性像是一种艺术，既然是一种艺术，它就等同于一种手艺，不仅仅需要知识，而且需要通过经验积累而得到直觉。对于很多人来说，有什么方法在正式开始之前，我们就能够得到这种经验呢？还是说，只有正式作为创始人去做这样的事情的时候我们才能得到这种经验呢？我们作为一个个体，这种风险和代价我们是不是能够承受得起呢？

王煜全

你的问题都包含假设，不利于找到正确的途径。

前瞻性思维需要培养直觉，但直觉包括先天和后天两种，前瞻性思维是后天直觉，甚至有和先天直觉相矛盾的地方，所以需要理性的、系统的训练。

前瞻性思维随时可以训练，每个人都可以像CEO一样看问题，经过千锤百炼拥有强大的后天直觉，形成对事物的洞察。CEO往往少有年轻人，因为需要经验累积。
