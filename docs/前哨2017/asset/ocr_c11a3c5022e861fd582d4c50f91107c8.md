# CES汽车展位近年来的变化

原本汽车并不是CES的特色，以前大车厂会去参加汽车相关的展览，而CES中主要是汽车配件供货商，主流车厂比较少。但这两年，随着汽车的电子部分比机械部分更重要，主流车厂慢慢转移动到了拉斯维加斯，将其变成主场，甚至将新车型也发布于此。

以前CES展上汽车相关的科技只限于音响等偏电子的产品，但现在更多的是人工智能、电动车甚至车联网这类更加时髦的性能展示。

# 大车厂逐渐发力

大车厂的主要展馆叫RVCC，走进去就象到了汽车展，我的总体感受是各大车厂都被唤醒了。前两年互联网风潮特别热，很多90后CEO被热捧，他们确实勤勉务实，因此各处争相邀请他们去做演讲。

# 主流车厂的解决方案

+   1、 电动车

电动车基本都是混合动力和电动，小趋势是具有切换功能，比如福特推出的混合动力车，用户可以自主切换用油还是用电；丰田非常出名的普锐斯是混合动力，但新能源汽车将迅速推出全电动款。

+   2、 人工智能

# 新进入者压力巨大

看展需要连续看，通过今年和去年的对比，可以看出这个产业马上就要沸腾了。我们一直强调新进入者压力大，原因除了大车厂的围追堵截外，另一个是汽车产业太保守——只和大公司合作。

# 创业公司在中国有机会

在全球的创新者都被汽车产业巨头压制的同时，中国并没有汽车巨头，所以中国反倒有机会。

# 硬件企业的机会

从全球角度看，并非新兴企业全无机会，硬件企业看起来就更有机会。因为硬件相对来说具备稀缺性。当全球各大车厂都在发力的时候，它的新兴部分只有个别供应商可以提供，所以变成买方多、卖方少。
