产。比如碳纳米管，它价格就很贵。

因此，应用拓展和产能增加的平衡，是材料科学创业公司面临的难题。

事实上，这也是我们为什么持续给大家介绍一些在生活中接触不到的科技——远离生活却对社会意义重大的新型科技，其创新阻力往往更大。

# 2.中国新型科技创业

我们中国产业环境是比较完备的，我们的产业集群优势要高于所谓的劳动力便宜的优势。

但是，我们在科技升级上仍然有非常漫长的路要走。这种时候，我们能否利用产业优势，对接国外的先进科技，积极主动地去创造更好的合作环境，决定了未来科技大潮中经济发展的走向。

# a）全民模式要发扬

我一直强调，全民呼吁互联网+使得很多传统企业重视互联网，把互联网当成先进科技，进而开始重视先进科技。

所以我们认为这种全民的推动，对先进科技的重视是必要的。只不过，要把互联网+改成科技+。
