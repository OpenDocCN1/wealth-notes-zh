# 小爱因斯坦：叫我Professor

今年的CES展上最亮眼的智能玩具是海银投资的Hanson Robotics(汉森机器人公司)推出的“小爱因斯坦”。

这款小爱因斯坦虽然身长不及一尺，但有手有脚，功能强大。它能做出50种以上的表情，比如爱因斯坦经典的“吐舌头”造型。同时可以灵活运用食指，指向特定的方向及物品。
