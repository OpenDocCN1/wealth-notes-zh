# 元旦篇｜2017年，前哨有哪些计划

2017年，前哨有哪些计划

# 王煜全

今天是2017年1月1日，开年第一天，我来给大家谈一谈我们的新年规划。

# 一、我们会继续提供前沿内容

有朋友反馈《前哨》内容太深、太枯燥、太烧脑，听了一段时间似乎只掌握了一点，没有太大收获；建议我讲一些能够独立于见影、让人突然启发开窍的东西。

这让我想起佛教有句话，叫做理需顿悟，事须渐修。开悟看起来似乎很容易，但你却不知道别人已经修了多少世。

对每个人而言，实际上还有很多不了解的东西，对基础还有所欠缺，所以首先需要有强大的基础实力，才有可能产生顿悟。如果没有每天的基础学习，对科技前沿就无法产生特别棒的直觉式判断。所以，日常的枯燥工作还要继续，坚持就是胜利！

前沿内容包括

+   1. 科技概念股 / 前沿行业分析
   帮助大家理解科技行业和科技概念，搭建知识结构；同时具有实用性，能够学会如何在这些行业里找到实际突破口。至少，有些概念是投资就可以赚钱的。

+   2. 产业新闻 / 新闻评述——
   独特之处在于不仅让大家掌握科技产业里最新最重要的动态，同时了解了背后的规律和发展趋向，以及其意味着什么。这是独一无二的门道。

+   3. 前哨圈供稿——
   我们已经组织了一个涵盖全球各个产业的前哨圈，每周提供一次顶尖专家的前沿分析，保证对各个产业、尤其是对研究的前沿信息作深入的跟踪。推动社会进步要靠研发，因为要把科研的东西变成产品才能推动社会进步。今天已经不是民科的时代，研发来源于高校和科研机构，所以我们需要前哨圈各个领域从事科研的前沿人物来帮助我们判断科研到底走到了哪里，我们才知道研发要走向哪里。

+   4. 加强企业深度剖析——
   2016年我们已经做过硅想、亚马逊等几个企业的深度剖析，2017年我们一定会增加这部分内容，对科技前沿的代表性企业逐一分析，希望大家可以从别人的案例里找到可以学习的地方，找到经验、找到规律。

+   5. 行业报告解读——
   他山之石，可以攻玉。很多全球领先的咨询机构或者政府的研究机构做了很多分析和报告，我们将在这些报告的基础上进一步分析，就能看到更多更广。

+   6. 牛人拜访与介绍——
   2017年我们会推出更多的牛人拜访，他们站得高、看得远，对一个产业的理解和见解是我们可学习的。需要强调的是，我们是学习别人实在在的见解和对未来的分析，而非学习他的成功学。

关于栏目时间安排，6个栏目每周分别讲一天，有很多当天根本讲不完，只能分成两天、甚至隔周再讲。请大家体谅，因为内容实在太多了，之后我们会尽量更有规律。

在信息越来越过载的时代，我们特别强调信息素养，叫Information Literacy，它的核心是：从繁杂的信息里读出系统，从系统的信息里读出疑问。所以，这正是你锻炼技能的机会，不仅纵向听栏目，还能横向进行整合，希望你可以和《前哨》一起锻炼，从繁杂的信息里读出系统，从系统的信息里读出疑问，掌握信息素养的核心。

关于内容的安排，我们还是不讲人生大道理，如果你实在想听，可以去参加我的线下活动，会有一些安排，比如明年和混沌研习社的合作课程。我认为人生大道理不是不能讲，而是应该等你先掌握一定的基础后再讲。

> 科技是一个优秀企业家的武器，你对你的武器库了如指掌后，才可以设计你的战略战术。往国外看，成功者也多是工程师学了MBA，而不是MBA去搞技术。所以，当你掌握基础之后，再想如何成功。先有技术的rolle基础，再学怎么做管理和经营。

# 二、会组织更多的线下活动

+   1、大课：
2016年和得到一起做了两次大课，分别在北京和上海，但内容比较偏等， basically都在讲积木式创新理念和全球科技前沿的产业动态。
2017年我们会深化内容，同时也想换形式，比如能否都做成直播，无论你身在何方都可以参与，这样我们可以安排每两个月或每季度一次。而且每次的话题可以提前公布，由浅入深，如果你每期都参加，相当于在订阅了《前哨》的基础上，再做一个系统的梳理，我们将对很多内容进行深入探讨，尽量把每个话题都讲透。

+   2、培训：与混沌研习社合作
（1）公开课，专门讲科技产业未来，尤其是社会发展新趋势中有哪些创业机会；
（2）产品营，讲透过人性怎么设计产品；
（3）科技特训营，讲全球科技产业的扫描，会对每个产业做更加深入的剖析。只有通过系统、枯燥的学习，覆盖各个行业的知识，才能锻炼出更强的判断力，加深你对产业的理解度，这个枯燥的基本功训练是必不可少的。

+   3、小班课程：
根据前哨用户的反馈，我们正在和得到一起讨论，可能2017年年中，计划推出一个小班课程，招收10至15个人，每组至少2人。这个小班就是给每人一对一的传授，彻底授之以渔，教会如何和国外高科技企业合作。包括如何向国外高科技企业投资、找最好的项目、如何让信任的自我介绍、看明白项目、如何跟对方胶朋友、建信任、执行项目等。

+   4、海外访学：
当下，中国的各种访学项目越来越多，2017年我们将推出一个非常特殊的访学项目，叫“20对20”——20个中国的企业家或者投资人（带家属），和国外的20个优秀的企业家、投资人（也带家属），选一个地方共同度过周末。白天大家一起休憩娱乐，晚上创业者们继续交流如何深度合作，如何建立信任。所以要建立真正的系统，建立真正的联系网，这是我们要做的事。甚至如果时间允许，我们将不止筹备一期，如果你有兴趣，尤其是确实想要在海外拓展并且有所行动的，欢迎参加。

+   5、年度活动：
这是大家一定要关注的重头戏——2017年4月19日，我们会做全球科技产业前沿大盘点。我们会用一整天的时间跟大家盘点全世界的科技前沿都有哪些，而且会邀请很多人出席，包括国外著名的企业家、投资人，还会在现场给大家展示非常棒的黑科技项目。我们有一个崇高的目标，既然后阿里能够把11月11日光棍节改成了购物节，我们能否一起努力，把4月19日改成科技节，变成中国对全球产业的一大盛会。希望大家鼎力支持，如果你有什么想法，例如如何把这个活动办得精彩，特别欢迎你向我们提出来。

# 三、建立社群

光有一次性的行动还不够，我们要长期联系起来，形成网络，形成平台，形成社群。

+   1、前哨圈2017年还会继续发展，将会把全球学术领域的前沿都吸纳进来，让大家全面了解全球的学术进展。

+   2、组织创新社，能力互补又 다가 공통 목표的入群，大家有实力、有差异、又有意愿，一起合作、一起创新。

+   3、创新行动队，创新社的规模、范围和数量可能很大，具体行动的时候就叫创新行动队。当一个项目来的时候，我就把能互补的人放到一起，希望每个人都献计献策，贡献自己的资源、能力和实力。这样就可以不同标签的人组织到一起，一起研究项目落地方案，一起研究应该跟谁对接资源，甚至一起组建董事会，一起...
