# ——杨培东的研究重点——

# 1、量子点

a.电视领域——
杨培东教授和同事于2001年共同创立了Nanosys（目前是全球量子点领域最大的公司）。三星作为Nanosys最大的合作伙伴，利用其最先进技术推出了量子点电视（CES上三星的热门产品——QLED新量子点电视屏幕）。

b.照明市场——
彭晓东教授（杨培东教授在伯克利的同事）回中国创立了纳丁公司（杨培东教授也是该公司董事），专专利用量子点技术照明，即固态照明Solid State Lighting。彭教授和杨教授都认为下一代照明系统就是量子点照明系统，该技术会得到广泛运用。

c.孵化的核心——
中国大力扶植海外部专家带回前沿技术，并给予充分的资金和研究支持，使技术能够顺利在中国孵化。但在孵化过程中，需要一个负责将高校科技转换成产品的研发型企业家（而非科学家或传统的生产、制造、销售型企业家），这是整个生态链的核心，中国目前依然没有意识到这个核心部分。
未来，创新生态成熟健全的标志是——出现一个完善的研发型企业家群体。

# 2、半导体纳米导线

半导体纳米导线和量子点同属纳米科技领域的两大高峰，杨教授和他的导师从1994年前后开始研究半导体纳米导线，从而奠定了杨培东教授在半导体纳米导线行业奠基者的地位。

半导体纳米导线的应用比量子点还多，例如电池、热电材料、太阳能等。

a.电池——
目前，在利用半导体纳米导线生产电池的领域，最领先的是斯坦福大学的华人教授崔屹。崔屹教授在国内创办了企业，利用半导体纳米导线生产电池。
越来越多全球顶尖的华人科学家回国，这是中国一个很重要的优势。

b.热电材料——
美国企业Alphabet Energy，利用纳米导线做热电的模组，通过废电发热回收废热能量。全球每年废电占发电总能量的2/3，虽然Alphabet Energy目前回收率只有2.5%，看似效率不高，其实市场前景非常广阔。
Alphabet Energy目前在北美以及国内的鄂尔多斯都有部署，它甚至希望进一步开发出安装在汽车底部废电废热回收装置，在汽车运行过程中同时回收转化成电能，使汽车尤其是电动车能够续航更长的里程。Alphabet Energy公司的未来具有很大的发展空间。

c.人工光合作用——
历史上第一次人工光合作用就是杨培东教授实现的，虽然这个技术依然停留在实验室阶段，还没实现商用，但随着回收利用率进一步提升，利用半导体纳米导线实现的人工光合作用，很有可能在未来大大超过自然界的光合作用效率。
除了提高光合作用效率，人工光合作用还能吸收二氧化碳。因此，美国政府投资大量资金支持人工光合作用研发，以期它能够在保持生态环境平衡方面发挥作用。
人工光合作用不仅具有科学价值，也具有保护地球环境的实际意义。虽然该技术目前还未实现商用，但已经在实验室得到了科学验证，下一步的工作就是如何将技术转化为产品。

Larry Bock曾任职美国著名的生物技术公司，之后转做投资人，成功投资了四五十家企业，总市值超过500亿美金。

Larry Bock对Nanosys公司的成功作出了非常重大的贡献。他不仅向Nanosys投资了1000万美金，还帮助募集了5500万美金，保证了Nanosys有充足的资金发展。同时，他非常看好量子点技术，亲自担任Nanosys第一任CEO。

Larry Bock在美国是传奇人物。实际上，他29岁就不幸失明，他在事业上的出色成就几乎都在失明之后，例如他是Illumina（即PCR，全球基因检测技术领域最领先的公司）的创立者和投资人之一。

在讲述硅谷生态的书《Rainforest》里，Larry Bock被称为Keystone Species（意指修建石门最关键的部分，没有它，门就会坍塌而不复存在）。Larry Bock就是硅谷创业生态中的“关键物种”Keystone Species。在一个生态系统中，不仅仅有创业的“新物种”，也需要有连接企业投资和高校科技的“关键物种”Keystone Species，这样生态才是完善的。

Larry Bock于2016年7月6日不幸逝世，享年56岁，这是整个创业界的损失。创业需要经验，我们从Larry Bock的例子中也可以看出，在整个创业生态当中，一个优秀的企业家是必不可少的。

# 科研和产业应当在一个生态中共存

科学发现是技术的源泉，但必须把科学通过技术转换成产品，才能推动社会发展，实现科学价值。在这个过程中，我们需要慧眼寻找产品转化的路径，所以，真正推动社会发展的其实是掌握先进科技的企业家。

在这个生态当中，也可以实现角色对换，当企业家成熟后可以转做投资人；企业家出身的投资人也可以回归企业。产业界是相通的，但产业界和学术界有一定隔膜。这两者必须形成有机的纽带，在一个群体里共存，形成塔档，最后才能把产品孵化出来。我们应当学习美国的双长制，将优秀企业家和优秀科学家一一对应结合。
