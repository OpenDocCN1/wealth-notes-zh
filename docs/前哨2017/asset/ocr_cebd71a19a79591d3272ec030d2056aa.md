前哨的第二季内容正在稳步筹备中，我们做了崭新的改版，会每周给你详细介绍一个科技产业，希望在一年里，帮你抓住科技浪潮的机会。

今天，我们照惯例发布一篇《征集：你的前哨一年》征稿活动的文章，由前哨用户文坛，分享他和“前哨”的故事。

作为一个工程师 & 半个产品经理，对 Google Glass 的误判让我不断反思自己在产业理解上的思维误区。如果要把整个产业脉络，我需要更深入更全面的产业信息和产业理解。

而此时，“得到”让我遇到了“前哨”栏目，感谢罗胖，感谢王煜全老师。

创业缘起：阅读了“前哨”2016年10月25-27日四期科技概念股（关于人工智能入口），经过两个月的思考分析，我在12月离职创立了如今的公司Topo VR，专注高质量VR／AR多人连线应用。

触发我创业的原因，关键字：

人工智能+增强现实

这一年里，王老师讲了很多期关于AI的内容，“前哨”基本帮我梳理了从技术到产业的各个链条和各大公司布局情况，减少了我在这方面的时 间耗费（我自己去做也未必能做到那么全面）。

显而易见，从接地气的电商到高大上的智能投顾，包括如今很火的自动驾驶，处处离不开AI，而AI也需要入口进入我们的生活，也需要我们的数据来喂养它。

当前来说进入AR为时尚早，所以我选择了从过往从事的游戏行业切入VR。但正如王老师所说，硬件的不确定性太多了，2015、2016年根本不是一个内容团队适合进入的时机。但我还是在去年12月奋不顾身地进入这个行业。除了前文所说“前哨”对AI的详细介绍是一个触发器，影响我判断的还有如下几个原因。

+   1. 手机计算力需求饱和，行业已经到了需求升级阶段。根据我们团队的开发经验，当前高通骁龙820只能勉强让人舒适地体验VR小场景游戏（基于Unity开发），根据我们用骁龙800、808、821系列的性能对比（小米4、4s、5s），我们测算下一代搭配Adreno 540的835平台，应该可以提供足够舒适的Mobile VR体验，硬件行业会不会倒逼产业升级呢？

+   2. 软件技术成熟。去年11月我重新评估了当前VR的开发工具Unity 3d引擎和一些相关的开发套件，让我惊讶的是市场上现成的开发套件已经能够足够好地开发VR，我认为可以开始从软件内容切入了。

+   3. 争夺用户时间。罗胖在去年跨年演讲时说到——未来的商业竞争是争夺用户的时间，这点我十分认同。未来的AR眼镜能达到随时随地使用的效果，睁开眼戴上，睡觉前取下，全方位覆盖一整天的生活。

+   4. 我们需要大屏幕。Mobile时代，PC最后的优势是计算力更强、屏幕更大，更适合重度工作处理。但近年手机计算力已逐渐追上（距离PC还有距离，但日常应用已有盈余），手机唯一的劣势是显示屏幕太小、无法方便地处理事务。但Mobile + VR / AR眼镜组合即将完全改变这个情况，人类360度视角将“延伸”屏幕。我认为，Mobile取代PC的时代即将来临，VR/AR的价值也许就在这里得以爆发。

说完了创业原因，也说说进入VR行业半年的收获：

# PC VR VS Mobile VR

感谢“前哨”不断安利CES，我发动在美国参展的朋友为我打探CES上VR的消息，高通的骁龙835VR一体机颠覆了我们对Mobile VR的认知。从那时起，我们果断减缓了对HTC Vive（VR虚拟现实游戏设备产品）平台的内容开发，转到到Gear VR（ VR 头盔 ）和 Google Cardboard/Daydream（基于Android操作系统的虚拟现实平台）的跨平台内容开发，我们必须要为未来一年Mobile VR可能发生的大变化做技术储备。

# 关于VR硬件的爆发

王老师比较乐观地认为2018年是VR的关键一年，我认为大概是2019年。我们从创业伊始便多方面评估当前VR硬件的现状。体验感觉是VR真要达到普及层次，首先要解决头显舒适度、发热量和续航等问题，目前除了Gear VR能让我连续无不适使用30分钟外，其余头显包括Oculus、Vive以及国内一系列硬件厂商的产品，都无法舒适使用超过15分钟。根据当前各大厂商的产品规划和已发布的新产品情况，我对硬件进化持审慎态度。可喜的是从2017年CES后，基于Mobile VR的6自由度组件已经出了不错的产品，包括Leap Motion和Nolo（我们正尝试将Nolo的交互应用到我们的Mobile VR产品中）。我认为VR是否能爆发取决于Mobile VR，而当前来说进展可喜，不过基于如何说服用户购买VR设备的角度，我们还是倾向于VR分体机。期待下半年上市的骁龙835平台的VR一体机，看看市场对它的态度如何。

# 关于VR软件的现状

比较不客气地说，当前国内AR/VR软件内容（包括我们去年早期做的内 容），在产品方面来看的确比较稚嫩。对比Gear VR Store上的产品来说，我们发现其实并不是因为这个行业太新，大家都做不好，只是我们没有立心去打造一款好的VR产品而已。如无意外，下半年在国外市场会有几款优质产品（注意不是爆品）出现，而国内的几个优秀游戏团队比较沉得住气，还在打磨产品，我对他们都很期待。

# 关于重磅炸弹AR Kit

苹果在6月发布的AR Kit，从外国同行的测试Demo来看，这个东西非常登天。如我之前所说，我们团队首先会从VR应用去探究AR的开发组件，经过初步头脑风暴，我们已经有了一些思路，希望能有突破。

# 栏目给我们未来定位的启发

王老师在栏目中说过，一些轻游戏性但更注重世界观建立的AR / VR游戏会有机会提前脱颖而出。作为一个游戏从业者，我认为世界观的建立其实是把游戏从一个IT工业的产品向艺术品升华的过程，就如iPhone是智能机艺术化生活的产物一样，是不容易的。当前我们的团队定位是主打跨平台（GearVR，Daydream），轻量化交互，优质虚拟场景，在线多人互动，在此基础上挖掘从游戏性到社交性的 一切VR发展可能。我们正从一个非游戏的方向探讨多人VR连线的垂直应用，希望能在这个惨淡的VR / AR寒冬中走出一条路子。
