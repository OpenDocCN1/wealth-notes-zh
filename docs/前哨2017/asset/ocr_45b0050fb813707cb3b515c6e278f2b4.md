# 什么是5G网络

首先，这里提到的5G和平常说的内存可不是一个东西。5G网络指的是“第五代移动通讯网络”。非学术的介绍是：比第四代（4G）更密。

4G无线通讯网络，我相信很多人已经体验过了，它解决了视频在没有Wi-Fi情况下也能利用4G通畅播放的问题，而5G时代会на对传输提出进一步的要求，尤其是类似虚拟现实实数据实时传递，它的数据量要比视频更大。

# 5G网络和过去网络连接的差异

5G的连接更可靠，以前的网络连接中即使带宽足够宽，但偶尔掉线也属正常。5G不同，5G相当于永远连接，永远可靠，不轻易“掉链子”。

有数据显示，2015年的网络数据流量中，50%来源于视频，预计到2020年，网络视频的流量数据会达到75%，因此，视频一直是流量的大头。

# 5G网络将带来更大的经济繁荣

最重要的是还不仅仅是网络建设，因为网络建设不过是确 high 的高速公路，高速公路能够促进的是经济繁荣。那么，什么是5G经济呢？高通CEO认为，在未来，5G网络能够提供2200万个工作岗位，贡献12万亿美元的经济增加值，这是一个非常惊人的数据，这个数据的支持就是手机使用。

# 5G对全世界进行体验提升的三个层次

分别为 smart city（智能城市网络）、smart home（智能家居）、smart body（智能身体）。

# 5G技术能够做什么

高通的CEO做了一系列的演示，其中一个是实时传输虚拟现实的VR信息，它的场景是这样的：一个运动员在山间骑行，他的电脑能够和家里朋友的虚拟现实头盔数据信号，那么家里的朋友带上虚拟现实头盔，就可以看到骑行运动员所看到的所有景色。这个方案看起来似乎并不难，但实际上背后所需要的带宽非常大，所需要的数据处理能力也非常强，因此体现了骁龙835的强大性能。
