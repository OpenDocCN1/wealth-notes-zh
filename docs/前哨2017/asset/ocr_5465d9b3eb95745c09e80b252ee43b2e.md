农业科技将向四大方向发展

王煜全

今天将从四个方面给大家介绍农业科技相关的成果以及对应的代表性公司，希望对你本身的行业也能有所参考。

# 生物技术

# 1、基因编辑

# 1）国外农业巨头

孟山都获取Broad研究所授权

杜邦获取Caribou Biosciences专利授权

# 2）高校和研究机构

例如：英国塞恩斯伯里实验室、首尔国立大学、美国明尼苏达大学、中科院遗传与发育生物学研究所等。

# 3）中科院

中科院遗传与发育生物学研究所的植物生物学家高彩霞率先在农作物（特别是小麦和水稻）上成功使用了CRISPR / CAS9基因编辑技术，全球领先。

# 4）创业公司Calyxt

位于美国明尼苏达州，是Cellectis公司的子公司。

通过基因编辑技术TALEN，开发一系列基因编辑作物，这些植物现已在美国田地种植。

截至目前，Calyxt还没有与任何种子公司建立合作关系。

# 2、微生物

# 1）AgBiome

美国公司，成立于2012年，专做微生物农业，研究微生物菌群在农作物生长当中的作用，以此提升作物产量和质量以及控制病虫害。

已对隔离和屏蔽了的26000种微生物进行测序和特性分析。

2017年将推出首个生物农药产品Howler（真菌杀菌剂），含有活性微生物，能够防止系列真菌和卵菌纲的病害，据称药效比现有生物解决方案高20倍以上，可完全取代化学农药。

# 2）Indigo

创立于2014年（前身叫Symbiota，2016年2月更名为Indigo），总部位马萨诸塞州，专注于通过植物体内微生物来改善庄稼的耐旱性、抗病性和整体健康，2016年7月完成1亿美元C轮融资。

2016年推出第一个商业产品IndigoCotton，其主要作用是提高棉花地的节水率。

# 大数据、传感器、物联网

# 1、大数据分析

# 1）Climate Corporation

专做农业大数据，2013年被孟山都公司收购。

# 2）Prospera

2014年成立于以色列特拉维夫，致力于运用计算机视觉和机器学习技术，监督农作物生产情况，从而提升农作物健康，优化农场运营方案。

技术已应用到西班牙和墨西哥农场，同时也在积极开拓欧洲更多农物和葡萄园的客户，甚至是美国的大麻客户。

# 3）佳格天地

2013年诞生于硅谷，2015年回到北京，核心研发团队阵容强大。

时空数据分析平台，将农多环境变量纳入计算模型中，结合实时更新的卫星数据，对农作物进行苗情监测、生长监控、病虫害预警、产量评估等服务。

# 4）大气候农业

基于智能硬件打造农业物联网，建立局部农业大数据平台，并为农业种植提供决策依据和建议。

自主研发硬件产品——农眼，可实时收集土壤、气象、病虫害、农作物品类等信息。

# 2、智能灌溉

# 1）CropX

位于特拉维夫的创业公司，主要产品是探测土壤参数的硬件和帮助农民展示相关数据的软件，并希望通过它们建立“土壤物联网”。

CropX最重要的传感器有三个，分别主要收集地形、土壤结构和含水量，再用App将云端的计算结果呈现给用户。

目前已在美国四个州的20座农场使用，覆盖大约5000英亩土地，用水量减少30%。

# 2）北京安赛博技术有限公司

通过物联网硬件切入种植的创业公司，为用户提供智能灌溉服务。

# 3、农场管理

# 1）Granular

2014年成立于旧金山，是面向农场的 management系统软件，提供农场全流程服务。

# 2）FarmLogs

成立于2012年，提供农业云服务的初创企业。

采集数据，上传到 Software-as-a-Service平台，分析后为用户提供智能预测和优化的数据，可跟踪农产品价格、耕作开支、监控天气、预测利润、安排种植等。

全球有超过130个国家使用FarmLogs的App，管理的土地面积已达6500万英亩；美国有1/3的农场是FarmLogs的客户。

# 智能机械

# 1、农业机器人

# 1）Blue River

成立于2011年，截至2014年已募集超过1000万美元资金。

用机器人系统优化农业种植，从而减少农药用量、降低种植成本。

# 2）Agrobot

位于加州，机器人可以采摘草莓。

# 2、无人机

# 1）PrecisionHawk精准鹰&大疆

PrecisionHawk是用无人机提供空中路径计算和数据评估解决方案的初创企业，成立于2010年。

2016年5月，PrecisionHawk和大疆联手推出精准农业套装，摄取无人机拍到的数据并转化成2D或3D图像，实现对田作物健康数据的灵活收集。

大疆推出农业喷洒防治无人机，主要用于农业领域的大规模喷洒农药、化肥等。

# 2）极飞

成立于2007年，于2013年开始尝试采用无人机进行农业服务。

2014年完成2000万美元融资。

# 新型农业系统

# 1、BrightFarms

创立于2011年，总部位于美国纽约，改变了美国传统的蔬菜供应链。

开设屋顶农场，通过在屋顶搭建水培鹅棚（光照充足，免受小动物、害虫侵袭），向城市居民出售本地自产的新鲜蔬菜。

# 2、AeroFarms

建立了世界上最大的垂直农场，每年可在占地6500平方米的厂房中生产90万公斤食物。

优越性：可在无法开展农业的地方生产食物。

这种新型生产模式可以大大减轻恶劣气候和城市环境对健康绿色食品的影响。

农业的发展，除了运用各种先进科技以外，农业本身也从传统的乡村农田逐渐扩散到城市，进入都市生活。这是今天给大家介绍的农业科技概念股的第二部分——各个科技领域和其中的领军企业，希望大家有所借鉴，可以把这些先进科技也运用到自己的行业当中。
