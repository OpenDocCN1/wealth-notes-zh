# 周末问答｜三大热点：
人工智能、机器换人、
国际化

关于三大热点问题的解答

王煜全

今天的周末问答，将关注三个热点问题：人工智能、机器换人、国际化。

有报告称人工智能行业从业人群结构不合理，具体表现在哪里？什么样的结构才算合理？

王煜全

2017年1月10日，创新工场发布《投资AI生态，共赢智慧未来》，里面提到根据LinkedIn统计，全球目前约有25万名人工智能专业人才（其中美国约占1/3）。

# 一、2016年4月，LinkedIn发布AI行业从业人群结构相关数据：

+   1. LinkedIn平台上的全球人工智能人才数量约25万，主要分布在美国、欧洲、印度和中国；
2. 拥有人工智能相关专业人才数量最多的几个国家，依次为美国、英国、印度、加拿大、法国、荷兰、德国、西班牙、澳大利亚、巴西、中国；
3. 中美人工智能人才的从业年限构成比例：

| AI人才从业年限构成比例 | 美国 | 中国 |
|---|---|---|
| 10年以上 | 50% | 25% |
| 5年以下 | 28% | 40% |

# 二、我对LinkedIn数据的观点：

+   1. LinkedIn数据在全球并不具有代表性（LinkedIn在欧美广泛使用，但在中国使用率较低）；
2. 在LinkedIn的分析中，中国排到了人工智能相关专业人才数量的第十一名，实际上数量更多；
3. 中国的人工智能行业人才普遍较年轻，超过40%从业人员拥有五年以下经验，这意味着掌握最新人工智能技术，能够更好地适应社会发展；
4. 得益于中国的大力宣传和推广，未来一段时间，中国的人工智能人才将会大量涌现；
5. 这一轮人工智能革命带给社会发展的意义甚至超过传统互联网，中国应当进一步加大宣传，努力培养人工智能人才，满足需求；
6. 人工智能逐渐成为下一个运动式发展的主标题，中国将在人工智能领域领先全球。

当全球都使用“机器换人”，我们的产品还有什么优势呢？

王煜全

+   1. “机器换人”只是一个先进的制造流程，但制造业的发展还需要考虑产业集群问题；
2. 中国制造业的优势并不靠成本支撑（近年来制造成本上升，已经高于周边落后国家），而是产业集群优势，各个行业都具有非常强大的配套能力，反而使综合成本降到最低；
3. 现在的创新需要整个产业链的协同，中国依靠产业集群优势和“机器换人”，将使制造能力再提升；
4. 国外使用“机器换人”、3D打印等先进科技，将极大降低原材料采购数量，再配合协同研发工具，将逐渐恢复自己的制造能力；
5. 中国一定要走在“机器换人”浪潮的最前列，提升技术水平，继续担任全世界最大的高科技产品制造基地。

中国的国际化人才越来越多，外资企业在中国的高管团队也逐渐本土化，但中国企业走出去后却还得使用当地团队，出海企业为何人才薄弱？是否有成功范例？

+   1. 中国擅长跨国企业运作的高管团队越来越多，但总体局限在国内，即按国际规则在中国市场运作；中国懂得按国际规则在国外运营的人才非常稀缺，这是一个重大问题。
2. 真正懂得跨国沟通的国际化人才往往就职于跨国企业；中国民企文化偏向传统风格，强调控制，普遍国际化程度不够。
3. 中国企业家（尤其老一辈）更相信自己的员工，对积木式创新接受度较低。
4. 成功范例——万向集团，在国内一直很低调，但在国际上非常成功。
5. 后续将推出系列报道介绍成功的中国企业，希望大家能有所收获，使更多的中国企业在国际上获得成功。

以上是今天周末问答的三个热点问题，祝大家周末愉快。

王煜全
