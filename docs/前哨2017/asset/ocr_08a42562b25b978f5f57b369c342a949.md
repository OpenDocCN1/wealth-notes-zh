# 这样的“爱因斯坦”，你见过吗？

研座以多人讨论的形式进行，参与的人有人工智能界的大咖——软银机器人公司的美国总经理、Hanson Robotics公司的CEO戴维·汉森、CTO安迪·瑞福肯，除此以外，还有一大小两台以爱因斯坦为原型的智能机器人。其中，爱因斯坦机器人的亮相尽到了与会者的胃口。

难能可贵的是，爱因斯坦原型机器人的外形和体态更接近我们熟知的“大爱因斯坦”机器人的形象，已经跨越人工智能机器人的“恐怖谷”（因不够逼真而令人恐惧）的阶段，惟妙惟肖，甚是喜人。
