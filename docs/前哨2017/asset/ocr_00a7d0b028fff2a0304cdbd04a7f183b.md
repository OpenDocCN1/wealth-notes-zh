# 我对前哨的期待

我所研究的领域是煤炭的洁净利用相关的装备制造，属于传统能源产业的一个小分支。翻阅前哨一年的文章，对传统产业的介绍不少。例如食品行业如何进击高科技？服装行业有哪些高科技？出行方式正在被高科技慢慢改变；智能家居领域如何突破；农业问题居然要靠微生物来解决；化妆品里也有新科技等。

从专业上看，我的研究方向属于一个相当细分的领域，但即使是传统产业也可以应用高科技，比如我们可以运用一些通用的高科技，例如大数据、机器视觉、新材料等等改造传统产业。记得有很多先进科技找不到应用领域，核心原因是整个产业地图没有打通，我们并不清楚材料的这一特性能够给哪些领域带来重大突破。我想这也是王老师发起黑天鹅社群的原因。所以我对前哨第二季的期待是能够讲一些高科技在传统产业的具体应用，这不仅能给我们带来启发，也会给我带来信心。

跟随王老师、前哨团的脚步追逐高科技的浪潮。另外我会对自己的专业深入了解，发掘其中的高科技，争取也能为前哨栏目供稿。相信在前哨的陪伴下，我的研究生生涯能够与众不同。
