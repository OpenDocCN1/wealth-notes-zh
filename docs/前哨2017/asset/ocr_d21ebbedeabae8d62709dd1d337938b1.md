司HERE，人工智能必须要高精度地图，这也是一个机会。

所以，创业公司不是完全没有机会，关键取决于自己的独特性。我们一直强调，在国外投资要投硬科技，就是因为强调它的独特性和专利壁垒。比如Mobileye虽然领先，但独特性不够，它的成败就取决于它的芯片到底最后能不能成功，我们拭目以待。

我们都希望看到更多的创业者能够挑战既有格局，能够推动整个产业向前发展。但现在看起来，在国际上已经赢定的是NVIDIA，基本赢了的是Velodyne，有待观察、有可能赢、当然也困难重重的是Mobileye。剩下的都是大厂商，现在看起来各大车厂还是他们自己竞争，那个老的格局依旧很难被突破。

# 创业者的悲哀

最后说下Navdy公司，它正在做Heads Up Display，中国翻译为“抬头显示”，意思是当你开车时，GPS的情况直接投影到车前方挡风玻璃上，让你的视线不离开正前方路面时就能看到。所以从一定意义上讲，是一个另类的扩展现实，如果能叠加路况信息会更好。

Navdy早在2012、2013年就推出了产品计划，但直到2016年10月份才交付，这回在高通展台上终于看到了它的成品。成品确实不错，但问题在于交付过晚，现在已经有很多竞争产品。虽然竞争产品都不如它，但老百姓感知就受影响了，因为你不是唯一的。

而Navdy这类创新企业最难做的一点在于Heads Up Display是一个后装方案，需要先拥有一辆车，但是越来越多的车会在车内内置投影显示，比如宝马的高端车；最好的是路虎中某一款车的演示，抬头显示不仅有路况信息，甚至把车前方的路况图像投影到车前挡风玻璃上，这让驾驶者看起来就好像车鼻子是透明的，车鼻子前面被遮挡住的路面一样可以看到。这些对于Navdy来说是致命的，因为别人是前装方案，买车时这些方案都已经整合进去了，就不再需要你的产品。

对于Navdy这样的解决方案供应商，除非你能够从后装变前装，就是你能够和车厂合作，现在看起来机会也不大，因为难度慢慢会降低，车厂就可以自己跟上了。

所以就像人工智能，汽车行业创业者很悲哀，太前卫了大家跟不上，就不会采用；慢慢不够前卫了，大家就自己出方案了，还是不用你的。结果就是创新者只是唤醒了老厂商，而自己不能笑到最后。所以再次强调，对汽车产业而言，中国才是创新者的乐土。
