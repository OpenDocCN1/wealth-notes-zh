# 前哨学习报告 | 前进路上，哨声清脆

王煜全

你好，我是王煜全。

前哨的第二季内容正在筹备中，我们努力争取早日给大家端上科技大餐。

过去的一年，我作为侦察兵，每天从美国发回我的科技观察和展望，希望帮助你用最低的成本、最少的精力和时间、获得最顶级的视野。

这一年，不少用户确实因为“前哨”在发生改变。

而我做节目最大的成就感就是能给用户带来意义。

之前，我们开展了《征集：你的前哨一年》征稿活动，今天这篇文章，由前哨用户傅俊军，分享他和“前哨”的故事。

这篇复盘想从一个朋友讲起，我是在埃及旅游的时候认识的这位朋友，在互相介绍的时候就没搞清他从事什么行业，听起来比较匪夷所思——“编织论坛”，接下来在埃及的十几天里我的单反相机派上了大用场，他带去的毛线是我相机最主要的模特，据说这些毛线的原料都是埃及某处羊身上的毛，终于回家了要拍些留影。我们相聊甚欢，找到了很多共同爱好——按他老婆的话说，除了我长得丑点，其他地方我俩还是挺像的（囧），不过我还是没搞清楚他到底是干什么的，当时我觉得不是慈善就是个人爱好。

回国一年后的一个机会到他家拜访了他，张家港，高铁无锡下车后再打车过去，拜访了他的公司和他家，聊到凌晨两点多，我才发自内心地意识到他的事业有多么的传奇，互联网有多么的伟大。

他做了一个论坛，给所有喜欢编织的人交流，论坛里他会分享知识、做培训、销售产品、答疑解惑等等，我都不用给他做广告，因为据说这是全国最大、最久、几乎唯一的编织论坛了，盈利及社会影响力自然不在话下。但我想提醒的是，在一个小城市，一个并不是最专业的人可以做出这么大影响力的事业，如果不依靠科技的进步——互联网，是万万不可能的，也是从那个时候我才隐约地感觉到科技是第一生产力的意义！

说回前哨，第一时间订阅了以后，我发现当时所订阅的几个牛人专栏里唯有王老师是自己叙述的，这种自信和对于时间的管理深深地感染了我，随着时间的不断推进，慢慢的，一年时间快到了，发现自己丰满了不少：

+   1. 看事情的角度，深受感染的是“特朗普”“美联航”两篇文章，看了多个维度不同牛人的分析和分享，自己也思考了不少，也和同事分享了不少，以为自己把各个维度都看到了和想到了，可听了王老师的分析后发现毛主席的那句话还是很高级的，“有一种胜利叫撤退，有一种失败叫占领”，我觉得应该在这之后再加一句“有一种进化叫野蛮”，我觉得这两期节目真正地把我变成了一个有意识在遇到问题时不只是简单地考虑单一维度，唯一标准，同时也会尽量不掺杂感情地去做和考虑事情。

+   2. 更自信，讲一个发生在我身上的小事情，我是做零售行业的，要大量地和外部客户接触，有一次我谈一个合作谈得极其的痛苦，费了很大的劲把对方约出来吃个工作午餐，过程中没怎么聊到相关工作，因为确实没有很好的切入口，偶然对方提到了要在接下来一周谈个VR的项目，我就激动的疯了，我努力抑制着心里的澎湃去谈了VR的内容制作、硬件发展，当我淡淡地说出“光场”技术时，对方让我重复了数遍，最后还拿出了笔记本做了笔记，你能想到当时我内心的激动吗？那一刻我已经不是太在意能不能谈成那个项目了，因为我可以用我的知识征服客户了！自信，是我最想感谢前哨的，深深地感谢。

+   3. 理财，虽然是些小钱，虽然是被大家感谢最多的，但我还是想说说，这不只是挣了点钱，而是给打开了一扇窗，想想一年前的自己还是在看房子的涨跌、基金的选择、信托的回报、APP的安全，和大家一起疯狂也和大家一起叹气。从比特币到欧元特克，这一年深深地觉得眼前开阔了许多，选择多了很多，不简简单单的是买一样东西，而是让自己脑袋里装进去许多“为什么买”，这是多么重要的一件事，知道为什么要购入不是去打听消息，知道路在那里不是跟着别人走，这一年没有听大牛说“不要买A股”，没有听顾问的“买二线城市房”，没有听朋友的“发现个好APP”。我选择了别人认为风险最大的那些，经过自己的思考和分析，你会发现风险只是别人认为的，而不是发生在自己身边的。

最后我想说，“前哨”应该更大地扩充自己的影响力，从我做起积极推荐，因为他对大家的影响是巨大的，不要忘记我那个张家港的朋友，科技改变了他的生活，也帮助了他的朋友们，我也希望更多的人能享受科技的饕餮盛宴，跟着王老师改变自己的想法，增加自己的维度，升级自己的认知。

希望“前哨”越来越好！

王煜全

现在是科技变革的时代，带来了巨大的机遇，随着科技的进步，机会会越来越多。而且，不需要你是技术出身，只需要你懂得用科技，懂得掌握科技的诀窍，你就有机会取得成功。

我是王煜全，你的全球科技前哨侦察兵。
