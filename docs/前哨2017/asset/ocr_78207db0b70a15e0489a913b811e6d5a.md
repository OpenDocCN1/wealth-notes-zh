企业生存最关键的几件事

王煜全

前啸的第一季即将结束，这一年的时间里，我们对全球科技创新领域做了深度分析，有不少用户留言说，专栏真正影响他们的投资、创业、工作。很多用户关心专栏的第二季，现在，我们已经在筹备阶段，相信会以更新、更好的方式和你见面。

近期，我们在发起一项“你的前啸一年”复盘征集活动，欢迎你把你和前啸的故事，你在前啸的学习清单，以及你自己对科技的洞察分享给我们，我们还为你准备了限量版的礼物，具体参与的方式在本文末位，感谢你，一年来对和我一起关注全球科技创新，期待继续共同进步。

细分的平台和服务如何获取用户忠诚度呢？毕竟客户的时间精力是有限的，每个细分领域经过激烈厮杀可能就只剩“头部”和其他了。新浪潮来了之后，用户迁移成本问题，怎么解决？领域太细分，也会导致一个“消费升级”就打翻一片。可以预见：随着平台和其他产品及服务的革新，竞争者之间的界限会模糊直至消失。不知下一波攻击从哪来，如何构建自己的壁垒呢？

王煜全

确实每个细分平台经过一段时间会只剩头部，但技术的进步会带来更多的细分，而新的细分往往属于新的参与者，但老的细分的头部如果不出重大失误也是不会消亡的，我的潜台词是：整体市场在扩大，新人超越旧人，但旧人也有市场，只不过创新者应该关注新科技带来的新机遇，因为新的领导者不是战胜旧的细分市场的头部，而是在新的细分里取得领先，而新细分的体量大大超过旧的细分。

像一般的小IP，比如淘宝直播间的某某知名购物主播，他们可能现在依附于淘宝平台，一旦做大或者想转到别的平台上，那么粉丝也必然会被带走一大部门；大的IP就更不用说了，造成的影响会更大。所以不知道平台应该和IP怎样发展，才能做到竞争力最优？

王煜全

这就牵扯到平台经济里各个角色的分工和价值的问题，平台和上面的参与者各自要有自己的不可替代的长板，参与者的长板是内容和品牌，平台的长板是用户数、关系和数据，用户数优势是根本，国外关系必须开放，所以平台要靠数据优势生存，中国关系属于平台方，普遍不开放，所以主要靠关系优势。另外有两种平台优势不可靠，一是支持能力优势，但优势容易被追平，这样的平台可能借潮流起来，但会很快衰落，比如博客；另一个是品牌优势，必须建立在其他优势之上。

+   1）做企业或者创业，到底是内部团队管理及组织架构职责分工等内部工作更重要，还是开拓市场更重要？

王煜全

能解决现阶段关键问题最重要，要分什么企业，产品优势明显当然是市场重要；市场稳定又够大，则是内部管理重要；研发开拓市场，则是外部资源整合最重要。

传统加工企业想转型，在还未摸索出如何转型的情况下，整理内部团队及管理制度，提高内部运营效率等一些优化自身内部管理的行为是否有必要？还是先找转型出路？

王煜全

首先不要把管理和开拓市场对立，其次关键是你的决心和相应的精力分配是否匹配，多数人是嘴上说转型，却赡不出去时间、资本和资源来支持转型的行动，最后落个温水煮青蛙。
