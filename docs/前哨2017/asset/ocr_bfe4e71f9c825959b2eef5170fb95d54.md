但我也一直强调，虚拟现实未来最大的应用肯定是在娱乐，3D、影视、游戏等，而游戏在 2017 年、2018 年还是有机会的，至少系统已经支持了，一些相对轻量级的娱乐游戏已经出现，例如前面回答中提到的 Pokemon go 的畅销。

而这类应用中有一个点值得我们深入去思考，虚拟世界世界观是否能够改变。希望有时间再和业内的朋友一起做一些相关的研讨，到时候再把这方面的思考汇报给大家。

总的来说，现有技术的低水平完全可以用世界观弥补，所以会让一些游戏热起来，但是整体热还需等到整体技术过硬才行。2017 年、2018 年的热只是点，要铺面的话还要往后，可能要到 2020 年。

王煜全
