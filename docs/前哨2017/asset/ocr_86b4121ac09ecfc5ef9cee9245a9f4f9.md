# 硅谷不倒翁，20年之见证

我与Frost&Sullivan公司的友谊始于20年前。

1997年10月，我邀请其全球创始人David来华，与北京市科技咨询协会一起做讲座，向国内咨询界的150多个同仁介绍美国硅谷和咨询业的发展历史与现状。而在几个月后的1998年1月，我与Frost&Sullivan的现任全球总裁Aroop Zutshi见面，达成合作协议，开始了长达19年的愉快合作。可以说我们当时是最早向国人介绍硅谷的。

客观地讲，Frost&Sullivan并非一个时髦的公司，与专注于IT分析的IDC、Gartner，或者更加前卫的专注分析互联网或者电商的eMarketer这些公司不同，Frost&Sullivan在全球有2000名分析师，分别专注于50多个大行业，数百个小行业，对各个传统行业都有非常深的了解。这也解释了在2000年美国互联网行业出现泡沫之后，很多盛极一时的巨头纷纷裁员倒闭的大背景下，为何Frost&Sullivan公司能够在风雨飘摇中屹立不倒。

这也给了我们一些启示——一个国家的经济不应该片面地侧重时尚前卫的先进科技，只有各个传统领域都实现科技化才能使得经济实现良性发展。当今美国的互联网越来越不是一个独立行业，而是渗透到各个行业领域去，使得传统行业能够持久地发展。反观国内，近年的“互联网+”甚嚣尘上，我希望“科技+”的口号和思维也可以更多地被提及和接受，因为科技才是产业发展的原动力。

# 机器智能崛起，行业分工巨变

Aroop在演讲中首先分析了人工被自动化替代的大趋势。

短时间内，很多老的职位会消失，新的职位会诞生。事实上从工业革命以来，社会职业恒定不变的模式就已经被不断的消灭和新生所替代。工作、职位的消失和新生其实是正常现象，现代人需要清晰地把握时代的脉搏，警惕职位的更迭。

# 扬长避短，正视超级城市化

Aroop还强调了“超级城市化”的趋势。

他的分析表明，大约八、九年之后，全球有86.7%的人会生活在大城市或者城市郊区，而真正生活在农村的人口会从百年之前的绝大多数下降至百分之十几。

当然“超级城市化”并不是发生在发达工业国家，印度的孟买、德里也都聚集了上千万人口，巴西的里约热内卢更是聚集了3000万人口，形成了超大型城市。

我们中国也接受和认同城市化的好处，但是考虑到交通、污染、治安这些随之而来问题，始终有些顾忌。意愿虽然良好，但是未来“超级城市化”一定是趋势——越是超大型城市，越容易发展出强大的公共交通系统，而且创新往往都来自于拥有较大人口密度和个体差异的超大型城市。因此，面对未来的大趋势，相比较限制，主动研究、扬长避短，才是该有的态度。

# 创新迎契机，产业格局瞬息万变

Aroop预测，未来各个产业都将面临产业变化加快的格局，即经过很长时间形成的产业格局在未来很短时间之内就可能会被颠覆。

比如在过去一百年里慢慢建立的物流业，将随着后端管理的自动化发展而发生行业形态的巨变；或者随着无人驾驶汽车和电动汽车时代的来临，汽车业主导者会由生产厂商转变为类似于Uber这样提供汽车服务的企业。未来的汽车产业，很有可能会像当今的电信业一样——汽车只是载体，用户更关心的是通过载体得到怎样的服务。

要应对这样的变化，需要对未来的产业格局发展趋势<|start|>外敏感，居安思危。同时，如果对某个产业的未来趋势有自己的真知灼见，那么产业格局的变化也可以成为创业的契机。

# 互联网引擎，开动数字生活列车

Aroop还与大家分享了他对互联网的看法——互联网将会进一步带动未来发展，达到超出我们想象的程度。

在未来，互联网将带动着数字化从三个层面 edad上实现立体的发展，一是从政府的角度，二是从公司的角度，三是从个人或者社会的角度，这三个角度的数字化的实现意味着大数据可以作详细的分析、人工智能可以通过足够多的数据变得更加智能、意味着IoT（“万物互联”）时代的到来。甚至进一步展望的话，人和机器自由对话的“脑机接口”时代也会来临。

# 科技+商业，双管齐下创未来

Aroop在演讲的最后，强调了科技发展和商业模式有机结合的重要性。

不研究科技，商业模式就没有竞争力，随时可以被模仿、复制。反之亦然，没有先进的商业模式做载体，先进科技往往也难以全面发挥效力。一言以蔽之，既不能不做科技，也不能做超科技，真正做业务的人应该把注意力放在基于先进科技的商业模式设计上。

这一结论戳中了目前国内科技产业的要害——要么直接抄袭海外商业模式，要么盯着前沿科技，做不到兼顾。更通俗地讲，坦克是英国人发明的，但是真正打赢闪电战的是德国人。希望中国能够涌现出更多能够制造出坦克的科学家，同时也能够有更多善打闪电战的企业家，两者结合，中国的经济才会在未来更加辉煌。
