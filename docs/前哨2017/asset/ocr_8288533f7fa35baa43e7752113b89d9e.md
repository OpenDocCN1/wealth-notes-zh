# Microbiome

# 1、Microbiome疗法

微生物菌群失调会造成多种疾病，传统西医破坏了微生物平衡，往往不起作用。

Microbiome是指用微生物群组来防止微生物感染的生态方法，让人体微生物系统回到平衡点。

# 2、肠道微生物

肠道微生物是近年来的研究热点，微生物寄生在人类肠道中，数量是我们自身细胞的数倍。

肠道微生物的作用：

+   1、在人体免疫发展过程中起到重要作用。\n2、与人体呼吸性疾病、衰老以及癌症关系密切。\n3、在药物使用方面，研究者也发现肠道微生物与抗生素、免疫治疗的关系非常大。\n4、通过与人脑关联，肠道菌群甚至可以控制人类情绪，还能影响对食物的喜好。

# Seres Therapeutics公司

Seres是Microbiome治疗领域的佼佼者。

2015年6月，美国医药局FDA正式授予Seres公司SER-109药物Breakthrough Therapy Designation（突破性治疗方向授权）。SER-109药物用来治疗CDI（艰难梭菌感染，一种很常见的医院感染），对医学界而言具有广泛的临床应用。

2015年进入一期临床，30例病人成功治愈29例。使得Seres在2015年顺利上市，且融资1.34亿美金。股价一度从18美元涨到40美元，长期在30美元左右波动。

2016年6月，二期临床设对照组对比后，发现没有明显疗效差异，二期临床被终止。导致股价跌至10美元左右，现停留在12美元。

近期，Seres公司重新获得FDA临床批准，方案没有大的调整，药剂量增加了10倍。

# 投资Seres的机会与风险

生物制药企业大多在药物还没临床前就已经上市，投资这类公司回报高，但风险也很大。Seres Therapeutics就面临着这样的局面。

机会：

+   1、Seres公司是Microbiome领域领军企业，具有明显市场；\n2、CEO是成功开发过多个新药的连续创业者和资深投资人，曾担任默克、强生的高管；\n3、疗效有机会显现，市值增长潜力巨大。

风险：

+   1、药剂量加到十倍，效果不一定显现；\n2、与此同时，副作用是否会大量增加。
