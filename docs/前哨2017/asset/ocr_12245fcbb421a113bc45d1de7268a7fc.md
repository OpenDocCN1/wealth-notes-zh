# 前哨小议 | 关于眼科 OCT的补充

眼科成像是是否是可以用认知测试，甚至是神经病变的检测，比如眼部血流的变化可以反映人大脑的一些改变。

感谢这位读者朋友的问题。眼是脑的窗口，脑部的一些神经性病变会造成眼睛结构或功能上的改变。目前有几个研究组（如美国布朗大学的 Peter Snyder 教授团队）正在研究能否通过对视网膜成像诊断出老年痴呆症（学名：阿尔茨海默病）。

研究发现，老年痴呆症患者的视神经纤维层厚度会变薄，视网膜血流也会降低，而且视神经细胞会出现凋亡等等。不过目前的研究还处于早期，可行性还需要更多的临床数据支持。

通过眼部成像来诊断与大脑相关的神经性病变必须克服一个难题：如何排除眼部自身疾病的影响，来准确诊断脑部疾病。如文中所说，视网膜厚度的变化，视网膜血流的变化等很可能是由于视网膜自身疾病引起的，如青光眼。

我感觉学生近视是一个逐渐变化的过程，可否定期检查，并给出指导性改进和治疗方案？另外将来是否应该有眼科定期体检呢？

近视有个敏感期，从小学开始的青少年时期，如果不合理用眼，很容易导致近视，需要加强户外活动，减少长时间近距离用眼，一般在学龄阶段每半年要进行一次常规眼科体检，如果有近视加深迹象，需要早期干预。如果是假性近视，物理治疗，休息为主，若是真性近视，需要正确配镜，或者佩戴角膜塑形镜，但是需要正确的验光和眼部评估。
