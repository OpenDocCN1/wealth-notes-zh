# 全球科技新闻｜特斯拉4月3日市值超福特

特斯拉4月3日市值超福特

王焜全

最近有一则关于特斯拉的新闻火了，新闻指出特斯拉于4月3日市值超过了福特，腾讯也在近期向特斯拉投了17.8亿美元，购买了5%的股票，造成了很多人对特斯拉的预期高涨。

我曾在前文中提到过，在2017年下半年或2018年初，有做空特斯拉的机会。现在，随着新闻的热度，我也来讲讲我的观点，希望给你多一个思考的角度。

以下是干货笔记，完整内容欢迎收听音频。

# ——♦ 特斯拉的六大困境 ♦——

# 创始人问题

俗话说，成也萧何，败也萧何。

不得不说，伊隆·马斯克确实是个天才，在对未来的布局上，眼光毒辣，看得特别准，基本每个点都踩在了未来的时点上。

布局了SpaceX，做航天，最后收回的火箭证明了重复利用可行。

布局了新能源汽车，在2008年，整个美国股市都不好的情况下幸运存活，获得了巨额投资，渡过了艰难的一关。

布局了做太阳能的企业，Solarcity，这家企业的特点是模式创新，用租赁的办法使太阳能用户可以花更少的钱享受太阳能的收益。

最近也开始布局脑机接口，其中有力的佐证是美国专门研究先进技术的机构DARPA准备了200万美元作为奖金，设置了一场关于脑机接口的竞赛。

但是，在充满竞争者的行业里，创新并不容易，尤其是具有强大竞争力的创新者，必须非常专注。

如果伊隆·马斯克单干任何一件事情，我都认为他的成功几率会非常大，但现在他同时做四件事，其实造成了他个人内部管理精力bundle和外部营销资源的分流。

# 市场接受度问题

特斯拉战线过长，汽车和家庭储能的协同效应都在电池厂上，但目前看，电池厂生产量是最大瓶颈，协同发挥不出来。

一个人使用的汽车和电池墙里面，蓄电池的电池芯都是一样的标准化和来自同一个电池厂，实际上是分流了生产量问题，而生产量问题如果不得以解决，终会影响到特斯拉的生死。

另一方面，买车的用户和买房顶太阳能系统或是家用电池墙系统的用户，他的购买行为是没有连续性。无论是电动车还是储能系统，都存在一个用户接受度的问题，只不过储能系统的用户接受度问题更大。

# 资金问题

储能电池墙肯定在未来会被需要，但需要市场的培育，Solarcity现有做法是融资租赁，但会造成巨量资金占用，未来是否有更好的解决方案，有待观望。另一方面，汽车产业的成本需求很高，对流动资金的需求更是巨大。

虽然伊隆·马斯克有着非常强大的资金储备，除去即将投入到Model3生产当中的20亿美元，至少有10亿美元储备在账上。而Model3制造成本高，30亿美元也仅仅生产10万台。因此资金上确实给特斯拉的经营带来了巨大压力，在汽车领域，20亿美元的资金储备并不够。

另一方面，据说2017年年中，Model3就要开始交付了，交付后，生产速度是否真的会如传闻所言加快呢？这真正经受考验的不仅是它的生产线，还有它的资金管理水平，能否足够迅速地现金回笼，造成不断流，目前看来难度不小。

而市场将会凸显一切问题，等到2017年下半年Model3真正开始交付时，市场会开始盯着你每月每季的出售量、利润等数据，反而会增大压力。而这些压力将从2017年财务数据中公布，你会发现它的财务数据并不会有想象的那么好。

如果特斯拉在未来实现了大规模量产，而财务数据却不够好的时候，市场上对特斯拉高速成长预期的梦将会被破坏的危险。

# 竞争的问题

Solarcity的融资租赁模式在美国已有了已拥有一堆效仿者，而业务模式的最大问题就是没有壁垒。汽车业内的竞争中，虽然特斯拉的汽车业务优势还挺明显，而且如今Model3如果能够大批量地量产，大家还是会预期特斯拉有盈利机会。

虽然现在Model3非常热，预定的车辆也破了世界记录。但是实际上Model3的局面和传统汽车不一样，Model3存在很多同质的竞争者。

例如丰田的普锐斯、尼桑的Leaf。而且其中一个还是主推的油电混合，避免了充电桩不足的问题，而且普锐斯和Leaf都是成名品，他们也在不断地更新迭代。

还有一个主要的竞争对手是通用汽车推出的纯电车，Bolt，它的性能几乎和Model3不相上下，唯一不足是加速度不如Model3优秀，但是在家用的小型车里，太快的加速度倒未必是好事，所以很多人在综合评后，给予了Bolt很高的评价。

# 中国市场开拓的问题

2015年，通用汽车在中国销售了300多万辆车，而特斯拉在中国销售量很小。即使是腾讯投资了17.8亿美元买了5%的股票，但钱并不会直接到达特斯拉手中，不是增发。

如今最大问题是Model3在中国未必有市场。中国的经济好转并没有太久，中国人更追求高端大气上档次，而两厢的节能车并不能满足中国人的需求，因此它在中国销量便成了问题。

另一方面，新能源车其实高度依赖于政策，Model3能否得到上牌优惠、免费等政策支持，取决于和中国政府的关系，而特斯拉和中国政府的关系，一直不够好，因此在中国市场的拓展是一个巨大的问题。

我认为，特斯拉是一个具有高风险的企业，它当然有高回报的可能，但它要么大成，要么大败。

# 技术优势问题

之前介绍过电池技术近几年都没有什么突破，在全球都在发展电动汽车的大环境下，电池成了电动车现有的瓶颈，因此全球的电池厂都在扩产。这种情形也造成了特斯拉的技术优势逐渐不明显。

中国在电动车市场的投入非常大，很多拥有强资金支持的企业，都选择从高端切入，从全球招揽最牛的设计师、工程师加盟，走高端路线。这会进一步减弱特斯拉的技术优势，尤其是特斯拉走着一条从高端到低端的路线。

未来存在着一个技术转换更新换代的问题，从现有的资料来看，新能源车未必只有电动车一条路可走。从能量密度的角度来看，未来新能源汽车很可能是氢能源车，而未必是电动车。

如今比较前瞻的企业也开始投入大量的资源和精力研究氢能源汽车。但我仍然认为，电动车的赢面要大，毕竞更早布局，如果整个技术能迅速建立起配套，氢能源的机会会小很多。但不代表电动车没有挑战，这场竞争还没有结束，未来鹿死谁手还不知道。

# ——♦ 总结 ♦——

确实不能说特斯拉输定了，但现有的关于“特斯拉市值超过福特，创新企业赢定了”的说法，也是不对的。

我仍然保留过去的预测，2017年底，2018年初的时候，特斯拉可能要度过一个生死关，当它推出Model3以后，财务数据怎么样，值得我们期待。

到2018年以后，能否实现盈利的同时还能迅速实现业绩的持续高速增长，最后将在2020年底交完答卷。
