# 周末问答 | 科技优化教育，教育面向未来

科技优化教育，教育面向未来...

又到了周末问答时间，最近有不少针对教育的问题被大家提及，趁今天为大家集中解答一下。

作为编导专业大三学生，担心如果人工智能被操纵传播假新闻怎么办？人工智能时代需要什么样的媒体人？

面对人工智能的大潮，中国高校自身的专业设置应该做什么改变？

王煜全

+   1. 中国的高教机制和国外接轨，学术研究和教育学习并存；新兴学科得到国家大力支持，发展很快。

+   2. 新兴学科同时也能促进招生，教育更多学生，比如人工智能和虚拟现实，新设学科将使新生学习最前沿的科学知识。

+   3. 希望中国更加开放，不仅支持新兴学科发展，同时也允许学科之间优胜劣汰，鼓励竞争，使培养出来的学生都能适应社会。

+   4. 学生要面向未来、放开胸怀，从世界的、跨学科的角度思考问题，所有科技都是工具，就像菜刀可以切菜也可以杀人，作为学生应当学习最前沿知识、最先进科技，最关键的是把使用菜刀的技能掌握在自己手里；如果具有正确的人生观、价值观，就可以用来造福社会。

中年女性，无法常去学校，如何持续学习人机结合的能力？

王煜全

+   1. 年龄与性别不是问题，例如印度重男轻女严重，女性受教育程度低，备受歧视，印度公益人士帮助印度边远山区家庭妇女学习编程，使妇女收入水平提高，同时提高了家庭地位，得到了家人尊重。

+   2. 当今社会已实现在家学习，只要能上网、有时间。

+   3. 编程知识可能离你较远，建议积极尝试手机APP，例如打车、导航、购物、订餐、自媒体等；手机APP依靠编程实现，是人类社会IT化的清晰写照。

+   4. 学会使用各类手机APP，利用现代科技改善生活、提升工作效率，这就是人机结合能力的培养。

因为王煜全老师的推荐，给孩子购买了cozmo，期待培养他们的机器智商。作为第一代移民，家中中使用中文沟通，孩子是否需要参加周末中文班进行系统学习？但孩子时间和精力有限，学习中文是否不如学习编程等在国外更实用的技能？

王煜全

+   1. STEAM是一个完整的学习系统，建议多注意国外在STEAM方面的教育系统，这个值得借鉴；我非常支持孩子学习STEAM。

+   2. 关于海外华人的第二代孩子是否应当学习中文，我认为需要考虑未来的实用性，如果以后完全用不上，那它的学习价值就很小；学习要和环境相结合，考虑孩子的感受。

+   3. 中国文化有很多适应现代社会的精华，关键在于如何向孩子展示，使他产生兴趣去学习，例如现在西方重视禅修、打坐，因为它确实能提升幸福质量、提升工作的专注度和生活品位；孩子学习中国文化的同时，学习禅修知识，一方面使自己受益，另一方面在与人交往时得到尊重，这样孩子就更容易接受。

+   4. 我认为，要给孩子提供学习中国文化的环境（并非送去中文学校），不能强迫；中文其实是交流工具，关键是上面承载的文化；对文化的热爱可以培养，不能操之过急；让中国文化尽量有趣和有用。

+   5. 我对中国文化非常有信心，在过去一百年，中国经历了长期动荡，文化大量流失，但随着经济发展，文化重建也随之展开，文化并没有丢掉，始终保持着良好的传承与发扬。

以上是今天关于教育问题的回答，希望对大家有所帮助。

王煜全
