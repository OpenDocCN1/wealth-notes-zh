锂电池行业未来也能是中国...

王煜全

本期周末问答是关于“如何判断公司实力”、“科研转化为产品”、“中国未来如何在锂电池领域领先世界”的问题。

以下是于货笔记，完整内容欢迎收听音频。

一般主要通过资产损益表、利润表和现金流量表来判断上市公司的经营状况，但如果财务报表异常则表示公司早就出问题了，所以究竟该如何判断一家公司的真实实力和潜力呢？

王煜全

+   1、财务报表是滞后量，财务指标好不代表就一定没问题。
2、财务指标不好，也不等于有问题。
3、财务只是一方面，最重要的是关注企业经营水平，尤其是科技的影响。

例如苹果公司，财务报表非常亮眼只能代表它过去的辉煌，但优势正在减少。苹果在引进先进科技方面明显不如其他先进IT企业，也不擅长搭建合作生态，未来会遇到发展瓶颈。

例如Autodesk，刚刚经历了转型的阵痛，未来值得期待。

一个公司的研发能力和科技产品储备才是超前量，能够预测未来。

有时候科学技术的日常实用化，是一种很遥远的回响，甚至遥远到连发明人都看不到它实现。请问王老师怎么看待这个现象？

王煜全

掌握前沿科技的企业家是最先进生产力。

+   1、科研无法预判，但把科研成果转化成产品是有规律的。
2、科研成果只有转化成应用，才能造福社会。
3、鼓励基础科技领先的同时，更不能忽视企业家的作用，要让科技走向市场。

例如：瓦特并不是发明蒸汽机，而是改良了蒸汽机，使它能大规模应用于工业实践，才造就了英国工业革命；美国近年的科研越发注重实用，企业与高校对接，形成良性循环。

专家预测锂电池行业将来又是中国企业的天下，但现有电池技术还不能满足于让新能源汽车快速替代传统汽车，王牌车企和科技巨头都斥巨资进行电池开发（尤其是自主研发新能源电池）。

您很看好比亚迪，如果电池技术有了革命性的进步，而这个进步不是来自比亚迪，那这个进步对比亚迪的影响是什么？

我想知道这个领域的技术进步和革命，会造成原有技术提升，还是直接颠覆原有技术？

《金融时报》发文指出“电动车这一行业，如果不断降低成本，但不断提升性能，就会触及一个极限——这种车太贵，因为能量密度不够高”，美国外交关系协会能源安全专家说“中国企业不会笑到最后，未来需要更高密度的电池，拥有下一代技术的制造商才会胜出”。您的看法如何？

王煜全

+   1、比亚迪在电动车领域布局良好，至于下一代电池技术，并不是王牌车企和科技巨头能够解决的问题，我认为它会诞生在小公司手中。谁能把下一代技术产业化，谁就是最后的赢家。
2、在电动车领域，《金融时报》认为这一代电池能量密度不够高是对的，价钱太贵是错的。
3、现有锂电池行业看起来似乎是中国企业的天下，但未来并不一定。
4、美国外交关系协会的人的观点反映了中国以前的问题：总是跟随别人的发展，落后于世界先进科技潮流，别 人科技升级，主要是替代进口，很容易被甩下。

海银资本就是想要解决这个问题，让中国企业直接和世界最先进科技对接，帮助对方实现从1到N的过程，同时实现双赢。
