# 前哨小议｜关于光声成像医学应用的补充

王煜全

本周的科技创新地图中，王博士给大家带来了关于光声成像的医学应用领域新进展。今天，针对前哨用户的提问，王博士再次作了相关补充。

我博士期间也接触到过光声技术。感觉现在最大的壁垒还是技术层面。与目前主流的MRI，CT，超声，射线的技术相比，无论从成像精度还是探测深度，光声差的还是有一定距离。

光声成像在探测深度上与传统MRI、CT以及超声确实有很大差距。但是光声成像在组织特异性上由于结合了光学的吸收特性，所以会再提供更多的信息。

由于光声在穿透深度上的局限，目前的应用也都是以观测组织表层面为主，比如皮肤上皮，组织内腔道内壁，乳腺等等。这一 些领域的应用如果能够开发完全，就已经是很大的市场了。

一个外行的问题，可能问题本身就很可笑：

+   1. 光声技术是比超声技术更好，还是两种技术各有优势？
2. 感觉光声技术的难点似乎在，如何使光声探头抵达检测目标，解决方案很多在于使光声探头微小化。如果我的表述是正确的话，那么，光声探头微小化只是光声技术的难点？还是说也是超声技术的难点？
3. 可否提供一些光声成像形成的图片？很想看看长啥样？

1.光声技术有个先天优势就是可以和超声技术相结合，因此光声技术本身兼具超声的功能。所以更多的情况下光声技术在实现的时候是在兼具超声的基础上增添了更多的信息。

2.光声探头的小型化是针对内窥成像的应用所必须完成的。这的确是光声成像技术在内窥镜应用的难点。超声的小型化，尤其是内窥超声已经在国际上相对成熟了。

国内也有数家知名公司在开展这方向的产业化。内窥光声的产业化还需要一定的时间，主要的难点在于导管材料选取，以及成产工序的设计（由于很多工序不能避免手工，因此良品率是未来的一个大问题）。但是我们认为这些工程上的问题在一定时间的积累下都是可以攻破的。

请问王老师这个技术可以简单应用到皮下脂肪和肌肉成像吗？如果可以在健身行业的机会是不是会很大呢？

+   1. 针对性的减肥和制定身体局部的健身计划。2. 判断一个人整体身体机能的优劣。3. 制定合理的膳食计划并进行监控。我觉得病人不如追求美丽的人数多吧。

光声成像是可以完成皮下脂肪的成像的。再加上自带的超声功能，的确可以做一系列的局部组织监控。光声对于脂肪的有效成像深度可以在0.5-1cm左右，结合超声后，对于一般手臂，小腿之类的应该是可以进行脂肪和肌肉的分析。

但是对于肚子，尤其是刚开始健身的朋友，可能有点够呛：），不过当然健身是一个重要的应用。

与此同时，光声在美容上也会有一系列的应用。由于可以分辨脂肪层和肌肉层，光声技术是可以指引玻尿酸注射的，也可以指导并且观测脂肪注射。这也是我们最近在做的一些实验哈。
