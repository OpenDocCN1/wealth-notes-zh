# ——◆ 光声成像的医学应用 ◆——

光声成像（Photoacoustic Imaging）是一种近十年发展迅速的生物医学成像工具。光声成像结合了光学成像和超声成像的优点，拥有广阔的应用前景。

光声成像的原理是，将一束脉冲激发光对生物组织进行照射。当特定的组织吸收了这个光的能量后会生热膨胀。这种脉冲产生的瞬时膨胀会导致一个压力波。我们知道压力波是一个声学信号，这个在超声域声学信号和组织对光的吸收成正比。

由于不同的组织吸收不同波长的激光，因此光声成像可以区分特定的生物组织（如血氧含量，脂肪，特定的造影剂等等）。而且由于不同位置组织产生的超声信号到达探测器的时间不同，我们可以重建出特定生物组织的分布图。

![](bbox=[0.22, 0.0023, 0.78, 0.0034])

光声成像技术继承了光学成像可以达到的生物组织选择性和特异性，但是解决了光学成像的组织穿透性不足的劣势。传统光学成像的组织穿透深度只能达到约1毫米，但是目前光声成像的有效成像深度可以达到数厘米。

光声成像的另一个优势是和传统超声成像的天然结合。光声成像的探头是可以和传统超声探头共用的。这就意味着经过对探头的改装，可以完成光声和超声的多模态成像，并且两个图像非常容易融合，分辨率也接近。

新的成像技术可获得高对比度和高分辨率的机体内脏图像信息，利于更快速地辨别和定位肿瘤位置。这些优势给了光声技术广阔的医疗应用前景。

光声转换现象是由Alexander Bell在十九世纪发现的，但是直到上世纪90年代才开始在生物组织上应用。真正打开光声技术在生物医学领域的应用的是当时在华盛顿大学圣路易斯分校的汪立宏（Lihong V. Wang）教授。他现在刚刚转到加州理工学院。

他在2003年和2006年的两篇Nature Biotechnology文章中把光声显微技术和光声断层扫描技术带到了学术界的聚光灯下。自此以后光声技术的学术文章和专利数连年增长。在这个技术的开发初期，它的主要应用还是以学术研究为主。

先后有多家初创公司围绕这个技术在学术上或者临床前的应用上寻找机会。绝大多数都是以观测小动物在药物调制下血氧含量的变化，以及在造影剂下小动物的肿瘤成像。

![](bbox=[0.18, 0.0066, 0.82, 0.008199999999999999])

这里面的初创企业有 FUJIFILM VisualSonics的Vevo LAZR（技术授权于Seno Medical Instruments）和Endra的Nexus 128（技术授权于OptoSonics）。而这一系列的市场体量有限。主要是以高校和科研机构为主要客户。

经过这几十年的发展，光声技术也从一个学术研究的工具慢慢转化成为一种可以应用在临床上的器械，并且在很多应用上完成了大量的临床数据。

下面我们来根据应用领域总结一下相应应用的价值和相应领域内的初创公司。

+   1. 乳腺

首先是乳腺癌。乳腺癌的早筛一直是一个重要的市场，而且基于影像学的早筛更是这个市场中最主要的部分。但是我们所熟知的x射线钼靶不但准确率较低而且有很强的辐射，而超声检查虽然没有辐射，但是准确率依然不高。这就导致了对新型低电离辐射高精准度的早筛工具的需求。

光声成像就是这样一个被寄予厚望的技术。它在兼备超声早筛功能的同时，增加了乳腺血氧含量和血管增生的信息，为早期乳腺癌提供更全面的无辐射的筛查方案。目前这个方向的产品有荷兰University of Twente的Twente系统，美国德州的Seno Medical，加拿大的OptoSonics，日本的佳能医疗成像等。

这个方向应该在未来一到两年内就会获得FDA的审批（三类医疗器械），有望成为光声技术产业化的第一个突破口。王煜博士所在的Vibronix公司的第一个光声成像的产品也在乳腺癌方向。

他们没有做传统的早筛方向，而是选择了乳腺癌手术过程中对组织进行成像，帮助医生可以更精准更快地完成乳腺癌手术。这个技术可以替代传统的术中冰冻切片技术来对肿瘤残余进行评估，从而使得医生可以在一次手术中完成所有肿瘤的切除。

+   2. 前列腺

其次是前列腺癌。在前列腺癌的诊断过程中，超声引导活检是目前的金标准。这个技术通过直肠超声对前列腺成像，活检针在超声图像的引导下穿过直肠壁对前列腺组织进行取样。这样的取样要做12次。这不但给病人带来巨大的痛苦，而且就算扎了12针，也经常由于癌组织过于分散而漏过癌组织。

目前斯坦福大学的Sanjiv Gambhir教授主导了一组临床实验。希望不通过活检，或者很少量的活检样本来完成对前列腺癌的诊断。目前这个方向还属于早期，门槛在于直肠光声探头的设计，以及如何让激光能够照射到更多的前列腺组织。王煜之前所在的Purdue大学的实验室也在进行这个方向的尝试。

+   3. 皮肤癌，卵巢癌和宫颈癌

黑色素瘤的诊断也是光声技术的重要应用之一。由于黑色素瘤的光学吸收和正常组织的不同，利用光声成像可以对黑色素瘤进行诊断。

卵巢癌和宫颈癌也有光声技术的应用，有些是借助造影剂来完成癌症的成像，有些是单纯通过肿瘤和正常组织血氧含量的不同来完成对肿瘤的分辨。由于还停留在概念期，离应用还有至少5-10年的距离。

+   4. 消化道癌症

光声技术同时也可以在微小化后完成对内腔上皮肿瘤的诊断和治疗。汪立宏教授的研究组在2014年将光声的探头微小化，并且以硬导管内窥镜的形式完成了在动物模型内的食道和直肠上皮的成像。

这种成像方案可以完成对消化道上皮的损伤诊断。这个应用的目的在于证明光声技术可以与目前已有的内腔超声进行结合，完成对食道癌原体的诊断和直肠癌的诊断。
