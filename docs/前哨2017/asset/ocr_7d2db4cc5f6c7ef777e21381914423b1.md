# 前哨小议 | 关于 FSO 问题的补充

王煜全

本周五，王云路博士在前哨提供了一篇 有关自由空间光通信行业的综述文章， 不少前哨朋友提出了非常优质的问题。 今天，王博士将针对这几个问题作回 答。

Arthur Ma：如果有一些不法分子利用 FSO进行反干扰甚至传输一些错误的数据，通过他们自己设计并制造的FSO，就像手电筒一样，可以远程照射并干扰 FSO终端。这种情况怎么办？

静妹：看了激光通信的这么多优点，缺点是天气原因对通信质量有较大影响，还有信息容易被窃取。

不少前哨朋友提出了关于FSO安全性的问题，在这里我统一解答一下。通信系统的安全性分析分为两个方面，一个是对信号的截获，一个是对信息的解析。

在这里，我们主要讨论第一个方面，也就是窃听者能不能轻松的获得信号。至于窃听者获得信号后能不能解析出里面的信息，这主要涉及数字加密等技术，属于信号处理的领域，与通信本身无关。

安全性是相对的，因此我们需要找不同通信技术来进行一下性能对比：1. 有线通信的代表，光纤；2. 无线通信的代表5G，WiFi或者微波。

FSO使用直射信道进行传输，收发端需要精确对准。窃听者必须将窃听器放在FSO的直射信道上才能实现信号截获。此外，FSO一般多建于楼顶、山顶等高空之中。任何想要窃听FSO信道的窃听者都必须么将窃听器装在收发端，这当然比较容易被发现，要么必须将窃听器准确的放在FSO直射信道上，且要稳定的悬停在空中。显而易见，这几乎是不可能的。

对于有线通信，窃听者需要将窃听器放在管线里，而且这些管线大多在地下，难度也非常大。

然而，对于蜂窝通信、WiFi等传统电磁波通信，它们的传输路径并不是直射信道，任何窃听者想要实现信号截取十分容易，他们只需将窃听器放在一个通信范围内的隐蔽角落里即可。

由此我们可以看看到，FSO的通信安全性与有线通信几乎是一个量级，远高于传统电磁波通信技术。如果大家不担心5G和WiFi的通信安全，就完全没有必要担心FSO的安全。

这里再补充回答一下前哨朋友问的关于FSO容易被遮挡的问题。正如之前讲的，遮挡物必须满足恰好落在FSO直射信道上且稳定悬停在空中这两个条件。显然，正常情况下，满足这两个条件几乎不可能。因此我们可以认定，FSO不会轻易被遮挡。

此外，虽然说雾霾会严重影响FSO通信质量，但本质上来说明影响也是相对的。相比晴天而言，雾霾天会让FSO接受信号功率降低，一个最简单的应对方案就是在天气不好的时候，将信号发射功率增大，而这种动态调整对FSO通信来说也并不算困难。

关于FSO的前景，与未来5G的关系，5G时代通信体系会呈现什么新的特征？

FSO的优点显而易见，包括速度快，架设简易，成本低，安全性高等。在未来5G时代，FSO不仅不会和5G通信技术产生竞争，而且会在适合自己的领域找到一席之地。

在回答FSO与5G关系之前，我们需要对未来通信系统做一个基本侧写：一般来说，想提升通信数据率，最行之有效的方法是提升带宽。载频越高的通信方式，其传输带宽也更高。

但是，载频变高也会有副作用，即电磁波的反射和衍射能力变弱，通信覆盖区域变小。这主要是由物质的波粒二象性决定的，频率越高，粒子性越强，波性越弱。

以前，我们为了保证远距离传输，使用800MHz左右的低载频的蜂窝通信。后来，2.4GHz和5GHz的中载频通信系统相继问世，典型的例子就是WiFi局域网。现在，以60GHz毫米波为代表的高频通信即将写入通信协议。那么在未来，以光通信为代表的纳米波，即超高频率通信很快也将服务于人类。

其实，蜂窝通信（分米波），WiFi（厘米波），毫米波，光通信（纳米波），相互之间并不干扰，可以同时使用。未来通信系统的一大特点就是网络层层嵌套，相互组合。未来5G系统，是在一系列基于蜂窝通信的大网络下，散落着许多基于厘米波的域域网、局域网，它们组成了大网络里的小小区。在各个小小区里，又会分布着许多基于毫米波和光通信的个域网，我们把它称作微小区。

以上说的是接入网部分。然而，5G通信系统只有接入网是不行的，网络节点之间的骨干网也很重要。由于光通信带宽大，覆盖范围小，特别适合点对点传输，因此光通信技术会成为未来骨干网络传输的重要解决方案之一。

虽然FSO和光纤有竞争关系，但是FSO的主要特点在于架设简易，它可以随时把小小区和微小区的基站相互连通，这种高度便捷性是光纤不具备的。此外，光纤铺设好了以后，不可能只给少数群体服务，一根光纤需要服务在其路径周圍的大部分企业、住宅楼里的用户；而FSO则更像是私人定制。

在本周文中谈到的FSO让交易所之间低延迟通信的案例里，实现低延时的根本原因是FSO链路只属于这两个交易所，其他人是不能用的。这种能够实现专属性服务的优势，光纤并不具备。（煜全老师在文中说的光传播速度快并不是低延时的原因，这一点有前哨朋友也提出了出来。）

总结一下，一些朋友担心5G的到来会扼杀FSO的发展机会，实际上这种担心是没有必要的。我们说的5G是接入网，而FSO针对的是骨干网。FSO不仅不会和5G竞争，而且它还将是实现细致布局的通信系统的保障。

关于中国FSO的发展状况。

很遗憾，除了华为以外，我并没有在网上查到其他做FSO的中国公司。大多数FSO公司都是来自发达国家。正如我在上一个问题里说的，FSO有点类似于私人定制。它的一大优势是给中小企业，或者是户外临时通信系统搭建局域网络。

目前，中小企业，或者是其他中小局域网的数据率需求仍然没有达到可以让FSO体现出优势的时候。

此外，FSO主要针对骨干网，即使在一些场景下大数据率需求确实存在，但是如果接入网不能实现高速传输，整个通信网络也不能搭建。这也是FSO一直没有获得很好发展机遇的原因。因此，5G的到来对FSO来说是一个契机。当接入网的技术可以支持高速传输时，FSO也会相应获得一个更好的发展机会。
