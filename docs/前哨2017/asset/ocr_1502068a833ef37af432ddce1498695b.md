# 全球化？中国的利与弊

全球化是指多边的开放合作，中国作为发展中国家，在全球化的布局中有弊端也有利好，是比较独特的存在。

全球化受益者大多数是发达国家，事实上，包括中国在内的多数发展中国家是全球化的受害者。究其原因，全球化的本质是由发达国家主导的资源再分配和利益再重组。在产业和业务被输入的同时，发展中国家就被动地成为了某一产业的“专门生产线”，一旦这种特色失去效果，就必然陷入经济下滑的怪圈。

那么这样的全球化何以对中国有利呢？因为中国其实是对observation对方全球化，而自己不全球化的受益者。其原因在于中国入世后奉行的“非贸易壁垒”条款——简单来说就是禁止发达国家一边倒地、单纯地输入商品，而是以合资建厂的形式引其整条生产线、销售、市场等等。其利好显而易见，中国的制造业成长为全球最强，中国人得到了标准化、现代化的经营管理培训。

# 时机未到却席卷全球，全球化养肥了谁？

全球化是一个将经济问题披上政治外衣以获得更大受容度的伪命题。意即在全球化当中，政治为经济代言。

发达国家的制造业遇到的人力成本、资源成本和效率问题，在全球化中得到了解决。更进一步，是发达国家的跨国企业的效率问题得到了解决。与在国内需要考虑国计民生不同，在全球的合作中跨国企业不会也不需要考虑政治问题。

总结一下就是，当今全球化的经济政治并不同步，而一个健康的、可持续的全球化体系必须考虑到发展中国家的感受和本国国民的收益。而如今政治经济不同步的现状可以说明，全球化的时机还未成熟。

# 投石问路，以国际化带动全球化

在全球化时机还未成熟的大背景下，一个可供选择的途径是，先做好国际化。国际化可以和全球化一样指多边的开放合作，也可以指两国之间的双边合作。

先学会和一个国家合作，以此为基础才能更成功地扩展多边合作。这也是目前中国急需的“走出去”中的一个可供探索的模式。照顾眼前利益，一味地坚持单边全球化，是不可能成为全球的领导型经济体的。

总体而言，比较落后的中国产业需要先有针对性地到国外学习如何做国际化，去融入本国的经济、市场、需求。如著作《正义之心》所讲，各个文化、宗教、社会所强调的利益点和价值观其实是非常接近的。国际化的过程中，中国企业要保持好输出自己价值观和尊重对方商业习惯和文化之间的平衡。

# 步步为营，战略投资布局先行

中国迄今为止的国际化的路数主要是在国外收购。而大多数大公司的做法是先有战略投资，慢慢了解对方。到对方企业成长到一定地步的时候，由上市公司完成收购，或者完成战略合作。

如果中国的大企业事先没有战略布局，想当然地收购国外的大公司作为股东耕耘多年的小企业，势必不能获得相互的理解和认同。如野蛮般粗暴收购，反而不能达到国际化的最终目的。

因此，对中国企业而言，学会战略投资做布局——风险投资基金来布局，企业跟上大合作，就迈出了国际化最重要的第一步。

基于此，前瞻希望能以对全球科技前沿脉络的足够理解，成为中国企业对接世界的一双眼睛。不仅做信息的前瞻，也是中外具体合作实践的前锋。

希望能搭建一个桥梁，使得中国的优秀企业能够走出国门，和全球科技最前沿的企业实现对接。
