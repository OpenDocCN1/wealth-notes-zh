血管疾病也有非常有前景的应用——血管内光声成像。血管内光声成像是在现有的血管内超声的基础上增加了对血管壁内胆固醇分布的测量。

大家可能知道，血管内壁经常会形成斑块。轻则使血管狭窄，重则破裂导致血管内凝血。如果破裂发生在冠状动脉，就会发生我们常说的心肌梗塞。这些斑块的重要组成成分是脂类（胆固醇）。这种脂类斑块越大，离血管内壁越近，也就更容易发生心肌梗塞的现象。

而血管内光声成像就是量化脂类斑块大小和在血管壁内位置的工具。这个工具可以被用于新药开发，心血管疾病的诊断，以及后期微创介入的指引。然而对心血管内壁成像需要将光声探头进一步微小化到1毫米左右，并且以软导管的形式沿股动脉一直伸入冠状动脉，这个技术的实现难度还是很大的。

目前，Purdue大学研究组正在美国国立卫生研究院的支持下进行研发。目前的进展是在大型动物上的实验。这个技术未来产业化的难点在于探头和导管的良品率，和激光光源的设计制造。王煜所在的公司也从Purdue大学获得了这个方向多个专利的授权，不过要完成产业化的这些技术难点，至少还需要5年的路要走。

# ——► 总结 ◄——

以上就是对光声成像技术在生物医学应用的一个简单回顾。光声技术在未来的产品转化上的思路主要是广泛地从超声的应用里找机会。寻找到那些超声技术可以解决一部分，但是又解决得不够好的应用。

如果光声技术得到的额外信息对这个应用是有益的（比如增加诊断的精准度或者降低某些医疗风险），那这就是一个可能产业化的机会了。

这种从存量中寻找到机会的优势在于：

+   1）医生更容易接受；
2）可以使用现有的收费方案（中国是收费目录，美国是保险代码）；
3）更容易通过药监局的审批。

这三个方面是医疗器械产业化最核心的考量因素。

当然光声技术肯定可以有超声完全无法解决的应用场景。这种全新的增量市场固然美好，竞争也很低，但是会有很高的政策法规上的门槛。同时需要长时间的市场和医生的教育。更困难的是进入中国的收费目录和拿到欧美这边的保险赔付代码。

无论怎样，随着激光技术的发展和超声技术的成本大幅降低，光声技术的应用和产业化的机会肯定会越来越多。我们也希望看到越来越多的光声技术的创新产品可以帮助更多的医生和病人。
