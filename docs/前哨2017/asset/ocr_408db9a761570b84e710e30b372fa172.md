# 全球科技新闻：那些会在2017改变我们生活的科技

那些会在2017年改变我们...

王煜全

今天1月2日，星期一，但仍然是节假日，今天给大家聊一个比较轻松的话题。华尔街日报给 astronaut 预测，将会有一些科幻电影中曾经出现过的技术，在2017年真正来到我们生活当中。我们来看看都有哪些。

以下是于贫笔记，完整内容欢迎收听音频。

# 最大特色是软件云端更新

一个先进科技，都готовка到说及新硬件，但现在有了软件更新、云计算平台的先进人工智能部署以后，未必需要购买新设备，只需要在手机上下载一个APP，或者在原来的APP上更新，就能实现很多嶄新的功能。

# 华尔街日报推荐了以下十大技术：

+   1 移动视频技术会普及

虽然2016年视频直播已经满天飞，但华尔街日报提及的移动视频技术不完全是直播。目前的视频直播是用手机实现，但看视频的大多数人仍然使用电脑或是投影到电视上。

2017年，用手机看大片会成为一个越来越普及的习惯，而且这件事正在发生。比如，新一版的苹果手机软件更新中加了一个电视键，点击电视键可以进行视频订阅。

以后，手机会更像电视。只不过，这种电视和过去播放节目的电视不同，它更像一个视频内容网站，而视频网站的内容提供更多集中到了手机上。

电视机屏幕越来越智能化，通过软件的更新，会自动安装一些APP，和许多手机端的APP对应。因此，通过电视也可以浏览手机上时常浏览的视频网站，在电视上看视频会变得和在手机上一样方便，而且手机屏幕和电视屏幕间的互动也会越来越顺畅。

+   2.头戴的电脑回来了

VR虚拟现实设备需要处理器，所以就等于将电脑戴在了头上，但这里主要指的是扩展现实技术。

之前的扩展现实技术有谷歌眼镜，但后来谷歌自己把它叫停了。

微软一直在推Hololens，之前的效果不尽如人意，但2017年，新的Hololens会推出一款扩展现实眼镜，能够将虚拟物和现实物体叠加到一起呈现，使得现实物体被打上各种标记，这类产品会在2017年被更广泛地使用。

华尔街日报预测，苹果在2017年有可能推出类似的设备。

华尔街日报还预测，2017年有可能等到Magic Leap。这一点我倒不太认同，虽然它的技术并不假，但什么时候能够大规模量产，实现应用，似乎对外吹了一些小牛，以至于给大家造成了一个负面印象。因此我不太认同2017年的Magic Leap会上市这一说法。

+   3.声控设备走进家庭

2017年，这个趋势不仅会在美国很明显，在中国也会很明显。

现在在美国更多的设备是智能音箱，只要你对着设备发布命令，它就能按照你的要求播放音乐。也可以和家庭里其他的系统相连，帮你开灯开关、控制空调等。

但是总的来说，通过开关控制空调的智能家居应用没有太大的市场，而音箱应用也不是那么常见。所以我依旧坚定地认为，智能家居应用一定是从遥控电视节目开始，而<|start|>声控制是一个最实用的方式。

声音控制会在2017年走进千家万户，尤其是和智能电视相配合的部分，甚至除了智能电视、智能音箱以外，其他的智能家居设备商也在积极响应了。比如通用电器公司，传统上生产洗衣机、洗碗机，现在把洗衣机、洗碗机的智能控制，都和亚马逊的智能设备Echo相关联了，它会更加方便。

智能家居过去了这么多年一直没有进展，正是因为缺少了一个可以重复的反复使用的应用作抓手，通过此应用扩展到其他相对低频和轻度的应用中。现在看来，这个抓手正是声音控制，所以，声控设备将会走进家庭，这是可以预见到的。

+   4.Facebook将还击假新闻

我们之前报道扎克·伯格在美国大选之后出来澄清假新闻事件，他对假新闻的治理态度一直很暧昧，认为这并不关他自己的事儿。现在，扎克·伯格第一次明确表态，要对假新闻进行治理，至少要打上假新闻的标签。华尔街日报认为这件事情是应 该干的，但对扎克·伯格的诚意表示存疑。

除了扎克·伯格的态度，另一则关于谷歌的新闻也提及了谷歌表示对假新闻无法处理。因为要识别一个新闻的真伪太难了，新闻的真伪从大数据上看，并没有太明显的特征差异，所以你怎么识别它是假的呢？这对人工智能技术仍是一个挑战，希望2017年，人工智能专家们能够一起想办法攻克这个问题，把假新闻处理掉。

+   5.机器人终于要上路了

机器人上路其实指的是自动驾驶汽车，华尔街日报的观点和前瞻的观点又一次重合：2017年不会有完全的无人驾驶，但任何新车都会有一定的辅助驾驶能力，这将会变成一个标配。只不过辅助驾驶能力真正进化到完全无人驾驶，还需要一个过程，2017年应该是等不到的。

现在，新锐互联网企业普遍比传统车企更加积极，都在积极尝试第四级甚至第五级的自动驾驶能力。只不过，四级、五级的自动驾驶车中，使用者依旧是一名驾驶员，而且更像监督员，帮助它们跑出更多的四级和五级的运行数据。当数据充 分后，政府才可能放开监管。

新锐企业往往要用更激进的策略和传统车企进行斗争。2020年可能是关键的一年，到底能否达到四级或者 群 五级的普及，要看2020年。

+   6.网络安全警报要响起来了

2016年有一个大新闻，在美国，雅虎丢了10亿用户的密码。中国也出现过类似的消息，有一些网站把用户的账号密码完全泄露。这些事情说明了什么问题呢？人人都在联网的情况下，你被黑客黑掉的可能性大增。

华尔街日报认为，2017年你很有可能会被黑客至少黑一次，所以现在是下载防黑客软件的时候了。以前我们常说给电脑、手机杀毒，现在看来，核心不是杀毒，而是防黑客，保护你的账号密码信息的安全。所以，是不是要更新你的信息安全软件了，这个是华尔街日报给我们提的一个警示，大家必须要重视起来。

+   7.新一波的游戏机来了

微软将推出带有强大虚拟现实功能的Xbox。日本老牌游戏公司任天堂也会推出电视游戏机和手持游戏机的两用手柄，手柄中间有屏幕，左右是控制键，直接拿在手里就能玩，也可以把屏幕的内容投影到高清电视上，用手柄遥控电视内容，和电视屏幕互动。

索尼会推出新的PlayStation，从虚拟现实的支持能力来讲，索尼的PlayStation甚至比现在的Xbox还要好。所以2017年，微软的Xbox要赶紧推出能支持虚拟现实的游戏机。一旦索尼的PlayStation推出新版，它的虚拟现实不会落后于微软。

2017年，虚拟现实将会渐入佳境。虚拟现实最后分出胜负要到2018年，但是2017年，各家企业都会开始加速了。

+   8.全屏手机将在2017年崛起

对手机产业来说，2016年过得并不好。

很多人认为苹果推出的iphone7过于平庸，基本上和iphone6没什么区别，除了一个无线耳机以外，但无线耳机也受到很多批评，太容易丢失。

三星Note7变成了丑闻，成了“炸弹”，飞机上甚至不允许携带Note7。
