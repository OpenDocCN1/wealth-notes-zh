纳米颗粒怎么找到特定部位的呢？

怎么做才能让纳米药物在复杂人体内精准投放呢？

纳米药物的投放并不是实现精准治疗的必要条件。举个例子来说，如果您需要去八达岭长城，从哪里出发并不重要，关键是坐到车。所以，我猜您可能想问的是，纳米药物是如何在复杂的人体内精准地到达特定部位的。

通常情况下，纳米颗粒是分散在水溶液中的，形成“胶体溶液”。此时的一群纳米颗粒可以理解为单独存在于溶液中。当我们将这个溶液通过静脉注射到血液中后，纳米颗粒分散在血液中，随着血液自由游动。也就是说，血液到哪它去哪。这之后，就会有三种去路：

+   1. 血流多的部位，纳米药物就会多。这个很好理解，毕竟纳米颗粒是跟着血流走的。比如纳米颗粒在肝脏的蓄积有一部分就是这个因素——肝脏血流充ñ；
2. 血管漏了，纳米药物漏出去。这就是我们文中提到的被动靶向的原理。肿瘤部位，血管结构与其他部位不一样，细胞与细胞之间存在较大的间隙（400 nm）因此纳米颗粒可以漏出去，这就形成了在肿瘤局部的蓄积。一些早期的抗肿瘤纳米药物的设计思路就是这个。
3. 纳米药物被特定的细胞捕获，就留在这里了。这就是主动靶向。纳米药物在血液内循环，遇到让它留下走不动的那个“它”。当然，识别“它”的机理有很多。例如：抗原-抗体的配对，化学性质的亲和等等等。我们暂且不做展开。
基于这种思路，人们设想，我需要去治疗的细胞、组织的表面如果有特定的抗原（例如HER2），那我就纳米颗粒表面设计一个可以与之结合的配体（例如anti-HER2）。那么纳米颗粒就可以准确到特定的细胞了。

所以，通常的设计思路就是上面三种。不过，这些只是人们美好的设想和模型，在复杂的人体内还有非常复杂的各种调控机制。例如肿瘤内压力升高纳米药物“漏”不过去，抗体类型特异性不佳，颗粒被免疫系统破坏，颗粒表面被蛋白包裹等等。这些都还有待于进一步的研究！

纳米药剂有没有可能用为普通药物呢？像普通的胃药、消炎药那样只是为了更少给身体带来影响的普通药，有没有可能用纳米药剂呢？不能成为的原因又是什么？

药剂学的终极奥义是寻找“合适”的递送系统。纳米技术并非是万能的，也不是普遍的。对于常规的疾病和药物而言，是不需要使用这种体系的。例如使用抗生素治疗细菌感染。当前的注射液或药片已经可以完美地解决大多数问题了。物美价廉，何乐而不为呢？不过，也有人在使用纳米药物去治疗一些极其特殊和严重的细菌疾病。在这种条件下，常用的那些手段都不好使了，纳米药物可以利用其特殊的性质，发挥高效杀菌作用。

小李有刀：纳米药物的瓶颈在哪里？

# 技术的瓶颈主要包括以下几类：

+   1. 高品质纳米颗粒的制备与工业化生产。可以这样理解，纳米药物看不见摸不着，结构都是纳米尺度下，也无法直接操纵。靠的往往是物理化学手段段特定
的材料自发组装。对于材料学，物理化学，工业设计都是比较大的挑战。
2. 纳米药物的靶向机理。体内情况复杂多变，肿瘤更是狡猾多端。现阶段人们也只是观察到纳米药物一些现象，靶向的机理还有待于进一步的探究。纳米药物更加高效地到达肿瘤很难，在肿瘤部位精确发挥疗效同样难。
3. 纳米药物在体内的变化。即使从化学上，我们可以选择我们认为合适的方式，以保持纳米颗粒在体内的稳定性，但是体内的情况非常复杂繁杂。蛋白，酶，酸，碱，高氧，乏氧等都可能导致纳米颗粒的改变。

极其痛苦的化疗时代已经过去了，现在的化疗基本可以达到比较痛苦或者不痛苦的状态，所以不需要过分担心。当然，还是希望大家都能保持健康！

已经有一些研究使用纳米药物去治疗心血管或相关疾病，也是可以具有一定的好处。但是据我所知，还没有药物可以用于临床。

血红细胞好像就是微米级（千纳米）的，要是仅仅血管运输，有必要纳米级的胶囊吗？到达纳米级，很多免疫系统问题会很复杂吧。而且尺寸大小，每个携带药量有限制，可能需要很多胶囊，成本也是问题。

血细胞虽然可以在血管中运行，但是，如果想要颗粒跟疾病的细胞和组织有更好的相互作用还是需要纳米级的尺寸的。现在应用于药物递送的纳米载体往往采用生物可降解的材料构建，运输到特定部位后，直接降解不进行回收。

确实需要很多个颗粒才能够包载足够的药物。但是，颗粒数量的增加并不意味着材料用量的增加，由于纳米颗粒内部比表面积更大，其包载单位量的药物，所需要的材料相对于大的颗粒而言更少了。微米机器 人也是当前研究的热点，但是不常用于血管内给药，往往是消化道或其他较大的腔道会用到。
