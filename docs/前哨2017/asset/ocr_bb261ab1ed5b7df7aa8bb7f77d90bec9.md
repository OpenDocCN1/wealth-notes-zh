# 超级城市化挑战与机遇并存

依据咨询公司Frost&Sullivan的观点，随着科技发展，未来会出现大量人数超过三千万的超级城市，人口密度极大。

与此同时，超级城市本身也会带来诸多好处：

+   创新中心；
技术支持，例如物联网、互联网、人工智能、虚拟现实等；
科技运用，例如社区服务。

科技促进城市化，城市化也促进科技运用。

# 社区服务分类

首先，按领域可分为三类：

+   医疗服务；
生活服务，每个人都只集中精力完成自己最擅长的事情，提供服务；
消费升级服务。

其次，按形式可分为三类：

+   共享服务，例如共享单车、家庭餐桌；
上门服务，例如上门遛狗；
就近服务，例如美国的便利店和药店是一体的。

# 美国社区医疗

美国早已完成社区医疗服务的广泛覆盖，但由于采用全科医生方式，近年来，全科医生制式凸显出众多问题：待遇不如专科医生；服务能力有限。

美国社区诊所正在兴起，未必安排医生，甚至只有助理医生，但装配更多检测诊断设备，尤其和大医院联网。例如美国最大的连锁药店CVS pharmacy和美国最大的连锁超市沃尔玛都积极参与其中。

# CVS pharmacy模式

2016世界500强企业排名第18位，拥有超过7800家零售药店。

MinuteClinic（分钟诊所）：

+   1999年，一位名叫Rick Krieger的人带孩子去医院治疗咽喉炎，仅候诊就花费两个小时，于是Rick Krieger决定致力于解决这个问题；
2000年，Rick Krieger开设了只能诊疗7种简单疾病的小诊所QuickMedx，大获成功；
2002年，QuickMedx更名为MinuteClinic（分钟诊所）；
2004年，分钟诊所开始在Target（美国连锁零售店）开业，与此同时，CVS发现并主动接触分钟诊所；
2005年，分钟诊所在CVS里尝试开设三家店；
2006年，CVS以1.6亿美元收购分钟诊所，如今发展到33个州超过1000家店，服务了超过1800万患者，包括40多种常见疾病和对慢性病的监测，患者平均等候时间低于15分钟，客户满意度95%。

# 未来趋势

随着医疗器械、诊断设备、检测设备的健全，一方面将推动医疗大数据、医用可穿戴、小型诊断治疗器械的发展，另一方面也会进一步促进小型便利型诊所的发展，两个方面相互推进、相辅相成。

美国社区医疗正在替代传统全科医生，日常小疾病将被迅速处理。
