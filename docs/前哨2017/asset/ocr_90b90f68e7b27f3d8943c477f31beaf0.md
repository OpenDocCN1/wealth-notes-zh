# ——黑天鹅社群邀请函——

首先，我想要声明一点：我并不是要做一个让大家连接的普通社群，我的目的找出一ថ条能够创新的做得更好、更有效率的新道路。

在全球各国，经济竞争转为科技创新竞争，而科技创新竞争焦点集中于如何提升创新效率这样的 بْن背景下，我有一个基本观察：以美国为首的国家，通过“积木式创新”提升了创新的效率，促使其经济发展盛不衰。

这样的“积木式创新”摒弃了传统的创新方式，改为通过拥有互补资源的人进行协作的方式使创新加速，这种牛的自由组合，效率更高。

2016年6月份，我和周其仁老师、薛兆丰老师组织中国企业家、投资人去美国游学，其间周其仁老师提到“创新发生学”——创新就像煮一锅浓汤，要有人才密度，不同领域的牛聚到一起，在交流、切磋中孕育创新。

美国硅谷就是这样的例子，那么是否意味着中国必须做出下一个硅谷呢？并非如此。我们需要探讨的是，能否利用互联网的优势，在线上形成较大的人才聚集密度，从而推动创新。

# 强、弱连接该如何利用？

如果要在线上形成密度，就涉及了另一个很有趣的问题，即强连接和弱连接。

弱连接是指相对薄弱的联系，而强连接则反之。在网络上强连接和弱连接有不同的用处，弱连接更利于信息传播，而强连接更利于引起行动。很多创业伙伴都是同学，因为同学往往是强连接。

基于强连接和弱连接的理论，线上的社群，比如动辄500人的微信群，其实有不小问题。原因就在于，500人的大群里相当于给强连接兑了水，造成强连接很难发挥效用。本来可以做成强连接的社群做成了弱连接，变成了仅限于传递信息的社群。此外，也有一些有强连接特性的社群做成弱连接，造成“信息的雾霾”——一个小圈子里，同样信息不断反复出现，造成话题被热议的幻觉和假象。

这样就变成了一个矛盾——明明强连接能引发行动，非要用来做信息传递。当然，信息要变得广大才能使得足够的牛人能够聚到一起，实现强强联手。这时候就需要弱连接的这种传播方式了。此外，光有密度还不够，必须要在自己领域里足夠强，也就是拥有长板的人，聚在一起才会产生创新的思想。

所以，首先要把足够牛的人召集到一起，让他们形成强连接，创新才有可能成功。很遗憾，现有的线上产品，没能做到这一点。

# 线上聚集不起作用，问题出在哪儿？

我关心的是，如何利用现有的工具形成创新，也就是说，不光是让创新发生，而是让创新真正成功。

通过互联网的弱连接作用把信息扩散出去，希望每一个前哨的用户都能够帮我把“黑天鹅行动”和“黑天鹅社群”广泛地传播出去，尤其是传递到你的弱连接那里。这样才能促使有足够长板的人参与进来，并且建立起信任。

此前我们介绍过《大连接》这本书，讲的就是很多创业者说那个我跟我是互补的，但是是无法有效产生连接。这就涉及到人和人之间的“六度连接”理论——每隔6个人，你能和世界的任何一个人产生联系。但是除此之外，人际之间的影响是三度的，也就是说双方中间隔着的人越多，就越可能不会产生有效的连接。因此，信用的建立是不能用弱连接来实现的，必须要用强连接，用信用背书的方式建立起来。

所以我们说，强连接和弱连接要综合使用。微信这么好的工具，在推动创新上并没有看到明显的作用，就是因为把强连接当弱连接用，把弱连接当强连接用了，本末倒置自然行不通。

# 共建互相信任的协作平台

我想邀请你共同完成一个实验——利用罗胖的个人影响力、罗辑思维和得到app的覆盖面，加上咱们各位得到用户、前嗅用户积极支持，使得弱连接的所有信息传播能够达到最广泛。

同时，我把愿意参与的、有热情、有能力的人聚集起来，帮他作信用鉴定，形成一个一个的小社群，在互有信任和信用的前提下，试图达到产生创新行动的效果。只有这样，才能真正把互联网用好。

很多人都说互联网进入了下半场，我认为其实离下半场还远得很，因为上下半场时间对等的话，意味着互联网整体的寿命只有20年，并不令人信服。当然，互联网确实需要升级了，以前我们强调的是信息不对称——如果不上网将会有很多信息不能掌握。但是现在大家都上网的背景下，下一个阶段应该是互联网如何能够促成更多的合作，或者促成全社会效率提升的问题。

此前我们提到阿里巴巴的现CEO卫哲说，马云认为B2B的真正含义应该是Businessman-to-Businessman，因为人和人才会建立信任，并基于信任达成商业上的相互协作。遗憾的是，虽然淘宝解决了小商贩如何和用户产生信任的问题，但阿里巴巴要做的全球商人的协作平台却并未奏效。其中的原因很简单，阿里巴巴的平台上没有一个信任系统，自然无法形成紧密的合作。

因此，我们推出“黑天鹅行动”和“黑天鹅社群”就是希望能够在马云提到的这个点上进一步去探索，找到互联网未来发展的核心问题的解决方法——如何建立信用系统。

# 打造精密协作的小群体

没有坦克就打不出茨沃电战，但是光有坦克没有用，一定要充分发挥它的威力才能达到最大的效果。

当今的互联网、社交网络，比如微信，就相当于坦克，但是大家将微信用成了娱乐工具，而非提升信用的工具；用成了弱连接交换信息的平台，而非强连接建立信任和协作的平台。

我们做的“黑天鹅社群”并不是要重新发明坦克，而是利用现有的坦克，真正打出闪电战来。所以我们虽然称其为“社群”，但这和之前的社群是完全不同的。

# 区别在哪？

首先，社会学领域有一个叫“邓巴数”的概念——即一个社会组织如果能够相互完全的熟悉，群体的数量不能超过150人。光从这一点上来看，就已经和500人的微信大群冲突了。当然，邓巴指数的是一个群体里相互熟悉，并未上升到相互的协作，一个群体里能够相互协作的其实只有30-50人。而能够步调一致地去完成一件事情的小群体则更小，只有10-15人。

我们将这个观点套用到军事上，150人大概是一个连，30-50人大约是一个排，10-15人大约是一个班。连是最小的整体作战单位，但是具体的战需需要几个排的配合来实现，而每个排将30-50人分成若干个10-15人的班，这意味着在战斗当中，你的每一个行动都应该在班内成 员的视野之内，互相拍着掩护冲锋。简而言之，一个班是干一件事，一个排是协作完成整件事情儿。

因此，“黑天鹅社群”不光是要大家相互熟悉，而且要产生信任与合作。
