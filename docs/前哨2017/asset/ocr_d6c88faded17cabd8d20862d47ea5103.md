# 创新地图 | 超高分辨率显微技术

超高分辨率显微技术

温苇，本本科毕业于厦门大学生物系，博士就读于香港大学医学院，目前在美国国立卫生研究院工作，主要研究免疫细胞趋化运动。

生物学是一门古老却又充满活力的学科，它的发展一直是以技术进步为原动力的。远到航海大发现带来了达尔文的相对论，远到基因测序技术催生了生物信息学，每一次技术的重大革新总能启发科学家从不同的视角探索生命的本质。

然而在过去的几个世纪里，虽然生物学的几大领域包括生物化学，分子生物学和遗传学都有了很大的进步，但非常依赖观察实验的细胞生物学的发展速度却差强人意。

究其原因，是因为细胞生物学的主要武器——光学显微镜，与其最初的形态相比并无本质差异。

光学显微镜的发明者是列文虎克，他对当时出现的眼镜片特别感兴趣，就自己打磨了两块来玩。当他把这两块镜片重叠在一起，用它们观察树木的切片时，他看到了从未看到过的细微结构。于是他请人打造了一个铁架子，造出了一台原始的显微镜。

这台显微镜开启了现代生物学的大门，也正是显微镜的出现，促进了现代病理学以及法医学的发展，因此成为人类发展史的重要里程碑。

成像技术的发展在很大程度上决定了生物学以及医学的发展。所谓眼见为实，形态学研究带来的印象是最直接最深刻的，对人类社会的发展也有很大的影响。

从百年前人们不知道细菌感染是怎么回事，到认识微生物、掌握杀菌技术，其对人类健康的影响 embargo 巨大。在显微镜的不断改进下，能看到的细微结构越来越多。

比如说，我们对流感病毒的研究使我们发现了它的特效药，这种药是通过使病毒外壳蛋白失活，从而不能复制出有传染力的下一代病毒来达到治疗的目的。

在研究的过程中，显微镜作为研究蛋白功能、蛋白相互作用和共定位的强有力手段，是必不可少的。

然而自第一台显微镜问世以来，300多年过去了，虽然现代显微镜不再依赖阳光作为光源，而且还能使用紫外光源激发不同波长的荧光，但科学家们每天使用的显微镜仍然和列文虎克爵士用的基本原理是一致的。

1873年，显微学家阿贝指出，传统光学显微镜存在分辨率极限。

比如把两个病毒放在一起，用传统光学显微镜是分不清一个还是两个的。这是由于光的本身性质决定的，任何镜片的改变和光的使用都无法避免。当研究对象是细胞形态学的时候，这个极限并无影响。但如果涉及到分子水平 的观察，分辨率极限就成为了科学进步主要 的瓶颈。

当然电子显微镜的横空出世部分解决了分辨率极限的问题，但是电子显微镜只能观察已经固定好的，失去活性的细胞和组织。或者说，电子显微镜观察到的是对于生物过程某一瞬间的一个截图，无法涵盖某一生物学过程的全部。

然而科学家们从未停止新方法的探索，并各自独立发展出新的显微技术。

例如在1995年，埃里克·白兹格的一篇纯理论设计的文章打破了光学显微镜发展的瓶颈。这篇文章首次提出分别照相然后重叠的思想和操纵荧光分子的想法，从基本概念上对光学显微镜进行了一次革命性的创新。

虽然是纯理论，但是它奠定了超级分辨率显微技术发展的基石。该技术让研究者们绕开光学极限，用方法的变革实现分辨率的突破。与此同时，斯特凡·黑尔也提出用两种激光来精确定位荧光分子，成为另一种提高分辨率的方法。

此后的20年里，超级分辨率显微技术迅速发展，如今已有STED，GSD，SIM，PALM，STORM等多种显微镜问世，达到纳米级的分辨率。

2014年，有三位在此技术上做出重要贡献的科学家们获得了诺贝尔化学奖。这也是对超级显微镜技术的一种肯定。

传统的荧光成像是用一束激光打到样品上，激发荧光分子产生吸收光，再用探测器检测光强。这样是同时检测整个样品平面的光信号。而埃里克·白兹格的新方法是通过控制荧光的激发和淬灭使只有百分之几的荧光发生，同时这种光信号是分布在整个样品的范围内的。

所以每一次检测到的都是单个点信号，看不出来整体的形状。这次是这个蛋白发光，下次是旁边的蛋白发光。如此检测成百上千次，就可以帮助合成一张整体图片。

你可以想象一张透明的塑料纸上有图像的一部分，另一张纸上有另外一部分，当把很多张纸叠在一起时就可以看到图像的全貌。

这种方法最大限度地增加了光信号的检测精度。再加上后期运算处理，照片效果可以达到近乎单分子水平。

一种技术不管多么先进，总要回答一个问题：它有什么用？那么我们来举两个例子。

我们知道如果皮肤擦破了，可能会有细菌从破的皮肤处入侵。有时候消毒并不能去除所有的细菌，这时候就要依靠血液里的免疫细胞聚集到伤口消灭细菌了。科学家们就在研究人的免疫细胞是怎么自主运动，从血液里穿过血管壁到达擦破皮的地方的。

细胞骨架蛋白（就是支撑细胞形态的“支架”）主要负责维持细胞形态，细胞的迁移也需要依赖它们。它们像是坦克的履带，在一边增长，另一边分解。这样细胞就会有一个方向运动。

也就是说，细胞骨架蛋白是在实时变化着的。而观察细胞骨架正是超级分辨率显微镜的拿手好戏。

传统显微镜只能看到这些蛋白“静止”地存在于细胞里，就算是移中的细胞也只能看到一片片的蛋白移动。而用这种超分辨率技术，我们可以看到一根根首尾相连的细胞骨架蛋白支撑着整个细胞形态。

同时，可以看到每根骨架的一头在生长，另外一头在解体，就像一个传送带，带着细胞向前走。这是非常基础科学的研究，让我们了解人类本身，推动人类的知识边界。

基础研究也是疾病治疗的重要前提。有了基础研究，疾病治疗才能更高效准确。就像我们提到的细胞骨架传送带，很多“货物”通过这个传送带运到细胞外或者从细胞膜运到细胞质，这是细胞与外界交流的方式。神经信号的传递就依赖这种运输。如果这个运输出现问题，疾病就会产生了。

现代社会有一种常见老年性疾病阿尔茨海默症，俗称老年痴呆症。它是一种神经退化产生的疾病，但我们对它的认识很不完善，一些基本问题例如神经是如何退化的都还不清楚。

有一种理论认为其生化病因是类淀粉蛋白质的异常折叠和堆积，另一种理论认为是可以稳定细胞骨架的蛋白发生异常变化，产生沉积而阻断神经元的信号传导。

利用超高分辨率显微技术，我们可以清楚直观地看到患病的小鼠神经纤维的结构性退化，从而利于研究其病因，致病过程，以及药物研发。

超高分辨率显微技术还在发展和摸索阶段，解决技术和应用层面的问题是有待突破的。

其一为技术层面，比如它对荧光分子的要求较高，需要含量丰富和亮度高的荧光标记蛋白，不然信号强度不够，不能达到超级分辨率的效果；仪器操作较为复杂，需要花大量时间调试等。

其二为应用层面，即它的应用方向还不是特别明朗，现在这些显微镜基本集中在生物科学领域的研究上。
