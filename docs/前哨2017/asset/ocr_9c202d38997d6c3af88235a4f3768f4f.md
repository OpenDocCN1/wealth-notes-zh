# 全球科技新闻｜小米自产手机芯片，跻身全球第四

小米自产手机芯片，跻身全...

王煜全

今天的产业新闻将给大家介绍小米新推出的手机芯片（2月28号已发布），虽然是“旧闻”，但十分重要。希望通过今天的讲解，能让你收获新的启发。

以下是干货笔记，完整内容欢迎收听音频。

# 全球仅四家手机企业能够自产芯片

+   1、手机芯片非常难做

目前，全球手机企业能够自产手机芯片的只有4家：苹果、三星、华为、小米。

手机芯片SoC（System on Chip系统芯片）非常难做，需要集成手机上所有芯片功能，包括具备各方面处理能力、协调传感器、计算和存储相互协作、管理通讯等。

SoC芯片的设计开发至少需要上亿美金。

+   2、自产SoC芯片，并不是包揽所有芯片

只做集成，并不完全自产，尤其通讯基带芯片，高端基带芯片由高通提供，普通级别由展讯提供。（小米采用展讯的基带芯片）

芯片生产和设计分离，只做设计，生产交给代工厂。（小米设计了负责计算的处理器，由代工厂生产）

设计部分需要芯片公司支持，例如ARM（移动计算领域中最先进的芯片提供者）提供简化的设计工具包Artisan。

# 小米芯片Surge S1

+   1、采用ARM提供的Cortex - A53处理器，8核，4个2.2兆赫、4个1.4兆赫（ARM经典设计思路big.LITTLE，既可解决复杂应用的计算问题，同时又适应耗能低的需求）；

+   2、安装Mali T860 MP4 GPU（ARM提供知识产权，自己开发设计，工厂生产），专业处理4K高清视频；

+   3、小米芯片为28纳米（全球最新芯片已达10纳米），虽无法和高通、骁龙835最先进芯片比拼，但已达到高通中端芯片的处理能力。

# 松果电子

松果电子负责开发小米芯片，由小米和大唐电信子公司——联芯科技（中低端芯片制造商）合资成立（小米51%，联芯49%）。

2014年11月，松果和联芯达成了1.3亿元的SDR1860平台授权协议。

# 芯片设计行业风险巨大

+   1、松果芯片未来发展路途遥远

华为海思的芯片设计思路是从高端到低端，比较容易实现；而联芯是由低到高，其中松果贡献巨大。

松果目前和小米的战略路线一致（用中低端价格来实现中高端性能），目前松果芯片性能达到中端，价格还需观察。

松果研发实力良好，但竞争对手强劲，未来发展路途依然遥远。

+   2、10纳米芯片技术挑战高

小米芯片为28纳米，因为设计能力有限，暂时用不到10纳米芯片的生产能力；
10纳米芯片生产能力全球稀缺，只有三星和台湾企业有能力生产；
设计能力需要和市场相匹配。

+   3、SoC自产企业皆为巨无霸

SoC系统芯片不完全自产，基带芯片方面，只有华为自产，苹果三星采用高通芯片，只有小米采用展讯。

# 小米必须做芯片

+   1、专利问题。做芯片以后，可以得到更底层的专利授权。

+   2、供应链问题。手机芯片愈加同质化，产品更难差异化。

+   3、应用问题。只有掌握底层芯片制作能力，才能自主修改应用。

+   4、市场问题。自己具有设计能力，依托代工厂生产，有效解决供货压力问题。

# 中国政府大力支持芯片产业发展

+   1、中国政府近年来非常支持半导体产业发展，尤其芯片产业。

+   2、国家之前花费巨资希望建立自己的芯片生产能力，例如：中芯国际。

+   3、近年来转为采用并购方式，例如：

清华紫光曾试图收购DRAM企业的Micron美光（过去12个月股价上涨133%，且仍具有超过50%的上升空间）；清华紫光投资美国硬盘厂商Western Digital38亿美元，占股15%，并帮助Western Digital收购著名闪存企业SanDisk。

国资背景的Canyon Bridge收购了Lattice（世界领先、专做FPGA的生产厂商）。

+   4、支持小米自产芯片。

# 悬念和期待

+   1、在国家层面上，之前整体布局偏向“国家队”，虽成绩斐然，但花费巨大且阻力不少，还由于价格波动带来损失（例如清华紫光投资Western Digital后，Western价格缩水，造成38亿投资仅值20亿）。之后的布局是否会向市场敏感度更高的私企倾斜，值得关注。

+   2、在小米的层面，应用能否创新、甚至超越苹果，目前仍有一点差距；在融入先进科技上，小米还有欠缺。

# 我的观点

+   1、如果乔布斯依然在世，iBeacon应用一定比现在流行；

+   2、通讯优先原则目前并不合理，手机产业的未来应当是应用优先；

+   3、在引领科技发展的道路上，希望小米能真正扛起创新的大旗。
