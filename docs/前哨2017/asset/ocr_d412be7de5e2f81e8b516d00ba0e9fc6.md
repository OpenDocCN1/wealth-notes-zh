# 关于中国企业的国际化

听王老师讲到Autodesk公司，查了下它的年报。发现2014、2015、2016财年，Autodesk公司的净收入出现明显下滑（2亿、8千万、负3亿），而三个财年在研发方面的投入仍持续加大（6亿、7亿、近8亿），这一大概率就是所谓的“阵痛转型期”。而股票收益率为从2015财年的每股负1.46美元变成2016的负0.28美元，不跌反升，显示出复苏的前兆。

想请教王老师怎么看研发投入与企业经营指标之间的关系？许多中国企业（特别是国企）在财务指标（特别是收入与利润）下降时总是首先考虑削减研发投入，是否正常？

# 1、滞后量

首先，财务指标是滞后量，财务出现问题，说明经营早已陷入困境。

其次，财务问题无法单纯靠研发来拯救，因为研发普遍需要5-8年的较长周期。

# 2、超前量

企业经营不能看财务指标，要从研发投入和市场培育等超前量去看。

大多数国内企业秉持“盈利与否，全靠市场”的被动思维，而真正能够转型成功的是仍有一定实力，又看到了未来的危机并果断转向的企业。

# 3、中国企业要学会打大仗

很多中国企业因为山寨而做大，但是不能长期持续。回顾我们的革命历史——开始打运动战，解放后打阵地战。

我们希望，中国企业能够学会打大仗、硬仗，靠转型成功实现国际化、全球化。

王老师，您提到我国应该“培养一大批研究型企业”，请您具体讲一讲我们应该怎么做呢？同时，我认为完全照搬美国的“积木式”创新在国内不一定可行。

首先，技术转让是瓶颈之一——对于国内高校的技术转让，国内尚未有拜耳法案这样的立法支持；去国外高校申请，对方会转让给素不相识的外国企业吗？

# 一、国情需考虑，不应成屏障

对“积木式”创新在中国的可行性的思考是必要的，但是不能一概而论地给予否定。

# 二、中国的自主创新前景光明

山寨产品为什么利润低呢？富士康代工苹果手机，一定程度上是独一无二的，按道理来说是有谈判议价能力的。

全球有这么强大的消费类电子产品的需求，中国为什么没有出现第二家类似富士康的企业？门槛高吗？这些制造业是劳动密集型的还是技术密集型的？

制造的制造机器不是也?要从国外引进吗？像日本的川崎重工、富士重工，中国好像只能买国外的设备机器，再加上中国低成本的工人来量产这种模式。另外，中国的徐工、三一重工企业，该如何评价？
