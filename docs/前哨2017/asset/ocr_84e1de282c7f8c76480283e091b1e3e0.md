# 小鱼太弱，大鱼太胖

谷歌看上了一个公司，2014年出资约5亿美元将其收购，2016年3月8日将其改组成一个部门并更名为Terra Bella，2017年2月4日将其出售。来去如风，颇多周折，背后一定有故事。

这家名为Skybox（天盒）的小公司生产的是直径不到1米、却带有直径40厘米摄像头的卫星，能提供清晰度、分辨率极高的地面图像。而谷歌当初の打算，正是希望借助卫星、无人机等各种方法实现对地面各个角落的互联傴的无缝覆盖。如今以3亿美元的价格将其“贱卖”给一家名为Planet Labs的卫星公司，谷歌又有竹么苦衷？

虽然强大，谷歌的主要业务收入依然依赖传统的搜索引擎，值得一提的当属已经拓展到智能家居领域的Android操作系统，这一点自然不容小觑。而谷歌近来动作频繁的战略调整，强调的正是近期的收入利润——为人熟知的GoogleX，从有望开启人类科技新大门到被抛诸脑后，背后的玄机就是利润，这也从侧面印证了在大公司里培养创新实属不易。

即使是谷歌这样高擎创新大旗的科技公司，在利润和创新的权衡中也不免向压力低头。同时这也给了创业者一个启示，以创新做武器，就有机会战胜步步不前的大公司。

# 行业转向，大鱼小鱼现不同

Skybox Imaging虽小，但有谷歌庇护，收购它的Planet Labs更小，由NASA的前工程师在2010年建立，旨在利用卫星提供多方位的地面服务。以小吃大，虎口夺食，它凭什么？

迄今为止，Planet Labs已经发射过数量众多的Nano satellite，即纳米级卫星。这些卫星不高于40厘米，长宽都只有20厘米，呈盒状，国内称为皮星。得益于如今的卫星研制摆脱了国家主导从而大大缩短了研发和制造的周期，卫星携带的芯片等零件也呈指数级缩小，才有了纳米级卫星的诞生。

很多业界专家认为，卫星行业正在经历一场类似于当年超大型计算机到微型机的巨变。面对这样的行业变局，小公司拥抱未来，� playa了发展时机；而大公司身姿笨重，步履缓慢——当年独霸计算机产业的IBM，就是在微型机风潮中倒下了。

显然，在谷歌和Planet Labs眼中，纳米级卫星的未来是不同的。

# 关注私人航天，期待中国布局

Planet Labs实际上是这类卫星的一个代表——迄今融资超过1.8亿美元，2013年4月和11月各放飞了两颗卫星，2014年1月份更是一次放飞了28颗被称为“Dove”（鸽子）的卫星。足见其野心勃勃。

事实上，Planet Labs本来计划到2015年底之前再放飞至少99颗卫星，使总数达到130颗。计划虽然没有实现，但是它计划于2017年的2月14号情人节放飞第三群88只“鸽子”。小而精细，低能耗、低成本，两年使用周期一到，便自动坠毁，这个模式看起来有很强大的生命力。

在波涛汹涌的未来大潮中，多数高管求稳，而创新者则是勇敢地下注。这次Planet Labs给出了科技产业中以蛇吞象的例子，而它也值得被期待，成为卫星领域的巨无霸。

在悄然成长中的私人航天领域，各个角度都有突破——此前声名大噪的SpaceX和Elon Musk（私人企业发射火箭），甚至私人空间站的突破都是例证。私人航天领域蓬勃发展，中国的投资者和制造商们却苦于种种监管和限制，暂时无法大面积布局。希望在不久的将来，中国能够抓住这次历史机遇，在全球科技前沿突破时尽快布局，并且逐渐成为引领者。
