# 周末问答｜前哨大会早知道

前哨大会早知道

王煜全

4月22日我将在北京举办第一届前哨大会，对此有很多朋友提出了一些相关的问题，今天将在这里统一集中作答。

嘉宾除了王煜全老师，还有哪些大咖呢？

王煜全

我们的原则是不会特意邀请成名英雄。成名，也就意味着他的时代已经过去，他的经验可能已经过时。虽然成名英雄的高度我们无法企及，但由于时代发展，他“登山”的旧有路径已经消失，此时他向我们分享的路径和经验已经过时，我们需要发现新的路径。而成名英雄不是预测未来的人，在这一点上他无法帮助大家。

我们会邀请的人，一类是未来的分析者，都是受人敬重的老师；另一类是未来可能成为比尔盖茨、乔布斯、孙正义这样的企业家和投资人。

此外，为了保证内容的完整性，届时只会邀请代表性人物上台，但我都会多作介绍。

前哨大会将出现哪些改变未来世界的黑科技？

王煜全

《前哨》一直在介绍改变未来的高科技，所以你不会对前哨大会上讲到的黑科技感到完全陌生（除非之前没有认真收听《前哨》的内容）；但至少也有rup的一半的黑科技将是你完全没有听过的新内容。

前哨大会上公布的黑科技将和以往《前哨》提到 }}{的高科技略有不同，前哨大会将更加侧重改变生活的部分。届时我们将发布两个榜单，即“改变世界的黑科技榜单”（侧重科技含量）和“改变生活的黑科技榜单”（侧重对生活的影响）。

欢迎你来参加前哨大会，成为科技的前哨。

王老师能否提前透露现场将要宣布的几件大事？

王煜全

首先，黑天鹅社群正在试点当中（目前已有10个小的微信群），总结了不少经验，也需要继续进化，4·22大会将宣布社群扩大计划，通过黑天鹅社群构建开放的信用、实现积木式创新。

其次，将宣布科技特训营二期的计划和详细方案，科技跨界融合才是真正的机会，我们必须 Mir 要了解科技全局，拥有全局性眼光，找到突破性机会。

同时，还会宣布新的美国之旅计划，今年将出现更多先进科技企业，我们也将帮助大家争取更多投资机会。

最后，还有至少两件重要的大事将在现场才会宣布，让我们共同期待。

作为一名普通的前哨用户，如何能够享受科技带来的红利？

王煜全

很多前哨用户非业内人士，暂时和科技产业没关联，依然可以通过《前哨》享受红利。

最小的红利是直接了解到发展前景好的企业与出现问题的企业，按图索骥买股票赚钱。这样使用《前哨》最为简单容易，至少帮你赚回订阅费用，但这个价值太小。

更大的价值、最好的投资是投资自己，《前哨》将告诉大家投资自己的方向，以及如何能够参与其中。你将在众多领域中找到未来方向，参与科技前沿，成为时代弄潮儿。

前哨大会翌日上午，为何还要组织和吴声老师的茶叙交流会（只限十人）？

王煜全

吴声老师对市场、产品、品牌了如指掌，出版了《场景革命》《超级IP》等超级畅销书，他永远站在时代前沿、引领产业潮流，这是非常罕见的。

我和吴声老师曾在1月份的CES展期间，给一位参会企业家做了企业问诊，询问他对市场的想法、深度探讨科技如何与现实需求相结合等，不仅这位企业家本人、所有代表团的成员都感觉受益匪浅，我也很享受这个过程。所以，我特邀吴声老师抽出宝贵时间，再进行一次企业问诊。

我预期最后将有10位具有一定实力的企业家、投资人或至少是具有明确想法、需求的人参加第二天上午的交流会，其间将给大家进行企业诊断、企业战略转型分析，并促成合作。

这相当于 是4·22前哨大会之后的福利，欢迎有实际需求的朋友参加。
