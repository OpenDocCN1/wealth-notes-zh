# ——◆ 农业科技火热之谜 ◆——

# 1、农业是大市场

农业未来有两个主要发展方向：

+   a.提升量

联合国粮农组织2009年的报告认为，到2050年全球农业生产力要提高70%才能满足需求。

+   b.提升质

2015年底，全球有机农业市场已达810亿美元，中国是第四大消费国；

全球前三大有机耕种土地面积排行：澳大利亚、阿根廷、美国，中国排第五；

2005年中国出台了《有机产品国家标准》，近期农业部也推出了《十三五全国农产品质量安全提升规划》。

# 2、农业是大问题

+   a.中国有很多和农业相关的上市企业，大多只从事简单生产，科技含量不高，和国外先进科技差距太大。

+   b.种业科技是科技含量最高的领域：

中国的标志性企业隆平高科2015年营业收入20亿元人民币，利润约4.9亿元（原因：农业在中国享受各种税收减免政策）。

全球领军企业孟山都2016年全球销售额是135亿美金（是隆平高科的40倍），但它在中国的市场份额不到它在全球的1%；每年持续投入总收入的10%作为研发投入。

+   c.中国农业企业研发手段相对落后，研发投入不足；市场潜力巨大，具有很大提升空间。

# 3、农业有大机会

+   a.引入先进科技项目，更容易提升实力。

例如：中国玉米产量是美国的60%，如果达到美国的科技水平，产量可以再提升40%，具有巨大进步空间。

+   b.全球农业科技已进入大数据人工智能和机械化、机器人阶段，中国这些领域的先进科技应当多与农业公司合作。

# ——◆ 孟山都的转型之路 ◆——

1、孟山都的市场已经相对饱和，54%是在美国，14%在欧洲，11%在巴西，7%在阿根廷，整个亚洲只占6%（中国不到1%）。

2、通过采取大量并购，引入先进科技。

2012年斥资2.5亿美元收购Precision Planting（利用大数据和人工智能做非均匀播种密度的种植）。

2013年斥资9.3亿美元收购Climate Corporation（谷歌前员工创办的农业天气数据公司），提供农业数据技术平台和自助保险服务。

3、孟山都认为在种子和化肥以外，大数据业务至少能够带来200亿美元营收。

# ——◆ 全球农业科技趋势 ◆——

+   生物工程（包括转基因）

+   大数据和人工智能

+   智能机械
