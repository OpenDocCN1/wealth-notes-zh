虽然国际上的手机发展得并不好，但对于中国企业来说，正好趁机更进一步，不管是华为还是小米，都有亮眼的表现。小米率先推出了除了下端以外，其他角度均为无边沿的设计款手机，满屏的设计非常亮眼。

但华尔街日报认为中国企业还需警惕，2017年的苹果和三星都有可能推出令人惊艳的机型，从而夺回失去的市场份额。华尔街日报预测，2017年是苹果品牌10周年，可能会有革命性的表现，其中一个传闻是苹果会将home键彻底去掉，变成软键盘，甚至下边的边框也会将边沿抹去，变成全屏幕的手机。

我认为，从苹果明年的表现基本能够窥见苹果的未来走势，它究竟能否延续乔布斯的革命性，就看明年的表现了。如果十周年都不能振作，未来可能真要走下坡路了。但如果十周年的时候，能够有一些求新求变的表现，凭借它以前的优势，应该还能延续它的辉煌。所以2017年，非常值得期待。

# 9.网络中性化的大变身

美国一直有个说法叫网络中性化，政府否决了网络可以针对某些内容提供商提供更高的带宽、更高的速度。

网络提供商虽然看似帮了内容提供商，实际上它会找内容提供商收费。反过来讲，内容提供商要把费用转嫁到用户身上。一旦基础网络运营商实现差异化的服务提供时，用户就会收到更多的潜在收费，实际上对整个市场不利。

虽然这个决策被否掉了，但很不幸，特朗普虽然还没有正式接任美国总统，但已经干了不少糊涂事。其中一件就是他任命的通讯相关负责人，是一个商业派、保守派，他是不支持网络中性化的，他支持网络运营商和内容商合作，给内容商提供差异化的更优质的接入和带宽速度，这样能够让内容商更好地向用户收费。

# 给大家讲一个小故事作为结尾：

我在美国众筹网站上看到了一个产品：两个耳塞式的无线耳机，能够用蓝牙绑定手机。它和普通耳机不一样的点在于自动翻译。

比如你的手机里面听到对方说英文，传到你的耳机里就能翻译成中文，你通过中文回复，对方手机接收以后，传到耳机里又变成英文。这样就可以跨语种地和别国朋友进行交流。听起来很美，但实际上，直到现在仍然没有任何可以轻巧解决的方案被做出来。但这个设计究竟是怎么回事呢？创作者可能在打一个时间差。

一般情况下，一个众筹项目从众筹开始到交付，需要一年甚至两年的时间，它可能只做了一个概念设计，但技术还无法做到。但他现在许诺了做出产品给你，你先把钱交给他，他拿这些钱等着谷歌、科大讯飞等公司能够有这样的技术后，就迅速做到已经设计好的耳机中，然后交付成产品。

我觉得这是一个很有趣的思路，就是对人工智能未来的能力先作一个预测，然后此刻作出许诺，将来能够达到某个能力时，至少可以把位置先占住。这样，企业就能对外宣称，我是全世界第一个推出可自动翻译的耳机。

但是，技术变化如此快，也需要一些聪明的策略，帮助企业把业务做得更好。

雷军就用过类似的策略，小米手机配置很高，但价钱很低。可是他产品推出时，你需要等到小半年后才能买到。但随着芯片的扩产，技术的不断更迭，几个月之后，产品的价格确实已经降到了雷军当初许诺的地步，所以大家会感觉小米手机永远是性能特别好、价格特别便宜。其实是大家忽略了等待的这几个月中，成本已经降价了。

但不管如何，这都是高科技在快速降价的过程中可以使用的技巧，这些技巧也能使他们更快地汇集资金，更快地推出新产品，其实也是造福社会。
