# 先请你作一个思考：

过去十年，最风光的互联网公司是BAT，BAT里最风光的是阿里。

BAT之后的下一代互联网企业里，最风光的要数京东。

可见，中国互联网力量中的最强者是电商。

那么，电商未来的决定性因素是什么呢？我先卖个关子。

# 无硝烟的战役，拼物流的竞争

都说互联网企业竞争是无硝烟的战役，而竞争的决定性因素是后勤。

解放战争为什么能够摧枯拉朽？因为我们在发动群众提供人力物力的支持上，做得非常漂亮；抗美援朝战争为什么是平手？因为远征时供给不足。

现代战争，较量的是物资、后勤，也就是科技的先进性。

由此及彼，电商这一仗的核心，是物流的比拼。

# 电商建立体系，物流左右战局

近年电商发展增速，大家对物流的需求也随之提高。

物流分三大块：仓储、货运和配送。

仓储是货物存放，货运是长途运输，而配送是货物到买家手上的最后一环。

看似是电商战争，其实打的是物流仗，谁的物流体系更便宜、更高效，谁就能最后胜出。

这也是京东和阿里都不约而同地花费巨资建立物流体系的原因。

目前，配送、货运和仓储这三项都各自有科技突破，今天我们主要带来配送的相关解析。

# 股票表现超IT大佬？披萨配送有绝招

过去十年，包括中国在内的全球互联网公司都很难风光。

尤其是亚马逊、苹果、Facebook等高科技领域的领头羊，在股票表现上也大杀四方。

然而，在过去几年里，有一个传统企业的股票暴涨22倍，完胜上述互联网公司。

这家企业，就是Domino's Pizza（多米诺比萨）。

没有店面、专注外卖的Domino，通过网络和电话预订送货上门。

此前我们曾经介绍，不同于大多数人聚居在城市的中国，欧美人的居住较为分散。

从物流配送的方便性、便捷性上来论，效率会比中国低很多。

但是，Domino是个例外。

怎么做到？

依靠极其发达的配送系统，Domino在提供服务的区域里都能在半小时之内完成配送。

# 机器人来袭，配送方式大变样

Domino最近刚刚宣布引入Starship Technologies公司的机器人来做配送服务。

Starship公司早在2016年就已开始提供配送服务，它的机器人能够以每小时10公里的速度完成自动化配送工作。

此外，Starship机器人还得到了奔驰公司的支持。

奔驰公司在2016年展示的未来概念卡车里，提供了卸载Starship机器人的功能——卡车将货物运抵目的地附近，卸载Starship配送车，配送车将货物送达。

同时，奔驰还斥资1720万美金领投了对Starship Technologies公司的A轮投资。

可见，Starship机器人配送车很有可能在未来大展拳脚。

如果Domino和它的合作成功，其配送效率有望进一步提升。

所以，在仓储、货运、配送三合一的物流体系中，配送已经积极引入了自动送货的机器人。

# IT大佬加入，第三方配送服务初露锋芒

不光是机器人，能够提升配送效率的方式还有很多。

国外来看，主要是两个竞争性的策略——

+   一是亚马逊的AmazonFlex，利用众包的服务提供最后一公里的配送或取件服务。
二是UberRUSH，即Uber汽车在空驶时上门取件或配送。

中国也有类似的尝试——

京东众包发展第三方线下配送，提升最后一公里的配送效率。

滴滴车的取件方面虽然暂无详细报道，相信只是时间问题。

可见，电商物流体系中，最后一公里配送的领域已被入侵，入侵者的模式出奇的一致——本身具有良好线上服务能力的企业，将配送服务扩展给第三方客户。

按照这个模式推演，未来Domino与配送机器人的合作成型后，有机会成长为和亚马逊竞争的配送平台。

亚马逊是配送商品，Domino配送食品，这样的未来蓝图非常值得期待。

让更多的餐饮企业加入电商大军，电商的未来会更加辉煌。

# 无人机无用？引领未来配送新模式

此外，在配送领域，一个潜在的有力竞争者是无人机。

虽然著名的研究公司Gartner不太看好无人机配送，列举无人机配送前景的时间性问题等一堆原因。

但是，我认为Gartner小看了技术变革的爆发性力量。

为什么呢？

+   其一，包括亚马逊（Amazon Prime Air）和谷歌（Project Wing）在内的很多IT企业都在积极尝试研发。
其二，类似前文所述的奔驰车和机器人配送的联动，汽车和无人机的联动配送将大有可为。

以上给大家分析了物流机器人领域中配送机器人的部分。

总结来看，电商竞争看物流，物流竞争看科技，科技竞争看整合。

当然，物流的整合不光有配送，还有仓储和货运。
