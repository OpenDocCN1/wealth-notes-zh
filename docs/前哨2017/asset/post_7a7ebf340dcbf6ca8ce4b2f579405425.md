# 前哨科技创新地图 | 人工光合作用开启新能源大门

人工光合作用开启新能源大...

汪磊：斯坦福大学化学工程学院博士后，研究领域是人工光合作用。

当你搜索“人工光合作用”时，经常会看到一些所谓的“重磅消息”，比如“某教授有希望近期解决能源危机”、“解决二氧化碳温室效应指日可待”等。然而事实上，人工光合作用领域的科研成果至今只停留在实验室阶段，还没有达到实用阶段。下面，我们来更客观地了解一下这一领域。

# 丨什么是人工光合作用？

自然界的光合作用是人类得以生存的基础。植物通过光合作用吸收二氧化碳，将其转化成碳水化合物，其中一部分口感更好的变成了我们的食物。从根本上来讲话，光合作用的原理是植物将太阳能的能量通过一系列复杂的化学反应储存在了碳水化合物中，然后我们人体内的酶又通过一系列化学反应将碳水化合物中的能量释放出来支持我们身体和大脑的运动。所以毫不夸张地说，我们一直在“吃”太阳能。

顾名思义，人工光合作用的理念就是用更简单的化学反应来更快、更高效率的完成太阳能的储存，毕竟植物光合作用周期长，效率低，而且产品单一。人工光合作用的终极目标就是直接利用太阳能、水和二氧化碳来产出液态燃料，比如汽油。这样就能实现二氧化碳零排放，同时解决了能源问题，也极大地改善了气候危机。

# 丨为什么需要研究人工光合作用？

上面其实简单地提到了这项研究的动机，但是很多人并没有意识到这项研究的重要性及紧迫性，其中包括现任美国总统特朗普，他和他的团队就对气候变暖相关的研究抱以怀疑的态度。

我们来看看下面这个简单的等式：

能源消耗 = 人口 × GDP/人口 × 能源消耗/GDP （能源消耗等于人口乘以人均GDP乘以单位GDP耗能）

GDP是我们生活标准的象征，也就是说，能源消耗是直接和我们生活标准成正比的。发达国家的人均能量消耗是世界平均水平3倍以上，而其人口只有世界总人口的不到十分之一。想象一下，任何事情都无法阻止我们一颗过上好日子的心，那么世界总能源消耗将增长几十倍。尽管化石能源还没有到枯竭的程度，但是也无法满足这么大的增长速度。

如果没有新的能源体系的建立，那么我们的子孙将无能源可用。人工光合作用是我们至今为止认为最适合成为未来能源的一项技术。尽管现在还没有到达实用应用的程度，但科学家们每天都在为这个目标而工作，希望大众能够给予足够的耐心和支持。

# 丨现在人工光合作用都在研究什么？

那么，如何实现人工光合作用呢？俗话说，条条大路通罗马。各自专业的科学工作者也有他们各自的想法，但是殊途同归，离不开以下几个基本的化学反应：

- (1) 水 + 太阳能 → 氢气 + 氧气
- (2) 二氧化碳 + 水 + 太阳能 → 碳氢化合物 + 氧气
- (3) 氨气 + 水 + 太阳能 → 氨 + 氧气

我们可以简单来分析一下这三个反应。

人工光合作用是一个很受重视的研究领域，尤其是美国和欧洲投入了大量的研究基金，也因此吸引了很多科研工作者和单位来从事这项研究，但是无论哪一个关于人工光合作用的研究，都离不开以上三个反应的紧密相连。总而言之，人工光合作用的研究还有很多的挑战，最大的挑战就是寻找高效稳定的催化剂来催化以上的反应。

中国人口众多，在能源和环境问题上，形势更加严峻。尤其近几年的经济快速发展，导致各地雾霾和其他各种污染情况严重，所以就更加突出了新能源研究工作的重要性。国家在这方面的投入也越来越多，一旦人工光合作用得以实现，那将是一个革命性的变化，全人类都会受益无穷。

又到了周末问答时间，今天补充回答一下区块链和中国制造相关的问题。

煜全老师在8月份提到比特币之后没过多久，我就购买了一些比特币，确实挣了一些钱，但是还是疑问。

- 1）比特币是区块链的应用中最广的一种，但区块链技术有被替代的可能，不能像黄金那样长期持有，以后数字货币如何发展？
2）区块链应用者的参与度决定其能否发展更远，而现在各大联盟兴起，是不是未来区块链应用将会在这些联盟中诞生，如果是，未来数字货币制度是不是也由联盟决定，国家概念是不是会被淡化？

首先，两者需要区分清楚，我们把区块链技术称为开源技术，而只要是算法公开，语言、代码被开放的技术，都可以叫作开源技术。所以，计算机、人工智能、虚拟现实，甚至包括生物技术，无人机制造，大量内容都是开源的。开源技术确实存在着容易被替代的问题，即便在今天取得暂时领先的企业也未必能够在未来发展起来。

以上指的是区块链，而比特币作为区块链的第一个主要应用，尤其是跨政府、分散式、P2P的，没有任何核心节点的数字货币，有它独特意义所在。

1.比特币不可能无限制发行，它的总量有限。世界上上格稀缺的东西随着时间增长总会增值，而且会增值的很快。比特币是严格稀缺的，所以未来一定会增值。但是在基于区块链技术生成的其他货币上，我并没有建议购买，因为我也很谨慎。

虽然区块链后来也生成了各种各样的货币，但总的来说，因为区块链技术是可复制的，而比特币却是第一货币，因此有了足够的强大的象征意义。基本上，比特币的价值不太可能消亡，所以我认为比特币是安全的，但这不意味着区块链也是安全的。

2.现在的联盟确实会在一定程度上左右区块链技术的未来发展趋势，但是它和我们前面说过的其他开源应用（人工智能）有点像，未来发展取决于最大的应用，但如今最大的应用仍未出现，因此未来的规则也还无法谈及。

今天的一些联盟不过是看到了巨大的潜力，但潜力究竟会出现在哪儿，我们还不知道。所以，全球最大的IT企业都会将自己的人工智能平台和算法开源，供大家使用。

3.从大趋势来看，政治强调国家概念，但经济强调全球化，如果给予一段时间，未来一定是经济主导世界发展的。因此，未来国家概念会因为经济贸易的逐渐一体化，大家理念上的逐渐沟通和共融而缓慢淡化，但不会是比特币的原因，比特币没那么伟大，比特币只是全球化、跨国家边境流动，在数字化时代来临时的一种体现。
