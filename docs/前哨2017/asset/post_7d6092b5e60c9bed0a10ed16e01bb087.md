
# 元旦篇｜2017年，前哨有哪些计划

2017年，前哨有哪些计划

## 王煜全

今天是2017年1月1日，开年第一天，我来给大家谈一谈我们的新年规划。

## 一、我们会继续提供前沿内容

有朋友反馈《前哨》内容太深、太枯燥、太烧脑，听了一段时间似乎只掌握了一点，没有太大收获；建议我讲一些能够独立于见影、让人突然启发开窍的东西。

这让我想起佛教有句话，叫做理需顿悟，事须渐修。开悟看起来似乎很容易，但你却不知道别人已经修了多少世。

对每个人而言，实际上还有很多不了解的东西，对基础还有所欠缺，所以首先需要有强大的基础实力，才有可能产生顿悟。如果没有每天的基础学习，对科技前沿就无法产生特别棒的直觉式判断。所以，日常的枯燥工作还要继续，坚持就是胜利！

前沿内容包括

- 1. 科技概念股 / 前沿行业分析
帮助大家理解科技行业和科技概念，搭建知识结构；同时具有实用性，能够学会如何在这些行业里找到实际突破口。至少，有些概念是投资就可以赚钱的。

- 2. 产业新闻 / 新闻评述——
独特之处在于不仅让大家掌握科技产业里最新最重要的动态，同时了解了背后的规律和发展趋向，以及其意味着什么。这是独一无二的门道。

- 3. 前哨圈供稿——
我们已经组织了一个涵盖全球各个产业的前哨圈，每周提供一次顶尖专家的前沿分析，保证对各个产业、尤其是对研究的前沿信息作深入的跟踪。推动社会进步要靠研发，因为要把科研的东西变成产品才能推动社会进步。今天已经不是民科的时代，研发来源于高校和科研机构，所以我们需要前哨圈各个领域从事科研的前沿人物来帮助我们判断科研到底走到了哪里，我们才知道研发要走向哪里。

- 4. 加强企业深度剖析——
2016年我们已经做过硅想、亚马逊等几个企业的深度剖析，2017年我们一定会增加这部分内容，对科技前沿的代表性企业逐一分析，希望大家可以从别人的案例里找到可以学习的地方，找到经验、找到规律。

- 5. 行业报告解读——
他山之石，可以攻玉。很多全球领先的咨询机构或者政府的研究机构做了很多分析和报告，我们将在这些报告的基础上进一步分析，就能看到更多更广。

- 6. 牛人拜访与介绍——
2017年我们会推出更多的牛人拜访，他们站得高、看得远，对一个产业的理解和见解是我们可学习的。需要强调的是，我们是学习别人实在在的见解和对未来的分析，而非学习他的成功学。

关于栏目时间安排，6个栏目每周分别讲一天，有很多当天根本讲不完，只能分成两天、甚至隔周再讲。请大家体谅，因为内容实在太多了，之后我们会尽量更有规律。

在信息越来越过载的时代，我们特别强调信息素养，叫Information Literacy，它的核心是：从繁杂的信息里读出系统，从系统的信息里读出疑问。所以，这正是你锻炼技能的机会，不仅纵向听栏目，还能横向进行整合，希望你可以和《前哨》一起锻炼，从繁杂的信息里读出系统，从系统的信息里读出疑问，掌握信息素养的核心。

关于内容的安排，我们还是不讲人生大道理，如果你实在想听，可以去参加我的线下活动，会有一些安排，比如明年和混沌研习社的合作课程。我认为人生大道理不是不能讲，而是应该等你先掌握一定的基础后再讲。

> 科技是一个优秀企业家的武器，你对你的武器库了如指掌后，才可以设计你的战略战术。往国外看，成功者也多是工程师学了MBA，而不是MBA去搞技术。所以，当你掌握基础之后，再想如何成功。先有技术的role基础，再学怎么做管理和经营。

## 二、会组织更多的线下活动

- 1、大课：
2016年和得到一起做了两次大课，分别在北京和上海，但内容比较偏等， basically都在讲积木式创新理念和全球科技前沿的产业动态。
2017年我们会深化内容，同时也想换形式，比如能否都做成直播，无论你身在何方都可以参与，这样我们可以安排每两个月或每季度一次。而且每次的话题可以提前公布，由浅入深，如果你每期都参加，相当于在订阅了《前哨》的基础上，再做一个系统的梳理，我们将对很多内容进行深入探讨，尽量把每个话题都讲透。

- 2、培训：与混沌研习社合作
（1）公开课，专门讲科技产业未来，尤其是社会发展新趋势中有哪些创业机会；
（2）产品营，讲透过人性怎么设计产品；
（3）科技特训营，讲全球科技产业的扫描，会对每个产业做更加深入的剖析。只有通过系统、枯燥的学习，覆盖各个行业的知识，才能锻炼出更强的判断力，加深你对产业的理解度，这个枯燥的基本功训练是必不可少的。

- 3、小班课程：
根据前哨用户的反馈，我们正在和得到一起讨论，可能2017年年中，计划推出一个小班课程，招收10至15个人，每组至少2人。这个小班就是给每人一对一的传授，彻底授之以渔，教会如何和国外高科技企业合作。包括如何向国外高科技企业投资、找最好的项目、如何让信任的自我介绍、看明白项目、如何跟对方交朋友、建信任、执行项目等。

- 4、海外访学：
当下，中国的各种访学项目越来越多，2017年我们将推出一个非常特殊的访学项目，叫“20对20”——20个中国的企业家或者投资人（带家属），和国外的20个优秀的企业家、投资人（也带家属），选一个地方共同度过周末。白天大家一起休憩娱乐，晚上创业者们继续交流如何深度合作，如何建立信任。所以要建立真正的系统，建立真正的联系网，这是我们要做的事。甚至如果时间允许，我们将不止筹备一期，如果你有兴趣，尤其是确实想要在海外拓展并且有所行动的，欢迎参加。

- 5、年度活动：
这是大家一定要关注的重头戏——2017年4月19日，我们会做全球科技产业前沿大盘点。我们会用一整天的时间跟大家盘点全世界的科技前沿都有哪些，而且会邀请很多人出席，包括国外著名的企业家、投资人，还会在现场给大家展示非常棒的黑科技项目。我们有一个崇高的目标，既然后阿里能够把11月11日光棍节改成了购物节，我们能否一起努力，把4月19日改成科技节，变成中国对全球产业的一大盛会。希望大家鼎力支持，如果你有什么想法，例如如何把这个活动办得精彩，特别欢迎你向我们提出来。

## 三、建立社群

光有一次性的行动还不够，我们要长期联系起来，形成网络，形成平台，形成社群。

- 1、前哨圈2017年还会继续发展，将会把全球学术领域的前沿都吸纳进来，让大家全面了解全球的学术进展。

- 2、组织创新社，能力互补又达成共同目标的入群，大家有实力、有差异、又有意愿，一起合作、一起创新。

- 3、创新行动队，创新社的规模、范围和数量可能很大，具体行动的时候就叫创新行动队。当一个项目来的时候，我就把能互补的人放到一起，希望每个人都献计献策，贡献自己的资源、能力和实力。这样就可以不同标签的人组织到一起，一起研究项目落地方案，一起研究应该跟谁对接资源，甚至一起组建董事会，一起讨论分配方案。我们的目标特别明确，就是必须要组建行动队，必须要有行动。

我们的目标是：为一个新的时代，重新定义创新！

希望你能够跟我一起参加到这个伟大的时代，一起参与到全球创新的潮流当中来。

我是王煜全，您的全球科技前哨侦察兵。
今天是前沿侦察的第200天。

王煜全

# 春节特别版 | 热科技、冷思考

春节特别版 | 热科技、冷...

大家好，我是李翔，今天串门到王煜全老师这儿，来给大家拜个年。

刚刚过去的2016年是非常“前哨”的一年。我相信大家已经被人工智能、深度学习、无人驾驶、VR、AR、MR（虚拟现实、增强现实和混合现实）这些概念轰炸了一整年。

《李翔商业内参》也做了不少这方面的内容，从AlphaGo大胜李世石、凯文·凯利对Magic Leap和虚拟现实的介绍，到谷歌、优步这些公司在无人驾驶领域的布局。这些新概念、新技术、新的名词已经在商业世界中变得不可回避，重要的公司也都重兵进入了这些领域。

我今天想结合自己2016年对商业世界的观察，给大家分享一些关于这些热门科技的冷思考。

首先，是因为媒体和传播的原因，大众对技术的认识和期待，可能同技术的真实进步程度不吻合。

# 比如自动驾驶领域——

国际汽车工程师协会把自动驾驶分为五个阶段。

按照自动化程度的不同，前三个阶段的技术，都需要依靠人类处理行驶过程中的紧急情况。目前市场上销售的自动驾驶汽车可以达到第二阶段，也就是有了车道保持和自适应巡航控制系统等自动驾驶功能。

# 再比如机器人领域——

科技作家约翰·帕夫斯卡采访了参与2015年美国国防部高级研究计划局机器人挑战大赛的公司和研究机构。参与比赛的佛罗里达人与机器人研究所的杰里·普拉特对他说，担心人形机器人暴动反抗人类的想法现在还早了点：“对机器人来说，光是行走就已经足够艰难。”

# 全球科技新闻：那些会在2017改变我们生活的科技

那些会在2017年改变我们...

王煜全

今天1月2日，星期一，但仍然是节假日，今天给大家聊一个比较轻松的话题。华尔街日报给astronaut预测，将会有一些科幻电影中曾经出现过的技术，在2017年真正来到我们生活当中。我们来看看都有哪些。

以下是于沐笔记，完整内容欢迎收听音频。

# 最大特色是软件云端更新

一个先进科技，都准备到说及新硬件，但现在有了软件更新、云计算平台的先进人工智能部署以后，未必需要购买新设备，只需要在手机上下载一个APP，或者在原来的APP上更新，就能实现很多嶄新的功能。

# 华尔街日报推荐了以下十大技术：

- 1 移动视频技术会普及

虽然2016年视频直播已经满天飞，但华尔街日报提及的移动视频技术不完全是直播。目前的视频直播是用手机实现，但看视频的大多数人仍然使用电脑或是投影到电视上。

2017年，用手机看大片会成为一个越来越普及的习惯，而且这件事正在发生。比如，新一版的苹果手机软件更新中加了一个电视键，点击电视键可以进行视频订阅。

以后，手机会更像电视。只不过，这种电视和过去播放节目的电视不同，它更像一个视频内容网站，而视频网站的内容提供更多集中到了手机上。

电视机屏幕越来越智能化，通过软件的更新，会自动安装一些APP，和许多手机端的APP对应。因此，通过电视也可以浏览手机上时常浏览的视频网站，在电视上看视频会变得和在手机上一样方便，而且手机屏幕和电视屏幕间的互动也会越来越顺畅。

- 2.头戴的电脑回来了

VR虚拟现实设备需要处理器，所以就等于将电脑戴在了头上，但这里主要指的是扩展现实技术。

之前的扩展现实技术有谷歌眼镜，但后来谷歌自己把它叫停了。

微软一直在推Hololens，之前的效果不尽如人意，但2017年，新的Hololens会推出一款扩展现实眼镜，能够将虚拟物和现实物体叠加到一起呈现，使得现实物体被打上各种标记，这类产品会在2017年被更广泛地使用。

华尔街日报预测，苹果在2017年有可能推出类似的设备。

华尔街日报还预测，2017年有可能等到Magic Leap。这一点我倒不太认同，虽然它的技术并不假，但什么时候能够大规模量产，实现应用，似乎对外吹了一些小牛，以至于给大家造成了一个负面印象。因此我不太认同2017年的Magic Leap会上市这一说法。

- 3.声控设备走进家庭

2017年，这个趋势不仅会在美国很明显，在中国也会很明显。

现在在美国更多的设备是智能音箱，只要你对着设备发布命令，它就能按照你的要求播放音乐。也可以和家庭里其他的系统相连，帮你开灯开关、控制空调等。

但是总的来说，通过开关控制空调的智能家居应用没有太大的市场，而音箱应用也不是那么常见。所以我依旧坚定地认为，智能家居应用一定是从遥控电视节目开始，而声控制是一个最实用的方式。

声音控制会在2017年走进千家万户，尤其是和智能电视相配合的部分，甚至除了智能电视、智能音箱以外，其他的智能家居设备商也在积极响应了。比如通用电器公司，传统上生产洗衣机、洗碗机，现在把洗衣机、洗碗机的智能控制，都和亚马逊的智能设备Echo相关联了，它会更加方便。

智能家居过去了这么多年一直没有进展，正是因为缺少了一个可以重复的反复使用的应用作抓手，通过此应用扩展到其他相对低频和轻度的应用中。现在看来，这个抓手正是声音控制，所以，声控设备将会走进家庭，这是可以预见到的。

- 4.Facebook将还击假新闻

我们之前报道扎克·伯格在美国大选之后出来澄清假新闻事件，他对假新闻的治理态度一直很暧昧，认为这并不关他自己的事儿。现在，扎克·伯格第一次明确表态，要对假新闻进行治理，至少要打上假新闻的标签。华尔街日报认为这件事情是应该干的，但对扎克·伯格的诚意表示存疑。

除了扎克·伯格的态度，另一则关于谷歌的新闻也提及了谷歌表示对假新闻无法处理。因为要识别一个新闻的真伪太难了，新闻的真伪从大数据上看，并没有太明显的特征差异，所以你怎么识别它是假的呢？这对人工智能技术仍是一个挑战，希望2017年，人工智能专家们能够一起想办法攻克这个问题，把假新闻处理掉。

- 5.机器人终于要上路了

机器人上路其实指的是自动驾驶汽车，华尔街日报的观点和前瞻的观点又一次重合：2017年不会有完全的无人驾驶，但任何新车都会有一定的辅助驾驶能力，这将会变成一个标配。只不过辅助驾驶能力真正进化到完全无人驾驶，还需要一个过程，2017年应该是等不到的。

现在，新锐互联网企业普遍比传统车企更加积极，都在积极尝试第四级甚至第五级的自动驾驶能力。只不过，四级、五级的自动驾驶车中，使用者依旧是一名驾驶员，而且更像监督员，帮助它们跑出更多的四级和五级的运行数据。当数据充分后，政府才可能放开监管。

新锐企业往往要用更激进的策略和传统车企进行斗争。2020年可能是关键的一年，到底能否达到四级或者五级的普及，要看2020年。

- 6.网络安全警报要响起来了

2016年有一个大新闻，在美国，雅虎丢了10亿用户的密码。中国也出现过类似的消息，有一些网站把用户的账号密码完全泄露。这些事情说明了什么问题呢？人人都在联网的情况下，你被黑客黑掉的可能性大增。

华尔街日报认为，2017年你很有可能会被黑客至少黑一次，所以现在是下载防黑客软件的时候了。以前我们常说给电脑、手机杀毒，现在看来，核心不是杀毒，而是防黑客，保护你的账号密码信息的安全。所以，是不是要更新你的信息安全软件了，这个是华尔街日报给我们提的一个警示，大家必须要重视起来。

- 7.新一波的游戏机来了

微软将推出带有强大虚拟现实功能的Xbox。日本老牌游戏公司任天堂也会推出电视游戏机和手持游戏机的两用手柄，手柄中间有屏幕，左右是控制键，直接拿在手里就能玩，也可以把屏幕的内容投影到高清电视上，用手柄遥控电视内容，和电视屏幕互动。

索尼会推出新的PlayStation，从虚拟现实的支持能力来讲，索尼的PlayStation甚至比现在的Xbox还要好。所以2017年，微软的Xbox要赶紧推出能支持虚拟现实的游戏机。一旦索尼的PlayStation推出新版，它的虚拟现实不会落后于微软。

2017年，虚拟现实将会渐入佳境。虚拟现实最后分出胜负要到2018年，但是2017年，各家企业都会开始加速了。

- 8.全屏手机将在2017年崛起

对手机产业来说，2016年过得并不好。

很多人认为苹果推出的iphone7过于平庸，基本上和iphone6没什么区别，除了一个无线耳机以外，但无线耳机也受到很多批评，太容易丢失。

三星Note7变成了丑闻，成了“炸弹”，飞机上甚至不允许携带Note7。

但华尔街日报认为中国企业还需警惕，2017年的苹果和三星都有可能推出令人惊艳的机型，从而夺回失去的市场份额。华尔街日报预测，2017年是苹果品牌10周年，可能会有革命性的表现，其中一个传闻是苹果会将home键彻底去掉，变成软键盘，甚至下边的边框也会将边沿抹去，变成全屏幕的手机。

我认为，从苹果明年的表现基本能够窥见苹果的未来走势，它究竟能否延续乔布斯的革命性，就看明年的表现了。如果十周年都不能振作，未来可能真要走下坡路了。但如果十周年的时候，能够有一些求新求变的表现，凭借它以前的优势，应该还能延续它的辉煌。所以2017年，非常值得期待。

# 9.网络中性化的大变身

美国一直有个说法叫网络中性化，政府否决了网络可以针对某些内容提供商提供更高的带宽、更高的速度。

网络提供商虽然看似帮了内容提供商，实际上它会找内容提供商收费。反过来讲，内容提供商要把费用转嫁到用户身上。一旦基础网络运营商实现差异化的服务提供时，用户就会收到更多的潜在收费，实际上对整个市场不利。

虽然这个决策被否掉了，但很不幸，特朗普虽然还没有正式接任美国总统，但已经干了不少糊涂事。其中一件就是他任命的通讯相关负责人，是一个商业派、保守派，他是不支持网络中性化的，他支持网络运营商和内容商合作，给内容商提供差异化的更优质的接入和带宽速度，这样能够让内容商更好地向用户收费。

# 给大家讲一个小故事作为结尾：

我在美国众筹网站上看到了一个产品：两个耳塞式的无线耳机，能够用蓝牙绑定手机。它和普通耳机不一样的点在于自动翻译。

比如你的手机里面听到对方说英文，传到你的耳机里就能翻译成中文，你通过中文回复，对方手机接收以后，传到耳机里又变成英文。这样就可以跨语种地和别国朋友进行交流。听起来很美，但实际上，直到现在仍然没有任何可以轻巧解决的方案被做出来。但这个设计究竟是怎么回事呢？创作者可能在打一个时间差。

一般情况下，一个众筹项目从众筹开始到交付，需要一年甚至两年的时间，它可能只做了一个概念设计，但技术还无法做到。但他现在许诺了做出产品给你，你先把钱交给他，他拿这些钱等着谷歌、科大讯飞等公司能够有这样的技术后，就迅速做到已经设计好的耳机中，然后交付成产品。

我觉得这是一个很有趣的思路，就是对人工智能未来的能力先作一个预测，然后此刻作出许诺，将来能够达到某个能力时，至少可以把位置先占住。这样，企业就能对外宣称，我是全世界第一个推出可自动翻译的耳机。

但是，技术变化如此快，也需要一些聪明的策略，帮助企业把业务做得更好。

雷军就用过类似的策略，小米手机配置很高，但价钱很低。可是他产品推出时，你需要等到小半年后才能买到。但随着芯片的扩产，技术的不断更迭，几个月之后，产品的价格确实已经降到了雷军当初许诺的地步，所以大家会感觉小米手机永远是性能特别好、价格特别便宜。其实是大家忽略了等待的这几个月中，成本已经降价了。

但不管如何，这都是高科技在快速降价的过程中可以使用的技巧，这些技巧也能使他们更快地汇集资金，更快地推出新产品，其实也是造福社会。
