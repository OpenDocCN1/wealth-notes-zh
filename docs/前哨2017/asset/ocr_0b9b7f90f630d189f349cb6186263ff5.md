# 前哨小议｜关于生物电路相关问题的补充

王煜全

本周四，尚午博士带来了关于生物电路领域的现状与趋势，今天根据用户的留言再作补充。

# 来自用户静姝、Plum、Vam ZHANG：

> “如果注射入人体，这种药物如何被人 体代谢？会不会对人体产生副作用／排异反应？ ”

非常感谢这三位读者的提问。这的确是一个非常关键的问题。药物进入人体主要有两种方式：静脉注射和口服。静脉注射的药物直接通过血液循环系统进入人体。口服的药物则需要通过胃肠道消化吸收后可能进入人体血液也可能直接排出体外（如通过粪便）。进入血液中的药物一般是通过肝脏和肾脏处理后通过尿液排出体外。

生物电路这项技术现在还处在实验室阶段，离真正的人体使用还有一段路。就目前来看，该系统中可能包含基因改造过的大肠杆菌和电子元件。这两个成分如果直接进入血液循环系统中，对人体是有  一定程度安全隐患的。

不过如果口服药物，药物不进入人体血液，而是通过消化系统排出体外则会相对安全。所以生物电路的应用将会首先尝试以口服的方式进行。如  此的话，该系统将很有可能首先被应用在人体胃肠道疾病的监控和治疗中。

另外，为了降低人体的排异反应，整个生物电路系统一定会被整合到一个相对封闭的胶囊里。胶囊的表面也会进行改造（比如修饰带有人体自身标记的蛋白，多糖受体），从而告诉我们身体“是自己人，别开枪”。

当然，这种进入人体的药物的标准研发步骤是非常严格的。药物在上市之前，医药公司一定会进行反复的临床前试验和临床试验，来确保药物的安全性。国家药监局也会进行严格的审查。

所以，如果未来有一天你在药店里买到了基于生物电路开发出来的商品时，请放心大胆地使用吧。

# 来自用户小李有刀：

> “文中讲述地生物电路好像只能对感染性疾病，比如细菌病毒作用比较大。那对一些非感染性疾病，如糖尿病，高血压和肿瘤性疾病作用有多大？”

非常感谢这位读者的提问。文中提及细菌检测仅仅是使用生物电路进行实时检测的一个例子。生物电路检测的目标关键不在于 是细菌病毒，还是人体病变细胞。其关键在于细菌病毒和人体病变细胞所产生的氧化还原分子。理论上，只要是有氧化还原分子的存在，不管是从何而来，电路系统就会相应地产生信号。因此，生物电路可以检测的范围非常广，可以包括糖尿病，高血压和肿瘤性疾病。

除了感染上的应用，生物电路还可以被应用在监控人体内的压力情况。人体细胞在特定压力情况下（如缺氧，吸烟，心情低落）会产生一种物质：自由基（free radical）。

自由基是化学物质在外界刺激下，共价键发生分裂从而形成的带电小分子基团。这些基团会试图通过氧化还原反应将其带有的电子传递给附近的其他物质。大多数自由基具有很强的氧化性，会损害周围的组织和细胞，导致人体慢性疾病和衰老。使用生物电路，我们可以对身体内器官组织中自由基的含量进行监控。

监控自由基的含量可以使我们增强对疾病的预防。比如，很多肿瘤细胞的产生便是由于自由基的存在损害了正常细胞的DNA。有意思的是，肿瘤细胞自身产生比正常细胞多的自由基。最近有研究人员试图证明精神分裂患者体内的自由基比正常人多。如果这个结论得到证实，这就意味着我们可以通过检测少量血液就可以诊断精神类疾病。

总之，该技术可涉及到的领域非常广，不只局限于细菌病毒感染的检测。
