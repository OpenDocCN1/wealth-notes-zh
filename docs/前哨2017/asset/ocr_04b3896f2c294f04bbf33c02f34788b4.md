# 王煜全

第一，生物技术正在全面展开，除基因组外，还有蛋白代谢中间体、微生物群组、精准医疗等。

从微观角度看，人体具有两套最重要系统，一套是基因系统携带了遗传密码；另一套是蛋白系统将基因表达成蛋白，从而形成人体结构，人体是个动态系统，一方面不断建设新细胞、新结构，另一方面不断消解老结构并重新加以利用。

因此，利用基因组可以考察人体的遗传特性，而了解人体现时情况则需要分析代谢中间体。

第二，这些进展能够让我们从更整体的角度看人，但需要更全面的数据支持，对于下一个医学革命而言，现在是第谷时代开始，还未到开普勒时代。

第三，第谷时代已经启动，开普勒时代就一定会来，因为人是最善于归因的动物。

第四，不必追求技术奇点，关键是创新能否成为潮流，生命科学领域的这一天已经到来，创新小公司大量涌现，例如利用基因编辑技术进行针对性研究。
