# CES展·第14期｜中国军团的CES之行

中国军团的CES之行

# 王煜全

今天是介绍CES展的第14天，我们已经用了两周时间为大家将2017年的CES展览全貌作了介绍，最后我们将以“参加CES的中国军团”作为此次展览的收尾。

以下是于货笔记，完整内容欢迎收听音频。

# 中国在CES上分量越来越重

今年一共有4119个展商，其中美国有1755家；中国排名第二，有1575家（其中700家来自深圳）。虽然中国展区面积很小，但依然有待提升。

# 牛人云集

李彦宏、张亚勤、吴甘沙（带着驭势科技去参展，有展位）、余凯（地平线机器人的CEO）、吴军（《吴军 | 硅谷来信》的专栏作者）、吴声（前嗨栏专门组织的游学团）。

华人之前在硅谷组织了一些科技前沿的研讨会，参会的多半是华人，现在中国人又把会场搬到了拉斯维加斯。

# 中国在很多新兴行业里获取了话语权

无人机——
除了著名的大疆无人机（它的创新性在全世界得到了认可），参展的其他无人公司基本也都来自中国。中国的整个无人机行业都在国际上获取了非常坚实的地位。

3D打印——
虽然3D打印今年已经不是最热的领域了，但在3D打印相关的展区内依然有很多中国展团。

新兴领域——
如今有不少中国公司推出了智能机器人产品，类似Nao机器人，大约高一尺，四足能够自由行走。比如优必选公司的产品，虽然这些机器人的功能比承诺相对简约，但会有越来越多的中国公司推出。

# 中国模式

在国外，一个领域往往只有一些顶尖的公司能够介入，无论企业或个人，都保持着很高的水准，但是参与的数量相对较少，竞争相对不激烈。而在中国，不管哪个领域，一旦热起来，就会有成千上万家企业杀入战场。即使一开始大多数企业非常业余，但最后能突破重围的企业往往非常优秀。

所以，在科技领域，全世界大多采用精英战术，而中国，一直采用人海战术。现在，人海战术波及到了国外，会不会覆盖国外精英战术的打法，使得一个个创新性的领域最后都被中国占领呢？我认为值得继续观察。

除了可行走的家用机器人，中国也在不断推出陪伴型机器人。伪制依然是多数中国参展企业的问题，这些企业的原创性依然不够。但现在中国的打法慢慢得到了国际承认，因为在中国人海战术打法中能脱颖而出的企业，往往竞争力非常强大。所以不是说人海战术一定不好，人海战术用高强度的竞争，倒也锻炼出了更优秀的选手。

# 参展的大公司

# 1、整体需要改进

中国的大公司（尤其是和科技相关的大公司）越来越愿意参加CES了。除了传统的华为、中兴、联想等，小米今年也是第一次参加CES展。

但总的来说，中国参展的大公司还有不少需要改进的空间。一方面，创新产品不够多；另一方面，不懂得展示自己的产品。比如华为、中兴，注重了技术描述，却忽略了用户体验。小米注重了用户体验，但它与CES展的气氛却没能完全融合。

# 2、可圈可点的地方

华为推出了全球第一款能够把亚马逊语音系统Amazon Alexa植入的手机；

联想做出了一款类似亚马逊Echo的音响，能够语音互动，而且据说音效比Echo好，但联想在语音互动系统与实际业务相结合的方面，不如亚马逊。

但是不管怎样，中国大企业正在向国际看齐而努力，这值得尊敬。

# 1、乐视的演讲和展示

在展示产品方面，得分最高的是乐视。在CES之前，乐视和法拉第未来做了FF91首发的开幕前演讲，吸引众多目光。而FF91的展台，无疑也是CES展的亮点之一。

不过，迄今为止法拉第未来也并没有说自己是一家中国企业，只提及了贾跃亭是股东，所以演讲和展示还不能完全归功于中国公司。希望未来有真正纯正的中国公司也能达到这样的水平，但不管怎样，这是中国人深度参与的公司，做到这个地步还是值得为他们叫好。

# 2、中国创新者

这一次中国军团的最大亮点在于很多很小的中国创新者，他们向世界证明了中国是有原创的创新能力的。

# a.驭势科技

吴甘沙的驭势科技，产品非常亮眼。一提到车，你或许就会想在一个封闭空间里，有两排或者三排朝着前方的座位。但在吴甘沙眼里，如果车已经是完全的无人驾驶了，车座就没有必要朝前，而应该布置的像个会客厅，大家可以坐在环绕沙发上面对面的交流、休憩娱乐。

他们重新定义了车，这是一个了不起的进步。而且我现场看到很多其他日系、美系车企的人专门过来考察驭势科技的新概念车，他们也希望借鉴这些概念。这无疑是中国引领了世界发展趋势的一个很棒的例子。

# b.物灵科技

一群很棒的年轻人，包括原来自百度的副总裁粟晓嘉唯，他带队做了一系列家用机器人开发，也承接了社交机器人Jibo中国化的任务，做的非常出色。

现在中国的创业有一个特点，大量的创业公司其实是在全球布局的。物灵科技就在硅谷有一个研发团队，专门负责更前沿的科技研发。所以，如今的中国公司不能完全称作中国公司，只能叫华人公司，或者华人主导的公司，因为它们已经是全球化的了，很多公司甚至注册就在海外，这无疑是中国国际化进一步提升的好范例。

# c.CellRobot玩具

CellRobot是一系列的小圆球，将它们巧妙地拼凑在一起可以形成不同的机器人。这个公司其实是一个北京企业，但是很国际化，他们的理念是做模块化机器人（需要机器人完成不同任务，可以用模块化拼接的方式来完成）。他们的口号是Hundreds of Robots in One，就是100多个机器人都可以合成为一个模块化机器人的系统里面。反过来讲，你能够用一个模块化机器人的理念合成出100多种不同的机器人。

# d.美甲打印机

对于众爱美的女孩儿来说，她们可以自己设计好想要的美甲图案，然后用打印机印到自己手上，自己作美化自己的艺术家。

# e.太火鸟团队&HAX加速器

太火鸟团队的展台上展出了几十个他们加速孵化的产品，包括拿了CES创新大奖的无人潜水艇。

像这样的加速器概念，还有另一个从深圳来的HAX加速器，他们更加国际化，实际上是一个美国团队到中国深圳设立的加速器。美国的很多创新者落地生产制造（尤其电子产品），是必须到深圳来的。所以也会有美国人愿意做中间桥梁，帮助孵化全球最先进的科技企业。这次HAX展台带来了很多新产品，比如能够录制声音的3D相机；一万美元以下的工业用的机器臂。

中国军团让世界耳目一新，恰恰是这些层出不穷的中国创新者。而这些拥有先进技术和创意的中国公司，才是中国真正的未来。
