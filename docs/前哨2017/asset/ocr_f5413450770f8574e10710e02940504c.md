# CES展·第12期 | 家电领域的跨界竞争

家电领域的跨界竞争

# 王煜全

今天是CES展会报道的第12期，给你介绍一下我在CES展会上了解的智能家电。

在CES消费类电子产品展上，家电一直唱主角。从最初的音响到黑白彩电，最终主要以电视作为家电特色，在CES展会上延续至今。

以下是干货笔记，完整内容欢迎收听音频。

# 非电视家电亮点平平

先从非电视的其他家电谈起，它们普遍亮点不多，也没有太多科技含量值得炫耀。值得一提的是以下几个产品：

+   1. 集成了亚马逊语音Alexa的LG冰箱，外形特色是冰箱门呈透明状，但受质疑的点在于用语音控制冰箱，让冰箱帮忙下单购物似乎并不是人需要；
2. LG品牌的草坪机器人；
3. 松下公司发布的桌面伴侣机器人，类似前几天介绍过的Jibo机器人，是从社交机器人思路入手的一款产品。

通过以上几个产品可以看出，目前智能家电领域确实存在着跨界竞争的局面，想要抢占家用市场的社交机器人公司也正面临着家电公司的阻击。

# 从历史上的电视看产品规律

虽在家电领域的亮点不及其他领域那么多，但是电视依旧成为了家电领域的最大亮点，不容小觑。近几年，电视产品的更新迭代甚至有了规律可循。借2012年的CES展会作为依据，看看这几个电视热点分别面临着怎样的结局：

迅速变热——
2012年，三星推出了55寸的OLED液晶屏电视。如今，五六十寸的电视几乎成了客厅的标配。

慢慢消失——
2010年前后，裸眼3D电视企图进军家电市场，但最终无论是3D电视还是3D内容，都没能被大众接受，以至于慢慢淡出了公众视野。

重新出现——
还有一种现象是“换药不换汤”，名词一直持续不变地推广，内容一直在迭代。例如，智能电视。过去在智能电视的推广上强调它的应用安装，三星公司的电视甚至能够整合上万个app供大家下载，相当于将pad和手机上的播放模式转移到电视上。现在，智能电视重新热了起来，从强调app下载转移到了语音互动、智能搜索、丰富的网络内容上，相当于智能电视和网络电视的合体。

# 今年的家电领域热点

迅速变热——

屏幕更大、图像更清晰的4K高清，它比曾经的HDTV清晰度更高出了一个量级，需要更高的带宽。谷歌公司在CES展会前迅速推出了VP9新格式，支持4K高清。

4K高清技术普及的同时也需要电视屏幕的进一步增大。这次CES展会上出现了120寸的超级大电视，这些大电视不仅尺寸在增长，也越做越薄，方便安装。预估也会变成客厅里的标配。

为了解决4K高清的普及，内容上也需要下不少工夫，LG邀请了著名内容提供商Netflix的CEO前来介绍他们在4K高清内容生产上的计划，他们将开始提供4K高清版的视频内容。

三星公司推出了QLED量子点电视，使清晰度更加饱和、更加真实地还原色彩。QLED的主要竞争对手是OLED，而索尼公司正式宣布加入OLED阵营，推出了OLED电视。两大阵营的角逐，让未来更加扑朔迷离。

中国的电视机厂商也在积极筹备，海信也宣称2019年会推出QLED电视。另一个显示屏的大厂商LG推出了一个完全不同的技术，Nano cell（纳米细胞技术），但它究竟会是未来趋势还是昙花一现，有何作为还需继续观察。

慢慢消失——

最早的电视是显像管电视，中间凸起；后来演变成液晶屏电视，大平板；如今又有 人认为平板不够好，要做曲面屏。我认为这个技术的适用性并不大，在多人同时观看时，曲面屏反而有副作用。因此，我认为曲面屏还是一个噱头，昙花一现的产品，用户未必会买账。

慢慢被普及——

Smart TV（智能电视）和过去的智能电视不同，更强调对内容的操控，使用户有更大的选择权，自主选择自己想看的内容。

# 多方向逐渐开始

后台系统之争

当Smart TV变成一个大潮流时，后台的操作系统之争愈演愈烈。

如今的操作系统思路分别是：

+   a.最流行的是谷歌Chromecast，主要使用者是三星公司。
b.另一个是WebOS系统，由于系统比较老旧，它的开放性可能会受影响，主要使用者是LG公司。
c.中国的海信和TCL公司选择和日本的操作系统公司合作，叫Roku。使用的是开放的操作系统Linux，被经过大量改动，因此也会受到一定的影响。

总而言之，虽然在后台操作系统上谷歌更占优势。但目前仍是一个群雄割据的阶段。

当电视屏幕提供商发现自己对操作系统有一定的控制力和选择权时，会倾向于设置自己的特色操作系统，以实现对底层更好的控制，因此在未来几年，操作系统还不容易被统一。

由于操作系统的不确定，亚马逊、Nexflix、Hulu、HBO等内容提供商纷纷向智能电视转型，提供订阅包，里面的内容可以随时下载，随时观看。但为了适应不同规格的智能电视，也需要开发许多不同版本，所以，电视最终能否统一到某个操作系统上，还需要拭目以待。

语音交互界面之争

前台争夺也同样激烈，尤其是在2017年的智能语音控制领域，不过这个领域的争夺会有提前落下帷幕的机会。如今，CES展会上，亚马逊公司的语音控制系统Alexa基本做到了一枝独秀。

和谷歌的Google Home相比，亚马逊在应用结合上做得更好，系统能够更好地接洽到亚马逊自己的服务中。

在人工智能时代，最好的人工智能并不一定是技术，而是和应用结合的最紧密的数据。而在离应用更近的维度上，亚马逊确实有着得天独厚的优势。

内容提供商之争

其中，苹果的Apple TV一直表现不错，而亚马逊、Netflix等其他内容提供商也不甘落后。

未来决定电视产业的究竟是谁，依旧充满了悬念。但随着各方竞争的加剧，消费者终将是最后的受益者。
