# 全球创业者报告

全球创业者报告

王煜全

新年新气象，周一给大家介绍了2017年将要进入生活的高校科技，周二介绍了有哪些新的工作机会，今天周三给大家介绍一下应该有什么样的创业者。

BNP Paribas（世界最著名的财富管理公司之一）和Scorpio Partners（财富管理相关的咨询公司）在2016年底合出了一个《全球创业者报告》，下面就给大家解读这个报告，借此使大家能够认识到什么样的创业者是这个时代的特征。

这份报告汇总了对亚洲、欧洲、美洲21个国家的2650位成功创业者的调查，他们具有很强的代表性，是创业领域的明星，总财富超过400亿美金。

# 《全球创业者报告》的结论：

+   1、从全球的角度讲，创业是有家族基因的，具有家族连续性。

比如特朗普，就是连续创业的家族企业，从他爸爸手中继承房地产事业，并扩大规模。全世界也亦如此，71%的创业者其实都有家族的参与，而且越大的企业有家族参与的比例越大。而中国的家族参与比较少。

|---|---|---|---|---|---|
|中国|21%|22%|3%|15%|52%|
|阿联酋|暂无数据|62%|26%|暂无数据|暂无数据|
|美国|21%|41%|20%|14%|33%|

中国的创业，家族没有参与的比例是52%，这是所有被调查的国家里最高的。反之，阿联酋是另一个极端，88%的财富都来源于世袭。

美国是一个相对更稳定的国家，从美国的数据基本上能看出未来创业的恒定状态，中国早晚也要走到这个阶段。美国正好介于中国和阿联酋之间，我认为这是比较恰当的一个比例。

+   2、精英创业者的特点：

# 专注

报告中提到，这些创业者平均参与或管理的企业数目是3.5个，少于去年调查的数目5.7。其实这一点我是存疑问的，理论上讲，两年时间，这个调查的数量不应该波动那么大，就是企业家在一年时间不可能更新换代。

但是另一方面来讲，他们的领域是值得肯定的，45%的创业者来自更新的领域，比如IT、互联网、移动、移动通讯，包括无线互联网，制造业、零售业和工程领域，要么特别新，要么和老的生活直接相关，这个就更容易创业成功。

# 有明确的目标感

一般来说，追求财务成功往往是个人动力的前两名，但往往并不是第一名，第一名更多的是追求自我超越、自我实现，或者有差异感、成就感。当然，太没有财务追求也不能成功。

# 信心

对未来充满自信，61%的创业者过去一年的盈利是增加的，63%的创业者预期2017年盈利还会进一步增加。

# 回馈社会和价值投资意愿

他们自己是辛苦打拼的创业者，所以也很愿意培养后起之秀。在投资方面，16%追加自己的生意，但18%会投到别的公司里做股权投资或者天使投资，去帮助别人成长和成功。

# 国际化视野

当然，1/2到2/3的生意主要还是放在本土市场。但是，除了本土和周边国家市场，他们最大的兴趣国排名第一是美国，排名第二是中国。因为美国具有得天独厚的、完整的、成熟的商业环境；中国其实是因为具有发展机会，所以中国现在在全世界是真的受到了非常高的重视。

+   3、创业者的五种类型：

# 超级创业者

这些人平均拥有2500万美元以上的可投资资产，他们比别人更成功，拥有的财富更多。

特点就是他们一般都非常自信，71%的超级创业者认为自己2017年盈利会持续增加。另一个特点是财富增长以后，这些人往往更重视CSR企业社会责任，这也是现在很多大企业非常强调的一个重点。说明企业大了以后，要为企业更多的责任。

# 连续创业者

他们比别人创建了更多公司，创业者平均创建了3.5个公司，但是连续创业者平均参与或者创建了7.5个公司。而且财富的多少和连续创业的数目呈一定的正相关，也就是说，财富越多的人，这里连续创业者的比例越大。

连续创业者有一个有趣的特点是喜欢控制。62%的个人连续创业者，他们是独家拥有企业的，35%要成为一个企业的主要大股东之一。当然追求控制的同时，也喜欢接受挑战。因为自己做主意味着压力也得自己承受。所以连续创业者愿意控制，愿意主宰，也愿意接受挑战，他们愿意进入新兴领域、新市场（包括进入中国）。

这些连续创业者多是家族企业，他们更追求兴趣，追求社会地位高于追求财务回报。他们天生就是创业者，这其实是整个创业者里非常重要的一支力量。

包括之前讲到美国的硅谷式创新，美国现在大量的高校科研的转化有赖于这些连续创业者，因为他们非常有经验，他们能够把美国最先进的科技用几年时间推向市场，变成能够使社会获益的实际的产品，所以连续创业者是非常重要的一支力量。

中国相对来说连续创业者人数较少，要拓展业务也是在以前的成就上上去拓展，他可以使公司多元化，但他不会跳出来结结束一个公司再于另一个，这点我们要向国外学习，向美国学习。

# 新世纪创业者，即80后创业者

他们的特点就是因为年轻，所以他们希望能有价值感和差异性，希望能让别人看到自己、认识自己、认同自己。但是到30岁以后，他们开始更多地考虑工作和生活、家庭的平衡了，有一种很强的回归感。

慢慢在社会经济生活当中承担更大的任务了，就像毛主席说的“世界是我们亝的，也是你们的，但是归根结底是你们的”，世界正在变成80后创业者的，90后在他们后面也会慢慢成长起来。

# 女性创业者

其实女性创业者各个年龄都有，但是因为她们的身份、性别特征造就她们有很强的共性：一直面臨更大的挑战。

因为商业战场主要是以男性为主，所以女性创业者一直都在努力地证明自己，而且，她们很自豪，因为她作为创业者就 可以突破Glass Ceiling玻璃屋顶（女性在公司内部任职到一定高度，就无法再升职）。所以很多女性创业者喜欢这种突破 玻璃屋顶的感觉，这和她努力证明自己得到回报是一脉相承的。

# 成熟创业者

就是美国所称的婴儿潮一代，即二战之后五六十年代出生的人，这批55岁以上的人叫做成熟创业者。

特点是创业较晚，平均年龄37岁才开始创业，并且人数不多。他们往往更现实，对财务的追求反而是前面这几类里面更直接的，他们把财务指标放在第一位。

但是他们也懂得更加多样化，他们不会把全部精力放在同一件事情上，多样化经营、多样化理财，能够有更多的互动，变成社会协调和资源调动的好手。

所以，虽然创业者总的来说有很多的共性特征，但实际上他们有自己的亚群体，每个亚群体的特征都非常鲜明。

# 我对《全球创业者报告》的评价：
