# 眼科OCT为何如此重要？

OCT：光学相干断层扫描技术，Optical Coherence Tomography，简称OCT。

视网膜病变是导致失明的主要病症，常见的包括老年性黄斑变性，糖尿病视网膜病变等。随着人口老龄化加剧，糖尿病患者增多，手机电脑的过度使用等，越来越多的人被视网膜病变困扰；预计到2020年，全球老年性黄斑变性患者达1.96亿之多。

视网膜疾病诊疗过程跟其它疾病一样，包括检查、诊断和治疗三个环节；精确检查是有效诊断与治疗的前提。但视网膜结构的特殊性给疾病诊断带来了极大的挑战。

具体表现为：

+   视网膜位于眼球底部，非常脆弱。
视网膜结构精细，视网膜主要血管直径约在100微米左右，视网膜厚度仅200 - 300微米左右，这200 - 300微米厚的视网膜中还包含了多层更精细的层状组织。
视网膜中多种生物信息与疾病相关，如视网膜厚度、视网膜血管网络、血流、血氧饱和度等等。

视网膜的这些特点要求视网膜疾病的诊断需具有：

+   非侵入性，最好具有非接触性。
高的横向分辨率，能分辨视网膜血管；高的深度分辨率，能获取视网膜不同层结构的信息。
同时要能够获取与视网膜健康状态相关的多种生物信息。

![](bbox=[0.115, 1.58, 0.97, 2.02])

光学成像能很好地满足视网膜疾病诊断的以上要求。

+   其一，眼底光学成像是非接触式的，这样诊断可以提高患者的舒适度；
其二，光学成像具有微米级别的分辨率，可以清晰分辨视网膜血管等；
其三，眼底光学成像中隐含着视网膜的多种信息，如视网膜深度方向所包含的层状信息，视网膜血流等。

于是，如何开发先进的视网膜光学成像技术，从而准确稳定地获取关于视网膜健康状态的多种信息，成了各大商家与研究院努力攻克的难题。

# 视网膜光学成像技术的研究历程

# 1861年，眼底照相机问世。

# 1886年，第一张人类的眼底视网膜图片被眼底照相机拍摄。

眼底照相机能拍摄眼底视网膜的图片，清晰分辨视网膜上的血管，这为视网膜疾病的诊断提供了初步依据。然而，眼底照相机利用的是面照明、面探测的成像技术，导致成像的对比度不高，同时没有深度分辨率，不能获取视网膜内部的层状信息，这给视网膜疾病诊断带来了困难。

![](bbox=[0.115, 3.65, 0.97, 4.2])

为了提高视网膜成像的对比度与深度分辨率，眼底共聚焦扫描显微镜在1981年应运而生。

眼底共聚焦扫描显微镜使用点照明，点探测的成像技术，提高了视网膜图像的对比度，同时使视网膜成像的深度分辨率达到了几十个微米的级别。然而几十个微米的深度分辨率仍然不能清晰分辨视网膜内部的层状信息。

同时，由于不能准确测量视网膜内部的层状信息，导致眼底照相机与眼底共聚焦扫描显微镜不能够准确获取视网膜多种信息，如视网膜血流、血氧饱和度。这进一步阻碍了视网膜病变的精确检测。

直到1991年，OCT技术出现，视网膜疾病诊断迎来了全新的革命。

# OCT技术的优势

OCT成像技术基于弱相干光干涉学理论，采用宽带光源做照明。作为一种光学成像技术，OCT成像在以下几个方面都具有显著优势：

+   1. 横向分辨率
ey科OCT成像的横向分辨率为15 - 20微米左右，完全能获得视网膜血管的高清投影。
2. 深度分辨率
高的深度分辨率是OCT成像系统最大的优点。传统光学成像的深度分辨率只能做到几十个微米，无法诊断视网膜内部的病变。而OCT成像系统的深度分辨率能提供几个微米的深度分辨率，极大优化视网膜疾病诊断。
3. 成像深度
成像深度必须跟深度分辨率联系在一起才有意义，因为如果深度分辨率非常低，在成像深度内的很多信息其实都混在一起。目前OCT的成像深度能达到1毫米以上，这也是传统眼科成像所不能达到的。
4. 成像中包含的多种信息
OCT拥有高的深度分辨率，能更精确稳定地捕捉视网膜中的多种信息，如OCT能对视网膜血管网络结构进行无创成像，同时OCT在视网膜血流测量上也取得了很大的进展。这为以后视网膜疾病的精确早期治疗奠定了基础。这些都是传统眼科成像仪器所不具备的能力。
5. 激光安全
目前商用眼科OCT所使用的照明光为760微瓦，远远低于光对眼睛的损坏阈值。

# OCT的商业现状

1991年，美国麻省理工学院Fujimoto教授等人在 “Science” （科学杂志）上首先报道了OCT技术，在接下来的25年里，美国政府共投入5.9亿美金资助OCT的研究。

以内窥镜OCT为例，它已经赢得了市场，目前全球每年约生产10万例OCT内窥镜成像。

据估计，到2020年内窥镜总市场将达到330亿美金，等者认为OCT内窥镜会占到内窥镜总市场越来越多的份额。
