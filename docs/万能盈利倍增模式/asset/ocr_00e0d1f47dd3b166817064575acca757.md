然后我们做一下价值塑造。

所以：我们要明白一个道理，在一些领域，并不是说，价格足够低，他就很多人买。

千万不要不敢定高价。

![](bbox=[0.12, 0.2, 0.69, 0.41])

我给你举个例子：人参在我们中国人脑袋里，是一个价格高昂的产品。但是其实人参的价格一点也不高，在原产地，就跟萝卜价格一样。

但是，如果你卖 20 块钱一斤，很多人会认为怎么样？

+   1, 肯定是假的。
2, 肯定不好。  对不对。 
3, 这东西，你看都不会看。  更不会愿意买回家。
因为人参价格 20 元一斤，他是违背常理的，人们就觉得越好的东西，价格越高才对。

但是后来我们把价格一调整：卖 2000 一支。

然后再配上：人参中的精华，精品中的精品。仅出售 2000 只。

结果很多人就愿意买。买回家，他还炫耀的不行，觉得这东西太好了。是不是非常有意思。

去年有一个老板是做 GPS 定位装置的。就是给汽车装 GPS 定位系统。

这个老板的成本价是 1000 块钱，他们卖 1500 元。结果他们的业务员根本卖不出去几个。
