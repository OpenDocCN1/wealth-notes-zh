# 【拆解同行 2.0 模板】

我们继续分享拆解同行业项目和思维的第二种模板 2.0.

1.0 是比较简单的思路。

如果要去完全颠覆一个行业，是很难的，自主创新也很难，因为没有人做过，我们也不知道结果怎么样，那么做失败的成本就很高。

所以我们还是利用拆解同行的思维，而不是一开始，就开始搞什么创新，独具一格。这才是最靠谱，最节省成本的办法。

这样犯错误的概率就没有那么大。

+   1, 先市调。 找到这些同行 。
2, 分析同行业产品系统。
3, 分析流量推广系统。
4, 分析成交方案和系统。
5, 看有没有设计什么裂变的方案。
6, 杜杆系统 他们都采用了哪些捷径或资源。
7, 模式 商业模式是怎么更快发展，盈利模式就是怎么搞到钱的。

这个模式我们要重点提一下：我们一定要用纸+笔 给画出来，一个构思图。

千万别用脑袋去想，去感觉。

因为我发现：如果我们凭借直觉造出来的感觉，记忆力很弱，而且非常模糊，就是说，我们只是知道一个模糊大概的商业模式，其实很多细节，我们并不知道怎么做。

但是当我们用纸笔，去写出来，画出来，设计出来的时候，你就能学到，感知到，这些同行的商业模式的思路。这点能明白吗？ 各位。
