就是直接把客户带入他最想要的效果和梦想场景中。把它最想要的效果，提前给他。

比如：“我读了孔老师的书籍，业绩从 100 万，赚了 500 万，足足翻了 5 倍，真的是太感谢老孔了”

是不是所有老板，都想这样做到这种结果。

那么我们直接把它带入已经成交的场景中，就很容易让客户买单。

比如：“服装店就是让你去试穿，你本来不打算买衣服的，试着试着感觉就来了。”因为你感觉还是新衣服好看。所以你不自觉就被成交。

# 3，就是我们的 “风险导入机制”

人购买某样东西，最怕的就是风险。

通常采用以下方式:【风险保障机制，本质 “消除顾客的不安”。】

# 0.基本承诺 （承诺结果，承诺保证，给对方一个确定的概念，让其感觉靠谱）

（1），退款保证承诺。 担心后悔，买到假货。

这样，支付风险就消除了。实际情况就是就算你提供了退款保证，真正因为不满而退款的不到总数的百分之一。
