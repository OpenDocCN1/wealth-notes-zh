一个公司赚钱不赚钱，首先，就看这个公司现金流怎么样。如果说：我们做一个生意，压了很多钱，库存占用了很多流动资金。回账那么就有个周期。如果过长。

我们企业：危机就会越大。

因为一不小心，可能我们就容易资金链断裂。

举一个例子：在房地产行业，很多人都认为这个行业很赚钱，听说这个行业赚钱，结果有无数千万富翁和亿万富翁，就感觉这里面有钱可以赚。

他们就去做什么？

开发所谓的房地产，因为资金量不是很大，所以他们只能选择在农村搞房地产。

刚开始做的时候信心满满。

然而真正开发，不断投入资金的过程中，他就发现，开发房地产远远没有那么简单。

+   1, 拿地需要资金。
2, 盖楼需要资金。
3, 拿开发牌照和许可需要资金。
4, 疏通关系和送礼，都需要钱。
5, 然而他们也想到了预售，结果没有卖出去几套。
6, 结果他就发现，开发了那么多楼，没想到资金量那么大。
