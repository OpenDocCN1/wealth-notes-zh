# 3，可持续（多次，持久，买单）

产品有 2 种频率：1，高频 2，低频 。
一般情况下，一台洗衣机，好几年是不会坏掉的。 我们要想真正可持续赚钱，最好做高频的产品。 这是保证是否重复消费的保证。 因为我们开发新客户的成本极高。 而我们留住第一次消费客户的成本就很低。
