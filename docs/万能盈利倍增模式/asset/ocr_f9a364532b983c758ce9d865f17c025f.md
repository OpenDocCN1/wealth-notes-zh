# 2，提高精准客户的数量

如果你是做奶粉的，准客户就是宝妈，精准度很高，转化率就会很高，但是你搞一些其他人，转化就太难了。

很多人用软件，自己胡乱加了 1000 人，结果没有别人加我们的精准客户群，主动吸引来的 10 个成交率更高。 而且更容易转化。

所以，我们要想提高转化率，不要老想着所有人都是我们的客户群，那是不对的。 我们应该追求，精准客户群。 这种人越多，我们转化的越多。
