# 5，升职不一定要加薪。

头衔不会产生任何成本，却有很好的激励效果。

在某些公司，我们为了激励员工，不断的升职，就可以给他们一些头衔，让他们有荣耀感。但是工资，可以不用加，为了降低成本。

就是我们虽然不给他开那么多工资，但是你可以给更高的职务，让他们得到更好的成长机会。

而且，就算未来他们不在这家公司做了，想跳槽其他公司，也会因为有高职务经验，可以得到更多薪酬。

什么副总裁，什么董事会理事，总经理，总裁，副董事长都是可以的，不想给他们加薪，又想让他们更努力工作，最好就是给他们一个高一点的头衔就行了。

头衔并不值钱，有什么舍不得的，又不会产生任何实际成本，但是对员工却很有激励效果。

在日常管理中，也可以这样做。比如有一家公司就这么做过：他们分为好几个部门。

+   1， 后勤部
2， 销售部
3， 生产部
4 运营部。 ....

但是他们员工因为资历比较深，又不能给他们开更高工资，但是又要满足他们的虚荣心，给予激励效果，所以就给他们提升了职务。

比如：他们后勤部，就有，后勤总经理，后勤部长，后勤首长，后勤总裁

虽然工资没有涨，但是总裁这名字好听，所以同样有很好的作用。
