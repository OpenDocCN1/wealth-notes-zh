记住：风险是好处的 5 倍之多。（人性最害怕风险，人性任何时候永远是趋利避害的动物）

信任疑虑抗拒通常为 3 点：

+   1, “买了是不是就上当受骗？”（人性都有被骗的心理，或曾经被骗过）
2, "不会有损失吧？"（人性都喜欢没有风险的东西。一旦有风险，人性就会抗拒）
3, “万一不好用咋办？”（人性总是会自问自答，都在找更多理由说服自己，我们营销就是引导他说服自己的过程。）

因为不安所以就可能放弃购买。

我们要做的是消除不安，给顾客一个确定的感觉，让顾客痛痛快快的买回家。

就像很多人说的：我知道这个项目很好，感觉很赚钱，很多朋友也做了，但是我还是怕亏钱。因为我曾经被骗过很多回。 所以很多人就不敢行动了。 恐惧了，不安了。 这就是为什么，好处足够多，信任也足够，为何对方还迟迟不动的本质原因了。

为了建立足够信任消除风险：

# 1，卧龙同理心效应。

就是你讲一些故事：有一些人，曾经也是被骗了，然后最后跌跌撞撞，还是愿意选择相信我们，他以为自己上当受骗了。 却发现，自己没有被骗，这样一种同理心。

你讲了这个故事之后，其实大多数人眼睛里，都怎么樣了。就是跟自己经历过去差不太多，突然他也用了这个产品，得到了很好的结果。 那么是不是会建立很好的信任。
