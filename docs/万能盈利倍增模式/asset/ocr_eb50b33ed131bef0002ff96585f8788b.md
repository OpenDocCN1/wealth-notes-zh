# 增加企业营业额

企业要盈利从这几个点入手：

+   1, 增加营业额
2, 增加利润率。
3, 降低成本。

| 营业额 ↓ | 利润 ↓ | 亏本 |
| 营业额 ↓ | 利润 ↑ | 利润是短暂的 |
| 营业额 ↑ | 利润 ↓ | 利润是不合理的 |
| 营业额 ↑ | 利润 ↑ | 利润是持续、恒久的 |

【高营业额不等于高利润】

比如：一家服装店，本来，他们的衣服每天能销售额达到 8000 块钱。利润率有 40%。一天能赚 3200 元。

但是因为同行业的竞争，巧合遇上情人节，来逛街的人比较多。
那么我们门店，就搞了一个活动，全场 8 折特惠。

结果营业额就提升了到了 1.2 万元 因为降价折扣，所以利润率只有 25%，然后今天我们一算只赚了 3000 块钱。
还不如不打折赚的更多。
表面上是营业额增长了，但是利润却没有增长

所以，降价，打折，促销并不一定是好招数。
如果我们公司出现了，利润下降，营业额（销售额）下降，那么我们就应该意识到企业存在的问题。

连续 2-3 个月，我们就必须要有一种危机感。
