# 【20 年总结的一套：万能的盈利框架设计方案】

![](bbox=[0.16, 0.14, 0.87, 0.33])

如果要学布局，我必须我们布局的校训：养身，立己，取势，明道，优术，合众，践行，与变化。

这句校训，看似简单，有不简单，但凡能做到的，可以成为布局的基础学员了。 我们每个人：作为布局人的一份子，必须，把这句话记在心里，而且传递给儿子，孙子，以及后续的后代子孙们。

这也是我为什么要写书，做一点分享的本质原因了。 了解到我们的校训，那么我们还要了解，我们的【布局导图】

![](bbox=[0.16, 0.53, 0.87, 0.82])

从上到下：战略——资本——管理——系统化运营——资源整合——布局系统。 从左到右：产品链——流量链——成交链——裂变链——杠杆链。
