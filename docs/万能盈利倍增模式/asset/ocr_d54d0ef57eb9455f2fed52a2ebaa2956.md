# 【战略轨道小模板】

[赚看得见的钱：利润仅仅占 10%]

+   1, 消费市场：产品买卖，方案。
2, 技术市场：卖设备和技术专利授权。
3, 跨界市场：客户需求多元化需要。

[赚看不见的钱：90%利润被白白浪费了]

+   4, 中介市场：做二道贩子，可进可退。 轻资产，收益大。（永远只做老二，谁厉害抄谁）
5, 创业市场：卖发财机会。
6, 资源市场：融合市场资源。
7, 平台市场：赚过路费，交易费。
8, 产业市场：中下游产业开发。

+   9, 资本市场：钱赚钱，赚金融，现金流，股权质押，卖未来等。 
10, 内容市场：卖经验，分享，咨询。

+   11, 培训市场：卖教育认知，圈子价值。

+   12, 圈子市场：协会，组织，机构。 
13, 媒体市场：直播，大赛，比赛，竞赛，行业媒体库，行业形态。 
14, 生态市场：整合国内外资源，建立行业生态，输入输出做生态链价值输出。

+   15, 眼球市场：注意力经济，炒作游戏，扩大巨大影响力的红人模式。 
比如：巴菲特慈善午餐 
16, 神秘市场：未知市场，长生不老，宗教，卖希望，梦幻王国，虚拟市场，内部银行，货币，卖觉醒，深 不可测，欲探究竟。

因为一个行业中，有很多经营轨道，而我们理应找到一个最轻松，最简单，高效，最能赚钱的经营轨道。
