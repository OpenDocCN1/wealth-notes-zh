# 【产品的选择，决定了利润的层次】

什么才是最“理想的产品”？

重新认识产品后，我们说一下什么是理想产品？

选择产品决定我们的利润方向。盈利方向。

有些行业，即便你拼了老命，智慧在高，也很难做出很大出息。有些产品，再努力做，也很难有很好的回报。

是选择暴力产品，还是微利产品？

虽然每个行业都一定有有它自己的机遇和机会。

举个例子：
你选择定位了要做老师：基本上你这辈子是很難赚到大钱的。
即便你足够努力，把学生都教育成为了清华大学的学生，那么也是很难赚到钱的。
当然了，也不是没有机会。

+   1, 你要么去做线上课程，服务全中国的学生。\n2, 要么开设直播，做网红老师。 也是可以赚钱的。\n3, 要么转行，跨界去做生意。 开学校。

我们来看：你做老师，那是卖时间。 出售时间给学校。

盈利就是:学校发给我们工资。

而你做线上课程，那是，卖课程，靠学生付费赚钱。\n而你自己开学校，这是做培训行业赚钱。\n同样一个人，不同的盈利模式和轨道，那么结果就会千差万别。

所以我们要找到一种最佳的产品模式：到底我们要卖什么。

这非常关键。
