# 认购方式

1，费用明细：牛苗成本5000元/头，10个月养殖成本4500元/头，管理费500元/头，共计一万元/头

2，预计投资回报：15000-18000（1000斤-1200斤，按照目前市场价格15元/斤）

3，养殖周期：10个月整（确保养到1000斤以上）

4.回报计算方式：每个月进场一批，最多100头，同一批次同时卖出后均价。

特别说明：公司不参与牛增值利润分配，每头牛利润捐赠1000元，为修建当地希望小学，其余全额回报给投资营。
