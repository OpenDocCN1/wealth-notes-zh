# 【怎么挖掘优秀同行】

1，怎么找到这些优秀的同行。

一句话：只要有人的地方，有流量的地方，都值得我们去市调，挖掘同行。哪怕没有同行，我们也可以市调类别相差不大的，跨界行业。

这样我们也可以复制过来，为我所用。

最简单的方式：

+   1，百度搜
记住：百度搜，不是让你简单的搜一下，而是要找出那些优秀的同行，都是怎么做的。
2，向同行业的人，让他带你如圈子。 在里面不断的问，想尽一切办法，肯定有人愿意帮你。 
3，找一个引路人，去认识行业顶尖高手 让他为我们解惑。 谁做的好，那些做的顶尖，或者其他。 
4，加入此类培训圈子，或培训机构，以及这类精英人群聚集的地方。 因为这里面信息量很大，值得我们去深挖。 
5，所有一切产品相关联的渠道。 快递，快手，抖音，企业管理，代记账，等以及其他。 
6，国内外新闻 行业新闻，动态。 
7，行业峰会，国家行业峰会 
8，其他

不管是线上还是线下，我们能尽可能市调更多同行或者跨界领域同类，都可以给我们很好的思路和路径。

+   9，还有一个最重要的就是：从顾客群入手。 从顾客入手，不断深挖。 
10，做间谍，色诱，其他等。

只要能用的方法，我们都可以尝试去尽可能找到更多同行，同类优秀的案例，做参考。
