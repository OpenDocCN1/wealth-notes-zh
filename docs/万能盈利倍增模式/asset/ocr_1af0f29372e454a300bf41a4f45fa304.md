# 【拆解同行 1.0 模板】

最简单的拆解同行的模式模板 1.0:

+   1, 产品系统 产品是啥。\n2, 流量系统 客户怎么来的。\n怎么推广的。\n3, 成交系统 盈利模式，怎么盈利的，怎么赚钱，收钱的。\n4, 裂变 客户是怎么转介绍的。\n5, 杜杆 有没有其他资源，条件，或者工具什么的。

这是我们拆解同行，1.0最基础的版本。 也是我们最容易看到，最容易复制的。

在我们拆解同行的过程中，我们要学会一个一个去拆，拆清楚了，搞明白了，再去搞下一个个。

而且那，我们不要抄普通的，但是我们可以看普通的缺点，我们要抄就抄优秀的。

不懂就照抄，抄裳他们。

这些模式，推广，引流，成交，裂变，因为这些都是他们当下行之有效的最好方法了。

要是有更好方法，他们肯定也会做，那么我们也跟他们一起做。就行了。

前期，先不要搞原创，先抄就完事了。

抄第一名，我们就可能成为中高手，抄小白，你最后连小白都不如。
