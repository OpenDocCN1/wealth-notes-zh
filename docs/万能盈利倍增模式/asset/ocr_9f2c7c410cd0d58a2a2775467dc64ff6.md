# 我们怎么赚到钱。

想要赚到钱，我们必须研究一个东西：就是盈利模式。

+   简单讲：
1, 这个项目能不能赚到钱，能赚多少钱。
2, 他怎么赚钱的，从哪里赚钱？
3, 该怎么做才能赚到更多钱？
4, 他卖的都有什么产品，卖给谁？ 怎么卖？ 怎样做才能卖更多？

盈利模式是核心中的核心。

不管你做什么，我们都必须要搞清楚，是怎么赚钱的。但是我发现很多人，天天做项目，都把盈利模式给忽略掉了。

他都不知道天天在忙什么，结果搞的一塌糊涂。

![](bbox=[0.12, 0.42, 0.77, 0.72])

比如：传统加油站的盈利模式 就是卖汽油，柴油赚钱。

这种盈利模式，就比较单一。

老板的资源配置，时间，精力，和思维，都应该专注于盈利模式的开发和利润的挖掘，延伸，嫁接。

就是要跟钱距离最近的地方。

企业亏钱，不赚钱，或者不能保持高速增长赚钱，那一定是老板的盈利模式出了问题。
