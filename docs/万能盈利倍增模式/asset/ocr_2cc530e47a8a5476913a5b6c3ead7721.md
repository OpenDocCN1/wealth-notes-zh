# 【拆解同行 3.0 模板】

如果我们继续进一步拆解同行，那么我们就可以用到这个。

![](bbox=[0.16, 0.166, 0.88, 0.447])

简称为：破解同行模板 3.0 。

+   1, 产品策划系统 同行业产品是怎么策划，包装，定位，品牌怎么设计。
2, 引流拓客系统。
他们怎么推广，付费，有哪些，免费又有那些，从哪里，都有那些方法，那些是有效的，哪些效果不好，哪些是他们在用的，哪些是他们没有挖掘的。
3, 培育成交系统。

他们把客户引流进来，肯定要有自己成交的方法，成交的话术，成交理由，成交场景，成交方式。

怎么贡献价值，怎么锁住客户，怎么让客户复购，这些都是成交一部分。
怎么满足第一次成交。

注意：千万别把这些搞的多么神秘，你所有遇到的商业，你买过的任何东西，都是这样被成交过来的。

我觉得越简单的东西，越好，越复杂的东西，越没有效果。

比如：你为什么要报名 198 布局速成班。
你为什么要报名 1680 的实操班。
