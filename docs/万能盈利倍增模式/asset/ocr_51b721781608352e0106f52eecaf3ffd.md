# 【三风水：】

风水：

+   1， 方向要选对（战略）

+   2，做对的事情

+   3，找到一个适合自己的平台。

+   4，风水学：灵魂，仪式感，崇高敬畏感，地理的摆弄顺应自然，不可逆势而为。

# 【四积阴功：】1，父母辈，爷子辈，等长辈积累的人脉圈子 2，祖上积德（曾经无偿帮助过很多人，到你这一辈就积累了祖上的德行，得到这些人的协助）

> 【所有的事情都是与人链接，这就是最大的阴功了】

# 【五读书】：1，学习（不进则退） 2，参加培训（缩短碰撞的经验，多拜师傅，老师） 3，随时随地获取新的智慧可以扭转命和运，掌握主动。

# 【六名：】1，找到属于自己的附属名，别名，艺名，笔名，英文名，给自己建立一种信仰，持续加持信念。（要知道：一个叫二狗的人，从生下来这一刻，这辈子就根本不会有多大成就！ 所以朱重八早早改名朱元璋。用名字，无形造就了一个皇帝）

# 【七相：面相】

+   1，天生的面孔（能给人不一样的感觉，或易于接触，或看似坏蛋） 2，后天自我改造的形象（整容，健身，美体,衣服，搭配，发型，装饰....）：一个人第一印象，建立第一种认知。（ 所以你的形象价值百万，有一定必要。） 3，相学，易经...

# 【八敬神：】1，必须找到一个信仰（信神，信佛，信命，信道，信科学，信自己，信布局，信贵人，一个有信仰的人，才能走的更远） 2，仪式感，崇敬感
