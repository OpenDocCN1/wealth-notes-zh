他是他想着赶快把资金流动起来，可是房子卖不出去。所以很多农村房地产，就给怎么样？还没盖完，就崩盘了。

就是说，没有后续资金了，找银行贷款，银行也不愿意贷款，找朋友借，又借不到那么多钱。我们就发现农村房地产之所以幡不起来，最重要的是他过高估计了自己的能力，以及农村人的购买力。回款基本上可以说是遥遥无期。

# 10，客户忠诚度高。

说起客户忠诚度，其实哪里有什么忠诚不忠诚。只不过你对客户有价值，客户才对你忠诚。就好比说：过去我经常喝农夫山泉水。但是后来，我就喝：凉白开。

![](bbox=[0.165, 0.328, 0.805, 0.767])

因为我发现他比农夫山泉更止渴，口感更好一些。自从我喝了这凉白开以后，我们的员工和家人，他们也都喜欢了这凉白开。

就是说，我去买谁，先问：有没有凉白开。其他水我一概不合，先喝这个牌子的。换句话讲：我可能成为了他的铁粉和粉丝。
