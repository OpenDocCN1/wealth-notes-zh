
# 【20 种最常见的盈利模式轨道】

主要常用的盈利方式：

+   1, 产品盈利。 靠卖产品赚钱。
2, 技术盈利：靠卖技术赚钱。
3, 服务盈利：多余的服务，收取部分服务费。

![](img/e4c54d03d15250bdb3a46029eaab2380_85_0.png)

我媳妇去香港某家餐厅吃饭，他们吃饭之间，针对每个座位配了一个服务员，主动给他们夹菜，煮熟，讲解菜品等。
这里面就收取了 10%的服务费。

+   4, 加盟盈利：靠卖加盟，专加盟费盈利。
5, 卖区域盈利：一个区域代理商，加盟商，收取一定费用。
6, 授权盈利：靠品牌授权盈利，授权专利盈利。
7, 设备盈利：卖设备，赚钱。
8, 工具盈利：靠卖相关产业链，工具。 比如：超市收银系统，门店 CRM 管理系统。
9, 品牌盈利：让消费者更加信任的付更多钱。
10, 模式盈利：挖掘看不见的利润。 比如：pos 机器免费送，靠分润赚钱。
11, 圈子盈利：卖付费会员。

12，内容盈利：靠书籍，写文章，写连载赚钱。
13，生态盈利：靠圈子之间的资源整合。 赚钱。

14，系统盈利：靠整合资源，让别人进入系统，来赚钱。
比如：我们加油站，可以让别人来投资，别人投资进来了，那么我就不用投资那么多钱，但是我可以掌握几千万的流动资金。

我一年什么也不敢，收利息一天就是 1000 块钱以上，一年至少也有 30 万的利息收入。

15，垄断盈利。 自己有核心的资源和技术，然后对外输出。
就可以形成垄断方式的盈利。

比如：你有一个治疗癌症的配方，或者能治疗阳痿的配方，那么别人搞不了，搞不来，只能从我们这里拿药。 那么我们就有了价格的控制权和发言权，以及流通权。

16，平台盈利：收取交易费和管理费。 我们负责坐庄。

比如：银河证券，打造一个证券的交易平台，然后让别人来这里面建议，那么他就可以赚钱。 还有时时彩，以及赌博，交易平台等。 都是这样的一个思路。

17，增值溢价盈利：很多东西，可能他是有溢价能力的。

比如：在汽油很便宜的时候，我们就进了 1000 吨存到油库里面，过了几个月，油价上涨，然后我们卖出，这一下就赚了 80 多万。

18，租金盈利：靠收使用费赚钱。

19，金融盈利：靠沉淀资金，以及沉淀资金的时间差，或者使用一些金融手段。

比如：银行现在都实行 ETC 免费送了。
为什么免费送，因为你只要过车，这里里面必须要充值一些钱。
那么每个人充值 200 多，中国 1 亿人用了该行的 ETC,每年就存储了 200 多亿现金流。

所以，他们就可以拿来去放贷，或者做投资等。

20，国家盈利：税收，增值税，消费税各种税务。

当然了，如果我们企业做到一定程度，我们也可以跟国家一样，针对别人进行收税。
比如：如果你做了一个 p2p 平台，或者说你做了一个虚拟币平台，那么很多人就在这上面交易，那么我们就可以收取一些税。

什么交易税，管理税，溢价税。

![](img/e4c54d03d15250bdb3a46029eaab2380_87_0.png)

![](img/e4c54d03d15250bdb3a46029eaab2380_87_1.png)

比如: 在我们国家沃尔玛的高楼层, 基本上都会有很多美食广场。 或者一些大型商场里面, 在楼层高一些的地方, 都会做一个美食大厅。 而这里就是一个小的国家和平台。

那么我们就可以针对商家收取一些费用:
卫生费, 服务费, 管理费, 和营业提成。

其实跟我们国家的卫生费, 企业税, 企业所得税, 企业增值税等都是一样的。 而对于这种盈利适合一种大的平台, 无论线上和线下都可以。

在我们做盈利模式设计的时候, 我们一定要多考虑, 赚这些看不见的钱。 这些才是真正赚

大钱的地方，因为一个企业 90% 的钱，都是在后端，在看不见的钱的地方。

比如：银行业是世界上几乎是仅次于烟草，最最赚钱的行业。

那么他赚什么钱？

![](img/e4c54d03d15250bdb3a46029eaab2380_88_0.png)

+   1, 企业贷款 赚钱。
2, 资金服务费
3, 房屋贷款 车辆贷款 以及其他电动车，摩托车，以及其他所有物品的分期贷款等。
就说房屋贷款，车辆贷款这 2 项，几乎 10 个人里面，至少有一个每月都要还贷款。
而银行赚什么，就是赚这种持续不断的贷款利息。

+   4, pos 机分润的钱。
5, 信用卡业务。
6, 基金和保险理财。

+   7, 金融机具的销售
8, 金融智能终端业务消费获利
9, 对冲业务
10, 票据业务

基本上为这 10 大类，我们就会发现，银行的盈利模式，是比较多元化的。 即便那个业务不赚钱，并不会影响整体的盈利。

所以在我们企业中，我们也要设计，从单一盈利模式，转移到多元化，组合的系统盈利模式。

# 【重新定义产品】

过去很多年，我们很多企业，都是靠单一的产品和服务进行盈利。

![](img/e4c54d03d15250bdb3a46029eaab2380_89_0.png)

理发店：只做理发服务，一次 10-30 块钱。

对于小老板，他们的盈利模式：一直以来都是靠产品盈利的。

但是今天我希望大家大家要改变过去的认知，重新对产品做一个新的定义。

什么是产品？

产品是你用来抵达用户，成交客户，帮助我们赚钱的工具。

不管你干什么，不管是产品还是服务，他都可以称之为一种产品。

就有人说了：

![](img/e4c54d03d15250bdb3a46029eaab2380_89_1.png)

我是帮助别人找风投的。

然后靠收中介费赚钱。

还有人说，我是专门给一些人疏通关系的，收红包或者钱。

那么这其实也是一种产品。

产品就是：只要能帮我们赚钱，他就是产品。

过去很多年，我们对产品的理解，都是过于把自己给限制死了。

很多人今天的思想里面，仍然只是把能看得见，摸得着的产品，才叫产品。看不见摸不着的产品，他们认为那不是产品。

这是很错误的。

![](img/e4c54d03d15250bdb3a46029eaab2380_90_0.png)

比如：海底捞的火锅比同行业的价格都高一些，就是因为他们除了卖给你产品（火锅），还卖给你了超赞的服务（也是一种产品）。 如果说，他们跟同行业价格一样，那么就等于服务产品免费了给你了。

# 什么是产品？

记住：一切可以让你和客户发生关系，可以让你成交客户，可以让你赚到钱的，都是产品。

什么虚拟产品，服务产品，实体产品，能帮助我们赚钱，他都是产品的一种存在形式。

![](img/e4c54d03d15250bdb3a46029eaab2380_90_1.png)

很多人说：我是在工地上打工的。 这个也算产品吗。

你打工，那你就是出售你的时间，这段时间是不是有别人支配，那么这是卖时间。只要你有钱，你不想做的任何事情，都可以买别人的时间，帮我们来做。

比如：照顾孩子，做饭，洗澡，搓背，扫地等。

所以表面上说，你是给别人打工的，其实你就是出售自己的时间罢了。就那么简单。

从这个定义出发，我们就可以不断挖掘可以赚钱的产品。

+   1，卖产品盈利
2，卖服务盈利。
3，卖技术盈利。
4，卖代理盈利。
5，卖加盟盈利。
6，卖区域盈利。
7，卖圈子盈利：付费会员。
8，卖资源盈利。
9，卖信息盈利。
10，卖经验盈利。
11，卖原材料盈利

简单讲，你有某个行业的经验，很多新进入的人，他也想学，那么你就可以搞培训，赚钱。其实，就是把你这一套知识，形成体系，卖给了别人。

12，卖时间。

13，卖数据。
比如：老王手里面有很多客户群，他不想干了，想把客户介绍给别人。其实也是变现的一种方式。

14，品牌授权盈利。

15，卖使用时间：出租。
.....

还是那句话：不管你卖什么，他能为我们盈利，就是我们产品的一种存在形式。

# 吴记黑鸭。东哥 ♂男

这是山东即墨的一个老弟，做的周黑鸭，2016 年，那时候他只是开一个小店。

![](img/e4c54d03d15250bdb3a46029eaab2380_93_0.png)

生意也不是很好，1年最多能赚20万，而且特别辛苦。

后来他就去山东即墨服装批发市场，里面租了一个摊位，因为那里面人很多，所以生意就很好。但是这一年来，辛辛苦最多不到30万，而且还要家里面的好几个人帮忙。

就是说这30万，要4个家人，还有2个员工一起来分，因为他招募了2个老太给帮忙。

这时候就是开一个门店，摊位，一年最多赚30万到顶。

就到了天花板，哪怕你用什么营销策略，充值，什么的，我不会有太大效果，因为客户流量就那么大。

所以：你不做战略调整，还是研究怎么引流，怎么拓客，怎么促销，充值啊，积分等，他根本一点效果也没用。

后来有幸遇到一个学员，这个学员就让他拍快手，他也不知道能不能赚钱，但是坚持天天拍摄，一个，2个，结果一下几百，到几千粉丝，慢慢的就涨了起来。

涨了起来，他干啥？ 这时候，就可以卖周黑鸭技术培训：学费5000元，包住不包吃。

结果这一年就赚了90多万。 只是赚培训费。

这时候，他们就增加了一条盈利模式，过去式单一的盈利模式。

现在是：卖产品+卖技术培训

2种盈利模式，就赚到了120多万。

而且那，员工也省了，因为来学的学员，都帮他们干活。 后来他就请我给他指点一二。

我就给他加了一些内容：就是我们的周黑鸭内部配料，什么辣椒，还有各种周黑鸭酱料包，添加剂等。

你可以不用交给他们，让他们从我们这里拿货，这样我们就可以源源不断的赚原材料的钱。

后来他听了我的建议：开设了淘宝店，卖辣椒，花椒，麻椒，以及周黑鸭的相关配料。让学员下单，然后给他发过去。这时候的盈利模式又多了一项。

卖产品（赚 30 万）+卖技术培训（赚 90 万）+原材料（每年多赚 5-10 万）；

这种就是多元化的盈利模式，就比较有竞争力了，就算其他人复制，也不见得一下子能复制的了。就算哪天，我们卖产品不赚钱了，我们这个生意影响也不会太大。

所以：如果我们生意要想做的足够有竞争力，我们必须挖掘出多元化的盈利模式

单一盈利模式《组合盈利模式《多元化盈利模式《系统盈利模式。

很多人就说了，老孔，你讲的不对，你看可口可乐，王老吉，农夫山泉，爱尔眼科，老干妈，他们的盈利模式，不都是单一的，而且做的超级好吗？

![](img/e4c54d03d15250bdb3a46029eaab2380_94_0.png)

我们要想把单一化的盈利模式做的好：那么必须要具备垄断的模式。

比如：老干妈 7 块钱一瓶。

对于刚起步的公司，他们很难复制。因为他们的没有那么多的优势。
他们已经有了先发优势，有最基本的配方，有比较好的口碑，以及比较低的价格。
如果我们要做辣酱，按照这个价格走，低了，赔钱，高了就卖不出去。

![](img/e4c54d03d15250bdb3a46029eaab2380_95_0.png)

比如：你家祛疤，祛疤的重要材料一绝，普通人就无法复制，多数人就没有这个核心资源。

如果市场足够大，那么我们就可以垄断全国 。

但是，如果我们做任何生意，没有这样的商业壁垒，那么我们必须从单一盈利模式到多元盈利模式，系统盈利进行升级。

![](img/e4c54d03d15250bdb3a46029eaab2380_95_1.png)

你卖煎饼果子，你生意很好，结果没过多久，这旁边就多了 4-5 家，那么你就直接玩完了。没利润了。 因为你的产品盈利模式太单一了。

但是如果你煎饼果子一绝，有独特的配方，那么可复制的技术壁垒就有了。 你家的煎饼果子，又酥又脆，又超级好吃，别人根本搞不了。

即便这附近开十家煎饼果子，刚开始可能会受到一些影响，但是最后你会发现，只有你一个人生意最好。

这就是有了技术壁垒。

那么就可以很好的生存下来。

但是在现实生活中，我们就发现，其实 99% 的行业和人，基本上都差不太多，可复制性太强了。

那么我们为了更好，更多的盈利：必须采取组合盈利，多元化盈利，系统的盈利方式。

让别人，都不知道我们怎么赚钱的。就是说，我们赚的是：别人看不到的钱。

前端 10%，的钱我们每个人都能看到，而且几乎每个人都能赚，但是后端 90% 的钱，很多人根本看不到，那么我们就可以躺着赚。

# 8，我们还可以做什么？

我们理发店，是不是用吹风机，剪刀，梳子，镜子，座椅，包括装修，以及其他等。

那么这个时候，我们理发店的吹风机，也是可以卖的，梳子也是卖的，座椅也可以买。

![](img/e4c54d03d15250bdb3a46029eaab2380_100_0.png)

很多物品，都是体验馆。既满足了使用需求，又满足了体验需求。

过去几年，很多门店都搞体验馆，其实我一直认为，搞体验馆，不如直接搞一个真实的体验馆。这样才是真正可以盈利的地方。

然而很多企业，非要搞线下体验店，结果大多数都失败了。

但是我们把体验馆搬到了正在用场景中，那么这件事，就完美了。

![](img/e4c54d03d15250bdb3a46029eaab2380_100_1.png)

我们过去的住宿，都是采取的靠收住宿的方式赚钱。

而我们完全可以靠整体装修赚钱，靠床垫，灯具，电视以及其他赚钱。

你看上我们房间里面的任何东西，你都可以直接买下，你想把自己家装修成这样风格的，我们直接给你装修。

所以：这种盈利模式的挖掘，就做的很好。

我们做一个假设：如果我们是做家具的，全国住宿宾馆，都是我们的真实体验店，那比你打多少广告都好用。

客户想要下单，直接扫码小程序付款就可以完成。然后直接送到家。

有一个厂家，就是这么做的，他们的床垫全部放到宾馆，结果卖床垫卖了 100 多万件。

在我们挖掘盈利模式的时候，我们不用说，非要每一个都做。

但是我们可以找到 1-2 个最佳的，能长久做下去，帮助我们赚钱的，就够了。因为企业的资源和个人的条件，他都是有限的。

如果我们无法把一些事，聚焦到 1-2 个点，那么我们是很难做成功的。千万别想着，我全部都做了，这是非常不现实的事情。

我们现在知道了盈利模式和产品是没有界限的。

# 【产品的选择，决定了利润的层次】

什么才是最“理想的产品”？

重新认识产品后，我们说一下什么是理想产品？

选择产品决定我们的利润方向。盈利方向。

有些行业，即便你拼了老命，智慧在高，也很难做出很大出息。有些产品，再努力做，也很难有很好的回报。

是选择暴力产品，还是微利产品？

虽然每个行业都一定有有它自己的机遇和机会。

举个例子：
你选择定位了要做老师：基本上你这辈子是很難赚到大钱的。
即便你足够努力，把学生都教育成为了清华大学的学生，那么也是很难赚到钱的。
当然了，也不是没有机会。

+   1, 你要么去做线上课程，服务全中国的学生。
2, 要么开设直播，做网红老师。 也是可以赚钱的。
3, 要么转行，跨界去做生意。 开学校。

我们来看：你做老师，那是卖时间。 出售时间给学校。

盈利就是:学校发给我们工资。

而你做线上课程，那是，卖课程，靠学生付费赚钱。
而你自己开学校，这是做培训行业赚钱。
同样一个人，不同的盈利模式和轨道，那么结果就会千差万别。

所以我们要找到一种最佳的产品模式：到底我们要卖什么。

这非常关键。
