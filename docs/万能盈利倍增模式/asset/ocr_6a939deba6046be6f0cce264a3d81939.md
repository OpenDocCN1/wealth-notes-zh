在过去麦当劳开的所有分店，都没有麦当劳大叔的形象。

他们后来就发现，有孩子的地方，就很容易积累人气。

他们为了给店里增加人气，他们就想了一招：就是在麦当劳店里，搞了很多玩具和儿童小型娱乐场，滑滑梯什么的。

刚开始有一家店，就为了引爆人气，就把这个设施和麦当劳大叔的形象给设计，然后摆出来，供家长免费玩。

这样，一下子这家店的生意就超级好。

为什么？

+   1， 因为过去冷清的门店，一下子被这么多孩子给带的非常热闹
别人一看，那么多人，很多人就愿意去这里消费。

+   2， 孩子玩累了，就想吃汉堡，喝东西。
�稳着，让父母给买，不买就哭。
所以父母也会不知不觉就消费了。

+   3， 他们还给孩子设计了复购模式。 就是我这一个玩具可以送给你，但是你要收集 3 个拼图，就就可以了。

3 次拼图，就是要麦当劳消费 3 次，然后可以兑换这个玩具。
那么这个店，生意好了之后，麦当劳总部，就市调是怎么回事。

为什么其他店，都不是很好，这家店，一直人流不断？ 后来，麦当劳就把这种模式，复制到全部的麦当劳门店。
