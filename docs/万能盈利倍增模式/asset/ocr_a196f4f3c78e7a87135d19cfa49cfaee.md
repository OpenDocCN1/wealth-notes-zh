但是你做抖音培训，后端就太大了。

你不但可以卖课程，还可以做资源整合，还可以卖抖音相关设备，还可以对接企业，还可以做流量合作，有太多太多的后端可以开发和挖掘。但是如果我们只是搞产品本身，那么挖掘后端的能力就太弱了。

# 复购率高好处。

我们现在生产一款面膜，效果极好，那么他的复购率就会很高。复购率高，就可持续带来不断的利润。

# 17, 能建立平台，实现自动运转，有平台生命力。

前期我们是自己公司来推广，后期，就是打造一个创业平台，让大众都来参与进来，最后我们只做平台，然后让客服来运营。

比如：马云的淘宝和天猫，都是这样的一个平台。刚开始是免费入驻开店，后来很多创业者不断进来，最后实现自动运转。快手和抖音也是如此。58同城和赶集网也是如此。

# 18, 能否接触到高端圈子和更成功的人士。

有一个朋友是做的图书出版公司。

就是专门帮别人出书的出版社。出版行业是一个劳动密集型的产业，每一本书有几十个环节，都需要人工跟进，它的制作周期太长，做一本书动不动要几个月，虽然利润很薄。

但是这个行业，最大的优点：可以接触度到各行各业的精英人才，能学到很多东西，认识很多人脉，得到很多资源。

从商业角度看，出版社不是赚钱的买卖，但是确实是获取资源的买卖。

就是说这个行业虽然不赚钱，但是他能带给我们认识更多优秀的人脉和资源。

我认为这也是一种很好的产品类型。
虽然不赚钱，但是赚的是人脉和资源。这个比钱有时候更值钱。
