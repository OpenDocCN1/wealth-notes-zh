# 深度揭秘：“莆田系”酒吧商业闭环比一个“莆田系”医院更赚钱的生意。

我们知道 2016 年 “魏则西” 事件，将莆田系医院推上了风口浪尖，那时候人们就发现中国几乎 80%以上 的医院几乎都是莆田系兴办的。

可能有人觉得医院是最赚钱的，今天我们看一个莆田系更赚钱的商业闭环玩法。

真是令人震撼，匪夷所思。

这种玩法，对我们做传统生意，还是线上生意的转型和模式升级，都有着巨大的学习，模仿，借鉴作用。
