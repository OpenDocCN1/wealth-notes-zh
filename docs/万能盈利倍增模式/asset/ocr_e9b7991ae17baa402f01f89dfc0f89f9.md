有一个小伙，给老板打工，一个月：3000块钱。
老板雇佣了小伙子，这个小孩就不能乱跑，只要上班时间，他必须待在店里面。

那么这个小孩，在卖什么产品？
很简单，就是出卖自己的时间。 =卖时间。

# 【选择理想产品小模板】

+   1，成本低 利润率高。\n2，高利润。 可以定高价，利润空间就越大。\n3，可持续（多次，持久，买单）\n4，唯一性（垄断）

+   5，必须性（刚需）

+   6，可复制（自己容易复制，别⼈无法复制）\n7，边际化成本低，趋近于零。\n8，仓储，物流成本低，趋近于零。\n9，现金流良好，账期短，甚至无账期。 无坏账，最好能预收货款。\n10，客户忠诚度高。\n11，具备自动购买力，不需要说服教育，客户自动想买。\n12，具备传播力，能自动传播裂变，省去营销推广费⽤。\n13，售后服务简单，甚至根本不需要售后服务。\n14，商品流通，资金周转率高。\n15，方便设计更多利润后端。\n16，复购率高。\n17，能建立平台，实现自动运转，有平台生命力。\n18，能否接触到⾼端的圈⼦和更成功的人士。

我们用这个【选择产品小模板进行对照】看看符合的条件有几个？
我们就可以发现，出卖时间，基本上满足的条件就只有一个：必须性。

就是大多数老板都需要打工的人。

其他基本上都没有。

但是小伙子，通过跟踪他就发现，老板1个月能赚1万多块钱，分自己3000，他自己净赚了7000多。 他觉得，不如做成人保健的老板那。
