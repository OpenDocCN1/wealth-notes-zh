# 第二点：『不要过于追求品牌』

耗费巨大的人力，物力财力，也不见得一定可以打造出一个像样的品牌。
品牌是啥？
就是核心竞争力。
表面上看，品牌就是无形资产，其实换句话讲：品牌就是一种信誉，就是消费者信赖的保证。

就是：我看到你这个牌子的衣服，我想都不用想，这可以放心买就对了。
所以：品牌是啥玩意，虚拟的一个商标而已。 其实本质上还是：来源于消费的者的信赖承诺。

辛辛苦苦打品牌还不如一句；1 年穿烂了，包换新。 3 年穿开胶了，包退钱。

你一个耐克牌子卖 398 元，我卖 398 元。

你更愿意买一款？
很多中小企业老板操盘一个企业，真正去落实品牌，就会发现非常不容易，而且非常烧钱，还没打起来，就可能已经死掉了。

但是又不只是你一个品牌，在竞争非常激烈的情况，你耗费巨大精力和人力，最终也不一定打造一个像样的品牌。

比如：小米很少做广告，但是人家是用产品保证，用性价比来做。 就很好。 品牌大多数情况下活下来的都是很少的幸运儿。

对大多数企业而言，试图打造品牌，在行业拥有绝对话语权，几乎是很困难的事情，除非你资金实力非常雄厚。

所以：对于中小企业来讲，刚开始是不适合大规模做品牌建设推广的。

因为大多数品牌推广都是在自我满足，并没有人知道，或者没有带来什么行之有效的话语权和成交率。

品牌太烧钱，会吃掉企业太多利润，而且成功率很低 。而我们企业应该追求的是利润，而不是什么百年品牌。

企业没有盈利，还开什么公司。
那不是扯淡，那就是在犯罪。
