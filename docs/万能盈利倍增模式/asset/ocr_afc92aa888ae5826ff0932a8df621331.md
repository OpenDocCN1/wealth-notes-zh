# 认购著四大保障

第一大保障：每头牛进场后买保险，保障价值安全。

第二大保障：牛出现伤亡，公司全部承担责任，用同批次牛进行补栏，保障正常的收益周期。

第三大保障：养牛时间周期为10个月，时间足够，能确保1000斤以上，保障投资者收益。

第四大保障：牛圈彻底完工后，全场装上摄像头，投资者可以实时看到牛场状态。

![](bbox=[0.202, 0.573, 0.709, 0.668])

你现在投入1万元，去认购，认购了之后，我们就可以拿这个钱去养殖牛，去招募人管理，去进饲料等。然后周期以10个月为期限，10个月之后可以退出，也可以继续养下一只牛。

那么对运营集团而言，钱都是客户出的，我们没有投入一分钱。

那么我们就可以赚到管理费，材料溢价费，以及其他一些基本费用等。还有资金的沉淀费。

这就是资本市场的一些思路和玩法。不单纯买卖，靠运作现金来实现市场的开拓。
