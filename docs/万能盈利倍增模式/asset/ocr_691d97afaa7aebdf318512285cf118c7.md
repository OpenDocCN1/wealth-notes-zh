# 我们怎么具体的去变现，落地。

对于我们分析市调别人的项目一般有这样几类人。

（1）自己没项目，自己可能就是比较好奇，或者想怎么参与进去。

因为你都不知道自己做什么，你破解别人的模式，就是为了提供给自己更好的思维，以便能找到创业的方向和思路。

如果你是在这个状态，我的建议是：你可以把别人比较优秀的点，总结成你的知识体系，以便后期我们有项目的时候可以从脑袋里调用起来。

当然了：最好有笔记，用思维导图，或者 txt，ppt，或者手写，都可以

这样你的记忆会更加深刻，而且什么时候需要的时候，可能就会潜移默化的想到，那么可能会对我们很有帮助。

如果你没项目，不去把这些变成深度思考的知识，那么基本上很快你就忘记了。

后面就算有项目，你也不一定能用上，因为你根本没有深度思考过，总结过。

我们在租赁加油站的时候，我们就想到了一个思路，就是找到一个核心的节点：要想找到租赁加油站的人，那么我们就跟卖加油机和维修加油机的人进行合作。还跟汽油柴油业务员合作。

因为他们手里面有大量的加油站客户，这些都有可能要出租加油站，或者出售转让加油站。但是如果我们找业务员自己去跑市场，很显然费时间和精力，而且不见得一定有效果。
