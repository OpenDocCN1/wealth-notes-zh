# 【万能市调模型】

没有数量级市调=项目失败;

所有营销方案制定和落地，都一定需要高手级市调（市场调研），不了解情况，就制定方案的营销人都是扯犊子。

# 【万能市调模型】

对内市调：财务数据+员工反馈数据+自身观察留意数据+找托来体验反馈数据。
对外市调：

线上市调：搜索引擎（百度）+电商平台（淘宝，京东，阿里巴巴，慧聪网，美...）+论坛（天涯，猫扑..）+沟通平台（微信，QQ，陌陌....）；百度系；阿里系；腾讯系数量级的搜索市调；

线下市调：陌生拜访+体验竞品+同行业交流互动+客户调查问卷+假应聘+间谍反间。 其他行业经验嫁接，业内指标(大数据分析)。

想做任何项目，都能100%成功，其实只有一个基本核心思路：市调。
研究消费者花费多少时间都不为过。

企业的首要利益相关者是客户。如果客户不满意，其它任何事情都免谈… 这个永远是第一位要解决的问题。

2，研究竞争对手花费多少时间都不为过。找100个案例，专业研究行业前3名+留意黑马；
3，研究自身优势，劣势，已有资源花费多少时间都不为过。

基本上市调方向为这3个方向。

这个市调，我讲过很多遍，但是我发现，真正落实市调的人，用心去做市调的人，真的是很少。

另外我要告诉大家的是：市调，不是说你市调2天就完事了，市调是你可能经常要做的事儿。而不是说：我简单的搜一下百度，问问朋友，就完事了。

在市调的过程中，我发现，我们学到的知识结构，思路和认知，真的是非常非常有用。
