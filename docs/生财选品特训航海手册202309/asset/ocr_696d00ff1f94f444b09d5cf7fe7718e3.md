# 小红书店铺选品方法（2）

生 —— 财

+   *   **如何选品**
*   宗旨：选品不在多，在精

+   *   **选品方向建议**
*   功能性半标品
*   自带流量的产品
*   新奇特且有真实需求的产品
*   红海市场中的蓝海
*   大牌平替
*   在确定要卖什么品类后，就一定定这个品类，不要换，店铺垂直很重要
*   美妆护肤品
*   知识付费类

+   *   **如何选到蓝海产品**
*   红海市场中的蓝海思路
*   找蓝海的方式（看数据）

+   *   **低粉爆款法选品**
*   找没多少粉丝但已经有品在爆的对标账号号易品
*   **原则**
*   对标模仿的小红书账号号低于 200 粉丝，同时最近 7 天发的单篇带货笔记点赞过 100，同时该带货笔记商品销量大于 100。
*   选品正确代表走完了 70% 的路，还有 30% 的路是封面 + 视频要模仿的精准

+   *   **抖音精选联盟排行榜选品**
*   第一：抖音的用户群体和小红书的用户群体有重合。
*   第二抖音上面的商品是以视频为主，素材比较多，方便我们进行混剪
*   **通过抖音去给小红书店铺选品**
*   第一，如果你在抖音上有开通商品橱窗，那么可以进入选品中心，搜索你选好的品类，找月销量排名前几名的商品去混剪，这是最高效的方法。
*   第二可以直接在抖音的搜索栏里直接去搜索对应的品类，再利用抖音的筛选功能去选择一天内最多点赞的内容，去进行混剪和搜集素材

+   *   **灰豚数据选品**
*   打开灰豚数据
*   点击笔记查找，选择笔记搜索
*   勾选上 [带货笔记: 是]
*   勾选上 [低粉爆款]
*   选择粉丝在 200 以下的，点赞在 7 天内大于 100 以上的笔记，同时该带货笔记商品需要销量大于 100，才可以选择这个品。同样使用低粉爆款法

+   *   **如何通过灰豚数据进行的逆向思维选品**
*   1. 按笔记数排序，选择互动数 300 以上 (低于 300 也可能是潜力爆款的商品，笔记数越多越好，证明这个账号在大力推这个产品，在小红书平台属于新品。
*   2. 进入商品详情以后判断销量 [1000 以内]，可以判定并没有大爆，这样我们竞争才不太激烈
*   3. 看粉丝数，如果是大博主，对方账号每发一条笔记，基础数据就是你的几倍甚至几十倍，模仿的必要性不是很大，当然也可以模仿，他吃肉你喝汤也不是不可以

+   *   **用蝉妈妈工具选品**
*   **用蝉妈妈找趋势爆品**
    *   [操作步骤]
    *   第一步：通过蝉妈妈的视频榜单，选择自己做的类目，譬如选择 “女装 - 连衣裙”
    *   第二步：选定类目后，再去找到符合小红书平台人群的产品。
*   **用蝉妈妈找新品**
    *   指那种新到全网都没有货，就是连厂家都没有发现做的那种，但是这块的需求又十分大的产品
    *   通过蝉妈妈 - 视频商品榜单 - 选择要做的类目，然后日榜单里面，选择趋势正在上升的产品，需要不断地上新品堆量，爆的概率还是比较大的

+   *   **在小红书 APP 选爆品**
*   搜索我们要做的同领域的关键词，找到在小红书销量最高的商品
*   分析对标账号的笔记和商品情况，到其他平台搜索同款，反向选品
*   建立 [选品漏洞池]
    *   写在有目的有规划的安排好第二天商品笔记的发布数量，比如你自己回测了封面标题，文案
    *   发布时间依然还没达到什么结果，那就要根据反馈情况看是否应该放弃

+   *   **小红书爆款选品合集**
*   搜索：最新的小红书爆款选品风向与方法

+   *   **如何测品**
*   在测品期间，测多个封面 + 标题
