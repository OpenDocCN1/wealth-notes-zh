如何选择蓝海产品

+   - 数据筛选
- 小众需求
- 词找货
  - 关键词找潜在的市场需求
  - 根据淘宝首页商品类目按梯级挖掘
  - 留心日常接触到的一些新奇的事物
  - 通过直通车数据反向查看一些非热门投放产品
  - 在[5118-关键词搜索]功能搜痛点相关的长尾词
  - 潜在的市场需求找关键词
- 货找词
  - 根据小红书荐物、淘宝首页猜你喜发等发
  - 根据在知乎、小红书等平台搜索功能挖掘
  - 根据热门产品、服务、app、头条等挖掘蓝
  - 其他来源：小众文化，小众爱好，小众品牌，影视剧同款、二类电商、微商朋友圈等

店群玩法选品

+   - 特点
  - 量最大，可以快速拉升流量
  - 1)价格比抖音低，因为我们要服务的这群人，是觉得抖音贵，来淘宝搜同款的这群人，所以价格肯定要低
  - 2)新奇特的产品，这些产品的特点就是—看就不很常规的款式
  - 3)这些品的利润率都很高，你可以去 1688 和拼多多去搜下，一般利润率都在 50% 以上，价格越低，利润率越高。
- 如何选品
  - 借助第三方工具(抖查查，螳螂飞，瓜瓜，考古加等第三方抖音工具)，前期可以去租子账号，可以打开 pdd 搜索
- 如何找更便宜的货源
  - 抖音产品的两大货源平台：1688 和拼多多

体系选品

+   - 1. 找体系
  - 提早“投资”上升期的抖音达人
  - 电梯广告
- 2. 做火炉
- 3. 第一圈红薯
- 4. 第二圈红薯
  - 仍然是放着，等红薯自然被烤熟，没必要做其他操作
- 5. 做利润品
  - 1.做套装；
  - 2.拍摄全网独一无二的漂亮亮图和视频(请个美女模特真人拍摄)
  - 3.加价卖

视频选品

+   - 在淘宝猜你喜欢、抖音视频、快手视频上去翻翻带货视频，看带货情况和出单数据，选择合适的品类
- 针对类目选品
  - 在选择产品的时候一定要细化产品内容
  - 建议要选择月销量至少 100-2000 的产品来推，效果会好一些
  - 价格：一般都是加价上 1.5-2 元
  - SKU；全部采集，上家有的 SKU 我们全部采集下来即可
- 注意
  - 运费:如果上家是有加运费的，我们再采集过来之后上传的商品也要加上运费，保证自己的利润
  - 水印;很多商家主图上都是会打水印花的，如果打了水印的我们就得处理一下，重新做一个图修改一下，或者直接不采集
