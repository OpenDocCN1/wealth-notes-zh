# 1.4.3 IPython 功能介绍

接下来，我们简要展示一下 IPython 的强大功能，由于我们尚未开始介绍 Python，读者暂时不需理会下面的语法，随着我们对 Python 的熟悉，则会慢慢体会到 IPython 诸多功能的便利之处。

+   1. 自动补全功能

In [2]: print("Hello Python")
