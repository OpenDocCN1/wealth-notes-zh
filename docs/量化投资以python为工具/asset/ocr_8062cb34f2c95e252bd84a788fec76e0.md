$$r_6=\ln\left(P_6\right)-\ln\left(P_5\right)=\ln\left(7.46\right)-\ln\left(7.42\right)=0.537\%$$

# 18.2.1 多期连续复利收益率

在计算 $k$ 期连续复利收益率之前，我们先用 2 期来示范如何计算连续复利收益率。与单期的计算方式 $r_{t}=\ln\left(1+R_{t}\right)$ 类似，假设 2 期连续复利收益率为 $r_{t}(2)$，则：
