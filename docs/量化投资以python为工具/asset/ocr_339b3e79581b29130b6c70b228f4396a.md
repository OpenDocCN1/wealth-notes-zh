+   增加行或者列

有时我们需要将两个数据集合并在一起，可能会往横的方向上接续更多的列，也可能在纵的方向上拼接更多的行。在列的方向上操作时，数据集会自动根据 index 对齐；在行的方向操作时，数据集会自动根据列的名对齐。

```
In [8]: s1 = pd.Series({1,2,3,4,5,6}, index=pd.date_range('20160102', periods=5))
In [9]: s1
Out[9]:
2016-01-02 1
```
