# 13.4 数据的离散度

数据的位置仅是一个点，若要全面地反应数据分布的特征，还需要其他的指标。数据的离散度也称为数据的变异性，主要衡量样本数据相对于中心位置的偏离程度。把数据的位置同离散度结合起来，就可以很好地刻画数据分布的特征。常用的离散度指标有极差、平均绝对偏差、方差和标准差等。
