+   当 $\alpha = 5\%$ 时，布林带上通道线为 $\bar{B}_{n} = u_{n} + 1.96 \times \sigma_{n}$，布林带的下通道为 $\underline{B}_{n} = u_{n} - 1.96 \times \sigma_{n}$

+   当 $\alpha = 1\%$ 时，布林带上通道线为 $\bar{B}_{n} = u_{n} + 2.58 \times \sigma_{n}$，布林带的下通道为 $\underline{B}_{n} = u_{n} - 2.58 \times \sigma_{n}$
