```
```
In [16]: dates = [datetime(2016,1,1), datetime(2016,1,2), datetime(2016,1,3)]

In [17]: ts=pd.Series([1,2,3],index=dates)

In [18]: ts.index[0]
Out[18]: Timestamp('2016-01-01 00:00:00')
```
```

时间序列之间的算术运算会自动按时间对齐。

+   1. 截取时间段数据

时间序列只是 index 比较特殊的 Series，因此一般的索引操作对时间序列依然有效。其特别之处在于对时间序列索引的操作优化。如使用各种字符串进行索引：

```
```
In [19]: ts['20160101']
Out[19]: 1

In [20]: ts['2016-01-01']
Out[20]: 1

In [21]: ts['01/01/2016']
Out[21]: 1
```
```

对于较长的序列，还可以只传入年份或年份加月份来选取切片：

```
```
In [22]: ts
Out[22] :
2016-01-01    0.003195
2016-01-02   -0.517593
2016-01-03   -0.812502
dtype: float64

In [23]: ts['2016']
Out[23] :
2016-01-01    0.003195
2016-01-02   -0.517593
2016-01-03   -0.812502
dtype: float64

In [24]: ts['2016-01':'2016-02']
Out[24] :
2016-01-01    0.003195
2016-01-02   -0.517593
2016-01-03   -0.812502
dtype: float64
```
```

除了这种字符串切片方式之外，还有一种方法可用：

```
```
In [25]: ts.truncate(after='2016-01-02')
Out[25] :
2016-01-01      1
2016-01-02      2
dtype: int64
```
```

切片时使用的字符串时间戳可以不必存在于 index 之中，比如 ts.truncate(after='8394')。
