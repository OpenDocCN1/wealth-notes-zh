值与最高最低价差值之比得到，其计算公式为：

W&R = (H_n - C_n) / (H_n - L_n) * 100%

其中，n为时间跨度，短期的威廉指标可设n为6日或9日，中期为14日或20日，长期为70日；

H_n表示n日内的最高价；C_n表示第n日的收盘价；L_n表示n日内的最低价。
