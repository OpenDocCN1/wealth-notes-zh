```
$$\begin{equation} R_{t}(k) = \sum_{j = 0}^{k-1} R_{t-j} \end{equation}$$
```

以此法计算得到的收益率与相乘计算得到的不同，相乘计算考虑到复利的效果；而加总计算是投入本金之后，每一期获得的收益没有再投入到资产中的收益。

根据单期收益率计算多期收益率操作上简单、思想上也容易理解，不过，由多期收益率计算单期收益率就没有这么直观了。由多期收益率计算单期收益率涉及平均的概念，计算的是在过去持有资产的几期里，平均每期的收益率是多少。比如，我们可以根据月收益率计算日收益率。与单期收益率相加或者相乘计算多期收益率对应，由多期计算单期也有两种方式，一种是算数平均（Arithmetice Average），另一种是几何平均（Geometric Average）。算数平均和几何平均的算法为：

```
$$\begin{equation} \text{算数平均收益率} = \frac{R_{t}(k)}{k} = \frac{\sum_{j=0}^{k-1} R_{t-j}}{k} \end{equation}$$
```

```
$$\begin{equation} \text{几何平均收益率} = \sqrt[k]{R_{t}(k) + 1} - 1 = \sqrt[k]{\prod_{j=0}^{k-1} (1 + R_{t-j})} - 1 \end{equation}$$
```

几何平均有考虑复利，衡量的是过去 $k$ 期中将每期的收益作为本金投入下期资产中这种投资方法的平均收益；而算数平均没有考虑复利的效果。

# ### 18.1.5 年化收益率

假设投资人现在面对三种资产 A、B、C，资产 A 三个月的收益率率为 3%，资产 B 三年的收益率为 25%，资产 C 一年的收益率率为 7%，每个资产收益率的计算时间区间都不同。作为投资人，我们该如何判断资产的投资表现呢？很显然，只要将各种收益率率换算成相同时间区间的收益率率即可比较。年化收益率（Annualized Return）是把当前收益率（日收益率、周收益率、月收益率等）换算成年收益率率来计算的，方便投资人比较不同期限的投资。现实生活中，投资人经常可以接触到“年化收益率率”这个词，比如建设银行七天存款的年化利率为 1.35%，工商银行推出一款 60 天理财产品，预期年化收益率为 4.6%~4.65%，阿里巴巴推出的余额宝七日年化收益率为 3.636%。年化收益率率只是一种理论上的收益率率，并不是投资人真正能够获得的收益率率。比如最近特别流行的各种货币基金都会提供七日年化收益率率供投资人参考，不过，七日年化收益率率是货币基金最近 7 日的平均收益水平，进行年化以后得出的收益率率，并不代表该基金之后的表现。年化收益率率与年收益率率不同，年收益率率是指投资一笔资产一年的实际收益率率，比如投资人购买基金时常常会参考过去一年的收益率率，这个收益率率就是年收益率率，是投资人过去一年实际获得的报酬，也是基金经理人资产管理的一个表现。年化收益率率低风险性的资产市场中应用十分广泛，而年收益率率可以应用于任何资产。接下来介绍如何计算年化收益率率。
