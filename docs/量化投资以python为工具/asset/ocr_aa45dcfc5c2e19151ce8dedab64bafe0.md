```
$R^2 = \frac{RSS}{TSS}$
```

根据公式(17.3)可知R²在0~1之间取值，其值越大说明可用模型解释的波动部分占总波动比例越高、拟合的越好。

# 17.3 古典假设条件下α、β之统计性质

最小平方法是利用误差平方和最小得出参数α与β的估计式，该估计式是样本X_{i}和Y_{i}的函数，也就是说不同的样本观测值会有不同的参数估计值α、β。一般来说，随机抽样导致的波动和选择的估计方法不同会使参数估计值与参数的真实值存在差距，因此Y_{i}和X_{i}需要满足一些随机条件，以衡量估计式的统计性质。以下为Y_{i}和X_{i}需要满足的假设条件。

+   1.   X_{i}，i=1,2,…，n为非随机的变数。

+   2.   存在参数的真实值α_{0}、β_{0}使得Y_{i}=α_{0}+β_{0}X_{i}+e_{i}；i=1,2,…，n，其中干扰项e_{i}满足以下性质：

+   a)   E(e_{i})=0，i=1,2,…，n，基于这个条件及X_{i}非随机的假设，可以得到E(Y_{i})=α_{0}+β_{0}X_{i}。

+   b)   Var(e_{i})=σ²_{0}，i=1,2,…，n，这个条件又被称为同方差(Homosciedasticity)条件；当i≠j时，Cov(e_{i}，e_{j})=0，这个条件是要求e_{i}无自相关性。在最小平方法的框架下，干扰项e_{i}的方差σ²_{0}的估计式为：

```
$\hat{\sigma}^2 = \frac{1}{n-2} \sum_{i=1}^{n} \hat{\varepsilon}_i^2$
```

以上的假设条件被称为回归的古典条件(Classical Conditions)。

接下来我们来分析最小平方法估计式α、β和σ²的统计性质。在古典假设条件下，可以证明最小平方估计式α、β是α_{0}、β_{0}的最佳线性无偏估计式(Best Linear Unbiased Estimator)，其中“线性”是之α、β为所有Y_{i}之线性组合；“无偏”是指E(α)=α_{0}、E(β)=β_{0}；“最佳”是指任意其他线性无偏估计式α、β之方差均大于α、β的方差，也就是说对于所有的线性无偏估计式α、β，Var(α)≥Var(α)、Var(β)≥Var(β)。

此外，我们还可以得到估计式α、β的概率分布。当满足古典线性回归模型假设时，最小二乘估计量α、β服从正态分布：

```
$\hat{\alpha} \sim N \left( \alpha_{0}, \sigma_{0}^{2} \left( \frac{1}{n} + \frac{\bar{X}^{2}}{\sum_{i=1}^{n} \left( X_{i} - \bar{X} \right)^{2}} \right) \right)$
```

```
$\hat{\beta} \sim N \left( \beta_{0}, \sigma_{0}^{2} \frac{1}{\sum_{i=1}^{n} \left( X_{i} - \bar{X} \right)^{2}} \right)$
```
