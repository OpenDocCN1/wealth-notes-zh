知道初始资本、收益即可求得投资组合的收益率 $R_p$：

```
$$\begin{aligned} R_p &= \frac{\text{总收益}}{\text{初始投入资本}} = \frac{W_0 \omega_A R_A + W_0 \omega_B R_B}{W_0} \\ &= \omega_A R_A + \omega_B R_B \end{aligned}$$
```

特定资产的风险可以用很多种方式来衡量，不过考虑到方便性和易解性，本章延续用收益率的方差（标准差）来指代风险。单个资产收益率的方差为：

```
$$\sigma^2\left(R_i\right) = \mathbb{E}\left\{\left[R_i - \mathbb{E}\left(R_i\right)\right]^2\right\}$$
```

两个资产组成的投资组合的方差为：

```
$$\begin{aligned} \sigma^2\left(R_p\right) &= \mathbb{E}\left\{\left[R_p - \mathbb{E}\left(R_p\right)\right]^2\right\} \\ &= \mathbb{E}\left\{\left[\omega_A R_A + \omega_B R_B - \mathbb{E}\left(\omega_A R_A + \omega_B R_B\right)\right]^2\right\} \\ &= \mathbb{E}\left\{\left[\omega_A\left[R_A - \mathbb{E}\left(R_A\right)\right] + \omega_B\left[R_B - \mathbb{E}\left(R_B\right)\right]\right]^2\right\} \\ &= \mathbb{E}\left\{\omega_A^2\left[R_A - \mathbb{E}\left(R_A\right)\right]^2 + \omega_B^2\left[R_B - \mathbb{E}\left(R_B\right)\right]^2 \right. \\ &\quad \left.+ 2\omega_A\omega_B\left[R_A - \mathbb{E}\left(R_A\right)\right]\left[R_B - \mathbb{E}\left(R_B\right)\right]\right\} \\ &= \omega_A^2 \sigma^2\left(R_A\right) + \omega_B^2 \sigma^2\left(R_B\right) + 2\omega_A\omega_B \sigma\left(R_A, R_B\right) \end{aligned}$$
```

标准差为：

```
$$\sigma\left(R_p\right) = \sqrt{\omega_A^2 \sigma^2\left(R_A\right) + \omega_B^2 \sigma^2\left(R_B\right) + 2\omega_A\omega_B \sigma\left(R_A, R_B\right)}$$
```

其中 $\sigma\left(R_A, R_B\right)$ 为资产 $A$ 与资产 $B$ 的协方差：

```
$$\sigma\left(R_A, R_B\right) = \mathbb{E}\left\{\left[R_A - \mathbb{E}\left(R_A\right)\right]\left[R_B - \mathbb{E}\left(R_B\right)\right]\right\} \quad (19.1)$$
```

从公式 (19.1) 可以看出，如果资产 $A$ 与资产 $B$ 收益率变化趋势是一致的（比如资产 $A$ 的收益率高于期望值时，资产 $B$ 的收益率也高于期望值），则其协方差为正；反之，若变化趋势相反，则协方差为负。协方差常常用来判断两个变量之间的相关性，不过由于协方差会受比例影响（比如把 $R_A$ 和 $R_B$ 同时扩大 10 倍，协方差会放大 100 倍），因此统计学家引入相关系数来刻画两变量之间的相关性。资产 $A$ 和资产 $B$ 收益率之间的相关系数为：

```
$$\rho_{A,B} = \frac{\sigma\left(R_A, R_B\right)}{\sigma\left(R_A\right)\sigma\left(R_B\right)}$$
```
