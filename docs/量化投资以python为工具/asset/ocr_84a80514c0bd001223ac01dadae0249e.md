在绘制柱状图时，我们可以修改柱状图的相关参数取值。参数 left 和 height 分别用于设置每根棒的 X 轴位置和高度，bar() 函数还提供了 width 和 bottom 这两个参数。其中，width 参数用于调整棒的宽度，而 bottom 用于设定棒底部的 Y 轴坐标，即柱状图中的棒不一定要紧贴 X 轴，而可以设置为 “凌空” 位置。如图 12.20 所示。
