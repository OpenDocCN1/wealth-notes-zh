# ### 25.2 ARCH 模型和 GARCH 模型

# #### 25.2.1 ARCH 模型

ARCH 模型的全称为自回归条件异方差模型（Autoregressive Conditional Heteroskedastic Model），经常简称为条件异方差模型。它是 Engle 在 1982 年分析英国通货膨胀率序列时提出的残差平方自回归模型。ARCH 模型主要是用来刻画波动率的统计特征的，因此我们先要弄清楚如何衡量波动率。一般先假设收益率序列 { $ y_{t} $ } 满足某个均数方程式，比如 AR(p)、MA(q) 或者 ARMA(p,q) 模型，这里用简单的 AR(1) 模型：

$$\boldsymbol{y}_{t} = a_{0} + a_{1} y_{t - 1} + \varepsilon_{t}$$

这样收益率 $ y_{t} $ 的波动率（条件方差）就可以用残差项 $ \varepsilon_{t} $ 的波动来刻画：

$$\operatorname{Var} \left( y_{t} | y_{t - 1} \right) = \operatorname{Var} \left( \varepsilon_{t} | y_{t - 1} \right)$$

波动聚集是指大波动跟随大波动、小波动跟随小波动，也就是说现期的波动会跟之前的波动有关，所以一个很自然的想法就是令 $ \varepsilon_{t} $ 的条件方差与过去残差项的平方有关。具体的，一个 ARCH(p) 模型可以表达为：

$\begin{gathered}\varepsilon_{t} = \sigma_{t} u_{t} \\\sigma^{2}_{t} = \alpha_{0} + \alpha_{1} \varepsilon^{2}_{t - 1} + \cdots + \alpha_{p} \varepsilon^{2}_{t - p}\end{gathered}$

其中 $\left\{ u_{t} \right\}$ 是均值为 0、方差为 1 的独立同分布随机变量序列，即 $ u_{t} \sim IID \left( 0,1 \right) ; \alpha_{0} > 0 , \alpha_{i} \geqslant 0 $，且假定 $\alpha_{i}$ 满足一定条件使得 $\varepsilon_{t}$ 的无条件方差有限，即 $\operatorname{E}\left( \varepsilon^{2}_{t} \right) < \infty$ 。这样我们可以计算 $\varepsilon_{t}$ 的条件均值（Conditional Mean）为：

$\begin{array}{l}\operatorname{E}\left( \varepsilon_{t} | \mathscr{F}^{t - 1} \right) = \sigma_{t} \operatorname{E}\left( u_{t} | \mathscr{F}^{t - 1} \right) = \sigma_{t} \operatorname{E}\left( u_{t} \right) = 0\end{array}$

其条件方差为：

$\begin{array}{l}\operatorname{E}\left( \varepsilon^{2}_{t} | \mathscr{F}^{t - 1} \right) = \sigma^{2}_{t} \operatorname{E}\left( u^{2}_{t} | \mathscr{F}^{t - 1} \right) = \sigma^{2}_{t} \operatorname{E}\left( u^{2}_{t} \right) = \sigma^{2}_{t} \\\quad = \alpha_{0} + \alpha_{1} \varepsilon^{2}_{t - 1} + \cdots + \alpha_{p} \varepsilon^{2}_{t - p}\end{array}\tag{25.1}$

从公式 (25.1) 可以看出，满足 ARCH(p) 模型的序列之波动（条件方差）与其过去 p 期的波动有关，而且会随着时间改变，这就是“自回归条件异方差”这几个字的含义，ARCH 模型刻画的这种现象被称作 ARCH 效应。可以验证 $\left\{\varepsilon_{t}\right\}$ 是白噪声过程，满足：
