# 第 17 章 回归分析

方差分析可以让我们知道一个因子对一个连续型的因变量有没有影响。但是，很多时候，我们更想知道连续型的自变量对连续型因变量有没有影响；如果有影响的话，那么这个影响具体有多大。也就是说，我们更想知道当一个连续型变量变化时，另外一个连续型变量会变多少。为了解决这个问题，我们需要进行回归分析（Regression Analysis）。回归分析能够将多个连续型或是离散型的变量之间的关系量化，从而找到事物之间的线性相关关系或是进行预测。

## 17.1 一元线性回归模型

### 17.1.1 一元线性回归模型

假设有两个变量：自变量（Independent Variable）$X$ 和因变量（Dependent Variable）$Y$，一元线性回归模型（Simple Linear Regression Model）是指用线性模型 $\alpha+\beta X$ 来刻画 $Y$ 的变动，其中 $\alpha$ 和 $\beta$ 是未知的、待估计的参数。通常当变量有随机的成分在时，就不能用一个变量完全解释另一个变量，因此我们将 $Y$ 表达为：

$$ Y_{i}=\alpha+\beta X_{i}+\varepsilon_{i}, \quad i=1,2, \cdots, n $$

其中：

- $Y_{i}$ 为变量 $Y$ 的第 $i$ 个样本，$X_{i}$ 为变量 $X$ 的第 $i$ 个样本，共有 $n$ 个样本，其中 $X_{i}$ 取值不能全部相等，也就是 $X$ 为非常数，假设所有 $X$ 的取值都相等，则可以推断 $Y$ 的变化肯定不是由 $X$ 引起的，研究 $X$ 对 $Y$ 的影响毫无意义。
- $\varepsilon_{i}$ 为随机误差项（Error）或干扰项，表示 $Y_{i}$ 的变化中未被 $X_{i}$ 解释的部分。
- 参数 $\alpha$ 和 $\beta$ 都被称为回归系数（Regression Coefficient），其中 $\alpha$ 是截距项（Intercept）；$\beta$ 为斜率项（Slope），表示 $X$ 每增加一个单位，$Y$ 平均会增加 $\beta$ 个单位。

这里要注意的是，线性回归模型中的“线性”指模型是参数的线性函数，并不要求是变量 $X$ 和 $Y$ 的线性函数，比如我们认为 $Y$ 与 $X$ 满足：

$$ Y_{i}=\alpha+\beta \ln X_{i}+\varepsilon_{i} $$

该模型可以转化为线性模型：

$$ Y_{i}=\alpha+\beta Z_{i}+\varepsilon_{i} $$

其中 $Z_{i}=\ln X_{i}$ 可以通过对样本 $X_{i}$ 取对数得到。因此只要是参数的线性模型，都适用于本章的分析。

### 17.1.2 最小平方法

在上述的线性模型中，$X_i$ 和 $Y_i$ 是样本数据，但还需要知道 $\alpha$ 与 $\beta$ 的值。对于 $\alpha$ 与 $\beta$ 的值，可以根据 $X_i$ 和 $Y_i$ 的数据来估计。估计的方法有很多种，比如前面讲过的矩估计法就是其中一种。很明显，采取不同的估计方法，就会得到不同的 $\alpha$ 与 $\beta$ 的估计值。而我们想要的自然是最接近真实值的估计，那么，应该采取什么方法进行估计呢？构建线性回归模型的目的是要来解释 $Y$ 的变动，因此我们认为 $\alpha$ 与 $\beta$ 的估计式是令 $Y_i$ 中未被 $X_i$ 解释的部分 $\varepsilon_i$ 越小越好。我们可以将误差项 $\varepsilon_i$ 加总令其最小，但是，误差 $\varepsilon_i$ 有时大于零有时小于零，加总时会正负抵消，这样就无法区分没有偏差和正负偏差相抵消时的情况。因此，我们选择使用误差 $\varepsilon_i$ 之平方和并令其最小，这种估计方法被称为最小平方法（Least Squares Method）。求解 $\alpha$ 和 $\beta$ 的方式可以用数学公式表达如下：

$$\min_{\alpha, \beta} Q(\alpha, \beta) = \frac{1}{n} \sum_{i=1}^{n} (Y_i - \alpha - \beta X_i)^2$$

根据函数最小化原则，能够令误差平方和 $Q(\alpha, \beta)$ 最小的 $\alpha$、$\beta$ 必须满足以下一阶条件（First Order Conditions）：

$$\frac{\partial Q(\alpha, \beta)}{\partial \alpha} = -2\frac{1}{n} \sum_{i=1}^{n} (Y_i - \alpha - \beta X_i) = 0 \tag{17.1}$$

$$\frac{\partial Q(\alpha, \beta)}{\partial \beta} = -2\frac{1}{n} \sum_{i=1}^{n} (Y_i - \alpha - \beta X_i) X_i = 0$$

根据这两条一阶条件公式，可以得到 $\alpha$ 与 $\beta$ 的最小平法估计式（Estimator）：

$$\hat{\beta} = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y - \bar{Y})}{\sum_{i=1}^{n} (X_i - \bar{X})^2} \tag{17.2}$$

$\hat{\alpha} = \bar{Y} - \hat{\beta} \bar{X}$

其中 $\bar{X}$ 和 $\bar{Y}$ 为 $X$ 和 $Y$ 的样本均值，注意式(17.2)是估计式，也就是说，样本观测值不同，我们就会得到不同的 $\hat{\alpha}$、$\hat{\beta}$。如果我们将样本观测值 $x_1, x_2, \dots, x_n$ 和 $y_1, y_2, \dots, y_n$ 代入估计式(17.2)中，即可得到 $\hat{\alpha}$ 与 $\hat{\beta}$ 之最小平方估计值（Estimate）：

$$\hat{\beta}_n = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

$\hat{\alpha}_n = \bar{y} - \hat{\beta} \bar{x}$

其中 $\bar{x}$、$\bar{y}$ 是 $\bar{X}$、$\bar{Y}$ 的实现值。

将 $\hat{\alpha}$ 与 $\hat{\beta}$ 之最小平方估计值代入线性模型，可得由样本观测值 $x_1, x_2, \dots, x_n$ 解释的 $\hat{y}_i$：

$\hat{y}_i = \hat{\alpha}_n + \hat{\beta}_n x_i, \quad i = 1, \cdots, n$

这个 $\hat{y}_i$ 被称为拟合值（Fitted Value），而样本观测值 $y_i$ 与拟合值 $\hat{y}_i$ 之间的差值为残差值（Residual Value）:

$\hat{\varepsilon}_i = y_i - \hat{y}_i, \quad i = 1, \cdots, n$

另外根据一阶条件式(17.1)，可得：

$\sum_{i=1}^{n} \left( Y_i - \hat{\alpha} - \hat{\beta} X_i \right) = \sum_{i=1}^{n} \hat{\varepsilon}_i = 0$

$\sum_{i=1}^{n} \left( Y_i - \hat{\alpha} - \hat{\beta} X_i \right) X_i = \sum_{i=1}^{n} \hat{\varepsilon}_i X_i = 0$

## 17.2 模型拟合度

在现实，可能不同的 $X$ 都可以用来解释 $Y$ 之变动，比如自变量 $X$ 是股票收益率，有人可能用公司每股收益来解释，有人可能用公司市值来解释。因此，我们需要一个指标能够判断出模型的好坏，对此，我们引入拟合度（Goodness of Fit）的概念。拟合度是指回归直线与样本数据趋势的吻合程度，取决于估计方法和样本数据。

常用来判断线性模型拟合度的指标是 $R^2$ (R Square)，又称作可决系数（Coefficient of Determination），它刻画的是自变量与因变量关系密切的程度，由回归模型解释的变动量占 $Y$ 总变动量的百分比刻画。如果将因变量 $Y$ 的波动（方差）进行分解，可以得到如下公式:

$\sum_{i=1}^{n} (Y_i - \bar{Y})^2 = \sum_{i=1}^{n} \left( \hat{Y}_i - \bar{Y} \right)^2 + \sum_{i=1}^{n} \hat{\varepsilon}^2$

其中:

- 等号左边为总平方和（Total Sum of Squares, TSS)，度量了因变量 $Y_i$ 的总波动情况;
- 等号右边第一项为回归平方和（Regression Sum of Squares, RSS)，度量了模型估计出来的 $\hat{Y}_i$ 的波动情况，由于 $\hat{Y}_i$ 是根据自变量 $X_i$ 估计的，所以这一部分可以说是总平方和中可以被自变量 $X_i$ 解释的波动;
- 等号右边第二项为残差平方和（Error Sum of Squares, ESS)，度量了残差的波动，即不能被自变量 $X_i$ 解释的波动。

由于 TSS、RSS、ESS 均为平方和，三者的关系为:

$TSS = RSS + ESS \quad (17.3)$

$R^2$ 的表达式为:

$R^2 = \frac{RSS}{TSS}$

根据公式(17.3)可知 $R^2$ 在0~1之间取值，其值越大说明可用模型解释的波动部分占总波动比例越高、拟合的越好。

## 17.3 古典假设条件下$\alpha$、$\beta$之统计性质

最小平方法是利用误差平方和最小得出参数$\alpha$与$\beta$的估计式，该估计式是样本$X_{i}$和$Y_{i}$的函数，也就是说不同的样本观测值会有不同的参数估计值$\alpha$、$\beta$。一般来说，随机抽样导致的波动和选择的估计方法不同会使参数估计值与参数的真实值存在差距，因此$Y_{i}$和$X_{i}$需要满足一些随机条件，以衡量估计式的统计性质。以下为$Y_{i}$和$X_{i}$需要满足的假设条件。

1. $X_{i}$，$i=1,2,\dots,n$为非随机的变数。
2. 存在参数的真实值$\alpha_{0}$、$\beta_{0}$使得$Y_{i}=\alpha_{0}+\beta_{0}X_{i}+e_{i}$；$i=1,2,\dots,n$，其中干扰项$e_{i}$满足以下性质：
   1. $E(e_{i})=0$，$i=1,2,\dots,n$，基于这个条件及$X_{i}$非随机的假设，可以得到$E(Y_{i})=\alpha_{0}+\beta_{0}X_{i}$。
   2. $Var(e_{i})=\sigma^{2}_{0}$，$i=1,2,\dots,n$，这个条件又被称为同方差(Homosciedasticity)条件；当$i \neq j$时，$Cov(e_{i}，e_{j})=0$，这个条件是要求$e_{i}$无自相关性。在最小平方法的框架下，干扰项$e_{i}$的方差$\sigma^{2}_{0}$的估计式为：

$$\hat{\sigma}^2 = \frac{1}{n-2} \sum_{i=1}^{n} \hat{\varepsilon}_i^2$$

以上的假设条件被称为回归的古典条件(Classical Conditions)。

接下来我们来分析最小平方法估计式$\alpha$、$\beta$和$\sigma^{2}$的统计性质。在古典假设条件下，可以证明最小平方估计式$\alpha$、$\beta$是$\alpha_{0}$、$\beta_{0}$的最佳线性无偏估计式(Best Linear Unbiased Estimator)，其中“线性”是之$\alpha$、$\beta$为所有$Y_{i}$之线性组合；“无偏”是指$E(\alpha)=\alpha_{0}$、$E(\beta)=\beta_{0}$；“最佳”是指任意其他线性无偏估计式$\alpha$、$\beta$之方差均大于$\alpha$、$\beta$的方差，也就是说对于所有的线性无偏估计式$\alpha$、$\beta$，$Var(\alpha)\ge Var(\alpha)$、$Var(\beta)\ge Var(\beta)$。

此外，我们还可以得到估计式$\alpha$、$\beta$的概率分布。当满足古典线性回归模型假设时，最小二乘估计量$\alpha$、$\beta$服从正态分布：

$$\hat{\alpha} \sim N \left( \alpha_{0}, \sigma_{0}^{2} \left( \frac{1}{n} + \frac{\bar{X}^{2}}{\sum_{i=1}^{n} \left( X_{i} - \bar{X} \right)^{2}} \right) \right)$$

$$\hat{\beta} \sim N \left( \beta_{0}, \sigma_{0}^{2} \frac{1}{\sum_{i=1}^{n} \left( X_{i} - \bar{X} \right)^{2}} \right)$$
