接下来拟合 CAPM 模型，即：

R _ { i } - R _ { f } = \alpha _ { i } + \beta _ { i } ( R _ { m } - R _ { f } ) + \varepsilon _ { i }

该过程用 statsmodels 包中的 OLS( ) 函数实现，分析的对象是之前生成的 xts 数据集 Eret。

```
```python
