其中 $x_0=0, \varepsilon_t \sim N(0,\sigma^2)$，这里的随机扰动项 $\{\varepsilon_t\}$ 即是服从正态分布的纯随机序列，$x_t$ 可以改写成 $x_t=\sum_{i=1}^{t} \varepsilon_i$，是 $t$ 期纯随机变量的加总，所以被称为随机游走（Random Walk）过程。弱式有效市场假说认为，股票的价格是随机游走的，因此是无法被预测的。
