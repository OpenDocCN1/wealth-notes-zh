# 12.2.2.1 添加标题

在图像中添加文本，包括标题、图例等，可以使得图像变得简单易懂。若要添加标题，可以通过 pyplot 包中的 title() 函数实现。

```
matplotlib.pyplot.title(s, *args, **kwargs)
```

+   • 参数 s 为 str 类型数据。

+   • 参数 loc: 设定标题的显示位置。可选取值有“center”、“left”或者“right”，分别表示标题显示于坐标轴的中央、左边缘和右边缘。loc 默认取值为“center”。
