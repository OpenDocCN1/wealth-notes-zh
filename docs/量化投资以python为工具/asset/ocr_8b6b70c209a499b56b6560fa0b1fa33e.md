$$\text{E}\left(R_p\right) = R_f + \frac{\text{E}\left(R_m\right) - R_f}{\sigma_m}\sigma_p \tag{19.10}$$

公式 (19.10) 可以清楚地表达出投资组合的期望收益率与风险之间的线性关系，风险越高，对应的收益率应该越高。

深入探索 Markowitz 模型的最优解，可以得到一个模定资本资产定价模型 (Capital Asset Pricing Model, CAPM) 的结论：对于任意的投资组合 $q$，其收益率 $R_q$ 满足以下关系式：

$$\text{E}\left(R_q\right) = R_f + \beta_{qm}[\text{E}\left(R_m\right) - R_f]$$

其中 $\beta_{qm} = \frac{\sigma\left(R_q, R_m\right)}{\sigma^2\left(R_m\right)}$，$\sigma\left(R_q, R_m\right)$ 为资产组合收益率与市场投资组合收益率之间的协方差。任意资产组合 $q$ 可以是单个资产 $i$，这样我们就可以得到 CAPM 模型的表达式：

$$\text{E}\left(R_i\right) = R_f + \beta_{im}[\text{E}\left(R_m\right) - R_f]$$

其中 $\beta_{im} = \frac{\sigma\left(R_i, R_m\right)}{\sigma^2\left(R_m\right)}$ 可以反应出单个资产的系统风险水平，若 $\beta_{im} = 1$，则资产 $i$ 的价格和市场投资组合的价格波动性是一致的；若 $|\beta_{im}| < 1$，则资产 $i$ 的价格波动程度小于市场投资组合；若 $|\beta_{im}| > 1$，则资产 $i$ 的价格波动更大一些。$\beta$ 值为正说明资产 $i$ 的价格与市场投资组合价格同方向变动，反之则反向变动。CAPM 模型在现实中应用非常广泛，很多券商会提供个股的 $\beta$ 值。
