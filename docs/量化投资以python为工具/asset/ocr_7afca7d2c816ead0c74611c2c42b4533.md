# • 替换操作

有时我们需要将数据集中的某个或者某些值替换、更新，即先找到要替换的数据所在的位置（通过位置索引或者标签索引），然后赋予新的值：

```
```
# 标签索引替换
In [22]: df.loc[dates[2], 'C'] = 0

# 位置索引替换
In [23]: df.iloc[0,4] = 0
