# 12.4.2.2 一个图中多条曲线绘制

有时候，我们想要将多个变量绘制在一个图形中，以直观对比多个变量的取值情况。此时，Axes 对象为我们绘图带来了较大的便利，只要创建一个 Axes 对象，在此对象所代表的区域中绘制图形即可。比如，将中国银行的四种价格（开盘价、最高价、最低价和收盘价）曲线绘制在同一图中，如图 12.32 所示。
