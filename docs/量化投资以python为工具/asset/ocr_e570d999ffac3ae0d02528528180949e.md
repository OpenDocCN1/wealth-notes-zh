continue 语句：表示不执行 continue 下面一行语句或者一个语句块代码，而接着遍历执行循环语句。

```
```
In [5]: for i in st1:
      ...:     if i=='python':
      ...:         continue #停止执行当前循环语句中的内容，并进入下一次循环
      ...:     print(i) #在for循环语句内部
      ...:     print('hello') #不在for循环语句内部，在for循环语句执行结束后执行
      ...:
```
a
b
c
d
hello
```
