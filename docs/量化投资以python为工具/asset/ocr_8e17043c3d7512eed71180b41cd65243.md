拒绝或接受原假设的结论。如果接受 $ \beta_0 = 0 $ 的原假设，说明变量 X 对于变量 Y 的影响系数为 0，则此模型的构造没有太大意义；若拒绝 $ \beta_0 = 0 $ 的原假设，说明变量 X 对于变量 Y 有显著不为 0 的影响，则可根据 X 的观测值来预测随机变量 Y。对于截距 $ \hat{\alpha} $，我们可以采取同样的方式进行检验。
