# Windows Anaconda Installation

+   1. Download the installer.
2. Double-click the .sh or .exe file. Anaconda will show the instructions on the screen.
3. Follow the instructions.

图 1.3 Anaconda Windows 版下载页面

以 Window 系统内置 Python 3.5 的安装版本下的 Anaconda 为例，成功安装后，打开 Anaconda Prompt 或者通过控制台切换到 Anaconda 的安装目录下，输入指令 “conda list” 并按 Enter 键即可查看已经成功安装的包。如下所示：
