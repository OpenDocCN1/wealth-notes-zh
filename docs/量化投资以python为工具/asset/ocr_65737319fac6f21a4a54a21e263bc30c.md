# 32.3.3 J 指标计算

J 指标是 KD 指标的辅助指标，进一步反映了 K 指标和 D 指标的乖离程度。第 t 日 J 值计算公式为：

$$J_t = 3 \times K_t - 2 \times D_t$$

其中， $J_t$ 为第 $t$ 日 J 值， $K_t$ 为第 $t$ 日 K 值， $D_t$ 为第 $t$ 日 D 值。
