```

```

第二个模型中各个变量的系数和第一个模型中这些变量的系数相差并不是很大，符号也都未变。这更加说明我们没有必要加入 `pl_c` 与 `pl_k` 这两个变量。

最终，我们得到的模型为：

```
$$\log (rgdp_e) = 8.3558 - 1.1296pl_i + 1.5452pl_g + 6.0596pl_m - 3.0228pl_x + \varepsilon$$
```
