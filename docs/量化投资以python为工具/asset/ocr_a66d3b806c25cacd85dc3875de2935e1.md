# 12.4.2.1 多个子图绘制

在实际绘图中，如果一个Figure对象中包容多个Axes对象，每个Axes对象的位置除了通过区域坐标和长度来设定以外，更为常用的方式是通过子图subplot（）函数来设定。

```
```
In [7]: ax1=plt.subplot(221)
   ...: ax2=plt.subplot(222)
   ...: ax3=plt.subplot(223)
   ...: ax4=plt.subplot(224)
```
```

参数“221”中的“22”表示子图排列为2×2形式，“1”表示第一个子图。同样道理，“222”中的最后一个2表示第“2”个子图，如图12.30所示。
