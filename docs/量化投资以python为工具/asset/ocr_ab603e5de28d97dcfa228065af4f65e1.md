# 移动型 OBV

移动型 OBV 是由累积 OBV 进行简单移动平均得到，一般选择 9 日或者 12 日 为时间跨度，移动型 OBV 的计算公式为：

$\begin{array}{c}smOBV_{t} = \frac{OBV_{t} + OBV_{t-1} + \cdots + OBV_{t-8}}{9}, \quad t = 9, 10, \cdots\end{array}$

用 Python 计算青岛啤酒股票的移动型 OBV 值。
