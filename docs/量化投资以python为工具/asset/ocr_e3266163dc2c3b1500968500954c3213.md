# 位置索引与切片

通过位置提取特定的数据与标签切片类似，不过是用 `df.iloc[row_indexer, column_indexer]` 进行操作：

```
# 提取某行
In  [24]: df.iloc[2]
Out[24]:
A      0.318700
B     -0.357701
C     -1.503945
D     -0.417211
Name: 2016-01-03 00:00:00, dtype: float64
```

```
# 提取某列
In  [25]: df.iloc[:,2]
Out[25]:
2016-01-01  -0.312846
2016-01-02   1.064430
2016-01-03  -1.503945
2016-01-04   1.541127
2016-01-05   0.125405
2016-01-06   0.950862
Name: C, dtype: float64
```

```
# 提取某几行与某几列
In  [26]: df.iloc[[1,4],[2,3]]
Out[26]:

            C        D
2016-01-02  1.064430  0.598022
2016-01-05  0.125405 -1.496913
```

```
# 切片
In  [27]: df.iloc[1:4,2:4]
Out[27]:

             C         D
2016-01-02  1.064430  0.598022
2016-01-03 -1.503945 -0.417211
```
