# 24.5.3 模型诊断

建立好模型以后，我们需要对模型进行评价。这里的评价不仅包括系数显著性的检验，还包括对残差序列是否为白噪声的检验。如果残差序列是白噪声序列，则说明我们的模型已充分提取了序列的信息，无法再通过调整模型从数据中获取更多的信息，因而模型的建立是成功的。如果残差序列是非白噪声序列，则说明我们的模型是不完善的，需要对其进行修正。
