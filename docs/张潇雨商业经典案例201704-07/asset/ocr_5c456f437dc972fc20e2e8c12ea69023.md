# PayPal | 神秘武器——“增长黑客”

思考题：你印象里有哪些把劣势变为优势的案例？

在“得到”每天听本书《逆转》里说过一个例子：在之前的律师行业，就太人是被嘲视的，即使是从常春藤盟校毕业出来，也只能接收比较“次级”的法律业务，比如企业诉讼文案；而当时的主流律师都是接收像公司发行股票、债券等的高级业务。后来隔了一段时间，随着企业的蓬勃崛起，企业诉讼案也相对地提高，而这时候就太人以前处理诉讼案所积累的经验瞬间转变为优势，在法律界成为大家想要争夺的稀缺资源，他们的机会终于来了。

在《极简人类简史》一书中讲到，人类的祖先本来是树上猴猿活得最差的一支，在树上的这个环境里它们是处于劣势的，后来更离奇的是被赶下了树。被迫在陆地上面对种种限制、各种危险的挑战。

用好的创意来弥补自身的不足，许多时候这样的办法非常管用。把原本广告花的钱省掉直接给产品的用户，让PayPal成功获取了第一批用户，可谓创意十足并且也创立了一种全新的产品广告模式。

> “当你挤进狭小的停车场时，当你支付那少少量的保险金时，当你支付修理账单时，或者当你用旧大众换新大众时，请想想小的的好处。”

我理解的增长黑客，更多是通过改变游戏规则去获取利益，利用边缘化的创新手段，绕开主战场和竞争主力，实现目的，最终实现变劣势为优势。

# PayPal | 护城河理论之“网络效应”

思考题：说说你对网络效应的理解？有哪些产品你觉得是拥有这些护城河的？

来聊和微信都是具有网络效应的产品，为什么一个成功一个被淘汰了呢？原因很可能是来聊推出后用户没有迅速达到关键数量，产生网络效应；而微信利用QQ和手机通讯录迅速达到关键数量，产生强大的网络效应，奠定了市场的垄断地位。

为了达到产生网络效应的关键数量，所以像PayPal、滴滴这样的公司都采用了直接补贴获取用户的方法，实践证明这些方法的确有效。
