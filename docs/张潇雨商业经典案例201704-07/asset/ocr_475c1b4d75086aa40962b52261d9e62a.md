# 发刊词 | 价值万亿美金的经验与方法

价值万亿美金的经验与方法，听起来有点令人听闻，但仔细想想，的确有其中的道理。

让我们把时间调回1996年12月20日，这一天，苹果宣布收购NeXT公司。这家公司的创始人正是史蒂夫·乔布斯，在经历了长达11年的“放逐”生涯后，乔布斯终于回归了苹果。

当时苹果的境况极惨，市值一路跌到了30亿美金，并且每天还在缩水。有一次戴尔电脑的创始人迈克尔·戴尔被问到：如果没有任何答案？？？？？

但故事的结局你已经知道了。戴尔公司如今已经退市，成了一家在业界无足轻重的公司。而苹果在乔布斯回归之后的二十年里一路狂奔，现在已经是价值超过7000亿美金的巨无霸，稳坐公司市值世界第一的宝座。

![](bbox=[0.25, 0.79, 0.92, 0.94])

乔布斯在这一二十年都做了什么事情？他精简了苹果的产品线，督促公司保持专注；下调了员工期权的价格，为大家重建工作动力；重新设计了“非同凡想”的口号，为品牌确立新的定位；他还推出了赢得年轻人好感的iPod、不顾众反建了苹果线下零售店、重整了Mac电脑系列产品、推出了改变世界的iPhone、开启了应用商店App Store、推出了iPad，顺便还把皮克斯打造成了世界上最好的动画电影公司……然后以74亿美的天价卖给了迪士尼。
