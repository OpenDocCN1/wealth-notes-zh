# 迪士尼 | 装了内容引擎的赚钱机器（1/5）

今天我们进入一家新的公司：伟大的迪士尼。

对于迪士尼，你可能一点也不陌生。它是目前全世界最大的娱乐公司，市值超过1800亿美金。可以做个简单的对比，同样是娱乐业的公司，之前在A股上市的万达院线，市值还不到100亿美金。

关于迪士尼有一个很有意思的现象，如果你熟悉这几年的中国娱乐影视界，你会发现，人人都有一个迪士尼梦。不管是万达、华谊、乐视，甚至是网文写作起家的唐家三少，都提过一个概念，叫“做中国的迪士尼”。不过至少目前看来，大家离这个愿景还有点遥远。

我很能理解这种愿望。因为迪士尼这家公司的价值，不只是1800亿美金这个数字这么简单，它除了在整个商业史上是第一娱乐帝国以外，迪士尼独特又巧妙的商业模式才是它引起各娱乐公司竞相模仿的最重要原因。所以今天的专栏，我们就来讲讲迪士尼的商业模式，也是它最值得思考的一个方面。

另外，迪士尼这家公司规模大、历史长。在它超过90年的历史里，有很多值得讲述的故事和商业案例，之后我们都会讲到。而在讲完迪士尼之后，我也会结合前五周的内容，重点给大家说说我研究商业史和公司的方法论。

# 收入结构

首先，分析一下迪士尼目前业务收入的构成。我们之前的专栏比较少提到数字层面的事情，之后随着专栏的深入，我也会带领大家一起做一些定量分析，这样你再看一家新的公司的时候，自己就能上手分析了。

现在我给你几秒钟，让你猜猜迪士尼这家巨无霸企业，它最大的收入来源部门是什么？

按照2016财务年度的数据，现在迪士尼一年的收入大概在550亿美金左右，有四大业务板块，分别为，影视娱乐、媒体网络、主题乐园与度假村，以及消费品与互动媒体。它们每年给迪士尼贡献的收入占比分别为，17%、43%、30%和10%。如下图所示：

你会突然发现，迪士尼的收入构成和我们想象的很不一样，最熟悉的电影和动画片部分，也就是“影视娱乐”部分，占比只有17%；同样是大 家熟知的迪士尼乐园部分，也只占30%；最大的贡献来自于“媒体网络”部分，占比超过40%。

"媒体网络"主要是指电视。你可能不知道，这部分最大的收入来源是一个叫ESPN的电视网，每年给迪士尼贡献100亿美金左右的收入。而它的核心产品是，体育。所以迪士尼算是真正做到了文体不分家。

# 《冰雪奇缘》：全产业链的案例分析

下面，我用一个案例来详细讲讲迪士尼全的产业链模式。

2013年，迪士尼上演了一部卖座动画片《冰雪奇缘》（Frozen）。这部电影一出来就让人耳目一新，因为这不仅是迪士尼最ԥ长的公主类故事，制作非常精良。同时又有新意，因为这个电影最后和王子没什么关系，是两个公主在一起了。
