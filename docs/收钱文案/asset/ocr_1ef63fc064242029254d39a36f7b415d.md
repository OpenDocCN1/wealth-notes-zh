# 举例：“推荐+好处+呼吁行动”公式

直接推荐其他人的产品或服务，说明产品的特点和好处，然后呼吁行动！

【普洱茶】给你推荐一款非常好喝的普洱茶，汤色如红酒，入口茶汤厚实，喝下去后，喉部甘甜，此时满口皆是普洱的陈香味。这是我去香格里拉发现的！如果你感兴趣，可以直接加她微信 xxxxxx 购买。

你可以把这条文案改成：

【小项目】给你推荐一个最近很火的项目，一天可以轻松收入 500 -1000，已稳定运营 3 年，时间自由安排。我朋友的妈妈 60 岁都在操作中，乐此不疲。如果你感兴趣加微信 xxxxxx，可以了解一下。

是不是很简单？

每个公式中的样例，基本上都有通用的关键词或句式，比如刚才的公式，关键句式是：

给你推荐一款/个......如果你感兴趣......

你按照公式和句式，写下你的文案即可。

在每条公式最后，我为你准备了一个练习，需要你动手把“关键词或句式”列到表格里。这样可以锻炼你的写作肌肉，提升写作水平。

你可以举一反三，根据公式和关键词写出文案。这样你就有了比竞争对手，更多的文案素材，能够源源不断地创作
