# ① XX 土蜂蜜

如何才能知道哪种蜂蜜是土蜂蜜？

第一、看，好的土蜂蜜色泽清逸，光亮如油，舀起一勺，你会看到绵柔顺滑，很温润的感觉，让你忍不住就想舔上去。

第二、闻，好的土蜂蜜会散发出淡淡的、纯净的芳香。

第三、尝，好的土蜂蜜甜而不腻，口感绵柔细腻，不涩不苦不酸。

XX 土蜂蜜，就是这种好的土蜂蜜，赶快做我尝尝吧！

# ② XX 橄榄油

怎样才算是高品质的橄榄油？

第一、观，油体透亮，浓，呈金绿色，或金黄色，颜色越深越好。而精炼的油中色素及其它营荞成份被破坏。

第二、闻，有果香味，不同的树种有不同的果味。

第三、尝，口感爽滑，有淡淡的苦味，及辛辣味，喉咙的后部有明显的感觉，辣味感觉比较滞后。

XX 橄榄油，就是这种高品质的橄榄油，你吃了还想吃！
