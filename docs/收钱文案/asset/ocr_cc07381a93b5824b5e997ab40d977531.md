# 88、采访+故事+结果+需求+呼吁

用第三者采访的方式，去访问创始人的创业过程，然后提炼出一个情景故事，以这个故事为引子，告诉受众他是如何做到的。最后，呼吁有类似需求的受众，可以咨询或购买产品。

# ① 神笔文案创始人

昨日，去北京采访了神笔文案创始人李炳池老师。25年前，他在经营摩托车生意的时候，连续10天都没有卖掉一辆！

他很着急！他需要让多人知道他的店。于是，他把能找到的各种广告文案书籍全部买回来学习，亲自撰写广告文案。

然后骑着摩托车，翻山越岭，到各个山村挨家挨户发自己写的宣传单......

没想到，他的宣传单就像24小时不停歇的销售员，不断地为他带来客户咨询、购买，有时候一天都能轻松成交10辆！

这让他成了当地小有名气的摩托车大王。
