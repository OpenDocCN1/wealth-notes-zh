# 收钱文案

这里使用的销售诉求 是独特和奉承。让读者感觉自己与众不同——我们谁不想被认 为是“独一无二”的呢？

短段落和短句子让这封信可读性更强。

注意，这封销售信是在销售提议——试驾玛莎拉蒂，并免费得到一瓶香槟的机会——而不是汽车本身。

非你莫属。这句话有点老套？我曾经也这么认为，直到我试图找到你。

现在，我知道“非你莫属”的真正含义了。

寻找你的名字和地址的过程，就像淘金一样。

问题在于什么？在于，我怎么才能找到那些愿意试驾（在他们自己的家里）新“玛莎拉蒂总裁”豪车的人呢？

我怎么找到那些具有独特的鉴赏力的人，对我们提供的免费法国香槟，以及对独一无二的豪车，无与伦比的试驾体验说“是”的人呢？

解决方案？好吧，我希望我要找的那个人就是你。

你是那种会买玛莎拉蒂的人吗？

那些选择玛莎拉蒂豪华轿车的人，并不是非得买最贵车的人。因为玛莎拉蒂不是最贵的车。比如，它只有劳斯莱斯价格的大约一半。

那些会选择玛莎拉蒂豪华轿车的人，也不是那种寻找身份地位象征的人。
