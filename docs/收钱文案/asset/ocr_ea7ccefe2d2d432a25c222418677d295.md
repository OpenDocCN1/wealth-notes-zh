# 98、确认回复+请求帮助+互动过程+问卷+期待回复

有时候，出于各种原因，有些潜在客户不会对你回复他的信息做出回应。很多公司会发出一封，或多封跟进信，希望得到没有回应的潜在客户的回复。

下面是来自 IBM 公司的一封跟进信。在一封信中，你可以把第一句话当做标题，用在信的顶部，就像这封信一样。

这封跟进信非常友好。措辞的选择（如，“你可以帮我们一个忙，回答问卷中的几个问题吗？”“不知道我们给你寄的资料，是否解答了你的所有疑问？需要我提供更多的帮助吗。”），让这封信看起来是 IBM 公司在试图帮助读者，而不是要读者给自己做什么事。

不过，如果撰稿人在信中详细描述他们的产品，及其主要好处，提醒读者他之前咨询了哪些信息，以及为什么他的回复对他很重要，效果会更好。

我又给你发信息了，因为我们没有收到你的回复。

你可以帮我们一个忙，回答问卷中的几个问题吗？

前段时间，你来信咨询我们的分析仪器，我们非常开心地给你寄去了有关资料。
