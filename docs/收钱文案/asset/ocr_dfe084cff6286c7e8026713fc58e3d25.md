# 96、坏信息+好消息+零风险保证+呼吁行动

这封信实现了两个目的（a）更新微信好友，（b）同时要求客户购买。这是简单有效的直邮案例。

请注意个人化的使用：“亲爱的XXX（人名）”称呼。
