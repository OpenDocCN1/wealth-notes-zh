# 收钱文案

如果要我推荐一位实战型的文案老师，
我都想向您推荐李炳杰老师

在我创立正显集团以来，文案写作一直是我的心中的“痛”。
我明白，如果公司少了文案这门绝活，每年都会至少损失
几百万的利润。

我开始到处寻找文案方面的学习班，很多课程只是当时学习
兴奋，过后实施得不到自己想要的结果，因为只为文案
写作热迷了心，文案成为挥之不去的“苦药”。

在文案学习这条路上我们后花了10多万，一直不得其法，
有时甚至怀疑自己是不是这块料。

其实我早于前三年就知道了李炳杰老师，也深信李老
师的文案功力，但李老师一直没有开线下的课程，让我及
大的遗憾。

2017年偶尔一次机会，见到李老师开班线下的文案，我全
身的血液都兴奋，三秒钟都没有考虑，以尽快态度打了款，
为信任而买单，为价值而买单。我不想再浪费时间了。

到现场后，《收钱文案》课程完全震惊了我。李炳杰老师在
课程里把李教做双场的手段，归是到每个双场的话术，简直
是叹为观止。我亲见见过一位年近五十的老大哥《对文
案的理解完全是一个白），竟然在该课程里，写出一封极
具杀伤力的收钱文案，连我这个互联网营销老鸟看了都有
一种想要买的冲动...

回到公司，我对正显集团的原文案，成交型文案，软文等....
按李老师的方法进行了改造，现在几乎写成交型文案都
可以收取10万以上的现金，而且以后还可以有更大的挖
挖空间…我有信心在2018年可以多做300万以上！！

在这里我可肯定的讲，李炳杰老师是文案这个领域的中国
NO. 1，建议你不可以不吃他。不够完，但是一定要来学习
进改变你命运的。
