# 如何使用呢？

首先，你大致浏览本书，心中有个印象，知道里面都是什么。

然后，你可以按照目录，选择你需要的公式和模板，改编或撰写你的文案。

或者，你也可以从头看到尾，熟悉每个公式和样例。当你写文案时，你大脑中就知道，应该参照哪条公式和例子去写，这样就能更有针对性。

当然，所有 103 条公式和列举的例子，你要灵活使用……不是说卖茶叶的文案，就不能改编成卖项目的文案，完全可以！

因为每条公式都是从“人性”的角度出发，有规律可循，它们的目的就是吸引顾客，最终让顾客采取行动。
