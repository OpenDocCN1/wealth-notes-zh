# 如何让爆款的直通车点击率翻倍

这个方法的原理是利用首位的直通车点击率最高，用相对低的ppc拿大流量。

首先宝贝本身要好，必须是爆款，各种详情页评价优化到位以后再开始推，测到一张高于行业平均点击率的图，比如我测出来这张是7%左右，行业平均是5%左右。

第一步建立一个标准计划，关键词出价，设置到首条的价格的一半，然后用抢位助手设置到溢价200%，接着走一个点击率持续拉升的7天螺旋，每天的ppc都会降。

因为卡在直通车首位，原本7%点击率的图，点击率变成了百分之九十。
