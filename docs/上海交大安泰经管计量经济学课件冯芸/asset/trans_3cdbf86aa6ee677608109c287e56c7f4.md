## 如何补救？
- 修正OLS估计量的方差公式
  - 利用正确的公式计算普通最小二乘估计值的方差（怀特异方差校正）
- 寻找新的估计方法
  - 加权最小二乘法WLS：对取自较小（大）方差总体的观察值以更大（小）的权重。

## 对原模型进行变换

$y_i = \beta_0 + \beta_1 x_i + u_i$

假定已知 $\sigma_i^2 = Var(u_i \mid x_i) = \sigma^2 h(x_i)$

$\frac{y_i}{\sqrt{h_i}} = \beta_0 \frac{1}{\sqrt{h_i}} + \beta_1 \frac{x_i}{\sqrt{h_i}} + \frac{u_i}{\sqrt{h_i}}$

$u_i^* = \frac{u_i}{\sqrt{h_i}}$

$Var(u_i^* \mid \cdot) = Var\left(\frac{u_i}{\sqrt{h_i}} \mid \cdot\right) = \frac{Var(u_i)}{h_i} = \sigma^2$

## 对原模型进行变换（续）

$y_i^* = \frac{y_i}{\sqrt{h_i}},\; x_{0i}^* = \frac{1}{\sqrt{h_i}},\; x_{1i}^* = \frac{x_i}{\sqrt{h_i}},\; u_i^* = \frac{u_i}{\sqrt{h_i}}$

$y_i^* = \beta_0 x_{0i}^* + \beta_1 x_{1i}^* + u_i^*$

对变换后的模型 运用OLS法，即
\[ \min_{\hat{\beta}_0,\hat{\beta}_1} \sum (u_i^*)^2 = \min_{\hat{\beta}_0,\hat{\beta}_1} \sum (y_i^* - \beta_0 x_{0i}^* - \beta_1 x_{1i}^*)^2 \]
\[ = \min_{\hat{\beta}_0,\hat{\beta}_1} \sum \frac{1}{h_i} (y_i - \beta_0 - \beta_1 x_i)^2 \]
\[ = \min_{\hat{\beta}_0,\hat{\beta}_1} \sum \frac{1}{h_i} u_i^2 \]
权系数 $w_i = \frac{1}{h_i}$

## 利用EViews程序完成的数据仿真：
异方差的影响

设已知总体回归函数如下： y_i = β₀ + β₁x_i + u_i =1+2x_i + u_i, 其中 u_i ~ N(0,σ_i²), 即存在异方差, 并且知道异方差函数形式为 σ_i² = 2x_i²。已经 x_i 有 200 个观察值, 分别为 1, 2, 3, 4, 5, …… , 19, 200。请建立一个工文件, 将 x_i 的样本数据保存为一个序列对象。同时将工作文件的 range 更改为 1 至 10000

- 1） 编写 EViews 程序完成以下步骤：利用普通最小二乘法（即 OLS 方法）估计上述模型参数, 并且循环 10000 次, 得到 10000 个 β₀ 和 β₁, 分别记为 β̂_ols,0 和 β̂_ols,1, 并分别计算它们的样本均值和样本方差。
- 2） 利用加权最小二乘法估计上述模型参数, 并且循环 10000 次, 得到 10000 个 β₀ 和 β₁ 的估计值, 分别记为 β̂_wls,0 和 β̂_wls,1, 并分别计算它们的样本均值和样本方差。
- 3） 试比较（1）和（2）两种方法得到的参数估计值的样本方差, 哪种方法得到的估计的样本方差更小, 为什么？
