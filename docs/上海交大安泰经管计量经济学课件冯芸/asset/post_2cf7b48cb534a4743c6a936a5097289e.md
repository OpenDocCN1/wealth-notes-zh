## 异方差的定义

- **MLR.5 同方差性**
  
  $Var(u_i \mid x_{1i}, x_{2i}, \cdots, x_{ki}) = \sigma^2$

- **MLR.5 不满足** ⇒ 异方差性
  
  $Var(u_i \mid x_{1i}, x_{2i}, \cdots, x_{ki}) = \sigma_i^2$

## 异方差的影响

Var(u_i | ·) = σ_i²

β̂₁ = β₁ + Σ k_i u_i = β₁ + Σ [ẋ_i / Σ ẋ_i²] u_i

Var(β̂₁) = Σ ẋ_i² σ_i² / (Σ ẋ_i²)² = Σ ẋ_i² σ_i² / SST_x²

同方差： Var(β̂₁) = σ² / Σ ẋ_i²， Var(β̂₁) = σ̂² / Σ ẋ_i²

异方差（White公式）： Var(β̂₁) = Σ ẋ_i² σ_i² / (Σ ẋ_i²)²， Var(β̂₁) = Σ ẋ_i² û_i² / SST_x²

Var(β̂_j) = Σ r_ij² û_i² / [(1 - R_j²) SST_j]²

## 异方差的影响（续）

- 对**OLS**参数估计值一阶矩的影响：不影响无偏性
- 对**OLS**参数估计值二阶矩的影响：
  - 基本假定下推导得到**OLS**估计量的方差公式不再适用（有偏的），其本质是由于σ²的估计是有偏的，因此建立在*t*分布和*F*分布上的置信区间和假设检验是不可靠的
  - 即便修正**OLS**估计量的方差公式，**OLS**估计量也不具有最小方差性
