## 更理想的概率模型

- 随着 $x_i$ 的增加， $p_i = E(y=1 \mid x)$ 也增加，但不超出 0-1 区间。
- 随着 $x_i$ 的增加，概率趋于 1 的速度越来越慢，随着 $x_i$ 的减小，概率趋于 0 的速度也越来越慢。

![](img/27e6f65397bb7fd3eced98a716a58f50_450_0.png)

## 线性概率模型

$p_i = \beta_0 + \beta_1 x_i$

$p_i$ 对 $x_i$ 有非线性关系

## 逻辑斯蒂分布函数

$p_i = \frac{1}{1+e^{-(\beta_0+\beta_1x_i)}}$

## 正态分布函数

$p_i = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\beta_0+\beta_1x_i} e^{-t^2/2}\,dt$

## 对数单位模型（Logit Model）

p_i = E(y_i | x_i) = 1 / (1 + e^{-(β0 + β1 x_i)})

设 z_i = β0 + β1 x_i

L_i = ln(p_i / (1 - p_i)) = z_i = β0 + β1 x_i，称 L 为对数单位

p_i / (1 - p_i) 为机会比率（odds ratio）

称模型为对数单位模型

## 模型的估计方法：极大似然估计
MLE

p_i = E(y_i | x) = G(x_i β) = 1 / [1 + e^{-(β0 + β1 x1i + ... + βk xki)}]

f(y_i | x) = [G(x_i β)]^{y_i} [1 - G(x_i β)]^{1 - y_i}, y_i = 0,1

l_i(β)

log[f(y_i | x)] = y_i log[G(x_i β)] + (1 - y_i) log[1 - G(x_i β)]

L(β) = Σ_{i=1}^{n} l_i(β)

## Probit和Logit模型的估计： MLE

max_{β̂} L(β)

= max_{β̂} Σ_{i=1}^{n} l_i(β) =

= max_{β̂} Σ_{i=1}^{n} { y_i log[ G(x_i β) ] + (1 - y_i) log[ 1 - G(x_i β) ] }

## Logit模型估计值的解释

概率的计算

$\hat{L}_i = \ln(\frac{\hat{p}_i}{1 - \hat{p}_i}) = \hat{\beta}_0 + \hat{\beta}_1 x_i$

$\hat{p}_i = \frac{e^{\hat{\beta}_0 + \hat{\beta}_1 x_i}}{1 + e^{\hat{\beta}_0 + \hat{\beta}_1 x_i}}$

## Logit模型估计值的解释

概率变化率的计算

$L_i = \ln\left(\frac{p_i}{1-p_i}\right) = z_i = \beta_0 + \beta_1 x_i$

$\frac{dL_i}{dx_i} = \beta_1 = \frac{dL_i}{dp_i}\frac{dp_i}{dx_i}$

$= \frac{1-p_i}{p_i}\frac{1-p_i - p_i(-1)}{(1-p_i)^2}\frac{dp_i}{dx_i} = \frac{1}{p_i(1-p_i)}\frac{dp_i}{dx_i}$

$\frac{dp_i}{dx_i} = \beta_1 p_i (1-p_i)$

## 股票近期表现

- 个股近期价格上涨幅度越大，投资者卖出可能性越大
- 投资者资金规模越小，近期价格上涨对投资者卖出行为影响越大，且影响时间越长
- 个股价格的下跌对卖出倾向影响并不显著
