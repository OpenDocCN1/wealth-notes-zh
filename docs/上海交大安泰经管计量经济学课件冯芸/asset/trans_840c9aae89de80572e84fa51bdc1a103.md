

## 双曲函数模型

$y_i = \beta_0 + \beta_1 \frac{1}{x_i}$

当 $x_i \to \infty$ 时，$y_i \to \beta_0$。

## 多项式函数模型

- **例子：总成本函数**
  - 线性成本函数 $y_i=\beta_0+\beta_1x_i$：边际成本不变
  - 三次型 $y_i=\beta_0+\beta_1x_i+\beta_2x_i^2+\beta_3x_i^3$：边际成本递增

![](img/27e6f65397bb7fd3eced98a716a58f50_362_0.png)

![](img/27e6f65397bb7fd3eced98a716a58f50_362_1.png)

$\frac{dy}{dx} > 0$，且当产量达到一定规模后，边际成本递增 $\frac{d^2y}{dx^2} > 0$。

$MC = \beta_1 + 2\beta_2x_i + 3\beta_3x_i^2$，即 $3\beta_3\left(x_i + \frac{\beta_2}{3\beta_3}\right)^2 + \beta_1 - \frac{\beta_2^2}{3\beta_3}$。为保证 $MC > 0$，且有正的极小值，因此 $\frac{d^2(MC)}{dx^2} = 6\beta_3 > 0$，对参数有以下约束：

- （1）$\beta_3 > 0$
- （2）极小值点 $x^* = -\frac{\beta_2}{3\beta_3} > 0$，因此 $\beta_2 < 0$。
- （3）极小值点 $y^* = \beta_1 - \frac{\beta_2^2}{3\beta_3} > 0$，即 $3\beta_1\beta_3 > \beta_2^2$，且 $\beta_1 > 0$。
- （4）$x_i = 0$ 时，总成本 $y_i = \beta_0 > 0$。

## 三、导致模型失效的可能之二：解释变量的选择

- 遗漏变量
- 多余变量

### 遗漏相关变量的影响

$$\tilde{\beta}_j = \hat{\beta}_j + \hat{\beta}_k \hat{\alpha}_j$$

$$y_i = \hat{\beta}_0 + \hat{\beta}_1 x_{1i} + \hat{\beta}_2 x_{2i} + \cdots + \hat{\beta}_j x_{ji} + \cdots + \hat{\beta}_{k-1} x_{k-1,i} + \hat{\beta}_k x_{ki} + \hat{u}_i$$

$$y_i = \tilde{\beta}_0 + \tilde{\beta}_1 x_{1i} + \tilde{\beta}_2 x_{2i} + \cdots + \tilde{\beta}_j x_{ji} + \cdots + \tilde{\beta}_{k-1} x_{k-1,i} + \tilde{u}_i$$

$$x_{ki} = \hat{\alpha}_0 + \hat{\alpha}_1 x_{1i} + \hat{\alpha}_2 x_{2i} + \cdots + \hat{\alpha}_j x_{ji} + \cdots + \hat{\alpha}_{k-1} x_{k-1,i} + e_i$$

一个例子：

正确模型：$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u$

遗漏变量模型：$y = \alpha_0 + \alpha_1 x_1 + v$

辅助回归模型：$x_2 = \gamma_0 + \gamma_1 x_1 + e$

事实上，遗漏变量模型不满足 MLR3（严格外生解释变量）。

OLS 参数估计量有偏：

$$\hat{\alpha}_1 = \hat{\beta}_1 + \hat{\beta}_2 \hat{\gamma}_1$$

$$E(\hat{\alpha}_1 \mid \cdot) = \beta_1 + \beta_2 \hat{\gamma}_1 \neq \beta_1，当 \beta_2 \neq 0 且 \hat{\gamma}_1 \neq 0 时$$

$$E(\hat{\alpha}_0 \mid \cdot) = \beta_0 + \beta_2 \hat{\gamma}_0 \neq \beta_0，当 \beta_2 \neq 0 且 \hat{\gamma}_0 \neq 0 时$$

$$\frac{\sum \hat{v}_i^2}{n-2} 是 \sigma_u^2 的有偏估计$$

$$\widehat{Var}(\hat{\alpha}_1) 是 Var(\hat{\beta}_1) 的有偏估计（上偏估计）$$

- OLS 还不是一致估计量。

### 包含多余变量的影响

一个例子：

正确模型：$y = \beta_0 + \beta_1x_1 + \varepsilon$

多余变量模型：$y = \alpha_0 + \alpha_1x_1 + \alpha_2x_2 + \nu$

应有 $\alpha_2 = 0$，$\alpha_1 = \beta_1$，$\nu = \varepsilon$

辅助回归模型：$x_2 = \gamma_0 + \gamma_1x_1 + e$

事实上，$\nu$ 和 $\varepsilon$ 都满足 MLR3（严格外生解释变量）。

OLS 参数估计量无偏：

$$\hat{\alpha}_1 = \hat{\beta}_1 - \hat{\alpha}_2 \hat{\gamma}_1$$

$$E(\hat{\alpha}_1 \mid \cdot) = \beta_1 - \alpha_2 \hat{\gamma}_1 = \beta_1$$

$$\frac{\sum \hat{\nu}_i^2}{n-3} 是 \sigma_\varepsilon^2 的无偏估计$$

$$Var(\hat{\alpha}_1) = \frac{\sigma^2}{(1-R_1^2)SST_1} \ge Var(\hat{\beta}_1) = \frac{\sigma^2}{SST_1}，只要 R_1^2 \ne 0，多余变量模型 OLS 参数估计总体方差大于真实模型中 OLS 参数估计的总体方差。$$

## 四、模型设定检验

- 嵌套模型选择：诊断多余变量或遗漏变量

$$y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \beta_3 x_{3i} + u_i$$

$$\frac{(R^2_{ur}-R^2_r)/q}{(1-R^2_{ur})/(n-k-1)} \sim F(q, n-k-1)$$

$R^2_{ur}$：无约束方程的拟合优度　$R^2_r$：约束方程的拟合优度

$q$：参数约束条件的个数

$H_0$：无约束模型与有约束模型无差异（即无约束模型存在多余变量问题）

$H_1$：无约束模型优于有约束模型（即有约束模型存在遗漏变量问题）

### RESET 检验

检验模型：$y = \beta_0 + \beta_1x_1 + \cdots + \beta_kx_k + u$ 是否遗漏重要的非线性关系

备选模型：$y = \beta_0 + \beta_1x_1 + \cdots + \beta_kx_k + \delta_1\hat{y}^2 + \delta_2\hat{y}^3 + u$

对应的假设检验：

$H_0: \delta_1 = \delta_2 = 0$

$$F = \frac{(R^2_{\text{新}} - R^2_{\text{旧}}) / \text{新引入的回归元的个数}}{(1 - R^2_{\text{新}}) / (n - \text{新模型中的参数个数})}$$

$$price_i = \beta_0 + \beta_1 lotsize_i + \beta_2 sqrft_i + \beta_3 bdrms_i + u_i$$
