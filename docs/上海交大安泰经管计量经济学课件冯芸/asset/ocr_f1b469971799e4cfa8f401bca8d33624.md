# 异方差的影响

Var(u_i | ·) = σ_i²

β̂₁ = β₁ + Σ k_i u_i = β₁ + Σ [ẋ_i / Σ ẋ_i²] u_i

Var(β̂₁) = Σ ẋ_i² σ_i² / (Σ ẋ_i²)² = Σ ẋ_i² σ_i² / SST_x²

同方差： Var(β̂₁) = σ² / Σ ẋ_i²， Var(β̂₁) = σ̂² / Σ ẋ_i²

异方差（White公式）： Var(β̂₁) = Σ ẋ_i² σ_i² / (Σ ẋ_i²)²， Var(β̂₁) = Σ ẋ_i² û_i² / SST_x²

Var(β̂_j) = Σ r_ij² û_i² / [(1 - R_j²) SST_j]²
