# 多个回归参数多个线性约束的联合假设检验（F检验）

$H_0$：模型线性关系不显著  ⇔  $H_0:\beta_1=\cdots=\beta_k=0$

更一般的联合假设  ⇔  $H_0:\beta_{k-q+1}=\cdots=\beta_k=0$

$$F=\frac{(SSR_r-SSR_{ur})/q}{SSR_{ur}/(n-k-1)}\sim F(q,n-k-1)$$

或 $$F=\frac{\left(\frac{SSR_r-SSR_{ur}}{SST}\right)/q}{\left(\frac{SSR_{ur}}{SST}\right)/(n-k-1)}=\frac{(R^2_{ur}-R^2_r)/q}{(1-R^2_{ur})/(n-k-1)}\sim F(q,n-k-1)$$

显著性水平 $\alpha$ 的拒绝域是 $F>F_\alpha(q,n-k-1)$
