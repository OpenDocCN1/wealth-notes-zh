## （一）概率和概率分布

- *随机试验*：至少有两个可能结果，但不确定哪一个结果会出现的过程。
- 例如抛硬币（正反两面）、掷骰子（六面体）、从一副纸牌（54张）中抽取一张

- **事件**：随机试验的可能结果组成的集合，它是样本空间的一个子集。
- 如果两个事件不能同时发生，则两个事件称为**互斥的**。

- 如果一个事件的发生与另一事件的发生可能性相同，则两个事件称为*等可能性*的。
- 如果可穷举试验的所有可能结果，事件称为*穷举事件*。

- 随机变量：取值由试验结果决定的变量
- 概率的古典定义（随机试验的*n*个基本结果互斥且等可能发生）：

P(A) = 属于事件A的基本结果的个数 / 所有基本结果总数

概率的频率定义：如果在n次试验或n个观察值中，m次属于事件A，假定n足够大，那么事件A的概率P(A)就简单地等于m/n（即频率）

## 概率的性质

- 0 ≤ P(A) ≤1

- 若事件A，B，C，......为互斥事件，则事件和的概率等于事件概率之和

- 若事件A，B，C，......为互斥事件，且为一完备事件组，则事件和的概率为1

- 如果事件 A，B，C，……不是互斥事件，则 P(A+B)=P(A)+P(B)-P(AB)
- **条件概率**：在事件 B 发生条件下，事件 A 发生的概率

$P(A\mid B)=\frac{P(AB)}{P(B)}$

- **概率分布或概率密度函数：** 随机变量的可能值以及与之相对应的概率值。
- 离散型随机变量的概率密度函数

```
f(X) = { P(X = x_i), 当 i = 1,2,3,⋯,n
0, 当 X ≠ x_i }
```

## （二）概率分布的特征

- 概率密度的矩
- 期待：随机变量的密度中心

E(X) = Σₓ X f(X)

E(X) = ∫ x f(x) dx

n阶原点矩: ∫ xⁿ f(x) dx

## 期望值的性质

- 常数的期望值为本身： $E(b)=b$

- 随机变量的和的期望值等于随机变量期望值的和： $E(X+Y)=E(X)+E(Y)$

- $E(X/Y) \neq E(X)/E(Y)$； $E(XY) \neq E(X)E(Y)$； $E(X^2) \neq [E(X)]^2$

- $E(aX+b)=aE(X)+b$

- **多元概率分布的期望值:**

$$E[XY]=\sum_x\sum_y xyf(XY)$$

- **条件期望:**

$$E[X\mid Y=y]=\sum_x xf(X\mid Y=y)$$

$$E[Y\mid X=x]=\sum_y yf(Y\mid X=x)$$

- ■ 方差：随机变量的分散程度

$Var(X) = \sigma_X^2 = E(X - \mu_X)^2$

$n$阶中心矩: $\int (x - \mu)^n f(x) dx$

## 方差的性质

- $\operatorname{Var}(X\pm Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)\pm 2\operatorname{Cov}(X,Y)$
- $\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$
- $\operatorname{Var}(X)=E(X^2)-[E(X)]^2$

条件方差:

Var[Y | X] = E{[Y − E(Y | X)] | X}²

## 协方差：两个随机变量的共同变动

$$\operatorname{Cov}(X,Y)=E(X-\mu_X)(Y-\mu_Y)$$
$$=E(XY)-\mu_X\mu_Y$$
