- 多元回归模型中的斜率项系数是在控制其它解释变量不变的情况下得到的偏效应。
- 为什么需要控制其它解释变量不变？

## 为什么需要控制其它自变量？

- 一个例子：打火机个数与患病概率
  - 家庭拥有的打火机的数量与家庭中身患癌症的人数之间是否存在因果关系？

![](img/27e6f65397bb7fd3eced98a716a58f50_219_0.png)

- 如果控制另一个解释变量（吸烟人数 $x_2$）不变，打火机的数量（$x_1$）与身患癌症的人数（$y$）之间可能就不存在显著的相关关系了。
- 如何“保持 $x_2$ 不变”呢？

## 如何控制其它自变量不变？

- 步骤1：
  $x_{1i}=\alpha_1+\alpha_2 x_{2i}+r_{1i}=\hat{\alpha}_1+\hat{\alpha}_2 x_{2i}+\hat{r}_{1i}=\hat{x}_{1i}+\hat{r}_{1i}$
  $\hat{r}_{1i}$是$x_1$中与$x_2$无关的部分

- 步骤2：
  $y_i=\theta_0+\theta_1\hat{r}_{1i}+\varepsilon_i$
  $\hat{\theta}_1$测算$x_2$不变的情况下，$x_1$对$y$的净影响

等价于多元回归$y_i=\beta_0+\beta_1 x_{1i}+\beta_2 x_{2i}+u_i$中$\beta_1$的估计$\hat{\beta}_1$

$E(y_i \mid x_{1i}, x_{2i}) = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i}$

- 偏回归系数：$\beta_1$度量当$x_2$保持不变的情况下，$x_1$每变化1个单位，$E(y|x_1,x_2)$的变化。
- 如果$x_1$和$x_2$不相关，$y$对$x_1$和$x_2$的多元回归中$x_1$的斜率项系数等于$y$对$x_1$的一元回归中的斜率项系数。

更一般地， $\tilde{\beta}_j = \hat{\beta}_j + \hat{\beta}_k \hat{\alpha}_j$

y_i = \hat{\beta}_0 + \hat{\beta}_1 x_{1i} + \hat{\beta}_2 x_{2i} + \cdots + \hat{\beta}_j x_{ji} + \cdots + \hat{\beta}_{k-1} x_{k-1,i} + \hat{\beta}_k x_{ki} + \hat{u}_i

y_i = \tilde{\beta}_0 + \tilde{\beta}_1 x_{1i} + \tilde{\beta}_2 x_{2i} + \cdots + \tilde{\beta}_j x_{ji} + \cdots + \tilde{\beta}_{k-1} x_{k-1,i} + \tilde{u}_i

x_{ki} = \hat{\alpha}_0 + \hat{\alpha}_1 x_{1i} + \hat{\alpha}_2 x_{2i} + \cdots + \hat{\alpha}_j x_{ji} + \cdots + \hat{\alpha}_{k-1} x_{k-1,i} + e_i

- 上述结论可以推广到任意$k$个自变量的情形。
- 多元回归不只是数学形式上的变化，其经济含义也不同于一元回归。
- 偏回归系数$\beta_j$：度量了在其它自变量不变的情况下，$x_j$每变动一个单位，$E(y|x)$的改变 量。

$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k + u$

## 总离差平方和的分解

- 总平方和 SST
  $$\sum (y_i-\bar{y})^2=\sum \hat{y}_i^2$$
- 解释平方和 SSE
  $$\sum (\hat{y}_i-\bar{y})^2=\sum (\hat{y}_i-\bar{y})^2$$
- 残差平方和 SSR
  $$\sum (y_i-\hat{y}_i)^2=\sum \hat{u}_i^2$$

## 三个平方和的关系

SST = SSE + SSR

拟合优度 R² = SSE / SST = 1 - SSR / SST = 1 - Σ e_i² / Σ ŷ_i²

## 四、参数估计量的评价准则

- 线性：估计量是样本观察值$y_i$的线性函数
- 无偏性：$E(\bar{y}) = \mu$, $E(\hat{\beta}) = \beta$
- 有效性：方差较小的估计量
- 最优线性无偏估计量（BLUE）：估计量是线性的和无偏的，并且在所有线性无偏估计量中方差最小

## 样本均值的抽样分布或概率分布

- 若 $y_1，y_2，……，y_n$ 是来自于总体均值为 $\mu$ 的一组随机样本，则样本均值是对 $\mu$ 的一个估计。该估计量是线性无偏估计量。

$$\bar{y}=\frac{1}{n}\sum_{i=1}^{n}y_i \qquad E(\bar{y})=E\left(\frac{1}{n}\sum_{i=1}^{n}y_i\right)=\mu$$
