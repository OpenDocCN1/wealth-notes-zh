# 遗漏相关变量的影响

OLS 参数估计量有偏

$$\hat{\alpha}_1 = \hat{\beta}_1 + \hat{\beta}_2 \hat{\gamma}_1$$

$$E(\hat{\alpha}_1 | \cdot) = \beta_1 + \beta_2 \hat{\gamma}_1 \neq \beta_1, \quad \text{当} \beta_2 \neq 0 \text{且} \hat{\gamma}_1 \neq 0 \text{时}$$

$$E(\hat{\alpha}_0 | \cdot) = \beta_0 + \beta_2 \hat{\gamma}_0 \neq \beta_0, \quad \text{当} \beta_2 \neq 0 \text{且} \hat{\gamma}_0 \neq 0 \text{时}$$

$$\frac{\sum \hat{v}_i^2}{n-2} \text{是} \sigma_u^2 \text{的有偏估计}$$

$$\widehat{Var}(\hat{\alpha}_1) \text{是} Var(\hat{\beta}_1) \text{的有偏估计（上偏估计）}$$
