MC = β₁ + 2β₂xᵢ + 3β₃xᵢ²，即 3β₃(xᵢ + β₂/(3β₃))² + β₁ - β₂²/(3β₃)，为保证

MC > 0，且有正的极小值，因此 d²(MC)/dx² = 6β₃ > 0，对参数有以下约束：

+   （1）β₃ > 0

+   （2）极小值点 x* = -β₂/(3β₃) > 0，因此，β₂ < 0。

+   （3）极小值点 y* = β₁ - β₂²/(3β₃) > 0，即 3β₁β₃ > β₂²，且 β₁ > 0。

+   （4）xᵢ = 0 时，总成本 yᵢ = β₀ > 0。
