## 进一步的问题：如何获知异方差形式

- 可行广义最小二乘（Feasible Generalized Least Squares）

估计 $h_i \to \hat{h}_i$

$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k + u$

$Var(u \mid x_1, x_2, \cdots, x_k) = \sigma^2 \exp\left(\delta_0 + \delta_1 x_1 + \delta_2 x_2 + \cdots + \delta_k x_k\right)$

$Var(u|x_1,x_2,\cdots,x_k)=\sigma^2 \exp(\delta_0+\delta_1x_1+\delta_2x_2+\cdots+\delta_kx_k)$

$u^2=\sigma^2 \exp(\delta_0+\delta_1x_1+\delta_2x_2+\cdots+\delta_kx_k)\,v$

$E(v|x_1,x_2,\cdots,x_k)=1$

$\log(u^2)=\log(\sigma^2)+\delta_0+\delta_1x_1+\delta_2x_2+\cdots+\delta_kx_k+\log(v)$

$\log(u^2)=\alpha_0+\delta_1x_1+\delta_2x_2+\cdots+\delta_kx_k+e$

$\log(\hat u^2)=\alpha_0+\delta_1x_1+\delta_2x_2+\cdots+\delta_kx_k+e$

$\log(\hat u^2)\;\hat g_i=\hat\alpha_0+\hat\delta_1x_1+\hat\delta_2x_2+\cdots+\hat\delta_kx_k,\text{或}\log(\hat u^2)=\hat\alpha_0+\hat\delta_1\hat y+\hat\delta_2\hat y^2$

$\hat h_i=\exp(\hat g_i)$

$w_i=1/\hat h_i$
