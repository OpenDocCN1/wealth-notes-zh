### 一、回归分析的含义

- 回归分析是用来研究一个变量（被解释变量或应变量）与另一个或多个变量（解释变量或自变量）之间的（因果）关系

- 为什么给定收入水平（x），仍会观察到不同的y？
- x并非唯一影响y的因素
- “其他因素”的数学处理：$y=f(x)+u$
- 但x是重要的具有系统性影响的因素
- 数学处理：对条件均值建模

  $E(u \mid x)=0$

  $E(y \mid x)=f(x)$

- y围绕它的条件均值上下波动

  $y = E(y \mid x) + u$

### 二、总体回归函数

$y = E(y \mid x) + u$

$E(y \mid x) = f(x)$

- $f(x)$称为总体回归函数

典型地 $f(x) = \beta_0 + \beta_1 x$

- 此时的$f(x)$称为线性回归函数
- $\beta_0$、$\beta_1$：待估参数或回归系数
  - $\beta_0$又称为截距项
  - $\beta_1$又称为斜率项

### 三、随机误差项 $u$ 的含义

![](img/27e6f65397bb7fd3eced98a716a58f50_174_0.png)

- 在解释变量中被忽略的因素的影响
- 变量观测值的观测误差的影响
- 其他随机因素的影响

### $E(u \mid x) = 0$ 意味着什么？

再利用重期望律（*Iterative Law of Expectation*，以下简称ILE）

$E(u) = E_x [ E(u \mid x) ] = 0$

$Cov(u, x) = E(u x) = E_x [ E(u x \mid x) ] = E_x [ x \cdot E(u \mid x) ] = 0$

- 如果随机误差项的条件期望为零，那么随机误差项的无条件期望也为零。
- 随机误差项与解释变量之间不（线性）相关的结论。
- y的变动由两部分组成：
  - 系统的或确定的部分 $E(y \mid x)$
  - 非系统的或随机的部分 $u$

### 四、线性回归的含义

- 参数线性

  $E(y \mid x) = f(x) = \beta_0 + \beta_1 x^2$

- 解释变量线性

  $E(y \mid x) = f(x) = \beta_0 + \beta_1 \frac{1}{x}$

- “线性”回归指

  $E(y \mid x) = f(x) = \beta_0 + \beta_1^2 x$

  对参数而言线性

- 回归分析关键在于对 $f(x)$，即被解释变量条件期望函数 $E(y \mid x)$（又称为总体回归函数）的识别上来。
- 即利用有限的样本数据信息尽可能准确地认识总体参数，称为统计推断过程

### 样本回归函数（SRF）：$\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i$

残差项：$\hat{u}_i = e_i = y_i - \hat{y}_i$

### 小结

- 回归分析
  - 从经济含义来看就是要寻找主要因果关系，因此它既承认真实世界的多向因果关系，又将重点置于主要矛盾。
  - 从数学处理来看就是要对条件均值建模。
  - 条件均值模型的选择中最为经典的是线性函数，称为线性回归模型，是指对参数而言线性。
- 回归分析
  - 回归分析关键在于对 $f(x)$（又称为总体回归函数）的识别，需要利用统计推断的方法
