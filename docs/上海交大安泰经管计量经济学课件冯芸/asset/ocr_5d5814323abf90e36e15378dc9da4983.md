# 另一种检验方法

$H_0: \theta_1=\beta_1-\beta_2=0 \qquad \beta_1=\theta_1+\beta_2$

$\log(wage)=\beta_0+\beta_1\cdot jc+\beta_2\cdot univ+\beta_3\cdot expr+u$

$\log(wage)=\beta_0+(\theta_1+\beta_2)\cdot jc+\beta_2\cdot univ+\beta_3\cdot expr+u$

$\log(wage)=\beta_0+\theta_1\cdot jc+\beta_2\cdot(jc+univ)+\beta_3\cdot expr+u$
