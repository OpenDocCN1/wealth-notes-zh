## （一）线性概率模型（LPM）

$y_i = \beta_0 + \beta_1 x_i + u_i$

$x_i$：家庭的收入

$y_i = \begin{cases} 1: \text{如果该家庭拥有住宅} \\ 0: \text{其它} \end{cases}$

$E(y_i \mid x_i) = \beta_0 + \beta_1 x_i$

$$E(y_i\mid x_i)=1\cdot p_i+0\cdot(1-p_i)=p_i$$

$$E(y_i\mid x_i)=\beta_0+\beta_1x_i=p_i$$

约束条件　$0\leq E(y_i\mid x_i)=\beta_0+\beta_1x_i\leq1$

## LPM的估计问题：$u_i$非正态性

- 随机误差项的非正态性，$u_i$服从贝努利分布
  
  当$y_i=1$时，概率$p_i$，$u_i=1-\beta_0-\beta_1x_i=1-p_i$
  
  当$y_i=0$时，概率$1-p_i$，$u_i=-\beta_0-\beta_1x_i=-p_i$

- 但OLS估计仍是无偏，此外，在大样本中，可沿用正态假定下的OLS方法。

## LPM的估计问题：$u_i$异方差

- 随机误差项的异方差性
- **OLS估计**仍是无偏，但不是有效的（即不具有最小方差性质）。

$$E(u_i\mid x_i)=(1-p_i)(-\beta_0-\beta_1x_i)+p_i(1-\beta_0-\beta_1x_i)=0$$

$$\operatorname{Var}(u_i\mid x_i)=(\beta_0+\beta_1x_i)(1-\beta_0-\beta_1x_i)=p_i(1-p_i)$$

## LPM的估计问题：预测值约束

约束条件 $0 \leq E(y_i \mid x_i) = \beta_0 + \beta_1 x_i \leq 1$ 不满足

- **方法一**：用OLS估计，如果因变量估计值为负，取为0；如果为大于1，则取为1。
- **方法二**：设计一种估计技术，以保证所估计的因变量一定落在$[0, 1]$上（例如Logit和Probit）。
