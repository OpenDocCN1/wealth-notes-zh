# 表 2 Logistic 模型中的变量说明

| 变量名称 | 符号 | 变量说明 |
|---|---|---|
| 是否摘帽 | Y | 1 表示经历过摘帽，0 表示未经历过摘帽 |
| 被 ST 原因 | ST CAUSE | 1 表示被 ST 原因与亏损有关，0 表示被 ST 原因与亏损无关 |
| 所属行业 | INDUS | 1 表示属于资源类行业，0 表示不属于资源类行业。其中资源类行业定义为包含能源矿产、金属矿产、非金属矿产和水气矿产的公司 |
| 公司规模 | INVALUE | 实施 ST 前一年公司股票总市值的对数 |
| 亏损程度 | LOSSVALU | 用被 ST 前一年公司的未分配利润除以总资产来衡量，其中未分配利润代表公司的累计亏损额 |
| 控股股东性质 | STATEOWN | 1 表示被 ST 前控股股东为国有股，否则为 0 |
| 控股股东持股比例 | LARGE | 被 ST 前第一大股东的持股比例 |
| 资产负债率 | DEBT | 实施 ST 前两年公司的资产负债率均值，度量公司债务状况 |
| 净资产收益率 | ROE | 实施 ST 前两年公司的净资产收益率均值，度量公司盈利能力 |
| 主营业务利润率 | ZYPRO | 实施 ST 前两年公司的主营业务利润率，度量公司的主业鲜明情况 |
