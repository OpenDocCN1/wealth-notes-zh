# 置信区间法

$H_0:\beta_1=0\Leftrightarrow$ 参数不显著（异于零）

$H_1:\beta_1\ne0\Leftrightarrow$ 参数显著（异于零）

在90%的置信水平上，$\beta_1$落在区间

$(18.50119-1.645\times11.12325,18.50119+1.645\times11.12325)$

即$(0.2035，36.7989)$，系数显著

在95%的置信水平上，$\beta_1$落在区间

$(18.50119-1.96\times11.12325,18.50119+1.96\times11.12325)$

即$(-3.3004，40.3028)$，系数不显著
