# 关于作者

除了博士学位，M.W.沙利文还攻读了 2 个硕士学位，2 个学士学位。他曾经还任教于乔特大学，波多黎各大学，马德里大学，耶鲁大学，马奎特大学和霍林斯学院。

沙利文博士是卡耐基公司授权的自动化教学媒体的主要研究者之一。他还管理 2 个国防教育的下属机构。

他写过 3 本书，7 个编程课程，以及许多其他出版物。沙利文博士现在是一个致力于设计培训材料的研究机构的总裁。
