# 6、一定要用最有价值的东西，
去运营陈昌文读书会和老板社群

我们的所有社群、我们的读书会，那么多群，我们每个老师在里面发的任何一句话必须是有价值的。从我们书上找有价值的话，或者你发的有价值的话，或者是在直播间讲的有价值，或者你的视频有价值。

**我们只允许给粉丝发有价值的东西，不允许发废话。**我们发的这一句话出去，必须对粉丝有帮助，你保证你发了这句话是为大家好 的，你才发。这个也是对社群的整体运营。

**我们读书会、社群内部的流量是相当大的，一定要用最有价值的东西去运营，用我们书上有价值的东西去运营这些群。**讲课要讲好，视频要做好，要往里面传播有价值的视频，一定要有价值，不允许在里面发垃圾信息。这样粉丝每天都会来看，而且会看上瘾。所以你们要去判断哪句话是垃圾信息。
