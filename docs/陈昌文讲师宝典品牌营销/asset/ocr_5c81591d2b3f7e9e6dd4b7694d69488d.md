# 必须打上《陈昌文解读《论语》》的标签

《陈昌文解读《论语》》是具有品牌影响力的关键词，用这个模式去宣传，去收单子。同时，我们用情感、营销等话题爆粉。爆粉的目的，还是为了变现，为了直播，为了打标签，为了精准定位人群。直播与视频的标签就是，“我主要讲的是儒家思想《陈昌文解读《论语》》。”必须打上儒家思想解读者标签、《论语》解读标签，然后营销、恋爱都是边角料，采取这个模式讲课、直播。

如此模式有什么好处？这样正能量化，讲啥都可以连接到儒家思想上，然后《论语》读书会会卖掉很多。这样，正面的东西就压制了可能出现的负面的东西。
