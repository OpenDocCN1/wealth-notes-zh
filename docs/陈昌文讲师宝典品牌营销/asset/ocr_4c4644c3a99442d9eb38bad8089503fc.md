# 打造个人品牌的好处是什么？

+   1、可以被动吸粉；
2、可以建立高端人脉；
3、可以社交到更多高端客户，服务价格更高；
4、客户会更信任你，因为你是一个有人设、有品牌的人；
5、你的一言一行，都将变成广告，都将具有传播力。

有个人品牌的人，比没个人品牌的人更容易被传播，而传播的次数多了，生意自然就好。拥有个人品牌的人，本身就是一个传播渠道，这个传播渠道就是口碑传播。拥有个人品牌的人，本身就会具备话题性，本能的会吸引很多人的自动关注与传播。如此，拥有个人品牌的人，自然具有影响力、渠道力、传播力。任何一个现代社会的老板、企业家，都应该拥有自己强大的个人品牌。如此模式，会让你在互联网时代做企业更轻松。
