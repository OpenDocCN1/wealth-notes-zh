# # 第十章

# 公开课，公开赚钱的秘密——我其实不是一个商人

这是中国文化当中缺失的一块，所以说我要把它补上来，就是我讲课，既讲善，也讲恶。所以你们很多人学习企业管理，学习当老板，但是还是当不好老板。你们很多人学习谈恋爱，天天学谈恋爱的技巧、方法、心法，但还是谈不好恋爱。为什么？因为你跟一个人渣在谈恋爱。你天天研究谈恋爱，但是你跟人渣谈恋爱，你去管理人渣，这能管理好吗？肯定管理不好。

所以我们做粉丝，我们也只吸引牛人。我们讲直播，也只吸引牛人。因为你跟这个人渣讲管理，讲做企业，讲合作，讲做粉丝，讲做视频，讲做直播，讲走正道，负责任，心中有别人，讲儒家思想，己所不欲，勿施于人，他说你是个骗子，对不对？这种人你怎么跟他交往？你没办法跟他交往，所以只好把他拉黑，拒绝他，所以我们不跟恶人交往。这是我们中国文化当中不太喜欢讲的，由于不喜欢讲恶，所以很多善良的人就踩坑。

你会听的，你自然知道，我这里讲的都是经商，讲的是人性，讲的是管理，讲的是人生，讲的是恋爱、婚姻，甚至小孩怎么教育，父母怎么对待，我这里都在讲。只是你听不懂，你会觉得我没有讲。你把我这些思想拿去，方方面面都能用，因为我讲的是道。聪明的人，自然会融会贯通，一通百通。
