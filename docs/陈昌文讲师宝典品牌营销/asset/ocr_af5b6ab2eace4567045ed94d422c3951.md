# 14、想要打造个人品牌，你要有鲜明的个性

差异化是形成品牌的核心。没有差异化，就没有品牌。

想要打造个人品牌，你要有鲜明的个性。你的个性越是与众不同，你的个人品牌就越能传播，越有效益，越有名声。人们不喜欢普通的东西，人们就喜欢区别于大众的东西。做品牌，一定要简单。

要想打造自己的个人品牌，就要打造自己的符号系统，比如，你的手势特别，你的声音特别。为什么你是品牌，你必须要通过肢体动作，或者语言动作，或者形象体现出来，区别于别人，并且坚持下去，然后，慢慢你就会在人们心中留下一个印象，个人品牌就慢慢形成了。要有差异化，要独特。首先，你的名字、服装、言行举止，是不是能跟大多数人区别出来？如果你跟大家都一样，大家凭什么关注你？凭什么觉得你特别？所以，在不违反道德的情况下，想要打造自己的个人品牌，首先要注
