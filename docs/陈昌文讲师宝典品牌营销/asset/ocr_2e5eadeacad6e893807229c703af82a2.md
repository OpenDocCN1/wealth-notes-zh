# 第十章

公开课，公开赚钱的秘宓——我其实不是一个商人

你的粉丝就会喜欢你，你自然就有商业机会，人家自然就会买单。

所以说这个混社会蛮好混的，你做不到“己所不欲，勿施于人”，所以你会觉得生意不好做，读书会不好卖，老板社群不好做，粉丝搞不到，抖音难玩。

你看看你那个抖音里面有什么价值呢？你在我们这个社群，你赚不到钱，听不到有用的，你想象一下你的心正吗？你心正，在我这里能听到很多有用的；你心不正，你听不到，你觉得没有用。你没有帮助别人的心，所以你的抖音视频就拍不好，你的直播也讲不好，你听课就听不到好东西了，你拍视频也拍不到好东西了，你讲直播讲的人家也不听，就是你的心不正。

你看我们这个社群很强大的，我们有些人做老师，我告诉你们，每个老师只要你有十个听众的，你都是牛人。你能把这十个人教好，你已经天下无敌了。你能教好一百个人，教好两百个人，你就是企业家。这个抖音，他给每个人机会，就是你可以变成企业家，你可以变成一个很牛的人，就看你有多好，就看你心有多好，就看你能够为别人付出什么。己所不欲，勿施于人。自己喜欢的东西，能不能让别人喜欢？
