# 13、个人品牌营销最核心的是你的名字

个人品牌营销最核心的是你的名字，以及你的服务、产品的名字，一个好记忆的名字，会极大的降低你的个人品牌的营销传播成本。品牌建立的最有效模式是，不断的在客户的脑袋里重复你的品牌名字、品牌故事、品牌形象。

比如我的个人品牌就是陈昌文，我的服务就是陈昌文读书会和老板社群。我们讲话、演讲、讲故事，最好都要带上陈昌文读书会和老板社群以及陈昌文的名字。这就是最厉害的个人品牌营销模式。

个人品牌要的是大道至简，也就是别人一看你的名字，就知道你是干啥的，比如陈昌文读书会、陈昌文老板社群，一看，就是读书的，做老板圈子的。如果你的个人品牌名字复杂，则所有人看起来都迷茫，不知道你是干啥的，你这个个人品牌就没有商业价值了。
