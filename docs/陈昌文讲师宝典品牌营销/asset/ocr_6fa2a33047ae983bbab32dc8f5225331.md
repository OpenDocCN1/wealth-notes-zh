# 9、形成团队传播，形成价值观的传播，
最后形成低成本运营

我们是要最赚钱，我们是要真理，我们是要走正道，我们是
要保证在绝对安全的情况下赚钱。安全、稳，比赚钱更重要，
钱不会少。

我们是怎么运营的？运营外部粉丝、内部粉丝、读书会粉
丝，我们是讲给美女老板、美女企业家听的，是美女老板和美
女企业家这两个关键词。美女老板和美女企业家，定位要狭窄，
因为定位一旦广了过后，你讲的再有价值，别人也不听，因为
别人觉得这个跟她无关，她就会觉得你讲的是废话。

所以定位要极其狭窄，就是美女老板、美女企业家，用我
们的书籍对着这群人讲。那么定位狭窄过后，你讲的每一句话
就是精准输出干货，她就会感觉到是精准输出干货。
