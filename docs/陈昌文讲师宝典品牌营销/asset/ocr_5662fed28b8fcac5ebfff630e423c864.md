# 17、个人故事是个人品牌的灵魂

如果你天天讲你的企业发展故事、个人发展故事，是可以打造自己的个人品牌的。自己的生活经历、工作经历，点点滴滴，汇集到社交媒体上，视频平台上，就是一个打造个人品牌的过程。

打造个人品牌，最快的方式是，每天不断的原创真实的、跟自己个人品牌有关系的原创故事。通过视频、文章、直播的模式，不断的在网络上传播。这是最快的方式，没有之一。

建立个人品牌的关键点就是个人品牌的知名度，通过文章、视频、演讲，不断的宣传自己的故事、自己的形象，公益为大家普及你所擅长的知识。不要以为做这个事情没有收益，其实在你不断的扩散自己名气的过程中，生意自然就会找上门来。
