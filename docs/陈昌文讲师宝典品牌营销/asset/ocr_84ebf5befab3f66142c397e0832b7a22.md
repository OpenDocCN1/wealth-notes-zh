# 9、利润是第一生产力，然后矩阵才能组成

所有人都必须是正能量的人。首先，做社群，就必须是正心正念、有道德素质的人。如果这个社群里有很多坏人，则矩阵就没办法做了，一定会坏事。

维护社群的纪律、名誉，以及社群的营销、价值，以及价值观的传递，这都需要很多人，需要彻底正的人，去组成团队传播。在传播的过程中，还有利润收入，才是对的。如果在传播的过程中，没有利润，这个生意就不好做。所以，所有的地方，都必须要有利润。

所有矩阵参与人员，都必须会营销，也就是永远要有定位，比如美女老板、美女企业家，永远要有营销。不产生利润的事情，做不好，也没有未来。讲师团，必须有利润。所有人带的团队，都必须有利润。没有利润，这个矩阵就没有势能，建立不起来。
