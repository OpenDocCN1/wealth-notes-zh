# 7、永远不要贪天功为己有

这个道，我再延伸一下，永远不要贪天功为己有，不然你会倒霉的，并且你不会赚到钱。这个世界就是这么有意思。

比如说，这个事情，是你在我陈昌文这里听到的，你就必须说是 在我陈昌文这里听到的，你就是一个坦荡的人。这样你去赚钱，成交、吸粉都会很快，你吸引来的也是坦荡的人。但是如果你要说这些东西都是你的，你就变成了贼。你虽然可以获得名声，甚至赚到一些钱，但是你的心出了问题，你的屁股就会出问题，你的道都会出问题。

那么你看我陈昌文是怎么讲的？我说我的儒家思想、《72大营销系统》，包括《恋爱宝典》都是抄的，不是我的。我就是古今中外几千本书，到处抄各种大师，抄了糅合成了这几本书。

比如说，我写的这个解读儒家思想《论语》，抄王阳明的，抄朱熹的，抄张居正的。我就是抄的。还有一些故事，我抄《史
