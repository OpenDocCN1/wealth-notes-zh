# 20、社群运营＋直播＋短视频模式，是打造个人品牌的最好模式

如果你有财力，最好建设一个团队来打造你的个人品牌。如果你有一个团队，那么你打造个人品牌的速度就会更快，要利用团队的力量去打造个人品牌。如果不差钱，就直接上团队帮你做视频、图片，然后你自己把控一下文案，这样传播，更具有权威性，速度也更快，信任度也更高，变现能力更强，就是成本有点高。

打造个人品牌当然是有成本的，不舍得投入成本的人不会有个人品牌。打造个人品牌，肯定是要持续不断的投入时间、精力、金钱的，如果没有投入意识，那么就别打造个人品牌了。任何人都可以成功，只是大多数人都不愿意投入，而只想产出。个人品牌只会越来越值钱，投入的每一分钱，都会让你以后的生意变得更好。这是一个长期投资，划得来。
