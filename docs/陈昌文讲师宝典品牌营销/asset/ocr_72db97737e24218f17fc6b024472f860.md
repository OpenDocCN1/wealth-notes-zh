# 9、该打造什么样的个人品牌，市场有需求

打造个人品牌，是要利用手里拥有的资源去打造的，而不是凭空打造，也不是想打造什么个人品牌就打造什么个人品牌。首先要掂量自己的资源、精力、实力，以及选择好平台去打造。
打造个人品牌的方向，首先是市场需求。我们必须选择一个具有强大市场的方向，去打造自己的个人品牌，这个方向没有市场，我们就不发力。打造个人品牌的目的，是为了让消费者买单，消费者不买单，则你这个个人品牌毫无意义。

该打造什么样的个人品牌，市场有需求？自己能做什么产品、服务？首先，搞清楚你的核心竞争力是什么？其次，搞清楚市场需求与你核心竞争力的结合点，然后，你的个人品牌就应该围绕这个结合点来打造了。产品、服务与市场的对接点上就是自己的个人品牌概念。换句话说，就是你的产品与市场需求的结合处，就是你的个人品牌的发力点。
