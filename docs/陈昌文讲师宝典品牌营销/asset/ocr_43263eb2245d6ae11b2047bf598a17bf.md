# 6、大老板就是菩萨

中国文化有一个特点，它隐恶扬善，他不讲恶的，只讲善的。但是陈昌文要讲，这不属于儒家思想。为什么陈昌文要讲恶的？因为你们要踩坑。因为陈昌文不讲恶的，你们就要拿血的代价，拿钱的代价去填那个坑，自己去总结。所以陈昌文要讲恶。

所以有些人恨我，也是因为我老是讲恶。有些人说我是研究黑厚学的，我不是研究黑厚学的。有些人说我有毒，我没有毒，都是善，但是我要告诉你们恶。比如说，我们讲课不给坏人讲，不给反对我们的人讲，不给找事的人讲。我们培训人，也不培训坏的人，因为他会搞破坏。他要搞你的破坏，也要搞我的破坏。所以我们要把它拉黑，把他踢出去，不给他机会。那么如果我们只讲善的，我们说用我们的心血去温暖他。他可不像这样，他的想法是把你搞死。
