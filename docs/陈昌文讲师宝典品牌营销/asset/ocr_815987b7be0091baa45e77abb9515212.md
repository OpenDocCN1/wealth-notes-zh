# 11、为价值观买单，和为价值买单，是两种人

社群传播的是整体价值观，输出的是整个社群的纪律、价值观。输出价值观和价值是两码事，输出价值观是一个很强大的营销，你可以专门输出价值观，也可以专门输出价值。输出价值，就是我这一块肉好吃，你来吃；输出价值观，你听我的，我说的就是对的。这两者可以结合起来运用，也可以一会讲价值，一会讲价值观。价值观是要排斥别人的，就是要排斥一帮人，你不认同我，就离开。认同我，就来。

所以很多人买苹果手机，本质上是在为乔布斯致敬，为他的价值观致敬，是这样去营销的。我们要让他们为陈昌文老板社群的价值观来买单，我们要让他们为读书会的价值观买单。为价值观买单和为价值买单是两种人，当然也可能有重合，但是它是两种不同的营销逻辑。
