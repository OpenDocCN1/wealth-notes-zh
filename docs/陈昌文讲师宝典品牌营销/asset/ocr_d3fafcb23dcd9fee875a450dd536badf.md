# 1、品牌基调，什么人适合买我们的品牌

品牌营销要有个基调。这个基调就是我们传播给粉丝的信息是：什么样的人适合买我们的品牌。我们的品牌是适合那种富贵的、不缺钱的、高智力的人，是心性过关的、虔诚感恩的人。这就是我们的品牌基调。

要做好品牌营销，一定要过滤人群，我们只要企业家、美女老板、牛人，坚决不跟低智力的、愚昧的、消极、负能量的人链接，否则我们的品牌就会死掉。

品牌基调是需要不断的在直播间、视频里，以及书本里传播的。传播品牌基调的目的，是降低营销成本。是这样的人，自然就买单了，就跟我们形成一个圈子了。不是这样的人，则没办法交流。我们是卖圈子的，没什么承诺，就是在这个圈子里，请大家自动吸收智慧就行了。
