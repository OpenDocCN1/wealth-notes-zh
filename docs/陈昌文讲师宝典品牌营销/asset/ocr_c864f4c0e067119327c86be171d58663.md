# 5、饭都吃不饱的人，
他理解不了礼节、荣辱的重要性

所有人，都只能营销企业家、美女老板、牛人，不要营销负能量、低层次的人。他们不懂礼节，并非他们不知道尊师重道，而是，要想学会尊师重道，是有物理、生理基础的。身体不好、经济基础不行的人，他们的人格也很难健全。身体不好、经济基础不行的人，没有事业的人，他们什么都没有，你给他讲尊师重道简直是笑话，他不会重视这个东西。

仓廪实而知礼节，衣食足而知荣辱。饭都吃不饱的人，他理解不了礼节、荣辱的重要性。这个观念没办法灌输给他们，即便是灌输给他们了，他们也不会执行到位。
