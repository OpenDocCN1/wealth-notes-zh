# 8、什么样的个人品牌是有价值的

想要打造好自己的个人品牌，要非常清楚自己能为社会提供什么样的价值。何为社会价值？就是你的个人品牌是解决什么社会问题的？这就是你的个人品牌的经营使命。搞不清楚自己的个人品牌经营使命的人，就是搞不清楚自己个人品牌对应什么社会价值的人，就没办法打造好自己的个人品牌。

个人品牌必须有社会价值，就是社会上的人需要你这个人品牌，能从你这个人品牌里知道点什么，拥有点什么。比如，我打造陈昌文读书会和老板社群，这个品牌有什么用？这个品牌，会让人知道，在这里可以提升智慧，是个高端圈子，这就是社会价值。有了社会价值的个人品牌，才会有生意主动找上门。
