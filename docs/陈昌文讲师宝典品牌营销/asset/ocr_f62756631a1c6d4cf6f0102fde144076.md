# 6、打造全媒体品牌营销形象

做品牌，就是要做好自己的直播间个人形象。有了品牌形象，流量转化才能做好。没有品牌形象，流量转化非常难做。品牌形象，就是你的样子、你的服装搭配、你的项链、你的一切言行举止。要搞品牌营销，各位的穿戴、打扮最好贵一点。贵，能形成品牌信任感，会进一步带动你的销量，就是卖奢侈品的感觉。

所有讲师，直播间的每一个东西，都是媒体。茶杯、项链、衣服，一切与“陈昌文方法”这个品牌挂钩。

品牌营销的本质，就是一切都是媒体，一切都是品牌，一切都是传播，一切都是形象。这个东西做好了，大家会变得非常厉害。这叫做全媒体品牌营销形象。
