# 12、打造个人品牌，要有一个品牌文化

打造个人品牌，要有一个品牌文化，比如我就喜欢讲儒家思想，这就是我们陈昌文读书会和老板社群的品牌文化。有品牌文化的个人品牌会显得非常高大上，也会给你的服务与产品带来溢价。想要搞好自己的个人品牌，一定要宣传一种文化，而我就是宣传儒家思想。有了文化，然后结合自己的业务，就可以打造强有力的个人品牌。我的个人品牌文化是儒家思想，个人品牌项目是陈昌文读书会和老板社群。想要自己的个人品牌传达多远，就让自己宣传的文化传达多远。

想要做好自己的个人品牌，一定要找到一个历史原型，人类生活中的原型，比如，当代子贡、当代张良、当代诗仙。这样，有了历史文化原型，能让人更容易记住，也更容易传播，且容易商业化，个人品牌附加上历史文化原型会让你的个人品牌如虎添翼。
