# 2、我们服务配得上我们的人，
服务知恩图报的老板

我们服务配得上我们的人，服务知恩图报的老板。这是我们品牌的基调。这个老板不知恩图报，我们服务他们干啥？我们服务有成绩的人、有事业的老板、企业家、美女老板。这样，我们的寿命才长点。

我们要对我们的道德素质高要求，也要对企业家、美女老板的道德素质高要求。没有道德素质的，我们不接触。他们来了也不虔诚，我们懒得搭理他们。要绝对的尊师重道，否则就是坏人。

要培养的是道德素质非常好的人，这样的人，我们从一开始就要筛选。所以，我们必须日日讲尊师重道，要把那些不喜欢这个观念的人逼走。在直播间、社群里，都要逼走。这样，剩下的人，就是尊师重道的，就好教育、教化。
