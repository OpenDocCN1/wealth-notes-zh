# 认同你价值观的人，一定会买单——陈昌文内部讲话

以前我跟一个高人学习过，那个高人告诉我，这个厉害的角色，一般情况下不要跟他成为仇人。这句话你们能听得懂吗？不到万不得已，这个事情就是没有办法了，不到万不得已，不要去惹厉害的，不要去跟他成为仇人。你跟他成为仇人过后，他的精力旺盛，因为没事做，他就会搞破坏。他搞破坏，就跟你搞破坏不一样，因为他有用不完的力量，所以尽量不要去得罪人，尽量不要去惹事，尽量团结人。

所以说是整体运营，我们要关注整体，而不是只关注几颗杂草，我们是整体去运营传播我们社群的价值观，在这个过程当中你们还有利益，也可以赚到钱。如果是讲课、讲直播，那么传播的范围更广，这样纠正的效率更高，你们的能量就会更大，社群也就会更加的正能量。道德素质比能力更重要，这样整体势能就能运营起来。

所以我们运营两件事，第一件事情是，自己的身心健康；第二件事是，团队的运营。传播我们社群的价值观，是会吸到粉丝，并且可以变现的。在抖音里传播我们的社群，人家会求着你来买单，这个叫价值观营销，他会求着你买单的。他认可你的价值观过后，他自然想加入陈昌文老板社群。你只运营粉丝就行了，你直播间运营到1000人、2000人，每天都有人求着你买单。以后进入我们社群的人，首先跟价值观正的人学价值观。
