# 他利润。

贵有恒，何必三更起五更睡；最无益，只怕一日曝十日寒。

做读书会，日日循环；做陈昌文老板社群，日日循环；做《论语》解读账号，日日循环，日日做视频、直播。无恒心的人，干啥都白干。

《陈昌文解读《论语》》，要长做，持久做，持续的讲解，低成本做视频、直播就行了。根本不用多么高大上，先跟着读就行了，日日循环这个即可。最厉害的人，就是日日不断的循环而已。每个人都要做这个作业，经济+功德+修炼自己，多管齐下。

读书会覆盖的范围非常大，所以要不断的提高道德品质，否则，德不配位，后必有殃。
