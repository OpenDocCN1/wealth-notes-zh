# 品牌基调

有些人，一旦得志就猖狂得很。这种人，在初期就不应该培养。真正发自内心的做到尊师重道，日收入自然增长，自然听得懂人话，否则，难，听不懂的。

很多人理解不了，为什么越厉害的人越谦虚，越低调，越尊老爱幼，尊师重道，孝敬父母？很多人理解不了，为什么一些人非常非常厉害，但是为什么那么懂礼节？他们不懂，其实，不尊师重道而聪明的人，就是在培养竞争对手搞自己，给自己埋雷。

人是在不断的轮回的，今日造孽，明日受苦。高手不造孽，受苦的基本都是傻瓜，或者说在消孽。尊师重道，就是给自己造福德。一些家伙不尊师重道，就是在给自己造孽。我早说了，利润低、赚钱能力不行，是德行问题。很多人智商低，理解不了。

我的目的是提升大家的收入，教育有道德、尊师重道的人，我不喜欢低等级、人格、道德素质差的人。在我们社群，装也要装得尊师重道，当然，我希望你们收到的所有人，都是尊师重道的真人。话语本身就是权力，讲话对老师尊重点，做好榜样，尊师重道。不要不尊师重道，而希望别人尊重你。

你欺师灭祖，你带的人都会欺师灭祖；你尊师重道，你带的人都会尊师重道。
