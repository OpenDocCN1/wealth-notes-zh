讲情感不会。讲营销，是吸引小老板、中老板。《老板心法》《老板兵法》《老板干法》勉勉强强吸引大老板。《陈昌文解读〈论语〉》与这些一结合，就是高档次的企业家、美女老板。这是我希望大家在社群里、视频里、直播里的讲课打法。

# 5、讲《论语》是赚慢钱，但是有复利，会越来越多，越来越稳定

+   学员：
《论语》学起来是比恋爱慢很多，但是运用起来，可以讲一辈子，把事业时间拉长。《论语》应该是之后复利最好的。

+   陈昌文：
《论语》是可以与《恋爱宝典》《老板心法》《72大营销系统》《讲师宝典》等结合讲的，是理论根基，发展根基。当然，也可以只讲《论语》，都能赚钱，只是快慢的问题。很多人不愿意赚慢钱，只想要快钱，故而，赚钱始终少。讲《论语》是赚慢钱，但是有复利，会越来越多，越来越稳定。
