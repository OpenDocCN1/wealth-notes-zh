# 21、一辈子，只做好一个个人品牌

只有聚焦的人，才会打造出来自己的个人品牌，今天输出这个内容，明天输出那个，会显得没意义。专家才有品牌。只有理解不变应万变的人，才能做好个人品牌。当我们确定了一个个人品牌的名字，一个个人品牌的项目的时候，我们做上一段时间就会焦虑，这玩意到底行不行？开始怀疑人生，开始找借口换个人品牌名字，换项目，这就是大多数人一辈子不能成功的原因。想要做好自己的个人品牌就要不换名字，不换项目，谁能熬一辈子，谁成功。

想要打造个人品牌，就要只做一件事，坚持做一件事，把一件事做成功。只承诺一件事，只有一件优秀的事情。比如，我是社群营销专家，不要讲多了，讲多了，别人就不信任你了，也不想跟你合作了。只承诺一件事，也是打造个人品牌的人必须明白的。如果你承诺的太多、太高，即便是很优秀，大家
