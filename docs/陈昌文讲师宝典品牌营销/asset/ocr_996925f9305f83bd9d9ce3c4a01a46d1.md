# 7、有人支持的本质是心地善良，尊敬事情，尊敬人，尊师重道

为道德负责的人，就一定为业绩负责。很多人理解不了这个。尊师重道，做到这点，自然能赚钱。道德与业绩是统一的，并非分开的，德本财末，是圣人哲学。当然，世界上确实有人不道德，而获得财富的，但这样风险极大，会出大事。道德、财富，必须统一。

人品、道德，大于能力。有人品、道德的人，他的能力慢慢就修炼强了，他走在正道上。若是只有能力，不懂尊师重道、道德素质，则，这些人没什么前途，是灾难。

在社群里，真正传达我书籍里的知识、思想的人，其实是有敬畏心的。没有这个心的人，其实还是下里巴人，还是啥都不懂的人。真正搞明白我这些东西的人，都会生起敬畏心去做视频、直播。到了这个程度的人，财富易如反掌尔。
