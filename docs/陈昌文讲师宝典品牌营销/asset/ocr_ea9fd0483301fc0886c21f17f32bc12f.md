# 教你如何打造个人品牌

想要打造好自己的个人品牌，要借助巨人的智慧、势能，以及名气，这是最快速的路径，让巨人加持自己。

打造个人品牌的时候，你一定要不断的说你的个人品牌历史原型的好话，这样，你就壮大了你的历史原型，这样，你的个人品牌也会跟着壮大。你能借到的势能就越大，这是一个双赢的工作。个人品牌一定要有历史原型，因为历史原型本身就有好多粉丝，你的个人品牌跟历史原型对接过后，大家就会迅速认识你，这也是为什么我要宣传儒家思想的原因，因为这个世界上喜欢儒家思想的人很多。我宣传儒家思想，就会蹭到儒家思想的热度，而且这个群体是高质量群体。

想要打造个人品牌，就要打造很多小细节仪式感，比如你每天早上都带大家学习一点东西，日日必做，这就是仪式感小细节。比如，每天早上带大家读《论语》。比如，你每天都写一篇文章给大家普及一种营销知识，这也是仪式感小细节。你以什么形式讲课，你对客户重视吗？怎么重视的，具体点？这些就是细节仪式感。只有拥有细节仪式感的人，才可能打造出好的个人品牌。打造仪式感是打造个人品牌的核心逻辑，你要让别人记住你，你就要有所不同。仪式感会让人会让人觉得受到了尊重。
