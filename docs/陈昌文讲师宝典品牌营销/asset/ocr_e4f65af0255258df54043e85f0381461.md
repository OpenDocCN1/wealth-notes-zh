# 11、 个人品牌涵盖的范围越小，越有价值

个人品牌会非常值钱，但一个人只能打造一个个人品牌，不能打造多个个人品牌，一个人有多个个人品牌，那么他的品牌就不值钱了。如果个人品牌的标签多了，你将会没有品牌，打造不起来自己的品牌。一个人只有一个个人品牌，那么，这个人就会非常值钱，打造个人品牌切记贪心，只做一个垂直细分领域的龙头老大，你的机会就会自动找上门，到处都会有人主动找你买单。

想要打造自己个人品牌的影响力，最好有一个爆款，也就是你在某个点上，超越了所有人，所有人都认为你在这方面是权威，或者第一，这就是你的江湖地位。人要的其实不是全面发展，而是专精一点，且把这一点做到极致，超越所有人，你就有了影响力，就有了江湖地位。
