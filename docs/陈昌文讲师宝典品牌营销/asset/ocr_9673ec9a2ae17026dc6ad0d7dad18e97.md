# 1、你只顾你自己，你一定是赚不到钱的，你最多就是个个体户

你想着你赚钱，你实际上是个个体户。你只顾你自己，你一定是赚不到钱的，你最多就是个休户，企业家是兼顾所有人的。你这个责任有多大，利润才有多大；能力有多大，责任就有多大；责任有多大，就有多大的利益，就有多大的权利。在我们社群时间很长的老师，本质上都是拥有团队的，就看你能不能摇得动。

社群是运营起来的，社群是团队运营起来的。我们社群里有很多财富，任何一个群运营好了，一年都能赚一两千万。一个社群上了1000人，运营好一个群就能赚2000万，我说的就是你一个人。我告诉你，这1000人当中你运营起来十几个人，一年就有2000万收入。收入不是别人给你钱，隐形的传播都是钱。
