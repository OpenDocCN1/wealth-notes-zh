# 政策效能扩大，经济动能改善

### ——10月经济数据点评

报告摘要：

10月规模以上工业增加值当月同比增长5.3%，市场预期增长5.6%，9月增长5.4%。10月社会消费品零售总额同比增长4.8%，市场预期增长3.9%，9月增长3.2%。1-10月固定资产投资累计同比增长3.4%，市场预期增长3.5%，1-9月累计增长3.4%。1-10月全国基础设施投资（不含电力）累计同比增长4.3%，1-9月累计同比增长4.1%。1-10月全国房地产开发投资累计同比增长-10.3%，市场预期增长-10.1%，1-9月累计同比增长-10.1%。1-10月全国制造业投资累计同比增长9.3%，市场预期增长9.3%，1-9月同比增长9.2%。10月城镇调查失业率5.0%，9月数值为5.1%。

综合10月的经济数据，拟合GDP增速继续加快，供需均在趋势改善。生产端工业小幅放缓，但服务业加快较多；需求端外需增长超预期，内需动能在改善，消费增速继续加快，投资保持平稳。

10月经济的亮点有三个方面。一是，服务业改善较多，这与逆周期政策加码，以及地产销售的大幅改善有关。10月一揽子货币政策显著提振居民风险偏好，金融、地产、批发零售等显著回升，带动服务业供需明显改善。二是，消费增速进一步加快，可选消费改善的面显著扩大，以旧换新政策在继续释放政策效能。三是，在近期地方政府化债取得积极进展的情况下，狭义基建连续两月改善明显，财政支出堵点得到疏通，已有财政政策效能更充分发挥。当前宏观环境最显著的变化来自国内，一揽子化债方案已经官宣，增量财政也在路上，房地产政策仍在积极调整，整体上基本面的积极因素增多，后续宏观基本面关注四个方面：

第一，增量财政发力的空间。一揽子化债方案让地方政府轻装上阵，政策效果从9月开始已开始有所体现，前期的政策资金正在加速落地形成实物工作量，短期内形成比较有力的政策脉冲。从持续性来看，仍需观察后续的增量空间有多大。12月的中央经济工作会议将对明年的增速和财政定调，在物价持续低迷、内需改善仍需巩固、外需存在较大不确定因素的背景下，期待增量财政进一步加码。

第二，货币政策宽松力度。当前增量财政在加快落地，无论从与财政政策的协调配合，还是从促进物价的温和回升，货币政策仍需要进一步宽松。当前市场预期美联储继续降息，国内货币政策仍以我为主。短期来看，货币政策或进一步降准，以配合2万亿元增量专项债的发行。明年政策或将靠前发力，一季度降息的可能性比较大。

第三，地产去库存政策的落地进度。10月地产销售同比显著收窄，同时房价下行速度放缓，环比改善明显，地产需求端止跌回稳值得期待。我们认为扭转地产负循环的关键在于促进地产价格的止跌回稳。当前政策效果仍需政策巩固，地产去库存的节奏和力度或是重要变量，我们认为，扭转预期宜早不宜迟，地产政策调整需要加快进度。

第四，外需的不确定性。10月出口异常增长，部分因9月台风对港口物流的冲击，后续两月或有回落。未来出口最大的不确定性来自美国的关税冲击，在关税政策落地之前，美国基本面的韧性，以及抢出口效应或继续促进出口保持平稳增长。

风险提示：国内政策落地节奏、美联储降息超预期。

# 1. 主要数据和结论

根据统计局公布：

10月规模以上工业增加值当月同比增长5.3%，市场预期增长5.6%，9月增长5.4%。

10月社会消费品零售总额同比增长4.8%，市场预期增长3.9%，9月增长3.2%。

1-10月固定资产投资累计同比增长3.4%，市场预期增长3.5%，1-9月累计增长3.4%。

1-10月全国基础设施投资（不含电力）累计同比增长4.3%，1-9月累计同比增长4.1%。

1-10月全国房地产开发投资累计同比增长-10.3%，市场预期增长-10.1%，1-9月累计同比增长-10.1%。

1-10月全国制造业投资累计同比增长9.3%，市场预期增长9.3%，1-9月同比增长9.2%。

10月城镇调查失业率5.0%，9月数值为5.1%。

综合10月的经济数据，拟合GDP增速继续加快，生产端工业小幅放缓，但服务业加快较多；需求端外需增长超预期，内需动能在改善，消费增速继续加快，投资保持平稳。10月经济的亮点有三个方面。一是，服务业改善较多。10月一揽子货币政策显著提振居民风险偏好，金融、地产、批发零售等显著回升，带动服务业供需明显改善。二是，消费增速进一步加快，可选消费改善的面显著扩大，以旧换新政策在继续释放政策效能。三是，在近期地方政府化债取得积极进展的情况下，狭义基建连续两月改善明显，财政支出堵点得到疏通，已有财政政策效能更充分发挥。当前宏观环境最显著的变化来自国内，一揽子化债方案已经官宣，增量财政也在路上，房地产政策仍在积极调整。基本面的积极因素增多，后续宏观基本面关注四个方面：

第一，增量财政发力的空间。一揽子化债方案让地方政府轻装上阵，政策效果从9月开始已开始有所体现，前期的政策资金正在加速落地形成实物工作量，短期内形成比较有力的政策脉冲。从持续性来看，仍需观察后续的增量空间有多大。12月的中央经济工作会议将对明年的增速和财政定调，在物价持续低迷、内需改善仍需巩固、外需存在较大不确定因素的背景下，期待增量财政进一步加码。

第二，货币政策宽松力度。当前增量财政在加快落地，无论从与财政政策的协调配合，还是从促进物价的温和回升，货币政策仍需要进一步宽松。当前市场预期美联储继续降息，国内货币政策仍以我为主。短期来看，货币政策或进一步降准，以配合2万亿元增量专项债的发行。明年政策或将靠前发力，一季度降息的可能性比较大。

第三，地产去库存政策的落地进度。10月地产销售同比显著收窄，同时房价下行速度放缓，环比改善明显，地产需求端止跌回稳值得期待。我们认为扭转地产负循环的关键在于促进地产价格的止跌回稳。当前政策效果仍需政策巩固，地产去库存的节奏和力度或是重要变量，我们认为，扭转预期宜早不宜迟，地产政策调整需要加快进度。

第四，外需的不确定性。10月出口异常增长，部分因9月台风对港口物流的冲击，后续两月或有回落。未来出口最大的不确定性来自美国的关税冲击，在关税政策落地之前，美国基本面的韧性，以及抢出口效应或继续促进出口保持平稳增长。

# 2. 服务业增速显著加快

10月工业生产略微放缓。本月工业增加值同比增长5.3%，弱于市场预期值，较前值放缓0.1个百分点，仍保持较快增速。三大分项来看，制造业同比5.4%（前值5.2%），采矿业同比4.6%（前值3.7%），电热水5.4%（前值10.1%），制造业和采矿业分别加快0.2和0.9个百分点，而电热水放缓4.7个百分点。

制造业分行业来看，装备制造业增加值保持较强的韧性，对制造业生产增长起到压舱石的作用。10月消费品制造业生产有所回落，但医药和橡胶塑料制品保持较快；高能耗行业继续分化，化工和有色继续保持较快增长，黑色增速加快，非金属负增长收窄；装备制造业整体增长保持较快，根据统计局新闻发布会，装备制造业增加值同比增长6.6%，但较多行业有所放缓，其中电子设备制造业增速继续保持在10%以上，景气度较高。

制造业向高端化、智能化、绿色化发展的态势明显。根据统计局公布，10月份高技术制造业增加值同比增长9.4%，快于整体制造业增速4.1个百分点。其中，集成电路、工业机器人的产量同比分别增长11.8%、33.4%。智能设备、绿色产品生产持续高速增长，10月份智能无人飞行器制造业增加值增长41.9%；新能源汽车、太阳能电池产量分别增长48.6%和13.2%。

10月服务业生产指数显著好于季节性表现。10月服务业生产指数同比为6.3%（9月同比为5.1%），为2024年最快增速。根据计算，10月份的服务业环比为1.24%，显著高于疫情前2017-2019年的均值以及2023年同期值。根据统计局发布会信息，10月在增量政策带动下，金融业、房地产业、批发和零售业生产指数都出现了明显回升，批发和零售业回升的幅度为2个百分点，金融业和房地产业回升幅度超过和达到3个百分点。

10月的GDP同比指数与比月改善。本月用工业和服务业同比增长拟合的GDP同比增长为5.5%，继续快于前值，主要是服务业生产拉动较多。往后看，在外需保持韧性、逆周期政策显著加码的背景下，工业生产和服务业或继续保持平稳增长。四季度GDP增速或在5%左右，全年能完成5%左右的增长目标。

# 3. 商品消费进一步改善

10月的社零消费增速继续改善。10月社零消费同比增长4.8%，好于市场预期。商品和餐饮消费同比分别为5.0%和3.2%，分别较前值回落1.7和加快0.1个百分点。

从商品消费来看，限额以上商品整体同比增长6.8%，其中必选消费和可选消费都显著加快。具体来看，必选消费中，粮油食品类保持平稳，化妆品同比增速40.1%，带动整体必选消费改善明显。可选消费继续受到政策提振，保持改善势头，其中汽车、家电、文化办公用品继续显著高增，10月分别增长3.7%、39.2%和18.0%，均较前值改善较多。与上月相比，本月可选消费改善的面显著扩大，服装和家具消费同比也显著改善，金银珠宝消费负增长继续收窄。往后看，消费品以旧换新政策将持续释放政策潜力，并在一揽子货币和增量财政政策提振下，居民风险偏好和消费意愿将持续改善，可选消费持续改善值得期待。

# 4. 基建投资改善明显

10月固定资产投资当月同比保持平稳。10月固定资产投资当月同比增长3.4%（9月同比增长3.4%）。其中制造业投资同比增长10.0%（9月同比增长9.7%），基建（不含电热水）投资同比增长5.8%（9月同比增长2.2%），增长均在加快。地产投资本月下滑有所扩大，同比增长-12.3%（9月同比增长-9.4%）。根据国新办信息，不含地产的固定资产投资1—10月同比增速为7.6%，显著高于1—10月整体投资增速3.4%。

大规模设备更新政策对投资的提振较大。设备工器具的投资快速增长，对投资增长拉动作用明显。根据国新办公布，1—10月份，设备工器具购置投资同比增长16.1%，增速比全部投资高12.7个百分点，拉动整体投资增长2.1%，对整体投资的贡献率在60%以上。

# 5. 就业压力继续缓解

10月失业率较上月下降0.1个百分点至5.0%。分户籍来看，本地户籍失业率5.1%（前值5.2%），外地户籍失业率4.8%（前值4.8%）；31个大城市失业率5.0%（前值5.1%）。

本月就业压力继续改善，本地和大城市就业改善是主要拉动项。10月外来户籍就业与前值持平，数值上好于去年同期水平。本地户籍改善0.1个百分点，回到近年季节性均值，就业形势保持平稳。此外，大城市就业与本地户籍就业同步改善，回到年初4月份的水平，或意味着大学生就业压力基本得到缓解。
