


# 基于微课的翻转课堂模式在民办高校政府会计课程教学中的应用研究

杨 洁

（武汉工商学院 管理学院，湖北 武汉 430065）

摘 要：随着教育信息化的不断推进，微课、慕课、翻转课堂等新型教学模式逐渐在高校教学中得到应用。针对民办高校政府会计课程教学中存在的课时有限、学生基础薄弱、实践能力不足等问题，本文探讨了基于微课的翻转课堂模式在该课程教学中的应用。通过分析民办高校政府会计课程的教学现状及存在的问题，提出了微课设计与制作、课前自主学习、课堂互动内化、课后拓展提升四阶段的教学模式实施路径，并从教学资源建设、教学组织管理、考核评价体系等方面提出了保障措施，以期为民办高校政府会计课程教学改革提供参考。

关键词：微课；翻转课堂；民办高校；政府会计；教学模式

随着大数据、人工智能等现代信息技术在财务领域的深度应用，政府会计改革不断深化，对高校政府会计课程的教学也提出了新的要求。2019年1月1日起，政府会计制度在全国各级各类行政事业单位全面实施，新的政府会计制度采用“双功能、双基础、双报告”的核算模式，对会计核算和财务管理提出了更高的要求。民办高校作为我国高等教育体系的重要组成部分，其政府会计课程教学面临着新的挑战与机遇。如何有效提升课程教学质量，培养学生适应新时代政府会计改革需要的能力，成为民办高校会计教育工作者亟需解决的问题。

微课作为一种新型的教学资源形式，具有短小精悍、主题突出、使用灵活等特点，为课程教学改革提供了新的思路。翻转课堂则通过重新调整课堂内外的时间，将学习的决定权从教师转移给学生，实现知识传授与知识内化的颠倒。将微课与翻转课堂相结合，能够有效弥补传统课堂教学的不足，提高学生的学习积极性和主动性。本文以民办高校政府会计课程为研究对象，探讨基于微课的翻转课堂教学模式的应用。

## 一、民办高校政府会计课程教学现状分析

### （一）课程内容体系复杂，教学课时相对不足

政府会计课程涉及财务会计与预算会计双重核算体系，内容涵盖资产、负债、净资产、收入、费用以及预算收入、预算支出、预算结余等多方面，核算逻辑复杂，业务处理流程繁琐。民办高校政府会计课程通常安排为32-48学时，在有限的课时内要完成如此庞大的教学内容，教师往往只能对重点知识进行讲解，难以兼顾全面性和深度性。学生课下缺乏有效的自主学习资源，对课堂知识难以进行及时的消化和吸收。

《携程集团2024年可持续旅行消费者报告》以崭新视角，深刻剖析了后疫情时代消费者对可持续旅行的观念转变。

当前，多数全球游客将获取有关可持续旅行方案的信息视为消费者的权利，而非仅仅是新奇尝试或者次要考虑因素，说明可持续旅行已成一个新常态。

全球可持续旅游委员会（GSTC）指出，可持续旅行即是承认旅游业带来的各类积极和负面影响，旨在最大限度地降低负面影响，最大限度地发挥积极影响。¹然而，研究表明人们对可持续旅行的认知不尽相同，在理解和动机方面存在地区差异。

其中一项关键差异是价格敏感度。尽管越来越多的游客认可并愿意选择可持续旅行，但大多数人不愿意承担因此产生的额外费用。

这说明公众的环保意识与实际行动之间仍存在鸿沟。加强公众教育以激发消费动力固然迫切，但正如调研结果所示，提升可持续旅行方案的可见度与可信度同样重要。有近三分之一的受访者坦言，他们从未选择过任何可持续旅行产品。

为应对这些挑战，我们希望通过本报告引领旅游业未来发展，让可持续旅行是我们共同肩负的责任。面对后疫情时代的经济挑战，游客群体愈发期望OTA平台能够推出更多激励项目，为可持续旅行贡献力量。

今年的报告基于4个大区共计109个国家和地区的9,867个调查样本，在携程集团2022年首次调查的亚太（APAC）以及欧洲/中东/非洲（EMEA）市场基础上，新纳入了拉丁美洲（LATAM）和北美（NORAM）市场²，并深入挖掘了Z世代（出生于1997至2012年间的人群）的偏好和区域差异。

我们希望这些调研成果深化公众对可持续旅行的认识，促进生态链各方携手合作，共同推动可持续旅行事业的蓬勃发展。
