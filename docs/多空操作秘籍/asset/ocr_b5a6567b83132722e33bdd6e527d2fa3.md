# · 第二階段：上升階段

買進的理想時機是一支股票最終翻越其底部而進入這個較動態的階段。當股價向上突破壓力地帶的頂端與三十週移動平均時，應該要有可觀的成交量配合。這是第二階段上升趨勢的開始。但是，在真正上升的強力部份發生前，必須明白在最初漲勢之後，通常會跟著至少一次的拉回。該次下跌會將股價帶回突破點附近，這是低風險買進的第二次好時機。不要執迷為每股進價節省幾分錢！比方說，如果突破發生在12.125處，拉回可能會到12.375或12.625或接近這兩個數字的附近。拉回的幅度愈小，通常顯示力道愈強勁。非常有趣的是，在突破點附近——最佳買進時機出現時，基本面報導通常都是負面的。除非你的股票經紀人偏向技術分析，否則他會勸你不要買進該股。

在第二階段的突破發生後不久，三十週移動平均通常就會開始轉而上揚。若每一次上升的高點皆高於前一次的高點，這便是買方的夢想。另外，盤整的低點也會愈來愈高。這是非常重要的。不論該模式所展現的多頭氣勢如何強而有力，也不要期望該股只漲不跌。圖2-3 International Paper（I P）說明了我所要說的意思。當它在一九八六年初進入第二階段（陰影區）時，所有的下跌整理皆發生在三十週移動平均上升趨勢線的上方，而每一波的上漲都使 I P 迭創新高。市場的表現永遠令人詫異，這也正是絕大多數投資人在市場中年復一年虧損金錢的理由。股票市場（或任何其他類似市場）將行其所必行的工作，使大多數人無法賺錢，而只慷慨地回報給那些機靈的少
