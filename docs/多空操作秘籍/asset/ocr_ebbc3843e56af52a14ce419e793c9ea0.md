# 圖1-5

現在你是否得到了一些啟示？這也就是為什麼精明的市場專業者總在利空消息下買進，而在利多消息下賣出。股票在可怕的消息籠罩下形成底部，而在一般大衆狂歡盈餘大幅成長、股票分割，及其他類似消息中形成頭部。因此，典型交易員與投資人會在樂觀的消息中，於高檔買進股票，而在媒體報導恐怖消息下，在低檔大量認賠拋售，這種情況也就不奇怪了。一般大衆一貫的虧損，與真正專業人員一貫的獲利，其原因無關運氣（好運或壞運），而是這兩種人所遵循的遊戲規則不同。這種情況與一個職業撲克玩家明瞭得失機率，拒絕跟進一付順子的牌，而業餘者卻會讓感覺引導他虧損，其間是沒有差異的。
