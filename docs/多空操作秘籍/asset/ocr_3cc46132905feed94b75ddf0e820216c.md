# 選擇類股

在審視市場指標並確認市場大勢是多頭之後，即可進展到下一步驟——選定未來幾個月之內涵蓋最令人興奮的上漲空間、而下檔風險最小的一個或兩個類股。這個工作不僅重要，而且非常關鍵！在幾年來觀察與研究市場週期循環之後，我心中認定類股分析與整體市場時機判斷同樣重要。事實上，在某些市場中，它甚至更為重要（例如，在一九七七年的雙軌市場中，績優股處於空頭市場，而第二線股則處於多頭）。

分析類股要從何處著手？絕對不是從閱讀基本面資訊開始。回顧一九八二年，當我對活動房屋類股（Mobile Home group）的看法轉為多頭時，當時這些相關個股的盈餘都只是馬馬虎虎，但它們卻領導了一九八二到一九八三年一波的上漲行情。大約在同一期間，一九八一年初，當石油價格漲到每桶38美元時，石油類股飆升。由於石油極度短缺，各方面的報導顯示它將漲到100美元。但是圖形卻道出完全不同的故事。數的石油個股圖形與類股圖形本身（圖3-13）都顯示主要的第三階段頭部正在形成。所以，與其聽信樂觀的基本分析，不如獲利了結才是適當的策略。後來的事大家也都知道，該類股就在接下來的幾年內崩盤了。
