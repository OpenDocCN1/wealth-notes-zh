# 測驗

+   1. 當一支股票向上突破壓力而進入處女地，是一項非常有利的因素。 對 錯
2. 相對強度乃衡量一支股票表現與其成交量之關係。 對 錯
3. 當一支股票出現突破，如果其他因素皆屬正面 (市場趨勢正面、類股屬強勢、壓力極小等)，可以忽視成交量因素。 對 錯
4. 底部區域之成交量型態，比突破時之成交量特徵更為重要。 對 錯
5. 壓力愈久遠，力量愈小。 對 錯
6. 縱使一支下跌中之股票，仍可能呈現有利的相對強度。 對 錯
7. 在主要下跌之後，所能尋求最有力與可資信賴之反轉型態為雙重底，而且價格應在移動平均之上方。 對 錯
