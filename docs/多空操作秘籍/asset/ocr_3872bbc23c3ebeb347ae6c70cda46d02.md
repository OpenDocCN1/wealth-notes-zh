# 什麼不可以買

在進入下一個重要課題——該買什麼——之前，我要確定你明白什麼不可以買。業餘技術分析人士（而且令人訝異的是，甚至一些不應犯錯的專業人士）都會犯一個共同的錯誤：當一支股票向上突破其底部，但它仍處於其三十週移動平均下降趨勢之下方時，就進行買進。這不是一支你該買進的股票，因為它還沒有準備發動持續的漲勢。多數情況下，數週之內會有短暫行情，然後就會垮下來。最好的情況下，該股會再繼續進行築底工作，使移動平均逐漸平緩。最差情況下，它會跌到交易區間底部的下方，開始新的跌勢。

這裡有兩個從一九七三到一九七四年空頭市場中選出的例證，它們明確說明了我的意思。Western Union（W U）在 一九七二年遭受嚴重打擊，股價由68跌到44。然後，逢低承接買盤進場並發揮支撐功能。經過幾週後，底部雛型開始形成（圖3-9）。在三十週移動平均跌破底部之後，註定失敗的陰影四處彌漫。交易區間的突破點（A點）處於移動平均的下方，這也具有關鍵意義。雖然W U隨後稍微超過移動平均，但是最初突破發生在移動平均下方的事實便是附加的警告訊號。移動平均從未停止向下而行，則更是一項嚴重的紅色警訊。永遠不要買進處於這種情況的股票，不論它有多便宜。
