# 別將所有雞蛋放在一個籃子

現在你知道何者應該買進、何者不該買進了。這裡還有一個最終的論點——分散，必須再好好討論一下。不論你多麼專精於我的系統，也永遠不要期望能達到完美的境界。未來是非常不確定的。在大多數時候可能是正確的，但有時候還是會犯錯。更為謹慎的做法是，將你的風險分散到幾支股票。以免一次不幸的選擇傷及筋骨。

即使你以停損（在第六章我會教你）保護你的多頭部位，但如果你不做分散，還是有可能嚴重受傷。如果你全部投入的資金部位遭到15％的虧損，你的荷包將大幅縮水。如果你不幸又遭到第二次15％的打擊，你的資本便將嚴重耗損。如果你將你的資金平均分散到十五個部位，其中之一虧損了15％，該虧損也僅佔你市場資金約1％而已。

市場平均法則的極佳範例，就呈現在一九八七年的《專業軌跡解讀》中。我在該年一月初所做的三個買進建議為 Dravo（圖4-34），Tandem Computers（圖4-35）與Texas Instruments。
