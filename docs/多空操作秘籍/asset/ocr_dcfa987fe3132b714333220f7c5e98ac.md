# ### 5. 成交量

現在，請謹慎留意！當我們站在買方面對向上突破時，成交量居於關鍵地位。未經成交量確認的向上突破，你絕對不應買進。如果你已經買進，而成交量並未確認，你就應該在第一段小漲中將它賣掉。放空時則全然不同。雖然以成交量明顯擴增確認其向下突破是個很好的現象，但是對於致勝的放空而言，成交量並非必要。股票上漲需要力量，但股票卻可以因其本身的重量而大跌。有很多案例，例如一九七三年的Jonathan Logan（JOL），成交量並未確認其向下突破，但該股仍成為令人嘆為觀止的贏家。JOL於55向下跌破趨勢線時（圖7-22之A點），完成了主要頭部。你可以注意到該點（B）成
