# · 極有利可圖之型態

回顧第四章，我曾經指出辨認頭—肩—底型態的重要性，因爲它們能引發令人難以置信的有利漲幅。反之亦然。頭—肩—頂型態（尤其是在大幅上漲之後出現）是最有利可圖的放空訊號。雖然它們不會時常出現，但出現的頻率多過於頭—肩—底型態，而且出現的次數足以成爲優厚利潤的來源。事實上，當你開始發覺有一群這樣的型態出現時，這就是主要市場頭部逐漸形成的訊號。

有效頭—肩—頂頭部型態的第一個要素是某支股票走勢曾經非常強勁，而且已經有相當的漲幅。這個型態的美妙之處在於它能辨認趨勢反轉。如果先前沒有漲勢供反轉做準備，那就忘了它吧；它不會令人興奮的。成交量在上漲期間應該遠高於其平均量，因爲追高的人在漲勢即將結束之前蜂湧而入。然後當獲利回吐出現，盤勢就會拉回整理（參見圖7-26的B—C）。當賣壓力盡時（C點），股票會彈升到另一個新高點（D點）。此時還沒有出現問題，除了在第二波上漲時成交量不再擴增，而且通常會小於前一波漲勢之成交量。這是潛在麻煩的第一個徵兆。成交量的萎縮即反映出高檔買盤意願的低落。
