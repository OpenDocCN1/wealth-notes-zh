非指那些在早上買進而在下午賣出的人。我對交易員的定義是指那些企圖捕捉每個為期二到四個月重大價格波動的人。我認為這是一種明智的交易方式。倘若總是星期一買進星期二就賣出，結果就只會讓你的經紀人變成富翁而已。

# 投資人（Investor）

我的投資期間是指十二個月。這並不意味你不能持有股票更長時間，但是我不認為在三、四或五年的時間架構內，談論市場（股票）是有意義的行為。在這麼長的時間架構裡，有太多的變數與太多的循環期可以發揮影響響。

# 短期（Short Term）

依據我的定義，短期操作是指為期一週到大約六週的周期。

# 中期（Intermidiante Term）

這種周期為期六週到大約四個月。

# 長期（Long Term）

我對長期的定義是四到十二個月。主要趨勢都是長期的，而且永遠有我們所知道最重要的型態。如果你能夠掌握長期趨勢，通常就能免於短期進出的錯誤。
