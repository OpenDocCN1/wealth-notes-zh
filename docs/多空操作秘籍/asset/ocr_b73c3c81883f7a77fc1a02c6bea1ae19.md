# 圖7-2

很多人屬於樂觀主義者，要他們從負面局勢中獲利有違他們的天性。但如果你只參與市場的榮面，這猶如駕駛一部只有前進檔的汽車一樣。雖然你用到前進檔的時機比較多，但是在少數情況下，當你需要在障礙面前退後時，沒有退後檔是非常危險的。這道理同樣適用於股票市場。以時間長短而論，多頭市場勝過空頭市場。例如在一九六〇年到一九八七年只有八年的時間屬於空頭市場，但在這些年頭如果出現失誤，你將喪失大部份獲利。若在空頭市場中不懂得利用放空的技巧，將使你的投資組合處於更不利的地位。若想要在空頭市場中進出，其最單純而合乎邏輯的方法，其實與學習在多頭市場中挑選最佳股票買進一樣，要學習在空頭市場中選擇最弱勢的股票放空。
