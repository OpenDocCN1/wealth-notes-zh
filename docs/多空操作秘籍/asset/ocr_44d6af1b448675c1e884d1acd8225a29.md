# ・ 何時該放空

下一個要解決的問題是：何時是放空的最佳時機？是在最初向下突破發生時（A點），還是等它反彈拉回到原來向下突破的區域時（B點）？同樣的，之前我們在買進時所學習到的每件事情，在放空時仍然有效，只是要顛倒過來即可。我先前曾經說過，面對向上突破的情形時，如果你在拉回時買進，風險較低，但是它很可能不拉回，如此一來你將完全錯失機會而永遠無法買進該股。因此我奉勸投資人，最佳戰術是在突破時買進一半的部位，另一半部位則在股價向突破點拉回時再投入。另一方面，交易員應設法攫取機會，因此在突破時即買進全數部位。放空的法則也是一樣。交易員尤其要瞭解這個重點。雖然朝向下突破點拉回的情形占一半以上，但它發生的頻率仍遠低於向上突破的拉回。理由很單純。股票下跌乃源於恐懼，一旦恐慌出現，它就會一面倒。但保守的投資人希望將風險維持在最低點，因此仍應在最初向下突破時先放空一半部位，然後在拉回時再放空另一半部位。

圖7-14推薦的一支放空對象——說明了我要表達的意思。只要它停留在第二階段，即使其本益比已高達47倍的荒唐水準，我們仍拒絕加入群眾來稱它為高估的股票。移動平均一旦停止上升而形成頭部，這就是把它列入放空名單的時機了。在它向下跌破A點之後，它仍不斷向下挫跌，接下來趣事便開始了。
