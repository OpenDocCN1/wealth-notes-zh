# 雙重底行為

我所要教導各位的下一個型態，雖然不具有像頭肩底那般強大的動力，但它也是非常有利可圖的一種形態。當它配合巨大的成交量、有利的相對強度與最小上檔壓力時，這種說法尤為正確。

# · 寬廣的底部就是好

在技術分析師之間有一句格言——「底部愈寬廣，上漲潛力愈大」（依此邏輯推斷，「頭部愈寬廣，跌幅愈大」）。我由衷地相信這項陳述。雖然在許多短期底部的案例中，配合著所有其他的致勝因素，也可以產生極佳的結果，但對於一個非常大型底部的突破，永遠都應該要特別留心。這非常重要，因為這種型態通常會導致廣大與持續的漲勢。直覺上來說，這理論具有非常意義。猶如一幢大房子需要一個堅實的地基，同理，一個大型底部可以推動一支股票長期走高。從技術面而言，它也具有意義。所謂大型底部的實際意義為，持股在第一階段形成期間經過充分換手。當股價下跌時，持有該股的許多賣方原先祈求打平脫身，最後終於厭惡地將持股以低價賣給一群新買方。這會使得上檔壓力減小。因為很多先前厭煩地希望打平脫身的潛在賣方，現在都已經將其持股拋售掉了。新的持有者則更具有耐心，而且打算等待該股大幅上漲後再賣出。

這裡有兩個範例顯示什麼是你所應該追求者。American Barrick Resources（A B X，圖4-32）在 一九八六年初於4處

向上突破壓力，而在未來十五個月上漲接近400%。我所強調的所有因素都出現了。當ABX移到壓力之上方時，其長期底部已告完成。成交量不僅在突破時擴增，而且在數週之前就已逐步凝聚。另外，附近並沒有壓力，RS線在突破時也進入正値區。

相同的致勝組合在一九八六年的Korea Fund（KF，圖4-33）也很明顯。當KF移到壓力18處之上方時，長期底部便已告完成，而且準備妥當迎接重大漲勢。在接下來的一年半，上揚到86的價格就是個重大漲勢。成交量、相對強度以及缺少壓力，這幾個因素再次成為一個典型的範例。

# 史丹的誠律

現在你已經很熟悉該於何時買進什麼，接下來這裡有一個關於何時該買進、什麼不可以買的審查明細表。雖然明細表很簡短，但它具有很深沈的智慧。如果妳能完全學習，確定在未

來永遠不觸犯這些規則中的任何一條，那麼你將發覺你的市場經驗會有趣且有利得多。

+   * 當整體市場處於空頭走勢時，不可買進。
* 不可買進處於負面類股中的個股。
* 不可買進處於三十週移動平均下方的個股。
* 不可買進一支個股，其三十週移動平均處於下降狀態（即使該股處於移動平均上方）。
* 一支股票不論其走勢多麼偏多，也不可在漲勢發動後太久才買進，因為其時股價已經離開理想進場點很遠。
* 不可買進在突破點處成交量表現欠佳的個股。如果你因為採用停止買單而買進，應儘快出脫該股。
* 不可買進一支個股，其相對強度處於不佳狀況。
* 不可猜測底部。一支看似便宜的個股可能演變成代價昂貴的第四階段災難。相反地，在突破壓力之上方後再買進。

# 別將所有雞蛋放在一個籃子

現在你知道何者應該買進、何者不該買進了。這裡還有一個最終的論點——分散，必須再好好討論一下。不論你多麼專精於我的系統，也永遠不要期望能達到完美的境界。未來是非常不確定的。在大多數時候可能是正確的，但有時候還是會犯錯。更為謹慎的做法是，將你的風險分散到幾支股票。以免一次不幸的選擇傷及筋骨。

即使你以停損（在第六章我會教你）保護你的多頭部位，但如果你不做分散，還是有可能嚴重受傷。如果你全部投入的資金部位遭到15％的虧損，你的荷包將大幅縮水。如果你不幸又遭到第二次15％的打擊，你的資本便將嚴重耗損。如果你將你的資金平均分散到十五個部位，其中之一虧損了15％，該虧損也僅佔你市場資金約1％而已。

很多參加我的講習會的人問，「我的投資組合內應有多少種股票才屬正確？」它應是八、十或十二呢？答案？並沒有一個單一的魔術數字！但有一個大致的範圍是我認爲有道理的。我知道一或兩支股票的資產分配方式太過危險。我也知道四十到五十支股票數量太多，而且難以追蹤。對你的投資組合保持適當的警戒態度，與扮演父母的角色很類似。你所負責的小孩愈多，便愈難照顧週全。股票也一樣。如果你將你的資產分配到五十支股票，你很難感受每支股票的表現。另外，你應該保持一種態度，集中注意力於表現良好的股票，然後把那些你認爲隨後才會展現活力的落後型股票暫時擱置一旁。這就是你讓好股票支援壞股票所產生的結果。

照顧你的股票的適當方法是，假裝每一個部位皆是你唯一持有的部位。如果它表現不錯，很好，就這麼做。但如果它嚴

重落後而且表現差勁，即使停損點未被觸發也應該減輕部位。將資金移入較具前瞻性的一支第二階段新股票。更明確的說，對投資金額較少（10,000美元到25,000美元）的小型投資組合來說，我分散的對象不會超過五或六支股票。如果你更上層樓，進入六位數字或更大的投資組合，我在任何一段時間所投資的股票種類最多為十到二十支。

在設計你的投資組合時，可採用大致等量的金額來作為依據。不可以像很多投資人一樣，他們以其所能購買的股票數量來思考。他們每樣皆買進1,000股，不論它是5美元或40美元的股票都一樣。你可以使用一個整數，假設我們以100,000美元投資於十支股票，每一部位應大致為10,000美元的價値。如果你買進每股50美元的股票，你只能買200股。如果第二個部位是每股10美元的股票，你將可遞出1,000股的買單。在設計投資組合時，你應利用一般常識，不可將所有的雞蛋放在一個籃子裡，但也不要走到另一個極端，使用太多的籃子。

這裡還有另一種分散的形式，是您應該知道與執行的。不可從某單一類股中挑選所有的買進對象。如果有三或四個產業呈現良好的技術行為，則可由所有這些產業中挑選出第二階段突破者買進，而不可僅選擇某單一類股。如果某類股突然反轉，則你的投資組合仍可保持良好表現。
