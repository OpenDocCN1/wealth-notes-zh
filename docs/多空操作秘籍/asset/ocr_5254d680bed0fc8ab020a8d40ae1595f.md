# · 濾委訂單

一旦你決定放空某一、兩支股票，下單方式應該如下所述。如果 X Y Z 股票於 24.875 向下跌破，則以 24.875 停止與 24.375 限制之方式放空所拋出的股數。此處有一點與買進時不同。買進時，如果該股交易活絡，則停止買進價格與限制價格之間的價差可設為 0.25。但放空時，你應該讓它至少維持 0.5 點。對冷門股而言，價差可能更大。為什麼？在紐約與美國證券交易所有個老舊的規則，稱為上檔規則（uptick rule）。它要求你只能在較高的價位放空。依據我個人的意見，這是荒唐而缺乏邏輯的規則，它起源於一九二九年的股市崩盤。為了避免空頭襲擊，交易所——根據其無限的智慧——決定不準許放空者迅速壓低股價。這顯示交易所非常偏愛多頭市場。但你是否能夠想像，他們要求你只能在價格走軟時買進股票？這簡直是無稽之談，因此我相信有一天上檔規則終將會被取消！不過目前由於此一規則，因此你應該要讓你的放空有較大的轉圜空間。

如同買進一樣，你所濾出的委託單應該設定為取消前有效。在店頭市場交易時，由於無法實際運用停止委託單，因此你必須依靠你的經紀人。不過在店頭市場交易的優點是沒有無稽的上檔規則。因此，如果你看見 X Y Z 向下跌破 25 的內盤，而 24.875 應該是放空之處，那麼只要內盤出現 24.875，你的經紀人就可以立刻為你放空。在崩跌的市場中，這實在是很大的優勢！
