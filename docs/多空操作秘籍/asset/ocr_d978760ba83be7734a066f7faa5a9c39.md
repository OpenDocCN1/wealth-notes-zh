# 第6章

# 何時賣出

投資成功之道，你已經完成一牛以上的旅程。爲了使旅程圓滿。這裡還有一些非常重要的步驟必須精通——學習何時賣出。如果你真的想要在市場上大有斬獲，賣出決策將具有關鍵地位。不幸的是，很少有市場玩家能夠精通此重要步驟。

只要曾持有的Avon從140跌到19（圖6-1），或Floating Point從45跌到8.5（圖6-2），便能使你快速喪失戰鬥能力，沒有復原的機會。你可能很難相信，有多少次我曾看到一些投資組合內所持有的個股一度是贏家，後來卻成爲大災難。你知道這故事吧。X Y Z股票在40處恰當地買進，然後它很快爬升到60。但市場傳說它會很快漲到100，所以爲什麼要賣出？等它跌到20時，你便完全明白應該賣出的理由了。

Alfin與VM Software（圖6-3與6-4）清楚說明了學習適當地賣出是何等重要。在此兩例中，買進訊號皆曾出現（圖中A點）。在接下來數月，這些股票上漲，成爲買者的夢想。但如果你與這些股票永結同心，美夢終將變成夢魘。在令人興奮的漲勢之後，每支股票都吐回了獲利。甚至更糟的是，最後實際上卻是虧損。一旦你精通本重要章節的技巧之後，就不會再經歷這種擂人心肝的情節了。
