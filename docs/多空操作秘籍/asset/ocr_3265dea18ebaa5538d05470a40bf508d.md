# ・便宜還是昂貴

下一個長期指標顯示我事實上一個實用主義者。雖然我堅決相信技術分析，但我總是儘可能保持客觀。在講習會中，我常常開玩笑說，如果對股票名單投擲飛鏢能夠給我80%的正確答案，那麼它也將會爲《專業軌跡解讀》「證據權數」中的第五十一個指標。不論是技術分析或是基本分析，我想要的只是對明天市場可能行為的較佳洞察力。不幸的是，大多數我測試過的基本分析指標，其預測能力皆不值得信賴。但有少數則是，其中最佳者爲股價／股息比率。這個非常長期的指標顯示股票價格是股息的幾倍。換言之，爲了買進價值一元的股息，你必須支付多少代價（以股票價格表示）？
