# 交易區間（Trading Range）

這是買賣雙方進行戰爭的中立地帶。當一種股票處於上升趨勢時，買方的火力明顯較賣方為強，會造成股價上漲的結果。下降趨勢則是銅板的反面，賣方的力量較買方強盛。但在交易區間裡，雙方勢均力敵，撕殺則發生在支撐地帶（本例為8到8.5）與壓力區域（本例為11.5到12）之間。請注意，在圖1-6中還有第二個交易區間（在26到30的區域）。
