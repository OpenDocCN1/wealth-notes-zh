最後應該注意的錯誤是，放空時未設保護性停止買單。絕對不可如此！如果你在紐約或美國證券交易所放空，則應設定一個取消前有效的保護性停止買單。但股票如果屬於店頭市場，則必須確定你的經紀人將它納入其市場監視系統內，當它觸及你的停止買進水準，即應立即回補。

# ・放空時之戒律摘要

+   * 不可因為本益比過高而放空。

+   * 不可因為股票漲幅過高而放空。

+   * 不可對每個人皆認定它會崩跌的股票放空。

+   * 不可對成交量薄弱的股票放空。

+   * 不可對處於第二階段的股票放空。

+   * 不可對處方強勢類股的個股放空。

+   * 不可在沒有停止買單保護的情況下放空。
