# 圖4-16

這就是我所要說明的概念。圖4-17的Acme United Corporation（ACU）在 گے一九八七年初於8.5處（B點）向上突破。但RS線卻警告你不要買進。為什麼？首先，RS線深入負値區，在零線下方很遠處。雖然這並不等於要自動排除買進該股的可行性，但它是警訊。該股的RS線最好要有相當的表現，否則最好忘了它。這只是第一個該忘掉它的理由——ACU還有兩項不利的狀況。第二個理由是RS線，該線處於一九八六年初高峰以來爲期十二個月的主要下降趨勢中。而第三個不利的訊號，是ACU在B點突破時，雖然價格線走高，RS線反而走低。因此任何買進該股的想法都應該告一段落。但是，誘惑輕率者的情況再度出現。該股在幾個月後再度突破9.125（C點）。再一次地，RS線低於先前之高峰（RS線上，C點低於B點）。而最終結果就是它未能隨快速揚升的道瓊指數走高，Acme實際上是走跌。
