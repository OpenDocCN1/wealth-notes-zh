# 測驗

+   1. 在第四階段的情況下向下攤平，唯一可接受的條件 對 錯 為，成交量呈現正向型態。
2. 當在處理店頭市場股票時，你可以採用停止賣出限制 對 錯 單，但不可採用純粹的停止賣單。
3. 對投資人而言，成功賣出之關鍵在於適當採用追蹤性 對 錯 的停止賣單。
4. 對投資人或交易員而言，能夠不使用保護性停止賣單 對 錯 而持有第二階段股票的唯一時機，是當類股與整體市場皆處於多頭趨勢時。
5. X Y Z 股票於78.5穿越其下降趨勢線時，你予以買進。先前高價位於 A 點為82。整理低價位於 B 點為72.75。如果 X Y Z 穿越 A 點，你預測其交易頂點會發生在何處？
A. 87.75
B. 82
C. 89.25
D. 91.25
