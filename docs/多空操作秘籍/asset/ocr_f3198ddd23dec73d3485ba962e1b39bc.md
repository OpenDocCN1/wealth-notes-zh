# ・與群眾相反

我們所探討的指標至少都具有一個共同點——它們都可以客觀地測量。它們都依據特定的統計數據（例如上漲與下跌家數，或創新高與新低的家數）。但是，這裡有一個主觀的指標，它不依賴任何特定訊號，可是它非常有用。我將它稱之為相反意見理論（theory of contrary opinion）。

這個理論談論的是群居本能對投資人之折磨。本理論的基本論點之一是，人身處於主流內感覺最安全。因爲這個理由，投資人形成了一致的意見。他們相互強化其信念，並封鎖支持其他結論之證據。在市場中，這種行爲往往導致崩盤前夕的過度樂觀信念，以及底部時的普遍悲觀看法。採用相反意見理論的人，則會試圖發掘出一致的意見，然後再以截然相反的方式運作。
