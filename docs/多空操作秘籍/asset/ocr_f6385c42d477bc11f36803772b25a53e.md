# 圖形——它們以各種型態出現

雖然有很多不同型態的圖形存在（日線圖、週線圖、月線圖），但有兩個基本型態你應該熟悉。雖然所有不同型態的圖形我都會一一揭露，但我會教導你什麼是對交易員、什麼又是對投資人最簡單最有效的圖形。

第一種圖形型態是長條線圖（bar chart），它描繪某一既定時期內的最高、最低及收盤價格，以及相應的成交量。第二種圖形型態是圈叉圖（point-and-figure）（參閱圖1-12 Marion Labs的圖形），它只記錄價格的變化，而忽略了時間與成交量的資訊。因此，在圈叉圖中，如果一支股票在一天之內大幅震盪，則在該天便需記錄好幾次。而如果在未來數天內該股價格沒有變化（接近相同價格），則不需再記錄，因為沒有價格變化可供記錄。圈叉圖（OX）基本而言是行動的簡潔摘要（圖1-12 Marion Labs 的O·X圖顯示了20年的歷史）。它們在認定重要型態，辨認支撐區域（股票在
