# 圖5-16

National Semiconductor（圖5-17）在一九七三年也展現了相同的贏家潛力。當時因為整體市場平均指數已經逆轉，因此你不應大量買進。在空頭市場，你應採大量放空。但是如果你碰上像National Semiconductor這樣傑出的買進型態時，你可以對你放空的部位承做避險動作，買進像這樣的絕佳候選股。但是，你必須確定它是一支絕佳的股票，因為當整體市場處於逆勢，選擇較差股票的空間並不存在。National Semiconductor就是這樣的絕佳股票。它是三樓贏家，成交量較數週前的均量增加幾乎三倍（圖5-17之A點），而且成交量在突破後數週，仍維持相當巨大之水準。相對強度在第二階段突破之前，處於零線附近。此後它快速強勁地進入正值區。
