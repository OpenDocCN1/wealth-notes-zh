這裡還有一個例子可協助你精通這個非常重要的獲利概念。這一對股票（圖4-10與4-11）皆來自於同一市場循環與同一類股。但其中之一出現超過300％的獲利，另一個卻出現虧損。答案並非遙不可及——關鍵就在成交量中。Puerto Rican Cement（圖4-10）於一九八六年初，在突破9以前的四週平均成交量為120。然後成交量擴增十倍，顯示某些人突然急於買進。這些人是正確的，因為他們在9處買進的股票，在僅僅十五個月後，以38.5賣出。

Texas Industries（T X I，圖4-11）是另一支水泥股，它於一九八六年初出現突破。但該股的漲勢在霎那間便消失無蹤，而非不斷展現雄風。成交量不僅沒有擴增，實際上反而萎縮，一直處於過去數月的高點之下。當其翻越31.5時，萎縮的成交量是當時避開T X I一個很好的理由。成交量訊號可以挽救你，因為T X I在數月後跌到22，而Puerto Rican Cement卻愈漲愈高。
