# 4. 不可只因為本益比太高而賣出股票。

上述範例的反面也是一項嚴重問題。有個古老的華爾街笑話說，一位投資人問他的經紀人，為什麼某支股票上漲。由於缺少比較好的理由，於是該經紀人應付說：「買的人比賣者多」。這個笑話背後所涵蓋的訊息與事實多於虛構，只是很少投資人能夠明白。他們總希望得到某支股票價位變動的理性答案。但他們真正得到的卻是藉口或推論之見解。很少市場參與者能夠明白市場並不是永遠理性的。它所反應的僅是目前市場上彌漫的投資人心理或心境。如果投資人極度看多而沈溺於樂觀的美夢，則高本益比也可以變得更高。Tandem Computers（TDM，圖6-8）清晰地說明了此一論點。在一九八五年
