# 圖1-5

現在你是否得到了一些啟示？這也就是為什麼精明的市場專業者總在利空消息下買進，而在利多消息下賣出。股票在可怕的消息籠罩下形成底部，而在一般大衆狂歡盈餘大幅成長、股票分割，及其他類似消息中形成頭部。因此，典型交易員與投資人會在樂觀的消息中，於高檔買進股票，而在媒體報導恐怖消息下，在低檔大量認賠拋售，這種情況也就不奇怪了。一般大衆一貫的虧損，與真正專業人員一貫的獲利，其原因無關運氣（好運或壞運），而是這兩種人所遵循的遊戲規則不同。這種情況與一個職業撲克玩家明瞭得失機率，拒絕跟進一付順子的牌，而業餘者卻會讓感覺引導他虧損，其間是沒有差異的。

因此，你的哲學應該很單純：

- 1. 不可在沒有檢驗線圖的情況下買賣股票。
2. 不可在好消息公佈時買進股票，尤其是線圖顯示在消息公佈前股價已有相當漲幅。
3. 不可在股價暴跌時因為股價便宜而買進。在賣壓持續下，你會發覺便宜會變得更便宜。
4. 不可在線圖的下跌趨勢中買進股票（我會很快地告訴你，如何明確定義下跌趨勢）。
5. 不可持有處於下跌趨勢的個股，不論它的本益比有多低。幾個星期後，在更低的股價下，你就會發現股價下跌的理由。
6. 永遠保持一貫。如果在實際完全相同的情況中，你有時買進，有時賣出，那麼你就犯了違反紀律的可怕錯誤。

所以請瞭解線圖解讀與技術分析並不是神秘的科學。它不是妖術或天文學。它非常單純，只是解讀市場健康狀態的心電圖。你的醫師在為你做診斷之前，會為你拍攝X光、檢定血液、或做ECG檢查。一位勝任的技術分析師，同樣也會對市場進行類似的檢查。他們兩者皆非巫醫（雖然我對部份醫師持保留意見）。讓我們繼續前進，我將帶你進入股票市場的內部。

我不依照嚴格的字母順序介紹這些技術分析名詞，因為有些既定的名詞先瞭解之後，你將更能掌握其他某些名詞的意義。首先，請對股票XYZ的圖形（圖1-6）稍做研讀、瀏覽一下，嘗試掌握這個圖形對你的意義。然後，第二回合，一次研讀一個定義，好好思考，只研究圖形中與定義有關的部份。不要貪多，不要企圖一次就把所有的意義記住。這完全沒有必要。對某些人而言，這是一項新語言，但只要你慢慢地研讀本節，它就會開始對你產生意義。在讀了幾章之後，你就會覺得自己是一個技術分析老手。且讓我們開始吧：

支撑（Support）——下跌趨勢很可能穩定下來的區域，之後可能反彈與回升（至少是暫時地）。它像是地板。但是請注意，不要變得太狂熱，就像很多技術分析師一樣，談到支撐就把它視為是一個點。它實際上是一個區域（Area）或地帶（Zone）。在圖1-6中，支撐最初是在26到26.5的地帶。第一次低點在26，第二次在26.5。第三次止跌於26.25，而第四次賣壓止步於26。

請注意，跌破支撐區絕對底部（本例為26），對股價而言具有非常負面的含意。支撐被測試的次數愈多，測試的時間愈長，一旦支撐最後突破時，其出現的負面訊號愈重要。請同時注意，一旦主要跌勢或漲勢形成後，沿途會形成新的支撐水準。以XYZ的例子而言，新支撐形成於8到8.5的區域（參閱圖1-6）。

壓力（Resistance）——又稱為供給（Supply），這兩個名詞可以互用。上漲股票很可能遭遇麻煩（至少是暫時地）而且發生回轉的區域。壓力區被測試的次數愈多，測試的時間愈長，一旦壓力區最後衝破時所出現的多頭訊號愈重要。在圖1-6的例子裡，壓力最初在近30的水準。在主要跌勢之後，下一個有效壓力地帶變成11.5到12。在XYZ股票突破壓力區上限之前，第一次多頭走勢失敗於12，第二次於11.5，然後在11.75。永遠記住，對股價而言，走勢衝破壓力區上限是一項極佳的多頭指標。同樣地，在主要走勢進行時，沿途會形成新的壓力（或供給）水準。在XYZ的例子中，第一個壓力在29.5至30的地帶。後來則落在11.5到12的區域。

# 交易區間（Trading Range）

這是買賣雙方進行戰爭的中立地帶。當一種股票處於上升趨勢時，買方的火力明顯較賣方為強，會造成股價上漲的結果。下降趨勢則是銅板的反面，賣方的力量較買方強盛。但在交易區間裡，雙方勢均力敵，撕殺則發生在支撐地帶（本例為8到8.5）與壓力區域（本例為11.5到12）之間。請注意，在圖1-6中還有第二個交易區間（在26到30的區域）。

# 移動平均（Moving Average、MA）

這是一項非常重要的技術分析工具，它能協助你同時留意短期與長期走勢。實際上，移動平均是將主要趨勢平滑化，使每天的瘋狂震盪（最新的電腦程式使得買賣盤震盪更加瘋狂）不至於將你拖離市場。幾年來，我發覺三十週移動平均最適合長期投資者，而十週移動平均最適合交易員採用。三十週的移動平均不過是將本週五的收盤價和前面廿九個星期五的每週收盤價加總，再把上述值除以30所得到的結果，即是本週圖形所應描繪的點(註4)。股票交易價格若處於三十週移動平均之下，則不考慮買進，尤其是該移動平均處於下降趨勢。股票交易價格若處於三十週移動平均之上，則不考慮放空，尤其是該移動平均處於上升趨勢。對於一個長期投資者而言，購買股票的最理想時機為股價向上突破壓力區，同時移至三十週移動平均之上，而且該移動平均不再處於下降趨勢。對於一個交易員而言，他可採取行動買進股票的理想時機，是當股票處於三十週移動平均之上，而且該移動平均正處在上升階段。交易員的理想進場點是等待股價在新的交易區間盤整過後，當它拉回移動平均附近，而再向上突破壓力區的時刻。

(註4) 某股票的十週移動平均，顯然就是本週五的收盤價與前面九個星期五的收盤價之加總，再除以十。

# 向上突破（Breakout）——股票價格移動至壓力地帶上限（在XYZ圖形為12）的上方時。

在本例中，一旦壓力地帶上限被清理乾淨，向上突破即發生在12.125處。猶如雞蛋有不同的品級，向上突破也有許多不同。永遠記牢兩項暗示：(1)股價在壓力區之下停留愈久，最後的向上突破愈具意義；(2)向上突破時，成交量擴增愈大，其所蘊涵的多頭氣勢愈盛。（不用擔心：我們在未來的幾章裡還會更詳細說明。目前只要記牢這兩項簡單的規則，即可大大增加你的利潤）。

# 向下突破（Breakdown）——與向上突破相反，即股票價格移動到支撐區底部（在XYZ圖形的例子為26）的下方。

在本例中，支撐區底部被貫穿時，向下突破即發生在25.875。與向上突破不同，向下突破不需伴隨大成交量即可視為有效。股票可以因為本身的重量而下跌，但是一般來說成交量還是會以某種程度放大。

拉回（Pullback）——股票向上突破交易區間而向前邁進之後，通常至少會有一次獲利回吐的整理，將股價帶回原始向上突破點（本例為12.125）附近。這是理想的第二次加碼買進機會（尤其是拉回發生時，成交量大幅萎縮）。相反地，股價向下突破到支撐之下而繼續滑落，通常至少會有一次拉回動作逼近向下突破的水準（本例為25.875）。如果拉回發生時，伴隨著很小的成交量，這就是放空該股票的理想點。

趨勢線（Trendline）——如果你拿一支尺連接某個圖形中的任何二個低點，便可完成一條趨勢線。但是，一條趨勢線與一條「有意義的」趨勢線之間的差異非常大！一條有意義的趨勢線至少會被碰觸三次。圖1-7（Skyline）說明了一條具有意義的趨勢線。在第五次測試該線而向下突破之前，它曾被碰觸四次。像這樣的線遭到破壞時，即應發出警報，因為這種突破代表主要趨勢的改變。向下突破一條上升趨勢線具有負面意義，而向上突破一條下降趨勢線則屬多頭（注意一旦Skyline向下突破它的上升趨勢線，接下來它便可說是崩盤了）。

上升趨勢（Uptrend）——某支股票（或市場平均指數）的高點越來越高而且低點也越來越高所構成的數列。該數列最少維持數個星期，最多到數年（參閱圖1-6）。

下降趨勢（Downtrend）——某支股票（或市場平均指數）的高點越來越低而且底部也越來越低所構成的數列。同樣地，該數列最少維持數個星期，最多維持數年（參閱圖1-6）。

接下來說明的交易員、投資人、短期與長期等名詞，其意義是相當主觀的。當我使用它們時，希望你能夠明確瞭解我的意思。這是很重要的，因為某個人所定義的投資期間，對另一個人來說很可能指的是交易期間。

交易員（Trader）——當我在本書中提到交易員時，我並非指那些在早上買進而在下午賣出的人。我對交易員的定義是指那些企圖捕捉每個為期二到四個月重大價格波動的人。我認為這是一種明智的交易方式。倘若總是星期一買進星期二就賣出，結果就只會讓你的經紀人變成富翁而已。

# 投資人（Investor）

我的投資期間是指十二個月。這並不意味你不能持有股票更長時間，但是我不認為在三、四或五年的時間架構內，談論市場（股票）是有意義的行為。在這麼長的時間架構裡，有太多的變數與太多的循環期可以發揮影響響。

# 短期（Short Term）

依據我的定義，短期操作是指為期一週到大約六週的周期。

# 中期（Intermediate Term）

這種周期為期六週到大約四個月。

# 長期（Long Term）

我對長期的定義是四到十二個月。主要趨勢都是長期的，而且永遠有我們所知道最重要的型態。如果你能夠掌握長期趨勢，通常就能免於短期進出的錯誤。

# 相對強度（Relative Strength）

指某一支股票（或類股）相對於整體市場的表現。例如，如果XYZ股票上漲十個百分點，而市場卻上升二十個百分點，則雖然該股價上漲，但其相對強度很差。相反地，如果XYZ股票下跌十個百分點，而市場平均下跌二十個百分點，則雖然該股價下跌，但其相對強度佳。衡量相對強度的公式是以股票價格（或某一類股的平均價格）除以市場平均價格。

放空（Short Selling）——這是最常被誤解與不常被使用的技巧。專業人士使用它，但個別投資人十之八九皆不曾嘗試。放空是對你當時未擁有的股票下達賣單；而且期待該股票價格在未來會下跌。如果你要在20放空XYZ股票，實際上你就只是向你的經紀人借入這些股票與買者交割。如果XYZ的股價如預期地下跌到10，你便能在市場買回XYZ股票償還給你的經紀人。在這個過程中，你每股賺了10美元。所以，誰說在空頭市場不能夠賺錢？

# 圖形——它們以各種型態出現

雖然有很多不同型態的圖形存在（日線圖、週線圖、月線圖），但有兩個基本型態你應該熟悉。雖然所有不同型態的圖形我都會一一揭露，但我會教導你什麼是對交易員、什麼又是對投資人最簡單最有效的圖形。

第一種圖形型態是長條線圖（bar chart），它描繪某一既定時期內的最高、最低及收盤價格，以及相應的成交量。第二種圖形型態是圈叉圖（point-and-figure）（參閱圖1-12 Marion Labs的圖形），它只記錄價格的變化，而忽略了時間與成交量的資訊。因此，在圈叉圖中，如果一支股票在一天之內大幅震盪，則在該天便需記錄好幾次。而如果在未來數天內該股價格沒有變化（接近相同價格），則不需再記錄，因為沒有價格變化可供記錄。圈叉圖（OX）基本而言是行動的簡潔摘要（圖1-12 Marion Labs 的O·X圖顯示了20年的歷史）。它們在認定重要型態，辨認支撐區域（股票在該處停止下跌）與壓力地帶（漲勢在該處遭遇麻煩）是非常有用的。分析股票時，我雖然會用OX圖來配合我所有的其他圖形，但絕對不可單獨使用，因為OX圖並未包含成交量與移動平均的資訊。另外，OX圖也較難精通。所以在本書中，我將完全採用長條線圖。在適當使用的情況下，長條線圖可以幫助你獲得可觀的利益。

現在讓我們回到長條線圖分析。我們所處理的時間長短實際上並沒有關係，但為了說明起見，假設我們在談論的是一天的交易（參見圖1-13的日線圖）。如果當天高點是18而低點是16.5，你所要的就是在當天高點（18）與低點（16.5）處，各點上一點，然後畫一條直線把兩點連起來。如果當天收盤於17.5，你就在當天交易價17.5處，畫上一個橫劃。至於成交量，顯示在圖形底部，相應的垂直軸上應該有另外的量度。如果該天的成交量是25,000股，你只要在25,000水準點上一點，然後由該點引一條直線下至成交量度的零線。隔天，高點為18、低點為17，而收盤為17。我們就在時間量度隔一線的右方，以同樣方式再畫出高點18，低點（17）與收盤（17）。假設第二天的成交量為20,000股。

所有這三種圖形皆有一個功能。日線圖（圖1-14）對短期交易來說絕對是最佳的工具。另一方面，月線圖（圖1-16）對追求數年趨勢的真正長期投資人而言，是優良的工具。介於兩個極端之間的便是週線圖（圖1-15），該圖是二者間的折衷。週線圖擁有足夠的交易資訊（雖然非常短線的交易員應該採用日線圖），尤其對中期（數個月）交易員及長期投資人息息相關的重要波動上，週線圖有其特殊價值。在本書中，我雖然會談論所有的圖形，但我會把重點放在週線圖，因為以整體而論，它們是投資人的最佳參考圖形，特別是因為它們可以一次顯示兩年的歷史資料。但是，請注意這三種圖形都是絕佳的圖形工具，而且皆可達成其各別目的。
