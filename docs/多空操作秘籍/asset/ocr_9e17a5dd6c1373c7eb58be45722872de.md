# 買進的理想時機

# · 如何買、何時買、買什麼

閱讀前兩章的內容之後，你的能力已進展到超出你所能理解的地步了。如今你已能夠拿起你的投資組合及圖形，區分良莠，不再盲目地依賴你經紀人的意見。你現在能夠快速地審視你的股票中，哪些是有高成功機率者，哪些很可能會為你帶來潰瘍之痛。知識即力量，而你正邁向成為Hercules(註1)的途中。但你仍有一些重要事項有待學習。現在地基已設置妥當，你已能輕易地分辨第二階段的多頭股票與第四階段的空頭情況。

下一個步驟是要架設建築物的其餘部份，學習最佳買進時機。另外，瞭解應該如何買進股票以及知道買進什麼股票是非常重要的。其之所以極端重要，是因為當你瀏覽圖形時，尤其是處在熱滾滾的多頭市場時，你會發覺有數以百計的股票可以買進。因此，學習如何篩選具有超級上漲空間的最佳股票、而捨棄次等股票的工夫，便具有絕對重要性。

> (註1) Hercules為希臘神話中的大力士。
