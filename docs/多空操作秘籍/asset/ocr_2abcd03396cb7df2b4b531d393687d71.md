# ‧ 適當地賣出——投資人的做法

我們已經知道何者不可爲，現在就讓我們開始討論決定何時該賣出的正確方法。理論上來說，投資人與交易員的做法是相似的，不過其中還是有些不同的指導方針與參數。我們先討論投資人的做法；下一節我們再檢討交易員應該如何運作。

所有優秀交易員或投資人首先應該要做的事情，就是瞭解自己絕對不可在沒有停止賣單（sell-stop）的保護下持有任何部位。所有期貨交易人士都知道這是成功的關鍵技巧。股票市場也沒有什麼不同。只是波動較爲緩慢而已。在股票指數期貨與電腦程式交易發明之後，這其間的差異很快就變得更小了。
