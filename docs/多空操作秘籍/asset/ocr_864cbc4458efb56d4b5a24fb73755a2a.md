# 圖1-17

我不會讓圖形中的所有特徵——其中有很多是很基本的——來煩擾你。很多特徵是令人迷惑而沒有必要的。我們只會專注於圖形中真正重要且會產生利益的部份。

+   1. 首先觀察每一個高－低－收盤價的條柱。股票價格是圖形中最重要的構成要素，因為隨著時間推移，它會形成一個型態，而給予我們下一個主要波動的線索與複雜的內涵。 2. 第二個要素是所描繪的週成交量。價漲量增、價跌量縮是一個有利訊號。就如我們前面所說的，在本書中也將不斷地強調，在向上突破時，呈現擴張性的大成交量是非常重要的。龐大的成交量透露急切而且有力的買進，會把股價推往更高處。
