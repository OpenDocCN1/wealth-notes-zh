# 7. 不可等待下一波反彈再賣出。

圖表型態顯示某支股票遭遇麻煩時，就要立即出場。不可再等待，希望在反彈中多撈個一、二點。這種戰術使你市場資金損失不菲的機會很高。River Oaks與Savin（圖6-16與6-17）的案例正說明了這種情況。River Oaks在向下突破6時即應賣出。後來它再也沒有彈升到該水準，而只是一路下跌到0.25！Savin在向下跌破7.25時出現強烈賣出訊號。後來它再也未彈升到該水準，而是一路下滑到1.125探底。所以，你一旦發覺危險徵兆，曉解到應該賣出股票，那就立刻這麼做——賣掉它就對了，千萬不可再為了尋求稍好的價格而煩惱。
