# 永遠不會太遲

截至目前為止，我們都在討論如何於向下突破點附近放空。當股票已有相當跌幅後，放空是否仍為可行？答案是當然可以。雖然在頭部附近放空比較理想，原因是潛在利潤比較大，但請記住，真正的大輸家在觸及堅實底部之前，看起來總有進一步大崩盤而跌得更慘的傾向。在第四階段下跌中放空，是交易員的好戰術，因爲隨即而來的賣壓通常既迅速又瘋狂。但是這套戰術僅適用於下降移動平均下側的盤整型態，且向下突破再發生之時。

這種型態的交易相當於在第二階段中的連續買進。猶如連續買進比較適合交易員一樣，這種型態也比較適合積極的市場玩家與交易員。但是這樣的放空有其優點，因爲當它再向下突破時，下跌速度會非常快。放空一支像Winnebago（圖7-25）的股票——它已經從50附近下跌到22——即使是在其出現整理而於21.875（A點）處再次向下突破時放空，仍然很有道理，因爲它很快就產生了豐厚的利潤。這種型態的適當放空對象，是屬於已經跌到無人喜愛類股中的部分個股。如果你能找到這樣的一支股票——如同一九七二年的Winnebago，而且倘若它曾經爲法人機構所偏愛那就更好了。法人機構由愛生恨時，你可以更加安穩地下賭注，並認定它一定會出現恐慌性賣壓而造成長期跌勢。
