# 為何放空令人如此畏懼？

如果你遵循我的法則，相信你可以看出放空所涵蓋的風險不會大於買進。如果是這樣，為什麼有如此多的人拒絕放空，為什麼他們會對這個非常重要而且有利可圖的技巧如此恐懼？以下是這幾年所聽到的一些最尋常的答案。

很多投資人認為放空非美國式作風。他們相信，我們都應該希望公司運作良好。他們的行為看起來就好像是在為當地的棒球隊或足球隊加油，而他們不希望成為叛徒。因為多數美國人的天性傾向樂觀，而放空通常被視為是負面的消遣。

我對上述說法的反應很單純。對市場與經濟現況予以瞭解絕對沒有錯。週期循環也是生活的現實，當股票進入下跌的第四階段時，仍繼續持有它與愛國心並沒有關係。同理，股票開始崩跌時，將它賣出避開巨額虧損則是理性的行為，而從跌勢中獲利也同樣合理。

放空實際上也提供了十分有效的經濟功能。放空會增加股票下檔的流通性，所以某支股票遭到痛擊時，跌勢終究會緩和。畢竟，某人放空 X Y Z 必須在某時點回補。每一筆放空都代表該股票的未來需求。股票下跌時，若放空者必須回補該股票，這種需求實際上還可以緩和跌勢。
