# 圖4-12

圖4-12顯示，XYZ股價位於圖形上半部，其對應之XYZ相對強度則在圖形底部。注意其股票價格行為雖屬中性——在51到55的交易區間內移動——但其相對強度線卻道出不同故事。該情況有利於從這個交易區間向上突破。另一方面來說，即使該股票最後愚弄了我們而向下突破，我們也別想放空該股。一支股票只要出現優越的相對強度，它便是在大聲清晰地告訴你，其跌勢將被偶限，所以請另尋放空對象。但如果你持有該股，你仍必須尊重向下突破的走勢而出場。

這裡還有另一個方法來保有自己的RS圖。有些圖形服務公司(註8)會將相對強度納入其圖形中。
