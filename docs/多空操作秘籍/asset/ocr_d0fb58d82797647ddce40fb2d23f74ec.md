# 5. 在負面情況下，不可向下攤平。

不論你是觀察一九七四年Polaroid（圖6-10）從接近150跌到16，或是看一九八五年Western Health Plans（圖6-11）從15.875跌到二年後的3處，其細節都相同。這些都是進入第四階段的股票，應該賣出持股。不幸的是，很多投資人卻落入了基本分析的陷阱。首先，他們持有該股是因為它是（或者他們認為是）好公司。當他們發覺自己陷入困境時，便決定在下波反彈中解套出場。這是市場被虐待狂中之最。在大多數的第四階段轟擊下，股票根本就不給你解套出場的機會。然後恐慌接手，自作聰明的投資人終將因向下攤平而自作自受(註2)。這種技巧在理論上極佳，但在實務上無異自殺。採用這種危險技巧的人，等於在乞求財務大災難。一九八三年到一九八四年間的Anacomp（圖6-12）與一九八一到一九八二年間的Halliburton（圖6-13），只是數百個案例中的二個範例，這些例子顯示，如果採用這種愚蠢戰術，你會被一掃而光。Anacomp向下跌破18而一路挫跌到2時，它出現明白的賣出訊號。Halliburton在向下跌破移動平均與位於70的支撐而一路跌到21時，它也出現賣出訊號。

(註2) 向下攤平是於較低價格買進較多股票，使平均持股成本降低的做法。
