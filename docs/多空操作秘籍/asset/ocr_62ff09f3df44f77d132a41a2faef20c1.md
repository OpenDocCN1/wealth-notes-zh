# • 選擇權：非常刺激但很危險的遊戲

下一個要探索的投資工具是選擇權。如果說投資領域「不適合寡婦與孤兒」，那麼這句話必然也適用於選擇權的領域。這項工具只適合專業人士與高風險玩家！即使是在最佳的情況下，選擇權仍具有高度的風險性。當然從另一面來說，如果判斷正確，你的收穫也將十分驚人！雖然我無法教你如何把選擇權的風險水準降低到如同公用事業類股一樣，但我可提供一些秘訣，稍微降低它們的風險。而且更重要的是，這些概念將可增加你的獲勝機率。

對於不熟悉選擇權的人來說，這裡提供了一段買進與賣出選擇權（call and put options，簡稱『買權』與『賣權』）的簡要描述(註3)。如果擁有買權（call），你便有權利在某特定時間內（到期日之前），以某既定價格〔履約價格（the striking price）〕買進一支股票。你買進該選擇權所支付的價格稱爲權利金（premium）。當你購買買權之後，就會希望該選擇權所設定的股票急速上漲，而這就是使得該項金融工具變得十分難以掌握的原因，因爲通常對股票上漲的判斷，你很可能是正確的，但如果漲勢在你的買權到期之前不曾發生，你的運氣就沒

(註3) 選擇權在金融市場屬於另一個領域，有其個别的交易所，術語和交易規則。我在此假設你對選擇權的基礎有一定的認識。如果沒有的話，請與你的經紀人聯絡，他們應該可以提供給你一些基本的說明資料。
