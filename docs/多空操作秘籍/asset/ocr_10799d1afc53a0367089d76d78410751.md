# 測量市場動量

紐約證券交易所的騰落數據，還有一些其他的利用方式。其每週的數據可作為你另一種長期分析的工具。每天的數據也可以用圈又圖的方式繪製，而不一定要採用我剛剛教你的繪圖方式。最後，為了交易目的，也可以製作短期振盪因子（oscillators）。每一個因素都可為市場走勢提供深入的洞察力。我在《專業軌跡解讀》中採用所有這些指標，因爲我覺得這些重要統計數據是技術分析的根本。只要你依照我剛才所教導的背離分析基礎來追蹤每天的數據，並配合另一個長期指標，就可以相當不錯地感受到騰落現象。這項指標具備有(1)非常精確，(2)易於解釋，及(3)計算快速的優點。我稱之爲動量指數（momentum index，MI）。它實際上就是紐約證券交易所騰落數據的200天移動平均。

在測量市場動量時，你實際上運用的是牛頓的物理定律。但在分析股票時，它應該修改爲「一個運動中的趨勢可以預期將持續到它反轉爲止」。換言之，不必在意小幅的波動，只要把你的注意力其中在主要趨勢上即可。這就是動量指數（圖8-10）能夠協助你之處。
