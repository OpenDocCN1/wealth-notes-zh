# · 讓我們以同樣的語言溝通

在利用圖形開拓你未來的獲利之前，有一些基本術語是你必須熟悉的。圖1-6將幫助你瞭解它們的意義。縱使你過去並不偏好技術分析，你也可能已經聽過或看過這些術語了。但即使如此，或許你還是對它們的確實意義感到有點印象模糊。沒問題，我們只要快速回顧一下，即可達到釐清的目的。縱使你是熟練的技術分析師，也請檢查我是如何定義這些術語，如此我們才能採用相同的方式溝通。這是非常重要的，因為這些術語是我技術分析方法的構成要素，本書將會不斷的使用到它們。所以請花費一、二分鐘瀏覽這些定義，確定每一個名詞的意義。如果你在本章善盡本份，那麼本書將十分易於理解。而且這也有利於你。如果你對某個名詞不是百分之百理解，往後你可隨時參閱本節的內容。
