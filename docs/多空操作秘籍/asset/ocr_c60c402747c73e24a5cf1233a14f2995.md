# 圖4-28

以Anchor Glass Container（圖4-28）的案例而言，該股跌到10（A點）之後，再漲升到14.125處。第二波賣壓使該股在一九八六年底跌回10.5處。然後開始進行緩慢的漲升，成交量也開始增加（這是一項有利的徵兆）。但是在到達13.5處，漲勢仍無法清除在14.125的重要壓力，因此接下來數週內又處於盤整的狀態。然後，該股一旦移到趨勢線與14.125壓力之上方以後，第二階段的漲勢便發動了。

在Sun Microsystems（圖4-29）的案例中，雙重底非常快速地形成。一旦移到15.125壓力上方之後，它便已準備妥當進入軌道。注意相對強度在此時上升良好且進入正值區。另外，成交量令人印象深刻。最後，當其克服20的水準後，上檔便已沒有進一步的壓力了。
