# 第8章

# 運用最佳長期指標辨識多空市場

在一九七五年一月、一九七八年三月，與一九八二年八月，當時若能積極買進，豈不是很好嗎？這幾個關鍵時刻，都恰好發生在主要多頭市場正要展開之前。而在一九七三年一月、一九七六年底、一九八一年七月，以及一九八七年十月初等主要空頭市場造成慘重傷害之前，如果能轉進極端防禦性的部位，那就更好了。《專業軌跡解讀》做到了——相信你也做得到！

一九八二年七月，當時很多經濟學者發表評論，認為經濟嚴重衰退還要持續一年或更久。道瓊工業股價指數處於800點之下，一位廣受尊崇的市場權威人士預測它將崩跌至少到500點——大衆傾聽而且信以為真。在空頭走勢進行十二個月之後，我在一九八二年七月二十二日的《專業軌跡解讀》寫道，「我們正處於一個新多頭市場的蘊釀階段。這是我們從一九八一年六月份轉爲空頭市場以來的第一次，希望各位利用所有回檔時機買進。」三週之後，市場觸及770的盤中低點，其他一切皆成爲歷史。本世紀最偉大的多頭市場之一從此展開。
