# 實際的案例

為了瞭解這些投機性工具多麼具有獲利性，讓我們追蹤我在《專業軌跡解讀》中推薦的幾個選擇權之發展情況。在一九八七年一月初時我曾建議訂閱者，如果Texas Instruments（TXN，圖9-9）普通股突破其於125的主要壓力，就可以購買其買權。當TXN確實穿越125.5時，你可用大約7美金的價格購買四月份到期而履約價格為125的買權。到了四月初，當TXN抵達其於203的高點（B點）時，買進選擇權的內含價值為78美元。這便是槓桿力量所創造出令人興奮的感受。雖然普通股出現令人欣羨超過60%的漲幅，但買權則狂升超過了1,000%。
