# ・以停止買單保護空頭部位

現在你對我接下來要討論的內容，應該已有了很好的概念。這其中並無令人驚訝之處，而僅是將我在第三章所教導各位的停止賣單概念應用在空方。如果將我們在第六章所討論有關停止賣單的每一個論點予以反轉，你就應該已經知道怎麼做了。我將快速講解一個理想範例以及幾個歷史案例，以確定你已完全瞭解。對我而言，這可是放空獲利的真正關鍵。第一，當你放空時，它能帶給你平靜。不要低估心理平靜的重要性；如果你對市場行為感到緊張，你的情緒便常常會超越你閱讀圖表的能力。第二點，如果放空部位的走勢不利於你，這項紀律將可確保你只會有小小損失。最後，一旦你的股票開始崩跌，它可以保證在第四階段不斷前進時，你的獲利也將隨之增加。
