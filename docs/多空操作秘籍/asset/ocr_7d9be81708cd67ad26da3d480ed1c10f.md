# 3. 不可因爲本益比低而持有該股票。

即使你的股票已經在做頭部，但本益比還是經常會處於很便宜的水準。通常股票都會先下跌，幾個月的之後令人失望的盈餘報告才會出現。到時候本益比看起來也就不低了，只是一切爲時已晚，持股已無法有利地出脫。另外，在很多案例中，即使本益比很低——而且一直維持在低水準，股票仍遭痛擊。圖6-7的Chase Manhattan（C M B）便明確說明了我的看法。C M B在一九八六年價格於50處時，本益比只有7倍。很有趣的是，在十三個月之後，其本益比更低至只剩6倍。不幸的是，該股已進入第四階段，股價由接近50跌到34。低本益比做爲持股的理由又如何呢！
