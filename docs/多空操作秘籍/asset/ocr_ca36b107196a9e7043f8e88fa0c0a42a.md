# 測驗

+   1. XYZ股票由50上漲至60，這是20%的漲幅。同時，對 錯
道瓊工業股價指數漲幅為25%。這是相對強度佳的例子。

2. 一條趨勢線遭到碰觸而未遭破壞的次數愈多，該趨勢 對 錯
線愈重要，而該趨勢線最終若被突破則更具意義。

3. 一條趨勢線的上升角度愈陡峭，向下突破該線則愈不 對 錯
具意義。

4. 股價移至交易區間內是多頭訊號，因為它顯示買方較 對 錯
賣方積極。

5. 一支股票處於交易區間而在反彈前跌到8。在上漲之 對 錯
前，第二次下挫跌到8.5。在彈升之前，第三次跌到
8.25。整個8至8.5的區域可視為支撐地帶。

6. 壓力地帶遭到衝擊而未被克服的次數愈多，該地帶最 對 錯
終的突破愈具多頭氣勢。

7. 不論基本面多好，永遠不要買進一支在三十週移動平 對 錯
均下降趨勢線之下交易的股票。

8. 一支股票突破壓力地帶成交量萎縮是很好的買進機 對 錯
會，因為它顯示賣方很弱而且還在轉弱中。
