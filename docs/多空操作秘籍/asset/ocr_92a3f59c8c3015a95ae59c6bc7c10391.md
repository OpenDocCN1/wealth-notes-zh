# ・真實的世界

現在你已經登堂了，接著讓我們來研究第二階段強力上漲與第四階段大災難的一些實際例證，以說明它並非「理論上有效而實際上無效」。沒有什麼能比事實更真實！雖然沒有任何一種預測市場的方法是絕對正確的，但我們在這裡所看到的結果是如此之好，好到令你難以相信！

在未來的章節，我將透露如何將狀況未如計劃所產生的負面效果予以極小化。現在請先看圖2-10至2-13的四支股票。它們在進入第二階段時，所有的股票都應該買進，猶如《專業軌跡解讀》所提供的建議（參閱箭頭）——當時它們正突破它們第一階段的底部。

當Starrett Housing（圖2-10）上漲到10之上時，等於是在一九七五年初完成了重要的第一階段底部。接下來移動平均翻揚，這正是一個節節上漲的例子。該股在未來六個月內上漲到24（相當於年率280%的可觀漲幅）。請注意，六個月內的所有盤整都發生在移動平均上升趨勢的上方。

當ARA Services（圖2-11）在一九八二年以巨量向上突破30時，它也表現出類似的勝利模式。它在未來九個月漲到55附近，呈現了相當不錯、約等於100%的年獲利率。後續所有的盤整，也都處於移動平均之上方。
