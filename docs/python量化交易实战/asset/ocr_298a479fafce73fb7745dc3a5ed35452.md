# 7.2.3 价差偏离度因子介绍

价差偏离度因子本质上是一个相对意义上的反转因子，价差偏离度低，近期跑输共同类股票，股票相对处于低位，有向上回复的动力，有正的预期超额收益；价差偏离度越高，股票处于相对高位，后期有回调的压力。
