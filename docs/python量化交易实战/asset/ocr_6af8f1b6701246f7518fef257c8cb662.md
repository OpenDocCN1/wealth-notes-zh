（6）使用峰度 Kurtosis 代替波动率。

```
def Kurtosis_get_estimator(price_data, window=30, clean=True):
    "峰度 Kurtosis 代替波动率"
    log_return = (price_data['Close'] /
    price_data['Close'].shift(1)).apply(np.log)

    result = log_return.rolling(
        window=window,
        center=False
    ).kurt()

    if clean:
        return result.dropna()
    else:
        return result
```
