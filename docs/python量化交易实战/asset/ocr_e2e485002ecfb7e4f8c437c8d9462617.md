# ◀ 回归模型的经典应用 ▶

回归分析是最常用的量化策略之一。前面在回归模型的基础讲解中，对使用 Python 进行回归模型计算做了介绍，包括使用回归模型对股价进行预测以及使用逻辑回归帮助股票买卖者进行决策等。

事实上，更多的回归模型应用于对股票的基本面数据进行分析，例如经典的 CAPM 模型、Fama-French 三因子模型以及最新的 PB_ROE 模型。这些都是已经应用于现实中的金融市场并获得认同和较好的收益的经典模型。图 10-1 所示为回归模型的示例。
