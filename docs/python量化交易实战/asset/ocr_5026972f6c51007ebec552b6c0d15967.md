前面对 Python 的安装做了基本的介绍，并且建议读者使用 PyCharm 免费版作为使用 Python 编写程序的编译器。相对于使用控制台或自带的编译器，可以更加直观和明晰化地对所构建的工程做出层次安排。

本章将着重介绍几个常用的统计学类库，针对量化投资的专用类库将在后面的章节介绍。
