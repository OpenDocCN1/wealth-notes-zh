# 第三步：TensorFlow 中逻辑回归模型的设计

在 TensorFlow 中，对于逻辑回归设计了便于使用的模型，代码如下：

```
classifier = tf.estimator.DNNClassifier(
    # 这个模型接受哪些输入的特征
    feature_columns=symbol_feature_columns,
    # 包含两个隐藏层，每个隐藏层包含 10 个神经元
    hidden_units=[128, 128],
    # 最终结果要分成的几类
```
