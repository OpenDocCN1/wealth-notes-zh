# 4.1.1 安装掘金终端

在处理测量数据时，经常要研究变量之间的关系。变量之间的关系一般分为两种：

+   o 完全确定关系，即函数关系。

+   o 相关关系，即变量之间既存在着密切联系，但又不能由一个或多个变量的值求出另一个变量的值。
