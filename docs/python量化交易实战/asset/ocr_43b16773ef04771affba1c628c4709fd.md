换句话说，回归算法是一种基于已有数据的预测算法，其目的是研究数据特征因子与结果之间的因果关系。举个经典的例子，表 9-1 为某地区房屋面积与价格之间的对应表。

# 表 9-1 某地区房屋面积与价格对应表

| 价格（千元） | 面积（平方米） |
| --- | --- |
| 200 | 105 |
| 165 | 80 |
| 184.5 | 120 |
| 116 | 70.8 |
| 270 | 150 |

为了简单起见，在该表中只计算了一个特征值（房屋的面积）和一个结果数据（房屋的价格），因此可以使用数据集构建一个直角坐标系，如图 9-3 所示。
