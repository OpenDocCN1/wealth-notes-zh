# 5.1.4 MACD 斜率的计算方法

MACD 的值只能用于反映不同时间周期内的买卖趋势情况。而对于上涨的快慢，MACD 并没有提供相应的函数去进行计算，此时读者可以通过其他的既有函数去获取相应的值。

斜率表示一条直线（或曲线的切线）关于（横）坐标轴倾斜程度的量。它通常用直线（或曲线的切线）与（横）坐标轴夹角的正切，或两点的纵坐标之差与横坐标之差的比来表示。
