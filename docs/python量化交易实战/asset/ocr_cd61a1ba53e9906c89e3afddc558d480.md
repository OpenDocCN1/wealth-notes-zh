不同颜色之间显示了不同的相关性，彩色的深浅显示了相关性的强弱程度。对此读者可以通过打印相关系数来直观地显示数据，相关系数打印方法如下：

print(corMat)

农业灌溉用水主要来自于天然降水和地下水。随着中原经济区的发展和城镇化水平的提高，城市用水日趋紧张。下面以河南省降水量的变化及分布规律为例进行介绍，为合理调度和利用水资源提供决策。

# 3.5.1 不同年份的相同月份统计

对于不同年份，每月的降水量也是不同，一般情况下，降水量会随着春夏秋冬的交替呈现不同的状态，一个横向变化的过程。对于不同的年份来说，每月的降水量应该在一个范围内浮动，而不应偏离均值太大。
