# 愉快地相好，就能吵越相愛

藉由「不一致」平息怒火

深入交往後，兩人難免會起爭執。

不過，有些情侶常因一點芝麻小事爭吵，遲遲不肯和好。儘管有個說法是「感情越吵越好」，然而吵得太過火也不行。

人在爭吵時會感到憤怒，會理性全失，只憑情緒行動。如果平時心裡累積了什麼不滿，也會趁此時怒火中燒，一口氣宣洩出來。

有個方法，能讓爭吵後的雙方感情更好。

模仿對方的動作與姿勢，試圖與對方協調，這個技巧稱為「一致matching」。此處則要運用「不一致」(unmatching)，也就是和對方的動作相反。
