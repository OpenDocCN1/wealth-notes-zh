# 即使對商品沒興趣也絕對會買
以「重複誘導性提問」技巧強化印象

有些業務員為了成交，會變得過於急切。雖然明知不該如此，然而老是等待對方答覆，正是無法達成業績的最大主因。

此時，可以運用「重複誘導性提問」（suggestive question）這個技巧。

美國肯特州立大學（Kent State University）做過一項實驗：先讓實驗對象觀看某段影像，之後再給予「錯誤的訊息」——其實影像中的人物光著手，卻以錯誤的訊息如「戴著手套的人．．．」為了隱藏指紋而戴著手套．．．」給予不

同於事實（影像）的印象。
