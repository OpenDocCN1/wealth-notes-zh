# 让对方知道，你想要的不只是朋友

不论做生意或谈恋爱，必定会有一起用餐的机会。
人在进食时，是最没有防备的状态。
难得约了对方吃饭，如果饱餐一顿就各自回家，未免太可惜了。
美国心理学家詹尼斯 (Irving Janis) 进行过一项知名的「感觉很好」(feeling good) 实验，也称为「花生与百事可乐研究」(peanuts and pepsi study) ... 他将大学生分成两组，阅读四个主题的论文，分别关于「癌症治疗」、「美国军队规模」、「月球旅行」、「3D 电影」。内容相当艰涩，即使平时习惯阅读的人也会大吃不消。
其中一组让他们在阅读时边吃花生边喝可乐，另一组阅读时则没有得到任何食物。
