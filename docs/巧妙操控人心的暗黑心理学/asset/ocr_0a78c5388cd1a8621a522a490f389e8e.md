# — 看某人就討厭？或許是你的心锚在作案！—

勾起我們的回憶，進一步引發諸如害怕、厭惡等情緒。

那麼，在公司裡有不對盤的主管時，應該怎麼做呢？

很簡單！去除心锚——試著打聽主管的個人背景，也就是家庭、個性等相關資訊。盡量多與主管接觸，不要抗拒、不要逃避。

清除心中的偏見，才有可能改善與主管的關係，讓工作順利進行。

由於心锚所設定的心理狀態，往往會讓我們僅憑外表或說話方式來判斷對方。當你越瞭解對方，原本穩固的心锚記憶就會漸漸淡化，直至失去作用。

這是NLP（神經語言程式式學，是以心理學與語言學為基礎的溝通技巧）經常使用的訓練方式，請務必一試。
