# 不拍馬屁，也能得到主管的青睞

以「自我狀態問卷」分析真實個性

不出人頭地就無法獲得加薪，也無法帶領下屬。被主管提拔是最快的捷徑，但是為了討好主管猛拍馬屁，反而會失去信用。

這種時候，要學會「讀重點」（focus reading），瞭解主管的真實性格，投其所好。

想分析主管的內心，可以運用「自我狀態問卷」（ego gram）這個方法。

這是企業也經常用來瞭解員工人心理狀態的測驗。

內容是分析五種面向，是每個人都具備、但是有所差異的特徵。簡單來說就是：「父親的角色」嚴厲」、「母親的態度」溫柔」、「大人的態度」理性」、「自由的心」自由奔放」、「好孩子的」協調性」。
