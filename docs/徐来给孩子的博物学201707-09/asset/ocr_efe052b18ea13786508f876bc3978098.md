# 为什么人类不登陆火星呢？

![](bbox=[0.25, 0.29, 0.9, 0.36])

这个问题问得好。人类为什么登陆火星？人类要想登陆火星，那也得能登得上去是不是？

我们的航天事业，可以分成载人航天和不载人航天两类。前者载人，后者不需要人来设计生命维持系统。你需要准备足够的氧气、水以及食品，要处理人排出的废物，去往星际的旅程，远程就要持续好几个月，所以说，得点儿水喝，还得能上厕所，看那么四五个月，这是很长时间的，所要求的生命维持系统就持续性好，而且，这个维系统必须得稳定，否则，只要稍微有一小段时间，人都可能无法生存下去，更重要的，是这期间人寂寞孤独旅途中，可能会导致精神出现问题，那就糟糕了。

# 为什么把耳朵贴在海螺的壳口上就能听到海风声音呢？

![](bbox=[0.25, 0.53, 0.9, 0.6])

徐来

首先，你这个问题是错的。我们把耳朵贴在海螺的壳口上，确实会听到一些声音，但不是海风的声音，海螺里并没有海风，如果你把耳朵贴在海螺的壳口上，听到声音，那你知道，海螺里的声音就是海浪一样。

好，接下来的问题是，海螺里是什么声音呢？

其实，我们生活的这个开敞的环境中，是被各种各样的声音淹没的。各种各样的声音混在一起，我们就会觉得，这种声音，无处不在，但是人一般不会注意到，因为我们的耳朵太适应了这个环境，这样你就可以把周围的耳朵中那种噪音屏蔽掉，让你可以听到周围，你的耳朵中，声音，或者你听到自己的耳朵中，声音，就有点像海浪一样。

不过，如果我们进入到一个相对密闭的空间，比如把耳朵贴在海螺的壳口上，那么声音，海螺中声音，就会显得更明显，如果你听了一会儿，你就会觉得，这声音，像海浪。

我们全家都爱听这个专栏，听完之后我们一起讨论一个问题：北极冰下的水，如果融化了是咸水还是淡水？因为印象中，淡水是很难结冰的。

![](bbox=[0.25, 0.8, 0.9, 0.87])

徐来

是的，水中的含盐量越高，冰点也就越低，但是一旦开始结冰，情况就发生变化了。

水结冰的时候，先形成小冰晶。小冰晶有个特点，它有挑性，会把水里的有些杂质量排掉。其中当然也包括在水里的盐分。所以，小冰晶并不是含盐的。不过，小冰晶和小冰晶会粘在一起，粘成冰，但是冰层与冰层之间可以保留一些盐分，这些盐分极少，所以总体来说，冰是淡水。

蚯蚓是分解者吗？

徐来

不是。蚯蚓主要是吃植物，也有些动物也吃，但是无论它吃植物的还是吃动物的，它都是食物链中的一环，不是分解者。我们通常说的分解者，是微生物，它们分解尸体，是分解者，而蚯蚓不是。
