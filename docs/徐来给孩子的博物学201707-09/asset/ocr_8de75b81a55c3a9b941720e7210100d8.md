# 什么是提花机？

它们当然有关系，不但有关系，关系还挺密切的。更重要的是，虽然我们是在看织布机，但看得有点过时，但我们看的是非常新的设备，是世界技术发展的象征。那个时候，人们看着织布机的时候，眼睛却在看着计算机，那是从什么时候开始的？这是从200多年前开始的，那时候，欧洲在18世纪的那段时期，进入第一次工业革命时期，产业革命是什么呢？工业革命就是人们从手工劳动向机械化大批量生产的一个阶段，简单地说，是向着人类那个时代最大规模地使用各种劳动机器。这次工业革命的核心是机器的发明，在18世纪，织布机就开始发挥作用。纺织机在我们生活里，是穿着在身上的衣服、床上的东西，这是从织布机开始的，纺织厂是第一个被改造的工厂。

织布其实很难，它也不难，织布要有很多线，那些线先纵向地排列好，一根一根的并排在起，那根，就叫做经线。经线是固定的线，那个横着排起来的是纬线，就叫做纬线。我们织布，就是让那根纬线，从经线中间穿过，把经线缠起来。一根一根地拉，一根一根地织。这样，第一根线在经线上，第二根线在经线下面，第三根线在经线上，第四根线在经线下面，就这样，一块布织好了一小部分。

![](bbox=[0.2, 0.6, 0.8, 0.7])

不过，这样织出来的布，颜色是单一的，线是什么颜色，整块布料就会是什么颜色。原来有人想了个主意，把经线分上不同的颜色，然后来织，这样就能用不同的颜色，在织物的正面做出一定的图案和花样。这就好漂亮了，这种方法，被称作“提花”。

![](bbox=[0.2, 0.8, 0.8, 0.9])

提花的织物是比较高级的织物，因为要织成图案的话，需要让经线在特定的位置上穿过。织机就需要一个复杂的机构，按照复杂的程序来操作，才能完成工作。

这种情况到了将近300年前终于发生了变化，在一个叫做雅卡尔的发明家里，发明了一种很有用的提花机。他在一条纸带上按特定的方式打孔，然后用这些打孔来控制经线的起落。虽然纺织工们还是不停地看着这些纸带，但至少不用死记硬背那些复杂的花式了。所以，这种半自动的提花机，一下子引起了关注。当时的人们不知道，这个发明意义重大。在上面打孔的过程，换成一个存纸的过程，在纸带经过的时候，纸带上的孔在特定的位置上被读出来，就形成了一个程序的指令。这个过程，也就是把织花的指令存储在了纸带上。

# 什么是雅卡尔织布机？

这个发明后来经过了几个发明家的改造，最后到了1801年，一个叫巴贝奇的人手里。巴贝奇是英国的数学家，他设计了一种机器，用来做计算，叫差分机。差分机是一种计算器，可以做一些非常复杂的计算。

1836年，巴贝奇在差分机的基础上又设计了一台新机器，叫分析机。这台机器可以执行复杂的运算，可以存储数据，可以控制流程。它的设计非常先进，是计算机的直接先驱。

分析机需要一个输入设备来读取指令和数据，于是巴贝奇想到了雅卡尔的提花机。他决定采用纸带作为输入介质，通过打孔的方式来控制机器的运行。这样，分析机就可以通过纸带来控制运算，就像提花机通过纸带控制织布一样。

巴贝奇的分析机并没有在生前造出来，但他的思想影响了很多后来的计算机科学家。19世纪，分析机的设计被很多人研究，包括著名的逻辑学家布尔。布尔发明了布尔代数，这是数字电路的基础。

# 巴贝奇没有造出来的计算机

我这里的计算，可不只是算一两个数，而是可以完成复杂运算的通用机器。虽然巴贝奇没有完成这台机器，但他的设计思想已经被后人继承和发展。

到了20世纪，冯·诺依曼提出了存储程序的概念，计算机可以存储并执行指令，这直接继承了巴贝奇的思想。现代的计算机，虽然形式上发生了变化，但其核心思想仍然来自那些先驱的探索。

织布机到计算机的旅程，说明了技术发展的连续性。每一种技术都是在前一种技术的基础上不断改进而来的。从手工操作到自动化，再到智能化，人类的技术史是一部不断进化的历史。
