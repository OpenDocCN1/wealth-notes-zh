# 宇宙 | 行星 | 土星为什么有光环？

为什么有些东西旋转起来快到一定程度，感觉旋转的方向和实际旋转的方向是相反的，比如汽车的车轮、陀螺等等。

![](bbox=[0.05, 0.66, 0.95, 0.74])

徐来
这个会很有意思的问题，我们在观察很多高速旋转的东西时，都可能出现这种现象，比如电扇、车轮等等。这个现象可能与视觉系统有关。

因为这些高速运动的物体，它们的运动变化都是连续的，但是人的大脑接受这些视觉信息时，可能是不连续的，就像电影画面一样，是一帧一帧的，虽然这种比喻不太准确。

但是你可以理解为，我们的大脑本身就像在看动画片，只不过每一帧的间隔时间非常非常短，所以我们可以很流畅地感觉到这种间隔。

但当大脑碰上高速旋转的物体时，物体本身转了一圈儿，大脑里收到的信息，只转不到一圈儿，如果这样重复信息下，我们看到的影像里，就会呈现出一种在它倒转的效果。
