# 生态学·植物 | 也许有一天，我们再也吃不到香蕉了

世界好大，奇妙的事情每天都有，一起去发现吧！

今天我们讲的知识跟香蕉有关，如果你们家里有香蕉可以拿一根，一边吃一边听我讲。

好了，进入主题，如果我们要做个水果评选的话，你知道谁是冠军？

估计三，香蕉应该拿不了第一，但肯定能进前几名。拿不了第一是因为，它其实不像香蕉产量。在常见的水果当中，它的淀粉含量其实是非常高的。要知道，我们平时吃的许多水果几乎都不含淀粉，且几乎很少。香蕉的淀粉量有一点程度上决定了香蕉的口感，吃起来有点绵绵的，没有太多水分。其实，在香蕉还是青色的时候，没熟的时候，香蕉里的淀粉含量更高，在没多少产香蕉的地方，这种还没成熟的香蕉，是被当做主食吃的。

香蕉又是一种非常重要的水果。全世界每年生产的香蕉产量，排在柑橘、咖啡、苹果之后，名列第四位。不过，因为前面三种水果榨汁的比例挺高的，而香蕉几乎完全没有法榨汁，所以，大家平时能触到香蕉的比例很可能高于前面三种水果。

# 什么是华蕉？

如果我告诉你，我们很可能很快就吃不上香蕉了，你会怎么想呢？要不要赶紧吃一根香蕉压压惊啊？

我可没有跟你开玩笑。我们确实很有可能很快就没有上香蕉了。因为，现在很有可能种业，正在受到一种疾病的全面打击，而且是毁灭性的打击。打击的源头，是一种真菌，它会感染香蕉，让它们生病，然后继续感染周围香蕉，死亡，这种病比成香蕉的癌症。

更糟糕的是，虽然香蕉的品种很多，估计超过100种，但在全世界以商业为目的的种植香蕉中，却几乎全是同一个品种的。这个香蕉品种，叫做华蕉。这是在中国发现的一个品种，据说，是一个英国探险家在华南地区发现它，它口味更好，也能够方便运输，所以对于现在的香蕉种植者来说，这几乎是唯一的选项了。这些香蕉树因此之间太相似了，以至于只要有一棵对这种病没有抵抗力，那么全世界的香蕉，都可能会被这种病感染。

但让人想不到的是，60多年前，这种真菌导致的另一种病，却把华蕉赶下过香蕉界的王座。

# 什么是大麦克香蕉？

在60年前的时候，人们吃到的香蕉不是华蕉，而是另外一种，被称为大麦克的香蕉品种。这个品种，是一位法国博物学家在东南亚被带到美丽的。跟现在品种的香蕉相比，大麦克不好个头更大，口味更好，而且产量更大。再加上果实质密，更耐运输，所以很快就成了当时有商业价值的香蕉品种。那个时候，跟现在华蕉的是一模一样。可是，要不怎么说天不绝人，大麦克上市没50年，也就差不多上个世纪50年代外出的时候，它就被真菌感染了，并且很容易也容易。更糟糕的是，现在前面说的那种病菌产业就开始感染，整个美洲的香蕉种植商业完全被摧毁，无数的香蕉公司破产倒闭。

眼看着人类就要没有香蕉吃了，怎么办？这个时候人类想起了种在温室里的华蕉。虽然整体上要比大麦克差一点，但，这个整体并不那么可以接受的时候，所以大家又开始种华蕉。如今，华蕉眼看就又要走上跟大麦克一模一样的老路了。

这事儿可不少。所以，大家到底想着怎么拯救香蕉。
