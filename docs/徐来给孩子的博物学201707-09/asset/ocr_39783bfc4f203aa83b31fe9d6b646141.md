# 12年后撞击地球的小行星

现在我要跟你说的这颗小行星，名字就有点吓人，叫“毁神星”。这个名字来源于古代北欧神话，一个掌管黑暗和破坏的神。这听起来够“恐怖”了吧？

科学家也是最近这几年才发现这颗小行星的。那颗小行星是在2004年3月由美国科罗拉多州博尔德的天文台发现这颗小行星的。经过连续观测，科学家们用了两年多的时间计算出了它的运行轨道。

那么，要怎么算出小行星的轨迹呢？首先你得确定它是小行星，而不是地球。然后，你得计算它的轨道，看它是否有可能与地球相撞。

![](bbox=[0.05, 0.34, 0.95, 0.4])

当天文学家们看到这条运行轨道之后，有些人就开始紧张了，因为这颗小行星的轨道有可能与地球相撞。

两颗天体的轨道是有交叉的，就有可能会撞到一块儿去。所以，看到这个情况，天文学家们忍不住去推算了一下，这颗小行星和地球到底能相差多远。结果一算，还真不是个好兆头。

那在2004年的12月28日，这颗小行星被发现在距离地球约3840万公里，比月球还远。美国宇航局的科学家们预测，这颗小行星将在2029年4月13日非常接近地球，但不会相撞。

# 一场虚惊

这下子可炸锅了，因为这颗星既不是小行星，也没在月球上，肯定是个大发现。

不过，你别担心。虽然科学家计算出这颗小行星与地球相撞的概率很高，但概率依然很小。

既然危险系数这么高，天文学家们就决定要跟踪这颗小行星，看看它到底会不会撞地球。
