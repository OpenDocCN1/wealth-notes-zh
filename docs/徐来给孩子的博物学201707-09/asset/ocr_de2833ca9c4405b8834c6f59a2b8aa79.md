# 遗传学·植物|番茄是蔬菜还是水果？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

美味的番茄，你—定很喜欢尝。

吃番茄的方法有很多很多。比如番茄炒鸡蛋，放一点儿糖，酸甜酸甜的，好吃。如果要做的火候不小心放多了一点，还可以临时改成番茄蛋汤，也不难吃。番茄还可以拿来炖，炖个豆腐，炖个牛肉都不错。另外，番茄酱，也是餐桌上不可缺少的一个好东西。

当然，番茄也可以生着吃，随手拿过一个，洗洗，直接放到嘴边就啃了一—手应该也多少沾了点红色的汁吧。番茄的汁水很浓，口味嘛，跟吃番茄差不多。

可问题来了，番茄到底是蔬菜，还是水果呢？

![](bbox=[0.2, 0.19, 0.8, 0.25])

番茄最开始被称为“狼桃”。

这事儿得从头说起了。

刚开始的时候，番茄在中国可不是什么常 见的东西，那是个新鲜玩意儿。

番茄最初生长在美洲，墨西哥的阿兹特 克人被认为是最早种植和食用番茄的人。 还记得阿兹特克人吗？在我前面的内容里 讲过关于阿兹特克人的故事，传说他们在 战争中使用马铃薯作为炸弹，来反击对手。

当时阿兹特克人反击的对手是西班牙人。 西班牙人来到美洲之后，开始接手阿兹特 克人，占领他们的土地，从他们手中掠夺 财富。这些被掠夺的财富当中，就包括番 茄。

但是，西班牙人把番茄带到了欧洲，却不 好吃，而是把它当做观赏植物种植—会结 小小的红色果实，看起来确实挺好看的， 很喜庆，为什么不吃吃它呢？因为欧洲人 当时犯了一个极其主义的错误。

什么是教条主义？意思就是，别人怎么说， 他就怎么信，不知道变通。

番茄这个植物，属于茄科家族。这个家族 当中的很多成员在欧洲、亚洲本来就有， 大家很熟悉，它们看起来，跟番茄有点 像。叶子花，有的还都有点毒。但 是有一点，欧洲、亚洲的茄科植物，大多数 都有毒，是不能吃的。所以，大家看到 番茄，第一反应就是，这玩意儿有毒，不能 吃。

后来，甚至出现了一种说法，说巫师们利 用这种植物的果实，榨出汁来，制作成药物，然后喝下这种药物，他们就能化身为 恐怖的狼人。所以，番茄也慢慢的有了 “狼桃”的称号。

还好，后来人们还是忍不住诱惑，尝了尝， 开始品尝番茄的果实。这种重量的食物也 因此进入了我们的生活，当然，问题也就 出现了，就是番茄到底是不是水果呢，我问 你的一样，清楚到底是蔬菜还是水果呢。

什么是尼克斯斯赫登案？

这个问题，大概每个人都有自己的心目中 的答案，也有很多人觉得，不管番茄是蔬菜 还是水果，有必要搞那么清楚吗？

如果你这样想，就错了。真的有人很认 真地研究了这个问题，研究这个问题，也 不是不好玩，而是非常严肃的问题，而且 研究这个问题的机构也是很了不得的机构 一美国的联邦最高法院。

这么一个高起来有点搞笑的问题，至于要 闹到最高法院来了吗？这事儿真的挺有思 的。我来跟你说一说。

![](bbox=[0.2, 0.73, 0.8, 0.8])

这个案子发生在1893年。美国的大案子都有 名字，一般起叫“谁诉谁”，是起诉方， 也老是告诉谁。这个案子，名字叫做 尼克斯斯赫登案。尼克斯不是一个人， 一家人，是美国人做水果买卖生意的，赫 登是美国纽约州的一个关税员。尼克斯斯 赫登案的目的高明，要求对方还 钱。

还什么钱？税钱。什么税呢，我们买东西， 东西都要交税，如果是税是买贵了， 就算了，可能会多收税，多收了，当然就 应该还给人。可是怎么会多收了税呢？

原来，根据美国当时的税，商人从国外 进口蔬菜水果等，待遇是不一样的。进口 蔬菜，你就缴关税，挺高的：进口 水果的话，你可以比进口蔬菜少交一点 税。

这个尼克斯一家，进口的是番茄。赫登一 看，这个是番茄，番茄是蔬菜，所以你要 交这笔税，不交我就不放你走。尼克斯 没办法，只能把钱先交了。可是完了之 后，扭头就把赫登告了，“我明明进口的 是水果，为什么要交这个美元多的税？”

你看，看起来是一个要不要退税的争议， 但实质上，需要弄清楚，番茄到底是蔬菜， 还是水果。这个官司一打就到了联邦最高 法院。
