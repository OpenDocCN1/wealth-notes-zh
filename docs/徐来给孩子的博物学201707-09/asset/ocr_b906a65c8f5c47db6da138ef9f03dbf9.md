# 生态学·植物 | 吃人植物到底存不存在？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

如果我问你，“你知道的最可怕的植物，是什么？”面对这样的问题，你会怎么回答呢？我相信，你肯定不会说：“植物有很多可怕吧，它们长在土里面，牢牢地被土地给困住了，根本动不了，怎么可能可怕呢？就算有些植物，是有毒的，那也不怕啊，不去碰它不就没了，它总不能把自己的根给咬断，然后跑过来咬人吧？”

可是，在我跟你差不多年纪的时候，想法可不是这样的。在那几个头，市面上流传着很多关于世界各地“奇异闻事”的书，还有一些小报杂志，也经常刊登这样的内容，什么外星人绑架地球人呀，魔兽三角啊，野人和水怪球等等。书里面会介绍图，会介绍这类的书或者杂志，就在这种的氛围上，我曾经读到过一种非常离奇的植物。叫曼吃，莫曼多来，莫来。是是巴吹着叹息的意味。文字写的有气无，复。看起来有点像是莫名其妙的美。

白树，是说道是一种柏树。名字不重要，重要的是这是一种吃人树。

# 吃人树怎么吃人？

这种吃人树，生活在东南亚地区，在印度尼西亚的爪哇岛上。在以前交通不发达的时候，爪哇是个很偏的地方。所以，当地被认为很荒凉，没人愿意去的地方。吃人树就是生在这种人烟稀少的地方。

这个树并不高，只有八九米的子，树上垂下很多细细的枝来。一上，会，动。个样人。…人。不，人，，，，，，，，。

当然，吃人树想要把人整个儿地消化掉也没有那么容易，需要好长好长的时间。消化完了，它就会伸展所有的枝条，然后再等两个人过来自投罗网。

正所谓一物降一物，虽然吃人树要吃人，但是当地的居民部落也早就知道了它的这个习性，所以常常会设想当一些大牲畜什么的扔到吃人树面前去，让它牢牢抓住这些血腥的牲，当地人这样投喂吃人树也是无稽之谈的。他们这样说是为了赚到对财富，来取回细枝上分泌出来的黏液。黏液黏性，却是当地一种非常好的药物。吃人树虽然能吃人，但最终是会被人制服，为入们所用了。

# 吃人树不可能存在

这是我可小时候读过的吃人树的故事。在那段段时间里，我都觉得这种树常恐怖，以至于和父母一起走南方城市，比如广州旅行时，看见路边的榕树，都远远地绕着走。因为榕树的枝上常下许多的气根，气根就通着树木暴露在空气里的根，这让我想起吃人树的小枝。

不过，长大之后，对植物学了些了解，很快我就明白了，这世界上并不存在什么吃人树。实际上，确实有很多植物是“食肉”的，的有500多种的样子。它们大部分只能做食昆虫，而被统称为“食虫植物”。它们就是些动物的元素，所以，一般会比较穷，可以在石头缝里，或者浅水中。它们不会通过光合作用，制造养分。但是这些环境通常都缺少一种植物生长所必须的元素，所以，光靠光合作用，它们的长太也不会太这个不难理解，就像你如果偏爱的活，也会出现营养不良的情况。

所以，这些植物慢慢地演化出了消化虫子的能力，通过选代，来补养充缺的元素。即使吃不到“肉”，它们也就是营养不良而已。再加之主动捕食行为对植物来说确实没有自主，所以，能一个守住免的方式吃点虫子已经很不错了。

当然，也有些食虫植物个头长得比较大，不能吃肉虫子，也能吃陷入陷阱的老鼠。不过，这一类植物你也到此为止了。

# 谣言是这样传开来的

那么吃人树的故事，到底是怎么回事呢？实际上，关于吃人植物的说法很早就出现了，现在明确可以看到的关于这种植物的描述，出现在150年前的叫。

当时，美国的纽约有一份小报叫《纽约世界》，说它的小组，可见这些经会给一些经人听而又没有什么根据的据，当时，有一个叫威廉德姆，宾西的人，给一家报纸写了一个故事，当中提到了，德国旅游专家卡尔，李普西的一封信。在封信里，李普信了非洲的马达加斯加岛上的一种会吃人树。后来，这位“旅行家李普西”甚至出版了一本书记来描述自己的遭遇。

他说，当时和他一同在马达加斯加岛探险。在访问一处原始部落的时候，他们见到了一个部落人像他们一样坐在。一棵树的场景。树貌像一样人，缠绕，然后叶上他的身体，直到把他完全吃掉。

这个故事发表之后，立即引起了许多人的关注。各地的报纸纷纷报道。甚至还传到了中国。中国有一位非常著名的植物学家，被称为中国现代植物学的奠基人，胡认，在他回忆自己的中学时段时，就提到当时的老师在课堂上讲过这种会吃人树的故事。

那么这个故事的真相是什么呢？1955年的时候，有一位美国作家对此非常好奇，所以追溯着发表的情况，以及故事中的一些线索进行了调查。调查的结果让人非常惊讶，不光整个马达加斯加岛上的这个原始部落完全是捏造的，连旅行家李普西这个人都不存在。至于说出这个故事最多的，作者根本找不到谁这样的事，那就没人猜得出来了。
