# 牧羊竟然成了凶手

事情发生在将近100年前了，那是在1921年，地点是北澳洲。

当时，美国和加拿大的很多农场主发现自己饲养的牛羊正在大面积地离奇死亡。说“离奇死亡”，其实也不太准确。因为农场主们非常清楚地观察到了牛羊的直接死因。那就是——出血。

出血这一事儿，你一定有过体会，比如哪几碰了一下，擦伤一下就出血。但是通常这种出血都是小事情，把伤口稍微清一下，压一下，很快就会不流了。因为血液有一种叫“自凝”的机制。自凝就是自己凝固的意思，血液里有一些成分，会让暴露在外的血液凝固起来，变成血痂。这一点，就不再多讲了。

但这些牛羊却不一样了，它们一旦有了个小伤口，血就会一直流个不停，直到最后死亡。这不太对。一位兽医接到命令，去调查这事儿。很快，他就找到了问题的原因：唯一的新变化就是699250

他推测那一年，由于天气异常温暖，降水也格外充沛，所以温度高，湿度也大，这两个条件加在一起，导致当地牧场主们为牛羊储存的牧草发霉。兽医怀疑杀死牛羊的元凶就是这些发霉的牧草。

为了验证推测，他做了一个对照试验，他找来两组兔子，一组兔子吃发霉里发霉的牧草，另一组吃正常的鲜样牧草。结果在前一组兔子上，果然出现了出血不止的情况，而后一组兔子则没事儿。

![](bbox=[0.1, 0.5, 0.6, 0.58])

这样一来，问题就解决了：不是发霉的牧草致牛羊死亡的？那就不让牛羊吃这些牧草。这事儿到此，就算暂时被平息了。但是有些医学家觉得不行，觉得事不能就这么到此为止，需要研究得再清楚一些。

1940年，一位名叫林克的化学家，成功地从这些发霉的牧草中提取出一种物质，叫双香豆叶素。双香就是两个，香草叶素就是从双子叶的植物中分离出来的一种物质。双香叶素，就是两个香草叶素组成的一种新物质。林克发现，就是这种物质，导致血液无法凝固。

![](bbox=[0.1, 0.7, 0.4, 0.78])

# 歪打正着的老鼠药

让血液无法凝固的东西，看起来可杀死什么好物种。你看，这种东西可以杀死任何牛羊的对面？即便这样，林克还是找到了这种物质的好处。他把这种物质取名叫“华法林”，然后把它们包装成了老鼠药。后来，为了获得更好的灭鼠效果，林克还通过一些设计改良，让华法林的抗血凝效果变得更强了。

这可真是一个奇思妙想。因为老鼠是一种生性非常警惕的动物。如果它们看到同伴吃了某种东西，死掉了，那它们很可能就会提高警惕，不再吃那种东西了。可华法林有一好处，那就是可以延迟上。老鼠最终死去，需要一定的时间。这样一来，老鼠就无法把同伴的某种东西关联起来，灭鼠的效率就提高多了。所以，很长一段时间，华法林都是最受欢迎且效果相对好的，在人类当时也还用它来老鼠的数量。

不过，只要是老鼠药，都会面临一个问题，那就是有些人会用它来自杀。果然，到了1951年，有一个美国人尝试吃老鼠药自杀，他吃的就是华法林。他自杀的行为被发现后，立刻被送到了医院。幸运的是，医生用维生素K给他治好了，他很快就痊愈了。这个小插曲给了科学家们一个很重要的提示：那就是，对人类来说，华法林其实是可以救命的，即使人类也可以维生素K进行抗。这意味着，华法林就可以用到人的身上啦！
