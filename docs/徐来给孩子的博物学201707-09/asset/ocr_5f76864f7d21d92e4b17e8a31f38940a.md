# 几千年煮出来的一碗面

在说方便面之前，我们先来说说“面”，你离我们现在的“面”字，其实它是两个字，再加一个“麦”字。这个字的来源，是用麦子磨出来的粉，也就是面粉。所以，用面粉和水制作出来的条状的食物，就叫面条。面条再稍称一下，就变成了“面”。

不过，最早的记录可能是面条做的。我们看现在普遍的说，最早是面食，我们有4000年的历史了，那是在青海省的一次考古发掘中发现的。这一小团面条状用小米做的，虽然只剩下一小团，但它条状的特征非常明显。也有一些学者并不认可这一说法，他们认为小米和糯米、大米都不一样，小米的粘度不够，没办法拉扯成面条的形状，所以我们判断那一小团面条可能是真面或者面糊凝聚成形的。

不管怎么样，一般向前追溯出现。到宋朝的时候，面条已经非常流行了。那个时候，日本派了很多人来中国学习，他们去西安等地方，有文人写到的，也有说玩儿的，都有人把面条这个东西介绍过去了，那个时候，日本的东西比较中日，就把面粉掺进米粉里，做成荞麦面。这个面一直流传到现在，也成了日本面食中的一个重要种类。

当然，日本也不是完全由面粉制作成的面食，这也是日本面皮。不过，日本拉面的拉并不是“拉面”这个词。这个说法有点绕口，我们平时说的拉面，比如下拉，这是拉，就是拉面，双手反复拉扯面，拉出细条面。但日本拉面的拉，并不是拉面，而是用刀切出来的。这个制作面条的流程要比拉面稍微要复杂一些。但大家说面很麻烦，想要吃面要煮面。要泡好，准备面条了，想要吃上一碗面，没有二十分钟你根本做不出来。

# 方便面是怎么做出来的？

原来，就有人会做一些有办法简化的做法。这里有一人，他没有方便面的人给做成了。他注意到，所有人都期望能够在最快的速度吃到一碗面了。于是，他在自家院子里支起了一口锅，架起大火，开始研究怎么生产一碗几分钟就能吃上的面。
