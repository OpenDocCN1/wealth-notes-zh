# 暑假期间，孩子在家怎样“有趣地”获取知识？

![](bbox=[0.08, 0.11, 0.92, 0.2])

三岁以前，负责情绪和感观的右脑比较发达，所以孩子用全身力气来表达自己的情绪。三岁以后，负责逻辑的左脑开始发育，孩子最明显的特征就是不停地问为什么。

暑假来了，你带孩子到景区、天文馆、博物馆，抓住一切机会给孩子拓展眼界。满足孩子的好奇心。其实，不需要太远，在生活随手可及的地方，孩子就有着一大半的问题，等着你为你提供最新科学地解答。

# 《给孩子的博物学》

![](bbox=[0.36, 0.37, 0.64, 0.43])

吃饭了，你让孩子多吃些胡萝卜，孩子好奇地问：

《给孩子的博物学》这样给孩子解释：

胡萝卜本来是紫色或者黄色的。400多年前，在一场荷兰和西班牙的战争中，奥兰治亲王领导荷兰人打赢了这场战役。奥兰治，用荷兰语拼写出来是orange（橘子、橙色）特别接近。很多人都把奥兰治亲王称作橘子亲王。所以橙色就成了当时贵族的象征。后来荷兰的园艺家偶然发现一株偏橙色的胡萝卜，觉得这是好兆头，于是重点培育这种颜色的胡萝卜，讨好橘子亲王。所以就有了现在在我们眼中的橙色胡萝卜。

在小区遛弯，看到了跑跑的大灰犬，孩子有点害怕地问：

![](bbox=[0.22, 0.66, 0.78, 0.72])

《给孩子的博物学》这样给孩子解释：

一万年前，人类的狩猎技巧发展起来了，打的猎物多了，多余的食物，要么被偷看盯上。有些食物保存在人类附近，看着物，时间久了，特别看管上人类一块儿打猎。人类也会诱导和帮助一些它们吃。再后来，人类还会收留被母狼遗弃的小狼，被人类捡回去的小狼，有些脾气坏，有些爆脾气，脾气好的，会成为人类的助手，帮人类护娃，帮人类照顾孩子，那些留的，脾气好的，愿意服从主人，那就要留着，帮忙打打猎，或者帮忙看家。可以用是，在一万年前才出现的，现在我们看到的各色各样的宠物狗，出现的更晚，大部分都不超过400年。

去动物园看到大猩猩和小猴子，孩子不解地问：

![](bbox=[0.22, 0.91, 0.78, 0.97])

《给孩子的博物学》这样给孩子解释：

两个原因。第一，散热。人类的祖先生活在森林里的，大概300万年前，地球气候变得干旱少雨，人类祖先被迫从森林转向草原生活。为了耐热和散热，人类毛发开始退去。第二，减少寄生虫。寄生虫会藏在毛发里，传播疾病，毛发退去可以减少寄生虫的生存空间，降低生病的风险。所以，为了适应环境的变化，人类慢慢进化成了现在这个样子。

《给孩子的博物学》全年包含260个研究课程，内容涵盖了物理系，天文学、生态学、营养学、遗传学等26个学科，为孩子传递生活常识、科学知识，拓展孩子的知识面。
