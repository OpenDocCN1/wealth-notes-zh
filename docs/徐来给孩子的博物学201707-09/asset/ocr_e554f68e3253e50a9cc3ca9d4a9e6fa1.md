# 其他天体·宇宙｜神秘
外星人的“哇！”信号

世界之大，奇妙的事情每天都发生
我们一起发现吧！

你一定能听到更多关于外星人的说法，
也一定在很多文艺作品里看过地外生
态人的身影。不管大家有没有幻想
过，在想象之外星人一定是友善的。

你听说了有关宇宙飞船的事情
没有，也许你觉得那只是小孩子
的幻觉，可你仔细听，那是真的！

# 什么“哇”信号？

这个“哇”信号，是1977
年8月15日，由美国俄亥俄州立
大学的大耳朵射电望远镜探测
到的。它的频率很特别，是1420
兆赫，正好在宇宙里氢原子能
吸收和发出的频率上。

![](bbox=[0.2, 0.45, 0.8, 0.52])

信号持续了72秒，强度比
周围背景强很多。天文学家们
立即对这种“哇！”信号进行
了分析。

后来，杰瑞·庞斯（Jerry
Pon）研究了这份数据，并且
指出这些信号很可能来自宇宙
深处的某个恒星系统。

![](bbox=[0.15, 0.63, 0.85, 0.72])

# “哇！”信号到底说了啥？

其实，科学家对这份数据的
解读非常有限。它被推测可能
是某种数学编码，或者是自然
天体的物理现象，至今并没有
确切的答案。

虽然这份信号没有明确指
向地球，但它的确让科学家认
识到，宇宙中可能存在其他文
明或自然智慧现象。

![](bbox=[0.2, 0.89, 0.8, 0.94])

# 无法解读的信号

信号在持续72秒之后就不
再出现。虽然科学家多次尝试
重新检测，但都没有结果，成
了无法破解的神秘信号。

至今，“哇！”信号究竟
是外星人的信息，还是宇宙天
然的电磁现象，仍是个谜。
