# 博物学家养成记

其实，现在你也可以通过制作印章的方式，来尝试一下活字印刷和雕版印刷的不同。在网上可以买到橡皮图章的全套制作工具，要不要自己动手试一下呢？

+   1. 最早的图书都是靠人工抄写来完成的。比如著名的死海古卷就是抄写图书。抄写的弊端是成本很高，容易出错。
2. 印刷技术的开端是印章。雕版印刷是一项非常重要的发明，它出现在隋唐时代，距离现在已经有超过 1000 年的历史了。
3. 中国的活字印刷最早出现在宋代，但是由于中国汉字的特殊情况，当时的活字印刷很难在中国普及。
4. 古腾堡是西方的活字印刷发明者，他不止是发明了一种印刷方法，还建立了一整套印刷系统，包括油墨、印刷机等等。
