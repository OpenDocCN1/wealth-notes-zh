# 什么是香菜的气味？

香菜是一种典型的有强烈气味的蔬菜。美类的蔬菜有很多，比如香辛料类的比如说是大蒜，还有胡椒、花椒、紫苏、罗勒之类，前段时间在新西兰，我注意到当地的毛利人使用一种奇怪的树叶来调味，气味也很浓烈，吃起来辛辣，号称毛利的胡椒。

香菜的味道闻起来很简单，但实际上它的成分非常复杂。科学家们从这种气味里面，找到了几十种不同的化学成分，这些化学成分还很活泼，没事就往空气里面跑，越跑越远。就是这些化学成分，组成了香菜奇怪的味道。

![](bbox=[0.25, 0.52, 0.75, 0.59])

既然香菜的味道，不是一种单一的成分导致的，那么利用其它类似的成分，有没有可能模拟出跟它闻起来非常接近的味道呢？那当然是可以的。不但可以是，而且不难。实际上自然界已经有动物做到了，那就是臭蟾。这是一种俗称臭大姐（下图）的昆虫，夏天经常见的，灰皮带一点斑纹，如果你轻轻碰它，它就会喷出一些带有强烈气味的液体来。那个味道，闻起来就有点像点是香菜的味道。

# 我们是怎么闻到气味的？

话说回来，为什么同样一种蔬菜，有些人那么狂热地喜欢它，有些人却躲得远远的？

这件事情困扰了科学家很久。

实际上，这本身是个很有意思的课题，气味到底对人类做了什么，人类对气味的喜欢或者厌恶，到底是怎么区分的呢？

先说一说，我们的鼻子是怎么知道气味的吧。

我们刚才已经提到了，气味的实质是一些化学物质。这些化学物质非常活跃，总是不好好地球呆着，稍尖了脑袋往空气里面跑。它们的化学名，科学家会给它们起一个专门的名字，叫挥发性物质，意思就是说这些物质很活泼，跑得快。

进到空气之后，它们就随着气流到处飘来飘去。如果正好跑到我们的呼吸，那些挥发性物质自然也就跟着气流进入了我们的鼻子。

进到鼻子之后，大部分挥发性气体和空气一起，进了我们的肺里面，来维持我们的生存。而有少量挥发性气体的分子，会撞击到我们鼻孔内侧的皮肤。这些皮肤，又薄又软，上面分布了很多血管，还有就是一种嗅觉感受器。挥发性气体分子碰撞了这些感受器，就会让它们产生一些电信号。然后，嗅觉神经负责把这些电信号传回到大脑的嗅区里面，大脑皮层会收集这些嗅觉信号，我们就能闻到味道啦。

![](bbox=[0.25, 1.0, 0.75, 0.0010500000000000002])

# 什么决定了我们对气味的好恶？

大脑采集到嗅觉信号的时候，是没有喜欢或者讨厌的区分的。但是大脑把这些信号输送至皮层的嗅区，喜欢或者厌恶的感觉就出现了。科学家们通过一个有意思的比较，他们发现，东方人，比如中国、日本和韩国人，是相对而比较喜欢香菜菜的。大概每100个人里面，会有超过20个人不吃香菜，而在西方人当中爱吃香菜的人，每100个人里只有五六个，不喜欢香菜的味道。这说明，东亚和中东地区的人食物都特别喜欢浓香。

科学家进一步研究发现，到底是喜欢吃香菜，还是不喜欢吃香菜，都是我们每个人基因决定的。之前我们已经见过一些基因的事例了。这是人类和动物身体上都拥有的一种遗传物质。我们从爸爸妈妈那里得到一半，再从妈妈那里得到另一半，然后两半拼在一起，就变成了我们身体里的遗传物质。这些遗传物质构成了染色体。我们每个人有23对染色体，也就是46条，我们身上的每个细胞里，都有这46条染色体，就放在细胞的核核心位置上。

所有染色体中的第11号染色体决定了我们在香菜方面的好恶。科学家发现，当一个人不在编写为rs7292101的位置上，出现了一种名叫膜嗅铃的物质。嘧啶是一种化合物名字，如果不了解它这个东西，那么它个人就可能会讨厌香菜；一旦对不上就不管了，反正也不含讨厌了。

实际上，这个第11号染色体，是一个非常厉害的位置——我们已经知道了，很多疾病，之所以会发生，就是因为我们染色体上的某些因素有关。现在，科学家们发现，这条染色体是包含人类很多高发的遗传病，包括很多遗传病的致病基因，比如自闭症、抑郁症、自化病和一些癌症等等。同时，这条染色体也是管理嗅觉感的一条主要染色体。

那么问题来了，人类对不同意味的喜好，会不会跟人类遗传病的存在某种联系呢？这个问题还没有最终的答案，科学家们还在继续努力研究中。
