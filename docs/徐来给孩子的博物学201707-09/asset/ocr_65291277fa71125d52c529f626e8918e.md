# 生态学·进化|复活节岛上的巨像为什么哭泣？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

在地球的所有陆地上，除了极端寒冷的极地之外，哪里最能到达？这个问题的答案，可能并不是沙溪口，不是高山，而是一座孤岛。

这座岛并不大，上面有三座火山，不过早就喷发了。除了三座火山之外，其他地方是一马平原。听起来是不是很让人错的地方嘛。要是这么想，你就可以到达的地方，哪里不是这样的呢。

这个岛屿比往住上非常偏近，就在附近的差，可以住人，但距离它在2000公里之外，差不多相当于从北京到广州那么远。在缺乏高效运载和导航能力的古代，那个岛几乎都是不可能到达的。

# 如同荒岛的复活节岛

在著名的大航海时代之前，人类只路过这个岛屿一两次。在当地人的传说中，这次登陆是由一位伟大的酋长带领的。科学家们通过各种方法大致地推测，推断这次登陆发生在大约1600年前。

直到1722年，才第二次有人发现了这座岛屿，这次是一位荷兰航海家。因为他发现的时候正好是西方社会的复活节，所以他就给这座岛起了名字，叫复活节岛。他和他的船员们登上岛屿的时候，被这里的景象惊呆了：整个岛上都没有什么，只有一点。绝大部分植物是低矮的灌木和草。这里也没有什么动物，太平洋其他岛屿上非常常见的，在这里一只也看不到。这里人住的地方，当然养不活太多的人。他估计岛上大约有2000人左右。因为缺少大树，所以他们没有无法去太远的海洋，他们的独木舟是用小木板绑成，所以非常容易被风吹走，根本不可能远航。

这还不够特别的。很快，航海家就注意到了这个奇怪的事情，岛上有足足超过一千个巨大的人的头部。这些石像被称为摩艾，雕刻的是男性的头部。摩艾看起来身材矮小，高度由一部分只几米。最高的超过20米，但大多数人5米左右。按照当地人的说法，摩艾就是那些祖先，雕刻当地人是为了利用这些雕像来祭祀祖先。

只有区区两千人的荒岛，怎么可能树立超过1000座巨大的石像呢？无论是最早记录摩艾的人，还是后来登陆这里的一些学者都感觉不可思议。后来，有一些考古学家对复活节岛进行了考察，结果发现，雕刻摩艾石像的石材，把几样结合起来并不是最麻烦的顺序，它们这些石像是站立在一些巨大的石土台基之上的。建造这些石头台基所需的人力可以是摩艾这些石像本身的几十、上百倍。

这么多来，岛上的人要完成这个工作了？难道真的是外星人干的？

# 这里曾经到处都是森林

当然不会。在岛上奇怪的情况引起了当科学家研究的注意，是很多人都去搞研究，终于慢慢弄清楚了。从人类第一次登陆这个岛到后来，到第二次发现摩艾，直到第三次，到底发生了什么。这件事情也让大家在争论。

听一下，听一个很有创意的观点。这位是美国的著名古动物学家，他讲了讲这个观点，讲的非常生动。

他的研究方法就是花粉分析。复活节岛的火山口堆积了雨水和泥土。而海底部的沉积，一层又一层，层层叠叠。科学家从过去几百年来覆盖的东四。仔细研究了这些沉积，惊讶地发现，其中含有许多棕榈树、科学、种鱼的花粉。以及在岛上采集的物种标本中，识别了二十多种原来生活在这里，但现在已经灭绝的植物。它们几乎全都是大树。

考古学家还通过翻拍当地的垃圾堆，找到了很多家猪等古人丢弃的垃圾物。除了当地人饲养的鸡之外，他们还找到了好几种海龟、海豹、海鸟的骨头。通过这样的方法，复活节岛的历史一点被复原了出来。科学家们惊讶地发现，他们在研究的这，算得是上人类历史上最引人入胜的事情。

# 复活节岛上到底发生了什么？

在大航海者族人刚刚抵达这里的时候，发现这是个森林密布，动物种类繁多，环境相当好的岛屿。于是，人们定居下来，逐渐繁衍加了一个部落。人口最多的发展，新增加超过了两万人，他们在岛上发展农业，建造了非常复杂的社会，也就是在这个时代，他们强大到可以推动文明了，雕刻出巨大的石像。他们用石像作为文字一这些在太平洋各个岛屿上生活的民族当是非常罕见的。

但是，它确实并非不知，这个岛屿的繁荣，其实是非常脆弱的，因为这个岛屿的自然条件并没有他们想象的那么好：首先，这个岛周围的海水比较冷。比较冷的海水导致了许多问题，这里降水比较少，不利于森林的恢复，海里珊瑚也比较少，这样周围的鱼群也会比较少；其次，这个岛的火山已经沉寂很久，所以的土地都比较肥沃，土壤的淤积程度也一般。人们会很容易把森林全都变成农田；最后，这个岛离其他的岛实在是太远了，住在这里的人无法得到其他岛屿的资源作为补充。

这使得复活节岛的环境变得非常脆弱，更容易从人们的破坏中恢复回来。果然，在这个岛屿的文明达到最鼎盛时期的之后，它就开始快速走衰了。

为了养活更多的人，树木被砍掉，森林被开辟成农田。但没有了森林的保护，雨水更容易把土地肥沃的土壤给冲走，于是人们就靠更多的农田来产出粮食来养活更多的人，需要更多的耕地，要更小的树木越来越多，岛上的人能砍伐的船也就越来越小，他们出海打渔的次数也就减少了，最后可以吃到的海鲜、鸟蛋越来越少，只能靠更多捕食岛上的鸟类，慢慢地连鸟类都吃光。

食物减少之后，人口也减少了，当地人无法建设自己的部落，只能通过战争或其他暴力来统治其他人。随后，战争也在岛上蔓延开来。最终，等到西方人到达这里的时候，看到的只是一个荒芜的岛屿，只剩下巨大的石像，似乎在告诉我们这些悲惨的故事。
