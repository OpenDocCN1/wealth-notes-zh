# 声学.科学史 | 怎样才能让声音不消逝？

世界你好，奇杂的事情每天都有，我们一起出发发现吧！

我们每天都要和别人说话，也听别人说话，但是声音这个东西，看不见摸不着，没有办法把它保存下来。

当然，我们也可以通过其他方式来保存和传递声音。今天我要跟你说讲的就是记录声音这件事儿。

# 你用过磁带吗？

如果打开微信或者其他什么通讯软件，按住按钮，你就可以和任何人说话，松手传输，声音就发送出去了。在这个时代，想传递一段声音已经变得很容易，如果是10年前，就没那么容易。那个时候，大家可以通过电脑来录制一段声音，但是必须要把它储存成一个单独的文件，然后通过邮箱或者其它软件传送。

再往前，你在爸爸妈妈小的时候，那就更难了。那时候，电脑在中国还没有普及，记录和保存声音的工具是磁带。这个东西，现在想已经不容易看到了，它是一种涂了磁粉的塑料壳，卷成小卷儿，装在塑料盒里。塑料盒里有两个轴，可以把磁带小卷儿卷在上面，无需什么录音带，还是插放录音带，都来记录声音。用来记录磁带的轴，更像是记录介质，但是磁带上的磁粉会脱落导致声音无法播放，而且磁带本身也很容易折断变形。

再往前，可就更麻烦了。那是唱片时代。声音被记录在塑料材质的圆盘上，需要使用非常大的设备才能播放。而录制唱片则非常复杂的工具，更复杂，个人或者家庭几乎完全不可能拥有这样东西的。

马丁垂尔记录下声音信号

如果再往前，人类所使用的记录工具就只有纸和笔。记录者只能把自己看到的听到的内容记录成文字，有些人，则把这种场面绘制成图画。这样的方式，最多只能记录人们说话的内容，而无法直接展示声音本身。

因为过于依赖文字记录，有人甚至直接把声音变成文字。那是在1770年前后，当时，法国巴黎有一位出版商，叫马丁垂尔，作为出版商，他每天都要处理很多的读信件，记录就是一门用特殊符号系统记录声音的快写技术。马丁垂尔对速记的方法很感兴趣，自己还写了一本书，总结提高速记效率的经验。但是，速记本身，是听别人说话，然后把内容记录下来，这个还真是大费事了。

马丁垂尔就想，我们最好把声音描接下来，然后根据这个描绘，来直接生成文件。这个想法很厉害，实际上是当下我们非常热门的一种技术：声音识别。
