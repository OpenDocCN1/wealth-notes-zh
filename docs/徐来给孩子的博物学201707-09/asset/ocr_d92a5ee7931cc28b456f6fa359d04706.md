# 天上最多能有几个太阳？

其实不需要好几个太阳，只要咱们头上的这个太阳，释放出来的能量稍微大一点，咱们地球可真有麻烦啦。不但人们得晒伤的几率会大大增加，连正在我们的无线电通信也会受到影响。如果太阳释放的能量多了很多，恐怕要不不了多久，人们所能看到的各种生物，都会被杀死，消失得无影无踪。

当然，你现在知道太阳和地球的关系，你也知道，天上不会真的多出个太阳。但古代的人们不知道这些知识，遇到酷热天气或者倒霉灾的时候，古代人就编出了许多太阳当空照的故事。

在古代中国的神话当中，就有“羿射九日”的故事，“羿”的本意是“鸟迎风飞起来”的意思。在传说里，五帝当中有一位帝尧，尧帝的手下，有一位叫后羿的官员，是个名号神箭手。据说有一次，天上突然出现了10个太阳，把土地都晒焦了。尧就命令后羿过来，“你去上头射下来，你把天上的这10个太阳，射下9个来。”

羿也是不答话。弯弓搭箭，嗖嗖地射下了其中的九个。这下好多了，天热也热不了，旱情也缓解了。这就是所谓的“羿射九日”。

说到这个传说，很多人都会把羿跟另外一个人物混成一团。后羿的字也是叫“羿”的，他可不是后羿，而是王，他名字里的这个“后”，不可说后羿生活在前面那个羿之后。在古代，“后”这个字是一个称号，代表统治者，后羿就是一个名叫作叫后羿的部落首领，他也很擅长射箭，所以，人们经常把他和那个射日的神箭手搞混。其实，羿日的舜是传说中尧帝的人，而后羿则是夏朝时的地方部落首领——这两个人可差着不少岁月呢。

# 神奇的大气光学现象

当然，并不是说天上真的出现了五个太阳。其实，太阳只有一个，但是因为在一种特殊的原因，在我们头部的空气中会出现一些特殊的光学现象，把一个太阳的影子折射到了某个地方，形成了太阳的彩色影子。这种现象，被称作“幻日”。

我们生活的空间里，充满了空气。不过，空气里可不只是气体，也有不少液体和固体，这两年我们常说的PM2.5，就是液体或者液体——是的，PM2.5小到我们的眼睛根本看不见的。它们还是固体和液体。另外，空气里也有冰。空气中，有些以气体形式存在的，就是水蒸气，有些以液体的形式存在的，就是小液滴，有些是以固体的形式存在的，也就是小冰晶。没想到吧？

当然，这并不是我们每个人的周围全是这样的冰晶——真要有一点点，气温也不会这么热了。它们其实都在海拔很高、很高的地方，前两天回答大家问的问题，我曾经介绍过，海拔越高，气温越低，这和大气的有关。所以上，空气中的这些小冰晶都集中在离地面2万米到4万米的地方。如果它们聚集在一起，就可以组成一些亮又白色的云，看起来是一丝一缕，一团的，有点绒毛的感觉。

有的时候，它们不会聚成云，而是散落在空气当中，这些小冰晶就像是一个小小的镜子或棱镜，它们会把折射或者反射太阳的光线。如果这些小冰晶的形状和大小都合适的话，就会把太阳的光线投射到某些特定的方向上，幻日的奇特景象就会出现。

当幻日出现的时候，我们会在太阳的两侧，看到两个比太阳小些，但是很清晰的亮斑，看起来就像是并排出现了三个太阳一样。

# 折射产生的奇景

其实，由空气中小冰晶造成的神奇天象远不止幻日一种。

高空中的冰晶，有些是扁平的，有些是柱状的。如果一个区域里主要是扁平的冰晶在折射光，那么就会较容易见到幻日现象，如果主要是柱状水晶，那么，就可能会造成另外一种现象：日晕。晕这个字，跟晕车的晕同一个字，不过这里不是说太阳在犯晕，在这里，晕指的是太阳光周围的那圈彩光。

如果冰晶都是扁平的，角度又被稍微改变一点点，那么也有可能形成圆晕，但这个圆晕只能是太阳周围一圈，也就是我们头顶正上方的天顶一圈，这个现象被称作“环天顶弧”。

除了幻日、日晕和环天顶弧之外，因为这些小冰晶的折射，还可能会出现的现象，如：幻日环、接晕弧、环地平弧等等各种各样奇怪的大气光学现象。科学家把这些现象模拟空气中的冰晶折射条件，已经搞清楚这些现象的形成原因。

当然，真的想要看到它们还是挺费劲的，毕竟我们的自然界不像实验室，可以随意改变实验条件。要想真的看到他们，就只能碰运气啦。
