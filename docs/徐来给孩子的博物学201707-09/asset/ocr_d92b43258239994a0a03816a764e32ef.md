# 黑王子和宝石

黑王子之所以那么有名，不是因为他长得帅，也不是因为他权力大，而是因为会打仗。当时，英国和法国这两个国家正在打仗，你知道就知道了，黑王子和他的军队，从法国一直打到英国内部，然后英国又反攻到了法国。英国有很多有兵的统帅，最厉害的就是黑王子爱德华了，他可以在法国大地上横冲直撞，全欧洲人都知道黑王子的大名了。

黑王子这么厉害，难免会被其他的国王欣赏，所以，就有另一个国家的国王想和他结亲。这个国家就是西班牙国王，西班牙就在法国的隔壁，但这是我们现在知道的西班牙，不是一回儿儿，在那个时候，西班牙被分成了好几个小国，我说的，是其中有一个王国叫卡斯蒂利亚，国王叫做佩德罗。这个佩德罗，有点小野心，很想把周围的几个小国都打服，然后把他并到西班牙就成一个大帝国了。他出发出兵，有一次，把旁边一个小小的国家给消灭了，就那个国王手中抢到一块巨大的红宝石。

可是，好景不长，没过多久，佩德罗自己的卡斯蒂利亚就乱了，有人起兵造他的反，造反的人，就有另一个国家的国王想伺机夺位。这下，佩德罗就自身难保了，赶紧想办法，怎么样能打败那些造反的，保住自己的王位。他一愁就想到了正在讨英国的英国统帅黑王子爱德华了。他赶紧派使者，去找爱德华，给他信，他说道爱德华，只要你帮我多少钱，我送多少礼物，这其中就包含那颗很大很大的红宝石。

果然，黑王子一出手，马上起就了结果。在英国军队的帮助下，佩德罗取得了胜利。而黑王子则得到了那颗红宝石，黑王子红宝石因此得名。

# 黑王子红宝石救了亨利五世？

后来，这颗红宝石一直保存在英国国王的手中。每个英国国王都非常喜欢这块宝石。又过了几百年，当年的英国国王亨利五世甚至把它镶嵌在了自己的头盔上。

这个亨利五世也是一个非常了不起的人物。黑王子爱德华厉害不当常：亨利五世比他还厉害。这位国王不当常学习的时候，很是顽劣无德，总是和一帮地位低下的人混在一起。他心父亲亨利四世一直对此发愁，担心他没有王子的样子，造反没有能力等等。但谁都没想到，这位亨利五世玩玩玩玩，带兵打仗也是这点都不含糊，还没有上国军队，就带将军打平了北方叛军法兰西。当上国王后，更是直接带兵出征法国，取得了一系列的胜利。他甚至被认为英国历史上，军事能力最强的一位国王，著名的大文豪莎士比亚，还专门为他写了一部很有名话剧。

就在那场战役中，黑王子红宝石又发挥了巨大的作用。在战场上，亨利五世带兵指挥，带兵士兵混乱，有弓箭手正在上打，带着长矛冲上去，有个著名的故事说，这一带正好射中了亨利五世头盔上的蓝宝石红宝石，然而一颗一都没有松动，蓝宝石红宝石救了亨利五世一命，不管怎样就是假，亨利五世确实活了下来，还在敌军身边奋命，最后他几乎几百弓箭手却打败了4万人的军队，以损失400人的代价，消灭了近12000名法军。赢得了欧洲历史上最著名的一次以少胜多的战役。
