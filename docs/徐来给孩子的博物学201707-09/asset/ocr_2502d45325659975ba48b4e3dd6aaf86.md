# **问答 | 转基因和基因变异有什么区别？**

大家好，我是徐来。今天又到了我来给大家回答问题的时间了。最近，天气非常热，很多地方都出现了极端高温天气。你所在的地方，也出现了高温吗？所以，问问题的口气，要减少十分，注意防热和多喝水量。

这回我收的提问，很多也和高温有关。我们来看看今天的5个问题吧。

> 我替我家小朋友提一个问题：外面很热，那么市道避风场里的防空洞或者地下停车场怎么凉快呢？

![](bbox=[0.15, 0.175, 0.85, 0.24])

这个现象是由两个因素导致的：

**第一个因素是阳光。** 地下照不到阳光，所以温度低，这个好理解。因为阳光是热量的最大来源，而空气会直接被太阳照着，再加上空气是可流动的，一个地方热了，很快就传遍周围加热了。所以，同样两个东西，在太阳底下的那个肯定比阴凉地的那个温度高。

**第二个因素是变热的能力。** 岩土比土是不好的流动，所以土壤不容易直接变热；其次，土壤的传热能力很差。虽然白天地表被晒得很热，但温度还没传递到土里深层就到晚上了，根本来不及把地下室变热。尤其是土壤到一定程度后，变热的，所以，就算是夏季有树荫的地方，肯定也没有地下室凉快。

为什么吐鲁番在北方，可地表温度达到了88度，比许多南方的城市还要热？

![](bbox=[0.15, 0.45, 0.85, 0.52])

首先，我们说吐鲁番最热，说的是夏季最高温度，而不是平均温度。大部分中国南方城市是季风气候，季风气候的特点是，受到海洋和陆地变压的差异，水分会带着风向移动，这会造成太夏天，就会变热，但几乎万里无云、很少下雨，不下雨就意味着太阳不会被云遮住，也就没有雨水冷却降温。

当然还有一些别的原因，比如吐鲁番是盆地，热空气不容易散出去；还有吐鲁番海拔很低，一般来说，地表温度会高。

最后补充一点，**其实科学家很少用“地表温度”这个词**，因为影响地表温度的因素太多了，不同颜色的地表温度都不一样。气象学上一般说的气温，是在前沿地测量的。吐鲁番记录到的最高气温是49.6度。

为什么海边贝壳上大多数都有一个圆洞？

![](bbox=[0.15, 0.715, 0.85, 0.785])

你的观察非常敏锐！冲到路边的很多贝壳上都有一个小洞，而且常见的地方是在贝壳的“尖角”处。你看到的这个小洞，正是这些贝类们的死因。

活贝壳里面有很多，很多人喜欢吃，很多动物也喜欢。但贝壳之所以没有贝壳，就是因为不能吃掉活虾，只能长出硬壳保护自心。人吃贝壳的话可以煮熟或者用工具撬开，动物怎么办？

有一些动物想了一个办法：在贝壳上钻个小孔，可以一边钻，一边注入一种特殊的酶，这样会分解掉贝壳的成分，让钻开甚至容易。

实际中，还会在沙滩上遇到杀死这些贝类的凶手。比如山东一带海域有一种常见的蟹叫**做扁玉螺**，它看起来扁的，很奇怪，外表是棕色的，海蚌也常常有黄。它就会用钻孔这一招。有时候扁平螺之间还会互相偷呢。
