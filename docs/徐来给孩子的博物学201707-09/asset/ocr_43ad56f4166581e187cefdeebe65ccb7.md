# —● 博物学家养成记 ●—

关于日食和月食，你还听到过哪些好玩的故事呢？在留言区分享给我吧。我会选出精彩的留言，在周末的问答里展示给大家。

+   1. 日食的发生是因为月球挡在了地球和太阳之间。虽然这样的情况每个月都会发生一次，但是因为月球轨道面和地球的轨道面有一个夹角，所以日食其实比较罕见；
2. 平均而言，每18个月就会发生一次日食。不过，因为月亮相对于较小，而且公转速度很快，所以每次日食最多只能持续7分多钟，而且只有很小的一片地区能够看到日全食；
3. 人类目前已经知道的最早的准确日食记录发生在公元前763年6月15日。
4. 因为太阳的光线太强，所以我们不能直视太阳，观察日食要通过巴德膜。

日食：一种天文现象，只在月球运行至太阳与地球之间时发生。日食分为三种，包括日全食、日环食、日偏食。其中较罕见的是日全食。

上小学的时候赶上海尔波普彗星是经过地球，那时候用肉眼就可以看到。加上过两年又很快赶上日全食，在那个时候感觉自己真的很渺小，对未来有着无尽的想象和求知欲望。现在经济条件更好了，可以给小孩子们买天文望远镜等设备，去观测这些自然现象，真正用身体去感受自然界的伟大。

2009年7月22日，我在成都“观察”到了日全食，好像是中午12点发生的日全食，天全黑了，路灯也亮了。

所以世界各国人民都有关于日食和月食的传说。最普遍的是神奇动物把太阳或者月亮吃掉了，古印度和加勒比海沿岸的土著人认为是巨蛇，中国人认为是天狗，越南人认为是青蛙，阿根廷人认为是美洲虎，西伯利亚人则辩称是吸血蝙蝠。

我上小学的时候，观测日食是每人发一个小玻璃片，在上面涂上墨水，等干了就可以看太阳了。这么多年也只看过偏食和全食，感觉环食更罕见呢？
