# 巴西是如何成为橡胶王国的？

橡胶是用橡胶树的树汁做的。不过，橡胶并不只有用这个橡胶树当中，很多植物都会产生含有这个成分的汁液，但是橡胶树寿命长、橡胶的产量高，所以它是唯一一种可以大规模生产橡胶的植物。

280多年前，一位法国的探险家在南北美洲的亚马逊地区旅行的时候，发现了橡胶树的独特属性，比如，很有弹性，可以随意加工成形状、轻便、防水。他把橡胶带回法国后，这种神奇的东西很快就引起了科学家的注意。橡胶身上的这些属性让它看起来能够完成很多的任务，不过，它最早在欧洲大多数时候，跟衣服涂了橡胶差不多，涂在衣服和鞋子上做成雨衣、雨鞋。

不过，天然橡胶有一个很大的问题，就是对温度变化很敏感，天冷的时候变得硬梆梆的，甚至有会脆的，而温度高的时候，又很快就变得软趴趴的，这种属性让它看起来不太好用。美思人一个叫做高廷异的发明家，因为很重要的机会解决了这个问题。这一点如此之重要，以至于把它叫解决，工业界对天然橡胶的需求很快就达到了此前的100倍。

![](bbox=[0.1, 0.73, 0.75, 0.82])

又过了几年，另一位发明家发明了充气轮胎，这就是我们现在常常使用的轮胎啦。这发明家的名字后来也成了一个轮胎品牌：邓禄普。

没过多久，橡胶就已经成了一种非常重要的工业原料。各种各样的人带着自己的梦想来到南美洲，寻找橡胶。巴西因此也成了世界上最大的橡胶出口地。寻找橡胶真是个麻烦事。因为橡胶树其实并不常见。亚马逊丛林里，橡胶树的分布非常稀疏，找到一棵橡胶树本身就是特别不容易的事情。一开始，人们获取橡胶的方式非常简单，一旦找到橡胶树，就立即把它砍倒，然后把树劈开，把流出来的树胶全都收集起来带走。

这个方法确实太粗暴了，很快，他们就开始找别的方法了。人们越来越意识到，在割破整个橡胶树的时候，再直接砍倒整棵树，而是在树皮上划出伤口，让胶液沿着伤口留下来，采出胶。这种做法不会立即杀死橡胶树，所以可以反复获取橡胶。不过，在野外情况下，这个做法一样会极大地缩短橡胶树的寿命，因为割上几次就没人想继续割了，还是会直接砍倒。

这个做法，既无法保证橡胶的产量，更会导致橡胶越来越少。于是，有真人开始研究人工种植橡胶的方法。开辟橡胶种植园，这种做法的出现一下子就解决了这个问题，同时，也提高了生产效率。橡胶树被集中种植在一起，方便了来采集胶奶，也方便保护这些树木，保证它们的健康状况，让它们尽可能活得久一些。

# 巴西是如何丢掉“橡胶王国”的？

有了橡胶种植园，巴西就成了名副其实的橡胶王国。

当然，也有人，在打橡胶种植园的主意。俗话说得好，不能把鸡蛋放在一个篮子里，意思是说，不能把所有业务放在一个地方。要分散投资，才能控制风险。橡胶这么重要的物质，全都由巴西一个国家来生产，提供给世界各国使用，恐怕也不是很安全的事情，很容易形成垄断。于是，有些人算计着把橡胶带出国，尝试在其他国家也建设橡胶种植园。

最后，一个英国人成功了。他把7万棵橡胶树种子偷偷地运出了巴西，带到了英国。为了能把官方送走种子，他甚至贿赂了巴西的官员。这个做法，后来引起了很大的争议，一些人指责他是小偷，但另一些人则说保护，当时巴西并没有任何法律规定，说，不能让橡胶树带出国。可不管怎么样，南美洲橡胶树是巴西对橡胶生产的垄断，就这样被打破了。

不过，要找到这7万颗种子的地方可不太容易。因为橡胶树其实是一种非常娇贵的树。

首先，它喜欢高温和高湿度，种植地区的降水量必须要很大，而且要常年均匀些，不能一会儿下一会儿干。其次，这个地方光照必须非常充足；最后，考虑到这树的树脂很大，抗风能力不强，所以种植这些橡胶树要到亚洲的马来西亚和斯里兰卡去，虽然最后只有几百棵苗留了下来，但正是这几百棵树，后来发出了马来西亚巨大的橡胶种植园。

不仅如此，亚洲的种植者们还发明了更好的割取树胶的方法，这个方法极大地提高了橡胶树的寿命。亚洲的橡胶开始占据优势。
