# 行为学丨动物丨恐惧会在你的记忆里留多久？

世界你好，奇妙的事情每天都有，我们一起去发现吧！

如果你经历过一件让自己感到害怕的事情，你可能会被吓得夜慌才好；如果这件事情让你非常害怕，你也有可能因此患创伤症；如果可不可怕，你可能会被困扰很久；但果再严重一些，那对你来说，这可能会是一辈子都无法摆脱的噩梦。

但是，你有没有过另外一种情况？你从来没经历过那件事，但你常常说回忆，你会去害怕它；比如，你从来没见过吹气，但是你看得到它，还是害怕，甚至不自觉地想起。这是为什么呢？

今天我想跟你说一说，恐惧会在我们的记忆里停留多久，以及我们为什么会天然害怕某些东西。

不过，我先不说你，不说动物人类。我要先从小浣熊说起。浣熊很聪明，有很强的好奇心，而且，它们的指甲非常灵活。浣熊洗澡是一种非常有趣味的动物，它把抓到的东西放到水里洗一洗的习惯。浣熊的“洗”不是洗的意思。浣熊的名字就是这么来的。

这个话题外，我记得唐诗里有“竹院清凉，荡漾下净池”的诗句，意思是洗水浣的姑娘们在净池边的岸上游玩，远远望回去，白帆点点，水上的落叶随着摇。这里的“浣”，跟浣熊的“浣”一样，也是洗的意思。

# 浣熊破坏了生态平衡

今天要说的这一群浣熊，不是在美國的，而是生活在加拿大，也不是生活在大陆上，而是生活在海岛中。这是在北美的西海岸，在美国和加拿大两个岛之间，有一个属于加拿大的群岛，叫加拿大群岛。这个海岛群岛，每个岛同岛同之间的距离不远，所以，大海阻挡了各个岛上的动物相互干扰，起到了一定的隔离作用。在其中的一个岛上，生活着很多海鸟。这些海鸟岛上的这些岛上，大海在中间相隔，岛同鸟群是无忧无虑的。为什么？因为，浣熊本身是捕食者，它们食物当中有一小部分是捕捉到的。但是它们身形比较小，大鸟在岛上，它们自己会成为比较大的动物，比如浣熊，海豹、企鹅、美洲狮等，甚至是猎物，本质，这些岛上原本狼、熊这些小型猎食者。不过，在百多，一些人类的大规模繁衍行为，已经把许多岛上的大型食肉动物都给杀死了。山中无老虎，这些浣熊自然就成了大王来啦。

![](bbox=[0.1, 0.71, 0.9, 0.82])

这些浣熊大王甚至改变了自己的生活习惯。比如说，原先浣熊都是夜伏才出来找东西吃的，现在，没有了天敌的威胁，它们大白天了，也敢大摇大摆地到外去了；再比如，它们原先是不会到潮间带找吃的东西的。

啥是潮间带？潮间带这个东西，你一定很熟悉。我们平时说的海滩，就是潮间带的一种。你看，大海在不同的时间，海水的位置是不一样的，就是所谓的潮涨潮落。在一个海洋中，涨潮的时候，海水就到了最高的位置，落潮的海水，就下到了最低的位置。我们说，在这两个位置之间，就是潮间带。

现在，海岛浣熊的浣熊也冲到了它们原本很少去的沙滩上找食物吃；还有一点，浣熊警惕性很强的动物，平时吃东西的时候，每隔几秒就会抬起头来，看四周的情况，很容易被追，但是现场情况又变了，它们潮间带寻找东西吃的任务中，几分钟都不抬头一下，感觉特别安逸，特别放心。

![](bbox=[0.1, 0.95, 0.9, 1.0])

浣熊是安逸了，可是生活在潮间带的生物们就不行了。浣熊没事就都窜到这里吃各种贝类，它们吃得太多太猛了，生物学家很担心，再这么吃下去，这个海岛的潮间带生物会收到非常大的影响。弄不好，会把一些贝类、小鱼、小螃蟹直接给吃没了。

这个时候能让浣熊稍微收敛一下的，大概只有狗了。可是问题是，如果直接放狗到海滩上去捕浣熊，好像也不太合适。大家知道也是动物，你总不会让别的放狗抓它们，明显是在虐待它们。那么有什么折中一点儿，的办法吗？

# 狗叫能吓跑到浣熊吗？

科学家们想的到一个很有意思的折中的办法，叫我们，我们在岛上做两个实验，第一，需要在一点人天敌会吓跑一下浣熊；第二，又不能用真的放出去天敌去追捕它们。好，答案已经出来了，既然不能真的放狗去抓浣熊，那就放录音。所以，科学家们搞了一个“伪天敌”计划。也就是，像真的放狗出现了，他们开始向浣熊们播放狗叫的声音。这个声音听起来比较长，有10秒钟，就这样，让浣熊听10秒钟的狗狂叫声。

科学家非常惊讶地发现，这个假的“天敌”，居然真的有用。浣熊明显注意到狗的存在——准确地说，是接受了错误的提示，以为它的天敌——狗就在自己的身边。在接下来的一个小时时间里，它们跑到荒凉的某个地方。然后，科学家进行了总计。在这一个月时间里，岛上浣熊的进食时间，竟然下降了三分之二多！

# 被写在基因里的恐惧

因为天敌叫声的存在，浣熊竟然吓得连找东西吃的都不敢了。要知道，在这个过程中，并没有任何一只浣熊真的看到狗的长声。它们只是听到了科学家播放的狗叫声而已。

接下来，科学家又去检查了潮间带上浣熊的食物的情况。结果，他们惊讶地发现，只用了一个月的时间，这里的生物得到了极大的恢复。有些原本已经被浣熊吃得几乎要绝迹的螃蟹，只用了1个月，就又出现了大量。

但是，我不知道你注意到没有。这里的浣熊已经有上百年没有听过狗叫了。别说是这些浣熊，就是它们的多爷，乃至它们爷爷的爷爷，都没有听过狗叫。那它们是怎么知道狗叫意味着着危险呢？

这实际上跟演化环境有关。每一种动物都是经历了漫长的演化，才变成现在模样的。在漫长的演化过程中，所有危险的样子乃至危险的信号，都在我们身上留下了记号。比如说，危险很快就留下来我们的，让我们记住它的形状或者声音，慢慢地记住危险信号就会留在我们的记忆力中。所以，我们的祖先呢，就有一些容易危险，他们因为害怕某样而放弃一些机会或者死活，但他们对危险处没有恐惧，那么我们伤害到它们的几率就会大大降低，那么他们生存下来的几率就会变大。时间长了，我们自然容易出现这样的本能了。

动物也是一样，比如，对大熊猫来说，狐狸是危险的因素，所以狐狸一旦见到食物都会非常紧张，像狐狸一样的黑色条纹。这也是大熊猫从祖先那里遗传下来的危险信号。
