# 行星·宇宙｜海王星是怎么算出来的？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

你喜欢看星星吗？在天气晴朗的日子里，抬头看天空，哪些亮星星在里，也能看到星星。这些星星都是恒星。恒星的“恒”是长久的意思。它们总是挂在天空中，一直亮着，一动不动。这些恒星离我们都很远，而且它们本身会发出光。

不过，最亮最显眼的，往往往星空里。行星是行星，恒星是恒星，恒星是长久的意思。它们总是挂在天空中，一直亮着，一动不动。

有些行星很容易看到，比如水星、金星、火星、木星、土星。其他行星因为离太阳太远，发出的光线非常微弱，所以人类无法用肉眼看到。今天我们就要说说肉眼看不到的行星的故事。

# 望远镜让人们看到更多星星

在没有望远镜的时代，人类只知道，地球之外只有水月亮存在。但是，后来人们发明了望远镜，把能看到的范围扩大了很多。一时间，各种天文台如雨后春笋，开始看看着看看看。

那个时候，没有现成望远镜，没有哪个天文学家想自己造。他们买，买哪个望远镜就哪个望远镜好，哪个望远镜好，他们就用哪个望远镜。

赫歇尔是个音乐家，后来到了英国，他在自己家里学天文，写音乐，写过曲子，也组过乐队。但是在英国认识了一个业余小提琴手，这个小提琴手本来是音乐家，后来在赫歇尔的影响下，他也开始对天文研究和望远镜感兴趣了。

没多久，一玩几处玩几处成了，他真造出来了很多望远镜，而且造得还不错，其中一架还被送到了中国。现在如果你去故宫还能看到这架望远镜。

# 赫歇尔找到了天王星

你可以因为赫歇尔只会造望远镜而不用望远镜，他用望远镜也很厉害。他自己造过望远镜看到过很多新星星，其中有一颗会移动盘子。于是，赫歇尔给天文学会写信报告，说自己观到了一个新星星。

不过，其他天文学家有些认为有问题，因为天王星有尾巴，可是观测到的这颗没有尾巴。又过了好久，其他天文学家通过更长时间的观测，估算出它和地球之间的大致距离，并且发现它围绕太阳转动的轨道是圆形的。看来这颗星，还真的是星星很不错，其他的星星轨道可都是扁的。

到这个时候，这才确定，赫歇尔观察到的是颗新行星。当时，赫歇尔很想命英国王乔治三世的儿子来给这颗行星命名。

![](bbox=[0.35, 0.92, 0.65, 0.97])

可是其他天文学家不乐意，因为按惯例，天上的行星都是用神话里的名字命名的。为了打破惯例，最后还是决定用希腊诸神里的“天空之神”，也就是宙斯爷爷的名字来称呼它，这就是天王星。

![](bbox=[0.25, 0.00103, 0.75, 0.0011])

![](bbox=[0.1, 0.00111, 0.9, 0.0012])

其实，天王星虽然离太阳很远，看起来非常暗淡，但是在某些特殊情况下，还是有可能肉眼看到。比如，在发疯这颗行星之后，天文学家们又去检查过前人的观测情况，发现一些特别亮过它前100年，天王星就被一位英国天文学家记录过了。

不过，他错以为这是一颗恒星，把它记录成了金牛座里的第34颗恒星。

你可别觉得天文学家发现了新一颗行星，给它命名字，就万事了，接下来准确地算出这颗行星的运行轨道。有一位法国天文学家，先行动起来，算出了这颗行星，并且出版了天王星的运行轨道。但是很快，大家就发现，这个表一个点都不准！不但不准，而且误差越来越大。于是，天文学家们回头去做解释，发现他没有错误。这么一来，就只有一个解释，那就是在天王星附近，很有可能还有一个更大的天体。

这个时候，数学就派上用场了。当时，科学家们已经发现星星运行的规则，以及它们之间的位置影响所遵循的数学规律了。所以，从理论上去，天文学家们可以从天王星的异常运行中，反推出那个影响它运行轨迹的星球到底有多大，以及它是一条什么样的轨道。

但是，说起来容易，做起来却是很难。那个时候大家还没有计算器，只能靠看纸和笔、手算。

# 到底是谁在干扰天王星？

最初算出这个答案的是一位英国天文学家亚当斯，他通过反复计算，画出了一颗未知行星的轨道，并且推测它是天王星轨道了影响。随后，亚当斯计算的结果发送给当时的英国著名的天文学家。不过，那个时候亚当斯是无名小卒，所以，这个结果没有受到重视，也没有公开发表出来。

与此同时，法国有一位天文学家叫勒维耶，他在计算那颗未知行星的轨道，并且算出了结果。当然，光靠计算是没有用的，还得通过实际的观测。真的看到这颗行星，才算好。自己，勒维耶就按照自己的计算结果，来搜索这颗行星。但当时的年纪的助理勒维耶也影响力很小，找到合作者。这时，小赫歇尔开始替自己寻找行星，小赫歇尔，发现天王星的赫歇尔的儿子。

这么一来，各个小团队就开始比赛了。最后赢得胜利的是勒维耶，他说德国柏林天文台的天文学家，按照自己计算的结果，在特定的范围内搜索这颗行星。终于在1846年9月23日晚上找到了新的行星，并发现了观测结果。现在我们知道，这颗行星，就是海王星。

后来，小赫歇尔团队才发现，他们其实早一个月就观测了这颗行星，只是因为太没当回事，错过了一个重大发现。
