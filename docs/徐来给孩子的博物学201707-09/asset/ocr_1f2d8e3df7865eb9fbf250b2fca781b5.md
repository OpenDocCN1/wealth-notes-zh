# 医学 · 动物 | “法庭审判”与“恐怖瘟疫”有什么关系？

世界之大，奇妙的事情每天都有，我们一起去发现吧！

你平时有没有犯过什么错误？犯错了之后，爸爸妈妈是不是会生气？其实，每个人在成长的过程中，总会多多少少犯点错误的。你爸爸妈妈小时候，肯定也犯过。不过，这也多说不是错你犯点儿错也没关系。虽然很多错误，虽然很小，但是也需要总结教训，免得再犯。

中国古代有个很聪明的人，叫刘备。他在临终前对儿子刘禅说过这样一句话：

> “勿以善小而不为，勿以恶小而为之”。意思是，你不要因为一件好事情很小，没什么好处，就不去做；也不要因为一件坏事情很小，觉得没什么影响，就去做。

道理很简单，虽然坏事很小，但是积累起来也是不得了的；做小的坏事，慢慢的就变成做中等等的坏事了，再慢慢的就会去做大坏事了。那做积累了，要是触犯了法律，还会被抓起来，被法院审判。

说到这个审判，在英国曾经发生过一件非常惊人的事情。这件事情直是让人感到难以置信，完全是意料之外的。而且，它给人们带来了巨大的谜团，困惑了人们好久。今天我们就说说这场可怕的审判吧。

# 可怕的审判现场

这个事情发生在整整440年前，那就是1577年的英国。我今天就要来跟你们说说这位让人匪夷所思的审判。

1577年，在英国，是著名的伊丽莎白一世女王的时代，这个事情发生的地点，在牛津，对了，就是那个有全英国最古老，也是最好的大学，牛津大学的那个牛津。

![](bbox=[0.15, 0.51, 0.85, 0.62])

那是7月初的一天，虽然天气很热，但是很多人都聚集在牛津城的法庭里，把这个地方闹得里三层外三层的。大家都知道这里干嘛啊，原来，这一天要在这里审判一个人，这个人的名字叫托马斯·詹姆斯，这个人是个书商。他犯了什么错误，这个有点儿不太可靠了，毕竟这是400多年前的事儿了。但是，这个人呢，一定是引起了极大的民愤，所以，现场坐满了上百人，看着这场审判，看到他受到伤害的人太多了，空气不流通，整个法庭里又是坏味儿，又是烟味儿，又是臭脚臭味儿，臭烘烘的。

不过，大家挤在这里也是没白挤，最后的判决结果是，这书商算是罪名成立，而且，给他的惩罚是把耳朵给割掉。这个惩罚，大家很满意。哈哈～奥，就把法庭上那么，这么个判决，那么臭烘烘的情况给忘了，反正判也判了，耳朵也割了，大家也就散了。

怎么说着说着大家都散了，这事儿难道就这么结束了吗？怎么可能这么简单。实际上，这才是事件的开始。

就在大家看完热闹，纷纷回到自己家中之后，有一个可怕的恶魔就钻了出来，开始在这些人当中横冲直撞。

# 黑色法庭带来的瘟疫

那些看热闹的人回家后，没过多久，就有人发烧了。很快，更多的人发烧了，他们把这个发烧的状态传染给了家里那些没有去参加法庭审判的人。有人出现的症状有很多，除了发烧之外，还会出现头痛、恶心，以及浑身痛，身上还会出现很多红点儿。又过了一阵子，有些病人就去世了。

导致这种状况的恶魔就是瘟疫。如果你还没有听说过这个词，那我就来告诉你什么叫瘟疫。瘟疫是指，由一些容易让人生病的微生物，比如细菌、病毒引起的传染病。比如2003年的非典，就是一种叫SARS的病毒引起的急性呼吸道的传染病学。你的爸爸妈妈应该可以给你一个讲一讲当时的情况；另外，还有已经在地球上消失的“天花”，也是瘟疫的一种。著名的是很可怕的传染病。
