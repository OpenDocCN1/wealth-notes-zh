# 最早的安全性测试

最初发现糖精的人看法伯格，当他准备大规模出售糖精的时候，他自己心里也清楚，这个东西是合成的，它跟传统意义上的食品不太一样，所以他保证这个量是安全的。为此，他还做了一些实验，比如说他自己一口气吃下了100克糖精，这个量，相当于好几公斤的白糖。吃完后，整整24个小时，他没有任何情况。还有，他也让别人尝试吃了一点点糖精，然后收集这个人的尿液分析发现，在尿完全干净了之后，这些糖精就通过尿完全部排出了。所以，法伯格认为糖精对人体来说，是安全的。

虽然我们现在用现在的角度来看，这样的实验其实还远远不够的角度来看，在那个时候，这样已经非常仔细了。尽管如此，还是有人对糖精不满。其中一个人叫威廉·F·G·麦克米伦，美国有一个机构叫FDA，是管理食品还有药品的监管的最重要的机构之一。麦米伦就是FDA最早创始人。他很不喜欢糖精这个东西，因为他觉得这个人形制造了一种虚假的甜味，但是想吃它的人制造了一种虚假的感觉，所以，他想把这个东西给禁止掉。

不过，当时没有多少人说他听他。所以他没有办法，只能去找当时美国的总统罗斯福。注意，这个时候的罗斯福是打赢第二次世界大战略的那个罗斯福，而他的堂兄，老罗斯福总统。不过，威利找到罗斯福也没用，因为他找不到一个理由去说服麦米伦，他觉得很无聊，麦米伦觉得这是一个要禁止？

# “糖精专门委员会”

除了总统之外，还有一位议员，也是极力反对糖精的。他理由很简单，只需要一点糖精，就可以达到很高的甜度，这给食品业节约了成本，有这么好的东西，为什么不让大家用呢——你看，各有说法，所以，这三个人就开始吵了起来。

但是吵着吵着，他们三个人都意识到了，大家只是各执已见，谁也没有充分的证据说，糖精到底是安全还是不安全的。所以，罗斯福总统说，我来想办法解决这个问题吧。于是，他组建了一个专门的委员会，来研究所的专家参加，到麦米伦不安全，这个委员会要研究的第一个东西，就是糖精。
