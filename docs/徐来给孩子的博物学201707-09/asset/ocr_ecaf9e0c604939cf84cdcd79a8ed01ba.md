徐来

你一定很喜欢拍照。可以自拍，也可以拍别人。现在，大家拍照很方便了，拿出手机就能随手拍一张。拍完之后还能马上传到网上。早几年可没这么容易了，那时候手机拍照的效果不太好，所以大家都要用数码相机。再早几年呢，就是胶卷相机了，在音像店花大钱的时候，拍照可是很稀罕的事情。当时我们家有一台海鸥相机，那是得锁在柜子里的，轻到不会被拿出来的。
再往后，拍照就更难了。照相甚至都成为一种极其隆重的事仪。

# 拍第一张照片的人，不是发明照相机的人

拍摄人类历史上第一张照片的人，叫做涅普兹。这是一个法国人。他发明有一种溶液，被大家照过之后会变化。洒青液体是一种黑褐的复杂混合物，是高粘度有机液体的一种。

![](bbox=[0.15, 0.31, 0.85, 0.42])

溶液被太阳光照过之后会变硬，而没有变硬的部分，可以用一些特殊的溶剂，把它溶解掉。这个特性很有意思，复制版画就是把这幅画的背板洗成干的，这样，白色纸面上的部分就都选洗光了。他把这张画，覆盖在青纸上，拿到太阳光下去做，画面上白色的部分底下的溶液就被晒到了，慢慢变硬，而黑色的部分，则不会变硬。然后再用溶剂把变硬的部分冲洗掉，剩下的部分就可以拿来印版画了。
再后来，涅普兹就想，“我能不能用同样的方法来试试，能不能把现实世界当中的景色给放进这个液里呢？”，他想到这，就去做了。
一开始并不顺利，颜色很不稳定。慢慢的，他摸索出了经验，然后在1826年的时候，拍摄了人类历史上第一张照片。我为它找来了这珍贵的照片（下图）。照片里模模糊糊地能看到他家阁楼外的房屋。

![](bbox=[0.15, 0.53, 0.85, 0.6])

但是，涅普兹的这个方法，实际上没办法大规模使用。因为穷青青变干太慢了。比如，为了拍摄到刚才隔壁外的景观，竟然用了整整8个小时来做这些事。
所以，涅普兹想要继续优化自己的技术。
现在，也有一些人正在关注这种感光线条记录影像的方法，这些人找到涅普兹，想要跟他合作。涅普兹最后选的那位合作者，正是我们今天的主角，他的名字叫，达盖尔。

# 达盖尔扛起了涅普兹的旗

要说这个涅普兹，运气实在是太差。在拍摄了人类历史上第一张照片后，大概只过了六年，突然有一天，这个人就去世了。
这个突然的变化，一下子就把达盖尔推到了众人的目光下。达盖尔是涅普兹相比，则太是微不足道。涅普兹是个印刷的，他做的这一套核心技术，是简化印刷的流程，让到对版法更简单，而达盖尔，他是个舞台设计师。舞台设计，经常要画一些计划跟效果图。房屋建筑啊啊什么的。所以，他的核心目的是让舞台设计绘画变得更简易。之所以要和涅普兹合作，是因为他觉得涅普兹的方法是一种很好的快速绘图技术。

要说达盖尔这个人，确实很厉害。他利用一些已有的经验以及涅普斯留下的资料，继续改进摄影方法，终于在涅普兹去世6年之后，完善了自己在摄影法。他对外宣布，自己发明的摄影方法取得了成功。
不久，法国科学院也承认了他的这项发明，正是因为这他在世界上第一张照片，但却成了摄影术的发明人。

![](bbox=[0.15, 0.89, 0.85, 0.95])

达盖尔的摄影方法需要用到白银、碘、水银和食盐。制作的流程也非常繁琐。但是人们可以用这种方法把眼前的景物给直接记录下来。不过，达盖尔摄影法获得的图像，没有办法印出来，只能拍照，通过盐片冲洗出来，或者用油画打印出来。通过这个法子拍到的图像，是直接印在了伏尔底纸的铜片上，而且，必须要从某个特定的角度才能看到。
除了这些成就，达盖尔还创造了一个记录，他拍摄了人类历史上第一张长曝光的照片。因为那个时候，照相机都需要很长的曝光时间，即便是达盖尔摄影法，也需要至少10几分钟。人必须长时间保持不动，他的色彩都会被保留下来，所以，达盖尔在拍摄巴黎街道时，因为有个人在换鞋，因为鞋的动感，所以，他的影像被保留了下来（下图）。

# 好发明家更要是好商人

在那个时代，为了保护发明家们的利益，专利制度已经被建立起来了。如果你能证明，你独立发明了某个东西，那么申请可以占有这个权利，以后如果谁使用你要用到你的这个产品或者方法，都要付钱，这其实是为了保护发明家的积极性。
达盖尔也不傻，发明了达盖尔摄影法之后，他也对这个技术申请了专利。但是，法国政府一看，这可不行为。因为这项技术很好、很赚钱，应该让更多的的人用到。再说了，法国人发明了这么好的技术，法国政府理论上也有权利，干嘛让法国政府独占，达盖尔摄影法给了专利权，并且解除专利。这样一来，所有人就能都能使用它了。
达盖尔虽然从法国政府那边得到了一大笔钱，但看着自己的专利在法国乃至整个欧洲大陆都失效了。他气不过，他就这样拿着技术找英国人。他注意到，英国的一些发明家也在摸索类似的专利，于是，他在英国申请了专利。英国的专利法跟法国的不太一样，法国政府出决定的，买回国有权，所以，他在英国的专利一直保留到无期。
这个专利真的是太厉害了，它不但给美国摄影术的发展产生了非常大的影响，也为达盖尔带来了更多的财富。
不过，达盖尔，人类的记忆力总是好不了的。在法国政府解除达盖尔摄影法专利的12年之后，一种新的摄影方法被发明了出来，它不但效果更加好，而且，出现了底片可以晒很多份照片。
