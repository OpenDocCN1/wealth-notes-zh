# 什么是英吉拉？

那是两三年前的一趟旅行了，当时我跟随着联合国儿童基金会的考察团去埃塞俄比亚了解当地的公共卫生情况。主要是当地疫情的使用情况一说到这，我想到你，你小时候也打过不少预防针吧，你一定很讨厌打针，甚至想着要整理好，但是，是保护我们的。打预防针是帮助我们的预防疾病的，是保护我们在非洲，很多地方和我们一样的孩子根本没打过预防针。所以，以后打预防针的时候，请不要皱眉头哦。

好了，说回刚才的话题，我吃的最恐怖的东西，我在埃塞俄比亚吃到了当地的一种经典食物，名字叫英吉拉。这个东西平时的时候看着整整齐齐，就像是一小卷平手巾，打开来，一面儿是光滑的，另一面儿则有很多孔洞，很像蜂窝一样。

这些圆孔内的“下手”，有些是白色的，有些是深棕色的（下图），有些是土灰色的，还有一些肉酱和菜酱，得撕下一小片英吉拉，然后蘸着吃。

![](bbox=[0.1, 0.52, 0.9, 0.62])

我吃了一口，太酸了，酸到让我觉得咬有点痛，就像是在喝强酸，感觉嗓子都被烧化了。这形容有点夸张，但英吉拉确实是非非常非常酸。

我觉得很怪常，为什么要搞出这么强烈的酸味，于是问导向，向导解释说，这个酸味是发酵的。英吉拉的原是一种叫做苔麸的东西，这是埃塞俄比亚人主要的粮食。它和其他国家的人常吃的、大米、小麦不一样，直接我们喝粥的，同时由于苔麸没有壳，让来发，再烘，就成了英吉拉。

苔麸到底是什么东西呢，我的好奇心立刻来了，于是特地去查了一下。一查才知道，这竟然是一种谷物。

![](bbox=[0.1, 0.76, 0.9, 0.82])

# 什么是谷物？

我们平时吃的粮食，主要是谷物。从生物学的角度说，谷物都属于禾本科的，跟我们平时吃的禾苗是同一个家族的。我们平时吃的稻米、麦子、玉米等，都是谷物，尤其是玉米，可别小看了玉米，它是世界上所有的农作物当中，产量最大的一种。

有意思的，人种植那么多的玉米，却并不是用来吃的。虽然我们平时会煮粥玉米吃，或者做成松仁玉米这样的食物，但总体来说，玉米长得太大的，很少很少的。人种植那么多玉米，其实就是拿来当做饲料，来饲家畜家禽的，也就是，我们平时吃的猪、牛、羊、鸡、鸭、鹅，很多都是吃玉米长大的。现在，还有一些人用玉米酿造，然后利用这些酒精来发电。

实际上，不光是玉米，其他种重要的谷物，也不是直接吃的。比如大麦，这是种植面积仅次于玉米、水稻和小麦的、世界第四大谷物。它也不是主要用来吃的，而是用来，这个季节里，很多人都爱喝上一杯冰啤酒清凉。这个啤酒就是用大麦做的。
