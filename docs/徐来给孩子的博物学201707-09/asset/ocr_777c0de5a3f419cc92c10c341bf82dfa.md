# 重力变化会带来麻烦

宇宙真的是一个有意思的地方。但是最重要的它是两个好玩的点，一个是失重，一个是射线。

失重这一点我们前面的专栏里也讲过。咱们简单复了一下失重是怎么回事儿。失重并没有重力，只是因为重力变小了，你会越来越像悬浮在太空中，你的身体会感到不舒服。

当然，登陆不同的星球，失重的感觉也不同。这取决于这个星球的体积和质量大小。比如月球，月球的质量比地球小很多，个头也小很多，理论上讲，月球上的重力差不多是地球上的六分之一。我们在地球上走路的时候，会感觉很轻松，走不了那么快，而且看起来就像是在蹦蹦跳跳一样。

# 射线的作用有好有坏

刚才说是宇宙第一个有意思的地方，失重。现在说说，第二个好玩的地方，射线。宇宙当中有很多看不见的神秘粒子，时刻刻从一个地方飞向另一个地方。地球的大气层能挡掉这些射线，但是离地球越远，防护就越弱。有些射线很厉害，会对咱们身体细胞当中的遗传物质，给咱们的身体带来伤害。所以在宇宙中要采取一些措施来尽可能挡住这些射线，比如不能在舱外停留太久，以及穿特殊的宇航服。

破坏其实也不都是坏事。有时候，被射线破坏之后再修复好，反而比原来更好。人当然不会，要是这么个好的，那就留下。如果是坏的影响，那就是“辐射育种”。你想在超市里见过一些诸如“太空南瓜”“太空番茄”之类的蔬菜吗，就是由太空育种，通过选择育种，这些植物种子被带到太空上去，这样对土壤刺激起来，这叫“诱导突变”。虽然植物在宇宙射线中受到损伤，但通过筛选，可以选出优良的性状。

有些植物的种子会产生变化，但是那些变化，不一定会在后面的生长过程中体现出来，即使体现出来了，大部分也是无用的变化，或者干脆是有害的变化。人类从1957年发射第一颗人造卫星开始就在尝试这件事。放了30多年，才成功地在一回中采到了几棵活物。那是一种叫“拟南芥”的植物，收获的种子很健康，还都能继续种植。另外，这种辐射育种完全可以在地球上，通过一些射线物质来模拟，根本没必要去太空折腾。但是，在太空里进行，可以节省很多的时间和费用。所以，人类一直都想建立“太空农场”。

# 植物还需要阳光和水

在太空里种物，我们遇到的第一个问题就是太空射线。万物生长靠太阳，植物当然也要靠阳光来进行光合作用。在地球上，有厚厚的大气层帮植物挡住部分辐射，它们的根系受到很大的保护。在宇宙的空间中，这种保护就没了。或者至少是削弱了。所以，先得被植物保护住，但是得透明的，不能一点儿光没有，对吧？

第二个问题是水。植物生长可以没有土壤，问题是有水，土壤是长。但不只有水，而且植物，尤其是我们种的那些作物，耗水量是很大的。比如大家吃得最多的食物之一，小麦。小麦生长的水消耗比100克水500克，也就是说，小麦每增加1克净重，需要消耗500克的水。注意，这是净重，耗水量不一定等于喝多少水，把水留在土里，几乎可以吸干，相当于地球上的水，大气中可有可无，而且运送水上去是很贵的。所以，在宇宙里种物时，需要设法把植物自己吸收并留下的水分重复使用。这可是个很费事的事儿。

失重条件也会给植物生长带来极大的影响，可能也会受伤。确实，就是飘来飘去飘，还能长得好。失重，飘来飘去的好玩的，而且在失重条件下，还会出现很多很奇怪的现象，比如水会在空中形成一个水球。但是，在失重的条件下，想要让水不滴下来是很难的。人分不清楚上和下，植物也是一样的分不清上和下。所以，在宇宙里种植物，根系没法乱七八糟。在地球上，根朝下，茎朝上，这个分得很清楚。但是，一失重，大家就经常混不上根和茎，分不清上下，还会出现四面八方都是根，都是茎的样子。

这样乱七八糟的植物，浪费了养料不说，也容易影响植物生长。更重要的是，失重条件会影响细胞的生长，甚至会让植物变得很矮小。科学家发现，在空间站里种出来的萝卜和大头菜，品质比在地球上种出来的要大得多，而且，采收后的叶片，虽然能生长，但依然是很瘦弱，开花种子的时间也比正常的时候晚很多。
