# ## 为什么会有年份葡萄酒？

葡萄酒的好坏，跟用来酿酒的那葡萄系统很大。而且不光是看葡萄的品种，即使是种在同一地方的同一块葡萄，因为温度和降水水平的变化，也会体现出品质的高低变化，从而影响最终酿出来的酒的好坏。所以，对葡萄酒来说，有些时候，葡萄的酿造年份会变得很重要。在有些年份里，温度、降水的水平特别适合葡萄的生长，种葡萄的人，管理葡萄也会特别用心，到了一定的岁数，就会有一杯好酒。所以，葡萄酒传统上是要标注年份来售卖的。品质越好的年份，价格也有可能就会贵。

现在问题来了，万一有人乱贴标签，把这几年新收的酒，贴上以前年份的标签来卖，那怎么办？

别说你不知道该怎么办，一开始所有人都不知道该怎么办。大家只能靠品尝家们的品鉴来判定，可是一来都让品尝家品鉴了，那这些酒肯定是打开了的，这是怎么卖呢？二来，就算是最好的品酒师，他也有拆穿了的时候，万一他品错了呢？怎么办呢？

# ## 什么是碳14测年法？

后来，有些科学家发现，可以用一些简单的方法来鉴定葡萄酒的年份。比如，我们的身体里就有碳，动物植物身上也有啊，平时吃的食物里都能找到啊。咱们身上碳的99%是普通的碳-12，只有极少部分碳-13和碳-14。碳-14是一种放射性同位素，它很不稳定，会衰变，寿命大约是5730年，这就是碳14测年法。这个原理特别好用，因为如果去检测一个东西里有多少碳14，就可以算出来它有多少年前形成的。

# ## 葡萄酒里为什么会有放射性粒子？

这第一个问题，后来其实也解决了，至少是部分解决了。解决它的是一位科学家，而且纯粹是误打误撞，胡儿胡闹玩儿的时候，解决了这个问题。

原来，有一帮科学家，专门监测从宇宙各处射到地球上的各种射线。但是，地球上的很多东西，本身也会向外发射射线。这其中，有一种叫做伽马射线的东西，放射特别强。它还是从天外来射到地球上的射线。科学家通过研究，发现这些伽马射线在穿透地球之后，会衰变掉一些。通过测量地球上的伽马射线强度，可以算出来它在穿透大气层之前是什么强度，这就是“宇宙射线”。

仪器做好之后，科学家就开始玩儿了，把各种东西都放进了伽马射线里测一测。结果，就有人发现了很奇怪的情况。有一些葡萄酒里，能检测出不应该检测到的伽马射线。所有葡萄酒，这些射线的存在还特别明显。一开始，科学家没有在意这些葡萄酒有什么特征，但是检测得多了，他们逐渐发现，射线特别明显的葡萄酒，主要来自两个时间段，一个是1950年到1963年之间，另一个时间段是1986年。

这两个时间一对照，科学家们立即明白了这是怎么回事。这两个时间段，前一个，是人类集中进行核试验的阶段；后一个，是苏联发生历史上最严重的核事故的时候。而这些放射性射线，其实都是核反应中产生的一种叫钋-210的放射性同位素。

而且，它发射的γ射线，是随着时间的变化而变化的。科学家可以用数学方法，整理出变化曲线，然后把某一瓶葡萄酒中测得的数据放回去比，立即就能知道结果。

更重要的是，伽马射线可以轻易穿透酒瓶，所以不需要打开酒瓶就能做。这样一来，咱们前面说到的那第一个问题，也就得到了解决。实际上，在2000年的时候，科学家就是这样生产了法1989年的葡萄酒，实际上是1962年产生的。

当然，说到这里你可能会担心，这种和核试验有关的粒子会不会不安全，会不会喝了之后反而给自己带来麻烦。这个其实不用担心，因为这样带有的放射性粒子能扩散到其余地方的数量是极小极小的，它们不会对我们的健康造成什么危害。
