# 40层楼高的超级巨树

现在世界上活着的最高的的一棵树，名字叫做“玄伯龙神”。这个玄伯龙神，是古希腊神话中的巨神，也是太阳神赫利俄斯的外公。巨神的名多来称呼一棵树，你可以发现这种树有多高。科学家发现这棵树之后，对它的测量进行了测量，结果发现它高达115米。115米是什么概念呢？咱们一般的楼房，每一层楼的高度在3米之内，如果你家住在40层以下，那么你所在的高度就比这个玄伯龙神矮要矮。

这种叫“玄伯龙神”的树属于一个特别能长个儿的家族，那就是红杉家族。红杉这种树，生长在美国西海岸的加利福尼亚州。尽管“玄伯龙神”特别能长个儿，但它也花了七八百年才长出现在这个个头。七八百岁，那它差不多是中国清朝刚建立的时候，就开始长了。虽然它的岁数已经很大了，但在红杉家来说，玄伯龙神还是个少年轻呢，它还在继续长高，以后可能会长得更高。

是不是很厉害？

可是我们前面说了，人长得太高会碰到各种各样的问题。其实，树长得高也会碰到问题，其中最重大的一个问题是，树木怎么把根部的水分输送到那么高的树枝上去。

# 怎么把水运上40层楼

我们都知道，水是生命之源，所有的生命活动都要靠水来维持。一棵树，往长到哪里去，肯定就需要把水运到哪里去。可是要把水运到115米，相当于40层楼的高度，可不是一件容易的事情——你想象一下，要想将一杯水，爬40层楼，那是一件非常可怕的事。但是做这一件事不可能的事情，时时刻刻都在玄伯龙神的身上发生着。

一开始，生物学家们认为，是“毛细现象”让细胞能到达很高很高的位置。毛细现象的意思是，有一种很细很细的管，里面包含很多很细很细的，能够引导水分往上去，填满它内部的料，有孔洞。这个现象在我们的生活当中非常常见，比如我们在桌子上泼了许多水，你常几张纸巾垫在水的底下，不一会儿水就会上去，都纸巾吸干了。这就是毛细现象的结果。

在树木的内部，也有很多又细又多孔的纤维。科学家们认为，它们也能通过毛细作用把水运升到很高的位置上，让整棵树的都变得水的。

不过，糟糕的是，也有一些科学家对这种可能性进行了计算，发现，如果只是靠毛细作用，植物只能把水运升到几十米的高度，对于一般的树木来说，可能已经够了。但是在红杉家族里，至红杉这个世界上最顶级的树来说，那是远远不够的。事儿就麻烦了。你看，按照这个理论推理，玄伯龙神长到这么高应该不可能，早该在几百年前就死了。所以，毛细现象的解释显然不对。

后来，科学家们继续研究，一个研究就发现了，原来对树木来说，不只靠吸水的依靠毛细作用的力量，它们吸水的地方，也能靠内部的水流，甚至去推动的水往上走的更大的地方。这个动力就是植物叶片的蒸腾作用。

![](bbox=[0.1, 0.00151, 0.9, 0.00165])

# 蒸腾作用是天然的水泵

所谓的蒸腾作用，其实就是说叶片每时每刻都在向空气中输出水。把大量的水分一排出，叶子和茎就变得很干燥了，于是就要从根部分水来补充。这样一来，就根据水分从根中分泌了出来，再加上毛细作用自身的推动效果，一直把水抬到了很高的位置上。也水也会干了，那么珍贵的水分，轻易蒸掉了，干燥蒸腾到空气里非常费劲。其实，水分的蒸腾对植物来说非常重要。光是叶面的原料之一，可以帮助植物带来土壤里的各种微质元素帮助植物生长。所以，植物能够源源不断地从根部获得养分。至于已经被吸收完微量元素的水分，已经有太大用处了，那就蒸腾吧！

根据科学家的测算，通过这样的方法，植物能过130米，也就是说，从理论上来说世界上最高的树，能比目前的“玄伯龙神”再高出10多米！

植物真的会很神奇。不过，这么神奇的植物用水也不是没有它的难题。水分会含有各种杂质，它们是只有植物会植物的供水管道出口的一些。每年植物都会用旧管道的面积长出一个新的管道来，这样一来，树木不但越长的越高，也越越长粗了。
