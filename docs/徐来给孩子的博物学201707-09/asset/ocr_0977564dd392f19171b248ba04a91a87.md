# 人多的地方灰尘也多

说到灰尘，其实我知道你注意到没有，灰尘的出现，我是不太有些规律的。有的时候，我们会发现，即便寒冬大冷的，几乎不开窗户，家里也会尽快积聚不少灰尘；难道说，是不是门不紧，把外面的灰吹进了屋内？

如果你是平时是一个仔细观察各种细节的人，可能会注意到一个有意思的情况，家里有多少房间，在各自的房间，使用，频率是不一样的。有些房间，偶尔有人进去一下，有些房间，几乎整天都有人。这个使用频率，跟房间灰尘的多少，好像有点关联。总是人的房间，灰尘会多一些，反之，就要少一些。

为什么会出现这样的情况呢？也许，你可能听过一句话，“灰尘主要是人的皮肤构成的”，甚至有些说法精确到，在我们的家里，灰尘里面有80%是人类的皮肤。听到这灰尘，你是不是会感到很大惊，“啊，怪不得房间里越多灰尘也越多。”

等一下，皮肤是长在我们身上的吗？怎么就变成了灰尘呢？其实，我们的皮肤不是一成不变的。最外层的皮肤细胞会逐渐失去活力，最终死去，然后就开始脱落下来。我们的身体就不断的有新的皮肤来替换它们。这种新陈代谢的速度也是一定的，差不多，一个成年人一天会脱落大概5克的死皮，日积月累，的确确实为咱们家里增加了许多灰尘。

但是仔细想想，又会觉得不对，皮肤细胞脱落以后，并不一定会变成灰尘的表面脱落下来，而是我们的皮肤上有油脂、有水汽，有毛发，它们本身就像有很大的吸湿能力，在我们的皮肤上，一直粘着灰尘，洗脸的时候，手一搓，就能把灰尘全搓下来，变成灰色的这玩意儿。即便它们掉下来，它们也不像是干燥粉末一样的一堆，而是软趴趴的，粘粘的对吧？所以，这些脱落的皮肤，会粘在衣服上，钻进衣服的褶皱里。除非我们把衣服洗干净，否则就算把这些东西也不会掉出来，它们中的绝大部分，还是会在洗衣服的过程中被水冲走，然后一起进到下水道里。

# 灰尘包含蛋白质

现在问题来了，我们家80%的灰尘来自皮肤，这个说法是怎么来的呢？你可能在想，这不是谁胡编乱造的，或者是谁随口一说。如果要这么说，那就错了，这个说法是科学研究的。

那是1974年，一个科学家发表了一篇文章，这篇文章专门研究了皮肤碎屑在空气中的含量。在研究中，这个科学家到，在自己所调查的农村地区，注意到80%的室内悬浮颗粒中包含蛋白质。这句话的意思是，有蛋白质，就是皮肤。皮肤是蛋白质，这个说法是有一定道理的。但是这句话有点意思，“有蛋白质，就是有皮肤”，但这是真的吗？

当然，这个说法还有一点，就是皮肤是蛋白质。除了人皮肤外，其他动物也有皮肤，它们也含有蛋白质。所以，皮肤是蛋白质。当然，皮肤是蛋白质，还有其他物质也含有蛋白质，比如头发、指甲等。

科学家分析了一下原因，他们觉得出现这种偏差的原因，是因为大家都在做运动，运动量比较大，就会有更多皮肤落在外面。此外，在运动过程中，皮肤会更容易从身体中脱落，这样，就会让皮肤落在衣服、床单、枕头上。

# 灰尘的成分跟环境有关

随着研究越来越深入，科学家发现，这个说法，有点人来，有点人走。因为很多因素会影响灰尘的成分。在不同的地方，不同的时间，得到的结果是不一样的。你在同一个地点的不同时间采样，得到的结果也不一样。很快，科学家就会想到，“我们一直认为，灰尘的成分是一样的，其实是错误的。”

实际上，后来有科学家研究了一些特定环境下的灰尘成分。比如医院，学校，办公室等。结果发现，灰尘的成分确实不同。这也说明了，灰尘的成分是跟环境有关的。

# 博物学家养成记

今天知道那么多关于灰尘的说法，是不是对灰尘有了完全不一样的认知了呢？如果再让你吸尘，会认真打扫吗？你可能会发现，灰尘里有很多成分，比如皮肤、头发、纤维等。它们都是来自生活环境的。
