# 什么是比邻星？

别除了，你可能没有见过它。因为这颗恒星所在的位置太南了，所以，在中国的大部分地域，无论如何都看不到这恒星。身上看到，武汉、重庆一带有城市的灯光，你也能看到它。但只能出现在比地平线略高的位置。这是无法观测到，何况，即使你到了较为温暖的地区，甚至出国的南半球，能轻易观测到南半球，甚至找到它也是肉眼看不到的，因为它太暗了，观察它要借助望远镜。

假如你身在南方，能够看到南方的星空，那么首先找到 南十字座跟 南十字座很好辨认，四颗恒星两两相连正好差不多是个十字形。然后，有一些很亮的恒星围绕在它周围，这就是半人马星座。找其恒星中最亮的一颗，它就是半人马座α。它是南十字和南十字座星系的最近门大说明一已经是当时人们能观测到的最亮的恒星，人们就称为它南十字，古人也常常在天上找它，古人称南十字为南十字，南十字是中国人对它的称呼。南十字和南十字座的两个最亮恒星，它们也是肉眼可见的。距离最近的恒星就是藏在南十字座的这个角落里。

这颗恒星叫比邻星。比邻就是邻居的意思，在茫茫的宇宙当中，它就是太阳的邻居，当然，也就是咱们所处的太阳系的邻居。

比邻星这颗恒星特别重要，全世界的天文学家们都特别重视它，来原因是距离太近。有多近？说出来吓死人，4.2光年。

说到这个数字，你可能没有概念。换个说法吧，如果你以10个速度绕地球跑的话，大概要跑上10亿圈。如果我们人类的飞机是飞得最快的飞机，那飞到比邻星也要需要一百万年的时间。

等等，这么说还远远不够。对的，最近，因为咱们所在的这个宇宙，真的是太大了。4.2光年之外有它个一颗恒星，已经足够让每一位天文学家兴奋不已。

# 什么是比邻星b？

不过，如果只是有比邻星，天文学家也不会这么激动。真正让天文学家感到兴趣的，是另外一颗新发现：2016年，天文学家们注意到，原来比邻星旁有一颗行星。这个消息让大家都很兴奋，因为人类已经观测到了无数的恒星，但找到的行星却很少，数量上完全无法跟恒星相比——你可能又问，这都不对了，你看，太阳有一个恒星，就是太阳，恒星有8个行星，还有好多矮行星和小行星，行星的数量还远远比得上恒星多，对不对。

话当然是这么说，但恒星会发光，行星就不会。所以，人们只能看到近处的恒星，而看不到远处的行星。这是之前的情况。但天文学家们发现了一件事。行星有它自身的光谱，天文学家们能从恒星到行星的光谱中，找到恒星光谱的一点点变化，来推测行星的存在。

![](bbox=[0.1, 0.28, 0.9, 0.4])

更重要的是，比邻星不但有一颗行星，这颗行星还适宜居住。

还记得我曾经给你讲过宜居带吗？宜居带，是说明一颗恒星周围的一个范围，在这个范围里，一颗行星既不会被烤得太热，也不会因为离得太远而过于寒冷。所以，在这个范围里的行星，是有可能存在生命的。这颗行星就位于比邻星的宜居带内，上面有水的几率非常大。

天文学家们给比邻星的这颗行星起了个名字叫比邻星b。

![](bbox=[0.1, 0.62, 0.9, 0.74])

# 关于比邻星b的猜想

当然，我们现在很难说比邻星b上面有生命，因为我们对这个星球的信息知道得很少。比如说，天文学家们知道，比邻星b比地球大一些，但是到底多大，他们并不清楚，只是推测出了一个范围。

这又是一个很关键的问题。如果这颗行星比地球大，那就有可能是类似木星或土星的大气行星，这种行星有大气层，它上面发生着生物的可能性就很低，我们称之为气态巨行星。

其次，虽然比邻星b处在比邻星的宜居带里，但还不能说明什么。宜居带里的行星要能产生生命，还需要有大气层。比邻星比太阳小，太阳系的宜居带就比比邻星的宜居带窄一些。
