# 精选留言榜

看到今天的专栏，让我想起了一个观点，说大多数人对于别人传播的已有的观点和结论都是直接接受，而不会去思考结论是否正确，论证过程是否科学严谨，所以当某天发现了事物的真实面之后，你会觉得很毁三观，谎言已散播各地后真理才准备出发，当谎言说的多了听的多了，人们就信以为真，并把它当成了真理。

温水煮青蛙的故事，之前听过，现在听了有新的收获，原来这个故事还可以反着用，你要影响别人做出一个大的改变很难，但慢慢一点影响就会有效果。好习惯也是慢慢从容易的事情做起不知不觉养成的。我还想到类似的，例如润物细无声，千里之堤溃于蚁穴，对于好的事情要坚持做，坏的事情即使再小也要避免做，这样才能不至于变成大的毁灭性强强的事情。有个强盗厉害他妈妈小时候纵容他偷小东西，咬掉他妈妈的耳朵。所以，从小就要端正思想，教育好，勿以善小而不为，勿以恶小而为。

徐老师好。看完今天的分享，我有点收获：第一，温水煮青蛙的道理。这让我想起了一句古话：勿以善小而不为，勿以恶小而为之，同时还让我想起一个近几年很热门的词——反脆弱。个中的道理，相信和人们防范风险，应对危机有关。第二，科学家煮青蛙的实验，这让我想起起烹饪界的一种烹调方法，叫做真空低温煮青蛙。原理就是将食材装进袋子里抽真空后，将袋子放到50到60度的恒温水浴中，进而烹煮食物的方法。听说用这种方法烹煮出来的食物会有与众不同的味道和口感。不知道这是不是与蛋白质的变性程度有关？

左边平流雾，右边海市蜃楼。我记初中（高中）的课文中学过一篇关于海市蜃楼的文章。现在具体的内容记不得了，大概的印象就是简单讲了海市蜃楼形成的原因。今天还收获了平流雾的概念，真是不学不知道，世界真奇妙！

记得中学学过海市蜃楼，可虽然去过海边，去过沙漠，都没见过此景观，而且已知温度，地方关系也比较密切吧。另外，我记得中学教的是海市蜃楼，沙漠蜃景。飞翔的荷兰人……我一下就联想到《加勒比海盗5》，还挺好看的。其实我对大海一直是很敬畏的，虽然我不怕水，但怕海。白天的大海湛蓝很美很美丽，有时候还很清澈见底。不过晚上的海就是黑色，像一个无比巨大的黑洞，可以吞噬一切，而且，这深邃的海底到底有什么，谁知道呢
