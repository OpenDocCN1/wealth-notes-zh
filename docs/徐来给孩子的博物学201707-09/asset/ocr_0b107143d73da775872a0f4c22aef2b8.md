# 博物学家养成记

从苹果籽到苹果树，这里面会发生怎样的变化呢？如果有兴趣的话，也找个花盆，种几粒苹果籽试试吧。当然，在花盆里没办法种出可以吃的苹果来。不过，观察一下苹果籽的发芽生长，也是一件很有意思的事。欢迎你 把种植的过程，拍成照片，发布在咱们的学习小组里。

+   1. 苹果最初生活在 中亚地区，但是果子比较小，汁水不多，也不甜。后来，经过培育的苹果，扩散到了世界各地。

+   2. 据说，伟大的科学家牛顿，偶然被一颗成熟落下的苹果砸中，并由此发现了万有引力。这棵传说中的苹果树被引种到世界各地，天津大学的校园里就有一棵。

+   3. 在美国的西进运动中，人们生活非常艰苦，苹果给他们带去了甜味。

+   4. 约翰·查普曼从苹果酒作坊收集苹果籽。种植了很大规模的苹果林，这个苹果林成了巨大的苹果种植资源库，为后世园艺学家培育优秀品种提供了帮助。
