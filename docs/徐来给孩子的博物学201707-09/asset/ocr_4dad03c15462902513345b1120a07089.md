# 生态学·动物 | 裸滨鼠为什么不怕疼？

世界好好，奇妙的事情每天都有，我们一起发现吧！

你观察过蚂蚁吗？蚂蚁可能是我们最容易观察到的动物之1了。每年春天、夏天、秋天，在池塘边上，在小区、人行道边、公园花坛里，一低头就能发现它们。你在这些地方看到的，东西大多数都是蚂蚁，也就是蚂蚁中的工人。这是蚁群当中的一种蚂蚁类型。

这个世系，有很多蚂蚁类型，它们构成了蚂蚁界。包含的蚂蚁类型，大体上就那么几种，刚才咱们说的工蚁，这是蚁群当中的工人，负责寻找运输食物、筑巢保卫蚁群、负责产卵。工蚁，负责保卫蚁群；另外，还有雄蚁，负责专门负责繁殖蚁群的；每一个蚁群只有一个蚁后。蚁后是所有蚂蚁的母亲，这只代表的孩子。而且，它还可以控制每一工蚁和兵蚁，让它们做啥，它们就做啥。

或许你听说过，以这样的方式集合成群的社会动物，不止蚂蚁一类的，还包括其他蚂蚁，比如蜜蜂、胡蜂还有白蚁。这些昆虫组成的群体，结构都是这样的。这样的动物，被称为真社会性动物。这里的真，不是真正的意思，而是表示强调，意思就是：这类动物构成的群体结构简单、更复杂，而其他聚集成群生活的动物，比如狮子、山羊、斑马等等，虽然也是社会性动物，但它们的结构相对要松散一些。

我今天要说的这种动物，不是昆虫，但也属于真社会性动物！

# 真社会性动物一裸滨鼠

在东京上野动物园的小型动物馆里，有一个展架，里面塞满了泥土，饲养员在泥土里铺设了一些透明的塑料管，用它们构筑起一个巨大的地下巢穴，这里生活着的，就是少见的真社会性哺乳动物之一，裸滨鼠（下图）。

![](bbox=[0.2, 0.71, 0.8, 0.82])

我不太确定，你会不会喜欢这种动物，我很喜欢它们，当时我在那个展柜前面停留了很长时间，仔细观看每一根管道里发生，看它们在做什么。有些老鼠甚至是活着才生不几久的裸滨鼠，看起来很嫩，很有喜感。不过，如果你看到它，可能会不太裸滨鼠，有点点恶心，它是一身老鼠，长了一副老鼠样子，更重要的是，它们身上几乎没有毛，粉红色的皮肤直接暴露在外面。这就是为什么它被称为裸滨鼠的原因，和那些毛茸茸的动物相比，它确实是裸体的。

这种奇怪的动物生活在非洲。它们组成裸滨鼠群，生活在一起，每个群儿几十只到两百只裸滨鼠。在一个群落里，有一只作为鼠王的雌性强裸滨鼠，其余的都是它的孩子。在整个群里，只有鼠王才能繁殖后代。它会分泌一种激素，来影响裸滨鼠群中其他的雌性强裸滨鼠，也就是它的女儿们，让她们暂时无法生育后代，这些雌性强滨鼠，非常像蚂蚁中的工蚁，或者蜜蜂里的工蜂，每天的工作就是沿着几十公里远的土地到地面到处觅食，寻找植物的根茎，带回去给大家分着吃。
