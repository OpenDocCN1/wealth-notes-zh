# 土星为什么和土有关？

土星为什么会叫土星呢？这个可有意思了，古代中国有五行解释世界的构想，后来要把所有东西，都分成五行之一组，然后对应到五行上去：五个方位：东、南、西、北、中是这样；五种颜色：青、黄、红、白、黑也是这样；当时人们能观察到的五颗行星当然也这样，古人根据行星看起来的颜色来给它命名，有一段时间土星星的颜色呈现一黄色，所以相对应地被叫做土星。

西天神话里土星“萨图恩农场”，这里是罗马人神话中农业之神的名字，手里拿一把大镰刀，嗯，正好也是掌管土地的神经。而且，这个萨图恩斯是坐于很高的，是罗马神话中天空的管理者朱庇特的爸爸。

土星的名字虽然叫“土”，但它一点都不土气。它可以说是太阳系里最时髦的一颗行星了。跟其他行星相比，它有一个特别重要的特点，有环。这个环，就像是一张圆形的厚纸片，横在土星的赤道位置上，跟着土星一块儿自转——乍一看起来，有点儿像是在太阳系里出现了一个超级大的大飞碟。

你想知道光晕有一个造型时髦的太阳系大飞盘吗？嗯，要想看到土星的环，阳光有点难调点。因为光晕里的土星，是看不太得清楚的，毕竟土星看上去是反射的太阳这么邻居的，如果您要看土星环的话，需要借助天文望远镜，或者品质比较高的双筒望远镜。

人类以前没有望远镜，所以一直到400多年前，在欧洲的荷兰，一些制造眼镜镜片的商人偶然发现了镜片可以加在一起放在眼前，放大远处的物体，把镜片的距离缩短，观察起来会很大，于是乎就有了一个。然后，他们反复试验这个东西很神奇，又根据这个效果，复制出制造了一些带有镜片的圆筒，这就是我们现在所使用的望远镜。

# 如何观察到土星环？

后来，这个方法被天文学家知道了，他们也开始自己制造望远镜，以便更好地观察天上遥远的星星。望远镜中最早一位，是意大利的伽利略。他在1610年的时候，第一次用自己制造的望远镜对准了土星。他注意到，土星的周围似乎有点不寻常的斑点。但是，当时玻璃片的制造水平还比较粗糙，望远镜的制作也没有经验，所以，伽利略看到的土星是模糊模糊的，他没办法判断，土星到底是哪样，写下了一段说明，说自己看到土星并不是单独一颗星，而是由三个部分组成的。这三个部分彼此相连，并且不会移动，中间那个部分要比两边的部分大很多。

伽利略就这样遗憾地错过了“土星环发现者”的头号。事实上，当时谁也没想到望远镜的发明，确实没有人在地面观察到土星的环。就这样，又过了将近50年，才有一位荷兰天文学家惠更斯，准确地描述了土星环的存在。不过，即使有了这个环，天文学家还是并不相信存在这个东西，因为对当时的天文学家来说，土星环实在太难观察到，又过了10来年，人们才接受了这一观点，土星环是存在的。

![](bbox=[0.1, 0.0010049999999999998, 0.9, 0.001045])

观测水平提高后，大家看得更清楚了，新的成果就开始往外倒。天文学界确认土星环在土星之后不久，法国天文学家卡西尼就发现，其实土星环并不是均匀的，它本身就是由许多层环组成的，有些地方，组成环的质疏密一些，有些地方稀薄一些，有些地方干脆就出现了很宽的缝隙。

现在的科学们是还知道，土星环其实并不是一整块儿的圆面，而主要是由很很小的冰构成的。

惠更斯和卡西尼这两位天文学家在人类了解土星环的过程中起了太重要的作用了，所以，后来美国航天局把最先发射的土星探测器，就用这两位天文学家的名字来命名。现在我们看到的不少许多土星照片，就是卡西尼拍摄的，不是天文学家卡西尼，是探测器卡西尼。

# 土星为什么有环？

好，土星环大家都知道，但为啥土星会有个环呢。你看，在太阳系里，咱们地球是没有的，最大的颗月球是拥有一个卫星，但是也没有环的，凭什么你个土星会有环呢？

科学家前后后继地做了很多研究。主要有俩说法，一个说法是说这个环是在咱们所在的太阳系刚开始建立的时候，和土星一起产生的；还有一种说法呢，说这个地方原是一是颗很大的卫星，结果后来被另一颗卫星给撞了，撞得土星环了，弄得粉碎，所以变成了现在的这个样子。

这两种说法，各有各的证据，谁都说服不了谁。但是最近有一些科学家发现，这种说法可能都不对，因为他们的观察和计算，土星环是以非常快得速度向外扩散。根据这个扩散的速度，他们计算过了土星环不到3千年前才形成，而在地球出现了生命之后才形成的。
