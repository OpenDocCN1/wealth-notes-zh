# 地喜·地球 I 从挖运河的工人变成大科学家

世界好大，奇妙的事情每天都有，我们一起去发现吧！

你喜欢吃蛋糕吧？有些蛋糕做得很有意思，表面上看起来是整整齐齐的一块，但是切开来再看，会发现里面是一层一层的，有些是同一颜色的蛋糕，中间夹着奶油、水果或者巧克力；还有一些是由不同颜色的蛋糕组合在一起的，做起来大概还是比较复杂的吧。要是有一块儿特别大的分层蛋糕就好了，那样就能一次吃个痛快了。

特别特别大的分层蛋糕，大到能把你周围的一切都放到上面去。不过，这块分层蛋糕可不可能吃，它实际上是我们脚下的那个星球。换句话说，地球最表层的那个叫地壳。别说我多薄是看我们得真的得厚，很厚是相对于地球来说的，其实，这个壳就有几十公里厚。

# 挖运河挖出了新地图

了解地下的东西，比了解天上的东西要难很多。你啊哦，抬起头，我们可以看到星空了，但低下头，却只能看到地面。要想深入了解，就得把地切开去。所以，古代的人类很早就看出了星空图，对于离我们非常近的星辰做出准确的记录。但我们却不太太了解地下的情况。

改变这种情况的人有大本领，是一个大宇宙学家，而不是一个挖沟的。挖河是怎么回事儿？

大多数河流本身不用挖，因为都是自然形成的。但是，如果我们在两条河之间架起桥梁，让船能够方便地在两条河来来回回，那就要有人把它们挖通。这样挖出来的河就叫运河，世界上最长的运河就是咱们的中国京杭大运河。其他国家也有运河，今天咱们说的就是一个在英国挖运河的。这个人叫威廉·史密斯，他生活的年代差不多相当于中国的清朝乾隆年间。

![](bbox=[0.15, 0.78, 0.85, 0.88])

威廉·史密斯没上过几年学，后来当了土地测量员。当时，正好赶上英国工业革命刚开始的时候，为了发展城市，商人们就还要煤来烧，木材，运到各个城市去。当时还没有火车，运输主要靠马，马车拉货，还要挖运河，让船能运一条河开到另一条河里去。但挖运河可不是个简单的事儿，因为脚下的土地，没有挖多深就会碰到岩石，挖不下去了；有些地方又不存水，把水引来很困难就流干了；还有些地方总是滑动，一滑动就河道给挤住了。所以，在挖运河之前，先要对将要经过的地区进行调查。威廉·史密斯就被安排去调查这些土地了。

虽然威廉·史密斯没读过几年书，但是他的观察力非常敏锐。他在做运河调查的时候发现，土随便挖一块土，往下挖总会发现，土不是一层层的，每一层颜色、质地都不太一样，更重要的是，在不同的地方，这些层次出现的顺序也是这样。威廉·史密斯不但敏锐，而且还把这一现象默默地记了下来，然后，每到一处新的地方，往下挖掘的时候，就拿来和挖过的一番。渐渐的，他发现了很多有意思的现象，脚下的大地，就像是分层蛋糕一样，一层一层铺出来的，先铺底下，后铺上面，不同的层次之前有先后关系，有些地方，特别是山有的地方，这些层次不是平铺的，而是斜着的。

就这样，威廉·史密斯白天出去干活儿，晚上回到家就把自己看到的层次画下来。时间久了，他竟然画出了一整片地区的地层关系图。

# 给化石排顺序

在这个过程当中，威廉·史密斯还发现一个有意思的事儿，那就是很多地方的岩石里，有化石的。他发现，化石也是按特定的地层顺序在一起的，某些化石总出现在某两个地层里，这是一个很重要的发现，当时虽然很多人都在收集化石，但几乎没有上升到这么多规律。

后来，威廉·史密斯去拜访一个朋友，那个朋友很有钱，而且很喜欢收集化石，所以自己建了一个小的博物馆用来展示他的藏品。威廉·史密斯到那个小博物馆里一看，诶，东西还挺齐全，也好看的，但是有个问题啊，这些藏品，是按外形排列的，圆的一堆，三角形的一堆，长条的一堆……你看，他说，‘你这样排不对啊。你看，这几种化石，是出在什么层地层里的，哪一种化石，出在什么层地层里’……然后把这些化石打乱顺序重排了一次。在场的所有人都惊呆了。

慢慢地，威廉·史密斯觉得自己的工具真的很有意义。他想帮绘制更个英美的地层图。但是，也没钱，也没有信用，谁能做这样伟大的事情，他就去说服帮助做这件事情。正当愁得没辙的时候，发生了一件有趣的事情。

# 利用新地图找到煤矿

当时正是工业革命刚刚开端，英国的资本对煤炭的需求变得很旺盛。英国要开工厂开机器，就要能源。所以，到处都有人在找煤矿、采煤矿。但是，这些英国老版只有钱，没什么知识，所以，开矿总是乱买一气。有一次，威廉·史密斯来到一个挖煤矿的地方，一看，说，‘你们这个挖的不对啊，这个地方地层不是没有煤层。’一开始矿老板不信他的，挖了好久，发现确实没有煤。他可想让威廉·史密斯，赶紧给他找煤矿。威廉·史密斯也有钱，一找准找煤矿。这个没什么人用的图，竟然被找煤矿了。威廉·史密斯的名声一下子就传开了。陆陆续续有很多采煤老板请他去找矿。这又来一年，他就有钱可以去更多的地方勘探了。
