因为，野生动物的生活环境跟咱们人类不一样，咱们要是觉得饿，家里又没有立即能吃的食物，可以到小卖部里给我买些吃的，或者干脆，可以叫个外卖来吃。野生动物呢，要是因为季节的原因吃不到食物了，那就只能吃自己提前收藏起的食物喽。

# 松鼠收集者——星鸦

会收集食物的可不是小松鼠，很多动物都是这样。咱们今天要说的这一种，是鸟类，名字叫北美星鸦。这个名字的意思是，它们是生活在北美的、身上有星星一样白色斑点的鸟。虽然叫北美星鸦，它身上却没有星星一样的斑点。为啥呢？因为星鸦这个学名来说的是生活在欧洲和亚洲的一种鸟，它的身上有很多星星一样的斑点，后来在美洲发现了星鸦的亲戚，所以就直接取名叫北美星鸦了，即便北美星鸦身上没有星星。

![](bbox=[0.05, 0.4, 0.95, 0.5])

北美星鸦还有一个外号，叫坚果钳子，也就是专门用来打开坚果的钳子。因为北美星鸦吃坚果了。北美星鸦最喜欢吃的坚果是松子。在它们生活的森林里，有许多高大的美国白松树。听到这个名字你应该就能猜到，这种松树一棵，它的树皮是白色的，不是跟星星一样，它是很白色的，所以非常好认。美国白松的种子里是夏天成熟，所以，北美星鸦来收集松子的工作，也是从这个季节开始的。

它们从一棵松树，跳到另一棵松树，然后检查每一棵松树。它们的嘴巴，非常的尖锐，像一把短刀一样，把松树撬开，然后把里面的松子给挖出来。它们这么做的效率非常高，有人统计过，只要一分钟的时间，一只北美星鸦就可以收集超过30颗松子。

用这么快的速度收集到松子，并不会马上被吃掉，而是收回来，作为粮食储备。噢，等一下，北美星鸦是鸟嘛，鸟又没有手，它们也不穿衣服，没办法把松子放在衣服口袋里，又没有随身袋儿，把松子放这里袋儿里。北美星鸦来采集松子的速度这么块，那么来吃了之后放哪儿呢，难道狼狽抓裤腰子一样，来一颗一颗吗？

哈哈，北美星鸦当然不会穿抓裤腰子，它们其实是把收集到的松子放在嘴里。在北美星鸦的舌头下，有一个很大的由皮肤构成的口袋，口袋伸缩性很好，可以放很多松子。每次在收集坚果的时候，北美星鸦总是把口袋塞得鼓鼓囊囊的。科学家对这个口袋进行过试验，他们惊讶地发现，那里能够放进差不多100颗松子。最厉害的北美星鸦甚至可以放上150颗、150颗啊，以后自己吃松子的时候可以尝试看看，150颗松子，堆在一起有多大。北美星鸦还真是厉害呀。

# 星鸦如何定位藏宝点

等到嘴里装满了松子，北美星鸦就要把仓库把松子藏好了。它们有时会在地上啄啊啄啊，啄出一个洞来，放上几颗松子进去，然后填回厚厚厚的落叶的地方，有时，会挖一块软瘦厚的泥土的地方，把几颗松子放在那层下；还有的时候嘛，会树上找个小合适小洞的地方，把几颗松子放在那个洞里面。每一处收藏地点，都只放三五颗松子。北美星鸦就这样，不停地收集松子，然后把它们藏起来。从炎热的夏天，一直持续到冬天，天气已经很冷，再也没找到松子了，经过了这么长时间的忙碌，每只北美星鸦都至少收集了五六十个松子小仓库，有些甚至可以有几十个小小仓库。

进入到12月份以后，树上的松子基本上已经被它们全都储存干净了。这个时候，北美星鸦要开始使用这些小小小仓库里的食物了。但是等一下，北美星鸦是鸟，一只鸟建了两成几十个小小仓库，又不可能靠记忆记住所有的仓库。那它怎么记得小小仓库在哪儿呢？

科学家早就注意到了这个问题。他们也很想知道北美星鸦是怎么做到的。很多科学家提出了自己的观点，有些人说，一定是它们定位了小小仓库附近的三个固定标识，比如说画面上石头、一个树桩、小灌木等等，然后分别记住这些石头、树桩、灌木距离小小仓库有多远，或者方位。通过这样的方法，北美星鸦就可以定位小小仓库的地点啦。

# 科学家跟星鸦开了个玩笑

当然，科学家总是要去验证自己的观点的。在上世纪90年代的时候，有个叫沃尔夫的鸟类学家，就去做了一件件事。他先观察北美星鸦储藏松子的地方，确定这些小小仓库地点。然后，等北美星鸦离开之后，挪动小小仓库附近的一些小石块。然后，在那里长期观察观察，看栖息地的北美星鸦是否能找回原来看的小仓库。果然！跟他原先猜测的一样，那些北美星鸦都回到同一个地点，找不着原先的仓库了。科学家这才终于确定，这种神奇的小鸟是在大脑里绘制藏宝图的方法。

但是问题又来了。北美星鸦一次性设置藏成功了小小仓库啊，也就是说，它实际上绘制了大大小小张藏宝图。它是怎么记住这些藏宝图的呢？嗯……这个问题就难住了，科学家到现在也在做没有明确结果的研究。科学家们发现更有意思的问题，也许，你长大了也会参与到这项探险工作之中呢。
