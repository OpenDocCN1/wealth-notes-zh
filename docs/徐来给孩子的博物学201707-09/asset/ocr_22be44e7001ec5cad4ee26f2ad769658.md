# 医学|人类|黑色水泵的秘密

世界大好，奇妙的事情每天都有，我们一起去发现吧！

在很多城市里，特别是有那些历史悠久的名城，大街小巷上都耸立着形态各异的名人雕像、纪念碑等建筑，来纪念那些发生在该地的一些伟大事情。

这个纪念碑，它是1859年，伦敦的一个医生，叫约翰·斯诺（John Snow）发现的。

当时，伦敦的霍乱非常严重。霍乱是一种肠道疾病，通过饮水传播。

约翰·斯诺当时怀疑霍乱是通过水源传播的。

他收集了大量数据，绘制了一张霍乱死亡率的地图。

![](bbox=[0.15, 0.315, 0.9, 0.42])

约翰·斯诺指出，霍乱的传染源是水泵。

他建议政府拆除水泵，并改善供水系统。

![](bbox=[0.15, 0.51, 0.9, 0.62])

他不仅是一个医生，还是一个优秀的科学家。

约翰·斯诺是流行病学之父。

![](bbox=[0.15, 0.7, 0.9, 0.8])

约翰·斯诺的研究为现代流行病学奠定了基础。

他的贡献改变了公共卫生观念。
