# 卫星·宇宙 | 太阳系最大的喷...

你一定见过喷泉吧？喷泉在现在这个时代，已经是一个司空见惯的东西了。城市的各个广场，都能听到各式各样的喷泉，或者直接花园的中心，小区的门口，或者花园的入口处，都装了喷泉。但是古代人就不太容易见到喷泉了，毕竟建造一座喷泉需要很多工程技术作为基础。

今天，咱们来说说喷泉到底可以有多大。

# 土卫二上有大喷泉

其实要想让喷泉喷得很高，是有点儿难度的。咱们人类建造的，能喷出最高水柱的喷泉是位于沙特阿拉伯的港口城市吉达。这座喷泉被称为法赫德国王喷泉，喷出的水柱超过300米。

除了人造的喷泉，自然界也会自然生成一些喷泉。在一些火山、地热资源丰富放电的地方，会出现间歇性的自然喷泉，间歇性喷泉的意思是，这些喷泉不是一直喷发，而是隔一段时间喷发一次。间歇性的自然喷泉是怎么形成的呢？其实是地下的热水把岩石和土壤中的水分加热到很高的温度，水分就蒸发，喷薄下降形成水，就会形成喷泉，喷出地面。

![](bbox=[0.19, 0.38, 0.81, 0.45])

在美国的黄石公园，有最著名的自然喷泉“老忠实”，它每隔数小时间隔都会固定地喷发，并且每次喷发的时间都差不多，所以叫“老忠实”。

![](bbox=[0.19, 0.48, 0.81, 0.55])

前段时间，我在新西兰的罗托鲁瓦火山区也欣赏了自然喷发的奇观，不得不说，这样的喷泉要比人造的喷泉好看得多。

![](bbox=[0.19, 0.57, 0.81, 0.64])

实际上，20世纪初期新发现了出现过一个巨大的间歇泉，喷射高度曾超过法赫德国王喷泉，可惜，那个间歇泉只喷了几年就停止喷发了。

不过，无论是人造的巨大喷泉，还是最雄伟的自然喷泉，都没有办法和太阳系里的另一种喷泉相提并论。它们在土星的一颗卫星上，这颗卫星叫“土卫二”。

# 高达几十公里的水柱

土卫二是很难被观测到，因为它个头实在太小了，而且离太阳的光环太近——它就出在土星最宽也是最稀疏的一条环E环之中，E是ABCDE 的土卫二恰好就在E环物质最密集也是最明亮的部分里，所以真是太难被观测到了。

后来，人类的探测器飞到土星，拍到了土卫二的近景照片。天文学家们看到照片后都被惊呆了。因为它的表面覆盖着厚厚的一层冰，是真正的冰，水凝结成的冰，而不是其他什么液体凝结成的。这使得土卫二的表面相对表面非常的光滑，呈现出一片白茫茫、滑溜溜的感觉——它也因此成为太阳系里最擅长反射光线的星球。

![](bbox=[0.19, 0.8, 0.81, 0.87])

不过，土卫二可不是完完全全的雪白的星球，在这颗卫星上，同样有颜色的变化，比如说，土卫二的南极地区，颜色就不太一样——会不会想到呢？土卫二也有南极吗？南极不是地球上的吗？不是，因为每颗星球，包括太阳在内，都在进行自转，就好像陀螺一样，只要自转，就一定围绕着一个轴转，科学家就把这个转轴的上面端作北极，下面端作南极了。所以，土卫二的两极地区，就存在自转轴的两端。

这个地区的颜色，没有那么白，而是略微发褐，甚至看起来带一点带褐黄色的颜色。科学家和岩石，很可能意味着这个地区的冰层里混合着其他物质。更重要的是，科学家在这个地区发现了很不寻常的活动，那就是一系列的间歇喷泉。

这些喷泉所喷时出来的东西，主要是水和水蒸气，其中也会夹杂着很多其他的物质，包括有机物。因为土卫二非常小，重力也极弱，所以这些喷泉可以喷得非常高，水蒸气轻而易举地可以喷射到几十公里的高空中，这是最为壮观壮观的场景之一，当你乘坐飞机从一个城市飞往另一个城市的时候，突然有一根水柱从洁白冰亮的表面中升起在自然的冰上出现的水柱，这一定是非常非常壮观吧？

# 喷泉孕育着生命

这喷泉不但非常美，而且非常的重要，因为这些喷泉喷出的东西实在飞得太高了，扩散得太远，甚至会再回到土卫二的表面，所以这喷泉对土卫二表面也有很大的影响。很多科学家认为，土卫二所在的土星E环，很可能就是由喷泉的。

接下来，科学家在对土卫二的观测中发现了很微弱的现象，这颗卫星在围着土星公转的过程中，出现了特别轻微的摆动。科学家对这种现象进行了深入研究，并得出了一个令人惊叹的结论：土卫二内部，也就是厚厚冰层之下，含有大量的液体。这些液体，受到惯性的影响，在轻微摆动时，考虑到土卫二里面薄薄的那层，水是流动性极强的，而喷射出来的物质，经过检测主要有：水分子。这么一来，答案就有一个了：在土卫二的表面之下，存在着海洋，而且是液态水形成的海洋。是的，科学家发现过，这个海洋是全球性的，你甚至可以说这是一个水冰世界。

![](bbox=[0.19, 1.0, 0.81, 0.0010500000000000002])

令人惊叹的还不止这一点。你看，我们现在正在知道，土卫二的冰壳子下面有厚厚的一层水。而且我们知道，热水一直接管。一个非常显著的是产生热量的。我们冬天洗很热的的洗，我们的大理石地板，双手很快就变得热乎乎的，对于它的情况也是一样，你把水注入水池里，然后抓着水去下加热，水中和物质发生核反应，一样会产生的热量。这个热量有可能来自土卫二的海洋内部，或者它深处的变化。所以，科学家现在已经知道，土卫二的海底有热泉涌液，热液喷发，就是非常热的水，从海底冒出来形成的。

我之前在专栏文章里，跟你讲过地球大底的那类生命，还记得吗？本文没有给你讲关于深海热泉的文章，那就去看那篇热泉文章，靠着热泉的能量能维维持独特的生态系统。这意味着，土卫二的内部很可能也存在着生命。抬起头，找找土星，或许我们就已经看到了太阳系内的同伴。
