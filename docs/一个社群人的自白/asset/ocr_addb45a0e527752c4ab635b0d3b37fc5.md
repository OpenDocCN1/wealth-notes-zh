# 十一、如何对待离开社群的人。

做社群，社群大了，需要用人，也需要开除一些人。有些人看似对社群有好处，其实是有坏处的；有些人看似对社群有坏处，其实是有好处的，我们得明辨是非，知道谁是乌合之众，知道谁是智力低下的人。我们也要知道谁是高智力的人，用高智力、真心为社群办事的人，开除、罢黜那些愚蠢、不为社群办事，或者好心办坏事的人。社群大了，需要正心正念，而且有智慧的人，没有智慧的人没什么用。

关于离开社群的人。所有人，我都希望他们过得好，但是不能伤害到社群的利益。如果这个人影响到留下的人的利益，就不是我要去管的问题了，就是大家都要去管的问题了。我们社群向来有道德优势，当然也有能力优势，但是不找事。但是有些人会故意找我们的事，或者是愚蠢，或者是故意使坏，或者是唯利是图，这些人用智力对付，用法律对付，用道德对付。
