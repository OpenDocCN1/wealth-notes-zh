## 5、经营社群需要哪几种人才

社群创始人的唯一目的，就是不断的打造人才团队、梯队。

社群的发展全靠人才，不同时期，需要不同的人才。人才有多少，社群就能发展多少，多安全。总来说，社群需要：

- 1、经济建设人才
- 2、管理人才
- 3、后勤服务人才
- 4、刚正不阿的人才
- 5、大道人才

各种人才，相互配合，相互支撑，相互说教，社群才能发展。
只有一种人才，就会出大事，就如人只有一个指头一样，指头要五个，而且要相互配合。最好有两只手、两只脚相互配合，这样机体才能发展好，社群里的人才也是如此。

经济建设人才，主要是建设经济，不断的为社群搞流量，搞变现，搞传播。

管理人才，是防止大家走偏，然后各方面相互调度。

后勤服务人才，这些人需要有奉献精神，不断的为社群做好各种后勤工作。

社群是一个庞大的体系，根本不是哪一个人、哪几个人就能干好的，是要各方面的力量集体配合，才能干好的。

刚正不阿的人才，也就是非常中正，这些人保证社群的正常运转，砍掉毒瘤，防止社群裂变空，被裂变成传销。

大道人才，这种人永远在牵引社群走在正确的道上，不偏离。

筛选人，比什么都重要。不要培养欺师灭祖的人，不要培养负债的、贫穷又不努力的人。只跟牛人在一起，只与厉害的角色在一起，也只吸收厉害的角色，只跟厉害的角色对话。不是厉害的角色，能拉黑就拉黑，别搭理他们，否则，他们没事做，还非常积极，成天浪费所有人的时间。

培养更多的团队长、企业家，跟着我们一起做读书会，培养更多有道德、有能力的人。严格筛选人。团队发展慢，发展的稳固就行，主要是要人才，主要是要有德行的人，主要是要真正的企业家，这样，这个团队培养起来，我们社群就能发展好。这个团队培养不起来，我们就不能大发展。

只找有企业家精神的人，加人自己的团队，常的就是企业家。这些企业家，跟着自己做事，跟着自己开发客户。企业家好管理，你一说，他就懂，他懂了，就跟着干，没有内耗。要我的是高人，高人相互配合，低端的人相互坑害，精神坑害、实际的金钱坑害，内耗相当严重。

我们为社群不断的找企业家，也不断的讲企业家精神，培养更多的企业家参与到社群营销这个游戏 Code 中来，参与到读书会中来，这个事业就能做得更大。我更多的是讲《陈昌文解读《论语》》，依托这个去做我们的品牌营销，吸引更多的企业家到我们这个圈子里来。带领一群企业家去做社群、来裂变社群，就能更好的做这个社群了。社群创始人，不能只看钱，要看整个社群的组织架构，把整个社群的组织架构做好了，业务自然就多了。

### 十、社群只培养、重用贴心可靠的人。

社群团队需要严苛的领头人，越严苛越好。标准越高，牛人越多，我们的单就越多。我要的是核心的、贴心的、真正善良的、愿意做事的人跟着我们社群做事。社群的讲师必须是可靠的人，不可靠的人不应该发言。

社群只培养贴心的人，只培养真正愿意为社群付出的人，只培养尊师重道的人，只培养真正善良的人。有二心的、心怀鬼胎的，要边缘化，要撵走。社群创始人 的心血，只付出给对的人，否则对社群就是灾难，对社群所有人的发展也是灾难。社群必须挖据德才兼备的人出来演讲。德行、才能不行的人，必须干掉，不能让他跟随着我们发展，避免给我们添麻烦。

要严格管控每一个讲师，每一个管理层。不合格的人，必须下掉，对德行不行的人，对人品不行的、对业务能力不行的，必须予下掉。否则，社群绝对没有发展。

必须有可靠、聪明、智慧的人，有胆魄的人来经营社群。也就是做社群，要找到可靠、靠谱的人跟随。这人有才华，有能力，但是不可靠，就不能被重用。可靠，是非常、非常、非常重要 的特质。不可靠的人，一定不能重用，不能委以重任，更不能给予光环。在可靠的前提下，才考核其能力、才华、本事。

道德是可靠的核心。这个人不道德，更不能委以重任，否则会引导整个社群走偏，给社群带来违法风险。不可靠的人，他的光环越大，权利越大，财富越多，对社群的危害越大。社群必须在安全的情况下运行，少赚钱都关系，要的是安全、长久。所以，对管理层，对人的考核必须越来越严格。社群越大，则需要对人才的考核越严格。所以我们社群现在审核核心的身份证、自愿申请书，以及资产证明，拒绝那些不合格的人加入社群。不合格的人，说不定就会给社群带来灾难了。

### 十一、如何对待离开社群的人。

做社群，社群大了，需要用人，也需要开除一些人。有些人看似对社群有好处，其实是有坏处的；有些人看似对社群有坏处，其实是有好处的，我们得明辨是非，知道谁是乌合之众，知道谁是智力低下的人。我们也要知道谁是高智力的人，用高智力、真心为社群办事的人，开除、罢黜那些愚蠢、不为社群办事，或者好心办坏事的人。社群大了，需要正心正念，而且有智慧的人，没有智慧的人没什么用。

关于离开社群的人。所有人，我都希望他们过得好，但是不能伤害到社群的利益。如果这个人影响到留下的人的利益，就不是我要去管的问题了，就是大家都要去管的问题了。我们社群向来有道德优势，当然也有能力优势，但是不找事。但是有些人会故意找我们的事，或者是愚蠢，或者是故意使坏，或者是唯利是图，这些人用智力对付，用法律对付，用道德对付。

我经营社群，是要带着相信我的人、人格高尚的人传播儒家思想＋陈昌文方法。如果我调教出来的人不合格，也就是我不合格；如果我们收进来的人不合格，也就是我不合格。不合糟的人，会受到对应的制裁。为了避免冲突，所以我们要不断的做筛选，这样，我们就能筛选到更多合群的人来到我们社群。我们培养出来的人，也就更合群，避免精力浪费。

### 十二、做社群，重要的是做规模建设。

社群要做好，就是不断培养优秀的、德才兼备的讲师。我的任务，就是呕心沥血的培养讲师，鼓励更多的人成为讲师。《讲师宝典系列》《72大营销系统》《恋爱宝典系列》都是用来培养讲师的。想做讲师的，很多都是老板，有能力的人。我们要吸引大量有能力的人参与到社群讲课，把内部、外部课程讲好。

做社群，重要的是规模。也就是要更多的人来矩阵，要更多的人来讲课，要更多的优秀人才，要不断的筛选德才兼备的人来社群。不要只为了赚钱，而要设定好框架。比如，只要富人、牛人、美女老板，设定好关键词不变，这样沟通效率高，成本低，这些就是框架。只为了赚钱的社群自然走不远。
