# 二、经营社群，就是经营大型团队。

团队是社群的根本，做社群必须做团队，而且是大型团队。

大型团队，首先要注意的是法律问题、道德问题、税务问题、培训问题，这几个问题都必须是创始人亲自管理。

做大型团队的核心是，帮助跟随自己的人发财，也就是真正想努力的人，你得让他们变成企业家，变成拥有自己团队的人。

我们必须从法律、道德、税务、培训等多个方面对各位代理人进行强力管控。因为有些人智慧不够，所以我们要帮助他们成为企业家。当社群里的很多人都成为企业家的时候，社群也就自然发展好了。

所有东西，有文件进行管控，具有法律效益，当然，最重要的是整体的品牌牵控。只有在拥有一个共同的、强大的品牌的情况下，我们的利润才会翻倍式增长。

# 三、做社群，就是做人才战略。

我的主要工作，是选拔人才，组织人才，使用人才，开除劣迹斑斑的人。我的主要工作，是团结人才，招聘人才。我的主要工作，是优秀内核，内部一定要有铁杆、优秀的人才跟着我做事。我的主要任务是去除偷奸耍滑、故意滑头，表面对我尊重、对社群尊重，实际上做事非常离谱，说一套做一套的人。
