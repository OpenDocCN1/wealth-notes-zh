# 11、我为什么做社群经济

社群是弱关系，也可以是个生意，也可以是个企业。社群模式，可以解决一切问题。社群什么都可以解决，商业上的、团队上的，都可以解决。我就喜欢社群模式。

我们社群是什么模式？就是纯粹的真诚，真正的去帮助客户，帮助每个粉丝的心。如此模式，干啥生意都能干好。对我来讲，我根木不是在做生意，我是要经营一掌子的人心。我经营粉丝的心，让他们真正懂得虔诚感恩，尊师重道，学习儒家思想，学习并且实践陈昌文方法。厚德载物，所有人想要真正成功，就要进德修业，进德是第一步。

社群管理的本质，就是用一颗真心去管理所有内部、外部粉丝，一切求真。通过书籍、讲课、朋友圈、36广告循环系统，对整个社群的所有人进行管理。每个社群成员本质上都是社群
