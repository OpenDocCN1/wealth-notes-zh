这个世界上，是有很多知识的，然而，有的知识对我们现在来讲，是没有意义的，我们就不学它，我们只学现在对我们有用的知识。头脑接受的信息并不是越多越好，要注意自己接受的信息，有些信息是无用的。一个 人接受的无用信息多了，这个人就会变成无用的人。

老板、企业家，只接受跟自己业务有关系的信息，如此，才是高人。

# 四、不断的提升自己的内心修为。

要不断的提升自己的内心修为，所以，打坐参禅，是非常重要的。内心要足够宁静，才能活好。内心足够强大，修为足够高，才能在大众面前游， 否则，你是混不了的。

心乱，则文字乱，思想乱，社群乱。心乱则什么都乱。竞争主要是安心，心安，外面打外面 的仗，内心是安定的。如果 搅乱了本性、本心，打仗就没有意义了。

真正的牛人，干啥都是快乐的、舒服的、舒畅的，心里是顺畅的。真正的高人、好人，一切都是快乐的，看透一切，看淡一切，做事毫不费力的走在道上，都是对的。顺天应人，无病无痛，其乐无比，优哉游哉。
