# 六、我写书的目的。

我做社群，全靠写作，写书、写文章。我写所有书籍的目的是为了教会大家做营销，做团队，做管理，增加大家的领导力。这是一个基础，也就是有了这些书籍，我们做微书就会做盈利了，而且讲师知道自己讲什么，讲出来有干货。写作、讲课，一定只讲干货，也就是粉丝百分百能得利的，这样就有了精准粉丝，有了精准粉丝一直跟随我们，我们就能很好的运营好我们的社群。

其实营销就是陪伴，不断的陪伴这些粉丝，用视频、文字、直播不断的陪伴、介绍。抄袭我的文字，让他们看就就行了。这样天天看，他们就沐浴在我们的营销环境中，实际上是个借力营销，也是个海陆空的营销。这样，社群的单子就会变多。
