# 四、复制

社群要发展好，一定要模板化。

服装搭配、说话的语言系统、直播间、视频里的风格，都可以模板化。如何做火视频、直播间，就是复制别人已经爆粉的视频、直播。

在我们这个圈子里、我们的书籍里，找到正能量的视频、直播去复制，主要是书籍里的文案、爆粉的文案，爆粉了，模板化，立刻让所有人复制、抄袭。粉丝不爆没有意义。

做社群营销，一切必须追求极其简单、白痴、傻瓜式，也就是傻子都会干，就能赚钱。
