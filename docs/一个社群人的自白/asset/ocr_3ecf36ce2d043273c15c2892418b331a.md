# 2、我为什么能把一个社群经营起来

我为什么能把一个社群经营起来？告诉你们，我一工作就开心、兴奋。我早上起来，第一件事就是工作、工作，还是工作。

我也不知道为什么，我就是喜欢工作，特别兴奋。稿文章、传播、维护社群、维护运营、思考前进、营销模式升级、理念升级、增大升级，这些都让我特别兴奋。我也不知道为什么，就是发自内心的兴奋。

从 2015 年 3 月开始，我是如何策划做这个社群的？

我做这个社群，是我的第一次创业。我开始只带了 3 个人，这 3 个人陪着我度过了初期的困难时光，后来，他们去打游戏了，没怎么努力，混日子去了。后来又发展了 2 个小伙子，这 2 个小伙子是之前 3 个小伙子当中一个小伙子的同学，他们找不到工作，到我这，我让他们见识了什么叫做日入一万，也就花了不到一个月的时间，然后，他们迅速的背叛了我，开始玩自
