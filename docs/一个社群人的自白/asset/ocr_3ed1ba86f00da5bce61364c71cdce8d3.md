对接自己企业的好产品，大概能赚多少钱？我也不知道。

社群发展到 2018 年，我们就开始进入抖音平台了，世界来到了短视频、直播时代。在这个时代，我们的利润更好了，发展更快了。其实我有很多社群，几十个吧，微信、QQ 里都有，只是有些社群不经营了。唯独经营下去的，以后就是这个陈昌文老板社群 + 读书会，服务美女老板这个路子。

更多猛料，我都会爆出来，但愿你们能在我这些猛料中，找到利润点、变现点。

# 3、为什么很多人做社群做不起来

想要做好一个社群，需要一直做下去，也就是你不能做几天，就说不做了。你不能看到其他生意好，又去干其他生意了。社群这个生意，是非常好的，我是卖品牌，卖读书会，卖老板社群的，当然，也可以做产品社群。只是我不喜欢卖具体的产品，你们喜欢，也可以去做，只要利润高就行了。
