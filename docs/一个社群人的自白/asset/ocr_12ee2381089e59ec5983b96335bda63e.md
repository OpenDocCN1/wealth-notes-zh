# 2、道德共同体

维护社群，必须进入法律共同体阶段。社群里的人、社群里的讲师，要做到令行禁止的阶段，由彻底愿意跟着社群，跟着我的人管理、统一安排。

# 8、为什么社群要隔离有欺师灭祖行为的人

组织里，只能有正能量的人。负能量的人、心怀鬼胎的人，一定要开除掉，否则，就如同浓疮一样，会波及更多的人。每个老师、每个发言人都必须真心的正，有道德。这个发言人，心术不正，一定要去除，否则，贻害无穷。
