# 有敏锐度的企业家
都应该实践社群营销

我的目的，是写一本如何做社群的书籍。企业家可以看，老板可以看，他们看懂了，从我做社群的实践经验中，去经营他们自己的公司、他们自己的社群。我可以成为社群顾问、专家，也打算培养一些社群顾问、专家级讲师去讲如何做社群。

我写作《陈昌文方法之一个社群人的自白》（以下简称《一个社群人的自白》），就是彻底介绍我做社群的经验，也是为了传播陈昌文读书书会、老板社群。很多企业家、老板都需要学习做社群的经验。

我本身是个案例，我们的陈昌文读书书会、老板社群也是一个案例。我写我做社群的实践经验，呕心沥血的写真实的操作手法，《一个社群人的自白》这本书，又会解决很多就业问题。这本书，还会创造很多千万富翁、亿万富翁，因为他们拿着这
本节，就可以变成社群营销专家、社群营销导师、社群营销讲师。

我本身是一个社群人，我当然是非常有资格介绍我做社群的经验的，这些都是我真金白银的经验。这本书总结了做社群营销的方方面面，它就是《一个社群人的自白》。

《一个社群人的自白》主要写我是如何做社群的？我是如何看待社群人的？我是如何运用儒家思想和陈昌文方法完成一个社群经营理论体系的？使用这本书，你可以运用于自己的企业中，与时俱进，提升企业在移动互联网时代的实力和竞争力；你也可以成为一名专业培养社群营销的专家、讲师、人才，搞社群培训、咨询服务。

一个会社群营销的人，一定可以改变自己的命运。一个会社群营销的企业家，一定可以让企业在移动互联网时代、短视频时代获取成功。不会的，可能就享受到社群营销的巨大红利。有敏锐度的企业家都应该实践社群营销。社群营销是当下最凶猛的营销，没有之一。

——陈昌文
2021.1.28

# 1、我为什么要写作《一个社群人的自白》这本书

我为什么要写作《一个社群人的自白》这本书？为了给企业家、老板一个做社群的实践理论依据，目的是教会企业家做社群营销，教会美女老板做社群营销。也就是说这本书，完全是为了让所有想做社群营销的人，来借鉴我做社群营销的思路。

按照我这本教科书，去做自己的社群。

我为什么要写作《一个社群人的自白》这本书？

做为影响力、品牌广告传播，介绍我们社群；卖给企业家、老板这些有公司的人，他们都需要学习社群运营，学会了，公司就会经营得风生水起；培养社群里的社群顾问、专家、讲师，也就是说，讲师们可以专业收企业家、美女老板到老板社群，做他们的社群运营顾问。这将是一个非常厉害的利润点，一个非常厉害的职业，利润会非常丰厚。而我写作的《一个社群人的自白》就是介绍我做社群六年来的核心心法。

《一个社群人的自白》就是写我做社群的思路、行为，写我做社群的核心理念，就是写给企业家、美女老板、牛人看的。我写作《一个社群人的自白》，是把我们社群当案例，企业家、老板们看了，也会做社群了，至少有了理论依据，可以依照我们社群，去建立自己的社群营销体系。不过，能不能做起来，看造化。这就是企业家读《一个社群人的自白》的目的。

我本人是专业做社群营销的，这本书是我做社群的实践经验、心得体会，一个运营数万人社群的真实经验。这些经验是教科书式的经验，很值钱，看懂的人，自然能经营好一个社群。很多人都会因为这本书，认识社群营销，而且去从事社群营销这个工作。所以这本书，既有指导企业家做社群营销的意义，也有宣传我本人、陈昌文读书会和老板社群的意义，让更多的企业家知道我们，最终找我们社群付费学习社群营销，进入陈昌文读书会和老板社群，看我们是怎样运作数万人社群的。

企业家、老板，在当今互联网时代，无论是卖知识、服务，还是卖产品，都需要运营社群。社群的运营，会让很多人成为你的传播者、铁粉，还有代理，以及产品的购买者。

同时，我们可以接触到更高级的企业家，这些人在跟着我们学习、交流的过程中，也可以促进我们更优秀。我可以把我们社群的运营模式介绍给所有的企业家，让这些企业家从我们社群运营的过程中，学习一下，借鉴一下，这就是我们对这些企业家的贡献。

我写作《一个社群人的自白》也是为了搭建企业家圈子，我个人也非常需要很多企业家，他们的思想能力对我也有好处。《一个社群人的自白》，其目的也是为了撬动整个企业家社群圈子。

企业家思维、真正的企业家、教你赚钱的人，能瞬间让你的赚钱能力提升几百倍、几千倍，只是一般人接触不到这种企业家，也没人调度。也就是说社会上大多数人，都可以变得很厉害，但是没有这些智慧思维的培养，他们就成了普通人，一辈子碌碌无为。

要学习顶级企业家思维、企业运营模式，跟企业家交流，才能变得更厉害，所以，要做企业家社群运营咨询。

《一个社群人的自白》既是写给企业家的，也是建立企业家社群交流圈子的。

我也可以接一些企业家咨询的单子，这样可以让我们成长得更快。但从社群经营的角度来讲，我们做好陈某文读书会、陈昌文老被社群，做好团队代理制度，已经拥有巨大的利益了，不太需要再开发一个咨询业务。我们的每一本书，都是一个读书会，也都是一个直播卖点、视频卖点。但也要服务更多更加优秀的人，否则，我们社群就会倒退，我个人的思维能力也会倒退。人的成长，全靠接触到更多优秀的人的思维。

《一个社群人的自白》要收到全中国的企业家，我们要成为社群营销领域的领袖，也就是，做社群将是一个行业培训，就如广告业一样，是一个行业，而社群营销、社群培训、社群咨询、社群讲师，是一个行业。我们的目的是开创一个行业，就如广告业一样，以后，我们的业，叫做社群业，专业经营社群咨询、培训、讲座。

我带着大家做社群营销的学术性研究，社群营销、新媒体营销、品牌营销、企业营销、企业家营销、思想营销和传播。我写著《一个社群人的自白》，这本书会通过视频、直播，传播给很多人，很多人都知道有这样一本书，专门写社群的，是一个社群运营的实践者写的书。

我写作的目的，也是为了自己成长，让跟著我的人成长。我讲课的目的，也是为了自己成长，让跟著我的人成长。价值、钱，来源于疯狂的售卖，所有人把我的文字变成视频、直播，卖陈昌文读书会，陈昌文老师被社群，利润就起来了。

我们是卖圈子的，这是利润的来源。

我写作的唯一目的，是提升自己。第二目的，是带着大家赚钱。我讲课的唯一目的，是倒逼自己前进，第二，顺手工作，是带着大家做试量和变现，所以，我要写《一个社群人的自白》。我开公司、运作资本、人脉的目的，是绑架自己前进，让更优秀的人，绑架我前进。被天道、《黄帝内经》绑架，这是我努力的方向。

大概很多年后，我或许会写《一个企业家的自白》《一个资本家的自白》《一个智本家的自白》，不过那已经很没意思了，因为已经到了布道层面。

现在我写《一个社群人的自白》，还在赚钱、传播阶段，是有广告目的、功利目的、招揽客户的目的，也是为了品牌营销，陈昌文老师被社群、陈昌文读书会的营销。

# 2、我为什么能把一个社群经营起来

我为什么能把一个社群经营起来？告诉你们，我一工作就开心、兴奋。我早上起来，第一件事就是工作、工作，还是工作。

我也不知道为什么，我就是喜欢工作，特别兴奋。稿文章、传播、维护社群、维护运营、思考前进、营销模式升级、理念升级、增大升级，这些都让我特别兴奋。我也不知道为什么，就是发自内心的兴奋。

从 2015 年 3 月开始，我是如何策划做这个社群的？

我做这个社群，是我的第一次创业。我开始只带了 3 个人，这 3 个人陪着我度过了初期的困难时光，后来，他们去打游戏了，没怎么努力，混日子去了。后来又发展了 2 个小伙子，这 2 个小伙子是之前 3 个小伙子当中一个小伙子的同学，他们找不到工作，到我这，我让他们见识了什么叫做日入一万，也就花了不到一个月的时间，然后，他们迅速的背叛了我，开始玩自己的套路，我就迅速的让他们离开了我的视野。几年过去了，我们没有联系过，再也没有见过面。

我经常想起跟我第一次创业的一个小伙子，跟这个社群营销无关的那个小伙子。他吃我的，住我的，买了零食藏在枕头下面不给我吃，脾气大，还非常倔气。我白天想办法做业绩，我去修过电脑，也去发过传单，还想着做恋爱方面的培训。他呢，他不愿意跟着我吃苦，他就去肯德基打工，然后又很恨我无能。

那个时候我比较单纯，对这些没有血缘关系的陌生人也很好，还借钱给他，那个时候我家里也没有什么钱。

我们社群的第一个单子，是在贴吧里出的。这个单子不是我出的，是一个姓孙的小伙子出的，第一单是 898 元的客单价，他高兴得从电脑旁跳了起来，冲到我家里来汇报，他说，啊，我出单了。

第二单是我出的，298 元，我忘记了是当天出的，还是第二天出的。还是第三天出的。后来，这个小伙子回去考察了，他带来2个同学，就是我说的背叛了我的那两个小伙子，还没学会爬，就想飞了，人心不足啊。要是他们素质好，一直跟着我做，现在想必也能过上幸福的日子了吧。

没错，这个很聪明的小伙子，当时还在读书，他只是实习的时候碰到了我，被我忽悠开始创业了。他开始了他的传奇人生，只是太短暂了，因为他太喜欢睡觉，太喜欢打游戏。他16岁，就做到了日收入一万。再重复一次，可惜，他就是太喜欢睡觉，太喜欢打游戏。我对那2个背叛我的同学也说了，创业不允许打游戏。

等我手里已经有了几百万现金，我觉得不能再在这个没有空调的出租屋里工作的时候，我带著另外两个 missed 人去搞办公室，租赁了一个甲级写字楼。我想大干一番。我们折腾了一天，回去了，一开门，发现那两个家伙在打游戏。我很生气，但没说什么，从此，我理解了，规则对某些人是没用的，他们就是不听话。

我见过很多做社群的人，太多了，他们都坚持不下去，一个群做几个月就死了。我做社群，活跃6年整，而且会活跃一辈子。我跟他们的区别在什么地方？我坚持每天有几篇文章，几千字、几万字的输出。我能长期坚持做一件事，日日写作几千字、几万字，写几篇文章。我发微博，有时候一天能发上百个，都是原创。我一直做社群，无论其他地方有什么诱惑，我就是做社群。碰到任何困难，我都不放弃。即便是走偏了，去做其它的了，很快我就放弃，马上又来做社群。

刚开始的 3 年期间，我日日讲课，一日不间断。每天晚上 7 点，一定讲课一小时，甚至三小时，搬办公桌也讲课。我的很多朋友都去玩游戏、泡妞了，我还是坚持日日循环写文章，搞段子，讲课，帮助大家搞流量、弄单子。我呕心沥血地帮助所有人，把所有人当儿子一样的教育。

我有个分钱，大部分钱都让大家拿，我只拿少部分，真心实意地为社群成员、为讲师团队付出。

我自己也有一定水平，不可否认。我阅读了很多营销书籍，古今中外大师的书籍，商业、企业管理的书籍，我自己也有做企业的经验。然后，我又熟读很多古圣先贤的经典，儒释道都有涉猎，这对开阔我的胸襟十分别有好处。我日日不断地传播陈昌文老师板块群的理念，日日不断地带着大家讲课。我的目的就是做好一个社群。

干了 3 年，我们就有了更多的讲师。这些讲师都很优秀，有的离开了，有的还在奋斗，当然，也不是都很优秀，说都很优秀，是给某些人面子。我群策群力，团结大家一起做事。我不搞一个人的战斗，我不孤独，德不孤，必有邻。

我把社群当成终身事业来做，我能容人，就算这个家伙让我很不爽，甚至有明显的错误（因为他的认知能力、经历不够，会犯错），我也能够容忍他们。我继续奋斗，我知道人都不完美。

我非常善良，只做好事，诸恶莫作，众善奉行。我心软，我希望别人好，我经常会遇到一个骗子、垃圾人、骗我，我看他可怜，也会给点。做社群营销，我就见过很多人，当然，也碰见过一些鬼，有些人希望我垮掉，希望我坐牢，希望我被整，希望我坚持不下去，抱歉，没能如他们的愿望。

我讲儒家思想，用儒家思想、王道思想，不断的匡正社群。我激情澎湃，我也不知道为什么，我就是非常疯狂的工作。今日，我生活非常有规律，能够做到早起早睡，锻炼身体，身心发展得越来越健康。我正在拥有我能拥有的，我的日子越来越好，效率越来越高，我更能经营好一个社群了。

我为什么做起来了这个社群？因为我只做这件事。我没有其他想法，虽然我也带着团队做过卖壳、卖过佛牌、卖过书籍资料，但是最终我都放弃了，还是如既往的做社群营销，这是我的天命。我很单纯，虽然有很多赚钱的门道，我也不想，就做这个。我从一而终，选好一个事业，就一宜千。于是，我就能做好一个社群。

我喜欢儒家思想，确切的说我喜欢国学，然后又研究营销，现在又在不断的出书，这个模式很好，我会一直干下去。我不想打工，我只想拥有一份自己的事业，所以我选择了做社群，也算误打误撞吧。

做陈昌文老师社群的时候，我本来只想赚点小钱，比打工强点就行，但是我一直在做这个社群，后来收入越来越高，到现在，居然要逼着我做到企业家这个位置。也就是说我得带出来更多的企业家，而陈昌文读书会就是裂变、培养企业家的项目。

社群现在最对的一步棋，就是有了系列书籍，做读书会。大家卖起来轻松，单子变多，影响力变大。社群现在最正确的路子是，有了这些系列书籍，里面有很多正确的理论，我们开始用真理、理论、原则讲课，武装自己，这样，我们讲课的质量非常高了，自然就有了前途。

到现在，我们社群主要传播的是儒家思想、陈昌文方法。儒家思想，这个是三观，是必须不断的传播的，这样才能让社群变得更厚；陈昌文方法，主要是72大营销系统，这是每个企业家都要学的。我知道营销有个4p理论，但是都去学这个，好像很多人不知道如何落地，所以我泛泛而谈，写了《陈昌文方法72大营销系统》，主要是帮助一些企业家、一些老板，拿来就可以用，马上可以直接落地的实操工具，可以说是企业家营销的应用，也是做企业、卖产品的应用。

做《陈昌文解读《论语》》这个读书会，其实是解决安全体系的，也就是法律风险、道德风险的防火墙，然后又能建立一个经济体系，这样我们社群才能长治久安做下去。做《陈昌文解读《论语》》，是要全员参与的，也就是陈昌文老板社群的所有人都必须有一个《陈昌文解读《论语》》账号，然后每日微视频、直播，然后驱动所有读书会的成员，都做《陈昌文解读《论语》》的主播，吸粉传播。这两股力量都用好了，我们的社群就能发展好，传播力、品牌影响力都会起来。我们要培养更多的 u 播主通过解读《陈昌文解读《论语》》获利，这样，社群就会更稳固。
