# 2、我的无形资产

人与人之间的差距，就是智谋、思维的差距。社群运营，全靠智谋、思维。不同的时间利用，有不同的效率，社群运作靠的是思维，并有鉴力。企业家思维能让人赚钱，企业家思维，一个变化就能变化出来很多钱。我们要的是无形资产驾驭有形资产，企业家的本事是拥有强大的无形资产。

交往企业家有好处，他的一个思维就能让你发家致富。人最厉害的是碰到牛人，跟着牛人学习思维。低层次的人，他们的思维没有价值，人生就没有什么价值。

我以前跟一个经理混，有大几万的提成被他扣了。后来，他给了我2000块解决了这段孽缘。其实任何人都有很多机会发达，可惜他们对他们的贵人如此狠毒。
