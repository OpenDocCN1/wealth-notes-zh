# 5、什么是高级感精神溢价营销

做社群营销，一定要营销高端客户。
高端客户，一定要有高级感。所谓高级感，就是这个品牌链接的都是高端人士、高智力人士、不缺钱的人，是社会上层的人才加入这个圈子，必须是行业上层人士。

比如，我们做美女老板这个圈子，就是全中国上层成功的美女，才加入陈昌文读书会、陈昌文老板社群。全中国上层女人、智慧女人、高级女人，才来阅读陈昌文的书籍，这就是做高级感营销，这与品牌营销是链接起来的，这是品牌的定位。

这种营销方法，叫做溢价营销、精神溢价营销，是奢侈品行业采取的模式，也是苹果手机采取的模式。陈昌文老板社群、读书会，以及书籍，都采取这种语言系统。品牌是卖给富人，卖给智慧的人，卖给社会上层的人的。

要告诉粉丝，读陈昌文的书是一件高级的事情、自豪的事情。
