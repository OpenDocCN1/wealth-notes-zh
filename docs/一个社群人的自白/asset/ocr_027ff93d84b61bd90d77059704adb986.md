# 3、为什么说社群经营是
社群管理者内心世界的体现

社群要经营好，首先要讲师团队厉害，首先要不断的提拔人才，首先要有固定的、德行高的人才在管理整个讲师团，然后，要客串讲师，也就是优秀的人、有特长的人，都应该到内部不固定时间分享经验。

我写了《陈昌文方法之讲师宝典系列》，我的目的就是要不断的培养讲师。讲师讲课，讲我自己书籍里的内容。我们的书籍，就是我们的方向、我们的内容、我们的教科书。

大量收陈昌文读书会的会员，这个收多了，就会有高端人士、成功老板跟着我们做讲师。他们写自愿申请书，交身份证复印件、资产证明，到我们的陈昌文老板社群，跟着我们一起做讲师。这样，我们社群就能滚滚式发展，发展的越来越好，参与读书会项目的人，利润也会越来越多。
