# 三、不耻商投资大脑。

高手对投资学习不恐惧，高手知道投资学习是应该的，是必须的，只有这样才会成长。普通人则不然，他们害怕投资血本无归，他们害怕学了也没什么用。

穷人的思维模式是固化的，久而久之，就是阶层固化，甚至堕落。富人的思维模式是我要学习，我要改变，我愿意投资，我要思考，我要想问题，我要老老实实拜师学习新东西。

会用钱的人，就是聪明人。能把钱变成更多的钱、更大影响力的人，就是聪明人。聪明人投资学习，不断进步，提升自己的社会阶层。傻子、笨蛋，拿着钱，也不知道该干啥，不理解投资自己的大脑是最重要的。

人最恐怖的，就是思想被玷污。

+   1、看黄赌毒。\n2、头脑里游离一些萎靡的东西。

聪明的人怎么办？

+   1、加入高端的圈子。\n2、跟着优秀的人学习思想，学习方法论。\n3、直接勤奋干活，赚钱。
