# 做社群，最重要的是正义、正气，也要社群创始人、管理层杀伐果断。

社群里的所有人、社群的讲师，必须是真正的在传道，传播正确的、正义的东西。社群里的讲师必须是真正虔诚感恩的人，否则，就会给社群、给所有人造成一个非常可怕、破坏性的影响，导致社群发展awa减速，人才凋零。

社群里的人，必须对社群创始人的理念、思想理解透彻，执行透彻，严格按照社群创始人的发心、发愿来做这个社群。社群里的人不能有二心，有了二心，社群也难以发展好。两面三刀的小人、表里不一的小人，说一套、做一套的小人多了，社群就会倒闭，没办法发展。社群创始人的内心软弱，就会导致社群发展偏离正道。
