# 2、如何打造社群品牌才能赚钱

做一个社群，只卖品牌，其他什么都不做，这是最高深的赚钱方法、销售方法。

投资一个词语，比如陈昌文方法，这样所有人都会去搜索陈昌文方法，而陈昌文方法下面有多少本书，多少个读书会，大家会去了解，但是都被囊括进了“陈昌文方法”这个品牌之下。这样，我们发的每一视频、每一篇文章，实际上都是在卖陈昌文方法，这样，这个品牌名字的能量大了，传播力度广了，贴现能力就越来越强了。

我们卖的是品牌，品牌营销要真实。卖品牌，做品牌营销，做链接式营销，要链接到“陈昌文”这个品牌身上，大家才赚得到钱。所有人都在做品牌营销，靠品牌赚钱，直接靠品牌变现，直接在书籍里、我的课程里找干货。我内部发布的文字，都要讲出去。
