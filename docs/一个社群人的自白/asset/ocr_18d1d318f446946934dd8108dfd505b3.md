# 四、锻炼身体。

如果长时间不锻炼身体，身体就会垮掉，精力不足，赚钱速度就会下降。

关注不了自己身体健康、心理健康的人，事业也不会健康。人有脑力劳动，也必须有体力劳动，把体力劳动当成自己的娱乐，而不是对人的要求。人比的就是健康，没有健康，什么都没了。一个有人钱，没有健康，也没什么了不起的。

陈昌文方法的养神系统的第一招，就是早起早睡，然后每日散步，锻炼身体。戒色是可以让人精力神增多的游戏。

人最重要的是早起早睡，锻炼身体，团队强大，无力而治，这样是最好的，除此之外，就不是最好的。照顾好自己，这个最重要，其他事情都没这么重要，然后跟着赚钱点，就这点事情，其他事情没这这两件事重要。

身体不行，就赚不到钱。所以，高手一定要保护好自己的身体，不搭理任何人。

人的精力不到位，就会出现什么也干不好的情况，所以，人一定要提升自己的精力，一定要早起早睡，锻炼身体，一定Val要保养好自己，才能战斗，否则没有战斗的意义，干啥都干不好。文案、收钱、讲课，都做不好，没有未来。人要健康的工作，我也要参与社会，参与交流，参与运动。
