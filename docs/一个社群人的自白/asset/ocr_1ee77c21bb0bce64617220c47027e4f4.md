# 7、我是怎样建立社群规则的

社群里每个人都有每个人的想法，这个人认为这样做好，那个人认为那样做好。人都有偏见。错误的项目、错误的人，就是浪费时间。每个人都希望按照他的想法发展，我的目的是找到最理性的那条路去做。

商业上的失败是不可救药的，也就是必须每一步都彻底的正确。做组织、做社群，不是一直相信、跟随我们的人，我们都不要，这些人没有任何价值。也就是说，要的是真正的好人，要的是真正的跟随者。不是真正跟随的人，我们都不应该花费精力去培养。普通人 不应该在社群内部发言，这些人愚蠢，也不会真心跟随，他们看看就行。社群核心要的是骨干，要的是真正的好人。

社群是规则领导、原则领导，社群只讲事实、理性，不讲
