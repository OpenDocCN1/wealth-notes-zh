# 后记

我们社群的书籍，每一套都是一个方面的教程。

《一个社群人的自白》，这就是社群运营的领导者书籍，也就是通过这套书，我们可以教会企业家学会社群运营。这本书，就代表着我们是行业标杆。

《一个社群人的自白》这本书的使命与目的，就是成为社群行业的培训者、领导者。也就是这个企业家要做一个社群，要用社群来运营客户、公司、代理商、粉丝，向我们学习就行了。

《一个社群人的自白》这本书非常重要，会因为这本书，以及我们整个书籍体系，立项社群营销咨询，成为这个时代的企业全案咨询。社群营销，分为品牌建立、项目运营、推广团队、盈利方案，这些东西都是为年入过亿的企业家老板、大富豪服务的。一个厉害的企业家想要建立起来自自己的社群营销模式，就需要找到我们取经、学习。
