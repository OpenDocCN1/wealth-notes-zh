# 4、关于自我反思

人从成功的地方，学不到东西。失败的案例，才能学到东西，才会反思。反思自己，出自己的策略，这是老板们要执行的。也就是，圣人要微群社疏，不能让肿瘤长大。反思自己，才能受到教益；指责别人，就会让自己荒唐，而且没有进步。

人的前进，源自于找自己的毛病，源自于反思。没有任何人对不起我们，是我们自己的思维、策略、做法出了问题。我们打造自己的团队、思维、管理、资本、学术体系，我们建设自己的公司，这才是我们要做的。赚钱才重要，其他的不重要。

一切错误，都是自己的思维错误，所以自己应该买单，这是真相。我们每个人都要反思，都要找自己的毛病，而不是怪罪社会，怪罪别人。人的战争，永远是自己内心的战争，跟外界无关。一切问题都是自己的想法问题，一切问题都是自己的
