# 三、我们社群学习的是什么？

我们讨论的、传播的都是儒家思想和陈昌文方法而已。
儒家思想、陈昌文方法，以及社群的各种心法是用来自啥的？一、提升赚钱智慧；二、提升婚恋智慧。如若有第三个，那就是防坑。我们要提升的就是大家的道德素质 + 营销能力、恋爱能力。

儒家思想解决价值观问题；
陈昌文方法 72 大营销系统解决营销、赚钱问题；
《恋爱宝典系列》解决情感问题。
这是我们社群给大家的 3 把利器。

人心要钱，我们就帮人赚钱；人心要繁殖，我们就出繁殖策略。所以我们社群的主题思想，就是提升人的生存 + 繁殖能力，这也是《陈昌文方法之恋爱宝典》系列推出的刚需性主题。

我用古今中外大师级的世界观来经营陈昌文老板社群，用大师级的组织管理模式 + 组织升级模式来经营社群。我们的任务，就是疯狂对铁粉好，提升他们的智力 + 经济能力，不断的讲法律、道德问题，这样去发展。
