# 4、为什么说做社群拼的是极致的体验

做社群，就是做好一件小事。人们都希望做伟大的事情，谈的都是世界上最大的事情，而要真正的伟大，就是用伟大的情怀，做好一件小事。

我们做好陈昌文读书书会，讲好书籍，传播好读书会，讲好课，就非常伟大了。所以，我们讲好书籍里的观点，就很伟大了。我们只给客户承诺进读书会，有内部资料送，里面有很多老师讲课，没有其他任何承诺。承诺越多，客户越不满意，但是我们要尽可能讲好。

只让客户记住一件事，进群，有内部资料送，有课程听，其他不讲。要卖一个极其简单的承诺，越简单，越干净，越好。但是在直播间、在内部课，尽可能讲好课、尽可能准确、用真理、有价值的解决客户的问题，并且帮助他们实践，让他们行动起来，
