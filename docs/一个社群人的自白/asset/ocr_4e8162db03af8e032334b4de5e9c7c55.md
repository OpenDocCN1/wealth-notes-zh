# 五、孝敬父母。

一个孝敬父母的人，内心才会开心。否则，不会开心。一个不开心的人，做不好管理者。要孝敬父母，父母是我们的天地。不孝敬父母，算什么人？爱护自己的家庭、孩子，也是要的。父母是要孝敬的，这是必须的。

年轻的时候，甚至怨恨过父母，没本事，为什么不能给自己非常好的条件、起点。现在，我们明白了，每个人都有缺陷，包括父母。他们不完美，但是，他们给了我们生命，给予了我们奋斗、改变命运的机会。血脉相连，实际上没有什么人比父母更重要了。

年轻的时候，自己没什么本事，与父母开玩笑，觉得很快乐。年纪大了，自己还没有什么本事，不是看父母白发，而是看到自己头上有些白发，再与父母开玩笑，心里就有点隐隐作痛了。你头发都白了，你还是个没本事的人，虽然能养父母，但你终究是一个没本事的人。你父母说话也难理直气壮，你说话也难理直气壮。

# 六、一切求真。

一切求真务实。对团队，对粉丝，对客户，对合作伙伴，只讲真话，只求真。
