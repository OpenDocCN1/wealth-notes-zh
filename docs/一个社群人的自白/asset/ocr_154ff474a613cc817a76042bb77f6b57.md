# 5、心性与命运

人的心决定了这个人的性，叫做心性。人的性，也就是性格，决定这个人的命运。人的运，决定了人的气，叫做运气。人的气决定了人的精神、态度、色调，叫做气色。而人的色，沉淀下来，就成了固态的相。如果继续往后讲，就是相貌。我们观察到这个人的相，就知道了这个人的貌。这就是人的心性、性命、命运、运气、气色、色相、相貌的根源。

人态度好，智慧就会增加，事情就能做好。人失败，大多都是因为态度不好。普通人要混的好，就是态度好就行了。可惜，大部分人都是心性不对的人，故而他们混的很失败。我们寻找人，首先是找态度好的人。

做人要正常一点，做事情也要正常一点。我们在追求理智的原则，我追求的是管理、人心、人性、规矩、真正的道理。
