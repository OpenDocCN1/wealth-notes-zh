# 8、如何设置进入社群的门槛条件

建立一个社群，是要严格执行收入标准的。一个准备加入高端社群的人，必须阅读和认可入群的免责声明（本书开篇有两篇免责声明，大家可以参考）；必须收集其身份复印件正反面，否则不收这个人，复印件必须要有，上面注明仅供入群证明使用；必须签字（注：必须手写）人群自愿申请书（本书开篇有加入陈昌文老师社群的自愿申请书范本）。

严格规整社群的入群门槛，进入高级群的人可以跟着我们终身学习、修行。

做社群，不收三无人员，否则你就要面临天天扯皮。只收有资产、能证明自己是老板的人，有一定赚钱能力的人。比如，年利润至少一百万以上。
