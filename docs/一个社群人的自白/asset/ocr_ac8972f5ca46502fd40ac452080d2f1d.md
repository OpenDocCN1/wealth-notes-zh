# 七、培养讲师团队整体传播、运营思维。

社群的任何讲师，都是团队运营思维，让读书会、陈昌文老杜社群的内部所有人运营起来。

运营的核心思路是价值，也就是你讲的每一句话，发Ring的每一张照片、视频，都是有价值的。你传播到群里的东西，必须是极度具有价值的。这个东西能吸引到所有人，否则，这个视频、照片就没有意义。直播也是一样的，我们讲直播，就必须讲真真正正有价值的事情，专门讲给老板、企业家这个群体，这样，我们才能精准输送干货。
