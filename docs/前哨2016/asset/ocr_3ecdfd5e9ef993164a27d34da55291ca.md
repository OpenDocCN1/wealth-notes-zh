# G-Summit与长城会

长城会（GWC）成立于2008年，致力于打造最具影响力的全球移动创新平台。

美国当地时间2016年9月28日，长城会组织的首届 “G-Summit：全球科学创新峰会”在旧金山举办。

长城会实行合伙人制，文厨先生是其联合创始人。作为一个民间的协会组织，长城会的全球化速度在中国首屈一指。

全球移动互联网大会（GMIC）是长城会发起的，全球规模最大、最具影响力的移动互联网行业盛会。自2009年第一届成功举办以来，GMIC已吸引全球超过70个国家的5万多名专业人士参加。2015年，GMIC从全球四站拓展至全球八站，依次在北京、纽约、东京、雅加达、班加罗尔、硅谷、圣保罗、台北等全球八地举办。GMIC关注的话题也涵盖全行业，促进包括零售、教育、医疗、金融、制造等领域的移动互联网化，关注跨界的创新与合作。

雷军早早就布局了长城会，现在是长城会的理事长。

# 参会感悟

学术界的人才纷纷地流向了企业界。大数据，人工智能需要数据做支持，没有数据，巧妇难为无米之炊。而数据往往在企业界手里。这个问题正愈演愈烈。

计算是需要钱的，Google的AlphaGo战胜李世石的背后是巨额的资金支持。

虽然人工智能，虚拟现实，生物基因是开源创新，但是因为数据控制和研发投入，同样会形成新的壁垒。很多传统行业实际上是没法做的。最后可能还是要交专利费。

在开源的环境之下，垄断的倾向依然非常强烈。
