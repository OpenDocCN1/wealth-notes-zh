# 认知科学商业化现状

美国政府发布了一个报告，指出未来科学最重要的四个领域叫NBIC，N是纳米科技，B是生物科技，I是信息技术，C是认知科学。

我们对大脑的了解，对自我认知行为的了解突飞猛进，但是在商业上面始终没有特别明确的成果出现。

比如NeuroSky生产的“情绪控制器耳夹”和“意念悬浮小球”曾经热销，但却是昙花一现，没有形成产业化规模。

# Lumosity：大脑训练软件

Lumosity，大脑训练软件的领军人物，全球最早推出系统推出大脑训练软件，证明大脑训练是有意义的。（官网 www.lumosity.com）

Lumosity把大脑功能分为五项：速度、记忆力、专注力、灵活性、解决问题的能力。

# 大脑训练是否有效？

Lumosity从自己的注册用户中取样，通过对照研究，证明使用Lumosity的软件后，智商提升。

+   但实验遇到质疑：
1.取样不公平。
2.美国乔治梅森大学通过实验，发现quista心理训练上，安慰剂效应十分明显；Lumosity的实验没有采取随机双盲，无法避免安慰剂效应，也就是对比结果无效。

科学家研究认为，益智训练只对用户现在训练的项目有效，并不具有延展性。

# Lumosity商业化受挫

由于商业宣传过度，夸大实际效果，遭到美国联邦贸易委员会处罚。

用户增长率、月活用户量、app下载量均大幅下降。

但迄今为止共有7000万人曾经用过Lumosity，它的用户量基础庞大，依然还是行业老大。
