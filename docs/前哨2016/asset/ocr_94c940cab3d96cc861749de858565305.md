# 周末问答 | 关于企业创新的五个讨论

关于企业创新的五个讨论

王煜全

今天的周末问答主要是关于大企业创新问题。

我有一个问题想问老师，对于一个企业来说，是不是追求利润最大化是最重要的？确实对大企业来说，创新乏力，但如果大企业考虑布局生态，用大量的资金投资科技企业而不是并购，是否未来收入也不错呢？

王煜全

第一个问题和企业形态相关。

假如一个大企业，把所有精力都放到投资科技企业中，而不是并购，那么它未来的收入肯定也可以不错哟。但问题是它可以不叫企业，直接叫基金了。

当然，这种转型型的企业也是有的。其实，这只是一个业务模式的问题，看你的模式是自己生产型，还是投资型。在生产型中是内生型，还是外部协作型。

如果企业是内生型，依靠自己生产研发一体化的大企业形态，那就不能这么做。

如果企业是外部协作型，由于投资一定也有被投资方，所以它也是协作的一部分，而创新的生态中，各个组成部分都很重要，所以，投资当然也是很重要的一部分。

我认为最核心的做法应该是专攻一项，找到自己的长板，学会和其他的长板拼接。这种时候，你就是有价值的。

普通草根是不是无缘涉足科技创新创业？假设研发只能小企业做，那企业就要专注做规模，像资本一样压缩时间，放大陆能。这样，研发结束后，小企业验正自己的产品，最好的办法是溢价卖给大企业，即市场的专业化分工。

对于小企业，研发的风险，一方面需要风险资本来分担，另一方面需要类似学校的地方作为新技术源头，即学校作为科技的孵化器，负责积累分母，跑出少数分子。这样得到的结论是，科技创新创业是依托平台的个人游戏，是机构之间的较力，普通草根根本无缘涉足。

那么，对于个人发展而言，要么抓住奇点处的技术，要么直接进入资本，分享技术福利。请教老师的是，我的逻辑有纰漏吗？

王煜全

不好意思，我只能说你的逻辑看似没有问题，但实际上有好几处纰漏。

这和经历过战争的兵法与纸上谈论的兵法区别一样。对大企业而言，即使你有能力做规模，故大陆能，但是能做到到底有多少稀缺依然是一个大问号。

最典型的例子是富士康，富士康算大企业吧，它专注做规模，也能够放大产能，而且还能压缩时间。但是，跟富士康合作的企业是不是被富士康收购呢？也不并不 是。大家都知道，小米如今的规模要比富士康大很多，就更别提iPhone了。

所以，应该把专注的核心放在积木式的协作上，而不是一家通吃。因为一旦通吃以后，就不可能在某个单项上永远保持领先了。

所以，这并不是大企业的机会。

假如你要衡量一辆车的性能，很可能是衡量它的速度，尤其是加速度。但要让一辆车达到最快的加速度，并不是意味着车上的每一个零部件都要达到最快的加速度，因为每个零件的考核标准是不一样的。

但是大家在一起协作时，是能够一起使整车的考核标准过关的。创新也一样，在整个创新生态里，需要有人做创新的事，也需要有人做不创新的事。创新和不创新的事，只有大家互补、强强联手，才能使得创新的事情真正做大做强。

关键问题并不是自己是否一定要创新，而是在创新的新型生态里，自己有没有地位和话语权。要想拥有地位和话语权，首先就需要你本身是一块足够关键的长板，才能够赢得其他长板的合作机会。

所以，这和是不是草根没多大关系，而是你有没有自己的强项。首先找到自己的优势，找到一个自己热爱且能够发挥所长的东西，然后在相应的领域里，把自己锻炼成最好，你就一定有非常光明的未来。

王老师，你总说大公司做创新很难做出有效的成果。杜邦研究院的撤销是一个标志，今天说的Google缩减创新部门也是一个标志。能否分享一下，这个转变是从什么时候开始的，您是如何注意到这种走势的发生的？

希望不仅学习到你分享的知识，也能学习你是如何学习和如何观察产业变化的，如何从一些细节、别人没有发现的地方去发现产业机会的。谢谢！

王煜全

说实话，这是我非常欣赏的一种态度。古话说“授之以鱼，不如授之以渔。”对于一个正在学习、希望成长的人而言，也是分到鱼不如学捕鱼。当然，我也非常愿意分享给大家我的经验。

第一，要有非常好的系统的建构能力。就是当你看了一个系统的知识后，能够把它后面的脉络梳理出来。

第二，对不符合系统的规则保持足够的敏感。一旦出现不符合系统的东西，那么，这其中必然会有问题。

我做了二十多年的咨询，习惯了看任何事情都从产业角度分析它在产业中的整体框架。
