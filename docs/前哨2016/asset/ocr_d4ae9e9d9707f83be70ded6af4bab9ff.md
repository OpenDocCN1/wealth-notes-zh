采访地点：美国 旧金山
新型投行公司Loyal3

+   Loyal3是一家新型投行公司，Loyal是忠诚的意思，3指的是三方：一方是公司；另一方是股市；还有一方是这个公司的合作伙伴和员工，也就是利益相关方。Loyal3用IT化的平台，在上市之前把承销的部分拆成很多小块，然后分散给大量的合作伙伴。

![](bbox=[0.08, 0.95, 0.95, 0.0011799999999999998])

+   绝大多数公司上市时，将股票卖给了所谓的机构投资人。这些机构投资人进行简单的低买高卖，以此获取利益。整个华尔街都是这种，比如高频交易，就是从现有的交易制度当中寻找漏洞，找到赚钱的机会。这些除了个人赚到钱以外，对整个资本市场有害无利。

+   以美国西岸、硅谷和旧金山为代表的FinTech——金融技术公司正在反思，金融应当恢复本来的面目，能够更好地为产业服务。

+   今天僵化的华尔街的那些投行，在当初其实也是先进的体系的创新者和革命者。投行之所以能做到那么庞大，是因为它是当初社会最主要的推动者。但现在整个社会的创新结构已经改变了，今天的创新不再由跨国公司主导，而是由很多生机勃勃、有广泛战略联盟的小公司主导。这些小公司需要的也不是当初那些投行，当初那些尾大不掉的投行只能为这些小公司添麻烦。

+   投行的命运必然会被改变，被运用先进科技、能够真正给企业带来价值的新型投行所改变。以Loyal3为代表，一个公司要上市，就可以把想要卖的部分，不直接卖给三家机构，而是卖给三百家，甚至三千家小合资伙伴和员工、顾客们。这样根据Loyal3的数据显示，这些和公司有业务联系或者从属关系的小合资伙伴和员工、顾客们，他们往往更忠诚、往往拥有公司的股票以后会长期持有，所以公司的股价会很稳定。同时他们也因为拥有了公司的股票而有了更强的主人翁意识，在未来的工作当中也更容易给公司带来更大的价值，这个才是多赢的局面。

+   基金是冷酷无情的，他们对这个公司根本没有任何忠诚度，他们保存这个公司股票的时间也很短。一旦公司股价上涨它就抛出去了。一个公司股价如果大量掌握在机构手里，就带来了不安定感，因为它经常会被买卖。

+   公司之所以能上市，和所谓机构投资人没什么关系。有关系的是他的顾客、他的员工、他的合作伙伴、他的渠道、他的分销商。这些有贡献者上市的时候，往往因为能力很微薄，没法大批量去购买公司的股票，而失去了能够享受公司上市、带来好处的机会。

+   资本不是万恶之源。僵化了的投资制度、投行制度才是万恶之源，把它改变了，资本就可以重新变成有源之水，灌溉这个产业的良性成长。

+   未来大量的企业发展都是生态型的，而股票作为一种生态系统的连接工具，能够让生态型企业获利的时候，生态的协同者全都能享受到利益，因为每一家协同者都是出了力的，再微小也应该享受到出力带来的成果。通过科技创新带来了全新的投行思维，使得原来一个人都憎恨的工具变成了一个可以使企业良性发展、对企业有所助力的工具。

+   一个时代会有新的发明、新的创造、新的创新、新的机制、甚至新的生态。新的生态需要新的配套，新的配套就意味着新的机会。当然这中间需要用技术来实现，所以这一轮的公司叫金融技术公司，但是技术不是目标，为产业服务才是目标，技术只是使自己更好为产业服务的一个工具。
