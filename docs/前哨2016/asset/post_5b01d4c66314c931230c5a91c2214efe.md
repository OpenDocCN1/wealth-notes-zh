# 触摸屏的历史

上世纪七十年代，美国伊利诺伊大学把触摸屏安装在PLATO IV计算机上，用于课堂辅助教学，触摸屏由此正式进入应用阶段。

上世纪九十年代，触摸屏出现在高端PDA里，当时的快译通和文曲星都有过触摸屏。

2004年，任天堂的掌上游戏机NDS在全球热卖，其最大的热点就是NDS拥有两块屏幕，其中一块是触摸屏。触摸屏随着NDS的流行而进入了更多人的视野。

2007年，第一代iPhone发售，它重新定义了智能手机。在iPhone发售之前，智能手机的定义是“用户能够自主安装软件的手机”，而在iPhone发售之后，智能手机的定义变成了“屏幕可以滑的手机”。

![](img/62f292c8be3ac58da47a6d8773aab464_89_0.png)

# 苹果手机的触摸屏

第一代iPhone使用的是电阻的触摸屏，支持基本的触控交互。后来苹果逐渐开始使用电容屏，极大地提升了操作手感。

为了使手机变得更轻更薄，屏幕制造技术从out of cell到on cell直至到最薄的in cell。

# 怎样实现三维触控技术

要实现三维交互，就必须能够实时捕捉到用户的手在三维空间中的坐标，并且根据用户手的三维坐标做出相应的回应。

# 三维人机交互方法带来的革命性应用

# 1.游戏

游戏是所有应用当中对于交互方式要求最高的，使用与游戏相配合的交互设备才能使玩家才能体会到游戏的魅力。一个方向是和VR技术结合例如《水果忍者》中的游戏可以在三维空间内通过玩家的手势进行。

# 2.增强现实（Augmented Reality），即AR

三维触摸屏很有潜力成为VR中人机交互的基础技术。

在AR技术中，用户佩戴的专用眼镜作为显示屏，通过计算机视觉技术将AR的图像界面与现实世界有机地结合到一起，并且投射到用户眼睛的视网膜上。

当用户的手做出动作的时候，AR设备必须能够准确地捕捉到手的实时位置，并根据用户手的动作做出相应反应。

陈玮，博士，德国DNV·GL集团新能源咨询认证项目经理和控制系统高级工程师，有八年风电行业的从业经验。

![](img/62f292c8be3ac58da47a6d8773aab464_91_1.png)

# 负电价的成因

2016年5月8日，在几个小时里，德国的新能源发电量达到了其用电总量的近95%，这是一个历史性的时刻。整个德国几乎完全依赖风能和太阳能的驱动。

天作之合：风电集中的德国北部风力强劲，太阳能集中的德国南部阳光充沛，加上当日是周日，德国的整体用电量相对较低。

偶然中的必然：从2015年的数据来看，德国的可再生能源占其总电力消费的三分之一。

![](img/62f292c8be3ac58da47a6d8773aab464_91_2.png)

![](img/62f292c8be3ac58da47a6d8773aab464_91_3.png)

![](img/62f292c8be3ac58da47a6d8773aab464_91_4.png)

在德国，一方面能源交易已经全面市场化，另一方面相关能源法律要求可再生能源必须全额上网，这意味着新能源发电量越大，传统能源的份额就越小。

电作为商品的特殊之处在于其生产和消费必须同步进行，存储的代价极大。

由于设备运转的需求，传统能源的发电量有一个最低极限值，因此一旦低于这个值，整个电网的稳定就可能受到威胁，必须通过补贴的方式尽快把多余的发电量卖出去，这就形成了高额负电价的现象。

这一偶发事件说明德国的新能源发展已经达到一个历史性的拐点，即如果新能源的装机容量得到充分发挥就可以满足德国大部分的电力需求。未来，德国的传统能源将从主力能源逐渐向辅助能源转变，主要功能是应对新能源发电的不确定性。

德国政府已经公开宣布将逐渐关停所有的核电站。

# 启示

德国的今天可能就是中国的明天，在能源变革的大势中，机遇远远大于挑战。

这次催生的负电价不是国家补贴的结果，而是由传统能源企业主动提供的，因此，传统能源企业完全有可能成为新能源的助推者，两者各司其职，相辅相成。

以新能源为主力的电网，其稳定性会大大降低，这就需要智能电网的蓬勃发展。

# 全球科技新闻 | 美国制糖业操纵科学家刻意误导大众

美国制糖业操纵科学家误导大众

# 科学互闻

近日，《美国医学会期刊：内科学》杂志揭露了上世纪六十年代，美国制糖业花钱购买科学家控制论证，弱化糖品与心血管疾病之间的关联，并将饱和和脂肪酸推为罪魁祸首的新闻。

美国加州大学旧金山分校的博士后研究员Christin E. Kearns从哈佛大学的历史文件中发现一个名为糖业研究基金（The Sugar Research Foundation）的商业集团，也就是今天美国糖业协会（The Sugar Association）的前身，在1967年花费重金聘请三位哈佛大学的科学家发表了一篇关于糖类、脂肪和心血管疾病研究的论文文章。

研究结果经过糖业集团的特殊挑选强化了糖类与心血管疾病之间的关联，并将罪魁祸首给了饱和和脂肪酸，使得数十年关于糖类的讨论完全隔离与轨道。

![](img/62f292c8be3ac58da47a6d8773aab464_94_0.png)

# 错误修正

学术研究规范：目前的学术研究规范对产业赞助的研究项目中可能的利益冲突有严格的规定。

美国的居民营养膳食指南对其涉及糖类的内容进行了修订。

# 目前的学术结论

+   饱和脂肪酸和心血管疾病之间的相关性缺乏证据；
摄入的胆固醇与血液中的胆固醇含量没有可评估的相关性；
过多的单糖摄入，包括葡萄糖和果糖，是心脏病、肥胖有关疾病的正相关因素，其真正相关性远高于脂肪。
饱和脂肪酸和不饱和脂肪酸和心血管疾病的关系一直有争议，一直没有明确的证据，只有反式脂肪酸是对身体有危害的。

# 舆论偏差

现在，一个人想要成为多个领域的权威，对多个领域有充分的辩识能力是十分困难。

专家一旦超出自己的专业领域，进行相对发散的讨论的时候，并不能保证专业性，比如霍金讨论人工智能。

我们对专家的观点一定要警惕，不要过度迷信。

绝大多数事情我们都无法百分之百的确定，不要非此即彼，非黑即白，需要拥有概率性思维，允许相互矛盾的证据存在，大胆假设，小心求证。

考察观点时重要的是出发点和立场，所以属决定陷阱，立场是中立的才能再看观点是否中立，臭名昭著的例子就是烟草行业。
