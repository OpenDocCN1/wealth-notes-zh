不是单打独斗。

所以我认为，在一个不熟悉企业，不熟悉情况的时候，先学会了解模式，待了解足够多了以后，再重构模式。一旦发现一个数据和模式是不一致时，立刻要警惕起来，不一定是这个数据错了，可能是模式错了。如果模式错了，就积极地承认并推翻这个模式，从头再来。

这是我在实践中觉得比较行之有效，能够对产业形成更深刻理解的一个思考方法，供你参考。

传统的跨国企业是否是纯粹的自由市场经济产物，如果是的话，反垄断法对大企业的垄断性起到了一个的抑制。但是这是政府行为，那么纯粹的自由市场经济是否可取。

要提出反垄断，政府要支持，但是美国的政府一定程度上被大企业绑架，而中国因为有国有企业的存在，反而不会受到大企业影响。可否进而推理得到，中国的专制在这方面优于美国的民主，而国有企业也在一定程度上解决了这种问题。

大企业的七宗罪也有反例，比如：海尔的改制，宗毅的裂变式创新，可否在大企业推广，这些应该有利于创新。华为的狼性文化对内部政治问题能起到抑制。

大企业收购小型企业，如果能够促进其创新的发展，未必是坏事，但是并购后的整合问题是个大事。小企业能够茁壮发展，要看投资和并购这两种方法谁跑得更快，更快。

这位前哨朋友的提问非常认真，留言内容很长。我来一一作答。

# 自由市场经济会不会形成垄断？

一定会。但是也会受到一些干扰，例如政府的管制。美国政府并没有被大企业绑架，美国政府经常因为反垄断的原因，甚至造成大企业被拆分。

最典型的是过去的贝尔公司，贝尔公司被拆分成了AT&T和一堆地方贝尔公司，造成美国电信业的全面开放，这些都是美国政府反垄断的功劳。

中国反倒在反垄断上不那么积极，因为中国有大企业，中国政府认为大企业给地方带来的经济效益更大，所以往往会支持大企业，而忘记了反垄断。

所以我认为，事实和你的推论正相反，中国对反垄断重视程度不够，而美国重视程度是很高的。

# 中国因为有国有企业的存在，就不会受到大企业的影响？

这是个很奇怪的论调，因为国有企业基本上都是大企业，你说中国的专制是由于中国的民主，这个我觉得不太对，因为它还是需要反垄断的。

当然，另一方面来讲，也不用过分地重视，因为实际上，随着科技的发展，老的垄断总是被新的垄断所替代。

谷歌战略的时候专门讲过，当你在某一个细分领域里进行垄断时，你会发现，这个细分领域的份额在整个市场份额里会有下降趋势，因为更新的细分领域不断出现，并且更新的细分领域垄断者还会动摇你的地位。

科技是对垄断很好的克制。所以我们要一方面寄希望于科技，另一方面寄希望于对反垄断的重视。

# 再谈谈你提及的大企业七宗罪的反例。

第一，我认为海尔的改制效果还有待观察，我不认为海尔已经破解了大企业的七宗罪。

第二，宗毅的裂变式创新其实现就是我们所说的呀，要想办法解决大企业的问题，把大企业拆成小了，永远不让企业长大哇。因为一旦长太大会裂变，最后没有大企业，只是一堆小企业，这和我们说的是同一回事嘛，所以我是支持宗毅的裂变的。

同时，我也认为海尔如果能够做到彻底的小企业化，把它的每个部门独立结算，而且每个部门的执行者都有股权，我认为才是真正有效的改制。但是一旦做到那一步，就自然形成了小企业群和小企业生态，也就不存在大企业了。所以我认为，对于大企业病根治的办法是消灭大企业。

# 华为的狼性文化对内部政治问题起到抑制作用？

这个也无从谈起，因为大企业的内部斗争是没有办法通过狼性文化来抑制的。而且慢慢地，狼性文化会越来越不被认可。

比如，我们这一代人都接受的观念是，进入一个企业要为企业作奉献。但如果你跟一个90后的技术人员说，你应该为企业作奉献，他只会“哈哈”冷笑。凭什么我为你作奉献，你为我提供什么了？

所以我更认同的说法是，人和人之间的关系是联盟关系，联盟是互惠互利的，谁也别为谁奉献终身。

现在不是用文化号召能解决问题的时候了，我们企业的管理也要与时俱进。以后有时间，我会跟大家具体谈谈，面向未来社会的企业管理会出现什么变化。今天暂不展开论述。

王老师好，隔壁吴伯凡老师曾经在一期里面提到了熊，说它的能力很复杂，水陆两栖，直立行走，适应各种环境，吃得还是杂食，还能冬眠。当时他的说法是，熊是没有大企业病的企业。这样的企业有吗？3M算吗？
另外，创新者曾经提出过一个方法，就是投资小企业，咋怕以后和自己竞争，这是不是大企业都成立投资部门的原因，他们的投资布局有用吗？

如果问到是否存在大企业病的企业，按理也不能说没有，就是尽量把大企业各部门分散开，变成小企业，让各小企业都有主人翁意识。

但总的来说，人为塑造的生态不如优胜劣汰的自然生态强壮和健康。所以我认为，凡是和自然靠着来的，一定是不够好的。自然中“物竞天择、适者生存”是最佳的择优工具。

这个地球上所有的物体都有大小，你见过无限生长的动物和植物吗？并没有呀。那为什么需要有无限生长的大企业呢？一个企业生长到上百万人，这不是畸形吗？自然界里没有不朽，而我们非要追求不朽，这不是和自然对着干吗？

投资小企业，咋怕以后这些小企业和自己竞争，这是一个很有的心态，也确实是大企业成立投资部门的原因。但是，这仍然不能避免大企业的没落。

前面讲过，很多小企业成长得太快，以至于大企业想收购它的时候已经来不及了。具体数据也能够表现出来，世界市值排名前五的企业，岁数最大的41岁，微软；岁数最小的12岁，Facebook；世界排名第一的40岁，苹果。

可以想象，这些企业年轻时大企业为什么不收购它呢？因为看不明白行情。等到大企业看明白行情时，小企业的价值已经上涨到收购不起了。

我认为更新换代才正是世界最本质的规律，也是世界的美妙之处。
