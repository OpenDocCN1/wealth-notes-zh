# 负电价的成因

2016年5月8日，在几个小时里，德国的新能源发电量达到了其用电总量的近95%，这是一个历史性的时刻。整个德国几乎完全依赖风能和太阳能的驱动。

天作之合：风电集中的德国北部风力强劲，太阳能集中的德国南部阳光充沛，加上当日是周日，德国的整体用电量相对较低。

偶然中的必然：从2015年的数据来看，德国的可再生能源占其总电力消费的三分之一。

在德国，一方面能源交易已经全面市场化，另一方面相关能源法律要求可再生能源必须全额上网，这意味着新能源发电量越大，传统能源的份额就越小。

电作为商品的特殊之处在于其生产和消费必须同步进行，存储的代价极大。

由于设备运转的需求，传统能源的发电量有一个最低极限值，因此一旦低于这个值，整个电网的稳定就可能受到威胁，必须通过补贴的方式尽快把多余的发电量卖出去，这就形成了高额负电价的现象。

这一偶发事件说明德国的新能源发展已经达到一个历史性的拐点，即如果新能源的装机容量得到充分发挥就可以满足德国大部分的电力需求。未来，德国的传统能源将从主力能源逐渐向辅助能源转变，主要功能是应对新能源发电的不确定性。

德国政府已经公开宣布将逐渐关停所有的核电站。

# 启示

德国的今天可能就是中国的明天，在能源变革的大势中，机遇远远大于挑战。

这次催生的负电价不是国家补贴的结果，而是由传统能源企业主动提供的，因此，传统能源企业完全有可能成为新能源的助推者，两者各司其职，相辅相成。

以新能源为主力的电网，其稳定性会大大降低，这就需要智能电网的蓬勃发展。
