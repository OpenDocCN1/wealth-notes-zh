# 科技和公益的结合点

社会企业和公益机构容易给人“需要别人长期捐助，自己难以可持续发展”的印象。因为本来赚钱就难，兼顾赚钱和社会价值，肯定更难。所以很多人觉得，公益机构和社会企业离高科技很远。

但实际上高科技本身就有公益性质，就是因为托了高科技的福，越来越多的人类才能享受到过去只有极少数人才能享受到的特权。比如说你家里有了扫地机器人，就不需要像贵族一样雇佣人，家里也能保持干净了。所以科技和公益从天就有很多的结合点。

# 公益运用高科技的例子

公益运用高科技有很多先例，主要是在宣传和媒体方面，尤其新媒体。

比如美国大选利用新媒体，公益和社会企业也是最常应用新媒体。我的好朋友邓飞组织的微博打拐和后来组织的免费午餐，都是利用了社交网络的传播特性和公众普遍愿意帮助他人和愿意行善的心理，形成了很大的影响。
