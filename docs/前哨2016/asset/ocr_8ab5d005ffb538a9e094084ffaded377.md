# 物流与供应链管理

中国和西方发达国家的人情不同，中国大城市的人口聚集度很高，最后一公里的问题可以靠人解决，而西方发达国家城市人口主要居住在城市之外，需要用技术解决最后 nuisance

借助GPS发展起来的远程信息（Telematics）供应链管理解决方案是物流行业的发展趋势。被美国最大的通信网络运营商Verizon公司收购掉的Telogis和Fleetmatics公司都是车队管理解决方案的供应商，今年7月登陆NASDAQ的Impinj公司则是通过物品智能化提供物联网的解决方案。

# 运送设备的革新

无人机递送服务在没有高层建筑的西方社区中有很大优势，Flirtey公司是全球首家实现无人机递送商业化的公司。2015和2016年，美国的联邦航空管理局（Federal Aviation Administration，FAA）先后批准了这家公司在农村和城市的无人机商业飞行。
