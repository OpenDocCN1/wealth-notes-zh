# 树立宏观的战略眼光

中国人善于捕捉风口，但有时也会因为过度关注风口而忽视了其他领域的机会。但现在全球创新并不仅仅限于互联网和人工智能，而是在各个科技领域里面平行展开的。

# 人工触觉系统

现在，人工视觉系统在视觉识别、图像识别、面部等方面都做得很好，甚至味觉、触觉、嗅觉系统的研究也已经展开了。解决人工触觉系统难题的是斯坦福大学的教授鲍哲南老师。

鲍哲南是被李飞飞老师推荐的，她既是斯坦福大学的教授，也是2016年MIT科技评论评选出来的35个35岁以下的科技精英之一。

鲍哲南的研究成果属于材料科学。原理是在纳米层面上做修饰构建材料结构，来达到轻薄的目的。它可以像一张名片一样贴在任何物体上，帮助这个物体感知触觉，而且还能用电刺激的方式把压力传感出来，再用计算机进行解读。

# 人工触觉系统的应用前景

人工触觉系统有着广泛的应用前景。如工业机器人、可穿戴设备、IOT（人和机器互动、机器和机器互动）等方面都会用得到。如果各种各样的设备上都有触觉，触觉就可以作为一个媒介，让人们的生活变得更加方便。

# 为什么要在研发初期就开始合作

这项技术离完全商业化还需要5到8年的时间，还在研发初期，不容易和中国的制造对接。但人工触觉系统在商业化的过程中并不是一个孤立的技术：皮肤本身是没有市场的，必须要把皮肤和机器人、可穿戴设备等结合，才会有市场。现在，跨企业的协同研发越来越多，而人工触觉系统这种技术更需要跨企业的协同研发，所以在研发初期就可以开始合作了。

# 我们要具有前瞻性

在投资上，一般要选择研发基本完成的有大规模制造的企业。但如果有清晰的市场导向和确定的研发效果，在早期就可以合作。除了研发的合作，还需要制造企业的合作。所以在投资上应该更前瞻一点。

如果能把相关行业的企业家、投资人聚集起来，投资于一些相对早期的全球前沿科技企业，同时在对方早期研发时就经常沟通，争取合作，对方的科技就更容易应用化、市场化，而我们中国的市场优势和应用优势也容易有科技的支持。这对于提升中国的科技实力是一件好事。
