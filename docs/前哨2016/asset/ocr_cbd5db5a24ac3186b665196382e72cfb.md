# 3D打印的三类行业应用

一是产品原型设计，设计公司开发产品原型时，需要做样品，费时费力。现在很多设计公司利用3D打印，把产品原型数据输送给对方，客户用3D打印出来，就可以针对原型进行讨论，省时省力。

专门针对产品原型设计的3D打印机有3D Systems。

![](bbox=[0.04, 0.64, 0.96, 0.8])

二是模具。模具的应用市场更大一些，它主要不是面向设计公司，而是面向企业生产，做开模。尤其是很多产品外壳需要特殊设计，用3D打印可以极大地降低成本。

国外有ExOne、VoxelJet公司都是专门做模具的。

![](bbox=[0.12, 0.13, 0.95, 0.27])

![](bbox=[0.05, 0.29, 0.96, 0.55])

三是做备件。华中科技大学，能用3D打印一次成型金属零件。中国的歼-20，里面也有基本元件是用3D打印成型制作的。
