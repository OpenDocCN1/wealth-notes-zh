# 未来教育的机会

中国家庭对教育非常重视，教育是刚需。

中国教育仍然集中在应试教育上。

义务教育不是一个开放市场，创业者机会有限，无非是教育辅助——网校、家教和习题，然而这些无助于改善中国传统教育的现状，传统教育需要改革。

英语教育，尤其“口语外教一对一”确实是很大的市场，但是增长空间不大，甚至有萎缩趋势。

IT教育在未来是一个有巨大空间的产业，但是目前以在职培训为主的IT教育效果不理想，市场在中国并不大。

# 未来教什么

未来的核心技能一定是IT化的，IT就是未来的英语，IT教育会大行其道；

IT教育的核心是实战，上手就能工作，在IT领域，教育和实战本身结合很紧密；

中国的教育工作者和IT领域的领军企业需要坐下来研讨未来IT技能的核心是什么，然后改变我们的IT教育现状，使教育出来的人能够适应未来的工作需要。

国际教育的新趋势叫做STEAM，就是科学(Science)、技术(Technology)、工程(Engineering)、艺术(Arts)和数学(Math)。

未来培养的孩子应该能够随时发现各种社会问题，并且具有解决这些问题的能力；

发现问题，自己动手。中国未来的中小学教育必然要向这个方向转变。

未来，人工智能会越来越成熟，那么人工智能难以替代的人类艺术和创造力的价值将会大大地提升。艺术和创造力教育就会大行其道；

未来的人需要具备机器智商，要懂得调用机器为自己干活。

# 未来怎么教

传统教育，上课加作业模式的结果往往很不理想，按照翻转课堂的理论，应该上课做作业，回家看教材。

是否理解教材内容，在第二天的作业中就能显示出来。课堂上，老师恰好可以针对性地帮助解决前一天的问题和作业中的困难。

偏科是因为学生被一个知识点卡住又没能及时解决，问题日积月累的结果，所以翻转课堂的教育，以老师及时辅导学生被卡住的知识点为核心。

除了模式，中国还有师资失衡的问题。双师教育，核心是用中国最好老师的视频课程作为学生的第一老师，而学校里的老师是助教。这对于农村和城市边缘的学校十分必要。

双师教育没办法一劳永逸解决问题，缺少互动的视频课程极其枯燥，很难让学生产生兴趣。

交互机器人可以弥补这方面的缺陷。
