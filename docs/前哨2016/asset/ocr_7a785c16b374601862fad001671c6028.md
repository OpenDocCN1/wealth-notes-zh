+   - 柔性电子产品分成三大类：柔性屏幕、柔性电池、柔性集成电路。最重要的一部分叫做柔性集成电路，即为印刷线路板加上上面的柔性电子元器件。这一部分如果都是柔性的，那整个电子部分就都能实现柔性了。

+   - 积木式理论就是，只有每块积木摆放到位，才能堆集而成的管理理论，源于西方管理学。MC10是伊利诺伊大学 John Rogers教授运用积木式理论拼出来的。他与前两天提到的North Bridge（北桥创投）公司的Carmichael Roberts是好朋友，Carmichael认为一定要找到一个足够先进的科技，依托于科技创业。

+   - 技术人员缺乏企业管理经验，所以一开始Carmichael兼职做了MC10公司一年的CEO，一直到找到了一个适合研发的CEO。后来研发基本上完成，考虑在全球开拓市场，这时候，那个研发型的CEO又不适合了，所以他自己就主动请求辞职。反复之下，终于找到了今天MC10公司的

+   - 要使基础科技得到实现，必须要有一套良好的机制。美国的科技之所以领先，就在于它实践了积木式理论：一方面是企业内部，需要管理、技术、研发，都可以用搭积木的方式搭起来；另一方面是企业外部，当需要外部企业协作的时候，也可以通过搭积木去获取协作需要的能力。

+   - 搭积木需要的前提条件是契约精神。这~一轮美国的创新，显著标志就是即插即用的积木式创新，所以它的效率非常高，能够让非常多的高科技迅速地实现转化，投入到市场当中，推动社会发展。这也是中国的企业家们需要学习的。
