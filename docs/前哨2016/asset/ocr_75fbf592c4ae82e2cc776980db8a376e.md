亚马逊在零售业的全面布局

# 一则新闻：

亚马逊在西雅图开了一个完全没有人的商店，Amazon Go，店里没有任何员工，你进门的时候只需扫一下面部，识别出你的样貌后，你就能进店选购商品了，拿完后直接出门就好。当然，它可不是免费，店里的智能系统会跟踪你的所有行为，然后把账单发送给你，你网络上支付就行。它只是省去了你的结账流程。

很多人说，亚马逊未来会不会是阿里类企业的克星。但我认为，这个业务不太可能终结阿里巴巴，虽然它确实是在积极地探索创新。

今天，我来和大家谈谈你没见过的亚马逊。

# 在零售业的全面布局

整体而言，亚马逊是一个战略布局非常清晰的公司，已经形成了自己在在线上零售、媒体业务、互联网媒体、云计算等领域的战略优势，而且是逐渐深入的战略优势。

亚马逊除了线下商店以外，线上商城也是非常强劲的，线上销售额一年能够达到上千亿美金，毛利润高达30%。

亚马逊有一套非常成熟的基于大数据的推荐系统，至少能够使它的线上销售额增加20%以上的收入。

第一，当你在浏览一个商品时，它做了非常针对性的推荐，你可以货比三家，买到最称心的商品。第二，在你买一个商品的时候，它还会告诉你，购买了此商品的人同时也买了其他什么商品。

这些推荐系统都增大了它的销售额。

亚马逊也在积极地打通线上线下，未来的线下一定是必争之地。但它的线下并不仅仅只是商店，还有一个新的服务在近期推出，虽然推出的声势不浩荡，但我认为它对未来零售的影响要比Amazon Go线下商店更大。

# Dash Button小按钮

我们可以理解为快捷按键。Dash Button只有创可贴那么大，而它连通了网络。它有什么作用呢？比如你经常在亚马逊购买洗衣粉，你可以将一个标着洗衣粉的Dash Button按键放在经常存放洗衣粉的地方，如果洗衣粉用完了，你只需要按一下按键，它就能一键下单，而洗衣粉就能直接送到家。

理论上讲，你可以在家里布置N多个Dash Button，分别指向N多个你需要重复购买的商品，让按键为你直接下单，省去了浏览网页查找购买的繁琐步骤。

这个产品自然很方便，但目前还不够实用化，因为太贵了，一个Dash Button就要几美。但我认为随着业务逐渐普及，成本肯定也会慢慢降下去，所以用户量才是最关键的。

# 1-Click专利

在十多年以前，亚马逊刚刚推出服务不久时，注册了一个小专利，这个专利可以说是美国专利历史上第一次授予的行为专利。叫1-Click，1-Click是亚马逊独有的一個技术，如果你曾经在亚马逊上输入过你的信用卡，想买东西的时候按一下1-Click按钮就能完成付费，因为你的信用卡信息和地址早就储存了。

这个技术刚开发出来的时候，还是有点技术优势的，但这项技术并不难，也没啥壁垒，所以理论上讲，人人都能做。而亚马逊把它这个技术的行为注册成了专利。也就是说，不管你用什么技术，只要是点击一下便可完成付费的所有行为，一律都侵犯了亚马逊的权。

这是美国专利史上的第一个行为专利，但后来并没有激起很大的重视。现在的Dash Button，其实就是利用了1-Click的专利，理论上讲，别人如果也做这种购买行为的产品，是侵权创的，如果想做，那就点两下吧。

这是一个线上线下结合的典型例子。它将线上点击一下的行为装到了Dash Button小按键上，然后这个按键是线下的产品，可以放在家里的各个角落，而线下的行为直接触发线上销售，非常漂亮。而且这件事在零售上的意义也非常大。

未来还有各种智能解决方案，比如亚马逊的商店，Amazon Go，它的解决方案就是通过进门时的面部识别和进门后的N多个摄像头追踪，并没有用到Dash Button这样的按键技术。

但不管未来是什么技术，都能够对人的行为进行充分的了解，当你有了购买欲望时，亚马逊能够第一时间满足你的需求，这才是亚马逊真正希望做到的，因为这样就能够让它在零售方面，对用户需求有非常准确的把握。

一个做得好的零售企业，它后台一定需要强大的物流系统。而亚马逊不仅前台做得很漂亮，它的后台也非常强大。

# Amazon Robotics物流服务

在很多年之前，亚马逊收购了Kiva公司，它的物流机器人做得非常领先。亚马逊在收购Kiva后，Kiva机器人很快被改组成了Amazon Robotics，亚马逊机器人。专门给亚马逊公司提供物流服务。现在，亚马逊的仓储物流都是自动化的。

亚马逊也在做更前瞻的试探。比如亚马逊的无人机送货服务，虽然它离实际应用还有几年的时间，但是它技术的储备是非常积极的。实际上，亚马逊正在从顾客、前台、后台、物流、送货各个方面着力，希望全方位地利用先进技术再造这个零售系统。

亚马逊当初是从网站零售做起的，所以它有一个优势，就是它的图书产品其实和音视频产品很接近，所以，亚马逊从图书拓展到了百货，成了美国最大的电商网站，实际上它的电器产品销量占了很大一部分。

另外，它也在积极地拓展到媒体领域，不仅出售DVD，而且出售线上视频，它变成了美国媒体分发的最大平台之一。现在，亚马逊的媒体收入已经占了整体收入的20%多。

# 亚马逊的 Echo 和 Fire Stick

未来的电视机不再是电视机，只是一块放在客厅的显示屏，主要用来显示互联网内容，尤其是互联网视频。而且，这些内容有一个最大特点的转换，从过去的调台、搜索，转换成了直接寻找。

亚马逊的Fire Stick，就是一个专门控制亚马逊内容的小遥控器，遥控器前端集成了声控的内容，你只需要直接对着Fire Stick说话，就能让电视机呈现出你所寻找的电影，让检索信息变得更方便了。

亚马逊现在非常积极地布局，除了它的电商以外，也在通过媒体向电视拓展，全面占领客厅。

亚马逊已经有了智能遥控器和智能音箱；我认为如果它能进一步用视频把用户吸引过来，电视是能够进一步改造成为电商平台的。

理论上讲，如果电视屏幕能够被语音控制，而且可以购物，那么，只需要设置一次1-Click后，是能够解决购物需求的，它适用用于很多不太会用电子产品的老年用户。

所以，其实亚马逊在积极地进一步拓展媒体业务，也在利用媒体业务进一步扩大电商零售。

亚马逊还有一个发展得非常快的业务，叫Amazon Web Services，AWS。亚马逊有三个梯队，第一梯队是零售，第二梯队是媒体，第三梯队是云服务，也就是AWS。从第三季度的累计来看，年内肯定会突破100亿美金的收入大关。

虽然100亿美金的收入只占了亚马逊全球收入的10%，但它的成长非常快，而且AWS上面集成了大量的 segments are covered.
