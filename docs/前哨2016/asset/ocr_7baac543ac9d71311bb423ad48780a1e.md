# Grit是什么

Grit一词在古英语中的原义是沙砾，即沙堆中坚硬耐磨的颗粒。

> "向着长期的目标，坚持自己的激情，即便历经失败，依然能够坚持不懈地努力下去，这种品质就叫做坚毅。" —— Angela Duckworth在2013年TED演讲时，给予Grit如是定义。

和Marshmallow test（棉花糖测试）一样，Grit可以从一个人现有的能力看到他未来的成长和成就。

作者Angela Duckworth认为Grit有两个特征，热情和持久。二者缺一不可，相辅相成。

# Marshmallow test和Grit

marshmallow test（棉花糖测试）是Grit面向孩子的版本，它的前提和关键是兴趣，然后再观察能坚持多久。

Grit是一个很好的指标，能够告诉我们未来什么人能有成就，因为有所成就者必备热情和坚持。

但不是什么事情都能做出成就，因为人可以坚持，但是兴趣必须培养。如果没有兴趣点，你的坚持便无意义。

Grit测试有一个变种，叫做Treadmill test。一个跑步机，测试在上面能跑多久。这是针对持续能力的变相测试，强调的是持久。

# 人类智商持续提升

人类的智商从一百多年前有测试和记录以来，一直在迅速提升。

人工智能正在抢夺和替代人的工作，我们必须知道还有什么空间可以提升。

抽象思维造成了智商的持续提升，人类继续强化抽象思维，并和具象相结合，这是人类未来的发展方向。要做到这一 点，需要热情（兴趣）+坚持。
