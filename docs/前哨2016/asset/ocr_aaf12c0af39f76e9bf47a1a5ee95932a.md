# 手环消费市场

大品牌在全球仍有比较大的统治地位，尤其是手环的最早推出者Fitbit，Jawbone也是手环领域的重要品牌。

手环的功能相对比较单调，进入门槛不高，市场竞争激烈，用户需求也不那么旺盛。

除此之外，作为手腕上的电子装置，故障率一直居高不下，需要强大的售后服务保障。

正是由于Fitbit在中国无法提供足够的售后服务保障，因此把先发优势拱手让给了小米。

# 手表消费市场

手表领域同样以大品牌为主，苹果的Apple Watch和三星的智能手表。这两款手表的全球销量成绩尚可。

但这是由于品牌整体的带动作用，而不是手表本身的实力，手表的機能仍旧比较单调，市场反馈比较一般。

# 消费市场的展望

去年，Fitbit在美国收购了硅谷著名金融技术公司Coin的可穿戴支付技术平台，打算进军移动支付领域。

苹果的Apple Pay也可能出现在Apple Watch里。

下一个消费级可穿戴领域的竞争可能发生在支付上。

来自大品牌和山寨品牌的压力，使创业者会受到双重夹击，做消费类可穿戴产品会举步维艰。

# 专业市场的特点与现状

专业医疗级别的可穿戴产品有巨大的市场潜力，拥有众多的细分领域。

细分市场之间没有竞争，每个细分市场都很大，消费者的健康需求是刚需。

有大公司在该领域，但依然有大量创业公司参与。

普通消费类可穿戴产品不能参与专业医疗领域产品的竞争。

医疗领域的产品需要得到医疗机构的认证，尤其是FDA认证，有一定壁垒。

# 机会与建议

只要和现有产品不在一个领域或一个治疗类别里，就可以避免竞争。

一旦获得FDA认证，就有了很好的壁垒。

专业医疗级别的可穿戴在中国更少见，还是一个巨大的蓝海。

美国医疗可穿戴的领域细分已经很清晰，如果中国公司能吸取他们的经验，找到突破点，或者和美国有优势的公司合作，在中国拓展市场，就会有巨大的机会。

中国的可穿戴设备声称具有医疗监护效果，但依然属于消费级别，而非医疗级别。

医疗领域有大量对移动和远程健康监护的需求，尤其现在医院特别强调对患者持续服务。

因为跨界合作稀少，所以中国专业医疗领域的可穿戴设备相对稀少。

创业者应该把握这个机会，积极寻求与特定领域的医学专家合作。反之，医学专家也可以主动和可穿戴厂商合作，这一巨大蓝海的市场前景值得期待。
