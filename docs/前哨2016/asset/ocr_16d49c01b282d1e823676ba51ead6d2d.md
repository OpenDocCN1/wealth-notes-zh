+   • 高科技要想成立，除了公司本身以外，还需要有一个非常大的生态环境支持。律师事务所是重要的一环。

+   • 现在很多中国的企业和个人去海外投资，目标往往是选择高科技公司，因为这些公司的科技含量特别高，回报相对不错。我们中国人出去，往往因为各种各样的原因，图省钱、图省事，或者觉得自己能掌握，而忽略了和中间层的合作。也就是说和对方谈的时候，未必引入了律师或者第三方咨询、调查机构。但是在全球的科技投资和并购案例里，律师的身影基本上是不可或缺的，甚至说因为你没有带律师，对方会失去对你的信任，从而拒绝和你谈判。现在我们中国在海外的很多收购，因为各种各样的原因会被对方限制，或者叫停，那我相信职业化、正规化的缺乏也是其中一个很重要的原因。

+   • Mintz Levin是美国一家与众不同的律师事务所。虽然都是律师，都提供法律服务，但是他们提供的是风险投资和创业相关的法律服务，他们在这个专业领域里有自己的独到之处。接待我们的律师在大学里担任风险投资课程的教授，同时在外面做律师。他对法律、对风险投资相关的法律非常的专业。

+   • 不仅如此，这个律师事务所甚至有一部分中间人的角色，它能成功给投资人和理想的科技公司牵线。它深度钻研的不限于法律领域，甚至在很多的专业科技领域，比如说信息技术领域，生命科学领域和新能源领域。Mintz Levin对这些领域的前沿科技和创新公司的跟踪相当发达。可以说他们不光是律师，而且做到了行业顾问的角色。

+   • Saverin，也就是facebook联合创始人之一，当初他在离开facebook时，和facebook现任CEO扎克伯格产生了矛盾。Mintz Levin曾经代表Saverin和facebook打了个非常著名的官司，最后Saverin拿到了很高额的赔偿。这场官司的胜利和这家律所对信息科技的理解其实是非常有关联的。

+   • 爱德华多·萨维林（葡萄牙语：Eduardo Saverin，1982年3月13日 -），是一名巴西企业家。他与马克·扎克伯格等人一同创办了facebook。截至2011年1月4日，他拥有百分之5，价值12亿美金的股份。

+   • 这家律所的负责人本身就是讲风险投资的教授，Mintz Levin律所甚至组了一些专项基金，当有好项目的时候，可以和投资人一起联合投进去。所以风险投资其实是整个创新里面不可或缺的一环，而律师也是另一个不可或缺的环节。懂高科技的律师、懂高科技的风险投资者和懂高科技的其他支持体系一样结合起来，形成对高科技，尤其对科技创新的支持性的生态，才能使得科技创新企业在美国有长足的发展。

+   • 中国要完善这样一个创新环境，我们的创新才能够有所保障。今天看起来，我们创新的环境建设相对要缺少很多，这个创新环境缺乏的背后体现的是我们对创新意识的缺乏，对创新环境的理解的缺乏。也就是说当在意识上都缺乏的时候，行动上自然表现出了欠缺。理念上的缺乏是需要我们去补课的，也就是说需要更多的了解世界创新前沿，首先不要说能不能自己独立搞出一个创新环境来，而是理解创新环境需要什么，然后在和对方的创新环境对接的过程当中，把自己的能力一步一步培养起来。我们也可以去和人家的律师学习，去和人家的风险投资学习，当所有这些创新要素都具备的时候，即使我们不建立创新环境，我们的创新生态一定也是优秀的。

+   • 参观这个律师事务所的启示是一—创新，需要一个完整的环境来支持创新。那么这个环境的建设需要有耐心，最重要的是需要我们在认知上对它形成充分的理解和充分的尊重，然后在实践中一步一步去实现。所以创新不是一日之功，但是我们只要长期的坚持走下去，就像过去三十年里，中国坚持改革开放一样。相信我们坚持三十年创新，中国的创新能力也一定是世界一流的。
