# 全球科技新闻 | 数据猎人：刚刚诞生的未来职业

新兴职业：数据猎人

# 数据现状

大数据和人工智能的前提是有海量的数据可用，未来可能有越来越多的人会从事数据收集的工作。

美国Guidepoint Global公司专门为咨询和投资机构收集和分析数据。

数据公司不仅需要大量收集行业数据，而且需要确保数据的有效性和关联性，为客户提供有针对性的服务，使客户清晰地了解他们所面临的市场环境。

# 量化投资

大型的对冲基金会会建立自己的数据收集团队。专门进行量化投资的WorldQuant公司的康复数据分析和团队每年收集各种各样的的数据来为投资模型服务。

量化（Quant）特指金融工程师。

# 隐私泄露与数据霸权

许多原本不是做数据收集的公司从各个角度切入进来。Slice Technologies是一家提供网购App的公司，应用免费，但是要求用户开放邮件数据以供分析，然后把分析结果打包卖给对冲基金。

![](bbox=[0.07, 0.00106, 0.95, 0.00135])

中国的电信诈骗情况非常严重，隐私泄露的危险时刻存在。

拥有大数据的企业对用户的理解要比其竞争对手深刻许多，容易形成数据霸权。

由于百度搜索的存在，百度的 commiss 就可以充分地了解用户视频的喜好，这就比优土土豆拥有了巨大的优势。

数据霸权存在使其它中国互联网企业超越BAT的机会十分渺茫。

# 应对措施

鼓励开发差额数据以外的数据库，发掘许多“沉默”数据的价值。

培养更多从事数据收集工作的专业人士。

每一家公司都应该进一步深入思考目前掌握的数据的作用。
