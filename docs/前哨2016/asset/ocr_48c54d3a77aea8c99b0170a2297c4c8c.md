# 半年特刊 | 2016《时代周刊》：10项全球最佳发明

王煜全

昨天讲了全球科技前沿中改变了世界的发明，今天讲讲那些改变了我们生活的发明。

改变世界的着重点更多应该放在理论是否可行、技术是否支撑上，使得产品得以实现。

而改变生活，我们更多的是看中它对用户体验的捕捉，对技术的运用，尤其是对产品的设计和实现能力上。

而产品，更多的是强调可行性和量产能力。

《时代周刊》近期推出了2016年全球最佳的25个发明，我们从中挑出了最值得一说的10个，给大家作介绍。

和《科学美国人》相比，《时代周刊》更倾向于用户导向，因为它不是一个科技杂志，所以杂志中的评论人和普通用户的角度更贴合。

# 《时代周刊》中的10项发明

# 1、苹果的AirPods无线耳机

在苹果7发布的时候，这个无线耳机也一同发布了。它可以和iPhone自动配对，不仅内置麦克风，还拥有加速度传感器、光线传感器、甚至可以检测你是否在佩戴耳机，假如你摘下耳机后，它就会自动暂停播放，样式看起来也极酷。

其实，苹果并不是很多科技的原创发明者，但它是最懂得如何把科技整合进产品里来提升我们生活品质的公司。这一点，中国的企业尤其应该学习。

# 2、索尼的PlayStation VR

一个虚拟现实的头盔。现在的虚拟现实头盔有4条路经：

+   a.一体机，既有显示器，也有处理器。
b.只有一个显示器连到电脑上。
c.只有一个显示器连接到游戏机上。
d.显示器上面插个手机，利用手机作为显示。

我认为，这四条路经中，一体机的未来空间会更宽广一点，但是非一体机主要的市场就应该和游戏机结合，因为绝大多数用VR的场景，如今看来最成熟的就是游戏领域。尤其是一般游戏机的硬件技术水平很好，是能够使得虚拟现实得到更高体验的。

现在，在虚拟现实还不成熟的时候，这个头显设备需要上千美金，如果和家里已有的PlayStation游戏服务器连接的话，可以享受既省钱又好的体验。但据说，PlayStation的虚拟现实显示效果还是不够好。

所以预测硬件真正完全成熟还要等到2018年，现在还是一个前期的探索，但是总体来说，这是一个不错的方向。

# 3、大疆的Mavic Pro

大疆是全球无人机领域的领导者，也是中国无人机的骄傲。以前大疆一直是偏工业级的商用无人机，现在这款个人用的偏娱乐型无人机，虽然体积非常小，只有743克，但依然延续了大疆的特点，功能非常全面，避障、跟拍，而且是4K的拍摄，这是大疆的一个新突破。

大疆之所以有这个突破，和它一直坚持自主研发芯片有着关系。它的应用突破依赖的是在硬件上下足了工夫，有点像华为，我们甚至可以说它是无人机领域的华为。

![](bbox=[0.1, 0.00555, 0.7, 0.0063])

# 4、Flyte

一个悬浮在空中的灯泡。这个灯泡很聪明，把磁悬浮和无线充电设计到了一起。在电池的作用下，灯泡漂浮在空中的同时还能发电。

![](bbox=[0.2, 0.00775, 0.85, 0.0087])

# 5、耐克的HyperAdapt1.0

这是一双能够自动系鞋带的鞋，鞋底上有一套系统，当你把脚伸进去后，鞋底感受到压力就会自动系好鞋带。当然松紧不满意也可以手动调节。

![](bbox=[0.15, 0.009699999999999999, 0.65, 0.0106])

# 6、亚马逊的Echo

一款更加智能的音箱。从外观看，Echo和普通音响没有区别，但是实际上它内置了语音助手，可以听从你的命令，帮你开灯、关灯、找音乐，甚至订外卖。

![](bbox=[0.12, 0.01185, 0.85, 0.01315])

# 7、戴森公司的Supersonic

一个非常值得介绍的吹风机。戴森公司很了不起，它一开始其实是利用了一个喷气发动机的原理做了一款电风扇。理论上讲，这样的发明往往只是一个奇思妙想，形成的产品会缺乏系列化和后续研发的能力。
