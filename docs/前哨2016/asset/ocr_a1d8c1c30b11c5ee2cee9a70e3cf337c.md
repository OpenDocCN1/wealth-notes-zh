# 4.OTOY

OTOY专注于光场数据渲染与压缩，其光场流直播技术对于VR直播来说非常重要。该公司CEO Jules Urbach认为光场技术是VR的终极。

由于VR画面需要后期进行大量图形渲染，而光场技术恰好可以将真实拍摄和虚拟构造的3D信息进行数字化保存，因此可以通过后期处理，让VR电影和VR游戏达到最逼真的效果。

OTOY 在 今年 10 月 举行的 Oculus Connect大会前夕表示，在ORBX Media Player下一次更新的时候，光场流直播技术将会登陆Gear VR。

# 1.叠境数字科技有限公司

2016年5月由虞晶怡教授领衔成立，成立之初就拿到了4500万天使投资。

6月24日，在上海科技大学举办的SIST symposium学术会议上，发布了360° 3D全景实况视频拍摄转播。

![](bbox=[0.05, 0.0017800000000000001, 0.98, 0.002])

叠境数字主要专注于光场采集和成像技术的研究和产品化，为优质的VR和AR内容制作提供一套完整的光场解决方案。

目前，针对B端的需求，叠境已经推出了专业高清的光场采集和处理系统以及解决方案，在VR和AR的影视、购物、直播、教育、医疗、展览展示方面已经开始内容的制作和相关的合作。

在未来，针对C端的用户，叠境也会将光场的相关采集和显示技术同各硬件品牌厂商合作，以技术授权和合作开发等方式共同推出光场类的VR/AR头盔、光场摄像机等消费类电子产品。

与此同时，叠境也在建立VR/AR的内容平台，以B端的360° 3D直播、光场拍摄系统、内容解决方案和C端的光场头盔、光场摄像机作为切入点，围绕VR/AR内容平台，不断丰富和分发优质的VR/AR内容，打造一个完整的“光场VR/AR生态链”。

其创始人虞晶怡教授现为上海科技大学信息科学与技术学院教授，美国特拉华大学计算机与信息科学系终身教授，叠境数字董事长，他已获得美国发明专利10项，并于2008和2009年分别获得美国国家科学基金的杰出青年奖和美国空军研究院的杰出青年奖。

# 2.蚁视科技

蚁视科技成立于2013年，拥有一种“复眼光学技术”，就是模拟昆虫复眼，直接进行阵列式光场投射，这也是蚁视名称的由来。

蚁视CEO覃政曾表示，这种技术与Magic Leap在原理上是一样的。这个技术方向，蚁视早在2012年3月就已申请了国际专利。

2014年底，蚁视展示了一款HR光场眼镜，可以自定义还原景深。蚁视把HR定义为采用光场采集和显示技术做成的一体化头戴式方案。

![](bbox=[0.05, 0.00492, 0.95, 0.00508])

蚁视的HR眼镜，有一个要点，就是传统的增强现实或透过式显示技术，显示出来的虚拟图像，一般都是半透明地浮在空中的，而且亮度极高，让人难以发现它其实是半透明的；而HR显示技术，就有可能显示出亮度跟自然物体一样的虚拟物体，逼真度极高。

不过，蚁视CEO覃政同时也表示，以目前的技术水平，大规模量产可能还需等待很久。
