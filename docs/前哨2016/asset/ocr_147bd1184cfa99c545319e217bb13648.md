# 社会普遍看法的四个象限

著名投资人彼得-蒂尔（Peter Thiel）在《从0到1》中提出一个国家或社会的普遍看法可以分成四个象限：明确的悲观，不明确的悲观，明确的乐观和不明确的乐观。

周其仁教授认为历史演进的变数就来源于社会当中的人对未来的看法。对于未来悲观或乐观的看法将直接影响我们的行为，最终决定历史的演进方向。

# 明确乐观的典型

研究航天飞机的XCOR公司。即使NASA放弃了，这群创业者从15年前开始一直坚持到今天，可能再有一个一年时间，产品就要开始试飞了。

XCOR在NASA刚刚开放私人航天的时候就决定挑战航天飞机这个连美国航空航天局都没能做成的事情。只有一群非常乐观的人才会去做这样的事情。

Elon Musk一直推崇的Hyperloop公司用短短两年的时间就规划出了超级高铁的整个设计方案，就差合适的实验场所进行验证性实验了。而就在几年前，这些还是天方夜谭。

# 到底是机制重要还是人重要？

好的机制能够促进创新，但是即使在不利的机制之下，人照样能够发挥自己创造力，找到办法，扭转局面。创业的本质是推动大家去实现一个远大的目标，然而成功不易，过程艰辛，再好的机制也无法保证所需的动力，因此真正能够持续激励大家去不断挑战自我的其实是心态，归根到底是人。

身处戈壁的以色列之所以取得了全世界有目共睹的成绩就是因为他们非常坚定地相信未来会越来越好，进而在这样坚定、乐观的前提之下做出了艰苦卓绝的努力。美苏冷战时期的美国亦是如此，在苏联在太空领域领先的情况下，美国完成了超越。

# 肯尼迪用怎么激励了一代美国人？

登月可能没有任何实质性的商业价值，但是应该乐观地相信航天技术能够提升整个国家的科技实力，能够应用到很多其他领域，最终能够转化为商业价值，提高全民的福祉。

科技有可能会带来危害，比如战争，但是不管未来怎样，我们希望这个决定权在我们自己的手里，掌握主动权，而不是放弃，让别人来决定自己的命运。

# 全球视野，全球行动。

我们不光要具备美国肯尼迪时代的精神，更要有服务于全球的意识。不光视野是全球的，而且行动的立足点也不只是中国。

周其仁教授认为我们不要被制度束缚死，要真正地行动起来，经济的好与坏其实和大家的心态是高度相关的。

虽然美国有先进的科技，但是我们可以积极乐观地去和这些先进科技对接，我们可能不是科技的发明人，可是我们可以是最好的使用者。
