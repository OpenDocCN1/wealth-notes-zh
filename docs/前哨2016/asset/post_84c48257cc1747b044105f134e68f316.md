我们一般认为，无人驾驶会让我们开车变得更加容易，即使不会开车的人也可以开车到处走了。

# 托马斯·库恩的《科学革命的结构》

范式转移这个词从哪儿来？来自于MIT的教授，托马斯·库恩，几十年前写了一本书，《科学革命的结构》。书中回顾了历史上科学思维方式的重大变化，将它们总结出来后，称作范式转移。

时候，千万不要让你的思维方式落伍了。

很多人希望提出的问题能够直接找到答案。但这一轮科学革命的转折和变化，最主要是思维方式的变化，就是要容忍不确定性，因为未来本就是不确定的，每个人唯有将自己投入到不确定性当中，才能消除惧怕。

# 一些建议

结合这一轮人工智能的进展, 现在的趋势和以前有一点点不同。

+   1. 保持短期乐观，长期谨慎。

历史发展的趋势是，保持短期的谨慎，长期的乐观。因为短期总会高估科技对社会的影响，长期总会低估科技对社会的影响。

但这一次，人工智能反过来了。短期要乐观，因为近期人工智能已经可以迅速运用到各个领域中了，所以在各个领域里面，将会不断的出现新突破。但长期要谨慎，因为这一轮的人工智能突破依然没有揭示人类智能的本质。

真正伟大的革命都是不可预期的，尤其是范式转移带来的革命。你不知道它会从哪里出现，也不能预期它出现了以后会长成什么样，你只能提供所有的辅助作为支持。

人工智能造成的思维转变，最主要的是，我们要从运动员变成教练员。人工智能像个孩子，你需要去培养它。现在的程序员编程序，强调的是自己的能力；未来的程序员编程序需要有教练员思维，把人工智能当作孩子，培养它、纠正它、调整它，让它在某个领域里，最终能够成为专家，解决问题。

这种时候，人类需要培养出对机器的理解能力，对人工智能的理解能力越强，才能更好地驾驭人工智能，这些都是我们要转变的思维模式，不光要让机器懂我，更重要的是我懂机器。

+   2. 不需要和科技巨头直接碰撞。

人工智能需要大量的数据支持，但千万不要和巨头直接碰撞。做人工智能的上山下乡运动，到敌人兵力薄弱的地方去。那些没有用上人工智能的地方，那些数据最丰富的地方。和这些领域的专家进行交流，一同潜心训练人工智能，把它训练成最优秀的选手。那么，在这个产业中，你的经营就一定是能够成功的。

所以，我鼓励大家，带着大脑中的自我革命，形成你自己的范式转移，到人工智能还没有覆盖的地方去，到数据最丰富的地方去，你就一定会有惊喜。

# 全球科技新闻｜美国研发投入每年增长200亿美元

美国研发投入每年增长200...

# 一则新闻：

美国国家科学基金会最近发布了一则消息，美国的研发投入正在以每年200亿美元的增长进一步扩大。

其实，美国国家科学基金会一直在统计美国的研发投入，但是统计的数据往往会有一个滞后期。也就是说，这条新闻虽然是刚发布，但只是告诉了我们，截至2014年底，美国的科研和研发的整体投入是4777亿美元，年增长200亿美元。

为什么我反复强调科研和研发的投入，因为它们经常被弄混。国内经常出现一种情况，认为科研投入都是面向高校，但是美国的科研研发投入是分成三部分的。

第一部分是基础研究，高校居多。第二部分是应用研究，往往是高校和产业各一半。第三部分是产品开发，把高校的科研成果转化成一个可以上市的产品，这部分的主导者主要是企业。

# 从数据看，这三部分的投入大致是多少呢？

基础研究部分的投入是840亿美元，占整个科研研发投入的18%。
应用研究的投入是936亿美元，占20%。
产品开发投入是3001亿美元，占63%。

# 从执行者来看，钱究竟归谁使用？

产业研发投入3407亿美元，占71%。
高校研发投入647亿美元，占14%。
政府机构投入523亿美元，占11%。

# 从投入者来看，谁是投入的大户？

企业和投资基金的产业投入是3186亿美元，占美国整体产业研发开支的67%。
政府投入了1198亿美元，占整体投入的25%。其中投给企业的是226亿美元，投给高校的是647亿美元。

# 政府的作用是什么？

政府的钱占了基础研发的45%，占了应用研发的36%，占了产品开发的16%。
产品开发是美国的科研研发里面最大的投入，占整体的63%，但是政府在这部分相对投入会少一点。也就是说，政府确实是投入了基础研发和应用研发，但是产业的投入还是需要由产业研发支出出来解决问题的。

所以，一方面，我们要强调重视对研发的投入，才能完成科研转化成产品的步骤；另一方面，投入应该是政府引导，但主要还是来自于产业界本身，也就是要提升产业界对研发投入的兴趣。政府除了资金以外，相关的配套政策更加重要。

3A笔记

从整体看，从1953年，科研研发投入占美国GDP的1.3%，到1963年，攀升至2.8%。之后，随着政府经费的削减，1980年，科研研发投入收缩到不足美国GDP的2.1%。又随着产业研发投入的迅速增长，1985年以后，整个科研研发投入占GDP的比例稳定在了2.6%上下。

# 从趋势来看，政府投入一度大于产业投入。

最早时，整个科研研发主要是政府负担，但到了上世纪六十年代中期，达到了高峰，在肯尼迪政府执政的登月计划期间，政府对各种科研研发的投入达到了顶点。但是之后逐渐下降、回落。

# 产业投入其实也会促进基础研究，并不是说产业界都是短视的。

产业投入不仅投入在产品开发上，也投到了很多基础科研上。产业界给高校投入了38亿美元，其中23亿美元支持基础研究。产业界花了219亿美元在基础研究上，其中自己投入了197亿美元；花了534亿美元在应用研究上，自己投入了466亿美元。

国外的基础研究和应用研究的投入，基本上是个倒金字塔结构。基础研究占的比例较小，应用研究稍大一点，最大的一块是产品开发上的投入。政府比较偏重基础，企业比较偏重产品开发。

# 产业理解 | 美国创新系统的优势与问题

美国创新系统的优势与问题

王煜全

昨天给大家介绍了美国科技创新投入的相关情况，今天继续给大家介绍美国创新系统的整体架构。

以下是于货笔记，完整内容欢迎收听音频。

# 基础科研是必要条件，但不充分

中国一说创新想到的就是科技上的突破，但很多科学家一直在强调，科研比应用更重要，只是我们并不这么看，我们总认为，应用比科研更重要。

确实，如果没有基础科研，就没有应用化。但是在推动社会进步上，基础科研只是必要条件，但它并不充分。

我们以前听说很多科研成功的例子，比如贝尔实验室、施乐实验室，它们都做出了很好的成绩。但这并不代表集中实验室做科技突破的模式是成功的，只代表它没有其他可竞争的对手存在罢了。

以前，只有大公司和大研究所才有钱做并且做出成绩。但是，在1980年，美国推出了拜杜法案，使得不仅大公司可以做研发，小公司也可以。

我们甚至还强调，研发是基础科研产品化的一个过程。突然之间，大量的研发成果能够迅速被带到市场上。

# 真正的变化从拜杜法案开始

从字面上讲，拜杜法案的核心是明确专利所有权。

拜杜法案之前，很多科研是由政府赞助的，甚至在上世纪60年代，美国政府赞助的钱比产业赞助的还要多。因此，科研结果归谁所有，一直存在争论。

到了1980年，政府痛下决心，不管是谁给的钱，只要没有单独的法律合同约定，科研成果的所有权一律归高校所有。

其中有两个细节，和确权一样重要。

# 第一，原来转让专利很贵，所以大公司为了把专利买到手，甚至需要把整个实验室都买下来。但是在拜杜法案之后，转让不再是转让专利，而是转让独家商业权益，而专利的所有权依旧归高校所有，教授依旧可以继续进行研究。

# 第二，以前转让没有具体的细则，但是拜杜法案之后，转让只是转让商业权益，非商业的东西，教授依旧可以继续做。因此，高校有了更多的热情把专利商业权益转让出去，因为这并不影响继续做科研，而且教授也愿意这么做。

# 执行是关键

最为关键的是，因为有大量的专利可转让，价钱就会降下来，慢慢形成了一种约定，先支付一笔相对比较低的首付，到产品上市之后再收取产品的专利使用费，大约不高于产品销售价格的3%。

我们曾经专门将此和中国情况作了对比，其实中国也有类似于拜杜法案的相关法律法规。只不过，中国的情况更加复杂。

因为美国的很多高校相对独立，不管是公立高校还是私立高校，它的独立裁量权都比较大，有权经营自己的资产。而中国高校基本都是公立，确权基本归属高校。

但是依然有个问题，就是中国的高也...国家...所以它本质上并没有解决问题。

若要在...需要给高校更大的自主裁量权。

更重要的是，中国还没有形成这些实施细则。一方面，中国没有转让独家商业权益的操作；另一方面，在操作过程当中，中国没有形成国外的这种先支付低首付款，后面用收入分成来提取专利使用费的操作模式。

当然，这种模式很合理，但中国也不是不能学。关键问题是中国需要建立信用，要不然这种模式高校是不敢尝试的，因为一些国内的商业机构跟高校谈好了专利后，高校并不能监督你到底赚了多少钱，所以企业相当于在无偿地使用高校的专利，老跟高校说没卖出去，这就有...信用问题。

所以，现在绝大多数高校在碰到知识产权问题的时候，宁愿选择一次性交易，而一次性交易自然也就贵很多。

反过来，这就给那些真正希望拿到专利的诚信企业设置了很高的壁垒，以致它们拿不到专利。

美国之所以形成了开放创新的局面，不光有拜杜法案，还有全社会的诚信机制作支撑。

更关键的是，有很多能够互相配合的小企业，即使小企业以前拿不到专利，现在拿到专利授权后可以做科研了。但它依然不像大企业那样人才济济，依然需要从外界寻找相关人才。这种时候，就需要外界有足够多的支撑公司才行。

# 美国的问题、中国的机会

这些年，我一直在中美两国之间往返，有一个切身体会，当互联网的大潮来临时，中国更多的是看到了面向消费者的应用，但是美国真正推动社会进步的在于面向企业，它造成了大量小公司的独立运作。

大量有能力的企业部门中的员工都变成了独立的公司和机构，当它需要合作的时候，可以从外部获取所有合作，这也是中国暂时学不来的。美国的开放创新有一个完整的生态，它需要所有的长板积木都相互协作，形成大木桶，才能拥有最先进的科技企业。

但是在中国，既缺乏能够做科技转化的长板，也缺乏和这些做产品化的人相配套的长板。

因为中国的独立第三方合作公司还太少，整个生态不够完备。所以这也是为什么自主创新应该是目标，而不是手段。

> 我们当然希望中国能够自主创新，但不是在我们创新能力还不够的时候就强调自己做创新，而是应该像过去的制造之路一样，尽量和世界最先进的创新企业学习，学习人家创新的经验。

现在看起来，美国最可贵的创新经验就是由小公司负责完成高校科研的转化。我们就应该跟人家系统地学习，尤其是在转化过程当中是需要中国的制造经验的。这种时候，我们也就有机会跟人家学习了。学习到我们每一块板都能在中国具备以后，我们的生态也就自然形成了。

我们的制造业一开始时，...这...中国的手机厂商必须...的路。

正因为之前的跨国手机企业在中国...中国最终形成了完整的生态。

中国要从招商引资过渡到招商引技，下一步就是要向全世界学研发，重点就是向美国学习开放式的研发、积木式的研发。只要我们掌握了这一...未来一定是光明的。

他们同样对美国创新领域的技术转化做出了非常大的推动。

DARPA的推动中，最有名的当属互联网的发展和计算机图形界面的发展。近年来还有像Boston Dynamics公司的发展，就是得到了美国能源部大规模的资金支持。这些不同部门的政府基金支持，使得美国的众多小微创新公司，在各个不同的领域对整个科技创新有非常大的贡献。

美国的这些政策对于想要推动科技创新的中国来说，有很大的借鉴意义。下面是我的一些浅薄的简单的建议：

+   1、继续推进中国高校和国家科研机构的制度改革，并加大科研资金的支持。

我本人并不建议把一部分科研基金转化为研发基金。基础科研是所有创新的源头。虽然中国科研界的最大症结在于整体科研界的制度与风气，但如果想有真正顶尖的科技创新，加大基础科研的投入是必不可少的。

+   2、加大中国给小微创新公司的资金支持。

中国现有的给小微企业的科技创新基金从频率和金额方面来说还非常有限，更多的政府对科技行业的资金支持体现在地方性的政府政策资金，而这些资金不可避免地会和当地政府政绩挂钩，这直接导致了很多政府的资金支持更多集中在了，已经较成熟的技术或者是直接要扩大产能的项目中。

这种分散的地方性的政策补助也很难关注早期的科技转化，因为各地政府很难找到非常适合评估各个领域创新性技术的专家，也就很难实行公平有效的资金分配。这方面，美国的SBIR/STTR、ARPA-E、DARPA的政策设置非常值得借鉴。

+   3、企业方面加强对研发观念的理解。

中国高校和企业之前的断层较大，国内传统企业的企业家知道技术创新的重要性，但对突破性创新性技术的研发过程缺乏认识，导致缺乏长时间持续的研发投入。在整体商业和社会的的大环境下，会把资源更多的分配到短平快的项目上。

+   4、增加对海外高科技企业的关注，加大并购与合作的力度。

培育中国本土的高科技创新任重道远，很难短期见效，对较为成熟的国外高科技企业，在适当的时机进行并购或合作，是现阶段非常实际也行之有效的方式。

中国资本运营的国际化、中国企业深入融入到国际整体创新产业的体系当中，必须和培育本土的科技创新同时进行。

+   5、继续加强知识产权的保护。

创新与知识产权保护的关系就如自由经济体制与产权保护的关系，想加强发展本土的科技创新必须逐渐加强中国的知识产权保护。中国必须有壮士断臂的决心来逐步实现这一体制改革。

# 周末问答 | 国家应该给企业什么样的支持

国家应该给企业什么样的...

许多经济学家都认为政府不应该干涉 “无形之手” 的运作，也确实有不少政府怀着美好的向往过于干涉经济，而导致与初衷背道而驰的例子不少。

但在科研上，政府的协助确实能大大地加强科技的发展。但到了研发阶段，就是市场运作才能起作用的范围了。

王老师赞成政府支持和干涉研发的过程吗？您的观点是觉得政府的支持应该到哪一步为止呢？

王煜全

首先我们要明确一下政府的职能是什么。如果政府的职能只是政治的话，那确实是不应该干涉经济运行。但实际上，政府有一个很重要的职能就是推动经济发展。

在政治上，政府的动作应该相对慢一点。因为法律出来后是不能经常修改的，所以要保证法律是必须要正确的，因此会强调有效性，但是有效性就会牺牲效率。也就是说，为了保证一个东西出台了以后是正确与否的，你可能会牺牲效率，不能动作太快。

但是在经济当中，恰恰是需要强调它的效率，甚至为了效率会牺牲有效性。也就是说，允许作出错误决策，但是不能不作决策，你必须要在事情还没有明朗之前就要勇敢地去赌未来。

比如，我们中国政府成功地赌赢了未来的几个例子，一个是太阳能产业，一个是电动汽车产业。

现在中国电动车在全球已经是首屈一指了，中国的太阳能也拥有了全世界最大的太阳能企业。这些都是我们政府勇敢下注的一个结果。当然赌归赌，赌的基础是要刺激经济，要有效率，要能够做到效果更好。这种时候，我们还需要更多地研究，使得政府的调控不仅仅是大把撒钱，而是能够实际地产生刺激。但是毫无疑问，只要政府有责任推动经济发展，它就必须要去干涉经济。

在市场转换制造成的时候，国家的政策主要是开放，然后很多外企到国内建厂，如今制造要换来科技，王老师觉得政府是不是该给企业一个宽容的税收环境（国内的税率确实过高），适当地降低税率，如果可以的话，将企业盈利之后的钱用于研发，甚至可以不交税。关于企业税的问题，王老师怎么看？

王煜全

我觉得这分为两个方面。

一方面，我同意你的话，对于企业研发的钱可以适当地在税收上做些减免，这是合理的。

另一方面，关于大政策针的调整。以前，国家的做法是，对需要重点发展的行业领域都给予支持和政策的优惠。为了吸引外资，给了外资企业和合资企业很多优惠，所以造成世界五百强纷纷到中国安营扎寨。后来，政府对创业创新的企业也给予了各种扶植，造成创业创新企业层出不穷。包括科技创新企业，国家给予科技企业认定了以后，也给予相应的扶植措施，我觉得这些都是非常有意义的。这些都是政府在宏观上可以做的事。

但是，现在形势有些变化。

+   第一，世界五百强企业不再是创新的源头，所以给予它们的政策可能要做一些收缩。

+   第二，我们强调创新没有错，但是过去对于创新企业的认定相对简单粗暴，就是看公司里有多少个硕士，有多少个博士。

但是中国现在高校中的理科系，学术水平提升的很快，理科系在世界级的杂志上发表了哪些文章，成为了评定整个科室（包括个人）的学术水平的重要依据。因为在世界级的学术论文上发表文章，走后门的空间不大，也就能保证它的公正性。

我认为，我们从招商引资变为了现在的招商引技，所以更要强调科技企业。

所谓招商引技，就是必须做到国内外一视同仁，不能只将海归企业认定为科技企业。

另外，也不是看多少硕士，多少博士，实际上硕士、博士的含量是很难评估的。而重要的是看你拥有多少先进的专利。全球的做法不是直接买断专利，而是拥有独家商业权益。所以，当我们认定一个公司是否为高科技企业时，只需要对它的专利进行评估。

+   第一，专利尽量是国际专利，如果是中国专利，除非能证明在国际上领先。过去的研发太强调进口替代，但是随着科技进步越来越快，必须要强调全球领先。

+   第二，允许公司独家获得授权，不一定非得自己开发专利。所以，不管是中国企业还是外资企业，还是留学生回来创办的企业，只要在中国经营，同时能带着世界性的先进专利过来，我们就应该给予支持。

如果他说他得到了哪些高校的独家授权，那我们中国也比较容易评估，因为直接找人家高校就好了。所以，如果我们能够在开放原则不变的情况下，大致调整一下方向，从招商引资到招商引技，然后在细节上强调先进科技企业的优惠政策，就一定能够刺激我们的研发进一步发展。
