# 来自：全球科技新闻｜人工智能时代来了

这个时代肯定是离我们不远了，昨天单位安装了一套松下公司复杂的安全系统，派作为网络工程师的我提供支持，可说实话，我从头到尾只设置了个密码，其他一切配置全部自动完成，而且如果单位的空调系统是松下的，他还能完成智能温控。我其实都挺小心了，不跟上潮流就会被机器替代，但对于如何应对目前智能时代的来临，虽然一直关注且看了不少文章，但真还没想出什么具体的实施策略来。望老师有机会做些较为具体的指导。

> "人们不应该去做那些可以交给机器来做的工作。所有我们所学会的可重复的事情，都可以表达成一种公式、一种规则、一种算法。任何可以通过规则来表达的事情，我们都可以将其交给机器来做，机器的意义在于帮助我们处理那些可重复作业的事情。"

"这样，我们就可以将我们最珍贵资源——时间，用在那些不能重复的事情上。在大部分历史上，已建立的经济组织形式中人们都不得像机器那样工作。因此，机器可以解放人类被浪费的潜能。"
