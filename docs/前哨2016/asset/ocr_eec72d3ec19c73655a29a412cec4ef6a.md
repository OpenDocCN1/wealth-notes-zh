# 产业概况

显示产业主要是LCD和OLED两个领域的竞争。Micro-LED是新兴的技术，又叫μLED。

![](bbox=[0.15, 0.96, 0.85, 0.0011799999999999998])

LCD基于白色光线穿过彩色滤光器而发出不同颜色。其自身不能发光，使得LCD发光效率不会太高。

OLED每个像素都可以独立发光，色彩更自然。而且其工艺比较简单，同时具有超薄、可弯曲的特性。

μLED是在一个芯片上集成的目高密度小尺寸的LED阵列，它是一个超微型的LED。其像素从从毫米降到10微米左右。

# μLED的使用现状及应用

苹果尚未推出OLED屏的手机，其原因在于它的寿命和稳定性不高，大规模生产受限，所以现在主流的显示屏市场依然被LCD占据。

而μLED屏，可以主动发光，直径可以限制在10个微米之内，显示精度很高。

第一代iWatch是OLED，但可能下一代iWatch就会使用μLED，因为μLED在显示上比这个OLED发光率高且耗能低。如果采用μLED，意味着电池的续航时间可以增长数倍，所以μLED很被看好。

# 技术投资的难点

技术投资最难的是看准了技术，当它还没有机会大规模商用的时候，就被一个更优的技术代替了。

技术产品的成功充满艰辛，不光要考虑它技术的优势，还要考虑它在生产、制造商方面的成熟度，还要考虑有没有竞争性的技术，把它给覆盖掉，有运气的成分。
