# 未来很丰满

第一，虚拟实在电影、游戏、娱乐等方面有非常广泛的应用，甚至会改写格局。

在虚拟现实游戏里，会得到完全的沉浸感，会觉得不再受屏幕的限制，而完全生活在另一个世界里。

电影不再会受导演控制，电影这种叙事手法会发生革命性转变，从导演的客观视角为主，变成以观影者的主观视角为主。

第二，有很多和行业结合的机会。教育、培训、体育、技能培养……

# 现实很骨感

虚拟世界的实现，需要软件、硬件和内容。

首先说硬件，一方面现在推出的只是头戴显示器，简称头显。它的壁垒不够。

# 内容方面

最近有一个扩展现实产品很成功，就是Pokemon。

# 从行业切入也较难

行业本身的价值大于虚拟现实应用开发者的价值，拥有行业的专业内容，拥有行业的专业数据，比能开发虚拟现实应用重要。

结论：现在虽然虚拟现实概念很热，但市场至少要三年之后才启动。对创业者来说，如何熬过去，是当务之急。

# 创业者怎么办？

很多创业者，因为在旱季没有水，要坚持活下去，就把自己锻炼成了仙人掌。然后市场来了，雨季来了，到处都是水，仙人掌首先被泡死了。

虚拟现实创业者需要考虑四点：

第一，要找最大的机会。没有最大的机会就没有风险投资支持，尤其是风口到来的时候。最大的机会，一是对消费者。二是对大行业。

第二，从自己最有优势的领域切入，建立自己的优势壁垒。

第三，要尽量整合资源，使壁垒更强大。

第四，要尽量利用风险投资，利用虚拟现实的风口，大声地忽悠、大声地宣传，目的是多融资。
