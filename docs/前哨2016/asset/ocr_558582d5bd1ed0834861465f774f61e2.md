# 有20岁的科学天才，没有20岁的产业专家

我们不是要打倒硅谷，而是要找到新的趋势和模式。

趋势就是双长制，要有一个经验丰富的CEO，和一个首席科学家。

年轻人当首席科学家是一个非常普遍的现象。

做企业经营必须有经验，所以往往创业者年纪大，而科学家很年轻。

创业，必须要有经验积累。

# 下一个五百强

科技真正推动社会的部分，不是科学家，而是企业家，是最会把科技带到市场的企业家。

中国的企业家和地方政府，要明白：找到下一个世界五百强，而不是和现在的五百强去世。
