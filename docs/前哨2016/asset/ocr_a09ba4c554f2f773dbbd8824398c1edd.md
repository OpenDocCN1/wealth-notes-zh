# 个人进取先于制度进步

与其强调机制问题，不如强调个人的主观能动性，解决现有各种各样问题的关键是能不能找到出路，做出成绩。

机制不是一两个人能够改变的，空谈误国，实干兴邦。

海银资本投资的AngelList、Terrafugia等公司都是一方面积极地研发产品，另一方面积极地推动政府去改变政策。

不要担心制度问题，因为很多时候制度问题就意味着机会。如果制度是完美的，那创业的机会早被人利用了。

十年前，围绕中国移动做移动增值业务的创业公司正是这样的情况。

旧有的规则是创业者跳进来的第一天就应该理解的，如果你觉得搞不定规则，就不应该创业，跳进来创业，就应该在这个规则底下找到出路。

规则暧昧不清的时候才是创业者的机会，一定是化不利为有利。

# 中国特色的科技泡沫

在国外，只有当科技转化成产品，产品又获得市场认可的时候，这个科技才能被叫作一个概念。甚至，如果没有形成足够大的品类，没有足够多的公司参与，都不能叫概念。

比如现在Fintech是一个概念，从网上P2P借贷的Lending Club公司到比特币公司的繁荣，各个领域的金融科技公司才能形成一个Fintech这样的概念，而且很多公司不光盈利，而且市值巨大，是经过市场检验的。

海银资本投资的LightSail公司是压缩空气储能领域的翘楚，但是离产品商用依然还有两年的距离；投资的另一家公司Witricity是世界最好的无线充电公司，但是真的无线充电产品还没上市，就这样，中国已经有不少压缩空气储能和无线充电的概念股了。

中国的科技概念比国外早很多，一些概念在美国还没形成，中国就先有概念股了。

概念股的利益巨大，海外市场给予中国最好的互联网公司的市盈率远不如在中国上市的不是最好的互联网公司的市盈率。虽然哪个有水分，一目了然，但是不管估值有没有水分，它也是被一个市场共同认可的，这也就导致中国的上市公司愿意去炒作科技概念。

# 科技投资是战略布局

高科技投资的特点是投错了就是泡沫，投对了就是提前的战略布局，回报巨大。如果你投对了，甭管今天你花的钱贵不贵，估值高不高，在未来都是便宜的，都能赚钱。

科技泡沫好和坏的分水岭不在于有多少泡沫，而在于你投资的方向和对未来的把握是不是准确。

在全球，大公司都是有战略投资部门的，早早投资于小公司，为今后并购或者合作做铺垫。

中国企业很少有战略投资部门，投资方向大多是股市和房市，无法解决企业未来发展可能面临的战略布局问题。

# 中国企业的未来选择

中国企业想要获得全世界最前沿的科技，就必须在全世界做科技的战略投资布局。

海外的战略投资布局可以引发国内股价的增长。

![](bbox=[0.08, 0.0053, 0.93, 0.0060999999999999995])

战略布局的主导者应该是中国的上市公司，而战略布局的受益者就可以是中国的大全体股民。

更多的中国公司应该建立战略投资部门，对科技做战略投资，中国的股民也可以享受全球科技发展的好处。
