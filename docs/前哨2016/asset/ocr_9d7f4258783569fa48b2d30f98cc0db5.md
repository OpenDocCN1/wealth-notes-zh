# 朱世根教授简介：

1989年，朱世根获得清华大学工学博士学位。

曾任东华大学副校长，东华在中国纺织领域是最好的大学。

在铸造领域，朱世根已经申请发明专利26项，其中有15项已经获得了授权。

朱老师曾经有一个令人骄傲的小经历，中国曾经很长时间在纺织机械上用的缝衣针都需要依赖进口，因为针的硬度和韧性要求很高，而中国当时无法做出来。但是朱世根老师经过多年科研后，终于让中国摆脱了这种局面，现在中国市面上用的针基本都是朱世根老师的研究成果。

我们之前一直讲，美国大量的科学发明都由教授完成，企业家则负责将科研成果转化成产品推向市场。但中国还是缺了这个环节，那我们认为是否可以开始尝试让企业家和科学家联手填补这个短缺呢？

而朱世根老师作为科学研发者，还有两个特别好的条件。

第一个，我们都知道铸造行业本身就是应用科学，科研本身离产品生产就很近。全国有2000多家铸造厂，朱老师和其中很多家企业都有着多年的合作关系，所以朱老师不是象牙塔类型的学者，而是很贴近应用的学者。而转化主要是和产业对接，这就使得这门技术的转化会更加容易。

第二个，我们都知道现在的钢材成型最主要的做法是铸造，这其中就需要用到模具，把钢水浇到模具里成型，然后生成产品。但这个模具的做法目前还是非常污染环境的，因为它掺了煤粉子材料。意味着整个铸造过程中会释放出大量污染物，而全国2000多铸造厂，每个铸造厂相当于一个小型的污染中心。

朱老师发明的新型低能耗环保砂型铸造技术是他经过多年探索独创的。做铸造的砂不需要掺煤粉，铸造过程中不释放任何有害气体。既保证了环境不受污染，也保证了铸造车间工作人员的身体不受损。

朱教授作为中国铸造协会的副会长，干了一辈子子的铸造工作，是铸造业的大专家，现在将全部精力都投入到了发明的商用化上。

这也是我跟大家介绍朱老师的一个很重要原因，希望通过向大家求助，使得他的发明能够走向社会，被推广得更加成功。

# 环保砂特点及优势：

云溪环保砂是一种可直接造型的铸造型砂。不含煤粉，干净清洁，生态环保，节能减排，可取代传统潮模砂、粘土砂。生产的球铁、灰铁、铝合金铸件不粘砂、不冲砂、不夹砂、无气孔、表面光洁，成品率提高。铸造生产过程无污染、生产环境清洁、型砂可循环使用。综合使用成本低。

# 寻求的帮助：

+   1. 需要更多合作方的支持：这个产品最好的推广方法当然是在全国均匀布设环保砂型制造厂，在铸造相对集中的地方布一个厂，直接本地生产，就近运输，以解决当地的问题。那这就是全中国如何布局的问题了。

+   2. 产品希望普及市场：很多企业虽然知道朱老师的这个产品好，而且更换后价格基本持平，并不会增加额外成本，那为什么仍然没有被普及呢？因为朱老师的这个技术有个特点，就是无法逐步替代，必须一次性把老砂清掉，因为老砂含煤粉，不宜与新砂混合一起使用，让很多铸造企业感觉有沉淀成本。但其实沉淀成本并不大，比起起误使用新产品，迟迟不更换其实更不划算。

所以，如果有经营高手既能和这些企业充分沟通，谈及好处；也能够设计出好的业务模式，使铸造企业将原有产品痛快替代掉，让污染彻底停止。也 avions 不失为一个好方法。

+   3. 需要政策扶持：前段时间，中国雾霾严重，有些铸造企业被政府勒令停工三个月。所以其实铸造企业选择不更换砂损失是否更大了呢？如果政府能够有相应政策，更换环保砂的企业经过排放标准检测后，能够允许开工，这或许对企业会是一种促进。

同时，如果政府部门可以有一定的支持经费，将企业的沉淀成本补贴上，也不失为一个促进企业更乐意更换环保砂的好办法。

尤其是环保相关的机构或者发改委，如果能够听到我们的呼吁，能够看到环保砂对制造企业现有的污染大户做出减排的贡献，希望能给予一些政策，帮助企业能够更好地转型，治理污染。

在美国新兴了积木式创新机制后，科研成果层出不穷。但是我认为，一方面，中国在很多领域有自己的优势，尤其是中国干了很多年而美国又没有干的领域，所以，其实我们创新突破的机会比美国大很多。

比如咱们今天谈到的铸造，美国铸造使用非常少，主要依赖进口。中国作为全球的铸造大国，在铸造上突破的机会也就很高。

我们以前为了工业发展牺牲了环保，那么现在恰恰是解决环保问题产业升级的好机会。所以我认为，中国科研要想在全球走出自己独特 umbre 道路，就要和中国独特的产业应用相结合，让我们的专家为中国的产业科技升级做出独特贡献。
