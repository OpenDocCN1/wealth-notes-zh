# 无人机产业才刚刚开始

无人机产业是开源的，所以它的竞争核心不是零部件，而是整机生产。

无人机的量产能力小，很难用芯片构建核心竞争力。

整机厂商获取核心竞争力往往靠工业化能力。除了产业化能力以外，更靠经验，没有硬壁垒。

有先发优势，然后有大量用户、经验积累，形成滚雪球效应。

无人机的硬件部分，已不是大家关注的焦点。利用产品给用户提供什么样的服务成为焦点。

# 无人机的精彩未来

无人机的主要应用包括航拍、农业，能源管线巡线、漏洞检测、安防，军事。

+   1. 这些领域相对比较狭小，未来有更广阔空间。
+   2. 即使是这些领域，核心也不仅仅是行业解决方案本身，因为各行业自身没有对无人机的操纵能力，需要熟练的无人机操作人员。
+   3. 关键并不是解决方案，而是你有一整套完整的服务体系。

未来无人机的核心提升空间是人工智能能力。

当无人机具备特别强大的人工智能时，它能做的事，会超乎想象。

无人机的自动驾驶比地面汽车和海底无人潜艇的自动驾驶都容易。

+   1. 没有那么多目标。
+   2. 空气中的飞行控制系统较易实现。
+   3. 无人机的管制容易，会成为一个普遍标准。

# 无人机的黄金时代

无人机在三方面有巨大发展空间：

+   1. 在自身性能上，避障能力、承载能力、续航能力会有很大提升。
+   2. 配套上解决，使无人机在配套能力上有更大增强。
+   3. 无人机承载的功能模块会得到加强。如物流配送能力、监控管制、搭载充电系统、搭载物流系统、甚至搭载武器系统。

当无人机充分自动化，性能局限被突破时，续航能力在三五年之内有大提升，配套系统也会完善起来。

它最大的应用是物流配送，现在的物流还靠人递送，未来大多数靠无人机递送。

未来无人机可以自己进入电梯、到达目标楼层，出电梯以后，把货物放到家门口。

M2M，Machine to Machine。机器人可以操纵电梯，无人机操纵电梯不是匪夷所思的事。

《哈利·波特》里，每个主人公、小巫师都有可爱的小猫头鹰。未来每个人都是哈利·波特，有自己的小无人机。

无人机数量会超过城市人口数量，飞的机器比人还多。

# 无人机创业的核心

不是硬件，也不是基础服务，是想象力。

服务的创新是无限的，只要有充分的想象力、充分的实现能力，现有的硬件和服务都是良好支撑。

未来无人机的前景非常广阔，适合有想象力、懂先进科技的年轻创业者。

# 大数据的未来

大数据的故事很精彩。通过大数据分析，美国的Palantir公司帮助美国政府抓到了本·拉登。

未来大数据的核心叫“社会化大数据”，人和人的关系、人和数据的关系都要用数据关联和呈现。这就是为什么在美国很多人认为谷歌的价值不如Facebook。

通过对社会化数据的分析，我们能够对人、社会和商业有更加深入的理解。

惠普的高级副总裁Bernardo Huberman是全世界最早利用社会化数据进行大数据预测的科学家之一。

虽然LinkedIn用户活跃度很低，但是从社会化数据的角度衡量，它的数据非常有价值。

大数据的特点，关键不在数据本身，而是数据的洞察力。

![](img/62f292c8be3ac58da47a6d8773aab464_38_0.png)

# 大数据的壁垒

社会化数据有强大的壁垒，巧妇难为无米之炊，只要掌握了数据，即使分析能力不那么精准，也能实现一些匪夷所思的事。

+   社会化数据分两类。
一类是开放的，像Facebook。
一类是封闭的，像微信。

微信互动数据积累的信息和相互关系，除了腾讯，没有人可以掌握，更别说使用。

大数据门槛非常非常高。

今天，大家都知道数据里有金子，因此大多数公司会采取相对封闭的办法。虽然今天的掘金能力不强，但是守着这座金矿，不许别人来挖。

这种心态会阻碍行业发展，最优秀的专家未必有机会获得数据进行分析处理。

数据垄断的问题在未来会更加严重。

# 无奈的现实

美国著名企业家、发明家、《奇点临近》作者库兹韦尔，为了利用谷歌公司的数据研究人工智能，不得不加入谷歌公司。

数据是许多公司的核心资产，得到数据的唯一办法就是加盟谷歌和Facebook这类公司。

许多公司利用手机App和浏览器里的Cookie获取大量用户信息，持续跟踪用户的行为，但这明显是对用户数据隐私的侵权。

对过度要求用户信息获取权限的行为进行监管是早晚的事。甚至下一代浏览器不再支持Cookie，不允许第三方对用户行为进行没有底线的跟踪。

无奈的是，如果不采用这种方法获取数据，数据就会被大公司垄断，小公司则更没有出路。数据整合也因大公司的市场占比过高而困难重重。

![](img/62f292c8be3ac58da47a6d8773aab464_38_1.png)

# 可能的路径

自己生产数据。数据生产方式已经多样化，通过第三方采集+自己分析，有很强的优势。

把数据采集和分析结合起来，给用户提供完整解决方案。个性化服务是未来大数据公司真正的竞争优势。

# 我们的机会

大数据很精彩，但是得有数据才能创业。有能力却没有数据，未必能创业。

数据和人工智能的结合是最优选择。

挖掘更多创造数据的渠道，更多利用数据的方法，关键是数据和应用要充分结合。

# 股权投资那些事

很多人都关心股权投资领域，因为它确实能带来丰厚的回报。

股权投资不像二级市场的股票，随时可以买卖。一级市场投资获取回报的周期非常长。但也是每个希望实现财务自由人的必由之路。

股权投资是冒险，而冒险是成功的前提。

在投资领域，美国很多高校基金的业绩非常不错，它们"另类投资"策略的核心就是投资一些风险很高的项目，获取很好的回报。

认为股权投资风险很高，是传统偏差，是不理解股权投资造成的。其实股权投资的风险比股市要低。

二级市场的利润降低是一个趋势。

公司价值提升最大的节点是上市前后，而推迟IPO是目前全球的趋势，推迟上市创造出一个超级IPO，它们未来的成长性很有限。

公司价值提升的绝大部分被风险投资赚走了，股民只能干瞪眼。

![](img/62f292c8be3ac58da47a6d8773aab464_41_0.png)

# 股权投资的本质

股权投资并非纯粹投钱。

资本只想锦上添花、不想雪中送炭的逐利本质和公司的利益矛盾。

全球量化宽松的背景使资本呈现泛滥趋势，资本价值下降。

股权投资的核心不是资本，而是你拥有帮助对方成功的资源，资本只是背书和证明。

![](img/62f292c8be3ac58da47a6d8773aab464_41_1.png)

# 股权投资的现状

每个公司都有大量外部协作，去掉协作伙伴，很多公司的业务模式都不成立。这种生态型公司当然希望在股权上能和它的合作伙伴有关联。

现有股权投资很难做到，因为法律对未上市公司股东的数量有严格限制。

美国的Loyal3平台就在解决这一问题，让企业的合作伙伴在上市之前可以优先认购部分优先股，共享价值。

今天的资本需求相比过去发生了很大变化，但资本市场却没有相应变化，无法满足小企业生态化协作的需求，华尔街的投资银行制度明显滞后于产业界需要。

![](img/62f292c8be3ac58da47a6d8773aab464_41_2.png)

# 海银资本的逻辑与策略

对产业界的企业来说，最核心的是对产业阶段的判断。是研发初期?还是研发完成?是需要生产?还是需要扩产?是在解決量产能力?还是在聚焦全球营销?不同的时期需要的资本支持不同。

我们的海外投资不看是A轮还是F轮，我们看这个企业研发是否基本完成，正在寻找大规模制造业对接，凡是这个时候，我们就投资，帮它完成对接。

只有对积木式创新的生态环境形成更好支持，才能使投资回报真正得到体现。

我们提供和中国市场、中国资本、中国制造对接的机会。帮助美国高科技公司调整全球战略，使它能够获得高速增长，然后我们得到投资回报。

# 可能的机会

想做股权投资人，资金多少在其次，资本以外的价值才是独特价值，必须要用股权投资的方式锁定独特价值。

资本不够，甚至可以绑定别人的资本。

# 三种杯型

酒杯的种类很多，一般分成三大类。

勃艮第杯，圆圆的，看着像郁金香的花。因为勃艮第的酒香味比较复杂，这种杯型容易把香味聚起来。当你品味复杂香味时，能够有更好的体验。

![](img/62f292c8be3ac58da47a6d8773aab464_42_0.png)

勃艮第杯

稍微比它细一点、长一点的，叫波尔多杯。

![](img/62f292c8be3ac58da47a6d8773aab464_42_1.png)

波尔多杯

更加细长的叫香槟杯。

![](img/62f292c8be3ac58da47a6d8773aab464_42_2.png)

香槟杯

基本上记住这三种就可以了。这些杯子没有很大差异，大家也没必要那么精通各种酒杯的形状，或者是叫法。

# 持杯方法

很多电影里财大气粗的大佬们喝酒时的持杯方法是不对的，是明显的禁忌。这样喝酒说明你有钱，但是没知识。

酒杯在座和杯肚之间有很长的把手，这个柄就是持杯用的，因为拿住这里时，不会使酒的温度上升。所以正确的持杯方法是三个手指头捏着中间的柄。

![](img/62f292c8be3ac58da47a6d8773aab464_42_3.png)

持杯方法也有不同境界。只拿着酒的底部酒托也可以，因为整个手的距离显得更长，更流畅一些。

# 品酒建议

不要盲目迷信什么酒杯喝什么酒，多做实验，因为喝酒时，各种实验本身就是乐趣。

品酒的乐趣，不要迷恋在器具上，而要积极去探索，去体会酒后面有意思的部分。

# 什么是自我认知？

人是进化的产物，所以认知是进化的副产品。

首先人类只能通过自己的各种感官认识外部世界，只有通过眼耳鼻舌身，通过视觉、触觉、嗅觉、听觉了解外部世界。

这些器官同样是进化产物，进化的目的不是使我们真正了解外部世界的真实，而是使我们能够生存。

为了生存，认知系统会扭曲外部输入，或者形成错误印象，只要能使生存能力提升，认知系统不介意做这种扭曲。

认知系统会把很多我们觉得恐怖的东西，内化到我们的系统里面。

只有人类能认知认知系统，我们把它叫做元认知。其它动物可以通过认知系统了解外部世界，但人类可以反思自己的认知系统，可以觉知到，什么是真实外部世界的反应，什么会产生偏差。

我们对自己的认知系统有充分理解时，可以想象，当下次错误认知再来时，就可以事先提防，能使我们对外部世界的认知更真实，同时也使我们对自己的了解更真实，我们就会更幸福。
