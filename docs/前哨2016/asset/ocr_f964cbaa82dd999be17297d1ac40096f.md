# Salesforce

全球最大的客户关系管理(CRM)软件服务提供商Salesforce，近年来也开始部署人工智能。

已经收购了RelateIQ（智能管理系统）、PredictionIO（机器学习的开源服务器提供商）、MetaMind（深度学习）、Tempo AI（智能日历应用）、Quip、Toopher、EdgeSpring等9家与人工智能相关的企业。

Salesforce已拥有一个175人的数据科学家和专家团队，而深度学习企业MetaMind的创始人Richard Socher是Salesforce的首座技术官。

可见，Salesforce可以在现有服务平台上集成机器学习技术、深度学习技术、预测分析技术、自然语言处理技术以及智能数据挖掘技术等。
