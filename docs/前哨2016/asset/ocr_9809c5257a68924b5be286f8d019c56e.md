# 科技概念股 | 看各企业在新能源汽车领域如何布局

各企业在新能源汽车领域如...

王煜全

昨天介绍了科技概念股的电动车相关背景和整个产业链特征。

今天跟大家详细介绍一下各企业在电动车领域的布局。

以下内容为干货笔记，完整内容欢迎收听音频。

各大车厂布局分为两条路线：以特斯拉为代表的高端路线，以自主品牌为代表的亲民路线（因为掏不上号而选择电动车作为代步工具）。

# —— ◆ 国外市场 ◆ ——

# 1.特斯拉（纯电动）

特斯拉目前的产品线拥有Model X、Model S、Model 3和一款即将打造的电动皮卡，车型主要集中在高矫轿车和SUV这两个细分市场。特斯拉将推出更小型的SUV，与Model 3共享操作平台。

特斯拉第一款汽车产品Roadster发布于2008年，为一款两门运动型跑车。

2012年，特斯拉发布了其第二款汽车产品——Model S，一款四门纯电动豪华跑车，采用的是松下18650电池组，续航可达480公里。

第三款汽车产品为Model X，豪华纯电动SUV，续航里程高达469公里。

2011年，特斯拉推出了Model S敞篷跑车，虽然一次充电可续航240英里，但售价却在10万美金以上。

特斯拉最新款的电动汽车Model 3，基础售价为3.5万美元（22.77万人民币），0-60英里内加速时间小于6秒，带Autopilot自动驾驶功能，支持超级充电，单次续航346公里，预计2017年底发售。

# 2.日产

日产是电动车领域的先驱者。日产的新能源汽车技术路线一开始就押宝在纯电动方面，日产在1992年就开始了锂电池的研发。90年代中期，开始测试电动车Altra。

截至2012年，雷诺-日产联盟用于电动车方面的投资已超过56亿欧元。

自从2010年上市以来，日产聆风成为了全球销量最佳的电动车。截至2015年12月，日产聆风销量突破20万辆。2016年的上半年，全球聆风累计销量达27151辆，成为最受欢迎的车型。

在完全充电情况下，可实现160公里以上的续航里程。采用220伏家用交流电，大约需要8小时可以将电池充满；而10分钟的快速充电，便可提供其行驶50公里的用电量。

2016款日产聆风取消了24千瓦时的电池组，搭载全新30千瓦时电池，续航里程相比之前增长27%，最大续航里程可达250公里。升级后的聆风电动汽车起价突破3万美元。

据悉，新一代日产聆风电动汽车将于2018年问世，搭载不同的电池组选择，最高续航里程可达340英里(约547公里)。

# 3.宝马（纯电动+混动）

宝马在电动车领域的研发已经走过了40多年。

2008年，宝马通过Mini品牌推出了电动测试汽车，该款车充电一次可以开大约160公里。

2010年，宝马推出电动车ActiveE。锂离子电池组容量为32千瓦时，可为ActiveE提供160公里的续航里程，使用220伏/32安电源充满电量只需4-5小时。

2011年，宝马发布i系列，宝马i3于2013年投产，如果不考虑汽油引擎扩展里程，汽车可以行驶114英里（约183公里）。i8是宝马推出的一款电动跑车，当汽油引擎和电动引擎混合使用时可以行驶330英里（531公里）。在纯电模式下可以行驶15英里（24公里）。

根据宝马集团的规划，未来每一款产品都会推出插电式混合动力车型。2018年，BMW i8 Roadster也将问世。2021年，宝马还将发布一款旗舰电动汽车——iNEXT，这款汽车将配备自动驾驶功能，并采用全新的内部设计。

# 4.奔驰戴姆勒

奔驰去年跟戴姆勒集团共同斥资64亿美元，研发低排放技术的项目，充分说明了未来几年奔驰新能源车的计划。

在2016年巴黎车展上，smart发布了全新fortwo、forfour和敞篷版的纯电动车型，三款车型的续航里程均为160公里。2017年，smart将提供一套快速充电装置，使得充电时长减少40%。

奔驰近日还表示，将在2017款的S550e混动版上，应用无线充电功能。据悉，这套无线充电系统的能量转化率可达到90%。

# 5.腾势

腾势是由比亚迪和戴姆勒共同设立的合资企业，于2010年正式成立，整合了比亚迪的动力电池技术、驱动技术和戴姆勒的整车制造科技。首款产品于2014年9月上市。

最新款“腾势400”所搭载的磷酸铁锂动力电池，由原来的47.5千瓦时升级到62千瓦时，续航里程提升至400公里。

# —— ◆ 国内市场 ◆ ——

# 1.BYD（混合动力一家独大）

比亚迪汽车去年是全球销量冠军，今年上半年在全球十大畅销车型中占据三席，分别是比亚迪唐、比亚迪秦、比亚迪E6，在国内市场更是处于领先地位。

比亚迪秦的月销量保持在2000辆左右，而比亚迪唐自推出后，月销量一直都稳居3000以上。

比亚迪唐是第一款国产的混动SUV，百公里耗电29千瓦，纯电续航达85公里，电池容量18.5千瓦时，满电满油续航达800公里。

2012年，在中国新能源政策不明朗的情况下，比亚迪率先推出了续航300公里的电动车e6。

2015年10月，续航400公里的比亚迪新e6正式进入北京市场。

续航方面，比亚迪的铁电池（磷酸铁锰锂电池）技术已经是世界领先。

# 2.北汽（纯电动为主）

北汽新能源致力于纯电动汽车发展，目前已经推出EV、EU、EX、ES等系列纯电动车系列，包括EV160、EV200、ES210、EX200、EU260、绅宝X25纯电动小型SUV等。

今年新推出的EU400，续航里程将达到360公里。

# 3.互联网造车 Pitt

LeSEE超级汽车 产品预计上市时间：2018年

今年4月20日，在乐视体育生态中心，乐视向全球发布了乐视超级汽车。乐视超级汽车的品牌名称正式定名为“LeSEE”，Le代表乐视，SEE代表“乐视超级电子生态”，号称是“完整的汽车生态系统”，这是推动乐视造车的核心理念。

蔚来汽车 产品预计上市时间：2016年底

NEXTEV蔚来汽车由互联网企业和企业家投资创建，包括领先的互联网企业腾讯、易车创始人李斌、汽车之家创始人李想、京东创始人刘强东，以及知名投资机构高瓴资本共同发起设立，是一家从事高性能智能电动汽车研发的公司。
