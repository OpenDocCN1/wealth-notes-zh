# 产业理解 | 我也反对全球化

我也反对全球化

王煜全

我们今天继续接着上周的话题，讨论一下产业理解里面的全球化问题。

首先我要站出来说，我是旗帜鲜明反对全球化的，这和大家的认识可能比较相反，虽然现在主流的观点认为全球化有各种各样的好处，但实际上我认为全球化还是有着很多问题。

现在我们来对全球化做一个深入地解剖，看看中国是否真的需要推行全球化，还是另有他路可走。

以下是于货整理，完整内容欢迎收听音频。

# 全球化的主导者是经济大国，更是科技大国：

我们说全球化的主导者都是经济大国，但是经济大国背后的本质是科技输出国。你的科技水平足够高，才能够把商品卖到全球各地。

全球化的主导者不是善人，他们的目的是把自己的商品卖到更多的国家。

福布斯有一个全球2000强公司的排名，其中中国占了200家，美国占了540家。除了中美之外，再没有一个国家超过100家公司。

中国在里面排名靠前的公司主要是大国企，比如传统的银行、房地产，而科技类、制造类的比较少见。而美国排名靠前的公司主要是科技类，因为美国是世界上最大的科技输出国。

其中岁数最大的微软公司是41岁成立于1975年；第二大的是苹果公司，也只有40岁，正值壮年，成立于1976年。年龄最小的是世界排名第五的谷歌，成立于2004年，现在只有12岁。

即使是后五名大多也是和科技高度相关的，过去都曾是科技的领导者，只不过现在因为新兴科技公司起来了，所以它们在科技领导力里面有所下降。

根据这个排名，我们发现了一个特点，我们真正能向全球输出的主要是科技，并不是其他签名资源，只有科技才能塑造一个国家的持续向外输出国的能力。

> 中国一直被叫做世界最大的科技产品输出国，但其实强大的科技制造业才是中国经济繁荣的基础。

因为中国科技企业的体量相比国际企业，还是比较小的。中国的经济走到今天是靠着我们强大的制造业，尤其是科技制造业，为全世界的科技公司制造产品，然后卖到全世界。

在这个过程当中，我们掌握了一些相当不错的科技制造实力，创造了自己的品牌，而且很多东西能够卖向全世界。所以，强大的科技实力制造业，才是中国经济今天繁荣的基础。

> 为什么有了这个基础，却仍然没有促成我们拥有巨大的科技制造企业公司？

简单来说，就是中国的全球化进程中，各家正在瓜分制造业的利润和家底，如果产业结构不调整而我们还要继续全球化，并且让制造业冲在前面，那么我们的未来其实会更加危险。

所以不是不要全球化，而是先要调整好内部结构，然后才能全球化，内部结构没调整好，盲目地全球化，我认为中国现有的结构尚未调整好，所以不适合全球化。

# 全球化的经济需要全球化的政治和文化：

过去的全球化的模式走到今天，其实是走不通的。

二战以后到冷战结束后延续的一段时间，也就是两大阵营的阶段。虽然以柏林墙倒塌作为一个标志，很多人认为这是冷战的彻底结束，但其实苏联的那个阵营并没有完全地坍塌。

> 当你做政治思考的时候，更在意互惠互利，你会更愿意结盟，更愿意去输出利益以换取利益；而当你做经济思考的时候，往往缺乏互惠互利性。跨国企业更多的是想从别处获取更多价值和利益，往往忽视了培养当地经济的发展。

所以说，经济思考和政治思考是有明显冲突的，甚至政治思考里面如果没有了强大的竞争对手，一个国家就会转而进行经济思考。

而美国现在的国际化、全球化已经是经济主导，而不再是政治主导了，因为它已经缺乏了政治的制衡。
