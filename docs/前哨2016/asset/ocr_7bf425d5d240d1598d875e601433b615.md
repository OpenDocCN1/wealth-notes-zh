# Betterment和Uber合作

Betterment是著名的在线投资服务公司，目前管理超过17.5万客户投资的超过50亿美元的资产。

![](bbox=[0.05, 0.78, 0.95, 0.95])

2016年8月24日，Betterment和Uber合作为司机提供退休账户的资产管理服务。

Betterment和Uber的合作是双赢的选择：Uber避免了法律纠纷和司机抗议，而Betterment获得了客户并扩大了资产管理的规模。

# Betterment和Wealthfront

Wealthfront一直是Betterment的竞争对手，由于Betterment没有最低投资数额的要求，因此Betterment更适合Uber的司机们。

Betterment每个账户的资产数额是Wealthfront的一半，而用户数量则是Wealthfront的2.6倍。Betterment采用低门槛的策略来积累用户数量。

在线智能投顾行业的“头部效应”明显，目前Charles Schwab，Betterment和Wealthfront公司分别前三名，2016年9月，行业前两名的资产管理规模占整个市场规模的63%，行业集中度越来越高。

在线智能投顾行业的壁垒不高，未来，小公司和新公司只能从2C向2B转型。
