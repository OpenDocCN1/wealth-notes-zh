# 柔宇科技

国内最出名的企业要数柔宇科技了，创始人刘自鸿在清华攻读了本科和硕士后，用三年时间在斯坦福拿下了博士学位。在国际知名企业干过几年后，和斯坦福的博士同学回国创业，建立了柔宇科技。

根据资料显示，他们的柔性显示屏和三星类似，使用的是AMOLED的技术架构。只不过三星生产的是固态曲面屏，强调曲面，而柔宇科技更强调柔性。

研发产品——

因2014年开发出了0.01毫米、卷曲半径为1毫米的全球最薄柔性显示屏而受到关注。

# 京东方

京东方着手柔性AMOLED研发始于1998年组建的AMOLED研发小組；2001年成立了实验室。目前，柔性产品已推出一系列的显示产品。
