# —— 国内外 的区别 ——

+   1. 中国在大型的一体化开发机器人上，仍然还有一定落后。比如我们和Pepper、ASIMO这类机器人相比，活动能力还不够领先。尤其是像ASIMO这类拥有足够强运动能力的机器人，世界上还不多见，中国现在还见过两足能够自主移动的商用机器人。
2. 从机器人的个性化出发，中国并不输给国外。例如酒店送餐的服务型机器人，中国做得很好。这类机器人其实考验的是我们的集成能力，而中国最大的产业优势就是产业集中度。所以这也是未来的中国机器人公司应该走的一条路，虽然在自主一体化上与其他国家存在差距，但我们只要找到了某个应用领域，深度应用需求，在单项上领先，中国是可以超过国外机器人公司的。
