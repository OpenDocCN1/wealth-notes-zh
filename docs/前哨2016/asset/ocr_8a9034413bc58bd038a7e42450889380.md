# —— ◆ 总结 ◆ ——

+   1、传统的汽车制造商已经纷纷布局自动驾驶。这些车企由于不希望将主动权交由科技企业，避免沦为代工厂的身份，通常选择联合汽车零部件厂商和互联网企业共同开发自动驾驶技术。

+   2、从各大车厂的日程表上看，2020年是个很关键的节点，不少互联网巨头和传统车企都把2020年视为推出高级自动驾驶汽车的商业突破元年，从此进入爆发增长。1人笔记

+   3、以谷歌为代表的科技企业，此前的策略一直是自主造车，但由于各种阻力，特别是在谷歌宣布放弃自主造车，改和传统汽车制造商合作后，预计越来越多的科技企业将选择与车厂合作。

+   4、近年来，汽车厂商和汽车元件供应商一直在追逐科技创业公司，以提升它们的车载连接性和加速无人驾驶汽车项目的开发。传统汽车制造商对于人工智能和自动驾驶创业公司的并购将进一步加快。

+   5、越来越多的自动驾驶研发公司认识到高校科研人员的重要性。例如丰田雇用了MIT、斯坦福大学的教授，宇通集团选择中国工程院院士李德毅合作造车，Uber挖走了大批卡内基梅隆大学的研究人员。各大车厂争相抢角，希望把最优秀的人才招致麾下，这也充分证明了自动驾驶领域的热度。

+   6、商业模式的转卖。可以看到，很多汽车生产厂商选择投资并联合汽车共享服务提供商，借助共享服务商的力量加速自动驾驶网络的布局。未来汽车的模式一定不是今天的生产销售模式，而是分时租赁模式，而汽车产业的重点将会从制造企业向服务企业转移。1人笔记
