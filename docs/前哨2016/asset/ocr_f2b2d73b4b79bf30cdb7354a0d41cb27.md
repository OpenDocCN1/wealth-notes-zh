# 自我认知-什么叫自我幻觉？

王煜全

以后每周的周末两天，我会开拓两个新“领域”，周六是“红酒知识”，周日是“认知开拓”。

这两块内容看似和你想了解的海外高科技没有什么关系，但实际上有更深层次的联系。

其一，“红酒知识”可以让你了解它背后蕴含的西方文化、折射出的礼仪、带给你的愉悦以及生活质量的提升。在另一重认知维度上，轻松愉悦为你打开一扇重要的文化之窗。

其二，我们对自己的真正理解不能建立在书本的理性知识上，而要建立在非理性的直觉基础上。

“认知开拓”致力于把认知科学结论转化为日常的训练，帮助你解决这些问题。它依托于认知科学研究成果，方法论也从多年实践中衍生。

关键不光是知识，更多地是实践的方法。让你在了解这些知识的同时，在自己的日常生活中活学活用。

和你的前哨一起，认知升级、认识自己。

# 自我

“自我”是进化来的，有它的存在价值。

自我是对自己的一个扭曲认知。几乎所有人在自我认知上都会认为自己比真实的自己要更好、更强大、更有能力。只有抑郁症患者能够真实地认识到自己的能力。

# 自我对进化有利

在进化当中，对自我能力进行放大，是有利的。

绝大多数动物，实时反馈是高效的。但是延时反馈往往低效。对人来说也是如此。

自我放大了远期的恐惧，使我们能够提防延时出现的恐惧。更重要的是放大了远期可能的好处，使我们愿意去追求它。

人类就是因为有自我的“我执”，所以为了万分之一的梦想，每天不断地做着延时反馈的努力。

我们要正确地认识自我，不要认为它全是坏的，都是贪嗔痴。也不要认为它全是好的，客观地反映了自己。

自我是一个进化的产物，你理解了它的来龙去脉，理解了它的工作机理，就能够客观地不带情绪地看待自我，也就能离了解自我更进一步。
