# 产业理解 | 传统跨国企业的“七宗罪”

传统跨国企业的七宗罪

王煜全

昨天的产业报告《谷歌战略》中提到，最近谷歌的战略发生了极大变化，不再以创新研发为主导了。

虽然谷歌是大公司，但它的岁数可不大，1998年成立的谷歌，现在才18岁。

哈佛商学院的克里斯坦森教授写了一本书——《创新者窘境》，他一直致力于帮助大公司走出创新者的窘境，但是我认为这条路走不通。

为什么呢？这就是我今天要讲的，传统公司一旦出现以下七个问题，创新就无法再延续。

# —— “七宗罪” ——

# 第一宗：人的异化

一家公司壮大后，随着员工数量的增多必然出现官僚主义。

官僚系统存在的问题是，它只强调了每个人要像螺丝钉一样，共同发力，使得整个机器正常运转，因此人会变的异化。

但是，在今天这个特别强调个人创新的时代，每个人都要找到自己的长板，找到自己足够强的优势。而大公司的系统里，它并不关心你有没有优势，而是关心你能不能像螺丝钉一样嵌入系统良好运转。

但今天的创新越来越个人化，最典型的例子就是J.K.罗琳：

J.K.罗琳在过去被认为是一个典型的失败者，她是个单亲妈妈，没有工作，家里连暖气都付不起，所以她只能到咖啡馆去写作，蹭点咖啡馆的暖气。直到她作出《哈利波特》后，才登上了世界女首富宝座。

# 第二宗：创新乏力

创新是以人为核心的，但随着人的异化发生，企业的研发效率自然也开始变低，只能按部就班的做些微创新工作。
