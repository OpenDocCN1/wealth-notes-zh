# 全球科技产业报告 | “分水岭”大时代

“分水岭”大时代

今天选了一份报告和大家分享：企鹅智酷的《中国科技&互联网创新趋势白皮书（2017）》。

这份报告篇幅很长，有140多页，涵盖了四大领域：资本、技术、用户、全球化，十大产业趋势：移动直播、智能手机、媒体与内容、移动支付、社交网络、旅游、电子商务、互联网影视、虚拟现实、出行服务产业。

这份报告除了对趋势涵盖的非常全面以外，也请到了诸多的业内牛人作分析，他们分别来自于产业界、投资界、技术界等，都是中国最高水平的专家们。

因为篇幅太长，我主要挑出了其中三个重点，跟大家作个解读。如果大家有时间，也可以通读一下这份报告，还会有很多收获的。

# 用户调查是腾讯最擅长的

首先，虽然企鹅智酷报告邀请了许多专家，但是用户调查才是腾讯最擅长的。我们都知道腾讯从QQ发展到微信，用户覆盖是最全面的，而且用户对腾讯的感情也很深厚。这种时候，对于用户调查所覆盖的准确度都比较有保障。
