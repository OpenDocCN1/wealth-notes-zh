# 无处不在的预测

基于社会和舆情数据做的预测是相当可靠的。比如一部电影最终的票房成绩和这部电影首映前在社交媒体上的热度是正相关的，越被热炒，就越容易有好票房，但是和这部电影的好评比例是无关的。

预测最重要的是以数据、模型和事实为依据。

美国总统大选预测的背后同样有大量科学的运用。

Nate Silver是美国著名的棒球和选举分析统计学家，他现在是ESPN旗下FiveThirtyEight的首席编辑和ABC新闻的特约记者。《信号与噪声》是他的代表作。

他成功预测了上一届美国总统大选的结果，甚至各个州的票数对比都被预测得相差无几。可是在这回他在Donald Trump的预测上翻了船。他分析错误原因一是数据量不够大，二是党内提名比总统选举复杂许多。

《华尔街日报》上周刊文说到，现在Facebook可以根据一个用户在不同政治文章上对like键的点击分析出该用户的政治倾向。

了解到一个流行观点，要弄清它的出处，结论的可靠性，才能避免误判。

SurveyMonkey成立于1999年，是一家在线民意调查服务提供商，它们对上一次英国大选的精确预测使其名噪一时。它们认为Hillary Clinton有较大赢面。

预测和博彩一直形影不离，连CNN都设立了预测大选的网站，让大家在预测大选的时候还能赌赌运气。CNN网站上Hillary Clinton的赢面很大。

# 如影随形的影响

Duncan J. Watts是微软研究院首席研究员，代表作是《一切显而易见》，书中提到影响一个人实际上要比大家想象的简单，只需要巧妙地设置一些数据就会对选民的投票行为造成影响。他通过一个叫作平行历史的实验佐证了他的观点。

政治选举不用推送广告，利用现代社交工具中用户的信息不对称，候选人团队可以将有利于本方的观点推送给选民，巧妙地造成认知偏差，从而左右选举局面。

最经典的案例就是2008年的美国大选，奥巴马团队利用Facebook筹集的小额政治捐款成功在竞选经费上超越对手，同时也通过有针对性的推送，说服摇摆和不支持奥巴马的选民支持奥巴马。

Chris Hughes是Facebook的联合创始人和新闻发言人，2007年，他从Facebook辞职加入了奥巴马的竞选委员会，帮助奥巴马做社交网络方面的竞选营销。

# 关注的原因

科技的渗透使许多应该是公正的重大问题变得不过那么对劲了。

电视的兴起成就了肯尼迪，而社交网络的兴起成就了奥巴马，科技对政治其实有着很大的影响。

科技的突破可以转入民用，给老百姓带来福利。总统选举正是一个试验场，各式各样的科技手段八仙过海，各显其能。在实现选举目标的同时，也可以进行大量的商业运用。

Gallup公司原来就是做民意调查的，然后把政治上的能力转换到了民用的商业调研上，成了全世界最大的市场调研公司之一。

未来一定是属于科技的，未来科技在政治上起的作用要比今天大得多，未来法律法规、政策在执行前可能都需要做模拟实验，拍脑门是不行的。

网约车其实可以部分解决短期就业的问题，但是新规则用基于户籍的方式变相的采取地域歧视政策制约了它的发展，令人觉得不可思议。
