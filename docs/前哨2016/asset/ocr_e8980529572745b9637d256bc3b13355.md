+   - Carmichael是North Bridge的投资合伙人。他的演讲内容非常棒，总结起来，有两个其他地方听不到的重要特征——有关创业和投资的改变。

+   - 第一个特征，private IPO，也就是私人IPO。我们都知道IPO是一个公共行为，指股票上市交易。而私人IPO是指融资额甚至超过了上市水平，但依然是私人公司。他们还是继续用投资的钱来支撑公司运行。细看就会发现，投资的钱不完全来自风险投资，因为风险投资没有那么大的额度。首先是来自于很多PE基金投资，也就是private placement，或者叫private investment。其次来源于传统上比较保守的投资基金，原来不投未上市企业、只投上市企业的这种基金。比如说像养老基金和共同基金，以前它们是不投未上市企业的。但是现在这些企业已经大到足以上市了，它只是不上市而已，这种时候这些共同基金、养老基金也对他们进行投入。而用IPO，也就是用上市融资的办法来解决发展问题的技术公司日趋减少。这是一个趋势，就是大型公司越来越推迟上市，或者干脆不上市。

+   - 第二个特征就是有大量的小公司出现。在美国2013年出现了32个天使投资基金，但是到2014年，新成立了131个天使投资基金。这些天使投资基金募集了超过15亿美元，每年有上万个新兴的小公司得到天使投资，能够继续走下去。但是我们也能看到，只有大概1%的公司能热到非常大，其他公司都死掉了。所以Carmichael称其为A轮断崖，很多公司是拿不到A轮的，更别说后面的B、C、D轮。甚至说绝大多数公司都拿不到A轮，这对小公司来说是很大的挑战。

![](bbox=[0.06, 0.0030299999999999997, 0.96, 0.0035800000000000003])

+   - 从Carmichael的分析里得到两个重要结论，一个是关于企业的，就是说绝大多数企业拿不到A轮。那么很多企业从创始的第一天就要考虑，我如何从小做大。如果你没有做大的机会，没有一个巨大的市场和目标，那别人根本不会考虑投资你。所以这种时候，你一定要志存高远，一定要好目标，才能拿到后续的投资。当然同时你的实际操作也不能耽误，不能没有实现的手法。就是既能够打好眼前的仗，也要志存高远，对企业的要求明显增加了。

+   - 另一方面对投资的要求也改变了，以前很多保守型基金，他投二级市场。但是现在很多企业不上市，或者推迟上市。那么这种时候，二级市场的收益会明显减少。因为二级市场的股票增长其实主要还是要靠成长性，等到人家上市的时候，企业已经很大了，成长性很差，这种时候股票的回报就不会很好，股票的增长性也就不会很好。所以很多基金改变了做法，从二级市场挪到一级市场，就是投未上市企业。

![](bbox=[0.06, 0.00477, 0.96, 0.00522])

+   - 比如说，美国做得很成功的耶鲁高校基金，由于管理得当，短时间之内增值非常快，成了美国整个投资基金的翘楚。那高校基金的秘密揭露出来其实也很简单，就是它从原来的传统的保守配置加大了另一类投资，叫做Alternative Investment，也就是另类 Stack 投资布局。所谓另类投资就是未上市企业投资，他们甚至加强了对中国这样不是很熟悉、对他们来说风险更大的市场里面的未上市企业的投资。当然现在看中国风险未必那么大，但当时这种投资决策是冒了风险的，不过回报也很好。所以对投资来说，大量投资家从过去传统的二级市场保守投资改到更激进的做法，做一级市场投资。

+   - 最后给大家一点建议，现在的财富增长最快的是做企业。小企业做大，增长非常快。或者投企业，如果能投中一个成长迅速的企业，增长非常快。但是不管你是投企业还是做企业，一定要瞄准一个大市场，解决一个大问题，真正能够为社会带来足够的利益，你自己的利益也就能保障。所以总结一句 话，作为一个希望能够对社会有所贡献的人，或希望借此提升自己实力、改变自己命运的人，要么加入创业公司，要么投入创业公司。
