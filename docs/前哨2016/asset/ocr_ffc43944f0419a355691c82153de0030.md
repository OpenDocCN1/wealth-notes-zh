自我觉知如何训练？

# 自我觉知的特点

自我觉知很容易受干扰，很重要的一个干扰是情绪，比如饿了的时候，只要看到美食，那觉知也会因此而变化。所以我们的觉知很容易误导我们。

所以我们要把情绪屏蔽掉，才能如实地看到这个世界的变化。

# 自我觉知的训练

第一个，觉知的特点是会对变化有更多的了解，当你坐车的时候，请你把眼睛，没有目标地看着窗外，觉知你的眼球被什么东西吸引了。到底是被静止的路边的东西吸引，还是被路上的动的东西所吸引。如果是动的东西到底是大车对你吸引力大，还是一个很破的这个自行车对你吸引力大。你会发现，原来我看东西的时候，眼睛总是不自觉地会被某个东西所吸引，时间长，甚至也就找到了自己被吸引的规律。

其实我们人类有共性的规律，但是每个人又会有自己的不同，取决于你对一件事情的重要性判断，所以这是第一个训练。

第二个，在嘈杂的人群当中，你去训练看，你的眼睛会被吸引到什么地方。是人的穿着、身体、面部表情，还是人的动作？人是社会化的动物，那我们最大的生存环境其实是人。那么在一群人里边，你要了解自己会被哪些人吸引，其实你也能够知道自己在和人社交当中，你的价值判断，甚至你对一件事情的轻重取舍的判断是什么，也加深对自己的了解。

第三个，在相对空旷和嘈杂的环境里，请你安静地找一个不受人关注的地方，闭上眼睛，去觉知周围的声音，听它从什么地方传来，你会被哪些声音所吸引。到底是噪音，还是别人的说话的声音，是近处的还是远处的。哪些更吸引你，哪些先送到你的耳朵里，而且你会感觉自己正在把专注力向那个方向转。

# 训练目的

通过这三种训练，让我们了解自己的被动觉知，就是被环境诱导着自动发生的觉知规律到底是什么。通过这种觉知训练，你一定会对自己本身是什么样的特征有更多的了解。
