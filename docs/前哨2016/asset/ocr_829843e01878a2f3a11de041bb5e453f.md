# 知觉分为主动和被动

人在没有预先设定的情况下，受到外界的惊吓等做出反应，属于被动知觉。

人有操控自己知觉的能力，可以主动关注某个点。

在禅修时，人的知觉能够扩展到关注全身所有变化的点或反应。

# 自我觉知的“寻”与“侍”

寻：主动把专注力放到一个点上，寻找它的变化。

侍：没有任何预期，但做到完全的知觉，对外界变化可以做到立刻反应。

艾伦朗格的《专念》就是“侍”的一种状态，专注在一件事上，以至于忽略了全身其他的感受。

下意识的完成自己熟悉的动作。

# 加强觉知能力

有意识的专注有助于工作。

加强觉知能力，并没有专注在哪一点上。

人类的知觉有清晰的规律。

加强觉知能力对人有很多好处，但需要通过训练。

得到训练后可以更多的了解自己，尤其是非理性的自己，从而做一个更加自主、有意识的人。
