看漫画也能学品酒？

# 《神之水滴》

《神之水滴》是一部以葡萄酒为主题的日本漫画，虚构了一个像罗伯特·帕克那样的品酒大师。

这部漫画的两个作者，一个是日本非常著名的漫画家，另一个是巴黎葡萄酒学院东京分校的品酒师。因此，这部漫画不仅故事离奇曲折，而且里面的红酒知识非常专业。

![](bbox=[0.08, 0.0070999999999999995, 0.95, 0.0086])

简单来讲，漫画里讲述了大师去世后，他的儿子和侄子通过比赛，争夺遗产继承人的故事。各种名贵红酒和红酒相关知识通过故事一一被显现。漫画用极度夸张的方式表现了红酒的品质和品酒的过程。

《神之水滴》是爱好葡萄酒的朋友不能错过的启蒙读物。

# 漫画的商业效应

《神之水滴》以杂志连载形式发表，每周吸引近50万日本读者，其中涉及到​​的葡萄酒引发了日本读者的购买热潮，以致常常断货。

![](bbox=[0.2, 0.00984, 0.8, 0.01035])

漫画中，并不是每款酒都是好酒，但是其中的经典款都很不错。

这套漫画在韩国也有巨大影响力，引入后，韩国的红酒进口量增长了1/3。

但这套漫画在中国​​的商业效应还不大，了解的人还不多。
