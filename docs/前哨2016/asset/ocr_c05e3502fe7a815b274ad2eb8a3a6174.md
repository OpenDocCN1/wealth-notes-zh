# 产业理解｜产融资本是未来的唯一资本

产融资本是未来的唯一资本

王煜全

上周我们有提到产融资本这个概念，有前哨用户留言希望我更详细的解释一下产融资本究竟是什么。

那么，今天我来和大家聊一聊。

# —— 今日概念 ——

产融资本：是产业资本和金融资本的结合。

产业资本：是企业用于支撑生产和流通的内部资本。

金融资本：将资本独立于产业，当产业需要的时候，为产业提供相应的服务。

# —— 产融资本的由来 ——

随着产业规模化的兴起，很多内部资本无法再支撑起大规模企业的需求，因此金融资本应运而生。

当金融资本独立后，流动性就会增加，它会自动地配置到更需要且能够带来更高回报的地方，也就增加了整个市场和资本金融的效果。

但是当金融资本过于独立的时候，以逐利为唯一目的弊端就显现了出来，不再如产业资本一样支持产业内部的发展。所以，当金融资本从产业里无法再获得利润时，它就会寻找其他发展方向。

但是，金融资本逐利并不是完全错误的。

去年有一本叫《21世纪资本论》的书大热，里面提到了一个观点令很多人恐慌：增值速度大于整个社会发展的速度。也就是说，如果你是资本家，你赚的钱会高于全社会的平均水平，换言之，社会中富者愈富、穷者愈穷。

但实际并非如此，至少从富豪排行榜上看，排在最前面的并不是资本家，而是企业家或创业者。因为有了科技发明、新 的产品、新的业务模式，让这些企业家创立的企业给社会带来了推动，从而让他们站在了财富阶层的尖端。

虽然资本家也有上榜的，不过排在了企业家后面。资本家总能找到更好的企业家进行合作，当企业家成功的时候，资本家也就赚到了钱。所以逐利性反而令资本家的配置效率更高了，因此他的财富增长水平也就比整个社会更快。

虽然如此，但财富增长最快的时候还是企业家。

例如财富增长最快的记录，迄今为止仍然属于扎克伯格，他2004年在大学宿舍里面创建了Facebook，这至今不过12年的历史，但Facebook却获得了全世界市值第五的公司排名，这是了不起的成绩。

资本并不是独立的跑赢社会发展速度，而是因为支持了具有时代沿代代表性的企业，从而实现了自己的增值。

# —— 企业的过去与现在 ——

金融资本对社会的贡献，已经出现了一些过时的征兆。

比如像一百多年前，美国经济的大发展正是因为当时的科技前沿企业的推动，像电报、铁路、石油、钢铁，这些产业在当时都是科技领先的。而这些产业都无一例外获得了金融资本的支持，实现了规模化的发展，从而也带动了整个美国经济的繁荣。

过去的企业发展还需要依赖大型跨国企业和大型集团企业等，依靠着内生式的发展模式。

现在的企业不再需要像从前了，虽然员工人数大大缩小，但影响面却大大增强。

那它怎么做到的呢？

因为它有更多的协同伙伴、渠道合作伙伴、终端合作伙伴，甚至把用户直接转化成了合作者，从而建立了一个生态型的企业。

我们来回顾一下阿里巴巴，淘宝上面几乎所有的商户都不是阿里巴巴的员工。再看看腾讯的微信产品，使用者也是成千上万，但没有人是腾讯的雇员。但当我们使用淘宝和微信的时候，我们实际上是间接的在为阿里巴巴和腾讯打工。

这是现代企业发展的特点，而这个特点中，金融并没有能力提供相应的支持。

过去的企业家主要是以经营垄断型企业为主，判断这类企业家成功因素是看他是否强势，只有强势的企业才能吸引同为巨头的金融资本家与之合作。所以，在以前，企业家不必拥有好名声，只需要你在领域内足够强势。

今天的生态型企业家，不再被看重你有多么强势，而是看你是否具有号召力，能否让更多的人和你一起朝着美好愿景并肩前行。

从上述解释中你应该能够看到，整个企业发展趋势是在变化的。唯独金融业仍然像一百年以前一样，寻找着巨头与巨头之间的合作，但缺乏着这个时代所需要的主要特征：公众的广泛参与度。

你可能会问：虽然金融资本没有跟上，但公众广泛参与其中，把自己手中的资本拿出来投资不就解决了问题吗？

但其实并非如此，因为公众手里的资本数量过小，小资本不敢冒险，所以大多数交给了银行，而银行又被巨头操纵，大资本从银行那获得的钱虽然很丰厚，但公众只能收取非常微薄的利息。

# —— 对风险的重新理解 ——

公众对风险的理解需要提升。

风险分两种：

一种是经营风险，如让公众直接投资一个企业，这个企业不管多么优秀，它总会存在失败的风险。

另一种是信息不对称的风险，就是你并不知道，你想投的那个企业它经营风险究竟有多少。

换言之，如果你能够对一个企业的经营风险有客观的评估，那信息不对称的风险将得到降低，从而你就能发现，其实有很多优质企业的经营风险都很小，投资这些企业会比基金等传统投资方式获得更多的利润。

未来随着企业的经营透明度越来越高，决定企业经营成功因素越来越多，如果企业把产业的生态型发展信息作清晰的分析，公众是有机会参与到其中的。产融资本未来发展的格局，一定不是孤立的产业资本，而是公众的广泛参与度。参与者本身扮演生态当中的贡献者，也扮演着生态当中的资本参与者，这会是未来的新局面。

# —— 美国的尝试 ——

我一再提及木式创新，也是呼吁大家以科技为先导，发展生态式的协同合作，目前美国已经做了不少尝试。

三个不同阶段的典型案例：

在企业发展初期：我们投资了一家美国最大的股权众筹网站，叫做AngelList，很多创业公司会在网站上发布公司的情况和简介，大家就能够将手里的闲钱在网上对该公司进行投资，创业企业就能够借此资金往前发展。

到后期上市之前：Loyal3公司将企业股票分成很多的小份，帮助企业把股票卖给他的合作伙伴、渠道、用户。因为这些企业之间都有紧密联系，所以当他们拥有了企业的股票后，往往忠诚度更高，持有时间也会更长，这就更利于企业发展。

在上市过程当中：美国有很多VC，在各个行业里面做深入的风险投资，他们不仅投资，还会对较好的科技和产业进行合作，推动更多的创新企业从高校拿来最先进的科技作孵化，然后推向市场。

# —— 产融资本怎么玩 ——

虽然美国已经做出了很多尝试，但我认为清晰的模式还没有完整地出现，有待打造。当然，清晰的模式一旦出现，将会成为下一个可以投资的巨大方向。
