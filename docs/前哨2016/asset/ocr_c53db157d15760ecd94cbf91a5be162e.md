# 产业理解｜资本的流向由谁决定？

资本的流向由谁决定？

王煜全

今天的产业理解时间，我们聊一聊资本流动。

先请大家思考一个问题：资本流向哪里，这件事由谁决定？

上周我介绍了产融资本，可能有人会有此疑问：为什么要花费那么大力度去做融资资本呢？直接让金融资本投向产业就不完了嘛。

可惜事情没那么简单。

因为金融资本的流向并不是你想让它往哪儿，它就会往哪儿。

# ——► 金融资本的增值因素 ◄——

中国现存的问题是大量资本流进了房地产。对此，政府为了抑制房地产价格的高速增长做了不少措施，但迄今为止效果并不好。因为资本流动是结果，而非原因。

那资本流动的原因是什么呢？因为资本的逐利性，导致回报其就是原因。哪里的回报高，它就去哪里。
