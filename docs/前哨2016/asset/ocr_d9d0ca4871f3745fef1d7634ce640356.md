+   • 摩尔定律是由英特尔（Intel）创始人之一戈登摩尔（Gordon Moore）提出来的。其内容为：当价格不变时，集成电路上可容纳的元器件的数目，约每隔18-24个月便会增加一倍，性能也将提升一倍。换言之，每一美元所能买到的电脑性能，将每隔18-24个月翻一倍以上。这一定律揭示了信息技术进步的速度。

+   • 计算机领域有个说法：常规的计算能力慢慢地趋进于极限，很难再突破。再过几年，摩尔定律就难以持续了。

+   • 不过现在不同了。虽然用现有的芯片做的常规计算机能力到了极限，但如果用量子计算或用光子计算依然能够达到持续的增长。

+   • 有人认为D-Wave公司并不是真的量子计算。普遍意义上的量子计算的计算单位叫量子比特，是用一个量子比特来做各种复杂的计算。量子比特的好处就是它是指数级的叠加。D-Wave公司用的不是量子比特，而是隧道效应，算法叫退火算法。

+   • 在D-Wave创立后的很多年里，它始终没能拿出产品来，所以很多人认为他们是骗子。直到又有一天，谷歌利用他们的计算机做了实际的练习、做了实际的测试，结果发现确实在某些算法里面，它比常规计算机要快成千上万倍，这个争议声音才平息了。虽然它不通用，但是在某些领域有优势，就足以使它能够往前发展下去了。虽然它不是普遍意义上认为的通用的量子计算机，但确实利用了很多量子原理。

+   • GPU只是对计算机的图形做加速，也不是通用计算，但是现在很多要求有运算速度的领域：比如虚拟现实、人工智能、大数据等都离不开GPU。所以它虽然不通用，但是在某些领域有优势。

+   • GPU：图形处理器（英语：Graphics Processing Unit），又称显示核心、视觉处理器、显示芯片，是一种专门在个人电脑、工作站、游戏机和一些移动设备（如平板电脑、智能手机等）上做图像运算工作的微处理器。
