# RapidAPI

这家公司于2015年在旧金山成立，公司创始人Iddo Gino现在只有18岁，是在以色列海法的一名高中毕业生。今年11月刚刚获得了350万美元的融资。

RapidAPI 的使命是使开发人员能够访问并轻松使用公共可用的API，以允许他们无缝通信。由于API之间没有通用的数据格式，所以将它们拼接在一起十分复杂。

RapidAPI 有一个在线API集中存储库，提供标准化访问，并允许开发者用极少的代码（甚至不需要额外代码）就能集成API。RapidAPI公司帮助解决API的复杂性问题，使得开发人员可以最大限度地提高API运行速率而不会产生当下可能减缓其运行的乱码。

RapidAPI现在拥有上万的开发人员，成千的应用程序和每月数十亿的API调用。
