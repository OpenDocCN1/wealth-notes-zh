# 产业理解｜能力如何转化为资本？

能力如何转化为资本？

# 资本的特点

著名经济学家何帆老师得到——“何帆大局观”里有一期节目，讲到秘鲁经济学家德索托在《资本的秘密》里面说：穷人之所以穷，不是因为他们没有财富，因为他们没有资本。

区别在哪呢？资本是受到法律保护，能够用来交易的资产。如果你只有财富，不能实现交易，就只能供你自己使用。

而资本的意思是说，财富不光能供你自己使用，而且你可以把它的价值拿出来，和别人来交易，从而创造更大的价值。能够保护交易，是资本最重要的一個特点。

# 积木式创新

我和薛兆丰老师在《全球风口》里面提出了积木式创新的理念。所谓积木式创新就是小企业利用自身的科技优势，然后和大量的互补的小企业合作。

比如说，我有科技，但是我需要协同研发，还要有设计，还要有生产，还要有品牌，还要有营销、宣传、销售、渠道、客服，各种各样的这些大企业才能够拥有的能力。以前小企业是做不到的，那现在小企业不需要在体内具备这些实力，而可以和这个更多外部的小企业合作，通过协作的方式来具备大企业能够具备的所有的能力。

# 财富和资本的区别

我们发现在硬的领域，中美非常互补，但是在软的地方，中美非常的不互补。所以造成我们帮助美国科技和中国企业来对接的过程当中，进展往往比较缓慢。

那所谓软的就是理念的部分，相互理念的沟通问题，造成美国对中国的合作有顾虑。

我们经常碰到这样的情况：介绍美国企业到中国来，往往很受欢迎。但是中国企业上来就会讲，你看你公司那么小，我能不能整个收购你。美国人就会觉得，哎呀，你似乎不懂我的规则。美国企业公司小不是因为它特别穷，在美国小公司的开放式创新已经形成了一个完整的生态，它的操作都是有非常清晰的规律的。那你贸然提出来去收购它，其实是没有收购机会的。

我们中国企业还经常说：我们市场能力强。老美其实关心的是：咱俩合作的话，怎么保护我的知识产权呢？

中美不互补的是什么？归根结底，其实是两个字，叫做信用。

我们在企业合作当中发现，企业合作也有从财富到资本，或者说从能力到资本的这种变化，就是中国企业已经拥有了很多的财富，也拥有了很多的能力，能力和财富之所以不被别人认可，是因为没有被转化成资本。

你不能利用财富和能力去跟人家协作，那财富和能力就会打了折扣。其实不光是我们碰到这种问题，很多新闻报道：中国企业到海外并购，往往双方都同意了，政府站出来干预，或者当地的居民站出来干预，拒绝这种并购，最后并购流产。

所以说明我们拥有的仍然只是财富，就是你有钱去收购它，但你拥有的不是资本，因为人家不愿意来跟你协作，就是不能交易，不能交易的财富就打了折扣了。

# 能力转化成资本的是信用

光有能力不行，从能力到资本之间，隔着一个信用。
