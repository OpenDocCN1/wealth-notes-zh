# 社交网络信息当真无用？

人类大脑和猩猩对比，人类大脑厚度增加是由于表面积增加，然后产生折叠形成。所以智慧的生成不是由于我们的深度提升了，而是因为我们的广度提升。

当我们接触了大量的社交网络信息的时候，碎片化信息的时候，我们了解的信息的广度都在增加。

大脑经过对复杂信息的充分理解，反倒能够形成对这个世界的真实的认识。
