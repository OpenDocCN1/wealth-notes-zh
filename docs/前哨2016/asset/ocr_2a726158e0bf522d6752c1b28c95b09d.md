# 创业者如何适应新生态

基于长板理论的积木式的合作；

科技的应用化加速，首先要会完整地为用户着想，把用户体验调到最优，使科技应用加速进入社会；

这个时代的经营范式是生态协作，是基于长板理论的积木式创新。

# 对联想的六条行动建议

+   1. 建立最前卫的用户研究部门以替代设计部门，如研究90后的《青年志》。

+   2. 在一个共同目标下的广泛合作：商用还是消费品，开放渠道给合作伙伴。

+   3. 时髦话题要占领，才能重塑形象：VR模块、游戏模块。

+   4. 和国际先进公司加强合作：和对方合作，帮助对方解决市场和制造问题。

+   5. 杨元庆高调出场，并请牛人撑场子，比如苹果请的任天堂。

![](bbox=[0.05, 0.0020499999999999997, 0.95, 0.00265])

+   6. 加强对全球先进科技的战略投资力度，举贤不避亲，可以和海银资本战略合作，仿效当年的红杉和思科合作。
