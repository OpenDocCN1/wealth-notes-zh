# 什么是人体的微流控芯片

在制药领域，研发新药需要做大量的实验，比如用动物做试验，看有没有效果，有没有毒副作用。但是动物和人是不一样的，对动物有效但对人不一定有效甚至有副作用。

制药公司需要一个模拟人体内部微环境的分析模型，去分析还原药物在疾病发生时能起到的具体作用。通过逆向工程的办法，研究人类器官本身，把器官中最核心的部分给它还原出来的技术，就是人体微流控芯片。

器官芯片，是一种用硅材料制作的芯片。人是碳基生命，机器人是硅基生命，因为人体细胞在硅上面的吸附效果特别好，所以未来完全可以实现人和机器人的融合。

器官芯片的核心是在芯片上种植细胞，而且这个种植的细胞是三维立体的，可以模拟人体的内外环境、人体器官，去看用药对人体器官功能产生什么样的变化。

如果把人体的诸多器官功能都模拟出来了，把多个芯片放到一起，就叫做人体芯片。

微流控芯片，它是在很狭小的空间当中处理微量流体的技术。比如肠道芯片，是模拟人的肠道的成长环境，肠道器官结构，研究药物、食物在肠道的吸收状况和吸收效率等问题。

# 微流控芯片的研究成果

肠道芯片，美国哈佛大学Wyss生物工程学院的Ingber实验室研制的肠道芯片，通过在通透膜上培养肠道细胞组织，模拟肠道结构和环境变化，还原测试口服液透过肠道吸收的情况，市场潜力巨大。

肺部芯片，也是哈佛大学的Wyss生物工程学院研制的，它是在通透性膜的上层培养气管表皮细胞，下层培养血管表皮细胞，模拟肺部吸入空气融入血液的功能和环境变化。

心脏芯片，哈佛大学Wyss生物工程学院，Parker实验室研发。把心肌细胞培养在一种有弹性，可变形的薄膜上，并模拟心肌的收缩、舒张和电生理反应，肌肉薄膜还可以被制成不同的独立的三维结构，观察模拟不同环境条件下的不同心肌反应。

血管芯片，是2010年多伦多大学生理学院的Boltz实验室研制出的。他在芯片当中搭建了一个空心的血管支架，然后在支架外侧培养了一层血管表皮细胞和一层平滑肌肉细胞。通过收缩舒张调节因子，外接导管等模拟血液的物质交换，甚至发现血管的局部应急反应现象，对心血管疾病药物研究很有价值。

肿瘤芯片，2012年MIT的癌症综合研究中心的Kamm实验室研究出了一款肿瘤芯片，可以模拟复杂的肿瘤微环境，包括低含氧量，肿瘤和环境的互动，以及营养物质的浓度 gradient等。

3D打印肝的组织，是打印肝的细胞。上市公司Organovo声称这是世界上第一台3D的生物打印机。3D打印肝的组织，需要先铺一层肝细胞再铺一层凝胶，这样周而复始层层堆叠，凝胶作为骨架，肝细胞依附铺层其上形成一个整体，模拟肝脏的功能。

# 行业现状

器官芯片是为了药企公司做药物研发用的，模拟药物对于某些器官的作用和反应情况。这个行业服务于药物研发领域，市场前景较好，全世界的市场空间大约10 ~ 100亿美金。

器官芯片行业现阶段知名公司包括：美国哈佛大学Wyss生物工程学院2013成立的Emulate公司、做3D生物打印机的上市公司Organovo公司，曾经市值达到10亿美金。

![](bbox=[0.15, 0.0079, 0.98, 0.0091])

传统药物研发的流程，是先做病理药理研究，然后建动物模型，上动物临床，做动物实验，最后是数据分析，药物评审机构审核。

行业前景很好，也有许多挑战：如何利用好人体胚胎的肝细胞建立可持久使用的体外模型；材料应用与环境刺激如何更真实的模拟还原人体微环境；科研产品属性无法量产；技术是全新的，相关分析数据还很难做到和现有的生物分析无缝对接。

人体芯片是研发还原人体的复杂性，同时保持实际操作的简便性，两者之间需要找到一个平衡点。

微流控芯片技术在生物制药领域很有未来前景，也有许多公司完成了技术突破和商业转化，值得生物制药领域的朋友提前关注和布局。
