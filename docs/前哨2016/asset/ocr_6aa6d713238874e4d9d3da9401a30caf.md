# 创新考察团团员冯启娜分享“罗辑思维”经验

罗辑思维的成功首先是因为定位清晰。罗振宇一直强调，他是知识搬运工。罗辑思维更强调做音频，即使是做视频，也力求简单。

他们认为，知识服务分两种，一种是节省时间的，一种是打发时间或者消磨时间的。在碎片化的应用场景中，音频明显胜于视频；打发时间的东西，娱乐化很强，让用户放松、消遣。罗辑思维明显属于节省时间类。

其次，罗辑思维是年轻人挑大梁的。就像Reid Hoffman的《联盟》里谈到的，公司和公司之间，公司和员工之间只有一种关系，叫联盟关系。没有领导和下属的关系，没有甲方和乙方的关系。联盟关系要互惠互利。他帮公司实现理想，也是在帮自己实现理想，双方的利益是高度一致的。

第三，给年轻人试错的机会。从工作当中得到锻炼，然后成熟起来。允许年轻人试错，一旦出现问题，就要迅速调整。

第四，罗辑思维很前沿，很擅长用新的技术来做事情。这和我们一直以来的观点是非常吻合的。

大家为什么推崇乔布斯，不是因为他是科学家，也不是因为他是科技专家，而是因为他是使用科技的专家，他知道如何让现代的科技，给用户带来最好的体验。

我们和中国的优秀企业对标，反倒更容易学到更多的东西，一方面我们要学习国外的先进经验，另一方面我们要学习中国优秀公司的先进经验。
