# 生理反应会影响心理

加拿大一个心理学家在两个桥上去测试大家恋爱态度，一个是很坚固的石桥，另一个是晃动的铁索桥。他发现在铁桥上恋爱成功的机率大大高于石桥。

在石桥上，安稳不害怕，所以没有什么特征改变。而在铁桥上，晃晃悠悠会产生害怕，害怕会分泌荷尔蒙，心跳加速、脸红从而认为爱上对方了。

这些证据说明，生理的各种反馈会对心理形成强烈的影响，甚至在一定意义上，心理认知本来就是基于生理反馈而来。

# 身心互动

心态既会影响行为，也会被行为影响。每天清晨镜子前的微笑将有助于让你保持一天的快乐。

具身智能：我们的智能系统是具身的，即我们身心的相连互通是智能的基础。

现代认知科学认为，我们的自我认知系统并不是人类发展早期，甚至人类之前就有的东西，而是在不断进化中产生的，自我认知系统并不能直接知道我们心情的好坏，它是通过综合我们的生理特征进行判断，因此，有时会出现误读。

日常行为会对心态产生强烈的影响，刻意地调整行为方式可以让我们变得积极许多。

我们通过行为辨别他人状态好坏的能力是很强的，只是往往我们一心多用，这种能力被我们忽略了。
