# 义乌印象与山腰理论

义乌印象与山腰理论

王煜全
今天给大家汇报一下我上周在义乌的见闻。
虽然义乌小商品城不如科技投资高大上，但实际上中国的商品就是因为义乌的小商品城而遍布了全世界。
以下是于贫笔记，完整内容欢迎收听音频。

BBC曾经拍过一个三集纪录片，叫《中国人来了》，有一个镜头让我印象深刻，在一个非常小的非洲小镇上，有且只有一条街道，而街道上满是小摊贩，售卖的基本是中国货，我猜大部分商品也是从义乌到那儿的。

小商品虽然廉价，但是对世界的贡献可不小，尤其是对非洲的发展。以前欧美国家想尽了各种办法帮助非洲发展，但始终都不见效果。而这几年非洲的经济增长不错，我认为中国小商品，尤其是义乌，是功不可没的。

> 道理想很简单，要促进比较贫穷的国家经济发展，必须先给他买得起的小东西，让它拥有商品的概念后，才能引发他的思考：我如何也能够参与到市场交易中通过买卖赚钱呢？在本地有了交易和生产，市场才能慢慢活跃起来，继而促使经济得到好转。
2人笔记

我认为这方面的发展，中国贡献是巨大的。可惜迄今为止，经济学上还未能有系统描述，因为西方人不大可能承认中国能够解决他们无法解决的问题，这一观点可以理解，但我相信，中国的经济学家一定能够较好的分析。

那么再此之前，让我先从我的视角看看义乌。

# 最震撼的是小商品城

义乌让我最震撼的就是它的小商品城，果然名不虚传，可以称为世界小商品之都。小商品城非常大，从宏观看分五个区，第一区走到第五区大概要花费三十多分钟，每个区又都有一到两栋大楼，每栋大楼有四到五层楼高，分东西南北四个方向，每个方位都是长长的走道。

不夸张的说，商品城可容纳的摊位有几万个，甚至十几万。而这些摊位不仅仅是针对着中国买家，外国人更拿这里当作淘商品的好去处。

据当地政府介绍，常驻在义乌进行各种采购的人就有2万之多，而外国人在当地占比比重也相当大。五号馆甚至有一层做进出口，算是给老外在中国设的一个展区了。

![](bbox=[0.15, 0.0022, 0.88, 0.0031])

义乌小商品城基本是在前店后厂的基础上发展起来的，企业普遍较小，科技含量不高。但它的优势就是贴近市场，前店卖得好，后厂立刻加工生产，而且创新能力一点都不差。

但是小商品市场存在一个问题，就是不做零售，只做批发。如果能将零售做起来，义乌或许可以做购物游。那么是否可以打造一个虚拟购物上淘宝，现实购物去义乌的购物概念呢？这应该是一个不错的设想。

# 山腰理论：中国可以服务于全世界

义乌的企业普遍都不大，据当地政府说，上亿规模的企业只有百余家，十亿规模的企业只有十几家，而上百亿规模的企业基本上一家都没有。所以虽然数量庞大，但市值上和全球大企业还是存在着差异。

但反过来讲，这个差异也有可能成为义乌的优势。

我们都知道美国的源头是科技，但它的先进科技却一直没有渗透到全世界，只是渗透到了发达国家，这是因为它的科技产品总是很贵。但是科技若不能惠及全世界，它所发挥的效用就会大打折扣。

> 中国曾经一穷二白，站在山脚底下，可随着过去两代人的努力，中国经济终于爬到了世界前沿的位置，但我们的科技实力依然处于山腰上。所以我们要利用我们已具备的生产能力，不只要掌握先进科技，从山腰走向山顶；还要向下覆盖到山脚底，用我们的优势低价，使得更多科技能够造福于全世界。这就是我们所说的山腰理论。
3人笔记

山腰理论在义乌得到了完美的印证。世界发达国家的科技做好了以后，只能覆盖其他发达国家，但是中国如果把先进科技拿过来，很有可能覆盖山顶到山脚的全世界。科技的特点就是普惠，当人人都能够享受时，它的收益才能够最大化。想想谷歌和Facebook的用户数，你就明白这个道理，用户就是一切。

![](bbox=[0.12, 0.00625, 0.88, 0.00715])

# 我们已步入了产融资本时代

在我们和当地企业沟通的时候也发现了一个问题，这些企业对先进科技的理解比较弱，例如如何前瞻性布局，如何引入更先进的科技增强自己的实力，包括如何对资本进行运作，他们是不懂长且缺乏了解的。

> 前一段时间吴晓波老师曾经提过一个非常有价值的看法，他说，我们过去的产业资本时代已经过去了，未来只有一种资本，叫做产融资本。
1人笔记

我是非常认同以上观点，在义乌我也看到了产融资本的未来机会，在全世界引入前沿科技，和义乌中小型企业对接，比如玩具对接先进技术，生产智能玩具，那么义乌的玩具业就会又兴旺发达起来了。

所以我认为，利用产融资本对接中国制造和世界先进科技，是一条可以走的路。而一旦这条路走得通的话，我们的山腰理论又可以实现了，我们上可以对接美国，反销回欧美发达国家，下可以让最先进的人工智能玩具惠及所谓第三世界的穷苦人，坦白讲这是非常让人振奋的。

# 政府如何与城市打配合？

前段时间看到一篇文章讲乌镇的管理。乌镇虽然是一个镇子，但乌镇与中国一个上市旅游公司签了乌镇管理协议，旅游公司帮助乌镇，把它打造成中国最好的旅游镇。

那么义乌是不是也可以用这种方式，把公共服务部分外包给旅游公司或者电商公司，让电商公司彻底改造小商家，让他们能够和国外更好的合作，包括帮助到来义乌采购的外国商人，使得他们能够更好的管理自己的供销存，效率进一步提升。

如果能够做到这些，无疑是更放大了义乌在全世界 org
