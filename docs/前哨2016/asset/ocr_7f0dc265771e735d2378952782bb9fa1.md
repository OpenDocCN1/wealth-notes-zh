# 前哨科技创新地图｜美国高科技转化如何跨越死亡谷

美国高科技转化如何跨越死...

2013年毕业于美国田纳西大学诺克斯威尔分校，博士期间发明了新型水向空气电池技术和高效绿色电解制氢水技术。

2015年，以主要创始人和发明人的身份在美国创业，得到了美国能源部ARPA-E的资金支持，之后又获得了MIT-CHIEF 2015年商业大赛的二等奖。

2016年获得了Tennessee Venture Challenge（田纳西创业大赛）一等奖。

今天，戚鸣博士和我们分享的是，美国科技创业如何能够更好地利用政府支持。

本周，我们一直都在讲美国的科研和研发，今天正好由我们前哨团队给大 家提供一个具体的实战案例，美国是如何对待科技转化过程中死亡谷的。

# 以下是戚鸣博士的文章：

本人目前在美国创业，做的是化工产业内的颠覆式创新。作为王煜全老师的忠实听众，在听了王老师对中国如何进行产业转型和科技创新的见解后，感受受益匪浅的同时，也非常认同。对于我们现在正在做的初创公司，我本人既是技术的发明人也是公司的创始人，对领先的技术如何转化为生产力有一些个人的见解。

我非常认同王煜全老师所说的美国“拜杜法案”的影响和中国政府对于科研（Research）和研发（R&D）的认识误区。我个人认为美国作为世界最大的科技强国，还有一些地方值得中国学习。
