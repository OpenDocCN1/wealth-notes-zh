# 科技概念股｜新能源汽车将迎来第二轮新概念

新能源汽车将迎来第二轮新...

王煜全

本 pric 的科技概念股讲的是新能源汽车，也被称为电动车。你可能会问，电动车概念应该早就流行了吧，为什么又会成为新的概念股呢？

此前介绍过，一般而言，科技概念股在中国有两轮流行。一轮是概念刚出来的时候；第二轮是概念真正给产业带来实际收入利润的时候。两个阶段中间会有一个股价下跌的时期。

因为概念刚出现时，大家都热捧，但过一段时间大家发现没有收入利润，或者有一些概念股最后根本没有做出来，就会造成下跌。一直到真正利用这些概念的公司做出产品，形成了收入利润时，才能重新形成新一轮的概念股。

但是，电动车领域特别有意思，而且不太一样。之前电动车的概念股热，在 2013—2015 年，都有体现。但预计在明年才会热，这其中有一个很特殊的原因，因为明年的电动车本身会受到很大关注。

至于这是为什么，今天就来和大家继续讲讲电动车。

以下是干货笔记，完整内容欢迎收听音频。

# 电动车的市场规模

现状：

2016年上半年，全球范围内的电动车（含纯电动和插电式混合动力车）的累计全球销量为306,823辆，同比大幅增长49%。

根据全国乘用车市场信息联席会的数据，今年6月份中国新能源乘用车销量同比增长163%至34,008辆；上半年累计销量120,382辆，其中纯电动车销售80,504辆，同比增长166%；插电混动销售39,878辆，同比增长91%。这充分证明了新能源汽车市场的巨大潜力。

前景：

Bloomberg New Energy Finance发布的一份报告指出，到2040年，电动车的销量将达到4100万辆，占新轻型车销量的35%。这几乎是2015年的90倍，2015年电动车销售量为54.9万辆，同比增长约55%。

# 影响电动车的几大因素

+   1、电池成本的下降

自2010年以来，锂离子电池成本已经下降了65%，去年达到每千瓦时350美元。Bloomberg的分析师预计，到2030年，电动车电池成本将低于每千瓦时120美元，随着新化学品的进入，电池成本将进一步下降。国际能源署指出，自2008年以来，电池成本下降约四倍，电池的能量密度增加五倍。
