# 8、MiniMed 670G

糖尿病人的 人工胰脏。人工胰脏就是一个胰岛素泵，加上传感器后就能对人体的胰岛素实现持续监测，一旦发现需要调节，就用胰岛素泵往人体里注入少量的胰岛素。

还有一个是我原来刷朋友圈时看到的东西，现在竟然也被评为了《时代周刊》的最佳25个发明之一，是固特异公司提出的球形磁悬浮轮胎。

它有两个方面的问题：

+   第一，这个产品本身是固特异公司拿出来的概念轮胎。很多概念的东西只是用来告诉大家我多么先进，只是一种概念。而《时代周刊》把这个概念拿出来评比，我认为还欠火候。

+   第二，它离实用实在太远，360度的球形轮胎，首先需要有通过磁悬浮方式把轮胎置于汽车之下的技术，它的可行性还有很多的问题。其次，它看似方便，可以朝360度的各个方向滚动，但是一个汽车轮胎占的地方就比别的轮胎要大很多倍，一个车底下4个球就把传统的空间全部挤没了。

所以我认为，当做一个概念是可以，但是实用性几乎没有。所以，改变生活也要立足于有实用性，才能真正地改变生活。
