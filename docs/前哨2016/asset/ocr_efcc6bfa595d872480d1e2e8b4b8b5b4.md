# 8月11日 | 一起读书 - 都是压力惹的祸？

# 《The Upside of Stress》

# 以前的观念：压力不好

以前我们认为压力不好。压力会造成我们焦虑、失眠、免疫力低下，导致我们生病，现代城市人之所以心里有各种问题，是因为我们压力太大。大家很坚定地相信这一套理论。

本书作者公开表示他要为以前承认并传播这个错误的认识而道歉。

# 作者的观念：对压力的不同态度和观念才能影响人的健康

实际上压力对我们的负面作用，只在我们相信压力会给我们造成损害时才成立。

大家都有压力，但有两种人，一种人认为压力真的带来很多生理心理的问题；另一种人认为压力没问题、是正常的、不会给我带来损害。

不是压力损害了人的健康和心理，而是对压力的不同态度和观念损害了人的健康和心理。

当你认为压力是好的，压力就是好的。为什么呢？压力其实是一个应激反应。

所谓应激反应，并不意味着会给我们带来伤害，应激只意味着我们会把全身机能协调、调动好，使我们达到最佳状态。

能够持续提供最佳状态的输出，其实会使人变得更强壮、更有能力。

# 错误观念的源头

让一只老鼠害怕，它就会出现各种反应，然后就死掉了。所以认为压力会让人也不好。

我们要格外警惕，从一件事上能不能导出另一件事。从老鼠能不能导出到人。

男性和女性在面对压力时，处置办法不同，男性面对压力时选择躲起来，自己去承担这个压力。而女性在面对压力时会选择找朋友，大家一起倾诉，当有压力时，反倒更外向，更愿意帮助别人，反倒更合群。通过合群的方式一起协作，消解压力。

压力对人会造成损害，会让人脾气大、攻击性强。这个结论也站不住脚。因为以前的科研样本选错了——选的全是男性。

压力之下男性的反应和女性的反应是不同的。

研究结论是，当你为别人着想，把小我化成大我时，就不单是压力被消解，而且活得更健康。

# 给我们的启示

第一、我们不用对压力抱持否定的态度，可以积极地面对。压力造成的应激反应，可以把潜能充分发挥出来。

第二、未来是女性的时代，因为女性更加愿意社交。在未来人工智能极度发达的时代，有三种人是不容易被替代的：一是创意工作者，二是连接者，三是领导者。

女性特别适合做连接者，连接者的数量要比创意者和领导者多的多。

我们大脑的主要部分其实不是脑神经，而是脑神经之间的连接。我们的脑灰质是脑神经加连接，而脑白质就是脑神经之间的连接，脑白质比脑灰质大。

男性如果学会更柔和、更社会化的女性化思维能活得更健康长寿一些。

我们可以通过对历史的分析，看到一个错误的观念是如何形成的。同时我们通过对科学研究的系统跟踪，了解一个新的正确概念如何更好地建立，这对我们建立一个正确的世界观非常有帮助。
