# 一起读书｜信息爆炸时代，接收太多嘈杂的信息真的不好吗？

信息爆炸时代，接收太多信…

# 《Nonsense》的意义

现实社会信息呈现无序化，也就是说从外部信息得不到一个比较公正的判断，或者得不到一个大家都公认的判断，信息间经常互相矛盾，各有各的证据。

阅读深度越来越浅，吸收的信息越来越杂，这样人会变迟钝吗？

# 大脑判断信息机制

大脑天生就是一个超级模式鉴别装置，如果你给的它一个已经呈现出清晰模式的信息，这个信息是没有矛盾的，它的模式识别系统就不启动，默认地接受信息。

这也就是说为什么我经常在读书的时候强调，绝大多数独立思考能力不够的人，轻易不要读书的原因，因为读书，作者往往不会把相互矛盾信息放到一本书里，所以你会得到一个非常连续的，系统的，没有矛盾的信息。但问题是，如果这信息错了怎么办？

反过来讲，如果大脑接受的信息本来就是嘈杂的，互相之间有矛盾的，我们大脑当中的模式识别能力下意识就会启动，天然地就会从这些嘈杂当中去识别出模式，以训练自己捉到那个幕后的真相。

# 智力工作原理

我们越吸收相互之间矛盾的东西，我们反而越能够对真实的世界产生一个真实的认知。

而反之，如果我们每天读到的都是一个确定的信息来源，完全没有任何矛盾的信息，那么我们的世界要小心了，你的世界构建可能也重大的偏差。

大脑不光不畏惧挑战，而且欢迎挑战。没有挑战的事物会使我们变笨，而充满挑战的东西会使我们变得更聪明。

在今天这个时代，我认为这本书重要在于告诉我们，不要担心，所有的嘈杂对你不光无害，甚至有巨大的益处，因为使得我们身处于信息爆炸今天的人，比过去的人对这个世界有了更加深入的理解。
