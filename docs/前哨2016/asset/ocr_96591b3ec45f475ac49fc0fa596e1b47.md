# 品酒实践

品酒主要不是学习葡萄酒知识，而是实际锻炼品酒能力。

品酒的核心是酒杯要把葡萄酒的香味聚住。品酒其实更多靠的是鼻子，不是舌头。

嗅觉要比味觉更加丰富。

# 品酒姿势

喝酒，含住，嚼，低头，吸气，噢。

葡萄酒的品鉴乐趣就在于体会到更多的层次，欣赏它的平衡型和复杂性，香味会使葡萄酒饱满很多。

这套流程的合适场合就是高档的法餐厅，这是法餐厅可以出声的地方，是懂酒的表现。
