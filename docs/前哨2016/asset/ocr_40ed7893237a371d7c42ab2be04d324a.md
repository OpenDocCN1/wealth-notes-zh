# 微生物群落与人

肠道菌群自发现以来热度节节攀升，每个人 的肠道菌群都不一样，并且肠道菌群的构成 会随着饮食习惯、健康状态、甚至睡眠周期 的改变而调整。

未来，针对个人量身定制的肠道菌群产品可 能会成为一种治疗疾病的手段，相关生物技 术和产业前景广阔。

# 微生物群落与植物

土壤中存在着无数的微生物，与人一样，植 物的生长也受微生物的影响，同时植物能够 区分有益和有害的微生物。

就像有益的活性微生物能够改善人体健康一 样，通过在植物根系周围建立一个最优化的 微生物群落，可以提高农业产量。

与以前单独利用某种微生物不同，今天的微 生物群落技术需要对土壤中的或者植物表面 的数万种不同的微生物进行一次性分析，并 研究它们是如何影响植物生长的。这种技术 将会重新定义农业。

# 领军企业

AgBiome公司成立于2012年，坐落于美国 北卡罗来纳州，现有36名全职员工，预计 2016年推出一款生物除菌剂Howler。

今年7月，Bill & Melinda Gates基金会向其 投资了3400万美元与其开发生物控制病虫的 方法以应对非洲严重的红薯病虫害问题。

红薯是撒哈拉沙漠以南非洲的重要基本食 物，也是当地人维他命A的主要摄入来源。 象鼻虫是非洲红薯种植的最严重虫害，如果 不使用化学控制会造成60%到100%的减 产，造成严重饥荒。

微生物群落技术的开创意义在于在不改变植 物基因的情况下同样可以提高植物的适应 性。

不论是转基因，还是基因编辑，都需要大量 的基础理论研究以明确特定性状基因的具体 位置，而植物生长的好坏很大程度上取决于 它的生长环境，环境的改变很可能使引入的 新性状无法发挥作用。

重新选择基因进行修饰往往无法应对突如其 来的状况，而微生物群落技术有着很好的灵 活性。

我们不可能对所有的粮食作物，瓜果蔬菜进 行反复的基因改造，而微生物群落技术却可 以无限拓展。

# AgBiome核心成员

AgBiome公司有着强大的科学顾问团队。最 著名的两位科学家都是从有害微生物的研究 转到有益微生物方向的。

Jeff Dangl教授：北卡罗来纳大学教堂山分 校微生物和免疫系教授，他的最大成就是在 分子水平解释了植物和微生物相互作用的机 制，即微生物是怎么让植物生病的，植物又 是如何进行反击的。

三年前Jeff Dangl教授宣称以病害发生为方 向的植物免疫研究已经死亡，唯一的出路就 是植物相关的微生物群落研究，并转变了自 己的研究方向。

Paul Schulze-Lefort教授：曾是德国的Max Planck研究所的植物育种中心主管。

今年4月，Paul Schulze-Lefort教授的团队 在西班牙中部高原发现了一种寄生于植物根 系表面的真菌。这种聪明的微生物可以检测 土壤中的磷含量。
