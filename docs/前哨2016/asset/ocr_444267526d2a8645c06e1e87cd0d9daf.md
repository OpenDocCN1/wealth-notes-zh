# 技术制作在娱乐形式革命的趋势

一是虚拟现实，VR除了应用在游戏上，也已经有电影制作公司尝试制作虚拟现实相关影视。

现在看电影形式是被动的，我们关注的焦点是被导演设定好的。但未来虚拟现实影视有很强主动性，它只构筑环境，你可以上上下左右前后六个维度自己控制关注点。

# 大数据在娱乐行业的发展

未来大数据可以分析用户的内容需求，为用户量身定做。

目前像美国的Netflix、中国的华策影视，他们的内容生成并没有依赖大数据，而它的内容分析、选角色、对外宣传等都是通过大数据支持的。

![](bbox=[0.12, 0.00175, 0.88, 0.00195])

《纸牌屋》的成功很大程度上源于Netflix大数据和用户分析

大数据分析和投资结合，利用大数据分析更有效的监控影视制作。

# 明星个人发展与科技结合

基于大数据和用户分析的明星管理平台，可以帮助明星判断商业价值，从而提高影响力。

社交网络出现后，利用人工智能帮助明星和用户互动，增强明星互动能力。

# 高科技如何发掘内容潜力

利用人工智能严谨的逻辑，预设主角特征、背景，自动生成影视作品。

把人的创造力和计算机的严谨逻辑结合，是目前人工智能做好内容的前提。

内容生产方面，设备上是被硬科技推动的，设备有了，自然会有新的形式。
