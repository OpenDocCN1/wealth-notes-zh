# 智能投顾是什么？

智能投顾（robo-advisor），一种在线投资顾问的服务模式。

智能投顾起源于人工智能的进步，这个产业2010年左右兴起于美国，前景十分可观。其中最有代表性的两家独立智能投顾公司是Betterment和Wealthfront。

![](bbox=[0.07, 0.82, 0.93, 0.00102])

# 目前智能投顾的分类

第一类，偏向机器配置。用户诉说需求后，买卖交易都由机器完成。

第二类，偏向个性化。智能投资顾问提供意见、投资组合，由个人决定买或不买。

第三类，人机结合。一站式理财平台，智能投顾帮你做资产配置，或你自己做资产配置，根据不同配置收取不同费用。

# 创业机会

小公司并非没有机会，智能投顾市场非常大，即使市场占比很低，但份额依然巨大。

作为个人资产管理，以前大家只重视高净值客户。未来，越来越多的生态环境和协同社交，意味着，考虑如何能够聚集理念相同人的钱去接触回报更高的另类投资，才是智能投顾未来真正需要研究的命题。

智能投顾刚刚冒头，还有很多可以探讨的空间。从长期看，智能投顾的成功将取决于真正看懂了这个行业，看懂了这个市场，真正能够给客户造福的创业者。
