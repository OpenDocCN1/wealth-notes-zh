# 7月5日 | MIT：创新与创业之间存在矛盾吗？

探访地点：美国 波士顿 MIT 麻省理工学院

+   - MIT的斯隆管理学院（MIT Sloan School of Management）：由麻省理工学院校友Alfred P. Sloan（当时为通用汽车总裁）于1952年捐助成立。身处高科技环境之中是斯隆管理学院最大的优势之一。在《美国新闻和世界报道》（U.S. News & World Report）的美国商学院排名中，斯隆管理学院常年保持全美前五的优异名次。

+   - 黄亚生教授，美国麻省理工学院斯隆管理学院副院长，政治经济和国际管理教授，并在该学院中国经济和商业国际讲座教授，同时也是复旦管理学兼职教授和湖南大学荣誉教授，兼任清华大学中国经济研究中心研究员，北京大学国际关系学院研究员，密歇根商学院威廉大卫逊学院研究员，世界经济论坛研究员，历任密歇根大学、哈佛大学教职和世界银行顾问。在麻省理工斯隆管理学院，黄亚生教授创办了“中国实验室”和“印度实验室”，旨在帮助中小企业提高管理。他是数家盈利性和非盈利性组织顾问委员会的成员。

+   - 斯隆管理学院是美国顶级的商学院之一，因为隶属MIT，能够和MIT的高科技相结合专门孵化高科技公司，其间诞生了很多美国的技术公司的高管，所以很有特色。斯隆管理学院有专门的创业服务部门，并且面向所有MIT的学生。也就是说，你在MIT的任何一个系里想要创业，都可以得到商学院的支持，而且商学院有意识地去组织学商业的学生和学技术的学生去互动，以找到配合的机械，这就是我们一直在强调的双长机制的背景。在一个公司里，懂商业和懂技术的人，两边都要强，这个公司才能够具有足够的实力。

+   - 作为斯隆管理学院的副院长，黄亚生教授应该是美国教育系统里做到最高职位的来自大陆的华人。他是美国、中国政策的权威，其研究很有見地，甚至被请到白宫去帮助奥巴马政府研究中国政策。我最早认识黄教授是因为拜读了他的一本书，《中国模式到底有多独特？》。其中，他认为中国模式和中国特色并不像想象的那般独一无二，我们完全可以拿中国和其他国家进行对比、探讨，发现我们的优势劣势，发现我们的机会威胁，然后做进一步地改进。中国就是全球经济发展当中的一个例子而已。

+   - 黄亚生教授是我们投资的1366公司的董事，其实正是因為认识了黄教授才能够顺利地投资1366公司，投资1366公司，我们有幸认识了1366的董事长，美国投资界的大咖Carmichael Roberts，之后，通过Carmichael又投资了MC10和Soft Robotics，这是一个投资系列，而这个系列的源头就是黄教授。

+   - 最近我和黄教授分别在中国出版了关于创新的书，我的叫《全球风口》，专门讲我们这回带大家去美国看的积木式创新的模式，就是把高校科技和懂科技的企业家结合起来，用小企业来推动科技走入大众生活。而黄教授的叫《创新的创新》，专门讲美国的创新在模式上有什么创新之处。我跟黄教授高度认同，只有在模式上取得了突破，才能诞生大量的创新企业。简单地从表面上看美国有哪些创新企业，是不是又诞生了一个乔布斯或是Elon Musk并不能对我们的创新产生太多的启发和指导，我们需要深入地去挖掘人家机制上的创新，这才是造成美国今天创新繁荣的原因。创新本身也需要创新，创新的机制创新了，创新的企业是完全可以期待的。

+   - 创新与创业之间是有矛盾的。黄教授认为创新是开放的，但是创业是排他的。虽然呼吁大众创业、万众创新，似乎创新创业天然地是应该在一起的，但是当我们深入的时候就发现，一方面创新需要开放，只有你的科研成果被全世界共享，别人才能够在你的科研成果基础之上继续创新，才能推动社会的进步，才能实现科技的扩散，但是另一方面，没有人创业时希望被别人抄袭，你好不容易有了一个创新的成果，把它转化出来，突然之间发现被全世界抄袭的到处都是，这对创业是一种沉重的打击。因此创新创业表面上看是和谐的东西，但是深究起来是有矛盾的。

+   - MIT化解矛盾的经验和做法：MIT首要强调的是创新优先，大力支持创新，同时尽量在支持创新的基础上做到又能创新，又能创业。这个前后的次序是很重要的。产学研的体制不是鼓励教授创业，而是激励教授创新。在大量创新的基础上，找到可以形成产品的项目去创业。更重要的是，创业不是由教授来完成的，MIT的体制不是鼓励教授创业，而是鼓励教授通过知识产权共享的方式来孵化公司，进而获得很好的回报，反过来激励教授持续创新。而这个公司的使命就是尽快地把教授的创新变成产品推向市场，推动社会进步，使得创新能够尽快地扩散，能够让社会获得创新带来的好处。

+   - 具体的值得关注的细节：一、教授不参与知识产权转让的过程。MIT认为教授的核心任务是创新，如果教授自己一天到晚到外面找公司去谈怎么把创新尽快地变现，那是背离教授创新初衷的，因此MIT成立了专门的知识产权转让办公室来帮助教授处理相关事宜。二、限制教授在MIT教职以外的時間投入。MIT规定教授一周五天的工作时间里只能花一天的时间来做本职工作以外的事。比如，你用你的创新在校外参与了一家企业，成为了股东或者首席科学家，这并不意味着你可以把所有的時間、精力都花在这家企业里面，你每周最多有ー天时间能够照顾这家企业的事情，绝大多数时间必须专注在自己的本职工作，教学和科研上，也就是持续的创新上面。三、实现人力资源的最佳组合。MIT认为教授擅长创新，但是不擅长创业和管理。这就是为什么斯隆管理学院需要有创业课程，需要让读商科的学生和读技术学生来对接，需要成立强大的知识产权转让部门，从校外找到合适的企业与教授的创新对接，让企业家来推动创新转化成创业产品，推动社会进步。教授完成了创新的工作，他的工作就做完了一大半，在公司里面教授更多的是提供顾问服务的。让专业的人做专业的事。只要理顺了创新创业的关系，让创新优先，才能做到有更多的产出。

+   - 对于美国教授来说，一旦拿到了所谓的tenure，就是终身教授的头衔，他们基本上就不用担心职务与薪水了。因为该头衔意味着不可能被开除掉，所以理论上讲，这样的教授应该没有再继续创新的动力了。但是在一个优秀的高等学校里面，同行的压力往往会变成巨大的动力。你发现周围的人都如此优秀，而且这些优秀的人还如此地努力地奋斗。在美国，教授们不仅在论文质量和数量上相互较量，现在新成果转化公司的多寡也已经成了新的战场，美国很多教授由于在各个领域里面都有特别突破性的创新，经过学校的知识产权转让办公室的协作，他们的科研成果就可转化进入到许多公司里，而教授也在这此公司里面拥有了股权。这使得同行们形成了一个攀比机制，并形成了一种持久的动力，激励着美国的专利转化，创新繁荣和企业进步。那中国也需要聚集足够多的优秀人才，互相攀比，互相鼓励，互相协作，我们的未来就一定会更美好。
