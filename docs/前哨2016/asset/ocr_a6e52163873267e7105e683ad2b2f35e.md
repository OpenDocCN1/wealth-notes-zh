# 一千小时理论

一万小时定律：作家格拉德威尔在《异类》一书中指出：“人们眼中的天才之所以卓越非凡，并非天资超人一等，而是付出了持续不断的努力。1万小时的锤炼是任何人从平凡变成超凡的必要条件。”

要成为某个领域的专家，需要10000小时，按比例计算就是：如果每天工作八个小时，一周工作五天，那么成为一个领域的专家至少需要十年。

很多计算机专家多是1953年出生的，因为七十年代初正是计算机系统、硬件系统成熟的时候，1953年出生的人就有机会发挥自己的能力。

一千小时理论：现代，各种新的知识层出不穷，当一个新的理论突破出来的时候，不再需要从零开始学习。因为已经掌握了九千小时的基础知识，只需要再学一千小时就可以掌握。

计算机、大数据领域的专家转行投入到人工智能，很迅速就能变成专家。

# 越是前沿的科技，竞争越激烈

即使最前沿的科技，也不能轻易赶时髦。越是前沿，竞争越激烈，对手越多，风险也就越大。

思考好自己所处领域的核心优势，制定相应的策略，是每个创业者必修的功课。
