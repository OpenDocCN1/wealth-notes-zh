总的来说，柔宇科技在两个领域已经布局了，而去比较领先，那我们从全球科技企业的发展轨迹来为它判断，下一步应该更集中在实现量产上，而不是在多个领域里面铺开做突破，而无法看到量产产品。

中国政府喜欢资助海归带回来的科技项目，企业从政府拿到了足够多的钱，反而导致企业不再关心量产，直接将政府补贴变为利润。

坦白讲，我是觉得这对公司的发展并不利，因为企业最终需要让市场说话，产品最终需要走向市场。去推出自己的产品，实现产品量产和收入利润的良性循环，而不是大研发范围。

# 深圳柔微传感器科技有限公司

应用案例——

智能文胸，iBra。女性佩戴上这款产品，就可以实时监测胸部和躯干的形体姿态，通过体态日志对女性身材数据进行长期跟踪，提醒用户自主调整，帮助使用者塑造良好的体型。

塑性需求虽然在女性中存在刚需，但产品可以继续考虑和健身机构、医学机构产生合作，把大数据公布出来，使得女性能够更放心的购买。

我们中国虽然在基础科研上比较弱，但我们能够从应用开发上下足工夫。

# ——▶ 柔性印刷电路 ◀——

# 东山精密

柔性印刷电路领域中国还是做得不错的，最值得可圈可点的就是这家东山精密。

今年7月份，东山精密完成了对美国MFLX柔性印刷线路板公司的百分之百股权并购。

MFLX公司本来说是纳斯达克的上市企业，同时也是苹果公司的主要供应商，在全球专业柔性电路板制造商中排名第五。而东山精密原来是做精密钣金加工和铸造的，在上市以后就早早布局了LED，然后瞄准了这家美国上市企业。

![](bbox=[0.15, 0.00325, 0.9, 0.0036])

东山精密在1月份以高出当时股价的40%收购了MLFX，很快MLFX的股价迅速涨到了接近东山精密的收购价，而东山精密在7月份就完成了所有的收购，所以东山精密是相当有魄力的一家中国企业。这个小例子我觉得非常经典，中国企业利用外来资源提升自己的科技含量。

所以我们一直强调，虽然中国企业的科技比较落后，但是只要擅打科技牌，也是能够把外国企业的科技拿下的。
