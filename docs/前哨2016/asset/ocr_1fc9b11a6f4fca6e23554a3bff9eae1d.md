# 葡萄种植

专门用于酿酒的葡萄的种植一般选择在贫瘠的土地上。由于缺乏养分，葡萄的根甚至能够扎到八米深的地方，根扎得越深，越能吸收到各种复杂的矿物质，而这些矿物质最终造就了葡萄酒各种各样复杂的味道。

# 品鉴味道

越是好的红酒，它的味道越是复杂，品酒的核心在于识别出酒里富含的各种香味。

这种复杂的味道要有层次、结构和均衡感，需要像欣赏香水一样有一个前调、中调、后调这样的逐层递进的过程。一口闷可不是品酒的节奏，既要仔细地分辨酒中蕴含所有香味，也要慢慢地品出时间带来的细微差异。

# 科学训练

鼻子不像大脑，它没有想象力，除非你闻过，否则完全无法通过描述想象出一种味道。为了能够辨识出所有的味道，你必须像训练记忆力一样训练鼻子，尽可能尝试不同的味道。

1980年，法国人让·勒诺瓦发明了叫作酒鼻子的葡萄酒香气标本用来帮助人们系统地训练嗅觉能力。
