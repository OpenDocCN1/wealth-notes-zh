# 医疗机器人

手术辅助是机器人医疗应用主要方向。

1985年，研究人员利用一台叫做Puma 560的工业机器人完成了机器人辅助定位的神经外科活检手术。这是机器人辅助手术实施的处女秀。

# 行业特点

缺点：产业化的周期长，进程慢，注册审批时间长。

优点：市场格局非常稳定的，各个细分市场泾渭分明，容易形成寡头垄断；技术和经验可以在不同的科室间复制应用。

# 手术辅助机器人领域

手术辅助机器人能够解决传统手术中的三大难题：

+   1. 人手操作的精确度较差；
2. 复杂手术的时间往往过长，医生容易疲劳；
3. 医生视野在人体容易受到阻碍。

目前，Intuitive Surgical公司的达芬奇（da Vinci）手术系统系列是最著名的手术辅助机器人，公司早在2000年就登陆了NASDAQ。

手术辅助机器人创业优势在于，虽然技术是开源的，没有太多的壁垒，但是FDA的认证是一个很强的壁垒，通过认证是一个漫长的过程。而先获得认证的企业在往各个医院的销售上就有了先发优势。这是医疗器械相关领域独特的地方。

美国Monteris Medical公司的NeuroBlate系统专门用于脑部肿瘤切除的手术辅助。

在骨科尤其是关节置换领域，比较著名的机器人有Robodoc、Sculptor RGA、RIO、MAKOplasty。

在导管介入领域，比较著名的是Hansen Medical公司的Sensei导管控制机器人系统，其联合创始人Frederic H. Moll还创立了另外两家机器人公司Auris Surgical Robotics和Restoration Robotics，分别关注于眼科和植发手术。

# 医用服务机器人领域

远程医疗方向的机器人大多在研究阶段，还没有特别成熟的产品上市；

医疗物资运输方向的机器人正在被许多物流利用，包括无人机和地面的运输机器人；

药房管理方向的机器人主要完成药品的配送。

# 医用康复机器人领域

医用康复中的机器辅助移动设备有四家领先企业，以色列的ReWalk Robotics，美国的Ekso Bionics，新西兰的Rex Bionics和日本的Cyberdyne。
