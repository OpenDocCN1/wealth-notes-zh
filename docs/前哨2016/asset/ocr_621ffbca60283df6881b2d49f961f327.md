# 为什么投资科技企业？

我们都知道高端烈酒市场一定非常传统，为什么加拿大科技创新企业可以获得它的投资呢？

因为鸡尾酒也是高端烈酒市场的一部分，而更重要的是占边三得利看待了一个趋势：全球的中产阶级都希望提高自己的品位，在品位提升上，能够在家用更便捷的手段得到更高端周的服务，永远是市场的追求。

以往我们想喝鸡尾酒会去酒吧，我们付的酒钱一部分是给调酒师，而如果在家有家用鸡尾酒机，享受的机会就大的多了。这也是一个把高端服务通过科技手段平民化的生动例子。

# 伴随新科技产生的的 新兴市场

最近听了罗胖新一期节目，叫做《老办法抓不住新机会》，他说希望做一个叫做知识的运营商，把最前沿的信息最快捷的传递给更多用户。他认为中国有一个新兴的中产阶级市场，而这个市场需要用知识武装自己，所以要用最省时间的方式来帮中产阶级获取最新的知识。

我由此悟到，所有成就巨大的创业都是和新兴市场一起长大的。为什么呢？

能够成就巨大的一些企业，有一个特点，它们往往是在整个历史发展的不连续点获取的机会，一种是政治的不连续点，二战之后，全球兴起了一批新兴企业，然后做到跨国化。另一种是经济上不连续点，中国的改革开放后，塑造了一批成功创业企业。那其实最主要的是科技上的不连续点，新的科技往往伴随着新科技会产生一批创业企业。

# 新兴市场有多重要？

最核心的其实不是科技，最核心的是新兴市场。

当一个新兴科技来的时候，传统企业也能雇佣很好的科技人员，也能掌握科技。而当一个新兴市场来的时候，往往会伴随着的是思维方式和行为方式的转变，而一个传统企业往往在这儿会碰到创新者的窘境。

比如Web2.0，能在互联网上做互动的技术并不是Facebook发明的，Facebook只是一个技术使用者。但是因为Web2.0使年轻人希望在网上不断互动的需求被满足了，他是第一个拿这个技术来满足年轻人需求的成功的企业，所以它创造了一个全球的最快成长记录。

所以抓住新兴市场，伴随市场一起成长，往往就造成企业脱颖而出。而这中间，技术只是扮演一个支撑的角色。

# 中国的新兴市场

很多人都在讲，中国新兴市场现在叫中产阶级。而新兴中产阶级最大的一个需求是装品位。而今天所说的家用鸡尾酒机就满足了这一点。

由此引申，中国现在这方面需求巨大，成就巨大的创业都是和新兴市场一起长大，中产阶级现在刚刚成型，未来还有很大空间，你今天来创业，等到中产阶级需求爆发起来的时候，你就成就巨大。
