# 过去的招商引资

中国改革开放三十多年，招商引资是一个贯穿始终的政策，各大开发区不断吸引世界五百强入驻，带动本地经济的同时，也带动了中国制造业的繁荣。

如今中国的招商引资不再是为了钱，而是高科技。而现在全球创新规律在变，已经不再由500强公司主导。

# 中国换来技术的时机

美国现在有上万家小公司，没有任何利润收入，依靠融资和投资，专心研发，通过研发上的突破带来未来的发展。

高科技小公司潜伏期5-8年，产品上市后经历5-8年，就能成长为一个新兴的世界五百强企业。而风险投资的介入期和中国制造业跟国外高科技企业对接的时机，是5 - 8年科技研发期的尾声。

比如特斯拉，它市场领先，这种时候投资引技条件无疑是苛刻的，他要真正把先进技术带到中国机会也非常小。

但如果一个产品研发刚刚结束，拥有世界最先进的科技，需要中国制造业帮它实现量产，也需要打进中国市场，中国的资金还能解决全球市场和生产需要的资金，中国对这个产品来说无疑有强大的吸引力。

# 新概念：招商引技

大的改革开放方向不能变的前提下，招商引资要做调整。因为对方不是资金雄厚的大企业，所以不需要引资。而是需要引技，因为对方是世界技术最强的、拥有前沿技术的公司，所以叫招商引技，而不是招商引资。

而招商引技难题在于没有一个清晰的合作名单，解决方法是建立公开科学的评价机制：

+   1. 直接评价，是否拥有独家开发或独家授权专利；

+   2. 间接评价，参考先进的风险投资企业，建立天使投资白名单。

招商引技具体的落实制度也需要做调整，更关键的是先进科技，而非必须是中國企业；同时需要建立专利保护机制。

前瞻性布局很重要，世界一千强数据变动巨大，小企业成长非常快。

中国要摆脱过去传统的来料加工，提前和国外的高科技公司合作，成为最重要的合作伙伴。

和全世界创新者合作，形成自己对创新的理解，中国一定能用制造业换来世界最先进的研发水平。一旦产业研发做到了世界最好，那中国的经济就一定独步世界。

所以中国对外的企业合作、政府合作，甚至是投资合作，一切核心都应该是招商引技。
