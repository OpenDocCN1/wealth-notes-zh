# 周末问答｜再议产融资本

再议产融资本

王煜全

前面我们讨论了好几期关于“产融资本”的话题。发现越讨论就越多的人提出更深入的好问题。

因此，为了让大家了解的更透彻。我们把这个话题再议一期。

您觉得产融资本由谁来主导会好一些，产业资本还是其他企业服务机构？另外您觉得产融资本能不能做好的核心是什么？因为我们在做资源整合的事，未来融合才是大方向，所以也在考虑产融资本的事情。多谢。

王煜全

我觉得这个问题问得很关键。按我们的理解来说，产融资本应该由产业主导，资本配合。

现在，很多西方人创业就有一個逻辑，最好的CEO应该是学技术出身，再去研读了MBA。因为学技术出身才能对技术有足够深的了解。对企业经营而言，你必须要有感觉后才知道怎么去操作，所以当你培养了感觉再去读MBA，就能够两全其美了。

我不建议先学企业管理，再去学技术，因为上学时学的企业管理都只是纸上谈兵，工作以后再去学技术，往往学不深，而技术是需要多年积累的，因此颠倒不成立。

一样的道理，因为产融资本是为产业服务的，所以你对产业的理解一定要非常透彻。而金融是工具，好的金融从业者应该是能够根据产业需求灵活运用金融工具去设计相关解决方案的，所以应该由产业主导，金融配合。

当然，最好的还是跨界人才，在产业界做过很多年，然后又因为产业进入到金融领域，在金融领域也有了不少的积累。相当于先学技术，后读MBA的这类人，他们自然是最好的参与者。

产融资本能不能做好的核心，其实需要两方面的兼顾，一方面必须要有对产业有足够的了解，知道如何去放大产业的能力，包括协调好产业资源。另一方面就是不能有偏差，不能只强调一切都是为产业服务，还要学会运用资本的放大能力，将产业和资本一同做好。

可以认为产业基金也是产融资本的一种形式吗？现在上市公司对这方面也都很关注，一些公司也在积极寻找好的并购对象。

王煜全

我认为产业基金是产融资本中很好的一种形式，只不过中国对上市公司金融层面监管突然放松了许多，尤其是上市公司并购，基本只需要备案就好。

所以造成了大量上市公司为并购而并购，为了找到下一个热点概念而并购，它们更强调短期行为，因为并购的钱是从市场上悠悠来的，自己并没有出钱。

如果并购效果不佳，公众也就忘了它，在股市上也不会有负面回报，所以这是一个比较普遍的短期行为操作。

但我认为这和产融资本的初衷是相背离的。因为产融资本的核心是为了支持产业发展，而现在上市公司的这种并购其实有点舍本逐末了。

我认为，上市公司应该充分利用现在政府在政策上放开的黄金期，积极地为未来发展做好铺垫。假设有一天政策重新收紧，上市公司的并购不再那么容易时，你把今天的机会都浪费在了并购一堆垃圾概念上，对未来没有注意，就容易吃亏。

一定要学会积极地为未来作准备，趁着今天并购还容易的时候，去寻找最好的并购对象，而不是寻找那些所谓的科技概念并购。

国家资本占了制造业过大的比重，这对产业升级是有利还是有害？

王煜全

不能一味地妖魔化国家资本，国家资本在产业上也是有帮助的。因为民间资本容易过度追逐短期利益，而国家资本会考虑的更长远。

比如，中国移动当初做的移动梦网就是国家资本，移动梦网时期的分配比例是85:15，自己拿15%，分给合作伙伴85%，以便大家都能达到共赢。这就造成了当时移动梦网的极大繁荣。

即使移动梦网后来因为种种原因繁荣不再，但它无疑也为今天的移动互联网繁荣奠定了基础。而大家也都知道，中国移动互联网在全球都是非常有实力的，这其实和当初中国移动扶植的产业有很大关系。

到现在为止，私有资本中，包括腾讯、阿里巴巴，它们在与合作伙伴的合作当中，都从来没有达到过85:15的比例，尤其是腾讯，在合作伙伴还比较小的时候，腾讯是有些胸怀的，腾讯拿三，合作伙伴拿七。

但是当合作伙伴逐渐做大的时候，腾讯的胸怀就没有了，反而变成倒三七开，而且会以各种各样的方法挤压合作伙伴的发展空间，这都是因为私人资本的逐利性造成的，所以不能简单地说国家资本占比过大就有问题。

但是，国家资本占比过大也不是没有问题，例如它在对CEO的考评上以及给予CEO的待遇上，都不如私人资本那么灵活。

如果国家资本在考评上也能参照市场导向，给CEO的待遇能参照行业内其他私人资本，我认为国家资本并不会造成过大的损害，很可能反而有利。

资本的逻辑就是追求自身最大的增值，这个没什么，但资本往往又是短视的，而且有一套自己的操作玩法。比如最近围绕宝能的几次并购，投资优秀的企业，却不是为了把企业制造成好，而是变成金融资本去套现。

在东北就有很多这样的情况，外部资金利用政策收购当地传统制造业，目的却不是想企业做好，而是为了企业的地皮，或者利用企业抵债套现。

那么在没有相关完善的法律法规推行之前，如何规避这种情形。

王煜全

我认为这并不是资本的问题，而是一个阶段性的问题。在现阶段，中国的资本产业发展还处于早期，就意味着会有很多人去钻资本的漏洞。

美国资本的游戏规则就非常清晰，所以企业收购后去套现提财的这种做假自然较少。当然美国也有恶意收购的存在，就是把企业收购后再分拆卖掉，但是它往往都遵循着产业的游戏规则，就是分拆再卖掉，也要分拆后总和大于分拆前时，它才会选择分拆。

所以，一切都要对企业发展有利，因为企业发展有利才会实现增值，增值了以后才会有资本回报。

所以，我认为这个困不是资本的问题，因为中国资本本身也是个产业，产业发展不健全的情况下，就会有哄人利用发展期的问题来赚钱，这个是我们需要警惕的。

但是也有解决办法。第一，让它发展，让金融业发展得更完善了以后，这些问题就不存在了。第二，产业界的人要学会利用金融。

不要在那里被人家族负了以后再去喊，像宝能这件事情就是典型，万科早就应该理解决，如果自己没有一套好的管理层控制手段，当然会被人家踩踏，因为规则早就写在那里了，而且这个规则并不是因为宝能进来后才修改成今天这样的。万科的隐患早就存在，但它一直没有去弥补。

所以我认为，中国的企业一定要更加慎重地去研究中国的资本。一方面避免被别人利用，另一方面甚至可以积极地利用现有的产业相关机会去追求更大的发展。
