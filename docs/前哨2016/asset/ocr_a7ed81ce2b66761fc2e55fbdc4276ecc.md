# 区块链是啥

区块链是比特币背后所有支撑技术的总称，也就是说比特币是区块链技术的一种表现形式。区块链是把加密数据（区块）按照时间顺序进行叠加（链）生成的永久且不可逆向修改的记录。区块链技术是下一代云计算的雏形，有望像互联网一样彻底重塑人类社会活动的形态。

理论上，区块链可以创造出无数种货币。

比特币是可以无限分割的，因此，小而美的商机就是投资比特币。

操纵比特币的想法基本无法实现，因为它的内容是加密的、过程是可追溯的，因此安全可靠。

区块链技术支持货币，但它不是一个货币，它是一个分布式系统。

区块链1.0就是货币，比如比特币、莱特币、熊猫币等。

区块链2.0就是广义的金融领域应用，比如智能财产和智能合约、股票、债券、期货、贷款、抵押、产权交易等。

现在已经到了区块链3.0时代，区块链的应用已经扩展到金融领域以外，包括医疗、司法、物流、政府、科学、文化、艺术等领域。
