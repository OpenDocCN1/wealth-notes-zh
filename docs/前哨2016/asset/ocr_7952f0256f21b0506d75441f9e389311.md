# QuantuMDx

成立于2008年的英国医疗设备服务商。

它生产了一款叫做Q - POC的手持DNA分析设备。如果想要用一个样本进行多个项目的检测，用DNA检测是最理想的方式，这家公司就是做这样的检测。

只需要采集一滴血，QuantuMDx设备就能够检测出采血对象是否感染了疾病或病毒，不仅仅可以检测出各种各样的病毒，还可以检测出病人所感染疾病或病毒的抗药性，整个检测过程不到20分钟，检测结果可上传到云端，辅助医生作分析。

所以，我们能看到Point of Care是个大趋势，一个点能够测试多项内容，然后迅速出结果，同时支持云端服务，甚至一个技术能够拓展到多个领域，这都是未来的发展趋势。

# Wicab

我投资了一家Wicab公司，这家公司的产品叫Brain port（大脑港）。它利用微型摄像机把眼前视频采集下来，再将光信号转换成等强度电信信号，然后用400个电极去模拟电信号，刺激舌头。

经过训练，这些数据能够被放到盲人的大脑视觉区中进行处理，盲人就能够接收到外部三维世界的动态信息，还能够作出立体的解读。

这个产品在去年已经拿到了美国的FDA，我也在积极地跟中国医药局沟通，希望在中国能够迅速注册，从而让这个产品为中国盲人带来更多福利。这确实是一个具有突破性的了不起的发明。

# Hocoma

这是一家瑞士的公司，它开发了一款可穿戴的医疗工具Valedo，它的目标患者是长期受下背疼痛和相关并发症困扰的病人。已获得FDA认证。

# —— 国内企业 ——

总的来说，国内可说的并不多，因为国内的一些企业技术还相对比较陈旧。可以说的公司我也列了几家。

# 广州万孚生物

它是一家上市公司，做的是快速诊断试剂、快速检测仪器等。但快速诊断仪器并没有多么创新，还是属于传统品类。但它从2004年就开始开拓海外市场，截至2015年12月31日，已经获得了FDA认证58项，CE认证110项，加拿大MDALL认证3项，产品销往到了100多个国家和地区，我觉得这是一个了不起的地方。

# 三诺生物

三诺生物是一家致力于利用生物传感技术研发和生产即时检测的高科技公司。简介上比较花哨，但还是血糖检测，和其他公司区别不大，说白了都是罗氏这类公司做过的大路货，因为中国一直有一个进口替代的趋势，国外做了什么，就去替代它。但替代的往往是国外已经相对成熟的技术，国外最新的技术却都看不到，也就无法替代了。
