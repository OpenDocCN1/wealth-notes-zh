# ——►柔性电路板◄——

美国现在基本上已进入到了导电油墨阶段，它不再像生产实体产品一样生产出一片金属来，而是直接用导电油墨打印。导电油墨和导电胶的市场，预计到2026年会达到17亿美元，相对于前面两个领域市场虽小一些，但依旧可观。

尤其是3D打印的电子产品和印刷电路板打印机两个产品正在全球流行，这也会让可导电的油墨和导电打印市场变得更大。让我们先来看看国际上有哪些值得关注的公司。

# C3 Nano 公司：

2010年在加州成立，现在已经拿到了2000多万美金的投资。它的主要产品是用透明的可导电墨水来替代传统的氧化铟锡半导体的透明导电膜。

这东西是干嘛的呢？简单来讲，就是触摸屏的触摸层。当我们的手指碰到触摸屏上时，触摸层能感受压力，然后把压力转换成电信号，使得整个屏幕能感知到我们手指触摸到了什么地方。

传统的办法是用氧化铟锡做触摸屏，而现在的做法是用银纳米纤维技术，这个技术同时也是具有柔性的，可以做在柔性的显示屏上。也就是显示屏可以折叠，可以弯曲，那我将可触膜贴在你的屏幕上，你的屏幕就可以变成可触摸的了。

这个技术来自于我们这之前介绍的斯坦福大学非常年轻出色的华人教授——鲍哲楠。鲍教授和John Rogers，MC10公司的首席科学家，一起做了很多联合的开发工作。所以它们的技术非常领先。

# Nano Dimension 公司：

Nano Dimension 是2012年成立的。这家公司非常有趣，它非常小，但两年之后就在纳斯达克很快的上市了。

在中国是有准入限制的，所以大家一般理解的上市公司都很大。但是在美国，实际上你可以没有利润，公司规模也可以很小，但能够上市，这就是所谓的小盘股，尤其是纳斯达克上有很多的小盘股，这也是其中之一。

到现在为止，它的市值也就6800万美金，没有多少钱。但是它生产的3D打印多层印刷线路板是未来的一个趋势。为什么呢？因为用3D打印多层印刷线路板可以做到电子产品的个性化开发和个性化生产，这一点是未来。

# Canatu 公司：

这是一家2004年成立的芬兰公司，是芬兰赫尔辛基技术大学的一个分技术。它也是做柔性电子产品表面触摸屏的可触摸部分。它与鲍哲楠教授技术的不同之处在于，canatu是用碳纳米管技术和富勒烯，富勒烯是碳纳米结构的碳管或者碳球。

如果石墨是一平层的碳原子，钻石是立体的碳原子组合，那富勒烯就是第三种状态，碳纳米管就是一种富勒烯状态的碳原子。它能够让触摸屏表面的触摸被感知，所以大多用在消费类电子产品上，尤其是汽车品牌。

科技最大的好处和最大的坏处都一样，它就叫跨界，你永远不知道竞争对手来自于哪个领域。就如同我们常说的，真正干掉柯达化工公司的其实是手机电子产品，所以未来真正干掉计算机会不会是碳这类传统的新材料呢？真的不好说。

至少我们现在看到，碳纳米管越来越多的侵入到传统的计算机领域，这个是可见的，我们如果要研究科技，就必须对它的全局有了解，要不然的话会挂一漏万，错过很多好东西。

# ——►柔性电池◄——

越来越多的产品变得柔性，电池作为一个重要的配套，当然也需要柔性化。

2015年时柔性电池的市场还很小，只有5000万美元，但预计到2020年就会达到61700万美元的市场，增速还是非常快的。因为无论是什么样的电子产品，它都无法绕开电池。

柔性电池的提供者中，三星和LG都有自己的柔性电池部分。

# 三星公司：

三星的柔性电池叫三星SDI，它现在做的是可折叠的210毫安时小电池，大多用在可穿戴设备里，电池本身的厚度可以做到0.3毫米厚，能够在人的手腕上进行5万次的弯曲折叠，而且不出现任何的故障，所以这个电池的可靠性还是非常高的。
