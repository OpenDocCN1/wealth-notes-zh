# ——► 国外创业公司 ◄——

国外的创业公司在小型医疗器械领域是非常活跃的，而且分成了不同的类型。

有些偏向于平台型，产品大多具有广泛的适用性；有些偏向于特色型，产品有很多创新的地方，使得用户在治疗中能够获得明显的效果。

# Butterfly Network

在我看来，平台型企业中，比较典型的是 Butterfly Network（蝴蝶网络）。

Jonathan Rothberg是著名的生物科学家、企业家、投资人，同时也是麻省理工学院的教授。他联合了一批从校的物理学家和工程师，共同创立了Butterfly Network，旨在打造全世界最小的超声成像设备。
