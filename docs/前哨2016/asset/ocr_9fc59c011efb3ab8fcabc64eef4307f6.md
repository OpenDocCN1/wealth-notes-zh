# ISORG公司：

ISORG是2010年在法国成立的公司，现在已经拿了接近1000万美金。它的传感器是光传感器，能够使得任何一个大型东西的表面形成对光的感觉，甚至形成对影像的感觉。而它又是柔性的贴在玻璃表面的，所以未来玻璃都会像你的眼睛一样，对周围的影像能够产生监测。

# MC10：

传感器部分最重头的就要说到我们投资的MC10了。MC10是2008年在麻省波士顿成立的，迄今已经拿到了超过6000万美金的融资。MC10最主要的特点就是它由首席科学家John Rogers提供技术。John Rogers是伊利诺伊大学的教授，也是柔性电子领域在全世界的领军人物。他其中一个成果就是MC10。

其中一个产品是橄榄球运动员用的软帽子，戴上这个软帽后，帽子会伸出一个尾巴来。当橄榄球运动员发生激烈冲撞的时候，想要检查运动员是否发生脑震荡，只要看看他头盔背后露出来的软帽尾巴，尾巴上指示灯如果是红的，就得立即下场；如果是绿的，继续投入比赛；如果是黄的，坐在场边休息，观察一下。因为冲撞的强度都能够被记录下来，所以它的第一个柔性电子产品已经变成产品化了。

![](bbox=[0.05, 0.428, 0.92, 0.525])

MC10真正杀手级的电子产品是biostamp，叫生物印章，相当于把一个东西像印章一样贴到一个人身上，它就能记录上各种生理指标。生物印章现在从终端产品到云端，再到整个后台服务系统都已开发完成，正在和美国几个非常棒的医学机构合作。就是利用生物印章贴到患者身上，对医学数据进行持续的记录、跟踪和解读。

我们希望中国也有更多的医学机构能参与到这种合作中来。因为我们一直讲，从全球角度上讲，先进科技开发固然重要，但先进科技的首先运用往往也意味着你能够成为最大获益者。
