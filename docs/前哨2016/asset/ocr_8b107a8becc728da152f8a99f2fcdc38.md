# 国际上的现状

在硬件领域里，机会不少，但主要都是国际大公司参与其中。

小公司除非在硬件上有非常强的科技，而且有一定的开发实力，否则，慎入硬件领域。

在软件领域里，大公司的布局也非常频繁。

谷歌和IBM并不想做专门用于下围棋或智力问答的系统。而是希望借此进入有更大市场空间的领域。

人工智能加上大数据，往往就能改变行业的现状。

在一些看似机会比较大的领域，恰恰大公司早已经重点布防过。

不管是硬件还是软件，都要慎入。

# 人工智能领域的热点

人工智能领域的细分，包括机器学习、自然语言处理、计算机视觉、算法、图像识别、语义网、语音识别等。

通过分析AngelList网站上小公司的融资数据，能判断出一个领域到底适不适合小公司进入。

从数据可以判断出：

+   一，虽然人工智能很多重点领域被大公司盘据，但整个人工智能市场，小公司还有大量机会，尤其是机器学习。

+   二，现在要和应用领域产生互动，要从现实互动中获得反馈，进一步训练计算机、训练人工智能程序。所以自然语言处理也非常热，而且未来有很大的发展空间。

# 中国的现状

中国在硬件领域，已经有大量大公司在做研发，但还没有特别突出的表现，也没有特别成熟的产品。

中国的软件应用很活跃，尤其是和现实应用结合的人工智能应用类开发。

国外大公司的人工智能着重于开拓新的潜在市场，而中国大公司的人工智能主要着重于和现有的业务结合。

# 机会

中国小公司和国外小公司一样，只要不和大公司直接对抗，机会很广阔。

两个重点：

+   第一，一定要和应用相结合。

+   第二，一定要选好合作伙伴。对方要在行业里有大量的应用需求，同时还能提供本领域的数据集。

虽然大公司在人工智能领域积极布局，基本把眼前看得到的机会都占据了，但是仍然有大量的机会，小公司可以介入。
