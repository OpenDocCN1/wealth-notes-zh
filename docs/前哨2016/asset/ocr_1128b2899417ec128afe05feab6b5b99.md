# 以色列Storedot公司

Storedot设计了一种快速充电的电池，叫做Flash Battery。这种电池充电速率比普通移动设备电池快100倍，能够在60秒内为智能手机充满电。而动力电池方面，快速充电EV电池可以在5分钟内存储足够的能量用于300英里（480km）的范围。

Flash Battery使用了独特的混合多功能电极，结合了锂离子电池和超级电容器两种类型的能量存储解决方案，将超级电容器的高功率快速充电能力与锂离子电池的高能量存储能力和低自放电率结合。

Storedot在2016年的CES展上展出了这种电池的demo，目前已获得了 $66M的融资，其中三星参与了A轮和C轮的融资，未来很可能有收购的意向。

# Solid Energy

Solid Energy脱壳于美国麻省理工大学能源实验室。

2014年成功开发出了目前世界上体积能量密度最高的“无负极”电池，这种第三代锂电池使用一种超薄到近乎没有的金属负极和更加安全的电解液，能够在有限的空间里提供传统电池两倍以上的电池容量，能使智能手机变得更加轻薄，手机待机时间和电动车续航里程翻番，而且电池价格变得更低，其新型锂金属电池的能量密度能达到1337Wh / L。

Solid Energy获得了美国通用汽车和美国应用材料公司的B轮战略投资，共同致力于无负极新一代锂电池的产业化发展。中国最大的汽车上市公司上汽集团也对其进行了B轮战略投资。三家机构在B轮融资中总共投资1200万美元。

Solid Energy目前正在致力于无人机电池的投产，计划于2017年投产手机和电子消费类产品的电池，2018年大规模投产电动车电池。

# Enevate

2006年成立于美国湾区。Enevate的HD-Energy技术使用以硅为主要材料的新型复合负极，能量密度是传统石墨负极的4倍。

Enevate CTO表示其技术适于大规模生产能量密度很高的锂电池。2016年初Enevate和智能手机厂商Sonim Technologies达成了合作关系。

2011年8月完成1000万美元天使轮融资；2015年9月完成2400万美元B轮融资。Enevate称此轮融资将帮助其HD-Energy技术的商业推广，并进入面向客户新一代平台的生产阶段。Enevate投资者包括了中国的青云创投。
