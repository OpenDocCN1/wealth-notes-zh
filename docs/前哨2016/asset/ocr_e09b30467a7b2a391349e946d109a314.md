# 第三、跨境并购还在交学费的阶段

报告里举了很多例子，表明了中国的跨境并购在急速上升，但是我认为有两点需要我们注意。

# 1、中国的跨境并购其实有大量被坑蒙拐骗的例子，它们都各有原因。

中国相对财大气粗，不太在乎价钱。

对本地情况不熟悉，经常会出价过高。

老外觉得中国人人傻钱多，愿意出高价。

所以，综合起来，中国的跨境并购吃了很多亏，希望我们学费不要交太久，尽早成熟起来。

中国的跨境并购应该先从跨境投资开始。

并购中投资太多便成了股东，当你成为了最大股东时，你需要为公司的未来发展负责任。但是你如果只是一个战略投资或者财务投资，风险就会小很多。

最应该走的路，不是在全世界各地跨境并购，而是应该做大量的战略投资布局，通过小额资金的投入占一个小股份，向国外的大股东学习如何治理管理一个企业。当你认为有管理能力的时候再并购，你才能顺利接手管理这家企业。

虽然很多并购保留了管理团队，但是你需要时间去了解如何控制住管理团队，所以应该从投资开始，而不是并购。

# 2、从投资当中覆盖更多的企业，持续地观察这些企业，再根据企业的实际情况并购真正可靠、业绩最好的团队，这样更加稳妥。
