# 周末问答｜技术转化行业如何才能不再“冷清”？

王煜全

我一直提倡积木式创新，提倡双长制——好的科学家与好的企业家结合。美国在这方面做得相对不错，华盛顿从拜杜法案推出到现在已经有30多年了；但是中国的技术转化市场却不那么令人兴奋。有人说我们没有真正好的科研，有人说我们没有好的企业家。

我看到有一位前哨的用户在国内从事技术转化工作，有一些困惑。这是好事儿，说明我们看到了目标，正在发愁如何到达。技术转化工作是创新生态中必不可少的一环，真心希望这方面能够有很好的发展。

我们从事技术转移工作，目前国内的技术转移行业可以用“冷清”来形容。一方面，高校大量的科研成果，由于立项时就与市场脱节，以及机制、体制问题，无法满足企业家实际需求，转化率较低。另一方面，企业有大量技术需求，但又无法与高校的科研成果直接对接。

王老师讲过，美国有大量专门进行高校科研成果孵化的多次创业的企业家，目前国内的企业家群体还没有形成。

以上这种状况，我想提两个问题。

# 问题1：国内技术转移机构，应该从何处切入，实现高校科研成果与企业、产业对接？

答：这是个很好的问题，也是个很难解决的问题。我更喜欢“技术转化”而不是“技术转移”的说法，所以，下面我还是用技术转化这个概念。

我其实在不同的场合一直都在说拜杜法案的推出对于美国技术转化的意义和价值到底有多大。但是，这个法案也不是理所当然就会出现的，很大程度上是企业界、科研机构和大学以及技术转化工作者共同努力的结果。

目前的情况来看，中国政府层面已经意识到技术创新对于创新创业、产业转型、经济发展的重要作用，但是具体的执行上可能还不太有效，我们往往喜欢去问科学家，而不是去问企业家，实际上真正能够将先进技术转化为生产力的，反而是那些有经验的企业家。

能掌握前沿科技的企业家才是社会的最先进生产力，要把拥有前沿科技的企业家摆到最重要位置上来，因为他们能带动中国“科技强国”梦的实现。

所以一定要来倒推相关政府部门的政策改变。国内的技术转移行业，从大的角度来看，应该在立法上多做一些工作。国内有相应的技术转移的法规和政策，但是具体的执行的时候可能就不那么奏效，甚至会出现让人非常遗憾的事情，比如浙江大学的那位副校长。这就说明，我们的法规和政策可能还不完善，还需要做更多的工作，这其实很大程度上是技术转移工作者的使命之一。而完成这种使命，可能需要很多方面的支持和推动。这里面是有很多工作可以做的。

# 问题2：美国进行技术转移的机构，在进行高校科研成果与企业、产业对接方面，有哪些商业模式可以被国内技术转移机构借鉴？

答：美国主要的研究成果都是从高校里面产生的，很多高校自身带有丰厚的科研基础和广泛的产业连结。那么美国的高校就要有专门的科研转化机构，来专门负责把科研成果和外面的公司、产业机构对接起来，使科研成果能够顺利转化为产品，上市，推动社会发展。这个团队里需要专业的技术人员、法律人员、商务人员等，职业化、专业化的团队很重要。

Association of University Technology Managers（AUTM），这个组织推动了拜杜法案的出台。它是各个高校里负责技术转让的负责人组成的一个商业机构，这个协会现在已经有了两万人的规模，每一次开年会都有近两千人参加。波士顿大学的文立民老师在这协会里有有十几年的会龄。

我们海银资本从三年前开始已经连续三年赞助了这个协会的年会，在今年2月份San Diego举办的AUTM年会上，很多中国人聚集到一起，成立了一个新的机构，叫做华人技术经理人协会，文立民老师是第一任的会长，协会成立大会上他们评了三位外部的顾问，很荣幸我就是其中的一位。

技术转让是一个非常专业的工作，需要有很多年的经验积累。国外的技术转让工作做得很早，有很多的经验，你们可以跟他们多多交流和沟通，如今也有了华人技术经理人协会，交流起来会更方便一些。

关于你的问题呢，我还有一些建议。

第一个建议：比如要尽快建立起信用体系。我们在评价一项技术的可行性的时候，标准有时候很不一致，可能政府部门职位比较高的人的话语权更大一些，市场和企业家的话语权反而要小，结果就是很多资源就会错配，往往政府支持的很多资源就会被浪费掉。

如何建立起一套信用评价体系，让技术转化的各个环节上能够尽快实现透明、高效，让企业家和市场能够发挥最大的作用，这是个很基本也很要命的问题。

第二个建议：如果你觉得国内的技术、体制或者环境不是那么理想，可以多跟国外的做些交流与合作，其实在美国有很多很多高新技术企业，他们默默无闻地做着研发工作，如果能与中国企业、资本和市场有效对接，会有巨大的发展机会。

本周五我们前哨团介绍的宾州大学郭猷楚同学参与的Y-prize项目，就是一个很好的例子，他们拿到了宾州大学纳米科技的先进技术，想通过前哨的平台征集应用解决方案。还有很多的海外华人，他们要么手里有先进的技术，要么知道先进的技术在哪里，但是往往被那些动作更快的曰韩企业给抢先了。这个时候，经历过30多年经济的高速增长，手里有大量的资本，有强大的制造业基础，有巨大的市场，也该轮到我们中国人了！

所以，如果再给你一个建议的话，那就是跟我们前哨合作，跟海银资本合作吧！

# 科技概念股 | 无线充电会在明年到来吗？（上）

无线充电会在明年到来吗？…

王煜全

今天给大家讲讲未来科技概念股的第三个——无线充电。

以下内容是干货笔记，完整内容欢迎收听音频。

# 为什么是无线充电？

任何一个未来科技概念股，除了它本身有非常强的技术和非常明确的市场应用以外，还需要一个触发因素，比如新闻。而无线充电的概念就是在很多人预计iPhone7会带无线充电功能的假新闻中爆发。

这个消息不是空穴来风，苹果一般是可以对行业标准或技术标准做出规定的，也就是说一旦它里面带了什么样的技术，这个技术就会在整个行业，甚至在周边行业里面蔓延开来，造成更多其他公司的效仿、跟随。

在iPhone7推出来的之前，很多人 在预计无线充电功能。而美国有一家叫Energous的公司，号称是给手机提供无线充电的，还自称和苹果公司有些合作，因此这一段时间内的它的股票因iPhone7的热潮上涨了两倍。

虽然iPhone7推出以后，并没有无线充电，但我们还是坚信明年应该一定会触发。

在明年，无线充电将有两个比较强的触发机会——

一个触发点：就是2014年时，intel公司宣布了No wire的计划。大约十年前，intel成功地推出带wifi功能的笔记本电脑芯片，现在推的No wire的计划，就是希望把把充电这根线再去掉，让笔记本电脑真正彻底无线。戴尔笔记本电脑领域还是有很大影响力的，它一旦推出的话，至少有大量的笔记本电脑都会跟随。所以这是一个触发点。笔记本电脑的无线充电推出后，就会产生对小家电，小电器充电能力的需求。

另一个触发点：现在越来越多电动汽车推出，我们预计，从2017年初开始，有两三款的日系的汽车就会推出自己的电动车，带有无线充电能力，再往后美系和德系车都会跟上，所以2017年，2018年几乎各大传统汽车厂商都会推出自己的电动车系列，而这些系列推出的时候都会事先预装了这个无线充电能力。那么可以想像，只要有几款带有无线充电能力的汽车上市，那无线充电这个话题也会热起来。

无线充电两个最大的领域：一个是车，一个是PC计算机。这两个领域在2017年都会触发无线充电的热潮，所以我们很坚定地认为无线充电在明年会是一个巨大的概念。

# 在国际上有哪些不同的技术和公司？

给很小的可穿戴设备充电时，属于毫瓦级别的充电设备，一般用是射频技术，叫做RF。

射频技术里面的比较出名的公司：Energous公司，Ossia公司，Drayson公司，都是基于射频技术的。

优势：一点对多，可同时给多个设备充电。

短板：1.传输电量比较低，基本现在市面上还没有太见到上瓦的，手机充电头可以看到基本是1瓦、2瓦，甚至4瓦，也就是说手机充电需要这样的瓦数。现在的这个射频技术勉强支持到2瓦、4瓦，但是能大规模商用还存疑。

2.因为手机普遍有金属外壳，那这个射频技术很多人认为它是穿透不了金属外壳的，所以射频技术现在看起来，未来可能是可穿戴技术的充电方式，但是至少现在还没有看到是不是能大规模的实现商用。

Ubeam公司的超声充电模式——

优势：点对多点，可同时为多个设备充电，超距充电。

短板：可充电的能量是非常非常低的，所以基本上只适合于低功耗的可穿戴设备和低功耗的物联网的设备。

WPC技术推出的QI——

优势：功耗较高。

短板：需要贴近，无法离远，充电瓦数不够，无法以一对多。仍然主要用于可穿戴设备和手机，无法适用笔记本。

技术特点：感应式，两个磁线圈需要贴的足够的近，通过一个带电磁线圈感应出另一个不带电的磁线圈，产生电流。

# 我投资了哪家公司？

在众多的无线充电技术里，我们投资了Witricity公司。

因为它掌握了无线充电领域，尤其是磁共振领域的大多数的专利，而它在明年将会出现的这个热点的两个领域里面都有深入的布局。

但随着明年无线充电概念股在全球热起来的時候，正是Witricity的价值增长最快的一年，因为大家会突然意识到无线充电背后的核心其实是这家公司。

目前，整个无线充电产生了WPC和A4WP两大阵营，所以会有一堆大公司支持，也造成了整个无线充电产业链是健全的，相关的技术标准都比较好，所以未来它的市场也是比较扎实的。

# 中国企业如何借助国际概念？

其实我们知道，我们科技的实用化、产业化实力在国际上还比较落后，所以我们很多科技概念都有赖于国际上一些新概念的推出，我们是跟随着国际概念跑的。

中国产业科技升级的策略：

如果你熟悉国外的科技概念，能够在国外的科技概念刚刚兴起时就借用它，就能够在中国资本市场上获得足够好的回报。然后再拿这些回报反投资于美国刚刚兴起的科技概念，实际上等于对先进科技做了早期战略布局。这对中国产业的科技升级是非常棒的策略。

现在看起来，无线充电在国外的早期热度已经过去，如今已进进入到实质性阶段，因此中国更需要在美国无线充电收入利润产生实质性收益时，尽快把无线充电概念做热，才能够加入到国外无线充电阵营当中。

# 中国先行企业有哪些？

硕贝德（总市值80.3亿）：

2008年进入无线充电产业并成立无线充电产品事业本部，是最早加入无线充电联盟(WPC)的会员之一。

这个公司现在注册了一些发明专利，是磁共振式的无线充电。但据我们所知，中国在基础专利上获取专利的可能性不大，如果要利用A4WP标准的磁共振技术生产无线充电产品的话，还是需要交专利费。

虽然它现在的产品还是基于QI的，但明显在专利和磁共振上已有布局了，这是中国企业非常好的一块。

接下来，中国企业不仅要在专利上给自己布局，也要借助国外先进专利迅速推出新产品，我们对此拭目以待。

中兴通讯（总市值614亿）：

中兴通讯是硕贝德在中国的合作伙伴，也是中国非常稀少的一家无线通讯公司。下属有一个中兴汽车，专门研发基于自主知识产权的新能源——车用充电系统，也和清华的汽车系教授有很多的合作。

他们一直声称是用感应式系统来给车充电。但据我们了解，从科技的角度上讲，如果是给大型的电车充电，那车底下的感应线圈会形成类似微波炉一样的磁场，辐射非常强，整个车上面基本是不能待人了，这是感应的一个弱点。所以我们认为中兴通讯如果能实现它所声称的技术指标，应该磁共振式的充电方式。

我们中国政府一直喊技术自主创新，但我觉得自主创新的意思是到创新的背后有自主性，就是说我能够对创新的这些技术产生一定的控制，而不是别人有专利，我也要自己再单搞一套。所以更多的加强国际合作会更好。

中兴通讯目前在中国就是比较前瞻性的布局了整个无线充电的系统，包括网络设计、建设、运维、无线充电的综合网络等。从技术上讲，它还是能够和世界最先进的科技合作的。

我们经常认为国外掌握了一个先进专利就会卡我们的脖子，或者收取高额的专利费，正因为国际公司被罩上了这样的负面形象，所以在中国想推广业务都比较难。但其实很多事情还是要具体问题具体分析的。

实际上在非军用领域里面，专利的使用是非常开放的，不会自动见到国外的公司纯粹因为商业的目的对中国的企业封闭专利使用权。同时它的专利使用费用的收取也有国际标准和规范，对全世界一视同仁。

所以，中国企业在国际化的过程当中，切忌闭门造车，也切忌民族主义泛滥，更多的应该遵守国际规则。只有学会别人的技能，才能跟人家在一个世界舞台上共舞。所以我们认为还是要获取最先进的国际化技术，然后把技术开发成自己的产品。

乔布斯做iPod，也不是自己非得开发一个高密度存储设备，而是用的东芝设备。我们希望中国有更多的企业，不光会自己研发，同时也能够拿到世界先进科技，在别人的基础上来做研发。

立讯精密（总市值376亿）：

曾经因为苹果声称iPhone7会有无线充电而受益，因为之前就是无线充电线圈的产品提供商，一直给苹果供货，所以很多人认为如果无线充电热起来，那它的线圈是不是也会赚钱。但是实际上无线充电线圈的供货是给苹果现有的可穿戴设备来供货的，例如iWatch。

立讯精密现在看起来，虽然有给苹果供货的优势和有这么高的市值，但是总的来说，在科研上面的实力还有待增强，这家公司目前拥有三项发明申请了专利，但都是外观设计，它更多的还是在用它的制造能力为苹果来服务，而不是它的科研水平。

但这也恰恰是中国企业的优势，也是我们正在寻找的中国企业：

- 在某行业领域有实力，像立讯，它已经给苹果供货了，所以它的市值也足够大。
- 它在相关技术领域仍有欠缺，但有进步的空间。在无线充电领域里面只提供线圈是不够的，因为提供的线圈还没有做到磁共振的标准水平。
- 需要创始人或者CEO有对远景的规划能力，能借助现在的生产地位和资本调度能力去布局未来，进一步巩固产业地位，甚至能实现科技升级。
- 这类公司要看到自己能力的长板和短板，取长补短，最后形成一个更好的产业地位。

顺络电子（总市值也有127亿）：

主要生产片式电感器，压敏电阻器等这类电子元器件。同时它也在为无线充电提供相关的产品，尤其是用于可穿戴，所以它的无线充电线圈也已经实现了量产，可用于车载装备的无线充电。

车载也是我们觉得非常好的领域，尤其是基于A4WP，磁共振方式的无线充电，除了可以用
于车来充电，也可以把整个车当电池，为车里的东西提供充电。

比如说你把手机掏在车座旁边的置物盒里，就可以为你的手机充电，这是一个特别好的解决方案。

# 中国企业在无线充电领域的未来方向

整体来看，中国的相关厂商中无线充电商家还比较少，除了中兴通讯在全面布局以外，其他的企业还是在为全球无线充电相关的原材料或者零部件作为供应商。

但是从市值上讲，这些企业都已经做很大了，所以这恰恰是我们给大家介绍无线充电科技概念股的意义：

借助你的概念优势，借助中国资本市场的优势，到国外和全球的前沿科技做结合，用战略投资，战略合作，甚至并购的方式巩固自己的地位，提升自己的科技实力，使得我们未来在科技发展当中能够越做越强。这是我们希望看到中国企业走的路。
