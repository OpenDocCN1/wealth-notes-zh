# 家用机器人的未来

家用机器人的核心，是满足用户需求，而不是炫耀互动能力、行动能力。下面四点，是未来家用机器人可以探索的。

# 一、玩具

玩具和传统IT产品本质区别，IT产品是排他的，玩具是不排他的。

用机器人做玩具市场，比做IT的潜在市场大很多。

做玩具的技术壁垒很低，需要熟悉玩具产业，要降低成本、满足用户需求、用高科技做出低科技、必须是孩子需要的。

# 二、教具

把玩具变成教具，寓教于乐，让孩子和玩具互动、学知识。

# 三、陪护

和人长得一样，表情栩栩如生的机器人，才能吸引老人愿意和它交谈。

每个人的笑容都不一样。未来，可以为老人定制和他的孩子长得一模一样的机器人。

陪护的核心不是监测老人的行动、生理数据，而是让老人愿意和机器人互动。

# 四、信息节点

机器人和IT在抢信息节点。

# 我们的创业机会

机器人行业创业并不容易，因为最核心的问题，是整合硬件、软件和应用，要有非常强大的纵向整合能力，最后要实现强烈的价值输出。

作为创业者，看大蓝海的时候先别惊喜，首先要想一想为什么它是蓝海。

家用机器人领域和别的市场很不一样，关键不是竞争对手多强，而是能不能纵向整合资源，做出特别好的应用服务。
