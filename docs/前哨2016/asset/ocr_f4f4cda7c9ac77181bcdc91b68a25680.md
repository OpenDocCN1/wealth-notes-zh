# 一、运载火箭

私人航天领域的运载火箭以Space X为代表，Space X的火箭非常大，它和中国的长征2型一样，是重载火箭。

亚马逊公司创始人杰夫·贝索斯，投资的运载火箭公司叫BlueOrigin，BlueOrigin是中小型火箭。

用火箭来做运载，现在全球的主体还是国家。

中国的长征2型运载火箭，在全球非常有影响力。但私人航天领域里的运载火箭部分在迅速崛起。

# 二、航天飞机

私人航天飞机领域最著名两个公司：

一家是Virgin Galactic（维京银河），由维京唱片公司的老板——理查德·布兰森投资。

另一家是海银资本投资，叫XCOR。

火箭和航天飞机解决的是运载问题，到天上以后，人不能暴露在太空中，需要一个接待站。所以空间站也是个好业务。

# 三、空间站

在空间站领域Bigelow Aerospace公司一枝独秀，Bigelow是这家公司的创始人，同时也是Best Western连锁酒店的创始人。

Bigelow希望把酒店开到天上去，所以他们做了胶囊型空间站，把所有需要的功能一次性安装好，装到一个可收缩的空间站里，然后用火箭发射到天上，到预定轨道打开。

# 四、小卫星

小卫星公司很多，小卫星和空间站的高度不一样，空间站在离地面500公里的地球轨道上，而小卫星在离地面400到450公里的轨道上。

未来地球轨道上可能会分布上千颗小卫星，这些小卫星能提供大量数据，比如说红外数据、视频数据、探测数据等等。无论大数据还是人工智能，都可以借助卫星数据做很多事。

# 五、太空探矿

地球上稀有的金属，在太空里却不稀有。

太空探矿不会每次都有好运气，但探不到矿，能探到水也是极好的。

太空很冷，所以很多小行星都有冰核，也就是有水，而空间站需要水。从地面往上运水明显不经济，所以很多小行星探矿公司不是探矿，而是探水。

# 六、太空能源

未来，薄膜型太阳能成熟后，在太空中可以张开数平方公里的薄膜型太阳能电池。可以一天24小时正对太阳，不被晚上的阴影所遮挡，还可以用激光，或者微波束直接把能量传送到地面上。
