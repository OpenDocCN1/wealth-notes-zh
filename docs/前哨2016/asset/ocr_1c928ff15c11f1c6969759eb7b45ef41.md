# 7月4日 | 1366：为了解决人类的能源问题

# 1366科技公司

建议环境下拍摄，点在上角拍摄距离可拍摄速度

探访地点：美国 贝德福德 1366公司

+   - 1366科技是一家旨在研发制造低成本、高性能多晶硅芯片的创业创新能源公司，利用MIT机械工程系的技术，他们的成果有可能在彻底改变现有的多晶硅硅片制造流程的同时与现有的供应链实现良好的对接，进而大幅降低太阳能发电的成本。在多晶硅硅片上面刷上铜线，加上电池组件就组成了太阳能电池，因此多晶硅硅片是整个太阳能电池中最核心的部分。董事会名单：Carmichael Roberts，Bob Metcalfe，Prof. Yasheng Huang，Reidar Langmo，Bruce Sohn，Frank van Mierlo，Amir Nashat。他们都是大牛人，如果你感兴趣可以上网"人肉"他们，这里就不一一介绍了。

+   - 1366的来源。1366这个常数是指从太阳照射到地球表面的光线每平方米的照射强度是1366瓦。
