# 科技概念股｜智能玩具正在掀起一波高潮

什么是科技概念股？

王煜全

今天开始给大家介绍30大科技概念股，那么什么才算科技概念股呢？

+   1、不是一个企业，而是一个技术，对一个或多个较大的应用领域带来革命性影响。
2、技术会给企业带来先发优势或壁垒。
3、技术对产业和应用的影响是持续性的。
4、影响会转化为较大的市场收益，对这个技术的早期投资回报较高。
5、影响是短期看得见的：美国是看见市场起来了，中国是技术证明有效了但应用还没出来。
6、全球性技术，但由中国企业参与或主导的。

智能玩具正在掀起一波高潮

# 为什么是玩具？

玩具的出错容忍度高，其他的人工智能应用则极低。比如自动驾驶碰到一些情况会无可奈何，自动翻译也出不了人工智能作家，人工智能诊断效率大大低于医生。而智能玩具恰恰是能够让人工智能获得初期市场的认可的一个切入点。

智能玩具和高科技产品不同，它们中间不存在竞争关系。我们对高科技是苛刻的，而对玩具是宽容的。

# 智能玩具目前的发展

+   1、Sphero公司推出的《星球大战》的新秀：BB-8（原来是R2D2），在全球形成了智能玩具的浪潮。要学会搭载别人的形象做自己的推广，在别人的这个平台上做营销。即Piggyback：在猪背上去搭便车；
2、Evollve推出的可持续执行外部程序指令的机器人，训练编程思维；
3、机器人博士们创建的Anki公司于10月16日推出了Cozmo，具有人脸识别功能和很强的智能性，能和人互动玩游戏；
4、Hanson Robotics在10月14日刚刚宣布和Disney战略合作；
5、Pepper正式在淘宝发售，有很强的与人互动的能力，售价19.8万。

# 中国的机会

家用机器人是个伪概念，因为它不能同时满足父母和孩子的需求。

中国有强大的制造业，美国需要中国制造。比如Evollve就是加州设计，中国制造。

中国玩具产业发达，市面上有电子的东西几乎都是中国产的，中国的电子产业很了不起。

玩具市场是清晰应用。孩子对玩具来说需求是明确的，而且要高度差异化。

# 谁是赢家？

虽然中国玩具制造业很强大，但是在全球市场上，中国的玩具几乎没有品牌。那么如果说中国的玩具公司借助自己强大的制造和在中国市场的推广实力，然后能够和高科技公司合作，利用高科技优势推出自己的品牌产品，这是一个巨大的商机。

中国的老牌人工智能公司会是智能玩具的支撑者和布局者，比如科大讯飞，尤其是小机器人。

影视娱乐是玩具市场最佳载体，可以积极投入、积极开拓市场和IP合作。

需要注意的原则：玩具公司也好，影视娱乐公司也好，或者中国新兴人工智能创业公司也好，要想拿到这个概念股的炒作的这个门票。因为概念股，你说你自己强，它一定有证明，所以最好的办法是要推出自己的人工智能的大牛，或者和全球的人工智能的大牛的公司来结合。

陷阱：玩具业的基本规律经常是低维打高维，也就是说玩具要求是非常低的这个成本来达到一个非常高的预期。需要掌握玩具业基本规律：低于预期的成本、高过预期的体验。
