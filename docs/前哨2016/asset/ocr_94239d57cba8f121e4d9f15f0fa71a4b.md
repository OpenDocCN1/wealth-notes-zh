# 为何选择单身

选择单身不是因为没钱结不起婚，而是因为足够有钱，可以独立生活。

但是现代人之所以选择单身，已经不是因为钱的考虑，而是当我可以承受的时候我会选择一个自己的生活方式，这是现代人非常鲜明的特征，就是活出自己。

《Going solo》这本书讲的是一个全球性大趋势，在很多发达城市里，选择单身的人尤其多，国际先进国家水平已经达到了50%的单身人口。

# 理解单身生活

单身的生活方式更丰富多彩。因为当你单身的时候，就会去开掘出各种各样的娱乐，尤其是和另一个潮流相结合，这就是超级城市的趋势。

超级城市的人口密度，再加上大量的单身，会出现文化、艺术的井喷。它会为未来的整个社会思想，为未来的文化、艺术奠定一个基调。

理解单身趋势，理解未来文化艺术的繁荣，要有很强的理解包容性，因为单身的人有各种各样的玩法，可能会熬夜，可能会噪音扰民，这无疑需要大城市来包容。

单身的人还有一个共性特点，他们的创造力极强，会不断创造出属于未来的东西，使得我们的生活更加的丰富多彩。
