糖尿病即将摆脱每日注射

孙庆楠博士，瑞士伯尔尼大学的人造器官研究中心做博士，硕士毕业于德国德雷斯顿工业大学自动化与控制技术专业。现在从事基于机器学习和自适应控制方法的人造胰腺的研究。

# 糖尿病的背景

糖尿病是一种代谢性疾病，血糖长期偏高，会引起很多急性或者慢性的并发症，严重影响患者的生活质量，甚至导致生命危险。

糖尿病也会造成对身体各个部分，眼睛、心脏各个部分脏器的损害，患有长期糖尿病会对人的健康有很大损害，造成寿命降低。

糖尿病分为一型糖尿病和二型糖尿病，一型糖尿病指身体无法产生足够的胰岛素。二型糖尿病是因为细胞对胰岛素不敏感，所以叫胰岛素抵抗，就是胰岛素对人体没反应。

糖尿病病人自身分泌胰岛素不足，基本治疗方法就是注射胰岛素，每日都要多次注射。注射胰岛素要根据患者的血糖情况、体重和进食的碳水化合物的含量进行胰岛素用量的计算，如果说注射胰岛素太多的话，也会诱发这个低血糖，血糖分解得太多，也会造成休克或者很多恶性的事件。

# 科学研发

科学家通过结合连续血糖检测仪和胰岛素泵，以及可以自动计算患者所需胰岛素剂量的控制算法，三者结合，开发出了新型的血糖调节系统，就叫人造胰腺。

人造胰腺相关临床实验显示，血糖仪检测，胰岛素泵和控制算法的结合能够显著降低极端低血糖和高血糖事件的发生，与长期糖尿病相关的并发症的风险也会有望被降低。

# 人造胰脏的原理

人造胰脏模拟了胰脏的功能，帮助糖尿病患者能够准确而及时地注入适量的胰岛素进行血糖调节。

胰岛素主要用于调降低人体内的血糖水平，但是低血糖也会造成严重后果，因此人造胰腺不仅要防止高血糖的出现，更要控制低血糖的发生。

人造胰腺是利用佩戴在患者身上的传感器，每5分钟进行一次血糖检测，并且将数据无线地发送给持续性的血糖检测仪，这些血糖数据会被传送给控制系统。控制系统根据患者的血糖情况，摄入的碳水化合物的含量，以及运动情况等信息进行综合分析，计算出最适合患者的胰岛素剂量。

佩戴在患者身上的胰岛素泵会收到来自控制系统的指令，自动进行胰岛素的注射。

通过这一套系统，患者不再需要用指尖取血的方式进行血糖检测了，也不用自己计算需要注射多大的胰岛素剂量，减少了患者的负担。

# 发展现状

2013年美国食品药物监督管理局FDA，首次批准了由Medtronic公司研发的人工胰脏系统，这是全球第一个被医药管理局批准的人工胰脏系统。该系统在病人血糖过低的时候会发出警告，如果病人处于熟睡状态，就会自动停止胰岛素泵的泵胰岛素的工作。

今年7月份，英国剑桥大学的研究团队宣布他们研发的人造胰腺已经在患者血糖控制临床实验中取得了成功。尽管面临许多挑战，但是研究团队相信他们的研究成果最快可以2018年上市。

来自瑞士、加拿大等国的研究团队也在进行人造胰腺的研究和控制算法的优化。

# 未来展望

人造胰腺系统，临床效果的研究未来还需要通过更大型，更长期的这个临床实验来得到更多的证据。

未来人造胰腺系统的实际应用还要医疗支付系统能够对其支付和报销，否则费用依然会太高昂，病人在经济上负担不起。

相信不久的将来，人造胰腺系统将会帮助众多的一型糖尿病患者摆脱日常的血糖检测和胰岛素注射。此时有很大的社会效益，也有很大的市场潜力，是值得我们关注的一个新科技。
