# 智能家居相关的领域

智能温控：Nest是最著名的智能家居企业，2010年，它以家庭智能温控设备起家，2014年，它以天价被谷歌收购，目前，它的 Khoon 产品涉及智能家居的各个主要领域；加拿大的ecobee公司由亚马逊公司Alexa投资，是该领域 的后起之秀。

安防园艺：由于中西方居住条件的差异，安防和园艺的需求和复杂程度差别很大。美国Edyn公司专门提供智能庭院管理设备。

中控设备：Amazon Echo是最著名的中控设备，是亚马逊推出的智能语音助手。Interactive Voice公司的iVee是该领域的后起之秀。

睡眠监测：Beddit公司是睡眠质量监测传感器的提供商；Lully公司的睡眠守护设备专注于提高婴幼儿的睡眠质量，间接地帮助父母获得更多的睡眠时间。

解决方案：Vivint公司是著名的家居综合解决方案提供商，可以按月提供费服务。2016年，硅谷大名鼎鼎的投资人彼得·蒂尔Peter Thiel领导了该公司。

未来智能家居的发展趋势是Machine to Machine，设备之间相互通讯，直接对家居问题进行智能处理。

之前介绍过的家用社交机器人Jibo可以提供情感化的人机交互界面，变成一个中央控制节点。

# 智能家居未来的不确定性

智能家居迄今为止没有找到刚需，现在我们对智能家居的描述和二十年前基本上没有什么区别。

我们对什么是智能家居，用户需要的智能家居是什么这些核心问题并不清楚。

智能家居的核心设备到底是手机、面板，还是其它设备也不清晰。

即使是Jibo，离找到核心入口需求也还有很长的路要走。

# 中国智能家居的格局

海尔优家，包括以空气盒子为代表的优家健康，以智能冰箱为代表的优家膳食，以热水器、洗碗机为代表的优家水生态系统，以洗衣机、烘干机为代表的优家衣物护理等等。

美的M-Smart智慧家居系统，围绕着营养、空气、水三大场景提供解决方案。

小米公司的米家生态链包括了足以和家电企业抗衡的各种产品，小米紧紧围绕手机打造智能管理核心。

中国以家电管理切入的模式可能比国外以家居管理切入的模式要好。

未来，人工智能和机器人领域的公司将会是智能家居领域强有力的竞争者。
