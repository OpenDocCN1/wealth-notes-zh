# 周末问答 | 把自己当将军，新科技当武器

把自己当将军，新科技当武...

王煜全

昨天跟了一把风，将这一周最热闹的川普成为美国总统的话题拿来跟大家讲了一些，那么昨天给大家解释了我眼里看到的未来，可能和大多数人想的都不太一样。

大家听起来觉得好像太乐观了。所以马上就有咱前哨用户问，为什么那么乐观呢？难道真的那么乐观吗？

首先，我们对于以上问题再做一个补充。

我们现在再来看看为什么美国选了川普，不就是因为全球的经济都不太好吗？以至于民粹主义抬头。但是这个经济问题的根在呢儿，我和主流的看法又不太一样。

现在很多人都会从经济、金融、政治方向去寻找根。那我认为从长期看，经济是决定政治的，所以核心并不是现在的地缘政治造成了民粹抬头和美国不景气，而是经济增长。

那么为什么经济造成了不景气呢？其实和科技这一轮的大提升有关。

我们都知道，这一轮的科技提升，包括人工智能、虚拟现实、大数据，大家都以为科技是造福人类 的，但是这些科技的普遍运用，其实更多的是形成了财富更大的积累。也就是说，从老百姓手里赚了更多的钱是给到了更少数的科技资本家手里。而老百姓得到的往往不是实惠，而是一堆玩具，对时间的消磨。想想你每天花了多长时间在不能帮你赚钱，不能帮你进步的事情上。
