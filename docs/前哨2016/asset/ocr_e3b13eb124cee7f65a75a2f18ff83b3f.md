# 周末问答｜研发和制造，是对立还是统一？（获奖名单公布）

研发和制造，是对立还是统...

订阅这个节目已经半年了，时光飞逝。我们需要去了解很多未来的高科技产业，掌握大量信息，才能磨练出准确直觉。还有就是您提到的大脑模块化总 alert

我今天正好有个问题想请教王老师，我刚阅读关于硅光子的文章，里面王老师说到，我们国家必须有自主知识产权，我在想老师是不是一直主张以我国先进制造能力对接美国的研发能力吗？

那中国企业负责制造了，干嘛还要去研发，搞什么自主知识产权。这一信息我就有點矛盾了，我们国家的企业是该自主研发呢还是专心制造对接美国的研发能力呢？

王煜全

这个问题答案其实很明确，终极的企业竞争优势应该具备知识产权和自主研发能力。

但是我一直强调，有自主研发能力是个结果，而不是手段。中国并不是因为从一开始就自己搞制造而强大，而是通过和最强大的制造业公司合作，使得制造能力变得强大。
