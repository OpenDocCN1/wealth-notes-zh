零售业的历史：目录邮购——商店广场——全品、单品、会员超市

Costco Wholesale公司是美国最大的连锁会员制仓储量贩店，是仅次于沃尔玛的全美第二大零售商，它的策略：通过会员制绑定用户和消费；通过精品制集中销 muff量以提升议价能力；通过利润控制保证永久最低价，不玩打折促销，节省用户时间；通过会员费补充盈利。

# 零售未来

零售业的经营水品高低取决于产业整合能力，科技应用能力，个性服务能力，资源配套能力。

# 改造生产，鼓励用户参与：

+   - 利用众筹平台对用户体验和产量需求进行提前反馈和准备；
- 利用物联网对农产品和大件消费品进行全程跟踪；

# 改造营销，强调精准分析：

+   - 利用买手、网红、内容电商提前分流用户，提高营销效率；
- 利用大数据进行偏好和行为预测，进行精准推送；

# 改造线下，突出体验享受：

利用线上优势，推进线下购物理验的升级，完成线上和线下是全面融合。
