# Blue Spark Technologies 公司——

2003年在俄亥俄成立，已经拿了两千多万的投资。它的特点是从日常用的干电池生产厂家那儿拿来技术，再做成商品化。

TempTraq产品：柔性电子最容易应用的一个领域就是将它贴在小朋友身上进行持续的体温监测，如果小朋友贴上这个装置，它就会持续监测小朋友的体温，然后把报告发送到你的手机app上面，如果设置一个报警功能，小朋友半夜发烧，手机就会把你叫醒。

传统企业如果太传统，若想孵化创新的企业，整个机制无法支持，所以最好把它变成一个外部创业公司，而Blue Spark Technologies公司就是选择了这么做。

# Enfuccell 公司——

2012年在芬兰成立，现在拿到了30多万美金的众筹，它有很多技术指标还是蛮受大家欢迎的，大家也可以关注一下。

从全球看，柔性电子部分有四大块，其中以显示器和传感器为主导，其他两部分电池和印刷线路板为配合，形成了一个市场。在未来有很大的发展空间，尤其是在明后年会有很多产品能让大家感知到，所以非常值得关注。

依旧重点推荐我们投的MC10：

它是被John Rogers教授孵化出来的最先进的科技企业，John Rogers教授不仅在柔性电子传感器和电路部分有很多的发明，同时还和美国西北大学的华人黄永刚教授一起，在2013年展示了一款柔性的锂电池，这款锂电池可以为LED灯供电，而且拉伸、折叠、弯曲，甚至按在手肘上都能照常工作。

黄教授在研究里面负责理论、设计和建模部分，John Rogers教授负责带领团队把可伸缩电池制造出来。

2015年，John Rogers教授联合华盛顿大学的研究小组，一同研发了柔性电子套，目前已经成功覆盖到一只小兔子的心脏上，可以监测小兔子心脏的心电活动，而且是以3D的形式监测，所以对心脏的活动可以说是了如指掌。这款技术还可以变成高精度的传感器，用来监测心律异常，这甚至会改变我们以前对心脏病的很多判断。

研发了一种柔性皮肤层，可以把人体的心电信号传输到智能手机和其他的终端上。John Rogers教授实际上做了各种各样的柔性产品，这是他保持领先的重要原因。因此我们推荐John Rogers教授创立的MC10。
