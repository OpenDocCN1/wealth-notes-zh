国企业不会思考如何惠及当地人，它的思考很简单，就是我已经支持了你美国，美国去到其他国家实现了政治的影响力、控制，那我就要求实现我在经济上的好处，所以这些跨国企业往往是自私的。

而且现在发达国家的跨国企业是凌驾于国家之上的，很多甚至已经超越了国家，就是说这些国家的领导人往往对跨国企业是缺乏控制的，而这些跨国企业为各种办法反而能够对国家意志施行重大的影响。

所以我们再也看不到马歇尔计划，更多的是简单粗暴的占领后，派出执商人去当地再继续获取资源，造成当地经济的进一步问题。

我认为全球化需要政治、文化、经济一体化的扩张。当你只是经济输出，而文化思考比较少的时候，文化冲突就成了今天全球化一个主要反对声音。

当初美国在占领了日本以后，曾经非常严肃地讨论过要不要审判日本天皇，最后的结果是豁免，因为天皇在日本被认为有着非常崇高的地位。虽然它和美国文化是完全抵触的，但美国仍然尊重了当地文化。

但今天又和过去不一样了，今天美国的占领国更多是掠夺。所以我们过去行得通的全球化实际上是有背景的，而今天缺了另外两条腿，只靠经济的全球化是走不通的。它只会造成更多地方的抵触。

所以我认为未来要搞全球化，也需要未来有足够强大的全球统一的声音，也就是说更多的是国家之间互相帮扶，所有参与国一起经济腾飞，而不是让对方把国门打开，你好把商品卖进去这么简单。

那未来会不会出现一个足够强大的单一的一级化国家，在全球范围既能和别的国家一起推行全球化，又能够帮助其他国家发展呢？现在看起来不大可能，不论是谁，它都可能会犯美国今天犯的同样的错误。

所以未来的全球化其实是需要出现类似联合国一样，具有强大政治影响力的跨国组织才能够实现的。但这个目标离现在还差得非常远。

# 我不支持全球化，但支持国际化：

对中国企业最重要的两个点，一个叫科技化，一个叫国际化。那国际化和全球化的区别是什么？

国际化是小区域和小区域的合作。比如说中国的一带一路就是典型的国际化，它的好处是具有针对性，你加入我的小联盟，我肯定是基于我们联盟的特色来讨论我能向你输出什么，你能向我输出什么，我们的讨论是一对一、互惠的。

但是全球化不一定做到互惠，因为很多国家一开门后发现只是自己单向的损失。

所以我认为未来全球化不再是主流，但是国际化一定是基调，各国会继续开放，只是会开放得更加理性。因为在不具备前提的条件下，全世界大搞全球化，不光不发达国家受损失，其实发达国家也受损失。

大家不要以为美国倡导了全球化，自己就是受益国，其实美国也有问题，因为全球化的真正受益者只是美国很小一部分的跨国企业，而其他大部分人并没有因此受益，实际上造成了美国矛盾的尖锐。

# 最后总结：

对中国人来说，全球化的时代结束了，但是国际化的时代才刚刚开始。我们已经在历史上证明了我们挺会全球做生意，懂得把我们的商品卖到全球。但是我们会全球的深度合作吗？尤其是和不同国家的、单边的、一对一的深度合作和跨国的经营。这个是对我们的重要考验。

王煜全
