# 无人机产业才刚刚开始

无人机产业是开源的，所以它的竞争核心不是零部件，而是整机生产。

无人机的量产能力小，很难用芯片构建核心竞争力。

整机厂商获取核心竞争力往往靠工业化能力。除了产业化能力以外，更靠经验，没有硬壁垒。

有先发优势，然后有大量用户、经验积累，形成滚雪球效应。

无人机的硬件部分，已不是大家关注的焦点。利用产品给用户提供什么样的服务成为焦点。

# 无人机的的精彩未来

无人机的主要应用包括航拍、农业，能源管线巡线、漏洞检测、安防，军事。

+   1. 这些领域相对比较狭小，未来有更广阔空间。\n2. 即使是这些领域，核心也不仅仅是行业解决方案本身，因为各行业自身没有对无人机的操纵能力，需要熟练的无人机操作人员。\n3. 关键并不是解决方案，而是你有一整套完整的服务体系。

未来无人机的核心提升空间是人工智能能力。

当无人机具备特别强大的人工智能时，它能做的事，会超乎想象。

无人机的自动驾驶比地面汽车和海底无人潜艇的自动驾驶都容易。

+   1. 没有那么多目标。\n2. 空气中的飞行控制系统较易实现。\n3. 无人机的管制容易，会成为一个普遍标准。

# 无人机的黄金时代

无人机在三方面有巨大发展空间：

+   1. 在自身性能上，避障能力、承载能力、续航能力会有很大提升。\n2. 配套上解决，使无人机在配套能力上有更大增强。\n3. 无人机承载的功能模块会得到加强。如物流配送能力、监控管制、搭载充电系统、搭载物流系统、甚至搭载武器系统。

当无人机充分自动化，性能局限被突破时，续航能力在三五年之内有大提升，配套系统也会完善起来。

它最大的应用是物流配送，现在的物流还靠人递送，未来大多数靠无人机递送。

未来无人机可以自己进入电梯、到达目标楼层，出电梯以后，把货物放到家门口。

M2M，Machine to Machine。机器人可以操纵电梯，无人机操纵电梯不是匪夷所思的事。

《哈利·波特》里，每个主人公、小巫师都有可爱的小猫头鹰。未来每个人都是哈利·波特，有自己的小无人机。

无人机数量会超过城市人口数量，飞的机器比人还多。

# 无人机创业的核心

不是硬件，也不是基础服务，是想象力。

服务的创新是无限的，只要有充分的想象力、充分的实现能力，现有的硬件和服务都是良好支撑。

未来无人机的前景非常广阔，适合有想象力、懂先进科技的年轻创业者。
