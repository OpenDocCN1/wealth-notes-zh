# Ostagram软件

Ostagram是一款神奇的软件，它可以把你输入的两幅图画的内容和风格进行混合，形成一幅全新的图画，目前，软件已经直接开放到了网页上，随时供你应用，操作简单，效果惊艳。（网站：Ostagram.ru）

![](bbox=[0.12, 0.64, 0.93, 0.81])

Ostagram的创作者是一个俄罗斯的小伙子，他在程序员社区GitHub上的名字叫SergeyMorugin，使用英文几乎查不到他的资料。

Ostagram是SergeyMorugin基于Google的DeepDream开发的。

![](bbox=[0.12, 0.0011799999999999998, 0.98, 0.00138])

# Google的DeepDream

与战胜李世石的DeepMind一样，DeepDream也是Google开发的人工智能系统。

DeepDream最初是Google开发用于参加全球图像识别的大赛ImageNet的人工智能系统，比赛的核心就是图像识别，尤其是人脸识别。

DeepDream不仅可以识别模式，而且可以自主进行模式强化，“无中生有”地将一个微弱的模式效果强化放大，就像人类从星星里找出星座一样。

原来在分析预测领域我们避之不及的过度拟合，在图像艺术上找到了用武之地。

Google 用 DeepDream 去比赛，而 SergeyMorugin 就用DeepDream 开发了 Ostagram。

今天计算机从某种程度上说拥有了人类的通感能力。

# 艺术的未来

未来，技术型的工作会由人工智能来替代，艺术家将在创意、创造力上有更大的发挥空间。

如果艺术家和人工智能能够深度合作做出更现代化 and 能够广泛适用的艺术作品，那会有广阔的商机。

# 高科技离我们很远吗？

比如你新开了一个餐厅，想要挂自己风格的画，那就用最强的人工智能和艺术家一起帮你定制作品。所以，人工智能已经侵入到了以前大家根本不敢想象的领域。

随着科技的进步，科技离每个人都越来越近，也就意味着，只要你有创意，只要你懂行业，只要你懂市场，懂用户，只要你有自己独特的优势，都有机会和科技结合。
