# 为什么推荐这本书？

今天给大家推荐的书叫做《Ready Player One》，中文名玩家一号，是一本科幻小说，写于2011年，正好在许多虚拟现实创业公司和技术研发开始之前，很多从业人员都受到了这本书的启发。

比如名声大噪的Oculus，2014年被Facebook以二十亿美金收购，今早些时候顺利推出了产品。Oculus的创始人Palmer Luckey曾多次公开表示自己对这本书的喜爱，现在Facebook每一位新进员工也都会得到一本。

斯皮尔伯格执导的同名改编电影也已经开拍了，预计2018年上映，还提到会和Magic Leap合作。

科幻故事不仅预测未来，它也影响，甚至定义了未来。那我们了解了这本书，从某些角度上就能够窥探未来。

# 故事背景：

故事设定在2044年，大部分人类用上了一套叫做OASIS的虚拟现实设备，这套设备包含一个主机，一个头显，一副触觉感应手套。那么时候地球上已经经历了能源危机，全球变暖等问题，生活环境变得非常恶劣，资源也很匮乏，所以大家都乐于用这套设备生活在虚拟世界里。

有一天，创造这套设备的公司创始人去世了，临终时留下了一个游戏，也是一个谜噻，最终赢得游戏的人可以获得创始人的全部财产，价值两千四百亿美金，但必须耍通过解谜才能一步一步进行下去。

故事中的很多人开始全职玩这个游戏，将赢得游戏作为了人生目标。书里的主人公韦德也是其中一个，故事就此开始。

# 虚拟现实的未来

在进一步展开这本书之前，我先和大家讨论一下虚拟现实的未来。因为尽管虚拟现实很火，但是如果它不会流行（很多人也持有这个观点），那讨论下去的意义就不大了。

我们先给虚拟现实下个定义：狭义来说我们现在认为虚拟现实是专指封闭式的虚拟现实头显。但广义来说虚拟现实是长期存在的一个概念。

> 著名科幻小说家，也是Magic Leap的成员Neal Stephenson在一次谈话中提到过，在我们建设未来的过程中没有什么是比好的故事更善于统一大家的目标了。

有人用电脑打游戏会陷入游戏中的虚拟现实，有人看电视会陷入剧情中的虚拟现实，有人想象力特别强，读小说可以在脑海中构建出一个非常逼真的虚拟现实。所以虚拟现实是我们人类长久以来都能够利用输入和输出的信息加上想象力构建出来的。

但是人的想象力并不相同，有人宁可读小说不愿意看电影，因为他们觉得自己靠想象力构建出来的世界比电影里的强多了，大多数人则可能需要电影来帮助他们完善虚拟世界的构建。

所以回顾过去，收音机相对于报纸可以在更多场景提供体验的机会，并且通过语音传递更好的体验。电脑相对于电视赋予了人类创造的机会。智能手机让创造和体验无处不在。

从总体趋势来看，能够从更多维度或者更深层次满足人类创造和体验的愿望，顺应了输入/输出设备的发展史。

从创造的角度来看，我们的手式可以用来自输入，身体移动可以输入，甚至眼神、表情都可以用来自输入。因为头显是在戴在头上的，未来有一天脑电波都可以用来自输入，创造的可能性大幅提升。

从体验的角度来看，现在的虚拟现实头显相较之前的输入/输出设备，最大的优势在于3D场景的逼真给我们提供了“沉浸感”，图像和声音都是3D的，未来甚至还可以增加嗅觉和触觉，多维度多层次地提升人类在虚拟现实的体验。

正因为虚拟现实设备是满足输入/输出设备的发展趋势的，所以才有虚拟现实和混合现实之争。

# 从小说中看未来硬件机会

下面我们回到这本书上。很多人，包括Palmer Luckey喜欢这本书的原因是它脑洞大开的同时也非常可行。

书中展现的虚拟现实不是单一的技术，它包含视觉、听觉、触觉、嗅觉、运动感，只有这些方面都足够完善才能创造出一个让人难以分辨的虚拟世界。

接下来我们就讨论一下它到底有多可行，摆在创业者面前的又是什么样的机会。

视觉，书里描写的头显能够提供近乎真实的视觉体验，现在市场上的设备还差的比较远，未来头显要分辨率更高，视场更大，处理器更块，重量更轻，散热更好，时延更低，价格更便宜，运用光场显示。因为它们不是独立存在的，所以这些技术都需要巨大的进步。Oculus的首席科学家Michael Abrash最近给出的预测是5年之后显示技术基本能够完善。

听觉，要保证和视觉同步的3D音效。目前几种感官里，听觉应该是最成熟的，市场上的头显基本都配有3D耳机，不少初创公司效果也做得很好，比如Doppler Labs。

触觉，之前有提到书中的OASIS设备是配有触觉感应手套的，有钱的话还可以买一套全身感应套装，也就是说如果在游戏里被别人打了一拳，现实世界中身体是可以感受到的。

触觉感应的研发方向是五花八门，充满想象力的。之前Kickstarter上有一个Gloveone手套，手套上加入了许多小电机，通过不同频率和强度的振动来配合视觉效果。还有一个Rice University研发的Hands Omni手套，在手套里加入小气囊，通过充放气来模拟触觉，据说效果更好但是比较早期。

还可以结合机器人，CyberGlove Systems之前开发了一套工业级的设备，手套上连接机械手臂，可以制造阻力。还有利用声波的，有一款设备叫Haptoclone，利用Kinect来判别手的位置，然后通过高强度的超声波制造阻力，配图图像让人感觉到了虚拟的物体。全身感应服也是有的，比如Tesla Suit，是通过全身52个点的神经肌肉电刺激来模拟触觉，之前发起了Kickstarter不过失败了。

总的来说，触觉方面还处于早期研发阶段，并没有技术相对成熟的产品，而且预计需求量将非常强大，有创业机会，但是依赖于头显的流行在先。

嗅觉，书中有一个细节是主人公走进了一家虚拟世界的披萨店，现实世界里立刻传出匹萨的香味，闻到香味觉得饿了可以直接咔快递，这算是新型电商了。查了一下还真的有公司在做，不过很少，效果也很一般。

运动感，是一个比较大的问题。目前的头显都没有很好地解决晕动症的问题。

晕动症就是说视觉体验和运动体验不一致产生的不是反应，平常晕车晕船都是同样的道理。假设我在玩一个游戏，游戏里我已经跑了五千米了，人还待在原地，那肯定要晕。

一种解决方案是万向跑步机，但是万向跑步机的使用者普遍觉得不舒服，昂贵的价格和机器巨大的体积也都是问题。所以现在出品的游戏还是尽可能地减少移动和加速，从内容设计的角度来避免过度的感官刺激。
