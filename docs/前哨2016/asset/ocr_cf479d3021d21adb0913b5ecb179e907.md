# 戒定慧

佛教中的自我认知实践十分丰富，其中戒定慧合称为三学。

戒是基础，完善道德品行不放纵。

定慧合称定慧双修，由定生慧。先让自己心情平静，当自我生理波动非常微小，就能感知很多细微规律。

![](bbox=[0.05, 0.86, 0.98, 1.0])

# 止和观

止和观是修炼定慧的方法。止：让自己心静，观：心静以后去觉知事物的运动规律，包括思想规律，情绪规律等。

心猿意马、杂念纷飞是人的常态，我们需要锻炼觉知能力去控制宝贵的注意力。

![](bbox=[0.12, 0.00133, 0.8, 0.00155])

# 呼吸

观呼吸是多数修行的起点，我们既可以让呼吸自主运行，也可以主动加以控制。这个特点在人体中是独一无二的。

在止观禅修里，需要达到的境界是，对呼吸既觉知关注，又不加以控制，当逐渐做到的时候，定力就会出现。

![](bbox=[0.03, 0.00195, 0.85, 0.0023])
