玩具公司 Jibo

+   - Jibo是一款社交机器人，Jibo公司就是以它的名字成立的公司，其创始人兼首席科学家Cynthia Breazeal是MIT媒体实验室的教授，也是社交机器人或者说情感计算领域（Affective Computing）的先驱。2014年，在美国著名的众筹网站Kickstarter（Indiegogo）上，他们完成了近四百万美金的众筹。

+   - Jibo公司非常有意思，因为它生产了一款特别好玩的玩具，一款叫Jibo的社交机器人，这款玩具具有智能，能够理解你的想法，能够用摄像头通过你的眼睛、你的脸、判断你的喜怒哀乐，然后逗你开心，并且当周围的人都快乐的时候，它就会启动录像把大家的快乐瞬间记录下来。当然，它还有很多现实的功能，比如，说笑话、帮你订餐、提醒你今天的天气、甚至帮你记录想记的事情，像备忘录一样，提醒你。

+   - 情感计算的核心是通过识别别人的面部特征来读出人的表情，让计算机能够理解人的情感。因为我们大脑当中有一种神经元叫做镜像神经元，这种神经元使我们看到人脸的时候就下意识的能够了解对方的喜怒哀乐，而且当对方快乐的时候我们也会觉得快乐，我们也会笑，当对方难受的时候我们也会觉得伤心，我们也会陪他哭，所以人天生就有识别他人情感的强大能力。人类 的共情能力就是由镜像神经元决定的，这种能力是超理性的，不需要我们去做任何的分析，我们下意识就会掌握。那么现在机器人也具有了这样的能力，它的开创者之一就是Cynthia Breazeal教授。现在Jibo就是利用了教授的科学成果具备了和人共情的能力。因此这个社交机器人非常值得期待，当你把这个社交机器人带回家的时候，它能和你做情感上的互动和沟通，尤其对小孩子来说又多了一个能够理解他们的玩具，说它是社交机器人一点也不过分。

+   - Kickstarter和Indiegogo是全球著名的众筹网站，双方互为强有力的竞争对手。到目前为止，通过Kickstarter，已有1100万人参与了对众筹项目的支持，承诺给予的资金达到25亿美元，108507个项目得到了支持。通过Indiegogo，223个国家或地区的人参与到了众筹项目，其每月访问量高达1500万人，其中47%的达标项目来自女性。

+   - 像Kickstarter和Indiegogo这样的众筹平台是催生各种创新产品的一个非常好的场所。由于创新是需要成本的，而很多创新来自个人或者来自小微企业，虽然他们有创新的想法，但是实现量产，降低价格往往意味着较大的前期投入，而量产的成本是要预先支付的，因此资本限制就成为很多创新者的瓶颈。即便你有好的产品，由于没有足够的资金把它付诸实现，也就不能把产品提供给消费者。在有了众筹平台以后，你可以通过拍一段介绍性的视频把自己的产品功能全部展示出来，向公众作说明。如果公众觉得有兴趣，那么他们就会愿意通过预付支持你的创新产品，而在得到资金以后，你所需要做的就是加班加点，在承诺的产品提交日期前把产品做出来交付给顾客。当然，这个日期可以很长，一两年都是很常见的。如果你没有筹到足够多的钱，无法启动自己的项目，那么就意味着众筹失败，已筹集的资金就会退还给支持者。同样，如果你没有按时把产品做出来，那你也得把钱退给对方。
