# —— 大脑部分 ——

前面我们讲了语言处理，而有语言处理也就必然有大脑。语言解决声音识别和语音合成，而大脑需要解决让互动变得更加智能。

国内外的 大脑部分都一样，多数是传统大型互联网企业，因为它们有非常雄厚的研发实力。

# 第一个大脑——百度

理由：有吴恩达担任百度人工智能技术的核心研究者。他曾经是负责谷歌大脑的负责人，后被骋到百度，做出了百度大脑，核心部分就有语言，图像，自然语言处理和用户画像，这应该算是全球最先进的技术。

技术合作：这项技术和很多企业进行了合作。例如：海尔、小米、乐视、联想、索尼、网易、特斯拉等，都在使用百度的智能语音的SDK。

百度自主研发的产品：度秘，用百度来给你当秘书。它集合了搜索、语音识别、大数据、人工智能等一系列的未来科技，还可以免费开放给所有的app，故入到各种智能设备中。另一个智能语音副教，叫CoDiver，它对语音的识别率超过96%。

未来，当你在开发应用的时候，可以内嵌度秘提供的各种智能服务，这是人工智能的一个大福音。也就是说，未来人工智能应用领域做得好的企业未必是最强的企业，它可能只是调用百度的技术。

# 第二个大脑——阿里巴巴

理由：投入了巨资来做研发。2015年联合富士康向日本软银旗下的机器人公司战略注资了145亿日元。

推出的三款产品：

+   1. 虚拟购物的助理机器人，叫做阿里小蜜，和Siri类似，但更多是处理手机的互动，协助会员来购物；
2. 智能机器人客服，它们可以理解你的口语问题，还可以分辨问题的焦点，理解上下文，进行自我学习。所以它的服务效率据称是人工客服的60倍。 
3. 阿里云ET机器人，具有全局意识，能对全局数据进行综合的整体分析，还能模仿人类的音色说话和唱歌，提供人脸识别、机器翻译、文字识别和通用图像分析等常见的人工智能服务。
