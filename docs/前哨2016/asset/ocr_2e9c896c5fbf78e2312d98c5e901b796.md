屏幕显示技术

# 屏幕显示技术

随着电子产品以及虚拟现实（VR）、增强现实（AR）和混合现实（MR）应用越来越广泛，市场对屏幕显示技术的需求也越来越强烈。

屏幕显示技术有两方面机会。一是在传统领域中，大屏的电视和电脑，小屏的手机和可穿戴设备；二是在头戴式设备中。

# 传统领域

主流技术比较清晰：一是传统的液晶显示技术LCD，二是有机发光二极管技术OLED，技术上我们正在经历向后者迁移的过程。

苹果要用OLED技术还有待时日。因为目前，OLED难以同时满足足够供货和质量两方面的要求。

![](bbox=[0.32, 0.0011799999999999998, 0.99, 0.00145])

LG的OLED电视

TCL的量子点显示技术在光的饱和度、清晰度和逼真度上比OLED更有竞争力，但是显示速度较慢，视觉暂留（余晖效应）较强，难以满足下一代头戴式显示设备的要求。

![](bbox=[0.25, 0.0016799999999999999, 0.95, 0.0019199999999999998])

TCL量子点屏幕电视

即使是一些逐渐清晰的主流技术，大规模量产也是难以突破的瓶颈。

柔性电子技术是支撑下一代显示技术的争夺焦点，其中包含三个部分：一是柔性显示器，二是柔性集成电路，三是柔性电池。

# 头显领域

3D是头戴式显示设备（头显）的主流，但是头显非常累麻烦，裸眼3D是未来的发展趋势。但短期之内，3D还是以头显为主。

裸眼3D最开始基于偏振技术，然后基于光栅技术，未来应该基于全息技术，甚至基于光场技术。

美国Magic Leap是一家增强现实公司，获得了许多大牌机构的投资，在它的头盔里就使用了基于光场的诱技术，效果十分炫酷。

# 显示领域的挑战与机会

从技术角度，裸眼3D和柔性电子技术都已经没问题了，问题在于高精度显示的量产。

在硅谷、小液晶屏上的全息图像显示做得已经很不错了，但是量产还有很大距离，产业化是一个难以逾越的鸿沟。

创新和量产都是一个国家的核心能力，中国不能“因此失败”。

科技创新就是挑战常识。之前，不仅在空气中的全息成像极其困难，按照这种透明介质上的全息成像同样难以实现，但这个难题被我们前文 features 介绍过的无线充电领域，WiTricity公司的首席科学家Marin Soljacic解决了。

进入这个领域，要非常谨慎。主流显示技术已经逐渐清晰，以OLED为主，三星、LG主导。

当然，依然有很多变数，无论是量产，还是创新，都有机会突破壁垒。
