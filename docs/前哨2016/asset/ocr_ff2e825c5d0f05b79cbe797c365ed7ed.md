+   - MIT机械工程的系主任陈刚教授认为，院系划分根本没必要。这和MIT媒体实验室另一个研究创新的彭特兰教授的观点不谋而合。彭特兰教授认为，创新就需要不同领域的人、不同知识体系的人之间深入碰撞。背景越复杂，背景越不相关，往往越能够碰撞出更创新的观点。陈刚教授不光是这种观念的支持者，也是这种观念的践行者。在他的领导下，MIT机械工程系有很复杂的结构。陈刚教授说"不应该有院系划分，而是以解决问题为主"。

+   - 怎么能让全球最顶尖的人才聚集在一个系呢？陈教授认为最核心的是招聘。招聘首先不能要有禁忌，说这个领域我不碰，那个领域我不碰。关键的衡量标准并不是你是哪个领域的，而是你能不能成为这个领域里面未来最牛的人。所以招聘的秘诀就是判断清晰，对方有没有在自己领域里面成为领军人物的潜力。当然也代表着他要承担一定的风险，因为没有人能保证研究一定会成功，但是至少通过分析一个人之前的科研成果，能够看到他清晰的研究轨迹，而且能够清晰地鉴别出他这个研究一旦实现突破，未来对这个行业领域的重大贡献，这种时候陈教授他就会毫不犹豫地把这样的专家引入到自己的机械工程系里面。就是因为有这样的胸怀，有这样的眼光，所以机械工程系才在各个领域里都汇集了全世界最厉害的牛人。

+   - 有学者认为，要做出成绩来，要么就基础科研做得特别扎实，特别基础；要么就应用研究做得扎实，特别应用。最忌讳就是落到中间，基础也不扎实，应用也没做好，这个观点很像过去台湾施振荣提出来的微笑曲线，你要么设计特别强，要么市场特别强，千万不要落到中间那断造上面去。看起来好像很有道理，但是MIT的机械工程系恰恰是违背这个规律的，他们擅长的就是用全球最领先的科技做出全球最领先的应用，根本不存在中间的问题，他把两边汇集起来，在中间反而实现了突破。

+   - "微笑曲线": 重要科技业者宏碁集团创始人施振荣先生，在1992年为"再造宏碁"提出了有名的"微笑曲线"（Smiling Curve）理论，以作为宏碁的策略方向。经历了十多年以后迄今，施振荣先生将"微笑曲线"加以修正，推出了所谓施氏产业微笑曲线，以作为台湾各种产业的中长期发展策略之方向。

+   - 微笑曲线理论的形成，源于国际分工模式由产品分工向要素分工的转变也就是参与国际分工合作的世界各国企业，由生产最终产品转变为依据各自的要素禀赋，只完成最终产品形成过程中某个环节的工作。最终产品的生产，经过市场调研、创意形成、技术研发、模块制造与组装加工、市场营销、售后服务等环节，形成了一个完整链条。这就是全球产业链，它一般由实力雄厚的跨国公司主导。以制造加工环节为分界点，全球产业链可以分为产品研发、制造加工、流通三个环节。 从过程产品到最终产品再到最终产品销售，产业链上各环节创造的价值随各要素密集度的变化而变化。发展中国家的企业由于缺少核心技术，主要从事制造加工环节的生产。然而，无论加工贸易还是贴牌生产，制造加工环节付出的只是土地、厂房、设备、水、电等物化要素成本和简单活劳动成本，虽然投入也很大，但在不同国家间具有可替代性，企业为争取订单，常常被压低价格。而跨国公司掌握的研发环节和流通环节，其所投入的信息、技术、品牌、管理、人才等均属知识密集要素，比制造加工环节更复杂，具有不可替代性。同时，面对复杂多变的国际市场，研发和流通环节要承担更大的市场风险，按照合并完成订单生产即可以分享利润的制造加工环节并不负责产品销售，市场风险极低。按照成本与收益、风险与收益正比匹配原则，跨国公司作为生产过程的最大投资者和最终产品销售的风险承担者，自然成为最大的收益者。

+   - 微笑曲线中间是制造；左边是研发，属于全球性的竞争；右边是营销，主要是当地性的竞争。目前制造生产的利润低，全球制造也已供过于求，但是研发与营销的附加价值高，因此产业未来应朝微笑曲线的两端发展，也就是在左边加强研发创造智慧财产权，在右边加强客户导向的营销与服务。

+   - 这明显是和刚才讲到的，要么特别基础，要么特别应用是相违背的。为什么这样？我认为就是因为他们汇集了全球最牛的人才，因为他的做法就是我们反思说的积木式创新。他让这些最牛的人聚到一起，用最先进的科技去解决这个世界上碰到的最难的问题，这种时候反而有意想不到的效果，反而能够突破要么特别基础，要么特别应用的限制，使得基础能够在应用领域换发出最闪耀、最夺目的光彩。

+   - 这个时代的特点就是只要你的方法对了，过去的很多限制就不再是限制，甚至可以成为你的机会，你可以用最先进的科技做出最棒的应用来，你可以瞬间做出像百年老店一样强大的品牌来，你也可以解决别人可能觉得完全没有希望解决的问题。所以不要自我设限，而是利用最先进的思想武装自己，不断地去挑战那些限制，不断地去挑战那些门槛。当你做到了，回过头来你就发现，你在建立新的规则。
