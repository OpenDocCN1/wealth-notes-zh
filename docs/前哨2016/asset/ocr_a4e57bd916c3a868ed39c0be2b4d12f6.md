歌、Lyft一起宣布结成联盟，在美国推广自动驾驶汽车技术。

2016年8月，收购Otto（一家研究货运卡车自动驾驶技术的公司）。

今年投资3亿美 元开发自动驾驶汽车，最初研发车型为沃尔沃的旗舰版SUV汽车XC90。这款汽车在今年9月开始在匹 Ayr 郊的街道上测试。

Uber研发的自动驾驶汽车已经在旧金山路上测试了几个星期，最近因未经许可上路测试被加州机动车车辆管理局叫停。

据称，未来Uber还会把自动汽车和专车服务结合起来，比如用户通过手机叫车之后，汽车将会自动行驶到消费者候车位置，完成送客服务之后自动返回基地。

# （3）Mobileye

Mobileye创立于1999年，但直到2007年，才签订了第一个生产协议。

目前在单一摄像头视觉高级驾驶辅助系统（ADAS）的开发方面走在世界前列，并提供芯片加载系统和计算机视觉算法运行客户端功能，如车道偏离警告、基于雷达视觉融合的车辆探测、前部碰撞警告、车距监测、行人探测、智能前灯控制、交通标志识别、仅靠视觉自适应巡航控制等。

目前，Mobileye的技术被宝马、通用、沃尔沃、现代、特斯拉、雷诺卡车等20多家汽车公司应用于生产的车辆中，据Mobileye官方介绍，迄今为止，全球有超过1000万辆汽车都使用了Mobileye的高级驾驶辅助技术。

因为撞车事件，与特斯拉终止合作。

与Delphi汽车公司合作开发了自动驾驶系统，预计于2019年投入生产。

BMW、Intel、Mobileye将联手为自动驾驶车辆建立一个产业标准的开放性平台。据悉，Mobileye将把算法集成在Intel的自动驾驶计算平台上，而不再生产自己的芯片。

# （4）Faraday Future

Faraday Future（法拉第未来，简称FF）是一家有着美国硅谷背景的智能互联电动汽车新兴企业，成立于2014年4月，因与中国乐视集团的合作而备受关注。

今年6月22日，FF宣布获得了美国加州自动驾驶测试资格。

在乐视10月份的北美发布会上，乐视公布了FF的首款车型。据悉，这款车将会在2017年1月份的CES上正式发布。

FF最近碰到一系列麻烦。其在拉斯维加斯北部投资10亿美元建设的工厂已停工。另外有厂商因欠款将FF告上法庭，一是零配件供应商Futuris(富卓)状告其拖欠1000万美元施工款；二是当地房地产商Beim Maple Properties起诉FF索要其拖欠的库房租金10.5万美元。投资造车产业需要巨大的资金，对于法拉第未来，还需拭目以待。

# （5）Drive.ai

它是研发如何将深度学习应用于自动驾驶的硅谷公司，由斯坦福大学的多名人工智能研究员创立，2016年3月份完成1200万美元天使轮融资。

Drive.ai开发的软件，利用处理能力相对不强的计算机就能控制汽车自动行驶。

Drive.ai将深度学习技术应用到无人驾驶汽车，使汽车在行驶过程中不断提高自己的“驾驶水平”。

今年4月，Drive.ai获得了在美国加利福尼亚州测试无人驾驶汽车的执照，成为第13家获得该许可的无人驾驶汽车的公司。

# （6）nuTonomy

nuTonomy是麻省理工学院衍生的一家公司，它开发的软件可告知无人驾驶汽车如何根据环境规划行驶路径。这家公司主要是通过对目前现有的出租车进行技术改造，让这些出租车能够实现无人驾驶。

成立于2013年，今年5月获得了1600万美元A轮融资。

在技术上，nuTonomy得到MIT和英国剑桥大学的大力支持，在汽车生产制造环节上，该公司也与法国雷诺公司和日本三菱公司展开合作。此外，就连新加坡政府直属的经济发展部门也对它提供了资金和政策支持。

今年四月份，nuTonomy就已经开始在新加坡公路的指定区域内进行测试。今年8月。nuTonomy在新加坡测试了免费的自动驾驶出租车叫车服务。这项测试比Uber还要早，让新加坡成为了全球第一个推出自动驾驶出租车服务的国家。

今年年底，nuTonomy将在波士顿进行更大规模的测试，届时将由搭载自动驾驶技术的雷诺Zoe电动车完成任务。

# （7）Zoox

Zoox成立于2014年，是一家用无人驾驶向民众提供类似Uber出行服务的硅谷初创公司。

该公司于今年7月完成了一轮2亿多美元的融资，Lux Capital和DFJ都参与了本轮融资，目前的估值已经超过10亿美元。

该公司的目标是在2020年之前研发出一款达到4级的完全自动驾驶出租车。

Zoox于今年4月初获得了在美国加利福尼亚州测试无人驾驶汽车的执照。

不过，该公司表示没有必要对外透露任何公司信息，所以外界对该企业的具体计划和方向仍然一无所知。

# —— 中国的自主品牌布局 ——

目前总共有十余家厂商涉足该领域。其中一汽集团、上汽集团、长安汽车、北汽集团、长城汽车、宇通集团等企业，都已经展示了其配备初级自动驾驶技术的试验车型，而就在2016年上半年，广汽集团、东风汽车、吉利汽车、比亚迪汽车、力帆汽车也纷纷宣布将在未来5到10年内完成自动驾驶样车试验。

# （1）上汽

2013年，上汽集团在自动驾驶领域“结盟”中航科工，并且在2015年的上海车展上展示了自主研发的智能驾驶汽车iGS。

iGS通过摄像头和雷达观测周 境环境，再把路况数据通过给控制软件进行分析，给出指令。经过路试鉴定，iGS可以初步实现远程遥控泊车、自动巡航、自动跟车、车道保持、换道行驶、自主超车等功能。

iGS达到了3级自动驾驶，10年后的愿景是5级，目前正在自主研发二代MGiGS。

# （2）长安汽车

长安汽车在大约7年前就开始无人驾驶技术的开发，目前是国内自动驾驶领域比较超前的汽车厂商。

今年4月，长安无人驾驶汽车从重庆正式出发，途经西安、郑州，最后抵达北京。这是继奥迪、谷歌之后，国内整车企业单次最长距离的无人驾驶汽车测试。这辆改装的睿骋车上，加装了高精度GPS系统、单目摄像头、激光雷达以及多个毫米波雷达。长安标已达到3级自动驾驶技术。

目前，长安已与高德展开技术合作，依靠高德的地图技术解决位置信息问题。

# （3）北汽

在今年4月份的北京车展上，北汽集团展示了其基于EU260打造的无人驾驶汽车。通过加装毫米波雷达、高清摄像头、激光雷达和GPS天线等元器件用于道路识别，同时配合高清地图进行路线规划，从而实现无人智驱。

得益于和社科院的合作，北汽无人驾驶汽车目前搭载的无人驾驶感知与控制元器件大部分都采用了国产化采购，目的是为未来的国产化量产打下基础。

今年9月举行的百度世界大会上，北汽与百度合作的最新研发成果北汽百度无人车亮相。这部高智能化汽车据称达到了4级无人驾驶技术。该无人车以北汽新能源旗舰车型EU260为载体。

# （4）比亚迪

2013年初，比亚迪和北理工签订了合作协议，三个月之后，他们就联合研制出了线控自动驾驶实验车辆。这辆测试车实现了车辆底盘部分的外部CAN总线控制，车上还使用了激光雷达。
