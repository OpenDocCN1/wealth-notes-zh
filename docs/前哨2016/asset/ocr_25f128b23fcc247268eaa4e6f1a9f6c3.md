# 机器人替代人类

美国以知识工人为主，它的机器人替代是从低向高的，叫做顺序替代。

在以中国制造厂为代表的体力劳动领域里，机器人替代是一个逆向替代过程，先替代的是最复杂、最成熟的工人。

# 万能机器手

Soft Robotics公司只有12个人，做出了"万能机器手"这么复杂的科技，它 sứ命就是使工厂实现完全自动化。

机器手是柔性的，能够从任何角度抓住任何形状的物体，而且不损害物体本身。

Soft Robotics公司运用哈佛的技术，利用仿生学原理，通过研究章鱼的触角发明了塑料的可变形机器手，像人的各个手指一样可以弯曲，非常灵活柔软，可以设置力度，从而不会捏碎任何想抓的物品。同时还可以抓起仙人掌这样带刺的东西，而不受伤害。

它是万能的机器手，正好弥补了工厂的最后一个环节。

# 科技转化型公司

Soft Robotics公司是最典型的美国科技转化型公司，一方面科技是从哈佛大学的优秀教授那里来，另外一方面CEO Carl Vause是一个非常资深的连续创业者。

美国尤其是东岸的VC，习惯投这种科技转化型的项目，在众多VC、风险投资商都想投进Soft Robotics的激烈局面下，我们是进入公司的三家投资人之一。

像这样的好项目，现在已经进入收获期，产品实现了量产。美国各个生产线都有大量的需求要用机器手来解决最后的装配问题，明显供不应求。

# 中美互补

中国的制造业和美国的创新产业从硬件上来讲，天然互补，双方有很强的结合点，但是在软件上，双方结合的仍然不够，甚至中美之间还有很大差距。

美国的创新者希望有更好的支撑企业帮忙实现量产、帮忙开拓市场，而中国现在因为软件问题，还没有配合那么顺畅。

美国现在有很大的热点，叫先进制造，他希望把自己的制造能力提升。如果中美对接不顺畅，十年之内美国可能自己的制造业就会崛起，就不再需要中国的制造能力了。

反过来講，中国在过去三十年里已经积累了大量的经验，我们认为中国是全球的制造专家，美国人真正要做制造还得找中国，才是双赢的结局。

# 中国在产品开发转化中的角色

像Soft Robotics这样的公司，特别希望能够和中国的制造企业实现更多合作，如果和Soft Robotics这样的小公司合作，你就是他重要的战略合作伙伴，甚至可以是他的战略投资人，学会别人的产品开发转化。

中国在产品开发转化领域是整个链条的缺失，我们需要向国外学习先进的研发能力。

美国创新者自己没有生产能力，而我们有生产能力，如果再具备了研发能力，我们将比他们更加完善、更有竞争力。
