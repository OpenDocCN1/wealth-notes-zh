# 獨特且不可思議的訊號帶你獲利

「這什麼啊？」

第一次接觸我的書的讀者們可能會這麼想。連我的忠實讀者們，看到我用這種插圖整理他們熟悉的訊號，可能也會覺得訝異，連我自己看了有時都會有「咦!？」的瞬間。這是一個不可思議的世界觀。

連我都很欽佩自己，竟然能想出這麼獨特的命名。不過我可不是譭眾取寵。

其實，其實這些命名都是精準表達特徵的名稱！

同時，可以說這 23 種訊號在預測趨勢時，精準度之高，其他方式根本難望其項背。只要繼續看下去，一定也會同意我的說法。

相場世界就是利用這些豐富的「線圖圖鑑」，進行 Good Trading！
