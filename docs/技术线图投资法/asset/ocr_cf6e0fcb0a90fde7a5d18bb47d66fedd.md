# 預測趨勢轉換時，要經常意識到關卡

大家應該都知道「人生的關卡」這種說法，指的就是入學、就業、結婚等人生的重要轉捩點。

股價一樣有關卡。例如大家應該看過「日經指數跌破2萬點大關」這條報導。

所謂關卡，指的就是過去趨勢中的轉捩點的股價，也就是「前一波高低點」、「整數股價」。

許多投資人都很注意，買賣時也會意識到這些股價，所以很容易成為趨勢的轉換點、上漲趨勢的作頭區或下跌趨勢的打底區，也可說是讀線圖時的重點。
