# 「賣點就在這裡！」預測下跌

而兩根黑 K 線看的則是高點。假設之前一直跌的 K 線反彈向上或盤整，然後出現一根黑 K 線，位置比起跌時的黑 K 線更低，之後股價會如何發展呢？答案就是可以預測股價將下跌。
