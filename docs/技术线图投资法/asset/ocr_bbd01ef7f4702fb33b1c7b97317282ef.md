# 關注均線重疊的「川」走勢

第 5 章曾經說明股價的波動模式，就是反覆由 A 局面（下跌）→ B 局面（盤整）→ C 局面（上漲）。還提過順勢操作買賣可增加獲利。

要順勢搭上順風車，重要的是找出趨勢轉換點。而找出趨勢轉換點的技巧就是「川」。

上漲觸頂轉進 A 局面（下跌）時，3、5、7、20 線的排列必須由上而下依序為 20、7、5、3 才行。

要成為這種排列，3、5、7 的位置必須反轉，並走到 20 日（週）線下方。

整體走勢會先看到均線之間距離變窄，然後重疊。之後相交，3、5、7 的位置反轉，變成 7、5、3 的均線排列，然後 3、5、7 依序由上而下穿過 20 日（週）線，進入 A 局面（下跌）。
