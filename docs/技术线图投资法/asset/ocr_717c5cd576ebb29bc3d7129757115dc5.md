# 特性＆定義

連續出現 3 根短紅 K 線、短黑 K 線等短實體的 K 線，稱為三顆星。在下跌趨勢中出現的三顆星，就稱為下跌三颗星。相反地出現在上漲途中的三颗星則稱為上漲三顆星。
