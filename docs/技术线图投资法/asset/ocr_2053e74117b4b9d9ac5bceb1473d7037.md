# 相場流觀點

上漲* 局面中有時會連續出現短紅 K 線、短黑 K 線、十字線等。然而，這並不表示之後一定會向上突破。若 K 線位於均線之上，可期待續漲，但如果向下穿破均線，也可能反轉向下。最好別急著出手。

> * 在上漲趨勢中，要經常意識到會不會突破前一波高點以及關卡。
