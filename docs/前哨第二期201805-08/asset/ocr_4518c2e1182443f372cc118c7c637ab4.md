# 一、高质量 VR 视频

当然，在 VR 技术找到应用场景之前，最重要的就是 VR 视频内容的制作。

目前 VR 视频的清晰度普遍都不够，就是所谓的失真，很容易就出戏，导致沉浸感体验比较差。

+   一个原因是制作 VR 视频本身就非常复杂；
另一个原因是受限于 3G、4G 网络的低带宽和高延迟。

沉浸式体验好的 VR 视频，应该包含三个部分：

+   1. 避免视觉中不协调的 Bug；
2. 实现双眼 3D 空间感；
3. 实现环境互动。

# 二、云计算+VR
