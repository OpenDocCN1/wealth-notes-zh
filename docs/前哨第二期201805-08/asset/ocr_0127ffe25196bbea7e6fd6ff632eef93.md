# 预告 | 云计算平台

我们下周的话题是“云计算平台”。

云计算的概念已经不陌生了，很多 人早就开始使用云盘服务，尤其是智能手机的普及，几乎所有品牌商都提供了云存储服务，比如存通讯录、电话记录、相片等等。

现在以全球来说，云计算平台处于亚马逊、微软、谷歌的三足鼎立状态，从成熟度和体量上来说，亚马逊无疑是老大，微软在利用自己的传统优势，而谷歌则在奋起直追。

在国内，阿里云占据了接近半壁江山，但腾讯、华为等巨头也在持续挑战。

可以说，全球主要的IT巨头，在云计算平台展开了激烈的竞争，那么这背后的商业逻辑是什么？现在的云计算平台发展到什么程度了？这个领域对创业者来说还有机会吗？

欢迎你的关注，我们明天开讲。
