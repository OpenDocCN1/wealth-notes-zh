所以我们说这三个方面需要从长计议，花10年的时间，如果我们能够得住寂寞，一定能够在一些行业当中取得领先。

中国目前在制造业上的优势，会不会随着金属3D打印的发展和应用范围扩大而削弱呢？

# 我的回答是：

表面上不会。

因为金属 3D 打印不会马上形成对中国的产业集群的威胁，很多零件用现有方法批量制造更便宜，很多零件也非金属，没有办法用 3D 打印打出来，但实际上金属 3D 打印会对中国制造形成本质性的威胁，这个原因是很iert人难以察觉到的，原因是什么呢？

就是制造业要掌握主动，就必须дро参与到研发过程当中去。

我们曾经介绍过在新产品的研发过程当中，有一个叫制造就绪指数，也就是说研发刚开始，制造就绪指数是1，最后做到了大批量的、高质量的生产，制造就绪指数才能达到10。而对制造企业来说，越早参与越主动。

中国之所以能够制造 iPhone，其实不是因为中国的制造精度问题，因为我们的制造精度很可能不如日本。甚至不完全是因为零配件问题，而是因为手机是在不断地升级换代过程当中的。

在不断的升级换代的过程当中，速度就很重要，而只有中国工程师能够极大地缩短从设计到量产的时间。因为从设计开始到量产，中间还有很多制造相关的小技术问题需要解决。反之，如果创新企业自己完成了小批量生产，交给任何一个制造企业，别人就能够批量生产，那么这个制造企业代工的价格就很便宜。

比如20年前台湾一度占据了全球的台式电脑的生产市场，但是却被挤压到几乎破产。台湾这些台式电脑制造企业的利润就是千分之一的水平，原因就在于，它们只是在后期介入，也就只是代工，没有介入到前期的研发过程 ‚中去。

所以我们反复地说，先进制造，造什么比怎么造更重要，为创新企业做制造很重要，因为在为创新企业做制造的过程当中，我们能够在制造就绪指数里尽 量前往做。

第10级的时候才能参与到，第9级就可以参与，第8级、第7级，甚至第6级，我就可以参与到研发过程当中，这样的话，研发和制造紧密配合，才能更好地制造出高科技的产品来，学会尽早参与研发，我们就有更大的竞争力。

而如果研发参与过晚，我们的制造业将会沦为纯粹的加工，那么这个纯粹加工的利润是非常薄的。

金属 3D 打印，容易让创新企业不需要中国就可以完成从研发到制造的整个过程，那交给中国的就是一个没有什么价值的纯低端代工，而中国必须要尽早地掌握金属 3D 打印，同时要更紧密地和全球的科技创新企业结合，这样才能保证自己在科技创新中的贡献，也就能保证自己的地位。

目前很多企业都在造电池，不仅有专门做电池的，还有主机厂也在建电池工厂，比如奔驰、特斯拉等等。在竞争日益激烈的情况下，宁德时代上市不久股价就涨到接近每股80元，它的最大竞争力体现在什么方面呢？大车企纷纷建立自己的电池厂，对它的发展会造成什么影响呢？

# 我的回答是：

我看股票从不看价格，我只看市值，宁德时代市值1840亿，我们做下比较，比亚迪去年1700亿，今年跌了，到了1270亿，广汽集团去年1800亿，现在跌了，剩下1000亿，而上汽集团去年3700亿，今年涨了一点点，到4000亿。

我的意思是啥呢，和车企比，宁德时代并不贵，但是别忘了，宁德时代可不是支撑一个车企，是支撑 N 多个车企，甚至未来的很多车企，主要靠宁德时代支撑。尤其是很多利好传出来，比如说宝马最近公布，会向宁德时代采购40亿欧元的电池，大约合到300亿元人民币。

当然是会在未来几年中交付，但是假设你把它分成五年交付，一年也会给宁德时代贡献至少60亿元人民币的收入。其实这就是宁德时代的核心优势所在。也就是说在电动车时代，真正最关键的是电池技术，而那些大车企建电池厂，是因为电动车核心部件就是电池，而电机和控制系统相对都简单，大车企怕被淘汰，所以它也希望尽可能掌握这个核心技术。

但是电池和大车企的传统优势丝毫无关，同时有整车也不会给电池生产和研发带来额外优势，所以我们认为，宁德时代的最大优势，最大的竞争力，集中在研发和生产先进的电池上，而且我们讲，大车企建电池厂的行为也不能拯救它们，只能说明电动车来到了以后，大车企都面临洗牌的格局。

当然具体说到个股，由于最近宁德时代有利好，利好会拉动股市，但是这个利好不会马上兑现，所以现在股票涨了以后，有可能短期会有回落，所以如果你只是买股票的话，可以等一等。当然我还是强调，整体的情况是非常利好的，所以长期持有，一定不错。
