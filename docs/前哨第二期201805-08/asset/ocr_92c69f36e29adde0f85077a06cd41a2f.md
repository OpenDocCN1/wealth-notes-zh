# 预告 | 新能源汽车

我们下一个模块要讲的，是“新能源汽车”。

近期，媒体报道了很多关于新能源汽车产业的新闻，有动力电池制造商，“独角兽”企业宁德时代6月11日登陆创业板。有特斯拉在年度股东大会上，正式宣布要在上海建厂。还有拜腾，宣布完成5亿美元的B轮融资等等。

看起来我们中国的电动车市场真的很热，在2018年的前哨大会上，我提出的十大科技趋势，其中一个就是电动汽车来了。可以说，电动车的趋势已经很明朗，它也是目前新能源汽车的主流。其实，新能源汽车不光改变了汽车产业，还在改变电池产业、甚至整个汽车交通的能源供给方式，而且也会推动自动驾驶、车联网等相关技术的发展，甚至还会改变我们每个人的出行方式。

在下一个模块中，我就会为你详细分析，新能源汽车领域将会产生什么样的产业格局？在这个演化过程中，会为我们带来哪些新的挑战和机会？这可是就在我们身边，未来两年会明显感受到的改变，欢迎你的关注。
