# 一、理性决策的重要性

一个在产业投资领域里面最成功的代表，就是我们常提到的孙正义。

孙正义进入各个产业领域的时候，都是基于大量的分析之后再作的决策，有时候一个分析甚至能够出几千页纸的报告。

那么我们今天也看到他在各个产业领域里面布局的前瞻性，比如我们看到像人工智能、机器人，孙正义的布局又领先了。

所以我们说，理性的决策在整个产业布局当中是非常重要的，对企业也必不可少。

理性决策不一定能保证你做的业务会成功，但是这不是不作理性决策的理由。虽然理性决策仍然不能杜绝风险，但是如果违背理性决策都不做，那你的经营的风险实在是太大了。
