# 预告 | 智能制造

预告 | 智能制造

我们下一个模块要讲的是 “智能制造”。

我在2018年4月22日的前哨大会说过，从支持创新的角度上看，中国制造是一流的，如果加上三个定语，大规模的、复杂的、开放式的，中国不仅是第一，而且是独一无二的。

近期，美国对中国发起的贸易战，明显阻碍了中美间高科技技术转移和产品量产的步伐。

我们说，尽管美国有大量非常优秀的教授，有非常前沿的科研成果，但实际上如果没有中国的制造能力来支持，很多科技创新企业就很难形成自身的造血能力，毕竞也不能总像科研机构一样，依靠研究经费就能运营。

所以，美国创新企业需要与中国制造企业合作，完成产品落地前最后的关键环节。

那么，在当前政治环境下，中国制造在全球创新生态中应该如何重构自己的角色？对于中国制造2025和工业4.0，该如何重新理解和布局，来支撑整个产业链的发展和升级？其中会出现什么新机会和涌现新的趋势呢？

我将在下一个模块中为你分析，欢迎你的关注。
