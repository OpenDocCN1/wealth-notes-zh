紧接着上帝又举了两个例子，说：

海中的怪物利维坦（那就是后来西方政治学当中最重要的几本著作之一的名字，那本书名就从这里来了），有鲸江到海的事，誰能制得住他，你行吗？只有我能。

陆地上的怪物Behemoth（还是那个作者霍布斯，又写了另外一本书，也是西方政治学一个非常重要的著作就叫Behemoth）。Behemoth也是憾天动地的本事，谁能制得住他，你行吗？只有我能。

所有这一切莫不出自于我，你有什么资格跟我这么说话？

约伯听到这之后，翻身倒头就拜，说上帝我错了，从此以后我必更加虔诚的信你。

故事到这里基本就完了。

# 一神教与非一神教的观念差异

这事儿在中国人听起来肯定会觉得匪夷所思，这上帝比魔鬼还坏，魔鬼好歹人家是一真小人，你上帝这就十一足的伪君子嘛，往死里玩你，而且完了之后还要你必须得发自内心的夸一句，上帝，你玩得真好！这是完全不可接受的事情，这种上帝太邪恶了。无法想象他们怎么可以信这种神。

# 信仰的无条件性

我们把刚刚那个故事往后延伸一下，有一个20世纪最重要的哲学家之一，本来是个奥地利的犹太人，后来由于种种原因跑到英国去了，如果你订阅了隔离刘苏里老师的名家大课的话，听到这儿你可能已经猜出来我要说的是谁了？没错，他就是维特根斯坦。
