这一讲，我们讲个工业4.0的典型案例，就是宝马在德国丁格苏的无人工厂。

现在宝马的很多车型都已经国产化了，但高端6系、7系，其实都是在德国的丁格苏工厂装配的。而且，丁格苏生产基地无论是在占地面积上，还是在产量上，都是宝马最大的生产基地，也是欧洲最大的汽车制造工厂之一。这个工厂不仅装配整车，也是汽车零部件的重要生产基地，比如宝马和MINI生产冲压件、底盘驱动组件等核心组件。

我在工业机器人的模块里就讲过，在制造业，一半以上的机器人都应用在了汽车行业，而且它们正在向“无人化”和智能化发展。我这里说的“无人化”是指引导的，其实，无人工厂并不是指完全没人。

那么该如何理解呢？

就拿丁格苏的无人工厂来说，其中的生产工作大多是由机器人、无人运输小车和自动化仓储来完成的。但是其里面员工有1万7千多人，所以如果较真儿的话，这根本就不是无人工厂。

# 一、无人工厂里的工作场景

那么里面的 人都在做哪些工作呢？

具体来说，人 在车间里担任的更多是“指挥员”和“医生”的角色，也就是设置设备参数、修改指令，或是设备维护工程师对设备进行检视和修复。主要就是根据不同的生产工序，设计流程，实现智能生产和智能物流，并且不断优化升级。

就拿汽车制造的流水线来说，主要是分为冲压、车身、油漆和总装4个大环节。除总装环节外，其它环节的自动化程度已经非常高了，尤其是车身环节，丁格苏的自动化程度高达95%以上，在车间里是基本看不到人的。

但总装在所有环节里都是相对自动化程度最低的，这其中的主要原因是，总装环节涉及的零部件和内饰件非常多，安装工序复杂。就拿内饰方面来说，为了满足客户的定制化的需求，就会有很多种组合方式。比如宝马3系，它的内饰有2万多种不同组合，这意味着从生产线上连续下来的两辆宝马3系几乎不可能完全相同。

对于这类工作，训练有素的工人比机器人更好用，而机械臂更多是作为工人的协助工具。

![](bbox=[0.22, 0.0019199999999999998, 0.78, 0.0022])

丁格苏工厂里就大量使用了这种机器臂，准确的叫法是“协作机器人”，也就是说一种能够和人类在一个空间里近距离互动、帮助工人工作的机器人。它的样子也是一个个的机械臂，但看起来比传统自动化生产线上的机械臂要轻巧很多。

传统自动化机械臂，人是必须跟机器在分隔的区域工作的，而且在机械臂工作的区域由护栏围起来，人是不允许进入的。这是出于安全考虑的设计，因为机械臂很重，并且不能够识别是否有在附近，很容易造成安全事故。

而用于智能制造的协作机器人有内置的传感器，可以与人在共同的空间紧密协同工作，安全传感器始终有监控功能，如果检测到障碍物立即停止工作。

在这里，人与机器人相互配合，使得生产系统更安全高效。比如，丁格苏工厂在总装车间安装天窗的轻型机器人，可以举起重达5.5公斤的齿轮，并准确地安装。

# 二、制造过程智能数据分析 and 监控

智能化的工厂想要实现生产制造的稳定和流畅进行，对制造设备和制造过程的实时监控就尤为重要。

在传统制造业中，主要还是依靠工人对于生产过程中的故障和偏差进行识别，或者对于一些简单参数的监控，总的来说，这些监控不够系统，也无法持续有效地监控设备和车辆状态。

在丁格苏的智能工厂中，这些人工监控被它的智能数据分析系统取代，英文叫Smart Data Analytics。

在整个设计制造的生命周期会产生大量的数据，数据包括生产设备上安装的大量传感器捕捉的数据、制造过程中产生的数据、物流数据等。

这些数据信息同时在虚拟环境下以三维方式镜像地重构和体现，这就是工业4.0中的一个重要概念“数字化双胞胎”，英文叫Digital Twin。“数字化双胞胎”可以准确地将现场的制造过程在虚拟系统中可视化。

此外，这些数据通过宝马的物联网，依托云计算平台对数据进行分析，实现流程监控和持续改进。

就拿冲压环节举个例子：

4吨重的钢铝卷切割成的多个钣金件通常在厚度、坚韧度、表面纹路上都不会完全相同。如果这些参数与标准相差太远，在冲压车体部分的过程中就容易断裂。

在丁格苏工厂的智能生产车间，每个钣金件都被分配了一个储存了这些参数信息的激光序列码。

由于这些数据在智能系统中被记录并分析，冲压过程中系统可以智能地根据钣金件的特点选择最合适的冲压力度。

此外，序列码使得每块钣金件的信息在生产周期中实现了可追溯，这样一来在车身环节系统可以将最适配的车体部件进行组装焊接，在油漆环节可以根據板件表面纹路选择最合适的油漆方式。

在运用了智能分析系统后，钣金件断裂率大大降低，后续用于钣金件重量偏差分析的时间也显著减少。

这里需要说明的是，在汽车行业，建立一套可靠、高效、完整、智能的可追溯系统非常重要。

你知道，汽车行业安全最重要，可追溯系统保证一旦出现安全隐患，或者出现故障需要召回时，这套系统能够第一时间锁定零部件、工序和供应商，快速找出根本原因。

在丁格苏工厂，智能数据分析系统，还被运用于对生产设备进行状态监控，计划预测性检修。在工厂中，对生产设备进行预防性的维护，及时更换设备零部件，是避免生产线非计划故障的重要举措。
