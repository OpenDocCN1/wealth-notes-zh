# 259 | 物联网：物联网之父-Kevin Ashton

# —— ◆ 内容看点 ◆ ——

通过阅读这一讲的内容，你将会掌握以下2个问题的答案：

+   1. 物联网的概念是怎么被提出的？
2. 物联网是怎么一步步演化的？

这一讲，我要给你讲的是物联网领域的先驱，MIT 教授 Kevin Ashton。

你要知道，物联网这个概念就是他提出来的，所以他被科技圈称为“物联网之父”，同时他也是 MIT“自动识别中心”的创始人之一，他一直希望实现物联网的自动数据收集和协同决策，不再需要人为干预。

在他的努力下，不仅推广了 RFID 技术的应用，而且还让“物联网”的概念深入人心。

# 一、脱销口红引发的思考

说起来有些传奇，“物联网”这个概念的提出，居然来源于一款脱销的口红。

Kevin Ashton 教授1968年出生在英国的伯明翰。1995年，他和朋友打算创业，做一家家条快餐店，他当时候很有想法，想做一个“网红美食”的品牌，但那时互联网才刚刚起步，他的想法还太超前，其他创始人也没有钱投入互联网运营里，所以他最终选择了自己离开。

后来 Kevin Ashton去了宝洁公司做品牌经理，开始管理玉兰油的产品线。

# 二、物联网的前世今生

前面我们讲了 Kevin Ashton 提出“物联网”概念的故事，但其实早在20世纪60年代，人们就制造了一种监控和数据采集系统（ Supervisory Control And Data Acquisition），简称叫 SCADA 系统。

+   一是，RFID 技术的大规模应用，构建了一个基于物流和供应链管理的物联网；
二是，智能手机的推广。手机上有大量的传感器，有 GPS、重力感应、红外感应、摄像头像、环境光感受器等。你的手机就是一个基于日常生活物联网的集成设备。
