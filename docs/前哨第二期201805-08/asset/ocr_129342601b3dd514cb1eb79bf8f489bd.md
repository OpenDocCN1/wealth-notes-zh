# —— ◆ 模塊總結 ◆ ——

我們這個模組的主題是 5G 通訊技術，介紹了以下四個重點：

第一，5G 通訊技術和相關標準都在陸續發展和完善當中，到2020年實現全面商用。它不僅開辟了移動通信的新時代，更重要的是，它是下一代無線互聯網，構築了萬物互聯的基礎平台。在這個平台上，人工智能、AR、VR 和 MR 等各項技術都將加速發展，相互促進，提高交互的效率，創造全新的應用場景。5G 時代的生活值得我們期待。

第二，創意產業會成為 5G 時代最先獲益的行業之一。借助人工智能、AR、VR 等技術手段，將迎來大爆發。由於 VR 對於帶寬的要求更高，所以現階段 AR 技術將更早實現商業化。但是需要強調的是，硬件技術和支撐平台都很重要。由於兩者的發展進程通常不一致，所以創意行業的創業者要把握合適的切入時機，在產品設計思路上要考慮與硬件和平台相匹配。

第三，高通的成功主要得益於用“專利綁定芯片”和“按照整機價格收取專利費”的收費方式，以及輕資產運營，只關注在知識產權、技術標準方面。儘管這種收費模式引來眾多質疑和天價罰款，但是這種模式很值得科技公司借鑑，只需要掌握核心技術，其他環節通過長板對接的方式與別人合作完成。同時，高度重視主領域的專利技術前沿動態，在未來競爭中占據主動和領導地位。

第四，5G 通訊技術正在不斷完善中，正是迅速尋找需求和提前布局的好時候。建議各個從事傳統行業的人，深入思考這個顛覆性的大機會能不能解決行業痛點。然后把它用“任務分解”的思路拆出來，嘗試提出創造性的解決方案。
