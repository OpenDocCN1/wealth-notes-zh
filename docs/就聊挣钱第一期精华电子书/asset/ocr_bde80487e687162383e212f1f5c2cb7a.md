2. 维护：催更，用他人案例吸引你，用不会被兑现的特殊奖金/保底诱惑，鼓励你发展下线赚钱；
3. 回流：第一笔补贴拿到手后，所有人都会不满意，会暂停拍摄。这时运营会不停安抚、鼓励，直到尝试让你继续拍摄，或者确认你不再合作。回流成功运营会继续维护，而失败则进行下一步；
4. 甩锅，废弃：运营将会把锅甩到 TX/上家机构头上，并表示自己如何亏损，已仁至义尽，最后与你同仇敌忾，安稳结束合作，以便下一次收割；
