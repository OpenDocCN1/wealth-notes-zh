# 智能眼镜的中国之路

首先给大家科普一下什么是智能眼镜？

智能眼镜是指如同智能手机一样拥有独立的操作系统，可以通过软件安装来实现各种功能的可穿戴的眼镜设备统称。它是最近几年被提出而且是最被看好的可穿戴智能设备之一。其具有使用简便，体积较小等，特点公众普遍认为智能眼镜的出现将会方便人们的生活，因此它得到了谷歌，微软等重点研发，被视为未来智能科技产品的重要增长点。
