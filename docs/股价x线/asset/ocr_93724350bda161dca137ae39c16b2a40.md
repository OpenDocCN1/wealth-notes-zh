# 3-14 利用上升 X 線

# 決定多頭市場終點

討論上升 X 線的最終目標,是如何利用它來決定多頭市場終點。確定了多頭市場終點,可以賣光股票,暫時離開市場,或加入空頭陣容。

多頭市場終點決定,通常由反轉型態:如頭肩頂、雙重頂(M 頭)、增大頂點及下降三角形等決定。但是,等待這些型態往下突破,再賣出股票,獲利減少許多。

誰不希望在高點賣出?

雖然,一些自誇在高點賣出股票的人,常被人認爲是吹牛,不過上升 X 線確實可以幫您達成這個願望。

多頭市場的漲升,一般至少都有兩個階段,第一階段上漲後,進行大盤檔,大整理,然後才有第二階段的上漲。所以,多頭市場終點一定在第二階段之後,可能是第二階段或第三階段,其中以第二階段最常發生。

如何在股價尚未完成反轉型態前,利用上升 X 線,決定多頭市場終點,是重要課題。
