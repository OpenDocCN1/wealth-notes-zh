# 14-2 下降 X 線是明確的支撐

股價下跌碰到下降 X 線會有支撐，不只支撐，還會在二天內上漲，第四章已經講的很清楚。讀者按照下降 X 線指示去操作，賺錢機會很大。

# 14-3 阻力

阻力是支撐的反面，股價在上漲過程中，有足夠數量賣出，以阻止股價上漲。

阻力水準是指在某一價位，會阻止股價上升，甚至引起反轉。

一個底部，對下一次上漲會形成阻力。

例如：李四在 40 元買進乙股票，不久漲到 45 元，李四自認決定正確，沾沾自喜。但是，一轉眼乙股票跌到 35 元，李四開始懷疑自己的判斷，並且有了損失，他想如果乙股票回到 40 元，夠本後就把它賣掉，因為乙股票沒有想像好。

所以 40 元底部，對下一次上漲，會形成阻力。
