# 15-2 頭肩頂反轉型態

最常出現、最可靠的頂點反轉型態是頭肩頂。

多頭市場第二部曲末尾，週線圖上有上升 X 線碰到

時，在日線圖上就要注意頭肩頂反轉來臨。

在日線圖上，多頭市場第二部曲股價加速上升，碰

到一條權威的上升 X 線後，忽然一個下跌，形成左肩。

緊接著一個上升，衝過左肩，但是，不久又跌落左

肩之下形成頭。然後，一個軟弱上升（成交量少）達到

左肩高度開始回頭，形成右肩。一旦回頭，跌破頸線，

收盤價離頸線 3 % ，頭肩頂完成了，空頭市場來臨。

頭肩頂形成過程，有一連串警兆。左肩有上升 X 線

碰到是第一警兆，跌破左肩支撐是第二警兆，右肩上升

成交量很少是第三警兆，右肩停止在上升 X 線的二度阻

力（圖 15-1）是第四警兆，跌破頸線已經是第五警兆。
