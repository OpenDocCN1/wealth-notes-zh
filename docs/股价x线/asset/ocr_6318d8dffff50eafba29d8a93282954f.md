# 16-3 其他底部反轉型態

其他反轉型態合併在本節敘述。

# 雙重底和小 W 底

雙重底出現在空頭市場的底部。首先是一個明顯的、大幅度的下跌，碰到一條權威的下降 X 線，產生一個 15～20 % 反彈，在小頂點上上下下兩三週，接著一個下跌，跌到第一底部時，可能碰到一條附近來的小下降 X 線，停在那裡有幾天，或一週之久，接著伴隨一個成交量大增的上升，且突破頸線，收盤離頸線 3 %，雙重底完成，暫時回跌至頸線成交量減少才可買進。其實，您早該在第一底部，碰到下降 X 線時買進。

雙重底未完成前，在第二底部，您不能判定這是一個雙重底，也許還會下跌。尤其是空頭市場第一、第二部曲時，第二底（或第二隻腳）的預期常落空。

空頭市場跌了半年之久，從下降 X 線判斷空頭市場已到尾聲，雙重底的發展才有可能。
