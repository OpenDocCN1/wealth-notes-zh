# 三重頂和矩形

雙重頂多一個頂就是三重頂。每一個頂，不一定一樣高，3 % 的差是容許的。三重頂可看作頭肩頂的變形，頭肩頂頭部稍低，就變成三重頂。如果三重頂三峰間較窄，上下幅度較小可以看作矩形反轉。

# 增大頂點

在頂點的發展過程中，一頂比一頂高，一底又比一底低，成交量高而不規則。這是股市失去理性，瘋狂的表現。反轉後的下跌，必然慘烈。

增大頂點不常出現，但是，一旦出現非同小可，一定要密切注意它的發展。增大頂點底線是水平的叫直角增大型（圖 15-16），它的形狀是下降三角形反過來。
