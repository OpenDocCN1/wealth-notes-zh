# 4.13 下降 X 線的心理

股價碰到下降 X 線時，股民的心理如何？答案是非常害怕，而這裡應該要有勇氣買股票才對啊！這是股民天生心理弱點。因此，買到低價的機會不多。

很多套牢者還會在此殺出股票。

沒有下降 X 線指標，您可以說我不知道啊，我以為還會再跌。有了下降 X 線以後，看清楚了，結果如何？結果是比較不會在此賣股票，但是，還是不敢買。這也難怪，此時眾人悲觀，被恐慌的氣氛嚇壞了，失去勇氣了，錢虧光了。另一心理是晚一點買更便宜吧。錯了，不按下降 X 線指示買進股票，最後都要後悔的。

您學習下降 X 線，同時也要進行心理建設。按下降 X 線操作，正確機率高（99 %），按心理操作錯誤多。

結論：股價碰到權威的下降 X 線時，或多條下降 X 線交叉時，要積極買股票。要有決心，要果斷，不可以三心兩意。有時要反市場群眾心理而行。

心理建設配合股價 X 線才能成功！
