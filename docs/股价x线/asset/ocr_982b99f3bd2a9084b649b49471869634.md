# 3-12 很多股票碰到上升 X 線

在同一時間，很多種股票碰到上升 X 線（譬如 有 20%）。這會造成一種氣勢，尤其是領導股和熱門股，有一大半碰到上升 X 線，這種情況顯示，大勢會有明顯回跌，也有可能反轉進入空頭市場。

所以，很多股票碰到上升 X 線時（包括指數線），要仔細檢查您的股票有無碰到上升 X 線，有無遺漏上升 X 線而尚未畫到者，並考慮賣出股票。當然，此時不能再買股票了。我們看過下一章後，會利用下降 X 線買進，此刻只考慮賣股票就對了。

沒有上升 X 線幫忙，在此處誤買股票是常發生的。

# 3-13 上升 X 線的心理

股價技術性分析所以會衍生，且經久不變，是群眾心理表現的結果。

股價碰到上升 X 線時，股民的心理如何？答案是非常想買進，而這裡應該是要賣股票才對啊！這是股民天
