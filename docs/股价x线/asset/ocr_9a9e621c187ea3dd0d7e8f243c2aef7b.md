所以根據 股價 X 線 操作，是不太需要保護性停止損失委託。保護性停止損失委託只有在，未碰到上升 X 線時忽然下跌。譬如上例，A 股漲到 60 元，尚未碰到上升 X 線，您未賣出。

突然的，A 股大跌至 30 元，這時您已經在保護性停止損失委託的 54 元賣出了。沒賣出的話，現在由賺錢變成虧本了。

雖然您有股價 X 線的厲害武器，保護性停止損失委託也是需要的。由上面例子知道，保護性停止損失委託可以在狀況很壞時，使您免於破產；而在已經獲利時，確保戰果，不會煮熟的鴨子飛了。

這一套辦法不錯吧，所以，保護性停止損失委託要照規定去設。

# 19-2 逐次的停止損失委託

當股價上漲碰到上升 X 線時，按照上升 X 線指示，賣出股票，股價隨即下跌，操作堪稱完美。
