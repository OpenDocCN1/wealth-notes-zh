# 18 缺口及一天反轉

股票圖缺口就是沒有交易的價格區域。

日線圖中的缺口，在上漲情形是，一種股票某一天的最低價，比前一天的最高價還要高；在下跌情形是，一種股票某一天的最高價，比前一天的最低價還要低。週線圖上類似，只是以一週取代一天。

缺口是前後天，股價在水平線上沒有重疊，市場上則沒有交易，這不是普通狀況，它有某種意義。

### 18-1 沒有意義的缺口

在討論有意義缺口前，先把沒有意義的缺口除去。

一個喊價單位的缺口，因為太小而無意義；成交量小的冷門股，經常有缺口發生，這種缺口無意義；除息或除權缺口也無意義。

以上缺口沒有技術性的意義，因此要從分析上除去，剩下有意義的缺口再來討論。

### 18-2 缺口的種類

除去沒有意義的缺口後，技術性分析有意義的缺口分成下列 4 大類（圖 18-1）：

- (1) 普通缺口（或區域缺口）
- (2) 突破缺口
- (3) 繼續缺口（或逃逸缺口）
- (4) 竭盡缺口

島狀反轉有兩個可以望穿的缺口，前面是竭盡缺口，反方向是突破缺口，如海中孤島。

### 18-3 普通缺口

普通缺口出現在一個交易區域中，或價格密集型態中，例如三角形或矩形。這些型態中的交易集中在上線和下線，中間區域交易較少，甚至沒有交易，於是形成區域性缺口叫普通缺口。

普通缺口出現在整理型態比較多，在反轉型態中較少。因此，在發展中的三角形或矩形，有許多缺口出現，就可預期這是整理型態，而非反轉型態。

### 18-4 突破缺口

突破缺口出現在一個整理型態、反轉型態或一條趨勢線的突破。例如，突破上升三角形及矩形的上線，或頭肩底的頸線，或一條趨勢線時，經常伴隨有突破缺口。

股價以突破缺口向上脫離形態，表示這種股票比沒有缺口者顯得有活力，買方力量較強，突破是真正的，您應優先考慮這種股票。

至於這個缺口會不會封閉？那要看突破時的成交量。成交量較少的突破，有一半機會跌回來封閉缺口。成交量很大的突破，回跌時只到缺口邊緣就會停止。

有些突破缺口發生在當天交易時間內，而日線圖無法顯示出來，如果這是您有興趣的股票，可以在網路上查閱個別成交紀錄，或看分時走勢線。

### 18-5 繼續缺口

繼續缺口又叫逃逸缺口，顧名思義，出現繼續缺口時，趨勢會繼續下去，莫非這種缺口有測量意義？

繼續缺口出現時，股價能再走的距離，和已走的距離一樣，在半對數紙上兩段的高度一樣。

有時，繼續缺口會出現兩三個，哪一個是中間，可以用來測量？您可以試著去平均它們的中點。但是，每個接連發生的缺口，將步步逼近上漲的終點，若有上升 X 線接近，上漲的終點真的快到了。不要陶醉於後面出現的缺口，您對於第二、第三個缺口不要抱太大希望，隨時準備在碰到上升 X 線時脫手。

### 18-6 竭盡缺口

再熱鬧的事也有結束的時候。

多頭市場最後階段的跳空，開盤就漲停板，非常振奮人心。但是，有一種缺口代表終點已到。該下車了，那就是竭盡缺口。

竭盡缺口伴隨快速變動，及高成交量而來，多頭和空頭竭盡所能產生最後一個缺口，也是空頭不計一切補回的時候，此後變動會減緩，甚至在買氣完全消失時，會在反方向產生突破缺口，連續跳空下跌。

當繼續缺口的測量已到達，上升 X 線橫在股價上，開盤就是賣股票的時候，有時漲停板可以撐到收盤前一刻，成交量則異常的大，但是，漲停板在臨收盤前打開了，收不了漲停板，第二天開盤就會跌停板，您回想一下，每個多頭市場，一些股票是不是這樣結束的。

如何辨別繼續缺口或竭盡缺口？

突破缺口後的第一個缺口，離上升 X 線還有一段距離，成交量尚未到驚人的地步（譬如發行股數的 1/10），上升潛力似乎還未用完，可以認定是繼續缺口。

此後的缺口，如果比前面的缺口都要寬，成交量更大，最重要的是碰到週線圖上的上升 X 線，都要認定是竭盡缺口。如果漲過上升 X 線也不要認爲突破了，上升 X 線失效了，回頭是一、二天內的事，一旦回頭，立刻會跌到上升 X 線下方很遠的地方。

竭盡缺口不一定要反轉，可怕的是週線圖上的上升 X 線，如果這兩者一起發生，反轉是難免了。

### 18-7 島狀反轉

島狀反轉的發生和缺口有關，所以在這裡又提出。

一個緊密交易區，它的前面有一個竭盡缺口，其後在反方向，形成一個突破缺口。緊密交易區可能是一天，那也可能就是一天反轉，也可能數天至一星期，維持高成交量是特色。

突破缺口和竭盡缺口出現在同樣價格，且水平可以望穿，這是島狀反轉。底部島狀反轉倒過來就是。

島狀反轉並不是原始反轉，但是，在島的地方，如果有碰到遇圖形的上升 X 線，原始反轉就很有可能了。

島狀反轉類似倒 V 形反轉，等到發現時已太晚。上升 X 線是唯一事前可以防範的。

### 18-8 一天反轉

單獨看一天反轉時，只是一天中行情劇烈的變動。在上漲情況是開盤衝高，成交量放大，然後上下震盪，甚至在漲停板和跌停板之間來回，變動之迅速，令人措手不及。收盤前在驚人的成交量中快速下跌，可能以跌停板收盤。一天反轉發生在多頭市場最高峰，或中級上升的頂端，事前一定有碰到權威的上升 X 線(包含日線和週線)，甚至已衝過上升 X 線若干天了。

一天反轉也發生在空頭市場恐慌下跌底部。開盤可能跌停板，然後步步上升，收盤達最高價。事前一定有碰到下降 X 線(包含日線和週線)，甚至跌破頭。

一天反轉並非原始反轉，但是，要注意往後發展。

# 19 停止損失委託

停止損失委託是緊急時的滅火器。

作股票的人最怕的是破產，如何避免呢？除了要有足夠的股票技術外，還要作停止損失委託。

停止損失委託分爲兩種：

- 1. 保護性停止損失委託。
- 2. 逐次的停止損失委託。

### 19-1 保護性停止損失委託

當您買進股票時，就要設下保護性停止損失委託，放空時亦同。

股票經常不照您想的方向進行。在您買進時可能大跌；而放空時可能大漲。

當股價不照您預期的方向變動時，您不知道情況有多惡劣。假如您不設下停止損失委託，您可能一天天盼望那不可能的回升。

當股價跌個不停時，您就會發現開始時只是一個不愉快的小損失，現在已經變成一個大洞，一個不可收拾的損失，甚至破產。

如何設保護性停止損失委託呢？

以多頭爲例子，您買進股票後要在買進價下方約 10 % 的地方，設保護性停止損失委託。10 % 是大概的，這要看股票的敏感度及您能忍受的損失。投機一點的股票要設大一點，以免因爲偶然的下跌而誤賣股票。

保護性停止損失委託設好後，一旦股價跌到此價，就不計一切賣出，以保護資金。要是賣出後股票又漲起來呢？這也是沒辦法的事，可視爲不是您能力所及。

其實，如果根據下降 X 線買進股票，最慢第二天就會漲起來，保護性停止損失委託是不會執行的。

保護性停止損失委託設定後，絕不可以向下移動，價格到了就要執行。以免猶豫不定，最終不可收拾。

買進後股價上漲了如何？這時要把保護性停止損失委託向上移動，而且隨著股價上漲隨時往上移動，一直到這一檔股票賣出為止。

何時賣出呢？可以根據上升 X 線操作，或您認爲滿意了就可以賣，也有可能在保護性停止損失委託價賣出。用下面例子來說明：

假定 A 股票在 40 元時，碰到下降 X 線，您買進一萬股，您在股價下方 10 % （36 元）設保護性停止損失委託。可是，您是根據下降 X 線買進的，A 股漲起來了，還漲到 50 元，這時您把 36 元的保護性停止損失委託取消，並重新在 50 元下方 10 % （45 元）設立新的保護性停止損失委託。

股價跌回 46 元，股票未賣出。轉眼 A 股漲到 60 元。您把保護性停止損失委託提高到 60 元下方 10 % （54 元）。但是，A 股漲到 62 元，碰到權威的上升 X 線，您賣掉股票，獲利 22 元。

所以根據 股價 X 線 操作，是不太需要保護性停止損失委託。保護性停止損失委託只有在，未碰到上升 X 線時忽然下跌。譬如上例，A 股漲到 60 元，尚未碰到上升 X 線，您未賣出。

突然的，A 股大跌至 30 元，這時您已經在保護性停止損失委託的 54 元賣出了。沒賣出的話，現在由賺錢變成虧本了。

雖然您有股價 X 線的厲害武器，保護性停止損失委託也是需要的。由上面例子知道，保護性停止損失委託可以在狀況很壞時，使您免於破產；而在已經獲利時，確保戰果，不會煮熟的鴨子飛了。

這一套辦法不錯吧，所以，保護性停止損失委託要照規定去設。

### 19-2 逐次的停止損失委託

當股價上漲碰到上升 X 線時，按照上升 X 線指示，賣出股票，股價隨即下跌，操作堪稱完美。

若沒有碰到上升 X 線，就已經出現下述情形，您要運用逐次的停止損失委託（The Progressive Stop）。

逐次的停止損失委託用在：

- (1) 一檔股票已經走到可以獲利地方，準備了結。
- (2) 一檔股票已出現高成交量，顯示出危險信號。
- (3) 一檔股票已經進入狂飆階段了，您擁有這檔股票時，覺得非常危險。但是，又想多賺一點，不願意太早賣掉。
- (4) 股票不能達到目標值時，看起來已經搖搖欲墜，怎麼辦？

您要以逐次的停止損失委託對付它。

這時把保護性停止損失委託取消，每天在收盤價下面一個喊價單位作停止損失委託，直到有一天開低盤，停止損失委託執行，股票賣出爲止，確保最大獲利。

舉例說明：

停止損失委託價 = y -（y × 10 %）， y 是股票價格

您以 40 元買進 B 股，在 36 元設下保護性停止損失委託。股價漲至 50 元，把保護性停止損失委託提升至 45 元，股價漲至 60 元，把保護性停止損失委託提升至 54 元。每漲一小段，保護性停止損失委託提升一次。

股價開始狂飆，誰都不願意放棄這檔股票。B 股漲至 100 元了。此時沒有上升 X 線碰到，可是已經出現高成交量了，看起來很危險。這時您把保護性停止損失委託（設在 10 % 之下的 90 元）取消，改在 100 元收盤價之下 一個喊價單位（99.9 元）設下逐次的停止損失委託（The Progressive Stop）。

第二天跳空上漲，漲至漲停板 107 元，逐次的停止損失委託未執行，這時您把逐次的停止損失委託改在 107 元之下 一個喊價單位（106.5 元）。

第三天跳空上漲，漲至漲停板 114 元，逐次的停止損失委託未執行，這時您把逐次的停止損失委託改在 114 元之下 一個喊價單位（113.5 元）。

看起來愈來愈危險，但是，第四天又跳空上漲，漲至漲停板 121.5 元，逐次的停止損失委託未執行。這時您把逐次的停止損失委託改在 121.5 元之下 一個喊價單位（121元）。

第五天開低盤，您的 B 股賣出了（一旦開低盤如果121元未賣掉，您必須以市價方式賣出）。

這樣，一開始，您只把保護性停止損失委託，改爲逐次的停止損失委託，最後多賺了好幾個漲停板，而所冒風險有限。

空頭也要設停止損失委託，只是方向相反。

### 19-3 停止損失委託如何執行

在台灣，停止損失委託不能事先輸入電腦，您可以委託您的經紀人，幫您執行，或者您自己在電子交易系統執行。

不過，停止損失委託訂在什麼價錢，您要事先在股票圖上作記號決定，這是您自己該做的。

有了經典技術性分析的基礎，也有股價 X 線這種厲害的武器，又有停止損失委託的保護，在您縱橫股市時，應是十拿九穩矣。

# 20 股票圖作法

股價 X 線 必須在半對數圖紙上畫出。

如果您已經有股票圖，那麼，只要在圖上加上股價 X 線即可。若是您未曾作圖，而必須從現在做起，或是您原來用方格紙，現在想改用半對數圖紙，以便更精確畫出股價 X 線，積極從事股票投資，本章對您有幫助。

### 20-1 方格紙有缺點

幾乎想畫股票圖的股友，一開始便會想到方格紙。因為它好買，且很多人使用。其實，方格紙並不是最好的工具，方格紙只適合於畫一些變化簡單的圖表，如溫度變化、生產量及學生人數統計等。

用方格紙分析股票並不科學，很顯然，一檔股票從10元漲到15元，差價5元，漲了50%。有一天該股票漲到100元，再從100元漲到105元，差價也是5元，漲了5%。同樣上漲差價5元，前者漲了50%，後者只漲5%。如果這5元的差價，在方格紙上取相同長度，便無意義。而方格紙不管任何價位，這5元的差價在方格紙上的垂直長度是一樣的。

說明白點，5元差價對於市價10元股票非常重要，但是，對於市價100元股票，5元的差價並不很重要。方格紙不能把這樣的特點表現出來。

總之，方格紙的缺點如下：

- 1. 一檔股票快速、大幅上漲時，每日價格變動愈來愈大，每天在圖上的長度愈來愈長，結果整個圖被拉長。
- 2. 一檔股票快速、大幅下跌時，每日價格變動愈來愈小，每天在圖上的長度愈來愈短，結果整個圖被壓扁，看不出什麼型態。
- (3) 由於上下變動不一致，趨勢線及 股價 X 線不準確，失去意義。
- (4) 每檔股票不能作漲幅的比較。
- (5) 大小不一，保管困難。沒有紙邊，不美觀，沒有成交量刻度，沒有日期線，完整性差。

### 20-2 選用半對數紙

針對方格紙的缺點，美國股市前輩設計了一種叫做TEKNIPAT 圖紙，即俗稱半對數圖紙，在美國已沿用了數十年，這是分析股價最有效的圖紙，本書很多股票圖都是使用這種圖紙。早年，以自製這樣多半對數圖作技術性分析，在臺灣是一種創舉。

您可以輕易看到很多圖例是那樣的細，筆者花了不少時間製作這些美觀的股票圖。

只有正確而美觀的股票圖，作技術性分析時，才不會感到厭煩和失望。因為股票圖正確，研判才不會失誤，才有把握賺到錢。

### 20-3 半對數紙圖紙優點

半對數圖紙優點如下：

- 1. 圖上相等的垂直長度代表相等變動百分比。
不管任何股票任何價位，只要變動百分比一樣，它的長度就一樣，不會上漲拉長，下跌壓扁，及不同股票變動不一致的毛病。
- 2. 股票圖在任何價位均不變形。所以，趨勢線和股價X線最準確。
- 3. 半對數圖紙上的上升趨勢線，突破較早，可以比方個紙早一點發現。
- 4. 半對數紙股票圖的趨勢線，是大約與水平成30 ~ 50 度角度的直線，是適當的趨勢線角度。
- 5. 各公司的股票圖，都是基於同一比例。因此，您可以很容易從每一種股票圖上升的長度，去比較上漲幅度，並據以計算各股票的敏感度。
