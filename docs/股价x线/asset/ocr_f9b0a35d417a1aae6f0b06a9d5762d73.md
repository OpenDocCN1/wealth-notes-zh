# 14-10 支撐和阻力互換

支撐位置若被跌破，會變成下次上升的阻力。例如原來是支撐的頭肩頂頸線一旦跌破，暫時回升只到頸線為止，上升趨勢線原是支撐，一旦跌破，暫時回升的阻力便是此線。

同樣，阻力被突破，下次回跌至，便有支撐。例如，頭肩底的頸線突破後，下次下跌到頸線可望停止。下跌趨勢線突破後的回跌，也到此線為止。

上升 X 線和下降 X 線，沒有支撐阻力互換情形。

權威的上升 X 線，如果短暫向上穿過，反而會迅速回跌至上升 X 線之下。任何情形，上升 X 線沒有支撐作用。上升 X 線是阻力，不要誤會誤用。

下降 X 線如短暫向下穿過，會迅速回到下降 X 線的上方，彷彿前面的穿過是多餘的，像盲腸一樣。任何情形，下降 X 線沒有阻力作用。下降 X 線是支撐，不要誤會誤用才好。
