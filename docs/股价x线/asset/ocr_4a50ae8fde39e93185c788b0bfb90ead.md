股價 X 線長時間使用，會有股價除息、除權而影響圖面的問題。一般除息只有一、二元，沒有影響。

週線圖上除權 20 % 以內造成的缺口，可以不予理會，不必填回除權缺口，好像股票正常漲跌一樣去畫、去使用股價 X 線即可。

日線圖上除權 10 % 可以正常使用，不必填回除權缺口。但是除權大於 10 % 時，要把缺口移回去，因為日線圖上的股價 X 線使用時間較短，大的除權在短時間內，多少是會影響股價 X 線的效用的。

現在股票衆多，碰到除權太大的股票，可以暫時不在這種股票上畫股價 X 線，另尋其他目標即可。但是股票圖還是要延續下去，等待未來的機會。
