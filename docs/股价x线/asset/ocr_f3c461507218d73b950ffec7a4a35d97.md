# 6-2 股價 X 線是斜的支撐和阻力 —— 可靠、準確

股價 X 線 是支撐和阻力的一種特殊狀況，一種斜的支撐和阻力。

從（圖 6-1）裡您可以簡單的理解，如何由水平的支撐和阻力，發展成斜的支撐和阻力，形成股價 X 線。

從（圖 6-1）的上半部的第二種情形看來，下降 X 線是從支撐狀況演變而來，只因為從第二頂點跌下來，在第一頂點的價位 A 未獲得足夠支撐而下壓了一點，這種過度的壓力，表示買方力量有所不足。當股價從第三頂點跌下來時，不會很快獲得足夠支撐，而需要跌到更 低價位 C，碰到這一條現在叫做下降 X 線時，買方力 量，才能勝過賣方而終於產生回升了，於是下降 X 線誕 生了。B 點愈低，C 點跟著降下來，下降 X 線傾角愈大 （愈斜向右下方的意思）。
