假如，股價下跌碰到原來那條 下降 X 線，仍然反彈叫二次支撐。

股價第一次碰到下降 X 線當然會反彈，第二次下跌再碰到同一條下降 X 線，是否會反彈呢？

可由下面決定：

+   （1） 空頭市場初期，股價下跌快，下跌潛力大，不易有二次支撐。

+   （2） 空頭市場末期，易有二次支撐。

如果，已經產生二次支撐後，股價第三次碰到，又有支撐叫三次支撐（圖 4-6）。

至於，若又有第四次、第五次支撐叫多次支撐。

二次支撐、三次支撐及多次支撐，發生在空頭市場最終階段，是空頭市場逐漸轉爲多頭市場打底階段。

股價第二次、第三次碰到同一條下降 X 線時，買進股票是不一定可靠的。但是，從它的發展過程，可以反推市場是否在改變中，空頭市場就要結束了嗎？

一條權威的下降 X 線 是要延長一倍以上的，用來試驗是否有二次支撐、三次支撐情形。
