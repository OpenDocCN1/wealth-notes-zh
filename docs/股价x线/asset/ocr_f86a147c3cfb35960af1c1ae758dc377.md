# ## 9-3 初學指南

股票市場上，每年都有成千上萬的生力軍加入，每一個人懷著夢想，夢想著有一天藉著股票賺到很多錢，實現人生的許多願望。

假如，您是一個初學者，想要利用一種可靠的方法作股票。有一天，偶然遇到 股價X線 這本書，買下了這本書，您已經踏出正確的第一步。

熟讀之後，開始畫 股價X線，按照 下降X線買 股票，按照 上升X線賣 股票，也能有些收穫，是一個好的開始。

但是，證券知識浩瀚，最好以股價X線為基幹，再涉獵其他技術，奠定穩固根基，才能立於不敗之地。

首先，把本書後半段的經典技術性分析看看，這一部分本來預定在 1998 年出版的，拖到現在，併入股價X線出版。

您再找到找美國股市權威 John Magee 經典之作的原文本或翻譯本好好看一看（初學者很費力）。
