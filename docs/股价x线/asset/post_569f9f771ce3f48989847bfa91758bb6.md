
## 4-8 B型下降 X 線

前面討論的下降 X 線，是頂和底相連的（至少間隔一個底和頂），它的方向是向右下方傾斜的，這種向右下方傾斜的下降 X 線，叫正統下降 X 線。

依支撐和阻力演變的理論（119 頁），有一種下降 X 線所使用的頂與底中，頂比底還低，好像中央山脈中的一個山頭比某一河谷低。這種下降 X 線畫出來方向是，向右上方傾斜的（圖 4-9）。

![](img/114f067fd2db153a6ed238c66e83de58_61_0.png)

圖 4-8 B 型下降 X 線。底 B 比頂 A 高，造成下降 X 線不向右下方傾斜，反而向右上方傾斜，這種下降 X 線叫 B 型下降 X 線。B 型下降 X 線效用和下降 X 線相同。

![](img/114f067fd2db153a6ed238c66e83de58_62_0.png)

圖 4-9 B 型下降 X 線出現位置。出現在多頭市場回檔 ($C_1$)，以及空頭市場早期 ($C_2$、$C_3$)。前者是回檔最低價；後者最好不要買進，上漲有限，若您買進的話，有漲就要賣。

向右上方傾斜的下降 X 線，和上升 X 線是會混淆的，因此另外命名為 B 型下降 X 線。

B 型下降 X 線和正統下降 X 線都是下降 X 線。它們的畫法、作用完全相同，只是傾斜方向不同。

B 型下降 X 線出現在多頭市場第一階段，或空頭市場早期。前者是買進的好機會，後者不要輕易嘗試。

## 4-9 下降 X 線和成交量

下降 X 線和成交量無關，股價碰到下降 X 線，都會漲，不管當時成交量如何。不過，如果下跌時成交量較小，反彈可能較大。當您考慮搶兩種股票的反彈時，選成交量較小，且碰到下降 X 線的那種；可能的獲利會大一點。

## 4-10 下降 X 線沒有測量作用

一條下降 X 線畫出來後，不能預測股價必定下跌去碰它。一條很陡的下降 X 線，有時永遠也碰不到。

下降 X 線只肯定股價碰到後會漲，至於股價會下跌多少，不是用下降 X 線去預測，而是用頭肩頂、雙重頂的最小測量、股票敏感度及市場大勢等去預測。

毫無疑問，如果股票下跌沒有下降 X 線去擋它，下跌比較容易。下面滿佈下降 X 線時下跌就困難些。

什麼情況下面不容易有下降 X 線：一為多頭市場狂熱上升後忽然反轉，二為空頭市場末期，股價直線下降的恐慌下跌。這兩種情況買進股票要非常小心，因為它們找不到可以畫下降 X 線的基本點，意思是沒有什麼支撐，不會上漲。

## 4-11 下降 X 線和恐慌下跌

買股票最怕碰到恐慌下跌。有時，您會看到長期累積的獲利，因為恐慌下跌在幾天內變成泡影，甚至虧損累累。

恐慌下跌容易發生在空頭市場第一階段，及空頭市場第三階段。股市一旦引起恐慌，似乎什麼辦法也沒有，唯一預防的方法是：

- 1. 利用上升 X 線，在還沒有引起恐慌時賣出。
- 2. 向下突破明顯的反轉型態時，不限價賣出。
- 3. 利用停止損失委託，跌到停損點時，不限價賣出。

恐慌下跌時即使碰到下降 X 線，其反彈只有一二天，搶反彈者要迅速了結。

恐慌下跌時，碰到一條很有權威的下降 X 線或數條下降 X 線的交叉點，並未停止，反而加速下跌。這種情況告訴我們：

一個較大反彈，甚至多頭市場就要來臨。

跌到下降 X 線下方部分屬於超跌，可考慮逐步承接，一旦回升必有可觀獲利。空頭在此刻也要回補了。

![](img/114f067fd2db153a6ed238c66e83de58_65_0.png)

圖 4-10 下降 X 線超跌。碰線第二天沒有漲，反而繼續下跌，這種超跌很快會漲到下降 X 線之上，下降 X 線不會變成阻力。

無論如何，空頭市場買進股票要少，不可以全力為之，因為空頭市場股價下跌，畢竟比較容易！

## 4-12 很多股票碰到下降 X 線

在同一時間，很多的股票碰到下降 X 線（譬如有 20%）。這會造成一種氣勢，尤其是領導股和熱門股有一半左右碰到下降 X 線，這種情況顯示大勢會有明顯上漲，也有可能反轉進入多頭市場。

所以，很多股票碰到下降 X 線時（包括指數線），要仔細檢查您心目中的股票，有無碰到下降 X 線了，有無遺漏下降 X 線而尚未畫到者。若股票圖太短，譬如只有三、四個月，必會遺漏下降 X 線。

很多股票碰到下降 X 線時，要考慮買進股票。當然，不能再賣股票了。我們看過上一章後，應該會利用上升 X 線賣出，此刻只考慮買股票就對了。

沒有下降 X 線幫忙，在此錯賣股票是常發生的。

## 4.13 下降 X 線的心理

股價碰到下降 X 線時，股民的心理如何？答案是非常害怕，而這裡應該要有勇氣買股票才對啊！這是股民天生心理弱點。因此，買到低價的機會不多。

很多套牢者還會在此殺出股票。

沒有下降 X 線指標，您可以說我不知道啊，以為還會再跌。有了下降 X 線以後，看清楚了，結果如何？結果是比較不會在此賣股票，但是，還是不敢買。這也難怪，此時眾人悲觀，被恐慌的氣氛嚇壞了，失去勇氣了，錢虧光了。另一心理是晚一點買更便宜吧。錯了，不按下降 X 線指示買進股票，最後都要後悔的。

您學習下降 X 線，同時也要進行心理建設。按下降 X 線操作，正確機率高（99%），按心理操作錯誤多。

結論：股價碰到權威的下降 X 線時，或多條下降 X 線交叉時，要積極買股票。要有決心，要果斷，不可以三心兩意。有時要反市場群眾心理而行。

心理建設配合股價 X 線才能成功！

## 4-14 利用下降 X 線決定空頭市場終點

討論下降 X 線的最終目標，是如何利用它來決定空頭市場的終點。

確定空頭市場的終點，可以進場大買股票，揮別空頭市場，早一點加入多頭陣容。

空頭市場終點就是多頭市場的起點，通常由反轉型態：如頭肩底、雙重底（W 底）、上升三角形等決定。但是，等待這些型態往上突破，再買股票，成本高許多，獲利則不確定。

誰不想在最低點買進股票，下降 X 線可以幫您達成這個願望。

空頭市場的下跌，一般至少都有兩個階段，有時有三個階段。

所以，空頭市場終點都在第二階段之後，也可能在第三階段。如何在股價尚未完成反轉型態前，利用下降 X 線，決定空頭市場終點，是重要課題。

決定空頭市場終點的方法：

- 1. 週線圖上碰到一條或一條以上的下降 X 線。
- 2. 月線圖上碰到一條下降 X 線。
- 3. 日線圖股價碰到三條下降 X 線的交叉點。
- 4. 日線圖發生二度支撐或三次支撐。
- 5. 空頭市場末期的恐慌下跌，股價下跌已經過一次或兩次煞車，最後碰到一條極陡的下降 X 線。

## 5 畫股價 X 線的細節

上升 X 線是底和頂相連（至少間隔一個頂和底）。

下降 X 線是頂和底相連（至少間隔一個底和頂）。

看似很簡單，但是，一般初學者，可能有一些困難，本章我們作更詳細的說明。

### 5-1 要用半對數圖紙

半對數圖紙最大特色是：圖上相等的垂直高度代表相同的上漲百分比。譬如甲股票從 10 元漲至 15 元，上漲 50%，乙股票從 200 元漲至 300 元，也上漲 50%，兩者漲幅在半對數圖紙上垂直高度是一樣的。作股票注重的是獲利百分比，獲利百分比高，代表技術好。而這百分比在半對數圖上，可以用尺量出，不必計算。

如果一種股票從 10 元漲到 200 元，方格紙股票圖將會被拉長 20 倍。您想這圖將是何等的畸形，趨勢線、股價 X 線完全無意義。而

- 半對數圖紙不會因股票大幅上漲被拉長；
- 半對數圖紙不會因股票大幅下跌被壓縮。

半對數圖紙始終如一，趨勢線、股價 X 線才有意義。市面上少有賣半對數圖紙，筆者推廣半對數圖紙已二十幾年了（詳見第 20 章）。

財訊日報及一些電腦圖，也採用半對數刻度，可以用來畫股價 X 線。但其缺點是圖太短，前面用來畫股價 X 線的點（頂或底）被切掉了。且垂直方向隨股價而伸縮，股票間漲幅不能用垂直高度作比較。

您如何知道電腦圖是半對數刻度？答：同樣價格的垂直刻度愈來愈小就是了。如果，同樣價格的垂直刻度均相等，代表的是方格紙的刻度。

想學作股票，親自畫一些股票圖是基本的課程。沒有辦法畫 1000 種，畫 50～100 種是辦得到的，也是需要的。

沒有辦法每天畫日線圖，可以畫週線圖，每週畫一次即可。其實根據週線圖去畫股價 X 線，並據以操作股票，比較輕鬆省力。幾個月內就有一次好機會，對上班族來說是很適合的。

本書附有發售空白半對數圖紙，分日線圖和週線圖兩種，讀者如劃撥購買，請註明清楚。

### 5-2 紅藍相間

在半對數股票圖上，畫出股價 X 線，不論是上升 X 線或下降 X 線，均以紅藍相間直線畫出，以別於紅色上升趨勢線，及藍色下降趨勢線。

畫的時候以紅色貫穿全線，再點上若干藍色即可，藍色的線在股票圖上太多，會干擾您的視覺，影響美觀。淡淡的紅色較不顯眼，作圖時筆不要太重，圖面保持勻整，使用大三角板。一種紅藍兩用原子筆，適合作股票圖，可畫趨勢線，也可畫股價 X 線，一筆兩用。

### 5-3 可以翻山越谷

上升 X 線基本點的選擇，不限於多頭市場部分 ($X_1$)，可以從前面空頭市場跳過一個大底 ($X_2$)，和多頭市場的頂點相連。空頭市場權威上升 X 線，也可以延伸至多頭市場繼續使用 ($X_3$、$X_4$)（圖 5-1）。

![](img/114f067fd2db153a6ed238c66e83de58_94_0.png)

同樣，下降 X 線的基本點，不限於空頭市場的部分 ($X_1$)，也可以從前面多頭市場頂點，跳過一個大頂，和空頭市場的底部相連 ($X_2$)，多頭市場權威下降 X 線 ($X_3$、$X_4$)，也可以延伸至空頭市場使用（圖 5-2）。

![](img/114f067fd2db153a6ed238c66e83de58_95_0.png)

### 5-4 選明顯的基本點

基本點就是頂點和底部，就是股票圖上明顯拐彎的地方，明顯起伏的地方。基本點見 311 頁。

由明顯的基本點連成的股價 X 線，比較權威，可信賴程度好，可以據以買賣，在股票圖上要畫重些。有的基本點不那麼明顯，股價 X 線畫輕些，買賣少一點。

一般初學者，從週線圖開始畫股價 X 線（包括上升 X 線和下降 X 線），週線圖上的基本點比較少，但是比較明顯，也比較好畫。畫出一條股價 X 線，馬上就可以根據來買賣，錯誤的機會少。

日線圖上的拐灣比較多，有些很細，一般初學者會感到有些困難，畫出後不知對不對，也不敢買賣。

有些基本點看起來不明顯，那是因為股價變動幅度大，電腦畫面自動壓縮的結果；另有些基本點看起來很明顯是因為股價變動幅度太小，電腦畫面自動放大的結果。初學者還是要固定在一種標準半對數圖紙去訓練比較好。電腦畫面則要考慮是否壓縮，或放大的因素，以確定基本點是否真的明顯，以免誤用。

但是，學任何東西總是：一回生，二回熟，三回就上手。和其他作股票技術比較，股價 X 線算是易學好用的。學股票技術從股價 X 線開始就是好的開始。

### 5-5 取真正頂點和底部

有的時候您會發現一個頂點區有數天，而最高價那天有上影線，最高價也比前後天沒有高多少，這時可以考慮把上影線切掉一點點，但是，最多切掉二個喊價單位，不能切太多，若上影線很長（譬如有一個漲停板大小），是不能全部切掉的。口訣是突出切一點。

簡單的講，上影線不能切太多。要是您無法決定，那就乖乖的採用最高點就是了，不要為此傷腦筋。下影線的問題，也用類似方法解決。

有時頂點有三四天，它們的最高價都差不多，形成齊頭狀，那就取中間位置代表真正頂點，口訣是平頭取中間。底部用類似方法。示範如下：

### 5-6 交叉愈單純愈好

股價 X 線必須和股價趨勢交叉，股價 X 線好像一個蹺蹺板，交叉點好像蹺蹺板的轉軸，蹺蹺板的轉軸只能有一根，如果有好幾根轉軸，蹺蹺板是轉不動的。

所以股價 X 線交叉點不要太複雜，愈單純愈好（圖 5-5），最好成一天交叉狀況，超過三天就不好。因為交叉區太複雜時，支撐阻力的消長已在複雜區改變了，股價 X 線可能沒有那麼準確了。
