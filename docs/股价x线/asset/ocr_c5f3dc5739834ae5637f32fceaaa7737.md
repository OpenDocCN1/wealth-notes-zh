圖 15-1 頭肩頂和二度阻力關係。第一次碰到上升 X 線形成頭肩頂的左肩，二度阻力出現在右肩。從頭部回落至上 升X線之下已經是非常狀況了，要密切注意二度阻力的發展。

頭肩頂成交量，一般以左肩最多，有時頭部最多，右肩最少。跌破頸線後，有一暫時回升，回升至頸線附近就回頭。一旦頭肩頂完成，最少會跌頭部至頸線的高度那麼多（牛對數圖），叫最小測量（S），一般都會跌比 S 還多，一直到碰到一條下降 X 線，開始反彈。

頭肩頂會變形而形成複合頭肩頂（圖 15-2）。

# 頭肩頂的策略

（1）利用上升 X 線在左肩，或頭部最高點賣出。

（2）在右肩上升 X 線二度阻力處賣出。

（3）跌破頸線時，不限價賣出。
