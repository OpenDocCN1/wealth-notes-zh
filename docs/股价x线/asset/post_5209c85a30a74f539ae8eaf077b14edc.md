## 6-2 股價 X 線是斜的支撐和阻力——可靠、準確

從（圖 6-1）裡您可以簡單的理解，如何由水平的支撐和阻力，發展成斜的支撐和阻力，形成股價 X 線。

# 7 股價 X 線權威性試驗

股價 X 線的最大好處，是碰線即回跌或漲升。

但是，用以連成股價 X 線的頂點和底部，是否具有代表性，這兩點和碰線位置三點之間的關係，我們仍要加以討論，以免囫囵吞棗。

權威性試驗就是指這條股價 X 線有多大的權威，有多少的可靠性。和趨勢線一樣，股價 X 線也必須經過權威性試驗，以確認它的可靠性，進而執行買賣。

一條權威性股價 X 線，可以幫您賺到錢的，而不權威或錯誤的股價 X 線，可能會導致虧損，豈能不慎。

## 7-1 剪刀原理

剪刀是一種槓桿工具，槓桿構造有三點：

- 施力點 (A)：剪刀把手施力的地方
- 支撐點 (B)：螺絲固定處
- 受力點 (C)：剪刀刀口

剪刀有三類型：

- 中等的（一般用的，AB = BC），
- 省時的（如剪布的，AB < BC）。
- 省力的（如剪鐵皮，AB > BC），

這分類是和 ABC 三點位置有關。

假如，有三條不一樣的 股價 X 線，它們用以連線的 AB 兩點和碰線的 C 點之間的關係和三種剪刀相比擬，那麼可以分成三類 股價 X 線：

- 第一類 股價 X 線： AB 長度等於 BC （AB = BC）
- 第二類 股價 X 線： AB 長度小於 BC （AB < BC）
- 第三類 股價 X 線： AB 長度大於 BC （AB > BC）

它們權威性依次排列：

第一類 股價 X 線最好

第二類 股價 X 線次之

第三類 股價 X 線最差

雖然第一類比第二類權威，但是，第一、第二類股價 X 線都可以用來買賣股票。至於第三類只要 AB: BC 的比不要太大，例如 5:3 而已，仍然可用。如果比達到 5:1 就不好了，達到 10:1 是不能用的。

以上 AB 或 BC 至少有 12 天（週線圖上 12 週，月線圖上 12 月，圖上 12 根線就是）

所謂 AB=BC 並非一天不差，相近即可，剪刀原理分類舉例如表 (7-1)，讀者可以舉一反三。

## 7-2 二週原則

以上三類 股價 X 線中，AB 或 BC 的時間都要受二週原則的限制。

二週原則是 AB 或 BC 的時間至少 2 週。（12 根日線），週線圖上至少 12 週，月線圖上至少 12 月，圖上至少要 12 根線的意思，多一些更好。

二週原則，其實是用以保證基本點明顯而已。一個次級點如果前後不足 3 天（全部是 6 天），就不是一個明顯的基本點，是不能使用的。一個基本點要 6 天，連接股價 X 線的兩個點，當然需要 12 天了。以前 12 天剛好是 2 個交易週。因此，稱爲二週原則。現在改爲每周交易 5 天，仍然沿用二週原則。如果 AB 或 BC 都只有 10 天如何？只能用來考量附近的短期變動而已。

## 7-6 失效情形

股價 X 線也有極少數失效情形，這些不外：

- **A. 在多頭市場：**

    口訣：*超漲快跌回*
  - （2）多頭市場起步時，大漲若干天，碰到上升 X 線，奇怪的是，第二天只有小跌（譬如跌 3%），這種情形第三天會開始再大漲，多頭市場起步，其上漲潛力是很大的，這可以理解。
  - （3）基本點不明顯、不符合剪刀原理、二週原則，這種失效不能怪股價 X 線失效。
  - （4）未使用半對數紙。方格紙股票圖碰到股價 X 線時問不對。這是圖紙問題，非股價 X 線失效問題。

- **B. 在空頭市場：**
  - （1）碰到下降 X 線 2 天內沒有上漲，結果會在第 3 天或第 4 天，加速上漲，迅速回升到下降 X 線之上，也就是超出下降 X 線以下的部分屬於超跌，撐不了多久，漲回來還我們吧。

# 8 半對數圖紙和股價 X 線

半對數圖紙用於股價技術性分析，它的好處我們已經討論好幾次了。

## 8-1 等比例圖紙

圖上同樣垂直高度代表相同的百分比，打開半對數圖，上漲高度大的，上漲百分比也高。上漲高度幾公分相當於百分比多少也是固定的，使用一把尺就知道上漲百分比，不必計算機。

## 8-2 圖不會變形

半對數圖不會因股價暴漲或暴跌而變形，畫出的各種線準確好看。半對數圖上的趨勢線經常是一直線，這是很迷人的地方，它為何要成一直線呢？這使得股票變成可以預測。股票一跌破趨勢線就知道了，它代表趨勢的改變。

同樣的，股價 X 線在半對數圖上也是一直線，也可以預測。

方格紙上的股票圖，上漲時圖被拉長，上升 X 線會提早碰到；下跌時圖被壓扁，下降 X 線會晚幾天碰到，股價 X 線就沒有那麼準了。恐慌下跌幅度太大時，則碰不到下降 X 線。趨勢線也不能畫直的，變成彎曲的趨勢線。所以，如果您研究股票，一開始想走正確的路，使用半對數圖紙不可少。
