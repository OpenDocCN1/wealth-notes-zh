# 17-7 半增大型及蝸牛型整理

半增大整理型及蝸牛型出現在空頭市場第一、二部曲結束後大盤檔。半增大整理型和增大頂點比較，少了第三頂點，因此叫半增大整理型，整理時間約一個月。整理後繼續空頭市場下跌，有時還會恐慌下跌。

蝸牛型以形狀像蝸牛稱之，特色是最後上衝失敗，原因是空頭市場還未跌夠，多頭像蝸牛頭一碰就縮了。

圖 17-7 半增大型及蝸牛型整理。 兩者常常出現在空頭市場第一、第二階段反彈後的大整理（12章）。 半增大型比增大型少一個頂，一般人會誤以為 W 底已形成，然而在突破前一頂時，成交量不高，不久就往掉，會大跌一波段。

蝸牛型特色是整理到尾聲，突然往上衝，隨即快速下跌。
