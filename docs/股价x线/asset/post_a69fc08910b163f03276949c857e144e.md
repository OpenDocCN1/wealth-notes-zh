
## 13 趨勢線

股價沿直線趨勢前進，就像物理學上慣性定律，在沒有外力干預下，運動物體會沿一直線作等速運動。

任何人面對股票圖，大略看一眼就可以發現幾乎所有的短期變動，和大部分的中期趨勢，都是沿著直線移動，甚至那些長達數年的原始趨勢，也是好像用尺畫出那樣的直，這是股票圖最令人著迷，和印象深刻的現象。

趨勢線分上升趨勢線和下跌趨勢線。

### 13-1 上升趨勢線的畫法

上升趨勢線的畫法是：底連底。至少要有兩個底部相連，並延長之（圖 13-1）。

![](img/114f067fd2db153a6ed238c66e83de58_192_0.png)

圖 13-1 上升趨勢線畫法。底部 ABCD 相連 ($L_1$)，叫上升趨勢線。由 E 畫 $L_1$ 平行虛線 $L_2$，$L_2$ 叫上升平行線或返回線，兩線之間叫上升趨勢軌道。跌破要收盤價離上升趨勢線 3%。

上升趨勢線 $L_1$ 是由底 ABCD 連成。A、B 兩點就可以連，加上 C、D 更好。$L_2$ 是由第一頂點 E 畫 $L_1$ 的平行線，叫上升平行線或返回線。

上升趨勢線在圖上以紅色實線畫出，上升趨勢線的平行線，以紅色虛線畫出。$L_1$ $L_2$ 之間叫上升趨勢軌道。

正常的話，股價會在兩線之間來回。多頭第二部曲股價容易衝出紅色平行線（$L_2$），以便有足夠空間發展反轉。

任何一次，股價未能達到紅色平行線，是股價衰敗的前兆，必須提高警惕，如早先已經碰到上升 X 線，股價下跌已不可避免。

### 13-2 權威性試驗

一條上升趨勢線的權威性可用下面試驗鑑定：

- (1) 底部愈明顯愈好
- (2) 兩底部距離要適當，太近（少於一週）不好
- (3) 愈多底部相連愈好
- (4) 上升趨勢線愈長愈好
- (5) 上升趨勢線角度不要太陡，太陡時，很容易因一個橫向的小變動（如旗形）跌破。

陡只是一個相對名詞，同樣股票在不同的圖紙上表現有所不同，您必須固定在一種標準的半對數圖紙才能比較。

### 13-3 突破及暫時回升

一條權威的上升趨勢線建立後，當股價向下穿過此線，且收盤價離上升趨勢線有 3 %，叫決定性突破。

突破 3 % 可能一天完成，也可以分兩三天完成。突破時成交量甚大，更加強突破的有效性。

但是，向下突破時，即使成交量不大，一樣有效。

向上突破下跌趨勢線則一定要伴隨高成交量。

向下突破後幾天之內，股價會上升到接近上升趨勢線附近，叫暫時回升。暫時回升不一定發生，市場未恐慌時可能有暫時回升，一旦恐慌，就不會有暫時回升了。

### 13-4 上升趨勢線跌破後

一條權威的上升趨勢線，向下突破後告訴我們，這個上升趨勢已經結束，接下來的走勢可能：

- （1） 反轉
- （2） 中級回跌
- （3） 橫盤整理

![](img/114f067fd2db153a6ed238c66e83de58_195_0.png)

圖 13-2 跌破上升趨勢線。中華汽車跌破上升趨勢線後，有暫時回升，同時發展反轉。

以上如何決定？要看這個中級上升的位置。多頭市場第一部曲結束後，以中級回檔及橫盤爲多。多頭市場第二部曲結束，則會反轉。

週線圖上有上升 X 線碰到，也有可能反轉。

無論如何，股價跌破上升趨勢線，還是賣出觀望爲上策。其實，早在跌破上升趨勢線前，應該已經碰到上升 X 線矣，早該賣了。

### 13-5 下跌趨勢線的畫法

下跌趨勢線畫法是：頂點和頂點相連，並延長之。至少兩頂點相連，愈多頂點相連愈權威（圖 13-3）。

如（圖 13-3）ABCD 連成下跌趨勢線 $L_1$，用藍色實線畫出。由 E 畫 $L_1$ 的下降平行線 $L_2$，又叫藍色平行線或返回線，以藍色虛線畫出。

$L_1$ $L_2$ 之間叫下跌趨勢軌道。正常情形，股價在下跌趨勢軌道內行進。恐慌下跌時會向下脫離，中級反彈或即將轉入多頭市場時，會向上突破。

![](img/114f067fd2db153a6ed238c66e83de58_197_0.png)

下降趨勢線畫法是由頂 ABCD 相連（$L_1$），由 E 畫平行線虛線（返回線）$L_2$，兩線之間叫下降趨勢軌道。

任何向上有效突破，必須伴隨高成交量。

突破後常有暫時回跌，回跌至藍色趨勢線且獲的支撐，同時成交量減少，就是買進機會。

當然更早之前，您已经靠下降X線，在更低價買進了。這時下跌趨勢線只是用來確認趨勢發展過程而已。

### 13-6 下跌趨勢線的權威性試驗

和上升趨勢線相同，下跌趨勢線需要權威性試驗：

- （1）頂點愈明顯愈好。
- （2）愈多的頂點相連愈好。兩頂點間距離要適當。
- （3）頂點太近（小於一週）不好。
- （4）下跌趨勢線愈長愈好。
- （5）角度不要太陡。

### 13-7 下跌趨勢線的突破及暫時回跌

一條下跌趨勢線建立後，若股價以高成交量向上突破，且收盤價離下跌趨勢線有 3 % ，叫決定性突破。

如果以低成交量突破下跌趨勢線，或收盤價離下跌趨勢線不足 3 % ，或盤中突破，收盤未破，都要對下跌趨勢線突破有效性起疑，尤其是空頭市場第一、二階段，股價向上突破一條下跌趨勢線，不可以立即買進，這可能只是一個次級上升而已，上漲有限，隨時會跌，特別是下跌趨勢線較陡的那一種。

空頭市場末期，股價會碰到週線圖上的下降 X 線，或有三條下降 X 線交叉，那時就要買進。然後，隨著下跌趨勢線的突破，更加確認多頭趨勢。

上升 X 線或下降 X 線，總是比其他技術性信號出現早一些，而且可靠。

### 13-8 下跌趨勢線突破後

一條權威性的下跌趨勢線突破後，可能走勢是：

- （1） 反轉（空頭市場反轉成多頭市場）
- （2） 中級反彈
- （3） 橫盤整理

以上可以參考空頭市場三部曲，及下降 X 線，配合判斷那一種情形，比較有可能。

### 13-9 扇形線

空頭市場轉成多頭市場，往往是一條一條的下跌趨勢線逐次突破。這群成組的趨勢線叫扇形線，好像一把扇子的骨頭（圖 13-4）。

![](img/114f067fd2db153a6ed238c66e83de58_200_0.png)

圖 13-4 扇形線。三條下降趨勢線構成一組扇形線，當第三條扇形線向上突破，一個多頭市場就要開始。

在多頭市場第一部曲結束的整理過程，也會出現小規模扇形線。扇形線只是用來確認多頭走勢而已。買進是靠下降 X 線。

### 13-10 股價趨勢線和股價X線

任何情形，股價 X 線信號都比股價趨勢線早若干天，買賣股票主要是靠股價 X 線，股價趨勢線是用來確認往後的趨勢，以決定是要做長線，或是做短線。

如果您都是做短線，完全用股價 X 線就對了，股價趨勢線可以不必畫，這樣就可以把做股票簡單化了。

- 股價碰到下降 X 線，買進股票，適當獲利即賣出；
- 股價碰到上升 X 線，放空股票，適當獲利即補回。
- 上升 X 線和下降 X 線也適用於指數期貨。

## 14 支撐和阻力

### 14-1 支撐

在下跌或回檔的過程中，有足夠的買進，以阻止趨勢的下跌，叫做支撐。

支撐水準是在某一價位，有足夠的需求，阻止趨勢下跌，甚至反轉。

一個頂點，對下一次下跌是支撐（圖14-1）。

假定張三在 30 元賣出甲股票，甲股票隨即跌至 25 元，但是，張三未買回。不久甲股票漲至 35 元，張三後悔了，可是張三不願意追高價買回，當甲股票有一天跌至 30 元，張三願意買回，再度擁有甲股票。

![](img/114f067fd2db153a6ed238c66e83de58_203_0.png)

型態上線也是支撐，如頭肩底的頸線（A），雙重底（B）、三重底（C）、矩形（D）、上升三角形（E）、對稱三角形（F）的上線，都有某種支撐（圖 14-2）。

![](img/114f067fd2db153a6ed238c66e83de58_203_1.png)

### 14-2 下降 X 線是明確的支撐

股價下跌碰到下降 X 線會有支撐，不只支撐，還會在二天內上漲，第四章已經講的很清楚。讀者按照下降 X 線指示去操作，賺錢機會很大。

### 14-3 阻力

阻力是支撐的反面，股價在上漲過程中，有足夠數量賣出，以阻止股價上漲。

阻力水準是指在某一價位，會阻止股價上升，甚至引起反轉。

一個底部，對下一次上漲會形成阻力。

例如：李四在 40 元買進乙股票，不久漲到 45 元，李四自認決定正確，沾沾自喜。但是，一轉眼乙股票跌到 35 元，李四開始懷疑自己的判斷，並且有了損失，他想如果乙股票回到 40 元，夠本後就把它賣掉，因為乙股票沒有想像好。

所以 40 元底部，對下一次上漲，會形成阻力。

![](img/114f067fd2db153a6ed238c66e83de58_205_0.png)

### 14-4 阻力潛能估計

三個因素可以估計阻力潛能：

- 1. 成交量大小
- 2. 距離遠近
- 3. 時間長短

尖的的底部，或成交量大的底部，其阻力比平坦底部阻力大。那是因為型態拖長以後，在底部買進的人，一部分已經賣出了。而在一個 V 形底部買進的，因變動快速，來不及出脫而被套住，下一次漲至此處，阻力就大了。

下跌幅度大的，下一次上升到此，阻力也大，何故？因為大跌之後，原先買進的人，心急的想以一個較小的損失賣掉，同時，在底部買進的人，已經有獲利了也想賣。所以往往等不到前一個底部價位就回頭了。

跌破一個底部後，短時間就回來，阻力大。時間一旦拖久了，一些沒有耐心的人，漸漸的把股票賣了，下次回來，阻力就小了。

一個高成交量的中級底部所形成的阻力，會在一次又一次多頭的攻擊中，消耗它的力量。在第一次的攻擊中，大量的供給使多頭退下來，第二次的上升，那裡的供給就少了一些，第三次攻克的機會就很大了。

在估計阻力時，高估一點總是比較安全，您可能仍在看漲而太樂觀了，忽視阻力存在。您會想套牢的人，應該知道情況已好轉，再忍耐一些時日，可能會獲利。

您可能忘記，他們已套牢很久了，這種股票太令他們失望了，一旦夠本，或少虧一點，他們都願意賣出，而再去尋找其他目標。

### 14-5 上升 X 線是明確阻力

上升 X 線 是明確的阻力所在，而且會在 2 天內下跌，碰到上升 X 線時，就按照第三章去操作就對了。

### 14-6 支撐潛力的估計

支撐潛力的估計可以用阻力的方法爲之。

高成交量的頂點支撐較強，離前一頂點時間近的支撐強，離前一頂點漲幅大的支撐也強。

但是，要記住尋求支撐位置，比尋求阻力位置不容易，在那裡一定會有支撐，一般很不確定。

在台灣，股市一旦反轉成空頭市場，總是快速的、恐慌性的下跌，所謂前一頂點的支撐往往無招架之力。

此時，不要急著去找支撐，讓它跌夠了再說。

一條有權威的下降X線是重要支撐，在空頭市場第一階段結束時，可以指示買進。

### 14-7 下降X線是明確支撐

下降X線是明確的支撐位置，股價碰到下降X線，股價不只停止下跌，而且還會在二天內上漲。您按照第四章下降X線去操作就對了。

### 14-8 支撐失敗的意義

股價跌到前一個頂點，並不停止，反而下跌到前一底部或更低，這種變動叫支撐失敗，也就是前一頂點失去支撐，這是趨勢改變的警兆，在多頭第二部曲後，可能反轉。

在這之前，週線圖上一定有權威性上升X線碰到，日線圖上可能有三條上升X線碰到。

![](img/114f067fd2db153a6ed238c66e83de58_209_0.png)

圖 14-4 反轉之前支撐失敗現象。箭頭處代表支撐失敗，支撐失敗意味應有支撐而撐不住，這種情形要注意反轉發展。

### 14-9 整數支撐和阻力

某股票在整數關卡如 50 元、80 元或 100 元。指數在 6000 點、8000 點或一萬點有阻力或支撐現象，這純粹是心理因數，確也有人在此買賣股票，是找一個較好計算的價錢。但這種觀念不一定可靠，失誤情形很多，只要打開股票圖就知道了。

上升 X 線才是真正阻力；下降 X 線才是真正支撐。

### 14-10 支撐和阻力互換

支撐位置若被跌破，會變成下次上升的阻力。例如原來是支撐的頭肩頂頸線一旦跌破，暫時回升只到頸線為止，上升趨勢線原是支撐，一旦跌破，暫時回升的阻力便是此線。

同樣，阻力被突破，下次回跌至，便有支撐。例如，頭肩底的頸線突破後，下次下跌到頸線可望停止。下跌趨勢線突破後的回跌，也到此線為止。

上升 X 線和下降 X 線，沒有支撐阻力互換情形。

權威的上升 X 線，如果短暫向上穿過，反而會迅速回跌至上升 X 線之下。任何情形，上升 X 線沒有支撐作用。上升 X 線是阻力，不要誤會誤用。

下降 X 線如短暫向下穿過，會迅速回到下降 X 線的上方，彷彿前面的穿過是多餘的，像盲腸一樣。任何情形，下降 X 線沒有阻力作用。下降 X 線是支撐，不要誤會誤用才好。

### 14-11 錯誤觀念

一般常認為一個頂點是阻力；而一個底部是支撐。這種觀念不正確。

在多頭市場，股價穿越前一個頂點是很簡單的，前一頂點只有在反轉區才會屢次不能過去，造成麻煩。

同樣，在空頭市場，股價超越前一個底部，也是很簡單的，勢如破竹。前一個底部，只有在底部反轉區，才跌不下去，才有支撐的情形。

### 14-12 斜的支撐和阻力

- 股價X線

支撐和阻力大部分是水平，但是股價X線是斜的支撐和阻力。這一點在第六章已經談過。

### 15-2 頭肩頂反轉型態

最常出現、最可靠的頂點反轉型態是頭肩頂。

多頭市場第二部曲末尾，週線圖上有上升 X 線碰到時，在日線圖上就要注意頭肩頂反轉來臨。

在日線圖上，多頭市場第二部曲股價加速上升，碰到一條權威的上升 X 線後，忽然一個下跌，形成左肩。

緊接著一個上升，衝過左肩，但是，不久又跌落左肩之下形成頭。然後，一個軟弱上升（成交量少）達到左肩高度開始回頭，形成右肩。一旦回頭，跌破頸線，收盤價離頸線 3 % ，頭肩頂完成了，空頭市場來臨。

頭肩頂形成過程，有一連串警兆。左肩有上升 X 線碰到是第一警兆，跌破左肩支撐是第二警兆，右肩上升成交量很少是第三警兆，右肩停止在上升 X 線的二度阻力（圖 15-1）是第四警兆，跌破頸線已經是第五警兆。

![](img/114f067fd2db153a6ed238c66e83de58_217_0.png)

圖 15-1 頭肩頂和二度阻力關係。第一次碰到上升 X 線形成頭肩頂的左肩，二度阻力出現在右肩。從頭部回落至上升X線之下已經是非常狀況了，要密切注意二度阻力的發展。

頭肩頂成交量，一般以左肩最多，有時頭部最多，右肩最少。跌破頸線後，有一暫時回升，回升至頸線附近就回頭。一旦頭肩頂完成，最少會跌頭部至頸線的高度那麼多（牛對數圖），叫最小測量（S），一般都會跌比 S 還多，一直到碰到一條下降 X 線，開始反彈。

頭肩頂會變形而形成複合頭肩頂（圖 15-2）。

**頭肩頂的策略**

- （1）利用上升 X 線在左肩，或頭部最高點賣出。
- （2）在右肩上升 X 線二度阻力處賣出。
- （3）跌破頸線時，不限價賣出。

**非反轉的頭肩型態**

多頭市場第一部曲末尾，會形成類似頭肩頂的型態，那屬於非反轉型態的頭肩頂，假跌破頸線後碰到一條下降 X 線，會進入多頭市場第二部曲。

空頭市場第一部曲反彈後，也會成一個頭肩頂形狀。空頭市場第三部曲，由空頭市場將轉入多頭市場前的打底階段，也會出現頭肩頂形狀，那是不用擔心的，若碰到下降 X 線就可以買進了。
