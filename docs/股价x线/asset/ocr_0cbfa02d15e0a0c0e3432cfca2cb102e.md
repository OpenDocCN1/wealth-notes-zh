# 13-3  突破及暫時回升

一條權威的上升趨勢線建立後，當股價向下穿過此線，且收盤價離上升趨勢線有 3 %，叫決定性突破。

突破 3 % 可能一天完成，也可以分兩三天完成。突破時成交量甚大，更加強突破的有效性。

但是，向下突破時，即使成交量不大，一樣有效。

向上突破下跌趨勢線則一定要伴隨高成交量。

向下突破後幾天之內，股價會上升到接近上升趨勢線附近，叫暫時回升。暫時回升不一定發生，市場未恐慌時可能有暫時回升，一旦恐慌，就不會有暫時回升了。
