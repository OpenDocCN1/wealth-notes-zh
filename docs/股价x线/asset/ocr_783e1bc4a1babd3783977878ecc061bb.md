（3）在多頭市場或空頭市場不明時，無論如何，股價碰到上升 X 線，賣出股票總是沒錯。然後等待碰到下降 X 線時買回。

# 3-5 多條上升 X 線交叉於一點

一個砲兵營，不會把十幾門大砲，全部擺在一個地方，而是分散在各地的砲陣地中。但是，它們可以同時朝一個目標發射，命中目標於一點。

有的時候，遠近不同的兩條或兩條以上的上升 X 線，會交叉於一點，該點好似多門大砲標的（圖 3-5）。
