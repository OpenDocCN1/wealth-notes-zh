股價遇到上面 5 種上升 X 線 ，在大勢很強時，可能是反轉型態的左肩。但是，在大勢不強時，或者出現在落後補漲股時，可能是最高價了。

落後補漲股往往在抵達終點時，整個大勢已快要反轉完成了，因此落後補漲股，沒有時間在頂點多停留一些時間發展反轉。好比一群登山的人，落後登頂的人會遇到最先登頂的人，已經快要下山的情形，您爲了跟上隊伍，沒有多少時間停留在山頂了。

如果，您有落後補漲股，遇到上面 5 種上升 X 線，要快速賣出，脫離市場。

賣出股票後，股價若是沒有反轉，而是盤旋整理，三週之後，能確認出可能又有一段漲升（景氣循環的大多頭市場才有可能），才可以酌量買進，並作停止損失委託。這次反轉沒有成功是一種警告，下次反轉會真的。

不過，股價遇到上面 5 種上升 X 線後，再漲一段情形很少發生。有上面 5 種上升 X 線信號，最後都是反轉居多，要有心理準備。
