# 7-4 基本點要明顯

前面已經討論過，基本點愈明顯愈好。

不明顯的基本點不要勉強使用，但是，電腦圖經過放大或壓縮，改變了基本點的原始模樣。電腦圖放大時，不明顯的基本點會變明顯，造成誤判。電腦圖壓縮時，明顯的基本點卻看不出來，反而不知要畫股價 X 線。如此這般，擾亂了判斷。

還是自己用半對數圖紙畫一些圖，不足的再用電腦圖補充，比較實際。

# 7-5 其他試驗
