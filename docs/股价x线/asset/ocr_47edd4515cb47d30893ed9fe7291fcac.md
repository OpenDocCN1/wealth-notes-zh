# 4-8 B型下降X線

前面討論的下降 X 線,是頂和底相連的(至少間隔一個底和頂),它的方向是向右下方傾斜的,這種向右下方傾斜的下降 X 線,叫正統下降 X 線。

依支撐和阻力演變的理論(119頁),有一種下降 X 線所使用的頂與底中,頂比底還低,好像中央山脈中的一個山頭比某一河谷低。這種下降 X 線畫出來方向是,向右上方傾斜的(圖 4-9)。

圖 4-8 B型下降 X線。 底 B 比頂 A 高,造成下降 X 線不向右下方傾斜,反而向右上方傾斜,這種下降 X 線叫 B 型下降 X 線。B 型下降 X 線效用和下降 X 線相同。
