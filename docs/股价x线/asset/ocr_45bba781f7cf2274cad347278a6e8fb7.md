# ## 4-2 下降 X 線的畫法

下降 X 線是一條直線，幾何學說兩點可畫一直線。要畫出下降 X 線，首先需要兩個點：一個是頂點，一個是底部。頂點和底部在股票圖上類似波峰和波谷，是連接各種線的基本點，本書第 20 章有討論。

要先確認頂點和底部，才能畫出下降 X 線。

下降 X 線的畫法是：頂 連 底

+   （1） 一個頂點跳過一個底部和頂點，和右下方另一個底部，以直線相連接，並延長一倍（圖 4-1）。

圖 4-1 下降 X 線畫法。 頂 A 跳過底 D 和頂 E，與底 B 相連。

口訣：頂連底（至少間隔一個底和頂）。A 連 B 要延長一倍。
