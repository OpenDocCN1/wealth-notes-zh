在多頭市場，碰到上升 X 線會跌多少？依股票的敏感度（一年中，各股票在半對數圖紙上變動的垂直高度作比較），碰線前的上升幅度，成交量高低及多頭市場初期還是末期而定。

假定股票敏感度高（股票較投機的意思），碰線前上升幅度很大（譬如 100 %）及一天成交量很高（譬如小型股達到該股票總發行量的 5～10 %），多頭市場已到末期（上漲已 3～6 個月了），則回檔在 15 % 左右，同時一個反轉已經悄悄地發展中，要密切注意。

至於多頭市場的早期至中期，碰到上升 X 線會回跌 5～10 % 。一些低敏感度及上漲不多者，當然，回跌會少一些。

股價碰到上升 X 線，不管回跌多少，總是會回跌的，可靠性 99 %，極少錯誤。

這是買賣股票非常精準的一條直線，或許可戲稱是世間最值錢的直線 吧！
