# 18-3 普通缺口

普通缺口出现在一個交易區域中，或價格密集型態中，例如三角形或矩形。這些型態中的交易集中在上線和下線，中間區域交易較少，甚至沒有交易，於是形成區域性缺口叫普通缺口。

普通缺口出現在整理型態比較多，在反轉型態中較少。因此，在發展中的三角形或矩形，有許多缺口出現，就可預期這是整理型態，而非反轉型態。

# 18-4 突破缺口

突破缺口出現在一個整理型態、反轉型態或一條趨勢線的突破。例如，突破上升三角形及矩形的上線，或頭肩底的頸線，或一條趨勢線時，經常伴隨有突破缺口。

股價以突破缺口向上脫離形態，表示這種股票比沒有缺口者顯得有活力，買方力量較強，突破是真正的，您應優先考慮這種股票。
