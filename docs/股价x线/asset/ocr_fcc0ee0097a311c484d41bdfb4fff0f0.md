# 圓形底反轉

圓形底和 V 形底相反，股價在底部慢慢反轉，發生在冷門股和小型股，您可能對這檔股票，注意有一段時間了，如何確認它是圓形反轉呢？大概只有從右側上升時，伴隨有高成交量，去發現它。

# 對稱三角形和上升三角形

對稱三角形一般出現在整理型態，它出現在多頭市場，或空頭市場中途的整理型態，比較少出現在反轉型態。但是，股票圖形並非全是科學，對稱三角形反轉型態也不是不可能，有時也因爲個人畫圖和判讀不一樣，解讀爲對稱三角形，其實是別的型態。
