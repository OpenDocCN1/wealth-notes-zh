# 10-3 真理恆久不變

一個人是否擔心作手會耍新花樣，而讓 股價 X 線 失其效用。

這是不可能的，就像許多人都知道頭肩頂反轉，卻 仍然有人套牢一樣。

作技術性分析的投資人在股市中畢竟還是佔少數，而成功的技術性操作專家更少。

不是投資大眾影響股價 X 線，而是他們造成供需， 造成股價 X 線，即使很多人知道股價 X 線，也只會加 強股價 X 線的作用，而不致讓它失效。

真理恆久不變，自從 1929 年到今天，有圖可證的 國內外股票市場，尚未見到股價 X 線有嚴重失效情形。

股價 X 線 使用於股票市場或期貨市場，作者是非常 有信心的。

讀者學好 股價 X 線，就可以縱橫於股票市場。
