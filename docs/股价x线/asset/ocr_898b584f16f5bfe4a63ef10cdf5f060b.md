# 4-4 下降 X 線如何使用

下降 X 線的使用，因多頭市場或空頭市場而不同。

（1） 在多頭市場，下降 X 線（通常是 B 型下降 X 線）是回檔的最低價。 碰線當天或第二天，股價便開始上升，而且會上升很多。

+   ☉ 假定您是空頭，應在碰線當天補空並翻多，切勿再觀望，最差操作者會在此放空，立即被軋空。

+   ☉ 假定您是多頭，在碰線當天加碼買進，並在買進價下方 10 %，作停止損失委託即可。

+   ☉ 空手的人，可以在此時買進，順利上轎。

（2） 在空頭市場，股價碰到下降 X 線，會在當天或第二天反彈，通常反彈 5～20 %

反彈幅度依敏感度及下跌幅度而定。

+   ☉ 假定您是空頭，應在碰線當天或第二天回補一些，反彈上升後再放空。

+   ☉ 假定您是多頭，在碰線當天或第二天，酌量買進一些（不可全力買進），並於反彈稍有獲利時即
