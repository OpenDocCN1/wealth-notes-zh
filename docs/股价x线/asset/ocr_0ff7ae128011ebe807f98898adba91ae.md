# 4-5 多條下降 X 線交叉於一點

和上升 X 線一樣，有時多條下降 X 線會交叉於一點。一條下降 X 線是一種支撐，股價碰到會上升。兩條下降 X 線交叉，支撐力量更大，回升更厲害。

不可否認，三條下降 X 線會產生極強烈的上升。
