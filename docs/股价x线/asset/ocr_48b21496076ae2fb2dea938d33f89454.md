# ### 17-3 楔 形

楔形有上升楔形和下降楔形。

多頭市場有下降楔形整理；空頭市場則有上升楔形整理。楔是尖形木片，用以擠入細縫撐緊。

下降楔形是向右下方傾斜的尖而細的三角形，整理時間約一月，整理完後繼續上漲。它出現在多頭市場第一部曲結束的大盤檔。

上升楔形是向右上方傾斜的尖而細的三角形，整理時間約一月，整理完後繼續下跌。它出現在空頭市場第二部曲結束的大盤檔。
