以上如何決定？要看這個中級上升的位置。多頭市場第一部曲結束後，以中級回檔及橫盤爲多。多頭市場第二部曲結束，則會反轉。

週線圖上有上升 X 線碰到，也有可能反轉。

無論如何，股價跌破上升趨勢線，還是賣出觀望爲上策。其實，早在跌破上升趨勢線前，應該已經碰到上升 X 線矣，早該賣了。

# 13-5 下跌趨勢線的畫法

下跌趨勢線畫法是：頂點和頂點相連，並延長之。至少兩頂點相連，愈多頂點相連愈權威（圖 13-3）。

如（圖 13-3）ABCD 連成下跌趨勢線 L₁，用藍色實線畫出。由 E 畫 L₁ 的下降平行線 L₂，又叫藍色平行線或返回線，以藍色虛線畫出。

L₁ L₂ 之間叫下跌趨勢軌道。正常情形，股價在下跌趨勢軌道內行進。恐慌下跌時會向下脫離，中級反彈或即將轉入多頭市場時，會向上突破。
