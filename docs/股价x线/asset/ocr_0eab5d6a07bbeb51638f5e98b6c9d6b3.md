正常的話，股價會在兩線之間來回。多頭第二部曲股價容易衝出紅色平行線（L₂），以便有足夠空間發展反轉。

任何一次，股價未能達到紅色平行線，是股價衰敗的前兆，必須提高警惕，如早先已經碰到上升 X 線，股價下跌已不可避免。

# 3-2 權威性試驗

一條上升趨勢線的權威性可用下面試驗鑑定：

+   (1) 底部愈明顯愈好
(2) 兩底部距離要適當，太近（少於一週）不好
(3) 愈多底部相連愈好
(4) 上升趨勢線愈長愈好
(5) 上升趨勢線角度不要太陡，太陡時，很容易因一個橫向的小變動（如旗形）跌破。

陡只是一個相對名詞，同樣股票在不同的圖紙上表現有所不同，您必須固定在一種標準的半對數圖紙才能比較。
