# 上升特色

+   (1) 上漲速度和第一部曲差不多，有時更快。

+   (2) 每上升 7～10 天會有次級回跌，回跌以旗形或細長三角形爲多。

+   (3) 整個第二部曲常有三個次級上升。

+   (4) 上漲途中隨便賣出股票，要高價才能補回。

+   (5) 空頭愈拋空，行情愈漲，直到空頭死心，並在高價，不計一切補回爲止。

# 尾聲

+   (1) 週線圖上有上升 X 線碰到。

+   (2) 日線圖上有三條上升 X 線碰到。

+   (3) 發生二次、三次阻力或二度阻力。

+   (4) 漲幅已和第一部曲差不多。

+   (5) 完成三個次級上升，竭盡缺口（跳空）出現。

+   (6) 出現新頂點時，成交量反而減少。

+   (7) 跌破一條權威的上升趨勢線。

+   (8) 跌破前一個次級頂點支撐（即支撐失敗）。
