# ### 是否有第三、第四部曲？

多頭市場是否有第三、第四部曲呢？不能期待每次皆有。但是，假如在第二部曲之後，反轉沒有來臨，只是不斷盤旋，當技術性情況，或客觀環境的確對多頭有利時，再考慮買進，並做下停止損失委託即可。

# ### 12-6 空頭市場

股價下跌一波比一波低，好像落潮。股價跌多漲少，下跌幅度至少 30 % ，下跌時間至少三個月，主要趨勢是下跌的市場叫空頭市場。

空頭市場主要趨勢可以分成三個階段：出貨期、恐慌期及斷頭期。

# ### 出 貨 期
