# 7-1 剪刀原理

剪刀是一種槓桿工具，槓桿構造有三點：

+   施力點 (A)：剪刀把手施力的地方

+   支撐點 (B)：螺絲固定處

+   受力點 (C)：剪刀刀口

剪刀有三類型：

+   中等的（一般用的，AB = BC），

+   省時的（如剪布的，AB < BC）。

+   省力的（如剪鐵皮，AB > BC），

這分類是和 ABC 三點位置有關。

假如，有三條不一樣的 股價 X 線，它們用以連線的 AB 兩點和碰線的 C 點之間的關係和三種剪刀相比擬，那麼可以分成三類 股價 X 線：

+   第一類 股價 X 線： AB 長度等於 BC （AB = BC）

+   第二類 股價 X 線： AB 長度小於 BC （AB < BC）

+   第三類 股價 X 線： AB 長度大於 BC （AB > BC）
