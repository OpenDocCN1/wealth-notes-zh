# 5-7 時間問題

毫無疑問的，支撐和阻力現象會隨著時間而模糊。

股價 X 線是支撐和阻力的演變。因此，股價 X 線的效果是受時間影響的。說明如下：

+   日線圖上，由次級點連成的股價 X 線，大約在半年內有效。

+   日線圖上，由中級點和比較明顯的次級點連成的股價 X 線，大約在一年內有效。

+   日線圖上，由原始點和原始點連成的股價 X 線（在週線圖上已經同時出現），大約在 5 年有效。

+   週線圖上的股價 X 線，大約在 5 年左右有效。

+   月線圖上的股價 X 線，在 10 年左右有效。

隨著時間的遷移，新的股價 X 線不斷產生。除非是由中級點所連成的股價 X 線，可延續若干年。一些次級點所連成的股價 X 線，將逐漸失去效用。
