頭肩底型態出現在空頭市場底部，由下跌轉爲上升的過程中。

在空頭市場底部附近，股價快速下跌，碰到一條權威的下降 X 線，反彈大約有 10～15 % 左右，產生一個左肩。

另一下跌，股價跌到比上一個底部還低的地方，跟著一個較大的回升。衝過左肩底部，達到上一次反彈高點，成交量增加，比左肩多，這是頭。

第三個下跌，成交量減少。跌到左肩底部位置，在這裡可能碰到上次那條下降 X 線的二度支撐，停止了。

接著，一個成交量大增的上漲穿過頸線，收盤離頸線有 3 % ，且成交量特別大，突破確認，頭肩底完成。
