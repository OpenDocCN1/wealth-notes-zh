量。成交量較少的突破，有一半機會跌回來封閉缺口。成交量很大的突破，回跌時只到缺口邊緣就會停止。
有些突破缺口發生在當天交易時間內，而日線圖無法顯示出來，如果這是您有興趣的股票，可以在網路上查閱個別成交紀錄，或看分時走勢線。

# ### 18-5 繼續缺口

繼續缺口又叫逃逸缺口，顧名思義，出現繼續缺口時，趨勢會繼續下去，莫非這種缺口有測量意義？
繼續缺口出現時，股價能再走的距離，和已走的距離一樣，在半對數紙上兩段的高度一樣。
有時，繼續缺口會出現兩三個，哪一個是中間，可以用來測量？您可以試著去平均它們的中點。但是，每個接連發生的缺口，將步步逼近上漲的終點，若有上升 X 線接近，上漲的終點真的快到了。不要陶醉於後面出現的缺口，您對於第二、第三個缺口不要抱太大希望，隨時準備在碰到上升 X 線時脫手。
