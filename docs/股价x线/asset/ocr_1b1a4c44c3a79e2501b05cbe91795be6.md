# ## 18-6 竭盡缺口

再熱鬧的事也有結束的時候。

多頭市場最後階段的跳空，開盤就漲停板，非常振奮人心。但是，有一種缺口代表終點已到。該下車了，那就是竭盡缺口。

竭盡缺口伴隨快速變動，及高成交量而來，多頭和空頭竭盡所能產生最後一個缺口，也是空頭不計一切補回的時候，此後變動會減緩，甚至在買氣完全消失時，會在反方向產生突破缺口，連續跳空下跌。

當繼續缺口的測量已到達，上升 X 線橫在股價上，開盤就是賣股票的時候，有時漲停板可以撐到收盤前一刻，成交量則異常的大，但是，漲停板在臨收盤前打開了，收不了漲停板，第二天開盤就會跌停板，您回想一下，每個多頭市場，一些股票是不是這樣結束的。
