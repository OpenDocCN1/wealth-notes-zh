# ## 20-3 半對數紙圖紙優點

半對數圖紙優點如下：

+   1. 圖上相等的垂直長度代表相等變動百分比。
不管任何股票任何價位，只要變動百分比一樣，它的長度就一樣，不會上漲拉長，下跌壓扁，及不同股票變動不一致的毛病。

+   2. 股票圖在任何價位均不變形。所以，趨勢線和股價X線最準確。

+   3. 半對數圖紙上的上升趨勢線，突破較早，可以比方個紙早一點發現。

+   4. 半對數紙股票圖的趨勢線，是大約與水平成30 ~ 50 度角度的直線，是適當的趨勢線角度。

+   5. 各公司的股票圖，都是基於同一比例。因此，您可以很容易從每一種股票圖上升的長度，去比較上漲幅度，並據以計算各股票的敏感度。
