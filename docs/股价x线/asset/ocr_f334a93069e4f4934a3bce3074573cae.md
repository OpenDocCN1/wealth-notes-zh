趨勢線突破有效性起疑，尤其是空頭市場第一、二階段，股價向上突破一條下跌趨勢線，不可以立即買進，這可能只是一個次級上升而已，上漲有限，隨時會跌，特別是下跌趨勢線較陡的那一種。

空頭市場末期，股價會碰到週線圖上的下降 X 線，或有三條下降 X 線交叉，那時就要買進。然後，隨著下跌趨勢線的突破，更加確認多頭趨勢。

上升 X 線或下降 X 線，總是比其他技術性信號出現早一些，而且可靠。

# 13-8 下跌趨勢線突破後

一條權威性的下跌趨勢線突破後，可能走勢是：

+   （1） 反轉（空頭市場反轉成多頭市場）
（2） 中級反彈
（3） 橫盤整理

以上可以參考空頭市場三部曲，及下降 X 線，配合判斷那一種情形，比較有可能。
