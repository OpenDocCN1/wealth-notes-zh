# 20-12 股票圖上還要什麼

股票圖上還要有什麼？股票圖上空白的地方，可以註明公司每月營業額，每季財務報告，歲後盈餘及股利分配等（網路也有），以及政治、經濟與國際大事。

最重要的是，圖上註明您對股價的分析的事後印證，及實際操作買賣的心得。碰到股價 X 線時，沒作的股票，可以沙盤推演印證。您的功力會迅速提升。
