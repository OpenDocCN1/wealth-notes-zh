# 14-6 支撐潛力的估計

支撐潛力的估計可以用阻力的方法爲之。

高成交量的頂點支撐較強，離前一頂點時間近的支撐強，離前一頂點漲幅大的支撐也強。

但是，要記住尋求支撐位置，比尋求阻力位置不容易，在那裡一定會有支撐，一般很不確定。

在台灣，股市一旦反轉成空頭市場，總是快速的、恐慌性的下跌，所謂前一頂點的支撐往往無招架之力。
