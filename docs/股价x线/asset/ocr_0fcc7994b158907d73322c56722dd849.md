# 尾聲

+   （1）高敏感度的股票，下跌已有 50 % （從第三部曲算起）。

+   （2）下跌幅度和第一二部曲差不多。

+   （3）中間已經過一個次級反彈（煞車）。

+   （4）遇線圖上有下降 X 線碰到。

+   （5）日線圖上有三條下降 X 線碰到。

+   （6）下降 X 線有二次支撐、三次支撐、二度支撐。

+   （7）市場利空消息頻傳，散戶空手多，成交量奇少。

+   （8）業績好的股票，已有轉穩趨勢，投機股仍然大跌。

# 空頭市場第三部曲操作

+   （1）下跌之初，不可買進，若有股票要賣出。

+   （2）尾聲時，試圖利用下降 X 線買進。

+   （3）下跌多，成交量少的股票，一旦進入多頭市場則上漲快。

+   （4）注意底部發展過程，做好進入多頭市場的準備。
