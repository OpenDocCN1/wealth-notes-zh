# ## 3-4 上升 X 線如何使用

上升 X 線的使用，因空頭市場或多頭市場而稍有不同，詳細說明如下：

+   1. 在空頭市場，上升 X 線是反彈的極限。

通常在碰線當天便會下跌，而且會下跌甚多，空頭市場本來就很容易下跌的。

+   ◎ 假定您是搶反彈的多頭，應在碰線當天出貨，出貨後不必急忙補回。

+   ◎ 假定您是空頭，在碰線當天或第二天加碼放空，同時在賣出價上面 10 % 地方作停止損失委託，此後靜觀股價下跌即可。(停止損失委託請看第 19 章)

+   ◎ 如果您是空手者，切勿在碰到上升 X 線時買進，任何時候碰到上升 X 線，都不要買進。應另尋求時機，譬如碰到下降 X 線時（下一章討論）。

+   2. 在多頭市場，股價碰到上升 X 線，會在當天或第二天回跌，通常回跌 5~10 % 左右。
