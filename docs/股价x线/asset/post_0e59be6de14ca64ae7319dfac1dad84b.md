
## 1 股價X線
### 如何發現

#### 1-1 技術性操作受限制

美國股市權威 John Magee 所倡導的股價技術性分析，即各種股票圖上的反轉型態、整理型態、趨勢線、缺口、支撐、阻力及成交量信號，雖然穩當可靠，不可或缺。但是，仍有缺點，它們的缺點是：

- （1） 不能在一個變動的highest點賣出，或最低點買進。
- （2） 不能非常明確指出，股價上漲在那裡會遭遇阻力；而在下跌途中，在何處會有支撐。

例如，在多頭市場末期，當您發現頭肩頂，或雙重頂已經發展完成，並有決定性的往下突破，再賣出股票，股價可能已經下跌 20%了，大大減少獲利。

我們的目標，是在頭部的最高點賣出。有些時候，可以由竭盡缺口、高成交量及一天反轉中，大略預測出來。不過，也有的時候，三個信號一個都未出現，股價便由頭部反轉了。

同樣的，在一個空頭市場的底部，當您發現多頭市場已經開始，股價可能已經上漲超過 20%了，怎麼不早一點買進呢？

還有，當股價上漲超越前一頂點，或當股價破底時，往往不知股價在那裡會停止。甚至在危險區域買進股票，這種事屢見不鮮。

如果發明一種新的直線，配合傳統技術性信號，能夠克服前述缺點，我們買賣股票當更完美，操作效率更高，並且可以避免風險。

可是，這種新的直線，如何發明呢？

由誰來發明呢？

#### 1-2 努力尋找

假如，有一條簡單的直線，不須經過很多麻煩，在原來股票圖上就可以直接畫出。

股價上漲時，碰到這一條直線必定向下跌；股價下跌時碰到這一條線必定上漲，時間不會超過第二天，我們便可以明確的在碰到這一條直線當天，或第二天採取行動，獲取最大利益。

這是作股票的人，夢寐以求的最高境界！

我把這條直線叫 股價 X 線。

為了能夠尋找到一條準確而理想的 股價 X 線，筆者花了四年時間，在本國 1972 年以來的 600 張標準半對數股票圖上，進行研究及分析，並把國外自 1929 年以來的半對數股票圖，拿來驗證，不眠不休，夙夜匪懈。

結果，在 1978 年發明了 股價 X 線。

股價上漲，碰到 上升 X 線 就下跌；

股價下跌，碰到 下降 X 線 就上漲。

時間不會超過第二天，而且有 99 % 的準確性。

#### 1-3 簡單、精確、有威力

股價 X 線是那種的簡單、精確、有威力，任何人經過學習，都會使用。

如果，在你原有的股票圖上，或是電腦圖上（縱座標是半對數刻度），畫上 股價 X 線。那麼，股票技術性操作更加完美了，在證券市場賺錢的機會大大增加。

#### 1-4 如何命名

股價X線 命名的理由有二：

- (1) 股價X線具有神秘的力量，能精確透視股價反轉位置，彷彿X光可以透視肉眼所看不到的地方。

## 2 股價X線的區分

### 2-1 有上升必有下降

股票市場有多頭趨勢；必有空頭趨勢。有上升三角形、上升楔形、上升趨勢線，就有下降三角形、下降楔形、下降趨勢線。除了成交量不太一樣外，上升或下降的觀念都可以倒轉過來。

### 2-2 上升X線及下降X線

股價X線 分爲上升股價X線和下降股價X線。

爲了簡單起見，簡稱 上升X線 和 下降X線。以後本書中均以上升X線和下降X線稱之。

### 上升 X 線

由一個底部，至少間隔一個頂和底，和右上方的另一個頂點，以直線相連接，這一條直線叫 上升 X 線。

上升 X 線向右上方傾斜。

股價下一次上漲，如果碰到上升 X 線，會在當天或第二天下跌。

### 下降 X 線

由一個頂點，至少間隔一個底和頂，和右下方的另一個底部，以直線相連接，這一條直線叫 下降 X 線。

下降 X 線向右下方傾斜。

股價下一次下跌，如果碰到下降 X 線，會在當天或第二天上漲。

如果，這樣的定義，您一時不甚明瞭，請繼續看完下面數章，便會豁然開朗。

## 3 上升X線

前面一章，我們談到上升X線，及下降X線的定义。本章要把有關上升X線的問題說清楚。

### 3-1 半對數圖紙

在台灣，以往大部分的技術性分析者，都使用方格紙，對於股價X線，最好的圖紙卻是半對數圖紙。近年來財訊日報及部分電腦軟體，使用了半對數刻度。半對數圖紙有何特色，第 20 章會說得更清楚。

如果，您是用方格紙，只要價格訂得不是很寬鬆，且股價上下變動百分比也不大（譬如說 20 % 內），方格紙仍然適合畫股價 X 線。

本書圖例，大部分都採用半對數圖，此刻先要知道的是：股價 X 線 是以半對數圖紙的股票圖作爲基礎，不論上升 X 線或下降 X 線皆然。

### 3-2 上升X線的畫法

上升 X 線是一條直線，幾何學說兩點可畫一直線。要畫出上升 X 線，首先需要確認兩個點：一個是底部，一個是頂點。底部和頂點在股票圖上類似波谷和波峰，是連接各種線的基本點，基本點第 20 章有討論。

上升 X 線的畫法是：底連頂

- （1） 一個底部跳過一個頂點和底部，和右上方的另一個頂點，以直線相連接（圖 3-1）。
- （2） 一個底部跳過數個頂點和底部（或叫翻山越谷），和右上方的另一個頂點，以直線相連接，但是，交叉點要單純，否則無效（圖 3-2）。

![](img/114f067fd2db153a6ed238c66e83de58_15_0.png)

圖3-1 上升X線畫法。上升X線畫法是底連頂（至少跳過一個頂和底）。口訣：底連頂，底A跳過頂D與底E和頂B連。

![](img/114f067fd2db153a6ed238c66e83de58_15_1.png)

圖3-2 上升X線翻山越谷畫法。底連頂，但是，可以跳過數個頂和底，交叉要單純。底連頂畫出的上升X線要延長一倍。

簡單的講，上升 X 線是底連頂，不過，底和頂之間至少要間隔一個（也可以很多個）頂和底。

上升 X 線 與 股價趨勢交叉畫出，但是，交叉點要單純，交叉點複雜無效。

股票圖上，股價 X 線 以紅藍相間的線畫出，先用紅筆貫穿全線，再點上若干藍色短線即可，以區別用紅筆畫的上升趨勢線。本書則以折線( 一一· 一一·→ ) 畫出上升 X 線，一種紅藍兩用原子筆很適用。

第 5 章我們還要討論畫股價 X 線的細節，您在此畫 上升 X 線碰到困難時，可以先看第 5 章。

### 3-3 上升 X 線的作用

—— 2 天內回跌

一條上升 X 線畫出以後，下一次股價若上漲，碰到 上升 X 線，股價會在當天或第二天下跌（圖 3-3）。

這是 上升 X 線 最大的特色。

![](img/114f067fd2db153a6ed238c66e83de58_17_0.png)

但是，這並不是說上升 X 線畫好在那裡，股價就一定會漲去碰，一條很陡的上升 X 線，股價也許永遠碰不到。碰不到的 X 線，暫時畫在那裡，也沒有什麼損失。

一般做法是股價已經上漲一些了，才開始畫上升 X 線，由 B 型上升 X 線（後面介紹）開始畫，依次是有機會先碰到的先畫，或按照比較水平的，仰角小的，仰角中的，仰角大一點的去畫（圖 3-4）。

![](img/114f067fd2db153a6ed238c66e83de58_18_0.png)

在空頭市場，股價只要碰到上升 X 線（通常是 B 型上升 X 線），便會在當天下跌，繼續空頭市場走勢，下跌當然很多，甚至跌到空頭市場終點為止。

在多頭市場，股價上漲碰到上升 X 線，會在當天或第二天回跌，當天或第二天回跌的機會各一半，完全視當時整個市場大勢而定。假定您的股票上漲已經碰到上升 X 線了，可是當天大勢不好，則當天便會下跌，若是當天大勢很強，可能在第二天才會下跌。

在多頭市場，碰到上升 X 線會跌多少？依股票的敏感度（一年中，各股票在半對數圖紙上變動的垂直高度作比較），碰線前的上升幅度，成交量高低及多頭市場初期還是末期而定。

假定股票敏感度高（股票較投機的意思），碰線前上升幅度很大（譬如 100 %）及一天成交量很高（譬如小型股達到該股票總發行量的 5～10 %），多頭市場已到末期（上漲已 3～6 個月了），則回檔在 15 % 左右，同時一個反轉已經悄悄地發展中，要密切注意。

至於多頭市場的早期至中期，碰到上升 X 線會回跌 5～10 % 。一些低敏感度及上漲不多者，當然，回跌會少一些。

股價碰到上升 X 線，不管回跌多少，總是會回跌的，可靠性 99 %，極少錯誤。

這是買賣股票非常精準的一條直線，或許可戲稱是世間最值錢的直線 吧！

少數股票碰到上升 X 線，回跌較少或不回跌者，我們在第 7 章討論。

### 3-4 上升 X 線如何使用

上升 X 線的使用，因空頭市場或多頭市場而稍有不同，詳細說明如下：

- 1. 在空頭市場，上升 X 線是反彈的極限。
  
  通常在碰線當天便會下跌，而且會下跌甚多，空頭市場本來就很容易下跌的。

  - 假定您是搶反彈的多頭，應在碰線當天出貨，出貨後不必急忙補回。
  - 假定您是空頭，在碰線當天或第二天加碼放空，同時在賣出價上面 10 % 地方作停止損失委託，此後靜觀股價下跌即可。(停止損失委託請看第 19 章)
  - 如果您是空手者，切勿在碰到上升 X 線時買進，任何時候碰到上升 X 線，都不要買進。應另尋求時機，譬如碰到下降 X 線時（下一章討論）。

- 2. 在多頭市場，股價碰到上升 X 線，會在當天或第二天回跌，通常回跌 5~10 % 左右。

（3）在多頭市場或空頭市場不明時，無論如何，股價碰到上升 X 線，賣出股票總是沒錯。然後等待碰到下降 X 線時買回。

### 3-5 多條上升 X 線交叉於一點

一個砲兵營，不會把十幾門大砲，全部擺在一個地方，而是分散在各地的砲陣地中。但是，它們可以同時朝一個目標發射，命中目標於一點。

有的時候，遠近不同的兩條或兩條以上的上升 X 線，會交叉於一點，該點好似多門大砲標的（圖 3-5）。

一條上升 X 線，本來就是一種阻力，股價碰到會回跌。兩條上升 X 線交叉，阻力更大了，股價碰到交叉點，回跌劇烈。若有三條上升 X 線交叉，股價碰到交叉點，回跌非常嚴重，並有反轉的可能，再詳述如下：

（1）多頭市場第一階段，有三條上升 X 線交叉，會產生大回檔。整理很久（一個月以上）後，有可能再上漲一段。

（2）多頭市場第二階段後，有三條上升X線交叉，會反轉進入空頭市場，進行長時間下跌。

![](img/114f067fd2db153a6ed238c66e83de58_22_0.png)

圖3-5 多條上升X線交叉。好像多門大炮朝一個目標發射。

下個結論：股價碰到愈多條上升X線，愈麻煩，下跌更多，更久，並有反轉可能。

股價碰到三條或三條以上的上升X線交叉，必須先視為一個反轉型態在形成中，千萬千萬不可大意！一定要掛記在心。

若有四條、五條甚至六條上升X線交叉，麻煩之大，可以想見，幾乎是反轉定了。多條上升 X 線交叉是賣股票或放空的好機會，這種事一年中有一、兩次。

### 3-6 上升 X 線二次阻力和三次阻力

股價一路上升，碰到一條已經建立的上升 X 線，會產生回跌。回跌後股價可能鼓足勇氣往上挺升，再次碰到原來那條上升 X 線（冤家路窄），這一回股價很可能衝過去，也很可能再次跌下來。

假如，股價第二次碰到原來那條上升 X 線，仍然回跌，我們叫它 二次阻力。而股價第三次碰到原來那條上升 X 線，仍然回跌，我們叫它 三次阻力（圖 3-6）。

並不是每一條上升 X 線都會產生二次阻力，二次阻力能否產生取決於：

（1） 股價在碰到上升 X 線前，是否已經上漲一大段了，是否已經完成各種上升型態，如頭肩底、雙重底的最小測量（252 頁）。

![](img/114f067fd2db153a6ed238c66e83de58_24_0.png)

圖 3-6 上升X線的二次阻力和三次阻力。股價第一次碰到上升X線回跌，上漲後碰到原來那條上升X線，再次回跌叫二次阻力，若第三次又回跌叫三次阻力。凡事不為三，多頭市場未期發生三次阻力，要注意反轉型態在醞釀中。

（2）股票市場潛力大小。假定，股價在碰到上升X線的時候，才剛剛脫離一個如頭肩底，或雙重底等強烈多頭信號，第一次碰到上升X線會回跌，回跌5~10%之後，立即快速上漲，輕易穿過原來那條上升X線，則二次阻力並未發生。

假如，股價在碰到上升X線前，已經有大量上漲，並且根據測量公式，頭肩底或雙重底的最小測量已經完成，整個市場也顯示上升趨勢快要告一段落，那麼，上升X線會產生二次阻力，也有可能產生三次阻力。至於若有第四次、第五次回跌叫多次阻力。

二次阻力發生在多頭市場第一階段末。會產生中級回檔，時間在一個月以上。

二次阻力、三次阻力及多次阻力，常發生在多頭市場最終階段，是市場的多頭已力竭，快要衰敗的現象。

一條權威的上升X線是要延長一倍以上的，用來試驗是否有二次阻力、三次阻力情形。

### 3-7 上升X線二度阻力

二度阻力與二次阻力略有不同。

二度阻力可看成二次阻力的變形，前面談到二次阻力可能失敗，股價快速上衝，使原來那條上升X線落在股價下面了。

但是，一條有權威的上升X線不要輕易放棄，把它延長，靜靜等待。

股價有可能在一次較大的回跌之後，重新跌到原來那條上升 X 線的下面。不久，股價反彈上升，再次碰到原來那條上升 X 線，遭遇阻力而過不去，結束反彈，此種情形叫二度阻力（圖 3-7）。

一個中級上升末尾，常出現二次阻力、三次阻力或二度阻力，尤其是反轉之前，二次阻力會形成小 M 頭。二度阻力則形成頭肩頂。

![](img/114f067fd2db153a6ed238c66e83de58_26_0.png)

圖 3-7 上升 X 線二個阻力。 二個阻力常出現在頭肩頂右肩，二個阻力會導致多頭市場轉成空頭市場，要特別注意。

上升X線的二度阻力和三次阻力，發生時機相同，是在多頭市場第一及第二階段快結束時。

尤其，在多頭市場第二階段（多頭市場第二部曲）發生的二度阻力，常出現在頭肩頂反轉的右肩部分。

此後，便進入空頭市場的無盡深淵。這一點要特別注意。您要把上升X線延長，一看再看。

### 3-8 B型上升X線

前面所討論的上升X線是底和頂相連（至少間隔一個頂和底），是向右上方傾斜的，這是正統上升X線。

依支撐和阻力演變理論（117頁），有一種上升X線是向右下方傾斜的，另一種是水平的。水平的就是一般的支撐與阻力。

向右下方傾斜的上升X線，和下降X線是會混淆的，因此另外命名為B型上升X線（圖3-8）。

連成B型上升X線的底部比頂點還要高，好像中央山脈中的一個山谷比某一山頭還高，這是有可能的。

B 型上升 X 線和正統上升 X 線都是上升 X 線。它們的畫法、作用完全相同，只是傾斜方向不同。

在空頭市場跌深後的大反彈，或空頭市場大跌後，初步進入多頭市場早期，會碰到 B 型上升 X 線。

![](img/114f067fd2db153a6ed238c66e83de58_28_0.png)

圖 3-8 B 型上升 X 線。底 A 連頂 B，但 B 比 A 低，造成上升 X 線向右下方傾斜，不要誤為是下降 X 線才好。

### 3-9 上升 X 線和成交量

上升 X 線和成交量沒有直接關係，反正股價碰到上升 X 線就得回跌。

當然，如果碰到上升 X 線時成交量特別大（譬如達到發行股票的 5～10%）。這表示淨額很多，會促使回跌迅速一點。尤其是上漲幅度很大的熱門股，碰到上升 X 線的回跌，又快又猛，常會跌停板。

### 3-10 上升 X 線沒有測量作用

一條上升 X 線畫出來後，並不能預測股價必定會漲上去碰它。您知道，一條很陡的上升 X 線，有時永遠也碰不到的。

上升 X 線只肯定股價碰到後會跌下來，至於股價能上升多少，須由頭肩底、雙重底的測量公式決定，或由其他方法預測。

當然，毫無疑問的，如果股價上升的路途中，上面滿佈上升 X 線，顯示阻力重重，除非多頭主力衝勁十足，無限制買進（成交量常顯得特別大，破紀錄），否則，股價上升便會步履維艱。
