# ## 1-2 努力尋找

假如，有一條 簡單的直線，不須經過很多麻煩，在原來股票圖上就可以直接畫出。

股價上漲時，碰到這一條直線必定向下跌；股價下跌時碰到這一條線必定上漲，時間不會超過第二天，我們便可以明確的在碰到這一條直線當天，或第二天採取行動，獲取最大利益。

這是作股票的人，夢寐以求的最高境界！

我把這條直線叫 股價 X 線。

爲了能夠尋找到一條準確而理想的 股價 X 線，筆者花了四年時間，在本國 1972 年以來的 600 張標準半對數股票圖上，進行研究及分析，並把國外自 1929 年以來的半對數股票圖，拿來驗證，不眠不休，夙夜匪懈。

結果，在 1978 年發明了 股價 X 線。

股價上漲，碰到 上升 X 線 就下跌；

股價下跌，碰到 下降 X 線 就上漲。

時間不會超過第二天，而且有 99 % 的準確性。
