
到上升 X 線時順勢作回檔，不然吃力不討好。

## 3-11 上升 X 線和恐慌上升

股票一旦引起恐慌上升（是空頭恐慌），人氣集中，軋空慘烈，這種股票碰到上升 X 線，有可能如下：

- （1）碰到上升 X 線的第二天，回跌一下而已（可能只有 3%），立即上升。
- （2）碰到上升 X 線的第二天、第三天都不回跌，在第四天後，迅速而大幅度回跌，常以跌停板方式落至上升 X 線下面，呈倒 V 字形反轉。

股價碰到上升 X 線，沒有在 2 天內回跌，股價本身已遭受強大的潛在壓力，這個壓力必定會在以後幾天爆發，大幅回落。

所以，碰到上升 X 線，在股價沒有回落前，買進這種股票是一種冒險行爲。十次有九次，最後證明都是錯誤。除非您動作敏捷，在股價將回落前，毅然脫手，否則，極易套牢。

## 3-12 很多股票碰到上升 X 線

在同一時間，很多種股票碰到上升 X 線（譬如 有 20%）。這會造成一種氣勢，尤其是領導股和熱門股，有一大半碰到上升 X 線，這種情況顯示，大勢會有明顯回跌，也有可能反轉進入空頭市場。

所以，很多股票碰到上升 X 線時（包括指數線），要仔細檢查您的股票有無碰到上升 X 線，有無遺漏上升 X 線而尚未畫到者，並考慮賣出股票。當然，此時不能再買股票了。我們看過下一章後，會利用下降 X 線買進，此刻只考慮賣股票就對了。

沒有上升 X 線幫忙，在此處誤買股票是常發生的。

## 3-13 上升 X 線的心理

股價技術性分析所以會衍生，且經久不變，是群眾心理表現的結果。

股價碰到上升 X 線時，股民的心理如何？答案是非常想買進，而這裡應該是要賣股票才對啊！這是股民天
生理上的弱點（或許該怪基因），因此，套牢、虧錢是宿命。

沒有上升 X 線指標，您可以說我不知道有危險啊，我以爲還會再漲。

有了上升 X 線以後，看清楚了，結果如何？結果是比較不會在此買進，但是，會捨不得賣，這也難怪，市場氣勢凌人，人人樂觀，被上漲的氣氛迷惑了，總覺得晚一點賣賺更多。

錯了，不按上升 X 線指示賣出股票，最後都是要後悔的。

可見股民學習上升 X 線的同時，也要進行心理建設。按股價 X 線操作，正確機率高（99%），按股民心理操作錯誤多。

結論：股價碰到權威的上升 X 線時，或碰到多條上升 X 線交叉時，賣股票就對了。

要有決心，要果斷，不可以三心兩意。

股價碰到權威的上升 X 線，鐵了心，就是要賣！

心理建設配合上升 X 線才能成功！

## 3-14 利用上升 X 線決定多頭市場終點

討論上升 X 線的最終目標，是如何利用它來決定多頭市場終點。確定了多頭市場終點，可以賣光股票，暫時離開市場，或加入空頭陣容。

多頭市場終點決定，通常由反轉型態：如頭肩頂、雙重頂(M 頭)、增大頂點及下降三角形等決定。但是，等待這些型態往下突破，再賣出股票，獲利減少許多。

誰不希望在高點賣出？

雖然，一些自誇在高點賣出股票的人，常被人認爲是吹牛，不過上升 X 線確實可以幫您達成這個願望。

多頭市場的漲升，一般至少都有兩個階段，第一階段上漲後，進行大盤檔，大整理，然後才有第二階段的上漲。所以，多頭市場終點一定在第二階段之後，可能是第二階段或第三階段，其中以第二階段最常發生。

如何在股價尚未完成反轉型態前，利用上升 X 線，決定多頭市場終點，是重要課題。

利用上升 X 線決定多頭市場終點的方法：

1. 遇線圖上碰到一條或一條以上的上升 X 線。
2. 月線圖上碰到一條上升 X 線。
3. 日線圖股價碰到三條上升 X 線的交叉點。
4. 日線圖發生二度阻力或三次阻力。
5. 日線圖碰到一條由多頭市場起點，和多頭市場第一階段上升之後，中級回檔的中心點，所連成的上升 X 線。此點不容易懂，示範如（圖 3-9）：

## 4 下降 X 線

本章我們利用上升 X 線相反的觀念，來討論下降 X 線。上升 X 線配合下降 X 線，買賣股票才算圓滿。

## 4-1 半對數圖紙

和上升 X 線相同，下降 X 線也必須在標準半對數圖紙上畫出。財訊日報及部分電腦軟體，使用了半對數刻度，可以直接在上面畫出下降 X 線，缺點是圖太短了，有些下降 X 線可能漏畫，失去買股票的機會。股價變動不大時（20%內），方格紙股票圖亦可。上升 X 線和下降 X 線，是以半對數圖紙的股票圖作為基礎的。

## 4-2 下降 X 線的畫法

下降 X 線是一條直線，幾何學說兩點可畫一直線。要畫出下降 X 線，首先需要兩個點：一個是頂點，一個是底部。頂點和底部在股票圖上類似波峰和波谷，是連接各種線的基本點，本書第 20 章有討論。

要先確認頂點和底部，才能畫出下降 X 線。

下降 X 線的畫法是：頂 連 底

（1） 一個頂點跳過一個底部和頂點，和右下方另一個底部，以直線相連接，並延長一倍（圖 4-1）。

![](img/114f067fd2db153a6ed238c66e83de58_49_0.png)

圖 4-1 下降 X 線畫法。 頂 A 跳過底 D 和頂 E，與底 B 相連。

口訣：頂連底（至少間隔一個底和頂）。A 連 B 要延長一倍。

（2） 一個頂點跳過數個底部和頂點（或叫翻山越谷），和右下方另一個底部，以直線相連接，並延長一倍（圖 4-2）。但是，交叉點要單純，否則無效。

![](img/114f067fd2db153a6ed238c66e83de58_50_0.png)

圖 4-2 下降X線的畫法。口訣：頂連底。頂A跳過數個底與頂，和底B相連，並延長至少一倍，注意交叉的地方要單純。

簡單的講，下降X線是頂連底。頂和底之間至少要間隔一個（也可以多個）底和頂。

下降X線與趨勢線交叉畫出，但是，交叉點要單純就對了，交叉點複雜無效。

股票圖上，股價 X 線以紅藍相間的線畫出，先用紅筆貫穿全線，再點上若干藍色短線即可，以區別用藍筆畫的下降趨勢線。本書以折線 （ --- … --- … --- … → ） 畫出下降 X 線。 一種紅藍兩用原子筆適用。第 5 章還要討論畫股價 X 線細節。

## 4-3 下降 X 線的作用
—— 2 天內上漲

一條下降 X 線畫出以後，下一次股價若下跌，碰到下降 X 線，股價會在當天或第二天上漲。這是下降 X 線最大特色。

![](img/114f067fd2db153a6ed238c66e83de58_51_0.png)

圖 4-3 下降 X 線的作用
股價碰到下降 X 線會在二天內會上漲。

雖然股價下跌幅到下降 X 線，會在當天或第二天上漲，但是，這並不是說下降 X 線畫好在那裡，股價就一定會跌下去碰，一條很陡的下降 X 線，股價也許永遠碰不到。一般是股價已經下跌一些了，才開始畫下降 X 線，由 B 型下降 X 線（後面介紹）開始畫，依序是有機會先碰到的，或按比較水平的，傾角小的，傾角中的，傾角大一點的（圖 4-4）。

![](img/114f067fd2db153a6ed238c66e83de58_52_0.png)

在多頭市場，股價回檔碰到下降 X 線（通常是 B 型下降 X 線），會在當天上漲，繼續多頭市場走勢，上漲當然很多，甚至漲到多頭市場終點爲止。所以，在多頭市場股價下跌，碰到下降 X 線是買進的好機會。

在空頭市場，股價下跌碰到下降 X 線，會在當天或第二天反彈，當天或第二天反彈的機會各佔一半，完全視當時整個市場的大勢而定。假定股票下跌碰到下降 X 線，若是當天大勢好，則當天便會上漲，若是當天大勢差，可能在第二天才上漲。

在空頭市場，碰到下降 X 線會漲多少？依股票的敏感度，碰線前的下跌幅度而定。

假定股票敏感度高（股票較投機的意思），碰線前下跌幅度很大（譬如剩下 50%），則回升在 5～20% 左右，有時會形成中級反彈。一些低敏感度及下跌幅度不多者，當然反彈會少一些。

股價碰到下降 X 線，不管反彈多少，總是會上漲的，可靠性 99%，極少錯誤。但是，空頭市場買股票要少一點。在空頭市場，股票很容易下跌，怕有閃失。

## 4-4 下降 X 線如何使用

下降 X 線的使用，因多頭市場或空頭市場而不同。

（1） 在多頭市場，下降 X 線（通常是 B 型下降 X 線）是回檔的最低價。 碰線當天或第二天，股價便開始上升，而且會上升很多。

- 假定您是空頭，應在碰線當天補空並翻多，切勿再觀望，最差操作者會在此放空，立即被軋空。
- 假定您是多頭，在碰線當天加碼買進，並在買進價下方 10%，作停止損失委託即可。
- 空手的人，可以在此時買進，順利上轎。

（2） 在空頭市場，股價碰到下降 X 線，會在當天或第二天反彈，通常反彈 5～20%

反彈幅度依敏感度及下跌幅度而定。

- 假定您是空頭，應在碰線當天或第二天回補一些，反彈上升後再放空。
- 假定您是多頭，在碰線當天或第二天，酌量買進一些（不可全力買進），並於反彈稍有獲利時即
賣出。買進股票仍受停止損失委託保護。

◎ 如果，您是套牢多頭，切勿在碰到下降 X 線時，賠本賣出，應等反彈時機機脫手減少損失，最可憐多頭會在碰到下降 X 線時殺出股票。

◎ 長空或空手者，要注意空頭市場何時結束，以便補空並翻多。怎樣利用下降 X 線決定空頭市場結束，後面討論。

（3） 在多頭市場或空頭市場不明時，無論如何，股價碰到下降 X 線，買進股票總是沒錯，然後，等待適當時機賣出獲利。

## 4-5 多條下降 X 線交叉於一點

和上升 X 線一樣，有時多條下降 X 線會交叉於一點。一條下降 X 線是一種支撐，股價碰到會上升。兩條下降 X 線交叉，支撐力量更大，回升更厲害。

不可否認，三條下降 X 線會產生極強烈的上升。

若有三條下降 X 線交叉，會發生下面情形：

![](img/114f067fd2db153a6ed238c66e83de58_56_0.png)

圖 4-5 多條下降 X 線交叉於一點。會產生大回升或進入多頭市場，是買進股票的好機會。日線圖才有此情形，週線圖有兩條交叉就很难得了。

（1） 空頭市場第一階段、第二階段，三條下降X線交叉，會產生比較大的反彈，有時是中級反彈。

（2） 空頭市場第三階段，或最後階段，若股價碰到有三條下降X線交叉，會反轉進入多頭市場。

## 4-6 下降X線二次支撐
和三次支撐

股價一路下跌，碰到一條已經建立的下降X線，會產生反彈。反彈以後，股價又下跌，再一次碰到原來那條下降X線。這一次股價可能不停留，繼續跌下去，也很可能第二次反彈。

假如，股價下跌碰到原來那條 下降 X 線，仍然反彈叫二次支撐。

股價第一次碰到下降 X 線當然會反彈，第二次下跌再碰到同一條下降 X 線，是否會反彈呢？

可由下面決定：

- （1） 空頭市場初期，股價下跌快，下跌潛力大，不易有二次支撐。
- （2） 空頭市場末期，易有二次支撐。

如果，已經產生二次支撐後，股價第三次碰到，又有支撐叫三次支撐（圖 4-6）。

至於，若又有第四次、第五次支撐叫多次支撐。

二次支撐、三次支撐及多次支撐，發生在空頭市場最終階段，是空頭市場逐漸轉爲多頭市場打底階段。

股價第二次、第三次碰到同一條下降 X 線時，買進股票是不一定可靠的。但是，從它的發展過程，可以反推市場是否在改變中，空頭市場就要結束了嗎？

一條權威的下降 X 線 是要延長一倍以上的，用來試驗是否有二次支撐、三次支撐情形。

A 連 B 在 C₂、C₃ 第二次、第三次碰到，叫二次支撐和三次支撐，在空頭市場末期，這是進入多頭市場的信號。

## 4-7 下降 X 線二度支撐

上升 X 線 有二度阻力；下降 X 線 有二度支撐。

股價第一次碰到一條下降 X 線，產升反彈後迅速跌到該條下降 X 線下方一段相當的距離（譬如 10% 左右），然後在一個強烈反彈後，股價又迅速回升到該條下降 X 線上方。這是一個不尋常狀況，既然跌破為何又

回頭？莫非多頭硬起來了，或是空頭心虛要認敗了？

衝上原來那條下降 X 線後，不久，又跌下來了，再次逼近原來下降 X 線，逼近、逼近，但是，就是不跌破，在原來下降 X 線上方，停下來了，重新上漲。

這種情形叫二度支撐（圖 4-7）。

A 連 B 在 C 反彈，隨後跌破，不久又回到下降 X 線之上，這不是一種平常現象。緩慢回跌後，在下降 X 線停止，叫二度支撐。在空頭市場末期，二度支撐支撐是進入多頭市場的前兆，是買進的最後機會。
