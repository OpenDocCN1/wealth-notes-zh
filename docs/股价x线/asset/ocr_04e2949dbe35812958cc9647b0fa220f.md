可以想見，幾乎是反轉定了。多條上升 X 線交叉是賣股票或放空的好機會，這種事一年中有一、兩次。

# ## 3-6 上升 X 線二次阻力

和三次阻力

股價一路上升，碰到一條已經建立的上升 X 線，會產生回跌。回跌後股價可能鼓足勇氣往上挺升，再次碰到原來那條上升 X 線（冤家路窄），這一回股價很可能衝過去，也很可能再次跌下來。

假如，股價第二次碰到原來那條上升 X 線，仍然回跌，我們叫它 二次阻力。而股價第三次碰到原來那條上升 X 線，仍然回跌，我們叫它 三次阻力（圖 3-6）。

並不是每一條上升 X 線都會產生二次阻力，二次阻力能否產生取決於：

（1） 股價在碰到上升 X 線前，是否已經上漲一大段了，是否已經完成各種上升型態，如頭肩底、雙重底的最小測量（252 頁）。
