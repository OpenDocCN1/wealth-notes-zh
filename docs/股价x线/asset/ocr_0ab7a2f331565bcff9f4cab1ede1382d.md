什麼情況下面不容易有下降 X 線：一爲多頭市場狂熱上升後忽然反轉，二爲空頭市場末期，股價直線下降的恐慌下跌。這兩種情況買進股票要非常小心，因爲它們找不到可以畫下降 X 線的基本點，意思是沒有什麼支撐，不會上漲。

# 4-11 下降 X 線和恐慌下跌

買股票最怕碰到恐慌下跌。有時，您會看到長期累積的獲利，因爲恐慌下跌在幾天內變成泡影，甚至虧損累累。

恐慌下跌容易發生在空頭市場第一階段，及空頭市場第三階段。股市一旦引起恐慌，似乎什麼辦法也沒有，唯一預防的方法是：

+   1. 利用上升 X 線，在還沒有引起恐慌時賣出。

+   2. 向下突破明顯的反轉型態時，不限價賣出。

+   3. 利用停止損失委託，跌到停損點時，不限價賣出。
