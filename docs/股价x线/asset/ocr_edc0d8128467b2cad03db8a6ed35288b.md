# # 1-4 如何命名

股價X線 命名的理由有二：

+   (1) 股價X線具有神秘的力量，能精確透視股價反轉位置，彷彿X光可以透視肉眼所看不到的地方。

+   (2) 股價X線作圖時，是以頂和底，或底和頂連接，和股價趨勢交叉畫出，類似英文字母X（畫法詳見後面數章）。

# # 1-5 有用發明

股價X線 是一種極有用的創見和發明，對股票或期貨技術性分析尤有益處。

古今中外尚無人提出這種線，因此，股價X線 在國內外是首次發表（1979年12月1日印行），我想在世界上有股票或期貨交易的地區，應該同樣會受歡迎。

股價X線 將會聲名遠播，造福股市投資人。
