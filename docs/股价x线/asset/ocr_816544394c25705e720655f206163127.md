賴程度好，可以據以買賣，在股票圖上要畫重些。有的基本點不那麼明顯，股價 X 線畫輕些，買賣少一點。

一般初學者，從週線圖開始畫股價 X 線（包括上升 X 線和下降 X 線），週線圖上的基本點比較少，但是比較明顯，也比較好畫。畫出一條股價 X 線，馬上就可以根據來買賣，錯誤的機會少。

日線圖上的拐灣比較多，有些很細，一般初學者會感到有些困難，畫出後不知對不對，也不敢買賣。

有些基本點看起來不明顯，那是因為股價變動幅度大，電腦畫面自動壓縮的結果；另有些基本點看起來很明顯是因為股價變動幅度太小，電腦畫面自動放大的結果。初學者還是要固定在一種標準半對數圖紙去訓練比較好。電腦畫面則要考慮是否壓縮，或放大的因素，以確定基本點是否真的明顯，以免誤用。

但是，學任何東西總是：一回生，二回熟，三回就上手。和其他作股票技術比較，股價 X 線算是易學好用的。學股票技術從股價 X 線開始就是好的開始。

股友們，學好股價 X 線，一生受用無窮，努力吧！
