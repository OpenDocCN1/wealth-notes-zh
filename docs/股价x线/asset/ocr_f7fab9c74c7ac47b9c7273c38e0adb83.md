# 6-3  股價 Ⅹ 線較敏感

不論上升 Ⅹ 線或是下降 Ⅹ 線，它們比一般支撐和阻力更明確，也更敏感些。只要在碰到 Ⅹ 線的當天或第二天就會產生作用。

這好比一個從高處落下的皮球，碰到水平的地面和碰到傾斜的地面，反跳的方式不一樣。

皮球碰到水平的地面，只單純往上彈；而皮球碰到傾斜的地面，不只往上彈，而且瞬時往旁邊跳開，看起來彈跳比較敏感些。

所以股價 Ⅹ 線比支撐和阻力更敏感，也更明確。只要在碰到 Ⅹ 線的當天，或第二天就會產生作用。
