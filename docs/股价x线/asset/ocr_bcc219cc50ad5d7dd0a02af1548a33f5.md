無論如何，空頭市場買進股票要少，不可以全力爲之，因爲空頭市場股價下跌，畢竟比較容易！

# 4-12 很多股票碰到下降 X 線

在同一時間，很多的股票碰到下降 X 線（譬如
有 $20\%$）。這會造成一種氣勢，尤其是領導股和熱門股有一半左右碰到下降 X 線，這種情況顯示大勢會有明顯上漲，也有可能反轉進入多頭市場。

所以，很多股票碰到下降 X 線時（包括指數線），
要仔細檢查您心目中的股票，有無碰到下降 X 線了，有
無遺漏下降 X 線而尚未畫到者。若股票圖太短，譬如只有三、四個月，必會遺漏下降 X 線。

很多股票碰到下降 X 線時，要考慮買進股票。當
然，不能再賣股票了。我們看過上一章後，應該會利用
上升 X 線賣出，此刻只考慮買股票就對了。

沒有下降 X 線幫忙，在此錯賣股票是常發生的。
