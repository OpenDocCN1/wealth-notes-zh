# 三、留学就业

# 留学生的回沪前途。

第一是父母朋友圈。第二是论文档次。第三看脸或内环线索本本。结论：去不去，都一样！欧美理工科试验设备好，出国有优势。文科社科类专业，严重脱离国情，聪明人都教傻了。英国经济学从来不说父母关系，就喜欢画表格，建数模。内地商业第一要点，去大单位大老板那里拉单子。你行吗？

# 现在每年出国留学约有五万人，基本都会回来

主要集中在京沪，日积月累，哪里有那么多好位置啊？除顶级人才，多数人的职场作用，除了当花瓶（企业对外宣传有用），和二本学生没区别。原来国内是啥档次，回国后还是那档次，老板的儿子还是老板。职员的儿子还是职员，还花掉了一套房的钱，找谁评理啊？

# 欧美外资精英单位的招聘内核。能不能拉来大单，是招聘第一看点。

技术都是成熟的，无论是法律，CPA，金融，物理化工程，房地产，永远不缺技术员。外企目标是，亿元级大单，这些单子都隐匿在你懂的大单位，能不能接到活，是衡量员工的唯一要素。怎么才能接到这些大单？哈，大家都懂的，看破不说破。

# 身边事。小王，29 岁，父母是某地某行业的核心环节。

小王一毕业，就在国外找好了顶级外企驻华公司。回来后，一年一次晋升，无论做什么事情，都会得到表扬。后来小王想辞职，公司老板亲自打电话说，不要辞职，有事可以请假，请假一年半都可以，随时欢迎回来。你看看，屌丝二代行吗？老外聪明着呢！

# 留学回来有用吗？

一半以上的博士可以在地级市的高校，混个正式编制。其他情况下，确实没用，就当是旅游吧。我是老留学生了，这个事情我在十几年前就发现了。原因：

+   1，体制内，不是特别在乎学历。

+   2，体制外，需要真本事，或者肯吃苦。这和留学没有一毛钱关系。举例，你是学外规设计的，老板可以给你半年机会，你给我搞个爆款出来。若可以，你就是副总待遇。若不行，滚，没用的东西，浪费粮食。呸呸呸！
