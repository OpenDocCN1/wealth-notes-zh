# 四、高考考试策略

考上好大学的条件是什么？高考说白了是记忆力大赛，不是什么智力测试。

在高中三年里记住最多的内容，是唯一的竞赛项目。数理化貌似理科，实际是各种题型的变换，有套路的。记住最多的东西，取决于：

一是记忆力。这是基因问题。大城市几十年来不断的从农村抽取高智商人口，平均记忆力水平确实优于这么多年还走不出农村的乡下人。

二是记忆条件。这个是物质问题。

+   1、学习环境。在安静富裕的环境中，容易静下心来，父母在隔壁打麻将，楼上邻居在打孩子，楼下小卖部在播放流行歌曲，这种嘈杂环境中，孩子就很难背书了。孩子在安静的高档社区，就好多了。

+   2、学习氛围。如果在垃圾学校，其他同学都在谈恋爱，打游戏，高中生自制力差，很容易放弃努力。

+   3、资料整理和授课水平。这是最关键的。同样学习一个复杂课程，优秀老师可以讲的深入浅出，总结出各种口诀，解题小秘密，学生很容易记住。而垃圾老师只会照本宣科，同学们昏昏欲睡。白白浪费时间。

三是家庭环境。这是感情问题。

如果父母很有钱，但是天天打架闹离婚，出轨打老婆，会对孩子形成巨大刺激，影响学习。

我们不排除个案或特长生，但大体上是富裕稳定家庭的孩子成功可能性大。另外，考场发挥是个次要因素，不过是记忆熟练程度的问题。滚瓜烂熟就不会紧张。

高考就是考熟练度。

考清华北大复旦交大，每年合计招生近一万人，录取率千分之一。天才的比率是百万分之一，所以基本还是靠“疯狂刷题+运气”，选择题蒙的全对。数理化最后两个大题，五分钟就有灵感。

考985，录取率9-12%，刷题刷到精神恍惚，四肢发软，80%有神经衰弱。

考一本，录取率25%，刷遍市场上主流的练习题，记忆力中上。

考二本，每天刷题到晚上十点半。每周可以玩一天。

考大专高职，平时像个学生样子即可
