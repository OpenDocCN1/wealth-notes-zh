# 读书重要吗？

你看谁，清北毕业，当了副总。实际上，读书不是第一重要。最重要的是，你在长期读书的过程中，形成超强的意志力，自律性，逻辑性。这个才是成功的秘诀。很多人没有读过大学，在其他道路上，例如打仗，下车间，做农活，在长期的实践中，也形成了强大的自律性，吃苦耐劳的品质，最后也成功了。

你去看那些大将军。黄埔军校，是短期培训班，勉强算小中专，保定军校读四年，算中专，这就是第一流了。很多人就是小学文化。廖耀湘是法国本科，孙立人是美国本科，孔祥熙是美国博士，那又怎么样？还不是输了。孟良崮之战，粟裕是师范中专，张灵甫是陆大本科，黄百韬是高中，李天霞是本科退学。

结论：不要迷信学历。重要的是，脚踏实地，干中学，学中干，向群众学习，向市场学习。

读书不能改变命运，改变命运的是有用的知识。

在计划经济时代，大专文凭就是干部编制。干部编制和工人编制，就像是北京东城区户口和安徽蚌埠农村户口。这个巨大的鸿沟，一般是绝不可能跨越的。

现在，文凭和身份，已经没有任何关系了。你是985毕业，不一定可以进入大银行，我是二本文理学院毕业的，我可以进大银行省分行。不服？滚。
