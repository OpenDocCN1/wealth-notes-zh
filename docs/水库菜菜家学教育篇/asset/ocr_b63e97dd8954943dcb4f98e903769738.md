# 挑食还是抢夺？

我和我的孩子，人生道路完全不同了。我的年轻时代是很悲惨的，主要是穷，没房子。top1 学霸，没有给我带来任何直接财富，就和六安师院的工资待遇是一样的，全日制本科。

年轻时候的贫穷，意味着没有女人，那叫一个惨啊！当年，我是满脑子的天天想女人，就想要个有单位的老婆，没工作我养不起啊。贫穷带来的绝望，是我一辈子的心理阴影。我现在不怕贫穷了，曾经沧海难为水，享受过富裕了，也就平常心。

我的孩子，物资条件很好了，为了避免大家的火气大，就不炫耀了。

我和孩子最大的区别是，孩子不知道什么是抢夺了。现成都吃不完，还要抢什么？我很发怒这个事情。财富不是永恒的，钱走旺家门。现在有，不代表将来有。一旦失去了抢夺能力，大浪潮一来，就饿死了。解放后，滞留上海的很多富二代，大多数人一辈子过得极差，活下来就很好了。有的富二代当年乱说话，最后死在了劳改农场。

俞敏洪说，不希望孩子读清华北大，那个学校的孩子，精神出问题的很多。我基本赞同。因为过于紧张的疯狂考试，往往是心理疾病的源头。我对孩子的要求是，德智体美劳。这话看上去好像很历史了，但真是有道理。

人品很关键。你能不能做大事，取决于你的凝聚力。凝聚力就是靠人品，靠情商。

身体是革命的本钱。我一定不会让孩子近视眼，哪怕成绩中下，我也认。反正我们也不靠做题过日子。

审美。很多人忽视审美素养。我是高度重视。因为我发财就是靠这个。全世界的生意，分为两种，一是技术，二是审美。我没有本事做出个华为苹果，但我会做滑板车，这个不需要什么技术，我做的漂亮就发财了，你做的不好看，就没人要。

劳动习惯可以防止懒散。人不能懒，懒久了，啥也不想做了。很多人当年下岗了，一歇三年，啥也不想干了。

如果不是走体制内，考试刷题，确实意义不大。我现在初二的数学题也不会了，这又怎么样？

我们的意见是，先给孩子幸福感。等孩子长大后，再说。

某熟人，家里条件也很好，几千万房子。他孩子一年级，偷家长钱，几十元，被父母打了一顿。孩子偷钱的原因是，家长不愿意给钱，还一直告诉孩子，你要长大后凭本事自己去做钱。
