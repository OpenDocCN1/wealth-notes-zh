# 职业教育和普通高考，是有冲突的。

孩子高中毕业到参加工作，当中只有四年时间。这四年学什么？主要两个选择，职业技能，普通本科。如果普通本科明显有利益，那么职业教育永远会边缘化。你给补贴，我也不感兴趣。没有一个家长会为了一点点补贴，放弃孩子可能的更优前途。

只有下最大决心，以最大勇气，彻底打掉普通本科，职业教育才有出头机会。否则，哪家的孩子愿意放弃二本，去学车床，钳工的职业教育？

我们现在的职业教育，已经非常那个了。我们在生产线一线的人，应该都知道。西装设计的学生，不认识面料。汽车设计的学生，不知道金属特性。建筑设计的学生，不知道施工工艺。土木工程的学生，不会使用水泥搅拌机。他们都 22 岁了。你说怎么办？

建议，保留 985、211 以下大学和高职拉平，注册入学，宽进严出，统称 “国民高等教育证书”。不再区分是哪个学校了，同学们可以跨校学习，网络学习，网上考试拿学分。

当然，这好像是可能的。这个产业链上，利益太大了。民办校，学区房，条子生，补课班，辅导书，哪个不是利益？

# 菜菜，你会送孩子去当技术工人吗？

如果取消职业教育和本科教育的歧视性区别，我肯定愿意孩子做个技术职员啊。你以为读清华是那么容易的吗？保送，你也毕业不了，真的。我是不愿意孩子读清华这种学校的。我希望孩子有个一技之长，干好了当老板，干不好，也有个保底的岗位。

现在的职业教育，实际上就是被人歧视的。”哈哈，他是可怜的职高男生，哈哈，她是笨笨的职高姑娘！” 气人吧？我不强求孩子读本科，但我更不希望孩子在青少年时期被歧视。两害取其轻。

# 对于大四的男生有何建议？

答：做好一门技术，不要老想当官。当官是一时的，做人是一辈子的。

# 我完全支持考证书，例 CPA，码农，工程师，律师，医师，翻译之类的高端证书。

大学课程基本是垃圾，教的也不上心，学的百无聊赖，倒霉的是父母血汗钱。高级证书的通过率很低，CPA 大概是 5-8%，医师通过率大概是 80%，这就逼得你认真学习，要比别人学的好，这就玩命了。如果没有这些考试，学生质量太差。
