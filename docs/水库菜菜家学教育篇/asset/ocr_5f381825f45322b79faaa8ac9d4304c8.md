# 二、如何留学

**留学归纳。**

清华的一定要去留学，努力成为顶级人才。

富二代留学，要去欧美，回来镇得住公司里的土鳖。

穷二代留学，只去加澳，留下打洋工。

小美白留学，争取找对象。

土肥圆就不要去了，去了也窝心。

村二代最好去第三世界留学，如印度，中亚，东欧，南美，小语种国家，毕业后留在当地搞法律政策经济研究，目标是，为今后大企业出海打前站。以前有个台商，岛内破产后，来大陆，没钱投资，天天写日记做调研：如何公司登记，买房买车，交通过路费，劳工政策等，后来成为大台商的咨询顾问，逆袭成功。

**一般家庭的家长：如果你的孩子有成为科学家的可能性，砸锅卖铁借人情债，也要送出去读博士。**

你放心，你儿子能够有这个底子，靠谱一点的亲戚都会借钱给你的。如果是镀个金的，就算了。富人家孩子也不傻。金龟婿没那么好钓的。

现在留学，和在国内差不多，孩子们互相比钱，旅游，吃饭，唱歌，舞厅，酒吧，买车，泡妞，买奢侈品，租房子，什么都要钱，你烧钱到最后，也不过是一场空。

**未成年孩子要不要送出国留学？**

答：未成年就出国的孩子，从身体健康角度看，肯定是好一点的。体育锻炼多，食品卫生好，功课不忙，近视眼少，大部分人心理健康。但也有缺点，脱离了中国文化，回来就麻烦。

中国人的传统观念，勾心斗角，思维逻辑，一般是中学大学形成的。如果你这段时间不在国内，这种思维是没有的。

建议：

+   1，移民的，早点去。

+   2，家里几个亿存款的，无所谓。

+   3，要回国发展的，没意思。孩子出去久了，人都快傻了，回来像个 250。既考不过国内的各种证书，也不懂人情世故，最多当个蹩脚翻译，混混小资！
