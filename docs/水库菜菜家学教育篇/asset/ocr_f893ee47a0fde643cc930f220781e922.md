**今天终于解开了一个人重大疑惑。**

我小时候，有个同学的爸爸是数学老师，这个同学是高考数学满分。毕业后，我曾经问他，为什么数学这么好？他说，父亲教了很多课外知识，包括蝴蝶定理之类的。因为当时也工作了，所以，我没有再问什么。但我一直记住了蝴蝶定理。我查了很多资料，但始终不清楚蝴蝶定理是什么。今天终于查到了，确实有用。

# 三、应对套路

# 为什么学霸好像一天到晚在玩？

我读中学的时候，有个事情，百思不得其解。我们班上也有个学霸，每天课间休息就是说昨天晚上电视剧是什么内容，还和一大群女生讨论。我真是气的昏古七了。我基本不看电视，就是看课本。

他下了课，在操场上玩半个小时再回家，晚上又看电视剧两集，那时候一般是 8-10 点，那他基本就不读书了。问题是，每次考试都和我差不多。我实在是备受打击。

工作多年后，我遇到他，旧事重提，才套出真相。原来是他妈喜欢看电视，然后第二天吃早饭的时候，他就问他妈电视剧的故事情节。他就带到班上吹，实际上他根本没看电视。我被骗了很多年。

# 不要轻信学霸家长的什么感悟！

绝大部分学霸家长去讲讲座，都是在骗人灌鸡汤。什么培养良好的人格，培养学习兴趣，滚 TMD 的锤子。我告诉你真相，看看体育比赛冠军是怎么培养出来的，就知道了。就是不断重复重复重复，熟能生巧，再加上教练员的不断纠错。

被淘汰下来的运动员，在业余比赛打打菜鸡，那是轻而易举的。
