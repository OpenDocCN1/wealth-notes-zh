二，提高私企的盈利能力，大家不要挤到有限几个的好单位，铁饭碗，例如银行烟草公司。

三，垄断企业岗位市场化，例如，每个人五年参加一次岗位考试，淘汰5%？这样的话，大家就少一点焦虑，就业歧视也太大缓解了。

# 京沪个别家长对考分的态度，已经心理扭曲了。

现在，京沪暗中流行一种新的生活模式，“虎妈牛娃不买房”。说白了，“奋斗二十年，直接倒插门”。这种家庭，父母都是985凤凰，农村二本研究生，拿了京沪户口，钱不多，会考试。

他们的内心是很压抑的。实力不够，欲望很大，索性赌一把孩子。他们年入30-40万，京沪户口，索性不真正买房了，买个远郊区老破小挂户口之类的。

租个漂亮房子，一年12万左右，上班近，上学近，生活舒适。老爸主要任务是赚钱。老妈不上班或者自由职业，一门心思搞孩子。我见过有个理工科女博士辞职在家教孩子考试，省市重点小学，前两名的水平。

他们的目标是，孩子考上常青藤。要么留在美加澳，买个大别墅给他们养老。要么回来倒插门，一了百了。

搞笑的是，现在的中小学最喜欢的就是这种家长，一路绿灯。因为这种孩子可以给它们学校挣面子啊！

范志毅说，“没房子，不能娶我家女儿”。真是有道理的。

我们倒插门上岸后，必须把别人推下车！哼！

# 京沪有很多凤凰家庭，发了疯一样投资孩子教育。（我不赞同，但也管不了）

家庭年收入四十万左右的中产家庭，只有一套勉强过日子的房子，最容易出现这种情况。孩子从小就读私立，家庭收入的60%用于孩子教育，不考虑改善住房，只买个便宜车，苦熬十二年。

他们非常清楚，自己的收入在京沪没有希望改善住房了，也没有能力为子女买婚房了，也不打算节衣缩食，怎么办呢？很简单。从小培养孩子进行考试，以后让孩子去美加澳留学，然后在当地就业定居。他们一般选择特定几个理工科专业，准备未来在美加澳当技术人员，或者学者。

父母到了55岁，就提前退休，京沪房子卖掉，去美加澳带孩子。
