### 京沪，文凭不决定收入，重要的是：体力和你懂的。

# 五、职业教育，学门手艺

社会主流人群是在六环外。

市场经济，最需要的是实实在在的劳动成果，给我带来明确效益。贴瓷砖，炒虾仁，做裤子，哪怕是 KTV 里小姐姐教我唱个歌，我都愿意付款。唯独副高，真没几个人感兴趣。你会啥？除了满嘴跑火车，你倒是给我说个明确的事情？没有，都是模棱两可，含含糊糊。

建议：除了家里有大企业可以接班的国民女婿，其他人最好是去学一个实用技术。如果你不幸学了经济学，你也要像菜菜那样，把经济学讲出二人转的感觉。人家就当是听一场笑话，赏你两个大子。

大部分人，只要掌握初中语文和小学数学，就可以应付正常文员工作了。

# 第十章 去留学，长见识

# 一、留学有用吗？

留学有用吗？我家族里，考中留留学生都有，倒插门必备项。

留学和“有用吗”，无直接关系。关键是你有没有实力？家庭实力，科研实力，工作能力。留学的目的是增加工作实力，文凭本身不重要。

我们上一代的留学生非常吃香，回来就是副高，三十几岁正高，四十几岁就是博导了，他们现在退休了。到了我这一代留学生，基本没什么直接的工作意义了，但是意外的赶上了倒插门。

# 一，现实情况

1. 体制外的单位，根本不看留学经历，只能能否胜任具体岗位。如果能干，合肥工大也可以，不能干，哥大蒂大的也不行。
2. 行政单位，你千万别提留学，并不是加分项，反而是异类。
3. 事业科教大企业，也只有宣传意义，真正分好处的时候，还是看论文和谁为你说话。

# 二，平民子弟留学

有没有用，关键看你是不是增加了实力？

1. 如果你考个美国律师证，美国大学的副教授，硅谷干了五年工程师，回国就能出产品，融创绩的，那是热门加分人才。
2. 如果是在剑桥大学读了个中文专业，那就看谁给你说话了。没人替你说话，你也是个笑话。有人给你说话，你也是个宝。
3. 如果是在土澳读了个商科，不留下来定居，回来等于零。
4. 如果是土豪家的硕士子女，赠送一个京沪户口，可以买房。

# 三，普通留学的价值在哪里？

1. 最管用的是在婚恋市场。倒插门，带个宾大硕士文凭，老丈人肯定高兴啊。说不定就加名字两套了。小美白有个加拿大文凭，嫁人也是可以多要彩礼的。
2. 有利于子女教育。出国留学，肯定是玩了不少地方，以后带孩子的时候，见多识广，肯定是加分的。
3. 日常生活中，可以鄙视一下土老帽小领导。自我呵 Q 一把。

# 四，总结

1. 增加工作实力是第一。这个是干货，但 90%的人是做不到的。
2. 留下来打工是第二。有个语言能力，给国内代购，给华人卖房，也是个活法。
3. 倒插门是第三。这个是最实战的，一步到位。

# 留学有用吗？

作为老留学生，我的体会是，现在留学基本无用，拿到博士，可以去安徽的三本大学混个讲师。90 年代初期，留学生是超级牛比的，不管学什么专业，只要回来，就是报效国家，好机会通通给你。那时候，大学老师工资大概是 80 美元，外国洗碗的工资是 1200 美元，能够下决心回来的，确实不容易。由于留学生自带光环，所以引发了狂潮。

2000 年后，国内富人留学已经普及了。一般是三种模式：公派，合作办学 2+2，自费。除了公派，其他模式一般是卖房凑钱。京沪卖房留学的特别多。当时，普通孩子一般是去商科类专业，反正是万金油，大家去的时候高高兴兴。

等到毕业的时候，大概是 2006-2010 年了。当初去的那些学生，无论老家哪里，回来基本是京沪广深。由于过于集中，造成了留学生大贬值，海带就是那时候出现的。关键问题是，留学生学的知识，国内几乎没用。除了学习计算机的，其他文科商科专业，在国内市场环境中，毫无意义。举例，你就算是耶鲁法学专业，哈佛商学院，回到上海，律师考不上，做生意没关系，除了去外企当基层员工，真是别无出路。

莱嫂学了几年回来之后，最大的收获是做西餐了。国外商科教育非常重视实战培训。但这种培训是假设你在美国的商业环境中，这就导致，学什么都是假大空。莱嫂的 excel 比较熟悉，是因为专门有个课程教的。

与此同时，2000 年至今，京沪房价飙升二十倍，90%的留学生倒霉了。即使勉强赖在外国不回来的，大部分人日过的也是可怜，因为没有社会关系，没有提升可能性，基本就是上海农民工的状态。当然，外国空气好。

你留学耶鲁，就是耶鲁水平？我呸！

这就好像是外国人留学清华，你会雇佣吗？

留学。

以我实践经验的看，不是top10大学的理工科学生，基本就是去旅游几年的意思，不要指望留学会带来任何经济收益。一般水平的孩子，拼搏八年，拿到博士学位，去地级市大学混个副教授是可以的，其他的，你想多了。

举例，会计；法律，金融等社科类的留学，基本就是去练练口语，增加一点见识，完全没实战意义。你不可能留在当地国实操，回京沪也没啥实际作用，过了1-2年，也基本忘光了，就剩下一张旅游证书了。

富人家的孩子，反正也不靠学历吃饭，可以去玩玩，涨涨见识即可，玩三年回来，有没有文凭随他吧。穷人家的孩子，砸锅卖铁去旅游，完全是一场没有希望的豪赌。不要以为在外国可以拐倒拆迁妹，舔上富二代，不可能的。现在的孩子，比我们那年代精明多了，就算是一个学校的，第一个月你们就玩不到一起。

富人家的孩子到校后，照例是胡吃海喝去旅游，没有万儿八千美元欧元，你连报团的机会都没有，第一个月，你们就分屋了。接下来，富人和富人玩，互相请客。穷人和穷人玩，一起买便宜牛肉。你们最大的交集是，代写作业，考试作弊。

三年后回国，都是靠父母。富二代有关系，直接高大上了，或者回家族企业接班。穷人家的孩子，回到了房价涨了一倍的老破小，拿着差不多二本档次的工资，仰天长叹，今后怎么办啊！

# 欧美硕士博士有用吗？

答：富二代留学是锦上添花。村二代留学，还不如读合肥工大。留学生很难移民（澳洲除外）。英美法的博士，除了理工类紧缺人才，如优质码农，其他普通专业对你移民找工作无帮助。欧美文凭在京沪求职并不加分，因为严重脱离实操。去京沪大专职校当老师比较有优势，好歹也算个花瓶。

# 普通人留学真的是毫无意义，除非为了转移资产。

1. 中国的理工科教育，对于奥数全国二等奖以下的智商，足够你学了，
2. 文史哲经，除非是为了拿个外国博士文凭，回国当教授，否则，毫无意义。国内实操方面，和专管员打电话就行了。
