# 第四章 读初中，抓方法

# 一、教育产业化：花钱找教练，得专业指导

以前是富孩子读书不好，现在是穷孩子读书不好。原因很简单：教育产业化。

我们读书的时候，成绩好不好，完全看天分。初二开窍了，找到学习方法了，成绩就上来了。若否，你完了，技校欢迎你。富孩子少，只要考不上，必然成为穷人们的热门话题。穷孩子去技校，没人说的。久而久之，很多人印象中，富孩子读书差。

以前，少数富家子弟读书不好也确实有具体原因。

一，家里太热闹

马爸爸创业的时候，有个照片，就是在家里开会。他可能是不抽烟的，如果三五个老烟枪凑在一起谈事情，孩子就别读书了。

以前，大家的房子小，生意人电话特别多，经常打几个小时电话，孩子干扰很大。

家长没心情管孩子，一天到晚的催货催款发工资，急得嘴角起泡了，哪有一心情一天到晚管孩子读书啊。

穷人家好，晚上没声音的。只要父母不打架离婚，学习环境是真安静。孩子静得下心学习。

二，没有高质量的家教

以前，很多家长是“十年耽误的一代”，自己也没有文凭，根本不懂教育。想抓成绩也没办法。大部分有钱家长就是一个蠢办法，把孩子送到班主任家里去住，一年给几万元。但是，大部分班主任家里的环境也不怎么样。大多数两室一厅。班主任只教语文，就不懂其他了。

现在不一样了。我们这一批人都是 985 打底的，自己就是学霸出身。比老师也不差啊。再加上无穷无尽的家教，只要从小抓，质量普遍高于穷人家孩子。

三，没有丰富的物质基础

十多年前，贫富差距也有，但不是那么扎眼。以前，穷人家孩子的心理压力不是特别大，下岗的那一批毕竟是少数，周围邻居大家都一样，孩子们还是可以克服调整。穷人家孩子还特别要强。
