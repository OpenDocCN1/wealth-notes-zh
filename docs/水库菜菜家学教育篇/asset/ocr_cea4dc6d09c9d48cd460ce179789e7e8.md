# 第八章 读大学，进社会

# 一、文凭的作用

**文凭，是中产碾压穷人的利器。**

富裕家庭可以不靠文凭了。富孩子能不能考上 985，家长不是特别关心。考上我高兴，考不上也没什幺。孩子以后不需要求职了，随便挑个公司去当 CEO，再给你配几个老臣，玩十年，就当练手吧。35 岁回总公司接班就行了。虽然大多数富人的公司也不宏大，比不上王健林，但也可以吃个饭。

真正残酷的事情是，中产阶层对下层的碾压。绝大部分中产家庭，年收入 50-100 万左右，高不成低不就，他们的职务职称不能继承。房子和钱也不多，留不下几套大平层。留给孩子的只能是文凭，而且他们中产有这个优势。

上海的中产人群中，本地人很多，也有很多是考试出来的安徽人，江浙豫鲁也有。他们对考试有非常成熟的打法，超级重视教育。这是他们改变命运的唯一武器，肯定会让子孙孙代代传。虽然外来中产现金收入高，但是没房子，大部分收入拿去买房了，结余不多，日子也紧巴巴的。

京沪也有很多比较穷的本地家庭，小夫妻也只是二本大专职高毕业，靠祖上积德，生在京沪，还算有房子和户口，但现金收入不多，夫妻年入合计 20 万以下，日子真不好过，属于京沪有房子的穷人。他们本身学渣多，对孩子教育基本没什幺经验，除了天才孩子，剩下就是请高水平家教提高学习效率了。

现在，最大的职场竞争就是，外地 985 中产对本地破落户的围猎。这一代人，基本可以打个平手。下一代的竞争，就更加激烈。你可以退出比赛，大家巴不得你走佬。如果不愿意退出，那就一起烧钱

**在底层通往中底层的过程中，文凭是最有用的。**

小王姐姐是省城下岗家庭出身，勤学苦练，月经不调，补习辅导班上了十多年，终于考上了普通一本研究生，毕业后再苦干了十年，不停的考试加班出差，熬到了省城大单位的科级编制，贷款买了城市副中心的三居室，人生逆袭成功了。与此同时，她的那些表哥堂姐，没有考上大学，现在继续战斗在微商一线，半夜三更给朋友圈发垃圾广告。

小王也知道，这就是文凭的最高境界了，接下来能不能继续进步，和文凭没有关系了。无论是赚钱还是提拔，不会再有人去问她什幺学历了。
