# 一、大学的本质

大学的本质，是教人生活赚钱。现在变成了卖个破文凭，啥也学不到。我日他姥姥O

大学教育和社会需求基本脱节。知识陈旧就不说了，敬业精神也是一比吊糟。大学培养的是懒教自由，胡说八道，特立独行的个人风格。而社会需求是，纪律严明，令行禁止，吃苦耐劳的劳动者。很多大学生，第一年上班就受不了了，好几年才能适应。而大单位，第一年的工作表现，几乎决定了其今后十年发展。

国外大学和国内大学，哪个可以学到真本领？女儿光是漂亮还不行，要有个谋生的技能。

答：大学不是培养谋生技能的，而是培育完整人格。（例如手不沾水，叫外卖，打游戏，考试作弊，谈恋爱，避孕知识）。国内国外都一样。纯粹的谋生技能，主要是考证书，医师律师会计师工程师分析师，一律考证！

二十年前读大学是投资。现在是纯消费。

读二本，和买一件名牌西装差不多，就是个消费项目。读不读是你的事，读了也不亏，但也不会让你多来钱，大不了去做个银行出纳，小报编辑。旧上海，留学生遍地，真正的上海滩富豪，绝大部分是自学成才的小业务员起步。绝大部分生意是吃苦耐劳攒人品，和什么大学没关系。你就算哈佛毕业，和我有啥关系？
