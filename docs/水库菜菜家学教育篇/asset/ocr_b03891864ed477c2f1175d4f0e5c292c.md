# 二、看清考试本质，掌握学习方法论

# 考试的套路。

考试就是试题，但试题不可能三天两头变化，现在的老师，懒得一比吊糟，基本都是老套路改一下，那么各门功课如何总结出最实战性的简要套路，就是取胜的关键。这个工作，一般是老教师秘而不传的，但说白了也不是什么秘密。偶然遇到年轻老师发神经，出一些歪题题目，不必担心，高考不会考的。当然，这是针对中上水平智力。天才少年其实现就是一个办法，看教科 书，研究教科书的编缉逻辑，无师自通。

# 现在的高考知识点，都是清朝的知识。

教育系统的传承，大概是中国历史最规范的技术传承了。无论风云变幻，老师还是那些老师，教材还是那些教材，思路方法代代传。那都是十九世纪的古老董知识，能改到哪里去啊？我感觉很多老师的潜在思路甚至可以追溯到我大清科举时代。

省重点市重点，在尖子生培训的过程中，确实有很多不为人知的商业秘密，就是如何选拔人才和培训人才。我看见在京沪有几个著名校长，当年就是我们那种打法的培训老师。可能他们后来走了大运，遇到了几个大佬孩子，省略几百字。

大家常见的开学摸底考之类的，就是最简单的识别尖子生的方法。很多劣质中学的摸底考，只知形式，不知内涵。我们当年的摸底考，根本不是靠题目，而是考体系。就是通过不同题型组合，考察你对这个学科的体系认识。分数不重要，重要的是你逻辑是不是流畅。

还有一个常见的是，高三分班。现在已经异化了。当年我是高二就分班。我是化学班小 班。我的智商，拿不到物理奥赛名次，只能被当做次品，送去化学小班。当然，这是省市级名次，不是班级名次。到正常班级，我们都是那种战神一般的学生。老师从来不找我们麻烦。

说了半天，什么意思呢？高考的知识点没有改变，高考的基本试卷没有改变，老一套的培训方法，其实还有巨大现实意义。如果你们要找超级补课教师，最好去找区重点校长给你推荐。他们很多人当年是奥赛培训班老师出身。
