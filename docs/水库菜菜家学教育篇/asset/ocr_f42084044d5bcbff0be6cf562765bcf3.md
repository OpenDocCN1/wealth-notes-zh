# 五、职业教育，学门手艺

社会主流人群是在六环外。

在改革开放初期，少量的国际化人才，会外语，吃西餐，那是需要的。大家都不会，你会你厉害。但是，这种人才的需求量是很少的，大部分的岗位需求，还是干活卖力气。

现在，我们幼儿园就开始教英语了，翻译笔，扫描软件，比比皆是，一般性的外语需求，已经供大于求了。不仅仅是外语，其他各种学科，也是供大于求。博士也很难找个大学职位了。副高满地走，根本没有多少需求。

市场经济，最需要的是实实在在的劳动成果，给我带来明确效益。贴瓷砖，炒虾仁，做裤子，哪怕是 KTV 里小姐姐教我唱个歌，我都愿意付款。唯独副高，真没几个人感兴趣。你会啥？除了满嘴跑火车，你倒是给我说个明确的事情？没有，都是模拟两可，含含糊糊。

建议：除了家里有大企业可以接班的国民女婿，其他人最好是去学一个实用技术。如果你不幸学了经济学，你也要像菜菜那样，把经济学讲出二人转的感觉。人家就当是听一场笑话，赏你两个大子。

大部分人，只要掌握初中语文和小学数学，就可以应付正常文员工作了。

黄埔军校，按照现在标准，不过是短期培训班而已，名将云集的前五期，读六个月就毕业了。民国时期的军事最高学府，保定军校，相当于大专，学制三年。98 年后大学扩招，其实是为了延缓 98 年大下岗时期的就业困难，把文凭彻底稀释了。

任何一个经济体的就业结构，还是二八效应。20%的岗位需要专门知识，法官医生会计师工程师等。80%的人是操作工，一共十个动作，只要培训几天就就行了。把 80%的人拖入无休无止的读书竞赛，对整个社会是巨大浪费。

扩招前的教育制度是对的。大部分人在初中就知道自己不是当工程师或研究员的料了，早早的去炒锅子当厨师，现在反而是高收入人群，五星级宾馆厨师长。那些磕磕绊绊考上大专的，反到下岗了，浑浑噩噩大半生，现在是网骂的主力。

如果你家孩子是块读书料，能够考上 985，还是要支持。如果也就是个三本高职水平，真不如学个卤鸡爪之类的谋生之道。当然，屌丝是不服气的。他们最喜欢捡漏逆袭。好吧，你咋咋滴吧。

你，几本？
