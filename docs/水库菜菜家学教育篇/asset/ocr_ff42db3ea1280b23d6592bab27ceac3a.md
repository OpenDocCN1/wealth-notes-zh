# 五、老师家访，如何应对

家访，是每个穷孩子的终身噩梦。从幼儿园到工作单位，领导家访基本就是来看看你家房子，没有任何实质性意义，只不过满足一下领导的好奇心，丰富一下人力资源部同事们的八卦题材。但这对一个穷孩子来说，简直是无与伦比的羞辱。你们都知道，我家住在老公房，二十年前的破装修，来吧，嘲笑我吧！

【我建议，中小学严格禁止教师家访】老师有什么事情，不能在办公场所谈，非要到人家里去谈？家访嘛，无非就是去看看学生家里的房子，看看经济条件，顺便可能还捞点礼品购物卡，在办公室不好塞啊。特殊情况，要有校长批准，严格把关。

高中家住破楼梯5楼，老师要家访，很焦虑，拿着扫帚把楼梯从一楼扫到五楼，想用干净来遮掩破旧。上课时，老师提到家庭情况，说大家家庭条件都很好，除了。。除了一位同学。我的脸涨得通红，虽然没点名，但说的就是我。我可怜的自尊心饱受打击。现在一线城市三套，房子能给我和孩子安全感。（求匿）
