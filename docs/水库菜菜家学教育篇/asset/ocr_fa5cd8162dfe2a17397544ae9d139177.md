# 七、高考之后

# 给高三女生家长的话。（拉内需，不用谢）

高考结束后，带孩子去北京花掉十万元。千万不要节约。女儿被屌丝骗了，那才损失大了。

+   x 缦酒店，大概是四千一天。住五天。2 万。

+   买个包包，2 万。

+   苹果手机 + iPad，1.5 万。

+   来回飞机头等舱，三个人，大概 2 万多。

+   最好的馆子，刷一个星期卡，1.5 万。

+   再买几套衣服，lamer，全套随身物品。

这个流程走下来，你家女儿就永远隔离屌丝了。她要是被屌丝免费祸祸了，那才损失大了。这钱不用你出，你只是垫一下，今后加倍收彩礼！

# 我有个心愿。

我要在孩子读大学之前，带孩子去领略一下世界的美好。预算是一套内环线房子，目前价值大概 120 万美元。我们只是财富的守卫者。若干年后，或许被打了土豪，我们有心理准备。这一套房子，是我和菜嫂在十多年前贷款买的婚房，是劳动所得。

孩子长大后，或许可以承接我们的巨大财富，或许是再次从零开始，我们都认。这个世界并不美好，充满了残酷的竞争或者斗争。有时候，甚至是你死我活的拼杀。但是，孩子的童年只有一个，在力所能及的情况下，我们尽量让孩子对世界有个美好的认识，让孩子带着爱长大。

有爱的人，就有朋友。若干年后，还会翻起来的。
