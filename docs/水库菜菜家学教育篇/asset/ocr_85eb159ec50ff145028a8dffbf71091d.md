# 三、小学生攀比，如何解决

**现在孩子们攀比财富的情况非常严重。**

我住的小区有几个小学生，经济条件好，但他们学校的大部分学生是住在老破日。下课后，孩子们结伴同行，自然分群，各自回家。高档住宅小区，玩的地方大，设施多，富孩子和富孩子一起滑车，捉蝴蝶，辨认树木，玩的不亦乐乎。老破旧小区，场地狭窄，没有绿化，车辆乱窜，家长不敢让孩子在外面玩，回家玩手机了。

我家对面有个简易棚小超市，老板娘孩子借读小学，孩子非常自卑，虽然是同行，但他不愿意和富人小区的孩子搭话，因为到了小区门口，富孩子就去花园了，穷孩子就去阴暗潮湿的简易棚了。

我和老板娘聊聊天，问了孩子的学习情况，属于后 40%的状态，一个班 35 人，大概是第 20-25 名。初二就要回乡下读书了。等初三毕业，争取在上海学个什么手艺，例如修车，做小吃，实在不行，继续干小超市。

穷爸爸可能无法负担较高的补课费，孩子成绩差是普遍情况，少数自然开窍的优秀学生例外。现在，富人小区一般都会插几个廉租房，本意是好的，但实际上，孩子们会不会更加虐心？这个需要进一步思考。

**和小学一年级的侄女谈人生。**她班同学上分为几个层次，她勉强挤入第一梯队，因为她家住本学区的第一名豪宅小区，单价十万多的。为了明确各家的排名，开学后不久，第一集团军的孩子们，各自带了小跟班，互相串门。她还有 3 个同学，也住在这小区，都是大平层，她家是小户型。经过民主评议，前三名，势均力敌，她们商量后，为了显示高人一等，给我家小侄女起了个绰号叫“两室一厅”。小侄女伤心的承认：人活着就是看房子！当然，她比其他孩子要好的多了。

**学校里的阶层分化，或许是不可避免的。**

我们要做的是，如何教育引导孩子们正确对待贫富差距，尽可能淡化阶层差距，而不是通过明和暗的手段，增加这种分化的深度。家长混的好不好，跟学校没有什么关系。小学那么急吼吼的要知道家长的各种隐私，到底是什么心思，路人皆知。建议：

+   1，教育部门立即停止收集学生家长职务财富的各种隐私，有身份证号码，姓名，电话，邮寄地址即可。不要说什么关心孩子，因材施教，你想什么我们不知道？

+   2，杜绝教育大纲外的各种秀才艺活动。这玩意就是比烧钱。校外文艺课，一小时几百元。学校期末还要组织学生们互相秀，真的没意思。真心喜欢的学生家长，你们课外去艺术学校玩，不要在同学们面前炫耀了。
