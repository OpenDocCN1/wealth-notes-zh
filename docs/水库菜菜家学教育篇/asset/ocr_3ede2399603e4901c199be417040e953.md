# 五、学艺术

# （一）审美是教育立身之本

**（家学）贵族教育的本质，不是你自以为的虚无缥缈的艺术文学，而是审美眼光培训。**

以前，西方技术进步没有现在这么日新月异。发财靠的是审美眼光。你把一个钻做成漂亮了，就是珠宝世家。你把包包做漂亮了，就是路易威登家族。大清王爷，天天搞些古玩字画，你以为他们很蠢吗？不是的。以前没有什么电子仪器，就靠鉴赏审美的眼光，这是可以当饭吃的。当然，谁也没想到后来是计划经济。

我家孩子得过一个民营唱歌比赛的全国一等奖，还发了个金牌。我事后把莱娘骂了一顿。孩子连个字都不认识，你就搞虚假教育，像话吗？后来，我家再也不参加任何比赛了。那个奖牌收起来放在鞋柜里了。现在孩子基本忘记此事了。

数学成绩和审美眼光，是教育的立身之本，其他都是虚的。比赛买个名次，还不如去美术博物馆看看。人物造型，人群排列，色彩光线，物语搭配，大师名家是怎么做的。举例，有一副名画，德皇加冕。画里面有几十个人，但他们排在一起，非常和谐，你看不出哪个突兀。

但是，你要是自己画一幅画，有十个人，怎么排列造型，你根本玩不转。水平达不到。小孩子肯定看不懂，但你可以稍微解释几句。这是潜移默化的教育。

很多人说，贵族教育玩艺术，是虚的。那是你不懂，没有家学传承，自以为是。

**我们大部分人都没有审美能力。**

前段时间出去旅游，我在风景区随机找了几个貌似中产阶级的中青年游客，帮我拍照片。他们拍照技术非常差，就是人物放在当中拍一下，当然，我不怪任何人。我的结论是，大多数人缺乏对美的欣赏能力，也不太会创造美。

这个情况是非常普遍的。我们从小到大，就看分数和职务，从来不考虑美化生活。装修就是买贵的。如果谁把刷题的时间用来刷眼睫毛，小刚说你，心思不在读书上，往大了说就是，小小年纪不学好。

大学毕业进入体制内单位，所有的人都非常疲劳。早上八点半到单位，至少六七点就要起来了。晚上六七点到家里，吃饭洗澡就累的半死了，如果辅导孩子作业，根本不用活了。哪有什么心思去发现美，创造美？那个腰围胖了三圈的女人，我也不想多看一眼了。99%的人，就这么昏昏沉沉的混到了五六十岁。最多是有点小地位了，啃两次蝌头。
