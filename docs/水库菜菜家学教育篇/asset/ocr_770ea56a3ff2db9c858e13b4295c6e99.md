移民北欧，北外本科，职员+低价别墅，郁郁寡欢。

留学伦敦，本科熬到了博士，买不起房，回省城三本，讲师。

# 身边事。

女，英国经济学硕士，回沪找了个小外企（卖化妆品）人事专员的工作，月薪 1.2 万到手，天天做报表，填表格，跑劳动局，三天两头要和闹辞职赔偿的外地人吵架，累成狗。工作性质和留学经历毫无关系。老板招聘她的最大原因是，一是安排外国老板亲戚朋友来华旅游比较方便。二是要求她打小报告。

# 留学生，无论是富穷，好吃懒做，好高骛远

绝不可能像当年的福清人，在唐人街烤鸭子，熬的住 20 年。除了澳加，95%是回来的。毕业勉强留下来的，多是临时性五年期身份，和绿卡还远着。这些人最苦逼，大多不是京沪人，无钱无房，文凭不硬，就业困难。我还见过德国留学，回来推销啤酒的，还不如村二代。

# 留学全额奖学金。

哈哈，那是骗外行的。我就是全奖出去的，月光族，留学的小日子还可以，但也是个温饱水平。最惨的是，自我麻痹，晒旅游照片，自以为是，结果错过了一小段上海房价暴涨期，亏到南天门了，典型的占小便宜，吃大亏。当年和我一届，没出去的，早了几年买房，回头一算，我 tm 亏大发了。
