# ## 六、对大学生的建议

**外地同学不要去有著名大学的小地方。例如厦门。**

我的天！满大街都是厦大毕业生。家家户户都能够找到 1-2 个厦大毕业的亲戚。搞笑的是，厦大的专业设置，碾压了你可以想象到一切领域，艺术到化学，法律到物理，经济到政治，还有神奇的人类学，海洋学，银河系最大。走入厦门任何一个单元楼，必有校友。

**给普通男女大学生的建议，加强厨艺。**

做菜真的不难，猪肉牛肉羊肉，海鲜，鱼虾蟹，鸡，火锅，炒素菜，我大部分做的不错。其实也很简单，买菜的时候，让摊主给你搞干净，回来后，按照做菜视频，copy 不走样，保证可以的。会做饭，家庭就有温馨的感觉，其乐融融，小孩子吃的也卫生健康。自己也舒服。

# **【给毕业季大学生的建议】**

再有几天，你们即将奔赴大江南北，在新的工作岗位上开始新的生活。在今后几年内，你们还要找，新的女友，新的房子，新的工作。如果你不能拼爹，那么你要在互联网思维，把自己想象成为一个 VC 投资人，把自己当做资本，寻找可能的热点行业，勇敢的进入，并长期持有。

**大学生即将离开校园。以我不太多的人生经验告诉你，运气比能力重要。**

我的 2 个同学，水平差不多，一个在三四线城市，由于一次大力提拔年轻干部的机会而飞黄腾达（那时小县城几乎无名校大学生），另一个在大城市默默无闻，但赶上了低房价，陆续买了多套房而发财。多年后相聚，互相感叹莫名其妙的人生。

**大学生如何规划今后十年？**

首先你定位自己：交际型（拉业务）还是闷骚型（技术男）？无论哪种，开始都很苦逼，没经验没客户，90%人熬不住，要转行跳槽。天下公司一样黑，各有各的烦。跳槽可以，但不要轻易转行。你就赌十年成才，不行就滚回老家。真正赚大钱的，还是拉业务提成。技术男拼加班熬身体。
