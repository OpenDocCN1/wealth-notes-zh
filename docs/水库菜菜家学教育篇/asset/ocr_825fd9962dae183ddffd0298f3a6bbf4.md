# ＠大牙花：普通人考上清华的秘诀是什么？

答：买下所有的知名参考书，题海战术。做不完，就看一遍。坚持三年，考不上清华，你来找我。

考清华，多少要有点运气。因为作文题和数学最后一题，在短时间内的发挥，基本决定了你是去同济还是清华。英语比较简单，因为是确定性题目。每年的天才没那么多。你把别人看过的书都看了+记忆力好，清华和同济，就是运气差别。清华北大和复旦交大，是同一类候选人群，考上哪个都正常。没啥神秘的。

# 如何考上同济上外华政？

考清华北大复旦交大，需要运气，一个选择题猜错了，就失之交臂了。但是，考同济这样的二流大学，稳扎稳打，还是可以的。我教你个简单的办法，放弃理科最后一个大题，拿 1-3 分即可，把其他题目做两遍，确保全拿分！这是百发百中的办法。

# 奶茶妹妹的高中前男同学。

这同学也是超优秀的，放弃保送北大，但他自己考考清华，结果考砸了，去了个闻所未闻的破大学。这里面说明一个问题，就是最后那个大题目，其实有较大风险性。这类题目，如果你有 24 小时，那种超优秀的学生都可以解开，但是高考只有 25 分钟给你，这就看运气了。你的第一反应如果是正确的路子，学霸可解开，但是你的第一反应错了，再回头，时间来不及了，最后几分钟，慌了。这一门课没考好，影响了考清华，后面几门课，精神崩溃了，基本考砸了。

牛人可能会选择复读，但是复读的心理压力太大，一般人心理压力扛不住，往往就去个二本之类的烂学校。

所以，很多考上清华的，并不一定是历来全年级第一名，可能是全年级前五名的水平，而真的是运气好，第一眼看到大题目，居然想到了最正确的路子，这就叫运气好，没办法。

# 为什么平时成绩好的人，有时候高考不一定好？道理很简单。

平时考试题目，都是以前的套路，没有哪个学校老师会重新写一套崭新的题目，另外编一套考题，这玩意很累人。那些刷题勤奋的同学，平时一般性考试就比较好。

高考的题目，基本是重新写的，很难在参考书上找到基本类似的题目，特别是两分以上的题目，这就看这个学生，会不会灵活变通了。
