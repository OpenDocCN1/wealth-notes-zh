# 我有个不成熟的思路。

我觉得普通二代在混文凭的同时，最好学个技术，找一个变化小，能够传下去的手艺，例如餐饮业，木匠，雕刻之类的。最好不要做大企业的螺丝钉，一换单位就是可能又是从零开始了。

# 天下的学问，都是一层窗户纸。

你隔着窗户纸，永远看不懂。捅开了窗户纸，就那几句话。会计学如此，航天设计也是如此。不要以为航天设计有多难，我家就是搞这个的，也是一张图一张图拼起来的，并不造个汽车复杂。
