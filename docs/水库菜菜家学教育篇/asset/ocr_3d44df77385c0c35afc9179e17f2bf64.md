# **学以实用，方得始终。**

上海老一辈的三甲主任医生，基本是大专文化。现在清一色的博士后了。老医生们干的也不错，划刀子也溜得很。我知道一个主刀医生，原来是文革时侯生产队杀猪的小伙子，见血不晕，调到卫生院帮忙。上海大医院的主刀大师傅，那个年代被下放到乡镇卫生院当赤脚医生。言传身教，慢慢养猪的小伙子，也会开刀了，专攻手腿的骨科打钉子。后来调到市中心医院，补了夜大专，中级职称。

为什么大专生也能搞起来？我说个小奥秘。八十年代，人才奇缺，没办法慢慢悠悠搞了，医科老师也是大干快上，只讲干货，基本不忽悠，三年大专也差不多了。天底下的学问，基本也就是三年熟练工。

当然，这个搞法也有缺点，老主任不习惯写论文，理论总结水平差一点，他们习惯带徒弟，言传身教，后来招了一些研究生，给他当助手，搞搞资料，写写文章之类的。

# **再做个医院的事情。**

医学是实践科学，99%是动手。现在的博士不一定比大专生好用。举个最简单的例子。牙科拔根管，那是要命的事情。我认识一个二本的屌丝医生，心灵手巧，只会拔根管，但是手艺一流。其他博士硕士拔不了，只能交给她。靠这个手艺，原本根木当不了三甲医生的屌丝，现在稳稳的三甲牙科花旦。但是评不上副高。

我有一次问那个杀猪出身的上海骨科医生（早已退休），为什么当年单单就把你从猪场调到卫生院？简直是奇迹。要不是这个阴差阳错，你还在杀猪呢！

他说，其实很简单。护士都是女的，那时候，农村女人胆小，看到骨科这种事情，害怕。我是杀猪的，不晕血，就去了。
