# 为什么我对孩子的考试要求不高？（生活没有标准答案）

我是学霸出身，有超级丰富的考试经验，搞个 985 跟玩一样。但是，我左思右想，我基本放弃了对孩子考试成绩的要求，只要中等就行了，考个二本我就非常满意了。

先说说菜嫂。菜嫂在高中的考试水平一般，也就是个普通大学的水平。以前，我经常嘲笑菜嫂是扩招的恶果。但近些年来，我渐渐发现，读书不太好的人有一些和 985 相反的特点，而这种特点导致了他们的人生好像比我们快乐。

二本狗的特点是，不求甚解，敢于瞎蒙。不求甚解是因为笨，实在搞不懂。全部搞懂了，那不就是 985 了吗？敢于冒险就更简单了，反正搞不懂了，但又必须交考卷了，那就蒙一个，也可能蒙对。

我们 985 不是这样的。任何题目，必须搞明白，一丝不苟，精益求精。我们不喜欢蒙一个，我们对每个题目都想知道标准答案。这种思维伴随了我们整个人生。

学习阶段，每个题目都有参考答案，只要投入，必有结果。这也是我们 985 的法宝。但进入社会后，人生的各种题目就没有答案了。深思熟虑和蒙一个，结果差不多。而且，985 过多的浪费时间去研究没有标准答案的题目（风险），反而大量的错失了机会。二本狗没有心理负担，走到这一步了，随大流，蒙一个，效率奇高。

在实际生活中，我和菜嫂的分工自然而然的走到了一个搞笑的局面。遇到实在无解的题目，我往往反复犹豫。最后变成了，她是领导，负责瞎蒙。在她拍板后，我只能认账，负责落实。落实细节，是我们 985 的长处。结果，各种大事情的最后效果，90%是好的。如果单凭我个人，实际上可能是放弃了，苦自己。

菜嫂敢瞎蒙，就不怕蒙错了吗？还真不是这样的：

+   一，有时候，选 A 选 B 都不错，最怕的是你没参与。过去这么多年，中国经济稳中向好，高速发展，导致了一个你想不到的结果：做比不做好，买比不买好。这是 985 无法预测的，只有 250 才能蒙对。

+   二，菜嫂家里有钱，蒙错了，也扛的起两次失误。事实上，没有出现重大失误。这和我落实细节也有关系。

+   三，250 必须配个 985 去落实。任何决策，关键是落实的人。菜嫂把我利益捆绑了，我不得不替她尽心尽力办事。这也是我时时刻刻想通的原因。

结论：太精明的人，只算小账，不敢算大账，往往错失机会。
