# 分析“假障碍”里面的留白

就算资讯和意愿都讲了，我们还可以分析她讲“我希望我们只是朋友”的意愿部分的语气比较强？或比较弱？若“意愿”部分讲得弱的话，她还是有矛盾。

注意，我只是说她有“矛盾”，这不表示她喜欢你，这不表示她喜欢你，当然如果她的“资讯”和“意愿”都跟你沟通得毫无矛盾的拒绝你，你应该是没有机会了。

我们的一个学员在追求一个女生时，一切的反应都很好，然后他开始第一次牵女生的手，没多久女生就问他：“你为什么牵着我的手？”而他就很听话的放开了。

请问女生有叫他放开手吗？女生有回避吗？她这个问题的留白是什么？

为什么我们的这学员这么听话呢？

他其实只是“没做贼的心虚”。

而我也见过不少的女方在男方表白后，因为自己已经有了伴侣，所以她拒绝了男方。不过，拒绝了过后都会问男方：“为什么会喜欢上我？”

这虽是好奇，但好奇背后的留白可能就隐藏着一些种子。我不是说女人不能好奇男人为什么喜欢她，我只会说若一个男人对我表白说爱上了我，我是完全没兴趣问他：“阿强，为什么你会喜欢上我？”

就算这女人喜欢上了我，若我对她没兴趣，我也是没兴趣知道她为什么会上我。除非这女生让我有矛盾，又或者我对目前自己的伴侣有矛盾，我才可能会在拒绝她后问她：“为什么你会喜欢上我？”

所以，如果一个女生跟你牵牵手后而讲了这一句话：“以后不要牵我的手，因为我的手只是给男友牵的。”这一句话的后半段其实是有留白的。

# 从行为看对方的留白

就算对方讲了“资讯”和“意愿”后，最终极的审核就要看她的行为，她还是不是照样的常常很想见你？是否应邀必赴？肢体上的触摸能否更亲密？

如果是的话，她还是很小意识的希望跟你可以发展下去，现在的主导权就在你手上。如果你真的守着做朋友的距离，久之她也会冷却下来；如果你是想要更进一步的，你要就继续的逐步升温。

女生跟男人讲“我们只是好朋友，不可能是情人”，或者说“我很爱我的男友，所以我跟你只能保持朋友关系”，但之后照样的在电话上聊六个小时，照样的常常跟你约会，跟你身体上的触摸越来越亲密。而且在做了这些举动后，还是照样的跟男人说：“我们只能做朋友，不可能做情人。”

很多男人在这时候就会崩溃了，因为他不知道怎么办。
