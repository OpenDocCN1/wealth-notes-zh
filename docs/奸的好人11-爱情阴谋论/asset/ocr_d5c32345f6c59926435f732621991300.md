# 肤浅精子的忏悔录

信心主宰男人选对象？

曾经有一个两性关系的作家写到，信心高的男人找女朋友的话，往往会找有外表的，而信心较低的男人则喜欢找有内涵的女人，他的结论是高信心的男人注重自己女人的外表，低信心的男人则注重女人的内涵。

但我则有不同看法。

我认为就算低信心的男人也是同样的喜欢外表，只不过他们缺乏方法或认为自己没有能力去追而已。

甚至一个男人若喜欢上某位“样貌平平”的女生，并不代表他不注重样貌。这个样貌平平的女生在某个层次上，还是有“样貌”。也就是说她的样貌的某种角度或有某种风味，让他觉得有点“爽”，他才会对她有兴趣。

所以就算一个男人认为自己选的情人不是他心目中的美女型，但他肯定还是为了对方的样貌或身材而动了心。所以，口口声声说“样貌”不重要的男人，我对他们的言论有很大的保留空间。

# 一个觉得女人外表不重要的男人

曾经多年前我在举办念力课程的时候，分享了多个学员们进行增加桃花运的“紫花冥想”的见证，见证中免不了就提到一些男学员的艳遇等等。有一个五十多岁的男人当众问我：“为什么你所分享吸引桃花运的例子提到的都是美女？其实在爱情里面，外表不是最重要的。”

我当时官腔式的答案是：“男人追求外表之后，若只顾外表而忽视了内涵，他将会得到他的教训，那么他以后才会欣赏内在美。”
