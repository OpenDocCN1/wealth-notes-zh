# 男女出轨的数量的诡异差异

根据很多个不同的版本的统计，伴侣出轨的数据有很大的差异，但基本上都是男人天大的高出女人出轨的机率。出轨的男人从百分之六十到七十，而出轨的女人则是从百分之三十到四十。若我以男人的最高数据（百分之七十）对比女人的最低数据（百分之三十），这两个数据的不对称有点诡异。难道那百分之三十的少数女人就和那百分之七十的多数男人轮流的玩吗？

出轨或劈腿数据常被批评的地方就是资讯来源的准确度，保守的人往往不参予这种问卷，甚至若参予的话，有很大的可能性撒谎。而女人因为被社会所灌输，女人出轨的极度负面形象，她们若参予这种调查的话，我会相信女人回答“有出轨”会多过说“我没出轨”。

同样的，一个人若不负保守而且还能够坦荡荡的分享自己出轨的人，他的答案虽比较诚实，但他不能够毫无偏差的代表了“普通人”。
