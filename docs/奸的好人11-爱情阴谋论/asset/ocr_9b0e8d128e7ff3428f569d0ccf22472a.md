# 由竞争而生的在乎

爱一个人就是在乎他，在乎他才会妒嫉，这只是“爱情信徒”的宗教理念。

在“爱情行者”的眼中，他会看到更多的可能性。他承认爱一个人会在乎他，但他也会问：“在乎一个人，是不是就一定等于爱是对方？”

广东人有一句话叫做“瘦田无人耕，耕了有人争。”

本来我也不觉得自己对“阿花”有兴趣，不知怎的，有一天我看到“阿强”跟她打情骂俏，“阿花”虽没表态喜欢他，但她却笑得粉脸怀春的，忽然问我可觉得我起码会对“阿花”好奇了。

一些结了婚的朋友也告诉我，结婚之前的他，因为样貌平凡，女人缘也不是很强，但是很奇怪，一结婚而戴上戒指后，有些女人纷纷的开始对他有兴趣，搞得他很迷迷。

我问这些朋友迷茫些什么，他们的答案是半开玩笑，半认真的说：“我迷茫该不该这么早结婚啊，婚后不久竟然会发现自己的真实魅力和市场价值，价值都是虚幻的

其实我想说：“这个不是你的真实市场价值，它是被环境或技巧营造和扭曲出来的。”

这个婚后现象可以从两个角度来解释，其中一个角度就是所谓的“禁果”现象，已为人夫者即为其她女人的爱情禁地，但恰恰的被禁的才有吸引力。

另一个角度则是“瘦田无人耕，耕了有人争”，这是一种羊群心理。一个东西本来是没价值的，但这家伙结婚了就表示他是“有人要的”。羊群心理就是既然人家要的，就表示那个东西有价值，而有价值的东西我就当然要了。

江郎鬼才有话说：价值是假的，它是从供应和需求的对比之下产生的。
