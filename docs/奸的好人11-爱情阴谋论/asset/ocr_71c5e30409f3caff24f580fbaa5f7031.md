# 告诉她有男友的第一个理由

第一个可能性就是为了要打发你，一般是发生在被追求的初期，她知道你想追她，你擦不出火花的同时又让她开始觉得闷、不安、甚至有压力，这时候就会丢出一些理由来阻碍你的更进一步。
