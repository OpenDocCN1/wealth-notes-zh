# 头身分离

通常是两个极端：一，下半身好像不听唤使，控制不了的一下子就早泄，根本没有机会享受性。二，因为头身分离的关系，快感的接受好像抽离了，搞来搞去心里只会觉得“‘What’s the big deal?！有甚么大不了？’”结果还是照样地没办法享受性。

反之，女生的性行为动作会比较全身式，而且也因为全身各部分在性行为时是连接着的，所以相对的也比较投入，更能“入境”。

什么叫做“全身式”的连接呢？

大家可以到夜店去看男人和女人跳舞时的分别，而这个两性跳舞的分别就可以解释为什么女人更喜欢看到梁家辉在电影《情人》中的床上表现。

# 入境……身、心、灵的同时投入

在 Club（夜店）里面，你会看到大部分的男人在跳舞的时候，上半身和下半身是切断了，有的舞姿是马上下半身为主，上下半身的动作其实只是应酬他上半身的舞姿而已。反之，大部分的女人，上半身和下半身的舞姿是比较能协调的。

跳舞的时候，若全身连接得流畅的话，动作才会有“灵魂”，旁观者会觉得这个舞者有 Presence（注：华文没有一个字眼能够准确的翻译 Presence，勉强的翻译是一种“全然进入当下感”）。

Presence 一宇的技术性不够强，所以在英文，这一字往住沦为浪漫废话。反之 NLP 圈子却用了另一个字来诠释它，这个字是 Congruent“一致性”。

# 女生为什么喜欢会跳舞的男生

夜店中的男性舞者因为上半身和下半身的分割，很多是跳得生硬，甚至是跳得好像一只有智障兼小儿麻痹的鸡，因为身体的各部位在动作上连接得不好的话，就会导致身心内外不能一致。

专业的舞者，或者是跳舞跳得好的人，其动作、呼吸和念头都需要一致，如此自己才能投入，也会让人觉得你的舞是真舞，而且还感受到你的“舞魂”。

有“舞魂”的舞者会让人觉得你那种跳舞的纯粹感和当下感，而不是机械式的跳舞。
