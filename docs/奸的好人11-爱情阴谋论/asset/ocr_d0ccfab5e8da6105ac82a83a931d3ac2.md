# 使女生开始主动打电话给你的方法

其实这个方法是男对女，或女对男都行得通，不过这个方法的前提条件是：你没有在对方脑中留下不好的印象。如果她已经开始回避你，则行不通了。

这个反客为主的方法就是：你先每天或每隔两天，定时、定量的打电话给她，一两个礼拜后，你就忽然间摘失踪。

而且若要制造更强的心灵空虚，你每一次所打的电话，是讲到最高潮或对方听到最开心的时候，就是你要挂电话的时候了。

> 江狼鬼豹有话说：在最高潮之后就挂电话，你会在对方心中制造下一次“电聊”的期待感，反之如果你每一次“电聊”是在最闷的时候挂电话，下一次的期待感就不强。

而且因为大部分的时候都是你先挂电话，在女方的脑海中播下了一个种，这颗种子是一个假象——女方觉得每一次的电聊都是她想跟你聊多过你想跟她聊。你甚至还可以就是大部分的约会，都是你先讲“时间不早了”。

这个情况跟很多分手反应是一样的，先提出分手的人会让另一方觉得自己被人遗弃，然后可能就会产生不甘心的尝试要挽回破裂的感情；而真实的情况可能是双方皆觉得这段感情没有什么发展空间了，但很胡闹的是：如果是我先不要你，你发现是觉得你好像还没有一点要我。

所以每一次的电话沟通都是你先挂电，女方就会渐渐的有错觉了。

注意，我说的挂电话不是你讲了一个笑话给对方听，她在“哇哈哈哈”的时候，你就趁其不备的“噗！”而盖她的电话，然后对方在电话的另一边能量最低点。正确的做法是在“电聊”的气氛上涨时，讲个要挂电的理由，如：“哎呀，我的朋友来找我了，我现在要跟他们出去喝茶。你早点睡啊，不要让我妈妈担心。”甚至说：“Oh shit！不知吃了什么，我的肠胃很感动，我要大便了。下次再谈。”

如此每次电聊都制造了期待，而且每次都是定时打电话来，那么在你忽然间不来电的话，对方忽然间就会有一个假的“空虚感”被投射出来了。

失踪后的同一天或第二天，对方就会有点不习惯这个“空虚感”，然后可能就会反客为主的打电话给你。
