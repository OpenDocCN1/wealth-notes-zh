## 宗教的起源

目前的进化论心理学家认为宗教的起源来自于“失误管理”，它是要用来管理两种主要的错误，就是，“肯定”和“否定”两种错误。

宗教信仰的“失误管理”其实就是一种赌博，是一个十七世纪著名的法国宗教家 Pascal 的赌注理论，叫做 Pascal's Wagers。

因为没有人是百分百“肯定”上帝的存在，如果你选择不相信上帝，但他又真实存在的话，这就叫做“否定错”，你否定了一个存在的万能的上帝，你的下场就是永远的地狱受苦。

但是如果你选择了相信一个不存在、虚构的上帝，这个错误叫做“肯定错”——换句话说，你是宁可信其有，不可信其无，若上帝是不存在的，你只是浪费掉一些精神和资源来相信而已。

江郎鬼才有话说：大部分的民间的和宗教的信仰，都是基于“宁可信其有，不可信其无”的模式。

Pascal 的结论是很有“赛局理论 Game Theory”意境的，他说在这个赌注里面，“不相信”的损失会严重过“相信”的损失：相信了虚构上帝，就只是浪费资源，但没信到一个真上帝，死后就肯定会永远移民到地狱去了。所以相信上帝是理智的选择，因为你可以避开更大的风险。

（注：若你是佛教徒，就把上文中的“上帝”二字改成“因果”。）

江郎鬼才有话说：Pascal 的赌注理论或其他 “宁可信其有” 理论，是有很多误导性元素的。

- 第一，这个赌注假设了上帝有能力把不信的人在死后打进地狱。有没有可能是就算我不信，他也奈我何问？
- 第二，赌注也假使了宇宙只有一个神，没有其他的神。有没有可能我信其他的神，也照样可以上天堂？
- 第三，有没有可能不管我们信或不信上帝、不管有没有上帝，大家死后都是上天堂？
