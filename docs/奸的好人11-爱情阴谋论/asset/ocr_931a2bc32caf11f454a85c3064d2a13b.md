# ## 经济水平和女人手的关系

在马来西亚我们常见印尼、缅甸等的外劳女佣人，通常她们的手指、手掌和前臂会比较粗大，有的跟男人的手差不多一样。我推测是她们的国家经济水平不高，所以女生从小就要干活，可能还要干粗活，我甚至怀疑也跟遗传有关。如果连续很多代都是要干粗活的，可能每一代的子孙的手就会保持粗。

特别是在马来西亚有不同的族群，其中一个土著族群是“马来人”。我在一九八九年离开马来西亚，在还未离开之前，我记得那时候的“马来妹”是吸引不到我的。但是我在九年后回到家乡，我发现有很多“马来妹”令我垂涎，短短的十年内她们的样貌吸引力有了一个很大的跃进。而且我还怀疑若不是因为娶“马来妹”要强制性皈依回教，不少的华人就会异族通婚了。（注：马来西亚有不同的种族，“马来妹”是拥有最多的臀腰对比是 1 对 0.7 的比例。）

“马来妹”的跃进，应该就跟她们的经济水平提升有关，在我离开马来西亚的时候，马来人的经济能力普遍偏低。但我回国后，他们的经济水平已经获得改善。不过，马来妹虽然漂亮，但有时候还会见到样貌美丽，但还保持手臂接近男人手臂般的粗大。在华人的族群里面，“女人身男人手”的还是比较少见。

在电视上有时候看到一些漂亮的马来女主持人，还是会看到她们的前臂指掌比较粗大。这可能是新一代的交接期。在十年二十年之后，马来妹的这个“女人身男人手”的现象可能就没飞湮灭了。

每当我跟朋友解释“手”和“贵”的关系，他们都笑说我有“恋手癖”，其实这只是我的眼睛和头脑有钻牛角尖的能力。
