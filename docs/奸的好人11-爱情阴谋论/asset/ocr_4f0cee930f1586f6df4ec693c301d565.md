# 甘苦的运用时机

曾经有人研究批评和赞美 的效应而做了个实验，这个试验共有四组。第一组的人先被赞美，然后再赞美；第二组的人就先被赞美，然后再被批评；第三组的人就先被批评，然后再赞美；最后一组人 就先后都被批评。

然后四组人都要为这个批评或赞美他们的人的印象打分数，他们发现第三组被“先贬后赞”的人所打的分数是最高的。

因为贬和赞有强烈对比，所以“先贬后赞”的效果就会比“一赞再赞”更好。

在我 和这位爱尔兰大学毕业生的互动中，我虽没有批评对方，但是这个女生对我的这句废话有这么大的反应，还要拜我之前得罪了她所赐。我运用的这个版本就不是“先贬后赞”，而是“先有冲突，后有了解”。

我就在告诉她我了解她时，间接的讲了她喜欢听的话。
