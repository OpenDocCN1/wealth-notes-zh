# 教会的私心，女人的欢呼

在十世纪之前，皇族或贵族若是老婆不能生孩子，老公可以要求离婚再娶，因为他们需要有能够承接财富的后代。但是因为遗产的分配出现问题，导致教会插手促使贵族们流失更多的遗产。

在是十世纪后的基督教教会不断刻意的修改婚姻法律，例如当时的基督教徒还要遵守复活节时三个礼拜禁欲条例，圣诞节时有四个礼拜不可以搞自己的老婆，在圣灵降临节需要禁欲一到七个礼拜，而且在星期天、星期三、五和六为布道和忏悔日，也不能有性行为。

嘿嘿，教会真变态，因为一年下来的话，最高记录共有三百零八天不能有性行为。

除此之外，当时的基督教把法律改成就算老婆不能生，也不能离婚，不能离婚就不能再娶，要老婆死了才可以再婚。同时男人也不能领养一个孩子来成为家族合法继承人。（注：今天的传统基督教徒还是认为离婚是有罪的）

为什么要这样做呢？

哈哈，教会是有私心的，他们修改的原因是用来确保某群体的人越来越少后代，特别是皇族和贵族若没有后裔的话，他们的土地和产业将会归教会所拥有。

这个十世纪的教会私心还有另一个理由，当时很多的贵族都是把财产遗留给长子，其他得不到财产，心有不甘的小儿子，很多都被天主教会招揽出来当神父，所以在教廷里面很多这种不开心的富家子弟，这是很典型的“被剥夺遗产的神父复仇记”。

所以，婚姻神不神圣是见仁见智了。

但相信宗教的人知道一个真相：“就算再荒谬的信仰，自己的宗教永远是合理的，而别人的宗教永远是不合理。”

婚姻是理性的产物，爱情则是不理性的，甚至是不合理的。
