# ## 垂帘听政的“章子怡”

这些统计没有错，女人也没有完全说谎，女人心中确实是有个“章子怡”，这个“章子怡”是女人从万年进化以来的基因需求。但市场上绝大部分女人的“章子怡”是不会直接以真身出现，她只是尝试在幕后的操控。

就好像章子怡演《卧虎藏龙》中的玉娇珑般，观众是不能以自己所认知的现实版章子怡来了解玉娇珑。我们虽然还是能够一看玉娇珑就认出那是章子怡的脸蛋和五官，但她的声调、举止、性格却是玉娇珑。

江南鬼才题外话：虽然我常开章子怡的玩笑，但她是少数能够以细微表情演绎出意境的华人女演员。女生可以参考她在《英雄》中为梁朝伟梳发的那一幕，她真的能够演绎出女人能为心爱男人梳发的那种开心，特别是梁朝伟微微转头注意一下她的时候，章子怡展露的那种笑容就好像一个天真婴孩的灿烂微笑般。

她能够成为今天的章子怡，不是纯靠“章子怡”，她确实是有下过苦功，她是少数能集样貌、演技和手段在一身的明星。

虽然女人喜欢男人的条件是：有钱、地位、上进心、高教育、安全感、对她忠心专情，但这些“条件”都不是直接以“真身”出现。

# 为什么女人不完全受基因的影响？

可能读者会有一个问题：“如果这个进化论是对的话，那么我们男人不就是喜欢生孩子吗？而女人就是喜欢找有钱的男人？

就好像《圣经》说上帝创造了人类，理论上人类应该是百分之百的恭敬上帝，然而上帝又给了人类自由意识，变成人们又有自主权选择要不要相信上帝。男人女人虽在基因上的择偶需求确实是跟“生存”和“繁殖”有关，但人类又有自由意识，我们甚至还找出上帝的漏洞。

所以我们会看到一个女生自觉男友很有才华，但从我们旁人眼光来看，那个男的却是一个没出息的家伙。如果每个女人都很清淅的知道自己的“章子怡”，那么，我的“追女班”肯定是没有市场需求了。（例如：章子怡就明确的知道自己的“章子怡”）

江南鬼才有话说：追女班这种课程具市场价值，是因为一般女人在爱上一个人的时候，她爱你的“潜能”多过爱你的“实力”。
