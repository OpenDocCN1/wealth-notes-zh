# 妓女的智慧

曾经有一次李老师跟我分享了他在香港的《苹果日报》所看到的一个性服务广告，这个广告的特别之处就是要“过关斩将”。广告的内容大概是第一关是用口，如果嫖客不泄的话，才可以过第二关的“冰火交替”，如果第二关又不泄的话，才可以过第三关……

我马上就笑问：“哈哈，那么是不是越越多关就越有折扣？”

李老师说：“没有，反而是每过一关，嫖费就跳一级。”

这个广告很针对男人的“征服感”的需求。

而一位读者在看了我们的《心魔行销》后，就告诉我一个性工作者如何对他做“假障碍”的方法。基本上在交易之后，女方在穿着衣服时跟他说：“幸好你刚才没有要我在上面，不然的话我会玩到疯掉。”

这位小姐很聪明，因为经她这么一讲，客户会很好奇到底她在上面的表现又会如何，因此她很可能就制造客户的第二次光临了。当然我推测她对有机会成为常客的男人才会出这一着，但是如果遇到的是国外游客，他们成为常客的机会几乎是零，她就不需要浑身解数的出动心理策略了。

可能就算她真的在上面搞的话，也没什么大不了，不过这确实是一位明白男人“征服感”的性工作者。

# 男人的要害

普通收入的男人可能喜欢嫖，但一个很有钱的商人未必喜欢找普通的妓女。他们喜欢花更多的钱到夜总会跟小姐们喝酒、把欢、唱歌、猜拳、聊天。甚至还要谈心。小姐们也不会那么容易的让老板上到她们，夜总会小姐不像一般妓女小姐一进客房套几句后就马上脱衣上床，她们还要跟老板们“培养感情”。

小姐们马上跟这些高级嫖客赔的话，客户反而感受不到挑战，但在这些大老板的“诚意”之下，小姐们才渐渐的“软化”，才叫做过瘾。简而言之，这些高级嫖客都要买一个——“征服感”。

甚至如果这些大富豪更有钱的时候，他们想征服更具有挑战性的名模或者女明星。那时候就花更多的钱和心思，基本上买这种挑战是一种地位上奢侈的炫耀。

> 江郎鬼才有话说：男人心中的意义和价值在于“征服”，这跟男人的睾酮素有关，因为统领者的睾酮素都是偏高的。

这是男人最自豪的，也是他的要害。
