# 男女都是不合理的

上帝使女人的卵一个月只有一粒，女人一生只能生产四百多粒，但男人的精虫却每天有上亿的数量，而且还可能到老死前还能生产精虫。请问上帝合不合理？

样貌普通的女人在化妆和装扮后，变得很有吸引力，使男人目不转睛地望着，但没化妆的时候，她的样貌又回复普通。合不合理？

我在课程中教样貌和口才普通的男人，如何以特定的谈吐，很快的跟女人擦出火花。合不合理？

不只是女人摸不清男人，很多男人也一直摸不透女人，因为双方在用着不同的模式来互相了解。

# 男女看爱情的两种相反模式

女人倾向于“宗教信仰”的模式来看待爱情，男人则是倾向于以“商业经营”的模式来思考爱情。这两个模式在面对上完全不同，所以才会互相觉得对方的不合理。

“宗教”会觉得“商业”亵渎了神圣的爱情，同时“商业”也不明白“宗教”的精神到底有什么价值。

女人面对男人时会说：“你怎么能够这样来看待爱情？”而男人则会想：“吓？为什么这个不是爱情？”

女人因为以宗教角度来看爱情，所以会觉得爱情这个东西是“有就有，没有就是没有”，是一种缘分，是一种 Feel。

所以很多男人对女人付出后，女生没有了 Feel，就不能接受男人的爱意，她是没有任何解释的。男士若笨得问女人“为什么你不能接受我？”

他得到的答案将会使他更迷茫。

# 上帝是不需要合理的

就好像宗教般，你不能过问上帝的决定，因为上帝的旨意是人类的智慧所不能明白的。同样的，女人给男人的答案永远都好像一个怎么猜都猜不中的谜语，她既不肯定，也不否定。

所以不少的男人都有这个经验：“明明她的信号是对我有意思，但当我要更进一步时，她们的反应又好像我犯了‘连尼姑也非礼’的滔天大罪似的，让我无地自容。”
