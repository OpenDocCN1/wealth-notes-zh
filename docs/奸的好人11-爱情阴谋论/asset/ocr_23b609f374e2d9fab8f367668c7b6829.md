# 射精和爽是两回事

根据生理学家的研究，男人身体上负责射精和负责高潮的，是两组不同的肌肉。往往是两组肌肉一起被启动，但事实上是可以训练到高潮时，只启动高潮的系统，但射精的系统却可以处于休息状态。

+   所以，一个经过修炼的男人，高潮基本上可有三类：

一、有射精；二、强行性的不射精；三、非强制性的的不射精。

其分别在于高潮的时间长度，男人高潮的快感是取决于下体的涨缩（Contractions）频率，一般男人有射精的高潮，其时间大概是三四秒而已。那种“非强制性的无射精高潮”的长度通常是普通版起码双倍以上，我的个人记录是十多秒到半分钟的高潮（这是最高纪录，不是每一次都能如此的延长）。

因为射精和高潮是两组不同的肌肉，射精是没有快感的，高超的快感是来自下体那种重复的“涨缩感”，而且就是每一涨缩就有一阵的快感。

普通有射精的高潮，通常涨缩快、次数少（三五次），但没射精的高潮会涨缩得比较慢，同时涨缩的次数多（我试过状态良好的时候，可涨缩十多二十多 次）。所以，无射精的高潮就可以把享受快感的时段拉长。据说著名的国际歌星 Sting，是可以把这个短暂的高潮拉长到整个小时，在这种特慢高潮时，一次“一涨一缩”的时间也会被延长到一分钟以上。

要达到这个境界其中一个主要的修炼，就是要“集中精神”，反而不是数绵羊的“分心”法。精神的集中才能对快感程度的察觉能力增强，你才有办法很明确的知道哪个程度才是所谓的“临崖勒马点”。
