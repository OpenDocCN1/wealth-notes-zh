# 古代男人性生活的极端典范

古代中只有非常少数的文化是一夫一妻制，其他的全都是一夫多妻。目前的一夫一妻是基督教的教义（新约的）。旧约圣经中传说很有智慧和道德的所罗门王却上有千个要妾。

所罗门王道不道德呢？

古印加文明的皇帝收藏着一千五百个漂亮的处女，以前的一个非洲皇帝是有权搞全国的任何一个女人，印度的乌达雅马皇有一万六千个妻妾。而我们华人皇帝的后宫都不会少过三千，唐朝的皇帝还有专人记录所有后宫的经期日子，以计算好排卵带给皇帝播种。

在古代的时候，老头伙有钱有势的话，娶一个十多岁女孩娃来搞搞是不稀奇的了。在古印度、中国和西藏，有些修行人想搞采阴补阳的双修时，可能会选刚发育的女生来做自己“道侣”。

西藏佛教的一位祖师爷“热罗 Rva Lotsawa”共有五位太太，最年轻的一位嫁给他的时候只有十一岁。甚至还有一个全世界最多人信的教。其创教教主本身共有二十七位太太，其中一个最年轻的被娶过门时只有九岁。

以我们现在的价值观，很难接受一个正常的成年男人为什么会会对九岁女童有那一方面的欲望，以现代的法律来做标准的话，这个以前的创教伟人是要被捉去坐牢（而且在牢里他的生活也不会好过）。

所谓的神都是雄性的？

但古代的人，特别是有地位的女人，确实可能是在思春期就要嫁给他人了，原因很简单：越早嫁人，她就有着越大的可能性还是处女。而她的责任就是要帮男人生孩子，生越多越好。如果女人淫乱的话，这个男人的家族就很有可能花掉了自己的资源来养育人家的孩子，所以男人就立了很多律法来控制女人。

在古犹太教的经典 Torah，通奸罪只是实施在女人的身上，已婚男人不能搞人家的老婆，但是跟另一个单身女人搞是许可的，而大部分的文化中，男人要搞妓女、女奴仆等，只要不是搞人家的太太，都是无罪。但女人一旦搞了自己丈夫以外的男人，可能就会被杀，而且是先虐再杀。

为什么古代的男女性道德观是此的双重标准？

因为这些道德观标准都不是神写的，它们都是人写的，而且还是“男人”所写的。

而且你知道为什么十诫中说不能搞人家的太太吗？哈哈，因为这些都是男人写，男人不要其他的男人搞自己的太太。所以，所有的道德观、通奸罪都是宽待男人和严惩女人。
