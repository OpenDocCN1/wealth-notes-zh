# 一个让我一生难忘的胸部

同样的，就算女人的胸部小，还是能够选择高姿态展现“乳谷”或“乳沟”（即是要用胶布把双房的距离贴近而制造乳沟）。女人甚至可以穿得密实而胸部低调，也可以穿密实而使人高调注意她的胸部。

我还记得一个很少见面的女性朋友 S 小姐，样貌只是中上，身材是“空前绝后”的（即前不突后不挺的意思），但是我有一天在咖啡厅碰巧遇上她，她穿的衣服是普通的办公室衬衫，胸前的纽扣开得很冇策略。松开的两颗纽扣和柔软的布质，让她胸前的缺口摇摇欲现，我只能说这种若隐若现的柔柔内肤，才真的要命。

老实说，若我要看色情电影的话，我很肯定是不会看以她为女主角的戏，但那一趟邂逅让我在聊天的整个小时中心神荡漾，同时又要很辛苦的集中精神维持自己的君子风度。

> 江郎鬼才有话说：我当然喜欢看胸部，但是，我还是要在这里向 S 致敬，因为这个让我印象最深刻的胸部，竟然是“没有胸部”。

我只能说我们男人是笨的，一个若隐若现就使我们神魂颠倒。而我跟其他男人不同的地方是：我也笨，但我知道我笨。

男人都看外表。

曾经跟李老师和李师母讨论到这个男人笨的习惯，我和李老师都坦承我们是肤浅的男人，选女人的话，要看了样貌才算。

李师母就对李老师抗议，她说李老师不是看样貌的男人。

她跟李老师说：“不对，你怎么说你是看样貌呢？好像老江这一类型的，看女人看到成为专家的，看人家一眼就能看出身体对不对称，这种人才可以说是为了样貌选情人啊。”

我知道李师母的意思，因为曾经有一个美女学员来上课，众多男学员对她垂涎，之后还听说有几个尝试追求她。不过我则是改不了自己的职业病，第一时间就听出她的声音有问题。我觉得李师母最好奇的地方是，我竟然只瞄了这女学员一眼，就道出了她很多人都没留意到的臀部形状。
