# 男人和牛的同与不同之处

而科学家所做过的其中一个试验就是有两组的公牛，第一组的公牛只是跟同一只母牛不断的交配，第二组的公牛则是每次交配的时候都有一-只新的母牛，而科学家们则度量公牛射精时的精液量。

他们发现第二组的公牛在跟同一母牛交配下，每一次的射精含量会逐步减少，但第二组的公牛，当它们跟第六性伴侣（母牛）交配时，第六次的射精量还是跟第一次的射精同样。

那么这是否代表了每个雄性动物，包括男人都有偷情的需要？

这个试验在人类应该比较难做到正确的测量，因为第二组的男人可能会说：“第二好比较骚，第四号比较邻家女生，我喜欢骚的，所以第二次的射精含量会多过第四次。”

而且男人跟牛不同的地方是，若这位喜欢骚味的男人被安排到跟一超骚娘搞的话，他还可能贪玩而不断的延迟射精，而这种控制射精的行为可能会导致他最喜欢的可能射得最少。

> 江郎鬼才有话说：你若问男人是不是想搞不同的女人，是个男人中有七个肯定说“是”，其余三个说“不是”的，第一个是虚伪的，第二个是Gay的，而第三个是和尚。

其是这个试验在猴子、老鼠和狗的身上上都得到同样的结论：雄的贪多，越多性伴侣就玩得越凶。同一个性伴侣的话，就越玩越懒。
