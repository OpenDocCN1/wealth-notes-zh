# 危险和快感的相似

人在危险、恐惧和紧张的时候，身体上就会分泌肾上腺素，肾上腺素会让人心跳加速，甚至还会促进五官感觉加强，变得更敏感。我举出其中两个心跳会忽然间加剧的时候：玩云霄飞车从最高点转下冲和性行为到就要高潮的时候。
