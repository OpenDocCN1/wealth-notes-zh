# 以妒嫉感来测试自己

若要知道自己还爱不爱一个人，其中一个最“勉强”的测试法，就是问自己：“我会不会有妒嫉？”

如果看到我的情人被其他异性青睞的时候，我会不会有情绪反应？

特别是条件比我更好的异性亲近他的时候，我会不会妒嫉？

甚至是比我更好的异性青睞他，而我的伴侣又有给予对方正面的回应时，我会不会妒火中烧？

如果是会的话，你“可能”还爱对方。为什么我说如果你会妒嫉的话，你只是“可能”还爱对方？

难道在乎对方不就是爱的表现吗？

# 在乎就是爱？

上一篇文章我说你可以问自己那个“妒嫉感”的问题，如果你是还会妒嫉的话，你“可能”还爱对方。因为问自己是一回事，正式发生的时候，可能你的反应又不同。有些人可能认为自己不妒嫉，但一见到相似的情景，可能就失控了。

因为妒嫉也可能是“机械式反应”。

很多人都知道若是完全不妒嫉的话，应该是很肯定不爱那个人了。但是为什么妒嫉也可能是机械式反应？

难道不是因为在乎一个人才会有的妒嫉的反应吗？

我见到有些人在过了热恋期后，已经是蠢蠢欲动的想往外发展，经常是半要半不敢要 的跟伴侣以外的异性搞搞暧昧，但基本上自己还是很规范。但，一旦他们的伴侣比他们先往外发展的时候，他们却很想挽回那一段感情。

好了，这个想挽回感情的举动，是不是表示他还爱自己的伴侣？

这是爱还是机械式反应？
