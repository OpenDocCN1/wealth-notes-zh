# 失控的快感

当女人说“爱情来的时候，怎么挡也挡不住”，她是告诉了你爱情不是自己能用技巧来控制的，她相信爱情就是一种“真情失控”。

坏男人在追求女人的时候，让女人觉得跟他在一起的危险不是“被害”的危险，为是一种“自己可能会控制不到自己变坏”的危险。

> 江狼鬼豺题外话：有些人说热恋中的女人最漂亮，有些男人说女人性高潮的时候是最迷人。

其实热恋期的女人固然很漂亮，但她的情绪是很单层次的“甜蜜”，高潮的女人也很美丽，但也是单层次的。

迷人的高潮是多层次的，例如她有高潮，但她微微带着一些罪恶感，所以很多婚外情的性高潮就有这种魅力。

但更美丽的高潮是女方对自己的性高潮微带神经质的矛盾感：她一面的觉得自己不应该如此享受性高潮，但另一方面又控制不到自己沉溺在享受之中。

日本的 AV 片一直都明白这个道理，但却制造不出来。

这种觉得“不应该”，但又“真情失控”的纵涌于这种“不应该”的快感中，女人往往能够在坏男人的身上得到。

女生喜欢坏男人的“攻击性”，不是因为坏男人真的会攻击她，而是坏男人会“攻击”到女人的界限和她舒适区的禁地。

好男人往往喜欢在对方的舒适区里面互动，这个区域的行为只能让你跟女性做朋友、好朋友、姐妹、哥儿们，甚至是做人家的干爹。既然你要女人成为自己的情人的话，你就要她走出她的舒适区。

须知道两只干柴若很温柔、舒服和缓慢的撩，永远是撩不出烈火的。好男人第一个要学的东西是：如何进入女性“失控”的禁地。

换句话说，你要是她走出舒适区，你也得走出自己的舒适区，你可能要做一些以往你觉“不舒服”的行为。

好男人听着，你在女人眼中，是个完全没有“难度”的男人，她知道她只要弹一弹指，说声她接受你，你就会如小狗般的跑到她的身边。然后她弹一弹指说你可以碰他，你就很守规规矩。

你的目的不是要成为一个侵犯者，而是要成为一个——有难度的男人。
