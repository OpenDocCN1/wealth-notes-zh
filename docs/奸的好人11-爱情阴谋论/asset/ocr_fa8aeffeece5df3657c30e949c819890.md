# 第六章 相爱与背叛的机械式反应

# 劈腿后的假赎罪，分手后的假情绪

# 骂权谋的人耍权谋

曾经有一个学员的的女友很讨厌他上我们的权谋思想课程，也不喜欢他看我们的《好的好人》系列书，她说权谋是骗人的，骂我们这个权谋思想很邪恶，教人使坏。某次学员的女友知道了他偷偷的上过我们的权谋课后，她还以此相逼而扬言要跟他分手。

> 汪郎鬼才有话说：一个男人要自己做自己喜欢做的事情、自己有兴趣的事情。女友却不能忍受这个兴趣，我就会叫她走路的。

> 同理的，我也不会要求我的女人为了我而放弃她的兴趣，因为以后她必然会以此事来埋怨我。

老实说，你看到这位女友以分手来威胁我们的学员，请问这不是权谋吗？但后来的发展确实令我们这位学员也想象不到的：

谁便宜了谁

女友背叛了他。

他在我的部落格留言，说他是边流着眼泪边打字的，他说：“江老师，我需要你的意见……我的女友背叛了我。她和别的男人发生关系。她坦白的跟我说了。但，我不要便宜那个男的，我也不要和我女友分手。我该怎么做？”

我当时给他很残酷的回应，我说：“你没有不便宜那个男的，因为是“你的女友”便宜那个男的。”

# 遇着了劈腿，不是找人理论的时候

很多时候我不明白一个人还要跟一个背叛他的人在一起，目的是为了什么？证明自己的“爱”是伟大的？

原谅了劈腿的女友，你真的不介意她在你背后跟其他人搞过吗？如果你跟女友搞的时候，忽然间她和另一个男人搞得香汗淋漓的画面在你脑中闪过呢？

这男学员告诉我：“女友虽承认了劈腿，但她说我们之间已经本来就有问题了，那第三者的出现只是加速恶化我们之间的问题。不过她却说还是很爱我，要跟我重新开始。我应该不应该去找那个第三者跟他理论？”

老实说，找第三者理论有用吗？
