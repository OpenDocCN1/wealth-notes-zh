# 上帝的闹剧，睾酮素和催产术之战

上帝的恶作剧始于他弄到男人有无限精子和偏高的睾酮素，但却只给予女人非常有限的卵子兼偏高的催产素，然后他又把怀孕生育的工作交给了女人，其他的两性关系就在长远的进化之下，开始逐步的蜕变。

男人因此可以到处留精，但女人却不能到处受精。所以女人在风险比较大的前提下，她就要选有资源能够帮她和孩子生存下去的男人。男人则在风险小的情况下，喜欢选择能够帮生殖的年轻、健康、好生育的女人。

也因为女人择偶的风险比男人大，所以在还未有性关系之前，主控权往往掌握在女人的手上，男人会对女人敬爱的宣言，甚至分享自己的情络来尝试打动女方。不过，一旦发生性行为后，过了一段时间，主控权反而在男人的手上了。

其中一个统计就是在第一年的婚姻中，百分之三十的女人会投诉男人不向太太表达自己的感受，会减少跟太太聊天。在婚后的第四年，投诉自己老公封闭的女人上升到百分之六十。

男人为什么在这个时候反而会少跟太太讲话谈心呢？

# 男女间的暗战

他热恋期的时候可以跟太太在电话上聊上六个小时，婚后却可以整个大半天都不跟老婆说一句话。一些人认为可能在追求期的时候讲太多话，该说的都说完了。但这是个废话，因为这个不跟太太说话的老公，总可以在见到好朋友的时候，又是滔滔不绝的。

男人在追求阶段时，因为主控权在女方，女方需求的是承诺，所以男人也有办法骗到自己给女方承诺。但得手过后的主控权就开始移交了，所以男方在这时候就会尝试减低承诺，而减低承诺的方法就是选择性的封闭自己的沟通。

这个情况就好像赌徒在看到自己的底牌时，需要做到不动声色才不会被对手看穿自己的反应，也好像客户在买东西时的讨价还价般，你不想给你的对手知道你的真正意愿，如此才能把握着主控权。男人在模糊了女人的视线后，他才比较容易和自在的把自己的“资源”转移到其他管道或阴道。

基因竞争的游戏就是一物制一物，男女双方各怀鬼胎，也各有法宝。你想选择性的封闭承诺，女方就会很自然的要出她的镇山之宝贝——闹情绪。
