# 女人感情专一的漏洞

我可以确确实实的告诉你，如果你以朋友的身份守着对方，她分手的时候，你肯定来不及追她。

在任何的信仰中，信徒们会想办法走漏洞而不破戒。例如在回教的教义里面，教徒必须吃“合法 Halal”的肉，而合法的肉是在念了经文后才杀的。但是工厂里面要屠杀大量符合回教法规的动物，如果还要每杀动物前要念经文，这家工厂将会是没有效率的工厂。所以他们就想到了一个漏洞：在工厂里面安装播音系统，不断大声的播放经文。

同样的，很多女人的爱情专一论，就只是一个理想的信仰，她们会想办法在信仰中找出一个漏洞：“就算我跟男朋友没有了感觉，只要他不是坏到我不能接受，我还是会暂时保留着他，直到有更好的选择出现为止，这就是出轨了。”

而且她的换男友态度就好像找新的工作般。

# 如何换男友？

女生换男友就像打工一族换工作，最理想的策略就是打着一份自己不喜欢的工作同时没有另一份更好的工作机会出现，然后自己也已经偷偷的去应征。

你也不可能跟目前的老板说：“喂，死老鬼，我后天要请半天假，因为要去应征另外一份工作。”

通常都是别家公司已经决定要聘请上班，自己才会递上辞职信，说：“老板，我觉得我们需要分开，这不是你的问题，是我的问题，因为我觉得我不适合这家公司的运作模式。”

如果样貌不错的女生，就算已经有了男友，应该也还有几个男人追着她和等着她。你觉得等着她和追着她的男人，哪一个比较有机会赢得美人？

一个有样貌的女生，通常在你认识她的时候就已经有男友了。就算是一个样貌普通的女生，她只会等到完全忍受不了男友的时候，才会提出分手。

如果她已经开始不大喜欢自己的男友，只要那个男的不令她讨厌，在还未到忍无可忍之前，她不可能去想“我要先跟他划清界限，分开了后，我才能再给其他更好的男人来追我。”

女生也不可能会很理性的跟不满意的男友说：“我觉得跟你在一起的感觉没有以前这么强了，我猜如果以后有另一个更好的男生追我的话，到了那个时候才分手可能会比较痛苦。不如我们现在分手，因为长痛不如短痛。”

女人不可能可以理性到……有人要照顾她，她也不要。也不能傻傻的先把一份“还可以”的工作辞掉，让自己可能连续几个月都没收入，之后才找到一份新的工作。况且到时候若新工作比旧工作差，岂非赔了夫人又折兵！
