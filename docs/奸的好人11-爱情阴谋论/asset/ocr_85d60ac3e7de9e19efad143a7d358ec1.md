# 家常菜和野味煲

在男女关系里面也不要妄想你有能力改变对方，知道自己有能力改变他人是一个很爽的认知，知道自己有能够改变爱人的能力，更加是一个自我膨胀的“心理软性毒品”。

所以很多男人会想拯救一个很麻烦的问题少女，而很多女人会认为她将会是把坏男人改邪归正的最后一个女人。

> 江阴鬼才有话说：男女关系中，“过滤”比“管理”更重要。

在工作上面对人的时候，能够运用多种管理手法，因为你跟被管理的只是盟友、下属，大多数是没有感情上瓜葛。但对一个你爱的人施展过多的管理，自他皆苦。

我相信很多人都试过这种感受，被老板恶意批评的伤害，远远比不上自己的伴侣用同样的语气和字眼地批评。

我不是说要管理的一段感情就不值得经营，值不值得经营是个人的，若双方都觉得可以承受这个管与被管的苦，感情自然就能够延续下去。

第二个要坦白面对的问题是：不要因为第三者能给你正版情人所无法给到的，就冲动地判断第三者就是你要寻找的答案。

在美国做过的一个统计是自己太太若胸部是较小的，丈夫召妓时往往喜欢选择胸部大的，妻子要是丰满的话就找苗条的，妻子苗条的话就找丰满的，妻子很艳丽的话，丈夫的还可能要找邻家女孩型的。

> 江阴鬼才题外话：在美国电影《Analyze This 老大靠边闪》中，影帝罗勃迪尼若扮演一黑社会老大，心理分析家问他：“问什么要找妓女？”
“因为我要得到口交。”
“你太太不能给你口交吗？”
罗勃皱眉摇头说：“不不不！怎么可以？！她每天都喘对嘴的亲我们的小孩咧。”

这就是很简单的：在家得不到的，逢场作兴时就会找家中得不到的野花。

若只是性苦闷，想开心，而第三者能够在性的那一方面逗得你很开心，第三者“可能”是你的答案，也“可能”只是你逢场作兴的需求，但不要因此而认为第三者就是你在爱情上所要的答案。

# 为什么偷吃的东西比较好吃？

男人所说的妻不如妾、妾不如偷，越是禁忌的桃花就越刺激。女人跟男人也是一样的，你在经历着偷偷摸摸的风流快活，是因为有新鲜感。况且我们《心魔广销》一书中所说过：“水果实际上好不好吃，和是不是禁果，没有直接关系。”

但，人就是犯贱的，要有障碍的禁果才好吃。
