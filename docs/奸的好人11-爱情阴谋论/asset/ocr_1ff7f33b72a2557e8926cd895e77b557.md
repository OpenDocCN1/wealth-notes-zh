# 火花前和火花后的策略

“火花前”和“火花后”所要采取的策略是完全不同的。

很多人都认为若女方跟你讲男人只是三年时间对她好，那么你若对她有兴趣，就要暗示或明示的符合她的要求，向她证明你这个男人是很长情的。

但这个做法是有危险的，特别是还未擦出火花前。（在我们的《心魔行销》中讲“意境行销”的部分，就写到一位运用讲故事来带出自己的专情“高价”，但却弄巧反拙。）

> 江郎鬼才有话说：异性对你没兴趣，不需要刻意附和对方；异性对你有兴趣，可以互相附和；对方对你的兴趣大过你对她的兴趣，她反而会刻意的附合你。

但是，就算对方是已经对你有了兴趣，若大家才约会不久，我建议你不需要直接讲自己怎样的长情，你倒可以讲个故事来暗示你的长情。

# 策略性的暗喻

最好是讲一些人家的故事来暗喻你是个长情汉，一般人的做法会讲些名人的故事。例如：萨康纳利·Sami Connery 被誉为是一个最有男人味的明星，却对自己多年的老婆始终如一。或者也可以讲讲在我们的《心魔行销》里面有讲到的一位天生失明的浪漫英国政治人物，因为恋上了天之娇，不顾一切的公开自己的恋情，导致断送自己可能成为英国第一个残障人士首相的政治前途。

女生最喜欢听这一类的浪漫故事，而先前那位说男人只对她好三年的女生，若听到这种故事的话，我相信她更加的为之感动。

或者你也可以如此说：“有一次我在飞机上见到最美丽的东西是，……你也知道做空中小姐的都有起码一定的姿色吧，当时我的眼睛在一直的扫描，做着我私人的选美会，以期找到当天最漂亮的空姐。后来终于让我看到那一天我见过最深刻印象的，不过不是空姐，而是坐在我旁边的一对老夫妻，他们应该有七十岁上下吧。只看他们的样子，你不会觉得有什么特别，他们只是一起的睡着了，不过让人觉得温馨的地方是……他们睡着的时候是手牵着手。”

相信我，在适当的时候讲这个故事，女人会对你另眼相看，特别是“爱情信徒”的女人，将会给你更高的分数，这个故事是真的，这对老夫妇是马来人，我觉得他们很 Cute。当我讲这个故事给女生听的时候，她们通常都会眼睛发亮。
