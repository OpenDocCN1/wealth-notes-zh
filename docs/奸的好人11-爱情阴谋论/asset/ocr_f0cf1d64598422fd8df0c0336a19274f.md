# 爱情的“现象”

人类本来就是感觉动物，而女人更是如此。女人往往就是喜欢说：“和一个人在一起就要看看自己有没有Feel（感觉）。"”

有的女人对感情过度注重所谓的“感觉”，我不少的女学员还问过我“怎样跟我那多年的伴侣找回热恋期的火花？”

> 江狼鬼射有话说：男女关系里面，男人在热恋期过后，会“想”在新的对象找新的热恋火花，女人在热恋期过后，会“想”在旧的对象找回过去的热恋火花。

各位读者，从生理学和进化论的角度来看，女生所追求的这种“感觉”其实是恋爱头三个月的头脑化学作用。

热恋期的时候，脑中充满了爱情化学元素，例如：Dopamine 多巴胺、Testosterone 睾酮素、Estrogen 雌激素和 PEA（Phenylethylamine 苯乙胺）等等。特别是在 PEA 的影响下，[你看到对方的一切都是完美的]，[他所有的缺点]，你都会合理化的把它们解释掉。所以 PEA 也被称为是恋爱的药物。

普通一个男人在你面前放屁或吃饱打嗝，身为女生你会觉得这个人“没礼貌”，但-year你热恋期的爱人在你的面前放屁，你会觉得他“很真”、“很可爱”。所以有些人说：“Falling in love is a God experience。恋爱是一种上帝体验。”爱人在你的眼中会如上帝般的完美无瑕。

但同样的这个上帝（爱人），在过了热恋期后，你可能跟他坐在一起看电视的时候，被他的一些很细小、很微不足道的举止干扰，你忍不住的转头跟他讲：“看电视就看电视嘛！你呼吸需要这么大声吗？”

# 爱情是解释出来的现象

很多人会误把“现象”和“解释”混为一体，在追求阶段时，身体是产生大量的化学作用，这种化学作用就如毒品般使男女互相的上瘾而在一起，而这对男女就把这个上瘾的现象解释为“Falling In Love（热恋）”。

在热恋过后的相处，男女就要把这个接下来的现象解释为“Love（爱情）”，所以开始就尝试以亲切感、责任感、关怀等来相处。
