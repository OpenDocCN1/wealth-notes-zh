# 女人喜欢对男人断章取义的妄下定论

若你直接坦白的说自己是一个长情的男人，女人未必信。不过你讲一个“欣赏着老夫老妻牵着手睡觉”的故事给她们听，她们却会对你投之过多的幻想。

如果听这个故事之前她又被你撩出了火花，此刻她会开始想像你就是这种会跟女人在一起，直到白头偕老时还会手牵手、齐齐睡的浪漫男人。如果这一个女人对这种白头到老的爱情有憧憬的话，你在她眼中的吸引力就会飙升了。

所以我们在《心魔行销》一书中就不断的说很多人买东西的原因是在买一个“幻想”。而男女间的恋爱也就是恋上一个幻想。女人除了喜欢听这一类的故事，她们还会很无聊的把故事中的主角的优点投射在“讲故事者”的身上。

但是女人有没有想过……一个男人很欣赏老夫老妻牵手而睡，和他是否长情；或能否将来跟你牵手而睡，其实是两回事？

长情的男人是否一定“会”欣赏这对牵手睡觉的老夫妻？

不长情的男人是否一定“不会欣赏”这对牵手睡觉的老夫妻？

就算是一个长情的男人，如果他的观察力不够好，就算他坐在这对牵手睡觉老夫妻的身边，他也不必然注意到这个温馨小细节，进而就没有一个可以跟人分享的故事了。

# 不是黑不一定代表就是白

上一篇文章那个讲“三年理论”的女生说她要一个长远对她好的男人，若她真的遇到如此的 男人，现实中她真的就一定会快乐吗？

答案是：未必！因为她只是说了一个男人对她三年后就开始懒，她会不快乐。但她并没有讲出“怎样”的男人是令她快乐啊！

> 江郎鬼才有话说：不会“不快乐”并不能直接代表会“快乐”。

但是在她还未知道怎样的男人才会让她快乐之前，她会认为“不会不快乐”的就是她要的“快乐”。

所以她才会对讲“老夫老妻牵手睡”的男人有很多的幻想，因为她认为能够欣赏这对老夫妻的男人，应该就不会懒了。

# 策略性的欣赏

所以，若你有意或无意的讲了这个“牵手老夫妻”的故事，她的脑中把你幻想成一个长情的人，在道上你有没有骗她吗？

若你根本没有欣赏“老夫妻牵手睡觉”但却讲了这个故事，对比你真的有欣赏“老夫妻牵手睡觉”而讲了这个故事给这位女生听，对女生来说，两者有分别吗？

很多人从道德的角度来探讨这个问题的话，可能会说一个不欣赏的人，却讲到自己好像很欣赏的，我也承认这就是骗人。但这个讲故事的人可能会说：“不错，我讲到好像很欣赏牵手老夫妻，但我有没有说过我是个很长情的男人？若要说我骗人，或者可以指责我偷了江老师的故事来用。但如果我完全没有讲过我是个怎样的人，我需不需要为我没讲过的话负责？”

一个人跟你说他会找人来杀你，你在法庭上是可以告他恐吓。但，如果这个恐吓你的人跟你说“你要小心点”，在法庭上是不能构成恐吓罪，因为他不需要为自己没讲过的话负责任。

但若我们再从道德角度来看这事情，我要问的问题是：“欣赏”的意思是什么？怎样界定一个人的“欣赏”？

江郎鬼才问问题：坏人能不能欣赏好人的“好”？好人能不能欣赏坏人的“坏”？谁说坏人只能欣赏坏、好人只能欣赏好？

就算我确实觉得这对“老夫老妻”很浪漫，很温馨，但是否表示“我”就是这种温馨和浪漫的人呢？

“为什么女人要这么笨的相信：一个能欣赏“美好事物”的人就是一个美好的男人呢？”

就好像一般人在看到一个样貌凶悍的黑社会老在抱着自己刚出生的孩子的一副温馨嘴脸，马上会对这个黑社会老大改观，认为他虽然坏，但既然他这么爱自己的孩子，再坏也不会坏到太过分。有的女人可能看到这种充满了爱心的坏男人，可能还为之心动。

请问：一个人充满父爱和他是否心狠手辣有关系吗？

江郎鬼才有话说：一个人欣赏一样东西，就只是简单的代表了他欣赏那一样东西。爱情信徒则会从这很单纯的“现象”，推论出很多的“解释”。

# 爱情就是希望“幻想”是真的

所以当你讲了这个“欣赏老夫老妻牵手睡觉”的故事，对方直觉判断你是她要的那种长情男人，是谁骗谁？

其实主凶是女人，是女人自己骗自己，因为她们很积极的去寻找这个“幻想”。男人的故事只是帮凶。

各位男人，当你看到身材样貌惹火的辣妹而判断他在床上能够让人销魂蚀骨，你确定你不是自己骗自己吗？
