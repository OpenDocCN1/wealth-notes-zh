# 热恋的目的

英国“国家毒瘾研究中心”的 John Marsden 曾经就说过爱情的感觉是会上瘾的，热恋就如同白粉或可卡因般的把男女绑在一起，有三个月的时间让他们觉得“不能不在一起”。

那么在一起干嘛？

就是起码他们能够搞起三个月，那么这就满足了基因想要繁殖的欲望了。

科学家们还发现到用着毒品时的头脑和热恋着的人的头脑，在 MRI Scan 的扫描下，两者脑中活跃着的部分竟然是完全一样的。

热恋期过后，脑袋就开始分泌另一组的化学物品——endorphin 脑内吗啡，所谓的细水长流就是这个时候了。

允许我再讲的白一点：于热恋期的性关系，双方的下体是男的会特别的坚挺，女的会特别的湿润。热恋期过后，男女的硬湿度就回归平常的程度。脑内吗啡的功能就是让两个人能够很舒服平稳的在一起生活。

要知道，跟同样一个伴侣是不能够再度激起 PEA 了，它只能够被伴侣以外的另一个人启动。这就是为什么有人说：“如果上帝是要我一生一世都只爱一个人，为什么他会跟我们开这个玩笑？”

> 江郎鬼才有话说：爱情是上帝赐给人类最大的闹剧

这就是爱情的“现象”了。

爱情信徒就是把这种天然自生的“毒瘾”视之为爱情真理。
