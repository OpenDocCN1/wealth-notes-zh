# ### 美貌的基因理论

有人说“各花入各眼”，美不美貌是很主观的。但是，在所有的文化里面，美貌其实是有一个架构的，就是“平衡”。

曾经有科学家们运用电脑技术把不同女人的脸综合起来，他们模拟四张照片。第一张是“四人脸”，即四个女人脸所综合，第二张是“八人脸”，然后就是“十六人脸”和“三十二人脸”。

然后他们请人来针对这四张照片审美，他们发现综合脸是肯定比原装版的脸更吸引人，“十六人脸”又比“八人脸”更具魅力，而最漂亮的就是“三十二人脸”。

当电脑把越多人的脸综合起来的时候，新的“人造脸”会越来越“均匀”和“左右平衡”。
