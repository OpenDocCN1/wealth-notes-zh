# 名女人讨厌感情暴力的真相

我曾经加过的一个电视谈话节目，与另一位女嘉宾和节目主持人畅谈《男人不该打女人》议题。主持人首先访问女嘉宾她如何看待打女人的男人。

她说：“他们是一种很要不得的男人。”

不久女嘉宾告诉我们，她的一位女性朋友如何被男友揪着头猛撞桌子和墙壁。我听着的当儿觉得有点惊讶，因为她描述得特别真实、投入、也很有画面感，我当时即怀疑她是否就是在描述着自己的经历。不久，主持人问了一个我意想不到他会提问的问题。

他很轻松的问了女嘉宾：“那么你有没有被男人打过？”

“没有！”她的反应很大，身体后倾的速度如跳开般的迅速。

女嘉宾的反应令我产生更大的怀疑——过了不久，她又义愤填膺的述说着她的那个“朋友”如何被男友捉头撞墙、撞桌子的过程，这时，我认为她经历感情暴为的机率应该起码有百分之八十。

节目完毕后，因为女嘉宾是位美女名人，我道听途说得来的消息，她一连几个男朋友都有对她施暴的记录。

我不禁要问：难道也有女人喜欢被人虐待吗？

# 越痛就爱的深？

多年前曾经有一个朋友带了一位女模特儿来见我，她的男友也陪伴着她一起前来。女模特儿的问题是：她每晚都做噩梦。

我问她：“这个噩梦一直做了多久？”

“已经有三年了。”

她答得很确定，所以我就装得很肯定的问她：“三年前……发生了什么事？”

她刚开始只是支吾以对，不过我再表现得更肯定的说：“三年前你一定发生了一些事情。”

她想了想，就转身对她的男友说：“你能不能暂时走开一下？……”

原来很多年前她交了一位男友，她有点激动的说：“跟他在一起后，我对性、爱情和人生的看法，从此完全被他改变了。”
