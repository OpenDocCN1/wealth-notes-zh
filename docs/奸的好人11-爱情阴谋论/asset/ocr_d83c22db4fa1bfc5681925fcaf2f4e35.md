# “精”和“精液”的分

当年的我因修行的关系，相信华人“精气神”之说，认为不可以随便浪费精液的能量，但自己又是血气方刚的欲海中人，所以才训练到自己有这种能享受高潮又不射精的功能。

后来才知道华人，“精气神”学说里面的“精”，非指普通的精液，精液是“精”的原料。换句话说，我当年只是“禁射”，但绝非“禁欲”。

在印度瑜伽里面也有“精气神”的学说，但它“精”的用词是“Ojas”，精液是“Shukra”，二者是有名词上的分别。真正的“精Ojas”很充足的时候，人反而是没有欲望的。

# 心理欲望要如何转化？

有些出家人（佛教、天主教和印度教）的长年禁欲，脸色看起来会不好，但有些看起来却很强壮。因为欲望是人体的自然反应，（若压抑的话）长年下来确实会使人精神疲惫，甚至还会衍生变态行为，例如：天主教神父的性侵犯孩童，我的男学员中有被和尚非礼的经验，我的男性朋友中有两位还被同一个和尚做“打劫式”的嘴对嘴的偷吻过。

但为什么有一些出家人禁欲却对他们有很正面的影响？甚至还很精神？

我看到有三种可能性：一，这个人有修禅定，故此控制身心反应对他来说轻而易举。

二，这个人在情绪上有很大的升华和转移，如：培养出很大的慈悲心，或对自己的神菩萨有很强烈的偶像崇拜情操。这个情况是把“精”转化成情绪的力量，然后把情绪的力量再导向无边众生，或导向一个超越宇宙的神。

三，这个人对某一门学问变成了很沉迷，不断的钻研下去。这是把“精”转化成学习和思考，在印度瑜伽，就是把Ojas转化成了Tejas，“精”转化成“神”。
