自己不需要爱情，即使需要，他是比较重视效果，感情和感觉都是其次。一个人可以对“爱情”不感兴趣吗？请问这合理吗？

最让我有印象的是她最后的问题：“人对爱情不感兴趣，合理吗？”

# 什么才叫做合理？

她问这个问题就好像基督徒问：“人能不相信耶稣吗？他为了你的罪而死耶！你不信，合理吗？”

基督徒有没有想过……耶稣有没有为你的罪而死是一回事，你信不信他又是另一回事。爱情信徒可能也没有想过……爱情是否真实存在是一回事，人需不需要爱情又是另一回事。

男女间还有很多“合不合理”的问题，要争执这些问题，就好像要争执哪一个宗教才会是真的般无聊。

信“一神教”的人觉得“多神教”的人是异端，信“多神教”的人又认为“一神教”的人极端。请问世界上这么多宗教，哪一个教才是最正确的呢？

女人的爱情观就像“一神教”，男人其实是向往“多神教”，但是目前社会上的主流爱情观是“一神教”。那么是否最多人相信的“爱情教”就是正确的呢？

答案其实是一句废话：你所相信的就是合理；你不相信的话，就不合理。

# “现象”和“解释”的混淆

举例，“性行为就要有爱”，对大部分的女生来说是合理的，但是“性行为就要有爱”这句话，套在男人的身上就不一定是合理了。

只有笨女人会在听到男人可以把性和爱分开时，皱眉而很鄙视的说：“为什么男人这么下流？我是性和爱不可分爱的。”

曾经我的一个吃素的朋友见到两位女同性恋者当众亲热，他就疑惑的说：“为什么两个女人可以搞在一起？爽吗？”

我当时是反问回他：哈哈，为什么你喜欢吃素？爽吗？”

女读者若觉得男人能把性和爱分开是下流的话，可以想像一下一个英国绅士看到华人在吃臭豆腐，他捏着自己的鼻子，然后皱眉鄙视的说：“Oh Shit！为什么华人这么下贱？不但能把这么臭的东西摆到口中，而且还能吃得津津有味。”

臭豆腐的“臭”是现象，“臭东西能摆在口中”也是现象，“吃臭东西吃的津津有味”也是现象，但“下贱”不是现象，而是英国绅士的主观“解释”。

江稻鬼才有话说：要成为一个肯思考的人，要“肯”去区分“现象”和“解释”。

甚至若美国人看到我们中国人或韩国人吃狗肉“现象”，会把我们“解释”为不人道的民族。
