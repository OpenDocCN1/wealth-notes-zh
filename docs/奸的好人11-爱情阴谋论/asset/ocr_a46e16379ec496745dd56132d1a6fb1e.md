# 正妹“人格”和“花瓶”的矛盾

我还可以以过来人的经验告诉各位男性读者，一个一百分的美女的信心不一定比八十分美女好。

可能有些就会问：“为什么百分的美女信心反而不及八十分的？”

百分美女因为是众人的焦点，但她若知道自己不是名人，也知道自己不是什么才华出众的人，她在年轻的时候还不能完全适应自己成为众人焦点。换句话说，她有点儿自己意识到自己是“花瓶”的尴尬身份。

> 江郎鬼才有话说：百分美女的“花瓶”意识是强过八十分美女，这也让她们会怀疑自己的能力和人格。

而时常被众人眼光注视的女生，她会越来越介意自己的妆化得好不好，服装穿得漂不漂亮，她们反而不是最自在的。（我这个“百分不及八十”的理论不一定适用于三十岁以上的女人，年纪开始大的女人可能学会如何接受自己不需要完美。）

其实百分美女的信心，基本上是比八十分美女来得高，只不过百分美女的信心会被内心矛盾所影响，所以她的信心不比八十分美女更好。她的矛盾来自于她永远不知道男人赞扬她的时候，是真的赞扬她的才能，还是因为她漂亮而借故赞扬她。她也难于明白喜欢她的男人，到底是喜欢她的“人”还是“外表”。

> 江郎鬼才告白：是喜欢外表，其他的都是自欺欺人的理由，再不然就是之后培养自己喜欢你的“人”。
