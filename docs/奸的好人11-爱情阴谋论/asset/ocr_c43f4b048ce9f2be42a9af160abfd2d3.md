# 如何启动“在乎”？

在打西洋拳的擂台上，其中一个策略就是你每一次要出左拳之前，刻意做一个晃动左肩的假动作，只要这个晃左肩的动作每一次都在你打出左拳前出现，你就开始在对方的防备系统中制造了一个机械式反应。只要你在突发其然晃动左肩后而打出右拳，对方的机械式防备反应被严重干扰而乱了阵脚，而你也找到对方防护的漏洞处。

同样的这个假动作理论也可以运用在人与人之间的沟通，甚至有些人也可能无意的运用在你的身上

举例，一个你本来都没兴趣的人，他很准时的在某些特定的时候做特定的举动：可能是邀约你，或者是打电话给你闲聊，你已经知道他会很关心你。直到你已经开始有了这个机械式反应，对方只要忽然间停止该反应就能打破你惯例的思绪。

我的一位女学员因为平常不乏有男人追求，有的还很有诚意和坚持的等待她回心转意。其中一个守候她多年的追求者是每年的华人新年一定会约她出来，然后一天又一天的过去时，他就开始有点在乎对方了，会思索为什么他还没打电话来？是不是有了新对象？

然后她也不明白自己为什么会有情绪上的牵挂，直到她开始关照自己的念头和情绪，才记起我之前讲过的“在乎一个人不一定等于就是爱上一个人”。

当对方忽然间在惯性的时间，没有对你做那种惯性的举动时，因为被打破了机械式反应，你的脑中忽觉不习惯。平常的这个时候对方是真实的存在着的，现在他忽然间消失的话，你的惯性反应就会把对方的“存在感”投射出来、一直想着他。

因为你一直的想着对方，你错觉了你是“在乎”这个人。

> 江狼鬼豺有话说：先以你的“存在”来对人制造习惯，然后以你的“消失”来制造心灵空虚。

所以，很多男生遇到的问题是只有他打电话给女生，但女生却从不打电话给他。其中一个原因就是男方不大会为女生制造“空虚感”。
