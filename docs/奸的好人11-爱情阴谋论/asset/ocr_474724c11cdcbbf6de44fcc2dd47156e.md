# 废话如何变成贴心的话？

男人可细心分析上面那段废话，因为废话虽废，但却是一个有做“功课”的废话。它虽很模棱两可，但又准确的描述出大部分美女的人生经验。前半段我讲出了她的挑战，后半段讲出了她的个人内涵；前半段我讲出她被其他芸芸众生“误解”，后半段我让她觉得被我“了解”。

整段话只有一个部分是假的，就是最后的：“因为你知道自己是个样貌出众的人，我觉得你反而会比其他人更加努力，付出更多来证明你不只是一个空有外表的花瓶。”最后这一段话我必须要有点虚伪才能讲出口，因为我根本不知道她是否一个“更努力“或“付出更多”的人。

我只是乱讲和不负责任的讲而已。

不过这一部分却是美女最喜欢听、最希望听到的。美女当然有决心要成为一个有内涵的人，但“有决心”和“是不是”是两回事。

美女会把“喜欢听的”和“真的”混淆，因为她“很希望”自己的内涵是真的。（我相信男读者抄下了这段美女喜欢听的废话后，也会感动流泪的说：“Oh my god！江老师，You are so right!”）

江狨蔓另有话说：能把对方心中隐藏着的“最惧怕”或“最希望”说出，就能成为对方内心世界的权威。

我虽然不是对很多个美女讲过这剧本，但我每一次得到的效果都是大同小异。女人就是这样：她们讨厌只是以貌取人的男人，但她又要男人来喜欢看她的外表，同时又耍男人不要只是看她的外表。

所以我上面所讲的这个模棱两可描述，就是她们最喜欢听到的——她们耍男人有办法认同她“跟样貌没关系”的优点。

很多男人觉得美女的“心”很难被看穿，事实上若要解读她们的心态和行为是更容易的，因为整个大环境会以很特定的方式来塑造出所谓的“美女习惯”。

要知道“性格”和“习惯”是有分别的，不同的正妹会有不同的“性格”，但她却很会有很接近的“习惯”。
