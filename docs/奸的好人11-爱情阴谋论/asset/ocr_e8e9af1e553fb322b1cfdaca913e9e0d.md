# ## 不需要被认同的魅力

女人味是很难能够从个年轻美女身上看到，因为它是经过磨练出来的，你不能将自己（在固执的意外）来指夸奖老。

有女人味的，会让男人看上去就觉得很舒服自在。大美人或许能够让身边的男人惊艳，但未必能够让男人自在，她的震撼力都是从“视觉”频道散发的。但是，有女人味的则除了也可以吸引到男人注视之外，她的感染力更是能够影响男人的“感觉”频道。

而所谓的“女人味”是很难纯粹从身材、样貌、化妆或整容而呈现出来。女生们真的是需要经过“被认同”的试炼。

注意，女人“要”男人认同、“需要”男人认同，和“不要”男人认同，是有分别的。

一个“不要”男人认同的女士，真的会完全不管自己打扮、不管自己的仪态是否得体。一个“需要”男人认同的女生往往都是信心比较偏低。不少的年轻正妹是徘徊于“要”、“需要”和“不要”之间的矛盾，一方面喜欢被男人注意，但另一方面她却还没办法很自在的应付男人对她的注意，所以才矛盾。

所以，“要”认同、“需要”认同、和“不要”认同的，是三种完全不同的女人。

有女人味的就要修炼出“我喜欢男人对我有兴趣，但我不需要男人对我有兴趣”的气质，所以她的行为举止才能让跟她在一起的男性，觉得分外的舒服自在。
