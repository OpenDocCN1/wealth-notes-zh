# 爱的乘法表

另一个方法是个古代道家的房中术，据闻有些人也听过“九浅一深”，即在抽插的时候，每九个浅插就一个深刺。后来我又在一道家文献中看到这“九浅一深”的完整版，我曾经在课程当中被人问起而讲授了这个完整版，被学员们戏称为“爱的乘法表”。

完整版的做法是分成十个回合，第一回合是“九浅一深”，第二回合是“八浅二深”，第三回合是“七浅三深”，第四回合叫做“六浅四深”，……以此类推，到了第九回合时候，就是“一浅九深”，之后的所谓第十回合就开始“全深无浅”搞完即可。

其实古人的这个“算数”的做法，因为有浅深之别，所以就会把感受变得有强弱之分，这是双赢的：男人是快热型，“浅”学武可以拉长自己的时间。当然，男人脑中在“记算”自己的深浅次数时，确实会自然的做到分心。而女人因为是慢热型，刚开始比较多的“浅”是用来配合女人的慢热，接下来越来越多的“深”则是把女人“热”的速度加快。

# 千抽之境

“鬼才版”的爱的乘法表就是在进行着敦伦时，心里是算着：“一、二、三……七、八、九、‘一’！”然后第二回合再算时：“一、二、三……七、八、九、‘二’！”第三回合算时是：“一、二、三……七、八、九、‘三’！”以此类推，算到第十回合时，就是：“一、二、三……七、八、九、‘十’！

换句话说，头十回合都是“九浅一深”。
