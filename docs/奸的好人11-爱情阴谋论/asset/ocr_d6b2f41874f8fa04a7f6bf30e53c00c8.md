# 男人和女人所喜欢的色情

在一九八六年，美国的纽约州大学对人做了一个类似上面的“牛反应”的试验。先别太兴奋的问我：“还有哪家大学还做着这个试验？我要过去参与。”这个试验不是测试人类伴侣多寡的性交频率，而是看男女对色情电影的反应。

他们发现男人一直看色情电影的话，如果下一部电影是同样的女演员演不同床戏，他们的反应就会弱。但如果下一部电影是不同的女演员，男人的兴奋度还能维持。

相对的，女人一直看色情电影的话，就算下一部电影是同样的男演员而做不同的床戏，她们还是有同样的反应。女人就算看色情电影也很专情，比较喜欢“同样”的演员演不同的床戏。

# 男人想搞，不需动脑

在美国某大学曾经做过一个试验:如果一个有吸引力的异性走到你面前对你说：“我其实已经注意了你一段时间，我觉得你很有吸引力，所以想和你上床一次。不用担心，这只是为了性，我们之后不会有任何的牵连……”

你会有什么反应？

试验结果是：当俊男对陌生女大学生说了这一句话时，百分之百的女生都拒绝了俊男；但是，反过来的时候，当美女对陌生男大学生提出相同邀请时，百分之七十的男学生马上接受。我需重复：是“马上、立刻、即时”的接受。

> 江郎鬼才有话说：男人某部分充血时，会动用到头脑的血。所以面对色诱时，若只有天知、地知、你知和我知，以后也没有任何瓜葛的话，大部分男人没有任何矛盾。

我知道有些人会说：“好的女人，一个就够了。”

我很好奇的是：好的东西，不是越多越好吗？

# 不贪多的原因

若世界的四大美人范冰冰、章子怡、舒淇和 Angelina Jolie 都爱上我，而她们都达成协议的跟我说：“江老师，我知道你是喜欢我们四位的，我们也喜欢你，而且我们也不介意同一时候一起拥有你，你介意不介意同时拥有我们四个女人呢？”

你说我会介意吗？

我唯一会讲“好的女人，一个就够了”的时候，是我怕若我要多过一个的话，我可能会两个都没了。
