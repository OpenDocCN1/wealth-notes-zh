# 赌徒会上瘾的关系

赌徒上瘾是因为他们有时候赢很多钱，有时候赢很少，有时候输很少，有时候输很多。最开心的当然是赢很多，但最要命的就是这个“赢很多”是不知道什么时候会出现的，可能是这一次，可能下一次，更可能是第四次你才赢多多。

命运跟赌徒玩的一场很厉害的心理战就是——“不定性”。就是这种“不知道什么时候会赢，但很可能就是这一次”的想法，让赌徒不断的执迷下去。

曾经有人做过一个这样的试验，在三个不同的笼子中各有一只猴子，每个笼中都有一个很明显的扳机。第一个笼中的扳机是你按它的话，没有食物从一个管道掉下来。第二个笼子的扳机则是你每按一次，就有一小块食物掉下来。第三个笼子的扳机很特别，你按它的话，有时候有食物，有时候没食物，完全没有规则。

科学家们就计算猴子按扳机的次数，很明显第一个笼子的猴子按了几次后就不再按了。理论上第二个笼子的扳机应该是被按得最多。因为按得多，食物就多。但是，事实上最高的被按次数，反而是第三个笼子的扳机，这个笼子的猴子按它按到如同疯子般。

这也是为什么不少写部落格和完Facebook的朋友也会有上瘾的经验，其中一个原因就是你得到“不定性”的回应，你不知道你的部落客读者何时会给你什么回应。

在人际关系上要实行“不定性”是很简单，你有点轻微的“神经病”和“疯狂”就对了，因为“疯狂”的人就会不按牌理出牌，而且只要好好的运用你的“四不定”，就是让人对你上瘾。
