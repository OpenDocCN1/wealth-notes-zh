# 爱情小说的文字模式

.爱情小说中的男主角不只是以行为来表示他的爱，他还一定要以话语来表达他对女主角的爱。其实爱情小说中的女主角和全世界的女人都不一样，她们需要“听”到男人讲出口。

男人无法明白爱情小说的魔力是因为我们男人的头脑中只有一个语言中枢，而女人的头脑中却有七个，同时她脑中连接左右脑的部分 Corpus Callosum 是比男人更粗大。男人的 Corpus Callosum 的厚度大约只有一个尾指般大，女人的则比拇指更粗。

这个左右脑的连接就是为什么女人往往比男人讲更多话，而且男人在发生一件事情后，脑中的语言中枢只有一个，我们要去解这一件事情时，是倾向以抽象的角度来思考。女人在另一方面则喜欢透过头沟通、讲、分享感受、诉苦来了解整个事情。

江阴鬼题意外话：会打女人的男人，除了有暴力倾向外，其中一个因素就是他们没办法在语言上表露自己对伴侣的愤怒，特别是如果这个男人又属触觉型的话，表露不到的情绪就会以肢体暴力来宣泄。

关于如何断定一个人是触觉型，可以参考我们的《勾魂夺心洗脑催眠》。

所以，小女孩通常比小男孩更早开始讲话，她们讲得比男孩更顺畅，用更正确的语法，甚至是用更多的词汇，而且男生的“读诵困难症”(Dyslexia)是比女生高了一倍。一个女人的能力较强，可能是女人比男人多雌激素 Estrogen。

女人在经期中段时，雌激素是最高的，这段期间她们的语言能力最强。如果这段时间你叫她们做绕舌，例如重复念“四是四，十是十，十四是十四，四是十四，四十四是四十四，四十四含四是四十”，她们可以念得很好。但这个能力在一过了经期之后，当雌激素变得很低时，这个绕舌的速度就明显的下降了。

因此，男人的语言能力都较集中在表达资讯，而女人则除了表达资讯，还要表达情绪、感受、体验等。

一个爱情小说的描述例子可以如此：“他那饥渴的双手，贪婪的征服了她的双乳，使她的身体颤抖出一阵波荡的快感。”
