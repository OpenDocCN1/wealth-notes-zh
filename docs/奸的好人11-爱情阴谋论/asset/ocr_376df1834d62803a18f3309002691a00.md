# 恋爱之前和之后的矛盾

# 之前和之后的关切

来我课程的男男女女问过我很多“感情”的问题，对我而言，大部分男女的问题都是千篇一律。

男和女之间的千篇一律还是会有少许不同，但都是“之前”和“之后”的问题。男的喜欢问“之前”，女的喜欢问“之后”。

男人最关心的莫不是追求期的问题：如何快速的擦出火花，如何更快的跟女人搞上。而女人都关心成为伴侣之后的问题：如何维持感情，甚至如何控制或管理自己的男人。

以上男女间的感情问题，可以很简单的归纳成你和你伴侣之间的“之前”和“之后”的诸多差异。

# 男女前后的各自矛盾

女人被追求的 Fall in love 阶段，她寻找“无为而为”的爱情，所以她不能接受一个男人太过有计划和刻意，她认为一切都要自然发生。这个阶段的女生往往是随机而应，听自己的“感觉”多过听自己的“目标”，很“不目标导向”的认为一切要随缘。

但是男人追求女人的阶段却跟女人相反，往往都是非常的目标导向：要追谁、追多久、花多少钱来追、怎样追、用什么方法来追，都要思考过。一些男人可能会说：“我追求女生不用技巧手段，爱情最重耍是真，我只是用诚意来打动她。”

这些爱情信徒的男生所讲的“诚意”是人格还是手段呢？

其实“诚意”可被解释为“人格”，也一样能被解释为一个“手段”，任何的解释都不是真理，它只是当事人的信念而已。

我的一位学员曾经告诉我，他备有追女基金，有追求阶段的预算，也有在对方成为女友后的另一个预算安排。呵呵，这位学员是从事保险行业，果然有风险意识和理财计划。

但，一旦男女开始在一起，这个倾向则会倒转过来。

成为男女朋友后，女人就开始要“有为而为”了，她会跟男人讨论以后要买什么房子、跟不跟父母一起住，一切都要有“计划”。男方则在这个时候开始只听自己的感觉，随机度日，一切随缘。
