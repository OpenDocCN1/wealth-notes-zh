# 本来无包袱，何来罪恶感

若我的生殖器官是正常的，不管碰触它的是我的手、女人的手、猴子的手、甚至是一个机器人的手，我的身体上还是照样会有一些起码的反应。

身体如有反应，那是一个生理“现象”，表示我的机能是正常的，但如果之前被灌输了些文化，我可能真的就会把这些“现象”解释成罪恶感，到时就真的需要心理辅导了。

已故的著名佛教作家冯冯，在他的最后一本著作《雾航》中透露他一生人都抱独身主义的原因，他不想伤了妈妈的心，因为他是同性恋。他声称自己一生虽对男人有兴趣，但在身体上都没跨出那一界线，他给的解释是他在当兵的时候，在部队中给军人强插过，自此后便成了同性恋。

我认为给同性恋强插过，不能构成你是同性恋的原因。有的同性恋者确实是天生的，有些可能是从发生的一些“事情”中给予自己是同性恋的解释。

冯冯可能真的是天生的同性恋者，他只是借被军人搞过的事件来给予自己和众人一个“道德”交代。也可能他根本不是同性恋，但因为他太多道德文化上的包袱，导致在被军人强插时，身体反应和精神道德相互交战，然后开始把自己解释成是同性恋。

特别是：如果他给军人强插的那一次就是他人生的一次性经验，而他那一次又有反应的话，他可能会给予更多不平等和先入为主的解释。
