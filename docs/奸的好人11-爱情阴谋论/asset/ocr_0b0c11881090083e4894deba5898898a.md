# 谁才是爱情小说中的真正主角？

爱情小说的故事发展可以说是千篇一律的，常上畅销排行榜的往往都是万变不离其宗——清纯女主角和一个有“坏能量”的男主角邂逅。

这种邂逅通常不是有计划的，而是被大环境的天时、地利、人和把他们丢在一个“人在江湖，身不由己”的旋涡中。

女主角的是天使，男的是魔鬼，女方是光明，男方是黑暗，一个是希望，而另一个则是绝望，但他们之间的爱情就是桥梁。而且对立若越大，故事就越美。

爱情小说中的男主角才是启动整个故事吸引力的钥匙，他可能是带有粗暴、威猛、昏君、败世妓爷、厌世、甚至讨厌女人或爱情，但在小说结束时，这个危险的“猛兽”终被女主角征服了。

# 千篇一律的爱情故事

女人喜欢的爱情小说是因为她们知道不管男主角怎样的难驯，女主角“一定”能够征服这个危险叛逆的猛兽，就好像我们看警匪连续剧时，剧中的男主角在枪战中就算中枪也“一定”不会死。

爱情小说中一定有一个高潮点，它肯定是跟男女主角之间的性爱完全无关。

这个高潮点是男主角真正的“爱上”了女主角，这个坏男人可能开始的时候只是被她的外貌吸引着，只想“搞”她，但直到男主角发掘出女主角的“内在美”，被她的“内在美”所感动而爱上她，女主角才正式的接受她。

女主角运用她的“爱”来感化这个“坏”的男人，因为在女人的心中，这个男人坏的原因是他没有真正的被“爱”过，而她就是众多女人中，唯一能够让他感受真正的“爱”的女人。

故事中男女主角的幸福和美满结局，有赖于女主角教会这个坏男人如何的去“爱”。

就好像男人喜欢看的 AV 片般，基本上爱情小说中的故事是千篇一律的，甚至是有漏洞的故事也不要紧。最重要的就是男主角要带“危险元素”。
