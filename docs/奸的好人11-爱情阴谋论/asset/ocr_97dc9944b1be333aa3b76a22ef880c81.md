# 人到底还是一个机器人

在我们所有的书里面，有一个名词常被我们用来形容人类的行为——“机械式反应”。机械式反应跟牛顿的定律是相关连的：“一个物体会继续的保持静止或保持移动，直至它被另一股外力的影响才会有改变。”

简单的说，人是遵从习惯的动物。在热恋期过后，双方必定的都会渐渐的回归自己之前的习惯。在我们的《勾魂夺心洗脑催眠》中写到人在热恋期的时候，往往视、听、嗅、味、触等五个感官都会被启动，所以热恋期的人会显得非常的“活”，不过热恋过后的人会开始渐渐的变懒，逐渐减去感官的管道，减到只剩下自己平常惯用的。

我承认爱情会改变一个人，但大部分的爱情只是在热恋期的时候改变一个人，火花一过，你还是你，她还是她，衣服還是要洗，牙齿還是要刷。人，始终是机械人。
