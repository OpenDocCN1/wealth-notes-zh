# 我不受药物影响的原因

当时我在服食过量的“神奇蘑菇”后，只是很客观的分析当时感受，我的感觉就好像被人从头上重重地敲了一记，理论上应该就晕倒，但却又好像浮游在欲昏未昏之间。

闭起眼睛时，眼底前好像有浮光掠影的色彩，脑中好像有被夜店中的超巨 THX 音响系统轰炸了整个晚上后的感觉。但是，就是没有大笑，也没有见到我当时所信的菩萨。
