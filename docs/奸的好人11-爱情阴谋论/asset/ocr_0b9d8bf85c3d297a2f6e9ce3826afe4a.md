# 十八分钟的差距

在我的追女班中，一些男人会问我关于性的问题，所以我也开玩笑式的自誉为欲海奇男。

最多人问的问题是：做爱怎样可以持久些？

我不知道东方人的社会有没有做过这个统计，不过美国有以下的这些数据：男人达到高潮的平均时间是两分钟多，女人达到高潮的平均时间是近二十分钟，美国女人的人生第一次高潮岁数是三十五岁。

不难想像为什么男人会执着一定要把时间拉长，起码拉至十八分钟。

# 男人对阳具的执着

古往今来的男人，（除了和尚），都想尽办法来延长时间。甚至乎有一个揶揄“威而刚Viagra”的阴谋笑话，它是说所有的科学家一直以来的目的（即“本地风光”），就是要发明使男人增长性交时间的药物，而在研发的过程中科学家们不小心的开发出其他“沿途风光”的药物，如：盘尼西林、阿斯匹林、互联网等等。

如果医生跟男人说，服食这个壮阳药的人有百分之十的人可能会因心脏病爆发而死。男人或许会眉头深锁，很关切地问医生：“你的意思是警告我吃了这个药后我可能会死，但它却会帮我的阳具变长两倍，同时可以保持勃起四个小时？”

“是的。我身为你的医生，有义务要向你报告药物的风险。”

“他妈的！你是我的医生，怎么不提早告诉我有种药？”

同样的，要男人戒除某种恶习的话，只要找出一份很详尽分析他的那种恶习会导致阳痿的医学报告给他看即可。我担保不管他的恶习已经多久，他都有办法戒掉。

除了西医有出售的男人救星“威而钢”，也有不少民间的壮阳秘笈流传着。
