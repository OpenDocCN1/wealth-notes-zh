# 女人爱美的目的

“让自己更漂亮，更具吸引力。”

“那么女人为了要更漂亮，更吸引人，目的是为了什么？”

答案是在我们的《冷血救世》一书写得很明白了，女人会说自己更漂亮就会更有信心，但，如果要说得直接一点，女人爱美而得的信心，就是来自于比其他女人更漂亮。

再讲的白一点：“女人的爱美的信心来自于比其他女人……更吸引男人。”
