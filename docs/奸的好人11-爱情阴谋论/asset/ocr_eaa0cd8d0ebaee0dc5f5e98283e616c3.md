江郎鬼才有话说：男人如果要等到打听到心仪对象分手的消息才正式启追，通常已经太迟了！因为她是有了新男人才是正式分手的。

这是一个好消息和坏消息，因为有男友或老公的女人更容易追，所以单身的朋友可以放胆去追。而身为男友或老公的，这个坏消息可以提醒自己不要偷嫖。

# 第三者和正派情人的角力

正处于热恋期的女生，我们用什么方法来追都会很难。但，只要不是热恋期的女生，多多少少都已经开始机械化，甚至可能还开始觉得“闷”，认为跟男友相处的节目不外乎就是那几种活动：出外吃放、喝酒、看戏，或在家吃饭、看电视、轮流等、

过了热恋期的女生已经更明确的看到自己的男友的缺点，假如没有其他新的男人追她，只要男方的策略让女人觉得很受用，能挑逗让她心动和擦出火花，女人的第一个被启动的感觉是“被认同”的开心；随之可能就会很机械式的想起“哦，我已经有了伴侣，可能不应该搞”。

但接下来，“对比法则”就一定会被启动，开始以这个新追求者的“优点”来与本身的旧有伴侣的“缺点”作对比，这就是我在前言中所说的——爱情体制的漏洞了。

所以天生的感情是很脆弱的，因为主观上新鲜的东西是永远是很容易把机械性的旧东西给比了下去。这时候，这个有男友的女生就会开始产生矛盾了。

江郎鬼才有话说：只要不是热恋期，有男友的女生跟容易追（条件是擦出火花），有女友的男生更容易出轨（条件是否能完全不被伴侣知道）。

# 单身和双身的“挑剔度”分别

有男友或老公的女生，若出轨的话，对找男人的要求会低于单身的女生。假如单身女性是想找“白马王子”的话，已有伴侣的女生想出轨时是可以接受找一个黑社会的小混混。已婚或有男友的女生要出轨的时候，对第三者不大挑食，可是一旦她们回复单身，她们对男人的要求就会提高。

同样的，已经有女友的男生，他想出轨的对象可能是一个样貌普通的女生，但是一旦他恢复单身的话，普通水平样貌的女生则未必能吸引他。

就好像克林顿当年丑闻，他就是选一个最顺手的对象——白宫实习生。偷情往往是“莫问好或丑，最重要顺手。”
