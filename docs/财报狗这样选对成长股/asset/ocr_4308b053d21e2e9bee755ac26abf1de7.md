# 遷廠完成後，飛捷營收獲利持續成長

+   A.飛捷單月營收
B.飛捷年度營收、稅後淨利

![](bbox=[0.28, 0.5, 0.62, 0.92])

由於飛捷新廠的產能是舊廠的數倍以上，擴廠完成後飛捷的營收與獲利開始出現顯著成長，在擴廠前的2010～2011年營收呈現衰退，但擴廠後的2011～2014年間營收合成成長率達15.9%，稅後淨利複合成長率更高達21.1%，優於營收的成長（詳見圖8B），主因飛捷的費用率控制得宜，從2011年的14.2%大幅下降至2014年的10.6%。由於飛捷的潛在產能還是遠大於現在的產值，因此飛捷的觀察重點在於需求端。

# 福興：2014年轉移產能後，獲利節節升高

福興（9924）是生產閥鎖的公司，主要工廠位於中國，主力客戶則以占比超過60%的歐美為主，我們也曾4.4介紹美國房市復甦時提到它。若以長線獲利來看，福興仍處於成長趨勢中，但短期也是有些颠簸。
