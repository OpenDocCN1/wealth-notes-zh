# 成功打入新客戶
可望增添成長新動能

4.1與4.2所提到的成長動能，都是由深有成客戶提供，可能是強有成戶本身大幅成長，或是既有客戶的滲透率大幅提高。本文提到的成長性，則是來自於公司打入全新的客戶，因而獲得新的成長動能。

公司打入新客戶，意味著新的成長動能，當然是令人高興的事，不過既然是第1次合作，就代表需要經過較長時間的磨合，且失敗機率不低。

開發新客戶大致可分3種狀況，以成功機率從高到低排序，分別是：原產品增加新客戶、打入產業新星供應鏈、參與產業巨頭創新計畫；介紹如下：
