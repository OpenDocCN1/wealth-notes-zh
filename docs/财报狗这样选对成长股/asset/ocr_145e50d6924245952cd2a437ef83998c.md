# 《指南3》工業：2012~2014年復甦最明顯

景氣復甦初期，大部分企業都會期望，不敢大舉投資，但若要等到軍市、房市都復甦後，代表景氣復甦的態勢較明確了，此時企業才會增加投資的力度。我們來看一些例子：

# ○受惠台股1：工業電腦（艾訊）

艾訊（3088）是台灣工業電腦龍頭廠研華（2395）的轉投資子公司，業務主要可分為自有品牌與 ODM（委託設計製造），其中自有品牌包括數位看板、車載通訊系統、軌道交通、綠能等，占總營收約 65%；ODM 則以博奔、POS（終端銷售系統）、投票機等，占總營收 35%，此部分由於是專業
