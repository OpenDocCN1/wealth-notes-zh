# 狀況4》客戶擴廠

當客戶因業務成長，展開擴廠計畫時，最先受惠的就會是設備供應商了。像是自動化設備組裝廠鐳程（3498），近幾年就是受到大客戶鴻海（2317）的擴廠而大幅成長（詳見1-4）。台股的設備商多半是電子股，我們就來舉個較特別的例子：漁網產業。

# 金洲：養殖業客戶擴廠並購入高毛利產品

金洲（4417）是生產各式網、線、繩的專家，其中漁網占總營收約略超過一半，而漁網中又以開船捕魚用的「圍網」占多數，約占總營收的30%～40%，而養殖業用的「箱網」則是占總營收10%～20%。
