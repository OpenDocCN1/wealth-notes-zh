# 汽車捲簾廠：皇田2013年起獲利大幅成長

皇田（9951）的主力產品是汽車窗簾，包括側簾、三角窗、電動後簾、遮物簾等，皇田在2012年前獲利算是相當穩定（2008年大虧主因操作衍生性金融商品失當），而2012年起休旅車開始流行安裝天窗捲簾，皇田順利打入天窗捲簾大廠Indalga供應鏈，2013年起獲利大幅成長，而2014年又順利成為福斯（Volkswagen）第2供應商，獲利再度躍進（詳見圖5）。
