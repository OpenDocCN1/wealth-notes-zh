# 原料料步入空頭
產業上游吹冷風、下游迎暖陽

由於全球薪資持續推升，人工成本占營收的比重多半呈呈環上升趨勢，不過原料成本就不是這麼回事了。以原物料來說，價格取決於供需，由於原物料的供需可能在短時間內大幅改寫，故價格也存在大幅波動的可能，短短2~3年價格出現數倍的波動更是時有所聞！

一般來說，人工成本占總成本的比重約在10%~20%之間，但原料成本卻常占總成本超過一半以上！所以在大部分的情況下，原料成本是比人工成本還要關鍵的，只要原物料價格出現顯著波動，就會讓公司的獲利跟著上下震盪。

原物料價格出現上漲或下跌時，究竟對公司是利是壞？要視公司在產業的上下游而定，理論上，原物料價格上漲時是對產業上游有利，對產業下游不利，而原物料價格下跌時則相反。為了解釋這個現象，我們直接舉3個最近出現大幅波動的原物料與相關產業來說明：
