# 處分虧損事業
可望帶來短期轉機

當公司的投資計畫成功時，公司與投資人都開心，但若投資計畫不如預期導致虧損還債，除了公司會傷腦，投資人可能更頭痛了。如果計畫還有特效，仍存在改進的空間，公司當然要奮鬥一下；但若起死回生的機會不大，公司就要考慮是否早日壯士斷腕，先幫公司止血，未來再找新的投資機會了。

若公司的投資計畫失敗，除了獲利會受到影響外，股價也可能跟着大跌，此時若公司考慮斷尾求生，處分虧損事業的話，雖然放棄了一些成長機會，但至少先讓公司的獲利回升至正常狀態，股價通常也會跟着回升，畢竟留得青山在，不怕没柴燒。處分虧損事業主要可分成 3 種情況，我們分別介紹如下：
