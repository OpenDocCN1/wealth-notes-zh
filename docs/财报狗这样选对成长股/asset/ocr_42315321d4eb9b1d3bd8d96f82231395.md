# ■南漳2011年後營收增加，但獲利反而更差

——南漳年度營收、營業利益、稅後淨利

![](bbox=[0.25, 0.15, 0.78, 0.75])

資料來源：財報狗、公開資訊觀測站 整理：財報狗

銷售狀況差又碰到商標問題，公司馬上就收掉該事業。2011年1月時，南漳又踏入全新的領域——水產養殖，主要的產品是石斑魚、鱸魚等。2011年水產養殖貢獻營收達15億元；帶動2011年營收飆升至19億元，較2010年大幅成長2.8倍（詳見圖5）。

飆升的營收有沒有為南漳帶來顯著的獲利呢？答案有沒有！加入水產事業後，南漳的毛利從2010年的18.1%大幅下滑至2011年的9.01%，整體營業利益也只有4,000多萬元；貢獻南漳的EPS不到1元，至於當年度2.8元的EPS則是靠處分土地的業外貢獻（但股價卻也從不到20元飆漲至60元，實在神奇！）隨後由於南漳水產事業績效不佳，獲利持續衰退，2013年時營收持續超過4元1由於獲利持續衰退，股價也持續下滑（詳見圖6），2015
