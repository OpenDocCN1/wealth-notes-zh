# ◎西柏：往高單價產品演進，毛利率提升

西柏（3541）是影音處理器代工廠，工廠與協力外包廠都位在台灣的新北市中和區，也未於中國設廠。西柏在 2009 ～ 2013 年受惠於產業趨勢穩定成長，2014 年則受惠於影音專輸規格 HDBaseT 普及，兩大客戶同時拉貨，導致營收大幅成長。2009 ～ 2014 年這段期間，西柏的毛利率呈長線上 升趨勢，2009 年時約 30.1%，2014 年時已上升至 38.9%，漲幅相當大（詳見圖 3A）。

西柏 2009 ～ 2014 年人工成本上升不少，不過也是跟著這段時間的營收與產出提升。人工成本占總成本比重從 10.8% 降至 10%，表現不錯，而人工成本營收比重則從 7.6% 降至 6.1%（詳見圖 3B），對毛利率的提升也有幫助。
