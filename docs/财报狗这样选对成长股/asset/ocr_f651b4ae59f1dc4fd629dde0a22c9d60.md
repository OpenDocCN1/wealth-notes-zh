# 2010年後，怡利電EPS年年成長、鼎天尚平穩
怡利電、鼎天年度EPS

鼎天(3306)是早期的GPS三雄之一，但隨著智慧型手機都搭載GPS功能後，另外兩雄環天科(3499)、具天(3431)已陷入娟平邊緣，唯有鼎天近期轉型成功，縮減白牌個人導航機，積極轉入軍用市場，從怡利電的GPS模組供應商，搖身一變成爲車載影音設備的競爭對手。不過鼎天的車載影音設備還在起步階段，獲利仍屬平穩，尚未出現大幅成長。
