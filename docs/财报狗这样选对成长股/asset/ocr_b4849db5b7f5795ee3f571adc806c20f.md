# 趨勢(3)物聯網：成長性高但應用領域分散

2014年台灣電子（2330）張忠謀董事長在台灣半導體協會發表演說時，點名半導體的下一個亮點會在「物聯網」（Internet of Things，簡稱IoT）。此言一出，投資機構就開始尋找所謂的物聯網概念股，並砸下重金投資。
