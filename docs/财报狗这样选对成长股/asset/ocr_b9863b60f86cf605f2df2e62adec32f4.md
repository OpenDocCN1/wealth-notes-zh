# ◎受惠者：東北亞航線為主的旅行社

根據日本觀光局統計資料，2014 年前往日本旅遊人次最多的國家，竟不是人口超過 10 億人的中國，也不是邻近日本的韓國，而是只有 2,400 萬人口的台灣！可見台灣人是有多愛去日本了。近年台灣人會喜歡去日本玩，除了喜歡日本的美食與文化外，最主要的原因還是日圓大幅貶值，導致去日本的旅遊花費大幅下降。
