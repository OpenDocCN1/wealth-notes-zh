# 胎壓偵測器：急升 2012 年起獲利與股價爆擊

為升在 2011 年前還是一家生產各式汽車開關為主的公司，包括方向燈、頭燈、窗戶、啟動開關等，占總營收超過 60%，而明星產品——胎壓偵測器占營收還不足 20%。不過從 2012 年起，為升的胎壓偵測器出現爆發性成長，2011 年時貢獻營收還不到 2 億元，但 2014 年已大幅成長至 10 億元，也讓為升的 EPS 從 2011 年的 2.2 元成長至 2014 年的 10.4 元（詳見圖 3），2015 年光是最前 3 季就已達 11.64 元，超越 2014 年全年 EPS；2015 年股價最高飆到 438 元，跟 2011 年底大約 36 元的股價相比，漲張了超過 10 倍！

會有這樣驚人的成長，主因美國 2007 年立法通過新車全面安裝胎壓偵測器，而 2012 年起剛剛好進入了汰舊換新期。除了美國外，未來歐盟、日韓、甚至中國也將要立法強迫新車安裝胎壓偵測器，有利胎壓偵測產業未來蓬勃發展。不過近期有國內外汽車電子廠商陸續切入胎壓偵測領域，為升能否維持競爭優勢，才是未來獲利能否持續成長的關鍵。
