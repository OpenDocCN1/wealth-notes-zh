2012 年廣隆營收出現大幅成長，主因中國政府頒布了「鉛酸電池准入條件」嚴格規範該產業，使得鉛酸電池製造商從 2,000 家以上降至 300 家以下，廣隆商取得空缺的市占率。2013 年中國政府的調控力道稍微縮減讓產業喘氣，廣隆數目又稍微增加；廣隆營收也出現短暫回穩，不過 2014 年後又回復上升趨勢（詳見圖 2）。廣隆在 2005 ～ 2014 年間，營收年增率高速 19%，稅後淨利年增率更高達 43%；可以說是中國政府調控鉛酸電池產業的最大受惠者。

由於 2016 年後中國可能會再祭出新措施調控鉛酸電池產業，像是徵收 4% 消費稅等，中國鉛酸電池廠的競爭力又會再下滑，對廣隆也是利多，不過幫助沒有之前這麼大就是了。
