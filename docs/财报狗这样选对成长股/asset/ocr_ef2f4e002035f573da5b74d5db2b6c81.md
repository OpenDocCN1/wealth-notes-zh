# 近年帝寶、昭輝獲利上升
帝寶、昭輝年度EPS

![](bbox=[0.31, 0.14, 0.52, 0.83])

昭輝（1339）的主力產品是保險桿與水箱護罩，且主攻美國 AM 市場，占營收超過90%。昭輝近幾年通匯CAPA認證的產品比重也是持續增加，也受益於遠通美國AM件提升的趨勢，再加上大客戶IKQ增加昭輝訂單比重、擴產等影響，近幾年獲利快速上升。不過2015年昭輝購併了一家中國汽車飾件公司，正式踏入OEM，由於還在磨合改善期，公司的本業獲利出現衰退狀況，未來可觀察經營是否出現改善。

# 醫療產業》調整補貼、設立認證衝擊相關產業

醫療產業由於與國民的健康息息相關，政府介入並訂立相關政策顯然是必須的。一般來說，醫療法規的種類相當繁多，但是以「調整補貼」與「設立認證」
