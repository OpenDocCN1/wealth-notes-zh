# ◎衰落：塑膠鏡頭落後歐（玉晶光、新鉅科、亞光）

在台灣塑膠鏡頭產業淘汰賽中，可以說是只有一個贏家，剩下的全是輸家。

玉晶光（3406）在 2011 年時還算是大立光的頭號對手，兩家廠商幾乎分食了 iPhone 的鏡頭，但在 2012 年蘋果 iPhone 5 推出後，由於製造難度大幅提升，玉晶光的技術逐漸跟不上大立光；兩者差距愈來愈大，玉晶光甚至在 2013 年後陷入虧損，股價從最高點超過 400 元跌至 40 多元，跌掉了 90%。

除了玉晶光外，其他玻璃鏡頭廠商如新鉅科（3630）、亞光（3019）等也陸續切入塑膠鏡頭產業，但這些廠商技術仍落後大立光不少， 2014 年全數陷入虧損（詳見圖 4）。
