# 財報夠這樣抓到成長股

我們再細部觀察豐泰的利潤率，可以發現豐泰的長期毛利率並沒有增長，這是因為雖然產品的平均單價有提升，但由於占製鞋產業成本相當高的「人工成本」近年來快速增加，2009年時人工成本占豐泰營收只有 17.2%，但到 2014年已上升至 23.1%。也就是說，人工成本的上升抵消了豐泰價格調升的利多。

雖然毛利率沒有增加，豐泰的營業費用率（以下簡稱費率）卻從 2007年的 14.5%下降至 2014年的 11.1%，主因這些年來研發費用都控制在 3%左右，但推銷及管理費用卻從 2007年的 11%下降至 2014年的 8%，代表豐泰在管理與行銷活動的成本管控上相當優秀。費率率長期下滑，是豐泰稅後淨利成長可以超過營收成長的主因。
