# 看生活產業變革 從食衣住行控股份

PART2

此外統一超還踏進了鮮食業，開始搶外食族生意，傳統便當、養大利麵、菜碗燕、炸雞……等什麼都賣，甚至還要從日本引進現場「炒飯（麵）」來搶小吃攤的生意。統一超的鮮食營收已占台灣7-11的15%～20%，每年以10%速度成長。

要做這麼多服務，大店化是必須的，傳統的便利商店只有25坪左右，但大店則是占30～50坪，有些大店甚至近百坪。一般店升級成大店後，營收可出現10%～15%的成長，再加上大店化後，銷售不少自有品牌產品，毛利率較高，對獲利貢獻更大。統一超在2009年時大店比重只有20%，到2014年底已成長至65%，這也是統一超的獲利在2009年後可持續上升的主因。
