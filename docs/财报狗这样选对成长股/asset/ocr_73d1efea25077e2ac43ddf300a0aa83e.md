# 發展風電產業》2007年起，風電裝置大幅成長

◎影響台股：風電葉片樹脂製造商（上緯）

要降低空氣污染，除了要淘汰落后產能外，發展再生能源也是必須的，風力發電當然是選項之一。

中國為鼓勵本土風力發電業者，在2007年時實施「70%本地自製率」政策，從此本地業者大舉建設風電裝置，2006～2010年新增風電裝置複合成率高達96%！然而裝機量雖多，卻碰到了相當多問題，像是裝置電壓不穩導致多起安全事故、儲電系統差導致風電調峰（詳見注1）能力不佳、電網建設不足導致偏遠地區發電無法轉送其他地區等。

於是，中國政府於2010年又發布「風電設備製造行業準准入標準」（詳見注2），開始調控風電產業，導致新增風電裝置在2010～2013年間幾乎零成長，不過中國政府此時也沒閒著，在2013年完成大規模的電網建置，2014年起放寬風電產業進入門檻，於是新增風電裝置又回到兩位數的成長。

上緯（4733）是專門製造各類「樹脂」的廠商，包括環保樹脂樹脂（工程用）、風電葉片樹脂、節能LED封裝樹脂等；其中環保樹脂樹脂與風力葉片樹脂，上緯都是全球前5大廠商，銷售地區則是以中國為主，占總營收超過

注 1：調峰：在用电高峰时，电力系统进行调节，以避免系统负荷过大。

注 2：风电设备制造企业准入标准，包括生产能力、设品质量、人才、研发费用占营收比重……等条件须符合规定，才能成为风电设备制造商。
