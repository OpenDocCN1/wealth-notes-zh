# # 迎戰3大衝擊
## 台灣食品產業「質變」

我們在2.1提到的服飾產業變革……機龍頭驅動變革，與2-汽車產業變革：電子化、高階化、電動車崛起等，都算是一種「全球趨勢」。而本文介紹的食品產業變革，則偏向「在地化」趨勢，像是台灣臺灣人口年齡的改變、店家轉型、台灣食安事件等。這些事件雖與國際無關，卻大大改變臺灣的食品產業。

民以食為天，食品產業是個古老但重要的產業。台灣經濟發展已穩定，從產業來看，食品相關產業成長性並不高。話雖如此，近幾年來卻有幾股趨勢發生中，衝擊著這個產業的「質」。這些趨勢由長到短分別是人口結構轉變、便利超商轉型、食安風暴等，分別介紹如下：
