# ◎購油成本下跌成為航空公司利多——以華航為例

油價下跌既然有受惠的公司，就會有受惠的公司，其中又以航運股受惠最
大。一般來說，石油占船運公司的成本達 20%，占航空公司的成本更高達
40%！所以只要油價下跌，對航運股當算是利多了。

營收 64%，營收高低依次為越太平洋航線、東北亞航線、東南亞航線、兩
岸航線等；貨運占營收 29%：其中越太平洋航線占營收超過 50%，歐洲與東
亞航線約各占 15%。
