# 營業費用率大增
佈局前要釐清主因

除了找出營業費用率（以下簡稱費用率）下降的公司外，我們還可以找出費用率大幅上升的公司。因為當費用率大幅上升，代表公司碰上了一些麻煩，若判斷此麻煩不至於影響公司太久，就可考慮在此時佈局，等麻煩事過去後再甜蜜收割，同樣可分爲年、季兩種觀察方式：

# 費用率》出現3個百分點以上增幅

當公司的年費用率增加了 3 個百分點以上（篩選方法詳見圖 1），就代表公司可能碰上麻煩了！當找出費用率顯著上升的公司之後，就要判斷公司陷入了什麼樣的困境，短期內能否出現轉機了。

# 案例）篇潤：侵權和解金＋客戶訂單取消，造成費用率大增

篇潤（6187）是設備製造商：主力產品是半導體封測設備，客戶爲日月光（2311）、矽品（2325）等封測大廠，佔營收約 40%；被動元件設備佔營收 24%，爲第 2 大產線；主要客戶也是國內的被動元件大廠國巨（2327）、華新科（2492）等；剩下還有一些 LED 設備、檢測設備等。近幾年由於景氣逐步回溫，對設備大廠篇潤的營收與獲利也有些許幫助。
