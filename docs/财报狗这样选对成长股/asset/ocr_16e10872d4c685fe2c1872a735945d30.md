# 圖解查詢》近一季營收成長大於20％標的

以財報淘網站為例，進入選股邏輯功能後，點選⑥「財報淘VIP」，接着選擇②「營收成長篩選」，設定⑩「近一季營收」條件為①「較前一季成長20%」及「較去年同期成長20%」（亦可視個人喜好與需求調整），並將兩項加入篩選條件中即可。

宏捷科（8086）是神化的晶圓代工廠，我們曾在本章1-5中介紹過。從財報可發現，宏捷科營收在2014年第2季時出現了顯著成長（詳見圖5），符合我們的選股條件，而當時的獲利和股價都還算在相對低檔。
