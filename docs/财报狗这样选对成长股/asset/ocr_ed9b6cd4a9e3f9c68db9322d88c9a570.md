# ◎ F·世态：受惠比特幣淘金潮，打造挖礦機供應商

再看另一個例子，這兩年有一種貨幣暴紅：不是美元，也不是人民幣，而是「比特幣」（Bitcoin）。比特幣系統是在2008年時，被一位謎樣人物中本聰所提出（詳見註1）；簡要來說，比特幣是一種存在於網際網路的數位虛擬貨幣，用戶只要提供電腦的運算能力以供比特幣系統的運作，就有機會獲得比特幣作為報酬，而這個過程被稱為挖礦。根據最初的設定，世界上的比特幣總量，總共只會有大約2,100萬個，預定2040年會全數開發完畢。

2010年時開始有人用比特幣交易，起初1比特幣只可換0.0025美元，而後比特幣持續升值，2012年時比特幣已升值至30美元左右。2013年11月時，比特幣出現了飆漲行情（詳見圖6），最高竟漲至1,200美元，甚至超過了黃金的價格！

由於比特幣的暴漲，網路一開始出現了比特幣的淘金熱。此時誕生了一種行業，就是比特幣數位挖礦商，只要購買挖礦商的產品，就能夠加入比特幣的淘金行列。其中最著名的挖礦商KnCMiner，已成為全球最大。

F·世态（3661）是特殊規格邏輯IC（ASIC）設計服務商，與創意（3443）、智原（3035）類似。F·世态早期主力產品是數位電視、消費電子等產品，2013年起搭上了比特幣持快車，成為KnCMiner的晶片供應商，2013年時KnCMiner貢獻F·世态營收的新台幣2億3,000萬元，約占營收9%。
