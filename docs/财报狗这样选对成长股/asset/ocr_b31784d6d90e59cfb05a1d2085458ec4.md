# ◎聚陽：2013 年後量產機能服飾，獲利明顯增加

聚陽 (1477) 是成衣製造商，主要的客戶是流行服飾業者或是大賣場，像是 Kohls、Gap、Target、Wol-Mart 等，主要是美國客戶；而聚陽的生產基地則是遍布各地，但以東南亞為主，如越南、印尼、柬埔寨等。

若以 2007～2014 年的長線趨勢觀察，聚陽的 7 年營收複合成長率約 5%、稅後淨利複合成長率約 6.4%，算是不錯，但稱不上出色，但若把聚陽分成兩個時期來看，2007～2012 年的營收複合成長率只有 1.3%、稅後淨利成長率也只有 1.3%，表現一般級；但 2012～2014 年的營收複合成長率則高達 14.7%，稅後淨利複合成長率則是高達 20.1%（詳見圖 1）！

會有這樣的差別，主要與聚陽的發展策略有關。聚陽在 2012 年以前還是以生產一般流行服飾為主，且從投資現金流可發現，公司多年來並無大規模擴廠動作。

經過多年的研發，聚陽在 2013 年起開始量產出貨機能服飾，從客戶端可以看到具體的成果。像是聚陽在 2013 年打入日本平價服飾優衣車 (Uniqlo) 供應鏈，幫其代工一般服飾與機能服飾，預計 2015 年可占聚陽營收 5%～
