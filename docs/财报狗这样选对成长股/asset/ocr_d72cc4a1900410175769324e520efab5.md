# 月營收》較上個月、去年同月成長30%

若公司的單月營收出現大幅成長，等到季營收公布才知道就太落後了！這時就可考慮月營收來變數，時效性可再提升！只要設定公司的月營收較上個月、去年同月都成長30%以上，就可找出月營收顯著成長的公司（篩選方法詳見圖7）！來看個例子：
