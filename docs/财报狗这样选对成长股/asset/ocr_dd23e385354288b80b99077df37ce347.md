# 內嵌式觸控需求大增，重壓觸控面板業

+   ◎衰落：觸控面板 (F-TPK、勝華、洋華、介面)、觸控供應鍵 (正達、安可、鈴旺科、友輝)

我們在 1-1 曾提過，由於智慧型手機、平板的興起，觸控面板業者的身價都跟著水漲船高，不管是以 Filin-Type (薄模式) 技術為主的洋華 (3622) 、介面 (3584) ，或是以 Glass-Type (按模式) 技術為主的寬福 F-TPK (3673) 、勝華 (2384 ，已下市) 等，獲利與股價都曾因此受惠。

不過，自從 iPhone 問世後，Glass-Type 成為主流，Film-Type 的洋華、介面逐漸遭市場淘汰，而 Glass-Type 的 F-TPK 可謂一枝獨秀；這項技術之所以能取代 Film-Type 成為市場主流，是因為它的觸控反應較敏捷、提供使用者較好的觸控體驗。F-TPK 藉如此技術，吃到第 1 代 iPhone 到 iPhone 4i 的訂單，寫下傲人的獲利成績。
