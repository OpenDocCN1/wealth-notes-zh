# # 國家法規制定
## 影響產業發展基石

第 1、2 篇介紹的科技發展趨勢與生活產業變革，多半是在自然情況下發生的，可能是供給面的技術剛好到位，或是需求面產生了變化等，本篇要介紹的產業變化，則是取決於政府或國際組織的管控，屬於法規面。本文先介紹「國家法規」，也就是各政府對國內產業所訂立的法規，對於產業造成的影響。

一個國家的政府對於各行各業的管理上，要站在什麼立場呢？一般來說，不要管理就是最好的管理，但在某些情況下，像是牽涉到安全、健康、教育、道德等議題時，政府還是要介入並訂立好遊戲規則，對整個產業的經營者與消費者是最好的。
