# 相關台股：鈊象

鈊象（3293）早期是專門做商用遊戲機台的公司，其中包括了益智類、模擬類、博弈類等，爾後也滄進了線上遊戲市場，以2015年而言，商用遊戲機與線上遊戲約各占營收一半。

鈊象的商用遊戲機台主要是出貨中國與義大利市場，這兩兩個國家都會用法規調控博弈、遊樂場產業，對鈊象的獲利造成顯著影響。鈊象2005～2009年獲利大幅成長（2008年因金融海嘯短暂修正），主因在2006～2009年陸續發生了中國遊樂場試點營運、義大利通過法令成換機潮、中國遊樂場全面解禁等，使得鈊象這段時間的商用遊戲機銷售大幅成長，2005年時實獻營收只有8億2,000萬元左右，2009年時已成長至22億元！

此外，這段時間也是台灣線上遊戲的黃金期，鈊象的線上遊戲營收也從2005年的3億2,000萬元成長至2009年的11億5,000萬元。

不過2010年陸續發生了義大利換機潮結束、中國遊樂場產業從嚴審查等，商用遊戲機台出貨開始下滑，再加上智慧型手機與平板興起，App（行動應用程式）遊戲取代了大型線上遊戲市場（1-1提到的趨勢），在這兩股法規趨勢、科技趨勢的作用下，鈊象的EPS從2009年的超過18元，跌到2013年的1.7元（詳見圖6）！可見了解趨勢的發展是何等重要。

為了解決困境，鈊象投入重金佈局App遊戲，再加上中國商用遊戲機市場已轉趨開放，義大利也可能會有博弈法規通過，鈊象未來獲利有機會回升。
