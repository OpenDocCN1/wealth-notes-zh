# 產業1) 電商：產值高速成長、網購、貨運受惠

根據國際市場組織 eMarketer 與資策會產業情報研究所（MIC）的研究顯示，台灣電子商務在 2010 ~ 2014 年產複合成長率高達 20%；成長速度相當驚人；但台灣的電子商務占整體批發零售的比重只有 4%，遠低於韓國的 10.1%與中國的 7%，滲透率仍低，預估未來數年，台灣電子商務仍可維持 10% 以上的高速成長趨勢。
