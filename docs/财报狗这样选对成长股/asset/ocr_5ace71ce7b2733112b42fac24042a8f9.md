# 投資選對小金雞
帶動母公司獲利飆升

我們在6.2介紹的公司發展的「新事業」，多半是指公司本身直接切入該產業，或成立100%持股的子公司來經營該事業。而本文則是指公司以投資方式，持股比重可能不高，但仍能享受被投資公司的經營成果。當被投資公司的股價或獲利出現爆發性成長時，持有這隻小金雞的母公司也不會錯買的。

當公司想要賺錢時，不一定要自己來開啟事業，而是可以靠投資的方式來享受對方經營的成果。就實務上，要投資對方公司就是買入對方的股票即可，但會計上則較為複雜，要看投資公司對被投資公司的想法是什麼，是想要持有長期還是短期？持有的比重多少？都會影響到會計上的認列方式，分別介紹如下：

# 短期投資以公平價值法認列

當投資公司（投資者）持有被投資公司（被投資者）的股票比重過低時（一般是指小於被被投資公司所有股份的20%），投資公司即被視為「無重大影響力」，且若持有時間又是以短期為主，那麼會計上的評量方式最簡單：即所謂的「公平價值法」，而公平價值法也是台股上市櫃公司投資股票最常見的會計方式。
