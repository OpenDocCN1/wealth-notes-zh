# ① 車載影音設備：哈利電市占持續拉高、鼎天起步中

哈利電（2497）為專門生產車載影音設備的廠商，其中又包含車載影音導航系統、後座娛樂系統等。由於新車搭載影音設備的比率一直在提高，中國市場的產業成長率甚至高達 20%。

哈利電 2010 年起陸續打入中國前 3 大車廠，在中國的營收占比已超過 50%，在東協、台灣的市占率也持續提高，造就了哈利電近幾年的獲利榮景；2010 年每股稅後盈餘（EPS）還不到 1 元，2014 年已達 4.5 元（詳見圖 2）。
