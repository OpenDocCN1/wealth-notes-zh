# 獲利關鍵因子 找到企業成長動能

福興的上海廠遭上海市政府徵收，2013年起停止生產，福興將此產能移轉至常熟與岡山廠，但由於福興的數種較複雜，轉移初期良率不佳，毛利率出現下滑情況。但由於2013年認列了上海市的遷廠補助金共約2億7,200萬元，此外又剛好處分絡果（3060）持股，獲利約1億元，業外收益不少，導致EPS反而創新高。

而2014年已調整完成，福興毛利率開始回升，但由於少了遷廠補助金，EPS反而出現下滑的情況；不過本業獲利其實是創下新高的，2015年繼續成長（詳見圖9），上半年獲利已較去年同期成長了78%。
