的時候公司可以賺大錢，景氣差恐怕又要陷入虧損，從單季獲利來看就可以看出這種大起大落的特點，股價也隨之波動，這對公司的經營相當不利，於是智威從 2015 年開始嘗試新的商業模式，就是採取與遊樂園「分潤」的方式，智威將設備交貸給遊樂園時，只收取部分款項，之後再從遊客搭乘體感模擬遊樂設備的營收當中抽成。

雖然智威力推此種分潤模式，但畢竟不是一般遊樂園習慣的模式，願意接受的廠商並不多，也導致智威的營收與獲利出現下滑。為了推廣此模式，智威與苗栗尚順育樂中心合作，為其打造包含「進擊的巨人」飛行劇場在內共 15 套設備，就是要采取分潤模式。若開幕後口碑不錯，也確實能為智威與尚順創造雙贏，那麼其他遊樂園或許也會開始接受這個模式。

# F豐祥：新客戶注入獲利新動能

F.豐祥 ( 5288 ) 是越南機車零組件製造商，包括把手、支架、車架、保險桿、底座等，占總營收超過 80% 。豐祥在 2013 年以前，客戶都以傳統機車為主，像是越南 Honda 、越南 YAMAHA 、義大利比雅久 ( Paggio ) 等，由於屬成熟產業，毛利率相對偏低。

豐祥在 2013 年接觸到新客戶——休閒車大廠北極星 ( Polaris ) 。北極星生產的產品包括重機、沙灘車、越野車等，必須相當耐操，對於零組件的要求當然也高，使得豐祥出貨的零組件毛利率也較好。

豐祥 2014 年時開始小量生產休閒車零組件，只占總營收 2% ~ 3% ，預計 2015 年成長至 5% ~ 10% ，若發展順利，未來數年仍有成長空間。由於休閒車比重增加，豐祥的毛利率也呈現上升趨勢 ( 詳見圖 3 ) ，為獲利帶來成長。
