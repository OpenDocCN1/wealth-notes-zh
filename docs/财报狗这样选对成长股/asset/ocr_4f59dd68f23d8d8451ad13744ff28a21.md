# 財報狗這樣建相對成長股

商，冰晶已占南僑營收超過10%。

2014年第4季劣油風暴發生後，南僑的營收與獲利非但沒有衰退，還持續增加，2015年第1、2季，單季EPS創下新高，股價也節節升高（詳見圖9）。在劣油事件發生後，食品廠商、美食通路廠商為了不要再中標、自然會改變生產過程較嚴謹的廠商了。南僑目前在台灣油脂市場的市占率排名第1，超過30%，由於受惠精準事件，市占率還在持續增加。

南僑近幾年獲利快速成長，除了受惠以上提到的油脂市占率提升、全家冰淇淋熱銷之外，也受惠於原料料的空頭走勢；若未來原材料轉向多頭，可能會影響到南僑的獲利，投資人也需留意。
