# 圖解查詢《單季毛利率連續3季上升標準的

在📖「財務狗MV」中，進入🎉「毛利率成長篩選」，設定📈「單季毛利率連續」為📈「3季上升」及「3季較去年同季上升」，然後將此條件加選右方的選股條件。
