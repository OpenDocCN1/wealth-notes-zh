# 歷史總會重演

# 只是換了新的名字

時報狗的第 1 本書《時報狗教你把好股賺 20%》在 2013 年出版時，迅速成為博客來財經書籍的週冠軍；更令人驚訝的是，該書在出版將近 3 年後，還常常重回財經書籍的百大榜上。股票投資書籍銷售熱期一向較短，時報狗的書卻能穩定長銷，顯見讀者对其研究品質的口碑與文章水準的肯定。這樣的成績，在我看來並非僥倖，完全來自作者的勤學研究。

在此透露一個小祕密，因為讀者的殷殷企盼，我們一直在籌畫時報狗的第 2 本書，希望打鐵趁熱，新書能早日出版。但時報狗的態度是，如果沒辦法寫出新的東西，寧願不出版！於是，計畫好的新書就在編輯的癱瘓等待中，一日接一日地度過，原以為這本書恐怕要難產了，但到了約定交稿的時間，編輯預定 250 頁的新書，卻暴增到 350 頁以上，光是圖表就超過 200 幅！

這就是時報狗對自己作品的嚴謹態度，在沒有方向時，寧缺勿濫；但確定方向後，又唯恐不夠詳盡，深怕對不起買書的讀者。

本書的重點在於從股票基本面挖掘成長股，作者耗費巨大心力，深入研究台股過去 10 年中，能成為業績領漲的祕密是什麼？以利於投資人可以根據這些方法，早日挖掘出一檔業績飆股，成為市場贏家。
