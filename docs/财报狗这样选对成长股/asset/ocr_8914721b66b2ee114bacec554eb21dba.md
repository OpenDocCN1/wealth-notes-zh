# 狀況3 參與產業巨頭創新計畫

產業巨頭一般擁有較多資源，並具備一呼百應的影響力，所以若能成為產業
巨頭最新計畫的供應商，當然也是令人振奮的事。若巨頭的計畫成功，供應商
就跟著上天堂；但若計畫失敗，雖然短期內仍可跟著受惠，但以長期角度來看，
可能要賠上研發資源，也要賠掉發展其他計畫的機會成本。
