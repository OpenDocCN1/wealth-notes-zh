# 財務構造轉型對成長股

雖然展店數多，銷售卻不如預期，原因可能與神腦受限於中國聯通的方案限制，營運起來綁手綁腳有關。此外中國薪資、租金都在上漲，導致汰神腦陷入開愈多、賠愈多的窘境，2011年時虧損近1億元，2012年擴大至近3億元，2013年超過5億元，2014年更超過6億元！增加的虧損吃掉了神腦在台灣的獲利，2014年稅後淨利甚至衰退超過6成（詳見圖8）。

最後總結一下，若公司發展的新事業是現有技術的延伸，那麼成功機率就大，而就算失敗的話損失也不大；若是跨入新的領域，成功與失敗機率可能就一半一半，要看經營者有沒有掌握關鍵資源；至於佈建新通路，對很多公司來說就像是跨入新領域級，要是通路當地的薪資、租金成長速度又快的話，那麼最後以失敗收場的機率就很高了。
