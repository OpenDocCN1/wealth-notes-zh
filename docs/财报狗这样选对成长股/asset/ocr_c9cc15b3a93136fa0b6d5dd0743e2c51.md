# 器件4）自動化導入

由於全球工資高漲，因此將自動化設備導入生產流程來取代人工，已成為長期發展趨勢。只要自動化導入順利，對於降低公司人工成本，以及提高製造的良率、效率，都可能有帮助。

# ◎百答：導入自動化降低人工成本，提升毛利率

百答（2483）是電子零組件廠，包括繼電器、程式開關、導線架、連接器等，應用領域包括工業、3C、通訊、LED（發光二極體）等；主力市場在亞洲，工廠設於中國的深圳、東莞、蘇州等地。百容在 2011～2012 年毛利率大幅滑落拖累了獲利，2012 年甚至陷入虧損（詳見圖 10）。

為何這兩年毛利率會大幅衰退呢？當然與中國高漲的人工薪資有關了，2009年時人工成本占營收比重只有 12.6%，但 2012 年時已成長至 20%（詳見圖 11）！

為了解決人工成本上漲的問題，公司已加速自動化製程來因應，2013年時雖然百答的營收成長，人工成本卻小幅下滑，人工成本占營收比重也下降至 18.7%。除了以自動化設備改善人力成本外，公司也實施不少動作來提升毛利率，包括剔除低毛利率訂單、整合集團資源以減少租金成本等，使得百答在 2013～2014 年毛利率與獲利都出現顯著成長（詳見圖 11）。

不過要注意，引入自動化設備對人工成本的控制在短期有效，因為剩下的員工薪資未來還是會成長，像百答 2014 年人工成本占營收比重又重新上升了；除非未來持續引入新的自動化設備，否則人工成本未來仍會造成百答
