# 看獲利關鍵因子 找到企業成長動能

由於中國工資上漲是長期趨勢，定穎若想扭轉現況，勢必得轉往製造較高利益型產品。定穎出的確在這方向努力中，慢慢在提高汽車板與穿戴式裝置等高毛利產品的比重，惟成效仍有待時間驗證。
