# ### 人力成本快速上漲
#### 何處設廠係大

人工成本是公司生產成本中重要的一環，以製造業來說，約占總成本的10%～15%，近年由於全球薪資上漲快速，對各行各業都帶來不少壓力。由於全球各國的工資水平上升速度差距很大，不同的產能布局結果，可能會造成相當大的人工成本差距，進而嚴重影響獲利。

全球各國由於發展順序不一，基本工資也差距頗大，以亞洲來說，日本、韓國的每月最低基本工資都已達1,000美元，比起台灣的600美元左右就高出大截，而台灣比起中國的300美元上下也高出一截，而排在後面的則是發展相對落後的東南亞，依序是泰國、印尼、越南、柬埔寨等（詳見圖1）。
