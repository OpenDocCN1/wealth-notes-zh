# 財務夠意樣絕對成長股

先看北京白砂，2010年時還有獲利 1,890 萬元，2011 年轉虧，虧損金額約 1,200 萬元，2012 年虧損擴大至 1,900 萬元。由於狀況持續惡化，公司與會計師認為帳上資產必須減損，於北京白砂於 2013 起開始提列資產減損，2013 年虧損擴大至 8,000 萬元。由於公司認為北京白砂存活機率不高，於是在 2014 年第 2 季把它處分掉，但北京白砂已在 2013 提列資產減損，2014 年結算時虧損只有 160 萬元。

上海白砂在 2010 年還有小幅獲利約 55 萬元，2011 時轉為虧損 1,800 萬元，2012 時則小幅縮減至 1,300 萬元。由於上海白砂的獲利同樣不佳，也於 2013 年時提列資產減損，使 2013 年上海白砂也是大幅虧損了 8,200 萬元。不過與北京白砂不同的是，公司認為上海白砂還有一線的機會，因此並未收掉，反而再增資約 5,000 萬元。上海白砂在 2014 年虧損大幅減至 2,300 萬元。

由於北京白砂、上海白砂都在 2013 年大幅提列資產減損，使得白砂科 2013 年 EPS 出現 -1.17 元的虧損，不過也由於減損已於 2013 年提列，故 2014 年時營運成本下降，EPS 也回升至 2 元（詳見圖 2）。

雖然上海白砂 2014 年時虧損縮減至 2,300 萬元，不過增資買入的股權看來產能利用率並不高；2015 年狀況再度轉差，上半年虧損金額已達 2014 年全年的 2,300 萬元。
