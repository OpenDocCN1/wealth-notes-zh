( 以下簡稱大車隊 ) 。

大車隊( 2640 ) 是全台最大的計程車叫車中心，全臺市占率達18%。大車隊近幾年營收與獲利成長迅速( 詳見圖1 ) ，2010 ~ 2015 年的營收與稅後獲利成長率都在25%上下。不過由於市占率已接近20%，加上在台北北市占率已達50%，未來再大幅成長的空間相當有限。大車隊也持續擴展業務，像是旅遊、洗衣、銷售遊戲點數卡等，若發展順利，成長動能才得以延續。

除了市占率已高，大車隊也面臨了 Uber 的競爭，雖然尚未看到大車隊有受到明顯的影響，但未來若 Uber 走向合法，對大車隊的衝擊就會提升。此外為了迎擊 Uber ，大車隊也推出 App 服務，不過與 Uber 比起來還有改善的空間。
