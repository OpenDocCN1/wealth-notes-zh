# 2、 高潤於2011、2012年營業費用率大幅升高

高潤年度營業費用率

![](bbox=[0.24, 0.23, 0.49, 0.81])

和解金提列為業外，造成了 2011 ～ 2012年嚴重的業外虧損。此外，由於高潤產品被判定侵害，客戶也被迫取消訂單，造成高潤營收大幅下滑，這使得費用本身雖無大幅上升；費用率還是跟著大幅提高。2013年後由於侵權問題已解決，客戶回覆下單，營收重回之前的高水準，費用率跟著下滑，獲利與股價也緩步回升至原先水準。

費用率較前一年、去年明顯上升

除了邁出年費用率顯著上升的公司外，我們也可從季的角度，找出季費用率較前一季、去年同季同步大幅上升的公司（篩選方法詳見圖 3），如此則有機會更早發現碰上面領的公司，並提早布局。
