# 季毛利率》較前一季、去年同年大幅下滑

若使用年毛利率觀察下滑的隱股法，遇到的多半是公司面臨長期的問題，像是該碼碰的轉型問題等。若從季的角度篩選，選出季毛利率較前一季、去年同年同步大幅下滑的公司，則可找出碰到一次性危機的公司（篩選方法詳見圖 3 ）。至於能否從危機中復原，則要視情況而定。我們來看個例子：

# 圖解查前》近一季毛利率出現縮水標誌

在⓪「財務查前」中，進入①「毛利率成長篩選」，將②「近一季毛利率」設定為③「較前一季減少3%」及④「較去年同年減少3%」，然後將此條件加進右方的選股條件。
