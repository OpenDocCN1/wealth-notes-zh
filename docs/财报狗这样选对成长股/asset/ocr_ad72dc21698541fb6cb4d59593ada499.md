# ◎受惠者：歐洲航線為主的旅行社

旅行社鳳凰（5706）的前身是成立於 1957 年的亞洲旅行社，比雄獅還要老。相對於雄獅的主力放在東北亞線，鳳凰的最大宗則是歐洲線，在 2014 年時賣斷營收約 10 億 9,000 萬元，占總營收約 38%，其次為東北亞線占比 13%，其他航線占比都不到 10%。

由於鳳凰以經營歐洲航線為主，可理解當歐元重貶時，鳳凰的業績應會有顯著
