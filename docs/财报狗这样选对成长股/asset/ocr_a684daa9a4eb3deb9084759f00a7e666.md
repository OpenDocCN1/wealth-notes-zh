# 互聯網產業5公司本益比偏高 網家、富邦媒、商店街、一零四、數字單月本益比

![](bbox=[0.26, 0.17, 0.48, 0.82])

註：本圖本益比計算方式為：月均價 / 近4季累積EPS，最新本益比截止至2015.12.14

資料來源：財報網、公開資訊觀測站整理、財報網

話雖如此，互聯網產業變化多端，若出現了產業轉型的现象，原來的產業霸主仍可能會輸給新型態的競爭者，像我們在[1-1提過的尚凡(5278)，所經營的「愛情公寓」在桌機時代已經是線上交友產業的霸主，但在智慧型手機與平板崛起後，市占率就被各個交友App(行動應用程式)所分食。

另外需注意，由於互聯網產業成長趨勢明顯，市場給予的本益比都不低。本文提到的5家公司中，若以2015年12月中旬股價與近4季EPS計算(2014年Q4~2015年Q3)，只有一零四在20倍以下，數字科技在20~30倍間，而富邦媒、商店街與網家都在30倍以上(詳見圖9)。高本益比就必須要有高成長率來支撐，有興趣的投資人需持續關注這些公司的成長率，投資時機也必須仔細拿捏。
