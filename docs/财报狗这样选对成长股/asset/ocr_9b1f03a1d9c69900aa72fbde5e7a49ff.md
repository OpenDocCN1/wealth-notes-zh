# 網路交易時代
電商、網路服務倍速成長

如果要談出近百年內影響人類最重要的發明，互聯網絕對可排上前3名。前面2章介紹的產業趨勢較偏向硬體產業，而本文介紹的互聯網產業，則是偏向軟體產業，介紹到的公司也偏向軟體公司為主。不過眾所周知，台灣是硬體王國，著墨在軟體的上市公司並不多，未來還有不小的發展空間。

講到互聯網，大家應該都不陌生，因為每天都在使用，但是大家都對互聯網的起源可能都不太了解。互聯網的雛型是美國軍方於冷戰時期（詳見註 1）建立的軍網ARPANET（Advanced Research Projects Agency Network，美國國防部高級研究計畫局網絡），並於冷戰結束後大眾開放成為互聯網骨幹。爾後互聯網開始蓬勃發展，到 2014 年底全球上網人口已達 30 億人，占全球總人口的 42%，而台灣上網人口達 1,763 萬人，占台灣總人口超過 70%。顯然，互聯網已幾乎深入了每個人的生活，其中也衍生出了相當多的商機等供大家發掘。
