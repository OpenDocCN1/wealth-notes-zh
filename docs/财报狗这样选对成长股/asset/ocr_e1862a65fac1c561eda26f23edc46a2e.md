# ◎方式3：合併報表

認定方式：母公司持股比重超過 50% 或具有控制力

影響：被投資公司財務須編入合併報表

若投資公司持有被投資公司股份超過 50%，或是雖不到 50% 但剩下的股權非常分散，一般就會被認為具控制力。除了在投資公司的非合併報表裡，要以權益法列報被投資公司的損益外，投資公司還要與對其具有控制力的子公司合併「合併報表」。我們來看個例子：
