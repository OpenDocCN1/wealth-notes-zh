# ◎案例）宏正：債權官司和解金提到於推銷費用，造成費用率飆高

宏正（6277）的主力產品是 KVM (Keyboard 鍵盤、Video 顯示器、Mouse 滑鼠) 切換器，占宏正營收近 70%，全球市占率約 10%～15%排名第 2，排名第 1 的美商 Avocent 市占率約 45%。

以 KVM 產業來說，宏正是後輩，Avocent 原本產線很廣，但宏正崛起之後，Avocent 就退守在高端市場。宏正雖取得中低端市場的超過一半的市占，但高端市場仍與 Avocent 戰得很辛苦，目前市占率仍低。

# 圖解查詢》近一季費用率大幅提升標的
