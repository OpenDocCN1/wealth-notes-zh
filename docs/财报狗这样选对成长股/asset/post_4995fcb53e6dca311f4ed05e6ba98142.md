
## 愛臺2》織布廠：龍頭續強、2小兵回歸

### 儒鴻：研發機能布已久，獲利持續高飛

以銷售產品來看，儒鴻（1476）與聚陽、鉅旺實一樣，都是以成衣為主，但差別在於聚陽、鉅旺實的布幾乎都是外購的；而儒鴻則是從織布、染整到成衣製造的一貫廠。

儒鴻在2007年時還是以布的銷售為主，佔營收超過60%，成衣不到40%；近幾年加強毛利率較高的成衣銷售，目前成衣銷售已升至60%以上。與聚陽和鉅旺實相比，儒鴻的優勢在於布料的掌控，儒鴻每年投入大量資金在機能布的開發，除了因自製毛利率較好外，更能快速反應客戶的需求。

儒鴻2007～2014年營收複合成長率高達19.3%、稅後淨利複合成長率更是高達38%（詳見圖4），成長性遠高於聚陽與鉅旺實。主因聚陽與鉅旺實都是在近幾年才加強成長性較佳的機能服飾銷售，而儒鴻則是一直專注在機能布、機能服飾的研發與銷售，是這股機能服飾趨勢下的最大受益者。

以客戶來看，各大機能運動品牌早已是儒鴻客戶，像是近幾年才暴紅的Lululemon早在十幾年前就是儒鴻的客戶，與儒鴻合作研發多年後才推出廣受歡迎的瑜伽服飾；Under Armour也已與儒鴻合作多年；傳統運動鞋品牌大廠Nike近年在服飾方面也是發展相當積極，像是高爾夫球服、網球服等也是找上儒鴻代工。由於以上品牌都在快速成長期，加上儒鴻每年都會增加不少新客戶，預計儒鴻短期內還能維持較高的成長性。

台灣的織布廠眾多，但多數仍是製造一般布料為主，像儒鴻專注在高端機能服飾並享有高獲利，可說是少之又少。不過由於機能服飾的高成長性，儒鴻的產能漸漸無法負荷機能服飾品牌廠的成長，於是像 Lululemon、Under Armour 等公司都在積極分散供應鏈，這也提供了台灣其他小廠崛起的機會。

### 得力、宏遠：打入機能服飾品牌，獲利改善

得力（1464）是織布廠，2009～2013年每股稅後盈餘（EPS）都低於0.5元（詳見圖5），2014年因處分上海土地與設備獲利大幅上升，本業並無改善；不過2015年因Under Armour下單量大增，上半年已獲利0.6元。

得力2006年時運動機能布只占營收10%，但經過近幾年耕耘後，運動機能布已超過 60%。未來如果 Under Armour 擴大下單且得力成本、費用管控得宜，獲利有機會再提高。

宏遠（1460）也是織布廠，過去幾年也是獲利表現不佳，不過近期陸續打入機能服飾品牌供應鏈，像是Lululemon、Under Armour、The North Face等，獲利也出現改善趨勢。

## 受惠3》紡紗廠：2大廠獲利增長亮眼

### 東隆興：發展高毛利產品，獲利顯著提升

既然而下游的機能成衣、機能布銷售成長性不錯，那麼上游的機能紗也要有成長才對。東隆興（4401）是亞洲最大的尼龍66 紡紗廠，尼龍66 與最常見的「聚酯絲」的差別在於，尼龍66較強韌、耐磨、重量輕、抗蟲、抗靜電等，很適合作在機能服飾。東隆興生產的絲主要用來製造運動服、高爾夫球服、瑜伽服、內衣等，主要客戶則包括品牌大廠lululemon、Victoria’s Secret、Nike等，儒鴻也是其客戶。

東隆興2007~2014年營收複合成長率只有3%，並不算亮眼，但稅後淨利複合成長率卻是高達17%（詳見圖6），主因東隆興的毛利率不斷上升，2007年時只有11.3%，2014年已上升至18.1%。東隆興的毛利率之所以提升，就是因為東隆興不斷往高質化方向走，像是提升毛利率較高的色紗、複合紗的比重等。另外，東隆興2014年營收與獲利都出現衰退，除了主因尼龍6報價大幅下滑，而尼龍6與東隆興的主產品尼龍66互為競爭替代品，不少廠商轉而採用成本較低的尼龍6所導致。雖然2015年後尼龍6的報價已回穩，但投資人仍需觀察未來尼龍6與尼龍66的報價走勢。

### 宏益：轉型生產複合紗，提升毛利率

宏益（1452）也是生產紡紗的公司，不過宏益鎖定的是最大宗的聚酯加工絲。宏益在2007～2012年間，除了2010年因景氣復甦，紗線短暫供不應求導致獲利上升外，其他年度的獲利表現並不出色。

雖然2013～2014年宏益的營收繼續下滑，但稅後淨利已出現明顯上升趨勢（詳見圖7），2012～2014年稅後淨利複合成長率高達40%，而 2015 年上半年則是繼續上升。會有這樣的改善，也是因為毛利率的提升，2012 年時宏益的毛利率只有 7.1%，但 2014 年已上升至 11.4%；而 2015 上半年則已上升至 19%。

宏益早期的產品都是一般紗，近幾年由於機能服飾興起，而「複合紗」較適合製造機能服飾，所以宏益決定轉型至複合紗的生產。要生產複合紗，需要高階雙胞胎假捻機，宏益的假捻機臺共 34 台，2013 年時已有 13 台改機成高階雙胞胎假捻機，2014 年提升至 17 台，2015 年再提升至 21 台，隨著高階假捻機台的提升，宏益複合紗的比重也不斷提高，這也是宏益毛利率持續上升的主因。

不過要注意，改機成高階雙胞胎假捻機，雖然可享有較高毛利率，但複合紗畢竟是高度客製化產品，若是景氣趨緩導致客戶拉貨減緩，產能利用率可能會快速下滑，獲利可能出現大幅衰退，投資人需留意。

### 機能服飾能否繼續帶旺紡織業，須留意未來競爭態勢

機能服飾的興起是很長期的趨勢，但畢竟機能服飾是較高價產品，且以歐美為主要消費族羣，若未來歐美景氣出現反轉下滑，也會對整個機能服飾產業造成短期衝擊。

台灣目前紡織業者眾多，但有切入機能服飾且獲利成長的，也就是我們提到的這幾家。未來有沒有可能有更多廠商一窩蜂地開始生產機能服飾？領先廠商生產技術是否能持續領先後進者？或是即將陷入價格殺戮戰？這些都是未來紡織產業的觀察重點。

## 汽車產業大革新：3股趨勢不可忽視

美國知名顧問公司BCG每年會訪問1,500名不同產業的高階經理人，並輔以股東權益報酬率、營收與毛利率成長等時期指標，選出全球最創新的50大企業。2013年的調查結果，前20大創新企業中，汽車產業竟高達9家！這不是夕陽產業嗎？原來有幾股趨勢，正在改變這個傳統產業。

2008年和2009年時值金融海嘯，全球景氣大幅衰退，汽車產業也出現了罕見的衰退走勢。不過2010年後汽車產業開始復甦（詳見圖1），2010～2014年全球新車市場複合成長率高達6.3%，其中成長最快的又屬北美與亞太地區，成長率都在9%上下，表現相當出色。

近幾年全球新車市場除了「量」穩定成長外，「質」也悄悄出現了變化，經過高檔化、電動車興起等3大趨勢，我們把汽車產業的變化歸納成3種趨勢，分別是汽車電子化、配備高檔化、電動車興起等3大趨勢，我們分別介紹如下：

### 趨勢1 汽車電子化：3類產業受益

早期的汽車可說是相當冰冷的機械產品，不但沒有什麼影音設備、導航系統，安全性也堪慮。不過隨著產業的發展，情況已開始改變，汽車搭載影音設備的比重持續提高，各項安全設備也是不斷地精進。台股的汽車電子產業區分成 3 項，我們分別介紹如下：

#### 車載影音設備：怡利電市占持續拉高、鼎天起步中

怡利電（2497）為專門生產車載影音設備的廠商，其中又包含車載影音導航系統、後座娛樂系統等。由於新車搭載影音設備的比率一直在提高，中國市場的產業成長率甚至高達 20%。

怡利電 2010 年起陸續打入中國前 3 大車廠，在中國的營收占比已超過 50%，在東協、台灣的市占率也持續提高，造就了怡利電近幾年的獲利榮景；2010 年每股稅後盈餘（EPS）還不到 1 元，2014 年已達 4.5 元（詳見圖 2）。

鼎天(3306)是早期的GPS三雄之一，但隨著智慧型手機都搭載GPS功能後，另外兩雄環科(3499)、晶盟(3431)已陷入虧損邊緣，唯有鼎天近期轉型成功，縮減白牌個人導航機，積極轉入軍用市場，從怡利電的GPS模組供應商，搖身一變成爲車載影音設備的競爭對手。不過鼎天的車載影音設備還在起步階段，獲利仍屬平穩，尚未出現大幅成長。

#### 車用電子安全設備：3大續優生成長驚人

隨著科技發展，汽車的影音設備愈來愈豪華，安全性當然也要愈來愈高，這就得靠各種車用電子安全設備的幫忙了，像是胎壓偵測、倒車雷達、安全氣囊等，而台股在這3個產業各有1家優秀的公司，分別為為升(2231)、同致(3552)、劍麟(2228)，介紹如下：

**胎壓偵測器：為升 2012 年起獲利與股價爆漲**

為升在 2011 年前還是一家生產各式汽車開關為主的公司，包括方向燈、頭燈、窗戶、啟動開關等，占總營收超過 60%，而明星產品——胎壓偵測器占營收還不足 20%。不過從 2012 年起，為升的胎壓偵測器出現爆發性成長，2011 年時貢獻營收還不到 2 億元，但 2014 年已大幅成長至 10 億元，也讓為升的 EPS 從 2011 年的 2.2 元成長至 2014 年的 10.4 元（詳見圖 3），2015 年光是前 3 季就已達 11.64 元，超越 2014 年全年 EPS；2015 年股價最高飆到 438 元，跟 2011 年底大約 36 元的股價相比，漲幅達了超過 10 倍！

會有這樣驚人的成長，主因美國 2007 年立法通過新車全面安裝胎壓偵測器，而 2012 年起剛剛好進入了汰舊換新期。除了美國外，未來歐盟、日韓、甚至中國也將要立法強迫新車安裝胎壓偵測器，有利胎壓偵測產業未來蓬勃發展。不過近期有國內外汽車電子廠商陸續切入胎壓偵測領域，為升能否維持競爭優勢，才是未來獲利能否持續成長的關鍵。

**倒車雷達儀：同致與中國通用汽車簽下長約**

同致的主力產品是汽車的倒車雷達系統，近年由於成長迅速，全球市占率已上升至第 3 名，僅次於德國的博世 (Bosch) 與法國的法雷奧（Valeo）。同致雖然在全球都有布局，但主力市場放在中國，由於同致在中國的客戶不斷增加，汽車安裝倒車雷達的比率也持續提升，在中國的營收已占同致總營收超過 70%。

支持同致獲利長期成長的，還有在 2012 年與通用汽車（General Motors）簽下的 7 年長約，供應通用全球 19 個國家，且供應年限與出貨國家仍在上修。同致除了主力產品倒車雷達外，在防盗器、後視鏡顯示器、攝影機、胎壓偵測器等都有布局，這些產品也在各國陸續被指定為強制安裝，對公司未來營運也有加分作用。

**安全气囊廠：劍麟近5年獲利大幅成長**

劍麟原是一家生產衣夾的公司，爾後用相關技術切入汽車安全件（包括安全氣囊與摺疊式安全帶），在2008年時汽車安全件占營收不到34%，但2014年已超過65%。由於此產業成長迅速，也讓劍麟的EPS從2009年的2.1元成長至2014年的6.8元。

為何劍麟的汽車安全件可以持續成長？原來全球安全氣囊產業由天合汽車（TRW Automotive）、美安（Autoliv）、高田（Takata）這3大品牌壟斷，而這 3 大品牌廠都已成爲劍麟的客戶。且由於安全考量，安全气囊的項目已由原本的前座安全气囊增加至後座安全气囊、側邊安全气囊、膝部安全气囊、簾式安全气囊、安全帶安全气囊等，由於品項不斷增加，劍麟的營收與獲利也能持續成長。

#### 車用電子零組件：3 家廠獲利佳，並布局新產品領域

汽車電子化的目的，是讓汽車的娛樂性、安全性、操控性提升，要做到這個目的，就要安裝上面提到的車載影音、倒車雷達、防盜器、攝像頭、胎壓偵測、安全气囊……等配備，然而要讓這些配備正常運作，就會需要相關的車用電子零組件。像是汽車電子化後需要較多的電力，生產車用發電機二磁體的朋程 (8255) 就能受惠；汽車電子化後也需要用到較多連接器，生產汽車連接器的胡連 ( 6279 ) 也受惠；另外，做汽車引擎零組件的車王電 ( 1533 ) ，也是因為整體使用量增加而受惠。

從獲利來看， 3 家車用電子零組件公司的 EPS，都是呈長期上升的趨勢（詳見圖 4 ）。而這 3 家公司除了原本產品鏈產業持續成長外，也都有新產品的布局，像是朋程切入車用電壓調節器、胡連切入電動車連接器、車王電切入胎壓偵測、後視鏡顯示器等，未來如果發展順利，也可望維持公司的長期獲利能力。

### 趨勢2 配備高檔化：2 高價零組件廠沾光

除了汽車電子化外，我們發現近年來汽車配備有逐漸高端化的現象，像是愈來愈多車款使用高質的「鍛造鋁輪圈」，也有愈來愈多休旅車使用「天窗遮陽簾」等趨勢，以下分別介紹這 2 個產業與相關台灣公司：

#### 鍛造鋁輪圈廠：巧新可望受惠於節省油耗趨勢

輪圈公司巧新 ( 1563 ) 成立於 1994 年，以生產高爾夫球桿聞名，爾後跨入鍛造鋁輪圈製造，目前已成為全球第 2 大鍛造鋁輪圈製造商。一般市面上的車款都是使用「鑄造」鋁輪圈，但鑄造輪圈有雜質高、結構較脆等缺點，若與鍛造工藝相比，不但重量多了 40% ，耐用度也較差。

話雖如此，鍛造鋁輪圈的難度高，巧新也是連續好幾年才成功打入汽車供應鏈。由於鍛造鋁輪圈的售價較高，目前只有高價車款才有使用，像是巧新的主要客戶廣架 ( Jaguar ) 、克萊斯勒 ( Chrysler ) 、 BMW 等，都有多款名車使用鍛造鋁輪圈。

另外，由於空汗嚴重，美國、歐盟、中國都陸續制定節省油耗計畫，強迫車商逐年降低汽車每公里的耗油量，如此一來，車商除了要想辦法提高燃油效率外，也要想辦法減輕車體重量，而使用鋁造鋁輪圈就是一個選項，目前已有意來愈多車款開始使用鋁造鋁輪圈。

#### 汽車捲簾廠：皇田2013年起獲利大幅成長

皇田（9951）的主力產品是汽車窗簾，包括側簾、三角窗、電動後簾、遮物簾等，皇田在2012年前獲利算是相當穩定（2008年大虧主因操作衍生性金融商品失當），而2012年起休旅車開始流行安裝天窗捲簾，皇田順利打入天窗捲簾大廠Inalga供應鏈，2013年起獲利大幅成長，而2014年又順利成為福斯（Volkswagen）第2供應商，獲利再度躍進（詳見圖5）。

汽車捲簾目前全球第 1 大廠是 Bosch, 市占率約 60%~70%, 而皇田市占第 2 大, 約為 15%~20%, 但有逐步侵蝕 Bosch 市占的跡象, 未來成長空間仍大。

### 趨勢③電動汽車崛起：齒輪組與液壓系統廠獲利佳

電動車產業發展已久，但是近幾年才較受到大家關注，原因就是特斯拉（Tesla）的崛起。其實特斯拉在 2003 年就成立了，只是早期推出的車款叫好不叫座，直到聯合創辦人馬斯克（Elon Musk）跳下來當 CEO 後才加速公司發展，並在 2012 年推出震驚世界的 Model S。

由於 Model S 具有充電時間短、續航力高、性能好、外型佳等優勢，價格也算可接受，算是首次讓電動車跳出框架，具備與傳統車競爭的能力。特斯拉的特拉供應鏈主要有兩家，分別是做減速齒輪組的和太（1536）與做電池線束的福聯（3665），分別介紹如下：

#### 齒輪組廠商：和大因 2 大客戶推升獲利成長

和大早期是做各種機械用的齒輪、轉輪產品，爾後慢慢聚焦至軍用的齒輪、轉輪產品，目前軍用產品已占營收超過 80%。由於和太希望做出差異化以維持高毛利，因此不做一般的軍用產品，只做特殊的齒輪或軸類產品，像是皮卡車、客車、工業用車、農業用車、沙灘車等，由於每個行業的需求不同，精確度也不同，所以都需要客製化處理。

特斯拉在 2010 年時找上和大，要和大為其開發 Model S 的減速齒輪組，之後隨著 Model S 產量出貨，和大的獲利也逐漸提升，以 2015 年來看，和太除了出新款 Model S 的減速齒輪組外，也開始出特斯拉於 2015 年推出的四輪傳動車 Model X 的減速齒輪組。由於四輪傳動要多用 1 顆減速齒輪組，對和太營收獲利貢獻會更大。

和大的客戶中除了特斯拉大幅成長外，最大客戶 Borg Warner 對和大的營收貢獻，也是以每年持續 15%～20% 的速度成長，也提升了和大的獲利持續成長（詳見圖 6）。
