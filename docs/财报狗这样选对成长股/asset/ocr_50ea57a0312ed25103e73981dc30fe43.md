4.1 到4.3我們是從公司個別客戶的角度來評估公司的發展，但客戶太多分散，就不太可能一個一個慢慢研究了。這時候，適合從銷售「國家」的角度切入，從公司主力銷售國的景氣發展狀況，來預測公司未來可能發展。本文就以美國為例，說明美國這個消費大國的景氣發展如何影響台灣的供應鏈廠商。

# # 主力銷售國帶旺供應鏈
## 以美國為例

美國人口占全球人口比重只有不到5%；但GDP（國內生產總值）卻占全球比重超過20%，是名副其實的世界大國。

由於美國是發展成熟的經濟體，有廣大的內需市場，可以較不受全球景氣的干擾。2008年發生金融海嘯時，美國雖出現嚴重衰退，卻也帶領全球率先復甦；2011年後，歐債危機、俄羅斯危機、中國危機陸續傳出，從各項經濟數據來看，美國幾乎沒受到影響。當全世界都在實施寬鬆貨幣政策時，美國已在失業率明顯改善及經濟活動溫和擴張的狀態下，於2015年12月17日率先宣布升息，長達7年的零利率時代正式告終。

由於美國是消費大國，台灣不少公司都以美國為主要市場，研究美國的景氣循環對投資台股可是有很大的幫助。我們以下分成车市、房市、工業這3個面向，來探討美國的景氣循環週期，以及對於台灣供應鏈的影響。
