# **從產業規格演進找投資機會**
**— 以電信業為例**

前4章所提到的趨勢偏一波到底，本文介紹的科技趨勢較具週期性，即所謂「產業規格演進」。像是電信產業規格演進（1G→2G→3G→4G……），半導體演進（90奈米→65奈米→40奈米→28奈米……）等，循著這樣的趨勢，會出現什麼投資機會嗎？本文以發展超過30年的電信業為範例。

全球電信產業在1980年代即開始發展，當時各國使用自己的規格，無法與他國互通，算是1G（第1代行動通訊技術）時代。隨後，歐洲各國成立ETSI（歐洲電信標準協會）推動統一電信標準，於1990年推出了第1版的GSM（全球行動通訊系統），此即屬於2G規範。又過幾年，ETSI再與日本、中國、韓國、北美的電信標準組織整合成3GPP（第3代行動通訊合作計畫）組織，並於2000年推出了UMTS/WCDMA（全球行動電話系統）規格，屬於3G規範；2008年3GPP組織再推出LTE（長期演進技術），也就是所謂的4G了。

不過從全球各世代電信產品銷售走勢可發現，從規範打出到實際流行，通常需要一段時間，像是3G第1版是在2000年完成，但滲透率大幅提升是在2009～2011年期間；4G第1版在2008年完成，滲透率大幅提升預計是在2014～2016年（詳見圖1）。
