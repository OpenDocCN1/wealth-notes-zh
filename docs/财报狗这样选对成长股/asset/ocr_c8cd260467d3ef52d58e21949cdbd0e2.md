# ## 匯率波動大
影響企業獲利狀況

除了人工成本、原料成本、製程的良率與效率之外，會影響公司獲利動動的因素，就是“匯率”，這個因素。尤其臺灣又是外銷國，上市櫃公司的營收多半是來自國外，這些國外貨幣相對新台幣的變動，就會對上市櫃公司的財報造成顯著的影響。

臺灣是島國，且人口並不多，企業經營都十分仰賴進口與出口，若某臺灣公司出口國的匯率相對新台幣大幅升值或貶值，公司收到款項換回新台幣時，就會大幅增加或縮水；相反的，若某臺灣公司的進口國匯率大幅升值或貶值，公司付出的新台幣成本就可能大幅增加或減少，會影響公司最終獲利狀況。此外，若擁有國外的資產或負債，當匯率變動時，也會造成換算為新台幣的獲利或虧損。

另外，就算出口國匯率沒動，但公司的競爭對手國匯率大幅波動時，同樣會影響公司的競爭力。

以下我們就用近5年內匯率大幅波動（相對新台幣）的4種貨幣——美元、日圓、歐元、黑奧（緋援：即巴西貨幣），來說明匯率波動如何影響到相關產業的獲利狀況。
