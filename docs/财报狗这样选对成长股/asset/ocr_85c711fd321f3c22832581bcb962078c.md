# 看企業投資成果 讓小金雞抱注獲利

再擴大致 2,000 萬 ~ 2,200 萬元，導致弘帆的獲利與股價仍舊維持低迷，不過其實最壞的情況已經過去。

2014 年第 3 季時，東莞國貿的虧損已縮減至 830 萬元，帶動弘帆的獲利大幅成長，EPS 從上季的 0.78 元跳升至 1.27 元，成長超過 60%，第 4 季時橘麗生活館已全數關閉，東莞國貿不但已無虧損，還有超過 3,000 萬元的獲利回沖，也使弘帆的獲利維持在高檔。

2015 年由於沒有橘麗生活館扯後腿，弘帆上半年 EPS 已達 2.65 元，較 2014 上半年的 1.56 元成長 70%（詳見圖 4），股價也從 2014 年低點的不 40 元，最高漲至 2015 年 11 月的 154 元，漲幅達 2.8 倍。
