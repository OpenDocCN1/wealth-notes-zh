穩定成長外，川湖的市占率也逐漸增加，像伺服器導動部分，2007 年時全球市占率尚不足 2%，但是到 2015 年時已超過 30%。

除了營收與獲利長線成長外，若仔細觀察川湖的營收年增率走勢，可發現有相當明顯的週期性，主要就是受到英特爾（Intel）伺服器 CPU（中央處理器）發表時間的影響，只要英特爾有伺服器 CPU 要上市，伺服器機殼、伺服器導動廠等都會為其設計新的產品，並造成所謂的「換機潮」。

像是 2011 年底開始有一波營收年增率往上的趨勢，是因為當時英特爾伺服器 CPU 新平台「Ronley」的上市，而 2014 年下半年這波營收年增率拉起來，就是英特爾伺服器 CPU 新平台「Granley」的上市（詳見圖 7）。
