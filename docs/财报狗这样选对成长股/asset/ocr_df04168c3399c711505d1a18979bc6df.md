# 高階金屬機殼產業興起，塑膠機殼漸漸沒落

#### 崛起：高階金屬機殼（可成、鴻準、F-鍍勝）

NB、手機、平板這些裝置，要如何做到輕薄化呢？機殼是關鍵。傳統的NB、手機外殼都是以塑膠為主，可是塑膠的散熱係數低；還要搭配不少散熱元件，難以做到輕薄，但輕薄畢竟是未來趨勢，此時散熱係數高於塑膠70～80倍的金屬機殼就派上用場囉！
