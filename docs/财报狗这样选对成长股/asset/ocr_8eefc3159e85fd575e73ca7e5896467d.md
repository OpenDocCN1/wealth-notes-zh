# 富晶通2012年Q1起稅後淨利轉虧為盈

圖：富晶通單季毛利率、稅後淨利率
資料來源：整理：財報狗

為 3C 產品的主流，導致富晶通的毛利率迅速下滑。

不錯好消息是，富晶通在 2007 年前後就開始研發航太觸控產品（影響系
統），2012 年終於通過認證開始量產出貨。由於航太產品的認證相當嚴格，
進入門檻較高，自然享有較高毛利率。由於低毛利率的 3C 產品比重下降、高
毛利率的航太產品比重上升，使富晶通的毛利率出現了顯著提升。此後，公司
就不斷縮減 3C 產品的開發，並專注在更多利基型產品，像是醫療、汽車、工
控等，也讓公司的毛利率與 EPS 呈現長期上升趨勢。
