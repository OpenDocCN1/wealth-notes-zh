# 力旺、同亨年度EPS

刷卡機大廠同亨的相關產品有 NFC 讀卡機與 Mobile POS（行動金融交易終端機，讀卡機外接於智慧型手機，即可進行刷卡支付費用），未來若是行動支付成為主流，不僅各賣場都必須配備 NFC 讀卡機，並且 Mobile POS 也可應用於保險業、快遞等交易，以接受消費者付費，對同亨業績的提升將有正面幫助。

以同亨 2009 ～ 2014 年的獲利來看並無爆發性，不過 2015 年上半年 EPS 已達 3 元，成長性佳；然而，須注意同亨算是設備廠，營收波動幅度大，需注意投資時機與風險掌控。另外，若未來大家真的開始習慣用手機或穿戴裝置付款，將會讓跨過信用卡公司、修造卡公司等，這類公司業績可能會受影響，讀者需注意。
