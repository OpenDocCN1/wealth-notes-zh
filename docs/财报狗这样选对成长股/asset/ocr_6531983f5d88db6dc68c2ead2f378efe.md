# ◎面板產業：三星除外，亞洲面板廠損失慘重

# 受惠臺股：友達、群創、華映、彩晶

美國司法部在 2006 年時，對亞洲的 8 家面板廠商展開了大規模的反托拉 斯調查，包括了韓國的三星（Samsung）、樂金（LG）；日本的夏普（Sharp）、 日本電氣（NEC）；台灣的友達（2409）、奇美電（3481），現為群創）、 華映（2475）、彩晶（6116）等，經調查後罪名確立，業者紛紛被處以鉅 額罰款，各負責人也赴美服刑。

唯有一家公司逃過了賠款與刑責，就是韓國的三星，因為其最早認罪並轉為 污點證人。除了美國司法部外，美國各洲、歐盟、日本、南韓、中國政府等， 也陸續對各大面板廠開罰，可說是沒完沒了，業者們紛紛損失慘重。

友達、奇美電、華映、彩晶等 4 家公司，都在這次的反托拉斯事件中遭受 重創，光是美國司法部的罰款，就分別高達 5 億美元、2 億 2,000 萬美元、 6,500 萬美元、3,000 萬美元等；另外還有其他國家的罰款等；這些罰款多 半在 2008 ~ 2012 年間認列，對原本就虧損連連的面板「慘業」無疑是雪 上加霜。

2013 年後，反托拉斯事件稍微告一段落，加上面板供需漸趨平衡，4 家公 司除了華映外都已轉虧為盈（詳見圖 4），其中彩晶 2015 年累積前 3 季又 陷入虧損。未來 2 年中國面板產能仍將持續開出，仍要注意產業供需發展對 公司獲利的影响。
