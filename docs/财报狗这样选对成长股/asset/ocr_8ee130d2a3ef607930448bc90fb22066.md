# 圖解查詢〉年度營收連續3年成長廣的

在⑬「財報檢索VIP」中，選擇⑭「營收成長篩選」，將⑮「年度營收連續」項目設定為⑯「3年成長」，然後將此條件右方的選取條件。

![](bbox=[0.26, 0.17, 0.54, 0.82])

資料來源、整理：財報狗

從新菱的年报可發現，2006年時新菱亞洲營收約6億4,000萬元，但到2009年時已成長至11億5,000萬元，3年複合成長率高達21.6%，而這個亞洲主要就是中國，代表新菱此时期的成长动能来自于中国市场。

中国此时期可以维持高度成长，主因当时中国消费力成长驚人，消费支出增长率都在10%以上，再加上麵包、糕點在中国的低渗透率/低份额，故可预期接下来几年应该维持高成长。
