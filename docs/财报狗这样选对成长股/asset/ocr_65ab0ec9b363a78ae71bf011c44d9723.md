2012 ~ 2014 年由於營收成長與費用率下滑，喬鼎的稅後淨利也向上攀升。不過進入 2015 年後，雲端產業普遍陷入高成長後的調整庫存階段，加上蘋果產品銷售狀況下滑，導致喬鼎的營收與獲利快速下滑，未來何時復成增長，要再觀察產業狀況。
