HDMI 規格換至 HDBaseT 規格，由於是新規格，除了單價較高之外，毛利率也較好。2 大客戶在 2013 年分別貢獻營收約 3 億 4,000 萬元與 1 億 9,000 萬元，2014 年分別飆升至 5 億元與 3 億 5,000 萬元，成長率分別高達 47%與 83%，這也是西柏營收與獲利在 2014 年大幅成長的主因。

展望未来，由于 HDBaseT 产品 2014 年占比营收已达 35%，未来再成长的空间有限；进入 2015 年，也因为 2014 年基数太高而出现年度衰退趋势，股价跟着回调。未来若要再出现如 2014 年的大幅成长，要观察是否将来有新的规格诞生；因为对西柏而言，愈多的规格，就是愈多的产品，就可以创造愈多的营收与获利。

# ◎旭电：大客户胜华倒阁，预留产能一时难消化导致亏损

反之，当大客户处在趋势向下的产业，或是在产业竞争当中被淘汰，也会拖累供应商。就像旭电（3390）是软体印制电路板製造商，经营的市场相当广，但仍以国内市场为主，客户包括面板彩晶（6116）、华映（2475），面板模组友達（8105）、触控面板联咏（2384，已下市）、介面（3584）等，终端应用则是包含智慧型手机、平板、NB、军用等。

2007～2012 年，智慧型手机与平板处于高成长期，旭电搭上了这波产业趋势乘着成长，这 5 年营收复合成长率高 21%，税后净利复合成长率更高 37%。然而在这样的亮眼成绩背后，却有一股危机暗藏，就是大客户联咏因受到 NB 行动装置轻薄化趋势的影响，外挂式触控面板的销售下滑，财务状态愈来愈差，然而胜华占旭电的营收比重却愈来愈高。
