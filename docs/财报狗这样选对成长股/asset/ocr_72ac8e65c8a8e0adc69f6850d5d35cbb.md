# 踩「雙反」、「反托拉斯」地雷

若法規,描述得得很清楚，廠商們都很容易遵行，那就沒什麼問題；但若法規描述得含模糊地帶，或是有公司便是要違反法規，那就會產生官司問題了。跨國官司當中，最讓企業與投資人聞之色變的有2種……「雙反法」與「反托拉斯法」。

我們在3-1-提到的法規，多是由各國政府為自己國家制定的，較不具爭議性；而另一種型態的法規則是跨國的，政府為了保護自己國家產業的利益，就會訂立一些嚴苛法規，並接受國內廠商的檢舉來調查這些國外大廠（當然也可能是國內，但較少）是否有違規的情形，其中最著名的就是雙反法與反托拉斯法。

由於這些所謂的「法規」，都是各國維護自身利益的展現，也就是誰的國力強，誰就最能貫徹這些法規。所以，目前雙反與反托拉斯的執行最強勁的，自然就是美國了。
