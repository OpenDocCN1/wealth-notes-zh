# 2014年起和碩股價隨獲利上揚
和碩單季EPS、股價月均價

![](bbox=[0.24, 0.18, 0.48, 0.85])

從客戶結構可以發現，華碩在2011年時占和碩營收比重 45%，蘋果只有 19%，但2014年時華碩已降至11%，反而是蘋果成長至49%！由於代工廠的獲利率通常高於其他產品，這也是和碩獲利能夠快速上升的原因。由此可見，和碩是蘋果分散供應商策略下的最大受惠者之一。不過要提醒，不是每個第2供應商都能能和碩這麼順利，像勝華在2010年成為蘋果觸控面板的第2供應商後，雖然2010年獲利一度轉好，但由於良率一直不佳，2011年之後虧損持續擴大，最後難逃重整下市的命運。
