# 看科技產業趨勢，搶風車策略狂飆

年後，中國本土智慧型手機品牌廠商興起（如小米、中興、華為），分食了三星的市占率，三星的獲利與股價也因此快速下滑。

總之，雖然 2015 年後智慧型手機仍可維持 10% 左右的成長率，但問題是高階市場已被蘋果佔據，低階市場又有中國一票品牌廠打得你死我活，如宏達電被卡在中間的廠商想要重返榮耀，不是這麼容易的事。

◎衰落：傳統手機品牌（諾基亞）、PC與NB品牌（東芝、宏碁）智慧型手機的崛起，受害最深的品牌廠，就是傳統功能型手機龍頭——諾基亞（Nokia）。Nokia 雖然一直有研發智慧型手機，但由於被過去的成功晶片以致轉型過慢，最後難逃被微軟收購的命運。
