# ◎ 高力：為燃料電池大廠開發關鍵組件，業績吃補

美國 Bloom Energy 公司成立於 2002 年，發展的是燃料電池技術。簡單來說，燃料電池是一種發電裝置，以氫氣作為燃料，透過燃料電池可轉换成電能和水（電能為能源，水為排放物），而氫氣的來源可以是石油或天然氣等。只要添加燃料，就能夠維持電力。由於燃料電池具有低污染、高續航力、高能量密度等特性，很適合企業、資料中心拿來當作備用能源系統，近幾年快速發展，蘋果公司（Apple）、沃爾瑪（Wol-mart）、eBay、可口可樂等大型企業都是其客戶。
