# 觀察重點5：檢測產業，新一代通訊技術帶動獲利

代表廠商：耕興、宜特
耕興（6146）的主要業務是電子產品的 EMC（電磁相容性）、Safely（安規）相關的測試，測試占公司營收80%以上，剩下的則是一些電子零件銷售。測試的產品以手機、平板為大宗，NB相關產品較小。

從耕興的獲利走勢可發現，2009～2010年是公司的獲利成長期，主因當時開始從2G功能型手機轉至3G智慧型手機；由於2G手機只有2個頻道，3G手機則有4～5個頻道，需要測試的頻道較多，自然測試的量價、毛利率會較好。此後的2011～2013年耕興獲利沒什麼成長，除了與手機還沒進入4G時代外，也因NB產業銷售欠佳，影響到耕興的測試收入。

2014年後，4G手機滲透率開始快速提升，由於4G手機的頻道數又比3G多出了2～3個，手機的測試單價又再提高，所以2014年起耕興的獲利又開始快速增加（詳見圖6）。除此之外，NB的WiFi模組也從802.11n的網路標準，走向下一代的802.11ac標準，同時WiFi模組必須向下相容，使得需要測試的數目也提高，讓耕興的測試費用也跟着增加。
