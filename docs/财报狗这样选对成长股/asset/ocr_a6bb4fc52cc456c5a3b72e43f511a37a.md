# 愛臺2》織布廠：龍頭續莊、2小兵回歸

◎儒鴻：研發機能布已久，獲利持續高飛

以銷售產品來看，儒（1476）與聚陽、鉉旺實一樣，都是以成衣為主，但差別在於聚陽、鉉旺實的布幾乎都是外購的；而儒鴻則是從織布、染整到成衣製造的一貫廠。

儒鴻在2007年時還是以布的銷售為主，佔營收超過60%，成衣不到40%；近幾年加強毛利率較高的成衣銷售，目前成衣銷售已升至60%以上。與聚陽和鉉旺實相比，儒鴻的優勢在於布料的掌控，儒鴻每年投入大量資金在機能布の開発，除了因自製毛利率較好外，更能快速反應客戶的需求。

儒2007～2014年營收複合成長率高達19.3%、稅後淨利複合成長率更是高達38%（詳見圖4），成長性遠高於聚陽與鉉旺。主因聚陽與鉉旺實都是在近幾年才加強成長性較佳的機能服飾銷售，而儒鴻則是一直專注在機能布、機能服飾的研發與銷售，是這股機能服飾趨勢下的最大受益者。

以客戶來看，各大機能運動品牌早已是儒鴻客戶，像是近幾年才暴紅的Lululemon早在十幾年前就是儒鴻的客戶，與儒鴻合作研發多年後才推出廣受歡迎的瑜伽服飾；Under Armour也已與儒鴻合作多年；傳統運動鞋品牌大廠Nike近年在服飾方面也是發展相當積極，像是高爾夫球服、網球服等也是找上儒鴻代工。由於以上品牌都在快速成長期，加上儒鴻每年都會增加不少新客戶，預計儒鴻短期內還能維持較高的成長性。
