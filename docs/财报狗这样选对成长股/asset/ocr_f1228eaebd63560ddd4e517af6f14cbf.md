# ○案例◎精華：營收高成長與費用控管得宜，費用率快速下滑

精華（1565）是隱形眼鏡製造商，雖有自有品牌，但仍以代工為主；我們在本書的3-1介紹過，但當時重點放在法規對精華的影響，這裡則是探討費用率變化。精華在 2009～2011 年，費用率連 3 年下降（詳見圖 6），帶動了精華的獲利與股價大幅上升（詳見圖 7），此趨勢又延續了兩年至 2013 年，直到 2014 年費用率才呈現平緩走勢。
