# 看客戶經營績效 掌握供應商錢景

2009～2012年間快速下滑，2009年時還有34%，但2012年下降至24%。主因這幾年是朋程在搶市占率的期間，希望一條大廠多外包給它，所以平均價格每年調降3%～5%，導致毛利率快速下滑。不過2013年後，價格漸趨穩定，再加上二極體主要原材料——鎢的價格持續下滑，朋程的毛利率開始止跌回升。

由於朋程在二極體市占率已超過50%，未來要再成長空間有限，若想重回成長趨勢，得看公司在新產品「憑壓調節器」的發展狀況。
