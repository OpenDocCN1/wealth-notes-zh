# ■解查詢》年度營業費用率增幅逾3個百分點標的

在⑩「財務VIP」中，選擇⑧「營業費用率改查篩選」，設定⑨「年度營業費用率-一年增加3%」，然後將此條件加進右方的選股條件。

![](bbox=[0.23, 0.18, 0.54, 0.91])

萬潤的營業費用率在2010年時只有17.9%，但2011年時一口氣上升至27.3%，2012年再上升至34%（詳見圖2）。由於費用率大幅提升，萬潤連2年陷入虧損，股價也從2010年的高點大跌逾7成！

為何萬潤的費用率會大幅飆高呢？原來萬潤的競爭對手美商ESI公司在2005年時，控告萬潤的產品侵犯其「電路元件裝封裝置」專利，經過多年纏訟，2011年6月一審判決萬潤敗訴，需賠償ESI新台幣7億元。
