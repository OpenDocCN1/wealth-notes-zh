# 圖解查詢》季毛利率成長3個百分點標準的

在3「財報狗VIP」中，點選2「毛利率成長篩選」，將6「近一季毛利率」條件設定為4「較前一季增加3%」及5「較去年同期增長3%」，將此條件加速右方的選肢條件。

![](bbox=[0.28, 0.17, 0.55, 0.86])

從利潤比率可發現，富晶通的毛利率在2012年第1季時只有6.3%，但第2季時就跳升至12%，符合我們的篩選條件；而富晶通的稅後淨利率也跟著從4.4%上升至3.2%，出現了轉為為盈的現象（詳見圖4）。

相較於2012年第2季毛利率的顯著改善，營收卻只出現小幅成長，為何會有此現象呢？原來富晶通雖然營收沒什麼變化；但產品結構已悄悄轉變了。富晶通在2008～2011年間，由於看好3C擴控的大趨勢，投入眾多研發資源與設備的購買，不料3C產品過於競爭，加上富容式閘控取代電阻式閘控成
