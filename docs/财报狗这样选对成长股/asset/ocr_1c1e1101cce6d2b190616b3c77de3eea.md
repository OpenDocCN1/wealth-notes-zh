30%，正新的中國營收占比更超過50%，可預見兩家公司都會受到美國對中
國雙反的影響。

其實從歷史資料即可發現，2009～2011年美國對中國實施輪胎特保法
的這幾年，正新與建大的獲利都呈下滑趨勢，尤其是中國占比較高的正新，衰
退幅度較大（詳見圖1）；不過這段期間獲利衰退還有另一個原因——輪胎主
原料橡膠價格大漲，影響到輪胎毛利率。到了2012～2014年，兩家的獲
利較為平穩，不過2015年雙反實施後，可能又會造成新一波影響，但若橡
膠價格繼續下跌讓輪胎企業成本下降，還是可以緩和 some衝擊。

# ◎太陽能產業：2011年起，太陽能獲利撐著美國臉色

要影響台股：茂迪
除了輪胎產業外，太陽能因屬於戰略能源產業，也成了雙反案的常客，其中
美國、歐盟都曾對中國太陽能電池實施雙反。

距今10多年前的2000年代初期，太陽能產業還是新興產業時，由於競
爭者不多加上需求旺盛，太陽能電池大廠茂迪（6244）的獲利相當出色，
2001～2006年EPS（每股稅後盈餘）連續成長，2006年時EPS突破16
元，股價更曾衝上千元，成為當時的股王。然而好景不常，2006年後各大廠
商產能陸續開出，再加上需求轉弱，茂迪的獲利跟著大幅下滑，太陽能也成了
獲利波動相當大的景氣循環產業。

2011年時，美國商務部接受了包含Solar World美國分公司在內的7家
公司申訴，開始調查中國太陽能電池的雙反案，並在2012年10月公布終判，
對中國產美的太陽能電池課徵雙反稅率平均達30.66%，以保護美國本土的太
能產業。
