# 3、陷入猎奇：在计谋上追求新奇怪

权谋和武术一样，花拳绣腿看着好看，实际上用途不大。权术研究讲究的是基本功，把基本功做扎实了，到处都能够散发出浑厚的功力。很多人，觉得一段材料里，没看出高妙的，新奇特的招数，就觉得索然无味，其实这就是跑偏了。权谋永远都离不开自身的资源、自己的实力、自己的计算和布局，而新奇特的招数，以少胜多的案例，终究还是少数ün。把基本功练好，比如制衡，这个招数基本原理很简单，但是用起来，却不简单，千变万化。

# 4、陷入卖弄：四处招摇学的新观点
