# 领导向下属借钱怎么办？

【困惑】老师，领导买房缺钱，向我借怎么办？

+   1、有能力的领导不会借下属的钱

作为一个组织的领导，首先从资源上说，因为层次的存在，能够获取工资之外的各种资源，所以，财力远远比下属要强。其次从权力上说，如果借下属的钱，在下属面前丧失了神秘感、权威感，基本上以后管理下属很难。最后是交情上说，一般人都是先借自己的朋友，关系好的，而不是在职场上借工作关系下属的。所以，真正优秀的领导基本上不会借下属的钱。因为借钱的领导，要么是自己不会混，要么是社会关系缺乏，要么是不懂管理，无论哪种，迟早倒台，这样的领导都不能跟随。
