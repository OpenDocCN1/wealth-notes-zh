# 12、权谋是思维的训练，而不是知识的积累

学员：一直有个困惑，想请 Q 帝大大释疑。权谋理论好像很容易懂，就算有不懂的东西经人一指点瞬间就能明白，不像高数，编程这些需要学很久。可实际情况却是真正能把权谋用得很好的人很少。这是什么原因？

权谋网：权谋不是一个个知识点，而是思考的方式。学习的过程也不是记忆知识，而是训练思维。之所以一看就懂，自己搞就不会。就是因为，没有经过思维训练。事情千变万化，所以知识点是没有规律的，但是这背后的思维方式是有规律的。只有掌握了这背后的思维方式，才能真正的用好，这叫做知其然；知其所以然。
