# 1、战略和战术是两码事

新东方的崛起来源于改革开放的历史机遇，时代的推动，恰好，俞敏洪就站在这个风口，如果不是俞敏洪，也会有李敏洪，王敏洪。有了这个历史机遇，接下来就是战术的问题了，这就意味着，他搞英语的培训不是自己的战略选择，而是他本身就是英语出来了，正好站在了风口，这就是小米总裁雷军说的，站在风口的猪。如果有风，猪都能飞起来，但是风过去了，猪还是猪。之前的战略方向是历史的机遇，所以，无形中他对战略的决断性就没有过成功的经验。所以，能够管好新东方不代表就有把握航向的能力。
