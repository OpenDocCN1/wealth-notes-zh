# 看不惯，该不该告密！

【困惑】老师，我想请教个事，我单位是国资下属企业，最高领导是董事长，总经理和下面一个部门经理是多年情人，对外一直说是朋友。最近两个人一起注册了个公司，利用现有单位的资源。 这事我应该告诉董事长还是装不知道。 我的级别较低，说了对我也没什么好处，只是这两个人我也确实一直看不惯而已。
