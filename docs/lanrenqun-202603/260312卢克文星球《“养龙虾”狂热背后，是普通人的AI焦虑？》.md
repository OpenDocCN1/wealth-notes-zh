# “养龙虾”狂热背后，是普通人的 AI 焦虑？

260312 文/卢克文工作室嘉宾云梦竹整理：公众号懒人搜索，懒人专属群精选懒人微信:lazyhelper1

![](image)

最近两天，“养龙虾”（即安装 OpenClaw）成了热门话题。这款开源 AI 工具自去年 11 月发布以来，一直在技术社群内引发讨论。但出人意料的是，OpenClaw 的“出圈”居然发生在中国。

从今年 3 月开始，上百人抱着电脑在腾讯大厦楼下排起长队，等待工程师免费安装 OpenClaw。与此同时，电商平台上代安装服务标价从 199 元到 699 元不等。由于它的图标形似一只红色龙虾，于是网友戏称安装这款软件为“养龙虾”。

然而，就在市场狂热之际，一盆冷水当头泼下。

3 月 8 日，工信部突然发文，要求各单位防范 OpenClaw 可能带来的安全风险。同时，包括大型银行在内的政府机构及国有企业已收到通知，出于安全考虑，禁止在办公设备上安装该智能体。

短短几天，冰火两重天，OpenClaw 为何能掀起如此风浪？还得从头细说。

## 01

我们首先要知道什么是 OpenClaw。简单来讲，它是一种 AI 自动化工具框架，也有人把它称为"AI 管家”。与普通的聊天式 AI 不同，它并不是单纯回答问题，而是帮助用户完成一整套任务流程。

例如，在写作场景中，用户只需要给出一个主题，比如“写一篇关于新能源行业趋势的分析报告”，OpenClaw 理论上就可以先调用搜索工具收集资料，再让大模型整理内容、生成文章结构，随后继续优化语言，甚至自动生成配套的 PPT 或图表。

在传统大模型中，这样的工作，需要用户进行无数轮问答，需要使用从 GPT 到 Word 等一系列软件，而现在仅仅 OpenClaw 一家即可。

在办公场景中，如果一个人需要准备会议材料，OpenClaw 可以自动读取会议记录，提炼出核心要点，整理成会议纪要，再生成任务清单发送邮件给团队成员。整理会议纪要不算难事，但根据会议纪要，通过邮件给不同人分发任务，就不是简单的事情。

它的功能确实强大，而且符合实际需求。所以，自今年 1 月份开始，就有大量的商家，特别是之前帮人本地化部署。Deepseek 那帮人看上了这个市场，然后就开始编段子了，这些人可谓深谙人性，编的段子那是直击客户底层需求。

其中一个案例是，利用 OpenClaw 在互联网撒网交友，然后添加联系方式，最后自动约线下见面。甚至有人暗示，自己利用 OpenClaw 一周能约三个。他们称其为“颠覆相亲市场的伟大创举。”

还有一些案例说自己用 OpenClaw 炒股，之前血亏的账号立刻就盈利了。

只能说，这些商家是真抓到了人性。在这些人的努力下，“养龙虾”开始小火，然后自媒体进场。有些自媒体嘛，节操也就那样，无非就是“你又要被 AI 淘汰了”一类的文章，用来制造焦虑，在焦虑下，一部分人还真开始去“养龙虾”了。

随后，互联网大厂看到了机会，因为 OpenClaw 完成任务需要调动大模型 Token（常译作“词元”），而在商业领域，词元是计量付费，用得越多花得越多。当 OpenClaw 出来之后，依靠词元计量付费的模型公司股价还涨了一波。

对互联网大厂而言，这不就是现实的需求吗？大模型一问一答能赚什么钱，词元计量付费才是王道。这也是为什么大厂会派出工程师，免费帮大家安装的原因。

大厂行动后，地方政府也坐不住了。

深圳龙岗区率先发布征求意见稿，其中提出，对向国际主流社区贡献关键代码、开发应用项目的企业，最高给予 200 万元补贴。无锡高新区拟对关键技术突破项目最高支持 500 万元。苏州常熟市也推出措施，对入选各级人才计划的 OpenClaw 相关项目，最高给予 600 万元综合支持。

在多方的共同努力下，龙虾热潮终于破圈，走进了大众视野。

在我们的认知中，这种政府牵头、企业拥护、个人追随的先进技术，那就是人类未来发展的共识啊。结果，工信部一纸文件下来，告诉大家，冷静一下，还有安全问题呐。

## 02

大家光想着挣钱，居然把安全给忘了。等到工信部发文后，一些安装 OpenClaw 的人去查询该软件的安全问题，把人吓麻了。

OpenClaw 的安全问题，和前文提到的便利性是相关联的，前文提到 OpenClaw 解决问题需要调用大模型接口，需要付费，那你是不是要提前给它信用卡验证码？前文提到 OpenClaw 可以给同事发邮件，那你是不是要提前给它邮箱密码？

问题来了，信用卡会不会被盗刷？

这个问题在国内还好，国内经常会通过一系列的手机验证码，增加你的安全性。可是在国外呢？但凡用 VISA 卡购买过海外资料的朋友都知道，很多时候，对方只需

要你的信用卡账号，和背面三位数安全码，就能直接扣款。

这就导致了第一个后果，一旦对方使用一点儿技术手段，或者在网上设置木马链接，你的账户就跟裸奔一样。

至于邮箱和工作环境，Meta 超级智能实验室人工智能协同总监岳夏，将 OpenClaw 连接到了她的工作邮箱，亲眼看着 OpenClaw 删除了整整 200 多份邮件，完全没有任何办法阻止，从此对 OpenClaw 一生黑。

简单来说，任何技术带来的便捷性，往往以牺牲一部分安全性为代价。OpenClaw 更大的危害在于工作环境。

比如，攻击者可以通过构造恶意请求在目标服务器上执行任意命令，从而获得系统控制权。一旦服务器被攻陷，攻击者能够安装后门程序或远程控制工具，还可能删除或加密服务器上的数据实施勒索。

其次，大量 OpenClaw 实例被直接暴露在互联网上且缺乏身份认证机制，这会导致未经授权的访问风险。例如，攻击者可能利用开放的 API 下载恶意程序或部署挖矿软件，使服务器资源被滥用，导致系统性能下降甚至造成经济损失。

以上仅仅是其技术风险的冰山一角。

真正值得思考的问题在于，为什么很少有人主动提及这些风险。

那些以安装 OpenClaw 为生的商家，实际上比普通用户更了解系统。他们清楚软件需要调用大量权限，也知道系统运行的复杂性，但在推广时很少提醒客户，甚至刻意不提醒，只强调好处。

在意识到 OpenClaw 的风险后，更令人啼笑皆非的情况出现了：为实现深度系统接管，OpenClaw 默认获取高权限，会在系统目录留下后门文件，手动删除极易导致系统崩溃，甚至埋下数据泄漏隐患。

于是，市场上迅速冒出一批“龙虾卸载服务”，远程卸载收费 199 元。

我刚刚看了朋友圈，远程无痕删除 OpenClaw 的报价，已经来到 299 了，小涨 100 块钱，这个涨幅比黄金猛多了。

好笑的是，这些商家往往同时提供安装服务，报价 299 元。同一款软件，安装和卸载都能赚钱，这简直是软件行业一大奇观。

掌握大模型技术的厂商也并非不知情。相关的安全问题早在今年 1 到 2 月，就已经在一些国外技术社区和安全论坛中被集中讨论过：AI 代理有可能在用户不知情的情况下执行有害操作。

还有研究者指出，OpenClaw 在一些场景下曾经出现过明文 API 密钥和凭证泄露的问题。如果攻击者通过提示注入或者利用不安全的接口端点侵入，就有可能窃取这些敏感信息。

而且，OpenClaw 的安全功能在设计上并不是强制开启的，而是可选配置。换句话说，系统本身并不会默认提供完整的安全防护。官方文档甚至直接承认：“不存在‘绝对安全’的设置。”

如果用户在配置过程中出现疏忽，或者某些密钥和权限被泄露，那么让 AI 代理拥有对本地数据的广泛访问权限，本身就可能带来极高的风险。

至于地方政府的态度，则更容易理解。在他们看来，AI 被视为新的技术浪潮和产业机会。如果因为担心风险而选择观望，就可能被认为是在拒绝进步、错失发展机遇。因此，即便一些人意识到 OpenClaw 可能存在问题，他们也很难在政策层面完全否定它。

与其说这是对技术的盲目乐观，不如说是在发展压力下形成的必然选择。而在这股技术浪潮之下，真正悲剧的往往是最普通的人。

在一些讨论 OpenClaw 的论坛中，可以看到一种颇为天真的情绪。许多人真心相信，这类工具可以帮助他们迅速追赶专业人士，甚至抹平原本存在的技术差距。在他们的想象中，只要安装一个系统、学会几个简单的操作，就能像工程师、程序员一样使用最前沿的 AI 能力，从而在新的时代里获得属于自己的机会。

但现实往往残酷得多。

像 OpenClaw 这样的工具，本质上更像是一种“效率放大器”。对于那些本来就懂技术、理解 AI 原理的人来说，它确实可以显著提高效率，让他们在原有能力的基础上做得更快、更好。然而对于那些连系统安装都需要支付费用、请别人代为操作的人来说，他们很难真正理解软件背后的运行逻辑，更谈不上掌握它的核心能力。

在这种情况下，OpenClaw 对他们而言更像是一个黑箱。系统在后台做了什么、调用了哪些工具、产生了哪些数据，他们无法识别判断。因此，与其说这些普通人是在主动拥抱技术进步，不如说他们是在努力避免被时代淘汰。

当技术被不断描述为“未来趋势”时，很多人真正的情绪并不是兴奋，而是一种深层的不安，害怕如果不跟上这一步，就会被迅速甩在后面。

然而，无论是商家，还是大厂，都利用了这种不安，成为推动他们商业进程的关键一步。

——分割线——

绝大多数人只盯着眼前的工资，却不知道一次远在中东的冲突、一次降息的决议，就能在一夜之间洗牌普通人的财富。

看懂宏观，是为了在周期切换时，不被当作代价。
