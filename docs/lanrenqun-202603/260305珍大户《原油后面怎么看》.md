

# 原油后面怎么看

最近美国伊朗大战，石油今天开始波动巨大，想知道后面几天石油还有行情吗，而且今天也奇怪，石油期货没有掉，LOF 跌的吓人，还好午盘之前拉起来了。

周日半夜的时候发的伊朗的帖子，可惜被平台删了。

主要意思就是劝大家别追这种行情。因为现在确实都是各种借风炒作，都是因为一个消息暴涨一下，再因为另一个消息暴跌一下，满足的都是高风险爱赌博人的参与需求。

因为原油波动，目前我们能看到的所有因素，都是不可能长期持续的。

这就意味着，我们目前看到的所有波动都是短期炒作，是不具备长期趋势的基础的。

因为大家要知道，在这次伊朗被袭击之前，国际原油市场的格局，是供大于求：供给方面：

美国一直在持续增产，产量全球第一。中东和大毛，依赖原油收入，所以非常在意国际原油价格，他们为了稳住价格，前面一直在持续减产。

所以这次美以打伊朗，背后其实也有王爷们吹耳边风的功力。

因为如果能让伊朗减产的话，就能让出份额给其他王爷国，增产增加收入。

所以你看——如果没有海峡封锁的原因存在的话，但凡伊朗减少的份额，中东其他国家 + 大毛就会立刻增产来补上减少的份额，使供给不至于减少。

而这次新闻爆出来的，开打第 1 天后，大毛和几个国家就同时宣布增产了。基本上就是这种思路。

原因背后就是供给过剩，

供给过剩对应的，是需求不足。因为全球经济萎靡，

加上新能源汽车覆盖率越来越高，

对原油的需求是不够旺盛的，这才是整个供过于求的基础。

所以伊朗挨没挨打，其实对国际原油市场的影响是非常有限的，因为整体供过于求，伊朗退出的份额很快就会被其他国家所补充。

而目前能够引起国际油价波动的最大原因，其实就是他们封锁了霍尔木兹海峡。

所以大家需要思考的是，他们的目的是什么？他们要封锁多长时间？多久预期能恢复？

你要考虑到，封锁海峡是一种几乎与全球作对，也不利于自己的手段。

伊朗自己的原油出口，中东王爷国的原油出口要靠海峡，

油价上涨，会让欧洲和美国的通胀雪上加霜，

东亚各个国家都依赖原油进口。可能只有俄罗斯是笑的。

所以，封锁海峡等于无差别的攻击所有人，

类似于你挨打了时，不是去打别人，而是先把周围一圈东西砸坏了，屎尿泼往群众，引起所有人不爽。

这种做法是真的奔着干架去的吗？

我小时候接受到的教育就是，

如果想要干架，哪怕打不过对方，也要奔着抠眼睛去，哪怕自己死到当场，也得拉着对方一起死。

如果遇到围殴，别人怎么打你都别管，只盯对方头领，所有武力值输出到对方老大身上，往死里干。这才是奔着打架去的。

相反，如果是要逃，该怎么做？把边上都搞乱，能砸的东西都砸了，场面一乱，自己就跑了。

所以大家想想，伊朗封锁海峡，到底是想猛劲跟以色列或者美国打到底，还是想拉中国，欧洲，东亚各国，王爷国，都帮忙拉架？顺便强行逼着美国坐下来谈判？

想到这，你就应该明白伊朗想的是什么了。

他真想打仗，导弹使劲砸航母，把航母打沉也算光荣一次。

相反，封锁海峡就意味着，导弹省着用。省着用，就意味着不想打。

还是那句话，菜逼不是风险。

只有不知道你到底能赢还是能输，你才能引起风险。
