# 快速、簡易的財務分析公式與比率

每股淨值 = \frac{資產總值 - 無形資產 - 負債總值}{流通在外的普通股股數}

負債淨值比 = \frac{負債總值}{股東權益}

淨流動資產價值 = 流動資產 - 流動負債

流動比率 = \frac{流動資產}{流動負債}

速動資產淨額 = 流動資產 - .存貨 - 流動負債

速動比率 = \frac{流動資產 - 存貨}{流動負債}

淨資產價值 = 流動資產 - 流動負債 - 長期負債

每股淨資產價值 = \frac{流動資產 - 流動負債 - 長期負債}{流動在外股數}

本益比 = \frac{股價}{每股盈餘}

毛利率 = \frac{毛利 \times 100}{總股數}

自由現金流量殖利率 = \frac{每股自由現金流量}{股價}

現金流量折現模型 = 現值折現

= \frac{未來價值}{(1 + 利率)^n} = 未來價值 \times (1 + 折現率)^n
