克拉曼提醒我們，貝他係數有以下幾個缺點：

+   - 貝他係數只從股價來評估風險，並未考量公司的基本面或經濟發展情況。
- 貝他係數忽略物價水準。例如用每股 50 美元買進 IBM 股票的風險不比用每股 100 美元買進時風險低。
- 貝他係數沒考慮到投資者對風險的影響。委託書爭奪戰 (proxy contest)、股東決議 (shareholder resolution)、與公司管理團隊溝通，或買下一定比例股份掌控公司等，都可以直接影響一家公司的真正價值。
- 貝他係數認為任何投資的上漲與下跌風險相同，只是股價波動與整體市場波動的函數而已。

克拉曼說：「這跟我們認知不同，在現實社會中，過去的股價波動不見得能準確預測未來股價表現（甚至很難成功預測未來的股價波動幅度），因此並不是評估風險的可靠指標。」$^{46}$

查理·布蘭德斯也同意這個看法。布蘭德斯說：「波動程度可以量化，但不確定性無法量化……（現代投資組合理論）將『波動程度』定義為『風險』可以說是不切實際，因為所謂的投資風險指的是賠錢的可能性。貝他係數是給只看市場整體（或多檔股票）的表現、但不管特定公司基本面細節的人。我說過，對價值投資者來說，這個概念不但無法成立，而且還可能很危險。」$^{47}$
