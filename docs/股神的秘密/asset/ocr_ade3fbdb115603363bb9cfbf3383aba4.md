# 參加年度股東大會：作個主動型投資人

投資人應該很想參加年度股東大會；或至少想參加一些公司的年度大會。

要了解企業的管理團隊好不好，最好的辦法就是親自去聽、去看他們是怎樣的人，這樣一來，你可以知道很多事，這些高級主管是不是很平易近人？是很緊張還是很冷靜？他們願不願意回答你的問題？

在傑克·威爾許（Jack Welch）還擔任奇異電子執行長的時候，如果你參加他們的年度大會，就會看到這位充滿精力、努力不懈的領導人；而且，他永遠要求更好。
