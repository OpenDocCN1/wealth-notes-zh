+   - 如果某公司破產了，可能也代表公司所處的產業面臨相當的壓力。以報業來說，情況顯然不可能回到從前，所以投資人也要重新思考。可是，大部分的人都想知道世界上正發生什麼事；資訊對民主政治、自由企業與多數活動來說都很重要，所以我們要問：是什麼會取代傳統的新聞來源？其中有沒有投資機會？如果你這樣想，可能就會投資在 Google，或投資美國清晰頻道傳播公司（Clear Channel Communications）等媒體股。

+   - 重要的產業不可能消失。食品、能源製造、醫療服務、銀行、汽車等重要產業中，一定會有公司屹立不搖。如果一家公司破產，沒希望東山再起時，就找他的競爭對手，看哪一家企業會吃下破產公司的市占。雖然福特汽車掙扎多年，還是有許多投資人在通用汽車、克萊斯勒出問題後，轉而投入福特汽車的懷抱。這些投資人相信，福特汽車對未來的規畫夠穩健，負債也比對手少。要說這是趁火打劫式的「秃鷹投資」（vulture investing）也沒錯，不過這就是資本主義的運作模式，我們的經濟總是如此不斷調整，所以不需要有罪惡感。
