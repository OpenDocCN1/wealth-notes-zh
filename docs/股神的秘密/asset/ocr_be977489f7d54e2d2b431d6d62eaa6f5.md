1，代表變動程度小於大盤。

如果某檔股票的變動情形與大盤完全相同，貝他係數就是 1。如果貝他係數為負數，代表當大盤上漲時，這支股票就下跌。

如果大盤指數漲了 10%，而某檔股票漲了 20%，這檔股票的貝他係數就是 2。如果一檔股票的貝他係數為 1.2，代表這檔股票的變化程度比大盤指數多 20%。

如果 A 公司的貝他係數為 0.70，則該公司的可能報酬率（虧損率）為大盤報酬率的 70%。如果 B 公司的貝他係數是 1.30，代表該公司的可能報酬率（虧損率）比大盤多出 30%。

高貝他係數的股票往往風險較高，但報酬率也可能較高。雞蛋水餃股* 的貝他係數往往很高。相對的，高貝他係數的股票報酬率雖然低，但風險也低。歷史悠久、信譽良好的老企業，貝他係數往往很低。

當然，貝他係數也可以是 0。有些貝他係數為 0 的資產理論上沒有風險，像是國庫券與現金。不過，貝他係數為 0 不代表一定是零風險。貝他係數為 0，只是單純表示投資標的與大盤的表現無關。譬如，股市與賽馬之間的相關係數為 0，不過這不代表賭賽馬就沒有風險。
