# 總在意料之外

根據價值投資者兼基金經理人查理·布蘭德斯的說法：「我總是強調，現在也一直強調，價值投資者——還有其他類型的投資人也一樣——會不斷看到市場令人意外的短期震盪與經濟變化。不管你預測市場可以漲多少、漲跌到哪裡，實際的表現永遠超越你的估計。就連我這樣的價值投資者也會常會覺得股價的變化實在令人意外。而且，我認為這種現象在未來也不會改變。」

# 當沖暗藏危機

當沖很刺激，卻又暗藏危機。隨著股票市場上下震盪，你也跟著殺進殺出，快速獲利。就定義來看，當沖就是看市場時機來投資。隨著個人電腦進歩神速，當沖的魅力也跟著水漲船高。
