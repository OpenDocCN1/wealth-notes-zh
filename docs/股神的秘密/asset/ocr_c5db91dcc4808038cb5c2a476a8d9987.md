# 安全邊際的限制

股價低於淨流動資產價值的公司，大多資本較小，也因此往往不受投資機構的青睞。資本小，交易量就低，很難購入較多的股份。如果投資人想取得一定的股份，可能要分好幾天才能買足想要的股數。

股價低於淨流動資產價值的股票不容易找，尤其在空頭市場更難。不過，2008年就曾短暫出現許多股價低於淨流動資產價值的股票。只是，雖然這時市場對追求淨流動資產價值的投資人有利，還是得研究為何這些股票的價格這麼低。當企業的市值低於淨流動資產價值時，與其繼續經營，還不如結束經營或賣出資產，利潤還比較高。如果這樣做，股東就可以分享資產出售的獲利。不過，除了資本雄厚、進攻型的投資人以外，大部分的股東都不希望看到這樣的結果，最好的情況是管理團隊可以扭轉局勢，讓公司的股票更吸引人，股價也跟著上漲。

葛拉漢建議，投資組合以低淨流動資產價值的股票為主時，應該：

+   - 股票張數比一般的投資組合更多。
- 盡力分散風險。
- 傾向持有獲利好的公司股票。獲利能力有問題、經營策略不明的公司都應該剔除。
