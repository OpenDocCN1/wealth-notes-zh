# 共同基金

共同基金很方便，有很超過1500支任君挑選，並成為主要的投資商品。不過，整體而言，共同基金的表現並不好，而且研究費与管理費往往墊高投資成本。免手續費基金（no-load fund）雖然不收手續費，但並不表示免費，因為這些基金還是會收管理費。

多年來，主動管理型的股票基金報酬比股市低約2%。¹⁰⁷約翰·柏格是先鋒共同基金集團的創辦人，他就寫過一本書，書裡提到，其實，大部分的投資人（包括非營利組織）投資在低成本的指數型基金會更有利。光是比較管理費，免手續費基金也比指數型基金高。

雖然如此，2009年股市開始反彈，共同基金一下子就流行起來。投資人很容易找到報酬率高達25%到35%的基金，其中也包括許多價值型基金。其實，報酬率之所以這麼高，是因為前兩年這些基金受創甚鉅。話雖如此，有將近2/3的基金表現還是比道瓊指數好。如果散戶沒時間或沒興趣研究股票與整體市場，還是可以買價值型基金。只是，在選擇這些基金時，還是得做點功課。
