經濟變化的影響。如果是生產、販售奢侈品或耐久財的公司，貝他係數就會比較高，因為人在手頭緊的時候可以選擇不買這些產品。如果負債比例提高，也會提高一家公司的貝他係數。

不過，貝他係數不見得能準確反映投資的風險，其中一個原因是貝他係數時時變動。此外，貝他係數的分析往往基於歷史數據，如果過度依賴貝他係數，結果可能會令人大失所望。

# ## 貝他係數與風險

雖然巴菲特同意貝他係數在衡量波動幅度時很有用，不過他也指出，波動幅度不見得代表風險，波動較大也不代表報酬就比較高。

基金經理人布魯斯・格蘭提爾（Bruce Grantier）說：「許多研究的結果都挑戰這項理論。價值型股票，也就是本益比低、股價淨值比（price/book ratio，或簡稱 P / B 比）也低的股票，貝他係數較低，但歷史的報酬率表現也比成長型股票高。這跟現代投資組合理論（MPT）的核心概念恰恰相反，因為現代投資組合理論認為報酬與風險成正比。」⁴⁴

包普斯特集團的塞斯・克拉曼也有類似看法，克拉曼寫到：「用一個代表過去價格變動的數字來代表一檔證券的風險，未免也太蠢了。」⁴⁵
