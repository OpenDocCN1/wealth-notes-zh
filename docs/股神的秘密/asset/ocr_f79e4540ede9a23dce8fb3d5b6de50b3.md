# 可轉換證券

可轉換股票與認股權證不同，但兩者有個共通點：其價值都取決於該公司未來的股價。

當情況不好時，企業可能比較偏好可轉換證券。專業投資人也比較喜歡可轉換證券勝過普通股，特別在風險走高時更是如此，因為可轉換證券的彈性比較大。

企業發行可轉換證券時，目的在募集資金。尤其是沒辦法靠傳統方式募集的公司（通常因為信用評等不好），有時會利用發行可轉換證券來快速集資。當一家企業的名聲或信用出問題時，就得額外付出成本來募集，這也是為什麼機會提高，風險也提高了。

可轉換證券通常是債券或優先股，可轉換成其他東西，通常是轉換成該公司的普通股。有時，是由可轉換證券的持有人決定要不要轉換，以及在什麼時候轉換。在某些情況下，發行的公司也可能保留更改轉換條件的權利。
