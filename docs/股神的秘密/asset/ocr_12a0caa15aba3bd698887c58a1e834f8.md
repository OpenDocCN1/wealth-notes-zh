· 有計畫地將贏來的錢（獲利）轉為他用。

要進一步了解賭博與投資之間的關係，可以上康州賭博問題協會的網站：www.ccpg.org。

# 防範詐欺

真正的價值投資者，在投資股票之前會先做相關功課，比較不容易陷入金融詐欺的圈套；柏尼·馬多夫（Bernie Madoff）這類詐欺犯設下的陷阱比較難影響到這些價值投資者。老鼠會與其他詐騙手段都一樣，很少真的影響市場，因為其背後的詐欺犯很少真的在市場投資。不過有個例外，就是公司內部的財務詐欺行為，這部分會在後面討論到。總而言之，要小心以下這些徵兆出現：

+   讓專專掌握你的資產，照他的意思投資、賣出，或隨時帶著你的錢一走了之。

+   持續出現不合理的超高報酬率。定期比較同商品的投資報酬率，如果有出現超乎尋常的報酬率，就要特別注意。

+   你不懂這些投資標的，而你的理專也告訴你，一般人本來就很難了解這麼複雜的學問。理專還告訴你，就是因為這樣，投資才會變成一門特別的學問。

+   投資時感性多過理性。可能你面對必須馬上做決定的壓力，可能理專施展百絡蓮花說你現在地位提升了，讓你心花怒放。

+   有一群狂熱的投資人共同參與投資計畫；這些人很可能是朋友、家人或是宗教團體。如果是宗教團體的人脈就更危險了，因為這些宗教團體都教我們要卸下心防，相信別人。
