# # 保守投資

巴菲特之前主掌「巴菲特合夥有限公司」(Buffett Limited Partnership) 時，批評他的人說，他不算是保守型投資人，因為他的選擇都很「不傳統」。也就是說，批評他的人將「保守」(conservative) 與「傳統」(conventional) 視為同義詞。

「的確，其他投資公司用比較傳統的方法投資，」巴菲特寫到，「對許多人來說，傳統型與保守型沒什麼兩樣。」「

但他也提醒我們，這種說法大錯特錯。「真正的保守投資來自聰明的假設、正確的資訊與合理判斷。這些特質可能會讓我們做出很傳統的投資決定，但很多時候也會做出不傳統的投資決定。’’

這個概念實行起來不容易，特別是在恐懼與不確定的市場環境下，更該拿出來提醒自己：**堅守葛拉漢的原則——獨立思考，不要人云亦云。**
