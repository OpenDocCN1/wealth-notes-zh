# 股東的責任

企業與主管機關有權利也有責任，股東當然也有權利和責任。約翰·柏格說，近年來這些專業基金經理人並未善盡職責，沒認真管理交付給自己的資金。「簡言之，」柏格寫到，「太多企業、金融經理人沒盡到職責，他們應該服務共同基金的投資人與退休基金的受益人，但他們卻沒做好工作。基金經理人沒盡到自己的忠實義務，企業經營者也將自己的利益放在股東的利益之前。」$^{82}$

柏格認為，法人与散戶都應該負起責任。股東自己應該：

+   - 知道自己是跟誰投資。
- 知道自己買了哪些股票，也知道這些股票的狀況。
- 了解投資人在總體經濟中扮演 的角色。
- 如有必要，要做個更主動的股東。
