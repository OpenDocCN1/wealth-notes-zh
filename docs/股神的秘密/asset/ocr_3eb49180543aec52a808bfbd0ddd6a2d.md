# # 尋找投資機會

布蘭德斯說：「一般來說，判斷市場時機是投資人常犯的錯誤；另一方面，看到房地產發生這些現象，就必須特別小心。這需要相當驚人的耐心，但投資人往往沒有足夠的耐心。」

布蘭德斯在 2008 年末給投資人的信中提到，許多價值投資的機會已經來臨，數千家好公司，如 Google、蘋果、英國石油（BP）、豐田等企業的股價都受到重創，來到低點。

這樣好的投資機會不到一年就消失了，但還是有部分優質的股票會低價一段時間。布蘭德斯解釋，只要有耐心，注重長期獲利，而且願意布局全球，不管短期市場如何震盪，其實有非常多的投資機會。布蘭德斯關注那些暫時失寵，但對生活、經濟很重要的產業，如醫藥與電信業，將這些產業納入投資範圍，提升基金的永續成長動能。

「銀行業就是一個例子。銀行體系與信貸服務有必要存在。如果你看的是未來 3 年、5 年的獲利，就會發現許多優良的投資標的。」但布蘭德斯也強調，分析銀行類股時要實際，「未來銀行的功用大概會不如此以往，而且銀行也必須依照法規提高自有資金部位；這樣做當然很好，只是如此一來也會降低投資報酬率。」
