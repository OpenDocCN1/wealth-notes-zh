# www.djaverages.com

提供所有道瓊平均指數（Dow Jones averages）過去與現在表現的相關資料。

# www.fool.com

「莫特利」（Motley Fool）網站。「莫特利」是最受歡迎的財經網站之一，針對各類型的投資提供新聞、分析、建議與資訊。

# www.footnoted.org

搜尋、提供並解釋企業提交給證券交易委員會的报告內容，附註（footnote）如何解釋，代表什麼意義。這個網站很有趣，也可以在這裡學到許多公司治理的相關知識。

# www.invetopedia.com

為投資人提供許多資訊，如一長串的名詞解釋、說明與財經相關文章。

# www.iqtrends.com

《投資品質趨勢》（Investment Quality Trends）是極具公信力的財經刊物，這是其網站。《投資品質趨勢》以三十年為單位追蹤、研究股利的重要性、影響與價值，並且提供投資收益與成長的相關資訊與指引。
