# 現金流（cash flow）

企業的淨利（稅後）與沖銷的其他費用，如折舊、折耗、攤銷等。

# 普通股（common stock）

一種擁有公司的形式。持有普通股的人，會在優先股持有人分得股利之後，才分得股利。如果公司遭到清算，普通股的持有人也是最後拿到錢的人。

# 道氏信號確認（confirmation of Dow signals）

「道瓊指數」或「道瓊運輸事業平均指數」（Transportation Average）變化方向應該相同，也就是說其中一個指數來到新高點或新低點時，另一個指數也應該出現相同變化，才能確認這是有意義的趨勢。另外，趨勢可能會在其中一個出現。

# 反向投資人（contrarian）

反向操作的投資人大大部分投資人的作法相反。反向投資人相信，如果大家都覺得會怎麼樣，實際上就不會是這樣。因為大眾集體相信某事會發生（如道瓊指數將重挫），就會做出相對應的動作：這樣一來，這件事就不會發生。當投資人相信某檔股票要漲，所以是好買賣時，就會去買，造成股價上漲。反向投資人喜歡買進遭人忽略的股票，等待這些股票重新受到注意。
