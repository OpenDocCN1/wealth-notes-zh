# 速動比率

速動比率又稱為酸性測試，可用來衡量企業每天的營運狀況。

速動比率 $ \frac{\text{流動資產} - \text{存貨}}{\text{流動負債}} $

速動比率為 1 時，代表如果所有營業活動突然停止，企業也能清償債務。聽起來這個可能性很低，不過像 911 恐怖攻擊之後，航空業便受到這樣的衝擊。當時飛機不能飛，可是薪水、設備維護、貸款給付等都還是要付，而且必須隨時準備好復工。過了 6 個星期，美國所有機場才重新開放，恢復航班。但即使這樣，很多人還是不願搭飛機，因此讓航空業經營更加困難。這次事件重創了航空業。這種意外就是會發生，所以如果企業能夠通過流動比率與速動比率的雙重考驗，就可以讓人比較放心。
