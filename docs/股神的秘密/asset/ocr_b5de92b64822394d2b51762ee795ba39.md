# 資訊永遠不嫌多

雖然葛拉漢覺得沒必要與經營團隊打交道，但過去 30 年來的發展顯示，投資人必須了解每一個細節，並且利用資訊提升自己的投資技巧。

「美國證券業的相關法規來自一個簡單、直接的概 念：所有的投資人，不管是大型機構法人還是散戶，都有 權在買入證券之前取得投資相關的基本資訊，而且只要繼 續持有，就有權繼續取得相關資訊。」美國證券交易委員 會在〈我們做什麼〉（What We Do）宣言裡如此寫到，「為 了達成這個目標，美國證券交易委員會要求，上市公司必 須揭露重大的財務相關資訊，讓大眾知道這些資料。這樣 一來，所有投資人都能用這些資訊來決定該買、賣或持有 某檔證券。穩定、即時、全面的正確資訊，是投資人做出 正確投資決定的必要關鍵。」⁸¹

還好，有了網絡之後，上市公司的資訊可以輕易取 得，而且任何人都可以取用。因為很少人會運用這些資 訊，所以如果你認真做功課，就占有很大優勢。
