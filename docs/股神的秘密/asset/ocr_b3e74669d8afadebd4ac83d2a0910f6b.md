# **www.sec.gov**

提供美國上市公司相關的規範、法條與公司治理等相關資訊。

# **www.sec.gov/edgar**

提供美國上市公司的相關文件與資訊。

# **www.sec.gov/investor/pubs/**

提供數千項多關於企業的實用資訊與指引。另外，這個網站也提供幾篇教你如何分辨、預防詐欺的實用文章。

# **www2.standardandpoors.com**

提供標準普爾公司產品服務與各種指數的詳細資訊。

# **www.treasurydirect.com**

你可以開設帳戶直接在線上向美國財政部（U.S. Treasury）買賣美國政府債券，如國庫券（Treasury bill）、國庫票（Treasury note）、國庫債（Treasury bond）或儲蓄債券（savings bond）。可以從指定的銀行帳戶匯出或匯入。

# **www.valueinvestorinsight.com**

《價值投資者洞察》（*Value Investor Insight*）雜誌網站。提供最新一期的雜誌試讀版。
