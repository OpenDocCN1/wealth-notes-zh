都用了這個模型。歷史教訓告訴我們，如果金融市場上每個人都做一樣的事，就會導致泡沫與難以避免的泡沫破滅。』 $ ^ { 42 } $

房價慘跌，失業率隨之攀升，債務違約擴及多項金融商品，幾兆美元瞬間蒸發，全球金融體系幾乎全面潰敗。這個故事的教訓是什麼？不管對專業投資人，還是其他散戶都一樣，那就是不要投資沒有徹底了解的商品。所有的金融活動都必然有風險。風險無可避免，但可以事先做好準備，防範於未然，並且降低風險。在這個過程中，務實思考大有幫助。

# 風險與報酬的相關性

葛拉漢說：「有時風險與報酬呈正相關……不過，價值投資法恰恰相反。如果你用 0.6 美元買 1 美元的資產，風險就比用 0.4 美元買 1 美元的資產來得高，但後者的預期報酬又比較高。』

這種推論又把我们帶回到葛拉漢的「安全邊際」概念；就像巴菲特所說，這個概念不需要用到高等數學。簡單來說，安全邊際就是資產的真正價值與股價之間的差距。如果這個值為負數，代表股價被高估了。有時這個差距變小，有時變大；這個差距變大時，就是我們要等的投資機會。
