# 商譽（goodwill）

為會計名詞，指的是「資產價格」與「實際付出價格」之間的差異。也可以指一家公司的名聲、專利、商標、位置等優勢的價值。

# 對沖基金（hedge fund）

指的是一家採有限合夥人制度（limited partnership），用高風險的方法尋求超乎尋常報酬率的投資公司。這些特別的基金公司經由主管機關許可，可以投資的標的包括其他投資公司不能投資的商品。一般來說，對沖基金的經理人會有績效費（performance fee）。每個避險基金都有自己的投資策略，自己決定要做什麼樣的投資，並選擇各自的投資方法。聯準會在 2010 年通過新法規，規定避險公司必須揭露更多訊息，也規範了更多的限制。

# 損益表（income statement/profit and loss(P&L) statement）

又稱為「獲利報告」（earnings report）。損益表反映出企業在某一段會計期間的收入與支出，這個會計期間通常是一季或一年。
