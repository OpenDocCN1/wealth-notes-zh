# 不需要時時關注的投資組合

價值投資法的一個目的是讓投資人可以長期持有一檔股票，當持有的投資組合規模較小且容易管理（例如不超過 30 支股票），只要定期注意投資方向，就不用花太多時間，壓力也不會很大。不過，近年來如此簡單的投資法的确出現很多問題。

儘管也有成功的例子，但是只買幾家企業的股票實在很難分散風險。此外，如果以爲買下一籃子股票、一輩子抱著不放就可以輕鬆獲利，不但不切實際，還有點危險。

惠特尼・蒂爾森（Whitney Tilson）與約翰・海因斯（John Heins）在《吉普林個人理財雜誌》（Kiplinger’s Personal Finance）裡寫到：「買進並持有的年代已經過去了，雖然我們不鼓勵頻繁交易，可是世界變化這麼快，如果買進之後就放著不管，風險會越來越高，特別是投資科技股的時候。」$ ^{21} $

蒂爾森與海因斯以諾基亞（Nokia）為例，諾基亞曾經是手機界的龍頭，「可是輸了幾回合的產品大戰後，立刻重重地從寶座上掉了下來。」$ ^{22} $
