# 槓桿操作（leverage）

借錢以增加購買力的投資方式。

# 清算價值（liquidation value）

企業賣掉所有資產，並清償所有債務之後可得到的現金。

# 融資／融券（margin）

用借錢／借券的方式來買／賣股票。

# 追繳保證金（margin call，又稱「融資追繳」或「補倉」）

券商要求投資人償還借款，可能導致投資人必須賣掉該證券。

# 安全邊際（margin of safety）

安全邊際的關鍵在概念是指投資商品的價值低於價格部分。在選股、選債或配置投資組合時，要找出這樣的誤差範圍，才能避免誤判或意外造成的衝擊。就好像工程師造橋時，橋樑可承受的重量設計會大於預想的重量。不過，關於如何加強安全邊際，有許多不同的理論。
