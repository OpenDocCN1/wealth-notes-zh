# 了解投機

《安全邊際》(Margin of Safety)一書中，作者塞斯·克拉曼將資產與證券分為兩大類：投資與投機。他說：投資就是「投入金錢並創造股東利益，但投機不是。」

不過，葛拉漢對投機的定義不太一樣；他認為，投機就是更大或更特別的風險。葛拉漢常說，如果充分了解投機，那麼投機就可以接受。他的意思是，投資人必須清楚自己承擔的風險是什麼，必須認真蒐集相關資料，也應該有充分理由證明未來得到的報酬值得承擔這樣的風險。
