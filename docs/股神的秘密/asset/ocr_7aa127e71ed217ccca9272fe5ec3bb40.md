# 安全邊際

拉比・納葛瑞詹 (Ravi Nagarajan ) 寫到：「我沒看到幾個經濟學家可以準確預測總體經濟的變化，也沒看過幾個股市分析師精準預測到主要股市將大跌 50%。當然，我當初也沒想到股市會一片哀鴻遍野，也不認為自己有能力預測明年此時的道瓊工業指數或 S&P500 指數。與其試圖猜測未來經濟或市場的走向，不如找一找哪些股票擁有較高的安全邊際。」 $ ^{8} $ 安全邊際就在那些你想買賣的股票中。

在價值投資法的討論中，常常會出現「安全邊際」這個詞。這個概念很簡單：如果你買一間房子的價格低於市價，或低於其他相同大小、相同種類的房價，那你承擔的風險就比較小。如果你需要賣房子，就比較有機會用相近或甚至較高的價格賣出。同樣地，用折扣價買車和買股票也一樣。價值投資者找的是好買賣，也就是價格低於實際價值的股票。買進價格與實際價值的落差，就是所謂的安全邊際。

有許多不同的方法可以找出安全邊際，葛拉漢主要從以下三個地方找：

+   - 資產評估。

+   - 獲利能力分析。

+   - 多樣化投資。
