+   - **有權在股票交易所賣出持股。**這保障投資人可以將股票快速變現。這種流動性正是股票與其他投資工具不同之處；房地產或收藏品往往要花更長的時間才能順利賣出。

+   - **持有普通股的股東可以享有普通股股利。**不過，並不是每家公司都會發放股利；就算會發放，可能只是偶爾發放。企業獲利往往會以再投資的方式注入企業，希望能藉此提升公司的獲利能力，為股東創造更多的價值。

+   - **有權檢閱企業的財務報表與紀錄。**申請公開上市的財報，包括季報、年報還有其他的報告。這些報告大部分都可以經由美國證券交易委員會的線上 EDGAR 資料庫取得。*

+   - **如果發現經營者有問題，股東可以對公司提起訴訟。**這就是所謂的股東集體訴訟。世界通訊當初誇大 2002 年的獲利，使股東、投資人高估它的財務狀況。事件爆發後，這家電信巨人的就面臨許多股東集體訴訟。另一方面，有些人主張應該限制集體訴訟的權利。
