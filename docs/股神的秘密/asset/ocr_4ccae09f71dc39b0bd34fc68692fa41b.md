巴菲特提醒我們：「我們面對的是新時代、新產品，但一切終究還是要回歸到市場的本質；市場應該為我們所用，而不是把我們牽著鼻子走。」

厄文·卡漢曾說：「在葛拉漢的保守派與股神巴菲特的高手風範之間，一定有適合自己的投資模式；要從中找到適合自己的風險／報酬組合，找出最適合自己資金需求與生活模式的投資方法。」⁵⁶

# 你是在投資，還是在投機？

許多投資人不懂什麼叫做投機，也就沒察覺到自己正在賭博。以下列出幾項特徵，提醒你可能以為自己正在投資，但其實是在賭博：

+   - 冒著風險進行投機，導致相當程度的損失。
- 已經賠錢了，還繼續投機，或是無法停損。
- 借錢投資。
- 行為反覆、不一致、不理性，或頻繁交易。

康州賭博問題協會（Connecticut Council on Problem Gambling）針對賭博問題提供一些指引，而這些內容很多都適用於證券市場上的投機行為：

+   - 不要動用到日常生活費用。
- 設定上限，算好自己最多可以損失多少錢，要是輸了這麼多錢，就立刻停手。
- 虧損就不要搶進，反而增加輸更多的風險。
