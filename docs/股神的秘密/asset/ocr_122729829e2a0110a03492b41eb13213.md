# 信用違約交換（credit default swap，簡稱 CDS）

為一種金融（交換）協議，用以轉移固定收益產品的信用曝險（credit exposure，指的是交易對手違約時可求償的金額）給另一方。

# 流動資產（current asset）

現金或其他可在一年內可變現的有價資產。

# 流動負債（current liability）

一年內必須清償的債務。

# 流動比率（current ratio）

流動資產除以流動負債。雖然每個產業情況不同，不過大部分的分析師認為，企業的流動比率應維持在 2，也就是流動資產應為流動負債的兩倍。

# 當沖交易（day trading）

在同一天買進、賣出金融商品的投機行為；換言之，即在同一天買股票，並在收盤之前賣出。當沖交易的投資方式包括買賣股票、股票選擇權、貨幣、還有各種期貨合約，如股票指數期貨、利率期貨、原物料期貨。這種行為又稱為活躍交易（active trading）。
