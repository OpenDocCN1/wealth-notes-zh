+   - 資料蒐集或實地查核是別人做的，別人說什麼你就信什麼。
- 網絡上或電話中有陌生人要教你如何發財。網絡是投資人的好幫手，但就像其他有用的工具（如鏈鋸、焊槍）一樣，也可能用在不好的地方。詐騙集團現在運用網絡，重新推出舊有的詐騙手法，老鼠會、拉高倒貨（pump and dump）都是他們的手法之一。本書最後面會附上相關的名詞解釋。

# 如何避免詐欺陷阱

+   - 不碰自己不懂的商品、計畫或投資標的。
- 不碰高風險的股票或債券。
- 查證理專、投資顧問的背景，在投資前先向主管機關查詢。如果對方獨來獨往，或只跟少數幾個人合作，就要特別查清楚，確定這筆投資一切正常。查明他是否擁有執照？購買的商品是否登記在案？是不是透過正當程序上市？對方之前有沒有詐欺的不良紀錄？
- 你的直覺會告訴你有沒有問題。直覺常常很準，所以要相信自己的直覺。

# 如何處理金融的詐欺行為

向負責的主管機關回報，求取資訊與協助。
