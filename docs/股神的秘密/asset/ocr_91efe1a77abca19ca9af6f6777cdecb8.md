# 葛拉漢的重要概念

1920、1930年代的股市表現看似毫無道理、難以預料。但葛拉漢知道，混亂的表象下有其規則。他指出，每支股票都代表真正的企業，而企業有其價值，就跟房子、馬匹或帽子有特定的價值一樣。知道買下企業的正確價格，再將這個價格除以流通在外股數（shares outstanding），就是正確的股價。聽起來也許是常識，但當時沒有人用這種方式投資；即使到現在，追隨這種理念的人仍是少數。

葛拉漢在50年前就有先見之明，告訴投資人不要試圖預測股市走向——這樣做必敗無疑。不過，投資人的確有辦法避免損失，趁股價低迷時買進價值高的股票。

葛拉漢鼓勵投資人自己思考、獨立行動，並且不斷問問題。經過不斷的觀察與研究之後，葛拉漢找出適用於所有投資人、經得起不同時代考驗的三大法則。

雖然巴菲特與其他葛拉漢信徒具有驚人的分析能力，但他們仍然信奉這三大法則：正確的態度、尋求安全邊際與估算內在價值。我們會在第2章進一步探討這些法則。

的確，大部分的散戶已經不知道要如何計算、甚至估算股票真正的價值（也就是內在價值）。最近的金融危機也無可避免地會持續發酵。可以說，一則以喜，一則以憂。
