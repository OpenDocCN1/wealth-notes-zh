+   - 穩固資產根基，如生產設施升級。
- 降低債務比例，因而減少營運成本。
- 刺激未來的獲利成長。

所幸，即使對損益表動手腳，往往也只會影響當年或短期的獲利。到最後，紙總是包不住火的。

# # 誠實的數字調整

有時，公司根本上有些東西會「沖銷」或「打銷」，這不見得違法。這種數字調整對投資人有幾個好處。譬如，如果某項借款確定收不到了，或某些資產變得一文不值（如因新設備的出現，所以舊設備的價值大不如前），那麼在會計帳目上調整這些數字對投資人比較好，因為這樣一來投資人比較能看到公司真正的營運情況。

有時，投資人可能過度反應，看到企業的營收暫時受創或股價下跌就驚慌失措，這時聰明的投資人就會利用機會逢低買進。不過要注意，企業管理團隊有時會故意將沖銷項目留起來，在獲利不佳時再認列。這樣一來，這些壞消息通通一次發作，就不會抵銷之後旺季的好表現。常常在沖銷之後的會計期間，獲利會往上衝。這樣的獲利成長讓一些人心花怒放，因為這些投資人將之當作成長的趨勢，沒發現這其實只是回歸常軌。要避免這種錯誤，可以
