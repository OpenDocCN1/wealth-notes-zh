# 衍生性金融商品

衍生性金融商品是用股票、債券或指數型金融商品包裝而成的金融投資工具。期貨與選擇權就是歷史最悠久、投資人也最熟悉的衍生性商品；但隨著時間過去，許多衍生性金融商品卻變得越來越複雜。雖然多數散戶不會將錢投資在複雜的衍生性金融商品上，但這些商品卻會出現在對沖基金和其他基金中，也可能出現在公司的資產負債表上。

一言以蔽之，衍生性金融商品不可信賴。面對這些複雜難解的金融工具，經驗老到的投資人常用「布萊克－修斯公式」（Black-Scholes formula）等複雜的公式來評估風險，不過這種工具不見得百分之百可靠。

巴菲特寫到：「確實，最近的這些事件顯示，許多知名執行長（或「前」執行長）根本沒有能力管理帳面上的許多衍生性商品，查理跟我也不例外。」⁵³

儘管巴菲特也持有一些遭低估的衍生性商品，不過他通常對衍生性商品敬而遠之。他在1998年買下通用再保（General Re）這家英國保險公司時，就學到這個教訓。他發現通用再保公司擁有太多衍生性金融商品，立即關閉該公司的衍生性商品部門，因而損失4億美元；他寧可這樣做，也不要續抱這些令人坐立難安的長期風險。那次決定的過程費時甚久，也很痛苦。
