# 空頭市場的特徵

空頭市場的低點跟多頭市場的高點一樣難以察覺，當股價越跌越深，專家們就會開始問：現在跌到谷底了嗎？甚至有些就直接宣稱已經跌到最低點了。

當然，股市的變化有跡可尋，可以發現一些徵兆，例如股價指數接近或創歷史新低。企業的資產負債表、損益表、本益比、現金股息殖利率（dividend yield）等數字都是徵兆之一。

只是，投資人這時往往鬱卒無比，無意再戰；就算價格再誘人，他們也不想重入股海。

# 現金股息殖利率
