大衛·埃本曾說：「我們還是偏愛價格遠低於淨值的股票，我們喜歡淨值帶來的下檔支撐能力與股價爆發力。」$^{43}$

為了確保安全邊際，就要找出具有投資價值的商品。這樣的安全邊際可能來自某樣重要商品的大量庫存、某特定領域的當紅產品，或是強勁的現金資本。此外，也要試著：

+   - 在市場走弱、許多股票遭低估時買進。2008年末與2009年初就是這樣的例子。

+   - 尋找暫時受到衝擊的公司。2007年、2008年金融海嘯發生的時候，有些聰明的投資人趁機檢視各大銀行的情況，找到價格低廉的優質投資機會。2009年末，豐田因為加速器問題召回部分車輛，問題就開始越滾越大；到了2010年初，已經召回超過800萬部車，不但讓豐田付出許多成本，也影響原本極佳的商譽。2010年1月19號，豐田的股價為91.78元；但投資人了解問題的嚴重性後，股價立刻應聲下跌。到了2010年中，股價已經跌到68元。看起來，豐田似乎玩完了。不過，其實福特汽車（Ford）與通用汽車（General Motors）都曾出現召回車輛的紀錄，後來股價也都回升反彈。價值投資者密切注意豐田的變化，認為只要有耐心等待股價回升，這其實是價值投資的大好機會。

+   - 即使空頭市場尚未出現，也可以仔細搜尋遭忽略的優質股票。
