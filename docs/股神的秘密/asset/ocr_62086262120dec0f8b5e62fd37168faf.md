# 預測股價高低點只會徒勞無功

1902 年，查爾斯・道在專欄裡寫到：「在股市裡，你永遠不知道漲的時候高點在哪，也不會知道跌的時候低點在哪；只有在最高點、最低點出現一段時間後，才能確定什麼時候是真正的高點和低點。有時可以猜到高點和低點的價格，但這種猜測實在沒什麼意義。華爾街有一句話說，只有愚蠢的投機客才會想要買在最低點、賣在最高點。有經驗的投機客都知道，沒有人可以總是買在最低點、賣在最高點。」$^{28}$

巴菲特說，大部分的投資人都禁不住市場時機的誘惑。他常觀察到所謂的「灰姑娘症候群」（Cinderella Syndrome）：「他們（投資人）到達舞會現場，雖然明知馬車在午夜 12 點就會變回南瓜，可是每個人還是以為自己會在 11 點 55 分離開，實際上這根本做不到。」

「如果你是百分之百的價值投資者，就不會買在高點。」大衛・埃本這樣說。大衛・埃本是「紐文信風價值機會基金」（Nuveen Tradewinds Value Opportunities Fund）的基金經理人，這個基金規模高達 5 億 7400 萬美元，他自認是尋找深度低估價值的反向投資者。在 2007 年、2008 年金融危機出現的前 3 年，他為客戶創造平均超過 17% 的報酬率。2008 年，他的投資組合跌了 32%，但在 2009 年又反彈了超過 40%。
