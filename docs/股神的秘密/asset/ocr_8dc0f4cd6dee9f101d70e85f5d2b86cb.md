# 了解風險

有些風險的道理很顯而易見。一般來說，年輕人比老年人更能承擔風險，他們有時間調整自己的投資方式，並且將之前的損失贏回來。收入較低、儲蓄較少，可承擔的風險就比較小；相對的，如果收入高、負債少、儲蓄多、有充足的緊急備用金，就可以承擔更高的風險。越急著想投資，就應該要越保守。
