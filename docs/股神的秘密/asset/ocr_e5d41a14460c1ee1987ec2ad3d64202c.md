# 成長型股票

投資高成長公司的股票可以替投資組合注入活力。不過，成長率越高，風險也隨之提升。最好的例子大概莫過於 20 世紀末的科技泡沫。還好，投資人可以用價值投資法找出優質的成長型股票。關於這部分，會在第 9 章進一步探討。

記得：

+   - 對投資人來說，能持續獲利的公司最有吸引力。
- 尋找獲利穩定上漲的公司。
- 尋找本益比相對（比起其他同業）較低的公司。
- 估計時，要保守。低估一點往往會有更多安全邊際。
