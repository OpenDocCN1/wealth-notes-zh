# 規則 9：分散風險

如果我們總是能夠完美做出理性判斷，總是很有遠見，就不需要分散風險。如果所有資產的漲跌都很規律，也沒有必要投資不同標的。只是現實並非如此，而分散風險可以加強投資的安全性，讓投資的基礎更穩固。

「另外，我要再次強調，每個人都應該持有一些黃金。」大衛．埃本重申，「投資組合也一定要包含房地產、股票與硬性資產。房地產的投資應該選擇沒泡沫化的市場，投資組合要全球布局，才能分散風險。」

# 規則 10：通膨不會消失

通膨是隱形的敵人，摧毀過許多經濟體，重創許多公司，並且嚴重侵蝕許多人的財富。

「通膨一定會影響到你，」巴菲特說，「而且是長期的影響。就算通膨只有一點點，也不是好事。」他說，對抗通膨最好的辦法就是維持自己的獲利能力，「第二好的辦法是擁有一家不需要太多資本的好公司，像是可口可樂。有了可口可樂，你就可以分享整個國家的獲利。」
