拉比·納葛瑞詹在「理性之道」(Ratinal Walk) 的網站上寫到：「許多股價低於淨流動資產價值的股票，股權都是集中在一個人或一小群人之中。在這種情況下，如果這些核心人物的想法與我們自己的利益衝突，就很難確保公司的價值能為股東共享。例如，如果管理團隊也領公司薪水，公司的錢可能會透過薪資制度大幅流向這些人，因而影響股東的利益。因此，一定要檢視企業的管理團隊是否可以信任。」66

# 流動比率

另一個營運資金的標準是流動比率。

流動比率 = 流動資產 / 流動負債

可以看到，流動比率很直觀，可以立即反映企業的現況———也就是當下的情況。流動比率為 2（即 2 元的流動資產比上 1 元的流動負債）比較理想。企業的負債不應超過流動資產的 50%。如果公司的存貨少，收帳也沒什麼問題，就可以負債稍微多一點；如果是大公司，現金又較不穩定，就不該這麼做。
