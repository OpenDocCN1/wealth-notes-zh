法律不過是最基本的保障。好的企業領導人知道，他們不但要遵守法律，而且還要用更高的標準要求自己。

「安舒龍」（Assurant）這家大型保險公司就有長達25頁的「企業道德準則」（corporate code of ethics）。裡面就提到，所謂好的行為，就是對股東最有利的行為，「我們致力於為股東提供長期價值。」安舒龍的道德準則如此寫到，「而且採用最高標準，不管做什麼都嚴格自我要求，以達成這樣的目標。」

《投資者財經日報》創辦人威廉·歐尼爾指出，如果企業不誠實、不公正地做生意，問題往往會反撲並自我修正，最後企業會自食惡果。歐尼爾說：「空頭市場來臨時，許多這樣的企業就會陣亡。」

「能做」不代表「應該做」，在資本主義的體制下，理性判斷與誠信還是很重要。

這次金融危機中，受重創的公司都是過度擴張與過退房貸放款企業，像英國的北岩銀行（Northern Rock）、美國的國家金融借貸公司（Countrywide Financial）都因為信用緊縮受到重創。超過100家的房貸放款機構在2007年、2008年間破產。貝爾斯登投資銀行（Bear Stearns）因為擔心在2008年3月倒閉，所以匆匆賣給了摩根大通。
