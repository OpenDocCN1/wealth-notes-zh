# 什么是“穷”？穷时该怎么办？

现代以来，汉语里很多字词的意思都变了。例如“穷”字，原意是无路可走、无法实施，但现代演变成没钱的意思，实际上替代了以前的“贫”字。

人生于世，总不免有受穷的时候。想做一件事做不了，做了一件事进展不顺，这就是穷。

面对穷的境况，不同的人有不同的应对方法。孔子曾说过，“君子固穷，小人穷斯滥矣”，意思是君子即使在困顿之中，也能固守本心，而小人一旦受穷，就会胡作非为。

孔子说这话时，是他一生中最穷的时刻，也就是被“厄于陈蔡”的时候。但他依然每天弦歌不绝。他的弟子子路不高兴地说：您不是君子吗？君子怎么会到处碰壁，落到这种地步？

孔子的回应，就是上面那句话。

另有一句最常用的，叫“穷且益坚，不坠青云之志”。这句话也跟有钱没钱毫无关系。它说的还是孔子的“君子固穷”之意，越是遇到艰难险阻，越是要坚定地朝目标走。

这句话实际上也解释了为什么君子能固穷，因为他们有青云之志。

古之圣贤教导人，第一在于立志，而且是树立远大的志向。有这个志向在，那么毕生就有奔头，遇到各种困难心里就能不害怕，不退缩。

今天我们要说成就一家伟大的企业，或者一个幸福的人生，也是要建立良好的使命和愿景。其实和古圣贤之教是一脉相承的。
