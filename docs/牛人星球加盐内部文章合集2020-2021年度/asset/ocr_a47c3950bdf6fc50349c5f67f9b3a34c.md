# 我们需要多大的耐心?

有一位星友问我，巴菲特的年化收益率也才 20%，不高啊，10 年才涨 6 倍，对普通人来说也没太大的吸引力。

他这话说的确实没错。巴菲特虽然被誉为股神，但是平均来说，他的每年收益率并不高。有很多人炒房子，一年涨 100%甚至更多，都不为过。单看这个数字，那是比巴菲特牛多了。

但问题在于，巴菲特是长期持续。他看的根本不是 10 年，而是 30 年、50 年甚至更长。

20%的收益率，涨 10 年，是看不出效果的，但是时间拉长到 30、50 年甚至更长，那就太吓人了。要知道，巴菲特 25 岁开始做投资，现在已经 90 岁了啊。我们假设开始的时候巴菲特资产只有 1 块钱，每年增长 20%，看看他日后投资的成果吧。（假设他能活到 100 岁，也就是连续投资了 75 年）

| 年份 | 资产 |
| --- | --- |
| 0 | 1 |
| 1 | 1.2 |
| 5 | 2.5 |
| 10 | 6.2 |
| 20 | 38 |
| 30 | 237 |
| 40 | 1470 |
| 50 | 9100 |
| 60 | 56348 |
| 65 | 140210 |
| 75 | 868147 |

所以你看，虽然刚开始看起来微不足道，但是当你把时间线拉长后，会发现到后面越涨越快。这就是指数增长的威力。

我们往往容易看一个事情短期的变化，而忽略了长期的效果。其实，长期比短期更重要。
