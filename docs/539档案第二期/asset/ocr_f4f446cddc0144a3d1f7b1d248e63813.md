# 我们的轮胎即使爆裂了...也可以让你从尤马开到菲尼克斯——204英里！

新固特异轮胎被刺破或爆胎后，让路边换胎店变得可有可无

车的 4 个轮胎都爆裂了，外面热得像火炉，你如何继续开 204 英里到达目的地呢？

听起来并不是很好玩，不是吗？然而，最近的一次固特异测试中，尽管 4 个轮胎都用冷凿扎破了，汽车依然从尤马行驶到了菲尼克斯，路途中没有带来一些不便。

这次旅程覆盖 204 英里，途径亚利桑那沙漠，温度高达 120°——路面滚烫。

在这段人烟稀少的路上，爆胎简直是件灾难，但是有了固特异轮胎内置“备用零件”，这次行驶测试得以顺利进行。

在这次行驶测试的最后，我们对固特异轮胎进行了检查，结果证明，缺气保用轮胎的“内胎”没有丝毫损坏……除了原来用凿子凿开的缺口，外胎其他部分也没有丝毫损坏。

缺气保用安全轮胎的成功，意味着汽车安全的一个重大进步。

这意味着，有史以来，第一次让车主，他的妻子，孩子真正摆脱了路边换胎的隐患。

# 缺气保用原理是这样的：

轮胎被扎破后，出现缺口或爆胎时，只有轮胎内层外部的空气泄露。内胎内的空气可以继续支撑汽车行驶，可以让你以常速行驶 100 英里，甚至更远。
