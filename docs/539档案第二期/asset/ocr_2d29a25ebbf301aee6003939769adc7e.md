# 现在，控制饮食很简单！

人类强烈地渴望快乐，长期以来，吃一直是人们追求快乐的一部分。难怪，很多想减肥的人，控制几天饮食之后，总会忍不住重新拿起垃圾食品，或放弃减肥计划。

为了欺骗他对美食正常的渴望，他开始服用“减肥丸”，通过增加基础代谢率，来降低食欲，这种药可能会使他感到不安、焦躁。为了补充因为吃的食物少，而缺少的营养成分，他又吃下了很多维生素药片。同时，他每天还要面对家人，他们每次都能吃自己想吃的美味饭菜。

对数以百万计真正想变苗条的美国人来说，现在真的有一个方法可以帮助他们了！那就是“饮食家”食物烹饪法，可以让你烹饪出漂亮，美味，营养丰富，又不含让人长胖的调味品的食物。

普雷斯托研究的“饮食家”能保留天然的盐分和糖，减少人体对高热量甜食的渴望。用这种方式烹饪的食物，饱腹感很强，因为它们非常美味，不用吃太多，就能感觉吃得很舒服。

一顿饭就可以通过一个锅，在短短几分钟内做好，并且确保各种食材的味道不混合。用“饮食家”方法烹饪的人，会用自己的烹饪锅，做出美味，营养的食物，而不必影响其他家人的饮食。

对遵循“饮食家”烹饪方法，控制饮食的人，有许多种食物可以选择：不管他是想要低热量，清淡的饮食，还是想要低脂肪、低胆固醇的饮食，现在许多医生都觉得，低脂肪，低胆固醇饮食，可能对预防心脏病有非常重要的作用。
