# 让家人更健康

调查报告显示，如何帮助孩子远离许多儿童疾病

医学期刊上发表的一份报告说明了，父母弄明白蛋白质“在孩子的成长中”扮演的角色，有多么重要。

这份报告，通过对数百名儿童的观察，表明，即使是轻微地缺少蛋白质，也会导致很多儿童疾病。

患有食欲不振，消瘦，免疫力下降，烦躁，麦粒肿，等等疾病的孩子，据观察，饮食中都缺乏蛋白质。

这个发现对父母可能有重要意义，但是对营养学家来说，已经不足为奇了，因为众所周知，肉给每个人，不管什么年龄阶段，尤其是处于成长期的孩子提供着重要的营养价值。

蛋白质是人维持生命的重要元素。肉是人体所需蛋白质含量最丰富，最优质的天然食品之一——供我们身体制造血液，肌肉生长，增强免疫力，抵抗感染，营养神经和组织。

B族维生素，铁和其他重要的矿物质。肉能提供身体所需的大部分必要营养物质。

肉中的脂肪也扮演着非常有益的角色。易消化，不会过量，不仅能增加饮食的乐趣，而且还能提供我们需要的能量。

肉中包含丰富的蛋白质，B族维生素，矿物质，能量（而且非常美味！）难怪人们都说“肉，真是好东西。”
