# 我们的轮胎即使爆裂了...也可以让你从波士顿开到纽约——231 英里！

新固特异轮胎被刺破或爆胎后，让路边换胎店变得可有可无

听起来令人难以置信，是吗？然而，一辆四个轮胎都爆胎了的车，依旧从波士顿开到了纽约，没有受到一些影响，全程历经 5 个小时。

固特异新型尼龙帘线缺气保用安全轮胎，可以保护“内胎”不受损坏……并且保护外胎除了被刀割坏，引发爆胎的地方，其他地方依旧完好。

从波士顿市中心到纽约时代广场 231 英里的形成中，几乎经历了所有可能的路况。

从泥泞的乡间小路，到拥挤的康涅狄格马路，任何轮胎问题都可能是灾难性的，而这次行驶测试没有遇到一点困难，进行的非常顺利。

缺气保用安全轮胎的成功，意味着汽车安全的一个重大进步。这意味着，有史以来，第一次让车主，他的妻子，孩子真正摆脱了路边换胎的隐患。

# 缺气保用原理是这样的：

轮胎被扎破后，出现缺口或爆胎时，只有轮胎内层外部的空气泄露。内胎内的空气可以继续支撑汽车行驶，可以让你以常速行驶 100 英里，甚至更远。
