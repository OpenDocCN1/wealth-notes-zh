# 科学是如何打破厚厚的泡沫之谜的

自动洗衣机制造商想要一种新的洗涤剂——
一种能去除各类污渍，又不会和以前的洗涤剂一样，产生厚厚的泡沫。

洗衣机制造商对理想洗涤剂做出的一些要求，非常具有挑战性：它的清洁能力至少要比目前洗涤剂好。它必须能够锁住清洗下来的灰尘，直到第二轮冲洗开始后，把灰尘冲洗掉。它不能产生厚厚的泡沫。

洗衣机制造商很早就发现，厚厚的泡沫对自动洗衣机不好。它会减慢洗衣机清洗速度，通常不容易清洗干净；而且经常会阻塞洗衣机的小配件，导致高昂的维修费用。

为了满足这些需求，化学家研发出了奥。奥含有“泡沫控制”成分，能打破厚厚的泡沫。在清洗的过程中，它不会在水面上产生厚厚的泡沫，减慢清洗速度，“泡沫控制”成分，能在水下发挥作用，把衣服洗干净。“泡沫控制”成分在衣服冲洗期间，不会附着在衣服上，而会和水一同流走。

今天，虽然奥仍然处于起步阶段，但是和那些实力雄厚的肥皂和洗涤剂、清洁剂相比，奥在洗涤品牌中销量却稳占第一位。而且它还是自动洗衣机洗涤剂指定用品。事实上，它object成功很大一部分要归功于自动洗衣机本身。

而且家庭主妇都证明，奥非常经济实惠。奥是浓缩清洁剂，用可用汤匙量取。一汤匙奥，比普通造成厚厚泡沫的名牌洗涤剂 3 汤匙的清洗能力都强。
