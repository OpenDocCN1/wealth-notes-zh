# 令人讨厌的人：

# 值得你为他们花费精力吗？

为什么你应该帮助那些给你带来麻烦的人？即使你想帮他们，那又如何帮呢？

医生们知道，总给别人带来麻烦的人，通常自己都处于烦恼中。那些总给你带来麻烦的人，他们可能自己就处于麻烦中——很大的麻烦！他可能精神上出问题了。如今，每10个美国人中，就有一个遭受着精神疾病的烦恼。

# 为什么他总是给别人带来麻烦？

这个人，还有他的一些行为，可能会激怒你，让你感到厌烦，不过他精神上遭受的痛苦可能无法估量。事实上，他可能也想与他人和睦相处。但他的内心不断迫使他做一些让人厌烦的事情。

# 你能帮助他吗？

当然，你可以给他提供帮助。虽然，你遇到这样的情况，可能第一反应是反击，实际表明，这么做，不能解决任何问题。事实上，你能给他提供的帮助非常简单，简单到你都无法相信它有效。这些人需要的就是理解…你的理解，理解他们遇到了问题。

给他们以同情……不要批评他们！像朋友一样去倾听。让他们知道，你在乎他们的感受……在乎他们心里的想法……在乎他们说的话！帮助他们意识到并不是所有人都讨厌他们。让你的行为证明这点。
