# 一切都源于粘膜

牙垢表明牙齿并没有清洁干净。牙垢形成的基础就是粘膜。如果 你每天清洁粘膜，牙垢就不会形成。

附着在你牙齿上的这个粘膜是大多数牙齿问题的罪魁祸首。它 一直存在，一直在产生。你用舌头就能感觉到。

粘膜指的是牙齿上那层变色的薄膜，而不是牙齿。它会粘住食物，使其发酵，产生酸。它会锁住这些酸，使其和牙齿持续接触，从而引起蛀牙。

数百万细菌在里面繁殖。这些细菌，以及牙垢，是牙齿脓漏的主要成因。

这层薄膜有粘性，所以会粘住食物。它会进入牙齿缝隙中，并停留在那里。普通牙膏无法溶解它。牙刷的刷毛无法够到它。这就是为什么每天都把牙齿刷的很干净，牙齿依旧会变色，腐烂。
