# 一款发动机的故事

由 R.E. 奥兹设计

我作为汽车制造商，这 26 年来，我的声誉大部分来自我设计的发动机。

可能对你来说，这款发动机是新型的，但对我来说，这已经是一个旧故事了。

# 终生事业

我是世界上使用燃气发动机最早的汽车制造商之一。在汽车大范围普及之前，奥兹燃气发动机已经享誉大半个地球。如今也是。

研发雷奥 5 代的发动机，投入了我毕生心血。就连我的竞争对手都认为，它是世界上最好的发动机之一。

我的目录册中详细介绍 了这款发动机。在这里我就不详述了。但是，这款发动机的声誉主要基于 4 点：

+   - 超常的动力——
- 超低音——
- 超长寿命——
- 方便调整——

# 严酷的测试

为了给你省去烦恼，我们对每个发动机都进行了 5 次严酷的测试。
