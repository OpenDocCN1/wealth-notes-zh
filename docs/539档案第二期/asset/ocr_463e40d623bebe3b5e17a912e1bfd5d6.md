# 生锈可以阻挡！

一位船长发明了它！
工业上证明了它！

当看到你的邻居往生锈的阳台栏杆上，涂栗红色的涂料时，不要惊讶。他很可能是用 Rust-Oleum 油漆来防止栏杆继续生锈。这不是普通的涂料，Rust-Oleum 的配方，是大约 50 年前，船长罗伯特·弗格森发明的，在他的职业生涯早期，他就对用鱼油来防止生锈产生了兴趣。他把经过特殊加工处理的鱼油，和防锈效果很好的颜料相结合。结果怎样？在用钢丝刷清理去除铁锈渣后，把这种颜料涂上去，物体表面就再没有生锈。可能因为鱼油将铁锈控制在了金属里面。这就是 769 年 Ruse-Oleum 特别防潮红色底漆的诞生。今天，Ruse-Oleum 投入工业生产，已经超过 35 年。

# 多种用途

周六，爸爸可能会用 Rust-Oleum 给他的割草机、打理草坪的工具，油箱、管道、花园栏杆，金属腰带、装饰铁、或汽车快速补漆。例如，爸爸可以骄傲地说，他多么会精打细算，只用了 98 美分（半品脱 Rust-Oleum）就让孩子的旧自行车焕然一新。工业方面也是如此，因为工业上金属比较多、全国每年投入 70 亿美金，使用 Rust-Oleum 来保护坦克、塔、桥梁、机械、管道、钢结构、设备等不受铁锈侵蚀。
