# 它悄然来袭，没有一点预警

来自：吉思·威尔，医疗新闻作家,休斯顿纪事报

这是一个漆黑，悲惨的夜晚，飓风戴安席卷了这个小小的新英格兰小镇——吹倒了树木，河水猛涨，流速满急，咆哮着进入了小镇。夜幕降临，山上山洪爆发……水沟成了河流……山谷成了湖泊。洪水已经开始——几分钟的时间，这个地方就进入了高危预警。

然后就是可怕的灾难后果……洪水消退，留下了死亡和废墟。慢慢地返回家园的灾民茫然四顾，他们面临的任务就是重建自己的家园。邻镇立刻送来了援助——还有一些食物、衣服、药品，包括来苏尔消毒液，防止传染性疾病的传播。

因为淤泥和碎片，是致命病菌温床，国家公共卫生通告，通常会提醒人们用有效的杀菌剂，如来苏尔，清洗灾后物品。

但灾后重建，并不是家里唯一需要来苏尔消毒液的时候。家中还有一个传播感染病菌的关键区域，那就是浴室。因为，危险的病菌（如目前医学头条“葡萄球菌”），就很容易在其表面沉积。

来苏尔消毒液，能够杀死它所接触到的病菌——即使是耐药葡萄球菌，还有其他许多致命的病菌。通过实验室的测试，使用来苏儿消毒液消毒7天后，它依旧有抗病菌效果。
