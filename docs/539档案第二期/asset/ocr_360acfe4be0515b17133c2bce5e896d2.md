# 如今复杂的电器，让你做家务更容易了，还是更困难了？

来自：乔治·罗姆尼

前几天，我在底特律一家电器展厅闲逛，当时我就忍不住在想，美国的家庭主妇们肯定对如今的机械仆人——她们的电器产品有想法。

闪烁的灯光，复杂的操作，看起来不知道怎么用的小器具，琳琅满目……但是，往往实用性却不强！

为什么会这样呢？我个人的观点是，如今一些制造商已经不能完全从客户的实际需要出发了。他们着重于通过产品装饰、广告，还有小配件来吸引顾客。

在美国汽车公司，我们坚持根据用户的需求，来设计我们的汽车和电器。我们牢记一点，你购买它们是为了使用，而不是仅仅为了向邻居炫耀。我们认为，产品噱头通常会分散顾客的注意力，使他们无法关注产品的真正价值。

例如，通过和许多家庭主妇交谈，我们了解到她们有个非常大的不满——那就是烤箱的清洁——这是厨房里最乱，最脏的工作。
