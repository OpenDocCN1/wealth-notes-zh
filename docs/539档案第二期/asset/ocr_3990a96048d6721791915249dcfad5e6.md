# 他们“从一文不名，到家财万贯”

# 现在，他们帮助别人做同样的事情

来自52个国家的学生。由著名艺术家自愿发起创办的艺术学校，现在依旧在运行中，他们对这个学校给学生带来的成就，感到非常自豪。

例如，埃里克·埃里克松，之前在明尼苏达州一个车库工作。在入学前，他从来没有上过任何一门艺术课。如今，他已经成为一个广告插画家，赚的钱是他之前工资的七倍。

![](bbox=[0.147, 0.435, 0.37, 0.616])

凯瑟琳·戈萨奇辞去了文书工作，准备要个孩子。在家的那几个月中，她开始学习艺术。在宝宝7个月大的时候，她就能够回到公司工作，这次的职位是高薪的广告艺术总监。

“谢谢你的课程，”，来自多伦多的罗伯特米查姆写道，“我从一个一周只能赚18美元的小职员，变成了成功的艺术家。我现在拥有了自己的房子，两辆车，而且还投资了两个公司。”

格特鲁德·范德·普尔在她入学前，从来没有画过一幅画。现在，她的画在纽约一个时尚画廊出售。

明天的著名艺术家在哪里？学生取得这么大的成功，多恩一点都不惊讶。“如今，训练有素的艺术家，机会无限，”他说，“我们不断地接到全国各地艺术品购买者打来电话，请我们推荐绘画技术好，可以接受全职或兼职工作，训练有素的学生——而不是天才。
