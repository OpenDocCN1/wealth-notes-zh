# 血液中的抗感染战士

研究表明，我们吃的食物，尤其是蛋白质食物，在增强身体抵抗感染能力方面，发挥着非常重要的作用。其中一个原因是，血液中的抗体“战士”是由蛋白质构成的——你从肉中获得的动物蛋白。

当超过一段时间，由肉类提供的蛋白质摄入过少的话，身体制造这些抗体的能力就会降低。含有丰富的蛋白质的健康饮食结构，能让身体始终处于“战斗形式。”

这就是为什么搭配均衡，营养丰富的饮食至关重要的原因之一——“饮食第一”成了上个月在华盛顿举办国家食品会议上的主题，参加会议的有著名科学家，教育家，医疗权威，商业，工业领袖等，美国总统在会议上发表了关于饮食健康的重要讲话，其重要程度可见一斑。

他们的目的是：重新让美国人民认识到营养丰富的饮食，意味着更好的生活。唤起很多家庭意识到改善饮食中的不足，和营养不均现象的迫切性。

好的饮食，当然包括大量优质的肉，因为肉能提供大量必要的营养元素。它是我们获取每天身体必须的丰富，优质蛋白的天然来源之一。它在为身体提供必需的B族维生素，铁，以及其他矿物质方面，起着至关重要的作用。而且肉的脂肪容易消化，不仅能增加饮食的乐趣，还为我们提供了身体所需的能量。

肉中包含丰富的蛋白质，B族维生素，矿物质，能量（而且非常美味！）。难怪人们都说“肉，真是好东西。”

这个广告中关于营养的说明，得到了美国医学协会食品和营养委员会的认可，符合当前权威的医疗意见。（619）
