# 为什么牙齿会变色

在你的牙齿上，附有一层有粘性的薄膜。用你的舌头可以感觉到。它附着在牙齿上，进入牙齿缝隙，并停留在那里。这层粘膜是牙齿的大敌。它会使牙齿变暗，并损坏它。

牙刷刷不掉它，因为普通牙膏无法溶解。所以，你两次洗牙间隔的几个月里，它可能还一直在不断地伤害你的牙齿。

变色的是粘膜层，而不是牙齿。粘膜层是牙垢形成的温床。它会粘住食物残渣，使其发酵，形成酸。它使酸不断接触牙齿，从而引起牙齿腐蚀。
