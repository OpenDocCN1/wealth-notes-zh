# 他们除去了氨的气味

研发了一种全新的松香味消毒剂配方
改变了美国家庭主妇清理房间的习惯

世代以来，美国的家庭主妇们都认为，如果没有家用氨水，家里就不能真正清理干净。老人 chēng 记得，以前家里做清洁，家用氨水和香皂一样，是必不可少的。

五十年代商业逐渐繁荣，许多新型多用家用清洁剂开始取代家用氨水出现在货架上，其中大多数价格都要高于家用氨水。为什么？

很明显，家用氨水有一种令人讨厌的特点：它有股强烈，刺鼻的气味，用起来很难闻。

这个问题威胁到了宾夕法尼亚州斯克兰顿两个退役军人的生计——艾尔文和伦纳德斯特尔。战后他们把所有积蓄都投资到了一家主要生产家用氨水的化工厂。

他们在想，"是否可以改变这种气味，用更好闻的气味取代它呢。"
