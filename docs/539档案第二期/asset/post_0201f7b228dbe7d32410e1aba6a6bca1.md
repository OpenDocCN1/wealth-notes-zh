
# 沉睡了数年——某些细菌又重新苏醒了——它在浴室找到了自己的天堂

来自：吉因·威尔伯恩
休斯敦纪事报、医疗新闻撰稿人

虽然现在许多引发疾病的细菌都被抗生素消灭了——但是，原来的某些细菌，在和我们的器官和腔相处数年后，又以新的摧毁力量重新出现了。

这些细菌——包括大肠杆菌，变形杆菌和气杆菌——之前一直帮助清除人体肠道的废物。

这些“肠道”细菌一直被某些疾病细菌（如链球菌和肺炎球菌）的分泌物所抑制。这些疾病细菌在抗生素的控制下，使得一些毒性肠道细菌有机会引发严重的系统性感染。因此，最近增加了一些因新出现的抗生素耐药细菌“葡萄球菌”引发的问题。

所有这些细菌，都会通过表面直接接触而感染——比如，当浴室地板，以及浴室用品上沉积这些细菌，人接触就会感染。事实上，浴室有可能成为疾病传播的关键区域。

这就是为什么说，浴室清洁剂一定要能杀死“葡萄球菌”，以及其他潜伏在浴室里，可能引发疾病的细菌。据相关实验室测试表明，肥皂，以及一般的松油洗涤剂，都无法杀死“葡萄球菌”——所谓的“消毒液”不是清洗剂的那种……也可能无法杀死它们接触到的所有病菌。

现在又一款家用产品，已经被证明是一种有效的杀菌剂。那就是来苏尔牌消毒剂，它能杀死它接触到的所有病菌——包括致命的肠道细菌，“葡萄球菌”，以及其他许多致命病菌。实验测试发现，它的杀菌威力能持续7天。

下面是每周浴室清洁的3个基本步骤：1、直接把来苏尔添加到常用洗涤液中。2、用添加了来苏尔的洗涤液擦地板、墙壁。3、在清洗浴垫和各种盖子时，先把它们在添加了来苏尔的洗涤剂中浸泡几分钟。注意：如果家里有人感染了病菌（“金黄色葡萄球菌”的直接来源），那么，病人每次使用过的浴缸、盆、碗、座位，都要用來苏尔进行消毒。

来苏尔的消毒效果能从这个周末清洁后，持续到下个周末清洁时，这是其他任何消毒液都无法做到的。对于那些喜欢飘满松木香的产品，我们还研发了松香型来苏尔消毒液。原味型和松香型，价格均为29美分。
