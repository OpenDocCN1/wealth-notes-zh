# 预制住宅：工业巨头有多庞大？

来自：詹姆斯·R·普莱斯
国家房产公司总裁

让我向你描述一个场景：从迷人的彩色房屋模型那里，顾客排成了一条长龙。他们慢慢地穿过这个明亮、时尚的房屋模型——这些人中，包含了各个年龄段，各个社会阶级的人。然后，很多人都向附近的一个凉棚走去，去签署购买这种房屋。在这里，这种房屋一天能卖一百个，甚至更多。

> 詹姆斯·r·普莱斯，被《时代》杂志称为“建筑业之王”，他认为，到1975年“美国至少一半的独栋住宅都会采用预制住宅。”

这个场景不同寻常，对吗？不，现在，在美国这种场景随处可见。只要国家房屋建造商展示房屋模型，就会有很多渴望拥有好房子的家庭过来看看，他们希望搬离拥挤的单元楼，住在视野开阔的地方。

这些美国人代表着一个巨大的市场。每 khoản都有超过一百万个家庭购置新房，而且人口还在不断增长。此外，高效的流水生产模式，用更快的速度，更低的成本，建造更好的房屋，使得我们能够不管扩大市场，让越来越多的人能够住上这种房子。

在我看来，未来十年到二十年间，美国一半的住房，将要在工厂进行生产和组装。这意味着预制住宅将慢慢发展成一个数十亿美元的产业。
