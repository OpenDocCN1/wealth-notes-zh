# 我为什么为蓝十字会无偿服务！

来自：乔治·A·纽伯里
制造&贸易信托公司总裁
蓝十字计划董事会会长 纽约布法罗

我必须承认，14 年前，当有人请我为布法罗蓝十字会服务时，我尚未真正意识到我的工作都包含什么。

当然，我知道我必须参加会议，协助制定政策。我以为就这些。我从来没有想到这个“业余”活动，会成为我生活中极其有趣，且非常重要的一部分。

从开始工作，我就发现，我身在一个工作严肃认真、努力勤葳的一个团队——他们分别代表着红十字的会员，雇主，医生以及医院工作人员。在遇到我所处行业，以及法律相关问题时，他们都会寻求我的建议，弥补自己的不足。在这里的每一个会议，每一次讨论，都会加深我对蓝十字成员的责任感，以及团队合作意识。

我对蓝十字的了解不断增加。例如，全国有超过 80 个蓝十字计划。全部依赖于像我这样的董事会成员和志愿者，帮助他们为 5100 万个成员尽可能提供最好的服务。

我也越来越意识到蓝十字会在他们社区的重要性。它是需要住院治疗的人，以及提供相关治疗服务的医院之间的重要纽带。它使得让美国人享受到比历史上其他民族更高水准的健康关怀成为可能。

如果你知道仅去年一年，美国蓝十字就为它的成员提供了超过十亿美元的医疗费用援助，你就知道此言不虚了。

有时，回顾蓝十字董事会会议的议程时，我会问自己：“为什么要我承担这个本不属于我的责任？”年复一年，答案逐渐变得清
