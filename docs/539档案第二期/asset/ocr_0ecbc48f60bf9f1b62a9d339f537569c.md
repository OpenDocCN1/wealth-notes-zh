# 在这张图中，你能找到多少会引发家庭危害的事？

![](bbox=[0.2, 0.21, 0.74, 0.49])

仔细观察上图，你会发现一些家中可能引发事故的潜在危险。

看到翻起来的地毯，地板上的溜冰鞋，楼梯上的书了吗？这些都可能让人摔倒——而摔倒是每年超过 13000 起致命家庭事故的诱因。

确保不要在楼梯上放任何障碍物，给孩子提供一个专门存放玩具的柜子——教育孩子玩完玩具后，要放在专门存放玩具的地方。地毯，当然要保持平整，确保不会绊倒或滑倒人。

壁炉上没有安装遮挡明火的玻璃？据估计，每天因为明火引发的家庭事故超过 1500 起。每个壁炉都应该安装玻璃——尤其是有刚会走路的宝宝的家庭。
