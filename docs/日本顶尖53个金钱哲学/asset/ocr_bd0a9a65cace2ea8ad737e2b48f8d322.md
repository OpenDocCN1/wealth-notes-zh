# 4
簡單的事物才能賺得更多財富

大富豪最希望凡事簡單。許多人的穿著或家居擺設偏好簡單設計，在生意上，他們也認爲「簡單最好」。我認識的大富豪中，在短期間建立財富的人都是從簡單的生意起家，例如專業化。不到處插一腳，只專注於一個領域而獲得成功的人相當多。

一位經營建材公司的社長，以前什麼建材都做，在激烈競爭下，公司營業額總不盡理想，他索性去無存菁專營鋁製建材一種。雖然產品範圍縮小，卻因此樹立新指標爲「舉凡一切鋁製品的公司」。除了鋁製建材的銷售和施工，業務更擴大到鋁製品的加工及回收等，還有鋁製鋼具及汽車輪胎鋼圈這些一般消費者取向的製品。結果大受好評，「說起鋁，就會想到這家公司」，訂單急速增加，公司也以驚人的速度成長。
