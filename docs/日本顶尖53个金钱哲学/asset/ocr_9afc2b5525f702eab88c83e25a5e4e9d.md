# 9

能否成為大富豪，就看敢不敢拿錢包裡的錢出來燒

我在第一章曾提到，大富豪說投資商品要看能不能「燒」，當時我以爲只是那位大富豪的想法特別，後來才發現其他的大富豪似乎也喜歡這麼說。看來，「燃燒」這個概念，應該是大富豪思維的共通點。

我再說一個有關燃燒的小故事，有一位大富豪這麼問我：「你敢不敢現在拿你錢包裡的鈔票出來燒？」我嚇了一跳，連忙說：「不，我不敢燒。」我記得當時大富豪略帶惡作劇似的表情笑著說：「所以你的公司才這麼小啊！」這個問題雖然很唐突，卻很有道理。

假設我們正開創事業，希望能夠大幅成長，這時如果只想守成，就無法再向前。有的時候，必須明知有不确定因素或風險，也能勇敢進攻的態度，這是事業成長所不可或缺的。
