# 重視速度，避免機會流失。

天都要去這家咖啡店報到。據說現在已經有一家分店進駐他的公司了。

光聽這樣，我們可能會以為「不過是有錢人的作派嘛」，其實不然。不管離得多近，為了喝一杯現煮的咖啡，包含交通的時間最少也要花十五分鐘。他衡量每天去光顧花費的時間和自己的時薪，冷靜判斷請他們開一家自己專用的分店，他可以将時間投注在事業上，會更有效率。

最近也開始有一些大企業注意到這一點。如果許多員工不惜花十分鐘去附近便利商店買咖啡或飲料，不如在公司裡供應簡單的飲料和點心。抽於浪費時間，就勸導員工戒菸，要求戒菸的最大目的雖然是為了員工的身體健康，卻也很有效地減少員工為了去抽菸而離開座位的時間。

成立類似事業的公司有很多，成功或失敗有著很殘酷的差別。別人要花三年完成的事，大富豪一個月就搞定，因為他們深知速度就是生財的泉源。
