# 2 看出第一名比第二名多出十倍的價值

大富豪都很在乎當第一名。
我有一位客戶買了全世界最快的汽車，據說最高時速可達四○○公里，雖是市售的房車，卻配備F1賽車等級的特殊技術，使得它比一般高級車的價格多了一位數，但是他說：「無論如何都想要這部車。」

坦白說，我其實不懂他為什麼對這部車如此執著，世界排名第二、第三的車，最高速度也不會差到哪去。當然價格也會很高，但是跟這台世界最快的車比起來，也算是還好而已。說到底，他也不可能一般在公路上開到四○○公里的速度，一樣的金額可以買十部最高時速達三○○公里的車了。

我忍不住問他理由，他這麼說：「誰會對世界排名第二的車有興趣？但是如果我開口邀請『要不要坐世界紀錄最快的車？』你不會想搭搭看嗎？第一名是有道理的啊！」
