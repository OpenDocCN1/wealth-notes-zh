# 4  速度可以創造財富

我的公司也接受不少各界人士前來諮詢有關大富豪取向的事業。曾經有某家醫院來找我諮詢「以富裕階層爲對象的醫療禮賓服務」。這家醫院的老闆本身就是個大富豪。所謂醫療禮賓服務就是依照患者的要求，爲其解決不安和疑問，協助接受正確的診療科別診治。

此項服務除了必須通曉醫院業務，還要有接待的專業知識，以滿足眼高手高的富裕階層。同時具備專門知識和接待技巧的人才並不多，依照過去的經驗，從一開始規畫課程，培養人才到不亞于高級飯店的程度，大概需要三年。

但是，這家醫院的老闆卻不想等那麼久，他說：「初期投資花多少都沒關係，我想一個月就搞定。三年等下來，豈不要產生機會損失。」雖然感覺很心急，不過他判斷眼前的成本多花一些，一個月就讓服務上路，這比損失三年可得的利益要划算得多。這正是大富豪們的共通點。他們做任何事都追求速度。
