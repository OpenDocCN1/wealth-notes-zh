# 13  **主動營造模式是成為大富豪的捷徑**

如果想要換新車或孩子要上大學，需要一筆錢，我們總是想：「能不能加薪呢？」但是這不可能馬上實現，因爲薪水是公司決定的。

上班族很難自己決定報酬，但也不是沒有。例如，被外商金融機構或是顧問公司挖角時，可以向對方要求「年薪六百萬再加上佣金六百萬，合計是一千兩百萬，可以的話，我就跳槽。」「如果不是這個金額就不接受邀約，能夠如此強勢交涉的人，就可以自己決定報酬。不過，這仍是很少見的例子，大部分都無法自己決定薪水。

我有一位客戶說：「若不主動營造模式，絕對當不了大富豪。」上班族的薪水是公司作主。自己經營公司才能隨著利潤決定報酬，這一季的利潤若是兩倍，報酬加倍也不難。但是公司利潤加倍時，又有幾個人的薪水可以跟著加倍呢？
