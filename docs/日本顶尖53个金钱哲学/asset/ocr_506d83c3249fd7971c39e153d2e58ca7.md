# 11
樂於花一千五百元喝一杯咖啡

我們平常買東西或到餐飲店消費時，不太會去注意商品的成本，但是每當大富豪在外面消費，就會試算各種商品的成本。從商品到消費者手上的過程都計算在內，直到完全理解它的價格才會付錢，這就是大富豪的作風。常有人揄揄「有錢人最小氣」，其實並不是這麼簡單，他們是不厭其煩地從各方面考慮成本，在付錢之前仔細評估。

聘請我們私人總管服務的客戶，也都很在意成本。有不少客戶看完估價單，思考片刻後便開口問：「你的收費這麼多，實際付給總管多少薪水？」我雖然回答：「真抱歉，這真是無可奉告。」但對方還是會說出具體的數字，「差不多是這收費的○成吧！」而且他說的數字還蠻準的，能馬上在腦中計算費用當中包含多少成本、公司的利潤，以及其他營運經費。接著又依據他所估算出來的數字跟我議價：「包含成本，超過○○○元的話，我直接雇總管還」
