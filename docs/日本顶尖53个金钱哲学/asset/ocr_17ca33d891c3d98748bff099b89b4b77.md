# 11

得到的錢總是比希望少

請在紙上寫下希望的年薪。你會寫多少金額呢？三百萬？三千萬？以前有一位大富豪曾經問我類似的問題：「你在紙上寫下想要金額，如果我要求你給我錢，你要多少？」當時我寫了「三千萬」。因為是大富豪問我，如果要我寫一百萬或兩百萬這種數字反禮，大富豪又問：「爲了得到到三千萬，你有什麼計畫呢？」包括我在內，對一般上班族來說，三千萬是個不得了的金額，一輩子賣命也賺不到這個錢，即使升到高層也很困難。

我稍做思考後這麼回答：「現在光靠我向客戶收取的報酬，要有三千萬是不可能的，不過如果我經營的公司繼續擴大，我也會考慮股票上市，這樣應該就不是那麼遙不可及了吧！」大富豪聽完說：「這麼看來，你有能力得到三千萬。」一樣是想賺大錢，有人會認真計畫，有人只是空想。如果要發起具體行動，就必須堅定地相信「我會賺大錢」。每個人聽到要寫下希望的年收人時，
