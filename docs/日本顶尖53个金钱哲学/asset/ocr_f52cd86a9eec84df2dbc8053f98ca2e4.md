# 1 喝一杯三十萬的紅酒可以賺十五億

大富豪經常舉辦宴會，招待生意上認識的朋友，分享自己珍藏的美酒。大富豪宴會上的酒皆是稀少見的名品，其中也有一瓶價數百萬，甚至上千萬的頂級紅酒。

閒聊之餘，大富豪會視適當時機拿出來，輕描淡寫地透露價錢，「這瓶紅酒，是大家也很熟的○○幫我以三百萬買到的。」或許有人覺得刻意說出酒價錢，不像是平時行事低調的大富豪應有的作風，其實他有他的目的。當客人聽到價錢，自然會望向自己手中的酒杯，暗自心裡計算，然後發現「這瓶酒倒了八杯，所以一杯要三十幾萬吧！」頓時感受到大富豪的慷慨。
