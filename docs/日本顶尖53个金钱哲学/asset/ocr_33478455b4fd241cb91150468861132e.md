# 後記

# 金錢是建立更好世界的手段

本書介紹的大富豪「金錢哲學」，是我在從事總管工作當中，客戶直接傳授的道理。每個事業或投資有成的大富豪，都有一套「金錢哲學」，無一例外。他們的哲學並不是把錢從右邊移到左邊就可以產生獲利那麼簡單，而是填堵禁欲修持一般的嚴謹態度。若能像大富豪一樣鑽研「金錢哲學」並堅持實踐，就算沒有特別的環境或天分，也能夠建立龐大的財富。

大富豪並不執著增加資產，他們很早就發現自己一個人有錢是無意義的，也很清楚那種爲錢失去理智，變成金錢奴隸的生活。嘴上是掛著「這邊賺錢」、「這邊虧錢」，周圍的人是不會聚集過來的，少了與人的聯繫，與金錢的緣分也就越來越遠，這就是大富豪的基本思維。

大富豪的「金錢哲學」就是藉著金錢與人結識，再藉著人脈建構更好的世界。他們的想法很單純，既不是特殊的思想，也不是宗教的信念。藉由經濟活
