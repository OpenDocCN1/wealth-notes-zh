# 4
最討厭讓人請客

吃飯這種事真是不可思議，不管吃什麼，只是被對方付了錢，哪怕是小說，都會萌生自卑感，覺得「被人家請客」。

大富豪也是一樣的想法。吃人嘴軟，如果被請託可能拒絕不了，這種事會沒完沒了，所以大富豪討厭讓人請客。不過他們倒是很喜歡請人吃飯，因為藉著請客可以讓各界人士記住自己，「萬一有什麼需要幫忙的，請多指教」。

一般以爲請客吃飯是直接關係生意商機，其實我們對請自己吃飯的人都會留下好印象。吃著同一道菜，聊聊出身或喜歡的口味，彼此交換訊息，距離一下子就拉近了。讓人請吃飯，心裡總會記著這個美好的回憶。

大富豪希望盡可能讓越多人對自己有 好印象，他們從經驗得知，越讓人有好印象，對自己的精神和財富都有好處。也有 人說：「給予別人，就是幫自己種下財富的種子。 」
