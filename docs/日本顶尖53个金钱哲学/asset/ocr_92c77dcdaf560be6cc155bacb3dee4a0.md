# 將期待換成感謝。

自己的資產也順利增加，對於一路陪伴、支持我的人，我是越來越感激。有一天，我突然覺得自己今後必須背负支持員工的使命。「在事業上軌道之前，當然要期待員工努力工作，當公司成長到一個程度，希望公司更上一層樓時，心中自然就萌生對員工的感謝了。

相信自己，讓爲公司付出的員工更加富裕，同時對別人的期待就越來越少。當事業繼續壯大，自己從有錢人變成大富豪，這時就不再期待他人了。」看著這些一直跟著自己努力的員工，我反而覺得必須對他們的期待做出回應，爲了保障他們的生活，我必須更努力。我告訴自己絕對不許失敗。」大富豪說。

自己經營的公司必須保障員工一家的生活，這個責任絕不輕鬆，大富豪肩上的責任和心理的負擔都是我們無法計量得知的。一個人的肩上擔負著上百人、上千人的生計，能不能撐住這巨大的壓力就是成爲大富豪的條件。
