# 2 所謂「人脈」

大富豪們的人脈其實並沒有很廣。在許多人聚集的宴會場合上拿到的名片，雖然都會看過一眼，但之後就隨手丟著，不會再拿起來看。大家以爲大富豪的人脈如天上繁星，其實他們平常來往的對象眞的很有限，至多也不過二十人左右。

這二十人的共通點很簡單，就是「自己可以提出無理要求的人」。他們只與符合這個條件的人深入交往。不過，雖說「可以提出無理要求」，但不是凡事都要迎合自己，而是對方提出的無理要求，自己也能配合的交情。

大富豪們基本上不怎麼講「人脈」這個字眼。我們會說「朋友」，外國人則說「家族」。即使是因工作結緣的人，他們也不稱生意夥伴，而是說「○○○是我們家族的。」他們重視的不是生意上的人際關係，而是朋友之間的交情。

能不能一起「喝荼聊天」，才是他們選擇交往的條件。
