# 12

最大的投資就是節儉

大富豪對刪減多餘支出的重視遠勝於增加金錢。

「資產要增加一成雖然極爲困難，但減少一成支出卻出奇地簡單。」不少大富豪都這麼想。

二○○八年發生金融海嘯，有位富豪一下子就痛失總財產的三分之一，你以爲他會爲了彌補損失，打算景氣恢復後一舉扳回的如意算盤積極投資？其實完全相反，他厲行節儉之道。因爲他在國內有好幾處房子，因此向我們這些私人總管徵詢意見：「一起幫我想想如何精減房子的維護管理費用。」可以節省比較多的是車輛管理費用，一年只開幾次的車，一星期至少要發動引擎一次，否則零件就容易劣化。過去車輛的發動都是委託外面的公司，現在爲了節省開銷就由我們私人總管代勞。
