# 12 坦承愛錢，就能聚集財富

「我想成爲有錢人！」能坦率說出這句話的人應該不多。有各種人爲了助大富豪的財力和經營之道，前來拜訪我的客戶。他們其實是自己想賺錢，卻不說出真心話，「這項事業將是貢獻社會，您願意投資嗎？」或是「您的事業可以更加擴大，可以出資嗎？」以這些理由來接近大富豪。

還有許多說想拜大富豪為師的，大家都說：「我想體驗社會。」「我想成爲像您這樣了不起的人，請收我爲徒。」

大富豪早就看透這些人的本心，委婉慎重的拒絕這些上門卻不說真心話的人，忍不住發牢騷：「爲什麼這些人不說他們就是想賺錢呢？坦承說出來，我也有相當的財力和經營之道，都可以教他們啊！」

只要坦白說出「想賺錢」，就可以得到大富豪的支持，偏偏大家都不敢說真心話，白白浪費了這個機會。我們都覺得老實說出「愛錢」是可恥不好的
