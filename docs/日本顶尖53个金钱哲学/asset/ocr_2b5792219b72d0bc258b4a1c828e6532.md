# 8

時時思考要買什麼

不管是對商品或服務，大富豪在購買時都經常思考著：我是付錢給誰？我付這筆錢能獲得什麼？例如，在便利商店買 bottled 烏龍茶，平均一杯頂多十元，若是在高級飯店的酒吧點一杯烏龍茶，可能要三、四百元。如果只用來止渴，這金額的差別也太大了。

但是，有大富豪卻認為：「飯店的烏龍茶，一杯五、六百元也不算貴，我買的可不是烏龍茶，在這裡喝茶可以眺望美麗的景色，還有心曠神怡的氣氛。」他付錢買的是在高級飯店放鬆休閒的時光，他很清楚自己投資的是什麼，才會不惜花好幾百元買一杯烏龍茶。

有一位經常在別墅開火鍋宴會的大富豪，他也是很清楚自己花錢買什麼的。這位富豪總是帶著公司的二十名員工，從東京千里迢迢到遠方的別墅，就為了開場火鍋宴，火鍋食材也不過一萬多元，但是租借遊覽車，以及為準備宴會雇
