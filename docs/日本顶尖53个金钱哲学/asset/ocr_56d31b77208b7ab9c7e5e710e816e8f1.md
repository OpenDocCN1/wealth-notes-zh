# 利用時間的需要。

大富豪們在商場上也積極地購買時間。有一位大企業的經營者併購公司就好像是在買日用品似的。「我們加入一個新市場，得花好長時間才能獲得一定的信用，若能花錢買下這些時間，沒有比這個更划算的吧。」併購公司就是把一家公司的信用完全買過來，也可看作是資方買下爲建立信用所需耗費的時間。

大富豪還貫徹「有人可代勞就找「人代勞」的方針，從製作文件到與客戶會面的事務都盡量委派，雇用優秀人才建立工作順暢進行的架構。

我自己一方面經營總管公司，也從事貼身總管的工作，一位客戶曾經勸我：「你不能親上現場，社長不專精於經營，事業就無法做大。」

有一位大富豪曾經這麼說：「若想建立財富，就要盡量買時間。上班族終其一生的薪水要花三十年去賺，但你也可能一年就賺到。想要一年賺到三千万，就必須將時間用在自已該做的事。」
