# 11
### 紀念幣的價值

與黃金和白金相同，紀念幣也是大富豪偏好的優良投資商品。每當有紀念幣發行，有位大富豪一次就收購數百枚，甚至上千枚。這位富豪碰到有銀行員來訪時，就問他：「這次的紀念幣是什麼？」「我以爲他純粹只是因爲有興趣蒐集，但他卻嚴正地告訴我：「這不是爲了興趣。紀念幣除了價值成本有保證以外，還有升值的空間，再沒有比這個更適合投資的了。」

紀念幣若升值，賣給錢幣商便能賺取利益，特別是發行時造成話題的金幣，或是限量發行的金幣等，升值機率都很高。

例如，一九九○年所發行，紀念日本天皇即位的三萬元金幣，現在的價值已超過四萬元。日本在一九九九年發行天皇在位十週年的三千元紀念金幣，其價值更翻升到三萬元左右，報酬足足有十倍之多。二○○二年日韓合辦世界盃足球賽的紀念金幣也升值了六、七倍。
