# 8  隨時清楚自己錢包裡有多少錢

大家知道自己錢包裡有多少錢嗎？
以前有一位大富豪突然問我這個問題，而我竟然答不出來。不能馬上回答的人應該和我一樣，平常要打開錢包看看，才知道有多少錢吧。然後發現手邊的現金變少了，再去銀行領錢，可能只有在領錢後才能夠正確說出錢包中的金額。

大富豪隨時都知道現在手邊有多少錢。他們平常大概隨身帶著十萬～十五萬左右，不只記得鈔票的金額，連多少零錢都清楚。
他們清楚的不只是錢包中的錢，從活期存款、定期存款的餘額，投資的股票或債券、基金的價格，到名下房產的時價，都要隨時確認。他們派人每天調查所有資產的價值，也就是每日結算。投資對象的數量和種類繁多，每天做報表想必相當吃重，大家或許認爲不用每天這樣詳細調查，但是有位大富豪說
