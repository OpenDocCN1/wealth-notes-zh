# 13

沒有經驗的投資要觀望三個月

我們都以爲大富豪只要覺得能賺錢，就會二話不說投入資金，但是有不少人投資前會花費很多時間做決定，尤其是第一次接觸投資商品或金額較大的投資，還有難以預測結果的投資，都一定會暫時持保留態度。特別是，他們保留觀望的期間都是三個月。

曾經有人向一位大富豪推薦期貨商品，他先觀望三個月之後才做決定。

「觀望期間，我心裡總是掛記著『期貨交易』這個字眼。閱讀書報也好，與人談話也好，都會特別留意期貨交易的資訊。」

大富豪的學習能力很強，三個月下來已經摸清了投資商品的特徵和風險，甚至了解專業門道，這期間他已經練就了評估投資對象價值的能⼒。

有些時候，投資必須當機立斷才能獲做大筆利潤，有時候卻是要從容蒐集資訊才能做出正確的判斷。
