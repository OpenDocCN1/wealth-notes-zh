# 3 刻意結識高一階層的人

聽說最近越來越多人拒絕公司主管下班後去喝一杯的邀約，說是「不自在」。如果是社長的邀請就更不想去，想盡辦法拒絕，這應該是一般人的感覺吧。一般都是普通職員找普通職員，主管找主管，大家都喜歡找與自己共通點多、地位相當的人一起行動，既聊得來，又能放心發揮牢騷。

但是，大富豪們都說自己在成為大富豪之前，都曾積極設法與比自己高一階層的人來往。普通職員找課長或經理、課長找經理或董事，這就是所謂的高一階層，聚餐喝酒時也積極邀請這樣的對象一起去。大富豪們的眼光總是朝「上」，於公於私都不忘向上之心。從年輕時期就與高一等的人交流，激勵自己積極追求同樣的地位。
