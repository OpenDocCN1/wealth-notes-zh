# 如果成為大富豪有祕訣，應該就是培養不放過好運的眼力，平時做好充分準備，還有覺悟。

每次聽他們這麼說，都覺得這些大富豪對「抓住好運的方法」，遠比財富本身要來得有興趣。事實上，大富豪們都很愛賭自己的運氣。

我有位客戶以前是東京大學工學院，據說花了八年才畢業。「那時候我不是在打工，就是在旅行，總之都在玩，滿心以爲東大畢業生到哪都搶手，實在是太天真了。等到我開始找工作，才知道人家最怕我這種打著東大的旗號，其實只會吃喝玩樂還畢不了業的，別說大公司了，我到哪裡都碰壁。這時一家小型軟體公司的社長找上我，我想『只要有工作』，就趕緊答應了。」

也就是說，正愁找不到工作的學生，剛好碰上好心的社長買口飯吃。當時這家公司的職員大約有十人，主要是開發控制印表機的特殊軟體，在這個領域有很高的占有率。他在公司擔任軟體開發，到了第三年出現轉機，社長說自己年事已高打算退休，他沒有繼承人，要從職員當中選一個人來擔任下一任社長。
