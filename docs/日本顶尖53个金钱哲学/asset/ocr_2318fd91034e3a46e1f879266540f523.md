# 5 最喜歡「買時間」

大富豪們最想用龐大資產換取的就是時間。所有的大富豪都希望花錢把時間買下來。例如我們提供的私人總管服務，為大富豪身邊的事務或業務提供協助，他們就是想從日常的雜事中解脫，爲自己爭取時間。

針對富裕階層的「節約時間服務」有很多種，高級飯店中設有「俱樂部樓層」、「商務樓層」等，就是爲了隔離一般客房所準備的特殊樓層。有專屬的櫃檯，在尖峰時間也能順利進行入住手續，這就是一種節省時間的服務。更有標榜不需辦理入住手續的高級飯店，會事先將房門鑰匙寄給優良顧客。最近還可以傳送到智慧手機的電子鑰匙，無須辦理手續就可入住的飯店，其數量也在增加當中。
