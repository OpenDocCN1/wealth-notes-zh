## 序 大富豪最初也只是个普通人

我在二〇〇八年创办了私人管家服务公司，专门为“大富豪”提供私人管家服务，从日常生活到公司业务都由我们提供协助，满足客户的各种要求。我的客户大多身价超过十五亿，年收一亿元以上的顶尖人士，其中不乏拥有数兆资产，或者世界富豪榜上有名的国外大富豪。

我创业八年来已服务过上百位富豪，也有幸结识数位百位富豪。在此之前，我完全不知道世上有那么多有钱人，而且他们多数不是继承家业或资产，而是白手起家致富。有的人自己创业成功，有人投资成功，也有人接收别人公司成功，他们各有致富之道，成为富豪的方法令我啧啧称奇。但是，他们有一个共通点——都是很普通的人。

# 老是迟到而被炒鱿鱼的大富豪

上班经常迟到的人可说是公司的冗员，但是竟然有早上总是起不来，上班刻板印象来问我：“拥有数十亿、数百亿资产的人，都是像上流阶层那种特集合团的吧？”“他们都有特殊才能，躺着就有钱赚吧！”“拥有大笔资产，钱就像滚雪球一样越来越多，真令人羡慕。”在认识各方大富豪之前，我也曾有过类似的误解，后来发现这种印象和实际情形有很大差距。白手起家的富豪几乎都是出身自普通的家庭，也没听说过小时候受过什么特别的教育。学生时代过着很普通生活，多数都经历过找工作或当上班族，也有人在短短几年内累积财富，却感叹“十五年前日子可苦了”，也有在一般公司待不下去的异类，才成为大富豪的。

如果我们能找出他们的共通点，应该就成为大富豪的捷径了。接下来我就介绍几个实例。

迟到，最后却成为大富豪的例子。

大富豪们多半是日出而作且精力充沛的晨型人，我要介绍的这位客户却是少见的夜猫子。他的口头禅就是“早上起不来啊！”因为他爱喝酒，长年熬夜，越晚精神越好的夜猫子大富豪。

他现在已经年过六十，虽然不再畅饮到宿醉，但年轻时喝过一家又一家可说是家常便饭，跟酒有关的糗事和英勇事迹更是不尽其数。不过，他的嗜酒贪杯竟也是晋身为大富豪的契机。

这位客户来自东北，从技职专科学校毕业后就来到东京，在一家专营大楼设备维修的公司上班，过着极为普通的上班族生活。这段时期他每天晚上都去喝酒，喝到天亮，早上常常因为宿醉而起不来。身为职员却经常中午才上班，一年下来，上司终于受不了，要他不必来了。他说：“公司无预警地就炒我鱿鱼，一时之间也找不到工作，当时真是穷途末路。我只会做大楼设备维修，一年下来大致掌握了工作内容，想想干脆自己开公司。当时才二十出头，天不怕地不怕，没想到还真是走对了呢！”

这位客户现在倒能像事不关己似地笑说这段往事。不过，这个在失业又走投无路的状况下所做出的决断，正是迈向大富豪的第一步，人生真是难以预料。

一开始他就像一般个人公司那样，拜托熟人帮忙介绍大楼设备的定期检修。创业的时候几乎没有资金，却有一样不同于金钱的巨大财产，那就是每天晚上出去喝酒时所结识的人脉。同业间的人脉就不用说了，加上交游广阔，大家想到“他失业有困难”，都纷纷帮他介绍工作。

此外，他决定创业的时机也是恰到好处，当时日本正处于高度经济成长期的最高峰，一窝蜂地建设高楼大厦。不久后，生意接踵而来，他一个人几乎忙不过来，后来雇用几名工程师，自己更努力接洽生意，业绩便蒸蒸日上。

“我们不是厂商系统，而是独立公司，所以一开始很辛苦，不过也因为这样磨练出技术来。我们甚至可以自己做出维修需要的零件，遇到大问题，都必须自己去解决，创业以来，我已经有了十年都没能去两天以上的旅行了。”

公司成立四十余年，已有上千名员工，分公司、分店遍布全国。他现在仍

然每晚出去饮酒作乐，尤其喜欢和员工们喝酒，每到傍晚下班时间，就看他在办公室找人去喝一杯。他的个性随和，员工们也都乐意参与。

爱喝酒，早上没精神，作为上班族，他的确是失败的，但是个性随和、人面广，我倒觉得他充分具备了成为大富豪的资质。

# 把大学的注册费和学费都投入创业资金的大富豪

白手起家的大富豪几乎都是勤奋努力型的人，其中不少人笃信“脚踏实地”，不过学校的课业又是另一回事。有许多大富豪在学生时期不爱念书。我有一个客户就是这样，二十几岁创业开广告公司，现在已是身价达数十亿的大富豪。

这位客户出身自北陆，高中一毕业就希望到东京发展，无奈家人不许他毫无计划就贸然前往，于是他便报考东京的大学，也如愿考上。只是他原本就不爱念书，拿着父母给的注册费和学费来到东京，竟然没有去学校注册，找到房

子安顿下来，靠着父母寄来的生活费每年的学费，开心地过起都市生活。

不过，也不能一直游手好闲，他开始在本就有兴趣的广告业打工。〔一开始尽是些夹报或在电线杆张贴广告的工作，后来在这行人面广了，便私下接案子做。渐渐有一些活动策划之类的大案子，一个人都快忙不过来了，才想说说应该可以开个公司。〕

有想法马上就付诸行动也是大富豪们的共通点。开始接到大案子后，他便雇佣几名职员，成立了一家小广告公司，创业资金就是父母寄来的大学注册费和四年学费。〔我当然对父母保密，他们到现在还相信我乖乖上大学，然后毕业了呢。所以我对家里谎报学历。〕看似玩笑话，但经过三十年，这仍是一个把所有亲戚都蒙在鼓里的秘密。

让他的公司壮大的秘诀就是他有人之明，例如把上门推销商品的推销员挖角来自己公司的事，就发生好几次。而且他的大哥性格强烈，很会照顾人，因此深得人心，也懂得将自己不擅长的工作大方地交给下属，态度诚恳，让员工很自然地愿意接下重担。

虽说他的创业资金是欺骗家人所得，但现在已是个拥有两百多名员工的老板，还在东京的高级住宅区田园调布购置豪宅，这样的成功也算是回报父母的孝行吧。当年的注册费和学费衍生出来的财富已不下数千倍，不禁让人想象如果当时他去上大学的话……

事业或赚钱与在学校的学习实是两回事，从这些大富豪的经历来看就能清楚明白。我听过一位个人资产额排在全球前十名的外国客户聊起他在学生时代几乎不念书，还拿父母给的学费去投资。他靠着投资顺利增加资产后，为了得到某家公司便想办法找上那里的员工，收购他们手上的股票。“对他们来说，公司的股票不如现金来得有魅力，想到可以小赚一笔，马上就卖给我了，也多亏了当年国家经济体制有重大改变。”这些持股竟然超过五○%，他成了公司的老板，接着更再接再厉增加财富，晋身为世界顶尖的大富豪。

成为大富豪的人，只要手上有一笔钱，即便是注册费或学费，在他们眼中可能都是可以用来挑战的资金。这是所谓“金钱就是用来投资”的哲学，他们平时就在脑中思考具体的计划，只要有钱就可以马上投入。

# 从阿宅玩家变成身价五百亿的大富豪

大富豪们的另一个共通点是，他们都很重视人际关系，在言行举止上谨慎小心，不得罪人，亲切随和，受位高者赏识，也令下属仰慕。如此看来，人面广、交情深似乎正是大富豪们致富的关键。有前瞻性的生意点子或是踏实的投资案，的确可以藉着人脉发展。不过，还是有不擅长与人交往却建立了巨富的例子。

我这位客户在大学时期曾经一度窝在公寓里，足不出户，他迷上有名的家用电视游乐器游戏，不去上学，每天窝在房间里不分昼夜地打游戏，原本在学校就没有什么好朋友，也没人会觉得他从未在校园里出现过。

但是，父母对他毕业了也不找工作颇有微词，不再寄生活费，他才发现自己的处境，不能只顾着打游戏了，必须振作起来。“当时刚好有几家专线线上交易的证券公司，在偶然的情况下我注意到网络上的股票投资。我手边的钱就是压岁钱或打工存下来的，大概有十五万左右，我拿这些钱当作筹码，挑战

网络交易。”

只要在网络证券公司开户，就可以在家进行股票买卖交易，这对不擅与人交往又讨厌外出的人是最适合不过的了。当客户必须在股票市场交易时间内一直坐在电脑前面看行情，若连国外市场都观察更加不分昼夜了，这对本来就沉迷打游戏的客户来说，并没有造成太大困扰。

不过投资和打游戏不同，他是完全外行，十五万的资金一转眼少了一半，他才急急忙忙地认真学习投资，就像沉迷游戏一般，他开始热衷于投资。他开始投资股票时机刚好搭上一九九九三年以来的科技股泡沫浪潮。急速成长的科技企业股票可赚取庞大的利润，他拿十五万积蓄投资，不到一年资产就迅速增加到一亿。

后来他运用这笔资金，让资产增加到三亿，却在二〇〇一年毅然决然地退出股票交易。“我的体力已经到了极限……那两年我埋头研究投资标的，睡眠时间搞不好比沉迷游戏时还少。”这位客户退出股票投资后没多久就发生科技泡沫，进入不景气时代，而他收山的时机也真是刚好。

他怎么花这些钱？不外乎是一人旅行，或回老家看看朋友。他既没有车，阔气的吃喝玩乐也不是他的作派，因为不爱出门，衣服或日常用品几乎都是网络上解决。后来有一次遇到一个许久不见的朋友，对方问：“既然你那么会投资，我出钱，你来帮我理财。”因此他又再重启股票买卖。这次刚好碰上日本景气回升，一直到二○○八年金融海啸发生的五年期，他的资产激增到五百亿。

我们公司一开始为他提供的服务是介绍女佣，当时他才三十出头。之后每次新年他都会独自出国旅行，我们便派一名同行管家为他服务，并且充当翻译。

现在三十多岁的他，穿着打扮相当朴实，生活也很简单，我想应该没有人一眼就看出他是个身价上千亿的大富豪。

这位客户是因为父母不再寄钱给他，才想到“接下来该怎么养活自己”。

如果当时他急病乱投医，随便找个兼职，或许就一直是给工族了。这一切

是因为他并非存着一夕致富的野心，而是利用小额利润的再投资，脚踏实地努

力，慢慢累积资产。我想这就像是打游戏一样，他只是单纯地从投资的胜利中获得乐趣，对一件事的完全投入，为他带来了巨额的财富。

即便不擅与人交往，也不喜欢抛头露面，也还是有致富的机会，他就是最好的例子。

# 东大毕学却找不到工作，后来竟接手公司成为大富豪

有时候我会问比较熟的客户：“为什么能拥有这么多财产？”多数富豪都回答我：“是运气好。”我想起那位年纪轻轻就买股票致富的客户，他开始投资的时候、中途一度暂停，后来又再次进场交易，事后回想起来，真的算“运气好”。

但是，说自己成功的秘诀是“运气”的大富豪们，随后又必定异口同声地补充：“每个人都会遇到好运和机会，许多人都没看出来，或是运气来了也因为没做好准备而错过。任何选择都一定有风险，觉悟和决心也是必备的。

我有位客户以前是东京大学工学院，据说花了八年才毕业。“那时候我不是在打工，就是在旅行，总之都在玩，满心以为东大毕业生到哪都抢手，实在是太天真了。等到我开始找工作，才知道人家最怕我这种打着东大的旗号，其实只会吃喝玩乐还毕不了业的，别说大公司了，我到哪里都碰壁。这时一家小型软件公司的社长找上我，我想“只要有工作”，就赶紧答应了。”

也就是说，正愁找不到工作的学生，刚好碰上好心的社长给口饭吃。当时这家公司的职员大约有十人，主要是开发控制印表机的特殊软件，在这个领域有很高的占有率。他在公司担任软件开发，到了第三年出现转机，社长说自己年事已高打算退休，他没有继承人，要从职员当中选一个人来担任下一任社长。

社长属意的人选就是我这位富豪客户，他是当时公司里年纪最轻，突然接到指示：“小子，你来继承公司吧！”社长的想法是：“交棒给最年轻的人，应该会认真考虑公司的未来。”其他的同事都是和社长同世代，或者资深职员，似乎也都被接受社长的选择，没有一个人提出异议。

当时公司还有负债，这也是资深职员没人反对一大要因。小公司是社长自己做保证，下一任的社长必须连同负债一起继承。“前辈们可能看我接了个烫手山芋，我才二十几岁，担一点风险没什么，只要好好经营就好，没有想太多。”
