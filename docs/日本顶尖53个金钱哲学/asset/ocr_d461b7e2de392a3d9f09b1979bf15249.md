# 14  比錢還重要的事

大富豪善於控管金錢，也擅長保護資產，知道營造產生金錢的模式是致富的捷徑，也努力實踐。
在一般大眾的眼裡，大富豪們的生活似乎是以錢為中心，有人甚至直接批評：「你們看錢比什麼都重要吧！」但是大富豪說，還有比錢更重要的事。與一般人一樣，家人是大富豪最重視的對象。大富豪希望子孫繼承自己的財產，過著不必擔心中金錢的生活，努力賺錢不是為了自己的欲望，而是疼愛家人。

這樣的心意也體現在聘用員工方面。有人甚至公開承諾，即使公司虧錢也絕不解聘員工，他們存下了足夠的預備金，已經做好萬全的準備。我有一位客戶經營機械維修公司，即使虧損到了非裁員不可的地步，他也不考慮解聘員工，「景氣會慢慢變好的吧！拿出公司的預備金來應急，總會有辦法。」他的態度就是維持雇用比什麼都重要。
