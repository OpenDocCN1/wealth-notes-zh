# # 1 不景氣就感到開心

一般來說，越是不景氣，大家越勒緊荷包，因為接下來的日子收入不會增加，股票和房地產價格下跌，資產也會減少，許多人會希望「至少節省一點」。

大富豪卻歡迎不景氣，景氣下跌的時候，他們才痛快地花錢。

不過，大富豪遇上不景氣也逃不過資產蒸發的下場，而且因為原本擁有的資產龐大，減少的金額位數也不容小覷。儘管如此，不景氣時，許多大富豪不但不節省，反而盡情地花大錢買東西或奢侈的休閒活動。「現在買、現在玩正是時候啊！不景氣時，東西或服務的價格才下跌，這是便宜買好貨的大好機會啊！」
