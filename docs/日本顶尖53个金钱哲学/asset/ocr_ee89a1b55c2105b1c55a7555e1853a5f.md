# 6
交遊廣闊就能產生財富

大富豪每天都要見很許多人，照訂製名片的頻率來看，一個月要見的不下一百人。如果從事業務或接待訪客的工作或許也要見這麼多入，但是大富豪除了工作以外，一個月還要見一百人。
他們通常有公司的名片和私人的名片。私人名片上沒有印公司名或頭銜，只有姓名和電郵、電話號碼等最基本的聯絡方式。我們總負責管理的就是這種名片，每個月大概有一百張要整理。單純計算，一天有三人，一年就有一千兩百人，以私人領域來說，人數算是相當可觀。想到要跟這麼多入會面，光是約時間豈不是大費周章？其實也不盡然。
由信任的朋友引見、受邀參加宴會等許多人聚集的場合，這些都不必事先約時間，也可能偶爾去朋友家，剛好有其他訪客，聊得很開心，便順道邀請對方「下次來我家坐坐」。
