# 9 重視小信賴，勝過大權威

大富豪不會因招牌的大小而左右對事物的判斷。例如，一般人要存大筆金額時，多半都會選擇大型銀行，或所謂的巨型銀行，但大富豪們卻比較常找私人銀行或地方銀行、信用金庫等。

一般人之所以選大型銀行，是因爲感覺大型銀行比較有信用。但是，大富豪選擇銀行的標準並不是看公司的規模，而是自己已被看重的程度。即使擁有一千五百億的資產，在大型銀行頂多被當成部分上市公司，但是一千五百億若拿到信用金庫，連同企業都會被當成貴賓禮遇。

這對一般人也是一樣，辛苦把錢一點一滴存進大型銀行，就算存了三百萬、六百萬，銀行的贈品頂多是從小包面紙變成盒裝面紙。當我們要辦理房貸或創業貸款時，以爲會比其他存戶得到更好的利率，其實並沒有。若是在小銀行存五百萬就可算是大戶了。此外，銀行對長期的存戶也有較高的信賴。
