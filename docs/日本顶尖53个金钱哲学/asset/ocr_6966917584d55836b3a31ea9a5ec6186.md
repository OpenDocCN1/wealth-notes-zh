# 2 投資的成功率只要一成就夠了

我們投資金融商品就是希望多少賺點錢，最好每次都無往不利，但是一位大富豪卻說：「投資成功的次數有一成就夠了。」

這位大富豪主要是投資股票，我問他：「您都買些什麼樣的股票？」他說的那些都不是會大幅升值的股票，幾乎都是穩定維持現狀的股票，其中一些股價還偶有下跌。

這位大富豪的投資十次有九次賠錢，他還是輕描淡寫地說：「如果抱著绝对不能輸的念頭，價格開始跌也遲遲不願賣出，反而會大虧。打定主意『贏一成就好，九成輸掉也沒關係』，這樣才能冷靜判斷。"

一般人手上的股票下跌，都會等回升到買進的價格之後再賣出，我們常常聽到許多投資人錯過賣出的時機，最後不得不以比買進時低很多的價格脫手。

這位大富豪投資股票的時候，價格如果跌了一成就毅然的決然賣出。
