# 5 絕不借錢給別人

大富豪們絕不借錢給別人，但也不會把來借錢的人趕出去，因爲他們不願與人爲敵。那麼，要怎麼辦呢？他們不借錢，而是給錢。例如，有人來找大富豪：「我想成立新事業，但是手邊沒有資金，可以借我三百萬嗎？」大富豪拿出三百萬，也不過問事業內容之類的細節，只說：「這個拿去當本錢，你有錢再還我就好了，我不會催你。」嚴格來講，應該是「無期限貸款」，也沒有借據，很可能也要不回來。

怎麼會做這麼荒唐的事呢？我曾經問過大富豪，他的回答讓我很意外。「我借他錢，萬一真的還不出來就會想逃跑吧，如果我說『有錢再還』，他就不會逃走，所以總有一天能要回來。」想想他說得有道理。若要對方在「一定期限內還錢」，還不出來就想逃走，但如果是「有錢再還」，就沒有逃的必要性。而且，沒有要求任何擔保又無限期地借錢，對方會對大富豪滿懷感謝，決
