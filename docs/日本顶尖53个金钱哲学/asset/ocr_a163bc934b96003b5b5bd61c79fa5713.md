# 花錢比賺錢還難

大富豪們常說「賺錢容易，花錢難」。讀者們或許認爲那是他們錢太多、花不完的感觉吧！

「花錢很難」這句話的意思是「浪費很簡單，活用金錢卻很難」。我們還可以用另一個角度來解讀：大富豪懂得靈活運用金錢，所以才當得上大富豪，過大富豪的生活。

例如本章一開始介紹過，大富豪會購買一杯要價三十萬的昂貴紅酒。如果他什麼都要最高級，這瓶酒也是他自己要喝，或許就可說是浪費奢侈。但是，大富豪將這一杯三十萬的好酒在宴會時拿出來與賓客分享，讓大家留下深刻印象，如此一來就建立了人脈。如果眞的做成大生意，或是因此認識更多大人物，這一杯三十萬的紅酒對大富豪來說就一點也不貴了。這就是大富豪活用金
