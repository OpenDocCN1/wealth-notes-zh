# 3
# 只以自己建立的模式賺錢

不少人投資股票時，會關注社會大眾爭相討論的企業，或參考專家分析。但是，大富豪的著眼處卻稍有不同，選擇投資對象時，不會依賴別人的判斷，而是重視與自身的關聯。

有位經營餐飲連鎖的大富豪投資某成衣廠商的股票，因爲對象是業界的績優廠商，算是很受歡迎的投資標的，但是其實有別的理由。「我們公司使用的制服和帽子都是在這家公司訂製。當我正考慮增加交易量時，又聽另一位經營連鎖店的社長也想找他們，覺得他們很有成長的空間。」

還有一家汽車零件廠的社長，幾年前開始就從事期貨白金的投資，最初的契機是他自己開發的事業。這位社長看準汽車產業將會加強廢氣排放的規定，公司很早就準備好跟進。「包含我們在內，如果整個社會都朝著這個方向進展，用作淨化觸媒的白金需求量一定會增加，我就開始投資白金。」
