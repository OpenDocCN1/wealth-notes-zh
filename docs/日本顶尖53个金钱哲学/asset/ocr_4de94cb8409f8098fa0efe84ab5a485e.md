# 5 娛樂也是一種投資

大富豪的娛樂多半是高爾夫球或遊艇，關鍵是這些玩樂之後常接著有生意往來。娛樂也是投資的一環。高爾夫球是幾個人在在一起輪流打，如果幾個小時相處下來氣氛融洽，也會聊到生意上的合作。

此外，遊艇也是大富豪獨樂樂不如衆樂樂的一項活動，他們多半都會邀請朋友一起。在船上悠閒地談天說地，是培養交情的最佳機會。

話說回來，大富豪並不是為了建立人脈或是談生意才出去玩。玩樂的時候就很單純地享受。不過，以他們的經驗，早就知道這些娛樂對生意很有幫助。

也有人藉著獨特的娛樂或嗜好來聯絡感情。
