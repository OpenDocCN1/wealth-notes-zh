# 7 生意夥伴多是不交換名片的

大富豪私底下一個月就要發出一百張名片，爲了結識衆多朋友，再從中找到與自己合得來，不過這實在不是有效率的方法。或者說，大富豪重視的是不必交換名片的人際關係。

我們從事總管工作最困擾的是雇主吩咐：「幫我聯絡一下○○先生。」當我詢問：「有名片嗎？」他竟然一副理所當然地回答：「沒有。」我正愁不知該如何聯絡，雇主拿出自己的手機：「我這裡有手機號碼。」我趕緊記下號碼，幫雇主聯絡，這樣的情形經常發生。

大富豪們之所以不愛用名片，是因爲他們重視與好友的日常交流，遠勝於公事上的應酬。一般人也有類似情形，「我們常常一起去釣魚，從來沒有拿過名片。」「志趣相投的同伴本來就不必交換名片。」
