# 07 | 暴力：内战何以发生以及如何难以和平解决？

我们前面讲过，按照韦伯的说法，国家是一个合法使用暴力的机构。但有一种情形出现时，国家就无法垄断暴力了，那就是国家处于内战状态。

# 为什么内战会发生？

中国历史的大趋势，是“合久必分，分久必合”。这里的“分”，不只是指国家分裂，而且还往往是国家处于内战状态。即像东汉末、西晋末、五代十国，以及明中后期等时期的混乱状态。

其他国家的内战也不少，比如17世纪的英国内战，19世纪美国南北战争，20世纪30年代的西班牙内战等等。

无疑，内战对付各都意味着巨大的痛苦。组织战争需要付出巨大的代价，战争也意味着大量的生命、财产伤亡。然而，为什么内战总是人类社会的噩梦？甚至是到今天，还有人死于国家以暴力手段的厮杀。

关于内战为什么会发生，国际学术界已经贡献了很多重要的理论，主要有包括社会结构论、认同论、资源争夺、权力争夺、失误假设、动态等。

但是这些理论是什么，我们大致都支持这样一个基本观点，即 人类社会中存在着反叛的巨大动力，而反叛 国家能力的加强，却极大削弱了反叛力量。

比如，中国古代的农民战争，不少就是“民不聊生”。像唐末黄巢起义，宋末方腊起义，明末李自成起义，都是因为政府无力控制社会秩序，民众起义反抗。

又如近代，20世纪40年代，在非洲国家尼日利亚的石油生产，在伊朗的石油生产，以及中东国家的石油生产，都出现过类似的情况。中央政府，无力控制国家石油开采，内战爆发。

你看，这两个例子看似具体情形不同，但大体都是相似的。 从理论上去说，包括仇恨和国家能力，是导致内战的两个重要因素。

# C-H模型：理解内战爆发的原因

看到这里，你可能会产生一个很奇怪的问题：既然内战的逻辑是相似的，那么，为什么有的国家容易爆发内战呢？这个问题一直困扰了世界很多的发展。

2001年，他们的研究 保罗·科利尔（Paul Collier）和 安凯·霍夫勒（Anke Hoeffler），对国内战争进行了研究。

2001年，他们的研究，被称为科利尔-霍夫勒模型，简称C-H模型， 发现了影响内战的5个关键因素。我这里为你简单介绍一下他们的发现：

+   1. **第一个因素是反叛武装对资源掠夺的容易度。**
   特别是，当一个国家有很多廉价的油田、金矿、钻石矿时，反叛武装就容易获得财富。

比如，中非有个国家叫塞拉利昂，它有丰富的钻石资源，一个小地方就能控制国内的采矿权。电影《血钻》，就是以塞拉利昂的钻石开采为背景的。

+   2. **第二个因素是反叛的启动机会成本的高低。**
