# # 08｜城邦：以民主控制权力的首次尝试为何没有成功？

我们第一课就谈到了国家。国家是政治起点，是执政的来源。有了国家之后不，我们的第二模块就是要看看，有了国家之后，权力一旦产生，就产生了权力是否会伤害百姓的担忧，于是如何控制权力，就成了人类政治进化的第二个根本动力。

为了控制权力，人类从古到今产生了很多政治发明。有些政治发明是成功的，成就了我们今天的整个控制权力的方法。我们的第二模块就是讨论这个话题，包括雅典、共和、立宪、议会、民主与创新等六个主题。

# 雅典的民主如何进行？

既然说权力要控制，那么社会究竟该控制权力到底呢？你很可能首先想到民主的方法。这一讲，我就带你进入古代城市的政治实验，就是古代社会用民主方法控制权力的首次尝试。

民主并非19世纪以来的新事物，而是一项古老的政体安排。它的专利权属于古希腊的希腊城邦。公元前5世纪到公元前4世纪，是雅典民主的鼎盛时代。

但问题是，在伯罗奔尼撒战争中，雅典城邦失败了。在后山，大师的改进进入了历史的舞台，那么，人类以民主的方法控制权力的首次尝试为何没有成功呢？

你可以试着先，我们顺着解下去，主要原原因是，在古代交通、通讯条件下，民主体系搞到了可上规模下，古代民主体系只能统治较小的国家。而雅典就搞一个大帝国模式失败的。

但问题是，早在遭遇亚历山大的军队之前，雅典城邦的行政权力也失灵了。因为形成了一种奇异的反动效果，特别是，柏拉图和亚里士多德这些哲学家们，普遍反对民主。这又是什么问题呢？

了解雅典民主的具体知识，并不是我们的主要目的。如果你对希腊学知识，还可以听听《苏格拉底、西方文明的源头》，我们看关注的是，古希腊民主制度的问题，仍然是今天人类讨论民主问题时绕不开的话题。柏拉图对古希腊民主的批评，仍然是今天很多思想家对民主制度的批评。

为了理解这一点，我们还需要简单回顾下来雅典民主的基本情况。**雅典民主有三项基本原则。**

+   - 一是大众政治的原则。成年男性公民平等地参与政治，他们有两个办法来体现公民权：一个是统治，一个是选举，而且通常还是选举办法。这就可以，谁也无法单独控制权力。
- 二是公民政治的原则。雅典公民通过6000人大会和民众法官机构来公共处理公共事务，同样可以防止个人控制权力。
- 三是多数决定的原则。雅典公民既大会投票制，无论是投票、陪审法庭还是公共会议都采取多数决。这就保证了权力掌握在多数人的手中。
