# 26 增长：为什么有的威权主义政体创造经济奇迹？

我们上一讲的主题是“蒙格托陷阱”。对于一个发展中国家来说，会完全不重视政体的权力。如果仅凭着基本面的经济转型去赌，就会让国家陷入贫穷与停滞的陷阱。这一观点，不光有蒙格托这样的案例，还有相当相关的理论研究。

美国经济学家道格拉斯·诺斯在1998年出版了一本关于制度与经济学的书，他问了这样一个问题：为什么是英国而不只是法或先发生了工业革命？

他发现，工业革命发生的前提，是产权受到了有效的保护。只有保护产权，产权才能启动动力。而只有保护产权受到有效保护，产权才能启动动力。而只有产权受到有效保护，产权才能启动动力。而产权又分1815到1688年两次形成的新政体权受到法约束的体制，也是经济成长的关键。

按照诺斯主义的说法，如果政治权力不受制约，一个国家就会陷入“蒙格托陷阱”，经济发展就不大可能了。这主要是来自西欧的经验。

# 威权主义的经济奇迹

但问题是，发展中国家很少在早期，就如同英国一样，发展出一套稳定的产权法律制度。我们前面还提到，蒙格托在其权派垄断独裁的政治传统。但并不是每个国家都有封地主义传统的，因此，我们考量各国发展上，还要考虑到各国国情的多样性问题。

如果一开始发展中国家起初并没有建立起一套完整的产权法治制度，事实表明，这些国家发展威权主义政体，大致是政体力量集中在一个人或小圈人士手中，这些国家难道就不发展了吗？

从各国经验来看，实际的情形非常复杂。一个有趣的表象是，有的威权主义政体不仅没有陷入“蒙格托陷阱”，反而实现了高经济的增长，甚至可称为“威权”的经济奇迹。

那么，你想得到哪些案例？比如，俄罗斯时期的西德表现就是一例。到1870年皮埃中期为止，他比20世纪欧洲在世界上繁荣的政体权。而在很多历史中，政治上是常常被说成，而经济却因在他的政治时期，却获得了长足的进步。

我们可以举个例子。比如一些西班牙在后期支持共和政与反独裁者的政治势力者，30多年以后回归西班牙时，竟然大杀一国。而为他离开的西班牙，已经实现了相当程度的工业化，俨然是一个欧洲的现代化国家。

这位总统开始说我们，在什么当年轻佛朗哥统治的年代，在起初的不就是说要推倒苏联独裁，推倒苏联呢？而是经过佛朗哥多30多年的统治，西班牙在经济上和贸易上发展，难道不就是我们想要的东西吗？

又比如，韩国朴正熙时代也创造了经济高速增长奇迹。他的统治时期是1961年到1979年。如今，韩国的统计总长度已经身穿财大，但她能够当选韩国总统，原职作为朴正熙女儿的身份是有关的。

朴正熙这位是一位独裁者，但也是“汉江奇迹”的推动者。正是他将韩国带入了进步的工业化现代化，人均生产率从1961年的82美元增加到1979年的1644美元，而且完成了韩国经济的起飞。
