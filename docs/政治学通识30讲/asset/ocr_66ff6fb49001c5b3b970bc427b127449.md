# 政治学从升级通单

好，我们这一讲的“主题”是第三世界的国家问题。

本页的重要启示，可以说明，西方世界非常复杂地认识，而福山、亨特纳等学者的分析，都主要基于新自由主义的发展中国家的发展，就是向自身独立的政体过渡，而没有考虑到国家本身就是一个政治问题。

正是因为这样，很多政治理论家对于发展中国家的政治结构及生产关系理解得很粗糙。到20世纪80年代末90年代初，大家开始意识到国家需要有一个强有力的政府来提供公共服务，以维持政治秩序。这比过去要现实，但很多学者仍然把国家看作一个“黑箱”，认为政府是外生的，因此很多理论都建立在一个国家是统一行动者的假设上。

# 延伸阅读

讲到这里，我向大家推荐一本书，是美国学者弗朗西斯·福山写的一部小册子，它的《国家构建：21世纪的国家治理与世界秩序》，主题就是讨论国家构建对于发展中国家的意义，如果你读完了，欢迎你在留言区分享你的读后感。

我们为什么关心的是为什么很多发展中国家容易陷入政治危机。与此相关的一个问题是，有的发展中国家更容易陷入经济停滞，这又是什么原因呢？这涉及到一个“资源诅咒”或者“民主缺陷”的话题，这就是我们下一讲的“主题”。

# 用户留言

+   - **包刚升**

  作者留言：为了让一门学科对人类更有帮助，它的价值不仅在于理论，更在于如何应用在复杂多变的现实世界中。因此，关于政治学的思考始终无法回避对现实世界的深入观察和理解。本讲的主题——国家的政治功能，也属于此类。它不仅仅是学术概念，更是一种对于人类如何组织社会、管理共同生活的深刻反思。

+   - **Stone**

  幸运的国家是相似的，不幸的国家却各有各的不幸。

+   - **类比到国家也适用**

  失败的原因有很多，民族、文化、地理、气候、历史、外部冲突等，这些因素在某种程度上都可能成为国家不成功的背景。

+   - **成功国家的原因之一**

  具有政治综合能力

+   - **佛门提**

  之前有过一本有思想的“故事”书：德维·阿马蒂亚·森和帕斯科·塞贡德的《国家为什么失败》，两位作者研究的都是对发展中国家的政治学，他们的核心观点是：“国家失败”的核心不是文化、地理等先天因素，而是政治制度的缺陷。在书中，第一部分介绍了两幅图：一幅是地图，标注了一些国家的失败程度；另一幅是时间线，标注了一些关键的历史节点。这两幅图结合起来，清晰地展示了国家失败的根源在于政治制度。

+   - **陈C**

  在西方国家的政治演化，一直处于“有限政府”阶段。即使在西方，很多社会现象、内部的问题，都反映了“有限政府”的局限性。在西方，即使是像美国这样的国家，也面临着政府能力的挑战，经济、社会、文化等方面的问题都反映了“有限政府”的局限性。

+   - **陈C** (续)

  1. 有限政府下成功的国家：美国、新加坡等，具备强大的国家能力和民主制度，经济、社会、文化发展良好。
  2. 有限政府下失败的国家：许多非洲国家、部分拉美国家，国家能力薄弱，民主制度不健全，经济、社会、文化发展滞后。
  3. 国家能力与民主制度：国家能力是民主制度有效运行的基础，民主制度是国家能力的重要保障。

+   - **罗峰**

  通过尼科尔斯对这个典型的发展中国家案例进行了几点总结：
  1. 国家的稳定不是恩赐出来的，而是逐步演化而来的。
  2. 国家作为集体，没有自由意志，一切构成了国家的“性格”。
  3. 国家不仅是地理上的共同体，更是意识形态上的共同体，认知认同是国家的基石。

+   - **伪装**

  从非洲国家的案例来看，有两个要点：
  - 第一，一个国家的历史不是孤立存在的，它与其他国家的历史相互关联，如美国的南北战争、法国的殖民历史等。
  - 第二，一个国家的稳定不是恩赐的，它需要强大的国家能力，包括法治、军事、经济等方面。

+   - **大船心**

  包老师好！
  福山的书中“国家构建”主题，主要讨论了国家能力的构建，包括法治、军队、政府等。他强调，国家能力是民主制度有效运行的基础，也是经济发展的关键。

+   - **刘澜**

  如果把一个国家比作一个“公司”，那么国家能力就是公司的“管理能力”。如果管理能力不足，即使有好的“员工”（公民），公司也无法有效运转。因此，提升国家能力是改善国家治理的关键。

+   - **叶辉辉**

  正如福山所言，国家能力的强弱直接影响了国家的民主、经济和社会发展。在第三世界，国家能力的提升是一个长期的过程，需要各方面的共同努力。
