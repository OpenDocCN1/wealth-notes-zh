# 独立战争之后的政治困境

我们都知道，美国人很骄傲自己有一部完成的宪法，是人类世界的第一部成文宪法，200多年，一直沿用至今，而且大体上保持稳定性。应该说，这是一个很大的成就。

但是，你想过另一种可能性没有，如果说在1787年召开制宪会议没有成功，早期的美国是否能够可能成为一个失联国家。这个可能性，并不是我的胡乱猜想，而是确实客观发生的事。

1783年，美国的独立战争胜利了，英国人被迫离开了，美国的革命也算胜利了，从某种意义上，美国从此就走上了一条自由和繁荣的强国之路了吗？

当然不是。从1783年到1787年，虽然只有短短四年，但是留下一个非常复杂、独特的历史标靶。我们可以看明白，一个后生下来的大国会发生什么。

**当时的背景是，独立战争之后，美国其实只是一个独立，但没有完成建国。**13个州只是一个个松散的邦联，更不是一个真正意义上的现代国家。

这就造成了四大问题：

+   第一个问题是美国有国会，但是国会无权，比如，国会没有直接的征税权，没有权威。

+   第二个问题是国会没有财政，也没有有钱，7年的独立战争花了不少钱，但是没有收税的权，但是负债的军政，但无法承担。这个负债在谁身上，就都成了一个烂账，怎么分担这个烂账，就成了一个难题。

+   第三个问题是美国有国家，但是没有国家权威，比如，美国各个州之间没有国家实力，每个邦之间在独立战争中，并没有能力协调战斗的军力。

+   第四个问题是外来上的难题，比如当时英法等国的干涉，这些外国势力希望美国没有强大的中央政府，最好美国分裂最好。

这种困境，让当时的美国看上去像我们今天所说的“失败国家”。你想想我们国家，在世界上有很多，但是今天的，我们国家也是，如果我们的政府管理好其他地方的事物，那就会是一个坏的国家。

那么，美国当时的政治状况没有多糟糕呢？重大家庭，往往是我们的政治重要的枢纽。你只需要看我们常聊的那两个，那美国1786年的谢斯起义（又译为“谢斯起义”）了。
