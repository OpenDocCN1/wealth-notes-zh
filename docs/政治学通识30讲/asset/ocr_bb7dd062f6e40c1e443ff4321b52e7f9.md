# 经济学背后的政治学

作为得到的用户，您应该很清楚亚当·斯密的一个理论。那就是“只看为了自身利益、自由活动”，没有人会“看不见的手”来调节个人的利益，即使个人是自私的，也不妨碍整体的市场运动与财富创造。这，大概是经济学大厦的第一块基石。

但问题也随之而来：如果市场完全可以依靠自我调节，那么只需要有企业和消费者，不就可以了吗？ 为什么社会还会需要国家呢？

如果您看亚当·斯密的话其实是一种哲学前提，你会说“对啊，这个理论的理论是一整条‘看不见的手’。那这个前提成立吗？前提是每个人都可以自由合作交易，即使一个互互有利的机会。但问题是，所有都会这么做吗？当然不会。如果市场上的个体不可能合作，彼此不能合作，甚至发生了冲突，那又该怎么办呢？

我，给你举一个例子。比如，你到菜场买菜。这是个很简单的交易，一手交钱一手交货，交易双方各有所取和小额。交易自然不存在大。可是，如果你付了钱，小贩非要你给他，就是不把钱给你，怎么办？你去找他呀。那就闹出什么，对不对？

你会说，因为菜场有保安啊。保安也许个头很小，没有菜场子强壮。但保安背后还有警察。警察背后还有整个国家的力量。对，所以，即使你是买小贩，国家的力量就可以起作用。换句话说，正是因为大家知道国家，就国家不直接参与干预，但它总是在场的，所以交易才能顺利进行。

你看，国家的存在是非常必要的。但这里，我们必须要追问：是谁第一次在学理上论证了国家的必要性呢？这就是今天不得不提到英国现代大学哲学家托马斯·霍布斯。

# 为什么要国家？

霍布斯1588年出生，1679年去世，他活了91岁，非常长寿。霍布斯不长寿，而且他的生命跨度，正好经历了英国历史上一个风云变幻、起伏跌宕的时期，他经历过英国内战，见过查理一世被砍头，也经历过克伦威尔执政，正是因为身处这些历史动荡与思考，霍布斯开始思考国家存在的本质问题。

而在他的之前，政治学家主要思考的是：什么样的是好政府？ 但这个问题有一个前提：那就是国家肯定是存在的，但很少人会追问：国家为什么一定会存在呢？

霍布斯思考的，就是这个问题。他认为，如果国家不存在，为了资源，人们为了争取所有有限的自然资源，就可能会相对立，甚至会因为“每个人对每个人”战争状态。这种“战争状态”的战争概念，在思想史上，就是霍布斯最著名的理论概念。

那具体怎么来解决这个问题呢？当然，就是建立一个政治机构。这个政治机构应该具有压倒性的优势力量，有权力制止所有人的相互伤害行为。这个政治机构，在霍布斯那里，就被称为“利维坦”。“利维坦”这个词，你可以不太熟悉，它是圣经中这《圣经·约伯记》的一种海中巨兽。霍布斯正是用它来比喻国家的力量必须是非常强大才行。

霍布斯的这个逻辑，在今天看来，我们可能不觉得有什么了不起。因为在霍布斯的这个理论已经成为很多教科书的基本信息，在300多年前，这对当时是一个惊世骇俗的思想。当时，所有谈论政治的人，都把国家当作一个先验的、既成的“两分人”。霍布斯开始说，它告诉你，你试试，对霍布斯来说，一个国家，它要治的人是社会—根根本的恶。这个提法在当时非常激进。

# 国家的三个基本特征

我们刚才讨论了为什么要国家，那么什么是国家呢？一般来讲，国家有三个基本特征：

首先，国家要拥有巨大的暴力资源，这个好理解，我们刚刚也谈过。

其次，国家要有对资源的掌控以及拥有垄断资源，如果两个对立的机构都巨大的暴力资源，就会爆发内政。我想，这个也好理解。

不好理解的，是国家的第三个基本特征—“合法性”。

合法性这个概念提醒我们，国家仅仅掌握巨大的暴力资源是不够的。我们普通人处理一般民间对象的暴力，仿佛就是“拳头大的说了算”，但国家不一样，国家不是打手，它不能用纯粹的暴力统治。理解国家合法性和巨大的暴力存在，国家会靠暴力，是不行的。

为什么？因为仅仅靠暴力，一个国家的统治成本会非常昂贵，而且这样的国家往往是高度不稳定的。

我举个例子，你就明白了。即使是历史上最强大的国王，他身边也一定有着持枪的护卫吧？我们在电影中经常看到这样的场面。但强国的权力有多大，当国王和军队卫士单独在一起的时候，国王的暴力通常比不过卫兵的。那为什么不自己抢？要么保护他，要么杀死他，甚至取而代之？

你要知道，这不是推理论说。实际上，中国的南北朝、五代十国、罗马帝国的晚期，这样的戏码在上演。

所以，这里并不是国家缺少暴力资源的问题，而是国家缺少合法性。最高统治者身边的人，对他拥有压倒性的暴力，之所以，在统治技术，特别是权力的顶端，就极易发生命数的动荡。

说到这里，我们就可以给“合法性”下一个定义了。简单地说，合法性，是一个国内政对于国家、对政治，对权力的内在认同与自愿服从。

当然，世界上不同类型的国家，寻求的“合法性”，的意义上，有些国家是所谓的“君权神授”，有些国家的民主制度。如果最好汉“打出‘替天行道’得国。其实，这也是寻求合法性。
