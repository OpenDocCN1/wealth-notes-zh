# 伪装

课程进行到这里，政治学都改变了你哪些旧思想的看法？

以前我是一个初级阴谋论者，遇事往往会直接找一个原因，而不考虑背后的逻辑。比如美国发展贸易说是美国人要压制中国经济发展；而实际上美国的原因与中国自己本身对全球化的反对声过高。美国人总统转移国内矛盾而为外部矛盾的原因则更更大一些。

改变了我对自己看法，民主不是一个制度，而是一个生长的过程，过去我会很常态地想当然的说民主是个好东西，却不问坏在哪里，更没有想到坏在哪里。

最大的是政治学“边界条件和适用范畴”这个方面概念。几乎所有的政治学都几乎可以归结到这三个思维模板当中去，而绝大多数人却以自由可以当作万能模型来套用，这是一种政治上的万维性思维，如果学习政治学只要一个政见，那么非简单。

# 陈C

课程进行到现在，收获不少，我总结出以下体会：

1. 政治学的核心是国家，虽然知道国家的形成，在政治学中有着非常重要的地位，但以国政为核心，即对内政对外政，我以及政治学的核心出发点，对我来说是一个重要的概念。

2. 政治学中的系统思维，政治并不是几个政治学中的核心因素，更像是一个复杂的动态系统，事实上，一个国家的治理体制如何确立，其政治形态都会受一定条件，受到治者，个人的影响，以及国内文化，传统，观念，经济，地形，地理位置等诸多因素的影响，并不简单抽象地采用某种政治体，就会成功的。理解中基于发展中的国情的机制，就是对这些思维方式的最好佐证。
