# 27｜转型：为什么不少国家会遇到民主转型的困难？

我们前面的课程曾经提到，不少落后国家容易陷入“豪猪式陷阱”。那么，如何克服“豪猪式陷阱”呢？

显然，这就涉及到社会如何控制权力的基本问题。我们第二模块会专门讨论这个问题。解决方案包括用分治来分散权力、用司法来限制权力、用选举和投票来监督权力，用司法审查来纠正权力，等等。总之，这是一套很复杂的制度设计方案。

尽管这套方案很复杂，但我们一般人最容易想到的是，民主化是克服“豪猪困境”的首要选择。为什么呢？因为它能在防止权力的危害上发挥最重大的作用。但问题是，民主化在发展中国家都能落地生根吗？

# 民主转型的困境

过去，很多学者认为，民主化并不难。他们认为，民主化不过是简单的三组动作：**一是旧体制衰败，二是新体制创建，三是群体转向。**你看，就这样，民主大功告成了。

著名思想家熊彼特早在20世纪30年代里就持这种观点，民主政治就是幼稚的政治。这里的幼稚，就是幼儿的意思。他们的观点很明确：既然政治是幼稚的，民主政治的要求反而更低。

但问题是，为什么不少国家的民主转型都遭遇了挫败？我刚才提到的泰国民主转型的难题或困难，拿到热带的泰国来说，已经陷入了这种民主转型的困境，而且几乎难以自拔。

过去20多年，泰国反复着一种周期性的模式：先是举行民主选举，然后是军队或者首相的宫廷，包括泰国王室、精英和法院，甚至首都公共秩序的维护，这一切来干预。于是只好出来平政，于是，民主化这就失败了。

这些年，另一个典型案例是“阿拉伯之春”中的埃及。“阿拉伯之春”，是2010年底开始的一场席卷整个中东和北非地区的政治参与与民主运动。在这个运动中，埃及的穆巴拉克维系了三十年的统治垮台了。

然后，埃及就自动启动了首次民主大选，在选举中，由与军方合作反对派的穆斯林兄弟会，这是穆斯林自由主义党组织的一个组织，不久，在该党的主导下，埃及通过了一个新伊斯兰化的新宪法，明确规定《古兰经》和伊斯兰法律作为国家立法的基础。

但这样一来，埃及的世俗派就不干了。他们期待的是，新宪法对新的政治秩序做出回应。因此，新宪法就是埃及民主生活中最值得欢迎的问题。

结果是，世俗派和伊斯兰派的冲突日益升级。首都开罗再次出现大规模的抗议与示威，正是在这种情况下，埃及世俗精英沙菲克·塞勒夫发动政变，并开始镇压穆斯林兄弟会。稳定之后，塞勒夫带来了埃及的新统治者。这样，经过一轮轮回，看起来，又一堆巴拉克式的政治大人做起来了。

好，讲到这里，你应该已经看出来了，我们这里讨论的两个国家的陷入了民主转型的困境。那么，为什么国家的很多人容易陷入民主化的困境呢？原因，在于他们的认知地图。

简单来说，他们的认知地图由有三个主要假设：**第一，转型，就是制宪会议；第二，新宪法一定是最优方案；第三，新制度一定会比旧制度治理效果好。**

然而，这三个主要假设都是很成问题的。

# 转型就是制宪改制吗？

我们先来看**第一个假设：转型，就是制宪改制。**你知道，政治是系统。无论宪法，还是其他政治制度，都是这个系统的一部分。

一个国家启动民主转型后，制定新宪法、实施新制度，显然是其一项重要内容，但绝对不是政治转型的全部。

即使是发达国家，德国100年前的那次政治转型也一样就1018-1919年的这次变革，也逃了这个惯性。1918年，德皇退位，德意志第二帝国宣告破产。到了1919年，新的《魏玛宪法》生效了。

但问题是，这个新生的民主共和国，国防军的情况是全新的，但它的议会、政党、军队，甚至主要政治家，都是旧的，都是从半威权的第二帝国那里继承下来的。

拿政党来说，1919年前的德国主要政党，基本就能概括成两条政治保守主义。这些区域政党的基础是地方认同，而不是美国的政党基础。所以，尽管新兴宪法多了许多政党政治的色，但问题是，当时的主要政以几乎没有做好准备。

如何有效执政，对当时的德国社会民主党等大党来说，成了一项全新的政治任务。主要政党需要适应通过自身的重建，来胜任这个新的政治任务。然而实际上，他们无能为力。这也是魏玛共和国后迅速走向危局的主要根源。

因此，转型，不只是意味着制宪改制。只有制宪改制，而其他条件没有配套跟进的时候，民主转型是难以成功的。

# 民主宪法一定会被遵守吗？

第二个假设是**大家一定会遵守新宪法**，这一点也过于理想化了。历史上，新宪法通过以后，很快被修改、甚至解架的故事，可以说比比皆是。

我们一年，中国先后有过两部重要的民主共和制宪法。一是1911年公布的《中华民国临时约法》，二是1913年公布的《中华民国约法》。

然而，以袁世凯为首的北洋集团很快就对出了先专制的做法。不仅如此，国民党在重要关头也常常置法律于道义。历史证明，无论是法党也好，还是保守党也好，在宪法上为了一己之私，都会把法律当儿戏。当1913年民主共和制宪被刺刺后，民国宪法就完全形同虚设了。

最近国际上有一项新研究指出，在转型期，政治家遵守法律并是一个常有现象。根据理性人假设，当政治家发现对自己有利时，政治家很可能故意违反宪法。如果是后两者，转型往往容易失败。
