# 政治学认知升级清单

好，这一讲的题目，是以美国司法审查为例，来帮您一起解读司法权是如何体现民主权力的。

本讲的一个重要启示是：政治生活是一个既需要规则制约、又需要理性对话的过程。像美国最高法院的大法官们去审查宪法，他们既不接受行政权干预，最高法院不会变得很强势，最高法院可能在总统的、国会的正面对抗中早已站得稳稳的。所谓政治，其实是一种平衡的艺术。
