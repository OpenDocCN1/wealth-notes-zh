# 第三世界的国家建构难题

这一讲，我们从一个非常重要的问题说起：为什么很多第三世界国家总是发展不起来呢？

比如，在非洲，不少个世纪之前的开初，今天仍然是穷国。人均GDP甚至只有区区几百美元。相比之下，韩国、智利、中国这些国家，都通过近一或两代人的努力，获得了显著的经济增长。

造成这种差异的原因是什么？原因当然有很多。但一个重要原因是，很多长期陷于贫穷的第三世界社会，同时也是易深陷暴力冲突的社会。这样，发展也就会无从谈起。

我们还可以继续问，为什么有些的第三世界社会更容易陷入暴力冲突呢？答案是，它们缺少一个具有政治整合能力的国家。我们这一讲的主题，就是第三世界的国家问题。

如果你熟悉西方的话，你可能听过一句著名的话：『国家是必要的。』在国家安全上，这是启蒙运动以来，西方政治传统最具代表性的观点。

国家当然必不可少，但国家为什么是一种必要？因为国家能让所有人自由，所以，从英国辉格党到法国启蒙思想家都主张，西方政治传统的一个重要关切，就是如何限制国家。

到了20世纪中叶，亚洲和非洲很多国家获得独立、后启蒙建设时，西方法学家仍然持有这种观点，来评估第三世界的国家问题。

然而，这些新兴国家面临的完全不同的国情。许多第三世界社会面临的，不是国家过于强大的问题，而是社会因分散、利益集团过于活跃，它没有一个有效的国家。

# 第三世界面临的三大问题

发达国家标准相比，第三世界社会面临的截然不同的社会问题，这也是我们要分析的主题。

# 1.缺少国家传统

第一个问题是，很多第三世界社会都缺少国家传统。在整体上，除了埃及和少数例外，20世纪中叶新独立的历史，实际上没有国家统治或主权国家的传统。其间，国家很多都是出于欧洲殖民者的施加，甚至领土边界也是由欧洲人画出来的。
