# 极简美国移民史

探讨这个问题之前，我首先要跟你强调的，很多人其实误解了美国的移民政策。有人认为，从美国来原是一个开放度高高的自由移民国家，不分教源、宗教，来原欢迎移民。这其实是一个很大的误解。

真实的情况是，美国实行开放政度的移民政策，主要是近半个世纪的事。在此之前，除了美西伯移民，美国其实还是一个很严格制移民的国家。

这种移民政策有三个基本特点：一是主要欢迎西欧国家的移民，二是控制东西欧国家以外的移民，三是通过同化与控制，塑造具有同质性的美利臣民族。

因为篇幅有限，我想我们无法讨论美国400年的移民史。所以，我只得跟你讲三个故事，来说明美国1960年之前的移民政策。

第一个故事是，早在1818年，纽约和新英州的爱尔兰人社团向美国国会请愿，希望在西部获得一块土地，来安置最穷苦的爱尔兰人。这听起来似乎是一个人道主义的诉讼请求，但是，国会却无情地拒绝了这一请求。

理由是，如果各同族的移民群体都建立自己的聚居地，那么有可能导致美国社会的碎化。可以见，那时的美国政识就认识到，应该同族移民保留性同化美国移民，而不是鼓励不同族移民保持他们各自的民族特质。

第二个故事是，美国曾出台过1852年通过的“排华法案”。作为中国人，当然对此非常不愉快。但“排华法案”出现，却有它特定下的政治背景。19世纪末时，华人劳工大量进入美国，引发了美国社会的担忧。

有议员认为，最大的问题是，华人劳工工资较低来于白人劳工，德国移民则利用美国化，从而真正融入其社会的主流。由此，“排华法案”就出台了。

第三个故事是，随着1890年以来南欧与东欧移民的增加，美国社会先后于1913年限制移民和1924年民民法，其核心是限制移民配额。

事情的起因是，19世纪的最后二三十年，来白西欧和东欧的意大利人、犹太人、斯拉夫人构成了移民大头。美国议员阿伯特特，约翰逊认为，西欧以外的移民会对“美利坚民族的同统一性”构成挑战。

新移民法规定，要以1890年美国人口普查为基础，根据当时有人口的大国比例，来决定今后每年各国新移民的配额。

比如，我拿到一个数据是，1924-1925年，中国、日本、澳大利亚、土耳其国的移民配额都只有100人，而配额最高的德、美、英和爱尔兰分别为51500多人、34000多人和28000多人，这比例多少地，也就是保持当时美国人口有的比例，宗教的宗团回比。

# 美国移民政策的转向

听到这里，我想，你过去的很多看法可能会被打破了。那么，我们什么形成美国最初移民的“大熔炉”的印象呢？这实际上跟美国20世纪60年代美国移民政策的重大转向有关。

这种转向的标志性事件，是1965年通过的《移民与国籍法》。这部法规了移民配额，由此拉开了美国历史多民民移民放宽的时期。你可能会问，为什么美国会发生这种转向呢？
