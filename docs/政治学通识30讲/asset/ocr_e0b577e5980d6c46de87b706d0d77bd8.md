# 05 | 君主制：为何一人统治模式可以延续数千年？

我们上一讲的主题是战争塑造了国家。完成课题是一国统一的，因此面临着如何统治治理国家的任务，这就我们遇到的第一种矛盾。于是，谁来的统治，人类历史上主要有两种解决办法，要么是君主集权制，要么是人民权利。

# 为什么都选择君主制？

在今天来看，民主制毫无疑问是一种更公平的制度。但是，可不一样，要求公平可以是我们的今天的事情，实现不了，需求公平，可以说，是人类天性的一部分，甚至到在你们家身上也可以看到这种公平的诉求。

著名的“王子”杂志2014年发表的一篇小文，他让一群婴儿发现另一组婴儿，完成没有任何任务，但得到的奖励都比他们的好时，表现是非常愤怒，会做愤怒的表情。你看，道子都有公平意识。

再回到我们的讨论。跟民主相比，在公平性上，君主制就输得很惨了。所以，今天君主制需要看重一种叫“制度”。那么，问题就来了：为什么在19世纪之前，除了极少数的例子，君主制是被普遍采用的统治模式呢？

其实，问题出在一个“扩展性”上。什么叫扩展性呢？我们可以打个比方，如果把一台电脑放在你面前，你有两套芯片，其中一套，性能超前，用的不是更好，但是其他参数没得选，但扩展性较好。还有没有一台，性能稍差一点，可扩展度不够好，但是功能强大，扩展性则强。如果让你选择，你会选哪个呢？

对，在政治史上，民主制就是那台有“扩展性”的电脑。在现代社会里，就是那句，民主。但是古代的民主和现代的民主，还是有不同，后面的课程中，我会带你理解两者的差别。

# 古代社会民主为何只适合小国？

今天我要讲的，当然是古代社会的民主。在古代社会，人类可以识别文字，记录之前，民主制的形式就是直接民主了，这就是民主最早的古代形式，但这种民主模式就适合小国，那么，都只适合小国，为什么只适合统治小国呢？

可以想象一个场景，在某个聚落，一个普通公民要从家里走出来，步行到首都中央广场上投票，然后在家前回家吃饭。那个时候，没有车，车在，有马车，但很不可不起哦。

那么，在这种条件下，人所能到达的最远距离是多少呢？正常人步行速度是每小时4公里，走56小时，8小时，已经是最极限了，因为你一天至少得吃饭，从早上到傍晚，从你住的地方到投票，你能够到达的最远的距离大约是25到30公里。

所以，一个古代社会要想实行直接民主，民主地域的直径就大概不会超过50到60公里。若按圆来计算，最大面积也就3000-4000平方公里，这么大么？恰好就是雅典，这个城市的面积，这么大一块地方。

这么小的地方，无论你的经济实力，军事实力多强，只要有规模巨大的君主制国家入侵，它还是很难抵御的，你看吧，古希腊那些城邦联合抗侵略，但最后还是被罗马，或者被罗马统治灭亡了。

而君主呢？它的扩展性强多了。因为的统治不需要公民都参与，君主制国家的统治，只要考虑一点，只需要马匹和士兵能抵达，就能在保障统治和税收系统的地方，就可以建立一个大的王国和政治大系统。古罗马史上的大帝国几乎都君主制。甚至古罗巴共和国，它的情形也非常奇特，我下一模块还会专门解释。

# 君主制如何“打补丁”？

不过，既然君主制在规模上有它的优势，但君主制也有它的弱点，这台电脑虽然具有良好“扩展性”，但是有很多bug，也就是软弱，不是容易修好的，其中，最大的bug就是君主本身。

君主是一个高高在上的统治者，但同时又是一个普通的人，有的时候也非常脆弱。

比如，某位君主能得发动、健康、意外死亡，就可能导致政治动荡。比如，君主的巨大权力也容易引起野心家觊觎，这些野心家不仅是来自上，更是来自下，这些，使得权力大厦从上到下，没有人不想取而代之，区别只在于有没有条件。
