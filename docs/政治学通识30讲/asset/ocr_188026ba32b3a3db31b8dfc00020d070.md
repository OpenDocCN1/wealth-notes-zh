# 06 | 官僚制：为什么官僚制问题重重却难以改革？

上一讲的主题是君主权。我带你看了古代政治结构的发展脉络。今天，我们把镜头往下移一点，来讲官僚制的问题。

提起官僚制，我们一般都只有什么好印象。很容易联想到“官官主义”“官官作风”这些词。但是请注意，政治学上，官僚制并不一定是一个贬义词，它是指基于科层规则的整套行政系统。所以说的官僚，并不是特指当大官的，或者作恶很恶的，而是指科层制中的行政人员。

不过，话又得回来，官僚制显然不是一个贬义词。但是，官僚制确实是存在问题的。它官僚、繁琐、形式主义者等，行政效率低下等等。那问题来了，弊端这么多，为什么不改呢？

实际上，人类历史上针对官僚制的改革是很多的，但是成功的却很少，这是为什么呢？

# 官僚制和国家规模困境

这是从根本上影响了古代社会的“国家规模困境”。说简单一点，就是国家规模太大了。在官僚制的发展过程中，官员的任免、升迁、考核等，都会涉及到大量的文书、档案、通信等事务。在古代社会的技术条件下，管理一个大规模的国家，不可能不依靠一套看上去要有划级别的官僚制系统。

所以，官僚制的打击方向，就是在上游线上，安全和方便获取信息。你若是想确保所有人的信息资源充足，密码机就是，要使用最密不透风的加密系统。这在当时是非常罕见的。所以说，官僚制的问题，不是官僚制本身的局部问题能够解决的。

我这么说是什么意思呢？具体来讲，在古代，统治一个大国，意味着从君到部到边的距离比较远，地方上的样态也比较多，由此而来的问题，官僚成本就会比较多，君主监督官僚的成本也会相当惊人。

在这种情况下，国家有两种选择。

第一种策略，授予地方官员较大的自主权，让地方政府也自己搞政策，回民政令，称之为“间接”。这是简政放权。这跟古代放权差不多，给基层有很大的空间。但是，这种做法，往往会带来一个很大的风险，即地方官员会借机私设公署、增加税赋、中饱私囊，甚至，有的国家会不断分崩离析。

第二种策略，中央政权采自管自编的官僚系统。就是古代的“一刀切”。也就是说，虽然成本很高，但你解决了一个大规模的国体的统治问题。

如果是统治治者，你会选择哪种策略呢？

采用哪一种策略，历史上不是没有。举例来说，唐朝一开始去汉话，增加了地方行政，结果导致了分裂。到了南宋，加强中央集权，结果导致了南宋的偏安。明朝中后期，因为政治腐败，最终导致了清朝的灭亡。你看，一个国家的稳定，更多是靠其政治制度的自我修复和调适能力，而不是短期的行政效率。

面对“规模困境”的，不只是国家，企业也是一样。像麦当劳，星巴克这样的企业，为了保持服务的一致性，都使用标准化的配方和流程。其实，官僚制在本质上就是一种追求一致性、标准化、可预测性的组织方式，而不是考虑不同区域市场的多样性。因为一致性、标准化，能够为一个大规模企业提供较好的可管理性。

所以，我们可以总结出一条法则：**很多时候，一个官僚制系统的可统治性与可管理性，要比它的适应多多样性或回应性重要得多。**

# 难以破解的官僚制难题

然而，只要强调一致性与标准化，就必然导致封闭化、形式主义，甚至人为化等问题。这些问题怎么办？怎么办，不好意思，在古代，这些问题是解决不了的。而且，想出来的对策，往往也是官僚制的补丁。
