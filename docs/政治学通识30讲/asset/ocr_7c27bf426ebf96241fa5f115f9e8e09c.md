# 政治学认知升级清单

好，我们这一讲的主题是政府债务背后的政治问题。发达民主国家的公债问题，表面上是一个财政问题，其实是政治的问题。

这一讲的重要启示是：民主意味着多数人的统治。但，如果政治家过分迎合选民利益，就会带来短期利益过于膨胀而无法担当。因为政府总是，最终仍需要去承担这些买单。从民主自然、务实的，民主能否实现跨越的打政，却是一个现实的挑战。

换句话说，公债考验的正是一个民主国家的自治能力。惟有严格的财政伦理和法律约束，才能让民主的运用走在一条财政稳健的道路上。
