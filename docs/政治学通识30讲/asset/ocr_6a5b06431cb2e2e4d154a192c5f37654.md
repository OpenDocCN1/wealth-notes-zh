# 15 政党：政党为什么会兴起？

巴别学·政治学课30讲

我们一讲的主题是议会制与总统制的不同，这一讲的讲题是政党。对于现代政治生活，政党们手里握着真实的**权力**。放眼全球，没有哪个大国的**政治**能离开政党。然而，就在200年前，欧美还认为政党是政治上的**大毒物**，甚至要从美国建国时刻说起。

比如，美国总统**乔治·华盛顿**，就认为，政党强调的是派系利益、不是**整体利益**，所以对一个共和国没有好处。这是什么意思呢？华盛顿还要从美国建国时刻说起。

# 华盛顿为何反对政党？

1789年，乔治·华盛顿就任美国第一任总统，他自认为，自己是**一位**独立的总统，他的任务就是为联邦人民服务，不是为汉密尔顿做他的政治**副手**，或者为杰斐逊做他的政治**代言人**；他想当的是**国家**的**管家**，而不是党派**党团**的**打手**。

你可能知道，汉密尔顿本身就是一位了不起的政治**家**。他是《**联邦党人文集**》的主要起草者和《联邦党人文集》的主要**编辑**，也是影响美国建国的重要政治**家**。

就任财政部长以后，汉密尔顿就**大胆**在**政策**上**搞**政党的**独立**，主张加强**中央政府**的权力，主动承担更多的政府**债务**，创立**国家银行**，以及**大**力**发展**工商业。**华盛顿**对他的**信任**，**大意**任用**自己的**支持**者**。

然而，汉密尔顿这样做，却**激起**了**杰斐逊**的**强烈**反应。**杰斐逊**认为，汉密尔顿的政策**违背**了**建国**的**初衷**，是**为**了**谋取**自己的**政治**利益，**而不是**为了**国家**的**利益**。

到**了**1791**年**，**国会**为了**筹措资金**，**决定**对**酒类**征收**税**。**然而**，这是一**项**有**争议**的**决议**。1794年，**宾夕法尼亚州**的**抗议**者为了**抗议**这一**项**政策，**爆发了**一场**骚乱**。华盛顿认为，**这件事**是**共和**的**派**与**亲**法**派**的**冲突**。

由此**可以**看出，**杰斐逊**认为，**政治**上的**斗争**是**为了**维护**自己的**利益，**而**不是**为了**国家**的**利益**。

到**了**这个时候，**竞争**已经**演变为**了**政党**的**斗争**。**在**华盛顿看来，这是**非常**不**好**的**现象**，因为**政党**斗争**会**导致**国家**的**分裂**。

**然而**，**杰斐逊**却**不**这么**认为**，**他**认为**政党**的**斗争**是**国家**的**利益**所在，**是**维护**民主**的**必要**手段。

# 为何政党会兴起？

**那么**，**为**什么**政党**会**兴起**呢？**我**们**可以**从**两个**方面**来**分析**：**第一**，**政党**的**兴起**是**为了**维护**自己**的**利益**；**第二**，**政党**的**兴起**是**为了**维护**国家**的**利益**。

# 最小获胜联盟法则

**我们**可以**看到**，**政党**的**兴起**是**为了**维护**自己**的**利益**。**在****现代**国家**，**政党**是**国家**的**利益**所在，**是**维护**民主**的**必要**手段。
