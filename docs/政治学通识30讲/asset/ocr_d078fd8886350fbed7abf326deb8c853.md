# 04 战争：为什么说是战争塑造了国家？

包明华·政治学基础30讲

上一讲，我们讨论了国家为什么会兴起。霍布斯说，国家的兴起，说到底是因为恐惧「人与人的战争状态」。但是，请注意，我们只是借借霍布斯的学说跟历史上推导了这个问题，但它说到底只是一个思维实验。

因为，人类历史上从来没有过所谓的「每个人对每个人的战争状态」。你想，就是黑猩猩部落也不会这样吧。

那么，在真实的历史过程中，国家到底是怎么来的呢？今天，我就带你回到真实世界，我们一起来看：**国家是怎么发育出来的？到底**是什么力量推动的？它又经历了怎样的演化？

# 战争塑造了国家

我们课程的介绍中，曾经讲到过美国制宪的故事。美国立国会派的诞生，是为了制定会议，这成为后来各国建国的规定动作。凡是建立国家，首先就要制定一部宪法。但这样一来，可能容易给人一种错觉，好像国家都是人为设计的结果。

美国有一位重要的政治史学家，他的名字叫塞缪尔·莫利森，主写过很多书，他提出了一个重要观点，他说，国家跟建造高楼和组建乐队本动力，不是人为设计，而是战争。塞利翁学说，非常有说服力，主要是他观察欧洲历史得出来的结论。

听到这里，你有没有想到：战争不都是破坏，怎么能成为国家形成的动力呢？我就给你讲一个我们更熟悉的古代中国的例子，你就能明白背后的道理。

# 国家建构的「三件套」

中国历史上的西周时代，其实像春秋战国国家形成的时期。但都知道，秦国的商鞅变法，废井田开阡陌、除宗室、废血缘、建立官僚体系，让秦国的国力空前强盛。

但是，你想过这个问题没有？好好的，为什么要给秦国变法这么大一个手术？而且那个过程是极痛苦的，主持变法的商鞅最后都被五马分尸了。原因就是因为反对的人太多，把社会变革搞得太过激烈了。

为什么秦国要搞变法呢？因为从公元前419年到公元前368年，这30多年间，秦国在与西边的魏国的一系列交战中，多次败于魏国之手，元气大伤。所以，变法也不是不得已而为之的事情，要不就亡国了。

而魏国当时的国力如日中天，它的精锐部队叫「魏武卒」，是魏国著名武训校尉吴起发明的亚甲步兵，号称「大夫七千二，全属六千二」，其余不分成伍。所以，当时的秦国根本不是对手。

那么，为什么魏国这么强呢？因为魏国率先搞了法家变革，也就是李悝变法，比商鞅变法还要早。我们还可以接着看：为什么魏国要变法呢？其实就是也迫不得已。因为魏国旁边有一个积极推行变法的韩国。

韩国的地理位置，似乎占据着当时中原腹地的中心。但这个中心位置并不是一件什么好事，因为四周都是敌人压力。用政治学的语言来说，它是一个地缘政治压力巨大的国家。

正是为这个，韩国的兵器制造业就很发达，他们最早发明了「强弓劲弩」，号称「劲韩」。《史记·苏秦列传》有一句话：「以韩固之矛，被坚利，驱马弓，骑射，一人当百，不足言也。韩卒之勇，天下莫能当。」简单来说，韩国军队武器精良，士兵勇猛，战斗力极强。

如果你是魏国，你旁边有这么一个凶悍、勇猛的邻居，你会不会感到恐惧？如果感到恐惧，你又会怎么办？所以，魏国只好变法。而魏国一强大，战胜秦国的几率，又逼得秦国也不得不变法求存。

所以你看，当各国的变法改革，不是一个用主动人为设计来打造国家强盛的形象，而是一个用环境相互的链条，因为在战争传导军事实压力，然后倒逼内政改革。
