# 28 | 分歧：财富结构如何塑造发展中国家的政治？

我们上一讲的主题是，为什么不少发展中国家容易陷入一种糟糕的困境。这一讲的讨论，我们要从一个大范围的视角切入，那就是拉丁美洲国家跟美国在发展和政治上的差异。

# 拉丁美洲和美国的发展差距

你肯定知道，西半球有着大大小小的几十个国家和地区，包括美国、加拿大等，均被很富裕，而拉丁美洲许多国家则不太一样。如果从人均收入来看，拉丁美洲国家跟美国的发展差距大约有5倍之多。

你可能会想，两者的差距历来如此吗？如果回到1800年前后，拉丁美洲的很多地方跟当时的美国还没有那么大，那么，为什么后来两者的差距变得这样大呢？

我们进一步说，经济其实还只是一个方面。拉美国家跟美国在政治上的分化，同样很明显。美国自1787年制定宪法之后，除了19世纪中叶因为奴隶制问题爆发过南北战争，其他200多年基本维系了稳定的民主共和政体。

但拉丁美洲国家过去200多年的政治，是难以稳定的。一般说拉美政治，你或许会想到的是不稳定的总统共和制和频繁的军事政变。直到20世纪八九十年代，这种状况才出现了改观。

那么，问题就来了：为什么美国的民主政体稳定，而拉丁美洲反复出现的民主政治经常遭遇危局？原因当然是很多。比如，有人强调，美国的民主政体，跟它相对富庶的宗主国西班牙的宗主国制度有关系。而类似墨西哥、哥斯达黎加等拉丁美洲国家，跟宗主国西班牙的关系就复杂多了。

# 美国土地制度的政治效应

这种说法当然是有道理的。但这种观点忽略了一个重要方面，那就是对美洲国家重要的影响。听到这个想法，你可能有些疑惑，土地制度到底有多重要呢？接下来，我要跟你专门讨论这个问题。

美国从殖民地时代至今，已经有400多年，土地制度当然经历过复杂的时代变化。但大体上，美国可以以一个白种人为主的资本主义国家而存在，这背后与美国早期的土地制度有很大关系。

1800年，美国国会通过的《土地法》规定，为了鼓励向西部迁移，决定分块出售西部320英亩的土地，并实行相对宽松的分期付款方式。到1804年，可售土地的数量就达160万英亩，甚至土地价格为两美元，但同样可以分期付款。

按照美国第三任总统托马斯·杰斐逊的说法，以稳定、自给自足的自耕农为基盘，美国就能建成一个理想的社会。

后来，随着西进运动的推进，更为著名的《土地法》是1862年的《宅地法》。该法规定，凡人是美国公民并满21岁，从未参加过叛乱的美国公民，只要宣誓申请土地的目的是为了自己耕种，在缴纳10美元登记费之后，就可以领取不超过160英亩的土地。此后，只要居住并耕种满5年，申请人就获得了土地所有权。

这意味着，当时的美国白人大约有几十户只需要花费几美元，就能获得160英亩的土地。160英亩，相当于中国的960亩，几乎是千亩良田，面积可以说是相当之大。

《宅地法》实施多年以后，美国总共发放了大约2.7亿英亩的土地以这样的方式分配，大约总共给160万自耕农家庭。这说明了一个时代自耕农家庭丰衣足食，过上农业社会相对优厚的生活。

正是由于这种土地制度的安排，所以在1787年美国总统制共和制和19世纪、20世纪的繁荣基础上，美国的政治秩序要一版就比欧洲稳定。不仅如此，美国农民在城镇与都市之间流动，相对富庶的自耕农更坚信凭自己的努力过上好的生活，而不是仅仅仰靠分配和福利。这也是美国个人主义精神比较旺盛的社会背景。
