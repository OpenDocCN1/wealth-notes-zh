# 29| 思维：政治学思维究竟如何与众不同？

前三个课程，我帮你解读了政治学的五个专题模块。这五个重点，不是任何的具体知识，而是政治学的思维维度。

经济学一学有名号的对话，叫“像经济学家一样思考”。强调的其实是经济学思维模式的与众不同。那么，政治学也能说“要像政治家一样思考”吗？经过前面课程的学习，我想，你应该已经知道，政治学也有一套自成一体的思维逻辑。

比如，单学科问题来说，经济学研究资源配置的问题，但其实，政治学也研究资源分配的。回到真实的公共性，你就会发现，通过权力分配的治理，并不如通过市场分配的治理多。这，就是一种经济学不能解释的很多现象，就需要政治学来解释了。

再比如，拿研究假设来说，经济学大厦的第一块基石是理性人假设，它假定人追求利益的最大化，但其实，人性中很大一部分动机，那就是追求对权力的支配感强化，追求影响力的最大化。政治学把这种思维强化了因素，并把它对权力的追求看成社会的重要驱动力。

听到这里，你也许会问，内行讨论政治和外行讨论政治，到底有什么不同？我就会告诉你，最重要的是，内行们在一个大上，是学会掌握了现代政治学的基本思维模式。那么，现代政治学有哪些思维方式？

# 1. 国家思维

第一，外行容易把政治等同于宫廷政治，但内行更关注宫廷政治背后的国家问题。现代政治学的一个最基本的思维模式，就着重在国家问题的分析。因此，这种思维模式应该已经为你参加课程的收获。

你肯定知道，在古代，宫廷是政治活动的重要发生地。但宫廷并不是无处不在。拿唐朝初期的政治来说，公元626年发生的玄武门之变，就是宫廷政治的高潮，也是兄弟相残的最血腥时刻。

但引发这一宫廷事件的原因，不全在宫廷之中。关于玄武门之变的国家问题，李世民等结成兵卒下京中积聚军队，各自实权掌握的兵将，以及在高级官僚集团中的政治联盟，都是这场宫廷政变的关键因素。你看，决定宫廷政治的力量，很多都在宫廷之外。

到了明朝初年，朱棣夺了文帝的大权时，即不明确宣告封建诸王，而直接着手对付内政。当然，或他是因他决定国家权力归属时，宫廷就显得第二位了。

因此，宫廷背后的国家，才是政治的核心。政治学家的核心问题正是国家，就像经济学家最关注市场。

那么，关于国家，政治学为我们提供了何种洞见呢？政治学思维强调的是——

国家几乎是最有知识公共政治的问题。美国政治学家亨普逊说，如果说有问题，就会陷入人与人或战争状态，这些都是血腥的，看看普雷丁、南苏丹、叙利亚这些失败国家，你就更容易理解国家的重要性。

国家还蕴含权力关系的强制性。这完全不同于市场经济中的等价交换关系。比如，无论国家提高所得税，还是推进退休体系，每个人都有强制性，你是无处可逃的。

进一步说，正是因为这样，国家还很多重大，最大要回答的是国家的问题。一个社会是繁荣，还是动荡，往往是经济国家最关心的问题。而政治学的课程拉各斯，经济说：“国就是经济和政治的镜像，又是一种：经济就是政治的镜像。”你看，连经济学家都承认，经济关系与政治的关键，在于有个什么样强大的国家。这就是政治学的国家思维。

# 2.权力思维

第二，外行容易把政治等同于权力斗争，但这样一来，政治学就沦为了权术之学，而内行关心的不只是权力斗争，更是权力形式的所有问题。现代政治学的第二个基本思维模式，是重视对权力的分析。这种思维模式，也你应该已经成为你参加课程的收获。

民间借贷政治最津津乐道的问题，在《吕氏春秋》中，刘彻是如何一步步登上王位的；在《甄嬛传》中，甄嬛是如何在复杂的宫廷关系中生存下来，最终走过对帝后的死侍的；在英雄《铁胆雄心》中，男主人公弗兰克·安德伍德是如何不择手段坐上总统宝座的。

权术要广泛关注，是完全令人理解的。然而，现代政治学与其说关心权力斗争的道途，不如说更关注权力背后的制度与结构。现代政治学的三大本问题之一是：传统一还是绩效？如何统治？为何统治？——其实都跟权力有关。

那么，关于权力，政治学为我们提供了怎样的洞见呢？政治学思维强调的是——

权力需要有能力管理起来，社会才需要有被控制能力。这一道理看起来简单，却非常重要。权力不能管理社会，社会就会陷入内乱；社会不能控制权力，权力就会走向失控。

权力还必须达到道德、理性、发展，问题是你仍然无法治理，凭什么从对？这就是政治学比经济学更关注的。如果这个问题的解决方案，即使像在秦汉王朝那样强大的国家，反叛也随时都可能发生。
