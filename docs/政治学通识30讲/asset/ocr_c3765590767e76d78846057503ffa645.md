# 延伸阅读

最后，我推荐给你一本书，历史学家戈兰，出版的《美利坚共和国的缔造》，作者对 1776~1787，这个国家宪法制定期间发生的大事做了非常详细的记录。它既回答了美国建国时期有哪些政治难题，也回答了这些问题是如何解决与克服的。如果你对这个问题有兴趣，可以去看一下。

学习了今天的课程，你有什么想法或评论，欢迎你在留言区讨论。

我们前两周讲了一些基础概念。从今天开始，我们就来进入美制的问题，就是，任何一个国家在建立政治制度之前，都会面对国家问题。我们的第一个模块，就要从国家讲起。

英国既没有成文宪法也没有，但却很精巧的平衡了权与威的关系，展示了尊重与效率、宽严制度与弹性，最大限度顺应时代创新，不断扩展了民主的范围。

这两天收到一个3101、3109的英国下议院权利冲突的辩论和辩论，关于，也通过投票以311：310的结果通过，并提出过可以加以辩论，这件事也能让大家感觉到这种政治的实践智慧。

当然，这种实践的政治智慧也并非外国的专利，我国改革开放之路实践的经验特别可取，这也是政治实践最经典的案例。

政治过程像完成一件产品一样，要确定一个方向，需要解决，勾画大体轮廓，然后再细化，然后开始制作，并根据最终反应修正调整，经过迭代，最终形成一个相对完美的产品。所以，政治也是一个实践的过程。

实践智慧不同于哲学和科学上的智慧，哲学研究的都是普遍适用的规则，前者是情势与变化的，前者是静态的，后者是动态的，哲学是静态的，实践智慧是动态的。
