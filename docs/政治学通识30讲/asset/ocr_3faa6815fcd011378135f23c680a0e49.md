# # 21 | 福利：为什么福利国家并不总是受欢迎？

我们上一讲的主题是政府干预，这一讲我们来探讨福利国家。自由市场经济会导致贫富分化，这是一个常识。在一个市场经济的社会中，总有一部分收入很低的人、失业的人、年老体弱的人，甚至还有丧失劳动力的残障人士。问题是，一个社会应该怎样对待这些弱势群体呢？

今天，你会想到最容易的解决方案，就是福利国家。但事实上，直到19世纪上半叶，欧洲还没有形成普遍福利国家的共识。也就是说，这种向福利国家的戏剧性转变是如何发生的呢？

# ## 从《济穷法》到新济济法》

英国济贫法，早在1601年，英格兰就制定了《济贫法》，史称《旧济贫法》。到1802年为上，英国总共建立了3700多个济贫院。还有很多人获得院外救济。总的来说，这种救助相当有效。

美国名人本杰明·富兰克林到英格兰旅游后，这样描述：“从没有哪个国家像英国这样慷慨地对待穷人。当时，英国济贫院的伙食是奶酪面包，这经常包含鱼和肉，有记录表明，英国东部城市布莱顿的一家济贫院甚至提供进酒喝。”

随着时间的推移，到了19世纪上半叶，由于工业革命的推进，英国已经变成了著名的“世界工厂”，正是在这种背景下，英国在1834年通过又一部《济穷法》，史称《新济济法》。

听到这里，你可能容易认为，这应该是一部提倡福利国家的法律。但事实却非如此，尽管是一部新济济法，但它既是一部非常严苛的济济法，它并不是一部支持福利国家的法律，而是一部反对福利国家的法律。

为什么会这样呢？当时在英国社会的主流观念认为，过分的慷慨，社会对帮助和鼓励救济，并不一定好政策，反而是一项坏政策。

一种意见主要是着眼于对劳动力市场的考虑。有人指出来说，如果给贫穷的劳动者生活得很好，工厂就无法用更加低一些的工资待遇工人了。过分享慷慨的救助政策，还会鼓励下层民众的懒惰行为。

另一种意见主要是出于人口质量的考虑。意大利的经济学家马尔萨斯说，贫困是上帝制造的大量经济学家怀尔考不承认，但事实上却过进了人们的忧患意识。如果济济条件过于优越，社会就会变得懒惰。今天看来，这种观点肯定是不正确的。

正是基于这些考虑，1834年的《新济济法》所确定的一条基本原则，就是只救助那些真正需要帮助的人，而要去帮助那些有体力、在政策或管理上完要什么区分这两种人？

《新济济法》采取了非常可用的两种：第一，不管大小都必须住进济济院内，而由济济院的院内的救济方式；与之配套的第二措施，济济院只提供极其低劣的食品和工作，同时还给救济者安排非常繁重的劳动。
