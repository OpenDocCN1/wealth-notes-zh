# **17 总统选举：制度设计是如何塑造政治共识的？**

我们说，任何政治的良好运作，都依赖于最大程度的政治共识。但问题是，政治共识是如何塑造的呢？这个问题比较复杂，我今天要跟你讨论的，是总统选举制度在塑造共识中的作用。

我们上一讲主要分析了国会选举制度的政治效应。你应该知道，对于议会制国家，选举主要就是选议员。但如果是总统制，就要面对由谁当选总统的问题。

# 总统选举制度

你可能在想，总统选举制度有什么好讲的？不就是选民投票，然后得票最高者当选吗？事情还没有那么简单。不同国家的总统选举制度，其实是不一样的。不仅如此，总统选举制度，还会影响到政治共识的塑造，影响到政治力量的具体。

在进入具体分析之前，我要简单地介绍一下总统选举制度。主要就是两种。

一种是**一轮多数制**，就是在**一轮投票**中，得票最多的候选人当选总统，而无论他是否获得超过半数的选票；

另一种是**两轮制**，顾名思义，如果第一轮没有候选人过半数，那么，就需要对得票最多的两位候选人进行第二轮投票，**终局当胜**。

按理说，如果多数制投票结果非常非常，但为什么如今很多国家都采用两轮多数制呢？

# 一轮多数制的问题

我多年前出版过一本很有影响力的书，题目叫《我们真实的政治》，里面分析的一个题是——智利1973年的民主崩溃，我读到这的时候，就发现一个很大的问题。

1973年之前，智利的总统选举在实行选举时采取的是**一轮多数制**。有人追问的是，那当一个候选人没有拿到过半数，只超过半半数，还**没有**拿到足够的投票数时候怎么办？比如，**第一轮**投票，如果得票最高的候选人没有超过半数，就得由第二轮投票来决定。

就是在这种选举制度下，在1970年的总统选举中，阿连德以36%的得票率当选总统，**当选**。你看，他并没有过半数，**但当总**。

36%意味着什么呢？意味**着投票率**，有64%的选民是不支持他的。

你可能会说，没有过半数也无所谓吧。民主的应有之义，不就是**少数服从多数**吗？但反过来，**当选**的多数，也是少数。
