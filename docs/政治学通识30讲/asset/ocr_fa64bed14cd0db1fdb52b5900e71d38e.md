# 25 | 停滞后：为什么有的落后国家容易陷入“蒙博托陷阱”?

创新开·政治学课堂第130讲

我们上一课说到，如果一个社会没有形成国家秩序，没有形成权威认同，就容易出现暴力冲突。所以，这些国家的核心任务是什么？不是搞经济建设，而是必须先建立一个有效的政治共同秩序。

建立一个有效的政治共同体，其实主要是两个任务：一是在组织上，完成看得见的国家建构；二是在观念上，塑造大看得见的大国家认同。

但是，如果一个国家能做到这两点，是不是就高枕无忧了？其实，这是远远不够的。国家秩序基本解决以后，发展又成了迫在眉睫的任务。

# 发展中国家的“蒙博托陷阱”

从数据上看，不少落后国家都会陷入停滞或不发展的阶段，比如，南非国家刚果解放半个世纪，但人均GDP目前仍然只有500美元。这样的国家，就处于停滞状态。

那么，为什么会停滞多年？有一种观点认为，这是因为政治学家30多年。政治学家人蒙博托有，我发明了一个词，将这种不发展的停滞状态，称作“蒙博托陷阱”。

蒙博托1930年出生，刚果民主共和国当时是比利时的殖民地。刚果民主共和国，又刚果是利（金），这个“金”，是指它的首都是金沙萨。

蒙博托小时候家境贫寒，母亲是酒店女服务员，父亲是一位比邻贝时法国人的佣人佣佣。正是因为这些苦难，勤心的苦大民心变成了蒙博托的法语教习。所以，蒙博托从小就很精通法语。

1949年，蒙博托参加了比邻的刚果军队，服役7年，晋升至士兵下士。行于被政治部调入，接到任务，蒙博托1956年就从非军事院校毕业后，并比到特接受军事顾问培训。正是在此过程中，他结识了新奥蒙莫运动党，从而有机会进入未来的权力核心。

1960年，刚果民主共和国独立，年仅30岁的蒙博托被任命为刚果军队参谋长，由此就获得了机会来掌控政权。

很快，由于总统与总理的内讧，国家陷入了政治危机。蒙博托发动了一次军事政变，并在1965年又发动了第二次军事政变，从此握大权于一身。此后，一直到1997年被迫流亡，他统治了刚果（金）长达30多年。

但是，就是这样一个人，后来被国际社会视为非奥奥奥奥奥奥奥的独裁者。关于他为什社会有这样的恶名呢？关于他统治刚果（金）的节，我们无须一一讨论。大致来说，蒙博托的统治有三个特点。

第一个特点是依靠裙带关系进行统治。

蒙博托不仅自己大权独揽，而且还要把自己所在族群的亲戚、族人拔到重要岗位上。这种做法，看起来并不符合当时官僚行政的原职。但在蒙博托看来，这可以防止权力落到对自己有威胁的手中。

第二个特点是真狂地收取政治租金。
