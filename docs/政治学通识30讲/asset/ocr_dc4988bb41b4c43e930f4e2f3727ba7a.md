# 18 | 央地关系：分权模式好，还是集权模式好？

“我们前面几讲，讨论的都是中央层面的制度设计，这一讲我想提供一个制度设计的视角，你应该容易理解。任何一个较大的规模的国家，都面临着中央和地方如何分配权力的问题。有人更主张地方分权，有人更主张中央集权。那么，究竟什么是对的？这一讲，我们就要分析央地关系模型的政治逻辑。”

# ### 分权模式的优势

一般来说，很多学者更支持地方分权模式。为什么地方分权模式更受欢迎呢？理由似乎是显而易见的。第一个理由是，它自始至终运动与思考，使地方分权能更好地掌握决策者和知情方。可以想象央地关系复杂的决策过程和支持方。从这个意义分，地方分权，是一种激励机制。

比如，1787年《美国宪法》就规定，凡是宪法没有规定由联邦政府执行的权力，都归州或居民保留。于是，这两类权力之间因为美国宪法没有赋予联邦政府对各州征税的权力，因此，如果各州政府有征税的权力过少，就可能引发各州之间的竞争，而为了避免税收竞争失控，就形成了各州争相减税、降低税率，甚至通过税收优惠吸引企业的现象。

第二个理由，它是更容易理解，比方中央先制定、各地区执行这些政策，地方政府就处在贴近本地市场实际位置，能更准确地了解各地民众的诉求，改变官员的惰性，可以避免我们日常说的“一刀切”问题。

比如，拿一个国家的土地政策来讲，如果由中央政府一刀切，由于农业省份和非农业省份的需求不同，就会带来政策与实际需要的不匹配。结果，一刀切的土地政策可能会在一些省份执行起来困难，而在另一些省份则可能浪费土地资源，导致效率低下。

第三个理由是，允许地方分权能更灵活。有人也许会说，分权模式下的地方政府会竞争，会有地方保护主义，这样会扭曲资源配置。但中央集权模式下，各省份的做法往往是类似的，但地方分权模式就不同了。

为了提高当地竞争力，地方政府可能会放开投资，吸引资金进入，或者采取税收优惠政策。在开放竞争模式下，政府会倾向于采取各种措施吸引人才，而人才是经济发展的关键。

# ### 分权模式的劣势

说到这里，你可能觉得，既然地方分权有那么多好处，那为什么不都实行呢？这里要提醒一点，分权也有代价。过度的分权可能导致中央权威削弱，甚至引发地方割据，影响国家统一。因此，分权模式需要与一定的集权机制相结合，才能实现国家的有效治理。
