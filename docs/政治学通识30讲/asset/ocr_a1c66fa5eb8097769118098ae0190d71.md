# 13 | 制衡：司法审查为何能约束民主权力？

上一讲的主题是，19世纪以来兴起的现代民主，成了人类经验出政治权力的终极解决方案。但是，新的问题又来了。

比如，现在这样一个民主国家，多数平民通过投票，制定一部剥夺少数人财产权的立法，或者多数族群要求少数族群，通过一个有限制少数族群权利的立法，这样的立法该无效吗？

这，就是当人民成为主权者之后，民主的权力是否还要约束的问题。

# 最高法院的司法审查权

我们这一讲，主要以美国司法审查制度为例，看看民主的权力是如何约束的。

众所周知，在美国总统、国会、联邦法院这三大权威机构，联邦法院是一个最弱小的机构，它既不像总统那样掌管军队，控制官僚机构，又不像国会议员那样手握立法及预算约大权。那，联邦最高法院如何发展出制约总统与国会的权力呢？

这里要为你介绍一个关键概念，叫作司法审查权，又称违宪审查权。这种权力的出现，可以追溯到美国历史上著名的“马伯里诉麦迪逊案”。

我们先简单说一下这个案子的背景。

美国第二任总统约翰·亚当斯在1801年任期之前，突击任命了一批地方治安法官，其中一个人叫马伯里。但是，当时的行政机构，没有那么高的办事效率，这个任命文书还没来得及发出，新总统就上任了。

随后，新任国务卿詹姆斯·麦迪逊就扣留了这份文书。这一封文件被扣留，总统任命就没有发出，新的执政者就不认了。

这样一来，马伯里就不干了，明明我已经被任命了，他要么告诉我一个理由，就不认了，那等于说，他要想告诉我一个理由，就不认了，那就是，马伯里诉麦迪逊案。这个案子的判决发生在1803年。

这个时候，美国的首席大法官正是后来大名鼎鼎的约翰·马歇尔。这个案子可以说非常棘手，因为被告是新任总统的国务卿。

而且当初，最高法院的院长是立宪时参议员的一致，当时的最高法院议员还只有一个办公室都没有，不得不借在国会大厦一楼的一个小办公室里审理案件。

如果你是马歇尔，你想让司法变得更为强大，你会怎么办？你会想办法让马伯里赢，为国赢得辅助吗？表面看起来，确实赢得了一战。

但是，对于手无寸铁的最高法院来说，这一判决可能会引起恐慌，因为最高法院与最高法权之间的正面冲突。一旦引发这种冲突，最高法院是没有任何武器的。显然，总统领导的行政部门在力量上要强势得多。

所以，马歇尔并没有这么干，他试图用另一个办法来解决这个问题。他直接驳回了这个案子。

为什么呢？因为这个案子不应由最高法院来审。那么，这是这个案子的上诉或通缉吗？不是。其实，马歇尔这样做，最终是为最高法院赢得了一张真正的王牌。

原来，马歇尔下到一个绝手，马伯里希望收到联邦最高法院发出的依据，是国会1789年通过的《司法条例》的第13条。但马歇尔说，不对的，这部宪法规定的那一条。

《美国宪法》第3条第2款规定，只有涉及大权、公权，领事以及一方为外国当事人的案件，联邦最高法院才可以为审理。除此之外的案件，都不应被法院直接受理，而应被法院管辖，作为一个地方治安官的官司怎么能直接到联邦这儿？

所以，马歇尔最关键的一招是，这件具体的事非曲直，我不管了，我要管的是，1789年的《司法条例》是违背了宪法的，这个法律的13条该被驳回。

然后，马歇尔在判决书中说了一个很重要的话，强调说，构成国家基本法律和制度的法律，远不及宪法所赋予的无上的权力。所以，违宪的法规，依然是司法部门的职权和责任。

说到这里，你就明白了，马歇尔的聪明之处在于：

+   1. 他驳回了具体的案子，避免了跟总统、国务卿之间的正面冲突。
2. 他借助于《美国宪法》为依据，审查一立法是否违背宪法，这就是所谓的“司法审查权”。
