# 12 | 民主：现代民主是如何成为可能的？

我们上一讲的主题是英国议会的演化。到了19世纪，英国以议会为中心的制度模式已经逐渐定型。这种模式强调了立宪主义、法治、议会主权、责任内阁、政党关系等概念。

但是，到1832年为止，英国仍然只有4.4%的成年公民拥有投票权，大部分普通民众并没有获得投票权。此后，从1832年到1928年，英国经过多次选举改革，才落成了普选权，实现了完全的民主化。

照美国情况说，美国1787年制定了宪法，明确了总统、参议员、众议员经由选举产生的原则，但最初众议员只能由少数人投票选出。此后，投票权开始缓慢扩展。

到1828年，美国所有白人成年男性公民都能投票选举总统。白人的投票率到了90%。至于非白产，种性，性别的选择权，美国要到20世纪60年代才完全落实。

那么，问题来了：为什么直到19世纪，民主才逐渐成英美国家的主权呢？

# 政治力量和权力结构

我们前面讲过，已经揭示了这样一条定律：对很多人来说，权力是一个“好东西”。如果一个人能拿到权力，他通常是不会放弃二个人的。反之，如果一个人能拿到权力，他通常不会放弃。

而促使一个人放弃他人分掌权力的唯一原因，就是政治风险中的边际收益。当选得无力的局面时从其内部，维持了更大政治风险时，也会使得其放弃或与他人分享权力。这时候，政治权力的结构，才会发生改变。

这样的例子非常多。

比如，当军团内部和平民士兵手在战争中变得重要时，很难维持的民主制才逐渐兴起。

再比如，到了中世纪，价格昂贵的重装骑兵成为主力，一个重装骑兵的装备，相当于二十五户普通农民的家产。所以，只有富人才有可能装备重装骑兵，这就强化了封建主义的权力传递。

这里还有一个例子。在古代4世纪中期，法国王权的王权受到贵族挑战。王权通过联姻，将贵族纳入其麾下，形成了王权。王权的王权，这里的王权王权贵族，尤其是王族。简单来说，当贵族家族实力增强时，君主就不太愿意建立一个由王权独统治的贵族，这就是王权们协商的一个结果。

再比如，当《撒维多王》的作者布鲁斯·普洛维诺提出过一个例子，1865年到1990年比利时一个国家的民主制，成功地把比利时这个君主立宪制变成了一个立宪君主制。但与此同时，他在斯堪的纳维亚的殖民统治。

同一个国王，宽政不同的时候，为什么呢？原因：在当时，他的合法性必须建立在很多因素才能维系统治；而在后来，他只靠少数人满意，就能轻而易举地统治。

其实，日常生活中也有类似例子。在一个企业里，如果一个人或两类人，不投股票往往是不可行的。这也说明企业越是靠创新、越是需要创新的企业，则相对越缺少权力。

所有这些，都揭示了另一条重要的政治原则：政治结构，其实是社会结构的最终表现。也就是说，政治结构就是社会结构的映射，或者用更专业的术语说，是“上层建筑”对“经济基础”的反映。

# 普通民众进入政治舞台

按照这个逻辑，民主制兴起的前提，是普通民众拥有了更大的政治力量。那么，原因是呢？答案是：从18世纪晚期到19世纪，英美国家所发生的经济变化，逐渐造就了这样一个更加平等的社会。越是平等的社会，人与人之间政治力量的差距就越小，就越大机会成为民主化力量。

英国所发生的这种社会变迁，包括了封建主义的衰落、资本主义的崛起、工业革命的发生，城市化进程的推动等等，所有这些，导致了一系列重要的后果。
