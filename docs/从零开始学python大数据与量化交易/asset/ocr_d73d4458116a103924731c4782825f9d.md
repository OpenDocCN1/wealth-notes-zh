# 表 3.3 字符串格式化符号及意义

| 字符串格式化符号 | 意 义 |
| --- | --- |
| %c | 格式化字符及其 ASCII 码 |
| %s | 格式化字符串 |
| %d | 格式化整数 |
| %u | 格式化无符号整型 |
| %o | 格式化无符号八进制数 |
| %x | 格式化无符号十六进制数 |
| %f | 格式化浮点数字，可指定小数点后的精度 |
| %e | 用科学记数法格式化浮点数 |
| %p | 用十六进制数格式化变量的地址 |
