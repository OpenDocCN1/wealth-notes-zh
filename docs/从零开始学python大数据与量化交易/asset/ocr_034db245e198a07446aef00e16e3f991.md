Sharpe 的计算公式为

Sharpe Ratio = (R_p - R_f) / σ_p

式中：

R_p —— 策略年化收益率；

R_f —— 无风险利率（默认为 0.04）；

σ_p —— 策略收益波动率。

# 14.5.4 Sortino（索提诺比率）

Sortino 表示每承担一单位的下行风险，将会获得多少超额回报。

Sortino 的计算公式为：

Sortino Ratio = (R_p - R_f) / σ_pd

式中：

R_p —— 策略年化收益率；

R_f —— 无风险利率（默认为 0.04）；

σ_pd —— 策略下行波动率。

在回测详情页面中，单击左侧列表框中的 Sortino，就可以看到 MACD 指标量化策略的 Sortino 信息，如图 14.20 所示。
