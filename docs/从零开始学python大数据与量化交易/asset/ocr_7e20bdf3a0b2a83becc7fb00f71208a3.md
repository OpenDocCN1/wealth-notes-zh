这是 print 语句的实例。print 并不会真的往纸上打印文字，而是在屏幕上输出值。

利用 print 语句，不仅可以输出英文，还可以输出汉字。在 Python 3.6.5 Shell 软件中输入以下代码：

```
print ("欢迎您！Python")
```

然后按 Enter 键，就可以看到程序运行结果了，如图 2.17 所示。
