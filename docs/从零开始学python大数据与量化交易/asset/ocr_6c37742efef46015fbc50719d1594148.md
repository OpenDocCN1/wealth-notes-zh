# 14.5.8 Max Drawdown（最大回撤）

Max Drawdown 描述策略可能出现的最糟糕情况和最极端可能的亏损情况。

Max Drawdown 的计算公式为：

```
Max Drawdown = Max (Pₓ − Pᵧ) / Pₓ
```

式中：Pₓ,Pᵧ——策略某日股票和现金的总价值。
