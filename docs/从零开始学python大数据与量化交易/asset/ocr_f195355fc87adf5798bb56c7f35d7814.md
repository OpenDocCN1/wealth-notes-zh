# 8.4 三维数组 Panel

获得股票数据 get_price()函数，如果获得的是多只股票的数据，则返回 Panel 对象。可通过 panel[列标,行标,股票代码]获取数据。

成功登录聚宽 JoinQuant 量化交易平台后，在菜单栏中选择“我的策略”→“投资研究”命令，打开“投资研究”页面。双击 Pandas 文件夹，然后单击“新建”按钮，在弹出的下拉菜单中单击 Python3，新建一个 Python3 文件，并命名为“三维数组 Panel”，然后输入以下代码：

```
import pandas as pd
panel1 = get_price(['000001.XSHE','000009.XSHE'],start_date='2018-09-3', end_date='2018-09-10', frequency='daily')
panel1
```

运行结果如图 8.27 所示。
