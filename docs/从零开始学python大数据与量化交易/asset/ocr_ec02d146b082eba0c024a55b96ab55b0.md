阵，它是左上和右下元素的乘积与其他两个的乘积的差。换句话说，对于矩阵[[a, b], [c, d]]，行列式计算为 ad-bc。较大的方阵被认为是 2×2 矩阵的组合。在 Python 中，是利用 numpy.linalg.det()函数计算输入矩阵的行列式。

矩阵的行列式示例如下。

```
import numpy as np
a = np.array([[1,2], [3,4]])
print("矩阵的行列式:")
print(np.linalg.det(a))
b = np.array([[6,1,1], [4, -2, 5], [2,8,7]])
print("较大的方阵的数据: ")
print(b)
print()
print("较大的方阵的行列式: ")
print(np.linalg.det(b))
print()
print("较大的方阵的行列式的计算方法: ")
c=6*(-2*7 -5*8) -1*(4*7 -5*2) +1*(4*8 --2*2)
print("6*(-2*7 -5*8) -1*(4*7 -5*2) +1*(4*8 --2*2)=",c)
```
