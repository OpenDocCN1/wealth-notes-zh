# 12.2.6 销售净利率选股

销售净利率是指企业实现净利润与销售收入的对比关系，用以衡量企业在一定时期的销售收入获取的能力，其计算公式如下：

销售净利率=净利润 ÷ 销售收入 × 100%

销售净利率反映每一元销售收入带来的净利润的多少，表示销售收入的收益水平。

销售净利率与净利润成正比关系，与销售收入成反比关系，企业在增加销售收入额的同时，必须相应地获得更多的净利润，才能使销售净利率保持不变或有所提高。
