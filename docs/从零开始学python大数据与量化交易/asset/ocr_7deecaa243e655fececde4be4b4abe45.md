# 3.3.2 赋值运算符

赋值运算符及意义如表 3.5 所示。

# 表 3.5 赋值运算符及意义

| 运算符 | 意义 |
|---|---|
| = | 简单的赋值运算符 |
| += | 加法赋值运算符 |
| -= | 减法赋值运算符 |
| *= | 乘法赋值运算符 |
| /= | 除法赋值运算符 |
| %= | 取模赋值运算符 |
| //= | 取整除赋值运算符 |
| **= | 幂赋值运算符 |

赋值运算符示例如下。

单击“开始”菜单，打开 Python 3.6.5 Shell 软件，在菜单栏中选择 File→New File 命令，创建一个 Python 文件，并命名为 Python3-6.py，然后输入以下代码：

```
a = 45   # 为 3 个变量赋值
b = 5
c = 0
c = a + b
print("a + b 的值为: ",c)
c += a
print("c += a 的值为: ",c)
c *= a
print("c *= a 的值为: ",c)
```
