# 8.2.2 从 ndarray 创建一个系列

如果数据是 ndarray，则传递的索引必须具有相同的长度。如果没有传递索引值，那么默认的索引将是范围(n)。其中 n 是数组长度，即[0,1,2,3···.range(len(array))-1]。

从 ndarray 创建一个系列示例如下。

成功登录聚宽 JoinQuant 量化交易平台后，在菜单栏中选择 “我的策略” → “投 资研究” 命令，打开 “投资研究” 页面。然后单击 “新建” 按钮，在弹出的下拉菜单 中单击 Python3，新建一个 Python3 文件，并命名为 “从 ndarray 创建一个系列”，然 后输入以下代码：

```
#导入 pandas 和 numpy 包
import pandas as pd
import numpy as np
#利用 ndarray 为系列赋值
data = np.array(['a','b','c','d'])
s = pd.Series(data)
print("显示系列中的索引和数据: ")
print(s)
print()
data = np.array(['a','b','c','d'])
t = pd.Series(data,index=[100,101,102,103])
print("显示系列中的索引和数据: ")
print(t)
```
