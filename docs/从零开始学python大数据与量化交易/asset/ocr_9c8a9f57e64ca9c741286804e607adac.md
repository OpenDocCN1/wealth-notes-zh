# 图 3.2 数值类型

有时需要对数值类型进行转换，数据类型转换时，只需要将数值类型作为函数名即可，具体如下。

+   - int(x)：将 x 转换为一个整数。
- float(x)：将 x 转换为一个浮点数。
- complex(x)：将 x 转换为一个复数，实数部分为 x，虚数部分为 0。
- complex(x, y)：将 x 和 y 转换为一个复数，实数部分为 x，虚数部分为 y。
