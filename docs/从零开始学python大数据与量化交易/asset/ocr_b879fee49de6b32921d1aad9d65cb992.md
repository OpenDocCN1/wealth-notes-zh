# 15.4  因子在研究和回测中的使用

在研究以及回测中，可以通过调用 calc_factors()函数来计算单因子分析中定义的因子值。calc_factors()函数的语法格式如下：

```
calc_factors(securities, factors, start_date, end_date)
```

各参数意义如下：

securities: 用来设置股票代码列表。
