下面创建文本文件，然后再读出其中的内容。在新建的单元格中输入代码如下：

```
c = np.array([1,4,3,6])
np.savetxt('mytxt.txt',c)  #创建文本文件，并保存数据
d = np.loadtxt('myxt.txt')
print("成功读取文本文件，然后显示：")
print(d)
```
