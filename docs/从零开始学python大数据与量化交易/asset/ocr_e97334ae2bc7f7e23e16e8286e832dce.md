# 9.6 legend()函数的应用

legend()函数是用来为图像添加图题的，其语法格式如下：
legend(*args, **kwargs)

参数是一个可变长度参数，其中最常用、最重要的可选参数是 loc 参数。loc 参数的字符与描述如表 9.3 所示。

# 表 9.3 loc 参数的字符与描述

| 字 符 | 描 述 |
|---|---|
| 0 | 由 matplotlib 确定最优位置 |
| 1 | 右上角 |
| 2 | 左上角 |
| 3 | 左下角 |
