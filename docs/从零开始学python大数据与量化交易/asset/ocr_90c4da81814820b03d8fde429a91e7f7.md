# 16.7.2 编写选股函数

选股函数，即选出沪深 300 医药指数成分股中市净率最低的医药股，具体代码如下：

```
def chenk_stocks(context):
    # 得到沪深 300 医药指数成分股
    g.stocks = get_index_stocks('000931.XSHG')
    # 查询股票的市净率，并按照市净率升序排序
    if len(g.stocks) > 0:
        g.df = get_fundamentals(
            query(
                valuation.code,
                valuation.pb_ratio
            ).filter(
                valuation.code.in_(g.stocks)
            ).order_by(
                valuation.pb_ratio.asc()
            )
        )
    # 找出最低市净率的一只股票
    g.code = g.df['code'][0]
```
