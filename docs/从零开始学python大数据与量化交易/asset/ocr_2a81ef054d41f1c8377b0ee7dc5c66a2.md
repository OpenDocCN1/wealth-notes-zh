显示所有的收盘价信息，代码如下：

```
dataframe1.loc[:,"close"]
```

运行结果如图 8.19 所示。

使用位置选取数据，语法格式如下：

```
df.iloc[行位置,列位置]
df.iloc[1,1] #选取第二行、第二列的值，返回的为单个值
df.iloc[[0,2],:] #选取第一行及第三行的数据
df.iloc[0:2,:] #选取第一行到第三行（不包含）的数据
df.iloc[:,1] #选取所有记录的第二列的值，返回的为一个 Series
df.iloc[1,:] #选取第一行数据，返回的为一个 Series
```
