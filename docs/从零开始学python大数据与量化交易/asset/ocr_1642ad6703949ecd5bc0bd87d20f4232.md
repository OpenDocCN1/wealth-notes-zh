# 7.3 Numpy 的矩阵

矩阵（matrix）是一个按照长方阵列排列的复数或实数集合，是高等代数中的常见工具，也常见于统计分析等应用数学学科中。

Numpy 的矩阵对象与数组对象相似，主要不同之处在于，矩阵对象的计算遵循矩阵数学运算规律，即矩阵的乘、转置、求逆等。需要注意的是，矩阵使用 matrix 函数创建。
