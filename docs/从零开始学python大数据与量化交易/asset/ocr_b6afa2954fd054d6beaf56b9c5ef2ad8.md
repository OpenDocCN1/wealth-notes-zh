通过逻辑指针进行数据切片，语法格式如下：

```
df[逻辑条件]
df[df.one >= 2] #单个逻辑条件
df[(df.one >=1) & (df.one < 3)] #多个逻辑条件组合
```

显示收盘价大于 5.10 的数据信息，代码如下：

```
dataframe1[dataframe1.close>5.15]
```

运行结果如图 8.22 所示。

![](bbox=[0.17, 0.605, 0.87, 0.82])

显示收盘价大于 5.15 并且成交量大于 26000000 的数据信息，代码如下：

```
dataframe1[(dataframe1.close>5.15) & (dataframe1.volume>2600000)]
```
