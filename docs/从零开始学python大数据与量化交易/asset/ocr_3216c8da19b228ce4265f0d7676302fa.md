# 4.4 集合

集合（set）是一个无序不重复元素的序列。集合可分两种，分别是不变集合和可变的集合。

# 4.4.1 集合的创建

可以使用大括号 { } 或者 set() 函数创建集合。需要注意的是，创建一个空集合必须用 set() 而不是 { }，因为 { } 是用来创建一个空字典。创建集合的代码如下：

```
student = {'Tom', 'Jim', 'Mary', 'Tom', 'Jack', 'Rose'}
a = set('I love python')
b = set()
```

# 4.4.2 集合的两个基本功能

集合的两个基本功能是去重和成员测试。

去重是指把一个还有重复元素的列表或元组等数据类型转变成集合，其中的重复元素只出现一次。

成员测试即判断元素是否在集合内。
