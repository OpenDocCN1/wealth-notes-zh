# 图 2.20 创建一个 Python 文件

在 Python 文件中输入以下代码：

```
print ("第一个实例：逐个显示'Python'中的每个字母！")
for letter in "Python":      # 第一个实例
    print ("当前字母 :", letter)
print ()
print ("第二个实例:")
fruits = "banana", "apple", "mango"
for fruit in fruits:      # 第二个实例
    print ("当前水果 :", fruit)
print ("输出完成，再见!")
```

其中 print （）表示输入一个空行。

然后在菜单栏中选择 File→Save 命令，弹出“另存为”对话框，保存位置为默认，即 Python 安装目录下，文件名为 Python2-1，如图 2.21 所示。
