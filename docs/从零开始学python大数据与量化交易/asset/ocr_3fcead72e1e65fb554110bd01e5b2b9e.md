print 语句还可以跟上多个字符串，用逗号 “,” 隔开，就连成一串输出。在 Python 3.6.5 Shell 软件中输入以下代码：

```
print ("This is ","a book!")
```

然后按 Enter 键，就可以看到程序运行结果了，如图 2.18 所示。

![](bbox=[0.26, 0.19, 0.78, 0.4])
