```
import numpy as np
from matplotlib import pyplot as plt
x = np.arange(1,25)
y = 6 * x + 11
a = np.arange(1,8)
b = 3 * a - 6
plt.figure()
plt.plot(x,y,"oy",a,b,"*r")
plt.show()
```

# 9.4 subplot()函数的应用

利用 subplot()函数可以在同一图中绘制不同的图形，其语法格式如下：

```
subplot(nrows,ncols,plotNum)
```

注意：subplot()可以将 figure 划分为 n 个子图，但每条 subplot 命令只会创建一个子图。
