# 12.2.3 净利润同比增长率选股

净利润是指企业当期利润总额减去所得税后的金额，即企业的税后利润。净利润是一个企业经营的最终成果，净利润多，企业的经营效益就好；净利润少，企业的经营效益就差，它是衡量一个企业经营效益的主要指标。

净利润同比增长率的计算公式如下：

净利润同比增长率＝（当期净利润－上期净利润）÷上期净利润的绝对值×100％

净利润同比增长率选股示例如下。

成功登录聚宽 JoinQuant 量化交易平台后，在菜单栏中选择“我的策略”→“投资研究”命令，打开“投资研究”页面。双击“量化选股”文件夹，然后单击“新建”按钮，在弹出的下拉菜单中单击 Python3 命令，新建一个 Python3 文件，并命名为“净利润同比增长率选股”，然后输入以下代码：

