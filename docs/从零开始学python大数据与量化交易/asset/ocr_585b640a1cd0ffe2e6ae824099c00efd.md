# 从零开始学 Python 大数据与量化交易

企业开办当初投入的资本，包括溢价部分；另一部分是企业在经营中创造的，也包括接受捐赠的资产，属于所有者权益。净资产的计算公式如下：

净资产=资产-负债

净资产收益率是企业税后利润除以净资产得到的百分比率，该指标反映股东权益的收益水平，用以衡量企业运用自有资本的效率。指标值越高，说明投资带来的收益越高。该指标体现了自有资本获得净收益的能力。净资产收益率的计算公式如下：

净资产收益率=税后利润 ÷ 所有者权益 × 100%

净资产收益率选股示例如下。
