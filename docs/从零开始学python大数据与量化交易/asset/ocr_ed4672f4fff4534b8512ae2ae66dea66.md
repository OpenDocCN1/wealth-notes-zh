双击“系统变量”列表框中的 Path，弹出“编辑系统变量”对话框，然后在“变量名”文本框中添加 Python 的安装路径，即 C:\Python36。需要注意的是，路径一定要用分号“；”隔开。

在环境变量中添加 Python 目录后，在 Windows 系统命令行程序中输入以下代码：

```
Python -h
```

然后按 Enter 键，就可以看到 Python 的相关信息了，如图 2.13 所示。
