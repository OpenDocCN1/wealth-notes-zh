# 8.1 Pandas 的数据结构

Pandas 的数据结构主要有 3 种，分别是 Series、DataFrame 和 Panel。

（1）系列（Series）是一维数组，与 Numpy 中的一维 Array 类似。二者与 Python 基本的数据结构 List 也很相近，其区别是：List 中的元素可以是不同的数据类型，而 Array 和 Series 中则只允许存储相同的数据类型，这样可以更有效地使用内存，提高运算效率。

（2）DataFrame 是二维数组，非常接近于 Excel 电子表格或者类似 MysQI 数据库的形式。它的竖行称为列（columns），横行称为索引（index），也就是说，数据的位置是通过 columns 和 index 来确定的。可以将 DataFrame 理解为 Series 的容器。

（3）Panel 是三维的数组，可以理解为 DataFrame 的容器。

# 8.2 一维数组系列

系列（Series）是由一组数据（各种 Numpy 数据类型）以及一组与之相关的标签数据（索引）组成。仅由一组数据即可产生最简单的系列，也可以通过传递一个 list 对象来创建一个系列。需要注意的是，Pandas 会默认创建整型索引。
