**Step2** 把參數帶入歷史行情做驗證。

**Step3** 了解此套參數的利弊得失、機率分布，以及應有的心理調適。

**Step4** 學習調整參數的知識。

**Step5** 練習調整參數的方法，包括均線的「優化（最佳化）」過程。

**Step6** 適度地提醒自己何時應該彈性調整參數。

# # 優化系統參數的方法

以均線為例，參數「優化」的基本知識如下：

+   （1）每個金融市場的參數不一樣。

+   （2）每個波段，尤其是上升波段的參數，可能需要適度調整，但不能搞的差異過大。

+   （3）每隔數年，參數可能會有一次比較具有規模的變動，但不會跟之前的差太遠。

+   （4）每支股票，參數都不太一樣。

+   換句話說，如果你同時操作五支股票，可能會碰到三至五套不同的參數。

+   （5）每支股票，在不同的年代（時間週期），參數會不太一樣。
