# 程式交易不保證能找到長期獲利的聖杯

> 目前電腦的人工智慧依舊無法取代贏家所有的智慧，所以投資人不可以過度依賴電腦交易系統！

一位聽過我演講的讀者，寄了一封信給我，談到電腦交易系統的問題。我相信，很多業內都會遇到這類問題，其實一般投資人也會遇到，因為現在很多人會買交易軟體，每個月還要固定繳交傳輸費，花費十分昂貴。所以關於這方面的问题，是跟大家滿密切的，而非遙遠。
