# 決定勝負的關鍵：
少去預測、做好準備

> 儘量少去預測，老老實實把「將來如果上漲」以及「將來如果下跌」的雙向準備都做好才行。

很 多自以為是技術派老手，在市場上待了很久，對形態學最重要且基本的心法卻一無所知，很不應該，但這種現象卻是相當普遍。

一種型態，當它還沒有正式成熟之前，我們可以去看它，也可以不去分析它，箇中的選擇端看你的操作系統來決定！有的贏家會去看型態，有的則不看，並不是說「型態學是一門正式的學問」，就規定每個人非用不可。

如果我的操作系統把型態看得很重，那麼，我就要去分析它。例如，分析盤勢如果往上的話，是屬於哪一種漲升型態？這種漲升段，在更恢弘的大格局裡是否有更重要的涵義？漲上去該怎麼辦？我們該怎樣應變？該做好怎樣的心理準備？……如果往下的話，是屬於哪種下跌型態？這種下跌
