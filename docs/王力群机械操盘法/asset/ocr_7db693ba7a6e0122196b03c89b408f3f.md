# 如何熬過抱單的歲月？（下）

> 波段操作，要懂得放下自己的妄想，才能正常地過生活、正常地思考。放下，並不只是一個動作，更是一種方法、一種需要不斷學習才能了解的智慧。

長久以來，很多人一直有個誤解，以為那些所謂的「贏家」在進場之後，一定能克服各種情緒的干擾，然後不花什麼力氣就獲利發財——依我個人的經驗與觀察，這真的是一項嚴重的誤解。

或許贏家們可能真的像他們說的那樣「克服」許多種情緒的衝擊，但那是經過奮鬥而換取來的代價，並不是悠閒地叼著雪茄、懷中抱著美女、悠悠哉哉喝著紅酒就能談笑用兵、輕鬆一筆帶過——確實是有贏家這樣操作，不過請相信我：能做到這種悠閒境界的贏家，絕不是一開始就能做到這樣，一定也曾經歷練過痛苦、掙扎、徬徨，也有過半途而廢、背叛自己的信念。反觀一般人在這種情緒淘汰賽中，不但身心受創，連帶對自己的正確操作法也失去信心，把金鑰匙當成
