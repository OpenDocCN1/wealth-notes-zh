# 二、算出要進多少部位？

確定交易部位的第一步，是確定用市場價格波動性（用其N 值定義）表示的價值波動性。至於價值波動性可用下面公式表示：

價值波動性 = N × 每點的價值

海龜法是依照一個「單位」（Units）來建立部位。1 N 代表帳戶資金的 1%。因此，市場或商品的單位可用下面的公式表示：

單位 =（帳戶資金的 1%）÷ N

舉例來說，台股指數期貨的交易：

+   * N = 100
* 帳戶規模 = 1,000,000 台幣
* 每點價值 = 200 元（以台幣報價的一大口台股指數期貨合約）

單位 =（1,000,000×0.01）÷（100×200）= 0.5 大口，也就是兩小口。
