# 另一種分批賣出法

這樣的操作法有好幾種，以下是第二種「堪用」的方法：

Step1 跌破第一道短天期支撐，賣出三分之一。

Step2 再往下跌破第二道支撐，再賣出三分之一。

Step3 再往下跌破中線支撐，賣出最後的三分之一。

Step4 如果恢復中線關卡，則大原則是往上分批買回原來

的部位的。

Step5 如果還沒有賣完就出現止跌反彈，則視狀況分批往

上買回失去的部位的。

這個方法的優點是，如果跌勢持續，執行起來會很機械

化。對於善於執行紀律的操盤手而言，很好。缺點是：第五

個步驟執行起來有難度，因為「視狀況」表示這裡面帶著預測成分。

操作者必須了解，這兩種分批賣出法在不同的下跌狀況，

會有不同的報酬率，很難說哪一個最好。

學習技術分析，就是要學著了解自己所使用的這個方法之

優點跟缺點。這個道理很深很深，不只股市適用，人生的很多領域都適用。
