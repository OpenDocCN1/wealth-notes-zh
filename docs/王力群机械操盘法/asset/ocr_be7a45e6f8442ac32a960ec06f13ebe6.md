+   （4）買進以後，如果順利的話，就依照 N 值開始計算加碼要加多少部位。

+   （5）買進以後，如果順利的話，做短線的人是看到最近十天的最低價就賣出；做中線的人是看到最近 20 天的最低價就賣出。

+   （6）買進以後，如果不順利的話，損失 2N 的時候就停損出場。
