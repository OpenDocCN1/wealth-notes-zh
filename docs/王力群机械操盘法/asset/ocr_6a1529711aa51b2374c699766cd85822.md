# 不猜頭摸底，
盡力把現在該做的事做好

> 盤中思考是一種極危險的動作，因為在盤中，我們很難成為一個理性的人。為了避免盤中思考，贏家們才發明了機械法。

看 完前一章，各位大概可以了解一點機械法的基本概念。機械法就好像是一種很固定的操作流程，人工干預的成分比較少，也很像是機器人，都缺乏「自由意志」（自由意志是你在當初設計那個機械系統時就要顧慮到的，而不是在啟動機器之後還去懷疑那個機器）。
