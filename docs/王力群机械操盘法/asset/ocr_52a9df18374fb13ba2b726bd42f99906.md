+   * Step1 準備好台股的历史資料庫，要有每日收盤行情（券商提供的免費軟體都會有）。

+   * Step2 把自己使用的機械法條件列出，至少應有「進場條件」跟「出場條件」兩大部分。

+   * Step3 逐日檢視每日收盤價，收盤價（或盤中價，視交易系統不同而定）符合進場條件則進場。假設買進，買進價位為 A。

+   * Step4 繼續逐日檢視每日收盤價，收盤價（或盤中價，視交易系統不同而定）符合出場條件則出場。假設前一個動作為買進，現在應為賣出價位 B。

+   * Step5 A 減 B 等於 C，再乘以部位的單位之後，C 就是本筆交易的獲利或虧損。

+   * Step6 繼續逐日檢視每日收盤價，收盤價（或盤中價，視交易系統不同而定）符合進場條件則進場。也就是重複步驟 3～5，得出多筆交易的盈虧，最後計算總合，驗證績效。
