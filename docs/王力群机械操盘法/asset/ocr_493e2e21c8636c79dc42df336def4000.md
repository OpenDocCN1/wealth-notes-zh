# 「不知道」也是一種對戰技巧

> 學習技術分析，除了充實知識外，還要學習「不知道」的勇氣：勇敢承認自己不懂，不要因愛惜顏面而裝懂。

人 不是神，即使在經年累月的看盤經驗中，磨練出一點預測的能力，但也沒辦法在每一年、每一個月、每一天，都把這個預測能力維持在「堪用的狀態」，更遑論長期維持在「最佳狀態」了。

很多時候，我們就是不知道。「不知道」並不可怕，可怕的是「明明不知道，卻裝作知道」。

學習技術分析，除了充實知識外，還要學習「不知道」的勇氣：勇敢承認自己不懂，不要因愛惜顏面而裝懂。
