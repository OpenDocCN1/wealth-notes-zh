# 花錢的時候，「嚴以律己，寬以待人」

離開日本之後，我的生活改變了。

一開始我也提過，基本上我個人每個月日常生活花費是一萬泰銖（約新台幣九千兩百元）。

我目前的淨資產差不多有七十億日圓。可是今年因為市場崩盤，我也不可能全身而退，所以資產幾乎沒有增加，光是要維持現狀就得費盡全力。儘管如此，我明明有那麼多淨資產，每個月卻只花一萬泰銖，各位或許會覺得我很小氣吧。

如果這樣叫做小氣，就姑且當作是這樣吧。
