# 没必要一味地追赶新事物

想要赚钱时，你的视线总是会看向新事物。但这也是陷阱之一，请务必小心。

这世上，新术语接二连三不断地出现又消失。例如：區塊鏈（Block Chain）、人工智能、5G 行动通讯、数位转型（Digital Transformation）……这些关键字之中，的确有些东西已经成为社会潮流，但问题在于这些东西是否真的改变了世界。「區塊鏈」这个词最流行的时候是二〇一七年左右，三年过去了，世界并没有因为區塊鏈技术而有了不同的样子。也就是说，人们往往操之过急，去接触那些号称「世界最先进」、「前所未有的商品或公司，白白浪费宝贵的时间和金钱。但那些新技术究竟有害归无害，是否真的有用还不知道。

结论就是，没必要为了赚钱而进入世界最先进的领域。若问我要如何选择，我认为最重要的是先攻克早就已经存在、无可动摇的领域。

举例来说，最近出现一种机器人顾问。所谓机器人顾问，一言以蔽之就是利用全自动的 AI 代替客户投资的服务。也有提供投资建议的机器人顾问。

现今媒体大肆报导机器人顾问，极力推荐投资新手采用，但我对此完全没有好评。
