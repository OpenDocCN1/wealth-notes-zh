# 坦白自己丟臉的一面，是好的開始

只要看過那些黑心企業被爆料後的應對，你應該就能夠明白老實承認錯誤的重要性。多數企業遭到爆料後，往往因為害怕大衆的批判而隱蔽事實，最後導致情況更加難以收拾。假如企業高層在事情剛爆發的階段就出面道歉，或採取必要的因應措施，事情多半可以好好收尾不會鬧大；還有企業在事情剛爆發階段就乾脆站出來公開一切，反而能獲得大衆的讚賞。也就是說，一開始就把膿瘡擠乾淨是處理傷口最好的方法。承認錯誤的話，丟臉只是一時的；若還有隱匿的真相，最好在被人揭開前就自行公開。這樣做雖然需要莫大的勇氣，但總好過之後信用盡失，演變成無可挽回的下場。
