# 即使是賺錢達人，進了賭場也會血本無歸

我身邊有不少人沉溺於賭場，全都無法戒賭；只要一陣子不去，就會引發癱瘓等戒斷症狀，因此每個月要上好幾次賭場。

二〇一八年夏天，我和一位朋友去新加坡的濱海灣金沙酒店，親眼目睹那位朋友在隔壁賭桌輪掉六千萬日圓。這位朋友是土木engineering公司的老闆，工作認真，一年可以賺到一億日圓以上，而他卻把那些收入全貢獻給了賭場。

還有大王製紙<sup>23</sup>前董事長井川意高的例子。

井川前會長在澳門和新加坡的賭場欠下鉅額債務，為了取得更多賭金，他從旗下七家公司不當融資了總金額約一百零五億日圓（約新台幣一千二百一十九億元），權充私人使用。這件事也出現在他的自傳中，我就不再贅述。

結果就是，當事人井川前董事長以特別背信罪遭到逮捕，不僅要坐牢，創辦人井川一族的所有成員也都必須卸任大王製紙的管理階層職務。

值得一提的是，井川前董事長畢業於東大法學系。如此優秀的人卻也輸給人類天生對快樂物質的渴求。我與對方兒過幾次面，他的個性很好，充滿魅力，除了沉溺賭博這點。
