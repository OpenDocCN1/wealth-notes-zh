# 交換「ZZZ」會讓你遠離有錢人之路

人際關係也是同樣的道理。

在你存下軍費三百萬日圓的過程中，人際關係會成為一大阻礙。原因在於，與人來往就免不了聚餐、婚喪喜慶等各類活動。光是受邀參加婚禮就會花掉不少錢。

因此，即使別人對你的做法有意見，但我認為做出「不出席」的決定很重要。你會因此覺得尷尬，事先斷絕與朋友之間的交流，也不失為一種方法。

假如你是透過社群網站或「ZZZ」與人交際，也容易因為已讀不回之類的小事，被人批評你白目、不會做人。好友名單限制在十或二十人就非常足夠了。貫徹不交換「ZZZ」的原則，你就能夠解決時間與金錢損失的問題。乾脆這麼想吧，每次跟人交換「ZZZ」，你就離有錢人之路愈來愈愈遠。所以不用「ZZZ」也是一種停損。

以我現在的情況來說，一個禮拜頂多傳一次「ZZZ」，而且是跟妻子。我們就住在一起，所以平常沒必要用「ZZZ」；我也不會傳「ZZZ」給妻子以外的人。你或許會覺得我的做法太極端，但這樣對我來說剛剛好，不會有壓力很舒服。
