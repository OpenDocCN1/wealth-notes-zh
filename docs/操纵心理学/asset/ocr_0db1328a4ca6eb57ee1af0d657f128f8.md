# 威胁
负面的预期

为了让操纵失效，你需要向操纵者说明你知道他的目的，而他为了私利使用的操纵性手段是不会有用的。

这一抵抗手段就像是这样的：

> “我知道你想让我替你做这件工作，但你的威胁是不会有用的。”

“我知道你想让我明天和你一起去，但对我冷暴力、忽略我是不会让我就范的。”

“我知道你想要我做你希望的事，但是你的怒气、咒骂和捶桌对我来说不会再有用了。”

最好的练习方式是将步骤 4 与步骤 5 结合起来，这就像一套组合拳。你会告诉操纵者，你现在知道他究竟在做什么，以及更重要的是，你对于他的手段是什么样的反应。然后你会告知操纵者，尽管你知道他想要什么，但曾经的手段已经再也无法让你屈服了。

# 步骤 6：设置你的条款

随着你实践这些抵抗手段，你会感觉到自我的重现。
