# 弥天大谎

操纵者的最终手段，就是“弥天大谎”。正如我们之前讨论的，操纵者的控制往往是建立在获益承诺以及规避损失、恐惧或其他坏事上的。一旦受害者被这样的承诺诱骗，操纵者的游戏就开始了。操纵者可能会利用所有强化手段和之前说到的控制方法让受害者为了获益或避开损失而持续地服从自己的需求。
