# # 反社会人格障碍

有这种人格障碍的人，终其一生都会实行不负责任的行为模式，并且毫不关心他人的权利、社会规范、良心指令或法律。这一人格障碍具有显著的性别差异，被诊断出来的男性远远高于女性。
