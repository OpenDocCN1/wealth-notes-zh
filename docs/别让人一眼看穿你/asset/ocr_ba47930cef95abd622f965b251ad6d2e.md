# 別讓人一眼看穿你
戳心與藏心的攻防智慧

關於低頭聳肩的自我保護意味，你可以想想這樣的情形。比
如，在你居住的社區裡一群孩子在踢球，當你走過他們的時候，
突然聽到有人喊：「當心，看球。」即便你並沒有看到足球朝你
飛過來，也會下意識地把頭低下，縮在兩肩之間。因為你希望用
這樣的姿勢保護自己的頭部，以及柔弱的脖子和喉嚨，避免受到
撞擊。

大部分人在潛意識裡都清楚這個動作的保護意味，所以當他
們可能受到外界攻擊時就很容易做出這個動作。

低頭聳肩是一種自我保護，更是一種信心程度的表達。所
以，如果是在交際或商務談判場合，要是你想展現信心十足的面
貌，那麼就千萬不要做出低頭聳肩的動作，否則會讓你的形象大
打折扣，想藏心更是難上加難。
