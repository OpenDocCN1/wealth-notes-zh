# 目 錄

# STEP 1

# 抓漏：想藏心，先找出破綻 7

生活中的各個動作、表情、言語，都可能充滿破綻，若想「藏心」，我們就需要找到自己的破綻，然後想辦法將其隱藏起來。

# STEP 2

# 釋放：不生氣，拋開憤怒情緒 31

生氣除了讓自己不愉快，又能改變什麼呢？這難道不是用別人的錯誤懲罰自己嗎？與其為別人的錯誤而生氣，還不如努力給自己爭口氣！

# STEP 3

# 放下：不煩躁，克制得失心 65

煩躁不安，有著無法克制的衝動，這一切都會被別人盡收眼底，成為你的弱點。人應該克制自己的焦躁，讓處事更有心機。

# STEP 4

# 自主：不盲目，養成獨立思考的習慣 103

太過服從，別人能輕易瞭解我們下一步要做什麼；太過服從，所以我們暴露了自己的內心。
