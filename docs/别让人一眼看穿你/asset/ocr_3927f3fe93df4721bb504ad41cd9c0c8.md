# 別讓人一眼看穿你
讀心與藏心的攻防智慧

當初他們約定，只要大盜把債券一拿出來，躲在衣櫃裡的 FBI探員就可以衝出來當場把大盜捕獲，但是大盜遲遲不肯拿出債券。

等到最後大盜終於上當，四人從衣櫃裡衝出來的时候，第一個人已經熱得暈了，連手裡的槍都拿不住而掉到地上，其餘三個人則脫得幾乎一絲不掛。

雖然場面十分可笑，但 FBI探員們還是成功地完成了任務，把這兩個大盜當場捕獲，並且還搜到了他們以前偷到的債券，數目總共達六百萬美元之多。

案例中的 FBI探員，如果因為自己的處境非常糟糕就大發雷霆，衝出去的話，他們就不可能完成自己的任務。

人生不如意時有八九，成敗之間僅有一線之隔。面對不如意的事情，我們必須屏棄頭腦中的慣性思維，不要把人生的大好時光消耗在怨天尤人的情緒當中。

如果你熱愛自己的生活，首先就要學會正確的引導自己的情緒，掙除心裡愛發牢騷的雜草，專心致志的投入，只有這樣才能獲得成功。
