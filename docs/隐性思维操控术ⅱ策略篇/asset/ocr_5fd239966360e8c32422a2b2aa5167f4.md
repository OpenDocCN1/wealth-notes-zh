正式运用互惠关系定律的操作过程中，我们要掌握以下小技巧：

+   1. 要了解对方，并给予对方理解。只有充分了解对方，才不会
“吾之蜜糖，彼之砒霜”的情况发生。而给予对方理解正是一种
最基本的互惠，这是对对方尊重，是获得对方对你的肯定的前提；
否则，很容易引起对方对你的“反射性”否定，进而产生负面效果。

+   2. 要经常表达感激之情。心理学家指出，人际交往是向着酬资
增加和代价减弱的方向发展的，随着时间的推移，物质酬资给人的
满足感会越来越弱，而心理酬资则不会。因此，要想满足对方越来
越多的酬责需求，只有选择心理酬资才是明智的，而感恩正是心理
酬资的一种主要方式。

另一方面，经常表达感激之情能够感染对方，让他也知道感恩，
使互惠的结果得以保证。

+   3. 永远不要抱怨。我们必须知道，在付出到获得之间，有一个
时间过程，有时这个等待的时间会远远超过我们所预期的。如果这
时我们抱怨，那么之前所有的努力都会白费。
