# **8.平息他人愤愤不平的情绪**

很多時候，對方之所以厭惡你、找你的麻煩，是因為你讓他產生了一種不滿足感、讓他感覺憤憤不平。那麼，面對這種人際困境，應該怎樣處理呢？

我們知道，人會因為獲得、擁有某些東西而產生滿足的心理體驗。然而，到底獲得什麼東西、擁有多少才能讓人滿足呢？正所謂“千人千面”，每個人對此的答案都是不一樣的。比如：一個非常有钱的人，他又得到了一大筆錢，這時候他該滿足了吧？事實上，只要他得到的錢沒有達到自己的預定目標，他仍然會憤憤不平地抱怨自己沒有錢。同樣的，“普通百姓”雖然只是得到了為數不多的資產，但由於達到了他的心理預期，他們會覺得非常滿足。

也就是說，一個人對現狀是否滿足，往往取決於其要求水準的高低，而這個要求水準則是根據一個合理根據設定的。因此，你可以通過給出不同的合理根據來任意設定對方的要求水準，進而達到讓對方憤憤不平還是滿足的目的。

以工資報酬為例。假設某一個工薪階層的人拿到了5萬元的年終獎金，那麼他是否會為此感到滿足呢？事實上，他能否滿足於這樣的獎金數額，並非取決於數額大小本身，而是取決於那個決定其要求水準的合理根據是怎樣的。
