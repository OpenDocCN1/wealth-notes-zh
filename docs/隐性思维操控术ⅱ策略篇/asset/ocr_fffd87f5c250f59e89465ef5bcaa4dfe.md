# 9.投石问路，探知对方内心的需求

威廉·约翰斯是乔治·巴滕公司的负责人，而德斯坦是巴顿·德斯坦·澳斯本公司的负责人。有一天，这两位在美国广告界赫赫有名的人物偶遇了。在这次偶遇中，约翰斯成功地探知了德斯坦的需求，进而促成了广告史上最大的一次合作。

当时的情形是这样的，约翰斯非常随意地对德斯坦说："前天晚上，我忽然发现我们两家公司销售渠道并没有什么实质性的冲突。"

德斯坦听完，立刻问到："你什么意思？"

约翰斯看着德斯坦一副着急却又故作平静的样子，"啊，其实也没什么。"边说边笑着走开了。

几个星期后，当两人第二次会面时，规模宏大的合作——成立巴顿·巴尔顿·德斯坦及澳斯本股份公司的讨论正式开始。

约翰斯抛给对方一句意味深长、让人费解的话，然后小心翼翼地观察对方的反应，进而探知了对方心理需求。的确，当对方对某一事物具有需求的时候，如果你含糊的语言正好碰触到他心中的需求，他就会表现得十分敏感。由于德斯坦心中有和约翰斯合作的需求，因此当约翰斯说到彼此销售渠道没有冲突的时候，他才会表现得如此敏感。
