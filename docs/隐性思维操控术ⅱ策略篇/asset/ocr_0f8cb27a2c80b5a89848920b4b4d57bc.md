# 6.创造良好的交谈氛围

20世纪70年代，心理学家亚历山大等提出了情境同一性原理。他们指出，对于每一种社会情境或人际背景，人都有一种最合适 的行为模式与之相匹配，这种行为模式与其情境具有同一性，故称为情境同一性。

在与人交往的过程中，人们发现，如果双方都能处于情感共鸣的状态中，那么这样的交往能在很大程度上促进彼此关系的发展。而心理学家认为:在交往过程中，人与人之间感情的认同和共鸣，是通过当时特有的情境刺激所形成的互通和互相感染的结果。因此，在进行社交活动时，我们应该积极创造情境同一性。就此，心理学家提出了以下几个建议：

1.创造好的交往环境。人所处的环境，包括地点、气氛等一系列因素，都会影响人的情绪。在人际交往中，选择一个舒适的、气氛融洽的环境，能使人的情绪处于良好状态，从而更容易进入交往状态。防失联V: 357607890
