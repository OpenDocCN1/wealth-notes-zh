# 1.挺身而出，承担责任

曾经有一个经理人向我提问，他说，“刘老师，我的团队当中每个人都想发挥领导力，我该怎么办？”我说，“我从来没有见过这样的团队，发挥领导力需要解决集体的难题，实现共同的目标，不是每个人都做的。你说的很可能是这样一种情况，他们每个人都想当领导”。

不知道你有没有观察到这样一种现象，大多数人都想当领导，只有少数人发 licht 发挥领导力。当领导意味着更高的地位，更大的权力，更多的金钱，这是大多数人都想要的。而发挥领导力，意味着挺身而出，承担责任，解决大家面对的一个集体难题，这只有少数人才有兴趣。如果 ...

# 2.说“我来”不是本性

有人可能觉得，“我来”很容易，不就是两个字吗？张嘴就来，其实说“我来”是不容易的，这不仅仅是两个字，这是一种挺身而出，承担责任的心智模式，这不是大多数人的本性。

+   1. 追随者是随大流，人越多越安全，有利于在原始环境中的生存；
2. 追随者通过模仿来学习，避免了试错过程中可能带来的危险代价。比如说看见曹操去尝荤，这个时候追随者就比领导来得更安全。

# 3.案例：南多的领导力

刚才我讲到的凶杀案是因为没有人说“我来”，所以变成了悲剧。下面我给你讲几个有人说“我来”的例子，因为有人说“我来”，因为有人挺身而出，所以变成了领导力的案例。

这个故事发生在1972年，有一架飞机从乌拉圭飞往智利，因为天气恶劣，坠毁在了安第斯山脉，这个飞机上有45个人，其中有5名机组成员，其他的人是一支大学...在飞机坠毁之后，45个人之中还有32个人幸存。

+   1. 他有想法，要自己走出大山，而不是等待救援；
2. 他有信心，在飞机失事的几天后，大家从收音机里听到消息，说救援者找不到他们，停止救援了。听到这个消息之后，大多数人都绝望了，都失去了目标。但是，南多没有，南多坚定了要走出大山的信心；
3. 他有行动，南多开始说服大家，鼓舞大家，让大家相信他的想法是可行的，组织大家做准备工作；
4. 他做表率，做好准备之后，他亲自带着一个同伴上路去寻求救援。

# 4.“让我来”与“跟我来”

我再讲一个例子，遵义会议，这是你非常熟悉的历史事件，是中国革命的转折点。遵义会议也是这样一个案例，是毛泽东挺身而出说“我来”，而且说得既有勇气，又有技巧。

“我来”可以有不同的说法，面对上级和上级，你可以说“让我来”。让我来干什么呢？让我来承担责任，解决组织面对的一个问题。在遵义会议上，毛泽东就相当说了“让我来”，他作为一个政治局委员，他没有坐在哪里等总书记和常委解决问题，而是挺身而出，承担解决问题责任。而且毛泽东很有技巧，根据当事人回忆，在遵义会议后，周恩来、张闻天都认为毛泽东可以当总书记，但是毛泽东说他不当，毛泽东挺身而出，他说的是“让我来解决问题”，而不是“让我来当领导”。这是毛泽东在当时非常有领导艺术的地方。
