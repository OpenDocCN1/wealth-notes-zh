# 留言精选

猫大哥曾俊龙 关注 21
权利的概念，我是这么理解的。

+   儿子面对老爸：
1、听我的，我给你钱（报酬权利）
2、不听我的，我揍你（强制权利）
3、我是你爸，必须听（合法权利）

+   儿子面对老师：
1、我听老师的，他肯定对（专家权利）
2、我听老师的，我喜欢他（参照权利）
3、我听老师的，他说的对（信息权利）

直对老爸时，儿子是被逼的。（职位权利）
面对老师时，儿子是自愿的。（个人权利）

儿子被逼着干活，肯定要推着走。（推力）
当儿子是自愿时，你走哪他跟哪。（拉力）

LS 9
如果我是被动同意，那是推力。
如果我是主动同意，那是拉力。

推力和拉力是中性词，分场合分情景，各有特点。
当我是被领导者，我会积极思考哪种力在起作用，如何借力用力。
当我是领导者，我会积极思考什么力配什么情景，推力和拉力变化调整。

不求成为伟大的领袖，但求成为自己的领袖，急躁推自己一把，松懈了拉自己一把

# 作者 回复

的确，有时要用推力，有时要用拉力。但是，正如德鲁克说“营销的目的是让推销变得多余”一样，“领导力的目的是让职位权力变得多余”。所以，领导力侧重于拉力。

青岛罗刚 5
老师今天讲的六种权力都可能用上，根据题意，双方意见开始时并不一致。

+   1、报酬：上司说，照我说的做，给你加奖金；
2、强制：上司说，照我说的做，否则扣奖金；
3、合法：上司说，我是领导听我说，错了我负责；
4、专家：上司的经验丰富，相比于自己，你更相信他；
5、参照：上司是你学习的榜样，你愿意服从他；
6、说服：你觉得上司说得有理，而且和你的想法其实不矛盾。

高手使用权力，重在达成目标，不用气势压人，却能让对方心甘情愿地服从。
