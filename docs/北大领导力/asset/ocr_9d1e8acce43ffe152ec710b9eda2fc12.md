# 划重点

领导者最重要能力是提问，而领导者要问的最重要的问题就是“你觉得呢”。这个问是涉所以说的谦虚的提问，符合他所说的第三种谦虚。

下一次，当下属从向你请示工作的时候，你知道该怎么说了。你说，我不知道，你觉得呢？你也可以跳过我不知道，直接问：你觉得呢？

最后留一个思考题：
下次来请示上作，问：这个问题怎么办？你说：你觉得呢？下属说，我就是不知道才来问你的啊。那么这个谈话该怎么继续呢？

面对别人的就是不知道，我一般有两种提问方式。提问之前我会根据对方的回答，主观的先做一个判断，这是完全没思考的不知道，还是有过思考卡了壳的不知道。

面对卡壳的不知道，我一般会问他，能分享下你的思考过程吗？或者会问“是不是过程中有什么问题吗？”然后根据他的思路再行分析。
面对完全没思考的人，我会再把问题抛一遍过去，问他“假如现在你是x，你会怎么办？”
