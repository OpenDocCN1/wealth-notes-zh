22讲 反思的本质是对思考再思考

好啦，最后总结一下，反思实际上为我们提供了一种从第一视角、从他人角度和从第三人称视角看待问题的能力。

# 1. 在行动中反思

企业何时能够进行一次真正有效的反思？这取决于CEO的反思能力。反思能力不是与生俱来的，而是需要训练。反思是一种主动的、在行动中、在行动之后进行审视的习惯。

# 2. 反思的本质

可能有人会问，为什么在反思中提到反思？反思的本质是什么？实际上，反思就是对思考本身的再思考。也就是对我们已有的经验、已有理解的再认识。

# 3 回头看一不是反思

回头看不等于反思。很多人把复盘当成反思，但复盘只是对过去的回顾，而真正的反思是对思考方式的质疑和重建。

# 4 带着问题

带着问题去思考，才能真正进行反思。问题是反思的起点，也是推动思考深入的动力。
