# 总结：

我给你总结一下这一讲的要点。在这一讲，我们围绕“我说个故事……”这一口诀，不仅复习了老内容，而且学习了新内容。我们复习的老内容是领导力故事的两大要素和四种重要的领导力故事。

# 划重点

三种创新讲故事的方式：用道具讲故事，用仪式讲故事，用行动讲故事。
之所以说它们是创新，因为它们都不是用嘴讲故事。用嘴讲故事属于倾听-感受-改变的变革模式，这两种方式属于两种更创新的变革模式：一个是科特所说的目睹-感受-改变，另一个是我提出来的体验-感受-改变。
