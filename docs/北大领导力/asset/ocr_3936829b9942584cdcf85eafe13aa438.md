# 须菩提 1

+   1.我教你五层次
1 管教：照我说的做
2 说教：我说给你听
3 身教：我做给你看
4 请教：请你来教导我-你说怎么做？-仍然关注事情
5 传教：请你告诉我：你为什么这么做？—进入意义层面。

一二三属于管理者：我来告诉你。教练四五才算进入领导力层次。老师

2.五层次是一个组合工具，高层次并不能简单代替低层次方式。

3.一般认为能够做到言传身教，身口如一的就已经是好领导了。现在加深理解，认识到还需 要依恃、循循善诱，让管理人员能够做到真正理解自己所做的事情在更大层面上的意义。

4.看到过很多人说过自己的领导“蠢”：公司初到一领导，我向他汇报，想要获得决策支持的时候，他问：一般情况下，会怎么做？你觉得我们应该怎么做？为什么这样做？回答完之后，他说：好，就按你说的做。
在这一过程中，用到了请教和传教的方式，领导不傻，不是真的“什么都不懂”，不然如何敢放心让你折腾。

# 文明 0

最近一位团队成员和我一起出差，主要任务是完成一份方案报告并获得批复。同事脾气比较倔强，我和她的沟通，就不仅仅是我布置一下任务就能放手。

面对一项任务，她总是说这不是我的责任，应该他们来处理，这时候，我开始管教，我说，“凡事不要计较，按照我说的做”。当她开始做以后，我也会进一步说教，与她分析原因，这是一个团队，现在你在前方，我和你了解情况，我们一起处理。最后，她说“我请教你给我看”。面对业主的时候，首先让她解释。当她很难说服的情况下，我会接过来，完成最后的展示和论证。这是“我做给你看”。在准备资料过程中，有些技术问题超出她能力，我说，你在这水力学计算方面是专家，你比我重要，然后大家讨论。这就是“请教”。我觉得“为什么做”这一点，我没有做到，当然她也知道这次是为了这份报告，但是她认为，这就是她此次的全部目的，这是我没有做到位，我应该给她整个项目的图景，让她全方面了解，可能會有不同的理解。

不知不觉，有些方面已经在使用，但是对照之后，还是有差距。谢谢老师，我也要做个合格老师。
