# 第一天：投资银行：不做银行业务的银行

第一天我给大家讲述了投资银行的历史沿革。我告诉大家投资银行不是银行，在20世纪30年代之前，投资银行和商业银行是共存于传统的银行业务之中的。

![](bbox=[0.15, 0.24, 0.85, 0.3])

这样产生了问题，因为存款本来就是想要稳定的收益的，但由于证券投资商业银行的业务没有分家，所以这些存款流入了高风险的股市，结果在操纵融资的时候很多中小银行相继破产，搞得投资者和储户都叫苦不依。那么在这次危机之后，美国政府出台了法案要求分业经营，所以1934年以后，投资银行开始独立于商业银行而存在。

与传统商业银行追求稳定、厌恶风险、监管限制较多的特点不一样，投资银行则是追求高收益和低风险，监管限制比较少，所以它们会更加于资金创新，像货币基金、资产证券化、风险对冲，这些都是我们现在耳熟能详的金融模式，最早的时候都是起源于投资银行的。

![](bbox=[0.15, 0.38, 0.85, 0.44])

从第二天开始，我就给大家介绍了投资银行一类重要和基础的业务——发行承销。在第二天的时候，我给你介绍了发行证券发行承销业务的概念和特点，然后你知道了证券的开发知识，帮助企业设计融资的产品和方式，然后选择发行的地点，利用自己的营销网络把证券产品卖出去的过程。

# 第三天：发行承销（下）：想上市，你的招股说明书写对了吗？

第三天，我接着给你讲解了投行在企业上市发行中的重要性。比如由大承经常写的招股说明书，其实承实际的就是投行拟写的，它的主要目的就是给投资者介绍企业的经营、财务、优势和监管信息。这份文件也是联系交易者和监管机构沟通的重要文件，它特别体现了投行的包装能力和专业素养。

![](bbox=[0.15, 0.75, 0.85, 0.8])

在中国的A股市场上，企业上市和别的国家不一样，我们实行的是核准制。在这么一个背景之下，招股说明书会很大程度上决定企业上市的成败与否，这既使得投行很凸显出沟通的能力，在这么一个投行市场上显得特别重要。有时换一个招股说明书没有写好，会搞掉一些资质很好的企业不能上市。一些业绩比较普通的企业反而能够顺利上市。

![](bbox=[0.15, 0.84, 0.85, 0.89])
