# 划重点

+   1. 利息本质上就是时间的价值，费雪理论认为：利率的高低是由时间偏好和投资机会两个因素决定的。居民的耐心决定了资金的供给，而资金的投资机会决定了资金的需求，这个供需的均衡点其实就是资金的价格，也就是利率水平；
2. 费雪理论是有限性的。比如在他这个理论里面，时间偏好是外生给定的，也没有考虑到现实生活中的政府干预；
3. 作为基础的利率理论，费雪理论其实可以帮助我们解释很多生活中的利率现象。
