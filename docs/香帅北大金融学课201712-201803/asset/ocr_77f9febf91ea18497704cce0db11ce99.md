# ——金融从业者——

一我用到的方法，分享给你

+   1. 第一时间抢知识：
作为不用直接参与交易的金融工作者，手机随时都会推送，所以每天专栏更新的第一时间就会点开学习，这让我养成了固定时间学习固定内容"的好习惯，学习金融课成了我生活的一部分。

+   2. 定期复习促扎实：
老师的每周复盘，是构建知识体系的利器。为扎实，我还推荐大家看课程标准，努力回想每节课的小标题，进而回想具体内容，如果忘记，抓紧时间回，

+   3. 工作当中长本事：
我从金融工作，但是很多业务还不熟悉。一边学专栏里的理论，一边实践具体业务知识，学专栏可以让金融业务知识点成线，而工作场景让理论知识实际应用。实践和理论，相得益彰。

+   4. 系统学习当回溯：
专栏课程只是打开一扇窗，想要精进需要自己推荐的延伸学习，比如，我会阅读香帅老师的延伸导读，比如《千年金融》，而且，工作之余我会参加债券方面的培训，并计划参加今年12月的CFA考试。

学习就要应用到实际中去，这才是最有成就感的！借用吴军老师的一句话"我走过的世界，分享给你"，现在，"我用到的方法，分享给你"。

——看留言、看复盘、积极分享

首先，我是一名银行客户经理，每天上完香帅的专栏后，当时老师讲的东西太少，刚好是自己从事的领域，这可能帮助自己从不同的角度，去理解和加深体系知识体系，而且很容易就能把学到的知识结合到实际的工作当中。

另外，我非常喜欢看每一堂课程的留言，这其中有非专业背景的同学，这些有价值的留言不仅提升了我的视角，还散了我的思维。

而且，老师每周的复盘可以让我温故而知新，让我对整个学习体系和脉络都更加清晰。

最后，我也经常会把老师的课程通过微信发给身边的一家一人，同事，让他们也可以和我一些学习，一起成长！

# —在校大学生—

—金融帮我拉近与身边人的距离

香帅和各位新牛好！我是一名大三的学生，今天来来到得650点。对于香帅老师的专栏，我利用的是从古鲁师那改编的"IPO"学方法（Inputtheknowledge Problem solving Output).

I-知识输入(Input):在学校的时候，香帅的金融课是我每天上午的课间听讲，听课频道在香帅专栏更新后，我会反复听香帅的举例和逻辑推演，整个清晨在学习中变得特别清晰。

P-问题导向(Problem solving):在文未听到香帅提到的问题和思考，我会试图反向思考，甚至提出两种假设和金融学知识，结合自己的思考，形成自己的观点。

0-输出见解(Output):经过每周的学习和复盘，我就会把学到的知识讲给家里的长辈听，这总是我最充满成就感的收获。

身边人听我学习，习到很多。新的，希望是香帅的带动下，离金融更近，离身边的人更近。
