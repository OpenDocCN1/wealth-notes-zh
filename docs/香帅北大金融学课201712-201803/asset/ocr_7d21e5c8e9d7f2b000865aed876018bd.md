# 第一章 财富：过去、现在与未来的思考

财富是生存的根本，是支撑我们生活、工作乃至生命的基石。

从过去来看，财富曾由土地、金矿、奴隶和战争塑造。

而现在，财富更多由知识、技术、资本和全球化定义。

展望未来，财富可能因人工智能、能源革命和太空经济而重新分配。

你如何定义属于自己的财富？是金钱、时间，还是自由？
