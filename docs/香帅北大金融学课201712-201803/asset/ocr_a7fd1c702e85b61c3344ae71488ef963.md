我们在财经新闻里，经常会听到“降息”和“降准”这两个词，只要有这个消息放出来，市场上都会大涨大跌。仔细读这些报道，上市公司大涨，美股一拉，哪些股票受益。与之相反，只要说到“提高存款准备金率”或者“加息”的话就一片悲鸣。前两年，美联储一松一紧的可能性变大，全球股市就应声而歌。

很多人并不明白，这些金融现象背后其实是现代经济运行的重要逻辑：国家通过央行系统，调控整个社会的信用规模和经济冷热。

国家是怎么通过银行体系来调控经济的呢？首先，国家通过中央银行来发行货币，然后通过商业银行体系发行货币，进行信贷。如果把经济看做一台水利，货币体系就是水，而商业银行信贷就是水渠。商业银行是向水放贷，就是水渠大小决定的送水率，直接影响着社会上的信贷规模和经济增长。

在这个水利系统里有两个巨大的闸门。一个叫做准备金率，一个叫做利率。央行是要把存款准备金这个闸门头拉大一点，或者拧小一点，都会马上让我们感到，钱多或者就变贵了。

今天我要给你们讲的就是存款准备金这个信用扩张机制，明天再讲讲讲贷款利率是怎么得到调节货币的冷热。之后你也会明白，这些看上去高深莫测的金融“大词”，其实是和我们的财富、投资、就业，密切相关的。

# 一、存款准备金制度的货币扩张机制

我们先来看看，什么叫存款准备金。储户把钱存入银行，银行再放贷出去，然后形成企业、个人的资本投资，支出再生产。但是，每家都有自己的储户有现金的需求，所以银行必须留下一部分钱以应对储户随时提款的需求，这部分钱就被叫做存款准备金，这个留存的比例就叫存款准备金率。控制存款准备金率，就像控制水渠的闸门一样，可以控制整个社会的信用规模。

更有趣的地方就是，在通过银行体系的循环中，存款准备金会有一个放大的作用，关于存款准备金率的任何一个小幅度的调整都会引起社会信贷规模很大的变化。有一个著名的叫《货币风暴》，里面讲了一个哈佛大学的MBA学生的课堂实验，整个地还原了这个过程。

课堂上，让学生代表银行，其他学生代表一个银行的储户，规定：所有的银行存钱准备金率是10%，也就是说银行有100美元，必须留下10美元，然后把剩余的90美元放贷出去。有个学生拿到了90美元贷款，这笔钱会存在其他银行的保险，然后这些钱也拿不出另外一家银行的保险，然后这些钱会循环下去。这个过程可以不停地循环下去，假如银行体系按照10%的现金准备金，最后我们社会上的流通的货币量有多少呢？猜一下，一定比你想象的多。

一笔100美元的存款，按照10%的存款准备金率流动，最后可以让我们整个社会流通的钱达到1000美元。那个时候在旧美市，100美元就是大富翁。这个1000美元就是货币流通。1000美元就是货币扩张了10倍，这个倍数其实算一下，就是存款准备金率的倒数10，所以也叫货币乘数。

好了，现在有了这个概念之后，你就知道了，如果觉得市场里钱太多，或者太少，它是可以通过存款准备金率来把信用率放大的。比如说现在钱太多了，就要把存款准备金率提高到20%，那货币乘数变成了10÷0.2=50。这样100美元就只变成流通了500美元，流通就变少了。同理，要是央行觉得经济过冷了，就去调低准备金率，比如调低到5%，那货币乘数就是20倍，原来100美元就变成2000美元了。所以说降准就是降低存款准备金率，也就是给经济放水。那储蓄存款准备金率就是收紧经济。

因为市场上钱变多了，投资机会也变多了，大家的机会变多了。

# 二、影响货币扩张的几个现实因素

好了，刚才我们讲了，调节存款准备金率可以改变货币乘数的倍率，社会上的钱会成倍地变大或者变小。但是如果把这个例子，其实就是个理想化的假设，在现实的过程中，银行的行为更为复杂。比如银行放贷的意愿，我们每个人、企业的货币持有量，都会影响到货币扩张的机制。

比如说，我们刚才假设的是银行会把除了存款准备金以外的所有钱都全部放贷出去。但是想一想，现在的假设经济情况不好，银行不会担心，贷款收不回来，那银行宁可不放贷也放在账上，它才会把钱留在保险柜里。那在银行的行为里，银行也不会把这个90美元全贷出去，只放贷50美元，这种情况也是有可能存在的。如果每个银行都这样存一倍一倍，即使央行大力地降准，但由于银行的放贷意愿降低，可以说经济的放大也大打折扣。比如哪一年，这个20年来最大的一次经济发生在哪一年呢？1998年。当时存在的现金资金率从13%降到了8%，但是1999年的经济增长速还是上不去，GDP增速仍然比创了90年代以来的最低水平，原因是什么？就是大家都悲观，银行不愿意放贷出去，所以即使降准，信贷规模也起不来，所以银行放贷的意愿会影响到信用扩张的机制。

另外个一个，就是我们个人和企业现金的持有量。最典型的一个例子是过元旦的时候，大家不会感觉到，到现金的地方比春节少，尤其是老年的春节，单位也会发奖金，朋友、亲戚之间要发红包，你还去大型购物场所，所以现金的使用量会节日期间进行很大。现在不一样了，可能会全部存进银行。现在在支付宝、微信上，你只用掏一部分钱，那它就会导致你的货币扩张机制被锁住了。过一年，央行得放一点水，来充实社会货币的投放，其实就是为了给这个货币扩张的机制来补充水。
