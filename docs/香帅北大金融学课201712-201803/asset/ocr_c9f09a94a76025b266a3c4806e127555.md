# 一、投资组合一风险分散的魔法

投资组合就是指按照一定的比例把资金投在组合中不同资产上。和单一个证券相比，投资组合最大的优势就是"分散风险"，通过基金投资的基本原理，就是投资组合。

那你怎么理解投资组合能分散风险呢？在经典的金融学教材里有这样一个例子，假定我们有一笔钱要做股票，目前你面前有两种股票，收益都是8%，而收益（这里指衡量风险的指标）都是25%。这两个股票之间的相关系数就是0.3，换句话说，也就是一个股票上涨0.3个单位时，另外一个大概率会下跌或者上涨0.3。

现在我要问，你是将所有的钱全部放在只买股票上，还是做一个投资组合，在两只股票上各投50%的资金呢？很多人凭直觉都会选择前者。既然风险数和风险都一模一样，不如全部都放在一只股票或者都是50%，不是挺好的吗？但在这个简单案例中，一半资金投在同一个股票上，每只股票上投入50%的资金，你的收益确实没有改变依然是8%，但是投资组合的风险下降到16.25%，换句话说，用投资组合的风险，比单一个股票的风险下降了35左右。

好了，现在我们继续把这个投资组合里的股票数目增加下去，4只、5只、6只股票，你会发现一个特别奇特的现象，随着股票数目的增加，你估计这个投资组合的风险呈现出单国下降的一个趋势。当股票数目增加到100的时候，风险已经下降到7.68%。

你可能会觉得个疑问，是不是股票的数目越多，风险就会永久地下降到下去，直到为零呢？不是这样的，当组合中包括的股票达到一定数目后，风险就会降到一个稳定的水平，那我们再增加股票数目，就没有效果了。

今天我们继续探索，为什么拥有多股票的投资组合比单个股票的投资风险更低呢？其实这不是魔术，而是一个简单的数学原理。多个变量组合的方差等于这些变量的方差，加上各变量之间的相关系数。这些变量在方差中的权重，然后再加上方差。这在数学上叫做协方差。

```
公式: $\sigma_P^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_i \sigma_j \rho_{ij}$
```

即使看不懂，也不影响你对这个问题的理解。我举个例子，你就会明白这个数学公式的背景原理。

你可以想象一下，物理世界里面的分子，它们的运动方向和速度都不是同一的，在这个运动，有的粒子都是，假设只有两个分子，它们以0.3的相系数在运动，那么其中有一个分子加多就会抵消掉。当很多很多的分子加入到这个运动的时候，中间更多的力量会被抵消掉，然后逐渐呈现出一种稳定的状态，这就是为什么我们观察到，随着投资组合中股票数目的增多，风险会逐渐降低。因为不同的股票，它的波动不是统一的。它们之间的不一致性会将部分的波动抵消灭了，这就是分散化效应(risk diversification reduces risk), 这也是我们刚才对我向大家说，更加广泛投资得基金能够更加有效地分散风险。

# 二、投资组合理论一华尔街第一次革命

刚才你知道了，分散化是如何降低风险的，其实市场上有很多人早就在有意识地采用这种方法。但是直到1952年，这个逻辑才被马科维茨写一个大学科茨的博士生挖出来的，然后形成了一套系统的金融模型。

了解到投资组合可以有效的降低风险之后，马科维思考虑了一个非常本质性的问题，在我们组建投资组合的时候，我们应该在哪些上投资多少资金，才能够获得最高的收益，承担更少的风险呢？用个隐术话来说，就是我们怎么才能够帮助那个最低的风险投资降到低呢？

马克维茨通过长期的思索以后，得出了一个简单，但非常天才的解答。他把由所有证券的投资比例作为变量，然后就针对资产配置问题进行了设计一个数学规划，对每一个固定的收益水平求解最小方差。或者对每一个方差水平去求解最大的收益。解好一多系数方程，就可以找到使投资组合收益最大，或者风险最小的投资决策。

在数学上，他的模型是如此简单，以至于马科维茨在芝加哥大学的博士生都解不了。但是华尔街可不管这一套。投资者们迅速的意识到，这个模型提供了一套科学、量化的框架，只有足够多的历史数据，就可以准确的找到投资组合，也是从这个时代开始，投资从一门经验和艺术逐渐向科学和技术转变。而知识，技能是可以通过后天的系统化学到获得的。

更重要的，在这个线性规划中。如果设计的证券数目越多，这个线性规的运算就会复杂。再增加，我们目前就没办法做了。随着这个理论的流行和使用，各个商学院学院的金融系的教学就开始转向数学方法来体现。基金业的从业人员也开始朝着越来越多量化方向发展。

所以，当我们说到基金有"分散化"和"专业化"两个特征的时候，这并不是两个独立的词条，他们背后是有着一个统一的理论逻辑支持。更重要的是，现代金融学的几乎所有分析，都是脱胎于马科维思的"风险一收益"这个框架。我们接下来讲的课程量是讲的更多因。都在这两个分析框架为相对简单也是因为他。这一经就是为"太高"的，因为其为其他的风险，在1990年时候获得了诺贝尔奖。
