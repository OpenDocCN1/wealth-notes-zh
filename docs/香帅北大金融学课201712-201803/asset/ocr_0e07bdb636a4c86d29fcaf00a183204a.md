# 011 | 比特币的未来在哪里？

你好，欢迎来到香帅的北大金融学课。

比特币可能是这两年货币市场上最让人困惑的事情了。前几周，比特币价格突然跌了2万多美元，这几天又飙“升得”下来了，减少了差不多一半的价格。 很多国人脑内的态度明确，今年9月份的时候，我们国家把所有的大货币交易所全部关闭了；另一方面，很多人仍坚持认为比特币会取代现有货币，成为未来世界的通用货币。

比特币到底有没有未来？这个讨论其实牵涉到一个现象，就是我们现在在聊的这些货币，人民币也好、美金也好、英镑也好，它们底质是什么？你可能考虑过很多经济学的素材，按照传统教材的思路，货币计量上量单位，货币交换媒介、价值储藏的手段，看上去比特币是满足这几种标准，但是这讨论都忽视了一个很重要的事情，我们使用的这些货币，它们的真名叫做“法币”，这些货币是 国家或者某个银行（比如中央银行）的一种特许权力而发行的，它背后的关键是国家信用。

# 一、现代货币的背后是“国家信用”

我们先来看一个具体的例子。我们都知道美元现在是全球货币体系的核心，任外的贸易都要用美元结算，各国在发行外债都要用美元，国际大宗商品、石油、天然气、铁矿、矿石，都是用美元计价的。可能有人会问，美元一定是法币，他是怎么来的呢？是在布雷顿森林会议上确定的。

二战以后，各国代表在一个叫布雷顿森林的地方开会，当时争论的一个关键问题就是拿什么货币作为国际货币体系？德国和美国国家是大家都一致的。美国的代表是经济学家大家都知道的经济学大师凯恩斯，他提出的方案是建立一个名叫怀特货币体系的货币，用一种叫做“班克”的国际支付单位，用这个去计价。但1946年的激烈争吵以后，怀特战失败了。大名家鼎鼎的凯恩斯爵士，布雷顿森林会议确立了美元的发行权。这是为什么呢？很简单，美国当时实在太强大了。它的经济总量增长到全世界的经济总量的1/4，还有全世界2/3以上的黄金储备。欧洲各国当时要战后重建，都要仰仗美国的贷款，所以说货币的权力之争，公道根本就不在人在，不在国家里，在什么？在布雷顿森林会议上，美元理所当然就成为了国际计价储备的储备货币，变成了国际货币体系的核心。

到了70年代以后，各国的经济已经开始复苏，美元自然就开始面临着贬值压力。美元一贬值，黄金的价格就飙了。最后美国干脆宣布美元和黄金脱钩。美元的法币不再受黄金储备的限制。只和美国的经经济增长和国债规模有关。但是到这个时候，美元的国际化地位已经固定了。美联储已经成为了事实上的世界央行。随着美元黄金的脱钩，全球货币都跟美元挂入了一个完全的信用货币时代。这个信用不是私人信用，而是国家的国家信用，这就是美元的利美之冠。那美元到底是如何成为世界币之三的呢？从故事里面，我们可以得到一条非常简单的原则，现代的货币信用货币，货币价值的浮动完全取决于一个国家的实力和其他国家对于这个国家的信心。

所以说没有国家信用加持的货币，即使可以成为计价、储备、交易的媒介，它也不能成为货币的基石。还有一个逻辑其实可以解决我们很多生活中的困惑，为什么人民币这些年国际化的地位上升？因为中国的经济实力增强了。为什么欧元一开始在欧洲动不起来？因为大家对欧共体的信心下降了，然后为什么在10年代日元又风光无限。因为90年代又在发钱呢？归根到底是对这些货币背后国家控制的信心。

# 二、国家和银行一起，重新塑造了货币概念

货币的发行，其背后的国家信用才是核心和关键。其实，在货币发行的过程中，还有一个枢纽就是中央银行，是中央银行通过拿到国家赋予的法定货币发行的货币发行权。实际上这里体现出来的是一个重要特征，国家和银行是交织在一起的，塑造了信用货币的概念。这个过程其实也是一脉相成的。也是慢慢由历史演化出来的，其中英格兰银行在中间扮演了一个特别重要的角色。

回头看看历史，我们前面说到欧洲在十四五、十五世纪的黄金，已经出现了比较完整的银行业，很多银行发行的汇票都可以在市场上流通，用来支付和计价。银行的纸币概念已经在欧洲流行了。但银行券这样的纸币也慢慢地在欧洲市场上流通了。这个时没有一个银行发展的发行纸币的地点都是平等的，没有说法高于谁之上，一直到17世纪末英格兰银行出现。这是英格兰王室跟一个苏格兰银行合作，使英格兰王室取得了这个特权地位。王室把纸币发权以它周边地区债券的发行权独家赐给了英格兰银行为。这是唯一一个条件，就是英格兰银行为王室提供一个长期的、稳定的、低成本的战争融资。从这以后，英格兰银行发行的纸币就被正式赋予了国家信用，成为了英国的法定货币。

这种国家赋予特定银行特许权力，垄断银行券发行的模式被快速复制到了各方。一个国家最主要的法币交易的发行，它能够获得长期稳定的资金，国家的权力变得很大。另外一方面，政府可以通过发行来调控社会上的信用规模，对经济进行调节和控制。很多人认为像英格兰银行在后期发权过程中一个金融创新，是英国在后来的大战略中能够取得先机，成为全球霸主的关键词因素之一。

我一再地强调，国家、银行交织在一起塑造了信用货币的概念，是现代货币的一个关键。而货币的背后是国家信用真正在主导的作用。所以说目前，在自然界人类是我们最熟悉的组织形式。但一个是人类，我们如果抛开国家使用这类货币的话，那就像是缘木求鱼、舍本逐末了。

现在你了解了美国霸主地位是怎么形成的，是国宪信用在后后支撑，也赋予了英格兰银行法定货币的发行权。现在在回头看看比特币，你首先会去对比美元。比特币是一种数字，它没有实体，很明显，它在很多场景下都能完成货币的传统功能，计价也好、支付也好、储藏也好，所以数字货币可能未来也货币发行的一个方向。 但是只要国家那个概念还没有被取代，像比特币这样去中心化的货币，要取代法宾实行发行的决定权吗？我觉得还是路漫漫其修远兮。
