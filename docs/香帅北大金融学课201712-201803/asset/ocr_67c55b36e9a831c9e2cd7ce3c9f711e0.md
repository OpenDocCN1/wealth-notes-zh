最近一段时间，人民币的升值让很多人很关注，很多网友留言问了人民币汇率的一些问题：人民币的汇率不是一直贬值吗，为什么最近又在升值？美元指数与人民币的升值有什么关系？人民币升值对老百姓的财富影响是什么？我专门做了这些大家关心的问题，进行一次系统回答。

过去两年半的时间，人民币兑美元汇率坐了一次过山车，先是跌到6.2关口（即1美元兑换6.2元人民币），然后涨到6.9左右，正是大家纷纷预期人民币“破7”的时候，又突然掉过头，从6.9左右又升值到6.3左右。很多人就问了，为什么会出现？这是这几年我国经济运行，很多人可能都看到，人民币也顺配地贬值，可就是不知道它，怎么看？

为了说明，我们来看回三个问题。

# 一、汇率波动，究竟是谁惹的祸？

我们先来看两张图。图1是衡量人民币的一个代表指数，也是看人民币对一揽子货币的平均汇率。从图1看，人民币2016年9月份以来基本比较稳定，在94至96这个范围内波动，这波动维持了快两年了，并没有太大起色，这意思是，对人民币的升，没有大起大落。唯独对美国大个子。所以，引起汇率过山一样波动，背后大动力，并不是人民币，美刀。

![](bbox=[0.08, 0.393, 0.91, 0.445])

这么说，是不是在故意推脱人民币的责任呢？不是。过去两年，美元的大幅波动，才是真正的因素。

图2显示的是美元指数的变化，也就是美元对于一揽子货币的平均汇率。图中可以看出，美元指数从80低位，涨到104高位，涨幅超过25%。然后，从2017年开始，到2018年初，又跌到不到80。跌掉了之前的翻好几倍。

![](bbox=[0.08, 0.494, 0.91, 0.545])

所以，即使你看人民币，只有美元，人民币也做过一次，高高低低。

以前人民币是盯住美元的，美元升值的时候人民币也被动升值，被美元拉升。而美元一涨到2015年8月的时候人民币盯住美元，人民币贬值就开始了。之前人民币的贬值，其实是被动的。后来，美元开始贬值，但此时人民币已经不再盯住美元，所以相对美元升值，但相比于欧元等其他货币，还是贬值的。

所以，人民币的汇率，为什么之前会大幅波动？背后的原因就是美元波动。中国有一句古话：树欲静而风不止，人民币是对，美元是风。树是静止的，而风是动。树只是随风而动。

# 二、美元为什么会大幅波动？

这个问题比较复杂，重要是当今天经济体系中，全球的重大政治、经济、军事事件，都会影响美元。为了让你快速抓住要点，我讲两个最关键的因素。

第一个因素，是美利加息率。从金融体系来说，维持美联储的利率水平，已经好多年了，2014年之前，美联储处于历史最低水平，2015年，美联储加息。在加息预期刺激下，美元开始大涨，从2016年1月起，累计升值超过25%。这一年，美联储连续多次加息，到2017年，加息预期兑现。而加息预期之后，美元升值动力，也慢慢消退了。

第二个关键因素，是全球经济复苏。2016年下半年开始，全球经济增长开始，欧洲经济复苏尤其明显，2017年，欧元区增速达到2.5%，十年最高，欧洲经济增长复苏，带动了欧元的走强。2017到2018年初，欧元对美元升值了17%。

这是什么意思？美元和欧元是当今两大货币，此消彼长，欧元的升值就是美元贬值，欧元对人民币的升值，也随着欧元升值。

你可能还疑惑，为什么欧元复苏，美元就下跌？其他货币会大跌吗？道理是这样的。中国有句话，叫“避险，乱世黄金”，说的是战乱的时候，黄金是最安全的资产，欧美也一样，美元和欧元是世界上最安全，最稳定的货币。所以世界主要经济体的货币，都是安全的，都会上涨。

当时世界主要经济体是，美国，全球经济增长缓慢，欧元复苏，而美联储加息，欧元，英镑，人民币，都因为经济复苏，有所升值。

这一轮升值，人民币表现也是中规中矩，升值幅度也不最大。人民币累计升值了8%，比欧元少。大家手里拿着人民币，对人民币升值的感受很深，是直观的。

# 三、如何判断美元的未来走势？

现在我们已经清楚了过去两年人民币的波动，原来根源在美元。这样看，美元的未来走势就很重要了。那么，怎么看美元的未来走势呢？

预测未来总是很难的事，预测汇率尤其难。因为汇率是一个国家宏观经济的总体情况的一个体现，涉及的因素非常复杂。但也不是全无迹可循，今天我们就讲一些理解汇率的一般方法。

理解汇率走势，要区分长期和短期，长期看趋势，短期看波动。

看长期走势，看影响国际综合实力的根本的，基础的长期变化。比如美元，美元长期强弱，是取决于美国在全球国际的相对份额。当全球经济在从多极化、演变成多级体系，美元的国际份额，长期就会下降。欧元，人民币等货币的相对份额，长期都是上升的，相对于美元。中国经济长期，是发展中经济体，仍然保持快速增速，长期对美元的影响力，会一些长。

看短期波动，看一些短期的重大事件，这些事件会导致一些短期的，比如说2—3年的汇率变化。比如，2014的美元升值，主要是美国加息周期的预期。2017年美元贬值，主要力量是，全球经济复苏。

说了一个原则，我给大家具体分析一下2018年的美元走势。既看长期，也看短期经济的关键事件，比如，美国继续低增长的力，如果特朗普关税政策不稳定，发生大规模冲突，那么，美元资产的小众性会显现，一个导致美元升值的力量。

判断美元的短期走势，要留意这些重大的风险事件。
