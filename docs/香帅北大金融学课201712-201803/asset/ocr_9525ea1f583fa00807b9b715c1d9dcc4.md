# 2. 第二份礼物：精选书单和延伸阅读资料库

课程上线以来，同学们一直在留言希望我推荐书单。关于读书的求是精不是“求多”。一本书要能读透，读出自己的感受，才算是真正脑汇贯通了。自然，这样的读法对书的要求就高，必须是精品，耐读，值得一再，再，再的重复。

所以这本书我一直很谨慎，一方面我希望这些书能帮助你更深度的理解课程内容，是课程内容的延展和加深，另一方面我也希望这些书对于你开拓视野，形成框架性思维模式有帮助。我在课程已经精选了三维，为让学者有余力的同学继续精进，我特地精选了二本配套你宝贵时间的书箱。我推荐了两本书：

第一本是著名学者钱颖老先生的《中国历代政治得失》。你要理解东西方文明的分期，要从东西方文明的演化说起，中国2000年朝宋代更迭时，变化流转，绝非一句“专制制度”可以概括，里与权力的相关思想，中央与地方的争夺，如何选拔人才，由朝廷制度如何设计，没有哪一个制度是完美无缺的，历代帝王将相都是尽了全力。理解过去，方能透视现在，展望未来，汉唐宋明元清，历朝历代的政治得失，在这薄薄的八册子里，钱颖为在为你一道来。读完这本书，你会理解我们课程中所说的“中国金融市场的“中央集权”政治”及“中央集权”政治，从而更重今日中国市场的演变化路径。

第二本是我喜欢的金融学著作，耶鲁大学的威廉·戈登曼教授的著作《千年财政史》。所谓金融就是举贷与资本，金融最根本的问题是钱从哪里来，钱又到哪里去，如何管理？金融史就是一部人类管理货币的历史，从古代的贝壳货币，到金银货币，再到今天的纸币与数字货币，每一次货币制度的变革都深刻影响着经济与政治。

读透这两本书，你不仅会对金融的演化有更深的理解，你对人类文明，社会制度演化的理解也会跃上一个新的台阶。

第三本：对于银行这个模块的学习，我特别选读了当今世界上最优秀的货币银行学者，弗雷德里克·米什金的《货币金融学》。这本书虽然也是教材，也是一点也不枯燥，大量的案例分析，严密的数据框架，使它的可读性远远超过一般教材。其实这本书的英文原名是《The economics of money, banking, and financial markets》，直译就是：货币、银行、金融市场的经济学。这个书名其实更准确地概括了本书的内容：在美国当今市场中，银行处于基础的地位，是货币流通的基本通道，帮助金融资产的水平和结构价格的波动，金融市场的运行，金融体系和监管的特征。你可以将米什金这本书当作我课程的教辅教材，可以加深对货币和金融市场体系全貌的理解深度。
