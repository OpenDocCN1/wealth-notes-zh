# 一、北京房价这么高了，会不会跌？

首先我们来看看北京的房价，北京其实一直是房价泡沫问题的焦点，为了解决这个问题，我们首先要思考，我先是自己的一个疑问，北京的房价应该比谁贵才是比较合理的？这个，问题是个好问题，但是美国那么发达，肯定是纽约最贵了，且慢，分析用基础经济学框架去告诉你，价格由供需决定。比如如果你告诉我北京的土地资源，北京的供给是稀缺的，而需求上，高收入人群对房子的需求是刚性的，那房价自然会高，对不对？

+   1. 首先我们从需求来看。北京是中国的政治、经济、文化中心，资源是高度集聚的。纽约是美国的经济中心，是美国的政治中心是华盛顿，文化中心是洛杉矶，纽约只是一个经济中心。北京是一个资源集聚的大城市，其资源集聚效应和经济发展潜力非常大，因此北京的房价理应高于纽约。而美国的纽约是美国的金融中心，北京聚集的是政治、经济、文化等多方面的资源，所以从资源聚集和潜在经济能力来看，北京的房子比纽约的应该贵。

+   2. 咱们接着来看看供给。北京住房作为最重要的公共产品，它应该是一个最公平的资源分配机制。北京住房供给的特点是，总量是巨大的，但是相对于需求而言，还是有限的，这就是为什么北京的新房价格一直居高不下，而二手房价格相对稳定的原因。

现在我可以给你简单总结下了，房子其实无非就是看供需，它的价格是供求关系决定的。北京的供需格局是供给小于需求，且供给是相对固定的。你看考虑到，我们国家在2023年到2024年，我们会进入一个高收入的行列，大概率事件是在2030年左右成为全球经济第一大经济体。

那现在是一个什么情况？现在在可比的一个区域和档次上，北京的房价是纽约的1/5。纽约的房价大约是北京的5倍。我们是1万看右，北京大概两千多，七八。我们再看看高端的大概，纽约每平米的价格折合人民币是30万左右，北京是15万左右。所以说我们认为中国的房价会继续平稳发展，社会总体结构会继续稳定下去，那么对比纽约，北京的房子是具有很大投资潜力的。

这个结论可跟踪我开设想得很不一样，对对不对？时间关系，我就不再进一步展开了，以后有机会再跟你详细解释的框架。

但是在过去的这几十年里，房价节节上涨其实造成了很多问题，比如说房产的信贷资金成本太高，会流失，年轻的人才留不住，还有那么多三四线城市因为过度依赖土地，土地财政导致了一系列问题。

我觉得那些使用过高的杠杆，还有很高税收等办法去抑制房贷的需求，这样其实并不符合，第一，如果国家政策决策目标是可房价上涨速度过快的趋势，可以通过税收、监管，甚至限购等办法把这些推盘和套利。但目的不是抑制需求，而是让那些投资性需求付出高成本。

# 二、中国房价有泡沫吗？为什么要频繁调控？

下面我再谈一下关于房价泡沫的问题。其实刚才我也讲过，房价的背后是什么？房价是一个国家的经济增长、城市化和货币化综合作用的产物，经济增长、城市化和货币化是影响房价的主要因素。如果经济增长慢、城市化低、货币化低，房价就会相对低。反之亦然。

目前我国的房价收入比，只有美国、日本等发达国家的1/5，还有很大的上涨空间，而发达国家的城市化率在80%，我们国家大约为57%左右，也有很大的发展预期。所以从经济增长和城市化两个角度，中国房价有很大的空间。

![](bbox=[0.25, 0.86, 0.75, 0.93])

更重要的是，在城市化的过程中人口进一步向大城市聚集，而我国目前的城市化人口基数低，是美国的4倍，日本的10倍。未来我国大中型城市的人口还会增加。所以你看，在很短时间内，总体的房价并没有下降。而经济总量庞大，这说明了什么？这并不是说大家都不理性，而是证明了中国的经济增长非常快，城市化水平也没得降低，所以在城市购房的需求也很旺。

好了，我们说完了经济增长、城市化和房价中的基本关系，接下来国家要做的就是，如果房地产泡沫没有，那国家为什么要出台那么多的调控政策？

其实这个问题真的是非常复杂，涉及到了反周期调控思路更深层次的逻辑，其实你可以问一下，如果没有泡沫的话，政府都不用调控房产了吗？仔细想，其实可能有很多原因是政府想要调控，其中最关键的一个问题就是财富分配问题。

中国的经济增速在过去几十年里面实在是太快了，就像什么呢？就像一路奔驰的火车，而这些大城市买房的人为获得优势，于是竞争非常激烈，买到了房子的人赚了很多钱，没买到的则越来越痛苦。这种失衡导致了社会情绪的不稳定。

一个社会最重要的中流砥柱是什么？归根结底还是人，人活着是要有希望的，没有希望，是一个特别可怕的事情，会产生很多的问题。我们可以从社会稳定的角度去理解，国家要出台政策，让房价不要再上涨过快，让更多人能够买到房子，对真实现“居者有其屋”，这样才能社会才能稳定。

所以房地产调控不是调控价格水平，而是调控上涨速度。让房价的上涨要适度，符合社会财富分配，是国家长治久安的一个稳定状态。
