# 一、空套与套期保值

今天，我来跟你们讲清楚，到底什么是对冲基金。在讲清楚对冲基金之前，你一定要先了解一个词，叫“套空”。手里是把它卖空这个东西，但是自己手里又没有的东西。

给你举个例子，现在有个股票，市场价格是100块钱，你看空这个股票，赌它还会大跌，那么你想空一个手里面有1万股会大赚，借他1万股，约定在3个月以后，把这1万股还给他。

这是你一定的利息，比如是5%，你不看空这只股票就卖空之后，你就迅速把它的2万钱出来卖，获利是100万，然后三个月后，如你所愿，这个股票真的跌到了80块，现在你花160万把它的买回来，然后还给别人，再扣上利息5万（100万*5%=5万），再加个利息5万（100万*5%=5万），这一单套空赚了多少钱？20万减去利息5万是15万，所以15%赚下15万，空手就白赚了15万。

好，现在你知道什么叫卖空了。

我们来看看“对冲”（hedge）。就是我们一个金融产品的同时，买入一个另外一个与价格变动相连的产品，来规避风险。这个词听上去很专业，对于不太了解这个道道来，你又都懂，用“赌空”前面点个道理解，吃火锅跑起来身伤，不都是为了对冲，防止解渴，或者长寿的风险吗？

对冲这个概念一点也不复杂，说白了，就是找到一件事情的相反作用，然后把这个事物的效用抵消掉，第一个把这个概念成功运用到生意场上的人是美国的阿尔弗雷德·温斯洛·塔普斯。

上个世纪50年代的时候，他发现所有的股票和大盘，股票大起大落他可以做了一个策略，一方面买入一部分自己看好的股票，同时卖空一部分自己看空的股票，这样一来，无论大盘是涨是跌，只要他已买入的个股比卖空的股票涨得多或者跌得少，他就是赚钱的。换句话说，通过相对地地买空大盘，转而用自己的股票去有独立于大盘的走势，对冲或者消失了市场波动性，所以塔普斯就对自己的基金叫作“hedged fund”（套利的基金），他也因此被称为世界上第一个对冲基金的经理。
