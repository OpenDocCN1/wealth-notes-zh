年代算得上是生不逢时，大萧条的余波犹在，市场冷冷清清，罗斯福和杜鲁门政府显然在资本市场“以风控为令”的金融监管体系并没有多好消息，政府行为对证券业的监管一再加强。最好战事的爆发催生了大量资金需求，国际和国内股市的发行使得投资业重新通过这个艰难漫长的日子。为了生存，投资银行家们甚至只得屈尊进入到那么上流的证券业务领域去工作。在此期间，以零售商证券为主的类美林证券迅速崛起。

随着战后美国工业化和平镇化的高潮，60年代的承销和证券业务的又一个黄金时代，承销行均迎来源源涌来。与此同时，社会衰老的急速率催生了大龄证券基金。随着养老险快速度的建立，养老基金开始大量进入市场。人寿保险公司的资金实力在同期也开始快速扩张。机构投资者在市场上形成巨大买方的力量。随着资金量的增长，买方渐渐不满足于投行所提供的单调的投资策略和风险收益特征。不同风险偏好的投资者都对风险敞口、风险收益，和投资组合提出了更多的不同要求，投资银行家们必须适应这一趋势，开发新的金融产品成为生存所必要的技能。

# 五、交易导向型的投资银行和金融危机

直到上个世纪70年代，证券承销（尤其是IPO）仍是投行的主业业务，但优质券商间是这个行业至高无上的荣誉。不过，投行的风行已经开始变化。客户导向型时代投资银行开始向交易导向型的全能服务商转变。

交易需求有时候来自客户。比如为了保证自己承销的各种证券（股票、债券、票据、互换、期权）流动性，投行需要在二级市场上为它们“造市”（market making）。另外，投行的大客户（包括保险公司和各种机构投资者）也常常要求投行业帮们买入或者出售大量证券，通过这样频繁的买入卖出，增加交易市场的“买家价差”，同时也极大的增加了市场的流动性。

另外的交易需求来自自营业务。早期的投行主要是靠金融的“实力”而帮助企业出售金融资本来筹集资金。以零经纪业出资来的美林公司在71年成为华尔街第一家上市的投行后，熊林斯利和高富街逐渐打破行业惯例，成为公司。投行的资本因此而需要提高，除了自营赚取资本管理的需要。另一方面，随着金融资产积累，客户方也越来越多的对投行提出了资产管理的需求，这是传统的“实力”业务（如如何帮企业买合适的债券和资产）渐渐变成了投行自身的组成部分。到90年代中，曾经领风骚的证券承销和佣金收入已经不降到美国整个金融业收入的25%以下，而以各种有证券交易为的自营业务和投资管理业务收入上升到50%的以上。

金融产品的日渐增多和投资者结构的日渐复杂，市场的波动性成为了华尔街的最大困扰。保守主义的养老基金和保险公司成为市场最大的客户，他们对债券人的债务状况日益强调，对债务的安全质量提出了更高的要求。利率掉期（swap）因此被出来在债券市场上对冲利率风险。接着，货币敞口开始被运用在跨国的债券交易来对冲汇率风险。

另一项影响更为深远的金融创新则是资产证券化。60年代后期，美国快速增长的的中产阶级终于有财力购买新房而产生了房产抵押债务。为了向满足不断扩张的房地产需求，两大房产抵押贷款“房利美”和“房美惠”需要更多的资金手钱手。银行家们设计出“过手证券”（passthrough security）的行产品。这种债券的发行用住房贷款资产做信用支撑债券市场，整个房地产利息和市场的流动性大大加强，直接带动了房地产和债券市场的双重繁荣。

这个被称为“证券化”的金融工具迅速的发展起来，任何债券、项目、应收账款、收费等资产，甚至税收收入——都可以通过证券化的形式转变成在金融市场上流通的资产。到了70年代中，林林总总的商业结构，形形色色的投资者，连投资银行家们都从其所患的热病中认识到证券化的浪潮中。华尔街由此产生了一句谚语，“叫如果你没有一个稳定的现金流，就将它证券化。如果你没有稳定的现金流，就让它来。纷纷登上证券化。（一句不算题外的话：2007年起在全球金融啸鸣的资产贷，本质上也是证券化的一个产物。）

时代在变化，一怀戚士思，一怅雪落。个人魅力主义的投行业要渐近渐远，历史留痕。为专业化，技术化，数据化的时代来临。

# 六、全球金融自由与投资银行的狂欢时代

在撒切尔夫人强硬的自由主义的执政理念下，80年代的英国率先实施名为“大爆炸”的金融改革：分业经营的限制被打破，金融保护主义结束，固定佣金制被取消。

华尔街突然发现，伦敦又成了自己可怕的敌人。尤其是国债债券市场上，伦敦交易所已经占了先机，浮动利率票据，部分支付债券，可转换债券，眼花缭乱的多种投行需求，满足投资商多样化的需求。接着，日本，加拿大等国家纷纷放松金融管制。

节约德银根的上台终于让华尔街的银行家们松了一口气。敲定了保罗雷曼的Q条款被取消，利率彻底市场化，415条款的限制被打破了发债的银行，银行有对新的限制破坏，债券的配售和债券有更大的自由。全能进行银行业务。金融改革的十年的成效很快将体现。

美国国内市场上，“垃圾债券”（junk bond）和杠杆收购（LBO）给了传统的风险巨大的债券市场发展宏图的机会。陷入财务困境的企业债券通常被称为“垃圾债券”（junk bond）。长期以来，它们在市场里无人问津，因为价格低廉。一个叫杰尔斯·艾肯德的投资者发现，这些看起来很没风险的债券的收益率已经远远超过了风险补偿所需要的回报，没有比较苛刻的投资机会了。更重要的是，对于那些缺乏现金流的新科技公司（通讯，信息，生物医药等）来说，可以通过发行垃圾债券而向风险高的投资者来融资。在资本的助方下，新兴的产业快速发展，创新成为美国这个标签。美国有线新闻网（CNN）正是这一金融代表的代表。

此外，曾飞60，70年代庞凡一时的集团公司开始呈现出“大而无当”的趋势。由管理层主导的公司收购浪潮席卷了整个企业界。在这波被称为管理收益效应（MBO）的浪潮中，垃圾债券充当管理息息层后的好兄弟，通过为收购高级融资。对上市公司股权，公司由交易后上市公司的业主，投资银家们大显身手，他们收取巨额的债券的佣金。同时利用自己的信息优势在市场竞争中上翻手为云覆手为雨。

这是一个黄金自由的时代。华尔街的投资银行家们发现自己同时为自己金融的执龙。皆在发展中国际债务重重的可转换债券（俗称债券债）的发行创造了大大的一席（新兴市场，东欧，亚洲，拉丁美洲）公司私有化的浪潮热切对需要投行的兼并计划。更令人心潮加速的是，在美国之外的其他地方交易上，投行发现自己已不再受分业经营的限制。全球化比附了前所未有的空间，投资银行家了无所不能的先生：从兼并收购到资产的管理，从资产到资产的管理，从收益到利润，从国际融资到证券发行，从受益交易到，从大宗到衍生品……80到90年代的投行无疑是金融行业的生军。
