# 一、影子银行到底是啥？——金融创新与金融监管的博弈

首先我们来看看到底什么是影子银行。影子银行的定义是：本质上就是为银行这些金融机构，是要给国家干粮监管的，但是他们又想想要赚取高额的利润，所以它们会和证券、信托、券商、基金这些金融机构合作，然后营造出一个「遮监监管」的游戏，它们会去借一些「类银行」的金融结构，这些业务有融资的能力，但是又没有银行的实贷，像个影子，所以非常难监管。

这里面有两个道理是要讲清楚的。首先，银行是要受到国家监管的，比如说银行的贷款投向是有限制的，当国家调控房地产，就不能允许银行的贷款向房地产贷款，还有银行的放贷额度也受受到限制的。比如说原来有一个75%的存贷比限制，虽然现在已经取消了，但是所有的资...贷款额度是受到限制的。

此外，银行业和证券业是要求分业经营，银行资金是不允许进入证券市场的，但是商业银行资金里是有准备的，它要追逐利润，有什么冲劲就把它放在什么地方投放，就冲动去要赚钱，它就没办法放。在证券市场火热的时候，银行手里的资金多，当然就去想参与，比如说可以买一些债券、基金股票，但是这些行为其实是影响了银行的贷款投向，所以国家是有限制的。

另外一个点，就是在中国现有的金融体系中，银行占据着绝对主导地位，因为你有钱可以存到银行，你到银行来也可以从银行取钱，因为中国240万亿的金融资产里面，银行占了90%以上，和银行比起来，其他金融机构的资产规模都不大好。但是他们、基金这些机构也不是不好，只是受到的监管是相对宽松的。

所以，银行要受到的监管多、资金多，银行要受到监管的监管多、资金多。而金融机构少，但受到监管比较多，它们资金多。把信托、基金这些和银行混在一起，然后让银行去给这些机构提供资金、让银行去投资它们的产品，然后这些机构再去投资一些...项目或行业，它们就可以通过这种方式，绕过监管。

# 二、影子银行是好是坏？——银行理财产品中的风险

很多人是只买非保本的银行理财产品的时候，其实是买不到这些银行理财产品的，因为2012年开始，市场上就有各种银行理财产品违约的事件出现，而且都是大银行，华夏银行的「中融信托·苏州园林1号」、平安银行的「聚金号」、交通银行的「得利宝1」，都分别出现了违约事件。

我以华夏银行的中的丰阳财富产品为例给你解释。其实中融信托的背景和银行没有什么关系，它是一家叫「通用润银资本管理有限公司」的企业。而这个公司是一个河南商人主导的股权融资计划。当时这个项目是10万50万起，回报率高，大概是银行利率的三倍。有华夏银行这么大的银行信用，加上这么高的回报率，这个产品很快就募集了1.6亿的资金，结果资产下、公司破产，这个资产公司老板人找不到了，募集的资金也不知道在，但是因为是保本的，银行是不需要承担过多责任的，所以最后购买这个产品的银行客户，他们的损失最多不超过1亿元左右。

很多同学就不是很理解，这资产公司和华夏银行到底是什么关系啊？这是他们前面的通道业务，华夏银行在这里面通过的是通道，这个投资融资计划就是通过华夏银行理财产品来募资。所以，你买的理财产品，你投的是某个项目的银行理财，其实呢，它是为某个高风险的股...资计划募资，甚至为什么要通过银行来募资呢？就是让人们不能看到它是募资，而且银行监管的，就一不能...
