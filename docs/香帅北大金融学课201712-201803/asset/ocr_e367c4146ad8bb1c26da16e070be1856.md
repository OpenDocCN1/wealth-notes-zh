这两年，在基金的圈子里，有一个特别热门的词语叫做私募基金。关于私募基金，市场有很多种说法。有的人觉得，私募基金是专门帮那些有钱人搞钱的，所以它肯定是更加更加高上档次。还有一些人就觉得，一想到私募，就会老是联想到清盘、跑路，好像感觉私募是今天特别靠，和跑清好像息息相关。今天呢，我就来告诉你私募基金到底是什么，和公募基金有什么区别。

# 一、私募基金和公募基金的差别是什么？

首先，我们来弄请什么叫私募和公募。私募和公募是金融市场上最常见的两个名词，其实它就是指资金的来源；在广义来说，公募就是指包括其他投资者的社会大众，公开募集资金的方法；而私募就是指针对少数人，也就是我们俗称的向净指给人群来募集资金。

而，根据募集来的资金要去投资什么，我们还可以把私募基金分成两类：一就是我们今天讲的这种一级市场的私募基金。另外，另一种就是二级市场的“私募证券投资基金”，在我们市场，就叫“阳光私募”。也就是说平听到的私募基金。在美国，它也可以叫“对冲基金”。

你可能会大吃一呀，平时听上那么高大上的对冲基金，其实就是我们经常的私募基。是，其实它只不过是听到的马甲而已。

美国对冲基金的故事，在下讲的时候我们还要详细地说，今天我们先来弄请一更实际的事，也就是切身利益的问题，就是和你投资相关，私募基金到底有什么特殊之处，而且能不能？

私募和公募一样，其实都是投资于股票、债券这些大资产。但是，和公募相比，私募有两大特征：一个叫“少监管”，另一个叫“高激励”。

# 二、私募基金的本质特征之一：少监管

公募基金面对的是所有的社会公众，管理着千万普通老百姓的钱，所以它一定都要严监管，要鼓励透明化，追求安全性。你看，万一这些老老姓的线进作方，或者胡乱作为，导致老百姓的钱血本无归，可能社会就不稳定了。

私募行业不一样，私募行业面对的是少部分高净值人群，一般来说，私基的门槛在100万，甚至更高。这些人群一般也被认为有较高的风险承受能力，所以他们即使亏掉也不会造成社会动荡。而监管是需要成本的，所以，对于私募基金，监管要比公募基金少很多，多了的管制条款。

比如说，全金国内有一个小有名气的私募基金经理，他两年前，就曾经在自一基金里，中过茅台还持有茅台这一支股票，你知道贵州茅台这几年的业绩一直很好，不少于200%的业绩也很好。但是这种方式的，在公募基金里，就是绝对的不能做，因为公募基金里，一支股票不能过超过5%，而私募基金里，就几乎没有这些限制，甚至可以100%买入一支股票。

在公基里，还有很多限制条款，比如说基金的总资产，不能超过基金净值的140%，而且也不允许给自己管理的这些资产，去找信用担保融资。到了2017年底的时候，金监局进一步地，把这种公募基金都给停掉了，这些措施都是什么？都是为了防范系统性风险，但老姓去赌暴露过度的风险层面。所以，公募基金基本上每个季度都要向公众吐露，持有这些基金的重要信息，而私募基金，这些约束条几乎全都没有。

所以你看，私募基金面临的是一个少监管的环境。这一个监管的环境意味着什么？对于私募基金来说，它就好比你开了个很大的投资，所以它们可能发生的更大。但相应，它们也可能会产生更多的风险事件，这就是我们在金融学里面讲到的风险和收益就是一个硬币的两面，它们总是同时存在的。

# 三、私募基金的本质特征之二：高激励

现在你知道，和公募基金相比，私募基金更少监管，一个是有趣的题目是，持有这种基金的管理，他的收入是什么？经过真正的权益投资者倒更多高价值吗？换句话说，作为基金的投资者，你怎么确保证基金收益能够好好打地打者你的本金？这就是我们今天提到的第一个重要特征：高激励。

通常来说，公募基金经理的收入大部分来自于固定的管理费，一般是基金规模的2%；而私募基金经理的大部分收入来自于业绩提成，通常是基金业绩回报的20%。这两者的差异有多大呢？可能远远超过你的想象。

金融市场上曾经引起过一阵风，就是公募基金的基金经理就是一些明星的基金经理给的是“奔私”，也就是从公募转到私募基金里面。曾经有一个公募“奔私”的基金人：说“过去在公募基金里，我一年能赚十一两万；还是算不中。但是我“奔私”以后，半年的工资，就赚了五十多万，实现财富自由没有问题。”这个人的100%，跟一个点其实就是，但是70%的回报率，在行业里能提取的业绩报酬都是实实的。

这一上来，你就明白了，公募基金经理的收入来自于基金会，和业绩的关系并不是特别大。所以，公募基金经理没有一种不敢亏钱，但求不亏的心态，只要他的公募基金管理得好，那么，只是把比公募基金规模做大就可以了。相反之下，私募基金经理的收入靠真的考验个人能力和努力程度来赚钱的，基金公司没有收人的，那基金经理的收入自然也会变得很低。

这种激励机对收入水平的不同是公募基金和私募的另一个重要区别。

所以另一个人能特别突出的明星基金经理，常常会选择“奔私”，就是跑到私募基金里面去。

# 四、投资私募基金比公募基金更赚钱？

现在你可能有一个感觉，私募基金更少监管，又高激励，所以可以吸引到更加优秀的金融人才，看上去私募基金比公募基金更赚钱才对。答案是不是定？

我们看一下数据，从2009年到2017年这9年间，中国公募基金和阳光私募的业绩表现比较。私募的平均收益率14.8%，公募是13.2%。

| 年份 | 私募平均收益 | 公募平均收益 |
| :--- | :--- | :--- |
| 2009 | 55.6% | 71.4% |
| 2010 | 3.5% | 5.3% |
| 2011 | -17.3% | -25.5% |
| 2012 | 1.8% | 1.6% |
| 2013 | 13.3% | 11.5% |
| 2014 | 30.9% | 28.0% |
| 2015 | 38.6% | 23.1% |
| 2016 | -3.3% | -6.5% |
| 2017 | 8.8% | 6.3% |
| 平均 | 14.8% | 13.2% |

这个数据看上去好像是，私募比公募赚钱一点，对不对？但是，这里我要给你提醒：私募基金的业绩通常比公募好，这是私募基金产品的效果更加严重，如果你买了私募产品，很可能会不心甘情愿就亏了。比如说2017年，整个市场私募基金的收益率是8.8%，跑赢了同期公募基金平均6.7%的涨幅。

但是，你没有看到的是，整个私募业内内部一半是海水，一半是火焰，很多大型私募基金的业绩很好，但是有30%以上的业绩，收益为负，如果你不小心选，300家私募基金会，你会被扣了，失去了本金，也就是说经理人跑了，你的钱基本血本无归了。
