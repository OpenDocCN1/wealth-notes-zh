前段时间，有个银行家说，“别的行业利润那么低，银行利润那么高，我们都不好意思公布数据”。这话可不是不假：2017年全球最赚钱的五家公司中，中国占了四家，分别是工商银行，建设银行，农业银行，还有中国薪水。作为全球银行业，平均也配着土豪薪水：去年招薪银行的平均薪水是46万，上海银行是45万。

从2003年到2013年被称为“中国银行业的黄金十年”，也是银行“躺着都能赚钱”的十年。

今天我就给你具体讲讲，银行到底是通过什么机制来获取高额的利润，接着我们再看看，在未来是不是不还是有躺着赚钱的机会？

# 一、银行通过存贷差赚钱的秘密：风险规模、期限和风险转换

首先看个数字，2016年中国银行业实现的净利润大概是1.6万亿元，其中净利息收入，也就是存贷差差不多占3/4左右。所谓的存贷差也就是银行吸收的存款和放出去的贷款，中间的利率差额，这是银行最重要的利润来源。另外1/4的利润来源大概分为两大块：

+   1. 银行吸收了存款以后，它自己会做一些投资，比如，在我们国家大概90%以上的国债都是商业银行买的，会投在债券这些比较安全的资产上面。

+   2. 还有一块利润叫通道业务费用，我们看到银行去买理财产品，其实大部分都是银行和其他金融机构进行合作，银行在这个里面其实是个“通道”的角色，收取通道费用，所以通道费用也是银行利润的一个重要来源。

至于大家平时比较熟悉的银行的手续费，其实在银行的利润里面是比较小的，尤其是股份制银行，它一为了吸引顾客，都会把这些手续费给免掉。

第三块利润：存贷差。银行自己投资的业务收入，还有银行的通道费用，实际上都依赖于银行的规模和吸收存款的能力，日子就是越吸收存款越大的银行，越能赚大钱。这也是为什么央行，就是我们全球最赚钱的五家企业中间，居然有四家是中国的工、农、中、建四大行，因为它们吸收存款的能力实在太强了。

既然我们对存贷差获取利润是最主要的来源，我们就面临这样的问题，它到底是通过什么机制赚取这个存贷差呢？存贷差看上去简单，存的钱和贷款中间利差的差，但是这里面的道理一点也不简单，因为这涉及了银行的本质。它是通过资金的规模、期限和风险的操纵，来实现资金的优化配置，然后从中赚取这个利差金额的。

这个概念可能比较抽象，我用一个小故事来说明。有两个村庄，一个村庄的村民比较聪明，手里面有余钱，另一个村庄正在搞各种加工业，酿酒，伐木等等，需要资金，所以大家都看到隔壁村庄去借钱。现在问题来了，比如说你刚刚加工，现在需要资金量，但是人家哪个人不存那么多闲钱，所以你想借很多钱，这就存在规模上有差异。还有，你要搞加工业得好几年，但是借钱的人都担心自己的资金流动性，而不愿意借这么长自己时间，这叫期限上有差异。还有更多的人，跟隔壁村的人完全不熟，没有信用，大家也不信任，收不到钱，这叫风险上有差异。
