家，跟咱们国家的国情不太吻合。经过这
些年的讨论以后，其实现在我们在朝
淡马锡模式迈进了一步。比如说现在有的
地区，地方政府作为有限合伙人，只充当
财务投资人的角色，不干涉基金的运营，
基金完全按照市场化的运作，想办法专门
投资于那些国有企业，通过市场化的运作
的模式去盘活这些国有资产。

# 今日概要：

# ■ 划重点

+   1. 主权财富基金是一种替国家财富增
值保值的资产管理机构；
2. 它是从外汇储备资产的管理开始
的。像沙特阿拉伯、挪威这种石油输出国，还有中国这种出口大国都累积
了巨额的外汇储备，也拥有庞大的主
权财富基金；
3. 新加坡的淡马锡是全球最成功的主
权财富基金之一，它这种经营权和所
有权相分离的模式，为中国的国有企
业改革提供了一种可能的方向；
4. 主权财富基金的版图里，石油国和
新兴国家占据着巨大的比重。
