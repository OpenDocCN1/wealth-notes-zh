# 034 | 延展话题：创始人怎么能用较少的股权控制上市公司？

你好，欢迎来到曾帅的北大金融课。

这两周的时间，我都在讲授投资银行的传统业务，发行承销、兼并收购。你可以看到的，在过去的几十年中，你依据靠的是人脉、资金和营销网络，大投行在资本市场扮演着上帝一样的角色。我们既能够获取项目，又是信息和资金中介，赚取着超级丰厚的利润。

但是，就像我们在上周的延展话题中说到的，时代变了，我们现在正处在一个资本不稀缺，好项目稀缺，企业家稀缺的资源大背景下。所以，企业和企业家的话语权变得越来越大。在整个的发展趋势上，我们可以见到两个明显的趋势，第一个就是重视股改结构的流行，让企业能够使用较少的股权控制企业。第二个，就是分散发行的投行关系承销越来越流行，投行的权力被分散掉了。

# 一、控制权之争：合伙人制度与AB股改结构

去年的12月15号，香港交易所宣布，修改现有的上市规则，允许存在双重股权结构的新兴企业上市。这个宣布出来以后，很多人感叹，早知如此，何必当初呢？为什么这么说？因为2013年的时候，阿里巴巴本来是想要在香港上市的，但是港交所当时特别顽固，坚决不同意做股权分制这件事，所以让阿里改成了“美退”。否则，如果当时阿里在港交所上市，那么现在的港交所，绝对是比中概股独立两步，是一个股份和控制权的问题。

你可能知道，一般的上市公司，是同股同权，一股就是一票。为了表达，现在的创业公司不太在意了。为了快速地发展，你可能会经历股权稀释。那创业团队，要么就放弃控权会失去控制权。

比如说，大家很熟悉的乐视入主夏普，就搞了股权混战的，管理层内斗，导致创始人周娟最后失去了新董事会、比如明阳人，当时是向明阳人投资了2亿元，但是中间也是因为各种事故，最后张江被掏空身处于。离开自己一手创办的明阳集团。所以说，资本和创业者之间的控制权之争，其实是这些年，资本市场上的一个焦点。

阿里巴巴的情况跟很多创业团队一样，在发展壮大之前一定会经历多轮融资。它大概经历了4、5轮的“远嫁”，又经历了B2B业务在香香上市、退市这么几轮。所以到2013年准备重新上市时，马云团队股份已经被稀释到了10%左右。远远低于日本软银集团和美国的雅虎。但是，管理团队不愿意卖掉控制权，所以在新交所谈判，他引入向美的合伙人制度。这是什么意思呢？就是现行的，管理团队拥着董事会里多数的提名权权、比如说董事会现有有9个人，我们合伙人可以提名5个，也就是能提最有半重的多。所以，即使管理层只有10%的股份，也可以把阿里巴巴的控制牢牢地抓在自己手里。

但是，港交所不支持这个合伙人制度。阿里管理层就承认，这是他们的底线。后双方就谈崩了，阿里就跑去美国的证交所。而美国证交所有18亿美元的募资金额为及美国股票市场以来以最大的IPO。而且到了2017年底，阿里的市值已经突破4500亿美元，是全球的第九大公司。

阿里为什么会舍弃纽交所呢？其中最大的原因就是纽交所允许AB股制度存在。AB股制度，说白了就是两不同种股权。公司在发行股票的时候发行两种，一种叫A股，一种叫B股。A型的股票就是我们从这些普通的公众，B型的股票由管理者持有。B型股票投票权是A型的10倍，也就是我们看有的是一股一票，大家可以一般去。你着，这样一来，马云团队用10%的股权就能完全对控制公司了。所以这种制度的本质和里面的合伙人制度是一样，就是让创始团队能够用较少的股份来控制公司。

这种股权结构，不是在原来那种资本为王的时代，是想都不敢想的，就是宏观形势发生了，科思德型企业也兴旺了，所以慢慢地也接受得开所改自身的规则。美国的证交所有得好处，就是在这个地方。美国1992年的时候就允许这样的上市公司，让几个小公司设立不同的股票，在这个层面上允许公司都采取这个制度。比如说谷歌的两位创始人加上他们的CEO，三个人持有谷歌大概三分之二多的B类股票。这样一来，他们就稳稳地控股谷歌的决策权拿在自己手里。再有趣的，谷歌的创始人上市之前就给公司的投资者合约，新投资者若对本公司或融资的收购将不大地作用于他们“在其权上，我们是尊重自己企业的，我们知道怎么更好地运营自己公司。”当然了，事实也证明，他们确实是做到的。
