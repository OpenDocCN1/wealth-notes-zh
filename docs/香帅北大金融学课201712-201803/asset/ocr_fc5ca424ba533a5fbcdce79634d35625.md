# 一、“智能投顾”这个投资顾问到底智能吗？

我们先来看一看，现在最火的是“智能投顾”。从 AlphaGo 开始，人工智能也成了最时髦的名词，很多机构都通过自己为客户提供智能投顾服务，然后以智能投顾的名头来募资，智能投顾这个名字听起来非常地时髦。

其实，说透了的，就是大数据来对每个客户进行动态的风险测评，然后再根据每个客户的风险偏好推荐最合适的证券投资组合。其实这个概念金融圈一点也不科学，一个点是不科学，这是1952年由马科维茨提出的投资组合理论（Portfolio Theory），马科维茨给了三个理论（在1990年拿了诺贝尔奖），这个理论其实就是根据很多人的风险偏好，在千千万个证券中计算组合的风险最优组合，看上去，我们个人化的数据库这么庞大，大数据的计算可以那么精确，这个模式在理论上好像是行得通的。但是你要考虑到，这对金融服务商有非常高的要求。

+   1. 首先得有海量的个人实时数据。
2. 得有极强的大数据分析能力。
3. 还必须得大量的像行为金融学、心理学、计算机编程方面的高级专业人士。

你现在放眼市场，有几个机构能够做到像腾讯、阿里、平安等少数几家金融企业，可能具备这三个潜质，但仍然需要很长很长的时间去挖掘数据，理解人性，做得到智能投顾，这条路还是得靠修正的。

至于绝大多数号称智能投顾的公司，完全不具备什么条件，我都不想出来他们拿什么投什么，什么智能，又怎么投出资产来，所以，我觉得智能投顾现在很大程度上停留在一个概念的阶段。

# 二、机器人怎么选股？

另外一个特别容易进去的坑是什么呢？就是很多人对机器人选股的智能化感觉越来越清晰。其实机器人选股根本就不属于智能投顾这个范畴里面，它属于我们昨天讲的量化交易。

量化交易策略，其实是需要时刻跟踪风险的。目前完全的机器人、程序化的交易并不好，比如说大家最推崇的金融市场的，首先我可以用智能选股，像“阿尔法狗”——AIQ，就在2017年10月的时候，在它的第一个月之内，大幅度地输给了标普500指数，也就是美国的大盘指数。

更重要的是，如果这个股放到中国市场看不靠谱了昨天我跟你讲过，中国市场变化快，规律不恒定，小概率事件时有发生，这种需要人工监测的机器人选股，风险是极大的。远的说，就今年以来的金融严监管，几乎所有的量化策略都失灵了，我是最近两个季度，很多量化基金的绝对收益在1%到2%之间，比你的银行什么收益都高。而一些人选，很多机构说可以跑低通胀，机器人选股，很多时候就是管事的赌法。我希望你们对这智能投顾机器人选股这两个概念要有一个清醒的认识。

# 三、P2P投资靠不靠谱？

这几年，P2P 投资烧火不得了，什么叫 P2P? 就是 Peer to Peer，也就是个人对个人借贷平台，在 2013 到 2014 年一个多年的时间，平台出了 3000 多家 P2P 平台，而且你们可以看到，那时候市面上充斥着各种 P2P 理财平台。2015 年以后，像 P2P、大众集团这种互联网金融案的爆发，监管越来越严了。所以，到 2016 年，有 1700 家 P2P 已经被爆出，或者跑路等。到了 2017 年，这种倒闭的 P2P 平台已经达到了百分之五十以上，一半以上已经倒闭了。

P2P 平台为什么会频繁出事呢？不是因为没有问题，而是因为平台背后的金融逻辑不同。其实监管层对于 P2P 平台的定义是非常精准的，像隔壁，P2P 平台怎么定义 P2P 平台的呢？它就是个“网贷平台，就是金融服务中介，你不能用钱或向中间吸收存款资金，不得非法集资”，换句话说，要么是不允许你搞资金池。这就叫 P2P 平台要做的是解决资金对于资产，为什么 P2P 平台，P2P 做的是一个人对一个人的信用债。P2P 的核心是什么？是去了解借款人的资质，包括他的还款能力、还款意愿。
