# 059｜延展话题：卖空机制到底是福音还是祸水？

你好，欢迎来到香帅的全业大金融课。

今天的延展话题，我想跟你讲一个有强现实意义的话题，在周一的课中对基金这一课，也告诉你，你看某一个上市基金没有这个证券，对上市基金证券来说，其实，这个机制在全球金融市场上是非常具有争议性的话题。支持者认为它能够提高市场的定价效率，反对者则认为它加剧了市场的波动。

更有意思的是，每次金融危机过后，各国的监管层总是会把板子打在卖空的身上，然后对它进行限制和约束。今天我就跟你分享的是，对市场来说，卖空机制到底是福音还是祸水。

# 一、估值偏高的纠作者

刚才跟你讲到，卖空机制的支持者认为它，能够提高市场的定价效率，这就要说到行为金融学一个基础性的理论，叫“估值偏高效应”（overpricing hypothesis）。这个理论认为，一支股票的价格所反映的是市场上各种观点和信息的混合体，正面的消息会通过“买入”的行为进入价值，而那些负面的消息，就需要通过“卖空”来进入价格了。最后均价的股票价格反映的是乐观情绪和悲观情绪的加一个平均值。

但是你想，如果市场禁止卖空的话，市场价格最后反映的是什么呢？它就仅仅是乐观情绪的观点。所以会变成是一个估值偏高的现象。更重要的是，在牛市的时候，大部分的预期都持比较一致的，更激进的买入。相对于拥有信息的投资者去估值过高，由于不能卖空，这种信息，或者说股价也就没有办法进入到股票的价格中，股票价格的泡沫就越吹得越大了。

我给你举个例子，可能你会觉得更加明白。在2015年，乐视网的繁荣期，关于要空卖手们的争议，其实也没有停止过。看好的人把它看作是钢铁侠马斯克一样伟大的创业者和梦想家，认为乐视会有一个大格局或者影像，而看空的人就认为他是个太贪，像刘慈鑫或者发布过《乐视网析论》，认为乐视的烧钱模式难以为继，它的事情和观念的现象可以向很快被完成。问题是，看好的可以大量地买入，但看空的呢，市场没有这个办法，所以你会看到乐视网的股价一路上涨。

2014年12月的时候，乐视的股价大约在28块钱，到了2015年5月，已经攀升到了719块钱，5个月的涨幅高达535%。所以在这个股价上涨的过程中，乐观的观点被不断地强化，更加地加速了市场热度的，很多在这个点位加的散户就生生地成了接盘侠。

那如果A股市场有个稳定的卖空机制，故事可能就会不一样了。在年11月份的时候，有一家在美国上市的金融股金诚股份，就爆出了一个虚虚事件，这么人的一文旦，当这就引起了做空企业的注意。并购的效应显现，那么这，卖空企业的做空比例明显上升了，到目前为止卖空企业的股价已经下跌了30%。负面信息其实很快地被反映在股价当中，所以估值偏高效应这个理论的支持者认为，卖空使得更多空方也能够通过卖空进入市场，有利于刺制单边交易的，并正过高的估值，助抑资产的泡沫。换句话说，就是卖空机制提高了市场的定价效率。

# 二、市场波动制造者？

这个观点在学术圈算是主流，但是现实世界的运行，其实不像学者们想象得那么简单。尤其是在金融危机期间，投机客们会很容易利用做空机制，放大市场的悲观情绪，或者恐慌情绪，从而引起市场的剧烈波动。

一个典型的例子就是2015年，我们国家的股市市场的，当时有一拨爆开的机会，他们会大量地买入或指指数的卖空者，也就是大量地卖空股指，比如说沪深300，然后回来在现货市场当中，再抛出现货大盘后股票。你想看，当时那种投机又躁动的市场氛围中，这种行为是特别容易造成恐慌性的风险爆发的，然后卖空者开始大获。投机客们则可以在股指期货市场的大盘上赚一票。

很多股民应该还记得，当时跟他们是很激痛的，亏钱血本的痛苦与这些投机者找到了风口之上。加上，当时据说还发现了一家境外机构在做空，结果主权资本和这种情怀上升在做空，监管层果断地将刀尖子在做空机制身上，接造地出台文件，从开户金额，保证金，手续费等多个方面严格控制股指期货的交易，基本上就是我们股指期货供给抽掉了。
