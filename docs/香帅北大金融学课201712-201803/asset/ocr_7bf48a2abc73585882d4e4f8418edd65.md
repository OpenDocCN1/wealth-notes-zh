# ## 第一天：为什么说基金是资管时代的新王者？


第一天，我给大家介绍了基金的本质特征和两大优势，所谓基金，就是把大家的钱集合在一起，由专业人士打理的一种资产管理方式。简单来说，就是“资金募集，专业理财”。


![](bbox=[0.0, 0.15, 1.0, 0.17])

分散化和专业化是基金的两大优势，从近几十年的经验来看，中国基金业的收益率是最能够跑赢大牛的。

# ## 第二天：怎么选择基金？给你一个投资坐标系


![](bbox=[0.0, 0.22, 1.0, 0.24])

第二天，给大家介绍了一个选择基金和配置基金的二维坐标法，这个二维坐标包括投资标的和追求风格两个维度。从投资标的来看，追求高风险高收益的就应该多配置债券，追求安全性的人就应该多配置债券，而追求流动性的人就多配置货币。


![](bbox=[0.0, 0.26, 1.0, 0.32])

从投资风格来看，主动型基金是通过选股和择时，在短期波动中追求高大盘的超额收益，这种基金适合那些性格极多变的“狐狸型”投资者。


而被动型基金，一般就是选取一个特殊的指数成分作为投资的对象，后者在长期趋势中获得市场平均的回报率，这种基金就适合那些安金雀舌的“树熊型”投资者。

# ## 第三天：私募基金比公募基金更高端吗？


![](bbox=[0.0, 0.44, 1.0, 0.48])

第三天，我们接着讲了私募基金的概念和特征。私募基金本质区别就是监管程度的不同。私募基金监督少，只面向高价值个人。为了管理人以及投资者的利益能更加一致，对经理人采取激励，但是激励增加也有副作用，它会增加经理人对短期业绩的追求和赌博心态。


![](bbox=[0.0, 0.5, 1.0, 0.52])

平均来看，私募基金的业绩比公募要好，但是私募基金也有一个很大的问题，就是它不公开，投资的风险非常高，大家介入的时候还是需要谨慎。


![](bbox=[0.0, 0.54, 1.0, 0.58])
