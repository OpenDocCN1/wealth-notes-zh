# 032 | 杠杆收购：华尔街的黄金游戏



你好，欢迎来到傅帅的北大金融课。

昨天，我们已经开始讲投行的另外一个传统核心业务，叫兼并收购。今天，我要接着给你讲一个话题。但是，今天我要特别给你，这是一种特殊的兼并收购，叫杠杆收购。

它特殊在什么地方呢？它就是用很少的自有资金去撬动很多的外部资金来进行收购，就像用了一根很长的杠杆。

前一章你有印象，不知道你还注意到没有？陈坤晓的“小燕子”赵薇被证监会处罚了。为什么呢？就是用了大量的杠杆来去做。为什么呢？这是一个价值30亿的企业，她自己只出6000万来买。你说50块钱的，所以只出个2块钱，付了9元，用50倍的杠杆来做1个2亿美金的游戏，这就是今天要讲的杠杆收购。

# 一、投资银行家怎么玩杠杆收购的？

你可能会感觉，这个杠杆收购可能是个坏事的东西？不是吗？就是空手套白狼？可不是，这逻辑不精确。杠杆收购可以是坏事，也可以是好事，关键看你怎么做。

首先，我们来看一看，这个杠杆收购到底是怎么样的，杠杆收购和所有的兼并收购业务一样，也是起源和投行。它是在上个世纪60年代，一个叫科尔伯格的美国投资银行家发明的。

当时市场上有很多家经营的小企业，生意不好，管理很混乱。但是企业主年老了，不想把公司卖掉变现。但是，企业主已经在这家企业，企业像他的儿子一样，企业主经营企业，想像经营和管理企业，用今天的说法，就是想卖掉所有权，保留经营权。

但是当时市场上的情况是这样的：只有大公司有资金来企业，买完了以后，业主得很快被控制起来。科尔伯格是美国的大投行贝尔斯登的投行的老板，在1965年的时候，他遇见了一个爱尔兰牙医开的小公司，这个小公司呢每年，公司利润特别多，老板已经很专业了，身体好了，这个时就是想做给别人管一笔钱，但是自己也没有那么多钱，他想继续经营公司。科尔伯格就给他出了一个杠杆收购，最后用自己的杠杆资金去收购，用85%的杠杆去收购了这个公司，买下来之后，他自己要控制的资金比例，原来的80万债务，只要付80万，那原来公司的老板就只需要付80万的债务和收购价，80万的债务和收购价是80万，那原来公司的老板就只需要付80万的债务和收购价，80万的债务和收购价是80万，那原来公司的老板就只需要付80万的债务和收购价。

4年之后，这家企业经营得非常稳健，负债也慢慢地降了下来。到那个时候，科尔伯格又一次用了自己很高的销售和融资能力，把这个公司打包，重新上市了，赚了8倍的利润。所以，杠杆收购一点不复杂，就是借钱买企业，然后再用四两拨千斤的办法取得企业的所有权。

通过这个故事，其实你会发现，和我们刚才讲的“小燕子”的例子不一样。杠杆收购并不是“血汗方”。企业主享受了，保证了经营权，然后投资银行用4年的时间赚到了8倍的利润，年回报率接近70%，而用同样的借款钱给他的也获得了稳定的利息收益。所以，在这个案例之后，科尔伯格就投资了另外两个投资银行家，一个叫克莱曼的，一个叫罗根特的，用这3个名字的每一个母成立了一个叫KKR的基金公司，在市场上的募资，专门来做杠杆收购的生意。

# 二、成功的杠杆收购需要满足的三个条件

现在你已经明白了，杠杆收购不一定是坏事，它可以实现多方共赢。但是，实现多方共赢其实是有条件的。有哪几个条件呢？

第一条，从刚才我们这几个例子里，你就会发现，公司的现金或者利润，一定要非常充沛，稳定。因为如果资金不充沛，不充沛，还不出利息的话，企业很容易破产。比如说一家生物制药公司，研发新药，可能要十一年还不上本，付不起利息，企业也会倒闭。所以，第一条就是企业的现金流一定要稳定地充沛。

第二条，就是你真的能够找到那种既有能力，又靠谱的公司管理层，能够大幅度地提高企业的经营杠杆，还要能削减成本。为什么呢？因为杠杆收购以后，企业的负债率就很高，本金付的压力会很大。所以，如果能削减成本，提高经营率的话，那很多高的负债企业就会像钢丝一样，很容易出问题。

第三条，就是杠杆利率要适中，融资计划要像案例中说的相对简单。因为给企业带来太高负担，呢？或是企业管理层不靠谱，还借了低息来运作也成不了什么？这些都会对杠杆收购的成败造成巨大的影响。所以说，听上去杠杆收购这件事简单，就是借上钱，买家公司，但是是非常考验投资银行家的智慧。你怎么样选择，怎么考虑，怎么融资计划怎么，怎么改组织企业，怎么退出，每一步都非常重要。只有所有的方面都做好了，你才能够实现多方共赢。就像我们刚才例子里面说的，科尔伯格做到了，就能够帮助中小型企业的企业主，帮他们有以换掉那个不得力的管理层，提高整个企业运营效率和价值水平，让中小股东受益。

比如说，刚才我们说到，科尔伯格建立了一个叫KKR的杠杆收购的基金，它在2002年收购了加拿大的一家公司。在它们经过研究发现后，加拿大的这家空二一二六，叫作KVR，这里就请了一位人力资源专家，重新设计了一个管理机制，然后规定，每一个员工每天得订2个小时，不然的话，每一个员工，每天少干一个小时，公司的销售额就翻倍，很快地就实现了盈利。

还有，就是大家很熟悉的例子，2015年的时候，民生银行杠杆收购万科。在万科被收购万金之后再的14个月内，万科的股价被拉了5个涨停板。不少万科的小股东们都赚了钱。所以说这种杠杆收购除了以换掉不得力的管理层，很多时候中小股东还可以受益。

# 三、高杠杆率也会伤害企业

高负债率，其实也会容易拖垮企业。比如说有一个非常著名的案例，KKR在1986年的时候去2446亿美金的价收购美国的烟草公司雷诺兹，雷诺兹的股权结构，当时管理层和投资银行家佩德·鲁德，有一本畅销书叫《门口的野蛮人》，写的就是这个案例，导致后来杠杆收购就被称为门口的野蛮人。

当时KKR在这个案例上用了非常复杂的结构化融资方案，杠杆率高达90%多，但是，后来随着烟草行业慢慢下行，一个好好的企业被过高的负债压得喘不过气，效果一路下行。一直到1995年的时候，KKR以零利润退出。尽管在80年代的时候，这种结构融资很沸腾飞扬，但是这无疑是一个非常失败的杠杆收购的案例。所以，一个非常负债的资产企业，这就是为什么赵薇这种用10倍杠杆的原因。在中国企业被管理是叫财务的原因，因为杠杆率到达到一个程度的话，不要怪经搞垮企业的做法，看上去更像一种投机和套利的做法。

所以，杠杆收购既不是天使，也不是魔鬼，要具体情况具体分析。现在，中国的债和美国的60、70年代有相似。在推入退休的年龄了，他们的下一代基本上都是80后和90后。这一代的人比父辈更加多元化，更多的人就不是要接手老企业，所以很多的中小主企业，现在就面临着杠杆收购的情况。再加上现在全球低利息，资金很充裕，所以我们看到的企业的趋势，在中国会出一批杠杆收购的浪潮。这个趋势会出现得特别快和企业注意的。对于普通百姓来说，也不用关注这样的企业，为什么呢？因为就像我们刚才说的，一旦进入杠杆收购，这种企业基本上就会有相当程度的溢价，是很好的投资标的。
