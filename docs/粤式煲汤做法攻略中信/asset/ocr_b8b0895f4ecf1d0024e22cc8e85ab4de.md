# 石斛麦冬汤

# 主要食材

+   - 汤料: 铁皮石斛、麦冬、玉竹、百合和蜜枣。
- 适合搭配的主食材: 鸡、瘦肉、鸽子和排骨等。

![](bbox=[0.52, 0.17, 0.95, 0.53])

# 做法步骤

+   1. 将石斛、姜片和蜜枣洗净备用;
2. 将主食材洗净并切块后加姜片焯水;
3. 将所有食材一齐放入煲内, 加适量清水;
4. 用大火烧开, 等水煮沸后转小火煮1.5小时, 最后放盐调味即可。

# 营养价值及适合人群

+   - 营养价值: 此汤清热养胃、生津止渴, 健脾养胃气, 生体液, 解渴钦。石斛有推动胃酸代谢, 提升结肠平滑肌肠蠕动, 促进消化吸收等功效。
