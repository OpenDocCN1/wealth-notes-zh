


# 米联储见250804——掌银台危机(川普会美国经济带入黄金时代吗?)

你好，我是米罐。

非农数据跌给美国股市带来了黑色星期五，但实际上，美国的经济状况并没有想象的那么糟糕，相反很多迹象显示，川普的操作并没有快速摧毁美国的经济，似乎还处于勃然的状态。美国经济分析局日前发布的数据显示，美国4-6月GDP按年率增长了3%，不仅超过市场预期的2.5%，更与一季度0.5%的负增长形成鲜明对比。连着盯川普的纽约时报，为了解释这种不太寻常的现象都专门写了一篇评论，“关税阴影下的美国经济天没事，是经济学家错了吗？”可见川普二次执政的第一个完整执政季度，从经济数据表现看出显著的反弹，这件事对对手都得重新审视川普的操作，到底是自己的认知深度陷入迷途，还是川总的操作确实神奇，难道川普真的会将美国经济重新带入黄金时代？

如果是，这对于已经站上擂台美国正面对决的中国来说，肯定不是什么好消息，因为是个明白人都知道，中美对决或竞争从来不是势所能力的竞争，是需要此消长加持的竞争。我们不要保证自己一直决策正确，还要依赖对于对方经常犯错，需要一个失掉掉水的美国，实实在的，中国要可以持续发展，理性规划，这些调整是有必要的。

是需要的。当然搞清楚目前美国经济的真实状态很重要，到底是真正的实质性经济改善，还是统计技术调整与政策短期效应叠加的结果，这对于判断未来的局势和战略相当关键。

美国二季度GDP为何从下降0.5%至大涨3%？这还需溯至三个月前。当时美国公布一季度GDP数据，获得了0.5%的负增长。当时部分媒体因美国经济出现负增长而断言其陷入衰退。但上一季度经济收缩的根源在于贸易领域的技术性调整。早在川普4月2日正式签署对等关税法令，全球市场已形成强烈预期，各国出口企业为规避关税风险，纷纷在3月加速对美国出货。

美国进口商出于成本考量，要求供应商提前交付订单。这种“抢出口”与“抢进口”的双向加速，直接推高了一季度美国的货物进口规模。当进口量大幅回升时，净出口数值必然收缩，甚至可能转为负值，从而对GDP增长带来拖累。具体数据显示，2025年第一季度出口对美国GDP的贡献率达到-4.61%，其中商品进口的负向拉动达4.84%。同期美国3月贸易逆差历史新高，这种“抢进口”效应的直接影响了美国经济增长的表现。进入二季度后，随着关税政策正式落地，美国对全球商品加关税的举措开始抑制进口需求。同时，一季度已提前储备库存，在此背景下，二季度进口规模收缩直接推动出口经济增长的正劲。数据显示，净出口对GDP的贡献率跃至正值的4.99%，较一季度提升近9.6%，其中商品进口的负向拉动转为正向拉动超过5%。这种戏剧转折，本质上是政策调整引发的贸易节奏，而非经济基本面的实质性改善。企业短期无需规模补货，多重因素导致二季度进口较一季度显著回落。

分类别，二季度中国国际购买（PIP）按月按年率继续下降，从一季度的1.9%至二季度的1.2%，取得2023年一季度以来新低，指向消费者和私人固定投资延续放缓。不过消费面，二季度美国消费项按月按年率录得1.4%，较上一季度上0.9%，主因政策不确定性退后，消费信心有所修复。但从按年增速来看，消费项年增速回落至2.4%，指向消费仍在下降，服务项按年增速拖累按年增速下滑的主要原因。

从销售增速来看，2025年6月美国零售销售按年增速取得3.9%，4月、5月零售销售按年增速均为负值，见关税导致的物价短期调整对居民消费的影响显著，居民对物价上涨相当敏感。一方面，美国实时薪资按年增速在1%附近波动，薪资收入保持稳定。但另一方面，信用卡贷款利率在高位，后续消费需求或有所缩减。

投资方面，二季度投资按月增速大幅滑落至-15.6%，较上季度降低39.4%。非住宅投资按年下降至3.2%，住宅投资按年增速下滑至-1.3%。其中，非住宅类下的建筑投资按年下降至-3.8%，高利率在抑制购房热情，开发信心不足，企业对地产投资热情不高。此外，6月失业率下降至4.1%，过劳动参与率下降至62.3%，指向永久退出劳动力市场的人数增加。6月非农就业人数略增至14.7万人，但政府贡献了一半的就业，私营部门新增就业从5月的13.7万人大幅放至7.4万人。7月这个数字又暴跌了一半，今年以来，动量持续录负值，指向劳动力市场仍在降温。

川总自己手里有钱，而且这个GDP增长让川普宣布胜利，川总甚至要求白宫弄个亿美元的超级豪华宴。白宫秘密秘书塞维特更是发布：美国增速超出预期，消费者信心也上扬。

川普的议程不断减少美国对外国商品的依赖，推动本土投资，创造了大量岗位。为了自己的中期选举，降息不仅是经济工具，更是搅动选举的杠杆。这次美联储投票，川普任命的联储理事舒曼和沃勒下反对票，主张立即降息25个基点，这是1993年以来美联储首次意见分歧。从这个角度看，鲍威尔不再为动，川总杀人的心思都有了。

面对这样的经济局面，联储依然保持不动。2024年12月降息后，联储已经连续第五次按键不动，继续选择观望，其核心逻辑依旧是经济前景不确定性仍然高，另一个维度就是担心通胀。美国劳工部数据显示，CPI回升至2.7%，这一数据虽突破警戒线，但打破了此前回落的趋势。对于眼下的经济，不如华街这么强硬，拒绝降息的唯一可以解释就是华街对美国经济判断半信半疑，还要为政策留空间。相比于对美国债的认知，现在美联储几乎不能犯任何错误，因为留给美联储的试错空间非常小，试错成本非常高。对川普而言，自己的任期是四年，下台之后管洪水淹天还是天下。

当前美国债务近37万亿美元，占联邦政府支出逾14%。7月初引发的《大而法案》，更是政府债务上限再抬高。可以说，美联储稍微松，财政压力就会缓解，这对川普和鲍威尔来说，就是你死我活的平衡。若降息50个基点，每年可减少利息支出近2000亿美元，也就是关税战打多久，美国的日子就好多了。

此外，降息还会激活产业投资，尤其是房地产市场。今年关键经济指标纷纷走低，川总需要降息这一强势调整，通过低利率带动企业投资、促进消费、推动股市，真正创造欣欣向荣的黄金时代。

全球高手都虎视眈地盯着美元债。但是也别忘了，美国当初成为大国并非偶然，要列举国家优势，要说战略纵深，美国只会中国更具优势。美国虽然年轻，但同样是生命力强的国家和文明，更重要的是与对手竞争时，如果你的胆量是建立在对手犯错的基础之上，那么这场决定从开始就隐含重大风险，中国还需要更加努力，再强一点，再强一点。
