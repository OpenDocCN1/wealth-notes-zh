


# 复杂的汇率博弈

猫哥原创

但是人民币汇率是一个超级复杂的问题，远非面上就那么简单。

首先第一个问题，对于人民币汇率，为啥官方层面主要是欧盟意见很大，而老美却一声不吭呢？

给大家一个数据，今年以来，人民币汇率对美元升值了4.6%（主要是最近几个月），但是对欧元贬值了8.4%。

## 为何人民币汇率会出现美元升值对欧元贬值的情况呢？

主要原因就是美国政治变动！

今年1月特朗普上台执政，一开始对兔子很不友好，拉开一副大贸易战的架势。

对此我们央行是怎么应对的呢？

央行的应对策略是通过多种手段将人民币兑美元汇率中间价牢牢钉在7.17—7.35这个区间，不管美元怎么波动，人民币始终控制在7.17—7.35，直接导致今年1月美元指数从高点109掉到7月的96的时候，人民币基本没啥变化。

但是与此同时，因为这个区间美元走弱，欧元、英镑等其他货币对应应该走强，在人民币汇率基本没啥波动情况下，实际人民币兑欧元等货币出现超过8%左右的被动贬值。

一直8月之后，中美关系缓，央行开放人民币盯死美元的口，让人民币兑美元出现了4.6%左右的升值。

那就问题来了，为什么从年初到7月份，央行要让人民币兑美元汇率盯死在1个极小的区间？

几个原因：

- 其一，特朗普上台就对华挑起大规模贸易战，兔子也做好了对美硬刚底的准备，盯死人民币兑美元汇率，可以让出口美国的商品减少汇率波动风险，能做一点就一点。
- 其二，国际大产品是美元定价的，盯死美元汇率可以稳定进口原料的预期与成本，防止因为中美贸易战恶化导致人民币大幅贬值而影响进口成本增加。
- 其三，盯死美元汇率可以让人民币兑欧元、英镑等其他国家货币的汇率被动贬值，这也是分担与美国贸易战的压力，将对美出口减少的份额转移到欧洲日韩等国。

所以，今年1-6月，兔子对欧盟出口增长高达11.5%。

8月之后，中美关系缓，所以央行放宽了人民币兑美元的管制，人民币兑美元汇率突破了7.17—7.35区间，年内升值4.6%。

人民币升值，国内一片叫好声音，实际上很多人人可能并不明白一个道理——对于一个贸易巨额顺差的国家，人民币升值其实是弊大于利，至少目前是如此。

为什么？

我们假定兔子每年出口是2万亿美元，进口是1万亿美元，假设人民币升值10%，理论上我们进口可以节省1000亿美元的成本，但是出口损失更大。

我通过AI提问，假如人民币升值10%，我们外贸企业能够涨价多少，AI计算的结果大致是3%—6%，其中3%是主流，6%是极少数护城河宽的大企业。

也就是说，人民币升值对于出口企业是利润极大的损失，因为我们出口商品大部分是美元计价，短期升值太快，外贸企业是受不了的。

举个例子。

某企业在人民币兑美元汇率是7.1出口百万美元的商品，商品生产、运输有周期，等这类商业交易完成后，外贸企业收到100万美元，但是这个时候，人民币兑美元汇率已经变成了7，也就是说预期回款本来是710万人民币，现在变成700万人民币。这样的价差对于企业就是巨额损失。

所以不要说人民币短期升值10%，就是短期升值5%大部分小企业都是受不了的，因为产能过剩等很多原因，国内中小企业即便出口，利润也是不高的，很多商品。
