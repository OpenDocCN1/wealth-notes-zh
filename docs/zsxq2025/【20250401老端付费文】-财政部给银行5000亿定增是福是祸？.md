


# 财政部给银行5000亿增是福是祸?

发布时间：2025-03-30

文/端宏宏

今天傍晚，中国银行、建设银行、交通银行、邮储银行同一时间发布披露向特定对象发行A股股票预案，引入财政部战略投资，财政部拟认购的金额上限额约为5000亿元。

按照金额和认购数量推算出来，财政部都是溢价认购，溢价率并不低。

- 中行认购价格为6.05元，目前建价5.50元（溢价10%）；
- 交行认购价格为8.71元，目前建价7.36元（溢价18%）；
- 建行认购价格为9.27元，目前建价8.52元（溢价8%）；
- 邮储认购价格为6.32元，目前建价5.2元（溢价21%）。

增发股票，对老股来说是利还是坏？看的如果是折价增发，那定是利空，如果是溢价增发，看溢价越高越好。如此明银行股注定有一个高开，不过A股你也懂，只要银行大涨，那么小盘股就是血流成河。

对于这次增发，一些人表示不理解，因为银行的钱本本来就不出，2025年前两个月，银行房贷量创造历史新低，比景之2020年都差。年后银行又亏了一万亿消耗资金，2.5%的利率都出来了，这就了，也没拉动贷款量。就算房贷利率再次下降，百姓们也还是优先先把钱本出去，现在的银行的钱本本来不出，为什么还要补充资本金呢？

真正的原因其实很简单，我觉得筹备一次大规模的房地产泡沫化，就是开发欠银行的钱可能链坏银行（一句话），就让银行出血，那么必须给它输血，让他慢慢缓血，以补充资本金来了。我相信这只是第一批，接下来还更多的银行增发。

其实量化现在，头上已经有了一个基本的共识，就是债务是不可能被量化的，这一点我早就说过了，一旦债务消失，股市也同时消失，经济必然通缩，到时候的日子将变得更加困难。如果你无法量化房价上涨，那么等到房价下跌你就会更加痛不不生。在我看来这些浅显易懂的道理，我们竟然为什么要走这么多年的老路，那么多学费才会明白，也是无奈的啊。

既然无法量化，那应该怎么办？其实也很简单，就是稀释。用更多的债务去稀释债务，这是唯一的办法。财政部又没钱，这5000亿的定增资金是怎么来的呢？还不是特别国债筹集的吗？他要是不发债，哪里来钱购买它，之前多年收到的红，他就早就花光了。

你看，最后中央政府发债把面的债务接过来，这也是当下唯一的思路题，因为居民和企业都不愿意杠杆，那债务的重任就必须你来承担，如果你自己不发债，通缩螺旋只会让经济越越小。这个银行放资金，就是为了了解房地产的风险，只要财政部到位，中国经济就有救了。

从历史上来看，财政部的大规模资金注入共发生了四次，分别是：1998年、2003-2008年、2010年和2025年。

1998年那是97年亚洲金融危机，再加上给国国企业的贷款都是坏账，银行都接破产的边缘，再不自己都活不下去了。2003-2010两次是为了银行市场做准备。

今年我认为其实就是为了给房地产债，同时市场再次大放水。因为CPI还在涨，经济根本就没有出口了，我们已经错过了很多次救经济的机会，不再做真的了。房价再这么下跌，房产的空跌率还要大。

明天大指数就就涨，全A指数可能还要跌，因为银行吸血会导致中小盘继续续期。目前股市和A股都只是下跌中，没有到位。

全A指数是从983点上涨来的，最高到了1195点，涨幅接近22%，现在的调整仅仅跌了5.2%（1132点），距离跌到位还很远了，我认为跌到1050点附近就算到位了。
