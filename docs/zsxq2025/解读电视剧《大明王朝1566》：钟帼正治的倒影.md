


# 解读电视剧《大明王朝1566》：君权正治的倒影（深度）

《大明王朝1566》是一部典型的知识分子电视剧。改革开放以来，士大夫阶级重新掌权，中国在八十年代起起“文化热”。那时候诗人的粉丝，疯狂程度比今天明星的粉丝有过之而无不及。电视剧作为一种新兴媒介，也成为文化热的一部分。除了《围城》《四世同堂》这样的典型的例子，《渴望》甚至喜剧《我爱我家》都可算做知识分子电视剧。

九十年代后，随着经济发展和一些政治因素，文化热退却。电视观众逐渐“老母猪”——即便没有受过高等教育的中老年女性，讨论婚姻、婚姻关系的电视剧成为主流。近十几年，网络、智能手机全面普及，小镇青年成为娱乐产品的受众主体。中国的文学、影视大众审美，都呈现出低龄、低智化的现象。在这样的历史变迁中，知识分子电视剧市场日渐狭窄。《大明王朝1566》是知识分子电视剧的顶峰，也是绝唱。作者刘和平选择明朝为故事背景是经过深思熟虑的，除了史料丰富。

# 明朝的人文环境与今天没有太不同

前的宋朝并非非典型的科举官僚社会，且蜀妻桂鸾、四相簪花这样的故事已如上古。清朝则有民族问题，版相特殊，未免不美。

有人喜欢把《大明王朝》看作权力斗与《权力的游戏》比较。这未免负了两位作者的美意。《权力的游戏》是历史剧，《大明王朝》讲的是君权正治的根本问题。《大明王朝》道出了明清以来，君权惯性的根本问题——科举官僚社会有基因缺陷。无论多少能驭乾坤，一旦进入这个系统，都不得不走上相互妥衡、相互绞杀的结局。整个社会会在制度性腐败中逐渐走向灭亡，皇帝当然是链条中的一部分。

中国历史悠久，皇帝的类型应有尽有。有唐宗这样的英雄豪杰，也有刘邦、朱元璋这样的底层出身。有人杀如屠的精神变态，也有喜欢做家具的手工爱好者。《大明王朝》塑造了嘉帝、裕王、李忌三个不同的统治者形象。历史上的嘉帝以聪明、性格坚毅、政治天赋过人称，十四岁就闯出大礼议事件，在与官僚士大夫集团的战争中大获全胜，一边用武力制服官员，一边在人格上格服他们。

也是嘉靖开始，中国的士大夫日渐“奴化”。《大明王朝》中，作者用春秋笔法描写了嘉靖这个典型的昏君形象。他不爱自己的国家，打着充盈国库的旗号自己敛财；他也不爱自己的子民，毁堤荒田的事情之一——“皇上心里装的是九州万方，一两个县的百姓嘛”。嘉靖帝这一类的统治者，最恶劣的不是贪谋私利、剥削下属，而是喜欢用术。对于统治者来说，这实际上流于上乘。与之相对是李忌的表现，剧中毁堤荒田事发生后，张居正、高拱等人的意思是不放弃浙江的百姓，赵此机会一举扳倒严党。

李忌马上反对说，她站在统治者的立场来看这个问题：党派斗争是官员的事，作为统治者还是应该以国家利益为重。剧集后期，为了让海、林夫妇安心替朝延办事，李忌让自己的弟弟跟随他们，这个做法保护的意义远远大于监控。使用权术的人，说到底替下属考虑就是自己考虑，这才是统治者的阳谋。裕王是中国历史上最常见的一类皇帝，有事的决心，但资质平庸。不过他信任下属，不掣肘，在短短几年内，反而做成几件大事。

这就引出了中国历史中非常有有趣的两个秘密：是不怕皇帝甚至穷藩，只怕他们想当明君，这类皇帝往往好大喜喜，高估自己的能力，错事做仿佛他们对国家造成的伤害远大于“二十年不上朝”或“骄奢淫逸”。二是在适当中，独裁总是显得更为有效。张居正当政时期，他实际上是帝国的独裁者，改革才能推动下去。并不是独裁，而是独裁统治可以更残酷。大明朝，郭党和东林党还能争取，到了清朝，皇帝大权独享，就是说一句“乾隆不识字”也要随自处了。

作者刘和平在剧中呼吁“君君共治”，柔性反对独裁，或许还隐含着改革体制的期许，但他基本上对当时的政治是绝望的。剧集结尾，海瑞上疏的巨大风波过后，景睿驾世，明景裕王登基。政治并没有因此得到清明，徐阶取代严嵩，成为新一代需要被打倒的对象。一切回到原点，再次进入死循环。《大明王朝》中的这些统治者是国家政策的制定者，他们每个人都是帝国中国中的精英。徐阶、高拱、张居正、严嵩们都是极其高明的政治家。可以非常肯定的说，这些高层领导人、政策制定者，不管他们贪了多少钱，是不是昏昏，制定政策的初衷一直是想把国家好，现实情况往往相反。我们注意到一个现象：历史和《大明王朝》也是，高层领导人总忙着掏钱，国库空虚。《大明王朝》也是到了晚期。

# 核心思想与实际冲突

| 核心思想 | 实际情况 |
| :--- | :--- |
| 制定政策的初衷一直是想把国家好 | 高层领导人总忙着掏钱，国库空虚 |
| 帝国政策必然失灵 | 皇帝与地方利益的冲突 |
| 帝国政策不符合地方利益 | 派系相互掣肘 |
| 皇帝并不在意当地死活 | 地方官员是“外人” |
| 地方官员与商人勾结剥肉百姓 |

这句话的核心是：帝国与地方利益的巨大矛盾。很多人一直有个迷，认为地主与农民天然对立，农民是所谓的“土地并”受害者。事实相反，农民与地主利益是一致的。此外，高层领导人在处理国家杂事务时（经济、教育、司法……）必然涉及到人。

杨金水这样的卑臣干事办成件事都如此艰难，制度之恶可见。高翰文这一类的官员也不少数，出身好、聪明灵性，觉得国家治理不好，最重要的原因是没有重用。他这样的人，身上的骨气比别人高傲几分，可以想象他在写“以改账、两难自解”的论文时是多么感情澎湃。然而一旦介入现实政治，兜头就是一盆冷水。在上任的路上，上司胡宪问的几个问题就让他哑口无言。刚上任第二天，就中了富商沈一石的仙人跳，官场生涯未得展开已黯然收场。

实际沈一石、艺娘并不高明，对他这样爱惜声的人却有奇效。到此，高翰文们会走上两条不同的道路：一条是剧中的高翰文那样，彻底在官场中被清除；另一条则是变成郑泌昌、何茂才。郑、两人一开始也一定像高翰文那样，从政之立志要做为人民实事的好官，现实与想象满差。他们很快发现，一个人要管理二十多万人的县，手里的俸禄连请师爷都不够。剧中何茂才质问赵起齐：“我确实污了，这些钱多费用在衙门的开支上，我想问赵大人，不为污靠那点俸禄怎么办？”

于是郑泌昌、何茂才就一咬牙，为了办实事、为了造福百姓、为了维持衙门运转——就不得少齐一点。剧中的郑泌昌是嘉靖二十一进士，为官可算清廉，十多年都升上去，因为他秉持着圣人的道理：君子矜而不争，群而不党。官场声有了了，可回头一看老婆孩子，心中未免波动。难道寒窗苦十年，不如某能辈已经升任？

郑泌昌、何茂才在浙江打拼，由于历来深，没有背景，很容易被人吃骨都不剩。杨金水一个人玩转江南，坏事做够，最后安排“装疯”。浙江布政使，郑泌昌、何茂才在浙江，杨金水在官场经营多年，杨金水能力是厉害的。

这样的官员历史上不是没有。于廉、王阳明。于廉的死源于皇位争，王阳明一生坎坷，政治生涯不算成功。这种社会诚信向淘汰机制。海瑞在真实历史中叫人厌恶，剧中的海瑞却出彩，正直迂腐、冷峻又幽默，政治手腕高超。不过他应该作为一种理想被榜颂值得商榷。廉清不如廉好的制度。《大明王朝》是中国最好的电视剧之一，作者生动、准确的描述了与今天相似的社会现状。剧中几十个人物，每一个都栩栩如生，甚至都能今天找到原型。

# 富商沈一石

沈一石内心与高翰文一样清高。他对芸娘的感情与其说是爱情，不如说是揽镜照般的自惭内在。他虽是江南首富，但芸娘一样，也不过是官府玩弄的妹子。他是从沈大亨到胡雪岩再到今天，历代富商巨贾的缩影。任你才华横溢，你有非凡的商业和政治智慧，最终不过是被权力踩在脚下的蝼蜉。

芸娘的塑造极为出色。她原本秦淮河上的女儿，又被沈一石买来送给太监杨金水做妾。这两个身份都极为卑劣，可她天赋高从自甘下贱，爱上高翰文义无所顾。没有自己的身份，配不上对方的想法。她更不清高，追情郎时会使用小手段，后凭借自己早年与杨金水、沈一石的关系，帮助丈夫高翰文成为江南首富。可惜的是，高翰文也是个天赋极高的人，天赋高就意味着心高。被清除官场后，心有不甘，最终走上沈一石的老路成为富商。在波诡云诡的政治斗争中，这两个人的下场恐怕不会太好。

芸娘很有政治智慧。她和高翰文一起被囚禁时，曾对高翰文说：“他们不是让我看住你，而是让你看住我。现在沈一石死了，杨金水疯了，我是过去那些事的唯一的见证人，有些事情说清楚的时候还得找我去做见证。他们不要留着我。”
