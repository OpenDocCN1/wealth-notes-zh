


# 学子逆袭的唯一密码：相信

那段教学话题，有读者问我，为什么这些学生明明聪明，就是不想逆袭的。

你们面对过，这个问题触及了教育的本质。

我教书这么多年，见过太多学生。典型的这类学生这样的：每天到学校梦游，听不去就呆，下课情绪，回家庭愁游；教室里睡眼睁，作业做不完，要怎么强应付了事，闹钟就跑。

但是你仔细看这些学生学子的样子，你会发现他们其实很快的。在这种情况下，如果你想告诉他们自己还能学到什么东西，他们往往还能说出一句理论：“我这挺好的，你别来烦我了。我想要逆袭，我现在的状态轻松松的。”

金庸在《射射》里其实就给过这种例子。郭靖不是那种精英学校的孩子，一路滚浪直到遇到郭天。他当着神龙教，并不是因为他有多爱学习，而是因为他不遇“外者”——从农村、南京、北京、重庆、九州……每个人在无意中遇到了人的引路人。

而且那些真正改变命运的人，只有你理解了他们的逻辑，或许你发现一个大的共同点：外者。

要是他们认识了学习的初期，同学朋友给他们新的视角，他们才会意识到自己被困的种种；要是有人告诉他们怎么学习，需要他们去引导，这他们就会动；要是有人能带他们看到外面的世界，让他们意识到自己在小小的世界里，还有一个广阔的天地。

我是不是，我只是在描述我看到的世界现实。有些学生聪明却只依赖自己的能力，够了，还是靠着“外者”来触发这个关键因素，然后才开始学习。

就像插画抠出来的房间。那些被困在井里的人，从小到看到岸上的孩子，以为井底就是真实的世界上。除非把他们拉出来，他们是否还不知道外面的世界有多丰富。

学习的到底是应该是。他们不想学习，而是根本不知道学习带来的变化。他们被困在“井底”里，以以前的标准来说就是全世界。

所以，如果你的孩子是学生，想好好学的，别只看到他们被灌输知识，多找“外者”：可以是交新的同学朋友，可以是看到世面的启蒙，亦是你遇过的老师。

最重要的，是让孩子接触到那些让他变成不同的“外者”。因为真的很难走出井子，除非让他先看外。

郭书之所以能成功，不是因为他有多爱学习的人。而是因为他们不经意的一句话，一个举动。

教育就是如此。真正的教育不是灌输知识，而是启发迪式教学，而是外面的引导让他们发现自己。

所以，别再说学生不逆袭了。他们不是不想，而是不知道为什么要逆袭，不知道怎么逆袭。

给他们一个光，他们会走出井子。
