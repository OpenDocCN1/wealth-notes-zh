


# 要成事，必须学会造势

原创：U 君 公众号：赢在8小时之外 25年10月8日

事和势，是两种对立而又辅相成的能量。

前者是具体的、客观的，后者是抽象的、主观的。

如果你只是上上班、做点小生意，你就聚焦于具体的事务即可。

但是，如果你想做大事、赚大钱，你就不能只顾低头做事，还要学会造势。

如果你只会做事、不会造势，那么你将会非常辛苦，付出再多也没有可见的回报，而且大家都会念你的好。

只要你掌握了造势的精髓，那么什么事情都会事半功倍，而且所有的人事都会任你调遣、任你驱使。

今天我就给大家分享5个造势的思路。

## 1. 师出有名

刘备和曹操都想天下，他们走的路线虽然不一样，但是思路是一模一样的，那就是“造势”。

刘备在起兵阶段，自称是“中山王之后”，就是为了让大家认可他的“汉室宗亲”的正统地位。

这样的话，其他姓氏的英雄豪杰才愿意聚拢过来，心甘情愿地辅佐他、为他卖命。

而曹操在造势的时候走的是另外一条路线：扶天子以令诸侯。

他控制了汉朝的皇帝，就相当于控制了一个公司的法人和公章，从此发布的任何指令都能正言顺、师出有名。

其实，两个人都“造势”的核心逻辑高度一致的：刘备以“汉室宗亲”锚定真正身份，曹操靠“扶天子”掌控合法权威。

他们通过构建“不可替代的价值背书”来达到三个目的：降低外界信任成本、凝聚核心资源、建立竞争优势。

我们在创业、网赚、做生意时，该如何借鉴这一思维呢？有两个方向可以发力：

### ① 出身正统

电视里卖药的那批“老大夫”，每个人都说自己是中医世家，自己是第十代传人，这跟刘备自己“中山靖王之后”没有区别。

大家并不会考证你的真实血缘，但是只要你敢说，就会有人敢信。

类似的，君德、同仁等很多传统品牌都在讲自己的传承，而不讲他们的产品到底有多好。

英国、法国的很多奢侈品，珠宝品牌的宣传口是“皇室专供”，只要有了这个标签，其他的话全部省掉了。

### ② 核心认证

卖奶粉的品牌声称自己的奶粉获得了欧盟认证，卖电饭煲的品牌声称其电饭锅通过了日本认证。

这些资质就像曹操的“公章”，是开展业务的“合法通行证”，有了它，不仅能合规经营，还能在竞争中形成“你没有我有”的壁垒。

做媒体、网课也是同样，有些自己都搞了这一堆头衔，又是什么商会会长，又是职业心理咨询师，又是 MBA讲师...

还有一些国产服装品牌（比如某某登、某波尔），他们出来的旗舰号就是“远销世界50多个国家”，以彰显自己的国际化。

实际上，只要碰到这种宣传口号，我一律判定为割韭菜品牌，大概率质次价高。

但是，多数消费者是没有脑子的，他们真的会为这些虚华而不实、无从考证的口号而去购买。

## 2. 他山之石，可以攻戎

老人在追女人时，把全部精力都放在女人身上，功利心很强，所以对方的防御心理也很强。

但是，聪明人都懂得造势，要么在环境上做文章，要么借他人的人口。

比如，如果你想表白，可以先营造环境、烘托气氛，比如在看烟花秀的时候，或者在风景特别优美的地方。

因为当浪漫的气氛营造出来之后，对方的心门就是打开状态，这时候你表白成功的几率就高多了。

或者，借他人的口来造势。

如果你们都是大学生，那么你不要总是给她买衣服、礼物，而是要经常给她买一大兜水果，这样她的室友都能受益。

俗话说，拿人手短、吃人嘴软，她的室友经常蹭你的恩惠，她们自然不会说你坏话，反而会在她面前夸你。本来对你印象一般，但是身边夸你的人多了，她也会觉得很好。

职场上也是如此，觉得自己对公司的贡献很高，想让领导升职，不要傻乎直接跟老板谈。你可以通过侧击来造势。比如，你可以鼓动同事或老板那里夸你自己，说业务多少好，服务多少到位，老板才会动。

## 3. 营销造势

拿网赚/付费这个赛道来说，实力和造势是相辅相成的，缺一不可。无论是创业、职场、个人成长随便一个领域，实力的人都多如毛，但是能赚钱的人寥寥。

原因就是，他们不会造势。或者拿做社群举例，如果我想让更多的人加入，就要经常在外面展示“火热”。比如，有人里面分享成功的经历，有人在里面互动，有人在里面表达感激。总之，即使社群很冷，也要营造一种“火热”，这样才会有更多的人加入，然后社群才能真正火起来。

Fake it till you make it，就是这个道理。任何东西和服务的道理都是相通的，一方面时刻宣传“已经收获了好处”，另一面，你要时刻传达一种态度：由于购买的人实在太多，马上名额了，先到先。

讲这样一个故事：城里有一位大师，大家都觉得他厉害，于是他听说了，假装里面装满了人。大家之所以愿意加入，纯粹是想出去，因为里面憋得太难了。记住，即使腹空空，也不要表现出冷，这是一种弱点。在商业社会里，越让人知道你厉害，就越容易。

## 4. 频繁出现

世界上很少有人能实现“四两拨千斤”的效果，大家无非进场的次数最多。举个例子，很多人都说苹果手机和特斯拉汽车很少做营销，全靠产品质量过硬以及粉丝们的口碑传播。我却不这么认为，我觉得无论是乔布斯、库克还是马斯克，他们都是营销的高手，也是造势的高手。

比如，他们的形象和言论频繁占据社交媒体的头条，这本身就是一场巨大的营销和造势活动。其实在市场营销领域，有一个专业词汇“占领人心”。只要你的形象、产品或口号占领了消费者的心智，你就可以肆意销售了。

想要达到这种效果，最好的办法就是“频繁出现”。举个例子，我很喜欢看王磊的营销心得，他当年运作碧润产品时，就通过频繁在电视上打那种“朗朗上口”的广告来占领消费者的心智，“孝敬父母送碧润”，“送礼就送碧润”，他通过这些口号，把自己的产品跟“孝道”和“送礼”进行了绑定。那么以后消费者在过年回家看望父母时，自然会有概率选择他们的产品。

搞网也是同理，无论你写文章还是拍视频，你必须频繁输出作品，最好是日更。在这种频繁的信息灌输下，大家就会逐渐熟悉你、信任你，进而在这里成交买单。

## 5. 顺势而为

如果我们没有造势的能量，那么借势、顺势而为就显得非常重要了。

举个例子，经常有人咨询我：U君我也想做付费阅读和付费社群，但是不知道什么时候时机才是最佳的时机？这时候，你要用心感受宏观和微观两种势能。

宏观方面，你要观察最近自媒体的行情如何？公共平台的流量如何？如果他们的势头很猛，你就可以放心杀入。微观方面，你要认真听粉丝的反馈。如果大家对待文章反应很冷淡，不愿意留留言、点赞、转发，那么说明势能还没有。反之，如果大家讨论的热情非常高涨，而且很多人说你的微信和社群，这时你就可以借着这个势头直接开启付费社群。

最怕的就是判断不断形势，公众平台有流量的时候你观望，等到流量过去了，你才姗姗来迟。大家的热情非常高涨时，你才开始。
