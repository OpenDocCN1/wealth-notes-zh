


# 神魔皆以血饲

来源：赢在8小时之外（付费文）

整理：公众号【知识星球TOP】

在上一篇文章里，我把钱排到了健康前面，很多人不理解。

正常，我的价值观本来就跟多数人不一样。我的收入、生活方式、生命延续形式也跟多数人不一样。

我也压根不会寻求多数人的认可。

![](img/c78fd8c64b40ea9f8c890486b4dbc699_0_0.png)

但是，我相信还有一部分读者，是认可我的这种说法的，尤其是底层出来、想要逆袭赚大钱的人。

健康算什么？连性命都要排在成功的后面。

今年年初开冬奥会的时候，群里就有人问我看看不看这些奥运会之类的比赛，我说我从不看。

另外，我不去动物园，不看动物表演。

因为我知道，凡是能赢得大量掌声的动物，都是从记事开始就被毒打、被严格训练出来的，流了数不尽的汗、血水、泪水……

所以在我看来，欣赏它们表演是一种罪。

电影《霸王别姬》在豆瓣的评分一直占据top3，原因有很多。

不同的人能从电影里读出不同的东西。

有一句台词我记得特别清楚：不疯魔不成活。

为了练成京剧名角儿，程蝶衣从小就是在师父的毒打下长大的。

只要能让徒弟们练出真本事，所有的手段都要用上。

至于身体健康、心理健康，谁管你那么多。

一旦成了名角儿之后，所有的掌声、荣华富贵都来了。至于之前做出的那些牺牲值不值？这个不好说。

但是可以肯定的一点：自己的大名能被几亿人知晓，所有的达官显贵都是自己所倾倒，这种生命状态是万里挑一的，也不是有钱就能买到的。

其实创业、赚钱也是如此，你如果真的想赚大钱，得先把灵魂交出来，押在自己的项目上。

神魔皆以血饲。

无论你想成神还是成魔，只要你想做一番大事，赚大钱，必须拿出货真价实的生命精华。

我之前说过金钱的意义，金钱就是生命精华的凝结。如果有人肯赠与你金钱，那么他就拿出了自己的一段生命精华献给了你，这是至高无上的忠诚和荣耀。

同样的，如果你想获得金钱，也必须拿出自己的生命精华来换取。

赚钱就没有轻松的。

比如，我每天都会写很多东西，有时候写得头昏脑涨，但我还是得继续写下去。

如果买了新键盘，一般用不了半年，键盘上的漆就掉光了，而且我的手指肚都起了茧子。

之前有个人咨询我，想知道做自媒体需要掌握哪些技巧，比如直播这件事。

我说：你要做好一个准备，自己会累死在直播台上。只要你做好了这种心理准备，那么就没有做不成的。

如果你去调查，不论是世界五百强 CEO，还是球星、明星、诺贝尔奖获得者，他们都过多年的死功夫。

另外，大家也不要羡慕那些整天炫富的各种二代们，他们的父辈或者祖辈当年都为了赚钱拼过命，有的甚至直接在战场上拼过命。

当然，有的富人虽然没有长时间拼命的过程，但是他们肯定博过命。

就是来说，他们肯押上自己未来的二三三十年作为赌注，博一把。

赢了就世代荣华富贵，输了心甘情愿进去，即使吃枪子也无怨无悔。

当年东北的黑帮老大乔四是怎么起家的？

在他还是一个小混混的时候，自己的老大遇到了拆迁问题，有几户人家软硬不吃，就是不肯搬走。

乔四出了一个狠招：把几个钉子户召起来，当着他们面把自己的手指剥了下来。然后说，你们如果不服，就把自己的手指也剥了下来。如果不敢，那就乖乖搬走。于是那些钉子户都吓了，乔四也在道上扬名，享了不尽的荣华富贵。

乔四这样的人，不仅有勇谋，更爱惜身体。但是他知道，自己如果不搏一把，自己这辈子只能烂在坑里。

当然，不是绝对建议大家去做“魔”，而是希望大家去做“神”。

其实，任何钱都是用生命精华换来的。如果你若肯花钱，那么在某种意义上就是博命的人；那么你就有了非常大的领导力和魅力。

举个例子，如果你是一个创业者，带领个人一起拼搏，那么你就不要纠结钱。比起吃饭，升级办公室，给客户送礼，买豪车、买奢侈品……我之前讲过“两个”理论，就是说如果你是老板，在买东西时不要太纠结。

注意，我不是让大家浪费，也不是让大家冤头，而是要找到花钱、花钱的感觉。两者并不冲突。

② 无事更耗心血

有人特别爱惜身体，从来加班，更不愿意拼搏到深夜。但是你要清楚，不要以为闲着就是在节省自己的心血，保护自己的生命精华。错了，真正的休息和放松，并不是无事，而是做自己喜欢的事，做能给自己带来成就感和激情的事。为了梦想而拼搏的人，每天都精力充沛、心里满满。

另外，很多人不在事业上拼搏，把宝贵的生命精华都浪费在错误的事情上了。比如，跟领导斗智，跟同事尔虞诈，跟人生生气，跟自己内耗……这些事情才是浪费生命。何苦呢，还不如去赚钱事业。

③ 我们不会一直辛苦下去。

说句鸡汤：只要勤耕耘，总会有收获的那一天。运动员从起苦练十几年，如果有天赋的话，也到了该拿奖牌的阶段了，然后就可以接广告、做代言，赚钱钱。京剧演员从童子功开始，苦练15年差不多挑大梁了，然后名满天下。写作、创业也是同理，一万小时是一个比较客观的衡量指标。人不可能一直苦下去，只要你拼几年，把收入渠道打通，组建好自己的团队，找到了赚钱的感觉，也找到了花钱的感觉，自然就可以放松下来了，从此只做自己喜欢的那部分工作。

④ 最后我想说一句，拼命也不是无脑拼。

自己的眼睛、脊椎、心脏如果出现了不舒服的状态，一定要学会休息，或者去看医生。无脑拼真的会猝死的。虽然我嘴上说着把金钱放在健康后面，但我并不傻，有些“身体零件”出现了问题，后期修起来就很麻烦了，甚至是不可挽回的损伤。
