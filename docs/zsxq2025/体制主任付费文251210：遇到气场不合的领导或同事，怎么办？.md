


# 遇到气场不合的领导或同事，怎么办？

原文：主任 公众：只纯干货 25年12月20日

遇到气场不合的领导或同事，怎么办？

很多人上班如上刑，不是因为工作有多多，而是因为单位里有一个“孽缘型”领导或同事。

尤其是遇到那种“八字不合”的领导或同事，那种感觉就像鞋里进了沙子，走不快还得慌。

如果能够远离，那肯定是最好的选择，但是在单位里，尤其是体制内，大家的关系很稳定，几乎不会辞职。这位“冤家”就坐在你对面位，天天在你面前面前，更惨的是，他是领导的话，可能还会给你穿小鞋，运用各种权力来打压你。

很多人觉得，职场里要不要怎么滚，合不来就硬刚，大不了一拍两散。到后来见到太多因为职场内耗把自己搞抑郁、丢工作、错机会的人，才明白一个真理：遇到不合又不躲不开的，最高级的生存智慧不是对抗，而是“降维”。

可能有人问：“降维”这不是物理课上的东西吗？跟职场际有半毛钱关系？”别急，听我用大白话给你彻底说明明白。

熵，简单来说就是衡量“混沌程度”的指标。

熵值越高，情绪越乱、越没章法。举个栗：你房间如果三天不收纳，衣服乱丢、零食袋满地，这就是高熵状态——找袜子都得翻山岭。反之，房间整洁有序，就是低熵——清爽、省心，能量消耗少。

把这玩意儿用到人际关系里，“降熵”就是说：别跟那些合不来的的人瞎缠，别让他们把你的工作、情绪、生活搅成一团糟，主动减少必要的消耗，及时止损，让自己的状态回归有序。

有人可能会问：这不就是冷处理吗？差不多，但“降熵”比冷处理更有策略，它是主动设计你的互动方式，把不必要的摩擦降到最低，而不是单纯地憋着或者装死。

先算笔账：跟合不来的人硬刚，并不划算

为什么呢？

第一，权力不对等。领导手里有考核、资源分配权，硬碰大概是你吃亏。大佬集圈就算对方是同事，他若打算办公室政治，你的直来直可能正中下怀。

第二，情绪成本太高了。和“合不来”的人较劲，你会不自觉地花费大量能量——担心他背后在搞小动作，甚至回家跟家人抱怨。你会发现自己心神不宁，上班像在宫斗剧，天天提防别人，精神内耗重，这就像带着情绪负重跑马拉松，累死自己也跑不快。

第三，可能误伤自己形象。在旁人看来，频繁冲突可能被解读为“情绪管理差”。尤其是当对方比你更擅长扮演“受害者”时。所以，除非你找好下家或财务自由，否则公开对抗像在雷区跳舞——看着潇洒，实则危险。

很多人遇到职场恶势力，第一反应是拍桌子瞪眼。但往往会打脸：你跟领导吵架，第二天就能被去边缘（如果单位有相关业务的）；你跟同事撕逼，转头就能在茶间听到关于你的“精彩传说”。

心理学有个“情绪成本”概念：每次愤怒都会耗尽大脑前额的葡萄糖，让你决策能力下降20%。更可怕的是，这种消耗会形成性循环——你越生气，越容易出错，越出错，越容易生气。最后就像掉进沼泽，越挣扎陷得越深。

20 个职场冲突案例，发现硬刚结局普遍悲惨：

- 3人被穿鞋到离职
- 5人晋通道被被忍吞声
- 7人陷入持续内耗状态
- 只有5人“赢”了，但付出了巨大情绪成本

说了这么多硬刚的后果，那很多人会问：“合不来又躲不开，难道就只能气吞声？”当然不是！忍气吞声是“忍”，是被动承受，最后只会把自己憋出病来；而“降熵”是“策略”，是为了主动掌控，是用最低的成本，保护自己的情绪和利益。

简单来说，“降熵的核心：减少纠缠，停止内耗，把注意力拉回自己身上。

## 第一招：物理降耗——减少必要接触

合不来的核心原因，往往是“互动太多，摩擦就多”。就像两个磁场不合的磁铁，靠得越近，排斥力越强。所以，“降熵”的第一步，就是主动拉开距离，减少不必要的接触，让摩擦的机会降到最低。

怎么减少接触？

说是领导的“接触降熵”。如果你遇到一个控制欲、喜欢PUA，或者跟你工作风格完全不合的领导，千万别跟他走得太近，也别事事主动汇报。正确的做法是：

能一条消息解决的别当面。除了必要的工作汇报和沟通，别主动找领导聊家常、谈想法，更别跟领导分享你的个人生活和情感。很多人觉得“跟领导搞好关系”就是要多互动，但如果你们本身合不来，过多的互动只会让领导发现“不喜欢你”，反而招黑。如果不是紧急工作，你可以隔一会儿回复，语气简洁，不说多余的客套。在茶水间、电梯相遇，可以调整自己的位置，点头就好。

说说对同事的“接触降熵”。如果遇到一个惹是非、抢功劳、或者靠谱的同事，最好的方式就是“敬而远之”。跟他合作时，一定要把内容、责任分工、时间节点都明确，避免后续出现。工作上只做必要的沟通，不聊私事，不吐槽。聚餐等活动，如果无法避免，你可以选择性参与，或者尽量远离。

## 第二招：情感降级，降低对任何人的期待

合不来的领导，别望他能突然开窍理解你的工作方式；对合不来的领导，最好的态度就是“降低预期”。把他当成一个“合作伙伴”，而不是“伯导师”。跟他的关系，只基于工作，他分配任务，你完成得薪水而已。对他有任何额外的期待，自然就不会因为他的性格问题而内耗。

## 第三招：心理降级——在心理上筑起“防火墙”

如果对方越界（比如推销本属于你的职责范围），用平静坚定的定的语气婉拒绝。领导让你帮他做私事，或者让你承担其他同事的工作，而没有相应的报酬，你可委婉拒绝，找借口。别不好意思，你是来上班赚钱的，不是免费劳动力的。领导可以对你的工作提出批评和建议，但不能对你进行人身攻击、PUA或者人格侮辱。如果领导对你进行不合理的指，或者语言打压，你学会反击。

写在最后：成人的世界没有“完美解”，只有“权衡后的最优解”。当会在复杂的人环境中优雅地“降熵”，你会发现：那些曾经让你心烦意乱的人和事，逐渐变成了背景噪音。而你珍贵的情绪和精力省下来，投资到真正的事情上了，你会发现你的生活越过幸福，日子也越过好。希望以上对你有帮助。
