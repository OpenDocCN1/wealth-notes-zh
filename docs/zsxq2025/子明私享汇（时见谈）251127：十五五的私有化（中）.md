


# 十五五的私有化（中）

发布时间：2025年11月27日

11月北京线下读者会系列内容

每一次制定五年规划，本质上都是在对之前规划的国有资产进行一轮私有化。

2005年，十五的制定期间，坊间为热议的，是大型央企的私有化，

此时路线为右转后向右，代表是超大型国企能够被私有化，中国大批石油公司上市IPO，

2010年，十二的制定期间，坊间最为热议的，是基础设施的私有化，

此时路线为左转，代表是支付宝私有化，Izj被干掉和温州追尾，成立了以中铁总、铁塔公司为代表的大型央企。

2015年，十三的制定期间，坊间最为热议的，是金融存款业务的私有化。

此时路线为右转后向斜，代表是野蛮人入万科，出现支付宝、微信支付、安邦保险、明天系、陆金所为代表的民营企业。

## 2020年，十五五的制定期间，坊间作为热议的，金融贷款业务的私有化，

路线为全面左转，代表是在外滩放炮的JackMa被干掉，大型国有银行兼并了农行与广发小微。

2025的十五五也是如此，本质上也是拿出一部分的国有资产进行私有化，

按照历史上的经济周期，十五五期间大概率的模式是先右转再右实，前两三年期间有一波私有化的群雄逐鹿，后两三年涌现几个三足鼎立的超级巨头。
