


# 第一章 归来

李凡：醒了吗？

林辰猛地睁开眼睛，大脑中一阵剧痛，他感觉意识有些模糊，身体也传来阵阵虚力感。他努力坐起身体，发现眼前的天花板渐渐变得清晰。他环顾四周，发现自己正躺在一间有些简陋的病房里。

林辰：我这是哪里？

李凡：医院。你刚才受了重伤，昏迷了很久。

林辰皱了皱眉头，努力回想刚才发生的事情。然而，脑海中一片空白，只想起一些支离破碎的碎片。

李凡：别急，慢慢想，没事。

林辰：我怎么了？

李凡：你遭遇了车祸。

林辰：车祸？

对，当时一辆失控的卡车撞了你，好在医生发现及时，才保住了你的命。

林辰愣住了，他完全不记得车祸是怎么回事。

林辰：我真的不记得...

李凡：没关系，可能是伤及了大脑。

林辰：大脑？

李凡：嗯，医生说还要观察观察。

林辰：多久了？

李凡：已经昏迷三天了。

林辰：三天……
