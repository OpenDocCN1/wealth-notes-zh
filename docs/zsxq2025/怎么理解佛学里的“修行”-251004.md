


# 怎么理解佛学里的“修行”？

今天是国庆假期的第 4 天。估计很多人还在各地旅行。而且我猜在很多人的旅行清单里，都包括一个去处：寺庙。

根据艾媒咨询的数据，超过 58%的人去寺庙，是为了缓解生活压力和焦虑，40% 左右是为了祈福。

但是，对很多人来说，理解佛学的门槛不算低。什么缘起、性空、五蕴、般若，这些术语就能把人绕晕。

关于了解佛学，王路老师本人深入研读很多佛学原文，而且作为文字高手，他特别擅长把复杂问题“化繁为简”。

今天，我们就通过这门课，来讲解一个现在很流行的概念，这就是佛学意义上的修行。

什么叫修行？想要理解这个概念，咱们首先要消除一个误区，就是佛学意义上的修行，并不等于吃苦。

比如，很多人认为修行要磕头、受挫，总之，普通人必须一路吃苦，才能抵达修行的终点。

再比如，现在流行一种方式，叫“关修”。甚至很多人会花大钱去参加修营，去山上的酒店，去那种每天冥想的生活。说白了，就是认为得找个安静且没人打扰的地方，才能修行。

但问题是，在佛法时代，其实根本没有“闭关”这个词。前面这些所谓的修行，其实只是换个环境。虽然换环境确实会影响人的心理状态，但是这些影响只是暂时的，一旦你回到以前的环境，接触以前的人和事，过去那些烦恼可能很快又跑回来了。

那么，佛学意义上的修行是什么样的呢？按照王路老师的解释，佛学所说的修行，目标不是消除痛苦或者追求快乐，而是让人不被观念所控制。

你看，我们经常会说“我有一个想法”“我有一个观念”，多了以后，你会以为那个想法就是你的，你是某个想法或者观念的主人。但按照佛学层面的解释，观念只是暂时“住”在这里。我们的大脑就像观念的战场，有的时候一个观念变成另一种观念，有时候也会受到一些错误观念的布设。

没错，修行的目的，就是摆脱观念的控制，获得内心的平静。

那可能会有人问，这些解释到底靠不谱？有没有科学依据呢？

关于这个问题，有位进化心理学家，叫罗伯·特赖，曾经专门写过一本书，英文名直译过来，叫《为什么佛学是真的》。他就从现代科学的角度，证明了佛学中的很多观点是有科学依据的。

比如，佛学中有一个关键的概念，叫做“苦”，而按照很多学者的考虑，早期佛教语典中的“苦”，准确的意思更接近于心理学上说的“不满足”。

你看，从生物进化的角度来看，人类的目的就是繁衍。而为了确保这个繁衍能一直持续，人类就进化出了一组奖励机制。

首先，大脑会告诉你，只要做了跟传播基因有的努力，比如让自己更优秀、更强大，在各类竞争中赢得胜利，只要做了这些事，你就会快乐。其次，大脑又会让你觉得，这些快乐都是短的，不能持续太久。大脑机制是为了防止你偷懒，要让你一直去参与竞争。最后，即使你的意识面对面前两件事，你的意识也会把注意力放在第一件事上，就是始终让你觉得赢了就能快乐，而不会在胜利之前意识到这些快乐是暂时的。

换句话，大脑只是把快乐当作诱饵，来促使我们一直去争取强好。

当然，从基因传播的角度来看，这些设定是好的，对活生生的个体来说，这就容易产生痛苦。

关于这个点，科学家们曾经专门做过一个实验。实验的过程是：把一只猴子关在笼子里，然后笼子里挂一盏灯，只要灯一亮，科学家就会给猴子喂果汁。之后，科学家们会观察猴子大脑中多巴胺分泌的情况。

这个过程重复了很多次。结果是：刚开始，果汁一旦进入猴子的嘴巴，猴子的大脑就会分泌大量多巴胺。而实验多次重复后，猴子就掌握了规律，只要亮灯，即使没有上果汁，猴子的大脑也开始分泌多巴胺。但后来，亮灯导致猴子多巴胺的分泌越来越少，因为猴子掌握了规律，这种快乐来自于“期待”。

根据研究，人类也是这样的。在真正开始做某事情之前，你觉得这件事会有多么快乐，但真正做了之后，快乐反而没有了。

回到佛学，很多人都听过一个观点：凡相都是虚幻。对应《金刚经》中的一句话：“凡相都是虚幻”。这里的“相”指的是一切感知的现象，包括物质、情绪、观念等。而佛学认为这些现象皆缘而生，所以是虚幻的。从心理学上来说，这种感受被称为“满足感”。按照佛学层面的解释，布施的关键不在于行为，而在于“满足感”。也就是当一个人做出布施行为时，大脑腹侧侧被激活，这两个区域是大脑“奖励回路”的核心，与快乐密切相关。

首先排第一位的是布施。所谓布施，是指慷慨给予，它不仅仅包括财富。其次，持戒。所谓持戒是指约束行为。注意，持戒不是简单的禁忌，而是通过自律规范身口，避免伤害他人，保护自己和他人。从心理学的角度来看，持戒相当于一种自我控制的训练，管理自己的行为、情绪和欲望。换句话说，持戒的核心不是“被迫遵守”，而是主动选择“不伤害自己”。

最后咱们来说忍辱。说到忍辱，可能很多人想到忍气。但注意，佛学层面的忍辱并不等同于忍气。比如，一个人在工作场合忍气，回到家里对家人发脾，这不叫忍辱。按照王路老师的说法，忍辱是训练“情绪调节”能力，学会不被小事点燃。从神经科学的角度，大脑对情绪的加工存在两种途径：“快速通路”和“慢速通路”。所谓快速通路，就是外界的刺激首先传递到了杏仁核，而杏仁核专门识别威胁，触发反击本能反应。比如一个人“一点就着”，就是杏仁核反应太快了。所谓慢速通路，就是外界的刺激同时传递到了“前额叶层”，大脑这一块负责理性分析，能够抑制杏仁核的冲动。从这个角度看，佛教所谓的忍辱，目标就是要激活大脑的慢速通路，延长情绪反应的“窗口期”，让理性足够的时间介入，抑制情绪的过度激活。

好，说到这里，我们算是粗略地讲了佛学里什么叫修行？它的本质就像王路老师说的，修行的目的是看清真相，而不是改变真相。
