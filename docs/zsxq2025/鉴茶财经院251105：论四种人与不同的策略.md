


# 鉴茶财经 251105:论四种人与不同的策略

(下午安排,这篇本本来周末未发的,也顺带谈“AI泡沫”的,略调整后给大家)

咱们群里有四种，不同人的角度和策略是不一样的，今天再跟大家重申一下。

第一种人是经验丰富的“操作型选手”。

平均持股时间不超过6个月，甚至3个月，一礼拜的比例比都是。操作，即希望获得“交易利润”。

但有几点你要明白：

1. 纪律是你的核心，你得起码看得懂基础的技术图形和量价吧？均线和平台都不会看，不就是上战场没拿枪吗？
操作型的技术标准，再给大家说N+1次，N+1：
- 5日平台（站稳与强势标准）
- 5日上（下）穿10日线（去留标准）
- 20日线（调整支撑线）
- 55日线（牛熊技术分界线）。

何时击鼓进军，何时鸣金收兵，给过傻瓜口诀吧？你根据自己的敏感度和承受能力，自选风控标准。

2. 其实要玩操作，技术只是一个方面，你还得勤奋。勤奋地看各种资料，勤奋地了解各种信息，还要有时间看盘，复盘，做笔记。

因为你要赚交易利润。而交易，就是多空随时转换。今天看多的明天就可以看空了，昨天利的可能今天就利了。如果没技术，也没有时间，文章还是挑着看不，还望买在最低，卖在最高，有点为难自己了。

第二种人是什么人呢？产业投资者。

看什么？产业逻辑。看的是什么？PE估值。

如此：

- 海外算力的逻辑，是 AI与业绩突破。
- 国产芯片的逻辑，是自主可控。
- 创新药的逻辑，是 BD 大单。
- 变压器的逻辑，是北美缺电。
- 游戏的逻辑，是精神片上瘾，等等。

逻辑没有证伪，它一直能看。我说的几个校花校草，逻辑证伪了吗？没有，预期反而加强了。核心的几个，明年20倍PE你怕个德啊。

问题是，通常的持股时间是多久？3+2年，甚至5+2年。大家可以看看外头的私募基金封闭多久，看看大资金是怎么赚钱的。7年左右，是一个完整的朱股周期。高净值人群买私募还等5年，还得交个人所得税，你长线怎么不看3年？

产业投资者是不看K线的，他们只关心：市盈率是不是高了，公司还有无增长，这个行业的景气有没有过去。假如你是一个公司的股东，你会不会要求企业每天交日报给你汇总结，每周交财报给你研究？你嫌不嫌烦？

第三种呢，新手菜鸟，将来进阶。

你的目的是什么？跑过银行投资和外面的理财。我们讲策略，目前就是保险+恒生+定投机器人ETF。

比如保险，股价涨了，你拿股票增长；不像涨，你拿4%红利。更稳健的就是宽基指数了，比如创业50，科创50。大A的年化收益，拉长看是没有输过存款和信托的。

这里就有两种策略：一种是达到年化目标，比如10%，走了，清仓不玩了，明年再再说。还有一种，我反正定看着，平时也不动，需要了钱了再说，当一种理财。442，532等阵容，也跟大家讲过吧。你说你希望在ETF里搞点波段，最简单的5日平台，跌破就站稳进吗？

第四种呢？是第二种的加强版，真正的国运。

是一帮老钱，大钱，甚至小目标级别的，群里不在少数，那人家看什么？拿到核心的东西，是趴着不动的，是锁仓的。比如我们讲的，中国有望成为世界级企业。跟他们吃饭交流，大家谈的一个话题是：中国如果从世界第二变成世界第一，谁会跟一起登顶？非洲和欧洲用支付宝吧，阿里巴巴一个，中国移动要突破吧，也算一个，都有谁相关的。

他们的策略，是一定的保底（比如债基货币红利）+一定的宽基（纳指指数+A500）+一定的世界公司。底仓、行情不好就买的模式。

综上，你要知道什么？知道自己属于那种人，是干嘛的，承受能力究竟怎么样。是一一还是二，我们的文章每篇你都要看紧住，随时发现变化。不能前排锚化了，别人都切换登电力软件了，你还在那边退钱。也不能觉得自己，一会是国运，一会是产业流，又是操作流。跌破5日平台不走，下穿10日不走，20日不反弹走，等60日线了，你问我怎么办？也不能不能，明明是看产业的，账别人给你算了，逻辑也给你汇报了，结果每天亏的，毫无体面。要么是赌的还是操作的。不要骗自己，好好跟自己谈，毕竟是闲钱炒股，不要加杠。最后，既然亏了，缺口已经补了，55日线拉起来了，那就是短期情绪释放了。但你以为红了，看多了，站稳了？站稳了就破了？站稳了破了。
