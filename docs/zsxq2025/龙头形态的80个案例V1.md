


# 龙头形态的80个案例

## 条件：

1、 龙头形态的3种形态
   - 十天三板，三连板除外
   - 形态1：一板断后板又板
   - 形态2：一板断后后2连板
   - 形态3：二板断后再一板

2、控盘口决（庄家控盘指标确认）
   - 中控进场，低控等待
   - >60进场，<60等待

3、 进场口决
   - 低开进场，高开等待
   - 首阴进场，阳线等待

4、出口口决（顶格筹码顶峰确认）
   - 红峰持有，绿峰出发
   - 断峰持有，顶峰出发

## 1、花头形态的三种形态

### 形态1

### 形态2

### 形态3
二板断后再一板
庄家中度控盘
