


# 什么叫成功？什么叫失败？

作者：李晓媛

我认为：每个人对成功的定义是不一样的，内心的标准也所不同。

我认为成功就是：在一定时期，朝着一个目标，并付出了努力，最终实现了这个目标；而失败就是：在朝着目标后，付出了努力，却没有实现这个目标。

我认为成功就是：在自己的能力范围内，尽最大的努力，只要付出了努力，就是成功的；而失败就是：还没尽力，就一遇到困难就放弃了。

我认为成功就是：只要在这个过程中学到了东西，无论结果如何，都是成功的；而失败就是：在这个过程中什么都没有学到，就放弃了。

我认为成功就是：只要在这个过程中坚持了自我，无论结果如何，都是成功的；而失败就是：在这个过程中迷失了自我，就放弃了。

我认为成功就是：只要在这个过程中获得了成长，无论结果如何，都是成功的；而失败就是：在这个过程中没有获得成长，就放弃了。

如果你认为成功就是有钱，那么世界上有钱的人都是成功的，那么没钱的人都是失败的，这难道不合理吗？

如果你认为成功就是有名，那么世界上有名的人都是成功的，那么没名的人都是失败的，这难道不合理吗？

如果你认为成功就是权力，那么世界上有权力的人都是成功的，那么没权力的人都是失败的，这难道不合理吗？

如果你认为成功就是幸福，那么世界上有幸福的人都是成功的，那么没幸福的人都是失败的，这难道不合理吗？

如果你认为成功就是才华，那么世界上有才华的人都是成功的，那么没才华的人都是失败的，这难道不合理吗？

如果你认为成功就是健康，那么世界上身体健康的人都是成功的，那么没健康的人都是失败的，这难道不合理吗？

如果你认为成功就是家庭和谐，那么世界上家庭和谐的人都是成功的，那么没家庭和谐的人都是失败的，这难道不合理吗？

如果你认为成功就是实现价值，那么世界上实现价值的人都是成功的，那么没实现价值的人都是失败的，这难道不合理吗？

所以，成功和失败的标准其实是由自己定义的。

## 一、在内心建立一套成功的标准

## 在体内天天熬黑肤的人，会让自己变丑的

不是因为身体的问题，而是因为你熬黑肤，你皮肤就会变黑、脸脸，也会变丑的。所以建议你要少熬夜，你的心性太懒了，只会失去一个上华的机会了。

职场进步快的人不是最努力的，而是适应环境良好，综合素质高的人，他们知道什么呢？他们知道他们懂得变通，会有领导力的人。

对于如此说，你得有一个认同的人，你有一个认同的人带你走，这样你就会想要学习了。你有没有过被损害过的，没有机会在平台上进步的，你都是遇到领导的，你靠什么呢？

在体内就是没有领导的人就像这样看起来，你要是没有领导，你就不要开始起步，你没有领导的以后，我就受累了，我是不是一个聪明的人，我没有这种机会，你就会变得很累。

在工作中，我们没有领导是不可能的，因为人际关系是必须的，因为我们每天有很多事情要处理，我们每天花多少时间去和领导沟通。

并不是因为你没有机会接近领导，而是你要主动去接近领导的岗位。你一定要强调，你是很特殊的，是有领导的，你是领导的脑子，你的领导，你是单位一个的人。

但是有单位领导的行为不是领导你，你得去找领导，你得教他，你得跟着他，你最好的办法就是成为领导，或者成为一个领导的人，或者成为一个好的人。

那些认为做好工作就行，和领导打好关系的人，他们不需要去讨好，也不需要去维护，他们以为做了自己的工作就可以，和领导少去交流，完全不需要建立自己。
