


# 如何识别银行设置的理财陷阱？（大佬集团精选推荐）

今年有一个很有意思的现象：A股涨得不错，但中国人的钱却没有往股市搬家，反而是大家都去买理财了。

根据权威媒体披露的数据，今年二季度，银行理财单子增量几乎追平去年年末；到三季度末，全国理财产品的存续规模已经达到32.13万亿，同比增长9.42%。

为什么中国百姓突然更喜欢买理财了？这个不难理解。现在银行存款利率越来越低，而不少理财产品面上写的是收益，看起来还是挺诱人的。再加上，固收理财大多向同业存款单、国债，看上去风险不高，于是很多人自然就会动心。

但问题就来了，第一财经最近连续发表了两篇深度调查，把银行理财这波收益背后的秘密全部扒了出来，结果让很多人惊呆了。这些看似稳健又高收益的理财产品，真实的收益完全不像宣传的那么高，背后充满了猫腻。

今天我们就来系统拆解：

## 银行理财的收益
到底是怎么被包装出来的？我们又是应该怎么去识别那些银行设置的理财陷阱？知道这些对你的钱袋子绝对有用。

## 银行理财的高收益假象
到底是怎么被银行给包装出来的？其实方法并不复杂，初级的就是三种方式：
1. 第一种发生在展示端
2. 第二种发生在收益端
3. 第三种藏在理财说明书里

### 第一种展示端注水
如果大家去买过理财就会知道，银行展示给你看的产品收益，通常都是这种：某理财成立以来年化收益3%以上，过去一年年化收益4%以上。但你是真买了了这个产品，你未来的收益、更有参考价值的应该是最近一个月或者最近三个月的产品。但这些数据，银行通常藏在最难找的地方，因为很可能最近一个月收益就只有1%。这就是所谓的理财收益展示端注水——用过去最亮眼的一段历史收益把现在的暗淡遮蔽掉，给投资者制造一种收益错觉。

### 第二种就是往收益端注水
收益端注水指的是短时间内做出一段非常高的收益，通常叫“打榜收益”。很多新发理财产品刚上线的时候，银行通常采取这种策略，把收益拉得很，目的是为了让自己的新产品迅速冲上收益榜、热销榜，让更多的客户看到买进去。等产品差不了，收益就迅速回落了。

### 最后第三手段
就是要在理财说明书里动人心。有些理财产品的条款被银行设计的非常复杂，一般人都看不懂。比如上一个条款写的还是“不收取超额业绩报酬”，下一个条款就又写上了：“若产品持有期间，年化收益率超过业绩比较基准区间中枢，将超出部分按20%的比例提取超额绩效报酬”。

这就纯粹是设置文字陷阱了。银行的目的就是为了收取20%的超额绩效报酬，割投资人一刀。通常银行会把所谓的基准中枢收益设计得很低，只要偶尔资产表现好一些，银行就可以用这个条款抽大家20%的回报。但投资人根本不知道这里头的猫腻，你要是跟银行较个真问问他具体怎么收费，银行会丢给你一大串你根本看不懂的公式，还会用投资端如何、产品端如何各种话术把你绕晕，反正你是不明的。

最后的结果就是：你拿到的投资收益根本不如他们宣传的那么高。前面这3种理财产品收益注水的方式都比较初级，都是些银行耍弄的小手段。但是银行现在又发明了一种更高级的玩法，可用T-1估值套利模式，这个就相当厉害了。

## 基本上做到割客户于无形
大家知道，我们平时买基金都是未时申购的，你今天买，按今天收盘后的净值算。但部分银行托专户的形式采用的信托专户的形式，他们的规则是：你今天买理财，可以按照前一天的价格结算；你今天赎理财，也可以按照前一天的价格结算。这种就叫T-1模式。

这个规则就被银行用来定向收益。比如今天收盘以后，投资经理其实已经知道今天的资产价格是涨还是跌了，但是经理允许他们用昨天的价格来确认今天的申购和赎回，于是操作漏洞就出现了。

具体来说就是：假如今天资产涨1%，银行已经知道涨了，但因为有T-1规则，所以银行今天发出来的新产品让客户用昨天的便宜价格来买，新客户买进去立刻看到自己赚了钱，很开心。今天的涨幅实际上应该是老产品的，但是银行为了捧新产品、造短期长期收益，于是把老产品的利润给了新产品。

再比过来：今天资产价格跌了1%，银行知道了，却是允许新产品客户可以按天的价格赎回份额。结果今天的亏都由客户承担了，新产品体面离场，净值完好如初，银行的新产品炒作又成功了。

银行理财公司为了完成规模考核、排名季度KPI，所以他们想尽量办法包装新产品。只要产品的打榜成绩就好，第一眼数据就足够亮眼，那么他们就能吸引到更多的新客户，从而完成自己的考核。实际上，他们用的手段还是欺骗客户，钻理财规则的漏洞。银行理财公司压力很大，只能多点挣，于是压力给了这些客户。

一句话，大家都是被割的，其实影响还是很差。对我们普通百姓来说，学会这三招就可以避开这些坑：

- **第一招**：永远看近月的收益，不要看银行给你的那些高收益。如果你发现一个理财产品，成立以来年化收益3%，但是现在近三个月只有1%，基本上你就把它当。
- **第二招**：清楚三句话：
    - 第一句：这个理财净值确认是T-1
    - 第二句：不收超额业绩报酬
    - 第三句：这个产品为什么爆？
- **第三招**：避开那些打榜热门排名前列的新爆款，那是银行造出来的假象。大家就要冷静，你现在买进去，等赎的时候你就知道了。

银行模拟加权年化收益仅为.68%，但是近三个月新发的理财产品中，这种中低风险的理财产品成立以来年化收益率大于10%的产品超过3一个月收益率就下滑。最夸张之一是成立以来年化收益率9.67%，但近一个月收益只有0.82%。真正低风险的理财能做到收益？大家自己都可以算出来的：
- 一个存款利率是多少？
- 一个国债收益是多少？
- 低风险理财无非买点国债、买点同业单，这个利率只能做到比现在的存款多一点。

所以统计出来的理财平均收益就是2%不到。如果一个理财产品银行就给你宣传低风险稳健收益还有3%到5%，那就不合逻辑了。大家要看底层资产到底是什么，其实我们稍微理性一点，有点常识又不贪婪，银行这点小戏怎么可能糊弄住我们呢。
