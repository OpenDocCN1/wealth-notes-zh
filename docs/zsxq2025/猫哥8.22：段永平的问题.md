


# 爱平的问题

最近爱平在微信群里发布了一个关于投资的问题，大意是他已经投入了500万，现在再买入未来5年会如何？

- 1. 美金
- 2. 英达股票
- 3. 比特币
- 4. 北京和上海的小型住宅
- 5. 各种理财
- 6. 台聚
- 7. 因特尔伯格养老

目前他面临的困惑是买哪一个最好？我是看好股票还是比特币？我也有一个有意思的问题，来说大家看看吧。

首先是英达股票了。

我不看好，它现在的市值很低，但它还有些技术优势，设计质量还不错，生产工艺定标很难，这是最近的。

如果政府不改革，美国经济就不会发生变化；如果政府改革了，美国经济还是很难转型，美国国家现在已经是老龄化了。

所以，5年后，英达的股票价格还是会有很大波动，虽然不会大，但还是会有很大的影响。

所以，对于英达5年后的结果，我就不会看好。

来就是比特币了。

比特币和黄金，哪个是首选的资产？虽然黄金具有避险属性，比特币是黑色的黄金。但是现在的比特币价格已经远超过了黄金的市值了。

但是比特币和黄金，谁更有增长空间呢？

相反，如果未来出现比特币泡沫，黄金就会出现泡沫。现在，我觉得比特币的增长空间比黄金的要大得多。

在老龄化社会，选黄金比较合适。确定，对于未来出现通货膨胀的资产，那就是选比特币了。

现在买比特币，一方面可以对抗通货膨胀，另一方面可以看通货膨胀的长期走势，未来还是受通货膨胀的趋势。

这被认为是比特币的市场并不是由政府主导来解决的（中国现在已经解决了），所以比特币未来可能会有太大的崩盘风险。

来说说台聚。

台聚属于中国消费升级的标的。

经济的发展，消费是基础。如果经济不好，消费就会萎缩，股票就会大跌。如果能经历一个以上的增长，那么台聚的涨幅确实很高了。

对于未来买台聚的风险，我觉得最大的就是中国房价。

5年后，中国房价还是最大的风险。但是，房价不会大跌，虽然不会涨，但跌的跌幅也不小了。

从比较股票的角度来看，台聚比房价是有风险价值的。

北京上海的小型住宅是最大的风险。

最后来说，对于买美元的来说，我觉得最大的风险就是汇率风险。汇率波动是有一定风险的，当然没有投资是没有风险的。

| :--- | :--- | :--- | :--- |
| 1 | 美金 | 2.70% | 通货膨胀风险，收益率低 |
| 2 | 英达股票 | 360万/年 | 风险中，收益率高，分红稳定 |
| 3 | 比特币 | 500万/年 | 风险极高，收益率高 |
