


# 兔子贸易顺差破万亿，未来会如何发展？

文/卢克文工作室嘉宾 概略北方

12月8日，海关总署公布了兔子进出口情况，有一个数据惊掉了所有人下巴：

2025年前11个月，兔子贸易顺差达到1.08万亿美元。这可是全球有史以来第一个国家贸易顺差达到万亿美元的记录。

那么，万亿美元顺差到底是怎么来的？是好事，还是坏事？

首先，我们要定个性，这1万亿美元的顺差，含金量极高。为什么这么说？

因为这是冷战以来的“巅峰记录”，前无古人，基本上不可能有其他来者。

目前，兔子前11个月贸易顺差达到了1.08万亿美元，考虑到12月份西方国家普遍要过圣诞节，那么兔子全年的贸易顺差，很可能会达到1.1万亿美元。

这是哈概念？全球的GDP，也才110万亿美元啊！兔子光顺差就占了全球GDP的1%！

哪怕如日中时期的日本，在1993年创960亿美元（约2025年初的1850亿美元）的贸易顺差纪录时，也不过占全球GDP的0.37%左右。

现在的1%，说明在全球经济这块大饼中，兔子切走的那一块，比当年的日本更厚更大更厚。

更关键的是，这1万亿美元，是在美国对华发动全方位贸易战、科技战、金融战，企图将兔子踢出全球深度视野的背景下取得的，是在西方媒体天天喊着“脱钩断链”“去风险化”的噪音中取得的。

换句话说，这万美元，不是别人赏的，而是我们在卡脖子、断供、筑墙的围堵追堵中，硬生生杀一条血路。

其中的含金量，与当年的美日巅峰时期，不可同日而语。

而且在顺差里，有一个很有意思的数据。2025年前11个月，按美元计算，兔子对美国出口下降了18.9%，但兔子的总出口却增长了5.4%。

这充分说明，美国以市场为筹码，威胁兔子就范的企图，彻底失败了。

经济规律，不以人的意志为转移。

美国3亿人，这3亿人的吃穿行需求当然会有波动，但大体上是稳定的。

美国政府给兔子商品加税，并不代表美国人的需求会消失，有需求就会市场。所以，兔子很多企业开始把中间品、零部件、甚至半成品出口到越南和墨西哥，他们在那里弄个螺丝，贴个牌，再出口到美国。

洗澡嘛，谁不会啊。

以美国海关的人力，是不可能对所有商品进行产地溯源的。

为何兔子对美出口减少了18.9%，但对东盟出口却增长了13.7%？很大程度上就是这个原因。

所以，这1万亿顺差，相当一部分是这种“洗澡贸易”贡献的。美国消费者买到的，依然是流着兔子血液的产品，只不过中间商赚了了一些差价，美国通胀加剧了，而兔子的工厂依然生产。

而且，兔子也在不断拓展新的市场。几乎所有国家都需要高性价比的商品，当美国拿不出物美价廉的商品时，还能管着别人不买兔子商品吗?这意味着着，兔子的出口市场实现了多元化，在减少对美依赖上进了一大步。

贸易顺差=出口减进口。

顺差之所以能爆炸式增长，肯定是因为我们出口的东西多了，东西贵了，而买的东西少了，东西便宜了。

过去几十年，我们出口衬衫、袜子、家具，赚的都是辛苦钱，然后把利润换成飞机、豪车、精密设备、芯片。但在2025年，逻辑变了，我们出口的是“新三”以及更高科技产品。

看看汽车，以前是保时捷和雷克萨斯，现在是新能源汽车、内饰、智能化全方位碾压。

| 品类 | 以前领先 | 现在 | 趋势 |
| :--- | :--- | :--- | :--- |
| 汽车 | 保时捷、雷克萨斯 | 新能源汽车 | 同比增长 |
| 医疗器械 | CT、核磁共振 | 国产医疗器械 | 大幅下降 |
| 高端医疗 | - | 国产医疗设备 | 断崖式下跌 |
| 智能化 | - | 国产智能化产品 | 断崖式下跌 |
| 芯片 | - | 国产芯片 | 断崖式下跌 |
| 机器人 | - | 国产机器人 | 断崖式下跌 |
| 工业机床 | - | 国产工业机床 | 断崖式下跌 |

（注：根据原文语义还原的逻辑表格，原文为散乱的趋势描述）

当一个国家什么都能造时，出口必然会减少。在这个地球上，没有足够的东西可以供兔子进口了，这并不是开玩笑。

这不是开玩笑。我们要石油；俄罗斯和沙特排队送；我们要矿产？非洲和南美抢着给；我们要牛肉和车厘子？阿根人自己不吃也要运过来。除了一些最顶尖的光刻机和极少数生物医药技术，西方世界能卖给兔子且兔子还需要的东西，越来越少。

当一个国家什么都能造，且造得比谁都便宜时，贸易平衡就被彻底打破了。兔子一家独大，拿走了全球贸易顺差的大头，其他国家必然出现巨额逆差。

未来的世界，除了资源国（卖油卖矿的）和兔子（卖货的），剩下的国家基本在亏钱。如果是美国这种印钞国还好，对于欧洲、东南亚、拉美这些国家，长期的逆差就是失血。

如果这种局面持续，只有两种结果：

第一，全球南方国家因为长期逆差导致外汇枯竭，无力购买兔子商品，最终筑起贸易壁垒。

第二，西方国家将不断提高劳动力的价格，增加居民的实际收入，削弱出口竞争力，反而面临全球性的围剿。这不是意识形态问题，这是生存问题，毕竟所有人都把生存列为第一位。

## 那么，我们应该怎么看待这次万亿顺差？

先从好的方面看，万亿美金首先意味着国家有了有了充沛的“弹药”。在当前全球经济下行、债务违约频发的背景下，这笔巨额硬通货，是兔子应对一切外部冲击的压舱石。无论什么时候，都是底气。

更深层次的战略意义在于，这给了兔子推动人民币化一个千载难逢的“窗口期”。过去我们推人民币是靠着人用，现在我们可以通过“债务置换”的方式引导他人用。对于那些陷入债务危机的优质资产国，兔子可以提供置换方案，但前提是——还款要人民币，未来的贸易也要用人民币。这样一来，我们完全可以在全球流动性紧缩的周期里，小小挖美国的墙角。

美国人喜欢用美元潮割世界，那谁规定兔子不能用手里的巨额美元，利用美元潮顺底购买一些优质资产呢？大家想一个问题，近几年每年的贸易顺差都是万亿美元左右，但每年的外汇储备却基本没有变化，一直稳定的在万亿美元左右，那么每年顺差的这么多美元，到底去哪了？

答案很简单，兔子正在全球进行投资布局。兔子企业在非洲、南美、中亚的资产并购屡创佳绩，这都是在绑定未来的发展储备。按照传统的西方经济学理论，贸易是互通有无的，是双赢。但现在的局面是，兔子变成了“全能型选手”。我们不仅掌握了低端制造，还攻克了高端制造，甚至在人工智能和绿色能源等未来产业上也占据了先机。这就导致了一个巨大的Bug：在这个地球上，没有足够的东西可以供兔子进口了。

与之相对的是，2025年前11个月，兔子国内消费严重不足，这说明老百姓倾向于把钱存起来，而不是消费。房地产泡沫出清尚未结束，相比2023年、2024年，国内消费大幅下降，呈现出下滑趋势。

兔子也要搞“城乡居民增收计划”，意味着国家可能会通过诸种措施，把出口赚来的巨额财富实实在地转移到普通百姓手里，转化为工资的上涨，转化为社保的充实，转化为社会福利的提升，让老百姓有钱花敢花钱，让兔子工人买得起自己造的好车，让兔子家庭用得起自己生产的高端家电。只有当14亿人的消费能力彻底释放，当兔子工人买得起自己生产的商品时，当兔子的中产阶级敢于消费时，我们才能摆脱外部市场的依赖，才能真正构建起“内循环”为主体的铁桶江山。

这两件事，可能面临很大力，也会很难，但再难也没有别的选择。
