


# 底层男人，千万不要研究戒色
原创：君子
公众号：赢在8小时之外

1. 欲望是男人的立身之本。凡能在事业上取得成就的男人，在“那方面”一定厉害。无论是学术界、演艺界、商界，只要是一个闪光的男人，那么他有很多欲望。有人会问：难道就没有事业厉害、男女方面简单的男人吗？抱歉，一个都没有。

> 因为欲望和意志是相辅相成的。人类一切底层逻辑都是欲望。如果一个男人在各方面丢失了动力或者信心，那么他的欲望和意志都会打折扣，基本上不成事。

表面上看，是为了防止他们堕落。实际上，真相比想象复杂。在古代，把男性变成阉太监的过程叫“去势”。所谓“戒色”，其实就是把男性的能量库给灭，只下一具躯壳，这时皇帝才能安心使用。如果一个男人能量爆发了，也要承受这种风险。所以，如果你想要成就，千万不要相信“戒色”文化，因为戒色的本质就是对男人进行阉割，让他变成废物。就像我之前在公众场合说过的：如果你处于底层，一定先让欲望得到满足，在此基础上再考虑人性和智慧。失去欲望就会失去一切。

# 戒色文化是一门生意
只要有人在网上聊“老祖宗留来的文化”，那么大概是想割韭菜（我自己例外）。比如：各种心学、各种国学、各种道德经、各种戒色文化……这些比较玄妙的词汇，其实都是为了钱。注意，我并不是完全否定老祖宗留来的文化，而是我相信市面上宣传这些东西的大师，99%都是为了敛财，而不是为了传道。毕竟，在我们土地上，至少有50%的人不相信现代科学（这部分主要是低学历、低收入群体），而是相信“老祖宗的智慧”。换位思考一下，如果你想要收割他们，你也可以从这些文化里面挑一个，然后不断宣扬，那么你定能收获一大批粉丝，这时候收钱还不是易掌。

一切都是生意而已。正常人都应该非常清楚，戒色这种事，没有一个身体健康的人能坚持下去，破戒的概率几乎是100%。千万不要听网上什么大神、那个大神，他们几乎都是想骗你的钱。

那么问题来了，既然戒色这么难实现，为什么会有相关的生意？原因很简单：越是难以实现、越无法实现的事情，大家就需要指引，也就越愿意掏钱。“减肥”生意也是如此，90%的人无法成功减肥（即使成功了也会反弹），所以大家需要别人的指引和监督，自然也愿意掏钱。如果一个人随随便就可以戒色、减肥成功，那么这些生意自然就会烟消云散。

所以，如果你是一个男人，你想做情感领域的博主，有两条路走：教男人泡妞；教男人戒色。如果你是一个女人，你想做情感领域的博主，也有两条路走：
- 教女人独立、不婚不育
- 教女人上嫁、组建家庭
无论走哪条路，你都能收获一大批受众，赚得盆满钵。

那么问题来了，如果男人想要身体壮、精力充沛、在“那方面”非常生猛、该如何操作呢？主要由下面几个因素决定：
- ① 遗传因素占比50%以上（你的父母基因是否优秀，他们是否生猛）；
- ② 营养是否充足，尤其是蛋白质、维生素、微量元素（很多吃米饭炒菜的国人都缺乏这3种营养）；
- ③ 睡眠是否充足（每天睡7个小时），每周是否有3小时以上的有氧+无氧运动；
- ④ 你是否承受很大压力（这个最影响“那方面”的发挥）。

总之，如果你在那方面比较弱，补肾、站桩、戒色都用没，吃人参菇、保健品也用没，你需要改进上面我说的几个因素。

# 3. 不要压抑自己的本能
生存和繁衍是刻在基因里面的，这些本能无法消除，也不应该消除。过度压抑自己的本能，会让自己的身体和精神出问题。而且，如果你只是一味地堵着、不疏通，那么压力就会不断累积，最后通过更加恶劣的形式爆发。这有科学依据，也有社会学的数据支持。比如单身男性比例高的地区，以及性交易完全禁止的地区，犯罪率会低。注意，我说的不仅仅是犯罪，很多犯罪的根源可能是“压抑”。所以，如果单身女性比例一直高，那么一定会默认性交易的存在（大部分国家都是这样）。其实女人也是如此，如果你去调查，你会发现如果不找男人，身体、精神更容易出问题。原因很简单，很多压力是要释放，很多激素要分泌出来才怪。

有人说，现在有各种工具和机器人也非常发达，“满足自己的需求”这件事不需要异性的参与了。我不认可这种说法。在我看来，人需要的不是本身，而是深度的亲密关系，这个比本身重要多。工具和机器人无法提供这种需求。很多单身的人都有一个误区，天真地以为找到了让自己产生生理反应的帅哥或者美女就够了，实际上这些都是单身人士的幻想。而且越是单身的人越喜欢性，越容易好色，因为他们缺乏人与人之间的亲密接触，拥抱、亲吻、说悄话能让人分泌激素，让心率降低，心情变得平和，整个人产生幸福的感觉。反之，越长期单身的人，激素分泌就会越少。这时候，孤独和焦虑会强化欲望，总想搞点。搞不了别人，那就搞自己（本质上是自我攻击）。所以，越单身的人越缺爱，越容易好色，因为性的本质是对亲密关系和爱的渴望。但是，心智健全的人都非常清楚，体内这种不安分的欲望并不是好事，它会让人长期处于自我攻击和后悔的恶性循环无法自拔。这就是为什么很多单身人士特别找到一种方法让自己从痛苦循环中走出来。你想戒色，最好的办法不是念佛，也不是站桩打坐，更依靠自己的意志力，而是给自己找一个伴侣。如果你找不到合适的人类伴侣，养一只宠物也许起到一定的替代作用。

# 4. 不要被弱文化洗脑
无论是古代宣扬戒色为首的君主圣人，还是今天宣传戒色的各种大师，基本都是富得流油，而且背地里可能都是色。底层要安分、不要挣，主要有两个方面考虑：
- ① 每个人都老实实，这样方便管理；
- ② 没人跟他们抢资源，他们就能占有更多资源。

当然，我相信一些大佬是真的相信戒色的，尤其是某些皇帝或者大富豪。原因就是他们身边的美女太多了，密密麻麻自己看腻了，或者身体真的透了，所以他们才会戒色。这就好比，真正的性主义者大概都是钱人出身。但是，如果你只是个穷屌丝，自己身边的资源非常匮乏，你还整天研究戒色文化，那不是自欺欺人吗？“戒色”文化之所以能大流行，核心原因是底层的穷男太多了，他们找不到女人。如果你也是这种人，戒色文化听起来就感觉很自己。但是，我希望你一定要擦亮眼睛，识别出什么文化是专门为穷人量身定制的，然后不要套。说白了，如果一个文化的信奉者都是穷鬼，那么你应该早日扔掉这种文化。反之，你去看富人都在玩什么、研究什么，就多往这个方向靠近（99%的富人在方面是非常多彩的）。

# 5. 如何疏导自己的欲望？
很多男人注定找不到让自己有感觉的异性，他们只能选择几条路：DIY、Buy、戒色。戒色这个我已经给大家排除了，那么就只剩下DIY和Buy了。

### ① DIY
很多人在DIY时特别担心以后会影响自己的性生活，所以是在研究戒色文化。我的经验是，只要不过度（比如一天一次或一天多次），DIY对身体根本没有任何影响。我大概从小学五六年级就开始了（大概一周两次？记不清了），但是现在是30多年了，从来没有感觉过那当年的DIY对今天的性生活有任何影响。

### ② Buy
我在公众号里写过很多相关的文章，大家可以在我的【赢在8小时之外】公众号主页搜索“开车”（不是私信），然后就会找到很多关于Buy的内容。很多人之所以不敢买是因为担心：法律风险、卫生风险。客观来讲，这些担心并不是多余的，但我更乎的是：如果你在那方面一直得不到满足，已经算不错了，你的生命体验非常差。如果你真的想戒色，最好的办法就是提高自己的收入。不用说了，一个人的月入一旦过了5万元，对他色自然就会产生免疫力。不是说不要近色，而是绝对不会为了漂亮而去。

下面这两个原因：
- ① 每天有很多刺激、快乐的事（比如做事业），只要投入精力，每天都能获得实在的爽感；
- ② 成就感、满足感。马斯洛需求理论早就把讲清楚了，色属于底层需求，需要一些基础。凡是容易的东西，一定要恰好处，然后继续探索。否则，你一直在底层打转，很快就会索味了。有人会说：为了什么拼？为什么要向上爬？我想说：我们的生命到底有多少可能性？到底走多远？生命是独一无二的奇迹，我不想把它浪费掉。
