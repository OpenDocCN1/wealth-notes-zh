


# 中美博弈+资本收割模型（五十三）

## 一、自主

那什么叫做真正的“独立自主”？

简单讲就是这个国家就算离开世界，不与其他任何国家有任何任何联系，也可以生存下来，而且也没有任何国家敢欺负它。这类这样的国家，才算得上真正的“独立自主”。

想要做到这点，有一个必要的前提条件，就是这个国家必须实现工业化。

那近百年来，真正实现工业化的国家有哪些呢？G8+中国，一共九个。

所谓的“G8”就是指：美国、英国、德国、法国、日本、意大利、加拿大及俄罗斯等八大工业国（这8个国家在二战前就已经实现了工业化）。

名义上，这些国家都实现了工业化，但是你细看就会发现有很多国家的产业门类是不完全的，比如德国、日本、意大利的军事工业已经被割割了（日本、德国和意大利是二战败国，它们被美国永久驻军，而且美国不准它们发展进攻性武器，它们没有核武器、核潜艇、没有航母，也没有地对地导弹等）。

你想啊，一个没有军事工业，国家的安全能得到保障吗？一个国家军事都不独立，它能算得上真正的独立吗？显然不能。

而中国则是二战后唯一一个实现工业化的国家。谁的贡献？教员。他通过抗美朝战争从苏联获得一套完整的工业体系，也被称为“156项工程”；再通过联美抗苏从西方获得一套工业体系，也被称为“43方案”。

依靠这两套工业体系，1960年11月5日，中国仿制的第一枚导弹发射成功；1964年10月16日15时中国第一颗原子弹爆炸成功；1967年6月17日上午8时中国第一颗氢弹空爆炸试验成功；1970年4月24日21时中国第一颗人造卫星发射成功。

让中国在最短的时间内完成核弹（原子弹、氢弹）、导弹和人造卫星的制造，即“两弹一星”，最大化的保证了国家的军事安全。

也是前任给我们打下了坚实的工业基础，这才让我们现在有了与世界一较高高的能力。很多方面我们现在不是几十年前，你觉得我们是差技术么？也许在局部领域里差，但这个差，也是和美国一家比。

那就算我们想要在这些局部领域里和美国合作，美国也不乐意。和其余非美发达国家比呢？很多方面还是我们的技术更强些。

举几个例子，目前只有中美同时拥有的两款隐形战斗机，其中J20已经大规模进入了作战序列；也只有中美还拥有独立制造航母的能力(俄罗斯已经没有制造航母的能力了）；目前只有中美俄拥有自己的卫星导航系统；目前只有中国拥有打航母的导弹……

另外一点与众不同的是，我们不仅仅仅拥有完整的工业体系，而且拥有两套完整的工业体系（一套在东部沿海地区，一套在大三线）。

之前讲城市定位的时候给大家提过，在四川我们还有一套完整的工业体系，全国38个重要工业部门，四川样样俱全。

对于一般的国家来说，拥有一套完整的工业体系就已经异常困难了，何况两套？这也是教员对中国的一个伟大的贡献，他奠定了中国的工业基础。

所以，从2011-2022年，咱们期间经历过王的任期，也没妨碍我们制造业增加值继续扩张。

懂王的目标是让制造业回流，自己的制造业要恢复增长，占比要增加。那过去十几年，美国的占比，有没有变大？有。从16%变成了17%。我们呢？从2011年的21%，变成了2022年的30%。未来的中国的目标是想在在全球制造业领域，拿到45%的份额。

话说G2的制造业份额都变大了。卷死了谁？日本、德国，这两个曾经战败、被割割的、没有自主权的工业国。历史上，也发生过，老大和老二打架，把老三、老四给打没了的情况。所以小日子的公司老板直接说：这种事，对日本来说，是国难。也就是说，两个拳头最硬的经济体，最有自主选择权、最有战略定力的经济体，都想要卷工业。

只要双方都在规避战，那卷起来，一定把周围的其他人卷死。简单讲，咱们就打算给全球开放市场，那些非美发达国家的企业，真的能卷赢我们本土的企业吗？他连自家市场都没把握守住，他会有信心抢夺自家市场吗？

从这点来，日本的职业经理人，感觉自己目前的节奏，是自己的国难，脑浆还是很清醒的。
