


# 业内人士更容易悲观是正常的

有一位读者提问：为什么一个系统的内部人员总是看到系统的负面问题，相反系统的外部人员经常认为是系统一片光明。还给出了两个猜测：猜一个是内部人员经常接触系统负面信息然后放大了感受，猜测二是认知不够高。

这种现象其实很普遍，有几个原因。

首先是信息接触的渠道和关注点不同。

业内人士需要深度参与一个系统的日常运作，接触到种种不方便言说的系统内部问题和堵点，还要为这些问题导致的后果负责，如运行故障、利益分配矛盾、决策执行偏差、内部运转磨损耗，而一个业内人士的工作效能和日常烦恼多数就直接来自于这些具体问题，当然会觉得很烦很负面。

而外部人士并不需要直面这些具体问题，只需要获得一个系统最终输出的结果，对这个系统的看法更加宏观、整体，一般也没有机会去深入一个系统内部，去了解内部的复杂运转和潜在问题。

所以，这个问题的出现首先是具体与宏观角的差异，用互联网的话来说，就是粒度粗细不同。

以学校教育系统为例，作为一名老师每天都要面对非常复杂的要求，要照顾管理好学生，还要应对教学评估，除了这些主业工作，还有很多临时增加的工作要求，薪资晋升也有很多抱怨，但对家长来说，最关注的就是孩子在学校学得怎么样、有没有出事，从整个社会角度，对学校的评估更加宏观了。

各个系统都是一样的。

其次，系统内外人士对系统的评价标准和期望也不同。对系统外的人来说，其实在意的就是一两个与自己利益相关的核心标准，如家长长期期待学校把孩子培养好、别出事故，劳动者去打工只要不能输，去政务大厅办事事是否方便高效，作为普通市民对水电煤气等要求就是稳定供应、价格低，其他不在乎。但上述这些系统的内部工作人员就不同了，评价的标准要更专业、更多维，而系统的管理者也会设定一个更理想化的管理目标，就算满足了系统外部人员的诉求，内部也会会有更多更高标准。

所以，不单单是内部人员经常接触系统负面信息的缘故。现在网络这么发达，有很多系统内部的人在公开网络吐槽自家系统的各种问题，但系统外的人看了以后，也并不在意，最终对这个系统的看法，还是取决于整体和结果，关心这个系统提供的产品或者服务是否能满足他们的需求，只要能够满足需求，那么这个系统内部再乱，那也倾向于认为系统正在良好运行。

除了了系统内外认知角度不同，还有一个很重要的原因：同样一个系统，只有少部分人代表高效的方向。

举两个例子，都是小镇亲经历，并且跟系统内人士交流的。

一个是中国芯片突破。这个领域前几年，内部很多人都很悲观，觉得这个也不行，那也不行，差距太大了，然后批评系统外的人盲目乐观。

可结果如何呢？最近《金融时报》援人士透露，国产DUV光刻机正在进行生产测试，该光刻机自上海初创企业芯源量产，从股权结构看，新莱持股50%，这是典型的华为系，新莱前身为华为2012实验室的星光工程部；近期华为宣布未来三年计划密集推出四款崭腾芯片，近期芯片领域也有很多重大变化，都在支持中国的开源模式，而国家也在加大对英伟达以及模拟芯片等的调查，这都说明，中国芯片突破在即。而且能够放大出来消息，说明早就有了了。

遥想三年前，中国芯片多数内部人士的悲观预期，这个对比就很明显。

并不是这些业内人士判断失误，只是他们并没有在上述突破的企业和项目组内，而在这些项目组内的人员，会倾向于保密。

就算同样在华为，同样在华为的芯片相关部门，也未必然知道隔壁项目组的进展，这是高度保密的，毕竟不同组之间还存在竞争关系，这都会影响系统内部人士的认知。很多时候来自系统内部人士的悲观，更多是对自己以及所在项目组、公司乃至从事技术路线的悲观。

第二个例子是军事战斗力。小镇记得清楚，两年前小镇说中国军力已经不惧任何来自外部的挑战，连续出现腐败等负面事件，于是就有不少朋友觉得小镇太大了，还有内部人士表示悲观。结果如何呢？到了2023年阅兵展示的装备早就先进了，就连西方机构不知道保密有多深，那么一个普通的军官，哪怕是在中央机关，直接参与其中的就不可能知道。

而小镇之所以保持乐观，是从底层的逻辑去分析。内部人士不是神，很多网络公开的部门都看不清方向，高层次的人也要意，也会存在认知固化。其实这个问题，小镇之前谈说过，作为决策者不能听专家的意见，内部人士也存在认知局限性。比如当时上马峡的，核心依据是担心沙俄，小镇在这里说一个实际情况，一些新项目的测试结果他可能并不知情，这是因为数据、认知不及时导致的偏差。更多就是利益触动的时候，很难忍住负面情绪，比如新能源汽车非常光明，但过去依赖传统燃油汽车又会怎么呢？当然，一定要辩证思维，不能盲目信任，对外部人士来说，也没有必要太在意一个系统到底如何运转，平常看待就好，只要一个系统整体越来越好，说明系统保持了自我能力，那就问题不大。
