


# 米联储间251110——五陵少年金东（中美干部培养的不同逻辑）

你好，我是米筐！

全球最大的城市选出了一名 90 后的市長，还是个印度裔，1991年出生的曼达尼当选纽约市長，备受言论瞩目。曼达尼身上除了90 后的标签之外，还有穆斯林、印度裔、民主社会主义者的标签，buff 满，关键是，纽约是资本主义世界的圣城，全球资本主义的高地，全球最大的城市，资本主义炼金术的山巅城，如今迎来了一位社会主义市長。

曼达尼这次选纽约是历史以来最年轻的市長，既说明纽约选民对传统建制派的不满，渴望阶级平等和社会公平，又说明了美国乃至西方选举民主具有非常大的灵活性，能让年轻政治人物飞冲天。

日前，纽约时文中一篇关于曼达尼当选的报道中写道：曼达尼之前是皇后区的州议员，年前宣布参选，不过是个履历单薄、在全范围内几乎毫无名气的理想型候选人。但她始终聚焦关注议题，精通社交媒体运营，且对未来抱有极具感染力的乐观态度。这些特质成功赢得了大量的年轻选民和移民群体，让她成功超越了多名资历更深的对手。可以说让川普这个人走政坛的力量如今又让川普的敌人走上权力巅峰，美国正以自己的方式完成政治体制的换血和优化。

一位具有强烈左翼倾向的民主社会主义者，曼达尼向富人加税；推动免费公交、冻结租金管理公寓租金、改革警察系统。她的当选说明作为西方资本主义大本营的纽约，正在兴起渴望阶级平等和社会公平的强势力量。缺乏政治历练的曼达地上任后能否兑现竞选承诺，能否有效维护平等与自由，能否让纽约出现可持续的积极改变，目前尚不知，但他掀起的政治风潮说明：渴望平等是人性的重要部分，一个社会的发展如果过于偏等，必然引起民意反弹，不是陈云升，就是川普曼达尼，方式不同，结果殊途同。

曼达尼是一位90后，能够主宰全世界最大的城市，是西方选举民主的一个引人目的现象。不过曼达尼并非个例，在她身后，是西方选举民主中经常会出现年纪年轻就能身居高位的现象。无论是47岁当选美国总统的奥巴马、40岁当选美国总统的万斯，还是40岁当选法国总统的马克龙，1989年生的法国前总理阿塔尔，都说明在西方，30多岁、40多岁身居高位是见所惯的现象。在中国都不会出现曼达尼那样的现象。同样是90后已成为世界大城市的市長，而中国的90后在政坛基本上都只是中下层的科级总部。纽约长在美国的影响，甚至超过直辖市長、省长在中国的影响。目前中国年轻的直辖市長、省长是70后，但只有四人，分别是1970年出的浙江省长刘捷、1973年出的山西省长侯亮、1970年出的广西壮族自治区主席韦辅、1970年出的江苏省长刘小涛。

对比之下，中美干部培养结果的不同，一个关键原因是中国政治与选举政治的逻辑不同：中国是自上而下的官员选拔体系，注重官员的层级与选拔，官员的任免是自上而下；而在选举政治的社会，政务产生主要通过选举，一个合法资格的人，只要有民意认可或民选领导人才即可，而民意这个东西，可以很成熟理性，也可以很荒诞疯狂，全看社会本身处于什么状态。相比系统性的人事制度有具体的人事逻辑约束，选举政治的不确定性和不稳定更突出。

在中国内地，一个进入仕途的人，只要不中途离职，那么几乎可以说政治与政务是他一的工作；而一个人只要未在青年时期进入体制内，可以说他将来几乎不可能进入仕途。较而言，在选举民主社会，政党与社会固然存在某种，但彼此之间是有相对宽阔的转换通道。这就造成了在中国内地一个人想升迁还能通过漫长而又激烈的官员选拔竞赛，越往越高，而在选举民主社会可能会出现年轻身居高位的现象或中途转换职业的故事。

西方选举制的优点是非常灵活，缺点是为了迎合民意而进行的各种所谓选举操作层出不穷，民意容易被资本、信息偏差等非理性情绪裹挟，滑向民主义。民众对社会认知的水平决定了当选员的水平，有时候一些朴素的认知可以起到作用，个体知识局限也会导致对选人目标缺乏动力，长期沉陷在解决现实问题以换取选举的状态下，甚至为了获选，不切实际地提出非理性目标，加上政治资历和经验不够，不能带来承诺的治理绩效。

美国首先通过系统性的规则制定，出一个由技术官员为主要部分的美国政府，所谓领导者，不管是市长还是总统，都是在这个机器上微调。所以民主制度可以运行很好，不管谁进来，都不会出错。随着自身发展陷入后期，过去的制度设定完全不同，美国政治出现的问题只能头疼，缺乏改革的能力，造成的结果是政治陷入形式主义，公共政策受利益操控，民众对政治失望而犬儒。应该说，对于人口众多、知识爆炸的现代社会，政治已经是高度复杂的工作。德国思想家韦伯写过：现代系统正在发展为一个高素质的劳动者，由于长期的准备和训练，有着高度的职业。

自古以来，权力都是稀缺物，争夺权力是人类永恒的主题。对于统治者来说，选拔合适的干部从来都是难题，这里有许多人才，同时也有人才不足的问题。这次拿掉这些干部，能够坐在这些位置，但是是个复杂的东西。人才永远是悖论，聪明的人难以控制，守规的人又不擅长解决复杂问题，这对治理来说就是非常头疼的事情。毕竟中西方，干部群体的道德能力直接影响一个社会的治理绩效。好的群体是好政府的必要部分，良好政府又是良政治的必要条件。中国还是美国，都有人才不足的问题。实话，拜登时期，看到美国每次陷入困境也是无奈。人的问题一直是问题的关键。中国革命的成功、改革开放以来的重大进步，科技和经济的发展，是各种因素共同作用的结果，但都离不开一批优秀人才的积极推动。对于干部培养制度，虽然中国政治具有浓厚的传统，层层考核与磨炼的严格选拔体系让中国产生一大能力出的干部，但官僚主义的困扰、门阀垄权的抬头，让干部选拔和培养经常受到限制，裙带关系后必然是劣币逐良，导致年轻人积极下降，导致社会活力下降。

如何保持和扩大中国所有的优秀传统，减少官僚主义、腐败、劣币逐良的问题，是中国现代化过程中待解决的重大挑战。若想求长久安、善治，当务之急是总结和反思中国现在的干部培养体系，并尽快补充。在经济领域吸收市场理念的同时，在政治领域，如何引入多元的培养路径和提升渠道，完善干部队伍的培养很重要。说白了，现在留给年轻人的空间还是太大了，对于一些可以放手基层自治的领域，应该让年轻人一点空间和机会，让年轻人有点盼头。以此为契机解决干部选拔过程中的黑箱困境。

70年前，社会活动家黄炎之言与毛泽东的互动让历史周期为许多人周知。在中国漫长历史上，政权的兴衰、朝代的更替是司空见惯的现象，正如黄炎所言其兴也勃，其亡也勃。当时的老毛说：只有让人来监督政府，政府才不敢松解。只有人人起来负责，才不会让人亡息。现在回头看，老毛的方向是没有错，但落下去真的难，而中国要追求真正的现代化，治理现代化是躲不开的一关。不解决人的问题，中国在中美竞争中真正保持持久的优势。

米糕祝各位晚安
