


# 金融黑幕：银行亲自洗钱

![](img/7cc30174334a1b939a57875a55c7709e_0_0.png)

富国银行的一位华裔高管茅晨月，在回国后被限制出境，据说她涉及一起案件，需要配合调查，但并没有透露更多细节。

不过我们都知道，外资银行如果卷入刑事案件，大概率与金融犯罪脱不了关系。

茅晨月出生于上海，2012年就职富国银行，专门负责国际保理业务。今年6月份，她刚刚当选为国际保理组织FCI的主席，现任富国银行董事总经理。

从她的背景和业务范围来看，基本可以判断她若涉案，十有八九是保理业务出了问题。

那，茅晨月可能会牵涉到哪些类型的金融刑事案件，她的操作手法又是怎样的，背后是否藏着更大的金融黑幕呢？

首先我们要知道钟轲的法律律，金融犯罪的刑罪都有哪些，然后我们再挨个来一套，看看茅晨月可能落在哪一条上。

那，钟轲的金融犯罪刑事罪有哪几种呢？

## 第一种合同诈骗

就是你做假生意骗钱跑路。

比如你自己伪造了一份假的贸易合同、假的发票，然后用假资料从银行或者合作企业骗了钱，这就犯了合同诈骗。

## 第二种取款贷款

这个和合同诈骗罪有些区别。

合同诈骗罪，你骗的可能是公司的钱；但骗取贷款罪，骗的就是银行的钱，骗银行的钱可比公司的钱严重重100倍。

## 第三种洗钱罪

就是帮助犯罪分子贪钱，把国内的黑钱洗到海外去。

## 第四种非法经营罪

你没有金融牌照，却干金融业，这种非法经营的事还真不少，比如黑中介公司卖理财产品，其实干的就是非法集资。

那茅晨月从事的国际保理业务，有可能中以上哪几个雷呢？

可以说，前三个刑事罪犯都可能扯进去。因为国际保理业务，大家别看名字好像很高大，其实就是应收账款融资。

什么意思呢？我们打个比方：

你是一家出口公司，卖了一批货给国外的客户，对对方说90天后给你付款，但你现在急着要用钱，那怎么办？

你就可以拿着这笔应收账款，去找银行或者保公司，提前换成钱回来，其实就是借钱，只是多付一些资金成本。

但前提你是真的卖出去了，真的有发票，真的买家90天后会给你付款。

要是这一切都是伪造的，出口合同是假的，发票也是假的，买家也根本不存在。然后，你用假资料包装出了另一笔应收账款，拿去融资了，你就犯了合同诈骗了。

那茅晨月所在的富国银行，会在其中扮演什么角色呢？

我们也可以来举例说明一下：

比如中国某家企业A资金紧张，想搞一笔出口套融资，于是伪造了一笔假交易，说自己出口了1,000万美元的货给美国的公司B。

假合同、假发票、假装货箱提单，甚至还有买家B出具的付款确认函，这一整套资料一应俱全。

然后A公司拿着这些资料，找到了富国银行的保理部门，请求配合国际保理业务。

富国银行的负责人茅晨月，审阅了这些资料，虽然她知道B公司其实是A公司自己控制的海外卖公司，根本没有实际业务，但他仍以富国银行的名义，签发了一份应收账款确认函。

这份信用函的内容大致就是：

B公司是我们富国银行的客户，确实欠了中国A公司一笔1,000万美元的贷款，90天后会付清。

由于富国银行在这类国际双保理业务中，扮演的是海外保理行的角色，所以这封函就成了中资保理机构判断信用的重要依据。

于是中国的保理公司看到富国银行的背书，就决定给A公司垫900万美元。

一般保理就是这样，先垫90%，最后贷款付款清了再支付最后的10%。这就是中国的A公司就顺利从中资保理机构套出了900万美元。

如果90天后A公司资金回笼，它控制的B公司就会把钱回来，完成这场合法掩盖的自融套利；

但如果A公司经营恶化，甚至跑路，那B公司也会失联，中资保理公司就可能血本无归。

那么在这个案例里，由于中资保理机构看不到出口，也就是美国的B公司的真实经营的情况，所以中资保理机构就只能去信赖富国银行的背书。

可以说，如果在国内的企业想要洗钱，只要搞定了茅晨月，那确实有多少钱，都可以通过这种虚假贸易洗洗干净。

刚刚才我们举的例子，如果境外B公司有黑钱，那么A公司通过这套操作，就把B公司里的黑钱变成了合法的出口收入。这就是贸易型洗钱的典型套路。

另外假如中国A企业，只是想把国内钱洗到国外，完全可以通过虚假贸易、发票的方式，把这笔钱打到美国的关联账户，形式上是正常的出口，实际上是人为制造贸易，把人民币换成了美元。

在这个过程中，如果像茅晨月这样掌控风控的高管，在付款环节只睁眼闭眼，不上报可疑交易，那这笔钱就能顺利进入美国系统完成洗白。

也就是说，洗钱不一定要在地下市场完成，银行也干脏活，所以不要对大银行有滤镜。看看最近这些年，大银行因为洗钱被各国政府开了多少罚单。2022年到2024年，罚单超过19亿美元。可想知，洗钱的利润有多高，大银行罚单不停。

我们再结合国际情况，其实还有另一种剧情：就是国内保理公司，直接和A公司勾结。保理公司的资金可能是来自理财平台或者民间集资，保理公司想把这些钱洗到国外。我们也来举例说明一下：比如深圳有一公司，手里有理财牌照，但他旗下还有一个理财平台爆了。这家公司和A企业商量好，搞一个出口合同，做一笔保理业务，然后再把这笔应收账款包装成理财产品的底层资产，向百姓集资。于是A企业顺利拿到了900万美元的融资，国内投资人买到了理财产品，年化收益7%；半年后，这个产品爆雷了，因为本来就是业务，所以保理公司根本不可能收到。

这种事在2015年至2021年之间发生了很多起，主要就是理财平台参与了虚假保理业务。

那时候问题又来了。像茅晨月一样背景优渥的外资银行高管为什么要冒险帮人做这种明显的国际保理业务呢？

我们可以从三个层面来理解他的动机：

第一种可能：他认为自己这样做风险不大。在他看来，这种具收账款确认函的行为，其实是国际保理业务里默认的灰色操作，这类本身并不等同于法律担保？妥的是一些什么“我们知悉此账基于客户提供的信息如何如何”，上面根本不会写我们保证还款。对富国银行来说，这只是流程性文书，不承担实质风险；而对中资保理机构来说，就成了洋行背书。一来二，富国银行既收了手续，又撇了责任；站在茅晨月的位置看，这笔买卖划算安全。

除此，还有第二种可能：人情债和职业惯性。大家别忘了，茅晨月是2012年进富国银行的，而过去这十多年，正好是中国企业出海最多，贸易最繁荣的好时代。茅晨月本身出生于中国，做的又是国际保理业务，那就一拍即合，直接去中国找生意就好了。想来，他之所以现在能在富国银行做到董事总经理，很大程度上也是靠着他深耕中国市场，拿下了一票来自中国的客户和交易，才坐稳了这个位置。这些年来，一路挣他上位的客户、老朋友回来找他帮个忙，他真的那么容易拒绝吗？何况又不是什么大事，还能给自己挣业绩，为什么不做？一旦被推上去，身居高位以后，很多事就肯定身不由己了。可以想象，当年茅晨月为了迅速做出业绩或许没少钱而走险，毕竟，洗钱的市场需求是非常大的。以前的监管还松，金融人才才能发挥的空间更大。再者你要赚钱，那你必须一定要适应客户的企业文化，这时候人人都打脸活事所难免。友谊，那都是一起干过坏事打下的，所以谁的屁股都不会干净。

那么最后还有一种可能，就是出于利益的诱惑，对方给的好处实在太多了，让人无法拒绝。要知道国际保险业务都是大生意，几百万美元上千万美元都算小的，所以如果他愿意在关键流程上一只眼睛闭一闭。
