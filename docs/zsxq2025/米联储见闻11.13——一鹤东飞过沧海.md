


# 米联储闻20251113——一鹤东飞沧海

法国要搞G20，请领导去，结果变成了二把手去，欧洲这个面子确实也是没什么面子了。为什么不去？法国和欧洲都需要心里有点数。当初马克龙来访华，领导表达了极大的诚意，从南到北，该给的里子面子都给了，但是欧洲一直上不了台面，骨头不硬，还两面三刀，包括最近荷兰的操作，所以，领导对欧洲的心也淡了，二把手去就行了。

相比于领导走出来，现在王室纷纷进来。这几天西班牙王国王来了，领导亲自接待，两人当天也共同见证了10份合作文件的签署，涵盖经贸、科技、教育等领域。国王费利佩还要对中国进行四天国事访问，这是西班牙主18年来首次访华。前段日子，川普去欧洲找北约勒索，只有西班牙敢反抗俄，前脚跟美国闹翻了，后脚来了中国，西班牙正在欧洲各国打版，如何维护国家利益。普京此前威胁，除非西班牙增加北约军费，否则将让西班牙在贸易协议中支付双倍费用，而西班牙的操作是掉头找中国机会。

对于西班牙敢跳出来说，中国是非常受欢迎的，一把手的原话是：“中国重视西班牙在国际和地区事务中的独特作用，愿同西班牙携手打造全面战略伙伴关系；两国关系将‘更有战略定力、更富发展活力、更具国际影响力”。还提出，两国可优势互补，共同开拓拉美等第三方市场。这话真的诛心，中西国家开拓拉美市场，可是美国的后花园，让美国气急如焚。西班牙语不是拉美的主要语种，美国也有大量使用西班牙语的群体。西班牙国王也很上道，回应西班牙和中国的友谊无疑将及两国国民，这与两个拥有悠久历史和全球使命的国家身份相符。西班牙和中国“已经铸了信任关系”。信任就是眼下中国和欧洲之间最需要的东西。在国王费利佩访华前，西班牙首相切斯已经在三年里三次访华。不同于首相访华，西班牙左翼政府的亲华路线只能表明政党的态度，而国王亲自来访，意味着不管未来哪个党上台，对华的基调都会保持一定的稳定性。

所以，国王访华对中国来说，也是一份政治立场的诚意，给中国吃个定心丸。毕竟欧盟反复无常，中国也早已厌倦了这些欧洲客的戏，想要让中国拿出诚意，首要需要欧洲国家自己展示诚意，国王访华本身就是表态。

除了西班牙，还有一个国王最近访华也引起了外媒的高度重视，就是泰王访华。因为这是中泰建交以来泰国国王首次访华。别看泰国不是什么正经国家，但是在整个全球华语体系中，泰国是东方西方都兼容的国家。历史上，泰国大部分时候都是亲西方的，泰王也很少出国访问。别看泰国政坛混乱，但泰国是数不多的真正的实权君主，不管泰国政治怎么乱，很少能威胁泰王的稳定性。所以泰王访华引起了外媒的高度关注，认为是风向标式的事件。毕竟是中泰建交50年来泰国国王首次访华，朱集拉隆功登基10年来，从未进行过外事访问，将中国作为正式访问的首个大国，也确实让其他发展中国家陷入思考。

中泰1975年建交以来，泰国前国王旺普密达多次会见邓小、李先、李谱、胡锦涛、温家宝等到的中国领导人；1987年至1998年，朱集拉隆功作为储储四次访问中国，会见多位中方领导人。但泰王从来没有来中国访问过。对于这次泰王访华，中方评价很高，认为泰国王室以真挚情谊和积极行动，巩固两国战略互信、促进两国民心相通。朱集拉隆功2016年登基、举行仪式时，中国一把手致贺电；2022年，习近平对泰国进行历史性访问，但中方并未将一把手访华作为中泰交往的里程碑，而是将泰王访华作为中泰关系发展史上的一座重要里程碑，就知道这件事的不一般。

上次韩国亚太会议的时候，泰国首相阿努廷曾领导会面，并保证泰国会反对赌场合法化。据泰媒报道，领导当当时对此感到满意，表明中国政府鼓励更多中国游客到泰国旅游。中国曾是泰国最大源国，但却因为缅国与邦妥引发的安全问题令泰国的游客锐减，加之此前为泰党主导的政府忽视了中国的担忧和顺意，坚持推行赌场合法化政策，导致泰国进一步流失游客。这次泰国引进最大的跨境赌博网站头子余曾江其实就是交名状。从缅北选举团区的覆灭到泰国跨境赌场被扫荡，中国正在重塑盟友国家在华安全问题上的立场和态度，这就是大国重新制定游戏规则的操作。

泰王虽是首次访华，但作为王储的朱集拉隆功早在1987年至1998年间，曾以王储身份多次访问中国，会见多位中国领导人，足迹遍及北京、上海、江苏、新疆等多个省区。登基后，他未曾来过中国，也未造访其他主要大国，仅在今年4月对丹麦开展首个国家行程。但是泰国的琳通公主访华50次，诗丽吉曾王后身份访华，但“王室访华”一直是一块空白。这也是泰国王室比较谨慎的地方，如同当年金西看不清国内谁说了算时，一直没有来中国，直到2018年修宪之后，知道领导在国内已经扫除政治障碍了才第一次访问。

这些小国自有生存之道，在政治风向的嗅觉上一般都很敏感，毕竟是他们的生存之道。而泰王之所以一直没来，也和当时的国际形势有关。
