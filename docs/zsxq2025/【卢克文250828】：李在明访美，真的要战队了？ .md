


# 叶语，我们要不要离婚？

八月了，林晨已经准备好了叶语的离婚书。

可是，林晨没想到，叶语竟然先提了离婚。

“林晨，我们要不要离婚？”

林晨愣住了，看着叶语，心里有些复杂。

叶语的声音很平静，听不出一丝波澜。

“叶语，你为什么突然要提离婚？”

“因为我们在一起这么久了，我觉得太累了。”

林晨沉默了，他没想到，叶语竟然会觉得累。

“是因为我哪里做得不好吗？”

叶语摇了摇头，眼眶闪过一丝泪光。

“不是你的错，只是我们离婚吧，好吗？”

林晨点了点头，他答应了叶语的要求。

第二天，两人在民政局领了离婚证。

林晨的心猛地颤了一下，酸涩不已。

林晨转身离开，眼泪无声地滑下。
