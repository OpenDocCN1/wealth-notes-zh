


# 90%的不舒服，呼吸都能解决

年底了，我们来关心关心自己的身体。曾有人统计，冬季人们的运动量平均减少30%—50%，基础代谢率平均下降5%—8%。再加上室内通风率下降，很多人会觉得特别、特别困。天一冷，整个人就变得懒洋洋的。

那么，怎么提振精神呢？

方法有很多，比如改善休息，增加运动，等等。但是，今天咱们说个更简单的方法，呼吸。

最近，上线了一本电子书，叫《90%的不舒服，呼吸就能解决》。作者是位从业多年的呼吸科医生。这本书很薄，总共还不到3万字。

有人可能会会好奇，呼吸这么简单的事谁准不会？难道还需要人教吗？

这本书里说，本来不需要，但是现在需要。什么意思？你看，我们人类的呼吸系统，是经过漫长的演化形成的。它定型的时候，人类还留在物资极其匮乏的远古时代。这套呼吸系统适应的是，那种需要经常跑步，需要到处狩猎的日子。现在，人们开始坐办公室。这套新的生活方式，跟我们自然的呼吸系统并不适应。

比如，有种常见的呼吸方式，叫“浅呼吸”。你坐在办公室里，一坐就是几个小时。这时候，你的呼吸就会变得又浅又浅。而这种浅呼吸，让你的肺只用到了三分之一的空间。换句话说，你的肺很大一部分，根本没有参与工作。作者就认为，因为氧气输送不足，人才会觉得累、觉得累、觉得脑子转不动。

再次如此，过度深呼吸。你压力大的时候，会不会不自觉地长吸一口气？偶尔深呼吸没问题，这是身体在自我调节。但问题在于，现代人的生活恼多，导致深呼吸频率很高。如果我们频繁深呼吸，就会打乱自主神经的平衡。本来想通过深呼吸来放松，结果反而让自己更焦虑。

你看，这几种错误的呼吸方式，是不是听起来特别熟悉？这是现代人的通病。久坐、压力大、生活不规律，都会让我们不自觉地用错呼吸方式。书里提了一个概念，叫“呼吸链断裂”。简单说，就是当你的呼吸方式出问题时，会引发一个连锁反应。就像多米骨牌，第一块倒了，后面全都跟着倒。

你看，你的呼吸变浅了，吸进去的氧气就少了。氧气少了，血液里的含氧量就会下降。含氧量下降，你每一个细胞的线粒体——细胞的能量工厂——无法正常工作。线粒体不工作，细胞就没有能量。细胞没能量，器官就运作不好。

运作不好，你就会出现各种不舒服。

比如，慢性疲劳。明明睡睡了8个小时，但是还是觉得累，觉得没精神。很多时候你可能觉得，这是因为工作压力大。很多时候，根源也许在呼吸上。我们晚上睡觉的时候，呼吸太浅，身体没有获得充分的氧供给，自然会觉得累。

再比如，肩腰酸痛、驼背。你可以觉得，这是因为我坐姿不对，是因为我长时间盯着电脑。但是，很多时候，根源也在呼吸上。当你用浅呼吸的时候，会不自觉地弯肩，用肩和脖子的肌肉来帮助呼吸。时间长了，这些肌肉就会紧张、僵硬，就会肩腰酸痛，甚至驼背。

更让人意外的是，连肥胖都可能跟呼吸有关。你想想，当细胞能量不足时，你的基础代谢率就会下降。代谢率下降，就更容易积累脂肪。而且，当呼吸不好的时候，人会容易疲劳，更不想动，这就形成了一个恶性循环。

换句话说，很多所谓的“小毛病”，比如头痛、睡不好、瘦下来，可能根源都在呼吸上。

那么，为什么呼吸这么重要？为什么呼吸方式的改变，能影响这么多东西？

这就说到一个观点。这个观点，可能跟我们的直觉完全相反。你看，我们一直以来认为呼吸的目的，是吸进更多的氧气。很多人觉得，深呼吸就是要拼命吸气，吸得越多越好。

但是，这个想法也许是错的。呼吸的关键，不是吸进更多氧气，而是为了保持体内适量的二氧化碳。

你没听错，是二氧化碳。

有人可能会觉得奇怪，毕竟，在我们的通常印象里，二氧化碳是废气，是要排出去的。但是，换个角度看，二氧化碳其实是健康的。你看，吸进去的氧气会进入血液，跟红蛋白结合。红蛋白就像一辆运输车，把氧气运到全身各处的细胞。

二氧化碳浓度高了，细胞就会工作；二氧化碳浓度低了，细胞就会休息。那么，什么时候才把氧气放出来？答案是，当它感受到周围有足够的二氧化碳。换句话说，二氧化碳就像一个信号，当二氧化碳浓度高时，它才会释放氧气，让细胞使用。

如果你体内的二氧化碳太少，红蛋白就抓不到信号，甚至会出现头晕、手脚麻。这就是过度呼吸。有些人在紧张的时候，会不自觉地大口喘气，结果反而越紧张。这种呼吸不是吸得越多越好，而是要保持平衡，既要有足够的氧气，也要适量的二氧化碳。

那么，有一个方法，叫膈肌呼吸。简单来说，用肚子呼吸而不是用胸部和肩膀。你可以试一下，把一手放在胸前，一手放在肚子上。深吸气，假如你的肚子鼓起来；呼气的时候，肚子收回去。这就是膈肌呼吸。

这种呼吸的方法：
- 吸气时，肚子鼓起来。
- 呼气时，肚子收回去。

膈肌是身体里最重要的肌肉。它就像一个活塞，在你的肺腔之间上下运动。当你在吸气的时候，膈肌向下压，吸进更多空气；当你呼气的时候，膈肌向上推，把肺里的废气排出。换句话说，用膈肌呼吸，你的肺部能得到更大的空间，效率更高。

膈肌呼吸每天练习10分钟。你可以在早上起床的时候，也可以在晚上睡觉前练，甚至在办公室里练。

除了膈肌呼吸，书里介绍了一个特别实用的方法，叫4-4-8呼吸。这个方法特别适合紧张、焦虑的时候。具体怎么做？
- 用鼻子吸气，数4秒。
- 屏住呼吸，数4秒。
- 最后用嘴像吹蜡烛一样慢慢呼气，数8秒。

这个方法的关键在于，呼气的时间是吸气的两倍。为什么要这样？因为当你呼气的时间更长，就能激活副交感神经，让身体进入放松状态。这个方法在重要会议前，或者开车的时候特别管用。只需要几个循环，就能感觉到自己冷静下来。换句话说，这是一个随时随地都能用的“镇静剂”。

需要特别说明的是，书中的这些观点和方法，都是作者基于自己经验的总结，仅供参考。如果你有呼吸系统疾病，或者其他健康问题，还是要及时就医，听从专业医生的建议。最后，也祝你在每次呼吸中，都变得越来越好。
