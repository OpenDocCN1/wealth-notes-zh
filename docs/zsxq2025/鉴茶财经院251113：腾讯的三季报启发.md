


# 鉴茶财经 251113: 腾讯的三季报发布

第三季度营收 1928.7 亿元，同比增 15%，预估 1888 亿元，上年同期 1671.93 亿元；第三季度净利润 631.3 亿元，同比增长 19%，预估 558.8 亿元，这是大超预期的节奏。

这说明什么？

第一，大象可以跳舞，大公司发展的速度和质量越来越高，它和小微企业组成哑铃模式，中间的中溜企业最难受。

就像有人问王一 1.2 万亿高不高，我们回复是不高，就折合 2000 亿不到美金，在全球科技公司排不上号。（当然不说现在你要追啊，大涨得消化）。

阳光也一样，最近消化前期的涨幅，消化还会上去（不是让追高啊，毕竟它只是 550 亿元的小卡拉米）。

第二，全世界最优秀的 AI 应用必然在中国，因为其他地方没有这么大的统一市场和价格战打到 9.9 的公共服务。

ChatGPT 因为回答法律问题会影响美国律师的生意，现在这方面基本上给停了。

目前，腾讯的活跃账户有 14 亿，而全球拥有手机的用户是 57 亿，套用《火军之王》里的话说。

第三，美股的七仙女在纳斯达克，中国的真科技巨头基本都在港股。

不要看到英伟达在涨，今年截至 11 月旬，向港今年净买入 1.3 万亿港元，累计净买入 5 万亿港元。

阿里、腾讯等印钞企业现在市盈率也就不到 20 倍，比大 A 那些不知道好去哪里。有人说普通人怎么能躺上这些大牛，讲了啊，恒科指数最近它们的调整，是一系列不可抗拒的超级宏观事件的影响的。

生产队和大资金，最喜欢收租生意的。

问题来了，腾讯阿里们赚了大钱，做什么事情最讨厌上面，上面希望它们去做什么呢？
