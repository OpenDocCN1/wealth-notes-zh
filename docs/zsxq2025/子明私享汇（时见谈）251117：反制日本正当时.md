# 聊完战略，再看战略

对于日本这个伪军来说，目前美国进入粮食大幅削减的周期，此时，日本就需要跳出来，展现自己的的价值，以争取夺到狗剩的粮食份额，争取主人把他的狗链解开。

在此，我们必须要反制日本，但也要控制火候。一方面，打狗，是给其他狗看的，打得越狠，其领狗的狗都会掂量继续向我们吠的代价与收益。

而日本吠的越凶，越会驱动美国把仅有的粮食集中在这个这个看起来最忠诚的狗身上，可以极大减少美国对其他国家和地区的支出，有利于我们接下来的在东亚战区的统战工作，降低统成本。

另一方面，打狗，是给主人看的，打得越狠，主人越是觉得这条狗基本能搞定我们，就越会蔑视我们。

就像当年柏林危机时，看着老美误以为是叫嚣的老将能够统一，我们速速完成了祖国大陆的统一。
