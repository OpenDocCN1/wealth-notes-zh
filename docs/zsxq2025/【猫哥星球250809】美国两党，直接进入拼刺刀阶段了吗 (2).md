


# 美国两党，直接进入刺刀阶段了吗？

![](img/802cf3cc29b18dd370292fcc6c0feced_0_0.png)

嘉宾供稿

如果真要问谁是自媒体创作素材提供的一哥，答案绝对是川普无疑。

这边印度成为美西方弃子的瓜我们还在津津有味咀嚼，那边川普又在国内放出一个大招。

北京时间8月8号一早，川普在社交平台上直接推，说已经指示美国商务开展一项新的人口普查工作，重点强调要把美非法居留人员排在外。

一时间，全美沸腾，为啥？

我们先说两个关键点：

其一，根据美国宪法第二条第一点规定，人口普查是10年一次，最近一次是2020年，也就是下一次人口普查的时间应该是2030年。

其二，人口普查的法定对象是“居住在美国的每一个人”，包括第十四修正案也明确说明人口普查涉及的是“各州总人口”，那就包括非法移民。比如最近一次的2020年川普普第一期搞的人口普查就没有非法移民排除在外。

所以，基于上述两个关键点，可以认为现任总统川普的这条指令，在人口普查的时间上、范围上属于明目张胆的违宪。

那么问题来了，为什么川普要激怒呢？

导火索还能从最近州的那场风波说起，事情大致脉络是这样的：

8月初，共和党的大本营得萨斯州公布了一个重新划分该州选区的方案，本来打算会上投票通过。毕竟在德州，共和党控制上下两院和州政府，方案要通过那是轻松愉快，无非就是走个过场。

结果，戏剧性场面出现了，有超过50民主民主州员集体连夜跑路，导致方案搁置。

因为根据得州规定，州众议院需要满足2/3出席议（100个）才能启动表决程序，而州众议院共150个席位，其中共和党占88个席位，民主党占62个席位，现在民主议员跑了50多个，分母都没有了，程序还未启动。

民主党严格执行不打赢就跑的战术进行拖延，反正加州凯凯集团老板把酒店房间都开了等大家去度假。

于是得州共和党抓住了，除了要对每人进行500美元/天罚款，还要打算跨州抓人，州政府不行就打算启动FBI，甚至拿取消议员资格进行威慑。

那么，为什么重新划分州选区这个方案受到民主党议员的强烈抵制呢？

简单的就是根据赢家通则，通过选区重新划分可以实现对民主党控制席位的压缩。

比如在德州，A选区民主党占绝对优势，B选区民主党占相对优势，C选区共和党占绝对优势，可以通过重新划分把B选区支持民主党部分划给A，把C选区支持共和党部分划给B，水多了加面，面多了加水，最终实现共和党控制B选区的结果。

这逻辑和我们种田赛马差不多，总就一个目的，为了中期选举在众院拿到更多席位。

而且这件事是拖得不得，虽然美国中期选举时间是在明年11月，但地方州的初选是明年3月，如果今年底搞不定重新划分分选区的相关布置准备工作，那事就有可能被黄莲。

很多人可能不明其中的门道，认为得州是共和党的大本营，又是摇摆州，黄就黄了呗，至于如此吗？这里讲背后的逻辑。

首先，谈谈涉及的是众议院而不是参议院这个问题。

其一，美国众议院435个席位是每两年全部改选，而参议院100个席位是6年换，其中每2年换1/3，而且参议院每州固定只有2个席位。所以对于中期选举而言，参议院波动很，而众议院波动很大。

其二，参议院涉及人事权审批，众议院涉及财政审批。对于川普而言，可能每天都要和众议院扯，可想而知众议院多重要，毕竟没钱寸步行。而且众议院还拥有对总统发起弹劾调查的核武器。

其三，美国执政党的中期魔咒，就是近百年的历史中，执政党在中期选举只有3次住了众议院。

所以，中期选举看什么，无非就是看众议院谁掌控的问题。一旦民主党翻盘，等待川普的绝对不是败脚这么简单，从两党现在不死不休的斗争格局，直接发起对川普的全面弹劾调查是大概率事件，这让你川普怎么能接受。

所以，从川普上台后，就准备在得州重新划分分州选区方案。目的是通过得州，在众议院增加5个席位，确保中期选举稳妥。

那么第二个问题，为什么川普选择拿州开刀呢？

个人判断主要有以下3个方面原因导致：

其一，美国众议院435个席位，得州3000万人口排老二，有38个席位，份额大，又是共和党大营，操作空间比其他州大。

其二，在美国众议院里面，得州38个席位其中共和党占25个，民主党占13个，虽然优势明显，但是川普不认为。他认为根据24年总统选举结果，得州38个席位中有27个支持民主党，那么至少有25个席位被民主党偷走了。

其三，用得州这个共和党票仓当试验田，要起到带头效应，为了更好的推行得州乃至其他州。川普这么干，也是没办法。

现在美国众议院席位格局是怎样？435个席位中，目前共和党占219席位，民主党占212席位，共和党领先7席，不过这里有4个空缺，今年下半年补选，大概率民主党会拿下其中，届时双方格局就缩小到5席。

别看这5个席位优势，其实背后的隐患非常大：参议院代表政客，众议院代表大众。那么川普现在的民意如何？

可以用危机来形容，根据CNN民调显示，川普支持率才41%，而且24年预测支持率均低于50%。这类民调水分太大，仅作为短期参考。

我们换个角度看：川普之前通过的大法案，本质上就是劫贫富济的方案，会有多大的民意支持？关税战导致国内通胀下来，还有非农就业数据等，大家都知道这5个优势很难守住，否则川普也不会公开践踏红线。

而且背后还有一个核心隐患——得州票仓。想不到吧！得州是从墨西哥出来的，最近几年因为人口红利因素一直在增加，带来的副作用就是拉丁裔和非裔占比已经超过50%，这些人立场是偏民主党的。如果接下来的拉丁裔和非裔再多点，如果得州民生问题出现波动，共和党这个铁票就有可能出现松动，甚至危机。所以，得州不仅要扩大优势的带头作用，更重要的是票仓稳固的问题。在这个问题上，对于川普而言不容商量。也正因如此，当得州民主党议员集体跑路延迟，川普的选择就不装了，彻底摊牌了，升级事态，将暗斗变成了向民主党全面掀桌的行为。

宣布启动新的人口普查，再根据人口数据重划众院席位分配规则。为了稳妥，川普设计了2个法宝：

一个是要求利用2024年大选数据加速进程。哈意思？我理解是高考成绩参考中考成绩。反正我对这句话理解不准确，不过对川普有利是无疑的，有懂的星友可以补充。

另一个就是前面说的排非法留人员。这是川普对民主党的一副虎狼狗，直接影响就是压缩民主党整体票仓，而且不排除在非法移民和移民问题上做文章，逼迫战队大张旗鼓。

所以，启动新的人口普查这件事，和一份议案、一项政策的博弈完全不在一个层面，这是要刨民主党的祖坟。短期目的是赢得中期选举，长期目标的是赢得下届大选，更长期可能一直坐庄了。

因此，美国两党关于中期选举的斗争已经正式打开，而且一上来就是刺刀见红直击要害，双方没有多少回旋余地。而我们要做的事情，除了过好自己的事，就是搬个凳子坐看两党白战如何演戏。
