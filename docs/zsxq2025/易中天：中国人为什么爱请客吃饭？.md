


# 易中天: 中国人为什么爱请客吃饭?

中国人喜欢吃饭，并不是中国人好吃，而是中国文化的思想内核——群体意识使然。

# 01
在中国看来，食物是生命之源。

因此给他人食物，请吃饭，是一种重的情谊；而接受他人的食品，则是受了很大的恩惠，必须加以回报。

但在通常情况下，这种回报并不困难。你请了我一顿，你还我一份就是。一来一样，两下也就平了。

事实上也是如此。

被请的人，很少有回请的。

而且往往是请了以后，对方又要以回请的名义再请一次。循环往复，没完没了。

结果自然是谁也不欠谁、或愁谁准欠谁。不管谁准欠谁，都好在一起吃了饭。

一起吃了饭又怎么样呢？就有关系了。

我们知道，中国人吃饭，无论团聚还是宴请客人，都是全体共食：所有的筷子，都伸向一盘菜；所有的勺子，都伸向一碗汤。

不管什么菜，至少在理论上人人有份，每个人都可以而且应该吃一口。

像西方人那样，各点的菜，吃各的菜，甚至各付的账，在中国看来简直是莫名其妙。

显然，在这里，最重要的“人”人都有份，大家一起吃。

也就是，中国人真正不是吃，或不是不吃，而是一起吃。或者说，共食。

# 02
事实上，请客吃饭的意义也在此于。

所谓兄弟，不就是在一在一起，吃同一种东西吗？

那么，如果我们聚在一起吃了同一种食物，岂非也是兄弟？

所以，无论你是否认同，也不论你我是是否相识，只要在一起吃饭了，就有了同一的生命来源，也就是哥们儿了。

餐桌上答应应事，就得努力去办。餐桌上的承诺不得吐开笑的，否则叫食言。

言出出口，食言意味着把吐出去的东西再吞进来，别人鄙夷不说，自己想也恶心。

所以，中国人一旦要求人帮忙，便多要请客吃饭。

当然，请客吃饭也不一定就是为了于人，更多的在于建立一种比较亲密的关系。

因为请客吃饭的意义，不在于或不完全在于“给人吃”，更在于“一起吃”，即不完全在“吃了人家的嘴软”，而在于“同吃一碗饭”的情谊。

这种情使中国人的人际关系温脉。

当然也不一定要请客吃饭，只要能聚在一起就行。

聚在一起，就有多少些“共食”的意思。

所以，即使是吃饭，吃自助餐，也要聚在一起。

# 03
关系好的一些，还要把自己的菜拨夹给对方，或从别人碗里夹菜吃。

正是由于这个原因，中国人不太喜欢分餐制。

尽管很多人都承认，分餐科学、卫生、不浪费，但同时也认为那种分餐方式太冷淡，太没有人情味了。

总之，共餐的目的，是情感的交流、心灵的沟通、血缘的认，因此不能考虑卫生，不用顾及身体，有灶扬火。视死如归的精神，所以餐桌上的流行歌曲就是：“感情浅，舔一舔；感情深，打冷锁；感情钱，出血。”

一个幽默气人的，应该能够为朋友两助插刀，献出生命眼睛都不眨一下。

如果连逛醉酒或吃出病的风险都不承担，谁会相信你为友而万死不辞呢？

# 04
餐具也有讲究，餐中最中国特色的筷子。两根筷子夹一块食物，本身就有共食之意义。

所以用筷子给客人夹菜，几乎是宴会上不可或缺的礼仪。

它表示客气，也表示和气，同时也未曾把对方牢紧夹住，以防脱落的意思。

其实，中国人最早是用刀叉的，正如中国人最早也是实行分餐制的。

甘肃武威望娘台齐家文化遗址出土的一件骨质餐筷，和现在餐所用的叉在外观上几乎无别。

但筷子终于取代了刀叉，共也终于取代了分餐。

这种转变是为了共食。有人说，这只是因为发明了桌子。

有了桌子，就可以围在一起吃饭，不用像先前那样，各吃各的。既然大家都挤在一桌子上吃饭，用筷子当然比刀叉方便。

问题是，发明了桌子，为什么要围在一起？即便在一起，也可以像西方人那样各吃各的！

说白了还是中国人爱共食。显然，对中国人来说，饮食的味道，不仅只是食物的味道，还包括餐桌上那种人情味。

中国的菜，便体现了这种团结、和合、融合的群体意识。

无论炒、煎、蒸、炖、烤、炸，几乎不是将主料和配料在一起下锅上桌，不会像西方人那样，肉是肉，鱼是鱼。

一些大菜名，如“全家福”“佛跳跳”“霸王别姬”，更是多种食材的和合，味道已分彼此。

而且，按照中国的烹调、营养学和食疗学的说法，这种“和合”，有利于阴阳协调，是一种科学的做法。

当然，最好食物味道极了，人情味又浓，而最能体现这双重目的，大概就是火锅了。

火锅不仅是一种烹饪方式，也是一种用餐方式；不仅一种文化模式。作为饮食方式，火锅可以多人合吃，也可以独食，然而独食者又何其寂寥。在火锅店里，我们实难见到独食者。这不是为了省钱，只因独食无趣。一般来说，中国人是不喜欢独食的。独食难肥，共食才能其乐无穷。

# 06
如果不得而叫酌，就要在想象中与人共华：“举杯明月，对影成三人。”

否则就叫唤酒。酌酒不但无趣味，而且会伤身。如果与友人共饮，则酒过干杯少，若量过多也无妨。

这就是请吃饭的意义。
