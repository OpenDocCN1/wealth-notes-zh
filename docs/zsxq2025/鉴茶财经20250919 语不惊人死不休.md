


语不惊死不休

一早上铺天盖地的种种都是，马斯克的，fake的。

其可是马斯克在干啥，一个名不见经的小的公司，要部长1万马斯克的铁豪。

马斯克当然说主业的，一个制造企业在自家农家搞这么多，你哪来的钱，企业说部署了Optimus V3，实质上马斯克v2.5就没造出。

国内的媒体非要歪解读为，马斯克说人形机器人是人的。

一把市场情绪燃底，来春，券商+机器人+低消费（旅游）。构成就3900的主力的是。现在是券商不让涨，机器人的代表科技高无敌，旅游也就变成旅游的表现出来，大当不要尽力了。

上午如果看到缩量和不修复废物，，如此，请注意：

1. 机器人还在，易中天胜的都逆势，天字在20日线反弹，资金在华为线和“通讯”那章要结束的包。

2. 游资和量化消散，开发，上海建等大家，它们跑头丢了马斯寨。

3. 游散了后各种乱赢，不是科技后圈了，因为是接盘，估计是退早事的。

4. 机器人自然归属于错，尤其是人形，跌后站稳5平台依然可以进，图形参考8月11日的宁王，之前嫌机器人人，这不是给你买下来了吗？不不买。

5. 有发现规律来搞去，不如猛杀冰底跌，一把拽着关注力扫地球。机器人制造的市场上，推土机器的崛起，然后后盘间或来一猛暴跌，还将继续前进。

6. 准备连一周后，三个左右的调整期吧，只是调整，牛市没完。后面可能有时间，创业板指要跌，不过信科技指数了。

一再跌9月很多人跑不是恒恒的，不信的。这段时间，就看谁能继续抱团不散，10月的行情把他们堵了。估计全团队还有点儿，水温有点控了，缩量8000多亿，周末计划要出利好了。

过去去不可为，所有的调整都是为了未来更高的突破，这轮车用30年，5年，为20年的角度来看，周末快乐！
