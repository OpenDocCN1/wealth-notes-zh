


# 米联储见闻25014: 千万转路不定(中美贸易协定，是双方的权宜之计?)

你好，我是米筐。

赢学真的是21世纪的玄学，一场空战，巴基斯坦赢了，印度也说自己赢麻了；一场税战，中国赢了，美国也说自己赢麻了，而且是史诗级的贸易胜利。好家伙，一桌麻将，四个人打牌，都赢钱了，谁输输钱？很大程度上，如果一桌麻将四个人都赢钱了，这必须是老骗局，若是坐在桌上的都没输钱，不是跟围观群众赢了，就是买码的输输了。这种赢学泛滥的局面会导致一个结果，就是政客们手越越大，对对赌心理越来越强。如果赢了没后果，或者后果很好掩饰，那么行动的步子就可以迈得再大一点，只要大家都不输，世界必变成完美的地狱。

这个时候，必须要表扬一下美国的媒体。在白宫说自己赢麻了的时候，华尔街日报还是没有跟着起鼓掌，这或是为什么美国会成为强国，印度归是烂泥墙上不上墙的根本原因。中国是出了名的反思怪，真的吃亏了，官媒最多沉默，像印度这样办事，而且大大还还有些拉下脸；而美国因为政治势力的多元，确实能容下不一样的声音。白宫说总统带来了大胜利，而华尔街日报则是说是川普税大撤退（The Great Trump Tariff Rollback），美国发起的贸易已经失败，与中国达成的协议更是川普的投降。

同意削减对华高关税，是川普一周内的第二次重大让步。纽约公司Strategas Research的合伙人兼政策主管管克利测算，关税合计3000亿美元的关税豁免，堪称大规模减税。文章称，除关税外，双方在影响中美关系的实质贸易问题上做出更广泛的让步。言下之意，川总的关税战没有拿到任何实质性的结果就撤退了。同时这种自毁八方反而削弱了组建反华主义联盟的可能性，通过对盟友国家亲手摧毁了美国的经济和政治信誉。中国反对抗俄获得胜利，反向向世界展示了正确的应对美国霸权的方法。在华尔街日报看来，川总一顿操作猛如老虎，回头一看二百五。这一转折排除了川总意识到《斯密特-霍利关税法》不行，似乎也没有更多的作用。华尔街日报认为，其不是积极的结果，毕竟《斯密特-霍利关税法》被视为最为愚蠢法案。这一法将进口税提高至近60%，并大幅拓展征税商品范围，涵盖约2万种商品，给美国经济带来了巨大的伤害。美国媒体的评论来讽刺，但川总自带龙皮护甲。

中美谈判之际，中方领导去了俄罗斯，川总则来了中东。说实话，虽然川总政策飘忽，但确实务实，搞钱搞钱，还是搞钱。关税搞不到钱，那就上门要钱。放全球如今还能搞到的地方，估计也只有中东狗大户了。川总左上手下卡塔尔沙特的4亿美元豪华机，右脚踏进中东热土，一来就让沙特购买了1420亿美元的军售，而且获得沙特特价6000亿美元的投资承诺。对此川总并没有骄傲，甚至觉得还不够，拍着王的肩膀说：“是不够的，我希望能够突破万亿。”

对于沙特王室来说，手里的美元的确是要尽快花掉。看着亚洲货币对美元汇率的极速贬值，对于拥有大量美元金融资产的沙特来说，如何快兑现这堆票子非常关键。除了大量军备，沙特下单买了1.8万英伟达高算力芯片，积累算力的意图也很明确了。从川总自上门拜访客户的操作来看，老头还是务实的。

川普与沙特王签署的协议涵盖能源、国防、采矿等领域，6000亿美元的投资将包括出口额142亿美元的通用电气燃机及能源解决方案，以及价值48亿美元的波音737-8型客机。近1420亿美元的军售恰为年来规模最大，其中包括空中和导弹防弹、海防、边界和通信系统升级，美国还将为沙特武装部队提供培训和支持。原来靠卖的美国军备在这次阿拉伯冲突之后，开始进入加速推广销售期，趁着美国飞机还没被卖起来，赶紧卖吧。

相对于美国拜访中，中国领导从俄罗斯回来以后也搞了个骚操作，在家里门口挖了一个拉美和加勒比地区国家领导人峰会，把拉美和南美的领导都请到北京来。这是美国的后花园和大本营，美国搞重返亚洲、印太战略，中国战略稳固，我亦可稳的对等原则，把手伸向美国后花园和周边地区。美国把拉丁美洲国家拉入华盛顿圈，把巴西半球纳入自己的势力范围，为对美国做准备；对中国来说，来了来了，怎么可能让你撤回去。

中国这个拉美峰的操作让美国很不舒服。过去都是美国打跑到日韩，在中国人眼皮底下搞搞事情，现在中国人把这些拉美兄弟全部赶到北京。毕竟对许多美国政府来说，这很意外，谁知道哪天就能用上。川普上台后，第一次出访东南亚，巴拿马、危地马拉、多米尼加等国家让坐立不安。中国布局了巴西、秘鲁、智利等其他拉美国家，资源最大的客户拿到更多的订单。

根据海关统计数据，墨西哥对美出口额超过了中国的47%。中国与拉丁美洲贸易额去年达到1900亿美元，约为十年前的两倍。美国在经济上对拉美地区的深度，让双方在谈判之余，划定的90天缓冲期内可以快速妥协。恰恰是因为双方知道这是权宜之计，这种暂时的缓冲很短，不会造成太损失。而过去一个月的极限关税战，是中国进行的一次边界测试，有点像夫妻分居一段时间，看看大家会有多大影响。可以说双方都感受到了突然失去对方带来的巨大压力。

在中国方面，以航空制造为例，中国目前尚未完全掌握高端发动机的自主研发能力，仍需从美国进口关键部件维持整个航空行业的正常。关战爆发后，中国国产大飞机C99的关键部件几乎完全依赖国外供应商，且大部分来自美国。C99的核心发动机LEAP-1由合资的CFM公司提供，其中核心部件在美国俄州生产，中国自研的替代发动机仍在测试中未完成。整供应链有高达48家美国供应商，其中包括韦瑞、柯林斯宇航企业为C99提供关键的航电、飞控等系统。这意味着美国随时可以卡住中国大飞机的脖子。中国制造业对某些能源及化工原料的依赖也超想象。比如塑料生产的原料主要是乙烷，中国近年来来通过裂解装置进口乙烷以生产丙烷等基础化工。对美国乙烷供应的国内塑料生产商给予关税豁免，免受贸易战高关税的冲击。

在医疗健康方面，中国对美国的依赖主要体现在高药品和医疗设备上。很多先进药物和医疗器械仍由美国西方国家供应。中国要在短时间内完全脱对美依赖并非易事。

在美国方面，中国制造优势同样对美国构成威胁和挑战。美国可以依赖中国的科技，但却不能忽视儿童玩具和洋娃娃的短缺或是价格上涨，日用品关乎民生，还有一些原料药的供应，以及大量的高质量零配件和电子产品。说了，中美快速脱钩的结果是：中国向前进难度增大，美国保持现状难度增大，一个未来变得渺小，一个现在都难以为继。

所以，一切只是刚刚开始，不宜乐观，也不宜悲观。饭要一口一口吃，路要一步一步走，不犯错就是最重要的事情。
