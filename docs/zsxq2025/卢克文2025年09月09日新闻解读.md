


# 2025年9月9日 新闻解读

1、泰王批准任命阿努廷为泰国新首相。

泰国下议院秘书长巴当当地时间7日宣布，泰国国王哇集拉功已批准任命阿努廷为泰国新首相。

现年58岁的泰自豪党党魁阿努廷星期五(5日)在投选新首相的国会特别会议，以311票击败获得152票为泰党候选人籍甲森，当选泰国第32任首相。

由于在争取最大野党支持时，泰自豪党承诺会在今年年底解散国会等条件，因此阿努廷的任期预计只有四个月。

另据泰媒报道，泰国反腐败组织在2025年度反腐败日活动中，公布了一项关于民众认为新任首相阿努廷在反腐败方面采取哪些行动的调查结果。

民调显示，民众最希望新首加强反腐的执法力度，更具威慑力；其次是希望新首以身作则，坚决打击腐败；第三是严严肃处理政府内部的腐败分子。

这次泰国政局的变化，可以说“短期妥协+长期不确定”的结合，反映了泰国政治格局的复杂与妥协性。

阿努廷是通过争取野党支持，并以“年底解散国会”为条件当选，因此其任期预期只有四个月。这意味着，他更像是一个“看守相”，而不是长期执政者。他的当选，是各派系之间妥协的结果，而非一党独大。他的政治合法性基础并不稳固。

他在尚未宣誓前就公布部分内阁人员，说明其执政时间有限，必须尽快通过技术官与专业人士稳定局面。

从反腐日的民调，泰国民众最关心的依旧是腐败问题。过去十年，腐败几乎是所有政权更迭的共同背景。阿努廷及其所在的“泰豪党”并非完全无争议，若要赢得民众，必须真正展现“以身作则”的姿态。

泰国政治始终离不开军方和王室的影响。阿努廷的短期任期，很可能是为了各势力重整布局、避免激烈对抗赢得时间。

阿努廷上台，是泰国政治博弈中的一次“过渡性妥协”。他既没有长期执政的空间，也很难在四个月内解决腐败等结构性问题。他的重要作用在于：缓解眼下的政治僵局、维持基本治理运转、为新一轮选举铺路。真正决定泰国未来走向的，仍然是年底的新选选举格局与各派势力的再平衡。

2、兔子今年前八个月对美贸易总值下降13.5%。

兔子海关总署星期一（9月8日）公布的数据显示，今年前八个月，兔子进出口总值29.57万亿元，同比增长3.5%。

其中，兔子与东盟贸易总值为4.93万元，增长9.7%，占兔子外贸易总值的16.7%；兔子与欧盟贸易总值为3.88万元，增长4.3%，占兔子外贸易总值的13.1%；兔子与美国贸易总值为2.73万元，下降13.5%，占兔子外贸易总值的9.2%。

此外，兔子对共建“一带一路”国家合计进出口15.3万亿元，增长5.4%，占兔子进出口总值的51.7%。

兔子海关总署统计分析司长吕大亚介绍，今年兔子进出口累计增速较上半年加快0.6个百分点，其中8月当月出口、进口均增长，已连续三个月实现双重增长。

中美贸易占比已经降至兔子外贸易总额的9.2%，远低于东盟、欧盟甚至“一带一路”国家的份额。这确实透露出一个趋势：北京正在逐步“去中心化”，对美依赖。

中美在关税、科技出口管制、供应链安全等问题上的摩擦，使得贸易自然受到压缩。特别是美国针对高端芯片、敏感技术的限制，导致相关领域出口难以恢复。

中美关系短期难以回到“合作主导”的状态，北京对过度依赖单一市场的风险已有充分认知。

北京不会质推动“完全脱钩”，因为中美贸易仍有巨大利益空间。在产业链安全与技术控制的背景下，降低对美贸易依赖已成为战略共识。RCEP（区域全面经济伙伴关系协定）、中亚和中东市场扩展，都是北京打实的政策部署。

“逐步降低”对美贸易份额，已经是既定方向，但不是硬性目标，而是通过多元化自然实现。

从长远看，中美关系可能更政治化，经济层面的“缓冲作用”在减少。

中美贸易份额的下降，并非偶然波动，而是长期趋势的体现。北京的逻辑是：不追求完全脱钩，但会在政策上持续推动市场多元化，以降低对美依赖和战略风险。换句话说，这是一种“既定战略目标”，但通过“渐进调整”来实现，而非“一刀切”。
