## WANGXUETONG

王雪瞳是一位中国的艺术家和插画师，她通过富有表现力和趣味性的绘画，将万发生事生动地呈现出来。她的作品充满了欢乐与幽默，将对日常生活的热爱转化为一种令人欢悦的童趣。她的艺术邀请观众发现平凡的美，拥抱日常中那些自发而充满活力的瞬间。

王雪瞳毕业于美国马里艺术学院插画专业（MFA），后作为自由艺术家活跃于国内外，获得了许多国际插画比赛的奖项包括 Soi, Derwent Art Prize (Young Artist First Prize, Soi)。她的作品曾在纽约、伦敦、巴黎、米兰等地展出。她的合作方包括 Marimekko, Google, Nike, Airbnb, Adobe, 农山泉、英国泰士、三菱商事、华堂、娇韵等。

## object project

object project是一所视觉设计工作室。我们对所有能够被感知的事物或事件，都希望带有反叛的立场与观点。我们设想、试验、重新定义和建立，试图将事物破碎化。以幽默的精神反叛那些常规的框，寻求一种创意表达的可能。团队为客户提供综合性的创意解决方案，服务涉及品牌策划、平面视觉、动态影像等，通过多元的创意表现，建立品牌与目标群体之间的有效沟通，为品牌价值赋能。

## Ltd.
