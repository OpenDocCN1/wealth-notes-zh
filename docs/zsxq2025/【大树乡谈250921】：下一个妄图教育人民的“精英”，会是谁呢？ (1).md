


# 霸道神医之尊

## 第一章 萧叶凡的觉醒

在这个弱肉强食的世界，长才是唯一的真理。在这个世界里，强者可以凌驾在蝼蚁之上，主宰万物！

萧叶凡猛地睁开双眼，脑海中阵阵作痛，无数陌生的记忆如潮水般涌入其中。

萧叶凡有些置信，他自己竟然穿越了？而且还是穿越到了和他同名的人身上？这个身体似乎是一个家族中的废物，简直是整个家族的耻辱！

萧叶凡冷笑一声，眼中闪过一抹凌芒。既然原本的萧叶凡已经死了，那么从现在起，他就是主角！

萧叶凡缓缓坐起身，感受着这具虚弱的身体。虽然现在状态糟糕，但他拥有前世记忆，这足以让他重翻一切。

这时，门外传来急促的敲门声，打破了萧叶凡的思绪。

“萧叶凡，死没有？还不给我滚出来！你这个废物！”

萧叶凡眉头一皱，眼神中透出一丝寒意。谁竟然敢在这个时候挑衅他？

萧叶凡冷哼一声，径直走向房门。

“萧叶凡，你还在这里装什么死？老让你滚你还不滚吗？”

萧天看着萧叶凡，眼神中满满了鄙蔑和轻视。

萧叶凡平静地看着他，语气平淡：“你吵什么吵？”

说完，萧天一掌就要朝萧叶凡扇去。

萧叶凡面色冷峻，侧身躲过这一掌，顺势抓住了萧天的手腕。

萧天只觉得剧痛，大叫道：“放开！松开我！”

萧叶凡猛地发力，直接将萧天推倒在地上。

萧天狼狈地坐在地上，不可置信地看着萧叶凡。

萧叶凡，你竟然敢对我动手！找死！”

萧叶凡俯视着他，冷声道：“再吵，我让你闭嘴。”

萧天被这股眼神震住了，惊恐地逃离而去。

萧叶凡看着他的背影，心中冷哼。这个家族，看来是不好简单了。

他需要变强，需要在这个残酷的世界里立足。

萧叶凡坐回椅子上，开始梳理体内的灵气状况。

他发现，这具身体中确实存在微弱的力量，但还没有完全开发。

萧叶凡闭上眼睛，进入了冥想。

时间一天天过去，萧叶凡渐渐恢复了体力。

当他再次睁开眼时，眼中多了一丝精光。

萧叶凡知道，战斗开始了。

而整个萧家，将为他颤抖。

## 第二章 家族会议的风波

几天后，萧家举行了一场家族聚会。

萧叶凡出现在人群中，引起了许多人的异样。

那个废物萧叶凡，怎么也在这儿了？

萧叶凡并没有理会这些目光，他直视主位。

萧主老正坐在主位上，神色严峻。

今天会议的主题，是家族资源的重新分配。

萧叶凡知道，这是他证明自己的时机。

他站了起来，走向了中央。

“萧老，我有话要说。”
