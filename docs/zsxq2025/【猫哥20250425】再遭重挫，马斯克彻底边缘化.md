


# 再遭重挫，马斯克彻底边缘化

## 嘉宾：梦回安西

近期，美国多家媒体爆料，马斯克和财政部长贝森特在白宫会会议上吵了一架。更多文章加薇：pep458

两人吵得很厉害，都互相骂娘了。事后，特朗普在处理中明显偏向贝森特，马斯克再遭重创。

那么，这是怎么回事？

我们以前的文章说过，贝森特是索罗斯的马仔，索罗斯的“成名作”是1992年做空英镑，获利超过10亿美元，当时具体负责此事的，正是贝森特。

而马斯克和索罗斯，是有深刻矛盾的。

一来，索罗斯代表华尔街，属于老钱，马斯克代表硅谷，属于新钱。新钱和老钱的矛盾，本就很激烈。

二来，索罗斯长期资助各种恐怖分子和政治正确，LGBT更是索罗斯的重点资助议题，马斯克则因政治正确病毒丢失了长子，两人在意识形态上十分不对付。

三来，马斯克对权力分配不满。

作为大功臣的马斯克，自然希望在政党里培养势力，最好自己的人马，能拿到一些实权部长。而每个部长，份量最重的无疑是财政部。

但偏偏马斯克的人马没有得到太多，除了马斯克亲自掌权的“政府效率部”，就只有一些顾问职位。反倒是自己的死敌索罗斯的马仔，得到了财政部长。

这一切，让马斯克对贝森特很不爽。

贝森特刚上任，“政府效率部”就找着去了，想进入财政部的核心支付系统，但贝森特的应对很老道，弄到了联邦法院禁令。

一招未成，马斯克又摩蹭起了别的策略——偷袭税局。

财政部旗下的国税局，因为代理局长们不合作的缘故，已经连着换了几任代理长，人事始终不稳定。马斯克趁机向特朗普推荐，由沙普利出任新的代理局长。

特朗普同意了。

但这个消息，让贝森特异常恼怒，毕竟国税局是财政部的下属单位，应由财长推荐局长人选。你马斯克不是财政部的，哪来的权力推荐？

4月17日，两人在白宫会议上当众吵了一架，贝森特指马斯克未能减少多少开支，马斯克则讥贝森特是俄罗斯代理人，两人还互爆粗口。

室内吵还不不够，两人随后走廊继续吵，差点要动手。

特朗普和意大利总理梅洛尼就在隔壁，他们都听见了。

一天后，特朗普决定，解雇沙普利，任命贝森特推荐的财政部副部长迈克尔·福尔肯，出任代理国税局长。

上一次，马斯克和卢比奥吵架，特朗普站队卢比奥，削了马斯克的权。这次，和贝森特吵架，特朗普站队贝森特，连续两次打击，对马斯克是致命的，不管5月份是否辞职，“政府效率部”都事实玩不下了。

“政府效率部”不是正式部门，改革能不能成，全看特朗普的支持力度，外界知道，特朗普在关键问题上总是不站马斯克，还怎么搞？

两个月来，马斯克已经得罪了内阁里三个派别。

第一个，是卢比奥为首的共和建制派。两人的分歧，在于马斯克认为国务院裁员太少。而卢比奥觉得，裁员太多自己还怎么干活？

外交是人力密集型行业，象征性裁一一点就行了。

第二个，是纳瓦罗为首的MAGA派。MAGA派希望加关税，不管不顾地加，但特斯拉的供应链是全球化的，关税会严重损害马斯克的利益，所以，他和纳瓦罗吵了一架。

在此之前，马斯克和MAGA派吵过一次，双方的分歧在于H1-B签证，MAGA不希望保留这个签证，觉得导致了大量移民进入，抢占工作岗位。而马斯克希望保留，特斯拉和X公司，有大量H1-B签证的员工，甚至马斯克本人，当年都是靠H1-B签证来到美国的。

第三个得罪的，则是贝森特为首的华尔街钱派。

除了这三大派别，内阁里对马斯克不爽的人还有不少，比如交通部长达哈，反对马斯克裁交通系统。国土安全部长诺姆和卫生部长罗伯特·肯尼迪，对马斯克颇有微词。

司法部长帕姆·巴厄，虽然没有明着表达不满，但语言中对马斯克有些阴阳怪气。

不夸张地说，马斯克已成为执政团队的内部公敌，真正和他关系好的，只有万斯。但万斯的投机属性重，难说是真好还是假好（考虑到万斯的金主是彼得·蒂尔，不大可能公开和马斯克翻脸）。

这个“一字并肩王”的保质期，未免太短。

马斯克不是一个人，他代表的是硅谷新钱，是近年来崛起的“科技右翼”路线。

在“科技右翼”眼中，民主党管制太多，政治正确导致科技发展慢。他们认为，只有放松管制，科技才能加速。说白了，所谓的“降本增效”，更多是表面，为了让私人资本。

对马斯克不爽的人还有不少，比如交通部长达哈，反对马斯克裁交通系统。国土安全部长诺姆和卫生部长罗伯特·肯尼迪，对马斯克颇有微词。

司法部长帕姆·巴厄，虽然没有明着表达不满，但语言中对马斯克有些阴阳怪气。

对“科技右翼”来说，自己在政坛的影响力远不如华尔街，共和党建制派处于旧式状态，扶不起来。比如马斯克在站队特朗普之前，是桑蒂支持的支持。无奈桑蒂斯不是特朗普的对手，在初选中局。特朗普既有前途又缺金主（在马斯克加入前，特朗普的资金一直少于哈里斯，也少于拜登），愿意给出的合作条件，于是双方一拍即合。马斯克的边缘化，无疑是“科技右翼”的重大失利。

当然，这未必不是好事。

“科技右翼”的许多主张，其魔怔程度比左歪有过之而无不及，真让他们成了，可能是大灾难。

一系列挫折，能让这帮人认清现实，别老想着搞独立王国。
