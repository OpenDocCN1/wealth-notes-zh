


# 守夜人总令觉悟星球 251008：机会?

已经在日本部署了一个反导弹系统，又在菲律宾部署一个反导弹系统。之前在台湾和琉球部署了高爪雷达，路基雷达的最远遥测距离是800公里。
探测只能看到，要达到威慑和攻击的目的需要部署中导系统，之前对球三角是没有覆盖的，如果实在在菲律宾部署，就把兔子核心区域全部覆盖了。

之前说过，不能老是拆，兔子大有可为。早两天看到新闻里面，耿大大使在联合国发言中特别提到了，要求美国在全球的范围内，撤回海外部署的核武器和京中导系统。我觉得提到武器是用来打掉的，核心应该是这个中导系统。

突然想起来我弟说国能回家，被紧急安排了去非洲出发一次。如果是从基层派出的级别的人去，基本上是为了训练或联合演习打个打算，而且规模都不大。但是我是从总部派出的，而且我是给老大大掏的，这就看着是战略任务，而不是基层训练交流。鉴于保密条例不能多问，就只能根据有限的信息进行合理猜测。

## 我的判断是：埃及！应该去埃及。埃及可能购买我们兔子的武器系统，并且在希奈半岛左靠埃及及侧部署一个能覆盖以色列及其周边国家的导弹系统，兼顾攻防，以防万一。我的判断是，如果是在埃及部署，那覆盖范围是足够。当然，埃及是最理想的。
