


# 达叔星球：地方彻底没钱，开始各显神通，政策倒逼进行中

2023-10-23 22:05

最近楼市里各种多的声音，正在全面增加，尤其是达叔在线下面会分享过的人物：

孟晓苏，开始下场自己做自媒体了。

按照达叔对他的研究，他这样的人，七十多岁了，应该不是下来吃自媒体这碗饭，更不是来卖课做生意的。那他为啥要下场做自媒体？

> 按照达叔对传播学的理解，应该是半官方性质的来做民意铺垫，为下一步政策转型做舆论准备。

其他人，能不能来做？

房价还能继续上涨，即使在当下，放在舆论场里仍然是热的。所以，绝大部分专家都不愿意发表这样的观点，都明哲保身。

谁愿意站出来？

得从人群中选。选择的标准有两个：

1. 又红又专+有担当敢挨骂
   - 又红又专：对房地产是真的懂，对外表达有说服力，孟晓苏是房改课题组组长，当年98房改的参与者，根正苗红，符合条件。
   - 有担当敢挨骂：这种在特定时期，敢于牺牲自己的名声，敢于承担骂名，放放在任何一个组织里，都是极其难得的人。

绝大部分人都是要明苟保身的，害怕被牺牲掉，于是都不说话，这是性格造成的。而孟晓苏的语言风格，有多少点像之前的任某，胆子比较肥，对民也不忍着，敢于下判断，就是告诉你，以后还得继续上涨。

孟晓苏发表了观点之外，还在代表产者群体，不断呼吁要开放城市限购，要阻止违法拍房入市，给失球迷群体时间。

从很多具体操作层面，不断反馈一些可执行的操作。这些观点，有没有用？慢慢会有。

## 因为利维坦内部的利益格局，不是铁板一块

全世界都知道你陷入了通缩，都知道你工业部门产能过剩，都知道你的经济被房产拖累。

解决方案之一，就是给中下层居民发钱，把房地产搞起来，把资产价格搞起来，增量涨工资+存量资产价格上涨，才能走出通缩，才能拉动消费。这是全世界个个精英群体给出的药方。

2024年中，IMF等外机构建议东大，要搞至少1万亿美金的刺激计划，才能改善通缩。东大当场否定了。

进入9月底，自己就宣布，要开始搞10万以上的刺激计划，这个规模大于1万亿美金。嘴上不认，动作上是跟，这就是务实的态度。

喊了一年的止跌回稳，如果无法做到，之前该破产的人已经全部破产了，剩下的群体如果彻底接受资产价格不涨，那未来想改变这个预期，就难了。

## 一旦资产价格不涨的预期形成，资产负债表收缩

所有人都不愿意继续加杠，最先受损的一定是利益维系自己。

因为家庭部门紧缩衣食，能把成本降下来，但很多地方性的开支是刚性的，压根就无法降低，会造成大量赤字和负债。于是，就发生了湖北表的声明：

一切国有资源尽量资产化，一切国有资产尽可能证券化，一切国有资金可能杠杆化，要活活一池春水。

> 翻译成人话，就是老子没钱了，家里还有点钱的土地、矿产、能源、水利的，拿出来换点钱，你们帮帮帮忙，价格好商量。

以前口号是要干实体，要加杠杆，欢迎民间拆防止资金脱实向实。为了这个目标，把居民端唯一愿意加杠杆的楼市，都给摁去了。

房价刚回调几年，“好日子”才开始，湖北在30多个省份单位里算是中等偏上的，不算最差的，能喊出这种过天的口的号？资产化、证券化、杠杆化，这不是都是上一周期在干的错事？

如果湖北当地的钱、民企老板，尤其是没啥背景的，脑子一发热，真掏真金白银去接盘，帮你渡过难关。能活到2025年，手里还有百万千万的人，一定是极其精明，极其保守，不愿意妄冒任何风险、甚至从不垫款做公家生意的家伙。

但凡野心大一点、杠杆高一点、给公家垫款多一点，在过去早就早就割，坟头草都3米高了。湖北北方肯定也知道，很难会有民企来接盘，为什么还喊这个出口？一定是有原因的，不会白喊，一定是冲着某个特定群体喊的。是谁？

## 金融机构

把这些国有资产，打包成 REITs 产品，对外变成年化收益3-4%的理财产品，卖给那些愿意买理财的广大民众。

国有资产名义上就是全民所有，现在证券化让全民买单，你可以花钱买你的资产了。你不买？你买的那些基金他们帮你买，你等着收利就行了，至于本金到底哪了，你反正也不懂，也不需要你懂。

地方操盘手+国企+金融机构三方联手本地化、债务化，就能拖过难关。各位小朋友都想过，东大14亿，每人给我块钱，我就有44亿。居民在银行里存了3万，不买房，只买理财，那就打包成理财产品卖给大家，换钱。自古以来，利维坦没钱的时候，先取商，当商没钱了，就取民，反正自己是没钱的，都是靠养。

这种资产化包装，要是还搞不来，那就直接抢了。谁敢去收？操盘手鼓鼓鼓励民加杠杆，如果搞搞，销售额还要持续下跌40%。

她还直接点名了三个自己机构持有的地产：华润、建发、新城控股，都表达了适度乐观的情绪。
