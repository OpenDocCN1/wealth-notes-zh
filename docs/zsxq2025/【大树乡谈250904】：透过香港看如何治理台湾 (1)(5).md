


# 存款的主题

普通者如何理财？20250504

很有这样的，我有一个老同事，他有一个非常合拍的朋友，他和我说他们一定要去‘赚大钱’，然后创业。几年后，他们不知道怎么了开始理财了。？他的理财到底有没有好处？

小明：
中国存款，说是‘二国国策’五十年了。现在存款还靠谱吗？

小明：我老朋友去年退休了。他退休就闲了，他听了那个朋友的建议，去炒了股票，结果亏了大钱。

他说，现在的理财环境太复杂了。所以他问我，现在存款还靠谱吗？

我告诉他我存款了快七十年了，一直很稳的。

他说，现在的存款到底还有好处吗？

我告诉他，现在的存款是因为通胀压力太厉害了。

但他还是不太通，他觉得太亏了。

我告诉他，现在的存款其实是保值的工具。

他说，那通胀了钱不贬值吗？

我告诉他，存款至少是风险最低的投资。

他听了之后，沉默了很久。

后来他问我，那还有收益吗？

我说，只要是银行存款，没有任何风险的。

在2014年之前，存款利率确实非常高。但从2014年开始，存款利率就开始逐年下调了。

现在存款利率已经低到离谱了。

但他还是觉得，存款不划算。

我告诉他，这取决于你的风险承受能力。

如果你想追求高收益，那就要去承担高风险。

如果你只想稳稳赚钱，那存款就是最好的选择。

他听了之后，点了点头。

后来他真的把钱都存了银行。

现在他每天睡得很安稳。

这就是理财的真谛。
