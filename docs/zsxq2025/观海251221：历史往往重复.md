# 【中国神华：拟购买国家能源集团及其全子公司西部能源持有的相关资产交易价格1335.98亿元】

财联社12月19日，中国神华(601088.SH)公告，通过发行A股股份及以现金的方式购买国家能源集团持有的国源100%股权、鑫鹰能源100%股权、化工公司100%股权、乌海腾骏100%股权、平压业100%股权、神延炭炭41%股权、吕德能44%股权、包头矿业100%股权、振兴公司100%股权、煤炭运输公司100%股权、港口100%股权，并以支付现金的方式购买西部能源持有的内蒙资产，交易价格为1335.98亿元。本次交易的整体股份和现金支付比例为30%和7%，其中现金支付对价额为935.19亿元。本次交易共涉及12家标的公司，业务涵盖煤炭、炼化炭、煤化矿等多个领域，有利于上市公司核心业务与资源价值规模提升，进一步优化全产业布局，为推进清洁生产、优化配置、提升盈利创造有利条件。通过本次交易，中国神华的煤炭保有量将提升至68.9亿吨，增长率64.72%；煤炭可采量将提升至345亿吨，增长率达97.71%；煤炭产量将提升至5.12亿吨，增长率56.57%；中国神华2024年每吨收益将提升至3.15元/吨，增厚6.1%。2025年1-7月每收益提升至1.54元/吨，增厚4.4%。

【情节严重！】投资者拉抬头压股价 交易所火速出手

2025-12-20 17:16 星期六

12月18日，北交所发布对李某莱采取自律监管措施的决定。经查明，2025年12月18日，李某名下证券账户与其涉案关联的账户，在交易北京证券市场上股票“违规股份”的过程中，存在抬头压股价的异常交易行为。18日当日，该股份涨幅达30%。北交所认为，其行为违反了《北京证券交易所规则（试行）》第6.2条第一款（三）项个人证券账户、两个以上上固定的涉案关联的证券账户，申报、连续申报、秘密交易、报价等行为的规定。相关投资者的异常交易行为导致股票触限制价格，引发异常波动情形，且在实施抬头压股价行为后大量向卖出，情节十分严重，市场影响异常。

同时，李某名下证券账户多次出现异常交易行为被采取自律监管措施，分别为2025年6月20日、11月7日被连续实施暂停证券账户交易，但仍未纠正，继续实施异常行为。鉴于上述违规事实，根据《北京证券交易所规则（试行）》第6.7条，以及《北京证券交易所自律监管措施和纪律处分实施细则》第十七条、第二十条的规定，交易所作出如下决定：对李某名下证券账户交易的采取自律监管措施，并记入。
