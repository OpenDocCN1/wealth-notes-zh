


# 什么是穷人思维？

以下十点，直指要害。

- 1. 白嫖：喜欢免费的东西，不愿意为他人的服务、工作、产品付费，经常花几个小时几天，省几块钱几十十块钱。以自己弱势为由，占别人便宜，但从不愿意被人占便宜，哪怕几块钱几十块小钱的亏？

- 2. 脸皮薄：因为穷而自卑，因为自卑而敏感，脆弱。在意外跟他人的看法，常常为了他人一句批评纠结几天，为了不重要的人的认知绞尽脑汁几天甚至几个月。

- 3. 假清高：盲目相信个人能力，对于假清高平台、人脉、资源有一种天然的抗拒和鄙视。别人赚钱发财都是“拉帮结派”、“狗屎运”。无法正视自身不足，假装清高，背后又各种嫉忌嫉恨。

- 4. 猥琐：有所隐藏，不大方。面对喜欢的人，不敢勇敢地搭讪交流，面对心仪的工作，不敢勇于直面主动争取。总是在隐藏，又总是后悔。

- 5. 抠门：金钱观非常保守，对别人抠，对自己也抠。不把钱花在投资提高自己上面，不花钱维护人际关系，举手投足之间，流露出一种小家子的气场。

- 6. 自大：不利用资源，不相信别人而凡事亲力亲为。遇到不懂的领域第一反应是单干自学，不会借力，也不想“麻烦”别人。

- 7. 短视：做事情急于求成，目的性很强，对短期带来金钱回报的事情兴趣很大，但是对需要中长期投资才能见效的事情相当排斥，喜欢一夜暴富，却往往成为收割的对象。

- 8. 计较：可以为了几块钱鸡毛蒜皮的事情跟人撕破脸皮干架，不喜欢欠别人人情，恨不得时刻划清界限，殊不知这恰是计较到骨子里的狭隘。
