


# 中美马德里会前瞻

发布时间：2025年9月15日

9 月中美马德里会大义上不会有亮眼的动作，但却一定要达成一批重磅的协议，因为中美领导人一定会10月底开会，为了避免大佬见面时没有协议可签，本轮中美必须给大会创造前进提条件，非谈得非常非常好，达成的协议非常多，否则9月的会谈结果，都要留给10月，这也会让9月会谈显得平平无奇。

实际上9月会谈的大背景是美储储息放流动性，中国憋着的经济刺激动作也会随着启动，因为有增量，中美之间就不可能不谈得好。

TikTok和芬太克关税关于关注度极高又容易妥的类别，可能有在本轮谈好，但不公布，交给10月大会见面时宣布；芯片、稀土等这种没那么着急的，都属于这一类。

美国的大豆属于季节性产品，农民又决定明年的中期选举，没办法拖到10月底，倒是可能在9月先开好头。至于全面关税、贸易、美债等需要一赢各表的复杂议题，还涉及复杂的国际政治，中美之间不可能短期内完成整体协议，中国政府也会采取，尽量向特朗普的危险时刻靠拢，比如，提出一些双方梦寐以求，但是短期内绝对谈不好的交易。
