


# 简单策略，方向性与周期

已更新 | 2023-11-25 10:59

今天开盘，一向是方向性和周期性的议题。

什么是方向性？是因素的聚类以及如何识别的计划和周期。

现从某个节点/板块/周期/如何开盘来识别自己的计划和周期。

什么是方向性，方向性的定义是基于基础的知识、经验，识别出来的结果以及，为了决定胜率的周期内在逻辑。周期决定胜率，仓位决定盈亏。

所以每一刻交易就是选择机会，先有方向，然后才有节奏的节奏。在这个月里，第一个月开盘的节奏很难控制的，也许可以参与交易了。

如果11月以前没有机会，那么就是你的机会。熊市已经逐渐结束了。

为什么11月会有这种强势行情？由于方向性的开始显现，压力测试，即将反转了。

什么是反转的出现？取决于方向性的显现。当方向性开始显现，当下跌速度/放量被得到出来，可能就能发现反转了。

在11月之前没有机会，但是从11月开始出现了机会。三个月没有机会，现在就要开始交易的准备了。

接下来/如何建立自己的系统，我想学习控制亏损以及如何寻找机会。

这个11月可以做到交易的亏损比前一个月好了。

所以我已经构建了系统，但是我们还要学会去寻找的机会。

在回看这段时间，在参与的机会中低价回调/高位突破的机会。

所以，我应该自己积累经验去寻找机会，什么时候做什么，是为方向的获取的收益。

接下来需要三个步骤：

- 1. 参与控制的机会，和制定机会和产生价值的交易，市场是相互博弈的结果。我是为了胜率，如果不是一个持续性的机会，那么就如此亏损，我是不错的。
- 2. 分批建仓，分批比较合适，不要太着急，不要太操心，但是一定要考虑仓位。
- 3. 学会如何止损，不要在亏损
