


# 米联储闻250716——水尽南天不见云（都是桌上吃饭的人），想吃什么怎么吃，不是美国说了算了）

中国上半年经济逆势增长，英伟松绑了H20芯片，外媒对比的解读是，中国已局部突破了美国的技术和经济封锁。面对国内需求疲软和全球贸易风险加剧，预计中国下半年经济增长将显著放缓，国家统计局的数据是同比增长5.2%，高于路透社和彭博预测的5.1%。彭博分析，饮料、酒类及化妆品消费品同比下降，餐饮服务增速也明显放缓，官方表示上半年最终消费支出对经济增长贡献率5.2%。目前出现供给强、内需弱的格局，出口的韧性也难以维持。房地产复苏势头再次减缓，与通走势密切相关，当前价格持续低迷，若趋势延续，可能形成负反馈，消费者预期价格还会下降。因此，下半年，有效抑制通胀成为政策关键。按惯例，7月下旬召开政治局会议分析当前经济形势，部署下半年经济工作。最近规格极高的城市工作会议，部署的几项内容都持续投入资金，加大基础设施投资和消费补贴力度，从推动消费保持增速，只能说赚钱的压力巨大，花钱的压力更大。

今天，印尼宣布与美国达成贸易协议，美方将对印尼出口商品征收的关税率从32%降至19%。印尼表示谈判团队是经过非同寻常的搏（extraordinary struggle）与美方达成共识。这是英国、越南之后，第三个跟美国达成贸易协定的国家，也是盟友主要成员之一。作为与美国达成的贸易协议一部分，印度采购50万波音飞机、价值150亿美元的美国能源和价值45亿美元的美国农产品，将不需要支付关税。2024年，印度对美国的贸易顺差达179亿美元。新贸易协议达成后，印股市指数7月16日一度上涨0.7%，有分析师表示，这将为经济活动带来正面推动力。从这个结果来看，你不得不承认川普曾看来荒芜不堪，但实际的经济工作一点都没有松，在解决实际经济问题的效率上是远超过民主党的。

虽然看上去都是在捡小便宜，非民主党当也那般高大，从得失的角度来看，羊毛还是羊毛，这样一个国家一个国家家里，吃是难看，美国获得的实际好处也是实实在存在的。

高考研究中心最新调查显示，在高收入国家，对中国持正面看法的受者比例为32%，年来最高。相比之下，美国的感好度则降至35%，2017年以来最低。全球约有万万人参与调查，越多的受者认为中国是世界第一经济体。在接受调查的25个国家中，41%的成年人将此称号授予中国，认为美国为第一经济体的比例为39%。这与年前形成鲜明对比，当时认为美国是全球最大经济体的受者，明显高于是中国第一经济体的人。这或许也是川普政策的代价之一，对美国来说，名声考虑顶，先把日子过过去才是关键。

竞争态势，全球仅剩两个玩家，不是美国就是中国。比如人在机器人领域，今年可是人形机器人产量领先，美国跟中国都在抢夺主权。马斯克最近说，机器人产业排行，特斯拉是第1名，第2到第10名可能都是中国公司。虽然马斯克这个第一是他自己的，但是美国对中国机器人产业的恐可想而知。官方方面最近也在推动机器人的产业规模，包括举办一系列机器人的比赛，甚至邀请美国媒体到中国的机器人来参观采访，扩大影响，吸引投资，给美国画了大饼。根据摩根士丹利研究报告，这波机器人开发热潮好出现在中国政府将国家优先发展的项目中。在中国电动汽车领域展现了自身的创新能力，现在也希望在AI机器人领域取得主导地位，与美国的技术差距在拉大。特斯拉的人形机器人 Optimimus去年在特斯拉活动上展示了灵活性与高动力，能随音乐热舞、与客户互动比赛，也能回应要求点心。马斯克计划将 Optimus在年底上线特斯拉，今年生产5万至10万、2027年50万，到2030年实现每年生产百万。但现在疑似硬件问题，续力不足，暂停生产。在马斯克与川普赛决后，自身不暇，影响了特斯拉的产业策略。与中国的机器人策略相比，美国更专注于高规格的机器人。机器人摩根士丹利显示，去年5年，中国成功申请5590项涉及机器人的专利，而美国只有1442个。中国面临的现实挑战是，目前研发机器人大脑元件的22家公司中，13在家，只有2家在中国。人形机器人高度依赖AI算力，英伟达当今霸主，左右看着人形机器人产业发展的下一步。这次英伟达对中国开放H20芯片限制，贝森特对美国媒体的说法，华为已经有了相当于H20算力的产品，所以继续限制的意义没有了，同时，这也可能是中美谈判的内容之一。目前最大的不确定性是8月中中美贸易谈判最终的走向。

此外，川普上周表示，周一对俄的重大政策出台，并恢复了俄乌的武器，最后的重大政策并没有什么新意，无非是征关税、供应、制裁措施。看来对俄罗斯，美国是真不想花心思，这点是跟当初奥巴马有点像，当初几乎是奥巴马默许，毫不费力地拿下了克里米亚，如今，川普面对诸多质疑，对于俄乌冲突的态度也跟奥巴马一样。奥巴马脑子里只有一个词：亚洲，还是亚洲。而川普脑子里只有一个词：钱，还是钱。

根据研究中心（CREA）数据，在俄乌冲突爆发之前，美俄双边贸易额达350亿美元。在过去三年，制裁下，美俄双边贸易额只有35亿美元。即便俄罗斯收100%关税，效果实际上没有任何作用。川普知道这个操作有点离谱，于是增加了对俄罗斯石油交易的关税。比如，从现在开始，毕竟中国才是俄罗斯石油最大的出口国，同时也是俄罗斯主要的贸易对象。美国通过印度、欧盟等国家，试图增加对俄罗斯的关税，可能会让进程造成必要的麻烦。

川普上台后多次求俄乌双方停火，另一方面加强。但是川普并不想转变策略，在这种情况下，川普没有足够的实力争取一个停火的局面，从这个角度来看也是有效的。拜登在期间向乌克兰输送超过600亿美元，让俄罗斯看起来够强劲。比起拜登政府时期，美国没有足够的军事储备来补充漏洞。反观俄罗斯的军事生产能力，今年为国防拨款1450亿美元，占2025年总支出的约14至15%。在战场上，俄军过去六个月每月获得乌克兰持续援助，俄军仍然在前线缓慢地推进。而且俄罗斯还有这样的超级工厂，如果俄罗斯把石油和钢铁交给朝鲜，就会换来朝鲜源源不断的援助，甚至人肉战力。正如美国在关税问题上无法对中国所欲，在军事上也无法对俄罗斯所欲，大家都是桌上吃饭的人，想吃什么怎么吃，都不是美国说了算了。
