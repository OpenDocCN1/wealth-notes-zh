


# 老实人的标志

原创：主任 公众号：tz 研究 25年5月8日

我们传统教育的观念里面，老实实在是被当作一个好的品质来对待的，尤其是当我们很小的时候，我们经常被教育要老老实实，做人要老实。我们夸一个孩子的时候也说：“你看这个孩子老实。”老实就等于听话，不会反叛，老实意味着看好家里，就是家长不用操太心的。可以说在学生时代，在学校里认真读书、守规矩、听老师家长的话，老实是个优点，老老实实的学习、考个高分，是非常有利于提高学习成绩的。

但是进入社会，老实人往往是被欺负得最多的对象。如果是单纯欺负新人也就算了，问题是一旦你被贴上了“老实弱”的标签，大家就默认你应该老实，就得吃亏、活得累死。如果别人评价你很老实，你是什么感觉？你听到这个评价你会不会高兴？我想以前可能会有人高兴，觉得这是对自己的正面评价。但是现在应该没人这么想了吧？

现在“老实”这个词，它书面上是褒义词，但是现实中已经是贬义词了。老实等于干活多、受气多、好事排最后。

在机关里面一样，老实人往往是干活干得最多的，一些没有人愿意干的活，领导就交给老实人来干。

老实人都于情面，脸皮较薄，又不懂得拒绝，往往越忙这个工作就越闲多。其实很多所谓的老实人，我更愿意把他定位为“不明的”，就是随波逐流，选择做好人，不轻易拒绝别人的请求，也不敢表达自己的想法和意见。

老实人的本质是不灵活，只认理，不懂变通。容易被欺负，固执，不懂变通，死守原则；性格软，情商不高，而且总在别人面前。在现在利益与规则发生冲突的时候，不知道如何应对，不知道什么时候该老实，什么时候不该老实，不懂得思考，洞察力不强。我们做人可以不本分，这个没问题，但是如果你不聪明、不动脑子，在职场中不会发展，还会被各种欺负，所有的脏活累活都给你。在单位里，最令领导害怕的，不是那些浑身带刺的，也不是那些有背景的，而是那些突然“开窍”的老实人。

老实人开窍的标志之一：认清人关系是一种博弈，要有一定威胁性。做当刺头必要，但是老实人更吃亏。更确切地说，老实人还不如刺头。

当然，我们没必要走极端，就是做人一定要刚柔并济，但千万不能当老实人，因为老实人的性价比是最低的。

俗话说：“人善被人欺，马善被人骑。”你过分善良，别人就会欺负你；你过分老实，别人就会骑在你脸上。人性“软怕硬”的缺陷是不可能克服的。

说白了，老实人的底牌被人看穿了，没有威胁性。人和人之间的关系其实是一种制衡关系，就是我经常说对另外一个人必须要有合法伤害，对方才会忌惮你。这个合法伤害不是说你要上去挨揍，或者你要去击坏，而是要学会适时反击。

别人跟你的每一次交往都是在试探你的底盘，弱的人人都上去踩一脚，欺负弱小可以是人的天性。你对别人的每一次回应都是在给别人提供如何对待你的依据，都是在对对方递刀子。也就是说，如果最后你被别人拿刀子捅了，这个刀子自然指的是虚构的，说别人伤害了你，你要记住这把刀子是你自己给出去的，是你递过去的。一个人不可能从一开始就开始被欺负，定是经历过过程，在这个过程中对方通过试探，通过你的反应判断你的态度，从而做出伤害你的决定。

那如果对方对你不客气、不友好，你需要知道这个行为是你默许的，这个口是你自己撕开的。因为对方第一次和你相处，他并不知道你的底线在哪里。是因为你的沉默、你的毫不反应、你的忍让加强了、激发了对方欺负你的欲望，这就是一个博弈的过程，没有谁一开始就开始忌惮去欺负你。

试探什么？试探你的底线在哪里？试探你的承受度，试探你的反抗度。比如说我们新到的环境和领导同事相处，他不可能一开始语言上非常过分的打压，不会一开始就这么严重，他可是开始有一些打压，但是他的语气上试探性的打压，试探打压之后发现你没有任何反应。

那我下次做一些行为，你是不是也不会有反应？给你安排的又是累又复杂的，然后好的、评优过的、露脸的活都给别人，侵犯你的实际利益。

年度优秀没有你，提拔没有你，这个时候你也没有任何辩解，没有任何争取。那么下次还会这样，甚至还会变本加厉。人和人的博弈就是一个虚实结合的过程。对方试探时，我们要做的一件事就是立框架，不要别人就开始欺负你。在舒服的时候明确表态，让对方觉得你是一个有框架、有分寸、有原则的人。

老实人开窍的标志二：任何好处都是主动争取的。

有些说老实人太谦卑，拿不到机会。因为职场没有绝对的公平，机会不是等来的，而是靠自己抢取的。面对机会的时候，你不争取，机会就会碰到。只有积极争取，机会才会给你。

不要等，机会是靠抢取的。要在领导面前刷存在感，如果工作工作完了，事后也可以去找领导汇报，让领导觉得你是不容易的。

不要让别人践踏你的原则和你的底线。千万不能太弱，可以妥协，可以示弱，但是在面对利益的时候，要立框架。对方在第一次试探时，我们用各种形式传递出去，让领导觉得你是一个有框架、有分寸、有原则的人，甚至不要太老实，老实人会保持距离。

如果你主动向领导争取，领导会认为你的好。当你开始主动规划未来的时候，已经超越了大部分人。一定要主动，你不跟领导表态，不跟领导去，什么好事轮不到你。再来说，你知道这次提拔没有，也要向领导传递信号，即使知道自己排不上号，也要去闹。为什么要这么讲？目的就是在让领导知道你不是无所求，不是可以随意拿捏、随意安排。如果已经忙完了，事后也可以去找领导汇报，适当拿捏一下即可。让领导知道你这个人还有脾气，下次再提拔不给你好，他就会考虑你了。另外还有一个方面，对领导来说，即使排不上号，你要去申请一次，领导可能没给你，他内心总觉得你欠了点什么，虽然本身轮不上你。但是很奇怪，人就有这个心理，你没给，他下次有机会的话领导就会尽量满足你，把之前欠你的还上。所以说我们一定要事先争取一下。作为过来人，我是非常明白的，很多时候提拔都是这样的状况，你这次提拔的，都是上一次或者几次欠下的债。比如这次提拔都是上次没有提拔成功的，所以早点汇报，早点争取才能早点排上号。通过询问一次来看领导对自己的印象。

当然，这还有一个前提，就是争取绝不能太早，相对提前就可以。你不可能刚到单位没两年，硬性条件还不是很符合，或者说排队十万八千里，你就去争取。那领导可能会觉得你对自身没有一个确切的定位，对单位的排序也没有一个准确的定位，是一个有点不清的人。所以具体情况你得体会分析掌握，但是一个大的原则就是要提前一点。

老实人开窍的标志三：要把自己当人

活着姿态真的很重要。本来平平洒洒两个人，你非要跪下来低着头人家说话，心理上就要矮一头。在对方眼里，你的恭敬不过是自卑，你的退让不是怯懦；你的忍耐，只不过是认怂了。

其实我特别讨厌“为什么我拿别人当人，别人却不拿我当人”这种话。想让别人把自己当人，不是怎么别人当人，而是自己得把自己当人。作为人，首先要爱自己，相信自己，坚持你所认为正确的，拒绝你所认为错误的；你不会看着别人的脸色而活，为自己而活，这就是把自己当人。

如果你被欺负了，不要觉得欺负了你是因为你太老实，而是因为你太弱。不要让别人觉得你好，不要让别人觉得你老实，让你太累。

不要让别人觉得你容易欺负，不要轻易放弃，不要随随便便付出，不要太老实，不要太老实，不要太弱。

不要让别人觉得你容易欺负，不要觉得你没原则。

不要让别人觉得你容易，不要让自己不舒服。一定要建立在自己舒服范围内，不要忍受，不要难受，不要不爽。所以这也涉及到一个边界的问题。在单位考虑问题，权衡利弊的落脚点都在利益的时候，你才是真正的成熟。

老实人开窍的标志四：敢于拒绝，善于拒绝

在体制内，你可以老实，但是一定要聪明。我们经常会遇到这样的情况：领导和同事把额外的工作交给你。比起属于你分工的工作交给你，你本身分工的工作已经不堪重负了。比如同事可能会帮你写材料、帮忙整理档案、帮忙填报，或者帮你忙一些数据录入等。那么如果你每次都答应，自己累得死，也不敢拒绝。假如哪天你工作比较忙了，你拒绝，对方还会生气，好像你帮他的忙是天经地义的事情，好像你不帮他就欠了事一样。

有一句话叫作“积水石成斗米”，用在帮你忙这件事情上也是如此。有人你平时不帮他，但是偶尔帮他一次，他会很感谢你；如果是每次都叫你帮，都答应了，有一次没有回答他就会后悔。所以平时高冷一点，偶尔伸出手，别人才会感激。

好人没有什么好，坏人也没有那么坏。只是坏人做了一好事，似乎就有值得原谅的理由；而好人只要做了一坏事，往往就没了原谅的余地。生活中很多事情都是这样的，借钱也是一样的。偶尔借钱给别人，别人会很感谢；但是如果没有钱用，他就找你，你每次都给，只要有一次不给他就觉得你是欠他的。人性就是这样，容易得到的东西没有人珍惜，我们每个人都一样。

有些人会选择做好人，轻易拒绝别人的请求，也不敢表达自己的想法和意见。这种做法不仅让自己很累，而且可能让自己失去原则和底线。同时，也不要随随便便帮助别人，有时候你越是愿意帮助一个人，你的真心就越显得廉价。你一旦帮助别人了，别人的工作就成了你了；或者你帮忙了，好处是别人的，一旦出现问题了，就会惹你说是你的问题，费力不讨，没有必要。

面对不合理要求的时候，我们必须学会拒绝，因为学会拒绝才是成为一个成熟职场人的开始。学会拒绝，你才会有气场。不会拒绝人的只能给人一种唯诺诺的形象，给人一种好人受气包的形象。学会拒绝，你才有魅力。有时候没脾气的人是没有魅力的。

当然这个拒绝不需要直接说，拒绝的时候态度要好，最好是调侃式的、微笑式的拒绝，化解尴尬。不要太老实，不要太弱，不要太老实。
