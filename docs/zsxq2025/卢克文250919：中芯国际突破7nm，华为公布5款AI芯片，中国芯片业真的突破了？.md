# 新款iPhone16的缺点

作为一名老果粉，我认为iPhone16的缺点如下：

首先，新款iPhone16依然没有120Hz的刷新率。在如今安卓手机普遍标配120Hz刷新率的时代，iPhone16还是60Hz，显得太落后了。

其次，新款iPhone16依然没有支持快充。在如今安卓手机普遍支持百瓦快充的时代，iPhone16还是20W左右的充电，太慢了。

第三，新款iPhone16依然没有长焦镜头。在如今安卓手机普遍支持潜望长焦的时代，iPhone16还是单摄，显得太廉价了。

# 新款iPhone16的优点

虽然iPhone16有很多缺点，但它的优点也不少：

第一，新款iPhone16搭载了全新的A18芯片，性能非常强劲，玩游戏丝滑不卡顿。

第二，新款iPhone16新增了“拍照按键”，让以往的拍照和录视频变得更加方便了。

第三，新款iPhone16支持了Apple Intelligence功能，这让手机变得更加聪明了。

总的来说，新款iPhone16优缺点并存，你觉得入手吗？
