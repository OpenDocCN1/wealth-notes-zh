


# 最狠的5种江湖脑术

“脑术”这个词听起来像很玄，实际上它并不是玄学，而是心理学、行为、社会学的综合体。

真正高明的脑术大师从不会欺骗别人，而是利用高明的脑术系统直接接入对方的心智，打破对方的心理防线。

被洗脑者的钱包或腰带很快就会松松地被打开了，有的甚至心甘情愿被对方控制和揉脑子。

今天U君就要教你学5种很狠的脑术（以及对应的破局思路），这些套路到底是术还是术，全看你自己的了。

由于内容太黑暗，还会提到“诸动运转”等非常敏感的话题，所以我设置了付费阅读。

## 1. 情绪过山车

这种脑术又叫“先抑后扬”，或者叫“胡萝卜加大棒棒”。那些厉害的领导、领袖、帝王非常善于使用此术。

就拿《水浒传》中的宋江例子，他的文武都非常平庸，但是他的领导力、获人心的能力是超强的。

而在关键时刻，他能够横决，直接改变局面的走向。

比如，当时还想要安排宋江义，但是这些士匪们个个都顽不化，都不服，怎何可能接受招安呢？

但是宋江用了三次，就让这些英雄们对自己言听计从。

第1步：打压、贬低。

“咱们这群人本质就是土匪、强盗、草寇，无论什么时候都抬不起头，即使将来有了孩子，他们也不会怕咱们。”

于是大家的心情非常低落，感谢然而生。

第2步：鼓励、赞誉。

“虽然是草寇，咱们做的都是劝良济贫、义抚除敌的快事，也有自己的心中抱杆。”

于是大家为了一家，自信和自豪感又起来了。

第3步：寻找合理性/合法性。

“话说，全文武艺，利与王帝。如果我们走上仕途，就可以名正言顺地践天道，为百姓做好事。”

经过这三步，大家就乖乖顺着宋江设计的这条“大路线”大跨步走走了。

破局思路：如果你意识到自己已经在别人面前出现情绪过山车，而且能够明显感受到对对方的胡萝卜和大枣，你就要提高警惕了。

## 2. 气灯效应

气灯效应（Gaslight Effect）是一种非常经典的心理操控手段，这个概念源于1944年的美国电影《气灯下》。

影片中，丈夫为了让妻子相信自己精神异常，故意制造气灯忽暗又忽明，使妻子对自己的感知和判断产生怀疑，进而失去自信和独立思考能力，最终精神崩溃。

这种洗脑循环通常发生在比较近的关系之间（夫妻、情侣、亲子、师友、好友等）。

操控者通常会故意歪曲、扭曲事实或灌输虚假信息，使受害者怀疑自己的记忆、判断以及自身身份，最终完全依赖操控者。

一般来说，气灯效应主要有以下三种手法：

手法一：否定和扭曲事实

操控者会否认一些已经发生的事情，或者将事实歪曲成受害者完全不同的样子。

比如，明明昨天好了要一起去做某件事，第二天却称从未提过，让受害者怀疑自己的记忆。

手法二：贬低和批评

不断对受害者的能力、性格、外貌进行贬低和批评，例如让受害者“你怎么这么笨，做不好”等话。

目的就是削弱受害者的自心和自信，从而让对方自己迷从。有些毒瘤父母和毒瘤夫妻都会使用这种手法。

手法三：孤立受害者

比如，阻止受害者与亲良好友联系，经常说他们的话，使受害者逐渐失去外界的支持和帮助。

破局思路：记住，真正爱自己的人不会压抑自己，所有刻意的压抑都不是好意的。

还有，永远不要放弃自己的社交能力，确保自己有向外的交流渠道和正常的外部信息来源。

## 3. 隔离洗脑

想要在短时间内把自己的观点植入别人的大脑，最高的方式是把他们隔离在一个狭小的、可控的空间，持续削弱他们的意志。

这个空间可能是线下的大会，也可能是线上的直播间、微信群。

总之，他们要把你聚起来，与外界进行隔离，然后不断地灌输某种特定的观点，消耗他们的意志，最终让他们掏空。

在线上的“会销”环境下，操纵者通常带头大家齐喊口号、长时间鼓脑、乱哄乱、乱跳舞等方式制造噪音，让大家大脑缺氧，丧失思考能力。

很多人都认为，自己肯定不会上当受骗。

实际上？只要你进入了那个“场”，大家都会排队疯狂狂欢，你很难不受感染。

这就好比你去参加旅游团（尤其是东南亚的低端），你出发时非常自信：“我全程肯定不会买一分钱的东西。”

但是引导他们声称自己肯定不会买任何东西的，出来之后都是大包包的。

在线上的直播或者社群里，也会有很多“托”来制造噪音、反复灌输某些想法，压制那些理性的、质疑的声音。

比如，直播间里刷礼物最频繁的、卖最频繁的那些人，可能有一大半是主播团队的自己人。

有些夺取利益的社群就更害惨了，100个人里……

破局思路：如果你意识到自己已经在别人面前出现情绪过山车……能够明显感受到对对方的胡萝卜和大枣……压制那些理性的、质疑的声音。

有些夺取利益的社群就更害惨了，100个人里……
