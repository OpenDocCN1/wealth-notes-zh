


# 突破4000点，要关注这些指标

来源：财富财经 2022年10月27日 12:21

4000点，所谓的支撑价格，其实非常关键。关键在于这些指标，目前已经关注到位了。

那么从今天的这些指标来看，指数依然疲弱，但指数并没有出现大跌，跌破5000点的概率并不大。

可以关注，下次4000点如何突破，目前已经关注到位，将看到胜利的信号了。

需要的。如果下疲弱的指数被破了，那么我们就有重光明之日了。

反过来想，要信心大一点。

长远来看，指数得触地回生。

从量能领跌的指标来看，有大反概率值得期待：

- 目前MACD指标显示背离倍率为161；
- RSI指标背离倍率为226。
- 均线指标也需要关注：这种背离的信号就足够了。
