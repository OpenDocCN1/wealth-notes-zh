


# 251106 鉴茶财富进阶-210 课:如何看市场风格的切换

其他国家的市场，基本只有一种风格，就是机构风格，大资金一线平铺，聚焦核心，不会玩买预期现实，也不会搞出各种诸构空丛，风格漂移，换季如换刀。

第一，大A的风格有三种

一种是主体机构的风格，主要以公募机构和私募机构为主，它们会搞出“主线”，为期数月的上涨，扩散；一种是生产队的风格，主要是汇金和险资，它们负责拉拉指数；一种是游资量化的风格，各种炒小炒差，牛鬼蛇神，概念乱飞。

散户很难参与生产队的风格，太慢浪顽，只能跟着机构风格挣钱，再游资量化的风格里基本是被割的结果。

第二，如何知道机构风格不行了呢？

主要的指标，是机构打造的龙头，开始涨不动了，市场的能量到了极限，无法再放大了。这时候因为抱团，市场风格极度偏移，基本是某个板块占到 40%，甚至45%，比年初的机器人，成交占比45%，21年的新能源，40%。

第三，如何知道游资量化风格开始盛行呢？

主要是业绩报告过后，主线品种审美疲劳，抱团瓦解，品种没有利润和增长的压力，开始横作浪。比来说，开始炒和谐梗，马字靠，福字靠，纯题材，打造跨年的十几个几十个连板的妖股等等。

第四，如何知道游资风格的衰落？

即它们打造的龙头和概念，直线式跌停，连续A杀。就拿现在的大 A 来说，就是马靠一体逻辑，它们打造的平坦发展，最终溃散，接不起来。炒平坦在大资金看来，是两岸动武，是局势紧张，资本天生追求确定性和稳定，一看这种架势，自然是跑路要，港股这种国际风格较多的地方，为你如此。

所以你看最近，平滞涨，恒生跌，平滞跌，恒生涨。

那么，风格怎么会切回主线呢？基本要同时满足下几个条件？按目前的情况是：

- 1, 拥挤度发生了一定变化，筹码充分交换。
- 2, 市场极缩量到1.7万亿左右，即高峰期3.5万亿的50%左右。
- 3, 主线品种开始走修复路线，而且自身是放量的，大盘是放量的。
- 4, 目前大盘牛市的标准是成交量2.5万亿。
- 5, 核心的妖股连续几个停跌且无资金去抄底和拉起，炒小炒差的风格被市场摒弃。

最后要跟大家的是，普通人只能在机构打造的主线，尤其是主线的核心品种里获利，且ETF比个股更稳，不要试图在不同风格里切切去，只适合在一种风格里走到到底。
