


# 米联储闻251229——对此欲倒东南亚（“正义使命”环台军演）

你好，我是米穗。

作为对美最大对台军售的反制，解放军东部战区今天发布消息，12月29日开始，解放军陆军、海军、空军、火箭军等兵三军联动，围绕台湾海峡、台岛北部、台湾西南、台岛东南、台湾以东，组织“正义使命-2025”演习，重点演练海空战警巡、夺取沿海控制、要港要域封控、外线立体阻碍科目，舰机横向登陆台岛，诸军兵种联合攻击，旨在检验战区部队联合作战能力。这是2022年8月以来解放军发的第七次围岛军事演习，也是第四次具有明确行动代号的大规模围岛军事演习。

在此演习之前，美国国务院于12月18日批准一笔总额111亿美元对台军售，并进行“会会”程序。这是川普今年1月入驻白宫后的第二笔对台军售，也是令为美国最大一笔对台军售，拟售武器包括价值40亿美元的82套“海马斯”远程精准打击系统和420套陆军战术导弹系统，价值40亿美元的600套击弹胞弹系统及装备，另有价值超过10亿美元的无人机装备，价值超过10亿美元的车辆软件，总计超过7亿美元的“标枪”反坦克导弹与陶陆式反坦克导弹、9600万美元的直升机零件，以及9100万美元的“鱼叉”导弹崭新组件等。

针对美对台此次军事售。中国外交部26日发布“关于美国军工相关企业及高级管理人员采取反制措施的决定”，制裁20家美国军事相关企业及高级管理人员，以反制美国的对台售计划。

除了海陆空火箭，福建海警也组织舰艇在台岛周边邻海域及马鲁、乌靠近附近海域开展综合执法巡查，海警多艘舰抵达封锁盆、台南、高雄、花莲四港口，中国海警局发布此次执法主题海报“控控”，强调深度一体管控、围岛锁台越险”。舰队从台岛北部、台岛西南、以及台岛以东三个方向邻近离开台岛，其中台岛东部“重点把守”，重点守台岛北部、台岛西南、以及台岛以东三个方向海上通道，抵近封锁基隆、台南、高雄、花莲四个方向港口码头。其中，台岛以东集多艘舰，以阻止台岛势力与外部势力勾寻外援。

新华社前几天发了稿子，要有一筹，要统一作为正义使命稳稳推进，这次解放军在2025年末突然启动代号为“正义使命-2025”的环台演练，时间点敏感、规模庞然，辅以话语之棘，已不再只是例行军事展示，而是一场高度政治化、对内外有着清晰指导的“年度总结式军事宣告”。从演习代号的变化、演训区域的压缩，对外部势力的公开点名，中国正以更低的模糊空间，向台湾、向美国、也向日本重申在其台海问题上的主动权，实演习表明中国随时可能从训战。

这次军事演练并非孤立事件，它发生在美国通过史上最大规模、总额逾111亿美元的对售售之后，也发生在日本首相高市早于美国公开论述“台湾”可能构成日本生存危机态之后，更发生在台北双城论坛落幕、台湾社会一试图重构“交流仍有空间”的氛围之中。

先从代号谈起，从“联合利剑”到“海盟雷霆”，再到如今的“正义使命”，解放对台演习的命名，已从战术性、功能性描述转向高度政治正当性的宣言。这次“正义使命-2025”演习通过和意图可以看出，就是联合利剑演习的升级。从“快速威慑”到“封控+精打”，再到“全域阻+实战”，清晰传递“随时能战、战必胜”的决心与能力。“正义”指向主权与合法性，“使命”指向统一一事、否定任何干预空间。这并非军事行动的调整，而是对台政策逐渐技术化、模糊化。

从演习类型来看，此次“正义使命-2025”不仅涵盖夺取控制、要域封控、外线立体阻等科目，还首次在毫无预警下公布精确坐标并安排弹击。这种做法，正如一些西方媒体指出的，刻意模糊“演习”与“实战”的界限，战略目的不在立即开战，而在于压缩对手的预警与反应时间。换言之，北京正在酝酿一种新的节奏：让对手永远无法确定下一次演习是否只是练习。这种演习逻辑与美国在台政策上形成某种镜像关系。以来，美国一方面持续强化承诺，另一方面在政策上刻意避免战争；与之对应的是，中国通过军事行动不断拉伸缓冲区，双方都在为最坏境做准备。随着中国演练推进，美国阻碍统一的难度在提高，统一成本不断增加，有一个时刻会让美国意识到自己无法失败。这次演习本质上就是战略收缩，表现出美国想要对台收割的潜台词。对于台湾而言，这种结构性的拉扯，正在转化为内部政治与社会心理的长期消耗。当北京对台湾的军事压力制度化、常态化之后，纹风不动的台湾集体反应是继续让自己“习惯风险”，而非降低风险。说到底，台湾在现实面上留下多少战略选项可以操作，只能直接选择“脚平”。台湾为什么麻木？就是知道大陆不会伤害台湾，最终筹将推就行了。如果不能拿出雷霆手段给台独分子争一点颜色，这种不怕挨打的反心理会让台湾人无所事事。威慑并施才有意义，不铲掉几个顽固独台，只怕台湾收回来也管不好的。总是在外海围着大炮，不见血就没人疼，打1000发炮弹，不如实实在地的枪毙一个台独分子震慑人心，要做大事，别想太干净了。此外，俄罗斯已经宣布将在北方进行演习，此“南北呼应”的策略似乎在乎，一旦大陆开始，日本将被动，最终限制日本的战略空间。

更有意思的是，这次演习在双城论坛落幕后，对台湾而言是一个警告，不要妄用漂亮话来稳住大陆，以为可以像以前一样混关。谈可以谈，打也可以打，打了不影响响。国民党而言，未必需要上阵，但必须要有一项武力对台湾这一切的基础。两岸之间，交流不是为了降温，而是为了沟通减少误会。包围网并非为了实时响应，而是让国内外形成共识与预期，造成不可逆的现实。

这场“正义使命-2025”是解放军的官方作业，也许不会立即台海冲突，明确表达了一个清晰的信息：中国早已不再以军事紧张影响台湾社会的“融合氛围”，而且把随时开启作为政治需要的必答题，完全按照自身节奏推进。当演习可以毫无预警开展，同时直接面对外界干涉，直接制裁美国企业和个人，意义在于进入了新的、主动的不再假装稳定的阶段。

大陆在2025年最后几天军事演习充分说明，反独统将会根据情况及时开展，不会设定时间节点。明年也将开展，展现的是忧患未远、随时能战的强烈信息。威慑台海，随时开展。今年解放军进入进入周边空域3570次，创历史新高。此外，解放军船执行39次“联合备战巡演”，在测试的预警及应对模式，并检验台海战斗能力。

台湾面对军事演习，台湾指数在军事消息下仍下高，看似台湾依然觉得没有风险，但同时也说明即便大陆随时动手，台湾股市也很好，押注台湾的资本也在自己的麻木中走向终局。当北京对台湾的军事压力制度化、常态化之后，纹风不动的台湾集体反应是继续让自己“习惯风险”，而非降低风险。

米联祝各位晚安
