


# 管理水平是目前制约兔子发展最大的短板

猫哥原创

## (兔子=中国)

这个标题有点反常识，今天就给大家聊一聊。

这两年经济大环境不好，很多人失业，失业之后就想找点事情做，很多人就选择做餐饮，毕竟餐饮看起来是门槛最低的。

但是门槛低并不代表做好，我不说很多餐饮小白创业碰得头破血流的故事，讲一个餐饮老玩家走的故事。

我家楼下有一个餐馆，叫徐徐记，这是餐饮做了十年的老字号，重庆都有几十家连锁店，在过去几十年时间，其每一家连锁店绝大多数时间都是盈利的，属于不折不扣餐饮界的资深玩家。

今年餐饮形势特别恶劣，覆巢之下必有亡卵，对于定位做中高端餐饮的馆子冲击特别大，所以现在的餐饮企业都在想办法转型破圈。

徐徐记也不例外，因为日常生活实在太差，所以我我家楼下这家也想转型，转型做什么呢？

做盒饭！

盒饭看起来好像像是餐饮做简单的赛道，一个定位中高端餐饮做盒饭是不是有点降维打击的感觉？

但是结果恰恰相反。

徐徐记在短视频平台投放大量广告，广告宣传的是每人19.9元，就可以在30种菜中随便吃，还有餐后的甜点。至于30个菜广告拍摄看起来都很有食欲，每个菜看上去都很好吃，毕竟徐徐记底色是做中高端餐饮，随便一个菜品拿出来至少从形象上比传统的盒饭菜品更有食欲。

但是结果却是一地鸡毛。

上来，瞬间秒光！中午可能去了300人，但是满能捡到菠菜的不到30%。

徐徐记做广告的时候根本就没预测到会多少人，估计就按照100人的菜品来配置，结果瞬间就来了300人，加上很多人不愿一起地抢好菜，实际只有60——70人得满意，其余200多人都是吃残羹冷炙，自然体验很差。

而后厨房，厨师炒菜手都炒酸了，也跟不上餐厅消耗的进度。

所以，做盒饭看上去很容易，其实难度很高，因为你根本就无法预测明天到店人数，人群又是在特定的时间点(11:30——12:30)涌入，如果你无法及时给人群提供足够的菜品，那么顾客的体验一定很差。

口碑一旦坏掉了，餐厅很难持续做下去了。

那么身边有没有做过中式快餐比较成功的案例呢？

有！

乡村基就是一个典型，乡村基在重庆起家，目前通过近三十年时间不断沉淀，目前已经发展成为国内最大最成熟的中式快餐品牌，全国连锁店超过1000家(没有达到这个数量级的快餐品牌就不要出来类比了，因为数量低一个维度根本就不是一个概念)。

我乡村基餐不管什么时候，不管什么门店，基本在5分钟以内就能拿到菜品，并且味道还好，就这一点秒杀市场上90%的快餐品牌。

那么乡村基效益怎么样呢？

说出来可能出大多数人的预料——这是一个沉淀30年的快餐品牌，一个经营模式非常成熟的餐饮企业，这是一家全国连锁超过1000家店的大型餐饮企业，但是它的效益很差。

列举2019—2022年乡村基利报的数据：

- 2019年营收：32.5亿，利润：0.8亿
- 2020年营收：31.1亿，利润：亏损242万
- 2021年营收：46.8亿，利润：1亿
- 2022年营收：47亿，利润：0.3亿

可以看出乡村基利润一直在0.6%——2%左右徘徊，我们取中间值，大致净利润也就是1%左右，如此低的利润简直比制造业还悲催，1%左右的利润率管理稍微松懈一点就是亏损。

一个三十年的成熟品牌都是如此，所以我们是不可以得出一个结论，快餐看起来很容易，但是要做大门槛难度极高？

我们来看看肯德基兔子区的数据。

2022年，肯德基兔子门店数量大致是9000个，也就是乡村基的9倍，当年营收是72亿美元，换算成人民币接近500亿人民币，而年的利润是7.87亿美元，换算成人民币55亿人民币。净利润大致是11%。

2024年，肯德基兔子门店数量大致是1.1万个，当年营收是85亿美元，利润是11.92亿美元，净利润大致是14%。

现在我们心自问两个问题：

同样是快餐，乡村基与肯德基相比理论上哪一个覆盖人群更多？哪一个更适合人口口味与习惯？

答案毫不无悬念应该是乡村基。

但是结果却是，肯德基门店比乡村基大10倍(意味着肯德基下沉市场更小)，单店营收每年是540万人民币(2024年数据)，或者560万人民币(2022年数据)，对应乡村基2022年单店营收只有420万。
