


# 米联储见闻251208——小白鸿于吾吾（解读新版《美国国家安全战略》）

你好，我是米堵。

这个周末真是刺激，中国的战斗机雷达锁定了日本，美国则发布了最新版的《国家安全战略》（National Security Strategy, NSS），一方面是日本的剑拔弩张，一边是美国的假意收敛。和拜登代的战略文件相比，这份战略的文本大幅减少，从头到尾只有 33 页，方向更是 180 度的扭转，在积极拥抱俄罗斯的同时，对欧洲的战略意识形态和军事、外交、移民等政策横加指责，甚至羞辱性地把欧洲推到单独与俄罗斯相煽，并将乌克兰作为重塑美欧关系的牺牲品。

针对欧洲多国政府对欧洲右翼的打压，新版《国家安全战略》声称欧洲面对面临被抹除的严峻前景，强调美国政府需要扶持价值观一致的欧洲极右党派，并未批贬：川普政府与欧洲官员存在分歧——这些官员依托不稳定的少数派政府，对（乌克兰）战争却有不切实际的期望，其中许多政府踏民主基本原则，压制反对声音。

但文件强调欧洲对美国仍然具有重要的战略意义和文化意义，跨越大西洋关系仍然是全球经济和美国繁荣的支撑之一，美国的目标应该是帮助欧洲正当当前的发展轨迹。在美国看来，欧洲和俄罗斯的关系严重恶化，已经不符合美国的战略利益，所以美国需要进行大量外交斡旋以重建欧亚大陆的战略稳定，降低俄罗斯与欧洲发生冲突的风险，重建与俄罗斯的战略稳定。值得一提的是，文件强调“终结北约不断扩张的印象，并防止其成为现实”，相当于美国彻底将俄罗斯从战略威胁的绞架上取了下来，这是美国政府明确将战争起因和俄罗斯与欧洲的冲突方面归因于北约的不扩张行为。

新版战略对北约扩容，并提到一个非常敏感的观点：最近几十年来，某些北约成员国可能成为非欧洲人占多数的国家。因此，这些国家是否会像签署了《北大西洋公约》的国家那样看待自己的国际地位，以及与美国的联盟关系，仍然是一个悬而未决的问题。也就是说，对于北约当初建立的根基和当下的现实发出了质疑，这份文件要求欧洲承担更多的防御职能，增加军费投入，否则美国可能在 2027 年退出北约。

川普第二任期上任后，开始战略收缩，回归俄罗斯主义，从谋求全球霸变为巩固在西方的霸权，对其最传统的后花园拉美洲大陆聚焦，在该区域加强与主要竞争对手对关键战略资源的争夺，并打击区域内的挑战者如委内瑞拉等，并与此同时重构俄罗斯的工业能力。新版《国家安全战略》也鲜明体现了这一点，用了相当多的篇幅关注半球、拉丁美洲、加勒比地区和其他其他美国军事的。

文件认为极端的全球主义和自由贸易掏空了美国中产和工业基础，把美国拖入了和自己无关的战争，让美国追逐切实际的目标，并且亲手摧毁了美国的根基——强大经济和工业基础、美国中产阶级国民的自信。所以美国必须在全球范围内做出艰难抉择：冷战结束后，美国外交政策精英们坚信，美国对全球的永久主导符合美国最大利益。然而，只有其他国家的行为威胁到我们的利益时，其事才与我们相关。

对于美国非常强调在亚洲、中东的利益，这份文件强调美国必须在西半球保持主地位，这是美国安全和繁荣的前提。这些与美国相关的利益包括：向西半球大幅部署更多美国军事力量；采取多项措施减少美国移民；推动美国建立更强大的工业基础；扬美国本土（包括欧洲）；恢复和振兴美国的精神和文化健康，让越多的强大的、传统的家庭来养育健康的孩子，以及一个视昔日辉煌和英雄的美国等。文件指出美国必须与拉丁洲各国政府的关系，包括合作识别资源，加强政府与私营部门的合作，为美国企业在该地区创造战略和投资机会。

在将重点转向拉丁洲的同时，对于印太平洋，文件承认亚太和中国的重要性，承诺重新平衡美国与中国的经济关系，优先考虑互惠和公平，以恢复美国的经济独立性，誓言要“与中国保持真正的经济关系”。与此同时，文件又表示“中国的贸易保持平衡，聚焦于非敏感领域”。

我们一直在强调一个认知，就是对美国来说，打不赢的对手是朋友，这是刻在美国人的外交认知。这份文件和川第一期及拜登政府的国安战略相比，对中国仍然保持警惕，认为是美国的战略错误在中国过去十年的战略机会机，让中美原本不平衡的关系变成了相互类似的 G2 集团，对中国仍要战略遏制，认为以后美国不能超越。但对中国的定位从未来是最危险的系统性竞争对手，悄然成为主要是经济等领域的竞争者。这是什么？这是打不过就暂时放不下，不是美国不想打中国，而是美国意识到现阶段打中国是不切实际的幻想，而且秉持这一目标会阻碍美国重建自己的血肉，所以美国还需要吸光养肥，甚至卧薪尝胆，寻找机会重塑自己的血肉。

文件围绕台湾问题提到两点：一是台湾半导体产业，二是台湾处于岛链的关键节点。总体而言，与其攻击性描述相比，这份文件对台湾并未持有攻击性承诺，反而侧重于如何平衡美国在台湾关系中的利益，力求避免直接冲突。显然，川普政府认为台湾不是美国的核心利益，而是必然在与中国发生冲突的情况下，美国的一个底线。相对于过去，美国总要主导，现在的美国要做个渔翁得绰有余。

总体而言，新版报告在内容架构、核心目标与路径方面做了重大调整，以美国安全为主线，凸显了“美国优先”的政治导向。旧版报告的核心逻辑是维持全球主导地位，通过强化盟友体系、拓展影响力、在全球遏制竞争对手，延续了冷战后期的干预模式。而新版报告彻底颠覆了这一思路，美国将利益放在首位，明确边界安全、移民管控、打击跨国犯罪是优先事项。要求进一步加强贸易、保障供应链、再工业化等方式确保经济安全。这意味着门罗主义成为美国的核心指导思想。门罗主义是美国扩张主义，试图将南部美洲造成无法影响到的后花园。写入《国家安全战略》，标志着美国实质转向孤立主义。不得不说，这份文件再次体现了美国人的务实精神。民主党认为民意永远愿承担与国家利益无关的全球责任，他们高估了美国同时资助一个庞大的福利监管国家以及一个巨大的军事、外交、情报和外援的能力。他们押上了巨大且具有破坏性的赌注，支持全球主义和所谓的自由贸易，结果掏空了美国经济和军事优势所依赖的中产阶级和工业基础。他们允许盟友和伙伴将自己的防务成本转给美国，有时将我们卷入冲突中。总结一句话：美国学会放自己，少管闲事。那么问题来了，是什么让美国开始觉得管事吃力不好了？为什么过去美国可以从全球获益，而现在不再了？就是分工这件事分岔了，没控好盘，最后把自己丢出去才能维持全球节奏。这70年来，美国并不是基于价值看待全球警察，满世界狼焰，到处拨乱，一手从乱中挣资源，一手收保护费来维持美国霸权地位的稳固。好得太容易了，让人开始只想靠歪道搞钱，却把最基础的衣食住行根源通路掉了。贪婪和懒惰是一切系统性崩溃的根源，但人类进化千年，谁也曾挣扎这两条基因里的病根。到底，万事万物皆有周期，能随周期波动兴迭的文明不死。别轻言跳出历史的周期，如同树木哪怕经历枯绝也不会妄言要四季常青，新陈代谢，周而复始，才是自然铁律，只能敬畏。
