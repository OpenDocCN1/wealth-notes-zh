

# 开启人民币国际化的时代

发布时间：2025年9月2日

印度伊朗高调参加会，
俄罗斯朝鲜高规格出席阅兵，
驱动他们的不仅仅是美国的政治压力与谈判，
也有从中国方面获取的巨大经济利益。

随着美国两党的权力更迭，
美元从美国流向全球的拜登模式结束了，
美元从全球流向美国的特朗普时代开始了，
就像兽世界中的血精灵对魔法的冯纳那样，
许多国家都需要找到一种货币来缓解他们对美国的强依赖，

于是，他们都将目光转向了中国，
希望获得中国的国家替代美国的跨国资本投资。

解决外汇尴尬问题可以，但也支持相应的筹码，
拿了中国的投资，就需要接受人民币支付的代价，
于是拜登准停止的人民币国际化又要重新启动，政府布局人民币出海的马云也得以重新重视，
但一轮出海的不是马云，会变成离岸人民币稳定币。

具体的模式，在上轮国家经济周期和这一年来已经展示过，
可以把这些这些国家视为中央政府的鸦鹺统治区，

北京的中央政府出钱给他们搞“两重两新”，
也可以通俗的理解为咱们出钱给这些地区“国补”，

这个时候一定要有中国版的阿里、美团、京东来接“国补”，
让这些国家熟悉使用离岸人民币稳定币来生意的，

等到特朗普本届卸任的时候，
人民币稳定币或许就有能力再次挑战巴塞尔老妇人了。

## 延伸阅读

### 【鸦鹺】

来源：百度百科

> 《史记·司马如传·安隐》解释说：“鸭，马蹄头也；策，牛蹄也”，引申为笼辖控制。汉、唐、宋、武、明、清诸侯对承认土地领头目，封以王侯或许以厚禄，纳入朝廷管理的制度。

所谓“鸦鹺”，就是一方面用“鸦鹺”，用军事手段和政治压力加以控制；另一方面用“鸦鹺”，以经济和物质的利益给予抚绥。

来，一起认识“两新”、“两重”政策！
来源：求是网 2024年11月14日

所谓“两新”，是指推动新一轮大规模设备更新和消费品以旧换新。2024年3月，国务院印发《推动大规模设备更新和消费品以旧换新行动方案》。

所谓“两重”，是指国家重大战略实施和重点领域安全能力建设。发行长期特别国债支持“两重”建设，是实施一揽子增量政策推动经济高质量发展的一项重大举措。
