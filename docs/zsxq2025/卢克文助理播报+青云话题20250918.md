


# 【助理播报】

国际：

1.当地时间9月17日，美联储最新的联储公开市场委员会货币政策会议纪要显示，美联储决定将联邦基金利率目标区间下调25个基点，至4.00%–4.25%之间。

2.当地时间17日，沙特阿拉伯与巴基斯坦签署了一项防御协议，协议规定任何对其中一国的攻击将被视为双方的攻击。

3.财联社9月18日电，特斯拉设计总监接受采访表示，特斯拉正重新设计其他受安全争议的车门把手系统。新设计旨在让乘客在“紧急情况下”更直观地操作车门。

4.据菲律宾媒体报道，菲律宾众议院议长马丁·罗穆亚尔德斯因卷入腐败丑闻于17日宣布辞职。众议员福斯诺莫·李当选举为众议长。

5.卡卡塔尔外外交大臣胡莱菲当地时间9月17日访问位于荷兰的国际刑事法院，探讨根据国际法对以色列袭击加多哈事件作出法律回应。

6.泰国国家经济和社会发展委员会17日公布了 2024年泰国贫困与不平等状况报告。报告显示，贫困人口已增加至343万人，占全国人口的4.89%。

国内：

7.今天（18日）起，电影《731》将在全球多地上上映。据网络平台数据，截至9月17日20时08分，该片首日预售票房突破1亿元，也是今年春节后首部首日预售票房破亿影片。

8.9月17日，工信部就《智能联网汽车组合驾驶辅助系统安全要求》强制性国家标准向社会公开征求意见。
