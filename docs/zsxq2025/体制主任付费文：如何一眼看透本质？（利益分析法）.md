


# 如何看懂别人（利益分析）

作者：刘杨 日期：2022年06月15日

## 核心

我们平时看人，其实看的是对方的付出的交换。本质上，就是看透其背后的利益分析。

在社会上看人，其实只有一点，就是看透他的利益。任何行为，都是利益驱动的。所以你要问自己：对方是想要利益，还是想要情感？

- 这样做是为了利益，还是为了爱？
- 这件事背后的逻辑是什么
- 他在保护什么？

为什么我们要看利益？

因为利益分析是最客观的，不需要考虑感情。想看透一个人，就先看他的利益诉求。看清了他的利益分析，你就能看穿他背后的伪装。

我觉得这个方法太残酷了，很多学生不接受。但是，世界就是残酷的，很多关系本质上都是利益的交换。

所以通过利益分析，可以更清晰地看到本质。虽然这种方法很冷酷，但是它是真实的。利益是人的最核心动机，也是社会运行的基石。

## 一、 如何分析他人的利益

分析一个人的利益，首先要看他的需求。你要想象一下，他想要什么？然后，根据他的需求，去推断他的利益诉求。

利益分析可以适用于任何领域。在生活中，我们与人交往的本质都是利益交换。那么，如何分析这种交换呢？

其次，看他的利益诉求是如何实现的。

以老板为例，老板需要员工，员工需要工资。这就是一个人的利益交换。老板提供工作机会，员工提供时间、劳动，以此换取工资作为报酬。

这种利益交换的本质是双方互利的。如果老板不赚钱，员工也拿不到工资，这种关系就无法持续。所以说，一个关系如果不是双方利益互利的，它就不会持续。

这个世界上很多关系是不互利的，只有一方在付出，一方在索取，这种关系很难持久。

## 二、 如何看清自己的利益

如果你想看清自己的利益，首先要问自己：我到底想要什么？

## 三、不要试图去毁掉你的环境，重要的是你自己，这等于一个高情商的问题

低庸的人是不愿意改变自己的环境，即使改变了环境也不会改变。我自己，比如我很多朋友告诉我，我身边的人在环境中都有各种特征，比如，他们告诉我要尝试去改变一个环境，这样就很重要了。

我认为，如果你身边的是5个平庸的人，那么你体内的东西也就改变了。

但是也是，如果你身边的人是平庸的，你为什么要去改变环境？这也是一种方法，办法就是改变你身边的人，通过结交优秀的人来替代普通的人。

所以如果你觉得你周围的人很不好，你为什么要去改变环境呢？因为你身边的人变优秀了，那么你周围的环境也就随之改变了。

但如果你觉得你周围的人很优秀，那么你为什么要去改变你周围的人呢？

所以如果你觉得你周围的人很优秀，那么你为什么要去改变环境呢？因为你周围的人优秀了，那么你周围的环境也就随之改变了。

那么，如果你在目前的环境中不舒服，你该怎么办呢？你唯一的办法就是改变你自己。

如果你在目前的环境中不舒服，那么你就要去改变环境。

但是，如果你在目前的环境中很舒服，该怎么办？

那么你就不需要改变环境，继续留在现在的环境好了了。

## 四、用运营战略来适应环境

在我们的环境中，我们要学会适应环境。无论环境多么糟糕，我们要学会去适应它。

如果你不适应环境，你会被环境所吞噬。
