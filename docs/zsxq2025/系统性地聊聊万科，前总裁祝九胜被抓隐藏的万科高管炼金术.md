


# 系统性地聊万科，总裁祝九胜被抓擒

## 藏的万科高管炼金术

为什么要聊万科呢？因为前阵子万科的新董事长，也就是深圳地铁的董事长被抓了，万科的前任总裁祝九胜也被带走了。这些事件似乎在告诉我们，万科的雷，没人兜了。

那么万科到底欠了多少钱？这钱又是怎么欠下的？深圳地铁一年给万科输血十几次，现在董事长被抓了，这是不是意味着，深圳国资委误判了万科的债务情况，以至于现在才发现，自己根本无力救起万科呢？今天咱们试着找找到这些问题的答案。

想知道万科到底欠了多少债，这债又是怎么欠下的，那我们必须从前任总裁祝九胜开始起，因为他就是万科的金融操盘手。祝九胜今年56岁，毕业于中南财经法大学，拥有经济学专业背景，早期在建行工作了19年，一路从福田支行副行长升到深圳分行副行长。

2007年和2009年，祝九胜两度向万科提供了合计700亿元的意向授信额度。可见在建行时期的祝九胜，就已经和万科关系异常亲厚。所以2012年，他顺势加入万科，用他的专业能力，把万科变成了一台金融操作极其精密的资金机器。说成人白话就是，是在当时，如果一家地产公司拥有了来自顶级金融系统的顶级专业操盘手，那绝对能把杠杆玩花来。

万科和恒大不同，恒大的手段相当简单粗暴，无非就是非法集资、压榨供应商那一套暴发户手段。而万科的资本术，就连万科自己财务部门的人都没几个了解。

祝九胜到底是怎么玩的？2025年1月16日，市场传言祝九胜配合公安机关调查被带走。1月17日凌晨，祝九胜更新了微信朋友圈来辟谣，但实际上，此后祝九胜一直被监视居住。而之所以不把他抓走，是因为深圳国资委万科的债务根本理不清，祝九胜搭建的金融网络实在太复杂了，所以他们需要祝九胜配合了大半年。

现在祝九胜正式被抓，那么接下来，我们还原一下祝九胜的金融操盘术。

祝九胜加入万科以后，一共是搭了3条输血管道，目的是把万科变成一台能靠资金循环、自我运转的高效金融机器。而这三条输血管道连接着一根主动脉，就是万科企业股中心，他是祝九胜为万科打造的整个金融体系的心脏。

## 时间倒回到世纪80年代

那时候王石刚把万科推向股份制改革，当时的理念还挺先进：创始人和员工大家都不拿股份，把股份统一放在一个公共账户里。这个账户就是后来的万科企业股，相当于是一个内部分红基金，不上市流通但能分红。

后来祝九胜来到万科，一看到这玩意，眼睛都亮了。这个万科企业股票账户有钱，又不在上市公司的报表里，这不是天然的影子金库吗？于是祝九胜就在万科内部干起了银行的老买卖。他让万科专门成立一个实体公司，全名万科企业资产管理中心，简称企业股中心，名义上是管理股，实际上可以体外运作的钱袋子。

祝九胜的计划是三步走：
- 第一步收钱：把多年积累的红利资金变现，形成一个亿亿的资金池。
- 第二步建网络：通过企业股中心去控股各种关联公司，打造白手套企业。
- 第三步搞自融：把企业股中心的钱借给万科。

不过为了让这套体系能够顺利运转，祝九胜先解决一个问题，那就是怎么让企业股中心顺利出圈。企业股中心本身是内部账户，钱不能直接流出上市公司体系，所以需要一个中间人。这个中间人就是万科会全资控股的上海万丰。祝九胜让企业股中心和上海万丰交叉持股，然后借助上海万丰的通道，把企业股中心的钱输送出去。

现在基础改造好了，那么接下来就是接上三根血管。第一条血管叫盈安合伙，这条血管连接的是员工的奖金分红。2014年初，王石在万科内部正式推行事业合伙人制度，并启动股权激励作为配套措施之一。所以盈安合伙的成立，就是代表事业合伙人进行投资管理的。当时盈安合伙委托金鹏资管计划，在二级市场多次买入万科股票进行金融融资。

金融融资的劣后级资金就是万科事业合伙人滚存下来的经济利润奖励金，优先级资金来自银行理财。

此外，万科于1988年进行股份制改造，王石与创始团队其他人选择放弃名下股权。这批原始股后来演变成万科股票和相关资产，被王石打包通过德泰信计划引入机构，在二级市场增持万科股票。也就是金鹏和德泰信资管，是万科管理层藏底下的秘密。他们通过这种操作来扩大自己对万科股权的控制权，高度分散，没有实际控制人，这让王石特别疼。一旦遇到外部资本要收购万科，他们才会利用德泰信计划来保住。

## 2015年的股权之争

2015年，某些势力支持强势收购万科，把王石逼到了墙角。祝九胜突然宣布辞职，自然是触了红线。虽然祝九胜辞职，但他其实并没有离开万科，除了万科总裁以外，还有另一身份就是万科财务顾问董事长。这家公司名义上做万科投资咨询，由王石创立，后来在祝九胜手里变成了连接万科内外资金的第二根血管。

2016年8月，祝九胜用万科财务顾问公司上海万丰出资数亿元，拿到万科20%的股份。而这家网贷平台母公司是金鹏所。有了这个PTO平台，祝九胜又可以开始表演了：他让金鹏所借钱给员工，让员工去投万科地产项目，比如借款利率是10%，而万科的地产项目收益又有20%，还能赚差。祝九胜接着把这些贷款打包成PTO理财产品卖到社会，于是又从外部融了一笔钱。金鹏所不仅搞员工贷款，还给万科的一些关联公司做担保。

真相就是，万科找了白手套帮自己去金鹏所借钱，这属于典型的自融。到目前为止，金鹏所尚未付的理财产品规模还有8亿。其实金鹏所这件事还有一个最大的疑点，那就是当年祝九胜捞了多少业务手续费，又分给了多少万科高管，这个答案应该很快就会揭晓，只要看祝九胜之后谁被抓了。

刚才我们讲了祝九胜挂了两根血管：
- 第一根血管盈安合伙：连接的是万科内部的钱袋子。
- 第二根血管金鹏所：打通了PTO融资的渠道，吸收员工和社会资金。

那么第三根血管是什么呢？它的名字叫博商资，它的功能就是四个字：表外融资。博商资就是万科企业股中心借上海万丰的通道。

## 搭建起来的一家白手套公司

假如一个万科的项目公司要落地开发，就通过博商资成立合伙企业，找来几家金融机构比如招商基金、东方资产、光大信这些让他们出大头，博商出小头。明着是找金融公司入股，实则就是找他们借钱做项目，这是表外融资的常规玩法，叫“明股实债”。

祝九胜这样就可以借博商资管很小的钱，搅动巨大的金融资本，为万科的项目进行表外描述。博商资管注册资本与实缴资本均只有1亿人民币，但大杠杆后管理的资产规模却是千亿级别的。这也是为什么祝九胜被深圳国资委叫去对账足足对了半年，因为表外债真的是太多了。

2024年底，博商资管出现巨亏，高达数百亿人民币。财新独家披露，当时博商的高管就已经逃亡境外，至今仍然失联。这个人到底是谁，带走了多少秘密和资金都不知道，但他总是把没走的人都给害了。因为从那时开始，万科集团高管和一线公司负责人、关键岗位人员、以及部分已经离职的管理层都被控了。万科高管为了自救，干脆把企业中心的那批股份和资产一次性捐赠了清华大学教育基金会，从此万科企业股中心注销并停止运营。
