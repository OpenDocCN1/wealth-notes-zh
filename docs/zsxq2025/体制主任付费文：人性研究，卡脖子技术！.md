


# 人性，演技术？

作者：李涛 2022-09-29 11:50

前言
本文是为了让对人性感兴趣的读者，希望帮助大家更深入地了解人性。

文中的观点仅代表个人观点，不代表任何立场，人性非常复杂，难以定义，请大家在阅读时多加思考。

很多人认为人性是天生的，认为人天生是善良的，只有在环境恶化时，才会变得自私、伪装、伤害别人。很多人认为人性是演化技术，认为已经把人性的底色看透了。

从我的角度来看，人性是后天形成的。其实，没有所谓天生的善或恶，只有被环境造就的善或恶。环境好，人就善良；环境恶劣，人就自私。这就是所谓的人性演技术吗？

## 人性的两面

每个人都有人性的两面，每个人都有人性的阴暗和光明。善良、贪婪、恐惧、虚荣、自私、无私。

从自私的角度来看，自私是每个人的本能。为了自己的利益，甚至可以伤害别人的利益。但是，如果一个人完全自私，那么在社会中是无法生存的。

从无私的角度来看，无私不是人的本能，而是后天教育的结果。如果一个人完全无私，那么他会被别人欺负。

正是自私和无私的平衡，才成就了一个完整的人。只有理解了人性的这一面，我们才能更好地保护自己；也只有理解了人性的另一面，才能更好地去处世界。

贪婪，是人性的欲望。每个人都有贪婪，每个人对金钱、权力、名誉、爱情都贪婪的。但是，贪婪并不完全坏。如果没有贪婪，人类就没有进步的动力。如果没有贪婪，人类就不会去创造。但是，如果过度的贪婪，就会导致毁灭。

恐惧，是人性的本能。每个人都有恐惧，每个人对死亡、失败、被拒绝、孤独都恐惧。如果没有恐惧，人类就不会规避危险，就不会去规避风险。但是，过度的恐惧，会让人变得胆小，因为害怕失败而不敢尝试，错失机会。

虚荣，是人性的需求。每个人都有虚荣，每个人渴望被认可、被尊重、被关注。如果没有虚荣，人类就不会追求卓越。
