


# 小程序越做越麻烦了

最近，发现小程序变得有点麻烦了。
以前开发小程序，几小时内就能搞定；但现在开发小程序，感觉却越来越复杂了。

开发成本极低，但现在现在开发一个小程序，感觉比开发 App 还要麻烦了。

以前写小程序，几行代码就能搞定；现在写小程序，却要考虑各种奇形百怪的兼容问题。

![](img/120d6fa004e522c23311130c007189e7_0_0.png)

以前写小程序，几行代码就能搞定；现在如下：

```json
{
  "pages": [
    "pages/index/index"
  ],
  "window": {
    "navigationBarTitle": "首页"
  }
}
```

现在写小程序，却要写很多代码：

```json
{
  "config": {
    "apiBaseURL": "https://api.example.com",
    "s3FileDomain": "https://cdn.example.com"
  }
}
```

还有：

```json
{
  "components": {
    "my-header": "components/header/header"
  }
}
```

以前写一个子页面，几行配置就能搞定；现在还要写：

```json
{
  "subConfigs": [
    {
      "page": "pages/sub",
      "pages": ["pages/sub/detail"]
    }
  ]
}
```

以前写一个样式，几行代码就能搞定；现在还要写：

```css
.container {
  background-color: #f0f0f0;
  padding: 10px;
}
```

以前写一个逻辑，几行代码就能搞定；现在还要写：

```javascript
Page({
  onload: function(data) {
    console.log(data);
  }
});
```

写完一个页面，要好半天。

而且还没发布呢。

但是，最近我发现了 DeepSeek，发现没问题了！

由于 DeepSeek，我写小程序的速度快了一倍。
