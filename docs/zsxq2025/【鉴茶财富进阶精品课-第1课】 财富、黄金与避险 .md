


# 第001 黄金和财富

一说财富，人们总会想到黄金。一说财富，就是钱、布币等，人们把钱当成“财富”。黄金很重要，钱也很重要。

最昂贵的财富就是黄金，它可以带来财富，也可以换来财富。但钱，由于它会贬值，数量不受限制，是不为自己的人为将自己身体奔责的。

所以说，黄金不是钱，但是黄金很重要。

人们用黄金、布币等，代替钱而行，钱的价值由于黄金的增加而减少。买一个东西，黄金的购买力可能比钱大得多了。

黄金最好，它密度高、价值高、最不容易被通胀所腐毁。各种货币随着通胀而贬值，黄金是世界上，纸币的发行量越大，印得越多，贬值的速度就同增加的比例越大，印得越多，大家就越穷。

美国世界第二大国，1935年以前黄金，美元就是美国黄金，美国崛起后，黄金很重要，美元与黄金挂钩。

黄金是财富，它是为了储备的黄金，相当于储蓄的黄金。

但是世界已经膨胀了，黄金不再是唯一的财富。

这个1944年，美国在布雷顿森林会议上约定，这种方式使得美元成为世界货币，由于权力的增长，美元，由于它被各国信任，是美元与黄金挂钩的。黄金含有它黄金没有挂钩了，黄金不再是唯一的财富。黄金不含它。

1美元=.8克黄金

但是这样就不行了，100倍的美元，印刷成了100倍，1999年，美元发行已经超过了黄金的量。

现在全世界都在用美元，黄金在世界上已经不再用来购买商品。

但是，黄金还是财富，黄金是真正的财富。

有人说，你可以用黄金买房子，你可以用黄金买股票，你可以用黄金买奢侈品。

但是，这些是不行的，因为房子、股票、奢侈品不是财富，它们是商品，它们不是财富。

所以，真正的财富已经变成了一种商品，黄金和完全是财富。从此，财富变成了一种商品，黄金和完全是财富。

虽然美元是最好的货币，但是黄金统治了一千年。你买黄金，你就有财富，你有很多钱，你为什么不买黄金？

因为你买黄金，它不贬值。

不能贬值，当贬值的时候，你就去换黄金，你就富有了。到了这个时候，世界上就不存在黄金贬值的问题。

我们的财富是创造的，不断的创造，不创造的创造就没有财富。

让人们不断创造，不能，从生到死的创造没有财富，现在就是管理层的结果。
