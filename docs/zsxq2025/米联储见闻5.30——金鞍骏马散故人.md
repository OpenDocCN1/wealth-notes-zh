


# 米联储闻20250530——金鞍骏马散溃

![](img/03694d3ce76dd8ecc743aeb7bd14d40a_0_0.png)

最近，浙江金融圈真的是翻天覆地，天雷滚滚，人心惶惶。杭州前段时间日子借着DeepSeek的东风，猛赚了一把流量，一扫阿里云当年蚂蚁金服的阴霾，没想到不到半年，浙江金融圈平地起风云，四大行长全部下马，还没出问题的都战战兢兢，朱从褚已经被宣判多时，还在不断牵出大佬们，这一波到底要挖到什么程度才会收手？

5月28日凌晨，工行浙江省分行行长沈荣勤退休8年后被带走调查。退休八年后，是不是意味着参加过2015-2018年那波金融暴利活动，不过看他的教育背景和职业履历，也是金融圈的老人了。沈荣勤毕业于浙江金融职业学院，原证监会主席吕敏、中信银行董事长方英等都是他的校友。从一名普通员工到了工商银行山东分行长、浙江省分行长，业务水平毋庸置疑。2017年退休，当年7月，他成为钱塘江金研究院股份有限公司董事长、院长，这个金融研究院的校会有8大民营企业参与，比正泰集团、盾安集团等，所有人都称之为浙江金融版“泰山会”。说白了，民间企业资本借他与国家金融系统打通了一个连接点。

在沈出问题前一个月，4月25日，在银行工作超40年、曾担任农行浙江分行一把手的老行人冯建龙及四五位关系人被有关部门带走。5月7日，官方宣布冯涉嫌严重违纪违法，主动投案，目前正接受纪律审查和监察调查。冯建龙也已经超过退休年龄，现年63岁，曾在农业银行各地担任要员，湖南副行长、浙江副行长、审计局广州分局局长、重庆行长。2012年担任农业银行浙江分行代表人，2022年卸任法人，期间担任浙江农业银行首席专家、浙江分行党委书记、行长，浙江省银行协会会长。

以往推，今年4月22日，财通证券突发公告，公司收到第四届董事会独立董事高强先生家族通知，高强先生目前因个人原因无法履职。一周后，中纪委通报，建行浙江省分行党委书记、行长高强接受调查。根据市场分析，他或涉建行原副行长章更生案，章在接受调查五个月后本周被移交司法。

高强曾长期在建设银行系统工作，在安徽分行担任副行长，在山西分行担任行长，在浙江分行担任行长，也是退休后担任杭州万胜私募董事长，从2020年11月担任财通证券独立董事。在高强之前，另一个建行系的老银行人章更生去年11月落马。

再往前追溯就是去年4月底，中行浙江分行行长郭刚落马，他曾任甘肃省分行长、浙江省分行行长，2020年5月已经离职。此后经常以浙江省金融业促进协会会长的身份参加各类活动。去年12月通报，郭刚违规经商企业、持有非上市公司股份，亲属投资金融产品提供帮助；生活腐化，道德败坏；长期与不法商人沆瀣一气，退休后仍利熏熏，利用职务便利为他在信贷审批、矿产开发等等方面谋利，通过收受和低价购买房产、溢价转让股权等方式非法收受巨额财物；违反国家规定发放贷款等。

也就是从去年开始到现在，四大行浙江分行全部下马，而在四大行浙江分行长落马之前，浙江杭州银行和浙商银行多位高管早已相继落马。去年8月，浙商银行行长张荣及分行干部都被带走。张荣不仅是任浙商银行行长，同时兼任北京分行党委书记，此前还任广发银行分行，2017年加入浙商银行，随后进入江苏分行，在多地担任不同职务，如一把梭。浙江金融圈的特点，从一个人的履职轨迹看出金融关系网，因为涉及到最敏感的问题，所以越少越容易掩盖，常出现这种金融干部到处任，完美闭环。

浙江金融圈这一波落马潮，溯源到朱从骏。从朱的简历来看，他不过是高级打工仔，从1992年1月进入证监会、上海证券交易所任职近20年，2012年5月升浙江省长，主管国资和金融10年后，2022年6月辞任浙江省从主席。2014年加入了浙商银行，其中沈仁康、刘龙同期加入浙商银行，融资方面的关键人物。沈仁康和刘龙在2014年前加入了浙商银行，一个任衢州审计局、衢州副书记，一个任衢州行长，浙江商银行的之一。

浙商银行在2014年8月正式开业，当时是全国第13家“A+”上市银行。去年8月地震，除了行长张荣，还有很多分行干部被带走。

对于朱从骏落马，媒体分析的第一印象是朱是典型的道口金融队，职业简历跟李几乎没有交集，所谓老乡关系更是扯淡，全是外面的操作手法，让人感受到一股无赖的感觉，毕竟朱很喜欢借外网搅浑水。朱落马后，突然爆出一堆文章，说进去了很多人，随之落马的至少有刘敏、王青山、李格平、郭树强、王亚伟；证监会评审处处长杨红、证监会发行部主任李俊强、发行监管审核一处处长张军、审核三处、审核五处处长，以及吴国焰，以及证券监督委员会党委、副主席王建军。朱和王建军工作也有交集。2008年王建军担任证监会办公厅副主任，彼时朱成为证监会主席助理、发行监管主任。这次落马的四大行浙江分行长：郭刚（2014年至2020年任浙江分行长）、高强（2015年至2020年掌管建行浙江分行长）、冯建龙（2012年至2022一直是农行浙江分行法人）、沈荣勤（2011年至2017年掌舵工行浙江分行行长），均为朱2012年5月奔赴浙江担任省长期间培养提拔起的。

除了沈，细数近一个月来浙江金融系统中落马的官员数量足以让人震惊。5月16日，浙江省委金融办原主任、省委金融工委原委员、省地方金融局原副局长潘恩落马；5月14日，工商银行杭州金融研修院原党委书记、院长蒋伟落马。蒋伟在2007年就担任绍兴分行长，2013年升任工商银行陕西分行副行长兼营业部与现金管理总部总经理，2016年底担任工商银行天津分行长，后来就到了浙江。加上连续落马的几个行长，对于驻浙江金融系统不到两个月的中央巡视组来说，工作量可不不少。如此短时间高频次，可见巡视组是带着重点名单来的，这或许可以解释为一直以来为霸道强势的冯建龙最终选择主动投案，估计也是看清楚楚在劫难逃，不如坦白从宽了。
