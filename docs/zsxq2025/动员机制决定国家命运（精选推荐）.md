


## 动员机制决定国家命运（大佬文圈精选推荐）

首先说明，本文大概率会让小清新患者以及唯民主论者，非常的不开心。因为本文将使用非常冷酷的语调讲述全球的政治和经济演变，到今时这种惨淡局面的背后的逻辑。

而逻辑是很残酷的，逻辑不讲人情、不给面子、不考虑善恶，不徒人心，逻辑只考虑成立的条件和前提，只要条件充分，前提确定，他就一定是要发挥作用。

对于唯民主主论，本文将会给予严厉的批评。欧式的泛民主主体已经完全丧失了动员能力，欧洲也有可能在现在的这场末日赛跑中第一个败下阵来，成为被危机的狼第一个碎的经济主体。

这么说吧，如果欧洲继续坚持持朽烂不堪的泛民主模式，他的结局将会非常确定：他残破的尸体将被中家中分食。

美国会将接收剩余精英，就是拿走人这一部分；

中国将会占领他们的市场，也就是拿走钱这一部分；
而俄罗斯将会占领他们的领土，也就是拿走地这一部分。

欧洲各国从此将成为一个历史概念，欧式文明也会自此消亡。大佬文圈相信一定会有很多读者，根本就无法接受这样残酷的论述，所以建议你们看到这里就不要下看了。

现在进入正题，首先需要说明动员到底是什么？

动员是国家通过其组织和管理体系，能够极大程度上推动全体国民以积极主动的方式应对重大灾难的能力。

这里的重大灾难包括了自然灾害、战争以及以来的经济危机。

一个国家的动员能力越强，就能越能推动其挺而出，直面灾难、对抗灾难，并因此有效提升应对灾难的能力。即便最终未能真正战胜灾难，至少能够减轻灾难带来的负面影响。

从原始人类诞生的第一天开始，就开始面临大自然的种种挑战，凶险的猛兽、恶劣的气候、残酷的自然环境，分分钟就能让脆弱的人类死于非命。个人的类在自然环境下根本就无法存在。

为了对抗自然，人类被迫了聚群而居的生活方式，并因此形成了部落聚制。即使是最原始的部落落，也会有组织、分工，也会建立起原始的动员机制。

能够猎取更多食物的部落，一定能获得更多的食物，占据更高的部落位置，获得更多的资源，这是大势所起，也是最根本的人性之所在。

当部落这样的组织形态建立后，战争就逐步发展为人类社会最可怕的灾难，没有之一。

任何一个还正常繁行的部落，都会与周边部落争夺各类自然资源，也因此一定会处于长期的战争风险之中。

部落首领为了保持并提升整个部落的战斗力，他要想办法建立有效的战争动员机制。

比较原始的动员机制就是奖惩机制，在战争中的战士将获得物质、社会等级方面的直接奖励；而俘虏叛徒则自然会付出代价。

更加精明的部落首领，会尝试建立长期有效的动员机制，他会在部落内部建立公平的食物分配体系以养育更多的强战士；他会建立残兵战士的营养机制，以解决战士们的后顾之忧；它发展生产金属冶炼和粮食种植等全产业并因此革新装备，提升战争储备水平。

在此之后，他会建立完全脱离的职业化军队，建立指挥秩序，提炼每一名勇士的战斗技巧和经验，形成城市化的军事技能并可能的在军队中普及。这么说，战争曾经推动人类在社会科学与自然科学这两方面保持进步的最大因素，没有之一。

自从类从树上爬到地面，进而形成大小小的部落，战争就是摆在人类面前最大的灾难。为了应对灾难，人类就必须学会动员，不能开展有效动员的部落一定会被灭亡，绝不会有例外。

如果有哪个部落首领们狂病，一定要拿走部落所有的资源，吃自己的肥腰肥体，不给部落里的群众留一口汤，让他们整天饿得鬼奄奄。这样拮劣的部落，就算自己的民众不造反，一定会被周围的部落一哄而上，起群而食之，绝不会给这样的垃圾部落留下一丁点的活路。

再强调一次，有效动员就是人类应对战争威胁的唯一方式，任何一个能够延续下去的部落以及此后大小小的王国，一定会建立有效的动员机制。战争就是人类永恒的主题，所以任何能够存续的国家，都必须建立有效的动员机制，没有例外。

在王国时代，无论什么样的王国，动员机制都包括三大共性：

- 必然存在一个中央政府统领行政、军事和司法；
- 必然存在一个自上而下的分布式体系，确保权力的触角能够尽可能延伸到社会；
- 必须存在一套广泛的洗脑工具，建立统一的思想和共识。这两种模式主要是一统王朝和封建王国。

实施动员本身就是国家的根本原因，甚至可以说是唯一的目的。保持强大的动员能力是漫长的帝国时代，所有的事情都是为了保持强大的动员能力提供的配套服务。

- 农业生产，核心是为了保持物资的供应；
- 让百姓吃得饱、穿得暖，是为了提升士兵素质；
- 教育，核心是为了提升士兵的思想；
- 司法体系是为了凝聚人心，建立强大的战斗意志。

总之，一切的最终归结到战争。所有的成果最终都要通过战争检验，一旦无法通过，民众就会越过越，杀得血成河、灵涂炭，最终只能王朝崩溃。

然而，致命的问题在于人心，人心不能守任何底线，而权力一定会腐人心。在所有王朝的初期，帝王都会留，牢记国家的根本目的就是强大的动员能力。

建立一个一统王朝，赋予顶层以巨大的权力，甚至允许皇帝为了天下，希望皇帝能够以家人的姿态看好这片疆土。然而权力很快就会腐蚀人心，从顶层的帝王到最底层，所有在权力链条上的人都会被权力蒙蔽双眼，最终留下两个词：左边的是贪腐，右边的是享乐。

于是整个国家的动员体系很快就会崩溃，从动员迅速变为收割，从底层的老百姓变成权力的收割对象，不再是被动员的对象。权贵们会疯狂地圈地运动，收掠天下田土，而草民没有任何抵抗力。国家的税赋体系也会很快演变成征收、割民的暴利体系。权力阶层会毫不留地吸干百姓的最后一丝骨，不留任何余地。至于国家的动员能力以及应对北方蛮族的战争能力，就让他见鬼吧。哪怕明天蛮族骑兵将夺下我的脑袋，也不影响我多吞一个铜板，再多吸一口民血，这就是权力的本性。

在利欲熏心之下，朝堂之上只能一群贪婪的恶魔，这是历史的纪律，以前是这样，现在也是这样。

在欧洲那边，情况同样恶劣，封建的贵族领沉浸在横征暴敛与穷奢之中，对于发展民生、兴修水利、普及教育这样的动员性管理动作基本上毫无兴趣。大统王朝还能在国破初定的前30年，扶持治理、爱护民的精神。

在欧洲这边，肮烂的空气从顶层的国王一直延到底层的骑士。甚至在所有的历史文献里，你都找不到欧洲的贵族们发展民生事务的任何记录。欧洲的农村很快就在整体上消失了，绝大部分的底层老百姓变成了依附于领主的农奴。整个欧洲的底层管理逻辑很快就退到了奴隶时代，欧洲因此长期发生大规模的饥荒，一死就是数十万人。对此，欧洲的首领们压根就不在意，你们死死了奴隶，无非就是损失了一点流动性资产而已，过几年就回来了。

这样恶劣的情况，欧洲的贵族领主根本无法员手下的奴隶起来打仗。贵族集团战争的动员能力一步步的衰弱到接近零的程度，这就成了两个后果：

幸运的是，草原上的蛮族长期处于分裂状态，无法建立稳固同盟。一支强大的势力统一了草原，那就是中原王朝和欧洲封建王国，从来没有例外。这种令人绝望的局面维持到17世纪末，终于于英国出现了转机。此时在英国盛行的信仰是新教，算是天主教改良版，对老百姓思想的动员。

1688年，英国的贵族们决心抛弃国王，从荷兰找了一位信奉新教的贵族担任国王，并且他们达成了一份协议，就是著名的《权利法案》。按照权利法案规定，国王的征税权和立法权都被拿走了，仅仅保留了一些行政权。再到1722年，英国议会选出了英国的第一位首相，拿走了大部分的行政权力并直接向议会负责。英国国王的权力受到进一步的限制，最后逐渐弱化了纯粹君主。

当然，此时把持英国议会的议员主要还是各地的封建领主，也就是传统意义上的贵族。不过没关系，通过议会来掌握大权，贵族们商量事情，以投票的方式决定国家的未来。相对于以前独断，当然是一种革命性的进步，这算是黑暗时代撕开的第一道子。

发展经济、促进民生，逐渐成为英国国家的首要任务。为了贵族的私人扩张领土，逐渐不再是英国政府的目标。在这样的背景下，美国的独立运动才有成功的可能性。当时英国政府并没有真正以开战的心态，集力镇压独立的战争，战争一直都是温和对待。英国议员们非常愿意接受美国方面派出的谈判使团。

1782年，美英之间终于达成协议，美国宣布独立建国并在此后的岁月里，一步成长为全球最强大的国家。

再到1785年，英国瓦特改良了蒸汽机，在当时英国政府的支持下，蒸汽机被迅速应用到纺织、水利、开矿等领域，人类自此进入了工业时代，根本性的改变还要看拿破仑。

1800年，拿破仑在法国的革命运动中横空出世，夺取了执政地位并开始制定《民法典》。

1804年，法国民法典正式发布，其主要内容是解放农奴，保障底层百姓的基本权利，规定所有人民平等，没有低贵贱之分，同时，该法典严厉的约束政府，严厉禁止公权力侵害私权。

拿破仑法典确立了新时代法律的基本精神，私权高于公权力，在两者发生冲突时必须优先保护私权。

拿破仑征服欧洲，征服了大半个欧洲，每到一地，他就强制推行拿破仑法典，解放农奴，打破原有的社会秩序，着手建立全新的治理秩序。
