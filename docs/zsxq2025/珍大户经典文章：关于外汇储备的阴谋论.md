


# 基金的艺术

【编号0548】关于基金的总结

这一回来，我又要和基金相处了。但是这次，我有了新的感悟，不再像以前那样盲目地和基金相处了：

## 一、下一次开始前要注意什么

其次，不要太害怕亏损。基金本身就是一种投资，有亏损是正常的，但是要做好心理准备。

## 二、持有基金后要注意什么

- 首先，不要在基金涨的时候就一把梭买入。基金大涨的时候， 往往已经到了高位了，并不会持续上涨。

- 其次，不要在基金下跌的时候就盲目割肉。基金大跌的时候，往往到了低位，很快会有反弹。

- 最后，要学会止盈。你赚了钱，难道不打算落袋为安吗？

很多人买基金失败，其实不是技术的问题，而是心态的问题。因为太贪婪，或者太恐惧，导致他们没有足够的耐心和能力，去承受基金波动带来的痛苦。

所以，心态好，一切都好。但是，心态好真的重要吗？心态真的比了解基金重要吗？

很多人买基金失败的原因，其实是因为他们不了解基金。如果不了解基金，你怎么可能心态好呢？基金一波动你就会恐慌。

所以，我们要学习了解基金。只有了解了基金，才能从正确的心态开始投资基金。

## 三、如何选择适合自己的基金

市场上的基金这么多，到底该选什么样的呢？其实，没有最好的基金，只有最适合自己的基金。

- 首先，看基金经理的业绩。虽然过去不代表未来，但它代表了经理过去的投资能力。

- 其次，看基金的风格。要看它的风格是否符合自己的风险承受能力。

- 最后，看基金的费率。费率越低，长期持有的收益就越高。
