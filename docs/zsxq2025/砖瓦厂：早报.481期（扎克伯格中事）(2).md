# 第481篇： 扎克伯格中国往事

这几年，全球化退潮，很多逻辑都变了。

站在这个时间点，再看许多事，下巴有托不住的感。

例如，2014年年末，风头正盛的扎伯格访美，顺道参观了Facebook 园区。在 CEO 的正式办公桌前，他一屁股坐在小扎专属的赫曼米勒工学椅上，扬着头，接受着站着的蓝星科技的汇报。

而这场汇报最成功的点，是小扎办公桌上那本，放着的印有领导头像的白底书。

谁道西方商人不讲政治？回头想一想，这十来年的事情影响之大，只是当时，已经足够了。

又一年，经纬搭桥，内蒙出身的礼部尚书，亲自在京接了这位媒体口中的“中国女婿”。

投桃报，2016年，G20峰会和博鳌亚洲论坛刚过去，小洛在天安门前，顶着重度雾霾跑步。一时间，中美领域互信合作的风，从长安街吹到了华尔街。而脸书，然有完成谷歌未之态势。

此，中美关系最后的美好时光。

时移世易，西方保守势力扩张，中国制造向全产业链覆盖，全球化退潮，开放成为了旧时代的音符。

东方这边，改革进入深水区，2017年，那位访问过的脸书的侍郎因销入狱，判词之严厉，震惊坊间。

再然后，中国的“好女婿”陆然换了副面孔——在诸多议题上，对东方百般骄诩，毫无情面。连带着中概股，被狠狠狠狠地打了板子。

回头想一想，这十来的事情影响之大，只是当时已惘然。
