


# 【助理播报】

国际：

1. 当地时间9月19日，美国总统特朗普签署行政令，大幅改革H-1B签证项目，要求申请人缴纳每年10万美元费用，否则不得入境。

2. 当地时间9月19日，《华尔街日报》报道，美国政府官员正与塔利班进行谈判，讨论在阿富汗巴格拉姆军基地恢复小规模美军驻扎，以作为反恐行动的前沿基地。

3. 当地时间19日，欧盟委员会发言人表示，欧委会当天通过了新一轮对俄制裁措施草案，该草案将针对加密货币、银行和能源领域。

4. 财联社9月19日电，泰国官方召开年度会议，讨论泰东边境安全问题。会议决定继续关闭泰东边境关口及商贸口岸，直至边境局势缓解。同时，泰军将在双方同意的区域建设边境防御屏障。

5. 韩国外交部长赵廷显9月19日表示，韩国政府将着力解决持美国签证的韩国面临的问题，随后才会推进总额3500亿美元的投资计划——该计划是双边贸易协定的重要组成部分。

国内：

6. 19日，《新时代中国推进妇女全面发展的实践与成就》白皮书发布。白皮书介绍，截至今年6月，18个省份适龄女免费接种HPV疫苗，每年惠及约500万女童。

7. 9月19日，轰动全国的“入室抢婴案”在泰安市中级人民法院一审宣判，4名被告1人被判死缓、2人被判无期徒刑、1人被判有期徒刑15年。

8. 2025年1—8月，全国新设外商投资企业42435家，同比增长14.8%；实际使用外资金额5065.8亿元人民币，同比下降12.7%。
