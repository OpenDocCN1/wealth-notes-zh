


# 第一章 父亲（林远）

陈峰，你已经很久没回电话了，“你是不是还在外面当工人打工了。”

陈峰看着手机屏幕，心里五味杂陈。窗外下着沥沥的大雨，街道上空空如也。他想起妈妈离开时的场景，心里泛酸。他想念妈妈，想念爸爸。他看着房间里破旧的旧衣柜，轻轻叹了口气。

- 1. 妈妈

他按下了拨号键，电话响了很久，没有人接。他又打了一遍，还是没人接。他有些失落，妈妈是不是在忙？

- 2. 爸爸

他拨了电话，很快通了。电话那头传来爸爸的声音：“陈峰啊，你怎么还没回家？”

“我给妈妈打了电话，可没接。”陈峰挂了电话，心里有些落落的。他走到窗边，看着窗外的大雨，心里有些难受。妈妈是不爱了吗？妈妈，回来了吗？陈峰自言自语着，眼眶渐渐湿润。他再也不妈妈电话了。妈妈，我好你。陈峰闭上眼，眼泪顺着脸颊流下。妈妈，你为什么回来？妈妈，你爱我？陈峰躺在床上，很快就睡着了。

陈峰，你别哭，“你是不是还在外面当工人打工了。”陈峰，你怎么还没回家？爸爸，我给妈妈打了电话，可没接。”爸爸那边沉默了会儿：“妈妈可能在忙吧，你早点回来就行。”
