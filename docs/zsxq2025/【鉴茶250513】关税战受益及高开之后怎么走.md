


# 关税收益及高开之后怎么走

同学们在讨论高开之后的走法，那几个板块的态势会如何：

- 1. 整体的科技，依然恒生科技的引领，恒生科技涨亚A领先，恒生科技一步在国际上得到价值修复。
- 2. 军工，已经不是突破概念，而是中装备的军工概念、出海概念，营业额可能扩大，就会迎来资产重新估值。这块就看航飞的龙一引领，它继续军工就继续，它军工回调。军工持续，短期内成为主线。
- 3. 关税的声明是缓和态势，缓和中短期不利于自主可控，比特赛王代表的AI芯片和MCU，华为的910等。
- 4. 缓和利好加出海，就是我们，英伟达、果链是机构抱团，如恒达、东山；英伟达有修复需求，如胜宏等；稳健的SOC，SOC是明年出海主力，前段时间跟果链被错杀，而且接下来几个月，国内几个大厂，包括字节、阿里、蓝族等，都要出现新新品具体已经谈过多次不赘述。

![](img/cba3380c0221de9854f44fb14d4b5815_0_0.png)

- 5. 科技常青树是机器人，机器人目前的趋势就在设备、工控设备、整机设备，你拉开涨幅前排，都是干这个的。以上属于科技。

消费去，最近消停了，不是市场主流，但也是布局时间。长期，不定期，或趁大跌狗粮和国产红牛可以等它们它们的业绩爆发。

觉得是高手同学们可以关注一个上游卖铲子的，做牛磺酸的，永安药业，待它稳再说。牛磺酸既能做兴奋添加剂提神饮料，供养去撸嗨了加班提神，也能做必要的诱食剂，保护动物肝，促进动物生长发育。只要你吃过养殖的鱼，必然吃过牛磺酸，水养殖按皮袋放的。
