


# 烈焰三国之——乘杂舟 已付费

原创 创奇杂谈盛京诚 2025年08月12日14:42 辽宁

头部主播牛修接过筒，归目观瞻，不禁惊慌失色：“公主，物有本末，事终始。不从导致通缩的根本入手，恐非良策也。”

蒙的心想，果然又是牛修，总是让我难堪，看我如何整你。遂忍目而道：“把他给我扔下去！重责80！”

![](img/52f50e34d8b78ae32a09776e58ee2ff0_0_0.png)

不一会儿，只听隔壁传来，“80、80、80……”

“什么80?砸砸呢?演小品呢？”蒙的恼道。

此时，小兵黄红从隔壁探出来：“公主，大锤80，大锤40，要不要40的？”

![](img/52f50e34d8b78ae32a09776e58ee2ff0_1_0.png)

霉的被烦的皱起了头：“这一天的脑都来烦我，我头能不痛哉？”

一旁的保健医恳托道：“主主的脑瘤应尽快安排开颅手术，我的麻痹散是原研药，目前只有高干可用，且安全可靠，价钱公道，望主主不可一拖再拖。”

蒙的此时头痛皱说道：“话托，就TM你话多！你来霍下前，孤并没有过脑痛，自从你呵呵睡不休之后我的脑袋就开始疼痛欲裂。你又屡三番向我推销肿瘤、原研药和开颅手术，钱花了不少，但病情却在加重，你到底是何居心？你与那江东医药代表大乔巧小乔巧暗搭奸，别以为我不知道。休要再言！”

![](img/52f50e34d8b78ae32a09776e58ee2ff0_1_1.png)

此时，士士僵干气脸涨信：大帐下雀雀无声。

“哎呀呀，神来之笔，神来之笔，主角真乃神来之笔也！”

惧于自恃辩才出众，诸诸课士前来观瞻，道：

众所周知，收入-成本=利润。天才的主公在每一项前乘以一个系数，变成：2*收入-2*成本=2*利润。这种乘法真是闻所未闻，1500年后牛顿爵士发明微积分，我们公主真的是遥遥领先。看这优雅的等式，不仅左右相等，且解决了通缩之难题耳！”

![](img/52f50e34d8b78ae32a09776e58ee2ff0_2_0.png)

大宰士夹小声道：“惧干！这是明显违反经济学原理的毫无理意的玩儿，你会不知道？你在误国啊~~”

惧于蝇嫡：“封fact交，岂不知有道则智，无道则愚？”

蒙的痛苦的挂着头：“你们几个TMD在蚕蛹什么？”

大课士锅夹道：“我们我们在说：主公高见！”

![](img/52f50e34d8b78ae32a09776e58ee2ff0_3_0.png)

“哦？就请封包细细讲来！”

夹类逍涌不绝：“主公真是英明，须知甲企业的成本或是乙企业的收入，乙企业的成本或是丙企业的收入……如此等式各项项乘以一个系数，皆上一阶，利润归于豪强，还过可消费，通缩可烟消云散也~~”

草民观之，事件件皆涨，卧榻不动之成本大幅提升，遑必涉及于工作。然而求职者许多，故工诸易难难，主公又又赢了！”

“哈哈哈哈，封包。此番解读正合意。”

## 郭嘉宁奉孝 乃才是策谋略

蒙的说着手舞足蹈，好不快活，脸色一沉，但脸色忧，道：“如此一般，草民会看穿否？”

僵干赶忙补充道：“主公莫忧虑，岂不闻我建议主公行之生育补贴300钱尚未发放，就发生了什么吗？”

“发生了什么？”蒙的好奇的。

“奶粉已聚耳！啊哈哈哈哈”僵干开心的说。

“正合意外、正合意外，草民果然愚愚，果然愚愚。回头给你加薪~~”

大宰土调夹夹风头都被抢干赶去，挠遥道：“报告主公，我们研究室推行的反令已经生效，外卖平台已不敢再低价促销。多个大宗物资已经涨，昨天碳酸钙在限产传闻出现涨价！下个月全民保险也会得到补充，为了交保险，小企业要关价、要涨价，要涨价，都符合主公之设妙笔之大方向！你们都是狐宰，都加薪！”

蒙的满意的笑了，然后习惯性的摸头：“唉？头疼了，头疼了。”
