


# 巨头的闪购大战
某布专栏 几类通

闪购之战，重要的不是在规则下的盈利权，而是规则的制定权。

![](img/9ad843e5d7a216803b0db86c811bc5fd_0_0.png)

2025年10月31日，淘宝闪购正式发布全新连锁便利品牌“淘宝便利店”，该品牌将以闪购形态，基于阿里生态的供应链优势，为消费者打造“一应俱全、24小时运营、30分钟达”的便利购物体验，并于11月1日正式面向消费者上线。

同时，美团的闪电行业态也计划拓展至10万家规模；京东旗下七鲜超市则完成了“仓店融合”模式改造。

阿里、美团、京东集体注闪购仓，本质上是对零售行业“近场化”趋势的确定性布局。那么，这种态势究竟为何而起？背后又反映出怎样的资本运作逻辑呢？

注：三大巨头布局闪购业务并非从近期才开始

美国方面，在2018年上线了美团闪购业务，初期主要通过接入线线下便利店门店线上业务，至今，其覆盖零售全品类的美团闪仓已达到3万个，2027年预计扩展到10万个。

京东方面，刘东东在2017年推出了“便利店”计划——“要在五年内开百万家京东便利店”。如今京东不仅拥有旗下七鲜超市完成“仓融合”改造，同时拥有京东Mall、京东电器等多种线下门店形态。

阿里方面，在2016年的电商大会上，马云提出了“新零售”概念，同年淘宝就开始结合控制供应链的模式，启动了“淘宝到家”服务项目“淘宝便利店”，以手机淘宝首页为流量入口，为周边三公里范围内的消费者提供1小时时达服务。

该项目之后在2017年5月正式更名为“淘鲜达”，主要聚焦生鲜、百货类的线上线下化服务，截至2020年底曾接入超过50家零售商、2500家线下门店。同年，阿里又通过零售平台推出的线下加盟零售店铺“天猫小店”，以品牌授权和数字化改造，将传统小卖升级为具备专属货架、智能管理和生态协同的智慧门店。

阿里、京东、美团在国内斥巨资打响胶战，本质上是用真金白银推动相关产业链按照他们的标准进行改造，从而建立自己的系统与规则，在这一轮的“人工智能+”的争夺中率先冲过终点。为此，付出多少代价都是值得的。
