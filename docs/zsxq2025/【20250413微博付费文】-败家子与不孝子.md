


# 家子与房子

2020-10-14 12:35

这是一个关于父母的一个很有意思的故事。在现在的社会里，现在的父母把孩子养太大了，现在的父母也往往对孩子留有感情，在家里就不会把房子留给自己的财产。

所有的孩子，都有父母的房子。父母的房产，对父母来说是自己的。现在的父母大多把房子留给孩子了。

但是因为，房子是自己的，孩子也是自己的。如果孩子去世了，房子就归谁了？这不就是面临的继承问题吗？

在老家农村，我有一个朋友叫张梅。她在2018年的时候把一套大房子给了儿子，把另一套小房子也给了女儿。后来，由于儿子去世了，女儿没有孩子，那么儿子的这套大房子应该归谁了？

根据法律规定，在没有子女的情况下，房子就归父母继承。如果有子女了，房子由父母子女共同继承。但是张梅并不知道这个规定。

《民法典》规定：“没有子女的，由父母继承；如果有子女的，由父母子女共同继承。”

后来，张梅的女儿也结婚了，她没有孩子。按照法律规定，由于没有子女，张梅的这套房子应该归谁了？如果女儿也去世了，房子又是归张梅和她的丈夫共同继承吗？

由于女儿没有子女，张梅的这套房子应该归女儿继承了。

后来，张梅的丈夫也去世了，那么张梅的这套房子又归谁继承了？

最后张梅也去世了，由于她没有子女，这套房子就归女儿继承了。如果女儿也去世了，房子又归谁呢？

这就是我想说的故事，关于父母的房产，以及关于父母子女继承的问题。

我还有一个朋友叫老王。他给儿子买了一套500万的房子。

老王的儿子没有结婚，也没有孩子。如果老王的儿子去世了，这套500万的房子又该归谁了？

老王，如果儿子去世了，这套500万的房子就归老王吗？如果老王的儿子还没去世呢？

如果老王的儿子去世了，这套500万的房子又归谁了？
