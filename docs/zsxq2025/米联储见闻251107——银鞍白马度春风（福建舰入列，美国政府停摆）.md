


# 米联见闻251107——银鞍白马春风（福建舰入列，美国政府停摆）

你好，我是米藕。

中国第一艘电磁弹射型航空母母福建舰”正式列入授旗，一把手亲自登舰参加授旗仪式。在官方报道里，还有一句话：一把手亲自决策福建舰采用的电磁弹射技术，而这个技术的实现是目前中国在该领域明显领先于美国的成果。福建舰的飞行甲板上，有四道跑道拉索、三个弹射起飞位，歼-35、空警-600等新型舰载机依次停放。领导前往福建舰现场，登上甲板，执行飞行指挥和起降运行情况。进入驾驶室，查看舰值到位，在航泊日志上签名，在弹射综合控制塔，观瞻工作流程，按下弹射按钮。福建舰是中国第一艘电磁弹射型航母，也是中国第三艘航空母舰，舰号为“18”，2022年6月6日下命名。福建舰由中国完全自主设计建造，其电磁弹射技术处于世界领先水平。中国由此进入三航母时代。

中国收获三航母的同时，美国收获千万万亿大富翁。在旧纽约市选举一位主张富人征税的候选人担任市长两天后，特拉斯股东通过了一项可能让马斯克成为全球首位万亿富翁的方案。特拉斯股东们坚信“赢家通吃”的资本主义模式，他们以压倒性票数达成一致：如果马斯克在未来十年内带领公司实现心驰勃的财务和运营目标，就给他价值1万美元的股份。

在资本力马斯克的同时，纽约选出社会主义者的现实也折射出美国人当下贫富差距巨大的现实。美国政府暂停37天，导致很多过去体面的政府官员开始为食物担忧。鼓励造者是资本主义的传统，与特斯拉股东在2018年批准的那份薪酬方案类似，这项包含了12个阶段的计划要求马斯克大幅提高特斯拉的市值，从1.4亿美元高达8.5亿美元，同时完成其他一系列目标，包括出售100万人形机器人以及实现1000万份自动驾驶软件的付费订阅。特斯拉董事及部分投资者，包括监管佛罗里达州公共养老基金的董事会，称赞这项价值数十亿美元的薪酬方案，认为将激励已成为全球首富的马斯克自动驾驶汽车等未来产品。佛罗里达州政委会在一份中阐述其为何投票支持马斯克薪酬计划的证券备案文件中显示：“那些嫌疑薪酬过高的人忽视了特斯拉的雄心之，而这种雄心直定义了特斯拉的发展进展。一个在激励框架下从濒破产发展到电动车和清洁能源领域领先全球的公司，完全有资金奖励特斯拉月级成果的激励机制。”马斯克的反对者，包括以及加州州养老基金的管理官，强烈反对这项计划，称它会让过多的财富和权力集中在一个个人手中。

纽约州州长马斯·迪尼波利在最新一次与记者和投资者的电话会议上表示：“这不是绩效薪，这是无约权力得到的报酬。”教宗十四世对此发表法，他在接受天主教新闻网站 Crux 采访时表示，马克的薪酬方案射出薪酬层与富豪群体日益扩大的鸿沟。大佬电信集团根据公司的证券申报文件，2024 年特斯拉员工的薪酬数约为5.7 万美元。马斯克间接回应了部分质疑，声称公司研发的人形机器人 Optimus 是消除贫困的唯一解决方案。目前机器人仍处于开发阶段。

“人们常说要消除贫困，让所有人拥有优质医疗服务。但实际上只有一种方法能够做到，那就是 Optimus 机器人，”马斯克说，“这将带我们进入超越想象的科学幻境。”根据代理求征机构齐洛森的数据，过去三年美国上市公司提交股东表决的类似高管股权激励方案约六个（尽管规模较小，除一个外获得）。富人帮助人已成为美国社会不可破的阶层壁垒，特斯拉市值从 1.4 万亿变成 8.5 万亿，这背后是给节奏 never die 打气，也不完全是为了马斯克个人，只能说其资本力已经是资本主义世界位数多的标杆，投资马斯克，本质是给资本主义延命，这钱与其说是投资未来，不如说是当下命。

资本之之所以如此押注马斯克，当然是希望马斯克这个现实世界的钢铁可以带领美国在中国的的高科技竞争中获取优势。中国在十五规划中所表现出来的对现代化产业体系和科技强国的重视，让美国资本落后于背。自第一次工业革命和工业革命以来，科技发展水平已成为现代国家或地区竞争的关键因素。中国在晚清的积贫积弱与今天的全球影响力，其中一个关键因素正是不同的科技发展水平。

年前中国还是一个遍地山寨产品的国家，但得益改革开放以来经济快速发展和过去的一些的大量投入，今天中国已经联上全球产业链的中高端，被英国《经济学人》称为科学超级大国。

在产出能力方面，中国研发人员数量已经超过美国，研发经费未来5至10年有希望超越美国，科研成果产出规模基本超越美国，但中国基础研究和尖端技术还是落后于美国，中国经济增速限制了中国投入的增速。

在产业应用转化能力方面，受立高校和科研单位的超低转化率拖累，中国的专利转化率明显低于美国，但中国的产研组织能力和技术扩散能够逐渐超越美国。

在服务保障能力方面，中美两国政府的科研基本上处于同一水平，但中国科研体系的行政化大低中国科研支出的有效利用率；此外，中国的金融支持和营商环境、法治指数，都与美国存在明显差异。

在消费方面，中国拥有全球消费者数量最多的单一市场，但中国国民消费规模、人均消费能力与美国存在不小的差距，从而限制了中国企业进行高附加值尖端产品的研发。

中国的创新竞争力与美国越来越接近，大致相当于美国 70%左右的水平，但是赶超速度在衰减，能否达到历史性超越美国的拐点，要看十五五的执行力和完成度，中美竞争是个长期的过程，百里者赛九十，越到后面考验中国能否通过发展和治理解决各种问题的能力。大佬集团过去十年中国的优势固然得益于自己的发展，其实也在对对手不断的出招，这一过极大的缩短了中美的差距，中国不能希望于对手继续出错，把发展的主动权掌握在自己手里。

这次美国政府再次停摆，表面上似乎只是围绕《平价医疗法案》补贴问题的争夺，但实际上，它像是两党长时期权力不对称的集中爆发。对于民主党而言，预算谈判是目前数不多能动政策影响的杠杆；对于共和党来说，他们认为民调在手、选民支持稳固，因此足够的气让僵局持续。双方认为时间站在自己这边，结果便是政府机关关门、公共服务停摆，成万上的公务员被遭到无休假。进界加信微255这种情形在美政治并非首次出现，这次格外特殊。通常，总统会面中调停，试图阻止。然而普普曾显得外从容，甚至让意停摆持续。保守派内部的判断，这一个。
