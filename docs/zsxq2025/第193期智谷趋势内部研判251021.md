


# 第 193 期 智趋势内研判 251021

内部资料仅提供给会员投资与决策参考之用，所有观点与分析勿直接用投资的依据，请各位对市场风险保持足够的敬畏。

本周最大的动向是四中全会（将影响未来五年的“十五五”规划），从 430 上海座谈会到国庆日报“钟八鼓”吹文章，已透露四中全会相关信息。智合趋势深度分析：

1. 十五五规划核心事项是完成第二次转型——十五五规划是第一次转型，从房地转向制造业，未来五年第二次转型将从一般制造业转向科技产业；
2. 前段时间的主要政策已围绕展开，包括内卷（避免资源堆砌到中低端产业）、统一市场建设（避免重复建设，资源要用在刀刃上）、城市化改革（不再摊大饼区域，收缩核心产业）、要素市场改革（关键资源要配到新生产力上）；
3. 十五五的发展模式是问题托底+科技突破，房地产、地方财政、内需弱等问题采用兜底的方式，稳住但不会发大力；
4. 股市会进入跑机模式（前行或后退、前行的速度，由调控者控制，不由参与者决定），承担着为科技输血、稳定社会情绪的任务。

大陆全面脱钩，恐正在从一种可能性，逐渐变成一种必然。一方面，特朗普威逼加征100%关税后，尽量美股大跌，但矿产、稀土资源却逆势上扬，市场纷纷押注战略资源的争夺；另一方面，过去几年被边边缘化的传统能源，伴随安全优先的政策导向，正重新得到重视（巴菲近日大“西方石油”旗下的资产）。智合趋势研究员谭游仁认为，这一系列异动传递出一个明确信号：产业与资本正在在可能的全面脱钩提前布局和合计。当博弈双方均可以在关键产业链领域进行“卡位博弈”时，最靠谱的路径就是各自建立一套不依赖对方的完整体系，例如美国联合西方盟友重建供应链，中国加速半导体自主生产。世界将变成两个体系，互不依赖、互相隔离。老板集团无论是美国进一步限制半导体，中国出稀土新规，还是近期兰澜宣布接管中资控股的芯片制造商安世半导体，都是趋势的显现。缓解可能是一些暂时情形，按美国学者米尔斯海默的理论，大国对抗是一种必然。这将是最最坏的一种情形，我们应该保持足够的警惕。

经济增速有所放缓，三季度 GDP 同比增长4.8%，创下近一年来新低，前三季度累计增长55.2%，完成全年目标不难，但内部分化更加严重。

研究员路口分析：

1. 大幅超出预期的，除了9月的出口，还有规模以上工业增加值增长(6.5%)，装备制造业和高技术制造业持续向好；
2. “内卷”在部分先进领域取得成效，汽车制造、计算机、通信和其他电子制造、电气机械材料制造等行业的产能利用率，二季度有明显回升；
3. 消费增速放缓，9月的消费数据直到11月以来出来，全国人均支配收入实际增长5.2%（第三季度），较半年放缓，与同期经济增速持平，边际不可避免对居民消费信心构成挑战；
4. 投资罕见下滑，1-9月固定投资增速同比下降0.5%，2020年以来首次转负；1-9月基建投资1.1%，2020年以来最差增速，地方财力紧张为主要因素；房地产投资持续下行；制造业从今年早期10%回落到4%，东部、民间投资跌幅扩大，说明民间信心不足。

从政策层面的安排来看，新增5000亿新兴政策性金融工具在9月底落地，中央也从地方债务存量限额中安排5000亿为地方增加财力，投资下滑趋势有望缓和；和消费作为“十五五”规划中五大战略之一，如何破解内需不足等民生难题有待四中全会揭晓。

楼市再次创造历史，9月份70个大城市二手房价格同环比全部下跌（国家统计局）。这是史上三次出现全部“双降”，前两次分别发生在2024年5月（紧接着出台517刺激政策）和2024年9月（出现924政策转向）。这次，恐不会出现大力度的救市动作。智合趋势研究员挂片分析，7月政治局会议首次没有提到房地产，表明在决策系统中的位置已经降格，高层或认为房地产对经济与金融的负向影响在减少。从数据来看，今年的土地收入依然延续，前8个月，30城土地成交为13128亿元，同比增长9%。据大根预计，由于“金九银”窗口已过，第四季度出台全国性刺激政策的概率较低。至于明年是否出现，取决于两个因素：
1. 第四季度房价是否加速下滑；
2. 房价持续下跌是否严重拖累居民消费或触发经济风险。

日本将诞生世界上第一位女首相，由日本版“特朗普”高市早苗出任。日本加速转向的趋势变得不可阻挡，高市早苗的政策包括：

1. 主张放水和刺激政策，以提升经济；
2. 主张让大的民族主义，修改和平法、军队正常化；
3. 限制外国人居留，限制外国人购买土地。

智合趋势研究员钟锐认为，在政治和外交层面，日本政府更加强硬；在经济和金融层面，日本可能会推迟加息，日元升值，流动性增加，对日本资产利好，近期指数连创新高。

国考：7年来首次缩招，明年或迎来“惨烈”。2026年国考计划招人数为38万人，是近年以来新低；同时国考年龄放宽（35岁宽到40岁）。这“一减一增”导致2026年报名人数和竞争程度创下高。智合趋势研究员申申分析，体制内就业扩张预期所知，随着政策推行，体制内“常态化”将成为概率。此外，智合趋势关注，体制内部门逆势增加8.7%（约2000人），占比高达65.6%。随着技术进步背景下，配置税务工作的重要性。今年8月累计增速5%，跨境电商、MCN机构、互联网平台等以往监管的领域，效率明显提高。

国考缩招后，是供养人员持续上升的压力。复旦大学的一项研究显示，供养数量一直上升，2020年达到684万人，但增速已趋缓。智合趋势研究员布语注意到，编制人员近年确减少，但退休人员供养占比不断提升（近四成）。今年政府报告提出“严控供养规模”，此外，供养率（供养人员占总人口占比）在地区间呈现“西高东低”特征，人口流出区供养率越高，负担反而轻。

中国面临气候变化。两条最重要的分界线：
- 半湿润干旱区界线——400毫米等降水线，向北推进；
- 湿润与半湿润界线——800毫米等降水线，冲击秦岭淮河线。

最直接的表现是华北、中部夏季延长、降雨量偏多、降雨强度增加，几十年不动。国家气候中心首席预报员章大全说，近十年来，我国东地区汛期多雨带明显向北移动了。2020年3月云南出现异常，2021年7月河南遭遇罕见大雨、塔克拉玛沙漠遭遇边界洪水，2025年华等地频繁遭遇降雨。智合趋势研究员暴雨注意到，气候北移还需要更多观察，结果已经十分明显。暖化趋势对于西北来说“南水北调”更管用，新疆成为产粮重地，对华北来说却是困难重重，出现了剧烈的极端气候事故（参考今年北京暴雨）。农事节奏、生活习惯将被颠覆，国家规划好的防灾建设、粮食安全，甚至是重大工程，都将面临重新审视。重大变化之，人真不能胜天。

目前A股在落地。上周市场没有复刻4月7日“关税黄金坑”，而是二次深探。智合趋势研究员老伯认为，主要有两个原因：
1. 市场连续上涨6个月后，获利盘丰厚，本身有调整需求；
2. 中美关系仍存在不确定性，上周特朗普发权威提醒市场风险依然存在。

市场寻找方向，预计会持续到11月中旬（中美关落地、十五五规划出、三季报落地）。

以下三个指标成立，则无大问题：
1. 量价，成交量在1.8万附近稳企，中证指数在60日线附近稳企；
2. 科技板块稳企，即人气股如寒武稳企；
3. 避险板块滞涨，银行等红利板块涨不动了，说明资金不再追求避险了。展望未来，科技成长仍是长期主线，但四季度面临长短期缺的风格切换，相对看好全球资源和部分顺周期领域（宏大叙事）。

欧洲正在强硬，强化在全球战争中的角色。先是欧盟考虑强制让技术，中美升级溢出效应明显，一方面是荷兰接管中国控股的芯片制造商，这反映了欧洲对中国掌控核心技术的安全感。另一方面是中国稀土资源，中欧摩擦频繁，尤其是新能源汽车、电池、矿产资源等行业。但从中方应对克制力权来看，对方确定的主要矛盾，中欧之间缓冲空间巨大，甚至形成新的利益绑定。

美国一次性没收13万比特币（当前市值约XX），这是迄今规模最大的行动。此外，美英宣布追查加密货币安全性的疑虑，美国政府之所以可以控制这些比特币，并非破解了加密技术。智合趋势研究员张之分析，比特币作为新兴金融工具最关键的“信用”并未动摇，充分反映了市场定价方面，比特币最近的价格波动基本没有关系。不过，这一事件强化了监管部门对加密资产的介入，让全球市场重新审视“国家权力与去中心化”的边界。未来，加密货币的安全焦点将从底层技术转向加密管理、资产托管与合规。这既意味着行业的进一步成熟，也预示着“匿名时代”正在加速结束。

核能初创公司Oklo股价暴涨八倍，市值达260亿美元，成为过去12个月内未产生收入最大的美国；由美国能源部长期创立的企业Fenmi，今年IPO估值高达190亿美元（美股史上第三）。智趋势研究员王胜分析，美国电力需求与供给的严重不平衡，引发了电力危机，即使它还未发一度电。波士顿集团预计到2030年，数据中心的用电量将是2022年的三倍。与此同时，美国基础设施老旧，比特高压电线路仅3000公里（中国约5万公里），亟需大建。引发美国电建大潮的不是电力企业，而是科技、金融巨头。其安全成色愈发突出，为了防止被中国卡脖子，美国政府断然放弃风、电，转大力扶持电力与核电。

# 人口拐点彻底来了吗？

中国65岁以上老人马上将超过少儿人数。国家统计局数据显示，截至2024年，65岁以上人口数上升至2.2亿，占人口的15.6%，逼近0-14岁的2.23亿。从增速来看，人口交叉拐点概率在今年内未出现。

1990年至2024年，35年少儿抚养比从41.49%降至23.00%，老年抚养比从8.35%升至22.85%，二者几乎持平。老年抚养比是指老年人员占总人口占比。
