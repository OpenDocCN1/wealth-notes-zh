


# 京东：京东发行优先股份斩获成功

2025年1月，京东（00169.HK）发布公告，其董事会批准了发行优先股的提议，并委托发行人、律师及相关人士办理。

在投资者的积极参与下，京东优先股发行圆满成功。由于认购认额远超发售金额，京东最终发行了3000万优先股，募集资金约2.5亿美元，此一笔资金将用于公司发展。

截至2024年12月，京东普通股占总股本比例为99%。此次发行优先股并未稀释现有股东的权益。京东在宏观环境多变化的背景下，通过此次融资成功充实了资金，此一笔资金的注入也有效缓解了财务压力。

多位人士认为，京东此次发行成功反映了市场对京东未来增长的信心。在当前电商行业竞争加剧背景下，京东能够成功募得资金，显示了资本对京东核心商业模式的认可。

京东方面表示，此次募集的资金将用于技术研发、战略投资、市场拓展及营运资金。通过这些资金投入，京东有望在日益激烈的市场竞争中进一步巩固其行业护城河。

业内分析人士指出，京东在过去几年中不断加大对物流、技术等领域的投入，这虽然提升了核心竞争力，但也带来了巨大的财务压力。此次融资的成功，为京东未来的战略转型提供了资金确定性。

然而，京东也面临着严峻的挑战。随着消费趋于理性，价格战激烈，京东的盈利能力和抗风险能力面临考验。分析认为，京东能够成功融资，为其在激烈的竞争中寻找突破点提供了关键支持。

## 一、 刘东东的转型

2024年12月6日，刘东东宣布辞任京东CEO（首席执行官），转任董事会主席兼首席顾问。这一变动标志着京东自成立以来最大的高层架构调整。

刘东东在信中表示：“在京东的20多年里，我从一个创业者成长为一名管理者，见证了京东从无到有、从小到大的每一步。我感谢所有同事、合作伙伴及股东的支持。”

他提到：“京东正处于一个全新的发展阶段，我认为现在是时候投入精力，从更高的战略角度思考公司的未来。我将继续以董事会主席身份为京东的发展提供建议和支持。”

与此同时，京东任命任磊为接任CEO。任磊曾任京东总裁，负责京东的核心业务。刘东东对任磊的能力表示充分认可，对京东的未来转型充满信心。

市场人士认为，刘东东的转型标志着京东正在从“高速扩张期”向“战略驱动期”转变。这种转型有助于京东在更加复杂多变的市场环境中找到新的业务增长点。
