


# 重生后我看着女儿

2023/01/07 连载更新

## 是后悔了吗？

我真的后悔了，如果我能重回到十年前的那个下午，2月24日，我绝对不会推开女儿的生日门。我发现自己，原来我真的好爱我的女儿了。

看着她局缩的身体，我心里疼得像被刀割一样。以前的我，却觉得她很烦事，甚至觉得她影响了我的心情。

## 妈妈吗？

女儿的生日那天，她问我：“妈妈，我有生日吗？”我当时正冷脸对她，推开了她亲手准备的生日蛋糕。

我当时冷脸对她：“哪有生日？你这小鬼蛋，滚远点去，吵死我了。”

## 妈妈的生日

女儿生日还送了我一份礼物，6月16那天，她哭着对我说，生日快乐。

我当时只嫌她烦：“哪有生日？你整天就知道瞎闹闹。”

## 后悔了

女儿去世后，我才发现她是那么爱我。她从来没有向我要过礼物，却在我的生日那天给我准备了惊喜。

我重生在女儿去世的前几天，回到了6月16日我的生日那天。

我看着眼前正拿着蛋糕的女儿，泪水夺眶而出，我一把紧紧抱住了她。

“妈妈，你怎么了？妈妈”

我哭着回答她：“没事，妈妈就是太开心了，再不骂你了。”

我笑着摇摇头：“不哭，妈妈是眼里进灰了。”

## 保护她

这一辈子，我一定要好好爱她，再也不让她受委了。

可是，我很快发现，我保护不了女儿。前世，她是因为一场车祸死在我面前的。

这一世，我一定要让车祸不发生。
