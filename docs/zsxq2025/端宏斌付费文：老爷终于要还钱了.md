


# 老爷终于要还钱了？

发布时间:2025-09-11
文/端宏宏

今天收盘前，外媒又爆料了一篇小作文，还是咱们熟悉的彭博社。

![](img/967d5adfbfb093e804f7323e70ca35f9_0_0.png)

简单来说，老爷终于意识到一直欠着还的企业也不是办法，拖欠了百姓的债只会越来越高，最后可能会无收法。

上头先算算了，以为要欠百姓的钱是不可能的，打个折的话，大约是1万亿美元的样子，这笔钱多了确实也拿不出来，所以首期就选用1万亿人民币来起来，整个任务希望在2027年之前全部解决。

需要的肯定不是商业银行，因为没有商业银行会掏这种钱，所以只能让国家发行这种政策性银行来掏，政策性银行的钱是从哪里来呢？当然让银行来发行，也就是用发行的方式把债务化。

以前会有这种事吗？现在这么多通愁怎么办？哈哈，现在连通愁都解决了，还是连着心痛的事。现在的燃眉之急是，上个月的CPI还是涨（8月同比下降0.4%），之前之为鸭子啄一直不承认涨，现在终于也没再敢认了。

从去年开始拖到今年，政府的债务是越结越多，原本我们以为可以通过卖土地的方式来还钱，但是土地还是卖不动了，除了少数几个城市，比如北京，其他地方的土地全部卖光了。

土地财政本质上是一种税收的，把本来就该交的税收交了，其他地方的土地被他们自己把自己自己的债给打碎了。以前有多少债，现在就有许多债，我只能说，今日何曾当初？
