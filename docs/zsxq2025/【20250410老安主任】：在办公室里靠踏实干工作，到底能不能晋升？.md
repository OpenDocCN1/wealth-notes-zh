


# 老主任：在办公室里靠实干工作，到底能不能晋升？

在办公室里靠实干工作，能否晋升？

其实，真的不怪领导，因为领导压根就没有看到你的那些付出。倘领导看到了你的那些付出白黑5+2，或许还能够为你晋升的筹码。所以我们经常听到老同志们，在单位做事，一定要在领导的皮子底下做，不然领导都看不见，你做再多对你晋升也没有太大的处用。

明白这一点，你就知道为什么单位里，那个办公室的同事更容易被重用了，因为办公室是距离领导最近的。他们的很多工作都是直接面给主要领导的，比如领导傍晚的时候要个讲话，第二天早早你就去交差，你就把讲话稿交给领导手里了，领导心里就有数了，你昨天晚上肯定加班了。再比领导要出去调研的，你把调研方案弄得完美无比，领导心里很高，知道你小子是一个心细有能力的好后生。

但是，如果你在业务室每天做一些事务性的工作，比如天天统计面上上来的 Excel 表，天天捣鼓业务上的琐碎事，除非你自己卷成单位的劳模，比累得住院了、吐血了，领导才知道单位还有你这一号干不要命的职工。领导或许在用人的时候会对你倾斜一下，不然领导压根不知道你天天在办公室里到底干了些什么，他会在不知道情的情况下重用你呢？

所以我们要去领导看得岗位上去，要去领导看得的工作。如果你的这个工作和岗位内容确实远离领导视线，你又想通过工作层面让领导看到，那么你就想办法去急难重、领导头疼的岗位上去。

比近期某些疫情期间，大家对疫情工作组的抽调可能有些畏惧心理，能缩就缩，能避就避，很少有人愿意主动请假。此刻我就建议你主动一些，与你的单位做一个不被领导看见的工作，还不如借这次主动请假在领导那里露个脸。差三差五你还可以把代表单位去支持的防疫工作在微信上或者通过短信向领导做一个简短的汇报。此刻向他汇报这些不再是越级汇报，这便是自己创造了一个单线，单独联络领导的机会。

再比如，前些年的驻村扶贫，有很多家庭的职工也不愿意去。毕竟一驻就是长达一年两年甚至更多年，如果你觉得与你在本岗位上被雪藏，不如主动变，看一看在驻村的过程中能不能找到机会。这个想法便是正确的。

当然，我们的这两个例子的前提是你确实在单位找不到单独联领导的机会，所做的工作也确实无法让领导知晓。如果你已经在单位核心岗位上，或者已经被领导垂青，或者重点关注，那你实在没有必要去到这些岗位上，刚才我我说的那些急难重的岗位就没有必要去了。

主动变到这些急难重的岗位上，但只要你稍留心思，主要领导便能够记住你。且以后有文件要求对这些极其难重岗位上的人要重用，即便没有文件要求，领导在下次用人的时候，在等待符合条件的人选中，你也是绕不过去的。毕竟大家都知道，对于单位来说，你是有功劳，你是代表单位去参加抗疫的，你是代表单位去驻村扶贫的。

能力强，却迟得不到领导赏识的人，大概都是像古代的姑娘，养在深闺，领导未识。
