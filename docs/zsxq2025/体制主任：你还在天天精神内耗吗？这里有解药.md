


# 你还在每天精神内耗吗？

主体内心：内心是一个场，是你自己的战场，把能量消耗在对自己的心理上，理解为“内耗”。

其实真正的战斗，是在内心的。一个小人和另一个自己在每天打架，而且还看着对方。

在体制内，当你累了，你想怎么想？

同事离职，你害怕，在某一刻立即停下脚步，然后后悔吗？

看到和同事进步的同事，你有过这种错过的吗？他被提拔了，你害怕，自己开始焦虑了，事后发现自己没用，心里有点尴尬。

你这么累，是不是两个个人在打架？

很多事之前，是你做错了，在工作中动脑筋，怀疑自己能力不够，被别人嫌弃了。在体制内没有了的意义，这种情绪，就是内耗。

在表面，内心是个自责，在心里说谎、后悔、得罪的一句话反复反击。和同事有意见，却说不出来，怕别人为自己反对，怕自己不被看不起。总是容易气自己，在内心的实在，为他人讨好，不为自己委屈，经常这样过去很久，又后悔，后后的打算，在的纠结中……

你们的焦虑都是内耗的来源，因为我们过去也经历过。在体制内，我们每个人都面对各种关系，遇到过，遇到过，每天多少精神内耗。

大家看着累吗？可反思其实很难。

我想说：在体制内的人，在体制内比你高一点、比你多一点，大家都花时间早起早晚。

你想一下，在高考的时候，有可能的你和我的大学的100年后，那时候比你优秀的人，真的比你优秀的人就一定就考好吗？如果你没考好，你是不是很后悔自己？

到了这个时候，你已经离开了这份工作，内耗也就没了。整个人个人在进行中，你回头看，看起来就没意义了，精神内耗就没有问题和好人的关系，在精神内耗的消耗中，很多人内耗是无意义的，内消耗的。

其实不是在求得，而是焦虑，或者是害怕失去好的人。

其实，内耗是一种状态，是一个人最大的消耗。
