


# 猫哥 251117: 中方反制高市早苗极端手段的可能性

这一次中日双方针对麦芒，某种意义上双方都没有退路。

我们一个个说。

首先是高市早苗政府。在前期竞选时，高市早苗支持率本来就不高，最后能够当选主要原因就是高市早苗对外强硬。某种意义上也可以认为，日本政党将高市早苗推出来当首相，就是希望对外一搏，为日本打开生存空间。

所以高市早苗的基本盘就是日本右翼势力。新数据显示，高市早苗政府支持率还有62%，但是对于其涉言论支持率为42%左右（民意经常也会变化）。

假如现在高市早苗妥了，收回言论并道歉，那么看着她将失去基本盘右翼势力的支持，其政治生命也将进入倒计时。

所以，除非中方给予高市早苗施加巨大的压力，否则高市早苗是不会收回言论的。

然后站在中方立场，其实也没有退路。

高市早苗是二战之后第一个表示要用武力干预台海的国家领导人，并且拒绝收回言论。拜登执政期间虽然说过类似的，但是次日白宫就做了紧急澄清，相当于含糊收回了言论——而且美国老大，多少还是有点特权的。

所以，如果中方退缩（或者不退了之），情况就会非常严重，限于：

- 鼓励日本右翼势力做大，甚至鼓励日本在未来的台海中武力介入。
- 助长台独势力张扬气焰。
- 台湾问题国际化将不可避免，现在全世界都在看着中方如何处理这件事，一旦中方退缩了，未来整个西方国家将如同俄罗斯一样变着花样打台湾牌。未来解决台湾问题将遇到更大的阻力。

所以，这一次中方一定要让高市早苗收回言论并道歉，这是真正的打一拳，免得百拳来。

那么未来中方应该怎么施压，让高市早苗低头呢？

反制手段大致就是三个方向：经济、军事与政治。

首选在经济领域制裁日本的可能性我觉得很低。

中日关系传统就是冷热热，在经济领域制裁日本非常不打算。

中日每天双边贸易额大致是3000亿美元，如果在双边贸易下手，基本就是杀敌1000，自损1000。

另外，今年因为各种原因因素开始大规模投资中国，今年日本投资中国增长幅度高达55%，中方对此肯定是非常欢迎的，如果在经营领域下手反制日本，人为打击日本投资中国热潮，无论如何都是非常不划算的。

然后直接用军事手段可能性也非常低。

对于中方而言，任何时候，台海才是重点，日本永远只是支线，现在台海还没动手，是不可能在支线动手的。

更为重要的是，高市早苗的言论前提是中国方在台湾使用武力，如果中方没有在台动手，日本是不可能有动作的，在这种情况下，率先使用军事手段对付日本不符合中方的风格。

剩下的就是政治手段了，这是中方反制高市早苗最可能的领域。

要在政治领域给高市早苗压空前的压力，就只能在最敏感的领土主权上做文章。

现在中方可以做文章有两个点：

一个是钓鱼岛，一个是琉球。

如果中方准备反制日本，钓鱼岛与琉球大致是一个层层递进的关系。

第一步大概是将海警执法落地。

过去中方在钓鱼岛附近海警常态化巡逻还是象征性的，中方的意图也很简单，在没有解决台湾问题之前，不会激化钓鱼岛问题的矛盾。

但是现在高市早苗挑衅在先，中方有没有退路，那就只能打这张牌了。

海警执法落地就是所有进入钓鱼岛的日本船只，中方海警都会扣押，以此观察对方动态。

如果高市早苗依然如此，第二步就是派出军事力量登陆琉球。如果高市早苗继续挑衅，第三步就是直接军事制裁日本。
