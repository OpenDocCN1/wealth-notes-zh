# 如何缓解孩子夜惊？

楼主你好，孩子一岁了，夜惊可能是和大脑发育太快有关的，平时也不用太担心。

如果夜惊得非常频繁，建议白天多带孩子出去运动，消耗掉多余精力。

一般来说，夜惊发生在孩子入睡后的两个小时内，孩子会大哭大闹但并没有叫醒。

孩子惊醒时，家长不要用力叫醒孩子，只要在孩子身边轻声安抚即可。

如果孩子经常惊醒，建议睡前给孩子洗热水澡，放松肌肉。

回复：也有可能是因为孩子白天太兴奋了，神经系统还没安静下来导致夜惊。

回复：其实很多孩子在这个期都是大脑发育太快，也会导致夜惊的。
