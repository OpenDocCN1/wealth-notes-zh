


# 已经付费的关系，就不要付出感情

原文：U 君 公众号：赢在8小时之外 25年12月21日

我们去外面消费、享受服务，这个过程本应该是舒适的、令人愉悦的。

但是，如果你把握不好消费者和服务者之间的“生态关系”，很可能会出现“花钱买不痛”的局面。

比如，你去理发店剪头、做头发，当你跟理发师还不熟悉的时候，他会非常尽心尽力的为你服务，生怕你不满意。

但是，如果你去的次数多了，还跟他聊了很多家长里短的事情，甚至有一丝“朋友”的味道，那他对你的服务就会大打折扣。

他在给新客户做头发时，技术水平、服务姿态这些能达到9分；由于你跟他有“交情”，他就只给你做到7分，甚至是5分。

我说的这种情况并不是个例，也不限于服务行业。

任何一个需要“花钱买服务”的情况下，甚至是男女交往的情况下，都是普遍存在的。

今天我就从5方面大家聊聊，为什么会出现这种情况，我也会给出对应的解决方案。

## 1.不要给任何人超出他本身地位的对待

如果你是“花钱买服务”的一方，你只付出金钱，不掺杂任何情感，那么为你提供服务的人一定会想办法让你满意。

但是，如果你不仅出了钱，还付出了情绪价值和情感，那么提供服务的人就会一定会翘天上。

然后就会冷你，甚至把你的优先放到陌生客户的后面。

尤其是理发、按摩等行业，从业者的素质普遍较低，缺乏最基本的同理心和理解力，没有一丝一毫的感恩意识。

如果你给他们超出他们本身地位的对待，那么他们就会骑到你的脖子上拉屎。

比如，加入了微信之后，经常给你群发营销内容，甚至还会找你借钱。

10年前我找过游泳教练，由于当时我还不懂人性的险，跟他他还成了朋友。后来他在朋友圈看到我发财，还成立了公司，他就开始找我借钱。

当时就把他拉黑了，剩下的两次课我也不要了。

因为，他已经对我起了“异心”，即使再去跟他学习游泳，他肯定也不会用心教我了。

毫不张扬地说，很多违法犯罪的行为，起因都是“错误的人成了朋友”。

## 2.不要让闲人进入自己的生活

在“花钱买服务”的场所，如果你对服务人员表现得平易近人，非常好话说，那么他们会设法拿你、坑你。

尤其是处于底的服务人员，几乎不存在“对我好、你也会回报我”的情况，对他们好，他们只会得进进尺。

从某种程度来说，金钱和感情是冲突的，是矛盾的。

你们有感情了，就不好谈钱了，那么对方很可能让你在金钱方面遭受损失。

为什么做生意、开公司尽量不要找“有感情基础”的亲戚或者朋友？

因为老板要跟职场上的员工讲规矩，但是跟亲戚要讲感情。

本来应该讲感情的人讲规矩，他们就会恨你。

但是，如果不讲规矩，那么事情就没法做了，公司里的其他人也不会服你。

所以，最好的办法就是：做生意、开公司不找熟人，只招聘陌生，彼此只谈业务和利益，不谈感情。

反过来说，如果领导对你特别，跟你有无话不谈，甚至把你当成他的好兄弟，你可千万不要舔上脸。

你要一直自己当成是一个下属，该有的礼数、该有的姿态，你一样都不能少。

否则，哪天你露出一丝一毫“老板就是我的好大哥”这种姿态，那么老板会在第一时间把你从“自己人”的队伍里剔除。

如果你从事服务行业，有客户把你当成朋友，你也要时刻把握好距离，一句逾越矩的话都不要说。

并且，永远不要对对方发消息（包括发祝福短信和营销信息），朋友圈也永远不要评论，偶尔触到让你动心的内容可以点个赞。

而且，在为客户提供服务的时候，一定要露出这种姿态：你是我的客户，我把新客户都往后面排，永远优先为您服务。

但是，90%的底层服务人员智、素质都非常低，他们永远不懂我说的这些道理，他们会任由人性的弱点作祟，永远留不住优质客户。

结果就是：自己只能永远留在底层，即使出现了一个机遇，也会迅速被他们破坏掉。

## 3. 广网，多面开花

我还是拿按摩和理发来说举例子。

我隔两天都要按摩一次，理发也很频繁，一个月至少两次。

但是，我经常光顾的按摩店有四五个，理发店也有四五个，从不办卡。

因为我的头发很短，偶尔有理发师也会问我：上次你过来好像像是两个月前了，你是不是也去过其他理发店了？大佬问我就会回答：是的。

我不会跟他多废话的，更不会跟他解释什么。

因为我非常清楚：我只要保持高姿态，保持神秘感，他就会用心为我提供服务。只要我多解释一句话，他对服务的质量就会直线下降。

人就是这么贱，没办法。

“长期光顾一家店”更是大忌，因为对方会在潜意识里认为：我的手艺好你离不开我。然后他就会出傲慢姿态，就不会用心为你提供服务。

反过来说，如果你是提供服务的一方，千万不要话多，不要试图图顾客。

比如，当你问“你不是去其他店了”这种话时，你就已经得罪顾客了。

再当你对对方熟络起来，甚至聊过家里情况，对方可能再也不会光顾。

如果一个人频繁光顾你的饭馆，你一看就知道对方要钱了，也不要随便乱话。

如果你问他“最近怎么样？”，他的心里就会有压力。如果你对每个客都嘘暖，你的生意肯定长不了，很快就会完吉。

## 4.永远不要把关系当成朋友

有人会问：服务人员和客户之间，永远成了朋友了吗？

我的回答是：如果你让“一方出钱、一方提供服务”这件事能长久，彼此最好不要朋友。

因为你们立场不同，想要成为朋友比登天还难。

尤其是客户，花了钱，投入了感情，怀了一肚子气，想想就觉得恶心。

从另一个维度来聊：双方成为朋友，提供服务的一方受了巨大损失。结果就是，很多老板盯上了。

保险的，在过程中建立起“深厚的友谊”，他就掏了几万元，觉得自己赚大了。

饭馆的，在过程中建立起“深厚的友谊”，他就掏了十万元。

投资理财的，在过程中建立起“深厚的友谊”，他就掏了十万元。

理发店的，结果就是，他开几年赚到的钱都被骗走了。

按摩行业更夸张，技师的一个比一个低，话术一个比一个高。所以，提供服务的人如果跟顾客达成了朋友，结局大概是“人财两失”。

## 5.付费的关系就不要感情

如果你是个有钱男人，你通过花钱征服了一个女人，让她心甘情愿跟着你。那在交往的过程中，对方必须是提供情绪价值、投入感情的个人。

如果你不仅交了钱，又投入了很多情绪价值和感情，那么对方会把你吃得连渣都不剩。因为感情这类东西，比金钱贵多了，甚至不可再生。

你如果花钱买到对方的感情（即使是表面的感情），也是超值的。

但是，如果对方又要钱，又不付出感情，甚至连装出来的情绪价值都没有，你还是早点换人吧。因为在对方眼里，你就是一个无处的供养者，活王八。

我见过很多男人，他们全家掏空六个钱包，单方面付出上百万，才勉娶了一个老婆。而且，他在婚姻生活里也没有什么地位，在外面工作，回到家里还要做家务、哄老婆……这样的王八，早晚会被女人给踢掉。因为他们对于金钱、性、感情、情绪价值的理解，付了钱还像哈巴狗一样为她提供情绪价值，她从骨子里都会瞧不起你。
