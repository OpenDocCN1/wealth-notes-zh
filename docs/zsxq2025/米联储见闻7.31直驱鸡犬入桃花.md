


# 米联储闻20250731——直击入局

![](img/72c0be0d5c78cd028ccc03e612c9db5c_0_0.png)

虽然黄仁勋来华表演很卖力，但兔子已经不是以前那个稍微展示友好，就会全力配合的兔子了。

H20解禁问题美国国内舆情还未平息，中方的棒子子却落在英伟达身上，显然，仅仅是解禁H20是不够的。英伟达算力芯片被曝存在严重安全问题，此前，美议员呼求要求出口的先进芯片必须配备追踪定位功能。

美人工智能领域专家透露，英伟达算力芯片追踪定位，远程关闭技术已成熟。难怪川普团队对美国国内称，卖兔子芯片是为了胜利胜利，这明显是算力领域的特洛伊马。兔子难道不知道英伟达芯片有后门？当然知道，但是一天买不到一天罚不到，只有合法的才能合法的。当黄仁勋对王文涛说兔子市场非常重要时，兔子才能留住英伟达的耳朵说出自己的想法。芯片留门的问题，可不仅仅仅是质量问题，英伟达的芯片可是只卖给兔子的，既然兔子的有门其他国家的芯片了，这是直接揭露了英伟达安全的底。

兔子现在相关法律依据很完备，只要通过正规渠道买到一个H20，就是铁证如山，就可以名正言顺的维护用户网络安全、数据安全，依据《网络安全法》《数据法》《个人信息保护法》有关规定来找英伟达的麻烦。今天网信办约谈了英伟达公司，要求英伟达公司就对销售的H20算力芯片漏洞安全风险问题进行说明并提交相关证明材料。终于明白，为什么兔子可能并不需要H20这种时货，但依然乐于用稀换英伟达芯片，要的不是H20，要的是英伟达的小算子。

兔子选择这个时候向英伟达出手，显然是希望英伟达继续努力向美国工作。毕竟在川总的心情不错，贸易战又赢来一个又一个成果，川总的表现连民主党的媒体都忍不住要承认自己在获得成效，BBC和纽约不约而同写稿子称川总在赢赢得贸易战，这两家媒平时很少说川总好话。

这些媒体认为，是日本的低头推倒了川总贸易战胜利的多米诺骨牌。因为所有对美国有着大量贸易顺差的国家，日本与美国之间的贸易协定是最有利的，或者是糟糕的一个。美国对日本进口商品征收的15%关税高于对英国的10%，但英国并没有贸易顺差。日本还成功保护了其农产品进口市场，尽管将会增加美国大米的进口量。虽然日本私人企业将以某种形式在美国投资五千亿美元，但原本这些钱也是全世界找标的目标。

与此同时，自4月2日提高关税以来，美国政府通过关税获得了可观的收入，而且除兔子外，并未针对美国出口商的报复。截至目前，今年的收入为美国财政部带来超过1000亿美元的收入，约占联邦总收入的5%，而过去通常仅为2%。贝森特预计，美国政府今年全年关税收入将达3000亿美元。对于川总而言而言，这是一笔相当可观的金额，而且几乎是在没有任何成本和代价的情况下获得的，不管最后是美国消费者买单，还是出口国制造买单，反正钱是流进了美国政府的口袋，是不是赢麻了。

当然可能是美元单买，今年上半年，美元篮全球货币贬值10%。这不仅抵消了关税的缓冲效应，还进一步推高了进口成本，目前做空美元是金融市场上最拥挤的交易。但对川普来说，美元走弱并不是坏事，甚至是目的之一，便宜的美元有助于美国铁锈地带的制造业重拾竞争力。事实上，目前美国国内这些过去的老工业州确实正在恢复活力。原本想跟川普大打一场的欧盟和日本都默默接受了川总看似无理的要求，对进口零关税，而出口产品面临不对等的更高的关税。

事实上除了兔子未输赢，主要发达经济体纷纷签署了包含历史上最高关税的协议，川总对全球贸易的愿景迅速达成。而不是太听话的巴西和印度都遭到了关税大棒的重击。现在全范围内看着兔子，作为美国小弟盟的日欧都接受了近乎羞辱性的贸易协定，作为新兴国家的印度巴西都都被美国关税大棒暴击，此时，中美协议就变得非常重要。如果兔子选择跟日欧一样滑跪，那么以后什么金砖四国，什么南方国家，都上组织，都扯脖子去，兔子依然是美国主导世界秩序中不起的斗。

如果兔子跟美国签订了远比日欧更合理的协议，那么日欧肯定要回头给美国找茬，印巴这些国家也会继续增加对美贸易的难度，关键看兔子能否扛得住，是能顶住贸易出口的压力，扛起这面大旗，还是最后选择服软了。

不管和子的谈判结果如何，大家都必须接受一种新态，那就是与美国开展贸易，其他国家不得接受15%至20%的关税，这个结果证明了川总的漫天要价是一种强大的谈判工具。

大家之前预期的通胀被消化了，美国底气。作为一个庞大且多元化的经济体，美国对贸易的依赖程度并不高，只要美国敢干，世界就会给你回应。所以预期通胀没有发生，川总的关税措施引发的恐慌已经被消化了。

根据高盛数据，美国进口额占56%，包括加拿大、墨西哥、韩国、巴西和印度都尚未签署协议。川普拿关税来为筹码，到底是因为美国的基础工业根本那么强，某些贫穷经济体更需要保护。最近通用和大众等汽车制造企业造成的损失超过1000亿美元。

川普在18个月内让制造业走弱，实物仅占美国的三之二，这种优势让川总能凭空造谎。反复无常的贸易战奠定了美国优先的基调。日欧负责签字，然后回头向民众解释：这是符合自身利益的。美国霸权如此兴，法国反对党领袖马克龙严厉批评，认为这完全是一场政治、经济和道德的惨败，这样的收割将被载入史册。此次百年未有的全球贸易战，让不少国家认清了一个事实，那就是从来就没有真正的盟友。

政治只有你死我活。。

1950年，兔子与苏联签订过军事盟约，但苏联试图控制兔子海军、干涉内政导致关系破裂。这段经历使兔子深刻认识到依附他国会导致民主受损和战略被动，因此建立独立自主的外交原则，强调不依赖盟友保障国家安全。而这次美国选择美国优先，何美式独立自主，与其养着小兄弟呼风唤雨，结果搞成一团乌合众。真要干起来，西方国家7个一个掉一个。

作为美国来说，也明白一个道理，养一堆跑的腿子不如自己的腿肉质好。什么盟友，都是喝酒吃菜，跟大佬后面假虎威，想占便宜的杂碎都特么给我滚蛋，乖乖的给我耗材。美国优先的难听是孤立主义，说的好听就是美国开始走向独立自主的道路。当大哥，尤其是唯一的大哥，当美国选择不当大哥，这个世界将会进入一个真正打擂的时代。我们终于进入一个男女相信爱情，国家不相信友情的新时代。
