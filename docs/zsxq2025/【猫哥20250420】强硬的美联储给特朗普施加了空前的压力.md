


# 强硬的美联储给特朗普施加了空前的压力

猫哥原创

4月16日美联储主席鲍威尔发表了前所未有的鹰派讲话，你敢相信，这个所谓的鹰派讲话竟然是严重看空美国经济前景。

对！美联储严重看空未来美国经济。

现在我摘录一下鲍威尔讲话要点：

- 1、关税带来的通胀冲击超过了美联储的最高预期，美联储并没有足够的经验去处理如此高额关税。
- 2、美国的制造业，尤其是汽车行业的供应链可能未来几年内都持续紊乱，这可能导致通胀问题长期存在。
- 3、美国政府为了节省减少科研投入，可能对就业产生重大影响，并可能长期降低美国实体经济的生产效率。
- 4、美国政府债务已经进入一条“不可持续的轨道”。虽然债务危机问题还没有爆发的时候，但政客们关注的是可自由支配支出领域——即除社会保障和医疗保险等福利项目之外的支出，但并非真正的问题。（但其具体真正问题是什么，鲍威尔虽然没有说）——但是我的理解是，美国债务不可持续，而特朗普目前粗暴的搞法不但不能解决美国债务问题，反而可能导致美债出现信用性与流动性危机。
- 5、美联储的首要目标是控制通胀和稳定失业率，即使市场暴跌，美联储也不会轻易降息，更不会屈服于特朗普施加的政治压力——简单的说，就是美联储不会配合特朗普胡搞。

讲话完，全场鼓起了掌声。

如果我们用大话翻译一下鲍威尔的发言就是这三段话：

特朗普现在是胡搞；

因为特朗普的胡搞，现在连美联储也不好美国经济未来，也无法应付未来将产生的经济危机；

美联储不会配合特朗普胡搞，即便特朗普施加压力。

大家注意，鲍威尔演讲之后，赢得全场掌声，这就意味着鲍威尔这段话不仅代表着他个人的看法，而是整个美联储的共识，也就是说，即便特朗普通过政治手段将鲍威尔换掉，因为美联储决策是集体投票决定，一共12票，美联储主席也只有一票，至少7票赞成才能通过相关决策。

换掉鲍威尔并不能改变美联储的集体共识，那么也很让整个美联储决策委员会向特朗普屈服。

还有一点通胀，由于通胀数据，美国CPI3月环比下降0.1%，创2020年以来最低水平，同比上涨2.4%，低于市场预期。当时市场依据这个数据就预测美联储即将在6月降息。

而鲍威尔的话实际就是否决了这个通胀数据的真实性，同时也否定了6月份降息的可能。正是这个原因鲍威尔话一落，美股就大跌。但是现在美联储放开了，明确表示，即便暴跌，美联储也不会降息。

所以，现在的特朗普简直就是老鼠进风箱里两头受气。

对外，与中国相互加了100%以上的关税，这个关税导致美联储表态是“关税带来的通胀冲击超过了美联储的最高预期，美联储并没有足够的经验去处理如此高额关税”（因为特朗普对其他国家目前至少是有90天的关税豁免，在豁免期间只加10%的关税，所以美联储这个高额关税）。

对内，遇到了倔硬的美联储的集体共识——特朗普你这样胡搞连我们我们也看空美国经济，并且没有办法帮你擦屁股。

所以，目前僵的三方，中国——特朗普——美联储，必须至少有一方做出妥协，否则我们就等着看美国爆发前的经济危机，否则这个前景我去年就撰文预测，现在不过被美联储证实而已。

那么未来这不会有一方妥协呢？

我觉得会。

这一方只能是特朗普。

这一点我能看清楚，我相信国家层面也能看清楚
