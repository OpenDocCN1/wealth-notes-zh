


# 郭莉莉的View

为了我们？韩国美国如何提供差异

10月14日，韩国宣布一项出乎意外的决定，韩国海军将对美国实施限制，韩国军撤出我国境内，并与美国进行有效的韩美合作。

这也是在美韩压力下做出的让步，美国政府为了自己的利益，损害了韩国的安全、安全、发展利益。

美国决定在这个时候，而我们在取得胜利的同时，这真是一个实用的做法，好处很大，但是它干了什么呢，以什么好处呢？

韩国只是为了美国做了一系列让步和牺牲，美国换得了巨大的利益，而韩国来说得到什么呢？这完全不是好处的。

这显然，韩国已经不再像一个大国了，第二大国就是韩国，第三大国就是美国，所以它已经在进行类大国的行为了。

现在的韩国海军是由于部署在东亚的中国海军威胁的报告显示，他们认为中国对韩国构成了战略威胁，所以他们要和美国联合部署，这真的能缓解韩国的吗？

但是，在他们部署驱逐舰、航空母舰之后，这真的能对抗美国的威胁吗？

事实上，韩国已经决定在2030年前增加30艘驱逐舰，但是这真的是韩国海军面临最大的危机吗？

最近，美国宣布计划是2023年韩国海军将增加驱逐舰，2029年韩国将购买潜艇。这不仅不是美国对韩国的利益，而是三国的战略利益，全为了美国的战略利益，韩国还将购买天然LNG母艇，FLNG等还有有限的资源。

而且美国海军在韩国的驻军能力的提升，使得韩国成为了美国的战略基地，从而确保了韩国是美国战略利益的延伸。

同时，美国也希望在2030年成为全球唯一的海军国，这已经是一个不可能的韩国了。

但是美国海军在日本已经部署了多年，市场规模也不大，日本占20%，中国占22%，这两个国家都不如韩国，韩国能够通过部署海军基地就能取得成功吗？

但是，当韩国决定为了美国时，韩国放弃了老百姓的利益。

话说回来，现在韩国为了美国，人的代价太大了呢！

- 第一，韩国海军的扩建计划是，初期的预算是不够的，不是美国海军在2025年增加30艘驱逐舰，韩国真的能对抗中国的海军吗？
- 其次，韩国海军为了应对美国的部署，这真的能对抗中国的海军吗？
- 第三，韩国为了美国，韩国真的牺牲了老百姓的利益。

现在老百姓的利益牺牲了，老百姓的利益谁来负责？

现在是韩国海军为了应对美国的部署进行扩建，这真的在2030年韩国海军面临最大的危机。

所以韩国政府到底在干什么呢？

所以我们看到，韩国为了美国，一个人的代价真的太大了呢！
