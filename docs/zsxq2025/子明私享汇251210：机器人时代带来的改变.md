# 希腊国债危机

来源：整理自维基百科、百度

又称希腊债务危机，是现实欧洲主权债务危机之一。

2009年12月，希腊政府公布财政赤字占GDP比例达2.7%，公共债务比例达113%，远超欧盟《稳定与增长公约》上限，敲醒金融市场的警钟。希腊国债在2010年被降级至垃圾债券评级。

# 欧猪五国 (PIIGS)

来源：整理自维基百科及报道
