


# 大宗商品的逻辑与节奏

原创：巴顿比格斯 公众号：巴顿比格斯 25年9月7日

![](img/05537bfdeb8ef09c1c233eca9564728c_0_0.png)

2025年4月以来，中国资本市场在宏观基本面际放缓，制造业PMI连续5个月低于荣枯线、社增增速降至3.7%、A股二季度净利润增速1.3%的背景下，上证指数涨幅接近25%创十年高，走出一轮大牛市。

大宗商品在基本面赢弱的背景下，不少商品却不断创出历史高，两个月时间多铜佳底部涨幅接近100%，而其供给端量仍在持续增加，需求端光伏比增减弱。黄金、白银纷纷创新高，沪银远月合约已经出现10000关口。

股市与大宗商品，这两大类资产价格走势，各有自己的逻辑，也有相同的宏观驱动。比如：第一，中国房地产泡沫风险下降，美国关税不确定性收。第二，美元边际走弱，全球资产受益，人民币贬值预期消失并转向升值。第三，全球进入财政主导+货币支持时期。

股市基于预期主导，上涨流畅，而大宗商品定价，则由供需与宏观定价协同主导，两者表现节奏存在差异。产业参与者看商品，不明里，产业看宏观，云云雾雾。所以，依赖单一因素判断大宗商品价格，无法得出正确的理解。

从历史大宗商品价格运行轨迹中可以发现，大宗商品兼商品属性和金融属性，影响商品的因素众多，核心是供需关系，流动性、美元指数、风险偏好等因素也会产生重要影响。

然不可否，供需关系是影响大宗商品价格的重要一环。供给端更多地反映通过成本约束商品的下行空间，而需求端则更多地约束商品的上行空间。在供给和需求博弈的过程中，率先出现边际变化的一端往往往商品提供走势方向。

如果从整个经济系统来看，大宗商品的价格变化，实际上反映的是经济的根本性变化，因为无论是供需，都是经济变化的结果。经济变化的核心，在于资本配置。大宗商品的研究和交易难度，远大于股市。

## 1. 美国非农数据走弱，这一数据会如何影响美联储降息节奏？对大类资产价格走势有哪些影响？

美国8月新增非农就业2.2万，较7月少达5.7万，并再度下修6月至-1.3万。大佬博文集团分行业大类来看，生活性服务就业新增趋势较为稳定，教育医疗、休闲酒店合计新增7.4万，与5-7月月均（7.5万人）、1-4月月均（7.3万人）基本一致，美国居民服务消费或保持稳定增长；批零交通公用事业大类新增0.2万人，较5-7月平均有所改善。

此前，2025年Jackson Hole全球央行年会，美联储主席鲍威尔明确表示“通过降息呵护就业市场+暂时性忽视通胀上行风险”的意愿。在此背景下，8月偏软的就业数据反而可能通过提高市场对降息的预期（产生影响）。

这一逻辑失效的条件是非农数据继续恶化，比如失业率连续触及及突破4.5%。当失业率接近或突破4.5%，意味着市场实质性恶化，可能触发衰退（预警），届时市场可能会从降息转向避险，风险资产将承压。

统计来看，2025年8月的数据较差，接近95%置信区间下限，但未突破8月的数据不是趋势性恶化。

资产价格来看，市场在降息宽松下，对非农数据反应最大的是十年期美债收益率下行接近XX个基点，不仅是对增长预期的反应，更是对未来融资能力的反应。换句话说，市场在定价美国政府支出还能继续加杆，降息宽松流动性充裕，风险资产反而受益。更差的经济，低的美债收益率，反而有助于政府借钱，推动信用增长，有利于风险资产。

## 2. 上周四指大跌，周五反弹，本周股市的调整是否结束?后续板块轮动与空间展望？

逻辑上，本周牛市动力并未改变：第一，资本作为稳健抓手，政策支持是核心力量；第二，国内端存款发生边界变化，后续不会轻易结束，且居民配置向权益资产转移；第三，宏观层面，海外美联储降息预期发酵，关税逐步消退，同时强化了美元走势，人民币稳定。

结合1971以来美元大幅贬值周期，对全球主要资产影响如下：

| 资产类型 | 平均涨幅 |
| :--- | :--- |
| 黄金 | 76% |
| 铜 | 40% |
| 工业金属 | 强劲 |
| 标普500 | 17% |
| 德国DAX | 7% |
| 日经 | 25% |
| 全球股市 | 4% |

均呈现趋势，即美元走弱，人民币汇率逐步收敛至中间附近，贬值预期已经消失，近期流动性充裕起了积极作用。

## 3. 黄金白银再创新高，白银接近10000关口，后续来看，黄金白银还有多大的空间

节奏上，短期来看，上证指数或完成回踩确认，周线呈现震荡上行，预计预计为3810-3850点，震荡区间3800-3860点。中期看，四季度目标大概破4000-4200点，下方支撑在3750。

长期来看，未来三年，A股会继续挑战015年以前的高点，5000点附近。

大佬文圈对于投资而言，遇到回调就可以加仓，布局宽基指数或者行业ETF避免错过行情，短期关注消费、金融板块轮换。

资金面上，近期上证指数出现缩量放量，成交2.3万以上，缩量意味着散户恐慌情绪不敢入境，只有主力资金护底，市场情绪逐步修复。细分指数表现来看，上证50、沪深300、深成指、北证50均实现反包，反映权重股稳，市场资产受资金青睐。科创50未反包且涨幅不及预期，核心原因是寒武、中芯国际等科技股乏力，说明市场风格从科技领先向板块轮动切换，科技股的单边上涨行情告一段。

黄金依然是确定性较高的商品，中美两国债务驱动的发展模式并没有改变。黄金价格来自两方面的驱动：长期是以货币信用为主线，中短期是对未来的通胀与增长进行计价，黄金周期价格走势与法币债务趋同。债务和货币可以随意增加没有约束，而黄金则存在物理的约束，无法随意增加，正好反映出法币的失控。所以，黄金的长周期上涨是大势所趋。黄金是法币的敌人，价值的镜子。央行配置黄金，实际上是减少对外依赖，增加资产负债表稳定。全球各国央行的资产，绝大部分都是别人的负债。中央政府的国债是政府的负债，而黄金不是任何人的负债，物理稳定，直接确认。

价格区间估，1971年金本结束时，美债余额3981亿美元，彼时国际金价42美元/盎司。2025年9月美债余额37万亿美元，55年债规模扩张93倍，简单推算对应的合理价格是42x93=3906美元，所以即便黄金已经涨接近3600点，后续依然有上涨空间。资产选择方面，黄金股和黄金实物ETF或者黄金期货。

白银，中期来看，黄金上行周期没有结束，白银未来大概将挑战45美元每盎司，沪银已经10000整数关口，但是中长期白银市也没有结束。大佬文圈按照层次突破新高的表现，后续的波动区间会开始，冲高可以开始止涨。

理解白银，需要有更高的站位，不能盯着白银的金融属性或者工业属性，有部分白银的空头觉得白银库存就可以做空白银，上后悔了经验主义错误。白银现在走的是宏观逻辑，价值重估。

黄金上涨趋势信号：第一，全要素生产率大幅提高，比如科技带来生产效率提升缓解通胀；第二，债务得到化解，美元信用回归；第三，全球货币重新回归，比如体后单一货币。显然，这些条件未来无法达到。
