


# 印尼全国骚乱，花人会不会再次遭遇殃？

文/卢克文工作室嘉宾 星海舰长

(花人=华人，兔子=中国）

8月底，一场大规模抗议活动在印尼首都是雅加达爆发，并迅速演化为大规模骚乱，印尼各地火光熊熊，一片狼藉，目前已经造成4人死亡，5人受伤。

本来吧，印尼总统普拉博沃要是要来北京参加9.3阅兵的，现在呢?也得不取消了行程。

那么，这起骚乱到底是咋回事?考虑到印尼“骚乱必屠华”的传统，那么这次印尼花人有没有危险呢？

## 1 一的一切，还要从印尼总统普拉博沃的新政说起。

2024年3月，普拉博沃当选总统，为了兑现竞选承诺，普拉博沃上任制定了一个计划——免费营养餐。简单来说，就是为印尼8300万儿童、小学生、孕妇和哺乳期母亲提供免费的营养餐。

这个计划挺好，问题在于，要花200多亿美元，钱从哪里来?印尼又不是什么发达国家，拿出这么一大笔钱是很困难的。

于是是在2024年8月份，印尼发布《2025政府财政预算草案》，根据新的预算，为了给免费营养餐计划腾出资金，决定减少对地方的转移支付资金。

地方的财政全靠中央的转移支付呢，现在中央把转移支付砍了，地方怎么办?总不能让公务人员都发不出工资吧?那只能办法增加税收了。

于是，各地开始显显神通，在自己权力范围内猛加税，比如酒店税、餐厅税、娱乐税、停车税、广告税、地下水税、非金属矿物和岩石税、燕窝税等等。

地方加税的同时，中央也没闲着，也在加税。

比如，去买音乐会门票、快餐、纸巾、味精和洗涤剂等日常支出，都要加消费税。就这样，印尼成了一个万税万税万万税的国家。

这样一来，老百姓的怒气就大了。

本来吧，这种事情如果是在经济上行期，生活压力会随着经济的发展而被掩盖，但随着特朗普关税战的开打，印尼经济遭遇重创，特别是出口行业，彻底经营不去了。

## 比如，印尼最大、历史最悠久的纺织企业——成立于1966年的PT Sri Rejeki Isman Tbk宣布破产，仅此一事，就导致印尼增加了数万人的失业人口。

不仅如此，今年五一劳动节普拉博沃推出的就业制度改革，也起到了反效果。根据改革内容，要求企业将外包员工转为正式员工。

本来是个好事情，但我们都知道，这样一定会导致企业成本增加，企业为了为了省钱，就会降本增效。所以2025年上半年，印尼失业率暴增，再加上高涨的生活成本，印尼民间已经如同一座火山一样乱了。

在这种环境下，印尼的互联网上开始流行“草帽旗”活动，简单来说就是把《海贼王》里面的“草帽旗”挂出来，代表自己对自由、正义和反腐败的追求。

政府原本对这种行为艺术也不管，但到了8月份，情况变了。

8月17日是印尼庆节，普拉博沃呼吁全国在8月悬挂国旗，但印尼民众开始整整活了，挂一面国旗，挂一面草帽旗，结果草帽旗和印尼国旗一起飘扬，图片和视频在社交媒体上大量传播，实有碍国际观。

这一一下子，很多官员坐不住了，就让警察去抓草帽旗的人。

结果，一下子把民众给惹火了。“我就是喜欢动漫《海贼王》，挂个动画里的旗子而已，违法？不违法！你凭什么抓我？”

于是，是一个名为PATI社区联盟的互联网群组，开始鼓民众上街游行，然后对游行进行全程直播，煽动更多的人上街。

终于，在8月13日，游行抗议者与警方爆发了直接冲突，多人受伤，冲突通过直播传到了全印尼，引发了全民愤怒。

不得不说，当愤怒渗入群体之后，带来的破坏力是惊人的。有人从去年那份《2025政府财政草案》中，发现了关于议员住房补贴的大瓜!此前，印尼议院取消了议员专用住房，作为补偿，议员每月可领取6000万尼比（约合人民币3万元）的补贴。

6000万尼比是啥概念?是雅加达最低工资的10倍，贫困地区的20倍。民众彻底愤怒了，“你说给女性和幼儿搞免费餐，我没意见，但这些钱为什么要从穷人身上剥削？不能从议员钱里流出来吗？谁知道议员住房补贴应该是应的，但这种补贴手舞蹈，更是让民众破了大防。”

于是，抗议人群迅速从“草根”拓展到了底层人群之中，提出了更为明确的诉求：
- 提高最低工资
- 废除“就业法”
- 建立反腐机制
- 追究腐败

游行队伍急扩大，开始放火冲击议会，并与警方发生了冲突。这个时候，一个意外发生了。8月31日，抗议活动期间，一辆警用装甲车辆撞到了司机阿凡，但警察并没有停下救治，而是导致阿凡死亡。

这个场景被无数手机拍了下来，四处传播，本来就激动的民众心头上又浇了一把油。于是，抗议活动迅速演化为全国性的骚乱，雅加达、泗水、万隆等地开始攻击警局，就连政务大楼都被烧了，烧死了5个公务员。

偏这个时候，还有很多嘲的议员，比如议员Ahmad Sahroni嘲讽示威者为“世界上最蠢的人”，议员Nafa Urbach说住房补贴应该是取消的。很快，印尼网民疯狂跑到议员家里，抢走了价值百万的爱马仕包、名表、隐藏版洗衣机、微波炉、浴室等。

这一一下子，印尼议员和高官人人自危，纷纷跑路到了新加坡和澳大利亚，印尼议会处于瘫痪状态。

面对如此严峻的局势，总统普拉博沃坐不住了，被迫在8月31日取消了来北京行程，随后发表了全国电视，算是释放了一些态度。普拉博沃说，向骚乱中不幸遭遇的司机阿凡及其家人致以深切哀悼，承诺政府会为其家人提供支持与关怀。同时，严厉批评执法过当行为，要求对事件彻查真相，若执法人员存在违法违规，必将依法追责。

除此之外，普拉博沃还承诺强调民众和平权利，同时要求依法处理违法行为（显然指的是挂草帽的行动）；同时决定撤销部分议员资格，国会领导层也宣布取消了住房补贴。

当然，普拉博沃也强调，部分抗议已演变成严重暴力与破坏行为，如焚烧公共建筑、攻击警局等，这已超出合法表达范围，属于刑事犯罪，必须严肃处理。

显然，这就是胡萝卜加大棒。

## 2 这一次，这次印尼骚乱，从根子上来说，还是积压的社会矛盾引发的。

印尼的腐败问题，最早可以追溯苏哈托时期，那时候侯商勾结、裙带关系几乎是公开的，腐败达到了顶峰。

虽然1998年苏哈托下台后开始了民主化，但整个社会统治体制还是苏哈托时期建立起来的，复杂的政关系，官员和富商之间盘根错节的利益链，可以处处滋养着腐败，根本不是搞个舆监督、设立个反复机构就能搞定的。

虽然普拉博沃高举为民的大旗，以下下层普通百姓的利益代言人而自居，但整个国家的体系都这样了，他又能如何呢？更何况，就连普拉博沃自己，不也是这个体系的一环吗？毕竟他的老婆，就是苏哈托的女儿。

这个体系自我循环、自我繁殖，靠着把控国家经济命脉，拿走了利益分配大部分蛋糕，只给印尼贫老百姓留下了内核糟，老百姓怎么可能没意见呢？

当人们都活下去的时候，你再加税，也别怪民起来造反了。

当然，虽然这次骚乱有印尼自身的原因，但如果仔细观察，也不难发现幕后是有黑手的。从印尼骚乱的情况看，颜色的味道还是很浓。比如，颜色革命都有一个代表性的标志物（玫瑰、郁金香、口罩等等），而印尼却有“草帽旗”。比如，颜色革命都有一个“去中心化”的者，PATI社区联盟、“全印尼学生联盟”、“GeayanMemanggil”等组织和NGO，他们实时分享，利用加密软件制造出谣言。比如，颜色革命往往带有冲锋的指挥，现场发现了可疑的蒙面人，手持武器，甚至抗议者砸了一天。

你看，这不是颜色革命是什么？因为兔子已经对比了。2016年时，印尼政局不稳，大量华人遭遇人身财产方面的威胁。这时，兔子海军的052郑州舰突然抵达印尼进行友好访问，局势就平息了。如果印尼政府再想牺牲华人来压抑自保，兔子30万吨的海军也能让印尼的政客冷静下来。

所以，印尼华人做的就是做好防范，尽量不要参与骚乱，免受其殃，其他的安全问题交给祖国就好了。哪怕血统再稀释，祖国认同再淡薄，兔子永远是他们的坚强后盾。
