


# 城市化的扬点：谈谈中央城市工作会议
猫哥原创

按：本篇为7月22日公众号付费阅读文章，同步分享至知识星球。

7月14日—15日中央城市工作会议在北京召开。

中央城市工作会议建国以来一共就召开了5次，最近一次是2015年，时隔十年之后再次召开城市工作自然意义重大。

那么中国城市未来将怎么发展？未来城市建设会有哪些变化？哪些城市未来更有潜力？哪些城市的资产值得长期持有？

把这场城市工作会议的核心精神搞清楚了，以上问题的答案自然不言而喻。

在分析这场会议之前，讲一讲几个重要的大背景。

## 背景1:西部开发。

西部开发是近二十年大家都耳熟能详的主题，那么大家是否知道西部开发顶层设计的思路是什么？

简单的说就是压制发达东部地区人群聚集，加速落后西部地区建设。

怎么压制东部沿海地区人口聚集？

就是控制发达地区建设用地指标，提高东部地区成本。

同时对西部内陆地区建设用地指标大管饱，快速提高西部地区基建水平。

这样，去东部地区打工人因为当地房价高，就只能回老家置安家。

这样不仅可以快速提高西部地区城市化水平，同时因为西部地区基建的改善，通过招商引资，可以接东部地区产业升级后淘汰的落后产业，实现我国全产业链纵深的梯度配置，建立国内经济内循环，最终实现共同富裕。

西部开发就是在这种顶层思路下提出的。

不得不说，这是一个宏大的颇具气魄的顶层设计，但是十多年实际执行效果却不是很理想。

因为卖地搞房地产来钱太快，所以西部内部地区很多地方政府工作重点不是去抓实体经济，而是大搞房地产，或者撤县设区，或者大搞新区建设。

一栋栋高楼大厦拔地而起，各种城市公园美轮奂，却没有足够的人口填进去，新区成为空城、死城。

为工业配置的开发区也是味贪大求全，大量资金砸下去，招商引资一团糟，根本就没有引进几家企业入驻，基础投入就没有获得合理的回报。

最后中西部基础设施水平是取得长足进步，但是同时也给地方留下了大量的债务，资源配置效率常低下。

所以，这种情况下必须进行整体性的纠偏。

## 背景2：城市化已经遇到瓶颈。

十年前召开城市工作会议的时候，当时我国城市化率大致是55%左右。

城市化潜力巨大，整个国家处于一个快速城市化的时期。

当下，我国城市化率按照户籍人口计算已经接近70%，如果加上流动人口，城市化率已经超过70%。

简单的，我国城市化目前面临的主要问题就是——农村已经没有多少剩余劳动力可以剩余城市，城市化已经遇到瓶颈；

- 房地产市场急萎缩，土地卖不动了，地方财政面临巨大缺口；
- 现有人口快速老龄化，生育率急剧下降，人口增长已经面临严峻；
- 地方债巨大，不仅过去那种依靠负债发展的模式已经难以为继，未来怎么解决地方债务也需顶层设计给出一个可行的思路。

所以，在当前当下，我国城市工作未来应该怎么做，就必须要求国家层面给出一个系统性的全面方案。

近期中央城市工作会议就是在上述背景下召开的。

首先，参加本次中央城市工作会议的阵仗非常强大。

中央层面，党政军、中央部委、部分高校主要负责人全部出席；

地方层面，省级负责人、省城市负责人、部分市级负责人统统参加。

这么多人参加的会议，目的只有一个：就是要将中央关于新时代城市工作的精神与原则原汁原味地传达到基层城市工作的各个层面，让中国这个庞然大物一样的巨轮经济体，在城市工作掉头转向的时候效率更高。

接下来就是未来城市工作的核心思路：上述描述我们浓缩一下，就可以得到未来城市工作的第一个主题：严控增量，盘活存量。

所谓的严控增量意思就是，城市化扩张会被严格控制，未来除了极个别城市，城市扩张基本不会允许。

包括不限于撤县区来扩大核心城市区域，设置新区或者开发区扩大城市范围等过去各种扩张城市的模式未来系统都会叫停。

简单的说，就是现有的城市规模已经足够了。

在出生率下降、未来十年人口负增长叠加农村已经没有多少剩余劳动力转移给城市的大背景下，现有的城市规模确实足够了，如果再进行各种大规模的城市扩张就是资源的浪费。

所谓的盘活存量就是，以有限的资源投入，提高现有城市现代化水平，让资源配置更高效。

在严控增量，盘活存量主题下，未来城市建设会出现以下变化：

- 大规模铁公机建设已经结束了，传统的老基建成为历史：以5G基站、光纤、充电桩、算力中心等代表的新基建会替代老基建；
- 西部大开发建设基本结束：西部地区未来国家财政会重点聚焦到成都城市带的建设(理由我们后面来讲）；
- 城市轨道交通建设会严控：未来确实有经济效益的轨道交通建设才有可能获得国家的审批，实际上有经济效益投资有回报的城市轨道交通之前已经基本完成。也就是说，目前没有经济效益的轨道交通可能永远停，主要原因就是轨道交通建设投资太大，盲目建设会给地方带来巨大负担。
- 高层建筑严控：特别是地级市、县城等城市未来基本不能批准超过100米的高层建筑，未来城市建设主题就是让房子矮下来，品质起来。
- 大规模拆迁基本结束：对于老旧居民区，国家会用“微改造”形式进行改造（包括装电梯、修复外墙、改造水网、增加停车位等等），提升老旧小区配套水平。
- 城市规划更注重人口与产业协同：过去很多城市搞新区，没有产业配套，大多变成鬼城，这个教训太深刻。
- 环保与生态治理加大力度：比如空气治理、水源保护等方面，大城市已经做得很不错，但是中小城市还有短板要尽快补上。

## 加速构建发展模式

这段描述里有两个关键词，一个是“加快”，一个是“新模式”。

### 何为发展新模式？
过去传统模式是什么？政府卖地获得收入，开发商卖房获得利润。未来整个城市都要严控增量、盘活存量，在这个趋势下构建发展新模式：未来开发商要从卖房转型到经营房，对于地方政府而言，同样从卖地获取收入转型到收取房税。

## 城市主题

未来城市工作第二个主题就是：城市群与都市圈。

过去我国城市建设是全面铺开，特别是西部开发，一把抓，结果效果不太好。城市建设与发展有固有规律，违背这个规律是要买单的。这个基本规律就是城市建设还是要人口走。人口净流入的城市建设即便投入一点也不会亏，但是人口净出的城市，投入再大也留不住人。

## 着力优化城市体系

所以，要着力优化城市体系。

### 怎么优化？
未来中国建设重点的城市群有：
- 京津冀城市群辐射东北与内蒙古
- 成渝城市群辐射西北与西南
- 长三角与珠三角是中国经济火车头

如果说过去我国城市建设是全面铺开，未来就是重点建设。上述四个城市群属于“组团建设”，在这四个城市群之外，大致是以省城市为中心的“网络化”城市群。“组团建设”的城市群本身对人口有很吸引力，国家财政会持续投入。除了这四个城市群之外的网络化城市群，国家财政投入就会小得多。

### 分类推进以县城为重要载体的城镇化是什么意思？
大致意思就是，大城市就业机会多，但是不宜聚集太多人口，所以更合适的模式就是：年轻人去大城市打工，但是还是要留在县城住。这种模式国外也是成熟案例，比日本：东京就业机会多，但是房价高，所以日本年轻人很多选择就是在东京打工，但是在东京附近的县城居住。比如北京周边的廊坊、上海周边的苏州、深圳周边的东莞、惠州，成都周边的卫星城市等等。

目前制约城市圈做大做强的瓶颈是什么呢？主要还是城际交通建设还不够，里面的主要原因是牵扯不同城市利益分配以及基建出资比例的问题。未来国家要做强大城市群与都市圈，那么国家财政在传统的基建层面就会聚焦在城际交通上，让大城市与小城市通勤更便利，通勤时间更短。

城乡县未来会有两种模式：
- 一种是组团式的，主要的代表就是上述四个重点城市带；
- 一种是网络式的，代表上述四个城市之外的城市群。

整体而言，组团式的城市带依托国家财政重点投入，发展机会会更好。

另外，按照目前城市工作的思路，地级市处在一个比较尴尬的位置。地级市上面是省级城市，那是未来城市群的核心；地级市下面是县城，这是未来作为“重要载体”的建设对象。

## 地级市怎么办？或者说地级市未来怎么定位？

个人认为，未来地级市产业发展以及对人口的吸引力是决定地级市建制能否保留的必要条件。你产业搞得好，能吸引人口聚集，你就留下；你产业搞不好，人口用脚投票离开，那就很有可能撤地县。一切都是市场说了算。

最后我们总结一下。未来城市工作指导原则就是城市建设与发展的资源投入问题更多的交给市场与人口来决定，行政干预更少。藏二八一八三六六三八四五。
