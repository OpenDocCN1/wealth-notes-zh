


# 猫哥 251206：委内瑞拉会不会成为第二个叙利亚？

2024年11月底，短短十来时间，统治叙利亚20多年的巴沙尔·阿萨德政权轰然倒台，让全球关注。1年后后的今天，委内瑞拉马杜罗政机会不会重蹈覆辙？本期内容我们结合当下情况，聊聊这个话题：

估计有很多人认为，马杜罗会成为第二个叙利亚萨，脑洞是不是得开了有点大？

毕竟马杜罗一直都被誉为拉美地区的反美战士，手上握着十万正规军和几百万民兵组织，还有委内瑞拉的热带雨林、山地作为屏障，虽然手上那点可怜的装备在老美面前还不够，但凭借武装人员的规模和复杂的地形，怎么也够美一壶，不至于步后阿萨德后尘，选择跑路吧。

理论上，持有上述观点的并没有错，是目前的主流观点，而且老美在委内瑞拉家口舞刀舞剑已经三个月了，退还还不不敢狠手也是事实。

但实际上呢？个人认为，这个观点的底层逻辑是有问题的。

为何这么说？

我们先看老方面：

首先，大家认为普川选择派兵实际占领委内瑞拉进行一场近身肉搏战吗？如果普川就是这个目标，那没啥话说了。

但如果不是呢？至少我认为，普川围困马杜罗，目标很简单：

其一，觊觎委内瑞拉的石油资源。

其二，重新启用“门罗主义”，控制拉美。现在的美国的趋势是收缩，但收缩也有底线，就是对自己的后花园，还是要有影响力和控制力。

鉴于占领委内瑞拉，想都不想，因为后面还要治理，老美不是圣母，它不会越这水。

也就是说，虽然占领委内瑞拉对我们来说，是最美的剧本。答案很明显——不会。老美目前的国内经济环境和中美博弈的态，它根本不敢贸然深陷委内瑞拉这个泥潭。不要认为五角大楼和白宫哪些顾问都是吃干饭长大的，会让老美富的剧本重演。

所以，老美现在的策略很清晰：

派兵封锁委内瑞近海，单方面宣布关闭委内瑞领空，摆出一副“关门打狗”的架势，让委内瑞拉自乱阵脚。然后，留2个后手时刻威胁马杜罗：

其一，考虑用导弹执行斩首任务。

其二，派遣小股力量，渗入委内瑞拉境内执行抓捕或击杀马杜罗的行动。目前有消息称，美国中央情报局和特种部队已经就到位，随时准备绪。

所以，如果按老美的策略发展下去，实际上马杜罗手上的军队和地形，并没有多大的武之地。我能打你，但你打不到我。老美可以用小的代价，颠覆委内瑞拉政权。

这里很多人可能还有一个疑问？

这2个后手，都必须有前提，那就是需要取得情报和当地局势支持，否则怎么搞空袭斩首？怎么地面渗透呢？

这里就说说马杜罗方面：

虽然马杜罗对外，一直树立的是强人形象，但实际上外强内干，内部早就疮透了。

有民调显示，约7成民众对马杜罗政府是不认同的。虽然我们可以不信民调数据，但委内瑞拉国内经济烂得不能再烂的现实，摆在在那里。

在这种情况下，国内民众支持率会有多高呢？

它就是一个独裁政府，不要把疑惑精力拔得太高。之所以马杜罗能够维持住目前国内局势，其核心抓手是将石油等经济命脉与军队捆绑，形成利益共同体，其中拿大头利益的还是被高层拿走了。也就是说，马杜罗政府的国内权力结构，所呈现的特点是“上层稳固、中底层松散”的局面。

缺乏民众支持，又有反对派从中搅扰，老美通过围困制造压力，再大把美金政策反中低阶的部分军队，想要获得情报，控制股份部队渗透，那不是拿捏摆的事吗？

所以，我们回头再看老美的策略和马杜罗困境就清楚，所谓的手上抵抗老美的资本，对委内瑞拉的控制牢固，实际上相当脆弱，其个人也是彼得一批。

12月4号，《纽约时报》援引人士就报道，马杜罗在每晚睡不同的地方，并且不断更换手机。这个消息是否准确属实，虽然要打一个问号，但是从客观环境和逻辑来审视，应该八九不离十。

至于外援方面，虽然会有，但我认为更多的也是象征意义。大鹅现在自顾不暇，距离我们又太远了，而且目前来说，中美处于休战阶段，只要老美不是采用实际占领为目标，外援很难对马杜罗给予足以影响战局的支持。

其它不说，叙利亚阿萨德与中俄的关系如何，想必应该比马杜罗好得得多吧，后面怎么样？

实际上很多时候，如果自己都不能自救，那希望于外援，就属于妄想。大佬集团也因为如此，委内瑞目前的局势对马杜罗来说是相当危险的，并不是主流观点那样的乐观。

想象着美军下场，马杜罗拼死抵抗，把战争拖延它三个载，然后我们坐收渔翁之胜利。

实际上，在这方面，美俄双方都清楚，并且目前马杜罗已经在上手准备后事了。

聊聊马杜罗和川普的那通电话。

大致是在 11 月 21 日左右，据说这通话是由卡塔尔、土其等等旋下启动的，川普在电话中表示，1周内要马杜罗立即辞职，就能保证他、他的妻子和儿子安全离开委内瑞拉，否则将面临军事打击。

而马杜罗方面给出的条件主要要涉及 3 点：

- 1. 要求对他和核心成员进行全球赦免，包括解除制裁、终止国际刑事法院指控。
- 2. 保留军队控制权。
- 3. 成立临时过渡政府，18 个月内选举。

虽然，马杜罗开出的条件看似是延延战术，为自己争取利益，同时留后手，但本质上就是立场波动。川普是一个精明的商人，深谙交易之道。马杜罗只要立场坚定，内心出现波动，就会死硬撑。

所以，马杜罗提出的这些条件川普当场拒绝，然后宣布关闭领空，部署力量深入委内瑞拉，老美通过围困施压，是不是来了。

还没完，马杜罗近日与川普谈时，他还说这次对话在语气上是相互重的，这是一次诚实的交流，双方朝着相互尊重。说实话，当我看了马杜罗的表态后，忍不住笑。

老美挂电话，准时关闭领空，这算是输吧。马杜罗不是反美战士吗？不是硬派吗？更打算软，甚至会引起连锁反应。至于这通电话，现在看来成了一道题，川普打算收拾马杜罗了。

所以，我认为马杜罗成为第二个叙利亚阿萨德不是可能，而是可能性增加。马杜罗是独裁者，对我们有什么影响？

要说影响，那有点，但要说影响有多大，根本谈不上。因为我们能源战略已经实现了多元化，在委内瑞拉的投资布局也少得，未偿的债务也不多。对于我们而言，委内瑞拉连暗助都谈不上，起到在拉丁美牵制的作用。

未来不管谁台上，发展经济都是首要任务，否则坐不稳，到时候就留老美自己收敛。阿根廷就是一个典型的例子，之前美莱对我们有利，现在还敞拥抱我们。

而且，美国的强硬干预加拉丁国家对“门罗主义”回归的担忧，促使它们更加积极地寻找与我们合作，实现战略平衡，这未尝是机遇。

要知道，老美已经不是90年代中东海湾战争时如日天的老美了，那时的老美只要戳个牙，中东一群爷都要罢，你看现在呢？

所以，老美要在南美拔钉子，过程一定不会轻松。中美博弈，东升西可是这个时代的主旋律，不会因为一个委内瑞拉马杜罗影响历史的进程，我们需要做的，就是干好自己的事，静静等待发展即可。
