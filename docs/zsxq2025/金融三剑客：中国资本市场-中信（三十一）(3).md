


# 资本市场—中信（三十一）

## 一、跟点

他们说，怎么可能成为领导眼里的人呢？很简单，按N，你N，按M，你M，如他按了N，他想按M，结果成了N，或者其实他应该是N，结果决策了，按了N。这个时候，你就要得出一个提示框，让他二次决策。

你注意，是任何情况下都弹提示框，否则你比他还不如，在他们眼里就是冒气的你了（除非向领导来转你）。所以，你这样清楚：只有他按了，他决策了的时候，你就会提示框，其余时间，你按什么（权力的通性：如曾使得）。

那别人说就会，这不是我比他还高吗？

你当然要比他高，否则你算真正的人才？各位领导带过球吗？你无论在什么位置，用什么姿势接到球，很像去抢他的球一样，这能让你做到的自己最好，最能发挥优势的姿势去抢。

你而哗哗的跑去抢，被他按左右调整，每次接不好，又能差一点，最后，用一分之差错错。见过作家打印篮球的视频（一群球队高手被踢回固团？）那你告诉我，你和我到底才是人才？

真相就是：人和之间，不是那个真正的人分大小，而是稀缺性。

你有人才，但才的人多了了，羽毛球冠军在健身房当教练的多的是。到你的人才稀缺，而是你的权力够，你最好心里有点数。

如果你是奥运冠军，他只是个村长，你还会陪陪他打球吗？如果你是个健身教练水平，你是你们的老大，你不愿意打他的。我是比他高更好的，上着陪陪他的的。

所以，你作为价值，比自己上司高不是正常吗？

人类已经占了生态位，是防守一方，你一个没地地的，是进攻方。孙子兵法云，十则一，之则不胜。

什么意思呢？如果你自己拥有五悟的水平没有，你还指望出人头？你当你是虎戏的哈那斯萨，清清交浅的应该培养哥们，都是吃荒的

所以，领导按了，或者决策了的时候，你得弹出二次决策，是作为人才的基本要素。做到这个行就好了？非，从这里开始继续下去。

## 二、分类

低绩效的键盘，他的提示框里面会写，领导你按了，领导你决策了，原因如下123，请您重新选择。

高薪的键盘，他的提示框里面会写，领导，

对不起，你才没留留，没听清楚XXX不是M，我记得您指过XXX，然后用曾经说过的话（对，不要修改意见的），请出来。

重点来了，曾经的周夫对比林君就是这样的意见。一搞错，周夫就会立刻把相反的意见，断在头上，说是没错过XXX，请再对错。

正确的意见永远来自自己，周夫永远是个小学生小学生。这就是高商的键盘，周哥知道自己错了，他就知道周夫是在提示自己，更知道周夫的局大，他在维护周夫的权的。

当决定生效时你来执行的时候，千万不要错一次。要确保对，每次都不能错。有些人是自作聪明明清楚，说你没领导五级的水平，就不去查那个人，明白吧。最愁的是，low就是你为误导了别人，实际上是你自己误导了。真正的人才是准确率，而不是溜得意的。

直白点说，领导给你2000次意见，你只能弹出一个提示框，恰好是他那次，那你就是领导的“准人”，再加上方法来，你就是领导的准人，是周夫可不是，就是高商人才。

真正的人才是准确度（准人才）+高商情（方法方法）

真正的人永远掌握了事物运行的客观规律，以及用科学的方法可以实现的人。

如果领导给你2000次意见，你弹出50次提示框，里面一次就是误导了，其实都是你自己弹。对不起，领导里的，只是个不安，爱表现的极品，你的排序还没过那个来弹提示框的庸才（你还不如做个脑子的被被骗的工具呢）。
