


## 4.17 递归（进阶）

什么是递归？函数是可以自己调用的函数。

递归（进阶）

一个递归函数通常包含三个部分：参数、返回值以及递归调用。在递归调用之前，必须先判断某个条件，以决定停止递归，否则程序将陷入死循环。

```python
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)
```

上面的递归在计算波那那契数列时效率很低，因为存在重复计算。我们可以使用记忆化优化。

```python
memo = {}
def fib(n):
    if n in memo:
        return memo[n]
    if n < 2:
        return n
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]
```

递归的应用场景非常广泛，比如二叉树遍历、快速排序、搜索算法等。

## 4.18 二叉树遍历

二叉树是一种特殊的树形结构，每个节点最多有两个子节点。

二叉树遍历主要有前序遍历、中序遍历和后序遍历。

```python
def preorder(root):
    if not root:
        return
    print(root.val)
    preorder(root.left)
    preorder(root.right)
```

前序遍历的顺序是：根节点 -> 左子树 -> 右子树。

```python
def inorder(root):
    if not root:
        return
    inorder(root.left)
    print(root.val)
    inorder(root.right)
```

中序遍历的顺序是：左子树 -> 根节点 -> 右子树。

```python
def postorder(root):
    if not root:
        return
    postorder(root.left)
    postorder(root.right)
    print(root.val)
```

后序遍历的顺序是：左子树 -> 右子树 -> 根节点。

## 4.19 动态规划

动态规划是一种解决复杂问题的方法，它通过将问题分解为简单的子问题来解决。

动态规划的核心思想是重叠子问题和最优子结构。

常见的动态规划问题包括爬楼问题、背包问题、最长公共子序列等。

```python
def climb_stairs(n):
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

上面的代码展示了如何使用动态规划解决爬楼问题。

## 4.20 贪心算法

贪心算法在每一步都选择当前最优的选择，以期找到全局最优解。

贪心算法并不总是能找到全局最优，但在某些问题中它是非常有效的。

经典的贪心算法例子包括哈曼编码、Dijkstra算法等。

## 4.21 回溯

回溯算法通过搜索所有可能的解来找到问题的解或解。

回溯算法通常用于解决数独问题、皇后问题等组合优化问题。
