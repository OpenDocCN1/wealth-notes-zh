


# 五年一轮的私有化冲击

发布时间：2025年11月6日

中国每隔五年，就是制定五年计划的那年，伴随着私有化的开启，都会出现一轮引发全国热议的“郭顾之争”。

2005年的标杆，是鲁能私有化大争；2010年的标杆，是支付宝和高铁的私有化大争；
2015年的标杆，是万维私有化大争；2020年的标杆，是蚂蚁金服私有化大争；2025年的标杆，是娃哈哈私有化大争。马云一己之力独占两次，也不得不感叹他就是中国私有化的急先锋。

跟美国类似，每一次制定规划，都是矛盾不可调和的冲突。2005年伴随着的是Public Interest和和021社保案；2010年伴随着的是刘唯军“Little Red House”和0577汽车组事故；2015年伴随着的是斯波和限制非理性对外投资；2020年伴随着的是Little Red House、反垄断、房地产三道红线。

## 郭顾

来源：整理自维基百科

指中国台湾学者、经济学家邱和平和中国企业家、格林肯集团创始人顾唯军的一系列争论。

该争论始于2004年8月9日，时为香港中文大学教授的邱和平在复旦大学发表演讲《在“国退民进”的盛宴中狂的格林肯霍尔》，邱和平在演讲中指责顾唯军以“七大劫”谋取国家的利益，兼批判中国的产权改革及市场化。13号，顾唯军聘请律师向邱和平起诉，控邱和平“诽”自己。后演变为一场两人为中心的一场社会经济争论。

郭顾直接影响了中国的国有企业改革。2004年9月14日，国国资委发布《关于企业产权转让有关问题的通知》，进一步规定了转让企业国有资产涉及上市公司股权性质变化的操作办法。

# 谁的鲁能

来源：《财经杂志》2007年第一期

很少人知道，鲁能年前已并非国有企业，主要由具有垄断地位的电网系统职工控股；注：鲁能集团的前身可溯到国家网山东电力集团旗下属于“三供产”企业，曾为职工持股的集体企业。2003年初，在鲁能集团的职工持股已一切就绪之时，《21世纪经济报道》发表“鲁能暗推民营化——31亿元资金控制360亿资产”一文，引发热议。）

更少人知道，今天的鲁能，已经完成了惊险的一跃：在内部严密运作之下，职工退股已经基本完成，两家位于北京的私人企业——北京首都能源集团有限公司和北京京源联合有限公司——已获得鲁能集团91.6%的股份。

2006年12月，鲁能清退职工股并引入两家私人企业股东的情况被反映到国务院，请求查清这一事件中可能涉及的“腐政问题”。
