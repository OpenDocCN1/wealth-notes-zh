


# 米联储见闻20250714——白鸽之白谁与邻

今天，沪市在反复确认了3500点之后出现了一波小幅上涨，大家以为3500点会是折返点后，A股反而一路高歌的持续上行。从3300到3500点，仅用了15个交易，在大家都盼着调整的预期中轻松跑了200点，不知不觉中，便宜的筹码被人拿走，而想要等待回调低价筹码的事情一直没有发生。大家看到一个逻辑，那就是兔子工业实力全球第一这件事已经是一个明牌，是一个熟透的事实，只是因为认知差的问题，还存在信息差。对于资本来说，任何可以说励志故事的资产都是值得拿来利用的融资工具，是让资本可以获取收益的载体。A股迟迟没有上涨的核心原因只有一个，就是能够推动A股上涨的资本还没有够低价筹码，所以在此之前，说故事不能大力；其次，就是他们只想利用兔子故事赚钱，并不想真的让兔子故事变成现实，所以真正的爆发点不在路上，而在顶峰处。

持续打击兔子的工业实力是美西方发达国家未来十年甚至更长时间里的首要任务。对他们来说，既要吃到兔子工业实力带来的资本红利，又要让这种实力不具备延续性，甚至要利用资本的力量让兔子的工业实力由盛转衰，才是一举两得的事情。资本除了盈利的天性，还有寄生的本能，宿主是必须要被牺牲的。所以，当欧等西方国家与兔子进行工业实力的竞争成为明牌，A股的机会就会慢慢显现。

今天上午，海关总署发布了2025年上半年进出口情况。今年上半年，兔子货物贸易进出口21.79万亿元，同比增长2.9%。其中，出口13万亿元，增长7.2%；进口8.79万亿元，下降2.7%。今年6月，兔子以美元计价出口同比增长5.8%，以美元计价进口同比增长1.1%，进出口数据均超过预估。外贸规模站稳2万亿元台阶，创历史同期新高。

从季度走势看，二季度进出口同比增长4.5%，较一季加速3.2%，连续7个季度保持同比增长。上半年，兔子对190多个国家和地区进出口实现增长，贸易规模超过500亿元的伙伴数量增加到61个，比去年同期增加了5个。在对欧盟、日本、英国等传统市场实现增长的同时，新兴市场贡献了更多的增量，上半年对非洲进出口1.18万亿元，增长14.4%，对亚洲进出口3572亿元，增长13.8%。

最新一期兔子海关贸易景气调查显示，出口企业和进口企业信心连续两个月回升。上半年，兔子对美国进出口总值为2088亿元，同比下降9.3%。其中，出口1555亿元，下降9.9%，进口5303.5亿元，下降7.7%。受普普关税战影响，中美贸易由第一季度同比增长转为第二季度同比下降，降幅达到了20.8%。所以，进入五六月后，零售终端行业感受到了前所未有的压力，这也是特朗普关税战的具体威力传导的结果，很多现金不足的中小企业加速淘汰，其中的影响是非常具体的。

日内瓦、伦敦经贸会谈中，中美贸易利面影响有所回升，6月份进出口值从5月份的3000亿元回升到超过3500亿元，同比降幅也明显收窄。所以，现在对企业来说，活下去真的是很困难的事情。很多企业可能经过半年运营，发现辛辛苦苦几乎不挣钱，所以下半年变得尤为关键。如果熬得下来，一年还有些利润，那么明年还会继续坚持；如上半年不挣钱，下半年形势没有变化，则年底又会洗掉一批企业，导致一波失业，从而让明年的经济压力更大。因此今年下半年，尤其是美国方面的博弈得尤为关键。

上半年对共建一带一路国家进出口11.29万亿元，增长4.7%，占进出口总值的51.8%，去年同期提升0.9%。其中，对东盟进出口3.67万亿元，增长9.6%。同期，对欧盟、韩国、日本等进出口都实现了增长。但也可看出，增长幅度在减少，增长越来越困难，尤其是日欧现在逐渐逐步抵触兔子的工业产品，有能力的国家纷纷把夺回制造业和工业实力作为国家的战略目标。

最近日本制铁的掌门就喊出，不认兔子钢铁世界第一的地位，并发誓要在十年内让日本的钢铁重回世界第一的位置。

中日在钢铁制造领域从合作伙伴到竞争对手，怨情仇40年。日本制铁退出宝钢的过程，双方结下了不小的梁子，一别不相宽，各自自生嫌隙。那边厢，日本制铁完成了对美国钢铁的收购，日本制铁会长桥本英二表示，将通过向美国钢铁派遣日铁的技术人员，保持世界第一的开发能力，维持日本制造业。未来会继续推行进攻经营策略，十年内要让日本钢铁重回世界第一的位置，日本想要重新夺回工业巨头的野心已经按不住了。

日本制铁在拿下美国钢铁这件事上看到了美国制造业的窘处，极大的增强了日本铁重建工业实力的信心。虽然美国政界对日本铁收购美国钢铁持否定态度，但最终他们发现日本铁与美国钢铁联手是美国钢铁实现重建的唯一办法，如果无法实现，当地经济也将遭受打击。如特朗普也不允许日本铁收购美国钢铁，对日本铁来说，通过改造美国钢铁，让日本制造业实现世界第一，日本铁希望通过走出去来加强自身能力。他们已经将数百名技术人员派遣过去，用自己的技术帮美国解决目前的工业瓶颈。在半导体相关领域，变压器的尺寸越大，效率越高。

此外，混合动力车和纯电动汽车都需要电机，但美国缺少高性能电磁板，这或许是日本铁可以为美国解决的地方。对于美国在制造业方面的优势，日本铁有一种天然的鄙视，他认为在钢铁行业中，美国作为兔子的对手是最具威胁的存在。实际上不可否认，日本铁的了解远胜于美欧，所以日本铁必须采取主动措施，抑制兔子的海外拓展，尤其是在印度市场，还有泰国。

日本方面也担心泰国将像越南和印度尼西亚一样落入兔子企业的控制之下，现在是需要挽回损失的时候。为了确保在十年后日本铁成为赢家，日本想要恢复到世界第一的地位，必须在美国、欧洲、印度、泰国这四大主要市场上确保生产基地，推进增产，目标是十年后达到粗钢产量1亿吨。

显然，日本想要借助这一波特朗普发起的强制策略，成为渔翁得利者。日本甚至希望通过兔子的低价攻势，让这些国家的制造商处于非常困难的境地，出现企业破产，然后让日本铁收购。实际上，美国钢铁的收购完美实现了日本方面的预期，因为兔子低价钢铁而倒闭的美国钢铁最后成了日本铁的货物。

日本铁在1970年代初一度成为世界第一，但进入2000年代后，由于兔子企业的崛起，从第一的位置跌落。现在他们在新的炼铁厂，到2028年将投资10亿美元，今后10年粗钢产量将2024年的1418万吨增加到2000万吨以上，增产超过60%。美国钢铁公司的美国市场份额将从目前的15%左右翻。考虑到特朗普正在对进口钢铁征收重税，日本铁对于这次收购美国钢铁信心十足，下一个可以让日铁未来十年掌握制胜道的关键棋子。目前美国需求的自给率仅为55%，扩大国内生产的空间很大。日本铁在印度与欧洲安乐特设立了合资企业，今后10年也将把粗钢产量比目前增加150万吨。而在日本铁进入印度后，印度也提高了对兔子钢铁的关税，印度和日本也有将兔子制造出口印度市场的共识。

所以，日本铁的野心并不是说就算了，而对兔子钢铁而言，日本铁的野心不是挑战，更应该是警示。如果解决兔子大而不强的问题，如果提高兔子钢铁的利润率，应对上次政治局开会所说的内卷问题，是兔子制造业能否继续增长的关键。低价不是长久计，兔子制造业大而不强的问题如果持续得不到解决，难免让兔子制造业迎来当初甲午海战的痛苦时刻。

日本是天赐兔子的对手，只要有日本在，兔子想要悠闲都难啊。
