


# 中美谈判会展望

发布时间：2025年10月13日

25年10月对美连连续多维度施加的制裁，不可能是某个部门的决定，只能是最高意志，这跟21年3月阿拉斯加的拍桌子类似，当年老杨也没有权力做出此类的决定，都是按照剧本演戏。

坊间有人认为这是美国近期制裁的反制，虽然表面上看确实如此，但实际上这是绝不可能的。

参考有些已经达成的TikTok协议，以及近期特朗普的一系列外交工作，这位老人没有精力关注对华谈判的准则，他需要的只是宣布获得一个胜利。同样的，面对一些美方部门级搞出的幺蛾子，我方最高决策者也没有兴趣捡枪换50米，大就不像马逊会会谈那样，提前结束谈判，推首首会谈，把压力踢给特朗普，让美国谈判团队来处理美国自己的内部问题。

在此此轮的临时掀桌子，跟四年前一样，同时考虑国内国际两个气候。

国际气候方面，中方判断对方处于系统性的风险当中，中国抓住了美国供应链的危机，必然会迫使美国总统让步和妥，兑现海峡的政治承诺。如果特朗普坚持不妥，那么他也会像拜登一样，任期内失去访华资格，美国AI大运就会骤然落下，特朗普无法跟自己的科技股东们交交代。

国内小气候方面，马上要召开决定“十五五”的四中全会，我们要团结国内各种力量，为蓝图铺路，就需要一个外部的敌人和巨大的压力，更需要特朗普的公开妥来助攻。但不同于四年前的鏖战，本次会前的时间并不充裕，拍桌子自然也留有巨大的回旋余地和面子。

中美两国冲突的下限是明确的，双方上限也是爆发新一轮的关税，特朗普必定会妥，同样上限也是很明确的。中此番迷你不是战术手段，而是战略手段，不是美国职部门的让步就能重启的，甚至会暂停通话来对对方团队施压，此中美之间加速回暖的趋势会暂停，本月底双方预计将能用来缓解关系、重启谈判，而不是彻底妥协。

### 特朗普威胁对中国征收100%的额外关税
来源：BCC 2025年10月11日

在周五早时候的一篇帖子，特朗普反击了中方本周紧缩出口规则的动作。他威胁要取消与中方领导人会晤。后他表示，他并没有取消会晤，只是不知道“我们是否还会会晤”。

布鲁斯学会研究员、中国问题专家乔纳森·敏华表示，中国最近的行为是为了影响即将举行的会议，并指最近的特朗普指令将不会立即生效。

“他正在寻找掌握主动权的方法，”他说。“特朗普政府不得不玩一场‘打鼠’的游戏，在问题出现时就处理它们。”

他补充道，他不认为中国担心美国采取报复行动。“解放日关税（Liberation Day tariffs）以及事态升级后又降级的循环让中国意识到，中方的承受能力更高，”他说，“从他们的角度来看，特朗普政府却退缩了。”
