


# 如何理解YY的价值

对于美股来说，芯片走势最为关键。

10月10日，美股周二走低，将美国带来四日大暴跌，更不乐观的人也将跌其中。与此同时，美股的科技板块依然是最关键的，这难道不是因为美中贸易战升级吗？

对于我们美股来说，好运跟随芯片走势。其实确实如此，因为美中在芯片领域争夺激烈，谁的胜负取决于芯片。

可能下周还要大跌，因为韩国的芯片还没跌见底。但是如此，你是否还感到意外了吗？

对于很多投资者来说，他们认为美股是有风险的。这是最近以来大家达成的共识。但是，在投资者们眼中，风险并不是风险。相反，投资偏好决定了美股的走势。你是否还害怕？

对于大家来说，美国政府的政策就是关键。所以，我们先来看看最近的政策变化。

近期，美国政府将对先进芯片实施出口限制。这是自八月以来美国政府首次对芯片出口实施限制，无疑是美股市的重大利空。

上周二，商务部又发布了关于芯片技术出口的新限制，引起了市场的关注。

接着周二，美股继续走跌，市场出现恐慌。周二收盘时，道琼指数大跌10%，纳斯达克跌5%，道指也跌3%，这是因为美国政府采取了严厉的法律措施。

接着周三，美股继续走跌，国运和科技大跌三天，周四美股还没跌见底，周五美股才开始止跌，甚至在收盘时才出现小幅反弹。

然而周五，华尔街发布了财报预测，预计美国将进一步收紧芯片出口限制，预计中国在美股芯片市场份额将减少。

从9月1日起，美国将限制出口价值超过100万美元的芯片，对于所有先进芯片。

对于美中芯片战，已经进入了新阶段。大家都傻了吗？由于美国在先进芯片制造上一直处于领先地位，但是我们能够制造出芯片来反击，优势还能反转吗？

其实，并不是。我们并没有被打击，芯片制造的领域早已是老牌追赶者的领域。但是，中国芯片制造的速度正在反超他们。

报告显示，2025年以后全球半导体市场，中国芯片将占据30%的市场份额。目前是26%，预计到2030年，份额将从22%增长到36%。

但是，我们能够制造出先进芯片来反击，我们还能反击吗，优势还能反转吗？
