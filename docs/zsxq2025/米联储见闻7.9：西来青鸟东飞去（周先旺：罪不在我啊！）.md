


# 米联储闻250709: 西来青岛东飞去(周先旺:罪不在我啊!)

你好，我是米餐。

昨天，纪委通报了湖北省政协原组成员、副主席周先旺涉嫌严重违纪违法，目前正接受审查和监察调查。这是今年武汉疫情F4中第二个落马的。三个月前，湖北原书记赵跃，现在是周先旺，还躲着，估计也开始瑟发抖了。时隔五年，还是躲不过，有点灰霉算账的意思。最近汉内部权的消息也越来越显露，从事务协调机制的建立，到各种人事事的突发状态，由于是一年一度接淮河时间，所以大家对内部的一些变化都非常敏感，海外媒体更是各种推测猜情。上周，苗华被拿下，这周周先旺落马，颇有你来我往的意思了。

周先旺在新冠疫情期间担任武汉市长，在疫情爆发初期表示，只要是有利于疾病控制，自己愿意辞职以谢天下，不怕留下污名。武汉2020年1月底城以应对疫情。周先旺当时接受央视采访表示：“一个千万级人口的城市，在人类历史上是从没有过的，但是面对的却是，把门关了有可能把疾病关在城内，在历史上我们都会留名谢下，只要是有利于疾病的控制，有利于人民生命安全、马国强（此时湖北省副省书记兼武汉市委书记）同志和我，承担任何责任都可以，因为关，最后说要加责，说人群众有意见，我们愿意辞职以谢天下。”当时在电视上做这个表态，说实话就是不懂政治的样子，毕竟武汉的决策从来不是武汉可以决定的，什么时候轮他们来背锅，从一开始，这就是中央级别才能决定事情的。何况时周胜旺启用锅销，提到疫情信息既有披露的不及时的一面，也有利用有效信息来完善工作不到位的地方。对披露不及时时，他希望大家理解，原话是：“它是传染病，传染病有传染病防治法，要依法去披露，作为地方政府，我获得信息之后，授权之后才能披露。”这一点在当时并不被理解。言下之之，之所以没有第一时间公布，是因为要向中央请示，所以披露不及时时的责任不在我身上，不在武汉，而在上面。这一进一出，都犯了大错，不该背的责任，你抢它抢，不该你的锅，你迷你些迷？说实话，周先旺能留在现在，我甚至有点意外。作为湖北本土仕员，他的仕途一直在湖北，若不是这场疫情，估计也很难被上面见到。2021年1月，他转任湖北省党委委员、副主主席，大家都以为为他平安落地了，但是今年将被处理之后，关于湖北F4的问题又再次引起关注。

周先旺和当时的湖北省委书记赵跃、湖北省长王晓东、武汉市委书记马国强被外界视作湖北F4，当时。他们应对疫情的表现遭到各路舆论的批评。可以说中央层面的领导制造了比较大的麻烦。大家还想不到新冠疫情是本世纪持续的时间长、波及最广的公共卫生事件，可以让千万万人失去生命，认知还停留在因为官员和制度的腐败低能低效所导致的瘟情祸，所以对于这些人的不满转化成了对体制本身的不满。如果不是世界范围内普遍的新冠疫情失控，而中国反而有效阻断了疫情传播，这四个人早就被拿来当替罪羊了。为了避免大家处理他们与疫情失责联系在一起，所以中央层面面对这四人几乎没有问责，哪怕他们在疫情应对方面非常诸多操作。

因为新冠疫情的爆发，湖北F4的政治命运发生变。2020年2月13日，在舆论传播普遍批评武汉防疫不力的情势下，湖北省委书记赵跃和武汉市委书记马国强同时被免职，分别由上海市长应勇、济南市委书记王忠信接任。1年后的2021年1月，周先旺不再担任武汉长，退回一线，转岗湖北政协。5月，尚未到退休年龄的王晓东卸任湖北省长，交衔武汉市委书记王晓林。之后，蒋良、周先旺分别在2025年2月、7月被查，并在曾在疫情期间调研湖北、武汉的应勇、王晓林分别升任最高民检察院检察长、湖北省委书记。这次周不仅自己落马，还有许多名人一同被抓、住所被毁。2025年5月17日，周先在落马前还去湖北十县调研。与周先旺有直接联系的人士表示，在被带走前几天，很少在微信上主动与人互动的周先旺向友人发送了一首南宋诗人戴复古的诗，戴复是南宋江南诗派诗人。在疫情期间，周先旺也经历过戴复古的诗，是《庚子序》（其三）：“我走拙家愁岐。有天不雨，无地可埋。劫数惨如此，吾曹忌见之。官司行，不过是文饰。”在疫情初期发的这个诗，言下之意而知，作为武汉的主官，发这个诗无非是想说，现在的这个惨况不是我造成的，也不是我主导的，我很感慨老百姓，惺惶作态之余还是推卸责任，这次事前再次给朋友转诗，大抵是要鸣哀慨，认为自己是权力斗争的牺牲。

今年4月，中央第九巡视组进湖北省，开展2半月左右的巡视工作。巡视组受理信访时间截止到2025年6月23日。一般来说，巡视组下来说是带着任务来的，有些甚至是定点打虎，二月老蒋被控制，四月来查湖北，肯定也是剑有所指，而周先旺就为了中央巡视组进湖北后打下的首“虎”。随着周先旺的落马，中委今年已查34名中管干部，党的二十大以来，累计144名中管干部被查，内地31份“打虎”全覆盖，几乎每个地方都有中管部下，而这些人能爬到这个位置是因为上有大树，在下面有根，都是中坚力量，发而动全身，难免会拔出泥盆，越查越惊心，有时候高位者投掷暗器，但是这一位确实有霸气，不管是哪条线，全然是不顾一切。如此做调整新疆大变，早先说他是回京统筹，但是这次做调整新疆，福建赶赶天津，靠近新疆边缘。

从人角度来看，陈小江进入新疆是另一股力量的平衡。陈小江是体制内出身，在纪委监察系统工作多年，在几年内有5次职务变动：2015年7月，进入中央纪委，任宣传部长；后担任辽宁省常委、省纪委书记。2017年4月，出任监察部长，10月当选中央纪委副书记。2018年3月，国家监察体制完成后，他继续担任中央纪委副书记、国家监察主任。几乎是一动逐级卡位，这样频繁的经历，在内部是罕见的。所以一直是外部关注的明星官。统战部作为中央直属部门，仅次于中办、中组部、中宣部，大门从未在系统内发生。1990年代以来，除延安早年由共统战部外，多数都是地方大员调任，拥有丰富的地方政经验。陈小江其实实实力派。2022年1月，陈小江进入新疆：依法治疆、团结稳疆、文化润疆、富民疆、长期建疆，表示不能来新疆。考虑到新疆在整个战略地位，这次入境新疆几乎是决策层对他的重用，背后的助力非同常。2023年以政治局委员身份担任新疆书记，是1954年以来首位汉族主任。他的任命几乎不是重用就是破格。从背景来看，马云江进入新疆大概会延续陈小江治理工作。相比之下，马云江任新疆的情形与现今调任新疆治理的方向变化，形势发生逆转。马云江在新疆干部会议上提出的是“坚持铸牢中华共同体意识作为工作主线”和“扎实推进民族共同体建设”，强调维护社会稳定首位，表示进一步深化改革，推动高质量发展，不断满足人民对美好生活的需要。马云江的主要重点还是抓经济，打造内陆开放高地，统筹发展和安全。相比之下，这次陈小江进入新疆，不仅是过去那种少数地区，可能会成为广东、江苏、三角之后的又一个引领中国经济发展的引擎。一直以来，地区发展到底如何配置，陈小江作为顶着各种破竹之刃，来自自委监察系统的陈小江入新疆，感觉是来抓人的。原本以为会在民委掀起反腐风暴，没想到最后居然丢了新疆。

至于马，如果真受航天系拖累，或者跟张春、陈全国一样，出任中央某决策议事协调机构的副手，或者在以后天、陈政的副国国家级领导。如果他接统工作，那就是另外一回了。

米粘粘各位晚安。
