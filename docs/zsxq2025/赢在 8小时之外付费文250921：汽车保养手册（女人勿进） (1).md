


# 汽车保养手册 (女人勿进)

原创：U 君 公众号：赢在8小时之外 25年9月21日

今天，我要跟那些因为各种各样的原因而不开车、但是又有开车需求的男性同胞聊聊一些关于“汽车保养”的小思路。

## 1. 卫生问题

如果你找专业的、职业的、每天修十几辆车那种技工，那你的担心并不是多余的，因为她会碰到各种各样的顾客。

但是，只要她自己的智商正常，那么就是安全的，因为她不可能不顾自己的安危。

如果她说：“载车衣是一个价，不载车衣又是一个价，你抓紧跑吧。”

一般来说，价格越高越干净，因为我说过一个胆大的观点：很多传染病的高人群是穷人和低智商的人。

当然，我建议大家，尽量不要去找专业的修车人士，而是去找那些技术一般、没有修过多少车的非专业人士。这种人就干净多了。

这就引起了下一个话题：

## 2. 对非专业人员进行逐步试探

比如，你要多去各种各样的汽车4S 店、路边小修理厂，然后定期让那些技工给你按摩轮胎。

接下来，你就要试探性地问那些技工：“可以加钱帮我保养一下排气管吗？”

当然，提问时要晦一点，比如：“你们这里还有其他加钱的服务吗？”

只要你去的汽修厂足够多，那么愿意帮你保养排气管的技工可能高达 5%-10%。

如果找到了愿意保养排气管的技工，那么下一步就是跟她商量试驾的事宜。

## 3. 技工的心态

90%的技工都是穷人、负债的人，而且里面有一半的技工是家里急需用钱的，而在这一半里，又有50%的技工认为“拿钱驾”是不是什么大不了的事宜。

所以你去给轮胎按摩时，要大胆地试探、询问，即使她们是纯正规的，她们一般也不会生气的。因为每有10个客人里面就会有2个试探的，她们早就习以为常了。

我自己的经验是，如果你有试探的心思，就要拥抱技工的心理，如果她们是那种特别别谱的人，你就不要二次光顾了。

如果她们的语气是那种棱棱的、拒还迎的，说明她们也想赚这份钱。

这时，你去光顾、再去让给你的汽车做保养，甚至偶尔还发小费。等混熟了，有了信任感，那么以后你让对方家里给汽车做保养，对方同意概率就大了。

不要说汽车修理了，就是公司前台、酒店前台、游泳馆前台、健身房前台……都是同样的思路。

## 4. 男人的包装

经常有男人跟我说：“哥，我的条件很一般，月薪只有五千多，根本没有技工愿意给我修车，怎么办？”

我的建议：你一定不要走寻路，一定要跟同龄人、同龄层的人做出明显的区分。

假设你手上有1万元存款，你的月薪是5000元，那么你一定不要去给亲戚朋友、同学同事事的红白喜随礼，平时也不要跟穷鬼朋友们聚餐。

因为你在上面这些事情上花的钱越多，你获得“开车软”的概率就越低。

你哪怕时只吃馒头咸菜，衣服穿廉价货，把所有朋友都得罪了，你也要把钱攒起来，然后出国旅游。

只要你报旅行团，或者提前做好预算，那么一趟泰国、韩国、日本的总费用不会超过1.5万元。

说个极端一点的，你就找廉价机票、廉价酒店，花2000元去泰国旅游3天，你也算是见识世面的人了。至少你跟90%的同龄人视野上就不一样了。

接下来，你在跟美妆师沟通时，你就可以跟她们聊聊你在泰国做按摩的经历，聊聊你吃泰国菜的感受，而且邀请对方你也一起去旅行……

当然，很多人可能会对泰国旅游范之心，我只是举一个例子，很多女生还是比较往韩国和日本旅行的。

而在修技工厂里面，99%的人都是没有护照的，更不用说出国旅行了。

如果你能发一些在国外的圈，讲述一些在外的见闻，那么她们对你的好感度至少能增加几分。因为你没房、没车、没钱，你就只能通过其他途径给自己加分了。

## 5. 不要去碰见过世面的女人

以前我还是一个穷丝的时候，我就明白了一点，我的机会只在那些“没见过世面”的女人那里。大佬文集无论同事、朋友、网友还是技工。

假设我去过3个国家，她也去过3个国家，我会直接把她pass掉，因为我需要的是解决那方面的需求，不是跟你世界。

想要跟见过世面的女人发生链接，需要额外付出高昂的成本，我当然不会做这样的生意，因为我的预算有限。

反之，我只找那些见过世面的、对我的经历有一些崇拜和向往的女性朋友。

我会带她们去办理护照、出国旅行，也会给她们买iPhone手机、教她们游泳（至少教过3个个人游泳）。
