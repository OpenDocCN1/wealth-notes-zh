


# 宁德时代2023年年度报告摘要

2023年，宁德时代作为全球领先的锂电池解决方案提供商，在全球宏观环境复杂、行业竞争加剧的背景下，通过坚持技术创新，深化全球化布局，在动力电池、储能电池及锂电服务等领域持续保持行业领先地位，公司经营规模和盈利能力实现稳健增长。

2023年，宁德时代公司实现营业收入2557.49亿元，同比增长22.3%；归母净利润440.26亿元，同比增长44.9%；扣非净利润356.43亿元，同比增长39.5%。净利率为17.2%，较去年下降2.5个百分点。

2023年，公司动力电池业务收入1695.88亿元，同比增长15.5%；储能电池业务收入610.12亿元，同比增长66.5%；锂电服务业务收入251.47亿元，同比增长7.2%。

2023年，公司动力电池使用量275.5GWh，同比增长25.1%；储能电池使用量113.3GWh，同比增长70.8%。

2023年，公司研发投入187.15亿元，占营业收入比例为7.3%，研发人员占比21.5%。公司全年申请专利12543项，同比增长15.2%。

## 二、发展展望

2024年，新能源市场预计持续增长，但行业竞争将加剧。宁德时代将继续领先，在高能量密度、固态电池等前沿领域持续突破。公司将加大全球化布局，确保供应链稳定，为客户创造长期价值。
