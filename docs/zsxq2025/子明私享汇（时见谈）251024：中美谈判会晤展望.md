


# 中美谈判会展望

发布时间：2025年10月13日

25年10月对美连维多维度加的制裁，不能可能是某个部门的决定，只能是最高意志，这跟21年3月阿拉拉斯的拍桌子类似，当年老杨也没有权力做出如此的决定，都是按照剧本演戏。

坊间有人认为这是此对美国近期制裁的反制，虽然表面上看确实如此此，但实际上这是绝不可能。

参考已经达成的TikTok协议，以及近期特朗普的一系列外交工作，这位老人没有精力去关注对谈判的细则，他需要的只是宣布获得一个胜利，同样的，面对一些美方部门级搞出的蚊戏，我方最高决策者也没有兴趣“机枪前挪50米”，大不了就像马德里里会谈那样，提前结束谈判，推迟元首会晤，把压力给特朗普，让谈判团队来理顺美国自己的内部问题。

在此本轮的临时撤凳子，跟四年以前一样，同时要考虑国际两个气候。国际大气方面，中国判断美方正处于系统性的风险当中，中国抓住了美国供应链的危机，必然会让美国总统让步和TACO，兑现海峡的政治承诺。如果特朗普坚持不TACO，他也像拜登一样，任期内失去访华资格，美国AI优势就会黯然下落，特朗普没法让自己的科技股东们交代。

国内小气五方面，马上要召开十五届的四中全会，我们要团结国内各势力，为蓝图铺路，就需要一个外部的敌人和巨大的压力，更需要特朗普的公开TACO来助攻，但不同于四年前的尘战，本次开会的时间并不充足，拍拍子自然也留有巨大的回旋余地和面子。

于是，中美两国冲突的下限是非常明确的，双方不会因此爆发新一轮关税战，特朗普务必学会TACO。但同样极限是非常明确的，中方此番不是战术手段，而是战略手段，不是美国职能部门的让步就能重启的，甚至暂停通话来对对方团队施压，因此中美冲突之前一直回暖的趋势将会暂停，本月底双方暗预计将用来缓解关系，重启谈判。

### 特朗普威慑威胁对中国征收100%的额外关税

来源：BBC 2025年10月11日

在周五早时候的一个帖子里，特朗普反击了中国本周紧紧出口规则的动作。他威胁要取消与中国领导人会晤。后他表示，他并没有取消会晤，只是不知道“我们是否举行会晤”。

布鲁金斯学院研究员、中国问题专家森·钦华表示，中方最近的行动是为了影响即将举行的会议，并指出中最近的稀土指令将立即生效。

“他正在寻找掌握主动权的方法，”他说。“特朗普政府不得不玩一场‘打鼠’的游戏，在问题出现时就及时处理它们。”

他补充说，他不认为中国担心美国采取报复行动。“解放日关税（Liberation Day tariffs）以及事态升级后又降级的循环还让中国意识到，中方的承受能力更高。”他说。“从他们的角度来看，特朗普政府却退缩了。”

华盛战略与国际研究中心关键矿产安全项目主任格鲁斯林·巴斯卡兰表示，仍有时间和空间进行谈判。中国的新规将要到12月生效。“谈判可能即将开始，”她说。“由谁谈判，在哪里谈判，都将随着时间的推移而确定。”
