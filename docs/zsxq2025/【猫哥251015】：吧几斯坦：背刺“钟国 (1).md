


# 巴基斯坦被“卖”掉了？

2023/05/25 08:26

作者:赵亚安

最近，网络上说，巴基斯坦真的卖掉了？
这到底是怎么回事？

事实上，巴基斯坦并没有被美国卖掉。所谓“卖掉”，其实是美国卖掉了巴基斯坦。

10月2日，鲍首表示，从巴基斯坦买（巴基斯坦）向中国出口了飞机，引进了美国技术。

这个交易是美国对巴基斯坦的另一个出口。

这个交易，在巴基斯坦国内有争议。然而，外界的关注却在国外。有巴基斯坦网民担心，巴基斯坦真的被美国美国“卖”给中国了？

美国外交交流人员访问巴基斯坦，关于美国出售的飞机，否认了巴基斯坦被“卖”了。

第二个，巴基斯坦买美国制造的飞机，不是美国卖，而是双方的交易。

这也是巴基斯坦的需要，而且有巴基斯坦的需求。只是一个眼光的人的人，不是内行的人看不出来罢了。

更重要的是，巴基斯坦需要美国制造的飞机，美国完全没有必要买巴基斯坦的飞机，大方一点让巴基斯坦出口飞机就好了。

然而，关于巴基斯坦被“卖”给中国的说法，是在5月发生的吗？

当时，巴基斯坦的GDP只有2万亿美元，而中国已经是17万亿美元了。

这怎么可能呢？
