


# 房地产政策将持续加强

从“五五”会议的五项安排来看，从全国工作会议来看，就可以看到房地产政策将在多个国家层面持续加强的态势，这对于有利于房地产市场是一个积极信号。

现在从“五五”的五项安排来看，第一项就是房地产市场要坚持“认购多需”，并要保障住房建设，明确要求“不搞大房价”，另一方面要坚持“房子是用来住、不炒房”，市场机制的更新、政策的调整，都至关重要。

现在从“五五”的五项安排来看，第二项就是“稳中并举”，明确房地产市场要持续发展，另一方面要坚持“需求导向”，明确住房租赁市场要持续发展。

现在从“五五”的五项安排来看，第三项就是“完善长效住房机制”。要加快保障性住房建设，建立多层次的住房供给体系，同时要完善住房租赁性住房供给体系。

现在从“五五”的五项安排来看，第四项就是“统筹城乡发展，城乡并举”。

“什么叫实现？”“如何实现？”到2025年要实现“房住中国”的阶段性目标。到2025年要加快保障性住房制度改革，加快住房租赁制度建设。

2025年要加快养老金制度改革：2025年要完成城镇职工基本养老制度的阶段性改革，2025年要完成城乡基本养老保险制度的阶段性改革，2025年要完成居民养老保险制度阶段性改革，2025年要完成医疗保险制度阶段性改革，2025年要完成基本养老金制度阶段性改革，2025年要完成基本城乡一体化住房保障制度改革。

“什么叫实现改革？”“如何实现改革？”这些改革都是长期性的，而且是一项复杂的系统性工程。但是，为什么要2025年完成？为什么要这么做？

2025年要完成基本养老金制度改革，这是为了应对人口老龄化带来的压力，也是为了增强养老金的可持续性。从2020年开始实施养老金个人账户，扩大了养老金的覆盖面，包括企业养老金、职业保险、居民养老金等。实施养老金个人账户后，通过调整养老金统筹账户和个人账户的比例，可以提高养老金制度的公平性和可持续性。

对于医疗保险制度改革，重点是，扩大统筹层次，平衡地区间差异。
