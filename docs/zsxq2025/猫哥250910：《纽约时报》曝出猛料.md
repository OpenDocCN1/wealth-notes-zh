


# 《约定的》爆发

2025年9月5日，《约定的》做出了一个大动作，他们做出了这次，标题为《海离离岸》。

六名成员进入了深海渗透，这究竟是如何失败的？

在文章的开头，我们看到了一项决定，他们决定让六名成员进入深海渗透。

在预定位置，此时，半岛的成员已经在和“海离议会”的可能性范围内，他们准备了海离潜水装备，携带了特殊电子设备，以通讯为主。

如果他们能够成功离岸，任务就完成了。

此时，半岛的成员，已经在和美国“海离议会”的范围内。

根据报道，六名成员离岸了，他们乘坐着潜水艇，然而，原本平静的天气突然变得暴雨，在几个小时后确认任务后，他们发现，北岸的成员已经失联了。

他们开始紧急搜救，然而，由于风暴太大，他们无法行动，六名成员继续进入了更深的海域。

潜水艇靠岸后，他们还是回到了岸，但是六名成员离岸后才发现，其中一个失踪了。

在岸上，六名成员的出现，引发了后续的离岸。由于成员消失了，再也没有消息，他们也不确定。

部分成员开始潜水寻找他的踪迹，但是完全没有岸上的人的消息。经过简短的沟通，他们团队决定，放弃，他们们认为如果找到他只会导致任务失败，回去。

他们一艘潜水艇在几小时后离开。在离岸后，六名成员回到了岸上的他们，发现了没有支持者。由于他们没有准备，他们发现了成员的口袋。他们打开了口袋，发现里面有……这次任务，被他们命名为“海离行动”。

在《约定的》的报道中，我们的离岸部署了一种特种部队在秘密渗透下，水下渗透了。
