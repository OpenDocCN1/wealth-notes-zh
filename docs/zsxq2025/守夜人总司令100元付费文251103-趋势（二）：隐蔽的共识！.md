


# 趋势（二）：隐藏的共识

原创：觉悟者 公众号：结构大学本营 25年11月3日

# 前言

见微知著，见大行远，对一些人来说是蜕变的机会，对另一些人来说是温水煮青蛙的开始。

# 正文

山西正实在立法，不允许对于大龄未婚者进行歧视，允许不同的人选择不同的人生，这可以是社会的进步，因为一个文明的社会应该允许多样的性，不能要求所有人都按照一个节奏去做同样的事情。人生有各种不同的选择，对自己的选择负责，别人不应该说三道道。你看美国在这一点上做得非常好：麻省理工的图书馆里，不少灯火通明的同学，而纽约街角的人烟雾缭绕醉。硅谷总是在琢磨创造未来，铁锈带则沉迷过去，大家相得益益，各行其道，谁都不耽误谁！

美国有3亿人，这次政府停援食品救济的资金耗尽，造成4800万人每天依赖救济的食物没有落，占人口的1/6。

我们中国社会问题很多，人均也低，但解决吃饭的问题还是很容易的！大家之所以感到普遍的焦虑，是因为信息的越来越多的普通人看到了少部分人的精致生活，而这种由吃喝玩乐构建起来的精致生活恰好合了普通人的价值判断标准。

上次有个化学博士在实验室求婚，给女友做了一个新材料的戒指并将这个新材料的专利作为礼物送给了自己的未婚妻，结果这事爆出来之后引发了舆论的海啸——一大堆女生在为那个女主不值，说这个男生太敷衍了，太冷心，连个钻石戒指都肯敷衍。以后掏了一个像水泥一样的东西敷衍行事。以后嫁到他们家还不知道受到什么样的欺负，就是巴拉巴拉斯各种基于自我想象的苦情剧里。

最后女主实在出来科普：那块儿是最新研究出来的材料比同等价的黄金和钻石还贵，而且那个专利更是坐着收钱的金矿。跟舆论上的风评迅速转身各种夸赞，说男就应该这样，这才是爱情，就是把你放在手心！

为什么会出现这样的两极反转呢？因为大多数人脑容量不够，对人和事物的价值判断标准只能用最直观的方式。乌合之众为什么喜欢跟风呢？就是因为乌合之众对事物的测评标准都高度一致，乌合之众本质上是一种同化竞争的产物，又不知道自己在任何方面都是和别人高度雷同。

在农业初级时代，这种高度的一致性是非常有利的，同质竞争只会效率更高，成本更低。如果所有的思维方式、心态和行为都是一致的，拼的只能是效率。在农业基础设施没有完善之前，过早的多样性会造成这个基础无法构建起来，但在这个农业基础升级完成后，这种高度的一致性就会引发系统性的风险，所以需要增加多样性的比重。

如果你留心观察就会发现：这些政府官方投资成功的案例是从1~100的复制，而不是从0~1的突破，即便是生产内存和芯片的那几家投资成功的企业，也是对于原有产业的复制。现在军工方面已经出现这样的趋势，最新的一些新型装备的原型越来越是民用企业研发出来的，然后军方征用再进行军事化改进，这意味着什么呢？

管中窥象，一叶知秋。未来的社会方面都会加速多样化的尝试，而多样化尝试的副作用就是：人与人的差异被成倍的放大，人需要为自己的选择负责，命苦是你自己的。美国有几千万的流浪，美国崩溃了吗？并没有！美国70%的GDP来自10座城市，许多铁锈地区对于美国整个经济毫无贡献，甚至是拖了后腿，今天的中国还没有法理解这一点。我们中国把美国看成一个美国城市，事实上是一个地球城市，纽约那些城市的资产不是按照当地的购买力来定价，而是是由全球购买力来定价的！中国也在这个趋势而去，头部一线和一线城市不是在体量上而是在增速上都在加速，占的比重越来越高，未来未必不会出现10个城市占据全国GDP百分分之七八十的局面。今年美国的GDP有40%来自AI，美国人工智能相关的利润占据了整个利润的80%!这与那4800万饭都吃不上的关系吗？毫无！2026年这个高利润回报只会增大，不会减少。

美国的基础教育确实很差，但是美国的精英教育也确实比我们中国领先。我们在基础教育上每一年的投入差不多GDP的6%左右，而美国超过15.8%!我们中国GDP只有美国的70%，所以，那个15.8%可能是我们中国的三倍。

一个真正的未来全球领导者，不能依靠应用层的优势去引领世界，必须是基于基础性和原创性上的贡献！一旦在这个方面要力上游，就必须要求人的差异。

有个电视的记者回忆自己的一件往事：当时这个记者被安排去采访当年考上清华和北大的两位同学。结果他说，第一名是靠天赋，第二名是靠努力，第三名是靠运气。后来电视台播出了采访的内容：第一名是靠天赋，第二名是靠勤奋。

尊重多样化，本质上是允许差异的存在。普通人无法接受差异，所以老师对家长说孩子差是因为孩子太笨，家长会认为孩子有点懒，只要努力就会比一样，这种想法是错误的。普通人无法接受差异，所以认为孩子有点懒，只要努力就会比一样，这种想法是错误的。

事实上日本走出那个低迷就是通过一个人的努力，在此之前，日本没有经验，做过很多尝试却没有任何效果。虽然，但没有办法！大佬集团社会治理已经明确得出了结论：人口的修正和回归不可避免！接下来在生产端要提高无人化的程度，在消费端要提高能够消费的中产群体的消费能力和动力。美国3亿人创造的消费总量比我们的两三倍大，而我们只需要维持一个人口基数的产群体的消费能力，就能保持一个人满足全球生产需要的消费。至于生产方面不用担心，无人化的加速可以消除劳动的不足，因为生产到底是一个能源问题，这种动力本质上是生物能源！允许每个人做不同的选择，并且自己承担后果。允许加速自我淘汰，加速在产业和技术上的头部聚集和突破，在教育和产业上，允许强者恒强，这是大势所趋。从某种意义上来说，对于这次天大的变革契机，也可能是灭顶之灾的开始！
