


# 守夜人总司令觉悟社星球250610:稀管制！

别的地方也有稀土，但是别的地方缺乏成熟的配套体系。像稀土这样的矿物物质的充分利用，需要一套逐渐生长出来的生态体系。钱是一回事，时间又是另外一回事！

我们中国的稀土管制形成制度，这种管制的目的不是用来作为谈判的筹码，而是要形成产业链的长期依赖。举一个例子，与稀土应用相关的原材料出口是禁止的，但是对这些原材料和相关技术的成品出口也禁止，开军工的应用，最大的份额在新能源汽车上，如果我们将保持有的政策，并逐渐形成一套管制的制度，那么，海外的新能源汽车产业，为了应对这种不可控的市场预期，不知道什么时候双方又打起来了。市场要求生产具有稳定性，资本市场对于企业的估值依赖企业的稳定性，如此一来，为了自身的利益，那些海外的相关汽车产业，就会与相关的技术迁移到中国来，然后在中国完成与稀土相关的生产，最后把成品出口到自己国家组装。

如果没有判断错，这应该是我们制定相关政策的最终目的，因为终端的限制不具有持续性。当房地产熄火之后，我们中国急需包括汽车在内的相关产业去拉动增长，如此一来，你不得加大与别人的合作，甚至技术转移和生产线，在这个趋势下不可避免的情况下，就需要在产业链的某些关键节点上形成绝对的控制优势。

这就比我们中国今天能够设计出更好的芯片，但是我们中国造不出来，一方面是因为光刻机，更重要的是我们缺乏工业设计软件，这个脖子比光刻机更要害！光刻限制的还是制造工艺，工业设计软件的限制会造成芯片设计图都画不出来，而且别人的工业软件去画图的时候容易造成安全隐患：曾经华为有一个芯片在设计了之后，一切应用都正常，然而，当把华为芯片部署到核心服务器上去应用的时候，核心服务器将会有一个暗藏的电路逻辑自动向外传输数据。这个逻辑并不设计者的原稿中，而是工业设计软件自己偷偷添加的，只有在特殊条件满足的情况下才会被触发！

一直以来，我们中国都是摸着美国过河，你不得不承认美国作为世界的霸主，在很多系统结构的设计上都是可取的，恰恰是这些系统的设计和关键位置上的卡位，保障了美国横跨四海的影响力，这是各个领域相互叠加的体系，牵一发全身，所以有那么容易被拆解。美国的独特地位仅仅因为美国的军事霸权或者金融霸权！每一个新兴产业和前瞻性的技术，是不是都源于美国呢？恰恰是这些东西不断为美国的整个控制体系链加瓦。

正因为如此，不是俄友而是竞争对手，任何人在某个领域的技术积累或者科技突破，以及产业优势都会成为美国的肉中刺。法国的一个通信企业被美国硬生生拆掉，德国的汽车工业在美国内取得遥遥领先优势的时候，突然爆发大环不合格的丑闻，经过多年的折腾，最后真相大白，大众集团没有合格，是美国搞的鬼，然而，此时，美国的目的已经到了。

俄罗斯和乌克兰之间的战争打了多年，此举对于美国来说，顶庄雾意在攻，真正要打的是欧盟。开战之前，欧元在整个结算体系中的占比接近40%，美元也只有44%，这场2022年2月开始的俄乌战争打下来，欧元现在跌了20%，美元上涨到60%多，掉的都是欧元的份额。大佬集除此之外，这些年不仅大国力在抛美元，连日本也掉了不少，然而，这些美元债是谁的呢？你去查一下数据就会发现，在过去的三年中，欧洲主要发达国家的美债规模急剧上升！你没错，就是美国通过2022年2月开始的俄乌战争看着欧洲各国吞下了亚洲主要经济体出售的美元债。嘴上都是主义，心里都是生意，在生存竞争中，只有幼稚鬼才会相信面上的那些东西，骨子里都是资源的争夺对生存结构的卡位。
