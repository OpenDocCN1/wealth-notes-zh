


# 克文251224: 南京博物馆事件，又出一个“董小姐”？

南京博物馆的事情闹大了。

不仅南博的退休老职工站出来，实名举报前南市长徐某平，江苏省政府成立了调查组，连国家文物局都成立工作组，开始核查了。

之前还有人在担心江苏方面是自己查自己的话，现在国家层面介入，想必会有份比较扎实的调查报告出来。问题在于，事情都过去20多年了，鉴定《江南春》为假的专家也太不在世了，从哪查起呢？

也许，那个被举报的前市长徐某平，是一个合适的突破口。

徐某平疑点最多，最适合作为突破口。

比如，在几天前接受记者采访的时候，徐某平先说自己今年80多岁了，生病在家里面。2008年退休后，所有的外界事务都不参与了，当时这个事不是自己经手的，自己不是书画鉴定家。

基本上，属于否认三连。

但互联网是有记忆的。

随便上网搜一下就会发现，徐某平退休之后，担任了江苏宁宁府博物馆馆长和江苏省收藏家协会的会长，经常出席各类文物、收藏相关的活动，忙得不得。这怎么是“外界事务都不参与”？

还有，他说这个事不是自己经手的。但1997年把《江南春》调拨给文学商店的记录上，可是看着徐某的大名。

这么急着撤清关系，看来徐某平绝对对知道些什么。从徐某平的履历上，或许一览端倪。

翻开各国国家级、省级博物馆任馆长的履历，你会发现他们一个共同点：

绝大多数人都是科班出身，要么是古大学大家，要么是历史学泰斗，他们身上带着一种浓重的书卷气，也比较惜羽毛。

但徐某呢？并不是，他既没有高学历，也不是文博出身。

1963年，徐某平从南师中学毕业，参伍进入进入空地导弹部队二营，也就是电视剧《绝密543》中一支打下过U2侦察机的传奇部队。

1969年，徐某平退回南京，在新华印刷厂当工，1973年7月，调入南京博物馆，负责一些后勤工作。

然后只有一年时间，徐某从工人身份转成了干部的身份。了解那个年代的，都知道这种提干的含金量。

此后徐某平步青云，只用了9时间，就从普通干部成长为南博的副院长，随后以副院长身份统筹权力十几年，并在2001年正式扶正成为院长，一直到2005年。

在论资排的文博系统，这种“非科班人员”有火箭式的跃升速度，只有两种可能：要么他是绝世天才，要么他拥有超常人的“运作”能力。

徐某平是哪一种可能呢？大家心里也清楚。

也许正因为这种出身的不同，注定了徐某平在掌权之后，其行事风格与传统的学者型院长截然不同。

学者型院长长吧，虽然也难免俗，但其骨子里往往有一种“知识分子”坚持，比如自杀的前院长姚迁。

对于一个靠“运作”上位的人来说，那就灵活多了，文物反而成了“顶级资源”。

从南博42名职工的联名举报信来看，大致可以拼凑徐某平在南博工作期间做了什么。

举报信说，徐某平任职院长期间，未经国家文物局批准，擅自拆毁抗战时期南运文物保管箱上的封条，取出大量珍贵文物。

然后他指使鉴定专家将故宫文物鉴定为“赝”，低价销售给主管的江苏省文物商店，再转手倒卖给儿子徐某江在上海开的文物拍卖公司，最后出售给法国的商人和各地文物贩子。

其中不仅有一大批宫陶瓷，还有数量多的国宝孤品书画作品。为了躲避清点检查，他长期拒绝、阻挠故宫博物馆归还文物的正当要求。

同时，他还将多件书画送给各级政府领导，包括江苏省检察院检察长、江苏省反腐局长韩某。

或许，这就解释了为什么《江南春》鉴定为假，然后拨给了江苏省文物商店。徐某平时不仅是南博院长，还是江苏省文物商店的代表。这才是震惊的地方。

- 逻辑如下：
- 左手是博物馆，右手是商店。
- 左手负责把文物定义为“假货”或“次品”出；
- 右手负责以低价接盘，然后推向市场。

在这个完美的闭环里，《江南春》从国宝变成商品，只需要徐某平签字。

假设这幅画不是假的，那问题就严重了。逻辑只有一个：洗白。

根据报道，陆某和徐某可是多年的好友，假设这幅画真的是他们勾结卖出去的，如果直接从南博买，那手续就不通了。

必须要有一个故事：画是庞家后人卖掉的。毕竟庞某在自己去世前已经将财产分为三份留给三个继承人，规定《江南春》真迹就在庞增手里。这样一来，国有资产流失的罪名就洗刷了，反正画已经卖了，没人能证明南博的这一幅到底是假的。

但是，这个故事有一个巨大的Bug——缺一个“卖画的庞家后人”。真正的庞家后人庞增、庞权等人，一直谎称他们捐了，没回来过，肯定不是他们卖的。没有后人，就“造”一个后人。

于是，这场大戏魔幻、最荒诞的角色登场了——徐某。

徐某是谁？她一名杭州师生物专业的学生，硕士论文研究的是植物病毒。你没听错，一个研究植物病毒的理科生。

但是，就在2014年南京博筹的“藏天下：庞某名画展”上，这位徐某女士突然华丽转身，变成了“庞某曾外孙女”，变成了“庞家后人”，展览的共同策展人。当时，南博的任领导徐某平、策划人庞某都对这个身份进行了背书，甚至大力推介。

请大家想一下，一个搞生物的突然跨界搞书画鉴定，这本身就离谱；更离谱的是，真正的庞家后人庞叔令就在现场，她根本不认识这个“亲戚”。

根据庞叔令的回忆，当时庞叔令见到自家亲戚还高兴，但聊了两句就感觉不对劲：“我觉得她讲的话和她的年龄不符合，好像要极力向我证明什么，但是提到家里的事情却漏言百出。最明显的例子就是她小时候在奶奶家看到一本册子，上面有贺明明的名字，也就是我的曾祖母。我一听就觉得有问题，因为她说看到的册子是解放前的，但是我的曾祖母在解放前不叫贺明明，而是随父姓叫贺氏。”

庞叔令越想越不对劲，就把徐某和南博告上了法庭。最终，法院判决：不认定徐某是庞家后人。

然后，有意思的话了。2016年，徐某父徐安华申请了一份“亲属关系公证”，这份公大致意思是：徐某是徐安华的女儿，徐安华是徐祖林和庞某的儿子，庞某是潘志新的女儿，而潘志新是庞赟的妻子。这么来算的，徐安华是庞赟外孙，而徐某是徐安华的女儿。

但是，2017年，这份公证被撤销了。因为徐安华提供的材料只能证明潘志新是庞赟的妻子，没有证明庞某是潘志新的女儿，徐某与庞某家族的血缘关联处于岌岌可危的状态。这层关系，说徐某是庞家后人，能唬住人的。为什么要费心思，把一个学生包装成庞家后人？仅仅是为了让她在展览上露脸，这是为了补上那个“洗白故事”的最后一环。

把逻辑串起来：
- 徐某平把画从南博“运作”出来，到了陆某手里。
- 为了掩盖国有资产流失，需要一个“庞家后人”站出来，徐某可能就是这个被选中的演员。
- 只要徐某这个“庞家后人”是被官方（南博）认可的，那么她每一句话都能成为那批文物的护身符。在这场戏里徐某可能只是工具不是操盘手。
- 真正的操盘手是那个站在她身后，敢于指鹿为马，敢于把“假亲戚”推上线的人。

这样一来，举报信里面的内容就说通了：一个强大的院长，利用制度漏洞通过行政手段将真鉴定为假，通过所谓的“合法手续”转移出国，一个富有的商人接盘，一个制造出来的“庞家后人”负责洗白。这就是传说中的“草蛇灰线，伏脉千里”。

徐某平编织的这张网，太大了。但是，最让人感到背后发凉的，不是这几个人，而是这件事背后的抗击能力。

根据报道，早在2008年，郭礼等十余名职工曾实名联名举报徐某平。几十个人啊！党员13人，民主派7人，知识分子22人！结果呢？泥牛入海。徐某平不仅依然退休，甚至在退休后依然在收藏界呼风唤雨。

郭礼在举报信中提到，徐某平将许多贵重字画作为“雅赐”，送给了各级关键人物。其中包括落马的江苏省前反贪局长韩某。根据澎新闻报道，徐某平、陆某和韩某三人是好友关系。

这可能涉及到到一个问题——“雅赐”。直接送钱太俗，太容易出事了。送画那是“文化交流”，是“鉴赏”。一幅画在账面上可能只值几千块（《江南春》6800元），但到了懂行的人手里，它就是几百万、几千万的硬通货。

这种利益输送极其隐蔽、极其优雅也极其稳固。徐某平不仅仅一个人，他代表的是那个时期文圈的一种“生态”。在这个生态里，文物是他们交权的“投入物”，是他们置换利益的“筹码”。那些收到画的人，他们会允许徐某平出事吗？徐某平出事就意味着拔萝卜带出泥。

所以调查来龙去容易，清楚画是怎么出去的也容易（毕竟单据都在）。最难的是查询徐某背后的事情，是查询这些年他把那些消失的画到底送给了谁。

说实话，南京博物的这出大戏，看得人唏嘘不已。但也许是件好事，撕开了文博系统封闭运作的一角。它让我们看到，那些躺在玻璃柜里的国宝，不仅需要物理上的防盗，更需要制度上的防盗。那些被调包的真迹、被撕毁的封条、被篡改的档案，终究会成为铁证。
