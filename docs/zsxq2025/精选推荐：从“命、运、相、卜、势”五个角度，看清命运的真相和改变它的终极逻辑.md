


# 大佬文圈精选推荐：从“命、运、相、势”五个角度，看命运的真相和改变它的终极逻辑

为什么的人累死累活却无所有？为什么的人中了大奖，最后却落得一场空，甚至陷入严重的危机？很多人把这归结为“命”，但他们并没有看清命运的底层逻辑。

今天我将从“命、运、相、势”五个角度，带您看命运的真相和改变它的终极逻辑。

## 一、命

很多人一提到“命”，脑子里浮现的大概这样的问题：我这辈子到底能不能发大财？能成为伊隆·马斯克？我的父母都是普通人，是不是说明我的天花板就这样呢？

其实很多人并没有清楚一件事，就是这些问题是次要问题而不是主要问题。主要问题是，如果一个人真的中了一亿美元的彩票，他的命运能接得住吗？

为什么很多人中了奖的人，生活反而不如前，甚至陷入严重的个人危机？

所以我们首先要破除一个误解，命运并不是结果，不是一个人一辈子的结局，而是一种结构。换一种方便的说法就是：所谓使命，就是有的人适合当地基，有的人适合做房梁，有的人做窗才能发挥他最大的潜力。假如这些方向搞拧巴了，让合适做窗户的去当了地基，那么这座房子一定不漂亮更不稳当。

我们来虚构一个能量模型，您就能马上学会我的意思。请注意，这个模型为纯虚构，并不指向任何人，请勿对号入座。

此结构主为丁年，月柱：庚申，月柱：癸寅，日柱：丁巳，时柱：壬子。

所谓丁火就是小小而精的火，如灯火、烛火、人间烟火等，怕风怕水，但能照一方。此命水盛火稀，能量小而精，四周被“冷”环境包围。一般江湖流派看了可能会告诉你：木弱或者缺这个，那个，得利，马上让你付二百块钱，给你起个带木的字，这是典型的流于表面。

此人想改命中，并不加木，木能生火，在现实中就是“稳定持续的精神输入”，比如去读书，去深耕专业；

用火，此命为孤火，应该找到志同道道的“团队”去进行“稳定持续的精神输出”，比如写作或者表达；

控水，请注意，一般人看到水多，第一反应就是把水砍下去，大错特错！问题不在于水多，而是要控制水的节奏，去做一些慢热的持续的、长期的。也就是说生命很适合做写作、讲述、视频内容等类型的工作。

因此，生命是什么呢？生命是一种能力和边界，只有能够承受住的福才叫福；承受不住的，中了一个小目标反而会变成“劫”。

太阳不怕风，烛光怕风，可烛光能照到的地方太阳却照不到。所以，逆命的第一步，不是人人都争着去做太阳，而是找到自己最合适的位置，舒展自己，让自己的潜力不被浪费。

讲完了“命”这个硬件结构，下文聊“运”。

您肯定听到过这样的抱怨：“我的命很好，出生不错，学历也高，可我就是运气不好”。

民间有一个非常著名的段子：“从文，三年不中；后学武，一炼误错祖辈，被逐；从商，遇运遇运；穷耕，大早大荒；最后学医，自撰一良方，服之卒”。

虽然是个笑话，但生活里很多人确实有这种感觉：干啥不成，吃苦愁赶不上热乎的，看着拉利却一辈子在二环上堵着，命但憋屈死。

是的，很多人为了“改运”总是做一些奇奇怪怪的事：买个奇运牌戴到脖子上、跑去请一些奇奇怪的东西供着...

我必须泼盆冷水，这些东西不但没用，还可能因为认知偏差引起负面连锁反应。

那么改运到底应该怎么改？

第一，运气不是运气好、点儿背，而是生命的一种周期，就像水和风一样起起伏伏。

中国人讲运、大运，用科学的词汇包装一下就是“能量周期”，所以当你发现自己无论做什么都打不顺的时候，说明你正在周期的低谷。如果这时候一个人还像前面那个段子里的人一样疯狂换赛道，从先文再习武、又从商、又种种，那就是和规律硬刚、十分不明智。

人生的低谷期想改运，别向外折腾，向内积累，按古人的话说就是“钻营”。外面都下大雨了，你还非得出去折腾，那就是硬刚，何不坐在家里，静下心来看着书写写字，提高一下以后堪能用的技能呢？

一句话，运气不好，不要急于翻身，频繁换赛道、借贷……运气不好的时候，不输就是最大的赢。

第二，一个反直觉的真相是好运比霉运值得警惕。

很多时候，真正淘尽人的不是霉运而是好运，霉运大多数时候倒霉却致命，好运却像放大镜一样会突然放大人的的一切：选择、短板、压力。回到文章开头讲的那个例子，有人中了一亿美元之后就会立刻放大人的能力不足、傲慢、贪婪。因此，改运的第二步，是一个必须保持头脑清醒，不要霍运，把好事变成坏事。

第三，改运需借势。玄学里有个词叫“借气”。觉得自己运气不好，观察一下身边的人是不是特别正能量？如果是这种能量场，尽快远离。所以改运就是更换磁场，和好能量的人在一起，自然就会发展。

运气不好时去走走，晒太阳，去健身把自己搞得精神气爽。这告诉我们的秘密：环境不好，心情就会差。

总结一下，运是变量，改命不是去修改，而是学会借势。无论顺伏，都能把主动权握在手里。

## 二、运

讲完了“命”这个硬件结构，下文聊“运”。

（此处略）

很多人觉得占卜就是“算命”，是想提前知道彩票号码或者提前问这笔生意能不能成？这个婚能不能？

但我听一位高人说过一句话，他说：“很多人都在用易经算命，但没搞清楚‘易’是什么。卦象从来不是平面的，而是立体的”。

这么想象一下吧：一个放在桌子中央的立体模型，当你坐在这这一侧来看时，它是吉是生机；可如果你站起来，走到桌子的那一边坐下去看到的却是凶。所以所谓吉凶，并不是绝对，取决于你站的位置、选择的角度。占卜并不是为了预测结果，而是为了切换视角。

如果你学过“六爻”，就会明白什么是“动”。卦里有动爻，意味着整个卦气就变。

## 三、相

相是一个整体的感觉，一个人面对另一个陌生人时，在极短的时间之内就会对这个陌生人做出初步的判断。靠的是什么？脸、眼神、气质、肢体动作这些不仅写着出身、教养、审美，也写着你这个人是不是正在“闪闪发光”的好运之中。

大家请注意，改相是最简单的改变运的方法实用且不迷信，请一定不要忽略改相的重要性。通过改相来改变命运吗？绝对的，而且实用简单。

第一，干净整齐。头发会留下第一印象，那么头发就要干净整齐，眉毛不能像杂草。眉毛乱的人给人一种心情不定的观感。把额头出来，搞个“大光明”，在传统逻辑里额头代表程，别让刘海压住你的运势。

第二，让自己看着“喜相”。有的人喜欢皱眉，嘴角下垂，那就对着镜子练习笑，舒展眉头，让嘴巴扬起来。多笑会改变面部的肌肉纹路，让一个人一看就想亲近。

第三，改变整体气质。有的人五官好、眼睛好，也爱笑，但若含驼背，显得垂头丧气的，一看就不精神。要时刻记住把背挺直，肩膀打开，走路时稳定、自信，不畏缩；说话时字字清楚，不要唯声蚊蚊。大佬文圈记：相是五官、气质等的一种综合。俗话说“纹路不如五官，五官不如气色”。

借势而起。对大部分人来说大环境不好，但对一小部分人来说正是施展才能的好机会。还记得开篇所说的吗？有人是太阳能照亮四方，有人是烛火可以照到太阳不到的地方。所以，一个人可能只是个朝九五的白领，在大更迭的时代，就可以借势而起，建立一番事业。

选择“势”。如果觉得自己居住的地方“势”不好，那就选择更适合自己的城市，也可以选择不同的国家或者行业。老话说“树挪死，人活”，一个人应该努力保持乐观的心境，这不是阿Q精神，佛学中有一个词叫“境由心造”，一个人面对同一件事情，因为心境不同，感受就会完全不同。我们这一既短暂又漫长，有些情况是我们如何也无法改变的，比如对宏观环境剧烈变动中，乐观对待是一种活法，面对也是一种活法。记住这一点：成功的人都是相信信念有效，失败者总把一切归咎于外部环境。

其次，人生决策必须谨慎。俗话说男怕错行，女怕嫁错郎。此话是人生经验的一种总结，有着非常深刻的道理。放在当下来说，婚姻是人生中的“合伙制”选择，会极大影响一个人的运势。一个相互支持、目标一致、财产稳定精神稳定的家庭关系，能够给人生提供强大的支持。选对一个好伴就是一次逆天改命的机会。

第三，要抵住短期诱惑。古人讲“立志”“自律”放在今天一样成立。人天生倾向于选择“马上得到”，所谓的“多巴胺陷阱”就是这么来的，但很多改变在短期内是看不见的，而是需要三五年。
