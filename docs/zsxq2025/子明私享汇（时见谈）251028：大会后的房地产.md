


# 大会后的房地产

发布专栏 知几共话

从“造富神话”到“家的本质”，高歌猛进的楼市站在了拐点上。

![](img/112632902861e12850e203f652a9f5bd_0_0.png)

2025年10月23日，二十届四中会公报发布，其中将房地产相关述置于“加大保障和改善民生活”部分，明确提出要“推动房地产高质量发展”。

这意味着，房地产行业将彻底告别过去的高增长、高耗能发展模式，走向高质量发展的新轨道。

不少的读者都在关注，大会后的房地产行业是否会迎来转变。今天，我们就借着大家的讨论，一起来揭秘未来房市发展的神秘面纱。

2015–2018是老登跑路的最后一次。

十年前的2015就是国家把房价炒起来，给老登跑路，到了2018，房地产进入利空时代。上海的房子很多不是老登的。老登跑路，就那两三年的光景。

好，这次可以好好准备一下，从2027开始，做一些资产清盘。

> 房产的时代已经过去了，房产后的利益集团已经被消失了。

那时的房产利益集团不会在10年后产生？

不会。

人口是最确定的宏观变量，AI机器人时代来了，大规模刺激人口出生已无必要，人口的供给与需求两端都已经被确定。

以京为例，北京的房价能起来是因为财阀、阀，你有钱你可以和小聚家一个小区，所以房地产“含权重”大的还能起来的。而我们“含权重”大的房子都是配给的，和普通人财富无关。

> 中国极少数地区的房价，还有上涨空间，但是房地产作为融资杠杆和化亿万已经结束了。

# 深度视野

那就是先进生产力的城市价值就是茅台和牛，其他就是散酒合成肉。

> 未来本质上除了绝版地块，只有独士土地的别墅才有价值。

子明：嗯，有道理，因为有土地，所以地段还有一定空间。

栅改的房价是城乡二元结构中城市对乡镇的剪刀差，也是权力对非权力二元结构中的收割效应体现。现在已经割不动了，没有新的收割对象了。

暴涨的房价过程中，最大受益者一直是权力阶，无论是个人还是政府。

在大会后，政府明确了房地产行业的定位：强化民生属性，推动高质量转型。住房的保障作用将替代投资作用，作为一项“民生商品”，走在未来的发展舞台。房价飞涨的时代一去不复了，我们将积聚能量冲击新的发展。
