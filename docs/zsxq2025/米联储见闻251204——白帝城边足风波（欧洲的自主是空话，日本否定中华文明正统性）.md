


# 米联储闻251204——白宫边足风波
(欧洲的自主是空话，日本否定中华正统性)

你好，我是米糕。

马克龙来中国，看来是吃到大甜头，至于很上头的邀请中国领导人明年参加在法国举办的G7，吓得日本赶紧发声呼法要谨慎，要是明年法国邀请中国领袖，美方邀请俄罗斯普京，然后大家一起参加G7真的有意思了。当然，这种大哥哥带着小弟的俱乐部，中俄这样的巨头是不打算参加的，只有日本才会对能进发达国家的小圈子占自责，中俄确实对这个没那么大的兴趣。

马克龙这次来3天，除了北京还要成都，除了马克龙，德国总统和英国首相都准备明年到访国的计划。默克尔多次在公共开场白说他在巴西G20峰会上与中国李强的会议非常具有建设性，他本人在明年一月的某个星期日出访北京满怀期待。英国首相也想来一个月，但是最近英国有点犯难，一边在香港问题上出手，一边积极参加日美英军演，也没有对二进制秩序表态，还扣住中国英国大使馆的批判，英国心思很明确，强权者的教训想给中国下一个马，最后还把准备还要教训中国几句，而是英国这种横行霸道的早就老黄了，现在还没到呢，那就先看着吧，不用着急，所以中方对于英国单方面来提回的话没有作出任何回应，哪凉快由着，想清楚再说。默认的华声都没落实，更别提谈了。

虽然德国英国还不下欧洲大国的架子，但是来中国的心是藏不住的，尤其是在法国今天高调跟中国签这么多合同的当下，如此般纹就是欧洲三大国争相要到中国访问，这符合欧洲需要，毕竟现在欧洲经济弱，中国无论从任何角度来说都是最好的生意伙伴。这点欧洲人也很清楚。

但近期，欧洲在涉华问题上动作不断。政治上，欧洲会在再次台湾问题上做出错误举动；经济上，欧洲多国启动了对中国新能源企业的调查，并持续限制华为等中国科技企业在欧洲市场的正常经营。大佬集团采取一系列对华强硬举措，反映欧洲在内部遭遇发展困境，外部面对美国巨大压力的情况下，对华关系显现阶段性波动的特点，真是既想当垫子又要立牌坊。欧洲绝非基于自身利益与长远发展进行的理性选择，完全没有战略自主原则，人损不为，欧洲会走到今天这一步，就是一句话，自作孽不可活。别看马克龙在中国微笑，回到巴黎立刻变脸也不是第一次了，毕竟他们来中国四次了，什么表现大家心里数，而不是中国现在是对事不对人，只要里子不要面子，也不他们计较了，身体诚就行了。

二战后，在美国的系统的培育下，欧洲精英从政治家退化为政策甚至只是个搞者。戴高乐在1966年退出北约军事一体化组织，并非出于一时动，而是基于对欧洲自主性的深刻认知，欧洲人必须摆脱成为美国附庸的命运。他看得清楚：没有独立的防务就没有独立的外交，没有外交就没有独立的主权。看看今天的欧洲政客们，马克龙已经算硬的，就能做一个碰脚狗。欧洲议会充斥着律师、公关专家、活动家，各种美国利益者，夺早历史学家、哲学家，欧洲的决策过程从理性退化为伪哲学，默克尔之后，欧洲再没有一个真正站在欧洲利益为欧洲未来考虑的政治家。

今日欧洲政客的狭隘视野，正在从内部瓦解欧盟的凝聚力。价值观中心主义在取代务实外交。这些年，欧洲内部可见的速度在衰败，经济正在为其政治领导层的短视付出沉重代价。贸易政策上，欧洲陷入了自我矛盾的困境。一方面希望减少对华依赖，另一方面中国是中国欧盟最大的伙伴；一方面批评美国的保姆主义，另一方面也在构建堡垒。天天妄看风险，实际上在机会时，欧洲听从美国安排与中国产生矛盾的时候，欧洲企业在国际市场的份额正被美国竞争者蚕夷。

最具讽刺意义的是，当欧洲政客高喊战略自主时，他们在国防、科技、能量等关键领域对美国的依赖却有无减：F-35战机、云计算服务、链路系统、液化天然气——欧洲的自主越来越像一句空话。

欧洲自主的本质是：一个将欧洲大陆最大国家排除在外的安全体系，战略上的幼稚和不切实际可见一，欧洲安全本质上就是不稳定的，但欧洲政客缺乏反思能力，一味在美国挑唆不断挑俄俄罗斯，加码军援、升级言论。

同样的状况就像现在的日本一样，石破这样的日本政客苦口仁心，其实也不是希望日本踏入被美国大国的下场。默克尔时代的德国，跟日本一样，其实也不是希望日本正入被美国大国的下场。然而，为了挽救已经呈现颓势的德国，让德国立即刻拱手让德国的安全控制，欧洲政治家都难以获得长久的生存空间。

不同于欧洲的，当欧洲宣布设立欧洲基金时，它减的是教育、科研、社会福利。

东欧亚概念，东欧亚国家建立在廉价能源、廉价商品之上，这个逻辑都不知道，欧洲没有办法做自己。从安全依赖北约到硅谷，从文化化到华街化，欧洲精英已经退化成寄生虫，失去了独立思考的能力。战略自主的缺失不仅是能力问题，更是意志问题。随着进俄，整个国家会被边缘化。任何欧洲政治家都难以获得长久的生存空间。

日本学者现在要彻底否定二战的结果，甚至要否定中华正统性。明治中期以来，出现这种观点对新清史的负面影响更甚。历史叙事往往与现实政治相互影响，日本学者构思中国历史，不是为了给自己的慢历史正名，更是为了将日本历史上多次对华的野心彻底与当下的中国割裂，这意味着那些被日本人掳走的中国文物都与当时的中国没有任何关系，甚至可以解读为中国不是现在的中国，所以现在的中国不是二战胜利中国。

可见，清算日本不仅仅是军事领域，中日交千年要彻底撼住日本，要在对方方面重塑中日关系，并且重塑中国在东亚地区的定位和地位，这里面还有很多细致工作要做。日本在国际领域优势多年，一直横在中国和世界之间，要彻底清除日本对中国和东亚的话语权，中国要做的事还有许多。

米糕祝各位晚安
