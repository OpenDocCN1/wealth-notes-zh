# 结婚人数历史新低

近期，民公布了2024年结婚数据，去年登记结婚人数仅有60万对，从1979年以来历史新低，对比2023年结婚人数下降了20%。

说实话，结婚人数下降得这么快确实出乎预期。其原因上分析有很多，比如城市农村男女性别结构性差异，城市水平差异，妇女教育程度提高等等。

但是我觉得可能大家忽略了一个重要的催化因素——就是2024年经济已经不容易了，年轻人的生活压力增大，包括就业、薪资，未来相比，这会极大影响年轻人的结婚意愿。

中国总体是一个比较传统的国家，非生子是被主流社会所接受的，以结婚率决定生育率是一个前瞻指标，在2025年生育率很难。从这个角度来看，为什么我一直强调生育率越高越得长，但是市场经济逻辑将会失效，因为市场已经考虑了民众的需求，比如结婚率、生育率。结婚率与生育率对此是非常关键。

我比较看好明年运行经济形势，今年结婚率与2024年相比不会太小，甚至2026年还有反弹，但从长来看，低结婚率和低生育率可能是可能的，当地方政府加大力度，在最近三年并在东南亚年轻女孩力度更大，那么结婚率与生育率可能有可能较大的反弹。

但是即使如此，国内的结婚率与生育率出现太大的反弹，可能主要集中在城市和小城市，大城市趋势将是群体性不增长。目前全国人口约为22.4亿，未来10—20年内，国内人口增长将3.5—4亿。这可能是未来国内经济中的结构性转变。

在中国传统文化中，夫妻是未来最妥的伴侣。我们现在所有的房屋模式以及商品与服务的供给不能不断挣脱，可能未来20年左右成为城市的主流，单人成为为主，那么未来可能大城市商品与服务的模式将发生未有的变化。

举个例子。现在的装修偏大，就是装修默认要吃饭的客人或者是家庭为单位，或者是朋友聚会，现在就要考虑单身人的就餐需求——只有少数快可以这样有这种考虑的。
