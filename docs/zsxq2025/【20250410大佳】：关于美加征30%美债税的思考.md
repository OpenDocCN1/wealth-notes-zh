


# 大佳 250409:关于美加征30%美债税的思考

关于美加征 30%美债税的思考——具有合理性，谨防三次冲击。（非常重要，建议阅读）

消息来源如下：
美国政府准备恢复之前免的持有美债利息收入的税收，税率为30%。

这是今天美债暴跌的主要原因。

我一听到这个消息之后，非常震惊。但是，认真思考之后，我们认为，这个消息可能是真的，且站在川川的角度上，是一个可能出台的措施。

原因如下：

1. 征收数量庞大美债税收，可以获得大笔税收。这笔税收有利于增加政府的收入。

2. 对川来说，美债收益率也许不是关键的，美元才是关键。征收美债税之后，虽然美债收益率暴涨，但是美元指数下降。

3. 对于很多国家来说，如果有美债获得利息收入，这部分收入是要缴到本国，作为所得税。对很多外国投资者来说，尤其是欧洲的投资者，美国不征收，本国政府也会征收。如果美国征收了，那么本国政府征收的反而就少了。其实对他们来说影响不大。

那么，对谁影响最大呢？对于亚洲国家。尤其是我们。因为中国是中国美国最大的债主，而且很多美债的持有有我们央行和外汇管理局。

既然川普能够向我们征收如此高的关税，同样，也会针对我们征收美债利息税。

如果这个消息是真的，会发生什么？

第一，美债违约率大增。最后可能迫使，美联储急注入流动性。

第二，全球市场，尤其是亚洲市场，会掀起一新的动荡。

我们认为，中美谈判的概率越来越低。现在不仅是贸易脱钩，可能要上升到金融脱钩。总之，风险系数进一步上升。**对A股影响不大，对港股，尤其是生科技，影响会很大。**第三次冲击，概率在上升。
