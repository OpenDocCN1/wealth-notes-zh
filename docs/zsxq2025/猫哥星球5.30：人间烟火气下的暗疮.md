# 嘉宾供稿

最近，安徽亳蒙城县发生的一起群体性食品安全事件，在互联网上闹大了。这场看似偶然的食品安全事故，实则暴露出地摊经济狂奔突进，背后深层的行业暗桩与监管漏洞。

事情起因是一个账号名为“如花（提拉米苏王国）”的本地网红主播，在5月20日这天销售了200多盒提拉米苏，结果直接把上百名粉丝干翻了。许多消费者在食用后集体中毒，症状包括高热、腹泻、便血等，甚至网传有人直接因肾衰竭进了ICU，且中年龄最小的只有6岁，截止到24号，医院还躺着130多号人。

整件事目前饱受争议的主要有3点：产品、模式和监管，我们一个来说。

首先，提拉米苏这个经典意大利味蛋糕，那绝对是对近年地摊经济不可或缺的品类。就在我自己生活的周边，几乎所有的地摊集市，都有2-3家卖提拉米苏的摊位，甚至还有在小区门口个小小摊直接卖的。在蒙城事件以前，我也买过不下5次地摊提拉米苏（包括小区门口）。说实话，味道一般，但现在回想，庆幸是身体没出问题。

说回产品本身，提拉米苏的传统工艺其实就是把生鸡蛋的蛋白、蛋黄打成酱以后，中间铺上饼干冷冻的一种甜品，由于全程不需要加热，所以它的制作相对便捷。

但是它对原材料和保存方式的要求却比较高。

比如鸡蛋，想要味道纯正，就必须采购无菌鸡蛋，但成本就会提高。而选用普通鸡蛋也不是不可以，但需要加热70°以上进行杀菌处理，而这又会牺牲口感。

最怕的是从成本和口感考虑，选择普通生鸡蛋制，又不进行加热杀菌，那么一旦制作、储存过程中卫生条件不好，就会导致沙门氏菌、李斯特菌或大肠杆菌的交替污染，严重点还会威胁人的生命。

并且，成品还对冷藏的要求，常温状态下超过2小时就会开始变质。

所以，用一句话概括就是，制作销售提拉米苏虽门槛不高，但是相当娇气，稍微不注意，就会威胁健康。

这位涉事的主播，应该是在食材、制作、储存、销售过程中某个环节或者全部环节出了纰漏，才酿成这起群体性食品安全事件，具体原因有感兴趣的朋友可以关注下后续贯信息。但个人认为，这一切说穿了，无非就是成本问题。

我咨询过有家庭制作的朋友，大致反馈就是如果自己亲手做，一般个6寸的提拉米苏食材成本就在50-60元左右。外面卖的提拉米苏一般可以切3个销售单位，也就是说光单位材料成本在16-20元上下（这里不需要考虑规模化问题，家庭式生产，1天个100个单位，还谈不上规模化）。

现在网上出来的主播520销售的单价是25块，这个价格不搞点减项，漏项是没有什么利润的，因为通常情况下，利润至少也得5成以上。

食品安全的重要性其实都清楚，但为何消费者对于现在比较流行的网红主播警惕性非常低呢？这就是本期内容要谈的第二个问题——销售模式。

审视“如花（提拉米苏王国）”的销售模式，其和很多本地食品网红博主的套路几乎一样。通过自媒体平台，比如小红书、抖音等，把滤镜开到最大去展示自己产品内容，涉及食材采购、制作等，然后夹杂着个人IP的信息，比如个人形象、居住环境、车子、旅游、健身等。反正就是给潜在客户输出一种信息：我分享的是一种精致生活，一种生活态度，产品是我的爱好，相信有人设包装，产品一定不差。

于是，经营不断的粉丝就会产生购买需求，加微信，通过微信蓄客，最后发布产品销售信息，开着精致的汽车，到达指定位置摆擂，客户线下支付，商品交付，然后边卖边直播，形成第一次传播。

不要小看这种销售模式，我了解的情况，本地博主靠这套打法，月入10万都不是难事。甚至更粗暴的运营逻辑是自己不用亲当牛马，自己只负责人设，做内容，客户服务，通过网上成熟的配套业务就可以把生意做成了。甚至很多运营者压根不知道“食品安全标准”是啥，觉得“不拉肚子就算合格”。

本质上，这种模式就是用内容和情绪价值覆盖了顾客对食品安全卫生的需求。在当下比较卷的环境下，又要赚钱，又要讨好市场，用健康做代价，不出问题才怪。

网上没有人对这种销售模式提出反对，毕竟很多地摊从业者没有营业执照、食品安全许可证、临时占道经营许可证、健康证、税务登记证。属于标准的“三无食品”，至于卫生安全基本靠信仰。

但是，在当下大环境不佳的情况下，这些反对意见很多会被喷成唾子，说什么要对生活容易的小贩包容，不能给穷人留活路等，一旦出问题，大家除了指责商家，就会把矛头指向监管。

最后谈谈监管问题。

地摊经济的兴起可追溯到2020年新冠疫情初期。为了缓解就业压力，我们城市明确“不将占道经营列为文明城市考核内容”。结果几乎一夜之间，全国涌现几千万流动摊。这种“放水养鱼”的政策确实激活了城市毛细血管，失业者得以以谋生，市民享受便利，城市重拾烟火气。但是造成的后果就是市场监管盲区的不断扩大。

为什么现在对地摊经济的监管手段失效呢？个人认为主要涉及几点：

- 其一，上面松了口子，下面有群众的共情，这让监管尺度不好把握。
- 其二，就算抓个现行，处罚力度也不大，比如此次涉事罚款力度低。
- 其三，地摊的监管确实有限。
- 其四，对于出了问题，很多时候。

地摊经济的优势与劣势如同硬币两面。它确实创造了就业，但是发展到今天，确实到了整顿的时候。《食品安全法》的条文并不是空文，如果不能及时堵上这些漏洞，类似的悲剧还会重演。我们希望看到的，不仅仅是涉事商家受到应有的惩处。更希望看到的，是监管部门能够以此契机，真正有所作为。是对所有类似网红的一次彻底排查，是对食品安全监管体系的深刻思考与完善。对于个人而言，大家一定要警惕，不要被滤镜迷惑了双眼，不要被故事模糊了判断。味道再诱人，包装再精美，如果连最基本的卫生安全都无法保证，那一切都是空中楼阁。未来的地摊经济需要更多科技赋能与制度护航，让每一份街头美食都得起良心与法律的检验。毕竟，真正的城市温度，从来不止于烟火，更在于安全。
