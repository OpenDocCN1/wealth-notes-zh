


# 智谷趋势内部研讨
2025年11月04日

*本文内部资料仅供会员交流与决策参考，所有观点与分析均不作为投资操作之依据，请读者对市场风险保持足够的敬畏*

1
在十五五规划建议稿中“消失”了三个关键词，透露出重要信号。第一个消失的是提到“房产税”，十三五、十四五都明确提到“推进房地产立法”。而且，房地产被划入“民生保障”的章节，在经济体制中成为配角，经济形势稳当，难以再承受严峻的财政改革动作。不提税不一定收益，十五五规划建议稿提到“建立住房全生命周期管理制度，维修、维护等成为收费的可选项”。第二个消失的是“和平与发展”是时代的主题，取而代之的是“变化交织、动荡、地缘冲突突发频繁”、“大国博弈更加复杂”，表明全球局势并不稳定，和平并不是世界的主题。第三个消失的词是“两共”（融入新时代解决台湾问题的总体略），涉及“台独”的表述，以往的“高度警惕、坚决遏制”升级为“坚决打击、首次并联、反对势力渗透”。近期警方方面对“台独”分子沈立的侦查是一个实证。智谷趋势研究员陆虎认为，“斗争于斗争”并非只是口号。

2
经济基本面出现走弱的信号。最重要的制造业PMI，10月录得49.0%（前值49.8%），连续7个月小于50的荣枯线。内需均出现回落，新订单48.8%（前值49.7%），出口订单45.9%（前值47.8%），在手订单44.5%（前值45.2%）。智谷趋势研究员陆虎认为，10月PMI走低主要有两个原因：一是中美贸易摩擦反复，导致市场预期、企业经营压力上升，减少生产；二是九月抢热蓝产透支了10月的需求。另一方面股市高涨，中国指数内涨（11月3日收）达到24%，但户却没有大的回撤。1990年日本泡沫破后的10年后，曾出现三轮行情（每持续一年以上，大盘暴涨40%以上），日本普通人都大规模参与，主要源于收入预期下降、预防性储蓄、负债负担三重压力。我们当下的现象值得关注。

# 3
上周出台的黄金收新，目的不止于财政增收，而是减少黄金实物在民间的流通，将其纳入官方体系，强化管控。黄金的投资属性和避险属性做了隔离。智谷研究员谭勇分析：第一，实物黄金交易，通过黄金期货交易所和上海黄金交易所两机构才能享受免税政策，而市场上其他第三方则需按规定纳税，此一举强化了两大交易所的差异性地位。未来，实物黄金投资态势逐步集中于交易所体系内，实现统一化管理和全流程监管。第二，此次减税主要针对实物，证券黄金产品如黄金ETF，继续免税待遇，显示国家限制收藏以避险为目的的购买金、金饰等实物黄金，未来将不再增加持有和流通成本。新的本质是通过制度设计将黄金的“投资属性”与“避险属性”做了隔离。前者被纳入国家主导的金融体系予以鼓励和规范，后者被逐渐弱化，不再支持为一种普通的民间避险手段。

# 4
前季度各省经济数据出炉，浙江模式和湖北模式出挑，西藏亦展现“赢藏”模式。东部省中，浙江GDP增速最高（5.7%）；中部省份，湖北增速和增量均为第一；西部省份，西藏增速最高（7.1%）。智谷趋势研究员陆新锐注意，这三个省份恰应了中国经济三大趋势：科技突破、产业筑基、安全兜底。浙江是全国科技高地，前三季度，高技术制造业增加值、数字经济核心产业增加值、数字经济核心产业服务业收入增长12.4%；11.6%；3%。湖北属于基础工业大省，汽车、钢铁、化工、电子产业发展强劲，紧抓十五五大主题；西藏是战略工作区，更是重构权的枢纽之一，得到了中央财政的特殊关注，基建全面开花（如雅江水电站、川藏铁路），GDP也能翻倍。

# 5
央行推动信用“释放”。10月27日央行发布，对于疫情以来，违约金额不高已全额清。智谷趋势研究员张胜分析，这五年才能修复其信用体系，背后呼应“增长”的需求。这次信用释放条件很清楚，在于筛选出一批还款能力、历史无累的优质企业，扩张发力，让那些已经爬起来的人继续贷款。

# 6
中美关系趋缓，人民币汇率连续走低。之前人民币汇率最高到7.08附近，跟客观氛围形成鲜明反差。智谷趋势研究员张鹏龚认为，一方面是金融市场“买预期”偏离，另一方面是美联储的韧性。虽然美联储在10月再次降息对亚洲影响较大，美元指数连涨至9.9。降息后，部分经济数据回暖，但制造业PMI连续7个月收缩，意味着明年中美博弈与经济环境的复杂性。

# 7
深圳将成为中国第三个举办APEC的城市（上海、北京之后）。选择深圳而非广州、成都、武汉等其它城市，智谷趋势研究员透露至少有三个原因：第一，深圳更具实力，是中国外贸第一城，深度嵌入全球产业链，符合APEC主张；第二，更能代表中国的科技创新走向，在全球化时代，中国维护多边主义的发展样本，加速经济一体化进程。第三，深圳国际化。之前衡量一座城市是否具有世界视野三个指标：没有举办过世界盛会、没有世界级的公司、没有对外输出世界的模式。中央支持深圳建设中国特色社会主义先行城市，正好补足了深圳的短板。

# 8
未来五年的经济重心并不是科技，传统产业依然占据上位。政策考量体现着“既要”的企图。十五五规划建议，现代化体系首位，其中“优化提升传统产业”和“培养新兴产业”明确指出，巩固采矿、冶金、化工、轻工、纺织、机械、船舶、建筑等在全球分工中的地位和竞争力。这些重工业化、传统行业跟地产是一条线上的蚂蚁，底下藏着内卷。顶层设计并非又要。智谷趋势研究员黄诚认为，第一，制造业是科创最大的源头，美国制造业占比已有10%左右，但中国科技创符合当前大国博弈的逻辑；第二就就业形势进一步恶化；第三防止产业转移被东南亚等地掏空，导致制造业比重下滑。

# 9
香港有望在2025年内成为全球最大跨境财富管理中心。机构Bloomberg Intelligence最新报告预测，2025年，香港管理的跨境财富规模有望达2.9万亿美元，一举超越长期基准瑞士。此前包括瑞银和瑞士咨询等机构都曾预测香港将在2028年能实现这一目标。领先的关键原因是，今年上半年香港保险行业新增保单保费达到纪录的137亿，同比增长50.3%。彭巍持续看好香港跨境理财趋势，认为未来5年均增速有望达到12%。持续的原因有二：一，地缘政治的不确定性强化了资产分散配置的需求，大量资产配置在中、亚洲以及中国内地转向香港，减轻对传统欧美财富管理中心的依赖；二，中国内地财富保值、增值以及财富传承的需求日益增长。在阿里和腾讯之后，电商巨头京东近日也宣布进军香港保险市场，看的正是香港在跨境财富领域的前景。

# 10
楼市已无“金银十”。失去了政策托举，10月二手房“量价齐跌”。广州4连跌、杭州7连跌；北京、上海、深圳和成都成交量也已与年内其他月份无异。环城二手房均价13268元/平方米，同比-0.84%，同比-7.6%，跌均扩大（中指院）。央行三季度“城镇储户调查报告”显示，居民预期从2019年至今的最低点，连续两个季度上涨。智谷趋势研究员分析，十五五规划对房地产“民生保障”定位显示大力转型几乎不可能。

# 11
由于供需变化，就业市场愈发两极化。报告显示，10月发布的数据显示，科技和“AI+”需求旺盛，其中22个与AI相关、8个与汽车相关、机器人设计、软硬件结合；另一方面低门槛需求旺盛，比如休闲消费类运动教练、按摩师、足疗师、销售员、客服员、运维员。智谷趋势研究员注意到，高学历需求上升，高学历、硕士、博士、工程师、程序员。这种结构性的变化让传统行业面临压力，消费者信心继续压力。

# 12
中国核能技术具有重要突破。日前，中科院宣布位于甘肃的铋熔盐实验成功实现示范堆，预计可在十年内完成产业化。智谷趋势研究员指出，项目的成功意味着中国第四代核电技术实现了弯道超车，对世界格局产生重大影响，解决能源卡脖问题。小型模块化反应堆未来应用于航母甚至星际飞行器等场景；摆脱了传统的水的依赖，可以在沙漠戈壁、新疆等内陆盆地建设，进一步提升。

# 13
资源主义高涨，多国将稀缺资源作为“武器”。智谷趋势研究员孙凡了近期资源国的做法：一，出口禁令和配额。比如刚果（金）自2月起实施长达7个月的出口禁令，调整配额，导致11月价格涨至39.6万元/吨，较年初涨幅134%；布宣布从2027年起禁止精矿出口，加纳计划于2029年停售锰矿；二，加税和控制。维比亚将矿产进口税从0.6%提升至3%，并拟控股未来矿产30%以上涉及20余个锂土矿；三，建矿产联盟，南美成立“欧圈”，推动资源化；四，价格手段由长期谈判转向“量销不价”。由于此类资源对于新能源、算力、数据中心、无人机等高端制造属于刚性需求，将在短期内加强资源的谈判能力，引发价格上涨。中国在全球收购了大批战略矿，特别警惕由于资源处于价值链底层，只要出现替代者，就难免周期反噬。

# 14
随着美元的降息和宽松，连带影响初步显，新兴市场的主权债务终于喘口气了。这意味着大部分债务人迎来喘口期。前几年美元加息时，斯里兰卡、巴基斯坦、老挝等新兴国家的主权债务纷纷暴雷，而现在在主要市场下降预期的驱动下，新兴市场主权债券的风险溢价已压缩至十多年来的最低水平——即债务需要支付的利息变少了。安哥拉、肯尼亚及亚南等国借债机会成功发行了新兴的主权债务。不久后，美联储或放缓降息并于12月1日结束缩表，这会降低偿还美元债务的成本，进而改善发展中国家的金融环境。智谷趋势研究员锦锐认为，主权债务危机的阴影可能被驱散，世界进入新常周期，直到下一次美元紧缩周期临。
