


# 男人的5种致命失败行为

原创：U 君 公众号：赢在8小时之外 25年8月22日

男人之所以是男人，就是因为他的手中掌握权力。

当然，我这里说的权力，不仅仅仅是指官场上的权力，更多的是人与人交往时体现出来的权力。

如果你失去了这种掌控力，那么你就会变成案板上的鱼肉，任人宰割。

今天我就跟大家聊5个常见的“失败行为”，我会拿男人们来举例子，不过很多法则都是男女通用的。

## 1. 金钱：权力

如果你耐不住他的软磨硬泡，把钱借了出去，那么等半年之后，他概率不会按时还钱，甚至还能跟你玩赖。

如果你消息发多了，对方还会变得非常不耐烦：“不就5万块钱吗，至于整天追着我这哥要吗，真烦人。”

发现没有，形势跟半年前已经发生了反转；当初借钱时，他是孙子、你是大爷；现在讨债时，他是大哥，你是孙子。

为什么会出现这么大的反转？

原因也简单，对于大多数普通人来说，金钱就是权力，你手里握着金钱，你就拥有了某种意义上的权力，别人就要看你脸色行事。

反之，如果你把金钱交了出去，别人手里握着金钱，这时候，对方就有了权力，你需要看他的脸色行事。

这个法则不仅适用于好兄弟、好蜜之间，就连父母与子女之间也适用。

比如，当你参加工作之后，你的父母很可能会诱骗你：“把工资都交给给我们保管，我们来替着，将来给你买车、买房、办婚礼。”

如果你信了他们这套说辞，把工资上交了，那事情很可能会失控。

比如，他们的钱会被骗子给骗走，或者，等你需要用钱时，他们就出尔反尔、不认账。

其实，这些并不是最大的风险和损失。

真正的损失：只要你把钱交出去了，你就会处于“失权”状态，而人与人之间的博弈的就是“握权力”。

如果你的手里没有任何权力，那么你就像一个被抽掉了脊椎的软体动物，任人拿捏、任人宰割。

其实这个法则同样适用于女人，女人如果把钱借给朋友，或者交给父母保管，很可能会造成“失权”。

如果你是小孩子，你不觉得这件事有什么大不了了。如果你是经历过社会毒打的成年人，你应该清楚，失权的那种无力感，痛彻心肺，想要扭转局面都使不上劲。

男孩从什么时候开始成为男人？就是当他做重大决定时，不再考虑父母的意见和评价，也不用担心“没法向他们交代”。

比如，真正能成人的人，一定能决定自己的学业、事业、婚姻大事。

比如，不想读书了，就直接辍学（当然不是我建议大家辍学，除非你像乔布斯、比尔盖茨那样，拥有雄厚的家庭背景和商业成就）。

比如，想去哪个城市或国家工作，说走就走，不在意父母的牵绊。

## 4. 支配权

其实这个话题我在公众号上说过很多了。

在25-35岁之间，一定不要让自己处于失效。否则的话，你的能量根本激发出来。

所谓的“顺从”，本质上就是听从。因为当你不能感受到支配感充足时，你的能量也是不充足。

所以，一定要把支配权牢牢掌握在自己手中。具体做法就是：大胆去跟交往，不要害羞。如果“正常途径”确实行，那就就要走偏。另外，不要问问题。

这就好像，在登山之前，认真地问：“这安全吗？”他们大概会认为你是个神经病。

## 5. 统治权（主导）

男人最有男人味、最有魅力的时候，就是他拥有统治权的时候。

比如，一家小饭的老板，一个小办公室的主任，一个小公司的领导，一个小微信群主，一个小大众榜。总之，当他说话时，下面总会有人在认真听。很多人之所以选择创业，并不是为了赚大钱，因为很多公司都是养几个人，收支平衡而已（真正的利润来自其他方面，比如房子租的）。

但是，这个创始人能够获得很多额外的能量和好处。举个最简单的例子，有些小老板觉得谈女朋友、相亲的性价比太低，自己总是处于“被挑选”的地位。但是，如果自己成立了一家网红公司、文化公司、新媒体公司的话，月薪5000元就能招聘各种高才和美女。

这时候，自己的生态位是老板，美女的生态位是员工，那么很多事情都可以顺理章地进行下去。我之前说过，“女人崇拜男人”这种组合才是稳定、长久的。如果在一段关系里，男人不能主导，那么这段关系很快就会摇摇欲坠。
