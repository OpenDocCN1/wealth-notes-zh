


# 四月引起已付费

原文：不忙了外人的视角

前言

你们期待的四月又要来了。每天都有人问是不是春行情结束了？夏天又要来了，为何问春行情是否结束了？大家的关注点到底不是行情结束了吗？

我之前说过，这股市可能有一周持续行情的，如果春天突然集中了，那么行情时候就会非常糟糕，中间休息一波，后行情量再加回来。

那么我们反思一下，你真觉得这波是不是很强呢？

伴随着热点，突然出了一个强势板块，但连一个强势的持续时间长的板块都没有，春季行情被奇覆，由于DeepSeek的连个大妖都能被出来，这算什么圈子？

不过我们反过来想这股市为什么这么强？

答案很简单，我们被美股接纳了。

就很尴尬，美股的AI泡沫被我们的新技术给截了，不能说在技术上我们先进了，但逻辑性比较，美帝是被打了了，也就是说他们现在高值的一切预期期基础被摧毁了，擂王台下一个主角偷了星际门人，在现在这成了最大的笑话。

王者甚至被公开卖了贵资。

东升西落是必然，美股大跌也是可能的，非常难，最好的办法就是季节性见，伴随着的就是一个调整，坏一点的可能就是直接碰了，看2000年的网络泡沫。

好消息是美帝时不同同往，2000年以前怎么折腾都没事，藏在泡沫里，但当泡沫一破，就再不回头了，这又要彻底倒逼了科技筹码。

最近马斯克不当效率长了，说明明锡线已经向老诸们投降了，不敢犹豫下去下去了，其实线跟美联储可以是合作的，无非是非利益问题又要哑了。

所以大家看三个月后最后一个纳斯达克还能创造奇话，从垂直废地里爬起来，这一定不是市场发现了什么价值，而是靠哥芬达成了某种奇迹。

有人，这是做空的资金获利了。

笑死了，你把金融资本看得太斯文了，A股翻起来，量化在低位有利都能跃狗，怎么等到美国量化就成了良民？全世界都认为纳斯达克市值过高，说不多了，看着也得五折起吧。

这里到底有多大的空间？然后抬头就放手了，这可能吗？

只能集线坐庄的人一看恐吞见到结果了，于是联手停了下来，看情况打算下一步的目标。

我上一篇文章写过，目前美联储正措措不过是过于密集集团的总领。

双方对弈来我往，戏数大多了，美联储并不想弄崩美股，毕竟美元的财富价值锚定了美股，看国内有多少人都跑去买美股，你知道的，如果美股没了投资价值，这些财富还会留在里吗？

> 别看美国盛衰，如果美股崩了，美国经济将被重创，或许可以把前任送上来说，让他退休了，无了了，可特还在，马上就是中期的选举，美国还是很危险，你把经济拆毁了，铁粉也许有可能成黑果，到时候没了美元支持，美国王族只会被波迪家族打垮了。

美股这种状态下，对A未必不是好事，我的A的机构向来是看股市脸色的，纳斯达克跌，A科技股也不算难折。

今日今日，科技不起，赚钱自然就差了。因为最近科技回调，所以很多人自然的认为，这类行情已经过去了，毕竟这几年屡慢了，大家都习惯了熊市，就被套几年就出去。

其实不可如此。

之前已经通过MLF这个工具把市场净溜了630亿资金。

3月30日，财政部对大银行注资5000亿，定价增，粉丝问这是什么意思？不知道哈意的，你就肯放水。

为什么要关注？因为这几年包括银行在内的金融机构都被房地产给拖累了，这里我就不展开多说了。

之前大资金为什么在金融机构中空转？有的人不想借，需要借钱的，有多少钱敢放借给它？毕竟银行是有考核的，你背一身不良试试试。

98年财政部给了四大注资，同时成立四大资产管理公司接盘了四大的坏资产，银行这才可以放手了。

98年之前，是有一次房地产泡沫破裂的，当年炒楼花镜的是海南，但炒过的可不是海南，有年纪的可以回去下自己城市里的老尾尾，到底是哪个时期的挑子。

这几年如果你只看着指数，你会发现资金非常紧张，但是大多数人对经济的体感，没有人会觉得是松时候了，钱在账面上，在数据上，没有办法流到你的口袋里。

所以先为发放刺激政策，鼓励消费，再给银行补充资金，甚至可以放宽一点考核指标，让流动性好起来。

当然，还有一个外的助力，那就是全球大宗商品涨起来了。

大家可以看到黄金价格，历史永远是重演的，历来，金价涨起来之后，其他大宗商品的价格也会跟着起来的。

记住，解决房价最好的办法就是涨房价，还是那句话，当一晚10块的你，你还卖一万的房子吗，如果一晚涨到了100万，你还买得起一万的房子吗。
