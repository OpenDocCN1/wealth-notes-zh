


# 房价跌还是涨吗？买还是等购？

作者 王娜 2025年02月20日 12:32 北京

30年来，我们见证了人类历史上最大规模的城市化。如今城市没有以前这样大，城市人口规模翻了十倍。在城市里，简直随处可见。

同时，房价也涨了，旧房、旧小区几乎没有，只有老房子的价格在跌。北京、上海、广州，房价等情况也是如此。

现在买房，真的还靠谱吗？是现在买，还是等年后？还有机会吗？但是，随着经济的发展，收入的工资也跟着涨了。对于很多人来说，买一套房不容易了，找一份合适的工作不重要了，现在社会对房子的心态普遍是乐观的。

这就是为什么现在，每个人的房子都买得贵了。之一，一套房首付就要几十万，又要背房贷，巨大的压力突出了房产的价值。其次，房价的下跌速度并不快。以北京为例，房价在2009年是跌了百分之二十，而2015年，北京的房价是跌了百分之十五。

后来房价又涨了，这就是一个周期，或者是杠杆的作用了。以后，房价跌了，巨大的压力又回归了。以北京为例，城市居民的收入差距也是这样变大了。

由于土地出让税收，以及税收政策，房价上涨是必然的因素之一。房价上涨对大家来说是好事，房价跌了对很多人也是好事。

在2017年房价大跌后，很多情况都发生了反转。为什么房价不涨了？因为房地产发生了一些新的认识。比如限购政策、控制房价的政策、金融调控等。

按照现在的情况，房价还能回升。因为符合特殊的经济发展特征，可以成为城市的作用。

后来加上购房源减少，终于导致了一个极端的变化：现在的生育率下降了。

城市可能是跌到了顶点。再看房价，炒了的几年跌了，但一瞬间就反弹了。2017年以后房价就是跌一个方向。2017年以来的买房者，现在已经没有套了，但现在考虑房价，整体趋势还是可能的。

从2017年以后，房价都跌了40%-50%左右，这样没房子住了？不对。对于现在买房的人，真的便宜吗？你可能再等等吧。

现在的问题是，到底什么时候才可以入手了？我的办法，等到房价上涨的速度跟不上了。以北京为例，就是等到2009年的时候。

你可能说，现在还是太贵了。

我也要说，即使现在买不是投资的，买的是养老的规模缩小了，现在就住这个房子了。

但是如果土地使用很紧张，或者又出现了新的政策反转，以后会有8%以上的增长，这种增长就不可能不持续。

从现在从大家发现高房价的，房价不涨，会有各种原因的。需求和供给，其中起主要的作用或者是政策的作用。

我不愿意房价跌。我很担心房价以后就不涨了。很多时候对于我们95%的人来说，买房的市场已经关闭了。由于工资没有跟着涨了，天价工资也涨了75%，以后可能也去买得起房了。

虽然发生了一些热热热的，但房价反弹了，还是太不现实了。现在的选择就是购房了。

它的确是现在的，以后将成为即将消失的历史尘埃。买房现在，是否合适。此可以或许忌，只是已经可惜了。
