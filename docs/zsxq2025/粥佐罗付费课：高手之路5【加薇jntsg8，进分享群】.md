

# 第五章：如何学会金钱？

首先，你要学会从挣钱到管理钱，从管理钱到投资钱，从投资钱到赚钱。这并不难，但要从现在就开始做。

其次，你要学会存钱、理财和生财。

但是，很多人一有钱就花光，挣了钱就去挥霍，结果导致生活越过越穷。

## 1. 学会存钱：养成“储蓄”习惯

学会存钱，是从父母开始的，从小就开始花零花钱、攒零花钱。你可能会想，存钱有什么用呢？

学会存钱，不是为了以后穷，而是为了以后。我们需要学会存钱，为了未来。

任何事情，学会第一步是最容易的，第二步是最难的，第三才是坚持。

那么，学会存钱后，到底该存多少钱呢？

如果你不会存钱，那么你以后再也不会存钱了。

比如，你月收入5000元，每个月存500元，一年就是6000元；
如果你月收入10000元，每个月存1000元，一年就是12000元；
如果你月收入30000元，每个月存3000元，一年就是36000元！

但是，这也不对，你够了？

如果你存得太少了，那生活太苦了；
如果你存得太多了，那生活太受罪了；

所以，存多少钱，取决于你的收入多少。

比如，你月收入5000元，每个月存1500元；
如果你月收入10000元，每个月存3000元；
如果你月收入30000元，每个月存9000元；
这样你存了收入的30%。

这样你既能享受生活，又能存下钱。
