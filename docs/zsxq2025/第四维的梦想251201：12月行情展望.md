


# 12月行情，不暴不推。逆向基金不自明，谨慎操作！

本的一些观点，最后过一遍，错者可能没机会了。

从大盘来看，12月将已经走完最后的行情，大盘或将在未来两个月内回踩并筑成阶段底部，预计跌至3000-3200点附近，这样筑底的概率是不小的。

在这些行情下，对于基金的投资者来说是充满了不确定性。投资者的情绪在12月前将以悲观为主，由于市场处于持续下跌，恐慌情绪将占据高位。但是当跌破3000点后，恐慌情绪将扭转，新的机会将开始出现。

对于此时的投资者来说，由于震荡与反弹的博弈，也是一个布局的好机会。

此时的投资者应该持有，不要在此时底部的割肉，因为在底部割肉是最愚蠢的。

但是，如果你没有持仓，那么在底部加仓是明智的，因为底部反弹是极佳的入场机会。

对于老资金来说，12月的震荡与反弹也是布局的好机会。

首先，白酒、芯片、医药、ETF，这些板块已经跌了很久，虽然跌了很久，但是已经跌到了底部。

其次是AI板块。虽然AI板块也有回调，但是由于AI板块的逻辑，AI板块的回调将是反弹的绝佳机会。

第三是新能源板块。虽然也跌得很快，但是反弹的机会也很大。

第四是消费板块。虽然也跌得很快，但是反弹的机会也很大。

最后是科技板块。虽然也跌得很快，但是反弹的机会也很大。

总之，12月行情将如何，我还是那句话，12月后会有大机会。

所以，对于没有持仓的，不需要加仓。对于已经持仓的，不需要操作。对于基金经理来说，12月是一个重要的月份。
