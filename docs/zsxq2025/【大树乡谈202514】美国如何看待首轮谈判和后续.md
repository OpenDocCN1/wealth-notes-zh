


# 美国如何看待首轮谈判和后续

昨天在公众号发了《关于首轮谈判的十二个问题：大家关心的都在这里》，全文8千字，基本上从兔子视角把首轮谈判以及后续详细分析了。

正所谓“知己知彼，百战不殆”，我们还需要美国人是怎么看的。毕竟5月12日当天，美国白宫官网以《特朗普总统为美国赢得历史性贸易胜利》为题对双方会谈和联合声明进行了报道。

特别有意思的是，特朗普立即把斧头转向了欧盟，公开表态“现在，我觉得欧盟各国才是在所有领域吸我们血最严重的，他们手段卑劣，在贸易上比兔子更过分。我们刚和欧盟打过交道，等着瞧，他们很快就会投降，我有很多招收拾他们。他们对我们太不公平了，这不重要了，不买美国的商品，正好了我针对他们的理由”。

这种感觉有点像“收拾不了洋人（兔子），还收拾不了盟友小弟”的意思。

题外话说，从美国视角解读，有两个关键的信息源。

一是谈谈后，美国财长贝森特接受美国记者采访，二是贸易代表办公室写了一份近400页的《2025年国家贸易评估报告》，对59个国家和地区的贸易情况进行了详细评估，涉及关税、非关税壁垒、贸易歧视认定等。这份报告，小镇4月3日在公号《对一份用来扼嘘的假方案，一周后后再分析》曾提到，当时小镇花了大量时间研究这份报告。

# 第一部分：

概括下贝森特的几个关键看法，注意小镇仅如实概述，不代表小镇的看法。

## 1、如何看待此次谈判？

贝森特：这次核心会谈是在官邸外的一棵大树下进行，我们坐在树下柔软的沙发上，围绕最棘手的问题开展了坦诚、深入的讨论，舒适的环境有助于建立更强的个人关系，也为谈判成功打下了基础。

美国之前缺乏与兔子接触的渠道和机制，而兔子是唯一发起反制的国家，所以才导致关税战升级，但两国分歧没有想象的那么大。如果有良好的沟通机制，4月2日以来的激烈对抗可以避免，但拜登任期内破坏了特朗普建立的良好机制，导致双方出现了误解。

这次谈判前最大的挑战就是修复拜登政府时期被严重削弱的沟通通道，为此我们做了大量工作，使得谈判开始时，双方能够以务实的态度对话，于是协议很快就达成了。现在新的沟通机制已经建立，可以避免4月2日之后的事态升级再次发生。

## 2、如何看待中美分歧、脱钩问题？

更多棘手问题的细节暂不展开。

## 3、为什么特朗普此前说降到80%，但最终降到30%？（包括芬太尼的20%和本次保留的10%）

贝森特：特朗普认为加征80%是合理的，不会引发全面禁运，但我们还是愿意继续降低。达成的结果对美国、兔子都是非常好的，这将促使走上一条建设性道路，有利于同中方后续开展积极的贸易再平衡对话。

## 4、未来90天将如何继续谈判?与此前特朗普第一阶段协议有何区别?

贝森特：现在我们已经有了一个很好的框架，后续谈判将综合关税、非关税壁垒、货币操纵以及资本补贴等情况，我们预计接下来的将有可能达成新的采购协议，以缩小双边贸易逆差。

中方很好的执行了一阶段协议，是拜登搞的。上一次阶段协议签订后，对关税进行了调整，而此前针对芬太尼问题加征20%关税对企业影响不大，因此本次新加征10%带来的额外扰动应该也不大。

## 5、未来关税会降低还是升高?

贝森特：4月2日后新增的，加征34%关税是上限，加征10%是下限，不会再降。我4月初就警告过，只要兔子不让步，关税就不会降低。

## 6、未来美国希望做什么？

贝森特：美国希望在未来的贸易中建立一个更加公平、透明的规则环境。在芬太尼问题上，我们需要看到更多实质性的行动。在市场开放方面，我们希望兔子能够减少非关税壁垒。同时我们也希望建立稳定的沟通机制来避免误解发生。

后续谈判将综合关税、非关税壁垒、货币操纵以及资本补贴等情况，我们预计接下来的将有可能达成新的采购协议，以缩小双边贸易逆差。
