


# 南院大王

2025-04-02 07:25

易经16豫卦下：怕高都是苦命

市场上有句话，叫做怕高都是苦命。

该卖的时候不卖，该拿的时候，却为一点点利润，放弃了大牛股，没有吃到升浪。

怎么回事呢？

九四：由豫，大有得；勿疑，朋尝。
象曰：由豫，大有得，志大行也。

由，是从，顺应的意思。

顺应机遇和周期，就会大有回报，不要怀怀，各种好事和朋友，都会像用发簪束头头发一样将来辅助。

中国的事情，都是天时利人和同频共振，各方面的因素齐聚了，时势就会起来，这个起来的力量和风口，超过你的想象。

这时候要有大心胆，敢于拿一下，不要盯着自己的一面三分地。

股市中，80%的时间在等待，20%的时间才会上涨，它体现在：

- 1. 内外部的环境都比较宽松，没有什么人玩猴子。
- 2. 大盘指数稳健，护盘力强大，资金面比较充足。
- 3. 主线板块大家热议，政策非常支持，隔三差五就有好消息。
- 4. 核心公司和龙头企业的业绩，市场，有明确的兑现和订单，预期星辰大海。
- 5. 带头的风向跟进连板，封涨，忍度非常坚决。

政策，资金，盘面，k线都同步共振，好消息一个接一个，这个时候不要怕高，敢于拿一下，主升浪中50%乃至一倍以上都是基本操作，

然后打完，你就可以走了。

不光是大A，我们现实中也是一样，

当一个东西的势头是涨的时候，全是好消息，坏消息都能解读为利好，各种因素推着他往上。

当一个东西势头要跌的时候，出来的全是坏消息，利好都能解释为利空，大家做乌鸦嘴罢了。

比如皮带哥，势头在的时候，造车，唱歌，都是多元化，一旦不再，歌舞团就要被深挖。

六五：贞疾，恒不死。
象曰：六五贞疾也，顽不死，中怀，未亡也。

很多人都把这解释为，虽然一直患疾病，但长久维持不会死去。

大王为什么要解读易经，市面上绝大多数要么弄神叨叨，封建迷信，要按照字面意思胡解一通，误人子弟。

易经是知行合一的智慧，没干过事，没体会周期，没领悟其精华。

疾，不是病，而是问题。贞，是正确的。

“贞”，就是正确的认识问题。

如果你正确的认知的了上述的问题和本质，你就死不了了，本金不会亏光。

“乘刚”。在易经中，是阴爻居阳之上，意思是不安全、协调的状态，也即“不确定性”。

如何应对不确定性？就是要“中未亡”，要居中。

你做好自己，因势利导，顺应周期，缘来则应，物去不留。

这世界哪里有永远的不确定，用自己的智慧和定力，去应对所有的不确定性。

上六：冥豫，成有渝，无咎。
象曰：冥豫在上，何可长也？

如果沉溺于快乐却执不悟，那就十分危险，这世界上哪里有永远持续的状态呢？要及时悟，改弦易易，这样就没有失误了。

“生于忧患，死于安乐”，是因为周期都有顶点，这世界的规律，是盛极必然，物极必反，盈亏同源。

就像我们多次讲过，一个股，短期到达高高的标志是什么？

- 1. 高位放巨量上涨，换手率极高，筹码派发给散户。
- 2. 各方面的政策和呼声普遍看好，几乎听不到杂音。
- 3. 未来的业绩算得出来，想象空间已不大。
- 4. 大盘开始缩量，他却坚挺至逆势，开始跌破5日平台，甚至涨不动了。

极周期来的前奏，口诀为：

应涨不涨为弱，应跌不跌为强。

豫卦是好卦，是享乐，是丰盛，但最后也告诉你，不要沉溺于任何“象”，而要保持内心的清净和头脑的清醒。

这和金刚经的“应无所有而生心”，有异曲同工之妙，大道的智慧，都是相通的。
