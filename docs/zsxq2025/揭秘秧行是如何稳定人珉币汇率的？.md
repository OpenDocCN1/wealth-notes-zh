


# 揭秘央行是如何稳定人民币汇率的

今年人民币为什么涨？是不是会一路涨到 7 以上？到底什么时候时候换汇比较划算？今天我们一次性把关乎人民币汇率的问题都讲清楚。咱们不会只会说人民币涨跌的表面逻辑，还会深度扒一扒，中国央行到底是怎么稳定人民币汇率的。

首先我们要了解一下，目前人民币汇率到底实行的是哪一种制度。按照中国央行的官方说法：

## 2005 年 7 月 21 日开始
央行进一步完善了人民币汇率的形成机制改革，开始实行市场供求为基础、参考一篮子货币进行调节、有管理的浮动汇率制度。

我给大家翻译一下啊，这段话是什么意思？就是说 2005 年 7 月 21 日开始，央行就对人民币汇率这个制度动了一个大手术。从那天起开始，人民币汇率正式受到三个因素的影响：

- 第一个因素：市场因素。比如出口企业把赚到的美元换成人民币，或者个人和银行买卖外汇，这些都会推动人民币的涨跌。
- 第二个因素：一篮子货币。人民币不是死死盯着美元，虽然主要还是跟美元走，但是现在央行也会参考欧元、日元等一篮子货币的波动决定汇率方向。
- 第三个因素：央行手动管理。央行每天都会设定一个中间范围浮动，并规定汇率只能在这个中间的上下多少范围内浮动。如果汇率出现极端情况，那么央行甚至还会使用逆周期因子来强干预汇率走势。

也就是说，人民币汇率既要市场因素的作用，又要受到央行的管控，目的是为了让人民币汇率尽量保持稳定。因为稳定是中国政府为人民币在国际上打造的市场。

那么为什么央行要让人民币保持稳定呢？其实最大的原因还是为了吸引外资来中国投资。央行是在告诉外资：你们放心来中国投资，人民币汇率很稳定，你们不要怕会有汇率风险。大家结合改革开放的背景，自然就能理解汇率稳定吸引外资有多重要了。哪怕是到了今天，大家看汇率的走势，仍然避免了大起大落，波动还算是比较小的。最近一年基本就在 7-7.3 之间波动，这背后自然就是央行操盘的功劳。

那么接下来我们就要说重点了，到底央行是如何调控人民币汇率的呢？刚才我们说了，人民币的市场是稳，可是市场天天在波动啊，美元的涨跌也会给人民币带来冲击，那央行要怎么维持人民币这个稳的设呢？答案就是央行手里有一套工具箱，有些工具是明面上的，比如第一个：人民币汇率的中间价。现行规定了当天市场价只能在中间的上下 2% 范围内波动。

那么这个中间价是怎么定出来的呢？很简单，每天早上外汇市场开盘前，做市商就是负责报汇率的那些大行，他们就会先看看：
1. 昨天收盘价是多少；
2. 一篮子货币里各种货币昨天和人民币的关系变化了多少。

他们把这这两个因素加在一起，算出今天人民币兑美元大概是什么价位中心，然后把自己的报价交给外汇交易中心。因为每家银行参考的权重比例不一样，有的更看重美元，有的更看重欧元、日元，所以大家的报价也会有点差别。外汇交易中心收到一堆报价后，再把最高的和最低的去掉，算出一个平均值。这个平均值就是当天人民币汇率的中间价，外汇交易中心会在每天的 9:15 对外公布。

咱们举个例子，假如昨天人民币兑美元的中间价是 7，收盘价是 6.995，假设一篮子货币的变化提示人民币应该升值 100 个基点，那天的中间价就是 6.995 减去 100 个基点等于 6.985，比昨天的中间价高了 15 个基点。其中 50 个基点是市场供求成的，100 个基点是一篮子货币带来的。

然而，我们会发现外汇交易中心给出来的中间价明显偏高或者偏低，这就说明央行背后用了另一个幕后工具，那就是逆周期因子。逆周期因子可以理解为：央行强行出一个他们想要的中间价，强行修正市场的走势。比如刚才的例子，按照央行的报价，今天的中间价应该是 6.985，比昨天高了 15 个基点，但央行引入逆周期因子以后，给出的中间价可能还是昨天的价格。这就说明央行觉得人民币汇率涨得太快了，进行了人为干预，同时央行会指挥国有银行去市场上卖美元避免人民币升值，把汇率从波动区间拉回去。

所以除了中间价和逆周期因子这两个调控工具以外，央行第三个大招那就是直接指挥国有银行去市场上买美元稳定人民币汇率，还可以用资本管制限制市场自由，但这个大招央行不容易用，因为会伤害人民币的国际信用。

现在我们了央行调控汇率的三个工具，就可以懂目前汇率到底是怎么回事了。首先来看看今年人民币对美元升值了多少：

| 货币 | 升值幅度 |
| :--- | :--- |
| 欧元 | 3.4% |
| 英镑 | 7.6% |
| 墨西哥比索 | 13.2% |
| 台币 | 9.1% |
| 日元 | 6.5% |
| 韩元 | 5.6% |
| 越南盾 | 5.4% |
| 印度卢比 | 6.4% |

大家发现，人民币除了美国以外的所有国家集体贬值，这就说明人民币只对美元升值。看到这个数据大家有没有感觉？那就是央行压制了人民币走强，事实如此。实际上从 2022 年 8 月开始，就一直启动逆周期因子调节，由于两年美元太强，人民币又走弱，所以央行必须控制人民币升值的速度。

那么具体应该把人民币控制在哪个汇率区间呢？到这里大家发现，央行为了打造人民币这个稳定的市场其实也付出了不少代价。比过去几年中国经济衰退、美元走强，人民币应该顺势贬值，但央行强行拉住了人民币不跌破 7.3，使得现在人民币汇率偏离程度超过了 2015 年。央行可是损失了一万亿美元的外汇储备才拉住人民币汇率。那时候央行的资本进出比较自由，现在央行肯定只能加强外汇管制，以牺牲人民币国际信用为代价强行拉住人民币。

现在等到美元终于走弱了，全球货币开始升值，但人民币又不敢升值过快了，因为还是要立住这个稳定的市场。再说升值太猛也会伤到中国的出口，更别现在中国还在美国打贸易战，出口压力已经很大了，急需从其他国家拓展销路。所以央行只能把人民币汇率控制在对美元升值但对其他所有货币贬值，把中国商品更多销美国以外的国家。

我们总结一下，人民币汇率最微妙的地方就是它既不是完全的市场货币，不是纯粹的固定汇率，基本就是央行通过精心布局让人民币汇率保持稳定，上下波动不要超过一个区间。
