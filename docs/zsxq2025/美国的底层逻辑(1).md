


# 美国的底层逻辑

## 前言

美国梦从来都没有变过，他就是狂热的清教主义思想。一边是孤立主义，另一一边是征服世界，两者其实都是美国梦，是美国梦的不同表现。也就是说，一个美国梦，两种方法各自表，简称“一梦各表”。

## 自从川普上台之后

川普的很多政策都到了媒体的广泛讨论和关注。和之前的民主党政府相比，整个现在共和党川普的政策，是180度大转向。之前是全球主义，而现在，是倾向于孤立主义，以美国为优先。

那最为重要的一点，就是他的很多外交政策，它不光是针对一些敌对国家，比如中国，更是针对过去的一些盟友，比如欧洲。美国跟欧洲的关系变得空前的紧张，这个在过去是很难想象的。

那么该如何理解这样的现象呢？一个最为浅薄的理解，就是把所有这些现象都归纳为川普的个人意志，那一种庸常的见解，或者错误的见解，基本上就是现在新闻媒体经常说的一些陈腔滥调。

那么实际上的问题绝不仅仅是这样简单。川普的任何一个行为，都不光是他个人意志的体现，更是体现了背后的一个国家的底层逻辑。川普或者是任何一个美国政客也，他其实都像一个提线木偶，背后真正操纵他的是整个国家的精神品质和国家的底层逻辑。

那美国的底层逻辑到底是什么？搞清楚美国的底层逻辑，就能搞清楚为什么美国的政策会发生如此大的转变。那要搞清楚这个底层逻辑，就必须从一个国家的历史还有文化入手，来谈论这个所谓的底层逻辑。

这个人物就是约翰·温斯罗普（John Winthrop）。他是什么人呢？他就是早期北美的一个殖民地——马萨诸塞公司的实际掌控者。我们从这个人物来说一说美国的底层逻辑。

温斯罗普是什么人呢？他一个生活在16~17世纪之间的英国贵族，同时他也是一个狂热的清教徒。由于他的个人不幸，当时的英国政府剥夺了他的公职。当时整个英国的政治环境，国王查理一世使用强硬的手段去镇压清教徒，英国乃至整个欧洲的宗教纷争持续不断。

在英国政府对于清教徒的镇压期间，他成为了公司的股东。这个公司就是当时的马萨诸塞公司。一开始这家公司的主营业务还在英格兰，但是温斯罗普慢慢看着英国的宗教环境越来越恶，清教徒的生存空间变得越来越小，因此他和同伴们就做了一个大胆的决定。

他们利用马萨诸塞公司的特许经营状况中的一些漏洞，向英国政府提出申请，把公司的业务迁移到远离英国的北美洲。这个提议最后还是得到了英国当局的批准。表面上看，只是一个非常简单的业务迁移；实际上背后代表以温斯罗普为首的英格兰教徒决心离开英国，和这个国家完全决裂，然后跑到遥远的北美大陆重新开始自己的生活。

在公司业务的迁移过程中，他也赋予了这次行动以神圣的宗教意义。他告诉自己的追随者说，他愿意卖掉英格兰的土地，在马萨诸塞湾建设一片教徒的土地。因此这一次的大迁徙就是清教徒受到神的感召，要完全抛弃那种邪恶的英国生活。

温斯罗普还引用了“山之城”的说法，认为清教徒在北美开辟的土地，“山之城”这个说法后来被广泛接受。美国的历代政客、学者经常引用“山之城”。

而在1630年代以后，就开始了一个重大的改革。就是温斯罗普把原来的公司改成了殖民地公司，它从一个单纯的商业机构变成了政治机构，而且带有非常明显的宗教色彩，也就是狂热的清教主义。

著名的保守主义学者埃利克·霍格（Eric Hogg）在《美国政治史》中这样评价温斯罗普这样的清教徒移民：他把这些人称为“革命分子”，认为移民不是为了美国的发展，而是为了永久地离开“山之城”。

这种以清教徒为主的殖民地模式，在温斯罗普之后就不断被复制。

## 这种模式的意义

简单来说，以上就是美国的精神起源。它带有强烈的清教主义，属于清教徒的政治；同时它带有非常强烈的分离主义色彩，坚决和整个旧世界决裂。这才是美国的底层逻辑，这在美国国家建立之前就已经根深蒂固了。

而美国历史教科书一般是以清教主义作为美国的根基。实际上，那些历代政客都不是底层逻辑，他们只是建立在这个底层逻辑之上的表现。

狂热的清教主义，这两个字贯穿了美国从开始到今天的历史。理解了这两个字，就能理解美国的大多数行为。从这个角度来看，今天的一些现象就会看出不同的意义。比如去年2月份，《外交政策》杂志发表了一篇文章，题目是《现在的欧洲成为了美国的敌人》，这篇文章谈到了之前美国副总统万斯在整个欧洲发表了对抗性演讲，认为美国的外交政策正在失去过去的宽容，甚至对于民主国家都会越来越不宽容。但实际上文章所谈的情况根本不值得大小怪，如果稍微对美国历史尤其是美国的起源有了了解，就会知道美国对于欧洲的敌意由来已久。我们可以说，如果对于欧洲没有敌意，那么美国这个国家就不会存在。美国这个国家之所以能够存在，历史上来看就是狂热清教徒移民的结果，也是对于欧洲敌意的后果。

现在美国的这种敌意恢复，正是应验了最初的说法。至于欧洲外的东亚地区，在北美清教徒的眼里，还有原始的非文明地区，他们都不屑看这些地方。其实这个才是美国外交底层的逻辑。

从源头来看，美国就是这样看世界的。当然你可以说经过很多人的繁衍，美国人的信仰和过去已经不同，可能现在很多美国人不是所谓的清教徒，甚至很多人已经没有宗教信仰。但是大家一定要记住，一个国家的精神，一个国家运作的底层逻辑始终具有延续性。美国那种清教徒的狂热以及他鄙旧世界，一直没有改变，这样的一个底层逻辑至今还蕴含于美国的政治和文化当中。

从这个角度来看，川普的很多政策他无非也是体现了这样逻辑。美国的底层逻辑这一部分内容通常是不会改变的，它是固定恒定的，但是它具有不同的表现形式。之前那清教徒式的分离主义、那种孤立主义是一种表现形式，但是还存在第二种表现形式。

两种表现形式的不同，就可以解释为什么美国的政策——第二表现形式就是一种所谓十字军一样的激情，要征服世界的激情。两种不同的表现形式形成了美国政策上的张力。我们来谈谈这个问题：美国的政治、经济、外交等政策方向，近年来逐渐从过去的全球主义、世界警察转变为孤立主义，还有本土价值的捍卫者。关于这种180度转变的讨论可以是铺天盖地，但其实它并不大惊小怪，因为这种转变它原本就蕴含于美国政治的德性当中。

一方面是源自清教徒的狂热宗教感情，这造成的孤立主义在美国的外交基本原则上也有所体现。在美国建国初期，新总统乔治·华盛顿在他1796年的《告别演说》中提到：“美国不要轻易信任任何外国势力，不要和任何外国势力结盟。”他的原话是这样说的：“一个民族应该经常警惕任何外国势力，这对于美国来说是最重要的原则。”

另一方面，这种狂热的清教主义激情，这种征服世界的渴望。早期的清教徒移民温斯罗普在《山之城》演说中最好的表述是：“他愿意卖掉英格兰的土地，在马萨诸塞湾建设一片教徒的土地。”这说明清教徒在北美开辟土地。

随着南北战争结束，工业资本占据了优势，美国开始工业化，并逐渐从一个孤立主义的国家，在政治上要与旧世界切割。

这种传统的思想在19世纪中叶以后发生了一些变化。南北战争之后，美国逐渐从一个孤立的国家变成了一个干预国际事务的国家。举例来说19世纪末的美西战争，美国获胜并直接干预了美洲事务；一战之后，美国在全球部署军事力量充当了所谓“世界警察”的角色。通过统计可以看到，1960年代以来，军事开支占GDP的比例从9%下降到4.5%，说明美国的十字军战士包含了政客、学者、商人、军人等等是一个庞大的复合体。

这一套体系在时间上更近，对于普通人来说更为熟悉，因此人们往往因为这一套体系而掩盖了忽略了过去清教主义的底层逻辑。这种狂热的十字军战士主要是通过三种方法来征服世界：

- **第一点**：建立了一套所谓的“大西洋革命”叙事，作为现代革命的起点。美国历代历史教材也采取了这种叙事，把独立战争作为现代革命的典范，尤其是针对那些非民主国家。这种叙事完全抛弃了以欧洲为中心的逻辑。
- **第二点**：在全球推广自由贸易的理念，并且很多学者发表文章说政府是市场的保护者，政治制度是自由经济的保障。如果人们想要富裕、自由，就必须采用美国这一套政治制度和经济规则。
- **第三点**：在大西洋革命叙事还有自由贸易体系的背后，支撑他们的是美国强大的军事实力。

这种狂热的十字军激情，很多人误以为美国精神或者说美国梦就是大家一起赚钱、一起消费、一起享受，把消费主义、享乐主义、自由民主理解为美国精神，这无疑是非常肤浅和错误的。

他就是狂热的清教主义思想，一边是孤立主义，另一边是征服世界，两者都是美国梦，是美国梦的不同表现。也就是说，一个美国梦，两种方法各自表，简称“一梦各表”。在这个与旧世界划界限的清教主义信条，以及征服世界的十字军激情之间，显然存在矛盾。本质上，美国的政治、经济、军事、外交等各种政策就是在这个天平的两极之间摇摆。所以我们会周期性的发现美国采取孤立主义，就是因为美国的底层逻辑有两种不同的表现形式。但什么时候要恪守清教徒孤立主义的信条，什么时候要拥抱十字军的激情，这是完全取决于美国的国家利益。说穿了，这一切还是以美国自己的利益作为优先。

文章写到这里，有人可能会问：美国人这样来回折腾，一会孤立主义，又是全球主义，这样来回搞他们自己不累吗？不烦吗？非常明确告诉你，他们不但不累，而且非常乐此不疲。为什么呢？本来就是一群狂人，一群狂热的清教徒，他们的精神是过于旺盛，这个特征很难被改变。

著名的通俗历史作者保罗·约翰·里德（Paul John Reid）在《美国人的历史》这本书中就写到了美国人的这种特征，他的原文是说：“他们当中是最优秀的人，也许也可以说是他们中最为极端的人，都是些自以为是的家伙，狂热、不妥协、傲慢、自负、精力充沛、百折不挠、英勇无畏。有时候是建设性的，偶尔也有巨大的创造力，但是时候却是社会和政府的危险所在。”

这段话是非常经典的。在我们之前的几十年，见证了清教徒带来的创造性和建设性，但是之后的几十年，很有大概率是要体会清教徒带来的破坏性和危险了。这就是美国的底层逻辑。
