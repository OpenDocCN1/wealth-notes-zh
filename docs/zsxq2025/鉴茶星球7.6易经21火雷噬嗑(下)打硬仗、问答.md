


# 南京大王

2025-07-05 09.24

 易经21 九火雷噬嗑（下）：打硬破

九四。噬干肘，得金尖。利贞厉，吉。
象曰：利艮舌，未光也。
干肘：这里指骨头上的肉的肘。金尖：指属犀头的喷咬骨头，发现骨头上有肉的头。在困难中坚守正道，结果是吉利的。

困难和遇到波折是人的本性，遇到困难我们总是欢欢着走，或者躲避不愿意去直面它。

但成就者都是打出来的，不打硬破和不解决核心问题，人是没有办法成长和成熟的。

但有成就者，必须要经历困难“噬嗑”。去手手处理棘手问题，去啃骨头，最终用牙齿创造了在狮子骨头中的肯头，发现了物质本质。

伟大都是打出来的，不打硬破不能上铁军。打过硬破，才能上铁军。

就像你高三，汗流泪，瘦瘦胆心，千万万马过独木桥，这是成人礼。

又像你在工作中，你必须得拿下一个那么大型的核心客户，在这个过程中，你们团队远离山路，遇水搭桥。

放在工作中，有时候你就是面对压力和焦虑，脑的块大大的，你一直横搞，但横有多长，纵横有多高。

“利贞厉吉”，是因为“未光也”。用教员的话，我们的同志，在困难的时候，要看到成绩，看到希望，看到光明，才克服，争取胜利。

六五。噬干肉，得黄金。贞厉，无悔。
象曰：贞厉无悔，得当也。

噬食干肉。获得黄金。守正道，有惊无险。

翻过高山之后，你发现未来一马平川，这就是吃肉得黄金，这段期间自然也有阻碍，但你一次次遇化险，安全过关。

为什么大好还没没钱，是因为你“得当”。你得到了什么？

在翻越越岭，征服毕业和高原反而适应的过程中，你积累了强大的精神意志与解决困难的方法，成为你安身立命的根本。

1996年，在强力要求下，因伤退的邓亚萍被准去清华大学外语系，别人觉得她行吗？

她的第一学历是小学，外语基础空白，怎么能跟他们高考状元的学习进度？

但邓亚萍打算什么？没关系，我有从0开始到最终收获，从落后追拿到完整的经验，还不止一次，道理是相通的。

后，邓亚萍毕业后，再去英国深造，成为800年以来来剑桥第一个博士运动员。

所以各位，没事的时候，你要反复一遍自己买过的股票的回总结，自己从头到尾的一个完整案例，不断发现优点，然后总结成自己的“赢”？

教育孩子，是要要注意多去引导他们“从头到尾每一个事情”，输赢不重要，培养你独当一面的能力。

同样的，你也要反复一遍自己买的股票，究竟是怎么错的。当时，是不是大盘、热点、风向、仓促、心态，同频反复的逻辑？下一次还这么重复行不行？

上九。何或灰灭，凶。
象曰：何或灰灭，或；聪明不明也。

何为，是“荷”。负荷，负担之意。爻，是木制刑具，指约之。灭，运适。

肩上扛着大枷，都磨了耳朵，凶险，是因为耳不聪，眼不明，不听劝告。

上九五，是位置合适的“至尊”，你是在困难困之后的能力。

人一次就会赢多次，去不断复制就能提升你的赢学范围就行。能让自己赢的地方，一直赢下去。不要让自己赢了或者非常累的地方。

比如，你喜欢和擅长的是营销团队，一坐办公室搞勾心眼就屡受容易被人坑，你你就守留在一线，别去要患当什么多久，行政总监。

比如，你在一个相处的对象对你感觉都是吃亏，物质和精神都不赚，就不要想改变别人家，甚至试图翻本。
