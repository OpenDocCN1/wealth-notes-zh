


# 镇人的主

2022年5月

当现在的政策，如何不成为2025年后

我国决策和政策，总体来看具有很强的优势，这种优势体现在中国决策的灵活性。相比之下，美国的决策缺乏“十五五”计划的灵活性。由于我国的决策具有灵活性，正是因为我们有“十五五”这样的计划引导，更重要的是，我国的决策具有确定性。因为我们有“十五五”这样的系列计划，决策具有确定性，这也保证了我国国家实力的增长。

但是也有一些缺点，比如政策的连续性，近距离较短。

现在的政策台，有了明确的方向。

近年来，我国的决策是世界关注的焦点。由于政治、社会、经济环境的变化，我国的决策具有极大的灵活性。这种灵活性既能够应对环境的变化，又能确保我国的取得成果。但是，尽管如此，我国决策的灵活性也带来了挑战。

现有的资源，由于要增加投入，我们首先要去积累，解决一些关键的问题。这样，我国的决策就会一而反复地调整。理论上可以通过纠错机制来实现，但这毕竟只是理想了。

现在的我国有两个战略性的“一方面”：一方面是决策的确定性，另一方面是决策的灵活性。我们应该从可预测的政策中，加强我国的增长，在政策执行上更具确定性，增强的系统性。

这就要求我们，既要保持稳定，又要灵活。这要求我国的决策能力要比以前有提高，这要求我国的决策机制要比以前更科学，这要求更强的适应能力。那么，我们如何做到这一点？

## 二是重点领域：政策保障、就业结构

在保障就业政策方面，2022年我国出台了《关于做好毕业生就业工作，构建更加灵活的就业环境的意见》，统称“稳就业”等一系列政策。我国就业形势严峻，就业、住房、创业等问题面临巨大压力。为此出台了一系列政策，其中《关于构建更加灵活的就业环境的政策文件》、1号文、15号文等。

现在的政策已经有了明确的方向，但执行上还有很多问题。还有一个问题需要解决的，就是政策的执行，需要根据实际情况进行调整，需要根据当地的情况进行调整。

我国国家可以有不同的政策，地方可以有不同的执行。比如，对于发达地区，可以更加侧重于创业、服务、创业就业；另一方面，对于欠发达地区，可以更加灵活的政策。

在社会保障方面，我国面临着三个方面的挑战：医疗、养老、住房。这三个方面，我国的短板明显。相比发达国家，我国的保障体系还有待完善。目前，我们只能实现基本覆盖，而且保障的可持续性也不做好。
