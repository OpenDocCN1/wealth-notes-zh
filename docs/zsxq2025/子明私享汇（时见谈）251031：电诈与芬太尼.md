


# 电击与芬太尼

发布时间: 2025年10月31日

今年中国演员王星经泰国被拐卖到缅北，引发了巨大的舆论浪潮，本质上是国家机器操控的，是有意的对泰国集团进行打压，因为泰国国内一部分反华利益集团结在缅缅泰边境地区，对中国进行网电击，中国想要消灭这一股黑产，防止资金流出，就需通过旅游风险和经济利益打疼泰国政府，追迫泰国政府肃清相关的反华利益集团，促使亲华的利益集团上台。。同样的，中国政府也以此理由牵制缅甸军政府，用中断援助和国际事务的要求让缅甸内部肃清反华利益集团。

# 美国高度重视芬太尼问题
来源：中国科学院科技战略咨询研究院2019年1月11日

2017年2月1日，中美经济与安全审查委员会发布《芬太尼：中国对美国的致命出口》报告，2018年11月26日，该委员会会再次发布报告《芬太尼来自中国》，继续指向美国国内非法芬太尼及类似物的最大来源。

美方报告认为，中国商人通过互联网掩盖真实身份，接触美国和世界各地的潜在客户；出口通过一系列手段规避监管，秘密毒品运往西半球，包括直接或通过墨西哥、加拿大接往美国。

中国持续加强双边合作，增加情报和信息共享，打击非法药物和化学品贩运。2018年12月1日，中美会晤后，中方决定对芬太尼物质进行管制列类，并启动有关法规的调整程序。

美国司法部和财政部已经对中国非法药物芬太尼采取司法行动。有分析指出，通过司法手段公开清理中国毒贩分子是美国对中国施压的一种手段，因中国为“不想被称为毒品国家”。
