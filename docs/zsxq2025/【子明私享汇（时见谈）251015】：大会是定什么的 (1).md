# 关于“几中全会”

来源：整理自中国新闻网、光明网 2017年10月

Q1：为何通常五年召开七次中央全会?

在共产党党章中找到依据：“党的中央委员会全体代表大会如提前或延期举行，它的任期可以相应地改变。“中央委员会全体会议由中央政治局召集，每年至少召开一次。中央政治局向中央委员会全体会议报告工作，接受监管。”改革开放以来，历届中共中央委员会五年召开七次全会已基本形成惯例，程序更加规范。

Q2：七次全会在什么时间召开?

综观近年来中共中央一至七次全会，一中全会通常在全国代表大会闭幕后随即召开；二中全会于当年春季全国两会前召开；三中全会于同年秋季召开；四至七次全会在随后每年秋季召开。

# Q3:每次全会承担的相对固定职责

| | 职责 | 核心词 |
|---|---|--|
| 一中全会 | 通常负责选举新届中央领导机构的重任 | 人事 |
| 二全会 | 通常为全国、国家政协和国家机构推荐领导人 | 人事 |
| 三全会 | 通常指导国家改革发展重大决策，如十八届六中全会提出全面深化改革方案 | 经济 |
| 四全会 | 通常提出改革发展重大部署，如十八届四中全会提出全面推进法治 | 重大决策部署 |
| 五全会 | 主要议题是“五五规划”，如十八届五中全会提出发展建议 | 国民经济规划 |
| 六全会 | 通常就党的建设重大部署，如十八届六中全会通过了《关于新形势下党内政治生活的若干准则》，并正式提出“以习近平思想为核心的党建设” | 意识形态、党的建设 |
| 七全会 | 承上启下，为下一次大会进行文件和程序的准备 | 承上启下 |
