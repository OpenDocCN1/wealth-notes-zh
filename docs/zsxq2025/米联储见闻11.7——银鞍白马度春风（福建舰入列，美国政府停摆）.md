


# 米联储闻251107——银鞍白马春风（福建舰列，美国政府停摆）

你好，我是米糕

中国第一艘电磁弹射型航空航母福建舰正式列授旗，一把手亲自登舰参加授旗仪式。在官方报道里，还有一句话：一把手亲自决定福建舰起飞，歼-35、歼-15T、空警-600等新型舰载机依次停停。领导还前往福建舰，登上塔台，了解飞行指挥和起降运行情况。并进入驾驶舱，察看舰载战斗，在航泊日志上签名，在弹射综合控制室，观摩工作流程，按下弹射按钮。

福建舰是中国第一艘电磁弹射型航空航母，也是中国第三艘航空航母，舷号为“18”，2022年6月底命名。福建舰由中国完全自主设计建造，其电磁弹射技术处于世界领先水平。中国由此进入三航母时代。

中国收获三航母的同时，美国收获一个万亿大富翁。就在纽约市选获一位主张富人征税的候选人担任市長两天后，特斯拉股东通过了一项可能让马斯克成为全球首万亿富翁的方案。特斯拉们基本信奉“赢家通吃”的资本主义模式，他们以压倒性票数达成一致：如果马斯克在未来十年内能带领公司实现疯狂的财务和运营目标，就给他价值近1万美元的股份。

在资本推马斯克的同时，纽约选出社会主义者的现实折射出美国人当下贫富差距巨大的现实。美国政府停摆37天，导致很多过去体面的公务员开始担忧。鼓励造富者是资本主义的传统，与特斯拉股东在2018年批准的那份薪酬方案类似，这项包含12阶段的计划让担任首席执行官的马斯克大幅提高了特斯拉的市值，从约1.4亿美元提高到850亿美元，同时完成其他一系列目标，包括出售100万台人形机器人，以及实现1000万自动驾驶软件的付费订阅。

特斯拉董事及部分投资者，包括监管佛罗里达州公共养老基金的董事会，称赞这项价值数百亿美元的薪酬方案，认为它将激励全球首创的马斯克打造自动驾驶汽车的未来产品。佛罗里达行政委员会在一份中其投票支持马斯克计划的证券备文件中指出：“那些高薪酬的人认为特斯拉的雄心巨大，而这种雄心直接定义了特斯拉的发展轨迹。一个在类似激励框架下从临破产发展到电动车和清洁能源领域全球领先的公司，完全有资格使用奖励级成果的激励模式。”马斯克的反对者，包括加州公共养老基金的管理官，强烈反对这项计划，称它会让过多的财富和公司权力集中在一个人手中。

纽约州审计长托马斯·迪尼波拉在最新一次记者和投资者的电话会议上表示：“这不是绩效薪酬，这是无约得到的报酬。”对此发表看，他在接受天主主教新闻网站 Crux 采访时表示，马斯克的薪酬方案折射出底层与豪门群体日益扩大的鸿沟。根据公司的一份证券报告文件，2024年特斯拉工人的薪酬中位数约为5.7万美元。马斯克回应了部分质疑，声称公司研发的人形机器人 Optimus 是消除贫困的唯一解决方案。目前机器人仍处于开发阶段。

“人们常说消除贫困，让所有人拥有优异医疗服务。但实际上只有一种方法能够做到，那就是 Optimus 机器人，”马斯克说。“这即将我们将进入设想的科学幻想。”代理机构乔森的数据，过去三年美国上市公司提交股东表决的类似高管股权激励方案约有六个（尽管规模较小），除一个外均通过。

富人富有已经成为美国社会不可逾越的阶层壁垒。特斯拉市值从1.4亿变成850亿，这是给特斯拉打打气，也不是完全为了马斯克的个人，只能说，马斯克的形象和个人号召已经是全球标杆。马斯克之所以押注未来，当然是希望在科技竞争中获取优势。

与其说是投资未来，不如当下续命。

## 美国政府停摆与局势

从最近地方选举来看，川普支持的候选人全部落败，说明美国政府长期坚持对执政党来说并非没有代价。随着时间推移，舆论的焦点从政策转向治理能力。航班延误、福利中断、民众抱怨不断，原本的政治算计转化为公众怒气。共和党内出现微弱动摇，部分温和派议员开始担心，这场政治可能最终演变为选举负资产。

这次地方选举中民主党大获胜利，尤其是纽约选出的市长曼达成为首位民主社会主义穆斯林和南亚市长。这个结果在社交媒体上被热烈庆贺，视为美国政治多元化的一次突破，甚至在全球范围内引起重视。从整体票率来看，民主党的温和派候选人在其他地区赢得更稳、更高。新泽西等地的重建派以明显优势超出预期胜利，这表明在当前的社会氛围下，选民倾向于支持治理能力的务实路径，而非理念先行的激进政策。

民主党此次大的根源，其实是对川普政府任期的普遍不满。许多原本支持共和党的拉丁选民，感受到移民政策变化——打击非移民带有偏向族的行为转向民主党阵营。反弹叠加经济与社会议题上的分裂效应，让民主党在城市地区重新聚聚了反对派联盟。
