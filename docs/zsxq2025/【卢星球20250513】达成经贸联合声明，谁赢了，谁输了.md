


# 中美达成贸易联合声明，谁赢了，谁输了？

文/卢克文工作室嘉宾 星海舰长

5月12日，兔子发布了《中美日内瓦京会谈联合声明》，至此，中美闹得沸沸扬扬的关税战，暂时一段落。

不得不说，这份联合声明签署得非常艺术，就像哈姆雷特一样，同人眼中有不同看法。

MAGA觉得美国赢了，美国人觉得中国赢了。

民主党觉得美国输了，美国人觉得中国输了。

那么，到底谁赢了？谁输了？

不同人对联合声明有不同解读的原因，还是因为声明有点晦涩难懂，如果不了解中美这次贸易战的交手情况，是完全看不明白中美之间谈妥了什么的。

为了便于大家理解，我们需要按照时间线梳理一下中美关税过程。

2025年2月1日，美国第14195号行政令，借口中国芬太尼出口，对中国商品加征10%关税。

3月3日，特朗普对14195号行政令进行了修改，把“加征10%关税”改成“加征20%”。

注意，以上这两次，中国采取的反制措施，都是敏感物资出口管制+不可靠实体清单+调查谷歌+部分产品（特别是农产品）10%~15%关税等，并没有对美国商品加全面的关税。双方真正你来我往的关税大战，其实是4月2日之后。

4月2日，美国第14257号行政令，宣布对所有国家设立10%的“最低基准关税”，对中国输美商品加征34%的“对等关税”。

![](img/de78c72f703d9adc2cb132404d62bae7_1_0.png)

4月4日，中国税委会2025年第4号公告宣布，对等对美国加34%关税。

4月8日，美国第14259号行政令，对中国加征50%关税（的就是84%）。

4月9日，中国税委会2025年第5号公告，宣布对等对美国加50%关税（也到了84%）。

同样是4月9日，美国第14266号行政令，对华关税加到了125%（增加了41%），中国继续发布6号公告，也加到了125%，并且表态，如果美国一意孤行，中国不予理会。然后美国也没有继续加码，因为实质上已经脱钩了，再加也没有意义了。

这个时候的态势，中国对美关税是125%，美国对华是145%(125%+20%)。

搞明白了这些，我们再去看联合声明，也就一目了然了。

先看宣言中美国要做的：

美国对华关税回滚到了4月2日的基准关税状态，在90天内，取消后第二次(14259号行政令)的50%关税和第三次的41%(第14266号行政令)，第一次(第14257号)的34%，也只保留了10%的基准关税（这个10%谈不下来，连英国都没有免除），其余的24%取消。

再看中国做的，也差不多，中国同样取消后第二次（5号公告）的50%关税和第三次（6号公告）的41%，把第一次（4号公告）的关税砍掉24%，只保留10%，期限90天。

看起来完全对等，中美都降了115%的关税，比较公平。

但事实上呢？还谈不上完全公平。

注意，特朗普上一任期对中国的关税还没取消，经过中美第一阶段贸易协议和拜登多次调整，加权关税差差不多在10%~25%。然后2、3月份的芬太尼关税，是20%，再加上这次保留的10%关税，美国对华关税仍然有40%~55%！

就算从这次特朗普上任起，美国对华关税仍然保持着30%，而中国对美关税呢?只有10%，看起来绝对是吃亏了。

而且，中国做的还有一条：采取必要措施，暂停或取消自2025年4月2日起针对美国的非关税反制措施。

这是啥意思呢?其实在4月2日之后，中国除了关税反制，还有一系列非关税的反制措施，比如中重稀土相关事项实施出口管制，比如将16家美国实体列入出口管制管控名单，比如暂停3家美国企业禽肉骨粉输华资质等等。

按照联合声明的精神，这些反制措施可能都要暂停和取消。这也是很多人破防的原因，辛辛苦苦和美国硬刚，结果美国人用30%换了中国的10%，而且中国还要额外取消非关税反制措施，这不是输了吗？

其实，不能这么算。

前两次20%的关税，美国没取消，但中国的反制措施没取消。比如美国两次关税，分别是10%和15%。同时，因为中国的反制措施比较具体，无法直接体现关税数字，所以看起来像是吃亏了。而美国媒体正是利用这一点，大肆渲染美国赢了。至于稀土问题，我们其实不必太担心。稀土的出口管制是针对美国么？实质上不是，但名义上是“履行国际义务”。既然不是针对美国，那这个禁令到底包在“2025年4月2日起针对美国的反制措施”里面？解释权在中国手里。最终，稀土出口令不是取消，要看美国表现。如果美国继续搅缠，还会进一步加强。大家可以看看措辞“取消或暂停”就明白了，中国其实留了后续筹码。所以判断谁赢谁输，不能单纯看数字，还要看双方得到了什么，失去了什么。美国想得到什么？在谈判中获得的实质性利益是对等基准关税，而美国却付出任何代价。比如美国对中国商品降到10%，这已经非常厉害了。

为了保证内容客观，我们看了中国发布的联合声明，5月12日凌晨，贝森特召开了记者会，其中有很多信息。贝森特传达的信息可以归纳如下：

- 关战打成这样，完全是因为中国反制了，美国原计划4月2日的34%是ceiling（天花板），10%是floor（地板）。
- 双方都不希望全面脱钩，美国只想在战略性领域继续采取脱钩措施（半导体、药品、钢铁）。
- 中国愿意解决美国芬太尼危机，也就是说美国20%关税可能会降。
- 美国的最终目标是实现贸易平衡：中国少卖给美国，多买美国货。
- 特朗普之所以让步这么大，是因为美国损失也不小。
- 未来90天，谈判集中在综合关税、非关税壁垒、货币操纵和劳工补贴等领域。

从贝森特的发言来看，虽然仍然充满了傲慢，但相比纳瓦那个疯子，已经务实了。这可能是特朗普选择贝森特作为中美代表的原因之一。说实话，这份协议对大多数人而言，都是远远超出预期的。我们可以回忆谈判之前，美国一再放风说找中国谈了，中国一再否认。就算双方确定要谈，但措辞非常谨慎，中国官方表述是副总理访问瑞士、法国，并参加了中法高级别对话。看到没？中国压根不是奔着贝森特去谈的，而是外出访问。在日内瓦会面的定义，中国用的都是“会谈”，而不是“谈判”，显然是不望达成什么协议。会谈期间，甚至还传出了中方代表摔门出的谣言，不过很快就被辟了，这也说明大家普遍认为谈崩的可能性大。

但没想到的是，这次谈竟然达成了共识，而且减关税的幅度竟然如此大，恐怕大部分人都想不到。伟人说过：“帝国主义者很傲慢，凡是不理的地方一定不理。要是讲一点理的话，那也是被逼不得了。”看看美国和英国、日本的谈判，美国都是强势地位，偏偏和中国达成了对等协议，只能说明一个问题：美国扛不住了。美国从中国进口的物资，其实是以小商品居多，大规模的零售巨头沃尔玛、家得宝、劳氏和塔特等公司集中下订单，小规模的是一些杂货店，以一个或者多个杂货柜的规模下单。因为中美道路遥远，所以美国的零售业普遍存在一个补货周期，一般是30-45天一次。

我们可以回忆，4月2日开始关税大战，为什么美国市场没有遭遇剧烈波动？因为美国市场上的商品有库存顶着，老百姓无法切身感受到关税战的痛苦。但是5月份，情况就完全不同了，过去洛杉矶每天20艘靠港的中国船只，现在一般也没有了。这意味着什么？意味着美国的零售业很快就会面临无商品卖的境地，物价会飞涨，CPI飙到天上去。这一点，从4月底沃尔玛通知中国供应商恢复发货就能看出，哪怕要交145%的关税，沃尔玛必须补货，否则真的无货可卖了。至于关税成本，转嫁给老百姓就得了。就连特朗普也承认，过去美国孩子能有30个，现在只能有2个，而且这2个孩子比过去要贵。
