


# 猫哥星球251209：政治局会议的解读

7号的政治局会议总体来说，是没有看到特别新的提法与表述的，这就意味着在未来一段时间，国家层面的宏观政策是不会有太大的动作。这里有几个原因：

首先重要的是，外部与老美关系在缓和，从特朗普1.0到拜登，老美与我们打仗了两轮总统期，实际上是没有占到什么便宜的。特朗普2.0上台之初试探性的摸了一下，结果还是搞不动。

搞不动的原因是我们还需要自身硬，也就是本次会议表述的，过去五硬实力与软实力明显提升，老美现在我们已经是代价大于成果，现在老美也有自身经济结构性问题需要解决（通胀以及特朗普支持率持续下降的问题），所以，未来一段时间或者说2026年，我们外部环境总体是缓和的，中美再次升级贸易概率不高。

其次，虽然现在房地产仍然没有稳健，经济总体还是处于低运行态势，但是房地产从高点已经超过一半，明年即便继续下行，对经济拖累已经很大，另外我国出口依然强劲，今年截止到11月，外贸顺差已经超过1万亿美元，全年顺差可能接近1.2万亿美元，这是人类历史上前所未有的高度。

全世界现在除了农产品与资源，能卖给我们的工业品越来越少了，中国产业升级已经呈现越来越强劲的趋势，这也是管理层在目前经济状态下保持战略定力的底气。

以上就是本次政治会议没有特别动作的逻辑，下面我们就来详细解读一下关键点及其细微的变化。

会议明确“继续实施更加积极的财政政策和适度宽松的货币政策”，强调发挥存量政策和增量政策集成效应，加大逆周期和跨周期调节力度”。

这里有两个点。

逆周期增加了一个跨周期，说明宏观政策的延续时间会很长，就是积极的财政政策和适度宽松的货币政策不会在经济下行的（逆周期）延续，而且即便经济恢复之后的“跨周期”也会继续延续。

为什么？

因为我国的趋势是老龄化与少子化，在这样的趋势下，利率整体是低位的，货币的整体宽松的，大佬集团说一句话就是鼓励消费与投资而不是储蓄。

## 为发挥存量政策和增量政策集成效应？

我的理解就是国家未来不太可能一下子出出一个很大的刺激政策，而是先先出一个政策试探市场反应，如果市场有正向反应，才有可能继续加码。

举个例子。

现在国家给新生儿每月补贴300元，很多人觉得不够，但是国家对这个补贴加码之前就是国家看到每个月补贴300元之后，对生育率有一个良好的带动，然后才有可能将补贴从300元基础上提高补贴标准。

这就是存量政策和增量政策集成效应。

增量政策不是一步到位，不是另辟径，而是与存量政策有协同以及集成效应。

会议提出“坚持以内需导，建设强大国内市场”，相比去年“全方位扩大内需求”的表述，更加突出内需在增长中的主导作用。会议要求“持续扩大内需、优化供给，做增量、盘活存量”，推动经济实现质的有效提升和量的合理增长。

所以，预计明年以旧换新补贴的财政支持规模将进一步提高，补贴范围从旧用消费拓展到更多一般消费和服务消费。大家家庭有大件消费的（如家电比装修比如汽车）如果不急需可以等等，明年之后后再购买就可以享受国补获得更大的优惠。

会议要求“有效防范重点领域风险，牢牢守住不发生系统性风险底线”，特别关注房地产、地方债务和金融市场的稳定。值得注意的是，本次会议未直接提及“稳住楼市股市”，而是将相关内容融入宏观和内需等表述中——就是“做增量、盘活存量”。

也就是说，虽然房地产还没有企稳，未来国家层面，根据“做优增量、盘活存量”目标可能会出现一些刺激政策，但是政策力度不可能很大。

所以，房地产还跌，房价还有下行空间，这与我前段时间预判基本一致。

需要特别注意的是，在表述八大任务中，风险被调到最后一位（去年是中间位置），说明虽然房地产还没有企稳，但是管理层已经认为房产风险不大——或者房地产出现断崖式下跌的可能性不大。

最后总结一下。

2026是十五五开局的一年，也大概是相对平静的一年，外部环境，中美关系缓和，各自解决自身结构性的问题——

美国是通胀，即便通胀指数降下来，但是物价是降不下来的，所以老美当务之急的就是发展经济，让老百姓收入提升才能应对高物价。

我们是通缩，是经济转型，也就是培育新动能替代老动能，是将新质生产力做大做强。

所以2026年中国宏观层面不会有太大的动作，但是科技创新发展新质生产力的步伐会加快——经济转型速度会加速。
