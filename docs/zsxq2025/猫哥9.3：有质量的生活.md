


# 健康的瘦

这篇文告诉我们每个人都要认真对待了。

第一个问题，你要学会瘦，我自然就会瘦下来。我尝试了各种学会瘦的方法，我好几年前就尝试过减肥，结果不仅没有瘦下来，反而更胖了。在最后几年，我终于瘦了，人的生活变得更有意义了。

因为有赘肉，常常走路觉得很累，偶尔活跃几下好了，好不容易了又反弹了。本质上是因为我的肠子不好，身体代谢功能差。上胖的人，往往肠胃功能差，瘦的人，肠胃功能好。

虽然现在是一个很痛苦，但是很多人在减肥。减肥的过程是很痛苦的，因为你要忍饿，或者你要坚持运动，或者是身体的代谢变了，减肥的感受就像生病一样痛苦。所以减肥真的太不容易了。

不是胖的人，其实还有很多人也想减肥。但是，比起减肥的痛苦，只要能坚持下去，每天运动三十分钟，身体就会变精神了。这种运动对生活的影响很大。

那么问题来了，到底我们身体瘦到什么样的才算瘦呢？

## 首先是肌肉

瘦的瘦，身体是健康的。有肌肉的瘦就不容易胖，有肌肉的瘦看起来更好。

我们大家要增加肌肉，肌肉是非常重要的。
第二个问题，我们要如何增加肌肉？

肌肉是一项训练，从你开始练就会长。在刚开始的时候不要放弃，只要坚持下去，肌肉就会长。肌肉越多，身体的代谢就越快，肌肉越多，消耗越多。只要你坚持，肌肉就会长，反之，肌肉就不会长。

举个例子。

肌肉是人体的核心。想要增加肌肉应该怎么做呢？

肌肉是力量的来源。想要增加肌肉需要长期保持高强度的生活习惯。
肌肉力量有两个作用，首先是增强力量，其次是提高代谢。肌肉力量还能帮助身体在长时间的消耗热量。

肌肉力量强大，对身体有很多好处。比如增强肌肉力量（增强身体的免疫系统），就不容易生病了。
