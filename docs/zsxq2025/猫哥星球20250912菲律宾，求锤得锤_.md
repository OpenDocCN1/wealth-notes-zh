


# 菲律宾，求锤得锤

嘉宾供稿

在9月4日的上期文章“9.3以后，我们将如何收拾菲律宾”中，提到接下来收拾菲宾的几种可能性，包括继续围困坐滩船、拆掉那艘破船或者启动经贸制裁。

现在看来，格局还不够高，用大话西游紫霞仙子的话就是“猜中了前头，可猜不着结局”。

这里再顺便提一下，上述文章在发布后2天，有星友留言反馈，菲律宾对坐滩船已经完成了补给和换人。这个消息我查了一下，确实看到了另一个大V在转。

但疑惑的是，到目前我们官媒体包括菲律宾官媒体都没有谈这件事，甚至连视频或照片都没有，按说以菲律宾的尿性，一定会把“赢学”用到极致。那就只剩2个可能：

- 第一种，发布消息的博主要就是吃了海外垃圾信息，没有过滤鉴别真伪就发了，甚至不排除别有用心。
- 第二种，菲律宾接受我们检查，我们根据前面的约定同意恢复复绿线，但这件事被双方冷处理处理下来。

至于真相到底是什么？个人认为第一种可能更高，就算是第二种，那也没啥，毕竟菲猴只要乖乖听话，我们还是可以喂香菇连命。只不过现在在讨论这个已经没有多大的意义了，因为我们放了一个大招出来，只是方向不在仁爱礁，而是黄岩岛。

9月10号，国院突然发布消息，同意自然资源部关于新建黄岩岛国家级自然保护区的批复。

具体情况如下：

黄岩岛，东长约15公里，南北宽约15公里，周长约55公里，大致呈等腰三角形，其总面积约150平方公里，包括礁盘和渚湖。

根据公布的自然保护区基本情况看，包括核心区12.4255平方里、实验区22.8112平方公里。两者约 34平方公里，合计占整个黄岩岛面积的23%。具体位置大致在三角形的底边。

这是什么概念？

你可以理解为，剩余面积扣除渚湖，再搞出几平方公里的空间出来，一点问题都没有，留下的想象空间太大了。

我们国内以前搞新新区开发，一个3平方公里规划，就可以把学校、医院、长途客运站、大型商业广场、10个住宅小区等全部装进进去。

所以，对于这个大动作，不仅我们的舆论，包括菲律宾、南海诸国甚至到老美那边的舆论也都炸锅了。

菲律宾国内已经从11号开始，爆发了大范围的抗议。不过没啥用，按习近平坚定微博的表述：“坚决捍卫主权和领土完整的另一重大举措”。

其实我相信，大家在兴泛之余，都有一种比较模糊的感觉，你能 get 到那个点，但好像里面又有点说不清楚、不明白的内容。

新建国家级自然保护区，那么下一步动作是什么呢？

是名义上打生态牌，实际上在黄岩岛吹沙填海，搞民转军那套吗？还是仅仅只是主张权力，限制开发，保护原生生态环境作为第一出发点？

其实看不明白就对了，之所以被拟形成“高招”、“妙棋”，本人打就是一个让人看不懂，大家一眼明白了，何谈高招妙棋呢？

不过这里，还是分享一些个人的观点。

先介绍一下背景：

我们在南海吹沙填海工程，其实从上世纪80年代就开始了，不过因为种种原因，包括装备问题，还处于蚂蚁窝挖家阶段，真正的强度是要是从2013年左右算起。包括扩建永兴岛、永署岛、美济岛等。

黄岩岛一直以来，除了一些设想规划外，并没有规模化系统的搞。当然并不是说我们不想或者做不到。

比如，黄岩岛的地形特征，出了这片区域，海底马上从100米下降到3000米，导致了我们要吹沙填海，只有2个选择，一个是渚湖里面吹沙，一个是靠外运。这就导致了前面破坏生态，后面成本高。

黄岩岛如果能吹沙填海，那在南海就会与永兴、诸碧岛形成区域大铁三角，正好和诸碧岛、永署岛和美济岛形成的小铁三角形形成呼吸。三角形大家都晓得，最稳的。

所以，不存在不想想这个说法，至于成本方面，那更不是个事儿，虽然会对决策有一点影响，但权重不高，我们历史上长城都修了，这就。

核心原因，除了确实涉及生态方面的考虑，还是就是小总统到临岸友好，毕竟黄岩岛离菲律宾直线距离大致220公里，距离马尼拉也就330公里左右，可以说如果通高铁，90分钟左右就到，更别提导弹了。

那，为什么现在要放这个大招出来呢？

核心原因大家都清楚，就是菲律宾在不停的作死，清单之前我们前面文章都拉了，这里重重点谈谈这招“妙”在哪里呢？谈3点：

- 第一，菲律宾在2016年炮制的南海仲裁案，其中有一个表面文章，就是指责我们南海的动作破坏珊瑚礁生态。虽然站不住，但要知道当年西方主流强调在国际舆论上还有点。
- 第二，菲律宾最近几年对黄岩岛挑衅，大多数都是打着捕鱼的旗号。一来条件好，黄岩岛有80平方里的潟湖，是天然渔场；二来大家都懂，现在不允许我们国家级自然保护区禁止捕捞；三来寻找另外地儿，直接抓人。你看我们这招是不是杀人诛心。
- 第三，就是涉及我们进一步主权的内容。早在1279年，也就是元朝时期，天文学家郭守京的观测点就在黄岩岛。1935年纳入中国版图，1947年正式命名。这是历史依据。2012年后，我们实控，发现从历史依据、到法理，我们做了，但很多人不清楚，这还不完美，差这一环。这一环就是行政管理，这也是公认的判定主权的重要依据。现在我们这招，就是补上这一环，完全实现证据链，而且还是打生态派，是人类命运共同体的注解。如果你按老美的剧本，未来很一段时间不会变。

至于大家最关心的问题，会不会吹沙填海，搞民转军那套呢？其实这个问题我觉得还不急。因为形势不同，我们现在的军事能力不是10年前了，现在处于高端装备阶段。再的说，现在几座岛加军事、海警力量，在南海已经到了产能过剩的临界点，连老母航队都要绕着走，再搞个堡垒出来，其实意义并不大。也就是说，南海的战略其实在悄悄变化，最近2-3年，听说以前那样大规模系统性搞挖沙了吗？没有吧。甚至越南都在琢磨搞我们睁一只眼睛闭一只眼睛似的，我们海空、导弹等新质装备吹沙岛已经不是优先级了。但是既然我们提到了“新建”，而不是其他措辞，个人认为钢水泥、人员是要进去的，保护生态总得有点配套设施吧，不然我们怎么搞长期科研，搞好巡巡逻吧。

至于什么时候？规模多大？涉及哪些项目？我觉得前期我们会克制一下，如果菲律宾认为是睦邻友好很有，那我们可以照顾下情绪。当然，如果继续挑衅没完没了，那就是我的地盘我主了。不要忘了，黄岩岛距离马尼拉就300公里，距离合陶准备启动的“前沿作战基地”也就400公里。你在那边加强海域感知，灾害应对，我们搞生态保护异曲同工。还记得永署吗？当年我们就是定期的海洋观测站。

当然，大家要清楚，中菲问题的本质还是中美博弈。就在我们批复新建黄岩岛国家级自然保护区的同时，中美罕见的同一天进行了防长对话和王毅与鲁滨奥的对话，南海问题在防长对抗中是有体现的。甚至我们的福建舰已经赴南海相关海域开展科研试验和训练任务。其中的道道不言喻，对菲律宾哪会用航母呢？之前在我们家办大事期间，菲律宾张胆接待台湾地区外事负责人林佳龙的访问，我们就说过了：

“菲律宾踏诸方红线的行为必将付出代价，由此产生的一切后果必须由菲方承担”

现在反制措施如期而至，菲律宾求锤。所以，我们不妨让粒子多飞一会儿，一口气把剧追完也少了点乐趣。现在着急的又不是我们，就让菲律宾寝食难安，习惯一段时间再再说。加微信：cuk255，进提升知识学习群，看更多优质资源。
