


# 镇长的话

有同事：我在一家公司工作，有同样的香港同事，和他也交流过，他打算以后“去大陆”不回台湾了。在我们退休之后，他打算怎么办法离开台湾呢？我现在的他是否还有打算回台湾

小明：

中国回大陆，一个“回国”梦五十年了。我们还会回大陆吗？

小明：今年我打算在香港退休了。有一个日子，我现在的这位香港同事问我，你打算回台湾吗？我说，不回台湾了，也不去了。他告诉我的一件事，是我1997年回台湾了，中国大陆还有人回台湾吗？现在台湾很大，很多很有力的人都去香港发展了。

我现在就是没打算回台湾了。结果他问我，回台湾有什么好处？我告诉，回台湾没大发展，我已经打算去香港的了。

回到台湾之后，我听到了很多消息。结果是，台湾已经很好了，我没有工作了，但是我有退休金了。小明今年打算在香港退休了，他问我，你打算回台湾吗？我说，不回了，我打算去香港。他问我，去香港了，以后还可以回台湾吗？

但我觉得香港比台湾好，我打算去香港的。不过，台湾的法律已经变了。

对于香港的这种情况，现在是2004年。

在台湾工作是不难的，但是回台湾很难，因为台湾的法律变了。

在香港，从1997年开始，到2004年，已经有大变化。但是香港的还是香港，台湾的已经不是台湾了。

在大陆，从2002年开始，也有很多人打算回大陆的了。

还有一些事情，在大陆的人开始考虑台湾这件事了。

以前有一天，我以为大家可以随时回去的。现在情况不同了，主要分为两个阶段：第一阶段以前，和第二阶段以后。

# 第一阶段：从1997年到2002年

从1997年到2002年，香港的人没有回大陆的。

# 第二阶段：从2002年到现在

从2002年开始，这一段时间里，很多人开始从香港回大陆了。但是这需要政策的配合，现在的政策也变方便了。

# 第三阶段：从未来

按照现在的趋势，未来以后大家可以自由回返了。这不需要政策的配合是理所当然的趋势了。

这以后从2025年开始，主要是为了解决现在2020年到2022年出现的问题。

对于回台湾的情况，已经有很多人打算回台湾了。

但是回台湾的人，已经没有那么多的了。

对于大陆的人，现在有很多人打算回大陆。

对于香港的人，现在有很多人打算回香港。

总的来说，现在的趋势就是大家可以自由回返。
