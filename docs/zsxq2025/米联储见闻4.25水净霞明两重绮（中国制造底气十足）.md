


# 米联储闻250425：净明两重戏（中国制造底气十足）

你好，我是米糯。

相比低调务实的耶伦，现美国财长贝森特在媒体上的曝光率要大得多，不跟马斯克互动，还经常在公开场合发表反击川的话，可见贝森特背后有自己的利益团体和指向。最近贝森特又跳出来为关税站台，说中国依赖出口的经济模式不可持续，不仅损害世界其他国家，更认为美国是在想帮中国经济转型。这离荒话说的，类似于我打你是为了帮你敲筋活血一样。贝森特之所以这么喊话，不仅是在于川的关税战，是因为现在美国国内自带了巨大的意见分歧和压力。昨天，华尔街日报社评委员会发布了一篇相当沉重的社评，认为美国已经输掉了这一轮与中国的博弈。

一直以来持右翼保守派立场的华尔街日报社评委员会，不仅在美国如今的共和与民主势力中拥有相当大的影响力，更被视为共和党以及白宫中成年人的声音。相比纽约时报对评论用文责自负的态度，华尔街日报的社评委员会一直坚持与舆论导向的功能。

这篇社评中的核心观点其实直白，认为特朗普政府4月初宣布对全球征对等关税，并对中国进行极限施压以来，白宫在过去的这20多天一直在不断做出调整：先是中国以外的其他国家给90天，然后是给苹果、英伟等大企业开门，再如准备大幅减轻对中国的关税。这无疑是在撤退，该报的社评认为，这是被金融市场的糟糕反应、物价上涨、人们对衰退的担忧，以及全世界其他地方的差评给出来的。这篇社评认为，中国对美国政府的强反击，说明中国已经看穿了白宫的虚张声势。而且中国从关税反击、管制出口到对美国产品和企业的限制，还有中国呼吁其他国家一同反制美国的话，都产生了效果。

一个残酷的事实是美国看起来赢得了这一轮，不过，华尔街日报社评中给白宫找了台阶，称白宫政策转向他们是因为撞了南墙后已经回头了，说明白宫听懂了。但这篇社评并没有让川总统听完，反而引发了川总的死忠。虽然有消息说，川正在考虑大幅削减对进口商品的关税，部分或削减一半，以缓解与中国的紧张关系。目前有两种方案：第一种对华征收的关税率可能下降至大约50%至65%；第二种方案则被称为分级方案，美方将进口中国的商品分为对美国国家安全不构成威胁和所谓对美国国家利益有战略意义的产品。对第一类商品征收35%的关税，对二类商品的关税率至少到100%。

白宫方面表示，这种变化不意味着对华关税问题的立场软化，华府不会单方面降低对中国的关税。而对于川总所说已经在在谈的消息，中方商务部的说法都是捕风捉影，不过中国的财长确实是在美国开会。如果是所有的接触，那就再明白不过了。财长贝伦就不是关税的直接官员，财长只是债务，川总的要求其实也是债务。先谈债务是解决根本利益问题，这个谈妥了，关税可不是具体执行了。现在的局面变成了美国虽然把枪指着大家的掏钱，但是中国只要不掏钱，大家都觉得枪是指着别人。

美国现在真的需要新鲜血肉续命了。国际评级标准普普报告，2025年第一季度的美国已有188公司申请破产，创自2010年第一季度金融危机以来最高记录；到2024年第一季度的139家大幅增加，也是自2010年第一季度的254家以来的最高数字。2010年是次贷危机爆发后，现在是新冠疫情结束后春天，这意味着新冠疫情是继续次贷危机对美国经济的微观意义的一次重创，而且可能还远于一次。因为次贷危机发生后有中国出口帮美国续命，但这些血包更多的流向了金融鳄子和巨头企业，对于实体中小企业的帮助有限。随着美联储继续暴力加息，借贷成本增加。
