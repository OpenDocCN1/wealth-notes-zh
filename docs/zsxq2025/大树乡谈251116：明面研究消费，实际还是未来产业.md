


# 行业主题

研究行业，实则是为了2025年0116

12号宣布了两个政策，先后为了进一步提升行业复苏热度。首先是1月17日的政策继续支持行业发展，宏观环境更加积极，这份文件提振了市场对中国的信心。

首发在1月17日的政策又包含了对25个领域的具体支持，显示了国家对优质制造业的重视。其他政策也释放了信号，比如鼓励创新、明确加强政策支持，并要求相关部门的责任，这是明确转型的积极信号。

“创业更具信心了”，这些政策也释放了信号，市场已经好转了，技术也有了，资金也回来了，未来也有了。因为有了政策，未来，国家也在探索新的蓝图。

但中下游和科技领域或将迎来新春天。虽然面临挑战，但机遇正在出现。随着一系列创新政策的发布，行业将迎来新的机遇。这个政策达成了预期，行业技术的突破将使得产品更具竞争力，市场基础得到持续回升，最终实现行业反转。新能源、汽车行业将爆发。

业内22日部门发布了《意见》将制造业向高端升级，满足高质量的需求，以及2023年年初发布的《关于促进服务业升级发展实施意见》：

从《实施意见》的政策来看服务业行业，首先需要扩大消费市场规模，其次要培育新的消费需求，另一方面还需要培育新的消费产品。根据文件所要求的，将包括智能、健康、养老、文娱，“服务业很有未来”。

从这个政策来看，行业依然是一个具有韧性的行业，结构整体积极，但重要因素的发展还有很大的空间。

最需要的是，就是政策的落地执行。

在行业持续向好的背景下，随着政策发布、新技术突破行业将迎来爆发，2025年下半年有望迎来行业反转，市场需求将得到有效释放。同时，汽车、新能源、健康医疗等产业链将迎来大反转。

两个月，就要关注即将召开的工作会议，会议的工作重点将会安排，也将涉及如何引导行业发展，政策文件将进一步落地。

虽然现在还有质疑，但随着政策发布，市场对信心的修复得到了。比之前的《意见》出台，市场只看到了两个利好，这对于行业的发展非常有帮助。

目前还没有具体的政策，但我们需要看到部门的具体措施。

在文件中提到的到的“扩大内循环”属于国家内部需要，首先要挖掘需求，比如科技、品牌、新产品要发现新需，促进消费升级，以及主导消费的规模扩大，这也是很有机会。

这还需要关注如何落实，落实后才能看到更多变化。首先要扩大供给，这比扩大需求更重要，未来还有待挖掘。
