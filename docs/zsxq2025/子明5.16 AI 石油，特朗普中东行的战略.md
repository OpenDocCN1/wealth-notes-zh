


# 石油AI，特朗中东行的战略

发布时间：2025年5月16日

上一次美国国务卿兼任国安顾问，是尼克松时代，在跟中国实现了历史性大和的同时，跟中东达成的世纪大交易，建立了统治世界半个世纪的石油美元体系。

这一次美国国务卿兼任国安顾问，是特朗普时代，在跟中国开启了90天谈判的同时，又跟中东达成了一系列破纪录的大交易，这一次，要建立统治下半个世纪的石油AI体系。

外交与安全权力的集中，必然会推动政策落地效率的提升，本轮中美、美沙的超市场预期的谈判，都是特朗普2.0团队高效的体现。

这次特朗普访问中东，可不是卖货那么简单，他是在为全球经济发动更换引擎打前站，也是为了他更换美利坚堡垒做准备，此次的身后，站着的是美国的AI巨头们。

上一次尼克松基辛格建立的石油美元系统，为美国缔造了强大的美元霸权，但也缔造了以基辛格为代表的Deepstate。

这次特朗普要建立的石油AI体系，为的是美国建立强大的AI霸权，同样，也会缔造以Pay为代表的新Deepstate。

美国现阶段，跟几十前的某大国非常相似，产业资本通过资助政治力量向金融资本宣告，试图把半个世纪以前的那个老妇人推翻，来建立一个符合他们经济利益的上层建筑。

那么，产业集团自然要对老妇人的两大经济根基动大手术。

一个重塑沙特（中东、俄罗斯、伊朗、中美）为代表的石油美元金融体系（资金流），一个是重塑中国（日韩台、东南亚、南亚、墨西哥）为代表的制造业美元贸易体系（物流）。

资金流和物流是特朗普必须要同时解决的问题，那么，随着中东行，他的资金工作大幅推进后，接下来的，更多的压力，将会集中限制在谈判的中国。

新世代的小萨勒曼可以抛弃石油美元转抱石油AI，只要将卖石油的美元，建设AI产业链和买入展望基金，就可以获得美国的安全保护和经济利益输送。但是想要中国抛弃制造业美元，转制制造业AI，难度和问题可是一般的大和多。
