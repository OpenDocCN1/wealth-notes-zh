


# 分享我的饮食和习惯

作者：U青 2025年05月26日 16:59

收藏 1

很多人说我经常和你一样，你每天都吃什么？你的状态是怎么样的？你身体好吗？

由于他人的建议，我开始记录自己的饮食习惯，并打算分享给大家。

## 一、 饮食

我开始用“健康饮食”来让我从身体上重新活跃起来，也比我原本想的减肥效果比以前多了。

事实上，我发现自己的体重比以前减轻了很多，状态也变好了。

现在，我发现自己瘦了很多，皮肤也变紧了，个人也更有精神了，长期来看会带来很多好处的吧。

我在晚餐时，多吃蔬菜，少肉类、主食、水果。

早餐要注意，盐、油、糖、蔬菜的含量有多高呢？

我尽量控制糖的摄入，主要是减少甜点和零食。

我每天保证足够的蛋白质摄入，保证充足充足。

我每天吃大量的蔬菜和水果，保证身体摄入足够的维生素和矿物质和纤维。

如果你中午吃不饱，晚上可以少吃，或者吃一个水果。

如果你晚餐吃得太晚，第二天早上就会饿，甚至不想吃早餐。

我晚餐吃得比较简单，比如就是沙拉、牛奶，或者一碗热汤。

我晚餐尽量吃得清淡一点的，这样可以减轻肠胃的负担。

我尽量在睡前三小时吃完，这样就不会影响睡眠。

我发现我坚持了这些习惯，对身体是有好处的吧？

我每天坚持喝一杯温水，这样可以保持肠胃健康。

## 二、 运动习惯

我每天早上起床后运动（时间：06:00-08:00），

运动前我会做拉伸，防止“肌肉受伤”的发生，

我平时工作坐的时间比较长，利用碎片时间多站起来走动。

在工作期间，我会每隔一小时就活动一下（活动身体）。

周末我会去健身房，跑步或者游泳，增强肌肉力量。

我非常喜欢运动，因为运动能让我更有活力。

只要坚持下去，身体就会发生意想不到的改变。

希望我的分享对大家也有所帮助！
