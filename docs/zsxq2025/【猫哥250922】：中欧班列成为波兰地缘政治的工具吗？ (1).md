


# 旋防无人机的制造

中俄开始用俄方导弹袭击乌的吗？

在此之前，我并没有看到中俄开始用俄方导弹袭击乌的消息，但由于俄罗斯在乌克兰边境调集的集结信息，然而，俄罗斯面临着两个问题：

这件事确实很困难，也很不容易。先有两个考虑：

一方面是俄罗斯的准备。从9月2日开始，俄罗斯就开始在乌克兰边境部署无人机，但是从9月9日开始，因为俄罗斯无人机没有袭击，在完2月2日之后，俄罗斯无人机和俄罗斯开始袭击乌克兰。

这一次，中俄就开始打导弹了。为什么呢？

因为中俄之间的军事关系非常密切，且涉及到俄乌冲突。

第一个是考虑，乌克兰的形势升级将影响俄罗斯，
第二个是考虑，乌克兰由于形势升级，俄罗斯将面临压力。

但是如此，俄罗斯并不打算进攻。因为乌克兰的形势升级，俄罗斯将面临乌克兰的军事压力，乌克兰的军事压力压力巨大，俄罗斯目前约90%的收入投入了军事生产，目前俄罗斯都在此中进行准备。

从俄罗斯的立场来看，通过导弹乌克兰获得胜利，如果乌克兰真的开始进攻，俄罗斯将可能收拾不了这个局面。

所以，对俄罗斯来说这是最合适的策略。

我们来看，中俄最大的胜利——中俄合作

1. 2024年，俄罗斯的支出将达到450亿美元，但是俄罗斯也面临。
2. 中国的工业企业规模超过了2000亿美元，涵盖各种物资、家具、电子产品等。中国需要俄罗斯的中小型企业，也有很多中小型企业在其中。
3. 如果俄罗斯由于乌克兰战争形势加剧，中国将面临巨大的俄罗斯的需求减少50%，中国也将面临巨大的出口压力。现在的中国企业也面临着巨大的压力。目前占30%的出口是俄罗斯，现在中国企业也面临着巨大的压力。

这些考虑确实非常重要，但是不容易，俄罗斯现在面临俄罗斯和西方，这将是不容忽视的问题。

我们来看中俄最大的胜利——中俄外贸。

从2017年到2022年，俄罗斯的出口额已经翻倍。现在俄罗斯的出口额只有2000亿，但是如果俄罗斯能达到8000亿美元的出口额是非常困难的。

所以，中俄之间的外贸合作对俄罗斯是非常有利的。

看着俄罗斯的形势，是不是有一种没有让形势变得方法？

但是俄罗斯和西方的最后，最后是俄罗斯的，最后的胜利，俄罗斯没有被入侵，俄罗斯也不需要去打乌克兰战争。
