## 商业医疗VS重疾险
| | 百万医疗险 | 重疾险 |
| :--- | :--- | :--- |
| 赔付方式 | 比例报销补偿型 | 定额给付型 |
| 保障期限 | 一年或五年，要续保 | 长期或终身 |
| 缴费方式 | 自然费率，每年递增 | 均衡费率，每年相同 |
| 产品用途 | 医疗费用补充 | 医疗费用、生活开支收入损失、后续疗养 |
