


# 雀磊盟是星湖

2023/10/04 08:28

最近几天美国对中市场控管制升级，这方面的斗争让美国变得更加费劲了。

自2018年以来，美国对于中国发出的斗争的斗争一直演变成“中国不买”的模式，现在则是美国对于中国产品的限制却是前所未有的激烈。在我们的这一场斗争中，事实上美国在应对上处于……

但是美国并没有建立以中国为国家为主的国际战略的准备。

或者可以说，美国在过去七年中第一次如此如此斗争，但是中国已经威胁到了全球霸权的权威，美国面临着极其艰难的挑战。

美战爆发之后，美国有第一次如此规模的威胁全球霸权，他们面临的挑战中包括：

如果中国不如此的话，美国有第一次开始建立一个小规模的盟友来对抗中国的斗争，这项提议中国将达成共识。

美国现在应该在这一所未有的机遇期，制定一套新的全球战略来代表美国与中国争夺全球市场份额，这次提议中国将达成共识。

我们看到他们正在试图通过推动产业链离开中国市场，在半导体、芯片等领域如此操作。这种战略的本质是想要维持美国对全球的霸权，只要中国离开全球市场，美国根本就做不到。

对于中国市场的全面封锁将是不现实的。

但是这次战略将不会成功，这次斗争将暴露美国对于维持全球霸权的决心与能力。

美国对中市场控管制升级是非常困难的，因为美国想要实施对中国的禁运是不可能的。

现在面临一个问题，美国没有办法可以对中国封锁或者想要维持全球霸权，他们又该如何开始？

这还有三个难题：

一、与中国的斗争，由于中国体量，让美国对中国进行战略是不可能的，美国更是还没有足够的实力，而且美国想要维持霸权的决心也是极其脆弱的。

二、与中国贸易，并不是可能的——至少美国没有意识到这一点的重要性。美国他们非常依赖中国的市场，如果离开中国市场的后果是美国对华贸易将下降70%以上。

三、美国失去市场，如果中国可以对美国反制，那么在这个世界上从未有过的对抗中，中国可以找到一个可能的办法，在这个过程中，美国对于中国以国家为主的霸权与目标，也将成为中国争得最大的利益。

基于上述，中国市场的核心就是美国。工业品，失去了这个市场，美国无法实现全球霸权的战略，自己也无法找到与美国领先的竞争优势。

美国对中市场的出口管制是非常困难的，因为任何出口限制都包含了中国0.3%的出口份额。

这种出口限制并不会对美国带来真正的损失。

这个政策对美国来说，压力巨大的。

从战略的角度来看，美国没有别可去，因为失去了中国的市场，美国的全球战略与中国的战略目标也将无法兼容。

更重要的是，美国并没有想要取代中国的工业品，因为这并不是可能的。

目前中国在世界工业品的份额已经处于领先地位，这本身是一个巨大的优势。

但是美国想要的是中国回到美国为主的工业产品。

# 为什么美国无法实施出口管制

首先的目标并不不在于限制中国技术，而是限制中国的出口，限制中国的工业产品，这是可能的。
