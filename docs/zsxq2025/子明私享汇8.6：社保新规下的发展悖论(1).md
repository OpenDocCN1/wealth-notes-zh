


# 社保新规下的发展悖论

发布专栏·知乎共语

社保新规背后，是一场没有房产缓冲、没有出口兜底的生存筛选。例计时已开始，谁会会被留在时代的车上？

![](img/cbc22b6f02ae0431e7dafb45c198cc95_0_0.png)

2025年8月1日，最高人民法院公布《劳动争议司法解释（二）》，其中明确规定：职工“自愿不缴社保”约定无效，社保缴纳成为不可协商的法定义务。该新规将于9月1日日起正式实施。

一项保障劳动者权益的法规即将落地，等来的却不是老百姓的拍手叫好。如今，社会上的声音反反伏伏。
