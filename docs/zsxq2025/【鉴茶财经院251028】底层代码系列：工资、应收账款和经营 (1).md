


# 鉴茶财经底层代码系列：工资、应收账款和经营

个人是需要经营的，企业也需要经营。个人经营最头疼的问题是工资，企业经营最头疼的是应收账款。

应收账款是什么？大家立刻就能回答，就是客户欠自己的钱。这只是会计概念哦。卖东西收钱难道不是天经义吗？为什么欠着？

我们很多人会说这是行规，大家都这样，更多的人说，如果不给欠账，生意没法做。但是，你去买LV的包，去买车辆奔驰，为什么不能欠账呢？

应收账款，其实是竞争力不足的表现。（请读三遍）

你的产品或者服务，没有好到要客户必须给你钱。

我们的大部分的企业，是把应收账款作为一个促销手段用。

应收账款，本身就是折销售。6个月账期，就是打9折。5%的财务成本，5%的理财或经营收入。

应收账款，就是把客户的风险转嫁到自己身上。地产和4S店经营风险已经非常大，所以他们坚决不准跟他拖收账款。

这就是应收账款的本质。

而为什么要说到谈工资呢？你仔细细想，你的工资是否也是应收账款呢？一个月工资呢？

你的劳动，为何不能现钱现货，或者先款后货？是否某种意义上体现了自己竞争能力还不太到位呢？

你拿到的工资，是否其实上是9折呢？早年间，职业经理人圈里，要求一次性支付1年，乃至3年工资的也有哦，大王当年也是第一批的发明和实践者，亲测有效呢。

问题是，我们开这个口，握在哪里呢？是不是我们的努力方向向呢？

应收的碎片化存在，就导致了很难经营，大部分难以升，比如，一个月3万工资，年底的结余15万就不错了，因为存不住。

相反过来，上来要求9折，支付30万的全年薪，一下买一套小房子，每个月咬牙，不这么过去了吗？年底的结余，自然远大于20万了。

经营的底层逻辑，就是永远尽量把收益留给自己，把风险嫁给别人。穷人，是因为没本钱，而缺乏风险转嫁思维呢，还是因为缺乏风险转嫁思维，而没本钱呢？

思维训练结束。说策略吧。

企业的应收账款怎么搞？大王团队当年投过一个公司，做上市公司备份里的生意，订单额很大，他觉得这就是好生意了。

错了，在经营的角度，不是客户越大越好，大客户不一定是客户，疫情后谁能活多久准也不知道，现金流、支付条件好才是客户。

所以，企业尽量不要把应收作为促销手段，很多痛苦的生意其实不做也罢。大客户，小订单，多频次，高周转才是好生意。

最后，宁肯折扣也要争取先付款或短账期的条件，一来，客户的习惯就不会被你培养了吗？

老板和高管们得想想，你的经营风险，可以转嫁给谁呢？转嫁给银行，当然成本最低了！

那么对个人来说呢？大部分人存不下钱，不就是为了化整为零吗？不知道钱哪里跑去了。

经营个人财富，最重要化整为零。能不能一次性的3年工资，而购进资产呢？不能向公司借款或要求支付一个整年工资，付一个首付呢？

一下拿1年工资，是不是积小胜为大战呢？

很多公司都有基金和可借额，大胆借入，这和穷没关系啊。

如果公司要提拔两个后备人选，一个欠公司30万，一个不欠款，公司肯定提拔谁呢？

以此类推，把这个思维方法延伸出去，又是另一方天地啊。

## 评论：

三弃子：我现在设备有4条路：1.采购方现款，自然得利；2.采购方没办法现款，那就走银行贷款；3.没办法现款，同时非优质客户，就放给经销商现款；4.让厂家提高出厂价，回款后后再付款给厂家。

南院大王 回复三弃子：对：整个链条中肯定有信用。很好，但是没有钱的客户，那么可以做收账款的质押或者保理。一定要自己产品很强，必须现款，一定要绑住整个链条中有信用的客户，才有供应链金融的可能性。
