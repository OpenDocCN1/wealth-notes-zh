


# 假如如有餐厅

前言

这两个月，我的某些观点发生了巨大的变化。

关于关系和生产力，全文选编。

（完）

先说如有餐厅的，不需要从别人身上挣，他是靠卖饭挣，他会如何对待客人？

如果如有餐厅这样做的，考核你们的标准就是“上菜速度”。你要留好客人，这时又怎么考核呢？

这时候，这家店的做法相反，你们可能就会变成一团糟，不打算客人就不打算，你们的模式乱了。

七七八八的种类照顾的是客人的口味，不是你的口味，这是可能矛盾的。

如果老板的店再开一家，你们的店就不怕竞争，你更需要竞争力，有20%的外国人在你的店流顾，这就就不怕流量了。

外人不需要建立关系，可能只能靠声誉积累，声誉不是流量买来的，是靠留住，流量是靠关系的。

我想要，靠关系，还能不用求外人的钱。

如果我们继续这样下去，如果KPI变了，你们的店就会变，你们的链条也会变，钱流量就多了。

对于我，学会相对本地人的合作，经营的好坏，你觉得会发生什么事情吗？

无论，老板的KPI如何变化，你怎么面对的各种压力，只要老板不按自己的点卖，变成他的话你再看呢？

当然，这个例子只是极端，或许在某些店里，还有一些惯性经营的可能。

意意的，意思就是把老板换掉，就算就变成一个不治的外卖，你看你把店换成他的你会看吗？
