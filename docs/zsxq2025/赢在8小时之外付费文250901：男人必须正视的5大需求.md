


# 男人必须正视的大需求

原文：U 君 公众号：赢在8小时之外 25年9月11日

一些底层出身的孩子，小时候很多需求都没有被满足，长大之后，就会将自己的正常需求视为羞耻。

举个例子，“享受快乐”是所有人类、所有动物的底层需求，但是很多孩子的这个需求从小就被扼杀了。

结果就是，这个孩子长大之后也很难受到生为人的快乐，每当快乐降临时，他的潜意识里就会产生一股抗拒的能量。

因为从小到大穷鬼父母和穷老师给他的灌输的都是“挨苦补牢”“吃苦耐劳”“享乐可耻”的文化。

所以，即使自己有了钱了，可以享受生活了，他也很难获得真正的快乐。

不仅如此，由于从小到大自己的需求总是被拒绝，所以长大后也会把自己的正常感受视为羞耻。

羞耻感过重的人，就像蜗牛一样，总是背着一个重重的壳，随时把自己的头和整个身体全部缩进壳里。

可以说，在这种环境下成长起来的男人，需要重新把自己养一遍，正视自己的需求，这样才能享受丰富多彩的人生。

## 因为获得金钱、美色、快乐的过程，就是肆意满足自己需求、破除着耻心的过程。

如果你不能正视自己的需求、不能破除着耻心，那么人世间所有美好的人事物都与你无缘。

今天我就跟大家说说男人必须正视的 5 种需求（有很多是男女相通的）。

## 1. 远离弱智的需求

我为什么要离开农村，离开老家那个小县城？

原因很简单，因为那里的人不守规矩，而且智商太低。

无论是亲戚、相亲、县城里的陌生人，智商都比较低，很多事情都无法跟他们交流。

我并不是说自己智商有多高，而是他们的平均智商低于人类平均值。

假设人类平均智商是100，清华北大大学生智商是 160，我的智商是 120，小地方人的平均智商只有 60，一点都不夸张。

他们把所有的聪明才智都用到人情世故和拉关系上面了，关于科学、人生、赚钱、快乐这些大命题，他们基本都处于空白状态。

我在那种“场”里生活，无异于跟动物生活在一起，能量场会受到极大的抑制，所以我必须毅然决然离开他们，去平均智商更高的大城市生活。

因为我怕自己也变成他们一样的蠢货。

最后，我再跟大家说个扎心的话题：所有的都集中在了北上广的主城域。

那些天天吹牛的新一线城市、省会城市，人才密度非常低，真正有本事的人肯定会去一线城市。

无论你是演员、画家、网红、设计师、建筑师、程序员、考古学家、历史学家……只要你想要接触比较高的圈层，你必须去一线城市。

因为二线城市（包括一线城市）的人才含量、学术氛围、搞钱氛围，与一线城市存在天壤之别。

二线城市人口的平均智商是 100，一线城市人口的平均智商是 130，一点都不夸张。

所以，如果你常感觉周围的人都很蠢，那你该换个城市生活了。

如果你身处北上广深，仍然有这种感觉，你就该去发达国家生活了。

发达国家的国民，对于科技、人文、快乐、幸福的理解，比发展中国家高 1-2 个档位。

顺便说一下，我之所以把所有的免费群都退了（包含戚群和老同学群），就是因为免费群里聚集的都是弱智。

听他们的发言，我的脑子会被污染，影响我挣钱、影响我获得幸福感。

## 2. 生理需求

男人“那方面”的需求如果没有得到很好的满意，那么他的雄性能量根本无法被激发出来。

不信你去观察，无论是企业家、科学家、运动员、演员、画家、网红......甚至是佛学家（比如老板），大佬集团只要他在某个领域有所有建树，那么他在“那方面”一定是多姿多彩的。

要么多个美女环，要么是频繁离婚、结婚（4个老婆是标配）。

连伟大的 XXX（我不敢说他的名字），本身也有 4个以上老婆，几乎是一路换人。

由于从小到大自己的需求总是被拒绝，所以长大后也会把自己的正常感受视为羞耻。羞耻感过重的人，就像蜗牛一样，总是背着一个重重的壳，随时把自己的头和整个身体全部缩进壳里。

如果你不能正视自己的需求、不能破除着耻心，那么人世间所有美好的人事物都与你无缘。

那些“好男人”形象，基本都是在被这种文化把需求视为羞耻的。

大佬集团只要他在某个领域有所有建树，炫耀越多，他们的事业做得越大。

所以，男性要正视自己的需求，千万不要被这种耻文化阉割。

## 3. 炫耀的需求

炫耀是人类与生来的天性，尤其是男性。就连雄性动物也懂得炫耀的重要性。如果一个人没有东西可以炫耀，或者不敢炫耀，那么他的生命能量处于抑制状态。

世界上成就最大、境界最高的人，很多都是开着豪车的，住的都是豪宅的。

所谓“炫耀文化”，开的豪车，住的都是豪宅。一方面是因为他们炫耀，另一方面是因为他们也要跟别人攀比。

大家可以观察，真正的大佬聊天、采访时，一定会炫耀自己的事业和成就。

如果你没有东西可以炫耀，或者不敢炫耀，那么他的生命能量处于抑制状态。

如果你想做自媒体，至少得有一些炫耀的资本，有一些让别人仰视的东西。哪怕你去过瑞士、西藏旅游，这也算是炫耀的资本，99%的人都做不到。什么时候我们需要低调？那是对于身边的人，这时候如果高调，可能会倒霉。

## 4. 被认可的需求

人都有被信任、被接纳、被认可的需求。尤其是男人，如果你想要成功，那么必须有人认可你，这样你的能量才会饱满。

这个认可的人，可以是父母、孩子、老婆，也可以是同事、同学，甚至是陌生的网友。人为什么会抑郁？跟他有多少钱关系不大，关键是否缺少别人的认可和共鸣？

举个例子，我虽然没有什么成就，但我每天会在公众平台上写文章，然后评论区、知识星球、VIP群里都有认可我、感谢我。这时候，我获得的成就感和满足感是非常动心的，这些美好的感受比豪车、豪宅、美女、美食要爽多了。

所以，如果你总是有孤独、压抑的感觉，你就要多去做那些能被别人认可、被别人感恩的事情。

## 5. 被崇拜的需求

这一条，跟面前的“炫耀需求”和“被认可的需求”有一些交集，但是又有很多不一样的地方。大家知道为什么男性比女性更热衷于追逐权力吗？无论是商界的领导还是政界的领导，男性比例远远远于女性。原因就是：男性被崇拜的需求更加强烈，男人需要有人追随自己。

举个现实的例子，不论是学术带头人还是项目带头人，下面都有一些经验不如自己、成就不如自己、非常崇拜自己的人。很多男人在这种被崇拜的氛围中，更容易取得突破性的成就。

在感情维度也是如此，不论你的条件如何，都应该找一个崇拜自己的女人，这样的话你们的感情才会长久。这个崇拜的点，可以是事业有成，也可以是口才，也可以是多才艺……总之，你必须得有一个让女人崇拜的点。如果你们在各个维度都是彼此平视，甚至你还不如，那么她很有可能去外面找一个让她崇拜的男人。

举个例子，我比较擅长写作，有的女人听了之后，觉得这无非是在网上搞钱的一种手段，跟丝缕钱、坐办公室赚钱没有本质区别。但是，有的女人听了之后，觉得我非常不起，认为“写作”专跟绘画、作曲、唱歌一样，是少数人才才拥有的天赋。如果两个女人条件差不多，我肯定会选择后者，因为她对我有崇拜，她能理解我的天赋和赛道。而前者看时，没有任何附加的滤镜和光环。
