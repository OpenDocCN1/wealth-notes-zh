


# 珍大户的经济圈 250912：政策解读十要素市场化改革上

昨晚上的新政，国务院关于全国分地区要素市场配置综合改革试点方案的批复，经济体制改革中国政府网。

可以确定这个就是2022年全国统一要素市场的延续。22年当时出了个建设全国统一要素市场的顶层设计意见，当时圈子里写了解读文章，因为内容特别长，还分成了上下两篇。

现在三年过去了，出台的这个是试点实施方案了。在具体分析之前，我想到了两个细节。

一个是，从顶层设计到试点开始，中间隔了三年，确实也能看出最近几年里各种棘手的事情应该很多。

第二是，这批试点的十个城市群，你会发现传统一线城市京沪深，缺了谁？北京加了通州，反正也算北京了；广东直接上了九市，不仅包括广州、深圳，还有珠海、佛山、江门、肇州、东、中山中山全家老小一起上了。上海呢？上海没有，但是环上海大都市圈了，包括江苏南重点城市（紧紧贴着上海的北边），浙杭南闽（紧紧贴着上海的南边），以及合肥都市圈。

最后就是福建三市，郑州，湖南三市，重庆和成都。上海为何没有？

如果再去重读我22年读的下篇，就会感觉好像都联系上了。当时F先生找了个老城区里的棚户区中，棚子搭建的一家杂烩馆，我们专门去吃火杂烩（超级好吃，真香）去的时候，我就趁机走了棚户区。

22年疫情的时候，广州+上海都是管控失败的地方，都出现了闯关卡、冲防疫人员的事情。广州出现的地方就是城中村棚户区这种地方。我这一回瞅，觉得确实缺少隔离条件。你不能说人家就不管管、不想被管，而是难以以居家隔离的条件。在城中村和棚户居住的人，他们的日常吃饭、重心，都严重依赖外面的社区生态才能存活。但是居家，是影响生存的问题。所以没办法强人。

所以广州这座城市后续的发展重点，应该是继续拓展基建、加深城市化，让更多虽然肉身在城市，却享受不到城市基础设施。相反，上海在疫情中出现的，各种男女老少都被封在小区里，也要每天下楼抽烟遛狗聚聊天，不是隔离不了了，而是就是你不听的。这是能力问题和态度问题的差异。

这次的试点，把上海大都市群都纳入试点了，对上海绝对不是一个好信号。我们继续分析，这次要素市场化的城市试点，想要做的是什么？

本质上，是要打破价格失调问题。在经济学里，价格是一切的调节因素。比如同样是买苹果，张三卖的苹果10块，李四卖的苹果3块，那就应该李四的供不应求，张三的卖出去才？而在现实生活中，价格信号在很多城市中间是失调的。

对比人才来说，去哪个城市工作？大城市，居大不易，工资根本不抗花，但大把的人往里挤。其他城市哪怕想花同样的工资，都很难把人挖过去。

所以人才图什么呢？人才会觉得，大城市机会更多，大城市上限更高，但这些因素很难量化，整体还是比较的考量。总之，导致价格信号失调了，市场化调节的手段失效了。

对企业也是，一线大城市已经很挤了，工资费、地租费、交通挤，各种成本都居高不下，连商务请的价格都要比其他城市更高。但企业为什么不外流呢？企业可能会觉得，产业链在当地，各种信息交流都要靠当地，况且出了一线城市招聘人才都不方便。大佬集团一样的结果，价格信号失调了，市场化调节的手段失效了。

对城市房价、土地价格也一样。一线的地五万块拍，小地方五千卖不掉。要素市场化，逻辑就是经济学里的边际效用递减。人才、土地、科技、劳动力、专业、产业配套，各种东西都是“要素”。要素投入进去，就应该产出，而产出是遵循边际递减规律的。

比去年去年50万人才到上海，但因上海人才过剩的利，所以这些新增人才，对社会产出的增量就比较小。没准到的GDP增量只有500亿。边际效用递减的利。如果这50万人才不去上海，上海GDP减少了500亿。但分散到其他10个地方，每个地方5万人才，其他每个城市因为这5万人才，都增加100亿GDP，那么对国家的总量就增大了。

企业也一样。科技也一样。配套也一样。产业链也一样。在过度拥挤的地方，不稀缺，就会边际效用递减。与其说是全国统一要素市场，不如说，这叫——官方下场挖角。

以10年的时间长度来说，人们很容易忘记很多事情，也很容易以为一些事情就是永恒。我记得那时候，八十年代末，九十年代初，世上没有“北上深”，只有“京津沪”传说，老一代人的印象里京津沪应该是比深圳多。但如今时代，“北上深”才是了。所以不要把现在当永恒，时代一直在变化。

具体看每个城市具体的不同点：

- **北京**：重点在引入国际人才，结算方便。
- **天津**：重点在建立金融中心。
- **上海**：重点在建立金融中心，但由于之前疫情期间被封在小区里，是能力问题和态度问题的差异。这次试点把上海大都市群都纳入试点了，对上海绝对不是一个好信号。
- **深圳、广州、广东**：都无法成为金融中心。
- **福建、郑州、湖南、重庆、成都**：
- **成都**：步子很少，很保守。仅有的额外探索是“建设用地”的审批放宽，并且还在谨慎地限制建设用地复垦为耕地。闲置土地腾退方式比较少。
- **重庆**：胆子大。有很多农村土地，目前是把眼光放在农村土地上，设立交易所，让落户农民卖出住宅使用权。这些措施实施后，重庆的土地供应会加大，资源便宜，短期内都不用考虑房价上涨，打的主意还是低价吸引更多人和企业落户吧。重庆胆子大还在于自己城市内部继续小型区做试点的尝试，位于万达开发区、川渝西部地区，要建设规划储蓄管理机制。
- **长沙、湘州、湘潭**：比上次胆子更大。可以在不改变工业用途的前提下，鼓励存工业用地采取增加建筑密度、建设多层厂房、减少绿地布置等措施开展用地空间，允许批准有条件地分割转让——意思就是设计的容积率红线都可以突破，企业嫌地贵的话，可以多盖几层。这是借着政策试点，使劲办法搞活。还支持跨省和跨市飞地经济合作——给你一块地算广州的飞地，企业搬来还算你是广州企业，只要肉身在长沙就行。可以说，整个试点方案就是官方鼓励挖墙脚，看谁家有本事挖得到的。同时也跟重庆一样，有农村土地的主意。
- **环上海城市群**：苏南在探索卖地用地入股，模糊土地出让时的功能。
- **宁波、温州**：探索卖地时不看价格，而是看贡献程度。
- **合肥**：脚踏实地，敢于苦苦干制造业，这些年越级超车了。
