# 钱是最容易省的，你还是确定的吗

这里分享一个观点：如果你实在没有钱了，人真的容易变吗？还是钱容易上岸？

很多人会选择逃避的，除非你压力实在太大了。
因为是你，你对一个环境的压力程度，决定了你有多强大。
你觉得一个人可以生活在大城市里，每个人都在城市里，如果你是没有底子的人，你就不敢离开城市，并且你觉得不工作离开城市，你就赚不到钱。

但是我发现，其实是钱决定了你。
我观察过存钱的人，很多人其实是不赚钱的。

我以前在工作后才发现，原来是这样。
我父母，他们工作，不工作就没领工资，他们觉得除了工作没有其他的赚钱方法了。

所以现在必须要意识到，钱决定了你。
你现在的环境，其实是钱决定的，而不是你决定的环境。
人比钱重要吗？

每个人都有钱，每个人都是赚钱的。如果你是打工人，你老了的老了就没钱了。
我很信的，如果你没钱，你就不敢结婚，你要求别人结婚。
你没钱，你敢结婚吗？

所以现在决定了，你还是确定的钱吗？

我听说的（我朋友说的）他当时很有钱，后来就变穷了（因为他投资失败了）。

我认识一个老同事，他以前很有钱，但他后来已经变得很穷了，
最后他是因为没钱去世的。

我发现他，有钱的时候，他足够的钱，他就要承受巨大的压力，因为他的性格很固执。

我有朋友，我问他，为什么你以前看起来那么开心？
他说是因为以前没钱，所以不需要买东西了；因为现在有钱了，所以想买东西了，压力就变大了。

他说，我有钱了，就不开心了。

我问他，你30岁的时候有多少钱？
他说我30岁的时候，我赚的大概就是三万多，我存款的只有三万多，也不非三千万。

我攒够钱了，就可以坐飞机去旅游了，攒够钱了，就可以坐打车了，不用挤地铁了，钱的压力就变小了。

如果你是不怕钱，那么对钱就不太压力了。
你现在的应该是和钱来对比，而不是用钱来对比。
比如我，和钱对比，是显然不同的；其实是，我和钱对比，如果你害怕穷，你害怕穷，你就会害怕钱。
所以我们一定要看到搞钱的方法，才能不怕钱。

但是我发现，其实钱决定了你的心情。
如果你没钱，你的心情就会很差。

我身边有两个朋友，一个很有钱，一个没钱。
那个很有钱的，他看起来很开心，另一个没钱的，看起来很忧愁。
我发现，其实钱决定了人的心态，和你和钱对比，和你和钱决定了你的心态，和你和钱决定了你的心态，钱决定了你的心态。

我那个很有钱的看起来很快乐，另一个没钱的看起来很忧愁。
我问他，有金钱可以得到快乐吗？
