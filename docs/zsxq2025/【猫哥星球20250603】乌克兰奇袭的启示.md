这个实践就是新冠疫情。

新冠疫情为了管控疫情我们是怎么做的？

- 病毒溯源，可以精确描绘出一个病毒携带者24小时行动轨迹；
- 时空伴侣，可以精确锁定可能与病毒携带者有时空交集的人群；
- 封控、网格化管理，供应链有效组织等等。

最后的大杀器是健康码对人群的分类管理。

说实话，不是因为病毒种类原因，国家放宽了对入境人员的管控（从7+14放宽到4+3），2022年根本就不可能出现后期疫情失控的状态。

我们这套模式对无色无味看不摸不着通过空气传播的病毒都能管住，更何况是一群渗透来的间谍大活人！

假如我们围攻台湾，国内只要以战时状态为名，实施类似“健康码”的管理模式，所有渗透的间谍马上就是裸奔！

冷知识，在疫情期间健康码管理下最大的收获就是抓到大批潜逃多年的案犯。

好吧，我们再降低难度，不拿出健康码这个大杀器——毕竟健康码管理模式对普通民众生活多少造成了一定的不便，我们搞内紧外松，把社区网格化、病毒（间谍）溯源、时空伴侣这一一套拿出来，境外间谍渗透进来破坏坏也难以登天。

乌克兰能对俄罗斯发动攻击还有一个物资基础，包括无人机零件运输与组装，炸药的运输。这一一套复制兔子简直困难万难，我们的边界管理是全世界最严的，已经很多多年没有发生过大宗毒品运输到内地的案例，这一套边界管控模式通过疫情得到极大的强化，比如西南边境，现在建立了铁丝网加无人巡查。
