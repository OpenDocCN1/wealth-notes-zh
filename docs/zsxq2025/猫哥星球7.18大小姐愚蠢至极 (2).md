


# 宗大小姐愚蠢至极

## 猫哥原文

最近看宗家产争夺案，越来越感觉宗大小姐愚蠢至极。

为什么？谈一谈我的看法。

达到一定数量级的财富是要与势力相匹配的，所谓的有钱有势这个词不是随便组合的。达到一定数量级的财富如果没有背景与势力护符——老祖宗是这样描述这种情况的——犹如小儿抱着千金过闹市，其潜在的风险不言而喻。

不讲古代比比皆皆的案例，讲一个我身边的案例。

我有一个朋友十年前摘到一个钨矿，当时钨矿石不值钱。所以这个矿大多数时候都是亏本，我这个朋友为了这个矿前后也投入了大几千万。

2020年时来运运，因为新能源汽车爆发，锂石价格暴涨，然后这个锂矿一下子价值就高达几十亿。我这个朋友没设过硬背景，加上拿矿与运营也有缺陷，然后被被人盯上。

过程就不说了，说结果。

涉黑，9年。

宗大小姐继承父亲的财富其实是有缺陷的，还是重大缺陷。

现在根据各方面爆料，宗老爷子在经营某哈哈的时候，其实是用自己完全控制的掏空了某哈哈，截止到2023年宏胜吃掉了某哈哈98%的利润。

如此如果属真，宗大小姐继承的财富涉嫌国资产流失，有关方面真要追究，宗家关联的人都要吃了兜走。

# 但是官方为什么没有较真追究呢?

两个原因。

其1，宗老爷子民间口碑很好，老老爷去世杭州有上千人自发来吊哀，更为重要的是，老老爷人设立得好——爱国企业家、生活简单、对员工厚道等等一直得得很稳。

其2，当时政治氛围对宗家很有利，前几年坊对民营经济一直有各种利空的声音，所谓的民营经济退出论引起市场很大反响，为了平息市场对上述负面信息的影响，国家层面花了很大力，两个不动反复强调了很多次。

所以，在这样的政治氛围下，如果官方较真对宗家进行查处，一定会引发论场轩然大波，毕竟老爷口碑好，社会同情心是占大家的，然后很可能被人扩散，动民营经济的集体信心。

所以，在老爷子去世后，官方给予待遇或是极尽哀荣，新华社、央视等媒体都第一时间发布公告，称其为“改革开放后民企业家代表的人物”，并强调其“艰苦朴素，实干报国”。

说白一点，官方对宗老老爷子极尽荣哀其实就像树一个典型，让外界看看国家表态的“两个不动摇”是说话算数的。

所以，现在我们可以得出一个结论，宗小姐继承的巨额财富依托的背景与势力是什么？

就是宗老爷子的人设与光辉形象。只要这些人设立得，只要这个光辉形象不倒，即便宗小姐做过一点，官方层面也要给几分面子，也会包容的。

比较典型的例子就是，宗小姐继位之后，又是大刀斧对员工动手，又要进一步将某哈哈有价值的资产转移到宏宏，当时员工持股与宗小姐产生严重的矛盾与冲突，宗小姐持股与员工持股差异不多，关键还要看地方国委的意见。

但是地方国委迟没有表态，估计也觉得宗小姐做得有点过，后来转折点是宗小姐一气之下公开辞职，事情闹大了，有关方面还是看在老老爷子的面上，捏着鼻子支持宗小姐，让她获全胜。

但是意气风发的宗大小姐根本意识不到，自己父亲的人设才是自己最大的保护伞。最近爆出的私人子女境外财产夺案不仅成为舆论的热点，更为重要的是，这是将老老爷子一辈人摧毁得干干净净!

- 爱国企业家，向境外转移了高达18亿美元的资产。
- 辛苦博素，竟然还有一大堆私生子。
- 实干报国，用离公司控制的宏胜掏空了某哈哈的资产。

这些丑闻一桩桩暴露在公众面前，也许宗小姐觉得无所谓，但是却是在打谁的脸？大家对比一下老老爷子去世时传媒的报道与高度评价，这就是打官方的脸！另外，老老爷人气设垮了，民间口碑基本废了。

所以，这就是宗小姐为了的一点境外利益，亲手将自己最大的背景与保护伞拆得干干净净。

简直就是愚蠢至极！

现在宗小姐就是面临这样的局面，官方层面得罪完了，民间口碑也废掉了，未来但凡做点过头事，官方层面还会捏着鼻子支持她，还会包容她?

用脚趾头想想也不可能的！

以宗小姐好强任性的性格，未来会韬光晦不不做过头的事吗？

就从她不顾一切摧毁老爷人气设形象来看，这一一辈子顺风顺水惯了，本事不大，脾气不小。过去没经历什么挫折，未来有她栽跟头的时候。

兔子有句老话，德不配位必有灾殃！这句话未来大概率会在宗大小姐身上印证。
