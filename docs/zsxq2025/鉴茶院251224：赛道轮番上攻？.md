

# 重生之上海

震惊的陆天：今天你这么晚来，我已经在等你太久了。

终于见到你，太激动了。

震惊的陆天：你这么厉害，这金钱怎么给合适啊？

陆天内心有些紧张，现在的局势，希望你不要太麻烦。

陆天笑了：“陆天，你真是个无可救的傻瓜。”

陆天：“在上海这么大的地方，就为了这一个机会，你准备好了吗？”

陆天已经准备好了，但现在，是该给你的机会了。

陆天：“陆天，这可是我最后一个机会了。”

陆天：“陆天，我准备好了。”

陆天：“你可真麻烦，这还不行吗？”

陆天：“陆天，我真的行了。”

（此处省略大量重复的“陆天，我行了”及“陆天，我行了！”内容）
