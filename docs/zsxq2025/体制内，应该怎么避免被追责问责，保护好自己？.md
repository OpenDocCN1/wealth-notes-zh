


# 体制，应该怎么避免被追责问责，保护好自己？

原创:主任 公众号:人性的视远 25年8月8日

常言道，害人之心不可有，防人之心不可无，很多时候我们不要有机心，但现实却看着我们不得不留个心眼。当前追责力度严厉，被追责问责轻者受批批评，重者面临降级降职，甚至可能面临监狱之灾。

公职人员一旦被判刑处罚，基本会被“双开”；对于渴望工作稳定的公职人员而言，背锅意味着饭碗不保，甚至失去自由。

从自然灾害到各类突发，再到行政行为，均在问责范畴之内。甚至在某些地方，桌子上摆花、未接电话等小事，也可能招致问责处分。

基层工作直面群众与实际事务，问责更为严格。

有的领导安排的工作任务不合法合规，有时候领导的要求指示是让我们触红线、打擦边球、越界，明显违法。这里的是领导本身对法规政策了解得不深透，有的是领导为了急于出绩、要结果，想在政策上灵活流通或者打擦边球，当然可能是领导自己有私心，有把违规的事情给下级，让下级背锅。

## 精研业务，把本部门、本行业的法规政策吃透

在体制内，从2000年以后都成立了一个部门，叫法规处或者法制科，即便某些单位可能没有这个部门，但他往往的职责也会合并在其他的部门里面去。

我们现在行政部门所涉及管理的范围越来越大，我们有时候会翻到五年前、六年的文件还在执行，它也没有说什么时候除了这个文件，它也没有设有一个有效期，它一直都在执行的过程中，我们甚至很多人都忽略了这个文件却存在，但是它实际上发生了一些效力。一旦发生一些问题的时候，我们找的时候发现依据依然是那个时候，10年前、20年前、甚至30年前、40年前的法规和一些制度。

我们很多法规法条、办法、通知都可以作为相关的依据，作为我们行政的依据。大集团同样在出现问题的时候，也是对我们追责的要求和一些依据。我们大家都经历过巡视、巡查、督查，很多时候一些巡查的人员，巡查人员来了之后，他也会说你做这件事似乎没有依据，拿出你的依据来，为什么这么做？

你的业务要精通，首先你就是要清楚哪些事情我能办，哪些事情就不能办，原则在哪里？底线在哪里？领导让我，我背不背锅？其实有时候领导不懂业务和政策，他认为你办的事情完全是在政策范围内之内的事情，所以我们要对自己做的工作、业务政策要精通，分得清楚哪些是红线，哪些不是红线，哪些是模糊地带，哪些不是模糊地带，这些事情要先搞清楚。

如果你作为一个普通人员，领导比精通法规，你却太懂，故意让你这样做，口头告诉你去这么做，并没有给你书面授权，你又不知道这个事情不应该该这样做，或者说你不认为自己是违规的，你做了之后责任在谁？你是具体经人员，你负极大的责任，这个锅你就会背得莫名其妙。

同样的道理，如果你作为一个中层领导，或者是一个科长也好，一个处长也好，你自己对自己的部门的法规权限不清楚，那么下属告诉你这个事情，领导可以这么办，让你签字的时候，你是签还是不签？你签了，你就有相应的责任，这个锅实际上是你下属去背锅，他有意的好，他无意的好，你都要负相应的责任。

我们一定要把自己管理的那件事、那个业务，或者那几项业务的法规和业务一定要搞清楚、搞明白，即便我可以溜着做，我要知道我擦的是什么边，我是不是擦边，还是越险自己心里有数，才做到不轻易地背锅。

## 多请示、勤汇报

工作中可能有的事情，由于紧急、特殊情况，跳过一些流程，跳过一些东西。比方说很多项目都有什么，先批边建，边批后补，现在很少有人敢做。即便我为了什么加快发展，推动项目落地，什么都可以说，什么理由都很充分，但是按正确的流程去做，你要负责，该处分还要处分，该追责还要追责。

尤其是很多刚到单位的，怕向领导汇报，可是致命的。从某种程度讲，是在保护自己，因为有的事情不准，向领导请示后，你只需要执行，出了问题是领导顶着。要是不请示、自己拿主，万一出了问题，即使领导汇报了，也很难。一切清楚，不是你作主完成的。

## 比较大的事情不要独自承担

当某些事情已经出现了不好的结果，比较大的需要背锅，如果发生了大问题，每个人都分担，那么责任就小一些。如果能大家一起背，责任就小一些。背锅的往往都是公事，如果一旦发生了大问题，领导和单位就会毫不犹豫地把你推出去。

有些事情，尽量让领导和你一起背，甚至单位和你一起背，把它变成一个集体事项，或者说是一个连串事项。那么如果领导发现大问题，领导会帮你办法把事情解决掉，化大为小。

为了自保，凡是需要签字、向领导汇报的工作，都要留痕。以后工作上出现了什么问题，自己不容易甩锅，还能证明自己干了哪些工作，还可以应付一些检查，很好的保护自己。

一定要留痕。资料、数据、会议记录、事后总结、照片、录像，领导的签字等，都是必须有的。一旦后续工作中别人甩锅给你，和你纠缠不清。

这些 ，举个最简单单位公章的例子，我在办公室工作的时候有同事做得很好，时刻记住“见签字才盖章”。大集团从不省略流程，也不会听从领导口头指示。如果领导外出会议、电话授权，他标注领导同意的日期、具体时间，等领导回来后补上签字。看起来有点板不灵活，但是时间长了，大家知道他坚守原则，默默遵守，不会发生其他单位，因为盖章流程不严谨出现推扯皮的事。

最主要，他把这件事看得很透。并不是自己管着公章摆设，而是盖章的事由多种多样。常规性工作还好说可以灵活，人证明、同意报考证明、遴选考试等，如果没有领导亲笔签字，他送对方人情悄盖了章，到时出问题说是单位开假证明，全是他的责任。

## 不要轻信他人

一些人之所以背锅，就是警惕心不够强，容易被人忽悠，结果成了替罪羊。那些想把事情成又不想担人的，会反复在你耳边念念叨：“没事的，领导都交待了，以前我们都是这样办的，你放心好了。”

在此，在听到这些话时，最好保持清醒的脑袋，先别考虑是不是领导交待的，而是要琢磨这件事是否符合规定。

## 符合规定？能不能办法?

要是不符合规定的，那就得想办法。如果符合规定的，就要提高警惕。关于自己的签名和经手的事情，要留痕。凡是需要签字的东西，很多时候都要认真清楚，不是你范围内的事情，不要随便签字，哪怕是领导让你签字，很容易掉进“坑”里。

为了自保，平时多留痕。工作中的这类书面材料，包括领导批示、口头指示记录、电话记录等。很多时候，需要签字的，都要留痕。工作中的记录，要详细。要清楚：第一流程是谁？第二流程是谁？后面是谁？怎么回事？领导怎么说的？当时怎么办的？

## 办错了怎么办

领导说是按我说的办，重复一遍，把手机录下来。如果以后出现比较大的问题，是领导授权你去做的，领导要求你去做的，当然这个事不要容易用，但是我们要有一个提防的心，以备不时。

最后和大家来说，当一个事情真的出现问题需要追责的时候，我们要分析形势，我们要态度积极。很多时候，为了追责，就是为了表态，是为了满足上级领导的表态，或者对上级部门的一个表态。

就是需要有人背锅的时候，当你们发现这个背锅无法避免的时候，我们态度要好，如果铁证如山了，有时候可以认，确实有责任在里面，确实是我犯了错误，我有问题，我服从组织的处理，我承担我该负的责任，我逃不开的部分责任，其他的责任还是要往外推。有些不是你的事情，不是你自己定的，是有别人授权和你指挥你，你不能说这个事就是我自己定的，不该的事情打死也不能认。处理人的时候也要有技巧，他会一直诱导你，当然态度一定要好，但是不该认的打死不能放自己身上。不要英雄运气，你一旦承认，你就很难翻身。
