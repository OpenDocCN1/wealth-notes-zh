


# 中东局势地震
# 嘉宾：梦回安西

2025年5月12日，就在中美公布瑞士回合谈判成果，产生世界性地震的同时，中东也发生了一场区域性地震。当天，库尔德工人党举行大会后，宣布将自己解散，放弃武装斗争，转为和平斗争。

谋求独立建国的库尔德人，一直是土耳其的最大麻烦。

仅在土耳其国内，库尔德人就有接近2000万，邻近的叙利亚、伊朗和伊拉克还有一千多万，合计超过3000万，属于跨国家民族。

遇到土耳其政府围剿，库尔德人可以跑到周边国家，等风过了再回来。而周边国家出于恶心土耳其考量，通常会睁一只眼睛闭一只。

另一方面，库尔德人分布的区域，还是崇山峻岭，围剿成本极高。

两大因素，让库尔德人拥有天然的斗争条件，组成了一批武装斗争组织，其中规模最大、影响力最大的，便是库尔德工人党（简称：库工党），乃土耳其心腹大患。

库工党成立于1970年，一开始受到苏联的支持，意识形态上奉苏联为尊，冷战结束后，库工党转换立场，变成了民主邦联主义者，也就是西方那一套。

美欧觉得，有必要制衡土耳其（尽管同为北约盟，但西方从未真正信任过土耳其），便扶库工党。

明面上，美欧为了不破坏土耳其的盟友关系，不会公开支持库工党。但私底下，西方为库工党的活动提供便利，动摇库尔德地区的人权说法。

再人道主义援助的名义，向库工党提供资助。瑞典之类的北欧国家，更是公开支持库工党，谁都知道，瑞典这么做是美欧的意图。

正因西方支持，周边国家也想恶心土耳其，所以土耳其迟缓不能消灭库工党。

既然如此，库工党为何要宣布解散？

因为美国想从中撤退，特朗普上台后，不断缩减在叙利亚的驻军人数，从2000人减少到了不足900人，撤离的意思很明显了。

不仅叙利亚撤离，明年，美军还可能从伊拉克撤走大部分兵。

“俄乌战争”问题上，特朗普如果想推进，必须争取土耳其的支持，控制着黑海出入口的土耳其，对“俄乌战争”很有很大语权。

乌开战后的大部分谈判，都是土耳其主持的，其影响力可见一斑。而土耳其显然不会白帮忙，让美国停止对库工党和库尔德人的整体支持，是必然要求的。

特朗普的态度，是同意的。

比如，叙利亚库尔德人主导的武装力量——叙利亚民主军(SDF），在特朗普的压力下，名义上接受了朱拉尼的收编。

土耳其在朱拉尼政府中有很大影响力，又一向把SDF视为眼中钉，企图借着朱拉尼“整编国内军事力量”的由头，削弱SDF，对此心知肚明的SDF，原本不想去谈判。

是美国方面施压，出动直升机，硬拉他们去。

随着美国不断撤离，未来四年，美国对库工等库尔德人组织的支持，势必大打折扣。失去美国支持的库工党，将很难对土耳其政府军。

库工党知道，与其继续对抗，不如个个对待。所以，早在今年3月份，库工党就放风要解散。这次大会，正式确认解散属于更进一步。而库工党的解散，属于区域性政治地震，对中东局势的影响巨大。

首先，是埃尔尔多安的地位，可能大大稳固。

我们前段时间说过，埃尔尔多安这两年，因为国内通胀上升的缘故，统治遇到了大麻烦。2023年大选获胜，已经显得十分勉强。

2024年地方选举，落了个惨败。

到了2025年，干脆把反派的领袖、伊斯坦布尔市長伊玛姆奥杜洛，随便找个理由给抓了起来。此事迅速引爆矛盾，让反对派铁了心要推翻埃尔多安。

在持续不断的大规模游行下，埃尔尔多安风雨飘摇。

就算勉坚持完期，到2027年大选，埃尔尔多安的麻烦很大，因为根据宪法规定，他不能再连任了，考虑到已经修改过一次宪法，总不好再修改一次吧？

那样也太不要脸了，必须找接班人。然而，埃尔尔多安所在的“正义与发展党”内部，找不到合适的接班人。要是输掉2027，埃尔多安这些年的事，很可能面临一次大清算。

别的不说，光是腐败问题，就够他喝一壶的。

偏在这个节骨眼上，库工要解散，真是想睡觉，就有人逸枕头。搞定库工，无疑是埃尔多安的大绩，属于历史级别的。

这样一来，埃尔尔多安的地位就得到了稳固。就算反对派再怎么叫闹，也没有大碍了。地位稳固后，就有了足够的威望，指定接班人。

其次，是以色列，要有麻烦。

利用自身对朱拉尼的影响力，土耳其这几个月来，在不断向叙利亚渗透。

比如，朱拉尼政府内部，已经有国防部副部长、北方地区司令部司令等等一批职位，被交给了土耳其指定的人。又比如，土耳其驻军，正在不断南下。

原先，土军在叙利亚的地面活动范围，基本局限于北部，靠近边境地带。但近几个月来，土军已经进驻了中部，连大马士周围，了土军。

这一切，令以色列感到压力山大。以色列希望，支持叙利亚南部的德鲁兹人“自治”，以此构建一个缓冲区。但在土耳其的支持下，HTS南下，大举德鲁兹人区域。

目前，HTS在叙利亚取得明显进展，迫使当地的一批军阀投降，控制了半个叙利亚。下一步，不排除土军进入叙利亚南部。

以色列是绝不愿看到的。

叙利亚变天，本是以色列的天良机，能够毫无阻碍地扩张领土，但土耳其太快了。

现在，土耳其的心腹大患库工又要解散，土耳其麻烦大幅减少，能够腾出更多资源，对以色列。

以色列势必尽力办法，给土耳其找麻烦，比如，库工党虽然宣布解散，但还没解散，还需要一些时间。

如果在此期间，以色列能制造一些事情，让库工党和以色列互相猜忌，或者提供援助，让库工党足够的资源，库工党不排除暂缓之。

昔日，以色列最大的敌人是“抵抗之弧”，未来，很可能是土耳其。

双方在地地上，存在难以调和的结构性矛盾。
