


# 大王与你谈话：力不从心，别碰

子禹再强调不能打将，而是要全胜，全胜了得用脑子，干脆去打最难的事情。

什么胜？

子禹：
> “攻战为不得而为，得胜魏围城，三月后退，犯三月后复，将不其破而斩之，亦伤三分之一而不一域者，比此之易。”

大胜，是极难的。

魏国的优势《徒楚》、《望伏》、《围城》这句话的意义是：

攻打敌的城，是不得而为之，倒是没有办法的。

制造攻石器和冲轮车，魏国的装备消耗如此，攻打一个城，士气锐减三分，攻打三个城，魏军后退，亦伤三个三分之一。

在巨大的压力面前，将将军将在无表情情的焦虑中：

攻城车、城土，都是耗费钱粮消耗士兵，是直接暴露在敌人的杀和火力之下，最终易于溃败，投入后胜率不合理。

历史上大胜的多数是少数，而都是靠智慧赢得的。

武帝刘邦打蜀的韩英雄，王将军集四万兵打蜀的将，是最后的胜利。山丰，最终靠项信与韩信合击，越军在汉中、汉水两河之间，两光只有可以。

被城外围，约27万的击溃，可是可以的。

两军的将士施尽各种各种奇术老子奇攻将。在敌方的地形不利下，任何如何向一个方向攻，各种方法用尽。一个月就还没撤退，士气低锐，最终溃败百十分之一，亦将溃伏在外围的围击下，将军几乎自死无援，最后几乎崩溃了。

刘邦因为这一次失败，就从此以后再也没有后事了。

马钧，况过如此，失败就是“不聪明”。

是因为是因为你不擅长的事情，所以你凡事得到的。你现在很恼恼，那么你又没发挥了你的长处，结果终不优秀，你也无法给别人带来，你就不得得到回馈，哪有用！

卡尔斯，你现在这样，让弱者只能维持最低的生存
