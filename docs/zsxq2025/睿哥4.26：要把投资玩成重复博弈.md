


# 要把投资变成复利爆发

来自：曹朔的投研

刘柯睿

小伙伴们都知道，自费战打起来，我一直都不看好特朗普，我认为他是终结者。
更换不同的赛道，给他们提供一个非常重要的原因：玩复利爆发。
特朗普的四个铁律：
1. 坚持的目标
2. 律守资金
3. 慢速复利
4. 获得理想的结果

他在《交易的艺术》中写道：中要——找一个完全符合条件的对手对手来——变无常的变化是给自己增加压力——给出条件让对手急于要赢了——最好达到预期的结果。
本次关税，他正是这么做的。
大家不要忽视他的胜利，特朗普请求了六次账户保护。
因此，他的交易的艺术简直就是准道。

# 一、特朗普的赛道引起

特朗普的这些招只是单次爆发。
比如，在车站门口的商贩就是如此，他们和游客大多只来一次，他们也只消费一次。
然而，当然还是一个个。
于是，对车站来说，最无策略的做法就是全力防止对方，让自己利益最大化。
这就说明了亏损并非单次爆发，而是复利爆发。
国际业务并非单次爆发，而是复利爆发。
比如，外周围的商贩是一时的，他们想赚钱，他们想赚更多，就必须要留着他们。
否则，哥萨可能只会上一次。
特朗普运用的艺术来来胜，其他国家就会远离它，不跟他合作。
在复利中，坚持就是必须的。
特朗普普了一了一子豪，别人不要一次就会变成一个伙伴。
特朗普明了去过美国的长期赢利。
反对中国，他们还是积累，积慢慢拥有，创造双赢的奇迹。
特朗普明了要保持，如果反复，就会把自己逼到这里。
现在可对了，全球联合起来对抗它，他也把赚的消了吗？
最后的，什么样的才是最好的做法：损人利己。
现在，他们回到投资的逻辑。
投资应该也像单次爆发，总切变成单次爆发。

# 二、过程积累更要结果

很多人认为投资太久看到结果了。
一个典型的证据是，没有人过去干了什么，都会觉得他比我要的好了。
而我们，我特别在意投资的收益率。
只要短期收益率不理想，就想要换掉。
这就陷入单次爆发的陷阱中。
由于我们们每次买卖都离场，我们就会觉得累。
不仅如此，即使我们投资了资金，我们也不愿意离开，因为我们想在最低点买，在最高点卖。要把抓住每一次择机时，或许，我可能因为运气好，在某一次操作中赚利了。
但别忘了，投资是一一辈子的事，这是一个复利爆发。
如果你能坚持投资的习惯，收益就会带你去。
一个单子，市场环境很好，但是，有人会贪吗？不要贪婪干付

就是我在追求单次最大化。只追求结果不要过程出错。
特朗普的几次涨跌，大家都已经准备好仓位的应对策略。
但是胆的，特朗普规模不够大，没有把股位盯到我们的仓位
也是，从结果来说，我觉得很好
但过程有过对吗？

我是认对的。
第一，我就是哪里都不要要求满，留有后；n第二，流动性要学会交易，底部要止损，为了安全，我更要很多等等
第三，仓位的价值，不就是犯错的地方，最后我们也不会有失错了
第四，我的量级资金没有投入过，并且是赔亏啦

重要的，我没有犯错，没有别人错在里面犯错，我们的逻辑成立了，我们抓住了。
未来，来也没有这样的机会了。
我们要做的是：把利润最大化的事实。
但这不能保证每次都有好的结果。
做投资一次要记住：

- 1. 有时候做对了，得到了不错的结果
- 2. 有时候做错了，得到了很好的结果

对于我个人来说，我会把过程做对，单次结果对不重要。

# 三、双赢赚钱

我不喜欢交易，我喜欢交易。
以交易来尊重对手。
就要尊重对手。
你赚的钱，就是你亏的钱。
投资对的，
投资有三种收益：企业增长+分红+翻倍回报。
把持股的价值，价值的变动可以忽视的
赚取企业增长和分红的钱不是错的，要从别人身上赚错的
所以，投资可以是双赢：赚了企业的盈利，又赚了企业的收入。
在股市里，大家都是想跑到别人家里去，就是靠市场听消息，说故事，捕捉别人的错，这图画叫什么交易
最后自己都得够了，哈哈我没睡到监控。
大家都想惹，自己不是总不会想去交易
从别人家里赚钱有容错吗？
别了！别人从你家里赚钱
在股市中收获交易并不是错，我也不是说我是错的
只不过，我不喜欢交易，因为是双赢的。
当我们用双赢思维去投资，你会发现，不用去别人家里赚钱，在某时刻，一群猴子会主动抓你手
你急，不要急。
这种思维，重要什么，比什么重要？
其实我们不需要任何技巧，如果你在投注时，情绪会把人变成真正的想法，双赢的人才能获得。

# 五、思维是胜之道

如果你把股市当赌场，你就是输家
如果你把股市当成一个经营的商场，你就是利己的商人
股市本身没错，完全取决于我们对待它
与人之间极大的差异，真的是你想的
你会发现，在漫长的投资过程中，真就是大道通宵，不需要任何技巧，最终能够大成，而是基于自己
把单次博弈变成重复我们需要：注重过程，懂得双赢，安全第一。
