


# 米联储闻 251015——假令风歇时下来 (NBA重启中国赛)

你好，我是米筐。

这里利中美贸易战拳打抬脚，那里利美美国NBA悄然返华。中美之间到底是真打还是假斗，令人迷惑。这次 NBA 中国赛后六年重启，举办地点颇为微妙，选址在特区澳门。中国媒直言，澳门只是试水之举，NBA需要从2019 年的政治风波中汲取教训，避免重蹈覆辙。这次NBA开赛更是成为各界名争夺流量的秀场，久不露面的马云都热闹起来了。伴随此的是，NBA与中国篮协在澳门共同宣布达成多年合作计划。这次NBA回归，蔡崇是关键角色，阿里也在此次中国赛中有着极高的存在，不仅是赛事赞商，旗下多个业务也参与其中。阿里云在赛前与NBA达成一项多年合作，阿里持股的社媒平台微博也与NBA 延续多年战略合作协议。

此外，NBA 中国赛的回归和金沙集团推动达拉斯有关。金沙团总裁兼首席运营官哈蒙特是NBA达拉斯独行球队的老板，他旗下物业澳门威尼斯人正是本次季前赛的所在地。NBA 结束于2019年10月，香港反港运动如火荼荼之际，任NBA期间总总经理黄峥在社媒平台X发名为“自由而起，和香港在一起”，引起中国各地强烈不满。央媒随后暂停 NBA 赛事转播，多家国取消对 NBA 的赞助，NBA 在中国的季前赛也被取消。这场政治风波造成数美元损失。直至2022 年，中国电视才逐渐恢复 NBA 赛事，但市场热度和商业合作远未恢复到黄金时期水平。NBA 近来试图重建中国的品牌影响力，从停止合作的政治诱因，到现在的口碑暖，背后却离不开政治因素的影响。NBA一直想要重回中国市场，而中国也想借 NBA 全世界流量，中国不拒绝任何合作，也接受知错改，中国市场允许大家发财，只要放下中国政治热度的执念，谈钱利时欢迎，翻身在感情上时滚蛋。

一边是民间交流，商业领域的回暖，一边是政府层面针锋相对的博弈，中美两国互加征的首轮船舶港口费用同步落地，几乎所有国家都可能陷入中美博弈的夹缝之中。大佬集团例如，中国对金属和磁体的出口限制，将影响到欧洲内部运输的欧洲汽车制造；而针对中国制造船舶的收费，即便对停靠美国港口的非中国航空企业同样适用。中国还将韩国航空企业华韩集团的五家美国子公司列入制裁名单，指控这些子公司“支持和协助”美国在造船的相关行动。当中开启塑身，世界就是地动摇，没有国家可以彻底置身外。但是从中国与美国的多次博弈经验来看，还是从中美贸易、中美关系的基本现实来看，眼下升级的博弈大概会在一段时间后达成协议。这次中美博弈陡然升级，很多美国企业已经跟狼来了故事里的村民一样，该干嘛嘛嘛，丝毫不影响他们的商业行为，因为他们意识到这次的关战更像是一个戏，很难落地。

很多人说，美国实力仍然强大，中国不可轻敌。说实在，中国在对美问题上从也不敢轻视，美国确实还是量第一的大国，但贸易战拼的是不同国家的韧性。美国还是全球第一大经济体，金融和科技实力冠绝全球，但美国不同群体、不同党派的关系高度化，日益严峻的社会割裂、政治化，美国虽然强，但现在的美国很难将力量凝结起来，说好听是自由，说不好听是散兵游勇，因此面对中国这种高度集中的挑战时，显得有些病态投医。中国与美国在许多方面存在不容忽视的差距，中国自身依旧面临诸多应对的现实挑战，但现阶段的中国具有世界罕见的整合和调动资源的超强大国家能力，能够在相当程度上通过舍弃短期利益来谋取中期的利益，并在一定程度上激发中国社会的共识与民族性的韧性，这意味着中国在应对博弈波动中具有不容低估的韧性和耐性。中国并不是封闭化的苏联，美国也不复当年的影响力与信誉，中美之间最根本的竞争到底到底是综合实力与人心的竞争，面对各自发展问题能否破解。

## 行业观察：全球机器人市场的变迁

最近，瑞士ABB宣布将机器人业务以53.75亿美元出售给日本软银。作为全球机器人大家族之一，ABB工业机器人高居全球排名二，如今却给了日本人。ABB是全球设备和自动化技术龙头，总部位于瑞士，列位世界500强。全球工业机器人出自ABB集团，与发那科、安川电机、库卡并列大家族。2024年，ABB机械销售收入22亿美元，全球市场份额第二，行业领先，却在机器人行业变成了卖家。从行业角度来看，ABB集团有电气、运动控制、过程自动化、机器人与离散自动化四大事业。其中机器人不是ABB的核心业务，机器人业务只占集团收入的7%。2025年二季度，ABB运营利润率提升至19.2%，机器人与离散自动化业务的运营利润率只有12.1%。虽然ABB的工业机器人业务仍全球第二，但在集团内部规模和利润都滞后。2024年4月，ABB曾宣布拟对工业机器人业务实施100%分拆，目标是在2026年将其为独立的上市公司。但是现在他们放弃了分拆转手给了日本软银，原因非常现实，就是对方给得多。瑞士投行分析，若上市，ABB机器人业务的估值预计为40亿美元以内。而软银给出53.75亿美元的交易价，高出市场预期一大截，面对如此丰厚的现金报价，ABB集团很难拒绝这一更具确定性的交易。

至于ABB为何卖，除了其诱人的现金，其实也有难言之隐。表面上全球机器人产业欣向荣，而从经营数据上看，2024年ABB机器人业务利润下降39%。2025年财务，ABB机器人与离散自动化业务营收同比下降，运营利润下滑20%，利润率从11.1%降至9.1%。背后的真正的台词就是，随着中国高端制造企业进来，美西方国家去赚钱的领域和日本都会越来越少，而现在估计还能卖掉，还能卖钱，以后真的连尾巴掉了。

中国是在全球最大的机器人应用市场，2024年工业机器人年安装量达到29.5万台，占全球总量的54%，稳居世界第一。随着埃斯顿、汇川技术等本土企业逐渐掘起，国产机器人的占比不断提高。2025年上半年，埃斯顿机器人市场份额达10.5%，连续两个季度列位中国机器人市场第一，首次在国内市场工业机器人出货量超过外资品牌。而四大家族的德国库卡早在2017年已被美国收购。这意味着行业的两个大巨头的两家欧洲头部企业已经退出了这一领域的竞争，欧洲企业几乎主动放手这些工业制造方面的先进生产力，除了心态上的短板，确实是研发能力、经营能力甚至是意愿都已经跟不上时代的节奏了。欧洲的老化，是彻底的、全面的、非修复性的老化。
