


# 鉴茶经院 251213:-易第 34 （上）： 空间与撤退的智慧

咸卦，是少男少女恋爱爱；

恒卦，是双方结婚了，在一起了，

然后呢，就会遇到婆媳关系的问题了。

这就是“遁”。

遁：亨，小利贞。

象曰：天下有山；遁君子远小人，不恶而严。

遁卦亨通的，柔小者利于坚守正道。君子要拉开与自己不舒服的空间，既不显露出恶，也能相互体面。

这里的小人，不是坏的，与道德无关，而是让自己不愉快念头不通的人。

这个意境，上卦是天，下卦是山，山有高磊进遥天的气势，天高向上，有避山的气势而退避之象，此谓“遁”。

婆媳关系，是不是像天和山，天高在上，需要尊敬；媳如山，自有根基。天和山，两个世界，无法交集，保持恰当距离与界限，才能长久和睦。

通，不是逃跑，而是策略性的给出空间，“不恶而严”。不露厌厌，就不会矛盾激化，互相保持庄威严，就会彼此敬畏，不会冒犯。

当然，婆媳之间非常微妙，就像女儿的情况也并不常见，但绝大多数都是相互“看不惯”。

没办法。视野，认知，年龄的差距太大了，从未磨合过，还要如此近距离的生活，必然各种冲突。

而媳妇们处理的好，基本都是能够“给出空间”。

先贤用家庭和婆媳关系的发展来告诉我们深刻的道理，即，你总会遇到外部环境的变化和各种问题，这些问题具有三个显著的特征：

一不由你决定。

二是它没有答案。

三是你努力没作用。

就像你能知道自己摊上什么婆婆吗，你努力半天很还能背道而驰。

婆媳关系，没有答案，只有空间。

或者说，空间就是答案。

同学们，在日常日常中遇到一些棘手或者难搞定的人和事情时，索性不如放开，等一等，或者战术性的离开一下，说不定问题迎刃而解。

放在投资和股市上也一样，如果真的按我们的节奏的，对于喜欢滚波段操作的同学来说：

- 30 离岸，是科技开始回归，市场光明，
- 31 离咸，是恋爱了，你大胆进入，热烈拥抱，
- 32 恒咸，是结婚了，重仓迎来主升浪，你要坚定忠诚，

如今，从11月15日，讲《你是电你是光》，主线涨了快一个月，基本都是30%以上，核心品种都已经创下新高，几个龙头已经点涨不动了，再加上美国昨晚的科技股大跌

- 33 逼挂，是女方海外算力的主要调整和休息一段时间了。

不调整够时间，又哪来筹码的充分交换呢。

哪一次的上涨，不是因为砸出了空间呢？
