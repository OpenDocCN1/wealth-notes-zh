


# 杨林被拒绝之后

这两天，杨林说：“我被重新考虑了，又被拒绝了，毕竟我是这里的人。”杨林准确地说道。

2016年，杨林的股份估值是237.76亿元（约合32.7亿美元），虽然已经涨到了300亿，但他还是不想卖，因为觉得太便宜了。

杨林对这个价格非常不满意，认为太低了，决定要等一等，等更有价值的人来买。他打算私化公司，这样至少会翻倍。

他想，如果我的公司能在美上市，价值至少能翻三倍。

杨林的打算是先在香港上市，然后再再去美国上市。如果能在美国上市，那价值至少能翻10倍了？

杨林的心里在想，如果现在2017年上市，价值至少能翻倍。等到了2020年后，价值至少能翻三倍。其他的股份，等万他在美国上市，价值至少再翻十倍就足够了。

2023年，杨林公司上市了，市值只有20亿，IPO跌了40%。作为创始人的40%股份，杨林想后悔，但股份已经卖了，后悔也没用，由于股份已经卖光了。

可是，这次杨林在2023年中国上市了，虽然只拿了15%的股份，但中国还有85%的股份。由于杨林还有这么多股份分红，杨林公司上市的分红，加上股份上涨的40%，对杨林来说，杨林心里也算舒服了，至少又赚了一笔钱。

杨林的心里想，虽然他没有一个大老板了，但他还有另一个大老板，就是他自己。由于Livery Investment Limited上市的第一天，由于杨林还控制着这家公司的控股权，杨林打算，现在再来一次上市是有肯定的。

杨林的心里想，如果2025年上市，至少又卖掉一半股份了。由于公司还有控制权，“万一卖掉一半，杨林还是老板，他还是老板。”杨林的公司就成了一个“杨帝国”。

2023年，杨林在上海开始经营一个新的集团，包括服装、饮料、古玩等各种。当时杨林的经营状况如何，但他自己觉得自己很有钱。

由于杨林找到了新的钱路，他开始扩张，由于资金充足，他的业务也迅速扩张。但是，杨林没有再次上市，因为他不需要钱，他已经有不小的钱了。

2028年，杨林的公司继续扩张，他的业务在全球范围内都有了。杨林的心里想，他已经可以成为世界富豪了。

杨林的公司业务越来越大，但他管理也越来越松散了。
