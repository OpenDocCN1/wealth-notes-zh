


# 洪灏：当下市场的主要矛盾-250325

## 当下市场的主要矛盾和重要时间节点

昨夜，美股强势反弹。其实，在经历了连续四周的下跌之后，标普上周其实是小幅收涨的。虽然上周几乎每天的盘中震荡超过了一个一百百分点，但标普上周只有一天是下跌的。对于每天天天看着美股开盘睡觉的人们而言，他们可能并没有感受到美股上周的修复。美股的技术修复从我们在三月三十日星期五发表的专属报告《洪灏：让美国再次遭遇衰退》就开始了。在那篇专属报告里，我根据当时美股的交易数据预测了美股这次的技术修复。而报告当日，标普收了一根大阳线。

譬如如此，美股各大主要指数上周依然出现了技术技术分析上的“死亡交叉”。这是一个令人担忧的形态，也就是股价的五十天均线下插到了两百天线的下方。标普昨天均线强弱修复了两百天线，但是慢均线之间的关系并没有改变。昨天和上周一样，还是依靠可靠科技股的抬升带领市场反弹。特斯拉在连跌了十三周之后大幅飙升了12%，去年一月以来最大的单天涨幅。还是少亏了特朗普在自己的社交媒体上宣称白宫是特斯拉的坚强后盾。白宫秘书长还特意在推上发布了一些内部会议的照片，宣称仰着DOGE，美国政府现在是“最高效的政府”云云。

盘面上，其实这几天美股的反弹都伴随着很弱的成交量，更像是一次空头回扣的行情。与此同时，证券公司交易的大客户的仓位其实实在被大幅缩减的。而引发反弹的这些科技股是今年以来表现最差的板块。因此，对冲基金空头获得了底部这次反弹的概率非常大。如果美股指标继续显示市场情绪低迷，那么这个情绪数据并没有从散户的买入表达出来。美国散户买入指数的资金量是近年来最大的一周。散户也在过去两周买入了价值80亿美元的特斯拉，是历史上最大的持有

机构的“聪明钱”和散户的“愚蠢钱”两者的交易背道而驰，是当前市场的主要矛盾之一。难道这两种钱看到的是一样的基本面?作为投资者，我们应该该信谁？

2018年9月3日，我在那篇经典的报告《洪啸：中美的周期冲突》用我的量化周期模型预测了几个交易日之后，从2018年9月中旬美股的暴跌。在这篇经典报告里，我开头还做了如下的预测：“当前可能是自2016年以来的、新的7年周期里的第一个3.5年短周期。这个周期将在2020/21左右再次下行，并伴随着严重的危机。“回头，2020年全球经济进入全面衰退，而中国市场在2021年的2、3月份左右顶点后趋势性下行。那时的指标仍在31000点。回头，一切都如此清晰；那年前的我，也如此所运。

溯历史周期的研究中尤为重要。这是因为，虽然“历史不会简单重复，但往往押韵”。对于波动理论，最难反驳的批评，就是一个人永远不会知道处于波浪中的哪一个阶段。因此，周期波动的起点总是出于主观判断，而对于没有经历太多周期的年轻分析师来说，则更具挑战。这也是为什么，好的宏观分析师的价值，总是在他的白发间、皱纹里。

借后视角，我们基本可以确定两个周期的关键点：2021年的周期高点，和2022年10月的周期低点。两个关键的时间点相差约一年半。请注意，此处对于时间运行的成交量，我特意做了模糊处理，因为周期不是闹钟，其运行有自己的律动，也没有绝对死板的节奏。如果我们能够确定周期运行的大致时间节点，那么我们就可以顺势推导未来周期运行的轨迹。

在时间节点这个关键问题上带说一下，在2022年10月31日这个重要的周期底部，我发表了另一篇经典的报告《洪灏：买！买！买！》。那是彭博终端阅读量全球第一的报告，也是业内公认的这次中国市场周期性修复的起点。到了2024年的9.24行情开启，回头再看，其实指低点是在不断上升的。

上午去北京西边开会后打开手机报价屏，赫然发现香港市场大幅下探。显然，我们之前反复的技术23/24,000的阻力，市场久攻不下渐显疲态。在岸市场在神秘力量的帮助下大致收平，离岸市场就没有那么幸运了。昨天收盘半时的上攻修复，主要还是铜板的上涨，但是今天还是压在各种负面消息之下。阻力位上最怕的就是来回拉扯。

那么，现在市场的主要矛盾是什么？

如果我们看国际铜价，纽约铜已经破一万美元，创出了历史新高。宏观上都把铜价叫做“铜博士”。这是因为铜是实体经济里很多工业品的原材料，关系到整个经济的方面面，因此铜价对经济周期高度敏感。铜价上涨，往往示着经济周期的修复回暖，因为实体经济对铜的需求将会增加。然而，当下的周期，是铜价上涨。
