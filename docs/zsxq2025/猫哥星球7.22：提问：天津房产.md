


# 提问：

猫你好，关注你很久了。今年看到知识星球618活动断开。我想向你咨询关于房产的问题。我有一套天津市和平区的学区房，22年为了孩子上学时购买的，只是为了落口。当时花了250多万，现在孩子上高中后房子用不上了。我咨询了房产中介，目前房子价格已经降到了210万。出租出去一年也没多少钱。在目前房产市场软弱的大趋势下，我是忍痛割肉低价处理合适，还是收一一下出租待房产市场恢复合适？目前我财务状况并不需要着急变现。但是我怕房产一天降下去。

猫哥回答：

通过AI查了下，天津和平区租售比目前大致是1.45%，目前我们30年期国债收益率大致1.9%，这就有不小的差距。

之前我给给过一个量化指标公式，房要企稳的标准是，30年国债收益率要小于房屋租售比，所以如果从静态来看，天津和平区房子未来还有继续下降的空间。

当然我也预判下半年美联储将降息，目前预判的降息50——75基点左右（自然也可能有变数，如政治博弈的变数），按照这个降息幅度，我们货币政策也会随同降息，如果我们跟随降息同样的幅度，那么届时30年国债收益率大致与和平区房屋租售比平，从这个角度来看，在中同时降息50——75基点时候，该地区房价在年底前有可能企稳，但也稳而已。

7月15日国家召开了城市工作会议，会议核心精神就是两个，一个就是严控增量，盘活存量，一个是建设城市群与都市圈，从这两个精神来看，即便是核心城市普通住宅未来也没增值的机会。

所以，综合方面因素，建议你可以考虑尽快手里房子卖掉。
