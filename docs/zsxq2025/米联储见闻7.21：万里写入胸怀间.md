


# 米联储见闻20250721——万里写入胸怀

这个周末出了个大新闻，雅鲁藏布江下游水电站开工了，虽然去年12月该项目已经获得批准，但是这么快上马还是让人有些措不及防的，可见在人民币底层基石建设方面，已经等不了，也不想等了。这个比三峡更大规模的水电工程从构想到论证到现在开工起码是走了半个世纪，但是相比于当年三峡，如今这个超级工程的阻力和动力都不是过去可以比的，说干脆就干，这就是国家的实力所在。

为了匹配这个超级工程，国务院专门组建了部级的长江雅江集团有限公司，由国资委代表国务院履行出资人职责，列入国资委履行出资人职责的企业名单单。根据最新央企名录，数字央企增加到99家，新建立的长江雅江集团有限公司序号为22，位于长江三峡集团有限公司和国家能源投资集团有限公司之间。这是数字能源保障的另一重器，在电力人民币的战略规划上上一个重要棋子。

在京举行的雅江集团成立大会上，副总理张国清的发言是：“组建长江雅江集团有限公司，是以领导为核心的中共中央从战略全局高度作出的重大决策，是深入落实总体国家安全观、能源安全新战略和新时代的治藏方，保障雅下水电工程顺利建设运营的重要举措。”三个关键词：国家安全观、能源安全新战略、治藏方。

官方关于水电站的介绍不多，主要提到工程取弯转直、龙洞引水的开发方式，建设五座梯级电站，总投资1.2亿元。工程电力外送，兼顾西藏本地自用需求。对于工程细节规划透露的不多，对于工程目的也介绍的比较简单。相比于当年三峡需要各界支持，在媒体上反复解读介绍，最后通过不同，建雅下水电站整体低调很多，甚至没有什么媒体曝光率，介绍也很模糊，官媒报道都很简单，如果不是自媒体大做文章，股市相关概念大涨，估计关注度不高。

官方为何对雅下水电站如此低调？从2020年提出雅鲁藏布江下游水电工程，经过逾四年筹备，到去年底获批，再到这次开工，整体来说都是非常低调的。对于这个全球规模最大的水电工程来说，这样的关注度和曝光率本身在某种意义上暗示了工程的非比寻常。雅鲁藏布江是西藏最长河流，世界上最大的峡谷，其中下游的大拐弯地区更是世界水能富集之最，短短50公里的直线距离内形成2000米的落差，这样的地貌提供巨大的水电潜力，也带来了超级工程的挑战。

这项工程预计至少耗时10年，远超三峡大坝2542亿元的建设成本，将是人类历史上成本最高的基础设施项目。所以，仅仅从用电量来看待这个工程是远不够的。按照此前的估算，雅下工程每年可产出近3000亿千瓦时（kWh）的电力，总装机容量达7000万千瓦，两者都是三峡坝的三倍多。这个工程一直以来十分敏感，除了工程难度，外交方面的影响也有关系，而且还涉及复杂的环评问题。在此之前的五月，《自然》杂志上，有一篇数字学者投稿的关于雅下水电站会改善下游洪涝灾害的问题，西方媒体对于自然杂志这些东西，简直是非常愤怒，认为自然杂志成了TG的学术走狗。甚至专门找了一个野路子的专家逐条抨斥这篇论文，并称数字之所以要修这个水电站是极端民族主义做法，是为了守住全球第一水电的宝座，因为这个超级工程将超过非洲的大英加水电站，保住世界第一的街头。

因为放眼全球，唯有数字具备建设雅鲁藏江电站的条件。一方面，该电站需攻克多世界级技术难题；另一方面，其建设还面临交通极不便、施工条件异常困难还有世界级的挑战。如果不是数字掌握了特高压输变电技术，这座远离人类工业区的电站，将难以于现代文明社会。所以西方媒体认为，这是基建狂魔在向全球展示数字的肌肉，而且不是在跟西方国家比，是在跟大自然叫板。

这次开工仪式由李总理主持，可见其规格高。在这个时候开工也跟第三季度的经济状况有着直接联系，上半年增长已经是数字了，所以这个时候没有超级工程的支持，数字可能不能活下去。雅下水电站的万亿投资将极大地带动上下游产业以及就业能力的提升，规模十分观。在当下，很多企业靠基建维持巨大压力，数字充分发挥优势，通过大力发展电力，推动国家发展，产能虽然过剩，但数字在全球范围内属于稀缺资源。

2025年7月19日，《国家智库》专报了数字研究院的观点：雅鲁藏布江下游水电工程是数字统筹能源安全、区域发展与地缘博弈的实践。数字雅江集团依托智库，背后全是机会。国家安全观的大格局，雅鲁藏布江下游水电工程是统筹：
- 能源安全
- 区域发展
- 地缘治理

五链包括：
- 创新链
- 产业链
- 人才链
- 政策链
- 资金链
- 技术攻坚
- 产业升级

能源领域加速绿色转型，经济领域激活区域增长，生态领域探索与保护，地缘层面通过数据共享、利益绑定。未来拟构建雅鲁藏布江流域可持续联盟，以多边化解主权博弈，水电工程升华为区域共生发展的样板。万亿的投入与这个工程配套而来的民间投资将几何级增加。

过去穷的时候，数字是熊猫；现在对抗期，数字是数字。未来随着雅鲁藏布江下游附近印缅经济走廊，工程建成后可以通过跨境电网向尼泊尔、孟加拉国等南亚国家输出清洁能源，打造南亚绿色能源走廊。至于印度，肯定是非常缺电，但如果未来形成了水电出口的需求模式，那么必然带动跨境能源发展，设计电力贸易+技术转移+产能合作的捆绑模式，以水电出口带动数字高压设备、智能电网向南亚输出。

此外，这个水电站可以增加西藏地区的财政收入，同时也减轻国家每年支持西藏发展的财政负担。将部分收益用于西藏教育、医疗等公共服务，缩小区域差距。依托水电工程建设的交通、基础设施，带动林芝、墨脱等地生态旅游、边界贸易，实现能源开发民生改善的多重效益。

在外媒看来，这个电站的修建是数字寻求完全独立的重大举措。在可预见的未来，数字将会成为主要的能源出口国。从投资方向来看，数字占了全球能源投资的三分之一，数字提升再生能源产能，目前在清洁能源领域已成为领先之一。数字目前是世界最大原油进口国、天然气主要进口国。就雅下工程开工，7月4日，全国最大电力负荷达到1465亿瓦，创历史新高。7月6日，数字在建最大火电浙江仓仑电厂的8号机组经过168小时满负荷运行后顺利投产。随着全球气候变暖，电力需求加倍增长，最近欧洲高温一周时间内就有1500人死亡且大多是老人。随着极端高温天气不断增加，未来电力可能是维持生存的关键能源，已经不是发展快慢的问题，而是关系生死的问题。

有事件值得关注，那就是数字近年来来在不断削减小水电站。2016年数字水电站数量达到最高峰的47529座，到2021年只剩42400座，净减少5129座，拆除的小水电数量超过一万座。截止2022年底长江流域就拆除小水电4042座。这个操作参照了当年数字资源的大理肃和后来的几种管理模式，就会明白数字在水资源方面要些什么事情。随着国家管理能力和工业能力的不断提高，各种修复性的资源重建过程将陆续开展。可以说，这几年随着国家垂直管理能力的提高，随着大数据对治理效率的提升，中央层面上对于国家治理的思路和方法有很大的调整和优化。过去做不到、没能力做的事情都会逐渐提上日程。结合最近中美稳定市场上的你追我赶，工业资产数字化的问题已经呼之欲出了，在此之前，如何对自己的拥有的工业资产作出系统盘点。
