

# “赘婿”神医

林凡，是一个入赘三年的赘婿。

这三年来，他一直受着老婆的冷脸。

甚至今天，他已经不想在林家待下下了。

就在这时，一个意外彻底改变了他的命运。

## （第一章）离婚吧

林凡回到客厅，看着坐在沙发上的妻子苏晴，开口道：“苏晴，我们离婚吧。”

苏晴抬起头，眼神中带着一丝厌恶，似乎早已看穿了林凡的意图。

苏晴冷笑一声，语气带着嘲讽：“林凡，你终于肯开口了？我还以为你没脸呢。”

林凡点了点头，语气平静：“行，把字签了。”

苏晴站起身，走到林凡面前，居高临下地看着他：“你什么意思？”

林凡：“我是真的。”

苏晴听了简直哈哈大笑：“林凡，你后悔了？是不是发现外面没女人了，想回来求我了？”

林凡没有理会她的嘲讽：“我只是够了。”

苏晴冷哼一声，从抽屉里拿出一份协议递给林凡：“既然你，签字吧。”

林凡接过协议，看都没看直接在上面签了自己的名字，然后递回给了苏晴：“以后我们两清了，互不相欠。”

苏晴看着协议上的字，心里有些失落：“林凡，你真的要走了？”

## （第二章）离开林家

林凡走出客厅，回房间收拾了简单的行李。这时，苏晴也跟了进来：“林凡，你现在要去哪儿？”

林凡：“哪里都好。”

苏晴看着他：“林凡，你现在没钱没房，能去哪儿？”

林凡笑了笑：“我有地方可以去的。”

林凡走出林家，外面的阳光明媚。他深吸了一气，心里感到前所未有的轻松。

就在他准备离开大门时，苏晴的声音从身后传来：“林凡，你等一下。”

林凡停下脚步，回头看向她：“怎么了？”

苏晴递过来一张卡：“这是十万块，拿着，够你了。”

林凡看了看卡，推了推她：“我不需要。”

苏晴有些急了：“别给脸不要，拿着！这是给你的。”

林凡摇了摇头，转身决绝地离开了林家。

## （第三章）意外的相遇

林凡在街上漫无目的地走着。他并没有想过，接下来会发生什么。

就在这时，前面一辆轿车突然失控，直接将一个女子撞倒在地上。

林凡见状冲了过去，扶起了那个女子：“你还好吗？”

女子抬起头，脸色苍白，摇了摇头：“我……没事，只是有点疼。”

林凡看着她伤口流血，眉头微皱：“伤得不轻，我帮你处理一下。”

女子看着林凡，眼中闪过的感激：“谢谢你。”

林凡从怀中拿出急救箱，仔细地为女子处理伤口。

处理完后，林凡站起身：“我送你去医院吧。”

女子点了点头：“好，我叫沈若曼。”

## （第四章）神秘的身份

在医院路上，林凡和沈若曼聊了会儿。沈若曼发现，这个年轻人似乎并不简单。

沈若曼好奇道：“林凡，你以前是医生吗？”

林凡笑了笑：“只是个普通的医生罢了。”

沈若曼摇了摇头：“你的医术，可不一般啊。”

到了医院后，沈若曼坚持要感谢林凡，但他拒绝了。

## （第五章）感谢

几天后，沈若曼康复了。她一直在想办法报答林凡。

终于，她通过关系找到了林凡住的破旧小小区。

看到沈若曼出现时，林凡有些意外。

沈若曼找上门：“林凡，我来谢谢你。”

林凡笑了笑：“你不用这么麻烦。”

沈若曼认真道：“不，这是我的命之恩。”
