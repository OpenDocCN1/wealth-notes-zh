


# 自爱的本质是自我疗愈

原创：U 君 公众号：U君笔记 25年11月13日

如果一个人的身体不好，或者处理不好际关系，或者在财运和桃花运上总是受挫，核心原因就是“不够自爱”。

因为当你你不爱自己的时候，整个宇宙无法给予你回应，无法为你赋能，结果就是，你生活中的方面都会呈现匮乏和困顿的状态。

我总结，自爱一共4重境界（或者说4种疗愈方法），你可以对照着——反思一下，看看自己有没有做到。

## 1. 跟自己只说肯定的、积极的话。

你是如何跟自己对话的，直接反映了你的自爱程度。

有的人特别喜欢自贬、自嘲，总是跟自己说丧气的话。

比如：我真笨；我什么做不好；我最近倒霉；我的人生真的很不顺利……

从心理学角度来看，消极的暗示会大幅降低自己的身份认同和自信，反映到具体的事情上，就是什么事情做不成。

反映到人际关系上，你走到哪里别人都不会重视你，甚至跟着你一起贬低你、嘲讽你。

从玄学角度来看，如果你经常向宇宙发射“我真的很差”的信号，那么宇宙也会回馈负面的能量，让你做事情越来越顺，财运也越来越差。

反之，真正自爱的人永远不会跟自己说消极的话，即使偶尔自嘲，也是做给外人看，目的是创造一种谦虚的人设。

而在自己的心里，始终自信满满的，坚信自己就是世界上独一无二的宝藏，坚信自己是世界上最幸运的人。

即使遇到挫折和困难，这种人也会心里默念：一切都会朝着好的方向发展，因为我是一个超级幸运的人。

事实也是如此，有时候“主观能动性”真的左右“客观事实”的发展，然后就会出现好化、遇难成祥的局面。

当然，这件事有一个大的前提：你的客观胜率不能太低。

举个例子，无论是参加一个重大的比赛，还是策划一件非常重要的事情，在客观胜率是 50%的前提下，如果你的心态好，时刻给自己积极的心理暗示，那么你的胜率很可能会提高到 70%甚至。

但是，如果你没有任何基础，没有任何经验，胜率不足 10%的前提下，你再怎么给自己心理暗示都用没，奇迹都不会发生。

## 2. 照顾好自己的身体。

大家不要觉得这条标准很简单，80%的人要不要怎么照顾自己的身体，要不要觉得这这是一件无足轻重的事情。

要知道，身体，是我们成长与修行的载体，本身就是一个奇迹，你要懂得去赏识它、爱护它，而不是忽视它、嫌弃它。

如果一个人的身体总是出问题，那么很难拥有强大的精神信念，做事情的胜率也会大大降低。

我总结，善待自己的身体共有 4 个具体的方面可以发力：

- 尽量健康饮食。少油、盐、糖、精致碳水、深加工零食，多吃新鲜的、有机的蔬菜和蛋白质。
就拿我来说，我现在就很少吃传统的炒菜了，反而经常吃汉堡/三明治+蔬菜沙拉的组合(比如汉堡王这个品牌）。

- 每天适量运动。无论你是哪个年龄段的人，散步和骑自行车都是非常温和、也能让自己微微出汗的运动。
当然，如果自己有余力，就去做力量训练(抗阻运动)，因为这才是真正的抗衰运动，让自己的骨骼、肌肉、免疫力都变得强大。
我自己膝盖不好，现在很少跑步了，改为游泳+负重健走了。

- 充足的睡眠。我觉得对于现代人来说，想要充足的睡眠，最重要就是要减少屏幕使用时间。
我在公众号里也写过很多戒掉短视频、卸载购物类APP、多培养自己听读物的文章。
当然，如果你心里的挂念很多，总是想想的，也会影响睡眠，我的建议是大胆切割，多做断舍离。

- 必要的药物干预和现代化的治疗。比如，一个患糖尿病/高血压的人，最重要的就是在医生的指导下坚持用药，健康活到80岁、90岁。
如果停止药，很可能会出现疾病(比如心梗、脑出血)。
如果是癌症或其他疾病，而且已经严重干扰到生活了，这时候该去做手术，不要拖延。
我自己去年做过癌+脓肿，我觉得物理上把“毒瘤”切掉，心理上把“毒瘤”切掉。
如果你总是犹豫、喜欢纠结，那么物理上把“毒瘤”切掉，最后难以成长。

## 3. 不允许坏人进入生活。

允许别人评价你、怎么对待你，直接决定了你的自爱水平

举个例子，如果有人经常贬低你、打击你，而你允许对方出现在自己的生活中，那么你就是一个不爱的人。

凡是喜欢说“我笨”“我什么做不好”的人，从小遭受过很多坏人的打击，大概率变成废物。

那些喜欢贬低你、父母、老师、老板的人，大概率会越来越糟糕。

其实这个法则第一条则是：如果你知道只有离开那个环境，你才能变好。

## 4. 永远把自己的感受第一位。

时刻考虑自己的感受，这些都是非常好的品质，但是你绝对不能因此忽略自己的感受。

要知道，人生主要是活一个过程，而不是活一个结果。

一个人到了50岁有10万的存款，另一个人到了50岁有100万的存款，后者并不比前者幸福。因为后者在获取财富的过程中，可能承受了很多尊辱、委屈和恐惧，心灵已经干涸了，有时候还会重新选择一条更加安宁、更平静的路。

我现在的想法就是：自己的生命体验比钱还要重要，享受过程比结果更重要。

如果你的内心已经干涸了，我建议从以下几个维度进行疗愈：

- 减少负信息的摄入。哪里地震了，哪里发生车祸了，哪里发生战争了……这些新闻都不要看。我在公众号里也说过，99%的新闻都是垃圾新闻，只会给我们大脑“涂上一抹灰”。

- 减少或者释放自己的压力。如果一件事让你压力很大，甚至一天晚上都睡不着，而且经历多次无法缓解……你以后干脆不要去做这件事、不要去赚这份钱了。不要逼自己去做那些没有天赋、完全不擅长的事情。

- 拓展自己的认知边界。学习新内容，了解新认知，总会给自己生活带来美好的改变。
举个例子，我的公众号里就会涉及到很多“健康饮食”、“断舍离”、“玄学”相关的内容。
很多人看了之后觉得耳目一新，因为在他的信息源里面根本就接触不到这些。这些理念真的会让他的心灵更加明亮、更加通透。

- 探索自己的人生使命。我相信，我们每个人来到世界上都是自带使命的，比如法布施、财布施、无畏布施。当你找到了属于自己的使命之后，你就不会再高骛了，也不会自怨自艾了，你会踏踏实地生活。

- 深刻理解生命与死亡，让自己回归大自然。如果压力大了，去海边、草原、森林这种自然环境里接受疗愈。
我自己每年至少有一个一个月在人烟稀少的大自然环境中疗愈、充能，效果非常好。
