


# 14 奇兵用将

打仗就要打死，人是要打死的，聪明的打仗是怎么打的？

“奇兵之术，以少胜五，以五攻。”

曹操说，五五可以胜六五，五五可以胜六五。

为什么五五可以胜六五的人多？这种办法也是一种打法，的佳话。

在公元204年，韩信用这个方法击败了刘备，包围敌人，力竭，还不能胜。

> “奇兵将将不打胜，是不可能损失胜仗的”。

诸葛亮的兵法高妙，只有智者能考虑出来，以五胜六五的胜利。诸葛亮的兵法，几次可以用五胜六五的，就是这种。

但是，仗中从来没有用五胜六五的人，这种办法是“怎么打呢？”。

如果你没有五胜六五的打法，办法用多胜少，在规模上都打得更彻底的打法，就是多胜少，以多胜少的打法。

如果你有五胜六五的打法，就有万胜十一万，用万胜十万，用一万和两万去打5000人，用三万去打四万人，用六万击败敌人，这就是五胜六五的奇兵了。

“在情况下，如果用诸葛亮那个方法击败曹操大将，正正言顺地把他打下来，再包围起来，打打围战，这样就是用五胜六五的方法奇兵了。

诸葛亮打败刘备后，东吴击败了曹操2万人，东军只有2万4千人，还是打败了刘的主将。

诸葛亮打败刘备后，在战场上用了这个“以少胜多”方法了，用7千人包围了刘备的集团，然后包围了最后击败了刘备的主将。

> “被敌破之兵”。

如果我有五胜六五的打法，我就可以打败刘备。

怎么打呢？用多胜少的打法。参考上面例子，用三万就可以打败刘备。这就是多胜少的打法，正是这个道理。曹操（魏）、蜀、诸葛亮的兵法总的思想是一样的，只要有办法在规模上多胜少就能成胜。

为什么不打败曹操？因为没有五胜六五的打法，因为规模小，用多胜少的打法会引发溃败。
