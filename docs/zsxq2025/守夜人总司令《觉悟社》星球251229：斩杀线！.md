


# 守夜人总令《觉悟社》星球 251229：斩杀线！

这不是什么新鲜的，只是把这个故事推过了一个流行的名字。很久以前就通过了【结构】基本概念推演出了这个结论：

搭建起某种生存结构的要素，一旦进入资产化的快车道，置于这种生存结构中的成本，就必然会水涨船高。

资产化会像一个无形的手，推动着置身其中的所有的生产要素，包括本人，不断强化这个趋势。

资产化会呈现出什么样的具象呢？简单来说，就是把人从各种相互扶持和相互支撑的结构中拽出来，让其处于一种徒手攀的生存处境之中，如此一来，所有的安全感和生存保障，就只能依靠唯一的途径，不断向上爬！

在漫长的封建社会，金字塔式的稳定结构为主。金字塔式统治结构之所以成为为主，是因为土地是农业时代财富的核心代表。公侯伯子爵，表面看起来像是社会身份和礼仪层，实际上是占据多寡的排序。

在传统的农业时代，占据更多的土地，就需要组织起来更强大的暴力，而要组织更强大的暴力，就依赖于你所辖的土地上能供养的人口和物产总量，这二者又取决于土地的多寡，于是，像一条蛇咬住了自己的尾巴一样，形成了一个死循环！这恰恰是在漫长的农业时代，不管王朝如何更迭，都不断重建原有的金字塔结构的根本原因。

科技革命打破了这个闭环：一个占据土地并不太多的贵族，通过发展工业能够以极少的土地拥有远超土地面积所对应的财富，这些财富可以从别的贵族的领地上大招募士兵、工匠和劳动力，从而组织更强大也更有效的组织暴力。

在《E10：密度的秘密》那篇文章文中，详细阐述了有组织暴力的演进方向，从人类密度向机械密度，继而向信息密度演化。每一次跃式的进化，本身就依赖更高的综合成本。为什么再过20 年，全世界 90%的国家，在武力对抗上将会呈现一方面的绝望呢？因为要发展信息密度更高的作战体系，依赖指数级上升的综合成本和社会生产基础，而这个发展信息密度更高的成本只能从现有的产业中赚取，这就形成了一个死循环！

当一个小贵族通过产业革命，组织更大的有组织暴力之后，为什么没有延续过去的剧本去掠夺多的土地，建立更大的帝国呢？因为小贵族自己的成功经验已经验证了什么更重要，所以小贵族会掠夺与扩大生产有关的要素，包括原材料生产劳动力人口贸易港口主要通道等！

这不是意味着传统的金字塔型的结构，正在向平面网状的结构转化呢？看起来好像是这样的，事实上这只是一个阶段。因为交易结构是极不稳定的，在一个漫长的交易链中只要有一环断裂，整个交易链就无法建立起来，所以这种过渡的形态一定会向稳定的形态转化。这就是为什么生意做了以后一定会去形成断层，店大客的本质是通过断层式的地位和权力来改变交易中的平等和自愿原则，最终类类似于农业时代金字塔结构中单向依赖的稳定关系。

我们在多年以前就讲过：当金字塔式的统治结构的维持成本越来越高，以至于无法继续运行的时候，金字塔的结构就会逐渐移动向交易结构转化。王朝的后期，君主从说一不二，转变为文官集团和世族大弈，这就是转化的明显呈现！任何原有的层级秩序无法维持之时，都会逐渐放权，让下面拥有更多的自主权。然而，下面通过这种主权发挥主观能创造更多增量和财富的时候，也会要求有更大的话语和决策权。于是，自上而下的依赖转向就成了为了相互博弈，这本质上是金字塔中的上部分逐渐平化的表现，如此一来，所有的压力都会被压到中下部分，从而让整个结构的秩序进一步难以维持，最坏的情况是导向全面碎裂。
