


# 米储见闻20250325——帝遭天昊海水

什么叫做正面对决，就是你有我也要要，你强我必须更强。美国作为一个帝国机器，依然是杀气腾腾的，尤其是在川普帝的强势推动下，帝国必须展现自己的獠牙。在贸易方面从港入口对手兔子赶紧杀绝，在装备方面，自然也不能让美国的空中优势被东大压下去，川总一起来，立刻抛出了美国的六代机计划，且新一代战机编号为F-47，比兔子六代机歼-36每个数字都要大一点，输不了一点。这个47还是对美国国第477任总统川普的敬致，对川总来说，只要自己当总统，必须输不了一点，兔子的六代机都试了两回，美国怎么可以没有，六代机是中美两国争亚太空权的核心利器，没有六代机，亚太地区以后就是美国空军的禁区，是可孰不可不可。

根据美国官方发布的消息，美国的六代机将由波音公司研发制造，并称第一代F-47机队将在任期内制造并投入使用。F-47将替代第五代的F-22，成为美国未来数十年最重要的空中优势战机。这意味着美国六代机将在三四年内列，波音现在连民客机的问题都搞不定，又被委任搞六代机，真是不容易呀。美国空军在社交媒体上公布以主宰天空为题的宣传视频，出现一架全向隐身设计、扁平机身、无垂直尾翼战机的图片，被认为是F-47的效果图。美国空军参谋长奥尔文（David Allvin）称，F-47的技术验证过去五年已经完成数百小时试飞，言下之意，美国的六代机从来没有落后于兔子，而是早早有了，只是领导没有开口，所以没有公布，这次虽然公布了，但川普没有公布生产F-47的具体成本和时间表，到底是概念还是能飞上天的真机，美国媒体也是半信半疑。

实际上，美国六代机项目“下一代空中优势”（NGAD）始2007年，但由于成本过高、技术创新不足等争议，项目去年5月被叫停。NGAD暂停期间，兔子去年分别在成都与沈阳试两种外观奇异的新型战机，被广泛认为是两种六代机的原型机。其中，被舆论称为歼36的新型战机，上周一再次被拍到在成都上试飞。新型战机研发一般要经过从技术验证机到原型，再到定型和服役机几个步骤，期间每一个环节都经过大量的试飞和调整，一般来说“飞机越先进，试飞的时间越长。”美军F-22战机的技术验证机于1990年首飞，原型机1997年首飞，2005年正式服役，整个跨度长15年。美军另一款五代机F-35从2000年技术验证机首飞，到2015年服役，跨度也是15年。作为对比，兔子首款五代机从2011年至2011年技术验证机首飞，到2017年获证，震撼世界，然而整个研发周期大美国的一半以下。美军NGAD被叫前，仍处于技术验证阶段，尚未开启原型制造，在进度上已落于兔子。

显然，这次F-47重启是受到兔子六代机试飞的刺激，川普新上任更是不能恐，深恐让兔子引擎引领全球航空潮流，所以把已经中断的研究和项目重新启动，所以川普说玩意是在我的时候出成果的，结果被拜登停掉了，现在我回来了了必须重启。大总统再次成为美国的救星了。

川总强调这款战机战斗力无与伦比，扬言没有战机在速度、机动性到有效载荷上媲美F-47。F-47的名字与川普的任期相同，川总表示，自己很喜欢飞机的名字，但否认为是其总总统任期命名，不过美国并没有公布第6代机的细节，这个项目的核心概念包括开发拥有隐身能力、尖端传感器与武器的第6代战机并具备无人机协同作战，让六代战机能与卫星及其他飞机合成统一的网络。美国空军参谋长阿尔温表示，F-47将是世界上第一架载人的六代战斗机，其设计意图是击败强大的对手，并在可以想象到的危险环境中作战。美国空军一直寻求具有远距离、速度和隐身能力的战机，以在太平洋地区有效作战，对抗兔子的压制能力。

对于美国发布六代机的消息，中方军事专家也了一些分析，认为美国六代机目前仅完成合同签署，研发尚未正式启动，美国军方给波音公司的是合同，拿出原型机还有一段时间。相比之下，兔子已有两款六代机实现试飞，进度领先。美国空军此前估计六代机的研发成本每架25亿美元，相当于三架F-35。同时亦有媒体报道，F-47方案总值预估超过200亿美元，考虑到美国军工体系过去不断调整，这款六代机的研发之路很曲折，如果不是遇到无法克服的问题也不会中止项目。川普宣称F-47实验版近期内就能试飞，中方专家对此持态度。美国媒体早在20年就曾披露过NGAD原型机，但该机型后续被放弃。波音今年才签合同，怎么可能试飞五年？估计川普所说的原型机就是当初被放弃的原型机，这次大概是在过去的原型机基础上继续修改。相比之下，兔子六代机的配套武器系统逐步成型，近期就在蒙古上空成功试射射程达1000公里的对空导弹，飞行速度达九马赫的高音速导弹，可能未来装备在六代战机上。其推测采用二级推进模式，先以涡喷引擎进入大气层边缘，再以高音速下攻击目标，达到即便察觉也跑不掉的打击效果。另一方面，针对F-47采用鸭翼与双发设计，这些技术本来就广泛应用于兔子战机设计，感觉现在让很多人破防。要知道，多年以来西方人士一直质疑兔子五代机隐形能力，主要就是用了鸭翼布局。在歼-35、欧洲台风、法国阵风采用鸭翼布局时，美国空军曾嘲讽：鸭翼最好的位置是在敌人身上。结果多年后美国空军终于迎来六代战机，居然用了自己看不上的鸭翼，真是脸打得厉害。而且，西方国家长期指责兔子战机抄袭，如今美国六代战机设计反过来用了兔子元素，因动机技术限制采用双发设计，如今技术改善后，双发反而成为优势。他以歼-35为例，其双发设计比美军F-35的单发设计在战场生存率与任务出勤率上更具优势。此外，目前公布的信息显示美军六代战机仍采用无人形式，理论上六代战机应具备切换为无人机的能力，同时搭载忠诚僚机。兔子空军已实现与忠诚僚机的协同作战，美方则尚未公布相关信息。不过目前全面无人化仍存在风险，主力战机无人化还不成熟，曾有伊朗俘美国无人机的例，俄罗斯第五代战机歼-57于乌克兰上使用无人机亦遭遇干扰与击落，成了五代机携带无人僚机出战的首例。但未来的发展方向仍是朝无人化的趋势去的。须具备比五代机更强的全向隐形能力。因此兔子问世的两种六代机都放弃了鸭翼布局，甚至选择了操控难度更大的无尾翼设计，以从基础外形轮廓上尽量减少雷达反射面。美国洛克希马丁公司的六代机概念图也选择了同样的设计思路。而如今公布的概念图采用明显的鸭翼布局，这让大家对美国六代机的含量存疑。六代机的重要发展趋势是取消垂尾，用超音速飞翼来提升隐形性能。波音取消垂尾又加上鸭翼，说明在控制技术上的研究可能不够，侧面也反映了波音在六代战斗机技术上的积累不足。但美国现在急需一个可以悠世界的东西，所以只能赶鸭子上架了。这次让波音六代机也引起了美国舆论的不满，要知道波音现在的经营状况简直是一团糟。民用飞机方面，波音737MAX频繁出整体故障，这对波音有质疑。军用飞机领域，T-7A红鹰教练机、KC-46空中加油机，还有航天领域，波音陷入了不是质量问题就是进度严重滞后、成本超支。NGAD项目超标的主要之一，是用了自适应发动机，想要大幅降低成本，就只能用常规航空发动机，如果放弃先进发动机，性能肯定得打折扣。此外，像六代机这么复杂的项目，对零配件的质量和数量要求都更高，F-35的大部分配件都得海外采购，甚至从兔子进口。现在川普还在贸易战，打兔子的工业实力，再加上稀土和稀有金属这些尖端武器必不可原材料兔子禁售，美国研发六代机的难度完全可以说是地狱模式。现在中美博弈一个显著趋势就是美国高调造势，兔子低调快跑，美国嘴里放炮，兔子埋头磨刀，一个猛说，一个猛的。兔子国家战略不仅是武器性能和军事性能的对比，更是国家治理能力、工业体系效率与战略定力的综合考量。
