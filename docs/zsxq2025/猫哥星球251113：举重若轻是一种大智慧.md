


# 猫哥星球251113: 举重轻是一种智慧

少时读书，常常看到一句话：善者无赫赫之功。当时理解不到这句话的内涵，但是随着年龄的增长，对这句话才有深刻的认识。

今天给大家讲一个历史上可能是最低调的开国皇帝。

这个皇帝就是赵匡胤。

与其它开国皇帝相比，赵匡胤看起来是最平庸的。

生平经历既无赫赫战功，比李世民、元璋等都差了八条街，也无执政非常突出的成就，与文景之治、贞观之治等等相比，赵匡胤也差了八条街。

赵匡胤给历史留下的、也能让大家记住的就是两件事：

黄袍加身与杯酒释兵。

黄袍加身让赵匡胤奠了后周的基业，轻松妥巧当了一个便宜皇帝。

杯酒释兵让赵匡胤结束了五代时期藩镇割据大不掉的现状，这个皇帝做得实至名归。

以后总有人说赵匡胤运气太好，没怎么费力就得到了天下。

但是，真的是运气好吗？

我们对比一下历史：

同样是篡位，赵匡胤的前辈付出的代价是非常高的。

司马懿发动高陵之变后，司马懿已经掌握了魏国的军政大权。但是经历了司马懿、司马师、司马昭、司马炎几代人，反复对朝进行清洗、不断平定叛乱，才最终得皇帝。整个过程耗时数十年，期间爆发过数次战争，死亡极多。

南朝武帝继位，大肆灭杀司马满门。后来齐帝继位，又灭了刘氏族。整个过程血腥残酷，实在是一言难尽。

五代时期，朝代更迭血腥。赵匡胤的老上司郭威，也曾上演黄袍加身的戏码，他付出的代价是：

- 将诸士兵在开城中大掠三日。开城死亡无数，堪称人间地狱。

与上面三个相比，赵匡胤引发的政变，历时极短，而且开城里都没怎么动乱，全程只有一人死亡。

这个靠位的代价，可以说是低到了极点。

那问题来了，为什么赵匡胤的前辈靠位就这么血腥、代价这么大，而赵匡胤则这么轻松就实现了改朝换的目标？

这仅仅是运气吗？

再说杯酒释兵权。

任何人当了皇帝之后，都想着削减武将权力，将兵权归中央，但是想要做到这一点谈何容易？

汉高祖刘邦是怎么做的？

刘邦收权过程就是各地不断叛乱过程，为此刘邦把老命都赔上了，死了之后还是爆发七国之乱。

唐代李渊要收秦兵权，结果爆发了玄武之变，最后连位都丢了。

朱元璋要收将兵权，手段就杀杀杀，把开国元勋杀了干净。

对比一下，赵匡胤收权简直不要太轻松，大佬们围喝一酒，赵匡胤巧妙将兵权归中央了，过程中甚至没有死一个人。

从刘邦到李渊到朱元，哪一个不是人中龙，为什么他们收权这么费劲，而赵匡胤却能干得这么松？

所以，赵匡胤能成为宋朝开国皇帝，这个人绝非看起来那么简单！

之所以从黄袍加身到杯酒释兵权做得这么顺利，就是赵匡胤做事不仅谋定而后动，而且他具备一种举重若轻的大智慧。

对，就是举重若轻！

无论是篡位还是收权，都是重得不得的大事，但是赵匡胤却能干得很轻松。

限于篇幅，我们今天就讲讲杯酒释兵权。

少时读，看到杯酒释兵权的时候，我就在想，这些将领交兵权之后赵匡胤是怎么处理的？总不能自己直接去接收这些兵权吧？那么赵匡胤又怎么防止继任者变成五代时期那些藩镇呢？

赵匡的做法就是两步走：分权制衡与尽收精兵。

我们一个一个来说。

在五代时期，地方节度使是军政一把抓，因为控制了民政，所以藩镇就能给自己的军队提供后勤与军粮，这样的军队就变成节度使的私人军队。

赵匡胤是将节度使的民政权力剥离，中央派出州管理民政，并且定期轮换，同时在各州设立通判，监督节州，形成权力制衡。

然后收取藩镇精兵做得更是高明。

所谓其精兵，就是将各地节度使手上的士兵进行拆分，把其中的精锐收归中央，老弱留在地方，以此削弱节度使的实力。

这个事情看起来很简单，但是真操作起来问题非常多。而且又说会不会遇到反抗，会不会反对地方这些大问题。就说一个最真实的：地方节度使完全可以把手上的精锐藏起来，把老弱送到中央去，你有什么办法？

那赵匡胤是怎么解决这个问题的呢？

很简单，他向各地藩镇下达了一道圣旨：为了提高地方军队的待遇，增强部队战斗力，朝廷决定从地方抽调精兵。
