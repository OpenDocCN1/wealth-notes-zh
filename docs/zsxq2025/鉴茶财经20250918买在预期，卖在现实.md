


# 买预期兑现 美联储昨天如期降息25个基点，符合预期，没有惊喜

今天没懂买预期兑现？很有可能，方法大概是冲回落。降息的受益板块是什么？黄金、有色等，这些资金已经跑了。更直接的受益的是我们一直说的恒生科技。首先是港股是国际市场，美元来的方便，其次是这几年可是跌得更劲的，别说A股了，连港股都流失不少，否则也不会那么多高才计划。那可以修复是先走HK的市场。那今天冲回落呢？在冰点或者老盘时，恒生指数是那些没上车或者错过的同学，又一个错车掉车的机会。但抄的方法建议你哈怂，之前有一篇《倒金字买入法》，可以去学习。你再说A呢，又要走一轮哨路线，总体跟恒生科技走，过两个月后回头，很多人不一定跑得过这个指数。

青春，永不言弃

消费是必然要求的。上午10点，召开高质量完成“十四五”的会议；下午3点，商务部、人行等召开大服务消费的有关会议。经济差，政策越好。昨天弹出的政策直刷屏，高达19条。提及消费，不要上来吃白酒，那是农业社会的思维，谁还缺一口吃饭，工业社会真正的消费是“服务”，比你去足还够。真正的弹性最大的谁？游戏传媒。这个已经位置不了。最现实的是谁？旅游。要去玩，玩要有场景，所以看到的旅游服务（注意不是景区，弹性小），综合服务。预期差最大的呢？券商。最贵收费软件就是同花，“要吐实向”的的就是券商。大盘要突破3000点的20年压力趋势线，事实证明，算力、半导体、新能源都带不动，一次次的搞动，要带量突围，看来还是靠三个板块：券商、机器人、消费。
