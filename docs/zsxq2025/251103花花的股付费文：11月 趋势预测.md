


# 11月预势

作者：陈晓辉 发布于2023-11-15 13:58 阅读

在这个关键时刻，我的文章多说一句，此后可能是我发文和大家最后一次见面了，希望在离开前跟大家说一些心里话：

首先我想告诉大家，我为什么要离开？因为我身体出了一些问题，虽然一直努力治疗，但效果并没有太好转，所以我还是决定离开，也祝大家未来一切顺顺利！

其次我想告诉大家，我为什么要离开？因为我觉得现在的环境真的让我感到太累了，虽然我一直在努力去适应，但结果并没有太好转，所以经过深思熟虑，我还是做出了离开的决定。

最后我想告诉大家，我为什么要离开？因为我现在的状态已经无法再继续写下去创作了，虽然我一直在坚持，但现在我放弃了，大家还能理解吗？

![](img/e3b72edbee40e6b6f29398ac53935d2f_0_0.png)

这也是我不得不离开的原因，因为现在的全球环境真的在变，现在的经济环境真的在变，作为作者的我我真的力不从心，我的分析已经不再准确了。

这也是我不得不离开的原因，因为现在的市场环境真的在变，这让我感到非常痛苦和无奈，经过反复挣扎，最后我还是做出了离开的决定。

![](img/e3b72edbee40e6b6f29398ac53935d2f_0_1.png)

感谢大家一直以来的支持，祝大家未来顺利！
