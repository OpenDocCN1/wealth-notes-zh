人以为吃学习的苦就能改命。

hi,我是陈默。

过年期间听到他们父亲说一件令人生心的事。

小学同学们说，有个邻居逼自己孩子复读，那个孩子已经复读4年，还是没考上大学。的确的是，那个孩子没有考上他心中的大学。

其实那个孩子早就准备放弃，但他硬是逼着他复读，之前两个人都大吵架，孩子直接跑到县城里躲起来来，爸爸找了好几天，就差报警了。

他爸爸认为是，人要是想要改命，必须死磕读书学习这条路。

我小学同学说，这孩子撞上有个父亲，真是八辈子糟了，再这么下去，孩子迟早会坏掉。

在我们老家，这类父母还挺多，他们执着地认为，只要好好书、学好知识，命运因此可以改变。他们不知道，不是所有人天生都是读书的料，一味死命学习，最后可能成了乌龟。

穷人看着孩子拼命学习，好好学校，长大后谋一个稳定工作，一辈子给别人当牛做马，最后越过越穷。

富人的孩子，从小被大人培养培养思维，不执着于考高考，进入社会后，他们的赚钱能力全被激发出来，最后越来越富。

说实话学习的很重要，但并不是改命的关键，所谓的高分和稳定，最后可能在“稳定的规则”里做一个普通人。

那些追求稳定的，最后也都够稳定。

富人想做什么，就立马而去，穷人想做什么，就是不停的在学习。

# 你要先明白赚钱的本质

富人与穷人最大的差别，不是于手的原始资本积累，而是认知差。

学习是为了提升认知和个人能力，但不要本末倒置，毕竟认知才是致富的核心，人永远不到认知以外的钱。小认知赚钱小钱，中认知赚钱中钱，大认知赚钱大。

不要盲目学习，要学以用之，在赚钱的路上，执行远远大于学习本身。

若没有明白这一层逻辑，再去去学钱，才能落入俗套。

钱的本质是什么？通俗讲，就是物有交换，也就是交换。你有什么东西，就从别人那里交换你想要的东西，你有什么，就赚什么，这个东西可以是产品，也可以是思维，也可以是技能，甚至是人脉、资源。

另外我们得清楚一件事，赚钱其实是分层的。

底层赚钱，是付出时间和劳动；中层赚钱，是付出智慧和人脉；高层赚钱，是出权利、荣誉和核心资源。

也就是，不同层次的人赚钱手段是不一样的，用什么去换钱，取决于你所处的赚钱阶级。如何身处底层，却赚到中层甚至高层的，其中很多需要对认知的刷新和人脉、资源的置换。

之所以很多人赚不到钱，就是仅仅留在“学”这一层面，而没有深度地去转换。

学习如果不能转化为知识，并系统地将知识转化为某项技能，打造市场信息差，那么就不可能打通变渠道。

同样是一棵树，有人只把它当垃圾收；有人把树叶做成画纸，在上面刻艺术字、人物画，装上框，一个卖十元、上百元；还有人建立树叶工厂，开网售各类树叶手办，甚至供给艺术展的某些公司、艺术馆。

# 从个人身上找价值

因为价值，就是你个人的商业名片，甚至是你生钱的本钱。

任何事物的存在，都有它的价值，这是广泛意义上的价值。而商业社会里的价值，就是能够变现的东西。客户意愿购买、愿意付费，无论是实体产品还是虚拟产品，能变现的，都有商业价值。

能发现、生产有价值的品，计划很多人都会，难是将它销售给买家。

这就涉及懂人性、懂营销，至少要有很好的服务性，站住用户角度，制造超高的体验。

很多人有特长，但不能变现，是因为没有将特长与价值挂钩。如果你会书法，仅仅是写好的，不能变现就没有价值的。若你能拍短视频，让更多人学习书法，粉丝搞到私域，付费积累，便了你个人的商业价值的。
