


# 单位里，领导眼里的“忠诚”与我们认为的“忠诚”，区别体现在哪些方面

原文：主任 公众：人性的透视 25年9月1日

在单位里，你和领导的关系如何，领导对你如何评价，很多时候直接决定了你能否获得重要机会，能否走向更高平台。

在“能力”和“忠诚”之间，大多数领导都会选择后者，是因为他们认为能力再突出，没有一颗忠诚之心，又有什么意义？

而在领导的评价体系里，最核心的一项品质，就是“忠诚”。

无论什么时候，忠诚都是上位者提拔下属时考虑最重要的一个因素。不够忠诚的，再有本事，也不会被领导当自己人看，更不会心思去培养，从领导视角来看，下属忠诚，比什么能力能力都更重要。

很多人会困惑：明明自己勤恳努力、任劳任怨，自己努力工作，为何领导却视而不见？明明对领导忠心耿耿，为何升迁名单中始终没有自己？这些问题的关键，往往在于很多人对“忠诚”的理解与领导的标准存在偏差。

很多人对忠诚的理解，总是浮在水面上，明明觉得自己一心一意、从无心，简直堪称“忠字当头”，可领导似乎总不放心，既不交重任，也不予信任。

## 问出在哪里？

其实在于：你所以为的“忠诚”，和领导所理解的“忠诚”，根本不是同一回事。

还有很多人把忠诚理解为“听话”。

错了。

忠诚是“磁场共振”，是你和领导之间无形的能量场。

领导也是人，也需要安全感。在单位里，能力可以培养，但信任无法勉强。

领导评价体系中的“忠诚”，绝非简单的“听话”或表忠心，而是一套复杂的能力与品格的综合评估。

你以为的“倾心掏肺”，在领导眼中可能只是“隔靴之阵”。

由于这个题目本身带有一定的隐性和敏感性，不便全部公开讨论，所有感兴趣的朋友可以继续阅读。（全共4200余字）。

那么，领导眼中的“忠诚”，究竟体现在哪些方面？

我把它总结为以下几点：

### 第一点：透明度

领导提拔下属前，会考察下属的忠诚。套路很多，比如已知的事情试探，看你是否说实话；或者找个人试探一下你……

忠诚第一个核心的要点就是信任，而信任的核心就是要不欺骗。因为人心隔肚皮，如何做到不欺骗，就是必须保持透明度。

很多领导都是怀疑念型的人，他只有通过一段时间对你的观察和考核，才能逐渐对你放心。他通常会用一件小事来试探你，看你在做这件事的过程中有没有隐藏什么？有些事不告诉他？你的能力怎么样？大佬集团一看你这人不藏着着急，对他足够忠诚，他了解了你，他自然就会增加信任。

### 第二点：可控度

权力最终是要寻求安全感的，这个安全感就是所有的都在自己的控制范围内。所以很多时候，投名状、交把柄、示弱、示错、装傻等手段，目的都是让领导有控制权。

之前在文章中写过，在单位里，听话，超越了50%的概率会被领导重用。

听话+有能力，已经超越了70%的概率会被领导重用。

听话+有能力+有关系，100%会被领导重用，而且委以重任。

听话+有能力+有关系有背景，你就是领导。

你能够做点事，领导用着省心，最好是缺了都不行。但是这不是决定因素，天赋并没有大家想象的那种。就像某位大佬说的，抓住了风口，猪都能飞起来，所以领导不需要你能力有多么强，忠心耿耿，不背叛，不做听话乌，我赢得过你，知道你一直站在这边，这才是最重要的。

有的人能力非常强，但是就是时候优秀，太服从领导管，领导往往对这类人利用，不重用。

很多被提拔的人坚决服从领导指挥，紧紧地从一把手角度考虑事情，时刻时刻跟在领导身边的人，贡献的就是忠诚价值。对于领导来说，这种忠诚价值很好用，毕竟你一个人再有能力，倘若不听招呼、不守规矩，还不如一个听话的普通人。

### 第三点：不能真正为领导分忧、解决问题？

忠诚，首先是一种价值能力，而不只是一种态度倾向。

从职场动机来看，单位里所有有进心的人，都可能为了获得提拔晋升，选择暂时委屈自己，甚至背弃个人意愿，伪装“忠诚”的姿态。

在这种情况下，领导若要从众人“潜在忠诚者”中选出真正值得信任的人，会优先选择那些具备解决问题能力的下属。

即使有人内心足够“忠诚”，但如果缺乏实际能力，无法为领导解决难题，对领导而言，其价值也十分有限。

就像我们评估一个人的综合能力时，除非忠诚度达到超过人的程度，否则领导将会考虑能力、价值方面，再决定给予机会。哪怕你心里再“忠”，但如果能力跟不上、办事不安，领导也很难视你可靠。忠诚，如果不能落到“办事”上，对领导来说就缺乏分量。领导视角的忠诚，本质是价值供给。

### 第四点：口风紧、做事密？

《周易》中：“君不密则失，臣不密则亡。”在单位里，有些话最好烂在肚子里。

领导接触的时候，有一次让我印象深刻，领导交代这些事最好带上。那时我年龄小，听了这句话后毛骨悚然。这件事如果领导单独交给你，肯定是把你当自己人。领导之所以找你，是因为觉得你值得信任、办事稳妥。领导交给你一些私人事务，你偶然透露了一些信息，又是偶然看到、听到关于领导的事，结果你恨不得让人都知道。真正用心的人，永远是那些管住嘴、办事密的人。

### 第五点：立场清晰、脚踏实？

你是谁的人？你跟谁站一边？这是领导内心非常在意的一线。

我们说三国中吕布能力强，曹操和刘备都不用他，看着你不放心，你今天杀丁，明天杀董卓。有些人喜欢表忠心，说我是你的人，你指哪里打哪里。高明的领导不会相信你，如果觉得你背景复杂、多方模糊，甚至走得近，那么你能力再强、说话好听，他也不敢重用。这一点是领导极为看重的原则。简单来说，领导会明确判断：你到底属于谁。只有当领导认定“是我的人”，才会放心将重要事务交给你，才会分享密信息。反之，若你转头就把这些事告诉其他，即便你是无心之举，懂的人可能会过度解读，万一你利用这些信息，后果不堪设想。

### 第六点：站在领导的立场想问题、办事

忠诚是有排他性的，它不是一种可以多方讨好的策略，而是一种清晰的身份认同。很多时候领导不便直接表意图，甚至不便亲力亲为。这时就需要有人理解他的处境并主动站出来推动事态发展。有时领导想向某个方向推进工作，却因种种原因不便直接表态。这时，你能够站在领导的角度，敏锐察觉到他的真实想法，并全力推动落地。这也是领导衡量“忠诚”的重要维度。你能不能察言观色，能不能领导之所想、领导之急，甚至提前布局、代为执行，这也是忠诚的一种高级体现。

### 第七点：关键时刻靠得住？是否递交过“投名状”？

你说你忠诚，凭什么能证明？是春风得意时的锦上添花，还是逆境低谷时不离不弃？

当领导面临压力，需要支持时，你是否愿意站出来——哪怕这滋味是承担风险、面对争议；当需要有人扛责、受屈的时候，你是否愿意主动分忧？

从领导视角来看，我说一就是一，我说二就是二，我的话够坚决执行，这才是最重要的。我承认你能力很强，但是你不听话，总是跟着，我是不会用你的。领导不会吃饱了撑着用自己造人的，我需要的是走到哪里你就哪里，我指到哪里你就到哪里。比如我出了一个新制度，连我自己都认为很扯，但是还得执行，一推行坏了，反对的反对，挑子的挑子的，都闹情绪不活，领导的处境尴尬，这时靠谱靠自己人，不管别人说什么，不管这个制度本身有多胡扯，领导说干，那我立马带头就去；领导手一指拿下这个山头，我立马带人就冲上去，只要有人干就没人闹事。当领导与其他同事或上级在立场产生分歧时，你是否毫不犹豫地站出来支持领导？

### 第八点：在他面前不要小聪明

每个人都有私心，这是人性常情。但如果想与领导建立深度信任，“诚”是最稳妥的方式。在职场中，有些人自以为聪明，喜欢投机取巧，这种行为往往被眼睛识破。真正的高位的人，诚诚恳，智慧远胜于圆滑。
