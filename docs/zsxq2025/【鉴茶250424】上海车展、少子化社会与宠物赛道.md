# 少子化社会与宠物赛道

据说，魔都的出生率已经低于韩国了。
孩子少少了，人的情感需求不会变，宠物就会取代缺口，从罗马到日本都验证过的事。

国内现在宠物情况怎么样呢，有些同学可能不了解了。2024年，“在编”宠物就有1.23只，超过日本的人数，同时还有总约4000万流浪的狗。

宠物的意思，就是不能让委屈。宠物的寿命通常10年以上，很多人家里的狗正值壮年，新生也没有计划生育，不用买房卖壶，其实最好的狗，还是华田园犬，老祖宗严选，身体好，适应强，不掉毛，体味轻，智商高，还护主，生病了会自己去找中药。

华田园犬里有两种神奇的狗：
一个叫五黑，全身黑色，据说有辟邪之功效，古人睡觉不好怕家宅不宁，会养五黑。五黑又叫唐狗。

一种叫五红，全身都是红色，玄学意义打满，五红才是旺财原型。
