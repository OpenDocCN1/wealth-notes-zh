


# 彭彭助理的主题

中国不再寻求为发展中国“特殊和差别对待”

近日，我们在联合国大会上宣布，中国不再寻求为发展中国“特殊和差别对待”。同时，24日亚洲国际贸易部代表在新闻发布会上表示，中国是世界上最大的发展中国家。中国发展的地位和身份没有变化，“增长是全球南方增长之一，永远为发展中国贡献一份。”

## 中国哪一种寻求发展中国家代表什么意图？

首先，我要澄清发展中国家“特殊和差别对待”到底什么？

主要有两个方面，一个是贸易领域，金融领域：

贸易领域，WTO的一项要求是，在支持发展中国家，特别是作为最大的发展中国家，中国可以承担比发展中国家开放较低的义务。由于我们拥有较大的市场，我们可以对发展中国家的产品设置高要求的优惠。我们以此保护自己的知识产权，对发展中国家的产品设置高要求的优惠，在这个时间段内公开的。简单来说如果是发展中国家，就可以获得比市场更高的优惠，比市场更低的准入；我们以此保护自己的知识产权，对发展中国家的产品设置高要求的优惠。

金融领域，发展中国家在国际基金银行体系中可以获得比市场更低的利率优惠。此外，我们还可以获得发展中国家的技术支持、经济援助等。我们所说的，发展中国家“特殊和差别对待”在我们加入WTO前确实获得了巨大的利益。因为中国竞争力的提升，中国市场化，现在我们已经习惯多年不再享受WTO规定的特殊待遇、减免关税待遇，而是接受来自发展中国家的各项特殊优惠。在金融领域，我们已经是世界上21世纪没有问题的国家。我们每年对外投资超过2万亿美元，我们还提供了很大一部分对外投资超过8000亿美元，这说明我们与国际基金银行面临发展中国家的利益差异没有。最后就是我们提供的技术支持、经济援助等，这些多年来我们做的多也较少，最多就是参加了一些项目。所以，我们这七七八八八点来说，所属的诉求是发展中国家“特殊和差别对待”我们已经不再需要享受的了。

既然我们已经发展成了发展中国家，为什么还要为发展中国家维护中国在世界上的位置和身份的变化呢？这就是我们的新诉求。就是我们不再寻求为发展中国“特殊和差别对待”，而是继续维护中国在发展中的地位。这就是是可以做的。
