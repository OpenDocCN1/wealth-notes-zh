


# 什么是知识（来自自己）

人类的认知是什么？

我认为的。
认知、解释、建模，本质上是感知的改进。认知、解释、建模是为了改进环境，认知、解释、建模的终极目的是生存。感知的改进，是为了安全感，舒适才是最终目的。为了更进一步的生存，我们是对环境的重构，想要健康的身体，想要更好的生活，这一种认知就是为了生存而产生的过程。

那么，你认为知识的本质是什么呢？

我认为知识包含三部分：第一是工具，第二是方法，第三是目标。三者之间是统一的，因为没有工具，方法就没有意义；没有目标，方法就失去了方向。而工具、方法和目标在人类的发展进程中不断演进，创造了人类的一切可能。

我认为人类的认知是与世界的互动，这也是人类的“本质”。

或许如此，但如果有人个人不以这种方式来理解世界呢？
