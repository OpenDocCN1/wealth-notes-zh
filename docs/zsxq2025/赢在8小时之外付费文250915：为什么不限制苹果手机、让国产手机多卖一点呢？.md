


# 为什么限制苹果手机、让国产手机多卖一点呢？

原创：U 君 公众号：赢在8小时之外 25年9月15日

1. 上次我在《如果房价完全开放会怎么样》这篇文章里说说了一个观点：就应该鼓励钱人多花钱、花乱钱，买那种贵又不实用的奢侈品，这样才能活下去上游的经济。

然后有人在评论说：不应该鼓励钱人购买奢侈品，因为利润大头都被国外的那些奢侈品牌赚走了。

2. 大概在20年前的时候，我还在上初中，那时候市面上有一种言论甚靡流俗：麦当劳和肯德基用的都是激素大大的鸡，大家千万不要去吃这些洋垃圾，更不要让自己的孩子去吃！

3. 上周，苹果发布了 iPhone 17，网上吵得沸扬，不出意料，这次又有很多网友呼吁“不买苹果、支持国产手机”这种言论。

还有一些极端的网友说：你买一部iPhone，就多了一颗射向你的子弹！

4. 还有人信奉这套理论：美国太坏了，总是卡我们手机的脖子，各种制裁，就是为了限制我们科技的发展！作为反制措施，我们也应该制裁他们，限制苹果在我们在这里销售。

上面这几类说辞，从表面上看好像有点道理，但问题是：

国家为什么禁止国外那些奢侈品品牌在我们在这里进行销售？难道国家不怕资产外流吗？

国家为什么禁止洋快餐在我们在这里开分店？难道国家不在乎青少年的身体健康吗？

国家为什么不限制苹果手机、让国产手机多卖一点呢？难道国家不想振兴民族企业吗？

我总结，国家之所以这样做，主要有6个方面的考量，下面我就给大家进行详细的剖析。

## 1. 全球一体化的趋势不可逆

2001年，我们加入了国际世贸组织 WTO，从此就成为全球经济链中的一环，跟外的贸易往来非常频繁。

由于我们的人力成本极低，所以生产出来的衣服、鞋靴、玩具、手机、汽车座椅垫等各种商品，价格非常低，能够销往上百个国家。

这就创造了大量的就业岗位，也赚了大量外汇。

从此以后，几乎人都都可以吃饱饭了。

如果不加入 WTO，可能还有三分之一吃不饱饭，一点都不夸张。

另外，随着全球一体化的推进，欧美、日韩等很多国家都来这里建立电子工厂（也是看中了我们的廉价劳动力）。

这些电子工厂主要生产电容、芯片、组装手机、电脑、空调等家电；还有一些汽车公司在我们这里组装汽车。

毫不夸张地说，这些电子厂/汽车厂在最近20年里，累计至少解决了10亿就业岗位（包括下游的各种产业，比如住宿、餐饮、交通等等）。

所以，让他们在我们这里建厂，绝对是双赢的局面。

当然，额外的条件/福利就是我们能买到物美价廉的进口/合资产品，比如丰田汽车、佳能苹果手机、耐克运动鞋、可口可乐饮料……

总之，全世界的老外对我们的印象就是：一个开放的、繁荣的、有合作精神的经济体。

这时候，如果我们突然发出这样的信号：禁止洋快餐在我们这里开店，抵制日本汽车和相机，限制苹果手机在我们这里销售……

那么，我们的国际形象会一落千丈，那些电子厂、汽车厂也会被哀闭，然后会有大量年轻人失业。

有人会说：我们有自己的民族品牌，无论是汉堡、汽车、手机还是相机，完全可以自给自足了。

我说并不能。

就拿汽车来说例子，底层的很多老百姓在买车时，主要考虑的是便宜、结实、耐用、省油、保值。

这时候，选择其实很少，就是丰田、本田、现代、起亚这几个品牌。

不光我们这里的老百姓选择这些品牌，就连美国、欧洲和澳洲的底层老百姓也会选择这4个品牌。

而顶层的有钱人呢，他们买车时，主要考虑的是性能、豪华品牌。这时，选择很少：跑车就是保时捷、法拉利、兰基尼；轿车就是宾利、劳斯莱斯；家用就是丰田埃尔法和别克GL8。

## 2. 富人的选择

上面说了，富人在买车时，肯定首选进口豪华品牌，这对于他们来说是刚需。

其实不光是汽车，衣食行的很多方面，有钱人只会选择进口品牌。

比如，富人小区、豪华商场的电梯，大概是美国的OTIS、日本的三菱/日立，欧洲的KONE/Schindler。

> 国产电梯的水平，跟家里至少有100 年的差距。

比如，富人家里/豪华里的里的马桶，要么是美标/科勒，要么是日本的TOTO。

空调、冰箱、电视、电脑这些家电也是如此，几乎100%都是进口品牌。

再比如，女人喜欢买的衣服/包包/化妆品，稍微高一点的商场，里面几乎看不到国产品牌。就拿运动品牌来说，有美国的Nike、Under Armour、New Balance、Columbia，德国的PUMA、Adidas，日本的亚瑟士、美津士。

休闲、时装、奢侈品的衣服也是一样，几乎看不到国产的身影。

而包包、化妆品、护肤品牌，稍微贵一点的都被意大利法国承包了，稍微便宜一点的被美国承包了。另外，我说的这些品牌，真正走进千家万户可能就是最近十年来实现的。

但是，你知道这些品牌是在什么时候进入富人家庭的吗？大佬集团圈是在上世纪的八十年代，那个时候他们就已经开始使用国际品牌了。

那个时候，他们会拿出“相当于普通人100个月工资”的钱去购买日本索尼电视。

到了2025年的今天，他们依然会拿出“相当于普通人100个月工资”的钱去购买进口电视。不过，价格在100万人民币以上的电视不止索尼了，还有三星，而且三星的电视品质已经超越了日本品牌。

总之，有钱人对国际品牌的依赖和信任度，远超普通人。而制定政策的那批人都是钱人，你觉得他们会把自己喜欢的商品给禁掉吗？而苹果的Pro系列机型，起步1万元起，也是有钱人的选择，所以不可能禁止。

说一个很多人不知道的常识：很多商场在引流时，对待耐克、阿迪、星巴克这样的“洋品牌”，是免租金的不仅如此，有的商场还会额外掏钱给品牌提供装修费。那些商场通过各种手段刁难、勒索品牌，也不会去惹品牌。为什么会这样？因为这些洋品牌是商场的引流，很多顾客之所以光顾商场，因为它有耐克、阿迪、星巴克这些国际品牌。如果没有的话，大家就不会去商场了。

## 3. 无法禁止

如果你想禁止快餐在我们这里开店，要找出违法的证据，比如添加剂超标、用工违法。但讽刺的是，餐饮街上添加剂最少的可能是这些快餐，最好的干净。所以，凭什么禁止？同理，如果你想抵制日本车、苹果手机，也要找出违法的证据。当然，你可以一刀切他们在这里销售，但是如果真的退出市场，到时候后果不可量。那么问题来了，国家为什么敢直接禁止某个品牌呢？原因有两个：

- 品牌本来就是一个流氓，在内割自己，在外坑别人，获取先进的技术。
- 生态本来处于上层，核心的技术、人才、贸易壁垒握在手里，想卡脖子就卡谁。

换句话说，制裁其他品牌，不会出现“自损八百”，如果一个发展，可能会出现“自损严重”。

## 4. 税收的需要

无论LV、GUCCI这样的奢侈品，还是iPhone这样的电子产品，每年贡献的税收非常高。举个例子，如果你买一个售价万元的包，里面可能有乱七糟的税，用来支付员工工资、租金、物流、营销费用。商场为了这些税，自己赚走了。所以，富人购买奢侈品，对刺激经济、解决就业只有好处没有坏处。苹果每年在这里销售手机、电脑、手表，纳税额也非常高。最重要的，苹果公司把一部分生产线放在这边，解决了大量的就业问题。

## 5. 给国产品牌榜样

网友说：如果可口乐退出市场，那么国产饮料就能卖到钱一瓶。其实，这种言论一点都不夸张，并不是国产饮料不良，而是因为技术落后、控制成本太低。无论可口乐还是百事可乐，口感都是一流的，被全球消费者认可。最重要的，它把成本控制得很低，大多数劳动者买得起，花几钱就能喝到。我觉得国产货之所以厉害，就是因为它“不分阶层”。比如，无论大学生、上班族、创业者还是总监，他们都会穿着同一款耐克鞋、同一款苹果。

## 6. 国行的手机是阉割版

虽然允许苹果在这里销售，但是其实也割了很多功能。比如：eSIM卡、5G毫米波、卫星通信、人工智能、信号频段、Apple TV、Apple Maps……所以，很多人说苹果信号差，并不是人家技术落后，而是国行版很多功能都割了，才导致信号差。类似的，很多国外品牌的汽车、电视、游戏机一旦引入国内，就会砍掉很多功能。为什么要这么操作？主要有两个：

- 怕你使用卫星通信、人工智能、5G毫米波等功能去做坏事。
- 怕你了解到了外面的信息，就不好管理了。
