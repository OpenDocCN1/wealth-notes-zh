


# 美国会不会下场

嘉宾：梦回安西

以色列和伊朗开战后，26架美军空中加油机发现紧急飞往中东，“尼米兹”号航母战斗群，也取消了对越南的访问行程，驶向中东。

那么，美国会不会下场？

其实，美国“重返亚洲”的战略，和以色列希望美国“重返中东”的心思是矛盾的。

和伊朗开战，只会让美国再次陷入中东无法自拔。

这一点不仅特朗普，连奥巴马、拜登都看得清楚。

2015年时，奥巴马和伊朗签署协议，就是希望给伊朗几颗糖让他们别闹了。不过，今时不同往日，2025年的伊朗显然比2015年要虚弱。

在以色列的打击中，革命卫队高层还损失惨重，指挥系统混乱，加上大量内鬼的配合，伊朗有崩溃的迹象，让美国下场可能性大增。

这里说的“下场”，指的是美军撸袖子上阵，而不是仅仅提供情报协助和后勤支援。从特朗普的本心看来，他确实不想下场。

但如果出现以下两种情况，就难受了：

一种是发生不利美国的突发事件，比如美军的军机遭到“误击”，或者美军基地被炸，出现不小的伤亡，无论真相如何，究竟是不是伊朗干的，都不重要。

重要的是，会给予美国主战派们一个借口，进而群情激奋，要求对伊朗开战，就像伊拉克战争前那样。到时候，特朗普将面临巨大的压力。

如果他同意，那就顺了以色列的意，“重返亚太”变成“重返中东”（当然，下场大概率只是派海军和空军，地面部队轻易不会派）。

如果不同意，可能会严重折伤自己的威信，毕竟特朗普上台几个月，内部搞出一堆趣事，共和建制派，可一直悬着坏兜，就等一个机会；

二是伊朗的表现继续下滑。

伊朗损失很大，除了内鬼，主要是判断失误导致的，袭击发生当天，许多革命卫队高层都没有疏散，大摆摆在家里睡觉，或者在指挥中心缺岗。

伊朗高层还觉得这是“狼来了”。完全没想到，这次，特朗普难得真诚。

经过损失惨重的一夜后，伊朗对革命卫队高层进行了重组，任命了新的指挥人员，接下来几天，不仅成功组织起了反击，还打得有声有色。

防空系统也重新开火，各种警察、民兵进行了一度的动员，总的来说，表现勉强且合格。但伊朗是一个抽象的国家，谁也不知道能支撑几天，后面又瘪了。

如果后面瘪了，甚至拿出比6月13日更差的表现，那特朗普下场的概率就大了。毕竟特朗普向来是欺软怕硬，当伊朗看起来像个破耗子，他不会介意再抡一脚。

想要避免美国下场，伊朗必须坚决反击。

客观地说，伊朗这几天的导弹击打，对以色列造成了一定的损失，主要如下：

- 1、海法炼油厂和配套的发电厂。海法炼油厂是以色列最大的成品油来源，供应了国内一半以上的成品油（剩余一半来自阿什杜德炼油厂），伊朗对该炼油厂进行了高强度打击。

可以确认，炼油厂的储油罐、蒸汽设施和配套电厂均遭到严重破坏，还有三名员工死亡。炼油厂所属的巴赞集团已经宣布，所有设施关闭，停产10天。

如果伊朗能加大打击力度，让炼油厂彻底被摧毁，以色列就要很难了：

- 2、特拉维夫都会区。这是以色列的经济中心和CBD，不下30发伊朗导弹先后命中，损毁了100-200栋建筑，其中一栋公寓内，就有35人死亡。

导弹还击中了富人区和国防部大楼，摧毁了几栋富人区的别墅，国防部大楼的损毁程度不明（以色列官方让报道，不过战时大概不让报道，由于严格的媒体管制，许多损失既披露也不报）。

- 3、茨曼研究所。这个研究所和IDF关系密切，负责前沿军事技术，伊朗导弹中了实验室，造成150多人死伤。许多分析人士认为，对茨曼研究所的打击，是伊朗取得最有价值的战果。

- 4、辛贝特的后勤中心。6月17日的导弹击打，伊朗重点关注摩萨德大楼，一共有四枚导弹成功突袭，但可能是被干扰了GPS，四枚导弹都没有命中大楼，而是砸到了附近的建筑。其中一座建筑是以色列安全总局（辛贝特）的后勤中心所在，也算不小的收获。另一枚导弹击中了820部队的总部，这是以色列的网络部队，伤亡不明。

总来说，伊朗的反击取得了一定的成效，以色列的防空导弹明显跟不上了，弹药不足，拦截率不断下降，局势已出现了翻转的迹象。

还是那个问题，伊朗到底有多大的决心，以以色列一次沉重打击？反击会进行多久？这些，都不确定。因为反击的同时，伊朗外交部门还在说着各种软话，还在幻想着谈判。
