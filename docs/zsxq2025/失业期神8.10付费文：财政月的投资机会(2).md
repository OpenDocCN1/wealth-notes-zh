


# 财月的投资机会

原文：失业期神 公众账号：失业期神 25年8月10日

前言

![](img/0a68599adf1932e418dd8d8d343201ee_0_0.png)

期股双修，胜天半子

在反内卷的行政命令下，上游商品远期飙升，从长期来看价格的维系还是会依赖服务端与企业端的有效需求，但是根据最近的几则大新闻，我认为短期在政府端的购买力下，是存在博弈机会。

传统9-10月是博弈财政政策的时间点，我从2023开始一直排除了财月以外的小周期，因为从上来说，除了财月，别的时间段博弈策略的确定性太低了，这次财月叠加了十五五五计划，按照惯例我也会深度参与，所以分出了部分资金去做多收益。

23年1月底财政宣布把赤字从3.0%加到3.8%，拉爆了大宗商品；24年9月底的货币加码，爆发了924疯狂牛行情，那年的财月投资机会在哪里呢？

我希望用长期与短期两个维度去看投资机会。

短期：

首财政政策目前的方向无非就是新能源旧换新与大基建，23是大基建，24年是以旧换新，25年我认为大概会回到基建，证据如如下：

7月1日，中央财经委第六次会议强调，深推进全国统一大市场建设，聚焦重点难，依法依治理企业低价无竞争，引导企业提升产品品质推动落后产能有序退出。

7月18日，工信部在国新新闻发布会上宣布将实施钢铁、有色金属、石化、建材等十大重点行业稳增长工作方案，核心目标是结构、优化供给、淘汰落后产能。

7月19日，国务院总理李强在西藏芝市宣布1.2亿规模的雅鲁藏江下游水电工程正式开工。

8月8日，交通运输部、财政部、自然资源部联合印《新一轮农村公路提升行动方案》（简称《方案》），明确到2027年全国完成新改农村公路30万公里，基本建成便捷高效、普惠公平的农村公路网络。

8月8日，国家铁路集团950亿成立西藏铁路公司，新藏铁路贯通新疆自治区与西藏自治区。

结合今年西藏自治区成立60周年，新疆自治区成立70周年，我认为今年的财政大概率聚焦于西部省市的基建，通过反内卷与基建项目，给上游商品创造短暂的政府需求，从而稳住 PPI 和 CPI，给市场强行注入通胀预期。

我个人对于阶段重建基建项目的未来盈利不作期待，而且我认为即使可以盈利，周期也太长了，很明显这是无奈之举，以旧换新国带带来了太多套利资金了，最后发现除了金价，别的商品价格依旧萎靡，还创下了新低，而基建的作用显得更为直接，可以短暂通过大量政府支出以代账解决物价与失业问题。大佬们既然财政的证据指向了基建，那我在这两个月的时间窗口里，做多权益的方向自然就是西部各省的基建类了。

为什么不是商品而是股票？我的答案是经历过去年924，我发现政策的有效性没有那么重要，重要的是产生的预期本身，在整个基本面与价格逻辑没有反转之前，强政策带来的强预期与弱现实是常态，而且西部各省的基建类股票偏中市值，如果政策方向判断正确，短期情绪的冲击能带来较大的额外收益。

长期：

我非常笃定，这次可能出现的大基建，只是缩大周期里的一个创造价格波动的小周期罢了，政府创造的需求从来不是改变周期的节点，这个节点必须居民端与企业端决定的，这个观点在日本验证了，如果政府需求能产生逆转性的意义，日本不需要失去三十年。

我们更大的逆转难题在于儒家思想下保守的国民性格，欧美相对容易走出通缩，因为给他们发钱他们用，月光是常态，家庭观念也没有那么厚（黑老人哥妻子弃子也非常常见）。

但是放在亚洲特别是中国，家庭观念告诉我们无法避免地进入预防性储蓄的通道。当通缩深浅地钉入中国百姓这个天生自我保护严重且小农思想惯性的民族，无论什么政策效果都是无力的。

所以如果我们从长期的视角来看待品种的，债券黄金依然是逻辑通顺的品种，但这两者在这一轮可能出现的基建小周期里，表达方式是不同的：

1、黄金在财政政策下反而是利好的，因为基建项目产生大量的政府支出，在看不到具体回报之前，所带来的赤字率提高的可能性是不可忽视的，而赤字率在新生生产力的促进下是有利于汇升值的，因为给资金创造了未来 GDP 高增长的预期，但是赤字率如果放在传统基建项目上的话，会导致人民币的贬值压力。沪金受益于这种币值压力。在此这个定价因素里，追求短期收益的强财政，对黄金并没有冲击，反而是利好。

2、债券在基建强势财政下，必然是直接的受者。财政政策挤通货，必然是直接的受者。

以上内容仅为个人观点，投资需谨慎，好运！
