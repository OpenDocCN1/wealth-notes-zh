


# 命运还是选择

前言

不管多么强大，他最终都会收获遗憾，有些东西却从未自己努力，最终还是不能拥有。

比方说他经历过的起伏，他精通此、神机妙算，算出来也不怕变了卦，但是比失败更要面对的，还是一个人的失败。在要去的时候，在三阎王的审判之口告诉他：“我们不能再后悔了，我终会告诉你，希望你不要再后悔吧。”你认为你的错，对我来说，让我错过了最后一次机会，大我都会忍不住想流泪。

他是一个非常普通的人，一个人的话是有点偏差的。我的例子就是：在生命的选择中，个人无法抓住命运的轮回。

关于命运论，命是生的，福在天，贵在人。

比方说一个人好就是福，一个人不坏就是命，这事儿就是天给的与不给的，是命运的事了。

什么时候叫命运？天来有分，天来有留。很多人认为命运是注定的和安命的。其实认为命运是自己的，只要努力就能改变命。从我以前的顺遂，走过去日子，终还是会得到圆满。

自由选择论和阶层论决定了命运。我认为命运是自己的，我所经历的都是自己的努力可以改变的。选择命运，努力可以改变命运，知识和高考，其实不是选择的。

自由选择论和阶层论决定了人生的走向。这两种理论其实是同一种理论，只不过我们站在其中一种里看，一种对另一种看。我纠结了在选择论和自由选择论之间互不相同，其实是矛盾的。

为什么叫命运？父母的出生决定了你的出生，其实是你无法选择自己的出生，出生家庭条件、父母的基因等等无法改变的，这就是命运的。

为什么叫选择？是人生的苦难的折磨，终会有注定的。时间和运气比较好的人，有运气的人，运气的人，每个人都有自己的运气，这运气你看不懂，但它存在却不能放弃。并不是说不能放弃，从努力成功的人来说，在我看来先来的命运，后来的选择，命运在天，运在人。

本文回答有三个问题：
1. 我们应该怎么看待命运的？
2. 究竟怎么改变自己的命运的？
3. 要不要去改变命运？

想看命运？
得不到不是合理的安排

年轻的时期你没有太多的遗憾，因为你才二十岁以前，有很多都是过的，但是40岁、50岁以后，你越来体会这个个的。延续说开头提到的那个例子，就是比方说我经历过的失败，这样一个的人，在要去的时候，他不会不遗憾。我们这些普通的人，在选择自己的的过程中会遇到困难，比如工作、失业了，投资也失败了，为了我们就没有办法呢？

# 命是定，运是变

运气：其实很多小说里都有这种说法，就是运气比作一样，比如天龙八部里的虎彻，运气越好，总能遇到机遇，还有各种机会、各种贵人，富贵果然是注定的吧？其实在现实世界中这种运气是存在的，我真的看小说也不错了。

其实运气就是概率学，比如打牌游戏，牌局一开了，运气就来了，把牌拿起来，这十把都都能赢，运气好，你可能就赢了很多钱。其实在80人里只有20人玩这种概率游戏，左手右手，你就能赢了。最后，总会有人赢你，我们不能保证你赢，你不能靠运气，你的运气也不够赢胜几百把，不是靠努力，而是靠了一个级别的。这种东西，他就已经被很多认识的人认为他成功了，因为他有太多的资源天生就比别人，甚至更高的人，因为他的基因没有失败了，或者他付出了努力，所以成就了自己，而他也恰恰能够被这样记住，他会在赏赐中遇到有帮助他的人，他自己如果运气不好或许无法成功，可能就是命所注定。
