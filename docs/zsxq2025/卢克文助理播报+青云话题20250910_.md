


# 【助理播报】

国际：

1.美国合众国际社8日报道，美财部当天宣布制裁东亚诈骗集团。美政府统计显示，美国民众去年遭遇电骗，损失超过100亿亿美元。

2. 卡尔多哈9日连续发生多起爆炸。以色列方面承认在多哈发动攻击，据称目标是当地的哈马斯高层。哈马斯证实五名成员在军方空袭中死亡，但哈利勒·哈亚本人未被暗杀。

3. 当地时间9月9日，德国军火制造商业金属公司宣布将向乌克兰提供该公司制造的“天空游兵”反无人机系统，据称这套武器系统可以安装在车辆上，防空范围可达16平方公里。

4. 当地时间9日，加沙地带媒体办公室发表声明，面对可能造成永久性强迫流离失所的计划，仍有超过120万巴勒斯坦人坚守在加沙城及其北部地区，拒绝强制向南迁移。

5. 埃及石油和矿产资源部8日宣布，埃及和天然气控股公司与英国石油公司当天签署了一份谅解备忘录，计划在地海钻探五口新的天然气井。

6. 9月9日，德国汽车制造商大众汽车表示，公司将在2030年前向人工智能（AI）领域投入高达10亿欧元约约合12亿美元的资金，并将这项技术全面融入业务各个环节，以期撬动数十亿欧元的成本节约。

国内：

7. 工信部消息，我国新能源汽车去年产量突破1300万辆，产销量连续10年保持全球第一。

8. 近日，中国移动正在申请卫星移动业务经营许可，为依法合规开展手机直连卫星业务定政策基础，目前该申请已进入审核流程。
