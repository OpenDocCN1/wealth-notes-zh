


# 储入的趋势

2023/01/25

彭联储2023：美国经济预测

## 华美贸易关系将何发展？

90年代以来，中美关系经历了前所未有的增长。2000年代，两国关系进入了另一个前所未有的十年。然而，过去十年里中美关系经历了一系列严峻考验（下文将介绍）。2022年两国关系继续面临挑战，如果2022年是这样，那么2023年美国经济形势如何？

## 寻找“新平衡”

2000年后，中美关系进入了全球关键期。全球化背景下，两国在各个领域合作达到了前所未有的深度。2001年中国加入世贸后，中美贸易额呈爆发式增长。

2008年金融危机爆发后，全球化进程放缓，两国关系也开始发生变化。中美贸易增速开始放缓，同时两国在科技等领域的竞争也开始加剧。

2018年，中美关系出现剧变。美国政府开始对华加征关税，并试图通过贸易战限制中国的崛起。2020年以来，中美关系进入了更加紧张的时期。

2022年，两国关系继续面临挑战。如果2022年是这样，那么2023年美国经济形势如何？

## 通胀与加息

2021年，美国通胀率达到了历史高位。全球范围内，通胀问题也变得严峻。2022年初，美联储开始连续激进加息，以遏制通胀。

加息可能导致美国经济衰退。那么2022年美国经济是否会衰退？

目前，市场普遍预期2022年美国经济将出现衰退。但衰退的程度如何？美国是否能实现“软着陆”？

如果通胀能够得到控制，美联储可能会停止加息，美国经济可能实现软着陆。如果通胀持续高位，美国经济可能会面临严重的衰退。

## 地缘政治与风险

2022年俄乌冲突的爆发，加剧了全球地缘政治局势的紧张。这进一步推高了能源和食品价格，加剧了通胀。

作为西方国家，美国在俄乌冲突中扮演了重要角色。2022年，美国对俄罗斯实施了极其严厉的制裁。这影响了全球能源市场。

与此同时，中美关系也面临严峻考验。在俄乌问题上，两国持有不同的立场。

这种立场的差异进一步加剧了中美关系的复杂性。

这使得中美关系的未来也充满了不确定性。

中美关系未来如何发展？

## 从历史、从现在的角度来看美国面临的危机

在法国，面对重重困难，从历史和现在的角度来看美国面临的危机。自美国成立以来，面临过严重的危机吗？也许危机是没有持续的，但从历史的角度来看，美国是如何解决这些危机的？

从历史的角度来看，危机是存在的。二战后，美国一直占据着世界霸权地位，但这种霸权的维持是脆弱的，随着时间的推移正在衰落。

“美国危机”其实是美国全球衰落的表现，这种衰落是必然的。如果美国没有其他国家取代它的霸权地位，那么这种霸权将走向终结。最后，美国能够通过什么样的调整来解决危机？

但是，对于“美国危机”和2025年《美国危机》报告，

以前，我们认为这个问题并不严重，但现在变得严重了。美国民众现在正面临巨大的威胁，但不必担心，因为大家都是美国人的，无论是在美国还是国外，都是美国人的利益。

在外部，美国面临着挑战。在亚洲，中国正在崛起，这种崛起速度是前所未有的。在军事、经济、技术、外交等方面，中国带来的挑战让美国不知道如何应对了。

这也是一个非常困难时期。从中国人的视角来看，美国二战以后的局面将如何？

但是危机是1940年到1980年代初是频繁的吗？当时的危机是1940年到1945年8月15日日本投降结束的吗？

当时的美国与许多盟友国合作。在战中，美国可以一己之力去解决危机吗？它可以通过一种强大的军事行动来解决危机吗？

现在的美国还能像过去那样在危机中重新建立起来吗？有能力应对即将到的危机吗？

在文章中，我们将详细述三个危机：第一个是美国内部，美国正面临“蓝色的危机”还是“红色的危机”？第二个是美国外部，美国面临着一个全新的威胁；第三个是美国制度的危机，即霸权的衰落。我们如何应对这些危机？
