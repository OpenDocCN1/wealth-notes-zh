# 郑家豪产：谁是继承者？谁又是守护者？

郑家豪产似乎没有绝对的继承者。

8月1日，香港法院作出裁决，支持了郑家豪的三个孙子郑嘉诚、郑嘉诚、郑嘉辉的诉求。这意味着郑家豪的遗产将由这三个孙子继承。然而，郑家豪的儿子们却争夺的是价值数百亿人民币的巨额家产。

不说是“郑家豪产争夺”落下了终点，但这场闹剧似乎刚刚拉开序幕。

香港的豪门争产被称为“夺产大战”。每一个家族的争夺背后，都是为了利益。而这种争夺的结局，往往是两败俱伤的。

这些案件往往让很多人感到唏嘘。为了金钱，竟然可以目反亲，甚至把家人送进监狱。但是，这样做真的有意义吗？

所以我想说，这些案件或许可以从另一个角度来看。与其说是一个利益的争夺过程，不如说是一个两败俱伤的过程。

2014年，郑家豪去世。当时他没有留下遗嘱，这为后来的遗产争夺之战埋下了伏笔。

此外，2003年郑家豪的妻子也去世了。她去世时没有留下遗嘱，这让郑家豪的遗产处分和继承问题变得更加复杂。

2024年，郑家豪的两个儿子郑嘉诚也相继离世。他们去世时同样没有留下遗嘱，这使得郑家豪的遗产继承人只剩下了三个，他们就是他的三个孙子。

郑家豪的遗产引发了激烈的争议。

郑家豪的遗产中，包含了价值数百亿的信和集团股份、新鸿集团的股份。

由于郑家豪没有留下遗嘱，他的遗产将按照法律规定进行分配。那么，究竟是谁才是真正的继承人？

郑家豪的家族成员中，他的三个孙子郑嘉诚、郑嘉诚、郑嘉辉是诉讼的原告。他们声称自己是郑家豪的唯一继承人。

郑嘉诚在法庭上表示：“我是我爷爷的唯一孙子”。

然而，郑家豪的三个儿子也早已去世，这使得郑家豪的遗产继承变得非常复杂。

郑家豪的遗产继承人中，还有他的三个孙女。

郑家豪的遗产争夺战反映了许多豪门家族的悲剧。

更让人唏嘘的是，这种为了金钱不顾亲情的行为，正在成为许多豪门家庭的常态。

如果郑家豪当年真的留了遗嘱，这场闹剧的闹剧还会发生吗？

郑家豪的遗产争夺战，似乎才刚刚开始序幕。
