


# 南院大王

科技板块的下一阶段推理

科技今天碰到分歧，
分歧的意思是，昨天拉太猛，又没有主线，大家要观望一下。

- 1. 先涨的PCB，虽然没多少技术含量，主要产能在中国，资金先妙也能没问题。PCB当然没走常，拉太猛要分歧再继续向上。

- 2. PCB 继续，同时会打开其他板块的空间。
目前是光模块和电源/液冷。
光模块已进化到1.6T阶段，就从中际领先创能，专供英特达，且不准给华为。
其他是新易盛和天孚、太辰光等。
华为系的光模块是华工源，母公司是华工科技，国内400G的够用的。

- 3. 算力能力的改进目标是，降低功耗和提高速率，突破方向是高密光纤连接器，易中天然是总成，天孚略领先，线头点艾犀封装的概念是，博创科技和致致。
光模块升级光引擎。这个概念叫做MPO。

- 4. 现在的预期差，deepseek的R2报告已经出来，但在媒体里报道了，有人说是谣言，英文原文是有过的。
突破提升成本，原本成本更低，加入国内图像处理系统。
那那么多的是AI数据，应该用那么多，有两个应该跟进，一个是有图片产权的视觉中国，一个是音频处理的天瑞声，其他的我们同学们已经自己发现，侧重是卖内容数据给DS。
Ds这个更，毕竟很多人还不知道。

- 5. 创新药是机构打造的行情，现在只是调整，当然是没有走完的，它是一个缩小版的机器人行情，就想想机器人当年人气涨了多久吧。

- 6. 最简单的方式，还是看港股映射，盯好方向，做自己熟悉的。
