


# 储人的观点

解决宏观难题，今年会有较大增长

2023年

去年，我国经济运行平稳回升，恢复超出预期。在困难重重的挑战下，我们既保持了战略定力，增强了发展信心。面对复杂严峻的形势，我们不仅稳住了经济大局，更在压力中把握了发展的新机遇。

回首过去，2023年中国经济展现出波浪式发展、韧性增强、生生有力的特点。全年5.2%的增速交出了亮眼的成绩，不仅高于预期目标，也顺利完成了政府全年预期发展目标。

从宏观来看，我国经济运行持续向好，宏观基本面保持稳固。这为中国经济的持续增长提供了充足的动力。

展望2024年，我国经济面临的形势依然严峻复杂，需求不足、有效需求不足、现实压力、结构转型压力等问题依然存在。但我们要看到困难中的乐观，有信心、有办法、有解决路径。

从预期目标来看，2024年我国经济增速预计将保持在5%左右的合理水平运行。

2024年是做好“后疫情时代”恢复性发展的关键年。我们要坚持稳中重心、改革举措，继续坚持“稳中经济运行，增强发展信心”。

2024年一季度，我国经济运行延续良好态势，回升势头强劲。消费回暖明显，制造业投资持续回升，出口表现亮眼，一季度经济增长超预期。

2024年一季度，我国GDP增长5.3%，比去年同期增长0.1个百分点，高于年初设5%左右的预期目标。

# 我们要解决哪些问题？

首先，要扩大有效需求。一方面要扩大内需，另一方面要扩大外需。要通过政策组合，精准发需，有效激发内需活力。

其次，要防范化解风险。重点防范房地产、地方债务、金融市场等风险。坚持底线思维，确保国内经济运行不发生系统性风险。

第三，要推进结构转型。加快产业升级，培育新增长动力。

最后，要做好水平开放。持续扩大制度型开放，构建高水平对外开放。

面对这些问题，我们不能照部就班，也不能坐以待毙，要从问题中找对策，精准发力。

我认为，解决宏观难题的关键在于发现问题，解决问题的关键在于增强信心。要通过一系列有力、务实的政策举措，提振预期，增强市场、企业和消费者的信心。

具体来说，我们要从以下几个方面发力：

一、扩大有效需求。要加大财政政策和货币政策力度，通过政策协同发力，有效提振需求。要加大扩大投资，特别是扩大基础设施投资。要增加居民收入，有效激发消费需求。

二、防范化解风险。要坚持底线思维，统筹防范化解房地产、地方债务、金融等风险，做到早发现早治理，确保经济运行不发生系统性风险。

三、推进结构转型。要加快绿色转型、数字化转型以及人工智能、生物制造等新兴产业的发展，培育经济新增长点。

四、做好水平开放。要坚持高水平开放，扩大制度型开放，营造更加公平、透明的营商环境。

这些措施不是难事，关键在于执行。只有落实各项举措，才能见到实效。
