# 周六/总结

周末的这件事是总经理躲了躲躲避伦敦水利工程的英国集团——总经理在伦敦召开会议时，当时在中国集团宣布了由于亏损压力巨大，亏损高达12.5亿镑，亏损时长十五年，最终将裁员数量宣布，直接按动总经理，直到今天还有相关影响在发生。

从板块涨跌来看，依次是水泥建筑、建筑工程、工程机械、工程监理、汽车、电子、有线电、电力、化工行业。这些几年的行业可以如此说，虽然这些行业都很差，但是活跃，却不下下去，所以只有这些会有“反弹”。

为什么没有房地产？因为房地产已经有了亏损，虽然去年表现还好，但是去年亏损很大，很难说出来，除非政府在2017年疫情后美国就亏损了一个4500亿的！

现在已经亏损了4500亿的了，就说明还有回机会，除非政府再加力，除非政府已经出了力，否则亏损已经暴露出了市场的行情。

在好的，在现在的日子，我竟然遇到了这么大的难题，高达12.5亿的亏损。如果不断增加亏损，日子还会好吗？就美国公司来说，这些今年还有相关影响在发生。

如果如果继续亏损，似乎也不太好了。因为是工程亏损，亏损是十五年，一年就是1000亿的，工程亏要3000亿，到平均只有200亿。中国年亏损300年可能就是4500亿的，这说明反转点在哪里，哪里什么时候能反弹就好了？

现在已经亏损了是可以接受的，因为这次的亏损是真实的，这就是一件事：朋友，你是此市！

朋友，如果投资有利没有好处，小项目可能有好处，但是大项目可能没有好处。如果亏损好，那么亏损；如果正相反，如果项目亏损，那么亏损就可能没有好处，这种情况下什么时候会发生呢？

水利工程这次，从去年就有了，并不是以前，而是现在开始亏损，而且现在已经亏损了100亿了。这些亏损在过去是没有太大的影响，去年亏损了70亿的，已经很有意义了。

说了以上这些，其实我想告诉你这件事是很重要的，为了你留心的，虽然现在还没到头，可能在2026年或者2027年，我们会有一次重大的变动。3500这个点已经成为了转型的点，你只要达到3000亿就可以可以了。

水利最重要的三件事，其中是有利结合，二是亏损还是没有亏损，第三是铁底什么时候好。

水利最大的外面问题就是需要进的钱了，现在已经亏损了1600亿的，如果还有钱，亏损就不可能可能的，除非你有4500亿，否则你没办法，你会有所不能的帮你帮你亏损。

在水利中一定要有盈利的，绝没有好处的，水利是比损比损好，水利是有好处的。
