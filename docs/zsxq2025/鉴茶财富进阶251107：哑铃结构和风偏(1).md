


# 鉴茶财富进阶 25107:哑铃结构和风偏

“风偏”是风险偏好和风格偏好的意思，

搞错了风偏，短期体体会不好，

跟死了风偏，又容易过山车。

风险偏好，指的是市场整体情绪和投资者群体对风险的态度。

- 当风偏好高时，大家都愿意为未来的高增长，为了故事性买单，
- 风格偏好中等时，大家会既看业绩又要看未来引导，追求量价齐升，戴维双击。
- 当风偏好低时，投资者更谨慎，追求确定的、眼前的回报，如稳定的分红和扎实的业绩。

买银行就是风偏极低，不想玩，收工的态势。买科技，就是风偏中等，站在看未来。

是在特定风险偏好下，市场资金呈现出的共同选择倾向，就形成了“风格偏好”。

比如，价值vs成长，大盘 vs 小盘，主题 vs 概念。

为什么通常11月，市场的风格会变化，风偏变得诡异呢？

因为按照规定，三季报后，公司的年报可以最晚在次年的4月30日之前发布。

很多公司是年报并一季报发起的。

也就是说，有长达6个月的时间，没人管你，没人追问你要业绩的事情，也不存在什么“暴雷”。

可不得撒欢的“炒小炒差”？

那么，市场就会出现哑铃结构，

一头是国家队和大型机构忙着报告，做总结，买入银行维护指数或者求稳，

一头是游资量化中小兴风浪，呼风唤雨。

超大盘和小小盘涨，中部倾缩。

游资们喜欢的套路昨天也讲了，

炒地图，炒概念，炒吉祥字，炒无厘头。

比如，福建概念，海南概念等。

海马汽车去年一共卖了45辆，八九个涨停，既带海南又带马。

因为杠铃结构会从中间抽血，所以风格要转换，等牛鬼蛇神们消停了再说。

他们会一个跌停，一次萎魔就消停吗？

不会，跌停板经常变成交他们诱多的工具，让散户觉得，昨天应该在-10%买的，结果错过了3个涨停，

对比他们，他们会把跌停板造成“空中加油”的态势，让即使进了妖股的同学，也感觉买少了，要加仓。

你怀疑，就连续拉板涨到你信为止。

现在阶段，就是海马汽车、平澜发展、海峡创新等概念下去了，被吸走的流动性才可能回来，回到主线方向。

所以你一看早盘，什么炒炒概念靠高，涨停的一堆，盘中说，什么海南概念大涨，你就知道，今天基本完了。

指数涨了，好像 20cm 的一大堆，跟你没啥关系。

等20厘米跳跳板那一头下去了，靠谱头这边的才会上来。

会很快吗？不会，因为大资金的撤离不是一天两天的，它们得好好布局。

现在，你只能他强任他强，清风拂山岗了。

那参与它们呢？很不建议。

有一个普遍规律是，不要美化自己没走过的道路，不要把灯泡塞到嘴里。真的拿不出来的。
