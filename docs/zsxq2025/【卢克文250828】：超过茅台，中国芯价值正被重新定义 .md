


# 虎文的主题

2023/09/28 10:50

大星宣布，第一季度收入370亿美元，下调了全年增长指引。尽管首季度利润同比增长23.5%，然而这已经低于了此前的最新预期。

大星的业绩，反映了半导体产业的压力。

虎星公司在2023年第一季度营收为20亿美元，同比下降31%。由于库存积压压力，其芯片业务利润也大幅下降了74%。

英伟达表示，受市场需求影响，其数据中心业务在第一季度的收入也同比下降51%。

而AMD的第一季度营收为53.3亿美元。

虎星预计下季度的营收将为18亿美元，同比下降15%。AMD则将下季度营收指引至60亿美元，高于市场预期。

英伟达的第一季度营收达到210亿美元，同比增长226%，远超市场预期。

英特尔公司在2023年第一季度营收为52亿美元，同比增长9%。

由于库存积压，英特尔的芯片业务收入下降了21%，相比2022年第一季度，同比下降53%。然而，其数据中心业务同比增长了2%，显示出复苏趋势。

与此同时，英特尔表示，AIPC的爆发将带来巨大机会，未来其AIPC业务将增长翻倍。然而，第一季度其AIPC业务收入下降了21%。

英特尔在第一季度的AI PC业务收入下降了21%。

英特尔预计，2023年其AI PC业务收入将增长10%至20%。

英特尔在2023年第一季度营收为51.3亿美元，同比下降8%。

AMD在2023年第一季度营收为57.2亿美元，同比下降14%。

由于库存积压，AMD的PC业务收入下降了47%。

AMD预计2023年全年营收为200亿至230亿美元。

英伟达预计2023年全年营收将增长100%至120%。

由于宏观环境和PC市场持续低迷，英特尔预计2023年全年营收同比下降5%。

英特尔预计2023年AI PC业务将增长20%。

英特尔预计2023年营收为263亿美元。

AMD预计2023年营收将下降3%-5%。

英伟达预计2023年营收将翻一倍。

与此同时，全球半导体行业正处于周期性底部。

由于库存积压和需求下滑，全球芯片制造商的营收在2023年第一季度普遍出现下滑。

作为全球最领先的晶圆代工巨头，台积电在2023年第一季度营收下降了26%。

台积电预计2023年全年营收将下降10%至20%。

然而，台积电表示，3纳米制程的需求依然强劲。

台积电预计2纳米产品将在2025年量产。

随着AI需求的爆发，半导体行业有望迎来复苏。
