


# 大力度的中资出海

发布时间：2025年10月22日

![](img/18e26edc0abbed9e52d59a202cf06f15_0_0.png)

三中，是确定中国跟海外开放的力度，也可以说是拿出来多少蛋糕跟海外利益集团交易。

用小学数学题表述，三中就是决定中外两个蓄水池批准可以联通多少个水管，多粗粗的水管。

所以，三中召开后，中国这个池子插水管附近地方明显变热，区域方面是外国人最多的上海，公司方面是外国投资者最多的平台公司，行业方面是外国最火热的人工智能，是因为大家都知道只要联通了中外，这些地方自然要承受迅速猛的水压冲击。

另一个角度来看，三中是决定了我们准备拿出多少蛋糕来交换，所以西方跟中国的关系，迅速变好，特朗普曾每次压骚后都会迅速TACO，因为他们都想吃这个蛋糕。

蛋糕不是方面出卖，而是相互的交换，美西方想要吃到中国开放的市场，就需要同样开放他们的市场供给中国，这也是中美贸易博弈的大背景。

中国迟谈没有跟他们谈具体的蛋糕领域，抛开之前讲过的政治因素，还有一个经济因素是在给中国的企业争取时间。

基于实力地位出发，中美签署的协议，纸面必然是美方更为有利，但纵观执行经验，每一次有利于美方的协议执行时都有利于中方，原因是中国的企业变动越会抢跑。我们每一次开放的的市场美方都很难吃下，但每次美方开放的市场会被我们吃干干净净。

所以随着中国开始转向开放，国家便开始大力鼓励企业家出国考察，如今随着中美APEC大概缓和，中国政府会以更大的力度鼓励中资出海，把判桌上拿不到的东西靠西方企业们抢回来，所以内在的各位企业也将受到被“统战”的待遇。

## 工业和信息化部发文助力中小企业出海
来源：新华网 2025年1月15日

工业和信息化部近日发布通知，组织开展中小企业出海服务专项行动（《关于开展中小企业出海服务专项行动的通知》），汇集各方力量帮助中小企业开拓海外市场。此次专项行动将重点提供政策准入、市场开拓、国际人才、管理提升、跨境金融、权益保护等6项服务。

## 2025年稳外资20条公布——继续支持外资企业投资中国
来源：人民日报 2025年2月21日

2月10日，国务院常务会议审议通过了《2025年稳外资行动方案》（以下简称“行动方案”）。2月20日，国务院新闻办举行政策例行吹风会介绍有关情况。

总的来看，“行动方案”具有4个突出特点：释放进一步对对外开放的积极信号，加大政策支持力度，积极开展外商投资促进工作，切实解决外资企业急的问题。

## 国务院常务会议解读 | 完善海外综合服务体系，为出海企业提供有力支撑
来源：新华网 2025年9月12日

2025年9月12日召开的国务院常务会议，研究完善海外综合服务体系。

会议指出，要着眼于为企业参与国际合作与竞争提供有力支撑，进一步完善海外综合服务体系。

最新数据显示，中国企业投资规模继续位世界前列。2024年中国对对外直接投资占全球份额的11.9%，较上年提升0.5百分点，连续13年列前三。

去年召开的中央经济工作会议部署扩大高水平开放工作时要求“完善海外综合服务体系”。
