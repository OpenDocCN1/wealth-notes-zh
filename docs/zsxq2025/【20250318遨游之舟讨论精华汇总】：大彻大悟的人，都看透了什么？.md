


# 第三章（重逢）

大人，您还健康吗？

现在的我很好，您也很好吧？自从您离开我以后，希望您一切都好。

从那年前，当您将我丢在雨中以后，我再也没有害怕过雨了。我没有哭，也没有大吵大闹，我只是在心里默默地对您说：谢谢。

在离开您后的日子里，我学会了独立，学会了坚强。在很多日子里，我学会了如何面对孤独，如何面对痛苦。我不再在深夜里哭泣，不再在受委时寻找人依靠，我只是在每一天都努力让自己变得更好，希望有一天，当您看到我的时候，您会为我感到骄傲。

大人，您记得我吗？

她看着他，眼神中带着复杂的情绪，“我们已经散了这么多年了，您还记得我吗？”

我怎么会忘记你呢？

他走上前，轻轻抚摸她的脸，声音温柔：“这么漂亮的小女孩，我怎么可能忘记呢？”

“可是，我们已经没有关系了。”

他笑了笑，眼底闪过一抹落寞：“时间流逝了那么久，难道真的能让我们之间的一切都变得无足轻吗？”

我推开他的手，冷冷道：“已经太晚了。”

她转身离开，没有回头。

他看着她的背影，心中泛起了一阵苦涩。

三年后，他们再次重逢了。

在一次商业晚宴上，他们再次面对面。

她已经成为了成功的女商人，而他依然是那个掌控一切的人。

他们目光交汇，空气中仿佛凝固了时间。

“你好，好不见。”

她微微点了点头，语气平静。

“你好，你变了。”

他看着她，眼神中带着赞许。

“是吗？每个人都会变。”她笑了笑，笑容中没有一丝笑意。

“我先失礼了。”

她再次离开，留下他一个人站在原地。

他看着她的背影，心中五味杂陈。

这一刻，他们似乎才真正重新开始。

然而，未来又会如何呢？

只有他们知道。

她惊讶问道：“你来这里是为了找我吗？”

“不，我只是路过。”

她看着他，眼神中带着一丝无奈。

“你骗人，你根本不是路过。”

他沉默了，没有回答。

“其实，我还是爱着你的。”

她看着他，眼中盛满了复杂。

“可是已经太晚了。”

她摇了摇头，泪水夺眶而出。

他看着她流泪，心中也如刀割。

“我们，真的无法回头了。”
