


# 体制内，如何避免那些毁掉你的事？

李建斌 2023-10-15 10:50

我看了很多大家留下的教训，希望大家能避坑，自己不要犯错。从学生开始每多吸一个教训，以后后悔就太晚了。

但是，我没有足够的教训。我工作了多年，才总结出这几点，希望大家参考一下：

## 一、不要显山水，说话要有技巧

可能你认为，有能力，领导会提拔你；有能力，领导会重用你。但你错了。在体制内，领导需要的往往是听话的人。如果你有能力，但表现得太显眼，领导不仅不会提拔你，反而会引起同事的嫉妒。

在体制内，说话是一门艺术。你不仅要说实话，更要学会怎么说。在领导面前，要多认同领导的观点，即使有不同意见，也要委婉地提出。

很多人在体制内，说话直来直去，没情商，这非常大忌。这不仅容易得罪领导，还容易得罪周围的人。

尤其是你还能力强，那些小人就会嫉妒你，这种人会在背后捅你刀。这种人，以后等了机会，谁来毁掉你呢？

## 二、不要抢风头，做事要有技巧

可能你认为，多干活，领导自然会看到你；多出功劳，领导会器重你。但你错了。在体制内，领导需要的往往不是只会干活的人，而是能把活干好，还能让领导有面子的人。甚至，领导最怕的是下属表现得比他还要优秀。

在体制内，做事是一门艺术。你不仅要把活干好，更要学会怎么把功劳归于领导。如果你把活干好了，但没有让领导有面子，那你没用。

很多人在体制内，埋头苦干，从不显露。结果就是，辛苦了半天没被提拔，反而被别人提拔了。

所以，在干活的同时，要学会适当地展示自己的成果。这并不是在炫耀，而是为了让领导看到你的价值。

在体制内，交朋友很有门道的。很多人在体制内，喜欢到处交朋友，结果最后发现一个朋友没交到，反而交了一群在背后捅刀的人。
