


# 猫哥星球 251226: 美国外交系统地震

近期，美国国务院突然要求，29名驻外大使必须在明年1月中旬前离职。理由是，这些大使由拜登任命。美国从未有过一次性撤除29名大使的先例，这是外交系统的大地震。

那么，这是怎么回事？

美国驻外大使分为两种：一种是非科班出身的“金主爸爸”，他们靠着大选给总统的捐款，而被“赏赐”一个大使职位；另一种是科班出身的人员，就是“职业外交官”。两种驻外大使，泾清分明。

前者，通常会被派往驻美（的盟国，如欧洲、加拿大、日本等等，这些地方条件好，重要的是，美国大使在这里就是“太上皇”。

他们不用做太多实际工作，只做一个礼仪性的人物，日常和盟友们联络一下感情即可，“金主爸爸”们则乐得当个甩手柜子，同时搅拌着外交官的履历。

有时候，连礼仪也可以不懂，只需要“发号令”。

特朗普第一期任命的驻德国大使雷格内尔，一直以居高临下的姿态，要求德国不购买华为的设备，惹得默克尔十分不满。

至于后者，职业外交官，就劳苦多了。他们多派往非洲、亚洲、俄罗斯这些“第三世界”，条件相对艰苦，也当不了“太上皇”，做的实际工作很多，没几把刷子是不行的。

过去，总统换届，只撤换“金主爸爸”，不会轻易动“职业外交官”，起码让“职业外交官”做完长期，降低换届给外交工作带来的冲击。

“金主爸爸”们不负责具体工作，将他们撤换，不会有太多影响；而“职业外交官”不同，可能换了一个人，原有的一堆项目就会停滞，更别说换一批人了。

所以，特朗普的举动让外交界极为震惊。

本次被撤换的29个驻外大使，有15个位于非洲，6个位于亚洲，4个位于欧洲，2个位于美洲，还有两个美国驻国际组织的代表。看得出来，非洲国家大使是被撤换的重头。

非洲的条件实在艰苦，别说“金主爸爸”，愿意去的“职业外交官”都没有多少。所以，美国驻非系统常处于缺编状态。

比如，特朗普第一任期，驻尼日利亚大使、驻肯尼亚大使等关键岗位，长期无人担任，只能由代办主持工作，但代办的级别不够，很多事没法拍板。

拜登任期内好一点，任命了驻尼日利亚等非洲主要国家的大使，不少非洲中小型国家依然没有美国大使。到了特朗普第二任期，问题更大了。

这一波撤换后，想在短期时间内找到15个愿意去非洲担任大使的“职业外交官”，几乎不可能。大概率，只能由代办主持工作。

特朗普不是傻子，知道“美非合作”，为什么要坚持撤换？表面上的理由是这些大使由拜登任命，不符合特朗普的心意。实际原因是，不引发很大风波的《美国国家安全战略报告中，“非洲”被放在最后一页，总共只有短短三段，基本是一些“加强合作”之类的片汤。

唯一的实质性内容，是鼓励美国企业加强对非洲矿产资源、能源的……字很少，内容也空洞。

这一点，和“非贸易”是对得上的。2011年，非贸易总额1250亿美元，到了2024年，数字不增反降，仅为700亿美元出头。也就是说，过去十多年，美非合作持续倒退，连基本贸易都无法保证。

问题来了，非洲作为矿产资源库，美国的“国家安全”有着特殊意义。比如稀土，非洲的稀土储量占世界已探明储量的三分之一。加强对非合作，还担心被兔子卡脖子？仅稀土，非洲别的的矿产资源也是有的，为什么美国不重视非洲？

开资源，需要基建、需要处理好与当地人的纷繁复杂的关系等等，总之，一团乱。
