


# 【25年0417】普通人的价值！

司令解读：留一半清醒，留一半聚群

◇正文

90%的就业由中小企业解决，这些中小企业或许只有单一种的业务，始终处于一种不死不活的状态，因为拼命挣扎，其成本和收益也不过是维持一种最低水平的平衡。虽然创造太多的经济价值，但解决了大部分的就业岗位。这样的微小企业最多，却异常脆弱，维持运转的业务往往高度依赖多年稳定的几个骨干人，老板往往以连环的方式维持着这几个人的稳定，从而保证业务能够进行，保证其他人的岗位。如果这几个稳定的离开，业务就难以维持下去，剩下其他人的也会面临失效。

调研后发现，这个社会大部分普通人的就业形式都是通过这种方式来实现的，这样的小企业既没有竞争力，也没有经济价值，甚至没有发展空间。然而，只要能够继续存在，就很有社会价值，解决了90%的劳动力的就业问题。

一个小餐馆，雇佣个人。一年到头除去开支其实并不挣钱，只要这个小餐馆开下去，就能为几个人提供就业岗位。2019年开始的疫情三年最大的损失就是让这种雇佣几个人，十几个人，几十个人的微小型经济实体，落在以后再也没有起来。

虽然小微企业对我们中国的经济数据没有产生什么影响：一个巴西一年出口的汽车获得的利润，就足以抵扣掉百百万这样的微小型经济实体，但巴西增长的汽车出口还需要多少雇佣上万人呢？当量提供就业的微小经济实体了之后，依赖于小微企业获得稳定收入的数千万人就会没有稳定收入，没有了稳定收入，这几千万人的消费就会减少，这些人的消费虽然不高，但规模很大！只有这么多人，才能消耗掉我们多的产能。一个亿富翁靠用黄金打造成一件衣服，几百万份，而且提供了几个就业岗位，但是几千万人怕每个人买50块钱的衣服，也是十亿级的生产需求，还不只是几亿的生产需求，而是让几亿的资金动起来了，通过流通环节和杠杆的加持，能够撬动百亿规模的经济活动，从而形成正向循环。

除了这个经济活动形成正向循环，由此形成的需求拉动的生产，又能提供大量的就业岗位。不是消费生产，而是流通，每一个环节生产的税收都是官方的收入。随着生产力的持续发展，或许不再需要普通人去生产，但是需要普通人去消费。美国有3亿人，有300万左右的人受过超级好的教育和训练，另外有3000万人配合这300万工作，担任演员辅助角色，剩下的人全是垃圾，其中60%的人文学化都没有，这不是我说的，这是美国著名的桥水基金大佬老·达利欧说的！

桥水基金老大达利欧这段话是说明，美国没有办法去生产，美国没有办法去生产，美国没有办法去生产，美国依然是全球最大的市场。

为什么大的需求呢？中国在过去的20年中，大概有4.亿人从农村搬到城市，随着生活水平的提高，城市人口对肉类的需求暴增，要提供这么多肉类，就需要大量的饲料去喂养，大豆可能是各种原料，玉米基本上就是饲料。阿根廷的潘帕草原，以前是放牧的，现在开始种大豆了，因为阿根廷发现出口牛肉不如出口玉米挣钱得多，所以阿根廷把草原改成农场了！

发达的经济体服务业占比很高，绝大部分服务业所提供的岗位，仅仅是生计。换句话说，越是发达的经济体，大多数普通人终极就像被饲养在一些无形的圈中的牛羊。做的事情没有任何价值，也不会有太多的空间，仅仅是用来换取生计所需的稳定收入，然后用这些收入去消费并在在这个环节中缴纳赋税，就像那些牛：吃玉米，长肉，提供肉类，我们会把这个过程中的细碎感统称为人间的烟火气。
