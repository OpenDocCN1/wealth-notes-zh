


# 最灵验的5个转运方法

原创：U 君 公众号：U君笔记25年9月14日

如果你最近几年诸事不顺，喝凉水都塞牙，那么说明你该做点什么来让自己转运了。

我总结，对于我们普通人来说，有5个最灵验的转运方法：换场，换相，换名，换局，散财。

## 1. 换场

如果一个东西长期不动，长时间在同一个地方，那么它就容易发霉。

同理，如果一个人长期在家里，很少出去走动，那么他也容易“发霉”。

当然，这里说的“霉”不是霉菌，而是霉运，倒霉。

从玄学角度来看，如果一个人长期在家里，灵气和运气都会耗尽，身体也会变得疲惫不堪。

想要转运，就要多出去走走，最好去有山川湖海、花草树木的环境吸收一下天地的灵气，感受大自然的阳光雨露。

从科学角度来看，如果一个人每天都重复同样的生活，接触同样的事物，见到同样的人，那么大脑会变得僵化、思维会变得迟缓。

但是，如果你经常去开阔的地方转转转，去风景好的地方呼吸一下新鲜空气，你自然会感觉精神振奋、充满能量。

这些都是精神维度的滋养。

在身体维度，多去外面晒太阳，能补充维生素 D，促进钙的吸收；多出去走动，还能促进血液循环，强健体。

有人会说：谁不想出去旅游啊，关键我是没钱啊，也没有假期，怎么出去旅游？

那也没关系，哪怕你在下班后去公园转转转，超级超市里逛逛也，千万不要总是重复“两点一线”的生活。

就拿“逛超市”这件事来说，虽然比“网购”和“点外卖”更耗时间，但是货架上琳琅满目的商品也能给你带来视觉冲击和新鲜感。

而这些冲击和新鲜感，能刺激我们大脑的神经元，让它们更活跃、更有活力。

总之，如果你每周都能接触一些新鲜的事物，去一些新的场景，那么你的大脑就会更年轻，运气自然不会差。

## 2. 换相

如果你一直留长发，但是身边总有很多“剪不断、理还乱”的破事发生，那么你可以尝试一下短发。

这并不像是玄学，而是，干练的发型会给自己很多积极的、勇敢的心理暗示，别人看你时也会被你的新“相”所感染。

在穿衣服这件事也是如此，不要盲目跟着别人去穿搭，也不要盲目去购买奢侈品。

你自己从内心去体会：我穿着这件衣服舒服吗？穿出去自信吗？

就拿 U 君自己来说，我是学习石油石化的，对于“染料”这个东西很在意。

一方面，我只买进口的品牌，因为国产的染色技术相对落后；

另一方面，贴身的衣服我只穿白色的、浅色的，因为上面的染料相对少一些，对皮肤影响也会小一些。

当然，我的这些担心可能是多余的、没有科学依据的，但是呢，穿上浅色衣服之后，我心里觉得很踏实。大佬文集圈对我来说，“浅色相”才是旺我的相。

反之，如果你喜欢深色系的东西，深色能给你带来安全感和满足足，那么你就多去穿深色的衣服、买深色的物件。

另外，如果你经常需要跟别人打交道、跟客户谈生意，不要穿得太随意，要穿正式的衬衫，要穿Polo 衫。

不要穿那种非常随意的 T 恤，否则别人很难尊重你。

总之呢，“体面”这个东西是需要刻意维持的，“怎么穿更得体、更体面”，是人生中一个重要的课题。

那么问题来了，男人穿什么牌的衣服能瞬间变得“体面”呢？

就拿 Polo 衫来说，我推荐下面这些品牌：HUGO BOSS、LACOSTE、HAZZYS、Ralph Lauren、Tommy Hilfiger......

这些品牌的 Polo 衫，一件要上千元左右。如果你觉得贵，优搭库也有同样版型的 Polo 衫，只需要两百元。

Polo 衫配什么样的裤子、鞋子合适？大家自己去网上搜一下 “Polo 衫搭配”，有很多穿搭博主在分享，你挑一款适合自己的风格即可。

女性也是同理，如果你之前一直非常“女性化”的时装，旗袍、裙子，气质拉满，但是命运始终不太好。

那么你可以换一种风格，开始穿比简洁的运动、休闲装，没准你的运气也会发生转变。

反之也是同理，如果你之前一直偏中性、偏简洁的衣服，那么你可以换一些“女性化”的衣服穿穿。

总之呢，如果你诸事不顺，可以尝试换一种完全不一样的发型，换一套完全不一样的穿搭。

说不定，倒霉鬼不认识你出来来了，霉运就不会降临到你的头上。

同时，幸运女神和财神可能就喜欢你的“新相”，然后好运和财运就会降临到你的头上。

## 3. 换名

一般来说，我们的大名都是父母起的，很难再改变了。

但是，我们的网名、昵称是可以自己决定的，但是呢，有的人给自己起的网名一看就非常“不聚财”，因为太暴露了，

比如，下面这些微信：

- A平安翠花
- A京开锁
- A努力发财
- A二手车
- A小宝
- A阿威
- A猫狗
- A锦绣
- A龙行
- A宏大
- A暴富瘦
- A舍得
- A厚德
- A胜者为王
- A人生旷野

通过微信签名基本能判断一个人的水位：

- 如果他的签名是“暴富”，说明他是个又胖；
- 如果他的签名是“舍得”，说明他是个斤计较；
- 如果他的签名是“厚德”，说明他是个坏种；
- 如果他的签名是“胜者为王”，说明他在现实生活中从来没有赢过；
- 如果他的签名是“人生旷野”，说明他是个被困住的底层牛马。

反之，真正高端的、有钱的人，不会把自己的职业直接写在签名里，反而会用比较低调的名字，比如：

- 闲云
- 听风
- 观海
- 归山
- 这种宏大的名字，
- 比如：
- 顺心

因为你的能量场就不起，很快就会发现，自己的生活里也会出现各种负担。

## 4. 换局

买车是个局，结婚是个局，养子是个局，考研是个局，稳定的工作是个局。

如果上面的局让你的内心非常宁静，说明你适合这个局。

反之，如果你在这些局里每天挣扎，都很累，说明你根本不适合，你需要给自己换一个局。

举个例子，在国企工作，我觉得很多事情和人际关系让人累，于是我大胆辞掉了。然后，当你置身于一个巨大的“局”中，感受到的不是快乐和满足，而是巨大的压抑，那你完全可以换一个。

## 5. 散财

如果你不是拿工资的底层牛马，而是创业者或者商人，那么豪宅对你气场和财运的加持是显而易见的。这个时候，开50 万的宝马肯定比国产车运更好，带来更多作者和订单。因为靠人不如靠马，谈生意时，一辆好车还是能撑场面的。所以，这个钱绝对不能省。

比如，如果你不想被噪音影响睡眠，不想被低素质的邻居扰，那你就多花点钱搬到高端的小区。你睡觉时候周围很安静，工作时候周围安静，思考时候周围也很安静，而且你出门看到的邻居，精神面貌这些非常好。这时候，你的能量场是非常饱满的。

反之，如果你为了省钱而住在老小的房子里，每天都能听到邻居吵架、训小孩、鸡飞狗跳的声音。出门就会发现，小区里都是低素质的老头太太，在电梯里抽烟、到处扔垃圾、吐痰、遛狗不拴……这时候，你的能量场肯定会受到影响。

为什么我鼓励大家经常去飞机等舱、住五级酒店？因为在那种比较贵的场，周围弥漫的都是贵气、财气，你自然也会受到感染。

我每天都要给别人发红包：看了一篇让我获益匪浅的文章，我会赞赏；点外卖我会给外卖打赏；我去其他公司拜访，也会给前台发红包……表面上看，我在散财，但实际上我收获的远远超出了我散出去点钱。我给创作者赞赏，他会更加努力创作我喜欢的内容；我给外卖打赏，他会在心里默默为我祝福。我给其他公司前台、酒店前台、健身房前台打赏，她们会告诉我很多内幕信息，让我看待世界、看待各个行业的视角更加通透。你说，我的财运能不好？
