


# 内卷环境下的生存策略

原创：赞赏U 君 公众：U君笔记 25年5月18日

世界上最内卷的地方是哪里？有人说是东亚三国。但是，只要你去过日本之后，你就会发现，根本不是这么回事，他们的内卷程度跟我们根本就不是一个量级的。

就拿高中生来说，他们基本都是下午3-4点放学。放学之后，他们的去向一般分为这5部分：

- 一部分会选择继续学习或者去课外补班；
- 一部分会选择乐器、体育等课外特长；
- 一部分会选择社交，或者参加社团活动；
- 一部分会打工兼职（受法律保护）；
- 一部分会宅在家里游戏......

之所以会有相当一部分高中生不把“考入好大学”作为人生目标，是因为高中生的就业率太高了。2024年，日本高中生就业率在90%以上，而且收入、福利、保障这些，不比大学生白领差少。微信号jntg2，免费资料群

就拿“外卖员”这个职业来说，不用太辛苦，每个月都能赚到2-3万元人民币（韩国比日本的收入还高）。只要不要进行奢侈消费，每个月固定销七八千人民币就足够了，只要正常交社保，看几乎免费（自己可能缴10%）。

最重要的是，一个人工作，全家（上下两代人）都可以免费看。

在福利待遇、社会保障等方面，韩国是跟日本学的，但是现在韩国有着“出蓝而胜于蓝”的趋势，人均收入、医保体系等维度，甚至超过了日本。

如果务农的话，韩国有类似于“农协”的机构，只要农民出来的粮食、蔬菜、水果，还有他们养出来的猪牛、鸡鸭，都卖高价。

就韩国来说，一个苹果要10元人民币，统一价，而不允许进口国外的廉价水果。结果就是，市民吃水果负担重一些，但是农民的收入就高一些。

其他衣服、家具等各种商品也是如此，他们不允许进口的价格冲击国内市场。结果就是，各个行业都没有“恶意压价”的内卷现象。加微信jntsg2，免费进资料群

就拿上学这件事来说，在20年前的时候，考上本科就已经的人生赢家了，直接拿到铁饭碗。到了今天，连研究生找工作都费劲。很多学生在10-20岁这10年里，每天都要学习10个小时以上。

之所以会出现这种情况，原因就是：物质极大丰富，而且就业岗位跟就业人数严重不匹配，各个行业都深度内卷。

所以，如果你是消费者，或者你是招聘方，那你就以极低的价格达成自己的目标。

但是，如果你你是开面馆的，生产T恤的，种西红柿的，找工作的......你就愁了，你会发现无论你把价格降到多低，同行的价格都比你更低。

那在这种内卷的环境下，我们怎么操作，才能让自己陷入内卷的旋涡?我总结，一共有4条出路:

## 1. 不要进入的市场

房子、汽车、彩票、婚姻......这些市场已经被内卷了，如果你不想拼命，尽量不要。如2025年的今天，无论是一线城市还是二线的小城，租金都极低（可能只在发达国家），而且大概率会降价。如果你买一辆价值30万元的传统燃油车，每年油费、保养、停车费、洗车费方面的支出可能在5万元以上（加微信jntsg2，免费资料群）。如果你买一辆价值30万元的新能源汽车，一年直接贬值到15万元，卖不掉。

在婚姻、彩票维度，如果你是个条件差的男人，发现婚恋市场就是坑（比如自己至少要5万以上），那你就别入场了。平时花钱，全世界几乎所有国家都不需要买房，如果你走出去，还要去边疆地区去找当地姑娘，她们对物质和金钱没那么大的需求。在商业方面，你就不要搞传统的生意了，不要生产T恤、手机壳、白酒，也不要开服装店、奶茶店、面馆，更不要种西红柿......这些行业已经极度内卷了。

## 2. 从物质向精神维度转变

有些人会认为食为天，每个人都要吃饭，所以我我要开一家面馆，每天卖几百碗面，纯利润不到3元，甚至是赔钱。生产T恤、种棉裤、养猪也是道理，因为在这片土地上已经极度内卷了。这时你要另辟径，向“精神”方向转变。举个例子，宠物虽然也是物质，但是它们会带来精神方面的陪伴和安宁。美容市场也是如此，让自己感觉良好。当然，如果你能在互联网上创造出各种精神粮食（游戏、视频、直播、音频、文字），大家愿意在你的产品上消费金钱和时间，那就更好了。2025年的今天，互联网的信息量非常大，AI已经超级发达，但是优质的视频和文字依然匮缺，有大的市场需要填补。加微信jnts2，免费资料群

## 3. 赚快钱

很多人看不上“赚快钱”的人，尤其是那些做传统行业的老板。但是，现在技术和信息的更新速度太快了，如果你还有“在某个领域深耕三五年”这种思维，那么等学会之后，很可能会发现早就被AI取代了。就拿计算机、美术、设计、音乐等专业来举例子，你在大学里苦哈哈地学习4年，等你毕业之后，发现AI做得又好，还不花钱。

昨天我看了亚马逊创始人Jeff Bezos一段采访，主持人问他最近在忙什么，他的回答是“AI”。他现在主要精力都放在AI上面，而且他认为以后手机上的任何一个APP都会跟AI结合。无论是社交、游戏、交友、购物、美图、地图、旅行、短视频……任何一种类型的APP都必须跟AI结合。如果哪个APP不跟AI结合，它很快就会被淘汰。加微信jnts2，免费资料群

所以是在互联网新月异的今天，我们必须时刻关注周围的一举一动，而且必须培养自己赚钱快的思维。真正赚钱快的人，对项目都是非常敏感，发现这个项目可以搞钱，那就去搞几个月，等风口过去之后，就换一个项目继续搞钱。那如何找到让自己赚钱快的项目呢？这就需要你拥有“持续学习”的能力。举个例子，如果你打算利用AI赚钱，那你每天必须时刻关注ChatGPT、Grok、Claude这些领先AI的最新进展。同时还要加入各种AI相关的学习社区，不能闭门造车。
