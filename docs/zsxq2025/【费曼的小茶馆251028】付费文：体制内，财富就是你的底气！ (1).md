# 前言

体制内人情故事系列的最后一篇。介绍体制内普通人慢慢变富的两个渠道。

体制内职场就是一个名利场。

如果你不是领导，你会信心不足。你是领导的话，你就会意气风发。

这就是个人地位和权力带给你的满足感。

但是，单位里并不是每个人都能提拔成领导的。

大部分人还是晋升到职级的天花板退休了。

这意味着，很多人都找不到自信的来源。

要摆脱这种感觉，一方面，要看淡功名禄，因为在体制内上班已经是康康的生活水平，日子还是比较滋润的。

另一方面，就是让自己变得富有。

如果你变得富了，你就不会羡慕领导了，而且也未必想当领导的。

因为当领导要操心的事情很多。

而且，你一想到，你每年的收入比单位领导还高的时候，你整个人就会有松弛感。

因为说明你为社会创造的财富高于领导的。

你的能力远远优于领导之上。

一想到这些，你就没有任何社交焦虑了，见到领导也不会紧张的。

因为不需要领导给你什么，你也不用求领导，所以没啥好紧张的。

在这种放松状态下，你的社交是充满自信的。

这也是我的一个感觉，我相信，只要你有创造财富的能力，你也会有这种感觉。

实际上，在单位上班，普通人比领导更容易创造财富，让自己变富起来。因为普通人更有时间在以下两个相对容易的赛道中，创造和积累财富：第一，做线下副业。

# 第二，做股票投资。

其实是我最想说的一点。

股票投资是最适合体制内的干部职工的。

因为收入稳定，家庭收入有结余。

那么，我建议可以拿出闲钱进行股票投资，记得——定是闲钱，要有投资的安全边界思维。

这也是为啥我说，每个月如果有副业的闲钱很重要。

因为这些副业的闲钱，可以投资到股票市场。
