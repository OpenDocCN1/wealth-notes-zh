


# 鉴财经院底层代码系列：风险、收益、眼见为实

今天周末，谈点轻松的课题。

人们常说，风险和收益成正比，如果收益越大，那风险就越大。

这个所谓的真理，大王在学习时就怀疑，后来搞搞金融，风险控制部门经常谈到这个看似真理的东西。

大王并不认为是这样的。

如果我们重回 2008 年的四万，大家肯定有多少钱拿去买房，如果重回 2015 年的后，借钱也要买房。收益是很大的，风险大吗？

又如，昨天美国出现的吵吵天的新闻，两党的不少的议员在 2 月 27 日就把自己的股票甩卖光了，那会是高点，都赚了大钱，收益很高。就金融来说，有风险吗？

因此，底层的代码很简单：

收益只与信息的占量有关。

如果你全知全能，知晓信息，开了全地图，你肯定能赚。

掌握的真实信息越多，你赚钱的概率越大。知道的信息越少，你的风险就越大。

中国的股市上，大部分炒股都是弄的，和你的技术没有关系，因为你根本不知道上市公司的真实信息。

所以，收益越大，风险越大，是用糊弄老百姓的，让所有人知道这个东西，稳定很不好搞。

大王的篮球在 2 月 28 起让大家不要上车，因为我们也掌握了一点这个信息。

普通人隐含真实信息的最大问题是，无效的内容太多，我们很难挣寻，来源真假假，我们很难判断，而一些更机密的，要去发掘、研究和判断。

消息，距离信息的质量差的很远，信息距离判断趋势就差的远远。

而以上都是反人性的，因为一般人只相信眼见为实。但这个眼见为实，都是他们故意让你看到，你才能看到。

人类社会今天如此精密，已经发生的事情，通常没有什么利润和空间了，都要靠着趋势或者未来来挣钱，却没有人告诉大家，那些都是没有发生的事，这个需要思维训练，眼见不为实才是。
