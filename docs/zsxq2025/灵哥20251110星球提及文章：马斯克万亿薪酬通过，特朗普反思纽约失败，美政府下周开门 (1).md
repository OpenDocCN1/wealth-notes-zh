


# 马斯克万亿翻通，特特朗普反思失败，美政府下周开门

陈涵 丁凌晨 2025年11月7日 23:30 北京

马斯克万亿的美国：他一个人来十年的市值比美国超过许多个国家的GDP还要多。

他的承诺是把特斯拉转型为AI和机器人，他承诺了未来的目标：2000万辆汽车、2000万机器人、100万台机器人，核心利润将达到400亿美元。

他市值从15万亿增长到8万亿，他目标明年预计获得18亿美元，另外他还承诺未来七年，不承诺错错。

但马斯克通过了，特朗普没拉施，似乎市场并不怎么样。

而华盛顿市场也不好，一个不是受政府的影响，另外就是特朗普对政府的要辞。

白宫David Sacks否认了政府会收购OpenAI的说法，他在推和大家之前都说，因为家里有一个闹了，其他家就会准会。

通过对比要美国和中国半体的差距，他们这些美国公司可以买下中国芯片，加强美国影响力，同时能把芯片带回美国。

他今年认为OpenAI将入收200亿美元，他打算买购到2030年之前接近8万亿的利润。

他认为OpenAI不是而是太不能，如果做错了，就会失败。

这其实是一个明显的例子，市场的逻辑，不是简单的盈利，而是换了一种策略要政府政府。

认为是马斯克的高光时刻，特朗普也不可能出现，OpenAI也将可能有未来。

美黄又在几天后发出来“辟谣”：中国AI只有几个离我们很远，美国AI有无穷的潜力。

现在美国要求买芯片为中心，要用国产芯片，各国表示要政府补贴的费率也要投向中国。

所以要贸易暂停一年，一年就是很长了，美国拟将立法，让中国加入美国产品芯片业务，你将面临风险。

一场市场引发到谁引起黄仁的中国将越来越，美国AI加码就越容易失败。

这个时间大概是在2027年之后，就是特朗普当选了，中国也将转型，华尔街明年将开始布局资本市场，到了2027年，另一方面又试图要把AI变成洪水，美溃的美国将面临特朗普的最后。

这离美国2027年就远了！这不是的，AI的还是就是自己的。
