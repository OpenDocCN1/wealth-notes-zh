# 石原茂——“战后80年以后”

/卢文/作者：石原茂访谈录

1950年代初，石原茂的政治生涯刚刚开始。在当时，他发动了一场“反美安保运动”，这实际上是战后日本政治的序幕。

然而，在1951年9月24日签署的美日条约当时并不受欢迎，但他成功地引起了许多人的关注，从此走进了日本政坛的舞台。

当时安保运动的兴起引起了日本社会的关注，但他由于失败，却挫败了作为年轻人的政治事业。卢文认为，这种失败是偶然的。当时安保运动的失败，让石原茂的政治生涯进入了转折点。卢文认为，这种失败是偶然的，但它成就了石原茂，让他赢得了一场意想不到的胜利。

这次失败，或许是他政治生涯真正的开始？

## 01 石原茂的轨迹

石原茂，出生在日本，但在战期间生活在美国。这种经历深刻影响了他对日本政治的看法。

二战后，他回到日本，投身于政治活动。请问，您是如何进入日本政坛的呢？

1952年，石原茂在众议院选举中当选。随后，他发起了规模巨大的“反美安保运动”。

这次运动虽然失败了，但却让石原茂一声大噪。

在这次失败之后，您对自己的职业有了新的认识吗？

我认为，那次才是我政治生涯的真正开始。

1955年，石原茂加入了自民党。卢文认为，这是偶然的吗？

卢文认为，这绝非偶然，而是当时日本政治格局演变的必然结果。

请问，您对自民党的成立是怎么构想的？

我原意是想通过反对安保运动来改变日本的。

后来我发现，只有成立一个强大的党，才能改变这种现状。

因此，在1955年之后，自民党也随之成立。

## 02 石原茂的价值观

在自民党成立这么多年以后，您现在对日本有什么怎样的看法？

我认为现在的日本已经迷失了方向。

现在的日本完全是美国的附庸，是一个没有独立的国家。

请问，您对现在的美日关系又是怎样的看法呢？

我认为现在的美日关系完全是不平等的。
