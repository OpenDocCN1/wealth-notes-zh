


# 二月：黄金与未来

限时

作者 失业阵期

# 前言

寻找市场错利中的机会

周五发布了三月黄金展望：三月避险、高涨、老牛回头市，是好机会还是长车呢？我的观点如下：

首先是西方市场，也就是基金团体内的市场预期。而且如此，目前的波动性是10%以上的，所以黄金与美元的关系有巨大的关系，美元强势将影响黄金的避险属性。

由于西方市场的背景本身没有那么重要了，黄金与通胀的关系才是关键。而且目前的通胀压力正在高升，黄金的价值也达到了前所未有的。

其次是亚洲市场，中国民众将黄金作为资产以保值，并对抗通胀压力。

不是这件事。在春节期间中国对黄金的需求增长过程中，黄金已经表现出强劲的动能，二月的周五的黄金数据显示了这利好机会，周五预测重心聚焦在下周：

- 一、一月非农，14.3万，低于预期17.5万；
- 二、二月非农数据高于10万；
- 三、失业率4%，低于预期4%；
- 四、工人时薪增长率和年率高于预期，新增就业人数58.9万，低于预期的82万。

从点来看2023年1月的数据，二三四五都是好，五比较好。西方市场的非农数据符合预期，但欧洲的非农数据意外好。德国的非农数据显示了通胀回升。

与此同时，英国的非农数据意外下降了7%，但其数据显示的通胀回升符合预期。

现在美联储的加息周期，为什么欧洲的压力更大？由于欧洲的能源危机，通胀压力更大。
