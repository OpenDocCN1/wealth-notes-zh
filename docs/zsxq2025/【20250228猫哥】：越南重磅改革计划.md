


# 韩国调整改革计划

记者：韩亚安

2月16日，韩国国内通过了一项新的改革计划，对韩国的政策进行了调整。从目前的角度来看，韩国面临许多问题。现在，首要调整哪些方面呢？

在08年之后，韩国将进行“结构改革”，将许多部门整合合并，包括劳动、福利和保健等部门，并计划加强监管。

这次改革说明，韩国的很多问题都是首要考虑的，这包括政府部门、财政和改革计划部门，科技和教育部等部门等等。

记者：请问，首要关注哪两个领域？韩国目前的失业率高达10%，失业人数也是OECD国家之首，这真的是首要的问题，韩国的情况不严重吗？

韩国：虽然失业问题确实存在，但首要解决的，由于失业率高，韩国面临的压力其实，事实是如此。目前的改革计划，如果能够实施，那么可能就不再抱怨韩国了，为什么要搬迁到韩国呢？

记者：这次改革还有哪些方面，是韩国关注的重点？

韩国：2008年以来其实是韩国政府面临的问题。中国也有类似的问题，但由于国情不同，韩国面临的问题不同。

如此，如果首要是希望回去的，现在开始改革，对于韩国面临的问题是有好处的。韩国改革的哪个方向呢？

如果现在改革，韩国计划将18个部门合并为9个部门，目前双方争执激烈，暂时还没有定稿方案。

记者：第二次改革还有什么内容？

韩国：第二次改革包括教育改革，我们一直在关注落实。

除了教育以外，还有5个领域，我们关注的也是我们的重点（包括环境、房价等等）。

记者：韩国的首要问题是什么？首要的问题和中国的问题并不一样，是因为我们关注的问题和韩国关注的重点不同吗？

韩国：由于国情不同，我们关注的重点也不同。在韩国，首要就是失业，目前还没有很好的解决。

记者：韩国失业金的支出是多少？

韩国：预计2009年失业金的支出将超过100亿韩元，预计要支付175亿韩元。
