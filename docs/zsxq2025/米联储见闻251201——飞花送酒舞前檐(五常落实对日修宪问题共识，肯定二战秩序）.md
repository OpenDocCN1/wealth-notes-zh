


# 米联储闻251201——飞花送酒舞前襟(五常落实对日修问问题共识，肯定二战秩序)

你好，我是米糕！

最近有点乱，今天还炸了一个群，东南亚因为一场台风，引印尼、泰国、菲律宾等多地出现洪灾和重大伤亡，各国死亡人数都是三位数以上，加上最近火灾不断，真是水深火热。日本这边降雨与仍在升级，并未降温，日本方面也未低头，大阪议会更是通过一个提案要求中国驻日大使道歉，气焰嵩张，并未低头。

高市这次上台就想给中国来个下马威，企图把小岛问题国际化，没想到中国借力打力，你要国际化，我就帮你国际化，但不帮你把小岛问题形成根源公布于世，顺便把小岛问题造成小岛问题的罪魁祸首搞了出来。说实话，别说小岛问题全球全世界都知道，但是很少国家和国际关注中国为哈密岛屿有主权，更不知道日本在这里面扮演角色，一直以为一小岛是什么专制对民主的侵略，压根儿不了解，小岛的主权问题是二战的一部分，所以这次日本主动跳出来说什么小岛有日本有事，让中国有机会在国际视野内，把日本的历史罪行再次抛出视野，已经被淡忘的历史再次回到公众视野，并将日本破坏战后秩序和复活军国主义之嫌糟在了世界面前。日本还没有把小岛问题国际化，中国会将此修问问题国际化，摆在各国，尤其是二战胜国，联合国五常国面前。

最近中国一个一个跟五常落实对日本修问问题的共识，毕竟五常之所以是五常，就是对二战结果的共识，如果你否定二战秩序，你不配做五常，你就失去了在联合国框架内制定游戏规则的权力，即使是美国天盟联合国，但也从不愿意脱离五常身份。俄罗斯因为俄乌冲突被一次挨骂，但是五常身份丝毫没有动摇，英法他们是守着这个身份不敢动，因为他们今天的经济实力和军事实力，早已备上上餐的实力，这是二战留给他们的政治遗产，如果作死者定下这个秩序，他们将被永远排除在全球核心权力治理层之外。所以，中国跟每一个国家落实对日本修问的态度，要他们确认对日本军国主义死复复到底是什么态度，必须每一个五常国家都要表态，并通报至联合国层面，看看中国外交部强强调的：绝不允许日本右翼势力努力历史否，绝不允许外部势力染指中国地区，绝不允许日本军国主义复活。如果日本想重走军国主义老路，最终只能失败告终，国际社会必须坚决阻击任何复活军国主义的图谋……从中方的系列态和行动来看，不仅仅仅是拒绝日本干预中国主权内政问题，更是借日本性破坏地区局势稳定、战后秩序和复活军国主义“三界”，并向五常确定他们接受日本的行为，并公开表态对战后秩序的态度。这样，将来日本发生冲突，这些国家就不能公然背离自己的公开表态。

实际上，如果把小岛问题作为中国的问题，则各个国家都插手，但是如果把小岛归于二战的历史遗留问题，这些国家想要插手就要考虑是否会危及自己的二战利益。

联合国本身就是建立在二战结果之上，为了避免日本再一次在世界上发动战争，为了惩罚日本的二战罪行，战后安理会制定了许多限制日本军国主义复和维护战后秩序的相关文件。

日本加入联合国后曾经多方废除这些文件，但是因为程序复杂，加上这些日本跻身 G7，几乎已经忘记自己曾是战败国的身份。日本近年来强化推动修宪强军，显然是有意在突破这些约束文件，也就是要挑挑战战后秩序。只是局势的复杂性以及美国出于战略需要的打包，使得这一问题无法引发国际社会的重视。日本多次试探，中国似乎都做出有效的遏，所以日本以为中国已经默默接受日本入海的事实，这次高市政府直接公开向中国叫仗，还称日本投资与中华人民共和国无关，这不仅违背了一个中国原则和小岛是中国主权不可分割的一部分这一联合国文件共识，更是在严厉挑战战后秩序。再加上推动对外出售攻击性武器以及叫要废弃无核原则，显然有复日本军国主义的意思。

随着中国把二战后针对日本制定的相关条款在全世界面前事实道理，日本挑战战后秩序和突破军事束缚的证据越来越清晰，西方国家也有意意识到了日本复宪问题的严重性。大佬集团尤其是在美国总统曾对台海问题敲打警钟之后，英法两国表示支持一中原则。

如果不是法国表示支持中国，预计这周的中国之行不会让他带来。马克龙访华前，王毅约与法国外长博纳诺通了电话，强调了日本首相高市早苗的言论是历史性倒车、损害中国主权和领土完整；博纳也表示，法国坚定奉行中国政策，理解方在台海问题上的立场。此外，王毅与英国首相鲍威尔通了电话，表示英国一守中国原则，希望与中国共同捍卫二战胜利成果。美国领导给予了积极回应，称理解岛问题对于中国的重要性，这是少数国家中极为积极意义。俄罗斯态度更加鲜明，俄罗斯发言人扎哈洛对日本在西南部署武器担忧，基本上与中国处于统一战线。这番话还有一个隐藏信息，那就是告诉日本，能引发敌对条款，必要时，俄罗斯会和中国一起采取行动。

，王毅也将前往俄罗斯参与中俄年度安全磋商，考虑到高市早苗和日本国内右翼和军国主义抬头的问题，两国采取更加针对性的行动。中国在联合国向多个国家发函，明确了高市早苗的立场。可见中国不管取什么行动，力度有多大，都要让日本真正感受到付出的代价。但这并非唯一的目的，中国要实现一个非常重要的目标，就是清除多年来关于岛链的叙事模式，连根拔起，作为胜利国，中国拥有核心利益。

从2012年安倍第二次担任首相开始，日本就在国际上进行一系列洗白，首先将自己打成战争者的形象，反复强调对日本造成的影响，其次将自己打成西方意识形态的关键员，最后将自己打成国际秩序的捍卫者，作为一个胜利国，世界也几乎忽略了日本积累。安倍还提出保安构想，日本与澳洲、美国、印度构成针对中国的钻石型包围圈，这个圈就是太平洋战略并直接生效四国安全机制 (QUAD)，尤其是普普上台后，就是安倍说服川普对中国采取强硬立场。此外，还推动廉价价值观，加强与欧陆、东南亚的联系，将西方势力推进进中国的包围圈，筹备亚洲盟，恢复最初的功能；由于东南亚和欧洲是中国两个重要的伙伴，日本不仅要在地上遏制中国，还在经济上打压中国。大佬集团同时设法禁集体自卫权、强化军事力量，在历史和领土问题上挑衅中国，为更多域外势力干涉亚太制造；英国、法国派出航母，德国派出军舰，到亚太活动都跟安倍下的政策有直接关系。可以说，近年来中国面临的安全恶化状况如此，日本确实肆无忌忌。如今，安倍自己受到了应有的惩罚，一条弹刺穿了他的肺部，加上下属的心肺复苏，让他的肺部血如涌，实在实在，他的死配得上他的犯罪。

现在高市早苗直接对中国发出了武力威胁，以二战战败国的身份威胁五个大国家，挑战胜国的国际地位，甚至颠覆国际秩序。日本政府试图以所谓共同价值观来掩盖军主义立场，现在已经藏不住了。作为一个借尸还魂的傀儡，安倍还没有活路，高市会用自己的法给全世界打版。

米糕祝各位晚安。
