


# 一场狗血婚外情，为啥成为舆论焦点

嘉宾供稿

最近几天，2位“董小姐”成了舆论热议的焦点。

前有格力董明珠关于“绝不用海龟，海龟里有间谍”的言论引发全网争论，正在大家津津有味吃瓜的时候，北京海龟“董小姐”一上场，格力的瓜瞬间就没甜了。

本期内容，我们谈谈北京“董小姐”的事。

先从一场狗血婚外情说起：

4月18日，北京医院眼科副主任医师向北京中友好医院实名举报，其丈夫肖飞多次内出轨，并意图非婚生子。

举报信的大致内容有2点：

一、作为北大医学博士、中日友医院胸外科副主任医师的肖飞，从19年开始，婚内出轨多人，包括同院护士长石某（曾为其2次流产），规培医师“董小姐”（已怀孕待产）及其他多名医护人员。

其二、除了私生活极度混乱外，还暴露了2起医疗违规事件：

1、2024年6月，肖飞利用职权将本应岗位至脊柱外科的董小姐留到本科室，继续方便“照顾”。这次举措当时引发了骨科教学秘书麻医生的公开反对。（当然，现在这位晚上玩诸胆的麻医生也因此意外走红，被誉为医疗界的一股清流）。

2、2024年7月，在手术室，董小姐因操作误遭护士批评，肖飞冲一怒为红颜，竟然擂挑子，将已麻醉患者遗弃手术台长达40分钟。

4月27日，中日友好医院发布情况通报，对于举报材料核实，结论是基本属实，根据相关规定，对肖飞予以开除党籍，解除聘用关系的处分。

在处分决定通报后，肖飞也做了回应：

- 1、承认和护士长、规培医师存在私生生活问题，但否认还有小五、小六的说法。
- 2、对于手术室冲一怒为红颜的事情，予以否认，给出的理由因为发生激烈争执，导致头晕、手抖情绪波动大，为了手术安全起见，需要调整身心状态。

说实话，关于个人的私德问题，社会上类似的例子多如牛毛，不足为奇。关于医德的问题，听起来吓人，但实际上发生在手术室的故事也不少，我甚至听过饮酒上手术台的事。

换句话说，单凭肖飞的私德和医德问题，掀不起如此大浪，真正把事件推向舆论风暴眼，冲上条热搜的是肖飞的“小四”董小姐的履历，这也是本期内容的重点。

这里还要感谢中国网友对内容的能力实在太强了，让我们能看到这场狗血剧背后触目惊心的现实。

这位25岁的“董小姐”本科毕业于哥伦比亚大学巴纳德学院学院经济学，2019年进入了北京协和医院“4+4临床医学试点班”项目。

上面看似简单的一履历，其实几乎等同于大部分医人的天花板。为啥？

首先，北京协和医院在中国是什么江湖地位。业界有“东齐鲁、西华西、北协和、南湘雅”这一说，也就是说北京协和医院是中国最顶尖的四大医院之一，可想而知要进入这个门槛有多难。

其次，“董小姐”毕业的不是我们传统理解的哥大，而是哥大的一所独立学院。这家巴纳德学院到底水平如何，我们不去评判，但是资料显示，2019年协和“4+4试点班招生简章”中，虽然哥在大，但巴纳德学院并不是公布的生源学校名单中。而在2019年，协和4+4共计国内招生规模有多大呢？大约就不到20人左右。

所以，问题来了，“董小姐”当年是如何靠半真假的学历，挤进如此稀缺的协和医院的4+4试点班次呢？

当然这还不够魔幻，我们接着看她医学学的历程。

2019年从经济学跨界到医学后，指导老师是骨科院士、学的内科，工作是泌尿外科，规培是胸外科，毕业论文是影像学。要知道，2020-2023年期间我们经历了什么，甚至有说法，这期间，搞不好有很长段时间在上网课。

不仅如此，更炸裂的是，“董小姐”30页的论文获得了博士团队的背书，而且在学习期间，还成为膀尿瘤临床指南第一作者。

这件事有多不可思议的，网络上有业内人士做了这样的一段评述：

“膀尿瘤治疗指南一般来说是给业内人士看的指导性内容，一般参与指南编写、讨论、审阅的，基本上都是泌尿外科科内知名专家。刚跨界到了泌尿外科就能第一作者这样的指南性文章，里面的东西，我就不说哈了。

说实话，“董小姐”的这段医学历程，都不能用“六边形”战士来形容，妥妥的就是医学界的“天才”。我们国内三甲医院，要拿到的医学博士并上手术台，没有10年以上学习实践经历是不可能的，但是“董小姐”却通过协和医学学院4+4 培养模式用几年时间就走完了别人10年的路程，并且成就斐然。”

其中道道，不说不知道，一暴露其实大家都懂。没由背后的资源赋能，是不可能的。

现在网友扒出来其家庭背景，“董小姐”的父亲是某某建研究院总总经理、党委副书记、母亲北科大某院副院长长。

有人说，这背景和医疗界不搭界呀！这句话的朋友可能就太单纯了，很多时候权力和资源是可以相互交换的。

还有人说，不是说“劝人学医，天打雷劈吗？”国外混个经济学文凭，干嘛回国不去从事金融相关的呢?来钱快还轻松。
