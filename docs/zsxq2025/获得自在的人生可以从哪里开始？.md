


# 获得自在的人生可以从哪里开始？

想要自在的人生，可以从放下别人对你的要求做起。回归到我真正需要什么。倾听心灵和身体的声音，这个声音往往的是真实的。

这是我总结佛、道、西方灵的心得体会。

很多人不懂这一点，即使你再怎么修，也很难得入。

记住，任何对你的要求，总是对他们有利，未必对你有利，虽然常打着为你好的旗号。

比如过节家里临临逼婚，你一定要学会放下，拷问自己是否需要。如果不需要，你已经表达意见，但他们还没有完了，这些的行为其实是在对你施行语言暴力（本质是施暴），你可以选择回击（好不要选这个），也可以选择回避（这个不错，下楼倾倒垃圾吧）。但你一定要做些什么，什么都不做，配合强奸没有任何区别。

再比如，你一方面常常抱怨念生活苦，另一方面非要攒钱买房。其实常常的抱怨是你真正的声音，而死磕买房看似是你的自愿，实际上是社会意识对你的强奸（你也是施害者）。

或者换个说法，“别人都买房了”这件事，通过你扭曲的思维方式（别人有，我也要有），成了你的执念。然后这个执念压抑了你真实的想法。

如果你目前的人生，不仅仅是这一条压抑你，而是有很多条在压抑你，你不能苦吗？

在这里其中，问题出在你的思维方式上，你应该质问“别人有，我也有”的合理性。

你会发现，别人有，和你也该没有任何必然的联系。你也应该建立在你想不想的基础上，而不是建立在别人没有的的基础上。所以，在这些中，你才是对自己施暴的主体。

就像《武林外传》经典的桥段：

到底是谁杀了谁？

是我杀了我~~
