


# 米联储闻250807-鼓行而西破犬戎（印度骑马梦碎，川普俄俄罗斯打印度）

你好，我是米蜡。

印度的美国梦终于还是破了，先有巴基斯坦空中挑下印度坠阵风战斗机，然后是川普大棒槌让印度彻底地从美国梦中惊醒。发展中国家就是发展国家，早被 G7 追逐的好梦一旦醒来，才知道自己并不是什么美女还娇，还是那个光脚瘸的破落户，最后顾四周，还是要把光荣投向中国。

川总昨天发布了几个重大消息，虽然威胜了俄罗斯，但实际上大棒直接打到了印度梦上：从8月7日起向印度额外征收 25%的关税，加上购买俄罗斯石油的惩罚，额外再征收 25%，等于征收 50%的关税。一下去，美印关系彻底打回原形，跌到冰点。

曾几何，无论是民主党还是共和党，印度作为对冲中国的超级人口发展国家，都是战略意义上的香饽饽，每次说印度的人口和人口年龄结构，就好像印度抱了一个大金矿一样。但是随着这几年产业转移，印度看不到高回报的期待，印度基础设施的短板无法支撑资本快速回报的诉求，发达国家对印度的态度开始从积极拥抱变成了消极应对，甚至是有些窘弃。

虽然川普在第一任将奥巴马政府时期的亚太战略调整为印太战略后，川普本人更是亲自访问印度，让印度加盟美日印澳四方安全联盟的一员。美印还签署了《地理空间合作交流与合作协议》（BECA），后被泛认为是双方已经是准军事同盟的关系。莫迪在主政印度以来频繁访问美国，川普第一任时期，莫迪在2017年和2019年两次访问美国。拜登政府时期，2021年9月、2023年6月、2024年9月访问美国。2025年2月，川普上任后不到一个月，莫迪访问美国，是继总理、日本首相和英国王之后，特朗普访问的第四个国家领导人。美国最多的发展中国家，莫迪和莫迪身后的印度一度因为西方国家的高傲看一眼，悔慌印度已经跻身为全球强国之一，印度再度加入金砖却是旧事，印度真正的位置在 G7。

随着美国调整全球外交战略，“没用的都给我滚蛋，不交保护费的都靠边站”，从来是想便宜不想出力的印度一下就变成不受待的破落户。再加上巴基斯坦空袭直接被击落了6架战机，川普更是新闻发布会上公开嘲笑印度“左一架飞机，擎右一架飞机”，嘻嘻哈哈哈哈的。印度气哭了，莫迪气了，但美国也清醒了：指望印度制衡中国，还不指望日本，印度根本不合流，还指望美国要跟印度做朋友——一个连巴基斯坦都不赢不了的印度有什么军事战略价值。

印度也知道普川上来不是来者，2月莫迪访美期间印度就开始谈及关税问题。当时为了弥合贸易差，印度计划和美国达成十亿美元火箭贸易，进口更多美国石油和天然气，以缩小两国贸易差，并设定到2030年将贸易额翻一番到5000亿美元的目标。

目前，美国是印度最大的贸易伙伴，但是两国的贸易额并不是特别高。2023/24财政年度双边贸易额约1180亿美元，印度差距320亿美元，是中国的三倍有余；但是是考虑到中美贸易总额才222亿美元，印度这个点钱挣得不容易。印度近年来来竭尽中美对抗的地缘政治糖，一边利用新兴大国的身份在西方世界备受宠爱，一边利用和中国关系不稳定的标签填补西方与中国脱钩真空留下的空白。

太美的印度莫迪认为自己已经是大师，是可以跟中美分庭抗争、上桌的局人，结果遇到川普这个泼货王，毫不留情撤下印度的垫脸——盘子咖喱肉沫，学什么大国崛起。川普对日欧尚且毫不留情，更何况印度这种种朋友，做菜都嫌味。在川普看来，新兴国家都是国际秩序的挑战者，中国是同样。2024年1月，川普曾开威胁要求金砖国家放弃美元替代的计划，否则对任何国家加关税。2025年7月，美国与日韩欧等盟达成关税协议后，对印度加额外50%关税，对巴西加50%关税，南非加30%关税。8月8日凌晨生效，除了中俄，几乎都是新兴国家被美国下手，可见美国很懂，这一轮要对新兴国家动手了。用美元换来了美国，印度等国家终于明白，只有跟着中国才有真正上桌的机会。想要抱发达国家的大腿，始终都是空欢。50%的关税将印度置于美国仇人的行列，让其加入了巴西。这意味着能够抱美国，巴西获得了同样好处，相比之下，印度却是手空空，既接不住中国的产业转移，也从雅鲁藏布大坝让莫迪发现，从雅鲁藏布嘴里捞不到。

今年2月，莫迪在白宫与川普见面时，表示印度有意为世界上最发达经济体之一，并将美国视为合作伙伴。川普的话就是“让美国再次伟大”——简称MAGA。当美国和印度握手合作时，川普露出了深长的笑容。川普当时的内心大概是：一个过去只能当贱奴的国家，居然还想让我美国当爹？你算个什么东西，还要跟美国再次伟大？这个言论从内到外听到，一个中国发展起来就让美国烦了，莫迪当时川普的操作是让印度看清楚自己是个什么东西。虽然美国想要控制中国，但是印度可能还比中国崛起更难受。

过去，美国之所以重视印度（尤其是拜登政府），是因为希望印度承接中国的产业转移。但是现在对川普来说，产业都要撤回中国，印度跟中国一样，不是朋友，而是竞争对手，哪里还有脸色？相比之下，生产成本更低的印度是比中国更讨厌的竞争者，所以关税也必须更高。只有增加印度制造成本，才会驱逐资本回到美国。想法一样，优劣互换：过去是印度优势的人口多、成本低、发展空间大，如今都成了阻碍美国再次伟大的不利因素。不打你准呀！如今25%的关税已高于越南、日本和韩国等亚洲竞争对手，严重削弱贸易的可性。加到50%的关税，基本是判断制度造成了局面。印度制造中拥有世界级的优势，每年对美销售超过100亿美元，也是印度重要项目。川普表示，将在“周左右”宣布对该行业加征一项可能高达250%的特别关税。作为众多在印度投资的美国企业之一，最近在印度一家工厂投资了30亿美元，印度生产的手机占据美国采购量的40%。如果关税加到250%，几乎可以彻底堵死印度的制造业。如果看到这一步，美印之间就真的亮梁子，没有银子了。

在这种大环境下，时隔七年，莫迪月底再度访华出席上海合作组织峰会就不难理解，这是他自己2018年以来首次访华。这次莫迪访华给中两国领导人会晤创造了可能，潜在在会晤中讨论的议题涉及及推进关系正常化，包括缓解边境地区紧张局势、恢复直航、重新开放贸易边界以及加强人员交流。莫迪上次访华还要追溯到2018年4月，当时他人在武汉出席中领导人非正式会晤。实际上，这次中国宣布开修雅鲁藏布大坝已经意味着中印关系的缓解。从过去几个月，两国外交长、国防部长和高级外交官，以及边界关问题特别代表、印度国家安全顾问与中国外交部长王毅举行会晤，达成为一些建立信任的举措，例如恢复凯什米纳罗尔姆圣址。印度自7月24日起，隔五年首次恢复对中国公民发放签证。7月，印度政府智库（NITI Aayog）提议恢复直航。反复无常，难以避免的。
