


# 如何识别银行设置的理财陷阱？

今年有一个很有意思的现象：A股涨得不错，但中国人的钱却没留在股市里，反而大家都去理财了。

根据权威媒体披露的数据，今年二季度，银行理财单增量几乎追平去年全年。到三季度末，全国理财产品的存续规模已经达到 32.13 万亿，同比增长 9.42%。

为什么中国百姓突然更喜欢理财了？这个不难理解。现在银行存款利率越来越低，而不少理财产品面上写的收益看起来还是挺吸引人的。再加上固定收益理财大多投向同业存国债，看上去风险不高，于是很多人自然就会买入。

但问题就来了，第一财经最近连续发了两篇深度调查，把银行理财这波高收益背后的秘密全给扒开了，结果让很多人都惊了。这些看似稳健又高收益的理财产品，真实的收益却完全不像宣传的那么高，背后充满了猫腻。

今天我们就来系统拆解银行理财的收益到底是怎么被包装出来的，我们又要应该怎么去识别那些银行设置的理财陷阱，知道这些对你的钱袋子绝对有用。

## 银行理财的高收益假象

到底是怎么被银行给包装出来的？其实方法并不复杂，初级的就是有种注水方式：第一种发生在展示端，第二种发生在收益端，第三种藏在理财说明书里。

### 第一种展示端注入：
如果大家去买买理财就会知道，银行展示给你的产品收益通常都是这种：某某理财成立以来年化收益3%以上，过去一年年化收益4%以上。但你要是真买了这个产品，你未来的收益应该是最近一个月或者最近三个月的产品收益，但这些数据，银行通常都藏在难找的地方，不让你看到。因为很可能最近一个月收益就只有 1%。这就是所谓的理财收益展示极端注水，用过去最亮眼的一段历史收益，把现在的暗淡遮掉，给投资者制造一种收益错觉。

### 第二种就是往收益端注水：
所谓收益端注水，指的是短时间内做出一段非常高的收益，通常叫“打榜收益”。很多新发理财产品刚上线的时候，银行通常采取这种策略，把收益拉的很高，目的为了让自己的新产品迅速冲上收益榜、热销榜，让客户看到买进去，等产品卖得差差不多了，收益就迅速回落了。

### 最后第三手段：
就是用理财说明书里动心思。有些理财产品的条款被银行设计的非常复杂，一般人都看不懂。比上上一个条款写的其实还是“不收取超额业绩报酬”，下一个条款就又写了：“若份额持有期间，年化收益率超过业绩基准区间中枢，将超出部分按 20%的比例提取超额业绩报酬。”

这就纯粹是设置文字陷阱了。银行的目的就是为了收取 20%的超额业绩报酬，割投资人一刀宰了。通常银行会将所得的基准中枢收益设计的很低，只要偶尔资产表现好一些，银行就可以用这个条款抽走大家 20%的回报。但投资人根本不知道这里头的猫腻，你要是跟银行较真，问问他具体怎么收费，银行会丢给你一大串你根本看不懂的公式，还会用投资端、产品端的各种神术把你绕晕，反正你就是弄不明白的。最后的结果就是，你拿到的投资收益根本不如他们给你宣传的那么高。

前面这3种理财产品收益注水的方式都比较初级，都是些银行要耍的小手段。但是银行现在又发明了一种更高级的玩法，叫“信托 T-1 估值套利模式”，这个就相当厉害，基本上能做到割客户于无形。

大家知道，我们平时买基金都是净值申购的，你今天买按今天收盘后的净值算。但部分银行信托专户采用的是信托专户的形式，他们的规则是：你今天买理财，可以按照前一天的价格结算；你今天赎理财，也可以按照前一天的价格结算。这种就叫 T-1 模式。

这个规则就被银行拿来分配收益。比如今天收盘以后，投资经理其实已经知道了今天的资产价格是涨还是跌了，但是制度允许他们用昨天的价格来确认今天的申购和赎回，于是操作漏洞就出现了。具体来说就是：假如今天资产涨 1%，银行已经知道涨了，但因为有 T-1 规则，所以银行今天出来的新产品让客户用昨天的便宜价格来买，新客户买进去立刻看到自己赚了钱，很开心，但今天的涨幅实际上应该是老产品的；但是银行为了捧新产品、短期高收益，于是把老产品的利润挪给了新产品。

再比反过来：今天资产价格跌了 1%，银行知道跌了，却是允许新产品可以按昨天的价格赎回，结果今天的亏由老客户承担了。这种操作让银行的新产品又成功地完成了 KPI 考核，在榜单排名上数据亮眼，吸引更多的新客户。但实际上，他们用的手段还是欺骗，为了完成自己的绩效，把压力转移给了这些部门和底层资产，制造了收益幻觉，最后收割了客户。

## 如何学会避开理财的坑

那么对于普通百姓来说，买理财还能避开这些坑，学会这3招：

- 第一招：永远看三个月的收益，确认是不是 T-1。
- 第二招：看清楚条款，收不收超额业绩报酬。
- 三招：看这个产品是不是爆款。

如果你看到这些词：稳健、短期暴涨、热门排名，就要自动反应：这是银行出来的假象。

现在的银行理财规模，平均年化收益率为 1.6%。但是近三个月新发的理财产品中，成立以来年化收益率超过 10% 的有很多，其中中风险的理财产品年化率大于 10%，一个月收益率只有 0.82%，明显是故意拉高。后期走来，真正低风险的理财能做到多少收益？存款利率只能做到 2%不到，3% 就不符合逻辑。
