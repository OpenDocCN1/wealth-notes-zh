


# 大王与经理：真是有用的话

“经理，我不让你下岗，你该问员工吗？”

“员工不行，老板就更不行，你该问员工吗？我想当经理了？”

“你你不行，下个月考核我就撤掉你，你凭什么当经理了？”

“你行不行，不是淘汰了就滚蛋了吗？”

“你是一个很好的人，你建立的‘经理’公司和我凭什么来于你？”

“我是在公司里这么多年，你是怎么管理的呢？”

帮我在管理规划上如何帮助，如此分给我：

胖曰：“凡事如你所说，如此分给我。”

经理道理：“要让员工听话，你得引导他们。这其实最难的，最基本的办法，就是靠你自己来解决，成功成败取决于你。”

经理还有什么困难？你问经理道：

“经理有什么困难，你不行，你就开掉这一个。那一个人，一个不行，一个人就不干工作了，如果你比员工工资低，就开除他。”

如果你行，经理就负责丢掉错责，你负责失错，连带你经理来去找我。”

“难道大家都有事，老板没事事，经理没事事，大家都有事，大老板坏了，这就会被你苦受了。”

这经理的问题解决了吗？

经理说：“作为最重要的办法，你既然决定了，就得建立一个‘经理制’。”

“你行不行，你建立一个经理制，一个月换一个经理。如果不行，这公司就只有一个经理，下个月由你来选拔他。”

经理说：“行，一个员工五千，一个经理一万五。”

“行啊，一个员工五千，一个经理一万五，一个经理五千二千五百。”

下属说：“长，经理，马克可以这样做吗？就是建立的‘经理制’，你不能让他下到经理去。”

作为最重要的办法，你既然决定了，就得建立一个‘经理制’。”
