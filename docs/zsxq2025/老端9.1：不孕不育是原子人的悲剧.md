


# 不是我们，而是孩子的理想模样

2023-09-01

上周，我接手了一个班级，初级学生。班级今年只有二十个学生，这个班并不算小，但这也是对的。2022年我们班有27个学生，平均两个孩子，有的多到2、3、4、5、6、7，记者还是来二。

孩子好不好，其实取决于父母的教育。父母的习惯，会影响孩子的成长。父母的观念，会影响孩子的未来。

现在的孩子，真不容易。他们要上学，要做作业，压力很大。现在的父母，也有压力。如果父母把压力都传递给孩子，那孩子就更累了。

现在的孩子，真不容易。如果父母在焦虑，如果父母在犹豫，孩子就会更加迷茫。我们真的需要一个这样的父母吗？

## 走进孩子的理想模样

但是，现在的学生，真的有梦想吗？如果没有梦想，他们如何去规划未来？如果没有梦想，他们又怎么可以实现梦想呢？

一个国家如果没有梦想，这个国家将会强大吗？如果一个国家没有梦想，这个国家又如何变得强大呢？

所以，我们应该给孩子建立梦想。但是，我们如何给孩子建立梦想呢？我们该如何引导孩子发现自己的梦想呢？

如果孩子没有梦想，他们的人生将会变得怎样？如果孩子没有梦想，他们的人生又如何变得精彩呢？

我想，父母应该学会放手。父母的梦想和孩子的梦想产生冲突。作为父母，我们要如何引导孩子发现自己的梦想？

我们应该学会允许孩子犯错。错误是成长的机会。只有允许了孩子的错误，孩子又怎么可能找到属于自己的道路呢？

我们应该学会支持孩子的失败。失败是成功的垫石。只有支持了孩子的失败，孩子又怎么可能找到属于自己的成功呢？

最后，我们应该成为孩子的父母，而不是孩子的控制者。成为孩子的朋友，孩子才会愿意向我们敞开心。
