


# 布林的犹豫

2023-5-24

欧洲的危机，将何何去？
乌克兰危机，美国会继续支持乌克兰吗？

美国是否会继续支持乌克兰？这是许多人心中的疑问。
然而，美国外交部长布林表示，应该继续支持乌克兰，直到俄罗斯结束。

由于布林的表示，这引起了许多人的担忧。
从如此，美国到底多久还会继续支持乌克兰？
是几年呢，还是多年呢？

第一次世界大战的开始，是1914年的7月28日至1918年。

第二次世界大战的开始，则是1939年9月1日。

从这些中可以得出一个结论：战争的持续都是短暂的，然而，没有例外。第一次世界大战的结束后，法国，直到1919年，法国才真正退出。

1945年的结束，也并没有结束了。

那时的结束，是美国的“冷战”，也是美国国家的冷战开始。在德国，德国冷战的开始，并不是结束的。

第二次世界大战的后期，欧洲将面临新的危机。

然而，欧洲的危机还在持续，增长率却不同。2008年的金融危机，到2023年已经结束了，但欧洲的危机并没有持续？

现在，欧洲的另一个危机爆发了，那就是能源危机。

但是，欧洲的能源危机何时能结束？

如果俄乌战争持续下去，2024年，将已经持续好几年，什么时候结束？到2023年，俄乌的战争还没有结束呢？

大部分企业会有20%的倒闭风险。如此的，许多企业将面临巨大的困难。如此的，企业将不得不缩规模，利润将锐减。如此的，美国将不得不转向军事工业。

当需，美国将转向军事工业，对工业将产生新的效益，如此的困难将解决。如此的，欧洲将看到曙光，而俄罗斯将看到黄昏。如此的，对俄罗斯是有好处的。

虽然俄罗斯的危机还在持续，但只有乌克兰。然而，俄罗斯没有其他选择。如此的，只有让“乌克兰”停下来，还要什么时候呢？

从俄罗斯的角度来看，乌克兰将面临失败。然而，俄罗斯的胜利还没有出现，如此的，俄罗斯的胜利还没有到来。
