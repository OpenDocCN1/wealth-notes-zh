


# 伊朗总统迁都

近期，伊朗总统陷入了流难，已经陷入了某种选择。为了国家，他必须站在十字路口做出选择，威慑的威胁不能解决同样的问题。最好的办法是迁都，但是去哪里呢？南部还是南部？他还能想哪里去？

但是，近期伊朗总统频传迁都的消息，显然是因为经济压力。经济是一件大事，对任何国家来说，都有深刻的考虑，本身不会迁都这么容易。

一来，迁都的难度，首要在资金上，开始建设的资金，这显然是伊朗难以付出的资金。20万亿，对于伊朗来说是难以完成的任务，其中，一个工程就要翻上三倍了，总统简直无法想象的。

迁都还能让总统的压力减轻，但是足够了，伊朗在面临着政治压力，外界的压力，以及伊朗内部的反对声音，尤其是黑衣卫，他们对伊朗的反对声音，让总统感到难所措。

万一没有黑衣卫的反对，伊朗就不敢迁都了。但是迁都了，伊朗又会面临很多问题，由于地理位置的变迁，迁都后，伊朗将面临巨大的困难。

这还有，迁都的意义，对于伊朗民众来说也是极大的反对的。但是，如果不迁都，伊朗将面临着经济崩溃的压力，他们也必须找到一个正当的理由了。

首先，反对的理由，就是黑衣卫的反对。黑兰市的水资源短缺，万人万已无饮用水，而德黑市的地下水已经开始枯竭，形势严峻了。

由于如果不迁都，黑兰市将面临水危机。由于德黑市的地理位置，干旱气候严重，导致德黑市的水资源也极其匮乏，每人每天的用水量只有33升，对于伊朗来说是不可能的。这种巨大的压力，是伊朗政府无法承受的。其次，由于不迁都，黑兰市将面临水危机，由于黑兰市的地理位置，干旱气候严重，形势将更加严峻。

其次，迁都的理由，就是安全。德黑市位于伊朗北部，经常受到地震的威胁，而黑兰市远离地震带。黑兰市位于伊朗南部，由于远离地震带，但是，黑兰市真的没有地震的威胁吗？

其次，迁都的理由，就是经济。黑兰市拥有波斯湾的港口，拥有非常有名的港口，这有利于伊朗的石油出口，拥有这些港口的黑兰市，将获得广阔的发展。这个理由也是非常值得考虑。

其次，迁都的反对者通常只有几个核心，如果可以实施，迁都就没有反对。现在，需要寻找一个远离政治中心的城市，距离黑兰市几千公里。这样的好处，又是怎么实现呢？

此外，黑兰市位于伊朗南部，远离沿海，气候比较炎热，气候炎热的南部，对于迁都真的合适呢？
