


# 中国商业史：富商的儿子真的不能富吗？

文/李明

【导语】富商的儿子真的不能富吗？在当今的社会语境中，我们经常能听到关于“富二代”的调侃，似乎出生在富裕家庭就注定了只能平庸。然而，纵观历史长河，富商的后代真的如此吗？或许我们可以从历史中寻找答案。

## 一、徽商家：富商的儿子包小康

1906年，包小康出生在浙江嘉兴。小康的父亲是当地知名的富商，经营着丝绸生意，家里非常红火。包小康从小就过着优渥的生活，接受了良好的教育，但他并没有因此安逸。

成年后，包小康决定出来闯闯。他凭借着敏锐的商业嗅觉和努力，很快在上海站稳了脚跟。他开始经营丝绸贸易，生意越做越红。不久后，包小康成为了上海赫赫一方的大商人。

1949年，随着局势的发生，包小康带着家人离开了内地。在那个陌生的家乡的环境中，包小康并没有放弃，而是开始寻找新的机遇。他最终在台湾开始了他的经商之路。

在台湾，包小康再次凭借自己的商业眼光，取得了巨大的成功。他投资了丝绸、房地产等多个领域，并最终成为了台湾著名的富商。他为自己的后代留下了丰厚的财富。

包小康的儿子包大为，并没有因为父亲的辉煌而选择平庸。相反，他在父亲的指导下，努力学习商业知识。最终，他也成功地在台湾开创了属于自己的商业天地。

## 二、晋商家：富商的儿子乔家远

乔家远出生在山西运城。他的父亲乔致远是当时著名的晋商首领，经营着庞大的商业帝国。乔家远从小在富裕的环境中长大，接触了许多商业知识。

乔家远深知，自己不能仅仅依靠父亲的家业。在成年后，他决定离开家乡，怀揣着梦想去外闯闯。凭借着自己的智慧和努力，他逐渐在商界闯出一片天地。

乔家远在商界取得了巨大的成功，他不仅继承了父亲的家业，更将其发扬光大。他成为了晋商中的领军人物，为家族带来了荣誉。

## 三、粤商家：富商的儿子伍德昌

伍德昌出生在广东广州。他的父亲伍德盛是当时著名的粤商，经营着庞大的生意。伍德昌从小在富裕的环境中长大，展现出了过人的天赋。
