


# 刚刚关注越南

在8月发布的最新数据显示，很多人都惊讶。但是这并不意外吗？2024年上半年确实发生了一次大转折：美国（40%）、加拿大（40%）、越南（39%）、阿尔及利亚（35%）、墨西哥（30%）和中非地区（30%）。

在这些国家，中国市场已经不再如意了。2024年中国在美市场的份额仅为31.8%，这比去年缩水了很多，这种趋势正在变得非常明显。

到底发生了什么？是因为美国需求减少了还是供应链转移了？

2024年中国在美市场最大的竞争对手是越南（22.8%）、墨西哥（22.7%）、日本（10.2%）、9.5%）。这些国家几乎占据了原本中国在美市场的份额。

然而，越南的增长真的是因为供应链转移吗？还是美国需求增加了？

但是，墨西哥也增长了40分之二，这说明并不是美国的需求减少。这种波动结束了，基本面已经稳固了。

这就告诉我们结论：其实是供应链转移了。但是，这种转移是从哪里转移到哪里呢？

在这些国家，中国的市场是安全的。

所以，越南和墨西哥的增长是一个关键的信号。但是，由于、加拿大、泰国、印度也在增长，这说明了什么？越南和墨西哥的增长并不是意味着供应链全部转移了那里。

那么，越南和墨西哥的增长是不是意味着美国需求减少了？如果美国需求减少了，为什么阿尔及利亚、印度、墨西哥也在增长？

所以，我们看到的是美国需求并没有减少，而是中国在越南、墨西哥、印度等地转移到了其他国家。

**最后，并不是中国在美市场份额减少，最让美国担心的是，越南现在面临着一个问题，有几个棘手的问题。**
