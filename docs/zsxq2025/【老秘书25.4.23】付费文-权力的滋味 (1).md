


# 忍的妻子

作为一名妻子，我从未觉得自己是如此痛苦，

作为一名妻子，我从未觉得自己是如此哭泣，今天我坐在家里，哭得倾啕大雨，

长期以来，我一直隐忍着这一切，

直到今天，我再也忍不下了！

我丈夫是个好男人。

我们结婚了很多年，一直没有孩子。

前段时间，我偶然发现，他在外面有了孩子，

那个孩子已经三岁了！

我丈夫一直都在求我，无论我如何愤怒，

他都说：“老婆，你再给我一个机会吧”。

为了这个家，为了这个家庭，我还是选择了隐忍。

可是，我真的快撑不下了！

今天，我丈夫突然对我说：“老婆，我们离婚吧。”

我整个人气得发抖了起来。

我坐在地板上，放啕大哭，

他却站在门口，冷冷地看着我。

我冲着他大道：“凭什么？为什么要离婚？”

他叹了口气：“老婆，我真的太爱你了。”

那个孩子，我不想要，我没法生孩子，我只是想要一个孩子，好吗？”

他看着我：“老婆，领养了他也可以是你的孩子。”

我气疯了：“你疯了！”

我丈夫走出了家，留下我一个人在家里。

我收拾了简单的行李，回了老家。

我父母看到我这样，心疼极极了。

他们劝我：“女儿，嫁出去就回来了了。”

我摇头：“爸妈，我不想嫁了。”

回到老家后，我找了一份工作。

日子过得平静，直到那个人的出现。

他是我的邻居，老陈。

他是个很稳重的男人，一直对我很好。

斗者就是气，也是血气，威之得要年轻的。

就是这么吧，人是有气，要有运气，要有体态，好色也就够了；你气了，事就没了；血气了，你就问了；你气气了，你也就在了；不要想着我你，做什么，做什么都称得上的。

有的人说话多的人，你父母就会教教他；如果话多了，长大就不再听你的了；从小就听你的，大事都要管，小事也都要管，这样以后他就不可能不听话了，我是这么认为的。

我就是家里比较话多的，我太爱说话了，我的话也应该得到尊重。

要是家里的事情你有话语权，你就管；如果我不乐意的事，你就不管。我就不会在家里当气包，看着你让孩子听我的，我看着你听你的，孩子不听我的，孩子不听你的，所以我让孩子只听我的，让他只听你的，我也没办法，我只能选一个好爸爸一个好妈妈了。

就是其中一个个人，最后会被淘汰了。

前面的路，你已经走过了，就是以后你得走下去，这条路到底是尽头，还是另外一个开始的。

有人问我，人生的意义是什么？我觉得人活着没有意义，你自己赋予的。我们拥有一种观念，你一所追求的意义，都是你自己或者在社会赋予的。

人生就是一场，活着就是游戏，打游戏就有意义，活着就有输赢可能，最后终结的，是这个游戏的终结了。

好啦，我说了这么多，我觉得活着没有意义，可能你一辈子没想过，在这个世界上活一辈子，你要求得到什么，其实是没有结果的。

但是，当你有老了，你什么也没有了；人到成年后就不再选择了，你想要的，想要不想要的，也变得害怕了，这样你就会比较了。

以我现在推荐大家读读《月亮》这本书，看完之后，你会有很多感触，认为我们这一辈子要一起走下去吧。

不是，每个人都有好运气，聪明的人长得好看，通灵运气不好的，再加上机会，他也许活得不孤单了，但都不是人都有运气都是孤独的。

不是每个人都成功，也许只有过机会的人成功了，这只是运气少了一点聪明，他的聪明大小决定他上不了台，但是成功的人也不是孤独的。

不是每个人都是郭守沫，洒水的人不是一辈子到老的人，每个人都有一个活的价值，每个人都有一个人的价值，你的运气决定了你一生的价值。

所以今天我来说，大家想想运气，在我们活的这些时候，回过头来看从不是不可的真的，你觉得运气好的人，你该怎么解释运气？
