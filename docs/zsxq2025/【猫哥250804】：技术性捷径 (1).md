


# 技能经营

大家职场老板都希望员工能自付责任，
这种表现会比一个人都多。

都是怎样获得老板信任呢？
这几年我一直在向老板汇报，老板一直是一个需要信任的人，

也有人，老板希望自己是个靠谱的人，
老板希望员工是个靠谱的人。

这看起来很难，其实是一个很容易的技巧，
老板的其实是非常利私的，
这种社交沟通比工作更重要，这一个值。

沟通与老板的关系很重要，这对老板
信任比表现好的人要重要得多。

所以，你需要提供价值给老板，
只要你提供价值，老板就愿意给你机会，

这种社交沟通比工作更重要，
这种社交沟通为什么这么重要呢？

在现代时代，老板就是老板，
员工就是员工，所以这是一种技术的技巧。

怎样才能让老板信任我呢？
这就有九个技巧。

## 一、老板的心态

老板的要求其实很难，对员工不体谅的。
首先，老板的要求其实是有价值的，

其次，老板在企业招聘时，
希望招到一个能自己解决问题的人，

## 二、老板的价值观

比如现在很多做电商的老板，
老板在世界市场上出现了很多很多机会，
这种机会让老板不再需要那么多的员工了，
现在的老板在招人的时候可能就不需要这些员工了，

所以，你必须是不可替代的。

## 三、老板的预期

老板对员工的期望非常高，
老板希望员工能帮他解决问题，
而不是给老板带来更多的问题。

## 四、老板的恐惧

老板最害怕的是出错，
老板最害怕员工犯错，

## 五、老板的欲望

老板也想赚到更多钱，
