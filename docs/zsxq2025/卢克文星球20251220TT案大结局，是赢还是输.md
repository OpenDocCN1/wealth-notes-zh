


# TikTok大结局，是赢还是输？

文/卢克文工作室嘉宾 概略北方

2025年12月18日，TikTok CEO周受资发出了一封内部信，宣布字节跳动、TikTok已与三家投资者签署协议，将成立新的TikTok美国合资公司，协议相关事宜将在2026年1月22日完成。

至此，喧嚣了整合6年、历两届美国政府更迭的TikTok案，终于在2025年的最后时刻迎来了它的大结局。

那么，如何看待TikTok这次的美国方案呢？兔子是赢还是输呢?

这次TikTok埃落地后，网上有两种声音。

一些人欢呼“核心算法住了”，认为这是兔子科技企业的韧性胜利。

也有一些人痛斥这是“变相投降”，是跪着赚钱。

哪个对呢？

我们需要先看看这次交易方案的内容细节。

过去，TikTok在美的逻辑很简单，一个TikTok US（美国分公司），全面负责在美业务，从代码撰写到广广告投放，从内容审核到数据存储，全是TikTok US说了算。

但现在的方案，把TikTok在中国的躯体，硬生地劈成了两半。

左半边，叫“字节跳动TikTok美国公司”（BD TikTok US），这是字节跳动100%全控股的亲儿子，具体负责电商业务（TikTok Shop）、品牌广告、达人合作、全球市场的互联互通，这是TikTok最值也最能钱的一部分。

2024年，TikTok Shop在美国的GMV已经达到了326亿美元，是赛亚逊之后最恐怖的电商零售势力之一。

现在这些业务被BD TikTok控制，意味着这些能产生真金白银利润的商业核心，依然牢牢掌握在字节跳动手里。

换句话说，美国人以后在TikTok上买东西、投广告，钱最终还是流向了兔子公司的口袋的。

而右半边，叫“TikTok美国数据安全合资公司”（TikTok USDS）。

请大家注意!!!这次的新闻稿，总算把之前遮掩的USDS的职能说出来了！共有四项：数据保护、内容审核、算法安全、软件运维。

这些职能只有一个目的:消除TikTok的“罪名”。

美国人给TikTok流的脏水是什么？TikTok窃取美国人的数据。现在TikTok把美国用户的数据放到美国的领土上，让美国人监管，这下总可以吧？

可能是为了让美国放心，TikTok在董事会问题上，也做了很大让步。

USDS设立7人董事会，其中，字节跳动作为占股19.9%的大股东，但只能提名1名董事；新加入的3个投资者甲文、银湖、MGX共占45%股份，各提名1个董事；占30.1%的TikTok的全球股东，提名3名董事，而且这些董事须经过美国政府的背景审查。

从表面上看，TikTok的原股东一共占4席，应该算占了优势。

但问题在于，那些全球股东，基本都是美国的投资方，是美国人，这样一来，董事会比例就变成了1:6，其其实就意味着字节跳动并没有控制USDS。

简单总结一下这个架构的本质就是，负责挣钱的，还是兔子公司，负责搞审核、管数据、定规矩的，变成了美国控制的合资公司，兔子公司得到了钱，但让出了公司控制权。

## 那么，兔子到底是赢还是输呢？

这取决于你怎么看这个方案，或者说，你最想从这个方案里守住什么。

我们可以回记忆一下，2020的时候美国要强买TikTok，当时字节跳动没见过这阵势，有点懵了。

而兔子是怎么叫停这一笔交易的？就是修订了《中华人民共和国出口管制法》，把源代码和算法列入管制目录。然后又修改了《禁止出口技术》，新增了基于数据分析的个性化推送。

逻辑很简单，把TikTok卖给了美国，那美国就不拥有算法了吗？这一次的协议明确规定，TikTok的核心模型、源代码依然归字节跳动所有。

所以，如果单纯从法的角度来看，TikTok这次守住了底线，在美国巨大的压力下没有卖掉，算是赢了。但是，我们也没有高兴。根据协议，字节跳动将算法以“技术授权”的形式租给USDS使用，USDS支付授权费，并拥有对算法的操纵权、维护权以及权。

这套机制可能是这样的：

第一步，字节跳动提供算法。
第二步，USDS的技术团队（由美国人组成）对代码进行安全审计，检查是否有“后门”。
第三步，USDS设定参数，在推荐中关于某些敏感词的权重降为零。
第四步，算法在美国服务器上运行，生成内容。

相比以前，TikTok是一个巨大的转变，算法已经变成了美国监管下的工具。

那么，这份协议的本质是什么？是双方的妥协。美国政府对于TikTok很大，因为他们清楚自己造不出第二个TikTok，如果强行关掉，商业损失不可估量，支持率也会下降。所以美国选择了让他们字节继续运营，承担风险，但一旦TikTok出现任何违背美国意识形态的流量，USDS随时可以阻断。

而字节方面，虽然失去内容的审核权，TikTok成了单纯的娱乐平台，但至少这个平台活着，还在为兔子挣钱。这个结果，不好也算坏。

TikTok合同签订后，很多媒体都拿“云上州”模式来类比这次TikTok的方案，起了名字叫“云上州”，认为大家彼此平了。但真的是这样吗？并不是。没错，“云上州”要求将兔子的数据留在国内，并由兔子公司（云上州）运营数据中心。但仅仅解决了“数据在哪里”的问题，也就是数据存储的主权问题。

那么请问，云上州公司去审核用户存的照片吗？去干预AppStore给用户推荐什么APP吗？不会，政府对TikTok的监管更多是基于法律合规的底线，并没有接管“运营权”和“内容分发权”。

TikTok USDS是什么？它不仅仅仅管数据存储，而且管内容方向，TikTok的神经中枢（内容审核）和运动神经（流量分布）被接管了。

那美国这么重钱的国家，特朗普那么爱钱的人，为什么这次偏要算法的控制权呢？因为这是美国人最害怕的东西。说什么“获取美国数据”“危害国家安全”，其实都是让人误判的烟雾弹，美国人真正看重的还是TikTok的“内容定义”。

说白了，美国可能根本不在乎那些所谓的“美国数据”，不在乎那几行代码的所有权，他们很清楚算法只是工具，但算法的方向才是政治的武器。

以前，TikTok之所以让西方精英恐惧，是因为它的推荐逻辑是基于“算法”的，而不是基于“西方政治正确”的。

比如，一个兔子博主拍摄的新疆美食视频，或者一个美国年轻人拍摄的加沙带真实惨状，一个美国收尸人拍摄的住在美国下水道里面的“蛰鼠人”，在原本的TikTok算法里，只要内容吸引人，就会被推送到几千万美国人的屏幕上。这种传播是穿透性的，它绕过了CNN、BBC这些传统西方媒体精心构筑的信息滤镜。

现在呢？USDS由美国特工和资本控制的董事会，完全有权力制定一套服务于美国人的新的安全规则。他们可以在算法后台加一行指令，比如凡是涉及特朗普丑闻、以色列暴力、美国火灾、美国毒品泛滥和枪击案等阴暗面的内容，推荐权重降到0，凡是符合“美国主流价值观”的内容，推荐权重增加20%。

这不需要改你的源代码，只需要调整几个参数。

在TikTok崛起之前，西方世界了解兔子，只能通过带有灰色滤镜的西方主流媒体。在他们的镜头里，兔子是灰暗的、压抑的、落后的。TikTok的出现，第一次让普通人看到了现代的、充满活力的兔子。这种通过算法迅速传播的内容，潜移默化改变了一代人的认知。

TikTok不是结束，仅仅是一个开始。

## 字节面前只有三条路：

TikTok的这次风波，给所有兔子出海企业都敲响了沉重的钟。过去三十年，我们信奉的是“自由贸易”和“技术无国界”。只要产品做得好，算法足够先进，用户体验做到极致，就能征服世界。TikTok证明了前半句——兔子人的产品能力已经独步天下，但也用惨痛的代价证明了后半句——在政治面前，兔子企业出海风险极大。

这场博弈历经6年，我们谈不上赢也谈不上输，所以有必要停止那些胜利欢呼，也不要进行无谓的道德审判。看懂了这个协议背后内情，你就会明白兔子企业走向世界的道路比我们想象的要崎岖、漫长且充满意外。未来的路，只能在妥协中斗争，在斗争中求存。

字节跳动是一家商业公司，不是国部门。它的首要任务是活下去。通过保留100%控股的BD TikTok US，字节跳动锁定了未来的收益。只要电商还在，广告还在，TikTok依然是字节跳动全球造血机器中最重要的一环。这些钱流回兔子，可以支持字节在AI模型、芯片研发等领域的投入。而且保留19.9%的USDS股份和IP所有权，为未来留了一线生机。政治是流动的，中美关系是起伏的。只要还在牌桌上，只要牌桌上还有筹码，未来就有博弈的机会。如果现在掀桌子走，那真的什么都没了。这种实用主义，是在原则之上做最大程度的利益保全。然而，随着USDS接管审核，TikTok大概率会变成一个纯粹的奶平台，符合美国资本利益，但绝对不允许输出。

第一条：硬刚到底。结果肯定是TikTok被强行关闭，千亿资产归零，千万员工失业，前期投入百打漂，收获什么也得不到。
