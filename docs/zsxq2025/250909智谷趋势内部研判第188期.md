## 3

管理层对社保有所忧虑，各地缴费基数“难产”。一般在每年6月至8月中旬，各省份会陆续公布当年社保缴费基数的上下限，但今年已到9月，仅有5份公布；更罕见的是，往常费基数都是逐年上涨，今年内蒙基本持平，河北下降。智谷趋势研究员布语分析，这意味着管理层对社保费基数连续上涨之势，踩下了调整的刹车。2020-2024年，京沪社保费基数下限分别上涨了88.8%和49%，太原、呼浩特、哈尔滨等城市的基数下限，已经逼近甚至超过当地私营企业平均工资。企业和个人负担成本过高，引发了弃保、社会情绪反弹等问题。预计接下来的调整方向，将从“提升缴费下限”转向“扩大覆盖人群”，通过适度下调个人缴费来提升对低收入群体吸引力；同时对高收入群体的社保缴纳强化核查。

# 房产换的要抓紧了，金九银十有热度，但可能远不及预期。智谷趋势研究员抓片注意到，北上深接连松沪限购后，短期内成交都出现了反弹；北京8月初松沪五环外，当月二手房签约环比涨4.28%；上海外环限购调后的后续周末，两日合计成交超2000套，大致相当于新政前4个工作日的总和；深圳上周五新政落地，贝壳合作门店周末的二手签约量较8月增长3%。但这一波热度恐怕难以持续。一来政策继续挤牙膏，药力不足，药效减退在加速；二来除上海等少数城市，大部分热度比去年同期更低。大佬文集团中指院统计的百城数据显示，8月所有城市的二手房价格同比增速全部在下降，以房换量的局面尚未扭转，应趁市场回暖，进行置换或变现。

# 马云买币、国企发，顶级企业家与标志性企业对数字资产派出第一张信任票。8月29日，国资企业深圳福田控股宣布在香港通过以太坊公链，发行全球首单 RWA（现实世界资产代币化）公募数字债券。9月2日，马云间接持股的云峰金融公告，购入 10,000 枚以太坊（ETH），总成本约 4,400 万美元，计入投资资产纳入战略储备。智趋势研究员张之分析，福田控股和云峰金融的运作风向，数字资产得到了传统企业的认可，从“币圈-投机品”走向“圈-战略配置”，进入主流资本视野。

# 体育文旅有望超越演唱会，成为消费亮点。“苏超”模式大热后，江西、浙江、湖南、广东等地陆续推出“赣超”、“浙超”、“粤超”、“湘超”、“川超”。“苏超”后，江苏景区门票预订量同比增35%，酒店订单增10%，租车订单增20%，过夜游客占比提升至38%。首轮“苏超”带动综合消费超亿元。智谷趋势研究员王磊分析，之前各地主要采取自上而下的政府补贴、配套公共服务，这次更多的是民间参与力引发消费爆发。最近国务院办公厅发布《关于进一步推进体育产业高质量发展的意见》。

# “省域中心”迎来新阶段，未来或诞生更多省域中心。首次不再限定城市，意味着此项政策将扩大至全国范围。2020年以来，已有多个省份设立了多个省域中心，通过下放经济权限、省委常委兼任市书记等方式予以支持。智谷趋势研究员申豹认为，原因在于破解大城市的困境，长期来看，中国区域发展从“效率优先”的模式转向注重协调发展与风险分散的新格局。

# 黄金价格再次上涨（9月8日达3645美元/盎司），背后是全球财政货币扩张、美联储独立性被质疑、特朗普把国防部改名为战争部，从“防”到“战”，丛林时代山雨将来。法案本质是财政扩张为了刺激经济；德国等欧洲国家的财政扩张正在进行，德国实际赤字预计从2024年的低于3%增至2027年的超4%，维持至2029年；中国的财政政策从去年三季度开始明确转向扩张。智谷趋势研究员钟灏认为，这会对黄金形成长期推动。同时近期白宫持续施压美联储，美联储货币政策独立性受到挑战；越来越多国家如哈萨克斯、土耳其、捷克、中国、波兰等央行近几个月仍在购金，目前全球行的黄金储备已经超过美债储备。

# 石破茂被迫辞职，日本将加速右转。《读卖新闻》民调认为，“无需辞职”的比例比“应该辞职”高2个百分点。在6位潜在候选人的民调中，石破茂依然遥领先。此次辞职是为了防止自民党分裂，智谷趋势研究员S博士认为，民调显示两大忧虑：1，日本政坛进入动荡期，未来可能重现首相轮换；2，右翼民粹崛起，自民党有高市早苗、小泉次郎等清一色的右，日本政坛崛起了民粹参政党，在年轻人中间（30岁以下选民支持率28%），联合其它党已倾覆执政联盟主导权。日本向右气候已成，未来谁也只是右的程度不同。石破茂任内倾向于缓中日关系，他辞职之后中日关系会经历一段困难时期。

根据公开信息统计，中国在推进 AI 与军工的融入过程中，合作对象不再限于体制内机构，还涵盖了数百家私营企业与普通高校。338 家实体中，近四分为这类非传统供应商，他们拿下了 764 份合同——数量远超其他类别。凭借灵敏性和市场效率，往往在碳纤维、5G、云等领域有更快的技术突破。美国方面已经意识到了这一趋势，由于这些民企和普通高校大多不在美国的制裁名单上，这意味着传统的封锁手段可能难以阻断技术流，因此相关封锁有可能再度升级。

# 我们仍未完全摆脱疫情后遗症。智谷趋势研究员黄汉城发现，今年上半年，受益于日本放宽签证，赴日中国（大陆）游客数量达到 2019 年的 104%。不过同期中国赴美游客仅为 75.5 万次，不及疫情前 2019 年 1-5 月份的 77.3 万，背后是贸易摩擦、产业脱钩、拒签率高等综合因素。2021 年美国的拒签率为 18%，2024 年上升至 47% 左右。与此同时，上半年赴新加坡的中国游客 148 万次，仅为 2019 年的 81%，赴泰国约 66%，赴菲律宾的只有 26%，其中泰国是受“暖腰子”影响，从过去的出境最热门地区跌神坛，菲律宾则是网络博彩导致人类地理空间的迁徙。

# 智谷趋势研究员马认为，今年1-7 月，香港人才计划申请明显下滑，同比下降 40%。香港方面，面临2020-22 年严重的人流流失，人才来源单一（约95%来自内地），匹配度不高，留下难度很大，成本高，岗位集中于金融、贸易、法律等少数领域，导致续签申请减少。预见大众化时代结束，重新回归高端化、精英化。

# 在“内卷”背景和激烈竞争下，两轮车熄火，四轮车出现了7个月以来的首次负增长。与此同时，比亚迪、雅迪等行业巨头销量同比增长29%，净利润同比增长59.5%。智谷趋势研究员黄狮虎认为，这反映了消费领域的“降级”。

# 纳斯达克修订规则，提高上市门槛。公开发行资金要求从500 万美元提升到1000 万，今年上半年，有 62 家中国中小企业市值低于 1000 万，有 39 家募资规模在 1000 万至 1500 万美元之间。这意味着，大量原本符合条件的中国企业将被拒之，加快停牌和退市流程。其中近 70% 的机构主要涉嫌操纵。

# 2022 年 8 月以来，各国央行的外汇储备中持有的黄金数量自1995 年以来首次超越美国国债。彭博社数据，截至今年月底，央行疯狂购金是一个新范式。黄金价格不断创新高，背后是地缘政治巨大的不确定性在价格上的反映，二是全球财政双宽松带来的流动性泛滥。高盛等国际投行对黄金价格的预测正在向3800、4000 美元路上。
