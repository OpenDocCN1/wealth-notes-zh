


# 中国加强境外投资税，是“共同富裕”和个税收持续推进的必然结果

本内容来自读者提问，有读者关注到中国加强境外投资征税，问问针对海外股票市场股票买卖收入税未来是否会规模铺开，还想了解中国如何获得境外投资数据。

关于这件事有两条政策主脉：

一是挤压灰色空间。要让过去有法律依据，但实际没有执行，睁开一只眼闭一只眼的领域，开始加强监管，这一路线属于“先富带动后富”的时代之变。因为很多灰色空间，恰恰是偷税漏税的重灾区，也导致贫富差距进一步一步拉大。

二是加强个税，尤其是相对富裕群体以上的个税征缴。对海外投资征税，这本质是个税不断完善的结果，现在已经推进到这一步了。

对海外收入征税，都在这两条脉络的火力范围内。

需要注意，在全球征税方面，全球主要国家与国际资本才是对立的，比之前美国主张“全球统一税”，中国是支持的，联合打击击全球征收洼地。

在这方面，美国失血非常严重，迫切需要与全球各国合作。比如小镇之前谈过的苹果“全球无工厂模式”，这种新模式脱离了传统的海关监管范围，大量利通过知识产权和全球征税洼地落入了苹果公司自己手里，这几年引起全球海关税管领域的重视，全球主要国家都在想办法堵住漏洞。美国要求苹果把生产线挪回美国，有“制造业回归”的考虑，但也是压苹果低头，把长期独占的利润拿出来。来说，美国针对日本，可能也与丰田把利润更多转入和维护保养，从美国大量拿利润有关，这几年美国汽车市场交易价格暴涨，然而丰田利润中，美国占比大幅下降，这是不正常的。

在这方面，中国也有很强的需求。

中美两国之间也有了一定的跨国税务数据的互通，就是“税务互惠”。早在1984年就签署了《关于对所得避免双重征税和防止偷漏税的协定》的双边收税协定；另外在美国出台《海外账户税收遵循法案》(FATCA）之后，经合组织参考这一法案，在2014年也发布了《金融账户涉税信息自动交换标准》，主要是指导参与国家和地区定期对税务居民金融账户信息进行交换，其中有一个关键机制就是“通用申报准则”也就是CRS国际税务合作，主要目的是打击跨国逃税，中国已于2015年加入。

所以，中美之间存在税务信息交互的条件，但在税务合作上确实存在一定的不对等。其其实还是相对好办的，毕竟随着非国家的国际资本越来越强大，各国政府之间迫切需要加强合作。更大的难点在于，中美两国税收政策和制度存在较大差异，而且中美之间的税务合作仅针对避免双重征税和防止漏税进行了明确的规定，其他还没有成文规定。

再加上，过去美国对税务合规规则特别在意，尤其重视跨境交易和投资的合规审查，比如美国“长臂管辖”的关键法案《外国公司问责法案》，就成了美国律师特别看重的高利润项目，后来也成了美国霸权的工具，被异化了；而中国受到的国力和税收征管能力的限制，过去长期对跨境交易和投资的税收征管能力限制较小。

但观察上述中美税务合作存在的问题，可以说仍然存在合作空间，技术性问题终究是可以一步步解决的，作为全球独一无二的经济大国，都需要对方配合。也需要强调，合作归合作、博弈归博弈，美国本身也想吸引更多来自中国的非法、灰色资金流入美国，比如搞稳定货币，小镇之前就说关键是争夺话和灰色资金，主要目标之一就是中国。

以上大概的背景，就可以回答“海外投资数据的掌握”这个基础性问题，中美还是可以合作的，中国已经与全球一百多个国家和地区实现了金融账户数据互通，目前已经掌握了海量数据。

中国从2015年12月加入CRS，一方面继续加强国际税务数据互通，另一方面在境内完善个税征体系。

2018年9月完成首次CRS信息交换，2019年1月执行新的个税专项扣除新规，接下来的几年不断完善个税征缴，几次扩大个税扣除项目，2024年12月新增个人养老金抵扣，现在大家应该已经习惯了每年上半年进行税申报。

通过个税申报，税务系统对全国纳税人的资产情况、社会关系已经有了比较详细的了解；从2018首次完成CRS数据交换，这些年来，也积累了相当庞的数据，作为线索足够了。

于是有了2025年对海外投资税的新动作。从税收追征期限来看，一般分三年、五年及不限期，从2019年开始加大CRS合作和国内个税完善，今年开始缴海外投资税，恰当其时。

还有一个细节可以体现中国在个税征缴方面的快速强化，很多在海外的中国人，已经开始注意如果想避免中国征税、实现一定程度的“避税”，那就要在海外一年停留超过183天。

实际“中国人在国外居住超过183天所得税怎么算”这个问题，《个人所得税法》第一条就有了明确规定，但长期执行力度很弱，这就是小镇前面的“灰色空间”。现在就是要清理这些灰色空间。

不要想着规避，因为不同于法律强调“不溯及既往”，税收是不管这一套的，今年新调整的，可以以前倒查几十年，全球任任何国家都会这么干，而且除了少数国家，全球大多数国家都是采取全球税收制度，也就是跟紧人走，只要是该国的税务居民，无论收入来自哪里，都要对收入进行征税，只不过为了避免双重税，普遍规定了境外居住的时间期限。

所以对富人来说，如果是为了躲避境外投资税，那么如果加入美国、欧洲国籍，反而会承受更大的缴税压力。唯一可行的方法，就是转换税务居民身份，获得如中国香港、新加坡这样的采取属地征税原则的税务居民身份，这样就对来自当地的收入征税，对其他海外投资所得不征税。

关于海外收入征税的未来。目前收取资本利得税，在全世界都是主流，中国以前因为发展速度太快，没有征收资本利得税，对于富人来说，未来海外收入的征税是必然趋势。
