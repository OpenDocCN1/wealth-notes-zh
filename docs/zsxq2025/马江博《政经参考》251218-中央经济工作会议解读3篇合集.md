


# 马江《政经参考》251218-中央经济工作会议（一）：看懂2026 关键大调

欢迎来到《政经参考》，我是马江。

从今天开始，我们谈一年最重要的经济会议——中央经济工作会议。

这是我们这门课第一次研读中央经济工作会议，所以我先给你补充这个会议的背景信息。中央经济工作会议，是每年最高级别的经济会议，它的核心任务是分析当前经济形势，部署第二年的经济工作，通常在每年的12月举行。而会议结束后发布的新华社通稿，是外界理解和预测中国未来一年经济政策走向的最权威、最核心的文本，也是观察来中国宏观经济政策的“第一窗口”。

这背后真正的经济指挥棒，往往通稿中一个词的变化，就决定了资源和资金的巨大流向，对我们每个人明年的大决策，比如投资、创业、就业等，都有重要的风向作用。

因此，我们将用三节课程的内容带你把这场重要会议理清楚。具体看，通稿前面部分是对经济的大定调和大政策，而后面则是针对明年经济工作的八个具体任务和发力点，咱们今天先说前面的定调部分，后面的课程，谈具体任务和建议。通过这次拆解中央经济工作会议通稿，我也想带你练一次如何读懂这种大文件。

## 对经济规律的新认识

对明年的总体定调，这里可以拆解成几部分：
第一部分是中央对经济规律的新认识；第二部分是对当前经济内部外部环境尤其是问题的判断，就是对当前经济形势的定调；第三部分是新一年经济政策的大方向；第四部分则重点谈财政和货币这两个关键经济政策明年安排。

先说第一部分，对经济规律的新认识。

这次提了“五个必须”，我挑出其中三个我认为相对更重要的来说。

第一一，“必须坚持政策支持和改革创新并举”。

之前“政策刺激”和“深化改革”经常被视作不能兼容，好像一说“政策刺激”，结构调整就可以一放。而这次我认为意见很明确了，短期的政策刺激和长期的结构性改革不是对立的，都要有的。所以我综合判断，调整结构在明年会强化发力。

之前“十五五”规划建议中有一个关键提法是“新旧动能转换任务巨大”，我认为这个表述是对之前的转型速度不太满意，必须要转，而且要加速转，这个信号揭示了未来五年新旧转换的波澜阔，而2026年将加速转换的开端，这是机会，也是挑战，大幕拉开的紧迫感很强烈。

第二是，“必须坚持投资于物和投资于人紧密结合”。

这个提法第一次出现，是在2025年初的《政府工作报告》里，最近已经进入了“十五五”规划建议稿，这次又在重要会议上重提。高层反复提这个概念，虽然很重视，那么背后的大逻辑是什么？

我认为，过去“投资于物”的结果，是形成了产能、住宅和基础设施，都是供给。而只有“投资于人”，释放人的消费潜力，才能产生更大需求，消化巨大的产能供给。

而“投资于人”我认为有两个方面：一方面是托底的，明年概率会继续加大医疗、育儿、养老等方面的投资，这是新机会，目的是减少负担，让大家有更多消费能力；另一方面则是搞的——大国博弈，科技研发需要高素质人才，其中就包括大规模培养理工科人才，这是一种“战略性投入”，所以明年有关教育、培训领域的投资，也会增加。

第三是，“必须以苦内功成功应对外部挑战”。

这句话很有意思，简单来说，未来一年，甚至是未来五年，我们要为大国博弈积累筹码。2025中美相互试探了试水温，而在2026年将是各自加速解决自身问题，准备更硬核博弈的一年。而对很多城市、产业、企业和个人来说，2026年则是抢占生态位的关键一年。

## 国内供需强弱矛盾突出

接下来谈第二部分，会议对当前经济形势的定调。

这次的关键原文是：“外部环境变化影响加深，国内供需强弱矛盾突出，重点领域风险隐患较多”。

我拿2024年的表述一对比，发现有几个关键点：

第一，在外部环境判断上，2024年的表述是“外部环境变化带来的不利影响加深”，而今年“不利”这个词消失了，变为“外部环境变化影响加深”，我认为说明外部影响不仅有不利的，也有利的，所以新一年更要保持对外的战略主动，动作可能会更大。

第二，在内部经济问题的判断上，2024年的表述是“主要是国内需求不足”，而今年的表述则升级为“国内供需强弱矛盾突出”，新强调了“供给”的“强”造成的供需矛盾。在今年7月，商务部长就提到，我国社会消费零售总额2024……

第三，在风险隐患的表述上，2024年是“风险隐患仍然较多”，这次变为“重点领域风险隐患较多”，我理解说明明年的风险工作更具针对性。

## 经贸斗与跨周期调节

谈完了会议对当前经济形势的定调，紧接着谈第三部分，明年经济政策的大方向。会议通稿有一个关键提法是“更好统筹发展和安全”。这句话在今年4月中美贸易战升级时提到过，而这次放在中央经济会议中，我理解则是变成了一种持久的战略，考虑到国内经济政策的压力，更多是考虑到外部斗争。

另外，会议继续强调了“稳就业、稳市场、稳预期”，把“稳”放在第一位。所以明年经济政策的关键信号是“稳中求进、提质增效，发挥存量政策和增量政策效应”。这句话跟2024年对比拆解：

第一小句，2024年用“稳中求进、以促进增长”，强调的是进和总量；而现在变成了“稳中求进、提质增效”，强调的是优化、质量和效益。我理解意味着工作重心突出了“优化”，我们提到的新旧动能转换的加速，也再次在规划中提到。

第二小句，“发挥存量政策和增量政策效应”，这是一个非常关键的提法，我理解意味着政策思路的重大转变：除了存量，也要盘活起来。

第三小句，则是重提了“跨周期调节”。“跨周期调节”最早出现在2020年7月政治局会议，当时的情况是当年受疫情影响增速比较大，高层面临选择到底是继续猛打，还是警惕放水带来的风险。当时“跨周期调节”是为了对冲短期波动，而“跨周期调节”是要提升经济长期韧性。

## 财政和货币政策

最后我们谈第四部分，明年最重要的两个经济政策：财政和货币政策。

针对这两项政策，这里提供一个简单的观察框架：财政政策你可以简单理解为政府多花钱，怎么花；积极的财政政策就是政府多花钱直接注入经济，降低大家负担，增加企业和个人的支配收入。货币政策主要就是调节市场上钱的多少，以及利率。宽松的货币政策你可以理解为政府通过降准降息等手段鼓励贷款、消费，间接激发经济活力，资产也会上涨。

不同的财政和货币政策，来看具体表述：2024年在述财政政策时，明确提出“提高财政赤字，确保财政政策持续力”，而在今年谈财政规模，只用“保持必要的赤字和债务总量”。这个区间明显，今年没有使用“提”“加大”“扩大”这类表述，只用了“保持”，我理解意味着明年财政扩张的力度大概超过今年。

另外，通稿中关于财政有一个关键提，要“重视解决地方困难”。我观察这在过去多年的中央经济会议中出现过，是第一次提出来，所以信号强烈。我认为此背后意味着当下部分地方政府财政困难、要应付的问题，明年基层的基础民生保障、公务员、老师工资等会更好一些。

再来看货币政策。今年和2024年相比也有几处明显的变化。首先，在关于降准降息的表述上，2024年使用了“适时降息”，意思是看情况落地；而今年用的是“灵活运用降准降息等多种工具”，这句话余地就很大，降准降息都是“政策工具”，什么时候用具体看。所以我综合判断，明年货币政策的力度也不会超过今年，而且会精准投入内需、科创、中小企业等领域。

其次，这次会议明确要把“促进经济稳定增长、物价合理升”作为货币政策的重要考量，表明了高层对物价目标的关注。明年是个关键指标，如果物价回稳，货币政策将更加温和；如果物价持续下去，货币政策的力度可能会有所加大。关于物价背后的影响，感兴趣的同学可以再复习一下。

# 马江《政经参考》251218-中央经济工作会议（二）：三大首要任务，影响巨大

欢迎来到《政经参考》，我是马江。

今天继续谈中央经济工作会议。上一课谈了这次的宏观调控和政策取向，更具体的影响还要看会议关于明年的部署，这就是八个具体任务。接下来的两节课，我和你分享我对这次会议的研讨理解——包括中央在重点关注哪些问题，哪些部门可能带来什么影响，以及我们可以关注的方向和建议。今天这节课，我们先谈前三大任务，剩下的五个任务下节继续。

## 内需主导下的新机会

先会议部署的第一任务就是内需。去年和今年都把内需排在了所有任务之首。2024年的表述是“全方位扩大国内需求”，而今年则变成了“坚持内需主导”。多了“主导”字，我理解意味着内需不仅是“稳定器”，更要成为经济增长的“主引擎”。

具体看，内需其实包括两方面：消费和投资。我观察到，今年发展内需的思路明显转变：

在消费方面，会议有一个新提，“实施城乡居民增收计划”。以往关于居民增收，大多围绕中低收入、退休人员等特定群体，这次提“城乡居民”，适用范围扩大到了全社会，我理解其目标还是实现社会收入上涨。进一步看，一方面意味着服务“增收”将受益，例如城市就业、职业培训；以及乡村振兴项目，比如特色产品加工、乡村旅游等将获得更多。

另一方面，新硬件和新服务的时代正在到来。2024年的表述是“扩大服务消费”，而今年把“商品”加上“优质”字，要“扩大优质供给”。什么意思？意味着在服务消费之外，大量的制造业，比如机器人、eVTOL（垂直起降飞行器）、AI设备等优质商品，具体包括个人和家庭的健康健康、医疗器械、户外运动、智能穿戴、家居家具等重点。

在投资方面，这次也有新的信号。会议明确要求“推动投资回升”，我理解相当是定定了投资重心。具体怎么做？要“适当增加投资规模，有效激发民间活力”。

对比2024年，很多地方财政困难，投资下滑，主要是受房地产投资拖累。现在重点已经转向了基建和先进制造业，因为投资容易过剩。客观来说，这样发达地区在招商方面的优势更加突出，一些发达地区过去私享的“土政策优势”则越来越不可能。在这个趋势下，不同地区未来发展的分化会进一步加大。

对于企业来说，全国统一市场对于那些具备跨区域经营能力、产品和服务标准统一的企业来说，是重大机会。它们将在中试放大、先进制造、供应链配套、规模化生产等环节获得红利。例如东莞、佛山在先进制造领域，苏州、合肥在成果转化等环节需求将加速。特别提到三角，未来更多的国家级大型科技项目将在江苏、浙江、安徽等地，“强者恒强”的逻辑更加突出。

# 马博《政经参考》251218-中央经济会议（三）：出海、楼市、股市与个人机会

欢迎来到《政经参考》，我是马博。

今天的课程是我们研读中央经济工作会议的最后一篇，我会把剩下的五个任务全部说完，然后再基于同学们可能普遍关心的问题，谈下我的判断和建议。

## 对外开放的新契机

我们将从会议通稿的第四任务说起，这是对于对外开放的，我理解下认为三个新的关键点：

第一，通稿说“优化自由贸易试验区布局范围”。

除海南自由贸易港外，内陆一共有22个自贸区，客观来说，有些自贸区是一种“工业化”的产品，模式比较诡异，也引发了招商内卷等问题。而这次的提法，我认为意味着未来不同自贸区的定位会进行改变。

对企业和投资者来说，如果你想在金融、数据、科技、医疗等高端产业上发展，可以重点布局沿海的自贸区，如上海临港、广东前海；如果你的优势是本土制造或供应链整合，内陆的郑州、成都、重庆的自贸区将更为；如果业务涉及东盟、中亚、俄罗斯等周边市场，边境自贸区如广西、云南、新疆的跨境物流、人民币结算和边境便利政策，就是你的跳板。

第二，会议要说“推动贸易更多区域和双边贸易协定”。

简单来说就是我们要大力拓展贸易投资的“朋友圈”，降低企业出海的门槛和风险，来应对整体国际贸易环境的不确定性。中国已经加入了“全面与进步跨太平洋伙伴关系协定”，就是著名的CPTPP，以及“数字经济伙伴关系协定”等。未来在出海过程中，中东的基建、新能源、数字经济；东盟的电动汽车产业、数字支付；南美的矿业、农业科技，都是值得关注的机会领域。

第三个关键点，不在原文中，是中央财办副主任文秀在中央经济工作会议结束后的一场解读中延伸提到的，央视的报道提到，他说“明年要扩大出口，也要增加进口，推动外贸可持续发展。”

这句话确实很有意思，中国2024年前11个月的外贸累计达到了人类历史上的第一个1万亿亿美元的准差。我认为上述亮眼的数据背后的关键之一就是高端制造业出口的强劲。举个例子，11月份集成电路（芯片）出口同比增长了大概34%，并且这两年都是高增长的。这然证明了出口的强劲，但我们显然也有忧心！持续的贸易顺畅并非好事，别的国家不高兴，可能会招致美国、欧洲，甚至是南美的贸易摩擦。

所以我判断，明年会加大推动进口。高端消费品、特色优质农产品、国内短缺的资源和技术装备的进口生意，迎来窗口期。

而迎合几个关键点，未来精通国际规则的法律、财税、合规等国际专业人才、数字技术人才，需求会更大，跨跨境电商、海外内容创作等领域的机会也会多增。

谈完第四个任务，接着会议部署的第五个任务，是要推进城乡协调发展，主要是农业、乡村、脱贫等事项，我学习下来发现，大部分和今年2月发布的中央一文件，以及4月发布的农业强国文件是一脉相承的，对这部分感兴趣的同学，可以复习第40、41和79、80课，我说得很详细了。

## “安全绿色转型”背后的去产能

接着谈会议部署的第六个任务，则是要“全面绿色转型”。背后我认为关键之一就是继续去产能的影响。

2024年中央经济工作会议，跟绿色环保相关的内容是排在9大任务中的第8项，今年则是排到了8大任务中的第6项，我观察，它是位次上升最大、最明显的事项。

之前在2015—2018年，我们主要是通过行政化手段来去产能的，比关停一部分钢铁厂，现在则是要突出市场手段，其中最重要的就是环保，会议说要“推动全面绿色转型”，“深入推进重点行业节能减碳改造”。明年企业可能因为能耗环保问题加速退出市场。

我认为背后不仅是“绿色转型”问题，也将是一场持续五到十年的强制性产业升级，这也是一直提到的新动能转换的一部分。钢铁、水泥、化工、有色等行业的每一企业，都要考虑进行新的技术改造，这是刚需，也是一个大机会。能够提供“诊断-改造-运营-认证”全流程服务的能源管理公司，将迎来红利。对于个人来说，这也是一个新的专业壁垒，是个人发展的一个不错的深耕方向。

另外，这部分也提到要“深入打好蓝天、碧水、净土保卫战，强化污染污染物治理。”蓝天、碧水两者其实是一体的是，首先是为了增加高中和好大学的学位资源，缓解大家的焦虑，其次也是为实体体系下的理工人才培养加码，因为优质高校的扩容大多是新的。

在医疗方面，强调了“优化药品采购，深化医保支付方式”，我们在国家公布的药品目录上再次加速。

接下来谈谈很多同学关心的房地产。

首先，房地产从2024年的第五项任务变成了今年的第八项，位次下降了。其次，在2024年和今年都放在了“风险防控”的任务中，但力度不同。2024年的表述是要“持续推动市场”，而今年的表述是“着力稳定”。另外，具体的表述则是“控总量、优供给、鼓励需求”。

我的看法是，未来首先是要“救交易”，房地产市场要更热闹，资产要流动，帮助消化库存。所以政策意味是，未来首先是要“救交易”，房地产市场要更稳。对于明年来说，如果有比较大的自住需求，可以积极考虑；如果没有太强烈的自住需求，可以继续观察。

关于风险防控，2024年主要提了地方债，而今年的会议又提了地方债，这说明很有必要。

另外，文件提出要“加强主要海湾整体规划，推动海洋经济高质量发展”，以后每一个海湾，比渤湾、杭州湾，要把岸上的城市和海里的产业，作为一个整体来规划，像宁波、青岛等这样的海湾城市，将加速度获得海洋的新规划红利。
