


# 全文解析《美国国家安全战略》

全文解析美国刚刚发布的国家安全战略。

这份战略报告从川普在年初刚刚上任的时候就开始制定。前后历经了九个月时间，经过了反复的修订，系统总结了川普的治理逻辑以及后续的政策方向。

这么吧，川普有一个很好的习惯，就是它以正式的文件形式发布的宏观政策都会认真的执行，因此了解了这份川普版的国家安全战略报告，就能在大方向上预判美国接下来三三年的政策态势，以及美国对世界将会加什么样的措施，带来什么样的影响。

首先来看这份报告的目录，它由四个部分组成，仅仅只看这份目录，就能感受到充分的川普式风格，一种强烈的做生意的味道。

该报告的第一部分引言部分述什么是美国战略，第二部分述美国应该要什么，第三部分述美国获得这些东西的可用手段是什么？第四部分就是战术部分，分别述了战略原则，优先事项以及针对全球各大地区具体的策略。从这样的目录来看，川普政府事实上已经将自己的意图表达得明明白白的：我现在要转型了，我想改变什么东西，得到什么东西，我计划通过方法得到我想要的东西都已经写在了纸上，供各位全文查阅。这种直白率的表明自己具体想要什么东西的战略性文件，在全世界说非常罕见，在后面的文件内容中，川普政府也没有堆砌大词，语言全都清晰明了。

这就是明牌的做法，对于现在的美国来说，它已经处于清晰的战略转型之中，此时没有必要藏着掖着。他是将自己的战略意图清晰地表达出来，越能够减少误解，降低国与国之间的沟通成本，从而更加有效的推动这份转型计划的实施。

我们来进入正部分，先看川普政府对于美国此前的国家战略偏斜的总结。这一非常重要，全字不漏地翻译如下：

冷战结束后，美国的外交政策精英们进行了自我说服，他们认为美国对整个世界的永久统治符合美国的最大利益。然而，其他国家的利益只有在其活动直接威胁到我们的利益才与我们相关。我们的精英严重误判了美国人民愿意永远承担全球责任的意愿。这种全球责任的负担与美国人民关注的国家利益毫无关系。

他们高估了美国的财政能力。在维持国内巨大的福利监管和行政系统的同时，维持巨大的军事外交情报和对外援助体系的能力，其实已经超过了美国的财政能力极限，他们在全球化和所谓的自由贸易上下注，这些极其错误且具有破坏性，损害了美国的经济和军事优势所赖存在的中产阶层和工业基础，他们允许盟友和伙伴将国防转嫁给美国人民。甚至经常性的把卷入大量的冲突和争议之中，这些冲突对他们来说至关重要，但对我们而言毫无关联。

同时，他们将美国政策捆绑在一系列的国际机构之上，其中一些机构明显有反美倾向，许多机构引导的跨国主义明确寻求解决单个国家的主权。总之，我们的精英不仅在追求一个根本上不理想且不可能实现的目标，而且在追求这一目标的过程中，他们削弱了实现该目标所必须的基本条件：美国的国，自然也是构建美国力量、财富和体面的基础。

川普政府明确的否定了此前美国精英们推崇的所谓全球化的策略。他们相信，这套全球化的做法极大的伤害了美国的利益，对美国的中产阶层和工业基础造成了巨大的侵害，甚至伤害了美国的格局。

因此，川普政府的首要策略就是反全球化。全球化这个词，在川普政府这里不具有任何的政治正确性，而是政治错误的集合大体。如果大家此前对全球化的未来抱有任何幻想，那么从现在开始，请离开这样的幻想。美国曾经主导的全球化的时代已经过去了。

接下来的 mega 还在位置上，左边的民主党人不能通过下一场大规模选举实现领土重来的话，那么川普政府在推的全球平衡贸易模式将会成为新时代的主流。在接下来的世界，类似钢铁这种全产业链模式，一个国家挣了全世界大半的外贸顺差的异常现象，应该不会再出现了。

接下来我们来看第二部分的主要内容：美国想要什么？

首先是关于美国在整体上想要什么的问题。这份报告列举了六个方面的核心内容，简述如下：

- 一、维持美国作为一个独立主权国家的地位，确保美国免受敌对势力的影响；
- 二、建立严格的移民秩序和边境管理秩序；
- 三、提升国家的基础设施水平；
- 四、大幅强化军事力量，提升军队的战斗力，强化核威慑力量，建设新一代导弹防御系统“黄金顶”；
- 五、繁荣美国经济，实现再工业化。推动能源产业大幅增长，保持技术领域的领先地位；
- 六、保持美国在制度和文化层面的软实力，恢复美国的传统精神。

这样的计划目标看起来不像美国的国家战略，单纯从文字来看，更像是一个发展中国国家的发展战略。比如第三条提升国家的基础设施水平的内容，意味着川普政府认为整个国家的基建水利已经落后于时代，需要开展大规模的更新建设。事实上，也确实如此。不说美国落后的交通网络，美国的整个电力系统都处于极端原始的状态。从一九九零年代之后就没有进行系统升级，州与州之间，城市与城市之间，电厂与电厂之间，连基本的电力调配系统都没有。稍有风吹草动，就是长时间的停电，且迟迟无法修复。

再来说第五条繁荣美国经济，实现再工业化。这一直是川普政府的重中之重，到了现在，任何企业向外投资，尤其是技术投资，都会遭遇毁灭性的割肉和暴跌。川普政府认为，保持技术领先地位是一种正确的做法。

总结起来，六大战略目标每一个都具有针对性。美国的再工业化本身就是针对全球化模式的挑战。

接下来是美国想要得到什么，也就是具体的战略实施。报告列举了五个实施方向，其中：

- 第一、控制整个美洲大陆，恢复门罗主义。
- 二、阻止并减少敌对势力对美国造成的持续损害。
- 三、维护欧洲的自由和安全。
- 第四、阻止敌对势力控制中东。
- 第五、确保美国科技水平继续世界领先。



样的表述来看，就算是真的爆发直接的军事冲突。川普政府也不会有什么意外情绪，无非是计划之中的开战之栗了。
