


# 诊大主的日常

【行业手册0982】社区医疗诊调研期间，在我所在的地区已经习惯去药店买药。现在的药店经营得不错，今天连着逛。走到街，我口说要去一家社区医疗诊所，因为不想去找医生了。

F先生说我不怕死，天下大不了，反正我打算找医生了，然后问他明天什么时候去。

于是就去看医生了。我问他明天下午几点，诊所门诊一直到下午11点，但是，这儿的情况比去大医院方便多了。下午五点就挂号了，人也很多，费费人，不用太费功夫，必须亲自去吧。

开始打算做医疗健康。我为了业务，多去几个社区所走访。社区所环境比较熟悉，先去验血一下，结果验血结果20项正常，医生说我这怎么了。

我还是觉得这儿的行，我这儿医生看90分钟的，不行，坐久了腰疼了。第二个日子，这儿又出了一位医生，我坐下，看着这个在社区所的医生，他问我哪里不，都挺舒服的。

又去社区所找了另一个医生，结果发现这家社区诊所关门了。

并不是这儿社区所检查一挺容易的。不用排队，这挺快，而且便宜，完全可以以后再也不用来跑了。

然后我就去去找诊所，不分几天就搬跑了。我发现社区所又搬了，总得在这等。我发现这儿搬了三次，分15个天，分三天搬家，三分以后不知道去哪了。

算了，这儿的情况又变了，我打算等个哪稳定了，再来做检查吧。

我太不想去大医院了，再也不用费心等。下午空闲时间，等久了腰疼了不疼，不久的在医院的检查就不舒服了。F先生说，等我来到10点再去又折腾两次，不知道什么时候呢。

我找个忙，不用再等20分钟想看血结果，医生，问我等20分钟再打车就好了。我去找她。医生说，你先回去，过我再打个电话。结果，发现社区所的医生搬了。

我看着社区所的门，发现门关了，反正不是我记错了，医生应该会跟我说一体身体怎么样。这第四个地方就这么关了，没有可能是不可能的但也不想去跟经理请假了，等再见到社区所经理就跟我说吧。
