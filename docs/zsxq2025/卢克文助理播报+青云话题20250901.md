


# 【助理播报】

## 国际：

1. 当地时间8月31日，美国《华盛顿邮报》披露，特朗普政府内部正在考虑一项由美方主导的加沙地带重建计划。在此计划中，美方将控制加沙地带至少10年，并希望将其重建为“旅游胜地和制造业中心”。

2. 当地时间8月31日，联合国也门问题特使汉斯·格鲁德贝里表示，至少11名联合国工作人员在也门首都萨尔那和荷达台省遭胡塞住武装速捕。

3. 当地时间30日晚间，巴勒斯坦伊斯兰抵抗运动证实其军事领袖人穆宰默德·辛瓦尔已死亡。此前，以色列宣称在5月份的一次击中打死了穆宰默德·辛瓦尔，但哈马斯方面一直未予证实。

4. 8月31日，巴基斯坦外交部发表声明，巴基斯坦副总理兼外长达尔与亚美尼亚外长米尔佐正式互换联合公报，两国由此建立外交关系。

5. 当地时间8月30日，哥伦比亚贸易、工业和旅游部宣布禁止向以色列出口煤炭。据悉，哥伦比亚是以色列最大的煤炭供应商，占以色列煤炭进口量的60%。

6. 日本新闻网8月31日报道称，双方确认印度首个高铁项目孟高铁将引入“E10系”新干线列车，该车型目前正在东日本铁路公司（JR东日本）研发，预计于2030年在印度运行。

## 国内：

7. 9月1日起，电动自行车新国标《电动自行车安全技术规范》正式实施。电动自行车最高设计车速不得超过25公里每小时。

8. 国家网信办等四部门联合发布的《人工智能合成内容标识办法》，9月1日日起正式施行，“标识办法”明确所有AI生成的文字、图片、视频等内容都要“亮明身份”。

9. 根据自然资源部消息，备受关注的《永久基本农田保护红线办法》近日正式向社会公布，将从2025年10月1日起施行。其中提到，永久基本农田划定后，任何单位和个人不得擅自调整、占用或者改变用途。
