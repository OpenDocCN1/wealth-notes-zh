


# 鉴茶财经院底层代码系列-呼风唤雨：管理、领袖之力的来源

管理要靠什么？靠能力吗？并不是，管理靠的是权力。能力只是权力的部分。

为什么有人的，明明是上面任命的领导，是局长，是处长，是总经理，是总监，但话说没人听，下面阳奉阴违。

为什么有人的，普通职务一个，却能呼风唤雨，影响一大片？

就得说权力是怎么来的。即上头任命你做总经理，任命你做处长，等等。孔子说，名不正言不顺。这个权力有用吗？没大用，只是门槛。

权力的第一个来源是组织赋予权。你能够用 KPI 和工具扣他绩效，罚他工资。威励他。也能够给他发福利，弄好处。这个权力有用吗？很有用。

但是，每一个领导手里的资源毕竟是有有限的，不能长期的给，人会视，也不可能所有人给。小惠未遍，民匮从疏。

权力的第三来源是专家权。你在某个领域或者公司与组织的运行，干涉最好，专业度最高，或者最能解决事情，你就是真正的专家，和职称学历并没有关系。

任何一个团队都是因为目标而存在的，而专家权，必须是领导的首要能力，要么自己最会干，要么自己最知道应该怎么干，这就是专家。

很多公司的老板都是首席销售员，很多单位的头脑最了解游戏规则，都是专家权。所以，要掌握。

第四个权力是典范。领导毕竟只有一个人，要发动所有人，就只能在游戏规则和 KPI 的框架下带人。就必须有人格魅力。

所谓的人格魅力，物质上要给大家带来好处，哪怕是小礼物和纪念品，不然大家跟着你干什么呢？

精神上，要有人性的优点，勇敢、公平、勤奋等等，你自己知道的良好品质都往自己身上加，控制自己，不断训练和实践。精神上的引领强大了，就是理念，人都是需要方向的，很多人，其实追随的是信仰，物质并不是第一位。

60、70 年代，大家跟着大队长书记拼命的修水库，那也不会什么物质，就不靠精神引领群吗？

管理就是权力。

组织权 < 奖励权 < 专家权 < 典范权。

典范权中的人格魅力到了一定步，你就是领袖。

这就是管理的干货。
