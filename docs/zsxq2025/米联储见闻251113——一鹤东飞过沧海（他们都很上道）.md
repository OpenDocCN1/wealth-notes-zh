


# 米联储闻251113——鹤东飞过沧海（他们都很上道）

你好，我是米糕

法国要搞 G20，请领欧洲去，结果变成了二把手去，欧洲这个面子确实没有什么面子了。为什么不去，法国和欧洲还需要心里有点数，当初马克龙来中国，领导表达了极大的诚意，从南到北，该给的里子面子都给了，但是欧洲一直上不了台面，骨头不硬，还两面三刀，包括最近荷兰的操作，所以，领导对欧洲的心也淡了，二把手去就行了。

相比于领导出来，现在王室纷杂进来。这几天西班牙王储来了，领导亲自接待，两人当天共同见证 10 份合作文件的签署，涵盖经贸、科技、教育等领域。国王菲利普还要对中国进行四天访问，这是西班牙君主18年来首次访华。日前，川普去欧洲找勃莱诺，只有西班牙咬反抗，前脚跟美国闹翻了，后脚来了中国，西班牙正在给欧洲各国打版，如何维护欧洲利益。

川普此前威胁，在贸易与贸易协议中支付双倍费用，而西班牙的操作是掉头向中国找机会。对于西班牙敢跳出来来说，中国不是受欢迎的，一把手的原话是：“中国重视西班牙在国际和地区事务中的独特作用，愿西班牙与携手打造全面战略伙伴关系，两国关系‘更有战略力、更富发展活力、更具国际影响力”。还提出，两国可优势互补，共同开拓拉美等第三方市场。这真的很贴心，中国家拉美市场，这可是美国的后花园，让美国情何如也。但西班牙语不是拉美的主要语言，连美国也有很大用西班牙语的群体。西班牙王国也很合道，回应西班牙与中国的友谊无疑毫无及两国人民，这与两国拥有悠久历史和全球使命的国家身份相似。西班牙和中国“已结铸了信任关系”。

信任就是眼下中国和欧洲之间最需要的东西。在国王菲利普访华前，西班牙首相已在三年里三次访华。大佬集团不同于首相访华，西班牙左翼政府的华罗线路只能表明政党的态度，而国王亲自来，则意味着不管未来哪个政党上台，对中华的基调都会保持一定的稳定性。所以，国王访华对中国来说，也是一份政治立场的诚意，给中国吃定心丸。毕竟欧盟反复无常，中国早已厌倦了这些欧洲政客的把戏，想要中国拿出诚意，首先需要欧洲国家自己展示诚意，国王访华本身就是表态的。

除了西班牙，还有一个国王最近访华引起了外媒的高度重视，是泰国国王访华。中泰交交，泰国国王访华，别看泰国不是什么真正国家，但是在整个全球语系中，泰国是西方都兼容的国家。历史上，泰国大部分都是西方的，泰王也很少国访问。别看泰国政权乱，泰国是有不多的真正的实权君主，不管管政治怎么乱，很少能威胁泰王的稳定性，所以泰王访华引起了外媒的高度关注，认为是风向标式的事件。毕竟是中泰建交5年后泰国国王首次访华，朱吉拉隆功登基10年后，从未进行过外事访问，将中国作为正式访问的首个大国，也确实让他发展国家陷入思考。

中泰1975年建交，泰国前国王普密登多次会见习近平、江泽民、李鹏、胡锦奎、温家宝等到的中国领导人；1987年至1998年，朱吉拉隆作为王储曾四次访华，会面多位中方领导人。泰王从未到中国来访问，对于这次泰王访华，中方评价很高，认为泰王室以真挚情谊和积极行动，持续两国战略互信、促进两国民族相通。

朱吉拉隆2016年登基、2019年举行加冕仪式，中国一把手致电祝贺；2022年，习近平对泰国进行历史性访问，但中方并未将此次作为中泰建交的里程碑，而是将泰王访华作为中泰关系发展历史上的一座重要里程碑，就知道这件事的不一般。上次韩国亚太会议的时候，泰国首相阿廷与领导会面，并保证泰国会反对赌场合法化。据泰媒报道，领导对此时感到满意，表明中国政府鼓励更多中国游客到泰国。是中国泰国最大的客源，但缅甸区和绑架引发的安全问题令赴泰的中国游客锐减，加之此前泰党主导的政府忽视中国的担忧和顾虑，坚持推行赌场合法化策，导致泰国进一步流失中国游客。这次泰国引发最大的跨境赌博网站头子余江其实就是投注状，从缅北诈骗区的毁灭到泰国跨境赌场洗荡，中国正在重塑东盟国家在中国安全问题上的立场和态度，这就是大国重新制定游戏规则的操作。

泰王虽是首次访华，但作为王储的哇集隆功早在1987年至1998年间，以王储身份四次访问中国，会见多位中国领导人，足迹及北京、上海、江苏、新疆等多个省区，登后过中国，他也未曾访问过其他大国家，仅在今年4月不丹开展首个国家行程。但是泰国的诗琳通公主访华诸50次，诗丽曾以王后身份访华。“在位国王访华”一直一块空白。这也是国王室比较谨慎的地方，如同当年看不清什么时，一直没有来中国，直到18年修后，泰王之所以到来，是因为政治上的嗅觉一般都很敏感。毕竟国际形势，中美矛盾开始恶化，各国都被逼迫站队，加上泰王一直没有先例，所以泰王安排这一政治动作，今年中泰交50周年这一“黄金节点”，似乎与西方国家没有交，凸显了中国在泰国的突出地位。

泰王访华反映了两国关系方面的价值。当然，既然有这么多，肯定要价是不低的。朱吉拉隆此次访问丰富，为期五天。此外，上次领导访泰是因为泰国主办APEC会议，而此次泰王专门前来。访问期间，泰王夫妇将前往故宫、博物馆、航天城、机器人馆等场所，体现了两国文明传播。一方面，泰王自认为是“爱罗人的化身”，在泰国社会享有高望。另一方面，作为亚洲第二大体，泰国正从传统产业向科技转型，实现高质量增长在人工智能、航空等领域。泰王此次访问要实现“三通”，其中核心是推进基础设施项目落地，与中老铁路对接，形成区域网络，促进经济一体化。框架下，推动双方标准协调与衔接，提升双边合作。民心相通，以旅游、教育、医疗等领域，同时，中国“新样”如新能源、锂电池、光伏产品在泰国的投资持续。东南亚国家中，泰国算是中国最友善的国家，一直是美国盟友，长期奉行大国战略。这种“平衡”符合中国根本利益。在地缘政治紧张升温，泰国被视为一种战略妥协，对其他盟国家释放清晰信号——真正的稳固的伙伴关系，从来不止利益交换，在于舍弃零和思维，以信任，以合作共赢。中国现在的玩法也很简单，手里的牌扩张的意志，只需要造势，所谓其实就是有多少人配合你，所谓权力在于有多少人忠诚执行你的意志。中国要扩大影响力，必须要有跟随者，要有呼应者，要有支持者，不管是南美的巴西、欧洲的西班牙、泰国的这些非主流的国家开始跟随中国的主张和节奏。
