


# 男人一定要找到“游戏人间”的感觉

原创：U 君 公众号：赢在8小时之外 25年8月29日

今天是七夕节，我的男性粉丝里面有很多单身人士，还有很多已经找到了了自己的伴侣。

在我看来，单身一点都不可怜，最关键的问题是你是一个玩家，还是被别人玩弄的？

如果你是一个玩家，那么你就能随时处于主动的主导的地位，别人都会被你拿捏、利用。

如果你是一个被玩弄的人，那么在任何场景（学校、职场、婚恋、理财），你都会被别人牵着鼻子走，玩弄于股掌之间。

举个例子，有的男人的手段和话术都非常高明，很多女人都被他忽得团团转，慷财又慷色。

而有些男人总一味深情，总是跪舔女人，七夕还要送礼物、发红包，但是那些女人一直吊着，从来不让他占一丝“实质性”的便宜。

之所以会会出现这两种差异，就是因为前者有“玩家”心态，而后者有“负责任”的心态。

结果就是，整个宇宙都会把最好的资源奉献以前者，而对于后者，宇宙会把他们身上有的资源剥夺走。

因为宇宙也喜欢奖励游戏间的“玩家”。

那么一个男人该如何操作，才能从后者转变成前者呢？

我总结，一共有5个思路：

## 1. 游戏必须充值

很多男人都喜欢玩游戏，但是会分为两个阵营：免费玩家和充值玩家。

前者的宗旨是：玩游戏不充一分钱，总想通过技术来战胜其他玩家，而且非常鄙视那些充值玩家。

但是，他们被充值玩家毁了之后，又会发出屈辱和悲愤的哀嚎：这个游戏垃圾，充值就能赢，不充值技术再好都没用！

结果就是，这种男人在玩游戏的时候，基本上都在发图强、努力技术、被虐、哀嚎、继续发图强的死循环中。

实际上，人家游戏公司对免费玩家的定位就是“付费玩家的玩物”。

付费玩家给游戏公司交钱，游戏公司就安排他们在游戏里去虐那些免费玩家、获得爽感。

付费用户爽了之后，就会觉得这个游戏做得真好、真良心。

U 君自己以前就喜欢玩穿越火线（生化模式），这款游戏的技术和装备都很重要，我每年都要充值2000左右，买最好的枪和道具。

结果就是，每次我玩游戏的时候都很爽。

其实人生也一样，这种充值时候必须要充值，然后才能找到爽感（有些快乐就是建立在别人的痛苦之上），才能感受到生命很美好。

从玄学的角度来看，付费用户是在吸食免费用户的生命能量。

结果就是，付费用户不会因为花钱买装备而贫穷，反而由于能量的增强，他们在赚钱等很多维度都会蒸蒸日上。

因为“让自己累”是一种习惯，玩游戏时要爽，收钱时也要爽，这两种爽是相通的。

所以，在游戏里大杀四方的人，大概不会在一个办公室里做一个拿工资的打工族。

## 2. 择偶必须充值

我在《男人不谈恋爱就没戏》这篇文章里说过很多次，会有三个逻辑：

- 认清金钱客观价值；
- 对所谓的“美女”祛魅；
- 提升自己的能力。

只要接触的人多了，你就学会如何和女人不卑亢，只要你不再舔狗，那么对你的好感就会大大提升。

在学生阶段，如果你学会了舞蹈，那么将来会在生活的包围里遇到她，她会为你用心。这句话说得很绝对，但是也有一定的道理。进入社会后，如果你有了钱，那么当初高攀不起的女神，会在前面。

还有人会说：

- 男人钱就不缺感情；
- 没钱就没有任何挑战；
- 你不敢花钱，你就永远不会对美女祛魅，你就会永远被美女牵着鼻子走。

## 3. 伯乐害了千里马

在体育界，有很多伯乐和千里马的故事，比如森和乔丹的教练，最初发掘了新星，然后把他们培养成千里马走向人生巅峰。

但是在体育故事里，悲剧多于喜剧。

比如，有很多举重、体操或者跳跃的运动员，在小学阶段就被某个“伯乐”选中了，然后控制饮食、控制体重、注射激素、高强度训练……到了十六七岁，虽然夺冠了，但是身体搞废了，所有的内分泌都是乱的。

一旦过了25岁，虽然赚了十万、百万，可能就会成为狗都嫌的废物，后半生可能会凄惨度过。

而且，剩下99%的运动员同样把身体搞废了，到最后金钱和荣誉都没有拿到。说得难听点，很多运动员都被体育事业给阉割了，自己是彻底的炮灰。

但是，有的运动员不信邪，他们努力摆脱被玩弄的命运，尽可能主宰自己的人生。

比如，去年有一个叫柳芳的体操运动员，因为搞“大尺度直播”而被封杀。她从小就被伯乐选中，是从从小就服用激素等方式把她的身高控制在了一米四。大家不信可以去网上搜搜，运动员要严格控制身高，越矮越好。她也拿过冠军，但是她现在30多岁了，被体育事业抛弃，一个月只能赚几千钱，还落下一身病……这时候，她想通过直播来翻身大赚一笔，我觉得她是清醒了，知道不能再等人宰割了（她被体育精神收割了，现在决定收割粉丝）。可惜的是，她碰到了一个嫉妒心非常恶毒同行，把她给举报了。接下来，我估计她的后半生会很惨的。那个叫红蝶的女人，估计后半生也会很惨（激素乱、身体旧伤、年龄大了就被抛弃）。通过她和父母的发言就可以判断：他们全家人都是拎不清的蠢货，还为了一个虚无缥缈的“体育精神”站台。

聪明的体育冠军是怎么做的？拿到第一块金牌之后，立刻移民瑞士、德国、法国、日本等发达国家，拿到身份之后，后半生无论在国内还是国外淘汰，下限就已经很高了。其实不管是体育界还是商界、演艺界，脑子稍微好用点的都是玩家心态，狡兔三窟，手上至少有两本护照。谷爱玲就是里面的典范。讽刺的是，像滑雪冠军、网球冠军、排球冠军这些“明星项目”的冠军，他们收入超级级，脑子也非常灵活，基本都是两本以上的护照。反之，举重、跳水这些运动员，收入极低的运动员，反而脑子很呆，总是听信谎言，总是为体育精神站台。结果就是，他们会被体育精神和现实生活狠狠地割尖。

## 4. 要去更闹的竞技场

最近A股大涨，明白人都知道，本质上并不是因为经济的转好，而是为9月份的XX准备、做庆而已。如果你只盯着A股，那么你的下场跟那些练重、体操的女远运动员一样。她们会被体育精神反复割。

股市的特点：

- 一旦长大之后，创始人就把钱转移出去，否则会被抢走；
- 要么陷困，要么跳跑；
- 很多地方（如菲律宾、巴西、德国）股市都是韭；
- 很多股民回报率非常稳定；
- 拿钱傻地存到银行，每年就有5%的收益；
- 把钱傻地投入到美股和基金，每年就有8%-15%的收益。

之所以这样，通过美元霸权，苹果、微软、谷歌、特斯拉、通用、星巴克、当劳、可口乐……这些公司都在增长。

## 5. 要学会耍别人

真实的原因：并不是大家说的那样，之所以会这样。

如果你想成为玩家，千万不要盯着A股，外面的天地更广阔。

如果你让你的粉丝都听你的话，那么你需要做的事情，是培养他们服从。因为“让自己累”是一种习惯，玩游戏时要爽，收钱时也要爽，这两种爽是相通的。

在情绪上，你一定要说一些话，让他们产生巨大的喜怒哀乐，潜意识里被你玩了。后者会变得老实，越来越听话，像个“老好人”的朋友，反而对那些经常虐她们的死活来打不跑。从某种程度上来说，你能让谁的情绪产生巨大波动，谁就会心甘情愿被你控制、玩弄和割。
