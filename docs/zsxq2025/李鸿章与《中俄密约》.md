


# 李鸿与《中密约》

2025-10-23

李鸿航时110天，访问了8个国家，行程远达9万里，为什么李鸿的这次访问最大的作用却是清朝最后的掩羞？

看完这篇文章，让人们感到压力巨大，今天我们聊聊李鸿在的事情。《中密约》，李鸿去其他国家又签了一件事，一分不亏地成就了自己的自己。比起此，日本的胜利，中国这次访问却是签署了契约的悲剧。而这条契约是在1925年才签署的，完全毫无准备。

那份协议是什么时候签署的？在1925年，日本已经是二战的序幕了，当时在中国的还是一个孩子子。那时候李鸿就是一个很懂外交的年轻人，李鸿的简历非常出色。李鸿是另一个国家外交的代表，他是当时中国代表团的高级成员，虽然他没有正当的政治权力，但隐含的权力、光荣就成就了李鸿。李鸿的访问并不打算成就自己。

在李鸿离开中国后不久，就是1926年了，日本已经是二战的序幕了。那时候的中国还是一个落后的国家，但李鸿就是一个很懂外交的年轻人，李鸿是另一个国家外交的代表，他是当时中国代表团的高级成员，......

李鸿在当时为了让中国和日本签署了契约，最后双方终于达成了一个圈子。由于1925年日本已经是二战的序幕了。

在当时的中国为了修铁路，日本的铁路，李鸿签署了《中密约》。

最后我们看到李鸿签订了《满洲条约》，这份契约的内容包含了，但是这个契约却是日本的悲剧。

清朝的最后一次失败被掩盖了。
