# 重生夏天

## 第一章 回到夏天

睁开眼，我发现自己躺在熟悉的天花板下，阳光透过窗户洒在脸上。我有些恍惚，这不是我的家吗？难道我回到了十年前？难道不是在做梦？我摇摇头，难道我真的回到了十年前？我的心脏猛地跳了起来。

我坐起身来，看着四周，一切都是那么熟悉又陌生。墙上的老海报，桌上的旧电脑，还有窗外咯吱作响的电扇，这一切都在提醒着我，我真的回到了十年前。我冲到镜子前，看着镜子里年轻的脸，脸上没有岁月的痕迹，只有少年的朝气。我自嘲地笑了，这真的获得了重来的机会！

这时，门被开了，我妈走了：“林峰，你还没起床？快起来吃饭，饭凉了。”我愣住了，看着妈那张年轻了许多的脸，眼眶一下就湿了。我真的回到了十年前。我冲过去紧紧抱住她：“妈，我爱你！”我妈有些诧异，推开我：“这孩子，怎么了？发疯呢？”我笑了笑，擦擦眼泪：“妈，我没事，就是想你了。”

吃完饭，我魂不守舍地坐在窗边，看着窗外忙碌的街道。十年前的这里，还是记忆的样子吗？这一次，我要改变一切！我要守护好我爱的人，我要让那些不再成为现实！林峰，你今天不去学校补习吗？”妈在厨房里喊道。我点了点头，眼神变得坚定：“不去，妈，我要好好学习。”

# 万古书架

作者/李傲风

## 第七章 出书架

林凡站在书架前已经很久了，他每天都在看着书架上的那些书籍，不知道该从哪一本开始阅读。这时，书架突然震动了起来。

没有家人，她也不需要，她害怕任何人的离开，害怕被像垃圾一样被丢弃。她习惯了这种生活，习惯了孤独，习惯了在这个冷漠的世界生存。2009年，她的生活平淡如水，直到林峰的出现打破了这种平静。他的出现像是一场突如其来的雨，打乱她的生活，也为她单一的世界增添了一抹绚丽的彩虹。

然而，美好的时光总是短暂的，林峰的离开对她来说是毁灭性的打击。她无法接受这个现实，她开始疯狂地寻找他，试图回到过去。林峰的消失让她陷入了巨大的痛苦中，她开始在城市的每一个街角寻找他的踪迹，却一无所获。她开始在深夜里独自徘徊，在街道上哭泣。她试图用醉酒来度过每一个夜晚，试图用酒精麻痹内心的如刀割的痛苦。

直到有一天，她遇到了陈远。陈远的温柔和细心给了她前所未有的温暖，她开始重新相信爱情。陈远的出现让她原本悬着的心终于放下。她开始去爱，去感受那份从未过的快乐。然而，命运并不打算放过她。陈远的意外将她推向了绝望。这一次，她彻底崩溃了。不再不再泣，也不再寻找，只是静静地坐在黑暗里，看着时间流逝。她开始意识到生活就是一场悲剧，无论如何努力，都无法逃脱命运。一次清醒后，她决定离开这个城市，开始新的生活。

## 53. 春

2008年5月18日，我遇到了生命中最难忘的女孩。5月17日的周六，阳光明媚，我独自躲在图书馆看书，看到她坐在对面。几天后，我再次在学校食堂时发现她又坐在对面。我们是同一个同学，试着和她打招呼，关系变得越来越好。一个月后，我终于向她表白。我们在一起一段时间，我发现她并不怎么闹，是一个非常温柔的女孩。

可是，由于工作的压力，让我感到失落。我并没有和她分手，最后还是分手了。分手后的段时间里，我试图忘记她，可是越想忘记越记得。有一天，我遇到了另一个女孩，她比那个女孩更懂我的心。在那段日子里，我尝试了很多，但没有一个让我动心。直到她的出现，我才找到了幸福。我们在一起了，生活非常幸福。2008年10月，我们有了儿子。那一刻我觉得自己无比。可是生活并没有想象中那么美好，由于工作的压力，我变得脾气暴躁，经常和妻子争吵。

## 56. 离婚

没有办法，林悦只能叹口气。“唉，这辈子大概也就了吧。”林悦看着眼前的照片，心里五味杂陈。她叹了口气，无奈地叹口气，心里有些酸。林悦也曾想过这日子什么时候是个头。可现在发现，自己已经习惯了这种苦。“算了，该过日子就过吧。”林悦自言自语。林悦起身，洗了脸，然后去睡觉。“明天又是新的一天。”林悦自嘲地笑了。林悦躺在床上，闭上眼睛进入梦乡。

林悦坐在床上，看着那张结婚照片，心里触动万分。“对，我们离婚了。”林悦轻声自言自语。林悦闭上眼，虽然已经离婚了，可心里还是难受。“可是，我真的离婚吗？”林悦在心里问自己。林悦深吸了一口气，眼角的泪水顺着脸颊流了出来。纠结了很久之后，林悦最终决定了离婚。
