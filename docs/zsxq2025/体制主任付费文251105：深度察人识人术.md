


# 深度洞察人术

原文：主任 公众：人性的透视镜25年11月5日

不管是体制内还是体制外，不管是择偶，判断你的恋爱对象是不是渣男渣女，靠靠不靠谱，还是识别潜力股，还是判断一个领导值不值得跟，识别下属，经商选择合作伙伴等等，都需要具备察人认术。

28岁以下的年轻人，别看他穿什么鞋、用什么手机，先看学历。不是说学历低就一定差，而是学历背后蕴藏着“自律”和“学习能力”。那些能考上985、211的，至少高中三年没闹腾，就算是普通二本以上，也说明有内驱动力，这是最快判断一个人是否聪明、自驱、自律的捷径，效率极高。

38岁以下，重点看职务。这个时候，学历光环该褪去了。人在体制内或者体制外混到什么位置，直接反映了他的社会化程度、解决问题的能力、精力体力以及（很可能有的）办公室政治情商。

不管是体制内还是体制外，如果一个人在35左右还没混过一半职，在其他方面也没有成就，你得打个号。

40岁以上，直接看财富量和社会影响力。到了这个年龄，财富（尤其是靠自己挣来的）就是一个人的综合能力体检报告。挣不到钱、无法用自己“所谓的才能”变现的，大概率是社会化能力出了问题，它包含了人性认知、决策、匮、资源整合等所有要素。

我知道，肯定有人说“学历不代表能力”、“有钱人也有草包”。没错，但这属于小概率事件。咱们普通人赌不起小概率。人的第一要义，是相信概率，不赌奇迹。一个能用自己才华稳定变现的人，通常更稳定，更有能力和你一起对抗生活中的不确定性。反之，一个总怀遇、抱怨社会的人，大概率是他自己对社会运行的底层逻辑一无所知。

# 潜在判断

这才是真正考验眼力的地方。

对于择偶和长期合伙人，这一项至关重要。怎么判断？在1对1的深度聊天中，你可以有意地抛出以下几个“探测球”：

- 先聊商业认知：考核对方对所从事领域，对行业赚钱的本质、自己能否保持竞争优势、未来商业演变方向有没有做深入思考。别问“你觉得这个行业怎么样”，太笼统了。要问具体的，比如“你现在做的业务，赚钱的核心是啥？你们公司同行比，优势在哪里？未来三年，这个行业可能会有啥变化？”

真正有想法的人，能跟你说得头是道，甚至能拿出具体案例；没想想法的人，只会说“还行吧”“挺好的”，或者跟着网上的段子吐槽。我之前跟一个做电商的老板吃饭，他说“我们做女装，不是靠低价，是靠抓‘妈妈群体’的需求——她们要瘦、耐穿，还有点儿设计，所以我们的衣服都做‘高腰A字版’面料选抗皱的”，你看，这就是深度的认知。

- 然后人性认知：通过热点话题，聊事情背后人物的深层利益动机和心理动机。聊到社会热点事件时，如果他只会说“人真坏”，那说明认知还停留在小学生水平。真正的高手会分析：“这件事情背后其实是A抢B的市场份额，顺便甩锅C。”

对人性有高认知的人，一定不是非黑即白的二极管思维，更不会不动就做道德批判，一定是灰度的、辩证的概率思维。比如，你可以聊：“你觉得那个明星出轨，背后的真正的原因是什么？”看他能否跳出道德批判，分析背后的利益动机。

# 高维性观察

一定是灰度思维，不会非黑即白，他们会从利益、心理、环境多个角度分析。

- 最后聊领导力：领导力为画饼、做饼和分饼的能力。你可以问学生时代有没有当过团主席、大型活动发起人或组织人经验，以及观察其日常为人处事是否有意识、分享意识。有领导潜力的人，学生时代就开始打造、维护自己的支持系统（关键老师、父母亲缘、关键同学、社会资源连接）。

这里得泼点冷水：判断别人的潜力，首先你得有“同认知”。如果你段位不够，很可能被一个特别忽视的“泥菩萨”（表演型人格）给住，反而又错过了真情。如果你觉得自己行不行，最简单的方法——带你信任得过的、有社会成就的长辈或朋友，帮你“面”一下，他们的“老狐狸雷达”往往很准。

# 诚信度

现在人都太“包装”了，朋友发几张健身房照片，就说自己“爱运动；跟他人合影，就说自己“人脉广”。但有些东西是“装不出来的”，因为造假成本太高。

先来说容易造假的“低门槛信息”：

- 炫耀式生活片段：朋友圈发豪车、豪宅，可能是租的；豪车方向盘、五星级酒店下午茶，这些成本太低，P图软件都能搞定。
- 标签：说自己“善良、孝顺”，结果连父母的生日都不记；说自己“靠谱、负责”，结果关键时刻掉链。
- 人脉：说“我跟谁都很熟”但你让他帮个忙，他就找各种理由推推推。
- 伪诚意：说“我想找结婚的”，结果约几次就想找借口。这种人就是“短辈”。

不容易造假的类型（高成本、强背景）：

- 学历、工作单位及职衔。
- 房产、工资流水/纳税记录。
- 负债。
- 股权。
- 论文。
- 身份。

对于体制内人员，判断非常好，看他的职务。
对于体制外人员，判断相对难，看他的身份是否对应。比如：
- 广东是粤、
- 浙江是浙、
- 重庆是渝……
- 对方的办公系统。
- 对方的项目。
- 对方的合同。
- 对方的诚信。
- 对方的信任。
- 对方的信用记录。
- 对方的执行能力。
- 对方的社交圈（低成本策略）。

# 互惠

这是我常用的一招：付出先置。比如主动买送一个小礼物。

一个人如果总是想着最大化自己的利益，意味着最小化别人的利益，时间长了就没有合作。不管好的生意，还是好的伴侣，一定是双赢。这在穷人思维里是“傻B”，但在富人思维里是一种快速的策略。

能互惠的人，说明他懂规矩、有意识，是合作之才。

你有没有遇到这种人：跟你吃饭，总让你买单；你找帮忙，跑得比谁都快；你找帮忙，他就“装死”。这种人就是“只吃不吐”，跟他们交就是亏本买卖。

成人的世界，没有免费的午餐，也没有付出。好的朋友是“你帮我，我帮你”；好的伴侣是“你懂我，我疼你”；好的合作伙伴是“你赚钱，我也赚钱”。

根据不统计，低学历、低收入群体中，有主动意识的可能不到10%（他们大多数觉得“你比我有钱，你买单不是应该吗？”）；而在高学历、高收入群体中，这个比例能上升到30%-40%。

一个人的物质匮乏，往往会导致精神上的匮乏，他们很难发展出利益上的追求。

写在最后：如果你的的人生向上走，必须拥有极强的“屏蔽”和“过滤”系统。绝大部分人的走弯路，都是因为认人不明，在错误的人身上花费了大量的时间和感情。能认识，意味着你抓住了幸运的本质，即：一眼选中好事，一眼避开烂。

“一眼识别”的本质也不是玄学，而是大量的错误和经验压缩后的模式识别。这“一眼”的功力，背后隐藏着一个人的悟性，以及上百次“看错”和“复盘”修炼出的内化直觉。
