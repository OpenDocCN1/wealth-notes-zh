


# 大智若愚

猫哥原创

今天聊一段个人感悟。

但是如果我们换一个角度就会发现，硬币的另一面是这个桥段的反派是很悲催的，要为前期的莽撞付出巨大的代价。

那么问题来了，为什么反派踩坑呢？

原因很简单，就是反派把主角真当猪做了！这才是反派踩坑的根本。

但是，天下底下有那么多猪或者傻子可以任人踩的？

所以，很早时候就建立了一个强烈的意识——任何时候都不要把别人当傻子。这个意识，实际上让我不但回避了许多坑，更为为重要的是，让我拥有了独特的思路，能比一般人看得更深更远。

举两个耳熟能详的例子。

## 案例1

小学的时候我就开始接触成语，很多成语的主角当时看就是不折不扣标准的傻子。比如刻舟求剑，即便当时是小学生，也觉得主角是标准的傻子。

但是成年之后，建立了不要把别人当傻子的思维之后，对这个成语就有了另外的看法。

如果我们把刻舟求剑的主角不当一个傻子来看，那么我们就会问一句，为什么他会这么干（刻舟求剑）？中国古代有一句名言：车船店脚牙，无罪也该杀！

这句话是啥意思？

意思就是古代车夫、船夫、店小脚夫与牙人的都不是良善之辈，脚夫与牙人的都不是良善之辈，人前好像有一个正当职业，人后就有可能坑害蒙匪杀人敛货的。

所以，当一个外出的人在乘船的时候，带着剑掉进水之后，船夫劝他下水去捡剑的时候，他如果真下水会有什么后果？大概率船夫会将他给吞了，为了免除后患甚至可能在船后头在水里的人直接灭口。

这就是不能下水找剑的原因。

那么为什么又要刻舟呢？我觉得是船夫看到乘客没有下水，随身携带的兵刃也没有了，开始动了杀机（目露凶光），于是这个人得掏出备用的兵刃，惯船夫不要乱来，至于于这刻舟不过是故意装舟，让双方不至于于当场破脸而已。

现在回头来看，刻舟求剑的主角是傻子吗？不是，这是真正大智若愚的人啊！

以上的推理我也是有有依据的。一个人出门偶然随身携带两件兵刃，说明这个人对外出的风险是有丰富经验的，这样的人可能是刻舟求剑的傻子？用脚头想也不可能啊。

历史上也有类似的案例。汉代陈平有一次乘船，同样也遇到了船夫不怀好意，于是陈平干脆把衣服个精光，主动帮助船夫摇橹，其其实也是主动给船夫表示，自己没有钱，不要打坏心思。

## 南辕北辙

这个成语的主角看起来也是标准的傻子。

但是如果这个主角不是傻子呢？那么他为什么要这么做？

这个成语有两个角色，一个主角，一个旁人，这个旁人一直在指点主角到楚国正确的方向是往南走。

而主角一直在打哈哈或者就是装傻，寻找一些无厘头的理由：“我携带的给养很多，我的车很好等。”

那么事件的真相很可能是这样，这个旁人可能是车夫可能是随行的陌生人，这个旁人虽然指的方向是正确的，但是主角意识到随行人不怀好意，虽然往南走路程更短，但是孕育着巨大的风险，如前段可有一就是黑森林，或者是乱岗。这些路段可能潜伏着随行的同伙。

所以主角断然改变方向，宁愿先往北绕一个大圈，也要避开那条虽然捷径有风险的路段。

在这个过程中，随行的人一直在试图试图说服主角改往南，但是主角一直在装傻，目的就是不愿在这个时候打破那层窗户纸，与这个不怀好意的随行者当场翻。

现在回头来看，南辕北辙的主角是傻子吗？不是，这是真正的大智若愚的人啊！

古代远出门就是这样，如果不够机警，缺乏风险意识，早不知道死过多少回了。这就是那句古话说说的，宁住野坟，不住荒庙，世事人心险恶啊！

不把别人当傻子可以避免踩坑，同样遇到风险的时候，装傻让别人把自己当做傻子才能规避风险。

刻舟求剑、南辕北辙的主角都是这样做的。这就是大智若愚的含义。
