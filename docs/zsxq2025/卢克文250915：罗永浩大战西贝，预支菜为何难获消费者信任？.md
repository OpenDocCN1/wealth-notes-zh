# 时代大涨价，我们没有机会富了吗？

但是可见，现在的年轻人确实不会变富了，简直是不可能的。

以前时代大涨价，我们就有预期可以变富的，这种机会来了，去买股票，结果就富了。

现在时代大涨价，我们却觉得“这种机会太贵了，去买股票，结果还是没富”。

可是现在的股票都贵了，现在的年轻人还是没富吗？

## 这些时代大涨价

最近时代大涨价了，我问朋友，我们怎么没有机会变富呢？你说你没买股票了。

## 一

这种活动，买股票就赚了，不买就亏了。

但是现在时代大涨价了，不买就亏了，买了又亏了，没机会了。

以前时代大涨价了，我们不买股票，后来我们发现没机会变富呢？

现在时代大涨价了，我们不买就亏了，买了又亏了，我再问朋友：“时代大涨价了，我们没有机会变富了吗？”

但是2017年，时代大涨价了，我们没买股票，结果真的没有变富吗？

那时候时代大涨价了，我们买了股票，结果还是没富，反而变穷了？

但是现在时代大涨价了，我们没买股票，结果真的没有变富吗？

但是现在时代大涨价了，我们真的没有机会变富吗？

现在时代大涨价了，我们没买股票，结果真的变富了吗？

但是现在时代大涨价了，我们真的没有机会变富了吗？

在2017年，时代大涨价了，我们没买股票，结果真的变富了吗？
