


# 价值

价值，是你所创造的价值。你的工作中很大一部分会被自动化取代。你没有一个可以被替代的价值，谁来？

如果你离开公司，公司会找到另一个替代你，这轻而易举。现在的公司，无论哪个行业，都能找到一个可以替代你的人，这难道是不可能的吗？

这种价值的价值是由什么来体现呢？除非你离开了公司，别人才会发现没有了你，公司会有什么了。最后真正的价值是，就是你你自己。

当你离开了公司后，老板可能会找另一个同事，来接手你的工作，这并没那么困难，毕竟这并不太难吗？

听到这样的话，你可能会觉得很失落，但是你想过吗，你真的那么不可替代的吗？

如果你发现自己没有价值，那么你离开公司后，该怎么办？如果你发现自己没有价值，还会害怕被淘汰吗？

# 选择

当你离开公司后，你才知道你有多价值。你不需要老板了，也不也不需要同事了。但是你会发现自己需要什么？你会发现自己需要的。长此来看，你还是会意识到自己失去了价值。

你现在要怎么选择？

如果你选择继续上班，你可能没有未来，没有理想。如果你选择创业，你可能面临巨大的风险，创业资金的准备呢？如果没有老板的支持，选择创业的风险你承担得起吗？

无论你选择哪一种，你都要面对后果。

当你离开公司后，你发现你不再需要老板，你不再需要同事的认可，也不需要老板的认可。如果你不再需要老板的认可和选择，你还会害怕吗？
