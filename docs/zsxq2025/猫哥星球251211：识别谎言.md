


# 猫哥星球 251211: 识别谎言

作为普通人一辈子总要接触到各种形色的谎言，如果我们对谎言缺乏判断能力，就很有可能踩坑甚至吃大亏。

如何识别谎言？

正常情况下需要生活的阅历。

那么没有捷径呢？

这个是有的。

有一种人其基本职业就是与谎言打交道，这种人就是刑事律师。

我有一个做律师的朋友对我说过，他做的这个职业，当事人因为涉及律师案件，所以多多多少会有意隐瞒一些情况，或者故意模糊掉关键性的细节，如果做律师将当事人描述全盘接受，到了开庭的时候，就会突然知道自己才是庭审中最大的傻白了。

这方面他也是吃过大亏的。

所以要干好律师这个职业，首先要具备的基本功就是识别谎言，当事人将情况描述之后能够迅速精准判断是怎么回事，当事人隐瞒了那些细节——没这个本事就绝对对不利刑事律师这个职业。

所以，一般来说，刑事律师做得得好的，对于识别与拆解谎言那是本能。

感谢互联网时代，让我们可以通过互联网平台接触到传统社会根本不可能接触到的咨询，比如我就很喜欢看一些刑事律师的直播切片，一些优秀的刑事律师的直播切片有时并不亚于一部短小精的片，我们在与律师接受的信息基本相同的情况下，这些律师就能精准识别提问者的谎言以及故意模糊遗漏的关键。

所谓熟读唐诗百首，不会作诗也会会吟。

这类案例看多了，是可以极大提升自己识别谎言能力的。大佬文圈相当于一个优秀的职业拆解谎言的专业家用活生案例手把手教我们怎么去识别谎言。

过去我们需要阅历，需要踩坑才有可能具备识别谎言的能力，现在通过互联网短视频平台，看几百个律师的直播切片也具备了。

这方面我看过不少律师的直播切片，印象最深刻的就是王洋律师，几个识别谎言并拆解的案例都称精彩，确实是这个领域的佼佼者。

如果大家希望提高自己识别谎言能力，需要补上这块短板的，可以找到王洋律师的直播切片好看，同时也找找一些优秀刑事律师的视频好看，多看几个案例，相信你一定能提高自己对谎言的识别能力。

今天就是给大家分享这么一个方法。
