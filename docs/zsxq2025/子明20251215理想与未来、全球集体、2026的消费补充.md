


# 统治、理想与未来

发布专栏：知几共话

历史的镜子里，映射的是未来。

在上一篇文章中我们讨论了多民族叙事瓦解的根源，也分析了大清时期的民族“包容”，并对明朝做了初步对比。

可是，明与清，作为读者心中绕不开的两座大山，他们是如何深刻影响兔子历史的呢？除了“治兴替”，对这段历史的研究和解释，还有哪些特殊的意义？推动历史前进的道路上不乏“理想主义者”，这些主义者的“理想”又是仅仅一种天真？

## 01 两朝倒车

12月6日 21:22

最近我一直在看“吃瓜好主”的相关解读视频，终于能明白清朝对外战争一直输的原因了。因为它的主要敌人是汉族，而不是边疆上的“外族”，而且还有对外转移财富的问题。

我也看过她的视频，她的意思是，明朝本来是牛逼的，而兔子整体实力开始退坡，则是从1644年满清入关后开始的。感觉这个观点或许有点问题。

有什么问题吗？

我查的资料，清朝时期的人口达到了峰值，而人口和所谓国家实力是相钩的强弱。衡量一个民族不同历史阶段的强弱，不能看内部。同一时间的欧洲，正是科技迅猛发展时候，而我们那时候在干什么？技术靠自己琢磨很难突破的。

统治几倍于自己民族的人，是一种杀，另一种就是愚民，内外矛盾兼有的时候，赔偿给外族还能维持统治。

这个满主的核心观点是：满清防基于防外，整个王朝是压制汉族，不惜让字率溃退，愚民，同时因为统治不自信，也抑制科技进步，招致蛮夷荒华。总之，是文化科技被清朝“双锁死”了。

在这个观点的基础上，她另一个的观点是，汉文明本身并不排斥科技，甚至具备向外学习的动力。且民族内在对于文化的，凭借汉族的内生力，应该不至于清末变成这样，如果没有异族压迫，甚至还有可能屹于世界之巅。一个反证就是，脱离清朝之后的一百年，兔子已经是坐二望三，某些领域甚至领先全球了。

可是如果真如她所说，这么牛的大明，怎么让满清入关了呢？而且这么多年的光复活动，都没有能力把蛮夷赶走，到底是敌军太狡猾，还是我军太无？

这主要是因为满清钉在全国各地的满城，维持了治安和收税。

编注：清政府在全国钉下三十余处“满城”，用物理空间隔离八旗与汉人，形成特权孤岛。其主要功能是军事控制，其首要任务是拱卫地方、威慑反抗，并在需要时迅速出兵镇压叛乱。

同时，明末被文官集团集体抛弃也是一个原因。原本以为会像明朝一样，没想到最后把自己搭进去了。

子明：明清的统治阶层都不是啥好东西，大哥别二哥。

现在论富上的明清之争已经论民族主义的表现，和性别、贫富一样，本质上都是情绪的发口之一，没什么讨论的价值。

当今讲民族大团结，实际上也在过分突出汉族，容易引起他人的反感，舆论上不好捏。三十年前，中华民族概念还是强调汉族为主的主体，只不过，当下社会不强调汉族主体，只强调中华民族，有些挖空概念的嫌疑。

## 关于清明的命运，明公有什么推荐的书籍吗？

子明：没啥推荐，就是单纯的统治阶级在开历史的倒车。说白了，在发展和安全的问题上，明清都不约而同地选择了后者。

统治阶级的第一要务是维持自身的存在，第二是维持自己的统治，发展科技的重要性必然要往后排。

当前的文化行业要从历史教育中多汲取营养，像明清这种离得的朝代影响也相当大，而且是从先进到落后的过程，很有研究价值，多研究其统治为何造成衰落。修史是服务几十万人，现在修清慢，就是为了十几亿人传承。修史的本意就是要尽力超越史和局限。修史的本意是要证明我是合法的。

子明：嗯，修史是为了证明那个字：受命。

从古至今，统治的首要逻辑都是存续，而非进步。而明清的选择，虽然在短期内稳固了政权，却在长周期中错失机遇。其中的权衡，至今值得我们思考。

## 02 理想主义者的“成分”

12月6日 21:36

我最近也在B站看一些政治相关，看了一个《芳华》解读，就被惊了。电影已经说得很白了，基本上就是在召唤。

小时候我就知道，世界上没有绝对公平，用一切努力不过是让自己更公平，革命不过是在追逐一个不存在的公平。但世界上终究有理想主义者。

三十之前谁不是理想主义者，三十之后还认为是理想主义者，也是。或许大部分理想主义者会被淹没，总还是留下一些。郭纲说过，三十之前没有出息，三十之后肯定没出息。未必，马斯克就是一个理想主义者。特斯拉是一家机器人公司。这一点，马斯克说得很透。在他巨大的蓝图里，汽车只是机器人的初级形态。SpaceX、Tesla和xAI，正在底层变成位一体。这才是特斯拉的底色，它是现实世界的顶级玩家。

ChatGPT、Claude和Gemini这种AI确实聪明，但它们是活在服务器里的，它们处理的是文字、图片、视频，环境是安全的。但特斯拉的AI面对的是打滑的路面，刺眼的光，突然冲出来的物理定律。

马斯克当时还说了一句很有面的话：由太阳能电的卫星就是未来。SpaceX创造载体（宇宙飞船）、Tesla创造肉体（机器人），xAI创造灵魂（超级智能）。马斯克是个饼大师，先改造地球，再改造星球。

怎么只相信人民的理想主义，不相信资本家的理想主义呢？我觉得马斯克的设想未必荒谬，无非是在这一代人不能实现。按照目前人工智能迭代的速度来看，我们都有可能看到那一。

子明：人民的理想，资本的理想，共同推动着社会的进步与发展。

子明：既要允许一部分（马斯克）先富起来，也要让先富起来带动后富。

当我们近观历史，民族就好，阶级坏，总会发现明清之间的种种不同。但当我们拉远视野，从宏观角度来看，明与清都是统治阶层上开启了倒车，让我们错失了历史中的各种机会，最终走向了落后挨打。

修史的本质，是扎根过去，塑造未来。理想主义的价值，是敢于相信未来。对于为了民族和人类未来奋斗的“理想主义者”，别让阶级属性淡化了其本真。让金石之声，也鸣初春的薄雪。
