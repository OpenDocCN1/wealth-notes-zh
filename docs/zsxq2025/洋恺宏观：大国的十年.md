


# 洋恺宏观精品文章

# 大国的十十年

对一个国家来说，十年的时间足以改变很多。有些抓住机会的国家，能够迅速实现崛起；有些误判形势的国家，则有可能走向衰落。

## 崛起的十年：苏联的重工业计划(1928—1938)

苏联成立后，一度面临内部忧患的局面。由于遭遇了苏波战争的失败，苏联搁置了对外的想法，转向内政建设。在经历了残酷的权力斗争后，斯大林成为新任领袖，他决心带领苏联实现工业化。

1928年—1938年，苏联用了十年的时间，就从落后的农业国建设成为欧洲最强工业国。斯大林接手的是一个烂摊子，但在他带领下苏联工业产值以年均两位数的速度增长，特别是以国防为代表的重工业，这些后来为卫国战争的胜利奠定了基础。

为什么苏联能实现跨越式发展呢？很重要的原因是抓住了历史机遇。1929年美国爆发经济危机，进而演变为席卷全球的“大萧条”，大量企业倒闭。为争夺市场，西方的资本家纷涌前往苏联寻找机会，确立了“市场换技术”的贸易模式。大量外资涌入这个社会主义国家，使苏联以较低成本获取西方先进技术。

然而在军事领域，英法美依旧对苏联实施极为严格的科技封锁。为绕开限制，苏联主动寻求与德国发展关系。作为被“凡尔赛条约”限制的国家，德国虽然有世界一流的军工技术储备，但无法将其投入实验和生产。西方的孤立政策使德国积极向苏联靠拢。苏联为德国研发新式武器提供厂房和土地，并利用这个机会观摩现代化武器的生产流程。

为推进工业化建设，斯大林执行铁腕政策，不惜一切代价从农村榨取资源。其农业剪刀差的做法让农民陷入贫困，拥有土地的乌克兰甚至濒临饥荒。

但斯大林成功利用西方国家在经济和外交上的盾牌，为本国争取到最大利益，为苏联的国防现代化奠定基础。如果没有这十年的积累，苏联绝无可能打赢二战，成为与美国并立的超级大国。

## 衰落的十年：苏联由盛转衰（1979—1989）

从绝对实力来看，苏联的巅峰期出现在70年代末。此时正值勃列日涅夫执政，当时西方处于第二次石油危机之中，高通胀和高失业同时出现。苏联的钢产量、石油产量及工业指标均超过美国，陆军装备与核弹头数量北约总和还高。根据西方评估，如果爆发世界大战，苏军能在一个月之内打穿西欧。

然而仅仅隔了十多年，苏联就走向衰落。很多人把苏联解体的原因归结为戈尔巴乔夫的软弱，但早在勃列日涅夫时期，苏联就已经走上了下坡路。勃列日涅夫依靠变法把赫鲁晓夫赶下台，起初他重用柯西金，试图引入商品经济。然而在既得利益集团的反对下，柯西金改革以失败告终。为了赢得保守支持派的支持，勃列日涅夫停止了改革计划，继续沿用计划经济。在放纵下，苏联的特权阶层迅速膨胀，吞了这个国家大部分资源，民生则日益艰难。在外交上，苏联转向大国沙文主义，与中国爆发边界冲突，最终把昔日的社会主义盟友推向西方阵营。1979年，中美建交，依靠中国的廉价劳动力，西方成功摆脱通胀问题，经济恢复内生增长。

在中东，埃及放弃了亲苏政策，转而与美国改善了关系。苏联失去了中东最重要的代理人，缺少干预油价的地缘杠杆。在美国的促使下，80年代 OPEC大幅增产原油，使苏联陷入财政困境。另一方面，中越战争使苏联失去了东南亚地区，作为补救，苏联侵入阿富汗，试图打通印度洋出海口，结果陷入了漫长的战争泥潭。从1979—1989年，苏联用了十年就从巅峰时期转向衰落期，包括普京在内的年轻人集体见证了红旗落幕的过程。

## 崛起的十年：日本的经济腾飞(1950—1960)

二战后，美国曾试图拆除日本所有工厂，使日本沦为农业国，摧毁其发动战争的能力。当时的日本人一度惴惴吾安，担忧自己国家的未来。按照罗斯福的设计，中国将成为战后亚洲的领导者，协助美国共同治理东南亚。罗斯福的去世改变了历史进程，杜鲁门政府并不愿意在亚洲身上消耗太多资源，在援助问题上拖泥带水，坐视政府在战场上的失败。

新中国成立后，美国曾试图以台湾为筹码，换取中国在美苏之间维持中立。不过新中国还是按照既定路线，奉行“一边倒”的亲苏政策，没收西方在华资产。1950年，朝鲜战争爆发，杜鲁门政府将其视为丢掉大后盾的连锁反应，为遏制共产主义在远东扩张，避免触发多米诺骨牌效应，美国以“联合国军”的名义出兵朝鲜，进而与中国爆发冲突。

## 衰落的十年：日本泡沫破灭（1990—2000）

上世纪90年代初，日本迎来经济巅峰，人均GDP超过美国，成为世界上最富的国家之一。以汽车、半导体等领域领先，日本积累了财富。1964年，日本举办东京奥运，也就是这一年，日本GDP超过西德，位居世界第三。然而苏联解体让日本失去了战略价值，日本无法解决老龄化和产能过剩问题，房地产泡沫破灭，社会陷入死缩。整个90年代，日本经济陷入通缩，人均收入停滞，国家看不到未来，“平成时代”取代“昭和时代”。直到2012年后，随着美国将中国锁定为头号对手，日本重新具备战略价值。在亚洲压力下，安倍推出了宽松政策，依靠汇率贬值刺激出口。在“安倍经济学”的驱动下，日本表现出通缩迹象。平成时期的代人，青春早已不在。

## 崛起的十年：中国与全球化红利（2001—2011）

1997年，东南亚金融危机爆发，这场危机迅速席卷东亚，中国外贸受到严重冲击。当时国内经济形势并不乐观，一方面是各种压力，另一方面企业经营困难，多地出现下潮。一些西方人提出“中国崩论”，令人心惶惶。

在悲观的情绪中，机会在酝酿。1999年中，两年后中国正式加入WTO。那时美国正处于全球化最自信的时期，对本土制造业竞争力明显高估。最开始美国试图把中国当作倾销市场，认为贸易有利于美国企业。然而加入WTO成为中国经济腾飞的起点，2001年—2011年，中国创造了历史上最大规模的工业化奇迹，按美元计价的GDP翻了6倍，取代欧美成为世界工厂。

中国的经济奇迹离不开00年代的全球化红利，依靠全球市场，东南沿海成为最富裕的区域。中央凭借东南沿海缴的税向西部提供财政转移支付，并通过房地产转换为购买力。加入WTO后的十年里，中国依靠工业化和城镇化，借助人口红利，经济跨越式发展，世界迎来中美G2时代。00年代是读书性价比最高的时期，正值高校扩招，很多年轻人顺利进入校园，并在毕业的时候赶上了随后的就业黄金期，那时各行业求贤若渴，愿意开出较为厚的薪资吸引届生。不仅如此，00年代楼市处于爆发期前夜，普通白领正常工作几年就能在当地买房。

美国一直后悔让中国加入WTO，认为这相当于养虎为患。但没有任何一个国家事先能想到中国发展得那么快，仅用十年就崛起为世界第二大经济体；毕竟东南亚也搞过出口导向型经济，但一场金融危机就让东南亚原形毕露。说到底，中国作为一个拥有深厚历史的国家，无论是国民勤奋程度还是政府治理水平，都远强于由土著文明构建的亚洲国家。美国的傲慢为自己培养出强大的竞争对手。

## 衰落的十年：西晋（从太康之治到八王之乱）

在中国古代，由乱到治、盛极而衰的案例很多。晋武帝统一中国后，实行轻徭薄赋、鼓励农桑的政策，社会经济得到恢复，史称“太康之治”。晋武帝去世后，皇后马后专权，她提拔了很多才，虽然朝廷斗争不休，但对民间产生影响。然而马后没有儿子，朝廷只能选择庶长子。为了保住权力，马后毒死了太子，这意味着司马家族失去了合法性。司马家族争夺皇位，西晋爆发了“八王之乱”，汉族军队在内战中消耗殆尽，西晋灭亡。
