


# 成事策略：最难抗拒的3个温柔陷阱

原创：U 君 公众号：U君笔记 25年11月16日

搞钱和成事的关键要素是什么？

共有3个：

1. 风口和周期的精准预判；
2. 能力和手感的反复打磨；
3. 精神和意志的绝对独立；

但是，现实太残酷，社会太狡猾，总有一些温柔的陷阱引诱着我们，让我们与上面三个成功背道而驰。

一旦你落入陷阱，很难看清局势，变得平庸、无力、匮乏。这时再想重新立起来，可就难了。

今天我就跟大家分享3个阻碍我们挣钱、成事、立起来的温柔陷阱。

## 1. 依赖

大概在2008年前后，我还在高中，我有两个非常好的朋友。

一个特别喜欢去哪里打游戏，高考之后他也整天待家里用电脑玩游戏（当时班上有三分之一的同学都玩电脑游戏）。

另一个长得很帅的朋友立志要做电视台的主人，，放弃了传统的高考路线，转而去学习“播音导”。

我描述的这两个人看似没有什么关联，其实很大的相关性：

玩电脑游戏的人变多，说明互联网时代马上就要爆发了；而后者还在努力进入没落的、传统的媒体行业——电视台。

但是明白人都其实知道，电视台、主持人，甚至艺行业、娱乐行业，当时已经开始下坡路了。

首先，主持人的平均薪资非常低，即使你是各大卫视的一哥姐，月薪可能只有一两万。

想要赚更多钱，就得自己去接广告、走穴。

而且，大家真正看的、家喻晓的主持也就那几个，一个手就能数得过来。

你确定你能成为行业内的翘臀吗？

即使你到了那几个知名的卫频道，做了知名的主持人，到了2018年左右，也没有什么人看电视了。

大家都在刷手机、玩电脑，即使电视剧也会通过互联网。

所以，指望着一个电视台吃一辈子的主持人，注定得很惨。

但是，有些主持人就很聪明（比如李湘），她在电视台赚到第一桶金之后，就开始转型为了做生意、做投资。

等到电视台彻底没落的时候，她的身分已经过了百亿了，而她的那些同事（电视台一哥一样）却在荧幕上死撑着、一个月拿万块的工资收入。

其实，李湘和她的那些主持人朋友明白一个事实：他们离开电视这个大平台之后，自己什么都不是。

但是，他们基于这个事实做出的选择却天差地别。

李湘意识到这个事实之后，就开始拓展自己的商业版图，逐渐脱离了电视台的控制。

她的那些同事们，却总想着忠于电视台、在舞台上坚守（落入了）“众星捧月”这种温柔的陷阱。

所以，他们的结局自然也是天地之别。

有人会说：你这都是事后诸亮，当时谁会预料到电视台会没落？

我的回答：

一方面，当时有很多信号表面说电视台已经没落（事实能说明一切）。

另一方面，明白人都知道，如果过度依赖某个平台，那么自己最终会肯定走上死路，所以必须另做打算。

类似的，如果某个人骄傲地说：我在大厂工作（某度、某团、某某条），月薪几万块，我要在这个岗位上好好做下去。加入微信引255你就知道，这个人很快就会陷入被动的境地。

原因也很简单，只要不是体制内的工作，那么裁员时刻早会到来；早则半年，晚则五年。

很少有一家公司十年以上的情况，常见的情况是：只要公司意识到你已经到35岁了，他们就会想办法把你“优化”掉。

所以无论你在电视、互联网公司，还是它的任何一个体外的公司工作，你可千万不要傻乎地一条路走到黑。

你要在鼎盛时期就开始给自己规划退路：要么准备跳槽，要么准备单干。

昨天我还在 VIP 群里说过一个观点：所谓的居安危、未雨绸缪这些都是贫瘠土地上的弱文化。你可以说这些是老祖留下的智慧，也可以说是这是一种悲哀。但是，既然我们摊上了，我们就只能居安危、未雨绸缪。毕竟，所有的平台都靠不住，这就引出了下一个：

## 2. 平台依赖

前天我在知识星球里发了一段话：从来不关心阅读量和粉丝数量，因为这些东西根本就不值。真正值钱的是自己的思维和写作能力。比如，“半个小时写出一有深度、煽动性的文章”这种能力才是稀缺的，也是真正需要培养的。

有了这个能力，即使目前市面上所有的平台都闭了，自己依然活得非常润。很多人看不透，他们整天追求粉丝数阅读量，这样让自己短视，也会忽视“周期”与“机制”。

原因二：

- 系统推荐是有周期性的，推荐时间超过一年，因为我做过调查。去年我记录了10个被系统推荐的账号，到了今年，他们几乎全部更新，而且之前的阅读量顶多十几。但是，我一点都不羡慕。
- 系统推荐是长期的，只要你的账号被系统推荐，就会引来很多陌生人（其中有一半是智商低的人）。这时候你只能写大众化的内容，稍微深度一点，他们就会举报你。
- 系统推荐是不断产生能量源的，如果你打造好了自己的流量流量，因为一旦系统流结束，你的积极性一下子消失了。
- 如果打造好了，这时候又获得了系统流，也是危险，因为新涌入的粉丝，大概会举报你之前的文章。
- 如果还没有打造好自己的收入，就获得了系统流，那么注定尝苦。

所以如果你也是做自媒体的，都要思考两件事：

- ①怎么把低质量粉丝筛选掉，只写高质量的迎合大众的文章；
- ②怎么打出一个完全自己的、完全可控的收入管道（如星球）。

## 3. 父母依赖

很多人都想摆脱父母的控制，但是真正独立的，是接纳父母的投资。

举个例子，无论你的父母智商有多低、眼界有多差，只要他们帮你了房付，那么后半辈子都很难了。俗话说，同样适用于亲子关系。你接受了父母的资助，你就忍受他们你所有的大事。

如果他们是世俗意义上的成功人士，那么你听他们指挥也不会吃亏，毕竟他们的经验比你丰富。

但是，如果他们是世俗意义上的失败者，智商极低、眼光差，只是为你交首付，然后想绑架你的人生，你就毁了。当然，如果有可能，就像我一样，只有大一费和生活费拿父母的接下来的所有费用自己挣。

这样的话，你很快就可以独立了。只有彻底独立之后，你才能拥有力量，你的天赋才有可能挖掘出来。很多人都落入了“被父母安排一切”的温柔乡里，反正自己也不用操心，舒服地享受人生好了。但是，“真正的选择”很快就会到来，可能是事业维度的，可能是婚恋维度的。由于你没有真正独立，当真正的选择来临时，你肯定会慌，无论是父母老师都帮不了你，只能由你自己决定。然后你就会发现，“争取独立”这个过程谁都躲过，而且这个过程可能需要5的时间。有的人无法依靠父母，所以在18-23岁之间实现了独立，从此以后就可以自己做任何重大决策；而有的人可以依靠父母，可能到了35岁才真正醒悟，真正有独立意识，他可能要用35-40岁的5的时间实现独立。有人会问：难道就不能一直依赖父母吗？我说：当一个人35岁、40岁的时候，他的父母可能已经老糊涂了，甚至不在世了。
