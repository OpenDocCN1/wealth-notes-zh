# 一、概述

- 2024年全球 RISC-V 芯片出货量中，中国占比超过50%。RISC-V 是一种基于精简指令集(RISC)的开源指令集架构(ISA)，其核心设计理念是模块化、可扩展性和开放性。RISC-V 满足从控制器到超级计算机的全场景需求，支持 FPGA、ASIC 等多种实现方式。其技术特点包括：

- 1. 完全开源：采用 BSD 协议，允许企业自由设计、制造芯片，并添加私有指令集，无需开放共享。

与 ARM 和 x86 比较，RISC-V 无历史包袱，兼具低功耗、低成本和高自主可控，适合物联网（IoT）和边缘计算场景。

- RISC—处理器支持端侧大模型推理，随着 AI 模型进入大规模应用，推理占总算力的比例持续提升，端侧应用蓬勃发展（汽车、边缘计算、AIPC），都会促进 RISC-V 加速增长；中长期看，RISC-V 具备逐步向高性能计算发展的能力与 GPU 竞争的潜力。

# 二、技术突破：RISC-V 架构的 AI 适配优势

### 1.矩阵指令集创新

RISC-V 的开源性与模块化设计使其在 AI 领域具备显著优势。例如，芯计算发布的 RISC-V 矩阵指令集采用参数化寄存器架构，支持从边缘到云端的 AI 场景，显著提升计算效率。

## 2. 低功耗与可定制性

RISC-V 架构允许开发者根据需求优化指令集，例如在 AI PC 中通过定制化设计实现 7B 参数模型的本地化推理，降低对云端算力的依赖。

AI 芯片创者 Tenstorrent 最新推出的基于 RISC-V 架构的 Blackhole 加速器包含768个 RISC-V 核心，峰值计算性能可达 745TFLOPS，超过了英伟达的 A100 和 L40S 加速器。Tenstorrent 的产品有望比同等性能的 GPU 系统便宜5到10倍。

# 三、生态进展：政策支持与企业协同

## 1. 政策驱动与产业联盟

中国主导全球 RISC-V 生态建设，占国际基金会会员近半数，推动技术标准化。

地方政策先行：上海、珠海等地通过资金支持与产业园区（如华发集团局）加速 RISC-V 与 AI 融合。

## 2. 企业技术突破

- 平头哥/阿里：玄铁 RISC-V 处理器支持端侧大模型推理，成本仅为传统方案的1/10。

- 奕斯伟计算：发布 RISAA（RISC-V+AI Architecture）平台，推动 AI 原生架构落地。
