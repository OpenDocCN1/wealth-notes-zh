


# 贫困基因携带的 5 个致命缺陷

原创：U 君 公众号：赢在8小时之外 2025年11月5日

## 1. 穷人总是被廉价的感情和情绪所捆绊。

熟悉我的朋友应该清楚，我经常经常按摩按摩，我也经常给那些按摩师出谋划策、让他们赚更多的钱。

上次有个技师跟我说，她平时也很喜欢旅行，去过很多地方，还出国过。

但是，她不敢在朋友圈聊这些东西，她担心那些顾客看到她的精彩生活之后，心生嫉妒，从此就不再光顾了。

因为有一次她在客户聊天时，顾客跟她说：“我都没去过拉萨，你竟然去过拉萨？！”

意外之外却是：“我是花钱享受的一方，你只是为我服务的，你的生活怎么能比我还丰富多彩？”

于是她再也不敢跟客户论这些精彩生活了，也不敢发任何有炫耀意义的朋友圈。

给她的建议是：一定要多爱美好的、向上的朋友圈，不要在意那些自卑而又大的客户，最好一次性把他们都得罪。

反之，你要把钱的优质客户筛选出来，只为他们提供服务。

因为人和富人存在着本质的区别，你无法兼顾。

一般来说，穷人是哀愁、情绪、廉价的情绪价值，他们在做决策时特别依赖自己的感觉。

而富人需要的规则、边界感和价值交换，他们在做决策时依赖的是底层逻辑。

所以，如果你是个吃过、玩过、见过的人，而且能够不吝啬地把自己的三观呈现出来、跟人进行讨论，那么就会呈现一种“大方”的感觉。

而这种大方的感觉，会让穷人吓退，但是会被吸引富人。因为越是有钱的人越有爱，越对美好的事物有感知。说句心的话，越是有钱的人越欣赏美女、美食、美景，因为他们早就摆脱了阶层社会的枷锁。

所以，如果你经常发那些让人产生美好联想的朋友圈（即使是路边的花草、小猫小狗），那也会吸引那些富有的人。

反之，穷人看到你这些美好的东西，要觉得你吃饱了撑，才会心生嫉妒、自卑等负面的感受。

大部分人都是“幸福小鬼”，当幸福降临时，他们会习惯地躲避、抗拒，无法坦然接受。

如果你想变钱，那就不要总是磨穷人的这些廉价心思，而是要尽早摆脱这些心思的束缚。

## 2. 人穷短，穷人群体里很少真正的“偏执狂”。

每个人都有强大、不服输的一面，因为这是我们生命力的体现。

但是，穷人喜欢廉价的事情上倔强，比如跟网友抬杠、互怼，在酒桌上跟穷朋友输赢。

一旦到了事业维度、个人成长维度，他们就立刻化身为“平庸之辈”，没有一点激情，没有任何见解，得过过、随大流。

富人则恰相反，他们很少在无意义的事情上跟别人争论，因为他们知道这样做回报率太低。

反之，在事业维度，他们的理念和行为都非常积极、偏执，自己认准的事情就要一条道走到黑。

要知道，偏执的人大概有50%的概率能做到，从而实现人生逆袭；而平庸的人有99%的概率会一直平庸下去。

所以，你可以回忆一下，在过去的10年里，你在个人成长、事业规划等维度，有没有过“力排众议”“豁出去”的瞬间？

如果答案是否定的，那么几乎可以断定，你在最近这10年里，人生不会有大的转折。

因为随便一个阿猫猫老狗吼你一下，你就吓得立刻缩回角落，继续任人拿捏、任人宰割。

相反，那些在特定领域取得重大成就、赚到大钱的人，肯定都经历过一次或者多次“豁出去”的瞬间，甚至把你身边的人都得罪一遍。

当你不顾众人劝阻、一意孤行的时候，大家都说你太倔强、太偏执、简直不懂人话。

但是，当你取得成功时，大家就会这样评价你：“我早就看出来了，你是个与众不同的人。”

顺便说一下，如果你想做自媒体、吸引粉丝，你必须说一些世俗的言论，如果你是个平庸之辈，大家凭什么会关注你呢？

就拿我自己来说，大家之所以愿意关注我，就是因为我与众不同、吸引眼球的言论。

有一本书叫《只有偏执才能生存》，我觉得这句话放到今天合适不过了。

因为人均资源极其稀缺，偏执不是为了出人头地，而是为了生存。如果你追求平平淡淡、与世争，那么连生存都是个问题。

## 3. 穷人的执行力和意志力都非常不稳定。

我赚钱之所以比同龄人要轻松很多，就是因为我有铁一般的执行力。

举个例子，当我意识到甜食对身体有害的、会让我发胖，我就把所有甜食、甜味饮料都戒掉了。

有人会说：偶尔吃一下还是可以的，也能让自己分泌多巴胺、感觉到小确幸。

在我看来，这种人什么事都不成，因为他们的原则太差了。

如果让这种人去做一件有积累性的事业（比写作），他们肯定会三天打鱼两天晒网。

今天心情不好，就不写了；明天生病了，也歇一天……

结果就是，很快你就做不下了，因为根本没有粉丝愿意关注你这种意志薄弱的博。

我自己就是去年做手术那天天都坚持更了一天，其余时间都保持日更1-2，所以活该我能赚到粉丝、赚到钱。

经常有人咨询我这类问题：心情不好、情绪不好时该如何调节？因为感觉已经明显影响到自己的工作和学习了。

我的回答是：我的脑子里根本没有“快乐”情绪这些概念，而且看来，这些词汇都是废物的专属，都是人为制造出来的的概念。

之前在《丛林社会10大生存法则》这篇文章里我提到了一个观点：动物身上有很多值得我们学习的地方。

比如，狮子每天需要出去捕猎，如果追逐了半天的羚羊，结果一只都没抓到，它本身不会气馁，会在原地休息，等待下一次出发。只要狮子状态健康，它就不会出现“心情不好、不想捕猎”。

人类其实一样，你认为“情绪”是真实的，那么你就会受到影响；如果你脑子里没有这个概念，你就就不会受到影响。

那些整天忧吟的人，就是因为把情绪看得重了。我自己也是这样的，确实能清晰地感知到，能量是有起伏的，每天的状态是不一样的。但是，我不开心时，也会假装自己开心，然后去做。

可以说，我不信情绪的力量，我相信事情的力量。做了事情，能量自然就舒畅了。这些概念，你越关注，就越会强化它们。结果就是，小的不开心变成大的不开心，短期的情绪低落变成长期的情绪低落。很多人会被这些概念困扰，就是因为他们从来不做事，每天都在胡思乱想。

## 4. 穷人太容易被消费主义洗脑。

人手里的金钱和精力都被消费主义走了，结果就是，自己也没有能量去成长。

之前我听到过一种说法：如果一个人的手机用了4年以上（而且还没卡顿），那么这个人的收入肯定高。因为他的眼光不一样，能筛选到手机。

但是穷人就容易被消费主义洗脑。一方面是因为他的眼光不够，不能筛选手机测评时间；另一方面是因为他们特别容易被广告诱惑，为了买新款手机，给自己增加额外的支出。

另一方面，他们特别好面子，认为用新款手机就能让人一看。结果就是，每两年换一部手机（损失2000元以上），执意要买车，而且他们的现金流被持续吞噬。

假设一辆新车，买回来当天折旧3万，而且平均月还要支付2000元额外费用（保险、保养、油费、停车费等等）。有人会说：下雨天你只能等公交、骑自行车的时候，你就知道没幸福了。我想，买车的幸福跟现金流根本没可比性。我在《小康生活和财务自由》这篇文章里说过：本金、资产都是虚的，现金流充足才是幸福的关键。

## 5. 穷人始终看不价值交换的本质。

穷人总想着往上交，由于他们无法理解，所以总是吃闭门饭。

上次我在《最重要的5件事》这篇文章里讲过一个读者给我的真实的案例：他有一个亿身家，但是遇到困难了，跟哥借5万，没想到被拒绝，于是他觉得哥太冷血。我说：不能怪人家，你眼里没有任何本事，你没有家人，如果把钱给你，大概是要不要回来的。他之所以成为亿万翁，是因为他非常吝啬，知道什么是资产，什么是负债。如果他是重感情的，今天借出去5万，明天出去8万……就不可能成为钱人。所以，外面的豺狼会把他的家里掏空。

你想得到贵人的帮助和提携，就要拼命提高自己的价值。举个例子，如果你是一名医生、老师，或者你是个二手车贩子、房产中介，哥肯定不会拒绝你，因为他知道哪天就能用到你。当然，在社交媒体发达的今天，最适合年轻人积累的资源就是影响力和关注。大家想一下，我在公众号上有几万粉丝，但是你知道能撬动的资源有多少？一方面我不缺资源；另一方面，如果我遇到医疗、法律等方面的问题，粉丝第一时间站出来为我提供援助。即使哪天我遇到了不正对待，我也通过互联网平台发声、引起关注，从而促进事情结局。
