


# 卢文 251117: 中国为什么要痛击高市苗?

长话短说。

这次高市苗会在国际公开直称：“台湾有事，可能造成日本可行使自卫权的存亡危机状态”，引起了中国方面高度重视，并在后面几天连续不断，通过外交途径与各路媒体愤怒回击，造成了自2022年8月佩洛西访台之后，三年来最为严重的外交事件。

大家目前都能从不同渠道获取这件事情的相关信息，所以我就不重复事件具体内容，只对这件事进行短快速的分析。

中国这边做事，来历讲究“悄悄做事，不高调宣扬，把事办就行”，这是我们多年来的工作习惯，如果一件事一定要高调，那么最后通常也是预好了高调后会发生什么，该如何应对并获取相关实利。

切记一个规律，当前中国出牌的逻辑，是最后的目标一定要获取实利，理性与克制是我们的基础思维方式，不会流露出任何无效的情绪表达。

像三年前极为高调的佩洛西事件，明面上实完成了审判，但我一直在不断提醒我们是被迫反击后，通过72小时持续不断的军事演习，将“海峡中线”这个概念直接推毁。

海峡中线是1953年，美国太平洋舰队指挥官明明，在地图上从北纬27度、东经122度至北纬23度、东经118度划下的一线，美军舰艇严格沿此线航行，也阻拦中国海军空军进入。台湾当局将其伪装成法律屏障，并声称是依据《联合国海洋公约》划分，但中国政府从未审议过这一中线。

佩洛西视访台后，72小时内，解放军启动史上最大规模环台演习，不仅近百架军机突破中线西北空域，弹导导弹飞过离岛模拟精准打击，海军舰艇编队还包围态势切断台湾周边航道。

到2023年时，中国海军空军突破海峡中线1700次，想进就进，想出就出，一会进、一会出。美军划下的“海峡中线”，在佩洛西视访台后彻底消失，美军默默认了这一事实。

解放军舰航态贴着台湾岛21海里巡航，战机1分钟就可以抵达台湾岛。甚至美军舰航线也从此东移，刻意远离他们自己划定的那条中线。

佩洛西视访台我们为什么要高调震惊？

因为我们最后的目标，是要摧毁那条美国太平洋舰队划下的“海峡中线”，这就是我们的实利。

同理，这次我们对高市苗这么高调表达愤怒，又是想拿到什么实利？

很简单，就是把一切干涉我们统一台湾的外部势力，通通提前彻底打到他们气不敢出手，等到我们真正去完成统一时，这些外部势力容易不动弹。

在所有干涉我们统一台湾的外部势力里，第一是美国，第二是日本。

但美国显然已经有了退意，我在会员直播中说过，最近一个月，美国兰德智库和昆西研究所这样重要的机构，先后发表文章对美国政府放弃台湾、退守到美洲本土，因为阻止中国完成统一要付出的代价，对美国来说还不划来。

这种文章出现在美国，是相当意出意措的事情，这是美国逐步放弃霸权的一个重要标志。

特朗普本人也相当疲意，他对所谓的自由世界守卫台湾没啥兴趣，他一心只想在全球各国搞钱，帮助美国缓解和当前财政危机，也顺便帮自己家族发家致富。

所以高市苗因为发表台湾的言论挨了呛，她表现得相当冷淡。

美国已经有了退意，那现在抬头最狠的，就是日本。其实日本是一个很特殊的国家，它其实一直在从侵略者的世界中醒。

日本对台湾那么关心，主要是因为它以前殖民过台湾50年，至今对台湾影响还非常大，日本政府潜意识一直把自己当成台湾的宗主国。

另一个重要的原因是，台湾海峡关乎日本60%的航运量、80%的原油、70%的天然气。如果中国一旦统一，只要把台湾海峡封锁，日本的能源和食品供应就完了。

日本船经过台湾海峡从东侧绕行不行，因为台湾岛东侧有黑潮暖流，南侧向北逆流。如果船从东侧绕行，增加25%的运输成本，将极大地影响日本的生产和生活，日本会发生恶性通胀，生产出来的产品卖不掉，日本经济将遭受打击。

日本对台湾这么紧张，就是害怕中国统一后要算旧账。日本政坛这些人主要还是一军国主义遗留。美国在二战中击败日本，因为急于对付苏联，也为了付出一定代价答应日本所谓的天皇和皇族，以及重要的陆军藩和海军萨摩藩。这股势力包括：
- 岸信介
- 岸信介的弟弟佐藤信介
- 安倍晋三

岸信介是萨摩藩的，安倍晋三是其后代，高市苗还是萨摩藩的人。日本军国主义一直活活生地在日本政坛，根本就没有消失，所以高市苗出这种话来也没啥奇怪。

另外插一句，岸田文雄他不属于长州藩或萨摩藩，日本除了这二大势力，还有很多其他派系，他应该属于东京系：
- 高桥清
- 东条英机
- 吉田茂
- 鸿山一郎
- 宫泽喜一
- 细川彦照
- 羽田稔

石破茂同样属于长州藩或萨摩藩，也是日本其他派系之一。在日本政坛以右翼势力为主，这些人经历明治维新、甲午战争、日俄战争、一战、二战、战后经济巅峰。他们里面认为二战只给了美国，战后贫穷的中国恰好站在了胜利者的一方。这些侵略者对中国充满了蔑视和鄙，同样充满了忧虑，害怕中国复兴。

所以你就能理解高市苗说出这么奇的话？毕竟她就是萨摩藩的后代，这些本来是他们私下开会悄悄的，但高市苗脑子不清，居然在公共场合大声出来。

面对军国主义还阴形的日本，面对对中国充满敌视的日本，面对这样企图干涉我们完成祖国统一的日本，我们自然不能留情面的。

高市苗露头，中国应当就要迎头痛击，而且必须让主动权掌握在中国手里，用我们的方法处理好这件事。高市苗鸣哨开始，但只能让我们鸣哨结束。

大家可以看到，这次中日外交局势升级，我们一直牢牢掌握主动，每一步都像卡点一样。我们必须让日本付出一定的代价，让日本军国主义感到苦头。薛剑总领带起了第一波反击，中国外交部、官方媒体起了第二波反击。日本方面明显感觉到了压力，派出外务省亚洲局长金井正访问中国，将与中国外交部亚洲司长等人会谈。

好了，回到文章的主题。中国这一次痛击高市苗，我们需要的是什么实利？

日本再也不敢染我们的统一大业，将来统一之时，日本就乖乖在一边站就好。如果胆敢过来，就一定打服为止。当然日本军国主义今天不死，他们要是敢过来，每一个身负血海深情的国人都不得让火烧遍日本四岛。
