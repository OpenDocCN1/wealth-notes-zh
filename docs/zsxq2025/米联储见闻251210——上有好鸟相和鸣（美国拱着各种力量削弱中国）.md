


# 米联储251210——上有好鸟相和鸣
（美国拱着各种力量削弱中国）

你好，我是米筐。

美国现在一方面跟中国你依我我依，一边拱着各国力量来削弱中国。越南选择了韩国开发高铁，印度智能手机的出口超过中国，巴西提前八年底与中国签订的稀土合同转向美国，日本在第一线跟中国在军库摩擦上来回圈撕消耗中国的精力，台权政府甚至喊出台湾已经是独立主国家无需宣示，并彻底否定洛宾和波尔坦坡旧金山，只承认什么安全策略似乎对华敌意。但这并不是个雾弹、缓兵之计，针对中国的围圈没结束，依旧是经贸外交三重奏，而且进入了胶奏阶段。美国现在就是通过千万百姓拖累中国发展经济和科技，快速实现美国的再工业化。

今天，川普接受美专访，重申自己和中国领导人关系好、通过谈判解决稀土问题，似乎给外界一种美国在稀土上仍然需要中国的假设，但实际上日本早在十年前就开始进行稀土替代计划，美国明修道，日本暗渡陈设，造出一副中国可以用稀土卡完全世界的假设，但实际上，中国在稀土方面的差异性优势却有可能没有那么不可替代。

2010年，中日钓岛发生争端期间，中国曾实质性切断对日本的稀土出口，此后，日本就已经悄然构建起一条大幅降低其对中国依赖程度的供应链。今天外媒披露，这一举措成为日本政治风险的重要保障。现在的日本成为美国的可借鉴路径，现在美国还需要时间确保足够的稀土供应。但日本的情况表明，摆脱中国掌控程度极大，需要政府持续与国际伙伴攻关。

2010年9月，一艘中国渔船与日本海上保安厅只在钓岛附近发生碰撞，事件升级为外交和经济危机。日本扣押了中国船长，中国当时未事先通知便实施了为期两个月的稀土出口禁令。当此时产业界负责汽车车辆的主管向内警告稀土突然供应可能导致整个汽车供应链停摆。当时的日本拟定了一套15年前价值超过10亿美元的扶持计划，旨在降低日本本土供应链的脆弱性，其中包括大力支持日本企业拓展稀土来源渠道。

当澳大利亚矿业公司莱纳当时面临财务困境，正试图打造全球第一条不依赖中国的一体化稀土供应链，在澳大利亚开矿石，在马来西亚精炼。但该公司难以等到足够资金以扩大西亚精炼厂产能。日本综合商双日株式会社负责资源安全的政府机构和能源安全组织可谓提着拨款来解决问题的。2011年，JOGM与双日株式会社达成协议，向莱纳提供2.5亿美元的贷款和股权融资，这次交易为日本确保了长期稳定的非中国来源稀土供应。

如今这些从澳洲挖出来的稀土被运往约8000公里外的马来西亚关工厂，该厂直至今年仍在中国境外运营的大型稀土分离设施，原材料通过化学工艺精纯成足以用于生产的单一稀土氧化物。这些稀土金属再从马来西亚运往5000公里外的日本，由双日株式会社负责分销给日本内的磁性制造商。这些磁体被用于丰田等汽车制造厂商的各类产品中。

2010年贸易争端期间，行业估计日本90%以上的稀土进口来自中国，而目前这一比例已降至60%至70%左右。双日株式会社2012年首次从马来西亚工厂收到大规模稀土货物，并持续扩大稀土的种类。去年10月，其产品线新增了一种特殊的高温磁体原料。如今最大的瓶颈是马来西亚的精炼过程。稀土的化学分离会产生大量酸性废料和数以千吨计放射性残留，妥善管理和处置这些废物费易且 costly。2011年至2012年间，由于当地民众的强烈反对和法律诉讼，莱纳在马来西亚的工厂遭遇了数月的延迟。直到多次修改残留管理计划后，该厂才得以投产。所以，双日株式会社和莱纳斯的成本高于中国竞争对手，需要政府补贴支持。

日本对于稀土自主的尝试一方面体现了中国稀土优势确实还有，毕竟日本默默努力了15年，还是要付出巨大代价才能实现替换，但确实已经把这条路走通了。而马来西亚这条术也成为稀土技术的漏网之鱼，技术复制相对于技术开发可是快速的。日本挖了15年的地，其实就是在挖稀土大杀手，让全世界感受到中国的威胁，此时日本技术就成了奇货可亚洲。美国媒体此时亮出这个信息，也有助于中国士气的意义。

川普政府已开始投入联邦资金构建本土供应链，包括支持加利福尼亚州的美国唯一稀土矿开采项目，以及北卡罗来纳州和得克萨斯州的加工和磁体制造设施。美国签署了多项国际协议，旨在实现供应链多元化、减少对中国的依赖，合作伙伴包括澳大利亚、欧盟和日本，其中日本的协议是在川普10月份期间签署的。

日本认为中国打稀土牌对日本来说反而是机会，在局势中联合解决。过去15年来各国都在享受中国的低价稀土，日本一直在默默承受着高成本投入产出的买卖。如今除了中国之外，唯有从矿山到磁体完美的国家（美国）的规模效应降低成本。所以，日本已经开始加强跟中国合作。

台湾问题上，并不是什么气用，不是简单的政头，而是深思熟虑、处处考虑。相比于甜傻的中国人，日本手上沾满了血，因为中日关系中的任何波动都敏感。而且日本人的性格就是伪装，如果符合日本利益，日本一定会道歉；如果不符合日本利益，日本就会强硬到底。选择立场的时候让中国丢脸，政客消耗了大量资源和精力。

台湾问题引起了中国跟美国全力竞赛的一个后顾忧。关于台湾问题，美国的立场，没有够硬骨头的决心，就别整天揉得沙子。对于美国最近战略降温，台湾问题也别太当回事。美国人的嘴就是骗人的鬼，哪怕他不提一个台湾，如果台湾关乎利益，他出手还是会出手。就像日子写出来就是怨念别人一样，美国现在所有的外交文件也是写给对手看的，中国要真的信了就太真了。

美国的事情，当年在朝鲜战场吃过的少吗？美国人什么时候是个讲诚信的人了？什么时候不是被逼才低头？就连选择也是打打谈谈，花样百出，背信弃义是常态，妥协停下来。什么立场到底什么宝贝。这次来说就把台湾问题的立场彻底说清楚，接下来就别再打哑了。更别对美国的态度草木兵，什么立场锁定都不如雷达锁定，现在雷达照了日本还要解释半天，还要通知日本。中国要是道德上也这么廉洁，做事赖手无脚，那真是自缚双手，让利于他人了。

米糯祝各位晚安。
