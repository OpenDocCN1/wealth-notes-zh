


# 三界：诸天第一签

## 第三十章 意外收获

林峰，这个刚刚穿越来的者，此刻正陷入了深深的震惊中。

他没想到，来到这个世界后，竟然还能遇到这种意外惊喜？

虽然这只是个开始，但对于现在的他来说，简直太幸运了。

![](img/ac4ae6223cba4dc0b8c56491000eac62_0_0.png)

林峰看着眼前的系统面板，心中涌出一股难以言喻的喜悦。

这算什么运气？这可是开局奖励啊，简直是给力太给力了！

不过，这种运气，以后还有吗呢？

林峰自嘲地舒了一口气。

要是，这种运气，再来一个呢？

要是，这种运气，再来三个呢？

要是，这种运气，再来五个呢？

这可太不可能了！

林峰笑了笑，摇了摇头。

哪怕只有一个，这一个也足够了！

林峰深吸一口气，准备开始战斗。

接下来，该他的了。

林峰眼中闪过一丝凌厉的光芒。

战斗！

轰！

林峰的身形如同一道残电，速度极快！

对方甚至还没反应过来，拳头已经到了他的面前！

噗！

对方被这一拳直接飞出去，林峰顺势而上，脚尖点地，又是几重拳！

轰！

对方再次被这一拳轰出去，直接吐了一口鲜血！

这怎么还没死？林峰眉头一皱，看来防御性不错啊？

林峰眼色一冷，看来只能用大招了。

# 第一章 震惊系统

林峰看着眼前的系统。

系统，你是认真的吗？这难道是真的吗？难道我只是在做梦吗？

林峰深吸了一口气，他试图让自己冷静下来。他闭了闭眼睛，等再次睁开时。

林峰再次问道：“系统，你真的存在吗？”

“叮：系统检测到宿主情绪波动，建议保持冷静。”

林峰苦了笑了。“如果这是真的，那我现在该怎么办？”

“叮：宿主已完成绑定，现在为您发布新手任务。”

林峰愣了了一下：“新手任务？”

“叮：任务内容——前往学校食堂，向女神当众表白。”

“任务奖励：十万现金；失败惩罚：随机除一项技能。”

这任务也太离谱了吧！向女神当众表白？这在开玩笑吧！

林枫看着系统面板，觉得有些不可思议。“我不去！我拒绝这个任务！”

“叮：宿主拒绝任务无效，系统强制执行。”

林峰彻底崩溃了。

林峰深吸了一口气，他开始考虑现实。十万现金是真的吗？如果成功了，我就能瞬间暴富了！可是失败了呢？随机一项技能？

林峰咬了咬牙。为了那十万，只能拼一一把了！

林峰走出了宿舍。

食堂里人满为患。林峰环顾四周，寻找着女神的身影。很快，他在食堂角落看到了一个身影。那是他的校花苏清清！

苏清清正低头吃饭，清丽脱俗。林峰深吸一口气，朝她走了过去。

随着他的出现，目光都聚集了过来。食堂里渐渐议论声响了起来。

“那是林枫吧？他要去苏清清？”
“他是不是疯了？”

林枫站在苏清清面前，心跳到了嗓子。苏清清抬起头，眼中闪过一丝疑惑。

“苏清清，我有话想说！”

全食堂瞬间安静了。

“苏清清，我喜欢你！”

苏清清愣了，随即脸通红。“你跟我在一起吧！”

如上所述，所谓的“我”其实就是过去所决出的一个结果，你选择一个“我”，是你与过去所约定的，这个过程就是所谓的“我”了。

但你所认为的，其实并不是这样了。后来，我发现我可以和过去的自己达成和解了。

对于过去的“我”，你是不错的。于是没有了“我”。也许没有了“我”，我就有办法活下去”。现在可以选择未来了。

由于没有了“我”，我不再需要担心“我”。
