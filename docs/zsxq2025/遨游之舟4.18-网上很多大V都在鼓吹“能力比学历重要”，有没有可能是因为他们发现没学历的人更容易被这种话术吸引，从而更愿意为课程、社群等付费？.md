


## 4.18 为什么会有力

地球上数无穷的人都在研究“力学”，但有可能是我们研究力学的人要面对的问题是：力是什么？哪里来的？

人类发现力了吗？

事实上，导致力学现象等根源的不是某种神秘的魔法，而是……

结论：导致力学现象的主要有三个原因：

第一，为什么会有运动？因为有力的。
第二，为什么会有平衡？因为有力的。
第三，为什么会有运动的改变？

运动是由于力引起的吗？是的，由于力的。每一个物体，只要它的运动状态改变了，就受到力的作用。但是，处于运动状态的物体也受到力吗？

那么平衡是由于力引起的吗？是的，由于力的。每一个处于平衡状态的物体也受到力。但是，为什么有的物体处于平衡状态呢？

我们学习到的力是物体之间的一种相互作用。那么，如果物体之间没有接触，它们还会相互作用吗？为什么会受到力呢？

在物理学中，我们把这种相互作用称为场。

### “质量”就是由于质量引起的力

万有引力都是由于质量引起的，但有可能是我们研究引力的人要面对的问题是：引力是什么？我们感受到的引力是什么？

# 4.2 为什么万有引力

万有引力学现象等根源的不是某种神秘的魔法，而是……

万有引力是由于质量引起的吗？是的，由于质量。每一个有质量的物体，两个物体之间都存在万有引力。

既然每一个物体都有万有引力，那么，为什么我们感受到的引力只有地球的引力呢？为什么我们不会飞向天空呢？

我们学习到的万有引力是物体之间的一种相互作用。

牛顿和万有引力的故事是广为人知的。据说在某一个秋天，年轻的牛顿坐在苹果树下休息，无意看到一个苹果掉在了地上。牛顿在想，为什么苹果总是直直地落地，而不是向上飞或者向侧面掉呢？他开始想，是不是有一种力把苹果拉向了地球？接着，牛顿又想，那么月球是不是也有这种力？如果是，为什么月球会绕着地球转而不是飞向天空呢？牛顿通过推想，创立了万有引力定律。万有引力定律指出：任何两个物体之间都存在万有引力，质量越大，万有引力越大；距离越小，万有引力越大。

万有引力公式为：

```
F = G * m1 * m2 / r^2
```

其中，F是万有引力，G是万有引力常数，m1、m2是两个物体的质量，r是它们之间的距离。
