


# 江西连选连任省书记马强

从1988年以来，“家南”落在同一地，中共连任过五人的消息，似乎也很有传奇色彩。

不过并不是如此的，在2002年之后，巴鲁也连连拔升，这种速度让外界感到惊讶，甚至可以说是“快出名”了。

但是，那一次连选引起了广泛的关注，目标人物依然是江西主席。

我的意思是，这次显然不是在江西，而是在安徽。

然而，这次显然不是江西，因为江西的升拔速度并没有那么快，而是外界的目光也开始转移了。

三个月后，安徽也选出了新领导长，王富强也被称为“家南”的传奇。这种传奇与江西似乎有着深厚的渊源。

这件事传出后，安徽的消息引起了当地许多人士的震惊。在安徽的政治历史上，从未出现过这种连任的现象。

这就是安徽选出的老领导长，赵强（dtg2）。

在进入安徽之前，赵强在江西担任过省委主席，曾担任江西省委副书记。

在江西的任期内，赵强在2002年当选江西省委主席。

2003年，赵强调往安徽，出任安徽省委书记。

然而，江西的领导班子在2017年9月17日，江西省委选出了新的省书记马强。

马强，1962年出生，江西吉春人，毕业于江西师大学。

1993年，马强进入江西省委工作，1996年起任南南昌市区市长。

2001年，马强被升任江西省委副书记，2003年起任江西省委常委。

2016年，马强当选江西省委书记。

2017年，马强再次连任江西省委书记。

在江西的任期内，马强几乎一直在江西本土工作。

但是，江西的领导班子在2021年发生了巨大的变动。

2021年，江西选出了新的省委书记李信强。

李信强，1960年出生，山东济宁人，毕业于山东师范工业技术学院。

2003年，李信强进入江西省委工作，随后担任南昌市市委副书记。

2006年，李信强被升任江西省委常委，2011年起任江西省委副书记。

2016年，李信强当选江西省委书记。

2021年，李信强再次连任江西省委书记。
