


# 珍大的主题

【股票00101】港币对港股有什么影响 >

看到柯杨子红说：“想去投资港股的，怎么考虑汇率的问题。今年美国加权汇率，港币和美元是联系汇率，会一起涨。人民币美元现在是7.12，假人民币跌到6.8，那投资港股至少要有20%的利润才能影响它。”

首先，需要确认的一点就是美元的贬值趋势和人民币的上升趋势。虽可能人民币没有很快涨到6.8，也不是升幅的差异，美元的涨趋势确实如此。以此汇率的变实际确认应该是这样。

其次，股票的价值源于营业收入（以及利润），长此久的营业收入，收入的增长持续很久，增长速度快慢等等，总的，公司收入规模规模是非常影响因素。

那可以把港股的公司分成若干：第1类，公司收入是美元以及港股市等别的货币的，那即使意味着这些公司的情况不是正常的变化，但美元的贬值和港股并没有大幅波动，但人民币投资人把港股价换成人民币的时候，就就开始受到影响了。这类公司我们不熟悉，觉得大家应该不要坏掉。

第2类，公司的主营业务在大陆，营业收入全都是人民币会计，那港股价值在股市的时候，不需要未来的营业收入估值从人民币换成股市此，这是正常的逻辑，只要港币市值、人民币市值换成股市后，直接转换汇率增长了，只是这种涨跌的幅度港币对股市的幅度，在合理的情况下，应该是相当的。因此所能对冲。

日常看到的熟悉的港股公司，说白了都是我们讨厌的大陆公司，大部分属于这一类。

第3类，虽然是大陆的公司，但是其主营业务有海外的业务，那时人民币其实是有影响能力，人民币升值5%，海外的业务会随着规模的缩减，这决定竞争剧烈的行业的小企业，这种公司又不可能成为能上的，还需要关注规模，并行业上也有些竞争，比如某些高科技行业。所以此时，行业分析可能影响更大。
