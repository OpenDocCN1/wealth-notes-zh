


# 鉴茶财经 251020:从两融余额看短期波动

这一轮市场的大涨，是由机构发动，但是由两融推动。

![](img/10d027c4125bc0a727e74c027d9b8762_0_0.png)

目前，市场几路资金态势如下：

- 生产队在护盘，
- 外资在观望，
- 游资量化在乱搞题材和马字辈，
- 机构还在出货砸盘保排名，

还剩一个两融，两融，已经成为影响市场走势的关键。

两融若挺住或者继续加大流入，市场会上上涨或者横盘，两融若跌了，市场还要因“去杠杆”，有一轮惨烈的下跌。

之前谈过几次两融，我们再看几个案例，“如旭创，我们看出融资余额是下降的，这是部分带杠杆的两融被杀的卖出了，然而，它的股价是横盘带上升的，大概说明机会开始买入，

- 胜宏，融资余额完全同步于股价，说明融资盘仍不在抱团买入，它两融余额的高点在9月23日的172亿，当时股价已经跌了，但融资依然在进场，说明机构在高位把筹码派给了散户，如今又跌到了143亿，仍然算占胜宏流通值的6.47%，说明胜宏基本由两融控制，两融涨它涨，两融跌它跌。

相比之下，两融占旭创的流通值是3.58%，说明机构资金占优。

再看几个：

- 工业联，最后一轮补涨的超级大票，两融和股价跌跌跌，证明机构还在疯狂出货，“后排”科技没有企稳的态象。
- 中芯，完全是被两融带了下去，现在还没有企稳，
- 源杰科技，当时是大牛，两融被机构玩弄于股掌之间，那个大M型也到了，一旦你大买它立刻砸盘码卖给你，高峰时，每天两融有8亿，现在杀到了6亿。

现在波动平稳，机构掌握了局面，开始试探性买入。

- 德科立，融资余额倒头向上，但股价还在跌，这就可能是：
1. 主力在大力洗盘；
2. 机构在继续把筹码出给散户。

这两种可能性都有，两融和机构随时空转多，多转空，这时他们看谁？就看龙头股。

龙头涨，它们趋势跟上；龙头流，它们趋势洗盘。

现在的科技龙头就是两波人，旭创和胜宏代表海外算力，赛王和中芯国际代表国产力，所有都要看他们脸色。

目前，两融依然保持在高位，大盘却不涨反跌，严重缩量，就是最大的风险，有很大概率说明，机构还想把高位筹码给散户游客，利用市场的宽幅震荡和下跌击穿他们的杠杆，继续收集“带血筹码”。

如此，科技的周线级调整依然不能结束了，反弹只能先反弹而不是反转，主要的机会，如果你不想看老登的保险电锚之类，机会只会集中在中天胜宁这六家。

或者略带偏颇的说：

寒王中信能稳，则科创能稳，否则继续跌。

旭创胜宏能稳，则创业板能稳，他俩不稳中宁王也不支棱，还会继续。

战场胶着的时候，空头和多头都会调集所有的力量在最核心的几个标子上厮，谁赢了谁再去吃别人。

如果你技术过硬又铁锤，或者短期波动根本不意，以旭创和胜宏为代表的科技战场，参与方法是什么？

你号跌我就上，比如4%-6%挂上去抄底，一旦涨就立刻。
