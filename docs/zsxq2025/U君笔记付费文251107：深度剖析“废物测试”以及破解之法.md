


# 深度剖析“废物测试”以及破解之法

原创：U 君 公众号：U君笔记25年11月7日

昨天在 VIP 群里发生了一件不愉快的事情，起因是这样的：有个群友想要某一篇公众号付费阅读文章的PDF。

我说，所有付费阅读文章都在群公告的文件里里面，自己下下载就行了。

我最怕群友帮助，但是怕怕什么，然后真有群友给他发了PDF。

然后我就说了一些很重的话，我说，提供这种服务的人现在现实生活中是低收入的舔狗、龟男（这是我的真心话）。

后来我也为过过的言论道歉了，因为无论求助者还是提供援助的人，很可能都是学生（我的VIP群不欢迎学生加入，意识太差，不上道）。

前者太懒了，举手之劳却要麻烦别人；后者看到人提出要求，他就要牺牲自己的时间去帮忙。

在我看来，两者都是非常恶劣的习惯。

在社群里，偶尔发生两次这种事情，其实没什么损失，但是在现实生活中，大家一定要警惕服从性测试（废物测试）。

举个例子，如果有友/同事让你帮着带饭，或者让你帮着倒水，或者想让你开车稍一程，你可千万不要答应。

否则，你会面临非常严重的恶果。

比如，你帮助他一次，那么他以后就会一直找你帮忙，你就不好拒绝了。

对方请你做一些“他自己举手之劳就能做的事情”，就是有意的或者无意的服从性测试。

只要你答应了，那么在他的心里，你的生态位就是仆人、老母子，他以后就可以随意驱使你了。

所以，以后你再遇到对别人提出的“对于你们两个都属于举手之劳”的请求，一定要在第一时间拒绝。

比如，你的室友在床上，想让你帮他倒杯水，你就直接说：我很忙，你自己倒。

如果你的室友让你帮你带饭，你就说，我去完食堂就去拉屎（或者去图书馆、公园）。

如果你的同事让你帮忙一桩，你就说，不顺路。

有人会说：赠人玫瑰留余香，今天你帮了别人，以后你遇到困难了别人也会帮你。

大错特错！这属于纯处生言论。

另一方面，你今天帮了对方的忙，等明天你需要帮了，对方可不一定会帮你，不落下石就不错了。

因为连个举手之劳都要劳烦别人的人，基本都是什么出息、心怀叵测的懒货，你望他会帮你？

不信你可以打心里问一下，你是否好意思让朋友你倒水、帮你带带饭？这些是心智正常的成年人提出的请求吗？

另一方面，我并不反对帮助别人，但是要分什么情况。

就拿 VIP 群来说，如果有人问那种“百度一下就出答案”的问题，我肯定不会跟他说好听的话，我也会禁止其他群友提供帮助。

但是，如果有人个人遇到困难（如医疗问题、法律问题、创业问题、自媒体收款问题），这时他在群里求助，我和群友都会积极地给他出策。

因为后者提问显然不是因为自己懒惰和愚蠢，而是尝试过很多渠道、都得不到解决。

而且，这种形式的求助/解答的启发性非常强，群里围观的人会受益匪浅，功德无量。

所以，我绝对不是禁止大家互帮互助，而是不要免费帮别人去做那些机械的、无意义的、没有回报率的事情。

否则，别人并不会真心感谢你，只会觉得你就是比较好使的奴才而已。

服从性测试/废物测试之所以危害巨大，主要有两个方面原因：

一方面是因为隐藏性太强，对方会从一件“举手之劳”的小事测试你。大佬圈你如果立场坚定，很可能就中招了。

另一方面是因为兜患无穷，会给自己带来长期的、巨大的心理内耗。

比如，你答应了别人一次带小的请求（比如帮你带饭），第二次他再次请求你带饭时，你就不好拒绝了。虽然你的内心想拒绝，但是很遗憾，你已经错过了最佳时机，这时你再叽歪歪，就得显得你很谱了。

不过，只要你醒悟了，而且做出决断了，那么无论出现什么样的恶果，总比你一错再错要强很多。

另外，服从性测试可不仅存在于同学、同事和朋友之间，有时情侣、父子、母女之间也会有服从性测试。

我觉得变成熟的第一步就是“挑战权威、不再服从”。

我拿“亲子关系”和“情侣关系”来举例子的。

如果你对父母的话听听从，把工资都交给他们，当你申请请花钱时还会有罪恶感和负罪感，那么你就已经成成了他们的奴隶。

如果你认可我面上说的这个理论，那么下次再遇到重大的人生决定时，你可以自己做决定，不要总是听父母的。

当然，他们刚开始可能觉得你要逆不道，但是如果你想实现真正的独立，这个冲突越来越好。

我自己就是这样过来的，我以前一直想让父母满意，凡事都尽量顺着他们，出去旅行时也会给他他们。
