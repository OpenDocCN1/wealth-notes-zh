


# 为什么要禁止风水和占卜？

原文：赞优君群众众：赢在8小时之外 2025年7月1日

温馨提示：本文不会宣传任何玄学内容，只是客观地阐述，为什么禁止风水和占卜行业。

如果你去过HK或者日本，你就会发现，满大街都是风水馆、命理。

有些地方还有占卜一条街，全靠摆算命的，不仅有东方的五行八卦，还有西方的塔罗星牌。

最重要的是，这些都是合法合规的，受法律和工商系统的保护。

那么问题来了，为什么在这些发达国家和地区可以搞这些“封建迷信活动”，但是在印度可是为什么就不行呢？

表面上的理由是：有些不良商家打着占风水的旗号搞封建迷信活动，对消费者进行骗财骗色。

比如，有的“大师”谎称能消除困难，让大家掏钱买所谓的“法器”，还有搞网络占卜，骗户充值。

“某个招摇撞骗的大师睡了100个女信徒”这种新闻屡见不鲜。

在我看来，这些都是冠冕堂皇的说法而已，根本没有说到点子上。

## 1. 法治健全程度

无论是HK也好，还是日本也好，在几十年前的时候法制就已经很健全了，凡事都有法可依。

比如，“出来卖”要去特定的店里，什么项目是合法的，什么项目是非法的，规定的清楚楚。

当然，如果是个人进行X交易，法律上是不允许的，在实际的操作过程中，警察根本不会。从人文角度出发，成熟的社会一定会允许女性出卖肉体的，这是她们的权利，而不是被压迫。

从法律角度出发，警察不能为了这些“下三路”的情绪闯人的家里或者酒店进行抓捕。

- 一方面，酒店方不会答应（除非警察持罪犯的抓捕令和搜查令）；
- 另一方面，纳税人也不答应，我们掏钱养着你们，就是让浪费精力去捉好？

占卜这个行业也是如此，无论是HK还是日本，都有这方面的法律法规。

比如，你想开一家理店，需要申请什么样的营业执照，经营范围有哪些，收费标准是什么。这些这些规定的一清二楚，如果你全申请下来了，就可以开店了。只要你合法经营，绝对不会“黑无常”和“白无常”来骚扰你、勒索你。

而且，他们的“协会文化”也比较发达。

就拿日本来说，他们有日本经营会、日本占卜师协会。这些协会能提供学术交流、技能培训，还能做资质认证。

## 2. 协会保障

像美国、日本这种老牌资本主义国家，从来不会像社会主义国家那样宣传自己对工人和农民阶层有多好。

但是，在实际利益和保障方面，他们反而做得是最好的。无论是美国还是日本，他们的劳动工人和农民的收入、保障这些都比白领和大学教授。

为什么能做到这一点？因为他们有工会和农协之类的组织，而且这些组织不是吃饭的，他们会切切实实为工人和农民争取利益。

比如，去年美国发生了一起“让世界瞠舌”的码头涨薪事件。本来码头工人的时薪是39美元（约合280元人民币），然后这些工人觉得太少了，于是集体抗议、游行……最后那些资本家没办法，只能妥协，把他们的基本时薪上涨到了163美元（约合450元人民币）。

那么问题来了，凭什么工人一闹，资本就要妥协？

原因也很简单，因为工人背后站着的是工会，他们切切实实为工人的利益想着，工人的利益一旦受损，工会从来不稀泥，而是正面硬刚资本家。结果就是，美国的劳动工人收入可能高于大学教授。农民也是如此，无论是美国还是日本，都有保护农民的组织。

比起美国的“农场局联合会”和“全国农民联盟”，日本的“日本农业同工会”，简称农协。这些组织之于农民，几乎就属于工会之于工人，他们切实实地保障农民的权益（比如坚决不让农产品卖个低价）。

在这里，日本和韩国做得比美国都还绝，我在公众号里也讲过多次。比如，他们本国如果能产大米和苹果等农产品，那他们就不允许随便进口外国的廉价产品，以免冲击本土产品的价格，让农民利益受损。

我之前去韩国才发现了这个现象，本地的苹果10元一个，全国统一。也有进口的苹果，可能是美国或者澳大利亚的，但是20元一个，你想买的话随便你。但是，他们绝对不会允许3元、5元的苹果进入本国市场。结果就是，市民吃苹果时感觉很贵，是农民的利益就得到了切实的保障。
