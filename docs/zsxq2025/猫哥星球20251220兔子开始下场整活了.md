


# 兔子开始下场整活了

嘉宾供稿

首先，我们把目光投向委内瑞拉局势。

时隔3个月，终于看到我们关注委内瑞拉的局势了。

12月17号，王外长应约和委内瑞拉外长进行通话，我们表达核心内容就4点：

- 1、明确指出，中才是战略伙伴关系。
- 2、反对一切单边霸权行为了。
- 3、支持各国捍卫自身主权和民族尊严。
- 4、委内瑞拉有权自主发展与其他国家的互利合作。

这一系列态度绝对让蠢蠢欲动的美国虎棺一震，无异于挥旗鲜明地告诉美帝，委内瑞拉这事儿，我们也打算掺和一脚。毕竟这个骨眼上，还能说双方是战略伙伴并明确提出“反对、支持、有权”的话术，就可见一斑。

再结合上海马杜罗通话，并争取到俄罗斯的支持，可以说中俄正在联手站在委内瑞拉的背后。

那么，我们现在我们调停支持委内瑞拉呢？

个人认为答案只有1个，那就是台海。

近日，美国启动111亿美元的军售，也是历史上最大一笔军售。

包括战术网络和部队感知应用套件、海马斯远程精准打击系统及配套的陆军战术导弹系统、M109A7自走加炮、“陶式”导弹、标反坦克导弹、反装甲型无人机导弹系统、“鱼叉”导弹的翻新组件。

虽然这些武器更多承担的是防御功能，但武装到牙齿的目的明一看就清楚。美国要坚定不移的战略收缩西半球，那我们可以收回家，他要收拾自己家门口的事，爱折腾就折腾去。但如果是“既要、又要”，那就只能你做主，别怪我们做。实际上，现在的川普非常难受。

在外部，马杜罗得到了俄罗斯的支持（至于怎么个支持，我们拭目以待）。

在内部，12月12日，作为加勒比行动的指挥，美军南方司令部令霍塞尔提前2年突然卸任，据传原原因是国防部长哈格莱塞在如何对委内瑞拉的问题上出现了根本性战略分歧。

说穿了就是川普想打，但下面的人反对。这不仅犯了临换帅的兵家大忌，同时也暴露了美国内部对委内瑞拉局势的严重分歧。

骑虎难下，内外交困，所以才导致川普19号说“不排除与内瑞拉开战的可能性”。听着是威胁，但用我们东方语境琢磨，调子明显降低了。

之前马杜罗是孤寡奋战，外表强硬其实内心慌得一批，现在有了中俄支持，明显腰杆更硬了。说话，我是盼美军早早下场，只要马杜罗躲过美国的斩首行动，不要怂，那就有戏看。

其次，我们将目光转向东泰冲突。12月18号，王外长同东泰国外长进行了通话，同时外交部亚洲事务特使赴东泰两国进行调解，推动双方双向而行，尽快实现停火，重建和平。

看得出来，在川普外交失灵后，我们在冷谈处理10天后，终于启动斡旋了。

真正的大哥下场，局势应该趋缓。

那么，为什么现在我们出面调停了呢?

个人判断涉及3个方面的因素：

其一，洪森打出了最大的筹码——电诈产业区的背后股东名单。

柬寨的电诈产业在这十来天的冲突中，已经被泰国拆得七七八八糟了，现在也到了收网阶段。这个股东名单可以作为后续线索。如果洪森给我们，个人判断局势还有转机，但也仅限于短期，从长远来看，失去支持，柬寨目前的经济状况还会持续。

其二，柬寨和泰国都是东盟成员，我们也是最大的贸易伙伴，虽然双方存在明显的差距，各自都有很大的困境，一旦冲突升级，对我们来说也不是好事。我们的诉求是，至少可以修理一下，让柬寨目前的经济状况好转，同时修理一下泰国，摧毁缅甸的电诈产业。既然目的达到了，那就适可止。现在出门斡旋，还能进一步提高东盟的影响力。

其三，要防止越南趁机做。大家发现没有，今年东泰冲突期间，旁边的越南都展现出惊人的安静。要知道，洪森当年就是靠越南带路，一步走到今天，他和越南的关系可以说一般。而且越南南北狭长，缺乏战略纵深，一直观测柬寨甚至生吞了。

所以，面对泰国的要掀桌子，越南完全符合合理。那么，个人判断，也许越南起了柬寨、黄埔等国，中南半岛之所以处于平衡态势，主要是有泰国存在。想，一旦冲突升级，战火持续，且不说越南转移。

以上就是近日我们对内瑞拉和东泰冲突的个人观点分享，最后说一下体会：

因为老美的衰退和收缩，全球真空带来了很多机会，对于越南来说更加游刃有余。

实际上，越南的心思真的太多的。最近中俄火药味浓的时候，越南和日本在东京举行一场外交和防务副部长级磋商，期间敲定了安保合作，拿到了日本的防卫装备。

更过的是，越南作为西方国家之外唯一的东南亚国家穿越敏感地带。这说明，越南在告诉西方势力，虽然能容越南发展，但不得不防它趁机做大南半岛的地缘影响力，从而而乱兔子在地球以及东盟的整体局势。

因为全球政治变量越来越多，我们目前需要做的还是抓住中俄博弈这条主线进行开展。一旦中俄博弈分出胜负，那日本、菲律宾、越南等等，后面有一万种办法收场。当然，前提还是它们不能玩过火，或者甘愿当美国的炮友。
