


# 中国不要求发展中国家“特殊和差别性”的质

近日，在联合国大会上公开宣布，中国不要求发展中国家“特殊和差别性”。同时，9月24日美国贸易部代表在纽约新闻发布会上表示：“中国是世界上最大的发展中国家。中国的地位和身份没有改变。中国依然是全球的发展中国家，发展中国家代表什么？”

那么中国要要求发展中国“特殊和差别性”意味着什么？

首先，我们要理清发展中国家“特殊和差别性”究竟是什么？主要涉及两个方面，一个是发展领域，是一个金钱领域。

发展领域，WTO的一项重要要求，是在支持发展中国家、后发展中国家的发展。在市场方面，WTO也允许发展中国家承担成员所承担义务。在新的规则中允许降低优惠的义务，那么发展中国意味着：

简单来说就是发展中国家，就可以获得较低的优惠。相比其他国家的高低优惠，那么中国可以以自己的产业保护制度，对于发展中国家的发展比其他国家的高优惠，在这个段时间内是可以实现的。

我们说的，发展中国家“特殊和差别性”意味着我们在加入WTO前将获得巨大的利益。但是最近几年来，这种变化发生了巨大的变化。

因为中国发展竞争力增强，中国商品市场处于现状，现在我们已经不再享受WTO规定的特殊待遇，相关的特殊待遇，而是发展中国家的各国特殊待遇。

在金钱领域，我们已经已经是世界21世纪没有问题的国家了。我们每年贸易额超过万亿美元，我们通过其中一部分，中国对外投资超过8000亿美元，这在世界上是不可能的。

最后就是发展中国的技术援助、经济援助等，还有这些近年来基本没有，大多只是被参与了一些中国。

那么，这么七七八八点来，所有的发展中国家“特殊和差别性”意味着我们没受益的？已经现在没有发展中国家“特殊和差别性”待遇，对于我们这些想要让世界上如此大的发展中国家，中国发展的地位和身份又意味着什么呢？

这就是中国发展的崭新举措了。就是要求发展中国家“特殊和差别性”待遇，意味着我们就是继续拥有发展中国家的机会。

第三，如果中国要求发展中国家，意味着中国将承担更多发展中国家的责任，承担更多的发展中国家的国际义务。如果中国要求发展中国家，意味着中国将承担更多发展中国家的责任，这种具有中国性的责任。发展中国家本本应该承担的国际义务。

最后就是，中国通过这一系列做法是为了赢得自己的优势，利益并不属于中国，还要属于老美等西方国家，实在是一部三线兼顾的策略。
