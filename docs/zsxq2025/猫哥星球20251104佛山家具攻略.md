


# 佛山家具攻略

# 猫哥原创

上周我抽了几天时间去佛山买家具。为啥去佛山买家具，原因很简单，佛山是全国乃至可能也是世界上最大的家具制造中心，光是佛山一个地区就集中了超过2万家家具生产厂家，产业规模与集群效应非常突出，目前国内大部分地区我们能看到的家具，大部分都是佛山拿的货。

因为巨大的规模效应，所以佛山家具的性价比非常高，具体有多高呢？我的文章最后会给大家一个数据。

因为掌握了这些信息，所以买家具去佛山就是首选。

佛山有2万家家具企业，还有无数展厅与商场，在海量的信息面前，我该怎么去挑选呢？

首先我想到的是买手，也在两个头部买手公司交了定金，当时的我的想法很简单，面对巨大的信息不对称，找买手代表让他们分配一定的利益是应该的。

但是在网上查询一下，发现买手这个行业很深。一方面，买手利用信息不对称与家具厂串联，虚报价格，这个虚假的幅度可能是好几倍；另一方面，家具制造本来就是很复杂的，布料、皮料、石材价格千差万别，普通人看上去差不多的料（石材），买手更换一下品类，这里的差价就有好几倍。

还是那句话，永远不要用利益去考验人性，面对唾手可的利益，没有人能经起这种诱惑。

我曾经接触了一家著名的软装公司，他们方案设计很优秀，但是我们去看他们落地的案例时，一个600米的复式房子，软装公司给她配的家具号称是国际品牌的平替高仿，那个客户为此买单价格是120万，当时看着这些家具就觉得品质很一般，觉得软装公司可能赚了了不少——这一次我去佛山后实地估算了一下，软装公司付出的家具成本不超过20万。

6倍价差！客户真是冤大头。

同样，我接触这些佛山的软装头部的买手公司，初步给我报价就觉得不大靠谱，价格基本与我在重庆买卖差差不多（可能略微便宜一点），综合这些情况，我决定不找任何中介，自己干。

对于一个家具小白的个体而言，那么我该怎么去佛山选择家具呢？

首先，我给自己的定位是不去任何卖场展厅，直接找靠谱的源头工厂。

为什么不去卖场展厅？

因为很多卖场展厅其实都是经销商在经营，这些经销商良莠不齐，加上家具行业水很深，实在害怕踩坑。

那么怎么才能找到靠谱的源头工厂呢？

我动用的是AI。

最初我设置的搜索关键词是：佛山、现代轻奢风格、口碑比较好的家具工厂。这个搜索出来结果一大堆，把这些搜索结果放到其他平台去搜索对比一下感觉好像也不大靠谱。

第二次设置的搜索关键词是：佛山、现代轻奢风格、著名的家具工厂。这个搜索出来结果也是一大堆，与上面的有重复，但是重复度不高，感觉心里也有底。

第三次灵机一动设置的搜索关键词是：佛山、现代轻奢风格、给国外品牌家具做代工的家具工厂。

然后做了一个攻略，拉了一个名单，赶到佛山后就去第一家觉得最靠谱的工厂。

当时早上迟到这个厂家之后，厂家的销售人员非常吃惊，因为平时能直接去他们这里看家具的或者是经销商，或者是买手带来的，客户自己主动找上门的非常罕见——销售总监还反复确认我们是否是第一次独自上门。

我就问，难道经销商或者买手带客户上门，与客户自己上门价格有多大区别？对方回答，经销商带客户上门厂家还要点30%，买多少没有说，这是内部约定。

然后我就与销售总监聊天，了解佛山家具市场状况，结合我前期搜索的资料，大致就七七八八比较明确的目标了。

接下来就是跑几家比较靠谱的厂家，为了避免大家觉得我在打广告，这里就不提厂家名字了，反正最后就是在两家比较大、业界口碑也比较好的厂家之间选择。

佛山家具报价比较混乱，这里水也比较深。

举个例子。

我去一家卖场都有5万平米的厂家，当销售人员确认我是直接客户时，家具报价直接是厂家刊价打4折，然后主动给我说，他还有9折权限，这么层层折下来，相比重庆已经很有性价比了。

销售人员又愣了一下，给我说，找老板最多还可以优惠30%。

再优惠30%是什么概念？

这么给大家说吧，如果在重庆商场买同品质的家具，在佛山基本就相当于……
