


# 【助理播报】

国际：

1. 美国犹他州州长潘塞·考克斯在9月12日举行的新闻发布会上证实，涉嫌刺杀斯特普朗的政治盟友查理·柯克，其嫌疑人为22岁的犹他华盛县居民凯泰勒·罗宾逊，目前被关押在犹州监狱等待被起诉。

2. 根据报道，法国总统马克龙表示，在“俄罗斯无人机入侵波兰”后，他决定调动三架“阵风”战斗机与北约共同保护波兰领空及欧洲东部侧翼。

3. 当地时间9月12日，阿尔巴尼亚总统贝加伊正式任命埃迪·拉马为总理。根据贝加伊的任命，拉马主导的届内阁将设立由人工智能系统“Diella”创建和管理的国务部，由人工智能担任部长。

4. 多家媒体12日报道，刚果(金)西北部11日晚发生严重船难，一艘载有近500名乘客的船只在刚果上起火倾覆，已造成107人死亡、146失踪。

5. 9月12日，巴基斯坦首都伊斯兰堡与伊朗首都德黑兰之间停飞了60年的航班重新恢复，伊朗航空公司将于每周二执飞一班航班。

6. 据缅甸广播电视台12日晚报道，缅甸警方近日在仰光省获4.44吨冰毒、1.1吨氯己酮酮、400万片兴奋剂和14公斤海洛因。

国内：

7. 财政部消息，今年，国家财政安排1000亿元发放育儿补贴、200亿元逐步推行免费学前教育。

8. 9月12日，国产电器巨头追觅科技宣布进入新能源汽车行业。将在德国建厂，并将于2027年推出首款对标布布加迪威龙的超豪华纯电车型。
