


# Tiktok 的“两套说辞”

发布时间：2025年9月24日

列强之间的停战谈判，分歧点不是利益，而是面子，因为列强的利益分配完全基于实力地位出发，非列强的棋子也许能利用列强的矛盾争取利益，列强在战场上拿不到的，谈判桌上也不可能拿不到。

![](img/2153f645d56eabbc94fefcc81a544066_0_0.png)

列强的对手只有列强，此无论是实战，还是金融战、科技战，只要开战就必须全力以赴，调度国内外的资源，并建立一套针对战争正义的叙事逻辑。这使得列强停战的难点，在双方如何拆除为为了战争建立的叙事逻辑，找到信徒们一个合理的解释。这使得双方谈判团队就像一个稽智匠，琢磨的都是如何实现实在面子上的双赢。

特朗普要停止拜登时代俄罗斯与中国的两场战争，关键的难点从来不是如何分配利益，因为美国基于实力地位出发，就没实力使得特朗普在很多人眼里看起来非常软弱。
