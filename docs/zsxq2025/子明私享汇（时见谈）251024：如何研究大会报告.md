


# 如何研究大会报告

发布时间：2025年10月24日

10月上海线下读者活动系列（八）

四中的本质是对利益的再分配，所以四中通告的文字版就需要字斟句酌，对于任何一件事情的表述变化，都意味着在这个领域的利益再分配。

绝大部分情况下，利益的分配不是非此即彼，而是平衡点的左右摇锯，博弈胜利的一方会将平衡向外扩展，表现为或是调整副词的力度，或是调整先后顺序。

譬如同一类的两件事情顺序倾倒，就意味着两个集团背后的努力此消彼彼长；譬如某某个事情上“更进”等词汇，就意味着推进这项事项的政治集团占据上风。对于金融贸易党来说，低端劳动力（移民）标杆是奉节与储备，归根结底，词汇的变化，是在告诉我们政治地位的变化。

因此，研究四中的报告，不是看了什么，而是要看相较于五前的五中变了什么，是要通过词汇的变化，发现这些政治集团的变化，我们要追溯的是政治集团，而不是政策本身。
