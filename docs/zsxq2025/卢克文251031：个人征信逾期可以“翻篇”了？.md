


# 卢克 25-10-31：个人征信逾期可以“翻篇”了？

央行传来好消息，特定逾期可以申请“信用修复”了！

这不是空穴来风。10月27日，金融街论坛年会上，央行行长潘功胜透露了一项正在研究中的一次性信用救治政策，引发广泛关注。

到底什么样的逾期可以“翻篇”？谁又能真正按下“信用修复”的快捷键？

## 01

首先要说明，不是所有人都在疫情期间逾期的人都能得到这次征信修复的机会。

央行行长潘功胜指出，政策主要是帮助那些受灾情景影响发生逾期、但后来还清欠款的人。

具体来说，必须同时满足三个条件才有修复资格：

- 逾期发生在新冠疫情期间
- 违约金额在规定标准以下（具体标准待公布）；
- 欠款已全部还清。

同时要强调，信用修复≠违约记录“一笔勾销”，而是将符合条件的记录在征信报告中隐藏起来。

这项政策预计年初开始实施，很多曾经受不可抗力“暂时失效信用防线”的朋友，有望“上岸”。

政策初衷是好的，可为什么很多人不买账?

仔细细想，有几个现实问题:

首先，它帮的是“已经上岸的人”：按照现行规定，逾期记录在还清后5年就会自动删除。

疫情封控从2020年开始，不少还清款的人，逾期记录的已经五年，短的也有两三年，这个政策并非让“污点”提前几年消失而已。

而这个政策救不了那些“还在溺水的人”。对于至今仍无力偿还债务的群体，这个政策起不起任何作用。

> 目前全国约有7亿有信贷记录，其中接近3亿存在不良征信，占比高达42.8。（数据来源于2025年《中国居民负债情况调查报告》）

这个占比还是很吓人的，差不多每两个借钱的人里，就有一个信用有问题。

这也解释了为什么现在各种刺激消费的政策效果都不太明显。这么逾期，说明生产生活不能保障，还怎么消费？

所以，出现了一种尖锐的批评：这个政策没帮大家解决困难，它只是想让更多恢复“贷款资金”，好让银行有更多业务可做。

很多人提到征信报告一肚子火，觉得这就是银行用来拿捏人的工具。

想贷款先查征信。银行打开报告一看，一句“不合格”就能把你拒之门外。

就算努力强化了，如果征信有瑕疵，利率立马就得浮10%到30%。算下来，房贷三十年还下来，多出去好几万，一辆车就这么白白没了。

原来，银行就是把你的征信翻来去地挑毛病，好理直气壮地利息、“加价”。

但真相正好相反：这套征信系统，其实就是在看着银行“区别对待”，防止它乱放贷。

大众印象里，银行是靠低息吸、高息放贷，吃息差钱的。但银行玩的是现金游戏，如果你办一笔30年的房贷，难道银行要慢慢悠悠30年才把钱赚到吗？

当然不会。

假如，你从银行贷款那300万，它会马上把你的贷款合同作价250万，连同其他人的“欠条”一起打包成一个理财产品，转手卖给其他金融机构。

这就是大名鼎鼎的ABS制度。通过它，你这边月供还了还没到期，银行早已通过打包转卖，把本金和利润收回囊中，根本不用等你30年，继续投入下一轮“金融流水席”了。

这套玩法看似花哨，但实际还在监管范围内。其实是征信系统管住了银行的手脚，让银行不至于肆无忌惮地放贷。

回想网贷最狂热的那几年，恰恰是征信约束对放贷机构严重缺位的时期。

当时，不少消费金融公司用低成本资金（比如4%的同业借款，不正规的小贷非法吸储），转头就以24%甚至更高的利息往外放，有的玩“砍头息”。

很多公司放贷豪掷巨大，你还没来得及后悔，钱就到账了。对于那些没有还款的人。

## 02 为什么它们敢肆无忌惮？不怕别人还钱吗？

记得前面提到的ABS制度吗？小额贷款同样会把你的债务合同层层卖，区别是银行有监管监管。

对于最终接手的公司来说，只要成功还款，它们就稳赚。

所以，即使你不还钱，这种模式也让无数借款人拖入了“以贷养贷-无限还收”的恶性循环，最终成了社会悲剧。

所以，征信报告不止只是借款人头上的剑，更是逼着银行一套统一的标准，为了利润。

回头看，消费疯狂的那几年，正是天灾威胁到很多人的生命，却威胁到了他们的生计。

不少人由于临时困境而走了。那时候逾期的，多数是小店主、打工族——他们的困难，更多是“诚实不幸”，而不是赖账。

征信系统本来是为了建立一套统一的“语言”，让金融机构理性评估风险，但在特殊时期，它却成了锁住很多人的镣铐。

银行贷款，主要看两点：

- 一是还款能力（够不够）
- 二是还款意愿（有没有）

就算你现在收入不错，但只要征信上有逾期记录（连续三个月，或者两年内累计六次），你就入了黑名单。

你只能找到地方银行。风险高，价格就得高。所以，你只能接受更贵的钱，国家给各种优惠都享受不到。

正是因为这个，现在推行“征信修复”机制显得特别意义。它不是从容失信，而是给那些诚实者一个宝贵的“重启键”。通过必要的程序和审查，帮助他们修复信用重回经济正轨，疏通那些被困难堵住血管。

## 03

征信修复为“已经上岸”的人清除了历史障碍。但那些还在债务深水里挣扎、爬不上岸的人怎么办？

正是这个悬而未决的问题，将公众的期待引导了深度的解决方案——个人破产。它和征信修复是一套组合拳：帮“好起来的人”修复过去，帮“病态的人”终结。

很多人觉得国外个人破产特好，法院一张欠债一笔勾销，其实有一个普遍的误会。

就美国吧，个人破产根不是“免单”，更像强制还款计划：它虽然能最终让你减免部分债务，但前提是你必须拿出诚意，在未来五年里，用稳定收入尽力偿还。

法院只保留你的基本生活保障（如自住房、汽车），大额消费全部受限。

而且申请门槛低。你得拿出切实行的行的款方案，还得让债权点头同意，不是你单方面说破产就能破的。

就算申请成功了，代价也不小。破产记录会跟着你七年，期间贷款买房车基本没戏。连信用卡都可能被换成“担保卡”——得先里面存钱才能用。想想看，在人均存款3000美元的美国，这样的利子多得可怕。

所以你看，这根本不是免费的午餐，而是一套严格的债务重组机制。这套思路在我们的司法实践中也有体现，只是咱们国家的《破产法》一直被称为“半部法”——2007年起，企业破产适用，可普通人的债务纠纷，还得走民事法官，靠法院强制执行。

虽然法院处理这类案件的逻辑也是债务重组，但因为缺乏全国统一的《个人破产法》，各地都是“一个案子一个办法”。深圳、浙江等地仍在试点“个人债务清理”，但整体还是摸着石头过河。

为什么推行一个个人破产法这么难？

第一，技术上确实有困难。我们现在很难一个人的家庭彻底查清楚。他到底有多少张银行卡，外面有没有投资、亲名下有没有代持的资产……这些信息散落在不同部门，没完全打通。

这就导致一个核心问题：怎么区分是“真还不起”的老实人，谁是“装可怜”的老赖？

深圳试点就遇到了这种情况。从2021年现在，法院收到一千多起申请，最后真正免债债务的寥寥。
