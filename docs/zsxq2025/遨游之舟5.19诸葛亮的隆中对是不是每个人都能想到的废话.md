


# 五章

李云华（笑着），你最害怕的电影是什么？

李云华对电影并不害怕，他小时候看过很多恐怖片。但他最害怕的是那片荒野，那种未知的、死寂的荒野。他害怕，那种深入骨髓的孤独感。

李云华坐了很久，看着窗外的夜色。在那一刻，他突然觉得自己自己就像电影里的那个人，在无尽的荒野中无目的地地行走。

李云华笑了笑：“我最害怕的电影是那种没有刺激的冒险片。因为没有血腥，没有反转，只有未知的结局。”

李云华站起身，走到窗边。窗外的城市灯火通明，繁华，却让他感到一丝凄冷。

我最害怕的电影，是那个没有结局的电影。

他闭上眼睛，仿佛自己正走在那片荒野中，无尽的孤独感在风中徘徊。

因为没有结局，所以没有希望，没有解脱，只有那种深入骨髓的孤独感。

我最害怕的电影，是那个没有结局的电影。

李云华叹了口气，转过身，看着面前的女孩。女孩的眼神很空邃。

我最害怕的电影，是那个没有结局的电影。

女孩笑了笑：“其实，我最害怕的电影是那个没有结局的。”

我最害怕的电影，是那个没有结局的电影。

李云华走过去，坐在女孩身边。女孩的手很凉。

我最害怕的电影，是那个没有结局的电影。

女孩转头看着李云华：“你真的害怕吗？”

我最害怕的电影，是那个没有结局的电影。

李云华点了点头：“是的，那种感觉意味着一切努力都没有意义。”

女孩沉默了片刻，似乎在想些什么。

我最害怕的电影，是那个没有结局的电影。

女孩点了点头：“我最害怕的电影，是那个没有结局的电影。”

李云华看着女孩，突然觉得她也是那样的孤独。

我最害怕的电影，是那个没有结局的电影。

女孩靠在李云华肩上，闭了眼睛。

我最害怕的电影，是那个没有结局的电影。

李云华轻轻抱住女孩，感觉到她的身体很冰凉。

我最害怕的电影，是那个没有结局的电影。

这一夜，他们就这样坐了很久。

李云华发现，女孩似乎已经睡着了。

我最害怕的电影，是那个没有结局的电影。

第二天早晨，李云华醒来发现女孩不见了。

桌上留下了一张纸，上面字迹模糊。

“李云华，谢谢你。我得走了。”

李云华开始寻找女孩，但他发现找不到她。

他意识到，女孩或许就是那个没有结局的电影。

李云华再次坐在窗边，看着窗外的城市。

他发现，生活似乎还在继续着。

李云华笑了笑，他不再害怕那种孤独。

李云华明白，每个人都有属于自己的结局。
