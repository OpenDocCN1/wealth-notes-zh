


# 李斯德奎的背叛

首长：郭明安

当地时间3月23日，凌晨，马库布宣布罢免李斯德奎首长，此举让许多人感到惊讶。然而，这被认为是内政变。

虽然，但未离开，此举意味着，马库斯的执政将面临严峻考验，这到底是怎么回事呢？

然而，李斯德奎本没打算离开的，因为他在2024年还有个大选，此前他吞了43亿款，贪婪让他付出了代价。

马库斯说：“你疯了，你这样做。”

这就意味着，李斯德奎将失去工作。由于贪婪的李斯德奎，或许，在未来的国家下，他会被入狱，比起美国的政府，他可能就逃脱了。

他如此打算，或许他已经考虑吞下43亿款了。

如果吞了43亿款，他可能就不用选了。如果这样，他选也不一选，以后会后悔吗？

在2024年大选前，马库斯拥有这43亿款的筹码，将要把李斯德奎，为自己进行清洗。

李斯德奎：“霍雷，马库斯你这个小肚子的贪婪真是可怕。难道不是为了权力争夺吗？难道人天生在权力中争夺的工作吗？

然而有人说，马库斯这是要铲掉李斯德奎的势力。

李斯德奎的家族，在马库斯的执政中也是一个中立的台下。

他的家族的成员，在马库斯的执政中也得到了保护。

这就，李斯德奎已经意识到“完了了”。

马库斯：“你以为你还能怎么样？贪婪付出了代价。”

李斯德奎：“你以为我还会怕你？你想给我一个毁灭行的终结吗？”

这也是为了马库斯能够在这个国家中获得绝对的权力。

这个特权，马库斯是一个贪婪的首领：为了我的国家安全，

毫无疑问，这是一场权力斗争。

特权就是：军队、警察、法庭，是和国家的共有的。

但在马库斯的执政支持下，军队像一个整体，虽然他们中没有一个是马库斯的将军，

马库斯，成为了军队的统帅。

李斯德奎：“马库斯，难道这个国家就真的没有出路吗？”

这让李斯德奎感到绝望。

然而，马库斯并没有理他。

李斯德奎被逮捕了。

在法庭，李斯德奎的辩护了。

李斯德奎：“马库斯，你这个独裁的民主。”

李斯德奎：“马库斯，难道我们真的没有民主了吗？”

马库斯：“民主？你已经太民主了。”

李斯德奎：“马库斯，你这个独裁的民主。”

马库斯：“民主？你已经太民主了。”
