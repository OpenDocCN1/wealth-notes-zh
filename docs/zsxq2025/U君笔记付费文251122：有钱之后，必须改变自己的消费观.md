


# 有钱之后，必须改变自己的消费观

原创：U 君 公众号：U君笔记 25年11月22日

当你还很年轻的时候，拥有大量的时间，但是手里却没有多少钱。

但是当你的的人生过了某个转折点之后，你拥有的金钱超过你拥有的时间。

这时，你的时间比金钱更昂贵，所以你必须要做两件事：

- ① 严格筛选所有试图进入自己生活、试图占用自己时间的人/事/物。
- ② 在花每一分钱都要考虑，这次消费会不会浪费自己的更多时间。

今天我就跟大家分享5条“有钱之后必须改变的消费观”，包括消费时间和消费金钱。

## 1. 金钱是权力/能量，物品是风险/债务。

如果你在闲鱼上卖二手物品，你就会发现一个非常痛心的事实：你直视珍贵的物品，在交易市场上根本值不了多少钱。

花1万元购买的包包，使用不到三个月，如果想出手的话，只能卖到5千元，而且买还会挑三四，跟你反复拉扯。

汽车、房子这种大件也是如此，今天买到手里，明天想要买的话可能就要打个7折（尤其是新能源车，以及大城市的房子）。

但是，如果你手里握着金钱，你是买方，那么所有的主动权都在你手里，你想要买什么就买什么，那种自由的感觉非常爽。

同时你要清醒地意识到：你一把钱花出去，那么你的主动权就消失了，你的那种爽感就会变一分。

我不是鼓励大家都变成守财、一分钱舍不得、过着清贫的生活，而是，不要轻易把手里的钱换成物品，不要轻易交易主动权。

我曾经经历过一个胆大的观点：当你手里握着金钱（而不是物品），你会发现大部分服务都非常便宜，跟免费的差不多。

点一份外卖，只需要几元的配送费；叫个网车，只需要几十元的打车费；去一次大保检，只需要百元的服务费……

只要你在花钱购买服务，你就会感觉生活非常爽，非常美妙，想抑郁都困难，因为你在花钱购买别人的时间。

而时间=生命，本质上你就是在花钱为自己续命。

但是，如果你把金钱换成了物品（比如贷款买车、买房），那么接下来的就轮到为你别人服务、为别人续命了。

这是一个简单的逻辑，但是很多人的脑子一辈子都转不过这个弯。

## 2. 避免购买那些“二次消费”的商品。

很多商品并不是花钱买，永久享用那么简单，你需要二次、三次甚至至多次消费，反复投入金钱和时间，才能持续拥有它。

举例子，如果你买了一辆汽车，你以为汽车就属于你了？大错特错。

你持有这辆汽车，需要持续投入时间和金钱，比如每年交保险费、油钱、停车费、洗车费、车位费。

不仅如此，每次洗车、每次停停车位、每次加油站都需要时间，每年还会会有各种各样的保险公司打电话抗你占用你的时间……

毫不夸张地来说，你买一辆价值20万元的汽车，每年在金钱上的损失就要5万元（包含折旧费），每年在时间上的损失至少是100个小时。

上次有个小小伙伴在知识星球里跟我咨询“购买智能手表”的问题，我的建议是：不要买。

一方面是因为，80%的人在佩戴一个月月的智能手表之后，就会失去兴趣，然后放在角落里吃灰了（我自己买过两块苹果手表、一块三星手表）。

另一方面是因为，如果你经常佩戴，那么需要每天想着给它充电（占用自己的注意力）。

经常出差的人更不推荐购买了，因为每次出门前都要额外携带充电线、充电器。

部分机场在安检的时候还要摘掉手表，放到安检箱中，增加遗失的风险。

机械手表我不推荐，一方面是比较重，生怕磕了，摘下来还会担心遗失。

另一方面是，隔几年就要去保养一次，比较麻烦。

当然，以上我是从节约时间、节约心力的角度进行分析的，如果你每天都要坐地铁/公交，而且每天都要去便利店买东西，那么智能手表还是很方便的。

就拿我来说，我平时都是把手机放在背包里，头上戴着耳机，坐地铁直接刷手表，去便利店买东西。

换句话，我用手表取代了手机、交通卡、很多功能。这时即使每天给它充电，也不觉得烦恼。

当然，我也非常看重售价，比如600元的星手表。

顺便说一下，在闲鱼上购买商品的三个操作要领：
- 筛选“个人闲置”
- 筛选“信用好”
- 第三个步，看卖家记录

如果你连这些都找不到，那你的智商太低了

## 3. 永远不要落入商家套。

总之，非常杂，他肯定不是为了你。唯一的波动是双十一期间，很多商品发现价格根本没有波动。我想表达的观点是：永远不要担心“我以后买不到便宜商品”。

现实情况是：好的东西概率不会绝版。科技只会进步，商品的性能只会越来越好、越来越人性化。

所以，延迟消费永远都是赢家。再说了，很多需求其实都是伪需求。

### 如何判断自己的需求是真需求还是伪需求？

我自己有一个小诀：如果我特别想买某商品，我会把它放到购物车，过一个月（或者三个月）再看到那件商品时，我很可能已经不要了。总之，手里的钱越多，越不会冲动消费，反而能享受延迟消费的美妙感。

## 4. “等等族”可能是最大的赢家。

对于手机、游戏机、自行车等科技相关的产品，消费者分为两大派系：手慢和等等。

- 前者总是担心：现在买以后就买不到，甚至成为（比如某款墨屏电子书、某款碳纤维自行车）。
- 后者总想：iPhone 的标准版一直不买，等到它高刷了才会考虑购买。

## 5. 不要把宝贵的时间给免费的人。

如果你已经到了“时间比金钱还宝贵”的人生阶段，就不要把自己的时间花在那些不值的阿猫身上。我自己在26左右的时候，就已经清晰地意识到了这一点了（当时我已经体验过“日入过万”的感觉了）。

我把所有的免费微信群都退了，包括同学群、亲戚群、家族群。我非常清楚，他们只会浪费我的时间，不会给我提供任何价值（负面价值>正面价值）。

如果你相信自己能赚大钱，那你大学毕业十年、35岁的时候，跟以前的同学绝对会有什么共同话题，再多的交流都是浪费时间。

至于家里的亲戚、长辈，更是没有沟通的必要，等你35岁的时候，那些老人已经糊涂了，有的已经去世好几年了。

至于同事的婚丧嫁娶，以及公司的聚餐、团聚、唱歌，更是浪费时间、浪费钱。

如果你决定成为钱人并且坚持自己以后会有钱，那么你跟他们肯定不会长久相处，顶多会有两年的交集。

所以，千万不要在这两年里把自己的时间和金钱浪费在他们身上。

我知道这样说有点狂妄自大，但是自我就是这样走过来的。我刚大学毕业就进了一国企，我每天都在跟自己说：比你们志向远大，比你们更有野心，将来也会比你们更富有，所以我不会在你们身上浪费时间。

事实也是这样发展的，以后我每进一家新公司都是这样对待那些同事的，直到我彻底不打工，成立了自己的公司。

如果你没有这样的志气和野心，那你就是一个庸俗人。其实抠门是表象，本质是思想独立，不再被资本主义牵着鼻子走。这些都是我有钱之后才产生的，越有钱越抠门这个道理。
