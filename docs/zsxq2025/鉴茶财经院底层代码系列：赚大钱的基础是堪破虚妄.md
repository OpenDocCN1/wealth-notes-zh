


# 鉴查财经院底层代码系列：挣钱的基础是填坑破妄

最早见到红星美凯龙的老板新建，是很很多年前了，那时候他还在开着红星家具厂，已经在常州开了一个家居卖场了，正准备搞大。

那时候大王勉强算青年才俊，而老车是个农民企业家，于是交流的比较水平等，大王就把当时不成熟的底层规则学学跟他他一通分析，他既然要开店，又连链，大王告诉他全世界开店成功的是麦当劳。

麦当劳是卖汉堡的吗？不其实是房地产和金融商。麦当劳在街道和街角处买下一一套房子，或者租一片自己根本没用的物业，然后再开餐厅，生意一火爆，当然附近房价和租金飞涨，它就是这么赚钱的。

麦当劳挣钱跟汉堡有关吗？看似，实际没有，深刻深刻。

在走时候，整个团队都意洋洋的告诉老车，嗯，啊，你要搞定这个家具卖场，等琢磨出家具没关系了，你就成功了。

没想到老车果然非常凡人，过了日子后，他说明明白了，家具卖场的核心不是家居，而是卖场，他干的是房地产生意，它特么跟家具毛钱没关系。

商业模式，跟麦当劳很像，很像。

老车从此推崇麦当劳，他要求自己的 LOGO，前面必须带一个金黄色的 M，大王明白，这是抄袭，哦哦，致敬麦当劳的 m型拱门。

中国家居卖场起的年代，大家还都以为自己卖家具的，要给家具厂商良好的环境，招商很委屈求全，只有老车知道核心不是招商家居品牌，他根本不管这事。

既然是商业地产，那么立足的本质，之一是段，二就是客户体验。

段上，老车后来去上海开了真北商场，然后又奔波去北京等大城市圈地，算是占到了先机。

客户体验上，买家具是为了满足对家的想象，必须高端。老车请了日本的设计师，设计了外立面和形象，一下就把星球家居之类的推出去很远，人们逛商场，扶梯都是错的，扶梯楼很费劲，叫你转来转去，增加你留逛的时间和动线，但老车认为，客户体验至上，他要求的扶梯必须下口都在一起，上看，立刻就能下楼走人。

红星美凯龙不收扣点和管理费，但是决要求统一收银，当时除了没人这么干，不得不说，他们掌握了家具卖场的行业本质。

他的行业本质是地产，核心资源是政府和消费者，真的跟家具一毛钱关系都没有。

后来，赖郡平到大陆忽悠，听说过后四处提两句话：

发现事物的本质，危机中寻找转机。

老邱忽悠和提炼能力都很强，确实也不是一般人，但有两个大毛病，一个是不具操作经验，一个是太好色又没品。但是后话。

老邱在这个基础上，破解了苏宁和美国帝国，都是弟弟干家电卖场，哥哥干房地产，弟弟压供应商供应商货提供提供现金流，哥哥搞房地产提供收益率。完美。

后来，我们扒透了小家电行业，他的核心本质叫做品牌堡轮。

小家电电商必须搞一个很厉害的单一，比如，格力造空调厉害，美帝造电饭锅厉害，海尔造冰箱厉害，形成客户感知：哦，这个品牌造家电器厉害。

然后，他们再扩充生产线，造电饭锅，洗衣机等系列产品，客户把你优势产品上的认知，转移到你其他的产品上。

说的通俗点，爱栗及鸟。反正其他的产品都是代工的，利润高到离谱。

再后来，就是房地产，房产看着是盖房子，但本质是融资能力。融100亿，利率便宜1.5%就是1.5亿净利润，干死也挣不了那么多。所以只做好产品，融资不行的绿城卫平、黄文仔的星河湾都退出市场了。

要破解一个行业的本质，就需要了解那个行业最关键的要素。

## 如此大王一再提出，赚钱，就是加工和出售廉价资源的过程。

而你能或许持有的这个廉价资源，如果正好是那个关键要素，那就是风口上的猪了，黄军也很贼，不把话说透，从敏族那边坑埋了一堆廉价要素。

大部分赚钱的事业，核心资源都是沉在水下的，其实没法量化，技术分析只能分析表层的东西，那个根本不是核心要素。

因此我们在内部开会时，会经常很深刻的问一句话：这家公司在卖什么？如果说出来的是商品层面的东西，那肯定不合格。

我们也可以自己问问，我们公司，到底在卖什么？我们这个行业，他的本质是什么？我们抓住本质了吗？

当然隔行如山，大王堤不透的行业多了，比如省城转到地市，地市转到小城的转运和服务支线物流，基本是黑白两道的天下。

而推到股市，技术分析能看什么呢？过往成交记录，箱震荡周期，平时有作用是在稳定与周期间，遇大震荡，模型立刻失效。最近涨疯了的光大证券，拿 MACD 金叉怎么看？高速华测速里，低空飞飞机，你忍测？上市公司、K 线结构，跟上涨有关系吗？可以说毛钱关系没有？股市上涨，就是因为总量资金进入，得分析资金来源和投资喜好，大佬账上有多少钱，你能分析吗？而且股市最重要的要素是人心，这是经济学和统计学界都没法量化的东西，那么怎么判断？干脆假设，西方经济学始终是一门脑科学，马克思倒是经济学引入了人的变成了思想家。资本市场第一个虚妄。

大部分我们认为的理决定性要素，其实并不是那样的。之前说过，投资界大佬都读过的《金刚经》，无我相。眼见为实，才是认识底层规则和赚钱的第一步。所以马云之前，天天叨叨，就是要普及的力量。
