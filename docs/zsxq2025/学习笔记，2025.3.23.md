# 学习笔记，2025.3.23

- 1. 我记得小时候学的是“穷则独善其身，达则兼济天下”。
后来看到又有人正版是“穷则独善其身，达则善天下。”
这话是孟子说的，现在书上是善天下。

兼济天下，有一种你到你那个位置就必须主动帮助别人的感觉，可能要强行改变他人的命运。

善天下，更是希望你发挥能，用对待自己的方式对待世界，你面对世界依旧做好自己就行。

不用去充当救世主，做好自己，有能力再去引导做好自己，也是在一定程度上改变这个世界。

每个人都有自己的命运，强行干预，会把别人的命运也牵拉出去。

- 2. 在网上赚收入的人很多人，一些人看到后有一种快钱很好，自己也要赚快钱的办法。

快钱没有问题，但是你去看那些能赚快钱，基本都是有了多年赚钱经验，看到机会来的时候，他才能跑速进去赚到钱。

一个什么基础都没有的人，没有人是独自面对市场的，想赚快钱，和希望买彩票中大奖是一样的，都是妄想。

快钱之前，首要积累赚钱经验，培养行动力和对市场的敏锐度，这样机会的时候，才能抓住。

而不是反过来，每天就盯着别人赚到了哪些钱，这样就能学个表象，最后赚不到，还要投入不少时间和金钱。

- 3. 如果你觉得一个人的认识和你相差差不多，不要想着说服他，而是应该远离。

在讨论微积分的时候，不可能从1+1 开始对对方不起。

大多数争吵就是这么来的，你无限切分，他说一堆土和一堆土放在一起就是堆土。

要尊重自己的时间和精力，用在值得的人和事上。

- 4. 每天对别人的的人生指手画脚，只能说明一点，他们自己的的人生也是一场糟透，他们在试图用这种方式来证明，别人的的人生也过得还差远了，用来找一点安慰。

就像，有人说自己过得难，就有人让他去医院看看别人比他更难，让他在更难的人身上找回点自信。

不要成为这种人。

- 5. 不要奢望别人来理解你，每个人都有自己的独特经历，很难做到完全身身受。

或者说，如果所有人都理解你，随便谁都能理解你，大概率你过的生活和他们一样平庸，没什么特殊的经历和能力。

- 6. 一个人，如果发现自己的人生长期在走下路，或者被同样出身的朋友越落越远，只能说明一点，自己过去多年的认知存在很大的错误。

想要逆袭，想要追上朋友的发展，首先要做的，是承认自己的错误，学习并创造新的认知系统，只有这样，才有可能新的的人生。
