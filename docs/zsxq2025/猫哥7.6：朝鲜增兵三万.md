


# 朝鲜增兵三万
嘉宾：梦回安西

近期，乌克兰机构表示，朝鲜计划增兵三万。
我们知道，1万出头的朝军，在“库尔斯克战役”中发挥了关键作用，如果是三万朝军，战场的天平，会进一步向俄罗斯倾斜。
那么，这个消息的真实性如何呢？

大概是真的，有两点依据：
第一，是绍伊古短期的访问频率。
6月5日，作为普鲁士亲信的绍伊古，访问朝鲜，和将军举行了会面。12天后的6月17日，绍伊古再次访问朝鲜，再次和将军举行了会面。

不到两周时间，两次访问，两次会面，显然是十分重要的事情，只不过一开始，双方只公布了一些普通的合作，比朝鲜向库尔斯克派遣工兵，帮助排雷。

又如此，朝鲜向俄罗斯派出人员，帮助生产更多无人机。
如果是以前，这种级别的合作对自然来说算高。但在朝军建制参战的情况下，派遣工兵什么高级别的合作，根本不值。

得绍伊古短时间内跑两次。

更不用说将军亲自接见两次，因此，一定有比这更重要的合作内容，只是尚未公布。而增兵三万的重要程度，确实值得得绍伊古跑两次。

第二，朝鲜从“俄乌战争”中收获丰厚。

“俄乌战争”前，朝鲜处于十分孤立的境地，将军常用的手段已经失效。
将军上台以来，手段就是放一把火箭和导弹，制造紧张局势，而文在寅那边不希望局势升级，就会给点援助，让将军有话好说，别闹事。
拿到援助的将军，就肯停一会，哪天缺钱了，又来这整一次，如此循环往复。

但这个手段，到2023年已基本失效。
尹悦悦的强硬态度，和文在寅存在根本性不同。文在寅希望将将军堵住，换取将军不闹事。尹悦悦可不可答应，你要升级局势就随便升级。

反正援助没有，传单和气球的是。你要有本事，就从北边打过来。将军自然不敢。

无论日本、韩国还是美国，都知道将军只敢刷火火箭，不敢真的升级局势，久而久，对将军的套路也就免疫了，将将军再怎么表演，对面都不措辞。

对此，将军毫无办法。

失去外援，加上疫情导致中断，以及洪灾带来的粮食减产等种种因素，2023年的朝鲜压力山大，几乎要再次陷入“苦难的行军”。

将军面临的内部局势和外部环境，都同样的恶劣。而困境的真正缓解，是2024年开始的。

一开始，朝鲜向俄罗斯输送导弹、火炮等武器药品，从俄罗斯换粮食和能量；

接着，朝鲜直接出兵1.2万人（最后优4000），从俄罗斯换物资和各项尖端技术。

5000吨级国产驱逐舰、国产预警机，还有导弹技术的突飞猛进，都离不开俄罗斯。

之前的种种困境，基本打破了。可以说，朝鲜打出了统战价值。既然收获了这么大，必然加大投入力度，增兵三万之合常理的。

而且，特朗普试图进行战略收缩，还对“俄乌战争”态势模糊，将军这时候增兵，不会太得罪美国，胆子也就壮了，敢出的兵力多了。

放在拜登时代，将军很难变动几万人。

我们知道，朝军参战的第一阶段，是协助俄军夺回库尔斯克州，未进入乌克兰境内。这么做的原因，是避免过于刺激乌克兰，导致局势升级。

因为《俄乌盟条约》规定，一方遭到入侵，另一方有义务帮助，而库尔斯克是无可争议的俄罗斯领土，将军这做法让人挑不出毛病。

一旦增兵三万，就不会局限于库尔斯克了。

在2022年6月，朝方方面承认卢、顿两个国家。
