# 猫哥原创

平时我们遇到较大社会问题总是下意识的把根源归结到制度上，哈毛病都往这个大比筐里放。但是制度有没有问题其实是很难界定的——包括究竟是制度有问题还是执行有问题就可以争论不休。

实际上我们要判断一个制度是否有问题是需要时间来沉淀的，需要不断的试错，所谓读史如观镜就是让我们在较长时间尺度中做出真正准确的判断。

举一个明清的案例。

明末清初这段历史最让人难平的就是满清军队对明军的碾压。

在明末清初几十年历史中，满清军队（前期叫后金）对上明军只要双方军队稍微上一个规模（比如5000人以上），满清都能做到100%全胜。

不仅全胜且交换比极为夸张，过去我一直不理解的就是，明朝拥有2亿人口，而金乃至之后的满清其核心基本盘满洲成年男丁在入关从来没有超过10万人，加上其他男女老少，清朝入关前期人口也就是几十万人这个水平。

2亿vs几十万人，就算清军每次战争都能全胜，就算每次战胜能打出1:10以上的交换比，几十年战争下来，满人人口基数又少，早就应该拖垮了。

事实上不是如此，清朝就靠着这几十万人口居然与明朝拉锯战了几十年，可是万人以上的会战就高达数十次，但是满清并没有拖垮，反而有点越打越强的趋势。

为什么会出现这样的现象？

原因很简单，清军每次与明军会战，不但能全胜，而且交换比极为夸张。

我们以萨尔战役为例，本次战役，明军10万大军全覆没，而金军获得了这样的胜利付出的代价是多少呢？

按照旧档案记载，“折损200余人”。一开始读到这段史料完全不信，后来看到清军与明军拉锯作战几十年，几十万丁口居然没有什么变化，慢慢才相信了这个记录。

明军损失10万，后金军损失200！交换比居然高达1:500。在双方武器装备没有的情况下，这样的交换比简直让人难以思议。

那么问题来了，明军为什么如此拉持久呢？

读史料，几乎所有的史学家一致认为这是明朝军事制度出现重大问题。

明朝军事制度是太祖所创造，为什么节约常备军事预算，明太祖创造了一个户户制度，根据这一制度的要求，一旦有家庭为了军户，即必须要世代表参军而不得从事其他职业，同时朝廷给军户分配土地，让他们战时作战，休时耕地，同时允许他们用兵役来抵消赋税劳役。

简单的来说就是国家给特定人群分地，获得土地的人群平时不需要上交税也不用服役，但是一旦国家需要征你入伍你自武装武器与粮食去战斗。

这个军户制度说白了就是相当于隋唐时期均田度和府兵制度的结合体，而里面的军户就相当于负着国防和治安等双重义务的自耕农。

随着国家承平日久，军户制的极端也逐渐暴露出来，比如由于士兵们常年耕种，缺少训练，一旦遇到一些突发的战事，作战能力极其低下。比如如军户的土地被上级官员侵占，军户缺少粮食如咬了子的苦不堪言。

所以这样的户军组成的军队与后金军队作战自然触即溃，战力低下。

写到这里，我们是不是就可以得出结论，明军战斗力不行完全是制度上出了问题？

但是硬币的另一面却具有讽刺性。后金军队战力强大是因为他们建立了更为先进的军事制度吗？

答案是否定的。

努尔哈赤文盲一个，怎么可能有能力设计高明的军事制度，后金以及后来的满清基本的军事制度完全就是抄袭明朝。

清朝的基础就是八旗制度，八旗制度虽然名称不一样但是内核就是一样复制明朝的户军制度。

满人同样也会被分配土地，但是因为后金前期没有其他的赋税来源，所以满人分配的土地比明朝的军户制度还不错——这些分配的土地需要承担高达三十几种赋税，所以八旗制度下的满人正常情况下负担远比明朝的军户更为沉重。

但是八旗制度下的满人与明朝军户唯一的区别就是，后金会不停对外挑起战争，战争的劫掠能够极大改善满人的生活。
