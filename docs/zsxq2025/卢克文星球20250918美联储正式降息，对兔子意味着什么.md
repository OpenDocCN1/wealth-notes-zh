


# 美联储正式降息，对兔子意味着什么？

文/卢克文工作室嘉宾 星海舰长

9月17日，全球翘首以盼的美联储降息，终于来了。

经过美联储联邦公开市场委员会(FOMC)的投票，最终以11:1的结果，宣布降息25个基点，将联储基金利率目标区间下调至4.00%—4.25%。

那么，美联储为啥降息?这次降息对我们又有什么影响呢？

## 1

在一个多月前，不降息，还是美联储的主流意见。

在7月30日的投票中，美联储还以9:2的投票结果宣布不降息。这才过了一个多月，怎么齐刷刷就同意降息了?意不意外？

不仅如此，上次投票之后，鲍威尔反复强调，“尚未就9月利率做出任何决定”，然后市场应声而动，9月降息概率从议前的63%飙降至45.7%。

鲍威尔这个鹰派态度，被许多人视为是对特朗普的一次正面回应。

特朗普是房地产商人，对高利率那是一点好感都没有，第一次破产，就是因为他当年建大西洋城的赌场时，借了年息14%的融资贷款还上不上导致的。

当了总统之后，高利率更是压得特朗普不过气来，现在美债已经37万亿了，利息支出都到了财政支出的四分之一，也就是说，美国财政收入100块钱，还完利息就剩75了，这谁受得了。

所以，利率必须降下来。

但问题在于，鲍威尔死活不同意降息。鲍威尔的出发点是技术指标，而不是政治需要。他清楚楚，降息固然可以刺激市场，但同样会让通胀到天上，个人就这么杠上了。今年8月，特朗普直接换掉鲍威尔的威胁都说出来了。

美联储是个标榜独立的机构，降不降息，总说了不算，市场说了才算。（不管真的假的吧，反正他们是这么说的。）

双方杠了几个月，什么狠话基本都说了，这个时候，降不降息已经不仅是经济问题了，而是关乎美联储独立性的政治问题。特朗普特别生气，但也没特别好的办法，只能像祥婶一样天天念叨。

万万没想到，一个多月过去，鲍威尔的态度来了180度大转弯，突然答应降息了。

为何会这样呢？

看看鲍威尔此前泄露的美联储决策机制吧，一般来说是看通胀+看就业。

通胀高了，需要加息抑制通胀。通胀低了甚至通缩了，要降息刺激经济。而而就业呢?就业数据好，表明经济好，无需降息。而就业数据差，则表明经济可能陷入衰退，必须降息救市了。

美国最近的就业情况非常不乐观。今年8月1日，美国劳工部公布了7月非农业部门新增就业人数7.3万，低于市场预期的10.4万人，失业率小幅上升至4.2%。

更关键的在于，美国劳工部大幅修正了5月和6月的新增非农就业人数，5月新增非农就业人数从之前公布的14.4万降至仅1.9万；6月从之前公布的14.7万下调至1.4万。

这简直是往脖子砍了好几年！说直接一点的话，恐怕就要说美国数据造假了！

说实话，特朗普看到这个数据，是非常抓巴的。非农就业数据不好，对自己的降息计划是有帮助的。但数据这么不好，而且都发生在了自己上台之后，这不是啪啪打脸说自己治国无能？

统计学是非常有门道的，有时候稍调整一下算法，就能得到截然不同的结论。换上自己人，就可以提供自己想要的数据了。

果然，9月6日发布的8月非农数据，新增仅2.2万人，虽然比5月和6月高，但低于预期。就这样，把数据往美联储桌上一一搅：你看着办吧。你还别，数据一出，鲍威尔的口风就变了，说就业增长面临下行风险，风险平衡点的变化可能要求调整政策，美联储对降息持“开放态度”云云。

此话一出，市场上9月17日降息的概率提高到了94%。到了9月17投票的日子，果然就降息了。

看起来，这次降息是鲍威尔顺应市场的一次妥协，但事情真的这么简单吗?未免，恐怕还有政治因素在里面。

从眼前的情况来看，特朗普确实搞不定鲍威尔，但这不代表，特朗普确实搞不定其他事。

美联储参与投票的联储公开市场委员会成员一共12个，其中包括7名理事会成员（由总统提名），固定的纽约联邦储备银行行长，还有4个轮流投票的州联邦储备银行行长。

理事会里面，有3个理事事是特朗普任命的，也就是说，特朗普如果能搞定其他人，也可能实现降息目标。

在这轮投票之前，美联储发生了两个人人事变动。

第一个是美联储理事阿德里亚娜·卡格勒于7月底辞职了，理由是要去乔治大学担任教授，她的任期到明年1月，她不想耽误开学就辞职了。虽然这个理由很扯，但的确给特朗普提供了一个机会，于是特朗普赶紧任命斯蒂芬·米兰接替，在这次投票中微弱优势获得参议院通过后，赶在9月16日签署了文件。

第二个是美联储理事莎·帕克特，她是拜登提名的。说实话，这点不算事，但由署长亲自举报那就是大事。

果然，8月25日，特朗普以涉嫌住房押贷款诈骗为由除了库克的职务。虽然库克随后上诉到了法院，而且打赢了官司，但特朗普还没有认可，就是说库克的职位不算数。说实话，这两件事起到敲钟的作用。

还有一个美联储理事，因为学校开学选择辞职？一个高权重的美联储理事，就因为学校开学选择辞职？这些事情实在是让人费解。

美联储的压力来自特朗普，这种压力暗示了美联储并没有独立。特朗普的努力通过努力，是特朗普抓住了两个人的把柄，然后格勒选择了离开。而库克选择硬杠到底，结果遭遇？

再深一点，两人被抓住把柄，其他理事有没有把柄？想想特朗普亲自安排经济委员会主任哈塞特、预算办公室主任沃特、国家委员会主任，这种猜测并非空来来。

毕竟，每月非农数据只是给这些理事们的台阶，真正原因是受到了特朗普胁迫，否则7月底还有人反对呢。而特朗普的那边，也可以说是自己的努力美联储才答应降息了，双赢。

## 2

# 为什么美联储这次降息格外引关注

不是因为单纯降息，要说降息，去年9月美联储也降息了，说明不了问题。更关键的在于，点显示，美联储将内降息次数的预测上调为了三次，除本次降息外，预计年内还有两次。甚至特朗普任命的那个理事斯蒂芬·米兰，还觉得只降25个基点不够，应该降息50个基点！她预测今年将降息到2.75%~3%。考虑到鲍威尔明年任期结束后，特朗普为了在中期选举之前制造一个欣向荣的经济局面，肯定会

导致兔子不敢搞规模降息、放水、发债刺激经济，因为一旦钱多了，你根本拦不住大量资金外流。兔子量化宽松本来是想让投资的，结果钱都跑出去了，那国内投资咋办？

更严重的是，美国加息提高美元资产的收益率，增强美元作为避险货币的吸引力，美元指数走强，直接导致非美元币相对贬值。这样一来，很多企业出口商品赚了美元，回国结汇就变成了赔钱的事情，不如在国外投资美债划算。

这样一来，就相当于原本应该回兔子的钱沉淀在海外了，对于兔子这样的大顺差国家来说，会加剧国内通胀，资产价格下跌，到处缺钱。投资和外贸都熄火了，那经济还好？但是美联储降息之后，那效果立竿见。首先，美联储降息，当地回报率下降，会有大量资本离开去新兴市场。所以资本必然流入，就像去年9月一样，对兔子的一些成长板块（比如科技）带来大利好。这种外资涌入不仅仅是股市的表现，更多的是对行业的拉动作用。打个比方，公司突然增加了100万的投资，产出更大，利润率增加了，甚至可能裁员再招，对大学生就业非常有好处。失业率下降了，整个社会更加稳定。其次，中美之间的利差缩小，热钱会涌入兔子市场，抢着买资产，房价也会跌，大大缓解房地产困局。第三，利差缩小会让兔子采取更大规模的货币政策，流动资金自然活跃起来，利率下降让个人贷款成本降低，有助于消费。当然，这些不可避免会导致人民币升值，兔子出口结构已经变了，原材料花费也会减少，总体利润反而增加。

所以，本轮降息意味着兔子团结一心，终于赢了美国发起的金融战，在AI领域不断取得突破，兔子极有可能回到经济高速增长的通道，让我们拭目以待吧。

这一轮降息将会给我们带来什么影响呢？来说结论，对兔子市场是个不小的利好。为什么？因为自从美国加息之后，中美之间发生了巨大的利差，最高的时候竟然达到了2.9%！这带来了一个什么样的结果？举个例子，你有100万，买兔子国债利率是一点多，买美国国债利率是四点多，你会怎么选择？肯定是想办法把钱换成美元去买美国国债啊！哪怕兔子有外汇管制，但也有太多的渠道去玩这个，所以只要息存在，这种趋势是拦不住的，这就是所谓的资本外流。

从趋势上来看，一定是利好。考虑到特朗普即将开始。
