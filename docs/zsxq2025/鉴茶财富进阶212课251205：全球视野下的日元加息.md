


# 鉴茶财富进阶 212 课 251205: 全球视野下的日元加息

日本有独立的金融体系吗？没有。一直是美元的附庸工具。

日元在过去拼命印钱，竟然能够“避险”，主要是四个原因：

一个是 G7 工业国家的体系和信心；
一个是日本在海外拥有巨量资源，包括各种矿产，东南亚的工厂等，有底层资产；
一个是日本汇率自走，日元可以便利的兑成美元，日元对美是贸易顺差；
一个是日本有美国的“安全保障”，经济和安全形势比较稳定。

俄乌和懂王上台以后，东亚军力崛起以后，这些基础都逐步不存在了。

2022 年以来国际资本的布局是：

1. 通过发动俄乌战争，断欧欧洲能源，唱空东方等方式，迫逼全球热钱回到美国，美储加息加速这一历程。
2. 在美股高位和美国利率高的时期，套现走人，寻找新的价值洼地，抄底便宜资产。
3. 这个过程不能一蹴而就，需要踏板和通道，日元就成了载体。
4. 美元指数高位时，逼迫日元走弱，大量美元和美债抵押（巴菲特这种），换成更多日元，建立出发阵地。
5. 在阵地上顺手买入商社，顺势把日本股市抬高，高峰套现，多赚一道，继续积累大量可用现金。
6. 此时你再看2022 年那些撤出地区，东欧，俄国，是不是需要重建，东大，是不是资产价格处于洼地？好的，准备慢慢买入。

他们准备走了，日元你可以可以加息了。

一手限制对美贸易顺差，不能再沽美国的便宜，一手再吓唬一下全球市场，一手让自己手中的日元能增值。
