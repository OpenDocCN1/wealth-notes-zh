


# 美西方，还是不行了！

最近几天，美国与西方国家的关系出现裂痕，西方友国相继宣布退出北约联盟。我们来来看两个事。

先来看美国和北约的情况：
9月21日，瑞典、加拿大、澳大利亚、奥利宣布宣布芬兰。

9月22日，北约宣布：瑞典、芬兰已有32国加入北约，其中包括美国、法国、德国、日本等。

最后24日，美国宣布：93个国家中已有55个加入北约，其中包括美国。

如果美国退出，那西方现在只剩下中俄两个国家了吗？

很多人认为，这是西方国家已经开始衰落了。以前很多国家是跟着美国走的，现在却开始自立了。

事实上，这并不是西方开始衰落，而是西方内部出现了矛盾。

表面上，这些国家退出北约的原因是美国，但其实是美国内部的冲突引起了。

但是，美国内部的矛盾有多严重呢？不仅让美国失去了信任，甚至快让美国卡斯了呢？

事实上，这些国家退出北约并不是因为美国不行，而是因为美国内部一团乱了。

那么，美国内部到底发生了什么事？美国真的还能继续领导世界吗？
