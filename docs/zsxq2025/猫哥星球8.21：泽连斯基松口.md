


# 泽连斯基松口

嘉宾：梦回安西

美国当地时间2025年8月19日，泽连斯基表示，不再将停火作为“俄乌首脑谈判”的前提条件。

这是开战三年半以来，泽连斯基最大的一次立场松动。

此前，欧盟和乌克兰坚持“俄乌首脑谈判”可以谈，但俄罗斯必须停火，撤军，吐出占领的乌克兰领（包括克里米亚），然后才有得谈。

这个态度，就是不打算谈的意思，毕竟谁都知道让俄罗斯撤军是不可能的。

其实，2022年9月“哈尔科夫大捷”前，西方的态度还是不排斥谈判的。比如2022年3月的谈判，西方自始至终都没有表示反对。

“哈尔科夫大捷”后，西方的信心来了。再上上“赫尔松撤退”，战斗第一年，俄军的表现远低于预期。西方认为，俄罗斯很弱，谈判立场变得极其强硬。

你不停火撤军，我就和你谈。这一立场，是为“先停火，再谈判”。

俄罗斯的立场，一直是“先谈判，再停火”。

俄罗斯采取这个立场，一方面是不可能撤军，另一方面是害怕出现反复。因为先停火再谈判，等于战火随时可以重新燃起，反复复复地拖延。

2014年，俄罗斯上当过一次。

2014年乌克兰颜色革命后，亲俄兵和俄军在顿巴斯发起大规模攻势，当时的乌军，根本没有做好战争准备。

能动用的正规部队，只有俄区5个旅，剩下一堆组织民兵，比如“亚速营”、“顿巴斯营”，都组织建不久，战斗力还不强。

亲俄民兵因此打好了几场胜仗，局面一度大好，但普京在德法两国的软硬施下，同意不扩大战果，双方签署了落实停火的《明斯克协议》。

# 结果呢？

利用停机的机会，乌军成功稳住了阵脚，直到今天，俄罗斯国内俄论都对《明斯克协议》存在巨大的不满，认为如果2014年不停火，乘胜追击的话，就没有今天这么多事了。

普京如果不想再被悠悠一次，就必须坚持“先谈判，再停火”的立场。不谈判，就跟你死磕，不存在先停火的可能性，避免局面再次出现反复。

# 特朗普普京呢？

也支持普京这一立场，从务实的角度，和平协议可以一劳永逸，减少拖延可能的。

从务虚的角度，和平协议也比简单的停火更好。

特朗普是想要拿“诺贝尔和平奖”的，前段时间，还被曝出亲自打电话给北约秘书长、现任挪威财政大臣的斯尔滕贝格，要求斯尔滕贝格帮助自己获奖（挪威政府在诺贝尔和平奖的评选中，份量很大）。

如果能促成和平协议，绝对够资格拿奖，但停火就不同了。停火很容易出现反复，万一前脚拿奖，后脚又打开，岂不尴尬？

而泽连斯基的立场松动，原因除了了特朗普施压，和乌克兰的人力资源枯竭有关。

当地时间8月12日，乌克兰总统泽连斯基表示，他已指示乌政府和军方考虑放宽对22岁以下乌克兰人的出境限制。

从2024年起，乌克兰政府对22岁以下年轻人的出境实施了很多限制，很难出去。

今年7月以来，由于正在进行的俄军战役局面不利，乌克兰网络更是盛传，军方为稳定战线，准备征22岁以下的年轻人，并得人心憧。

泽连斯基不得不再表态，不应限制22岁以下年轻人的出境，安抚一下社会。问题在于，乌克兰的人力资源，是一个摆在台面的事实。

比如，最近俄军掉了至关重要的顿斯克区域高点“恰索夫亚尔”，在恰索夫亚尔的一位乌军营长就直言：我们没有足够的步兵来防守。

所以，泽连斯基的表态，是指示政府和军方“考虑放松对22岁以下乌克兰人的出境限制”。

重点是“考虑”，是否同意不好。

从侧面说明，乌克兰政府和军方不太想让22岁以下的乌克兰人出境，乌克兰的人力资源危机，已经到了很严肃的地步。

战争每进行一天，俄罗斯的优势就大一点，此时不谈判，越往后，乌克兰没有筹码。这种情况下，泽连斯基只能松口，改变“先停火，再谈判”的立场。

同意先谈判，其他事情后续再说。

不过，短期内谈成果的可能性仍然不大，要是俄罗斯给出的方案，乌克兰难以接受。

俄罗斯的方案，是要要求美国法律上承认克里米亚、卢甘斯克、扎波热、赫尔松三州按实际控制线停顿，顿茨克州西部的乌军撤退，让俄军接管顿茨州西部。

作为交换，俄罗斯将哈尔科夫州、苏梅占据的领土归还给乌克兰，同时保证，扎波罗热州和赫尔松州的战线，不会发动新的进攻。
