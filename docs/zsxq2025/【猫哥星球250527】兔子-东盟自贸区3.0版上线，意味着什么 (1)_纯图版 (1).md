


# 兔子-东盟自贸区3.0版上线，意味着什么？

在5月20日这一天，我们相继宣布了2件大事。

其一是5月30日在香港举行国际调解院的公约签署仪式（关于这个内容，大家可以爬楼看前期的星球文章一“香港国际调解院，一场静悄悄的革命”）。

其二就是涉及兔子和东盟深化合作的重磅协议。

5月20日，兔子与东盟10国经贸部长共同宣布，全面完成兔子-东盟自贸区3.0版的谈判，并计划积极推进各国国内签署签署批准程序，争取在年底前正式签署协议。

这不是一件小事，而是涵盖全球三分之一的人口和GDP，未来每年贸易额超过5万亿人民币蛋糕，促进兔子和东盟区域产业链更加深度融合的大事。

## 那么，我们该如何去解读这件事呢?个人认为应该

从2个维度去审视。

第一是历史脉络：

东盟10国包括文莱、印度尼西亚、马来西亚、菲律宾、新加坡、泰国、柬埔寨、老挝、缅甸和越南。

兔子-东盟自贸区的启动要追溯到2002年，兔子与东盟签署《兔子与东盟全面经济合作框架协议》开始，直到2009年签署《投洛协议》才真正算是主要的谈判，并于2010年1月1日起宣布正式成立，进入全面执行阶段。

也就是说，整个1.0版，跨越时间将接近8年。

而2.0版的谈判从2011年就开始启动，到2015年签署协议，再到2019年全面执行，差差不多用了8年时间。

那么当前的3.0版呢？

加微信intsg2，资料分享群

从宣宜的信息看，从2022年11月启动谈判开始，经历9轮正式谈判和上百场工作组会议，到2024年10月谈判，目标在今年底签约。

虽然全面执行的时间尚不明，但是我们单从谈判到签约这个过程，3.0版明显较之前1.0和2.0已经大大提速了。

为啥？

其实很多人不太清楚，东盟成立的初衷，最早虽主要的出发点是抱团取暖，平衡内部各国之间的关系，但是还有一个隐藏的，就是对抗我们。而且想插手东盟事务的国家，不仅仅仅只有老美，还包括俄罗斯、日本、印度甚至澳大利亚。

所以，在面对外部势力干扰，内部各怀鬼胎的情况下，我们和东盟的自贸区合作进展才显得异常艰难。

从2002年到2025年，整整用了23年。但现在，时局正在发生根本的变化。

第一，不论前期的道路走的多么坎坷，甚至现在菲律宾远在当“刺头”，但是我们和东盟的整体合作体量还是在进一步扩大，2024年双边贸易额接近7万亿人民币，双方互为最大贸易伙伴。这是一个基本盘，谁会和钱过不去。

第二，在16年中南海对峙以后，特别是近几年，随着我们在科技、军事方面的全面迸发，不管东南亚诸国有什么歪脑筋，都必须要接受兔子的强大，积极向我们倾靠的这个事实。

比现在越南已经悬勒了，菲律宾这次也选挣着鼻子认了，不承认就可能被盟踢出群。

比去年东盟开会，企图妄想再提“北亚亚洲版”的调，印尼就警告日本说：克制一下，不要自找难堪，东盟对“亚洲北约”不感兴趣。

### 第三，外部势力比如俄罗斯、日本、印度等，搞点小动作恶心一下，刷存在感可以，真想深度介入进来，现在已经有心无力了。当然，为啥自诩但就算川普选择拉拢盟，通过关税优惠搞分化瓦解，除了拖延下时间，本质上也挡不住兔子-东盟自贸区前进的步伐，这就是要谈的第二个维度，关于3.0版的核心内容，

这次3.0版自贸协定的主题是“包容、现代、全面、利益”（注：原文“意大利”疑为“利益”之OCR误识别，此处根据语境修正为“利益”），这四个方面包括：

- 包容：让不同发展水平的国家受益。
- 现代：涵盖数字经济、绿色经济等新兴领域。
- 全面：涵盖贸易便利、标准互通等内容。
- 利益：让大家在规则中共享收益。
