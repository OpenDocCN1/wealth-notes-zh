


# 米联储见闻20250611——闻道龙标过五溪

这个世界，所有的道理都需要实力支持。我一直认为，美国是一个非常务实的国家，川普更是一个非常务实的总统。当中中美是两国对立时，很多核心矛盾都无解，但是当美国分裂成两股势力后，很多核心矛盾就变成了博弈的筹码。美国内部的竞争正在成为侵蚀美国国家利益的毒液，但即便每个人都能轻易看出问题，身在其中却也身不由己。当年兔子内部神仙斗法时，香港街头人潮涌动，美国隔岸观火；今天兔子回旋镖精准命中靶心，正可谓“天天在看，苍天绕过谁”。

这边厢，伦敦传出积极信息，中美经贸磋商首次会议有框架性结果。所谓框架性，就是大家把自己的边界和红线交底，达成了彼此的共识，在这个区域范围内，可以实施可行的合作和交易。大家都知对方要什么，对方不能放弃什么，互相都能接受对方的底线，才能谈上真正意义的合作。这里面最大的变化，就是中美谈判不再是美方单方面威逼，而是真正相互解决关切的对话。

中方会后的表态很常规，还是过去那套，可见方从一开始就很明确的诉求；而是美方的表态一直在变化。这次会后，美方的表态是：“本次会议取得了积极成果，进一步稳定了双边经贸关系，将按照两国元首通话要求，与中方相向而行，共同落实好会议共识。”这中间很关键的一句话就是“与中方相向而行”，这是中方一直以来所强调的事情，现在美国终于接受了。

这边厢传出积极消息，那边路透社透露，兔子商务部已向美国三大车车的稀土供应商发放了临时的出口许可证，通用汽车、福特汽车和斯泰兰的供应商已获得部分稀土出口许可。商务部同时表示，愿意为符合条件的稀土出口申请提供绿色通道，以加快欧盟企业的批核流程。上述企业获得的稀土出口许可证至少有效期为六个月，但目前并不清楚具体获批的出口量、具体产品类别。这个结果表明，兔子确实是拿土拿捏了美欧。

在美方缓解稀土的消息的同时，兔子这边也发布了一个消息，就是长和出售海外港口资产的问题。说明和卖资产这个事情确实不是李家能说了算的，当年他能买以及他现在能不能卖，都不是他能说了算的。而且这次不是李家出门表卖或者不卖，而是巴拿马运河管理局跳出来来说，目前交易结构或将导致所有权利过于集中，损害巴拿马市场竞争力，也不符合中立原则，并不会允许美政府船只免费通航。

你看到没有，当大哥们在台面底下把利益定了，小弟们就就好了，各归其位，在商言商，通情达理。所以解决问题就要直面根本矛盾，本身是中美关系的暗礁，妄老李很狠也没用，而中美的矛盾最终是双方实力决定的。实力不够，矛盾就是矛盾，根本无解；实力到了，矛盾就是势逼人强，不行也行了。

对于巴拿马的表态，外交部顺势表明一立场：“关于港口和出售海外港口资产，国家市场监督管理总局和相关部门已多次发声，你可以查阅。作为原则，我在这里强调，中方一贯反对经济胁迫、霸道、霸凌。关于有关国家船通航问题，中方将一如既往尊重巴拿马运河的主权，承认运河作为永久中立国际水道的地位。中方支持巴拿马作为主权独立国家，坚持独立自主，坚定捍卫自身的合法权益。”这一唱和，就把这大戏给唱完了。

实际上，中美这轮沟通效率非常高。5月初次接触，6月领导通话，三天后再次接触谈两天，就达成了“框架协议”，延续了世界上两个最大经济体上个月达成的贸易休战。远比川普1.0时代的谈判节奏快很多，说明美国有自己的难处和紧迫性，确实也是等不起的。

谈判小组成员之一，商务部长卢卢特尼克表示，美国对兔子限制稀土矿物和磁体出口的担忧已经得到解决。他还说，在协议实施之前，川普领导将听取有关协议的简报。更有意思的是，他说了一句：“他们专注于努力实现习主席告诉川普总统的内容，我认为双方都有额外的动力来完成工作。”这说明中方在落实领导意方面不遗余力，而美国对此表现出了配合态度。

回顾这段时间以来，中美的斗争过程有一点很明确：要在斗争中获得话语权，卡住对方的尺寸才有话语权。所以对中美来说，这几年比的就是谁的短板少，谁能拿捏对方的短板，谁能死死卡住对方的供应链。兔子出手晚，但出手时已经占据了绝对的优势，但它能垄断，而且时机精准，把王牌留到了最后，不出手则已，一出手卡死，而且是完全不做利益考量。

相比之下，美国在卡兔子芯片这件事上，利益考量太多，绳子一寸尺寸收紧，又担心一下子卡死了经济利益受损，结果给了兔子巨大的时间和空间去解决问题，争取活路，结果却没有卡住，反而让对方出了手脚。
