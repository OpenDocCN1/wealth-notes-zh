


# 储蓄本人的“三驾”

2023.05.22

作为通过储蓄增加财政收入的方向之一，官方在10月16日召开了首次储蓄管理工作会议，将“三驾”作为议题。

这次会议要关注的是，储蓄为引头，已经有一国通过资产化可以实现财政收入的增长，另一方面资产化也可以实现流动性，另一方面资产化可能带来风险，不能亏损、不能泡沫、不能剧烈通胀，也不能面临巨大的风险。同时，2023年以来，政策的“三驾马”到底效果如何？

官方指出，要警惕“三驾马”带来的风险，这是一个系统性问题，也是国家级的风险。2023年5月以来，官方通过资产化来扩大财政收入的增长，但面临着风险，那么储蓄的风险性在哪里？所谓的储蓄的风险性到底在哪里？此外，资产化是否具有可持续性？

## 如何解读“三驾马”的政策

这次政策涵盖了资产的资源化、资产化、资源化，最终效果如何？北京的2023年三驾马化目标为扩大财政收入的大目标，其目标是通过建立一套资产化模式或资源化模式，来实现这一目标。这需要新的政策配套，以防范可能出现的极端风险。

首先要做好储蓄的资源化，其次是资产化，土地、房地产，最后是资源化，最终的效果如何？北京的2023年三驾马化目标为扩大财政收入的大目标，其目标是通过建立一套资产化模式或资源化模式，来实现这一目标。这需要新的政策配套，以防范可能出现的极端风险。

从2015年以后就开始了一系列改革措施，政府明确了“房地产资源化”的初衷，在土地资产化之后，土地资源化之后，官方在10月16日发布的意见中，提出了“一条路到底”的改革，用贷款置换住房或许可以实现。

从这些政策的背景来看，政府的意图是，通过资产化缓解地方政府的财政压力，通过资源化缓解地方政府的债务压力，通过资产化缓解地方政府的土地财政压力。

但这些政策的执行过程中暴露了新的问题。由于地方政府的财政压力，通过资产化缓解了地方政府的土地财政压力，但并没有解决地方政府的问题。在地方政府债务巨大的背景下，通过资源化缓解地方政府的债务压力，但引发了地方政府的财政问题，这就产生了新的风险，那么政府如何防范这些新的风险？

另一方面，资产化也带来了新的风险。由于资产化缓解了地方政府的财政压力，但可能增加了地方政府的债务压力，这可能引发地方政府的系统性风险。

目前全国的经济面临着需求侧结构性改革、供给侧结构性改革的矛盾，这并没有得到解决。但是，通过资产化和资源化，可以缓解这些矛盾吗？在房价以及房地产市场，资产化可以缓解吗？资产化和资源化可以缓解吗？那么储蓄的化效果如何？储蓄的风险在哪里？
