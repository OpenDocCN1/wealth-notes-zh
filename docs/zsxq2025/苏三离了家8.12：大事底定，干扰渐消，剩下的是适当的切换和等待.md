


# 大事底定，干扰渐消，剩下的是适当的切换和等待

原创 苏三离了家 2025年08月12日20:47 湖南 6听 全文

今天更新一下8月的合集，说一下对下个阶段交易的看法：

站在此刻回头看，如果在4月7日（此处可能有误），大部分人那会满心的惶恐和不安，以及对未来往何处去的茫然无措，3000点发危机，不知A股将往何处去。

但仅仅4个月时间，上证指数就已经回到了3600一线，离去年10月8号的珠穆朗玛峰仅10点之遥。

也是如此，在4月巨大利空击出深坑之后开启反弹，4多个月了，还处在这一轮反弹周期中，甚至都不好称其为反弹，毕竟将近700点的反弹也太过了。

在反弹的某几个阶段，我主动去判断过见顶，在数日乃至一周周的周期内看似是正确的，但没过多久指数就又回来了。一直关注我的朋友应该都知道，我一直觉得W底更稳固，有一只右脚会更好，所以在心态和预期上一直有在等待那一只右脚，但不好意思，一直没来。

在指数这600点的反弹过程中，并没有单一的主线贯穿了这一轮的上升，生蛋百丑，大家。

4月利空后我梭哈的，填了7号的大坑；4月底5月初转了一波科技，中道崩组，然后美国医药加税的消息利空转去了创新药，一直做到6月中旬，中东打开，因为经历过关税战黑天鹅流动性危机的原因，我现在对风控值提的很高，所以那天开盘就是迎仓，等中东事件平复，最后就是6月23/6月24重新梭哈，回归科技至今了。

所以我我自己在整个反弹周期里的节奏大大概是消费-AI/机器人-新消费/创新药-科技。

在我做的这些东西之外，可能还同时存在一些很强势的题材/主题，但我基本偏离了交易方向，按部班班去做自己看好的东西。

并且非常非常非常重要的一点，我在介入的时候都是板块的左侧，在每个阶段的绝对底部，无人问津，也没有什么在较长周期内看好，所以买起来很从容，成本相对值非常低。

因此，我在交易上其实是基本不做跟随的，只有在自己的认知框架内审慎思考后的绝对主观。

我如此主观的性格，强势的上证指数其实是让我很难受的，因为在某一个看似摇摇欲坠的时刻，我总想主观的判断要见顶了，但它每次又都回来了，主观的想法和客观的事实之间的矛盾，会让我心态上有些焦灼。

所以，我在6月底指数回踩后再度重新向上时选择科技作为这一轮的交易方向，很重要的一个原因，我之前也写过：上证和科创之间的剪刀差，科技板块在事实上是落后于上证的。

基于这个事实，指数如果继续反弹向上，两创科技有补涨的空间和动力，如果涨几天后然而止右脚，先跌的先企稳，科技往下的空间也不大。这是在尽量做好风控和回撤空间准备的选择。

后发生的现实是：上证在6月底最后一次踩了MA50，之后一路增速慢牛上涨，先破25年3月高点，然后一路逼近24年的最高点。

我不觉得有人能提前想到会这种情况，8月才过去一半，眼看着就要越过那座高山，毕竟在7月底的那个调整，也不看着特别像不行了吗？那谁想得到接着就是一波波上证7连阳呢？

我这几天有在思忖，我到底是靠什么精神力这一一路满仓甚至满融的坚持下来的。并且很多很多很多次我的脑子已经开始打架，劝自己控减仓了。

我想大概这么几个原因：

1. 足够好的买点，足够低的成本。我买的所有科技股，在我买入之之后，除了个别的，在之后的时间里都没有止损的机会。

2. 足够强势但温和的指数。上证在我重新满仓之后基本上沿着50日线运行，走势强但不会过度，这对趋势很有利。

3. 心态上放弃直接在高位波动的风险，刻意的用高位来控制。

4. 风格上的契合，带来了很多的超额。这一点其实讲过，7月中之后基本进入了新易盛/中际/工业富联几个风格趋势上涨，不停涨。这种风格延续至今，越来越多的股票走出了整个框架，去高低。

5. 不确定性，也之前很难克服。经历过清明之后，现在的基本对不确定性放在首位了。

8月最大的确定性是什么？在我眼里是8月12号关税到期后能否顺利持续。其实我遭遇基本没有第二担心，因为论一直会继续续期90天，没落地前，哪怕99.9%的概率，我不想碰到那99.9%的一致性反词是反向而行，99.9%的踩踏。而且斯德哥会议，我们跟美国并不好。所以我一直没减仓，但在上周开始缓慢减仓，卸掉了，对持仓的构成在后面做了调整，来临时小概率，足够对冲，并且保存了余力。

具体的：我买了中国移动、制冷及稀土。

1. 小转大，在本周内放弃小微盘，转向大盘股，应对微盘的中报风险。其实涨得比较好的已经都是大股了，趁着大部分人还贪的时刻，应该有时间完成切换。这也是我上一篇文章强调的，此时我们要追求平衡。

2. 这段时间涨的多又涨高，自己没有成本优势，既没中报又没出报的公司PASS，既别持有，也别买入。如果本身位置特别低，自己很有信心，那可以自己决定。

3. 交易能力不行的朋友，我建议还是主动减仓以规避风险，指数冲击3600是很合适的时机。如果不减的话，尽量把仓位聚到中报业绩断层，最近回踩过的横盘的公司里，类似于我买巨化北稀的地方。

4. 本周的四五到第三周这几个交易应该是8月风险最大的一段时间，可能在这段时间少亏点。

5. 目前为止，还是更看AI硬件的部分，AI硬件理应有一波属于自己的主浪，这甚至都不是基本面决定的，是图形/趋势/泛滥的流动性/无比强势的情绪，这些因素决定的。只要不加滤，这些东西就会彻底燃尽，这些东西不见顶，就不可能有大的板块和主题之间的切换，而只有当它们趋势的回踩震荡的日子，其他东西出来可见天日。当CPO/PCB-液冷-电源-CPO完成一个循环，最后又回归CPO，回归中际/新易盛/亚宏/富联，它们结束震荡又一次开始上行，新高，为AI硬件突破估值天花板，打开新的空间。
