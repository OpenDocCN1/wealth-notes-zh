


# 卢克域251230: 本轮对台军演分析

12月29日，解放军开展“正义使命-2025”围岛军事演习。

相比之前的联合利剑演习，本轮演习更接近实战环境。演习区域突破了12海里所所谓的“台湾领海线”，演习区域距离台湾本岛最近仅有5海里，且首次在岛的东南部设置演习区，将巴士海峡包含在内。

另外，根据新闻公告，东部战区于12月30日在划定区域进行实弹射击。这是2022年以来，五次环台军演中首次加入实弹射击项目。参加演习的无人机，还拍摄了一张台北101大厦的照片。

如此精彩的演习到底意味着什么，我们细细道来。

## 01

央视发布演习消息后，东部战区放出了幅海报，一幅题为《正义之盾 破限除妄》，内容为两个有着“八一”军徽和长城图案的盾牌分别插在岛东北、东南海外，即台海和巴士海峡，拦住了2艘舰向台岛发射M142海马斯火箭武器的集装箱船、C-130大力运输机和弗利吉尼亚级核潜舰。

另一幅为《正义之箭》内控外敌，以箭比喻导弹，射向航号1108台湾磐辖号导弹巡防舰以及海尾角落的外军逐舰。根据影像图像判断，该逐舰应该是美方的阿尔伯拉克级。

将信息串联起来可以发现，本轮演习的第一个核心重点，就是新闻中的要域封控、外线立体阻阻等科目。为什么要进行相关科目的演练？其实就是对民进以及西方回应的。

《2023财年美国国防授权法》赋予了美国对台五五年内提供100亿美元的军援预算份额。而根据今年12月17日的新闻，军援包括光学跟踪引导导弹（TOW）及反装甲无人机导弹系统，步枪导弹及相关设备等等。这些装备都是在俄乌战场发挥过的，占美国军售的大头。

在台湾当局的设想，甚至历次棋推演中，台湾都可以利用东南方的海港，接收来自西方的物资。即便台湾岛北部直面大陆的区域全面丧失，中部还可以依靠山脉进行游击作战，学习乌克兰国土防御，组建驻防队伍。

换句话来说，西方援助既是台湾以武抗拒的生命线，也是其规划中计划解放的物资链。

而援助物资的入口，就是台湾东南部的港口体系。在内部的多次推演中，台湾默认这个区域在台海或者西方盟友手中。因此，能否有效切断东南海港的外援，是围困成功与否的关键。

所以，演习对台湾南方方向开展了高度针对性的演练设计。

这个部分，也可以最近比较火爆的集装箱模块化武器关联上。

该武器的出现，意味着解放军范围更广的区域拒绝能力。当年陆炮上舰，是基于客观现实的无奈。而现在集装箱模块化武器的开发，成功将货舰变成了武器运载平台，对于我国区域拒绝战略，具有重大的意义。

## 02

在过去一段时间内，台湾方面在系统研究乌克兰战争的基础上，逐渐形成了一套自己的防御认知：依托武器体系，通过制造足够规模的人员伤亡，来形成战略威慑，以此实现“以武拒攻”。

围绕这一思路，台湾开始针对性地引入和升级西方武器体系。空军方面，推进F-16V战机升级，并采购AGM-88辐射导弹、AIM-120中远程对空导弹，以增强防空压制与空战能力。

陆军方面，引入M1主坦克，替换原有旧装甲力量，同时大量采购 HIMARS（海马斯）火箭系统；海军方面，则部署岸基反舰导弹，强化沿岸阻止能力。

这套系统的核心目的，并不在于正面胜取，而是构建一张“高防、高代价”的防御网络。换句话说，防御本身，就是台湾威慑战略中最重要的一环。

而在末轮演训中，我们可以看到，针对台湾构建的这套作战体系，我军给了一套清晰、分层推进的系统性解题方案。

在此次演习中，均可以观察到台军F-16V使用“击手”应对对我方战机进行持续跟踪的情况。在台军具备AIM-120中程对空导弹的背景下，第一阶段竟然投入了无人机，显然并不符合合成与风险评估。

所以新闻稿中才会写：火箭军对多艘船目标实施点名追踪和模拟突击，并对陆上固定重要军事目标实施多波、大量模拟击打。

此说明，演训的第一步不是海军机动，而是火箭军突袭。这一安排，本身正是俄乌战争反复验证的经验总结：在面对具备现代防空体系的对手时，首轮行动应依赖航空兵强袭入，以导弹撕开防线。

随后，就是空军与海军联合开展争夺。在火箭军完成对固定目标的初步毁伤之后，空海力量进入，夺取空权与海权。

官方新闻将此阶段概括为“综合权”，这一概念并不限于传统意义上的空、海。在现代作战条件下，“综合权”至少包括：
- 对敌方卫星体系确定位能力；
- 对雷达与通信网络的干扰能力；
- 削弱对方指挥、动员与组织能力。

在围岛演习中，这显得重要。完成这一切之后，则是陆军火力机动。在整个练习过程中，各军在不同阶段、不同目标上的明确分工，正是联合作中最关键、也最具实战价值的部分。很有可能是在凌晨时段，我军从西南方向实施了明显的掩护行动，成功吸引军方防空与空监控的注意力；与此同时，无人机则沿海低空接近北方，完成了关键侦察任务。

换句话说，台军被牢牵制在西南方向，在台北方向形成了防空盲区。而这一点，恰恰触及了围岛演习的另一项核心价值：通过演练，逼迫对手做出真实反应。

台湾强调自己是全球防空密度最高的地区，为了进一步提升台湾防御能力，赖清当局推动了台湾之盾防空系统建设，计划将美国爱国者导弹、NASAMS防空系统，以及台湾自制的天号、雄风导弹与反无人机融合在同一指挥网络下。

而无人机对台北地区的侦查，恰恰戳穿了赖德的美梦。这次试探，明显拆出了台车的不足。如果说，联合利剑系列演练，主要检验的是战区体制下，我军军种之间的联作战能力，那么“正义使命”所呈现的层级，显然更深入一步。

正义使命并不是对一个战术场景的简单重复，而是围绕台湾整体防御战略，逐层拆解、逐项验证的系统性推演。本轮演习中最冲击力的一幕，无疑是我军无人机俯拍台北大楼。从公开视频判断，该型无人机如果是战时，这么短的距离，台北地区所有目标都处于火力覆盖范围之中。

看到这里，很多人可能会产生疑问：俄乌双方早已频繁使用无人机突袭，怎么拍到一座建筑就成了“意外之喜”？在俄乌冲突中，大量投入无人机本质更接近“巡航导弹式”自杀无人机。这类无人机体积小、飞行高度低、雷达反射面有限，反而不容易被防空体系第一时间捕获。

而此次出现在台北上方空中的无人机，并不属于这一类型。从画面判断，它搭载了红外探测系统，体量明显偏大，雷达反射面远高于攻击型无人机。按理推断，此类目标理应被发现。

更值得注意的是，画面显示，该无人机的行动时间大约在凌晨1点44左右。在查阅台军同期发布的台海动态通报后，我发现台军晚上通报的空中活动主要集中在西南方向的机群，对于台北方向的无人机行动则完全没有提及。
