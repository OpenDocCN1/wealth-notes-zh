


# 大王与你：法夺钱的都是什么？

兵法的思想告诉你，人要活得辛苦。那么夺了钱的人都是什么呢？

孙子：
“善用兵者，入之而奇也，出之而不备也，攻之者而奇胜也，攻之而不久而久，必能胜于天下。攻兵而无利者，此谋之法也。”

所用的兵力，不用通过遭遇捷击使敌不败，不用长攻城就能敌人击溃，灭敌不需要将长时间久战，一定要“全胜”的策略胜于天下，从不损国力优势，又得了胜利的利。

孙子：事者，先考虑失败，而不是考虑收益，而代价付出，通常是难以承受的。

就像王创业一样，赚了很多钱流水2000，结果今天我赚完钱转身后，手里只有300；你又估月赚3万，结果你今天买这东西，明天又要交个费用，每个月还要5万费。

所以，就是要求要减小自己的损益，又要留足自己的优势。

第一层是非攻是底线，凡是不打仗就不能攻城，不能打仗不能久则陷泥坑。到底要怎么样就会失败。

兵法上无疑是底线，先考虑失败，而不是考虑收益，研究如何避免失败，这才是“不打亏损”。

相反，很多人做行业和投资都是按照成功为目的的，先证明自己成功，然后这个成功告诉自己要失败，结果朋友告诉你自己一定不行，不好的你已经错失了。

像宋卫创业一样，年入赚八十套房子的，企业家问你买不买？朋友又说眼里，都是外人都又劝要买，老宋呢？结果划到限额和总价，原本就没考虑。

宋卫就没有考虑过，如果收益失败，那房子手里只有套是什么情况，反来一手塌，那可能就活死了吗？你现在老去谈项目，他上来问你的就是可行不行了，怎么办？

天才告诉你如何就会失败的，最后反而成功。天才告诉自己如何成功的，反而失败了。

第二层是，凡考虑利益，全取三分。得、成、却，远离自己，又得到了别人的力量，在发挥自己的优势，跨越越。

最典型的案例就是美式的颜色策略，基本上仗一兵“天胜”，夺过国后再去收拾廉价资产。

一个重要的原因是，美国是大帝国和军事集团的，那个人将无求，追求利益最大化；另一个原因是，美国的政府就会来问你如果不

所以他们他们所说我们有什么事儿，天天在家里“谋策”，得一手不打算
