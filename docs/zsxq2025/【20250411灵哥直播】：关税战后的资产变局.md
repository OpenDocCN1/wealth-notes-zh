


# 4月 11日直播：中美关税后的资产变局

## 1. 深度分析中美脱钩趋势

中国刚刚正式宣布继续加码关税到125%，对美反击。

不过公告中说：鉴于目前关税水平，美国商品已无市场可能，如果继续加征关税，中方将不会予以考虑。

就是说后面在关税数字上就不陪玩你了，你爱加多少多少吧，反正我们已经在实质性关系全面脱钩的方向上走了。

然后我们还有一句话：“若美方继续实施实质性损害害中方利益，中方将坚决反制，奉到底。”

这句话含义已经很清楚了，后续就是打你的，打我的。美国再不回头，别怪我们在全球的各个阶段全线反击。

现在是可以值得的战略路径，这个机会是特朗普送给我们。

对内是统一市场，外贸整合，内循环，一思想重视消费拉动增长，发展外循环，发展科技，国产替代。

对外是赢过美国，让美国回到中国，中国提供各国一切，从基础，到资金，到科技，到市场。

一路是我们主动的，要让别人为什么要跟你，后续的外循环和中国经济的全面深度调整，从军事到科技交通到人民币国际化，是会各国来我们。

从这一刻开始，国际秩序的旧王已死，新的确立。

特朗普已经软化了，我们现在是非常明确的他是睁看着你，他不理他。我们对是有是有提前提的，即取消所有关税，还有包括那些的小动作。

特朗普4月29日是百日演讲，如果他之前向中国进攻，取消所有关税，那他面子就丢大了。

一种可能是他要在最近这几个KPI，即某几个国家成立新的贸易协定来撑面子，4月29日后再处理对华问题。

就看他挣不住的，一个是金主的，是一个股市。

## 2. 中美何时降息深度分析解析

市场上都在押美联储6个月，今年降100个基点，灵哥给大家的定心丸一定会更早，降息幅度更大。

3月 CPI 是负的。特朗普曾加中国贸易战引发了大的通胀压力，对苹果等企业做了很多的利空。

老百姓的部分的涨幅可能跟不上美国国内服务业的暴跌，还有美国 CPI 指数中有25%是虚估房租，以前美联储每次都是虚估房租来操控的。

从美国实际经济情况来看，应该是衰退，而且局面是全面衰退。

当如近期美股连续暴跌，美联储召开临时会议降息，那一切有可能。

## 3. 美股是反弹还是转跌？后续分析，港股又如何

给大家介绍个逻辑，去全球买美股是自己手里有日元或人民币，然后卖出美元，然后去买美国资产，中国资产上涨，引发全球更多的人来接盘。

还有用日元这种玩法，干涉是借日元买美国资产。美国自己的对基金也是加了杠杆，大家可以看看比特公司MicroStrategy，还有外达崩国图都是错的。

现在的问题是当衰退来美国，特朗普增加不确定性，各国要被被打，大家首的就是卖出美国资产，所以这个路径就反过来了。

卖出美国资产，换回美元，这就会带来踏覆性的下跌。

日本经济通缓，哈非特买入日本，日本通起来，又要加息。欧洲要扩张张武，所以要扩张财政，现在要在意和合作，再加入中国科技来平稳，欧美价格将如此之止了。

所以中的博弈会体现在美国一下，中国上一下。每一天当不是全球资金进来，而是有实打实的业绩表现。

市值哪里呢？上涨就开始加息，就是全球价值要开始转移了，在过去赚钱，赚的是美国的美元，逐渐变成全球的钱，赚的是中国央银行的钱。

这里有一个货币发行理论可以解释这样，即未来美国人民币的发行将由本国资产组成，外汇占比逐渐下降，还有未来不能把生产资产吸进来，锚会导致债券贬值。

消费哪里来？村向向回，购买超市市场，城市反乡村乡村，形成的循环。老外可以来钱，在过程中命中到中优。

如果不是加入中国，就是不用中国老老百姓加入到中国的内外的循环。

以后港股A股都是芝麻开花节，你会发现港股更符合品牌类公司，A股更符合核心资产，核心供应链，当然其中有交集，很多公司也会上市，视源被考虑在香港上市。

从金融层面来说，实际上是多了一层防火墙，A股定价权全控，港股无法做到全控，受国际市场情绪波动会更大一些，但是两层防火墙，风险就变小了。

美国等中国做空吗？用不用考虑这个问题，中国在美国市场上是帮美国赚钱，而现在已经是双重上市了。

几年前审计合格的时候，那时候复文要写些最后还是会好的，我们也也做了。但我们是每次被找，长记忆都是，可以改变限制条件。

美国市场在遭遇情况时，并非刚性偏，比如可视可可选，比如 Costco；另外国债只要大家相信美国这就不会错，那国债仍然是 OK 的。

金融市场今年会有更多情况发生，可以留资金，耐心等候。

## 4. 市场深度探讨

机器人、国产算、云计算、软件、半导体、AI端全都是被倾杀，业务和我们之间没关系，反的是利好，比如硅半导体等，加速国产替代。还有最近的AI相关的，比如端侧 SoC 芯片，云计算等都会变热，机器人基本上把前两个月涨幅跌了。

PCB错，出口到美国的比例很大。

创新赛是错的，因为不是出口位，和美国企业签署合作关系，也和关税关系。

新能源汽车，智能驾驶是错，反而是利好，中国达成优势，欧洲愿意放弃关税，而是以最低价格中国进来。

小米的硬件是错，和美国市场关系不大。

黑铁的错，其实在很多苹果公司全球都布局工厂，而且如果会被豁免的。尊宇光、瑞磊，立证会有大权翻涨。

AIDC 电源错，准澳、泰利、泰豪等均为国内业务为主，且美国品牌因其价格高了，我们还要让客户产生利润。

实际上很多企业反映后会因此受益，因为我们技术和高端制造仍然有很多优质供应链。

## 5. 黄金和石油趋势

黄金在3500美元走！美国马上迎来退和大印，非常美国信用。

特朗普已经说了伊朗不谈判，就会用军事手段。我们一定不要认为当前的叙事，比如美国国退预期，油价大跌，今年油价就一定回来，或者到100美元。

有两个变量，一个是特朗普继续老鼠，因为油价不低于页岩油，美国的石油市场在萎缩，Opec+为什么增产，是为了抢市场份额。

还有一个变量是各国的石油库存都很低，包括美国和中国一旦中国开始加杠，拉消费，美国大降，全球新增开始投资，很可能石油的需求太涨。不仅石油，很多实物资产等等有价值的需求，过去几年其实是在高利率下各国的投资投放。
