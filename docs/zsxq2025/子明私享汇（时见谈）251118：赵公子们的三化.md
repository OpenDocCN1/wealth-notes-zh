


# 赵公子们的三三化

发布时间：2025年11月18日

11月北京线下读者聚会系列内容

赵公子们购买消费品本身概率是输的，
但赵家是不会输的，
因为赵家普遍在国内拥有海量的固定资产，
这些资产想要在过去几年折价严重，
赵家想要把这些资产盘活，
就需要需要通过一些资产整合的方式来实现。

以上上海为例，
闵行、张江的大量商业地产，
都可以用来开星巴克，
什么星巴克自己教室，星巴克外语角……
还能让马弓老师老师把补贴转到星巴克，
18块的咖啡9.9 元，很快就能把市场份额
抢回来。

有市场预期，
这些大陆新开星巴克就可以港股 IPO，
赵家把烂在炉里的固定资产装入上市公司，
便可以最终换成股市出境，实现资金的撤离，
本质上，赵公子们就是想着国家的三三化周期，
实现自己家族的三三化。
跟 2015 年的很多企业出海并购还还是很相似的。

# 2015中企海外并购超593起 对外投资量首超万亿美元

来源：新华社《经济参考报告》2016年1月18日

商务部15日发布对外投资数据显示，2015年，我国对非金融类直接投资创下1180.2亿美元的历史最高值，同比增长14.7%。

从投资的方式来看，并购无疑成为2015年对外投资的主力。初步统计，2015年中国企业共实施的海外并购项目593个，累计交易金额401亿美元（包括境外融资），几乎涉及国民经济的所有行业。
