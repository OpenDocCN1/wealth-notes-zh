


# 聊聊内参、智库和规划的真实故事

中国特别缺人才。

老分析政策产业的容易疲劳，聊聊真实故事吧。经常有读者留言提到内参、国家智库，最近又逢“十五五”规划。从结果上看，感觉中国的决策特别强，能够很精确的预测未来国内国际变化，制定的中长期规划也基本能如期完成，这反映了中国的决策参谋能力很强，很容易把内参、智库之类想得很厉害。

实际接触之后就会发现，中国实在太缺人文社的人才了。内参、智库、规划这类最核心的参谋智囊，机构数量庞、人员也很多，每年产生大量的成果，但有价值的很少。在中国，规划、决策的人才不在智库单位，而在公职体系内，高级的领导才是这方面的专家。

小镇以前对智库有滤镜，直到真正接触。刚到北京的时候曾轮岗过一阵子，主要处理一些事务性工作，具体工作是两件事：一是批示跟踪，二是内参报告筛选。

第一件事最烦琐，领导每年有大量批示，不能批完没有后文了，就需要有专人按照批示去询问相关人员、部门，问问进度咋样的，有时候搞定了，碰到棘难题了，有没有需要领导汇报的等等，当然还有一些具体工作技巧，这就不展开了，最后整理出一个册子向上报告。就像在企业里工作，老板安排一项工作后，自己主动向老板汇报具体进度，别等到事情办妥了或者完成了一次报告，这会让老板觉得没安全感、失去掌控能力。

第二件事就比较有意思了，直接打破了小镇对多数智囊、内参的崇拜。小镇以前在基层工作，还是很向所谓内参的，刚接工作的时候，每天都收到大量已经经过层层筛选的内参资料，毕竟送到这个级别的已经是海量内参报告中最精华的一部分了，起码是前1%。

要注意小镇那时候工作没几年，个人认知能力不配给现在的小镇提坝，但当时看到这些东西，仍然大失所望，只觉得这东西小镇都能写。而小镇当时负责的就是根据一些要求，对到了这一步的材料进行第一轮筛选，除了某些有固定处理方案的，其他如果连小镇都觉得不妥的，就可以直接扔回袋了，甚至不需要粉碎处理。

现在回想下，当初的岗位安排特别好，让小镇这个基层人员直观地了解了那些高高在上的东西到底什么水平。当然水平高的确实有，但占比太少了。

哪怕部分优质的材料，也过于学术化、理论化，不接地气，并不能有效地指导实践。还有的对客观事物的认知需要更新，能够感受到受到一些现有理论体系的影响颇深，导致分析并不客观，最突出的就是对特普朗2016年胜选预测严重错误，都没有几个敢预测特普普胜选，至于客观调查处理就更难了。

所以2012年后强调“讲好中国故事”，随着中国自然科学和产业破局，人文社科的短板越来越突出。2020年在经济社会领域专家座谈会上指出“新时代改革开放和社会主义现代化建设的丰富实践是理论和政策研究的‘富矿’，我国经济社会领域理论工作者大有可为”，2022年提出“构建中国特色哲学社会科学，归根到底是建构中国自主的知识体系”，2024年最终提炼为“实施哲学社会科学创新工程，构建中国哲学社会科学自主知识体系”。

但难度非常大，甚至大于中国自然科学和产业突围。所以，大家不要看到小镇的文章就觉得自媒体都是这个水平了，国家智囊水平高到什么程度？其实如果把小镇放在国家智囊中，水平起码也能算平均以上了，上面自然有很多很厉害的人，但不要过于高估。

问题有很多，最突出的就是实践与理论的脱节。要想搞智库研究、写内参等，显然是学术界、理论界更多要做的，政府体系重点是做事。然而学术理论界习惯了拿来主义，对西方理论体系产生了非常严重的依赖，导致自主创新极为困难，目前也存在一些零散的小理论创新，但不系统，更无法拿出符合中国实践，又能得到其他国家认同的理论体系。在中国实践与西方传统差异越来越大的情况下，拿出来的建议方案，效用也可想而知。

而几乎所有现行人员、教育者习惯了西方理论体系，高校教师接受的往往是传统的学术训练，并不了解如何进行自我认知的拓展，去了解更全面的社会现实，别说一般高校了，就算在清华、北大这种级别的高校，教授与时代脱节，不是啥新鲜事。

还有一个问题就是中国不像西方，学术界和政界存在制度性的“旋转门”，在西方教授可以很顺利地去政府担任一定职务，比如美国搞贸易战，负责贸易战操作的就有大学教授。这就导致了理论和实务之间脱节更加严重。

虽然反过来官员可以去高校种种研究，但数量太少，而且基本上是单行道，出去了就再回不来了。至于目前存在的高校教授地方挂职，地方上不会真把挂职干部当作一般的，基本上是走个形式了。

在这种情况下，也不奇怪为什么内参、智库在国家政策决策领域能够发挥的作用有限。因为很多决策的细节和关键的数据，理论学术界并不掌握，而且看似高端的研究，最开始写的人或许不过只是在上学的学生罢了，能有多少见识呢？

当然，内参在社会上还是神秘的，就有不少智囊机构找企业要赞助，就说自己已有内参通道，能够到批和关注等。这话是真的，也确实能送上去，但想想每天这么多材料，哪里看得完啊，所以小镇都干过筛选，扔内参报告的工作，每天以公斤为单位扔废纸。

实在的，企业家赚钱也不容易，适度跟智库机构合作，搞影响力和背书是可以理解的，但真要想反映问题获得支持，不如直接走公关渠道，申请跟相关部门直接面谈，或者整理成报告。按照标准格式，小的概括在4页内，大的几十页详细展开，这些都是常规操作；或者决策者关注，效力更大、更快、更有力度，可以说改变了中国的治理。

因此，真正的国家治理精英基本上在公职体系内层级越高，认知越高。所以对国家政策感兴趣的，建议多看书籍，目前愿意出来的人太少，公职体系内的这类人才往往是自学出来的，导致数量严重不足。

在规划的层级上，一个典型的规划分配逻辑如下：

- 基层层面：主要是科员开始参与规划，打下手、跑腿、整理档案之类的活。
- 对应一级：科员和副科员基本成了规划的主力，负责具体工作。
- 对应二级：主任员开始参与制定，这时候是大部分力量，负责具体起稿。
- 对应处级：到了处级就是核心骨干，负责协调工作，培养出合格的规划。
- 对应厅级：到了厅级就可以对外组织工作，这项工作非常资深了。
- 对应部级：资深作者，不仅要对国家政策脉络，还要对当前国情和未来方向有准确把握，做出自己的意见进行判断。

这种规划过程不像自然科学那样确定性强，很多事是说不清的。在社会科学领域，个人的经验特别重要，这省省，很难培养出合格的规划。

所以小镇一直认为，一般高校和本科阶段，需要接地气了。小镇这个基层人员直观地了解了那些高高在上的东西到底什么水平。当然水平高的确实有，但占比太少了。

所以2012年后强调“讲好中国故事”，随着中国自然科学和产业破局，人文社科的短板越来越突出。文科真的不是没用，而是大用，问题是培养文科人才，尤其是用的文科人才，尤其是急需的文科人才，实在太难了，文科领域的分化比理工科得多。所以小镇一直认为，一般高校和本科阶段，需要压缩文科生数量，这对国家、学校、个人都是好处。随着中国向上攀登，对文科的需求大增，很多领域急缺人才。比如AI时代已经到来，如何对AI进行有效治理，这是特别大的难题。但难点很多，从个人的角度，生活在后智能时代的人，从小被大量AI炮制的虚假信息逻辑掩埋，由于过度依赖AI缺乏对自我思维和认知的磨炼，现在短视频在网络的占比进一步大增，碎片化、娱乐化、娱乐化更加严重，未来建立辨别真伪的能力都难，如何进一步学以致用？

这个话题太大了，小镇也没办法，只能尽力而为，起码保持自我的思考能力，努力做到“君子使物，不为物使”。
