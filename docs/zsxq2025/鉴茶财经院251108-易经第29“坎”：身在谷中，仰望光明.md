


# 鉴茶财经院 251108-易经第29“坎”：
## 身在谷中，仰望光明

人也好，国家也好，都会遇到“坎”，

最近的股市也是一个坎，主线混沌，风格漂移，赚钱效应很差。

造成这个原因是什么？

是前面的28卦，大过。

过，是事情过犹不及，科技涨的太多，又时值年底，要调整一下，消化筹码，反复震荡。

坎，就是坑，是陷，

一个人在低谷期怎么办法？遇到调整怎么办法？你的股票被套了怎么办法？

先用智慧给了我们指引和启发，

坎。习坎，有孚，维心亨，行有尚。

象曰：习存存，习坎。君子以常德，习教事。

“习”，是重复，也是练习，比如复习。尚，是风尚，风格。

“孚”，是信心，是诚信，大A也有很多带孚的，天孚不解释，还有个老登，中孚实业，做煤炭的，走的不错。

“亨”，是亨通，亨通光电我们也熟悉。

同学们平时起起名字，多看易经，里面很多吉祥的字，还朗朗上口。

这句的意思是：

坎，重重困难，荡如潮水拍岸而来，只要你怀坚定的信心，执者专一，坚持自己的风格，使心保持光明通达，就一定获得成功。

初六：习坎，于入巴（dàn），凶。

象曰：习入坎坎，失道凶也。

窘（jǒng）是坑里的坑。

掉了深坑里的凹陷，凶险。

明明知道有问题，非要要去创业，越做越凶，疲于奔命。

明明知道该走了，破位了，跌破箱体了，就是不走，坑里还有坑，跌了还在跌。

在困境的初始阶段，人们往往因为慌乱而做出错误决定，

此时的好点策略是什么呢？

不要乱动，接受自己被套坑里的现实。

六三。来之夭坎，险且旦，入于岌，勿用。

象日：来之夭坎，终无功也。

来去去的都是坑，危险且波折很大，一折又进深坑，不要动。
