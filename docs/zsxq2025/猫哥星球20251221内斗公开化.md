


# 李在明府，内斗公开化

## 嘉宾：梦回安西

近期，韩国统一部和外交部两个部门，矛盾公开，此事震惊了韩国政坛。

那么，这是怎么回事？背后，藏着什么问题？

12月16日，韩国外交部召开了“韩美对朝政策磋商”。

“韩美对朝政策磋商”机制，起源于2018年，由韩国外交部和美国国务院东亚局牵头，普通磋商每周一次，高级别磋商每年1-2次。

按惯例，韩国外交部、统一部、国家安保室这些部门都会参加。

但这一次，韩国统一部抵制磋商会议，拒绝参加。

因为前一天，韩国外交部发布了一份声明，主张“韩美对朝政策磋商”属韩美首脑会后续落实范畴，应由其主导，统一一部纳入了该框架。

以前磋商会议，就是大家平等交流，外交部和统一部是在里头话语差差不多，谁也管不着谁。

但外交部那一句“应由其主导”，等于以后磋商什么、怎么聊，我说了算。

统一部哪儿能忍?

于是，统一部选择硬刚，不仅抵制12月16日的磋商，还自己开了记者会。而韩国外交部，如期在12月16日，和美国举行磋商。

韩国外交部主张，韩国不能轻举妄动，擅自与北边交流，凡事等待来自美国的“指示”。试图掌握“韩美对朝政策磋商”会议的话语权，就是为了落实自己的主张。

而统一部认为，应该直接和北边对话，可以自己解决就没必要“麻烦”美国。

韩国统一部长郑东咏在记者会上表示，“若抱持等待美国批准和签收的官僚主义思维，半岛问题将无从解决”。意思就是，咱们能不能积极主动一点，什么事都等待美国“审批”？

这样一来，外交部和统一部的矛盾，就公开化了。

随后，六位统一部前部长，发表联合声明，力挺郑东咏，批评外交部。

六位前部长，分别是李钟奭、赵明均、金相哲、李仁荣、权守世、金慷洙。这六位部长，横跨卢武铉、文在寅和尹锡悦三个时期。

可见，两个部门的矛盾，已经积累了多年，不是今天才有。

而双方深层的矛盾，在于两点。

## 第一矛盾，是蛋糕怎么分

外交部负责外交事务，是国际通行做法。但北边和南边是同一个民族，如果用外交部，岂不默认北边是“外人”，不利于南北统一？

所以，1969年，韩国成立统一部，专责处理南北关系。

最初的设想，是统一部处理南北关系，外交部处理与其他国家的关系，分工明确。然而，实际操作中，这一设想无法落实。

因为南北关系，牵涉及的国家太多了。
比如，南北局势紧张，是不是要通知美国？那么，哪个部门来美国协商？

另外，“六方会谈”时，既和南北问题相关，又与其他国家相关，这种交叉状态，怎么划分界限？

十分模糊，也无法准确划分，因为涉及的东西太多了。双方在很多时候争夺权利，都认为自己应该管得更多，对方应该管得少少。

统一部长，和外交部的关系，往往好不了。

## 第二矛盾，是职能定位

统一部的职能定位，是南北关系，实际中，会做大量促进南北关系的动作，诸如民间交流合作、建工业园、离散家属团聚等等。

这种定位，让统一部属于“温派”；

而韩国外交部，底线是“国家安全”，对于民间交流，其实并没有大的意愿，主张对朝关系，不能脱离“韩美同盟”这个框架。

说难听点，就是听美国的。

而美国对北边的态度，一向强硬，即便是特朗普，和将军见面多次，也依然在军演、制裁等方面，保持高压态势，要求半岛无核化。

所以，外交部属于鹰派。

这种差异，直接体现在本次部门冲突中。

前面说了，韩国统一部长郑东咏在记者会上表示，“若抱持等待美国批准与签收的官僚主义思维，半岛问题将无从解决”。

这番话，其实说得很胆。

因为郑东咏说这番话的前一天，美国驻韩国大使馆临时代办金·凯文，才和郑东咏会面过。

在会面中，金·凯文明确，要建立外交与安保议题定期沟通机制，对外发布信息时统一口径，并强调要坚决维持现有对朝鲜制裁。

翻译过来就是，你的口径，和美国一致。

在此前一周，金·凯文在采访中说得更直白，“是美国特朗普政府在和朝鲜谈判朝核问题，韩国只是协助，不能越俎代翁”。

看到没，“韩国只是协助”。

韩国外交部愿意协助，而统一一部不乐意，这也促成了双方矛盾的公开化。

对此，李在明是什么态度呢？

他先是赞扬了外交部，称其“拓展经济领域方面发挥了重要作用，没有什么可批评的”。

随后，话锋一转，表示“不必要的强硬政策导致了双方的相互厌，解决朝韩问题是统部的责任”。

看似各打五十大板，实则站队统一一部。

因为李在明的对朝政策，和文在寅是一致的，希望通过温和手段，不说解决问题，起码将局势降温，别一天天整得大家那么紧张。

这也延续了韩国左派一贯的立场。

他任命的统一一部部长郑东咏，履历很有意思。

卢武铉时期，郑东泳就担任过统一一部部长，期间推动南北对话，曾以特使身份，会面南边的二代目。

同时，郑东泳还是李明的“恩师”，就是他，把李在明引入政坛。贵为左派大佬的郑东泳，倾尽资源，成功让李在明当选城南市。

没有郑东泳，李在明可能今天还在当律师。

可以说，郑东泳担任统一部长，李在明对朝政策的体现。
