


# 逆天命的5个玄学提醒

“命运”这个词听起来好像很妙，其实想要逆天命，并不需要到处求佛，也不需要请教别人。你只需要改变自己的处事方式和习惯，命运自然就会转变。今天我就跟大家分享5个逆天命的玄学提醒。

## 1. 顺应自然
无论命运让你承受，你就静静地接受即可，不要总是逆天而行。在此基础上，想办法把对自己不利的事情变对自己有利。

举个例子，我在公众号上每天放观点、表达内心的想法，很多人会在评论区嘲讽、批判我。这时候我的应对策略有三个：

- ① 下策：跟每一个批评的人都针相对，甚至相互攻击。而且必须要向他们证明：我是对的，你是错的；我的格局很高，你的格局很低。结果就是大家都会认为我是一个狭隘、愤青的人。
- ② 中策：只要有人对我提出建议或者意见，我都虚心采纳，反思自己哪里错了，争取早日改正。但问题是：无论我说什么，只要我发表观点，总会得罪一部分人。
- ③ 上策：只要有人在评论区批判我、嘲讽我，我都会第一时间挑选他们的留言，还会给他们点赞。会有有人支持我，也有人反驳我，站在我这一边。无论是哪情况，他都给我带来流量、带来度，我都应该心怀感激。所以，如果你以前是一个“听到让自己舒服的观点立刻炸毛”的人，那么你可以尝试把他们赶走，那么你的命运将会好转。

## 2. 不要跟任何人谈论梦想或目标
真正的梦想，一定是神圣，不能跟任何人分享。如果你忍不住跟别人分享了你的梦想、对未来的规划，那么实现梦想的概率就会大折扣。一方面是因为当梦想失去了神圣性，附在梦想上的核心能量就会大折扣，奋斗动力也会大折扣；另一方面是因为如果你的梦想太大、太耀眼，会招致小人的嫉恨，他们会嘲讽你、打击你，甚至暗中破坏。这时候你实现梦想的概率就更小了。其实不光梦想和目标，任何隐私都不要跟别人泄露，包括你的婚恋情况、家庭情况、收入情况等等。比如，你刚刚进入一个新的单位，这时候可能会有热心的老大对你嘘寒暖、关怀备至，接下来就开始打探你的隐私：有对象了吗？父母是做什么的？家住在哪里？只要你如实回答了，那么以后再次走入这个“场”时，你会感觉自己仿佛挂不住，能量非常虚弱。因为你的所有隐私都被别人掌握了，别人会根据你的情况制定出一套拿你的策略。反之，如果你的秘密越多，神秘感越强，那么你的能量也就越足，没人敢随意支配你、拿捏你。类似的，千万不要把一些神圣的理念挂在嘴边，那样的话分量会大折扣，甚至会引起反作用。举个例子，如果有老板的办公室挂在“厚德载物”“上善若水”这类牌匾，那么几乎可以肯定他对员工非常差劲。如果一个人的微信签名是“万恶淫首，百善孝先”，这个人一肚子坏水，因为缺什么才会宣传什么。

## 3. 一定设立清晰的边界，不要介入他人的因果
上次在VIP群里，有人分享“上海劣质学生餐”的新闻，而且有打抱不平的意思，我抓紧制止了这个行为。在我看来，即使他们吃屎，跟我一毛钱的关系都没有，我的注意力、核心精力都放在赚钱上，没有闲心去关注别人的伙食。再说了，你以为你整天忧国忧民、为这个发声、为那个发声，他们就会感谢你？错了。如果你真的去上海声援那些孩子，要求为他们讨回公道，那些孩子的家长可能会跟你说：“你这个臭外的，不要在我们这里瞎捣乱。”类似的，过去几年总有人问我支持大鸿还是乌鸦，我说我谁都不支持，我只管好自己的生活。有些人就拎不清，非要支援这个、支援那个，甚至亲自过去给他们加油助威。但是呢，不论是大鹅还是乌鸦，他们对特定的群体都是歧视、蔑视的。你以为自己站在了正义的一方，实际上一旦你真的过去了，只会遭受他们的漫骂和围打。我这个人是非常冷血的，不会介入任何人的因果。不要说孩子被侵略了，即使父母往火坑里跳，我都不管，因为那是他们的宿命。如果你盲目介入别人的因果，那么最终会被拖进泥潭、拖进粪坑。

## 4. 财务规划永远第一位
对于个人来说，99%的烦恼都能用金钱解决，在金钱面前，感情、人脉等都不值。所以聪明的人一定会财务规划放在第一位。比如，永远不要超消费，只要手机还可以坚决不换。另外，如果你想让自己有掌控感，最重要的不是交人，而是开发几个收入渠道。首先，它每个月都能给我稳定的现金流，少则七千，多则两万。之前我说过一个观点，不管是发展副业还是投资理财，什么时候应该引起重视？就是当你开始更新认知，化解负面情绪。大部分人无聊的时候，都会选择信息输入，比如刷短视频、看书……花个小时写篇文章比花五个个小时读完本书更有能量。写作绝对是一种精神疗愈，是一种对心灵的照顾。

## 5. 责任划分必须清晰
要么遗传，要么受熏陶。如果你的牙齿不好、眼睛不好、肠胃不好，那么责任全在父母身上，因为父母督孩子少吃甜的、按时刷牙、看电视、规律饮食。如果一个孩子在25岁的时候就已经掉了颗大牙、高度近视、肠胃总有问题，那么他的要负主要责任。举个例子，上次在知识星球里有个小伙伴问我：怎么规划才算对孩子负责？我说：只要给他规划一条不需要高考的路线（比如海外留学），他在3-18岁之间的压力比同龄人减少80%。这就是送孩子最大的礼物。总之，如果你在30岁之前感情总是不顺、身体总是出问题，你就怪父母、怪原生家庭就行了。但是一旦过了30岁，就要对自己的人生负起100%的责任，因为你已经独立了，你要对自己的每一个决定负责。这时候如果你还总是怪原生家庭、怪环境，那就是你的问题了。你完全可以选择糟烂的原生家庭做出切割，完全可以选择离开碱地，去更加文明、更加富饶的土地上生活。重要的是你可以大步地离开有毒的人、有毒的关系，像死狗一样把它们甩在身后，轻装上阵。
