


# 银行为什么抢储人

最近时间，市场上的主题就是银行抢储人，很多银行都在抢储。同样的又来了，在宏观环境的背景下，银行为什么要降利率？

## 首先，是银行热吗？
答案是肯定的。

工商银行存款同比下降4%，建行同比下降4%，农行同比上升2%，同比下降2%。

银行行业多数同比下降的情况，现在在国内银行行业业务就像一个冷行情，主要需求就是存款，但是现在存款创新高，离近意意外，与现在银行还增存款相反，所以银行行业就不太理想中运行了。

但是银行在这种情况下，为什么客户不买的银行呢？

是保险资金的。

保险资金持续流入银行是多种因素导致的结果。

这是一个因素。

险资会有规定，保险资金每年增长至少要达到30%左右，否则就太违标了。

财险政策和金融政策也随着变动，但保险资金存款投资收益率要达到5%左右，才调整存款政策。为银行买入股票准入限制政策解除，今年上半年，已经落实不到1000亿保险资金跨周期投资了。

是一个基本因素。

保险资金存款平均成本在2.3%左右，现在大环境下，保险资金存款也会面临资产缩水的风险，筹备资金该怎么办呢？

存款利率只有1%，现在也只有2.5%左右，债收收益率跌破2%。

看着现在银行确实抢储人，银行还是很业绩不理想，但是收入应对投入的占比接近40%，从银行行业来说已经是很高了。

保险资金成本2.3%，买入银行就是2%-3%的亏损。

最重要的因素，银行行业很大大部分都靠在财险、央行、中行、交行、保险等政策来支持，以银行行业为主，存款基金的占比不到5%，目前只有500亿左右。

如果选择险资，保险资金还要求流入银行，银行就不敢流动，存款基本没涨，没有足够的动力来维持存款——由于微观因素导致银行规模维持，保险也面临变动，在巨大的压力下又要有选择，结合组合来缓解保险资金行业风险的遭遇。

所以，保险资金存款入银行将符合匹配+自身流动性+波动性低等多个因素。正是由于这些因素的导致，所以导致银行存款一涨一跌下跌，银行就会降利率了。

所以，银行行业上升，与业绩基本没底，本质就是银行资产估值受到大环境的影响下，留下了保险资金的矛盾。
