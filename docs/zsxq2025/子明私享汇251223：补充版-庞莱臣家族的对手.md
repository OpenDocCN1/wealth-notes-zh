


# 废之臣家族的对手
发布时间：2025年12月22日

一、废之臣族的画并不是真心的捐赠，而是在50年代公有化时代下，超出自身力量无法继续持有，面对私合营，不得不破财平安，《一代英雄》被胡世岩不断压榨，《潜伏》中被吴忠不断压榨的，逸，在当代过程中，不断低价让资产和捐赠贾亨、王健林也是如此。

![](img/78dd7463f7610a9a8731ffcd7739a7_0.png)

二、南京博物馆就是之前的白手套，就像《一代英雄》中的沙淮，《潜伏》中的余则，作为执行机构，他们本身并没有贪的意愿或者胆量，但是有很多领导会像吴敏一样，打着赏的名义借走后不归，甚至将藏品像“玉座金佛”那样用仿座与不存在的方式从账中抽走，让成为私人财产。领导们背后势力之强大，自然能压得不起波澜。

![](img/78dd7463f7610a9a8731ffcd7739a7_1.png)

三、全球收藏界顶级知名度的浙江富豪家族打了几十年的宁波，都不敢于跟官家硬碰硬，硬得天下皆知，不是因为他们突然理了，而是因为《大明王朝十五六》中的那一句：“在浙江，你能做些事，是因为你背后有人要撑腰。”当年掠夺富豪家的势力，在最近一轮房的过程中惨败，本着敌人的敌人就是朋友，富豪家族就成了海威，陆匪与南京博物馆这些白手也就肮脏了。

洪波能够做这些各方弈的过程中，没有谁是白莲花，这次事件不过是一越了半多个世纪的权力与资本置换的黑金政治史的一角。

## 独家 | 南京博物馆收藏明代沈英《江南春》为何现身拍卖市场？
来源：澎新闻 2025年12月17日

废之臣（1864—1949）是中国现代收藏家，其“虚斋”收藏的宋画以质量精湛、体系完整著称。

上世纪50年代，废之臣曾向南京博物馆等多家国有博物馆捐赠了大量古代书画。

1959年，废之臣之孙广增和向南京博物馆无偿捐赠废之臣“虚斋旧藏画”137件（套）。

2024年10月份，广增和之女叔令就诉137件（套）含明代沈英《江南春》图卷藏品是否得到妥善保管、流向等有关情况，函致南京博物院，要求确定所有文物现状。当时南京博对于叔令的要求，未获得任何回复。叔令对南京博物院提起诉讼。

2025年6月28日，叔令依据法院的《民事调解书》，前往南京核验藏品原件，发现包括沈英《江南春》图卷在内五件古画无法看到。

## 馆藏明代画拍卖市场？南京博物馆回应
来源：央视新闻 2025年12月17日

南京博物馆发布情况说明：2024年1月以来，南京博物馆收到叔令关于明代沈英《江南春》图卷出现在拍卖市场的诉讼。

关于沈英《江南春》图卷，南京博物馆回应：馆藏明代画拍卖市场不存在。
