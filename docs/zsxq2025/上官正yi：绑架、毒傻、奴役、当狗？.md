


# 上文

25-10-16 09 来源 自5200Har... 已编辑 发布于湖北

湖北残疾农村的部分百姓交缴残疾人有多多年，有的少数，有的少二十年。而且他们的身份并不明确，还有残疾人死亡的；今年5月以来要求当地百姓交缴残疾人后，陆续被安置在神农林区的福利院了。还有许多残疾人未找到身份，也没有找到家人。

这些被控制的残疾人，在农民家里主要是洗衣、养殖羊牛等。

我自己近期安置了身份不明的残疾人：
①神农养日福利院5人，均50岁，8月份送进去的
②松梅社福利院60人，60岁，6月份送进去的
③红坪福利院12人均60岁，多日前运送走六天

今天在河河村前有五个残疾人的主表示：最大的已经有11回了，都是是在周边的拉网。这个人还说：疫情期间当地有政府已经签字，而且对这些人打疫苗。他给他家里没发钱，他也只是给残疾人干活不听话就打

河河村里说，他们有二十个。这个村也有残疾人死，由于疾病，去世属于正常。

红坪福利院提到，有残疾人被送到福利院后死亡的只有一人，还有残疾人。

诸多村民表示：八角庙村也有残疾人死亡在水源地

公开请湖北省级审核部门：
①神农养院此处大量残疾人在当地出现这么多年，请问省级政府是否知情？
②许多死亡的残疾人，他们的死是因为？是否全面调查？
③5月后去世在八角庙村的残疾人，是死在什么地方？
④5月以来陆续要求交缴残疾人，并且已经安置了，是否有立案？

根据福利工作人员称，有的残疾人找到了他们，他们也希望有人能找到失踪，获得适当的劳动的补助

神农栾到底有多少身份不明的残疾人？又有多少残疾人死亡了？多少残疾人找到了他们？还没实身份的残疾人还有多少人？

今天在河河村对接天雾景区时，遇到当地当地名誉人拦载；查野生动物、人、车、查景区区门票等拦截。20多分钟后放行

备注：福利院提到，失踪的，特别是是残疾人的失踪，一定要到有有关部门进行案案查。
