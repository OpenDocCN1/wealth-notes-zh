


# 猫哥星球251224: 互联网的捷径

后台经常有人提问，孩子大学毕业怎么找工作，特别是家里没有资源没有人脉的情况下，感到非常迷茫。

这里，我就系统教大家一讲，在互联网时代绝对是有捷径的，前提是你学会如何利用互联网这个平台。

在讲方法论之前，先给大家讲两个案例。

案例一。

身边一个朋友的儿子去年大学毕业，居然直接就进了某大厂云业务团队，我大概了解一下这个大厂的情况，云业务是这个大厂目前最好的业务，也是待遇最高的部门，因为待遇高，所以基本不对外招聘，那么朋友的儿子是怎么搞到这个工作机会的呢？

说出来像一钱不值，朋友儿子在大学阶段就是很活跃的性格，经常混活跃软件论坛，并且非常积极，包括发言，提出问题，提出解决解决方案等等，然后就与某个网友混了，别人对他也认可，这个网友就是某大厂云业务部门的一个小主管，就这样这个小子的推荐的，朋友儿子大学毕业就进入这个部门，第一年薪资就是60万，今年已经到80万了，

明年不意外应该过百万了。

再来一个。

雷军是怎么发迹的？

早年雷军创业失败后，在家里没事就混专的软件论坛，然后给金山提问，并且提出解决问题方案，然后就获得金山老板的赏识，诚意邀请雷军加入金山，金山就是雷军发迹的起点。

从这两个个人案例可以看出，在互联网时代想要走捷径获得机遇很简单，就是要用好互联网的平台，要在平台上充分展示自己的热情与才干，然后就可以等待女神的眷顾了。

所以，对于现在的年轻人如何找工作机会完全可以参考上述两个案例，当然具体方法有所区别，下面是干货，大家一定要认真阅读：

首先选择合适的平台注册自己的社交账号，推荐可以选择抖音、视频号、知乎、小红书（这个平台侧重于女性，男性就没有必要了），微博学习可以，公众号门槛有点高自己酌情考虑。

注册账号之后，就把这个账号当作工作账号来养，不要当个人账号，为何？

每一个平台都有自己的算法模型，这个算法模型会根据你这个账号的情况放到特定的流量池，这个账号很关键。

如果是工作账号，那么在养养号的时期一定要谨慎使用，一般只关注与自己专业者职业生涯兴趣相关的账号与内容，持续一段时间，平台的算法模型会自动识别你账号的特征，将这个账号推荐给特定的流量池。

在养号的过程中一定要注意只浏览与专业与工作相关的内容，遇到平台推送的其他内容一律划走——即便这些内容可能是你感兴趣的（比美食美女等等）也要划走，因为一旦你停止观看，就会导致这个账号的流量池出现混乱。

一定要确保这个账号所属的流量池非常准确，这样未来才有可能让你的内容在这个领域的人群刷到。

养一周左右就可以发布内容了。

那么发布什么内容呢？

如果已经参加工作就发布自己对工作的感想、总结、工作方法的分享等等；如果仅仅是大学毕业生（或者在读学生）同样就分享自己对专业的学习体会与感情、想法等。

尽量做到言之有物，思维清晰。

如果发送几期内容之后就不知道发什么内容，互联网这么大，你花点点心一定能找到灵感，大不了就借嘛。

有干货就发干货，没有干货就立人设，包括不限于热情、精力充足、自律（健身打卡）等等。

在平台的个人简介一定要加上：希望与行业同业的优秀人才交流，附上自己的联系方式。

这个账号做上一段时间，可能是几个月可能是一年，这就是你最好的数字简历，相比传统投送简历的方式，这个数字简历更丰富立体更能打动别人。

这个方法不仅适用于年轻人找工作，同样适用于在职场不如如意打算换一个更好工作的人群——如果自己不想真人出镜被同事看到，就用卡通头像替代，AI还可以变声处理。

按照这个办法去做，因为你的账号被投到流量池，那么看着你的数字简历在累一段时间之后可能被几千万的同业（同专业）群体看到，也就是说你找到好工作的机会相对传统的模式互联网放大了百倍千倍。

这就是捷径，这就是你可以在同等资历下获得更多职场溢价的方法论。光这个方法论我我觉得我就得对不起你们付出一张知识星球的门票价了。
