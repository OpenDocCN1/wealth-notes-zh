# 大事主义（事大维主义）

来源：整理维基百科

大事主义是东亚一些小国主张的应该服从大来保存自身的一种意识形态，与朝贡秩序相关，通常出现在属邦与宗主国家之间。

在朝鲜末期（十九世纪末），主张忠清朝、反对对日本干预的人被称为“事大党”。大事主义的形成与传统的华夏秩序有着紧密的关系。

“大事主义”这一专词是在二十世纪初，由韩国民族主义者发明的。其中“事大”一词由来已久，语出《孟子·梁惠王下”，“惟智者为能以小事大事”。
