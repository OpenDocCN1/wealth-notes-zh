


# 迎接超级企业的垄断时代

发布时间：2025年8月7日

中美都在加速进入一个企业崛起的时代，就像上次百年未有之大大变局那样，会崛起一批垄断多个上下领域的超级企业，如当年日本的三菱和三井，美国的克拉克菲尔和卡内基，德国的克虏伯和西门子。如果没有一批国际级的超级企业，国家就会在这一轮大变局中被其他国家踩在脚下。

![](img/f0def942fa4d1a1ad03186a84ed3dff9_0_0.png)

这些超级企业会在全国统一大市场的建设下，从煤炭到石油，从稀土矿到锂矿，从铀矿到发电，从铁路到港口，从货运到航运，从快速到网络钓车，从数据到算法，从隐私到信用，从信贷到大金融，将触手伸向新一代新生产力的上下游。这些准备开启新时代的垄断企业不惜代价的支持特朗普，放对垄断企业的监管。
