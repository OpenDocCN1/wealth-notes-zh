


# 米联储见 251217——锦囊养之怀袖（玛总不好.....)

你好，我是米横。

今天下午，A股突然反抽，一跃而起，修复了昨天的大跌，最近A股回来折腾，上串下跳，像极了想要搞死中国的美国，这个时候普通散户的操作难度是非常大的，我其实已经封仓看不了，留了2 仓位，其余的就放在随便量化庄家们折腾了，不看他们表演就是了。

昨天，中央财办发布，预计全年经济增长5%左右，继续位居世界主要经济体前列，经济总量有望达到140万亿元左右。就业总体稳定，外贸强劲增长、出口多元化成效明显。特别提到，供应劲而需求弱的矛盾突出，重点领域风险隐藏较，大多是发展国家转型中的问题，绕不过，躲不过，相信只要努力，明年将继续实施积极的财政政策，包括保持必要的财政赤字、债务总规模和支出总量，用好财政政策空间，应对未来风险留有余地，确保财政可持续。会实施适宽松的货币政策，将促进经济稳定增长、物价合理回升为货币政策的重要考量，保持社会融资环境适宽松，灵活运用多种货币政策工具，帮助降准减息等。中央财办估计，明年人口、物流、信息流、资金保持较快增长，投资和消费增速有望恢复，产业转型升级加力，科技和产业创新进入成果集中爆发阶段，经济发展前景十分明朗。

最近海南全岛封岛，知道海南封岛的概念是22年提出的，当时还是疫情当中，中央决策的说法是2025年前实现海南封岛，今年7月公布12月8日封岛，这三年经过多少事情，言出法随，三年前说的，三年后必落实，与海南封岛落地的各种基础设施准备和制度准备，人员准备，政策准备全部到位，所以TG说要统一就一定会统一，说要把消费作为战略工程就一定会执行到位，你信得信，你不相信实会信你，就这么回事。

上周的经济工作会议强调“内需为主”，强调加大周期和跨周期调节力度”，与今年10月的“十五五规划”提及的“强化逆周期和跨周期调节”表态相近。“逆周期”的说法早去年政治局会议已提出，主要侧重短期，“跨周期”意味着中长期的战略规划。

会议以“八个坚持”括重点工作，分别是内需为主、创新驱动、改革攻坚、对外开放、协调发展、“双破”引领、民生为大、化解领域风险，与去年提出的九个重点工作颇多的共同之处，政策变动不大。IMF总裁古尔基近日直言，中国经济体量太大，无法通过出口带动增长，应该加快国内增长，对内地经济长远发展更有利，全球经济亦可受。说白了，人家也看不下去，按照中国这个低价向全球营销的趋势发展下去，世界经济估计都要危险了，所以让中国尽快通胀起来已经是世界经济发展的首要任务。

最近一次局会和一次经济工作会议还有一个信息引起外界关注，就是一位局长已经两次缺席会议，很长时间没有露面了。M总今年7月突然被宣布不再任山西省一哥之后，关于他的去处坊间有很多传闻，迟迟没有落地，当时官方通称其“另有任用”，也后以局委身份，如常参加高层会议或活动，比9月3日的天安门阅兵、10月下旬的二十届中全会。他的“任用”始终没有公布，成为局委中唯一没有具体实权的存在，这本身就很不正常。

11月28日，局进行第23次集体学习，M总不在其中。两天后，与其直接共事了三年的下级、西北省省常务副主席陈伟杰涉嫌严重违法被查调查，关于M的处处不妙的传言明显密集起来。然后上周继续缺席局经济工作会议，进一步证明了吕事的。老爷文集团和对应的是，中纪书记李书11月28日也没有参加学习并引起，但李在本周中央经济工作会议公开亮相，扫除了谣言。而M从去年到现在确实是每处疑惑了。

今年66岁、曾有“航天少帅”称之的M总祖籍山东郓城，生于黑龙江鸭山，是矿工家庭，兄弟数人，父亲和两个哥都是矿工，一个弟弟经商。M天资聪颖，幸运在高中毕业时赶上中国恢复高考制度，进了阜新矿业学院，之后到天津大学读力学系一般力学专业硕士，接着再考取哈尔滨大学博士研究生，成了中国国务院学术委员会发现国家制度的第一批博士生。毕业后留校任教，也在这里连续晋升为讲师、教授；34岁成为哈尔滨最大年轻的导师，当上上海大学。同年，离开校出任中国空间技术研究院（五院），领军中国研制的“国家队”，不久后调到中国航天集团，历任副总经理、总经理。M曾现场组织了多次航天发射，成功发射了25颗卫星，还指挥了神舟八号、神舟九号、神舟十号。妻子是本科同班的同学，在研究生期间结婚。短短13年转入地方，历任广东省副书记、深圳市书记、广东省长，M提前拿到了新届入场券。以来，M的结局是一个总理，最大的限制是没想到任新疆一哥。

M的本科同班的同学，广东最近今年有点埋干部，上一个莫名其妙的消失在名单中被边缘化了，有一个在重庆又留了，还有一个就走人了，广东迹之后成为埋人的地方。在M出现异常之时，李在纪委的位子上，这就免得说其中的门道了，无论是负责调查，还是被牵连，都可能导致短期“消失”。

M被调离山西后，不少部门接连。1月1日，政协副主席Z被查；1月10日，省市委书记、政法委书记马志杰被查；1月30日，副主席陈伟杰被查。今年8日的局会议也与过去两年12月的局会有不同，过去两年12月的局会都要主持召开局常委会会议，听取中纪委国家监委当年工作情况和明年准备汇报的状况。但今年12月的政治局常委会会议以前，没有听取中纪委国家监察的汇报。其二，去年两年的政治局会议的议题，除分析研究经济工作外，还研究部署明年反腐工作，并确定来年1月中纪委召开的日期。但今年12月的政治局会议的议题中，没有提及反腐，没有听取中纪委国家监察的汇报，没有规定2026年1月中纪委会召开的日期。今年12月的政治局会议上，纪委李Y会议中的主角之一。但是，与其有关的议程被取消了。11月28日的局会，主要议题是审议“关于十届中央巡视份情况的综合报告”，李是中央巡视工作领导小组组长。按常规应该出席但缺席了。这并不是正常表现。

纪委，公安系统最近有些不寻常之处，11月初，联邦调查局局长帕特尔访问北京，就太尼运输和执法合作问题，与中共磋商。帕特尔在京会见的中方代表不是公安部部长龚家禁毒委员会主任，而是公安部排名第三的副部长。

至于出事可能的原因，说是受近两年军工腐败。落马后M跟着“失踪”，意味着政治局人员又了一个。大佬集团这两年来，在猛烈的反腐与人事风暴中，高层人事异常频繁，军委从七人减少到四人，随着换届日子接近，高层人事还有变动。团成立初就少了一个，如今又再少两人，仅剩2人了。
