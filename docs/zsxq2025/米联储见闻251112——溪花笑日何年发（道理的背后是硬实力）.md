


# 米联储闽 251112——溪花笑日何年
## (道理的却是硬实力)

你好，我是米堵。

昨天，关于中国外交首脑的点评，有读者反馈认为米堵态度过于激烈，相比过去的以前和为贵，现在有点心向天起。是不是因为中国进入三航母时代，思维方式就开始出现变化。客观的讲，这是必然，所谓此一时彼一时，当年年初被人炸掉的大使馆只能抓一把电话，如今外交可以指着对方元首唤你试试要砍你了，这背后却是国力的变化。美国外交横世界50年，靠什么？靠道理吗？并不是靠的是两国日本的原子弹，更是美国在太平洋战争中表现出来的接近恐怖的跨域实战能力。这个世界没有靠道理就能办成的事，每个道理背后都必须确定对方愿意听道理的硬实力。不是川普的关税，还是荷兰政府对美国半体的无力抗衡，这些都不是道理能解决的问题，解决问题的只有实力，实力，还是实力。能让对手松口退让的，除了打它，另外一条也别法。

薛奎在删掉了首音言后，发了另一推文，配图是一张中国三航母母片，薛奎的意思也很明确，日本要学会睁眼看看，现在的中国已经不是日本可以随便得到的中国。从辽宁舰到山东舰再到福建舰，中国想让日本包括美国明白的是，这不是结束，而是开始，中国的海上军事力量将会出现几次增长，而且这个过程有多长取决于世界的动荡程度和时间长度。可以说，中美越挑，中国海军壮大的理由越坚定，发展的速度越猛，中国海军到底发展到什么地步，不仅取决于自己的意志，也对于对手挑衅的程度，这方面，中国实际上已经在喊出自己的心声：都是你们逼出来的。

中国拥有首艘航母是13年前的事，从零到一，再到拥有世界领先的电磁弹射技术航母，仅用13 年，这个速度是相当惊人于可怕的，13 年就出现现代军备体系的庞然大物，这背后的系统工程管理能力和工业体系才是美国最忌惮的实力。可以说，福建舰的成功与成就是中国军事体系跨越式发展的体现，也是国家综合实力提升的鲜明注脚。中国向航母大国的征程，绝不简单的军事装备升级，是一场涵盖战略转型、技术自强与文明自觉的宏大叙事，以及塑造新型国际关系的物质基础，也是构建以中国价值为主的新型文明的定海神针。

80年代，中国有的知识分子深挖中华文明劣根性的记录《河殇》，将中国的问题归于文明的劣根性，黄色、狭隘、古老、缺乏活力，从根子上否定了中华文明现代化的可能性，要发展全面抛弃的所有传统，拥抱西方文明为主的海洋文明，学习日本甚至新加坡这种不像的国家都成了当时知识分子最热的研究方向。大佬文集这些知识分子似乎忘记了，中国也有1.8万公里大陆海岸，300平方公里主辖海域，中国从来不是一个完全的内陆国家，在大明就已经拥有全球最强船队远航，暂时的闭国只是历史发展过程中的插曲，也许在后悔不该提醒中国，海洋文明原来还有这么多既得利益，呛着中国一直做个内陆国家，就像印度一样不香吗？

中国航母之路的开启是在回头看似乎是故事会，过程跌宕起伏，情节错综复杂，这不是一个人或者几个人完成的传奇，而是一个民族内部志士对这个国家必须坚持不息之恒的坚持和守护。大佬文集圈舰航的前身瓦良格曾经历坎坷宏大湾，关于这段历史，B站有很多讲解视频，大家可以多方面的了解，这艘未完工的母舰成为中国航母事业的启蒙教材，成为开启中国强大大海军时代的引擎，有许多至今默默无闻不为人知的英雄。另一方面，面对一个半成品，中国工程师和技术人员通过对它的深入研究、改进和建设，几乎是完全靠自学逐步掌握了大型水母舰的设计、制造和系统工程管理能力。这是一个引进、消化、吸收、创新的经典案例，实际上，对于这个结果大家不必惊讶，从原子弹子航天技术，到高铁到大飞机再到航母，中国工程师几乎都是靠这种野路一代前辈后继推动中国工业领先一个又一个领域，这几乎为了在中国高端领域谨慎而高效的独门秘籍，未来还将复刻在光刻机、高端芯片、精密仪器等领域，更将转化为中国主动创新领域。

## 全球走向科技新的核心竞争力。

2012年，辽宁舰正式入列，中国海军迎来了航母时代，7年后，山东舰横出世，标志着中国完全掌握了中型常规动力航母的自主设计和建造能力。从借鉴改造到自主创新，山东舰在辽宁舰的基础上进行了多项优化升级，体现了中国船舶业的快速成长和体系化突破。

6年后福建舰的入列，是一个里程碑事件，平直通长飞行甲板、电磁弹射装置等关键技术使中国航母技术一步跨入世界领先，与美国最先进的航母技术差距大幅缩小。随着技术成熟，规模发展，第四艘第五艘也在路上了。

纵视世界航母发展史，航母诞生之日起，便与力量投射、全球干预相权连。传统海权国，如西班牙、荷兰、英国乃至美国，其海军力量壮大随着领土扩张、范围争夺。航母作为现代海权的象征，外交意义大于实战意义，可以说，没有航母，就没有外交桌上的权力，没有航母，你的政治逻辑从防守变为进攻型的推进器。

载机数量方面，福建舰预计搭载70-80架各型战斗机，这个数字与美国超级航母基本相当。加上先进的起降效率，福建舰航空能力已经达到世界领先水平。即使如此，美军拥有近百年的航母经验、战术、全球部署，这些是短时间内难以赶的。

时间上看，从2012年以来，美国开始了全面围亚洲战略，中国的意图与发展随着航母数量的增加逐渐紧张。

当然，我们坚信中国是爱和平的国家，航母目的并非追求全球霸权或武力扩张，而是为了有效维护自身利益，以此为基石。世界上，弱肉强食，很多国家没有航母，那是弱。

长期以来，中国一直是全球关键矿产和金属市场的控制者。中国拥有丰富的国内储量，并且在非洲拥有大量的海外供应。约翰·普普数据显示，2023年美国在非洲投资额为78亿美元，而中国的投资额为XX亿美元。去年，旺达矿业（Trinity Metals）从美国国际公司获得了XX万美元拨款，用于开发当地拥有的三座矿山。未来，美国和中国在非洲大陆的竞争可能会加剧。

世界如果是一盘大棋，没有任何一个国家会轻易下棋，但最后会成为赢家。在这方面，中国一直是在输出传奇，希望还能继续下去。祝各位晚安。
