


# 南南资讯（新）

1. 现在不要教孩子学英文单词，也不要背单词，也不要背单词。在他之前一个单词也不要教。不要带他去学任何英语，如果教了孩子学英语，就会被孩子教了，就完了。

2. 先给他上课，让他听听、跟读、发发音。让他听听英语单词，听听最喜欢的英文单词。每个孩子每天听听，天天听，每天听听英语单词，不要背。

3. 让他看英文视频，多看，不要太多。多看就能从耳朵听到嘴巴，会有比较多的从听听到说出几句英文的转化。

我的孩子学英语就是这样的：从一年半到半年年半，共学了66天，每天听英文左右。没有从耳朵听到头部，会有比较多的从听听到说出几句英文的。

2. 孩子没事没事放放英文音乐，因为他会去听英文的。我不让他背单词。我每天放放英文50分钟，每天在早上上学前听，在开车时听，在车上也听。

3. 多看英文视频就好了，几年以后就会看懂英文，感兴趣了。学了英语以后会发现自己看懂英文了，不用翻译了。

4. 孩子不需要背单词。英语是国外的语言，孩子可以教他。如果是可以，就让他背单词；如果是单词，就让他背单词就行。根据孩子的反抗性可能不行。

学英文，语感和能力是最重要的。英语是不需要背单词的越好，是不会背单词就行。

背单词确实不重要，这种事儿到孩子到十一岁以后也不用了，单词是靠记忆的。

但是，我要在孩子的社会融入和英语知识之间找一个平衡。如果你教太多，让孩子自己学英语、同学都合学，是不会影响他的社会融入的，这是一个需要考虑的。

有些孩子可能没有基础，不在学校的评价体系。有些孩子很大。

在中国，多说英语的孩子并不会变差，也不会影响学习的学术知识。他们只能把英语当成成绩去，学校只会按照这个老师的要求去。这里很多人学了一辈子英语，见到大学毕业了还没达到能够实际应用能力的高水平。

学习英语需要语感和强化。最好几年以后所有课程都是英文，这样就能掌握了。这里是很多人让孩子读英语学校的。

以中国的情况，你可以在学英语的时候，其他的课程都先放下，集中时间，每天听英文读书。这样就会让他觉得每天在看英文书很有趣了。

中文是不需要的，在中国每天都在说中文，每天听中文，实际上每天十个小时都在学校学中文，所以我我觉得我的母语境教育简直是神奇的。
