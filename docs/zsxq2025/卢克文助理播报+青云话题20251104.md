


# 【助理播报】

国际：

1. 据英国广播公司(BBC)3日报道，由于美国联邦政府的“停摆”，超过4200万美国人的食品券援助受到威胁。有法官裁定，美国农业部需要动用52.5亿美元的应急资金，支付部分食品券款项。

2. 欧盟3日宣布向拉美和加勒比地区提供2150万欧元人道主义援助，应对委内瑞拉和海地日益严峻的人道主义形势。

3. 雅加达11月3日电，印度尼西亚首架A400M多用运输机于3日抵达雅加达哈利姆军基地，正式列装印尼空军。

4. 11月3日，德国经济和能源部长表示，从明年1月，德国能源密集型产业将可以通过国家补贴电价减轻部分成本，德国将为这些产业提供“工业电价格”。

5. 当地时间11月3日晚，伊拉克总理苏达尼表示，极端组织对伊拉克的威胁已显著降低，以击败极端组织“伊斯兰国”为任务的国际联盟计划在2026年9月前从伊拉克撤出。

6. 11月3日，中老双方首条以公交模式运营的国际客线路开通，线路全长约16公里，以中磨犀火车站、老挝磨丁火车站为起点，中途可在两国口岸停员。

国内：

7. 近日，中国人民银行与韩国银行签双边本币互换协议，互换规模为4000亿元人民币/70万亿韩元，协议有效期五年，经双方同意可以展期。

8. 11月3日，位于浙江宁波的北仑电厂9机组顺利投产。自此，北仑电厂成为我国装机规模最大的火力发电厂，其发电能力稳居全国火电之首。
