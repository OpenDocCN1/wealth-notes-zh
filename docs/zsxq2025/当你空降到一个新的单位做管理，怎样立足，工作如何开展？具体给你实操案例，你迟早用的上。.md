


# 当你来到一个新的公司后，应该如何工作？有什么建议？并举例说明。

很多人去新公司后，停留的时间太长，等半年后就换行业，这样对自己不利。

大公司机会很多，你想去大公司上班就去，换行业也跟跳槽公司一样。

这并不是你最好的选择，多尝试几个机会比较好。

介绍一下我的几点：

- 1. 对上级怎么做？
- 2. 对领导怎么做？
- 3. 同事怎么做？
- 4. 对自己怎么做？防止被开除

## 第一，优先上线。

最重要的工作就是上级，一个上线关系好，工作就轻松了。

作为优先上线，只有老板满意，你的工作才轻松，因为你就是和老板在一起的人。

## 第二，是业务。

项目业务要多听，多问。

请记住，刚进新公司后，多向同事请教，业务上手很快的，业务完全在靠自己摸索。

但是，虽然同事可以教你，但并不负责你的失错，业务的还是老板的。

先就做好老板的业务，老板满意的项目（老板重视的项目就行），新项目就接一个项目，多听、多问。

## 第三，是同事。

最好是和同事关系处好，同事们很多时候能帮助你。

即使你没有丰富的人脉，也可以建立的人脉，建立自己的人脉。

也可以和同事一起业务，以后会有帮助。

但是，同事也是需要帮助的，不要总是去麻烦同事。

作为新人，你要多给同事提供帮助，建立好关系对你是有好处的。

比如，和老板关系好，建立一个上线关系，老板就不可能开除你了。

如果你让老板满意了，老板就会保你，这样你有机会了。

## 第四，对自己怎么做？

首先不要急着表现，新人要有足够的耐心。把第一步做完给老板汇报。第一步可能是原型，是个草稿，都行。

这是业绩的第一展示。

然后第二步。步子一定要迈小的。这意味着每隔两三天，老板都能看到你负责项目的进步。

即使最后没做成，也会给老板一个感觉，你在持续推进了这个项目且一切都在他的掌控之内。

当然，如果有业绩，最后也没必要追求100分的业绩，做到80分就可以。做的太好了，平级那边可能就会出点事了，哼怨的、摘桃子的，就可能就会出来。

我来访就是因为新项目的漂亮，被公司副总看不惯，开始内部斗争。坚持了一年走了。这里有一个背景，就是他是公司老板请来的，但是公司副总当时不太认可。所以后边就出了一些状况。

80分，意味着项目有些瑕疵破绽。这是要卖的破。

最后，到这一步，老板信任关系建立，项目有个小成，团队有自己的人，有可以干活的人。就算有个稳定一点的立足点。
