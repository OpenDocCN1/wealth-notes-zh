


# 灵哥星球 250423 问答精华汇总

灵哥：

美团和京东，网上各类分析的都有，其中不看京东的一个核心分析是美团的外卖利润率很低，大概3个点点不到。言下之意，这不是什么好生意，所以京东没戏之类的。

寡头暴利，怎么可能利润只有3%?

从创新战略角度，建议大家看一看，哈佛教授 Clayton Christensen 的《创新者窘境》。即大公司为何无法跟进小公司的创新，是因为小公司方案更便宜、更简单、更容易。如果大公司跟进，相当于立刻刻削减自己的利润，因此大公司总是容易在创新时忽视创新理论，然后持续被颠覆。

归根到底，是利益集团不愿意自己颠覆自己。这是过去这些年，科技企业会持续被颠覆的原因。无论是柯达，还是 Cisco 等，有太多案例。

腾讯上市之后，高层团队早就被投行帮持，已经失去了真正的产品能力，所有十年前全互联网行业叫腾讯“狗日的”，因为当时腾讯全面抄各种创业小公司。

移动互联网崛起，腾讯当时做即时通信的内部团队有好几拨，包括 QQ 自己的团队。但当时的内部阻力很大，关键就是微信会坏掉 QQ 的命。

还好，腾讯最后一张王牌，马化让张小龙只在广州呆着，如果没有广州的产品团队，腾讯可能更早就被颠覆。马化要求张小龙只跟我汇报，最终微信成功了，而且张小龙起初拒绝了腾讯内部各种利益集团试图侵入微信流量获利的企图，长时间把微信做成一个非常克制，对用户好友的平台。

从马化的角度，他一定是读过《创新者窘境》这本书的，这在当年的互联网圈是必读的一本书。所以与其让他，比如雷军的联合 QQ，如让自己颠覆自己。

腾讯的成功是一个罕见的案例，而且那时候还没有国家层面的互联网垄断，完全是靠自己对基业的理解做出的转变。

我在上周五上海和腾讯直播总监，后来的视频号专家小老师，还有感情大 V Vayawawa一起吃饭，大家都说如今为止，所有的平台，还是微信好。抖音现在平台上赚钱，普通商家，普通网红也都赚不到钱了。

这些互联网的历史和认知，如果你没有正确的理解和看待，你就不能理解京东做外卖的意义，网络上的分析基本上都是隔靴摇夷而已。

从垄断者角度，美团的漏洞是在垄断利润太高了。从战略角度，京东当前考虑的不是什么代替美团，他考虑的是用低价切入。

京东搞的类似价格战，他是可以亏钱的，但这个亏的钱是有限的，因为京东的外卖市场份额只有美团的百分之几。美团只要跟，比相同有效利给商家，那么美团的财务损失远大于京东。

我上面说了，除非战略垄断，自己革命的决心，正常的垄断头部，不会进入价格战。这就让后来可以有效的拆开一个口气，建立一个可防御的根据。

如果我们用革命战争的角度来看，为何井冈山能够开辟，是因为在革命初期，国民会非常自然的认为是那是井之尺而已，不值得大干戈，派系小队伍打打就可以。另外各个军阀谁都不想实力消耗，所以井冈基地才可能在缝隙中建立起来。

然后可能会有人问，那不是后来还是大举围剿，反围剿失败，不得不一万千里长征吗？是的，事实已经了，我们看到终其一生，蒋石都是依靠美国人，依靠江西财阀，也就是依靠外生的昂贵的组织模式。所以最终比靠内生的成本更廉的组织模式共产党打败了。

京东的所谓外卖，其实就是建立一个可防御的根据地。在战法上，在当前这个阶段就是对的。因为美团的模式中很大比例的是那些地下室商家，靠廉价的卫生桶入者获得订单流量，打造出配送体系，再在食堂商家中溢价变现。这是过去的互联网玩法，本质上和 QQ免费后卖 QQ秀增值具备获利是一样的。

挑战者按照美团的玩法就不可能了，但是京东的战法恰好是正确的选择，也可以充分证明东方的智慧，和指导创业几十年的哈佛教授的颠覆式理论，都是一致的。大家难免会问，那么之后怎么演变？

从京东角度，他完全可以耐心地看美团跟进。美团只要跟进，京东就可以持续布局，继续挤压美团的空间，比如增加商家。只要骑手减少，服务能力降低，速度下降，客户就会流失，内部结构就会撕裂。

那美团有没有可能？实际上很难。归根到底，美团玩的那套玩法是非常复杂的，即时零售所有的商业模式都是建立在这套体系上的。京东外卖和过去淘宝商家本质是一样的。

- 这种模式通过低价切入获取流量。
- 这种模式通过有限的亏损建立防御地。
- 这种模式通过规模效应形成闭环。
- 这种模式通过算法优化解决问题。

京东外卖现在有很多问题，包括骑手接单面临各类竞争。
- 这种模式通过渗透美团的份额，对于一个企业的打击是毁灭性的。
- 这种模式通过品牌认知重构，垄断是可以永恒的。
