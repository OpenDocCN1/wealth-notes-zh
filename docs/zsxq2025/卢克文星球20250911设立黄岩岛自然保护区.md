


# 设立黄岩岛自然保护区，要收拾菲律宾了？

文/卢克文工作室嘉宾 流离

9月10日，大阅兵兵刚过一周，国务院做出重大决定：批复自然资源部，同意新建黄岩岛国家级自然保护区。

注意这个“批复”，说明自然资源部早就申请了，只不过这一天才正式批复。

在93阅兵震撼世界后公布黄岩岛自然保护区，能从中解读出什么信息？猜测已久的黄岩岛环境，是否还要在未来的自然保护区进行？

# 01

黄岩岛作为自古以来的我国南海岛屿。曾于1997年开始被菲律宾侵取15年，直到2012年“黄岩岛事件”后，被我国收回实际控制权。然而菲律宾贼不死，屡次非法入侵黄岩岛海域，挑战我国主权。

针对菲律宾的举动，我国法律在2024年11月10日正式公布黄岩岛领海基线声明，划定了以黄岩岛为中心12海里的领海范围，24小时不间断巡逻，强化。

文有《联合国海洋公约》和国际法律依据，武有万吨海警船、055驱逐舰和歼16战机等先进武器做盾，双管齐下。

批准新建黄岩岛国家自然保护区，对菲律宾又是刚柔并济的一招。

相比之前普遍猜测的，对黄岩岛进行吹填作业，自然保护区这一手，确实出人意料。

很多朋友可能会喜忧参半——喜的国家加强了对黄岩岛的保护力度，终于要开发建设了，忧的是出于生态考虑，黄岩岛自然保护区可能不会进行大规模填海造陆，未来军事基地的建设和其规模可能会受影响。

但深入分析国家决策的各方面考量，就会发现其妙处。

在政治上，根据《中华人民共和国自然保护区条例》第三十一条规定，外国人若想进入国家级自然保护区，不仅需要保护区管理机构批准，还需要省级一级的环境保护、海洋、渔业等行政主管部门批准。

这意味着，管控力度的进一步加强。

另一方面，这样做在国际上不会太敏感，菲方难以指我方“以大欺小”，一个自然保护区，不是很正常？

《条例》给我方维护黄岩主权提供了更有力的内法依据，菲律宾若再越界，将不仅面临海警、解放军的强阻止，更将面临保护区管理机构、海南省各部门的依法追逐。而这些部门机构的执法人员，即使是开着军舰的士兵小伙，也没有什么不合理的吧？

## 为什么明知菲律宾不会老实守法，我们还要来这一手呢？

菲律宾一直试图立法为自己的侵略行为背书——2024年11月8日，菲总统小马科斯签署了所谓的“菲律宾海洋法”和“菲律宾群岛航道法”，将黄岩岛等岛礁非法纳入其“专属经济区”，并得到了美国支持。

这种出台“违法”的行为无疑是挑衅，而前文提到的我国正式公布黄岩岛海基线声明，就是我方的法律回击之一。此次将黄岩岛纳入我《自然保护条例》范围内，则是我方主动用法律武器，扩大执法覆盖面，可谓一转攻势。

黄岩岛海域丰富矿产资源和5亿石油储量，自然资源部公布的《2024年自然资源公报》显示，我国石油储量不过38.51亿，是举足轻重的海上大油田。

而且，黄岩岛海域是南海航道必经之地，对我国海上运输至关重要，决不能退让。

黄岩岛还是我国渔民祖祖相传的渔场，正如老渔民所言：“黄岩岛湖边的鱼群，认得中国渔船的引擎声”，岛心的大片浅水湖是良好避风港。这片盛产石斑鱼、鳗鱼和金枪鱼的大渔场，不仅过去养活了南海渔民，更是未来我国渔业发展的新引擎。

建立自然保护区，也有助于推进对这片重要经济区的保护和开发步伐。面对环境保护这杆大旗，一贯反华的西方也没法说我们的不是。

行政法规配合常态化巡航，做到了软硬两手维护主权。

回到保护区核心的自然问题上，中科院2024年报告指出，黄岩岛海域有36种珊瑚和472种海洋生物，珊瑚生态系统对环境变化非常敏感，且这里存在濒危物种礁、瑏屿。

而在2024年5-6月对黄岩岛生态系统调查后，国家对这片生态环境尚属健康的海域选择了更审慎的态度。虽然填海造陆可能引发生态危机，因此先建立自然保护区，再进行开发建设是更稳健的选择。

# 02

国务院批复的同一天，国家林草局也公布了黄岩岛国家级自然保护区概况——保护区面积3523.67公顷，位于呈腰三角形的黄岩岛环北东北南“长边”上，分为核心区和外围的实验区，主要保护对象为珊瑚生态系统。

黄岩岛总面积约15000公顷，实验区占了保护区的三分之，意味着黄岩岛大部分区域都是填海。这里科普一下核心区和实验区：

- 核心区：是保护对象集中地，未经批准禁止任何单位进入；
- 实验区：可以进行科研活动、教学实训、考察、旅游以及驯化野生动物繁殖，甚至生产、居住等有限开发。

为了维护保护区，《自然保护区条例》规定必须常驻人员，保证科研人员安全、工作生活以及后勤保障。然而黄岩岛上都是礁石、沙洲和潮汐浅滩，目前有灯塔、渔船避风港等简单设施，所以自然保护区搞不了填海，反而因为黄岩岛礁盘结构复杂，湖水浅，以往填海船不仅用来作业，也有破坏珊瑚生态系统的危险。

今年8月，我国自主研发的“通浚”轮、“广”轮成功下水容量达3500立方米，最深可挖20米，距离15~20公里，大大提升了填海效率。等到下半年，黄岩岛填海工程中，我们又开发了构建人工礁框架的沉箱由珊瑚骨料和特种水泥混合内嵌调节水体，使人工礁三个月内形成了生态系统。

对于黄岩岛填海工程来说，部分环境脆弱的海域不适合填海，使用沉箱+珊瑚种植技术，可以在兼顾维护主权和生态保护的同时填海作业。可见，此时建立黄岩岛国家级自然保护区，还是我国填海技术突破的结果。

# 03

说到一周前的93阅兵，正好再盘一下东南亚地区到场嘉宾，就能理解我们为什么会在阅兵前后在黄岩岛问题上出招。东盟十国中，印尼、马来西亚、越南、老挝、柬埔寨和缅甸都是最高领导人亲自现场，凸显了对华关系的重视；剩下四国泰国和新加坡派高级官员出席，只有菲律宾未被邀请而缺席。

谁接到谁不到，都是政治站队的表现。印尼作为东盟第一大国和G20成员举足轻重；马来西亚和新加坡选择务实面对合作；越南虽然存在南海争端，但年中高层互动，合作领域扩大，也邀请参阅，关系大为。

可见，东盟的大部分力量都站在我们这边，至少不反华。菲律宾宾被邀请，说明我们将其归为东盟中唯一的顽固分子。

2022年小马科斯上台以来，菲律宾依然依仗《美菲共同防御条约》，给它的“专属经济区”和挑衅行为壮胆。2023年至今，菲律宾都在派遣各类船只闯南海海域，导致了2024年两次撞船事件。

# 4

近期，菲律宾变本加厉，联合美国在福建沿海380公里的巴丹海峡布防，又向瑞典采购军机、向美国订购反舰导弹系统。

菲律宾不仅因为美国撑腰，还“光脚不怕穿鞋”，屡次在国际上炒作我们欺凌小国，“强势透明”策略就表现出了这一点。

在近十年军备突飞猛进，我们在南海的国防策略越发主动，对2022年以来小马科斯的挑衅行为也丝毫不不息。炒作国际舆论的“强势透明”策略也在方执法力量更加常态化存在，警戒范围进一步延伸了。

我们已连续16年保持东盟最大贸易伙伴地位，2022年RCP启动以来，和菲律宾以外的东盟国家深化合作，雅万高铁、中老铁路这些一带一路成果和对华出口节节攀，都让它们得到了实惠，只有菲律宾对华出口增速快速反跌-4%。

我们不仅发财还不菲，还缓和对越关系，破坏了菲律宾试图联合越南在南海问题对抗我们的企图，让我们得以在南海专心对付菲律宾，所以近期在南海问题更为主动。

今年，中马两国互访，和印尼总统普拉博星夜赶到阅兵现场的友好迹象，也说明马来、印尼与我们的关系。
