


# 2023/1/4 股市快报

2023年1月4日，沪市股市低开走低，成交量持续萎缩，上证、深证两指双低收。上周连续三个大涨后，今日市场明显遭遇了回吐压力。早盘沪指低开，电子、计算机、传媒等板块表现低迷，沪指指数大幅下挫，深证指数同步走低。

今日，沪指报收3284.13点，下跌33.38点，跌幅1.01%；深成指报收10553.58点，下跌91.33点，跌幅0.86%。两市成交约9000亿元，较上交易日缩量约10%，显示市场多头意愿依然低迷，观望情绪浓厚。

从板块来看，今日半导体、人工智能、光伏、新能源、锂、微电子、云计算、白酒、旅游、传媒、影视等板块普遍走弱。银行、煤炭、食品、建筑材料、钢铁、医药、电力、白马、银行金融等板块表现相对尚可。

个股方面，中芯国际、北方华创、海光信息、华虹电子、中电五六创等芯片股领跌下跌；宁德时代、隆绿能源、阳光电源、比亚迪股份、天齐锂等新能源个股也集体承压。

总体来看，市场在经历了一周的大涨后，今日出现回调属于正常调整。成交量的萎缩说明市场尚未形成新的上涨动能，资金仍处于观望状态。后市需关注政策导向及资金面变化，短期内市场可能维持震荡整理格局。
