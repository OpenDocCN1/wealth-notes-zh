


# 马克龙的威胁

猫哥原创

5月30日，在新加坡香格拉会议上，法国总总统马克龙放出一个惊人的言论：若朝鲜军出现在欧洲，北约将扩大到亚洲！

那么马克龙这个言论究竟是什么意思呢？

首先，就是对朝鲜军队参战俄乌冲突表达严重不满，其次，马克龙这番言论是有针对性的——亚洲那个国家有能力阻止朝鲜军队参战俄乌冲突？

毫无疑问，而且只有一个国家就是东大。

所以，北约将扩大到亚洲就可以视为对东大大出发的威胁——如果你不能阻止朝鲜军队到俄乌参战，那么北约军队就会进入亚洲。

这个威胁又引申另一个问题——为什么马克龙认为为北约军队进入亚洲成为对东大的威胁？

现在我们想一想，假如北约军队进入泰国、越南甚至是韩国、日本，东大会认为这是对自己的威胁吗？

肯定不可能啊，毕竟北约军队进入亚洲某个国家是当地自己的主权问题，东大对亚洲任何一个国家也没有领土要求，唯有一点领土纠纷就是印度，但是是以印度傲娇的特性。印度能允许外国军队进入本国国土吗？

用脚指头想也是可能的。

所以，盘点下来，东大绝对不能容忍外国军队特别是北约这样的组织的军队进入的地区只有一个——台湾。

所以，马克龙的威胁其潜台词就是这样一个意思——如果东大阻止朝鲜军队到俄乌参战，北约军队将进驻台湾！
