


# 体制内，财富就是你的底气！

原创：湾区逸曼 公众号：逸曼的小茶馆 25年10月25日

## 前言

体制内人情世故事的最后一篇。介绍体制内普通人慢变富的两个渠道。

体制内职场就是一个名利场。

如果你不是领导，你会信心不足。你是领导的话，你就会意气风发。

这就是个人地位和权力带给你的满足感。

但是，单位里并不是每个人都能提拔成领导的。

大部分人还是晋升到职级的天花板退休了。

这意味着，很多人找不到自信的来源。

要脱这种感觉，一方面，要看淡名利禄，因为在体制内上班已经是康康的生活水平，日子还是比较滋润的。

另一方面，就是让自己变得富有。

如果你变得富了，你就不会羡慕领导了，而且未必想当领导了。因为当领导要操心的事情很多。

而且，你一想到，你每年的收入比单位领导还高的时候，你整个个人就会有松弛感。因为说明你为社会创造的财富高于领导的。你的能力远远优于领导之上。

一想到这些，你就没有任何社交焦虑了，见到领导也不会够紧张的。因为不需要领导给你什么，你也不用求领导，所以没啥好紧张的。

在这种放松状态下，你的社交是充满自信的。这也是我的一个感觉，我相信，只要你有创造财富的能力，你也会有这种感觉。

实际上，在单位上班，普通人比领导更容易创造财富，让自己变富起来。因为普通人更有时间在以下两个相对容易的赛道中，创造和积累财富：

第一，做线下副业。

最简单的线下副业，网约车、外卖员。这个属于辛苦的，但是，如果你在下班时间和节假日时间跑跑，一个月挣两千元是非常有的。大家不要小看一个月的一两千元额外收入，其实有很大的作用。我会在后面说。

当然，这个需要你放下面子。实际上体制内确实有人在干这辛苦活儿，主要是体验一下为主。

## 主要的副业，还是有门槛的线下副业，比如家教、考公讲师、考证讲师。

现在绝大部分体制内的职工，都是本科以上，擅长考试。那么就可以利用闲暇时间，去做考试辅导相关的副业。要找到这些副业，在渠道上，可以联系当地的教培机构，也可以在线联系互联网上几家头的教培机构。

由于教辅市场需求大，再加上你是余副业，属于灵活用工，这对教辅企业也有吸引力。做教辅行业，一个月挣几千块是有有的，这几乎等于挣掉了一份工资了。

第二，做股票投资。

其实这是我最想说的一点。股票投资是最适合体制内的干部职工。因为收入稳定，家庭收入有结余。那么，我建议可以拿出闲钱进行股票投资，记得——是闲钱，要有投资的安全边界思维。

这也是为啥我说，每个月如果有副业的闲钱真的很重要。因为这些副业的闲钱，可以投资到股票市场。

今天我查了一些数据，长期来看，能跑赢通胀、跑赢黄金、跑赢债券的，就是股票。比如，沪深300ETF（宽基指数），2005年—2023年底年化收益在9.5%左右。这是很收益水平，绝超大多数的主动基金。

如果你担心投资个股的风险，你就选沪深 300ETF就行了。今天我特意看了下，沪深 300 的市盈率在十四多点，目前仍处于偏低的估值区间。如果你喜欢保守型投资，就买沪深 300ETF（宽基指数）这类宽基指数好了。

巴菲特也是推荐普通买宽基指数。当然，投资股票最重要的，我认为是收利息。因为红利型的股票还是不少的，在能源、保险、家电、银行、公路这些赛道，依然能找到 4%左右股息的股票。从统计角度，长来看，这些股票的价格大概会跑赢大盘，同时每年又能给你带来不错的利息。如果每年都能积累一部分资产，十年后就是一笔不错的资金。
