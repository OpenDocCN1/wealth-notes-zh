很多公司事不关自己，云山雾罩的就不符合基金的坦诚标准。

【会议要点】

1. 业绩与行业展望
- 三季度业绩增长放缓原因：三季度业绩增长主要个别客户阶段性出货提货节奏变化的影响，属于阶段性情况，并非趋势性问题。
- 未来市场需求与景气度：尽管三季度业绩增长放缓，但从Q4到明年，市场需求的确定性非常强，行业景气很高。
- AI 行业发展节奏：AI 行业有其自身节奏，三季度行业情况及公司面临的情况符合行业发展规律。

2. 订单与客户情况
- 海外客户订单情况：市场传闻海外客户有订单行为，但从公司厂商侧看，市场端与厂商落地存在时间差或理解偏差。更关注客户具体订单的产品类别、时间点需求变化，并据此准备材料和产能以满足交付。

# 3. 供应链与备货
- 供应链准备与压力：经过多年积累，公司与长期合作伙伴保持稳定合作关系，在备货和原材料准备方面经验丰富，已做成充分准备并积极备货。目前供应链存在一定压力，但不会成为明年产能释放的核心问题。

# 4. 产能规划与释放
泰国工厂并非在今年全部释放或准备完毕，仍处于持续提升阶段，未来会根据订单需求持续扩展。(99%的基金经理没有企业经验，他们不知道如何规避风险的)。

# 5. 产品与技术进展
- 1.6T 光模块出货节奏：1.6T 光模块在Q4及明年将持续上量，量级和收入占比持续上升。
- 年硅胶相关产品占比明显提升，三季度已已有硅光产品出货。

# 6. 财务相关问题
- 存货情况：三季度存货环比增长约七亿，属于正常环比增速。公司备货策略维持原有且更激进，不存在因短缺导致被动采购的情况。
- VMI模式下出货所有权未转移时属于公司存货，一般以客户从VMI提货时点确认收入，具体结算因客户而异。

# 7. 长期展望
27年具体数据目前无法看到，但整体趋势和方向不变，预计保持高景气持续向上的趋势。
