


# 1万亿美元化债是何用意

外媒的消息说，政府正在考虑要求国家开发银行等国有银行和政策性银行向地方政府提供资金，偿还拖欠债务。

总盘子1万亿美元，一期1万亿元人民币，2026年前完成。

拖欠的是什么债务呢？

欠民间企业的债务。

第一，现在消费萎靡、经济不振的核心原因，是各界反映“没钱”。

因为国有城投公司、平台公司等，拖欠了各种民企、包工头的大量应付账款。

导致一个地方有钱人的可支配消费“大幅降低”。于是他们缩减了大量不是必要的开支和消费。比如跑车不买了，KTV去得少了，公司不扩张了，房子也不买了。

因为政府欠他们的钱，可以不还，抱着还不还的态度；但他们欠银行的钱，不能不还。

而科技新贵成长起来又很慢，况且绝大多数地方搞不了科技。

当有钱人的主导模式从“花钱”变成“还债”，就会带动大家都不花钱的“内循环”陷阱和“资产负债表衰退”。

就会陷入通缩。

就会变成日本“失去的20年”。
