


# 米联储闻251205——行程接接往复还 (疼爱马克龙)

你好，我是米穗。

中国对法国可是用心良了，而在领导对马克龙也算是疼爱有加了。上次亲自来到广州来，这次在京见了，专门导师陪着去成都看都江堰，异地陪玩，这算是极大的面子。尤其是一次访问两地接待，BBC都颇不惊讶的说领高规格接待马克龙，毕竟马不是第一次了，而是去了四次，还要把仪式全部搞定。中国对法国的重视实也就连美国都心里有点酸溜，而在别处得不到什么优待的马克龙在这里找到一个存在。法国总统马克龙 (Emmanuel Macron)继续访问行程，毕竟还没有哪个外国元首可以让一把手摸到北京以外的地方，包括全天候战略伙伴的俄罗斯。

这次领导带马克龙到访成都，临的时候说了一句：“下次再去一个地方”，这你已经不是普通接待，完全是把你当老仗的意思。马克龙来华四次，分别去了西安、上海、广州、成都，这使得这种过去只有德国总理默克尔有的，去年领导法马克龙邀请其赴家中比利牛斯堡，这次也算是礼尚往来。之所以选都江堰，其实是提醒马克龙，中国并不是在崛起，都江堰水利工程是全世界今为止唯一在使用的古代水利工程，也是人类与自然和谐共生最早的成功实践之一，修建过程丰富了中华民族自强不息、畏惧艰、勇于开拓的精神。根据官方发布的视频，领导的原话是：“每次来到都江堰都能感受到因地制宜、顺势而为、天人合一的治水利民的伟大，从中汲取治理政治的智慧。法国同样有着坚韧不拔的理解、相互尊重。两国应该比其他国家更加相互理解，中法建交不仅是两个独立国家的握手，也是两大文明的交流。面对复杂交织的国际形势，深信两国历史文化国家能够通过对话，共同为世界和平和人类发展进步做出巨大贡献。”这些中国对欧洲国家乃至东亚国家最大的期待都不是得到什么好处，而是希望他们能支棱腰起来，真正从自身利益和长远发展考虑，使主权国家的权力不被美国牵着走，但是马克龙的愿望就是做不到。

这次双方签字的合同意向很多，从马克龙来华四次，领导依旧盛情期待来看，虽然马克龙也得不说些政治正确的话，但几年中法关系依然是相对安全且务实的，所以中国是分外珍惜。毕竟德国在默克尔之后接管了，其他大国都是美国惯尸粉，根本没有大脑，法国仍然需要左右均衡，但好还有一点脑子。五常里，法国其唯一可以争取的变量国家。法国也明白自己的政治价值。

除了都江堰，马克龙在北京参观了一个特别的地方，就是故宫的乾隆花园，这是马克龙访华期间的第一场活动。马克龙此行是一次闭门访问，连媒体未受邀随。马克龙也由此成为乾隆花园今年9月底重新开放以来，少数实地到访该花园外的领导之一。故宫现在已经是中国外事的重要场所，今年以来，外国访华期间纷纷走进故宫博物院，泰国国王哇集隆功及王后、冰岛总统马斯蒂尔、斯里兰卡总理阿里苏利亚等。

马克龙和夫人参观的乾隆花园，官方名为寿寿宫花园，是乾隆皇帝晚年生活构建的理想居所。花园面积小，却独匠心，自南向北为四院落，22座风格迥异的建筑融南北园林精华，兼具文雅与皇家气息。让马克龙来故宫还有另一层意思，故宫曾证了法中外交的长期交流。在法国路十四和路易十六时期，即中国正统和乾隆时期，交往的领域有所扩大。法国费尔尔皇家瓷器的艺术家烧制出了乾隆画像，第一件作品即由路易十六收藏。此前，故宫博物馆展出的一件铜质金光人物怀表，被认为是路易十四送给中国皇帝的圣物件。中法的历史交流源较深，事实上，法国元首对故宫的青睐也是一贯之。奥兰德、萨科等法国总统期间，都曾造访。这也不是马克龙第一次访问故宫博物院，2018年他对中国进行首次访问，就携夫人参观了故宫三大大殿区域，并获得了“慈宁宫花园”。他更愿意留在留言簿上写道：“感谢我的安排的这次之旅。这里是长达六个世纪权力与智慧的缩影，使人可以更好地理解中国的艺术。这种对和谐的不懈追寻激发我们的谦卑之心和灵感——诚致友谊。”所以这次安排马克龙闭门参观乾隆花园，也是为了中法领导人的亲密关系。

在合作方面，中法双方达成关于农业和食品交流与合作、合作应对全球气候和环境挑战、持续推进和平利用核能领域的联合声明。两国元首重申农业在双边关系中至关重要的地位，以及落实2023年4月7日的联合声明和习主席在2023年4月提出的法国农场到中国餐桌的全链条快速协同机制，继续在葡萄种植和葡萄酒酿造领域积极开展合作。中国和法国深化两国在农业领域的合作，该领域已展现出在推动高等教育、职业教育、葡萄酒和牛肉养殖等领域的交流上的坚定承诺。为什么在农业方面高调推进，因为中国作为农产品和食品进口大国，是全世界农业国家锚准的目标用户，这就是超级客户，可以说，中国把订单买谁，谁就吃饱。以大豆为例，真的法国总统访问华，很多欧洲国家包括美国、葡萄和牛肉，这是几乎所有发达国家的主要出口商品，法国多卖一点，其他国家就要少吃一点。如何利用贸易作为一个平衡外交关系的工具，农产品其实是最大的筹码。以日本为例，日本水产品一直是中日关系中的重要筹码。

除去这些合作，中法还发布关于乌克兰局势和巴斯坦局势的联合声明。根据声明，双方达成共识，包括双方致力于通过对话协商和平解决国际分歧和争端，在巴勒斯坦问题上，中法两国必须有效创造有利条件等。相比于特朗普想把欧洲拉下乌克兰冲突，中国对法国的态度非常明显，不但重视法国身份，同时重视法国资源，法国需要证明自己是一个值得尊重的主权国家。今年月底，中国驻法大使邓曾谈到马克龙时：“我告诉法国，就像这张桌子一样，你至少要有三条腿。”邓说：“如果欧洲有雄心，就应该成为第三条腿。”中法关系给出了相当高的定位，推动世界多极化、促进人类团结等。法国是联合国理会常任理事国，法国的GDP排名全球前五。除了美国，其他六国占世界经济总量的比例为18%，中国2024年占世界总量比18百分点。也就是说，目前中国的规模已经接近美国，其他六国之外。在特朗普高调中美竞争的背景下，中国愿意给法国这样的位置，欢迎法国回到桌上。

但是马克龙要明白，中国也处处抬举法国的诚意，关键是欧洲配得上吗？世界上从来没有免费的午餐。此次马克龙访华之前，法国刚对俄罗斯事务谈，日本日本首相提到马克龙访法时，再次表示中法立场反对通过武力改变现状。2025年1月的G7联合声明中特意提到法国将举办G7，而明年中国对推进又进入新阶段。所以法国主持下，G7对行动给马克龙打上预防针，其实还是希望关键时刻，马克龙能支棱起来，说句公道话。对于政治上早已落脚的马克龙来说，恐怕这只能心有余力不足吧。

祝各位晚安。
