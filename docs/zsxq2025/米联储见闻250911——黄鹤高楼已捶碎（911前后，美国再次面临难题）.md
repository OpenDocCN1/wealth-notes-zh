


# 米联储闻 250911——黄鹤高楼被砸
(911)前后，美国再次面临难题

你好，我是米糕

今天是9月11日，24年前的9月11日，恐怖分子劫持民民客机，对美国境内目标发动自杀式袭击，两架撞上世贸中心双子塔，一架撞上五角大楼，另外一架坠毁在宾夕法尼亚亚州，共造成2996人死亡，成为改变世界走向的一次超级黑暗事件。24年后，911前夕，中俄同时给美国出了难题。就在911日，31岁的川普铁杆支持者查理·哈克肯被众枪击身亡，美国的危机从盛世的惊鸿一瞥到现在的千疮百孔到处漏风，一个超级帝国陷入低谷只需要经过两个样本。

在911事件后的20年间，美国耗费8万万美元在全球范围内85个国家开展反恐行动，导致直接死于战争的人数达90万人，其中美军死亡达7000人，造成难民和流失人口超过3800万。出来混，总要还。过去24年，为了维持美国在冷战后形成的超级霸权，为了让美国政党实现利益最大化，美国的政客们在全球肆意践踏，自己也付出重代价。虽然美国制度在两场主要战争中迅速达成了重塑霸权、重构秩序的目标，美国在后期治安战中深陷泥潭。虽然反恐战争透支了美国的国力，导致美国在大国竞争中优势日渐稀薄，最终美国不得不结束反恐战争，转向重返亚洲，面对大国竞争。

现在的美国，虽然国力早已不是24年前的美国，但依然坚持霸权之道，美国优先，以单边主义、强权政治取代多边规则，不择手段地追求安全、经营等领域的绝对利益，霸权行为恣意发扬无忌惮。犹太集团这次纵从以色列空打卡塔尔，可说是彻底打破了美国作为大国的外交底线。现在的美国，既留不住以色列，也没有任何底线，盟友、对手、合作伙伴混淆不清，统都是可以打、合作可以伤害，完全是敌友不分，没有原则，思路混乱。

也恰恰因为美国失去了大国的体面，于是大家都开始给美国上药，给普普出难题。大阀兵结束后，中俄都用自己的方式给美国出了难题。中国是直接将黄岩岛为自然保护区，并下令菲律宾军舰拖走，上海海警撞军舰后，是惹了老了，决定要把菲律宾这个猴子狠狠扇打一次。这次大爆发后，立刻策划保护区，然后给美国打话，表明自己要干啥，言之凿凿：“你要不要要事自己看着办”。对于中国的操作，猴子今天表示强烈抗议，中方表示不接受，建立自然保护区是中方主范围内的事。接下来，就看老中的手段了，也看美国怎么招。

以色列直接空袭了美国中央司令区域总部所在的卡塔尔，试图击杀在多哈豪区一座建筑内商谈停火方案的哈马斯领袖，最终却没有实现目标，却给美国出了另一个难题。川总今天很生气，在电话里跟塔拉维夫比了很久，但是全世界都不相信，以色列可以绕过美国的防空系统对卡塔尔实施空袭。现在美国谁看，哪怕美国不承认，美国的盟友们心里一紧，试想能不能跪美国，好比卡塔尔这般。但卡塔尔得到了什么？怨恶不分的大国，让人如何相处。以色列也把难题给川总提出了，现在川总需要花戏表演美国信誉这块烂疮百孔的牌子继续糊。

俄罗斯也没有闲着。9日晚上11时30分，19架称来自俄罗斯的无人机开始入侵波兰领空，从德国、荷兰到意大利的北约国家军队都赶忙应对，击落当中有威胁的4架无人机。这是北约军史上首次在北约国家空域接触潜在目标，也是首次有俄罗斯无人机在波兰范围内被击落。如果真的是俄罗斯的操作，显然俄罗斯也用硬手段对待川总，出了一道难题。这题也是送命题，至于美国如何应对，俄罗斯无人机侵犯波兰领空，给川总出了另一道难题。川总面对，美国只能敷衍。
