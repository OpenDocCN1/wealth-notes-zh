


# 新的消费刺激机制

发布时间：2025年12月16日

源自12月深圳线下读者系列内容，以及12月15日部分群聊内容。

从26年开始，我们的消费刺激路线就改变了，25年就是一个一个过渡期，国补退潮，资补加码，阿里、美团和京东为代表的平台公司开始补贴。

从效率和结果的角度，企业补贴比国补要不少。首先，企业补贴的效率更高，国补很难避免被命中的之间企业利用规则中饱私囊，但平台企业的反应力度与审查能力远高于政府；其次，平台补贴比国补的受众大众。

国补的电子和汽车，本质上是在补贴产中，效果小；但奶茶代表的平台补贴主要针对底层牛马，受众面非常大；

第三，国补主要是耐用品，透支未来消费，国补的消费都有显著的使用周期，今年消费明年就没有消费力，而奶茶代表的消费补贴有巨大的消费粘性；

第四，平台补贴的就业带动比国补得多。国补主要是帮助电子和汽车领域仓库，这些企业流水程度高，带动就业极为有限，但平台补贴主要带动快递等人力，解决就业。

马云一顿饭才能吃几个馒头，必须让马云把钱发给百姓才能真的刺激头部消费。

有消费才有就业和工资收入，经济才能循环起来，所以以26年的消费放宽来看，是很有可能成功的，毕竟国补用的是中央财政预算，企业是通过资本市场向未来借钱。

但放任企业补贴，要付出的代价也是非常巨大的，中央政府必须要卖而储备，给之前不会给的政策，才能驱动企业家里出血，给出比国补更多的资金。以25年前先行的星巴克、汉堡王为例，国内赵家资本消费领域，大规模的开店扩张，与麾下的平台企业合作，进行消费补贴，既拉动了投资和就业，又刺激消费，国家则会例允许他们通过 REITs 将流水的资产打包卖到资本市场。同样的，放任平台企业刺激消费，自然也要对垄断进行一定程度的默许，允许平台企业与消费企业有更多的甚至间接控制。

# 全国首单（轨道交通并表类型REITs），落地无锡！

来源：无锡日报、上海证券交易所、百度百科 2025年12月13日

近日，无锡地铁1号线REITs项目获得上海交易所审核通过，为全国首单轨道交通并表类型REITs。

REITs，是指“不动产信托基金”，是向投资者发行收益证书，募集资金投资于不动产，并向投资者分配收益的一种投资基金。

REITs的推出对经济发展意义重大，可以帮助企业快速回资金，盘活存量资产，给市场注入新动力。此外，降低了投资者参与不动产投资的门槛，具有流动性较高、收益相对稳定、安全性较强等特点。

该模式由美国在1960年创造。和60—70年代的其他金融创新同样一样，REITs也是为了逃避管制而生。随着美国政府正式允许满足一定条件的REITs可免征所得税和资本利得税，REITs开始成为美国最重要的一种金融工具。

# 关于《中国证监会关于推出商业不动投资信托基金试点的公告（征求意见稿）》公开征求意见

来源：中国证监会 2025年11月28日

2024年度的个人所得税综合汇算办理时，为贯彻落实中央、国务院决策部署和“资本市场新国九条”要求，推动不动投资信托基金（REITs）市场高质量发展，丰富资本市场融资工具，支持构建多层次市场发展模式，持续增强多层次市场服务实体经济。我国REITs试点以来，已形成一定的规模。
