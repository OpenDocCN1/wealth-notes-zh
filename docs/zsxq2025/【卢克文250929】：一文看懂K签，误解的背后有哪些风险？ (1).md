


# 爱卢的文：你还有勇气吗？

2023/05/24 14:56

一文看透，醒后的你还有勇气吗
文/作者：星海行者

1、2010年，中国还面临着严重的就业压力。那时候的K出生那几年，K面临的是就业压力，社会面临的是入场压力，那时候的中国还面临着经济转型的压力。

那么，现在的K醒来是什么时候？社会会有什么样的结果呢？

这就就像，醒来是什么时候，梦还是真实？现在的K，在2018年出生，但他着巨大的就业压力，可能只有10岁就要面临入场压力了？

现在的K面临的是什么压力？现在的醒来又是怎样的结果？

那么，现在的K还有勇气面对吗？

现在的，中国已经发生了很多变化。首先，就业压力变了，以前是人不找工作，现在是工作不找人了。其次，人才供需结构也变了，优秀人才缺了。

但是，这些变化，真的足够让现在的K有面对的吗？

首先，现在的中国已经进入了老龄化社会。以前是人口红利，现在是人口负债，劳动力人口在不断减少了。

其次，人才结构也变了。以前是缺技术工，现在是缺高技术人才，高尖人才缺了。

最后，高等教育程度也变了。以前是大学生不值钱，现在是大学生满街走，学历也贬值了。

那么，现在的K面临的是什么样的压力？

首先，现在的竞争压力是巨大的。以前是人跟人竞争，现在是人跟人内卷、内卷。

其次，现在的门槛变高了。以前只要本科就能进，现在要名校硕士才能进大厂。

最后，现在的环境也变了。以前是机会到处都是，现在是处处可见的生存危机。

那么，现在的K还有勇气面对吗？

首先，现在的职场规则变了。以前是干一辈子公司，现在是随时可能被裁员。

其次，现在的收入预期变了。以前是努力就能致富，现在是努力可能都温饱。

最后，现在的心态也变了。以前是敢想敢想，现在是随缘躺平。

那么，现在的K还有勇气面对吗？
