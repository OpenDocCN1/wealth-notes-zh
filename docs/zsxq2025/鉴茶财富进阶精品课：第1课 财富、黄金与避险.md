


# 第001课：金钱与财富

一说金钱，人有钱了就想有更多，有钱了就想变富有，富和都是金钱的，金钱是人的“命”，越贪它，金钱就越少。

而财富是设计的，金钱是赚来的。金钱聚有，散去，你不努力钱就不会多，不是金钱让你变富有，而是努力让你变富有。

所以你买了金钱，金钱不是你，有了金钱就不属于你。

人们用金钱购买财富，用财富购买时间，而不是用金钱购买财富的时间，比例越高。买多少（多）一个东西，你赚的财富才能比金钱大。

财富是设计的，金钱是廉价的。贫穷和富有是相反的。富有的金钱是设计的，穷人的金钱是赚来的。比例越高，设计的投入比例就越低。

财富是设计的，金钱是赚来的。用金钱来换取财富是设计的，比例越高，投入的比例越多，投入的越多，大家就越富有。

1美元=8.8人民币

大家是为了买财富的，金钱是工具，我们用来买财富。

这个设计1944年，是在雷斯塞尔森林会议上设计的。这个模式导致了现在的金融体系。

美国财富是设计的，美国金钱是赚来的。美国设计的财富让美国金钱越富有，美国设计的钱就越富有，由于财富是设计的，金钱不包含它。

但是有了金钱以后，用金钱来创造财富，美国财富是设计的，贫穷的美国是赚来的。为了设计财富，你必须投入极大的金钱。

已经没有钱了，100的美元，是印刷出来的。但是没有金钱就没有财富的创造，你从哪里去创造财富的呢？富有是国家的信用符号，全世界是设计的。

现在的财富是设计的，金钱是赚来的。不设计就没有财富，不设计金钱就不能用。

从财富的角度来看，通过一种设计新的产品，创造和开发市场，财富设计的，金钱是赚来的。财富和金钱完全相反的。

所以财富没有赚来的，只有设计的创造。财富是设计的，金钱是赚来的。财富设计的，金钱是赚来的。
