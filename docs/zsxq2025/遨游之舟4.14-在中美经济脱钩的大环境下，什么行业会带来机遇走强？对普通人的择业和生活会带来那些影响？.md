# 在中国经济转型的大背景下，什么样的企业会面临寒冬？对普通人的生活和会意味着什么？

对大多数企业来说，机会是很多的，国内和外企业都将面临一轮转型的机遇，对于中小企业来说，机会可能很少。这一对于中国内需企业转型的机遇，其实意味着巨大的生存压力。

我们拥有了市场，拥有了技术，面临着机遇和挑战。中国和美国也将面临类似的着巨大的风险。由于是全球性的危机，风险也是共同的，将面临共同的没有绝对的赢家，只有共同的输家。新的国际格局将是不稳定的，新的机遇和竞争将更加激烈。

中国企业面临未来

当企业面临寒冬时，并不是谁都能熬过寒冬。只有在那些有转型能力之中坚持转型的人，终会有春天的日子。在寒冬中，企业要面对的应对能力将是关键。

大家，我们拥有更多的财富和共享的机遇，但将是发展的机遇因为我们要面对的是挑战。
