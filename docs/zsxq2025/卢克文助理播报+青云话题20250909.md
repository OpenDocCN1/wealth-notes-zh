


# 【助理播报】

国际：

1. 法国总理贝鲁卢领导的政府在国民议会8日举行了信任投票中未获通过，贝鲁卢将代表政府向总统马克龙交辞呈。

2. 三星生物9月9日宣布，已与美国某制药公司签订价值12.9464亿美元（约合1.8001万韩元）的委托生产（CMO）合同。

3. 9月8日至9，中俄蒙以“联合防范打击边境地区恐怖破坏活动”为课题，在中俄蒙边境某区域组织“边防合作-2025”联合演练，这是三方首次组织边防部队参加联合演习。

4. 伊朗外交部长巴斯·阿拉齐7日为英国《卫报》撰文，显示伊朗愿意接受对其核计划的监督以及铀浓缩的限制，以换取西方解除对伊制裁。

5. 匈牙利媒体报道，当地时间8日，匈牙利总总理欧尔班致信欧盟委员会主席冯德莱斯，要求欧盟赔偿匈牙利为保护边界安全所支出的费用。

6. 西班牙首相桑切斯9月8日日上午在马德里表示，西班牙政府将发布一系列针对以色列的措施，其中包括批准禁止向以色列出口出售武器的法令、禁止向以色列出口出售武器或燃料的船只或飞机在该港口中途停留或进入该国领空等。

国内：

7. 最新数据显示，2024年我国对外直接投资净额为1922亿美元，比上年增长8.4%。

8. 国家卫健委介绍，育儿补贴申领已正式全面开放，可以通过支付宝、微信和各省政务服务平台线上申领，也可到达婴儿户籍地的乡镇政府、街道办事处进行现场申领。

9. 工业和信息化部长李乐成9月9日在新闻发布会上介绍，我国已建成全球最大、覆盖最广的网络基础设施，5G基站达459.8万个。
