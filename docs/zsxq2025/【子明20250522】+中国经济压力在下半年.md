


# 中国经济压力在下半年

发布时间：2025年5月22日

中国一季度经济数字维持较为漂亮，有三个决定性的因素。

- 一是特朗普上台后为了避免被关税抢出口，
- 二是为了应对关税冲击大幅度的以旧换新补贴，
- 三是拖欠了许久的公务员员工工资重新发放，

“三驾马车”的同时发力，驱动了中国经济迎来了开门红。

可以预见的是，一季度的三驾马车都会在下半年火。。

- 1、特朗普给的90天关税豁免驱动出口。为了避免被税，在五六月份顶着30%的加征关税继续猛抢出口，把下半年的海外库存和需求一次性的补足。
- 2、汽车与消费电子产品都有两年以上的保鲜周期，自去年下半年开始的大力度国补，也会透支消费者的消费热情，使得下半年开始出现失效与消费失速。
- 3、刚刚不用紧日子，马上开始了八项规定，根据历史经验，八项规定将持续至少一年以上，消费的断崖式下降，直接带崩白酒为代表的高端消费。

可以说，中美经谈判的结果如何，中国都必须在25年下半年启动新的经济引擎。

参考特朗普1.0时代，选择无外乎两个，一个是科创，一个是地产。可以预见的是，在拜登时代落寞多年后的科技，又将卷土重来。

房地产整体虽然积重难免，但“含金量”应该还能看。

## 一季度国民经济开局良好
来源：国家统计局 2025年04月16日

初步核算，一季度国内生产总值318758亿元，按不变价格计算，同比增长5.4%，比上年四季度环比增长1.2%。

分产业增加值，第一产业增加值11713亿元，同比增长3.5%；第二产业增加值111903亿元，增长5.9%；第三产业增加值195142亿元，增长5.3%。

市场销售增速回升，以旧换新相关商品销售增长较快。

消费品以旧换新政策继续显效，限额以上单位通讯器材类、文化办公用品类、家用电器和音像器材类、家具类商品零售额分别增长26.9%、21.7%、19.3%、18.1%。

固定资产投资稳中有升，高技术产业投资增长较快。

一季度，全国固定资产投资（不含农）103174亿元，同比增长4.2%，比上年同期加快1.0个百分点；扣房地产开发投资，全国固定资产投资增长8.3%。

分领域，基础设施投资增长5.8%，制造业增长9.1%，房地产投资下降9.9%。

高技术产业投资同比增长6.5%，其中信息服务、航天器及设备制造、计算机及办公设备制造、专业技术服务业务分别增长34.4%、30.3%、28.5%、26.1%。

货物进出口持续增长，贸易结构继续优化。

一季度，货物进出口总额103013亿元，同比增长1.3%。其中，出口61314亿元，增长6.9%；进口41700亿元，下降6.0%。民营企业进出口增长5.8%，占出口总额的比重为56.8%，比上年同期提高2.4个百分点。
