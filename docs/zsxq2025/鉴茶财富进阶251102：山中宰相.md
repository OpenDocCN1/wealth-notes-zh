# 鉴茶财富进阶 251102: 山中宰相

今天来说一个传奇人物陶弘景，他是南朝末朱梁初丹阳殊陵、林陵，也就是南京。

陶弘景从小就非常聪明，精通文历法术、山川地理、兵法韬略、医术药物、琴书画乃至阴阳五行，他还炼过丹，写过医书，是一个典型的斜杠隐士老。

36岁的那年，他辞职归隐山林。离朝廷那天，公卿贵族为他送迎，车马多的把路都堵了。

南齐末，萧衍篡了齐朝政权，之后和大臣们商定国号的事，但始终得不到统一的意见，于是派人去陶弘景。

陶弘景遂按易象推算，建议国号为“梁”，同时又为梁武帝推出出生登基的日子和时辰。

梁武帝特别希望他出来做官，有一次急了，下诏问他山里有什么这么不肯给面子？

陶弘景说是写了首：

## 《绍问山中何所有赋赋诗以答》

山中何所有，
岭上多白云。
只可自怡悦，
不堪持赠君。

陛下下您问我这山里有什么宝贝，值得我留恋？我告诉你吧，这山岭之上，最多的是那自由自在的、洁白飘逸的云彩。不过可惜啊，这种快乐只能我自己在山中亲身感受受，心旷神怡，我没办法把它摘下来打包给您。

萧衍也是明白人，看了信后，不再强求。从此，每国家有大事，都会进山去咨询陶弘景，陶弘景也因此得到了“山中宰”的美誉。

陶弘景的核心智慧在于，它能够找到自己安身命的精神源泉，和外界的事物和谐统一。

从古至今，社会的“成功模板”同样五花八门又异曲同工，名望、职务、权力、财富、高薪、豪宅、名校，但这些都是欲望需要的，不一定是心灵需要的。

一个人真正的安宁，是不依赖于外在的给予的，权力、财富、他人的等都是世俗的表象，你越追求越焦虑。如果你能够对美好事物有足够的感知与沉醉，哪怕是一朵花、一粒树、一部你喜欢的电影，你就能超凡俗，给灵魂充上电。

名车、豪宅、财富、地位、奢侈品，都是我们喜欢的，完全可以光明正大的追求，但我们追求的时候也要知道，它们不是得不可，更是生命的意义，喜物而不溺于物，钟情而不陷于情，追求而不强求，以内心的平衡驭外界的波动，你就是山中宰者。
