


# 创始人的春天

2023-05-22

似乎对创始人的需求减少了，但需求并没有消失，甚至在未来-2025-2030

这几年我们发现一个现象，那就是很多国家虽然经济下行，但创业的人却在增加。创业的需求在变大，门槛在变小，但不再像过去那样创业变得那么容易，政府的影响也越来越大了。

对于创业的同一个核心就是国家能否提供环境。最关键的，就是政府能否提供支持、财力的支持、政策的引导。当然，政府在资源分配上拥有权力，如果政府分配资源不公平，那么国家的创业环境就会变得糟糕。那么创业是好事还是坏事？

但是，由于不同国家之间的政策差异，创业环境也很大不同。在很多国家，由于政策的改变，创业热潮就消失了。

那么创业者是否应该要向政府索取帮助？或者，创业者是否应该受到政府的监管呢？

几年年前的创业潮退，一个最明显的首过于美国。由于政策的改变，美国的创业潮退非常巨大。但是，创业的需求依然在增加，政府的影响也变强了。

但是几年了，由于技术进步使得新的创业需求开始在全球范围内涌现，通过不同的方式资金转移出来，这是否会引发新的全球趋势？创业潮将会变得更加复杂吗？

这一类，是由于技术的进步使得新的机会在全球范围内涌现。创业者是否还需要政府提供更多的帮助？或者，创业者是否应该受到政府的监管？这种机会的出现，未来也可能再次出现。看来，我们需要的是帮助，还是我们需要政府的监管呢？

对于处于中间位置的政府来说，中长期应该如何通过财政或政策来引导创业？然而，由于政府的资源是有限的，很多国家，足够的创业支持是否足够吗？

从美国，很多国家的创业潮退，其实是因为资金的匮乏。但是，这是否取决于国家的经济实力还是取决于政府的分配？首先，资源的分配是否取决于政府的主观意志，其次资源的分配是否取决于国家的需求？其次，资源是否充足？最后是否取决于政府的效率

对于地区，创业环境也是不同的。比如印度和美国，大家有不同的环境。在印度，政府的态度与美国完全相反。在这种情况下，政府应该减少还是增加创业支持？根据这种假设，结果是，“比几年前和现在的创业潮，是三个完全不同的潮流，未来可能不同的

所以，创业潮的减少，是因为政府减少了基础的投入，这直接导致了环境的恶化，导致了创业的衰退。然而，这种衰退是由于政府的因素，还是由于市场的因素？这取决于你如何回答。也许这也有不同的观点。

从一个角度看，创业的衰退，是产业发展的必然。但是这种创业潮的衰退，是由于政府的因素，还是由于市场的因素？这取决于你如何回答。也许这也有一个遗留的问题：如果创业衰退是必然的，那么未来还会引发新的创业潮吗？

在这种情况下，作为政府的部门，我们该如何应对这种衰退呢？

作为市场监管者，政府应该对行业进行干预还是引导呢？

例如，每一个创业者都需要政府的资源支持，但是政府不应该提供给每一个创业者，应该提供给最有可能的创业者。这种做法是明智的。
