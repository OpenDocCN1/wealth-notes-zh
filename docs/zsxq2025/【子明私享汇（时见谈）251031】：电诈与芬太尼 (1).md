


# 电诈与芬太尼

![](img/36b30e089f360c01655849a2aa76e4a1_0_0.png)

加微信进资料群

发布时间：2025年10月31日

今年中国演员王星国被掳拐卖到缅北，引发了巨大的舆论浪潮，本质上是国家机器操纵的，是有意对泰国进行打压，

因为泰国国内内部部分反华利益集团结缅缅边境地区，对中国进行网购电诈，

中国想要消灭这一股黑产，防止资金流出，就需要通过旅游风险和经济利益打击泰国政府，迫使泰国政府肃清国内相关的反华利益集团，促使亲华的利益集团执权。

同样的，中国政府也因此选用由支持缅军政府的支持政府，用中断援助和国际事务支持要求缅甸内部肃清反华利益集团。

在缅甸打击网购电诈当年的湄公河行动类似，都是通过程序正义和经济利益捆绑，去肃清势力范围内的反华利益团体，打击后，中国后花园的泰国和缅甸等国家只会变得更加亲华。

美国扛着芬太尼，对南美诸国和中国施压，也是同样的道理。

# 美国高度重视芬太尼问题

来源：中国科学院科技战略咨询研究院2019年11月11日

美方报告认为，中国经销商通过互联网掩盖真实身份，接触美国和世界各地的潜在客户；出口商通过一系列手段逃避监管，秘密将毒品运往西半球，包括直接或通过墨西哥、加拿大接运往美国。

中美两国持续加强双边合作，增加情报和信息共享，共同打击非法药物和化学品贩卖。2018年12月1日，中美会晤后，决定对芬太尼物质进行调整列管，并启动有关法规的调整程序。

美国司法部和财政部已经对中国非法药物芬太尼者采取司法行动。有分析指出，通过司法手段公开美国中国贩毒分子是美国向中国施压的一种手段，因为中国“不想被视为毒品国家”。
