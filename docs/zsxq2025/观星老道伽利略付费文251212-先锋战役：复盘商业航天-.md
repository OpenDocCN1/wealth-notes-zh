


# 先锋战：复盘商业航天

原创 观点道者 观点道利航
2025年12月12日 12:23 北京

前文：中国经济五五规划的A股时间线

## （一）启动阶段

11月初启动（科创50指数突破600日后），11月初进入加速——资金回流政策转向，行情板块开始呈阶梯式上涨。

进入加速的诱因因素是11月中旬每周发布太空规划蓝图，提出700-800km近地轨道数据中心；国家航天局随后发布《商业航天高质量安全发展计划》（2025—2030）。

11月14日至12月4日共15交易日，航天领域最大涨幅118%，多次分歧出现。

政策→订单→技术突破三重重构。

GW链下年中市场爆发，调研数据显示航天需求远超预期，火箭运力缺口显性化。

“此前”计划于9月起飞并对接发射站运行，验证了商业航天热度；加速推进，方面要求火箭报告显示朱三号可重复火箭继续爆发，依然是航天领域（中国航天、中国卫星）。

明正反正，首先并没有作出任何承诺，反而是市场没有重点重心，或是上市龙头的“航天”企业头部蓝星（如中国航天、航天发、航天科技），呈现利好回兑；2025年行情爆发之潮。

本阶段行情回缓，防守的品种需加关注。

其实如果时间拉长看，在今年三季度行情和航天领域已经如此商业航天爆发，显然是调研驱动涨（截止11月初之前已有32个概念接航天市场占比领先——龙腾市场地位/矩阵已形成垄固格局）。

## （二）产业链结构

- 卫星制造：星载、TR组件、姿控系统应求，航天装、电子等一个月内最大涨幅50%。
- 火箭发射：可回收火箭发射至5万元/公斤，中科航、天兵科技等概念上市。
- 地面连接：6G加速推进，手机直连卫星为手机带来流量，上海二涨幅超10%。
- 运营服务：卫星互联网有望在明年爆发，中国卫星、银河航天率先完成3万颗调优，奠定“星座计划”。

十五规划卫星定位发射

（十五规划卫星定位发射航天首次被视为新建设基石，战略意图：结束五五规划期间大爆发——航天的及社会经济效益）。
