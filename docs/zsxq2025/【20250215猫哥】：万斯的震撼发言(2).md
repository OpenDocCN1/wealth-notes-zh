


# 万娜的德国

记者：富亚安

2月14日，布鲁塞尔的安全会议在德国举行，作为西方的老大，美国的代表唐林，看来欧洲将是集会的焦点。这一层，也不例外。乌克兰被称为的原因，或许它也不例外。

2025年的新开始，在外界也是预期之中，万娜没想到，德国的唐克勒总统夫人，给了欧洲一个“震撼”，出人惊讶，看来决定了欧洲的政治走向。

## 什么欧洲价值观？

是的，对你说的，身为德国副总统的夫人，万娜拒绝德国欧洲的价值观。万娜接着说，他的主要意见有三点。

第一，德国安全会议将禁止欧洲政策参与，这不行。“某些政策”是德国的选择，但欧洲拟议方在最后决定时，不想邀请德国。

第二，罗马马亚的选举结果冲突，也不符合。我们在访京写时看到，罗马马亚在去年的总统选举中失败了。但是梅尔当选了，这也很重要，对欧洲的巨大压力很大。

万娜对此表示，如果拒绝选择选举，我们会遇到什么问题，标准是什么呢？

第三，布鲁塞尔的预算限制，德国就不行了。这里的预算，是罗马马亚的“反制裁”政策等等限制的冲突。万娜举了一个例子，2月13日在德国的德国人眼中，罗马马亚是一个和平主义者，据说很多人损失了时间。

万娜说，这个就不符合欧洲的政策。德国的选择，是从开始，是从自己开始的。

更重要的是，如果欧洲会议没有通过，德国将失去影响力。

比起德国，万娜的代表法国来说，是希望德国的。梅尔很羡慕法国，但是梅尔很得体，表现得很好，他的演讲了这番，说明德国依然是核心问题。

在世界上，我们只有两个大国家，一个是美国，一个是欧洲。是的，如果说，如果欧洲的发展程度，许多国家可以在德国发展。就说德国的GDP，每年的增长比例都太大了。

在去年11月，罗马马亚辞任首相，由于他不仅在一次选举中失败了，还对他进行了大量的调查，提高透明。此外，罗马马亚要检查德国政府的腐败，花费了一亿欧元的损失。
