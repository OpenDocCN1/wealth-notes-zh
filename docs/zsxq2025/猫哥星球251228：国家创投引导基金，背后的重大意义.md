


# 猫哥星球251228：国家创引导基金，背后的重大意义

今年3月在两会期间首次提出，到7月正式完成工商注册，国家创业投资引导基金终于将年底的点在周五正式官宣启动。

涉及信息量比较，这里我们把一些核心关键内容，揭开了认识一下：

先谈谈启动的背景。

实际上，类似基金，我们并不是空白。早在10年前，我们就已经启动了新兴产业创业投资引导基金、中小企业发展基金、科技成果转化引导基金。只不过，在面临新形势、新挑战、新目标，需要再进行金融创新。

国家创引导基金，顾名思义，核心落脚点就是创投，通俗理解就是风投。

大家应该都有一定感知，近年来，国内的创投环境实事求说是有点低迷，其核心原因主要有以下几点：

其一，市场资金供给显著收缩，包括 VC/PE（风险投资/私募股权）新募基金的数量和规模出现大幅减少。这背后多重因素导致：

包括资新规后，银行、信托等渠道的资金受限，以及受地缘政治和美国高校影响，导致外资活跃度下降，手头有钱的高净值群体资金外流。

其二，初创科技公司，虽然前景好，但是风险高，在当前的宏观背景下，投资趋于保守，策略更倾向于投资中后期项目，对需要长期陪伴的早期科技项目（即“早早、投小”）变得更为谨慎。比较出的现象是，许多投资协议加入了要求创始人回购股份的“对赌”条款，实质上将投资风险转嫁给创业者，违背了风险投资担风险的本意。

其三，退出通道阻塞。在国内，早期创投资本主要获利退出方式是 IPO，这两两年，因为 IPO 审核收紧，导致投资资金被“锁”在项目中，无法形成“投资-退出-再投资”的健康循环。

换句话说，国内创投市场，因为“募、投、退”三个环节循环不畅，一方面初创企业融资难，另一方面资金又跑去抱团取暖。导致“早的死、涝的死”这种资源分配不均衡的现象有点演越剧烈的趋势。

这个时候，国家下场，启动国家级引导基金，就显得意义非凡。它和之前产业大基金（比如半导体产业基金）不一样，这些大基金直接对接产业链上的重点企业进行大规模战略投资，主要投向具备一定规模的成熟产业，旨在在集中力量突破关键领域的“卡脖子”技术，完善产业链，提升产业整体竞争力。

而国家创投引导基金承担的角色和任务是孵化初期创科技企业，类似于“国家团队天使投资人”一样。如果说前期的大基金是产业攻队，那么现在的创业引导基金就是整个硬科技领域开垦播种、培育苗。功能不一样，任务不一样，定位也不一样。

谈谈它的核心内容：

第一，钱从哪里来？

通过发行超长期国债，由财政部出资1000亿，随后通过引导基金-区域基金-子基金-直投项目的三层架构，扩大资金池，形成万亿规模。

通俗理解就是国家先拿出一笔原始资金，再吸引地方政府、央企、金融机构、民间资本一起跟投。

第二，投向哪里？

方向已经结束了，主要涉及集成电路、人工智能、航空航天、低空经济、生物制造、未来能源等未来新质生产力领域。

## 第三，如何投？

核心点就是早投、投小、投长期。

种子期、初创企业，投资规模将不低于基金总规模的70%。大佬文创圈拟投资的小型企业要求对对方估值在5亿元以下，且基金单笔投资不超过 5000 万元。

引导基金设置 20 年的存续期，10 年投资期，10 年退出期。在这点上，远超传统创投基金7-10年的周期，是“耐心资本”的典型体现。

对于国内初创科技公司而言，完全就是一场甘露，逻辑很简单，从2026 年开始，它们可以源不断的拿到规模相当的“长钱”，好好埋头苦干，啃科技新的。

当然，除了上述内容，还有3个关键内容值得赞：

其一，政府虽然是出资，但不具体事务，让专业团队进行管理。

其二，KPI考核，简单以单个项目盈亏作为依据。

其三，这次创业引导基金特别强调“不设地域返投”。

说说第三点：以往很多产业引导基金，由于地方招引、拉动GDP和税收因素，要求基金将一定比例（如60%-70%）投资于本地的企业，这就相当于地方保护，阻碍大面积竞争。

换句话说，现在确定的长三角、港澳、京津冀这几个区域引导基金，可以在全国范围内筛选具有潜力的项目，让资金优先走，从地方培养最优苗。

从某种意义上，我们的地方发展模式也会随之变化，以前靠发展变成未来工作。

总的来说，国家创引导基金启动，不是简单的基金扩容事件，而是亲自激活国内创投环境，给市场吃定心丸，强化投资信心。反映了国家在创投领域出现的变化。同时，也希望我们能够在总结以往经验的基础上，相关配套机制能做得更好，少点干扰，让这个重大创新举措更好服务于未来发展新质力的战略。

最后，说说哪些受益。首当初创公司，高校实验室、科研所等；其次是金融机构，包括券商等，试想孵化企业越多，意味着后续业务量会增加。第三的长期繁荣也是一个必要条件，创引导基金如何退出，“募、投、退”一定要形成闭环。也特别提醒大家，不要看到政策发力，本质是长期逻辑，从操作层面，包括资金落地、签约陪跑，单纯想短期靠“炒”获利，还需要长期视角去布局。
