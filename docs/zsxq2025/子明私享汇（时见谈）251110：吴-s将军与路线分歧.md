


# 吴石将军与路线分歧

发布时间：2025年11月10日

吴石将军直至1972–1973年才被追认为烈士，是因为路线在1971年才调整。在1971之前，是左派与鹰派当权；在1971之后，是右派与鸽派当权。左派与鹰派是主张通过侧重战争来解决问题，右派与鸽派是主张通过侧重外交来解决问题。

吴石将军的路线，是Z主导的统战路线，类似于解放战争时期倒戈的国军将领，属于不战而运之人，潜伏而定的路线。伴随着朝鲜战争，美国下场，统战路线宣告失败，使得走军统战路线的群体都受到打压。在71年之前那个段时间里，从LKN到PHN，Z的统战干将普遍没有什么好下场，吴石将军的功绩自然就没法拿出来。

随着基辛格的访华与中美签署二十余年的对抗，中国结束了与美国的对抗，最终我们转向了右派与鸽派当权，拿到了跟美国签署的联合公告，这也意味着祖国一将将从统战路线转向统战路线，就曾经贡献卓越的吴石将军便可以成为烈士了。

历史如今再次走到了十字路口，面对光明能否否扮演的最终选择，面对两岸路线的最终选择。沉默的荣耀和吴石能够被揭露全民知晓，是因为统战的力量要把他推到台前，毕竟对于目前热发展的东南沿海各省来说，和平统一——更符合大家的利益。

# 吴石

来源：整理百度百科

吴石（1894年9月14日-1950年6月10日），福建省闽县侯洲（今福州苍山区闽洲镇）人，先后毕业于保定军校第三期炮兵科、日本东京炮兵专科学校、日本陆军大学，中国国民党高级将领，革命烈士。

吴石参加过两次东征、平广州反动团乱、平直潭军杨响闽、刘武武装叛乱、抗战期间先后参加随延战役、豫桂战役、湘鄂战役、闽龘战役等，是中国政府中位高有权的人物，为中国共产党提供大量秘密核心情报，加速解放全中国的进程，是中国中共战线上的传奇英雄，也是一位“终极潜伏者”。

在台期间担任国防部部长课长，因叛徒身份被台湾当局逮捕，于1950年6月10日被枪杀于台北北区马场町。1973年，追其为革命烈士。

# 尼克松访华

来源：整理百度百科

1972年2月21日，美国总统尼克松一行抵达北京，对中国进行为期七天的历史性访问。访问期间，双方对国际形势和中美关系交换了意见，着重讨论了印支问题和台湾问题。

1972年2月28日，中美双方经过反复磋商，终于在上海发表了《联合公报》（又称《上海公报》）。《中美联合公报》的发表标志中美关系正常化的开始，以后中美关系的进一步改善和发展了基础。

# 中美联合公报（摘录）（1972年2月28日）

来源：中华人民共和国外交部官网2022年6月6日

应华中华人民共和国邀请，美利坚合众国总统理查德·尼克松从一九七二年二月二十一日至二月二十日访问了中华人民共和国。

双方回应了中美两国之间长期存在的严重争端。中国方面重申自己的立场：台湾问题是阻碍中美关系正常化的关键问题；中华人民共和国是中国唯一的合法政府；台湾是中国的一个省，早已归祖国，解放台湾是中国的任务，别国无权干涉，全美国武装力量和军事设施必须从台湾撤离。中国政府坚决反对任何旨在制造“一个中台”、“一个中国、两个政府”、“两个中国”、“台湾独立”和搞歪“台湾地位未定”的台湾立场。

美国方面声明：美国认识到，在台湾海峡两边的所有中国人都认为只有一个中国，台湾是中国的一部分。美国政府对这一立场不提出异议。它重申它对中国人自己和解决台湾问题的关注。考虑到这一前景，确认从台湾将推出全部美国武装力量和军事设施的最终目标。在此期间，它将随着该地区紧张局势的缓解和逐步减少它在台湾的武装力量和军事事务。

# 《沉默的荣耀》热播引媒体关注，国台回应

来源：整理自视新闻微信公众号 2025年10月15日

10月15日，国台办举行例行新闻发布会。记者提问，近日，大陆电视剧《沉默的荣耀》热播，引发闽媒体关注和报道。国台办表示，这部剧通过刻画历史人物，展现了中华民族精神，这符合两岸共同的价值观。
