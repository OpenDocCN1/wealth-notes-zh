


# 卢克文251111:聊聊我公司的一些心得体会

关于开公司创业，我讲过的个人经历，都是真真切切的血史，想创业或正在创业的，大家一读，可以当作沟通交流，应该帮一些朋友少走些弯路。

2010年我开始第一次创业，带着打工10年存下来的10万块汗钱，在广州白云区租了个民房开女装淘宝店，坚持了不到一年就滚回职场上班了。

这次失败的原因主要是选错了赛道，以及没有找到供应链。

女装赛道要会挑衣服，还有有女装工厂给你供货，你才能拿到优质且廉价的货源，注意“优质且廉价”是两个条件必须同时存在，拍摄、上架、开直播、刷单这些是次要条件，我当时只擅长后面的工作，前端货源我不懂，我就不会挑衣服，也只能在十三、红棉档口碑拿货，我没啥现金流，拿的货少，档口老板给的价格相当相同，同样一件T恤，我拿要50元一件，别人拿只要35元。

服装的生命周期又极短，三个月换季，春季没卖的衣服，到夏天就变成存在在那里，你又重新找货、重新拍图、重新上架。

做到三四个月的时候，就知道这生意做不成，每个月才卖十件衣服，房租都不够交，士气低，团队氛围非常差，每天都在熬时间，熬了一丁点小事架。

这次创业可以说是惨败，惨到我回去上班第一次发工资时，身上就只剩60 块钱了。

## 这次创业给了我三重大教训：

一是要要选择好赛道，不要做任何自己擅长的领域，像女装这种行业，我这种钢铁直男完全不懂产品，做了就是送死，如果我当时选择卖运动鞋、卖打印机，在当时的淘宝黄金时期，我估计八成能做起来。

二是要要将成本抠到底，一分钱要缩成两半花，所有不必要的开支一律砍掉，不要有任何高额的基础成本，比如：房租、工资、进货成本等。

三是要要搞定供应链，没有供应链不要谈创业，没有供应链的创业是自欺欺人。

这次创业把我折磨惨了，我体验到了从未过的的人生压力，那种“每天亏损、心急如焚”的痛苦感，折磨了我三三个月，但也极大提升了我的压力能力，以后遇到挫折，我一般都能无动于衷。

所以我常常建议大家，最好试试去创业一下，成功了，人生就上一个台阶；失败了，你体验过那种极度的痛苦，能练出一个大心脏，也会更懂得经营的不容易，懂得自己的能力到底几斤两，从而不狂妄、不自恋、不骄纵。

回去了五年班，这五年打工赚钱，买房买车娶媳生娃，2015年5月，33岁的我还还完贷，房贷也提前交了半年，卡里还剩两万钱，开始第二轮创业。

有人想不通了，干脆非要跟死磕呢？不创业不行吗？好好打份工不行吗？

真不行。

因为我30岁的时候，就做到职场天花板了，在电商总监这个岗位上磨了四五年，工资年薪一个个50万上下，再往上就上不去了，没有进步的生活让人非常颓废，感觉这辈子到了头，我不想人生的顶点，就此凝固在这里。

而且我当时一些淘宝技术，还想证明自己，感觉自己开店能赚更多，就不甘心，一定要再一搏。

第二次创业时条件好太多了，这五年在圈子里交朋友，到处拜访客户，供应链早就就不成问题，我甚至能多线发展，同时在灯具、女装、童装、艾条、小米电等赛道同时出发，一口气开了六家店铺。

灯具的老乡的工厂，女装直接用原公司批的货、艾条找的湖北供应商、女装找的虎网红同学、小米电找的中山的电器工厂。

大家一定很好奇，为什么这次，别人愿意给我供货呢？

道理也简单，你想收获，就要先付出，我都是免费给他们分享做淘宝的技巧，别人信任你了，才愿意给你供货。

> 切记，穷创业，一定要先付出，再谈收获，不要一上来就吐臭逼人谈条件，我们没有这种资格，我们要懂得别人占便宜。

那有人说，别人占了便宜不理我了咋办？兄弟，把格局打开，别人占了就占了，不要斤较，我们博的就是一个成功率，十个人占了我的便宜，总有两个人感谢我的，这两个会是我一辈子的恩人，其他八个人，他们只是人生的过客，不重要的。他们占了我便宜也改变了什么，但我只要获得20%的信任率，就可以改变我一生的命运。

有了供应链，有了淘宝经验，现在就差组团队了。

两万块钱不要说团队，连平时发工资维持团队都足够，这怎么玩呢？

我主要用两种办法解决了团队问题。

一是我自己边练边兼职，在各地继续讲课，让团队有现金进来，平时讲课一天500块，最高次讲课赚了一万块，彻底盘活了我早期团队，避免了遇到一点困难就解散了。

二是我在小区租了两套办公室的房子，请以前的同事一起来，付不起高工资，以底薪加提成的方式，底薪2000块，一人负责一家店，解决了招人的问题。

2015年这次创业早期非常顺利，有供应链、有淘宝技术，成本压到极致的情况下，当时用了半个月，做到了5000块一天，艾条店每天1500块一天，但利润高。童装销售不高但较为稳定，灯具和小电做得不好，不过每天挣几百块。

重要的是，我现在真正做老板了，现金流源源不断进来，不需要忙着处理所有的细节，真的比打工舒服多了。过了半年，所有的淘宝技巧突然失效了，营业额暴降80%，我跟我的小伙伴都被懵了。这么搞了一个多月，我想尽办法救店铺，跑去杭州找人算割，被一个骗子骗了我万块，回家后我气得哆嗦，站在台上恨不得从阳台下去。员工们也都受不了了，开始一个离开，最后我找最好的一个离开，公司只剩两个。

### 个人

其实创业的三大条件：成本、技术、供应链。我又丢失了技术这一个重要选项，又要重新开始。

我开始承受人生中压力时期：第一段是欠钱，第二段是广州创业失败——当时是很迷茫，真的不想回职场上班了，开始到处找朋友学习，到处拜访淘宝高手。广州有个做女式内衣的哥们，这时候拉了我，他带着我一起沿着广东和福建跑了一圈，看了几十个细分行业的老板，见过不少奇人，他们各自有赚钱的方法，有些老板虽然只是谈了几句，但你可以从中获得巨大的灵感。

对了，我以前写过那年在福建某市，看到几千万工厂车间里的壮丽场景，就是那段时间发生的事情。回来吸取了别人的成功经验，上手做了两件事：一是削减原来的店铺，专注重点店铺的直通车和销量排名；二是攻淘宝客赛道。在那个阶段，淘宝客曾经有一段非常好的红利期，爆发很快，赚钱很容易。又通过了这次危机。这时候我又面临重组团队的问题，我就在小区群里招工，小区邻居推荐他们来女孩上班，一下凑齐了十几个不到二十岁的小姑娘。给他们在租了房，又租了一栋别墅做办公室，开始了人生中最幸福的几年工作时光。就是我在[暂时没有中间派]这篇文章介绍过的，那几年，每天只要工作一两个小时，大部分时间都去爬山，别墅办公室里每天叽喳喳都是女孩。

2018年底，我因一时机缘误入自媒体，2019年4月突然大红，从7月开始，在深圳罗湖设立了一间办公室，招了三名员工。2021年我把办公室搬到了东莞，在东莞待了两年，再次重组自媒体团队，2023年又把团队搬到了成都，以此定居成都。前面我介绍了创业的三大基础条件：成本、技术、供应链。我创业成本低，别的公司可能还缺资金，基本上就是四大项了。再重复一遍，成本、技术、供应链、现金流，这是创业的四大核心要素，缺一不可。要创业前，一定要把这四大项都统一，不要胡乱创业。

### 有人说那团队重要吗？

其实团队是可以慢慢组建的，团队是必要条件但不是核心条件，我的团队不断打散重建好几次，都是先有业务再有团队的，团队是自然而然的事情，并不是你创业成功的绝对要素。最后我再想下这些年个人开公司的一些心得：做生意，最好不要跟人合伙。尽量不要跟合伙，因为人品不好、互相不够信任，产生大量的冲突。就算跟合伙人品很好，也会因为观点不同发生大量冲突。表面上看并不是深深的矛盾，但实际过程中会生死矛盾。比如我想把公司搬到成都，另一个股东要搬到上海，这种观点不同，最终导致溃灭。分利润、怎么分，这种事通常是散伙的主要因素。

第二个是，小公司一定要独裁，千万别搞民主，老板只要保证业绩优秀，自己舒服怎么来。跟员工沟通，只要业绩到位，怎么放松怎么来。老板必须对公司负责，要保证最高成果，亏了承担后果，不要让公司扩大模式，所有事情一定要短平快，遇到事情马上拍板，立刻投入，速度要看到结果，别磨蹭。再让员工对团队负责，不要对任何同事抱太高的期待，不听话的，这种人就是祸害。

第三个是必须杀果断。小公司气强，只要有一个人出了问题，他很快就会影响全公司。有人带头摸鱼，老板视而不见，公司很快就会一起摸鱼。有人业绩太差但是还能拿着不错的薪在岗位上，公司很快就会躺平。有人恃才自傲，帮公司赚了点钱就不断在公共场合挑战权威，很快就会不把老板放在眼里。这时候就要迅速炒，一点不要留恋，只要按《劳动法》办事就行，容不得有一点心慈软。凡是混日子的、水平太低的、不尊重你的，该炒的要炒掉。老板要切记，赚钱了，分一部分给同事们是你的责任，因为公司一旦亏损，从哪个方面来说，同事们的第一步就是跑，这世上不可能有人和你同甘苦、共患难。别人也要养，别人就是打工而已，既没有这个责任，也没有必要。

最后我想提醒一下，我说的公司经验对小公司有效，小公司短平快，是因为老板往公司一站，所有人都看到，所有事都心肚明。凡是公司做到一定程度，人多一起来，大家就开始乱。为了保证能对负责人，保证不乱，在大公司做事必须留痕，一留痕就必须有流程，一有流程大公司就开始变得笨重、迟缓，这也是大公司不得已的地方。不同的经验要用在不同的环境中，不能盲用，要活灵活。
