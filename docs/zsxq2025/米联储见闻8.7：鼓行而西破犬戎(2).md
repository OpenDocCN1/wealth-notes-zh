


# 米联储见闻20250807——鼓行而西破幻梦

这种骑墙梦终于还是破了，先有巴基斯坦空中挑下印度战机，然后是川大棒猛砸了印度，印度彻底从骑墙梦中惊醒。发展中国家就是发展国家，早先被G7追逐的好梦一旦醒来，才知道自己并不是什么美颜娇娇，还是那个光脚的酸酸的破户，最后环顾四周，还是要把目光投向兔子。

川总昨天发布了几个重大消息，虽然威胁了俄罗斯，但实际上上大棒直接打到了印度身上，从8月7日起向印度额外征收25%的关税，加上购买俄罗斯石油的惩罚，额外再征收25%，等于于是征收50%的关税。一下子，美印关系彻底打回原形，跌到冰点。

曾几何起，无论是民主党还是共和党，印度作为冲兔子的超大人口发展中国家，都是战略意义上的香饽饽。每次说起印度的人口和人口年龄结构，好像印度抱了一个大金矿一样。但是随着这几年产业转移，印度看不不到什么高回报的期待，印度基础设施的短板也支撑不起资本快速回报的诉求，发达国家对印度的态度明显开始从积极拥抱变成了消极应付，甚至是有些嫌弃。虽然川普在第一任期将奥巴马政府时期的亚太战略调整为印太战略后，川普本人更是亲自访问印度，让印度加入美日澳四方安全联盟的一员。印度还签署了《地理空间合作基本交流与合作协议》（BECA），后被广泛认为是双方已经是准军事同盟的关系。莫迪自2014年总统印度以来更是频繁访问美国：川普第一任时期，莫迪在2017年和2019年两次访问美国；拜登政府时期，2021年9月、2023年6月、2024年9月访问美国。2025年2月，川普上任不到一个月，莫迪就访问美国，是继以色列总理、日本首相和英国国王之后，特朗普2.0时代直接访问的第四位国家领袖，也是近年访问美国最多的发展中国家。

莫迪和莫迪身后的印度一度因为西方国家的高傲看一眼，产生幻觉：印度已经跻身全球强国之列，印度加入金砖都是屈就，印度真正的位置在G7。

随着美国调整全球战略，没用的都给我滚蛋，不交保护费的都靠边站，从来都是想占便宜不想出力的印度一下就变成不受待见的破落户。再加上巴基斯坦击空直接被击落6架战机，川普更是新闻发布会上公开嘲笑印度“一架飞机，右掉一架飞机”，嘻嘻哈哈之余，印度气了，莫迪气了，但美国也清醒了：指望印度制衡兔子，还不如指望日本，印度根还不入流，根本指望不上。豪门对豪门，竹门对竹门，美国干哈跟印度做朋友？一个连巴基斯坦都搞赢的印度有什么军事战略价值。

印度也知道川上台来者不善，2月莫迪访期间，美印就开始谈及关税问题。当时为了弥合贸易逆差，印度计划和美国达成数十亿美元军火交易，并进口更多美国石油和天然气，以缩小两国贸易逆差，并设定到2030年将双边贸易额翻番至5000亿美元的目标。但是半年过去，当日本韩欧等方都同美国达成了15%左右的关税，最早跟川普接触的印度被公开处刑，加征额外25%的关税。今年4月一起开始，美国对印度设定的关税税率是26%，而从4月到8月，印度同美国的谈判只取得了美国降1%的结果，这比完全不接触还糟糕。印度是打也打不过，谈有谈不着，结果被川普公开羞辱吊打，最后逼得莫迪老心不得不咬一牙，决定8月来访华了。没有什么比被巴基斯坦吊打后还要主动访问让印度扎心的了，可见莫迪老心真是急了。

目前，美国是印度最大的贸易伙伴，但是两国的贸易额并不是特别高。2023/24年度双边贸易额约1800亿美元，是兔子的三分之一有余。

但是考虑到中美贸易额，印度这点钱挣得不容易。印度近年来吃尽中美对抗，一边利用新兴国家的身份在西方世界受宠，一边利用兔子关系填补西方脱钩留下的空白。太久让印度误以为自己是大棋，是可以跟中美分庭抗的，结果遇到川普这个活阎王，毫不留情扒下印度的脸，学什么大国。川普对印度毫不留情，何况印度这种穷股。在川普看来，新兴国家都是国际秩序的挑战者，印度也是如此。2024年1月，川普曾公开威胁，要求金砖国家放弃新货币或支持美元替代计划，否则要收100%关税。

2025年7月初，特朗普警告要对与美国政策保持一致的国家加额外关税。在日韩欧盟达成关税后，美国对印度使出50%关税，对巴西加50%关税，南非面临30%税率并在8月8日正式生效。除了中俄，几乎都是金砖国家。可见美国人下手是很明确的，击打印度很简单。这轮对新兴国家动手，印度不得不继续谈判。印度终于明白，只有跟着兔子才有真正的机会。关税将印度置于巴西的行列，让巴西获得了同样的待遇。相比之下，印度从兔子拿多少好处？结果是双手空空，两头挨打。印度拦不住雅鲁布江修大坝，也没有从兔子嘴里抢食。

# 莫迪的选择与转变

今年2月，莫迪在白宫与川普会面，印度有意成为世界上最发达经济体之一，并用美国的话说：“让印度再次伟大”——简称MAGA。“当美国国家和印度联手，就成了超级繁荣伙伴。”川普听了露出了意味长的笑容。川普当时的内心里大概跟看戏一样，除了嫌弃，甚至有些暴虐：一个过去只能当奴的国家居然也想当爸爸？你算什么东西，还要跟美国一起再次伟大？这种言论从内到外让川总烦了，一个兔子发展起来可能比容忍兔子更难。

羞辱让印度看清楚自己到底是个什么。虽然美国想要遏制兔子，但是要遏制印度可能比容忍兔子更难。过去，美国之所以重视印度，尤其是拜登政府，是因为希望印度承接兔子的产业转移。但是现在对川普来说，产业都要撤回。印度跟兔子一样，不是朋友而是竞争对手，哪里还有脸色？相比之下，生产成本更低的印度是比兔子更讨厌的竞争者，所以关税必须更高，为了增加印度制造的成本，才会驱赶资本回到美国投资。

想法一变，优劣互换。过去是优势的人口、成本、发展空间，如今都成了阻碍美国再次伟大的不利因素。如今25%的关税已高于越南、日本和韩国等亚洲竞争对手，严重削弱相关贸易的可行性。加到50%，基本上判印度制造死刑。印度在药领域拥有世界级的优势，每年对美销售额超过100亿美元，也是印度重要创汇项目。川普表示，将在“一周左右”宣布对该行业征收一项可能高达250%的特别关税。扎来公司作为众多在印度投资的美国企业之一，最近在印度一家工厂投资了30亿美元，印度生产的仿制药占美国仿制药采购量的近40%。如果关税加到250%，几乎可以彻底干掉印度的仿制药行业。如果真走到这一步，美印之间就只有梁子，没有银子了。

在这种大环境下，时隔七年，莫迪8月底再度访华出席上海合作组织峰会就不难理解，这是他自2018以来首次访华。这次莫迪访华给中印举行领导会晤创造了可能性，潜在会晤中可能讨论的议题涉及进一步推进关系正常化，包括缓和边界地区紧张局势、恢复直航、重新开放边界贸易点以及加强人员交流。莫迪上一次访华还要溯到2018年4月，当时他赴武汉出席中印领导人正式会晤。实际上，这次免于宣布建雅鲁布江大坝已经意味着中印关系解了。
