# 【青云话题】

【沃尔玛通知我国供应商恢复发货，是等不起了吗？】近日，美国零售巨头沃尔玛被曝紧急通知我国江浙地区供应商恢复发货，引起了人们的关注。其中还明确新增税成本由美方承担。此前，沃尔玛曾试图将关税压力转嫁给供应商，要求降价10%-30%，导致部分企业暂停发货，此举被商务部约谈。

现在这一转变，多少显得有点“滑稽”，有人称，说越南印度等生产的东西西合格率很低，这侧面说明了我们的制造业水平在国际上具有不可替代性，至少美国短期是无法摆脱我们供应链的依赖。还有人说，这个转变就暗示了赌的就是时间，时间拉长，就知道害人终害已。

这个转变说明了什么问题？沃尔玛的“妥协”，是权宜之计，还是代价反噬？是否会引得其余企业纷纷效仿？而我国的断供对美影响究竟有多大？
