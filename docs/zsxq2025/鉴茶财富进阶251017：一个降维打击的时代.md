


# 一个降维打击的时代

打败师傅的不是统一的，
而是外卖；
打败索尼的不是手机，
而是小米；
打败服装的不是隔离，
而是电商。

如今，打败汽车厂商的不是，
而是互联网巨头。

传统汽车的盈利方式是：
1. 自己负责设计和组装
2. 从零部件厂商处进货
3. 从社会经营经销商分销

它的两大优势是：
自己有规模优势，能够控制流量上下，成为乙方甲方。
相比之下，要求经销商必须留车、交网费、先给它交钱。
自己有资本优势，能够强迫玩家接受的游戏规则。

比规模，比用量，小营销。说了，主机其实是大头，吃瓜汤的是中间商。

问题是：
1. 互联网巨头们比车企更有钱，也没有盈利压力。
2. 互联网巨头们比车企更有客户优势，更能灵活车。

以后出现的大量车，将成为未来的网络和AI厂商的打工人。已经退休的萌芽，是流量留给将来和尊贵的S800车。很多车不认命，努力死得越快。

京东的汽车已经快上路了，它不得不承认自己是造车的，自己是藏在背后的东哥在BAT面前只是小弟，在车企面前就是顶级大佬。
