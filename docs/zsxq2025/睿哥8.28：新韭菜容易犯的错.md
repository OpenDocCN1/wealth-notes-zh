


# 新莱亚经营的肺

来自：春明的投研
2025年08月28日 06:30

最近莱莱引入了不少新朋友，这其实是一个情绪指标，近期行情不在升温。通常来说，在这个时候的想法，往往是被行为吸引，被选择进股市推一把的。如果你有这种想法，就要当心一点。

在股市想得快，往往是任性的。
今天你有这个想法，大家讲讲，当事人新莱亚经营的肺。

## 一、资金

有人说：现在有备资金，涨会有很多理由。
未来并不是一个开始，备仓不能低于以下：

- 1. 看到韭人
- 2. 总想赚，想总是个错
- 3. 没有不切收益预期；比如新莱亚的收益率是5%-10%
- 4. 错失机会，盲仓睡觉
- 5. 空直盯行情；
- 6. 直盯着计划，不动就离；这都是在制度优越，本质上是来自自尊的表现。
- 7. 主动战胜，跟人比战。

人是一个很奇特的生物，已经自己觉得累，往往容易，还有几个人都不敢靠自己。

## 二、分清底气和实力

股市这个地方很难，有时候，连孩子都能轻松而容易地赚钱。
之所以是，越是不聪明的人，越觉得自己聪明了。
更有钱的人，越是聪明。这个时间的收益性就越高。
他是这里公认为自己是股神，简直是用运气打胜仗。
股市的往往不分清赚到的钱是靠运气当成实力。

在股市里挣钱，千万不要以为这不是本分的事。这属于运气时代。
就前几天还有很多人在房子上赚到钱；
这不过遇到面对面，带了坏，最坏的都是持有信。

做人必须保持谨慎。
大家做股市的这条路，都是聪明人。
只要你有自知之明，在股市就能赚到属于你的收益。
而有自知之明的人，股市现实就困难，可你又不是老韭。
即便你账户有3000万，也不会留下留痕。

## 三、错误的行为是被纠正的结果

在股市里，你会看到很多表演技巧。
他们可能是错误的跟涨，而又在鼓励你的跟涨，让他们让你亏了少钱。
在我们生命中经常遇到这种。

比如，很多商家靠亏损弥补了少钱。
小错错认亏了少钱。
如此，如果一直做下去，将在自作自受。

市场可能会给我机会的，也许就是继续下去停停。

每当遇到困难的事情，人都会发现自己，然后又会去执行错误的行为。
很多投资习惯的环境就是脆弱的。
你也许可能也不理解为什么散民A股没有价值了？

世界是公平的，只要坚持正确的，就会有的回报。长期坚持错误的，就会被惩罚。
看着等待一定要补这个错。

## 四、容易丢失自己的自己

很多人为了跟波动，操作大开火。
动不动就会亏损。
小明说：反正我发现自己不是一个人用这种方式发财的。

市场的风险就是容易丢失自己的自己。
一路踏空，越难越的接回来，就用更高的价格接回来。
而你持有的成本还没涨后，就再也忘记亏损了。
多卖几伏就能保持自己，在市场边缘被别人仓进去的。
千万不要被套牢，在资金充裕的时候，很少人被群众簇围。
等到看到亏损时，你就不会卖出来了。

大家都想过，市场什么时候结束？
也过一段时间，市场变大的变化？企业变大的变化？我们的人的情绪完全忘了不要？
在股市里，有时候亏损，也要接受。
股市有几种方法可以你。

比如，上涨的过程中，突然遇到暴跌，并伴随着各种故事，导致散户离场。
再涨，经过一段时间，你可能开始热热了，就又忘了套了。
在市场上一过了一段时间，会有经常的亏损，这也不让你被套牢，你不是这样？
很多时候都翻了。

比起很多基金公司股票涨起来了反转了，之后才开始做调研。
因此，在实际市场上，机构也不比散户有优势。
大家要把光一直拉长，一年一年会像去年左右，不要被A股短长线这种话给骗了。
我们就可以看着涨套仓，要不要套牢，一定要记得做好。
