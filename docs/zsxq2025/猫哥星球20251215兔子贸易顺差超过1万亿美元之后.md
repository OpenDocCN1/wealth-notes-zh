


# 兔子贸易顺差超过1万亿美元之后

### 猫哥原创

这个事有点热，热的原因就是这个顺差金额在人类历史上是史无前例的高度，让离方集体破防，公众号我会分析兔子贸易顺差为什么会达到这个高度，知识星球我就会专门写一份对我们普通人的影响。

前几天与朋友撸茶聊天，朋友提出一个建议，建议我有机会还是转部分资金去香港，原因就是香港存款利率远高于大陆。

对于朋友的建议我是不大认同的。

全世界利率差万别，如果仅仅做个资金搬运工作，将资金从低利率国家运到高利率国家——就能实现无风险套利的目标，简直就是天上掉馅饼。

按照这个思路，都不用将钱运到香港了，直接去俄罗斯不更好？俄罗斯年利率是20%，存一年就能拿到20%利息，比香港高多了。

但是天下哪有这样的好事？

在不同经济体通过利差套利，一定有一个汇率风险，就是不同货币的汇率波动风险。

我们以香港为例，香港存款利率高于美元计价的存款，目前年利率大致是3.4%左右，比大陆整高了2.4%左右（国内大致是0.95%），我们假设目前人民币兑美元汇率是1:7，你想办法汇出700万人民币到香港，可以兑换100万万美元。然后存入银行，一年后可以获得3.4万美元，相比国内利率增加了2.4万美元看起来很不错不是？

但是有一个问题，未来一年人民币兑美元汇率会怎么波动？

假如，人民币贬值了，对美元汇率从1:7变成1:8，那里还有额外100万人民币的汇率贬值收益，但是如果未来人民币升值呢?从1:7变成1:6.5呢?那你汇率损失就是整整50万人民币，相比那点利率收益简直不值一提。

那么未来对人民币汇率还看空还是看多呢？

现在我们来谈一谈外贸顺差的问题。从2021年开始，兔子对外出口贸易顺差持续扩大，2021年—2025年，预计兔子外贸顺差应该超过3万亿美元。按照道理，这么大的外贸顺差，人民币汇率应该升值强劲，但是实际情况呢？

人民币汇率走势却出现走弱的趋势，从2022年4月开始，人民币兑美元汇率从6.4一路贬值到7.35，现在有所回升，目前是7.05左右。

为什么兔子外贸顺差巨大，即便除去服务贸易逆差（每年2000亿美元左右），4年累计外贸顺差应该超过2.5万亿美元，结果人民币汇率不反升降呢？

两个原因。

其1，美联储从2022年4月开始暴力加息，最高点联储利率超过5%，中国国债利差超过3%。

其2，2022年开始兔子房地产持续下行，基本是连跌4年，对经济拖累较大。

因为这两个原因——中美无风险利差扩大，叠加对国内经济看空，所以外贸企业在出口产品获得结汇之后大量选择留在境外套利，虽然4年时间，我国出口扣除服务贸易逆差之后累计顺差高达2.5万亿美元，但是大部分资金不回结汇。

而且境内大量资金又有出境套利的需求（光是2023年，大陆资金借道去香港买理财险高峰时期增长了26倍，导致人民币在外汇市场上需求上升下降，自然人民币汇率走弱）。

但是现在整体逻辑已经出现巨大的变化。

其1，美联储已经开启降息周期，今年降息三次，目前美联储利率在3.5%左右，与兔子利差已经开始缩小，我们还是以香港存款利率为例，目前利差大致在2.4%左右。

其2，房地产已经连跌4年，虽然还没有企稳，但是预计明年即便继续跌对经济拖累效应已经大幅大幅减小。

其3，兔子产业升级开始发力，今年贸易顺差预计在1.2万亿美元左右，明年可能达到1.3万—1.5万亿美元，兔子制造业开始有了横扫全球的势头，所以，最近世界银行与国际货币基金组织纷纷上调了明年兔子经济增长的预期。

所以，从2026年开始，人民币汇率我是坚定的多的。

所以，现在将资金从大陆转移到香港或者其他国家未来风险大于机遇。

我们还是以香港为例，假设我们现在转移一笔资金去香港存钱，就算是利率锁定3.4%，比大陆高出2.4%左右，但是只要明年人民币兑美元汇率升值超过2.4%，这这一套动作下来，反而是得不偿失。

那，明年人民币汇率会升值超过2.4%吗?
