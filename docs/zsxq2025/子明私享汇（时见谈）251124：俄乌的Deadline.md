


# 俄乌的 Deadline

发布时间：2025年11月24日

11月北京线下读者会系列内容：关于读者对俄乌冲突问题的回答

站在去年年底的角度，我对俄乌冲突中中美冲突的缓都偏观了，认为控制了参俄两院和最高法的特朗普，会在上台的首年取得突破性进展。

经过这一年来来看，虽然特朗普是真的想取得进展，破天荒地一再邀请老板访美，顶着巨大的压力，将普京带来了阿拉斯加来会晤，但中美的正元首会晤会被拖到明年，美俄的停火协议预计也要被拖到明年。

美方内部的阻力只是其中的一部分原因，更重的是俄元首非常熟悉特朗普，都认为被拖到特朗普的 Deadline，能够拿到最为优厚的协议。

而这个 Deadline，就是特朗普的中期选举。

所谓 Deadline，是中美很清楚地知道，不能拖住中期选举，一旦特朗普中期选举失败，失去了两院中的任何一个，特朗普都可能丧失现有的权势，届时中美、美俄的协议都可能出现变数。

# 美乌联合声明：已起草更新版和平框架文本

来源：央新闻 2025年11月24日

当地时间11月23日，美国白宫发布联合声明称，美国与乌克兰代表团在土耳其就美方提出的结束俄乌冲突“28点”新计划举行会议。

声明称，此轮会议“成效显著”，双方在对齐立场、明确下一步路径方面取得了“有意义的进展”，并共同起草了一份更新后的和平框架文本。

声明强调，最终决定将由美国总统和乌克兰总统做出。
