本轮金融战，美国联日本，将人民币资产推向死地。也造成了我们巨大的痛苦，我们的内消耗相当于反击一口，让西方的产业界很痛苦。你来往之中，彼此都是输赢。

其实，最近，村里的动作炸裂，大家有很多要说明。是在离岸市场发行40亿美元的主权债，然后，又发行了40亿欧元的主权债。这两次发行，都相当成功，每次都是接近30亿的认购抢购。

或许我们就要问了，为何此时要用美元去发行自己的主权债？本质上，就一句：

## 借荒地

结合前两期的分析，大家也都看得出来，目前我们跟其他国家进行激烈的全球流动性争夺。出口，不过我们用商品进行激的流动性争夺的一种形态，但是，不够。

如果我们在金融领域发力去更积极地参与到全球流动性争夺，就会遇到一个问题：

## 如何定价我们中国的主权债？

这次，我们分别用美元和欧元去发债，规模这么小，就是用美元和欧元的信用，去测试全球市场如何计价中国的主权债。毕竟，将来还债的，可是里村。

从实际发行角度来看，效果很好，市场对于中国主权债的认可度极高，甚至很多人抱怨发行太少，买不到。

那么，这里想象力空间就出来了。

如果我们来发行无限期限的离岸主债（哪怕还是欧元或美元载体），比如3个月期的、5年期的、10年的等等。不同期限的主权债有收益率，就可以形成一个中国主权债的收益曲线，这就完成了定价问题。

这个东西一旦建立，将不用美元或欧元去发行，直接用人民币去发行，可以了。到了这一步，美国再来玩，就不是那么简单了。

当然，中国并不以此为终点。目前中国利用离岸市场的利和发展，逐步推广“黄金”。按照框架设计，未来其它国家可以从离岸市场购买人民币；也可以用人民币直接换黄金。也就是说，人民币用黄金储备，也就逐步形成了。

从生产体系到人民币国际化，前景，崭露水面。

## 收益率依旧不足

这个之所以如此快速推进，也要感谢美国，尤其是拜登和川。这两位的微操，实在不行。

美国体系外，其它国家陆续的，都想要寻找更多的资金。可以说，如今在美元体系外，建资金池，是许多国家的安全诉求。就像欧洲用美元换机制“武器化”，相当于全球GDP。如果有一天美国问怎么办。

其实，中东、日韩有很多经费，都有类似的担忧，慌得。眼前，就地崩塌，实力大国还得出手。别看欧洲内向，也看美国，硬捍。

三国虽然都可以提供一定程度的“安全”，但是俄罗斯提供了不了稳定收益”。能够提供“安全”，又能提供“稳定收益”，就剩下中国和美国。问题是，拜登时期严重配合，现在大家觉得有点慌。这里就是人民币体系最大的历史危机。试图，如果更多国家将自己的储备放在人民币体系，那么，人民币资产会有任何反应吗？就是说，在国内进行的金融变革，更大的变革是离岸人民币体系的构建。这里希望体系互补，避免这些金融变革困境，同时也为未来获得国际资金提供循环。不过，即使如此，人民币体系还有一个月：要确保收益率提高，就需要国内来加杠杆。可是，居民家庭、民企、地方财政，都是措手无策。

如此，加速国内体系的扩容和体系化，重要企业稳定，就是接下来全面推进。让他们去杠杆，提高投资收益率，才能更好的引导全球流动性的进入。请注意，这将是12月份会议中必须推进的事宜之一。

全面实施中央财政负债表扩容，是中国经济下一步必要的。这个比货币刺激更关键。其实，现在美国也在努力降低自己的融资成本，这本意我们是一致的。通过打压油价、债务、各自采取生活成本等微调，美国在重塑生产要素市场。只是不过，美国的这些做法都是相同的，且难以持续，中间的阻碍实在太多。在大国博弈时代，美国现在已经认识到，直接抓我们做不到。

此，通过地缘陷阱和外围渗透，两个维度来抬高中国获得全球性的融资成本。与之对应，中国在各种反制，疯狂击美国边的盟友，是在变相提高整个美元系的融资成本。

这就形成了双方在战期间的主要博弈焦点。美国经济和金融市场，现在全哑。而他们最大的一个优势在于，折利率到底是多少，无法确定，就无法精准立未来的值、投资回报率等。所以，中国渐进地打击美国体系的融资成本，就会有小的战果。

当前，美国是全球的甲方，中国是最强大的甲方。但是，当下，甲方的力量相对更大，乙方相对受到压制，这是不争的事实。虽然我们已经做了很多工作来美国单一市场的依赖，却依旧不够。在此，12月份的经济形势会增加更多支持消费的举措，也是势在必行的。

过去，我们尽量排除投资，然后换非人民币，好像就能托付GDP。现在，经过了多的波折，已经做不了了。必须正视一点，2026年要保住5%，压力在前，这是全球经济基本面决定的。因此，让更多国家使用人民币、结算人民币，实则是对国内消费增长的一种需求倒逼补充。眼下，随着中美博弈进入深水区，我们也要注意到，现在的美元体系不再是“闭环”。

外循环（商品美元），不再是统治性的，而是各国本币结算；内循环（金融美元），在部分头部领域失效了。这意味着我们将面临一个巨大的风险。美国经济和金融市场的失效，正在成为中国根基。人民币资产未来怎么走势，依旧离不开几个规律：

- 1. 先险后房
- 2. K型分化
- 3. 央妈为主，主动放水为辅
- 4. 先进制造业，内部扩张
- 5. 自主可控
- 6. 进场策略，优势在新能源—黄金—自由贸易—制造业类

这是目前的核心组合！它们环环扣，缺一不可。对于个人投资者而言，不需要摸，只要在这个熟悉的细分赛道，那么你就可以跟进一起。此外，对于目前的地缘博弈，不要太忧虑。因为里面的东西，其实很简单：有利于大国生态。也就是说，就是不要出去搏命，而是要共生状态。

对于大国来说：

- 1. 人口问题。
- 2. 高龄化趋势，速率不同。
- 3. 维持人口规模的红线。
- 4. 数字。

其它国家，就不用说了。然而，能够做到加速提升的，只有我们一家。这意味着我们可以用高劳动力生产来应对人口压力。因此，我们不是在做什么大国博弈，是在为自己的生存。试想，或许我们就赢了德国和日本，但是人口问题妥妥处理，结局很好。其实，人民币资产的走势，最后有一个趋势：构建稳定、完善的国际体系。

人民币价格的走势，不仅仅是看美储的货币政策，不仅仅是美国需求不够，是大国博弈，更要看人民币内外机制到位。今年，主力高度控盘，将大A拉到今天的位置，也产生了积极的全球反馈。这也直接鼓励了让他们意识到，这是一条非常战略的路。而要全面提升，依旧离不开房产。毕竟，居民家庭的左右财富在这里；银行信贷的合格抵押在这里。于是，我们可以看到策略：先用大A和大规模的基础、工业投资托举美国需求；等这些力量边际递减的时候，再逐步用产业接力托举。因此，12月份有关地产的政策不会特别多，因为现阶段属于前期。等这波需求的效果边际递减明显了，外需也跟上了，地产又要动了。本质上，这些都是工具，都是服务于国家宏观目标的。我们根本不需要去区分，哪些工具我们喜欢，哪些工具我们不喜欢。跟着核心之子的意志和信号灯走就可以了。先防后军，这个策略依旧有效。因此，后续大A还有空间，行情还有走光。
