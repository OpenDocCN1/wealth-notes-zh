# 人生哲理

![](img/e8e843a949516ba4d2a1f0d6c48a35305a_0_0.png)

Michael Simmons 的一篇“信息茧虫自救指南”，非常适合当今信息过载的情况下下阅读，对于一个手机上没有抖音快手，没有新闻软件的人来说直抒同感。

> “我们消费的信息和我们摄入的食物一样重要。它影响着我们的思想，我们的行为，我们如何如何理解自己在世界上的位置，以及我们如何如何理解他人”——Evan Williams, Twitter和Medium的联合创始人

现在，在世界的某个角落，有一段文字、一章内容或者一本书，只要你读过，就有可能改变你的人生轨迹。我把这种内容称之为“突破性知识”。

在这个信息爆炸的时代，寻找并掌握突破性知识的能力，是我们需要学习最重要的技能之一。我们每个人都曾有过类似的突破性体验。是父母、导师或老师说过的一句话，深地改变了我们的思维和行为。或者是一本书，深地震撼了我们的内心世界。下文将这些书籍简称为“动能书”。

比如，沃伦·巴菲特的“动能书”是《聪明的投资者》，他在19岁时就阅读了这本书。这书为他的投资哲学奠定了基础。

而埃隆·马斯克的“动能书”是《银河系游指南》，他表示这本书帮助他思考更更大的问题，从而解决世界上更要的问题。

我最近的“动能书”是《穷查理宝》，它是白手起家的亿万慈善家·查理·芒格。这是我第一次接触心模型书籍。通过学习和应用心模型，我成功开启了新的事业。一次突破性的体验可能持续几分钟，但它的影响可能伴随我们一生。这就是学习的杠杆效应。

现在，尝试一下，如果每年都能有一次突破性的知识，而不是十年才有一次，或者一个月有两个，而不是一年只有一次，那么将会带来翻天地的改变！这并非不可的梦想。

考虑到突破性知识的强大影响寻找的难度，我们都需要面对一个基本问题：如何在有限的时间中，在纷杂复杂的信息中，找到能够改变我们的突破性知识？

这个问题引起了我的兴趣浓厚。作为一个阅读过许多畅路教科书的人，我多年来一直在反思这三个问题。我的书架、亚马逊购物车、Kindle电子书和 Audible愿望清单积攒着数百本我渴望阅读，却没有时间阅读的。因此，我形成了一个真正的“无味的阅读列表”。

随着时间的推移，我开发出了方法来应对，这是基于我的经验，并且借鉴了世界上顶尖企业家和领袖（包括埃·马斯克）的学习方法。然而，在我们开始采用这种方法之前，我们首先需要理解这个问题。正如哲学家查尔斯·凯特林（Charles Kettering）曾过的：“一个问题的提出，就等于问题解决的一半。”

## 一、引发信息末日的四大问题

信息过载是一个重大问题，但实际上，它是由四个各自指数级加速化的问题构成的，它们汇集在一起，就能引发一场巨大的危机。这场危机可能会让我们集体变得无味，而非更加醒明，让我们分崩离析，而非固团结一致。这场危机有许多称呼，但我认为最为恰当的是信息末日（Info-Apocalypse）。引信息末日的四大问题包括：内容冲击、信息茧房、持续性分心以及错过恐恐惧（FOMO）。

### 1. 信息末日问题一：内容冲击（Content Shock）

> “信息的大量倒入导致了注意力的极度匮乏……”——赫伯特·西蒙（Herbert A. Simon）

随着在线出版和社交媒体的发展，我们可以接触到的知识正在飞速增长，我们人类的信息处理能力无法跟上这种速度。同时，每天，每一秒钟都有更多的内容涌入眼帘。问题在于：我们如何从中挖掘海量新信息，学习新技能？这些信息深藏得太深，我们几乎察觉到它的存在。

### 2. 信息末日问题二：信息茧房（Echo Chambers）

随着群体规模的扩大，它们往往走向不稳定、多元化，最终分化为各种种子群体。这种现象在宗教中表现尤为明显。犹太一直在发展，直到分裂成多个不同的教派，其中一个分支发展成为基督教。基督教发展后，又分裂为天主教和新教。新教发展后，进一步分裂为浸信教、卫理公会、路德教等。这种现象在每个群体领域内都存在。

每个群体都会发展自己的语言和文化。尽管提高了群体内部的沟通效率，信息的输入输出却变得更加困难，因为它必须经过语言和文化的转译。每个群体都会根据与其他群体的差异或发展发展一种身份认同。这些群体之间的观念堡垒会导致极端化和偏见的产生。

在宗教和政治领域，这种现象尤为明显，但实际上，它在所有领域都存在：过于商业化的艺术家被视为“背叛者”。企业家常被认为只于理论、脱离实际。许多从事自然科学的学者，甚至不认为社会科学是真正的科学。与畅销书的学者，常被视为不严谨。问题在于：每个群体都生活在自己的茧房中，他们认为这就是“真实”的世界。在这个社交媒体和算法推荐流行的时代，更加孤立，因为我们接触到的信息越来越少。

### 3. 信息末日问题三：注意力涣散（Distraction）

五年前，我有幸遇到了 Meetup 的创始人，他告诉我了一句：“如果你现在觉得东西容易让人瘾，那么等到以后后再评价它。”如今，我们的时光已经流逝，我们与移动设备、互联网以及社交媒体的关系经历了人的转变。随着时间的推移，我誓要卸载所有的社交应用，尽管如此，我发现自己已经在战斗中。我曾尝试屏蔽 Facebook、Twitter 或 YouTube，但每一个都是重要平台。

市场专家、软件开发者和增长黑客利用这些信息来抓住人的注意力。为了达到这个目标，他们每年都有数十亿美元的投入，甚至开发了基于广告的模型或虚假信息，形成了一股不可忽视的力量，不仅分散了我们的注意力，还阻碍了获取更有价值的信息或实现目标。

### 4. 信息末日问题四：错过恐惧（FOMO）

如今，相比十年前，吸引人的“值得一看”的内容比任何时候都要丰富。然而，更多的选择并非好事，事实上，这种选择的多样性很快就会让人不堪。对我们来说，放弃优质选择是非常痛苦的，这种现象在心理学上被称为“损失厌恶”。此外，由于优质选择如此多，我们经常面临难以判断哪个是最佳。例如，对于未来的职业规划，我们应该阅读有关数据科学或人工智能的书籍吗？我们应该提升自己的沟通技巧成为更优秀的领导者？或者，我们应该探索最新的健身方式、饮食习惯或教育方式来提升人的质量？这些每一个都是重要的，在这些选择之间权衡，就像是在苹果、橘子和杏仁之间选择一样复杂。这类决策在心理层面上极具挑战性。问题的关键在于：由于优质选择过多，加之对最佳选择未知，我们总是在不断怀疑自己是否做出了正确的决策。结果：媒体垃圾食品。这个推拉扯（注意力冲击、信息茧房、注意力持续涣散和FOMO情绪）使得未经过思考的普通人容易沉沦在“媒体垃圾食品”中。他们会随意浏览推荐的内容，轻松点击那些令分心的信息，而当面对选择时，却往往感到不确。

“食物沙漠”是指那些地理位置偏离，难以以合理价格获取新鲜食物的区域。对于那些未经熟悉的人来说，互联网越来越像一个“信息沙漠”，充斥着大量的低质量或误导性的信息。更让人担忧的是，很多人在这样的环境下误以为自己变得更加聪明了，实则恰恰相反。

这就是问题所在，解决办法是什么？

虽然信息末日描绘了一幅渺淡的地图，但从另一个角度看，突破性知识和信息比任何时候都更加丰富和触手可及。现在，来自世界顶级知识越来越容易获得，其中大部分都是免费负担得起的。预测，到未来九年内，人类所创造的科学知识将达到水平的两倍。如果我想学习舞蹈，20年前，我只能找到本地的专业课程或阅读相关书籍。在今天，我可以轻松在YouTube上找到27.7万个相关视频，并从中选取一个来学习。此外，我还可以用180美元的价格购买Masterclass 的全程通行证，从罗斯·华华（Ron Howard）那里学习艺术，从阿隆·索尔金（Aaron Sorkin）那里研究剧本，或者从马丁·斯考斯（Martin Scorsese）那里深入了解电影制作。在这种情况下，我们必须谨慎地挑选我们消费的信息，我们实际上是生活在一个充满了无限可能的信息荒漠之中。这是最好的时代，这是最坏的时代；这是智慧的时代，这是愚蠢的时代；这是信仰的时代，这是怀疑的时代；这是光明的季节，这是黑暗的季节；这是希望的春天，这是绝望的冬天；我们眼前拥有一切一切，我们眼前一片荒芜；人们向天堂，走向地狱。

如何快速获取突破性知识，如何在噪音中找到信号？这些技能将在未来转化为巨大的优势。这些人仿佛生活在一个“甜味”之地。这是一种被普遍忽视的技能。将充满危机的信息世界转变为乌邦，关键在于我们需要从被动接收信息向主动筛选获取信息。我们不能盲目依赖摘要、默认通知、算法推荐，这些设计的目的只有一个：在短期内尽可能抓住你的注意力，而不是在长期上你的利益。

## 解决方法一：提出问题，从增强性认知中筛选

- 1. 自己一个简单的问题，帮助你从增强性认知中筛选突破性知识；
- 2. 使用更高价值的新格式；
- 3. 学习一项技能，这将系统的帮助你。

核心的就是明确区分增强性认知和突破性知识。一旦你明确了目标，找到它毫不容易。就像我们已经读过二十本相关的书，然后又读了一本一样的书。增强性认知通常只引起你的兴趣，很快就会遗忘。相反，突破性知识会挑战我们关于世界运作的基础信念，或者提供一种全新的视角。这种增强会深刻影响。识别潜力的突破性知识其实并不难。在接触任何内容之前，我们都会问一个具启发性的问题。

## 解决方法二：意识到信息过是一个古老的问题

古老的解决方法值得一提的是信息过其实是一个由来已久的问题。信息过的速度可能在增加，但这个问题本身不是新兴的。人类的集体积累以一种超过我们能力的指数速度持续增长。自以来，哲学家、思想家和知识分子一直对信息过发表评论。罗马哲学家塞卡（Seneca）曾：“无穷的书籍和图书馆有什么意义？一生都难以阅读这些书。学习者并没有从中受到指导，反而被它们的数量所压垮。”塞卡的观点强调了，仅仅拥有大量的信息和资源，并不意味着能够从中受益。相反，过多的信息可能成为一种负担。1962年，詹姆斯·米勒的研究强调了处理信息输入的重要性，表明人们必须对信息的处理和应用进行调整，而不是无节制地吸收。2007年，大卫·弗斯特·华莱斯特更进一步，他提醒我们，在处理大量的信息时，维持开放和灵活的心态是至关重要的。与所有古老的问题一样，人代代相传地试图解决信息过载的问题。虽然大多数尝试都失败了，但确实有一些解决方案一直存在，并且它们非常有价值。其中一个解决方案就是寻求具有高价值密度的知识格式。社交媒体上发表的帖子，通常是一个作者最好的想法。在某些情况下，如果他们发表了一篇长文章，这可能是他们这个月最好的想法。一本书有价值的，因为它包含了作者心中最好的想法。它还经过了仔细的审查、批准和编辑。书籍想要更有价值。在过去的五年里，这类摘要的制作已经形成了一个小型产业。如果你在亚马逊上搜索任何一本畅销书，可能会发现若干个相关的版本。



我其实难的是哈莱姆区的一所高中，那里更像一座监狱，而非一个教育机构。所有的窗口都被木板牢牢封闭，建筑外部布满了涂鸦。为了进入学校，我还需要经过金属探测器的检测。学校四周是围墙和围栏，几乎是一座孤岛。

与此对比的是，我的高中环境优美，周围满是鲜花、运动场和茂盛的树木。在那届毕业生中，几乎每个人都有机会进入大学深造。

当我踏入哈莱姆的那所学校时，我感到一阵深深的悲哀。谁能说这里的机会是平等的呢？学生们选择哪所学校，归根结底取决于他们想要的地方。

这种差异不仅让人心痛，而且更让我担心的是，网络世界可能会孕出比现实世界更大的不平等。尽管互联网理论上为每个人提供了平等的机会，但并非每个人都理解如何管理信息并充分利用这些机会。

这种情况导致了一部分生活在信息过剩的混乱世界里，而另一部分人则享受着信息丰富的。如果我们不积极学习网络环境的技能，并将这些知识广泛传播，我担心的我们的社会将逐步极分化。

如何去热爱自己的事业？从自由者看来：

> “财富自由之后想做什么就做什么，现在就该做什么做什么，这样的工作才是理想的工作。这样的工作，你会很开心，能够学到东西，充满激情。每天从床上爬起来，一天不工作。”
——巴菲

我们之前看过的巴菲特的演讲，很多人被这段话所打动。或许热爱的事需财富自由后再去考虑，我们现在就可以开始实践。

但依然会露出很多现实问题：
- 热爱可以变成职业吗？我不确定喜欢的事情能不能够养活自己。
- 现在的工作让我没有时间去尝试喜欢的事情。
- 我要辞职吗？没有收入怎么办？

自己分享的文章来自Dan Silvestre，他通过设计“最小可行生活”，有计划的平稳过渡到了一名内容创造者和教练，并成功运转了10年。

如果你也想实现“一直热爱的事”，这篇文章一定会带给你启发。原文很长，以下是核心内容：

1. 最小可行生活 (MVL) 和最小可行产品 (MVP) 类似。可以用相对成本的测试你喜欢的事情是否可行，并不断迭代甚至重新尝试。
2. 首先你需要评估的财务状况（包含储蓄和支出），从中抽出一笔梦想基金，计算自己已在无收入的情况下，为自己喜欢的工作做了多久。
3. 为提高测试成功的可能性，重点是延长测试时间。
   - ① 减少非固定支出：包含住房、聚餐、会员等开销。
   - ② 增加额外收入：在自己工作的同时，可以抽出小部分时间兼职，这些收入将会流回你的梦想测试基金。
4. 一旦收入开始覆盖日常开销，你的“热爱”就有持续运转下去了。

# 每个人都可以自己喜欢的事

外面下着雨，天气与我的心情形成鲜明对比，我喝了一口热茶，写了一些，然后又写了一段。我越写越多，我就越清楚我想说什么，我一步下去该去哪里。键盘发出的“咔哒”声和雨落在屋顶上的声音融为一体，如果还有声音我听不到，我进入了心流状态。我是大脑思考的翻译工，我可以在屏幕上感受到思考和联系。多奇的感受！我喜欢我所做的事。

过去六个月，我一直在做我的工作。回想大学毕业的第一年，我做过一年的自由职业者，然后搬到瑞士一家技术公司，九个月后，我意识到我更喜欢以前的生活。我是回到了起点，但是有了一个计划，一个开始的计划，我开始做一个【生产力黑客社区】，并开始认真写博客。依靠一个简单的商业计划，我对接OKR作为反馈循环，我开始自己工作了。

在这个六月里自己工作的时间的，我得了比以往要更多的成果。这些经历教会了我一些事，最重要还是改变了我的视角：我现在遇到事情变得坚韧。

我预计大多数事都会变得精通，如果你肯付出努力并养成每周复的习惯，最终它不仅变得容易，而且变得更好。这不是篇劝熏的文章。这是我在过去5年中学到的关于工作和幸福的浓缩精华。通过构建最小可行生活，学会有计划的改变原来的工作和生活，真正实现一直热爱的事。

## 什么是最小可行生活

在科技领域，大部分公司都是通过开发最小可行产品（MVP）开始的。构建只有一个核心特性的产品，以便从早期用户那里收集反馈。这是测试和探索产品方向的最简单方式，少即是多。

## 最小可行生活 (MVL) 遵循相同的逻辑：

- 找到你生活中的“核心特性”：所有对你生活没有价值的事情都不是核心，你可以没有它；
- 设计最简化的版本：一旦你只关注你生活的核心特性，你会发现你已经可以为自己工作了；
- 收集反馈并根据需要进行调整：MVL不是一次性的，而是一个持续不断的迭代过程。

MVP的美好在于没有投入昂贵的成本。使用最小可行生活作为模型可以给你同样的优势：如果不起，迭代并再次尝试。如果没有任何结果，你依然可以前进。

### 什么是阻止你做喜欢的事情

我已经做了十年以上的自由职业者。我在Freelance从事行政工作，那时工资很高，让我没有时间去尝试喜欢的事情。虽然只是兼职，我在大学毕业后停止了自由职业转而进入行业。

为什么用一个词来形容？是恐惧。害怕“自己无法生活”，没有经验和专业知识，必须假装自己知道，直到……我应遵守社会规范，符合预期。

### 设计一个最小可行生活

第一步是评估现在的财务状况。你需要知道的收入——常规收入、被动收入和储蓄，以及你的支出——可变支出和固定支出。打开Excel表格，并在左上角选择“文件”，将数字添加到黄色框中。

| 类别 | 说明 |
| :--- | :--- |
| 普通收入 | 税后目前工作中的收入 |
| 被动收入 | 任何不需要工作就能提供收入的来源 |
| 储蓄 | 随着时间积累的财富 |
| 可变费用 | 你想要减少或者消除的项目（例如：食物、租金、娱乐） |
| 固定费用 | 你真正无法消除的项目（例如：贷款还款） |

在表格上，你可以看到测试时间——根据最初的财务状况，在没有收入的情况下，你可以自己工作多久直到把钱花光。

### 延长你的测试时间

理想情况下，你需要至少一年的时间来做测试。在这一年中，你需要不断做一些调整，你需要一些时间才能赚到第一笔收入。一年的时间足够长以开始覆盖开支所需的收入，让你的测试逐渐变为现实。

另外，如果你已经有了被动收入来源，你调整的剩余就会比较大。不如说重点是延长你的测试时间。由于你需要了解财务状况，公式是：储蓄 + 收入 - 支出。购买更多时间的简单方法是专注于方程式中的“支出”部分。

### 降低支出以增加测试时间

假设你的数据：按照现在的烧钱速度，你将在第三个月陷入困境。让我们考虑一下你可以做出的一些调整：
- 搬到一个更便宜的城市或当前城市找一个更便宜的公寓
- 购买更便宜的食物并批量购买，每天吃同样的餐
- 减少外出就餐、娱乐和消费
- 取消付费订阅

你决定对其中几个选项做重点调整。由于你在家里工作，避免了通勤（没有汽油或公共交通费用），你的新数据会变成这样：现在你有9个月的时间，虽然不理想，但比之前的情况多了4.5倍。这就是削减开支的力量。你需要强迫自己思考你可以削减什么。最小可行生活是尽可能延长你的时间。支出只是权衡：你用钱交换时间。一旦这样考虑，很少东西是不可接受的。问题就是：“我想花钱在上面，还是延长我的测试/转型时间？”

如果你真的想要自己工作，你几乎都会选择后者。你开始用“时间”而不是货币来看待。一旦你做出了转变，你就是无敌的。

### “更进一步”的最小可行生活

开始为自己工作的安全的方法是将最小可行生活更进一步：在自己工作的同时，抽出小部分时间为他人工作。这样做，每个月你将为测试基金带来额外的资金。每天至少兼职一小时。

如果你已经知道想为自己工作，请从一开始降低支出。这是我遵循的计划。我通过大幅降低支出尽可能节省资金。很快我就有一年多的测试/转型时间。

你的测试时间可能不到6个月，最终结果如何，取决于你是否采取行动。
