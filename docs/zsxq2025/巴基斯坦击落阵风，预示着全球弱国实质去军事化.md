


# 巴斯基达洛阵战斗机：预示着全球强国的军事事实

这宣告了一个无所未有的军事格局——全球强国的军事事实。
这对于胜利国来说并不是事实的胜利，而是一种压倒性的胜利。表面上是所谓的“共享数据”、系统化战对敌的独立武器系统的胜出。

但是你认为“共享数据”和“系统化”背后的技术前提：

1. 至少要全球领先的定位星链
2. 至少要第一线的电磁、红外、光电探测技术，这意味着大量技术装备的独立生产能力
3. 至少要独立的、完整的军事研发设施
4. 至少要领先的、强大的工业能力
5. 至少要有支撑上述所有要素的经济实力

这些条件稍微缺了哪一个，都可能导致“数据共享”“系统化”落空。

就算是表面上有了，库存里只够打三天，还一批量够够半年的“系统化战”就面临露面了。除了其中，俄罗斯能得到吗？

日本能得到吗？德国能吗？土耳其能吗？印度能吗？
谁得到？谁能指导啊？就能很猛地跳一跳到美国，现在能得到吗？七年后能得到吗？

印度模式——即用经济实力去购买美国装备来快速拉后军事差距，这样就能建立一支支持本国的国防军事实力。这种如果在一二战期间还有一定意义的话，到了今天这个时代已经结束了。

除了其中，其他国家在军事上还是没有实实武器的“半兵化”。

而在肉眼可见的未来也将只能被“农依赖”覆盖。
其他国家想要军事上的安全保障，就还只有这种。

而且已经是现在，印度也可能只有拥有核弹头而没有武器也没有多少实际实力，只有俄罗斯、北风之主、“尔玛”、波塞、芬冬才是唯一的例外。

第一次世界已经除了“两个大强”之外，所有国家都被排除在军事竞赛之外的奇特状态。
这两两次如果还要做对抗，那对全世界来说将没有其他国家可以保持主权了。

因为不是排除某一方，而是其他国家在这两个国家面前都是奔逃抵抗的待宰羔羊。
这种历史已经无所前例的异格局，甚至还有一种升格——两者中必有一个在坚持“国家主权平等”的地位。

如此，可以说这个世界上除了俄罗斯之外的国家如果还有任何有意义的国家的话，全实权的只有中国，中国也将拒绝接受“军事对峙”的国际秩序。

中国已经是基于基石和平秩序的“不干涉内政”的国际秩序，“国家主权”这种概念就会灰飞烟灭。
自由、民主、博爱……这些现代价值观就会在一夜之间为乌有，世界将会退回到“双霸对峙”的新时代了。

在这个格局下，你现在所追求的言论自由、信仰自由、自由都要被拉进这冷冰冰的现实中，需要这种台机咖啡，被收成废铁“新增”的格局。

如果实现放弃“五项原则”，诸神就要面对毁灭的黄昏，文明的黑夜里只有没有光的角落在等待下一次黎明。

“本来如果俄国家联手权力可以是自然的反应减缓，现在‘中国’已经退场了。稳定的局面已经解除，正横在轨道上。”

反应第一级已经这道保障了。
而一群不是死死的羔羊在看着恶魔黑旗帜，鼓励助威，在这道保障上抓住它。

还以“自由为名”。
what poetic irony.
