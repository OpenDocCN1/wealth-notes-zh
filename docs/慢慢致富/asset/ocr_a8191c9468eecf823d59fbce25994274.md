# 第 9 天

# 享樂跑步機

“

持久的幸福在於日復一日、年復一年去做那些有意義的工作。

”

我們昨天討論到「社會概況調查」。為什麼我們的幸福感不會隨著生活水準的改善而提升呢？問題出在所謂的「享樂適應」（Hedonic Adaptation），或者也可以稱做「享樂跑步機」（Hedonic Treadmill）。

現在來想像一下我們去乘坐加勒比海遊輪、買了一座更大的房子、開起來更快的車，或者是獲得晉升外加薪水調高。當這些事發生在我們身上時，我們一定會感到更加幸福——但只是短暫的。當遊輪之旅結束了，我們也很快就會將之拋諸腦後。同樣的，我們也很快習慣了更大的房子、更快的車、更高的薪水，然後就不再把它們當作一回事了，我們的注意力會轉移到其他事物上——想要得到
