# 關於作者

喬納森·克雷蒙（Jonathan Clements）是HumbleDollar.com的創辦人，曾經出版了七本有關個人財務規劃的書籍，其中包括了暢銷書《金錢超思考》（How to Think About Money）。他也是美國最大財務顧問公司之一「創意規劃」（Creative Planning）的顧問及投資委員會成員。喬納森曾經在華爾街日報（The Wall Street Journal）工作長達20年，主要的工作是撰寫個人理財專欄。他也在花旗銀行集團（Citi Group）工作六年，擔任集團內個人財務管理教育部門主任。

喬納森熱中於自行車，偶爾也跑步。他出生於英國倫敦，畢業於牛津大學。喬納森已婚並有兩個婚生子及兩個收養的孩子，一家人住在紐約市的北邊。
