# 符合目標的投資配置

![](bbox=[0.46, 0.2, 0.54, 0.24])

> 重點不在於我們如何精細配置股票、債券、現金以及另類投資，重點在於配置之後的堅持執行。

投資組合裡短期價值波動和長期報酬的主要推動器，就是所謂的資產配置（Asset Allocation）。也就是我們如何調配投資組合裡的四類基本項目：「股票」、「債券」、「現金投資」（像是貨幣市場基金和存款帳戶），以及黃金、地房屋、避險基金等「另類投資」。

以短期來說，股票無疑是有風險，但以長期來說，它會是投資組合裡資本成長的發動引擎，它的獲利很輕易就可以超過通貨膨脹。現金投資一直被認為風險很低，但如果把通貨膨脹以及稅金考慮進去，我們很可能會在這方面的投資蒙受損失。
