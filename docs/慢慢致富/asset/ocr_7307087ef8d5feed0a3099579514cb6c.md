# 先顧好需要什麼，再談想要什麼

![](bbox=[0.1, 0.2, 0.91, 0.21])

> 豪華車輛，是租來的嗎？房子很大，房貸也大嗎？花園很
美麗，造景公司的錢付了嗎？

你買得起心目中的夢想之屋嗎？你有必要的資金來為你的孩子
支付大學費用嗎？去一趟兩星期的歐洲旅行，是個精明的財務決定
嗎？我並不是在這裡告訴你怎麼去花你的錢，你可以決定自己該怎
麼做——只要你能把自己的未來、以及那些在財務上需要倚靠你的
人照顧好就行了。

這就意味著：你應該每個月都要確認自己為將來的退休做好足
夠的儲蓄。除此之外，你的「財務工具箱」內還需要另外四樣東西：**醫療保險**、萬一失去工作時的**應急基金**、存款不足 100 萬美元時的
**失能保險**、存款不足 100 萬美元而且有家人的倚賴你時的**人壽保險**。這些都有了嗎？那麼，其他的財務安排就隨你了。
