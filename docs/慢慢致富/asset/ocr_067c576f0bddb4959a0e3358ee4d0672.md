# 雙贏計畫：退休基金 + 減少卡債

> 你可以有卡債，也可以把鈔票從窗口丟出去，因為它們是同一件事。

你如果諮詢過財務顧問，他們應該會告訴你，每一個人的財務狀況都不一樣，所以沒有單一的解決辦法。這個說法大體上是正確的，但下列兩個忠告還是適用於所有的人——如果你還沒有遵循實施，現在就是開始的時候了。
