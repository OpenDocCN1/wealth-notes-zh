# 第 70 天

# 理財單純化

> 我們在塵世的不朽還得靠其他人去想起來，所以要確認他們能記得。

假定你明天突然死去。我知道這個想法不會讓人舒服，但在那種時刻，你自己的財務問題已經一了百了，但你的家人呢？他們的問題才正要開始，特別是如果你留下來的是一團混亂，他們要如何妥善處理你的遺產？如何解開你所留下如一團亂麻的財務迷宮？為了讓你的家人更容易處理問題，你現在就應該整理一下自己。
