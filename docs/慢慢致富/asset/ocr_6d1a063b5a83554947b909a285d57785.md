# 第 13 天
盡量控制自己的金錢流向

![](bbox=[0.12, 0.3, 0.18, 0.33])

> 許多看起來愚蠢的人卻有辦法短期內在市場裡賺到錢，但
以長期來說，降低投資成本和只冒合乎情理的人，
才會在最後真正勝出。

![](bbox=[0.83, 0.42, 0.89, 0.46])

讓我們回頭看一下你昨天所記下最聰明和最愚蠢的理財動作。現在問問你自己：你自認為聰明的舉動真正聰明嗎？還有，你認為
是愚蠢的作法真的愚蠢嗎？

舉例來說，2007 年到 2009 年股票市場崩盤之前投入大量資金，
看起來是一個愚蠢的舉動，但我们怎麼會知道股市就要崩盤了？我
不會說那是個愚蠢之舉，只能說是運氣不好。

現實的狀況就是，財務的世界裡有太多不可控的因素，所以運
氣就扮演了很重要的角色。我們不知道市場是否明天會崩盤；我們
無法控制自己是否會罹患重病，結果需要花費昂貴的醫藥費；我們
也無法阻止老闆關閉某個部門並遣散所有員工。
