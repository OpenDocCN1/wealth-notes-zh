# 提高你的信用積分

![](bbox=[0.12, 0.29, 0.18, 0.33])

> 如果你對自我價值的評估是建立在車輛是否花俏、房屋是否夠大上面，你將永遠不能滿足，心情也將永遠無法平靜。

![](bbox=[0.83, 0.42, 0.88, 0.46])

+   ① 檢查一下你的信用報告，看看其中是否有誤。
