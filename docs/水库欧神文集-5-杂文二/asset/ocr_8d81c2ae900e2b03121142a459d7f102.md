# 二）怒气

“怒气”这种事，每个人都有。

你如果请一个 50 岁的阿姨吃饭，她会流着泪，说全世界的人都合谋欺负她。LGBT 如此地遭受不公。

但我们是文明世界的人。“文明”的含义，就是讲道理。

公说公有理。婆说婆有理。

不能偏听“一面之辞”。“道理”是一件<font color="red">很客观</font>的事实。

曹伯钰的理由是，五星地产项目，是一个坑子。

所以他不能写软文。

但钱得照给。

“骗局”的理由，曹伯钰说老白的五星地产项目，是“资金盘”类。

啥叫资金盘。呢，简单讲，就是“售后包租”。

+   * 房屋售价 100W 元。
* 但是，承诺房租 10 万/年。
* 包租前三年。

很多人拿计算器一算。“租金回报率”高达 10%。
