# 一）纠纷

作为吃瓜群众，最令人精神抖擞的，恐怕就是“大V爆料”了。刺激更深一层，则是“二V互撕”。

“互撕”这种八卦顶级究技，在“和气生财”的今天，已经很难看见了。难道遇见一次“二V互撕”，半个水渠系都被惊动了。啤酒，瓜子，一度脱销。

这一次互撕的双方，是：

+   - 美国海归：曹伯钰
- 五星地产：老白（西港）

鉴于圈外人士不了解，我们简单介绍一下：

+   1. 6.12 曹伯钰发布《西港最大骗局揭秘，你们全都上过当》
2. 6.13 老白反击《我在西港请了个美国大海归！》
3. 6.15 曹伯钰辩解《西港骗局吃瓜第二弹：海归教骗子如何写回怼贴》
