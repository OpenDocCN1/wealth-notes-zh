# 该女性，默认，是有资格管男朋友的。

也就是，如果你是她男朋友的话。她理解的“三观”，她心中的“正义感”。

女朋友是有资格，管男朋友，不允许他出轨的。

或许我们的读者，懵懵懂懂没思考过，这方面的问题。

但如今我们点出来了，大家扪心自问，你内心的“逻辑”，的确是这样想的。

水库的招牌，叫做“毁三观，竖新生”。

三观尽毁。你以为天经地义，从来没质疑过的东西，其实有很大的“思辨”空间。
