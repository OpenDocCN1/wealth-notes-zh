对于 3 * 2 = 8 这个公式，现在我们的要求是：

仅改动一个字符，使得这个等式成立。

+   一个茶杯，在中国售价 8 元。
在马来西亚售价 3 马币。
1 马币 = 2 RMB
马来西亚物价比国内便宜，大家纷纷去马来西亚采购。

为了让等式成立，我们有几种改法：

+   3 * 2.7 = 8，改变汇率。使得等式成立。
4 * 2 = 8，改变价格。使得等式成立。
3 * 2 ≠ 8

第三条，才是最牛的一条。

类似于做“小鱼饼干题”，你直接改个不等号出来，才叫突破脑洞。

而在现实的经济中呢，“≠”就相当于“外汇管制”。货币的不可自由兑换性。
