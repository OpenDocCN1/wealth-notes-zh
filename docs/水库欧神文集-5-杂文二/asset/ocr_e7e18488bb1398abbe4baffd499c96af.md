# 1 复利是世界第八大奇迹

复利是“世界第八大奇迹”。知之者骤，不知者被赚。 ——爱因斯坦

一个物理学家说出这样的话，是不是感觉很奇葩？其实爱因斯坦是犹太人，利息最早就是犹太人玩得最好的金融方式。

很多人对利息都无法理解，更不用说是复利了，先看个例子：

“复利”被誉为世界第八大奇迹。据说是爱因斯坦说的。

“复利”承诺：
- 只需要非常小的本金（迎合了屌丝）
- 经过了漫长的时间（30~40 年）
- 最终可以成长为一笔巨大的财富。
小人物也可以成为“千万富人”。
