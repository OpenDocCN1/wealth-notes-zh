# 四）关于经济

有钱人不再追求金钱，不是问题。
有钱人不再赚钱，问题就大了。

我们知道，生产力最优化的状态，叫做 “帕累托最优”。
数学上，可以表示为 dT=0，一切可交易机会，均已做完。

可事实上，一个社会，远远达不到 “帕累托最优”。
往往距离还有很远很远时，它就停滞了。

这个时候，依然存在 dT>0，依然存在 A 与 B 做生意。“A 也得益，B 也得益”，大
把商机。

但是 A 说，“我不想干了”。

“我已经触及了财富的上限”，“会触发 C 的觊觎”。

任何一种政体，都有它对应的 “政体上限”。

+   某些政体，在 USD 3000 时就停滞了。我们称之为 “中等收入陷阱”。
有些政体，在 USD 30000 时停滞了。我们称之为 “高等收入陷阱”。

制度决定经济。

（帕累托最优，可能是 USD 500000/人。多二个零，潜力发挥不足 1%）

如果我们研究的目标，是富国强民。想要尽可能发展国力，过上幸福富裕的生活。
则我们的制度，应该是一种 “没有抢劫” 的制度。

每一个人，都享有非常高的 zz 权力。
哪怕你拥有很多财富，你也享有制度上，舆论上，能力上，不受抢劫的自由。
