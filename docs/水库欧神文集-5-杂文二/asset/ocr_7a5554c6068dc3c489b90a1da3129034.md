# 三) H2S04

同样道理，还有一个家伙。是著名的“浦东帮”领袖。

买房买在浦东，逃筹一塌糊涂。手中没有任何一套房子，翻 15 倍以上（不含杠杆）

尤其是最近几年，“水库”的主力，根本不在上海。

我们说：“离开上海吧，上海雪坡不长”。

他傲慢自大：“宇宙中心是联洋”。

我们说，“去 C Q 吧，上海经济颓势尽显”。

他说：“我才不去那乡下呢，我就要待在井里。联洋宇宙中心”。

我们说：“别买房子了。时代变了，买地吧”。

他说：“啥？听不懂，看不懂”。

联洋平民窟，垃圾地段。
