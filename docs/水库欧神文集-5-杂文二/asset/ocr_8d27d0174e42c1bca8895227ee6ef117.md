# **四）培养孩子**

生儿如羊，不如生儿如狼。
软弱、懒惰与愚蠢是恶德，余者都是美德。

象我们这样的家庭，培养孩子，关键看她的性格“不对称”。
她必须有强烈的喜好，强烈的偏好，强烈的欲望。

喜欢的类型，反而不重要。譬如她小时候喜欢“巴啦啦小魔仙”，长大了一定不喜欢。你根本不用担心。

但是性格，一定得要“不均衡”。
每件事浅尝辄止，肤浅炫耀，才是最无望的类别。

人在激烈对抗中，比较容易暴露本性。
“打孩子”虽然是一句戏话。但有意识制造冲突，可以观察孩子的本性。
为了这个萌蠢的小怪物，还真是操碎了心。
