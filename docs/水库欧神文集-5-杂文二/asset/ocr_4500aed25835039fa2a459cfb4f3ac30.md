# 三线是什么，三线就是重庆。

虽说有上千个项目，但绝大多数核心，都设在了重庆。

“水库论坛”从四五年起，就已经有计划地“撤出沿海，转入西南”。

+   - 我们撤出沿海 100000+/m 的高价房子。
- 换入重庆，西南，低价民宅物业。

“换筹”这是一个长期，缓慢的过程。

+   - 鉴于限购，限贷，限售等重重困难；
- 税费，拘笋等精细操作，
- 而且广深本身还有一定的涨幅潜力；

“跑步中跳舞”，要把“换筹”这件事，做得很平稳高效，可真是不容易的事。

但是无论如何，我们认为目前“沿海：中西部=8:1”的房价比例，是很不合理的。

从nxh和经济重心转移，等基本面来看，

# 押宝中西部，尤其是西部，更符合 nxh 大趋势。
