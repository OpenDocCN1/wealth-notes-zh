# 道典正义 —— 远近亲疏 #J120

你不会抢你的亲娘。

# 一） 亲儿子

在小说《将夜》中，有一段情节。
宁缺刚刚突破领悟了“感知”境界，可以凭借超能力，探知骰子的点数。

于是宁缺拉着桑桑，奔城南赌场大赢一通。骰盅翻飞，点点都成了对家心头血。
二个人偷贼一般，躲在屋子里数银票，眉开眼笑。

宁缺对桑桑说，“待会赌场发现抽老千，一定会追过来”。
“这钱咱们得拿紧了，说什么也不给”。

宁缺的脸皮，厚得象南京城墙一般，非红衣大炮决计不能轰开。他又是大修行者，具备强大的武力。
这似乎也算是某种程度上的文武双全，“文质彬彬”。

宁缺打定主意，无论赌场人“说辞”是什么。钱不脱手。
