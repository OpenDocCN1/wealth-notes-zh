# 二）取舍

我讨厌这篇文章的原因，因为它从头到尾，充满着浓浓知乎“工业党”的味道。

+   知乎工业党说：
* 计算机产业很重要，所以我们要倾国之力，打造尖端计算机工业。
* 高速铁路产业很重要，所以我们要倾国之力，打造高铁工业。
* 光刻机产业很重要，所以我们要倾国之力，打造芯片产业。
* 太空竞赛很重要，所以我们要倾国之力，打造航天产业。
* ............

经济学是关于“取舍”的学问。

俗话说，“小孩子才索要糖果，成年人会询问价格”。
整天喊着“我要我要”，给人一种很 Low 的感觉。“工业党”都是没有教养的巨婴。
