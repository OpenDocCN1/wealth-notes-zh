# 一）份额

这两天，一件“商战”中的事，勾起了我的回忆。于是写下此篇。

话说，NN 年前，公司总裁看着我们的财务报表，突然悠悠说了一句：

> “团队非常优秀，但我希望你们做得更好”。

> “比如说，市场份额能不能提高 1%”

是不是非常平平无奇的一句话。

在几乎所有的电视剧，电影，网络小说，商战文学，大亨几乎坐下来，甩一支雪茄：“我要 10% 的市场份额”。
