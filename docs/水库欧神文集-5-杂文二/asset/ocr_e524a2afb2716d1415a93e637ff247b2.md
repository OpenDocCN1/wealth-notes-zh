# 二）赛跑

有时候，我真的很想佛系。疫情期间，躺了几个月，感觉非常地慵懒。

但是“投资”不能佛系。

你休息几个月，外面的世界就天翻地覆了。

![](bbox=[0.15, 0.325, 0.85, 0.695])

我们知道，最近几个月，最热门的城市是“深圳”。

如果你从1月1日~到6月1日，错过了“深圳行情”，什么事也没做。那你可能就损失了数百万，

这是好几年的工资，都补不回来的。

身边所有的人，都在用越来越快的速度“变富”。

渐渐地，任何一个人，都可以拿出1000万元现金。物价也在飞快地上涨。
