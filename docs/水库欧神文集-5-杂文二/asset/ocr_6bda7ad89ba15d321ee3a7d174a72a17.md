# 楼市看的是十五年的利益。
房企看的是一年的利益。

二者盈利模式完全不同。“地产股”其实不关心“楼市大盘”的涨与跌。
房价跌，拿地成本也降一点好了。
水退船低。

“地产股”关心的，是周转，规模，每一个项目的“品牌溢价”程度。
品牌溢价，每套房毛利 +10%
周转十次，一样是 +100% 的利润。
其背后，是无数小数接了“品牌贵妇”CEO 盘的累累尸骨。

+   - 地产股 = 制造业，搏的是经营毛利率
- 地产 = 金融业，搏的是涨跌。
