# 二）贱货

让我们梳理一下，在《后浪》这个视频中，那些包装光鲜，令人“羡慕”的年轻人，都炫了些什么。

+   - 穿着汉服，在直升机畔跳舞
- 外滩江边，饕餮晚宴
- 跳伞，骑行，滑板
- 塔克拉玛干看日出
- 逛街，购物，吃喝派对。

基本除了“西藏洗涤”，文青的那一套全齐了。

你说我羡慕不羡慕，很抱歉，以上种种，在水库看来，都属于“娼妓之道”。

红酒喝得越好，越是下九流。

“娼妓之道”你吹得越高大上，我们越觉得恶心。

作为一名“70后”生人，象哥哥这种半截入土的老头子，我看《后浪》吹捧，主要是不适应；一百个不适应，浑身别扭，扭得难受。
