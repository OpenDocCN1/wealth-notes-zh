# 三）财富的下限

在郑渊洁童话小说《皮皮鲁和鲁西西》中，讲述了一个太阳城的故事。在这个虚构的世界里，所有的工商业，都已经被“大型财团”垄断。他们是如此地有效率，个人根本无法竞争。
