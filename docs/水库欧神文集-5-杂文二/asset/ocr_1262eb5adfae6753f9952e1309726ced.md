# 北京家庭平均资产900万，你后悔了吗？

近日，中国人民银行调查统计公司公布《2019年中国城镇居民家庭资产负债情况调查》结果。数据显示，城镇居民家庭户均总资产317.9万元，以实物资产为主，住房占比近七成。

![](bbox=[0.36, 0.69, 0.67, 0.78])

城镇家庭资产分化明显，北京近900万

调查显示，城镇居民家庭总资产均值为317.9万元，中位数为163.0万元，北京最高为892.8万元。均值与中位数之间相差154.9万元，表明居民家庭资产分布不均。
