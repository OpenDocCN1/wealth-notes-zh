# 三）螺旋骗傻

凯恩斯主义的第二个谬误，他们认为通缩是会“传递”的。类似于金融危机，钱庄一家连着一家倒闭。价格螺旋式下跌。

这也是彻头彻尾逻辑不清。基础功混乱。

价格只是“相对比率”。有人降价，必然有人“升价”

+   举个 例子，假设某球经济体，只有2个国家。一个 A 国，一个 C 国。
* C国专注于挖掘原材料。
* A国专注于深度加工。

C国并没有“高精尖”加工的能力。A国也懒得挖原材料。
C国挖出来的煤炭木材，卖给A国。
A国加几个零之后，把部分制成品返销给 C 国。构成了循环。
