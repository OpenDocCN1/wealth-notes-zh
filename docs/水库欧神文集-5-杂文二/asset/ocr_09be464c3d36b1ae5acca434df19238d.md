# 四）洋房

上海的老洋房市场，早就垮了。

老洋房市场二条出路，一是象“思南公馆”一般，整体改建，整体改造。30幢别墅一起维护，造成一个高档社区，地段也非常优秀。

另一条路则是政府出于商业目的回收，做商业的饭馆或者会所。例如巨鹿路的“庞苑”，据说最后一户钉子户，是以30万/平米的价格买下。

也使得整个项目，不可能赢利。
