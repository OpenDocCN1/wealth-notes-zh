# **暴力是客观的，最终裁决者。**

五）产权竞争

很多人不明白，在《道典正义》中，似乎没有正义，公平，平等，伦理。

“产权”章写了 2000 字，一点都没有涉及到生产者的利益。

是不是只要有了暴力，就可以为所欲为？

其实不是的，因为“产权制度”决定了暴力能力。

一项好的“产权制度”，例如保护生产者，劳动者，可以极大地激发生产积极性。风投与产权交易市场，可以鼓励创新。

当一个国家率先踏上“工业革命”，完成机械化工业化，就可以获得非常大的暴力力量。

**暴力是第一性的，产权是第二性的。**

**先有暴力，后有产权。**

产权为了暴力服务。一切为了生存和繁衍。
