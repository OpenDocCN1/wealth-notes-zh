# 银行融资的八大密码(干货)

+   一是有营业执照，是合法企业；

+   二是独立核算、自负盈亏、自主经营；

+   三是在银行开设了基本账户和一般存款账户；

+   四是具有按期还本付息能力；

+   五是在工商行政部门办理了年检手续；

+   六是拥有一定的自有资金，产品有市场，生产经营有效益；

+   七是纳税和信用记录良好；

+   八是资产负债率符合银行要求等等。在此基础上，企业的资信等级越高、财务状况越好，就越容易取得银行贷款。
