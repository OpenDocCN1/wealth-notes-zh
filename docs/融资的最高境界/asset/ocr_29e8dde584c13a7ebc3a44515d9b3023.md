# 第三步骤：开始表演

小芳请小姐妹过来参加自己的结婚典礼，有人要问了：这不是生完孩子了？还办婚礼？问这话的人显然不专业，婚礼是有目的的，别着急，跟着一诺老师的节奏你就会恍然大悟！

请来的嘉宾可想而知，男的都是阿狗的狐朋狗友。女的都是小芳的，同道中人。小芳带着的小姐妹，开始参观别墅。

小芳拿着一串车钥匙，上面有路虎、宾利、劳斯莱斯的车钥匙……对着小姐妹说：宾利和劳斯莱斯在公司接待大客户用的，那台路虎他开去上班。唉！只给我呀，留下这两台破车，小姐妹看着车库停着的奔驰和宝马，表情那是相当复杂啊……
