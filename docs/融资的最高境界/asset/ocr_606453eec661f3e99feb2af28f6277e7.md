# 小型电缆厂实操案例(实战)

一诺老师的弟子杨老板，开了一家小型电缆厂，注册资本1000万元。由于看到国际铜价在上涨，所以杨老板想多储备些库存，这样就可以坐等价格上涨而获利了。可是这样一算，杨老板至少还需要800万元资金才能解决问题。为此他用公司的自有土地、厂房做抵押，在某商业银行贷了800万元流动资金。

眼看贷款即将到期，杨老板的这些库存是准备用于生产的，现在不能卖出，否则就会打乱原来的安排。这样，要归还这800万元贷款本金及利息，他变得无能为力了。
