# 一诺老师 ABC 买房 9 大要素

+   1、 流水要求（可操作空间）

+   2、 买现不买期（出证快）

+   3、 不限购（无户籍社保名额限制）

+   4、 不限贷（贷款环境好）

+   5、 不限售（购买后转手卖，无交易时间限制）

+   6、 升值潜力大（周边配套好：商业、学校、医院、银行、五星级酒店）

+   7、 房源可控（价格可控、买卖时间可控）

+   8、 低首付（首付越低越好）

+   9、 住宅 70 年产权（公寓慎重）
