# 第一步骤：个人融资

阿明是潮汕人，潮汕人有个特点，就是喜欢做实体产业，这也正好是银行的最喜欢的，银行喜欢把钱借给实体，不愿意把钱借给办教育的、咨询顾问公司等。

因为中国有句古话叫做“跑得了和尚，跑不了庙！”

所以，想要融资贷款，做实体就对了！

为了快速融资，阿明启动了信用，办了多张信用卡，融资 20 万。不仅如此，阿明也让女朋友、和自己的弟弟妹妹等多人同时启动信用，这样可以同时融资，阿明可支配资金高达 35 万。
