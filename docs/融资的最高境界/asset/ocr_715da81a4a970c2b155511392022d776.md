# 第 24 课: 权力融资法

# 把看不见的钱变成看得见的钱(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说的权利，主要是指以股权、知识产权、收费权等为代表的各种新型财产权。因为它们具有很高的财产价值，当然可以在你需要用钱的时候作为质物，向银行获取贷款。

# 股权质押融资方案(实用)

一诺老师认为，如果你是上市公司，那么你所拥有的非流通法人股，就可以用来向银行进行质押贷款，这是很受银行欢迎的。如果你不是上市公司，可是你拥有某家上市公司的这些非流通法人股，同样可以这样做。
