
# 第一步骤：学习改变

各位别忘了，这个老光棍是一穷二白家徒四壁，人长得可谓是矮胖丑，可是这小子有个特点，就是爱吹牛皮。

孙牛皮没有资金、没有背景，但是，他为什么会白手起家、空手道创业，并且在当地叱咤风云呢？

按照孙牛皮的话说就是自己热爱学习！

![](img/b740e884aae911cd1331c6fbabe15425_195_0.png)

不知道是谁推荐孙牛皮看了《金瓶梅》，全书 80 万字生动描写了人性的阴暗、险恶、贪婪、放纵，颠覆三观的堕落和性爱，普通人看《金瓶梅》也许是被应接不暇的花样和招式迷住了，可是孙牛皮的关注点却清新脱俗！

孙牛皮对这本书有独特的见解——孙牛皮认为，里面的男猪脚西门庆，之所以腰缠万贯，就是因为西门庆专门勾搭那些有钱人家的寡妇，就是死了老公的有钱人。这样呢，西门庆把对方取过来，就相当于把对方的家产都取了过来！

孙牛皮恍然大悟——这女人啊，长得年轻漂亮的没有钱，有钱的都是又老又丑！

可是喝了“五粮液”，这满嘴的稻花香啊！

特别是亲热之前，一定要喝一种叫“欧玛尼”的红葡萄酒，这保证让对方亲着你不松口，为啥呀？因为“欧玛尼”红葡萄酒中含有单宁，花色素苷，它们能够着色在舌头和嘴巴上，人的舌头、牙齿和嘴唇有一层粘膜组织容易吸附这些果糖，会让人有一种感觉那就是：你的口水有点甜！越亲越上瘾！

#### 第二：拉近关系

最好是男女之间都一起喝“欧玛尼”的红葡萄酒。

![](img/b740e884aae911cd1331c6fbabe15425_197_0.png)

喝醉了也许误事，但是如果你能喝 1 斤的喝半斤，那你真的是可以激发潜能、飞马扬鞭，让对方腾云驾雾、夜夜讴歌啊！
