# 债创业的逆袭之路！

梅姐办了一个小厂，做皮鞋的鞋盒，因为这才是低成本创业最好的项目，专门承接来料加工，这样自己就只用出房租、水电和人工费，而且人工都是压 3 个月的工资，也就是要等到第 4 个月才发第 1 个月的工资。

所以，梅姐有足够的时间来创造奇迹！

![](bbox=[0.15, 0.37, 0.87, 0.51])

> 资本的最大成本是时间！

— 诺老师

各位知道吗，在 2000 年的时候，很多外来务工人员在温州的基本工资只有 800 块钱，想要拿更多工资只有加班加点，累死累活的干到天荒地老，一个月也只能拿到一千块左右。

由于梅姐的代工费比较低，加上梅姐善于交际，客户自然不愁，梅姐的工厂是开足马力、通宵达旦的加班加点！工厂赚不赚钱没关系，为啥呀？因为梅姐正在筹划一个更大的计划！

梅姐可谓是心理学大师，知道员工要什么！

于是乎，就故意当着员工的面数钱！
