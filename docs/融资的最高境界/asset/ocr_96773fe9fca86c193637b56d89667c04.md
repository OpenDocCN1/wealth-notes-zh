# 法人信用卡账户透支贷款(实操)

信用卡是一种非现金交易付款方式。它不鼓励预存现金（预存现金不计利息），实行先消费后还款，享有免息还款期，你可以自主决定如何分期还款（不过有最低还款额要求）。

一诺老师认为，在过去，我国并没有这种真正意义上的信用卡，所谓的信用卡只是没有任何信用卡功能的储蓄卡，所以这种信用卡在我国反而被称为贷记卡。
