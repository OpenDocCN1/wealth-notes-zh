# 第33课：委托融资法

让银行帮你在民间融资的方案(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

个人委托贷款名义上称为贷款，实际上属于民间借贷，是一种合法的、创新的民间融资渠道。

![](bbox=[0.14, 0.43, 0.88, 0.55])

一诺老师研究发现，所谓个人委托贷款，就是民间借贷双方通过银行中介来确立借贷关系。说得更通俗一点就是，出借人虽然愿意把钱借给你，可是你和你的企业名不见经传，甚至还处于创建过程中，信杆和效益什么的都无从谈起，直接把钱交给你觉得风险太大，所以先把钱交给银行，委托银行贷款给你；银行作为受托人，根据委托人确定的贷款对象、用途、金额...
