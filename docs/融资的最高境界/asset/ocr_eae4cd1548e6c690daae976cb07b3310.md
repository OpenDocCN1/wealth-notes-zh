贷款项目的币种只能选择美元，这时候也就没什么可选的了。

+   (3)国外银行贷款的还款方式可以自由选择，这对许多企业来说反而增加了“麻烦”，就是不知道怎么选。

一诺老师认为，应主要考虑三项因素：

+   一是贷款数额、期限，数额不大、期限较短的适用到期一次偿还方式。

+   二是利率，如果采用的是固定利半，当利率下降时借新还 IE)，可以减轻利息负担；如果采用的是浮动利率，利半呈上升趋势时提前还贷较合适。

+   三是汇率，如果贷款币种呈上升趋势，这时候提前还贷能降低汇率风险。
