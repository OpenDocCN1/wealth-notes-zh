# **第二步骤：自己特长**

由于阿狗那是山穷水尽啊，房子、车子、存款那是啥都没有，征信在银行还是黑名单，阿狗填表的时候哇哇的哭起来。

众所周知，一诺老师课程讲究实操，一诺老师的弟子内训，那不是讲课，是在做实操落地！

所以，当其他弟子都在做计划的时候，阿狗哇哇的哭了起来，流下了悔恨的泪水！

阿狗一生沾花惹草，如今浪子回头，一诺老师觉得可以让他分享一下，这样呢，可以给大家一个警示！

![](bbox=[0.15, 0.5, 0.88, 0.63])

谁知道阿狗站在讲台说：“一诺老师，您是我的第二偶像！”

一诺老师吓一跳，心想：“1服了 U，全世界最伟大的人生教练，居然是你的第二偶像！”

可是做为一位顶级的人生教练，不仅要内心惊涛骇浪而不表与形，还要能泰山崩于前而不变色！
