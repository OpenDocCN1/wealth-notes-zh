# 第一步骤：学习改变

各位别忘了，这个老光棍是一穷二白家徒四壁，人长得可谓是矮胖丑，可是这小子有个特点，就是爱吹牛皮。

孙牛皮没有资金、没有背景，但是，他为什么会白手起家、空手道创业，并且在当地叱咤风云呢？

按照孙牛皮的话说就是自己热爱学习！

![](bbox=[0.12, 0.38, 0.88, 0.49])

不知道是谁推荐孙牛皮看了《金瓶梅》，全书80万字生动描写了人性的阴暗、险恶、贪婪、放纵，颠覆三观的堕落和性爱，普通人看《金瓶梅》也许是被应接不暇的花样和招式迷住了，可是孙牛皮的关注点却清新脱俗！

孙牛皮对这本书有独特的见解——孙牛皮认为，里面的男猪脚西门庆，之所以腰缠万贯，就是因为西门庆专门勾搭那些有钱人家的寡妇，就是死了老公的有钱人。这样呢，西门庆把对方取过来，就相当于把对方的家产都取了过来！
