# 存货质押融资的四种操作方案(实操)

# 第一种操作方案：仓储融资

就是你把自己的存货，存放在银行指定的仓库中，由第三方代为管理和保管。这时候的存货你照样可以出售，但贷款必须汇入你的银行账户，直接冲减银行贷款。

这时候的保管仓库，既可以是自己的仓库，也可以是银行指定的其他仓库。如果是自己的仓库，银行通常会雇用第三方作为代理人，或者直接派出管理人员，对这些存货进行监督、管理，以确保银行对这些财产拥有的合法权利。
