# 第三种方式：借款基础贷款

这就是说，如果你拥有许多应收账款，并且这些应收账款能够作为永久性铺底流动资产，那么你就可以以这些流动资产为基础，向银行申请一个长期授信额度，例如 100 万元。

在这个额度内，银行可以随时向你提供循环授信。

一诺老师的经验告诉我们，当你需要向银行申请贷款时，你要向银行提供一份应收账款消单，列出每笔应收账款的客户名称、账龄等要素，然后在这 100 万元的额度内拿到银行贷款。

![](bbox=[0.1, 0.48, 0.33, 0.63])

不用说，你提供的这份应收账款消单额度，应该使得永久性流动资产保持在一个相对稳定的水平上，例如 100 万元以上。

银行则会重点考查你的这个借款基础是否真实可靠，主要是看这些应收账款是否合格。否则，银行的风险岂不是太大了？
