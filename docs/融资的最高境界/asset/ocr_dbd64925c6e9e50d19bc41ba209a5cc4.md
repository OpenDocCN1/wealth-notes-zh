# 第21课：质押融资法

# 如何打造银行眼中的信用(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》!

存货质押贷款，连同下面要说的应收账款质押贷款、无形资产质押贷款，合称动产质押贷款，或者叫动产抵押贷款。

如果你以企业名义去申请银行贷款，房产证、银行存单、国债肯定是可以抵押的，可是如果用汽车、首饰、家用电器等动产做抵押，银行一般会拒之门外。

![](bbox=[0.13, 0.56, 0.87, 0.7])

因为这些东西不但不容易存放保管，而且实际价值很不容易鉴定，贬值速度还快。但如果这家银行开办了动产抵押贷款，你就可能会如愿以偿了。
