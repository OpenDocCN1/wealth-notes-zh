# 外部融资首选银行融资(实用)

毫无疑问，小企业如果缺少资金，最应想到的还是从银行获取贷款。道理很简单，相对而言，银行贷款的成本低、期限长、风险小、手续简单、方式灵活、资金到账快、资金供应量大。而且，银行贷款的利息可以进入成本，能起到节税作用。

资料表明，我国中小企业需要从外部融资时，94%会首选银行贷款；而在中小企业的外部资金来源中，92%的资金确实就来自银行贷款。

一诺老师认为，只要有可能，小企业在需要资金时，应当首先考虑直接从银行取得贷款，这是最简单的道理。不过由于银行放贷有许多要求，所以你必须符合它们的要求才能顺利拿到货款，避免走弯路。
