# 第二步骤: 准备道具

阿狗在一诺老师的亲自指点下，跟小芳去拍了很多张婚纱照、花了10万块去世界各地逛了一圈，最重要的是拍了很多照片：东京铁塔、夏威夷海滩、荷兰童话世界、菲尔铁塔……

接下来，在三线城市花了1.2万租了一栋超级大院子的别墅，租了一辆宝马、一辆奔驰，作为日常代步！这还不够，在万恶的某宝买了路虎、宾利、劳斯莱斯的车钥匙！

还想办法借来了一批金银珠宝：黄金大链子、金戒指、大钻石、水晶、玛瑙、珍珠项链……甚至还有十几个金条！

还定制了别墅的门牌，上面写着“小芳府邸”，很多人可能不知道，住别墅的人，一般都做了一个门牌，挂在大门口。
