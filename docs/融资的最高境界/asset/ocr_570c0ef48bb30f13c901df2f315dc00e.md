# 第四种操作方案：提货担保融资

如果你在信用证项下的进口货物已经到港，可是货运单据还没到，按理说这时候你只能眼睁睁地看着不能提货。可是，你如果向银行提出申请，要求银行出面向船公司出具期货担保，是可以让你先下货的。

这样不但能节省高额的滞港费用，而且还可以缩短商品上市时间，把握市场先机，实际上变相实现了融通资金的目的。

一诺老师发现，这时候你是需要日后及时补交正本提单，并且负责交付船运公司各项应收费用甚至赔偿的，但总体上会大大缓解你的资金周转困难。
