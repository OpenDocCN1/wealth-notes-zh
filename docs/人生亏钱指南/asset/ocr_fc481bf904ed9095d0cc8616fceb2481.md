# @匿名

刚毕业那会，在一家公司上班，公司很好且日益壮大，然后公司用自己的产品做了一个项目（就是现在所谓的资金盘），公司里的很多员工和很多客户都买了这个项目，然后自己也跟着买了，结果不到半年的时间项目崩盘了~公司利益者获益，公司关门自己亏了一年工资~很久才缓过劲来~

惨痛的经验教训：

+   1. 不了解的东西千万不要碰！
2. 千万不要随大流，看着很多人都干，自己也跟着干，一定要有自己的独立思考和判断！
3. 不要对公司或对公司的领导人太过相信和追随，记住只有永远的利益，别被卖了还帮着数钱！
4. 谨防身边的庞氏骗局~用独立思考去辨别它~多问为什么？！
5. 最后，记住天上不会掉馅饼！！！
