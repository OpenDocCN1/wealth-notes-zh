# 【青年公寓亏钱经历】

2018年青年公寓青年驿社区风口正盛，蛋壳和万科疯狂拿地，深圳拿地成本飙升，在深圳有了9个成功案例后转战东莞。

东莞拿地成本低，成功拿到地铁口项目，装修升级花费420万，119个房间，2019年开始出租，出租当月去化80%

欣欣向荣的趋势，信心十足，成为5公里内同行的核心，当时东莞本地地商开价500万让我们转让给他，为了能够在东莞市场打出名声，作为东莞的模板项目我们拒绝了。

接着发生了在深圳没有遇到事情，租客流动性特别大，每个月新增承租数量15-20个，流失租客10-20个，招租成本上升，各种问题也慢慢浮现出来……

+   1. 产品质量问题：联排房间隔音差，原结构楼板薄，楼龄太久墙体渗水，虽然多次处理但总有淡淡潮湿的味道。

+   2. 大部分房间未设厨房，承租多为刚毕业的单身大学生，流动性大，同时比较吵闹于扰稳定工作的租客。

+   3. 前期 khusus 定价低，承租条件宽松，前三个月实行免押，后期实行一押一租，客户退租成本低。

+   4. 招租成本高，前期中介与租客合作拿到一个月租金佣金后平分甚至3-7分，后期自主招租平台流量费用高。
