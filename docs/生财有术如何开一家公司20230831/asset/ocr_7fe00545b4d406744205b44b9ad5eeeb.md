# 4、财进三步

1. 总经理要懂点财务知识：

* 资产负债表：
企业在一定日期财务状况的主要会计报表；
* 利润表：
计算及显示公司的盈利状况；
* 现金流量表：
一定时期现金流进/流出动态状况的报表。

2. 平衡好基石部门跟前端打单+后端交付部门之间的投入产出关系。

* 公司初创期，一人多岗，能兼看都先兼着，减少成本；不用请一堆的行政、人事、会计、出纳、仓管、前台……
* 公司的发展扩张阶段，不要财务还是外包（劳动密集型企业的），年底一算账多交40%的税；
* 3. 要平衡好前端打单部门、后端交付部门之间的投入产出关系，避免大量的人力闲置成本。
* 不要公司一群人在前端搞流量、搞成交，后端交付团队交付只有几个人，接不过来，影响口碑；
* 不要公司一群人在前端等客支付，后端打单团队没有实现足够多的精准，商务团队成交率低时，还要求减少；
