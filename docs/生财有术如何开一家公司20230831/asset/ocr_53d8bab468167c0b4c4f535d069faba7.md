# 职位描述：

# 岗位1 职责：

+   1. 管理公司社群日常运营工作及推广工作；

+   2. 负责社群拉新与维护，对用户社群进行分群管理，建立用户体系；

+   3. 运用多种销售技巧拓展付费会员，提升用户价值，为付费会员提供咨询服务及会员在使用过程中出现的问题提供解决方案等；

+   4. 挖掘和分析用户，及时掌握财经新闻热点，建立有效运营手段，策划线上活动提升社群用户量与活跃度，增强用户粘性；

+   5. 配合部门工作。

# 任职资格：

+   1、1年以上用户运营或客服经验，相关工作经验者优先；

+   2、金融、会融、财经类专业优先考虑；

+   3、熟悉线上渠道的推广手段及规则，熟悉社群架构及玩法，懂得规模化运营社群，有完整成功案例优先考虑；

+   4、拥有一定的人际沟通能力与协调处理能力，思维活跃，善于学习。
