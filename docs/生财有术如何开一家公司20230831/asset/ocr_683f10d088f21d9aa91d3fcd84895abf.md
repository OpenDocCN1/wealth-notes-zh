比如对公司，当你创造利润后，公司能活下去，有更多现金流来支撑公司运转，给你更大平台和空间成长，这是一个三方都能得益的事情，也是我们底层驱动力，驱动员工朝着更好的方向去实现梦想。

# 2. 场景布置

举个小细节，单从销售团队来说，小到从工位布局，大到从整个办公环境设置，就是一个销售“场域”

好的场域是从一进入办公室，就能让人感受到这里是来打仗的！这个场域就搭建成了，当然好的销售场域最好是用“制度”管人，而不是人管人。

# 3. 广而告之
