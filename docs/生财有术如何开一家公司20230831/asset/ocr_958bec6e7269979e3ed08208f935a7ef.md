# 手游运营

岗位要求：

+   1、作为运营参与自研自运产品的运营工作；

+   2、参与版本规划，数据分析，活动策划，用户运营等产品运营工作；

+   3、能够与用户打成一片，做好用户运营，了解用户需求，快速响应，通过版本需求和运营事件满足用户。

岗位职责：

+   1、1年以上游戏行业的手游运营经历；

+   2、至少参与过一款手游产品的完整发行工作；

+   3、对运营活动，数据分析，运营类系统策划与跟进，用户运营，整体运营工作，跨部门沟通与协调都有自己丰富的经验；

+   4、热爱游戏产品，能够长期在一线与玩家沟通，倾听玩家声音，深刻理解用户驱动产品和运营的理念；

+   6、抗压，有高度责任心，能面对瞬息万变的行业，以极大热情去开拓新领域。

对于游戏公司手游运营来说， JD 的基本思路还是很清楚的，能明白岗位和职责。但关键的点是在于，你想找一个具有创新思维，有热情去探索新领域的游戏运营，但在 这个 JD 上没有体现出来，你能期待跨行业的童鞋会被你打动吗？
