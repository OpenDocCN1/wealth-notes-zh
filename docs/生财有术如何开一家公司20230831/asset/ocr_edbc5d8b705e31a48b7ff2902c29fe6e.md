# 序

税收的强制性与不确定性

税，从刍、赋、贡、征、役而来。税收自我国复兴以来就一直存在，成为推动中华文明进步的基石。税收具有强制性、固定性、无偿性，但是由于税收政策的统一性和抽象性，也造成税收执行中存在一些与社会经济环境的不适应性，即纳税人端无时不处于一种不确定性与风险性环境，因此，根据社会经济状况发展变化，税收政策需要不断调整，税收改革需要持续推进。

谈到税收的不确定性，也就意味着纳税人面临一定的风险。在我国当前财税改革大背景下，企业自治无限凸显，税收风险遗留在后侧，作为财税从业人员，需要未雨绸缪，从前端规避风险。而税收风险规避的第一步，就是加强对政策的理解与正确应用。

规避税收风险推动税收筹划

税务风险的规避和经济效益的提升密不可分。

无论从财税收入占比、企业税收负担、行业生命周期而言，房地产税收都是一个需要深度研究的课题。

据《经济参考报》消息，地方财政收入中依赖于房地产市场的比重大约占40%左右。从房地产开发商税收成本而言，税改成本占到20-30%，对于大型房地产企业，一年税款上亿甚至几十亿，税收负担同样会成为压垮中小房地产企业的最后一根稻草。房地产行业的税种涉及面广，税收负担重，其他行业无法比拟。在房地产市场下行期间，开展税收筹划的重要性不言而喻，法律框架下的税收筹划是房地产商提升经营效益的重要途径。

理论融入实践的财税操作指南

宏观经济增长放缓政策变革之下，房地产企业面临不可避免的战略调整，税务人员自身知识结构的职能能力提升至关重要。

文怡的这一著作，旨在提升广大财税人员对于税收政策的领悟和把握。文怡曾在总局从事房地产代征和检查审理工作，后又在地产集团负责各业务线管理工作，曾多次到杂志及关于中国税务师等报刊，曾出版《一本书读懂税务筹划与风险防控》，也受多家企业集团、税局和院校邀请讲授专业课程，在税收理论研究和实践操作方面都积累了丰富经验。她对专业的热爱和不倦的探索精神是我们所称道的一种人生情怀。

本书体现了引导式思考的魅力，文怡以案例为引，带领读者思考，进一步剖析税收政策，将税法条文字背后的含义和各税种之间的差异及关联进行了整理与分析，并将企业税、融资业务、合资企业、关联交易、涉外业务及反避税、股权交易、上下游税收以专题进行阐述。本书三易其稿，反复推敲修订而成，成书时50万余字，后压缩为简洁清晰版。

之书。通过阅读本书，读者不仅能够提升对税收政策的理解，还能极大提高对税实践的指导力。这并非一本纯读意义上的教科书，而是一本理论结合实际的财税操作指南。
