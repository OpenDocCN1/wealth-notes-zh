# 客服违规处罚及奖励条款：

+   1.  上班期间从事工作之外的事情，消后息工包括但不限于（看电影、小说、中途请假出去吃饭、耍手机等）。

+   2.  工作时间客服服务态度不符合公司的服务要求包括但不限于消极对待客户，反问客户，讽刺客户，大声质问客户，与客户理论骂脏口等。

+   3.  月比例 1%~3.2 的裁员，2 次当事人与月超额提成自动降低 10%，第三次降 20%，第 4 次 30%，客服连续 1 次/月主管可提请客服组长带领组员跟脸客户口改善申请，恢复提成（盒蓝盈脸道稍略流程）。客服连续 2 次，违规后的第三月主管可申请服务升级恢复提成。经过公司考核后可恢复（盒蓝盈脸道稍略流程）。

+   4.  小组成员违反主管扣罚 50 元/次（公司由查到的，主管自己发现的主管不罚款），第 2 次主管罚款 100 元，2 次以上客服被罚款或者主管定义为消极怠工人员不要从小组管理，主管可向公司申请该员工脱离本组，客服自己找其它组接收自己，如果其他组不接受，无组可去，那么该客服直接由公司管理，无小组接收的客服取消超额提成。

+   5.  每月迟到超过 3 次（包含 3 次）或者请假超过 2 天（包含 2 天）的客服人员（有相应业绩完成抓扣的不计算为入内），当月超额提成自动降低 5%。

+   6.  返佣或者不开单每次扣罚 10 元，（以打卡为意）。

+   7.  客服人员当日业绩未达到 2 万超额提成为 30%，客服人员当月业绩超过 2.5 万且足 3 万的超额提成为 40%，客服人员当月业绩超过 3 万超额提成为 50%。计算现同时按照额提成标准执行。

+   8.  私自吸收客户红包未缴到公司账户，被公司聘请的三方客服回访询问核实出来的，直接辞退，所有工资扣罚，证据直接移交深圳兴合律师事务所及公安机关，停发所有工资，直接开除，证据移交司法机关。

+   9.  未转正员工离职前 7 天提出，转正员工提前 15 天提出，未按照流程离职，强制离职按照旷工处理，旷工 1 天扣 3 天工资。

+   10. 违反职业道德和其他不符合公司规定的视情况处罚。

+   11. 完成 3 万业绩，可以冲抵当月 2 次 20 分钟内的迟到不加款。当月可以冲抵 2 次 4 个小时内的请假不扣款。

# 六、简单规则附能主管权利，减少主管管理时间，多做业绩

+   1.  主管拥有开除组员权利，如果组员被开除，组员只有自己去寻找新的组接收自己，如果没有寻找打到新组接收，组员由公司直接管理，只要是由公司直接管理的组员超额提成自动降低 10%。

+   2.  如果组员有违规情况，比如自己因为客服服务态度不好被处理，只有主管可以申请给组员解除，组员不能自己申请，可以让组员去协调主管之间的微妙关系，解决相互依赖的问题。

+   3.  组员受罚，主管会受到连带责任，也会受罚款，防止相互包庇的行为。目前公司主要用这几条就让组员基本服从主管的管理了。没有用太多的其他条条款款。
