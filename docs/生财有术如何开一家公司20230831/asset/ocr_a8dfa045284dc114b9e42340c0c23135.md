# #案例分享#

大家好，我是刘宁培，在深圳。公司主业是企业咨询+投融资，副业投资点小生意。

今天分享我们公司做企业咨询时，了解企业、了解项目经常用的几个工具，我们就靠这几个工具，做到短时间内，比企业主还了解他们的企业（大企业除外）。

+   - （一）项目全景图、（二）一页纸项目管理、（三）商业模式画布、（四）波特价值链。

尤其是第三个工具“商业模式画布”，教会你用一句话简述“商业模式”，基本上是通用版，每个企业、每个项目都适用。不管是做项目的，还是创业的，都可以好好看看，你项目最缺少的东西，大部分能在这页里面找到。
