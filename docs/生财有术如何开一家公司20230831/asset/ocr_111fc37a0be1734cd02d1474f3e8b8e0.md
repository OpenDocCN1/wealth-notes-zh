# 地图审查关注的主要内容

根据地图审查工作职责，地图审查工作重点审查地图图幅范围、行政区区域界线、我国重要岛屿、涉密内容、重要地理信息数据以及国家规定需要审查的内容。

# 一、地图图幅范围

（一）中国全国

最北端位于黑龙江省漠河县北端的黑龙江主航道中心线上；最南端位于南沙群岛的曾母暗沙；最西端位于新疆维吾尔自治区的乌恰县乌兹别里山口；最东端位于黑龙江与乌苏里江交汇处的黑瞎子岛。

当中国全国将南海诸岛作为附图表示时，地图图幅北、东、西边应顶阿上，南边至南段岛最南端。

南海诸岛附图的图实范围：北边至我国陆地和部分台湾岛；南边至加里曼丹岛上印度尼西亚与马来西亚间的全部界线；西边至越南首都“河内”；东边至菲律宾首都“马尼拉”。
