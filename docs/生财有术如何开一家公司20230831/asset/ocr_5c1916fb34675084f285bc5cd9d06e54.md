# 关于利诱分享朋友圈打卡的处理公告

微信安全中心 2016-08-16

一直以来，微信明确禁止利用以产品功能进行诱导分享的行为。近期，某些公众号、APP软件等主体通过返学费、返实物等方式，利诱微信用户分享其链接（包括二维码图片等）到朋友圈打卡，严重影响朋友圈用户体验。违反了《微信外部链接内容管理规范》，部分主体在处理活动被处理后，只是替换课程介绍页面中的违规字眼，但仍在业务流程中用各种方式利诱用户分享朋友圈打卡，有的甚至通过变换域名、新增类似业务等进行恶意对抗，多次违规。

根据《微信外部链接内容管理规范》，微信禁止通过利诱分享，诱导用户分享、传播外链内容或者微信公众号文章，包括但不限于：现金奖励、实物奖品、虚拟奖品（红包、优惠券、代金券、积分、话费、流量、信息等）、集赞、拼团、分享可增加抽奖机会、中奖概率，以积分兑换金钱利益诱导用户分享、点击、点赞微信公众号文章等；（从其他软件诱导用户分享到朋友圈也属违规）

诱导分享为非常规营销行为，严重破坏正常的朋友圈体验，违反了《微信外部链接内容管理规范》、《微信公众平台服务协议》、《公众账号运营规范》、《微信开放平台开发者用户协议》和《微信个人帐号使用规范》等相关协议及专项规则。一经发现，微信团队将进行如下处理：
