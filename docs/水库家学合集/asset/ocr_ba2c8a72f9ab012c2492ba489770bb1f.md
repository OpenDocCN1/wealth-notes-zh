# 译文

"为学日益"，什么叫学问？学问是靠知识、读书、经验，一点一滴慢慢累积起来的。今天懂一点，明天再懂一点，后天又懂一点，多一分努力就多一分的收获，这就是做学问。人 为的学问是有为法，是有为之道，要慢慢累积增加起来，不是一步登天。

"为道日损"、学道与做学问相反，是要丢掉，"日损就是一天丢一点，明天一点，什么都要放下丢掉。修道的人常笑自己，一方面有欲望学道，一方面又不肯放弃读书，爱读书就是最大的欲望。"
