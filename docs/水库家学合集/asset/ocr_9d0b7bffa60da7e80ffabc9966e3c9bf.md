# HPV是什么?

HPV，即人乳头瘤病毒，是一种最常见的性传播疾病的病原体。常引起外生殖器湿疣、宫颈上皮内瘤变（CIN）等，某些HPV 病毒持续感染还会引起宫颈癌等。

除了有可能导致宫颈癌以外，90% 的肛门癌，40% 的外侧/阴道癌和 12% 的头颈癌与HPV 感染密切相关。
