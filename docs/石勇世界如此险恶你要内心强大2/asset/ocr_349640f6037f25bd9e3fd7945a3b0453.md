# 22. “外向”的意思是：一个人不把自我亮出来，他就等于不存在

问：很多人最喜欢说，“我性格有点内向”“我性格有点外向”。性格的“内向”“外向”是什么意思？

答：所谓“内向”“外向”不是性格的类型，就是说，一个“内向”的人，可能是自卑型性格，也可能是攻击型性格，而一个“外向”的人，可能是表演型性格，也可能是炫耀型性格。

严格来说，它不是什么性格倾向，“内向”“外向”反映的不是一个人的性格特征，而是一个人在心理上世界的关系，是他的一种心理倾向！“内向”就意味着，他害怕把自我暴露出来，因为他在心理上无法控制自我暴露出来的后果。而“外向”则是，如果他不把自我亮出来，他就体验不到他的存在！
