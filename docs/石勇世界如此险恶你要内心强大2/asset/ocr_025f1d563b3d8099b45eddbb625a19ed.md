# 不玩神秘主义，不喊励志口号，不煮心灵鸡汤
继续恶狠狠、掏心窝地直言隐秘的心理真相

+   ◎我们的人生出了问题，至少有一半是心理出了问题。而我们的心理问题，又至少有一半来自头脑的肤浅和紊乱。

+   ◎我们常常干的一件事情是：以杀伤自己的方式，来在心理上给自己疗伤。

+   ◎人们一旦从别人身上获取了心理优势，往往不会收手。

+   ◎骗子和忽悠大师们最高的境界，根本不是去说服你，而是让你自我说服。

+   ◎如果一个人走不出过去，就一定会和现在过不去。

+   ◎有些人看起来不说话，但在他心里面，一直对世界说狠话。

+   ◎只要一个人还记得他是谁，他的话，就一定会透露出这一点。

+   ◎改变我们自己，其实就是改变我们在头脑上和心理上与世界的关系。

+   ◎信任一个人，我们在心理上就解除对他的防御了。

+   ◎喜欢围观的人，内心里有破坏性；不敢去围观的人，骨子里害怕暴力。

+   ◎如果有人对你表示失望，你要看一下，是不是他和你签订了一个心理契约。

+   ◎有心理问题时，正确的方法是不要想着去消除它，而是要澄清它、破译它。
