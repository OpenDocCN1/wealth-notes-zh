# 4.应该怎样选人用人

白金汉和古道尔就给团队领导者提出了三个建议。在我看来，这就和球队主教练选拔和用球星是一样的。

+   第一，你应该要输出，而不是以输入为导向。能力模型是输入，这个人能干出什么才能才是输出。你需要够精确，就应该提供这种输出的信号。至于说这个人的其他方面，那他根本考察不过来。输出导向，要你用人用特长。
第二，把人放到合适的位上上去。这就好像把球员的身材评语进行位置安排一样—要根据你看的人身上有什么样的方向，再根据人协调吩法—而不能让人适应岗位。
第三，各种人才都有，每个人都有特长有缺点，那么下的就是体现你的领导技术了。人越是多样化，你就越需要想办法他们相互交流、理解和配合。
