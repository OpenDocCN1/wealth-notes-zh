特别放送：重新认识“运气”

万维钢

这一期的特别放送，我们总结一下“运气”——到底什么是运气？好运气是天生的吗？成功主要靠努力、还是主要靠运气？灵感和运气有关吗？运气能改善吗？有没有系统提高自己运气的方法？这些问题，不仅仅你关心，世界上顶尖的学者和专家，都很关心。今天我就把这三季日课中，有关“运气”的最新科学研究帮你做个汇总，希望能帮你重新认识“运气”。

# 1.什么是运气？

个人运气的规律有三条，姑且称之为“运气动力学”：

+   1. 运气可以放大
2. 运气可以累加
3. 竞争越激烈，运气越重要。

这个人才流动的时代，就是胜者通吃的时候。胜者通吃的时候，是竞争越来越激烈的时代，是个人能力越来越重要的时代。

如果你能在某个领域中，表现得比所有人都高出一点点，也许你的收入就会比所有人都高出很多倍。

所以这也是运气越来越有用的时代。

戳此复习：运气动力学

# 2.怎样系统地对待运气？

不必在一平一次的输赢，应该关注一生的原则和系统。

要想真正安身立命，得建立自己的系统，而不是别人系统中的一个角色。

过滤短期信息，专注长期表现。对自己的系统保持信心。

戳此复习：怎样用系统下一盘大棋

# 3.运气好的人都什么样？

“相信自己有好运气”和“获得好运气”之间，可能是有联系的。

运气好的人有三个性格特征：

第一是外向。外向者喜欢跟陌生人聊天，他总能注意到那些有意思的人，然后从聊天中获得新的信息。再一点，外向者也善于让别人注意到自己，这样别人也会主动找他。

第二是开放。开放的人愿意尝试新的东西，他对风险没有那么害怕。

第三是神经质程度低。所谓神经质，就是容易焦虑、容易紧张，容易妒妒。而运气好的人恰恰没有这些负面的情绪，做事非常放松。

# 4.怎么才能改善自己的运气呢？

第一，多参加一些新活动，体验一些新东西。运气好的人喜欢尝试新事物，运气不好的人一天到晚就是干自己那点工作。

第二，要相信自己的直觉。如果你直觉上认为一个东西有意思，你就应该大胆探索这个东西。你喜欢什么课程，就去学学呗？运气不好的人还在权衡纠结利弊的时候，运气好的人都已经尝试过了。

第三，要乐观。乐观就是相信自己运气好。乐观的人就敢于尝试。

第四，要善于在坏事中发现好事。哪怕遇到不幸和失败，其中也有希望和机会，这样你就能比更好地恢复过来。

说白了，就是创造机会、发现机会和敢于行动。

# 5.为什么好运气不能延续？

为什么成功电影的续集都不如第一部高？
为什么NBA新秀第一年表现好，第二年就不行了？
为什么父亲有个子高的“好基因”，儿子却矮？
为什么“富不过三代”？

丹尼尔·卡尼曼在《思考，快与慢》里，对回归平均有个很好的解释。想要理解回归平均，你得理解下面这两个公式 ——
成功 = 天赋 + 运气
大成功 = 多一点点天赋 + 很多好运气

你得承认运气的作用。

# 6.怎么让好运尽量延续？

如果你想长久地享受好运气，从一个成功走向另一个成功，就得学会子贡说的“富而不骄”。

# 7.怎么让运气为我所用？

坚持不懈地做下去，成功就可能在任何时候出现。

# 8.怎么帮助别人得到好运气？

如果你想帮助一个人，直接给钱、直接提拔、直接安排选中，其实是不太好的的。

# 9.成功究竟是水平高还是运气好？

科学决策的一个境界是把决策水平和运气分开。头脑清醒的人必须能区分决策和运气。
