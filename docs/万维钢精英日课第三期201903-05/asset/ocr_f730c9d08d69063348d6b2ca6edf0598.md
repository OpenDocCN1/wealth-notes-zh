# 3.阶层与入学考试

+   1. 课外补习对差生最有效；
2. 对数学和英语比较有效，对语文作用不大；
3. 补习的效果主要发生在初中阶段。上了高中以后，课外补习只在数学方面、而且是只对差生有一定的效果。

+   1. 学生的成绩反映了学生的智商；
2. 学生的智商是继承于家长的智商；
3. 家长的财富和学历，反映了家长的智商；
4. 所以学生的成绩才会跟家长的财富和学历有关。
