# 来自日课：博弈设计者

读者 Ada邹：

*比如你的房子按行情能卖100万元*这里有个假设前提，就是我的这个房子的行情价是共识，这里有信息不对称问题，还有信任问题，房产买卖交易属于低频高消费，像58同城、乐有家的2手房交易信息是否降低了信息不对称呢？

万维钢

是的，买卖各方对房子的基本行情有一个共识。对个人来说，房产的确是低频交易，但是对整个市场来说是比较高频的。

# 来自日课：冥冥之中有定数

读者 卫盘螺丝钳赵杰：

一旦出现了绝大多数群体的普遍认同，其实也就很大程度上自我销毁了。就好像《极组》这本书中所描述的清朝晚期，其实如果当时没有西方列强这个最大的干扰因素，清朝已经奋起正寝了，也就不会有后面的所谓中兴了。纳什均衡在达成当下的稳态同时，也一定程度上出现了限制和压制的特征，难道一定要外界的突然打击才能破局吗，能不能从内部自身打破这种“稳态”？

读者 施德兰：

我有个问题，就是男女比例问题。按常识说男生女生应该是随机的吧？我记得我阿姨生了8个女的。这种分布是随机的吗？但是从整体人类来说，男女比例还是很均衡的，我看了很多报道一般都是在一百比一百零几，这是为什么？

读者 杨志峰：

我有个观点，我们大多数人，学完得到其他课程和精英日课后可能会有和自己比的进步，但放到非常多的人的整体看，大部分人依然平庸，有点悲观，但应该是事实。看资本市场是，经济学+博弈论的眼光，但读过很多日课后发现看一项事物需要很多眼光，有时老师告诉我们要有历史的眼光，有时是有思维的眼光，有时是价值观的眼光等……是否大部分的平庸的人依然平庸就是没走这条路呢？
