return 0.5 + 0.5 * (tree.r - tree.d - 0.5 * tree.v*tree.v) * tree.dt / tree.v / math.sqrt(tree.dt)

# ## 13.2.3 偿付函数

偿付函数很简单，是一元函数，输入为标的价格，输出为偿付收益，对于看涨期权来说就是

$pay = \max (S-K,0)$

代码如下：

```
def pay_off (spot):
    global strike
    return max (spot - strike, 0.0)
```
