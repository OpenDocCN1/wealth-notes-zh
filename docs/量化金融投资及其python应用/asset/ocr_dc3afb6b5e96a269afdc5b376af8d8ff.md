# 3. ARCH 模型的建立

首先确定 ARCH 模型的阶次, 可以用$\{a^2_t\}$ 序列的偏自相关函数 PACF 来判定:

```
fig = plt.figure(figsize=(20,5))
ax1 = fig.add_subplot(111)
fig = sm.graphics.tsa_plot_pacf(at2, lags = 30, ax = ax1)
```

由图 7-22 可以粗略定为 4 阶。

然后建立 AR(4)模型:

$$ \begin{array}{l}\sigma_{t}^{2} = \alpha_{0} + \alpha_{1}a_{t-1}^{2} + \cdots + \alpha_{4}a_{t-m}^{2}\\
\eta_{t} = a_{t}^{2} - \sigma_{t}^{2}\\
a_{t}^{2} = \alpha_{0} + \alpha_{1}a_{t-1}^{2} + \cdots + \alpha_{4}a_{t-m}^{2} + \eta_{t}\end{array} $$
