# 9.1 BP神经网络的拓扑结构

人工神经网络是在生物神经系统的启发下发展起来的一种信息处理方法。它不需要构建任何数学模型,只靠过去的经验来学习,可以处理模糊的、非线性的、含有噪声的数据,可用于评价、预测、分类、模式识别、过程控制等各种数据处理的场合。人工神经网络理论研究发展相当迅速,据统计,到目前为止已经提出了 30 多种神经网络,其中最流行的有十几种。BP 神经网络(Back Propagation,反向传播)是当前应用最为广泛的一种神经网络,它的结构简单,工作状态最易于硬件实现。其应用范围主要有识别分类、评价、预测、非线性映射、复杂系统仿真要等。因此,本章应用 BP 神经网络来研究现金流因素分析的分类问题。

BP 神经网络是典型的多层网络,分为输入层、隐含层和输出层,层与层之间多采用全互连方式,同一层单元之间不存在相互连接,BP 神经网络的拓扑结构如图 9-1所示。

设输入向量为 $\boldsymbol{X} \in \mathbf{R}^{n}, \boldsymbol{X}=(x_{1}, x_{2}, \cdots, x_{n})^{T}$; 隐含层有神经元 $Z \in \mathbf{R}_{1}, Z=(z_{1}, z_{2}, \cdots, z_{l})^{T}$; 输出层有神经元 $Y \in \mathbf{R}^{m}, Y=(y_{1}, y_{2}, \cdots, y_{m})^{T}$。设输入层与隐含层之间的连接权为 $w_{iy}$,阈值为 $\theta_{j}$; 隐含层与输出层之间的连接权为 $w_{jk}$, 阈值为 $\theta_{k}$。各层神经元的输出满足

```
$z_{j}=f\left(\sum_{i=1}^{n} w_{i y} x_{i}-\theta_{j}\right) \tag{9-1}$
```

```
$y_{k}=f\left(\sum_{j=1}^{l} w_{jk} x_{j}-\theta_{k}\right) \tag{9-2}$
```

函数 $f(\ast)$ 满足

```
$f(u_{j})=\frac{1}{1+e^{-u_{j}}} \tag{9-3}$
```

```
$F: X \subset \mathbf{R}^{n} \rightarrow Y \subset \mathbf{R}^{m}$
```
