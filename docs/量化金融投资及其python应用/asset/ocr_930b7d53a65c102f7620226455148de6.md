# **1. 二次规划问题的标准形式**

二次规划问题的标准形式如下：

```
min 1/2**x**^T*Px* + **q**^T**x**  
s.t. **Gx** ≤ **h**, **Ax** = **b**
```

上式中,**x**为所要求解的列向量, **x**<sup>T</sup>表示 **x** 的转置。

上式表明, 任何二次规划问题都可以转化为上式的结构，事实上用 CVXOPT 的第一步就是将实际的二次规划转换为上式的结构, 写出对应的 **P**, **q**, **G**, **h**, **A**, **b**.

目标函数若为求 **max**, 可以通过乘以−1 将最大化问题转换为最小化问题。

**Gx**≤**b** 表示所有的不等式约束，同样, 若存在诸如 **x**≥0 的限制条件, 也可以通过乘以 −1 转换为≤的形式。

**Ax** = **b** 表示所有的等式约束。

# **2. 求解过程示例**

二次规划问题如下：

```
min 1/2*x*<sup>2</sup>+3*x*+4*y*  
s.t.  *x*,*y* ≥ 0, *x*+3*y* ≥ 15, 2*x*+5*y* ≤ 100, 3*x*+4*y* ≤ 80
```

在此例中, 需要求解的是 *x*,*y*, 可以把它写成向量的形式, 同时, 也需要将限制条件按照前面介绍的标准形式进行调整, 用矩阵形式表示, 如下所示：

```
min(*x*,*y*) 1/2 [ 1 0 ; 0 0 ] [ *x* ; *y* ] **x**^T [ 0 0 ; 0 0 ] [ *x* ; *y* ] + [ 3 ; 4 ]^T [ *x* ; *y* ]  
[ -1  0  -1  2  3 ] [ *x* ; *y* ] ≤ [ 0 ; 0 ; -15 ; 100 ; 80 ]  
[ 0  -1  -3  5  4 ]
```

如上所示, 目标函数和限制条件均转化成了二次规划问题的标准形式, 这是第一步, 也是最难的一步, 接下来就简单了。

对比上式和标准形式, 不难得出

```
**P** = [ 1  0 ; 0  0 ],  **q** = [ 3 ; 4 ],  **G** = [ -1  0  -1  2  3 ; 0  -1  -3  5  4 ],  **h** = [ 0 ; 0 ; -15 ; 100 ; 80 ]
```

接下来就是几行简单的代码, 目的是告诉计算机上面的参数具体是什么。

```
from cvxopt  import solvers, matrix  
**P** = matrix([[1.0,0.0],[0.0,0.0]])  #matrix区分 int 和 double,数字后要加强小数点  
**q** = matrix([3.0,4.0])  
**G** = matrix([[-1.0,0.0,-1.0,2.0,3.0],[0.0,-1.0,-3.0,5.0,4.0]])  
**h** = matrix([0.0,0.0,-15.0,100.0,80.0])
```
