```
if 条件 1:
    执行语句 1
elif 条件 2:
    执行语句 2
else:
    执行语句 3
```

注意 if、elif 和 else 是对齐的，不能有缩进：

```
t = 3
if t < 3:
    print 't < 3'
elif t == 3:
    print 't = 3'
else:
    print 't > 3'
t = 3
```

# 2. while 语句

while 语句的格式为

```
while 条件 1:
    执行语句
    if 条件 2: break
```

例如：

```
a = 3
while a < 10:
    a = a + 1
    print a
    if a == 8: break
4
5
6
7
8
```

虽然 while 后面的条件是 a<10，即 a 小于 10 的时候一直执行，但是 if 条件中规定了 a 为 8 时就中止循环，因此，执行结果只输出到 8。

# 3. for 语句

for 语句的格式为

```
for 条件:
执行语句
```

for 语句可以用于遍历一个序列/字典等。例如：

```
a = [1,2,3,4,5]
for i in a:
    print i
```
