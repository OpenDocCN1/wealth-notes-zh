# 3.5 访问数组和矩阵元素

数组和矩阵元素的访问可通过下标进行，以下均以二维数组（或矩阵）为例。

```
a = np.array([[3.2, 1.5], [2.5, 4]])
print a[0][1]
print a[0, 1]

1.5
```
