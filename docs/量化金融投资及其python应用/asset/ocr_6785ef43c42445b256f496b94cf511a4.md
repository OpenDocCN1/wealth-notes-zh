# 4.3.1 无约束优化问题

所谓无约束优化问题指的是一个优化问题的寻优可行集合是目标函数自变量的定义域，即没有外部的限制条件。例如，求解优化问题

Minimize  $f(x)=x^{2}-4.8x+1.2$

就是一个无约束优化问题，而求解

$$\begin{array}{l}\min \quad f(x)=x^{2}-4.8x+1.2\\\mathrm{s.~t.}\quad x \geqslant 0\end{array}$$

则是一个带约束的优化问题。本节更进一步假设考虑的问题全部是凸优化问题，即目标函数是凸函数，其自变量的可行集是凸集(关于凸优化问题的详细定义可参考斯坦福大学Stephen Boyd 教授的教材Convex Optimization，下载链接：http://stanford. edu/～boyd/ cvxbook)。

下面以 Rosenbrock 函数

$$f(x)=\sum_{i=1}^{N-1}\left(100\left(x_{i}-x_{i-1}^{2}\right)^{2}+\left(1-x_{i-1}\right)^{2}\right)$$

作为寻优的目标函数来简要介绍在 SciPy 中使用优化模块 scipy. optimize 的方法。

首先需要定义 Rosenbrock 函数：

```
def rosen(x):
"""The Rosenbrock function"""
return sum(100.*x[1:-1]-x[:-1]**2.0)***2.0 + (1-x[:-1])* *2.0)
```
