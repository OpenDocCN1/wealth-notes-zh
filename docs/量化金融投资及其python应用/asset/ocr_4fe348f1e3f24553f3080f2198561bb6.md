```
returns = np.log(data / data.shift(1))
```

# 3. 给不同资产随机分配初始权重

假设不允许建立空头头寸，所有的权重系数均在0、1之间。

```
noa = 4
weights = np.random.random(noa)
weights /= np.sum(weights)
weights
```
