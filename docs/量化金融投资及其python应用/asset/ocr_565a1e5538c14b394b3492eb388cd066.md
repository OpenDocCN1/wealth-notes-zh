# 7.2.4 拟合优度及预测

# 1. 拟合优度

使用下面的统计量来衡量拟合优度：

> R\textsuperscript{2}=1− 残差 的 平 方 和 总 的 平 方 和

但是，对于一个给定的数据集，R\textsuperscript{2}是用参数个数的非降函数，为了克服该缺点，推荐使用调整后的 R\textsuperscript{2}：

> R\textsubscript{Adj}\textsuperscript{2}=1− 残差 的 平 方 的 方 差

它的值在 0、1 之间，越接近 1，拟合效果越好。

下面计算之前的上证指数日收益率的 AR 模型的拟合优度：

```
score = 1 - delta.var()/temp[17:].var()
print score
0.0405166950061
```

可以看出，模型的拟合效果并不好，当然，这并不重要，也许是这个序列并不适合用 AR 模型拟合。
