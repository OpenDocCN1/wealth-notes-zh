# ### 14.1 热传导方程

本节使用热传导方程作为偏微分方程的例子：

$u_t - \kappa u_{xx} = 0, \quad 0 \leqslant x \leqslant 1$    (14-1)
$u(x,0) = 4x(1-x), \quad 0 \leqslant x \leqslant 1$    (14-2)
$u(0,\tau) = 0, \quad \tau \geqslant 0$    (14-3)
$u(1,\tau) = 0, \quad \tau \geqslant 0$    (14-4)

其中, $\kappa$ 称为热传导系数。

式(14-2)称为方程的初值条件(initial condition), 式(14-3)和式(14-4)称为方程的边值条件(boundaries condition)。这里使用 Dirichlet 条件。

可以看一下初值条件的形状：

import seaborn as sns
import numpy as np
