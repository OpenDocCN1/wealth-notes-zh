```
dx = X / N
dt = T / M
kappa = 1.0
rho = kappa * dt / dx / dx
```

这里做正向迭代：迭代时 $k=0,1, \cdots, M-1$，代表从 0 时刻运行至 $T$。

```
for k in range(0, M):
    for j in range(1, N):
        U[j][k + 1] = rho * U[j - 1][k] + (1. - 2 * rho) * U[j][k] + rho * U[j + 1][k]
    U[0][k + 1] = 0.
    U[N][k + 1] = 0.
```
