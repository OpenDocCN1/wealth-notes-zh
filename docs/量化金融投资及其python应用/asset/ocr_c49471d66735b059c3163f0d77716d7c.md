# ### 4.3.2 有约束优化问题

有约束优化问题的一种标准形式为

> min $f(x)$
s. t. $g_{i}(x) \leqslant 0, \quad i=1,2,\cdots,m$
$\mathbf{A} \mathbf{x} = \mathbf{b}$

其中 $g_{1},\cdots,g_{m}$: $\mathbf{R}^{n}\rightarrow \mathbf{R}$ 为 $\mathbf{R}^{n}$ 空间上的二次可微的凸函数；$\mathbf{A}$ 为 $p \times n$ 矩阵且秩 $\operatorname{rank}(\mathbf{A})=p<n$。

考察如下的例子：

> Minimize $f(x, y)=2 x y+2 x-x^{2}-2 y^{2}$
subject to $x^{3}-y=0$
$y-1 \geqslant 0$

    """ Objective function """
    return sign * (2 * x[0] * x[1] + 2 * x[0] - x[0] ** 2 - 2 * x[1] ** 2)
def func_deriv(x, sign=1.0):
    """ Derivative of objective function """
    dfdx0 = sign * (-2 * x[0] + 2 * x[1] + 2)
    dfdx1 = sign * (2 * x[0] - 4 * x[1])
