为了平稳时间序列，后面会介绍这种处理。

下面给出平稳性的定义：

如果对所 $	ext { 有的时刻 } t$、任意正整数 $k$ 和任意 $k$ 个正整数，$\left(t_{1}, t_{2}, \cdots, t_{k}ight)$ 和 $\left(r_{t_{1}}, r_{t_{2}}, \cdots, r_{t_{k}}ight)$ 的联合分布与 $\left(r_{t_{1}+l}, r_{t_{2}+l}, \cdots, r_{t_{k}+l}ight)$ 的联合分布相同，就称时间序列 $\left(r_{i}ight)$ 是强平稳的。即 $\left(r_{t_{1}}, r_{t_{2}}, \cdots, r_{t_{k}}ight)$ 的联合分布在时间的平移变换下保持不变。这是一个很强的条件，而我们经常假定的是平稳性的一个较弱的方式。

若时间序列 $\left(r_{i}ight)$ 满足下面两个条件：

$E\left(r_{i}ight)=\mu, \quad \mu 	ext { 是常数 }$ 

$\operatorname{Cov}\left(r_{i}, r_{i-l}ight)=r_{l}, \quad r_{l} 	ext { 只依赖于 } l$

则称时间序列 $\left(r_{i}ight)$ 是弱平稳的。即该序列的均值和 $r_{i}$ 与 $r_{i-l}$ 的协方差不随时间而改变，$l$ 为任意整数。

在金融数据分析中，通常所说的平稳序列是弱平稳的。

差分就是求时间序列 $\left(r_{i}ight)$ 在 $t$ 时刻的值 $r_{t}$ 与 $t-1$ 时刻的值 $r_{t-1}$ 的差，不妨记做 $d_{t}$，这样就得到了一个新序列 $\left\{d_{i}ight\}$，为一阶差分。对新序列 $\left\{d_{i}ight\}$ 再做同样的操作，则为二阶差分。通常非平稳序列可以经过 $d$ 次差分，处理成弱平稳或者近似弱平稳时间序列。如图 7-1 第 4 张图所示，可以看到二阶差分得到的序列比一阶差分效果更好。
