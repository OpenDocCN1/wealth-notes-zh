# ### 3.7 缺失值

缺失值在量化分析中也是一种信息，NumPy提供了nan作为缺失值的记录，通过isnan函数判定是否为缺失值。

```
a = np.random.rand(2,2)
a[0, 1] = np.nan
print np.isnan(a)
[[False True]
 [False False]]
```

nan_to_num函数可将nan替换成0，在6.3.2节将介绍pandas提供的指定nan替换值的函数。

```
print np.nan_to_num(a)
[[ 0.58144238 0.
 [ 0.26789784 0.48664306]]
```
