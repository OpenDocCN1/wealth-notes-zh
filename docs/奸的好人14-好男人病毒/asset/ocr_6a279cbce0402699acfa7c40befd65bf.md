# 痴缠的乞丐

从前面的几篇文章中所探讨的几个“好男人”个案，我们都可以看到一个共同点——当好男人变成女人勿近的“瘟疫”时，好男人会觉得委屈。

有的在跟女生交往时，简讯越传越多的时候，女方就开始表明态度是只能跟他做朋友。好男人逼于无奈的妥协，跟女生说：“好吧，大家就做朋友吧。”

他的心中认为只要能够保持着朋友的关系，就还有一线生机。他会稍微的守守规矩，然后为了尽快让这一线生机变成转机，就会“再续前愚”，继续的加强电话简讯的关怀攻势。

我称这种为“痴缠的乞丐行为”。

在一轮攻势后，又收不到女方简讯回复时，还会发个有“火”的埋怨简讯：“怎么我传简讯给你，你都不回复给我。”

# 辅导师的功德全部消失

以下是一个读者给我的留书，他虽然在失败中体验到我们书中所说的“不要跟追求的女生做辅导”，也明白了做好男人的下场，但我希望大家看看这个好男人做辅导背后的动机，这是很经典的好男人病毒：

过去我帮过了位女生渡过种种难关（也就是说我用了“好男人”的追求法），没有我的话当时她的日子会过非常之痛苦，而且她的学业也会有很惨的下场。

当我用尽了所有力量去帮助她时，其结论只是证实了江老师的主张——“帮助未到手的 女生等于斩自己的小弟另”，因为事后她生活恢复正常时（也就是说我的价值变小），她就将过去我的功劳完全归自己（我当时是跟她吵了两天），然后回过头来跟她的朋友一齐把我当成贱价的人渣看待。

我抗议说：“你这叫恩将仇报！”

她回应：“不见得你对我存在着什么恩惠？”
