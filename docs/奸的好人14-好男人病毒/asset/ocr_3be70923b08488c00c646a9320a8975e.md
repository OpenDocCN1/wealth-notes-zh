# 应付诉苦的女生

有些女人喜欢长篇大论的讲自己过去的感情，特别是之前的那些有不好结局的感情，或者细数对她不好的前任男友。特别是如果你跟她第一次约会，她就跟你讲这种话，她对你那方面的兴趣还是不大，甚至可能是你还未擦出足够的火花，当然还有另一个可能性是：她是瘟疫女。

我不是说如果女生第一次跟你见了面就诉苦，就表示没救了。我可以接受听她讲前任男友如何伤了她，但我只能接受听一次。如果第二次见面时，她又重提的话，我就会尝试用话术来做转移。如果我转移了过后，她还是重提的话，表示她还未准备好把过去放下。

这个时候我会有两种做法：一，如果我确实对她很有兴趣，而且她看起来也不像是“瘟疫女”（放不下不一定等于瘟疫女），我就会选择用NLP的技巧把她的这个记忆淡化。二，如果她放不下，同时我确定了她是“瘟疫女”（即除了前任男友伤过她，她还认为每个人都伤过她），我不会浪费时间，我会马上放下。

那么男读者最关心的问题就是：“如何不让女生不断的说她的心事和诉苦？”

# 错误的“情绪式”四两拨千斤

你若没有吸引她的话题，又不主导着话题，而且又是一个很好的聆听者（好男人往往是聆听者），女方会很自然的就开始跟你讨论姐妹群谈论的话题，而姐妹话题中就少不了要诉诉苦。

如果女方在初次约会就讲出自己的烦恼和痛苦，你就稍微认同一下，因为你不让她觉得你完全不关心她的感受。然后紧接着就要转去其它更精彩的话题，这就是四两拨千斤。

这个认同是有技巧的，你不要认同她话中的某些特定字眼，更加严禁认同她话中情绪元素很重的字眼。

举例，她说自己的前任男友在她的背后跟其他女生交往，她觉得男友不尊重她。如果你说：“我很认同你的说法，两个人在一齐的最基本，就是尊重。”

“尊重”这两个字就是情绪元素很重的字眼，只要你一讲出这两个字的话，她就会觉得你实在很了解她，还触动她内心的郁结，她就会开始喋喋不休的把自己当时的情况和痛苦道出。

而好男人还会笨到要想问出更多细节，你越问，对方就越投入于过去不好的回忆中，这个过程在我们的《印象洗脑术》中称为“重新逼真化（Revivification）”。
