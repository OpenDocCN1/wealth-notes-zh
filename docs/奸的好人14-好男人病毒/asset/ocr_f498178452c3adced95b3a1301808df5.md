# 后记 江郎鬼才的“大男人真言”

女友批准你搞其它的女人？

我以前的女朋友曾经有一次跟我闹情绪，她在电话上跟我说：“其实外面还有很多比我更好的女性，你应该去找她们做你的女朋友。你要找其它女人上床也不要紧，我和你也只是朋友关系而已，我不会介意的。”

记得，女友讲这种话，她不是在批准你出去乱玩，而是讲反话。假如我说“好啊”的话，她肯定会发更大的脾气。假如我说她是最好女人，我不想找其它女人，她却说不相信。这个两难的格局怎么办？

这个情况就好像女友跟你说如果你被其它女人吸引，她要你坦白告诉她，她要你们俩之间没有秘密。但，你若真的告诉她你对哪个女生有性幻想，她就会开始闹脾气了。

> 江郎鬼才有话说：女人的行为很矛盾，但她一点都不觉得自己矛盾。

女人到底要听真话还是假话？

她就好像犯人的辩护律师般，一些辩护律师会跟客户说：“我要你小心的听我以下这翻话。身为你的辩护律师，我的专业操守是不准许我为你说谎的。我要你听清楚，我…是不能为你说谎的，你明白我的意思吗？”

注意，他没有说犯人不能说谎。但，犯人不要笨到告诉自己的律师自己说谎。这就是好男人跟自己女人互动时，常会遇上的一个两难困境：“我若骗她而过关，我则对不起自己的良心。我若坦白的话，却又过不了关。他妈的，我该怎么办？”

当时我被前女友问了这个两难的问题后，我并没有如犯人般编侧谎言出来。我没说我要找其它女人，也没说她是她心目中最好的女人，我只是把心中感受到的事实说出。我说出了我的“一大男人真言”。

大男人真言

她听了我这一翻话后，马上忍不住的哭了出来，哭泣了几分钟后，她终于开口说：“真希望你就在我身边。”
