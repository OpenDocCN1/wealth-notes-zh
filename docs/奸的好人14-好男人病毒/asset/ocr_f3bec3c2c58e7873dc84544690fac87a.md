# 好男人通病：急于向女人证明

好男人因为觉得需要得到女人的认同，所以很多时行为上都是向女人证明这个、证明那个的。为什么他要关怀女生？他希望能向女生证明他的诚意。

在本书前端“很有创意的拒男系统”中提到一位台湾的学员刚开始的时候因为以无辜行为来邀约女生，结果邀约回避了他，他也逼不得已的放下她了。后来他看了我们《奸的好人系列书》时，已经是放下半年后的事。他接下来以悟性明白了自己过去追女成功和失败的关键分别，然后重新追求成功。

话说有一天他和女友在看着台湾的综艺速配节目，节目中的一名人气最旺的女生在描述自己的择偶条件时，说出了她讨厌性格不成熟的男生，同时要求自己的未来伴侣是有经济基础的人。接下来节目中参加速配的一位男生就不断的说自己是如何的成熟，还说自己虽然未有雄厚的经济基础，但他正在很努力的赚钱。

我这位台湾的男学员一听这电视上的男生如此说，他忍不住的破口大笑，因为他明白男生越向这位人气女生证明自己，他的价值反而就会越来越低。当时台湾学员的女友问他到底在笑什么，他就说没什么，也没跟女友解释电视上的这位男生其实正在削小着自己的睾丸，而且越削越小。

但，一个有价值的男人，他就有办法让女人向他证明。

# 借李老师的口来拍马屁

在好几年前，某个电台定时的每个星期邀请我上节目成为嘉宾，女主持人是个气质型女生，她有一双大大的眼睛和一把清脆的声调，我和她在空气中的互动非常有火花，而且有时候她还会在节目中以她的声音来做角色扮演。

在我上了她的节目几次后，李民杰老师在听了节目后，他说我的声调在电台上的时候有了 一个特色。我听到了李老师给我的回馈后，我就想到了下一次做节目时，我一定要跟这电台的主持人分享李老师的见解。
