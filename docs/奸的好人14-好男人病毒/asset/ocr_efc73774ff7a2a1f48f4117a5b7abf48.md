# 维持期和追求期送礼方法的异与同

有些读者若已经看了我的《爱情阴谋论》，就必定知道什么叫做送礼的“四不定时则”。根据“四不定”的做法，你是很随机的有时候该送的就送，有时候该送的也不送，时而不该送你也送，时而不该送的话，你就不送。若你以“四不定时则”与上面所说的“奖赏强化理论”对比来看，你可能会觉得有其矛盾之处。

若依“四不定”的其中一个架构：不该送的时候你也送，这不会强化她那些“不该”的行为吗？

答案很简单，“奖赏强化理论”主要是在追求阶段的时候用，“四不定”则在维持感情阶段就很重要。

但，你若看高手K的鲍鱼故事，他显然是用“奖赏强化理论”，但因为他做得即兴，所以也附带一点的“四不定”。而且，在维持感情的阶段时所用的“四不定”的莫中一招就是“该送的时候就送”，这其实也是“奖赏强化理论”。

在追求期的送礼，就是要做到上面所说那种一举三得的效果：“特别印象”、“强化女方对你的喜爱”和“即兴浪漫”。

# 如何跟女人谈心才不会沦落为好男人？

# 要谈心还是要谈爽？

我记得有一次我在国外时，我分别搭讪过两个女生，一个是澳洲妹，另一个是墨西哥妹。

澳洲妹的那一场搭讪是在夜店，我跟她聊了三个小时，而墨西哥妹我是在等巴士时搭讪，只跟她聊了还不到四十分钟。两个女生我都交换了电邮，在回国后，我传了电邮给这两个女生。

澳洲妹在回复时，只是两三行字而已。

墨西哥妹则写了整篇文章来回复我，而且还在电邮中拍我马屁，暗示她很仰慕我这种男人。而且墨西哥妹还一直跟我互传电邮，又说她的生日会中她父亲请来了Mariachi乐队（墨西哥街头乐队，戴大帽子，穿上加斗牛服装的，寄来了乐队和她跳舞时所摄的照片。因为远水不能救近火的关系，我就开始渐渐没再跟她联络。
