# 女人喜欢废话连篇论爱情

女人喜不喜欢男人记得她讲过的话？

曾经在台湾的 NLP 大师 Hogan Lee 的部落格中，有一个人问起了一个策略上的问题，要网上的 NLP 诸友帮个忙。（注：有兴趣的朋友，这一篇网志在 Hogan 老师部落格的网址是：

这位男生对自己长辈所介绍的一位面包店的门市小姐有兴趣，虽然跟对方交换了电话号码，但对方都没接他打的电话。面包店小妹的官方声明是说她那段时间比较累，所以很早早就睡了。

（注：这本书的下一章我就会解释到这位面包店小妹回避男生电话的原因。）

他的问题是：怎样能够让女生对他好奇，期待他打过去的电话？

好多个朋友都给了不错的答案，其中最让我留意的是一女生给的答案。

她的建议是：“身为女生的我一定要说说话，女生啊！最容易被『记住自己说过的话』的男生吸引。就算是帅哥也一样（帅，久了又不能当饭吃）。信念很重要，要相信自己可以。然后记得女生说过的话，例如喜欢吃碗粿，又是台南人，明天就跑到台南买碗粿（这只是例子，大家不要想太多）。包准她感动到心里去（永远记得那碗粿的滋味）。这样亲切感马上就有了，第二步她就会接你的电话了，因为你是唯一会记住她说过的话的人，再来约出门就不难了……加油”

基本上，她的意见是女人最喜欢男人记得她讲过的话，例如她喜欢某些东西，你就记起来，然后找机会让她知道你很有心。这个策略可以用四个字来形容：“细心关怀”。
