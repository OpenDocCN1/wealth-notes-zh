# # 江郎鬼才骂女人的三重转

# ## 我被当成后备约会男

我记得以前在追着一个很漂亮的女生时，因为我和她都很忙，所以很辛苦的才找到大家有空的时间出来见面。在吃了个不到一小时的晚餐后，我就建议我们去喝些东西，她却跟我说：“哦，不能，我等一下还要见另外一个人。”

我听了后有点纳闷，因为这是她第二次找我来充塞她的时间，，我只是她用来打发她下一个约会前的空档。她第一次拿我来塞时间，我还会觉得她可能是无意的，但如果连续的发生第二次，我就觉得这是故意了。

她见我的反应，就开始扮可爱、讲搞笑的来过关。

之后我送她到她的车子的时候，我就很冷静的跟她说：“我很少见到你，所以想花多点时间跟你在一齐…如果以后你跟朋友有约而只是叫我来填饱肚子，你不需要找我，我相信很多男人都肯陪你吃饭。”

她还是以装可爱讲笑的方式过关，我听她讲话时，已经很想摇头了。

# ## 儿童不宜的留言

我进入了我的车子后，拔了个电话给她，问她：“你有没有什么东西要跟我讲？”

她开始火大，说我这ㄍ男人怎么这么不大方，然后就挂了她的电话。我再拨一次，她不接。我想了想，终于想到要跟她讲些什么话。我这些话要分成两个部分来讲。

大约半小时后，我再拨个电话给她，她还是不接，而我就是预计了她是不接电话的。
