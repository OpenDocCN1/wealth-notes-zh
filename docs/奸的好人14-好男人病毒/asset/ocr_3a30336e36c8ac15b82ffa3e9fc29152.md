# 好男人病毒之自封无辜烈士

事业心重、不想谈恋爱，但又不直接拒绝

以下是一位读者所问关于男追女的问题，我把这一问题呈列这里，其中一个目的是给上过道女班的人做反面教材，让你们更明确的加强自己在情场上的“阴阳眼”：

老师，我追求一个女孩，我们相处了半年左右，我可能不小心的也跟她做了很多辅导、听她的心事。她是那种吃软不吃硬的女孩，即是说只要你态度强硬她一定不爽，好声好气的说她就会心软的听。

她对爱情甚少幻想和渴望，给人的感觉是她的事业心重过爱情。

她喜欢什么事都说清楚，因为她不喜欢家人、朋友、别人妄加猜测她。她清楚我对她的感情，但她的答案是：目前不想谈恋爱。

我叫她直接拒绝我，让我死心，她不说话却露出不忍的表情。

我只能说他对方的这个判断是不准确的，因为是以一厢情愿的心理来推测而已。

解读女人拒绝男人的理由

当女人在追求者的面前讲“我现在不想谈恋爱，因为要专心在我的事业上”时，你认为这是理由还是借口？

如果女人对你说她目前不想谈恋爱，她不是不想谈恋爱，她只是不想跟“你”谈恋爱。

就好像甄子丹电影《叶问》，当他饰演的叶问打败一北家拳挑战者时，挑战者垂头丧气说：“今天北派拳法输了给南派拳法。”

他用了宏观转移法来认输，变成是拳法派别上的输赢。

甄子丹却把他从宏观拉下来，他说：“这不是北家拳的问题，这是“你”的问题。”女生如果遇到一个能制造火花的男人，就不会讲这类我们称为打发男人的废话借口。

这位读者说女方“不喜欢人家妄加猜测、什么事都要说清楚”，这个就更矛盾了。若真的什么都说清楚，为什么还会拖泥带水的不拒绝他呢？

其实，她只是不想做人做到极度分明而已，她还相信“今日留一线，他日好相见。”她根本不是什么都喜欢说清楚的人。
