# 一拒有一因，一推有一由

其实这个女生当时根本不想跟他出去，他却不撞，只知道要用诚意和坚持来感动她，听到星期天没空，就从星期一问到星期六。

就算你很有诚意，女方还是一定会令每一个拒绝都有它的理由。

“你星期天有空吗？”

“星期天不能，因为星期一的工作会很忙，我需要养精蓄。”

“那么星期一呢？”

“因为休息了两天，星期一我们的公司会有很多事情要做，所以下班后会很累。”

“星期二可以吗？”

“星期二也不能，因为星期一做了很多事情，我们就要在隔天开会检讨，通常会很晚才下班。”

“哇！你好忙啊，礼拜三有时间吗？”

“礼拜三要是交我们检讨的报告…礼拜四我要在家看电视连续剧，Desperate Housewives 是我每个星期四都追看的，我不想错过了一集…”
