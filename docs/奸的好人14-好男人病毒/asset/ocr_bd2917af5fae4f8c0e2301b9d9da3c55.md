# 女生不赴约的官方理由

以下一位追女班学员的留书，他是上完课后才把他的过去告诉我。我犹记得他在课程中问我：“如果女方的工作真的很忙，每次约她她都没时间出来，要怎幺办？”,
我说：“忙到完全不能出来见面？”
“对，她真的非常非常的忙。”,
我当时只是觉得很奇怪，．因为我认为没有人说会忙到要跟朋友见个面都成问题，所以基本上我在课堂中只是叫他接受事实。不过，课程后他给我留书报告他过去的一个个案，我看了后才明白为什么女生没时间见他。
