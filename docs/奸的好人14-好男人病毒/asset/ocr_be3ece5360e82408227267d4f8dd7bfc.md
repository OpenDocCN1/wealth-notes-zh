# 不小心放电的效果

Carm 也是一位常经过我的便利店的女生（不是那位多伦多大学的女生），她不完全 是白种人，可能是希腊、意大利或犹太人。她身材是瘦小、不高、肤色是浅橄榄色、看起来 很舒服，属气质型的女生。（若要我比较的话，Chantal 会比我更艳，Carm 是乖女型的。）

她给我“电”到每天早上经过时，就会对我笑得很甜。直到有一天我的”电眼神功"发出了 我想象不到的功力。

她在经过我店前时，当我们如常的眼神接触时，我的眼神可能就像“我有话要告诉你" 般，所以她进入了能量最低点，停下来。她看着我的表情就好像想问我“Yes?”般，眉毛有 少许上扬，但她用这个表情看着我的时候，她才惊讶的记起原来我并没有跟她讲过任何话， 所以她也微微的尴尬。

# 不知所措的装病

我见她如此的有能量最低点，轮到我问她：“Yes？”

然后，她紧张的惊醒过来说：“呃……呃……没有，我…我有点不舒服。”

我心里偷笑，但表面上我还是问她：“你OK吗？你需不需要头痛药？”

她说：“不需要，不需要，谢谢。我没事。”

她离开后，我心中暗想：“嘿嘿，电眼神功的功力又提升了。Yes!”,

第二天她经过我的店前时，她做了一个举动让我信心大增。

# 眼神换取礼物

她手上拿着两杯咖啡跟我说：“刚才我经过 Tim Hortons，我买了一杯加糖黑咖啡给你， 你喝咖啡吧？”（Tim Hortons 是一家多伦多卖咖啡和 Donuts 甜圈的连锁店）
