# 菩萨脸，色狼心

男读者们，你听到 Elton John 跟你讲这翻话，你觉得他的信息有什么不对称？

你们也想象一下，如果那位女模特儿窃听到这位男学员的“无条件中有期待”的宣言，她又会有什么反应？

> **江狼鬼豺有话说：** 好男人觉得自己对女生做“开心”行为，女生却觉得好男人开心“性行为”。

在女人的眼中，这种男人是披菩萨外衣的色狼。女人已经是很难讨灰色狼了，但对这种“外菩萨内狼”的男人会有更加不安的感觉。

（广告时间：这位学员不是我追女班的毕业生，追女班的毕业生起码已经被我这位师父告诫过不能对女生讲这一种“无条件中有期待”的话，在我的追女课程中，这位学员的故事一早就已经是被列为教材的。）

我也不禁的问自己：“为什么男人会讲这些如此经典的话？”

这位学员的自白虽然很经典，但他也不敢对女生坦白。不过，我另外一位学员却比这“无条件有期待”的大胆，他的故事同样的被我列为追女班教材，因为他跟上面那位学员的说法是反其道而行的——“无期待有条件”。

他说他认识了一个女生三个月，女方给他的反应一直都不错，不知为何最近完全不再跟他联络，他问我有什么方法帮助他。

认识女生→女生反应不错→不知为何女生回避他。
