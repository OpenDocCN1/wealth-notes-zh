# 女人诉苦的目的，就是为了诉苦

不少的老公在听太太诉苦后，就会马生给予建议要如何解决问题。我有一个朋友的太太就是常回到家就投诉老板怎样不好，朋友听老婆投诉多次后，就给了她几个建议，不过奇怪的事情就发生了。

每次我的朋友建议她辞职或换公司，他的老婆必定都有理由。如：现在还不是时候，因为她要把某个计划先弄好；又或者说现在的行情不好，冒冒然出去面试的话，得到的薪水不会太高；总之朋友的每一个建议都被否决掉。

> 江郎鬼才有话说：女人有有时候的诉苦，就只是純粹要诉苦而已。

所以就算老公一片好意要帮忙老婆解决问题，你还是忍著。所以从老公的角度，有些男学员会问我：“江老师，我看过老婆的这种情况，若再走下去，一定会出什么问题，难道我知道了她会出什么问题，我不阻止她吗？”

# 不断给建议的伤害性

我告诉大家，没有一个人是喜欢不断的听人家的建议和警告，若你不断的每一次都建议和教导你的太太应该怎样做，时间一久，她还是会对你有抱怨。因为不断给建议伴侣，实在是间接的说她笨，而且没有人喜欢自己的伴侣认为自己笨，男人更加不能忍受自己的太太女友说自己笨。

> 江郎鬼才有话说：直接讲自己伴侣笨，会有伤害，但，间接讲伴侣笨的做法（即不断给建议），伤害更大。

被直接讲的人，可能会生气的就反应，怒气可能表达了出来。被间接说笨的人是最难受的，因为伴侣没有做出任何人身攻击，但你却感受到，你要怎样骂架呢？

而且给建议的一方背后一定有一个振振有词动机——“我为了你好”，你要怎样去骂一个“为了你好”但却又间接说你笨的伴侣呢？

就算你的建议是对的，她没跟随你的建议而终于遇到挫折，你跟她讲：“你看！我老早就跟你讲了，你就是不听……”
