# 好男人病毒的机械式反应

就好像我们的书《勾魂夺心洗脑催眠》中所说的销售员迷信“听到越来越多客户说 No 时，YES 就越来越近”。很多的好男人在面对自己的心仪对象时，会比销售员更迷信“越多的 NO 就越接近 YES。”

迷信的销售员下场是他会执著用“一个无效率的方法”来见很多个客人，若一天见四个，一个礼拜见二十个，一个月下来就可能见了八十个人。他玩着的游戏规则叫做——“数字游戏”。

虽然是“一个无效率的方法”对八十个人，其中总有几个是能成交的。

好男人则是以“一个无效率的方法”不断的对“一个不想成交的女人”，他的下场你可想而知。

江郎鬼才有话说：不过好男人的这种“无用方法”，若也好像销售员般一天骚扰三个女生，一个礼拜骚扰十五，一个月成功骚扰六十个，在数字游戏的法则之下，应该也有办法一个月骚扰到一个肯跟你上床的。
但这个方你不保你能骚扰到你喜欢的那一类型。

同样的，一个好男人往往在没有人点醒他，或者没有一个他尊敬的人启蒙他，每當他喜歡上一个小女生时，他就会继续的触动他的“简讯电话强迫症”。所以我才在追女课程中设下大诫，严禁我的学员讲任何话来提醒女生她没回电的行为。

就算他们之前跟女生在简讯上很闷，而女生也因此渐新不回复，如果他有机会再度跟女生在电话上联络，他要想假忘了这件事情般。不然的话，他会不小心的以“心理强化法则”来促使女生更加讨厌他。
