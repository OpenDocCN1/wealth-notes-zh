# 印象定型：辅导式和顾问式追求的危机

在追的阶段时，男士们不要去解决她的问题。我的意思不是说她跌倒你不扶她起来，而是说她的家庭、人际、钱财、感情、人生方向等的问题，你都不要去解救她。

举例，如果你追求着的女性说她的生意不好，但你却是知道很多销售技巧是能够帮到她的，你就要控制着自己不要教她。请注意，外观起来是很冷血的，但，如果你太热血，觉得能帮则帮，而且她也接受了你的帮助，你就要预知可能追不到她。

如果在追的期间，她问你的解决方案时，你也傻傻的给意见的话，她会觉得你的意见有价值，但，你的身份也就开始倾向成为她的免费个人辅导或顾问了。

这就叫做“印象定型”，往后她一需要吐苦水，或解决某些问题时，才会想起你。

> **男人向女人诉苦的真相：** 之前就有一位女学员问过我一个问题，她说她在我们的书上看到的若要跟女生发生感情的话，就千万不要做对方的辅导员，不要聆听她的痛苦。

所以，当有一个男生对她说：“你不是我要的那一类型”后，他开始跟你诉苦、讲心事。女学员因为对这个男生没兴趣，所以就照着我们书的说法，跟他辅导，结果这个男生之后就跟她表白了，她问为什么会变成这样。

第一，一个对你没兴趣的人不会跟你讲“我对你没兴趣、你不是我喜欢的类型、我不是要追你”之类的话，特别是不打自招的讲了两次，就很肯定是在讲反话了。

第二个重点确实是我们之前的书里没写清楚的：男人和女人不同，女人对男人诉苦的话，她会把男方看成好朋友或好姐妹。但是，男人若对女人诉苦的话，往往是已经对女方有兴趣了，他想用的策略是希望女生同情他。

所以我才屡次在书中提出“不要做辅导男”的戒条，因为大部分女生都只能对辅导男“感恩不感受”，但问题是一些女生在约会时不期然的诉苦，其实人与人之问诉诉苦是蛮正常的，只不过好男人遇到女人诉苦时，他们会情不自禁的去继续放大女方的诉苦行为，然后尝试借势做拯救者或智者，结果这就像在木头上淋水，很难再擦出火花了。

我也不是说完完全不跟女生分忧，但要怎样做才是正确的处理？
