# 有钱不能吸引女人

我认识的一位女艺人，她自己也承认自己是一个很爱钱的人，同时也很积极的赚钱。因为她名人的关系，追她的人不乏富商、有钱少爷之类的。不过，最近见到她的时候，她又好笑又无奈的告诉我：“我最近才．知道自己有多么的清高。”

原来又有另一个富商追求她。

她说：“他真的恨他妈的有钱，我到今天为止还不曾认识过可以有钱到像他这么夸张的人。”

这富商在吉隆坡黄金闸区的市中心就拥有上百个旺店都是他的，又拥有兴旺的购物广场，而且还拥有上市公司。撇开他做生意的收入，单单只是租金的月收入就已经是个很恐怖的天文数字了。

然后她说：“虽然我很爱钱，他也很喜欢我，简直无微不至的关怀我，把我当成公主般的呵护。但，……哎唷，不知为什么，我就是不能接受他。”

其实这位女艺人不是不能接受他的“人”，而是不能接受他的“沟通方式”。这富商的沟通方式把男女互动中的火花全部歼灭，她完全没办法对这个人有任何感觉。我还笑着跟她说：“嘿，你要叫这些人来上我的课。”

你们可能会问是不是他的沟通方式很霸道？很大男人？很猥琐？很木讷？

都不是！他很喜欢她，也很尊敬她，也很关心她，也很有诚意……但这些就是他败笔的地方。

那么，如果不是算有钱，或者收入普通的人，他们能不能把到超级正妹呢？

记得，我上一本书《爱情阴谋论》中就说过，一般男人见到超级正妹，就会断定是有钱或者装有钱才能把到她们。
