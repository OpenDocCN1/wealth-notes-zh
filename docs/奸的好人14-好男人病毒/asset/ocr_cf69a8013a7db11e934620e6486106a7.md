# 我人生中第一次邀约女生

# 无稽的借口

当我一去到 Hudson's Bay 时，可能是有臭男人的机械式反应，走进这种销售女人化妆品的地方，女服务员都装扮粉饰的美美的，让我很不自在。

走了走，终于让我远远的看到 MAC 的摊位，瞬间开始紧张起来，果然儿到 Chantal。心中盘算着要怎么过去跟她讲话，但其实这些要讲的话一早就已经盘算好了。

就好像有些人准备了要做一些重要又被挪后多次的事情，面临要做之前会很奇怪的发现自己的客厅很需要打扫、冰箱很需要清理。同样的，不知怎的，偏偏就会在这个时候，又觉得很需要再做最后一次的盘算、再多一次温习那已经准备了一个礼拜的对白。

为了要培养情绪(mood)，我就在离开她的摊位大概一百尺以外的地方，在众多其它摊位摆设的障碍物中，好像印地安人要杀人之前，不断在她周围围绕着慢慢走。我当时的动作大方，但心理却鬼祟的在她的附近盘旋。

盘旋了整整四十分钟后，我却还没把情绪培养好，还在盘算如何上去跟她打个简单的招呼。

最后，就好像需要打扫客厅和清理冰箱般，我竟然会记起原来还有一件事情要办…我的表带最近坏了，该是时候去买一个新手表。
