# 巧遇奇书得开窍

这一位学员在被女方很有创意的拒绝了很多次后，再怎样有诚意还是得面对现实，所以最后他也弃权。

他的第二个体验就是“开窍”。

他开始以书中的见解来回忆自己过去追求女生的成功和失败，从这两个对比来应证我们书中所讲“见地”和“手段”他终于明白了。
