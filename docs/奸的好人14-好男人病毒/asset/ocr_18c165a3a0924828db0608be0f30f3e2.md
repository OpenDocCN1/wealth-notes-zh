# 我人生中的第一个邀约

结果，我又花了二十分钟去买了一个手表。不过，在补了我生活上的一些物质不足后，我好像再也想不到其它的借口。

后来，就硬着头皮，上去打招呼，但这是拖了整整一个多小时的思维包袱的招呼。而且一开口时，我却用上了一个全新的借口。

我走到她的摊位前，跟她说了：“嗨，好吗？”

她见到是我也微笑说：“好啊，你呢？”

我就说：“还好…因为我在附近买了手表，所以顺便过来见见你。”

他妈的，自己还是有点不好意思，我还傻傻的展示新手表给她看，好像想证明我真的是有买手表，幸好还没有笨到把手表的收据也拿出来给她看。

大家寒喧几句后，我就跟她说我温习已经七天的对白：“1 was wondering that if you are free, maybe we can go grab a cup of coffee some time.（我在想如果你有时间的活，我们或者可以出来喝喝咖啡。）”

这可说是我人生中第一次约女生的对白。

她很兴奋的说：“好啊，可以啊，我给你我的电话号码。”然后就给了我她的电话号码（当年在加拿大，手机选不是很流行），我满心欢喜拿出把电话号码放到自己钱包内，确保放得好好的，但后来我才知道电话号码的真相。

# 遥遥无期的电话

过了几天，我一打电话给她的时候，才知道原来她给我的是她工作地方的电话号码。

她的同事接了电话，然后叫 Chantal 来听，当我一讲我的名字，她说：“Oh yes yes, 我记得你。”

“没有啦，就是想看看你什么时候有空，我们去喝咖啡。”

“好啊，好啊，但我现在在个工作着，不如这样吧，我迟些时候打个电话给你。”

“好啊，假如我不在的话，就留言在我的语音信箱。”

各位读者请暂停，思考一下，你们觉得之后的发展是什么结局呢？男读者们，请问通常这个情况下，女生还会不会再打电话给你？

# “我再打给你”的意思

这是我第一次了解到，当女生跟男人讲“我现在不能，我再打电话给你好不好？”
