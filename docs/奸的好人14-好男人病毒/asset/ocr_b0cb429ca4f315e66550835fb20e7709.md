# 合理化的宅男

我十五岁的的时候开始学佛，还是认真的那种。正处于思春期的我除了觉得读书的学生不应该恋爱，学佛后又觉得佛教徒不应该助长自己的欲望，所以对于看到的美丽小女生，都是远观而不敢狎玩，敢看不敢动的。
