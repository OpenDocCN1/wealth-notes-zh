# 天马行空的 “创意拒男” 系统

**男人的破釜沉舟约会法**

上两篇文章中所分享我的 Chantal 和 Carm 经历，我相信很多男士们都中过招，而且很纳闷的是女方又不直接拒绝你，因为直接告诉你她没兴趣的话，你就可以把精神和资源投资在另一个对象上。

她没说 “不”，但只是把它一直挪后。

而且你也不可以在对方不肯明确给予你承诺的时候，就想破釜沉舟，半礼半推式的逼对方讲出一个确定的约会日期。

我以前就有试过这么笨的方法。

我可以告诉大家，你若要破釜沉舟的话，你肯定沉舟，然后葬身于浩海之中。

> 江郎鬼才有话说：破釜沉舟在一些情况下的表白期可以用，但在邀约女生出来喝咖啡也要上破釜沉舟的话，女生会心想：“你以为你是谁？”

**“约会挪移大法” 的第十二层功力**

我们一位学员在来上课之前，透过阅读了我们的书（即《奸的好人》系列书），终于把失手的对象追了回来。不过他之前失手的其中一个原因就是他想“破釜沉舟”。

他邀约这位女生时，每次得到的回答总是“我那一天没空。”

当他提议：“不如星期天吧，星期天的时间怎样？”

“哦，我星期天通常不习惯出门，因为隔天要上班，会好累。”

“那我们可以星期六出去吧。”

“我已经有约了。”

人家连续的推辞了三次，他也没办法，就暂时放下。

到了下一个礼拜他又再邀约，这一次他有备而战了，因为他知道了女方星期天不出门嘛，所以就直接问她星期六有没有空。

女方说：“我星期六想在家休息，因为我星期天要出去。”

男学员很惊讶，觉得好像被人出卖了般：“赫？你不是星期天不习惯出去的吗？”
