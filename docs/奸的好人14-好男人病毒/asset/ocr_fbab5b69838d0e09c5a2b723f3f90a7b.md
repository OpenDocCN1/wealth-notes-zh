# 女人如何应付好男人的无声契约

你可以想象以下的这个男女互动对白：

男：“我做的这一切都只是为了你着想。”

女：“哦，感恩，谢谢你，有你这种朋友真好。”

+   男方觉得女方讲谢谢不是他要听的答案，所以他就开始向对方告白：“其实，我一直都很喜欢你。”

女方开始给他更多他不要的答案：“哦，谢谢。被人喜欢是很开心的，但我只能当你是朋友。”

男开始急了，他尝试用罪恶感来间接逼对方说：“难道我一直为你着想的付出，你不明白我的意思吗？”

> 江郎鬼才有话说：他妈的，明白你的意思是一回事，明白了后要不要接受你又是另一回事。

女人是明白男方的意思，但她也不喜欢被人间接强逼，更不喜欢别人背后男有动机。碍于你曾经在行为上有“为她着想”过，她不好意思直接戳破你这个好男人的假逻辑，所以她就装傻的给你一个没歉意的道歉：“我真的不知道你是对我有意思的，如果我之前有误导了你，让你觉得我是想跟你在一齐，我向你道歉。”

女方这句话的潜台词是：“我没有错，是你笨而已。不过因为你曾经为我付出，我为了好让你下台，所以我才给你一个应酬式的道歉。但是，请你别再笨到以为我这个道歉是真的，然后还尝试以罪恶感来对我施以人情压力。”

# 如何击破好男人的虚伪？

其实女方很想如法庭上盘问证人般直接盘问这男人：“赫！你不是说你做的这些都只是为了我着想吗？你的意思是你当初为我着想，其实是另有目的的？”

男：“不！我没有这样的意思。”

女：“那么如果你没有目的的话，你的意思是不是因为你为我着想，我就有义务要接受你的爱？”

“呃…”

男方就会有点像我《爱情阴谋论》一书中开端时所提到的那位对我搭讪的基督教徒尝试解释《圣经》中“喝毒不死”的矛盾般，他可能就会对女生说：“为什么我讲了这么多次，你还是不明白？我觉得你在曲解我的意思。”
