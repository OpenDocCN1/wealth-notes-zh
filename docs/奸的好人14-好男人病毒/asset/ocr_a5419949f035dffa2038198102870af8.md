# “幸福”概念的真相

在《极端自我就是王》中，我们写到有位女士问过李老师“成功的女人有没有幸福？”李老师直接说她浪费时间，我也认为讲这种话就等于讲着自欺的废话，通常是又不成功又不幸福的女人才会问这种问题。（后来我们听回来的消息是：她不是赚到钱，而且也跟老公安了婚，最近听说跟新男友在一齐）

她是一个典型型被概念性废话洗脑的人，所以表面上虽是追求幸福，事实上它已经变成了包袱。“幸福”这个字眼不再是女性用词，因为女人追求“幸福”，男人也迫不得已的也开始被这两个字所洗脑。

我办课程多年，见过不少的男士在喜欢上一个人的时候，会给自己一个很伟大的解释，例如他们会讲些“为了她的幸福、为了我们的幸福，我想把她追到手”之类的话。

你会发现在平常的时候，男人跟男人聊天是很少用“幸福”这两个字，但一旦他决定要追求一个女生的时候，“幸福”这两个字会很机械式的常挂口中。

各位男士，如果你挂在口中的有“幸福”之类的字眼，例如：“我要给她幸福、我要寻找我的人生幸福、我要为了我和她的幸福着想”，请问幸福这两个字是怎样被灌输到你的脑中的？

很多男男女女都囫囵吞枣的相信了一些爱情信仰，女性希望自己能够得到幸福，男性则希望自己能够给予幸福，但你有没有思考过“幸福”这两个字在你的个人定义中，代表着什么？

就算你自己“幸福”的定义已经厘清，你又怎知道对方的“幸福”也有清楚的定义？

甚至在一大部分年轻女孩脑海中，“幸福”这两个字根木是浪漫废话。她的幸福概念根木尚未成形，你认为你真的能够给她幸福吗？

男人若要吸引女生的话，你要先把自己定位为一个能让她心痒的男人，先不要想着什么“为自己幸福、为她的幸福着想”的废话。

用“幸福”策略来追求女生，是男人被女人误导后的爱情信仰。被误导后的男人会开始很沉重的看待如何追求女人，而男男女女也开始自己骗自己，认为人生的幸福只是在于没有美好的爱情。

李老师也提过一个很过瘾的观点：他说为什么离婚的人会被别人或自己标签为“婚姻失败者”？但在商场上被骗、被遗弃、亏本的人却不会被人家说：“你看！这家伙是一个生意失败者！”
