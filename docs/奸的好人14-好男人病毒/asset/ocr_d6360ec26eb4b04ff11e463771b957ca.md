# “心理强化法则”

“心理强化法则”的理论很简单，任何行为若有透过某个明确信号的响应，该行为就会受影响。例如：若要训练狗吠人，每当牠见人而碰巧有吠的行为时，你就拍拍牠的头而说些奖赏式的话，这只狗以后吠人的行为就会被强化。

同理的，那些有简讯电话强迫症的男人，在不厌其烦的传简讯骚扰女生而得不到女生的响应后，最后当女生勉为其难的接了他一次的电话，男生往往会以“理强化法则”使本来就觉得他烦的女生，继续恶化成觉得他讨厌。

这些男人可能会盘问犯人的讲“什么你不接我的电话？… 干些 什么？”
