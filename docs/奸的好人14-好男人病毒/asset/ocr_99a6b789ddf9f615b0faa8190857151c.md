# 好男人的迷思与陷阱

你们（特别是男读者）可能就会很迷茫的问我：“那么如果无私情人是好男人失败的地方，为什么你还在《爱情阴谋论》教男人怎样增长时间、搞什么『千拙之境』的东西？『千拙之境』不就是要缩短男女间达到高潮的时间上差异，帮男人能够不要太早亭事吗？”

因为我曾经是好男人，我知道你们最想知道的是什么，但我要告诉你们，这些重要，但都不是最重要的。我教男人关于“千拙之境”，只是要给大家更多的选择权，绝对不只是单方面的增加自己的时间。

好男人的想法是：就算我的“器具”不够宏伟，但只要我学会“时间”够长，“技术”够厉害和标奇立异，我不就是一个大情人了吗？

好男人一旦成为“无私情人”的话，他会变得很自强不息，除了掌握了一百零八种悦取女人“快感绝技”、自己的“时间”已经到整个小时，他还是想办法再更上一层楼，他要成为自己女友或老婆人生中所遇到最厉害的情人。

一味的有意无意向女人传达“我以你的快乐为我的幸福、我以弄到你爽为我的快感”这类的无私宣言，表面上女人应该就会觉得自己幸福，事实上女人很下意识的会得到另一个对你有害的讯息。

# “人格”和“付出”的关系

> 江郎鬼才有话说：人格可以弥补你付出的不足，但付出是弥补不到你人格缺陷。
