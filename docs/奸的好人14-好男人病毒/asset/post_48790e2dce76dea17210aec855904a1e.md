# “美中不足”的推动力

注意，我上面这段话是个以“假障碍，来引导对于过关的方法。我先借李老师的口来称赞她，说她和我在节目是很有火花，然后就抛出了一个“障碍”。

结果，在节目结束后，我正在收拾自己的东西时，大眼 DJ 就在我临走前说：“喂，有时间的话，我们出来喝喝茶，聊聊天吧。”

记得，通常是男方先提出邀约的，不过，这次却是女方先提出，不是我。

说我们“能在节目上有火花”是一种赞赏，接着说“虽在节目上有火花，在社交时还能否有火花”，就好像是一种美中不足，这是对之前赞赏的一个挑战。人就会因此被推动着要证明挑战者是不对的。

> 江郎鬼才有话说：我说出了你的“好”，然后再说你的“好”只差那一点就能达到“完美”，你就会很有理由的要做得更好。
举例，如果我要求你走三步过来，你可能会懒于行动。但，如果我告诉你，你本来就是要走一百步，然后我骗你说你已经走了九十七步，你就会很勤奋的走完最后那三步。

你可以想象一下，如果我说：“我的朋友说你和我在电台上很有火花，出来见面喝茶的话，一定会更有火花。”你认为她的反应又会怎样呢？

她会觉得我好像暗示得太明显了，而且她也没有欲望要向我证明我的看法是错的。

# 开放式的考题有封闭式的效益
