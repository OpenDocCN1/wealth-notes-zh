# 第四章 一个拥有菩萨脸孔却带着强奸犯淫笑的太监

# 辅导式追女……自断男根

西施有抱怨

很多年前某一天，我在一庙中看着书的时候，遇到一位来求签的气质美女。当时庙中没有其它人，她走来问我会不会解签。我虽然口才很好，但我还不至于因有美女来问我，我就会假扮成一位会解签的专家。

我老实的告诉她我不是解签之人，不过我就邀请她跟我一齐去朋友家中的 BBQ 聚会，因为聚会中有一大师兄会解签。结果，这位美女就载着我去了朋友的家了。

我和美女一到朋友家的时候，我第一时间把她介绍给所有的朋友，然后就告诉大师兄美女要解签。师兄看了看了她的签后就问她：“你想问什么？”

她问签的事是有关于自己的男朋友。

然后她开始投诉男友的不是，数落他怎样不好等等。

> 江戸鬼才问题：男人听到美女投诉自己男友或老公时，通常会有什么反应？为什么美女会让男人有这种反应？

不知为何，我本来对这位美女是有兴趣的，但一听她不断投诉和抱怨男友后，就对她没兴趣了。

“西施撩心”不够“西施埋怨老公”美

大师兄有什么反应呢？

大部份的男人一听到美女投诉自己的男人，第一时间就会想：“他妈的，这么漂亮的女人投诉自己的男人的话，一定是男人的错！”

所以大师兄他就气字非凡、满脸正气的说：“男人不应该这样…做人哪可以如此…”

男人就是男人，看到“可怜”的美女，会有两种反应：就是安慰美女，二就是跟美女站在同一阵线上，一齐骂她心目中的坏人。大师兄也不例外，马上从男人的角度数落人家男友的不是。
