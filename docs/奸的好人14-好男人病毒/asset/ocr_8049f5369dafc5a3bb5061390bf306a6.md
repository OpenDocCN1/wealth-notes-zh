# # 废话如何影响一个人的信仰？

# ## 人人爱废话

很多年前我和李老师刚开始办权谋课程时，有一个学员在课程当中问了一个问题，他说：“两位老师，你们公开教这种技巧，会不会教坏了人？你们这样散播权谋思想，会不会让这个社会变得更负面？”

因为权谋课程完全没有教人做犯法的事情，当时我和李老师都很好奇为什么这个人会觉得我们可能会教人做坏事。（注：我们的课程没有教人弄假文件或使用暴力之类的手法，里面所教的都是关乎人性的合法技巧）

后来，在一次的旧学员聚会时，他告诉了我们他的商业理念，他说人要做事业的话，就要做“良心事业”。但是，我们背后听到的消息是：这个人以前是某银行的贷款部主管，他运用了自己对贷款手续漏洞的了解，自己辞职后就跟银行借了一大笔钱出来做生意，然后很“巧妙”的生意失败而破产，但若干年后他不知从“何处”

我来一笔钱而东山再起。

我记得当年跟李老师说：“他所谓的‘良心事业’应该有很特殊的定义吧！”

李老师说：“就好像我的亿万富豪的表亲在上了权谋课程后，特别的找我谈话，说我不应该教人这种权谋之术，他还叫我多上台湾陈怡安教授的课程。”
