# 老老实实关怀女生的追求策略

大家阅读到这里，看到了钱财、样貌和地位都不是最关键的女人春药，那么老 老实实的对女生付出关怀重要吗？

我在这里告诉大家：追女生时，“关怀”也只是能打开方便之门而已，因为没有 人会拒绝另一个人的好意。不过，问题是：阿猫阿狗也会关怀女人，女人不会因为 你的关怀，她就会爱上你。

付出和关怀在维持感情 (Love) 的阶段非常重要，但在要使人爱上你 (Fall in Love) 的阶段，往往会很容易有反效

就拿“以钱追女”为例，若女生还未喜欢上你，不断的做银弹攻势，花钱在女 人的身上，对方会觉得你想用钱来“买”她。如果你是一副色狼的模样，女方就觉得 你想用钱来买她的身体。就算你一副好好先生的模样，真心诚意的以钱来关怀她， 她可能觉得你想用钱来买她的心，但，你还是没办法完全打脱自己想用钱来“买” 她身体的嫌疑。

> 江郎鬼才有话说：要让女生有恋爱的感觉，你的管道不是用钱、样貌、地位、口 才、才华或关怀。钱、地位、口才和才华让人敬佩，样貌让人看多几眼，关怀让 人感恩，但敬佩、看多几眼和感恩不是恋爱的感觉。

先决条件是：只要女方喜欢上了你，这些管道才能把“喜欢”升华到“恋爱”。

反过来说，如果女方开始喜欢你了，就算你的本意是用钱来“买”她的身体，她 还是觉得你很有“心”。

不要以为走关怀路线女方就会喜欢你，用关怀和用钱追求女生可能最后的效果 是一样的：女方觉得你想用关怀来“买”她的身体。
