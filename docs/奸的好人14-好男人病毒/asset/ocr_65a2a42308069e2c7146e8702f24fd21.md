# 罪恶感的拉锯战

我心里面兴奋的要命，还未接电话前我还说：“Shit！难道真的有效了？”

我尽量保持冷静的接电话，电话中她整个语气都变了，她使用了一个很弱的声音说：“Sorry啊，江。”

我一听到她说 sorry 时，心里面就已经窃笑了，同时我整个人就软化了下来。从她这么弱的语气，我可以想象到她那三天跟罪恶感搏斗的思路。

我问她：“Sorry 什么？”

“…如果是我有 hurt 到你，伤害到你，我跟你说过不起。”

我心里叫出了 YES! 她跟我道歉，可以说是个好现象，但是我的好男人毒素还未清除，所以很大方、很快、很紧张又很关心的说：“哦，不用对不起，你没错，你没有伤害到我，我没问题的…”

我不知道你有没有试过讲了一些话，你好像可以看到那些话从你口中飞奔而出，然后你很希望能够把那些话收回来？

我当时一讲了那句话后，就知道自己讲错话了。
