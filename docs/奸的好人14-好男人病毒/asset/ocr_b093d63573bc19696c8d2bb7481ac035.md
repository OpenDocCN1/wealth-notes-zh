# 好人和坏人如何接受无条件的道歉？

我可以很肯定的告诉大家，如果对方是个“坏人”，他伤害了你，然后跟你道歉，你马上无条件接受他的道歉的话，你是在姑息养奸。坏人会把你这个弱点记录在案，他知道以后要利用人的时候，你会是他的第一人选。

但是，如果伤害你的人是“好人”，然后他有歉意而向你道歉，你也是马上毫无条件的接受“好人”的道歉，对方反而会开始回避你。

他回避你的原因有两个：

+   一，他觉得自己真的伤了人，所以不值得接受如此无条件的原谅，所以不想“睹物思情”才回避你。如何借女方的道歉赚取更多的好感？

+   第二，对方会对你的无条件原谅感到很奇怪，他会想：“蛤？我之前不是得罪了你吗？怎么你连生气的反应都没有，我到底是否真的得罪了你？”

因为你之前的举动让他觉得他有“做错”，他现在见你马上接受他的道歉，他会怀疑你之前的举动是否在“做戏”。

> 江郎鬼才有话说：我当时不是为了做戏，我要“太极拳”把罪恶感推回给她不是我预设好的对白，纯粹是把自己的感想说出。不过，我那马上无条件接受人家道歉的行为确实是会让人觉得我不是个老实人（甚至她可能会当我是伪君子），但我的动机是什么都不重要，对方觉得我不老实，我就不是一个老实人了。

所以，沟通的意义不在动机，而在对方的反应。
