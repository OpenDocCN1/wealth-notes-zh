# 1. 童年经历构建情绪人格

心理学或科学家，很喜欢把人类的情感模式比喻成浮在海面上的冰山。

为什么这样说呢？因为我们自己意识可以察觉的部分，只是海面上那个冰山的一角；在那个冰山下面还有一大块，就是我们本能运作或内建情绪人格的部分，这是我们自己可能也没有察觉或无法察觉的更大一块。

这一讲，我们就来说说，情绪教养冰山下的那一块。

在谈孩子的情绪教育的时候，我通常不太说这是“教孩子情绪管理”，我喜欢用情绪教养来谈它。因为教养是个长期的人格内建的历程，而情绪管理只是后来知识上可以去学的，很有限的那部分。

如果在孩子的情绪教导上，我们只做冰山上 面情绪管理的那一块，却不去管冰山下情绪人格的那一块，你会发现情绪的教导效果非常有限。

比如说你是一个情绪人格很负面的人，可能会花大钱去上个什么 EQ 课程，上的过程你会觉得太有道理了，我应该怎么怎么改善自己。然后在回家的路上，你就告诉自己说，好，等一下看到老公，我要温柔，我要面带微笑，我要怎样怎样怎样……

结果呢，回到家一打开门，看到老公把屋子弄得乱七八糟，你就一把火上来，结果什么 EQ 课堂全都丢到海里去了，对不对？
