# 智慧K線戰法

智慧K線戰法屬於短線操作法，擷取明顯上漲或下跌的一段，由於規則簡單，操作容易，又稱為「傻瓜操作法」。這種簡單的方法是根據「市場慣性原理」，當價格突破前一天的高點，買進力道大於昨日，依慣性股價會繼續往上；當股價跌破前一天低點，表示多方力竭，空方力道大於昨日，股價容易繼續往下。

智慧K線戰法重點說明

我們利用「市場慣性原理」下單操作，是最省時間的下單選擇方式，也是最可能買在發動點的第1天及買在高點結束的第1天。主要操作方法說明如下：

+   戰法優點：
1. 規則簡潔清楚，容易執行。
2. 短線即可獲利，停利明確。
3. 不需要看盤，收盤前5分鐘看盤即可。
4. 不會賠大錢，獲利很好。
