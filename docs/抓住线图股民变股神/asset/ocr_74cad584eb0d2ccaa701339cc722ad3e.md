1. 在空頭走勢使用波瀉型態戰法

想用順勢操作波浪型態戰法在空頭走勢做空，必須配合波浪型態，看趨勢方向為空頭時才能進場。同時，一定要在反彈止漲再下跌時放空，以及在盤整末端向下跌破時放空。主要操作方法說明如下：

+   - **進場** （1）股價高檔做頭，出現「頭頭低」（峰峰低）的第2個頭及下跌的黑K線，股價跌破5日均線。
- （2）下跌一段時間後反彈，出現止漲回落的黑K線，股價跌破5日均線。
- （3）在盤整末端股價向下，出現跌破盤整的長黑K線。

+   - **繼續** 收盤沒有突破5日均線時，續抱。
- **加碼** 收盤確認股價突破上升切線，且股價突破5日均線時，回補。

+   - **止賺** 進場當日波浪轉折的最高點，以及盤整跌破的下頸線位置。

1. 在盤整區間的順勢操作戰法

前述有提到順勢操作波浪型態戰法可以用在飆股、強勢股、多頭股票，但不能在盤整區間使用。如果遇到盤整的情況，可以採取以下5種因應策略。

+   1. 進入盤整可以採取做或不做兩種策略，除非價差很大，否則不宜操作。
2. 如果前波走勢是多頭，盤整區間以「低接高出」操作。
3. 如果前波走勢是空頭，盤整區間以「高空低補」操作。
