# ▲上圖說明：

+   ⑪ 股價走勢在低檔有價有量，為向上攻擊量。

+   ⑫ 上漲一段之後，股價在相對高檔有價有量，則容易拉回整理。

+   ⑬ 盤整後，有價有量，為突破的攻擊量。

+   ⑭ 在高檔有價有量，為出貨量，容易拉回。

+   ⑮ 在高檔下跌反彈，有價有量，反彈不過前面高點而下跌，為再次出貨量，容易反轉下跌。
