# 二、做空頭出現急跌時的發現及買法

由於V形及倒V形反轉的速度很快，許多投資人常常無法在第一時間發現及介入，因而錯失賺錢的機會。

事實上，只要瞭解它的特性，知道如何操作，大膽進場，果斷出場，要賺這種小飆一段的利潤，實非難事。

以下提供當空頭出現急跌時的操作定法：

買進 一定要同時符合下列條件才可以買進。

+   1. 出現連續重挫急殺3天或3天以上的長黑K線或跳空跌停。
2. 下殺出現暴大量的情況。
3. 當天出現下列K線上訊號：
	- 開低走高的長紅K線。
	- 長下影線的紅K線或黑K線。
	- 長下影線的十字線。
	- 股價當天跌破昨日低點後，收盤時上漲突破昨日高點的吞噬紅K線。
