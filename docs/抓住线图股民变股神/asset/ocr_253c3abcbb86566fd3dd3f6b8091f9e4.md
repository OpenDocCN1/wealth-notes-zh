# ## 第 3 篇

# ### 第 4 章 波浪型態進階研究 1：多頭、空頭及盤整圓形及買賣位置

2. 多頭的金貴買點位置

+   （1）底部盤整，股價已向上突破下降切線，出現「底 高」且帶量拉出長紅K線時。

+   （2）底部盤整完成，出現突破前面高點的帶量長紅K線時。

+   （3）回檔出現沒有跌破前面低點，且出現再向上升漲的紅K 線時。

+   （4）盤整末端，股價出現帶量長紅K線往上突破上頸線時。

3. 操作時的重要觀念

+   （1）多頭進場，最佳買點就是前述的4個位置。我們在選好 股票準備做多之前，必須看日線是否為進場位置點，如 果不是，最好等到進場位置時再動作，否則隨便進場很 容易短期套牢或遭到停損。例如：沒確認打底就去買、 回檔尚未止跌回升就去買、盤整還沒有結束就去買、上 漲好幾天去追高買，結果造成操作困難而賠錢。

+   （2）股價突破前面高點的買進，前述說明只有兩個位置： 一是底部盤整完成的突破確認，一是盤整末端的突 破。為什麼行進中回檔後再上漲突破前面高點時，不 是最佳買點？理由是一般主力在往上拉漲走一段創新 高後會洗盤，讓過多的浮額賣壓換手，所以連漲3～5 天之後容易回檔，因此當創新高時去追買，往往是買 在回檔後上漲的第3或第4天，正好處於過高要拉回的 時候，隨時會碰到拉回的狀況，所以盡量買在回檔後 再上漲的第一根紅K線，既容易停損，獲利空間又大。
