# 20週均線交易法的重點說明

20週均線交易法，簡單的說，就是用20週均線（相當於100
日均線）做為判斷多空方向、股票進出及停損停利的依據。20
週均線交易法的重點說明如下：
戰法優點：

+   1. 規則簡單，容易執行。
2. 長波段操作，能獲得可觀利潤。
3. 不須經常看盤，適合波段投資。
4. 依長期趨勢操作，行進中不必看盤，比較不受短期的基本面、消息面、指標、成交量的影響，因此操作EQ穩定。
5. 適合大額資金操作。
