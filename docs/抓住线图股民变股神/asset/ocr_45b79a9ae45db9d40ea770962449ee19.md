交易條件：

+   1. 以波浪型態為最優先考量，順勢交易。不逆勢交易。

+   2. 採用3日均線及10日均線為操作進出依據。24日均線做為趨勢方向及多空的依據。

+   4. 漲多高檔要做頭下跌，出現「頭頭低」（峰峰低），空頭走勢要確認。

+   5. 無論進出，均以收盤價確認。

+   6. 可以減少進出操作的次數，容易控制操盤EQ。
