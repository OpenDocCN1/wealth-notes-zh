# 〕迴線\*、日線M 頭\* 的風險

股票在週線看到低檔\* 底，但是看日線卻呈現M 頭部，這時該如何操作？

+   週線：低檔出現\* 底。
日線：呈現M 頭。

![](bbox=[0.14, 0.34, 0.89, 0.5])

股票在週線看到低檔\* 底，中期的確是好買點，但是日線當時波浪型態是M 頭，短線是空頭，買進容易套牢，因此，不能因為週線轉多而立刻買進，要等到日線止跌出現「底底高」向上的時候再買進，這時週線、日線同步向上，易漲難跌。
