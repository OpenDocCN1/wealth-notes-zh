# [ 盤整波浪的特性和買賣點]

1. 盤整波浪的特性

+   （1）不符合多頭波浪型態及空頭波浪型態的波浪。

+   （2）橫向在上頸線與下頸線之間漲漲跌跌。

+   （3）觀察重點：盤整末端的突破方向是向上還是向下。

2. 盤整波浪的買賣點

+   （1）靠近下頸線未跌破，向上漲時買；靠近上頸線未突破，向下跌時賣。

+   （2）盤整區間幅度太小或橫向盤整時交錯雜亂，無法確認波浪型態時，應停止交易。
