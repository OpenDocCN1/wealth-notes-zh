# ## 二、 股價線上攻進許多常見出現

![](bbox=[0.155, 0.22, 0.85, 0.475])

資料來源：富邦e01電子交易系統

# ### ▲上圖說明：

+   1. 1997年11月10日，台硝股價上月線，但是月線往下，不進場。

+   2. 1997年12月3日，台硝股價再站上月線，月線往上，在收盤價29.1元買進。

+   3. 1997年12月9日，股價跌破10日均線，在30.2元賣出。

+   4. 1997年12月26日，股價再站上月線，月線往上，在收盤價30.3元買進。

+   5. 1998年1月7日，股價跌破10日均線，在30.4元賣出。

+   6. 1998年2月2日，股價再站上月線，月線往上，在收盤價30.4元買進。

+   7. 1998年2月6日，股價連漲3紅，高檔出量，出現長上下影線的紡錘線，在收盤價33.3元賣出。

+   8. 1998年2月9日，股價暴大量跳空上漲拉出長紅K線，在收盤價35元買進。

+   9. 1998年2月12日，股價高檔價量背離，出現長上影線，次日開低，在38.2元出場。
