# 第 3 篇

第3章 K線賺錢密碼3：判斷長紅K線、長黑K線的祕訣

+   2. 連續上漲出現第3根或第4根的長紅K線

當連續上漲出現3根或4根長紅K線，這時，獲利的人隨時要賣出，空手投資人不適合在此進場，因為多頭氣勢雖然強，但是極易追到高點而套牢，因此，要等到回檔修正後再買進。
