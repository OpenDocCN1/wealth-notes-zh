# 第四章 張炳雄「不該”投資：股票操作敗案例

△上圖說明：

大盤2008年上半年創9309點高點的同一時期，弱勢股華上（6289）股價由27.8元拉回整理，後來只上漲到28.3元，當大盤反轉之後，華上股價則一路大跌到10.2元。

趕快換股操作，否則難以解套，結果，他一直到2011年5月25日才願意以52.7元認賠賣出，轉進正在多頭上漲的股票基泰（2538），5月25日當天以17.5元買進基泰，截至6月20日以21元賣出，7月4日再用20.4元買進，到7月20日以23.5元賣出，一共操作兩趟。
