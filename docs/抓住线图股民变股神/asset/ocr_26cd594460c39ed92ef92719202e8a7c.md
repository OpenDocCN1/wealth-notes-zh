# ▲上圖說明：

+   1. 土紙（1903）股價在第1段飆漲5支漲停板，等待回檔續勢再漲的機會。

+   2. 修正2天，股價繼續向上突破下降切線及高點，抓住續勢機會買進，但是後面幾天沒有如預期上漲，會停損1次。

+   3. 第2次符合向上突破下降切線及高點的進場條件，買進。

+   4. 做到第2段飆漲。

+   5. 修正2天，股價又向上突破高點，抓住續勢機會，立刻買進，但是後面幾天沒有如預期上漲，會停損1次。

+   6. 第2次符合向上突破下降切線及高點的進場條件，買進。

+   7. 股價再度突破回檔盤整的上頸線，為加碼點。

+   8. 做到第3段飆漲。

+   9. 跌破上升切線，出現黑K線，出場。
