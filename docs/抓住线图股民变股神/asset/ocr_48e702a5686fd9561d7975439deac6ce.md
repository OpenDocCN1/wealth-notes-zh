資料來源：富邦eO1電子交易系統

# △上圖說明：

+   ⑪ 怡利電（2497）股價在底部盤整3個月，發動前有洗盤的動作，先跌破盤整下頸線，再往上飆漲。

+   ② 2011年4月7日，拉出長紅K線突破盤整區，股價站上20日均線，買進。

+   ③ 2011年4月14日開平盤，隨後股價往下跌，以飆股停利紀律立刻出場。以飆股戰法調整跌破上升急切線⑦出場，或跌破昨日K線低點⑤出場。

+   ⑥ 2011年4月20日，拉出紅K線突破昨日K線高點，回跌後上漲買進；停損守波段低點⑦，買進。

+   ⑧ 2011年5月5日開高走低，出大量，以飆股停利紀律，回跌接近平盤時賣出。以飆股戰法調整停利，看到黑K線，出場。
