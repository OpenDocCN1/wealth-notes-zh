+   2. 上漲途中回檔後，出現再上漲的紅K線，股價突破前日高點時。
3. 續勢盤整完畢，股價向上，出現突破盤整的暴大量長紅K線時。
4. 強勢飆股的第1根上漲長紅K線高點，被第2根紅K線越過之後，可以買進。

交易規則：

+   [**進場**] 收盤前確認股價，突破前一日高點時買進。
[**續抱**] 每天收盤前檢視股價，沒有跌破前一日的高點時，續抱。
[**空場**] 收盤前確認股價跌破前一日低點時，出場。
[**停損**] 進場當日K線股價的最低點（不能超過7%）。

# 1. 在空頭走勢炒盤的操作定義

用智慧K線戰法在空頭走勢做空，要配合波浪型態、趨勢方向空頭及K線出場訊號，主要操作方法說明如下：

進場時機：

+   1. 高檔出現不過前面高點的「頭頸低」下跌黑K線，以及確認頸部完成的下跌黑K線，股價跌破前日低點、跌破頸部盤整下頸線的位置。
2. 下跌途中出現反彈後再下跌的黑K線，股價跌破前日低點時。
3. 下跌中，續勢盤整完畢，股價向下跌破盤整區時。
4. 確認空頭的第1根下跌黑K線，第2根跌破低點的黑K線，可以放空。

交易規則：

+   [**空場**] 收盤前確認股價跌破前一日低點時，放空。
[**續抱**] 每天收盤前檢視股價，沒有突破前一日的高點時，續抱。
