# 空頭走勢中如何操作續勢戰法？

想用續勢戰法在空頭走勢放空，必須注意以下交易規則：

+   *   放空：在第1段下跌出現反彈後，符合下列情況，放空。
    *   （1）當天開高走高，股價在高點隨即向下下跌破前一日低點，並且再創新低價。
    *   （2）昨日反彈上漲，今日卻跌破昨日最低點時。
    *   （3）一連數天反彈後，出現黑K線跌破上升急切線。
    *   （4）橫向盤整後，出現長黑K線跌破下頸線。

+   停損：停損點設在進場長黑K線的最高點。

+   續抱：飆股股價未突破下降切線或前日高點，續抱。一般下跌走勢股票，採取自行應用的戰法續抱。

+   回補：飆股用飆股戰法回補，或者用飆股調整戰法回補。一般下跌走勢股票，採取自行應用的戰法回補。
