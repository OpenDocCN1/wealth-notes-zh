# 1 從多頭的回檔幅態看股票強弱

當股票是向上的多頭股票在上漲一段之後都會回檔修正，回檔的幅度只有本波上漲的0.382就止跌，繼續往上，為強勢回檔；回檔到上漲幅度的0.5，為正常回檔；回檔到上漲幅度的0.618或更低，為弱勢回檔。強勢回檔的股票走勢最強，正常
