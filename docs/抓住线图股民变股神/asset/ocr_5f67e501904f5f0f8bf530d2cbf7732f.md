# 第7章 K線賺錢密碼2：8個K線攻擊及下跌訊號

**2. 出現地樁似的長下影K線：**

低檔出現長下影線的錘子，第2日要紅K線，過前一日高點才能確認止跌反彈。

![](bbox=[0.6, 0.2, 0.76, 0.34])

**3. 低檔出現十字K線：**

低檔出現十字或類似十字K線，是變盤訊號，第2日突破前一日高點的紅K線才能確認變盤。

![](bbox=[0.58, 0.39, 0.79, 0.53])

**4. 低檔出現倒鉗K線：**

低檔出現長上影線的K線，是止跌訊號，第2日開高向上，表示止跌，但是第3日要過前一日高點的紅K線，才能確認反彈。

![](bbox=[0.58, 0.57, 0.82, 0.71])

**5. 低檔出現穿心紅K線：**

低檔出現長紅K線，突破前日長黑K線的1/2價，為多頭強勢止跌訊號；出現長紅K線後，次日要再過前日高點才能確認。

![](bbox=[0.57, 0.75, 0.83, 0.88])
