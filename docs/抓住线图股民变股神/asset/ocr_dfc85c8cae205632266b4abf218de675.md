# 波浪型態的角度與幅度

我們觀察走勢圖時，除了波浪型態之外，走勢的角度與幅度，也透露出股票的強弱。

+   1. 上漲角度愈大的股票愈強

![](bbox=[0.11, 0.33, 0.36, 0.47])

![](bbox=[0.37, 0.33, 0.62, 0.47])

![](bbox=[0.64, 0.33, 0.87, 0.47])

+   2. 下跌角度愈大的股票愈弱

![](bbox=[0.11, 0.57, 0.36, 0.71])

![](bbox=[0.37, 0.57, 0.62, 0.71])

![](bbox=[0.64, 0.57, 0.87, 0.71])

當大盤處於多頭格局時，大部分的股票都會上漲，這時要選擇上漲角度大的股票操作，因為，市場總是呈現「強者恆強、弱者恆弱」局面。
