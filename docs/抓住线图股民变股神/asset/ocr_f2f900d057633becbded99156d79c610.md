# 第5章 波浪型態進階研究5：抓住急漲末端最佳賣點的方法

股票在行走時，經常遇到飆股起漲時、末升段噴出時、底部

V型反轉時或主力做價時的股價急速上漲走勢。遇到急漲的股票，可以採取下面4種方法出場，一般來說，都能夠賣到相對的高點。

# 急漲股票賣到最高點的4種方法

+   1. 用K線戰法，只要收盤價沒有跌破前一日K線的低點就續抱，當收盤前股價跌破前一日K線的低點就賣出。

+   2. 用急切線戰法，當股價開始每天上漲時，把日K線的低點連結往上畫出一條上升切線（稱為急切線），當股價出現黑K線跌破上升急切線時就賣出。

+   3. 用K線出場訊號，當日出現大量長黑K線、長上影墓碑線、十字線、長下影線的吊人線、創新高收盤破低的黑K等K線訊號，當日可以先賣出，如果不賣，當第2天走勢不理想時，就要快速賣出獲利。

+   4. 3日均線戰法，當股價跌破3日均線時就出場。
