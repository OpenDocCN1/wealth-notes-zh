这时，我们要反思自己是否承诺过什么没有兑现，这是顾客反悔最常见的原因之一：

+   1. 顾客记着优惠而忘了条件，总希望你无条件给予优惠。

+   2. 优惠有时间限制，过了时间限制没有等到优惠而不想付款。

+   3. 也有可能是你催促得不紧，让顾客感觉自己未被重视。

在交谈过程中，我们一定要注意信息的传达是否到位，尽量少谈题外话，想办法强化客户头脑中产品的各种促销措施，优惠限制条件等等，尽量不要等到付款前才重复。因为优惠的具体信息，条件，数量等够顾客很难记清楚。而在交谈过程中我们如果过多提到优惠措施力度，会使得顾客忽视掉优惠的前提条件。最后，顾客会坚持认为自己没有听错、记错。即使其他方面都已敲
