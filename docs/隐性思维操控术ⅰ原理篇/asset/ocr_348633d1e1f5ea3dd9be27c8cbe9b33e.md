# 跟不上步调的思维操控者

这似乎是个笑话。对于自以为聪明不需要锻炼就能出奇制胜的营销员，客户就是他们锻炼的对象。当然思维敏捷也是一件不可多得的好事，但是毫无思维上的准备，沟通好只是自己的设想，万一碰到意外况，会突然跟不上步调，被顾客牵着鼻子走。也有人碰到“百变”客户，在电话里和蔼可亲的，到了实际交谈的时候，特别是签单的时候变得“不可理喻”。于是对于客户提出的刁钻问题一时语塞。思维上的滞后，使得他们无法清晰地表达自己，就容易被客户认为是不用心服务，不真诚。
