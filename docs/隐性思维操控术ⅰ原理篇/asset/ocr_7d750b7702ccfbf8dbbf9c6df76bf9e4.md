任何想成就一番事业的人都有过这样种感受，不注重细节，可能越过了很多程序，时间使用效率虽高但办事效果极差。成功路上容不得丝毫马虎大意，唯有胆大心细，切实做好每一个件小事、把握好每一个细节，才是避免烦恼、灾祸、失败和耻辱的最佳策略。

# 3 成败在第一个五分钟里
