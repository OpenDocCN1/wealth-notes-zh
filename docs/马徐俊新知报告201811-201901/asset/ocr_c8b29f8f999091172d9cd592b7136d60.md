# 今日报告：我们错怪了糖吗？

当我们也跟进了奖励系统的理论，我们不时也忘了走入生发原生的理由。
——Freeconomics Radio

马徐骏

人们都知道糖不健康，但是最新的调查显示，糖的消费量和肥胖人群的数量之间，并没有明显的正相关性。是我们一直错怪了糖吗？

+   - 为什么糖明明是成瘾品，FDA却不管它？
- 为什么营养学家和技术手段都帮不了你？

今天的内容选自一个新的来源，叫做 freeconomics Radio，这是一个美国非常知名的播客节目。

你可能知道，播客平台的内容，靠谱吗？
相信你一定听过一套鼎鼎大名的书，叫《魔鬼经济学》，作者是史蒂芬·都纳和经济学家史蒂夫·列纳特，同《魔鬼经济学》的英文名，叫《 Freakonomics 》，主播，freeconomics Radio 这个播客的主持人，正是史蒂芬·都纳，而史蒂夫·列纳特也是这个播客节目的常驻嘉宾。

这个播客的宗旨是 “Discover the hidden side of everything” ——带你把事物不为人知的隐藏面发掘出来。史蒂芬都、和都纳录播客，嘉宾可都是各个领域学者专家，选题也总能贴近生活，讲述方式也非常有趣，所以它一直是iTunes人气最高的播客之一。

今天我们讲的内容，就来自freeconomics Radio人气最高的一期节目，叫《我们错怪了糖吗？》（There's a War on Sugar. Is It Justified?）
说起吃糖的坏处，相信你也脱口而出：导致肥胖、糖尿病、增加心血管的风险等等。但我今天要告诉你的是，这些观念可能需要更新。

就拿糖和肥胖的关系来说，从1985年到2009年，伴随着全世界消费量的上升，肥胖的百分比也急剧上升；但从2000年至今，人们对糖的消费量已经减少了15%-20%，肥胖人口数量却依然在增加，所以糖和肥胖之间的关系，显然不像烟会导致肺癌那样，呈现出明显的正相关。

那么，今天的这所有内容要糖的敌人吗？当然不是。我们要来对几个关于糖的高认知，比如为什么糖会成瘾FDA也知道的这一点。却不像管毒品和酒精一样来管控糖？我们又没对基于基础科学这样的技术来评估风险，除了糖瘾机制呢？糖到底有没有一个完全的食用标准？我们需要营养专家的建议吗？

通过今天的内容，我想带你了解，糖背后那些不为人的真相。
