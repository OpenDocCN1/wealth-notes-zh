# 149报告 | 人工智能为什么学不会“常识”？

我们需要想办法让AI掌握常识，因为它们需要依靠常识来展开推理，理解这个世界。

——（选线）

马徐征

强大的人工智能，遇到了最初级的问题——它们竟然学不会常识。这是为什么？

今天的内容分为两个部分：

+   - 深度学习为什么教不出常识？
- 如何让人工智能学会常识？

最新一期的《连线》杂志（2018年12月刊），封面文章探讨的是人工智能的“天花板”。你可能觉得，咦？人工智能现在不是风头正劲吗，怎么就遇到天花板呢？

说高深有点意思，这个天花板，竟然是非常简单的事，像小孩子都知道“常识”。

常识，英文叫common-sense knowledge，就是“人类对于那些习以为常的事情”。比如水会往下流，铁会沉入水里，太阳每天都会升起。

虽然这些知识并不深奥，但是掌握它们非常重要。它们决定了我们如何在这个世界里行动。比如，如果你无法预想水往低处流，那么你在建筑楼房、铺设管道、规划排水系统时，就会非常费劲。

但人要智能就不行。一旦条件发生变化，它无法像我们那样举一反三，无法对“新情况”进行推理和预测。人脑可以通过归纳、演绎、类比等多种方式来获取常识，而AI目前还做不到。

原因在哪里呢？《连线》杂志指出，人工智能之所以无法具有常识，是因为目前主流的“深度学习”技术本身存在着局限性，它无法让机器“像人一样思考”。

现在，已经有计算机科学家开始想想法突破这个天花板，让AI也具有常识，可惜这个工程非常难，而且代价高昂。

接下来详细说说。

> 我放上今天的神句：
We need to start figuring out how to imbue AI with everyday common sense, because it needs rules that can help it reason about the world.

这句话的意思是：我们需要开始想办法让人工智能掌握常识，因为它们需要依靠常识来展开推理，理解这个世界。

# 深度学习为什么教不出常识？

可能你想过“为什么”：现在的深度学习技术，确实能让人工智能完成各种复杂任务，比如识别图片、下棋、翻译语言等。它甚至可以击败人类顶级棋手。但问题在于，它并不理解这些任务的“意义”。它只是通过模式匹配和统计概率来完成任务，而不具备常识性的逻辑推理能力。

比如说，深度学习很难理解“因果”和“反事实”。

+   - 例子：你看到一个玻璃杯从桌子上掉下来，摔碎了。一个具备常识的人能立刻明白：如果杯子没被放好，它可能不会摔碎；如果桌上铺了软垫，杯子可能不会碎。但AI很难理解这种“如果...就...”的因果关系，它只能根据大量数据预测“杯子掉下去会碎”。

这就是深度学习目前的短板，它能处理特定的任务，但缺乏通用性和灵活性。

# 如何让AI学会常识？

怎样才能让AI学会常识呢？两个思路：一是从物理学的角度建模，比如把物理规律（重力、碰撞、摩擦力等）嵌入到AI中；二是从社会学的角度建模，比如让AI理解人类的情感、社会规范和意图。

+   - 物理建模：通过构建物理引擎，让AI理解物体如何相互作用。例如，让AI学会“推一个盒子”的动作，需要考虑摩擦力、盒子的重量、推力的方向和大小等物理参数。
- 社会建模：让AI理解人类的意图和社会规则。例如，让AI识别“这个人在笑是因为开心还是因为尴尬”，这需要理解语境和情感。
