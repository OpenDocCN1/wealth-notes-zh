而同样问题，全世界的平均数据只有25%。

1997年，在美国纽约发生了这么一起事件：一个来自秘鲁的旅游的丹麦妈妈，在餐厅吃饭的时候，自己睡着的孩子放在婴儿车里，留在大街上，结果，她被纽约警方逮捕了，逮捕理由是“儿童监管不良罪”。

这件事当时在丹麦引起了轩然大波，因为这样的的情况在丹麦再稀松平常，父母们都会这么做。这位丹麦妈妈在20年后接受《纽约时报》采访的时候，还表示对此不可理解，她甚至说，她感觉美国的父母整天都生活在恐惧之中。

刚才提到与英国记者罗桑丝也提，北欧国家这种人与人之间的彼此信任，是会“传染”的——自从她搬到丹麦生活之后，经常出门家里不上锁，停完车也不锁车。是的，北欧人之间的信任程度就是这么高。

所以你看，与互相怀疑相比，北欧人选择了彼此信任，这就让整个北欧社会的安全感非常之高，人民的幸福感当然也就更高了——所以说，快乐，首先一种理念选择。

此外，在北欧国家有一种独特的文化叫做hygge，这个词，很难在中文化找到对应的直译，它大致就是一种舒适而且令人满足的感官或环境氛围，包含了归属感、快乐、温暖、放松这些元素——这是北欧人的另一种快乐秘诀。

北欧人认为，想要获得hygge，那么你住的地方，应该有有充足的照明，温暖芬芳的事物和非常柔软的东西，比如枕头或者靠垫。

很多人都听说过，北欧人酷爱蜡烛，丹麦人的蜡烛消费量欧洲第一，比排名第二的奥地利要再多出两倍。这是因为，北欧人认为，蜡烛能营造温暖舒适的氛围，他们特别喜欢在屋子里点蜡烛，还在蜡烛的亮度、造型、香味上下足了功夫，这是他们创造hygge的一个关键要素。

你可能觉得，这些都是非常简单的生活琐事，但有研究表明，感受hygge不但可以让人觉得幸福，也会让人们与周围的人更友善。罗桑认为，hygge对于北欧人的整体幸福感提升，有着非常重要的作用。

虽然我们可以没有北欧国家高，在一天的辛苦工作之后，回到家中，窝在松软的枕头里，点上香薰和蜡烛，让自己享受片刻的放松，而不是通过抱怨、抽烟、酗酒之类的方式来发泄。你看，至少我们可以选择去刻意营造hygge的氛围，为自己带来快乐。

# | 总结

北欧人民的快乐指数全球领先，并不仅仅是因为北欧国家富裕、社会福利好。要知道，税率高、社会活力低，都是北欧人民付出的高昂代价。

北欧人生活更快乐，其实是因为他们做了两个选择：选择去相信他人、选择创造自己舒适的生活氛围，这就是我们可以直接拿来用的好方法。

就像Freaknomics Radio的节目里说的：我们都会受困于某些东西，但我们可以选择究竟要困于什么。

```
We're all trapped by something, we have to choose what we're going to be trapped by.
```

这句话，也是我们今天的金句。

最后我想说，快乐其实不是什么需要追求的境界，快乐就是一种选择。
