# ## 160报告：如何“利用”你的愤怒？

愤怒比其他任何一种情绪所能传达出来的信息都更多、更快。

——《纽约时报》

### 马徐骏

我们平时经常这么劝别人：“生气有啥用？解决不了任何问题吧！”但其实，你有没有意识到，愤怒是信息量最大的交流方式之一，合理“利用”你的愤怒，能解决不少问题。

今天的议题分为两个部分：

+   * 愤怒有什么用？
* 如何让你的愤怒不越界？

愤怒通常不会有什么好事，如果有人说爱生气，那你就一定会脾气不好，甚至修养不够。但你有没有想过，愤怒这种情绪，其实可以变成“武器”为你所用？

最新一期《大西洋月刊》上有一篇文章，叫做《我们为什么会这么愤怒？》，就探讨了这个话题。这篇文章的作者是查尔斯·达尔，《纽约时报》的记者，曾经获得过普利策新闻奖。

在这篇文章里，查尔斯通过很多例子分析了愤怒的各种用法：愤怒不仅可以疏导我们的情绪，有时还可以形成有效的沟通，甚至还可以作为凝聚公众力量、维护正义的工具；不仅如此，愤怒还可以被巧妙地调和与操纵，让别有用心的人从中获利。

当然，愤怒一旦过激，一定会造成恶劣的后果，所以，查尔斯也在文章里总结了如何控制和调节的办法。

好，今天我们就来说一说，我们能够如何利用和控制“愤怒”这种情绪。

# ### 1 愤怒有什么用？

我们平时经常这么劝别人：“生气有啥用？解决不了任何问题吧！”果真如此吗？作者查尔斯说，其实愤怒是信息量最大的交流方式之一。

愤怒比其他任何一种情绪，所能传达出来的信息都更多、更快。

这句话，也被选为了今天的天问句。

```
Anger conveys more information, more quickly, than almost any other type of information.
```

查尔斯引用了马萨诸塞湾大学的心理学教授James Averill做的一项问卷调查。Averill选择了大学生中产阶级居多，且与父母常为的小镇Greenfield作为调查对象。他原本认为，这些调查对象会被大多数人归为垃圾桶，但没想到，小镇上的居民非常积极，不仅回复了这份问卷，有人甚至还问卷后面附上了感谢，大部分人都认为，愤怒其实是一种很好的解决问题的方式，发一纸公文，往往不会让情境变得更好，反而可以改善原本糟糕的关系。
