# 代表未来科技应用方向的创新

这个部分我们主要讲三个发明，它们要么是使用了高新科技，要么是借助了新的商业模式，但都为未来科技发展方向做出了应有的方向，这一点在大家实际来看我是选了四个，但输送血液救命的人，咱们之前专门用一整期的篇幅讲过，我就不复述了，剩下的三个分别是：协助盲人视物的眼镜，隐形电视，个人定制的服装。

我们先来说协助盲人视物的眼镜—Aria，光听名字，你可能以为这款产品是通过加强盲人自身的视觉能力，来达到改善他们生活的目的，其实完全不是，这款产品使用的是borrow—借用，或者更准确的说，是“共享”的概念来解决盲人的生活问题。盲人可以通过佩戴特殊的眼镜，或者使用手机app，把自己四周的图像实时传输到网上，由全身无残的视觉专家通过盲人的视角来观看周围的环境，然后指导他们的行动，回答他们的问题，这款产品的产品经理人自己就是一个盲人，在此之前，她也使用Aria的服务，但人往机场工作了一年多都没有碰到任何问题，于是决心加入Aria的团队。可见这款产品是真正的非常好用。

![](bbox=[0.25, 0.19, 0.75, 0.28])

隐形电视是三星公司今年推出的一款产品，咱们家里的电视机平时不用的时候，就在一块巨大的黑镜子，而这款电视可以开启应变模式，在不用的时候融入家居环境，跟周围的环境保持同样的图案，让你感觉不到电视机的存在。当然，现在看起来是比较简单，但我认为它代表了未来人类生活的一种趋势，就是“去存在化”，只有在需要的时候才出现，平时隐藏在居家环境中，让空间的一致性最大化，其实《三体》的小宇宙，二百年后的人类城市生活，就是这个样子的。

![](bbox=[0.25, 0.39, 0.75, 0.48])

最后咱们来谈个人定制的服装，我们现在去商店里面买适合自己身材的衣服其实并不容易，每个人体型高肥不同，有些衣服只有均码，更好看也穿不了，但如果按照自己的身材定制，价格又太高，一般人承受不起。日本的2020公司推出了一个服务，你只要穿上一件带白色斑点的黑衣服，在自己家接受3D的身材扫描，通过手机app和手机面部识别的技术，Tazoo公司就可以为你全身建立一套3D数据模型，然后根据你数据定制衣服给你，目前可以使用是T恤和牛仔裤，分别是22美刀和58美刀，这项发明展示了未来世界里“平均的终结”，而个性化、定制化，从医疗到衣食住行，都会是必然的趋势。

![](bbox=[0.25, 0.61, 0.75, 0.7])

好，这个部分介绍的三个发明，其实最重要的理念，是把现有技术做了更加具体的场景化应用，当某种新工具出现了，另一种情形也会反复出现，就是发明这种工具的人，很长时间里不知道它最终能有什么用处。而能够把新工具更好的融入到人类的生活里去，本身就是了不起的发明。

# 1 总结

我们今天讲了《时代周刊》2018年最棒的50个发明，它们或者某种巧思，或者是简单的组合，又或者是新科技的落地应用，但我觉得离不开最核心的一点是，好的发明，是为了解决人类生活中的实际问题，而不是为了发明而发明，好的发明，只要有价值，哪怕再简单，就是了不起的。
