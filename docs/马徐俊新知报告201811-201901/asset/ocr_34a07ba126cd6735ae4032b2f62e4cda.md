# # 134报告｜让飞机告别噪音的“离子推进”技术

![](bbox=[0.15, 0.1, 0.85, 0.19])

离子推进技术为飞机和航天器打开了一扇新的大门，让它们可以飞得安静、构造更简单，而且不会产生任何污染。

——《自然》

马徐锐

你或许也曾经受飞机噪音的困扰。那么今天的内容将会带来一个好消息——《自然》杂志说，一项崭新的技术，可以彻底解决飞机的噪音问题。“无噪音飞机”很可能成为现实。

今天的笔记分为两个部分：

“离子推进”技术如何让飞机告别噪音？

“无噪音飞机”离我们还有多远？

长久以来，飞机的噪音一直是航天业的一大问题。不少经常坐飞机的人，包里都会带着降噪耳机或者隔音耳塞。其实被噪音困扰的不只是乘客，还有机场周边的居民。全球各大城市的机场，无论是扩建还是选址新站点，都很容易遭到周边居民的抗议。位于机场边的房产，升值潜力也比其他房子差。为什么呢？原因都是噪音。

自从莱特兄弟让第一架飞机升空以来，100多年间，飞机的外形、动力装置、燃料等都发生了翻天覆地的变化。但到目前为止，所有飞机都有一个共同特点，就是都需要靠运动部件的运动产生推力。比如，我们乘坐的客机是靠机翼两侧的引擎——或者几万个圆筒的巨型涡轮来；而直升机则靠靠巨大的螺旋桨才能飞起来，这两种动力方式，都会产生巨大的噪音。

不过，一项最新的技术，可以彻底解决飞机噪音的问题。《自然》杂志发表的这篇文章说，麻省理工学院副教授斯蒂文·巴雷特（Steven Barrett）领导的团队，研发出了一种能够降低飞机应用这项新技术。采用这种新技术的飞机，不使用传统引擎，不消耗化石燃料。更重要的是，它不会产生任何噪音。

目前，离子推进飞机的原型机已经在室内试飞成功。外界表示，这是航天技术迎来的重大革新，它为航天器带来了新的可能性。不过，要想在实际飞机上应用这项新技术，可能还需要很长的时间，最有大概率先被的，是无人机领域。未来使用离子推进的无人机，会变得相当安静。可以想见，这会在无人机在军事、运输、拍摄、环境监测等领域，获得更广阔的发展空间。

# “离子推进”技术如何让飞机告别噪音？

离子推进飞机之所以没有噪音，是因为这种机相改变了自己的动力方式。它不再是用电装置产生的“离子风”推动的，而不是传统运动部件。这很好理解：既然飞机没有了涡轮风扇，又没有螺旋桨，那自然也就没什么噪音了，这等于是从源头上解决了噪音的问题。

可要问怎么让飞机“离子风”又是什么，它怎么让飞机飞起来？原理听起来并不复杂，这涉及到电和空气之间的一个奇妙的关系。这么说吧，当电流经过两个电极之间的区域，一旦施加足够的电压，空气里的氮气分子就会发生电离，产生离子。这些离子会从电极的正极向负极流动。接下来重头戏了：当飞机飞行的过程中，会与周围的空气分子发生碰撞，就像打乒乓球一样，把这些分子推向前进，形成一股离子流。而气流产生了推升力，这也就是“离子推进”飞机动力的来源。我这么说，应该还算清楚吧！

其实，离子推进的原理人们早就研究透了，也已经应用在航天领域。现在在多数卫星的尾部都装有推进器，比如美国的“黎明”号小行星探测器，就是离了推进器飞往太阳系的小行星带的。老实话，“离子推进”听着很大，但它有一个致命的缺陷，就是推力很小。有人形容说，这种推力只能“吹动一张纸”。只不过，在近乎真空的太空环境里，微小的推力就能让航空器前进。

可在地球上，情况可不一样了。我们知道，地球上的大气层是非常厚的，阻力可比真空环境大多，要想在大气层中推动一架飞机飞行，那需要相当大的推升力。离子推进飞机这个设想，其实几十年前就有人提过，但最后几乎所有科学家得出的结论都是，按照离子推进的这种原理，它的推升力是不足以推动一架飞机的，这压根就行不通。

那这次麻省理工的巴雷特团队又是怎么做到的呢？他们想到的办法是，增强电压。理论上如果电压足够高，离子风的推力，或许就能推动一架小型飞机。可问题来了：想要产生高压电，装置就要很大才行，这会加重飞机的整体重量，让飞行器更难推动。研究很快陷入了僵局。

最终，经过长达9年的反复试验，巴雷特团队找到了解决方案，他和MIT电子与航空航天专业的埃德蒙·佛罗团队合作，设计出了一套强大又轻便的电源系统。它核心部件，就是电流。简单来说，他们为机翼安装了一排新型的聚合物锂电池，电池本身很轻，但通过转换器又能提供所到的高电压。这个电压有多大呢？可以到2万伏。

为了匹配这套电源系统，巴雷特团队又经过了各种微调，最后做出了代号为“Version 2”（也就是“第二代”）的飞机原型。飞机翼展5米，质量只有2.45公斤，差不多只相当于一只鸭的重量。

研究人员又在机翼下方，安装了两排金属线，看上去就像是两排百叶窗。这两排金属线，就是能够产生“离子风”的正负电极组了。

之后，就迎来了激动人心的时刻。在麻省理工学院的室内体馆里，巴雷特团队开展了“Version 2”的试飞。最终结果是，“Version 2”以每小时17千米的速度在体育馆里平稳飞行了60米，直到撞墙才停下来。他们一共进行了10次测试，飞机在每次试飞中都有稳定的表现，没有出现过任何不稳定迹象，就像普通飞机在空中平稳滑翔一样。更厉害的是，整个过程没有产生任何可闻的噪音。巴雷特团队的设想，终于初步实现了。
