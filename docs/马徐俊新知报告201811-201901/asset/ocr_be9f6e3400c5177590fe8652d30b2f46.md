# **120报告｜过度推崇“男性竞争文化”错在哪?**

今日报告: 过度推崇“男性竞争文化”错在哪?

对企业来说,“男性竞争文化”是“毒药”, 无论男性员工还是女性员工, 都会深受其害。

> ——《哈佛商业评论》

人们都说“商场如战场”, 你可能觉得, “男性竞争文化”看上去挺合理的, 恰好适应了商业竞争的残酷。但《哈佛商业评论》认为, 正是这种“男性竞争文化”, 给企业造成了多方面的伤害。

今天的议题分为三个部分:

+   - 什么是“男性竞争文化”?
- “男性竞争文化”如何伤害企业?
- 企业如何改变“男性竞争文化”?

这些公司的一些知名“企业”, 比如Uber、Nika、CBS (美国的哥伦比亚广播公司) 接连曝出了多起职场丑闻, 包括猥亵行为、职场骚扰, 还有性骚扰等等。其中陷入丑闻漩涡最深的, 可能就是Uber了, 就在去年, 一系列的性骚扰、性别歧视和员工之间的打手报复等事件, 让Uber所谓 toe-stepping (意为“踩脚刹车”, 式的竞争性企业文化, 受到了外界的强烈打击。有离职的前员工揭秘, Uber的工作环境简直是各种“权利的游戏”, 员工相互攻讦诋毁, 对各种违法违纪行为, 管理层睁一只眼闭一只眼。

问题到底出在哪呢? 斯坦福大学、英属哥伦比亚大学、多伦多大学的三位管理学教授联合做了一项相关研究, 刊载在《哈佛商业评论》的官网网站上, 他们把企业的深层原因归结为——这些企业过于推崇一种“男性竞争文化”。

什么叫“男性竞争文化”? 其实, 很多人听过的“雄性文化”, 归根结底就是一种“男性竞争文化”, 这种文化崇尚高强度的男性竞争, 可以“赢家通吃”, 鼓励员工表现出反抗, 鼓励加班、鼓励用尽一切方法达成目标。

说到这, 你可能觉得, 都“商场如战场”, “男性竞争文化”看上去挺合理, 不正好适应商业竞争的残酷吗?

但《哈佛商业评论》认为, 这种“男性竞争文化”对企业正常运营带来的风险, 像争议、暴政、性骚扰等给企业风采的影响, 或者其它更多与它有直接的关系。我们有必要对它建立一个新的认识。

**Ⅰ什么是“男性竞争文化”?**

“男性竞争文化”, 英文叫做masculinity contest culture, 其中的核心词masculinity, 它指的是, 一种男性具备的特质, 或者“男子气概”, 比如说得强、主动、喜欢掌控一切、喜欢冒险、喜欢打破规则等。那么, 这种“男子气概”如何出现在企业文化里面, 会变成什么样呢?

三位管理学教授调查了美国和加拿大的几千名企业员工, 把他们的反馈进行归纳分析, 最终总结了企业中的“男性竞争文化”的四个特点:

+   - 不喜欢任何弱点: 企业要求员工必须有强大的自信, 不能表现出犹豫、疑惑、不要求认错和失误, 不能表现出温柔或脆弱的情绪;
- 崇尚力量和毅力: 企业偏袒那些用身体素质, 运动能力优秀的员工, 喜欢员工官方履历, 提倡员工以高强度的工作为目标, 提倡加班;
- 任务永远优先: 企业要求把工作, 甚至包括家庭, 都不能耽误工作。企业认为员工调离, 会对工作投入度;
- 内部激烈竞争: 在职场上, 要想成功, 你必须打败你的同事; 员工之间的信任感极低。

以上这四个特点, 共同定义了“男性竞争文化”。那这种类型的企业文化, 在哪些领域比较常见呢? 答案是, 在那群男性占主导地位的, 如军事、金融、体育等行业。

比如金融行业和科技行业, 市场行情瞬息万变, 极具风险性; 还有医疗外科, 手术具有极高风险的防卫; 再有军警, 手都是军队或警察系统, 工作职责高、风险高, 竞争异常激烈。在这些行业的企业里, 男性优势都很大。

那可能得问, 企业里面不都是男人, 不是还有很多女员工吗? 实际上, 女性要想在个“男性竞争文化”的企业里生存, 她们会感到压抑或被排斥, 大多数成功的女性, 基本上表现出了一些不输于男人的好战心。否则, 就只能甘为一些辅助性的工作, 为那些成功的男人们打下手了。
