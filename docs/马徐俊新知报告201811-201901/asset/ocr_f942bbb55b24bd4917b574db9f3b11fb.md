# # 161报告 | 动物应该享有法律权利吗？

今日报告：动物应该享有法律权利吗？

> 任何物种都有生存和获得安全的权利。在我们看来，“生存权”不仅仅意味着活下去，或者对人类带来工具性的价值，它还有更多的含义。
——《经济学人》

马徐骏
《经济学人》提出，动物应该和人类一样，享有法律权利，成为“法人”。这背后，反映了人类对动物认知的不断更新和突破。

今天的议题分为两个部分：

+   1.  当动物成为“原告”
2.  对动物权力的重新思考

# ## 当动物成为“原告”

乍一看到这个标题，你可能会觉得，这不是老生常谈吗？现在热爱动物的人越来越多，各种动物保护组织也非常活跃，法律对动物权利的保护也不少啊，所以这个问题还值得再讨论吗？

但是注意了，今天咱们要谈的主题，不是“保护动物”，而是让动物和我们人类一样，享有属于自己的法律权利，成为“法人”（legal person）。这个问题，是许多国家在法律领域里面临的一个共同难题。

最近一期的《经济学人》杂志国际版，就发表文章探讨了这个话题，标题很直接，叫做《动物应该享有法律权利吗？》（Do They Have Rights?），不仅这个问题之所以值得被拿出来讨论，仅仅是因为人类社会的文明程度在大幅提升，人类越来越关注其动植物的福祉，还有另外一个因素，也把动物的法律权利问题推到了人类的跟前。

第一个因素是科学家研究发现，动物是有自我意识的。我们以前以为，自我意识是人类独有的东西，但这种想法已经被证明是一种错误和偏见。那么问题来了，一个拥有自我意识的动物，怎么能享受跟人类一样的法律权利和公平待遇呢？

这也牵扯出了第二个因素——随着人工智能的不断发展，如果有一天机器人有了自我意识，那机器人是否也应该享有法律权利呢？

文章里有句话说得非常好：

```
Every species has a right to life and security [and] that, in our view, “life” means something more than mere survival...or instrumental value for human beings.
```

这句话的意思是：

> 任何物种都有生存和获得安全的权利。在我们看来，“生存权”不仅仅意味着活下去，或者对人类带来工具性的价值，它还有更多的含义。

这句话，也是我们今天的金句。

# ## 当动物成为“原告”

2018年12月14号，一只叫Happy的亚洲象，在美国纽约州的法庭上成为了原告，代理律师兰蒂·怀恩要求法庭授予这只大象一种法律特权，叫做“人身自由权”（habeas corpus）。理由是，Happy在2006年的时候，通过了“镜子测试”，被证明是具有自我意识的。

关于“镜子测试”的概念，咱们之前在087号报告里专门讲过，能否从镜子中认出自己，是判断智慧生物是否拥有自我意识的一个标准。

律师认为，既然大象Happy已经拥有了自我意识，那么动物园把它关在笼子里的行为，就属于非法拘禁。这个案子在我们专栏上线的时候，还没有作出判决结果。

其实多年来，人们一直在试图给动物谋求更好的福址和生存空间。在过去十年里，欧盟、印度、哥伦比亚相继通过了，使用动物幼化物品的全球测试。美国纽约州和伊利诺伊州，禁止马戏团使用大象表演，佛罗里达州禁止赛马。2018年11月，美国加州通过决议，要求农舍养殖的动物，必须有属于自己的最基本生存空间。

但象Happy的案子，听起来还有点匪夷所思，动物还有“非法拘禁”的概念？这不该是适用于人类的条规吗？

其实，这件事看起来有些“奇葩”的案件，反映了一个新趋势——动物的法律权利正在得到尊重。过去，这种以动物为原告来争取法律权利的案件，几乎没有胜诉的可能，但是现在法律界和动物保护机构不断努力，近几年，在全世界范围内，动物们正在不易觉察地“反败为胜”。

比如说，一些动物获得了一种叫做“非人类法律身份”（non-human person）的权利，也就是说，虽然这些动物不是人类，却拥有了跟人类相当的一部分法律权利，比如人身自由权等。

2015年，阿根廷法院判了一只叫圣德拉的红毛猩猩拥有了“非人类法律身份”；2016年，阿根廷法院一只能叫哈西的类黑猩猩获得跟跟泰利一样的法律地位。虽然哈西和利有了跟人类差不多的法律身份，如果继续关其于负责，那么从哈西和利，那就要非非法拘禁了。所以，最后哈西和利被送去了巴西的自然动植物保护区。自由在巴生活，至今还呆在那里。2017年，哥伦比亚最高法院也对一只黑猩猩执行了相同的判决。

你现在应该可以理解，为什么这只叫Happy的亚洲象，能够站在原告席上，为自己争取“人身自由权”了。这背后，是整个法律系统对动物权利这个问题的风向变化。那么，是什么原因，推动了这种变化的出现呢？

# ## 对动物权利的重新思考

2018年5月，美国司法部作出了这么一件等事：一只叫Tommy的黑猩猩站上法庭，等待法院裁决它是否是有资格获得“人身自由”。在这个时候，法官能提出一个疑问——以前，法庭裁定动物不能享有法律权利的理由是，动物无法对自己的行为负责，但是，这个理由越来越站不住脚了。

为什么这么说呢，你想想，人类的婴儿，甚至是昏迷中，失去意识的成年人，也无法对自己的行为负责，但他们却能享受法律权利。那么，为什么不可以呢？这是一个非常明显的法律漏洞啊。

况且，近十年来随着科技的进步，人们对动物有意识的认识也越来越深入了。我们发现，动物不但有情感、智慧，还有跟人类相似的群体和社会化行为，也是跟人类，跟动物的差别，可能并没有那么大。

目前，全世界大部分国家的法律里，都是把动物当作人类的财产来对待的，因此动物并不享有类似、财产权、人身自由权这样的法律权利。但是，法律上规定的“法人”，必须是人类吗？

当然不是了。法人是个法定的概念，我们却知道，公司可以是法人，甚至自然景观都可以是法人。2017年，新西兰就给惠阿河特意授予了法人的身份，让这条河流的当前处于更好的保护。类似的案例在印度也有过。

有意思的是，美国有三个州的法律规定，如果一对夫妇离婚，法院决定要里向孩子的抚养，那么无孩子的情况或向选择离婚，则也必须考虑孩子自身。你看，这跟离婚案件，让孩子决定多少是屁股，也是一个道理。在这种情境下，身为动物的动物，跟人类的孩子已经没法区别了。
