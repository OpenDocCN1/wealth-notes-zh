# 今日报告：科技如何帮助西方劳动者与资本博弈？

科技曾经侵蚀了工会的力量，但驾驭好科技，可以让劳动者组织起来，再度拿回自己的权利。

——《经济学人》

马徐程

西方的工会曾经是非常强势的组织，但半个世纪以来，工会在科技的存在下，几度经历兴衰。通过今天的内容，你也许会科技给人类社会带来的影响力产生新的认识。

今天的议题分为两个部分：

*   科技如何左右工会的兴衰？
*   社交媒体如何给劳动者赋能

最近我在《经济学人》杂志上读到一篇文章，讲的是劳动者与资本之间博弈的故事，文章的标题非常有趣，叫做《全世界的劳动者，联合起来上网！（*Workers of The World, Log on*）》

我先说为什么会被这篇文章吸引，因为原来我和很多人一样，一直认为，科技的进步，正在逐渐削弱普通劳动者在资本面前的话语权，而且担心这种状况会愈演愈烈。但《经济学人》这篇文献的观点却恰好相反，它认为科技尤其是社交媒体，发展得尤其快，甚至在帮助劳动者们逐步拿回原资本博弈中的利益，其中最典型的就是“工会”（*union*）的振兴。

文章里说，科技曾经侵蚀了工会的力量，但驾驭好科技，可以让劳动者组织起来，再度拿回自己的权利。

这句话我也选为了今天的金句：

> *Technology has eroded union power. Harnessing it may help organised labour to stage a revival.*

通过今天的内容，你不但可以了解劳动者和资本之间的博弈简史，还会听到科技作为一个新的变量，是如何改变局双方跷跷板的重量之间的博弈简史。若错过了这一点，会让我们对于科技的影响力有一个更深入的认识。

# l 科技如何左右工会的兴衰？

在我们的印象里，西方的工会是很强势的组织，它们也可以代表人们跟资本家谈判，要求加薪或者谋取更多的福利，在判决资家的时候，还可以组织劳工罢业，逼资本家就范。

在最鼎盛的时期，工会强大到甚至可以在右派。当年罗斯福想要在美国实行新政、搞经济刺激的时候，如果美国工会不代资谈判，跟他们结盟，或就是会工会的支持，“罗斯福新政”一天都搞不下去。

就连咱们中国的吉利汽车的老板李书福，在2008年要收购沃尔沃的时候，也想过尽办法要安抚沃尔沃的工会，否则，哪怕谈成了福特公司的全球总裁，这事儿也是没戏。
