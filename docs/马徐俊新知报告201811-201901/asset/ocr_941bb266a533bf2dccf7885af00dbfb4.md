会对人造成什么影响了。那是不是就说就不要自律了呢？

# 如何调节自律的分寸？

《新科学家》一共给了三个建议，第一个建议是：重新评估你的目标。

作者说，适度自律当然是好的，但更重要的是，我们要想一想，在什么时候、什么情况下更需要自律。

想想刚才那个调查，哥伦比亚校友后悔年轻时错过的欢乐时光，你就会明白，你应该做的是重新评估你的长期目标，看着它值不值得你要通过高度甚至是过度的自律来实现。

文章还提醒说，那些高度自律的人，他们一旦设定了一个目标，即使这个目标对他们来说已经没有意义了，他们还是会坚持不懈的去实现这个目标，但这不仅不会让他们更幸福，还会影响他们的快乐指数和健康。

第二个建议是，在工作和生活上，你不仅要管理自己，也要管理别人对你的期待。如果你是个高度自律的人，你需要和别人谈论你遇到的困难和挑战，而不是把所有的压力和不满意压在心底。

最后一个建议是，你要适当的降低对自己的标准，不要对自己太过苛责。也让别人知道，你也是个普通人，你也会累，会辛苦，不要让他们把你的付出当做理所当然。

# 总结

咱们都知道自律是有好处的，在生活和工作上，很多人也给自己设定了条条框框来管理自己。但看完今天的内容，你就知道，自律再重要，也不能过度，否则也会伤害到我们自身。

在努力让自己更自律的路上，也许我们也该停下来想一想，更自律有没有让我们真的过的更好。就像文章里说的：我们应该记住，自我控制只是一种工具，学会什么时候不使用它，才是更明智的选择。

这句话也被我选为今天的金句：

> We should remember that self-control is merely a tool and we should learn when it would be wiser not to wield it.
