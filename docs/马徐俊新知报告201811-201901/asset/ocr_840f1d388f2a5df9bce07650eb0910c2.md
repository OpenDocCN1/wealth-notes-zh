# 165报告丨关于创新文化的五个硬道理

今日报告：关于创新文化的五个硬道理

关于创新的残酷真相就是一面是创新，一面是纪律。

> ——《哈佛商业评论》

马徐徵

那些“看上去很美”的 innovation 故事，只是硬币的一面，硬币的另一面，就是我们今天要讨论的五个原则。

+   - 包容失败，但不容忍无能
- 给予心理安全感，但也要建立绝对坦诚的沟通文化
- 要勇于进行实验，但也要有高度的纪律性
- 要寻求协作，也要实行个人问责制
- 组织要扁平化，但须领袖强大

你可能听说过很多关于创新文化的故事，最近，苹果CEO库克最广以为例的就是苹果内部没有级别，Facebook是“放养式”……越有个姓越好。因为认为，个性才有创造力。谷歌更是鼓励失败，公司内部有一条企业文化俗语：失败好，如果失败的次数少，说明你尝试得还不够努力。

这些故事听起来都挺美好的，但是，最新一期《哈佛商业评论》的封面文章，却让这些听起来很热闹的行为，只是新文化的硬币的一面，另一方面，是保证这些文化能够成功的精髓，就是纪律。

文章的标题就叫《关于创新文化的残酷真相》（The Hard Truth About Innovation Cultures），作者加西亚·皮萨诺（Garcia Pisanos）是哈佛商学院的教授，主修科技和企业运营管理。

在这篇文章中，皮萨诺从企业文化、管理和结构三个方面，总结了企业关于创新的五条原则，分别是包容失败，但不容忍无能；给予心理安全感，但也要建立绝对坦诚的沟通文化；要勇于进行实验，但也要有高度的纪律性；要寻求协作，也要实行个人问责制；组织要扁平化，但须领袖强大。

有意思的是，这五条原则，每一条的前半句，我们都耳熟能详，后半句，恰恰是我们没有看到的硬币的另一面。

# 1 包容失败，但不容忍无能

你可能听说过这句话：要建立创新文化，就要包容失败。但皮萨诺说，这句话少了半句，完整的表述应该是：包容失败，但不容忍无能。这是我们今天的第一条原则。

皮萨诺说，公司应该包容的是建设性失败（productive failures），这类失败能够为后面的项目带来新的知识和经验。

但公司应该容忍包容，尤其是因为技术不成熟、信息不清晰、工作流程、管理能力不足而造成的失败，这是绝对不容忍的。
