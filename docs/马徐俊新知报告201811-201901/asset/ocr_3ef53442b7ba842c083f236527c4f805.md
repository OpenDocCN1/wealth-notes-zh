# # 142报告 | 摇滚乐队能给企业管理带来什么启示？

今日报告：摇滚乐队能给企业管理带来什么启示？

如果把摇滚乐队看作一家企业的话，那么其实际正在企业也越来越像摇滚乐队了。

—— 《1843》

马徐骏

滚士乐队为什么长盛不？披头士乐队为什么分崩离析？每一支顶级摇滚乐队背后，都有一套独特的管理和运作模式，从他们身上，企业管理者或着者能得到一些启发。

今天的议题分为四个部分：

+   - 披头士乐队的一朋友模式
- 汤姆·佩蒂和伤心人乐队-专制模式
- R.E.M.乐队-民主模式
- 滚士乐队-亦敌亦友模式

我们通常觉得，摇滚乐手都是我行我素、不服管教，人生放浪不羁要什么自由，你不可能知道，其实际每一支顶级摇滚乐队背后，都有一套独特的管理和运作模式，这也是支撑他们走向成功的重要基石。

最近在 《1843》 杂志上，看到一篇很有趣的文章，讲到什么是。这篇文件分析了披头士乐队、汤姆·佩蒂和伤心人乐队、R.E.M.乐队、滚士乐队这四支顶级摇滚乐队，把他们分别对应到朋友模式、专制模式、民主模式和亦敌亦友模式四种管理模式上，角度是较独树一帜。

文章作者格雷·斯利策斯，如果我们把摇滚乐队看一家企业的话，那么其实际正在企业也越来越像摇滚乐队了。这句话也成为了当天的金句：

> > *If rock groups are businesses, businesses are getting more like rock bands.*

下面我们则分为四个部分，来看看这四支摇滚乐队各自不同的管理模式，它们的优点和缺点分别是什么？在不同管理模式的运作下，这些乐队最终的成功或结局是什么样的？他们能给企业管理者带来哪些启发？

# I 披头士乐队-朋友模式

鼎鼎大名的披头士乐队是摇滚音乐界的传奇，《1843》把他们定义为“朋友模式”的典型代表。

披头士乐队由约翰·列侬、保罗·麦卡尼、乔治·哈里森和林戈·史塔德尔四名成员组成，从1960年乐队成立以来，他们一直以形影不离的好哥们形象出现在大家面前。他们穿着一样的西装，穿着一样的衣服，久而久之，甚至连长也越来也越像了，他们的言禁主亲如兄弟，声音起也起大地衣无编。

他们之间关系好到什么程度呢？披头乐队的分家，一个人可以来另一个人的录音工作室，然后当作不留情面地调侃对方。保罗·麦卡尼就曾说过：“我们是一个人，我们只不过是一体的两个部分。”

那么，像披头士这样友谊和生意不分的模式，能有用到企业里吗？《1843》认为，一方面，披头士乐队的模式有积极意义的一面，研究发现，能在办公室交到朋友 的员工，会受到工作更有动力，而且常常更加快乐，也会获得更好的绩优评估。

但另一方面，如果员工在办公室搞太多交友，可能会为企业管理带来混乱、造成失败。

其实，披头士乐队最后分家正是因为这个原因。1967年，在披头士乐队的专辑《Let It Be》准备发布的时候，保罗·麦卡尼也录制了一张个人专辑，并希希望尽快发布。为了不与相互争夺销量，乐队的其他成员要求他暂缓发布个人专辑，但他没同意，直接引发了一场经济纠纷。

实际上，这原本是一个有关营销计划的商业决策，但却变成了乐队的成对与信任危机，而这件事也成为披头士成员失和的导火索。

最终，这支传奇乐队在1970年宣布彻底解散。

通过披头士乐队的例子，我们就能得到一个企业管理的经验：在“朋友模式”的管理体制下，虽然员能获得更多友好氛围，但发生利益冲突、做重大决时，就可能会给团队带来了太多的情感纠结。正常商业决策变成了，成了个人情快接。最后，不但生意黄了，恐怕连朋友都做不成。

# I 汤姆·佩蒂和伤心人乐队-专制模式

汤姆·佩蒂和伤心人乐队是美国一支老牌摇滚乐队，拿着这个乐队的名字，你能就知道，佩蒂是乐队没有灵魂人物，他就是主唱，又是词曲作者，没有他，整支乐队就没有主心骨。

其实佩蒂完全可以一个人发展，但由于童年家庭的原因，佩蒂需要一支乐队来让他获得归属感。可是，为了维护团队的安定团结，即使佩蒂的贡远远大于其他成员，他也一直坚持让团队成员之间要平均分配收入。

但是，这种“平均主义”的状况最终被打破了。当汤姆·佩蒂和伤心人乐队发行的几张专辑大卖之后，乐队管理了职位经人Arthur Roberts来打理事，Roberts做的第一件事，就是用自己以前管理乐队的失败教训，劝佩蒂放弃这种平均分配收入的做法，最后，佩蒂接受了Roberts的意见。

虽然团队其他成员对新合作模式很不满意，但最终所有成员都选择了接受，并继续留在乐队，由此形成了佩蒂为核心的“专制模式”。这种模式不但让乐队维持了佩蒂一贯的音乐风格，而且让乐队长期保持了稳定。

在当今这个流行扁平化结构的商业时代，仍然有一些企业更像佩蒂·汤姆·佩蒂一样，以“独裁”的方式来管理团队，并获得了成功，比如微软的CEO约翰·伦伯斯和苹果公司乔布斯。

当然，“专制”模式失败的案例也多，所以，采用这种模式来经营的企业，员工只能期望企业的核心领导人，都能有像佩蒂和乔布斯的天赋和能力了。

# I R.E.M.乐队-民主模式

R.E.M.乐队成立于1979年，是美国过去20年里最有潜力、风格最类别的几支摇滚乐队之一。R.E.M.乐队的管理模式非常民主，每个成员都有平等的发言权否决权，也就是说，无论商业还是艺术创作上的事情，每个人都要参与决策，只有当所有人的意见达成致之后，决策才能生效，而且团队成员的收入都是平均的。

这样的民主模式，R.E.M.一坚持了32年，直到乐队前成员少。除了R.E.M.乐队之外，Coldplay也是少数几个用民主模式管理，并且得成功的乐队之一。

那么，为什么汤姆·佩蒂和伤心人乐队要放弃民主模式，改为专制模式，而R.E.M.乐队可以始终维持民主模式并获得成功呢？
