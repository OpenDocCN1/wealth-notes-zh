# 154报告｜“基因家谱刑侦学”为何登上《科学》年度榜单？

![](bbox=[0.3, 0.03, 0.7, 0.08])

今日报告：“基因家谱刑侦学”为何登上《科学》年度榜单？

警方找出“金州杀手”的过程，是一项了不起的成就，“基因家谱刑侦学”就此推开了一扇大门。

——《科学》

马徐骏

有意思的是，“基因家谱刑侦学”入选《科学》杂志2018年度十大科学突破“榜单”，靠的不是科学家，而是警察，这是为什么呢？

今天的议题分为两个部分：

+   * 为什么说“基因家谱刑侦学”具有突破性？
* “基因家谱刑侦学”的应用前景

最近，国际权威期刊《科学》杂志（*Science*）公布了2018年的十大科学突破，其中包括：揭示细胞发育的全过程，捕获来自遥远星系中的微子，快速显示分子结构，搭建出冰原深处的陨石坑，科学界的“反馈墙”、古代人类的混血、首个“RNA”药物、5亿年前最古老的动物、细胞内的“相分离”，十大突破，都是警察。

老实讲，这十大突破，和“科学家”的故事，都离我们的生活比较远，所以，光看名单，你可能会觉得这份榜单不知所云。

不过，其中有一项科学突破，我觉得特别有意思，那就是“基因家谱刑侦学”，我觉得它单独拎出来，好好给你讲一讲。

![](bbox=[0.3, 0.33, 0.7, 0.37])

我为什么说它有意思呢？因为完成这项科学突破的，竟然不是科学家，而是警察。今年4月，美国加利福尼亚破了一起大案子，他们逮捕了一名73岁的白人男性，最终确认，他就是上世纪七十年代犯下一系列强杀案件、臭名昭著的“金州杀手”（Golden State Killer）。

值得一提的是，在侦破这起案件的过程中，警方用到的技术很厉害，叫“DNA家谱”。简单来说，就是警方把嫌疑人的DNA传到了一个开放的在线基因数据库网站，通过DNA数据匹配，先找到了嫌疑人的亲戚，然后，再通过这些亲戚，最终锁定了犯罪嫌疑人。这个方法非常有突破性，很多在之前破不了的悬案，都有了破案的希望。

《科学》杂志评价值：警方找出“金州杀手”的过程，是一项了不起的成就，“基因家谱刑侦学”就此推开了一扇大门。

> The way investigators fingered the alleged Golden State Killer was a stunning development, ushering in a new field: forensic genealogy.

这句话，也被选为今天的金句。

# Ⅰ为什么说“基因家谱刑侦学”具有突破性？

其实，“基因家谱刑侦学”这项技术，最大的贡献就在于，它实现了“模糊匹配”。这种突破并非常常见。要知道，以前的警方从犯罪现场收集了DNA之后，要想找出犯罪嫌疑人，就必须精准匹配，如果数据库里没有相匹配的DNA，那就找不到这个人了。

但是基因家谱技术让警方可以先找到犯罪嫌疑人的亲戚，再根据亲戚锁定嫌疑人——这种“模糊匹配”，能帮助警方大缩小搜索范围。

逍遥法外40多年的“金州杀手”就是这样被找出来的。所谓的“金州”，就是美国加州的别称。这起案子当年在加州非常轰动，人间之色。从1974年第一次作案，到1998年收手，这十二年间，这个恶魔在加州地区多次犯下严重入室强奸、杀人案件，尤其喜欢对夫妻做，对手子实施强，再残忍地将两人杀害，据估计，被杀人数至少过13人，被强暴的女性多达51人。“金州杀手”成了美国历史上最臭名昭著的连环杀手之一。

![](bbox=[0.1, 0.72, 0.9, 0.78])

可是，这么多年过去了，加州警方和FBI用尽各种方法，一直没能找出金州杀手到底是谁，这起案件就成了悬案。直到2016年，警方终于一件此前所有的事：他们把嫌疑人的DNA上传到了一个叫GEDMatch的民间网站上——我们就管它叫G好了。

这个网站提供基因序列服务，上面大约有100万个用户自己传上来的DNA信息，来自了解自己的祖先和家族起源，这相当于一个庞大的开放基因数据库。

警方在数据库里没发现匹配的人选时，于是，警方选择合作，通过一种叫“长系家族搜素”（long-range familial search）的新技术，在寻找与嫌疑DNA模糊匹配的数据，最终找到了嫌疑的十几个远房亲戚。

警方再通过搜索这些亲戚个人信息，综合分析的人口调查记录，绘制了一张张的家族图谱。最终，这个家族里有一个成员：高、符合嫌疑人的特征，73岁的白人男性詹姆斯·迪安吉洛（James DeAngelo）。

一番背景，原来他从前做过6年警察，具有极强的反侦查能力，难怪警方一直没找他。

警方没打草惊蛇，悄悄跟踪观察了迪安吉洛很多。最后偷偷从他的门把手上提取了DNA，并从垃圾桶中翻出了他喝过的纸杯，拿回去一对比DNA，结果完全匹配。迪安吉洛就是金州杀手！这个加州传奇长达几十年的杀人悬案终于被打破了，很快，检查员以6级一级谋杀罪，对他提起了诉讼。

金州杀手伏法之后，警方的破案手法引发了外界关注。

总的来看，基因家谱技术之所以能破案成功，得益于两个非常重要的技术进步。首先是公共家谱数据库。众所周知，警方的DNA数据库，基本只有犯罪前科的人数据，而如今的普通人只要花一点钱，就做到自己口腔细胞，给专业的公司，就可以自己的DNA进行系列。
