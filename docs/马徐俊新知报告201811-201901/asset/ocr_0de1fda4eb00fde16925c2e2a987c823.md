# 今日报告：播客如何靠“讲好故事”翻身？

突出表现主播内心的摇摆和纠结，正是《Serial》这部播客让听众欲罢不能的奥秘。

——《纽约客》

马徐锐
美因国

在美国，播客是一个庞大的产业，但在2014年之前，播客相当冷门，直到《Serial》的出现，引爆了播客的市场，那么，《Serial》成功的秘诀是什么？

今天的议题分为两个部分：

+   - 《Serial》如何创造新的叙事手法
- “讲好故事”怎么带火一个产业

播客，英文叫做Podcast，简单来说就是音频内容的网络分享平台。比如咱们的得到APP，就可以算作是一类基于知识服务的付费播客。早上洗澡、上下班通勤的路上、还在跑步机上挥汗如雨的时候，你都会打开来听一听好吧。

在美国，播客是一个庞大的产业，其中最主流的平台就是苹果公司的免费播客APP，里面有大量免费的音频节目，可以在线听，也可以下载到手机里听。

另外，市面上还有不少第三方播客APP，用户群体也庞大。根据新榜单显示，美国每4个人里就有1个是播客用户。

不过，在几年前，播客行业在西方还是相当冷清的，节目少，也说几人听。直到2014年，美国出了一部叫《Serial》，的调查类音频节目，这节目推出不到一个月，听众破百万，下载量破亿，正是它的成功，让公众重新认识了播客。

《Serial》为什么这么受欢迎？《纽约客》杂志最新刊发的一篇文章，提出了一个很有趣的观点：《Serial》成功的秘诀就在于，用播客创造了一种全新的叙事手法，也就是让主播成为推动故事发展的关键人物，通过深入展现他的内心活动，与听众建立起情感连接。

凭借这一点，《Serial》不仅赢得了超高人气，更让人们看到了播客作为一种新的内容创作平台的巨大潜力，随后，资金和人才涌入，才让播客迅速发展成为一个大黄金产业。

# 《Serial》如何创造新的叙事手法

你可能会觉得，播客不就是用声音讲故事嘛。对，用声音讲故事没什么特别的，这是一项古老的技术，但是《Serial》独特地方在于，它赋予了一个讲述者，也就是说，一个明确的主播，让她自己变成了推动故事往前走的关键人物，并与通过展现一种心态的摇摆和纠结，与听众建立起一种情感连接——这种叙事手法在西方，是从未有过的。

要说清楚这一点，我们得看看《Serial》到底是怎么讲故事的。这个节目选取的题材很刁钻，讲的是十二年前发生的一起惨烈的高中凶杀大案。这是一个真实事件的——1999的冬天，美国巴尔的摩的伍德罗恩高中的韩裔女学生海莎丹（Hae Min Lee）放学后去没回家，一个月后，他的尸体在学校附近的公园被发现。

警方怀疑杀死海莎丹的人，是她的男前、一个穆斯林男孩阿德南·赛瓦德。虽然阿德南坚决否认，但他始终无法提供不在场证明。最终，17岁的阿德南被判终身监禁，高中还没毕业就开始服刑。

14年后，调查记者莎拉·凯恩格，《Serial》的主播，收到了—封邮件，是阿德南的好友拉比拉比亚写的。拉比亚坚信阿德南是凶手，认为赛瓦德是骗局，受托了一位不太起眼的人，给到到拉迪乌法·凯尼希望她能想办法查出真相，凯尼被拉马迪这个案子吸引住了，于是独立展开了调查。
