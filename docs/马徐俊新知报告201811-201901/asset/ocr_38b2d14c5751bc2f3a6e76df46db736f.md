# 今日报告：为什么科学家不如娱乐明星红？

科学家们的威望和社会地位下降，是由传播媒介造成的影响力变迁决定的。

> ——《鹤鹤》

麻省理工学院的一项研究认为，决定一个人知名度被人们记住多少的主要因素，是人类的大脑记忆与过往信息的载体。那么，为什么娱乐明星比科学家更有名呢？这对人类社会将产生什么样的影响？

今天的议题分为三个部分：

+   - 集体记忆是如何表达的？
- 为什么科学家不如娱乐明星红？
- 未来我们将记住谁？

我们经常发这样抱怨——为人类文明的发展做出了重要贡献的科学家，无论在知名度上还是关注度上都远不如娱乐明星。如今这是一个流量都道的时代，这种情况还有愈演愈烈的趋势。

有一种观点认为，科学家不如娱乐明星红，是由于科学家的娱乐明星的评价体系不同，科学家追求的是长时间跨度的名声，而娱乐明星追求的是短时间内的热度。

最近在《鹤鹤》杂志上看到一篇文章，叫《我们终将忘记约翰·列侬》(How Well Forget John Lennon)，作者是麻省理工学院媒体实验室的伊德·伊达尔戈教授。针对刚才提到的那个问题，伊达尔戈教授提出了一个新的见解，他认为一个名人，无论是科学家还是音乐家，包括体育明星、明星，想要能被长期记住、起决定作用的其实是人类集体记忆（collective memory），以及我们传递信息的载体。

《鹤鹤》杂志的特刊编辑凯·伯杰采访了伊达尔戈，谈到了伊达尔戈教授最新发表在《自然》杂志上的文章：今天我就不去讲伊达尔戈教授的研究，直接来给各位分享一下他对我提出的问题的回答：为什么伊达尔戈不如娱乐明星红，也有一部分原因是科学工作者自己造成的？未来又将进入我们的集体记忆？

# 1 集体记忆是如何表达的？

作为历史学家，你可能经常会听到“集体记忆”这个概念，那么什么是集体记忆呢？伊达尔戈教授对集体记忆的定义是：特定范围内，大多数人共同拥有的知识和信息。

伊达尔戈教授认为，集体记忆对人类而言，是非常重要的东西，甚至人类之所以能够称之为人的唯一理由，由于集体记忆不断积累，我们才能够走到今天，如果没有人类能系统地、不用发动战争，只需能让汽车、电影、手术等整个人类将不复存在。
