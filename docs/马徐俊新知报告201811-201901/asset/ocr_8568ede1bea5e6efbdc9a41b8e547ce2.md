# ## 131报告：《时代周刊》发布2018年最棒的50个发明

这50个发明，改变了我们生活、工作、娱乐的方式，甚至让我们重新思考了“可能性”这件事。

——《时代周刊》

马修·麦克德莫特

2018年最棒的50个发明，让我们重新思考了“可能性”这件事。

今天的议题分为两个部分：

+   - 最棒的5个创意发明
- 代表未来科技应用方向的3个创新

每年年底，《时代周刊》都会推出一个很有意思的榜单，专门选出一年里最棒的发明。去年的这份榜单，我曾经在上一季的专刊里读过，获得了很酷的这份榜单。

最近，2018年的榜单新鲜出炉，这份榜单混合了《时代周刊》编辑部的投票、世界各地主流媒体记者的意见，以及网络公开评选的结果，一共评出了50个年度最佳发明（best inventions）。

《时代周刊》把它们叫做“50个了不起的发明”，因为它们不仅让世界变得更好、更智能，而且也有趣了。可以说，这50个发明，改变了我们的生活、工作、娱乐的方式，甚至让我们重新思考了“可能性”这件事。

我把这句话选为了今天的金句：

> > 50 groundbreaking inventions that are changing the way we live, work, play and think about what's possible.

由于报告篇幅有限，我从榜单上的50个发明里精选了8个，分成了两大类，一类是富有巧思的创意发明，另一类是代表未来科技应用方向的新发明，接下来我将给你做详细的介绍。

# ### |5个富有巧思的创意发明

这五个发明没有所谓的黑科技或者领先的新技术，但都非常巧妙，也有趣，也非常实用，不少在市场上销售也非常可观。

它们分别是：万用锅垫、随处可贴的工具箱、教孩子学编程的魔杖、任天堂Labo游戏套装、提高睡眠质量的耳机。

首先是万用锅垫，叫做A lid that fits most pots，它们常做一个萝卜汤、一个铜勺、一个盖盘，但饭吃过的大家都知道，锅垫其实是个很尴尬的东西，什么地方不说，因为形状各异还不好放，如果说有一种万用的锅垫，什么容器都能盖上就好了。

其实这种产品一直都在研发，但都不理想，要么是容易掉进锅里，要么太收缩不了锅的容量，或者导致硅胶包裹的不够好。
