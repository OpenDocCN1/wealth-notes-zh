# 今日报告：科学预测寿命成为现实？

人的寿命已经被写在你的DNA中了，我们只需要想办法把它解读出来。

> ——《麻省理工科技评论》

马修·赫拉德

《麻省理工科技评论》披露了一项革命性的新技术——通过观察DNA的特定变化，可以科学地预测出人的寿命。这技术，将对医疗、保险等行业带来巨大的变革。

今天的议题分为三个部分：

+   - 寿命是怎么算出来的？
- 延长寿命是可行的吗？
- 寿命预测的商业价值

我们每个人都好奇过自己能活到多少岁，对吧？不过这个问题，科学家回答了，长期来这是一个真正的“麻省理工科技领域”。可是，最新一期《麻省理工科技评论》却刊登了一篇文章说道，美国加州大学洛杉矶分校的生物学史学家史蒂夫·霍瓦茨（Steve Horvath）正在致力于开发一项具有革命性的新技术，这项技术，可以科学预测人的寿命。

霍瓦茨的方法是，通过测量DNA的某些特定的化学变化，算出人的衰老速度，再过衰老速度的快慢，进一步估算出人的年龄。

实验证明，这个方法是可行的。虽然目前，霍瓦茨还无法对寿命做精确预测，但这项技术的发展前景不可小觑。

《麻省理工科技评论》预计，这项技术一旦成熟，人的预测寿命将成为一项重要的参数，为医疗行业、保险行业带来巨大的变革。更让人期待的是，科学家们也许会根据这项新技术，找到真正有效的延长寿命的方法。

这篇文章最有趣的新知是：人的寿命其实已经写在自己的DNA中，我们只需要想办法把它解读出来。

这句话，也被我选为了今天的金句：

> Your life span is written in your DNA, and we're learning to read the code.

# 寿命是怎么算出来的？

刚才我已经讲过，对寿命的预测，是通过衰老速度来估算的。而衰老速度，跟人体DNA的某些化学变化有直接关系。简单来说就是，通过观察人的DNA，就可以预测寿命。

这个发现，完全是偶然。谁发现的？就是我们刚刚提到的加州大学洛杉矶分校的教授霍瓦茨。

说来也很有意思，霍瓦茨自己是个异性恋，但他有个跟他作一模一样双胞胎弟弟，却是同性恋。作为生物学家，他对此一直比较困惑和想不通。几年后，他开始研究这个课题，思考着这种现象是不是“表观遗传”。

“表观遗传”这个概念，我在《新知报告》之前的文章里曾详细讲过。简单来说，“表观遗传”就是，你的一个切完全由DNA序列决定的，某些先天因素（比如吸烟）也会影响到基因表达，让人们呈现出不同的特征。

原本霍瓦茨相信，之所以双胞胎长得一样但却不一样，和表观遗传有关系。但样本分析结果显示，没啥关系。

霍瓦茨并没有失望，因为在这个过程中，他有了另外一个重大发现：有一些蛋白质和表观遗传有关系，那就是——衰老。

霍瓦茨觉得，这个发现太重要了。他立马停止了手头的其他工作，一心扑到了这个项目上。

具体来说，霍瓦茨的发现是：通过观察DNA的主要成份“端粒”发生的变化，能够准确地计算出人的生理年龄。通俗讲，就是身体年龄。通过和实际年龄对比，就可以知道你的衰老速度。

这个发现有什么用途呢？这么说，如果你知道了一个人的实际年龄，然后再观察他的DNA就出了生理年龄，就可以判断出这个人身体的衰老速度到底是快还是慢了。

比如说，一个人实际年龄是35岁，但他的DNA显示，他的生理年龄是40岁，那就说明衰老速度快了；反之，如果生理年龄是30岁，比实际年龄小，那就是衰老速度慢了。

霍瓦茨管这个发现叫“表观遗传时钟”，英文是The Epigenetic Clock。这有个形象的叫法，指针对走得快，说明人衰老得快，指针对走得慢，说明人衰老得慢。

下一步，通过这个时钟，就可以预测人的寿命。时钟走得快，寿命就短；时钟走得慢，寿命就长。

这个方法准不准呢？霍瓦茨的团队想了个比较巧妙的验证办法，他们检测了1万3000个血样本，这些样本都来自几十年前的集合，样本的主人就去世了，在逝者们的寿命就是已知的，很方便比对验证。

最终结果是，霍瓦茨的“表观遗传时钟”的可以用来预测寿命的长短。

不过，这种预测还不够精确，也就是说，霍瓦茨虽然能预测寿命长短，但霍瓦茨一个人只能预测多少岁。现在，霍瓦茨的实验团队正在开发新版本的“表观遗传时钟”算法，让人寿命预测变得更精确。

看到这儿，你可能会非常关心一个问题：既然人的寿命会被记录在相关里面，那有没有什么办法能减缓衰老速度，延长我们的寿命呢？

# 延长寿命是可行的吗？

对于延长寿命是否可行的问题，霍瓦茨给出的答案是：可行。

为什么这么说呢？要把这个问题解释清楚，我们又得回到“表观遗传时钟”的原理上来。

“表观遗传时钟”走得快慢，是由DNA中的化学组物变化决定的。随着我们年纪增长，DNA中的“端粒”会随着或或某些化学组物增加或减少，找出其中300~500最重要的变化，而这些变化，就是他用来判断衰老速度的依据。

打个比方，这几百种变化，就相当于“表观遗传时钟”背面的机芯和零件，它们可以决定时钟走得慢或者快一点。

但是霍瓦茨发现，这些化学物质的变化模式并不是固定的，而是会受到外在因素的影响。他的估计是，40%由遗传基因决定，剩下的则是由生活方式决定，外加一些运气因素。

什么意思呢？就是说，你的生活方式，会对你的衰老速度有影响。比如常喝点红酒。如果你吃得健康，比如多吃鱼和蔬菜，衰老速度就会慢一些；如果你长期失眠，衰老速度就会加快。

另外，吸烟会显著增加你的衰老速度，这种影响不会在生理年龄中体现，它是体现在你的“表观遗传时钟”上体现出来的。

你可能想问，这些发现不是挺符合大众认知吗？没什么新的。那我可说一个可能会颠覆认知的发现：运动对寿命的影响。你可能觉得，锻炼对身体健康能延长寿命吧？

但霍瓦茨的发现是，有规律地做锻炼身体，似乎并不会让你的衰老速度减慢多少。体现在寿命变化上，可能也就最多增加几个月的寿命。

当然，这不是说运动没用，运动或许并不能帮你活得更长寿，但它可以让你在有限的寿命里，更有活力。

可以想见，如果寿命预测的结果并不是个绝对值，而是可以改变的，那就意味着，我们可以透过这套数据算法，来测试一些新型方法对我们寿命的正面作用，或者无效，然后对自己的生活方式做出更合理的调整。

更值得期待的是，科学家用这项技术，可能会开发出能延缓衰老的“黑科技”。除此之外，寿命预测还具有非好的商业价值……
