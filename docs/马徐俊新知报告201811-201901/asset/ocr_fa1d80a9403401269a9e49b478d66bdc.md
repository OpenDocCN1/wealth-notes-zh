# 今日报告：精品付费短频会是一个热点吗？

Quibi想要成功，视频质量不但要高，数量还要充足。

——《财富》

![](bbox=[0.05, 0.22, 0.2, 0.25])

《财富》杂志认为，美国新成立的流媒体公司Quibi开辟了“精品付费”这条新的赛道。Quibi是如何做到的？这条赛道可以走多远？

今天的议题分为两个部分：

+   - 精品付费为什么会是短视频的新赛道？
- Quibi如何吸引好莱坞顶级资源？

短视频近年来非常火，且不说YouTube、奈飞这类专业视频平台，就连科技巨亚马逊、苹果，还有社交媒体Facebook、Snapchat，都在花大力气投资制作短视频类型。不过，最让这两位创始人自豪，却把关注的焦点投向了一家新成立的流媒体公司Quibi。

这家公司从创立之初就很受关注，主要是两位创始人太有名了，一位是梦工厂创始人杰弗瑞·卡森伯格（Jeffrey Katzenberg），另一位是刚退休的前CEO梅格·惠特曼（Meg Whitman）。算起这两位创始人的人脉和影响力，Quibi获得了来自迪士尼、福克斯、时代华纳等影视巨头10亿美元的投资，还签下了奥斯卡最佳男演员，执导过《水形物语》的吉尔莫·德尔·托罗、《蜘蛛侠》的派洛瑞奇等。这些电影大腕，都会为Quibi制作内容。

借着这批优质资源，Quibi计划在短视频市场开辟一条新的赛道——精品付费视频。一方面，它不同于YouTube品用户自制视频，而是邀请业内大牌，呈现出莱坞级别的短小精品；另一方面，它要用以免费为主的视频市场，打造一个靠用户付费订阅来盈利的模式。

卡森伯格和惠特曼坚信，Quibi会成为短视频市场的下一个领跑者。

不过这条赛道想要走得通，视频内容的数量还要有保证。卡森伯格说过这么一句话：Quibi要想成功，视频质量不但要高，数量还要充足。

In order for this (Quibi) to succeed, you need quantity of quality.

这句话，也是今天的金句。

# 精品付费为什么会是短视频市场的新赛道？

听到“精品付费”四个字，你可能会觉得，没有什么新鲜的。你看我们《得到》，做的不就是精品内容吗？但是在短视频市场，精品付费这条赛道还真没有入过，这确实是一条新赛道。
