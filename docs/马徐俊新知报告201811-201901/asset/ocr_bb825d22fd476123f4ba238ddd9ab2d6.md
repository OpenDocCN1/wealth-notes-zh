# ## 今日报告：三大权威英文词典的2018年度词汇

这三个词概括了人类面临的几乎所有的议题，也反映了人类在现代社会中的感受有多极端。

——《卫报》

马徐骏

《牛津词典》（柯林斯词典），美国在线词典选的2018年度词汇，不约而同地折射出了焦虑和困顿的情绪。这是为什么呢？

今天的议题分为两个部分：

+   - 2018年三大年度词汇
- 年度词汇折射了什么样的焦虑？

去年底了，英文界最权威的三大词典强势联手，做了一场“最牛盘点”，给出了2018年的年度热词（Word of The Year 2018），它们从词汇的来源素养、角度、重要等角度来看，概括了这一西方世界在认知、社会文化、生活方式等领域最新的趋势，也为我们了解西方认知的最新趋势，提供了一个更高的维度。

这三大权威词典真的应该叫个霸者：《牛津词典》不用多说，它被《纽约时报》评为全球最著名的英语词典，从1928年开始正式出版，到今天已经有90年的历史了；《柯林斯词典》一直是英语学习者的必备词汇书，几乎一人一本；而美国在线词典 Dictionary，准确来说，其实是“在线字典”，是美国最大的词典网站，在年轻用户中非受常欢迎。

近年来，这三大权威词典发布的年度词汇，都是西方媒体重点关注的大事，像《卫报》《纽约时报》《时代周刊》这些顶级媒体，一到年底，就都会盯着这马嘴翻动动作，等年度词汇一出炉，立刻马不停蹄地大篇幅报道，生怕错过这个知识界的热点新闻。

那么，回顾2018年，它们都选出了哪三个年度词汇呢？

《牛津词典》选出的年度词汇是 toxic，意思是“有毒的”；《柯林斯词典》选出的年度词汇是 single-use，意思是“一次性的”；美国在线词典 Dictionary 选出的年度词汇是 misinformation，意思是“错误信息”。

听起来，这三个年度词汇都不同而地折射出了一种情绪，那就是焦虑和困顿。那么，三大权威词典为什么选择这三个词呢？这些词汇背后，反映了哪些社会现象和问题？

# ### 2018三大年度词汇

先来说说《牛津词典》选出来的 toxic（有毒的）这个词。这个最早是在17世纪的中医出现在英文世界里，它来自于拉丁词“toxicum”，意思是“毒药”。《牛津词典》认为，这个词几乎是用来形容在过去一年里，从工作影响到社会文化，乃至人际关系和心态，总之所们遇到的一切问题，都可以用这个词来描述。

比如说，“男性毒害”有了官方英文表达，叫 toxic masculinity，字面意思是“有毒的男性气息”，在职中，由于投资币毒害、薪酬不公等因素等因导致上班族的压力越来越大，甚至出现了精神问题，这种工作环境就叫做“有毒的环境”，英文是 toxic environment。

再来说说《柯林斯词典》选出的年度词汇 single-use（一次性的），这里指的是一次性使用的物品。他们认为，一次性使用的物品容易造成环境污染最深层的原因。 公众和政策制定者需要更深入的认知。 2018年10月份，欧盟议会投票通过了一项决议，他们认定在2021年，欧盟所有成员国禁止使用一系列一次性塑料用品，比如说吸管、餐盒等等。

那最后一个选出的词汇是美国在线词典 Dictionary.com 选出来的，Dictionary 的年度词汇是 misinformation（错误信息）。

在这里，简单介绍一下美国在线词典。相比前两个简单粗暴的大部头，美国在线词典的风格更“fashion”一些，在这个网站除了可以查询单词的含义和用法，也还能找到很多讲英式文化、英语历史、这些热词常见的西方社会现象等，也有广泛社会影响的词，比如说网红 influencer，再比如如今天非常火的一些英文单词，可以说是应有尽有。如果你对英语感兴趣，那我推荐你常常用刷这个网站。

咱们继续来讲 misinformation。人们通常会把网络上不实信息统称为“假消息”，但在 Dictionary 看来，假消息可以分为两种，故意作伪的信息，或者叫谣言信息 disinformation，和无意识传播的错误信息——misinformation，你可能听出来了，最大的区别在于发布信用性的人的意图。比如说一个社会，他明知消息是错的还通过社交媒体传播，那这个叫虚假 disinformation；而老百姓不知道消息为真，继续传播出去，这时，这个消息就变成了错误信息 misinformation。

那这个词应该怎么更好地准确地使用呢？比如说，你看到妈妈或爸爸在朋友发朋友圈。文章为我们看来明眼是挺有科学依据的，文章替了替老父亲是没有任何目的，会觉得他怎么还会发些没用的东西。但是如果你的信息，你说，这个是父母故传的信息——disinformation，那就不是因为他们不知道信息是错误的和传播是错误，而是知道他们父母是受害者，我相信信息是针对他们争取到的，同仇敌忾，而不是一味地指责他们传假信息。毕竟，他们只是被 misinformation，misled 了。

我说的这一点，只是 Dictionary 选择这个词的一个原因而已。这三个词典，在选择年度词汇时都有更多的考量。

# ### 年度词汇背后的焦虑

牛津、柯林斯和 Dictionary 选的这三个词，有毒、一次性使用和错误信息，都有一个共性，那就是这三个词都隐含了一种普遍的焦虑或者困惑。

就拿《牛津词典》来说，今年的年度词汇 toxic——有毒的。《卫报》说，《牛津词典》的数据显示，2018 年“toxic”在词典网站上的搜索量增加了45%。我们从搜索数据上，就能看出人们关注的焦点。

那么，“有毒”这件事，危害到底有多大呢？《牛津词典》说，它渗透到了人们的日常生活、职场环境，甚至思想潮流的方方面面。

比如说，WTO 最近发表的报告，说全世界有超过90%的儿童，受到科技界的“良心担当”——谷歌，默认了手机工具事件，就是为了谷爱富和层员工们，加上不平等和性骚扰造成的有毒职场环境。牛津词典首席编辑，格拉萨斯（Casper Gratwohl）说，在过去一年里，“有毒”这个词反复用来描述我们面临的各种情况，toxic 无处不在。

而《柯林斯词典》在这个一年，更关注的是环境问题。柯林斯认为，新闻报道和电视节目对环境问题的关注，提高了人们的环境意识，这让“single-use”这个词的使用次数，从2013年以来，上升了4倍。

柯林斯认为，一次性使用的物品，主要是塑料。它造成环境污染和破坏食物的真正原因。但《卫报》为莱斯特理论说，还可以挖掘更深层的原因，有两个大经济因素，金属吸管可重复使用的东西在价格更高，所以价格低更廉大一次性用的物品更受欢迎。二是资本主义型态的抛弃型社会也推动了一次性物品使用的风潮。
