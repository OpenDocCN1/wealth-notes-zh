# 145报告｜领英创始人的“反常识”创业方法论

# 今日头条 | 领英创始人的“反常识”创业方法论

无论你的企业有10名员工还是1万名员工，闪式扩张都是获得胜利的必备手段。在这个世界里，速度是唯一重要的竞争优势。

——比尔·盖茨

天下武功，唯快不破，这句话，完美地诠释了领英创始人里德·霍夫曼的创业方法论。

今天的议题分为三个部分：

+   接受一定程度的混乱
快速解决问题的方法才是好方法
关注当下，放弃完美

硅谷的传奇投资人、职业社交网络Linkedin的联合创始人、里德·霍夫曼（Reid Hoffman）最近出了一本书，书名叫《闪电式扩张》（Blitzscaling）。霍夫曼在介绍这本书时就说，创业公司千千万，有的赚了一桶金，有的却成长为行业巨头，这背后有什么秘密呢？

这个秘密叫做“闪电式扩张”——Blitzscaling。

你可能要问，什么是闪电式扩张？闪电式扩张代表的是一系列的方法组合，这些方法能够帮到你的公司实现超高速发展，打败竞争对手，从行业中崛起。

Airbnb的CEO布莱恩·切斯基（Brian Chesky）就说，这些方法是初创公司最重要的方法，它为完美地描述了初创公司在每个阶段面临的挑战，并且提出了应对的方法。

谷歌前CEO埃里克·施密特（Eric Schmidt）说，像更慢的方法，省下了硅谷初创公司取得成败核心的知识点。比尔·盖茨还为这本书写了序言，对这本书的实用性给予了高度肯定。

那么，到底怎么实现闪电式扩张呢？霍夫曼说，对于实现闪电式扩张，创业者在公司早期应该看重的就是速度，要快！

在这个原则下，你要遵循最核心的这三条“反常识”行为守则，它们和你平时在商学院学习到的知识，可能很不一样。

这三条原则分别是：
第一条：接受一定程度的混乱
第二条：快速解决问题的方法才是好方法
第三条：关注当下，放弃完美

# I 接受一定程度的混乱

霍夫曼说，传统的管理思想，是追求秩序和规则，创业者想象中的公司蓬勃发展，公司运营井井有条，稳步向前。但霍夫曼说，不对，对于一个公司最重要的快速度发展，在你追求闪电式扩张时，你就得接受一定程度的混乱。

就是说，当你在进行闪电式扩张的时候，可能一年就要重组几次，从管理到到员工构成，都会反复调整，进进出出。

霍夫曼说，就像他管理的Paypal来说，Paypal取得的成功够了不起了吧？但这家公司的董事会开始说，我们既没有在未来长远地想象，就说公司在三年后会发展成什么样都没有任何概念。更绝的是，他们都组成系混乱管理都没有。

霍夫曼说，大多数时候，他们唯一做的事就是明确每个员工负责属于哪个团队，其他的团队组建一概没有，乱就乱吧。

不仅如此，哪怕员工手头负责的工作，也是变来变去的，公司里经常会见到这样的情况：我想知道过去4年这了个项目？出很多，但现在，我们换个部门做了。

你说，一个人，公司今天安排了做这个，明天又安排做那个，人公司还来变去，未来也没有展现出计划，这公司能成功？霍夫曼的回答是，能。

就是这样看似糟糕的管理，在公司进行闪电式扩张的时候，给了他们更直觉的优先权。内部的混乱让组织里的每个人都在应对变化时，反而能把公司更具弹性地在剧烈变化中，更灵活，让公司更具弹性地去解决突发状况，在剧烈变动中迅速调整。

所以，霍夫曼给出的第一条原则是，如果一个初创公司想要实现闪电式扩张，乱是对的。

# I 快速解决问题的方法才是好方法

可以说，公司在每个时部都有要面对的问题，在制定解决方案时，霍夫曼说，先想到，快点解决比什么都重要，速度是第一位的。

那你可能会说，这样想出来的办法不都是权宜之计，纯粹为了应急么？以后如果遇同样的问题，还是要想办法解决，为什么不设计一个一劳永逸的方法呢？

霍夫曼说，你看Airbnb怎么解决房源发布的质量问题就知道了。

Airbnb刚创立时，房友在网上发布的房源品质都不好，Airbnb前后使用了三种方法，每一个方法都彻底推翻之前的方法。

最开始，Airbnb一共只有三名员工，也就是三名创始人：布莱恩·切斯基（Brian Chesky）、乔·戈比亚（Joe Gebbia）和内森·布莱查捷克（Nathan Blecharchick），两个创办人拿自己的相机来给房人拍房源，另一个创办人就没日没夜地维护网站。当时他们每天要拍10户人家。

慢慢地，Airbnb的业务有了起色，单靠两个人拍照，是无法满足业务需求了。这个时候，他们开始从各个渠道招募摄影师，有朋友介绍的，有人网上找来的，甚至对摄影感兴趣的房东都被招进来了。

就这样，他们组建了一支10到10人的拍摄团队，按每套房50美元的价格帮他们拍照。当时他们还用了电子表格来分配任务，追踪工作状态。

但Airbnb发展得太快了，这个拍摄团队和摄影散式很快就不堪重负，将提供摄影团队人扩充到550人，还是跟不上公司发展。到了这个时候，Airbnb才将房屋摄影管理进行自动化。

最开始，他们给网站增加了一个按钮，一个是房东申请摄影拍摄，一个是摄影拍摄结束后请收款。最后，他们招聘了专门的软件工程师，整合了系统，从而彻底摆脱了摄影来完成任务，全部转移到线上自动完成。

霍夫曼说，你看，Airbnb在将房屋拍摄管理彻底自动化的前，用了三种不同的方法，对Airbnb来说，一开始就没有全功能自动的拍摄管理系统，根本没有任何意义吗，因为最开始时工师一共才10到左右。你看看，唯一的工程师就是原创人内森。而他们当时的做法，虽然是临时的权宜之计，但不能说，他们在资源有限的情下，也实现了快速发展。

就像霍夫曼说的那样，暴力破解也许比个设计优雅的解决方案还要好，因为前者只要花百分之十的时间，哪怕最后这个方法被抛弃了，对企业家来说，也是划算的。

# I 关注当下，放弃完美

霍夫曼认为，为了实现闪电式扩张，要遵守的第三条原则就是只关注当下，放下长远构想。
