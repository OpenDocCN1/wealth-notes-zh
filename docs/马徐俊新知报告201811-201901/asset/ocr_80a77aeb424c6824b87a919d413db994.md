# 今日报告：停战百年后，西方媒体如何回顾一战？

在很多历史学家的眼里，第一次世界大战，只不过是欧洲各国处理彼此矛盾的一个开始。直到1989年德国再次统一的时候，欧洲的国内核心矛盾才真正得到解决。

> ——《周刊报道》

马俊骏

今天的“双十一”，恰好是第一次世界大战停战一百年的纪念日。在这个时间节点上，西方媒体不约而同地对一战做出了回顾和反思。《纽约时报》《周刊报道》认为，一战和二战根本就是同一场战争的上半部分。

今天的双分为两个部分：

荒唐的“停战日”

为什么说二战在所难免？

11月11日是咱们中国人的购物狂欢节，但在西方世界，“双十一”有着完全不同的意义，它是第一次世界大战的停战日。

这一天，如果你走在英国街头，会看到很多人挽着手臂，到纪念一战死者墓园，人们用这种方式，表达着对先烈的哀悼。

今年的“双十一”，在西方是件大事，因为第一次世界大战确定的停战时间，是1918年11月11日上午11点，到今年，正好整整是一百年。很多西方主流媒体，包括《卫报》《纽约时报》《周刊报道》《组约邮》等在内，都发表了相关文章对一战进行回顾和反思。

我在梳理了一批西方主流媒体的报道之后，在《纽约客》和《周刊报道》里，找到了两处鲜明的观点。带我们从一个新的视角来重新回顾一战。

比如，我们通常认为，第一次世界大战停战，是因为交战国的伤亡都很惨重，导致双方对战争都感到厌倦，才叫停了战争。而乌克兰、乌克兰都战胜国，又有处理好跟战胜国、也就是德国之间的关系。像是《凡尔赛条约》的规范太过苛刻，要求德国付出的战争赔偿数额也太过庞大，这些原因才导致了20年后第二次世界大战的爆发。

但《纽约客》提出了不一样的观点，它认为，其实上个世纪的两次世界大战，根本就同一场战争的上半和下半截，一战的停战，只是上战争结束时的喘息，一战结束，德国民众从心态上，也没有做好接受失败的准备。

而按照《周刊报道》的观点，在很多历史学家看来，第一次世界大战，只不过是欧洲各国处理彼此矛盾的一个开始。直到1989年德国再次统一的时候，欧洲的国内核心矛盾才真正得到解决。
