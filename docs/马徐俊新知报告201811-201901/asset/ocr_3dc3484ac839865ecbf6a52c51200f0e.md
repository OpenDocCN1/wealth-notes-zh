# 今日报告：像理解药品一样理解算法

穆晓雅

普通人在潜意识里，对“算法”二字有抵触心理，原因很简单，因为未知，总是恐怖，这是人之常情。今天我要带给大家的一个方法论，可能会帮助你消除对算法的恐惧。

今天的议题分为三个部分：

为什么说理解算法就像理解药品？

好的算法、坏的算法和危险的算法

应该如何正确对待算法？

如今“算法”这个词，我们生活中的出现频率越来越高。但是，很多人并不知这个，这个充满了科技感和未来感的概念，究竟意味着什么。

尤瓦尔·赫拉利在《未来简史》里过一种惊人的可能性，就是算法成我们的先知，成代理人，而最终成为我们的君主，我们什么都看不到算法，其实从这里个质意义上也能看到，算法的民意，对算法本有抵触心理，原因很简单，面于未知，总是恐怖的，这是人之常情。

今天我来给你一个帮助你理解算法的方法，它来源于伦敦大学学院的原学家，刘韵萌女士今年9月出的一本新书（Hello  算法），弗雷因究，这个里，弗雷因究究未来和人类之间关系，在这本书里，弗雷因究告诉我们是，究竟应该如何理解算法，在未来又应当是如何相处？

弗雷因究，尤瓦尔·赫拉利说过，那种算法统治世界的未来，并不能出现，因为算法的实质是规则方药是利一样的，只要正确的理解，它一定是有大的，只要让我们算法变得透彻、可监督。这句话我也选了今天的金句：

```
We need to make algorithms transparent, regulated.
```

《纳福蝶》的作者迈克尔·尼格尔亲自来了弗雷，专门为此写了一篇序文，到今天我们就看看弗雷因究是如何理解对算法的理解，以及她所描绘的未来之中，人和算法是如何共处的。

| 为什么说理解算法就像理解药品？

弗雷因究，我们之所以对算法产生恐惧，是因为对算法的解知出了偏差，大多影响我们的大学和小学把算法描绘得无所不能，但实际情况是它可能无法全成，因为算法就是程序嘛，程序是人写的，人作为创造者都不是完美的，怎么可能会无所不能呢？弗雷因究有一个很有意思的类比，把算法比作了处方药。

弗雷因究，算法这东西，是人为服务的，本质上药品是有规则的。在现代科学中，把药物系统没有区分。科学中的药，药是不监督的，可以拿一个例子，里面装些有毒有害的液体，你说可以治病也好，有益健康也好，只要有人信了，就可以卖钱赚钱了。这种情形显然不会持不下，保障药品的安全性，确保药品的有效，是人类保证自身利益最大化的理性选择，在美国是食品药品监督管理局，也就是FDA这样的机构监督。
