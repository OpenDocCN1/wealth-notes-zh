# | 《连线》杂志为什么力推生物检测技术？

为庆祝创刊25周年，《连线》杂志办了一个很特别的庆祝活动，邀请25位来自各行各业的创新者像彼得·蒂尔、比尔·盖茨、马斯克、乔·比森斯、史蒂·萨克斯、英格瓦·坎普、埃利·冯·贝尔哈根等，让他们评测能改变世界的10项技术。其中，比尔·盖茨和谷格的CEO桑达尔·皮查伊，分别把票投给了血液检测技术和视网膜检测技术，这两门技术都属于生物检测技术的范畴。

当然，其他人投的票也很有意思，比如贝克、霍金也投了一票。对，你没看错，就是一张钟，这个钟叫万年钟，据说可以运行1万年；还有彼得·蒂尔，投票说未来主要用VR技术。

咱们再回到比尔·盖茨和皮查伊，他们之所以把票投给了两门生物检测技术，是因为他们，生物检测技术可以给人们提供了成本价、精确度等健康手段入门，让人类能够随时判断自己的身体状况，及时发现和治疗疾病，对于提升全人类的总体健康水平来说，非常有用。

我在这儿为你解释一下《连线》杂志这张榜单是怎么选出来的，你就会明白它的含金量有多高。

《连线》杂志的编辑们先是根据自己多年来的采访、报道和记录，结合科技领域里人物的权威和影响力，选出了一张名单。把过去25年里，编辑们认为对全球科技及影响最大的25位人，这25人，杂志对这25人进行了专访，或者去邀请他们为未来25年，写文章来，让他们讨论在接下来25年里，会改变世界的人和项目。

你看，有意见的是，《连线》周刊在科技界的影响力。《连线》在科技领域里，把25位大人物叫过来做了一张圆形形，还在旁边加了一条注记——这张图可以理解为是硅谷的一些“大佬”。

# | 血液检测技术的最新趋势

刚才咱们说过，《连线》杂志推的生物检测技术包含了两大方向，一个是血液检测，一个是视网膜检测。

在血液检测方面，比尔·盖茨提名的生物医学学家史蒂芬·丘克（Stephen Quake），他是斯坦福大学的生物医学学家。丘克带领团队发明了一项血液检测技术，这项技术目前主要的应用，是用来检测婴儿的生育日期。这个技术在今年6月份在《科学》杂志上发表的，当时《纽约时报》《科学美国人》这些科学界的权威媒体都纷纷做过报道。

那么这个技术到底厉害在哪里？咱们不妨设想一个场景，电视频里总能听到这样的桥段，一个女产女士产前产期无法确定，导致整个家庭都乱成一团，大家手忙脚乱地去医院，你知不知道，医生看到这种情况不会做好准备？

答案是，目前的技术还真做不到。

咱们从世界范围来谈说现实的早产儿情况，根据WHO在发布的《早产儿全球报告》，全世界每年有1500万早产儿出生，咱们中国每年有200多万早产儿，排名全球第二。

你可能听说过早产儿身体素质会有“足月儿”的孩子，的确如此，但你的最大误解，早产儿是全球五大婴儿死亡的主要原因。研究发现，早产儿在婴儿出生时若存活下来，在发育的过程中，因为身体很脆弱，也容易患各种疾病，导致夭折。

更糟的是，2/3的早产根本毫无征兆，医生也找不到确切的原因，你可能会问，有没有办法通过检测来预测孩子是否会早产呢？一般来说，现有的方法只对某些高有孕产风险人群，比如有过早产经历的女性，但即使如此，判断是否早产的准确率也只有在20%左右。
