147报告 为什么年轻人越来越没有创业激情？

# 今日报告：为什么年轻人越来越没有创业激情？

缺乏个人储蓄，来自海外的竞争和对现有平台的过度依赖，让千禧一代的创业之路越走越窄。

> ——《大西洋月刊》

马晓骏

虽然洋河出过不少创业明星，但是《大西洋月刊》却说：千禧一代可能是最没有创业精神的一代，为什么这么说？

今天的议题分为三个部分：

+   * 为什么说千禧一代没有创业激情？
* 经济压力如何困扰千禧一代？
* 阻碍千禧一代创业的“外患”

英文里有个词叫Millennials，翻译过来叫做“千禧一代”，它是指出生在1982年到2000年之间的年轻人。千禧一代出生在全球多如牛毛，比如Facebook的马克·扎克伯格、Snapchat的发文·施皮格尔 (Evan Spiegel)、咱们中国高潮起的创办人程维，都是其中的杰出代表。不管是民众还是媒体，都从这些明星领袖的身上，看到了千禧一代的雄心壮志和创业精神。

其实很好理解——千禧一代进入人生的黄金时段，受教育水平极高，有经验，有体力，可以说是万事具备，只欠“创业”，所以非常理所当然会觉得，年轻的创业者会越来越多。

但《大西洋月刊》最近却发表了一篇文章，提出了跟我们直觉相违背的观点，就是千禧一代的创业激情正在萎缩。它的标题就叫《创业不酷了》（Start-Ups Aren’t Cool Anymore）。

作者史蒂芬·哈里森（Stephen Harrison），现在为电脑和互联网新闻、杂志《连线》 (Wired) 供稿。在这篇文章中，哈里森提出，虽然千禧一代的受教育水平高，但并不像老一辈认为的那样有创业激情。美国某研究机构Totalist的联合创始人，美某某机构 (John Terlist) 的负责人说：“千禧一代即将成为近代史上最有创业激情的一代”。

那么，千禧一代的创业活力到底有多低迷？背后的原因又是什么呢？

# 1 为什么说千禧一代没有创业激情？

不同专业机构调查研究，在千禧一代对创业的态度方面，都有一个一致的发现，就是千禧一代高度肯定创业的回报，真正不敢去创业的年轻人，是少之又少。

四大国际会计师事务所之一——安永曾经和美国智库机构“经济创新集团” (Economic Innovation Group) 共同做了一项研究调查，这项研究调查覆盖全美，调查对象就是千禧一代，调查内容是他们的一些数据，记录的是你的回答在统计中占比，这些数据都是经济相关的问题，比如你对创业的态度，是否曾创业，政府对企业的态度等。

![](bbox=[0.2, 0.0015, 0.8, 0.0018])

调查发现，72%的千禧一代对创业高度肯定，这说明好的、既能推动经济发展的创新，又能提供新的工作岗位。78%的人都认为，创业是人类社会的标志。

但问题来了，当问到他们自己会创业的话，只有22%的千禧一代说，会创建自己的公司。比起他们自己创业，更多的人（大约70%）说，他们更愿意在一个已经存在的公司里，慢慢往上爬更容易成功。

今天的这篇文章的作者哈里森自己就在读MBA，对此他深有体会。他说，班上提问，大家讨论的都是创业，做机构，做投资，比如说创立一个有定时发送通知的消息应用，或者一个类似软件分发平台的想法。但过了一段时间，哈里森就会发现，大家还是想当然而已，没人想要落实。

其实大家很关心千禧一代多少，并不是第一次被记录在案。《华尔街日报》曾经分析过美联储发布的数据，他们发现，30岁以下的创业者比例一直在下降，已经下降到近25年的最低水平。

那么问题在哪呢，从总体环境上来看，世界更加平等，科技发展越来越快，尤其是我们受到的教育水平，越来越高。这就是美国学者说：千禧一代是有史以来教育程度最高的一代人。

所以人们会问：日子越来越好了，怎么会反而想出离窝的鸟却少了吗？

# 2 经济压力如何困扰千禧一代？

文章分析，这背后有三个原因：经济压力过大，激烈的海外竞争，和对现有平台的过度依赖。我们先来讲讲这个最重要的原因——经济压力。

美联储的经济学研究发现，在当前的经济状况下，千禧一代并非不像人们普遍认为的那样，更多的是机会积累财富，在相对方面非常焦虑，这就导致了千禧一代压根不敢，也没底气创业。

咱们刚才说过，千禧一代是美国历史上受教育程度最高的。我觉得是这个情况和中国差不多。但不同的是，中国有国家买单，无非是学例子，耶鲁大学法学院，2017-2018学年，一年的费用加杂费就要82602美金，将近60万人民币。

你可能说这不是名校，名校的学费当然更高。其实，就算是普通的大学，一年的费用也要在3万美金左右，这对于多数美国家庭来说负担是巨大的，所以很多人靠借贷才能支付起学费。

毕业以后，急于一份收入高，稳定的工作偿还债务，根本不敢创业。

他们有梦想呢？《大西洋月刊》最近还写过另外一篇文章，标题叫“是不是千禧一代累了？”，也是说经济拖垮了千禧一代，文章中就引用了美国智库，皮尤研究中心的调查数据，说千禧一代和前代相比，购买的房子和汽车的数目都要少。

在2016年，35岁左右的美国人，只有大概34%的人有房。他们的前几代，比如35岁以下的人，一半的人都有房。

车也是一样，美联储经济学家发现，购买新的车的平均年龄，已经上升到53岁以上。老年人买新车多，年轻人买新车少。

文章还提到，买房买车是为了自己的生活方式，当然不是，是他们的买不起。

没房没车也就罢了，个人储蓄都很少。安永曾经发表过报告，在报告中给出这样一个数据：在千禧一代中，如果生活里出现非急的情况，急用现金，63%的人连500美金都拿出来。

听到这儿，你就明白为什么不愿意创业了。最普通的创业活动，创业需要资金，要么是自有资金，要么是从家人那里借钱，但个人储蓄很少。

还有一招，是找风投。但是在美国，想投你的基金很难。

《硅谷周刊》有一篇文章，标题叫“硅谷创新不孤单”，说的是在中国，硅谷创业者们去寻求投资，在美国，创业者们去寻求投资。

简单来说，在美国的创业者们，想要找钱，得先跟最富有的大佬搞好关系，然后大佬投个100万美金，作为启动资金。

如果你想找更多的投资，就得找风险投资公司（VC），VC会帮你做尽调，估值，再投几千万美金。

但如果你没有一个可信赖的创始人，也没有靠谱的项目，没有人会投你。

那经济压力这个因素可算算是“内忧”，那么，阻碍千禧一代创业的“外患”又是什么呢？

# 3 阻碍千禧一代创业的“外患”

阻碍千禧一代创业的“外患”，是越来越激烈的海外竞争和对现有平台的过度依赖。

文章中说，最主要的是，中国投资方向变了。10年前，中国资本愿意帮助中国企业，美国企业通过收购能顺利掌握这些数据。而现在，大多数中国资本，都把技术带到第三方。

根据《华尔街日报》，在2017年全球前五大风险交易中，有三家都是中国企业，分别是滴滴出行、美团、百度。
