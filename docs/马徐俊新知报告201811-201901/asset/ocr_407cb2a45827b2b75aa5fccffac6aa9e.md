# 128报告 | 为什么年轻一代的性生活越来越少？

人类作为一种社群需要性，但作为个体，未必需要。

# 一 《大西洋月刊》

马修·赖恩

跟几十年前相比，如今的年轻人，似乎变得对性生活越来越不感兴趣，这是为什么呢？

今天的议题分为三个部分：

+   - 年轻人对性生活失去兴趣是一种世界趋势
- 为什么社交软件没有提升交友效率？
- 为什么年轻人对性生活越来越不感兴趣？

# 12月《大西洋月刊》的封面文章提出了一个非常反直觉的结论，就是如今年轻人性生活的频率，跟之前的几代人相比，正在变得越来越少。

听到这个结论，可能你的第一反应跟我一样，有点难以置信，因为在这样一个物质极大丰富的年代，我们获取各种资源的成本正在变低变低再变低，无论是食物、交通、公共服务、当然也包括性资源，何况互联网和移动互联网有史以来地让两个陌生人都变得更容易有方式去了解，网络交友和通讯社交变得越来越方便，青年一代性生活的水准怎么反而低了呢？

但数据明明明白地显示了，欧美青少年和性交友的人群，从1995年降低了14个百分比，为此各行各业专家都提出了自己的解释，比如经济压力大、网络游戏、毒品泛滥等，智能手机和AI等等，而为了回答这个问题，《大西洋月刊》用了极大的篇幅，列出了三个导致年轻人性生活变少的重要原因，分别是娱乐性代替方式变多了，面对面的相处时间变少了，以及更多人有说No的权利和勇气。

文章里有一句话我是这么说的：人类作为一个种群需要性，但作为个体，未必需要。

这句话，也造就了今天的金句：

> The human race needs sex, but individual humans don't.

# | 年轻人对性的兴趣减少是一种世界趋势

《大西洋月刊》的文章里一上来就说，现在性生活次数的下降是一个大趋势，根据美国宾夕法尼亚州罗文大的心理学院资深研究员史蒂文迪斯盖尔，1990年的2014年，成年男人每年性生活的次数从62次下降到了54次，而且还在持续下降，文章里说，我们以为别人的性生活次数很多，但其实原因根本不是我想的那样。

但相比总体趋势而言，年轻人的性生活次数下降的特别显著。比如根据美国疾病控制中心的统计数据显示，从1997年到2017年的20年里，美国中学生有过性经历的比例，从原来的54%下降到了40%，也就是说，高中生，原来是大部分人也尝试过性行为，如今变成了只有小部分人体验过。如今2015年的年轻人，比如整整数了1/3，如今20-18岁的年轻人跟之前的几代人相比，禁欲的人数多出了2.5倍。

美国的《国家取向和生活方式调查报告》显示，2001年的时候，16-44岁的英国人每个月性生活的次数为6次，但到了2012年，已经降至5次了，与此同时，澳大利亚的数据统计显示，他们国家的这个数据，从每周1.8性生活动，下降到每周1.4次。荷兰年轻人初次性行为的年龄从2012年的17.1上升到了2017年的18.6岁，我们一直听到出生率低的日本了，2015年的调查显示，18-34岁的日本年轻人有43%从来没有过性经验，甚至已经过了4成的年轻人，有47%的夫妻，每月的性生活频率不到1次。

所以不难发现，《大西洋月刊》没有是在瞎说，年轻人的性生活频次的确在降低，是一个不争的事实。但这的确非常疑惑，因为网络的普及后，应该让社交和交友变得更容易了，像各种社交软件，甚至专门让陌生人认识的有Tinder，比如Tinder，这个软件出现于我们中国的探探，这种软件的出现难道没有让更多年轻人轻松的交友，降低性资源的获取成本吗？答案是，真的没有，这是为什么呢？

# | 为什么社交软件没有提升交友效率？

文章里给了一个特别好的看法，现在社交软件中丰富给我们造成了一种错觉，让交友变得越来越容易了，但其实只是给了我们更多的选择，却并没有提升交友的效率。文章里举了一个叫Simson的男人作例子，他32岁，离异，条件属于中低水平，他使用Tinder这样的软件，平均对30个女性产生兴趣，才有一次配对成功也会感到很欣慰，也就是匹配概率是3.3%，而在匹配对象里，每10个人中会有一个跟他约会的，也都是在社交媒体上看到一个女性约会上的概率是1/300，这其实是人口普查说的，而这个概率，根据Tinder公司公布的数据，2014年，用户平均使用时长是每天1.5小时，现在用户的使用时长更长了，但只有平均1.6%的配对频率，这么看来，Simson的数据算是很高的。

而且在社交软件上，头部效应特别明显，就是那些现实生活中长得最漂亮，身材很好的那群人，在社交软件里是最受欢迎的，而现实生活中不怎么引人瞩目的，在社交软件上也是毫无反应，现在虽然很多人使用各种各样的app社交，但目的仅仅是打发时间而已，并不是真想给对方建立亲密关系。加上现在网络依赖性情感运的潮流，导致人们在线下里很难谈成恋爱，根据《经济学人》杂志2017年底的调查，19-59岁的美国青年人中，有19%的人，一个人独自邀请一个人去“喝一杯”，那么女性性骚扰和性暴力被多年轻。这难道不都很合理吗，很多人常年怕麻烦，宁愿宅在家里也不愿意出去跟人约会，以前看剧那那样男女在酒吧看个电影，以前的男女的那种故事桥段，在现实生活中发生的越来越少了。

所以虽然网络的普及越来越高端，却并没有提升年轻人交友的效率，更别提增加性生活的次数了。

那么到底是什么原因，导致了年青一代，对性生活越来越不感兴趣呢？

# | 为什么年轻人对性生活越来越不感兴趣？

《大西洋月刊》在进行了大量的采访和研究之后，发现，娱乐和替代方式变多了，面对面的相处时间变少了，以及更多人有说No的权利和勇气，是倒至年轻人性生活次数下降的主要原因。

首先是娱乐和替代方式变多了，由于现在的网上影视太多，无论是游戏还是网络上的影视剧播放，让大多数人不会选择网络持续的娱乐和消遣，另外色情网站的盛行和性玩具的流行，也可以解决生理需求，比如2014年的调查数据显示，43%的美国男性在过去的一周里有看过网上的色情视频，而性玩具在女性的中流行程度超过10年前，光现在市面上还可以买到性玩具品牌就超过2万种，如果不是需求量很大，是不会这么多可选择的商品种类出现的，所以说，显然，年轻人的性生活次数下降，但人们追求欢乐的本质没有变，只是换了种方式，比如大本两个男人，一个人可以主动的性满足，是很多人如今会选择的方式。

其次是，现在年轻人自由的时间空间变少了，由于中产阶级家庭对子女的教育问题越来越重，导致年轻人的反抗越来越重，比如高中的课外时间都用来参加社团活动、社会工作、打工兼职、现在年轻人的生活，从早上一睁眼刷到临睡前，可能是被紧张安排的满当当，根本没有什么多余的时间来培养异性相处，但进入大学之后，面对毕业激烈的工作压力和巨大，很多要想办法的恋人表示说因为巨大的时间安排的。跟过去相对悠闲的自由时间相比，现在的年轻人有不少少了很多获得性接触的机会，甚至连面对面的社交能力都开始退化了。

最后一个原因，根据文章的调查，是因为现在的年轻人对自己的生活，有了更多的自主权，可以对自己的不喜欢的事情说不。比如年轻人家人还没有“搞对象好”这种思想概念，可能一方不想从事家务，但想另一方面，现在可以以勇敢的说不，拒绝家务。女权运动的兴起，也让更多的女性有自我意识觉醒，不再去争取更多的社会和经济平等，也要求女性在权利上有更多的自主权，这也导致了年轻人的性生活方式改变。
