今日报告：为什么说海尔重新发明了管理？

企业界一直在努力探索，如何将从官场的经验中解放出来，而海尔通过具有强大激励作用的商业模式，最终找到了。

—《哈佛商业评论》

马徐骏

《哈佛商业评论》的封面文章，为了海尔最新发明了一套管理体系，解决大企业的两个顽疾——官僚化，而解决官僚问题的核心，归根结底，就是解决分利的问题。

那么，海尔是如何重新发明管理的呢？这也是我们今天这个议题的三个主要部分：

《哈佛商业评论》最新一期的封面文章，罕见地聚焦了中国老牌家电厂商海尔，原因是，它为海尔解决了一个困扰大企业的难题——官僚化。

如果你在大型企业呆过，对官僚化的感受可能会比较深刻。比如说，团队有一个新的提案，要层层审批上报，要等总部领导的指示之后才能行动，这个过程往往耗时很久，等下来，市场先机可能早就没了。这就是企业官僚化带来的“官本位”问题。

美国的投资大师查理·芒格把它称作一种观点认为，官僚化是企业发展的必然结果，但《哈佛商业评论》却认为，中国企业海尔打破了这个迷思，找到了官僚化这个问题的解药。

海尔的这味解药，叫做“小微模式”，英文叫microenterprise。

什么叫“小微”？简单来说，就是超小型的公司，一般就由十几个人组成。小微在公司内部就大了量的小微”，小微可以直接对接市场来开发产品，也可以为其他小微提供服务支持。它们自给自足，自由协作，形成了一个灵活又统一的生态系统。

《哈佛商业评论》认为，正是“小微模式”激发了海尔的活力，帮助海尔实现了整体的持续增长，稳坐世界第一大家电生产企业。更重要的是，小微模式解决了困扰企业的官僚化问题。正因如此，《哈佛商业评论》给了海尔一个很高的评价，说它“重新发明了”适应数字经济时代的管理模式。

“小微模式”是怎么解决了企业官僚化问题的呢？《哈佛商业评论》将解决方案归纳为三点：第一，仿照互联网的特点改变企业架构；第二，将管理模式人性化；第三，用演化的思维处理企业管理中变化。这三点，我认为也正是小微模式带给我们最有价值的三个启发。接下来，我将带你分别了解这三个启发分别是什么。

# ｜企业架构网络化

你可能会想问：小微有什么特别吗？被誉为“数字时代思想家”的哈佛大名鼎鼎的二道·福伯斯有一句很著名的论述，说互联网的特点是“小块、松散耦合”。

“小块”的意思就是，网络是由小站点或小的节点构成的，这些小节点可以自由地生成连接，并且通过互联网相互连接。

松散耦合，就是大家用着一套通用的技术标准，让数据可以在不同站点之间流通，将网络给静态变成了个体模式。小微也是这样，它也是小块的松散耦合。

这个小块有多大呢？海尔将一个庞大的企业拆分成了4000多个“小微”。其中2000小微主要集中在家电核心业务，还有超过50个小微在全公司内开拓新市场。比如在线游戏。而剩下3800个节点小微，我们类的都是服务于设计、生产、人力资源、法务等当成产品，卖给其他小微。

小微可以自由形成、自由发展。谁有一个好点子，马上就可以在企内部招募队友，成立一个小微。小微之间可以合作。每年，那些直面消费市场的小微都会自己定一个营收目标，然后向自己要达成这样的目标，我需要什么样的设计、技术、要什么样的厂家生产、获得什么样的销售支持等。一旦有了需求，就开始向公司内部的“其他节点小微”招标。通常，每个需求都会有两三个小微带着方案来竞标。

最终，最适合的小微企业中标，双方签订合同。如果企业内部的小微确实满足了需求，它们甚至可以从企业外部寻求第三方服务。

你可能想问，这么多小微，大家不会乱套吗？答案是不。这些小微商虽数量庞大、类型繁多，但它们在目标设定、合约签订和沟通协调方面，使用的是同一套方法和标准。这就像小微形成了一个十分灵活，却又能够有组织的架构。

讲到这，你应该已经明白了，为什么《哈佛商业评论》认为小微模式是模仿了互联网的特点了。它通过小模块的松散组合，把原本官僚化的“金字塔”架构打散了，形成了一个更灵活的生态系统。

# ｜管理模式人性化

《哈佛商业评论》说，近年来大多数企业努力在做的事情是数字化，而海尔做的却是一件更重要的事，就是把它的商业模型、管理模式“人性化”，英文对应的词是humanize，在这里的意思是“激发人的活力”。

那么怎么“人性化”呢？一个核心理念，就是赋予员工“拥有者思维”。我们都知道，创业的人经常会有持有者思维，具体表现就是“事上见”，为了做好事情，甚至会把自己的家也投进去。出了问题，也会主动承担。这种“拥有者思维”，正是创业公司的优势所在。

那怎么能大企业的员工也能有这种心态呢？海尔给了员工两个东西：一个是高度的自主性，一个是强大的分红机制。

高度的自主性这一点，我们刚才已经说了，小微的组织发展是自发形成的，员工们自愿加入、自由分工。小微群体要面对哪个市场，参加哪个发展策略，由哪些人来做，这都是用“自下而上”的方式一起制定的；他们不再是员工，而是小微的共同拥有者。

如果小微团队内部成员之间出现不信任，团队成员会自动淘汰换岗。

那强大的分红机制又是什么呢？我们知道，企业的激励机制一般比较“稳定”，年终奖分红通常也是按年分红10%左右。但海尔的小微企业不一样，它的分红和业绩直接挂钩，而且有三扇门，包括维持目标、中期目标和高目标。

我们看了一下，发现机制相当复杂，咱们就不讲那么细了，总之一个原则，就是业绩越好、拿到的利润越多，奖金、收益和分红就享有。而目标还是层层加码的。这对员工，无疑是直接的经济利益激励。

# ｜持续10年的演化思维

“演化”的思维在小微模式里随处可见。比如，小微的竞争机制是优胜劣汰的；小微的封闭的孤岛是非常强调“迭代”的，对海尔的高层来说，每一类平台评价一个新颖或新点子的好坏，他们的做法，就是放手让小微去尝试，然后通过市场来检验。

最开始的，小微需要由投资合伙人从哪里来的呢？海尔由部分风投资金，合伙人的小微要从他们那里获得第一笔风投。如果产品最成功了，那海尔就会对小微提供内部资金方面的支持。如果小微发展得好，海尔甚至会主动下风风投资伙伴的部分股份，为自己持有。通过这种筛选方式，海尔做到了只把资源给那些最有增长潜力的小微。

《哈佛商业评论》里有一句评论说的很有意思：“它说，创新这件事，说得极其简朴的‘意义’。这—说，海尔都非常明白。想找到下一个数亿美元的商机，唯一的办法就是成成立一个一群新的公司，然后给予公司机会，让它们自由地去尝试。”
