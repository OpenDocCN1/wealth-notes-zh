# # 今日：报告 | 如何用eDNA破解尼斯湖水怪之谜

对eDNA的研究将带来巨大的回报，与之一比，尼斯湖水怪找不到也得到，已经不要紧了。

——（BBC聚焦）

# ## 马修·穆迪

尼斯湖到底有没有水怪？用最新的eDNA技术，可以帮助科学家找到一个确定的答案。

今天的议题分为两个部分：

+   - eDNA如何揭开尼斯湖水怪之谜？
- eDNA还能在哪些领域派上大用场？

尼斯湖水怪的传说我们都知道，已经流行了上千年了。至今，依然有一些死忠粉相信，在苏格兰这片浑浊的湖水深处，栖息着一只像龙一样有着长脖子的巨大生物。当然，对于这种传说，科学家大多是不信的，只是之前他们没办法证明自己的观点。

不过，这个谜团的真相很快就会水落石出了。最新一期（BBC聚焦）报道说，新南威尔士大学可以视为当前探索尼斯湖是否存在水怪的一个项目，以彻底摸清第五湖到底有没有水怪，他的方法非常值得关注，叫eDNA，也就是environmental DNA（环境DNA）。

原来，科学家们发现，动物在某个环境里生活，身上的各种痕迹会携带自身DNA滴洒到四周，所以在整个环境中会形成所谓的环境DNA。在最新的技术中，已经可以让科学家通过检测环境的eDNA，一次性了解湖泊中所有生物的信息状况。如果有水怪，它的DNA一定会被发现。

但是，eDNA这项技术的意义可不仅仅在于找水怪，如果科学家能够掌握它，就意味着，寻找和监测新生物不用再大海捞针了。那么，eDNA未来会用在哪些野生动物保护方面能发挥作用？更厉害的是，它可以像“时空望远镜”一样，帮助科学家了解某个环境里曾经有过哪些生物，这些生物又出现过怎样的演化历史变迁。这项技术，将会是一个非常强大的工具。

# ## eDNA如何揭开尼斯湖水怪之谜？

为什么尼斯湖水怪的传说能流传上千年，至今还有很多人相信呢？最关键的原因是，科学家没有办法证实水怪是否存在的，换句话说，在传说领域上，科学家不存在的办法去“证伪”。而eDNA，让科学家有了一个强大的“证伪”武器。

在此之前，科学家尝试过用科学手段去辨别尼斯湖水怪是否存在，但他们的做法，反而加深了人们对水怪存在的执念。科学家先是做什么呢？他们先是潜潜水员到湖里一探究竟，还使用水下机器人，拍到水怪存在的证据。可是，他们发现尼斯湖水怪太深了，只要深度超过9米，就什么都看不见了。

后来，科学家们又用声呐，对尼斯湖的水下环境做了一个整体扫描，结果没想到eDNA，有到了一个惊人发现：尼斯湖很深，深度达到了226米，可以轻松地下一座摩天大楼，而且地形很复杂，在湖底横亘着一条巨大的深沟。

很多人就想，“哦，那水怪很可能就藏身在深沟里”。

说到这，你就明白了吧？科学家之前的这些方法，表面上看起来都是“没找到”水怪存在的证据。但它们最关键的错误，都是在“证明”。而eDNA技术解决的是什么问题呢？它可以明确地告诉科学家，湖里到底有些什么生物，有没有水怪，自得一目了然。

那么，eDNA究竟是什么？

首先DNA我们都知道，不用多解释了。一个生物体的DNA中，包含着关于它本身的很多信息，而且现有人取DNA的方法非常常难，做，而且检测得到的DNA，只需用棉签在它的口腔上颈来回刮几下，就能获得足够的组织提取出它的DNA来了。

那么，随着这个思路我们就可推测，生物在自然生态环境中，就留下很多包含自己DNA的东西吧？比如一些脱落的皮肤细胞、毛发、尿液和排泄物等等，这都携带着生物的DNA吗？

从上个世纪90年代开始，科学家就开始做这方面的研究了。他们发现，从土壤、地表水、冰和海洋中都可以成功提取出生物留下的DNA信息。于是，科学家们发现了一个环境中，所有被发现的生物DNA的混合，叫做eDNA。这个DNA是生物学的，代着英文environmental，就是环境的意思。一个环境中的eDNA，就相当于它的名片，生活在其间的所有生物的信息，都能从这张名片里找到。

不过，虽然eDNA概念提出得比较早，但它真正发挥作用还是近几年的事情。这主要是依赖DNA测序技术的进步，让检测数据容易、易测和精准。此外，一个东西的完善关系，那就“基因库”。

为什么这么说呢？打个比方，你是警察，要通过指纹找出犯罪嫌疑人，那你必须得先有一个足够的指纹库，把提取出来的指纹和库里存储的指纹进行比对，才能知道这个指纹是真是假，谁是真凶。eDNA？这里的库就是基因库。如果你的基库不完整，或者提取出来的DNA，也不知道它们都归属于哪些生物。

从上个世纪80年代开始，美国、欧洲、日本先后建立了一个基因组数据库，而2016年自启的中国国家基因库，是目前全球最大的基因库，生DNA基本占上十万分之一。有了比较完善的基因库之后，eDNA才能发挥大作用。

怎么着呢？科学家会取环境样本中的eDNA，把里面不同的生物DNA，然后与数据库比对，分析它们所属的物种信息，最终鉴定在这个环境中共有的所有物种，这个方法又被称为“DNA条形码”。

这一次，麦克劳恩自驱动的尼斯湖水怪检测项目，就是使用这种大工具。目前检测正在进行中，但一旦结果出来，尼斯湖水怪到底有没有水怪，将会找到一个确定的答案。

# ## eDNA还能在哪些领域派上大用场？

如果eDNA最后证实尼斯湖中水怪的存在，即使不存在是个小惊喜，也算证实水怪不存在的。这个检测虽然依然有限，因为科学家们为了以全面了解尼斯湖的生物多样性的状况，需要对这片水域的保护和管理，就至关重要了。

而eDNA这项技术更大的意义在于，它让科学家摆脱了肉眼探索的束缚，对于追踪、研究和保护一些非常罕见得濒危野生动植物，它也是一项极有潜力的工具。

就在今年4月，全球最权威的龟类保育组织TGA在官网中宣布，确认全球第四只蟹龟的存在。在澳大利亚龟类可能会灭绝前，它曾在全球濒危的龟龟龟类，有多大濒危呢？此前，被认为全世界仅存了只。而今年，龟龟在越南又发现了第四只，科学家还专门考察了关心。其实，科学家并没有直观见到这只蟹龟，那是怎么证明它存在的呢？就是通过检测eDNA证明的。

同样在今年，在太平洋西南部的新喀里多尼亚群岛，科学家通过eDNA采样，发现了六只从没见过的巨鲈。研究者说，eDNA比传统的人工观测或者自动摄像机拍摄更高效，这就好比“无论你看不到或看到，你都知道，它就在那里”。

不管这些发现，都为人类探索生物多样性提供了新思路和工具，eDNA这个工具，科学家们可以濒危动物制定更有针对性的保护策略。

eDNA还有一项本事是你意想不到的，那就是遗传潜能。eDNA中包含的大多数信息都是活的生物留下的，但是，科学家也已经在其中发现一些，比如动物DNA，属于已经灭绝的或已灭绝物种，如猛犸象和巨齿鲸。这证明如果条件合适的话，eDNA是可以保留上千年之久的，它像一部“时空望远镜”，能帮助科学家了解一个环境中生物演化和变迁的历史。

其实，eDNA不光对科学家有用，它还有广阔得商业用途。对于三文鱼或者海洋商业捕业有重要经济价值，但是水藻、温控环境比较敏感的海藻，用eDNA分析前就可以更准确地了解这些鱼类成分。
