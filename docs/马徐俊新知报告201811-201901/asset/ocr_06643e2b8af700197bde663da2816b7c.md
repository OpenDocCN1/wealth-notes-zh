# ## 人类如何改变了鸡这个物种？

你大概没意识到，我们现在吃到的“鸡”，已经和以前完全不一样了。现代鸡和它的祖先相比，体态发生了巨大的变化，而且完全要依赖人类的饲养才能活下去。这种鸡，是人类改造动物种群的最好证明。

现代肉鸡到底发生了哪些变化呢？首先，它们的生长已经完全依赖工业化的养殖，与外界是完全隔绝的。从出生的那一刻起，鸡舍是人工控制的，小鸡生长在人工控制温度的鸡舍中，长产的鸡则全部被密集地放进养鸡舍里，厂里的工人每天做的唯一的事情，就是不停地给它们喂料。

这种肉鸡，生长速度极快，只要六星期就可以成熟了。但神奇的是，这些鸡却比祖先的祖辈还重，体重，几乎全部在它们的腿部和胸部上，也就是最适合给人类当食物的地方。

一般来讲，工厂在肉鸡生长到5周左右的时候就会将其宰杀。如果把它们的寿命太长，对它们来说反而是一种痛苦。

为什么呢？因为有研究显示，这种肉鸡，如果果能活过中间从第5周到第9周，死亡率会快速增长，这是由于腿部和胸部的肉在迅速增加，体重大了，而腿和骨头的心脏和肺部器官的体积却很小，这些都限制了它们的生理机能，缩短了它们的寿命。就算不宰杀，它们自己也活不长。

以前的鸡，可并不是这个样子。你看人类驯化动物到现在有几万年的历史了，但鸡的形态一直没有发生什么明显的变化。公元前1世纪，人们开始有记录地生产肉量更多的肉鸡，但和它们的野鸡祖先相比，肉鸡相比，差别并不大。而演化成现代肉鸡这样的形态，却只用了一百五十年左右，这一切是怎么发生的呢？说起来，这跟一场比赛有关。

![](bbox=[0.05, 0.64, 0.95, 0.68])

1946年，美国举办了一场比赛，叫“明日之鸡”，英文为Chicken of Tomorrow。这个比赛由一个组织发起的，由美国农业部门主办，算是个国家级的比赛。比赛历时超过两年，主要目的是为了鼓励农民饲养出体型更大、产肉量更高的鸡。

这场“明日之鸡”比赛办得相当成功，而它也成了人类彻底改造鸡这个物种的分水岭。

为什么这么说呢？因为和16世纪培育鸡鸡的时候不同，这次人类进入了工业化的养殖手段。从上世纪50年代开始，人类对产蛋更多的鸡，实行高效的工业化养殖，从而大大增加了鸡的种群生存的特征。鸡身上那些关于大量蛋种的特征，比如说，能够不停地产蛋，快速长肉，而且肉还专门长在对鸡和人的好处，这些性状被加速放大了，只用了几十年，肉鸡就演变成了现在这个样子。

你可以想一想，如果靠自然演化，现代鸡鸡会大规模出现吗？肯定不会，给鸡几万年也没有用吧？因为大尾鸡，给鸡大尾和鸡，这些大尾巴，这些特征在自然环境下，根本活不下来。

但有了人类的现代养殖技术，那就一样了。这些肉鸡从生下来，就处在人类建造的封闭环境，有人喂食，有人喂水，甚至有人喂养抗生素和疫苗。它们根本不需要面对自然的挑战，它们只需要接受人类的挑选。

所以，现代鸡的出现说明了什么？它证明人类为了自己的需求，可以利用现代化的技术，彻底改造一个物种。

在这个过程中，人类用技术手段，战胜了这个物种天然的，让这种个体不但能存活下来，甚至在数量上还能“称霸”地球。人类对自然的影响力，在鸡身上体现得淋漓尽致。
