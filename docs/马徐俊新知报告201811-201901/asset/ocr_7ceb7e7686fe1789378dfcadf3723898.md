# 视网膜检测技术如何为体检“赋能”

下面，我们再来看谷歌CEO皮查伊看好的视网膜检测技术，对这项技术，我们可能还不太熟悉，但它的作用之大，可能会刷新你对健康检查的认知。

在这个领域中，皮查伊提名的 人物是R. Kim，这个人是印度Aravind眼科医院的首席医生。Kim说，在神经学里，视网膜是大脑神经系统的延伸，通过视网膜检测，可以看出你身体的很多信息。

四年前，谷歌就和这家眼科医院共同研发过一个项目，它是一个通过视网膜来检测糖尿病病变的自动检测系统。这个项目结合了谷歌的AI技术，患者提交视网膜照片后，这个系统几秒内就能返回检测结果，把病变情况清楚地汇报给患者。

目前，这家医院的研究人员还在研发通过视网膜来检测慢性病症的技术，包括帕金森综合症、阿尔茨海默症等等，希望帮助人们及时检测、提早预防。对于视网膜检测技术 的未来，Kim是这样描绘的：未来在机场、车站，只要没个硬币，就可以做一次视网膜检查，只要几秒钟，检测系统就会告诉你，你的身体出了哪些问题。

从这个未来图景中，你就能感觉到，视网膜检测技术能让每个普通人；以几乎最低的时间和经济成本，来更清楚地了解自己的健康状况，提早预防各种慢性疾病。

以前，你可能在电影里看过那些超级富豪是怎么检查身体的，他们只需要抽一滴血，或者朝配备尖端技术的仪器照一下眼睛，就能得到一份详细的体检报告。也许在不久的将来，你在家 人或朋友去做检产，听到的信息就不是几月份生，而是具体到精确的日期，得知这个日子时，孕检就能在医院里提早准备好，从从容容的迎接新生生命呢。又或许，你在等飞机或火车的功夫，花几块钱就可以做一个精准的身体检测了。

而在现实生活中，像这样低成本、高精度的 健康检测技术，已经在路上了。它们的出现，不但让普通人得以享受更便利的健康检测服务，还能挽救许多人的生命。不夸张地说，这两项技术给人类的生命健康，带来了非常平等的福祉。
