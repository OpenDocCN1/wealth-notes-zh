# 今日报告：过度自律如何损害身心健康

我们应该记住，自控力只是一种工具，学会什么时候不使用它，才是更明智的选择。

——《新科学家》

（编者按：自律能力越强越好，但《新科学家》杂志的封面报道，将让你重新审视自律的边界所在的问题。）

今天的议题分为三个部分：

+   过度自律降低幸福感
过度自律引发的健康问题
如何调节自律的分寸？

如果问，**世界上最想控制又最难控制的人是谁？** 其中一定有一个是你自己。

我们都希望对自己有更强的掌控力，每个人年初列的wishlist，里面的目标、几乎都与自律相关，比如要坚持锻炼、不吃垃圾食品、要早起早起、定下计划就去执行、不要拖延。

自律，对我们，似乎也像一个magic pill（神奇药丸），似乎可以帮助我们实现人生绝大多数目标。

从心理学上来说，自律还有很多名字，比如说自控、自制，还有咱们平时说的延迟满足感、控制不必要的情绪、抵抗外界干扰与诱惑、在困难面前不退缩，这些都是自律的表现。

这些表现，是不是听起来特别棒？我们通常会觉得，自律能力越高越好，再多也不过过。但最新一期《新科学家》的封面文章却提出不同的观点——更多的自律帮助你实现目标，对生活有更多掌控，但如果太过自律，反而会损害你的身心健康，比如降低你的幸福感，让你更容易患的疾病。

这个观点从文章标题中就能看出来了，叫《放轻松》（Loosen Up），作者大卫·罗伯森是一名科学作家。

他在文章中引用了以色列心理学家利亚德发表再《心理科学最新新研究》上的研究论文，《心理科学最新新研究》是美国科学协会APS旗下的期刊，而APS是美国心理和心境学机构，咱们的读者老科普就曾在专栏里详细讲过这个机构有多厉害。

简单说来，APS是科学化程度最高的一个心理学家组织，能发表在他旗下期刊上的文章，都是经过心理学行业认可或认可的，被认为能够推动心理学发展的论文。

你明白APS的权威性，也就明白了今天要讲的这篇文章的分量了。

# 1 过度自律会降低幸福感

利亚德认为，过度自律会从三个方面影响你的幸福感。

首先，当你取得成绩时，过度自律会让你错过人生的喜悦时刻。

纽约州立大学奥尔巴尼分校的学者马克·穆拉文（Mark Muraven）就曾经做过相关研究，他发现，自律水平比较高的志愿者，他们会无缘无故压抑强烈的情绪。当这类人取得好成绩，本来要欢呼雀跃，或者和别人开一庆时，他们的处理情感或者是会让他们错过那些本该为自己骄傲自豪的时刻。

其次，过度自律会让你对身边的人不满。

这是怎么回事儿呢？文中也说了，一个人自律程度越高，那么从角度来说，这样的人会遵循更严组织的纪律，会更认真严格的完成安排自己的工作。这也是我们平时说的“靠谱”。

你可能说这不是挺好的么？问题也在于，人们会习惯这种靠谱，并把这种靠谱当做理所当然，而忽略了靠谱的人是背后默默做下了多少牺牲，花费了多少时间来完成的任务。文章里说，这种现象不是特例，而是人类的相关共性。英国圣公会大学就曾经做过一个相关实验。研究者召集志愿者来做一个测试，在这个测试中，志愿者会阅读几段描述不同的文字，然后志愿者根据这些描述来给这些人排工作，并且评估他们为了完成任务需要付出的努力。
