# 今日报告：香蕉生存史：人类和病菌的演化比赛

在这场演化比赛中，病菌和人类都在竭尽全力地奔跑。

> ——《鹦鹉酱》

马徐俊

香蕉是我们最熟悉的水果，你可能不知道，它经历过两次生死存亡的大考验，才活到了今天。香蕉的故事让我们看到一个缺乏多样性的物种，将会变得多么脆弱。

今天的议题分为三个部分：

+   为什么香蕉对病菌毫无抵抗力？  
人类与香蕉病菌的第一次交手  
现代科技与香蕉病菌的世纪大战

香蕉是全世界消耗量最大的水果，全球平均每人每年要吃掉大约30千克。但你可能不知道，物质价廉的香蕉，曾经两次因为病菌的袭击而濒临灭绝，最后人类只能通过现代的生物技术，培育出更强的品种，才让香蕉生存了下来。

可以说，香蕉的生存史，就是人类种植技术与病菌进化的一场世纪大较量。《鹦鹉酱》最近发表了一篇文章，就专门讲这个故事，文章标题叫《香蕉到底怎么了？》（*Whats Wrong with Bananas*），作者是加州大学河森分校著名基因学教授唐诺·艾尔诗丹（Norman C. Ellstrand）。

艾尔诗丹教授在文中总结说，在这场共同演化 co-evolutionary 的比赛中，病菌和人类都在竭尽全力地奔跑。

> In this co-evolutionary race, both the disease organism and human are running as fast as they can.

这句话也被我选为今天的金句。

今天，我们就来聊聊香蕉经历的两次惊心动魄的香蕉保卫战。

# I 为什么香蕉对病菌毫无抵抗力？

其实，香蕉并不是自然形成的水果。它和橙子、柠檬一样，是人类通过对人工杂交获得的新品种，这种杂交果往往比野生水果更大、更甜，更好吃，但它们和种子一样，不具备生育能力。那要想繁衍后代怎么办？从同一批切头上剪下来的小芽继续种。

也就是说，只要人工杂交的香蕉，不管你是哪个城市、哪个店铺买到的，这些香蕉的基因都是一模一样的。

这就有好处也有坏处。好处是，有了同样的气候、同样的土壤、只要控制好外部生长环境，就可以获得稳定的果实品质。所有香蕉的外观、口感和生长期也几乎一模一样，种植者可以进行统一的采摘、包装和运输。

坏处是，一旦某种致命的病菌盯上了所有香蕉的基因一模一样，它们很难产生任何有效的抗性来抵抗袭击，最终只能全部感染，全军覆没。也是由于这一原因，杂交出来的香蕉曾两次濒临灭绝。

它们主要经历过两次关于生死的存亡大战。

# II 人类和香蕉病菌的第一次交手

第一次生存大战和一种叫做黄叶病病菌有关。在19世纪前，人们通过对照野生香蕉品系杂交，获得了香蕉，大家管这种杂交香蕉叫“大麦克香蕉”（Gros Michel），这种香蕉于1885年被发现后在全球大卖。美国的公司引入了美国，成为进口到美国的主要香蕉。

但好景不长，在20世纪初，大麦克香蕉感染了黄叶病，叫黄叶1号。这种病菌潜伏在土壤里，对大麦克香蕉的根系发出猛烈攻击。更糟糕的是，感染了黄叶1号的香蕉大麦克香蕉，不仅无法传染给其他香蕉，它的叶子会迅速枯黄，再也无法为果实提供营养，随后，成熟的香蕉因为日晒过熟而变黑。

更讨厌的是，这种病菌传染能力极强。它不但能在空中传播，通过昆虫传播，还能通过土壤在车里。黄叶病菌孢子在地面中能够活上几十年，这意味着感染了这种病菌的土地，几十年内不能再种香蕉。黄叶1号在20世纪50年代迅速爆发，很快被扩散到了除亚洲以外的所有香蕉种植园。在短短10年的时间里，大麦克香蕉几乎从地球上消失了。当时在哥伦布有一次歌谣流行一时，名字叫《没了！我们没香蕉了！》（*Yes! We Had No Bananas*），说的就是大麦克香蕉在美国宣告灭亡。之后，大麦克香蕉彻底在美国和非洲绝迹，只有泰国仍在种植。

当时，黄叶1号的危机来得太突然，又没有丝毫准备。怎么办？急得赶紧找出一个能可以替代大麦克，而且又能抵抗黄叶病的香蕉来。万幸的是，人类当年除了培育香蕉，还培育了很多其他的杂交品种。华蕉就是其中一个。

它起源于越南和中国，后来被传到英国，被威廉·卡文迪什（William Cavendish）公爵引进，种在他的庄园萨沃伊庄园里，作为招待贵客的红色水果。由此英国人命名为*Cavendish Bananas*，中文简称华蕉。这个身怀绝技的小因子因为黄叶病的爆发被打碎了。

人们急需寻找大麦克香蕉替代品的时候，华蕉在众多的中脱颖而出。虽然华蕉在口感上远远不如大麦克香蕉浓郁，但是它的优点是，它能抵御大麦克香蕉所染过的那些黄叶1号，而且可以在被这种病菌袭击的土壤中种植。这就让很多被污染过的土地重新焕发了生机。于是华蕉成了新宠，在20世纪60年代开始大规模种植。1939年，美国都乐食品公司在加勒比斯种香蕉，随后在1947年正式将出口替换为华蕉。

由此我们可以看到，在第一次人类与黄叶病的交手中，多亏了人类多年来一直在培育不同品种的香蕉，这才化解了危机。

在这一次危机之后，华蕉走上了一统霸主地位的霸主之路。这种局面，延续了很多年，人们也做梦都不会想到，在20年里，黄叶病的病菌正在分秒地进化。

它就像小强一样，杀虫剂用得好越强，它变得越强。到了20世纪60年代，有人发现台湾的香蕉园遭感染。香蕉接连倒伏，人们却一直没找到原因。后来，植物学家对采集到的真菌样本研究分析后，才确诊它是黄叶病。

可这个消息就像滚进大海的一颗石子，并没有引起太多人注意。20年后，黄叶病菌一役，从台湾一路向外的扩散，蔓延到巴基斯坦、老挝和婆罗洲，甚至漂洋过海到达澳洲南部。直到那时，整个香蕉产业才从梦中惊醒。

但这次，人们面对的不只是黄叶病1号，而是变异、更强硬的黄叶4号。4号病菌不光能感染大麦克香蕉和一些种植范围很小的本地香蕉，连华蕉都难逃免。

这个病菌给世界下了个难解的外号——香蕉瘟疫。今天，除了非洲西部和拉丁美洲没有被它占领的地方，除了人工隔离以外，没有什么好办法对付它。

在国际贸易如此发达的今天，黄叶4号在全球蔓延如日方升。更糟糕的是，在2010年，人们发现印度的华蕉感染了黄叶4号，本不能免疫的华蕉，又一次不得不从梦中惊醒。

在第二次香蕉保卫战之中，人类的应对要从容得多。
