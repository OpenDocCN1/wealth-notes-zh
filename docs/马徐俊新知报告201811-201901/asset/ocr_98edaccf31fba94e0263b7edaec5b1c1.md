# 今日报告：人工智能为什么学不会“常识”？

我们需要想办法让AI掌握常识，因为它们需要依靠常识来展开推理，理解这个世界。

> ——《连线》

强大的 人工智能，遇到了最初级的难题——它们竟然学不会常识，这是为什么？

今天的内容分为两个部分：

+   - 深度学习为什么教不出常识？
- 如何让人工智能学会常识？

最新一期的《连线》杂志（2018年12月刊），封面文章探讨的是人工智能的“天花板”。你可能觉得，咦？人工智能现在不是风头正劲吗，怎么就遇到天花板了呢？

说得有些有意无意，这个天花板的“竟然”是非常简单的，是小孩子都知道的常识。

常识，英文叫common-sense knowledge，就是猫人对世界万物的一些基本认识，比如说液体加热后会沸腾、圆的东西可以滚动着走。

虽然这些知识并不高深，但掌握它们却非常重要。它决定了我们如何在这个世界中生存， 也影响我们生存的环境发生了变化，人生就可以利用常识，快速适应它。

但人工智能就可不行了，一旦条件发生变化，它当会场束手无策。想要在应对对的新情况？可以，你要从头再来，让它重新学习。

原因在哪儿呢？《连线》杂志指出，人工智能之所以无法具有常识，是因为目前主流的“深度学习”技术本身存在局限性， 它只能让智能机器很快地突破能力，却无法让 人工智能去 推理，也无法让我们对知识进行归纳和迁移。换句话说，你难以积累常识， 更无法用常识来认识这个世界上最正确的认知。

现在，已经有计算机科学家开始想办法打破这个天花板，让人工智能也能拥有常识，可是这个过程非常艰难。为什么呢？ 我们稍后再详细说。

我先送上今天的金句：

> We need to start figuring out how to imbue Al with everyday common sense, because it needs rules that can help it reason about the world.

这句话的意思是，我们需要想办法让人工智能掌握常识，因为它们需要依靠常识来展开推理，理解这个世界。

# 深度学习为什么教不出常识？

你可能会有些不明白，现在的深度学习技术这么强大，人工智能不仅能快速学习，掌握图像那么复杂的规则，难道还学不会常识吗？

没错，常识确实很简单，但是要想掌握常识需要具备一种能力，就是推理能力，它叫做reasoning，人工智能可以深度学习，但它没有推理能力。
