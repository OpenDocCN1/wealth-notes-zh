# 今日报告：建筑"网红化"的利与弊

如果建筑设计师一味地复制粘贴网络上的流行元素，只会导致严重的同质化，让人们对美疲劳；设计师应把这些元素变成自己的东西，更好地融入到建筑当中去。

——《卫报》

马俊波

今天的议题分为两个部分：

+   1. 建筑"网红化"的好处
2. "网红"建筑背后的质量倒退

假如你准备去一家咖啡店，你会最先考虑什么？咖啡豆和食材的来源？投资预算？还是个地段？如果你去问一名设计师，他会告诉你，关键是：门面设计！一定要走网红风，只要到店铺变成“打卡圣地”，人气高，生意一定好。

最近，建筑"网红"化这股风潮席卷了全世界，比如在芝加哥千禧公园（ Millennium Park ） ，它的设计非常有趣，外形就像一颗无比光滑的银豆子，能够映出一颗看似巨大的豆子在翻着跟斗，只要你从上面路过，就会看到自己扭曲变形的样子。特别有趣，所以，这个"云门"非常受游客的欢迎，几乎是芝加哥必去的一处打卡圣地。

![](bbox=[0.1, 0.48, 0.9, 0.58])

《卫报》最近就这个现象发表了一篇文章，讨论了建筑"网红化"这个现象，到底是好事还是坏事。在这篇文章里， Instagram 的联合创始人克里格利姆（Krieger）说：

> 如果你一味地复制粘贴网络上的流行元素，只会导致严重的同质化，让人们对美疲劳；设计师应把这些元素变成自己的东西，更好地融入到建筑当中去。

```
Copying and pasting design tropes would lead to bland homogeny. But instead, if you can make it yours, it can add something to the building.
```

这句话也成我今天的金句。

# 1 建筑"网红化"的好处

其实，建筑"网红化"这股热潮流，说起来，还得归功于社交媒体的高达人发展。社交媒体的巨大流量是自媒体人，很多人才会专心思索寻找那些非常吸引眼球的建筑，变成打卡圣地，吸引无数人前往。

这也让商家和建筑设计设计师在社交媒体上的热度作为重要的参考因素，于是，建筑物本身的用途不再那么重要，它们的样子好不好看，能不能拍成好看的照片，成了社交媒体上流传开来的潜力，才是最重要的。

总的来说，建筑"网红化"还是带来了不少正面的影响。

![](bbox=[0.1, 0.92, 0.9, 0.97])

首先，它为线下零售业注入了新的活力；其次，它把小众艺术推广到大众，让更多的人走进博物馆和美术馆；还有第三个好处，催生新的产业。
