# 今日报告：日本如何应对老龄化社会

日本应对其老龄化社会的经验，或许可以成为中国对抗老龄化的一个参考。

> ——《经济学人》

《经济学人》认为，对于中国来说，在应对人口老龄化的问题上，日本是一个很好的学习对象。

# 日本如何缓解劳动力短缺？

日本的养老院服务模式好在哪里？

老龄化社会是一个全球性的大问题，比如说，咱们都说日本社会老龄化非常严重，那多少算严重呢？在日本，每年死亡的人数要比新生多400,000人，人口总数出现了负增长。

同时，日本人的平均寿命有84岁，是全世界人口最长寿的国家，老年人越来越多，有超过28%的人口年龄在65岁以上，全国有69,785名百岁老人，与20年前比，总数翻了4倍。

总的来说，人类的平均寿命正在变得越来越长，伦敦商学院的经济学家彼得安德鲁·斯科特，他的《百岁人生》里就说，研究发现，一个100后活到100岁的概率是50%，而10后，20后的孩子将个个都是百岁寿星，于是我们，活到100岁，或者说将近100岁，是好事在眼前的事。

长寿当然是好事了，但长寿带来的老龄化趋势，也给整个社会带来了巨大的挑战，比如说人口数量降低，劳动力短缺、医疗负担过重，养老系统不堪重负等问题。

# 日本如何缓解劳动力短缺

《经济学人》的文章说，老龄化社会带来的最大问题就是劳动力短缺，就拿日本来说，求取数量与市场供应空缺比是1:1.6，也就是说，每100个日本劳工，想找一份工作，市场上有1.6份工作等着你。你也不是不愿意来呀，日本确实缺劳动力了，但这只是开始，预计到2030年，日本的劳动力将从现在的6700万缩减到5800万，还要再减少将近1000万的劳动力。

解决劳动力短缺问题的关键，就是要找到足够的人来工作，对此，《经济学人》认为可以通过三种措施来实现这个目的：延迟退休年龄、鼓励女性就业、积极引进移民。下面，我们就详细来讲讲。

首先，要延迟退休年龄，提高人们的工作年限。

延长工作时间对政府的财政有巨大的好处，既能带来更高的税收，也能降低政府在退休金上的投入。《经济学人》为此专门采访了日本首相岸田文雄，安倍在接受采访时透露，他想建立一个充满劳动力，人们终生工作的社会。

那么怎么做呢？首先，从政府层面来说，可以把退休年龄从60岁调整到65岁。但这不仅进一步的延长工作年限，更不得强迫自愿遵守。日本政府的做法是，采取一些激励手段来鼓励延迟退休，比如说给延迟退休的人，给予更高的退休金，同时，日本企业也要积极参与，除了放宽退休年龄限制，还可以返聘已经退休的员工。
