# 今日报告：童年为什么“变味”了？

我们给孩子创造的生活，不过是我们自身生活的一个迷你版本而已。

> ——《经济学者人》

马俊毅

仅仅一代人的时间，“童年”这两个字，留在我们记忆里的事物，已经和他们的父辈截然不同了。

今天的议题分为三个部分：

+   * 大环境如何影响童年？
* 新的育儿观念正在“绑架”童年？
* 科技让孩子变得更“宅”了？

《经济学者人》杂志创刊时的第一篇特别报道，讲了一个让我触动的很深的主题——“童年”的变迁。

文章里说，现在年过30的人记忆中的“童年”，大部分记忆都关于：摸着钥匙和零钱走出家门小伙伴四处闲逛，跟父母聚在一起的时间并不多。

但如今的孩子们，却过上了另一种童年：他们大部分时间都呆在家里，要么长进在成人的孩子房中，一起上学；要么在父母的家里，孩子每天各种玩伴都坐在游戏室里，赶到去参加各种活动，或者一天里有好几个小时花在了各种电子屏幕前。

童年形态的改变，就发生短短一代人的时间，且已非常剧烈。那么，到底是什么造成了这种变化呢？

《经济学者人》杂志从城市化进程的加快、家庭结构的变化、劳动力市场的改变、教育理念的更新，以及数字时代的到来等诸多方面入手，分析了童年被改变的原因。通过这篇文章，你会看到，“童年”这个重要的生命阶段，是如何在一系列复杂因素的叠加和影响下，变得面目全非的。

# ｜大环境如何影响童年？

过去30年里童年的改变，受到了整体外部环境的影响。主要包括城市化进程的加快、家庭结构的变化和女性就业机会的增多。

我们先说城市化。现在全球城市人口超过了50%，在发达国家，有80%的人都生活在城市里。城市生活给我们带来的是更多的就业机会、教育、医疗资源，以及丰富的文化和休闲娱乐活动外，也是有代价的：房价高、通勤就水说了，城市生活往往缺少大面积的绿地、交通状况较差、空气污染严重。

还有就是，城市生活本质上是一个陌生人社会，大家彼此之间不认识，不像在乡村，来了个陌生人都会盯着看。所以，在这么多的危险因素下，生活在城市里的家庭，父母就会放手让小孩子在没有监管的情况下，到外面随便玩耍呢？显然还是让孩子尽量呆在家里，是最安全也是最放心的选择。

其次是家庭结构。如今全球的家庭都在变得越来越小，根据OECD也就是经合组织的统计数据，全球的生育率都在下降，从下面这张图中，你可以非常清晰地看到这个趋势。

![](bbox=[0.0, 0.00101, 1.0, 0.00106])

1970年的生育率是2.7，如今只有1.7了。而且国家的生育率更多，从5.6降到了1.6，下降了72%。另外现在结婚年龄也越来越晚了，根据是OECD的统计数据，1990年，女性结婚年龄是22-27岁，男性不超过30岁，如今女性平均结婚年龄是30岁，男性是32岁。

你看，生育率下降，结婚年龄推迟这两个因素加在一起的结果就是，家庭规模变小，孩子少了，父母能提供的物质条件更好了，因此会在孩子身上投入更多的资源，加上如今教育观念的改变，如今的家庭对孩子的成长，从量大管饱，变成了精品培育。

第三个因素是女性就业状况的改变。OECD的数据显示，女性就业率，从1970年的47.6%上升到了现在的64%，换句话说，原来多数女性不工作，如今是多数女性在职场驰骋。这跟第三产业的高速发展，以及女性学历水平提高有着直接关系。传统那种养儿防老，女人操持家务带孩子的观念，已经逐渐过时，高学历的现代女性，有追求自我价值实现的勇气。

报告里说，未来女性参与就业的人数会持续增长，换句话说，从那两种家庭是女性的一揽子职业状况，将给那种男大女小的对等替换，女性对家庭投入的精力不减少，势必会导致她们不愿意多生孩子。

所以，这些外部大环境的变化，使得女性不愿意多生，孩子少，孩子有更多的资源投入在孩子身上，让孩子有了更良好的成长环境，但都市生活带来的更多安全隐患，使得我们的生母更不愿意不安全感让孩子的安全问题，让孩子走出家门的时间变得更少了。

# ｜新的育儿观念正在“绑架”童年？

你可能不知道的是，“童年”这个概念，是直到17世纪才出现的。

文章说，之前在西方文明里，孩子一直都是劳动力的主力，在工业革命之前的中世纪的欧洲，咱们看到古装剧里打仗的时候都是保护妇女儿童，其实是一种现代观念。古代大人没有“童年”这个概念，孩子在大家庭里，是重要的成员，也是劳动力，可以下地干活儿，甚至上工厂做工。《雾都孤儿》的故事相信你也记不住啦。

对于孩子的教育和投入，是直到上个世纪才开始被重视的，普希金斯学大的心理学家，维兰德·皮尔森，是第一个定义了童年的概念，所谓童年就意味着，“经济价值上的无用和情感价值上的无价”。

而现代，人开始越来越重视孩子的教育这种观念，是受到了芝加哥大学的经济学家詹姆斯·赫克曼的重大影响。赫克曼是诺贝尔经济学奖的影响，他认为，早期的教育研究非常有效。他发现，0-5岁之间的儿童质量教育投入，将会带来5%-13%的长期回报，不仅包括孩子长大成人之后，会有更好的健康状况，更低的概率会陷入贫困，或者走上犯罪的道路。
