# 今日报告：“零工时代”的游戏化管理

在工人的头脑中，玩家和游戏之间的内在是依赖。取代了老板和工人之间更深层次的对抗。学习如何巧妙地玩玩游戏规则，成为了唯一的选择。

——《卫报》

马修敏

如何让人们热爱自己的工作，甚至对工作上瘾？《卫报》这个关于“游戏化管理”的故事，或许能给你一些启发。

今天的议题分为三个部分：

+   * 什么是“游戏化管理”？
* 如何通过“游戏化管理”来创造利润？
* 如何制定游戏规则？

“零工经济”（gig economy）这个概念越来越流行，现如今的零工，不再是过去的这类快送、当个服务员等，它已经变成了一个人们用自由的时间和技能交换金钱的便捷方式。零工经济的从业者来说，这对他们的安全和工人权益的掌控。他们不仅可以选择什么时候上班，还可以选择在哪儿上班，多上多久。但对于依赖零工经济的企业来说，如何管理和约束这些零工从业者，就是一个不小的挑战了。

《卫报》最近就发表了一篇文章，讲的是依赖“零工经济”运行的网约车公司Lyft，利用游戏化管理提升司机工作的主动性，甚至让他们心甘情愿上瘾。换句话说，就是，游戏化管理具备“操纵人心”的能力，能让人心甘情愿地赴赶。

今天的内容，我会给你讲讲，网约车公司Lyft如何利用游戏化管理，解决所有司机公司都面临的两个难题，以及谁制定了游戏规则？这又代表了哪些社会意义和转变。

# 什么是“游戏化管理”？

所有网约车公司面临的两大难题，一个是留住老司机，零工经济时代，更要维护和平台合作，全靠司机个人意愿。网约车平台司机驾驶特别短，根据Uber的统计，50%的司机都跑不过过2个月的时间。加州大学圣迭戈研究所所里的一份报告指出，能坚持超过一年的的司机，只有4%。第二个难题就是，即便司机留住了，怎么能让他们多接单，多为公司创造利润？

那么，Lyft是怎么解决这两大难题的呢？这家公司的杀手锏就是一游戏化管理。

什么是游戏化管理？这里咱们可以学个新词gamification，意思就是“游戏化管理”，它指的是利用游戏的各种元素，比如说得分、等级排名、挑战等元素应用到非游戏场景里。
