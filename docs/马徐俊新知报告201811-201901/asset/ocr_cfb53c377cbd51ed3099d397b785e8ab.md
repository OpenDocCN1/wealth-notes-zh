# 今日报告：鸟撞机事故为什么变多了？

“‘哈德逊奇迹’过去10年了，在空中，航班性击鸟事件的数量正在攀升，这与环保事业的进步，航空业的发展、飞机改造的迭代都有关系。

你可能看电影《飞机》，它说的是2009年，一部飞机在纽约上空突发引擎失灵，险些机毁人亡，幸亏机长乘里利奥斯果断，把飞机紧急迫降在了哈德逊河上，机上155人生还。

这真实发生过的事故，被称为“哈德逊奇迹”

你知道吗？这么严重的飞行事故，其实是一个特别不起眼的原因引起的，一只鸟撞上飞机，破坏了引擎，造下了后续一系列问题。这种情况，在航空史上也有一个专门名词，叫“鸟击”，而“哈德逊奇迹”告诉我们，当鸟击飞机，在空中安全，是一个绝对不容忽视的风险。

今年，恰好是“哈德逊奇迹”发生10周年，那么，10年来，由鸟撞机引发的飞行事故，有没有变多呢？航空业对哪些做了哪些应对？

《福布斯》杂志最近采访了世界顶尖的鸟击专家理查德·多尔贝尔（Richard Dolbeer），他带来了对好撞机的一大坏消息。好消息是，机场鸟击事故量在持续下降，获得了不错的进步；但坏消息是，在空中的击鸟事故发生的数量不降反升，从2000年的94起，上升到2017年的101起。那么，问题到底出在哪呢？

# 1“哈德逊奇迹”为机场带来了哪些改变？

当年，“哈德逊奇迹”引来了机场和美国当局对野生动植物的重视。机场加强了鸟类管理，降低了飞机在起飞和降落时遭遇鸟类碰撞的风险。

文献指出，在机场附近，对飞机造成破坏的鸟类数量，从2000年的741起，下降到2017年的652起。

而美国联邦航空局也加大了在这方面投入，自从2009年以来，美国联邦航空局投入了3.5亿美金，来帮助机场处理野生动物管理计划。目前美国大多大型机场，都配备了野生动物学家，通过他们的专业知识，来帮助解决问题的。

这些动物学家办法，就是改变机场周边的生态环境，让鸟类不再把机场当作栖息地。为此，他们采用了多种手段，比如投放无人机或者放猎狗，把鸟赶走；或者减少鸟喜欢吃的野草或水，或者减少它们不喜欢的鸟，在草坪上种上灌木让鸟飞不进草坪；这样，就达到了驱赶效果。

另外，机场还会对一些小型非保护鸟类进行捕杀。文章介绍，“哈德逊奇迹”之后，纽约市已经累计捕杀了5万只鸟。

这些方法相结合，确实降低了机场附近鸟击事件的发生率。但是在空中，这些方法就失效了，被炸鸟击事件的数量不降反升。为什么这样？其实，这是环境和科技因素共同作用的结果。

# 1 为什么空中的鸟击事故不降反升？

人类之所以没能降低空中的鸟击事件，主要有三个原因：首先，环保活动让鸟类数量增加，让空中交通越来越拥挤；最后，飞机结构的改变，也增加了事故发生的可能性。
