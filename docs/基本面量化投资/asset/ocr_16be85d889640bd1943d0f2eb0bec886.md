# 基本面量化投资

$$\sigma(r_p)^{\text{ann}} = \sqrt{\frac{1}{T-1}\sum_{t=1}^{T} (r_{p,t} - \bar{r}_p)^2} \times \sqrt{T^{\text{ann}}}\tag{15-39}$$\n\n其中，$r_{p,t}$ 是投资组合每期收益，$\bar{r}_p$ 是投资组合各期的平均收益，$T$ 是投资组合实际交易期间，$T^{\text{ann}}$ 是相应的年化乘数。年化乘数的取值标准为：如果按日度收益计算，取值 252；如果按周度收益计算，取值 52；如果按月度收益计算，取值 12；以此类推。\n\n类似地，我们也可以计算出年化主动风险：\n\n$$\sigma(r_a)^{\text{ann}} = \sqrt{\frac{1}{T-1}\sum_{t=1}^{T} (r_{a,t} - \bar{r}_a)^2} \times \sqrt{T^{\text{ann}}}$$\n其中，\n$$r_{a,t} = r_{p,t} - r_{b,t}\tag{15-40}$$\n其中，$r_{p,t}$ 是投资组合每期收益，$r_{b,t}$ 是业绩基准每期收益。在实践中，$\sigma(r_a)^{\text{ann}}$ 通常用来衡量跟踪误差，式(15-30)是式(15-40)的矩阵形式。\n\n除了收益率标准差，$\beta$ 系数也被广泛应用于衡量投资组合的风险。当 $\beta$ 系数大于 1 时，说明投资组合承担了较高的市场风险，即投资组合收益随市场涨跌的幅度比业绩基准更大。业绩指标中的 $\beta$ 系数的计算公式如下：\n\n$$\beta(r_p, r_b) = \frac{\text{Cov}(r_p, r_b)}{\text{Var}(r_b)}\tag{15-41}$$\n其中，$\text{Cov}(r_p, r_b)$ 是一段时间内市场收益与业绩基准收益的协方差，$\text{Var}(r_b)$ 是同期的业绩基准收益的方差，计算所用的收益率数据均为事后值。\n\n此外，最大回撤(max draw down, MDD)也是基金经理偏爱的风险指标。该指标衡量投资组合在历史期间的某一时刻开始运行的最大可能亏损。计算最大回撤指标要用到净值(net asset value, NAV)的概念，定义 $\tau$ 时刻投资组合的净值如下：\n\n$$\text{NAV}_{p,\tau} = \prod_{t=1}^{\tau} (1 + r_t)\tag{15-42}$$\n接着定义 $\text{NAV}_{p,\tau}^{\max}$ 为 $\tau$ 时刻前投资组合的历史最大净值，对于整个投资期间 $T$，最大回撤可以表示为：\n\n$$\text{MDD}_{p,T} = \text{abs}\left[\min_{\tau}\left(\frac{\text{NAV}_{p,\tau} - \text{NAV}_{p,\tau}^{\max}}{\text{NAV}_{p,\tau}^{\max}}\right)\right]\tag{15-43}$$
