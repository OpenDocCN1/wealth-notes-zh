# 1.3.4 业界的实践

如果想了解如巴菲特、芒格、格林布拉特等投资大师的投资方法，甚至想了解一些著名的基金的投资策略，那么时刻牢记“廉价＋质量”的投资原则是非常重要的。下面我们以格林布拉特及其神奇公式作为例子，详细讲解这一原则的应用。

# 格林布拉特和神奇公式
