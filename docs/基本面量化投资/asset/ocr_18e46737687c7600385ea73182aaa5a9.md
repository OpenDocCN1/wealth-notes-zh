其中    A = l′ Σ−1 l,    B = l′ Σ−1 μ,    C = μ′ Σ−1 μ    (15-22)

式(15-22)刻画了 σ₀² 和 μ₀ 的对应关系。对应每一个给定的 μ₀，都能找到相应的 σ₀²。由(σ₀², μ₀)组成的曲线就是所谓的 effettive frontier( efficient frontier)。

上述优化方法是在给定预期收益(μ₀)下寻找风险最小的投资组合。事实上，我们还可以给定预期风险(σ₀²)，找到预期收益最大的投资组合，优化的目标方程如下：

max w′ μ
    w
满足    w′ Σ w = σ₀²,    w′ l = 1    (15-23)

必须定量控制风险的基金经理通常会设定投资组合的预期风险水平，因此式(15-23)的优化思路在投资实践中更为常见。

此外，还有一种应用较为广泛的优化方式如下：
max w′ μ − λ w′ Σ w
    w
满足    w′ l = 1    (15-24)

其中, λ 是风险系数, 更大的 λ 意味着风险相对收益而言所付出的成本更高。这种优化方式本质上是优化经风险调整的收益，常应用于 Barra 等商业软件中。

# 15.4.2  考虑约束条件

虽然基准均值-方差优化模型的逻辑很简洁，但在实际应用中，基金经理往往必须加入更多的约束条件，使得投资组合实际可行或满足相应的标准。
