# 天诛进阶之 D 算法 #3700

越是到了后期，内功心法越是简单。往往就只有一句话，一个公式。

天诛进阶传说已久的 D 算法，说穿了只有一个智识障：“贷款永不归还”。

一）世界观

“贷款永不归还”。这句话是什么意思。

在我们正统的 AB 算法之中，遵循的是传统的思路。也就是田园风格，小家碧玉，宁静而又恬逸。

在这样的生活中，是没有“贷款”的存在。生活也永远没有压力。

当进化到 D 算法之后，我们有了贷款，并尽力去偿还贷款。

可是你仔细看，C 算法的最终目的，还是“还清贷款”。也就是你按照现金流盈亏平衡的原则，尽可能去多贷。

每月勤勤恳恳活着。终有一天，360 个月以后，你会还清贷款。回归“正常人”的生活。
