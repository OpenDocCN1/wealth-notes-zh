# 翠湖天地项目住宅价值解构

住宅价值：主要由商业、办公、稀缺人工湖等综合因素带动地段价值，及未来规划带来较高的预期溢价，在产品本身打造相对不是非常出色。

![](bbox=[0.14, 0.56, 0.7, 0.75])
