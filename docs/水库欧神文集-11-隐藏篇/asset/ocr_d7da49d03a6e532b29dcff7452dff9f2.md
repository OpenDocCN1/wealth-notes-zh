# **先拼长板，再拼短板！**

![](bbox=[0.14, 0.63, 0.36, 0.81])

+   创业者需要先把自己的长板发挥到极致，从千军万马中杀出一条血路，抢先获得融资，把业务优势转化成融资优势（关键是速度，不要过分纠结估值和金额）；
业务和融资暂时领先后，需要尽快补齐自己的短板，再次转化成下一轮的融资优势；
案例：某社交电商
擅长社交传播能力，借助社交媒体迅速低成本的获取了大量用户，但是供应链能力不足，客户体验不好，早期留存很差；
A轮融资后，迅速完善供应链能力，提升用户体验，留存大幅提高；
