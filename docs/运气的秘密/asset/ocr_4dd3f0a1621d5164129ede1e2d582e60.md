# 创意审计

一项针对美国数百家公司财务报表的研究发现，随着时间的推移，6项财务比率（例如销售额与库存的比率、收入与整体资产的比率）都会向着行业的平均水平靠拢。于是，作者推测，行业平均水平是最终目标。除此之外，当一家公司看到相应的数据与行业平均水平之间存在偏差时，会通过改变自身行为或者使用通用审计规则提供的空间来调整比率。

创意审计并不是机械地通报收入或支出，它的报告存在着一定的层级空间，会通过调整数字得到想要的结果。
