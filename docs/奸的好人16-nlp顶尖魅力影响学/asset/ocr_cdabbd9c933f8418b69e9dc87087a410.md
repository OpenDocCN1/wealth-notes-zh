# 三种声调

我们的声调，我们的声调大概是有三种，有一种就是，那个讲话的时候，讲到最后的时候声调是往上。第二种有些就是完全是平的，到最后也是平的。第三种有一些到最后是往下。往上的这个名称，这个叫做问问题。这个声调（平），这个叫做发表声明。第三种叫命令，隐喻命令（下）。
