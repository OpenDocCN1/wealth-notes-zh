# 第一部分 毒辣 NLP 讲义

# NLP 成功模式

1、明确知道自己的目标

除了知道不要是什么，一定要知道“我要的是什么？”

2、采取行动

假设自己已经到达目标，从目标的立场，推理出所有的过程。“我要采取什么行动才可以达到这目标？”

最少推理出三个选择。

3、观察是否接近目标

假如观察到偏离目标，重复第 2 个步骤。

假如观察到接近目标，保持所采取的行动。

4、灵活性的调整所采取的行动直到达到目标

在合法及没有伤害到任何人的情况下，不择手段。
