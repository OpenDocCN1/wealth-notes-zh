
# 毒辣 NLP

听她重复多次的话，你就要听；或者她讲到某一个字眼的时候，她会加重她的语气。举个例子，假如有人提问：“你喜欢怎样的男的？”她说：“我喜欢有安全感的，有钱的，有火花的，当然还要爱我。”其中，“火花”这个字最重要。这样讲“火花”的时候，她加重语气。大概你就会这样问下去：“你所指的火花是什么？”这样问下去，加重语气，她会重复多次的话，就表示那个字对她很重要了。重复问过她，来求证，就显得你很了解她了。这种求证，不要自作聪明把那个字改了。

举个例子，有个人要买东西，他说：“我要考虑考虑了。”最近我用广东话说就是“手紧”。“手紧”是什么意思？缺钱，就好像没钱的意思。你不要重复：“最近你很穷，就是手紧。”所以你就用回他的那个词。

我再问你们，快乐和开心是一样还是不一样？
“一样的。”
一样还是不一样？多少人觉得一样，多少人觉得不一样？那到底是一样还是不一样？每个人都对，也每个人都错。因为这个是你的个人价值观。有些人，在价值观里面，快乐和开心是同一东西；有些人，他就不一样了。刚才那些举手的，觉得不一样的，你觉得在比较兴奋的程度上是快乐比较兴奋，还是开心比较兴奋？多少人觉得开心是快乐的？请举手；多少个人觉得——我又忘记了——“兴奋是……”？快乐是比开心更兴奋的？举手。然后每个人的讲话又是不同了，所以你不需要去多猜，因为你永远也猜不到。你直接听他讲什么字，你就用第二个字回去，用回那个字，这是最重要的一点。

明白吗？我记得，马来西亚这边有一家公司是教人家英文的，叫做“ARK”，在马来西亚是蛮出名的，做的是往公司进军。这个企业家是自己创业的。这个 ARK 这个人，在我刚回到马来西亚的时候，应该是 99 年的时候，有一个创业家的演讲。他自己就是一个创业家，他上台后就讲：“噢，很多创业就是看到人家赚钱他就跟着做，他说这个不叫做创业。真正成功的创业家，你的嗅觉要很强。他讲在商机还没有完全正式成型之前已经嗅到那个商机，你要有那种猎杀动物、那种猎杀的本能，有这种本领你才会有办法成功。”

他讲的时候，我听他演讲，因为有百把二百个人，我就是其中一个而已，当时我还不是很出名的。听他这样子讲，在为他重复了几次。（02:15:05）

好了，到了 2005 年的时候，几年了，五、六年后，哈，这个人认识一个人，认识我。那个 ARK，行销就要做训练，然后那个人就提议找我。

我，然后就讲，大家寒暄了几句，然后他就说：“近来马来西亚有很多教英文的机构开始，竞争很大。”他就这样大概讲讲，然后说他们公司的那些开国工匠、老臣子就开始有点懒了。然后我就认同他，我说这个是真的，因为做销售的几乎没有多余的话，我真的觉得自己很虚伪，没有效果的话很快就死了。

然后他就眼睛张得很大：“YES，就是嘛，老板把他的苦水都吐出来。”现在你知道教英文，多大竞争吗？其他的公司派的销售员，纯粹是没有薪水，只是拿那个佣金。我的公司有底薪金给你的，他们现在开始偷懒。人家没有薪水的，反而到我们公司楼下，看到客户进来之前就拉着他们走。你看我们怎么跟他们搞？他就说：“你看，我这过程之前只是讲到那一个字——懒。我只讲这一个字，他就说 YES。”因此我们这样就很容易了，我们听对方的那个字。

记起来，没办法记的时候，在你手机那里说，想办法把他的字眼记下来。记录了后就跟他们聊天，候就可以把那个字眼拿出来。你们想象一下，刚才的那个 ARK 的创办人，他为什么会觉得这么兴奋？当我在讲课的时候，现在他会不会觉得我在尝试说服他？不是我在说服他，他自己说服自己，他不觉得。我是在想推动他上去我的那堂课，他感觉到这个人其实就是我要找的。他没有推到我，其实我推他，我只是用他的字眼在跟他讲，变成了他只听到我在用自己的头脑在跟他讲，所以他的情绪激动。

所以这个听，重复的次数，声调，然后你重复给对方。好，现在就是训练，这个训练就是你们一组人问我，就是做这个开放封闭，就是当自己聊天，好像大家交朋友聊天，你问我问题，然后就是开放封闭，开放封闭，这样子来模仿，模仿。

来一个人，就像聊天一样，大家在一起认识了，在一个咖啡厅见面了，就要聊天去问我一些问题。来，任何一个人就可以，快快快点，我要你们讲出来，因为你讲出我就马上更正。直接问就可以。

“什么？”
“你几公斤？”
“我几公斤？”公斤，你知道多少吗？218 公斤。注意一下，他这个问题是开放还是封闭？开放。表面上是开放，“你多少公斤”是开放，实际这是封闭，因为，我自己讲事，答案只有一层而已，多少公斤，我 218。你不能问“218 怎么样？”所以只有一层。假如只有一层，是叫做开放还是封闭？所以是封闭的。像问那个人：“你在这个公司多少年了？”开放还是封闭？封闭。听起来好像是开放，但是其实是封闭，因为他不再开下去。

再来，“你喜欢听什么音乐？”
“噢，喜欢听什么音乐？鼓的。有一种音乐叫跳 K，东欧，还有 DDK。DDK 是我蛮喜欢听的，通常是一些快的歌，这就是我喜欢听的歌。”

刚刚他问的什么问题？“你爱听的歌是什么？”不不，你马上就开放了。你要先封闭了我，再问那个问题，对不对？这都是开放的。刚才我讲了这么多，我要封闭的问题。封闭是最简单的。

“你喜欢听什么的快歌？”这还是开放。

封闭是什么意思？刚刚我讲的那些歌，然后要怎样？封闭是最简单的。当我讲“我喜欢布鲁斯”时，你喜欢布鲁斯？当我讲“DDK”时，你喜欢 DDK？不一定要讲什么模式。然后再来，再来。

因为你刚才问的那个问题问到了一点，你刚才问的时候有点迟疑了。我的反应，我刚才是比较想控制的，但我不要你会因此受影响，所以我就用迟疑的方式来答，因为对你刚才提问的时候，所以喜欢女人味的。那么，用一个正常人听你这样讲的话，他就会看，看你的一个反应，到底你还会问什么。我就会猜，迟疑的回答，我让你的语调来引导我。刚才你讲稍微快一点了，这样子的意思：你喜欢有女人味的，对你来讲，女人味比外表重要一点点，女人味会比那些清纯的少女……就一定要讲。当你讲外表重要吗？你就会讲到外表。

因为当时我可以讲外表，但你讲外表重要，你是不是喜欢清纯少女型？
“对，我不喜欢。”
再来，通常只是讲了几句，怎么样再讲第二句了？因为我越讲越深的时候，我的情绪还没动了，你知道吧？就像别人问你喜欢什么颜色，黄色，我的情绪还没动。你问我这两种，我的情绪还是不会动。你要问到我自己情绪动了，你才能够了解了。女人味是什么意思？或者哪一种女孩子你是觉得有女人味的？举一些例子，那么我越讲越细的时候，我的情绪就会讲入那个状态，那就是开放。

> “为什么你这么胖了？”

刚讲了一大堆的封闭。以上，封闭为什么会这么重要？举个例子，你在飞机上跟一个陌生人聊天，你不会开放封闭，封闭错误了。

“我是第一次去吉隆坡。”

所以他一句连续都说不了的话，所以说是封闭，封闭错误了，接下要聊下去估计也是难。要聊的顺畅，刚开始聊的时候，是要讲一些：我想交朋友。交朋友和审判是不同的。交朋友是要让对方刚开始的时候很容易。对方很容易，也会让你很容易。你问的那些问题让对方觉得他认同，所以我才要你们这样子来。

刚才你们会问我一些开放式的问题。问开放式的问题问得多，你要怎么样的封闭我，再问第二层的开放？大部分你们问的都是第一层，第一层啦，还没到第二层。

所以我刚才是要讲，要是公众的时候要怎么呢？而且我不要你讲你的废话。正式的情况，开放封闭的中间要加些什么东西？自己的废话，就会变得对方会觉得你，因为一直在重复地讲。当时一定今天你到这里上课就是要听我讲废话。我讲我不要你问问题，你讲废话的时候，当时一句话很长，我只要你们自己做开放封闭，就尝试直接对着我说好了。

我要求你们感兴趣做反问，你们在家里的叫做咨询意见。

初学的人了，我帮助你们就是用这种重复来帮你们。假如在正式的情况，你们可以讲一讲废话，然后你们在……也不是这么多人喜欢的历史，不过你的意思就是你喜欢宗教的历史。我就觉得比较自由，我给你们做，因为你们是初学。其他的我会少研究，但是宗教的历史，我会研究。

假如是在正式的情况，你们可以讲个黑话，再：“其实也不是这么多人喜欢那个历史，不过……”你的意思就是封掉你以前的历史，我就可以知道。我给你们一个教程来做，因为你们是初学。其他的，我比较少研究，但是宗教的历史，我有研究。
