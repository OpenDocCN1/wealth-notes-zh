# 中階

+   1. 《會計科目解祕》(Accounts Demystified: The Astonishing Simple Guide to Accounting)，作者是安東尼·萊斯（Anthony Rice）。
2. 《笑傲股市：歐尼爾投資致富經典》，作者是威廉·歐尼爾。
3. 《怎麼知道這檔股票能賺錢？》，作者是理查·柯克、李奧·高夫。
4. 《大到不能倒：金融海嘯內幕真相始末》，作者是安德魯·羅斯·索爾金。
