# **借他人之手**

李侍尧自己是汉军旗出身，在乾隆早期就开始进入官场，在和珅出现之前，李侍尧绝对是最得乾隆欢心的官员之一。正是由于这个原因，李侍尧这个没有功名的人也开始步步高升高，成为了总督、巡抚一级的封疆大吏。李侍尧在地方上确实有一些成绩，但他确实是一个贪官。在乾隆朝，好大喜功的乾隆皇帝喜欢各种稀奇的珍宝。作为地方大员，那些封疆大吏每年都会献给乾隆一批自己辖区内的珍宝。这明显是在赋税之外的一种变相摊派，李侍尧出任两广总督时，使用的也是这个办法。他自己不会拿一分钱，他会先各级政

府在征收时，肯定会增加一部分，不经自己还要捞一分。所以说，在乾隆朝，对老百姓额外征收的费用，比赋税还高。
