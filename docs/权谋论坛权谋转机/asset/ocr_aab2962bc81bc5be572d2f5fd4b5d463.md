# ## 善于表现自己

一个人的才华，唯有显现出来，为人所知，才可能成就事业，然而古人云：“木秀于林，风必摧之。”才华的展示，往往会招来平庸之辈的嫉妒与摧折，机遇与风险并存，想要把握机遇，必须勇于担当由此要能带来的风险，放开胆子，一往无前，畏手畏脚的人只会看着大好时机在眼前溜走，时机只会青睐那些勇敢的人。

和珅在他 23 岁时，被授为三等侍卫，后来以被挑选进入黏竿处，黏竿处又称为上虞备用处，即是皇家的仪仗队，皇帝的出巡等一切仪仗事宜都由上虞备用处负责 和珅由此得以经常有机会在皇上身边，一般的侍卫都安于现状，不思进取，加上“ 伴君如伴虎 “的古训，整日唯唯诺诺、小心谨慎、唯恐一时差错，招来杀身之祸，更别说敢在皇帝面前直陈已见了，而这正是和珅等待的机会。
