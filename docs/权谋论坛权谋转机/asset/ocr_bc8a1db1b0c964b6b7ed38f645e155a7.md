# 积累知识

想得到别人的赏识首先要积累足够的知识，平凡的人普天之下很多，为何和珅得到乾隆的赏识，无非就是他懂的你 也懂，他问的你也知道。

猎人外出打猎，人们劝他装上子弹，他却大为恼火说：

> “打猎的地方还远着呢，装一百发子弹都来得及！”

走着走着，他看见一大群野鸭密密地浮在水面上，此时放枪，准能收获不小。可惜，就在他匆匆忙忙装子弹时，野鸭有了警觉，早已飞得无影无踪迹。

猎人失去猎物，只因为他把“机遇”放在了“口袋”里。人 只能去等待机遇，而机遇却是从来不等人的。
