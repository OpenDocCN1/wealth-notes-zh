# **洗钱黑变白**

“洗钱”一词的由来20世纪20年代，美国芝加哥一黑手党金融专家开了一家洗衣店。他在每晚计算当天的洗衣收入时，就把其他非法所得的钱财加入其中，再向税务部门申报纳税。这样，扣去应缴的税款后，剩下的其他非法所得钱财就成了他的合法收入。这就是“洗钱”一词的由来。

“洗钱”是指通过金融或其他机构将非法所得转变为“合法财产”的过程，一方面，通过洗钱，有组织犯罪掩盖了其犯罪活动踪迹，得以“正当地享受”犯罪所得；另一方面，洗钱为犯罪集团介入合法企业提供了资金，使其能够“以合法掩护非法”，不断扩大犯罪势力。
