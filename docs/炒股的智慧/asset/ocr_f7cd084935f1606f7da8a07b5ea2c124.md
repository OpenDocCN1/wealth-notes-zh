# 第三節 股票分析之我見

一般股民唯一會關心的就是股價什麼時候會升，什麼時候會跌。而我們知道股票會升的唯一原因是買者多過賣者，股票會跌的唯一原因是賣者多過賣者。股票分析能夠定量出股價什麼時候升跌嗎？答案是不完全能做到！
想像一下什麼因素會讓股民買股？政治、經濟、心理、環境因素等等都有可能，但這些都無法定量。

金融分析者發明出一本益比之類的指標試圖將股價的評估量化，但本益比同樣不能指出股價明天會升還是會跌。那麼這些分析理論的目的何在？答案是：這些分析提高了預測股價變動方向的準確度。也就是說可以提高股民入市的勝率。
