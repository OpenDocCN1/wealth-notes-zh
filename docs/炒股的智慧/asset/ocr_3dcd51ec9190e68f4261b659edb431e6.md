# 小環境

+   一、營業收入：一個具有發展潛力的公司，其營業收入必須有快速發展的勢頭。去年賣出一億元的產品，今年兩億元，預計明年四億元。這樣的公司常常提供了股價在短期內翻幾倍的機會。

+   二、盈利：有些公司做很多生意，但就是不賺錢。公司經營的好壞主要以盈利作為衡量的標準，盈利增加，股價自然上漲。

+   三、固定資產：固定資產就是公司現有的所有「不動」的資產。如果公司的市場總價是十億元，固定資產是十五億元，你可以認為股價沒有反映公司的價值，股價偏低了。

+   四、類似公司的情況：大家都生產類似產品，例如電視機，其他公司的績效和這家公司比如何？同類公司常常有類似的經濟週期，股價的波動也類似。

+   五、品牌的價值：有人估算過，光是「可口可樂」這個名字就價值五百億美元。你打算投資的這家公司有無優秀品牌？這可能對股價有深遠的影響。
