# 第 2 章 股票分析的基本知識

濟大勢上的分析時間不超過十五分鐘。大環境的變化是談天的好材料，用來炒股實用性不大。但是大的政治動亂和經濟震盪當然例外。

研究小環境中公司的經營情況是必要的。以我自己的經驗，如果只靠走勢圖來判斷股票走向，不知道賣的公司到底是做什麼的和營收如何，會讓我觉得很心虛。

研究公司的經營情況必須具備一點會計的常識，要能看懂公司的財務報表。但這裡面的遊戲也很複雜。以銷售收入而言，公司是如何計算銷售收入的呢？有些公司賣貨後收到錢才算收入，有些公司只要發了貨就算收入，更有些公司把訂單全部都計算在內。但是要注

意的是，發了貨能否收到錢是個問題，就算是訂單也有可能被取消。

固定資產怎樣算也有學問。有些老工廠在紙面上還值不少錢，但事實上那些舊機器送人都沒人耍，這樣的公司你說固定資產是多少？按市面上買價減去折舊計算固定資產，得到的數字可能很漂亮，但其實沒多大意義。

讀者們在研讀財務報表時必須留意這些細節。
