# 依風險承受力買股，最終達財務自由

# 新序

這本書十六年前曾由三聯書店出版，得到不少讀者譽稱為「中國人寫的炒股經典」，我深感榮幸。今次全新版本問世，書中已受時間檢驗的內容基本上保持不變。

在這十六年間，中國股市從初始到市值排名世界第二，僅列美國之後。這是了不起的進步，中國正以前所未有的速度拓展著經濟版圖，做為股市的參與者、有耐心的股友，同樣收穫了經濟成長的果實。

就炒股而言，股市沒有新東西。十六年前炒股和今天一樣，十六年後炒股也將和今天一樣。但我希望補充「風險管理」的重要性，因此特別增加了第九章〈善戰者無赫赫之功〉，我想說明的是，股票戰役是打不完的，而且想打隨時可以開打，但打這種戰不應行險鬥狠，試圖畢其功於一役之勝，集小勝為大勝，最後達致財務自由，才是成為股市最終勝利者的智慧之路。
