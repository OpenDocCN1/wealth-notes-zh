代，美國股市碰到幾年瘋狂的牛市。回頭想想，自己的運氣不錯。

如果你鐵了心，要擔大風險賭一賭，打算手邊那點錢虧光了就當每禮拜少吃一碗牛肉麵。以下是三條日交易的注意事項，或許有助於提高成功率：

+   一、忘掉基本分析，完全用技術分析操作，記熟這本書介紹的幾個圖。

+   二、做短線！看十分鐘或三十分鐘的 K 線圖，就算是五分鐘也好。

+   三、定個止盈或停損點百分比。例如虧五%就停損出場，但賺一五%也止贏出場，短線交易不可以照搬「讓利潤奔跑」的教條。

更進一步，如果你什麼技巧都不想記，只想買一支便宜股放個幾年碰運氣，這也是方法之一！但這就沒有什麼技巧可言了，這是用買彩票的方式賭股票。祝你好運！不過要有心理準備，買彩票中獎的機率很低！

也許你真碰到好運，那三萬變成了三百萬，這時我也要提醒你不要像上述劉姓炒股人一樣繼續往下賭。拿出兩百五十萬做謹慎投資，每年一○%也有二十五萬，夠一家四口吃飽喝足。窮人開革命情有可原，富了還鬧就是自己給自己沒事找尷尬了。
