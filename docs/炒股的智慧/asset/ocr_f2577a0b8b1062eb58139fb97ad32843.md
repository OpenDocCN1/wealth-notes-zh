# 要有應用知識的毅力

餘炒手想法設法不去停損。

怎樣才能減肥？答案其實只有四個字：少吃多動。減肥的知識是如此簡單，減肥應是輕而易舉吧？事實正好相反。美國有個統計，每一百人參加減肥訓練，只有十二個人降低了體重，其中只有兩個人將體重降低持續一年以上，也就是只有二%的成功率。減肥失敗的原因不是因為學習減肥多麼困難，而是因為大多數人缺少每天應用這些知識的毅力。你很想吃一塊蛋糕，但你知道這一塊蛋糕下肚子，運動一整天的效果就泡湯了，你忍得住嗎？你訂好計畫，每天吃什麼、運動多久，可是你堅持了多久呢？

炒股也是一樣，任何對炒股有一定認識的人，都明白炒股所需的具體知識少得可憐。股票只有兩條路可走，不是上就是下，影響股票升落的因素就是這麼多，真正重要的因素列出來占不滿你的手指，甚至不識字的也可以在股市露一手。股票的引誘力也人所周知，你如果做得好，前景大大的光明。

這樣的行業，成功率甚至低過減肥！為什麼？因為人們常常做不到自己該做的事情！

人們都知道誠實是取信於人的不二法門，有多少人做到了？我欣賞王安電腦公司創辦人王安的話：『我可能沒有把我知道的全部告訴妳，但我告訴妳的全部都是真的。』我們都知道
