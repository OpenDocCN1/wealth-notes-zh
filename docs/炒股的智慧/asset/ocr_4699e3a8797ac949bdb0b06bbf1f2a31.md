# 選擇股票的步驟

在選擇股票之前，你需要首先選擇股票的類別，例如地產股、金融股、電子股等。讓我將這個過程簡化成以下三個步驟：

第一、什麼是大市的走向？如果大市不好，你最好什麼都別買，安坐不動。我知道對新手而言，讓錢閒著是件極其難受的事，但你必須學習忍耐。就算你看到很吸引人的臨界入場點，也不要輕易有所動作。大環境不適合的時候，你的勝算便降低了。

第二、哪些類別的股票最具「牛勁」？需要指出，如果兩檔股票的技術圖形相似，例如，同時在充足的交易量之下進入爬坡階段，其中一檔股票屬「牛勁」很足的類別，另一支屬「牛勁」不足的類別，你會發現屬「牛勁」足類別的股票很容易就升了一○○％，而「牛勁」不足類別的股票要很辛苦地才能爬升二○％。
