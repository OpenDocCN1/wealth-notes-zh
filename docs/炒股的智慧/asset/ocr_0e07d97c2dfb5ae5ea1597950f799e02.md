# 四、久賭必贏階段

回到我的故事。我炒股的最大挫折，就發生在「有靈光在我腦海閃耀」之後。有四年多的時間，股市對我而言成了「沒錢人學到很多經驗」的地方。我不知有多想快快地撈上一筆。有整整兩個星期，我虧掉五萬三千美元。真正的挫折不在於虧掉的數目，而在於這次虧錢完全不應該。按我的規則，我只會虧掉四千美元左右，那是我停損的極限。但我注下得太大，又不肯及時停損。我犯了不該犯的錯誤。我用希望取代了分析。我自以爲懂股票了，其實還不全懂。

隨後一個月，我開始整理自己的思路，總結五年來的經驗及教訓，綜合我這些年來的廣泛閱讀，結果就是這本書所說的一切。有兩年期間，我完全按這本書所說的原理解辦，每年的報酬率都超過一一〇％。但需要特別說明的是：這樣的報酬是在極小的風險下取得。日後是否能持續這樣的報酬，我不知道，但我知道我已定出了可行的炒股計畫，只要按這個計畫做，我久賭必贏。差別只在於贏多贏少，那跟運氣有點關係。

現在我們談炒股的最後階段——久賭必贏階段。
