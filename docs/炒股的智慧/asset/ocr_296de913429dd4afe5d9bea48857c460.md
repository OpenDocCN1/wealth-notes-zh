# # 三則故事

# ## 第一則：年輕人的故事

從前，有位鄉下青年，讀了點書，嫌鄉村的生活單調，決定要去城裡闖世界。臨走時他向村長請教，村長給了他三個字的忠告：「不要怕」。並說等他回來時還有另三個字相贈。

三十年後，飽經風霜的青年帶著滿頭白髮決定還是回到鄉村生活。回來時，得知當年的村長已死，心中悵然若失，不知村長另外要贈的三字是什麼。後來村長兒子轉交給他一個信封，說是長者臨死前囁咐交給他的。信裡只有三個字：「不要悔」。
