# 第一節 學股的四個階段

在我學股的過程中，我最希望知道的就是我已經學到什麼地步。當我達到什麼地步的時候，才可以認為已經畢業。當然，畢業並不表示已成爲專家，但起碼它表示我已擁有足夠的知識在這行生存。

就數學而言，小學的內容從加減開始，中學的內容包括幾何代數。你很清楚你的數學知識已經達到了幾年級的水準。

學股有沒有這樣的級別之分呢？答案是「有」。

我就以自己的學股歷程談談學股經過的階段，你可以參照我的描述，估計一下自己現在處於什麼階段。這些階段的劃分並不嚴格，很多時候是互相交錯的。如果人性共通的話，我學股的歷程應該和你十分相似。

# 一、變幹階段
