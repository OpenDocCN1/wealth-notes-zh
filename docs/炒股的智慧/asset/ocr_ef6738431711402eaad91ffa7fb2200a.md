# 馬多夫騙局

名。只有一二．五％，是不是讓很多股友很失望？有多少人認為進了股市每年不翻上一倍不能稱爲功勞？

再講個伯納·馬多夫（Bernard Madoff）的故事。幾年前馬多夫因爲詐騙被抓了。這裡不談他的詐騙，這裡講他是如何贏得專家們的信任。伯納·馬多夫是美國納斯達克前主席，他不和普通人大交道，他的投資客戶都是大銀行，大退休金管理機構或豪門巨富。這些人都專家，或有人行家做顧問，想騙這些人不是件容易的事情！

他靠每年提供一二％的報酬，每個月一％，年年如此，贏得專家信任！所有專家都知道，若一位投資經理有足夠的知識和經驗，每年一二％報酬是可以放在很小的風險之下得到的；不容易，但做得到！沒有人會懷疑納斯達克的主席是否有足夠的知識和經驗！市面上平均年報酬比一二％更高的基金多的是，但他人報酬總是有起有伏，有時也虧錢！伯納·馬多夫特別的地方在無論大市好壞，年年拿個一二％。馬多夫基金最後的規模是六百五十億美元，向專家籌到這麼多錢是多麼地不容易。

說到這裡，這一章想傳遞的思路應該更清楚了。
