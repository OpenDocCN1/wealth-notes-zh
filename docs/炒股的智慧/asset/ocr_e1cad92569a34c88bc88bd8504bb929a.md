# ## 第三節 善戰者無赫赫之功

先講個我自己的故事。一九九二年，我開始在一家小證券行做股票經紀人。雖然那時我已經有過幾年基金的投資經驗，也完成了金融學業，可是在股票交易上還算是個新手。我邊做經紀人邊自己替自己炒股，有時太過專注，等到回过神時天都亮了，我找到了自己想終身從事的事業。我太喜歡交易了！

做為科班體系出身，我一直受到傳統的金融理論影響；例如什麼隨機漫步理論、充分市場理論等等，我受到的教育是：市場是有效率的，所有的因素都已經反映在股價之中。這些說法成立的話，個人炒股便無意義了，買指數基金就好了！可是現實生活中就是有人年復一年地擊敗大市。

科班學習的範疇是華倫．巴菲特，也就是那套價值分析，買了不賣的理論。我自己雖然經驗不足，但也可以感到這套理論很難實踐。大家都價值分析，去哪裡找那麼多便宜貨呢？憑什麼認為自己比別人更會分析？老巴的那套東西我試了很短時間就放棄了。我開始廣泛讀書，研究那些前輩股市天才們的經驗。

我在大學的專業是工程，有著不錯的數學基礎；自然地，研究的目標注重可以量化的方法。在經過一段時間研究之後，我為自己定位了一套操作法：賣空跨式組合期權（short straddle）。
