# 第二節 「瘋」故事解剖

看到路邊盡是一幢幢空空的大樓，電視報導說中國的现房供應過剩要花十五年才能吸收。我不知道十五年是否太長？就算五年吧！如果這些地產開發商不是用國家資本，有幾位能撑上五年？可惜這些地產商據說大多是用國家資本，虧了算國家的。眞讓我難過！這些可是老百姓的血汗錢。

更早幾年，我在美國讀到有關中國郵票瘋的報導。一張毛主席和林彪在天安門城樓檢閱紅衛兵的郵票被炒到四千元人民幣。清朝的大龍郵票被炒到上百萬我不奇怪，因爲全世界僅存一枚。而毛主席和林彪檢閱紅衛兵的郵票我自已都用過，那是「文革」期間最常用到的郵票之一，四千元是當年普通職工一年以上的薪水。如果不是期待比你更傻的傻瓜會用比四千元更高的價錢讓你脫套，你還會會買這張郵票嗎？爲什麼不去箱子底下找舊信封，或許你會找到好幾張這樣的郵票。
