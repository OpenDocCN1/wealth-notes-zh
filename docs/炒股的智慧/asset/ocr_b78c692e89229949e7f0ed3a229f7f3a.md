# 市場從來不會錯，但你自己的想法常是錯的

有多少次，你拍著腦袋大叫：「見鬼了，無論從什麼角度分析，這檔股票都沒有理由跌，它很快就會反彈。」我朋友來找我討論股票，他們都會一條條列出他們的分析，最後認定這檔股票升到頂了，那檔股票跌到底了。

我無法證明其對錯，通常我只建議若想買那就買吧，但若股票又跌了一〇%，即刻脫手。如果你想賣，那就賣吧，反正不賣你也睡不著。

華爾街很多著名專家，在這一條原則上都翻了跟斗。人一旦出了點名，名聲就重於一切，他們認為股票要升，不升怎麼辦？他們最終結論當然是市場錯了，市場還未體驗到這檔股票的價值。結果就是專家們一個個從寶座上跌下來。這樣的故事非常多。愈聰明的人，愈容易自以爲是。他們在生活中的決定通常能做對決策，或是有些一開始不對勁，但最終證明他們正確。但在炒股這一行，或許最終他們的確正確，但在市場證明其正確之前，他們可能早已剃光頭回家了。

不要自以爲是，不要有虛榮心，要按照市場給的資訊決定行動計畫，一有不對勁時便即刻認錯，這才是股市的長存之道。
