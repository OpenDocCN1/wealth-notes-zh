# 二、新產品

如果有家公司發明了根治癌症的新藥，你可以想像這家公司的前景。新產品提供了公司快速增長盈利的可能。

這類例子很多，例如：美國新態（Syntex）公司在——九六三年發明了口服避孕藥，結果其股價在六個月內翻了五倍。王安電腦因為其新型的文字處理機，在——九七八年至——九八○年間，公司股價升了十三倍。速食店的概念成形初期，麥當勞（McDonalds）公司的股價在——九六七年至——九七一年的四年期間翻漲了十一倍。

新產品並不侷限於「實物」，可以是新的生意概念、新的推銷手法、新的管理方式。
