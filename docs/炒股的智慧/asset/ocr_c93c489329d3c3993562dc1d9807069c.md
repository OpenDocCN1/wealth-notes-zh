# 大出所料的損失

問問你自己喜歡做決定嗎？喜歡獨自爲決定負全部責任嗎？對九九%的人來說，答案是否定的。股市這一恆久的賭局卻要求你每時每刻做理性決定，並且爲決定的結果負責全責！這些就淘汰了一大部分股民，因爲他們沒有辦法長期承擔這樣的心理壓力。

這一恆久變動的股票市場還有一個致命特點：它能使你虧損較比預期要多得多的錢。如果你什麼都不做，也可能使虧損不斷增加。在賭桌上，每場遊戲你最多失去你下的注。你在下注之前就很清楚你準備失去這個數目。在股市，它把你的下注拿走一些，又給回一些，有時多些，有時少些。你該說如何是好？在過程中，你原先預估最多只虧一百元，但最終可能虧掉五百元。因爲股票這個遊戲沒有終止的時刻，沒有人告訴你遊戲結束了。

它從不結束，除非股票停盤。

在賭場裡，每場新的賭局都有新的開始，並且自動結束。基本上，勝負的結果由機率決定。你如果不想輸錢，下一手不下注就可以了。只要你不動，本金就不會減少。

對坐在賭桌上的賭徒來說，不下注是很困難的。因爲新的賭局就是新的機會。你很少看到賭徒願意錯失新的機會。雖然不入場不容易，出場卻很容易，無論贏或輸，遊戲結束時就自動離場了，你在理智上不需要做任何判斷。
