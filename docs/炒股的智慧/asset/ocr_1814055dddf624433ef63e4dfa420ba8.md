# 第一節 阻礙炒股的心理障礙

這個世界充斥著滿腦子幻想，但從不實踐的人；也有很多埋頭做事，卻從不幻想的人。那些滿懷理想，並且努力實踐實現理想的人少之又少，但是只有這些人才是生活中真正的成功者。他們每天都充滿活力，爲實現理想而努力，不計報酬。因爲工作的樂趣已是最大的報酬，他們把每個失敗和挫折都當成前進路上不可避免的障礙。

從這一點來說，在股票這一行成功的條件與其他行業毫無區別。

想成爲一位成功的股票投資人，你必須做到下述三點：

+   第一、獲得炒股的基本知識。
第二、制定確實可行的炒股計畫。
第三、嚴格按照這個計畫實行。

到現在爲止，你已具備足夠的基本知識來判斷股票的走勢和股市大局，知道應該如何選股，如何決定買入點和賣出點。你已經有足夠的知識架構制定作戰計畫。
