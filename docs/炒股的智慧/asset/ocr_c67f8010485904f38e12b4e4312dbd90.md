# 第一節 炒股成功的基本要訣

去炒股無非是瞎貓碰到死耗子。

學股之路艱難且漫長，想要從股票學校畢業，學股人必須有一定的素質。只有具備這些素質，你才可能熬過黑暗時光，否則，成功只是幻想。你如果還不具備成功的投資者具有的特質，希望你從今天開始培養。那特質就是——除了毅力之外，沒有別的要求。

任何有虧損的行為都可稱爲「投機行爲」。在投機遊戲中，你希望最好的結果，但同時爲可能的失敗做好準備。炒股的行爲便是典型的例子。

投機本身是門學問。幾何學有幾何原理，投機學也有它固定的投機原理。做爲投機遊戲的參與者，你必須遵循投機原理。以這些原理做指導，鍛鍊遊戲的技巧，隨著時間的推移，你對理論的理解愈來愈深，玩遊戲的技巧愈來愈熟練，如此一來，你便能夠成爲一名專家。
