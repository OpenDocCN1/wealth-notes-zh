# 第一節 華爾街的投资智慧

要把所有的華爾街家訓都寫出來，起碼需要兩百頁篇幅，而且其中大部分是「為賦新詞強說愁」。我將親身實踐後證明最重要的規矩整理出來。這些規矩已由我的實際操作證明可以遵循，而且行之有效，希望讀者們能牢牢記住。

# 停損，停損，停損！

我不知這該如何強調這兩個字的重要，我也不知還能否解釋這兩個字，這是炒股這一行的最高行為準則。你若覺得自己實在沒辦法以比進價更低的價錢賣出手中的股票，那就趕緊退出這行吧！因為你在炒股這一行沒有任何生存的機會。最後割一次肉，痛一次，你還能剩幾塊錢替兒子買奶粉。

# 分散風險

做這行需要賭性，但不能做賭徒。如果你喜歡刺激，手手下大注，夢想快快發財，那麼遲早會翻船說再見，而且速度會比你想像的快更多。就算有十次好運，但第十一次好運不見得還會落在你頭上。
