# 我如何看待股票大市？

炒股高手傑西·李佛摩是這樣強調股票大市的重要性：「炒股的訣竅便是在牛市中全刀投入，在牛市結束或接近結束的時候賣掉你的所有股票。」

股市就像羊群，單獨股票就像羊群中的羊。當羊群朝某個方向前進時，大多數的羊跟隨著同一方向。股票也一樣，在牛市的時侯，大多數的股票升，熊市的時候，大多數的股票跌。就如同做其他生意一樣，順勢是成功的基本保證。做服裝生意的要賣流行款式，不要進冷門的樣式。炒股的道理也一樣。不管你選了多好的股票，在大市向下的時候，它跌的機會大過升的機會。那麼如何確定股票大市呢？

要確定大市的走向，最重要的是每天要追蹤股票指數的運動。如美國的道瓊指數，日本的日經指數，香港的恆生指數，上海、深圳的綜合指數等等。

就我自己的經驗來說，用技術分析的方法來判定大市的走向及走向的變動是最為有效的工具。研究股票指數圖，把它看成一檔股票，看看這檔股票現在是處於什麼運動階段，它運動正常嗎？

留意每天的交易總量。如果股市交易總量很大，但指數不升，或開盤走高，收盤低收，這就給你危險信號了。
