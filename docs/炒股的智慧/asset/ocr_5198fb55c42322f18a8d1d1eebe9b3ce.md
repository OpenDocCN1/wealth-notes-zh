# 一、盈利的增长

本益比是很重要的概念，即「股價÷收益」所得到的數字。

但我發現新手們常常過於注重本益比，他們把它當成股價是否便宜的衡量標準。這種概念基本上是對的，但是實用性卻不大。舉例來說美國的微軟（Microsoft）公司上市初期，本益比超過一百，就算是今天，它也超過五十。若是數十年前你買了一萬美元微軟的股票，今天就是百萬富翁了。

一個健康、發展迅速的公司，其盈利必定逐年增長。這個增長的速度愈快愈好。一個公司的盈利若能以每年二五%的速度增長，那麼三年就能將盈利翻一倍。盈利增長的速度必須建立在合理的數字上。去年每股賺了一分錢，今年二分錢，盈利增長了一○○%，但這個數字沒有意義。如果公司的盈利從每股五角升到一元，這個一○○%的盈利增長必定將使投資大眾的眼睛發亮。

盈利增長的前提是銷售收入的增長。一個公司的銷售收入如果無法增長，盈利增長通常是玩會計遊戲的結果，對於這一點讀者們要特別留意。
