# 第一節 何時買股票？

在前面談了股票的性質與特點、炒股基礎知識和炒股成功的基本要素之後，本章將專門探討最技術性的實戰問題——怎樣買賣股票。

這個問題我打算從買賣股票依據的基本原則、買入操作的技巧、選擇股票的程式等方面加以闡述。

# 基本原則

在我討論「何時買股票？」之前，我要提醒各位讀者，就我多年炒股經驗，選買點的最要點是選擇停損點。也就是在你進場之前，你必須很清楚若股票的運動和預期不合，你必須決定在哪點停損上離場。換句話說，在投資做生意前，不要老是想著要賺多少錢，首先應該清楚自己能夠虧得起多少。有些人以一○％的數量當做停損基數，也就是十元進的股票，以九元做停損點。有些人將停損點定在支撐線稍下。有些人定二○％的停損額。還有其他各種方法。無論什麼方法，都必須有個停損點，這個停損點不應該超出投資額的二○％。請讀者切切牢記，否則一切都是空談。
