# 二、摸索階段

我自己在蠻幹階段大約待了半年，幸運的是，我居然在這一階段賺到了錢，使我對自己的悟性有了極大的信心。或許這就是初始者的好運。這段時間我開始大量閱讀有關炒股的書籍。我知道這樣蠻幹是不對的，我開始試驗「截短虧損，讓利潤奔跑」。

首先我學習停損，我給自己定個規矩，只要股票從我的買價下跌一元，我就賣掉，以後這樣的損失累積成很大的數目，股票常常一碰我的停損價就反彈，我便幾乎平地不斷停損，小損終於加成大損。我明白了元一的停損不對，我便開始把停損點放大，由一元加到一○%，最後加到二○%。這段時間持續了兩、三年。結果還是不行。舉例說，三十美元的股票，我將停損點定在二十七美元，股票升到三十五美元，我就將停損點定在三十一·五美元。實驗的結果，我買賣的次數少了，但我常常是虧錢時在二十七美元賣股，賺錢時在三十一·五美元出場。這樣虧虧三美元，賺時只有一·五美元，算算總帳，還是虧錢。
