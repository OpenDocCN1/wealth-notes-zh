# 不要向下攤平

除了手續費之外，每天買賣都帶來情緒波動，沖散了冷靜觀察股市的注意力。可以這么說，在你留著跟蹤的股票中，說每天都有七〇或八〇％勝算的交易機會是騙人的，好的操作機會不會天天都有。股民之所以頻繁交易是因枯燥無聊，頻繁交易不僅損失手續費，同時也使得交易品質降低。

犯了錯，不是老老實實地認錯，重新開始，而是抱著僥倖心理，向下攤平，把平均進價降低，滿心希望股票小有反彈就能挽回損失，甚至賺錢。這是常人的想法和做法，但在這卻是破產捷徑，英國歷史最悠久的巴林銀行（Barings Bank）就是這樣倒閉的……

上海石化在美國掛牌上市，一九九七年最高曾達到每股四十五美元。從四十五美元跌到三十五美元，很低了吧？你心裡想，是不是應該再補上兩千股？若是再跌到二十五美元，你打算怎麼辦？還往下攤不攤？結果，上海石化一路跌到每股十美元。做為一名股票投資人，這樣的好戲只要上演一齣，你的財產就全部被套牢。等它升回四十五美元嗎？或許有可能，但這是兩年後或是二十年後才會發生的事，誰也說不准……如果股價永遠回不去呢？這樣被燙傷一次，你將不再有膽繼續炒股。假如幸運地市場給你一個解套機會，你會馬上套現把錢放在米缸裡，心中覺得還是天天摸到錢才會放心。
