# 操作技巧

以下讓我們分析一下買股票時怎樣具體操作。

+   1、升勢時的操作（圖4-1）

假如這是一個正常的升勢，A、B點分別是波峰和波谷。一旦股價超過A點，便是好的買入點。假設A為十五元，B為十三元，則好的買入點是十五、一○元或十五、五○元。因爲你可能判定這是新一波的開始。假如股價升到十六、五○元，你便可將賣出價定在十五、五○元。記住保本。
