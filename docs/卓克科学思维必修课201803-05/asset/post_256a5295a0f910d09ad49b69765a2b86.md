# 206 | 遗憾：明朝可以产生科学思想吗？

![](img/2a007d9b2edf272f0ffcba41cd9344f7_93_0.png)

206 | 遗憾：明朝可以产生科...

# ——► 概念20：遗憾 ◄——

中国在明清两朝曾长期和西方科学保持接触，关系有时亲密、有时疏远。有人认为当时的中国没有发展出现代科学很“遗憾”，而实际上，只是必然，没什么遗憾。

上节课最后我留了一个问题，就是如果在中国古代，有人把大量的欧洲书籍带到中国，比如说几千册，会不会增大知识的渗透率，在中国古代就走上现代科学的道路呢？

这个假设实在是太大，几乎没法回答。

但其实回答这个问题并不需要假设，因为这样的事情在1618年发生过，那就是在明朝末年的万历年间，曾有西方的传教士带着几千部图书来到中国。

我们上节课说的那两本《天体运行论》就在其中。这段历史其实叫做“西书7000册入华”，它对中国的文化影响很明显，但也只能算是影响，最终也未能改变我们的思维习惯。

那这节课，我就给你讲讲西书7000册入华。

# ——► 施行海禁的明朝贸易 ◄——

我们先说说那个时代的背景，整个明朝期间，都是施行海禁的，也就是老百姓不能随意跟其他国家进行贸易。

尤其是到了1500年之后，欧洲各国因为航海技术的发展，都开始走了殖民的道路，这种方法对付太平洋上的小岛是可以的，对付南美的土著居民也可以，但到了中国就行不通了，因为明朝的中国也是一个强大的政体，军事实力对于几艘远道而来的舰艇，对付几千侵略军，这是毫无问题的。

所以，西方各国逐渐放弃了殖民中国的念头，走了文化交流的方式，希望通过这种方式跟中国互通有无，尤其是希望能够开放贸易往来。

但是明朝始终没有开放自由的贸易，贸易也有，只能以朝贡的方式进行，那就是西方国家进贡我们东西，我们再以相等量级的物品回报。

1553年的时候，一些葡萄牙人以赖着不走的方式，在澳门长期滞留下来，后来通过贿赂的方式达成了一系列的协议，最后澳门就成了欧洲人来中国的第一个停留地。

那我们注意一下这个时间点，1553年，这是哥白尼去世之后10年，所以那会儿西方人对太阳、月亮、地球到底谁绕着谁转已经有了明确的观测证据。

# ——► 本土化传教见成果 ◄——

欧洲人自从可以在澳门长期居住了，就在那儿修了教堂，还派了耶稣会的传教士，最初传教的人没有经验，派来的人不会说中文，也不了解中国，来了还按世界其他殖民地区那么搞，所以传教的阻力非常大。

从第二任会长罗明坚开始，就很注重国前的培训了，所有人都得改名，使用中国人常用的名字。比如说他叫罗明坚，他本名叫 Michele Ruggieri，所以就根据近似的音译起名罗明坚。

除此之外，来传教的人也必须会说中文，会写中文，这对当时的传教士来说门槛确实很高，他们到了中国之后，还不能大张旗鼓地宣传宗教，要多多尊重当地的风俗，多多学习不懂的中国文化，尽量把把天主教图书翻译成中文版。

也正是因为这这样本土化的改进，中国人后来对传教士的接纳度增加了。

罗明坚当年就引荐了利玛窦来中国，这个人更是 不把自己当意大利人，不仅是个中国通，连穿着打扮也跟中国人一样。

利玛窦通过宦官引荐，见到了神宗皇帝，打破了一直以来 的倨傲，神宗皇帝就允许他在北京建立教堂了。

自此，京城的达官显贵就逐渐听说了很多闻所未闻的事，比如像地球是圆的，月食是因为地球走到了太阳跟月亮之间，太阳比地球大很多很多，世界上还有很多的大陆，等等等等。

当然，这些概念的接受也不是一蹴而就的，明末的大学者李之藻评价利玛窦这个人是这么说的：

> 最初10年，以为他是个异端学说的人，后来发现是一个特独立行的人，进而又发现是一个博闻有道之人，甚至还不止于此，后来只要发现了问题就跟他商量，最终的结果往往就跟他说的是一样的。如果没有听他的，你就后悔去吧，这个人实在是够厉害。

# ——► 西书7000册入华 ◄——

从利玛窦打好了基础，再下一任的耶稣会会长龙华民觉得时机成熟了，可以把更多的书籍递中国了。

于是就把比利时的传教士金尼阁派回了欧洲，筹备运书到中国的事，之后3年半的时间，金尼阁在欧洲各教会游历募集各类的书，而且还经常穿着中国人的衣服，在广场上作演讲，号召年轻的传教士都到东方去。最终，一共集中了7000多部书，运往澳门。

现在听着觉得没什么，有些人一年给自己买的书都超过100本了，但是那是1618年，那个年代的书籍很珍贵，比较贵的像《天体运行论》，那个价格大概是那个年代大学的两年学费。

像哥白尼，1543年去世的时候，家里所藏书加起来一共才40本，所以一下凑齐了7000部书，还有好几千种，几乎不是重复的，涉及到当时欧洲各行各业的内容，这就是著名的西书7000册了。

可以说，当年在欧洲都很难找到哪个图书馆可以跟这西书7000册相比。

那这些书都是什么内容呢？

首先就是突出自然科学类的内容，因为当时传教的大策略就是弱化文化差异带来的抵触情绪，所以天主教义的这些内容是可以往后放的，要更多体现出自然科学类的内容，尤其是前一代的传教士给了一些建议，说中国人很重视天文历法，所以天文学跟数学方面的内容可以多一些。另外，跟治疟疾有关的內容也尽量多，这么做能让中国人立马看到西方文化的 效果。

另外一个特点就是这些书的装帧都极其精美，这个建议是利玛窦给的，因为他之前带进来的书，凡是那些体积特别大的，镶着金边 的书就算是没有翻译过来，纯拉丁文的，中国人一点都看不懂，但这种书给人的架式就是这里一定写了一些比较重要的东西，即便人们看不懂，也会认为这本书比较珍贵，保护得比较好。

所以，西书7000册是能选精装本的就不选简装本。

# ——► 不同的宗教是敌人 ◄——

但是，经过6年多的时间，金尼阁把书凑齐了，装船经印度，到1619年再回到澳门的时候，局势变了天，他已经不能再进入北京了，南京也不行，只能寄在澳门。

这是因为，明朝对天主教教士的政策发生了一个180度的大转折，这个转折是发生在1616年，那会儿金尼阁还正在欧洲募捐书呢。

1616年的時候，礼部侍郎沈樾到任南京，就收到了很多投诉的案子，社会上也有传言，说从前来的那些洋人现在开始阻碍我们祭祖、祭天拜孔子，而劝人去拜什么上帝，而且这样的故事越来越多，沈樾就非常不满。

因为从前这些教士只是踏踏实实地学汉语，学官话，测算天象，那现在开始到处嚷了。

其实这是因为利玛窦去世了，从他去世之后，传教士在中国策略大方向就改变了，从前也有很多人反对利玛窦的行事风格，认为他让大家入乡随俗的方式是对耶稣会的侮辱，所以现在要按他们的方式普及天主教，就比较强势。

所以沈樾给神宗上书，状告传教士的三大罪状：

+   - 第一个，收买人心，企图颠覆中国；
- 第二个，勾连白莲教；
- 第三个，破坏礼仪文化。

几次努力之后，神宗也终于怒了，下令禁止天主教，杀了一批传教士，关了一批，大部分都驱逐到澳门去了。

教会书籍被定为是妖书，搜到就烧毁，也就是这会儿，金尼阁带着西书7000册回来了。他就只能把书暂时安置在澳门，金尼阁的传教活动之后就大都只能以地下的形式秘密进行。

因为大批的传教士遭到迫害，也组织不起来一支有力的翻译队伍推esch那些书，最终带书回来的金尼阁也只能眼睁睁地看着那些书就堆在库
