# ——► 概念21：追赶 ◄——

1847年，三名中国学生赴美留学，迈出了中国追赶现代科学文明的第一步，他们之后成了"留美幼童计划"。留美的幼童人到中年后又促成了"庚子赔款奖学金计划"。这些奖学金培养的人才几乎就铸成了中国现代科学所有学科分支的创立者，确立了现代科学在中国的位置。
