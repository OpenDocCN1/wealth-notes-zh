# ——► 概念19：源头 ◄——

大学是在社会需求的土壤上生长出来的，它是现代文明的源头。而一个国家强大的标志，是拥有 الحد一些世界闻名的学院。我们需要从文化的角度，带着演化的思维去解读它们的值。

# ——► 教会大学 ◄——

上节课，我留的问题是，由校长管理的大学又是怎么出现的呢？

因为现在世界上所有的大学全都是这种模式，反而是没有任何一个大学是由学生管理的了。其实它的起源也跟教会和皇帝的权力斗争有关系。

你想，既然有皇帝拉拢学者组织，那么教会一定也有反抗。但他们是不太去争取那些散落在各地，专门翻译阿拉伯著作的学者，因为这些人天生就解除了大堆教会抵制的內容。

# ——► 皇帝给大学的特权 ◄——

神圣罗马帝国的皇帝自从颁发了特许状之后，就尝到了甜头，因为这些学者从阿拉伯文抄写古罗马法典翻译过来之后，那些内容都是全新的，全新的内容怎么解读它，这就给学者们留足了空间。

因为他们都心怀感激，皇帝当时给了他们一个国中之国，所以在注视跟解读上都利于皇权的统治。以 后，皇帝跟教会再出现纷争的时候，皇帝就可以把传说中的罗马法搬出来，指给大主教看看，这就是我们的依据。真的就有很多时候，大主教被问得哑口无言。

# ——► 教会的反击 ◄——

教会那边也不甘示弱，他们除了成立自己的大学，也希望自己大学里的学者能解释罗马法典，看看能不能找出支持自己管理统治的内容，而且教会也在争取那些学生大学。
