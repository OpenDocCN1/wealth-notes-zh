# 科学家上班都干什么？

这个道理如果用抠鼻子的研究来说，对普通人就很好理解，但往往我们一看到类似这个生物学家研究的是“溶酶体激活清除聚积物并增强衰老中静止的神经干细胞活化”这样的题目，或者是看到一个物理学家研究的是“模卓（ji）底上吸附氘原子促进石墨烯生长的实时成像”这样的题目，一看到之后，我们就好像感觉自己跟科学完全没有关系了。

其实本质上，他们用的都是同一种思考方式，而且这样的思考方式会给我们带来启示。

# ■ 划重点

+   1. 科研工作，往往让外行人觉得和自己没关系，但实际上，科学的研究方法和思考方式，是人类目前能掌握的最有效的认识世界与指导生活的方法论。 2. 科学方法不仅在研究时用，生活中你感兴趣的任何话题，如果一定要问个为什么的时候，使用“测量+验证”的思考方式，都能得到很有参考价值的结果。
