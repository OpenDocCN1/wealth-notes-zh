# 184 | 谬误：空调真能“每晚只耗1度电”吗？

# ——►概念17：谬误◄——

有些结论因为“科学”这样的再准确，有些观点在宣称中设一再夸大。试试其中可以量化的部分进行查证，或者寻找归纳的一致性，就能识别出其中的谬误。

空调真的能一晚上只耗1度电吗？

这算是一个把简单计算运用到识别夸大宣传的实战，很多被夸大的结论，如果它在表述中就涉及到定量的描述，那其实是很容易看穿的，只要我们拥有一些基础的中学物理知识，稍加查证，就可以算出真实情况是在什么范围。

这种思考尤其对于广告宣传具有防忽悠的功能。

# ——►定量估算验真伪◄——

有空调厂商说，空调一晚上上只耗1度电，1度电多少钱呢？

在中国大部分城市都是7、8毛钱。那省电到如此地步，我觉得已经不能用惊喜来表达了，简直是省到了令人发指啊。

为什么呢？

我们来定量地看看，大家可以抬头看看自己家空调的底部，都贴着制冷量跟耗能的标签，我也拍了一张，给大家看看。

![](bbox=[0.45, 0.0017800000000000001, 0.85, 0.0025])

因为它是制冷，所以咱们看标签的上半部分，跟耗电有关的就是“额定输入功率”这一栏，我这儿写着790瓦，也就是说工作1小时，耗费的能量是790瓦·时，瓦跟时中间是乘法的关系，所以点一个点。

我们常说的“千瓦·时”就是1000瓦乘以1小时，而千瓦·时就是我们俗称的1度电。

所以我这个空调工作1小时就已经耗费了0.79度电了。

一晚上要按8小时算的话，我这要耗费3.1度电；

就算是可以有一些妥协，不总是制冷的，制冷10分钟，停10分钟，那一晚上也要耗费3.1度电。

要保证一夜1度电，大致的使用模式，那就应该是1个小时里只有10分钟制冷，剩下50分钟都是关闭的。

# ——►定量化描述◄——

那咱们进一步地来判断，实际情况，如果仔细查一查一晚1度电的宣传，它还有更多定量化的描述呢，因为它需要三个前提条件同时满足：

+   - 第一个，是打开空调的节能模式；
- 第二个，是把空调的温度设置为26摄氏度；
- 第三个关键，就是室外的温度最高不能超过28摄氏度，而且还得是一个非常小的房间才行。

因为这已经涉及到更细致的定量数据了，所以我们要挖出更多的内容才能验证这些。
