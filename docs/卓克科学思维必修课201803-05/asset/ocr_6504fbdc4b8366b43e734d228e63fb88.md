# 209 | 问答：冥想和灵修对身体有益吗？

有很多同学都问过，冥想或者灵修对身体有什么影响？

# 简单回答是：

依照场景和条件，自主地将冥想或者灵修对人是有益处的。

但是如果是社会上办的收费的灵修班，组织的培训，这都掺杂了很多虚假的宣传在里面，而且不少非但无益反而有害。

具体来说，冥想几乎是所有宗教里的一项活动，各地地方的定义不同，比如说专注冥想是让注意力集中在某一事物上，正念冥想是尽量让注意力不放在任何事物上，还有其他的慈悲冥想或者是仁爱冥想，总之是让人处于摆脱俗物的思想状态。

# —— ◆ 专注冥想 ◆ ——

长期训练专注冥想的人，保持警觉的能力强，而且对外界的刺激反应速度表现非常稳定，这个就是专注冥想对身体影响的结论。
