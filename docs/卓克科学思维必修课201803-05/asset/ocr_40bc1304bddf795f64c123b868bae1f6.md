# 176 | 成瘾：毒品疫苗真的能帮助戒毒吗？

# ——► 概念16：成瘾 ◄——

生物大脑中的多巴胺制造了一个行为模式奖励机制，形成了兴奋与满足，当对抗ees产生习惯性或依赖性，即为“成瘾”。如果对“化学物质物对人的影响”的理解，就会发现，主观意识能够把控的疆域并不很大。

这节课我们说的是毒品的疫苗，这是一种对疫苗概念的突破，因为原本的疫苗都是针对免疫系统的补充增强，而毒品成瘾的过程中并没有什么微生物的入侵，自然传统概念中的疫苗是无用的，但当科学家们作出了突破之后，我们会发现，原来疫苗还可以这样用。
