# 204 | 问答：判定“药酒没有好处”的逻辑是什么？

有同学问，喝药酒对身体有没有好处？

这个问题简单回答：

酒精对人体的害处是喝一杯就有<|message|> 的坏处，喝两杯就有两杯的坏处。在这个基础上，如果再加上各种药材，那说不定能达到喝一杯就有两杯的害处了。

# ——► 酒精的代谢 ◄——

我们先来说说酒精，对于食草性的动物来说，其实大家都有代谢酒精的能力，越是以食草性为主的动物，这方面能力就越强。

# ——► 酒精的风险 ◄——

我们先总的来看看，酒在消化道里会被吸收，送到肝脏静脉，这些含有有害物质的血液在肝脏中 N 多消化酶跟消化液的作用下会变成无毒的物质，营养吸收掉，有害物排出体外。

# ——► 草药的风险 ◄——

说完酒精的危害，我们再来说说药酒中的药。

很多人愿意从情感上相信几百年前的古人对草药疗效的判断，可是这里很多药材是有肝肾毒性的，这些毒性的具体科学分析还很不透明。
