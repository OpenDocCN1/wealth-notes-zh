可是西方就有优势，因为它使用字母文字，就算是加上那些符号，顶多200个汉字就够用了，所以在这一 点上，欧洲是占据了巨大的优势。

# ——◆ 火药与造纸术 ◆——

火药跟造纸术，这两个可以算得上是完全立得住的发明。

欧洲开始用火药的目的就是战争，时间是1770年，他们用的是三硝基苯类，俗称黄色炸药 TNT，而不是中国的那种黑色粉末的炸药。而中国黑色粉末的炸药是从北宋就开始用于战争了。

马克思提到的，把骑士阶级炸得粉碎，从这个短语也能看出，骑士阶级的衰落年代比1770年要早个好几百年，所以当年骑士的火药肯定不是黄炸药，而是中国的黑色火药。

这个火药是从阿拉伯地区传过去的，而阿拉伯人之所以有，是从蒙古兵那里学会的火药的制造技术，所以中国的黑色粉末的火药对西方的旧制度的瓦解是确实产生巨大影响的，这条可以立得住。

造纸术也是立得住的。那是公元100年左右，蔡伦就用植物纤维做材料造纸了。

反对的观点说​是古埃及的莎（suō）草纸比蔡伦的早了3000多年呢，欧洲早就 有羊皮纸了。

但其实：

莎草纸的制作工艺极其烦琐，而且莎草这种植物只生长在干 旱的沙漠边缘，所以非常不方便大量地造纸；

欧洲的羊皮纸就更贵了，很多学者都是舍不得买，反复地把墨水洗掉，在上面写下新的内容。

所以，古希腊的莎草纸和欧洲的羊皮纸的应用，实用性大概跟中国古代的活字印刷是差不多的。所以说我们采用植物纤维的造纸术相比欧洲，优势是非常大的。

比例如洛阳纸贵，就是形容公元300年左右，大家都喜欢《三都赋》，争相买纸抄写的情况。在那么早的时间就把纸张的价格降低到老百姓都用得起，所以造纸术的影响应该是四大发明里最大的。李约瑟在之前三大发明中加入了这一条还是非常有道理的。

# ——◆ 课程小结 ◆——

那么这节课，我们能从四大发明的实际情况得到什么科学思维方式的收获呢？

那就是留意常见的口号式的说法。

虽然四大发明里两个半成立，一个半是传说，按说是及格了。但问题是，如果作为这么着力宣传，代表着我们民族古代科技水平的一个引以为豪的标志性说法，可信度竟然只有将将及格的水平，那其他只是普通级别传递给公众的内容，它们的 revolution 可信度又能有多少呢？

笛卡尔对科学思维的总结就是：

> 凡是我没有明确认识到的东西，我绝不把它当作真的去接受。除了清晰分明地显现在我心里，使我无法怀疑的事情除外，不要多放一点东西到我的判断里。

这种说法在四大发明里就根本没有体现，因为四大发明的说法掺杂情感因素太多。

科学思维的方式作判断的行事风格，不只用在科研中，任何需要作判断的时候都用得上。不论是信息的接收方，还是信息的制造者。讲求科学思维的人不应该是现代社会中的异类。
