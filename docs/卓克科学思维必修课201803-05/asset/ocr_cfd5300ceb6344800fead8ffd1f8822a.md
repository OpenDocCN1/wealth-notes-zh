# ——> 概念20: 遗憾 <——

中国在明清两朝曾长期和西方科学保持接触，关系有时亲密、有时疏远。有人认为当时的中国没有发展出现代科学是因为“遗憾”，而实际上，只是必然，没有什么遗憾。

上节课最后我留了一个思考题，科学思维习惯有没有可能在中国古代生长发芽、开花结果呢？

其实这个系列我就̅要帮你回答这个问题。

那我们先要从哥白尼的《天体运行论》说起，因为这个可以算是最早以定量计算为重头戏的科学研究著作。我会给你讲讲这本书的历史研究，听过之后，你会对很多问题都产生稳固的看法。

# ——> 形而上学 <——

如果说欧洲开始走上了一条科学之路，那追溯源头还是要从古希腊说起。

那个时候，欧洲人脑子里始终存在一个高于现实世界的法则，学术化一些叫做“形而上学”，那时候的哲学把数学中的“数”，几何中的“形”奉为真理去追求。

# ——> 科学思想诞生的基础 <——

这种思维习惯在欧洲大约到一四几千年就有了改变。

# ——> 难懂的天体运行论 <——

长久以来研究科学史的人都有这么一种说法，就是《天体运行论》太难读了，这客观上保护了它，因为很久都没有人发现里面有大逆不道的内容，但其实也阻碍了人们的阅读。
