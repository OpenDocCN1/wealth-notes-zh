# 19 | 第一个细胞是怎么形成的

![](bbox=[0.0, 0.08, 1.0, 0.18])

你好，我是王立铭，欢迎来到生命科学50讲，我们继续讲细胞的故事。

上节课结尾，我留了一个关于细胞的逻辑难题。这个问题的核心在于：当地球上第一个细胞出现的时候，它是如何一下子就构成生命的所有要素——物质、能量和自我复制的功能——同时包裹到细胞膜里去的呢？

这个问题听起来有点难，但如果你仔细观察一下，会发现难以回答。

说到底，这又是一个“先有蛋还是先有鸡”的问题。这里的“鸡”是细胞膜，“蛋”是细胞膜里面的蛋白质、DNA、RNA和其他生物物质。

我们说过，细胞膜是起到物理屏障和约束作用的一种结构，主要是由特殊的脂类分子组成的。

细胞像一个装满水的气球，细胞里面的DNA、RNA和蛋白质，也是喜欢水、不喜欢油的分子。所以我们根本不可能自由穿过细胞膜，因此，也就被牢牢约束起来了。

但这样一来，问题就出现了。

如果是先有“鸡”，也就是先出现细胞膜的约束，那环境里的蛋白质、DNA、RNA等分子，就根本没法穿过来，进入到细胞内部，这样的细胞是个空泛的气球，完全没用。

反过来，如果是先有“蛋”，也就是蛋白质、DNA等分子，好像也不行。因为没有细胞膜的约束，这些分子是会更自由扩散的。还没有形成细胞，这些分子就已经在地球海洋中扩散得无影无踪了。

说到这儿，我需要插一个背景介绍：今天的细胞其实不存在这个问题，因为它能够在细胞膜上面各种各样的蛋白质分子执行运输任务。这些蛋白质分子能够形成狭窄的小孔，让各种物质有秩序地进出细胞。

![](bbox=[0.0, 0.82, 1.0, 0.89])

但是不要忘记，在第一个细胞形成的时候，这些帮助运输物质的蛋白质分子，应该是还不存在的。因为在第一个细胞出现之前，这些蛋白质分子根本没用。

这个“先有鸡还是先有蛋”的问题怎么解决呢？

你也可能想到，如果一堆类分子正在慢慢聚集成为球的结构，恰好在中部漂浮着几个DNA分子、RNA分子、蛋白质分子，这样来，它们就非常容易被地包裹在细胞膜内。

但是，如果想要这样的情形出现，那概率实在太小了。因为我们需要的可不仅仅化学应上的可能性了，还需要到几种事情在时间和空间上存在惊人的巧合。所以，关于这个逻辑难题，大家一直在寻找更合理的解释。

今天，我会告诉你生物学界提出的三种可能的解释，你也来看着哪一个更靠谱。

# 假说一：千疮百孔的细胞膜

第一种解释“鸡”，也就是细胞膜有关。有人推测，在早期的细胞生命中，细胞膜还没有这么坚固。

换句话说，早一样的细胞生命有一个千疮百孔的外壳。这样来，和生命活动相关的分子，就可以慢慢地通过这些小孔进入到细胞内了。

这个说法还得到了一些实验证据的支持。比如，在默奇森陨石上找到的脂类分子，就和现今地球上的细胞膜上的脂类分子有所不同，形成的膜的刚性也可能会松。

当然，这个假说有一个逻辑问题，那就是，如果早期的细胞真的不是千疮百孔，那么生物物质能进去，自然也能出来。

说到底，这个假说百孔，细胞膜好像也就没有什么实际用了。而且，这些远古生命是怎么慢慢地让细胞膜越来越密闭，越来越结实呢？在这个过程中，它们又怎么保证生物物质不会全部流失呢？这些问题也不好好回答。

# 假说二：能够翻转的细胞膜

我们再看第二种解释，这个解释跟“第一种解释”针锋相对。

有人认为，生命物质压根儿不需要“进去”。生命物质完全可以呆在同细胞膜的外面，而可以通过某种方法固定在细胞膜表面，不能自由离开。

这个说法在逻辑上的确能自圆其说。我们知道，细胞膜的一个重要功能就是空间约束作用，能把化学活性相关的物质、能量等要素拢在一起。

那么，不管是把它们包在细胞之内，还是将它们定在细胞外表面，其实都能达到一样的目的。

然后呢？可不知道到了什么时候，细胞膜发生一个大尺度的翻转。本附着在细胞外表面物质都会翻转到内侧。

就像是你冬天脱手套的时候，要是从手套腕部一扯，手套的外面就会翻到里面去了。

这种猜测的问题，逻辑上很完美，但是有多少实际证据的支持。当然了，有一间接证据，今天的地球细胞确实有折叠和细胞膜的能力。

比如我们身体内的白细胞，就能通过改变细胞膜面的形态，像形成一个凹包，或者伸出几只手，把周围的细菌和细胞碎片，吞到它的内部。这是第二种解释。

# 假说三：ATP合成酶的小孔是天然通道

那第三种解释是什么呢？其实，如果你回想一下上一个“先有鸡还是先有蛋”问题的解决方案，可能自己也能想到思路。

我们再来回忆一下。上一个“先有鸡还是先有蛋”的问题，说的是保存信息的物质DNA，和推动生命活动的物质蛋白质，究竟谁先出现？因为它们难以独立产生，但是同时出现、相互配合的概率又极其微。

那么到底是谁先出现的呢？我们给出的最有可能的答案是RNA。RNA既像物质又像DNA，既能保存遗传信息，又能像蛋白质一样催化生化反应的分子。

那么，“今天的”这个先有鸡还是先有蛋生命物质？RNA也是像DNA一样，一物两用，两全其美的解决方案呢？

你别急，这个思路可能真到了。具体的解决方案，实际上和我们前面提到的一种蛋白质分子有关。

你可能也记得ATP合成酶。我们之前讲能量这个要素的时候说过，它是一种非常古老的蛋白质，能够利用细胞膜两侧出现的离子浓度，维持生命运转的能量ATP。

你可以把ATP合成酶想成一个复合式分子机器，它能在细胞膜上钻出一个小孔，通过了一个带走三个小流的水分子发机器。当离子穿过这个小孔的动力，能够驱动叶片转动，产生ATP。
