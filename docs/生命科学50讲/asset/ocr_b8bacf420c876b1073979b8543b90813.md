上节课，我们回答了自我意识三个最基本的问题：自我意识是什么？它是人类独有的吗？它对生命和智慧的存在有什么意义？

这一节课，我们就来讨论一个更深层次的问题：自我意识的生物学科解释到底是什么？

我先给出一个简单的回答——自我意识的生物学基础，可能是大脑里一群特殊的神经细胞，叫做镜像神经元。

我用了“可能”这个词，是因为一直到今天，关于自我意识的神经生物学基础，关于镜像神经元在中间起的作用，仍然是一个争论不休的话题。

我们甚至对大脑中到底存在多少镜像神经元，它们主要分布在哪儿，它们的生物学本质是什么，都非常不清楚。

因此，一个非常有趣的现象是：关于镜像神经元，存在一种科学发现，多种表述，所谓“一科各家”的情况。

特别乐观的人会认为，它是塑造人类智慧的最重要的物质基础；特别悲观的人会认为，它是上个世纪神经生物学最大的谎言。

咱们的课程到现在，还是第一次遇到类似的情况：这样的困惑在整个生物学，乃至整个自然科学里面都很少见。

# 黑手党实验：自我意识的新思路

在介绍镜像神经元这个概念之前，我想先带你来思考一个问题：请你闭上眼瞎想想一下，当你自己照镜子的时候，你到底是如何判断出镜子里的那个形象，就是我们自己的？

你可能会说这太简单了，通过照片，通过录像，我就知道自己长什么样子了。当我在镜子里看到过一个长得一模一样的人的时候，我知道那就是自己。

但你仔细想想，可能就发现自己一个解释站不住脚。

在照片发明之前，在肖像画发明之前，甚至在镜子发明之前，普通人其实是不可能提前知道自己长什么样子了。更不要说放在著名的镜子实验当中，黑猩猩是从来没有使用过镜子的。

但即便如此，你把它第一次拉到一面镜子面前，它仍然可以准确地识别出，镜子里的这个形象就是它自己。这种识别过程是怎么发生的呢？

我设计了一个全新的思想实验，来和你一起讨论这个问题。我给它取了一个好听的名字——“黑手党实验”。

假设我找一二十个高矮胖瘦和你差不多的人围在你周围，每个人都穿一样的衣服，戴一样的帽子，戴墨镜，穿着黑风衣，绑着左腕手套，一副黑手党的打扮。

然后，你们十个人同时对着照一面大镜子，这个时候，你还能不能知道镜子里到底哪个人是你呢？

你还是有办法的。

比如：你偷着地做几个小动作，转动一下眼珠，皱一下眉头，扭一扭腰，就会马上知道，镜子里面在同时做同样动作的人，必然是你自己。

这个假设的黑手党实验，其实提供了一个解释自我意识的简单思路。

什么意思呢？

根据这个实验你会发现，自我意识的产生，需要综合两方面的信息。

一方面，需要采集你外部世界的信息输入，比如：看到你镜子里到底是谁正在转眼珠、皱眉头、扭腰；

而另一方面，同时需要采集关于自身的信息输入，得知道我自己现在也正在转眼珠、皱眉头、扭腰。

如果两方面的信息在时空上高度吻合，我们就会产生一个“这就是我”的想法，就能顺利通过镜子测试。也就是说，我们客观上也拥有了自我意识。

这里或许也有点得意劲，没关系，我再说得更具体一些：如果想象我们的大脑中存在这样的一些神经细胞，它能够同时检测到外部世界的感觉输入和来自身体内部的感受输入。

如果两种输入很吻合，它就会产生类似的反应。那这群神经细胞的活动，就有可能是自我意识的生物学基础。

# 镜像神经元：可能的生物学基础

那么，根据黑手党实验提供的这个解释自我意识的思路，我们大脑中到底有没有这样的神经细胞呢？

还真有，这就是所谓的镜像神经元。这种神经细胞由上个世纪90年代初，意大利神经生理学家 里佐拉蒂（Giacomo Rizzolatti）发现的。

他当时正在研究猴子的大脑是如何控制躯体运动的，于是，他就把非常细的电极，插入猴子大脑里专门负责运动的那块区域，来记录神经细胞的电传信号。

他发现，猴子的脑皮层有这么一些神经细胞，在猴子伸手去抓桌子上放着的花生时，就会产生强烈的电信号。

紧接看，当他看到花生，是负责做实验的科学家去抓桌上的花生，猴脑皮层里的这些神经细胞，也同样会产生强烈的电信号。

这也太有意思了。

也就是说，猴子大脑中有一群细胞，会而且只会对两种相互对应，但性质截然不同的事情起反应：

+   - 第一种，是猴子自己在做某件事情的时候；
- 第二种，是猴子看见别人在做同样一件事情的时候。

这个现象其实很像照镜子的过程。正因为这些神经细胞，会对互为镜像的两种印象产生类似的反应，所以里佐拉蒂就叫它镜像神经元。

结合我们刚刚的讨论，这群镜像神经元好像天然就能和以自我意识联系起来。因为它确实具备了对外在世界的感知和外在世界的印象，联系在一起的威力。

在过去20年里，对于镜像神经元的功能有各种各样的研究。

比较保守的推测认为，它们可能能够帮助我们更好地理解他人的行为。而更激进的猜测则是认知同他、共情能力等等。当然还有最高级的自我意识。

当然，这些假设也收获了非常多的反对意见。有些人甚至完全不相信，真的存在一群特殊的镜像神经元。

因为，直到今天为止，人类判断一个神经细胞是不是镜像神经元，唯一的方法就是扎入一根电极，看看它对镜子和外界的同样动作产生类似的反应。

我们也不知道这些神经元分布在大脑的哪些。实际上，在大脑的很多区域，据说都发现了镜像神经元存在。但是，又没有哪一个地方集中出现得很多镜像神经元。

我们也不知道这种神经元长什么样子，表达什么样的蛋白质，有什么的功能。

我们甚至都不能确定，人类的大脑中有没有类似的神经细胞。毕竟，我们没办法在大脑里面扎入电极做实验。
