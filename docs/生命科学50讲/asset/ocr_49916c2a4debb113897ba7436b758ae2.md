# 语言能力并不特别

其实，语言能力本身并不特别。生物个体之间任何形式的交流，都可以看成是某种形式的语言。

比如在前面两节里面，发光细菌利用“内在感应信号”来相互识别：蜜蜂的蜂后分泌一种化学物质，阻止其它蜜蜂继续变成蜂后，这就是某种化学语言。

除了化学语言，动物还演化出了更复杂的交流的形式。比如著名的蜜蜂舞蹈。

你也可以想到，几只工蜂想要形成分工合作，总需要彼此共享信息。

早在上个世纪40年代，奥地利科学家——利利（Karl Ritter von Frisch）就已经发现蜜蜂之间可以通过身体语言交流信息。

比如：采蜜归来的工蜂，会一边快速摆动尾部，一边在蜂巢上沿直线爬行。这个动作可以画而复始，重复很多次。

利利的研究表明，这个特定动作携带了非常丰富的信息。蜜蜂爬行的直线和太阳光之间的角度，就标注了食物的方向；而舞蹈的总时间，就标志着食物的距离。

其他的工蜂看准了这种身体语言，就能够集合出发采蜜，帮助它们更好地找食物。

类似的例子还有听觉语言。

鸟类世界里，有着差不多一半的物种，有非常发达的鸣叫能力，而且更重要的是，它们可以发出不同的叫声，传递不同的信息。
