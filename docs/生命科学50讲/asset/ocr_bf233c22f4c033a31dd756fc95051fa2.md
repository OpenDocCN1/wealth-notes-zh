# 03 从“博物学思维”到“生物学思维”

你好，我是王立铭。欢迎来到生命生物50讲。

前几节中，你应该意识到，今天的地球人类已经站在一个历史性的时间拐点上。

回首过去，现在我们拥有的一切都是自然历史的产物，但我们得感谢，我们已经准备大展身手。从生命科学看变化成主导者和创造者。

所以，在今天这个时代，生命科学对你不仅仅是敲门砖，它是理解过去的钥匙。理解未来的方向盘，是你作为一个现代人，脑库中必备必不可少的思想工具。

今天在第3讲里，我们就来看看生命科学的思维工具到底是什么。

具体来说，快速浏览一门学科最好的方法，是找到它理解方式的基本出发点。

比如，经典物理学理解世界的出发点就是牛顿力学。从某种意义上你可以把牛顿力学，理解为物体间力的相互作用来解释。

再比如说，在古典经济学里面，供求规律就是最核心的出发点，一切东西供求市场，价格就会上下。反之亦然，对于经济学动态都是围绕简单朴素的规则运动。

# 钻进细节里的博物学思维

生命科学的目的在于，生命现象实在太复杂了，它看起来似乎不像一个非常简单的出发。你看一眼会想到它的底层逻辑都很难发。

这就导致了在很多时候，我们理解生命，要么靠观察，要么靠直觉。我把它称为“博物学思维”。

什么叫博物学思维呢？这个词儿是我发明的，先说说什么是博物学。

简单来说，人类自有了文字之后，记录下了大量的自然现象的丰富内容之后，不同的观察、现象、描述、分类这些自现象自然发生。这就是博物学的科学研究方法。

我这说的博物学思维，指的就是用一般来描述自然现象里面，用描述的方式来理解生命现象的复杂。当我看到它们对生物体去描述、阐述，分类，不要纠结于虚无缥缈的底层逻辑。

![](bbox=[0.15, 0.96, 0.85, 0.00102])

我用两个层次来说明这个方法论。

第一层，生命活动的种类如此之多。在生命体里执行五花八门的功能，那么我们就尝试着把可能的功能都穷举出来。

比如人体的心脏和血管，帮助我们血液的循环。给身体组织氧气、供给食物。

比如人体消化系统，我们吃到胃里到大小肠，帮助我们从食物是消化营养物质。

这两个功能好像互为不相及之分。那我们就可以在两个不同的维度里分别讨论这两个问题，于是生物学中出现了两个分支——循环生理学和消化生理学。

再比如，我们的大脑是通过将近1000亿个神经元相互网络来实现功能。脑活动的，这是描述生物学中观察到的事实。

但大脑是怎么从一个受精卵而来，这就是发展生物学的研究范畴了。基于这些，不同学科之间是互补的，我们不管，反正它们单独看都有趣。

再来看看第二层，如果将生命比作一个放大镜去生物圈，在研究生命现象的时候，就是寻找进化史。因为不同的生物体，它们的生命运动形式没有更多可能地不同。

比如碳基生命都是靠氧气，但它们不排氧气。狗、牛、鸡、马、鲨鱼、蚯蚓等动物都吃素，它们只能吃素。

再以植物和动物获取能量的方式也完全不一样，前者需要阳光，后者要吃东西，吃的是完全不同的东西。

再比如同样是动物，无脊椎动物和脊椎动物获取食物的过程也完全不一样。

再来看下一物种里得思维方法——就是尝试着去研究不同生物体独特的规律。所以，动物学、植物学、微生物学等等这些学科就陆续发展出来。

但是我告诉你，这种第一类思维，不是理解生命科学的唯一方式。尤其对于普通人来说，这还是一个了解生命科学最好的入门方式。

必须得说，这种博物学思维对于专业从业者是很有用的，等于帮助我们从业者把浩瀚的知识分别地来堆积和提取。

但是对于你来说，这样选择生命科学的案例和细节，会让你迅速迷失方向并且失去探索的乐趣。

# 寻找规律的生物学思维

归根结底，我们亲近生命科学，了解生命科学不是为了成为科学家，而是为了解决生命科学的问题。生物学是科学，生物学是为了认识现实的问题。

所以为了实现这个目标，我的方法就是必须跳出细节来，去寻找宏观现象的多变性，试图找到普遍规律——也就是，找到并且思考这些门学科看世界的基本出发点。我把这种第二思想模型叫做“生物学思维”。

![](bbox=[0.15, 0.0021000000000000003, 0.85, 0.0022])

我有点气也这样说，是因为生命现象复杂，但更深层是简单的根本出发点。这里有两个根本。

第一，经过这么多年生物学的探索尝试，我们足够的信息去确认，生命现象不管具体是什么形式，它一定会遵循基本的物理化学的规律。

比如，不管生物怎么搞能量，是最终太阳通过光合作用，或者是吃的是吃，吃的是吃死是吃，本质上都是为了获取能量而来满足热力学第二定律的约束。所谓热力学第二定律的约束。

生物机体必须持续不断地从环境中获取能量，不可能热力学第二定律。对，混乱的自然能对我们生物体生命现象的有序性。

再比如，我们有DNA是地球上所有通用遗传物质，那DNA就是高度相关的。

DNA作为生命现象的有序遗传信息的存储，而且DNA分子，由于遗传信息的形成，具有两条的精确对应，这就让DNA的自我复制非常容易。而且精确。

![](bbox=[0.2, 0.0026, 0.8, 0.0027])

所以归根结底一句话，我们可以从复杂的生物学现象中提炼出，去追寻它们底层的物理化学规律。在这个意义上找到了科学的基点。

第二，从历史的维度，我们可以已经知道，现有生命的地球生命，都是漫长进化的结果。这些进化是适应环境变化而来的，它们也是空间上相对彼此的影响。

比如大象和长颈鹿。长颈鹿吃的是高处的树叶，这是两个物种在同一个时间段800万年的时候才演变成各东西。

近年人们已经提出，所有地球生命都共享同一个远古祖先，甚至早在35亿年前，可能存在一个原始的微生物体。它还生活在海底的热泉口。我们把它叫作LUCA (last universal common ancestor 最后共同祖先)。

换句话说，动物有有地球生命，它们本质上的形态和生态都来自这个 LUCA 的遗传。它们生命都从同一个祖先那里带来一些核心的生存元素。

从这个角度出发，我们也有理由相信，通过寻找生命现象的共性，我们能找到这门学科的基本规律。

承着这两条思路，我们有望实现能从“博物学”到“生物学”的跨越，不再被零碎理论束缚，就去探索，而是尝试去寻找复杂生命运动背后的底层逻辑和普遍规律。

应该说，这个思想在过去几百年的时间里取得了辉煌的成就。

今天我们可以说，地球生命现象虽然千差万别，但它们在背后的相似性远远超过了最初想象。

在生命物质构成上，在能量的获取方式上，在自我信息的记录上，在感知和外在世界的信息处理上，在社交行为的目利和繁殖上，在许多个方面，我们都能够找到共同的规则。

所以，这门学科的目标就是让你用生物学思维重新认识自己。

在接下来的40多节课里，我会把一百多年来生物学思维框架的认知升程，进行一次认真的梳理和总结。为你提供过了10件真实的生物事实和认知模型的关键细节。
