# 43 | 镜子里的自我

你好，欢迎来到生命科学50讲，我是王立铭。

今天是我们第九个单元的第一课。我想先问你一个问题：在前面的八个单元里，我们从物质到能量，从单细胞到多细胞，从感觉输入到社会生活，已经讨论了构建生命和智慧的八个元素。

如果我们在脑海中构建出一个假想的生命，完全具备前面这八个元素，你觉得它已经具有智慧了吗？

好像还不能。

比如：我们完全可以假设有这么一台机器。给它通电上，它就能够按照固定的程序开始零件装配，组装出一台和自己完全一样的机器。

+   - 它可以利用各种传感器，获得周围世界的很多信息，对零件做储存起来；
- 它可以通过代码的输入来实现学习；
- 它还能够和其他机器联网，彼此分工和配合。

你觉得它拥有智慧吗？

好像不行。也许你说不出为什么不行，但是我信，你一定会觉得那里有点不对劲。

这样的机器似乎今天我们也有能力设计制造，但是这样的机器和咱们人类，似乎差距还不是那么一点点，这就是讨论智慧的麻烦。

曾经有个美国最高法院的大法官，说起如何鉴别色情内容，他用了一句话，说这东西很难定义，但是，

> > “我只要看见它，我就知道它是不是。”

这句话用来形容人类智慧似乎也挺恰当的。给智慧下个确定义决不容易，但是，只要我看看它，我就知道它是不是。

从这一讲开始，我会跟你一起讨论构成生命的第九个要素——自我意识。

从这个名字你就能够感觉到，我们要触及人类智能的核心，也是最神秘，人类理解最难的部分。

意识到自己的存在，意识到自己和周围的世界完全区间，也许是人类智慧和机器之间最本质的区别之一。

这节课，我们就来讨论关于自我意识的三个最基本的问题：

+   1. 自我意识是什么？
2. 它是人类独有的吗？
3. 它对生命和智慧的存在有什么意义？

# 自我意识并非天生俱来

先说这第一个问题，自我意识是什么？

为了回答这个问题，现在请你想想“我是谁？”这个经典的问题。当你听到这个问的这一刻，你脑海中浮现出来的是什么图像？

所谓自我意识，指的就是这种知道世界上有“我”这么一个独一无二的个体，知道我和世界其他所有人，所有生物，所有东西所有不同的这样一种感觉。
