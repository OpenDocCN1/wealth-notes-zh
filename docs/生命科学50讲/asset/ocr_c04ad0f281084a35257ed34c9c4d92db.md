# 特别放送 | 万维钢回答：人工智能主导的“正确”世界，才是最可怕的

王立铭
你好。
昨天我回答了王维刚老师一个关于“基因演化”的问题，同时也向方老师请教了一个“智慧演化”的问题，今天就跟分享一下方老师对这个问题的回答。

请万维钢老师的问题是這樣的：
人类智演化终点，是不是让机器和算法接管一切？未来一万年有可以自利产权什么？
我们都知道，在千百万年前基本权利的时候，在面对巨大力量，比如洪水猛兽或者猛兽时，人类是没有反抗能力的。而现在的我们，可以轻易地让机器人和算法接管一切。

这当然不是坏事，但是问题是，如果人类把权利让出去了，谁来保证这些权利不被滥用？如果人类失去了判断力，谁来保证我们做出的决定是正确的？这是一个非常深刻的问题，也是我最困惑的地方。

万维钢老师的回复如下：
王老师这个问题是我们这些讲书人都很关心的。我最近也在思考这个问题，今天跟你分享一下我的看法。
我觉得，如果人类的智演化终点，是机器和算法接管一切，那其实不是坏事。因为人类最大的弱点，就是我们太情绪化、太容易犯错。如果我们把决策交给一个足够理性的系统，那其实是我们人类的一个进步。

但是，这里有一个非常大的问题，就是“谁来保证这个系统是正确的？”
如果这个系统本身是有漏洞的，或者被别有用心的人控制了，那我们可能会失去自由，甚至失去生存的权利。所以，我们要保证这个系统是安全的，是符合人类的利益的。
这需要人类有一定的掌控力，能够随时“刹车”，让这个系统停止运行。这也是为什么我觉得，人类的智演化终点，不应该是完全交给机器，而是人类和机器的结合。

我们还有一个很重要的问题，就是“什么是正确的？”
如果机器和算法是“正确的”，那这个“正确”是谁定义的？是人类定义的，还是机器自己定义的？如果是由机器自己定义的，那我们可能会面临一个巨大的风险，那就是机器可能会做出对人类不利的决定。所以，我们需要保证，这个“正确”是由人类定义的，是符合人类利益的。

我个人的观点是，人类的智演化终点，应该是人类和机器的结合，而不是机器取代人类。人类应该保留一定的掌控力，保证这个系统是安全的，是符合人类利益的。
希望我的回答能对你有所帮助。
万维钢
