# # 24 | 谁在主宰细胞的命运？

你好，我是王立铭，欢迎来到生命科学50讲。我们继续讲细胞的分工。

上一课，你知道了人身体里面，那么大规模细胞分工的简单过程，知道了细胞命运的三个转折点。

你有沒有想过，在这个过程中，无数个细胞的生命是怎么变得不一样的？

这些细胞都是来自同一个受精卵，为什么后代细胞能变得五花八门？

为什么有的细胞会变成胎儿的一部分，有的则会变成胎盘？

为什么有的会方方正正的，比如肝细胞，有的却多得毛样的，比如小肠上皮就会长成长绒毛一样的突起？

为什么有的寿命很短，比如红细胞和上皮细胞，一般只有几十天最多几个月的寿命，但是有的细胞却可以活好几十年？

是什么力量推动它们走向不同的道路呢？

这里，我想用一个物理学常用的概念——对称破缺——来对一种方式解释一下这个问题。

对称破缺的意思简单来说，就是对称被打破了。这就细胞像的分工一样。

打个比方，有一个美轮美奂的细胞，你可以把它看成一个人类彩色的球体。但是，当它从中间一分为二，变成两个细胞的时候，两个后代细胞的身份就不一样了：一个专门生产神经细胞，一个专门生产皮肤细胞。

这样一来，原本的完美对称就被破坏掉了。那么问题就来了，在生物体内，对称破缺到底是怎么发生的？

这个问题直到今天都还是生命科学研究的热点话题。因为，想要构成一个生物体，需要的细胞类型实在太多、太精细了。

换句话说，在生物体内部，对称破缺发生的次数太多、过程又太多样了。所以，仍然有许多关键的细胞运命运没有得到理解。

今天，我想帮助你简单地了解一下其中根本性的生物物理原理。

> 一句话概括：细胞的对称破缺，是内因和外因共同作用的结果。

你肯定会说，这又是怎么解释的呢？好吧，我这里先不给你透露答案，但通过本讲，你会发现，这句话是非常准确的。

这一讲，我就具体解释一下，为什么说细胞的分工、细胞的对称破缺，是内因和外因共同作用的结果，即内因和外因又是怎样起作用的。

# ## 分工的外因：环境中化学信号的强度

先谈外因，也就是环境因素。外因导致对称破缺，原则上很简单。

我们可以想象一个完全对称的球形细胞，要进行细胞分裂了。与此同时，这个细胞所在的微环境中，有一种化合物浓度分布不均匀，比如在左边，浓度比右边高。这种化学物质可以接近，甚至进入细胞，影响细胞的命运走向。
