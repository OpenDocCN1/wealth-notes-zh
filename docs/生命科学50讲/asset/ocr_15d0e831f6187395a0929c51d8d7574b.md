# 30 | 嗅觉与味觉为什么“不智能”？

你好，欢迎来到生命科学50讲，我是王立铭。这一讲我们继续讲感觉。

不知道你有没有听过一个比较振奋的猜测，它是说：主要依靠视觉信息输入的动物，才可能发展出高度的智慧。

虽然现在有好多史上最亮的实验基础可以证明，但是今天地球上最聪明的那些动物，包括人类、猩猩、海豚、大象，确实也都是以视觉信息为主的。

我的猜测，这些可能是因为视觉信息，或者说人更广一些，光这样的电磁波，在准确反映环境变化、承载丰富的信息这两点上，要比其他的**躯体**都强大。

所以你看，天人类卫星里使用的交流工具，比如手机、电器卫星，还有互联网，也确实都是利用电磁波作为载体的。

如果我这个猜测成立，这就意味着，如果我们有一天能够找到有高度智慧的**外星人**，在很大程度上，它应该也会长着类似眼睛的**高级视觉**，依靠收集环境中的电磁波信号感知世界。

那么反过来问呢？如果不是视觉这样基于光、或者广义的电磁波的感觉，而是基于味觉和嗅觉这样的感觉系统，有可能支撑智慧的诞生吗？

我个人的观点是：几乎不可能。

为什么呢？这就需要我讲清楚味觉、嗅觉和视觉到底有什么不同了。

这一讲，我们就从信号源的性质、信号采集、信号处理三个层次，来理解一下其中的区别。

# 信号源：光与化学信号的区别

第一个，我们先来看看信号源的区别。

视觉系统感受的信号是光信号，或者更广义地说是电磁波信号。这一类信号有三大特点：

+   1. 直线传播；
2. 光速传播；
3. 不依赖具体的介质。

这三大特点就保证了，根据视觉信息的输入，动物能够非常准确和及时地判断物体的位置、大小、运动方向等信息。

甚至在外星球，在宇宙深处，没有大气的地方，视觉信号也是可以发射和采集。

对比起来，嗅觉和味觉系统，它们感知的是具体的化学物质。
