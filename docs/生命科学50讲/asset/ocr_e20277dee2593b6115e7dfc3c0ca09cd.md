# 26 | 缸中之脑：我只是我的感觉

你好，我是王立铭，欢迎来到《生命科学50讲》

从这一讲开始，我们进入课程的下半部分，来讲讲智慧的生物学。

我们总是喜欢带着点淡淡的优越感，表达这样的意思：咱们人类这种跑得不够快、跳得不够高、不怎么会游泳、力气也不大的生物，能够站在生物圈的金字塔顶端，靠的是独一无二的人类智慧。

但是，“智慧”到底是怎么一回事呢？

老实说，“智慧”这个词儿太大、太复杂了。感知外部世界、学习和记忆、运动、情感、理性思考、自主意志，这些似乎都可以说是智慧的一部分。

想给它一个简单好记的定义也不是那么容易，更别说彻底搞清楚它的生物学原理了。

但是，按照咱们前面那么多讲的经验，我们还是可以利用生物学思维，从复杂多样的智慧现象里，抽象出一些放之四海而皆准的元素来，和你一起逐层解构成人类智慧的规律。

所以，从这一讲开始，我会用五个单元的内容，带你剖析人类智慧的五大元素。

而第一个元素就是感觉，因为感觉对智慧生命至关重要。

# 感觉是智慧的基础

为什么这么说呢？首先，我们要知道什么是感觉。

简单来说，感觉就是生物体从外部世界获取信息的过程。感觉是人类作为一种智慧生命，和环境互动、甚至改变环境的基础。

当然如果你说有点儿悬，我拿来两个例子证明这个观点。

第一个例子——注意。

有很多人认为，注意这种能力就是最底层的智慧。这话说得有点牵强，注意这东西会不会有，也算个能力？不过我得说，其实这是很有道理的。

我们就拿视觉做例子，我们的眼睛能看到光，但是外部世界的光源实在太多了，大白天走在大街上，几乎周围的所有东西，不管是尺寸、形状、颜色，都在用光信号吸引你的注意。

这个时候，你的眼睛得先选择盯着一眼哪里了解个大概，再选择盯着哪里搞清楚它的细节本身选择反映着，你的大脑对外部信息重要程度的区分。

而且，这个倾向还会受到你的认知能力、你的经验、你的内在状态的影响，比如：

+   - 一个男生在大街上走，更容易注意周围的美女；
- 一个小偷可能更注意周围人的钱包；
- 一个流浪汉更容易注意哪里有垃圾，等等。

而在注意之后，更复杂的神经活动，比如：情绪变化、理性思考、采取行动，才有可能发生。
