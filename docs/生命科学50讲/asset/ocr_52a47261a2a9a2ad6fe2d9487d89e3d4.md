# 36 | 假如记忆可以移植

![](bbox=[0.1, 0.08, 0.9, 0.13])

你好，欢迎来到生命科学50讲，我是王立铭。

今天是我们学习单元的最后讲。在前面的几节课里，我们讨论了学习的生物化学本质，也讨论了如何人为地增强或者削弱学习的能力。

今天，我们讨论一个更科幻，也是你更关心的问题：我们有没有可能在大脑里面造一段虚拟记忆，甚至移植一段别人的记忆呢？

这问题虽然听起来科幻，却是人类永远的命题。就连高考考作文文，都曾经在1999年使用过《假如记忆可以移植》这个题目。

为什么我们那么想出虚拟记忆，甚至要直接移植记忆呢？

原因很简单，现在是一个信息爆炸的时代。每一天，人类世界生产出的数据都超过了古代社会上千年的总和。

这么多信息，怎么生产、存储、传播，就已经是非常大的技术难题了。更重要的是，我们人类的大脑该怎么适应这个信息指数增长的时代？

要知道，人类大脑的体积和结构，从人类出现到现在二十多万年中，都没有发生过显著的变化。这般大脑里面处理信息、学习和记忆的能力，应该也不会有什么飞跃。

那么这样一来，人类信息生产的能力，和人脑学习功能之间的差距只会越来越大。

因此，如果能有个办法实现人工模拟学习，甚至为人脑锻造移植记忆，那就太好了，一劳永逸地解决了问题。

好消息是，赫布定律也确实给了我们一个理论上的可能性。

你看，根据赫布定律，学习的本质就是两个总是差不多同时活动的神经细胞，它们之间的联系会被增强。

也就是说，我们有办法能够人为地让不同的神经细胞总是同步活动，我们就可以人为地增强它们之间的联系，从而创造出虚拟的学习和记忆来。

前面几讲的课程里，我们也讲过类似的思路。比如，我们可以往神经细胞里面插入微电极，通过放电的方式激活神经细胞。

打个比方，我们如果能在巴甫洛夫的狗的大脑里，找到口水细胞和铃铛细胞，然后在这个两个细胞里，分别用微型电极插入电流进行训练，就可以完全不需要狗粮，而不依赖经验，让这条可怜的狗在听到铃铛的时候流口水。

但是，这个思想实验听起来好，却没有什么可操作性。这主要是因为两个原因：

+   1.  第一，动物大脑里的神经细胞实在太多了，根本不可能到哪些细胞是负责什么的，代表了什么记忆。
2.  第二，在动物脑袋里插电极是一个破坏性很大的手术，在活的动物脑袋里，扎上成百上千的电极，动物根本不可能保持头脑混乱和清醒。

# 两种武器：定位记忆和唤醒记忆

没想到，过去几十年里，神经科学家们居然获得了两个非常强大的武器，把这两个技术难题都给解决了。

这第一个武器，能让神经科学家们准确地找到代表一段记忆的神经细胞。

这件武器的原理是这样的。我们已经知道，一段记忆在大脑中的呈现方式，大概就是很多相互联系的神经细胞的集体活动。

但是，怎么找到这群总是一起活动的细胞呢？我们发现，某些细胞被激活之后，会启动启动脑部某个基因的开启。

这个基因具体是什么的，我们暂且不讨论，但是我只要强调，利用分子生物学技术，基因的活动是可以被准确追踪的。

因此，只要在动物的脑子里，看哪个基因在某些时候经常被启动，我们就可以反过来推测，这些神经细胞刚刚被同时激发了。而某些细胞当然就代表着刚刚发生的一段记忆。

![](bbox=[0.3, 0.36, 0.8, 0.4])

第二个武器，是让神经科学家们能够遥控神经细胞的活动。

这个武器实际上是一个来自海藻的蛋白质分子。这个蛋白质分子被海水照亮之后，能发生结构变化，在海洋细胞里产生一个电信号。

对海洋藻来说，这个蛋白质是很重要的，它能帮助准确地找到太阳光的位置，进行光合作用。

而它对人类科学家更重要。只要把这个蛋白质拿出来，放到动物的神经系统里，动物的大脑就具备了海藻的本事：能够被光激活。

有了这个蛋白质做秘密武器，神经科学家们就不要再做微电极了，他们只需要在神经细胞里面放上这个蛋白质分子，然后远远地照亮，就可以人为地控制这些神经细胞被激活的时间。

这两件武器加在一起，能产生巨大的威力。

这第一个武器能够告诉我们，某一段记忆，在动物的大脑里具体是由哪些神经细胞代表的。第二个武器呢，能够让我们利用光，准确地操纵许多个神经细胞的活动。

那我们是不是可以用第一种武器，在动物大脑里定位一段记忆，然后用第二种武器，随时随地唤醒这段虚拟记忆呢？

甚至，利用同样的思路，我们是不是还可以把一只老鼠的记忆，移植到另一只老鼠的大脑里面？

# 移植记忆：临场其境得实现

就过去几年里，美国麻省理工学院的利根川进（利根川进）实验室，首先做了这方面的探索。

他们的做法可以分成两个步骤，其实也就是先后利用这两种武器的过程。

首先，他们把老鼠放到一个全新的环境中。利用第一种武器，我们可知在老鼠的脑子里，哪些神经细胞同时开始活动了。这些信息就代表着对这个新环境的一种场景记忆。
