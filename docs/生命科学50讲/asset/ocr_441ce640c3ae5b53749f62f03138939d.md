分工这个词你肯定不陌生，在人类世界里，它能带来很多好处，比如：提高效率、降低成本和互相协作。

对于地球生命来说，它的每一个细胞之间也存在分工。这是为什么呢？分工到底有什么好处呢？我们下讲讲详细展开，先吊吊你的胃口。

这一讲，我们先解决生命学分工的一个原理问题，也就是说，在这种细胞之间的功能分工出现之前，细胞生命必须还得完成一件事。

那就是，在生命体内首先得有超过一个细胞，这些细胞之间才有可能发展出不同的功能来，才可能配合和协作。

所以，为了讨论细胞的分工，我们首先得讨论这个先决条件：单细胞生物是怎么变成多细胞生物的？单细胞生物为什么要变成多细胞生物？

按照常规，我们应该先讨论“为什么”这个问题，再讨论“怎么变”这个技术来问题。但是在这——我想换一个顺序，先讨论“怎么变”这个技术问题，至于原因呢，我们稍后再揭晓。

# 单细胞生物如何变成多细胞生物

怎么变成多细胞生物，这个过程在技术上还挺简单的。

我们首先想象一下，一个单细胞生物怎么繁衍后代。这个过程如果用一个词来概括，就是“分裂”。

细胞长大成熟，在这个过程中，遗传物质DNA首先完成自身复制，分裂到细胞的两边。然后，细胞从中间断开，一分为二，产生了两个新生细胞，它们各自独立生活。

就这样，细胞生命的繁殖，或者自我复制就完成了一个循环。

![](bbox=[0.05, 0.73, 0.95, 0.83])

你脑海中如果有了这个细胞分裂的场景，理解多细胞生物的出现就容易多了。

最简单的思路就是，如果单细胞生物分裂之后，产生的两个细胞没有分开独立生活，而是一直黏在一起，就这样一分为二，二分为四，产生的后代细胞总是不分开，总是固定在一团，那一个多细胞生命就产生了。

说到底，我们每个人都是从一个小小的受精卵分裂而来，这背后其实也是这样过程。

而且我还得强调，让细胞分裂之后产生的两个后代细胞彼此不分开，这件事实际上是挺容易的。

一个有力证据就是，生物学家们在实验室里已经能重现这个现象了。

比如，有研究发现，只需要改变酵母细胞内遗传物质DNA上的某一个位点，就能让酵母细胞只分裂一次。最后，这种单型的单细胞生物，就会变成一片雪花一样的多细胞形态。

![](bbox=[0.05, 0.00108, 0.95, 0.00135])

既然实验室里能非常轻易地实现这个过程，你就可以想象，在地球生命演化的过程中，多细胞生物形态的出现，也应该是挺容易的。

实际上也是如此。通过分析今天地球上多细胞生物的遗传信息，人们已经可以推测，在整个生物演化的历史上，多细胞生命形态至少独立出现过46次。也就是说，今天地球上的多细胞生命，有至少46个互相独立的源头。

你看，这个好像比出现LUCA（地球生命的最后共同祖先），比出现ATP合成酶，比出现线粒体这些生命事件要容易多了。

说到这儿，我们基本解决了多细胞生物出现的技术问题，也就是“怎么变”的问题。我们才讨论这个问题，也是因为好解决起来比较容易。

但是接下这个“为什么变”的问题，就没那么容易了。为什么多细胞生命会出现呢？

# 多细胞生物：为了更好地吃和避免被吃

你可能都不觉得这是个问题，生物进化从简单到复杂，从低等到高等，从单细胞到多细胞，这不是规律吗？

还真不是。我们上一个单元讨论过这个问题，地球生物演化根本没有方向性可言，只要能存活下来，就能繁殖后代，这样的生物都优优势，就会占上风。

从地球生命出现，到多细胞生物出现，长达20多亿年的时间里，地球上只有单细胞生物。一开始是细菌这样最简单的单细胞生物。在能量革命之后，出现了携带线粒体的单细胞生物。

但是无论如何，它们都还只是单细胞生物。即到了今天，地球生物里数量最多、种类最多、可能也是总重量最多的生物，仍然是单细胞生物。

所以，多细胞生物的出现可不是什么历史必然。

我们可以反过来说：多细胞生物这种形态的出现，在技术上是虽然简单，但是既然它们出现之后还能存活下来并且活得很好，这本身就很说明，多细胞生物一定得具备什么特别的生存优势才行。

只有找到了这个生存优势，我们才能真正理解多细胞生物为什么会出现。

在这里，我先给出一个高级版的答案：多细胞生物的出现是为了更好地吃，也是为了更好地避免被吃。

其实，在之前的单元里，我们已经好几次提到过单细胞生物可以互相吞吸，比如细菌革毛的起源可能就是一个个大个的细胞，吞吸了另一个较小的细胞，但是却没有把它当食物消化掉，反而让它寄生在自己体内生产ATP。

实际上在单细胞生物之间，猫捉老鼠、老鼠躲猫的游戏，大概已经进行了好几亿年。

可想而知，在这场生存竞争中，个头大一点是有好处的：对于捕食者来说，个头大就意味着有更强的吞吸能力；对于被捕食者来说，个头大，也许就能逃脱魔掌。

但是怎么变大呢？

上一讲，我们讲过一个思路：拥有了线粒体之后，单细胞生物有了更多的能量，当然也可以长得更大。

但是我们必须记得，虽然线粒体提供了几乎没有上限的能量供应，但是单个细胞的尺寸还是会有物理极限。
