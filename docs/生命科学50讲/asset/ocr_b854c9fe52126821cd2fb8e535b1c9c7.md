# 自由意志是什么？

首先，我们来着什么是自由意志。

围绕自由意志这件事，人类哲学家已经进行了超过两千年的思考和争论，光是自由意志这个的定义，都可以讨论很久。

当然了，在生命科学50讲里，不需要太过纠结这个问题的复杂。

为了简单起见，我们就把它有一个比较通俗的解释：我们一个人，是否能够自主决定自己此时此刻的思想和行为。

或者换个法，某个时刻下表现出来的一切具体的思想或行为，到底是谁决定？是自由意志，还是早已被决定好了？

你也许觉得“早就被决定好了”这个概念比较难得，不过想一想就懂了。这句话的意思是，你的思想或者行为，是在此之前发生过的所有事情，叠加在一起带来的必然结果。

所有事情包括你的遗传基因、生活经历、做决定之前的外部环境、吃没吃晚饭、精神好不好、心情如何、面前的人穿红色还是绿色、等等。

所有这些因素加和起来，造就了一个无可更改的决定。
