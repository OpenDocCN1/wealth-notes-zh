# 自我意识：顽固还是灵活？

我想先通过两个思想实验来开始我们的讨论。

第一个实验，我叫它“完美复制”实验，这也是不少科幻小说曾经用到的情节。

假设有一天，人类发明了一个机器，能够以原子级别的精确度在几乎一瞬间扫描你的整个身体，然后完美地复制出另一个人来。

那么，你原来的自己和这个新出现的副本，会为彼此是同一个你吗？

如果这时模拟让原来的那个人死去，因为反正已经有一个一模一样的副本了嘛，原来的那个你愿意吗？

或者让新复制出来的这个你捐献给，治疗原来那个你的疾病，新复制出来的你会同意吗？

这个思想实验估计让你有点头大，但是仍然值得你花上几分钟思考一下。我给出的答案是不会。

在前面几节课里我们讨论过，自我意识这件事，实际上本质意识过“我”这个概念，和时间上物质万物、所有的同类、都截然不同的这么一种独一无二的存在。

或者说得再直接一点，任何一个“我”都具备天然的排他性，都会以除了自己以外的所有东西认定是“非我”。

既然如此，无论是人体和人造复制技术有多么高明，创造出来的每一个人，都会拥有独立的自我意识，并不会产生意识上的混淆，更不会慷慨地做自我牺牲。
