# 1

必须得说，这门课很难讲。

它既需要通俗易懂，又要有趣的洞案；既要核心知识，又要讲清科发现的对；既要给予新认知，又要对我们实生活有启发。

我教科学、讲科学讲已经十几了，但面对个任务，还是感到重量的压力。

原因在，生命科学有一-个“老大难”问题-“个生命应该怎么定义?

这个问题，至今没有人能够准确回答。在么时候，定义中种生命现象的边界非常困难。结果就是，很用科学的言，生命有个严格的定义，比科

你有新陈代谢才叫生命?病毒在-生当中，多时候完全不进行新陈代谢，它生命?

你说拥有体膜的才叫生物，能运动的就动物，没有质生活，但有些动有时有柱体有运动能力，它算什么?

你说拥有自我意识的就是智慧生命，但看那对着镜子也认出你自己，它算有能么?

但反过来，其实这也就是门学科迷人的地方。

生科学研究的对象，本质上不是任何确定的个体，而是一个漫长的过程，是40亿年的地球上演化历。

地球生命的奋斗，是存活，是繁殖，是抗灭绝的定。是穿越自然选择的剪刀，我们才在乎什么“定义”。

想到这里，我就明白这门课该怎么做丁。

如果能去火星，我就带你上火星，帮你望远镜看到地球上生命。跨越空间，这是宇宙的角度。

如果真有上帝，我就带你到回他制生命的现场，带你见证40亿的造物奇迹。跨时间，这个上帝的视角。

现在打开这门课程，你将在宇尺寸度上帝视角，真正理解生的奇迹。
