# 38 | 团结就是力量

你好，欢迎来到生命科学50讲，我是王立铭。这一讲，我们继续介绍社会的生物学。

上节课我们讲到，社交是费氏弧菌繁衍和竞争的新策略。这种细菌聚集在一起发光，能帮助自己更好地生存。

实际上，这样的社交行为在动物里很常见。

荒野上的狼群集体捕猎，可以杀死比自己个头大得多的猎物。反过来，食草动物，比如斑马和羚羊，也会集体行动来吓跑一部分捕食者。

毫无疑问，这些行为能够帮助动物们活得更安全、更有效率。所谓团结就是力量嘛。

> 其中，最能体现这种团结的力量，最能展示精密的分工合作的，就是所谓的真社会性的生物。

世界上有什么真社会性的动物呢？最容易想到的就是蜜蜂和蚂蚁。地球上已经发现了超过17000种真社会性动物，除了一种哺乳动物，其它的大多是蚂蚁和蜜蜂一类的昆虫。

这一类生物除了存在分工和合作外，还有一个特别重要的特征，就是它们当中有一部分个体，彻底放弃繁殖的权力。

你看，这一点是不是很像微观层面上，我们身体细胞之间的分工？红细胞也好，皮肤细胞也好，神经细胞也好，为了执行它们的功能，也确实都放弃了自己的繁殖权力。

你会畏小瞧了这种动物。在自然界，真社会性昆虫只能占到所有昆虫种类数的区区2%，但是它们的生存和繁殖能力非常强，以至于它们全部个体的重量加在一起，超过了所有昆虫的一半。

这么强的竞争力是怎么做到的呢？今天，我们就来好好研究一下它们。

# 竞争力来自社会协作

一句话总结，它们的竞争力，全靠复杂的社会协作。

如果你见过蜜蜂的蜂巢，哪怕仅是见过它的照片，你肯定会惊讶于这种建筑结构是多么气势恢宏。

我们在设计方案，这些身材那么小的虫子，是知在没设计图，也没统一的指挥的情况下，修建出严密的六角形结构蜂房的。

![](bbox=[0.2, 0.71, 0.8, 0.81])

特别是，你还要考虑到蜂巢的原材料，要每一只工蜂身上一滴一点的分泌，而且要全程，显然得不到任何现代科技和机械的帮助下，这工作得难度应该要比这及人修建金字塔，还要大得多。

而在严密的建筑结构背后，支撑它的更加严密的社会结构。

我们还是拿蜜蜂做例子。

一窝蜜蜂可能有上万只，但它们当中只有一只蜂后，专门负责生育后代，每天吃得以后能生出上千个卵。蜂后的后宫里有几百只雄蜂，专门负责和它交配，提供精子。

在外国，有成千上万只工蜂，负责所有的日常工作，这里包括修建和清理蜂窝，照看蜂后，采花粉喂养后代，抗击入侵者等等。

而负责干洗的工蜂内部，也会继续出现更精细的分工。比如：刚刚发育成熟的工蜂是不会飞，因此主要做内部工作，像清理蜂窝，给幼虫喂食。

而这一两个月之后，等它们逐渐长了翅膀，学会了飞行，它们才开始做外部工作，比如采蜜和保卫家园。

你可以想象，这个更加细致的分工，当然是很有意义的，让工蜂做到了一尽其长。

说到这里，你也能看出来，这一窝蜜蜂像个多形体的复生生物个体。蜂后和雄蜂是它的生殖细胞，而所有的工蜂都是它的体细胞，而且具有精细分工的，不同类型的体细胞。

从蜂巢里单独抓任何一个蜜蜂，它们生存能力和行为都是极为有限的，但是上万只蜜蜂在一起，依靠这个复杂的社会组织，它的伟大工程。

# 蜂后：The Chosen One

那么，这种严密的社会结构和分工合作，在生物学上是怎么实现的呢？

> 你可能不知道，蜂后和工蜂，实际上在遗传物质层面，是高度相似的同姐妹，而且天生都具备生殖能力。它们的差别是在出生之后，被环境塑造的。

简单来讲，蜂后和工蜂在幼虫阶段，吃到的食物非常不一样。

在成千上万的卵里面，负责照顾幼代的工蜂会随机挑其中一个，用营养更加丰富的蜂王浆来喂养。

这样一来，它长大以后会体型更大，长出非常丰满，而且会生育非常多的后代，它就是独一无二的蜂后了。

我们经常说谁谁擅长干什么事情，是天之骄子，的chosen one。你蜂后才是真正字面意思上的the chosen one。

相反，没有任何花蜜，只能吃相对没有那么营养的花蜜，它们的体型比较小，生殖器官也退化了，变成了勤勉勤劳的工蜂。

![](bbox=[0.15, 0.0015400000000000001, 0.85, 0.00165])

更有意思的是，那只被挑出来的蜂后长大以后，还会专门分泌一些化学物质，保证其它蜂王幼虫都只能变成工蜂，确保它独一无二的权力。

# 利他主义的生物学原理

讨论到这里，你有没有发现出现了一个新问题？

之前我们说过，在多细胞生物体内，生殖细胞和体细胞也出现了类似的分工，前者负责繁殖，后者放弃了繁殖权利负责干活，共同保证这个个体可以很好地生存和繁殖下去。

但是蜂后和工蜂是完全不同的生物个体，工蜂为什么要把它的自私让，一辈子勤勤恳恳，帮助别人的繁殖呢？

这种现象，在生物学有个专有名词，叫做利他主义。

在历史上，这种现象曾经对达尔文的进化论造成很大挑战。而目前来看，我们可以逐步理解利他主义的生物学原理。

想到进化论，你肯定知道这样的说法，“物竞天择，适者生存”。谁能生环境中生存，繁殖后代，谁就会被选定为自然选择的赢家。

换句话说，在达尔文提出进化论的时候，自然选择的对象很明确，是一个个的个体，“个体选择”。

很明显，蜂蜂们刚才才的讨论，这一点和真社会性生物的生存方式矛盾。按照经典的进化论，不繁殖的生物总是被淘汰掉的。所以，针对很多真社会性生物，来陆续提出了很多的学，

首先登场的是“群体选择”学说。

这种学说的逻辑是，自然选择的对象，其实不生物个体，是群体，甚至是整个物种。
