# ## 已知的未知

其实，面对生命和智慧，还存在大量己知的未知——也就是那些我们知道自己还不知道的东西。

先说说生命。

虽然课程讨论了五大元素：物质、能量、自我复制、细胞、和分化。这些都是地球生命大厦最重要的梁柱。

但是对于这座生命大厦，我们还有太多的建筑细节仍旧面目模糊，比如：

米勒的烧瓶实验，让我们知道了生命物质没什么特殊的，但同时这个实验也证明了，在原始地球浩洋中，肯定诞生过更多的氨基酸分子。那么，多出来的那些氨基酸为什么被废弃？

我们知道生命遗传物质是DNA和RNA，但果，不知道为什么DNA和RNA不约而同使用了四种碱基作为基本的结构单元。RNA世界的假说，真的代表了生命的起源么？

如果当真如此，第个RNA生命会是什么样子？它又是从什么时候开始，把使命转交给DNA和蛋白质的呢？

我们知道，细胞膜的构构非常容易形成，在澳大利亚的莫若索陨石上都搜找到来，那么既来之，细胞膜究竟是怎么来外客，还是地球土生生的？除了薄薄的磷脂双分子层，地球生命为什么没有发展出任何别的办法造细胞，包裹自己呢？

我们知道，多细胞生命在地球上反复出现过很多次，也可以想象，它们当中的大多数都没有繁衍到今天。

那么，那些不幸的多细胞生命谱系，究竟是为什么原因而墙谢？

单细胞生命可生可灭，多细胞生命如何一定会衰亡衰老？它们的寿命是由什么决定？为什么在我们身边，会同村在只能活几天的蜉蝣，和万年不死的犬树？

总之，关于生命活动，还存在大量已知的未知。

接下来我们再看看智慧。

我们讨论了智慧的五种元素：感觉、学习、社会、自我意识和自由意志，一步步挖掘出智慧发生的底座规律。但是对它们，我们尚未了解细的更是多了。

至今为止，我们虽然开始了解感觉信息是如何被收集的，但是，对于感觉信息怎样在大脑皮层，被重新组装成一个天衣无缝的虚拟世界的，我们仍然几乎一无所知。

我们虽然开始知道，学习的过程在神经细胞是面大脑是如何发生的，但是，我们还不知道形志是存储着大脑中，到底是由什么具体形态存储在单个的脑中，又是由谁提取的，更不要说试图把一个人的记忆，转移到另一个人的脑袋里，或者用计算机人工制造记忆了。

# ## 未知的未知

其实，这些“已知的未知”只是给未知开了一个遗遍。

面对地球生命和智意现象，更无奈的是，我们还大多“未知的未知”一也就是说，我们甚都不知道还不知道的东西。

什么是我们不知道的？我们实在技术手段、数学习具界世界观，我们有缺陷。

我们都承认，复杂生命，从简单细菌到人体一都是个复杂系统，其复杂性远远超过人类研究过的任何对象。

粗地估计一下，人体任意一个细胞内会有上万种、几百万上百亿个蛋白质分子同时存在，并且开始工作。

从某种意义上说，想要理解区区一个细胞的生命活动，我们得对这么多蛋白质分子的区间、分布、数量变化、三维结构形成之间的协同工作，都要有深人的理解和计算，还必须考虑到这一切都发生在几百到几千立方米、几秒到几十秒的时间空间带内。

这还仅仅是一个细胞。

考虑到人体有上百万亿个细胞，考虑到这上百万亿的细胞都自区区一个受精卵的得分裂，考虑到这上百万亿个细胞之间的合作，我们可定不会否认，对于理解生命现象，我们缺的可能不光是知识，更是观察和分析复杂性的技术手段，数学工具，乃至世界观。

说到这，我想请你想想，我们有没有可能打破“未知的未知”呢？或者说，如果我们能做到，我们已很办到了呢？

我知，关于生命，如果我们能够在实验室从无到有地制造出，一个哪怕是非常粗模粗范的新生命，能够存活，繁殖，和环境互动，那我们就自以骄傲地说，我们已经在很多方面了。

不过很遗憾，这一天仍然遥不可及。用技术资源和资源层面的，而恰恰如前所述的时空尺度和复杂系统的观察力，我们对生命现象的把握，更多地时候都仅停留在“我们知道什么东西”的水平上。
