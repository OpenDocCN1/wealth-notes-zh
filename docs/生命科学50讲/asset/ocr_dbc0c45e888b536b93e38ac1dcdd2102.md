# **维勒实验：击穿活力论**

放进第一道[光]的人，是德国化学家弗里德里希·维勒（Friedrich Wohler）。

有点讽刺的是，维勒只是贝利乌斯的学生，是那个提出“活力论”的瑞典人。

咱们先来复习一下“活力论”。它认为，生命之所以是特殊的，是因为生命带有“活力”，而活力来自于生物体内的化学物质和化学反应。这些物质在自然界中找不到，这些反应也不会在自然界中发生。

但1824年的一个实验改变了一切。

这一年，维勒试图在实验室中合成一种新的化学物质。实验结果出乎他意料，烧瓶里生成的白色晶体看起来有点陌生。

实际上，维勒一直到1928年[才最终确认]这个东西是什么，而这个结果对于贝利乌斯的学生来说太魔幻了，太难[以接受了。]

原来，这个东西是尿素。顾名思义，这是一种存在于生物尿液中的东西。长久以来，人们一直认为尿素就是一种典型的活力物质。请注意，维勒的实验里面，两种原料物质都是可以从自然中获取的。

所以这个结果说明，生命体内的物质是可以在实验室里从无机到有制造出来的，这什么特别的。“活力论”的天花板就这样被捅了个大窟窿。

插个八股。1982年，维勒去世100周年的[时候]，德国专门发行了一枚邮票纪念维勒的实验，因为这个实验除了成功合成了尿素之外，还有更深远的意义。

![](bbox=[0.15, 0.341, 0.85, 0.395])

稍微引申一下，那些传统上认为只有生命体才有的活力物质，居然可以在实验室里很方便地合成。既然如此，地球生命的物质基础好像并没有我们想象的那么神秘。

顺着这个逻辑往下推演，可能不光是物质，也包括生命体内进行的化学反应，还有生命的结构、繁殖和生存方式，甚至智慧形态存在，也不都是设计什么神秘的，也都能在实验室里面很方便地解剖、分析、甚至制造[出来？]

换句话说，就是从维勒实验开始，人们才[开始]觉得生命现象是可以被揭示、被操纵、甚至是可以被预测和改造的。

从这时开始，人类科学家真正开始了理解生命现象的探索过程。

# **烧瓶里的原始地球：生命物质不特殊**

当然了，不管我们怎么引伸维勒实验的结果，尿素毕竟只是一种不复杂生命物质。我们必须要追问一句：构成生命体的核心复杂物质，比如DNA、蛋白质，是不是仍然只有生命才能生产呢？

如果是，那么似乎可以说生命物质在某些独特性。仅是维勒实验，并没有让“活力论”死去。

彻底葬送生命特殊论的杀手在1952年出现了，此时距离维勒实验已经过去了128年。

这个[杀手]叫斯坦利·米勒（Stanley Miller），这个史加哥大学上的博后生的人[物]，现在是芝加哥大学上的博后生的人[物]，对地球生命的起源问题产生了浓厚的兴趣，成功说服了自己的导师，做了一个特别有创意的实验。

实验本身其实很简单，但野心却非常大。

米勒模拟远古地球的环境，准备了一个大大的烧瓶，里面灌上水，模拟海洋，然后在烧瓶底下加热，模拟海洋的高温。他在烧瓶里面充上气体，比如甲烷、氨气、氢气，模拟原始的地球大气。除此之外，他还在烧瓶里面充上电，[电]击发生电火花，模拟远古地球大气上的雷鸣闪电。
