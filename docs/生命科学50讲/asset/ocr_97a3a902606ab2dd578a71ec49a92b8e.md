结果当然就是，不管这个老鼠此刻正身处哪里，只要亮紧了那十个排成五角星的神经细胞，老鼠就会以为自己身处 A 笼子里；而只要亮紧了 15 个排成圆圈的神经细胞，老鼠就会以为自己跑到了 B 笼子里。

所以利根川进他们就样，成功地把老鼠带入到一段虚假的记忆当中。

利根川进他自己就说，也许这个研究未来用在人体内，可以帮助那些刚从战场归来的士兵们，彻底擦除战场的可怕记忆。

毕竟人类文学艺术作品的一大追求就是现场感，能让人感同身受，进入一个从未经历的场景中去。而利用这两种武器植入虚拟记忆的方法，肯定是最直接，最有现场感的。

当然了，在你欢欣鼓舞之前，我还是得泼一盆冷水。

# **本章总结**

![](bbox=[0.12, 0.00106, 0.92, 0.00116])

# (A) 生物体为什么需要学习功能？

为了解决刺激——反射模式的两个缺陷。

第一，局限性。遗传物质能够编码的模式有限，只能为生死攸关的事情做准备。

第二，盲目性。这种模式重复多次，也无法变成能够积累的经验。

# (B) 学习的本质是什么？

宏观层面：在原不相关的东西之间建立新的联系。

微观层面：单身派对定律——总是同时被激发的神经细胞，它们之间的联系就会增强。

# (C) 如何增强学习能力？

学习意味着神经细胞联系的增强，而神经细胞联系的变化取决于“裁判蛋白”。增加“裁判蛋白”的含量，可以增强学习能力，反之减少可以抑制学习能力。

# (D) 如何虚拟记忆？

利用两个技术武器：

第一，定位记忆。

追踪被激活的基因——定位这些基因所在的神经细胞——这些细胞代表一段记忆。

第二，唤醒记忆。

在生物体内容植入能被光激发的蛋白质——利用光操纵神经细胞的活动。

科学家利根川进说，如果把虚拟记忆的研究用在人体内，可以帮助归来的士兵彻底擦除战场的可怕记忆。
