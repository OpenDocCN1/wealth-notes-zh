# 葡萄糖是身体的蓄电池

能量从哪里来？

吃饭当然是动物最直接的能量来源。但食物的能量是从哪里来的呢？植物不吃饭，能量又从哪里来呢？

你现在一定想到太阳。

是的。太阳是几乎一切地球生命的终极能量供给者。太阳光里蕴含着巨大的能量。

有多大呢？

全人类每年使用的所有能源加在一起，差不多也就抵达地球的太阳光里蕴含能量的万分之一。

请注意，是抵达地球的太阳光。因为太阳光是照向整个宇宙空间的，而这些抵达的太阳光，只占太阳总辐射量的几亿几分之一。

所以你可以想象在太阳周围的宇宙空间里，蕴含着多少可利用的能量。

![](bbox=[0.05, 0.74, 0.95, 0.81])

当然了，除了太阳能，我们其实还有很多其它的能量来源。

+   - 比如来自大地深处的地和地球核的热量，这种能量也可以被生物利用；
- 比如化学反应产生的能量；
- 比如放射性物质衰变产生的能量。

所以，在地球环境中，能量和生命物质一样，并不稀缺。

既然能量并不稀缺，那么是不是能直接按生命利用呢？生命使用能量的方式，不是烧煤发电，点火，水被加热变得滚烫；灭火，水很快变凉呢？

显然不是这样。如果生命是以这种方式使用能量，那就在没有热的食品，植物应这一夜就死完了，在没有食物供应的情况下，动物应该很快就饿死耗死了。

所以，生命对于能量的使用，一定有一套专门机制，它能把环境能量替换为自身的微量储能，先存储起来，然后再根据机体的需要使用。也就是说，生命的躯体里一定有一块蓄电池。

这个蓄电池是什么？不同生命体，使用的蓄电池一样吗？

为了回答这个问题，大家慢慢把注意力聚焦在一个特殊的化学物质上一葡萄糖。

这种化学物质其实200多年前就发现了，发现者是德国化学家、分析化学的祖师爷格拉夫（Andreas Sigismund Marggraf），他从葡萄里分离出了这种分子，所以才起了这个名字。

后来大家逐渐发现这种物质似乎到处都是，很多生物体都能被提取出这种物质。

到了20世纪末，大家才开始思考它为什么————对于今天的地球生命而言，葡萄糖就是一个普世的能量来源。

所有的动物，都包括大多数细菌、真菌这样的微生物，都是直接靠这种分子里获取生命活动所需要的能量的。

即便是可以直接利用太阳能的植物，也是先利用太阳能制造葡萄糖，然后消耗葡萄糖，驱动生命活动。而对于动物来说就更简单了，它们可以直接从食物里获取葡萄糖，然后消耗葡萄糖，驱动生命活动。

我们人类更是如此，要知道，面包、米饭、玉米、土豆里，最主要的就是由葡萄糖分子聚而成的淀粉。而微生物制造葡萄糖的方法就更多样了，它们可以利用太阳能，利用各种各样的化学能，来制造葡萄糖。

这就是说，小到细菌，大到蓝鲸，所有的生物体里的都有一个共同的能量之源—葡萄糖，它似乎是生命历史上的标准配置。

# 生命选择葡萄糖的两大原因

那么，为什么演化偏偏选择了葡萄糖？

当然，严格来说是个历史没办法的问题，如果时光流一次，地球生命很可能走上完全不同的演化路径。

但是作为能量储备，葡萄糖确实有两个特别明显的，可惜地球生命决定更换一个蓄电池，它肯定也得满足这两条。

第一个优势是葡萄糖的分子结构稳定。一旦被制造出来之后，在地球生命体内部，可以存储相当长的一段时间，而且，制造葡萄糖的原料又极容易获得。

那这特性有什么用呢？

你看，虽然自然界中的能量很丰富，但不稳定，比如太阳热，这是对于生命的最根本的威胁。因为葡萄糖极其稳定，所以地球生命一旦学会了制造、储存和使用葡萄糖，就能形成对环境的高度依赖。

植物学会了制造和使用葡萄糖，就能够跨越黑暗；动物学会了利用葡萄糖，就有了自由活动上的可能，不用从早到晚一直守在食物边上，不停地吃东西。

我们甚至可以再展开追溯：

几百年前，欧洲的探险家能开启大航海时代，把世界各地的人民联系在一起；宇航员能飞向太空，慢慢去探索整个宇宙，这样的系统是因为人类能够利用像葡萄糖这样的化学物质，作为稳定的能量储备。

这样只要出发的时候，随身多带一些食物，比如面包、土豆、太空食品，就能开始一场说走就走的旅行了，这个意义可谓不重大。

葡萄糖的第二个优势是存储的能量很容易提取。葡萄糖虽然稳定，但却不是个老实蛋。生命，需要的时候，它能量时方便地以不同形式、逐渐释放。
