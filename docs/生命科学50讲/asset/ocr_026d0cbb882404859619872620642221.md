# 48 | 人类心智：白板还是蓝图？

你好，欢迎来到生命科学50讲，我是王立铭。

我们继续讨论人类的自由意志。

上节课，我们讨论到像吃饭和爱情这样生死攸关、关乎本能的行为，应该不需要自由意志就能实现。这一讲，我们来进一步思考，人类更高级、更复杂的心智活动，是否需要自由意志呢？

我们很容易理解，很多人类特有的复杂功能，比如会写诗的功能肯定吃不出来。至于孩子的生理发育，在出生前，后天的经验和学习可以在上面随意涂抹，画出每个人独特的大脑、人格、价值观，画出每个人独特的人生故事。

这个思想可以追溯到英国17世纪的著名哲学家约翰·洛克（John Locke），他认为人类刚出生的时候大脑是一张白板，一切思想都是来自后天经验和知识。

如果这种思想是正确的，那人类高级的心智活动当然是非常自由的。因为在这块白板上怎么涂画，除了家庭、学校、朋友会影响你以外，自己本人当然也可以拿起画笔涂抹涂抹。

真的是这样吗？人类的高级心智活动到底是不是自由的呢？我们今天就来讨论这个问题。

# 遗传因素影响高级心智活动

其实，现代生物学的研究表明，这种思想恰恰并不能成立，大脑绝对不是一块白板可以任由作画。

充其量，它也只是一张已经预先存储了很多设计信息的蓝图，不管原不原同意，你的实施也都要在这个大框架下，按照预先预设好的结构来影响你的行为。

我们曾经讨论过的人类语言，就是一个很好的例子。

语言当然是一种非常高级的心智活动了。我们可以很快发现，人类的大脑，特别是人类可以根据某些语法规则把词汇组装成语句的能力，是地球生命当中绝无仅有的。

但是，在社会文化的讨论中，我们也说过，人类的语言功能并不完全是后天学习获得的。

别的动物，哪怕是人类的近亲黑猩猩，通过后天学习可以掌握不少人类词汇，但是仍然无法掌握人类的语法能力。

所以，人类语言尽管需要后天学习，但是大脑的语言能力，在很大程度上是我们携带的遗传物质赋予我们的。

同时我们知道，人类的思想交流，科学发现，文学艺术，这些特别抽象的心智活动，在很大程度上，是通过语言和语言衍生出来的文字传递的。

伟大的哲学家维特根斯坦（Ludwig Josef Johann Wittgenstein）认为，世界上所有的问题要么是个语言问题，因为只有一种问题能够用语言描述，别人理解，它才真的成为了一个问题。

那么既然语言本身是先天决定的，我们是不是也有理由相信，人类的所有心智活动也都由遗传信息规定的呢？

这个猜想很可能是正确的。

在过去三四十年里，人类遗传学在反复证明，除了刚才说到的语言之外，遗传因素强力地影响了我们几乎全部的高级心智活动。而科学来理解的主要手段，是分析人类的双胞胎。

这是怎么回事呢？

你可能已经知道，一对双胞胎宝宝，如果是从同一个受精卵分裂而来的，也就是所谓的同卵双胞胎，那么，他们两者之间就共享几乎100%的遗传物质。

与之相对，在人类当中，随便挑选两个同班孩子，他们彼此之间遗传物质的差别就非常大。

换句话说，同卵双胞胎就是天然的对照实验。

特别是如果两个同卵双胞胎的孩子，从出生以后，因为某些原因被分开养育成人，他们的家庭环境、学校、朋友、都很不一样。

但是，他们如果仍然在某些方面表现出了高度的相似性，那我们就可以说，这些特征就是遗传，而不是环境决定的。

那么，通过研究同卵双胞胎，科学家们有什么发现呢？

先说一个容易理解的结果。通过研究同卵双胞胎，他们确认身高这件事基本上是遗传决定的。

在上个世纪80年代末，美国明尼苏达大学的科学家，就利用整个明尼苏达州的双胞胎，做了这样的研究。

因为同卵双胞胎之间，不管是不是在一起长大的，身高的相似性都相当高；而如果是两个孩子没有血缘关系，因为某些原因在一个家庭长大，他们身高的相似性就和小街上随便找两个陌生人差不多。

他们甚至还计算出来，身高的遗传率是80%左右。这个数字怎么理解呢？

如果你在美国遇到一个身高1米69的成年男人，你就马上马上算一下，考虑到美国成年男性的平均身高是1米78，这个人的身高超过平均值12厘米。

这12厘米当中，差不多有10厘米，是他爹遗传给他的，剩下20%是环境的影响。

而且这里可能还包括他牛了多少钱、晒太阳多不多，上学期间有没有好好锻炼身体等等各种因素。

所以，遗传因素对身高的影响是非常巨大的。

现在让我们回到这个关心的命题：人类更高级、更复杂的心智活动，是不是也是遗传决定的？需不需要自由意志呢？

通过研究同卵双胞胎，研究人员分析了人类的各种心智特征，比如智商、记忆力、幸福感和自信心，比如外向好还是内向，友善还是邪恶。

他们的发现是，所有这些指标在很大程度上都受到遗传因素的影响。

虽然对于这些心智指标，遗传因素的影响相对于身高要小一些，但是，仍然有50%，甚至70%，远远大于任何单一的后天因素，比如家庭环境、教育水平等等。

更不可思议的是，根据双胎研究的结果，连我们的价值倾向也可能会受到遗传因素的强烈影响。
