# 王立铭紧急发声：为什么基因编辑婴儿在今天不可原谅？

王立铭 生命科学50#

> 为什么基因编辑婴儿在今天...

就在今天，2018年11月26日，一条科技新闻朋友圈。

南方科技大学的生物学家贺建奎在香港接受美联社会访时声称，他的实验室利用一种基因编辑技术，在至少六对夫妇的受精卵上，修改了一个名叫CCR5的基因。并且，其中一个修改后的一对双胞胎女儿已经在这个月出生了！

贺建奎表示，这种操作能够让这些孩子具有对艾滋病的天然免疫力，这种能力在当今的世界十分罕见。

如果美联社的新闻属实，那今天是一个注定要载入人类历史的日子。

有史以来第一例和第二例被人为修改过基因的人类个体，就这样不声不响无声无息的时候，来到了这个世界上。

我相信在未来几天，会有更多的技术和监管细节被审查和发布出来，我会和得到的朋友们一起，看看最新得消息和有关方面的后续处理办法。但是在第一时间，我想和得到的朋友们分享我的解读和思考。

必须说明，这条消息让我个人是非常愤怒的。

我是一个比较熟悉基因编辑领域的生物学家，2016年6月甚至还写了一本专门解读基因编辑技术，书名叫《上帝的手术刀》。

这项技术仍然充满未知风险。所以，我认为，目前就在人类个体身上尝试基因风险，又几乎没有任何健康好处的研究，不光是不科学的，更是不道德的。这是对人类尊严和科学精神的践踏。

你可能会很想知道我的愤怒来自哪里。为了说明清楚这一点，我们还是先闪回科学本身来讨论。

首先得明确，用修改CCR5基因的方法来对抗艾滋病并不是什么新鲜的主意。

我们知道，艾滋病的发病原因，是一种叫做人类免疫缺陷病毒——简称HIV的感染。

HIV能够确切识别人体中的某一类免疫细胞，从而杀死这些免疫细胞，从而让患者丧失免疫功能，最终可能会死于严重的感染。请注意，HIV之所以能够识别细胞的感染对象，是借助自己基因中的信息，而它的表面，有一个天然的分子结合桩被HIV借用了。这个分子结合桩就是CCR5基因生产的。

所以，反过来说，如果人体当中天生就没有这个CCR5基因，那是不是就能天然对艾滋病免疫呢？

还真是这样，在人类世界里，有1%的北欧人由于基因缺陷的CCR5基因的缺失，从而对艾滋病免疫。

人类世界里存在的这个天然的艾滋病防御武器，给很多医生和科学家提供了对抗艾滋病的思路。

比如说，在著名的柏林病人的案例中，同时感染了艾滋病和白血病的美国人蒂莫西·雷·布朗接受了来自CCR5基因缺陷人群的骨髓移植，没想他的白血病和艾滋病竟然被同时治好了！

就在几年前，美罗华加拿大公司还在研究通过一项骨髓移植技术，人为破坏掉艾滋病病人体的CCR5基因，他们确定也发现，这些病人体内的病毒水平明显降低了。这些案例在我的书里也有详细的讨论。
