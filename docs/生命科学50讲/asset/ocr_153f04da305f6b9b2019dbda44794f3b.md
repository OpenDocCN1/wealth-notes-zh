# RNA是病毒的遗传物质

首先，我们先来简单了解一下病毒。

病毒有两个特点。第一，病毒是一种介
于生命和非生命之间的东西，我在之前的
讨论里，有意识地忽略了病毒，也是因为这
个原因。

为什么说它非生非死呢？因为病毒颗粒
非常小，直径往往只有几十到上百纳米，
比最小的细菌还要小很多。

这些病毒颗粒其实没有什么生命迹象。你
可以简单把它理解成一层轻质的蛋白质
外壳，里面装了一条或者几条存储遗传
信息的分子。这样的病毒颗粒根本没有
利用环境的能量，也没有能力自我复制，
因此很难说是生命。
