### 5.1 交叉验证评估器

交叉验证评估器，函数名称是 cross_val_predict，可以对每一组输入数据点生成交叉验证评估器。

对于机器学习而言，通常需要 train_data（训练数据）和 test_data（测试集）为两个部分。

测试数据（test_data）的验证结果叫做伪误验证值（validation_error）。

对于任何一种算法或名模型，若只用一次或少数几次的数据进行训练、测试，作为评估算法、模型好坏的标准，那么这件的结果存在很大的偶然性。

在实验当中，必须多次、随机划分训练数据和测试数据，分别计了多次的伪误验证值。这样，根据多次的伪误验证值才可以较为客观地评估算法、模型的好坏。

交叉验证是在数据量有限的情况下，采用的一种稳健评估手段，它可以自动、随机地按不同比例对数据进行划分、测试。

sklearn 中的交叉验证模块主要的功能是：

```
model_selection.cross_val_predict
```

函数调用接口如下：

```
cross_val_predict(estimator, X, y=None, groups=None, cv=None, n_jobs=1, verbose=0, fit_params=None, pre_dispatch='2*n_jobs', method='predict')
```

调用的参数如下

- estimator：表示不同模型的变量。
- X：训练数据集中。
- y：训练数据集所对应的正确结果数据
- cv：代表的是不同的交叉验证方法。

需要注意的是参数cv比较复杂，既可以是用户定义的验证函数名称，也可以是int类型数值。

当cv是int数值时，默认使用验证函数StratifiedKFold，或者KFold交叉验证函数，如果指定了类别标签，则使用的交叉验证函数是StratifiedKFold。

### 6.1 决策树算法

决策树算法（Decision Tree Algorithm），简称 DT 算法。

## Python机器学习与量化投资

决策树算法是一种无监督的学习方法，用于分类和回归 它们根据中 结合的决策规则进行迭代，以预测目标变量的值。

决策树算法最早产生于20世纪60年代，是一种接近函数拟合的方法，本质上决策树是通过一系列规则对数据进行分类的过程。

在进行逐步应当过程中，典型的决策树分析会使用分支变量或决策节点。例如，可以一个给定用户分类成信用可...或不可...。

决策树的结构中的叶子是可变的，可以是一组有限值，设称为分类的。在这些树结构中，叶子表示分类标签，分支表示对这些分类标签的连接特征。如图6.1所示。

![](img/93734a9b810ff3e8778504a648b013dc_117_0.png)

图6.1 决策树算法

决策树算法的优点如下。

- 模型便于可视化。
- 无需对数据进行预处理。
- 助长对人、地点、对象的系列不同特征、品质、特性进行估计。

决策树算法的缺点如下。

- 容易出现过拟合，虽然创建了一个决策树，却过于复杂无法应用在工程实践中。

- 决策树模型不稳定，即使很小的变化，也会产生完全不同的模型！
- 可能归于局部很小的问题。
- 它们在线学习。

传统决策树算法往往基于启发式算法对样本和属性进行随机抽样，例如贪婪算法，即每个节点创建最优决策。这样一来，虽然该算法不能产生一个全局最优的决策树，却可以降低整体效果风险。

决策树典型的表现形式为二叉树，尽 nella 和修改结构方面的二叉树 树上每个节点代表一个输入变量（x）与一个基于该变量的分离点（规定这个变量是否改了）。

决策树构造方法其实就是每次选择一个好的属性和分裂点作为当前节点的分类条件。

决策树算法同样适用于数值分析，是一种逼近函数近似的方法。它是一种典型的分类方法，首先对数据进行处理，利用归纳算法生成可读的规则和决策树，然后使用决策对手数据进行分析。

决策树训练学习起来很快，预测速度也很快。决策树对于各不各样的归属它能给出准确的预测，并且无需对数据作任何特殊的预处理。

从商业决策的角度来看，决策树是通过尽可能少的步骤来判断问题，预测决策正确的概率，从而用一种结构性的、系统性的方法来作出合理的结论。

#### 6.1.1 ID3 算法与 C4.5 算法

决策树算法的核心是 ID3 的改进算法 C4.5 算法。

1986 年，人工智能学家 J.Ross Quinlan 提出了著名的 ID3 算法，可以减少树的深度，加快运行速度。

ID3 算法的目的是减少树的深度，但是忽略了对叶子数目的研究。

C4.5算法在ID3算法的基础上进行了改进，在信息熵的处理、剪枝技术、派生规则等方面有了较大改进，既适合于分类问题，又适合于回归问题。

#### 6.1.2 常用决策树算法

常用的决策树算法如下

- ID3（Iterative Dichotomiser 3）算法：采用信息熵技术估算信息的不同强度，选择“信息增益”最大作为节点特征。它是多叉树，即一个节点可以有多个分支

- C4.5和C5.0算法：是ID3算法的改进版本，同时采用信息熵技术估算信息的不同强度，选择“信息增益比”最大作为节点的征。它们是多叉树，即一个节点可以有多个分支

- CART（Classification and Regression Tree）算法：分类和回归树算法。采用基尼指数来度量信息的不纯度，选择基尼指数最小作为节点特征。它是二叉树。

- RF（随机森林）算法：通过使用多个部分随机选取的数据子集的树来改善决策树的稳定性。

- CHi-squared Automatic Interaction Detection，CHAID算法

- Decision Stump算法。

- MARS（多元自适应回归样条）算法

- GBM（Gradient Boosting Machine 梯度推进机）算法

- PUBLIC算法。

- SLIQ算法

- SPRINT算法

- M5算法

- Conditional Decision Tree 方法。

这些算法的主要区别在于度量信息的方法、选择节点准则和分支数量的不同。
