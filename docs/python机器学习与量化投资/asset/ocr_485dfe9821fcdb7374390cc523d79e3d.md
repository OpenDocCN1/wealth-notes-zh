调用 GaussianHMM（高斯隐马尔可夫）函数，生成模型，并保存变量 mx 中，调用参数：
n_components=nn9
表示隐马尔可夫生成的状态数目，这个参数涉及模型不同的理论知识简含米说，模型生成的状态数目对应的正是我们设定的价格分类

因为股票市场波动很小，我们按收盘价下分之五的上下波动，对数据进行分类，如下所示。

+   - 2，波动大于 100.5%，up 上涨模式。
- 1，波动小于 99.5%，down 下跌模式
- 0，波动在 0.5%之间，eq 平稳模式。

以上分类类似足球的“310”（胜平负）模式。

所以，调用 GaussianHMM 函数时，一般采用实际分类的值数进行调用，它在测试结果如下。

+   - n=3，模型准确率为 37.23%。
