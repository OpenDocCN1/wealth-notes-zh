图 16.1 神经网络算法

ANN 方法模型里面的各个节点被称为“神经元”或“单元”，这些节点之间加上连接构成的网络就是“神经网络”。

ANN 方法模型要进行训练，训练的过程就是网络进行训练学习的过程，通过训练学习过程来改变各个节点的连接权值。

ANN 方法模型的主要缺点如下

+   - 方法模型收敛速度慢。
- 计算量大。
- 训练时间长
- 缺乏足够的理论基础。

常见的 ANN 方法如下。

+   - PNN（感知器神经网络）方法。\n- BP（反向传播）方法。\n- Hopfield 反馈网络方法。\n- Elman 反馈网络方法。\n- SOM（自组织映射）方法。\n- RBF（径向基）方法。
