可以看出，scikit-learn 内部的回归1方法几乎满足了所有开发者的需求，而且更重要的是，scikit-learn 针对每种方法都进行了底层优化加速，并且提供了简便易懂的参考案例。

# 3. 聚类

聚类是指将相似对象自动分组，也就是自动识别具有相似属性的给定对象，并将其分组为集合，用于无监督学习的任务。常见的应用场景包括顾客细分和试验结果分组。

目前 scikit-learn 已实现的聚类方法包括：k-Means 聚类、Spectral Clustering（光谱聚类）、Mean-shift（均值偏移）、分层聚类、DBSCAN 聚类等。

# 4. 降维

数据降维是指减少需要考虑的随机变量的个数，其主要应用场景包括可视化处理和特征抽取。

目前 scikit-learn 已实现的降维方法包括：PCA（主成分分析）、NMF（非负矩阵分解）、Feature Selection（特征选择）等降维技术

# 5. 模型选择

模型选择是指比较、验证、选择参数和模型。对于给定参数和模型进行比较、论证和选择，其主要目的是通过参数调整来提升精度。

目前 scikit-learn 实现的模型选择方法包括：Grid Search（网格搜索）、Cross Validation（交叉验证）和各种针对预测问题估计的 Metrics（度量）两款

# 6. 预处理

数据预处理是对数据的特征提取和归一化，是机器学习过程中的一个步骤，也是极为重要的一个环节

这里归一化是指将输入数据转换为了具有零均值和单位方差的新数
