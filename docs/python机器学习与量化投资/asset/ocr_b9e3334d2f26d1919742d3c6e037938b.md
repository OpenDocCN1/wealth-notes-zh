调用模型的内置训练函数 fit，通过训练数据 X、Y，对模型进行训练。
通常，这个阶段是耗时较多的。

sklearn 的 fit 训练函数和 predict 预测函数是机器学习中非常简单的 API 接口，也是各种神经网络、深度学习的简化接口标准，像 tensorflow、keras 等框架，都参考了这种设计。

这种模式相当于 TensorFlow 等神经网络平台的 batch 迭代校型的入门单开了，却对于模型中的众多细节优化却无能为力。

第 7 行代码如下：

```
print('第7, predict 测试结果')
df_test['y2'] = mx.predict(xtest) # cross_val_predict(mx,x, y, cv=20)
zt.preDF('df', df_test)

```
