# 机器学习算法模式

由图 8.1 可以看出机器学习的三大要素：数据、算法模型、计算

+   • 数据：在大数据时代，各行各业基本上都充斥数据，缺乏的只是从数据中提取出有价值的参改。

+   • 计算：在前都有同样的模式，学习训练期间采用 fit 训练模式，实凡采用 predict 预测函数，只是不同模型的 API 接口有所之别。

+   • 算法模型：这个通常经验和数据调试，根据不同的项目挑选不同的模型
