# 36. sklearn.metrics（结果测度）

sklearn.metrics 模块，包括模型、算法评估功能，评分功能、性能指标和损失指标和统计量。包括以下若干部件。

+   - Model Selection Interface: 模型选择函数。
- Classification metrics: 分类 metrics。
- Regression metrics: 回归 metrics
- Multilabel ranking metrics: 多标签排序 metrics。
- Clustering metrics: 聚类 metrics。
- Biclustering metrics: 双聚类 metrics。
- Pairwise metrics: 成对 metrics。

# （1）Model Selection Interface（模型选择界面）

+   - make_scorer: 按性能测试...损失函数评估分。
- get_scorer: 获取性能测试评分。

# （2）Classification metrics（分类 metrics）

+   - accuracy_score: 准确性评分。
- AUC: 采用梯形法计算曲线下面积。
- average_precision_score: 从...平均精度 (AP)。
- brier_score_loss: 计算 Brier（布莱尔）分数。Brier 分数是评价概率预测准确度的一个指标，适用的前提是只关心某个事件是否发生（0-1）
