# 量化分析常用指标

量化交易属于新兴产业，TA-Lib 企业软件包收录的商数虽然多，但大部分是传统技术指标，对于量化交易、量化分析领域有很多人缺乏 本书上要介绍量化领域新出现的一些技术指标。

量化分析本质上是一种风险和收益的综合平衡分析，其经、三大指标是夏普比率、詹森指数和特雷诺指数。

+   - 夏普比率（Sharpe Ratio），也称夏普指数，缩写为 SR 简介地识，它指的是收益率与风险的比例。夏普比率代表投资者每多承担一分风险，可以多得到几分收益。若为正值，代表企业报酬率的高过波动风险；若为负值，代表企业报酬率大过风险... 通常，这个比例越高，投资组合越佳。

+   - 詹森指数（Jensen），又称为阿尔法值，是衡量基金 manager 收益大小的一个指标 这个指标综合考虑了基金收益与风险因素，比单纯的考虑基金收益大小更科学。

+   - 特雷诺指数（Treynor Ratio），缩写是 TR，是每单位风险承担的风险溢价。特雷诺指数越大，单位风险溢价越高，绩效越好；相反，特雷诺指数越小，单位风险溢价越低，绩效越差
