## 集成算法

集成算法，也称为集成学习算法，英文全称是 Ensemble Algorithms，简称 EA 算法。

EA 算法功能非常强大，也非常流行，是当前机器学习四大主流思路之一，也是行业的研发热点。

EA 算法通过使用一些相对较弱的学习模型，彼此独立地对同样的样本进行训练，然后把结果整合起来进行整体预测，以提高系统的最终效果。EA 算法由于采用了投票平均的方法组合多个分类器，可以减少单个分类器的误差，从而提高算法整体的准确度。

EA 算法消除了个别的偏差，减少了预测的方差：多个模型集成后的预测结果比单一模型的预测结果更稳定。

在另外，这被称为多样化：多个模型的组合波动总是远小于单个模型的波动。

EA 算法不容易产生过拟合：如果单个模型会产生过拟合，那么将每个模型的预测结果分别地组合（取均值、加权平均、逻辑回归），就可以轻易解决过拟合问题。

EA 算法通常分为两大类型：

- AdaBoost 迭代算法
- RF（随机森林）算法
- Blending 集成迭代算法
- GBM（梯度提升机）
- GBRT 算法

决策树算法大部分也是 EA 算法。

## 14.2 装袋算法

装袋算法是一种根据均匀随机分布从数据中重复抽样的技术

装袋算法也叫 bootstrap 方法，与随机森林方法类似，还常用于决策树倾斜

装袋算法的基本思想可以分为三个步骤。

- 步骤一，把数据分为 n 个小组，类似把一堆水果装到 n 个袋子里，而这也是装袋算法的一种形象的比喻。
- 步骤二，对各小组的数据进行分析，找出每个组的最佳答案 相当于在每个袋子里选出符合要求的水果。注意，不是最大的水果，而是符合要求的水果
- 步骤三，把 n 个小组挑选出的结果进行汇总，再挑选出最频繁出现的结论的结果作为最终答案，类似统计学的众数似然 对水果例子而言，如果按大小作为标准，不是挑选最大或最小的水果，而是按大小分类后出现最多的一类水果

## 14.3 AdaBoost迭代算法

AdaBoost算法是一种迭代算法，其核心思想是针对同一个训练集训练不同的分类器（弱分类器），然后把这些弱分类器集合起来，形成一个更强的最终分类器（强分类器），如图 14.1 所示。

在针对二元分类所开发的 Boosting 迭代算法中，AdaBoost 迭代算法是第一个成功的算法。

在金融量化分析领域，往往需要有较多数据对未来的走势进行预测，这种基于大数据的高频分析，经常会用到 GBM 和 AdaBoost 两种 Boosting 算法。

Boosting 算法是一种集成学习算法，它结合了建立在多个基础估计器上的预测结果，以此来提高单个估计器的可靠性。Boosting 算法通过给训练数据重新分配权重来优化最终的计算结果。

![](img/93734a9b810ff3e8778504a648b013dc_251_0.png)

# 图 14.1 AdaBoost 迭代算法

AdaBoost 算法不仅是通过改变数据分布来实现的，它根据每次训练集中每个样本的分类是否正确，以及上次的总体分类的准确率来确定每个样本的权值。

AdaBoost 算法将修改过权值的效数据集再发送给下一个分类器进行训练，以后再将每次训练得到的分类器组合起来，作为最终的决策分类器。

通常，AdaBoost 算法与决策树一起工作。在第一个决策树创建后，决策树在每个训练实例上的性能仍被用来为下一个决策树针对该实例所应分配的权值。难以分类的训练数据被赋予更大的权重，而容易分类的数据则被赋予了更小的权重。重复依次创建，每次更新训练实例的权值，会影响到序列中下一个决策树的学习性能。在所有决策树完成后，即可对新输入的数据进行预测。而每个决策树的性能将由它在训练数据上的准确度来决定。
