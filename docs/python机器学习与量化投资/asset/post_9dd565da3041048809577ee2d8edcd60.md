## 13.1 主成分分析

主成分分析方法，英文全称是 Principal Components Analysis，简称 PCA 方法。

PCA 方法是统计学的方法，通过正交变换将一组可能存在相关性的变量转换为一组线性不相关的变量，转换后的这组变量称为主成分，如图 13.1 所示。

![](img/93734a9b810ff3e8778504a648b013dc_229_0.png)

PCA 方法是常用的降维方法之一，在数据压缩、消除冗余和改善数据中的噪声等领域应用。以及我们提到降维时容易想到的办法就是 PCA 方法，下面我们就对 PCA 方法的原理做一个总结。

PCA 方法可以用来降低算法计算开销、去除噪声，以及使结果易于展示理解等。

PCA 方法就是找出数据里最重要的方向，用数据里最重要的方向来代替原始数据。简单来说，PCA 方法类似于作文里面的主题思想，或者说凤尾报道的摘要、大纲，通过更加简洁的核心数据，反映样本内容。

PCA 方法的主要应用领域包括数据压缩、简化数据、数据可视化等。

### PCA函数接口

sklearn 模块内有一个 decomposition 子模块，用于处理降维方面的算法问题。

其中模块的 PCA 方法函数的 API 接口如下：

```
PCA(n_components=None, copy=True, whiten=False, svd_solver='auto', tol=0.0, iterated_power='auto', random_state=None)
```

相类似其他机器学习方法提供的方式，PCA 方法函数的 API 接口调用的参数和其它是比较少的。

其中主要参数如下

- n_components，表示保留下来的特征个数。如果设置为'mle'，将自动选取 Variance 个数，使其达到所要求的方差百分比。
- copy，默认为 True，表示在运行算法时，是否将原始训练数据复制一份。若为 True，则在运行 PCA 方法后，原始训练数据的内容不会有任何改变，因为是在原始数据的副本上进行运算的；若为 False，则在运行 PCA 方法后，原始训练数据的内容会改变，因为是在原始数据上进行降维的
- whiten，默认为 False，表示对数据进行白化处理，所谓白化，就是对降维后的数据的每个特征进行归一化，让方差都为 1。对于 PCA 降维来说，一般不做白化处理。
- svd_solver，表示指定奇异值分解（SVD）的方法。由于特征分解是奇异值分解（SVD）的一个特例，一般的 PCA 都是基于 SVD 实现的。有 4 个可以选的值：auto、full、arpack、randomized。randomized 一直适用于数据量大、数据维度多同时主成分数量比例又较低的 PCA 降维，它使用了一些加快 SVD 的随机算法。full 则是传统意义上的 SVD，

使用了 scipy 对应的实现。arpack 和 randomized 的使用关系类似。区别是 randomized 使用的是 scikit-learn 自己的 SVD 实现，而 arpack 却使用了 scipy 对应的 sparse SVD 实现。默认是 auto，即 PCA 办法会从前面讲到的三种办法里面去权衡，选择一个合适的 SVD 办法来降维。一般来说，使用默认值就够了

PCA 函数返回的是一个 PCA 对象，主要包括以下属性。

- components_，返回具有最大方差的成分
- explained_variance_，降维后的各主成分的方差
- explained_variance_ratio_，返回总 n 个各自的方差占比比例，总是对应归类。
- n_components_，返回所保留的特征个数 n。
- mean_，返回值的平均值。
