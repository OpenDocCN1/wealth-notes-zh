## 9.2 隐马尔可夫模型

隐马尔可夫模型，英文名为 Hidden Markov Model，记简称为 HMM 模型。

隐马尔可夫模型，通过分析可见数据，来估计隐藏的状态的发生。相反，借助隐状态分析，隐马尔可夫模型可以估计未来可能的观察状态，如图 9.2 所示。

在图 9.2 中，通过隐马尔可夫模型，已知冷、暖压的发生频率（这是隐状态）可预测晴天、雨天、多云天的概率。

隐马尔可夫模型的优点是允许纵向变化，常用於识别和预测操作。

与其他机器学习方法不同，隐马尔可夫模型我们没有直接使用 sklearn 内含的相关函数，而是使用 hmmlearn 模块。

## 实例算法

实例算法，英文全称是：Instance-based Algorithms，简称 IA.

实例算法只需要先选取一批样本数据，然后根据某些相似性，把新数据与样本数据进行比较，以找出相似的匹配。

实例算法是极简单的机器学习算法之一，它不像其他算法，需要在样本空间建立一般性的模式公式，而是它通过输入的数据进行分类或回归学习，并从失败最终结果

因此，实例算法也被称为“靠家通过吃的学习”或“基于记忆的学习”。如图10.1所示。

![](img/93734a9b810ff3e8778504a648b013dc_198_0.png)

实例方法处理成的模型对原始数据样本实例有很强的依赖性。实例方法在做预测决策时，一般是在某个范围内给出相应的预测结果。

实例方法的缺点是处理成本需求较高。无论从 CPU 运行速度，还是算法存储软件需求都很高，方法占用的空间和运行的速度几乎取决于实例样本的人数。

常见的实例方法如下，

- KNN：K近邻方法，英文全称是 k-Nearest Neighbor。
- LVQ：矢量学习方法，英文全称是 Learning Vector Quantization
- SOM：自组织映射方法，英文全称是 Self-Organizing Map
- LWL：局部加权学习方法，英文全称是 Locally Weighted Learning。

## K最近邻算法

K最近邻算法如图 10.2 所示。

![](img/93734a9b810ff3e8778504a648b013dc_199_0.png)

所谓 K 最近邻，就是 k 个最近的邻居的思想，说的是任何样本都可以用它最近的 k 个邻居来代表。

KNN 算法可用于分类问题和回归问题，该方法更常用于分类问题相对于回归问题。KNN 方法分出的一类是多数平均值；对于分类问题，
