# 2.3 机器学习算法流程

通常机器学习的算法流程如下：

+   - 选择模型函数 mx_fun。
- 把训练用的特征数据矩阵 x_train 和对应的标签（结果）数据矩阵 y_train，
  传入模型的函数 mx_fun。
- 系统内部的机器学习函数会自动分析特征数据与结果数据之间的人系，
  这其中的一个过程就是机器学习的过程，也是训练模型的过程。
- 通过对训练数据的机器学习和数据分析，系统会生成一个 AI 机器学习的模型，我们将其保存在变量 mx。
- 把测试数据 x_test 输入到 mx 模型变量中，mx 会调用内部的分析函数 predict，
  生成最终的分析结果 y_pred。
- 如果是实盘，我们输入最新的数据，比如今天的股市数据正在进行中的足彩比赛赔率数据，系统会自动生成相关的预测数据，比如每天或未来几天股市走势数据或其他输出结果预测数据。

在进行实盘运行前，我们会对模型产生的预测数据 y_pred 和正确结果数据 y_test 进行对比，判断模型的准确度，并通过一些优化措施和参数调整进行迭代运行，或者采用其他的模型提高最终结果的准确度。

# 2.4 机器学习数据集

机器学习通常使用两组数据，一组作为训练数据，一组作为测试数据。在每组数据中都包含一组多维的多数据矩阵作为特征数据矩阵，以及一组一维的数据作为结果分类数据，从而形成 4 个数据集，通常这 4 组数据变量的名称如下：

+   - x_train，训练数据，多维多枚数据矩阵。
- y_train，训练数据，一维结果数据矩阵。
