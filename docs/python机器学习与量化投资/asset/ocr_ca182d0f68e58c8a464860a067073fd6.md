# 14. feature_extraction (特征提取)

sklearn.feature_extraction: 特征提取模块，主要用于从原始数据提取特征数据，包括提取数值、文本、图像等数据的特征提取。

+   - DictVectorizer: 变换的特征映射为向量。
- FeatureHasher: 把特征向量采用 Hash（哈希）函数进行散列交换。
