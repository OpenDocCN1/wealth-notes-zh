
弹性网络算法是一件同时使用 L1 范数和 L2 范数作为正则化矩阵的惩罚回归模型。岭回归法、套索回归法，可以看作是弹性网络算法的例子。

套索回归法常用于特征选取，而弹性网络算法类似套索回归法的衍生版本，在套索回归模型上添加了一个 L2 范数正则化的“惩罚”项。当两个特征和另一个特征相关的时侯，套索回归法倾向于随机选取其中一个，而弹性网络算法更倾向于选取两个。

## 11.4 最小角回归算法

最小角回归算法，英文全称是 Least-Angle Regression，简称 LARS 算法

LARS 算法模型特别适合处理高维、少样本数据。LARS 算法类似于前向逐步回归，在每一次迭代当中，找到与残差最相关的变量。当多个变量与其相关时，不是沿着相同的残差变化继续，而是沿着残差交点之间的等角方向前进。

LARS 算法通过相关性逐步与残差变化相关的特征。从模型上看，相关性实际上就是特征与残差之间的最小角度，这就是 LARS 名称的由来。

# 聚类分析

聚类分析，又称为聚类算法、集族算法，英文全称为 Clustering Algorithms，简称 CA 算法。

聚类算法通过对一组目标进行分类处理把属于同一组（即一个类）的目标划分在同一组中，与其他组目标相比，同一组目标彼此更加相似。

聚类算法就似回归算法一样，有时候人们描述的是一个问题，有时候描述的是一个类算法。

通常，聚类算法首先按照中心点，也称通过分层的方式，对输入数据进行归并，把输入样本聚成围绕一些中心的“数据团”，以找到数据的内在结构，按照相似大的共同点将数据进行分类。

聚类算法可以让数据变得更加有意义，不过聚类算法的结果往往难以解读，对于某些特殊数据，结果可能无法使用。

常用的聚类算法如下。

- K 均值算法。
- BIRCH 算法。

- EM 算法。

- HC（分类聚类）方法

- 基于模型聚类模式

- 神经网络/深度学习聚类模式

## 12.1 K均值算法

K均值算法，英文全称是 K-Means Algorithm，也称为 K-Means 方法，简称为 K 均值算法。

K均值算法在本质上是一种聚类算法，把 n 个对象根据它们的属性分为 k 个类 (k < n). 如图 12.1 所示。

![](img/93734a9b810ff3e8778504a648b013dc_220_0.png)

# Python 机器学习与量化投资

K 均值算法涉及目标，每个目标有自己的质心。一个目标内的质心和各数据点之间距离的平方和形成了这个目标的平方位之和。同时，目标的平方位之和加起来的时候，就成了目标方的平方位之和。

K 均值算法假设对多个样本空间向量，不足使各个群组内部的均方误差总和最小。

K 均值算法是一种无监督式学习算法，与处理混合正态分布的数据同类算法很相似，因为它们试图找到数据中自然聚集的中心。

K 均值算法给每个目标选取一个点，这些点称为质心。每一个数据点与距离最近的质心形成一个目标，也就是一个集群。

K 均值算法的缺点是对高维空间、多如的数据集效果不佳，尚要预先利用 PCA 等算法对数据进行降维

## 12.2 BIRCH算法

除了 K 均值算法外，BIRCH 算法也是一种常用的聚类算法。BIRCH 算法的全称是层次平衡迭代聚类算法，英文全称是 Balanced Iterative Reducing and Clustering Using Hierarchies, 简称 BIRCH 方法, 如图 12.2 所示。

![](img/93734a9b810ff3e8778504a648b013dc_224_0.png)

图12.2 BIRCH 方法

BIRCH 方法运行速度很快，只需要单次扫描数据就能进行聚类分析，适合于数据量大、类别数也比较多的情况。

BIRCH 方法通过聚类特征树（Clustering Feature Tree, 简称 CF 树）来快速进行聚类分析。CF 树结构类似于平衡 B+ 树，每个节点由若干个聚类特征（Clustering Feature, 简称 CF）组成。

BIRCH 方法把所有的数据建成 CF 树，对应的结果就是若干个 CF 节点，每个节点里的样本点就是一个聚类的簇。BIRCH 方法的主要过程就是建立 CF 树的过程。

# 降维算法

降维算法，英文全称为 Dimensionality Reduction Algorithms，简称 DRA 算法。

DRA 算法通过无监督学习的方式，利用较少的信息来归纳或保留数据。DRA 算法和聚类算法类似，通过分析数据的内在结构，来找到数据间的关联。

DRA 算法常用于高维数据的可视化，也用来简化数据，以便其它算法使用。

DRA 算法的优点是可以处理大规模数据集，无须在数据上进行假设，缺点是难以分析非线性数据，难以理解结果的意义。

常用的 DRA 算法如下。

- 主成分分析
- 主成分回归
- 偏最小二乘回归
- Sammon 映射
- 多维尺度变换
- 投影小块
