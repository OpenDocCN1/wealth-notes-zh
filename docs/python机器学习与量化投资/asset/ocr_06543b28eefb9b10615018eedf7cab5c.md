LinearSVC（线性支持向量分类算法），函数接口定义如下：

```
svm.LinearSVC(penalty 'l2', loss='squared_hinge', dual=True,
tol=0.0001, C=1.0, multi_class='ovr', fit_intercept=True,
intercept_scaling 1, class_weight None, verbose=0,
random_state=None, max_iter=1000)
```

两个函数的上变量调用参数如下：

+   - C，惩罚系数C，默认为1，一般需要通过交叉验证来选择一个合适的C。
  一般来说，如果样本点较少时，C需要小一些

+   - penalty， title正则化参数，以用于线性拟合，可以选择‘l1’即L1正则化或‘l2’即L2正则化，默认为L2正则化

+   - epsilon，允许误差

+   - loss，损失函数类型，默认为epsilon_insensitive，可选为squared_epsilon_insensitive。
