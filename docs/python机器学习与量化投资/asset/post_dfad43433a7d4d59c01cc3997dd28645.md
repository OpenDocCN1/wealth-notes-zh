## 3.2.1 股票池

股票池，英文名亦是：Stock Pool，是业内对投资...的通俗称呼

股票池...的是一种股票投资组合，也就说俗说的“不要将鸡蛋放个...子里”。将...分散投资到几只股票中有利于降低投资风险

通常股票池内几只股票的选取是行讲究的，比如不同行业的搭配、...

## Python 机器学习与量化投资

收益（同时意味着风险）与低风险（同时意味着低收益）的权衡、长期与短期的权衡等。

它各常说，传统金融投资与量化投资的一个最大不同点，是股票池的应用。

传统金融投资往往喜欢挑选龙头股、漂亮股、潜力股，寄托于某个个股的分析。这类似于足球比赛，人们喜欢巴巴 vs、某个等传统强队。

量化投资不是关注几只龙股的表现，而是关注“池子”的整体收益。一个股票池通常有 50～100 只不同风格、类型的股票，而且其中有 30%～40%的股票处于亏损状态，只要整个“池子”(pools)的收益是正收益的，比传统投资更加稳健。

此外，量化投资中股票池的定义与传统金融投资也有不同。传统投资谈及中股票池更多的是各选换的思想。

而量化投资中所说的股票池是已经进行投资的对象。对于一位量化投资者而言，假设他投资了 50 只股票，他的股票池就是这 50 只股票，而整个沪深两市的几千只股票，都只是他的备选投资对象。

量化投资与传统金融投资对于股票池的应用也有很大区别

传统投资各一类投资的股票品仲很少，而且更换的频率很低。而在量化交易当中，股票池一线在 50～100 只股票之间，单只股票的资金额在 50 万元左右，和市场之地交易成本高度相关。此外，股票池的更换非常频繁，而且是同归性的，通常 1～2 周更换其中的部分股票，按 5%～10%的亏损或股票收益率、亏损率的百分比进行更换。

在量化交易中更换股票池的通用原则是把近期收益较差的一批股票剔除，这个原则虽然不太符合传统金融投资者的思维，不过如有严格的统计学的数理支持。
