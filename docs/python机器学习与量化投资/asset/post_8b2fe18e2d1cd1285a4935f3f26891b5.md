## 1.1 scikit-learn模块库

scikit-learn, 仍称 sklearn, 是用 Python 开发的机器学习模块库, 其中也含大量机器学习算法、数据

scikit-learn 模块库优点很多: 简单易用、API 接口完善、案例文档丰富
内容经过筛选的、高质量的机器学习模型; 模块覆盖了大多数机器学习任务; 系统可扩展较大数据的处理。

在 scikit-learn.org 网站首页头, scikit-learn 官方总结的优点如下

- 简单高效的数据挖掘和数据分析工具。
- 可在各种环境中扩展使用。
- 建立在 NumPy、SciPy 和 Matplotlib 上。
- 开放源代码, 可免费商业使用 BSD license.

scikit-learn 模块库是开源的 Python 机器学习算法框架, 源于 2007 年谷歌公司的 Google Summer of Code 项目, 最早由数据科学家 David Cournapeau 发起, 是 Python 语言中专门为机器学习应用而发展起来的一款开源软件。

scikit-learn 模块库是一个简洁、高效的算法库, 提供一系列的监督学习和无监督学习的算法, 以用于数据挖掘和数据分析。scikit-learn 几乎涵盖了机器学习的所有主流算法, 这为其在 Python 开源世界中奠定了江湖地位。

scikit-learn 的算法库是建立在 SciPy (Scientific Python) 之上的, 这也是其命名的由来。

SciPy 模块库是 Python 语言的瘦科研计算工具包, 在于 SciPy, 目前开发者们针对不同的应用领域, 已经发展出了众多的分支版本, SciPy 的扩展和模块在化统上被命名为 Scikits, 即 SciPy 工具包的延伸。

和其他众多的开源项目一样, scikit-learn 目前主要由社区成员自发维护。可能是由于维护成本的限制, scikit-learn 相比其他项目更新更为保守。

这种保守主要体现在两个方面。

- scikit-learn 从来不处理机器学习领域之外的其他扩展。
- scikit-learn 从来不采用未经广泛验证的算法。

## 1.1.1 scikit-learn 的缺点

虽然 scikit-learn 以模块功能强大，目前已经是机器学习领域重要的模块了。但是，scikit-learn 也有缺点。

scikit-learn 模块的缺点主要包括以下几个方面。

- 不支持深度学习和强化学习。
- 不支持 PyPy 加速，也不支持 GPU 加速。
- 不支持除 Python 之外的其他语言。

这些缺点主要是由历史原因造成的，scikit-learn 始于 2007 年的作品，已经有超过十年的历史，其整体架构不适用于目前的 GPU 架构、神经网络和深度学习。不过这些缺点都不足大问题。

在深度学习、神经网络领域，目前有众多的优秀平台：TensorFlow、MXNet、CNTK、PyTorch 等，scikit-learn 模块与这些平台配合，主要用于数据预处理和特征筛选。

GPU 加速和 PyPy 优化属于 Python 底层优化，特别是 NumPy 基础科学计算库的优化，目前对于 GPU 的优化版本已经不鲜见，其中 MXNet、PyTorch 底层模块库，都是基于 NumPy 的 GPU 优化版本。

从工程角度而言，scikit-learn 的性能表现是相当不错的。

究其原因，一方面是因为其内部算法的实现十分高效，另一方面或许可归功于 Cython 约束：通过 Cython 在 scikit-learn 框架内部生成 C 语言代码的运行方式，scikit-learn 消除了大部分的性能瓶颈。

至于最后一个缺点，scikit-learn 模块不支持除 Python 之外的其他
