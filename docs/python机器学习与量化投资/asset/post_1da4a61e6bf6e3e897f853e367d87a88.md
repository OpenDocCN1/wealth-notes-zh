## 7.4 极端随机树算法

极端随机树（Extremely Randomized Trees）算法，简称 ET 算法，也称为异常随机树算法或完全随机树算法，如图 7.10 所示。

![](img/93734a9b810ff3e8778504a648b013dc_163_0.png)

图 7.10 极端随机树算法

ET 算法是由 Pierre Geurts 等人于 2006 年提出，该算法与随机森林算法十分相似，都是由许多决策树构成的，但该算法与随机森林算法有两点主要的区别。

- 随机森林算法采用的是 Bagging 模型，而极端随机树算法使用所有的训练样本都到每棵决策树，也就是说每棵决策树用的是相同的全部训练样本。
- 随机森林算法在一个随机子集内找到最佳分裂属性，而极端随机树算法完全随机得到分裂位，从而实现对决策树进行分裂。

极端随机树算法是随机森林算法的扩展版本，在 RF 算法基础上增加了一些随机性分析来选择分裂特征，在对连续变量特征选取最优分裂位时，不会计算所有分裂位的效果。

极端随机树算法在 RF 算法采用 Bagging 和 Random Subspace 的基础上，对于一棵决策树选取的 Split Value 采用随机生成。

虽然决策树对的非连续数值的特征，会计较的 Split Value，而是按照极端随机算法。对于一个属性在它的取值范围内都会随机生成一个 Split Value，然后选择一个属性来进行分裂（树多一义）。

极端随机算法通过选取节点内的所有特征属性，划分所有特征属性的分叉值，然后分叉值大的那两种形式实现对该节点的分叉，这种方法比随机森林算法的随机性更强。

对于某决策树，由于它的取样分叉属性是随机选择的，因此它的预测结果往往是不准而的，但将多棵决策树组合在一起，就可以达到很好的预测结果
