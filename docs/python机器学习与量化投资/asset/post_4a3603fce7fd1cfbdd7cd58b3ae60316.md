## 8.1 学习模式

根据机器学习算法模型与训练样本处理方式的不同，通常可以把机器学习方法分为两大类：监督学习、无监督学习。近年来，深度学习、神经网络的发展，又增加了一类：强化学习，不过这个属于神经网络领域，不会额外说明

在企业实际应用当中，比较常用的就是监督学习和无监督学习两种模式。在图像识别方面，由于存在大量的目标识别数据和少量的可识别数据，半监督式学习成为一个很热门的话题。强化学习更多应用在机器人控制和其他需要进行系统控制的领域

### 1. 监督学习

监督学习主要用于一部分数据集中（训练数据）有某些可以依据的标签，例如同余的样本缺乏并止要求依据的场景中。

监督学习例子采用的输入数据被称为“训练数据”，每组训练数据有一个明确的标识或结果，如防垃圾邮件系统中的“垃圾邮件”“非垃圾邮件”，手写数字识别中的“1”“2”“3”“4”等。

利用“训练数据”，算法模型会生成映射函数，训练过程会不断纠正，直到模型在训练数据上获得良好的准确度。

监督学习的常见应用场景有分类问题和回归问题，常见监督学习方法有回归方法、DT（决策树）方法、RF（随机森林）方法、K近邻方法，以及BP（反向传播）神经网络方法。

### 2. sklearn监督学习

在sklearn模块中，与监督学习相关的算法模型如下。

- - 广义线性模型（Generalized Linear Models）
- 线性 and 二次判别分析（Linear and Quadratic Discriminant Analysis）
- 内核岭回归（Kernel Ridge Regression）
- 支持向量机（Support Vector Machines）
- 随机梯度下降（Stochastic Gradient Descent）
- K近邻（Nearest Neighbors）
- 高斯过程（Gaussian Processes）
- 交叉分解（Cross decomposition）
- 朴素贝叶斯（Naive Bayes）
- 决策树（Decision Trees）
- 集成方法（Ensemble methods）
- 多分类和多标签方法

- - 拟证选托
- 等式回归
- 概率校准
- 神经网络模型（监督）

### 3. 无监督学习

无监督学习主要用于从未标注数据集中挖掘数据之间蕴含关系的认知

无监督学习模式，数据必须先进行标识，学习模式是为了推断出数据的一些内在结构，例如关联规则的学习和聚类分析等。

无监督学习模式没有任何目标或处结果变量需要预测或估计。这个方法用在不同的组内聚类分析。这种分析方式被广泛地用来细分客户，根据不同的方式分为不同的用户组。

常见的无监督学习算法模型包括 Apriori 关联算法和 k-Means 算法。

### 4. sklearn无监督学习

在 sklearn 模块当中，与无监督学习相关的算法模型如下。

- - 混合混合模型
- 流形学习
- 聚类
- 双聚类
- 分解成分中的信号（例如分解洞见）
- 协方差（...）
- 新奇和异常识别
- 密度估计
- 神经网络模型（无监督）

### 5. 半监督学习

严格说来，半监督学习模式也是监督学习的一种。

只是半监督学习模式的输入数据的一部分被标识，一部分没有被标识，特别在“训练数据”情况之下。

半监督学习模式可以用来进行预测，但它通常先尝试学习数据的内在结构，以便合理地组织数据来进行预测。

半监督学习方法上是一些常用监督学习、分类回归方法的延伸，方法也包括图论推理方法（Graph Inference）和拉普拉斯支持向量机（Laplacian SVM）等。

### 6. 强化学习

强化学习是近年神经网络、深度学习的产物，主要用于动态系统处理以及机器人控制等。强化学习方法可以渐进地进行决策。

在强化学习模型当中，输入数据作为模型的反馈，不像监督模式，输入数据仅仅是作为一个介入模型的方式。

强化学习介于监督学习、无监督学习两者之间，每一步预测或者行为都或多或少有一些反馈信息，尤其是没有正确的标签或者错误提示。

在强化学习模型当中，系统被放在一个能让它通过反复试验来训练自己的环境中。机器从过去的经验中进行学习，并尝试做出新的判断。

强化学习常见方法包括马尔可夫决策过程、Q-Learning 和时间差学习（Temporal Difference Learning）。

## 8.2 机器学习五大流派

在网络上，曾经有人把机器学习分成五大流派。

- - Symbolists（符号学派）：使用符号、规则和逻辑来表征知识和进行推理。关注哲学、逻辑学和心理学，将机器学习视为逆向演绎（Inverse of Deduction)，而用归纳决策树。
- - Bayesians（贝叶斯学派）：注重统计学和概率推理，获取发生的可能性来进行统计推理，常用方法为朴素贝叶斯或马尔可夫。
- Connectionists（联结学派）：使用概率回归加权神经元来动态地识别和归类模式，关注物理学和神经科学，基于研习大脑的逆向工程，常用方法为人工神经网络。
- Evolutionary（进化学派）：在进化学和进化生物学的基地上，设计算法模式，计分并分析其中的最优解，常用方法是进化算法。
- Analogizer（类推学派）：根据约束条件来优化函数，关注心理学和数学优化，以此来推断结果，常用方法为SVM（支持向量机）。

# 概率编程

概率编程，英文全称是 Probabilistic Programming，简称 PP，其更加专业的名字是概率编程语言（Probabilistic Programming Language，简称 PPL）。概率编程是与传统面向过程、OOP（面向对象）完全不同的编程方式。在人工智能领域，概率编程与传统的机器学习、神经网络完全不同，是完全独立的另外一个体系

PP（概率）可以一方面是机器学习、神经网络的重点发展之一。

- - Pyro 概率编程语言：Uber 与加州大学伯克利的研究成果，该语言基于 Python 与 PyTorch，专注于变分推理，同时支持可组合推理方法。Pyro 的推理方法，通过随机数描述构建神经网络模型。
- - WebPPL：一个基于浏览器的在线概率编程平台，以教学为主。
- - Edward：谷歌推出的概率编程框架，是一个用于概率处理、推理和评估的 Python 库。它是一个用于快速实验和研究概率模型的试验平台，同时还集合贝叶斯统计学、机器学习、深度学习、概率编程几个领域。Edward 构建于 TensorFlow 之上，它支持计算图、分布式训练、CPU/GPU 集成、梯度剪切功能，可以使用 TensorBoard 进行可视化分析。

## 9.1 朴素贝叶斯的七证之旅

朴素贝叶斯分类是一系列分类方法的总称，这类方法均以朴素贝叶斯定型为基础，故统称为朴素贝叶斯分类。

朴素贝叶斯方法，英文名亦是 Naive Bayesian，简称NB方法。NB方法...易于实现，且对于大型或...常用。朴素贝叶斯的...对应了...方法的分类方法。朴素贝叶斯定理提供...中P(c)、P(x)及P(x|c)计算...后计算P(c|x)的方法。

NB方法模型由两种概率组成，它们都可以从训练数据中直接计算出来。

- • 每个类别的概率
• 对于给定的x值，每个类别的条件概率。

一旦计算出以上概率数值，NB方法模型就可以使用朴素贝叶斯定理对新的数据进行预测。当数据是离散值时，通常会定义一个钟形的概率分布曲线，这些很容易计算出这些数据的概率。。

理论上，NB方法误差很小，然而所需要的参数也很少，对缺失数据不太...，方法也比较简单。

朴素贝叶斯假定每个输入变量都是独立的，所以被称为“朴素的”。虽然统计学的读者一定都知道，朴素贝叶斯模型在很多领域内有着无与伦比的地位的应用，如图9.1所示。
