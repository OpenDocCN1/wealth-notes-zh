PP 模型大部分都基于 Bayesian（贝叶斯）方法，目前常见的 PP 方法如下。

+   - Bayesian（贝叶斯）方法。\n- Bayesian Inference（贝叶斯推理）。\n- MCMC（马尔科夫蒙特卡罗）方法。\n- 序列蒙特卡罗推理方法\n- HMC（哈密顿蒙特卡罗）方法。

PP 方法更多用于神经网络、深度学习领域，从本质的名称而言，有点过于专业了，不过在 sklearn 机器学习模块中，也成了一组和 PP 方法相关的函数。

一组函数是基于（贝叶斯）方法，如下所示。

+   - MultinomialNB，多项式朴素贝叶斯算法\n- GaussianNB，高斯朴素贝叶斯算法\n- BernoulliNB，伯努利朴素贝叶斯算法

另外一组函数是基于 HMM（隐马尔可夫）方法，如下所示。

+   - GaussianHMM，高斯分布 HMM 模型函数\n- GMMHMM，高斯混合的 HMM 模型函数。\n- MultinomialHMM，多项式（离散）HMM 模型函数。
