### 4. Exceptions（异常和警告）

sklearn.exceptions: 异常和警告模块，包括 sklearn 模块所涉及的异常和警告。

### 4、输出信息和处理异常

- NotFittedError: 如果分类器在拟合前调用，将抛出异常。
- ChangedBehaviorWarning: 警告类通知，用于任何行为上的变化。
- ConvergenceWarning: 自定义警告，用于捕获收敛问题。
- DataConversionWarning: 警告通知，用于格式或类型转换。
- DataDimensionalityWarning: 自定义警告，通知用户数据/维度的潜在问题。
- EfficiencyWarning: 警告通知用户计算效率低。
- FitFailedWarning: 警告类，用于拟合评估时存在的错误。
- NonBLASDotWarning: 当没有使用 BLAS 计算时运行时出现警告。
- UndefinedMetricWarning: 无效度量时出现警告。

### 5. Cluster（聚类）模块

sklearn.cluster: 无监督聚类算法模块。主要的类定义如下。

- AffinityPropagation: 仿射传播聚类算法。
- AgglomerativeClustering: 层次聚类算法。
- BIRCH: 聚类算法。
- DBSCAN: 密度聚类算法（基于密度）。
- FeatureAgglomeration: 特征聚类算法。
- KMeans: K-均值聚类算法。
- MiniBatchKMeans: 迷你批次 K-均值聚类算法。

- MeanShift: 均值偏移聚类算法。
- SpectralClustering: 投影归一化（找出拉普拉斯分解）聚类方法，上述的函数如下
- estimate_bandwidth: 计算均值偏移聚类使用的带宽
- k_means: K-means 聚类方法。
- ward_tree: 沃德基于聚类的树结构图。
- affinity_propagation: 仿射传播聚类算法。
- dbscan: DBSCAN 密度聚类算法。
- mean_shift: 均值偏移聚类算法。
- spectral_clustering: 投影归一化（找出拉普拉斯分解）聚类方法。

### 7. Covariance（协方差估计）

sklearn.covariance: 协方差估计模块，包括一组处理估计协方差的估计方法。协方差矩阵定义为逆的协方差，协方差估计方法所形成的几何相似性理论密切相关 包括以下函数。

- EmpiricalCovariance: 最大似然估计协方差。
- EllipticEnvelope: 用于检测异常的高斯分布数据集中
- GraphLasso: 企图估计协方差估计方法，使用 L1 惩罚估计器。
- GraphLassoCV: 在估计协方差交叉验证，使用 L1 惩罚估计器。
- LedoitWolf: 估计器
- MinCovDet: 最小协方差行列式（MCD），稳健估计器的协方差。

### 8. model_selection（模型选择）

sklearn.model_selection: 模型选择模块，包含以下几大分类

- Splitter Classes: 分割器类
- Splitter Functions: 分割函数
- Hyper-parameter: 超参数优化
- optimizers Model validation: 模型验证优化

#### （1）Splitter Classes（分割器类）

- KFold: K-折交叉验证
- GroupKFold: K-折迭代交叉的分组分割
- StratifiedKFold: 分层 K-折交叉验证方法
- LeavePGroupsOut: 留 P 组交叉验证方法
- leavepgroupseutN: 留 P 组交叉验证序列
- LeaveOneOut: 留一法交叉验证序列
- LeavePOut: 留 P 法交叉验证方法
- ShuffleSplit: 随机划分交叉验证方法
- GroupShuffleSplit: 混洗组交叉迭代验证方法
- StratifiedShuffleSplit: 分层混洗分割交叉验证序列

- PredefinedSplit: 预定义分割交叉验证对象。

- TimeSeriesSplit: 时间序列交叉验证对象

#### （2）Splitter Functions（分割函数）

- train_test_split: 训练和测试数据集分割函数

- check_cv: 建立交叉验证输入检查器。

#### （3）Hyper-parameter（超参数优化）

- GridSearchCV: 网格搜索交叉验证。

- RandomizedSearchCV: 随机搜索交叉验证。

- ParameterGrid: 对函数进行多参数网格搜索。

- ParameterSampler: 指定分布按参数抽样生成器。

- fit_grid_point: 按一组参数运行拟合。

#### （4）optimizers Model validation（模型验证优化）

- cross_val_score: 交叉验证评估评分。

- cross_val_predict: 对给定一个输入数据点生成交叉验证评估器。

- permutation_test_score: 评估是否交叉验证式评分的敏感性。

- learning_curve: 学习曲线。

- validation_curve: 验证曲线。
