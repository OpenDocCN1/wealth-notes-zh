在调用 PCA 算法进行降维处理时，n_components 调用参数不同的数值表示不同保留维度，对模型最终结果会有所影响。

+   - n=2，准确度为 63.83%。
- n=3，准确度为 67.02%。
- n=4，准确度为 68.09%。

当数据采用标准的 OHLC 格式时，输入数据属性字段仅有 4 个字段。当 n=4 时，其实并没有进行降维处理，所以最终的准确度结果是 68.09%，这与直接调用 K 邻近回归函数完全一样。
