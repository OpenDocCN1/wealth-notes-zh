# 25. naive_bayes（朴素贝叶斯）方法

sklearn.naive_bayes 模块，包含朴素贝叶斯（Bayes）方法，这些是在监督学习方法的基础上，应用贝叶斯定理和强（朴素）的条件独立性假设开发的方法。

+   - GaussianNB: 高斯朴素贝叶斯方法。
- MultinomialNB: 多项式朴素贝叶斯方法
- BernoulliNB: 二元伯努利（Bernoulli）朴素贝叶斯方法。

# 26. Neighbors（近邻）方法

sklearn.neighbors 模块：实现了 K-近邻方法

+   - NearestNeighbors: 无监督学习邻居搜索方法。
- KNeighborsClassifier: K-近邻方法。
- RadiusNeighborsClassifier: 给定半径内的近邻投票方法。
- KNeighborsRegressor: K-近邻回归方法。
- RadiusNeighborsRegressor: 给定半径内的近邻回归方法。
- NearestCentroid: 最近质心方法。
- BallTree: BallTree快速广义NN空间搜索方法。
- KDTree: KDTree快速广义NN空间搜索方法
- LSHForest: 基于LSH布料类似的近邻方法。
- DistanceMetric: 距离度量类。
- KernelDensity: 核密度估计。
- LocalOutlierFactor: LOF方法，用于识别异常子的无监督异常检测方法。
- kneighbors_graph: 估计（加权）为点x的k近邻图。
