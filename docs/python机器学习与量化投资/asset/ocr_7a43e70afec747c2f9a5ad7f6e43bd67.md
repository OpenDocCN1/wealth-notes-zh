# 案例 3-5：当上证遇到机器学习

据集合，过<|start|>这 4 组数据交换的名称如下。

+   - x_train，训练数据多维数组数据集合。
- y_train，训练数据一维结果数据集合。
- x_test，测试数据多维数组数据集合。
- y_test，测试数据一维数组数据集合。

习惯上将 x 数据集合用于训练，y 数据集合用于测试。此外通过对数据集合 y_train 的分析，会生成一个新的预测结果数据集合 y_pred，这个数据集合也是一维的结果数据集合。

案例 3-5 的文件名是 kb305_ids01.py，本案例将具体介绍如何按机器学习的要求把上证指数分为训练数据集合和测试数据集合。
