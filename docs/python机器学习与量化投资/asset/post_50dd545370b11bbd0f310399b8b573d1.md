## 3.4 preprocessing模块

sklearn 在数据处理方面做了大量工作，专门集成了一个用于数据预处理的子模块：preprocessing。

事实上，目前的深度学习、神经网络平台，例如 TensorFlow、MXNet 也在广泛使用 sklearn 的 preprocessing（数据预处理）模块作为数据处理的工具。

## Python 机器学习与量化投资

preprocessing 数据预处理模块，全称是预处理和规范化 (Preprocessing and Normalization)

sklearn.preprocessing 模块包括数据缩放、归一化、二值化包括补齐方面的函数。具体如下

- Binarizer：根据阈值数据进行二值化
- FunctionTransformer：构建自定义函数
- Imputer：用于处理缺失值的抽补变换函数。
- KernelCenterer：中心内核矩阵。
- LabelBinarizer：标签二值化。
- LabelEncoder：把列表中类标的数据标记化为数字编码。
- MultiLabelBinarizer：多标签二值化。
- MaxAbsScaler：按照特征最大绝对值进行缩放。
- MinMaxScaler：最大化、最小化规范化
- Normalizer：各个数据归一化处理，使样本特征和为 1
- OneHotEncoder：独热编码。
- PolynomialFeatures：生成多项式特征变数。
- RobustScaler：使用对异常值鲁棒的统计信息来缩放
- StandardScaler：通过消除平均值和缩放到单位方差来标准化特征，使各特征的均值为 0，方差为 1。
- add_dummy_feature：添加数据集中。
- binarize：表达布尔值特征
- label_binarize：以 one-vs-all 的方式对标签进行二值化
- maxabs_scale：将每个特征缩放到[-1,1]范围，而不破坏稀疏度。
- minmax_scale：通过将每个功能缩放到给定范围内来转换功能
- normalize：将输入向量分别缩放到单位范数（向量长度）

## 案例 3-6：比特币与标准化

数据标准化，英文名称是 DataStandardization，即将特征或样本的分布归一成标准正态分布，也叫高斯分布。

数据标准化最常用的方法是 z-score 规范化，也称零均值规范化，也即使处理数据的均值为 0，方差为 1。

标准化的原因在于数据的特征的方差过大，会影响、影响数据集中其他特征的权重。

标准化的过程为两步：去均值的中心化（均值变为 0）；方差的规约化（方差变为 1）。

在 sklearn.preprocessing 模块当中内含着 scale 函数。

# 案例 3-7：比特币与归一化

数据标准化归一化，是数据预处理的两个上下以

## Python 机器学习与量化投资

归一化的具体作用是归纳统一样本的统计分布性。归一化在(0,1)之间是统计的概率分布，归一化在(-1,1)之间是统计的坐标分布。之所以将特征归一化到一定的范围内，是为了应付那些标准差距小的特征并且保留原始数据中的0位。

归一化有同一、统一和合一的意思，从根本上，神经网络是统计概率作为核心运作方式的。

从运作深层的角度而言，其实也可以不进行归一化处理。不过，归一化可以加快训练神经网络的收敛性，提高模型运作效率。通常在模型训练前对数据进行归一化处理。

在 sklearn 模块库中提供了 MinMaxScaler、MaxAbsScaler 等函数用于数据归一化处理。

案例 3-7 的文件名是 kb307_prc02.py，本案例用于介绍数据归一化函数的使用。
