# 网络资源

本书的案例程序，已经做过优化处理，无须 GPU 显卡，个个支持单 CPU 平台，不过为避免版本冲突，请尽量使用 zwPython2017m6 版本运行本书的案例程序

使用其他运行环境的读者，如 Linux、Mac 平台的用户，请尽量使用 Python 3 版本，自行安装其他所需的模块，如 Numpy、Pandas、Tushare 等第三方模块。

此外还要注意的是，大家运行本书案例得到的结果可能与书中略有差别：因为多次运行同一案例，结果都有所不同。这属于正常情况，因为很多机器学习算法，内部使用了随机数作为种子，用于系统变量初始化等操作，每次分析的结果或各中间参数会有所不同。

版本冲突是开源项目常见的问题，为了处理这个问题，本书的源码是独立保存的。此外，我们还另行设计了 zwPython 教学版。

建议初学名先使用 zwPython 教学版，相关的插件程序，已经经过版本兼容测试，并且集成了 zwDat 金融数据库。
