+   - Bayesians（贝叶斯学派）：注重统计学和概率推理，获取发生的可能性

- Connectionists（联结学派）：使用概率回归加权神经元来动态地识别和归类模式，关注物理学和神经科学，基于研习大脑的逆向工程，常用方法为人工神经网络。
- Evolutionary（进化学派）：在进化学和进化生物学的基地上，设计算法模式，计分并分析其中的最优解，常用方法是进化算法。
- Analogizer（类推学派）：根据约束条件来优化函数，关注心理学和数学优化，以此来推断结果，常用方法为SVM（支持向量机）。

# 8.3 经典机器学习算法

经典机器学习算法不是通过对算法模型的内在逻辑和归纳关系，而是从机器学习算法模型在学术工程领域的应用角度，或许知名度来对算法模型进行命名

这种命名虽然看起来有些不妥各见，但从某个角度思考，这未免不足冲实践上意义在人工智能领域的运用。

机器学习常用的经典算法如下：

+   - PP（统计的...）
- RA（回归方法）
- IA（实例方法）
- RA（正...化方法）
- DT（决策树）
- NB（贝叶斯方法）
- CA（聚类分析）
