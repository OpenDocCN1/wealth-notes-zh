而不仅关心事件发生的概率影响：

+   - classification_report: 产生一个七类分类报告的文本报告
- cohen_kappa_score: 计算 Cohen Kappa 评分，统计误差注释协议
- confusion_matrix: 计算混淆矩阵来评估分类性能
- f1_score: 计算 F1 评分，又称为平衡 F 或 F-分歧度评分
- fbeta_score: 计算 F-beta 评分
- hamming_loss: 计算平均汉明损失
- hinge_loss: 平均铰链损失（未正则化）
- jaccard_similarity_score: Jaccard 相似性系数评分
- log_loss: log 损失，逻辑损失，又称为交叉熵损失
- matthews_corrcoef: 计算 分类的马修斯相关系数（MCC）
- precision_recall_curve: 对不同阈值绘制精度-召回率
- precision_recall_fscore_support: 计算准确率、召回率、F-measure 等参数
- precision_score: 计算精度
- recall_score: 计算召回率
- roc_auc_score: 计算曲线下面积（AUC）的面积评分
- roc_curve: 计算 ROC 受试者操作特征评分
- zero_one_loss: 零分类损失

# （3）Regression metrics（回归度量）

+   - explained_variance_score: 解释方差回归评分函数
- mean_absolute_error: 平均绝对误差回归损失
- mean_squared_error: 回归均方平方误差损失
- mean_squared_log_error: 对数回归均方平方误差损失
- median_absolute_error: 中位数绝对误差回归损失
