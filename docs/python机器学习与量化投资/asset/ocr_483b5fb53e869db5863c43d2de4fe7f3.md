使用了 scipy 柯对应的实现。arpack 和 randomized 的使用关系类似。区别是 randomized 使用的是 scikit-learn 自己的 SVD 实现，而 arpack 却使用 了 scipy 柯的 sparse SVD 实现。默认是 auto，即 PCA 办法会从前面讲到的三种办法里面去权衡，选择一个合适的 SVD 办法来降维。一般来说，使用默认值就够了

PCA 函数返回的是一个 PCA 对象，主要包括以下属性。

+   - components_，返回具有最大方差的成分
- explained_variance_，降维后的各主成分的方差
- explained_variance_ratio_，返回总 n 个归各自的方差占比比例，总是对应归类。
- n_components_，返回所保留的特征个数 n。
- mean_，返回值的平均值。
