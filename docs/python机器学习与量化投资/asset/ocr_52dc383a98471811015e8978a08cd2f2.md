# 17. kernel_approximation（核近似）模块

sklearn.kernel_approximation 模块收录了核近似方法，基于随机叶交叉特征映射内核近似方法。

+   - AdditiveChi2Sampler: 添加卡方核近似特征映射。
- Nystroem: 奈斯特姆 Nystroem 内核近似方法，使用训练数据的一个随机子集。
- RBFSampler: RBF 内核近似方法，基于蒙卡洛随机叶变换的 RBF  简效映射。
- SkewedChi2Sampler: 近似特征映射的“斜卡方”内核，基于卡洛随机叶交换方法。
