
KNN 方法的由来及分类(?)：

KNN 方法通过周围 k 个案例中的大多数情况划分新的案例。根据一个距离函数，新案例会被分配到它的 k 个近邻中较为接近的类别中。

KNN 方法是一个相对比较简单的机器学习算法，在理论上也比较成熟。KNN 方法的核心思路是：如果一个样本在特征空间中的 k 个最相似（即特征空间中最邻近）的样本中的大多数属于某一个类别，则该样本也属于这个类别。

KNN 方法的分类是根据一个距离函数进行判别的。这些距离函数可以是欧式距离、曼哈顿距离、闵式距离或齐次汉明距离。前三个距离函数用于连续变量，第四个函数（汉明函数）则被用于分类变量。

需要注意的是，距离或紧密度的概念在高维度（或者大量的输入变量）中可能会失效，因为输入变量的数量对于算法性能有着很大的负面影响，这就是所谓的维度灾难。

KNN 方法的缺点是需要大量的距离计算，计算成本很高。数据要进行预处理，对异常数据要去除和清洗，此外还要对数据进行标准化处理。

在 sklearn 模块库当中，K 最近邻算法相关的机器学习算法函数位于 neighbors 模块库，主要如下。

- KNeighborsClassifier，K 最近邻算法。
- NearestNeighbors，最近邻算法。
- KNeighborsRegressor，K 最近邻回归算法。
- NearestCentroid，最近质心算法。
- Locality Sensitive Hashing Forest，局部敏感哈希森林算法。

# 正则化算法

正则化算法，英文全称是 Regularization Algorithms。正则化算法是其他算法（比如回归算法）的延伸，根据算法的复杂度对算法进行约束。

正则化算法是对模型复杂度对其进行“奖惩”，它喜欢对简单的、能有更好泛化能力的模型，通常会对简单模型予以“奖励”，而对复杂模型予以“惩罚”。

正则化算法的优点是其“惩罚”会减少过拟合，可以找到最佳结果。正则化算法的缺点是其“惩罚”会造成欠拟合，很欠拟准模型参数。

在机器学习中，无论是分类方法还是回归方法，都可能存在由于特征过多而导致的过拟合问题，通常的解决办法有两种。

- 减少特征，即取最重要的特征。
- “惩罚”不重要的特征的权重。

广告行业有个名言：

我们都知道有 50% 的广告是无效的，但问题是，我们不知道是哪 50%。

同样，对于机器学习而言，在通常情况下，大家也不知道：

应该“惩罚”哪些特征的权重取值。

向正则化方法可以防止过拟合，提高泛化能力，解决这类的问题，如图 11.1 所示。

![](img/93734a9b810ff3e8778504a648b013dc_206_0.png)

图 11.1 正则化方法

正则化方法可以保留数据原来的特征变化，但是会减小特征变化的改变。这个方法非常有效，几乎有很多特征变量时，每个变量都可能对最终的预测结果产生一点影响。

正则化项即惩罚函数，该函数对模型向心进行“惩罚”，从而避免单纯最小二乘问题的过拟合问题。

近年来，随着神经网络、深度学习技术的发张，大数据模型的流行，数据的正则化方法的研究也越来越深入。

目前常见的正则化方法如下。

- 岭回归方法，英文全称 Ridge Regression。
- LASSO 方法，最小收缩选择方法，又名套索回归方法，英文全称 Least Absolute Shrinkage and Selection Operator。
- EN（弹性网络方法），英文全称 Elastic Net。
- LAR（最小角回归）方法，英文全称 Least-Angle Regression。
- L1 和 L2 正则化方法。

## 11.1 岭回归算法

岭回归方法，英文全称 Ridge Regression，简称 RR 方法。

岭回归算法本质上是对小二乘法的改进版本，通过损失部分性质、降低精度，使其结果更加符合实际，是一种更可靠的回归方法。如图 11.2 所示。

![](img/93734a9b810ff3e8778504a648b013dc_207_0.png)

图 11.2 RR（岭回归）算法

以前我们条形的准确度（按 1%精度）达到人约有 68%，接近七成。而 RR 岭回归算法没有经过任何优化，准确度达到 73.40%。

在处理戈尔数据的回归问题时，线性回归通常会遇到以下一些问题，

- 预测精度低。
- 当结果数据方差小时，容易产生过拟合。
- 当结果数据方差小时，容易产生无效结果
- 模型的解释能力低，戈尔型度高。

岭回归方法，我们严格的理论基础：

根据高斯-马尔可夫定理，多重相关性并不影响最小二乘法估计量的无偏性和最小方差性。

最小二乘法估计量在所有线性估计量中是方差最小的，但是这个不一定足够优化。

通常，还可以找到其他的估计量，这个估计量虽然有较小的偏差，但它的精度如能大大高于无偏的估计量。

岭回归方法，总是根据以上原理，通过在正规方程中引入ϕ的而使以获得最优结果。

岭回归方法虽然效果不错，不过还存在以下一些问题。

- 岭参数选择方法太多，滞后太大。
- 根据岭迹图进行变量筛选，主观性太大。
- 模型变量太多，难以筛选。

为改进岭回归方法当中的这些问题，有学者又提出了 LASSO（套索）方法、LAR（最小角回归）方法等多种改进版本的算法模型，以优化模型结构，方便筛选自变量。

岭回归方法本质上是一种缩减的方法，通过把一些系数缩减成很小的数，来优化模型结果，类似于降维方法，保留最少的特征，以减少模型的误差，便于判断。

实际研究表明，与简单的线性回归相比，这种缩减方法的确能够取得更好的预测效果。

## 11.2 套索回归算法

套索回归算法，英文全称是 Least Absolute Shrinkage and Selection Operator，如图 11.3 所示。

![](img/93734a9b810ff3e8778504a648b013dc_211_0.png)

# 图 11.3 LASSO（套索）回归算法

岭回归算法主观性太大，很多多余的选取都需要人工，仍然经验证手动完成，完全不适合大数据和机器学习思想。

为克服这些缺点，有学者对岭回归算法进行了多方面的优化，设计出套索回归算法

套索回归算法，是 1996 年由斯坦福大学统计学家 Robert Tibshirani 提出来的，套索回归算法最初用于计算最小二乘法模型。套索回归算法输入简介，却揭示了很多估计值的 accesses 性质。

- 估计值与岭回归和系数选取的关系。\n- 套索回归系数估计值和软阈值之间的关系\n- 当协变量共线性时，套索回归系数估计值不一定唯一。

套索回归算法模型简单，便于分析，而且方便筛选多效变量。套索回归算法通过构造一个惩罚项得到一个较为简洁的模型，压缩一些系数，同时设定一些系数为零。

套索回归算法也叫作线性回归算法的 L1 正则化，和岭回归算法的主要区别就是在正则化时，岭回归算法用的是 L2 正则化，而套索回归算法用的是 L1 正则化。

图 11.5 弹性网络算法
