前面几组代码， ## 数据准备，和前面的案例 9-2 大同小异，故此处不再重复说明。

第 5 组代码如下：

```
#5
print('第5, 模型设立')

mx = linear_model.Lasso()
```

```
#6
print('第6, fit 训练模型')

mx.fit(x, y)
调用 fit 函数，训练模型。
```
