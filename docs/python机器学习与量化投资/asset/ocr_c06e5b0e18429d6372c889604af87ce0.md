# 13.1 主成分分析

主成分分析方法，英文全称是 Principal Components Analysis，简称 PCA 方法。

PCA 方法是统计学的方法，通过正交变换将一组可能存在相关性的变量转换为一组线性不相关的变量，转换后的这组变量称为主成分，如图 13.1 所示。

![](bbox=[0.33, 0.5, 0.68, 0.68])

PCA 方法是常用的降维方法之一，在数据压缩、消除冗余和改善数据中的噪声等领域应用。以及我们提到降维时容易想到的办法就是 PCA 方法，下面我们就对 PCA 方法的原理做一个总结。

PCA 方法可以用来降低算法计算开销、去除噪声，以及使结果易于展示理解等。
