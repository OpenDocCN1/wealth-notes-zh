这种保守主要体现在两个方面。

+   - scikit-learn 从来不处理机器学习领域之外的其他扩展。
- scikit-learn 从来不采用未经广泛验证的算法。

# 1.1.1 scikit-learn 的缺点

虽然 scikit-learn 以模块功能强大，目前已经是机器学习领域重要的模块了。但是，scikit-learn 也有缺点。

scikit-learn 模块的缺点主要包括以下几个方面。

+   - 不支持深度学习和强化学习。
- 不支持 PyPy 加速，也不支持 GPU 加速。
- 不支持除 Python 之外的其他语言。

这些缺点主要是由历史原因造成的，scikit-learn 始于 2007 年的作品，已经有超过十年的历史，其整体架构不适用于目前的 GPU 架构、神经网络和深度学习。不过这些缺点都不足大问题。

在深度学习、神经网络领域，目前有众多的优秀平台：TensorFlow、MXNet、CNTK、PyTorch 等，scikit-learn 模块与这些平台配合，主要用于数据预处理和特征筛选。

GPU 加速和 PyPy 优化属于 Python 底层优化，特别是 NumPy 基础科学计算库的优化，目前对于 GPU 的优化版本已经不鲜见，其中 MXNet、PyTorch 底层模块库，都是基于 NumPy 的 GPU 优化版本。

从工程角度而言，scikit-learn 的性能表现是相当不错的。

究其原因，一方面是因为其内部算法的实现十分高效，另一方面或许可归功于 Cython 约束：通过 Cython 在 scikit-learn 框架内部生成 C 语言代码的运行方式，scikit-learn 消除了大部分的性能瓶颈。
