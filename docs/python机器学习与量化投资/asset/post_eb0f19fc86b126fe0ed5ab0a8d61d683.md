
## 1.3 机器学习：从忘记开始

广大初学者面对人工智能、机器学习这些“高大上”的概念，一方面迫切希望能够学习相关的知识，另外一方面，面对各类层出不穷的概念，会让人眼花缭乱，无所适从。

目前 Python 已经是人工智能、机器学习的行业标准语言，TensorFlow、Torch 在 2015 年、2016 年先后开放了 Python 语言接口。

scikit-learn 是 Python 语言生态下的人工智能模块库，目前已经收入 scikit 基金会，通常仍称为 sklearn

还记得我们开头的那个 scikit-learn 引发的风波吗？不知道大家的第一反应是什么，反正笔者听到此间的第一反应是吓呆了，也明白为什么这么多初学者对人工智能趋之若鹜。

笔者始终认为自己是一名软件工程师，或者叫程序员，也只是网络上常说的“码农”。

对于程序员而言：Talk is cheap, show me the code!

更多的理论，也比不上几个成功的软件作品，笔者虽然谈不上有什么成功的大型作品，但也写过不少小型的程序，例如原生的 OCR 识别程序和英汉翻译软件。

特别是英语翻译软件，笔者当时（1997年）的翻译程序所使用的是免费的字典，几十万条的翻译程序，多种语言资料，全部都同步时间同步，基本无需任何成本，翻译效果也还不错。而当时同类同家的翻译软件，收费巨大，也不过几十万条的资源库。

那么原生程序，应该是采用 C 语言、Delphi 语言的标准而改善，没有任何第三方 AI 架构（如 sklearn、TensorFlow 等 AI 模块）依赖的程序。共同的难处，做过系统的程序员，或者阅读过 Linux、安卓系统、TensorFlow 系统源码的程序员才会明白

### 2.1 经典机器学习算法

目前，机器学习虽然众多纷入，但还处于启蒙阶段。在本节的案例中，涉及以下经典的机器学习方法。

今后在爱尼花卉数据集（Anderson's Iris data set），也称许尼花卉数据集

朵（Iris flower data set）或是鸢尾花卉数据集（Fisher's Iris data set），是一类多重变量分析的数据集 它最初来源于加·安德森从加拿大加的纳半岛上的鸢尾花朵中捉取的地界分类数据，后由罗纳德·费舍尔作为判别分析的一个例子，并运用于统计学中 该数据集包含了 50 个样本，归属于鸢尾花下的三个亚种，分别是山鸢尾、变色鸢尾和杂吉尼三鸢尾 共 4 个特征用于样本的变量分析，即花萼和花瓣的长度和宽度 基于这 4 个特征的集合，我们发展了线性判别分析以确定其分类

我们的目的还是通过案例，对这 3 种不同种类的鸢尾植物的数据，采用专业的数据分析手段和人工智能方法，让同学们学会分类植物的种类

由于 scikit-learn 出现很早，当时还没有 pandas 等下一代数据分析软件，所以 sklearn 为了保证运行速度，还这使用 NumPy 模块的 ndarray 多维数组作为数据源和内部的数据格式

近几年出现的 TensorFlow、MXNet 等神经网络、深度学习平台，为了提高效率，在数据接口部分也广泛使用 NumPy 模块的 ndarray 多维数组格式

不过 NumPy 模块的 ndarray 多维数组是面向性能的数据格式，在应用方面不常规易用

目前，随着 pandas 等新一代数据分析软件的普及和推广，以及一级开发人员对效率的考量，越来越多的项目开始使用 pandas 的 DataFrame 数据框架作为数据保存格式，从而方便调试代码，交换数据

本节的各个案例都基于 pandas 优先的模式，所以广泛使用 DataFrame 数据框架作为程序中间数据，只要在必须使用 NumPy 模块的 ndarray 多维数组格式时，才转换为对应的格式

有关数据转换的细节，我们会在实例当中具体说明。本程采用 pandas 对比 sklearn 人工智能，以便初学者把握数据内部的结构和细节

传统的 sklearn 人工智能文档，大部分还这采用 NumPy 数组格式，而 NumPy 是为了追求极限性能设计的模块库， 很多方法函数非常复杂，不宜

于此

从总体进度上讲，绝大部分初学的人工智能学习之路，介于步入门从 NumPy 这个模块开始给吓退了

本以全部采用简洁的 pandas 命令，从这些源到 sklearn 进行结合，无须学习额外的语法，以便于初学入门

### 2.3 机器学习算法流程

通常机器学习的算法流程如下：

- 选择模型函数 mx_fun。
- 把训练用的特征数据矩阵 x_train 和对应的标签（结果）数据矩阵 y_train，传入模型的函数 mx_fun。
- 系统内部的机器学习函数会自动分析特征数据与结果数据之间的人系，这其中的一个过程就是机器学习的过程，也是训练模型的过程。
- 通过对训练数据的机器学习和数据分析，系统会生成一个 AI 机器学习的模型，我们将其保存在变量 mx。
- 把测试数据 x_test 输入到 mx 模型变量中，mx 会调用内部的分析函数 predict，生成最终的分析结果 y_pred。
- 如果是实盘，我们输入最新的数据，比如今天的股市数据正在进行中的足彩比赛赔率数据，系统会自动生成相关的预测数据，比如每天或未来几天股市走势数据或其他输出结果预测数据。

在进行实盘运行前，我们会对模型产生的预测数据 y_pred 和正确结果数据 y_test 进行对比，判断模型的准确度，并通过一些优化措施和参数调整进行迭代运行，或者采用其他的模型提高最终结果的准确度。

### 2.4 机器学习数据集

机器学习通常使用两组数据，一组作为训练数据，一组作为测试数据。在每组数据中都包含一组多维的多数据矩阵作为特征数据矩阵，以及一组一维的数据作为结果分类数据，从而形成 4 个数据集，通常这 4 组数据变量的名称如下：

- x_train，训练数据，多维多枚数据矩阵。
- y_train，训练数据，一维结果数据矩阵。
- x_test, 测试数据，多维多变量数组。
- y_test, 测试数据，一维多变量数组。

习惯上，train 数据集用于训练，test 数据集用于测试。此外，通过对数据集 y_train 的分析，会生成一个新的预测结果数据集 y_pred。这个数据集也是一维的结果数据集。

通过对结果数据集 y_pred 与实际的测试数据集 y_test 的对比，就可以评估模型的准确度。
