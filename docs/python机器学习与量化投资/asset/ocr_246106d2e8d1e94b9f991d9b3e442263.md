函数返回的值保存在变量 c10 当中，是 list 列表格式。

再说的是，在 cross_val_score 函数的返回值中可以负数 例子中 cv 参数为 10 时，对应的输出结果如下：

```
cross_val_score: [ 0.1924246  0.33670479  0.78512653
0.04713863 -0.09994952  0.44728146  0.00533902 -1.7067912
0.75230078 -0.39694398)
mean: 0.03526319049678992
```

c10 的返回值不能用绝对值的方式，不然平均值会出现大于 100% 的情况。
