这个深度仅仅有些,只作为教学案例使用,为了方便决策树模型的输出。在实际当中,往往会使用较大的深度

不过决策树方法容易出现过拟合的问题,所以也很少使用类似深度学习及神经网络方法般的深度进行训练。
