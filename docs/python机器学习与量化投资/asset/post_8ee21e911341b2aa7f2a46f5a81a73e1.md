## 2.5 数据切割函数

在代码中，涉及一个 sklearn 模块的专业函数：

train_test_split

train_test_split 函数只是对数据进行切割，为了数据划分处足够随机，并非正规的机器学习函数

我们也可以通过其它函数或自行编写的函数完成类似的功能 在前面的例子中，数据文件读取也有类似的功能。

对于所有通用的情况，集合而言，sklearn 内的 train_test_split 函数使用更加方便

train_test_split 函数是 sklearn 的 cross_validation 子模块中，功能是从样本中按比例随机选取 train data 和 test data

需要注意的是，在未来新版本的 sklearn 框架中，cross_validation 子模块会废弃，train_test_split 函数分离函数会采用全新的框架接入。

下面，该函数的调用语法形式为：

```
x_train, x_test, y_train, y_test = train_test_split(x, y,
test_size=0.4, random_state=0)
```

其中：

- x 是训练参数的数据集合
- y 是训练参数 x 相关的结果数据集合。
- test_size 是样本占比，如果是整数，则是样本的数目。
- random_state 是随机数的种子。

## 金融数据的预处理

在现实世界中，金融股票数据是相对比较规范的数据源，但还是存在许多不完整、不一致的“脏数据”。这些“脏数据”不仅无法进行数据分析和机器学习，还会影响最终的结果

为了提高数据分析、机器学习的质量，数据预处理技术应运而生

数据预处理，英文名称为：Data Preprocessing，是指在数据分析、机器学习前，对原始的数据进行分类或分组后，对数据的清洗、筛选、排序等必要的处理过程。

数据预处理有多种方法：数据清理、数据集成、数据变换、数据缩减等，其核心都是数据的“归一化”处理。

各种数据预处理技术，大大提高了数据分析模型的质量，降低了企业识别分析所需的时间。

## 3.1 至简归一法

数据归一化是数据预处理中常见也最常用的处理方法，即将不同类型的表达式经过转换化为互相统一的表达式，成为标准。在很多计算中都会用到这种方法

## 归一化形式

- 把数值变为(0,1)之间的小数。
- 把有约束表达式变为无约束表达式。

归一化变换是为了方便数值处理，使其可控，把数值映射到(0,1)的区间之内来处理，可以更加便于运算。归一化是一种无约束处理下可以使数值绝对值变成相对值的关系，是一种简化计算、缩小范围的有效办法。并且在各步骤结束后。并经过反归一化处理，一切数值都可以还原
