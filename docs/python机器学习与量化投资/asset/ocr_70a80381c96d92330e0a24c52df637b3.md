-化处理：

不论是化绘金之投资，还是化交易，在进行投资回报分析时，经常会要把不同的股票按投资回报率、收益累计在一张图当中再进行对比分析，从中找出似佳的或优劣的投资产品。

一般而言，进行单一股票的收益率为分析还是比较简单的，把最终的资产总额除以投资额即可。不过，对于化交易而言，这些当中存在数十只不同的股票，股价部不相同，进行对比分析会非常麻烦，就需要先进行数据的归一化处理。

不过有了 Rebase 变量归一化函数，这分析就非常简单了。

需要注意的是，Rebase 变量归一化函数并不是 Python 和 pandas 的原生函数，而是 Pn 金融模块对于 pandas 的克充函数。

具体细节，请参见相关网址：http://pmorisscile.github.io/fn/
