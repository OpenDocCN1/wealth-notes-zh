# 成熟 Python 开发平台

+   - 提出“零配置、零安装”开发理念，绿色软件即开即用，类似 Mac 开发...类似风格，免驱安装，解压即可直接使用，还可以放入 U 盘，又有 Mob-App 移动式开发环境。
- 具有“外引”与“内引”双开发功能，内含众多功能强大的开发模块，如 OpenCV 视觉、人工智能、CUDA 性能 GPU 计算库（OpenCL）、pandas 数据分析、机器学习、NLTK 自然语言处理
- 便于扩展，用户可以轻松添加相关模块后，体验功能已齐全，无需用户“预设”，例如像拷贝文件一样简单，向U盘移动便可继续开发，实现“一次安装，到处可用”
- 针对中文开发文档缺乏、系统的不足，内置了诸多中文文档 OpenCV、Fontforge 和 Python 入门教程
- 内置众多中文字体 TrueType 字体
- 人性化例程不缺项，涵盖 OpenCV、CUDA、OpenCL、Pygame 等

如此种种只是为了使 IT 行业外的用户能够“零起步”，快速入门，并迅速在时间内应用到生产环境当中。

zwPython 前身是 zw2015sdk：为了能够从设计平台，从设计开始向广大设计师提供一个统一的、可移植的字体设计平台，以便于大家交流

+   - 设计师、美工及文艺青年、IT 小白，所以，简单是必须的，开软件用也必须是零吧。
- 由于设计师的设计，所以图像处理 PIL、Matplotlib 模块是必须的。
- 实现了 OpenCV 作为图像处理、匹配模块，自然也提供了机器学习功能
- 字体处理数据量很大，利于大数量计算，需要集成 SciPy、NumPy 和 pandas 数据分析模块。
- 由于原生 Python 速度慢，所以添加了 PyCUDA、OpenCL 性能 GPU 计算模块
