# 1.1.3 scikit-learn 六大功能

scikit-learn 机器学习模块库，功能强大，模块众多。模块的主要功能包括以下六大类别：分类、回归、聚类、数据降维、模型选择和数据预处理。

流变说明的是，近几年神经网络、深度学习的崛起。scikit-learn 机器学习模块在以新版本的发布中添加了 MLP 多层感知器等类型的神经网络模块。

不过，scikit-learn 不支持深度学习，也不支持 GPU 加速，因此其内建的 MLP 等模型仅用于教学和小规模数据应用。
