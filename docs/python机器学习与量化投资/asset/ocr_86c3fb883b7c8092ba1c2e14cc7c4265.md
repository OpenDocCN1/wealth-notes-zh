# Python机器学习与量化投资

+   - sklearn.datasets：数据从模块。
- sklearn.decomposition：降维分解模块。
- sklearn.dummy：伪类模块。
- sklearn.ensemble：集成学习模块。
- sklearn.exceptions：异常和警告模块。
- sklearn.feature_extraction：特征提取模块。
- sklearn.feature_selection：特征选择模块。
- sklearn.gaussian_process：高斯过程模块。
- sklearn.isotonic：保序回归模块。
- sklearn.kernel_approximation：核近似模块。
- sklearn.kernel_ridge：核岭回归模块。
- sklearn.discriminant_analysis：判别分析模块。
- sklearn.linear_model：线性模型模块。
- sklearn.manifold：流形学习模块。
- sklearn.metrics：结果评估模块。

该模块包含：

+   - Model Selection Interface：模型选择界面。
- Classification metrics：分类度量。
- Regression metrics：回归度量。
- Multilabel ranking metrics：多类别排名度量。
- Clustering metrics：聚类度量。
- Biclustering metrics：双聚类度量。
- Pairwise metrics：成对度量。

+   - sklearn.mixtture：高斯混合模型模块。
- sklearn.multiclass：多分类模块。
