# 案例 7-6：上证指数案例应用

案例7-6的文件名是 kb706_ET_reg100.py，本案例介绍 ET 回归的批测试效果。

案例通过调用 TOP 股权模块中生成的决策树测试结果两致进行验证。案例采用上证指数作为数据源。

案例核心代码是第 4 组：

```
#4,
print('4, 模型测试')
mfun=ensemble.ExtraTreesRegressor

df9 = zai.mxtst_DTree100(mfun,df_train,df_test,ndepth=3)
df9['k3'] = df9['k']
df2 = zai.mxtst_DTree100(mfun,df_train,df_test,ndepth=5)
df9['k5'] = df2['k']
df2 = zai.mxtst_DTree100(mfun,df_train,df_test,ndepth=10)
df9['k10'] = df2['k']
zt.print('df9',df9)
df9[['k3','k5','k10']].plot(linewidth 3)
```

调用 TOP 股权模块的 mxtst_DTree100 函数，分别按决策树的深度为 3 层、5 层、10 层进行测试。
