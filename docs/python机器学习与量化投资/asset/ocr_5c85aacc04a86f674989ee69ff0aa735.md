# 案例 9-1：上证朴素贝叶斯算法

案例 9-1 的文件名是 kb901_nbClass.py，本案例示范介绍如何使用 NB 朴素贝叶斯算法进行上证指数的分类进行分析。

分类时改使用的 GaussianNB（高斯朴素贝叶斯）分类模型

前面几行代码用于读取数据，具体如下：

```
print('1,rd data')
foo='data/sh2018.csv'
xdf=pd.read_csv(foo,index_col=0)

zt.prDF('xdf',xdf)
```

```
print('2,xd data')
xdf['xprice']=xdf['close'].shift(-1)
xdf['kpr']=xdf['xprice']/xdf['close']*1000
xdf['close_next']=0
xdf.loc[xdf.kpr>0.05,'close_next']=2
xdf.loc[xdf.kpr<0.95,'close_next']=-1
xdf.fillna(method 'pad',inplace=True)
zt.prDF('xdf',xdf)
```
