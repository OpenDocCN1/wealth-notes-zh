保存训练好的模型。

需要注意的是，在实际当中，我们保存的是训练好的模型！

当然，也可以在每次调用 fit 训练函数前，另外保存于一个空白模型之中，然后通过输入不同的训练数据，进行尝试。

有机器学习、神经网络、深度学习经验的读者都知道，机器学习训练时间的环境是 fit 模型训练。以前，标准的神经网络模型往往有上百亿，采用 GPU 集群，也要数月的训练时间。

因此，及时保存训练好的模型，对于模型应用、实验分析，非常重要。事实上，谷歌、Facebook 等大企业在 GitHub 项目网站上都提供了大量的预训练好的模型供大家多方应用。

在案例当中使用 sklearn 块库当中的 joblib 函数来保存、读取模型，参见如下导入语句：

```
from sklearn.externals import joblib
```
