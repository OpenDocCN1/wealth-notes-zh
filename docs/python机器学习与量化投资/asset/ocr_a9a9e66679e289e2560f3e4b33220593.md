SVM（支持向量机）算法的全称是 Support Vector Machine，通常用来进行模式识别、分类和回归分析，支持向量机算法的诞出，有很深的理论背景。

sklearn 模块中的决策树函数有以下两个变量函数：

+   - DecisionTreeClassifier，决策树分类函数
- DecisionTreeRegressor，决策树回归函数

这两个函数使用的算法都是 CART 算法，也就是分类回归树算法。回分类准则默认使用基尼指数。在后面的案例当中，我们可以在决策树可视化图片中看到基尼指数的使用。

sklearn 模块当中的决策树算法，其内部实现炎优化过的 CART 树算法，既可以做分类，也可以做回归。

```
random_state=None, max_leaf_nodes=None, min_impurity_decrease=0.0,
min_impurity_split None, presort False)
```
