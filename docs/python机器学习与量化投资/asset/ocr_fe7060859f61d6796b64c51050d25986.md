import 引入常用的模块和模块的缩写。上面的 import 语句都比较正常，请注意以后的两行语句。

```
import tflearn
tflearn - tf.contrib.learn
```

tflearn 模块两钟导入方式 严格说来，第二种方式不是标准的模块导入命令，而是-种别名，是长变量名称的缩写。这是<|message|>，tflearn 不只是 TensorFlow 系统内部的第三方模块，而且也存在类似名称的 tflearn 模块，不过两者的差别并不完全小少，当名在测试 TF-GPU 1.2 和 tflearn 0.31 时，出现了一些冲突问题

为了程序的兼容性，通常采用以下的形式：

```
tflearn  tf.contrib.learn
```
