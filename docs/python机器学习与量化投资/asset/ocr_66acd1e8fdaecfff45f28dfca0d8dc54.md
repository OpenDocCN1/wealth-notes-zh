在量化分析，其他常用的指标如下

+   - 总名收益（Total Returns），能够反映收益情况
- 基准收益（Benchmark Returns），用于比较收益情况
- 基准收益率（Benchmark Yield），也是贴现折现率，投资项目最低标准
的收益水平，即选择指定的投资机会或投资方案必须达到的期望收益
率。
- 阿尔法（Alpha），是指超越预期收益的超额收益率。阿尔法来源于
CAPM 模型。传统阿尔法常是指在基金经理处理了 β 部位的头寸后，
通过衍生品冲销 β 部位的风险，从而获得真正的阿尔法收益。
- 按照 CAPM 模型的设定，β 系数是用来反映一项资产系统风险的指标，
用来衡量一种证券或一个投资组合相对总体市场的波动性（Volatility）的 一种风险评估工具。
- 索提诺比率（Sortino Ratio），缩写为 SR，与夏普比率类似，所不同的是它只分了波动的好坏，以此在计算波动率时它所采用的不是标准差，而是下行标准差。这其中的隐含条件是投资组合的上升（正回报率）符合投资人的需求，不应计入风险因素。和夏普比率类似，这个比率越高，说明基金在相同单位下行风险能够获得更合适的超额回报率。索提诺比率可以作为夏普比率在衍生品冲销组合风险性基金时的一种修正方式。
- 信息比率（Information Ratio），也称为领估值比率（Appraisal Ratio），缩写为 IR。信息比率是从主动管理的角度描述风险调整后的收益，它不同于夏普比率从绝对收益和总风险角度来描述。信息比率越大，说明所获得的超额收益越大，相对收益相对优于大盘的程度越高。计算公式为：将基金收益率减去同类基金或大盘收益率（即下的位为超额回报率），再除以该超额回报率的标准差。
- 算法波动率（Algorithm Volatility），是指算法在实际执行期间内所表现出的波动率。
