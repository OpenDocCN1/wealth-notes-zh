# 2. Base（基础）模块

Base 基础模块 sklearn.base，包含 Base 基类定义和其他函数。常用类定义如下

+   - BaseEstimator：训练估计基类
- ClassifierMixin：混合分类器
- ClusterMixin：混合聚类基类
- RegressorMixin：混合回归估计基类
- TransformerMixin：混合转换基类

sklearn.base 常用函数是 base.clone，即复制一个新类实例
