+   - n_estimators=100，梯度提升的迭代次数，也是分类树的个数。

由参数 n_estimators=100 可以看出，GBDT 算法虽然对于决策树的复杂程度不感兴趣，可是对于决策树的种类数量要求很多，默认值就是 100。
