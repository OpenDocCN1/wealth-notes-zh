岭回归方法，总是根据以上原理，通过在正规方程中引入ϕ的而使以获得最优结果。

岭回归方法虽然效果不错，不过还存在以下一些问题。

+   • 岭参数选择方法太多，滞后太大。
• 根据岭迹图进行变量筛选，主观性太大。
• 模型变量太多，难以筛选。

为改进岭回归方法当中的这些问题，有学者又提出了 LASSO（套索）方法、LAR（最小角回归）方法等多种改进版本的算法模型，以优化模型结构，方便筛选自变量。

岭回归方法本质上是一种缩减的方法，通过把一些系数缩减成很小的数，来优化模型结果，类似于降维方法，保留最少的特征，以减少模型的误差，便于判断。

实际研究表明，与简单的线性回归相比，这种缩减方法的确能够取得更好的预测效果。
