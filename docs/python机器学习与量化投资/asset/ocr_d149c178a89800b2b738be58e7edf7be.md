# 1.2.3 “零对象” 编程模式

显然，很多人认为 Python 是一种“面向对象”的编程语言。

对于初学者而言，把 Python 视作一种 BASIC 风格的、过程式入门语言，学习难度可以降低 90%，基本上学习一小时即可动手写一些代码。

有人说，“面向对象”最大的好处是方便把人脑子搞乱。

Windows、Linux、UNIX、Mac OS X 内核都是 C 语言写的。有一 种系统是 C++ 的内核。无论怎样的实现系统，源码很庞大，连他们自己的程序员都无法维护，所以就死了。

简而言之，“面向对象”风格的代码：一个字“繁”、两个字“繁杂”、三个字“繁杂冗”。

“零对象编程模式，用 BASIC 的方式学习 Python”，是我写向 Python 初学者提出的 一份完整的学习理论，一家之言，仅供参考。

Talk is cheap, show me the code！大家还是多多动手。

大家似乎觉得讲了“零对象”，下面关于“对象”补充几点

+   - 不只“面向对象”风格的代码不等于不能使用，只对各种采用“对象” 方式开发的软件，我们仍然可以放心使用。

+   - 将 Python 记为“面向对象”语言并非大错不错。事实上，许多人认为，Python 也是 一种类似 LISP 的“函数”编程语言

+   - 它名从编程十年，从未用过“面向对象”风格的写过一行“class”（类对象）代码，依然可以应对各种工作

+   - 讲“面向对象”纯属理论在业界仍然争论不休，入门名功夫不多， 还是通开强名间的火力朵。
