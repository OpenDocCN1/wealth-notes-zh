# 1.3 机器学习：从忘记开始

广大初学者面对人工智能、机器学习这些“高大上”的概念，一方面迫切希望能够学习相关的知识，另外一方面，面对各类层出不穷的概念，会让人化繁乱，无所适从。

目前 Python 已经是人工智能、机器学习的行业标准语言，TensorFlow、Torch 在 2015 年、2016 年先后开放了 Python 语言接口。

scikit-learn 是 Python 语言生态下的人工智能模块库，目前已经收入 scikit 基金会，通常仍称为 sklean

还记得我们开头的那个 scikit-learn 引发的风波吗？不知道大家的第一反应是什么，反正笔者听到此间的第一反应是吓呆了，也明白为什么这么多初学者对人工智能趋之若鹜。

笔者始终认为自己是一名软件工程师，或者叫程序员，也只是网络上常说的“码农”。

对于程序员而言：Talk is cheap, show me the code!

更多的理论，也比不上几件成功的软件作品，笔者虽然谈不上有什么成功的大型作品，但也写过不少小业的程序，例如原生的 OCR 识别程序和英汉翻译软件。

特别是英语翻译软件，笔者当时（1997年）的翻译程序所使用的是免费的字典，几十万条的翻译程序，多种语言资料，全部都同步时间同步，基本无需任何成本，翻译效果也还不错。而当时同类同家的翻译软件，收费巨大，也不过几十万条的资源库。

那么原生程序，应该是采用 C 语言、Delphi 语言的标准而改善，没有任何第三方 AI 架构（如 sklearn、TensorFlow 等 AI 模块）依赖的程序。共同的难处，做过系统的程序员，或者阅读过 Linux、安卓系统、TensorFlow 系统源码的程序员才会明白
