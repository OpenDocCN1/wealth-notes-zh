弹性网络算法是一件同时使用 L1 范数和 L2 范数作为正则化矩阵的 惩罚回归模型。岭回归法、套索回归法，可以看作是弹性网络算法的 例子。

套索回归法常用于特征选取，而弹性网络算法类似套索回归法的 衍生版本，在套索回归模型上添加了一个 L2 范数正则化的“惩罚”项。当 两个特征和另一个特征相关的时侯，套索回归法倾向于随机选取其中一个，而弹性网络算法更倾向于选取两个。
