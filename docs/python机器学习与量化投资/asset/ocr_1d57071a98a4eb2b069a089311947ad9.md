# 内容简介

本书采用生动活泼的语言，从入门的角度，讲解了 Python 语言和 sklearn 库内存的各种机器学习方法；介绍了股市外汇、比特币等实际交易如何在个股量化方面的分析和应用，包括玉米价格的预测、大盘指数的分析等；简少的实例让广大读者能够快速地掌握机器学习在量化分析方面的切点，为进一步学习金融科技奠定扎实的基础。
