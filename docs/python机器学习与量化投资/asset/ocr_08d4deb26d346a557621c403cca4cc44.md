# Python 与机器学习

目前神经网络、深度学习大热，谷歌、脸书、微软、IBM、亚马逊等企业巨头，纷纷投入巨资，各类机器学习的开发平台层出不穷：TensorFlow、PyTorch、CNTK、MXNet、Keras 等。

与此同时，Python 语言成为人工智能一开发语言。

在传统的机器学习领域，或者说占典人工智能领域里也同样不权，scikit-learn 始终处于工各级的统治地位。
