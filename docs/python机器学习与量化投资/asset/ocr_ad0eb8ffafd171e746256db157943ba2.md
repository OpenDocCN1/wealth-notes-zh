# PCA函数接口

sklearn 模块内有一个 decomposition 子模块，用于处理降维方面的算法问题。

其中模块的 PCA 方法函数的 API 接口如下：

```
PCA(n_components=None, copy=True, whiten False, svd_solver 'auto', tol 0.0, iterated_power='auto', random_state None)
```

相类似其他机器学习方法提供的方式，PCA 方法函数的 API 接口调用的参数和其它是比较少的。

其中主要参数如下

+   - n_components，表示保留下来的特征个数。如果设置为'mle'，将自动选取 Variance 个数，使其达到所要求的方差百分比。

+   - copy，默认为 True，表示在运行算法时，是否将原始训练数据复制一份。若为 True，则在运行 PCA 方法后，原始训练数据的位不会有任何改变，因为是在原始数据的副本上进行运算的；若为 False，则在运行 PCA 方法后，原始训练数据的位会改变，因为是在原始数据上进行降维的

+   - whiten，默认为 False，表示对数据进行白化处理，所谓白化，就是对降维后的数据的每个特征进行归一化，让方差都为 1。对于 PCA 降维来说，一般不做白化处理。

+   - svd_solver，表示指定奇异值分解（SVD）的方法。由于特征分解是奇异值分解（SVD）的一个特例，一般的 PCA 都是基于 SVD 实现的。有 4 个可以选的值：auto、full、arpack、randomized。randomized 一直适用于数据量大、数据维度多同时主成分数量比例又较低的 PCA 降维，它使用了一些加快 SVD 的随机算法。full 则是传统意义上的 SVD，
