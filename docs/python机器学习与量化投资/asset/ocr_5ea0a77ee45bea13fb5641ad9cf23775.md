# 9.2 隐马尔可夫模型

隐马尔可夫模型，英文个你为 Hidden Markov Model，记简称为 HMM 模型。

隐马尔可夫模型，通过分析可见数据，来计泡的状态的发生。相反，借助隐状态分析，隐马尔可夫模型可以估计未来可能的观察状态，如图 9.2 所示。

在图 9.2 中，通过隐马尔可夫模型，已知冷‘(压、低‘)压的发生频率（这是隐状态）可似测晴天、雨天、多云天的概率。

隐马尔可夫模型的优点是允许纵变化，常用於识别和预测操作。

与其他机器学习方法不同，隐马尔可夫模型我们没有直接使用 sklearn 内含的相关函数，而是使用 hmmlearn 模块。
