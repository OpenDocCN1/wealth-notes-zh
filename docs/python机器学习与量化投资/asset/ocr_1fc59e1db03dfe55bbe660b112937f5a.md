# 图7.1 RF随机森林算法

随机森林这个术语是 1995 年由贝尔实验室的 Tin Kam Ho 所提出的随机决策森林（Random Decision Forests）理论发展而来的。后来，Leo Breiman 和 Adele Cutler 推出随机森林的算法，并注册了 Random Forests 商标。

随机森林算法是一个包含多个决策树的算法，并且其输出的分类是由个别树的输出分类的众数而定的，这个算法结合了 Leo Breimans 的 “Bootstrap Aggregating” 思想和 Tin Kam Ho 的 “Random Subspace Method” 来建造决策树的集合

随机森林算法是 DT（决策树）算法的一种衍生算法，遵循了 Bagging 算法的原则，引入随机性来得到次优分割点，而并不是选择最佳分割点来创造决策树。

它针对每个被估计树所创造的树与其它类型有所不同，仍能够以其独立的方式推广预测，并且可以更好地估计潜在的真实输出。

如图 7.2 所示，是一个随机森林算法实例，在基因达尔文，在考关了大多数乳腺癌与父相关的基因后，通过随机森林算法计算出发病风险。
