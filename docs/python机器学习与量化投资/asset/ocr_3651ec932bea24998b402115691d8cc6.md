# 4.1 回归方法

Regression（回归）方法，是最常见的机器学习方法之一，其原理是通过分析数据的趋势，来探索变量之间的关系

回归方法本质上是基于数理统计分析的机器学习方法，目前已被纳入统计机器学习之中。

回归方法用于估计两种变量之间关系的统计过程。当用于分析因变量与一个或多个自变量之间的关系时，该方法能提供很多处理和分析多个变量的技巧

具体而言，回归分析可以帮助我们理解当任意一个自变量变化的另一个自变量不变时，因变量变化的类型是 常见的线性回归分析能
