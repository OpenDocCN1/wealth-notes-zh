# 11.4 最小角回归算法

最小角回归算法，英文全称是 Least-Angle Regression，简称 LARS 算法

LARS 算法模型特别适合处理高维、少样本数据。LARS 算法类似于前向逐步回归，在每一次迭代当中，找到与残差最相关的变量。当多个变量与其相关时，不是沿着相同的残差变化继续，而是沿着残差交点之间的等角方向前进。

LARS 算法通过相关性逐步与残差变化相关的特征。从模型上看，相关性实际上就是特征与残差之间的最小角度，这就是 LARS 名称的由来。
