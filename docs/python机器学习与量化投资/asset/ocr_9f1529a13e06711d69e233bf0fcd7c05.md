+   - radius_neighbors_graph: 计算（或仅）点半径为 X 的近邻图。

# 27. neural_network（神经网络）

sklearn.neural_network 模块：包括神经网络模型的方法。

+   - BernoulliRBM: RBM 方法，伯努利受限玻尔兹曼机方法。也存在限伯努利方法。

+   - MLPClassifier: 多层感知器方法。

+   - MLPRegressor: 多层感知回归方法。

# 28. Calibration（校准概率）

sklearn.calibration 模块：包括预测概率的校准方法。

+   - CalibratedClassifierCV: 保持回归或 sigmoid 方法校准方法。

+   - calibration_curve: 计算真实预测概率的校准曲线。

# 29. cross_decomposition（交叉分解）方法

sklearn.cross_decomposition 模块：交叉分解方法。

+   - PLSRegression: PLS 偏最小二乘回归方法。

+   - PLSCanonical: PLS-C2A 方法。

+   - CCA: 典型相关分析方法。

+   - PLSSVD: 偏最小二乘奇异值分解方法。

# 30. Pipeline（管道数据记录）

sklearn.pipeline 模块：用于记录 sklearn 机器学习方法各个流程。

+   - Pipeline: 础转换流程。

+   - FeatureUnion: 串接多个转换器对多结果。

+   - make_pipeline: 按给定转换器构建管道。

+   - make_union: 按给定转换器构建联合转换。
