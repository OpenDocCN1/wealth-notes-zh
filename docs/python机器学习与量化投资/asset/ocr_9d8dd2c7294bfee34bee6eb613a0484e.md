# 图 11.3 LASSO（套索）回归算法

岭回归算法主观性太大，很多多余的选取都需要人工，仍然经验证手动完成，完全不适合大数据和机器学习思想。

为克服这些缺点，有学者对岭回归算法进行了多方面的优化，设计出套索回归算法

套索回归算法，是 1996 年由斯坦福大学统计学家 Robert Tibshirani 提出来的，套索回归算法最初用于计算最小二乘法模型。套索回归算法输入简介，却揭示了很多估计值的 accesses 性质。

+   - 估计值与岭回归和系数选取的关系。\n- 套索回归系数估计值和软阈值之间的关系\n- 当协变量共线性时，套索回归系数估计值不一定唯一。

套索回归算法模型简单，便于分析，而且方便筛选多效变量。套索回归算法通过构造一个惩罚项得到一个较为简洁的模型，压缩一些系数，同时设定一些系数为零。

套索回归算法也叫作线性回归算法的 L1 正则化，和岭回归算法的主要区别就是在正则化时，岭回归算法用的是 L2 正则化，而套索回归算法用的是 L1 正则化。
