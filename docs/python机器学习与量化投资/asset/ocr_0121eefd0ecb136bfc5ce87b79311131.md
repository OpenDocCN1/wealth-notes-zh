# 案例 2-2：爱丽丝进化与文本矢量化

案例 2-2 的文件名是 kb202_iris02.py。根据 xname 的类别名称，设定一个有意义的设为 xid，来完成这个文本信息的矢量化工作。

下面我们分步逐一讲解。

第 1 组代码，读取 Iris 数据文件，并保存到 df 变量：

```
#1
fss='data/iris.csv'
df=pd.read_csv(fss,index_col=False)
```

第 2 组代码，根据 xname 字段，按 1、2、3 分别设定 xid 字段，完成该收爱丽丝分类名称的矢量化操作。xid 全部设为 int 类型后，再保存到文件 iris2.csv 中

```
#2
df.loc[df['xname']=='virginica','xid'] = 1
df.loc[df['xname']=='setosa','xid'] = 2
df.loc[df['xname']=='versicolor','xid'] = 3
df['xid']=df['xid'].astype(int)
df.to_csv('tmp/iris2.csv',index=False)
```

我们已经将 iris2.csv 文件复制到 data 目录下，在后面的案例中，大家可以按使用这个文件作为数据源：data/iris2.csv。

第 3 组代码，输出修改后的 df 数据信息：

```
#3
print('\n3 df')
print(df.tail())
print(df.describe())
```
