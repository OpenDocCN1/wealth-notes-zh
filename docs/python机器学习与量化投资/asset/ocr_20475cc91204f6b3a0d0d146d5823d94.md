# 机器学习编程入门

本章我们通过几个经典的、完整的机器学习小实例，介绍机器学习应用的完整流 程，以及机器学习在金融数据、优化分析过程中的应用场景。

# 2.1 经典机器学习算法

目前，机器学习虽然众多纷入，但还处于启蒙阶段。在本节的案例中，涉及以下经典的机器学习方法。

+   - 线性回归，函数名：LinearRegression。
- 朴素贝叶斯方法，函数名：MultinomialNb。
- KNN 最近邻方法，函数名：KNeighborsClassifier。
- 逻辑回归方法，函数名：LogisticRegression。
- 随机森林方法，函数名：RandomForestClassifier
- 决策树方法，函数名：tree.DecisionTreeClassifier
- 迭代决策树方法，又叫 MART（Multiple Additive Regression Tree），函数名：GradientBoostingClassifier。
- SVM 方法，函数名：SVC。
