# 8.4 小结

机器学习以人的用处是通过对历史数据的分析，找到其中的潜在规律，从而对未来进行预测。

传统的机器学习软件 sklearn 比 TensorFlow 等新一代神经网络、深度学习系统更加试用。

sklearn 机器学习软件用 fit 函数进行训练后，直接用 predict 函数对新数据进行分析。

通过本章，我们从多个角度对机器学习算法模型进行了分类梳理。大家对常用的机器学习模型应该有了基本了解。
