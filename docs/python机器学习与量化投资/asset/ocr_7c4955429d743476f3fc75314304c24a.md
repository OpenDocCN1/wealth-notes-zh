# 4.5 逻辑回归算法模型

逻辑回归算法模型（Logistic Regression）虽然名字里带有回归二字，不过却是一个分类算法。逻辑回归算法虽然也属于线性回归算法，但由于使用较多，目前已经成为一个独立的机器学习算法类别，如图4.6所示。

简单来说，逻辑回归算法是通过将数据拟合进一个逻辑函数，来估计一个事件出现的概率。因此，它也叫做逻辑回归

逻辑回归类似线性回归，因为它的公式是找出多个输入变量的加权系数值。与线性回归不同的是，逻辑回归预测输出化的函数是非线性的，也被称为逻辑函数
