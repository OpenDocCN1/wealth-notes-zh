设置运行环境，主要是以下语句：

```
np.set_printoptions(suppress=True)

```

分别设置如下环节。

+   - 小数显示不采用科学计数法，更加直观。
- pandas 的表格输出宽度设置为 450，以免经常换行。

初始化参数有两项，一是定义 clst、mlst 列表变量。这二是标准 OHLC  founding 数据字段，用于设置数据字段名称。不过在进行实盘分析时，往往需要加入其他金融指标参数，如 AVG（均价）、MA（均线数据）等。

其中 mlst 对应的 MA 字段名称还要和下面的 tax_mul 函数调用参数匹配。

另外一是具体数据的设置，重点是以下语句：

```
xdf['avg'] = xdf[clst4].mean(axis=1)
xdf = zta.tax_mul(zta.MA, xdf, 'close', 'ma', [5,10,15,30])
```

前面一句是 pandas 的内置 mean 函数，注意 axis=1 参数的使用，采用行模式求均值，一般初学者很容易在这里出现问题。

第二句调用 TOP 版本的 TA-Lib 金融函数库的 tax_mul 函数，批量生成多组 MA 数据，有关细节，请参见有关代码。
