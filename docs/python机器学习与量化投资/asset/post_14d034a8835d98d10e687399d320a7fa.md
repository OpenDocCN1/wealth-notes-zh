# 支持向量机

## 15.1 支持向量机算法

支持向量机算法是神经网络、深度学习兴起以前最流行的机器学习方法。

支持向量机，英文全称是 Support Vector Machine，简称 SVM 方法，如图 15.1 所示。

![](img/93734a9b810ff3e8778504a648b013dc_256_0.png)

SVM 方法设计思想是：对于二元可分的模式，存在线性可分的高维的优化超平面

对于不可二元分类（线性分开）的数据，SVM 方法使用内核函数将原始数据转换为新空间。

SVM 方法在于超平面使分类超平面（Hyperplane）的边界最大化，可以轻松地对数据样本进行分类。SVM 方法在高维空间中表现良好，如果维数大于取样的数量，SVM 方法仍然有效。目前 SVM 仅用于二元分类。

SVM 方法的优点如下。
- 在非线性可分问题上表现优秀。
- 长期在变量 X 与其他变量之间进行二元分类操作，无论其关系是否为线性的。

SVM 方法的缺点如下。
- 训练困难。
- 无类型限制。

支持向量机方法将训练样本表示为空间中的点，它们被映射到一个新的图 中，由一条明确的、尽可能宽的间隔线分开，以区分两个类别。

超平面是输入变量空间内的一条分割线。在支持向量机中，超平面可以通过类别（0 类或 1 类）来区分输入变量空间。

超平面与最近的数据点之间的区域称为边距，在分类两个类上具有最大边距的超平面被称为最佳超平面。超平面的确定只与这些点及分类器的参数有关。这些点被称为支持向量。它们支持并定义超平面。

平行超平面间的距离或间隔越大，分类错误的总误差越小。

SVM 方法在本质上是一种二分类方法。在 N 维空间中给定两类点，支持向量机生成一个（N-1）维的超平面将这些点分为两类。比如在纸上有两类线性可分的点，支持向量机会设计一条直线将这两类点区分开来，并与这些点的距离都尽可能远。

支持向量机方法是一种监督式学习的方法，主要用于以下领域：模式识别、统计分类、回归分析、展示广告分析、人体结合部位识别、基于图像的性别估计、大规模图像分类等。

本质上，SVM 方法也是一种基于核函数的机器学习方法。

基于核函数的算法思想，是把输入数据映射到一个高阶的向量空间，在这些高阶向量空间里，有些分类或回归问题就可以被更容易地解决。

其他常见的基于核函数的方法如下。
- RBF（径向基函数）方法，Radial Basis Function。
- LDA（线性判别分析）方法，Linear Discriminate Analysis

## 15.2 SVM函数接口

在 sklearn 机器库中，有独立的 SVM 模块 sklearn.svm，其中相关的机器学习算法函数如下。
- SVC，C-支持向量机算法。
- LinearSVC，线性支持分类算法。
- LinearSVR，线性支持回归算法。
- NuSVC，Nu 支持向量算法。
- SVR，SVR（Epsilon）支持向量算法。
- NuSVR，Nu 支持 SVR 向量算法。
- OneClassSVM，无监督异常点检测算法。
- ll_min_c，辅助函数，返回边界系数。

其中与本个案例相关的两个函数如下。
- LinearSVR，线性向量回归算法。
- LinearSVC，线性向量分类算法。

LinearSVR（线性向量回归算法），函数接口定义如下：

```
svm.LinearSVR(epsilon=0.0, tol=0.0001, C=1.0,
loss 'epsilon_insensitive', fit_intercept True,
intercept_scaling=1.0, dual=True, verbose=0, random_state=None,
max_iter=1000)
```

LinearSVC（线性支持向量分类算法），函数接口定义如下：

```
svm.LinearSVC(penalty 'l2', loss='squared_hinge', dual=True,
tol=0.0001, C=1.0, multi_class='ovr', fit_intercept=True,
intercept_scaling 1, class_weight None, verbose=0,
random_state=None, max_iter=1000)
```

两个函数的上变量调用参数如下：
- C，惩罚系数C，默认为1，一般需要通过交叉验证来选择一个合适的C。
  一般来说，如果样本点较少时，C需要小一些
- penalty，正则化参数，以用于线性拟合，可以选择‘l1’即L1正则化或‘l2’即L2正则化，默认为L2正则化
- epsilon，允许误差
- loss，损失函数类型，默认为epsilon_insensitive，可选为squared_epsilon_insensitive。

# 人工神经网络算法

人工神经网络算法，英文全称为 Artificial Neural Network Algorithms，简称 ANN 算法。

ANN 算法属于类模式匹配算法，模拟生物神经网络，采用类似于大脑神经元连接的结构进行信息处理，通常用于解决分类和回归问题。

ANN 算法是 20 世纪 40 年代后出现的。似乎由众多的神经元叫门的连接似乎连接而成，具有大规模并行处理，分布式信息存储，良好的组织、自学习能力等特点。

在神经网络算法当中，比较经典的 BP（反向传播）算法是人工神经网络中的一种监督式的学习算法。

反向传播算法在理论上可以逼近任意函数，其基本结构由非线性变化单元组成，具有很强的非线性映射能力。而且网络的中间层数、各层的处理单元数及网络的学习系数等参数可根据具体情况设定，灵活度很大。在数据优化、信号处理、模式识别、测能控制、故障诊断等领域已有广泛的应用前景，如图 16.1 所示。

ANN 算法是机器学习的一个庞大分支，目前热门的深度学习就是由神经网络算法发展而来的。

![](img/93734a9b810ff3e8778504a648b013dc_265_0.png)

图 16.1 神经网络算法

ANN 方法模型里面的各个节点被称为“神经元”或“单元”，这些节点之间加上连接构成的网络就是“神经网络”。

ANN 方法模型要进行训练，训练的过程就是网络进行训练学习的过程，通过训练学习过程来改变各个节点的连接权值。

ANN 方法模型的主要缺点如下
- 方法模型收敛速度慢。
- 计算量大。
- 训练时间长
- 缺乏足够的理论基础。

常见的 ANN 方法如下。
- PNN（感知器神经网络）方法。
- BP（反向传播）方法。
- Hopfield 反馈网络方法。
- Elman 反馈网络方法。
- SOM（自组织映射）方法。
- RBF（径向基）方法。

# 多层感知器

多层感知器，又称多层神经网络，英文全称是 Multi-layer Perceptron，简称 MLP，是一个前向结构的人工神经网络，映射一组输入向量到一组输出向量。

MLP 是常见的神经网络算法，它由一个输入层、一个输出层和一个或多个隐藏层组成，如图 16.2 所示。

在 MLP 模型中，所有神经元都差不多，每个神经元有几个输入（连接到前一层）神经元和输出（连接到下一层）神经元，该神经元会将相同的信号递给与之相连的多个输出神经元。

MLP 模型可以视为一个有向图，由多个节点层组成，每一层全连接到下一层。除了输入节点外，其他的每个节点都是一个带有非线性激活函数的神经元（或称处理单元）。反向传播算法的监督学习方法常被用来训练 MLP。MLP 模型是感知器的推广，克服了感知器不能对线性不可分或进行识别的弱点。

![](img/93734a9b810ff3e8778504a648b013dc_267_0.png)

# 图 16.2 多层感知器

若每个神经元的激活函数都是线性函数，那么，任意层数的 MLP 都可被简化成一个等价的单层感知器。

事实上，MLP 模型不仅可以使用任何形式的激活函数，比如阶梯函数或逻辑S形函数（Logistic Sigmoid Function），但为了使反向传播算法进行有效学习，激活函数必须限制为可微函数。由于具有良好的可微性，很多S形函数，尤其是双曲正切函数（Hyperbolic Tangent）及逻辑S形函数常被用作激活函数。

常被 MLP 模型用来学习的反向传播算法，在模式识别的实践中深受关注并在计算神经学及并行分布式处理领域中，持续成为该研究的热点。多层感知器已被证明是一中通用的函数近似方法，可以被用于拟合贝尔的函数或早决策分类问题。
