归一化的具体作用是归纳统一样本的统计分布性。归一化在(0,1)之间是统计的概率分布，归一化在(-1,1)之间是统计的坐标分布。之所以将特征归一化到一定的范围内，是为了应付那些标准差距小的特征并且保留原始数据中的0位。

归一化有同一、统一和合一的意思，从根本上，神经网络是统计概率作为核心运作方式的。

从运作深层的角度而言，其实也可以不进行归一化处理。不过，归一化可以加快训练神经网络的收敛性，提高模型运作效率。通常在模型训练前对数据进行归一化处理。

在 sklearn 模块库中提供了 MinMaxScaler、MaxAbsScaler 等函数用于数据归一化处理。
