# 14.2 装袋算法

装袋算法是一种根据均匀随机分布从数据中重复抽样的技术

装袋算法也叫 bootstrap 方法，与随机森林方法类似，还常用于决策树倾斜

装袋算法的基本思想可以分为三个步骤。

+   • 步骤一，把数据分为 n 个小组，类似把一堆水果装到 n 个袋子里，而这也是装袋算法的一种形象的比喻。

+   • 步骤二，对各小组的数据进行分析，找出每个组的最佳答案  相当于在每个袋子里选出符合要求的水果。注意，不是最大的水果，而是符合要求的水果

+   • 步骤三，把 n 个小组挑选出的结果进行汇总，再挑选出最频繁出现的结论的结果作为最终答案，类似统计学的众数似然 对水果例子而言，如果按大小作为标准，不是挑选最大或最小的水果，而是按大小分类后出现最多的一类水果
