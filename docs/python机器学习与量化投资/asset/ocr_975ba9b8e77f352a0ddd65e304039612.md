# Python 机器学习与量化投资

preprocessing 数据预处理模块，全称是预处理和规范化 (Preprocessing and Normalization)

sklearn.preprocessing 模块包括数据缩放、归一化、二值化包括补齐方面的函数。具体如下

+   - Binarizer：根据阈值数据进行二值化
- FunctionTransformer：构建自定义函数
- Imputer：用于处理缺失值的抽补变换函数。
- KernelCenterer：中心内核矩阵。
- LabelBinarizer：标签二值化。
- LabelEncoder：把列表中类标的数据标记化为数字编码。
- MultiLabelBinarizer：多标签二值化。
- MaxAbsScaler：按照特征最大绝对值进行缩放。
- MinMaxScaler：最大化、最小化规范化
- Normalizer：各个数据归一化处理，使样本特征和为 1
- OneHotEncoder：独热编码。
- PolynomialFeatures：生成多项式特征变数。
- RobustScaler：使用对异常值鲁棒的统计信息来缩放
- StandardScaler：通过消除平均值和缩放到单位方差来标准化特征，使各特征的均值为 0，方差为 1。
- add_dummy_feature：添加数据集中。
- binarize：表达布尔值特征
- label_binarize：以 one-vs-all 的方式对标签进行二值化
- maxabs_scale：将每个特征缩放到[-1,1]范围，而不破坏稀疏度。
- minmax_scale：通过将每个功能缩放到给定范围内来转换功能
- normalize：将输入向量分别缩放到单位范数（向量长度）
