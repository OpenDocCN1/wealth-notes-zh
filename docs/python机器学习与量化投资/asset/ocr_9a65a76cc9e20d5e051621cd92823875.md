+   - max_depth: 决策树的最大深度。当树的深度达到 max_depth 的时候，无论还有多少可以分支的节点，决策树都会停止运行
- min_samples_split: 分裂所需的最少样本的数目，当样本的样本数小于该参数后，则不再生成分支
- min_samples_leaf: 一个分支所需要的最少样本数，如果在分支之后，某一个叶子节点的样本数小于该参数，则递归，不再进行递归，递归后的叶节点的输出以该叶节点中众多的标签为准
- min_weight_fraction_leaf: 最小的权重系数
- max_leaf_nodes: 最大叶节点数，None 时无限制，以参数时会忽略 max_depth。
