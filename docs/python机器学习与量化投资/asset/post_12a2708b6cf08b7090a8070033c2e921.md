# 图7.1 RF随机森林算法

随机森林这个术语是 1995 年由贝尔实验室的 Tin Kam Ho 所提出的随机决策森林（Random Decision Forests）理论发展而来的。后来，Leo Breiman 和 Adele Cutler 推出随机森林的算法，并注册了 Random Forests 商标。

随机森林算法是一个包含多个决策树的算法，并且其输出的分类是由个别树的输出分类的众数而定的，这个算法结合了 Leo Breimans 的 “Bootstrap Aggregating” 思想和 Tin Kam Ho 的 “Random Subspace Method” 来建造决策树的集合

随机森林算法是 DT（决策树）算法的一种衍生算法，遵循了 Bagging 算法的原则，引入随机性来得到次优分割点，而并不是选择最佳分割点来创造决策树。

它针对每个被估计树所创造的树与其它类型有所不同，仍能够以其独立的方式推广预测，并且可以更好地估计潜在的真实输出。

如图 7.2 所示，是一个随机森林算法实例，在基因达尔文，在考关了大多数乳腺癌与父相关的基因后，通过随机森林算法计算出发病风险。

在许多领域，随机森林算法都是很好的工程决策方案，不过的是，随机森林算法背后的理论至今仍然是一个谜，目前依然没有系统、科学的

理论依据。

# 图7.2 RF（随机森林）算法实例

随机森林算法中有很多不同的分类树，每个分类树都可以投票来对物体进行分类，从局选出最多票的类别。

随机森林算法非常类似 GBDT（迭代决策树）算法，但区别在于它没有迭代，并且森林树的长处不受限制。

因为随机森林算法没有迭代过程，不像 GBDT 算法需要迭代，不断地为每个样本以及子分类器的权重，因此模型相对简单，不容易出现过拟合，可以随时加树的改善，而且执行的速度也相对较快的。此外，随机森林方法对大规摸数据集和存在大差异且不相关特征项目的项目的相关性非常好。

# 7.1 随机森林函数

在 sklearn 模块中，与随机森林方法相关的函数位于集成算法模块 Ensemble 中，其中相关的机器学习算法函数如下。

+   - RandomForestClassifier: 随机森林分类方法。
+   - BaggingClassifier: 袋装分类方法。相当于多个次数投票来决，对于多次测试，每个样本返回的是多次预测结果最多的那个
+   - ExtraTreesClassifier: 极端随机树分类方法。
+   - Adaboost 迭代算法：其核心思想是针对一个训练集训练不好的分类器（弱分类器），然后把这些弱分类器合起来，构成一个更好的最终分类器（强分类器）。
+   - GradientBoostingClassifier: 梯度分类方法。
+   - GradientBoostingRegressor: 梯度回归方法。
+   - VotingClassifier: 投票分类方法

随机森林回归方法 RandomForestRegressor 的接口定义如下：

```
RandomForestRegressor(n_estimators=10, criterion='mae', max_depth=None, min_samples_split=2, min_samples_leaf=1, min_weight_fraction_leaf=0.0, max_features='auto', max_leaf_nodes=None, min_impurity_decrease=0.0, min_impurity_split=None, bootstrap=True, oob_score=False, n_jobs=1, random_state=None, verbose=0, warm_start=False)
```

随机森林分类方法 RandomForestClassifier 的接口定义如下：

```
RandomForestClassifier(n_estimators=10, criterion='gini', max_depth=None, min_samples_split=2, min_samples_leaf=1, min_weight_fraction_leaf=0.0, max_features='auto', max_leaf_nodes=None, min_impurity_decrease=0.0, min_impurity_split=None, bootstrap=True, oob_score=False, n_jobs=1, random_state=None, verbose=0, warm_start=False, class_weight=None)
```

以上两个的接口，多定义不多，常用的参数如下

+   - n_estimators: 树扩展的迭代次数，也是弱分类器的个数，默认为 100
+   - max_depth: 决策树的最大深度，默认值是 3。
+   - max_features: 每个决策树使用的最大特征数。

在以上参数中，max_features 有多个选项。

+   - Auto/None: 简单地选取所有特征，每棵树都可以利用。在这种情况下。
时保持并没有任何的限制。
+   - sqrt: 此选项允许树子树的特征可以以总特征数的平方根的个数使用。例如，如果总体特征的总数足 100，则每棵子树只能取其中的 10 个使用。
+   - log2: 另一非常类似类的选项。
+   - 0.2: 此选项允许单个随机森林的子树可以利用变量（特征）数的 20%。如果想为深部分特征的作用，可以使用 “0.X” 的形式。

增加 max_features 的值，一般能提高预测的性能，因为在每个节点上，有更多的选项可以考虑。

不过它降低了洋树的多样性，而这正是随机森林算法独有的优点，同时也会降低模型的泛化性。

# 7.2 决策树测试框架

由于 sklearn 模块在设计时考虑了函数 API 调用接口的统一性。因此，基本上模型的训练都是调用 fit 函数，模型的预测都是调用 predict 函数。

而模型的另外和准确度也可以由 sklearn 内置的函数以及 TOP 交叉们定义的函数进行统一评估。这样一来，就为机器学习算法、模型的统一测试奠定了基础。

我们首先设计一个基于决策树框架的机器学习测试框架，在数据预处理方面，为了结合金融化实际情况，做了以下优化。

+   - 本节案例采用的数据全部是金融实盘数据，如上证指数、BTC（比特币）交易数据等。
+   - 样本曲线当中的变量 y，就是实盘中第二天的收盘价。
+   - 变量 y2 是模型生成的第二天收盘价的预测值。
+   - 对于分类模型，采用的是上涨、下跌、平盘三种模式。
