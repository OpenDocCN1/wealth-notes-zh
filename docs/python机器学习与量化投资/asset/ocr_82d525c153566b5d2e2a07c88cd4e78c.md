# 案例 3-6：比特币与标准化

数据标准化，英文名称是 DataStandardization，即将特征或样本的分布归一成标准正态分布，也叫高斯分布。

数据标准化最常用的方法是 z-score 规范化，也称零均值规范化，也即使处理数据的均值为 0，方差为 1。

标准化的原因在于数据的特征的方差过大，会影响、影响数据集中其他特征的权重。

标准化的过程为两步：去均值的中心化（均值变为 0）；方差的规约化（方差变为 1）。
