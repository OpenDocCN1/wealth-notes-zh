# SVD函数接口

sklearn 模块中的 decomposition 子模块用于处理降维方面的算法。其中核心的奇异值分解的方法的 API 接口如下：

```
TruncatedSVD(n_components=2, algorithm='randomized', n_iter=5, random_state=None, tol=0.0)
```

SVD 的方法的 API 接口的更多参数如下

+   - n_components, 保留下来的特征个数 n 如果设为'mle', 将自动选取
  特征个数 n, 以刚满足所需方差百分比。
