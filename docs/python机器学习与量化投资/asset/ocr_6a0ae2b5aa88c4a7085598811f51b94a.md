# 4. Exceptions（异常和警告）

sklearn.exceptions: 异常和警告模块，包括 sklearn 模块所...。

# 4、输出信息和处理异常

+   - NotFittedError: 如果分类器在拟合前...调用，...抛出异常。
- ChangedBehaviorWarning: 警告类通知，...用于任何行为上的变化。
- ConvergenceWarning: 自定义警告，...来捕获收敛问题。
- DataConversionWarning: 警告通知，用于格式或类型转换...。
- DataDimensionalityWarning: 自定义警告，通知用户...数据/维度的潜在问题。
- EfficiencyWarning: 警告通知用户，...计算效率低。
- FitFailedWarning: 警告类，用于拟合评估时存在的...。
- NonBLASDotWarning: 当...没有使用 BLAS...计算时...运行时，出现警告。
- UndefinedMetricWarning: 无效度量时出现警告。

# 5. Cluster（聚类）模块

sklearn.cluster: 无监督聚类算法模块。主要的类定义如下。

+   - AffinityPropagation: 仿射传播聚类算法。
- AgglomerativeClustering: 层次聚类算法。
- BIRCH: 聚类算法。
- DBSCAN: 密度聚类算法（基于密度...）。
- FeatureAgglomeration: 似...行征聚类算法。
- KMeans: K-均值聚类算法。
- MiniBatchKMeans: 迷你批次 K-均值聚类算法。
