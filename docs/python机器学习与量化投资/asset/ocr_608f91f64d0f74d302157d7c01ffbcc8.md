# 致谢1 化为归一化形式

+   • 把数值变为(0,1)之间的小数。
• 把有约束表达式变为无约束表达式。

致谢1-化上变换是为了方便数值处理处是可控出来的，把数值映射到(0,1)的区间之内来处理，可以更加便于运算。致谢1-化是一种无约束处理下可以使数值绝对值变成相对相对值的关系，是一种简化计算、缩小范围的有效办法。并且在各步骤了都结束后。并经过反归一化处理，一切数值都可以还原

# 案例 3-1：麻烦的外汇数据

尽管在 zwDAT 企业数据库中已经收录了各中外汇交易的历史交易数据，但是只到 2016 年以前的，作者决定采用最新的外汇数据作为案例数据。

流行的 Tushare 只有国内的 A 股数据，很多数据网站的 API 只提供 3~5 天的数据，而且需要注册。和讯等财经网站也足以采历史数据，甚至这行外汇历史数据。最终还是在 pandas 上找到了解决方案

pandas 在独立出来的 pandas_datareader 模块中集成了多个著名的金融数据网站，一站式提供了股票期货、外汇黄金等多种金融数据。

pandas_datareader 模块，内含的金融数据网站包括：Yahoo、Enigma、FRED、Google、MOEX、Morningstar、Quandl、Stooq、NASDAQ、IEX 等。

pandas_datareader 模块源码在 GitHub 开源项目网站上：https://pydata.github.io/pandas-datareader/stable/

案例 3-1 的文件名是 kb301_xdown.py，本案例介绍如何使用 pandas_datareader 模块，并下载最新的外汇交易数据。

程序文件导入模块代码如下：

```
import pandas_datareader.data as web
```
