# sklearn 常用模块和函数

本附录主要用于介绍 sklearn 人工智能、机器学习的...函数。

# 1. 模块库清单

sklearn 人工智能、机器学习模块，常用的子模块如下。

+   - sklearn.base: 基础模块。
- sklearn.utils: 常用工具模块。
- sklearn.cluster: 聚类模块。
- sklearn.cluster.bicluster: 双聚类模块。
- sklearn.covariance: 协方差估计模块。
- sklearn.model_selection: 模型选择模块。

该模块包括：

+   - Splitter Classes: 分割器类。
- Splitter Functions: 分割器函数。
- Hyper-parameter: 超参数优化。
- optimizers Model validation: 优化模型验证。
