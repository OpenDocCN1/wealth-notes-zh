# 盡全力在上海搶房

房子一起買中悄悄溜走，加上對房市走勢不確定，內心深處充滿猶豫，時間在流逝，冰棒也在融化，我依然沒有辦法把手上的錢花出去。二○○九年九月，也許是上帝厭煩了我的猶豫，只聽見「轟」一聲巨響，中國政府四兆刺激計畫就來了。巨響之後，中國房價開始暴漲。
