# 開啟新的投資階段

好自己的財務，存下該存的錢。如果你是一個很會花錢、沒有毅力的人，縮短房貸年限可以強迫儲蓄，早日擺脫房貸給你的精神壓力。 中國有一句官方的話：「房子是用來住的，不是用来炒作的。」這句話從經濟學原
理來看靠不住，對一般民眾而言應該是：「如果你想住房子，必須學會炒作房產。」一房地產市場和股票市場一樣，人生最後的贏家不是辛苦賺錢的人，而是對市場趨勢做出正確判斷的人。
