# 第十章 投機者該人人喊打？

保險箱裡睡大覺的。銀行會把錢投入生產環節，因為銀行的錢需要貨出去，這些存款即使不投入生產環節，也會透過消費貸款進入更需要消費環節，人們願意支付更高的利息去消費，說明有更急迫的消費需求。存款、投資和生產與消費一樣是對社會促進作用的事情，為什麼大家總覺得像葛朗台這個守財奴一樣，存款是可恥的呢？總體來說還是漫長的文化影響，人類進入資本主義時代的時間並不長，人和人透過和平合作的方式共同生產、創造出更多社會財富的時間經歷也不長。在早期暴力掠奪的時代，你擁有更多財富，多半是從窮人那裡掠奪而來的，所以自古各個民族、文化都有鄙視富人的傳統，而富人總是在不停的存款、放債。今天我們知道利息的本質是選擇權，就是股票交易中經常說的期權。因為放債人把錢借出後，就失去了選擇的權利，沒有把錢借出去之前，他的錢可以今天花，也可以明天花，錢借出去了，那他只能明天花，等於丟掉自己今天錢的自由，因為少了這個選擇

* 葛朗台是法國作家巴爾扎克小說《歐也妮·葛朗台》中重要人物，他是一個有錢的商人，但為人非常吝嗇。
