# 老中的理財經

他。那個時候找工作不是問題，因為高科技公司搶著招人。從機場到學校的路很長，要一個多小時。老宣講完他的美好生活，開始給我上第一堂美國理財課，這幾十分鐘的理財課讓我獲益匪淺。幾十年後的今天，當我回憶往事，除了感謝他在我絕望之際來接我，還有就是這幾十分鐘的理財課。老宣語重心長的告訴我，在美國管理個人財務，一定要做好這幾件事。
第一，要累積自己的信用紀錄，提高和保持自己的信用分數。我需要盡快去辦一張信用卡，然後每個月按時付帳單。他提醒，信用卡一定要全額付清，不要欠款，一旦欠款就會利滾利，愈滾愈多，不要讓銀行賺走任何一分錢。如果哪天實在忘了按時付款，記得趕緊打電話給銀行解釋，不要留下不良紀錄。
第二，他告訴我，最好買一輛五797新...的日本二手車。在美國沒有車會寸步難行，五年的二手車不用買全額保險，只需要基本責任險，保費會便宜一半。此外，日本車比較省油，最重要的，是日系車新的一手車有幾個好處：比較可靠，所以維修成本較低；五年的二手車不用買全額保險，只需要基本責任險，保費會便宜一半。
