# 網路泡沫破滅

山灣區看了一輪，因為聘用我的單位希望我過去一下，確保我喜歡那裡的生活環境。我碰到了在新加坡的一個同班同學，他在北加州生活了一年，正打包準備搬往芝加哥。他說你要來灣區，灣區不是什麼好地方。我問為什麼？他的解釋是，灣區房價太貴，到處塔車，還跟我分析，他用不到三分之一的錢就可以在芝加哥買到同樣大小的房了。他選擇可能適合他，但是不適合我，我比他更有奮鬥精神。沿著公路開車，兩邊一期望不到頭的都是房子，我四肢健康、精力飽滿，當這些房子屬於我之後，房價高對我來說就是一 件好事。當然人各有志，當著朋友的面不能這麼說。

我幾乎是在網路泡沫化前的六個月才把工作確定下來，雖然還沒拿到正式的畢業證書，但是我已經開始上班了。經濟危機來臨前大數人都可以感覺到，雖然股市還有暴跌，影響價格的主要因素已經不再是公司獲利的好壞和基本面，而是政府政策。當時一個明顯的例子就是聯準會下調利率，股票價格立刻反彈，但是第二天市場似乎才明白，聯準會下調利率預告著經濟危機的來臨，於是股票價格又下跌。市場變
