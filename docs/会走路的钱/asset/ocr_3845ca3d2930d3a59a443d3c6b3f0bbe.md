# 維持正現金流

場，如果錯過了半年的多頭行情，也許你就錯過了大半個行情。

穩健投資房地產的第二個核心奧祕就是維持正現金流，這往往是投資者永遠面臨的兩難困境。市場上沒有十全十美的房子，在房價比較高的地區購買房子，比如紐約、舊金山、上海、北京，難免是負現金流，如果在中西部、德州或土地不那麼貴的地方買，房子雖然便宜，立刻就可以實現正現金流，但是房子增值緩慢。

最後會導致兩種結果，在房價比較貴的地區，因為房貸可能高於房租，很難實現正現金流，買入之後每個月還要貼很多錢進去，很難實現滾雪球的效果，所以房價比較貴的地區普遍人很難變成大地主，除非有一些特殊歷史原因。而在房價比較便宜的地區，雖然可以實現正現金流，但是房屋增值緩慢，需要很長時間才能營到甜頭。 grands這些地區的普通人有機會成為專業地主，只要一心一意做好房地產投資，比如在學校周圍買房子，靠正現金流不斷滾動，最終可以做出較大的規模，我在美國這麽多年看到的大地主，多半屬於這類。
