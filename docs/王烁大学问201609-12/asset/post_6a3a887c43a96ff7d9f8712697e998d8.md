# 第12周问答｜通货膨胀是常态

**Damon 郭龙：世界越来越有不确定性，请问王老师，通货膨胀会到来吗？**

自从进入法定货币时代，通胀就是常态而通缩是异常。我们几乎始终身处通胀之中，偶尔进入通缩，就意味着经济陷于很大困难之中。

通胀常在，因为对一个经济体来说，最重要的事情之一就是保持足够高的就业率，或者反过来说，把失业率控制在足够低的水平。它跟提高生产率一样重要：生产率上不去，经济没有真实增长；失业率控制不住，社会要重来，一切都免疫。

现代央行，不管其使命陈述写的是控制通胀单一指标，还是控制通胀和促进增长双重指标，其货币政策实际上长期都是偏通胀的。

所有经济体都希望得到一定程度的通胀、接近充分的就业、稳定在自然水平上的长期增长。所以，管理得再好的经济体，通胀也常在。

以美国为例，从未出现过恶性通胀，但自从美元于70年代与黄金脱钩以来，其真实购买力已经下降了95%。今天的一美元，相当于当年的五美分。

通胀虽然两个字，却包含着多重含义。

第一种是物价上涨和温和上涨。几乎所有经济体都欢迎这种情形。对温和上涨的定义，视乎各国的政治经济状况而不同。比如中国，5%以下就是温和的；比如德国，5%肯定难以接受。这个国家对于历史上恶性通胀的后果极为敏感。

第二种是明显上涨。同样，各国人民耐受度不同，但不论哪个国家，通胀水平持续在两位数都是不可接受的。但凡央行履职，都会尽力把它压下来。

第三种是恶性通胀。如1920年代德国剧烈通胀，货币贬值到如纸，悲惨纪录直到近年才被打破。这种情况一旦发生，明天没有意义，人人活在当下，社会礼拜乐崩，一切坚固的都烟消云散，国家倾覆。

当然，恶性通胀从来不是因而果。它也几乎从来不是经济管理失败所致，它折射社会整体溃败，首先是政治失败。它是晴雨表，也是放大器。

你的问题是：我们会不会进入这种状态？

第一，离得还很远。历史没有方向也不会线性发展。过度沉迷于见微知著，结果往往是杞人忧天。

第二，不过，正如去年诺贝尔经济学奖得主安格斯·基顿所说，过去几百年，人类逃离饥荒和疾病的速度与规模是从所未见的，也是偶然的，没有什么理由认为它一定会持续。

第三，太阳底下无新事，这次不同。各有各的理，你怎么办？别预测，做准备。建议你再读一遍本专栏文章《黄金有何用》。

# 债转股是一连串事件的第一步

![](img/4df33f9dae681a82a46724774851329a_79_0.png)

碰到斯蒂芬·罗奇，前摩根士丹利首席经济学家，现在耶鲁大学杰克逊研究院讲《接下来的中国》。他长期坚定看好中国经济，自中国经济从1998年亚洲金融危机开始，讲到中美经济双引擎，再到今天全球普遍悲观之下自嘲为“仅存的最后一头中国牛”。

就这么“乐观”的人，谈到中国银行体系的不良贷款率，还是说，恐怕有10%。

所以，今时今日，债转股又来了，1998年以来的第二次，这次的最终规模肯定会比上一次大很多。

首要启示是，银行真不是什么好投资，不良贷款的多与少首先看老天脸色，其次看人怎么造。经济起伏一次，银行就要重新洗一次牌。巴菲特早就说了，银行这门生意的杠杆率太高，8%的资本充足率就是12.5倍，还不算绕着走的部分；还有就是内部人控制太重，基本都不值得投。

不过，他自己说的话，自己没忍住，主要投过两个，一个是所罗门兄弟公司，1980年代的华尔街债券之王，出丑闻垮了；另一个是富国银行，2008年金融危机中仅免于风波的大银行，几乎成为美国银行业之王，现在也被揭出一堆丑事，眼看着差不多了。巴菲特尚且如此，你呢？

回头来说债转股，这是什么？

许多年前，一位朋友欠我钱还不了。他有点金融知识，跟我商量，“这样行不行，钱不还了，就算你投资我这个人，我将来所有现金流的1/10归你，行吗？”

这就是债转股。单个银行与单个企业搞债转股跟这没什么本质区别。借钱的人还不起钱了，如果你豁不出去让他破产，就只能商量着来，要么少还点，要么钱没有命一条你拿去，或者拿走1/10条。

债转股细节无穷尽，不提了；往大里说，好处是这些：

企业债转股，负债勾掉，减少还本付息负担，资产负债表处理干净，重新贷款，机器转起来。如果企业不是无可救药，总会有些生机。对银行来说，反正贷款是还不上了，不良贷款在资产负债上反正也藏不住了，反正让他破产能拿回来的也更少，不如能转些股份回来就转些回来吧。

单个银行与单个企业只要两边谈得拢怎么都行，放到整体来看就不同。

政府主导债转股，不应该是为了救谁不救谁，也不应立足于在银行与企业之间如何分蛋糕，也不必说什么银行赚了好多年钱现在应回馈实体经济之类。政府的目标应是出清僵尸贷款，使银行体系恢复信贷能力，为经济增长提供动力。

反面教材是日本。在泡沫经济破灭后，日本的银行积攒大量不良贷款，但迟迟不作清理，以致长期不能恢复信贷能力，这是日本经济多年不振的原因之一。

问题是，谁来付费呢？单个银行与单个企业搞债转股的话，各让一步，商量着解决了问题，主要是银行付成本；银行体系与实体经济搞债转股，谁付成本呢？

银行账上的不良贷款，经由债转股程序移出，变成间接持有的企业股权，不良贷款和企业股权一样没有流动性，只是换了个记账方法，对恢复信贷能力还是没帮助。

也就是说，对经济而言，债转股只是个步骤，它有助于部分厘清银行不良贷款，但主要还是为下一步做准备。

下一步是什么？

第一，这次债转股会有很多市场化因素。市场化因素云云，除了不良贷款用市场化定价等必有之机制外，这次多了用股市来消化的机会。

以最近某上市公司债转股方案为例，银行债转股，原股东大幅摊薄之外，多了定向巨额增发一节，向股市要钱。债转股如果不想成为银行与企业之间的零和游戏，就要从外部要资源，A股金矿不用白不用，股民们做贡献的时间又到了。

第二，清理不良贷款是一连串事件，债转股只是先声。中国银行体系不良贷款规模是多大？很多估计，确切知道的就没有。没爆发时干干净净，爆发了一地鸡毛，从来如此，哪里都这样。假设就按10%不良率来说，毛估估，就是打掉利润，打掉拨备，再打掉一半资本金。想想中国银行业资产总额超过200万亿元。这可是A股股民作贡献就能抹平的。

第三，银行体系再注资只是时间问题，问题只在于还有多久，用什么方式。现任中国人民银行行长周小川就是1998年到2000年代中期清理银行体系的重要参与者。翻看后来写的文章可知，1999年成立四大资产管理公司搞债转股，本来就是清理银行不良贷款系统方案的一部分，只是后来因为各种原因没有一气呵成，暂停了几年，直到2004年陆续用外汇储备注资国有银行，开启整个金融体系的再注资进程。今天债转股重来，轻车熟路，估计整体步骤已有预案，不必像上次一样再无谓浪费时间。只是用什方式目前无从知晓，上次用外储注资可谓出奇兵，现在时势不同，多半不会重故伎。

拭目以待吧。
