# 全球化退场 乱世登场

这篇文章写于英国脱欧之际，原题目《全球化退场，乱世登场 只欠川音》，现在不久了，略作修改，适用于今天。

> 全球化不玄虚，它是货物、人、资本、信息、观念在全球的自由流动，从来与每个人切身利益相联。它就像水往低处流一样自然，从来与每个人切身利益相联。但它又不可能到达终点，自由流动从不曾充分自由，因为多赢只是理论上的可能，现实之中自由相待而来的往往是多赢的世界，于是高度发达的全球化也依然是多赢的世界。全球化是全球的退场，这是它的宿命。

“别人看法”

起有始，落有终，英国脱欧，川普上台，我们目送全球化此去焉归。

+   一

人们希望全球化是平等交往的结果，但它从来并非如此。近代以来两次全球化的主浪潮，都伴随着强军政治-经济-文化体向全球的暴力输出，第一次是19世纪的英帝国，第二次是冷战结束后的美利坚帝国。市场经济秩序的扩展、自由民主观念的传扬，要以英帝国强权为后盾，现实就是如此赤裸裸。

全球化必须得有种引擎，而今天引擎正在熄火。美利坚帝国固有所恃帝国一样，犯下过度扩张的错误。911之后，在阿富汗战争之外，多打了一场不该打的伊拉克战争，战略国外界，更多消息不靠谱，是开始乱套，战略性撒出伊核世界。干掉了一个拉登，却把更大的魔头放出底瓶。

纷乱生，已明白白纸在墙上。在全球化的经济一摊，多边贸易谈判多哈轮的一拖再拖，没有下文。亨廷顿《文明的冲突》也嘲笑了一十数年，但这五个字都被现实主义证明生命力惊人，今天被嘲笑的说成了福山的《历史的终结》。讲述这场充满暴力的国联是极小数的，但真的就是这场无休止的国联，是利益有关，惟与信仰无关吗？

阿拉伯人血染美黄沙，发达世界还可以转过脸去，巴黎变成战场，却又往何处逃避？难民涌入欧洲，将欧洲人民及其领导人置于左右为难的选择。选择它一视全还是人道主义？善就占到了时上前，但担心心正在猜疑中原里，更别问，经济哪里都不行，欧洲也没有余裕。

英国人不是慌态的后代，力量平衡政治学的信徒。首次以欧盟前标志，在一线大国之中，他们首先明确地发出境信号。

兄弟们，我先走一步。

英国不会是最后一个。

脱欧对英国冲击有限，反正它从未放弃英镑，也一直保有边界。欧盟受到的影响较大，但只能做微做看的欧盟，不比大要差。欧洲统一的问题就先是德国问题，德法同心，欧洲统一就会提上，少了英国在内部羁绊，可能还会有效牵率。

问题是会不会出现连锁反应？如果欧洲统一是逆向反者，那么酝酿的欧债危机将重新卷土重来，会是更大危机的要素。

+   二

11月8日，全球看美国，美国看川普，川普泽不似人君。

2008年金融危机，美国模式的自由资本主义怯怯，2016年川普上台，美国模式的政治一倒也已裂行。

美国失志，世界失序。

那些做成了“大事”的政治家，从来都不悖于政治不正确。希特勒的想法从不遮掩，《我的奋斗》早讲到了前头。普京想干什么，很多人说搞不懂，那是因为他们不肯相信眼睛看到的东西。普京上台第一天就发表《千年宣战》，把愿景讲得清清楚楚，要让俄罗斯重新强大起来——熟悉的旋律。

川普也在这个传统里头：为了让美国重新伟大起来，他要坚唱：要给墨西哥竖道墙，以便挡住南面过来的人们；要在来自中国的“威胁”面前坚强，在任何妨碍美国重新伟大起来的力量面前，他的方法都是硬墙。说起光荣孤立，大洋为屏障，谁能比得过美国呢？

如果美国也坚唱，那么，墙在各地竞争并起没有悬念。走好，托马斯·弗里德曼笔下那个平坦的世界。

+   三

这跟中国人有什么关系？

1978年以前的中国，社会与政府是两个完全重合的同心圆。社会就是政府，政府就是社会，政府之外无社会。政府把一切管起来，个人的工作、生活、思想，整个社会的经济、政治、文化。

1978年以来的30多年，总体上是政府自我改革与社会从政府中挣脱出来的过程，从政府之外无社会到政府之外有社会的过程，是社会在政府之外获得生命力的成长过程，是个人意识从集体意识脱离的过程，是政府相对收缩，社会急剧扩展的过程。

近年来，社会仍在持续拓展新的边界，但政府重新扩张，所以对社会有双重感受，一方面是真实感受到经济、生活方式、观念的全球化，另一方面也同样真实感受到来自政府的力量在变强。

在爱丽丝漫游奇境里，红皇后对爱丽丝说：她必须一直奔跑才能停在原地，因为世界在动。这同样适用于现在，社会一直在跑，为了获得更多的自由度，社会也一直在跑。

现在，全球化跑不动了，渐渐消退；再见，全球化；下次见到你不知是何年。在那之前，各自珍重。
