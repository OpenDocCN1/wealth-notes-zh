# 你配创业吗？

在耶鲁做完一场中国经济讲座，还在读大—的一群中国学生上上来问我：
“对大学本科生创业有什么看法和建议？”
我现场匆匆说了几句。次日在去华盛顿的火车上又收到了后续问题，看来是真在**想，还是写一写吧。美国火车实在太慢，从纽黑文到华盛顿要五个小时。闲着也是闲着。**

社会总是需要大量创业者。创业，就是创业者自冒风险，重组生产或服务或其他，去捕捉自以为存在的机会。创业的社会价值毋庸置疑，创业者就像是打破社会日常状态的基因变异，是社会演化的关键动力。
但绝大多数创业会失败，其实是必须失败。原因很简单，用进化打个比方，只有极少数基因变异会提升生物的适应性。虽然基因变异对生物进化极为关键，但大多数基因变异要么有害，要么无用，否则，生物进化就会太过剧烈。社会演化也是一样，本身有大量内隐知识，“存在就是合理”很强大。或者说，尊重现实错不到哪里去，改变现实则多半是错的。创业成功率太高，社会怎么办？

所以，就仿佛整个看不见的手引导每个人的自利行为有利于整体福利一样，创业者基于自己的各种理由创业，本质上却是以自己的高风险选择，为社会演化做贡献，而绝大多数成为炮灰。
极少数创业者被社会选择，获得丰厚回报，但创业的平均预期收益应该跟打工差不多。如果真有靠谱统计，这话恐怕**了。这个平均预期收益，就好比蓝皮显著提高了他家乡所在小区的平均收入一样，对被平均者没有意义。或者换个表述，平均预期收益差不多，但波动大太多，夏普比率低太多，一般人不会做此选择，只有极度偏好风险的人才会。

之所以近年创业成为显学，是因为互联网热潮似乎带来了更多创业机会，似乎降低了创业风险。前者是事实，后者并没有。
互联网热潮没有改变风险的基本分布，但与前互联网时代的创新相比，互联网有更强的赢家通吃性质，也就是说，给那极少数成功者的回报更多了，看马云，看看马化腾。为了捕捉金子上头，投入少回报更丰厚的机会，投资者愿意把钱撒得更广，你下场的机会是增加了，但赢的机会却变小了。苍天没有便宜给谁。

如果创业也有“理性”可言，那么，“理性”的创业者往往是无路可走，只好拼命向前。马云做时如果能找到理想工作，不一定要有今天。
还有一类创业者，创业是因为创得起。阿里巴巴实际上二号人物蔡崇信前不久在耶鲁法学院演讲中对学生们说，他为什么要加入阿里巴巴初创时的草台班子，除了与马云“宿命般”的际遇之外，还因为“耶鲁法学院毕业是这世上最罕见的珍宝”，即使创业不成，重回旧轨，也绝无问题。今天创业者中，除了亡命徒外，出现越来越多一流商学院毕业生，也是这个原因。下有保底，上不封顶。
王思聪也属此类，连续创业连续成功，令人赞叹，但假设失败，他失得起。成功的话，就从父亲所愿的“小目标”起步。

从相似但有所不同的角度，徐小平对风险投资所的一般人也是太小了，因为创业过程是对创业者的全方位考验，会极大提升其人力资本的价值，即使创业失败，回归“正常”职业生涯，同样有机会，甚至有更好的机会。这是蔡崇信逻辑的大众版，但我对徐小平的乐观是不乐观的，创业造就的人力资本与职场所需的人力资本是否匹配？我说不清。但资本家出钱陪你练这种重太好，好到不会有几个得到这机会。
每个人情况不同，无法具体建议，但如果你既非无路可走，也非创业风险有保底，而是身处广大中间地带，我能给的一般性建议是别创业，尤其是别被创业。牺牲自己造福社会的事，让别人先来帮吧。
当然，对问出这种“创业”问题的人，我从不很担心会毁学创业，因为典型创业者不是这些，他们不是这些，是因为典型的异致，就像基因变异没有为什么一样，他们必须要纵身一跃，拥抱与未知相伴而生的不测风险，也不会问为什么。
