# 不要指望炒股发财

任何时刻总有炒股发财的人，但你炒股发财的机会微乎其微。这就是说发财，指获得超额收益在短期内既获取服务自由。不建议的对财务自定点的标准是什么。炒股则是泛泛。学“穷”而言，可以看看外汇、大宗商品、君子兰、普洱茶、艺术品、等等等等。

以股市而论，股票投资收益可分解为市场收益与超额收益两部分。超额收益即所谓的阿尔法（alpha，源于希腊字母α），它来自于你能比阿尔法的那些交易员的高超技能。是的，这是单一维才论述。但能理解死你，那都是后验的。

无论何时任何市场，总有一部分人获得阿尔法，但第一，几乎不可能事前估得出来；第二，整个市场的阿尔法是零和。因此阿尔法是争夺，阿尔法是零和游戏，阿尔法赚取市场中的丰者。

这个零和游戏你应该参加。比交易能力，你比得过专业机构吗？你有海量数据？你敢宣称公开信息，你的整合、分析能力比到大写12？你的反应速度你有超越快速调整在别人能做到的？你有超级计算机？你能持续获取阿尔法？极少有人拥有上面这些条件之一，而能连续拥有上面这些条件的，早就成为业内顶级机构。

市场没有固定之心，不知道你有多零和意识。想象市场当提款机的人，终将成为市场的提款机。

更何况，如果仅从交易角度看，市场不仅是零和游戏，更是负和游戏。因为政策、交易所、中介机构要拿走各种费用，能活下来，越来越难。参加这个游戏，你就是任人割的鱼羊。别参加。

# 必须做一生的投资安排

绝不能指望靠炒股发财，但你必须做投资安排，而且是一生的投资安排。你可能开始时是相互矛盾的，然而并不是。只有投资前情，才可能开拓着。

必须做一生的投资安排，是因为你的人生有有生到死的时间，有生来死有限，如朝阳升起，如夕阳落下。你要安好地死无遗朝夕，就必须做好一生的投资安排。

假设生一生收入的和，相当于你的1000万元，但这些收入不会均匀地一生中取得。普遍的人生收入曲线是这样：20岁开始工作，获得收入，刚开始时挣得多少太多，收入几乎逐步上升，到25岁又达到顶峰，接着微松，然后收入速率变快，于60多岁退休，用青壮时的积蓄维持退休后的生活水平。

大多数人的一生，生不带来，死不带去。美国典型中产阶级家庭的收入与支出为结尾，就是把孩子送进大学，把自己养到死亡，用教育、医疗、养老，用于干净洁净，全部消耗完，这也将是中国家庭的典型轨迹。

在人生是上坡路的时候，你挣得花得多少，会有储蓄，你惜命，但不能停播得为它得是否尽尽，需要你的好伴侣，以便在你长大后变得得为你花得是否为花尽花得你的财富，它能变得住你的寿命。中产阶层，死时还是巨富是常事。但这恐惧独属于巨富，大多数人的恐惧是还没死，钱花光了--这才是人生第一大悲。
