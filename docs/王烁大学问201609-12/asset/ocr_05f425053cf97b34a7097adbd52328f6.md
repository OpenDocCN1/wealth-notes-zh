# ## 这次美国大选解决不了
## 重要问题

![](bbox=[0.05, 0.08, 0.15, 0.11])

这次希拉里对川普，打破了近几十年来美国总统大选的套路。

过去的套路是这样的：

在两党初选阶段，你会见到候选人拿出许多极端到奇葩的政策，因为候选人必须满足自己阵营喜爱的基本盘，而党内激进派的意见往往必然是基于原教旨的。这次大选的初选阶段也不例外，两党都有其他候选人拿出许多激进主张，民主党有桑德斯，共和党有克鲁兹。

在两党产生总总统选人，进入对决阶段后，就不一样。过去，双方都会向中间位置靠拢，调子降下来，立场温和许多。这不是因为政客虚伪，政客当然都是虚伪的，但他们在对决阶段的选择反映的是选举逻辑。

两大阵营对峙，站在己方阵营之前，面对对方阵营。这时该做什么？

你得喊话。要争取对方阵营中的人向你倒戈，得往中间走。

事实上，这正是政治学著名的中位选民理论（Median voter theorem）预测的结果。

中位选民理论是这样的：假设基于一个议题投票，两方竞争，选情分布，而选民的立场或者连续分布或者随机分布，那么两方的竞选纲领就会往中间靠拢，最后到达难以分辨的程度，重叠在正中位置。所谓正中，不是平均值，而是所有人按立场排序后最中间那人，他的投票决定胜负。

道理一说就懂：无论在这个人的左边或者右边，都会输，输给对方反向的选民总数+中位选民，必须居中。

其实，中位选民定理就好比两个人分蛋糕的博弈，最公平的分法就是一人负责切另一人负责选。候选人竞选也一样，你所在的任何政策立场，只要偏左或者偏右，都会被另一方“选择”只在偏向中间的正中立场占优，好比你蛋糕分得不均匀，对方先选。所以，你的最优先选择就是占在中间，对方也是一样。

![](bbox=[0.2, 0.65, 0.8, 0.71])

中位选民定理的适用范围远不止政治选举。只要符合这些基本条件：

+   - 单一议题
- 立场随机或连续分布
- 多数者胜

那么制胜点都在中间。比如说，只要没有发改委来指导的国家，加油站大都比邻而建，就是同一道理。想想看，还有哪些问题满足上述条件，适用中位选民定理？

美国近几十年总统选举最后阶段一再重现中位选民理论的预测。许多时候，两党总统候选人在重要问题的政策立场，无论是经济、对外交、对征税，都难以作出显著区分，双方比来比去，最后只好比选民观感、人格判断，而不是政策分歧，因为没有。结果就是，胜无大胜，败不惨败，下次再来。

这说明什么？

说明美国人人长期以来的政治立场分布满足前面所说的条件：要么很随机分布，要么是很强分布，总之，散得比较均匀，并不极化。这使得选举变得相对无聊，即使体系稳固，国家幸事。
