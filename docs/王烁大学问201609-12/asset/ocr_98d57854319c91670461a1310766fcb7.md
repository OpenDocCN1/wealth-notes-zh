# 第12周问答｜如何加深对知识的理解

张容：公众演讲可以把自已学习到的知识讲述出来，您认为写作和公众演讲哪个更能加深对知识的理解呢？

王烁

这个只能说是看人。管理学大师德鲁克说，有些人是长于读有些人长于听，要根据自己的长短和别人的长短组织相应交流方式。同样的道理也适用于写与读，有人擅长写，有人擅长读。我自己是长于写，短于读，我不觉得在理解知识上两者有什么高低，但两者适用的情境是不同的，要知道自己的长短，选择适合的情境。这是扬长避短的一面。

另一面，就是不要总呆在自己的舒服圈里。要追着自己适应所处并不舒服的地带，有所改变，有所进步。比如，演讲我不行，但也不能总躲着。耶鲁世界学者项目有个演讲培训，我去参加了，颇有体会，也学到了一些技巧，已经在前面的专栏文章《领袖演讲术入门》里分享给大家了。

老猫儿：提到随时随地说服人的能力，而不是事后想到如何应答，应主要从哪方面锻炼？

王烁

跟上一个问题相似，你得了解自己。比如说我，与一对多演讲相比，一对一效果更好，所以我可能尽量把谈话变成一对一。如果一对一谈话中，反应速度仍是问题，那就有意识地吧速度降下来。

举个相同但可悲的例子，我跟同期世界学者大冰天对话，我是来自美国外交部的级外交官，说话总是慢得有趣。我向他表示钦佩，他说自已其实说话快，因为脑子转得太快，甚至因为脑子转得太快，说话跟不上就默默着。我说，你这种情况我熟悉，因为我的同事斯蒂文也这样。不过怎么在你身上没感觉到啊？他说，因知道自己有这个缺点，所以长期训练，有意识地放慢语速，现在大改观。

还有，就是多说自己的。虽然这条自已做得不是很好。我自己，是跟人往往无话可说。你的这种情况，当时说不出来事后又想起来说该啥，我少年时代也有。我靠什么呢？多读多想多写，这种症就慢慢消失。
