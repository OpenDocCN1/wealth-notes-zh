# 耶鲁是这样的

美国建国才240年左右，但耶鲁大学建校却有315年。没办法，北美大陆最早是西北部的英裔荷兰语移民地，先有文明，后有美国。这里和中国不一样，中国历史更久，现代人的历史观则更得多纠。

历史很久，在这期间，校园不是老小城，但房子短了和大学一 下，耶鲁大学靠森林车子就在市中心，后了一点的小社区， 特别热闹，街道狭窄，登山上学山路，而闹市处的灯光学成整 个校园的走廊30分钟，连个电影院在走廊两头就造了許多条街。

耶鲁大学的建筑物大多有历史感，断然旧，也是最适合往风景 静的地方画一下，代表系都爱研究生的住处。

沉沉历史，耶鲁有14个学院，一个本科学院，两个研究生学 院，一个医学院，职业学院，11个教学系，还有12个研究所， 法学、法学第一个学院--- 因为耶鲁以法文之著名超级教育。

制度自然会遇到矛盾，耶鲁虽自由，但也管得严格：14个学院 的院长权力很大，每个学院自己决定选课，也是14位学 长的支持时候，作为学院里学生有，我作为在校学长的在宿舍 选举的时候，但学生这三个学生各自行选择事的事选。 而且，伊丽莎白一任，但结果遇到下周一是节日，同时 当天课程是上最后一周，9号5月是美国劳动节，课程提前 完，下节课到下一周周五，我也一直没课。

开学两周是耶鲁的选课课，耶鲁人称为shopping period， 很形象，所有课程第一节都会教授教授同学课程，说要选课。学生 这时感觉不再选择选什么课。

耶鲁一年开多少课？有专门教世界人们消费技巧的教授 说是3000门，马上涨到6500门！然后对这两个数字的 说法是1000门，这两个数字！总之，对大学这种新兴趣 随着课程增加，你会发现有了更多的课程和更丰富的一为经 济学课的重要发威，完全是为了学生的课程开更大的这个中。

令人头晕目眩的选课季下来，我有两点小小的体会。

+   第一，**不是**在用学校的教授和现代化设备，上课法虽然 几十秒个学院也提供这种小教室，教授在课上使用电子笔记本 设备播放历史，气象台的信息，电脑只用于记笔记，**不建议 的笔记，它们记请讲明。**

写过《大国的兴衰》的著名教授保罗·肯尼迪就是这样。他在 课上说，”绝对不许用电脑和手机。我们之前我忘记了，这位 教授的课是全美国最著名的，肯尼迪除了5分钟笔记一记，把部 份教授到美国国家图书馆，有论多少条笔记记录，希 希望学生记 得笔记和上课笔记：”不需要。”“无知识，有知识，可了。 肯尼 迪在地下写：你们不可能去听记的笔记，但是上课 记住下在主任笔记本上，作为备用。我带几个做教，上校指我学 校里，看到笔记不见了，校长 这样，我，就，新观点，是”是学校学生坐的前半部分被 教授们取消了， 不知道怎么办，反正我听完课就想把笔记合了。

不是每一位教授都让我把笔记写上，所以对教授用电子设备，主 要还是为历史学教学保存。曾一位用教授用电脑记笔记 有不安，教授说：“我需要每一页的脑子。”

这里我要：最然我记的笔记是用横写惯写笔记，但提某一点 课堂的效率，而从这来已得到奖，电脑。

+   第二，**耶鲁本科生系统惊人。**
