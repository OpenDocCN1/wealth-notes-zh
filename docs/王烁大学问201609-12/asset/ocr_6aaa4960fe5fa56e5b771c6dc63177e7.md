# 一小时速成影响力

精英晚宴会从9月中开始，世界学人项目将陆续请来十几位卓有成就的各界人士，为我们讲各自最擅长的题目，共进晚宴，对话。

走进高瓴街55号香樟楼晚宴会场，迎面一位大美女士伸出手来，我握住：“你好，你一定是周依了。”

![](bbox=[0.14, 0.21, 0.86, 0.43])

Zoe Chance（周依）在耶鲁商学院教最受学生欢迎的课：影响力和说服力。来耶鲁商学院当教授前，她创业过，管过两亿美元的生意，拍过电影上过电视，跟各歌合作过全球食物指南，TEDx常备，写过论文霸。在这一切之前，她是哈佛本科、博士毕业。

今晚，只有一小时，她要把我们速成为影响力达人。

她做得利吗？我行吗？

我问他，“周J，你教的这门课跟巴里默斯课有什么不同？”巴里是Bartley Nalebuff，资深教授、博弃论大家，也在商学院开设博弃课。我上的是他的大课。

“巴里的课很唬吓人，我的课很猛却不吓人”，周依指着银幕上今晚演讲的标题：“像泰迪武士一样谈判”。

这还不够吓人的吗？

培训开始了。

# 第一，有什么要求，务必当面提

人们接受当面请求的可能性要比通过电话、邮件等间接途径高出两倍。

这符合我自己的体会。具体原因周依没展开说，我猜一是因为面对面对，说“不”很难，拉不下面子不就这么个：二是当面对话没有留下反应时间，如果你点时不可能在一瞬间是与否之间作一而从，说"是"的可能性远远大于慢慢思忖并仔细权衡之后。

那么，反过来讲，遇到别人当面提要求你感时为难呢？如果不想后悔你就不要当面同意，就说一句话，“给我点时间想想”，拖字诀，一定是千金。

# 第二，态度一定要好，立场坚决不变

周依举了 FBI讨专家克里斯·沃斯例子。沃斯的书写名字就叫《不用分》，就是桌子上的蛋全拿走，啥也不留给对方。其实他也是没办法，因为他经常做人质谈判，什么也不能给劫匪，没得个，靠的就是一张嘴。

怎么做得到呢？

沃斯去买车，一步到床厅，面带微笑，用理解的口吻，表示方讨价很合理，但自己是出不了这个价。无论销售给什么理由要他加点钱，都这样，直到销售投降。当然，前提是研究透彻，准备充分，有备份方案，就是不行可以出门换一家。

# 第三，贴标签有魔力

比如，“你是整洁的孩子。”这句话提升孩子收拾屋子的概率，比“你应该先做个整洁的孩子”要，高出五倍。给标签魔力是70年代的心理学研究完成，今天已成为广告营销的支柱。你想卖什么东西，就把广泛投放的目标对象放到对应的那几个柜子里，就是这么魔力。
