# 极简金融课（中）：对你唯一靠谱的投资方案只有一个要求！

交易环节是零和博弈，但市场还有正和博弈。这正是你可能在市场中战胜通缩的根本原因。

长期中，股市参与者总以来的整体收益，并不都是正零，最终取决于上市公司效率提升业绩改善。所有历史数据以来，所有主要股市的代表性指数，在长期中看，穿过短期波动之后，都显示为一条向上攀升的线，就是斜率有所不同，因此存在所有人都获益的机会。这个正和博弈就是你作为普通投资者唯一应该参与的部分，透过市场赚企业成长和经济增长的钱。

抓市场收益，就是抓市场的贝塔（beta，来源于希腊字母β），放弃战胜市场的执念，转而享受市场整体的风险报酬收益水平的回报。巴爷曾说过同理，风险如同河水吗？阿凡提说，如果飘飘石一样大。飘，阿凡提说的其实就是贝塔。

不同市场的贝塔不同，最简单的方法就是股债混合。相对而言，股票长期收益率越高波动大，债券长期收益率低但波动小，互相补充，两者组合投资，能够在部分熨平波动地同时获得相对稳定的收益。

# 举个简单例子：

+   - 你有一笔工作收入，就开始建立股债投资组合，不要等。
- 初始比例如为股债8:2，股8债2。
- 每年或者平衡十一次：如果股票涨上所占比例超过80%，则卖出股票买入债券，把比例恢复到8:2，反之亦然。
- 但是，每隔相当长一段时间后——般建议10到一年次——你需调整股债比例，逐步从8:2降到7:3降到6:4降到5:5...债所占比例逐渐来越高，最终到退休以后主要以债券为，即没有借收入，年轻人轻易承受股价波动风险，退休之后，因为没有工作收入，就应该承受投资上的一些险比例调整是为了匹配你的生命和收入周期。本内容仅供社群内部学习交流，切勿外传，人群群cccdd660道理就是这简，细节来说有无穷细节。

+   - 股债初始比例8:2对你来说是合适？
- 退休后全为债券对你来说是否过于稳健？

每个人的生规划收入和投跨人生周各期分配情形都不同，只能是根据自己情况选择最适合自己的那个方案。大体而言，冒险期越率，退休后就必成守，这性格无关，关你的人生周期起点。

至于买哪些股买哪些债？尽早忘掉这些问题，不要去赌你的眼光，也不要去博有眼光到合适的人帮你做决定。你得选择代表性为广的股票和债券指数，然后在与这些数对应的指教化投资工中，选择交易成本最低、成交量最大的那。

这个思路放弃择股，几弃择债时，仅仅根据个人的生命周期和收入分配置最小风险的市场，最终把命运交给市场而不是自己的人博奕市场，对绝大数人来说是一种一靠的投资策路，选择不再试图战胜市场而是拥抱市场，才能免于被市场有针对性的伤害。

之所以它靠谱，是因为长期中大体能躲战通胀。它能使你一生渐渐积累不被通缩所侵蚀，使你克制当下欲望把消费延期到未来的努力不致虚报。它不能实现你的发财梦，但能保护你。

之所以如此，是为一系相关因素：从数十年的间维度来看，代表性最广泛的高债指数与市场通胀相关，市场与经济高度联。你看到越来越多的资产：房地产、大宗商品、海外资产、对冲基金、PE/VC等等。投资工具越来越复杂，但你的思路应当始终清如初：确定初始比例，中定期调期再平衡，长中定期调整比例，以配自己的生命周和收入分。

它对你只有一个要求，而这个要求很高：克制自己的聪明主意，压制自己觉得市场是不可抗念头，放弃与市场博弈，转而以长打短，把投资当作为你工作生互补的另一面，把光阴岁月严丝合缝，相互对，阴阳对。

把时间拉长到你的一生，视野从股债市场发致富转到利用市场保护自己，你会观地多市场长期波动，用更稳定的心态、更少的精力，更明确但长期中更有效的方法，来理自己的财富与人生。
