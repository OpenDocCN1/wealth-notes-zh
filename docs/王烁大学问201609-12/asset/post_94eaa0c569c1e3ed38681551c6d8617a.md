
# 极简谈判课：有无选择决定拿到多少

先复习一下极简谈判课迄今讲过的内容。

谈判是做蛋糕和分蛋糕。

蛋糕=双方谈拢的收益-双方谈不拢的收益。

谈不拢时双方各行其事的收益即各自的BATNA，就是各自底线，因为收益低于BATNA则谈判无意义，该干什么就干什么去更好。

问题来了，BATNA确定了你的底价，但你可能只要底线。极简谈判第一课（首先，你得谈判！）讲清了只要底线的后果，就是谈成或谈不到就有限，谈不成就没有转圜空间。

在BATNA之上还有整个蛋糕在等着你，你要多少？

至少有三种分法：

- 第一，误导、忽悠、欺骗、恐吓对方，能弄到多少是多少，最好是全拿。许多人就是这样做，还有许多人认为人生赢家就该非得如此不可。
- 第二，按比例分，这是最常见的做法，双方各自投入多少资源，按比例分蛋糕。很合理吧？
- 第三，平分。

先来看第一种，事实上，以运用心理学技巧为核心谈判术，很容易走到这条路上来：

消除人性的弱点并利用它。没有证据显示这样不行，因为人生短暂，因为搞一票大的从此可以财务自由，因为许多人记忆力只有7秒钟，交情或笑话不笑。总之，成功有很多种，这也是一种，如果你有自信走这条路的话。

它的缺点是不好掌握，首先是没有普遍方法——每发现一个心理学就把心理改成心理术，但每一个心理学就有一个对应点，你使诈我使诈这个循环走不出来。谈判总要求止，知止而后有定，定而后能静，静而后能安，安而后能虑，虑而后能得。但心理底无止力的。

巴里说，谈判不必是心理战，可以变成似做数学题，我更喜欢这条路线。

那么，第二种按比例分如何？

按比例分蛋糕，最典型的就是股份分成，出多少分多少。不过先省着，下面再回来讲它。先再讲个巴里的故事。

可口可乐跟茶厂合作，因为可口可乐采购量大，让茶厂瓶成本从0.19美元降到0.11美元，假设采购1亿个瓶子，成本总共下降800万美元。怎么分？

可口可乐说，成本下降主要来自于我的采购能力，对你也益处多多。第一个办法是销售法，可口可乐销售比茶厂多，可口可乐销售额比茶厂太大，你们分个几百万美元很不错了；第二个方法是简单切一刀，我要把分法写在了报表上是过了重要头的零头，零头分，没意思，咱们们分700万美元的，你们头100美元，100万美元对茶厂已经够意思了吧？

巴里不这样看。他说：你的采购能力是很强，但没有茶厂也不行，你既互不可缺；你说钱太少了你都没用，那800万对你也是太少，不如都给我吧。

这些对话包含了两个关键原则：

- 1. 任何一方想多分的理由在谈判中都是对称的。以后面对对方多分蛋糕的理由，哪怕看似很合理，你总只要多想，都能找出恰当的回应，以子之矛攻子之盾。
这是因为，
- 2. 在双方BATNA之上做蛋糕，缺哪方都不行。巴里举了个极端的例子：A、B两公司兼并后产生一大部分是由A公司收编B公司带来生产流程革新，这些收益该怎么分配？都给A？全给B？巴里说，B公司可以这样主张：如果不是我的生产如此落后，你A公司的技术就哪里能有这般大的改进收益？我的落后与你的先进，一起做大蛋糕，我落后我有功。

最后，可口可乐与茶厂平分了装瓶成本下降带来的收益，每家拿到400万美元。

巴里认为，任一方放弃的话蛋糕都会消失，所以最好就是平分。合理、有原则的谈判好比做数学题，先确定每个人自己的BATNA，再定蛋糕有多大，最后平分。

回到前面提到的股份分，真的谁出资多少拿走多少吗？

其实不是。

你看马云在阿里巴巴搞的合伙人制度，且把当季、软钱在一股不变，只看作大股，当季软钱，雅虎人股中只投了钱，马云将支付宝走，释放强烈信号：越来最小的蛋糕哪一个呢？

类似的故事在中国商界天天都在发生，近年来效应公司因中国CITOD大离职潮，爆出期件争议，并使得互联网公司员工工期问题成为焦点，其本质是管理层与核心员工各自的BATNA发生剧烈变动，然后管理层重新蛋糕。

这个话题也有另一面，经济学家们通常说，"人力资本是长着双翼的，"指人力资本可携带，而它本质上就是的你的BATNA。无论如不能自己掌控自己的BATNA变小，在所谈利率中你首先得的是你自己的BATNA，然后再加你多得的蛋糕，你的BATNA越大，对等的BATNA越小，你就能拿走越多。

这些故事告诉我们，在中国这块大地上，法律不是挡箭牌。BATNA变了，谈判就跟着变。每个人为自己负责的最好办法就是增加BATNA。有选择权才能多拿。讲得已，最靠谱的走生策略。

前两天去见耶鲁法学院教授蔡美儿，就是《虎妈》、《虎妈战歌》作者——这个话题以后会单独写一篇，聊天中，她忽然说：

> 你说什么使人幸福？我觉得是有选择使人幸福。

英雄所见略同。

# 极简谈判课：保住你那一半蛋糕

### 这节课系统答疑

问：你在第一课里讲必须敢要价，后来又说蛋糕应该平分，不是相互冲突了吗？

答：不冲突。因为现实事前没有人知道蛋糕有多大，而蛋糕的大小取决于双方的BATNA（如果谈不成双方各行其事的所得）。但你一般不会知道对方的BATNA，对方也不会知道你的BATNA，许多时候甚至你连自己的BATNA都不清楚。所以，你得通过要价厘清双方的BATNA大致位置，才能对蛋糕大小有个相对靠谱的估价。

延伸开去说，当对方看法跟你不一致的时候，千万不要说服对方，要转而利用双方看法的不一致，尽量做大蛋糕。

比如，互联网公司招人往往是现金和期权组合，但员工与公司对现金和期权的偏好截然不同，因为人与人的风险偏好必定有差别。无论对方是哪种，你或还是员工，千万不要说服对方把钱法调整到你跟头一样。你应该把自己认为便宜而对方认为为贵的尽量都给他。如果他比你更喜欢现金，那么新酬组合中就要尽量多含现金；如果他比你更看重期权，那么组合中就要尽量多含期权。

偏好差是关键，有偏好差才有双赢，大家偏好一样反而成了零和游戏。

问：我是想平分蛋糕，但对方坚决要多拿，给我下了最后通牒，不同意就拉倒，谁也拿不到。我怎么办？

答：首先，要算清楚，搞明白你有没有高估了自己的BATNA。比如，如果你比他更着急要把蛋糕分掉，因为马上要还房贷，那么，急着想用钱本身就会降低你的BATNA——你大概把蛋糕大小算错了。

然后，如果你确实把所有因素都算到位，蛋糕没高估也低估，那么，对最后通牒的最好回应就是拒绝相信它。因为谈判失败则对方也受损，所以如果他足够理性，那么他开出的最后通牒是空想的。经常在在谈判中开出条件后玩失踪，让对方找不到自己，就是要以此制造最后通牒效果。遇到这种情况，你也玩失踪就好了。

记住一点，面对蛋糕的时候，双方是完全对称的。对方能做什么你也能做什么，对方不应占到上风。

讲个故事，某报业大亨问电影明星，100万美元共度良宵怎么样？明星点头；大亨又问，100美元一夜怎么样？明星大怒：你把我当成什么人了？大亨说，你是什么人刚才已经搞清楚了，现在我只是要确定价格。

这对最后通牒也适用。你是什么人，我早已知道了。

问：平分蛋糕是必然的吗？

答：人与人之间在现实世界中分利，信息不太透明，情绪不太稳定，理性不太够使，哪里有什么必然的事情？只不过，给定双方BATNA已知，则蛋糕大小已明，那么平分是最自然选择，也是双方聚焦点所在。你不应当拿不到一半蛋糕，正如你也不该拿到一半以上，在蛋糕面前双方完全平等。

了解这些，便知道，谈判之难不在心理攻防，而在于信息获取：我的/对方的BATNA是多少？受哪些因素影响？双方偏好差别是什么，蛋糕最大能搞到多大？蛋糕大一点还是小一点对我有利？

了解这些，便能把它判断从心理战变成做题。

你读完极简谈判课以后，要做的第一件事，就是把它传播出去，越广越好。想想看，如果将来的谈判对手也看了极简谈判课系列，你们之间的谈判，将是多么轻松愉快！

祝好运！

# 第6周问答 | 耶鲁大学的通识教育

Lens: 王老师，能否详细介绍一下耶鲁大学通识教育的理念和方式，对我们有什么参考价值？

王烁

耶鲁最重本科教育，而本科教育的风格是通识教育。所谓通识教育，旨在为学生带来完整知的知识结构，养成能思考的通用智慧。学生们会有专业，但大量涉及本专业之外的知识。因此不同于职业或者技术教育，比如说，在耶鲁，本科生院和研究生院、医学院、法学院、商学院等等都叫作职业学院。

通识教育起源于古希腊，指公民所应当具备的知识与能力，要与公共生活社交完整的人。也就是，要会打扮，会闹，能打官司，在法庭上为自己辩护，所以得懂哲学、数学、语言、演讲术、音乐、天文、逻辑、等等等。

现代社会分工明细，古希腊的通识教育当然只能从精神上效仿；作为现代公民应当具备的知识，一般说来就是文学、哲学、数学、部分自然和人文的文科。你从大学毕业，应当具有现代公民的完整智能，而不仅仅是被打造只解决特定问题的工具。

最原本地保持通识教育的，是一些小型的文学院，规模极小，教学质量极高，散布在美国英格兰乡间，稍有点与外界隔绝。耶鲁早已走出这个模式，成为现代研究型大学，但还保留了通识教育的精神。

我看到的情况是：

- 第一，本科生集中在住校，分成14个学院（college），每个学院都建古雅，四面团合，有广大的中枢，学生住在此食宿，娱乐。也有图书馆和体育设施，college 在管教学，主要是住和生活设施，旨在让学生们增加交流，培养集体感。要么说，在现代社会会重兴一种中典风格。
- 第二，所课老师，其多少大课，因为没有本科学开课太长，比如保，肯尼迪学系开课，年纪大了，站一会儿就坐下，所以专桌，就这样，还是开三门。
- 第三，耶鲁最大的系是历史，经济系届居第二，在圈内很难想象。因为耶鲁历史系水平极高，特别是古典部分，有希腊古希腊教历史学在Donald Kagan 专组，大量学生注册历史，同时学其他专业课。我一个学生联络就是历史学生，就计算机。通识教育体后让学生有自由的选择。
- 第四，大量本科目的课程并非关于技能和知识，而在于修养与思考。比如，耶鲁有一门课，‘值得活’（Life Worth Living），依讨论哲本人及其所处的哲学，探讨在这些哲人眼中对多生问题的回答：值得活？怎样才感觉？有何希望？失败怎么办？对有责？老师严据中引，引导学生。这门课师年，学生们成立了‘哲得活’协会，使命陈述是：‘让每个耶学生都要认真思考活为什么值得这个题目。’
- 第五，耶鲁通识教育，也有弱点，比如科学一偏弱。我耶听学生说，多年前，还曾议过撤除科学技术相关学，当然而成，但重时亦时，据是当下耶校最受关注的新道。
