# 28 | 林毅夫：该如何看待中国的产业政策？

徐琳：经济·大师30讲

林毅夫：该如何看待中国的...

你好，欢迎来到《徐谦·经济大师30讲》。

这一讲，我将为你介绍最近十年最大经济学辩论，那就是产业政策之争。所谓产业政策，是政府制定引导产业发展的政策，有点幼稚体改革。第一位是林毅夫（1952.10-至今），北京大学教授，上次已经介绍过了。另一位是张维迎（1959-至今），是林毅夫老同学。两人，当年还一起创办了北大中国经济研究中心。

![](bbox=[0.25, 0.18, 0.75, 0.32])

张维迎生于1959年，陕西人。八十年代，他在国家经济体制改革委员会，工作了六年，可机构简称体改委。提起体改委，你可能不知道，当时可是赫赫有名。周小川、楼继伟、李剑阁、郭树清这些技术官僚，都是从那里出通。

当年很多改革试点，当时不开会改委。我和朋友说，在江浙沪，当时体改委年轻人多，往往可以同最高领导沟通，大家都有很强的使命感。后来，体改委会并到国务院，在体改委工作了的人，有的经商，有的从政，有的做学者。但你观察下，人的气质，还有点不太一样，90年代，张维迎去牛津大学读博士，回来后在北大，在大学生改革等公共事件中，可发可不发。

上一个人说了，林毅夫有种书生气质。张维迎呢，在政治体系中，农村出身，带着西北人的淳朴。他的个性，真率而独立。发言说，往往有种觊觎皇帝新衣的直白犀利。有朋友就说，两人都是经济学家中的大IP，自带流量。所以，他们的产业政策辩论，关注度自然非常高。

2016年，张维迎写了篇文章，叫《为什么产业政策一定会失败？》。他指出，产业政策是新中国特色，也注定是失败，是穿着马衣的计划经济。而产业政策之所以失败，除了认知方面的原因，还有激励机制方面的问题。

随后，林毅夫则发表《经济发展有产业政策才能成功》文章，为产业政策正名。他从新结构经济学角度指出，新结构经济发展是张维迎学才说，新经济经济，就是林毅夫这些些年力推的理论，认为发展中国家要保持较快发展，必须在每个时点找出自己的比较优势，这1次优优势，是这个时点的要素禀赋决定的。他认为，经济发展需要看“有有效力的市场”和“有为的政府”的共同作用，来发挥比较优势。

# 有效市场和有为政府

有效市场我们都知道，“有为的政府”，就是强调政府也要有所作为。林毅夫认为，在技术创新和产业升级过程中，必须要有“一个一个亏损的企业的家？“，如果政府将资源都去补贴，去补贴它企业，后来者将会趋之若鹜，也拿不到垄断利润。所以，对第一个亏损的企业和从业者，失败成本低成功收益高的对企业的这样，有些至关重要的行业可能没法发展起来。怎么鼓励制度？他认为，发达国家激励主要靠薪酬制度，发展中国家，就需要加上其他的激励。

外行看热闹，你学了这门课，你应该理解要看门道。产业政策，不仅在经济学争论。也关系到如何定位中国政府。所以，不但涉及学术，也与现实深度关系。

如果熟悉林毅夫，你知道这些年，他一直在努力推“新结构经济学”。产业政策是其中之一。新结构经济学的产业政策是怎么样的？它的主要理论是，产业与国为竞争者。就是若在于比较优势的产业，变成竞争者去发。由于先决比较优势的企业则助其转型，转它去适应，大概是热张继逊，去适应。他也有些退。逐渐落到了奥地利经济学派。所以，他的观点，基本只有市场的才是最好的。

对产业政策的不同，可以说是两人主要分歧。张维迎定义，是指政府以行政性手段或歧视性对待，林毅夫相对则宽容，认为产业发展，是中央或地方政府为促进某种产业发展，有意识采取的政策措施。

我查了一下，产业政策这个词，70年代之前，英语还没有。最早的产业政策实践，来自五六十年代的日本。日本主管商工业省通产省，开始扶持经济。可以这么说，产业政策跟大成色，有人从日本人日本二战后的经济奇迹，就有人从通产省官的荣民经济政策，我有个日本朋友，还在通产省工作多年。他跟我说，产业政策是使用，需要有场景。要么是资金缺乏，要么是产业政策幼稚。

自然，对通产省奇迹，也有不同看法。我和经济大书会书的那学青教授聊过。他说从并不是，例汽车行业和制造业。是接受日本投资商银行资本，最后通产省。如矿业，石油和煤炭行业，才是接受日本贷款最多的行业。他甚至指出，日本汽车的辉煌，是厂家抵抗住通产省规划的结果。

# 近距离看产业政策

从国际经验看，成功和失败的产业政策都有，有基本相同的背景，可能要问可以，在非国不行，或者反之。评价政策还有时间因素，既需要长时间的考察。有的产业政策，也许刚开始成功，随后就暴露缺陷。

比如光伏行业。2005年，无锡惠德在美国上市。创始人的富豪效应，吸引了不少人目光。而且，光伏行业有环保与回趋高光环。所以，开始大力推进光伏新能源的战略考虑，不少地方政府对于光伏企业，不惜给出各种补贴和支撑。从青海到东北再到四川，各地都热烈欢迎。有学者统计，仅仅浙江，就超过200多家光伏品企业。2011年，中国光伏组件光产能超过全球总量1.5倍。一时间，中国光伏行业间最火爆。但是好景不长，随着全球金融泡沫，光伏行业相关产品的价格一路跳水，光伏行业大量过剩，库存化不掉。2012年，海外上市的光伏行业全部亏损。

一个很有趣的事，为什么出现这样的结果？首先，中国光伏起跑时，更多因为成本优势，甚至，是建立在电费费各种补贴之上。这些补贴，没有真正给出效益，甚至补偿性的激励机制。导致行业内大上快上，行性外溢而滞。无形中，对产业快速实现产能过剩。这个案例，往往被作为产业政策失效的案例。随着时间，一些光伏行业也发也变化。到2018年，一些前有优企业，慢慢重新占到了变化后的世界市场。

那反观过来，产业政策是有是成功的例子？有一种高玩就认为，在中国高铁，就说话有观点在高铁在中国推进铁路行业的过程中，以铁道部为核心，制定推出了一系列强有局，将国有企业推进行政局。形成一个谈判主体，于是，主导了国际技术巨大投入。就说话，中国的高铁行业从大到存，快速发展起来。目前拥有高铁里程，比全球其他国家加起来还多。
