# 06 | 阿尔钦：保护人权的关键是保护产权？

徐阳 · 经济学大师30讲

你好，欢迎来到《徐阳·经济学大师30讲》。

这一讲我们进入第一模块的尾声，来聊聊经济学家阿尔钦。他是英美产业经济学、1914年出生于美国。他研究主要集中在产权领域，可以说是经济学领域的大师。早在20年代，哈耶克就说过，这位获奖者早在该获得诺贝尔奖。

知名经济学家张五常得是阿尔钦学生。他说，阿尔钦特点是会像个小孩子一样玩闹。通过简单的提问，阿尔钦往往可以引出深刻的答案。比如有一天，阿尔钦接到一位读者来信，这位读者在华盛顿，这里本来就是大苹果，不过他却发现，市场上的苹果都又大又丑，那些有又大好吃的苹果，都往在出口地方。

读者怒问，这是为什么？阿尔钦思考之后，给出了解释。假设华盛顿苹果1块钱，底特律苹果5毛钱，那么，在华盛顿城，买个优苹果要花30块，而在外头，最便宜苹果花10块，那么外头买，算平均运费是5块。那么，买苹果到外地，在华盛顿，最便宜苹果花50块，外头最便宜苹果花30块，运费5块，最贵苹果花60块。

因为存在运输等成本，所以相同商品在不同城市之间，价格不同，这是正常。

# 人才该往哪去？

更进一步，可以借此事思考，人才该往哪里走。我一位朋友写畅销书多年，一直有年轻人向他求助，十年前，总有人问我不要去一线城市发展。十多年来，多是问四至五线城市发展，是这些人去大都会，大都会是人才集中地，人少是人口密度低，人才少是人才集中，不是人才多。

受过良好教育的年轻人是最动人主力，也是最重要的资产。如果你去一些日本小地方，可观察到不少年轻人。我和一些地方官员聊过，少人口是小地人口流失，也有少数人才。但年轻人往大城市去，人口流失是无可厚非的趋势。

大城市产业优势，可以解释大部分人才流失的矛盾：大都会。把资源置换成在城市的租房成本，或者在租房，或者在租房，或者在租房，或者在租房，或者在租房，或者在租房。

# 阿尔钦的产权制度研究

说完了阿尔钦研究的方法论，接着来谈他的研究成果。就是产权制度。他可确定产权？简单说，产权是一个社会制定规则的、选择一种产品的使用与用法的权利。可分，产权包含两个基本要素，首先是资源资源用途的排他性，即只要是自己的，不是别人，可以对资源做出相关决。其次，从资源收益的可转移性，你从这个资源收益可全部收益，即可以转卖相关权益，即转让。

理解这三个要素，可以消除很多误解。比如阿尔钦在《假定》里说，1000人的小镇，有剧院。剧院是股份制所有，1000个居民都有份。同时，小镇有一座教堂，属于共同财产，也归这1000人。

你能看出这两种产权的归属，有什么区别吗？表面上看，剧院和教堂都归居民，似乎没区别。但剧院为小私，所以剧院可以买，旧居民不快乐，还可以从剧院的获利获得收益。但教堂不一样，你不能拆了教堂，卖了，或卖了，卖了，卖了。

产权三要素来看，可以看出剧院是私有财产，教堂是公共财产，区别在哪里，居民对于私人财产的关心度，不会超过私人利益。相反，对于公共财产，关心度则会随着人口的增加而减弱。

这个案例看似抽象，却很有现实意义。如果把场景换成农村土地，其争议，也可以看看得比较清晰。在过去，集体土地承包，所以，生产大集体，大家偷懒动力强。农民积极性不高，大锅饭吃得多，产量低。土地承包后，农民积极性高，多劳多得。

# 保护产权就是保护人权

除了张五常，阿尔钦在国内学界也有很多粉丝。我上周我上课，总讨论阿尔钦。他说权利是权利，权利是权利，权利是right，right的意思是正确，所以权利必须是正确的。不过，经济学者的“正确”，可能与普通人大常理解的迥异。

比如，国人对名校很尊重，但名校招生歧视新闻也不少。2018年，哈佛大学就起诉职业歧视。原因是人认为，条件相同时，亚裔学生被录取可能低于其他族裔。

听起来很不公平。种族和歧视，都是敏感的话题。很多人第一反应，加强立法。但想一想，真的有用？从立法来，实施隐性歧视。不用多说，当年保护黑人的立法，也许就是今天亚裔歧视的源头。人在歧视观的问题不止此，甚至，白人里也在抗遭遇逆歧视。

如果立说立不歧视解决歧视问题，什么方法更公平？阿尔钦的思路是绕开歧视，回到产权。今天高度进入产权歧视，与历史上黑人租房遇到的问题极相似。

故事要从种族隔离说起，种族隔离在美国历史上一直存在，二战后才逐渐改变。过去一个黑人妇女想向白人房东租房屋，有可能被拒绝。如果要买房，要办贷款，银行可以完全定贷款，租房房东定房价，黑人妇女也是可以通过增加房租，来获得机会。相反，如果房东对租房有更大定价权，相同地区对租房白人进行管制，那么价格相同或者相差不大时，房东肯定会选择给白人，给黑人。

没学过经济学的人，往往会有一个疑问：富人等强势群体，往往是产权，产权是不是更多保护富人？其实，产权，产权不是保护富人。阿尔钦认为，产权就是一种人的权利，保护产权就是保护人权。二者并不矛盾，而是相辅相成。完善的产权，可以抵御歧视，因为可以给有权力保护人权，穷人等弱势群体。让房东有权决定租户，是穷人自己主动选择，人，房东就是产权的体现。当大学或者房源，拥有完全的定价权，亚裔或者黑人，可以通过价格机制，来赢得机会。

# 正确理解和看待歧视问题

你可能会问，高校既黑人，还是歧视？这也说得通。但歧视在经济学科中有，有些不同。从阿尔钦视角来看，歧视无处不在，竞争就是歧视的同义词。

人们为什么会有歧视？最根本原因，就是资源太少，无法满足所有人的需求。为了节省判断成本，人们往往粗暴地用简单符号来做出判断，比如种族就是典型例子。在大公司工作，就像去餐馆用餐。这是一般人看来，是给人贴标签，是歧视。但反过来，也是给人帮助人们更高效做出决策，有一定的合理性。

真实世界，歧视无处不在。年龄、学历、种族、性别都可构成歧视的理由。不但现实中的歧视，往往是赤裸裸的。而现实中的歧视，可能是静悄悄。呼吁解除歧视当然是政治正确，但未必会有利于效率。经济学家说解决歧视问题要换个角度，就是要理解歧视的代价。

经济学是关乎选择的学科，而有选择必然有歧视。选择了A，其实就歧视了B以外所有人。反对歧视，是有歧视，也是自由。选甲，也就是拒绝了要乙和乙以外所有人的代价。歧视者需自付承担代价。同时也不得不付出高昂的代价，或者说需要付出更高的，前租房房东，就需说存在一种补偿。就是自己房东比歧视者，其代价也是很高。他为了自己的歧视行为，付出的代价是，只能收取比较低的房租。
