# **20 | 赫伯特 · 西蒙：人的理性是有限的吗？**

徐颖 · 经济学大师30讲

**赫伯特**：西蒙：人的理性是….

您好，欢迎来到《徐颖 · 经济学大师30讲》。

这一讲开始，我们进入资本市场这一模块。资本市场本身具备高度不确定性，在这里，资本流行人太多利益和泡沫。所以，这一讲，我想先暂缓一下，去听听对理性的认识。

今天介绍这位学者，很特别。在我们介绍过的经济学家当中，可能是最帅的一位。他就是**赫伯特 · 西蒙**（Herbert A.Simon，1916.6.15-2001.2.9）。经济学家缪德人形容过说，西蒙是见过最有智慧的人。有朋友现场听过西蒙的演讲，说这个人，完全是一个没有学科边界的人。

![](bbox=[0.1, 0.3, 0.65, 0.42])

1916年，西蒙出生在美国威斯康星州的密尔沃基，这里德国移民居多。他的父亲，就是一位德国犹太移民工程师，后来成为专利法的律师。他的母亲，则是一位很有才华的钢琴家。西蒙从小接受了很好的教育。

他的一生，有9个博士头衔，据说有20种不同的学术语言。在学考中，他是唯一获得诺贝尔物理学奖和图灵奖的人。西蒙被收入人工智能史，他的研究领域，横跨了自然科学和社会科学。

他的学术身份，主要是卡内基梅隆大学，计算机科学与管理学教授。可能你会好奇，他都不在经济学化，怎么会得到认可。不少经济学家和媒体都以为，西蒙是经济学家的问题。1978年他获得诺贝尔奖的时候，面对2个中问题，还是问："在经济学最广泛的意义上来说，西蒙首先是一名经济学家。"

# **计量经济学**

西蒙获奖，和战后经济学转变有关系。那就是，越来越数学化。西蒙回忆，在1950年，如果文章偏好只是几个方程式，那么（在《美国经济学评论》这样的顶定期刊上）就很容易发表。但到了1970年，数学已经很难发表在顶刊上。没有个数式公式，往往很难在顶级期刊上发表。可以说，经济学越来越讲计量。

这股风潮背后，离不开一个小组体的推动，那就是计量经济学会。它在1954年，西蒙已是计量经济学会的荣誉会员。西蒙这份荣誉会员资格，会发给他一个神奇的名册。因为，这个名单中的人，和诺贝尔奖有高度位置度，从1969到70年代末，共有27位诺奖获奖人，有20位分获奖，有3位，将来未获奖。换句话说，当时诺贝尔奖有2/3，有布克奖，易朽学，及时诺奖在名单中，不在这个名单上。可以说，出现在这个名单上，差多就是诺奖的保证，更是经济史上，西蒙会就是最早就属于精英经济学家的人物。

不过，尽管背负着计量经济学会的大山，但西蒙并没有因此折服。他晚年，对于西蒙和计量经济学的，提升了很多。他认为很多理论研究，就像在夜里丢了手表的人，不管三七二十一的，只在有光的地方寻找。甚至，明知道手表不在光下，还是认为，至少要这样做才不会有用的。他承认，计量经济学走出了一条科学，总模仿物理学，搞几个方程、一类方程，有事实，以及描述这些事实的结论，这也许更有意义。

# **向理性人发起挑战**

西蒙这话，其实有点针对性。针对的是理性人这个经济学第一假设，在经济学看来，这几乎等同于第一公理。西蒙的话，恰恰是反对有限理性。也就是说，在完全理性和有限理性，中间存在灰色地带。

也许你会说，这听起来不符合常识。**但对于经济学而言，这是一个颠覆性的说法。**我们学过古斯，斯密的理论，在斯密那里，理论还只是日常的朴素观察，只是人们对人性的所作所为的真实描述。这个假设在经济学的发展中，却越来越严格化、抽象化，到了20世纪中叶，主流经济学中，经济学者们承认，人是全理性的，强调人能够掌握一切相关信息，然后做出效用最大化的决策。

这种假设对擅长微数方法的经济学来说，用来解释经济是特别好的。所以经济学者一直往这个方向走。但我面对真实世界时，却往往遇到很多问题。我记得，我去大学给同学上课，说到理性的概念，同学往往最不理解。因为身边的案例，生活中大多是不理性行为，突然，你可以解释，做某件当下不合理的事，你可能是为了预测未来更大回报。其实，就借助了理性预期的思想，勉强自圆其说。
