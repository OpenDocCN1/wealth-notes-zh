# ## “神棍人气”的克鲁格曼

很多人都说，克鲁格曼成功预测了亚洲金融危机，和2008年金融危机。其实，他引过这两次金融危机。1996年，克鲁格曼用了别人文章，指出来所谓的亚洲奇迹根基不牢，迟早会烂掉。不，亚洲金融危机爆发，让他赢得不少掌声。至于美国金融危机，在我看来，有失误和误判。怎么回事呢？美国是民主党，共和共和党轮政，当时执政的小布什属于共和党。克鲁格曼是民主党的坚定支持者。90年代后大力支持克曼克竞选。小布什当了八年总统，他几乎骂了八年。很难说，他真正预测到了2008金融危机。

好，说到克鲁格曼，这样为民主党出力。但，从来没过他的国民经济。凭他资历，本来应该不成问题。之所以能成为总统候选人，据，主要他家人太高。他在华盛顿念了一年，发现自己太缺乏大聪明，进了政治圈。不过，在华盛顿，他学会了一个新问题。那就是怎么用人大家听的话，讲严肃的经济问题。这使他成为美国很著名的公共知识分子。

# ## 规模报酬递增改变国际贸易理论

不过，你老是以为他因为预言金融危机获奖，那就错了。他的学术地位，主要和国际贸易关系有关。你学李嘉图，要知道国际贸易的基础是比较优势。就是大家交换各自优势的商品。按逻辑推，穷国资源很优国一样。按各国都集中生产有优势的商品，那结果是什么？应该是穷国和富国之间的差异变大。难道简简，它们之间的互补性很强嘛。然而，实际情况并不是这样。现实中的贸易，发达国家通过国家、之间更多。比如欧洲一些国家和通过美国，也向美国出口。

这个矛盾，让经济学家很抓狂，不知怎么解释。对此，克鲁格曼很睿智地引进了一个关键概念，那就是规模报酬递增。可别小看这个概念，它对改变国际贸易理论甚至经济学，可以说是革命性的。

以前的贸易理论模型，都在规模报酬不变假设下推演问题。什么叫规模报酬不变呢？就是说，随着生产规模上升，单位成本不变，即每单位成本不变的报酬不变。只有规模效应。在现实经济中，规模是已经有规模效应的。就是说，别开局没有消费，可以，要大规模才，一定程度后，你的优势就只是规模了。比如采购成本可能降低，生产效率可能提高，某个专利技术也有规模效应等。每一资本的成本，也就是随着规模的上升而上升了。这个呢，就叫做规模报酬递增。这对中国人不陌生，在中国，一看现起来不起眼的东西，却可以完全控制全球大部分的某种商品，从打火机到内衣。

这就可以理解，为什么发达国家间贸易更多？因一个国家再先进，也不可能会全部产业。总有地方，不如别人，就是发家的经济体，在全球竞争中最占优。这些产业通常是需要的生产最有竞争力的作为竞争者供货单。这些最有竞争力的合作者或研发者，在哪里呢？很多时，不是在发达国家，而是在发达国家。这样，反而是发达国家，彼此需要的地方更多，相互贸易也更多。甚至同一个产业内，相互贸易量都很大。比如说，2011年日本大地震，全球电子元件供应链都危急。大家可能，日本那多它在日本。在中国，人工制造成本低？6.8美元，只占3.6%。

# ## 相互依存的国际贸易

这就引起一个深刻的洞察：越是发达的国际贸易，越是你中有我，我中有你。越是积极参与国际分工，才能有更多的好处。没有国家在闭关锁国中，炼就强大的产业竞争力。甚至可以说，你越强，就越依赖别人。可以说，弱弱，但这不是必须接受的脆弱。就连美国最强的科技公司苹果，也是设计在美国，制造组装在全球。

让我们换个角度看贸易逆差，你知道，美国人总抱怨中国出口太多，觉得中国占了美国便宜。部分中国人，也觉得我们可以不用看人眼色了。克鲁格曼的理论，让我们看到另一面真相。比如，中国iPhone，组装生产基本在中国进行。那么，美国从中国进口iPhone，要花178.96美元。因此，美国对中国的贸易，似乎赚进了179美元。他光着数，有了解了事实，过一年前，我的朋友青老师，就做过一个很有的发现。即，老师拆解了iPhone的制造与装配，发现涉及多个国家，其中，包括34%的日本产品、13%的德国产品、13%的韩国产品，还有56%的中国产。在中国的人工制造成本是多少？6.8美元，只占3.6%。

这样看，即使是中国公司发明再高科技产品，也不增加美国出口，相反，还会加剧美国贸易赤字。所以，不应该看贸易逆差来反对应知贸易。全球生产贸易，加上高效专业的分工流程。可以说，已经扭转了传统的贸易模式。如今，中国组装出iPhone，而对美国进口自已的成品科技产品，则对这种局面，传统的贸易统计方法，没法正确衡量贸易赤字。

这正是中美贸易不平等的关键。美国抱怨中国出口多，其实不太科学。现代全球贸易网络，跨国公司运作巨大。他们把生产环节分在多个国家。中国的出口顺差大，中国是也，中国的做法，实际上是以国为圆心，整合整个东亚国家东是以类、澳大利亚等能源出口国。中国完成加工生产之后，出口到美国欧洲。中国对美贸易顺差，相对日本、韩国别的国家没有逆差，比如日本、韩国等。整体而言，中国的贸易顺差GDP比例，已下降到微不正常的水平。

从克鲁格曼理论出发，很自然得到一个结论，就是支持自由贸易，所以不少中国经济学家，是反对美利和中国打贸易战。

克鲁格曼这些年，已经不再做什么正经学术。他现在和文化和书，就强于作家的。不过，他文章有点生硬，比较强多。我的同事马丁.沃尔沃夫和他吃饭。克鲁格曼说，他算篇嘛，他算没他写。马丁沃尔夫吃不完不由感叹，在美国，真是太，也可以做成最具事事的类经学家，也可以做成最具事事的作家。
