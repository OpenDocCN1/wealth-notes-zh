# 26 | 萨克斯：休克疗法下中俄转型为何如此不同？

徐琳 · 经济学大师30讲

你好，欢迎来到《徐说·经济学大师30讲》。

模块的主题就是，了解经济学家们，是如何用经济理解中国过去，探寻中国未来的。

你知道，中国改革，是从70年代末期开始，如今经济稳步，自然对于已经经历阳光、空气和水一样自然。但是，短短三四十年前，却完全不是这样。苏联在这个国家，听起来很遥远，但其实是到1990才解体的。比中国和俄罗斯转型，现在中国已经半个全球经济第二，而昔日大哥却陷入各种困境中，比如遭受巨毒，目前，俄罗斯全国GDP总量仅仅和中国广东省相仿。

你可能好奇，都是从计划经济起步，为何结果如此不同。你只能对一种流传很广的说法，如中国走不了，苏联走不了改革，也就是摸着石头过河，而苏联是激进改革，如这条路线，所以效果不好。真是怎么？其实这真有把其中的道理，给简单化。

这一讲，我要向你介绍经济学家与此有关。他就是美国经济学者，杰弗里·萨克斯（Jeffrey Sacks，1954.1.15至今）。他1954年生于美国底特律，一路在美国哈佛大学读到博士。1980年，以助理教授身份加入哈佛大学，3年内就正副教授。当时，他才不到30岁，这个成就一般人来说，很不正常。他不干别的，不舞什么，他志向在于为全世界发声，在1980年代与90年代，他便被叫做“休克疗法之父”。

正是他，向俄罗斯提出了激进的休克疗法。

![](bbox=[0.25, 0.58, 0.75, 0.72])

# 休克疗法

所谓“休克疗法”，来自主医学。听起来像惊骇骇，意思是，当一个国家出现经济、政治不稳定的，资本外逃，汇率下降，通货膨胀，货币贬值的经济危机时，休克疗法就是进行必要的休克。

你可能会说，俄罗斯错就错在，千不该万不该，偏偏选择休克疗法，其实，与其说，俄罗斯选择了休克疗法，不如说休克疗法选择了他们。如果想进一步了解历史，就会知道，80年代，苏联也试图进行改革之道，发现行不通，之后的休克疗法是没有选择的。

苏联的命运转折，发生在1980年代。直到1980年，著名经济学家库兹涅茨，还有别的经典教科书《经济学》中预测，苏联的国民收入，可能2002年超过美国。此前，他的预测是1994年，我们也不能说，预测太差。1994年。我的预测，也是根据苏联过去一直追赶的美国态势作出的。

萨姆森预言未曾，苏联经济开始走下坡路。1980年起，1985年，后任大书记在2%左右。当时，苏联最后一任总书记戈尔巴乔夫，曾想在计划经济框架之内进行改革，实行新式经济改革，提供经济。这就是“计划的市场化”。结果，情况就不太顺。他本人也面临着苏联体制下的巨大困境。1991年8月，他的俄罗斯总统叶利钦，发动了。上任不久的苏联，是苏联经济停滞、经济倒退、物资短缺、通胀、经济衰退、1991年GDP下降13%，让一片灰心死海中的民众，也渴望更彻底的改革。
