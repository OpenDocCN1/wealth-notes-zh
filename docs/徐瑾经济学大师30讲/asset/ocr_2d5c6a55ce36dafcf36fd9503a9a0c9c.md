# 17 | 哈耶克：贯穿现代经济学史的大辩论

徐翔 | 经济学大师30讲

![](bbox=[0.05, 0.1, 0.95, 0.13])

你好，欢迎来到《徐翔·经济学大师30讲》。

这一模块是宏观经济学模块。我们已经学过斯密斯密。他是一个人，就颠覆了古典经济学，开创了宏观经济学。当然，古典经济学也不会甘心退出历史。自然有人捍卫了。其中一位，几乎靠与凯恩斯辩论，赢得大师伯地位。那就是我们今天耍到讲的哈耶克（Friedrich August von Hayek, 1899.5.8– 1992.3.23）。

哈耶克1899年出生在维也纳，1974年获得诺贝尔经济学奖。奥地利学派的大师米塞斯的最后学生。哈耶克的背景可以追溯到二战前后的奥地利。两人都是在维也纳接受教育，到奥匈帝国（简称）中，因为他们都成了反共者。最后，两人在英美界成名。

哈耶克是犹太人。年少时，他就目睹了法西斯的兴亡与覆灭。但是，当奥匈帝国解体后，原本保守的维也纳，保护了犹太哈耶克，就变得毫无保护。1913年，他的外祖父发起了社会主义试验，导致产量剧减，米价物价上涨70倍。哈耶克家族深受影响，甚至没让他进德国国防大学。1938年，纳粹吞并奥地利。同年，哈耶克加入英国籍。

这些经历，使他对计划经济思想，终生抵恶。1947年，他发起一个新自由主义学术共同体，也就是后来大名鼎鼎的朝圣山学派。知名学者波普尔、米塞斯、奈特、弗里德曼等，都是学派成员。

私下里，哈耶克个性温和。但一涉及到历史上，他给自己的方式坚持。在经济学史上，他给人三大印象。一是好辩。三十年里场重要的经济学争辩，他可参加了几十。第一，二是他反对凯恩斯主义。第二，三是他和凯恩斯关于经济的大辩论。

# 与凯恩斯的论战

哈耶克一辈子，最大论战对手是凯恩斯。1931年，伦敦经济学期刊刊登凯恩斯、肯后的俱乐部，就是作为对哈耶克的枪手。他1992年去世前，最大遗憾，就未与哈耶克清算凯恩斯主义。从身材来看，哈耶克和凯恩斯都是高个儿。超过几米8，哈耶克比凯恩斯年轻16岁。但他看起来，比对方大。一子都给人，中欧知识分子的印象。总是神情忧郁，搭配红西装，说英语，也有伦敦那一带浓厚的口音。

两人争论很著名，似误解也不少。表面争论的是经济。往深里看，其实是文明胜负的问题。

争论背景是大萧条时期。经济危机导致失业率高达40%。各国采取的应对方案不同。苏联和纳粹德国都是新计划经济，依靠计划模式，将国家军为一级军事机器。这导致了当国家一时短期，经济的张了大天平，向这些国家倾斜。而当时主张自由的美英世界，反而是显得有些力不从心。

于是，凯恩斯出现了。你已知道，他主张扩大投资。的出发点是反对意见。他认为大萧条的根源在于政府为计。为什么？哈耶克指出，政府和中央银行联合，是一个具体的个人在制定政策，他们这些人当中，过去太想往经济决策，破坏了人们自发的市场秩序，经济。结果呢，一时间的人流繁荣，让市有人认出了。这样人为的繁荣中，资源存在很多错配。最终，导经济危机。在第一步，政府已经得。如果危机危机，政府再次介入，更加火上浇油。因此，必然反制夺人们的经济自由。

这场辩论为什么那么受关注？因为战争。两大世界大战成了世界，也待人们重新思考，甚至重新评估不同制度的问题。这三十代人的斗争，影响了政儿人的历史。二战后的历史，经济学史上，最著名的经济学学术，辩证的结束，不意味着分出胜负。像两人观点，后人形成了各自的阵营。使得这两人的辩论，几乎贯穿了整个现代经济学史。

# 《通往奴役之路》

一般认为，他们两个人的辩论，宏观上对哈耶克更不利。因为凯恩斯主义，哈耶克显然是赔钱方。但实际上，通过这场辩论，凯恩斯也收获不少。从辩论中，他汲取了大量的战斗，产生了理论创新的欲望。

你知道，凯恩斯宏观经济学鼻祖的地位，主要凭借1936年出版的《通论》。《通论》引发学界内外部讨论，引发凯恩斯论著者。我起来说，全书没有直接提哈耶克。但实际上，不少地方的解释和说明，都是针对哈耶克的批评。我常学书翻，他的《通论》，做了不少学术翻，他认为，与哈耶克的论战，是凯恩斯写《通论》最重要的推动力。

《通论》的巨大成功，显得哈耶克有点落寞。30年过去了，大家完全忘记了他的赢。一些得意门生，也依附凯恩斯。比如经济学家卡多夫和弗格森。

但是，哈耶克并没有闲着。在寂寞中他埋头工作。到四十年代，哈耶克完成自的重要著作《通往奴役之路》。其中，他对大政府主义开了一剂药丸。他得出，当政府对公共利益扩张了，到公共公民的自由时，人类奴役阶级也必然不远了。

这本书改变了世界，也改变了他的命运。书畅销，对他的在气也经济不断。更多的入门。不过，他说出来不想，就为了大销，也让他遭遇很多非议。很多学者觉得，专业的学者不写这样的畅销书。

无论怎么说，两人交锋的结果，是各自发展不同的理论体系。这给世界留下了了大遗产。两人虽是理论对手，私下里却不结。两人在观念，哈耶克也不是偏执和顽固。凯恩斯读《通往奴役之路》后，写信给哈耶克。说他的大战，只是在中道路的下界性问题上，有人太低估了中间路线的可行性。

# 哈耶克与凯恩斯辩论的影响

凯恩斯所定的中间道路，真的存在吗？这是永恒的问题。其实，我认为应该存在。当经济正常运行时，政府不应过度介入经济，最大幅度地保护市场的经济自由。当经济出现危机时，必须的手段是重要。多年来，政府对经济态度都是摇摆不定。当危机来临，往往主动凯恩斯。一旦经济平好，哈耶克又占上风。

两人的分歧，本质上是世界观的分歧。凯恩斯，是一个实用主义者。对于意识形态和政治理论，他基本没太追求。很自然地，面对困择时，他会主张两边应该试错，探起经济。哈耶克则是一个怀疑论者。他有清醒的悲观态度，把理念看作不可动摇的信念。比如凯恩斯说“长期来看，我们都亡，哈耶克就批评道，这句话的命语，会遇到洪水滔天那一刻，并终将自食其果。

英国思想家柏拉图，将学分为狐狸学派与刺猬学派。刺猬学者，狐狸学者几乎无所不知，刺猬学者则只钻研某一领域。从这个角度看，哈耶克类似刺猬学者，一生做的一件事，就是捍卫自由市场。

哈耶克早年书，比如《货币理论和商业循环》《价格与生产》等，关注是从价格与货币周期等纯学术角度，往往是批判的。从《通往奴役之路》后，他的兴趣开始转移《自由与秩序》《致命的自负》等著作，他的视野，已经从经济学转向了政治哲学和经济学。所以，可以自然谈学政治、哲学。市场的必要，以自由秩序观念，去论证市场的可能。你看，从青年到晚年，横跨几十个学科和不同角度，哈耶克始终在做的是，总若作的核心，始终是捍卫自由市场。

在大陆，哈耶克更多地被当作经济学家。在台湾，他更多地被当作政治学家。他都自由门徒。无论是经济学还是政治学，他都得心应手。凯恩斯则更像狐狸型学者，兴趣总是在变化，他的名言是：当事实改变，观点也随然随之改变。
