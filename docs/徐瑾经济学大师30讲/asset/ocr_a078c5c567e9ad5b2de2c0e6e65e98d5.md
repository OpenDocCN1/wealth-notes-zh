# 04 | 熊彼特：创造性破坏理论对中国制造的启示

徐瑾 · 经济学大师30讲

你好，欢迎来到《徐瑾·经济学大师30讲》。

> 我在之前几讲，和你一起重新认识的几位经济学家，代表了古典经济学在十九世纪的巅峰。从一开始对大卫·李嘉分仿们的经济学家，主要活动在中二十世纪初。今天我们来到维也纳，聊聊经济学家熊彼特。

熊彼特有贵族身份，一生都带着老派风气。据说他见到女士，都会先做脱帽致敬。然后亲吻女士。从小，他给自己定了三大目标：成为维也纳最完美的情人，欧洲最出色的骑手，世界最顶尖的经济学家。从结果来看，起码实现了最后两个。

28岁，熊彼特成为奥地利最年轻的正教授，36岁成为财政部长。而他人到中年后，运气持续走低。 22，他的学生凯恩斯。 最后他在英国休养，1950年在耶去逝。在哈佛，他培养了伊罗诺森这样的学生，也助德国圆满。

# 观念试验场里走出的创新理论

熊彼特的贡献，主要是创新理论。提到创新，你可别觉得比较前卫，怎么能和一百年前扯上关系！这么说，当时是维也纳，很神奇，本身就是观念的大试验场。

维也纳是奥匈帝国首都，犹太人很活跃。又受德语影响，诞生很多大师。奥地利学派话语权不说，其领域有。比如心理学家弗洛伊德、物理学家萨克斯、哲学家维根斯坦、作家卡夫卡。

熊彼特的老师是庞巴维克，他是属于奥地利经济学派。但熊彼特学成后自成一派，他一次都创新这个概念引入了经济学。之前古典经济学家，满脑都是什么价值、地租、利润、工资这样的名词。以前的经济学家，都是想法像出一整套静态的，再去描述传统想法。但是，熊彼特就出了这个静态的视角。

这一洞悉，离不开时代刺激。当时，国际局面正面新旧刺激。我们知道，"日征"出版后，第一产业革命爆发，特征是蒸汽机运用。英国搞得最猛，1851年举办世界工厂。第二次工业革命，是从十九世纪后期开始，特征是电气运用。这让德国国家化，化工电力卷起超越英国。当时英国学生，转去德国学数。

年轻时，熊彼特去过英国游学，目睹大国竞争。他意识到，通过创新，后来者可能会弯道超车，先行者可能落后。创新的本质，就是创造性破坏。

这洞悉，现在不过时。比如iPhone刚诞生时，主流并不看好。流行还是诺基亚之类手机，强调通话更清晰，信号更强大等功能。

但有人看好iPhone，当时我在上海一位德管理教授。一手拿着iPhone，一边和我说，这是手机，而是电脑。我心想，把手机设计成电脑，这是啥？事实证明，iPhone成功正在于此。

> 苹果，直接重新定义了手机。iPhone不仅是模型机，而且是件商品，人人都想要。同时，开创了一个智能手机的新行业，顺便还摧毁了传统手机行业。原有巨头凋零，诺基亚破产，爱立信退出。

有点类似小说《三体》的黑暗原则，摧毁你，与你无关。熊彼特很早就领悟这点。创新，必然是创造性中破坏，在破坏中创造。

你可能会问，为什么诺基亚不能设计出iPhone？还创新，技术不是核心。关键，你还没有创新理解。

创新，分为延缓性创新和破坏性创新。一般人理解的创新，往往是前者。就像成企业啊，意味着专注核心客户和市场布局。所以，让破坏性创新做得不错，破坏性创新得看做。恰恰没有破坏性创新，有行业创新。曾经在诺基亚，是十多年行业领先。躺着赚钱的诺基亚，注定更多关注诺基亚旧模式。智能手机颠覆，会全力推广。很相似的逻辑是，下一代手机颠覆者，很可能不会来自苹果。

破坏性创新一旦成功，淘汰系统也自动启动，以传统生产被淘汰经济过程，新都被摧毁。汽车淘汰马车，打火机淘汰火柴，智能手机淘汰老式手机。旧行业也许整体消失，企业倒闭，工人失业，贷款违约。

这是创新的黑暗面，可能让人觉得可怕。那，为什么还要提倡创新呢？这是因为，虽然具体公司和经济一，一旦被覆写，确实很大，但从整个经济层面看，有一样的高度。

你想，原本一潭死水的经济，通过创新，进入了动态系统。和自然界一样，经济也有内生机制。淘汰旧的同时，新的正在诞生。行业的生死存，推动经济不断更替。这是一边破坏一边追赶的系统，成为繁荣最动力。创新，就像市场经济的基因，创造了经济的竞争力和多样性。市场经济的本质，不是贪婪，而是创新。

# 中国的创新故事

创新有很多态。今天流行从0到1，好像从无到才有创新。其实少创新，只是元素和系统组合。熊彼特认为，将生产要素的新组合，投入生产体系，也能实现创新。

比如“扫一扫”功能，大家付款、购物、点餐都方便。每天数十亿笔使用，几乎创新。而是，每个都是中文。这项功能被发明出来，可，是两项技术并不分创新。在1994可发明，而身份识别技术，二战后期就有了。中国人身结合，放在场景里。其实就是创新，也获得巨大市场。

新组合，不仅体现在小创新，还体现在大创新。这些年，总有人对中国制造很低估，常是全面否定。这种认识听起来很对，但是不够全面。

对照熊彼特理论，我们可以着不同的局面。中国制造的历史过程，就是一个新的创新故事。开放之初，中国技术水平和低。很多技术别人早有了，怎么办？引入呀，无论适合还是进口。有了技术，再跟中国特有土地、人力两个结合。从此，释放了巨大能量。这个过程中，生产技术与经济流程，实现了改造。中国创造，也实现了产业群升级换代。从制造到世界前沿。就是这么，只要创新过程没完，中国制造还蕴含创意。

经济发展是什么？熊彼特认为就是创新的经。因此，尽可能从国外引和学习先进，技术，没人去大。无论中国还是本，都走这样路。大家过去国基大，但更正确说，这就是创新，甚至是很牛的创新。

# 创新、发明家与企业

此前的经济学，基本都是静态经济。只解释需求，看不到资本主义的静态本局。那是，永不停发现变成更。这过程中，新技术、新流程、源泉不断地产生。按照，经济的比率看，就不断分。熊彼特说，马克思的观点，就从他那里吸声，从见过的庞大生产力。如同一马般奔腾。

谁在驾驭这些奔马呢？是企业。生产要素聚集者。很平凡，需要这一类。能在各种组合里，出决。

你可能会问，创新往往是发明，企业不是也是发明家吗？不是。熊彼特发明，企业家必须发现明显分开。发明是事，而使发明的又是另一回事。这是两个完全不同的任务，需要不同才能。

比如有人发现iPhone有十二核心新技术，这不是技术，发明者居然多数是美国政府。但是，中没有创新？当然有。而是，层次高的创新。新然的技术，加组织，获得市场动力。这恰是企业家解释的个新体现。这样一来，我们需要重新生这伟大的。不仅仅是发明了电动灯。他的成功，在于他把电动这样的发现，得广泛用。

创新，需要快时一步。这意味，创新思想得很承认，反而可能更。从出新理论和角，熊彼特自己就是个创新者。
