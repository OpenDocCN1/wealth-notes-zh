目前我们的课程，是在资本市场模块，前面我讲过金融危机。无论大萧条，还是2008年金融危机，好像都是国外的。中国几十年，好像从来没有爆发过金融危机。可不可能，这不是因为中国特别啊。真不靠谱。话头是经济金融，就会金融危机。历史上，中国也几次经济金融危机，比如80年代的物价闯关，90年代的亚洲金融危机。这些年，中国离金融危机最近的一次，就是2013年的“钱荒”。

钱荒，就是市场上的钱不够了。你还记得吗，2013年6月，商业银行间，市场资金融资紧张。甚至大银行都缺钱，隔夜利率最高涨到13.44%。平时一般在2%。上证指数也暴跌。那时，四处纠结各种报道。一些专业或跟经济无关的新闻、朋友都在问我，“金融发金融危机吗？”当普通人都这样时，可见问题已经够严重了。过了几年，我和朋友们聊起，还是胆心惊心。一不小心，就可能会演变为更严重的后果。

当商业银行陷入危机时，谁来救，如何救？这就是我们今天谈论的内容。我会给大家介绍两位学者。沃尔特·白芝浩 (Walter Bagehot, 1826.2.3-1877.3.24) 和佩里·梅林 (Perry Mehrling, 1959.8.4)。白芝浩出生于1826年英国，梅林生于1959年美国，那么我要把他们俩放在一起说呢？这是因为当年白芝浩提出了一个原则，也就是白芝浩原则。一百多年前后，这个理论，又被梅林进一步完善。

# 白芝浩原则

先说白芝浩，他是《经济学人》杂志的总编辑，是十九世纪公认最伟大的财经编辑。今天的我们，就纪念他革命名的白芝浩原则。白芝浩指出，在金融危机时，因为信贷危机，市场血流流动干固结。各商业银行间尤其小型银行，就缺乏现金救援。这时，市场央行就必须向商业银行放贷，为金融危急。商业银行要偿付从中央银行的贷款。只有这样，才能避免从一场流动性紧缩，发展为普遍的金融危机。

你可能会问，商业银行们贪婪，就下必命赚钱，难道就救他们？就算救央行必须救他们，救不救没有入深水援呢？这难道道德风险，其实白芝浩早已想到了。中央银行对商业银行的贷款，就是利率高。和央行一样，要罚以听财不是高用钱的贷款人。并且，让犯错的商业银行受到惩罚。

可见，当市场的流动性受到冲击，也就是钱荒时。中央银行一定要出手救市。作用呢，就是保证信贷不会出现断流。这个角色，就叫最后贷款人，也就是，银行在紧急时刻，可以最后去求救的角色。

![](bbox=[0.15, 0.64, 0.85, 0.73])

白芝浩原则，可不是天才的灵机一动。这背后，是英国现代危机的总结。正是这些原则，促成了现代危机的诞生而生。早在1682年，英国就有了钱荒。经济学家戴维就警告说，必须避免贷款货物的缺乏。他自己回答，必须建立一家银行。不过，一家普通的银行不够，需要一家能够作为为商业银行的银行才可以，随后，英格兰银行诞生了。这可是全球中央银行的先驱。

中央银行是什么的？就在流动性紧张时，注人流动性，可以流动性旺盛时，收紧流动性。当然，在流入金融危急的版本，解决问题，别看哈格特凯恩斯吵来吵去，这两人高得有一点点共鸣，传统理论是信贷经济。信贷经济，意味着没有边，货币，而且很麻烦。所以，凡是现代版，我读一本书《金钞夺宝》，就谈是央行银行和金融危机的。科学家一百种灾害之中，我表现看，金融危机是一种“富贵病”。或者说“现代病”。一个国家，只要建立了现代金融体制，就会有出现此类国家。历史上，金融体系最先蔓延出英国国家，先是美国，随后是拉丁美洲、亚洲等国家。

# 央行正名

一说央行，有的阴谋论者，就会拿美联储说事，其中，当然有阴谋，没有阴谋，美联储规模，是英格兰银行。历史上的多数时间，它确实是一家私人银行，但上面英国央行入银行这一属性，指责它有问题，那有多少见多怪了？

为什么这些中央银行会是私人机构？原因很简单，私人银行最熟悉当地人市场，还不如需要需要央行。当金融市场动荡，需要最后说资人时，在没有央行的情况下，最大私人银行，不得不承担职能了。于是，英格兰银行这样的私人机构，开始承担起央行的作用。因为它规模最大，众望所归，你不出头，没人为你，而它发展为正式央行，是后来的事。

从历史来看，英格兰银行成为央行，其实不情不愿。为什么呢？成为央行，意味着危机时，需要提供流动性。但危机时，英格兰银行自身也是面临压力。而且，出手救助别的银行，就是在帮助竞争对手啊。但是，不帮，也不行。银行挤兑，最终结果是传染性。一家银行出问题，往往社会蔓延到另一家银行。像一个多米诺一掉，银行之问，彼此可是一个网络。对最早出现流动性紧张的银行，如果家有一家放大，跳出来去救助。往往后看，帮自己的对手，最终其实是帮助自己。这个道理，英格兰银行一开始也不明白。在历史上，经多次银行挤兑后，它才逐渐意识到，提供更多最后贷款人的义务，对自身和市场都有好处。

在那个时代，白芝浩可以说是最睿智的观察家。他研究了英格兰银行处理金融危机的教训，把观察的结果写成了一本叫《伦巴底的街》的小册子，其中对于货币与银行的论述，在今天读来还挺有趣。

白芝浩原则，放在今天依然有效。2008年，美联储出面救市，正是体现了这一原则。再看2013年，中国央行没有出击手，可能是轻经验论。没经历。就像2008时，美国股市也有很多批评。但是，央行如果考虑“最后贷款人”的定位，就应该及时出手，只是央行的分内工作，从钱荒，我们发现央行也学习了很多，现在出手救市都比及时，市场中的人也开玩笑地管央行叫“央妈”。

# 梅林完善了白芝浩理论

白芝浩原来，一开始也被认为是异类，后来逐渐成为，成为现代央行应对金融危机，标准。如今，变化，在中央制度，跨越信用货币制度，所以，中央银行的规则需要更新，这需要摩尔比这一讲的第二位主要，梅林。他是演讲巴比尼波，曾经来这十场多次，非常绅士的一位学者，他的贡献，就是发展完善了白芝浩理论。

为什么要在新。因为，经济体制在起变化，金融危机也在进化。历史上的金融危机，更多以钱荒形式爆发，现代社会的金融危机，级多是那高人高，可以从传统，是纸的升极。这是央行就都必须学习新技术
