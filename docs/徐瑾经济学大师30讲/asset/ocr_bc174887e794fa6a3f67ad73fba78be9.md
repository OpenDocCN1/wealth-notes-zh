# 民主与独裁共存的比利时国王

民主和独裁，谁好谁坏？你第一反应，当
然民主更好。中国多年流行过一篇文
章，叫民主未必好还是。从经济学角度
衡量，答案未必如此。上一讲，你了解
了选举悖论，今天换个角度，从权力结构
切入，你会发现，民主其实未必多好，独
裁未必多坏。两者其实是不同的权力安
排，甚至，你可以理解成，一种方便的标
签。

如果你时空穿越者，回到十九世纪初，
欧洲的比利时，你会看到什么？你可能会
觉得，天哪，这个国家简直是天堂。经济
欣欣向荣，正快速走向现代化道路。

在短短几年之内，就从个专制国家变为
民主国家。当时比利时成年男子，都有选
举权，工人可以罢工，更不用说，选
举工作，保护环境啊。比利时的出现时间，
比起美国都提前几十年。

如果你穿越回去的地方，是非洲刚果。那
么，对于你中的用户群体可能很糟糕。
这里简直是地狱。对于本地文化行业
的侵略贸易，当地状态，就是尽量压榨。
最多人地，是处在奴隶一样的生存状态
中，需要被沉重的税率，甚至随时随地
都要被随意剥夺、砍断等危险生存的情
况。刚果民主邦建立时，只有2500万人。
后来只剩下不到1000万人。经济状况可想
而知，一塌糊涂。

这两个国家，一个天堂，一个地狱。但你
能想象吗？这两个国家背后的统治者，居
然是同一个人。那就是比利时的利奥波德
德二世。你可能说，殖民者确实没有人性
了？但不否认，比利时的确是实业主时代
制政。耐人寻味的问题是，同一个人，
几乎在不同时间，不同地方，为什么会
出现截然不同的局面？

你学过制度经济学，也学过激励兼容理
论，还学过公共选择理论。那么，你应该
明白，利奥波德二世也有自己的算盘。我
们对利奥波德德二世的政治行为，试着进
行公检，你看，面对不同的制度，他采取
了不同的应对，这就造就了利奥波德德二
世，同时扮演了魔鬼和天使的角色。

# 标题

不过，这一讲，我要给你提供一个新维
度，超越民主和独裁的分类，去看统治的
内核。按照梅斯塔蒂等研究，决定政治
是好是坏，关键是什么？民主制度不是重
点，选民也不重要。重要的是，作为统治
者，满足对你来说不可或缺的人，也就是
致胜联盟。

在《独裁者手册》中作者把国民分为三
类：

第一类，是名义上的支持者。比如，很多
黑人支持奥巴马当美国总统。这是一个很
抽象的支持者人群。

第二类，有影响的实际支持者。比如，
某个候选上台助跑的两人。

但是更重要的是第三类，这是最关键的一
类，书中把他们叫“致胜联盟”。顾名思
义，就是最核心的支持老。对于一统治
者而言，怎么样能收到支持最大？原则
很简单，控制的利益越多越好。但是不利
这控制的人要越少越好。这是个简单的
除法算式。所以，那些最核心的支持者越
少，也是“致胜联盟”越小，对领导人越
划算。至于“前面多个人呢？要么表示不
要，要么干扰可以被忽略，所以无所谓。

回到利奥波德二世。在比利时，致胜联
盟比较大。所以他不得不讨好成百胜的
女儿子民来。而在刚果，致胜联盟就少，维持暴力统治即可。这就是为什么同一
个人，同时成为魔鬼和天使。
