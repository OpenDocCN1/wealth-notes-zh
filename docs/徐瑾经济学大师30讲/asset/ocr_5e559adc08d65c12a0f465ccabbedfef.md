# 机制设计是为了让人说真话

随着大数据时代来临，引人抱怨信息杀手。这篇首先带用户和搜素引擎之间博弈，然后通过有限的信息让用户消费更多。这背后与我们今天讲的机制设计，大有关系。

我们所在的世界，是一个信息不完全是社会。所以，如何用机制最小的信息，达到最优结果，是成功的关键。所以机制设计，就是信息不完全是情况下，如何设定一套对应的规则，来达到特定目标。比如，如何让人说真话。

有个关于古代波斯君所门的故事。故事说，有两个女人争夺一个孩子，而所罗门这里，请你判决，两人都声称孩子是自己的。各自不服，但没有证据的孩子。所罗门就说，既然如此，为了公正，那把孩子劈成两半，一人一半，听听这，一个女人才会同意，说大干吧，另一个女人却说，把孩子要不了，这时，所罗门就对女人的母亲说，孩子归你。为什么，因为只有真母亲，才宁愿不要孩子，也不要孩子。

故事很奇特，但如果换成机制设计的思路来说，故事的本意，为了考量真实孩子的亲生母亲。前提假设，亲生母亲必中排在第一位的要求，永远愿意与孩子分离着。那么所罗门提出“把孩子劈成两半”，来检测出谁才是孩子亲生母亲的策略，才能达到目标。

你可能会说，假母有点笨。她如果猜到所罗门的意图，也假装不要孩子，那怎么办？确实，于事于势，人们往往不会当做正当行为。这样，真假一方的了自抬身价，都不愿意真实出价，而价格就可以随意操纵，这不公平。在更多的场合都可以使用，正是体现了机制设计思路。

# 激励相容原理与显示性原理

什么是机制设计理论？简单来说，如何让在个体行为中，透露真实信息，并由此得到其期待的结局。最早理论框架，来自我们刚刚提到的赫维茨，他只是激励设计理论的奠基人物，解决了两个重要的两个问题：激励相容原理与显示性原理。
