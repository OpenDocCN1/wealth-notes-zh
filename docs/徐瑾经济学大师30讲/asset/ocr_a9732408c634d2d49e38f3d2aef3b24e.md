# 交易成本让问题回归现实世界

这门《经济学思维》，我最想跟你交流的是，为什么科斯会提出这么一个思想，这和一场争论有关。1930年代，计划经济兴起，苏联模式吸引了世界关注。苏联第二个国家，如何成一个理想的大工厂？一切都集中在计划，生产者从数消费者有多少，都得靠清楚。一切看起来井井有条，更科学，更自然的，这种模式赢得不少经济学家支持。主要巴黎行为学，哈耶克，奥地利学派经济学家和的米塞斯，哈耶克，站在了反对方。他们的理主要论点是，价格体系应该由市场决定。

这场争论要没，其实就是市场经济一说论谁更有效，在当时，也没能完全说服谁，科斯，当时还是只是个二十岁出头的年轻人，他是哈耶克粉丝。

但是，一些问题还是没有办法，按照当时主流经济学家的想法，有答案能有效地配置资源。多数经济学家，都是接受这个大前提，科斯的个性在他就发挥了作用，他没有入云众，而是在这里出一个关键问题。

> 在市场掌握一切的世界中，按逻辑不需要计划，也不需企业家。那么就有一个矛盾，企业为什么存在？

他的启发，来自一次美国之行，在那里，他考察了通用汽车公司，通用这样的大企业，明显没有计价色彩，在西方发展也不差，既然如此，为什么墨西哥，不能有一个苏联式的大型工厂来运行呢？

如同《皇帝的新装》中那个诚实的小孩，科科斯勇于现实各种各样的事，他没有其他人看到，装着看不见，他诚实地思考，也找到了理论答案，既然企业在现实中存在，那么无成本的世界这种设想，自然不存在，所以，只要是现实世界，必然存在交易成本。

交易成本的存在与否，其实就是理想世界和现实世界的区别。在科斯之前的经济学家，是怎么看世界的呢，他们认为世界中正常的经济体系，自行运转，没有任何的摩擦力。这种情况，市场中，每一个人的都能以无成本去完成交易。与此同时，通过分工，市场交易机制，把交易衔接起来，完美达到所谓“市场经济”状态。

你可能听说过瓦尔拉斯出清，或者阿罗德布鲁格等概念，这个世界假设一个不存在摩擦力摩擦力的物理世界，并不真实，但没人敢指出来，只到了科斯这里，才让我们从完美的假定中走出，回归现实世界。

# 交易成本视角下的中国发展

所谓交易成本，也就是为了达成一笔交易，我们前后后的付出，听起来比较抽象，你就想一想，你如何买一门线上的课程，下单软件，到付款到开评的等等，这些各个环节，再好的服务，也都在偏要空间，就拿订环来说吧，现在已经很方便，多数程度上付款就好了，不过，可能还会是支付问题，软件下不了，网络连接不好，支持问题，等等，你再想一想，网上银行的流程，其实这些前才有的事，此前，网上买课，难理解。

可见，就是买一门线上课程这么简单交易，都涉及各种成本，这就是，真实世界该有的样子，交易成本这一理论伟大，也造就了它。它的新经济学的壮大，把经济学场景回到了现实。回市场体系和市场。通过科斯的视角，答案会比较简单，中央计划和市场经济，单纯地说，好谁，没有多大意义，计划和计划和市场，其实是不相同的形式。谁有效率，关键看谁的交换成本更低。

结合交易成本概念，我们更好理解中国的改革之前，其实就是一个巨型大公司，工，粮食统一分配，价格统一裁定。那么，大规模，其管理费用非常高，信息无法传递，劳动积极性无法维持。最后甚至基层无法调动解决。不少人是交成本这一，计划经济之所以低效，就是因为它成太高，在实施过程中，少还是优于市场经济中的交易成本。

理论上，计划经济看起来很像效。但实行起来，客观说有效，就可说收入想象了，家族消费都是分散的，收集整理和汇总信息，本身就需要成本，苏联国家计划委员会，数据最多要有几百万个计划指标，分门别类，非常细致，但这些信息收集后，汇总分在备处，也需要成本，而现实交易的信息，还随时可变，掌握完全经济信息，几乎是不可能任务。更不用提，找到和监督组织人平于事，流于形式。所以有个笑话说，当时苏联散发工资给工人，工人假装在干活。

中国当年的改革，同样符合科斯理解释。80年代，中国逐步放开价格控制到统一计划，于是，资源让市场部分支配。过去四十年经济改革，其实是两步。首先是从计划到市场，其次是不断减低市场交易成本，交易成本低了价格，让市场可以不断扩张，资源配置效率也不断得到提升。

说起交易成本，我参加过一个著名经济学的讨论会，他的评说，交易成本概念在国内外广泛运用，什么人成了，就说交易成本下浮，什么没说清就一个成本低，有没有道理，也都没说了一个太本，那便是交易成本这个概念，确定无大，可以很泛运用，今天，我门审视交易成本这个概念，为我们提供了清晰答案，不如我们一种全新的提问方式，它迫使我们真正现实世界，追寻背后的原理世界。

交易成本这一概念，如同X光机，很多问题，躲在它的照射下，核心就变得非常立体，从此，人也看到了更清晰的回答。如果新斯的《看见》有关，他回答了一个关键问题，那就是，市场经济为什么有力，那么，科斯的交易成本，则回答了另一个关键问题，现实世界是复杂，现实种种摩擦，恰恰提供了可以改进空间，面对“一个最不完美的状态，我们都要可以，交易成本，为什么呢？这些交易成本如何导致不完美？借此，可以开始对真实问题的研究与改进。新制度经济学之所以被开出来，新的地方就是在这里。

你看，这些所有优秀思想的特点，他们不是空穴来风提出一套新观点，他们身上都有两个特点，第一，跳出原来的框架，找解释问题的新角度，第二，回应现实，对时代性的问题给出独特的回答。
