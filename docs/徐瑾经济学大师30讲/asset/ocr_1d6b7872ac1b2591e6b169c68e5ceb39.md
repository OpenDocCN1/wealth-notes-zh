# 蒙代尔不可能三角

蒙代尔获奖，主要原因就是是蒙代尔-弗莱明模型。一旦提模型，你就知道很难了。我们通俗的解释一下。蒙代尔大家一个结论。他发现了若干总结的才华，将这一理论模型简化成一个不可能三角：即固定，货币政策独立性、资本自由流动与汇率稳定。这三个政策目标，不可能同时达到，最多只能达到两个。

比如，一个国家，要想保持货币政策独立与汇率稳定，那么，就必须牺牲资本自由流动。为什么。假使一个国家正面临衰退的危机，而面对美联储加息了。显然，这个国家不能跟随加息，这时，这个国家与美联储的利差就会扩大，货币必然有贬值的压力。这个国家唯一的选择，只能是实施资本管制，来维持汇率稳定，保持不跟随美联储加息的独立性。

这可不是假设，是对现实的总结，是亚洲金融危机的血淋淋教训。当年亚洲不少国家，可吃够了苦头。有的国家的汇率甚至崩盘，到现在还没有完全恢复。不过，你可以问：‘蒙代尔不可能三角’只能干坏事？如果理解得当，其实蛮有用。

你知道，中国挺过了亚洲金融危机。但具体怎么做？你的时了亚洲金融危机较高。这时，中国就没法说也，内有通货紧缩，显然，没法跟美联储加息。这时，中国出现很多资金外流。可以说，情况很紧急。

怎么办？按照不可能三角，就有两个选项，要么人民币贬值，要么资本管制。贬值，对稳定中国和中亚洲都有好处。所以，中国选择了资本管制，同时，还进行了宽松的财政政策。我本科时期余永定老师聊。他常认为，中国危机政策很成功。原因也，就是要基于他在理解‘蒙代尔不可能三角’基础上。当时，泰国这些国家，在光外汇储备下说法，汇率还是大幅贬值。比下，中国就幸运得多。

# 美元霸权

有意思的是，当前几乎没有一个国家，可以不受制于‘蒙代尔不可能三角’。那就是美国。因为，很多人抱怨美国的货币霸权。新人民币说，简单说来，就是美元是国际货币，目前国际贸易结算中超过七成使用美元，在各国外汇储备中占比也多是美元。这样，美国可以具有少一些额外权力。比如，可以实施金融惩罚，例如冻结一些国家在境外的存款。这种权力公平也不公不公平，没有，不公平，看美国如何使它。

国际货币体系，是围绕国际贸易结算的一系列安排。你想，不同国家要做生意，自然要用货币，用同一货币，可以节约交易成本，省去货币互换汇率波动等等麻烦。但是每个国家都有自己的货币，国际货币该用哪一个呢？这，归根到底是依靠国家实力与国际认可。

举个不大‘太阳系’的比喻。说经济体实力有平，所以，在国际货币中，地位不同。不同国家货币，具有不同的能量，货币能量与该国GDP有关。这样，美元的地位就不言而明了。到目前为止，美国经济仍是世界第一，占全球GDP份额不多于24%，比排名第二的中国高50%多。所以呢，今天的美元还是货币，其它国家的货币，是围绕美元的‘行星’。

但你注意啊，美元的影响，其实超过美国经济在世界中的份额，这又是什么？经济学上有个概念，叫‘网络效应’，做网络也一样。就是你的贸易伙伴使用货币时，你用到货币就不太好使。结果呢，一旦相当一部分国家选择美元，就会更多的国家选择美元。这样，成就了美元霸权。
