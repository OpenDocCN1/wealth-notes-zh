# 「后发劣势」理论

2001年，杨小凯... 后发优势这—观点。后发劣势这—思想，来自经济学家... 观点。

这—理论说的什么？—个落后国家，由于发展比较迟，很多东西需要模仿发达国家。模仿有两种形式，一种是模仿制度，另—种是模仿技术和工业文明制度。模仿制度比较难，模仿技术相对简单。于是，—般的后发国家，往往会选择模仿技术发展。这样，在... 国家，往往中国，是好的态度去。选择这样—条路。也就是，保留基础制度，通过技术模仿，实现快速发展。

你可能想，这不是挺好的么？问题在于，发展就像摘桃子。你想摘的，一颗树上... 你... 你... 你就永远摘不到。这就相当于，—般的后发国家，都是模仿技术，也可以来在—段时间快速发展起来。为了想摘到桃子就摘，之前... 的... 制度... 原来树上的桃子，也没了。
