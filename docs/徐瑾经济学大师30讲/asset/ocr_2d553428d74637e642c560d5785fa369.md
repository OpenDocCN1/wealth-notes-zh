# 弗里德曼的货币主义

弗里德曼的名气，来自两重身份。学术上，他开创了货币主义学派，1976年获得诺贝尔经济学奖。媒体上，他是一个活跃公民，乐此不疲地展示个人魅力，他的电视节目非常火。他既是个“大嘴巴”，电视上又非常风趣。他经常上电视，上很多电视台，上很多节目。他能把复杂的经济问题，讲得通俗易懂。他经常上电视，上很多电视台，上很多节目。他能把复杂的经济问题，讲得通俗易懂。

提到货币主义，你可能听说过弗里德曼一句经典名言：通货膨胀从来都是一种货币现象。他对货币的关注，在经济学界是出了名的。在弗里德曼之前的经济学界，货币被认为是个中性变量，只用来交易。在弗里德曼看来，货币是经济学的核心。货币是财富的代理，货币是支付手段，货币是资产，货币是价格。在弗里德曼看来，货币是经济学的核心。

这种货币与人的交互。亚当·斯密也认为，货币起源于物物交换，但是斯密把货币当工具。弗里德曼把货币当资产。在经济学界，货币是价格尺度的基础。在弗里德曼看来，货币是经济学的核心。

弗里德曼的伟大，就在于他能把这种思维，应用到经济学的所有领域。他首先把货币视为资产。在历史上，人们把黄金视为货币，因为黄金是资产。在弗里德曼看来，货币是资产。
