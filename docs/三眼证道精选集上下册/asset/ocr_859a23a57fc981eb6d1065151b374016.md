# 简化与复杂

开悟需要简化；
迷惑即为复杂。

简化属守，属明，属盾；
复杂属攻，属暗，属矛。

知识的妙处在于变化，
即可简化，亦可复杂。

简化，使人得到真相；
复杂，使人得到幻象。

助人，须教人简化之道，简化使人开悟；
捕食，须给人平添复杂，复杂使人迷惑。

世间幻象奇多，真相稀少。

众生多皆沉迷于幻象不能自拔，被捕食却喜乐非常。

可暗可明，可阴可阳，
可真可假，源自心性。
