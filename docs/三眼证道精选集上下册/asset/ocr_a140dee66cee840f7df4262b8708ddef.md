研究历史就是研究人类思想的“结构”演化，无论发展几万年几亿年，只要有人存在，农场无论以何种形式存在，人性里都有 0 与 1，无论是看五千年历史还是看未来，这个 0 与 1 之间形成的诸多“结构”会一直有用，这是真知识。

# 科技是更加满足人性的膨胀，并且是逆自然的。
