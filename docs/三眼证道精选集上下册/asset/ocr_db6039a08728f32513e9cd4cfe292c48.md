# 1: 基建

# 2、地产

放水了，房价要暴涨？别做梦，房地产一定会有措施，但那是引人去救场，不要去！越是救市措施力度大的地方，越不要入了，政策相反的地方是好地方。

疫情一定会改变人们的偿债心态，虽然我们的记忆力很短暂，但至少会改变意识一两年，也就是靠债务推动的金融品（房子）会很尴尬，这时候就需要反向操作，抄漏是个好机会，但几年内居民偿务是举不动的，所以抄漏的原则在于可租，也就是租金回报要高，杠杆加到与租金持平即可，手握 n 年即可见大回报。

核心城市和小城市之间会有“城乡镇结合部”地带，这些结合部一方面可参与核心城市经济循环，又能享受“打散”核心城市带来的户籍开放红利，未来看好这些结合部的发展。
