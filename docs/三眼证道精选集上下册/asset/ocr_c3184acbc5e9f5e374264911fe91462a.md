# 谋略观 | 真善美都是“刻度标尺”！

8月1日

![](bbox=[0.13, 0.26, 0.88, 0.46])

能有反义皆为指数，运用就在一正一反变化之中！平时精力有限，思想观系列刚写了几篇，挖了个大坑，星球小伙伴有人问到真善美如何运用，刺激下开始写谋略观；思想观系列是基础，谋略观系列是运用，思想与谋略其实是一体的。在文后，会阐述一下何谓思想与谋略，先开始本篇。

能有反义词的东西，都是指数；运用，就在于这一正一反的变化之中。真善美均为玩操控的招法。思想的存在只有一个任务，就是为了“存疑”，设立边界（参阅思想观系列）；设定规则则时，玩真善美是基本方法。不同人派别对于真善美的定义不一样，以此来设定边界。如说像是儒家对于仁，本身都是人而定的，但要操控一定要求行正反区隔，从而操作一切观念与行为；又像是子盾 lun 玩子盾，分析什么主要矛盾次要矛盾都是小道，大道在诗外，是如何能自己建立一套正反矛盾！说什么是主要的它就是主要的，说什么是次要的它就是次要的，决定于木仓村子。所以 Z 治与宗教的区分，就是于木仓村子里硬做已了。真善美，没有属性，只是刀。看怎么用，这个“怎么用”就是加属性。单独的讲什么真善美，准也没解决不了，必须要加以属性才行。譬如：真诚、真实、真摯…慈善、和善、友善…阳光之美、暴力之美、正义之美、邪恶之美…再做个比喻解释一下；真善美就好比是“没刻度的尺子”，如果要用它，就需要：1、得选择“量什么”；2、得设定“刻度”。
