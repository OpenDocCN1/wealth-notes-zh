# 道是怎么被扭曲的？

百姓日用而不知，故君子之道鲜矣！

好东西一定不是众人（百姓）皆知的，众人的双眼被迷惑（业障），活在假象之中，他们见不到真相的本因，是他们根本不想看见真相 所以就见不到真相；

真相与假象的区隔形成ぢ猪杀形态，前者对后者是高维对低维的猪杀。见《生存法则一》；

观察一个东西，能否接近其真相，脑子做加工（脑智）不是最主要的，往哪里加工（心智）才是prin最主要的。

“百姓”与“君子”的区别，第一位的是“认真能力”的区别，而不是“认知能力”。

人要先有“心的认真”，才会有“脑的认知”。

在悟道上，“认真能力”（心往哪用）决定了接近道的距离。
