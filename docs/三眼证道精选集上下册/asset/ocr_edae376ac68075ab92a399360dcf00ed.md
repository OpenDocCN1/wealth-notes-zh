# “养鱼”背后的真相

无论是放水养鱼还是扩大内需，简单讲背后逻辑就是贫富分化，我们不叫这个，我们叫做“结构失衡”，跟下游叫做“负增长”道理一样；

比如什么经济发展结构失衡，区域发展结构失衡等等...也就是经济循环转动了，为啥会失衡呢？

而放水也是有讲究的，想一想如果水里鱼都没有了，光放水只会流进地主家池子里...

社团大与小逻辑上都一样。

人界与动物界一样，都是抢地盘、控地盘和搞分配这三样。

养鱼的本质就在搞分配上！
