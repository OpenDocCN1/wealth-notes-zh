# 城镇化

外面叫城市化，我们叫城镇化，这是有区别的。这里也没法细说，细说你就看不到文章了，参见《养蛙》一文，或者公众号里搜索“养蛙”即可。看一切经济活动和社会活动，就要以“分配”的眼光去看。城市和城镇的区别就在于“上与下”的分配。搞城市化？几亿农民都进京享受与土著同等的公共卫生服务和福利？
