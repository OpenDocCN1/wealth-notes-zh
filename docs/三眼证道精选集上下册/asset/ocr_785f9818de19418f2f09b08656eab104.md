# 统筹区域经济发展
习近平作出战略性布局

统筹区域发展，是一个重大课题。12月16日出版的第24期《求是》杂志发表了习近平总书记的重要文章《推动形成优势互补高质量发展的区域经济布局》。
在文章中，习近平实事求是地分析了我国区域经济发展形势，高屋建瓴地对区域协调发展作出战略性部署和具体安排。新华社《学习进行时》为您梳理。

区域战略就是围绕核心城市的城市圈协同发展战略，协调发展就是区域内的要素可以自由流动，也就是市场起到资源配置作用。

要素的核心是什么？就是人和地！
