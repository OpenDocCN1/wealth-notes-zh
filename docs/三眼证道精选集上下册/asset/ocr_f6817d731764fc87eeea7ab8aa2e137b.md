# 平衡与失衡

在《变局二》开篇就讲：无论什么改革，每次都会创造新的倾斜之处（失衡），此时漏洞显现，而几乎所有的创新奇迹都源自于漏洞。

什么意思呢？

就是事物的发展是“跷跷板不断运动”的过程：失衡-（平衡）-再失衡…
