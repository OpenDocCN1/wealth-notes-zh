# 4、旧的开放。

前三十年发展可以归结成“租改卖借”，也可以讲“空间换时间”。空间就资源，包括土地、国企股权、地产等。

租，在开放思维的引导下，把不动产便宜出租出售换成流动性资产，作为国家发展的启动资金，开启现代化大门，同时老百姓储蓄在累积。
