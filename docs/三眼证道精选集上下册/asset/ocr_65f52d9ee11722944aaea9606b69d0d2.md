# 从人类政府组织机构说起

人活着啥最重要？
回答：钱啊！

拿出一张 100 元纸币，对着看 1 分钟，这东西魔力为啥这么大？这东西咋来的？

绝大多数人只研究怎么赚钱，而很少有人研究钱是啥、从哪来。
如果你连这东西咋来的都不知道，怎么能更好的获取和利用它呢？
在人生四大必修课中（赚钱、忽悠老板、骗客户、哄老婆），对钱的理解是人生最重要的必修课！
认识钱要从政府组织机构说起，因为钱就是它造的！
