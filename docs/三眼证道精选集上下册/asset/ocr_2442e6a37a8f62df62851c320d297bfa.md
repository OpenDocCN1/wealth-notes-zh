# 全球经济危机到底是个啥？
就是流通性危机，啥叫流通性危机，就是钱转不起来。

经济是需要“循环”着转，转速越快，里面的钱和商品转的越多，经济就越好。
经济危机就是转不动了，转不动就是萧条了，就是衰退了，这仁词叫啥都行，一个意思。
