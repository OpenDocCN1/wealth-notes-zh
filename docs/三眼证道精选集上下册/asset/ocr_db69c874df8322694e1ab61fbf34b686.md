# 当前政治经济大事盘点：简化是洞察，复杂是忽悠！（一文说清）

3 月 20 日

![](bbox=[0.12, 0.32, 0.9, 0.57])

说在前面 三眼很认真写知识，但多数人估计不爱看！为啥？很多读者觉得我写的很“干”，我说一下！不是我写的干，而是事实就那么点东西……媒体与自媒体内容写作特点是：夸张讲述故事；三眼不是什么擅长写故事的，三眼真大写家知识是如此。比如小张和小王打架了，就因为一支铅笔，三眼就写几句话告诉诸位真相，这就很“干”；媒体呢，就很会“讲故事”了：从小张妈妈的表姑奶的大舅的三叔开始写，村里面各种乱七八糟的事都往里加，把打个小架写成部落战争才好看！媒体属性是传播，得“震撼”、“震惊”才行。——一搞乱了人们的大脑，让人们变成“自以为是的傻比”。三眼很喜欢以前的网络氛围，那时候没有什么知识付费，写东西都免费收看，素质大写真与东数都很“干”，只聊实际的不聊虚的；现在都玩付费流量后，看起来是要“尊重知识”，其实是搞“贩卖知识”！净搞些头巴脑的“震撼体”。虚头巴脑的东西抓吧抓吧可能也就几句话的事，很多读者都被这种调调给洗脑习惯了了，要是不绕点弯子，就觉得不“解渴”……最近发生国内外诸多事件，其实几句话就能讲完，润色成可以传播的“震撼”，三严觉得好麻烦啊，我就讲干的，爱看不看，给铁粉写！

写！
