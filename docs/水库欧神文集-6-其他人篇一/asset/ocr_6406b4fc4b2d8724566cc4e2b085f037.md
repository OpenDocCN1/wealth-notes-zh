# 员工的自我修养#X47

原创：吴剑雄

我们要构建一个巨大的联盟，但是联盟内部，并非同质的。

上下级之间，并不一定是同样的关系。

即使是员工，也可能有三种类型。

# 一）君臣

第一组关系，是主公与家臣。

先问一个问题，你的老板，提供的最大的资源是什么？

不是工资，不是平台，也不是他最有能力。

有时候你心里犯嘀咕，这老板水平也不咋地啊。

老板提供的最大的资源，是安全，是生存。

老板承担了所有的风险，你只需要卖力干活，甚至都不用考虑行业大势。

老板每天担惊受怕睡不着觉，你确可以刷刷农药开开心心。

有个巨大的肩膀替你承担了一切。

这个角色，就是老板，君主，王，死亡率最高的职业。
