# **小人何以得志#X41**

原创： 吴剑雄

一）新手村

《论语》里，讲到 man，有两种用法。

“道千乘之国，敬事而信，节用而爱人，使民以时。”

一个叫“人”，“爱人”。

一个叫“民”，“使民以时”。

有一种说法是，“人”指的是贵族，“民”指的是平民。

而在古希腊古罗马，贵族与平民之间的抗衡，一直是一条主线。

护民官制度、十二铜表法，就是平民力量崛起的产物。

直到屋大维称帝，才算是平民的最终胜利。

这里想说的是，politics 的第一步，是区分“人”与“民”。

好比打游戏，其他玩家可以来揍你，你不得不迎战。

但除了玩家，还有 NPC，主要任务是给你任务做。

你点开对话框，他对 你笑。你 对 他挥拳，他还 对你笑。

你骂他 SB，他依然对 你笑。

这是 NPC，是民，你不需要管他。
