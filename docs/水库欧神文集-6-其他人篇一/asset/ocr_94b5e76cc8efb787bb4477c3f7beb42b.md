# 二）共同点

而普通人的思考，都是基于共同点的。

好比一谈房价，就必提日本泡沫经济。

一年跌 60%。

**然而** **其实两者根本不是一回事**。

只要用放大镜仔细一看，就会发现不一样。

货币不同、政策不同、政体也不同。

根本无法得出相同的结论。

人们喜欢找共同点。

因为通过共同点，就能把世界**简化**成很简单的系统。

进一步地，就把复杂的事情简化成概念。

网上很流行一个词的段子。

发生了一个事件，能用一个词来评价，**显得十分机智**。

还有种一切尽在不言中的快感。

还能让其他懂的人产生一种身份认同。

比如

> **【知乎】：在所有亲戚当中，丈母娘一定是最关心你买房计划的那位。** **如果你** **对买房这件事情已经厌倦，那么当丈母娘再次给你提到买房的事情时，你就** **可用这四个字怼回去：“租售同权”。**
