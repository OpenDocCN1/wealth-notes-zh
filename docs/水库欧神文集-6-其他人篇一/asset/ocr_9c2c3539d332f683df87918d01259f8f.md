# 二）未知

我们假设你的能力，能够让自己稳在所有的阶层。

让你做小兵，你每个科目都完美完成。

让你指挥作战，你也调度有方。

那么还有个问题，如何从 level1 进入 level2?

在现实世界中，可能第一次升级，来自高考。

第二次升级，在于进入一个组织。

第三次升级，未知。

第四次，未知。

第五次，未知。

可能是得到了大 boss 的赏识，一路培养。

可能是前面有前辈带路。

好比半泽直树握住上司的把柄，强升两级。

我一个上海 XXX，怎么就成了 XXX 呢？

每次的机制甚至可能都是随机偶然的。

前一次比演讲，后一次比人脉，下一次比业绩。

最后一次，是整个大环境突然变得对你有利。

关键是，整条科技树，都是暗的。

升级是需要能量的。

关键在于找到能量所在，并设法借助其力量。

从小学到大学，其实走的是一条固定的升级方式。

只比拼成绩，科技树全明。

直到毕业之后，发现世界根本就不是如此。
