# 分析世界的几个步骤 #X27

前一篇文章《[说客与律师](#)》写了表达自己想法的方法。

+   表达之前：*重要的是得出自己的想法。*

+   那么这一篇就写写：*怎样得出有洞察力的结论。*

如何进行思考，如何分析我们周围的世界。

一）不一样

一般人喜欢找规律，从共同点里总结规律。

但我要说的是，要*找不同点*，而不是关注共同点。

*破案的关键，在于发现不一样的地方。*

*发现不同才会产生疑惑，才会进行研究，才会寻找真相。*

*我们看侦探小说，主角破案，都是因为发现了别人没注意到的反常的细节。*

凶案之后，主角仔细回忆每一个场景。

“他当时说的那句话，应该只有看到了现场的人才知道。”

“明明破产了，却打车来回。”

“可疑，太可疑了。”

于是顺藤提瓜，真相大白。
