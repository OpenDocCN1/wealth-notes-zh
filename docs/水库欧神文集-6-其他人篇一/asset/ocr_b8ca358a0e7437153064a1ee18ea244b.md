# 首先，你的内容必须设计得能吸引尽可能多的受众。

所谓团结大多数，孤立极少数。

诀窍就在于把自己的事，转化成大家的事。

好比你走在路上被人打了，这是你们之间的事。

“某地某人在街上被打。”

但是如果你通过细节表明，你一直温文和善，从不与人结怨。

“现在上街危险了。某地 27 岁白领，送孩子上学路上被无缘无故暴打一顿。”

好人也会莫名其妙被打，这就牵涉到很多人。

因为大家也担心莫名其妙被打。

如果你再说明被打了没人管，对方还很嚣张。

“傍打人者有 XX 背景，路人无动于衷。”

那就成了全社会的事情，黑社会猖獗，监管缺位，绝大多数人都会胆战心惊。

网红打人？哈，早就看你 不爽了。

# 第二，要树立明确的敌人。

当你确定了受众，第二步是要诱导他们帮你转发，发酵。

转发的动机，主要是正义感，焦虑和愤怒。

正义感：我是一个正义的人，关心弱者。

焦虑：天啊，太可怕了，怎么办啊，谁来管管吧。

愤怒：可恶的奸商，大家都看看，弄死他！
