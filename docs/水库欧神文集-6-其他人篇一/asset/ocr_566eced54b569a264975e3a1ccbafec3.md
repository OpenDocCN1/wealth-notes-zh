# 四）契约

上一集我们说到，产权是防盗科技。
接下来我们将契约。契约是弱化的产权。
本质上，你欠我 20 万，就意味着我有 20 万。

产权是交易向空间的扩张，契约是交易向时间的扩张。

最早的交易，是一手交钱一手交货。
对应到产权，就是实际控制的钱交换实际控制的货。
地摊交易，眼见为实，几乎是最安全的交易。

但我们知道，这是非常低效的。
低效的原因在于，很多交易都不会发生。
我下个月才发工资，能不能先买个苹果手机。

史玉柱第一桶金，是卖自己开发的文字处理软件。
软件是自己在学校系统开发的。
为了给客户展示自己的软件，他买了一台电脑。
只不过想办法说服电脑公司，晚一个月付钱。
