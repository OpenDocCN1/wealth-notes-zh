# ## A9 最怕尸骨无存。

基业后继无人都是身后事、是小事。

眼下先想想，我出事儿的时候，有没有人联名抱团保我吧。

“哪有什么格调，每个阶层的人都在拼劲全力生存而已。”

不是外界臆测的湖边禅修聚会，没有屌丝 yy 的那些喝茶、抚琴、美女伴游。

这种力度意味着什么？

意味着它真的要培养自己人。
