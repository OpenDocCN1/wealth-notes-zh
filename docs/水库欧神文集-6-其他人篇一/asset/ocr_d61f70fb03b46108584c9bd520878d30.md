# 四）装备

“装富，炫富，混迹于富人圈”是一个系统工程。

中产阶级通常，很难为富人圈接纳。因为他们不懂富人圈的游戏规则。

普通的白领小女孩，想要嫁给社长，那是千难万难。

对于小女孩来说，最大的忌讳，是浑身上下只有“一件”名牌。

这里面的关键词是“一件”，而不是品牌。

贫穷，会从每一个角落散发出来。

一般来说，目前主要流行二种趋势：

+   要么你浑身上下，全部都是名牌。

+   要么你浑身上下，一件也没有名牌。纯为穿着舒服。

有钱人分二种，讲究的和不讲究的。
