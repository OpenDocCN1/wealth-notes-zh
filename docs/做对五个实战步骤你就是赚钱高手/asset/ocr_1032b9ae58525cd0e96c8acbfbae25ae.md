# ⑤ 參考5：日線參考「MA5均線操作法」做空

+   1. 波浪型態多頭完成。
2. 股價符合多頭進場位置進場。
3. 進場停損守進場紅K線最低點。
4. 收盤跌破MA5均線出場。
5. 多頭趨勢改變（日線趨勢出現頭頭低），停止操作。
6. 逆勢做多也可用此方法短線操作。
