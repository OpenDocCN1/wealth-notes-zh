# 選股SOP：短線做多

# 範例

冠杰(6243) 2010/11/26，量天出短大量長紅K線，以下是符合短線做多的條件：
①向上跳空長紅K線當日縮量收，收盤強於前一日高點，波段型態形成「頭頭高、底底高」的多頭趨勢。
②均線3線向上多頭排列，股價在3線之上。
③第一隻腳38.08落底反彈，當天大量，多方後續反彈往上到月線，再下
股打第二隻腳。
④多頭確認上攻連續2天爆大量。
⑤KD指標黃金交叉多排向上。
符合短線做多的條件之後，再看往上會遇到那些壓力，這些壓力就是可
能的獲利目標。
⑥季線向下的壓力。
⑦前日高點的壓力。
⑧向下跳空缺口的壓力。
由上面區的僅利目標來預估，上漲獲利都不是高，只能做短線操作獲利，
