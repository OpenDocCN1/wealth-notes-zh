# Part 2 ▶ 5大實戰操作

# 操作重點

底部轉折低點出現大量連三紅，或是上漲3天出現2次跳空缺口快速上漲，後續完成多頭底部，為強勢上漲的潛力股。

# 圖形解說

強力反彈後回檔不到反彈幅度的三分之一，就轉折上漲完成「頭頭高、底底高」的多頭確認，為強勢上漲的潛力股。

鴻海 (3293)，日線最低點大量反彈。

② 回檔幅度約三分之一就出現止跌的紅K線，後續上漲出現底底高的打底
③ 第一隻腳。
④ 打底時再出現大量長紅K線，突破盤整高點，多頭「底底高、頭頭高」確認，為強勢多頭底部，突破時股價收盤58.3元，後來一路漲到175.5元。
