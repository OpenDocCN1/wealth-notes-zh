# ⑥右蓋4、週線雙頭「K線操作法」饅頭

+   1. 週線波浪型態空頭完成。
2. 股價符合空頭進場位置進場。
3. 進場停損守前週進場黑K線最高點。
4. 收盤穿越前一週K線最高點出現。
5. 空頭趨勢改變（週線趨勢出現底底高），停止操作。
