# 判別多空

戰時不想被敵人戰勝，防守要固若金湯；想戰勝敵人，進攻作要勢不可省。善於防守者，如同隱蔽兵力於地下，深藏不露；善於進攻者，發動進攻如同神龍九霄而下。正所謂防守能保衛自己，攻能一舉奪勝。

在商場上，公司經營必須隨著市場的景氣變化調整，景氣不 好時要能守成，不被打敗；景氣好時，要能開疆拓土，擴展業 續。操作股票，要審時度勢，國際經濟衰退、國內景氣下滑、大盤趨勢不佳時，要保守應對，投入資金要減少；當大壞境變 好，趨勢成大好時，要抓住機會，全力做多。

# 買賣沒有絕竅 只有參考

再好的股票，在趨勢轉空頭時也會有下跌，再差的股票，在趨勢多頭時也會上昇。以大立光（3008）為例，獲利創新高，可是趨勢轉空頭，股價照樣下殺。
