# ①長線領空實戰範例

![](bbox=[0.42, 0.13, 0.78, 0.9])

創惟（6104）2007/4，月K線長黑吞噬，跌破連續上漲7個月的上升切線。

+   ① MACD指標在0軸之上，死亡交叉向下。
② KD指標80死亡交叉向下，月線回檔訊號，可看週線條件做中空。
③ 2007/8，月K線長黑吞噬，頭部「頭頭低、底底低」，空頭確認。
④ MACD指標在0軸之上，空頭排列向下。
⑤ KD指標空頭排列向下。

另線完成長波段條件，回到週線操作，長波段中線操作可用5週均線操作
作，長波段長線操作可用20週均線操作。
