# ⑦ 掌握面面接觸面意總結

綜合前面所說的重要點，可歸納出下面3個重點：

重點1：「基本分析」以公司本身具有的價值，衡量現在股價高低，是否值得長期投資。「技術分析」則是透過圖形量化指標，推測股價的變動，看是否 possibility 上漲或下跌的機會，進而操作買賣獲利。

重點2：透過「基本分析」，可以了解所要購買的股票的本質。透過「技術分析」，則可把握具體的買賣時機。

重點3：成功的投資人是把兩種分析結合運用，用「基本分析」評估較長期趨勢，用「技術分析」判斷短期走勢及進出時機。

只要充分了解股票投資與投機的不同之處，我們就可以根據自己買賣股票的定位，在進場前做好準備，還好買進的股票。這樣一來，買進股票之後，就很清楚自己在做什麼、以及要做什麼了。
