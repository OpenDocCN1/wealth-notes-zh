# 宏泰2012/1/30，當天出現向上跳空大量長紅K線，以下是符合短線做多的條件：

① 向上跳空長紅K線實體棒，收盤突破頭肩底啟整高點，型態確認，同時「頭頭高、底底高」的多頭趨勢也確認。

② 均線3線向上多頭排列，股價實在3線之上。
③ 第一隸腳，12.8落底反彈，當天大空，多方後續反彈往上突破月線到前面高點，為多方強力反彈，然後高檔盤整，形成頭肩底型態。

④ 型態完成，多頭確認上攻連續攻擊大量。
⑤ KD指標黃金交叉多頭向上。
