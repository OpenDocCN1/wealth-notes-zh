# Part 2 ► 5大買點與外觀

# 空頭破空位置

空頭向下跳空長黑K線，股價維持在缺口下方整理，當出現整理裡末端的集中長黑K線下跌時，是放空的位置。

# 擒空圖1 缺口之下等空點

+   1. 黑K線如符合「價跌、線實」的訊號，放空成功下跌的機率很高。
價跌：收盤價下跌，收盤價跌破K線整理的最低點。
線實：K線收中長黑K的實體棒（下跌2.5%以上）。
成交量：大量或小量都可以。

+   2. 日線進場的K線訊號是操作短線的放空位置。
週線進場的K線訊號是操作長線的放空位置。

+   3. 曾日下跌黑K線如果更是再出現跳空下跌的K線，是主力強勢下殺，更要把握機會進場做空。

+   4. 放空後要設定停損，並且嚴格執行停損。
