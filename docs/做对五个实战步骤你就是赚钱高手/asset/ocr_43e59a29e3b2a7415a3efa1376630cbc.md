# ◎方法⑥：回鍋空頭「MA10均線操作法」做空

+   1. 波浪型態空頭完成。
2. 股價符合空頭進場位置進場。
3. 進場停損守進場黑K線最高點。
4. 收盤跌破MA10均線結束出場。
5. 空頭趨勢改變（日線趨勢出現底部底高），停止操作。
