# 掌握短線各類K線型態

① 數量 2012/10/8，日線大量長黑K線下跌，跌破前面低點，空頭趨勢「頭頭低、底底低」確認，股價跌破MA20，均線3線空頭排列向下，當日收盤15.1元進場做空，用日線「長短線綜合操作法」操作。

③ 2012/11/2，大量長紅K線收盤突破MA5均線，收盤11.9元空單回補。短線單次獲利3.2元，獲利率21.1%。
