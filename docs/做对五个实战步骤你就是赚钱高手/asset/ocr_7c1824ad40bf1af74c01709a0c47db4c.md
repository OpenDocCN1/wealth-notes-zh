# Part 2 ▶ 5大實戰案例

◎2014/10/7，日線大量黑K線下跌，收盤跌破前一日最低點，至頭反彈再下跌，當日收盤37.15元進場短線做空，用日線空頭「MA5均線操作法」操作。
◎2014/10/22，紅K線收盤突破MA5均線，收盤34.25元空單回補。短線單次獲利2.9元，獲利率7.8%。

關鍵點提醒
◎日線至頭「MA5均線操作法」操作短線，一共進出2次，歷經1個月。
參考獲利：1.5元+2.9元=4.4元，獲利率4.4÷40.3=10.9%。

# ◎寄語7：◎關鍵點「MA10均線操作法」觀參

+   1. 波浪型態多頭完成。
2. 股價符合多頭髮進場位置進場。
3. 進場停損守進場紅K線最低點。
4. 收盤跌破MA10均線出場。
5. 多頭髮趨勢改變（日線趨勢出現頭頭頂低），停止操作。
