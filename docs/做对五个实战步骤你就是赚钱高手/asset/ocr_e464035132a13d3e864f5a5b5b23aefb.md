# 第 2 章 股票做多 6 個進場位置

多頭繼續買位置 3
多頭中長紅K線上漲後，股價維持在K線上方僵盤，當再出現大量中長紅K線，突破僵盤最高點時，是進場的位置。

資料來源：昌鴻e01電子交易系統
