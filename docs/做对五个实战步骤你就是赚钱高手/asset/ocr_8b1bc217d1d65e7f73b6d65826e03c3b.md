# 停利的基本觀念

俗話說：「會買股票是其次，會賣股票才是師傅。」經過學習習，一個人會曉得如何挑選股票，但通常沒有停利的規畫。換句話說，懂得買進，而不懂得賣出，只會看著股價上漲又下跌，或者抓到一支會漲的股票，但是漲一點點就賣掉，該賺的錢沒賺到。股票賣出換成現金，結算有獲利，才是真正賺錢。沒有賣出前，股價隨時都在上下下，如何拿捏該賣出的價格，的確不易，賣得太早只能賺到一點小錢，設賣沒賣，股價又可能快速回跌，反而賠錢。如何賣出股票是獲利的關鍵，停利是每次交易的最後一個動作，如何劃下完美的句點，雖然苦的付出有代價，是戰后必須停利要有以下的正確觀念，否則永遠會賺飽不定，造成該賣沒賣，不該賣卻賣的情況：
