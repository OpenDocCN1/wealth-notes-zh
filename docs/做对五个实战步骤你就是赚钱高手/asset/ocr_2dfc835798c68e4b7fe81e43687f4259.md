# 第2章 股票做多6個進場位置

和旺（5505）2010/1/8，已當週出現大量長紅K線，符合中期做多進場的位置：
①多頭走勢上漲一段後築整理，等待盤整的突破或跌破再進場。
②當週放量約為前一週的3.8倍大量。
③當週上漲16.5%，中紅K線實體棒，收盤突破盤整上頸線及前面6個月高點。當週收盤前確認，符合中波段操作進場買進位置。
