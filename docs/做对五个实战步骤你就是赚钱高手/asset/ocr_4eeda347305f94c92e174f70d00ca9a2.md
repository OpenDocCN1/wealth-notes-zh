# 短線做多

# 選股SOP：

短線操作股票，當股價的日線完成下列幾項條件時，可以短線做多：

+   1. 趨勢條件
日線波浪型態（趨勢）符合「頭頭高、底底高」的多頭架構。

+   2. 均線條件
日線的均線3線（MA5、MA10、MA20）多頭排列，均線向上（注意：季線如果還在股價上方，而且是下彎走勢，當股價上漲靠近時，會有壓力產生）。

+   3. 股價位置
股價收盤在3線（MA5、MA10、MA20）之上，同時看股價在整個上漲趨勢中，是位於初升、主升或末升階段。
