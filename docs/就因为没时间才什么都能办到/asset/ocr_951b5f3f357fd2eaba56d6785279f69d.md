# 邊跑邊想「怎麼走下去」

如果留學之前就知道會有這些情況，我還會前往美國嗎？老實說，我沒什麼信心，可能會把留學行程延長幾年，利用時間多存點錢吧。

幸好我是在不清楚美國的生活實態，就去了美國，而且就算問題層出不窮，仍堅持到底，我才能拿到哈佛的碩士學位。

回國之後，經常有人找我商量出國留學事宜，而我一律說：「還沒做之前不要想，先做了再說！」

無論什麼事情，要等萬事俱備才動手便很難實行，但只要先衝出去，就有機會慢慢修正軌道，思考其他途徑，並設法找出通往目標的方法。

我們用腦袋思考，用腦袋煩惱，用腦袋踩煞車，但世界上有許多事情，要動了、撞上了、乘上浪頭才能明白。

不是只有成就大事業才算「行動」，開口請人幫忙，將心動的格言寫在紙上，都是確切的「行動」。只要動一動，就會學到、發現到許多意想不到的事
