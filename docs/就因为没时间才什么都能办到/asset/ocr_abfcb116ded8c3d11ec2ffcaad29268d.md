# 心裡認為「一定能成！」自然就 有出路

說到「我能成功！」的莫名自信，我認 為這不僅可以用來準備考試，也是快 意人生所不可或缺的元素。

重點不在於成功或失敗，心想「能成 」而激發鬥志更為重要。

不少研究報告都曾提到，無論做研究或做教育，自信比客觀評價更重要。

我覺得日本人重視客觀多過主觀，但 如果是重視主觀多過客觀的人就會覺得「我能成功！」相對地會成長得比較快速，鬥志也比較高昂，人生也更加快樂。

這種人的大腦會更有活力。

我認為無論什麼事情，只要覺得「我 能成功」，你就已經站在終點附近了。
