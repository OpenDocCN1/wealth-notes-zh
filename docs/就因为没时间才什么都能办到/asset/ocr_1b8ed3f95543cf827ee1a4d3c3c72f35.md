# 只要加速，就會收穫意想不到的成果

跳，沒什麼準備就踏出了第一步。

任何人任何時候要開始新的活動時，總需要一股勇氣跨出第一步，而且有不少人會猶豫不前。但越是在這時候越要記住「先動起來，之後便能輕鬆前進」——我就是這樣說服自己的。

總之先動手和腳，踏出第一步，就會發現第二步比第一步輕鬆多了。腳踏車也是剛踩第一下的時候最費力，但踩第二下、第三下會越來越輕鬆，速度也越來越快。

挑戰某個新領域也一樣，腳步不要停、用心準備，不要等到具備一定的知識才開始，直接行動，往新世界撲過去就對了。

或許會碰到重重難關，每碰到一關就要撞得鼻青臉腫，但唯有實際站在最前線才能發現問題。直接動手，問題來了就想辦法解決，一關一關克服後會越來越順暢，不只速度快也更有自信，吸收得也更快、更多。
