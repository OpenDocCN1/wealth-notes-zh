# 有一張書桌就等於回到個人的世界

話說我有一張充滿回憶的桌子，那是爸媽慶祝我升上國中所買的。這張透出淡淡原木芳香的書桌，寬度大概有我的兩手臂張開伸直那般的長。同時還配了一張原木椅，椅墊上鋪了深綠色的天鵝絨。這張桌子不同於一般書桌給人的印象，原木穩重厚實、氣度非凡，總讓我感覺一坐在桌子前，就能激發想像力、拓寬眼界般。
對中國生來說，這樣一張桌子實在太豪氣了點，有一天我忍不住問了媽媽為什麼會送這樣的書桌給我。
媽媽想了一下，就給了我下面的回答：
「桌子是每個人的心靈依歸。它不僅可以用來念書，還可以寫日記、寫信、收藏珍貴的東西，是塑造人格、培育心靈的地方。所以我們認為有必要送你一張好桌子，這麼一想，就知道那張芳香的實木書桌是最好的選擇。」
只要有心想，哪裡都可以念書。客廳的茶几也好，餐桌也好，甚至地板也行，但我母親所關注的是「環境」，考慮的重點是，我面對書桌時的「身體感覺」。
