# 決定做之後，大腦會主動找出路

我想這念頭，源自於一股莫名的信心，相信自己必定能成功。我天生就不喜歡輸的感覺，非常討厭辦不到、不可能之類的說法；爸媽也是從小就對我說「穩波好棒，什麼都會！」

感覺好似爸媽為我種下許多「莫名信心的種子」，不知不覺長成了大樹。漫畫《東大特训班》也影響了我。或許不少人聽過這部漫畫，內容是說主角櫻木建二身為律師與老師，為了重振一間即將破產的私立高中，讓兩位連考普通大學都不敢想的高中生，考上了東大。
