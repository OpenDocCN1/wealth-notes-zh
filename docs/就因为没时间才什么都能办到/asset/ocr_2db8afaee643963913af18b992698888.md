# 15 再小的情緒交流都不能省

# 拉下臉也要學會「受助力」

該怎麼輕鬆地請求他人幫助，又該如何開心接受幫忙？要請人幫忙時，關鍵的視角轉換就在於「借助他人之力，並不是找人麻煩」。

那究竟該如何受人幫助，才能保持良好的對等關係，而不是階級關係？

二〇一一年三月十一日發生東日本大地震，讓我發現了答案（附帶一提，地震發生時，我已從哈佛學成歸國一年多了）。

當時我前往宮城縣擔任救災義工，就曾經見到許多情況是，「助人人」與「受助者」之間的心意相違。比方說我是以婦產科醫師的身分前往災區，但剛開始根本找不到孕婦願意接受我的幫助。
