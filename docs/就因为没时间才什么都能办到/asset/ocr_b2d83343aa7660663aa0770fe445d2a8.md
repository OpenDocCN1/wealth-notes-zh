# 〔結論〕 祈願我的經驗能成為你前進的助力

著「我想您是不同世界的人」「我沒有吉田醫師那樣好的條件，不可能邊帶小孩邊留學」這類的意見。每每看了總讓我反省，可能我還不夠老實吧。

我並不是什麼女強人，反而有諸多不足，而且是在他人的協助下，才能夠像是騎著腳踏車般持續奔走。當我開始傳達真實的失敗經驗與克服危機的訊息後，最近終於有聽眾回應「我想我應該也辦得到。」「既然吉田醫師這麼說，我就試試看吧。」

每次演說，我都十分期待將會遇見的聽眾，更希望我的掙扎經驗，能夠成為眾人探索自我人生的線索。

二〇一三年七月寫作本文的當下，我已有育有最小兩歲，最大八歲的四個孩子，而且第五個孩子即將臨盆。

孩子多的好處是，孩子們能夠互相照顧，慢慢的也就不需要父母動手操勞了。家族成員越多，氣氛就越加熱鬧，而且多了個性不同的新成員，也讓人更加雀躍呢。
