# 在郵戳截止日前都不放棄

前面提過「越到截止關頭越是衝勁十足」，但要發揮這股能量的前提是「絕不放棄」。

直到最後都不放棄，代表真的已盡力而爲，直到最後一秒鐘都不放手。

例如申請文件的截止日期可能是「○日截止，以郵戳爲憑」，那麼不放棄的意思就會是「即使在○日的最後一秒鐘衝進郵局也不放棄！」

把信件丟進郵筒，需要一些時間才會被蓋上郵戳，若是親自拿到二十四小時營業的郵局寄，就能立刻蓋上郵戳。我一向膽子小，寄件時還會特地確認：「郵戳是蓋今天的吧？」

我有好幾次半夜衝進郵局的經驗，雖然沒什麼好說嘴的，不過確實有許多獎學金，是靠著這種絕不放棄的態度爭取來的。

前些日子我又是在截止日當天，帶著申請文件去主辦窗口申請某筆研究費，而且還是寄出的五天前，才提出研究經費申請並拿到申請編號。

我在截止日當天拿著一整套文件前往主辦窗口，負責人還說：「我以爲妳已……”
