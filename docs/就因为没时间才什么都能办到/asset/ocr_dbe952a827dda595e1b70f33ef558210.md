# 「Make a difference!」這句話銘刻我心

我在留學的後半懷了第四胎，就在研究所畢業後，回國前夕生下了四女兒。

回到東京後，我一邊帶著四個女兒，一邊做研究。

就在回國數個月後，發生了東日本大地震，令我坐立難安。我在第一時間前往宮城縣石卷市擔任賑災義工。

另外我也開始參加輔導員培訓課，心想這一定能在醫療現場派上用場。但又不能把孩子放在家裡，所以我每次去石卷市當義工，就在當地住一兩晚再回東京，過沒多久再從東京出發。每次擔任義工，包包裡都會帶著培訓講義，好在路程上念。
