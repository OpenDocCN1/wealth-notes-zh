# 時間越自由，反而容易一事無成

在固定時間，固定地點，加上有同伴。只要湊齊這三大要件，就容易加速達成新目標。

我曾經有段時間與孩子們一起做收音機體操（國民健康操）。每天早上六點半，會有一群老年人在附近的公園做體操，我們就跟著他們群集做操。

夏天時，我會準備好飯糰、水果等簡單早餐，做完操之後就地在公園用餐。運動後神清氣爽，且在清新的空氣中，對著花草樹木吃早餐，食物也更加美味。孩子們也玩得開心，於是就養成了固定做操的習慣。
