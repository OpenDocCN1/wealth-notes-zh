# 別被「時間管理」的魔咒給束縛了

時間只要省著用就好，時間只要擠一擠就有，不是這個意思。「時間管理」這句話固然迷人，但可別被綁住了。

重要的是，先提高眼前現有時間的密度，做「最大價值」的利用。

也就是，把「時間價值」放到最大。

這並不是單純的在一定時間裡塞滿該處理的事，提高產能而已。

以工廠的生產線來說，不斷提高產能就是把時間價值最大化。但就人性來論，偶爾放下產能，休個假享受天倫之樂，这样子運用也是將這段時間的價值最大化。

假日別塞滿行程，讓身心放鬆，做好健康管理，如此一來下週的時間運用就會更有效率。
