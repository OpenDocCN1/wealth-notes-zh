
# 每天忙到爆炸，工作評鑑卻持續低迷

當這股「幹勁」爆發出來時，就是開始實現理想的最佳時機。有時這股爆發力甚至能助你開拓出嶄新生。我對此深信不疑。

話說回來，其實我是最近才開始有這種想法。前面提到我神清氣爽地與家人一同抵達波士頓機場，但在這之前的一年半時間裡，我每天都被工作、家事、小孩給轟炸，生活過得滿是憤慨。

本文開頭說到「一整天在辦公室裡忙進忙出，大大小小工作不斷。回到家又是做家事又是帶孩子，被各種型態的工作占滿。」不瞞各位，這說的正是我本人。

當時我在東京銀座的婦幼綜合診所擔任婦產科醫師，大女兒才兩歲，老二只有兩個月大。

我的上班時間是上午九點到下午五點，而且住處遠在枡木縣宇都宮市，每天要花三小時來回通勤。下午五點一到就衝出診所，趕著回家。

先到托兒所接小孩，回到家已是七點；到家之後一邊陪小孩，一邊做晚餐，然後餵小孩，給嬰兒哺乳，接著洗澡、洗衣服，準備明天托兒所要用的東西……每天都像是在浪裡翻騰般。

當時我雖爲婦產科醫師，但在知識、經驗上不如資深醫師豐富，只是個畢業八年、成長中的半熟醫師。

爲了更接近資深醫師，我必須吸收更多最新的資訊與知識，並且運用在治療上，提供病患最佳的治療結果，同時也建立自信。但儘管鬥志滿滿，卻擠不出時間參加通常在晚上舉行的講座、研討會與讀書會。

我想學會統計、病理等研究技術，以作爲治療的科學根據。爲此，出國留學就是個辦法。說起留學，一直都是我長久以來的夢想……唉，但是我每天累到連教科書都不想翻開了說。

每天，我幾乎是哄著孩子睡覺，然後被疲勞與瞌睡蟲打倒，不知不覺跌入夢鄉……

我總覺得自己是「二十四小時營業」，但是我並沒有在診所開夜間門診，也不參加診所會議，所以工作評鑑持續低迷。

這時候又遇到大女兒住院，情況更是雪上加霜。大女兒剛過一歲生日不久便染上肺炎，併發小兒氣喘。氣喘是支氣管發炎的症狀，如果狀況嚴重，整個身體機能會立刻受損，而有必要住院治療。

每個孩子的氣喘發作情況不同，有些孩子只要定期回診就好，但我女兒經常一住院就是十天。

住院之後，幾乎二十四小時都要有家人陪在病床邊，而這種重責大任九成都落在我這個媽媽的肩上。

小兒氣喘的特徵之一，就是痊癒之後還很容易復發。每次好不容易出院，在家觀察一段時間後，心想她總算可以上托兒所而放心工作的當口，她就又復發住院。

讓我滿是挫折。

別說是吸收新資訊、新知識，就連工作都做不好，還提什麼留學。對照心情降到最低的我，症狀緩和的大女兒卻在病床上笑得天真。她身體好轉，確實讓我鬆了口氣，但想到同一天自己負責的病患要回診，不知道由誰代班，而且一直請假實在愧對上司與病患，又再讓我跌回了萬丈深淵。

我每天這麼拚命，卻沒有一件事順利，也沒有半個人認同。一回神，我已經好一陣子成天對著丈夫與朋友抱怨不停。

但就在某天，我突然心生疑惑——

「我感觉自己就像個悲劇女主角，但這麼下去真的好嗎？」我開始認真地思考，如何才能擺脫這種痛苦的狀態，要改變現狀的話，有沒有可行的方法呢？

這時候我在書上看到了一句話，深深的刺進我的胸口。

「不是因為某件事情很難，你才不想做，而是因為你不想做，所以變得困難。」（出自《死時誰為你哭泣》作者羅賓·夏瑪）

的確，我想念書，想往上爬，卻沒有動手做，反而怪罪環境與孩子的身體狀況。是我的心默許自己因爲忙，所以一事無成。再這樣下去不行。

這一刻我像是吃了秤鈎鐵了心，隱約中聽見鏗鏘一響，打開了心裡的開關。

# 抑鬱的心情讓人想要改變

讓留學夢成真吧！

許多人聽聞我一邊做婦產科醫師的工作，一邊念書準備考試，最後還帶著三個女兒去美國留學，都不禁要問：「怎麼辦到的？」其實一切的起點，就在這裡。

因為沒時間，所以辦到了。回想起來，我總是深陷於時間限制中，婦產科醫師的工作、帶小孩、做事……肩頭真的是「千斤萬擔」，動彈不得，但也正因如此，心中才會強烈湧現出「想做事」的渴望。正因為無法輕鬆完成，「想做」「想成功」的意念才越发強大。

再加上工作與育兒不順心，心中大量的飢渴與焦躁反成了燃料，轉化出「無論如何都要進步，改變現狀」的決心。

如果有人對我說一天二十四小時都歸我管，可以「自由自在」，我應該無法在短時間內念那麼多書。如果孩子長大了，早上我還有閒情喝杯咖啡，想必我也不會這般熱血沸騰了。

每天被工作煩得焦頭爛額，時間又被家事和小孩占滿……但就是這般「忙到沒時間眨眼」的關頭，才是提升自我的契機。

「想做事」的能量此刻在心底漲到了最高點，而「諸事不順」造成的抑鬱卻成了助燃劑，正是引爆這股能量的絕佳機會。

因此，如果各位讀者也被工作、家事、小孩等諸事纏身，騰不出時間，請不必失落。因為這反而是個「機會」。

沒時間、諸事不順的「障礙」，正是引領自己更上一層樓的大門。你眼中的高牆，其實是道有把手的「門」呢。

# 02 想做的事統統一起進行吧！

「一件一件照顧序來」，人生不夠長！

決心留學時我只有兩個女兒，但在考取哈佛大學公共衛生研究所，前往美國就讀時，又多了一個月大的老三。

大家聽我帶著三歲、一歲、一個月大的三個小女孩出國留學，無不驚訝莫名。每個人臉上彷彿都寫著「為什麼要選在這時候懷孕生子？」我的答案是：「在這時候懷孕是計畫內，而且連生三個女兒，讓我很開心呢！」每一個聽到回答的人无不瞠目結舌。

大多數人如果家有幼子，又想出國留學，通常會等留學結束再生，或者等孩子有點歲數了再去留學，但我不這麼想。

我傾向，如果同時有幾件事情想做，就統統一次完成。

原本我就打算生三個孩子，但又不想因為帶孩子讓工作出現太長的空白，所以把生育年齡拉得很近，最好是每一胎都差不多兩歲左右。「計畫生第三胎」的時機恰好與「想留學」的時間重疊，我不考慮先做哪個，而是讓兩件事一起完成。

若問我為什麼，因為人生只有一次。身為婦產科醫師，我比任何人都清楚生育有年齡限制。

對我來說，「想繼續工作」「想留學」「想當個兒女成群的媽媽」是人生的三大支柱。這三大支柱並非各自獨立，而是像三條絲線，交織互補，強化了我的生命。

舉例來說，我在工作上面對病患時，偶爾會猶豫 A 療程與 B 療程哪個最適切。而且我很清楚「根據經驗判斷，A 比較合適，但我必須出示統計資料，有科學根據才能說服病人。」然而日本在女性醫療方面仍缺乏研究基礎。於是這個念頭就刺激了我，讓我產生動力準備考試，「我非學會統計技術不可，所以一定要讓留學計畫實現！」

此外，因為懷孕在身，我更加注意飲食，這也確保了我的健康狀態，讓我有體力投入工作與學習。

冰箱上、洗臉台，家裡到處貼滿了英文單字，讓孩子們看著爸媽努力讀書的身影，要比說一句「乖乖讀書」效果更大。

當然，現實總有不如意的时候，像是回到家已經精疲力盡，孩子哭鬧著要人抱，會讓我感覺特別累。

但我仍然認為，同時進行會利多於弊。

畢竟要是一切照順序來，先這個再那個，理想永遠不會實現。有幾項事情想做，就同時進行。我認為這就是實現夢想的竅門。

# 賴床有名的吊車尾醫師

想做的事情統統一起進行。

聽我這麼說，或許有人會以為我是精明幹練，無所不能，辦事俐落的女強人，但我與女強人恰好相反。完全稱不上是「精明幹練的人」。

我是在聖路加國際醫院完成實習醫師訓練，而且還是吊車尾升上住院醫師。

主因是，我非常需要睡眠。每次輪班都叫不起來，護士們便七嘴八舌地說：

「今天當班的是穗波啦。」「難怪！」然後親自來休息室叫人。無論我多麼擔心病患的身體，在ICU（加護病房）護士站輪大班還是照打瞌睡……常常連兇惡的護士長都看不下去，不時會端杯咖啡給我喝。

還有，要是碰到不懂的事情，我還沒自己翻教科書找答案，就已經開口問上級醫師了。結果惹來實習學長姊一頓罵：「妳長腦袋是幹什麼用的？想啊！」

剛當上醫師的時候，想打點滴經常找不到血管，連病患都拜託：「請換個醫師來打。」我聽了眼淚就不爭氣的擰不停。當時不像現在有注射練習器，學長爲了補救我不拿手的找血管技巧，還提供自己的手臂讓我練習：「拿我的手當練習器吧。」

當時，我每天晚上都自動前往急診室高喊：「不管是一身血還是怎樣的，只要誰需要打點滴，請交給我！」就這麼花了幾個月時間徹底磨練出找血管的技巧。

多虧這段訓練期，打點滴找血管我變得比誰都厲害，在德國留學期間，甚至同學都說「要打點滴就找Fran Yoshida（古田醫師的德文）」呢。原本不拿手的事情，竟成了我的拿手好戲，讓我深深感受到，只要徹底練習，缺點也會變強項。

我想我的人生再也不會有那樣廢寢忘食的時候了。雖然辛苦，但是克服困難的過程給了我無比的信心。我覺得那是成爲社會一分子的原點，也是人生最寶貴的時期。

我能撐過艱苦實習醫生階段，百分之百是託了眾人的福。我學到的技術與經驗，全都是拜他人之賜，完全不是靠我自己獨力擁有的。一直以來，我都這麼認爲。

回首來時路，原來我這一途都是這麼走來的。

準備留學的時候，留學期間，乃至於現在，都是多虧了眾人的鼎力相助，我才走到這個境地。

「所有事情統統一起進行吧！」聽起來可能會讓人有一個人乘風破浪的感受，但其實我是借助了衆人之方才到今天。

同時進行，或許正是我這種笨拙、不得要領的人，才需要這一招吧。

# 03 下決心，不要想「or」而要想「and」

準備考試、一邊工作、懷第三胎，三管齊下

「妳竟然能邊帶小孩邊留學哈佛，一定很辛苦吧？」常有人這麼問我。

而我的回答一律是，「就因為帶小孩和留學一起來，我才能搞定喔！」前面提過「懷第三胎的時機」與「想留學的時期」恰巧重疊，事實上生第三胎與留學時機重疊，是我「算計」好的。

我當時已經下下決心去留學，但即便真的拿到了留學門票，必須向主管說：「我要去留學了」，也不能確定主管會點頭答應。而我自己也沒信心能兼顧工作與留學。

我曾經若有似無的對主管表示想去留學的心願，不過當時的主管對我說，在國內累積經驗要比出國留學更有意義。

此外正逢婦產科醫師不足，我的同事們每天都做到鞠躬盡瘁。我明知道這種緊迫狀況還提出留學申請，似乎太自私了……然而這並不能改變我留學的決心。

於是我想到一招，就是利用產假和育嬰假。日本法律允許產婦在生產前後最多請十四週的產假，而且產後可以請一年的育嬰假。只要利用產假和育嬰假留學，事情就簡單多了。

感謝老天，讓我順利懷了三女兒。

我在準備考試的過程並沒有對同事們說起，直到哈佛寄來錄取通知，我才拿著它去找主管請產假和育嬰假，並說明我的留學計畫。「我真是敗給吉田醫師了。」上司也不禁苦笑，接受了我的留學申請。

當初我想在育嬰假期間取得畢業所需的學分，回來之後再恢復原職，但無法確知回國的日期，卻要診所保留職位，這樣實在太不負責了，所以最後我選擇了光榮辭職。

我能實現留學夢，就是因為念書留學與懷孕生子同時進行才能做到。想做兩件事，乾脆同時進行，才能兩全其美。

# 同時做，一起搞定

人生經常被迫做出各種決定。女性通常煩惱的是要結婚或要工作，要事業或要家庭；男性也會想在工作之餘，再回大學或研究所進修吧。

我想無論男女，都有人煩惱著該如何面對現實工作，或是追求兒時夢想。其實我到大學演講時，也有學生問我「該如何考慮事業規劃與人生規畫？」當我聽說有人煩惱該選「A或B」「C或D」，我便毫不猶豫地建議：「先別考慮or，想想看有沒有and的路子吧！」別想著要先實現哪個夢，而是去想怎麼同時實現所有的夢才對。

同時想做很多事，卻要一起實現，聽起來或許很辛苦，但很多時候分開來做反而困難，一起做更容易成功。

像我準備留學並不是等辭掉工作才開始，或者請假之後才開始，而是平時與工作同時進行。我在第一線努力的同時準備留學，因此在治療病患時，也謹記著自己要留學的目的，讓我可以持續維持高昂的鬥志。

我想不少女性請育嬰假帶小孩，是爲了專心帶小孩。這是很了不起的事情。不過，我呢，正因爲有「下午六點半一定要到托兒所接小孩」的條件限制，才能提高工作上的專注度。

靠著專心工作，排除帶小孩產生的煩躁，而工作上的壓力，在孩子的笑容中化爲雲煙。就是這樣往來於育兒和工作之間，我才能夠喘口氣。

事實上，的確有不少事情是同時進行反而能兩全其美。像是：

- 不少上班族都很努力投入喜歡的運動與興趣，既鍛鍊體格也磨練心性，而且每天都過得充實飽滿。
- 此外，也有不少女性累積了一定的事業後才想要懷孕生子。身爲婦產科醫師，我看過不少病人，特別是許多女性理首於工作，一不小心就過了生育年齡。

而我認爲同時投入事業與生育，兩全其美的機率會比較高。

如果爲了「or」而煩惱，就想一想能不能「and」。

不要想著二選一，而要思考如何雙管齊下。

# 04 甚至在雙管齊下的奮鬥過程中，再投入其他「想做的事」

正因為工作與家庭兩大任務幾乎把我累垮，準備資格考、學英文、玩運動的充實感才能讓我從壓力中解脫。

正因為有「不得不做的事」，才要靠「想做的事」來解脫。

正因為專心投入「想做的事」，「不得不做的事」帶來的痛苦才相形渺小。

在不同的事情交替刺激下，更能讓鬥志昂揚。

想要達到這個境界，我認為必須横跨多個領域，增加廣度，才有更多放鬆的機會。

# 「亂成一團」是一定的！

# 不要期待做到「工作與生活平衡」

同時進行多件事還要順利成功，訣竅在於有「亂成一團」的心理準備。

例如公事與私事兩全其美，就是「同時進行」的範本。或許不少人會認為，公私應該分明？沒錯，白天是公事，晚上是私事，清楚區分時間和空間，心情會比較輕鬆。

但要是分得清清楚楚，就很難同時進行了。

有個詞叫做「工作與生活平衡」，我覺得其中大有問題。因為要讓工作與生活平衡，就必須工作與生活壁壘分明，像是放在天秤的兩端，強迫自己保持兩邊的平衡。

說實在的，工作與生活真的可以壁壘分明嗎？

以我來說，在晾衣服的時候會想著怎麼回覆某人的電子郵件，也會利用診所午休時填寫小孩托兒所所需的文件，甚至在工作空檔會突然想到：「對了，忘記檢查給消費合作社的訂單啦！」回到家，笑著陪孩子玩，但心底仍掛記著白天主管吩咐的事，思考該怎麼解決……

「幾點到幾點上班」「幾點到幾點帶小孩」真的很難涇渭分明。有時候會埋首於工作，趁空檔時處理私事；有時也會將私人時間拿來考慮公事。聽起來好像很混亂，毫無章法。

但就因为變成一團，才能雙管齊下。正因為難捨難分，才能兩全其美。

舉個例子：前些日子，透過演說認識了一位大學生A，他寫了封電子郵件給我說：「可以討論研究所的事情嗎？」無論公私，我都愛幫別人忙，所以回信說：「我很榮幸能與你討論！」但平日我們倆的時間怎麼也湊不起來，我方便的時間，A同學要上課；A同學晚上才有空，但我卻得去托兒所接小孩。

於是我提議：「就選在星期天，我家附近的大學碰面。」因為當天該校舉辦校慶，我可以放小孩到處玩，同時與A同學討論，而且第一次見面選在歡樂的場合，A同學的心情應該比較輕鬆，孩子們也能放心玩。

當天我讓孩子在看線範圍內玩耍，同時與A同學討論。不出所料，雖然孩子們沒事就打斷我說「口渴了！」「要上廁所！」但目的依然圓滿達成。

又有一次碰到媒體來採訪，但孩子碰巧發燒。當時我就把採訪地點改到家裡，邊接受採訪邊為孩子準備草莓牛奶……同時工作與照顧小孩。

「照顧小孩」與「跟A同學討論」、「接受採訪」與「照顧生病的孩子」，如果分開進行會比較輕鬆，也能更加專心。

但，想找到大家都方便的時間分別進行，可不容易。要同時進行，才能一次搞定。這就是「and」的思維。

# 享受「亂成一團」，就能提高層次

學英文之類的情況也一樣。心想等有時間再去上英文會話課，總是抓不出時間。然而在通勤或跑步時耳朵沒事做，卻知道要打開pod，戴耳機聽音樂。

利用空檔學英文，就要與生活、工作融為一體，絕非「幾點到幾點學英文」，而且比等待時機上英文會話班，更能盡快展開學習。

同時進行，就要有亂成一團的心理準備。

「總覺得行程好像有點混亂」「不勉強分得清清楚楚」這樣也不壞。當你覺得「亂成一團也挺有趣的！」就能同時進行所有想做的事。我真心這樣認爲。

# 「散漫的估算」是一切的起點

經常有人問我：「穗波女士爲什麼可以一邊工作、顧家、帶小孩，還能準備留學？」

關於這問題，在後面章節會仔細說明。但我其實是真的有些調度時間的小妙招，把擠出來的時間用來準備考試。不過，說到開始念書的最大理由，卻是「不小心就開始了」。

這是實現理想的訣竅之一。不對，如果我這人不草率行事，便什麼事情也辦不成，所以或許該說草率行事才是一切的起點。正因爲我有先做再說的行動力，才能實現理想。

有全職工作，有家事要做，有小孩要帶，怎麼還能找出時間念書？因爲我從來沒有仔細想過，考取理想的研究所需要念多少書，就只是一個「想留學！」的念頭，便讓我翻開了書本。

一個草率的行事的人，腦袋裡總想著沒問題、不危險。這種「散漫的估算」與我的「草率留學準備」是一樣的道理。

雖然不是簡單的事情，但船到橋頭自然直。在打算開始做什麼事情，或挑戰新領域時，「船到橋頭自然直」的散漫估算、樂觀主義，是一項強大的武器。

其實我在前一段研究所生涯中，就已經實踐了這種「散漫的估算」。我從三重大學醫學院畢業後，前往東京都中央區的聖路加國際醫院實習三年，之後又考上名古屋大學的研究所。

當時我白天是臨床醫師，傍晚下班後在研究所鑽研課題與研究專題，所以我認為，這次出國留學只要夠拚，應該也能船到橋頭自然直吧。

沒想到……這次反而被「散漫的估算」給坑了。

哈佛公共衛生研究所的學習生活，遠比想像中還艱苦啊！每天緊鑼密鼓的課程，分量沉重，沒課的時間全都得用來預習、複習、寫作業……完全可以照往例撐過去」的程度。

事後回想起來，雖然「散漫的估算」讓我吃盡苦頭，但仍是帶領我前往哈佛的「起點」。這麼一看，「散漫的估算」確實會帶領我們前往意想不到的境界。

# 只要動手，就會找出時間

草率，採取行動。只要事情一開始運轉，時間就會跑出來。這是我以身試法學到的結論。

我一天二十四小時都耗盡了，哪有時間再多做點什麼？

你是否有這樣的遺憾？前面說過，我原本也是這樣的人。

但就算沒時間，還是會有其他想做的事情。

既然如此，就先往想做的事情踏出第一步吧。五分鐘也好，十分鐘也好，先往小地方跨出一步。

想學會英文，就先報名托福考試，買題庫寫個一頁，背一個英文單字。

別等到條件齊全，時間充裕了才開始，先動手就對了。先踏出小而確實的一步。

別等有時間了再起步，只要動手，就會找出時間。先動手做了一點點的事情，自然就會擠出時間繼續做下去。

我剛進入哈佛之前不久，就去上了一堂時間管理課程。我對「時間管理」這個課題饒有興趣，課堂上最令我印象深刻的一句話是：「There is not the information that is enough to begin something. Anyway, let’s begin it!」（不要長會有足夠的資訊讓人開始做事，直接動手就對了！）

翻書書時記在筆記本上滿字的一句話，我大感驚到自己的思考邏輯問題，它說起於「直接動手就對了」。
