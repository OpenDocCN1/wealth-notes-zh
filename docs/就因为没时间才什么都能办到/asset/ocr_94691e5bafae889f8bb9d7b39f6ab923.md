# 13家事不要「五五分」

「比」教育」老公更輕鬆的方法

夫妻之間最容易發生爭執的原因之一，應該就是家事如何分擔了。

根據日本厚生勞動省（相當於台灣內政部）發表的「平成二十三年版 職業婦女實錄」，可讀到以下的內容：

在擁有未滿六歲之幼兒的雙薪家庭中，妻子每天的家事處理時間為五小時三十七分鐘（其中育兒時間為兩小時八分鐘），丈夫的家事處理時間為五十九分鐘（其中育兒時間為三十分鐘）。

同樣是擁有未滿六歲之幼兒的家庭，若男方有工作，女方為家庭主婦，妻子每天的家事處理時間為八小時四十分鐘（其中育兒時間為三小時五十分鐘），丈夫的家事處理時間為五十九分鐘（其中育兒時間為三十四分鐘）。
