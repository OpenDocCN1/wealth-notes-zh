# 父親的身教：邊折尿布邊讀論文

我爸爸即使忙著帶小孩，也能充分運用零碎時間。

我父母都是大學教員，因為生在雙薪家庭，所以我出生後四十三天就被送進托兒所了。那時候沒有現代這麼便利，尿布還是布做的，托兒所自然也也都使用布尿布。

聽說每天早上去托兒所，爸媽都要先把自己孩子使用的尿布對折再對折，放進櫃子裡。以嬰兒用的尿布來說，應該至少有十幾條吧。

多年以後，從托兒所同學的媽媽那裡聽說，我爸爸在折尿布時，還把論文放在地板邊邊折邊讀。眼睛看著文章，雙手沒停的折尿布。

現在我雖然已經擺脫準備留學時那樣的忙碌生活，但走在診所的走廊上，或是從托兒所衝往車站的路上，我也都在思考著論文內容，或者邊吃午餐邊念書。

在這種時候，我腦子就不時會出現爸爸邊折尿布邊讀書的身影。
