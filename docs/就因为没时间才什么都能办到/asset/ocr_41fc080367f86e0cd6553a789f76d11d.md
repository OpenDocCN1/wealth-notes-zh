透過網路提交論文、托福成績單等文件，依內容判斷考取與否。當時我報考了四間研究所，涵蓋哈佛在內，而必要的文件都大同小異，包括：

+   申請書

+   托福成績單

研究所方面會以托福成績判斷考生的英語能力，科目包含閱讀、聽力、口說、書寫四項。四科滿分一百二十分，想報考哈佛必須拿九十分以上。

+   GRE成績單

GRE是美加地區研究所的共同入學考試，有數學、英文、論文三科。報考哈佛研究所需要一千分以上。

+   小論文

+   推薦信三封

我拜託實習時期的醫院醫師、國內大學與研究所的恩師為我準備。由於老師們都很忙，我並不請他們撰文，而是自己先打好草稿，再請老師修改。
