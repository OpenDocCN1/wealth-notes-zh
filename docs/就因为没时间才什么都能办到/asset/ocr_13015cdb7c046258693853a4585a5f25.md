# 第一步最耗力氣

總之先動動手腳，踏出第一步。

雖然第一步要費很大的力氣，但習慣之後自然就能持續下去，而且不需要花太多力氣。

我這人做什麼事起頭都比別人慢，還經常發呆，在實習期間就有位學長為了鼓勵我說：「靜止時的摩擦係數比開始運轉後的動摩擦係數更大。」這句話我一直銘記在心。就物理定律來論，由靜轉動的瞬間所耗的功是最大的。而這不就是俗諺所說的「萬事起頭難」嗎？
