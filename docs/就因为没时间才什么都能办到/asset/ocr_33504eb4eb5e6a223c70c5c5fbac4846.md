# 克服棘手的數學從「一本書」下手

這表示英文能力要非常好。我有個朋友就建議說：「最好用數學拚輸贏。」GRE 的數學水準相當於高中程度的數學，靠數學搶分要比正面迎戰困難的英文有利多了。

話雖如此，我最後一次念數學是十五年前的事情了，而且我本來就討厭數學。最讓我洩氣的是，我雖買了 GRE 的考古題，卻幾乎完全看不懂。

我只好向數學高手老公討救兵泣訴：「完全看不懂啦！」他便從基礎開始教我。我丈夫也經常早睡早起，在自己的書桌上辦公念書，所以我都趁著清晨孩子
