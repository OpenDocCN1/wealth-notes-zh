# 「小壓抑」比大麻煩更礙事

□ 孩子的鞋已經不合腳了

□ 想給家裡換新棉被

□ 大女兒一直唸「○○欺負我！」

這些事情都沒有須立即處理的壓力，所以時間窘迫時都順延處理。

孩子說「誰誰誰欺負我」，其實相當常見。跟同伴吵架是孩子成長的必經之路，当孩子抱怨與誰的關係不順利時，基本上我都只傾聽孩子訴苦，讓她覺得「媽媽知道我很傷心」就好。

但話說回來，如果孩子對同一件事情抱怨多次，而且內容聽來有點異樣，那我就會煩惱不已，但通常都不是什麼大事，所以我會先不處理。

像這種心頭上很在意，或者會有點抑鬱的事情，都該列成清單。

會這麼說是因為我在輔導員培訓課學到了一件：「小壓抑會奪走超乎想像的大能量」。
