# 限制「只有這裡」「只有現在」更能專心一志

「只有這個問題」「只有這個地點」「錯過就沒機會」看起來是很嚴苛的限制，但其中卻隱含著提升注意力，增加速度的大優點。

我認為念書也是一樣的道理。

比方說我念高中時，嘗試過很多不限時間地點的學習法，包括可以自由選擇何時聽CD做英文聽力訓練，以及可隨時練習、內容可增減的題庫，但總是失敗連連。但等我有了孩子、出了社會，「耳朵有空的時間」被侷限在通勤等特定時段，反而有了「此時不聽更待何時」的感受，而利用Pod聽英文，效果倍增。

念書要持之以恆，最好的方法是限制「時間」「地點」與「同伴」。

我結束美國留學，返國後開始透過視訊方式來修習輔導員培訓課，這個課程每星期一到兩堂，每次一小時，同時會有好幾位學生一同參與。

不少人問過：「一邊上班一邊帶小孩，竟然還能參加輔導員培訓？」「但其實若是只有我一人上課，應該很難學得好吧。
