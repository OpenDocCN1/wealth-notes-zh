# 如何籌措每年四十萬的健保費

另一個叫人難以想像的問題，就是健保費。

剛到美國時大女兒三歲，二女兒一歲，三女兒一個自大，小孩子容易生病，所以必須加入健保。

其實在前往美國之前，我已研究過健保資訊，但當時只知道「哈佛學生必須強制加入哈佛大學健保，金額比民營保險便宜很多」。畢竟當時沒有資訊可以比較美國的健保細節。

到了美國，在開學典禮上收到新生手冊後，我才知道「便宜很多」的比較標準，是基於全美健保的家庭年支付額為四十萬台幣左右。

哈佛大學提供給學生的健保保險費，單單我一個人每年是九萬台幣，但全家每年大約要四十萬台幣。

這根本付不出來啊……我立刻面臨了出乎意料的經濟難題。

我到處打聽有無方法節省健保費，找了大學學務處，沒有好消息，再加上前
