# 先把時間安排給「大石頭」

各位可有聽過「大石頭理論」？

這是說，如果你手邊正好有幾顆河岸邊常見的大石頭，以及十杯的小石頭，還有一袋細沙。除了這些之外旁邊還有個空桶子。

如果要在桶子裡裝進最多的石頭和細沙，應該怎麼裝才好？
