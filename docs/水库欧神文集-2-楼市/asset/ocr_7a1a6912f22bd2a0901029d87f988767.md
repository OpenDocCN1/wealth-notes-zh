# 二) 问题之症结

你发现问题之所在了么。
当一个男人跳进商店，他根本不会考虑别人的想法。根本不会考虑女人们的价值观。他选的是自己喜欢的商品。

| 得分 | 男人 |
| :---: | :---: |

| B | 2 |

也就是这棵决策树中，他是竖着长的。
在男人眼里，他就是选择 ABCD，他就是选最好的。所以他会买 A 回家。
同样道理。女人购物，她就会选 B 回家。
