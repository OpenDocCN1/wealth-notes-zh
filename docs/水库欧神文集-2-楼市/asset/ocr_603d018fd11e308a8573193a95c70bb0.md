# 四） 开拓的鸡汤

开拓很难。只要踏入荒原一步，就是十倍的辛苦。

有些人，在老巢大本营，如鱼得水，过得象地头蛇一样。可是只要一旦脱离主场，马上陷入人生地不熟，水土不服的境界。

我们做生意的，一定要分清楚“耕耘”和“开拓”的区别。二者的含金量是完全不同的。
