# 一）逻辑难题

和傻空辩论讲道理，是一件很困难的事。因为他们的逻辑断层太多，多到了难以批改作业的程度。

譬如一篇典型的傻空作文。写到了“因为 A，所以 H”的分析。

他是这样写的：A->B->C->D->E->F->G->H

但是你 和他说，A->B 是错的。加营业税并不能抑制房价，反而会使房价更高。B->C 也是错的。房价更高并不会使国际热线加快流入，反而会使投资流出。

所以 A-“Not B”-C，
也就是 A 到 C 的逻辑反而是顺畅的。贞贞得正。
唉，这都什么事啊。
