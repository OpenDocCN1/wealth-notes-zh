# 炒房客流派（八）----失败者 #520

Q：为什么没有豪宅别墅流。

A：亏钱有流派么？

一）贵妇

前二天，一个贵妇追着我满世界的骂。

如果Singlish不是太退化的话，她的意思大致是这样的：

“我朋友房子海德公园，那是富丽堂皇Royal气派，你哪比得上”。

“我买房子一定汤匙一品，No.1才是高大上”。

“呸，你那些贫民窟老破小。姐姐根本踏足不进去。一口水喷在屏幕上”。

我冷冷地看了她三秒钟，“你是媳妇么”。

你是媳妇么。你这辈子赚过钱么。

不知道是你老爸牛还是你老公牛，你本人这辈子赚过钱么。

你这辈子除了花钱，你懂得怎么赚钱么。

这个姐姐的本事，就是劈着又跨着腰，指着那里骂：“姐姐的房子比你好”。

花钱的事谁不会。

我们是在比谁的房子更好么。大小脾气谁不会。

我们是在比谁的房子“能升值”。

在过去五年，英镑的汇率跌了有近40%，而海德公园的房子还涨不到40%。

你去买，那不是豪宅。那是耻辱。

你不是贵妇，你是婊妓。
