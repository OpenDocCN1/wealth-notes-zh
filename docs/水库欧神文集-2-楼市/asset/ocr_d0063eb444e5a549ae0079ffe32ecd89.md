# 二）涨幅

浦东涨不动。

时至今日，我不明白为什么还有人喊：“浦东涨幅快”（“浦东涨幅远超浦西”“LZ 错失大牛市”）。

过去的十五年中，涨幅最高的，或许是桃浦万里板块。许多人不知道这个地方，在上海铁路西站附近。紧贴着铁路线以北，是上海著名的脏乱差地方。也完全没有任何小白领屌丝涌入。

万里的涨幅，大致是 1999->36000，十五年涨了 18 倍左右。
