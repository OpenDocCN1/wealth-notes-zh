# 四）租赁房

说回“只租不售”房源的话题。

从经济学上讲，存在三种档次的效率：

+   * 最高效率：KFS 可以选择出售，出租，甚至干脆捂地。

+   * 中等效率：KFS 建房出售

+   * 最低效率：KFS 只出租

最高效率的时候，“房价”最低。

和一般人直觉的相反，经济学是支持“捂地”的。KFS 可以自由捂地的时候，房价最低。

dT>0，同样一块猪肉，又能做糖醋小排，又能做鱼香肉丝，则饭店的收入最高。食客也最幸福。
