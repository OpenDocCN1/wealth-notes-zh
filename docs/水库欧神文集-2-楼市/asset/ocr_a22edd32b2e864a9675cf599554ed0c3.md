# 1）急跌必须要急升

纸币永远在贬值。哪怕是庞大的泡沫，过了两三年，也会缩小一圈。
所以—个没爆炸的炸弹，Maybe 就永远不炸了。

急跌必须要急升。只有在急升的基础上，半年（甚至单季）涨幅超过 +50%，这才埋下了急跌的种子。

大跌之前，必须要有暴涨。如走势平稳的 2016 夏 ~ 2017，我们认为暴跌的可能微乎其微。
