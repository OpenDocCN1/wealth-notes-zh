# 二）泡沫阶段

楼市的第四个阶段，是泡沫阶段。

在《[泡沫分水岭](#链接)》#1080 一文中，我们曾经说过。

+   我们并不认为 100000+的房价是合理的。而认为是有泡沫的。

+   有泡沫不代表不涨。

+   2000~2013 是上半场，2013~2026 是下半场。

如果楼市产生了“赚钱效应”。老百姓前仆后继地涌进去。

今天不买，明天就再也买不起了。

别和我说调控，我买来自住得。

别和我说睡大街，你有汤臣一品么，你有别墅么，你有好房子么。那“改善”需求还很大。

问题问，这样一股热潮，到什么时候终止。

答案是：当人民再也买不动的时候。

象目前的上海市场，就有一点“涨不动”的味道。
