# ## 不征房产税，凭什么为什么 #1120

# ### 错误的舆论：

+   * “土地不是私有的”
	* “要开人大了，改法律土地私有。然后就可以开征物业税了”。
	* “虽然要征物业税，但是土地变私有了。我想房东也是乐意的”。

# ### 正确的逻辑：

+   * 世界上根本不存在“财产税”。
	* 没有土地才需要交税，有了土地才不用交税。“正向”资产。
	* 能保护你的，是宪法。而不是投机取巧。

# ### 一）社会契约论

18 世纪，卢梭提出了“社会契约论”。

之前的二千多年，都是农业社会。实行的是“绝对君主制”。皇帝拥有无限的权力。到了工业革命之后，需要一种新的社会组织方式，以及生产力理论基础。

“社会契约论”是现代社会的运转基石。几乎所有的现代化文明国家，都依赖于此。
