一）流派终结者

在前面的文献中，我们说道了炒房客的八种流派。如果将他们分类一下的话，请问你会分几类：

| 资产流 | 人力流 |
| :--- | :--- |
| 大面积低单价 | 老破小，最低总价流 |
|  | 法租流，民宿流 |
|  | 药单，法拍，银主流 |
|  | 周转流 |
|  | 使用权，小产权流 |
|  | 癫癫流 |
|  | 转租流 |
|  | 贵妇流 |

答案是二类。他并不是 4+5 的分配，而是 1+8 的分配。

为什么，因为我们首先要问你一个至关重要的问题：

“假如上海楼市彻底崩溃，你会破产么”。
