# 三）CEO 盘的含义

CEO 盘的特征是什么呢。譬如附近普通的地段均价是 30000/m，你卖 40000/m，那不叫 CEO 盘。只能叫高品质溢价盘。

CEO 盘，你要卖 80000.

在八万的基础上，普通人基本不会关心了，当笑话看了。那你售楼处也不会拥挤。大可以高档香薰泡二杯金骏眉，请贵妇慢慢赏鉴。

当一个楼盘达到了“市场价二倍”以后，他最紧需的是 IB 格。性价比可以很低，但是 B 格一定要高。
