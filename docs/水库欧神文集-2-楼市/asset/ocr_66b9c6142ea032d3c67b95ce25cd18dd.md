# 炒股业黄金时代 #930

2009 年我认识了一个红衫资本的 MD，到 2012 年再见面时，他颇为同情地说：
“这二年政府限购限贷，管制最严，炒股业的日子不好过吧”。
我惊异地说，“没有啊，2010-2013 是炒股业最好赚的日子。堪称黄金时代”。

# 一）禁酒令

铅笔盒有一系列的文章，关于美国 1920 年代的“禁酒令”[1]。当时，出于一些宗教信仰，女权，反德意志等原因，各基督教团体联合推出了“禁酒令”法规。
禁止 USA 酒类的制造，贩卖，出售等等。

+   禁酒令完美地达到了以下效果：
1) 喝酒的人更多了
2) 喝出病的人更多了
3) 酒商酒贩赚到了更多的钱
4) 黑帮泛滥

这件事乍一看，颇为令人困惑。但如果我详加阅读“禁酒”系列文章的话，你应该学会从
“二阶经济学”的角度去思考。
