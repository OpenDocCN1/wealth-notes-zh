# 您在食物上花费太多吗？

无论您用一美元购买了多少食物，如果它不含有一百分的食物营养价值的话，那么您就花费太多了。桂格燕麦片比您可以购买到的其它任何食物的营养价值都高，并且花费的金钱更少。
