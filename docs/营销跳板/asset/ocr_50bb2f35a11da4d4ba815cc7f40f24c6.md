# 心脏病

症状:

心脏的颤抖和悸动;

心脏的疼痛或者压抑;

胸口不舒服或者产生压;

抑之感;

无法侧躺侧卧;

轻微运动之后便呼;

呼吸痛苦或困难。

脉搏跳动不规律;

虚弱，晕厥；吸困难;
