# H型号使用的低压磁发电机和电流断续器优势
斯图贝克汽车
“有名誉的汽车”

在过去的一个季度里，我们已经充分地证明了，我们新型号II汽车中所使用的点火系统绝对是可靠和有效的。

在使用我们的低压磁发电机为电流断续器提供电流时，只需要不到两尺的接线就可以了，并且，短路问题得到避免，火花塞的烦扰也被消除了。

我们为电流断续器提供电流而使用的西姆斯—博世牌低压磁发电机，可以为每个汽缸提供极大极热的火花。

我们点火系统中的所有控制机构都位于汽缸的顶部，很容易接触到。

这是与最近范德比尔国际公路比赛中获胜车辆使用的同_类型的磁发电机，并且我们发现，斯图贝克汽车的齿轮在驾驶过程中，它的服务实际上是完美的。

斯图贝克汽车的每一个零件都是经过长时间的、努力试验的结果。我们的改进全部都是为了更优质的服务，而并非为了广告推销。
