# 尺寸增加 10%

由于无损耗钢轮胎拥有额外的魅力，所以在尺寸上可以增加 10%。我们便这样做了。那也就意味着多 10%的空气—多 10%的承载能力—可以承受对于 90%其它轮胎而言超载的额外部分。

在汽车满载之后，普通尺寸的轮胎一般情况下负荷都会超过预期界限。而那就是大部分爆胎的原因。我们的超大号轮胎，对于一般的汽车而言，平均都能增加 25%的轮胎英里数。这两种特点放在一起—无损耗钢和超大号—通常情况下都将轮胎的坡面一分为二。

然而，如今，无损耗钢轮胎的售价并不比任何标准规格的有轮钢切损的轮胎要高—非加大尺寸的轮胎。
