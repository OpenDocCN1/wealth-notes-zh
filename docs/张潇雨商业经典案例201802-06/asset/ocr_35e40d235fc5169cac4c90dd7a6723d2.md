# 【加餐】巴菲特｜我们不该跟巴菲特学什么？

投资要趁早，投资的手艺需要的是时间积累、一夜暴富，100%的 人曾经这么想过，结果100%地失败，即使运气好成功一次，一样守不住财富，也会挥霍一空。想要获得投资的成功，需要时间来积累，和你选中的公司一起成长。错误在其中在所难免，早犯错好于晚犯错，受到的损失不一样。好的方式是和自己的孩子一起练习投资，这远比给他买一套房子更有意义。

今日学习心得：老师这篇文章虽然是“不该跟巴老学习什么”，但我还是认为这些是学习的点。拿巴老教GEICO这个案例来说，他带给GEICO的是全身经脉的打通，真正是在救一家企业。当然他有获利的心无可厚非，但是放在资本世界里，这游戏的规则是，我短期内帮你，我给你人脉，给你钱，给你势能，一赚钱钱我就撤了。所以很多经过资本洗礼的公司在后面都垮了。

# 【加餐】巴菲特｜我们应该跟巴菲特学什么？

如果我们把投资比作奥运会，那么巴菲特、芒格和他们的团队就是最聪敏、最专注、最勤奋的运动员。当这三个元素聚集在一起，就会产生奇迹。

我们有很多其他领域都能看到这样的例子，年轻的“飞鱼”菲尔普斯很早就有个雷打不动的习惯，每一天都保证在水下训练六个小时。他也被称作天才。也许人们都很喜欢用天才来解释一些超出人们想象的成就，但是其实最关键的因素往往是超乎人们想象的专注和勤奋，当事人对自己近乎苛责的严厉，以及他们放弃的很多很多乐趣。

人生有时是很难奈的，要想获得各个领域的平衡，可能就很难成为一个领域的顶级天才。我还是喜欢看到那些能够在人生的各个层面都获得圆满和平衡的人。专注而勤奋，也懂得适度和平衡，也许是真正的智慧，因为那样的人生，快乐会来自各个层面，交融在一起才会更加深刻、丰富、长久。

巴菲特的第一个妻子苏珊曾经安慰巴菲特的孩子说，你们要懂得理解你们的父亲，他只能给予你们这么多。纵然富可敌国，却不能够给自己的孩子真正心灵上的陪伴，赢了世界的巴菲特，不知是否会觉得德尔失落呢？

但是我们每一个人都要学习这样的专注，不管在人生的任何领域，专注都会给予我们极大的动力，也会产生美好的心流。当然，我们也要懂得去学会平衡取舍，找到最恰如其分、最适合我们自己的圆满格局。

今天的文章特别有收获：

+   1. 不片面强调事物的某一方面。正如专注是一种好品质，但人的时间和精力有限，专注于做事情就会忽视生活中的其他部分。我感 hall 觉理性状态是：看到一件事情的正面，同时想到它的反面，具备同时想到两者的能力，作出合理的决策。有时事情的两面都没有对或错，区别仅仅是有一定的选择会更适合一点。

+   2. 简朴的精神作用。保持简朴有两种精神作用，一种是如老师所说，可以降低精神享受的阈值，稍微的消费就会带来满足感，但是这个阈值可能会随之提升。如果不控制，就会变成“渔夫和金鱼的故事”中的老太婆。保持简朴的另一种精神作用应该是让心情平静，很多出家修行的人之所以遁世而居，就是不让自己的心境被“尘世繁华”所诱惑。我感觉心情平静对于思考非常要，情绪会导致很多错误决策。

+   1. 吴伯凡老师说，管理就是剔除一切不创造价值的环节。这对企业管理、个人管理都具有非常好的指导意义，巴菲特老爹于个人管理上就完美验证了这句话。
