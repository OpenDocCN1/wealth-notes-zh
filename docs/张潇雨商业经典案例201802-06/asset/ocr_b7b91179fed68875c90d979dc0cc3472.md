# 周末互动 | 拼多多：社交电商要实现了吗？

周末互动 | 拼多多：社交电商… ↓

你好，欢迎来到《商业经典案例课》的周末互动。我是张潇雨。

不知道听完这周的专栏你有没有受到什么启发。本质上，这一周围的文章算是给我们之前讲过的这些大公司做一个总结和延伸。

之前我们基本是以单个公司为单位来讲述的，而当我们熟悉了解了这些公司的创立过程、商业模式、经营方向等这些背景信息之后，再来横向地把它们放在一起看就会更有意义了。

商业从来不是孤立的，任何一个市场和行业的发展与前进都是这个领域里主要的玩家们互相博弈，相互促进——也就是我们说过的“竞争”——在这种竞争的力量之下形成的结构。所以在专栏开始进入到最后部分的时候，希望你能够学会以这种动态的视角来看待商业。

这周的周末互动我想给大家推荐两篇文章，这两篇文章当然有些关系。在这周内容里我们没有提到和我们最息息相关的两家科技巨头——阿里和腾讯，所以周末互动里我就给大家留个小作业，去看看我推荐的这两篇文章，看看阿里和腾讯这两家公司在未来会有什么新纠纷，而这对我们生活的影响会有那些。如果看完了你有什么感想，也欢迎在专栏后给出我留言。

这两篇文章都是关于一家公司的，一篇叫做《消费降级巨头拼多多》，一篇叫做《堵截千亿拼多多，阿里与腾讯的电商新战役》。网上都很容易就能搜到。

从名字就能看出来，这两篇文章讲的都是这一年来最现象级的一家电商公司“拼多多”。

其实连我也是前几个月才真正知道这家公司的，之前只是听说过，但是没有太怎么关注。结果当时我听到了一个说法，然后彻底震惊了。那就是：拼多多如今的订单量已经超过京东了，而它成立的时间还不到三年。

当时我对这个数据非常怀疑，但后来经过多方验证，发现这个数字应该是真的。当然，由于客单价比较低，拼多多的GMV——Gross Merchandise Volume——也就是总成交额还比不上京东和淘宝，但现在也已经达到了每个月400亿的量级，也就是年5000亿GMV的量级。而京东超过1万亿，阿里全平台超过4万亿。

但是不要忘了，第一，这家公司成立还不到三年时间，目前还在非常迅猛地发展；第二，这家公司完全是依托微信生长起来的。

腾讯这些年一直想做电商，从而威胁阿里的司马昭之心所有人都知道了，所以“社交电商”的概念大家也说了很久，“拼多多”是不是真的要实现了呢？这能给腾讯这家已经足够巨大的公司带来什么样的想象空间呢？

这里面的问题我就不过多回答了，留给你看完这两篇文章之后慢慢思考。

据说现在阿里和京东已经成立“打多办”了，也就是所谓打击拼多多的专门业务部门。我想它们现在也不得不重视这匹巨无霸黑马的崛起，看来中国未来的电商行业还会有更新的变量。希望大家可以多多关注。

最后，我想给大家读一段其中一篇文章的节选，让你来感受一下整个中国发展最早、如今最成熟、看似格局已定的电商行业，又面临着怎样的变化：

2017年年底在广州举办的小程序公开课上，游戏和电商是最受关注的话题，拼多多、蘑菇街等微信官方主推案例悉数登场。

一个无法证实但在行业里流传的数据是，2017年微信生态的电商总GMV已经超过万亿了。小程序在其起到关键作用。“据说张小龙找到【蘑菇街创始人】陈琪，给他看了下小程序数据说，蘑菇街只要把微信这部分生意做好就行了，就足以做成一个大公司了。”一位行业人士对36氪说。

腾讯也在密集投资小程序电商相关的创业公司，比如为公众号自媒体提供技术、供应链、选品、售前售中售后等一套电商运营服务的SEE小店铺，就在1月23日宣布获得腾讯战略投资逾千万美元C轮融资。

业内FA机构从业者表示，基于微信流量的电商类创业公司肯定都希望获得腾讯的投资。“说白了还是看腾讯的意思，扶持哪家，哪家就是‘太子’”。

“从用户的体验出发是一个万能句，其实就是腾讯不想把流量分给你，现在有了小程序就不一样了，run来run去还是在它的体系内，所以就全力支持”。

在阿拉丁创始人史文禄看来，阿里生态之所以能崛起，是依靠拥有大量个人卖家的淘宝；小程序开放给个人，则意味着微信可以像淘宝一样，打造一个承载大量个人卖家的电商平台。“微信里本身存在转发信任，由个人形成的新电商群体迅速崛起。”

# Netflix顺风顺水，迪士尼难道大势已去？

迪士尼现在的战略更多是防御性的。如果其他的内容提供商也效仿的话，就会进一步地削弱Netflix的竞争优势。而且Netflix 不得不加大对自主内容的投入，盈利状况就会进一步恶化。迪士尼最大的竞争优势就是它的IP。从经典的迪士尼的人物，到皮克斯、漫威，甚至是世界杯，都是神级的经典IP。围绕这些IP的商业元素，比如主题乐园、电影，以及相关的玩具，一直都是持续增长。受到Netflix冲击比较大的，是ESPN体育以及ABC为主的电视网络业务。这些业务虽然盈利很高，但是和迪士尼的核心IP业务相关性不是很大。新的Streaming业务，因为在内容上的先天性的缺陷，很难形成网络效应，对Netflix的冲击不会很大。HBO前两年推出的类似业务没有对Netflix造成任何影响就是一个很好的证明。如果迪士尼等于是壮士断腕的话，不分拆或者<|message|>

我个人感觉，Disney的流媒体路线更像是对现有变现渠道的一种补充。张老师今天的问题很有意思，Disney的能力模型就是一个IP + 全方位的系统变现。这个系统本身是封闭的，是提供垂直产品的最佳结构。同时，其中的环节，比如原创IP，和系统外的环节的结合也足够紧密，同样具备平行型的基础。Disney最核心的能力，还是IP，Disney的系统更像是一个放大器，而不是具备网络效应的网。最核心的因素不是系统的产品组合，而是价值链最前端的IP。当被从价值链前端扼杀掐断之后，会受到巨大冲击。所以后续的转型，如何利用优势丰富自己的IP是后续转型的关键。Disney最后也许会选择开放的垂直型的转型路径，张老师前几节课程复盘任天堂switch中提到创意，要保护小。如果Disney的赚钱机器这个庞大的平台，能够允许小创意在平台上孵化，那么无论怎么样的高昂掏人，都很难动摇Disney的根基。
