# 护城河理论 …

有的企业会拥有一些很特别的东西，这些东西很难被人们模仿，可以长期作为竞争优势存在。这些东西就是企业的护城河。比如京东的物流体系，Facebook的网络效应。

--出自: PayPal | 护城河理论之 "网络效应"

# 价值投资理论 …

当我们投资一家公司的时候，本质上购买的是它未来的赚钱能力。

--出自：里马遗 | 公司价值的本质——自由现金流

# 长线思考 …

如何判断一件事情值不值得做？想想这件事情10年以后的价值，如果依然很高，那就值得。这就是长线思考。

--出自：里马遗 | 居安二十年的长线思考

# 飞轮效应 …

一个公司的各个业务模块之间，会有机地相互推动，就像咬合的齿轮一样。一开始从静止到转动需要花比较大的力气，但每一圈的努力都不会白费，一旦转动起来，齿轮就会转得越来越快。这就是飞轮效应。

--出自：里马遗 | 三大支柱业务与“飞轮效应”

# 第三空间理论 …

人们需要有非正式的公共场所，把工作和家庭的忧虑暂时放在一边，放松下来聊聊天，这个场所就是“第三空间”。比如德国的啤酒花园，英国的酒吧，美国的星巴克。

--出自：星巴克 | 第三空间与社区精神

# “跨越鸿沟”理论 …

一个产品在从小而美走向主流大众的过程中，必须要跨越一道鸿沟，这个鸿沟就是主流用户和初始用户的差异。如果产品不能转变为满足主流大众的需求，就有可能死掉。

--出自：小象局 | “跨越鸿沟”理论

# 炫耀性消费 …

有对于有些人来说，光有钱是不足以满足自己的荣耀感的，还要证明给别人看才行。为证明自己有钱而进行的消费就是“炫耀性消费”。“炫耀性消费”的目的不是消费，而是把自己跟别人区分开来。

--出自：奢侈的受难 | 炫耀性消费与“有闲阶级”理论

# 占优策略 …

竞争中避免要根据对手的举动来制定策略，但如果存在一个，无论竞争对手做什么，你都能保持不变的策略，这个策略就是“占优策略”。比如你是零售商，你的策略是把“多快好省”这四个要素占全了，那么无论对手做什么你都可以按兵不动，因为它逃不出你的手掌心。

--出自：里马遗 | 从“多快好省”到“占优策略”
