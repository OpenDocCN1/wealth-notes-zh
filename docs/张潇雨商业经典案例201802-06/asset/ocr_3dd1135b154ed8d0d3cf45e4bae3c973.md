# ｜巴菲特和芒格的第一次合作

雷克希尔曼-科恩是一家位于巴尔的摩市中心的百货公司，当时这家公司的老板科恩家族和一些主要股东都想出售自己的股份，后来他们就找到了巴菲特。

于是巴菲特拉着芒格一起飞去了巴尔的摩，到了那里之后，他们立刻喜欢上了科恩家族的人。这家人简朴、正直、城实到处都有他们的熟人，虽然很有钱了但是还是开着一辆小破车。
