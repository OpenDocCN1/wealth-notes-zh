# 周末互动｜宣布一件关于毕业的小事

周末互动｜宣布一件关于毕业小事 ↓

你好，欢迎来到《商业经典案例课》，我是张潇雨。这周的周末互动我们来宣布个小事情。

我们的专栏写到现在，正好离结束还有4周时间。在结束之前，为了检验大家的学习成果，当然更重要的是让大家都能够参与进来，我给大家准备了我们课程的最后作业——《商业经典案例课》的毕业论文。

其实这个毕业论文的概念也很简单，就是让大家简单地做一次案例研究，然后把研究成果写下来，讲给所有人听。

从我自己写作这个专栏的经验来看，这是一个很好的学习过程，也能让你把这一年讲到的很多东西串联起来，所以我希望大家多多参与。

关于这次毕业论文的具体要求是这样的：

我们的主题是：选择一家专栏里没讲过的公司，从分析商业案例的角度，写一篇案例报告。

形式完全不限，可以是我平时专栏的文章风格，或者你自己觉得合适的风格都可以。

字数的话不要超过3000字，往下没有具体的限制。不过以我的经验来看，1500-2000字以上的体量是个下限，这样才能把一件事情说清楚。

如果你没想好选择哪家公司来写，我给大家提供几个方案：英伟达、Lululemon、Zara、Warby Parker 和周黑鸭。

这几家公司的业务大家相对都比较熟悉，网上能找到的资料也比较多，只要稍微做一些研究应该都能写出东西来。当然，你也可以选择自己比较熟悉或者喜欢的公司来写，这些只是给你们做个参考。

另外，我可以给你们提供一些分析的角度，可以从下面这些切入点来分析这些公司：

+   1. 这家公司的早期创业历程：它是怎么发展起来的？
2. 公司发展中经历了哪些变化和转型？
3. 这家公司犯过什么错误？为什么会犯这样的错误？
4. 这家公司的主营业务是什么？利润主要来源于哪些业务？
5. 最近的几年，这家公司有哪些关键决策？是否有背后的商业逻辑支撑？
6. 在你看来，这家公司未来会怎么样？你看好或不看好的原因是什么？

我要说明一下，你在毕业论文里不需要把上面这些角度全部覆盖到，毕竟我们文章篇幅有限。我觉得能把其中的一两样讲清楚就好了，具体从哪个切入点来写，要看每家公司不同的特点。

最后，我们会根据大家交的作业来选出3-5篇优秀论文，这些优秀论文的作者将成为《商业经典案例课》的优秀毕业生。而优秀毕业生会获得我们准备的惊喜，这个惊喜应该是很不错的，这里我们先卖个关子。

另外，我会在专栏正式结束的那一天，也就是5月24日（周四），来做一场直播，和大家复盘一下这一年多我写作这个专栏的心路历程，也和大家做一些互动，到时候多回答一些大家的问题。另外在直播里我们也会表彰优秀毕业生，所以希望大家多多参与。

# 保时捷和大众，到底是谁收购了谁？

由于亲姻关系，保时捷并购大众的意愿是容易让公众理解的，本以为是一场人尽皆知的公公并购案，却演变成一场螳螂捕蝉，黄雀在后的大戏，成了商业并购的经典案例。刘瑜有过一个形象的比喻：“如果你同时养了猫和鱼，猫吃了鱼，你除了责备猫，更应该责备自己。”让大众回归保时捷家族，把费迪南德·保时捷博士曾经的梦想与事业发扬光大，对他们两个人来说，都是一个至高无上的选项。

# 西南航空｜如何成为一家长盛不衰的公司？

西南航空表面上看是蓝海战略，价值创新。本质是“产品经理”把客户的需求洞察得非常到位，一切回归人性的底层需求的研究，探索，满足。巴菲特老爷子不投航空业，是指那种不赚...任何行业都赚钱，关键看是谁在操盘经营。
