# Elon Musk | 如何延续整个人类的生命？

200多万年前智人从东非往外扩张时，灭掉了全球约50%的大型陆上哺乳动物，同时也灭掉了其所所有人种，使得我们智人成为地球上唯一只保留一种物种的种类。我们能成为地球的主宰并非因为人的独特和高贵，而是我们灭掉了所有其他人种。

还有什么梦想是不敢去想的呢？马斯克用行动证明，有些事不是因为难你才不去做，而是因为你不去做才显得那么难。

+   1. 既然不能与强人工智能的机器人竞争，那么就变成机器人——收缩型战略，战略转换；既然地球可能不再适合人类继续生存，那么就将选择殖民和移民——收缩型战略，放弃和清算。

+   2. 既然选择殖民或移民其他星球，那么就选择发展相应的技术，做好所有准备——发展型战略，一体化、多元化、密集型战略通信都有。

+   3. SpaceX、Tesla、Solaricity、Hyperloop、Boring、Starlink、Neuralink都是建立在以上收缩和发展战略上的职能战略和业务战略。马斯克看似胸阔大，不按常理出牌，其实是非常严谨、逻辑缜密的战略大师。

超越商业、自然科学、人文学等所有学科，没办法一并归纳或可以单一解释的问题系统可以归为哲学问题。所以马斯克同时是一位哲学大师。

# Elon Musk | 马斯克的局限性与公司存在的问题

开疆拓土和老成持重，这两种性格在不同的环境下，取得的成就也不相同。

新领域 的开拓者，需要的是冒险精神，是不断探究自我边界的过程。就像哥伦布一样，在他启航之前肯定不会被自己是否能 力不够这样的问 题困扰，勇往直前发现未知领域才是他们生命中的终极使命。

老成持重的守业者，就是你我这样的普通人，知道自己的能力边界，在能力范围内努力做事，像一个个螺丝钉一样维持着社会机器的正常运转，毕竟大多数人在这样的状态下才觉得心安。

一些人守着边界，另一些人热衷打破边界，没有对错之分，只有选择不同，毕竟让鸡蛋站在桌子上的办法不是每个人都能想到，不是每个人手中的鸡蛋都恰好是熟熟的。

先给大家试用个公式表示，知识+技能+心态（经验）。范围是随时间或空间这几个维度变化的。能力如果在时间这个维度叠加，能力范围一定是动态变化的。

举例，每天听得到，大家都是再拓宽知识。有些人不光听，还坚持输出或给别人讲，这就是在提升思考和写作的技能。心态或经验更是在时间长河中得到洗涤和提炼。范围就是边界，边界就是用来打破的。能力范围更是如此。

有些事是事物的能力问题，有些事是人的能力问题。对于事物的能力问题，也就是事物的极限，再怎么努力也是无法超越的，那就更好地在边界里做事。对于人的能力问题，当然是要不断提升。

对于埃隆·马斯克做的这些事情，不管他最终做到哪一步，最终收益最大的都是他。不仅自己的能力得到极大的提升，而且还让全世界的人认识了他，还会名垂千古。当然他的能力是很难复制的，我相信应该还有比他厉害的人吧，可是我们就记住了他。正是因为他这么不平凡的想法，造就了他伟大的一生。反过来想就算失败了，也顶多破产，破产照样能够好好吃生活。收益这么大，风险几乎为零，这样的事情那是要拼了命都去做的，能力问题就边做边提升，可能慢一些，但方向对了怎么做都会有收获。

一个人的能力范围是很主观的诠释，如何确认能力范围的边界，以什么标准划边界？个人以为能力边界如同科学一样是可证伪的，是自我认知的局限和相信权威的盲目。而商业、经济并非工具及方法，无法确认其特定的用途、规则。

比如对一个人的评价性格比较内向、不善言辞。不适合做销售，不适合做这做那，把一个人的边界画了出来，如听其所言日复一日便固化了其边界；如反其道而行之，主动钻研与实践，认识到销售的本质与客户相互信赖、服务质量、主动聆听有很大的关系，日复一日在拓宽自身边界的同时，不善言辞的性格也会有所改善。

边界如同会察言观色一样，映照始终不离能力，一旦能力有所提升，边界也会随之移动。而一个人的能力范围有多大，始终是一个变量，当然所谓的边界也未曾存在。
