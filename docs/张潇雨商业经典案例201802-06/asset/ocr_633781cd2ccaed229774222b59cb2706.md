# Facebook的用户要离它而去了吗？

记得何帆老师曾经提过网路系统的三难题：开放，安全，速度。最多只能三取二，不能全拿。例如俄罗斯情报部门用科技对美国总统大选的影响，这就是脸书是一个开放且讯息流动速度极快的网路系统，但是就牺牲了一点安全。

沉迷性，只要对我来说我发现自己的时间有看不可控的时候，我就会渐渐地保持对这个应用的距离。比如说在刷抖音的时候会看不到时间，从而一条又一条地去看。当我发现这一点的時候，1.我会选择不在做重要的事情的時候去看它，比如睡觉前，工作休息的时候。2.把这个应用所有的通知关闭，这样没有通知就基本上不会想到。3.如果这些努力依然没有效果，那我会选择把它删掉一段时间，在这之后如果需要，再把它加载回来。但是依然关闭通知，放到一个文件夹里，在外加载回来的应用不会占用太多的时间，因为之前属于它的时间早在它消失的这段時間里被别的事情占用了。这个方法用于各类直播软件、微博的观看，正掏占我注意力的应用我都会这么处理。最近正在处理微信的朋友圈，用的是上周例会脱不花分享的方法，每天只开朋友圈一个小时，只是我又多加一条，每过一周减少十分钟，直到减少0为止。我对社交软件的选择就是大家在用什么我就用什么就好了。我韩国同学KakaoTalk 用得多，那就下，孟加拉和越南同学Facebook用的多，那就下，只要不突破过度依赖这个底线都可以去尝试，大不了就如所说执行一遍算法就好了。

隔壁万老师刚讲到，客观环境是最硬的东西。一个想改变一群人太难了，深刻的变革是从环境开始的。环境变了，游戏规则就会跟着变。游戏规则变了，人就会跟着变。也就是说，想要大规模地改变人，必须指望环境先变了才行。应用到Facebook今天的局面上面，太贴切了。环境无时无刻不在变化，而2018年尤其剧烈。Facebook的未来与特朗普的上台一定是个标志性事件，有时就是这么没由来地偶然决定了历史的走向。再美好的愿望也无济于事，敬畏啊！

从历史的角度来看，广告主、媒体、观众（用户）都是一直存在着某种“博弈”关系的。三者的主动权依次发展到了现在以用户为核心。最底层的逻辑大家都在争取注意力。试图把注意力变成商品。然而用户认识到了这点，对低俗的信息，用户会逐渐远离。举个身边的例子，大家会把一些微商的朋友圈屏蔽。群信息调整成“消息免打扰”模式。甚至把一些久不联系的朋友删除。定期取关某些公众号。这些举动，都证明了，用户在保护自己的注意力。当人们发现周边的 人开始少用某种社交软件的时候，这种负的网络效应是严重的。我认为社交产品通过算法，精准算出对不同人起到成长意义的信息，形成正反馈，是平台长久稳定发展必走的一条路。

# 数字时代的新垄断

张老师您好！我感觉数字时代不会有传统意义上的垄断了，因为现在基本上就是资本为王的时代。每 一个大公司的成长与崛起，每一个新兴行业的发展与壮大，背后都有资本的影子，资本都是逐利的，在追求利润最大化的同时，也催生了跨界现象的出现。像近期的美团进军快递行业，滴滴进军外卖行业，直播平台进军小视频行业等等，科技行业在保持自身特有优势的前提下会越来越同质化，不会存在绝对意义上的垄断。就 像马化腾说的那样，他不知道颠覆微信的会是谁，什么时候会出现，巨头们谁都不敢忽视危机感，反过来倒是我们用户获得了实惠，选择更多了，价格也更优惠，我们应该欢迎这种垄断。

最近很巧合地看到很多关于“时代造英雄”的内容，最终定格在陈大年与他的wifi钥匙。26岁时和哥哥陈天桥成了首富，那会儿他们信奉“天道酬勤”，一年休7天，可终于有一天，毫无征兆地倒在电梯口。现在的他与他的公司绝不加班，中午一起打太极，十个项目只挑两个做。他知道一年休七天的工作方式顶不上一到一个好的时代风口。回到这些大科技公司，时代让他们成为了当今的王者，数字化的垄断也好，像at&t的恶意垄断也好，市场和时间会给你行为答案，指不定你也什么都没做错就被淘汰了。庆幸现在的经济发展速度，大胆地想一下，以后每个人的可穿戴设备就是钢铁侠的雅琪斯系统，指不定“5+2=1了。今天的留言总觉得有点消极，忘同学和老师见谅。

成功的那些人，是成功想象了未来，并且努力把想象变现实的那些人。马云认为未来的世界里，人 们通过网络进行商品交易。马化腾认为在未来的世界里，每个人都需要一个网络电话号码本，还有一种网络通讯工具。他们当年不会用Word，不会剪贝粘贴，不会做PPT，一点不会阻碍他们抵达今天。技能并不能抵御明天的来临，也不能保证自己在未来的竞争 力。同样地，设法找到那些AI替代不了的工作，并不是人类在机器时代降临之后的最优解法。真正的重点在于构想出一个机器和人共存的世界，并且在那样一个设定下的世界里，找寻属于自己的机会。在此之前，需要仔细观察这个世界。观察资金和技术的流动方向，看看是谁在悄然建立技术壁垒，把人群分开。看看是谁在吸纳资金，默认把热点领域转移；是谁在提供机会和可能，为通向未来人机共存的世界而铺平道路。武器不会杀人，杀人的是操控武器的人；AI也不会和人争工作，和人争工作的就是那些试图重新在这个世界分配财富，设计未来的 人。没有什么机器和人争工作，唯一的区别在于，你究竟是站在制定未来新游戏规则的一方，还是站在未来接受新游戏规则的一方。这决定了你是被机器服务，还是被机器取代。古往今来，概莫能外。

我的观点是数字时代的垄断利弊相间，无法一言以蔽之。利：1.大型数字企业获得了集中资源创新的可能性，并且可以看到Alphabet的很多业务都是具有长远前景的。2.这种垄断减少了不同平台之间的互联互通成本，也降低了用户的 使用成本。3.平台型的公司给予用户单一的交付界面，降低了用户的学习和使用成本。4.减少了对新时代的困惑感，有助于用户的心态稳定和情绪健康。弊：1.大公司使用低价或免费的策略，但是羊毛出在狗身上，最终还是会体现 在产品的售价中，消费者是最终买单者。2.资源集中后有的公司用于创新，有的却用于模仿、抄袭和扼杀创新者。3.单一平台的技术风险对于用户来说更高、更不可承受。4.用户减少了触达新服务、新产品的可能性。
