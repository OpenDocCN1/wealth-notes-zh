# 乐高 | 什么是企业的边界与核心？

核心这个问题（为何存在）让我联想到著名的“保安三角”。对应一个人和生命（也可以是产品、品牌、公司、组织以及机构等），核心就是回答“我是谁，从哪里来，要去哪里”的问题，后面两词其实是进一步清晰和明确“我是谁”，“我是谁”是最内心的核心。

+   1) 每个人都是独一无二的，都有自己的独有特性和灵魂。关键是做一个准确清晰的定位，以便和这个世界进行协同与交互。2) 定位清晰之后，需要结合“过去”的一些情况（优势优点、可选路径、现有的能力范围以及资源什么的）和当下的状况去丰富和不断完善这个定位，让自己的独特性凸显，进一步与这个世界协同与交互。3) 今天文中再次不只一次提到了“有限定期限和范围”，这个真的太重要了，有一个词叫“生命周期”。

今天的课程，让我惊讶的是，乐高作为玩具行业的老大哥，竟然对自己的客户如此不了解，完全按照自己的想法来设计产品。可以想象，连乐高这样的公司都做得如此不到位，世界上的大多数公司，很可能都犯了同样的错误。
