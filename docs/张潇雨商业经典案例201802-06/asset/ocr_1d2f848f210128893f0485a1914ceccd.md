钮找不到。每年300块钱的服务费倒是没白花，隔三差五需要远程维护。没有比较，就看不出差距。微软的设计者一定仔细琢磨了消费者的使用习惯，让人依旧直截就能很容易地找到常用的功能按钮，简单、好用，没有存在感，我想这就是最好的设计。很奇怪，这个专栏给我的感受也是同样的舒服。跟了大半年，从来没有硬着头皮在学。案例把金钱知识、管理知识巧妙地融入到生动的故事情节之中，好听不累，而且容易记忆。特别夸一专栏转述师徐佳杰的声音，好像老师亲自述一样自然，为专栏增色不少。总之就是特别掏缘的感觉。

# 微软Ⅰ与苹果之战的半个真相

每家公司都有自己的基因，微软是通用而苹果就是私人定制，当公司的理念和社会的發展相匹配时，就会迎来公司的高 速增长。PC时代微软用通用便捷的操作系统为互联网制定了行业标准，所以他成为了那个时代的巨无霸。移动互联网时代，苹果用iphone和ios定义了智能平台的规范，所以取代了微软的统治地位。不得不说是时代成就了微软和苹果的伟大。

这些年我们说的“寡家通吃”实际上早在微软的时代就已经开始了，只是伴随着近年更多的独角兽企业出现，我们才把这个规律总结出来。对于苹果公司来说，想在一个相同的领域和去当时的霸主微软竞争，实际上已经很强去撼动它的市场地位。或者说它想要挑战的，实际上并不是微软，而是全世界人民的使用习惯，以及企业之间的合作逻辑。直到苹果推出了智能手机，他才在一个全新的领域，打开了自己的市场。就像阿里想通过来去挑战腾讯的QQ、微信实际上也已经很难实现了。尽管从技术和功能来讲，采往并不一定很差。而腾讯当年的拍拍网，相同的道理也很難去打开败阿里淘宝和天猫。京东现在是通过物流体系建立了自己的竞争力，否则可能也很難和阿里竞争。具有网络效应的企业一旦成为市场的独角兽就很难被撼动。

最近在很多地方听到一个观点，过去你所依赖的优势，在未来将会成为你的拖累。这次说的微软和苹果之间的战争又印证了这一点。没有一个优势，能够让自己永存。不管是个人还是公司，都要想办法拥抱变化。要跟过去的自己说再见。用李白的一句话来说，弃我去者，昨日之日不可留。

我认为任何事情都不存在必然：1.我认为有必然的趋势，但不存在必然的主角。窦建德如果不是失误被擒，最终是 否李渊建立唐朝，就不可预测了。很多时候，很多事，是具有巧合和运气成 分的。2.其实有时候，我觉得看商业 史，或者其他任何历史，都应该像推理 小说一样读，一点点给出线索，让人们 先去思考，因为只有这样才能体会当事 人的难处。即便最后给出结论，也应该 是以事后总结的方式陈述，唯有这样才 能不被上帝视角所误导。3.我认为更思 考的问题，不是乔布斯必败，而是在 微软飞速崛起的时代，为何没有遇到旗 鼓相当的对手，就像特斯拉之于爱迪 生，戴姆勒之于卡尔·本茨。知今需鉴 古，无古不成今，希望商业史最重要的 价值是作为我们多元思维模型的一元， 而非其他。

是失误，还是必然，老实说，我也不知 道。今天专栏提供了一个必然的视角； 然而，在当时就真的没有其他对抗微软 的办法了吗？或许有，只是乔布斯没想 到，或许没有，老实说不知道。结果已 成历史，关键在于视角。

# 微软Ⅰ智能手机时代的大逆转

老师，首先，我觉得当时必须搞出一个 独立部门，对核心管理层直接负责，不 需要和其它部门有交集。说白了搞一个 类似于谷歌的X部门，让一些想法自然孵 化，我觉得是会有机会的。其次，作为 一个WP的曾经用户讲述我的体验，在流 畅度上WP不输IPHONE，唯一的问题是 应用简直少的可以怜，我不知道WP除了 office还能干什么，这个产品的定位还是 企业级的定位，而非个人化的定位。这 个问题是致命的，所以移动互联网其实就 是一个体互联，不是组织互联，可微软的 思路好像还是企业级的PC互联的思路。

通过今天的课多少明白了微软输掉的 逻辑了，但在移动终端除了手机以外，比 如笔记本电脑，我依然觉得微软有机会。 如果用过mac系统的仵你会明白，很 多软件与mac都不兼容，所以这也是 为什么苹果玩命地要让IPAD取代 LapTop，因为只有这样，苹果的优势才 能够显现。最后，微软的战略应该是发挥 原有优势的同时忽略暂时的劣势，因为 手机的办公效率是不可能有笔记本好 的，屏幕是一个瓶颈，应该考虑在移动 互联网办公上下手，这个是微软的绝对优 势。
