# 谷歌｜人工智能时代的两大挑战

很多人会钻技术的牛角尖，忽视技术的目的是为这个好产品服务，这是一个大坑，太多人跌进去，是因为没有回到事情的原点，就是为别人创造价值这件事。人们最终是用一个产品去解决问题，技术只是产品的内在而已。最近老师一辈的企业家，董明珠、王健林、孙宏斌，各种不顺、被看衰，缘由就是把商业当做赚钱工具，满脑子机关技巧，洞悉人性后的巧取豪夺。脱不花说到的两个词很贴切一利用人性、诱惑人性。他们能够成功很大的原因是赶上改革开放的红利，以及更好地猎到大众。王健林他们脑子里想的是怎么赚更多的钱，这是优先级，其次是要怎么做才能赚到钱。反观谷歌就很不一样了，舞兮自己成功的本质是让别人喜欢我，同时离不开我，产生这个黏性有了依赖，再想办法赚钱。以前用搜索技术，在免费的公用网页上直接变成一个好产品。可能现在入口被硬件用物属性先行占领了，但谷歌的企业文化以及商业信念还是没变，那就有永远机会找到下一个入口。现在的智能汽车就算是没有押对宝，但以谷歌的开放性包容性，终究会找到这个入口，微信不就是这样被做出来的吗？
