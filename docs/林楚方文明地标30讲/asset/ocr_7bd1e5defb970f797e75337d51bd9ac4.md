# 本讲小结

借助罗塞塔石碑上的古希腊文字，法国人商博良破译了古埃及文字，把人类有文字记载的历史，往前推进了两三千年。

文字是语言的次生符号。它的出现，打破了时空界限和人脑的记忆局限，让人类得以处理更大量、更精细的信息，从而能够管理超大规模组织。

文字催生了知识群体的产生，推动了纸和印刷术的发明，让知识的生产和传播范围更广、速度更快。
