# 1. 时间颗粒精确到分秒

格林尼治天文台在伦敦东南近郊。从高空俯瞰伦敦，会看到泰晤士河蜿蜒地穿过城市，其中有一段河道呈明显的U字形。在U字的底部，就是格林尼治公园，我要带你去的天文台就在公园的小山坡上。
