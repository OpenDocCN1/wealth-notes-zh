## 150 | 共享经济源于自由软件精神

## —— 今日内容看点 ——

通过阅读今天的内容，你将会掌握以下3个问题的答案：

- 1. 共享经济概念的起源是什么？
- 2. 什么是自由软件？

相信有不少人是因为滴滴或者摩拜，才第一次知道了共享经济这个概念。但很多人可能都不知道，共享经济其实最早萌发于一群信仰自由软件的极客。而极客精神的典型代表，就是我今天要介绍的代码托管平台 GitHub。

### 一、代码托管平台GitHub

GitHub 是全球最大的开源代码平台之一。所谓开源，就是指公开源代码。

一般来说，只有软件的原作者才拥有程序的源代码，如果公开源代码，就相当于把自己的心血免费送给了别人。但也正是因开源，软件行业才得以迅速发展、百花齐放。

而我们今天要讲的 GitHub，可以说是开源精神的极致体现。

### 二、布道者：理查德·斯托尔曼

在众多程序员心目中，理查德·斯托尔曼是神一般的存在。他始终坚信软件不应该只是被用户使用，软件的源代码还应该被用户所学习、共享和修改。

那为什么理查德·斯托尔曼会怀抱着这样的信念呢？

这还得从他的生平经历说起：

### 三、奠基者：林纳斯·托瓦兹

而这个内核部分的开发者，正是我们要讲的第二位奠基人物，名叫林纳斯·托瓦兹，他就是后来的“Linux 和 Git 之父”，和理查德·斯托尔曼一样，林纳斯·托瓦兹也是一个技术狂热者。

当 Linux 内核完成后，他立刻分享了内核的所有源代码。按他的说法，如果全球各地的黑客都来动手修改源代码，肯定能够带来一场开放的协作，从而创造出真正出色的软件。

- 1. 不管出于什么目的，所有人都有运行这个程序的自由。
- 2. 所有人都有任意复制这些代码的自由。
- 3. 在得到源代码的前提下，所有人都有改进程序，并公开发布改进的自由。

文件夹会越来越多，管理和存储成本也会跟着增加。

为了解决这个问题，林纳斯·托瓦兹开发出了一套版本控制系统，并把它命名为 Git。

每当代码改动出现新的版本后，系统就可以对新版本拍一个快照，然后根据时间等信息生成一段唯一的序列。这样一来，程序员们就可以使用 Git 的日志文件来观察和追溯每一次版本的变动了。

更方便的是，如果想跳转到某一个特定的版本，你只需要在日志里面找到对应的序列，向 Git 发出请求就可以实现。至于存储成本的问题，因为快照只包含了变动的信息，没有改变的信息是不会放进去的，自然也就大大缩减了储存成本。

这套系统简单易上手，所以内核的开发者在做其他项目时，也渐渐地开始使用它。于是，GitHub 就这样一传十、十传百地应运而生了。

程序员们开始把自己的项目上传到 GitHub 上面进行托管，并希望社区里的其他人也一起来参与项目的开发。后来有非常多软件都是依靠这种共享方式才取得了成功。

### 四、程序员的Facebook

其实早在 GitHub 之前，就已经有不少代码托管的网站，但是大多数网站更像是一个代码下载网站，往往代码出问题了以后只能自己修修补补，想要优化代码，还得加入特定的组群才行。

另外，从技术上来说，也是 GitHub 更胜一筹，大多数代码托管平台都采用中心化版本控制，所有的更改都要立刻同步到服务器上，一旦断网或者发生错误更改，就要花大量的时间恢复到之前的版本。而 Git 采取的是分布式管理系统，你可以在本地完成修改后，再同步到远程主机。

除了刚才提到的这些优势，GitHub 还被称为是程序员的 Facebook。

在这里，所有开发者都可以关注某个仓库，并接收到它的实时信息。同时，每个仓库又都有一个提问区，用户可以把自己遇到的问题发布到上面，然后等待作者或者其他用户来解答。这样就等于建立了用户和作者，以及用户和用户之间的互动。

这种管理方式吸引了许多著名的极客，他们纷纷把自己的项目放到 GitHub 上，而他们的粉丝也跟着转战到了这里。就像网络经济一样，一旦越来越多的节点加了进来，GitHub 的影响力就会呈现指数增长，还会进一步迫使其他项目加入。

现在，包括谷歌、Facebook、Twitter、微软在内的业界巨头都将自己的开源项目托管给了 GitHub。GitHub 的价值得到了广泛认可，2015年，它的估值就已经达到了20亿美元。

而在 GitHub 提供的支持下，也经过接近10年的发展，数以万计的优秀项目在一群具有极客精神的程序员手中大放光彩。比如最近非常火爆的 AI 框架 TensorFlow、Keras等等。所以，开放的力量真的不容小觑。

所以我们特意给大家安排的是让大家看到一个产业链条当中的各个核心部分，这样我们的团员就能够对整个产业发展的规律，尤其是背后蕴含的东西有更深入的了解。

首先我们去拜访了很多教授、专家和学者，因为我们原来说过，现在的科技创新基本上不可能从山沟里出来了，而是师出名门，也就是说，从高校，尤其是从名校出来的居多。

其次，我们也去了很多孵化器、技术转移机构和很多创新的小企业，因为很多高校的科研成果之所以能够落实到产品转化，最核心的是有很多的小企业在做转换的工作，而其它的支持机构给予辅助。

在拜访的过程中，我们带大家参观了知识产权转让办公室，孵化器、创新中心，甚至律师所和行业咨询公司，这些都是创业成功的必要支持部分。通过全面的了解，我相信很多人会对美国的创新系统有了更深的理解和认知。

为什么必须有一个深层次的认知呢？

原因其实也很简单，当你去跟人家合作的时候，你必须要知道，在他的系统里面，哪个是他缺少的，哪个是我们具备的，或者哪方面我们能够帮到他，这样才能够形成一种双赢的合作。

所以这也是我们一直强调的，中国人出去不能只是去马观花，而是要真正地理解人家背后的规律，因为只有当你理解了他们的规律以后，你才能够真正地去跟他们合作。我们一直强调，在产业中实际操作的人必须要有成败论英雄。

第三个信条是：我们特别强调实践。

我带着大家看项目，非常鼓励团员一起下来分享，一起来讨论，看的项目到底好不好，甚至我们一起来系统地对项目作分析和平价，同时也锻炼大家和对方沟通交流甚至谈判的技能。

其实中国人现在出去的越来越多，看到的东西也越来越多，但是到了最后，真正能够合作成功的，可不仅仅靠看项目，还要真正能够有实践的能力，能建立互信，懂得怎么去进行商业谈判，懂得运用所有的知识工具，使自己获得成功。

所以除了看和学以外，实践是必不可少的一环，我们要学会如何系统地了解国外各个前沿企业的现状，学会如何去作系统的分析，学会如何去和对方沟通交流，包括谈判技巧、合作技能，这些都是要在实践当中掌握的。
