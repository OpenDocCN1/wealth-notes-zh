# 预告 | 健康管理

虽然我们每个人都希望保持健康，但实际上健康管理是反人性的，比如，热爱美食，你需要控制，喜欢喝酒，你也需要控制，吸烟有害健康众所周知，但吸烟的人口依然众多。

健康管理说起来简单，但现实生活中能做好的人少之又少，因为它需要持续保持健康的饮食、规律的运动、良好的作息习惯，这些都需要自律。

不过，随着现代生活水平的提高，大家相比以前是更关注健康了，而且，得益于互联网、可穿戴设备、大数据、云平台、人工智能的发展和普及，我们掌握了在一定程度上能战胜人性的武器。

下周，我们就来聊聊健康管理，从这个产业的发展现状到未来趋势，欢迎你的关注。我相信，你也一定对如何更好的管理自己的健康感兴趣。
