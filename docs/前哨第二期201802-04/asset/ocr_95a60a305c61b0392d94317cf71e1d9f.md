# 预告 | 互联网保险

我们下周的话题是“互联网保险”。

一提到保险，相信不少人的第一个反应就是“骚扰电话”，整体来说，咱们中国人对保险的印象大多是负面的，所以大家对卖保险的都是避之不及。

实际上，传统的保险公司的产品确实有不少问题，比如保费高、赔付周期长、保单复杂化、信息不对称等等。

但是，现在可是移动互联网的时代，科技早已渗透到各行各业，保险也不例外，下周，我们会介绍一个新概念“保险科技”，也就是运用科技手段，对数据进行更好的获取、整理、分析，进而提高保险服务的效率。

那么，在这个过程中，传统的保险公司会如何进行科技转型呢？科技初创企业又做了哪些创新呢？互联网保险的发展趋势是怎样的呢？从中又涌现了哪些新机会呢？

下周，我们详细说，欢迎你的关注。
