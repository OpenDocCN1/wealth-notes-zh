# 172 | 科技正在改变我们的行为与思想

# ——信息汇报——

我们海银资本这几年一直在做海外高科技企业的投资布局，这个事情也得到越来越多的认同和支持。

前不久我们和光大控股一起组建了一个新的基金，叫光控海银。它是以海银资本全球高科技项目为基础，以光大控股的产业投资能力为后盾，推动全球的高科技原创技术与中国行业龙头企业的产业融合。

投资方向将专注于全球未来创新科技领域的公司，重点是在新能源、医疗健康、人工智能和机器人、新材料、计算机与电子、航空航天等创新领域当中具备领先科技的企业。

现在我们希望招募志同道合的人加盟，一起把这个事情向前推进。
