# 一、最赚钱的作家-J.K.罗琳

在《哈利·波特》里，J.K.罗琳创造了一个风靡全球的魔法世界。她从小就喜欢创作一些奇幻故事，创作完后就会念给自己的妹妹听。《哈利·波特》系列的雏形，就是某一天她在火车上产生的一个构思。简单说，这是一个小男孩到魔法学校去学习的故事，构思产生以后，罗琳就开始写作了。

但是，罗琳的写作之路并不是一帆风顺。

写作初期，她不幸遭遇母亲去世，随后自己又成为单亲妈妈，还曾经患上抑郁症，靠领国家救助金度日。不过，1997年出版的《哈利·波特与魔法石》彻底改变了她的命运。从此她实现了从人生低谷到人生赢家的华丽转身。

# 二、莎士比亚和J.K.罗琳

罗琳是多产的英国作家，我在前哨第一季的时候就介绍过，MIT 斯隆商学院的副院长黄亚生老帅拿她对比过400多年前的莎士比亚。这两位处在不同社会背景中的英国作家，存在着极大的差别。而这种差别，正是不同时代的不同的推广营销渠道，最终造成了在商业价值上的巨大差异。
