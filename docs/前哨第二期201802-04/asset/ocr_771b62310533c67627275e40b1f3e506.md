# 前哨投资基金进展：

大家都知道，我们年初就介绍会成立投资基金，用于帮助全球科技更好地在中国落地。

我们的理念是：

投资实业也许不是一个社会上容易引起广泛报道的那种百倍千倍回报的投资，但却是对中国经济乃至世界创新都至关重要的，而且有先进科技作保障，相对风险会小一些，当时就得到了很多老朋友的热烈响应。

回到主题，我们本周要讲的是一个大家普遍关心的话题：如何让资产升值。

最近我在后台看到几个用户的留言，说自己在某美股交易平台上买了股票，但因为平台申请券商牌照的问题，要求用户把资金都撤出来，很多本来打算长期持有的用户就不得不清仓，所以都遭受了不同程度的损失。

其实这些年来，可以说因为经济的高速发展，大家兜里的钱多多了，尤其是可配置的资产越来越多，资产管理的需求自然高涨，大家都想到好的投资产品，让资产持续升值。

# 一、资产管理的特点

在全球化已经非常成熟的今天，国内的很多投资者已经不再把目光局限在银行的理财、国债和A股市场上了，大家都在积极寻求资产的多元化配置。

# 二、美国的“亨利族”

在2008年金融危机后，美国出现了一个新概念，叫做“亨利族”，也就是HENRY群体。HENRY来自High Earners Not Rich Yet这5个单词的首字母缩写，意思是高薪却不富有的人。

# 三、中国的“新中产”群体

我们接着说咱们中国的“亨利族”，在中国，这个群体更多被称 School为“新中产”。

他们的年龄在30-50岁之间，家庭年净收入大概在10-50万人民币，可投资的资产是20-500万。这个人群往往拥有良好的教育背景，具备一定的审美能力和不错的全球视野。尤其是互联网的发 ate。
