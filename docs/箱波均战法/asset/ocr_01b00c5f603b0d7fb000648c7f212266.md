圖一我們叫上漲。

圖二我們叫回檔。

圖三是股價轉浪續上，我們叫 N 字上漲。

圖四是連續 N 字，我們叫向上波動。

當股價下跌，我們就叫下跌、反彈、轉浪續下（倒 N 字下跌）、
向下波動。說法不同，道理一樣。

既然每日收盤價所代表的是多空交戰後的強弱結果，那把每日
收盤價的點與點之間做連線，就形成一日波動了，一日波動會有 N
字上漲或倒 N 字下跌的型態出現，這些 N 字最少就是三到五天的收
盤價所組成的，因此慢慢就形成短線趨勢的概念出現了。連續向上 N
字的型態我們稱之為向上波動，連續向下倒 N 字的型態我們稱之為
向下波動。當股價波動從收盤價的連線（MA1）所形成，也就是小
波動慢慢累積成中波動，中波動再又累積成大波動，因此形成不同
級數的波動架構了。

從上面的概念，我們馬上解決了新上市櫃新股的操作問題，當
今天只有第一根日 K 線出現時，使用均線和指標的朋友需等到收盤
根數資料充足才能下決策。但是若使用箱波均的 mal 概念，只要出
現一個 N 字上漲就多空力判，就可以進場了。當然最小的一分鐘或
者五分鐘的線圖就可以開始切入操作了。
