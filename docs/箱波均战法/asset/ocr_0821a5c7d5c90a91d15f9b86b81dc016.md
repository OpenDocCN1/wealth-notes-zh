# 第五章

我們繼續看上圖的 F- 寶聯日線圖，我們找出線收盤價最低點 22.55，然後找出其下跌次低反彈箱頂底出來，把下跌次箱頂 27.7 和下跌次箱底 26.3 給往右延伸，用來觀察後面股價的走勢在什麼時候要開始發動。於上圖的圈圈處出現過過頂不破頂的訊號，後面股價漲幅驚人。

![](bbox=[0.1, 0.37, 0.9, 0.65])

我們看上圖茂順的周線圖，我們找到收盤價低點 21.65 之後，往前找出其下跌次箱頂底，後面我們發現股價歷經四年的時間，最後於圈圈處出現過頂不破頂的訊號，股價漲幅接近三倍以上的利潤，一般人很難等待四年在一個高檔震盪洗盤，但是一旦時機一到，看到過而不破的訊號進場，後面的速度與利潤是很值得期待的。
