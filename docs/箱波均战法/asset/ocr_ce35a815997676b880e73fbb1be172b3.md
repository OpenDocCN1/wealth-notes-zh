# 六、基本進出操作與停損

# 缺口進出法

+   1. 當股價下跌波動時，以收盤線反彈低點為箱底及以收盤線反彈一折之高點為箱頂，畫反弹修正箱。

+   2. 當收盤線回跌時未能收破箱底 + 轉折向上，稱為出現止跌缺口為買進時機。買進後，若未能收過箱頂或收過叉破，應立即出場。

止跌缺口現，雖是買進時，後續應過頂，止跌乃為真。

+   3. 當股價上漲時，以收盤線回檔高點為箱頂及以收盤線回檔一折之低點為箱底，畫回檔修正箱。
