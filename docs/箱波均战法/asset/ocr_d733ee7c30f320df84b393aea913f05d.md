此是理論本身存有的盲點所致，與運氣何干？

N 師的「箱波均」理論可謂是投資理財技術分析方法發展史上的一次偉大突破，後人將證明該理論將和「K 線、波浪、均線、葛浪碧法則」等經典理論齊名，甚至會有所超越！此理論最大的價值在於破解了以上理論的迷思和盲點，於當下便可清晰無誤分析出某層級趨勢力道的延續、暫歇、阻斷、逆轉、收復、擴大！沒有模棱兩可的解讀，只有當下清晰無誤的操作。此理論最大的特點在於把握當下，當下即是，沒有預期，沒有規劃，沒有執著。拋棄了一切形式與預期，只關注當下力道博弈與攻守轉換，無招無示、無羈無絆、電光石火、瞬息而擊、可大可小、收放自如、物我二忘、如雨化田，為投資理財操作最高境界！N 師能不藏私地把自己十年積澱萃取昇華而來的理論精華公諸於世，實在是投資者的幸事，實在是為華人爭光。

「箱波均」理論以獨特視角，用「箱體」來分析力道消長轉換。此箱體非同與以往的「箱體理論」，而屬於幾乎完全不同的邏輯分析體系。若讀者感覺該理論過於簡單易學，進而懷疑該理論價值，那實在是讀者不解「大道至簡、大象無形、大巧不工、重劍無鋒」的道理！此外 N 師是修佛之人，常以佛法度化我這等愚鈍之人，使我受益匪淺，借此向 N 師表達感恩之情。得緣 N 師點化是弟子修來的最大福報。
