# ## 第二章

這一張圖我們再多加高點之間的連線，整體的波動就在這兩個紅色階梯狀所包圍著，當箱頂（高點）創新低且箱底（低點）也創新低就是空頭走勢，直到有一天箱頂（高點）過前高且箱底（低點）不再破前低才有展開多頭走勢的契機。再搭配前面的反彈箱與回檔箱的觀念，下跌走勢其反彈箱沒有收過前都沒有機會扭轉原趨勢，上漲走勢其回檔箱沒有被跌破前都沒有機會扭轉原趨勢。

![](bbox=[0.1, 0.36, 0.9, 0.67])

在上漲趨勢當中每次回檔都會有回檔箱出現，我們以宏達電的周線圖為例，我們發現每次回檔箱之間距離越大，多頭力道越強勁，另外只要回檔箱之間沒有重疊都是漲勢，同理，下跌趨勢中每次反彈都會有反彈箱出現，只要反彈箱之間的距離越大，這意味著空頭趨勢越強勁，不能因為跌深就去搶反彈。再者，只要反彈箱之間沒有重疊的都是跌勢。
