# 二、本書緣起：「箱波均」基本原理

當股價在一個區間震盪修正，造就了一個箱子。

當股價向箱子上下任何一個方向突破，就成了 N 字或倒 N 字，造就了波浪。

當修正與突破交替進行、不斷循環，就成了各種不同級數的均線走勢。

不同級數均線的不同均線走勢，又形成了後續短中長線股價的趨勢互動。

其中，短均線的一波趨勢波動完畢，即是中均線的一個趨勢段完畢；必然進行短均線的一波修正波動，亦即中均線的一個修正段。中長期均線波動的關係亦復如是。

這就是我們利用箱、波、均來抓住長短線各別多空脈動的基本思維。

先有市場交易，再經投資者根據交易價格加以記錄與刻畫，於是有了 K 線圖。一般技術分析指標，則是根據交易數據算出強度，再依強度曲折畫出指標線圖。不管是 K 線圖或是指標線圖，有圖就有型態，型態即代表訊號。但是「正是是嶺，側看成峰」，一樣圖可以有多種解讀，何況多樣圖？原因在於，趨勢判斷人言言殊，也因此，趨勢判斷越看總是越複雜。
