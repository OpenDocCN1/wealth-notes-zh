# 箱波均拉

底，做買進的動作，此時下跌波動力道被阻斷，因此買進之後還有充裕的時間可以觀察是反彈還是由空轉多，若想猜最低點，經常會跌多想就搶多單，最後才懊悔不要接掉下來的刀子，因此不預設立場猜低點才是箱波均的以逸待勞的方針。

+   *   在空頭趨勢有兩種買法
*   到目標區，指標背離止跌，逢低買（猜低點風險高）
*   反彈之後，拉回有撐止跌，積極買（阻斷之後以逸待勞）

# 勝率與風險利潤比

+   *   勝率＝買賣成功次數／總買賣次數
*   減少進場次數
*   只操作自己有把握的段落與線型
*   風險利潤比＝進場停損費用／預定可能的利潤
*   停損的設置與執行
*   要抱的住一段大行情

勝率與風險利潤比配合才能賺多賠少累積財富。
