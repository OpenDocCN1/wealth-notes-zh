# 第四章

收盤價就如濾波器過濾雜訊，高低點如K線圖的上下影線只是盤中多空交戰瞬間的情緒所產生的痕跡，並非真實的勝負關鍵，收盤之後才見真章，因此收盤價具有高度的參考價值。

若只看一個收盤價的連線，其所形成的波動是很清楚的連續N字與連續倒N字的循環，藉由次箱的研判可以簡單的捕捉發動點與轉折點。打個比方，今天是紅K線但是收盤價比昨天的收盤價還低，在收盤價的連線是往下的，但是投資者看到紅K線心中會安慰自己，低檔有人照顧所以收紅K線，同理，今天是黑K線，但是收盤價比昨天收盤價還高，但是投資者看到黑K線心中會認為有賣壓，再看今天的量能出大量，心裡就開始忐忑不安了，因此我們希望以收盤價的連線作控盤，所謂制心一處，無事不辦。
