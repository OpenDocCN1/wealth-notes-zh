# 箱體均 畫箱

畫箱 → 觀缺口 → 下單買賣，從 6.7 出現賣出訊號之後，於 6.92 出現止跌缺口的買進訊號，後面持續往上畫回檔箱，直到 11.6 出現止漲缺口的賣出訊號。此兩段的價差為 (6.92 - 6.7) + (11.6 - 6.92) = 4.9 元利潤。

畫箱 → 觀缺口 → 下單買賣，從上圖的 11.6 止漲缺口賣出，10.6 止跌缺口買進，10.05 止漲缺口賣出，10.15 止跌缺口買進，後面持續畫回檔箱，於 14.6 出現止漲缺口賣出，這四段價差為 (11.6 - 10.6) + (10.05 - 10.6) + (10.05 - 10.15) + (14.6 - 10.15) = 4.8 元的利潤。
