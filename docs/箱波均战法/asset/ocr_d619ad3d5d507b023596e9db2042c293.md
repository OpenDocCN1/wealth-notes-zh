# 一、箱液均操作理論

先有市場交易，再經投資者根據交易價格加以記錄刻畫，於是有 了 K 線圖。一般技術分析指標，則是根據交易數據算出強度，再 依強度曲折畫出指標線圈。不管是 K 線圖或是指標線圈，有圈就有 型態，型態即代表訊號。但是「正看成嶺，側成峰」，一樣圖可以有 多種解讀，何況多樣圖？趨勢判斷人言言殊正是這個原因，趨勢判 斷越看越複雜也是這個原因。

這套操作理論是要讓我們回歸原始 K 線圖，從箱子出發，藉由 波浪，根據均線而進而操作。並照金剛經所言「無住生心」的道理， 不執著於既有的多空印象、不執著於波浪幾浪、不執著於滿足價位、 不執著於得失多少；只要訊號出現了，當下即是！原本的訊號條件 消失了，新的訊號出現了，也是當下即是！完全依照系統的訊號， 該進就進，該出就出。我們叫它「箱液均」操作理論。

當香味撲鼻時，常令人感到心曠神怡。這套操作理論是要將操 作判斷單純化，讓每個操作者學會這套理論以後，在市場上能「以 逸待勞，適時切入；穩健獲利，輕鬆成就。」對於投資操作這件工 作就像「香撲君」一樣，感覺輕鬆、自在、幸福感受。或許，也可叫 它「香撲君」操作理論！
