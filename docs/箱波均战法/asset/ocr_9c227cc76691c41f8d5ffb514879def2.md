# (三)收復

1. 上漲次箱底收破後，重新站上而不再跌破，稱為「多頭次箱收復」。簡稱「收復」。有重回多頭的象徵意義。

2. 下跌次箱頂收過後，重新跌破而不再收過，稱為「空頭次箱收復」。簡稱「收復」。有重回空頭的象徵意義。
