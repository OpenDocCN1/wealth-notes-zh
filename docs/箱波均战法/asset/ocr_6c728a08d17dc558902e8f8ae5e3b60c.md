# 三、「修正」與「缺口」的定義

+   1. 股價向上波動中回檔的一折，與股價向下波動時反彈的一折皆叫做「修正」。  
每一折修正皆包含其細波的一波修正波動；反之，每一波修正波動皆可化為其次級波的一折修正。  
畫修正箱時以此「一折修正」為畫箱標準的。（圖七）（圖八）

+   2. 向上波動時，一折回檔修正後未能收過箱頂續漲即折回，其折回前的高點 d 與箱頂 b 點之間的空隙稱為「止漲缺口」。（圖七）

缺口出現即是修正波動的刺激，也有機會是多空波動逆轉的起點
