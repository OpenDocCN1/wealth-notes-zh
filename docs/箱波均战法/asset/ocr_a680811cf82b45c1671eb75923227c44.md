畫箱 → 觀缺口 → 下單買賣，從上圖的 17.85 出現止漲缺口的賣出訊號，於 17.75 出現止跌缺口的買進訊號，於 22.2 出現止漲缺口的賣出訊號，於此兩段的價差利潤為 4.55 元。

結論，以金像電為範例的緩漲標的物，於 2014 年的五月 8.09 買進，到 2015 年的 1 月底結束，其總共的價差為 0.34 – 0.14 + 4.6 + 4.55 = 9.35 元。也就是張 8.09 元買進賺了 9.35 的價差，由此範例告訴我們當強勢熱門股走軋空走勢則能賺多賠少，若是找到緩漲的股票，則利用缺口操作法所賺的利潤會比較差一點，但是依然還是能賺多賠少。

以上，我們找強勢股和緩漲股為範例，讓讀者知道缺口操作法的優缺點，其優點為可一段一段賺取價差，且不用知道多空趨向與轉折，自然缺口操作法會幫助您抓到轉折與多空趨向。其缺點就是太
