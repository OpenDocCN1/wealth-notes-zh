  - 該回不回的追買
  - 拉回修正止跌的逢低買

當向下波動持續之中，都是順勢做空，空頭走勢的波動為「破而不過」時賣出，本書籍提倡以逸待勞，因此著重於反彈不過次箱，做反彈逢高賣出。

- • 在空頭趨勢有兩種買法
  - 該彈不彈的追空
  - 反彈修正止漲的逢高賣

當上漲波動的次高回檔箱底被攻破之後，反彈不過次高回檔箱頂，做賣出的動作，此時上漲波動力道被阻斷，因此賣出之後還有充裕的時間可以觀察是修正還是由多轉空，若想猜最高點，經常會漲多就想放空，最後順勢波動沒有賺到，還被軋空賠錢，因此不預設立場猜高點才是箱波均以逸待勞的方針。

# 逆勢系統（減碼與試單）

- • 在多頭趨勢有兩種買法
  - 到目標區，指標背離止漲，逢高賣（猜高點風險高）
  - 拉回之後，反彈無力止漲，積極賣（阻斷之後以逸待勞）

當下跌波動的次低反彈箱頂被收過之後，回檔不破次低反彈箱底，做買進的動作，此時下跌波動力道被阻斷，因此買進之後還有充裕的時間可以觀察是反彈還是由空轉多，若想猜最低點，經常會跌多想就搶多單，最後才懊悔不要接掉下來的刀子，因此不預設立場猜低點才是箱波均的以逸待勞的方針。

- • 在空頭趨勢有兩種買法
  - 到目標區，指標背離止跌，逢低買（猜低點風險高）
  - 反彈之後，拉回有撐止跌，積極買（阻斷之後以逸待勞）

# 勝率與風險利潤比

- • 勝率＝買賣成功次數／總買賣次數
  - 減少進場次數
  - 只操作自己有把握的段落與線型
- • 風險利潤比＝進場停損費用／預定可能的利潤
  - 停損的設置與執行
  - 要抱的住一段大行情

勝率與風險利潤比配合才能賺多賠少累積財富。
