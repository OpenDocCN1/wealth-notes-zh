# 第四章
要圖表讀出前言之箱波均SOP戰法

轉到盡頭缺口現，因此一段波動的結束幾乎都會有止漲缺口出現，出現止漲缺口可能是修正波動，也可能是逆轉的開始，因此於此可先獲利，等候確認是修正波動，在於止跌缺口做回補多單即可。

波段操作就是想要獲取一段利潤，因此風險與利潤之間要有較好的比例，一般都取賠 50 點賺 150 點，賠 100 點賺 300 點的這種 1:3 的方式。利用缺口操作法，先選定想要操作的週期，然後遵守缺口訊號的買賣時機，進而獲取波段的利潤。

箱波均波段操作買賣規則：

+   1. 出現 mal 波動破不了左邊的 mal 箱底，收盤一往上勾時為止跌缺口買進
2. 出現 mal 波動過不了左邊的 mal 箱頂，收盤一彎頭時止漲缺口賣出
3. 若沒有出現止跌缺口時，收盤出現下跌阻斷，隔天一開始直接補空單，買多
4. 若沒有出現止漲缺口時，收盤出現上漲阻斷，隔天一開始直接買多單，放空
5. 若沒有以上的訊號，守好停損 50 點，獲利看缺口
6. 買多單同時就是把之前的空單補掉，平多單的同時就是再放空
7. 也就是說止漲缺口補多單 + 放空，止跌缺口補空單 + 買多
