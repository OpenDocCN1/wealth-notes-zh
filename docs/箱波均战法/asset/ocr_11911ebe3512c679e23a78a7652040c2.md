# ### 五、成為贏家需改變的四個關鍵

《有錢人跟你想的不一樣》這本書提及改變四要素，我們把他利用在技術分析上如下：
關於改變的四個關鍵因素：

+   1. **察覺**：您要先知道某件事的存在，才能改變它。您要知道技術分析的盲點才可以從異常抓到轉折

+   2. **理解**：了解思考方式後，你就會知道，一切都由你內在而起。任何技術分析的訊號是由買賣力與人心的貪，怕，恐，所產生的結果

+   3. **畫清界限**：你的想法不等於你自己，你是創造者。你選擇了你的想法。清楚瞭解自己的投資屬性後規劃自己的操作系統與訊號

+   4. **重新設定**：設定你的心靈檔案。我要選擇新的思考方式，讓它幫助我得到快樂和成功。設定好贏家的思考模式從投資中賺錢而得到經濟自由與生活無慮

# ### 六、觀盤心法

趨勢的形成是市場的共業使然，無論多頭、空頭都有緣生緣滅之時。在技術分析的範疇，對趨勢我們只求適時發現，不必預設立場。趨勢是讓操作者客觀的跟著走，不可主觀的限定。這是「趨勢為師」的意思。

是故操作的心態不應有主觀的多、空方向之執著；應放空一切立場，冷眼旁觀，以照見其緣生緣滅之當下；而技術分析就是要觀
