# 專業推薦

從事自營操盤以來，我一直強調操盤的秘訣在於「趨勢為友，情緒為敵」；趨勢為友代表以基本面的趨勢當選股依據，而情緒為敵就是以技術面為輔的反市場操作。

本書是呂先生技術面操作的無私分享，非常值得投資人深入研究。

# 推薦序一

## 理財之道在於跟著專家照著做

理周集團總裁 洪實山

在商場與財經媒體市場的資歷將近四十年，大家經常都會問我一個問題：「有沒有一個一勞永逸的理財方法？理財有什麼訣竅嗎？」，答案很簡單，就是跟專家、贏家、跟有錢人站在一起，他們做什麼你就跟著做什麼，跟著照做就可以了，理財是沒有門檻的！

簡單來說是複製別人的成功模式，如果真的還不知道怎麼做？就直接買本「理財周刊」吧，跟著裡頭的財經專家、分析師投資理財，從股票、期貨、選擇權、國內外房地產、保險、基金通通都有。在股票市場中亦是如此，贏家與輸家也有循環，跟著贏家一起做就是正循環，學會贏家的方法自然會成為贏家，就算無法徹底學成，至少總也比較接近贏家的距離一點吧。

若有套操盤方法學會可以一勞永逸，一次就學會並能看懂全世界的所有商品的股價趨勢動向，也適用於股匯市、期貨、債券、基金等金融商品，只要有收盤價的連線就可以操作該商品，那麼你要不跟著這個贏家來學？相信佳霖的這本《箱波均控盤戰法》不會讓各位朋友失望。

呂佳霖說的好，股市是一個很好檢驗自己是否能戰勝自己貪嗔痴慢疑的地方，戰勝了就邁向贏家之路，失敗了就容易沉淪下去，投資人都務必提高警覺，小心應對。任何投資操作的成功條件，皆以遵守紀律為第一，要完全依照訊號行事，該進則進、該出則出，該停損則停損，絕不加入自己的想像與固執，選定一套符合大賺小賠的交易系統，剩下的就應該只是聽話照做，不該存有主觀的偏執。

畢竟系統的操作機制都是經過深思熟慮及無數的驗證而得到的理論，佳霖經過多年實戰經驗所觀察出股價的多空循環的慣性，而記錄下來形成「箱波均控盤系統」的確有用，書中已用大量走勢圖來做驗證，勝率自然無庸置疑，當知道方法之後，剩下的就只是依照紀律去操作了。

理財之道真的不難，找到對的人、對的方法、對的公司、對的刊物，你就能走向對的道路。致富關鍵就在理財，而理財之道就在跟著專家照著做！

# 推薦序二

## 股海浮沉，誰與爭鋒

唐鏡人

茫茫股海中，投資者渺小得像海洋中的一個泡沫一樣微不足道。潮起潮落間，很易使人迷失自我，消磨沉淪。我和大家一樣，也屬於這微不足道中的一份子。然得N師器重，為其新書作序，自覺才疏學淺，惴惴不安。此也足見N師胸襟似海，保養萬物！

投資者經歷了最初的時間浪費和金錢虧損後，志弱者便下「股市都是騙人把戲」的結論，從此與股市絕緣。志堅者，痛定思痛，重振士氣，再入書局，老老實實地找到一些流傳百年的經典投資書籍，如「K線戰法」、「波浪理論」、「形態學」、「回憶錄」、「戰勝華爾街」……等，作者也都是大名鼎鼎，如雷貫耳。又是幾年的閉門研讀，潛心研究。各種名詞、理念、形態、組合、原則、方法、訊號、紀律……記得腦子要爆炸。自以為天道酬勤，付出終有收穫。進入實盤操作才發現這些組合、形態、訊號……在操作的當下適合多方雙方解釋，只有等到後面走勢清晰了，才能確定之前的訊號是何用意。可為時已晚，不是錯過了最佳進場時機，價格已飆漲大段，惶恐不敢再追，望「牛」興嘆，便是進場後遭遇逆「勢」破位，匆匆止損出局，驚魂未定間，股價又突然急拉，心痛不已。此時便開始懷疑自己的運氣怎麼這麼差，總是作出與後市相反的理解。實不知此是理論本身存有的盲點所致，與運氣何干？

N 師的「箱波均」理論可謂是投資理財技術分析方法發展史上的一次偉大突破，後人將證明該理論將和「K 線、波浪、均線、葛朗碧法則」等經典理論齊名，甚至會有所超越！此理論最大的價值在於破解了以上理論的迷思和盲點，於當下便可清晰無誤分析出某層級趨勢力道的延續、暫歇、阻斷、逆轉、收復、擴大！沒有模棱兩可的解讀，只有當下清晰無誤的操作。此理論最大的特點在於把握當下，當下即是，沒有預期，沒有規劃，沒有執著。拋棄了一切形式與預期，只關注當下力道博弈與攻守轉換，無招無示、無羈無絆、電光石火、瞬息而擊、可大可小、收放自如、物我二忘、如雨化田，為投資理財操作最高境界！N 師能不藏私地把自己十年積澱萃取昇華而來的理論精華公諸於世，實在是投資者的幸事，實在是為華人爭光。

「箱波均」理論以獨特視角，用「箱體」來分析力道消長轉換。此箱體非同於以往的「箱體理論」，而屬於幾乎完全不同的邏輯分析體系。若讀者感覺該理論過於簡單易學，進而懷疑該理論價值，那實在是讀者不解「大道至簡、大象無形、大巧不工、重劍無鋒」的道理！此外 N 師是修佛之人，常以佛法度化我這等愚鈍之人，使我受益匪淺，借此向 N 師表達感恩之情。得緣 N 師點化是弟子修來的最大福報。

以上句句肺腑，不敢妄語，望有福報之人，得緣悟道！

# 作者序

所謂：一元復始萬象更新，任何事物都是由一而生，此為一生萬法的道理。收盤價是多空交戰最後的戰果，利用收盤價的連線（也就是1均線=ma1）所形成的向上波動與向下波動來研判股價漲跌盤的方向是最恰當和適宜的，股價出現向上波動的上漲的次箱為多頭趨勢動力的關鍵處，沒有攻破前上漲趨勢動力依舊。股價出現向下波動的下跌的次箱為空頭趨勢動力的關鍵處，沒有收復前下跌趨勢動力依舊。

由於收盤價的連線是全世界各國任何商品都會顯示出來的線型，諸如原油，基金，原物料，債卷等等都是以收盤價為投資報告居多，很多報告不會附上K線圖甚至也沒有kd指標可看，因此學會箱波均控盤戰法就能一勞永逸，一次就學會看懂全世界的所有商品的股價趨勢動向。當讀者把箱波均的基礎理論建立之後，最重要的就是如何使用這些理論去實戰，因此特地精心設計把理論轉化成實戰的招式，讀者只要背誦簡單的口訣，了解其使用的定義之後就能開始實戰，本書從最簡單寫到實戰整合運用，利用缺口操作法與次箱操作法，就能一招鎖喉擒主升了。

當讀者了解箱波均的基礎理論也進一步知道如何把理論轉化成實戰的招式之後，最後就是建立堅定的信心，箱波均控盤戰法為超越傳統技術分析的終極聖盂，破解技術分析的盲點與迷思，最後印證主力控盤的手法就在箱波均控盤戰法裡面。

當我們知道簡單的趨勢操作之後，最重要的是如何心平氣和的穩定下單，《金剛經》上告訴我們「一切法得成於忍」，想要有所成就，沒有耐心是不能成功。有耐心的持續做對的事情就是操作紀律，要懂得克服自己的煩惱，克服自己的慾望，凡是有這些事情衝動引發起來，自己要馬上想到後果，若是投資無法克服貪瞋癡慢，結果就是賠錢居多。打個比方，在最近贏錢之後就開始買高我慢驕傲起來，心想賺錢這麼簡單，對市場開始鬆懈，開始不遵守紀律的下單，最後把之前賺的賠回去的例子頗多。因此「息滅貪嗔癡，勤修戒定慧」是贏家都會遵守的心法，這心法是教育，輸家被教育成功之後，是一定可以成為贏家的。

最後勉勵各位：願無虛發，功不唐捐。願越大福越大，大願就是我，當您捨得為人，您自然就會得到更多。若只是為自己那只是小我唷！所謂信願行三合一才能成為贏家：信就是找到一套自己驗證後相信的方法，也相信自己可以學會這一套控盤的方法。

願就是期許自己可以依照這套方法達到賺多賠少的目標。行就是隨緣盡份依照訊號所學的去實踐之，隨緣就是不預設立場，該砍就砍，該抱就抱就是盡份。若只會下單不會思考，就如沒有學正確的方法，盲目操作，操作就會很辛苦。若只會思考不敢下單，那就無法實現我們的夢想。只有知行合一（信願行三合一），那就是圓滿的！

功不唐捐就是：「努力下功夫，這種功夫絕對不會白白的浪費掉，也就是一分耕耘，一分收穫的意思。」成功的人因為有夢想，並且不斷努力，終於達成目標，正可說是「人生有夢，築夢踏實。」我相信只要有理想，並且盡力去實現，美好人生是可以預見的。

以上就是願無虛發，功不唐捐的分享，最後祝福各位心想事成，荷包滿滿，幸福滿滿！

# 導讀

我們常聽到：凡走過必留痕跡，種什麼因，得甚麼果，前世累積的福田厚實，今生就財富旺旺來，前世累積的福田薄弱，今生就得辛苦與辛勞。所謂：事出必有因，我們可以藉由前車之鑑，來推演後面可能的結果。在技術線圖也是如此，凡走過必留痕跡，圖型中的上漲次箱或下跌次箱（痕跡）就是轉浪或逆轉浪的關鍵處，也是支撐帶與壓力帶之觀察處。由興到衰，或者否極泰來都有許多空循環的道理，股價就如偈言所說的「箱波均」不斷的循環不已，若能以一貫之，制心一處，必能無事不辦。

在股市的波動之中不外乎「多頭，空頭，盤整」這三種走勢，多頭走勢的慣性為「過而不破」，空頭走勢的慣性為「破而不過」，盤整走勢的慣性為「不過＋不破」或者「又過＋又破」，因此只要抓住多空盤三種慣性各是哪兩個步驟，即可輕鬆分辨出盤勢唷！

當收盤價的連線出現上漲→回檔→轉浪續上，形成 N 字上漲，此時可以找到上漲回檔箱，再次回檔＋轉浪續上，形成向上波動，此時可以找到次高回檔箱，當股價不斷的回檔＋轉浪續上，次高回檔箱不斷的往上移動停利。向上波動何時結束，我們是利用次高回檔箱底作為向上波動阻斷與否的依據。

![](img/f4d43e1509d33bd8b5a7a0e86a3dc645_12_0.png)

在股價上漲過程中，會出現止漲缺口的修正波動，只要次高回檔箱底沒有收破前，向上波動力道是持續的，若次高回檔箱底被收破，則有兩種狀況：第一：能夠再次收復次高回檔箱頂，則重回多頭，前面的修正就稱為中繼再漲，第二：若跌破次高回檔箱，反彈收不過次高回檔箱底，則出現逆轉浪而下的走勢，此時就稱為做空階段。

當收盤價連線出現上漲→回檔→轉漲續上→回檔→轉漲續上，收破次高回檔箱底，反彈收不過次高回檔箱頂，此時出現止漲缺口的賣出訊號，後面再轉浪而下，就形成下跌反彈轉漲續下的倒 N 下跌，若後面反彈之後又持續轉浪而下，就形成向下波動，此時候次低反彈箱頂往下移動防守，當次低反彈箱頂沒有收過前，下跌走勢的向下波動就沒有被阻斷過。

直到有一天，次低反彈箱頂收過，回測不破次低反彈箱底，此時出現止跌缺口的買進訊號，後面再轉漲而上，又回到前述的上漲 N 字，因此股價多空循環就是如此的井然有序，循環不已。本書籍把以上的每一個名詞與環節都定義得很清楚，讀者可以在閱讀時從上述的股價多空循環之中，知道現在身在何處，知道股價的位階是在那一個環節之中，如此學習必可「以一貫之」快速學習，輕鬆成就！

## 一、「路漫漫其修遠兮，吾將上下而求索」

此言是我第一次參與潤泰集團尹衍樑總裁開創新研發會議中聽到的，出於屈原的名作《離騷》，意思是：在追尋真理上，前方道路還很漫長，但我將百折不撓，不遺餘力地去追求和探索。尹總裁告訴我們創新研發不要怕失敗，就如愛迪生一樣，若沒有 99 次的失敗經驗，怎會有第 100 次的成功呢？

如何運用歷史的軌跡與資料，去尋找一套能賺多賠少的投資方法，是投資人最想要知道的，最好能多空皆宜，長短皆能研判的一招闢天下的方法。正如佛家所云：一生萬法，萬法歸一。在這十幾年的技術分析研究之路，經過經年的實戰經驗累積，終於創新出一套符合上述的方法，我稱為「箱波均控盤戰法」。

無論多頭趨勢或空頭趨勢都有緣生緣滅之時；但趨勢的形成是市場當時的供需使然，它只能讓投資者以客觀的心態發現它並跟著它走，非可用主觀心態來期待。

因此在技術分析的應用上，對於趨勢的變化我們只要做到適時發現就好了，不要主觀的預先規劃！主觀又期待的預先規畫就會產生「先入為主」的執著心，對於後續盤勢的發展就無法做出客觀的判斷。

是故投資者的心態不要有主觀的多空方向之執著；應放空一切立場冷眼旁觀，以照見其趨勢形成之當下適時切入。趨勢是讓操作者以客觀的心態跟著走，非可用主觀來限定。這是「趨勢為師」的意思。而技術分析就是要觀其因緣成熟之際切入。這就是我們把「如如不動，不取於相」的道理用在技術分析的眞義。

技術分析的理論與指標包羅萬象，任一種都有用，但也任一種都很難真正派上用場。問題不在理論或指標本身，而在使用者的心態：第一，一般操作者對技術分析理論與指標有貪學的心態。本來多學並非壞事，但除非學到融会貫通並對所學深具信心，才能在實務上靈活運用。否則，學越多越感到無所適從。第二，一般操作者對投資獲利有貪多的心態。對於行情想要大小通吃。於是在盤中一下看過 K，一下看日 K；一下看小時 K，一下看 5 分 K。看了就心動，因為長短線各有多空訊號，想要賺取長漲幅，又不想失去短漲價。

但因長線還有更長線，短線還有更短線，以致抓不到長短線之各別多空脈動，而進退失據。不但因小失大甚至有時還白白停損。因應之道在於「守一 K 線級數操作」與「建立捨小就大的心態」。

是故，如何只用一套操作理論，就能同時抓住中長線多空方向以及適時發覺短線買賣訊號，益形重要。「守一 K 線級數之圖表操作」是在固定級數之 K 線圖上，運用長短均線的排列互動，判別長短趨勢的行進、修正、轉浪、逆轉浪。所謂一樣圖含有多樣情（情報）。果能捨得短線價差，亦不奢求一步登天獲取最大漲幅，依照自己能接受及滿足之 K 線級數，等待訊號，守一操作；則獲利的不斷累積，日久亦能成就大事。這正是佛法所說「制心一處，無事不辦」的道理。再強調一次，「如如不動」是要我們平心靜氣、冷眼旁觀、等待訊號！「不取於相」是要我們不執著於既有的多空印象；因為趨勢隨時在變，訊號出現，當下即是；原本的訊號條件消失，新的訊號出現，也是當下即是！

## 二、本書緣起：「箱波均」基本原理

當股價在一個區間震盪修正，造就了一個箱子。

當股價向箱子上下任何一個方向突破，就成了 N 字或倒 N 字，造就了波浪。

當修正與突破交替進行、不斷循環，就成了各種不同級數的均線走勢。

不同級數均線的不同均線走勢，又形成了後續短中長線股價的趨勢互動。

其中，短均線的一波趨勢波動完畢，即是中均線的一個趨勢段完畢；必然進行短均線的一波修正波動，亦即中均線的一個修正段。中長期均線波動的關係亦復如是。

這就是我們利用箱、波、均來抓住長短線各別多空脈動的基本思維。

先有市場交易，再經投資者根據交易價格加以記錄與刻畫，於是有了 K 線圖。一般技術分析指標，則是根據交易數據算出強度，再依強度曲折畫出指標線圖。不管是 K 線圖或是指標線圖，有圖就有型態，型態即代表訊號。但是「正是是嶺，側看成峰」，一樣圖可以有多種解讀，何況多樣圖？原因在於，趨勢判斷人言言殊，也因此，趨勢判斷越看總是越複雜。

這套操作理論是要讓我們回歸原始 K 線圖，從箱子出發，藉由波浪，根據均線而進出操作。並照金剛經所言「無住生心」的道理，不執著於既有的多空印象、不執著於波浪漲浪、不執著於滿足價位、不執著於得失多少；只要訊號出現了，當下即是！原本的訊號條件消失了，新的訊號出現了，也當下即是！完全依照系統的訊號，該進就進，該出就出。我們叫它「箱波均」操作理論。

當香味撲鼻時，常令人感到心曩神怡。這套操作理論是要將操作判斷單純化，讓每個操作者學會這套理論以後，在市場上能「以逸待勞，適時切入；穩健獲利，輕鬆成就。」對於投資操作這件工作就像『香撲君』一樣，感覺輕鬆、自在、幸福戚。或許，也可叫它『香撲君』操作理論！

## 三、鑑往知來，複製成功經驗

在操作與投資，大家最擔心的是未知世界裡，其右邊盤勢還沒發生的情況下該如何推估，是否有跡可循呢？

從箱波均控盤戰法告訴我們：一定會有一個「關鍵次箱」，讓我們可以推估後面的可能走勢路徑。因為任何事件都是「因緣而生，因緣而滅」。當多頭趨勢增強的時候此時為「因緣而生」，當還沒有「因緣而滅」時，多頭走勢就是要符合拉起有守次箱，與見壓不是壓的向上轉浪成功現象。

當「因緣而滅」之時，我們就會發現此時的走勢會上檔有壓出現止漲缺口且見撐不是撐，出現破而不不過次箱。這些都可以從箱波均的關鍵次箱來研判多空之間的力量消長，就是緣生緣滅的道理啊！

箱波均控盤戰法就是提供一套緣生緣滅的關鍵樞紐，從「過而不破」知道方向往上，從「破而不過」知道方向往下，因此右邊的未知走勢，已不全然是未知！

箱波均的「關鍵次箱」能提供投資者操作的方向，以及「缺口操作法」用來研判止漲與止跌的訊號，當投資能抓住關鍵樞紐，就能以逸待勞，贏在起跑點。

## 四、學習與思考並進，邁向贏家之路

孔子說：學而不思則罔，思而不學則殆！學而不思則罔是告訴我們，學習時若不去思考書中的義理，則無法將此知識變成自己的一部分，那這學習依然是一無所知！思而不學則殆是告訴我們，只憑空去思考事情但是沒有去學習前人所留下的經驗和知識，那依然無法在重要時刻作出研判對錯的決策。

這個告訴我們學習和思考都很重要需要一起並進與互補，我們常聽到溫故而知新，這是告訴我們因為有去思考所以又得到更多的想法與舉一反三的效果！學習技術分析也是如此，當我們讀書學習技術分析的時候，若只依照書中所講解的，但是沒有去思考實戰的時候何時比較適合，何時就不適用的話，就會淪為死讀書，而變成理論，這和實戰有不少的落差。

若只會思考但是不去參考各家對於技術分析的不同講解，去了解他們為何對同樣的線型有做不同的解析，那在下單時就容易猶豫不決，不知道實戰的時候到底會發生什麼事情！學習和思考就是把前人的經驗經過思考邏輯和評估之後，改良成自己操作的策略，這樣才會找到一套屬於自己成功的方程式，在這邊分享我學習與操作的思考邏輯，希望對讀者與粉絲都能有些許的幫助！
