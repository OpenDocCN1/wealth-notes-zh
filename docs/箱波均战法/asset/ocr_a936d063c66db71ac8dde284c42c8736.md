# 第四章

兩儀，兩儀生四象，四象生八卦，八卦演盡天下事。箱波均控盤戰法以收盤價的連線所產生的波動為基本波動，以此基本波動來推演後面的向上波動和向下波動以及次級波動和次次級波動的關係。

在實務的操作上，投資想要知道的是甚麼？我們歸納如下：

+   一、我到底要買還是要賣？

+   二、買了之後怎研判要不要漲？

+   三、放空之後怎研判要不要跌？

+   四、我要如何試單與加碼？

+   五、我要買多少資金，小買還是重押？

以上的問題，在技術分析的術語就是，止跌買，續漲多單續抱，止漲賣，續跌空單續抱，強勢軋空買多一點，緩漲買少一點，強勢殺多空多一點，緩跌空少一點。

以下我們就針對要不要漲，要不要跌來做深入的討論。要不要漲有兩種情況：要漲其實就是向上轉滾續漲的意思。不漲其實就是止漲的意思，在箱波均用止漲缺口來作研判。要不要跌也有兩種情況：要跌其實就是向下轉滾續跌的意思。不跌其實就是止跌的意思，在箱波均用止跌缺口來作研判。以下我們用簡單的箱波均股票賺錢箱來闡述要不要漲，要不要跌這四種買賣訊號。
