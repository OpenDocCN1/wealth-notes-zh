並闡述它的意義如下：

+   1. 壓力點與支撐點

如果股市只有多方沒有空方，或只有空方沒有多方，則成交值等於零，股市必不存在。所以在股市中多空交戰是常態，越是多空看法分歧交戰越是激烈。

多方為了保全做多利益而力守的點位，我們稱之為支撐點。

空方為了保全做空利益而力守的點位，我們稱之為壓力點。

+   2. 守多點與守空點（圖五、圖六）

b 點是當初獲利賣壓發生的地方，也是空方趁機做空的地方，
所以 b 點即是壓力點也是空方守空點。

c 點是當初從 a 點做多的人為了保全利益，在適當的點位 c 蓄力守住，並向上推升的地方，
所以 c 點即是支撐點也是多方守多點。
