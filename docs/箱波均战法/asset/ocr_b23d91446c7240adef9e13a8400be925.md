# 3.b 點是到達 d 點的必經 : ( 圖五 )

b 點是多方要創新高必須突破的最後點位。

如果 b 點無法收上表示空方力量仍比多方大，代表市場的多數仍然看空。多方必須重新尋找支撐或確認支撐，蓄勢才能再發。

# 4.c 點是到達 e 點的必經 : ( 圖六 )

c 點是空方要讓股價續跌並創新低，必須擠破的最後點位。

如果 c 點無法攻破表示多方力量仍比空方大，代表市場的多數仍然看多。也代表 c 點股價仍為市場多數所認同，市場的做空氣氛並未形成。

5.bc 之間即為多空交戰未分勝負的地方，我們視為回檔修正區 (或回檔整理區)。若將 bc 兩點畫成兩條平行線，則像一個箱子有箱頂也有箱底，所以我們稱之為「修正箱」。

6. abcd 四個點所形成的上漲 N 字波動其 bc 兩點為回檔箱，abcd 四個點所形成的下跌倒 N 字波動其 bc 兩點為反彈箱，因此畫箱的基礎就是 bc 兩個點所畫出的水平線作為箱頂與箱底，利用股價「過而不破」或者破而不過，來研判後面的走勢，由於 bc 兩點是「箱波均」的主軸之一，因此取為 bc 法則，由 bc 兩點所畫出的股票箱是我們抓轉折與發動點，獲取利潤的工具，因此稱為股票賺錢箱，期許讀者可以藉由簡單的「箱波均」的方法，賺取利潤，累積財富。
