# 第一章

不執著於得失多少；只要訊號出現了，當下即是！原本的訊號條件
消失了，新的訊號出現了，也當下即是！完全依照系統的訊號，該
進就進，該出就出。我們叫它「箱波均」操作理論。

當香味撲鼻時，常令人感到心曕神怡。這套操作理論是要將操
作判斷單純化，讓每個操作者學會這套理論以後，在市場上能「以
逸待勞，適時切入；穩健獲利，輕鬆成就。」對於投資操作這件工
作就像『香撲君』一樣，感覺輕鬆、自在、幸福戚。或許，也可叫
它『香撲君』操作理論！

# 三、鑑往知來，複製成功經驗

在操作與投資，大家最擔心的是未知世界裡，其右邊盤勢還沒
發生的情況下該如何推估，是否有跡可循呢？

從箱波均控盤戰法告訴我們：一定會有一個「關鍵次箱」，讓我
們可以推估後面的可能走勢路徑。因為任何事件都是「因緣而生，
因緣而滅」。當多頭趨勢增強的時候此時為「因緣而生」，當還沒有
「因緣而滅」時，多頭走勢就是要符合拉起有守次箱，與見壓不是
壓的向上轉浪成功現象。

當「因緣而滅」之時，我們就會發現此時的走勢會上檔有壓出
現止漲缺口且見撐不是撐，出現破而不不過次箱。這些都可以從箱波均
的關鍵次箱來研判多空之間的力量消長，就是緣生緣滅的道理啊！

箱波均控盤戰法就是提供一套緣生緣滅的關鍵樞紐，從「過而
不破」知道方向往上，從「破而不過」知道方向往下，因此右邊的
未知走勢，已不全然是未知！
