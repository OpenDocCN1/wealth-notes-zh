# ## 二、每日收盤價的痕跡就是多空交戰的成果

我們常聽到「一生萬法」，任何源頭的組合都從「一」開始，就如投資也是每一次的戰果累積下來才能致富的，因此每一次的勝負戰果都是難能可貴，也就是我們常聽到的積沙成塔。然而股市的波動也是如此，一根 K 棒是從開盤、高點、低點，及收盤價所組成，今天的開始是開盤價，今天的結束點是收盤價，盤中的震盪兩端就是今天高點和今天低點。

收盤價是一檔股票每天多空交戰的戰果，不管盤中如何高低震盪上衝下洗，一天的勝負就在收盤結束。每天的戰果也將刻劃出一條痕跡，我們可以藉此分出短線的多空強弱。打個比方，今天收盤比昨天收盤還高，今天就是多方勝，今天的收盤比昨天的收盤還低，今天就是空方勝。

把每日收盤價的點與點之間做連線，就能夠輕鬆找出每日交戰的痕跡。方法非常簡單，也可以直接透過下單軟體，將均線參數設定為 1（MA1）或是「收價線」來找出。這上上下下的痕跡，就像是波動一般，會有 N 字上漲或倒 N 字下跌的型態出現，這些 N 字最少就是三到五天的收盤價所組成的，慢慢就形成短線趨勢的概念出現。連續向上 N 字的型態我們稱之為向上波動，連續向下倒 N 字的型態我們稱之為向下波動。當股價波動從收盤價的連線（MA1）所形成，也就是小波動慢慢累積成中波動，中波動又再累積成大波動，因此形成「不同級數」的「波動架構」了。
