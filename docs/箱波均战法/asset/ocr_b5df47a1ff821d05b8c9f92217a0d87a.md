# ## 步驟七 如何分段治事賺價差

在金剛經提及：應無所住而生其心，如何可以讓自己操作時「不敢於相」，和持股能「如如不動」，直到趨勢阻斷結束為止，是在股市中想賺取一段波段價差的投資者最想要的方法。有學過波浪理論的朋友都知道，波浪常有浪中有浪，波中有波的迷失，最重要的是數波數到最後真的分不清楚是哪一波了，究其原因在於修正波動第二波和第四波有強勢平台整理的選項，因此數波有時候不是五波而出現七波，另一個是當某一波走延伸波時，您就會發現走完五波怎麼還持續往上走呢，此時若執著於波數去做放空就會被軋。因此若利用上次我們提及的上漲次箱與下跌次箱作為多空趨勢阻斷與否的關鍵，就可以不執著波浪是幾波而能賺取中間的價差了。當我們不執著波浪是走了幾波了，只要每次的上漲次箱不斷的往上移動，直到有一天收破上漲次箱反彈過不了做出場，這樣就真的可以達到「應無所住而生其心」。
