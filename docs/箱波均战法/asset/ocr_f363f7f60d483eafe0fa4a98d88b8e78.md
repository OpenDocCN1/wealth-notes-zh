# 第六章

您會發現依照因果循環，以前種下的因，當緣分到了，就會結成果實的，因此從「預知前世因，今生受者是」這個道理，就可從左邊線圖（前世因），去推右邊可能的線圖（今生受者是）。再從「預知後世果，今生作者是」也就是說：原本命中沒有財庫，除非您現在努力種福田，往後就會有財庫。依照這道理，若原本失敗的地方，能夠努力克服才能重回多頭，不然股價來此都是要先視為風險區，就是這個道理。

「如何找出左邊已知線型的關鍵處」就是「箱波均操作理論」所探討的樞紐與主軸。操作時最重要就是研判多空與強弱，研判多空是讓我們想要買還是要賣的依據，研判強弱勢讓我們要買多還是買少的依據，上漲次箱與下跌次箱就是多空之研判，箱頂與箱底就是強弱之研判。

我們以多頭為例，其有三次的買點：

+   1. 止跌缺口的試單點（搶反彈）

+   2. 站穩下跌次箱底的試單點（多頭的底限）

+   3. 站穩下跌次箱頂的加碼點（軋空的前兆）
