# 第六章 箱波均三招訓練法

從上圖的和旺周線圖，從 56.2 跌到 16 元，何時會由空轉多呢？我們找到收盤價最低點 16 元，往前找出其下跌次箱頂底出來，我們發現上圖的圈圈處出現過而不破 23 元的買訊，後面股價漲到 73.9，其利潤有超過三倍之多。

從上圖的高點附近，我們不容易看出型態學裡面的 M 頭在哪？股價卻往下大跌，從上圖的低點附近，我們也不容易看出型態學的 W 底在哪？股價卻往上大漲，型態學有多種作頭或作底的組合型態，若可以以一貫之，只用一個關鍵研判所有型態學的關鍵，這不就是大道至簡的好方法嗎？

本書一路走來，讀者可以發現要上漲必有一個關鍵要克服突破，要下跌必有一個關鍵要克服跌破，找出這個關鍵樞紐就是箱波均的次箱處，由於缺口總在次箱處，因此次箱和缺口是不一不二，終於達到萬法歸一的箱波均招式油然而生。
