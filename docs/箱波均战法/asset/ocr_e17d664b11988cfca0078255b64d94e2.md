# 轉浪買回訊號

畫箱 → 觀缺口 → 下單買賣，從上圖的祥碩 32.35 出現止漲缺口的賣出訊號，於 34.65 出現過箱頂的轉浪買回訊號，於 39.85 出現止漲缺口的賣出訊號，於 39.6 出現過箱頂的轉浪買回訊號，於 39 出現止漲缺口的賣出訊號，於 37.95 出現止跌缺口的買回訊號。

（32.35 - 34.65）+（39.85 - 34.65）+（39.85 - 39.6）+（39 - 39.6）+（39 - 37.95）= - 2.3 + 5.2 + 0.25 - 0.6 + 1.05 = 3.6，這五段價差可賺取共 3.6 元的利潤。
