# 第六章

我們看上圖的全譜周線圖，我們可以找到收盤價最低點為4，往前找出其下跌次箱頂底出來，我們發現從左邊數來第一個圓圈處出現回測不破下跌次箱底5的拉回買點，於左邊數來的第二個圓圈處出現回測不破下跌箱頂7的轧空前兆買點，後面股價漲到28元。

讀者可了解當過頂不破頂時買進，經過不到一年漲幅有四倍，這樣就是不疾而速，以逸待勞的贏家方程式啊！後面第三個圓圈處也是出現過頂不破頂的訊號，後面也是走出快速噴出的走勢，由此可見，正確的事情不斷的作，箱波均真能一招鎖喉擒主升，能不能等待這個訊號出現才出手，且不斷的依照此方法持續遵守紀律去操作就是各位的修練了。一旦各位修練完成，恭喜您拿到長期贏家的證書，必定能賺多賠少累積財富的。
