# 第二章

<mark>結論</mark>

雖然說「一生萬法，萬法歸一」。如果不解「萬法之所以生」，實難達「歸一之妙用」。本來，一分用心得一分受用；十分用心得十分受用；這是亙古不變的道理。基於篇幅所限，本書只能介紹箱波均的基本邏輯，也只教讀者基本的操作方法。希望將來有緣發表更多更深的箱波均操作理論！

雖然說只介紹基本的邏輯與操作方法，但讓我想到殊勝的「念佛法門」，上智下愚皆能受用。蓋上智者徹悟而不疑，肯依教奉行；下愚者力不及疑，有緣而得，既得能信，亦依教奉行；故而皆能受用。又如，先人留下名店，子孫若能創新固能發揚光大；雖不能創新，如能堅持先人秘方保持好品質，亦能守成。

前面說「箱箱過破是轉浪，轉到盡頭缺口現；止漲缺口宜賣出，止跌缺口要買進。缺口最佳買賣點，缺口總在次箱處。」實際已點出「一生萬法，萬法歸一」的「妙一」。讀者若能完全依照訊號進出與停損，不參雜任何猜測與妄想。沒有缺口訊號時，如如不動，缺口訊號出現，才下手。雖不保證大賺，小贏不難。

所以任何投資操作的成功條件，皆以遵守紀律為第一，要完全依照訊號行事，該進則進該出則出該停損則停損，絕不加入自己的想像與固執。因為系統的操作機制是經過深思熟慮及無數的驗證而得到的理論，自己的想像與固執是一時所生的情緒反應。孰優孰劣，
