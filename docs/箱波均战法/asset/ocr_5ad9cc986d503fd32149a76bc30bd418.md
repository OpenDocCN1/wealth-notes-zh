# 推薦序二

股海浮沉，誰與爭鋒

唐鏡人

茫茫股海中，投資者渺小得像海洋中的一個泡沫一樣微不足道。潮起潮落間，很易使人迷失自我，消磨沉淪。我和大家一樣，也屬於這微不足道中的一份子。然得N師器重，為其新書作序，自覺才疏學淺，惴惴不安。此也足見N師胸襟似海，保養萬物！

投資者經歷了最初的時間浪費和金錢虧損後，志弱者便下「股市都是騙人把戲」的結論，從此與股市絕緣。志堅者，痛定思痛，重振士氣，再入書局，老老實實地找到一些流傳百年的經典投資書籍，如「K線戰法」、「波浪理論」、「形態學」、「回憶錄」、「戰勝華爾街」……等，作者也都是大名鼎鼎，如雷貫耳。又是幾年的閉門研讀，潛心研究。各種名詞、理念、形態、組合、原則、方法、訊號、紀律……記得腦子要爆炸。自以為天道酬勤，付出終有收穫。進入實盤操作才發現這些組合、形態、訊號……在操作的當下適合多方雙方解釋，只有等到後面走勢清晰了，才能確定之前的訊號是何用意。可為時已晚，不是錯過了最佳進場時機，價格已飆漲大段，惶恐不敢再追，望「牛」與歉，便是進場後遭遇逆「勢」破位，匆匆止損出局，驚魂未定間，股價又突然急拉，心痛不已。此時便開始懷疑自己的運氣怎麼這麼差，總是作出與後市相反的理解。實不知
