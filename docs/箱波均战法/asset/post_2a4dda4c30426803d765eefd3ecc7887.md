
# 一、箱液均操作理論

先有市場交易，再經投資者根據交易價格加以記錄刻畫，於是有 K 線圖。一般技術分析指標，則是根據交易數據算出強度，再依強度曲折畫出指標線圈。不管是 K 線圖或是指標線圈，有圈就有型態，型態即代表訊號。但是「正看成嶺，側成峰」，一樣圖可以有多種解讀，何況多樣圖？趨勢判斷人言言殊正是這個原因，趨勢判斷越看越複雜也是這個原因。

這套操作理論是要讓我們回歸原始 K 線圖，從箱子出發，藉由波浪，根據均線而進而操作。並照金剛經所言「無住生心」的道理，不執著於既有的多空印象、不執著於波浪幾浪、不執著於滿足價位、不執著於得失多少；只要訊號出現了，當下即是！原本的訊號條件消失了，新的訊號出現了，也是當下即是！完全依照系統的訊號，該進就進，該出就出。我們叫它「箱液均」操作理論。

當香味撲鼻時，常令人感到心曠神怡。這套操作理論是要將操作判斷單純化，讓每個操作者學會這套理論以後，在市場上能「以逸待勞，適時切入；穩健獲利，輕鬆成就。」對於投資操作這件工作就像「香撲君」一樣，感覺輕鬆、自在、幸福感受。或許，也可叫它「香撲君」操作理論！

## 二、每日收盤價的痕跡就是多空交戰的成果

我們常聽到「一生萬法」，任何源頭的組合都從「一」開始，就如投資也是每一次的戰果累積下來才能致富的，因此每一次的勝負戰果都是難能可貴，也就是我們常聽到的積沙成塔。然而股市的波動也是如此，一根 K 棒是從開盤、高點、低點，及收盤價所組成，今天的開始是開盤價，今天的結束點是收盤價，盤中的震盪兩端就是今天高點和今天低點。

收盤價是一檔股票每天多空交戰的戰果，不管盤中如何高低震盪上衝下洗，一天的勝負就在收盤結束。每天的戰果也將刻劃出一條痕跡，我們可以藉此分出短線的多空強弱。打個比方，今天收盤比昨天收盤還高，今天就是多方勝，今天的收盤比昨天的收盤還低，今天就是空方勝。

把每日收盤價的點與點之間做連線，就能夠輕鬆找出每日交戰的痕跡。方法非常簡單，也可以直接透過下單軟體，將均線參數設定為 1（MA1）或是「收價線」來找出。這上上下下的痕跡，就像是波動一般，會有 N 字上漲或倒 N 字下跌的型態出現，這些 N 字最少就是三到五天的收盤價所組成的，慢慢就形成短線趨勢的概念出現。連續向上 N 字的型態我們稱之為向上波動，連續向下倒 N 字的型態我們稱之為向下波動。當股價波動從收盤價的連線（MA1）所形成，也就是小波動慢慢累積成中波動，中波動又再累積成大波動，因此形成「不同級數」的「波動架構」了。

## 二、修正箱的定義

細觀圖二，我們提出 b 和 c 兩個重要的點，衍生圖五與圖六。

![](img/f4d43e1509d33bd8b5a7a0e86a3dc645_57_0.png)
![](img/f4d43e1509d33bd8b5a7a0e86a3dc645_57_1.png)

並闡述它的意義如下：

- 1. 壓力點與支撐點
  - 如果股市只有多方沒有空方，或只有空方沒有多方，則成交值等於零，股市必不存在。所以在股市中多空交戰是常態，越是多空看法分歧交戰越是激烈。
  - 多方為了保全做多利益而力守的點位，我們稱之為支撐點。
  - 空方為了保全做空利益而力守的點位，我們稱之為壓力點。

- 2. 守多點與守空點（圖五、圖六）
  - b 點是當初獲利賣壓發生的地方，也是空方趁機做空的地方，所以 b 點即是壓力點也是空方守空點。
  - c 點是當初從 a 點做多的人為了保全利益，在適當的點位 c 蓄力守住，並向上推升的地方，所以 c 點即是支撐點也是多方守多點。

![](img/f4d43e1509d33bd8b5a7a0e86a3dc645_58_0.png)

- 3. b 點是到達 d 點的必經：(圖五)
  - b 點是多方要創新高必須突破的最後點位。
  - 如果 b 點無法收上表示空方力量仍比多方大，代表市場的多數仍然看空。多方必須重新尋找支撐或確認支撐，蓄勢才能再發。

- 4. c 點是到達 e 點的必經：(圖六)
  - c 點是空方要讓股價續跌並創新低，必須擠破的最後點位。
  - 如果 c 點無法攻破表示多方力量仍比空方大，代表市場的多數仍然看多。也代表 c 點股價仍為市場多數所認同，市場的做空氣氛並未形成。

- 5. bc 之間即為多空交戰未分勝負的地方，我們視為回檔修正區 (或回檔整理區)。若將 bc 兩點畫成兩條平行線，則像一個箱子有箱頂也有箱底，所以我們稱之為「修正箱」。

- 6. abcd 四個點所形成的上漲 N 字波動其 bc 兩點為回檔箱，abcd 四個點所形成的下跌倒 N 字波動其 bc 兩點為反彈箱，因此畫箱的基礎就是 bc 兩個點所畫出的水平線作為箱頂與箱底，利用股價「過而不破」或者破而不過，來研判後面的走勢，由於 bc 兩點是「箱波均」的主軸之一，因此取為 bc 法則，由 bc 兩點所畫出的股票箱是我們抓轉折與發動點，獲取利潤的工具，因此稱為股票賺錢箱，期許讀者可以藉由簡單的「箱波均」的方法，賺取利潤，累積財富。

## 三、「修正」與「缺口」的定義

- 1. 股價向上波動中回檔的一折，與股價向下波動時反彈的一折皆叫做「修正」。
  每一折修正皆包含其細波的一波修正波動；反之，每一波修正波動皆可化為其次級波的一折修正。
  畫修正箱時以此「一折修正」為畫箱標準的。（圖七）（圖八）

- 2. 向上波動時，一折回檔修正後未能收過箱頂續漲即折回，其折回前的高點 d 與箱頂 b 點之間的空隙稱為「止漲缺口」。（圖七）
  缺口出現即是修正波動的刺激，也有機會是多空波動逆轉的起點

- 1. 上漲次箱底收破後，重新站上而不再跌破，稱為「多頭次箱收復」。簡稱「收復」。有重回多頭的象徵意義。
- 2. 下跌次箱頂收過後，重新跌破而不再收過，稱為「空頭次箱收復」。簡稱「收復」。有重回空頭的象徵意義。

## 六、基本進出操作與停損

### 缺口進出法

- 1. 當股價下跌波動時，以收盤線反彈低點為箱底及以收盤線反彈一折之高點為箱頂，畫反弹修正箱。
- 2. 當收盤線回跌時未能收破箱底 + 轉折向上，稱為出現止跌缺口為買進時機。買進後，若未能收過箱頂或收過叉破，應立即出場。
  止跌缺口現，雖是買進時，後續應過頂，止跌乃為真。
- 3. 當股價上漲時，以收盤線回檔高點為箱頂及以收盤線回檔一折之低點為箱底，畫回檔修正箱。

- 4. 當收盤線回升時未能收過箱頂＋轉折向下，稱為出現止漲缺口為賣出時機。融券賣出後，若未能收破箱底或收破又過，應立即回補。
  止漲缺口現，雖是賣出時，後續應破底，止漲乃為真。

# 第二章

### 結論

雖然說「一生萬法，萬法歸一」。如果不解「萬法之所以生」，實難達「歸一之妙用」。本來，一分用心得一分受用；十分用心得十分受用；這是亙古不變的道理。基於篇幅所限，本書只能介紹箱波均的基本邏輯，也只教讀者基本的操作方法。希望將來有緣發表更多更深的箱波均操作理論！

雖然說只介紹基本的邏輯與操作方法，但讓我想到殊勝的「念佛法門」，上智下愚皆能受用。蓋上智者徹悟而不疑，肯依教奉行；下愚者力不及疑，有緣而得，既得能信，亦依教奉行；故而皆能受用。又如，先人留下名店，子孫若能創新固能發揚光大；雖不能創新，如能堅持先人秘方保持好品質，亦能守成。

前面說「箱箱過破是轉浪，轉到盡頭缺口現；止漲缺口宜賣出，止跌缺口要買進。缺口最佳買賣點，缺口總在次箱處。」實際已點出「一生萬法，萬法歸一」的「妙一」。讀者若能完全依照訊號進出與停損，不參雜任何猜測與妄想。沒有缺口訊號時，如如不動，缺口訊號出現，才下手。雖不保證大賺，小贏不難。

所以任何投資操作的成功條件，皆以遵守紀律為第一，要完全依照訊號行事，該進則進該出則出該停損則停損，絕不加入自己的想像與固執。因為系統的操作機制是經過深思熟慮及無數的驗證而得到的理論，自己的想像與固執是一時所生的情緒反應。孰優孰劣，

孰可信孰不可信不是一目了然？

可以影響市場的因素很多，以致多空趨向可能瞬息生變，這是我們第一個要建立的概念；不但不可固執原本的趨勢規畫，還要隨時因應變化，調整規劃。能利用系統的機制，來研判市場的變化並立即順應變化，才是贏家。在所有操作系統上，面對所謂「該漲不漲」及「該跌不跌」的情況，叫做異常。發生「異常」時，經常是多空逆轉的關鍵時刻，一定要誠實面對並立即處理。

一般投資者最難做到的是停損。一者在心態上不想發生賠錢記錄；二者心裡還存著當初買進時預計獲利的憧憬，深怕賣錯了美夢就破碎了。而事實上是：

- 1. 停損＝不讓損失擴大。所以賣對了可以防止大賠，賣錯了只是小損。
- 2. 市場上適合投資的標的與時機永遠都有，賣錯了另找標的與時機再投資又何妨？所謂「留得青山在，不怕沒材燒。」不就是這個意思嗎？
- 3. 不想發生賠錢記錄是最愚痴的執著。我們常說開源節流，會錯的人只把重點放在節流，變成吝嗇之輩。真正意義應是同時把「應有」收入放大，把「不當」支出縮小。所以經營之道在於營業收入大於成本支出，非不支出！投資之道在於投資獲利大於投資損失，不怕小損！記錄只是過程，最後的加減合計才是結果。如果正常時大賺，異常賣小賠，合計結果當然是獲利。
