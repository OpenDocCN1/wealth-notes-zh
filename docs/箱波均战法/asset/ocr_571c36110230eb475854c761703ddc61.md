# 第四章

因此我們可以知道每天多空交戰的結果就是在收盤價，不管如何開盤或者盤中如何高低震盪上衝下洗，多空交戰的勝負結果就在收盤時，因此每天的收盤價就是多空交戰結束後所留下的戰果，從這些戰果所遺留下來的痕跡，可以分出短線的多空強弱，打個比方，今天收盤比昨天收盤還高，今天就是多方勝，今天的收盤比昨天的收盤還低，今天就是空方勝。用幾日的收盤價來做平均就可以看出這幾日的多空強弱與趨勢了。這就是移動平均線的概念。
