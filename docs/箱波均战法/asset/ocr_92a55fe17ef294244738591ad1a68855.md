按照箱線規則言之箱波均SOP戰法

![](bbox=[0.11, 0.17, 0.91, 0.45])

畫箱 ➜ 觀缺口 ➜ 下單買賣，於上圖的 60.2 出現上漲缺口的賣出訊號，於 48.15 出現下跌缺口的買進訊號，於 47 出現上漲缺口的賣出訊號，於 45.2 出現下跌缺口的買進訊號。從這三段的利潤價差 $ (60.2 - 48.15) + (47 - 48.15) + (47 - 45.2) = 12.7 $ 的價差利潤。

我們總結華亞科從 2013 年的一月做到 2014 年的 10 月，這一年多 的價差為 $ 1.91 + 4.9 + 4.8 + 3.35 + 9.75 + 1.3 + 29.35 + 12.7 = 68.06 $，我們第一張股票是從 4.79 買進的，這價差非常的驚人，從 上面我們可以知道：箱波均的缺口操作法，不需要知道趨勢方向，一 直分段治事，就能賺到每一段的價差，再者，讀者也可以看到我們 跟著缺缺口操作法就自然而然的抓到每一個轉折點，但是需要容忍 盤整忽賺忽賠的心量，依照箱波均的缺口操作法，一步一步印的執 行，自然就能賺多賠少，邁向長期獲利的贏家了。
