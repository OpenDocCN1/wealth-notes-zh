漲到某處遇到壓力，此時收盤價一彎頭，就會出現一個 b 點，此時在上漲過程中，我們專注於畫回檔箱，此回檔箱的箱頂就是 b 點。當回檔到某處遇到支撐，此時收盤價一上勾就會出現一個 c 點，此時就能畫出回檔箱的箱底就是 c 點。從下圖我們可以看到畫回檔箱的步驟：當 b 點一出現畫出箱頂，當 c 點一出現畫出箱底，此時就出現一個回檔箱，利用此回檔箱來觀察後續要不要漲。

我們可以看下圖，當我們把 bc 這兩點的回檔箱給畫出來之後，我們會看到此時股價是由下往上勾，因此我們如何研判後面股價要不要漲呢？我們利用 b 點畫出來的箱頂來作研判，若後面的 d 點無法收盤超過 b 點，一出現收盤價彎頭，就是止漲缺口的賣出訊號。若後面的 d 點順利收盤超過 b 點，我們就把移動停利點移到 c 點。同樣的，當 d 點無法收盤超過 b 點，一出現收盤價彎頭為賣出訊號，此時股價往下跌，此時我們如何研判後面的股價要不要跌呢？我們利用 c 點畫出來的箱底來作研判，若後面的 e 點無法收盤小於 c 點，一出現收盤價往上勾，就是止跌缺口的買進訊號。若後面的 e 點順利的收盤跌破並小於 c 點，此時我們把移動停利點移到 d 點。
