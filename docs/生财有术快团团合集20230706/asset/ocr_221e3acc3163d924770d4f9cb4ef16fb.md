# 3.2 有选题/模版后，具体怎么做？

+   1)  找到业务相关话题词，如水果、团购等

2）用后森采集器爬前500条数据（不想自己爬的小伙伴私我，我给你现成的数据）

3）从一条条数据里找到共性，选题、模版共性。重点看低粉高赞、低粉高评的内容

4）按照模板1:1发（把对方图片放到软件上，图层放到最底下。然后在上面开始创作，模仿位置、字号、文案、颜色、图片等等）
