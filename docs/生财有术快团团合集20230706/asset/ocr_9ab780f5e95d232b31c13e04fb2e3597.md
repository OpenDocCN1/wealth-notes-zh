# 三、零售定位及变现期：产假不只是奶娃，而是有大把可以赚钱的时间啊

妈妈们都知道，生孩子休产假并不意味着放假休息，从孩子呱呱落地开始，意味着要开始学习做妈妈，要在短时间内学会关于人类幼崽的一切知识，意味着从此失去了一整夜睡眠，只有漫漫长夜里没有预兆的随时醒来喂奶、换尿布以及深夜喂，意味着产假里只有很少的基本工资，而房贷、生活等开销仍然在转动甚至更多。

因此，在休了 2 个月产假后，我意识到，该做副业了，生活里多一个收入进项总是好的。在成为妈妈后，虽然没法做到每一样给都娃最好的，但我不希望因为经济压力，每一样好东西都只能看看而已，却为孩子找平替。

回头看来看，很有成就感，可能别人的产假都是无止境地奶娃，我的产假成为了微信私域变现的窗口期。
