# Q：為何股價會分波段上漲或下跌？

A：為何股價上漲不會一波到底？或者下跌時，不會幾天內就一次到底部呢？為何會有一個推拖拉的漲跌過程，並讓K線圖形成如同大海波浪般的價格浮動呢？

K線理論如何解釋這點？

第三卷所提到的「費雪方程式」，可以有效說明此點。當市場上可投入股市的資金（M），乘上股票流通的速度（V），將等於股價（P）乘上股本（T）時，資金的流通速度就會影響股價。

別忘了，股市是天天開盤交易的市場，就好像水管裡的水天天在流動，不同的流速就會決定不同的價格，而資金流速正好是市場消息面的直接反應。在資金流速天天變、日日變下，股價自然不會固定在一個點上，而會形成一個浮動過程。

即使是在股價呈現一面倒上漲或下跌過程中，因為資金流速的關係，價格仍將是波動的。這是一種從資金行情來解釋價格波動的角度。
