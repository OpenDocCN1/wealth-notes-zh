# S 型浪潮：虹吸原理

投資朋友不曉得有沒有想過一個問題，為何股價從歷史走勢圖看，它的上漲很少呈現直線上揚或下跌，大多時候是呈現 S 型的波浪走勢呢？

既然股價要上漲，為何不一價到底，而要彎彎曲曲、漲漲跌跌，繞來繞去才漲到合理的滿足點呢？而股價下跌，雖然比較快，但也常有數波反彈行情，造成 S 型的彎曲走勢。

為何如此呢？

在回答這個問題前，先來談談資金數量與需求曲線的關係。

事實上，我們應該這麼理解：需求曲線本身就在反應市場資金數量的多寡，因為投資人是看好後市而希望帶錢進場買股票，市場資金水位的上升正是投資人需求向右擴張的直接反應！

資金數量增加，則需求曲線右移；資金數量減少，則需求曲線左移。就此而論，若把資金數量固定為一個常數，則在 MV = PT 的公式裡，影響股價的唯一變數將是交易速度。（補充：在市場發行股數 T 也維持不變下）
