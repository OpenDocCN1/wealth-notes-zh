# 買＝賣？股市是個變色龍

在我們繼續解讀多日 K 線的排列組合之價量奧祕時，要先補充一個股市投資的多空轉折關鍵。

先問問大家，你為何想要買股票呢？你又為何要賣股票呢？想通了這點，你就更能明白 K 線理論的奧祕。

通常一個人會想買股票的理由很多，包括看好股價會上揚、公司獲利提升、資金行情、政策作多等等。至於會賣股票的理由，則是前述利多消息或題材消失以外，還加上眾多利空消息的打擊。

但不管怎麼說，買股票的是你，賣股票的也是你，想買、想賣的都是你，這和古典經濟學對市場參與者的說法很不一樣。

在亞當．史密斯的經濟學世界裡，種蘋果的果農與做麵包的師傅，最好專注本業，在蘋果市場與麵包市場專心當生產者就好，別互換角色。果農想吃麵包時，就到麵包市場成為需求者，麵包師傅同樣也會是蘋果市場的消費需求者。兩人都不會跑去別的市場當非本業的生產者。
