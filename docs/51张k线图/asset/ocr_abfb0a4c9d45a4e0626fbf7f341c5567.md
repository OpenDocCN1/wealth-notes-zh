# 案例2、華寶的晨星圖

![](bbox=[0.148, 0.176, 0.914, 0.545])

案例2為華寶（8078）的日K線圖，在八月上旬時，股價下挫收多日黑K線，且成交量不小，意謂著是供給曲線右移導致的股價下跌。之後，出現一個跳空下跌的小紅K線，當日成交量則萎縮，意謂著賣盤縮手，供給曲線不再右移。

投資人接下來要留意，需求曲線是否跟進右移擴張呢？從晨星出現後的幾日之成交量極度萎縮來看，需求曲線雖未右移，但供給曲線已經確定不再右移了。也就是說，賣壓已經釋放完畢，投資人可以大膽布局，押寶買驚即將破繭而出的時日。

九月初，紅三兵出現，確認多頭虹吸現象發生，在晨星出現後大膽布局華寶的投資人，將有豐碩的股價上揚成果。
