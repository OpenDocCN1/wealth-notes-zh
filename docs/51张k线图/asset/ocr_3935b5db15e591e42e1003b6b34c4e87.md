# 物極必反：變盤定律

假如股票市場像個密閉的沙漏，當沙子漏到一個程度，會有人將之反轉過來，讓整個壓力的箱的虹吸現象變換過來。

那麼，我們該如何研判那翻轉的時刻呢？而那翻轉的變盤時刻，又為何會發生呢？

先回答第二個問題：「為何市場會變盤呢？」

物極必反，可說是宇宙的基本定律。

天黑之後會天亮，天亮之後會天黑；潮汐上漲後會退潮，退潮後會漲潮；月亮圓了會缺，缺了會圓。宇宙就是一個相對的世界，包括股市也不例外。

只是，剛剛的第一個問題來了：「我們該如何研判那變盤的翻轉時刻呢？」

股市像一個沙漏器，只是漏沙的時間每次都不一樣，我們無法預知市場何時是買壓大於賣壓的多頭市場，也無法知道何時買賣壓力會反轉過來，變成賣壓大於買壓的空頭市場。
