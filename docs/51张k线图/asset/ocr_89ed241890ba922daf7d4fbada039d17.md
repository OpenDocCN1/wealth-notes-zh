# 資金行情：費雪方程式

本卷，我們將為讀者解讀「酒田五法」：三山、三川、三兵、三空與二法，這五條神秘的操盤口訣，到底想表達什麼？

為了讓抽象的口訣不再神秘兮兮，我們先來剖析影響股價的五大現象：費雪方程式（Fisher Equation）、白努力（Bernoulli's Principle）流速定律、虹吸式現象、物極必反定律與群羊效應。之後，再回頭來看本間宗久透過 K 線所想觀察的股價漲跌模型。

先回到前文所說的古典經濟學，在這裡，西方經濟學者鼓勵人們進行專業的分工，並進行不受人為干預的市場交換，因為這樣做，才能得到社會總體財富增加的好處。

但現代人都清楚，當社會財富增加並以貨幣形式呈現時，市場將因錢滿為患而產生物價高揚的通貨膨脹危機。為了降低這個危機，各國中央銀行必須提高利息，以控制貨幣數量。

利息與物價，似乎是相互關聯的兩種東西。利息偏低時，貨幣數量會增加，物價慢慢就會高昂。反之，利息走高時，貨幣數量將緊縮，物價也就會慢慢降下來。
