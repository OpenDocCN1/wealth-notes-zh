# PART 2 解讀股市戰法

# 從西方經濟學看 K 線理論

假如本間宗久真如歷史傳說那樣，出生於西元 1724 年。在他出生前一年，遙遠西半球歐洲大陸外海上，英倫群島的蘇格蘭地區也誕生一位日後著名的經濟學者亞當。史密斯（Adam Smith，西元 1723 ～ 1790 年）。

亞當。史密斯被奉為現代經濟學之父，他所提出的「一隻看不見的手」（an invisible hand），為詮釋現代市場運作的最高指導原則，並成為古典經濟學的核心概念。

經濟學家後來根據亞當。史密斯的創見，逐步演繹出「讓市場飛」的自由市場概念。古典經濟學家們揭櫫一個很經典的自由市場說法，就是「市場機能」可以決定最有效率的商品價格與生產量，因此又被稱為「價格機能」。 

今天，翻開任何一本經濟學教科書，在討論個體經濟學時，都會談到「需求」與「供給」決定市場價格，而「需求」與「供給」也就是那「一隻看不見的手」。
