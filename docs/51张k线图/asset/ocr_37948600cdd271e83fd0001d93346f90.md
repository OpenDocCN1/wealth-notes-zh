# 2-2

# 消息面影響下的供需曲線

但似乎也不對啊，古典經濟學派透過市場機制所要解釋的內容是：如何為整體社會尋找最符合生產效益的商品價格和生產數量？因此，均衡價格應該最終會趨於邊際效益最適當的那個均衡點上，並靜止不動才對。

可是證券市場上的股價天天變、時時變、分分秒秒都在變動，哪有所謂靜止不動的均衡價格呢？可見本間宗久與亞當。史密斯對市場價格的看法大不相同。

是的，K線被畫成黑、白兩條顏色，反映的就是東西兩位「市場高手」的基本差異：本間宗久是一個追求個人最大私利的米商，亞當。史密斯則是一個想尋求社會最大公利的經濟學者，出發點的本質不同，對市場觀察的角度當然就有差異。

事實上，兩人在同年代、不同地區所觀察到的市場價格調整機能，是一樣的，只是兩人觀察目的不同，解釋市場機能的工具不同，腦袋中的基本理論思維也不一樣。
