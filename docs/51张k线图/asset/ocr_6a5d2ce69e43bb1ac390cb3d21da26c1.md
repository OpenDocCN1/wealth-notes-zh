# 【K線的假...問題】

+   1. 價跌量縮的黑K線：買盤縮手導致價格下跌，但供給曲線是否會右移而大量釋股？或者惜售而導致價格回穩？仍有待觀察，投資人不宜貿然賣股。
2. 量大價跌＝黑K線：持股者想大量賣股票而讓價格下跌，在趨勢成形下，應該考慮賣出股票。

一旦我們透過供給、需求曲線的變化，將量能的觀察放進來，就會明白，單日的長紅線或長黑線，還得參考成交量能的變化，才能解讀出更精確的買進或賣出訊號。否則，單看長紅線就想買股票，恐怕相當危險，這也是運用K線工具時該注意的地方。

除此之外也別忘了，需求曲線會變動，供給曲線也會，當需求旺盛而推動買盤（需求曲線）右移時，賣盤（供給曲線）也會被牽動出來，並造成盤中均衡價格的變化。這個變數一被拿進來解讀，我們就會發現K線之上、下影線的有趣變化。

# 【上影線的...問題】

舉例來說，圖9是一張需求強勁擴張的日K線圖，當買盤D於盤中快速右移時，使得股價攀上25元高點。此時，原持股者認為有利可圖而大量賣股票，造成賣盤S線右移至S1，價格開始滑落，讓尾盤均衡價收在22.5元，成為「上影陽線」或者「陽形開盤夭」。 

傳統上對此的解釋是什麼呢？表1指出，這代表「上升力強，但仍需謹慎」。要謹慎什麼呢？答案就是賣方的賣壓湧現，很可能會延續至第二天，並讓今日盤中的25元成為高檔價位。
