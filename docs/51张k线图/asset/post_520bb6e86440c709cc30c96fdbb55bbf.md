
率只是反映股價偏離平均成本的狀況，並不能與變盤點劃上等號。

更何況，所有的均線都是一個假設值，是過去10日或30日的一個股價平均值。隨著每個交易日的往前推移，平均值也會發生變化，並產生動態的移動。

當日市價乖離過去均線的幅度，只是一個參考值，很難是一個必然發生的變盤點。因為市價與均價都在動，在一個強烈的多頭或空頭市場中，股價嚴重向上或向下乖離平均值，也很正常。投機者很難說正乖離或負乖離多少，就是賣出或買進的訊號。

較安全的運用法是使用 BIAS 指標時，除參考乖離率數字外，還參酌比較 K 線型態，尋找並研判股價底部與頭部的變盤訊號。

另一個由乖離率衍生出來的著名技術分析指標叫「相對強弱指標 RSI（Relative Strength Indicator）」。RSI 指標的原理是假設收盤價是買賣雙方力道的最終表現與結果，並把上漲視為買方力道，下跌視為賣方力道。

可以把過去一段時間的股價收盤較前一天上漲的點數，加總起來，得出一個總漲幅，再除以 N 日，得出一個 N 日平均上漲幅度。同時把同一段時間，收盤價若較前一日下跌的點數，加總起來得出一個總下跌幅度，然後再除以 N 日，得出一個 N 日平均下跌幅度。

把過去 N 日股價平均上漲幅度與下跌幅度加總，當作分母，再把 N 日平均漲幅當分子，就能得出過去 N 日的股價漲跌強弱度。

其公式如下：

AUₙ 表示：n 日內收盤價上漲點數的 n 日平均數 = Σ（上漲點數_i）／n

ADn 表示：n 日內股價下跌點數的 n 日平均數 = Σ（下跌點數_i）／n   RSI = 100 × AU_n ／（AU_n + AD_n）

如果聽不太懂這意思，我們可以換個角度來說明。就是把過去 N 日股價的正乖離與負乖離幅度，加總起來，得出一個上下乖離的平均值當分母，且視為 100。則 N 日內股價正乖離的天數若大於負乖離的天數，且漲幅也較大的話，RSI 會高於 50。

如果 N 日內，股價只漲不跌，完全無負乖離時，則 N 日上漲幅度的分子會完全等於分母，而使 RSI 等於 100，為最強勢。

但若 N 日內股價都是負乖離，而無上漲幅度時，分子將等於 0，而使 RSI 等於 0，為最弱勢。

RSI 只是反映過去一段時期的漲跌動能之百分比分而已，沒有明確規則顯示高於 50 為買進或低於 50 為賣出訊號。或者 RSI 指標來到 100 時該賣出，或降至 0 時代表該買進。

RSI 只是把過去股價相對漲跌的強度數值定義在 0 ～ 100 之間，方便投機者理解過去 N 日的漲跌趨勢與強度。拿 K 線指標來理解，就是把過去 N 日的紅黑棒子統計起來，看是紅棒子多？還是黑棒子多？再看是紅棒子長？還是黑棒子長？

把過去 N 日陰陽線發生的天數與每日柱體長短加總，得出紅與黑的比例：大於 50 表示紅大於黑，上漲動能強；小於 50 代表紅小於黑，下跌動能強。這樣的概念便趨近於 RSI 指標的意義了。

總結而言，RSI 指標僅止於計算陰陽線的強弱動能而已，離觀察變盤點還有點遠。投機者很難直接拿 RSI 指標就來進行合理投機點的設算。

## KD 指標與 K 線的差異？

許多證券投資人常把 KD 指標與 K 線混淆，以為兩者是相同的東西。實際上，同樣叫 K，但兩者相去甚遠！

KD 指標的正式名稱叫「隨機指標」，它是由 K 值與 D 值兩個數字所構成。至於 K 值為何叫 K 值？D 值為何叫 D 值？這只是發明者隨興所取的名字與代碼，沒有任何意義。

這個指標是先找出近 N 個交易日中，最高價與最低價的價差幅度，然後計算出當日收盤價與最低價間的差距幅度，稱為未成熟隨機值 RSV（row stochastic value）。

```
RSV = (第 N 天收盤價 - 最近 N 日內最低價) / (最近 N 日內最高價 - 最近 N 日內最低價) × 100
```

由 RSV 的求算公式可看出這也是一種融合平均線、乖離率與強弱指標的工具：當股價處於多頭時，收盤價有往當期最高價接近的傾向，這時候 RSV 值將不斷上升；而在下跌過程中，收盤價有收在接近最低價的傾向，這時 RSV 也會傾向下降。

RSV 值本身就能判斷股價強弱。RSV 等於 0 時，表示當天收盤價是 N 日內最低價，而當 RSV 等於 100 時，當天收盤價是 N 日內最高價。如果 RSV 等於 50，則表示收盤價在高低價的中間。

市場上另有一個著名的技術指標叫「威廉指標」，其數字就剛好是 RSV 值的倒數，反應的也是低點買進或高點賣出訊號。

RSV 反映當日股價與過去 N 日股價漲跌幅相比之間的強弱位置，如果把今日 RSV 數字縮小為 1/3，再計入前一天的 RSV 權值為 2/3，將得出一個短期上漲動能 K 值。

再把 RSV 進行移動計算，把最近三分之一 N 日的平均漲跌趨勢加總起來，放大其權值，再加權平均入前一天的落後動能，投資人可得到一個近期緩慢上漲動能之平均趨勢，稱為慢速移動值 D。

當日 K 值 = 前日 K 值 × 2 / 3 + 當日 RSV × 1 / 3

當日 D 值 = 前日 D 值 × 2 / 3 + 當日 K 值 × 1 / 3

這意思是什麽呢？當股價向上或向下移動時，當日股價會領先平均價格而向上或向下滑動，K 值計算的就是這個短期內股價向過去 N 日之最高、最低價位快速移動的動能。

D 值是 K 值的「加長與加權移動平均」計算法，以得出一個觀察時間較長、較為慢速但比較明確的短期漲跌動能趨勢。所以，K 值可稱為漲跌動能的領先指標，振幅大且比較不穩定；而 D 值為漲跌動能的同步指標，能顯示相對較為明確的上升或下跌趨勢。

透過領先與同步指標的訊號落差，投資人可以掌握追漲或追跌的趨勢：當股價上漲時，K 值、D 值都會向上增加，但 K 值會領先 D 值上漲，而呈現黃金交叉的買進訊號。

反之，當股價呈現下跌趨勢時，K 值與 D 值都會向低點區域移動，而 K 值會領先 D 值下跌而呈現死亡交叉的賣出訊號。

從 K 線理論的角度看，我們該如何理解 KD 指標呢？其實，根據第三卷的虹吸原理所述，KD 指標就是在計算股價買壓與賣壓之移動趨勢變化的徵兆，或說，測量供需曲線的移動強弱趨勢，以研判股價壓力箱裡的壓力變化。

根據股價五大漲跌原理，當市場買、賣壓力出現變化時，就容易引發 S 型虹吸現象的發生。KD 指標就是計算買賣壓力變化的一種數據指標，與 K 線理論常有互補之處。

請記住，K 線是透過觀察跳空、晨星、夜星、十字變盤線等 K 線型態來觀察行情轉折點與變盤點，並希望提早在虹吸現象發生前或當下，布局股價移動趨勢。

但 K 線理論可以觀測出變盤型態，卻無法精確計算出市場背後之買壓、賣壓的力道消長，而 K 值、D 值的數據變化卻可以。當 K 值訊號由低變高時，代表買氣正在激揚。但這是一個暫時性的激情？還是明確的翻轉訊號呢？就要透過加權平均後的 K 值變化，得出 D 值的緩慢卻同步變動之趨勢。

當 K 值與 D 值雙雙由低向上走時，就代表股價由低翻高的變盤力道正在增強。反之，股價在高點反轉時，KD 值也會發生由高往低走的買盤減弱反應。

以正常狀況來說，KD 值訊號出現由 20 往 80 的移動過程，往往是 K 線出現紅三兵的 S 型股價虹吸式上揚階段。而 KD 黃金交叉時段則為變盤後要發生紅三兵的初始上漲動能萌生階段。

反之，黑三兵發生時，也會出現 KD 值由 80 往 20 滑落的下跌訊號，此時，KD 死亡交叉也常發生於黑三兵之前。投資人只要明白這個原理，就能相互運用 KD 指標與 K 線理論的長處，得到加乘運用的效果。

試著模擬 KD 指標的變化：當股價底部的變盤十字線發生時，當日 K 值與 D 值是不是都會處於過去 N 日的最低價位上？也就是說，KD 價都會進入 20 以下超跌區呢？

事實上，一旦十字變盤出現後的隔日，股價連續收紅時，K 值就會領先上揚，然後拉抬 D 值慢慢上升，並形成黃金交叉。這個時候，投資人就能夠明確確認變盤完成，上漲的買壓已經大於賣壓。

反之，當股價高點發生跳空夜星或十字變盤線時，收盤股價也將處於 N 日高點價位 K 值與 D 值都將來到接近 100 的超買過熱區。一旦變盤後賣壓浮現，股價開始向下移動時，K 值將領先反應而向下遞減，同時拉下 D 值訊號，形成死亡交叉。

KD 指標可以說是把 K 線變盤完成後的買賣壓力，透過數字的計算，而得出一個具體化的消長結果：KD 黃金交叉為買壓遞增的買進訊號；KD 死亡交叉為賣壓遞增的賣出訊號。

KD 指標在實務應用上的最大盲點是：訊號高檔鈍化問題。也就是說，股價急漲與急跌過程中，每天都會創新高價與新低價，則處於高點區或低點區的 KD 值，會出現接近 100 與 0 的動能過熱、過緩與沒反應的狀況，讓投資人無從判斷高低點而發生高點太早賣、低點又賣太慢的落後反應。

徹底明白 K 線背後的股價漲跌原理，搭配 KD 值計算出買賣壓力的強弱變化，則 KD 指標搭配 K 線變盤圖則就能得到加成效果。

## 亞當理論最得本間宗久的心？

在所有的西方技術分析理論當中，我覺得亞當理論最接近K線理論。接近，不是兩套理論的觀察工具相近，而是他們的核心思想最接近。

亞當理論的核心精髓，可以用撰書立著者王爾德（J·Welles Wilder）的話來說：「我們談的不是什麼偉大、複雜的東西，而只是非常簡單的事情，那就是『什麼東西管用？』」

什麼東西管用呢？能賺錢的方法最管用。在投機的世界裡，能協助投機者捉到價差的方法最管用。

亞當理論非常強調自然趨勢，也就是相對於直線、人工畫出來的趨勢線而言，亞當理論關心的是：市場伴隨股票價格趨勢而產生的自然運動趨勢，也就是著名的 Delta（對稱）現象。

Delta 現象認為，趨勢就是一再重複的事，而準確的重複會造成「對稱」的情形。那麼，什麼事情會造成市場完美的對稱？一個是與目前時點的接近程度，一個則是該點的速率。

也就是說，市場愈接近「目前」的時點，而且市場移動速度愈快，則市場本身預測的未來走向就愈準。

在本書第三卷中，我透過資金定律、努力定律與虹吸現象這三者，詳細說明股價漲跌原理，相信讀者們基本上對於亞當理論有另類的詮釋法。

股價對稱現象，來自於市場交易速度，以及投資人交易時的相對位置。

舉例來說，當我開始觀測與預測股價的那一天，如果市場交易相當熱絡，而過去 5 天股市又有強勁上漲趨勢，那麼在同樣市場流速下，未來 5 天繼續漲的機率就偏高，因為這是一個動者恆動的對稱關係。

但如果我把預測值提高到 10 天，如果過去 10 天股價也是呈現強勁上揚，但因為預測的數字資料離現在的時點太遠，我要 預估 10 天去預估未來 10 天的股價走势就容易失真。

另外，我選擇觀測股價走勢圖的那一天，如果市場交易緩慢，則我要預測未來股價走勢的難度也會加高，因為預測一條緩慢河流的走勢遠不如澗涓溪水簡單直奔前村那般簡單。

市場交易速度與投機者的觀測位置，正是所有技術分析理論的運用堂奧。亞當理論可以說是完全直指核心，把這項要點詮釋得非常清楚。

對 K 線理論來說，K 線觀察的並非市場客觀不變的運作法則，而是要觀察市場的變動法則。市場在變，交易者在變，連使用 K 線的人自己也在變。既然大家都在變，那麼不變的就是如何變中求變，在市場變動中，彈性變動自己的投資步伐。

K 線圖則沒有標準不變的答案，一切端賴自己的獨立判斷。所以本間宗久透過《三猿金泉祕錄》一書，用三猿為比喻，揭櫫他的賺錢祕方：第一個心法是「非禮勿視」，第二個是「非禮勿聽」，第三個是「非禮勿言」。

- 非禮勿視：不可執著於表相，必須看出行情背後意義，陰線及陽線會不斷的互換，特別注重行情反轉的判斷。
- 非禮勿聽：勿以消息面作為交易的根據，影響價格走勢的不 是消息事件本身，而是交易者對消息所做出的反應。
- 非禮勿言：勿與他人討論行情及市場策略，可以傾聽別人的看法，但必須具有獨立思考及判斷的能力，否則，太多的討論將影響你的判斷。

股市沒有標準答案，一切都仰賴自己的判斷。本間宗久所謂的三猿祕密，我認為也是亞當理論的核心宗旨，值得投機者多加留意，以避免在股價趨勢上產生執著心：囿執於眼所見的 K 線型態，執著於耳所聽的多空消息，甚至發出我可以預測股價的狂妄言論。

當一個投機者無法倒空自己，無法臣服於市場而隨股價趨勢而走時，江爾德在《亞當理論》一書中警告說：「非要讓外界服從自己，這種心態遲早會把自己毀掉！」

本間宗久地下有知，聽到這話應該也會拈花一笑吧！

## 酒田戰法的根本心法——本來無一物！

酒田戰法的根本心法是什麼呢？

據說本間宗久晚年遁入空門，學佛去了。一個富可敵國的米市投機者，最終放空一切，遁入佛門，這個歷史寓意極深。

我無法找到本間宗久晚年生活究竟如何的確切證據。但佛學喜談空，而「空」，就是我認為 K 線理論的根本奧義。

提醒一下，這是我所理解的本間宗久與其 K 線理論，不是本間宗久翁託夢或降乩來告訴我，一切只是我身為作者的理解，並闡述這個原理出來與喜好技術分析理論的讀者分享。

空，是什麼意思呢？為什麼「空」是酒田戰法的奧義？

我把我所理解的投機成功之道，以及酒田戰法的根本精神，解釋為「五空」，以作為本書結論：

- 1. 預測空：並上沒有活神仙，K 線不是百發百中

許多技術分析的愛用者，喜歡運用技術分析工具預測未來。但事實上，這是一個很危險的態度。就好像一個登山者，想要征服高

山，因此運用一切工具就是要挑戰絕對高點，最終卻葬身於深山叢林中一樣危險。

技術分析不是挑戰股價絕對高點與低點的工具，而只是投機者跟著市場趨勢，尋找柳暗花明又一村的趨勢轉折點之工具指標。

投機者一定要把征服市場的雄心壯志放空，才有辦法使用技術分析工具卻不執迷於其中。世上沒有百發百中預測市場、預測未來的活神仙，相信一個能挑戰市場的預測值，不如選擇尊重市場，謙卑柔軟，隨時調整對市場的看法，才有辦法低進高出，在投機的市場持盈保泰。

- 2. 對錯空：看對就衝，看不準就休息

股市是一個相對的世界，也是一個變動的世界。在一個沒有黑白道理的投機世界裡，投機者為何要去爭辯對錯呢？

投機者除了不該跟其他人爭論誰的看法對，誰的看法錯以外，更不該獨自一人跟市場對話，並與市場拔河爭論是非。

投機者從K線型態看到了上漲的趨勢與訊號，並不代表市場必然會漲。投機者從K線找到頭部變盤點時，也不代表市場未來一定要跌。

市場背後還有一個更高的主宰者，任何人都捉摸不住其規律。投機者看對行情時應勇敢衝刺，但錯了，就要收手，虛己以待未來，不要停留在錯誤的挫敗中，更不要固執己見為對。

一切都是大自然與市場無情的力量在運作，在股價律動之中，永遠有測不準的風起雲湧、山色變幻。投機者要虛心以待，因為與其執迷於自我的判斷，不如經常放下自我，以空無的心來看市場。當股價無心以出岫時，再坐待雲起，參與市場。

- 3. 澄意空：居心觀察行情趨勢

萬事萬物皆空，市場消息更空。投機者最忌諱杯弓蛇影，看到影子就開槍。因為技術分析在捕捉市場參與者的集體心理反應，這常讓一側自以為冷靜的投機者，卻常成為市場上最衝動的人。

投機常常失敗，是因為經驗豐富，而不是經驗不足。

投機常常失敗，是因為掌握的消息太多、太早，而不是消息太少、太晚。

獵人遲早會死在獵槍底下，魚夫遲早會淹死在大海之上。原因是什麼？是因為他們太專業，以致於誤判形勢。當一個善於研判技術分析工具的人，知道如何捕捉市場根據消息面所做出的買進、賣出反應時，往往他最終自己就會死在消息面上。

觀察別人對消息面如何反應，卻忘了自己也根據同樣消息作反應的人，就好像沒穿衣服的小孩，嘲弄國王沒穿衣服。

放空自己對消息面的反應情緒，冷靜觀察眾人對消息面的反應，才是正確的投機之道。

- 4. 市場空：睥睨獨尊，逆勢操作的勇氣

買進訊號浮現了，但市場一片悲觀，你敢買股票嗎？

賣出訊號出現了，但市場景氣大好，你捨得賣股票嗎？

你是否能克服自信不足的人性弱點，勇敢去走一條屬於你自己一個人的道路呢？

你有沒有勇氣一個人獨行於投資市場上，不從眾而行，也不呼朋引伴，只是一個個人走自己的路——不管那條路是羊腸小徑？還是康莊大道？

喜歡反市場操作的投機者，往往會犯了高點不願意再追高的毛病，因為他習慣獨自獨行，不喜歡跟著大家一起走。但他卻不知道，有時混入人群裡，一樣是千山我獨行。

喜歡追高殺低的投機者，往往會犯了死在最後一浪的問題上，因為他知道如何順勢操作，高點追高、低點殺低，只要嚴格做好停利、停損的紀律，積極領軍衝鋒的效果極好。但重點是，別在行情反轉時，忘了當改變看法的第一個領導者！

第一個改變看法的人，往往是寂寞又勇敢的人。不管是人氣渙散的羊腸小徑，或人氣旺盛的康莊大道，放空市場，放空眾人，永遠走自己的路，是投機者成功的主要條件。

- 5. 股價空：唯偽不空，別迷失在金錢遊戲裡

你錢賺很多了？很好！那接下來呢？你靠著以小搏大的投機必殺祕技，在股價波動的市場撇走了可觀的財富，讓年輕的你，口袋多金而響亮。

但接下來呢？你該如何守住你的財富？

夏天溪水氾濫時，一個擁有一整條溪流的人，如果以為一輩子都不缺水喝了，恐怕是一個最傻也最妄自尊大的人。

投機的財富如溪流，易暴起，易暴落。多頭行情賺到的錢，不是投機者一輩子的錢，除非他看空一切，徹底帶著財富離開空幻的市場。

萬事萬物皆空，市場空，股價更空。世間不空之物，是生養萬物之物。

冬天萬物不生，而春日草木重生。那個主宰生命生機的大自然力量，看得見？摸得著嗎？

試著把股價想成春日的水草，在夏日豔陽下舞動，但是仍也會凋零於秋日，死亡於冬天。

股價只是股票的表象價格變化，在萬物皆空下，不空的是股價背後的东西。投機者在追逐空幻的股價時，別忘了時時提醒自己，你賺到了好幾桶金，接下來呢？

股價會空，什麼是你人生不空之物呢？
