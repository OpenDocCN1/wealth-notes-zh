# PART 4 圖解K線的祕密

就像水管裡的水流，形成一個拉著一個的趨勢，並不容易反轉。因此，黑三兵也是行情短期內不易上漲的徵兆。

標準的黑三兵，像紅三兵一樣，通常也會下列基本型態：

+   (1)三根黑K棒的實體幅度不會太小或太大，通常為整齊的中黑線型態。

+   (2)會有上下影線，但不會太長。第一根黑K線常為留上影線的剛沖天炮；第二根則常有上下影線；第三根則有短下影線。

+   (3)三根棒子的實體高低幅度相近，高低點不會差距過大，並形成交疊型態。尤其是三支中的最後一支，實體幅度不可突然縮小。若突然縮小，代表跌勢可能已經收斂。

運用黑三兵和紅三兵一樣，要確認是上檔黑三兵，還是下檔黑三兵，也就是說，在股價頭部區發生的黑三兵，比較能確認為行情大幅回落的型態。至於在股價底部區發生的黑三兵，則可能意味著下跌走勢的來升段，底部常會因為下跌量能釋放完畢而日益接近。

觀察成交量能大小，也是確認黑三兵之真實意義的好方法。通常，上檔黑三兵常伴隨著成交量能的放大，代表賣壓快速湧現，而在第一根黑K線有極大套牢量的狀況下，隨著第二根黑K、第三根黑K的出現，原先看好的買盤便可能產生失望性賣壓，讓行情止跌不易。

相反的，下檔黑三兵常常伴隨著成交量萎縮，也就是說，是買盤萎縮導致價格下跌。在賣壓相對不重，且股價已低下，買盤隨時有可能因股價觸底而湧現。因此，黑三兵的型態也有可能是利空出盡的好消息。
