# 圖 4、股票市場的倒虹吸現象

![](bbox=[0.18, 0.188, 0.77, 0.49])

當我們一樣用一根管子，放到兩個倒過來的盆子下方，然後把管內的水吸乾，讓白色的空氣進來時，則水壓會向上壓迫左邊盆子的空氣，使得空氣向下流進彎管內，然後，再透過空氣分子相吸的原理，加上下方盆子的水壓大、上方盆子壓力小的關係，白色空氣最終會全數流向高處的盆中。

這就是我們剛剛說的，倒過來的虹吸式原理，是水的壓力促成空氣如同正常版的水流一般，形成氣體在高低兩個倒盆間的 S 型虹吸現象。

現在，我們把藍色的水想成市場上想買股票的人，白色的空氣想成想賣股票的人，則當密閉的箱子裡，也就是證券市場，發生資金湧入現象時，市場買壓會增加，而股票持有者的持有價位則會被推升。
