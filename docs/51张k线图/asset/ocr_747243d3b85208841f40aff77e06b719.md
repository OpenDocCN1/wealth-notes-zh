# 群羊效應：跳空定律

當我們從質雪方程式來看證券市場時，將能尋找到一種從市場資金數量、交易速度所對股價造成影響的解釋模型。這個解釋模型是一種純粹從資金流通角度所觀察出來的交易遊戲規則。

當我們從資金流速關係來觀察股價變化方向時，又將能衍伸出從白努力定律這樣的流體力學角度，試著觀察交易速度對買壓、賣壓的影響，並尋找到股價漲、跌的原理。

當我們接著從流體力學之虹吸現象來觀察證券市場時，又將發現股價總是呈現波浪上升或下降型態的道理與祕密。

當我們再從宇宙物極必反的定律來觀察股市時，又會發現，股價的上升或下降趨勢不可能恆常不變，而透過單日K線、多日K線的顏色與排列型態，投資人將能提前嗅到市場物極必反法則下的變盤訊息。

透過前述四大定律，我們幾乎已經完整解說一個從資金流速觀點所看出來的股價變動模型，並開始逐漸理解到，原來活在二百多年前的米市操盤高手本間宗久，早已利用K線來觀察資金流速觀點下的市場價格變化。
