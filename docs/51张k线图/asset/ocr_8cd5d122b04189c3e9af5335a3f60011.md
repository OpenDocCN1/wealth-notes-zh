# 觀法 1 大陽線

![](bbox=[0.2, 0.188, 0.228, 0.255])

【大陽線的總線解讀】

實——大幅開低收高的陽線，此為漲勢訊號的一種，依其陽線的長短另有中陽線和小陽線等，從其陽線的長短幅度可以臆測出當日的漲勢強度。

【近線的價量解讀】

+   1. 價量俱揚的紅 K 線：反應需求擴增，買股者眾增的現象，在市場買氣旺盛下，投資人可以考慮買進。 2. 量縮價揚的紅 K 線：因持股者惜售而導致價格上揚，但日後市場買方的需求是否跟上，仍有待觀察，投資人不宜貿然買股。

# 觀法 2 大陰線

![](bbox=[0.205, 0.642, 0.23, 0.71])

【大陰線的總線解讀】

實——大幅開高收低並以「長黑」收市，此為跌勢訊號的一種，依其陰線的長短另有中陰線和小陰線等，從其陰線的長短幅度可臆測出當日的跌勢強度。
