# 第37问答 | P2P关键信息是

**青梅煮酒：** 能不能讲讲P2P？有学者说股市是零和博弈，而P2P是正和博弈。

**王烁：**
你说的这学者是谁？你请他给出来，保证不打他。任何合作能创造更大价值的事情都是正和博弈。P2P和股市都可以是正和博弈，当然，也可以说，它们都是正和博弈和零和博弈的复合体。

先说股市。股市投资收益可以分为贝塔收益和阿尔法收益。所谓贝塔收益，就是**市场收益，股票作为一类投资品在长期中的预期回报，这是正和博弈**。你我有得，当然可以取我的之所失，反之亦然。所谓阿尔法收益，就是交易产生的收益，因为一方的能力、信息优势而获得的超额收益。**如果不考虑交易费用，全市场的阿尔法收益之和为零，它是零和博弈**。所以，所得是我之所失，你死我活。

再来说说P2P。所谓P2P，原意是点对点，变成一种金融模式后是个人对个人贷款。好比你我向对方借钱，这种事情自古以来就有，现在通过互联网技术，在更大的规模上匹配有闲钱的人和资金需求的人，创造此前没有的价值。这就是正和博弈一面。

借钱最大的问题是信息。我想钱借给你，你还没有交代，我不愿意。银行本质是信息中介，它愿出风险，把闲钱拿出来，放给需要的人，中间它承担风险。**P2P越过银行，但它有没有掌握这些关键信息呢？**

绝大多数P2P没有这个能力，没有关键信息，不能鉴别贷款人的信用。如果他并不能鉴别骗子，那你就成为零和游戏。骗子骗走多少，你损失就多少。更主要的是，这种P2P往往是挂羊头卖狗肉，名正是一个个人对个人贷款，实际上是它在利用自己建立的资金融通，把贷款人的钱放进池子里，滚动操作。**本质是银行业务，问题是P2P并不持牌，亦不受银行监管。**

这游戏很危险，所以一度那么多人玩，原因也很简单。对P2P公司的创始人们来说，这件事看做免费使用期权，玩得下去就玩，玩不下去就跑路。
