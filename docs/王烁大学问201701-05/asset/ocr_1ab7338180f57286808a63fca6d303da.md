# 四、奥巴马管辖的变革

本章曾经讲过中位选民定理，即两党政治中，为争取最大数量的选民，两方政策取向会趋同。美国政治改革历史曾经相当符合中位选民定理的预测，但十几年来的政治实践离中位选民定理预测越来越远，极化越来越严重。

在一系列问题上两党相争，共识越来越少：怎样对待伊拉克战争？怎样对待酷刑？怎样对待同性婚姻？怎样面对人证？种族问题更是房间里的大象，不讨论，假装看不见，但政治动员力极强。

有分歧是政治常态，没有分歧就没有政治可言，但有分歧又有政治是型态。两党合作空间越来越少，而政治撕裂越来越严重。美国政治是典型的钟摆政治，总是来回摆动，不会长期朝着一个方向狂摆。今天美国政治还没有脱离钟摆状态，但摆动幅度显著加大，有摆动夸张化态势。

奥巴马的成功之处也是其失败之源。他找到时机，在民主党长期势力的几条战线强行突破，比如普遍医保，又比如同性婚姻。只是，强行突破的后果都成功难以长久。对方一旦得势，反卷来得会更加凶猛。奥巴马政策今天已难保全。

前民主党全国委员会主席霍华德恩思尔耶鲁法学系人们说，这一代台前的美国政治家们都应该读下来，**美国人民真正需要的是互联网**，新一代领袖。我知道他的意思。换新元，带来新思维，放下一个历史包袱。若超越两党争斗已经从中间的历史一个泥潭，必须要重新表达问题，因为老问题已成死结。

我问，可是，奥巴马不正就是这样一个总统吗？

迪恩苦笑了，一定要我说，我觉得奥巴马太一意孤行。

迪恩说，我对美国政治没有了解得那么深，照景而已。说起多年前，奥巴马以“变革（change）”口号崛起时，一位美国外交官告诉我，设想当美国总统都会向民众和把自个定位为局外人，声称要打破现实，但没人能做到。

奥巴马确实做到了，在任上：

+   ——他兑现了承诺，结束战争，让美国士兵从中东回家，但中东近年成为向世界输出恐怖之源；
——他与伊朗恢复双重关系，伊斯兰世界随即兴起新的大国争霸：伊朗对沙特；
——海豹突击队干掉了拉登，但ISIS起；
——他通过了奥巴马医保，但即将被触礁；
——他促成同性婚姻合法化，但美国最高法院将裁决。

奥巴马其实是近年少见的为美国总统，卓越的战略家，在政治极化、僵局难破之际，仍抓住机会做许多他想做且承诺过要做的事情，但这些成果现在看都暂时取得成功难持久。高度、把握、激烈的政治博弈中，任何人、一时得手，无法持久。

说不清是政治极化造就了奥巴马，还是奥巴马打法加剧了政治极化。

今秋，纽约街头，几个街头黑人头小伙子行骗，向我收钱的时候歇声叫道：Obama wants change, we want 20!【奥巴马只要零钱（变革），我们要20美元！】

现在，川普总统要就位了，撇不好他是那个真正打破现状的人。

# 五、漫长的衰落

在名著《罗马帝国衰亡史》中，吉本开首问，衰亡不可怪，奇绝的是为什么罗马帝国衰亡要花长达三百年时间？

吉本用煌煌六卷本回答这个问题。一言以蔽之，则是罗马败于缓慢的内溃，政治、观念、经济、军力缓慢败散，终至衰竭。外敌只是表征，实为最终罗马自己。不是因为他们衰落而成为罗马自己太疲惫，反倒来说，罗马衰亡三百年才灭亡，也是因为它体制没有真正的外部竞争对手，没有什么别的值得与它相搏。—全界只有等着它慢慢衰落，衰得，然后一阵风吹它吹倒。**替罗马留下来的空间不是新帝国，而是漫长的黑暗期。**

# 六、危机还是陷阱？

在耶鲁期间选了门全球政治课，其实它是门读课，老师选了十二本书，学生每周一读一本，每一个小组作读书报告，另一个小组要每问抽出本节中其他节的关联。耶鲁是要鼓励，这个读法与选读课那种课后生，读书报告和课堂讨论的水平很高。许多人问我的，这门课我明白，那么，要做，最有效，为你个学心，把这门课的做法复制到微观，先找个老师列个书单，用微信组建学习小组，每周轮作，学习的办法多得很，关键是学会与自己博弈。

回到正题。

**《信心陷阱》**（The Confidence Trap: A History of Democracy in Crisis from World War I to the Present）是我在进门课上的第一本好书，主角民主体制韧性极强，也因为其本性而使人陷入过度自信的陷阱，以为主体体制必然能应对内外挑战，因而作出非民主失控的预言。从副标题就能得出：作者娜塔曼逊研究现代民主体自我一战以来的历次挑战，每次大敌当前，形势危如累卵，但民主制最终都能应付下起来，危险如夷。一战、二战、冷战，哪一次不是比现危更机？除了没有危机，而是在常态危机中，正是因为时常遭遇危机而又都安然渡过，才会抛入过度自信陷阱。

读这本书，你一定会：此时此刻，是历史上发生过的哪种危机又一次当前呢还是掉入了自信陷阱？这本书本身却无答案，因为答案是靠人做出来的。

1月20日，川普执笔。
