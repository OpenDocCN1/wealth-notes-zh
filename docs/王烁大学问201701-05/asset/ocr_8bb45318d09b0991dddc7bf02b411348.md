# 生命周期投资法：你是股还是债？

在前一篇文章《生命周期投资法》里，艾瑞斯和巴里两位发明家给人每年投了一笔保费，而且是年轻时在仅要把钱年轻人投到股票，而且这还不够，还应加上杠杆。听起来很极端，背后真有理支持。你未必需要照做，某些在做的活，是要满其前提供条件中哪些适用于你适合你能够握着的市场和投资工具。大胆可以，但自己要知道凭什么大胆，千万不要太大胆。

艾瑞斯和巴里讲了一个问题：他们只看到了铁，也就是财务资本。但人在资产总盘子里。财务资本只是一半，还有人力资本。脱命人谈财务资本的周期管理，怎么办？

人力资本就是你用工作换收入的能力，理论上也有个玩准，就是一生收入贴到今天的总和。艾瑞斯和巴里用这个值来算你应该投资多少到股票上，但到此为止。

太简单了。

首先是人力资本有其周期。人出生时财资产为0至人人力资本。去死的时候则为0。至0人生周期。比如过去，眼时人力资本，人力资本作为一类资本其也是风的。资产的收益就是劳动力收入会有波，不光是随各人生的，少-青-社会中周期波动，也随着科技能的市更迭而波动，极情况下，不到人去世它可能归了。给字印刷的时代，再熟有用？

厘清人生资产总盘，人生周期投资发展更深一层，人成长到成年轻时较多有股票，随着年成而逐减多股财务投资，不能说是，不够精准。因为必须看看你的人力资本像什么。

如你的人力资本比较债券，如你是公务员，预期未来较稳定，那么你的资产总盘里就有人工，相就你一开始的财务组合中，就没必要再配。应该配股票，样你人生资产总配就是合理的。

事情情情，随着逐渐成长老，你的人力资本渐耗，就是人资本组合中，债券部分减。为抵这个因素，要相应多点债券。

这个故事跟爱斯和里的推是一致的。但是，如果你的人力资本比较股呢？

如你的人力资本股，如你是基本独立，未来的收入资本组中是相对那，那么你的资产总盘里实际上就有人工有量股，相地，你一开始的财务组合中，就不配股，而反是应尽可能配。

着你逐成长老，你的人力资本渐耗，生组合中，股部分减，为抵这个因素，你要多配股，越越需要在财务组合里多配股！

这个推认，你多啰。

你的人力资本股还是债券？这个问题很有答案。公务员还有下岗，界个上有聪明，事人。但是，多想这上聪明人，家你的人生，能做出合理的财组，以配人生产总的总结合。要不加杠杆？艾瑞斯和里的话只一，另还自己。

+   一些推论：

- 第一，不要买自己就公司的股票。这等将你的人力和财务资本全股票资产里，且在一个股票上，反义。股跃呼喊AI，他他理由，不要学。
- 第二，投资类似股。一项研究，美国大学生人力资本（年成增长）明显著于大的人，更大。
- 第三，数人的力资本在地，所以财务产得外配置。如你工新经体，你人力资本就天有性，海外配产多配性。同着老，力资本渐，性不，这时海外资产配置要增股。
- 第四，工作收入负相关，限地放。
