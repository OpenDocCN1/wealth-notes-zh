# 用同理心寻找复合成长

这是个别特苏台。一群耶鲁本科学生坐在会议桌旁，主讲位坐的是张磊，高瓴基金创始人；身旁主持的是大卫·斯文森，耶鲁大学基金管理者、传奇投资人。你想知道细节更多的，请往前翻本专栏7月9日、11日发过的文章。

这里是耶鲁校友基金的会议室，也是斯文森的课堂。

几十年前，每周一下午一点，斯文森会挑精选出来的16名耶鲁本科生上投资课。今天的讲人张磊再合适不过。

十年前，张磊从这里出发。耶鲁商学院毕业后，他在耶鲁投产基金做分析师，然后创业。耶鲁投产基金给他投了1000美元。经常投没有业绩记录风险的他能标井获得成功，是斯文森投资风格的重要标记，在投张磊上获得的成功却超过了当初所有想象。

才十年，高瓴资本就发展成为亚洲最大的美元PE基金之一，管理200多亿美天资金，规模已不于耶鲁大学基金本身。今天张磊自己也成为耶鲁大学校友，成功如此快如大，通势木犹不可。

高瓴资本的英文名称Hillhouse取自耶鲁校园里一条路的名称，路边是经济学系，路石是杰克逊国际关系研究院，我在这里来回走了四五个年，每到从来到，红叶满地，新英格兰之秋极美，自然与人文相得互益，浓缩在这条路上。

从张磊所投心得中，我挑出印象最深的一点，根据笔记整理加工，如下。如有错漏，一切在我。

# “教科书式投资”

张磊称高瓴投资耶鲁投产基金，是教科书式投资。斯文森出身耶鲁，是耶鲁教授、诺贝尔经济学奖得主托宾的弟子，真正的学院派：寻找阿尔法的前提，是真正超越贝塔之难。

张磊自陈脱胎于耶鲁投产基金，“投资这件事，我是在那个办公室里学”的，因为没有在任何别的地方学过。世界观，价值观，金融教科书用了用不了？张说，高瓴经历证明，教科书式投资真管用，哪怕在中国也能管用。

不过，只知道教科书，不知道现实的杂七杂八，事实上可能是有对的。设想看，要是投资生涯是从深厚交易或短线投机起步，反查教科书来，张磊会成为什么样子？

所谓教科书式投资，张磊认为就是长期投资，投资于价值，投资于合理（make sense）的东西，比如高频交易这些对他来说就不合理。简单明了的东西则比较容易是合理的。

说来简单，但合理这门槛并不低。

# 聚焦

追求长期价值，追求合理性，偏向简单明了。张磊说，最好一年只需要一个好主意就够了，而不是一年必须有50个好主意。

找到一个好主意，然后让它在时间中成长。纲举自张，这番逻辑会重置你的行为、所领导的组织以及自己的生话。

要选择战场，选择你有比较优势有核心竞争力地方。“弱水三千取一瓢，禅宗追求极简思维，讲的都是同一件事”：你想做什么？如何运用你的知识实现复合成长（How do you compound your knowledge）？时间是我们惟一的资产，想好怎样组织你的时间。

# 传统价值投资已过时

张磊将高瓴的投资风格称为长期结构性价值投资：“我们重视价值，但不做格雷雷姆风格的传统价值投资。”这类投资过度关注过往的财务数据，有可能掉入刻舟求剑的境地，结果常常变成僵带式价值，就是醉时态看价值好像很便宜，但企业价值几乎已尽，就像烟落，捡起来也只剩一口可抽。

他寻找的是那些能在长期中带来巨变的公司，识别成长的动力（dynamics），投资于拥有这种动力的企业，与它们一起长期增长。

确实，如果是基于历史财务数据机械地看估值，这些事情机器能做地更好。张磊称，传统价值投资会被廉价商品化（commoditized），但如果能像我们一样能在10年前就看到京东规模能成长到比所有零售连铁企业都大，这种能力就无法被廉价商品化。

要获得这种能力，“我认为需要独立思考、好奇心和同理心（intellectual independence, curiosity, and empathy），尤其是同理心。”

# 将同理心制度化

张磊举了投资腾讯的例子，高瓴多年前投资腾讯，至今仍然是其最大投资之一。当时腾讯市值只有大概十亿港元，今天的市值就不多说了。

腾讯当年主要产品是QQ，当时谁重视QQ呢？有身份的人用微软的MSNMessenger。如果投资先看市盈率的话，张磊说，永远没有理由投资腾讯。幸好，高瓴不能关心市盈率，也不在意商业模型不是很实体货币化（monetized）——只要它能创造价值，货币化是迟早的事。

在他眼中，投资期足够长的话，估值太重要——又不是追求30%~50%的收益，而是要看到十年之后，寻找的是那些能长期带来巨变的公司。

问题是么张磊知道有没有价值？能不能带来巨变？张磊自己又不只研QQ，怎么知道QQ有没有价值能不能带来巨变？
