# 第34周问答丨概率没有那么简单

> **上善若水**：想犯罗牌的概率权，给你两个按钮，按第一个，可以直接拿走100万美元，按第二个，有一半的机会拿走1亿美元，正确答案是有半的第二个按钮。如果没有背后的一整套概率知识，很多人都会做出错误的选择。

**王烁**

在专栏文章后面的留言中，经常看到读者谈到罗振宇讲的这个例子。如果概率这么简单就好了，情况不同，选择不同。

第一，如果这个游戏可多次重复，按第二个按钮。

第二，如果这个游戏可多次重复，但第二个按钮的回报改成有一半机会输掉本金，有一半机会增值一亿倍，而且一旦选择第二个则必须玩下去不能停止不能反悔，那么，你应该按第一个按钮。

第三，如果游戏是一次性的，这个问题没有标准答案。钱对每个人的效用不同，100万美元对普通很重要，1亿美元（或者的例子5000万美元预期收益）对王健林来说只是完成个小目标。对同一个人来说，100万美元和1亿美元的效用也不是线性递增的。否则怎么会有“第一桶金”的概念？如果线性递增，则一百桶金的话都应该是一样的。而对于要饿死的人来说，确定的一百万比不确定的1亿重要，一百万就能活下来，博一亿可能死。

不幸的是，人生百年，许多事是重复发生的，或者至少是许多人可用可重复的眼光来对待他们。所谓把眼光放长，不执着于一事一地一事，即指此。

不幸的是，越重要的选择越难为重复，最重要的选择往往不可重复。我们应该作何选择？

这就是著名的孤例难题。它是个哲学问题，我介绍一种回答。

概率学家、哲学家查尔斯·佩尔斯（Charles Peirce）说，我们应该作预期收益更高的那个选择，即使它对我们是一次性的，预期收益在此并无实际意义。

他说：“（在做一次性选择时），逻辑要求我们的利益不再受限于自身，不能锁定于自己的命运之中，而必须拥抱整个社群；同样地，社群利益也不能受限于自身，而必须扩展到所有人类。它必须超越这个地质时代，超越所有边界。逻辑植根于社会原则。”

也就是说，对我们每个人来说的一次性选择，对整个社群、全部人类，以及未来世代来说，是可重复选择的一次取样，惟其如此，预期收益才有意义。为什么要这样做？佩尔斯说，“因为信仰、希望和慈悲”。
