# 生命周期投资法：趁年轻多借钱？

从本期开始陆续刊出进阶金融课，各位务必重温本专栏开篇的极简金融课三篇，否则白读，进阶金融课看了白看，反遭其乱。极简金融课的意思是普通人只能追泡沫或权益，的方法是量化投资+多元定投+定期再平衡。我在耶鲁期间，问过从诺奖得主希勒、桥水基金管理之王奈森以降的许多人，结论好的一句话：对普通人来说，没有比这更好办法。

进阶金融课同时从大小处着眼，小处讲用于日常决策的关键金融概念，大处讲清楚怎么形成危机时有何逻辑你如何自处。进阶金融课不是教你怎样投资，而是教你怎样理解现实，说得更准确些，从你的角度透过金融框架理解现实。金融化世界是现实世界越来越重要的一部分，同时还叠加在现实世界之上。不理解金融，如何理解现实？

如果你从-开始就看《大学》，自然会知道巴里(Barry Nalebuff)是本专栏里的重要角色，他是耶鲁商学院教授，连续创业者，跨界高手，深耕博弈论，告诉我如何教学又学学术，还高格调谈课里出钱，教大家基于博弈论有尊严有原则有技巧地主张利益。

除这些之外，他还精通投资。

有次跟他上爬纽黑文东岩，下山路上，谈起他合著的一本小书《生命周期投资法》（Lifecycle Investing）。我说，巴里，生命周期投资读得很彻底，但正如你们在开篇就说到，等看到这本书再练，黄花菜都凉了。

巴里指算一算，哪里话，还没来得及，别提，全部跟股票指数，再把杠杆加到200%，把失去的时间追回来。

我笑笑。

巴里还在兴致勃勃地算，忽然想起忘了啥事，"喂，你们中国股市那个样子，哈哈哈，当我没说。"

我耐下心来讲，中国股市也是股市，妖是妖了点，但哪里的股市没妖气呢？中国投资者的问题不在于投中国股市，而是只有中国股市可投，海外投资工具太少，渠道太窄，长期高度管制，不得不加大风险。哥伦比亚大学商学院教授康·哥兹曼（William Goetzmann）研究发现，由于海外投资受限，中国投资者大体只能投国内股票，无法充分多元化，不得不加大风险偏好。风险本来就够这么大，再加满杠杠，巴里你是嫌中国投资者死得还不够快是吗？

巴里说，你说得对，不过中国人海外投资这件事毕竞是可以做了。生命周期投资法基于时间多元化，其逻辑适用于中国投资者说到底也只是个时间问题。对吧？

我推倒承认。

巴里建议我找这书的第一作者聊聊，我在耶鲁法学院斯特林楼二楼的办公室找到了伊恩·艾瑞斯（Ian Ayres）。

艾瑞斯也是神人，他是美国艺术与科学院院士，同时担任耶鲁大学数学教授和商学院教授，比较Superhero，多数数建议做什么关系，比如SuperCrunchers，讲如何基于数据运用统计学思维解决问题；又比如Carrots and Sticks，讲如何用用激励与自我管理，这本书还衍生出StickK网站，一步一步教你怎么设定目标，设定筹码，找到裁判，巧用同伴压力。又比如这本《生命周期投资法》。总之，他跟巴里是同一类人，聪明过人，精力过人，兴趣广泛，精通学术，追逐实效。

生命周期投资法到底是怎么回事？

它是投资多元化在时间维度的逻辑展开，但是展开得极尽彻底，打破股票组合的常规，认为年轻人必须把投资全部放在股票，这还不够，还必须加杠杆，而且越年轻越好。

投资多元化至少包含三层：

第一层是投资工具组合的多元化，最基本的如股票股指数的组合，至于是否加入房地产、黄金、其它实物资产、衍生工具，看每个人自己的风险偏好；

第二层是地域的多元化，是不能全投在母国，由于生于斯长于斯，人力资本都在这，那么你多元化就要你把财力资本也都当海外配置；

第三层就是时间多元化。

投资要跨时多元化，因为人的生命周期以及收入的波动，人生命最大悲剧是钱没花完，人死了。人生第二大悲剧是钱花完了，人还活着。如果你20岁开始工作，60岁退休，人均寿命是75岁，这笔钱要维持你60年工作的收入，要支撑75年的生活开支，时间长按将近一倍——不要以为前20年父母养你省了便宜，你得养育自己子代，代际转移支付。
