# **第 111 封信 | 澳大利亚日记 ( 三 ) ——墨尔本**

![](bbox=[0.08, 0.09, 0.14, 0.11])

> 第111封信 | 澳大利亚日记...

宝宝，你好！

我在澳洲的第三站是墨尔本。如果你在澳洲要找一个最具有欧陆风情的城市，那么就要看墨尔本了。

墨尔本的历史并不长，它在 1835 年才开始建城， 1837 年以英国前首相墨尔本子爵的封号命名了该城市。到了 1850 年，殖民者在墨尔本周边发现金矿，于是来自世界各地的淘金者纷至沓来。因此，墨尔本也被称为“新金山”，而之前的淘金之都圣弗朗西斯科则被称为“旧金山”。

墨尔本的市区非常值得一看，那里有很多德国和意大利风格的建筑，非常漂亮。另外，它的皇家植物园规模很大，喜欢花卉摄影的朋友可以去那里展现自己的摄影技巧。墨尔本也是最早居住海外的中国人的聚集地，那里有规模很大的唐人街。

墨尔本最著名的景观是在它西边的漂亮海岸线。从市区出发往西沿着滨海高速公路——大洋路（ Great Ocean Road ）一路开，沿途是澳大利亚最著名的自然景线，和壮丽的海岸线穿梭于鬼斧神工的奇石景中。

![](bbox=[0.3, 0.495, 0.7, 0.53])

从墨尔本市区出发，大约一个半小时就能到达大洋路上的第一个景点，爱丽丝湾灯塔 ( Aireys Inlet ) 。世界上的灯塔大同小异，在澳大利亚最值得一看（或者拍照）的就是这座七层高度的灯塔了。在那里不仅可以欣赏灯塔和海岸峭壁一同构成的风景，而且可以在灯塔上眺望海岸。如果是当地的冬天（北半球的夏天）在灯塔上看日落应该非常壮美（夏天日落较晚）。

从爱丽丝湾灯塔往西开车大约 2 小时左右，就能到达著名景点十二门徒石 ( The Twelve Apostles ) 附近。这里第一个景点是吉布森阶梯（ Gibson Step ）。所谓 Step ，就是阶梯，那里能走到海面上看悬崖。

如果是晴天到那里，可以看到湛蓝的水天一色的美景。我去的时候阴晴雨天，天色蒙蒙的，但是红色的悬崖峭壁和海水的绿色形成鲜明的对比（非颜色的海，颜色是绿色的，非常深的海，颜色是绿色的），有一种打翻调色板的感觉。

![](bbox=[0.3, 0.815, 0.7, 0.85])

沿着大洋路继续往西走，很快就能到达当地最著名的景点十二门徒石。那段海岸是由红土和沙石构成，质地松软，被海浪侵蚀后，切割成一个个小岛似的礁石，矗立在海中，一共 12 个，被称为“耶稣的十二门徒”。不过由于这些年海水的进一步侵蚀，只剩下八九个了。
