# 历史给他留下特殊位置

平民家庭，学者出身，技术官僚，不期然成为大国总统，治下有亿万人口、万亿美元GDP，上台伊始就得拯救国家于金融危机，差不多，然后用之以致用，用于扶贫；人生华彩却在退伍，终结一党连续执政71年来中断的历史，和平交权；回归校园，教书至今。

这般传奇人物，在现代政治史上独一无二，我在耶鲁见到了。

恩斯特·塞迪略（Ernesto Zedillo），1994年到2000年间任墨西哥总统，现在是耶鲁大学全球化研究中心主任。

塞迪略的办公室在耶鲁大学北坡科山山顶的贝德楼，结庐人境，车马不喧，繁华落尽，在此栖身。

![](bbox=[0.05, 0.39, 0.95, 0.45])

塞迪略问我来自。

我说，来向你致敬。

2000年，墨西哥总统大选，塞迪略所在的革命制度党选择输，输给反对党候选人11个百分点。墨西哥宪法规定总统只有一个任期，塞迪略不能参选连任，但他抢在革命制度党候选人之前，作为执政党的在任总统承认败选结果，锁定大局，终结了革命制度党自1929年以来的连续执政历史——也被不少华人视为叛徒。

我说，历史会给你留下特殊位置。现代史上还没有发生过，一个政党连续执政71年，然后其总统接受选举结果，和平交权。

你为什么选择这样做？

塞迪略答，倒没有你说得那么简单，好像仅仅是我这般选择就行一样。民主的形式在墨西哥早就有了，政党选举公职这件事有很长时间，但当时并不完全公平，总是对我所在的革命制度党有利。在我当选总统之前，已经有过改良。在我任总统期间，我尽量使这个系统真正更具竞争性过程更公平，结果就是把革命制度党给选下去了。

同期耶鲁世界学者中，加比莉娜来自墨西哥，也曾担任过教育部副部长，颇多事曾与塞迪略共事过。她向我说见过塞迪略的难题，我说，他很谦卑。

加比莉说，是的，因为他做的非半关键。
