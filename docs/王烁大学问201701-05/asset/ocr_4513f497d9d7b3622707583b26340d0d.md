# 深度工作法

深度学习是人工智能的事，深度工作则是每个人的事。

生活与工作被切割成一个个碎片，这已是既成事实，我们不可能也不会想回到碎片化之前的那个田园牧歌时代；但时间在碎片中迷失，却始于手机没有用处，就算手机非大碍极，未了还得自己决定接下来怎么办：生活是你自己的，工作是你自己的，把生活过得最为充实，把工作做到最高效率，责任只属于你自己。

必须在碎片化中找到深度工作之路，下面有一组办法。

第一，反复练习。

我们都知道大脑皮质，但大脑还有近50%由“白质”构成，即髓磷脂，也叫髓鞘素，它得以产生并包裹大脑神经纤维化使其过程叫作神经髓鞘化。神经髓鞘化能使神经传导速度变快，好比由粗管变成宽带，对高级动作技巧反应的学习来说至关重要。

神经髓鞘化会在两种情况下发生：小朋友在成长过程中自然获得，成人也可获得，但必须付出大量努力反复练习才行。

好消息是大脑的可塑性伴随我们一生，也就是说，什么时候学习都不晚，坏消息则是这并不容易。重搭大脑回路，需要大量、反复、有针对性的练习。形成肌肉记忆两件事：第一，反复练习，这告诉我们成人学心必由之路；第二，**正确练习**，仔细聆听反馈给你的信息，有针尖地调节练习方式同样重要——你不别大脑搭建错误的回路。

第二，善用注意力剩余。

你做当下这件事，与你做上一件事及下一件事，有关联。注意力是我们最主要的资源，时间碎片化对**我们的**消废，多就是来自于在多件事中来回切换，注意力随之损耗，于是忙碌、焦灼、效率低下。我们试图多任务处理以获得效率，结果却适得其反。我们不是人，人脑学不是电脑，做不到万花丛中过，片叶不沾身。

接受人脑的黏性，我们只能克制多任务处理的冲动，转而致力于两件事：第一，一个时间段只做一件事，不仅仅是因为专注才有效率；也分为专注才能找到工作本身乐趣。第二，前后相邻的时间段尽量做相关的事情，尽量不要跳到不相关的事情上。专注做一件事，会形成注意力剩余，对做相关事务有帮助，不要浪费它。把时间组织块，把相关工作组织块，善用注意力剩余，事半功倍。

第三，养成适合自己的工作节奏。

好习惯是最大大的，而坏习惯也是顽固的，所以最得养成好的工作习惯。习惯最有用之处就是自动克服拖延症，并对工作的焦虑化解为一道自固定流程，不再需要耗心理能量去启动，去克服。

好工作习惯不一种。比如说，美国小说家斯蒂芬·金的习惯就是每天白天自己在书房里，不写够字数绝不离开。有人拜访东欧某位笔耕数九的作家，在其书房发现书桌笔满书满架，大为拜服。这位作家大笑说，如果你把软塞起来，也能做得到！

这习惯多半不适合你，但你得形成自己的好节奏。不然，每天光你花决定何时开始工作件事，就够折磨你一整天的。

下面这些模式都行，看看哪个适合你：

+   - 隔绝模式：工作时与世隔绝，像僧侣一样；
- 双模式：在两种模式中切换，既像僧侣一般与世隔绝，也有正常生活；
- 节奏模式：定期，最好是每天，都固定做同一件事，形成节奏；
- 记者模式：记者有截稿期，按需写作。

第四，敢于关机。

确定一个时间，比如每天晚上8点，最后查一些邮件和办些杂事，然后结束工作，不再查邮件，不查看短信，不再刷微信朋友圈，最好关机。不在做无谓，至少把工作手机与生活手机分开，关掉工作手机。

第五，干票大的。

把视线从眼前事务中抽出来，往远方看，当然也不要太近。给自己定下未来半年到一年要做成的一件大事，然后去完成它。

高目标-任务分解-针对练习-反馈调整-朝一个目标设法提高，这是摆脱低效忙碌的终极大法。

最后，推荐《深度工作法》（Deep Work），作者是Carl Newport，麻省理工学院计算机博士，现乔治城大学计算机教授，几年前为了帮助学生决策开拓智能《学习骇客》（Study Hacks, http://cainewport.com/blog/）被视作最有用的自励类博客之一。本书于今年初出版后，《经济学人》杂志评论说：“深度工作是知识经济时代的杀手级应用。”亚马逊读者打分最高的平均分高达4.7，满分是5分。
