# 大学优异的基因

![](img/d0b39398554e3d9ba7f47bdd8890a825_35_1.png)

朋友发给我刘守英先生的文章《哈佛为何一流？》，建议我写篇随笔。其实姚玉在前，我何必继续？写鲁优异之处，又岂是我浮光掠影能否选？

想来想去，还是凝聚到一点，从耶鲁看那些最优秀的大学生何为基。

### — 1 —

耶鲁是私立大学。所谓私立，即其经费不由政府拨款而来。耶鲁大学每年预算中，最大宗收入来自耶鲁基金的贡献。校产基金主要来自校友捐赠及其复息，这对耶鲁至关重要。汇集各路捐赠，耶鲁校产基金现管辖260亿美元资金，在美国大学中仅次于加州大学，名列第二。过去五年中，为耶鲁贡献了超过50亿美元的运营资金，是最重要的资金来源。耶鲁也曾使用一些政府经费，主要是某些课题项目在政府资助下，但所占比例有限，部分散在大量课题里，并不集中，对大学整体不构成影响。

大学为何要有校产基金？大学之道，在明明德，本不在产。有产的理由，是以可永续的财务资产，创造稳定的收益，为学校教学、研究与扩张提供资金。大学首先应使善道，由此界说哲学，研究的旨向与规模，催生长期资金需求规划，倒推产业收益率目标，并形成基本制度；管理要专业、资产配置要多元化，要求给定收益目标下的风险最小化，治理结构要最大限度透明化。

耶鲁校产基金现由传奇管理人大卫·斯文森执掌，他以一己之力开创校产基金管理新路，收益率稳定地战胜市场，为耶鲁大学的永续在财务上奠基，其投资理论已统治整个大学校产管理界。在《大学论》中他已多次出场，想对他了解更多的话，请往前翻看专栏文章。

> 财务自由本身不能保证思想自由，但没有财务自由的话，绝对没有思想自由。

### — 2 —

与其他美国大学一样，耶鲁大学的最高权力机关是董事会，不过耶鲁大学董事会的名称不太一样，Yale Corporation，耶鲁法庭。耶鲁历史太悠久，1701年成立时全称即“学院”，1718年获南人伊莱·耶鲁捐赠560英镑，改为现名——这大概是历史上性价比最高的一笔冠名捐赠了。

耶鲁校董会共19名成员，校长是当然成员，另外两名当然成员是康涅狄格州州长和副州长。其余16名成员中，10名为继承校董 (successor trustee)，6名为校长实校董。

其实在多年以前，根据康涅狄格州宪法，州政府在校董会中有八位代表，除州长和副州长外，还有另外六名政府官员。1752年，耶鲁校史上的著名校长克莱普曾想将政府官员挤出校董会，以失败告终，因为耶鲁当时还必须要依赖政府资金。

两三百年来，耶鲁校董会全天然取消。州政府代表只剩正副两位州长，其余六名政府代表已全数消失，由六名校友校董取而代之。

继承校董也经历了相似的历程。耶鲁创立之初期属于教会。耶鲁大学的独立，是教育、研究、思想自由和学术影响等方面的历史，同样是从教牧会中独立的历史。耶鲁前身由十名牧师创建，所谓“十位创建人”，这十人被视为当然校董，后来按继承其位的人，则称作其继承者，因此有“继承校董”之称。直到近三百年后，耶鲁才于1905年产生了第一位不是牧师身份的继承校董。

今天，耶鲁大学早已彻底独立，早年由政府和教会统治的顶层结构焕然一新。校友校董也好，继承校董也好，现在的耶鲁校董会里，除正副州长外的17人，包括校长在内，全部都是耶鲁校友。

当然，还能看到许多历史遗痕。比如校董的选举方式不一样：继承校董的选举只在现任继承校董任期届满之后才举行，且只有前任六位继承校董有选举权，一旦选到的是朋友，六年任期。名名校董出任，服务一届也就是六年，六年才能梯次换完。谁来选呢？耶鲁全体校友，每年春天投票。

如此大牙交错安排，早年应是出自政府与教会相互制衡的设计，留下是今日，暗合进化论的逻辑：如果什么东西没坏，那就继续用着。同时它使耶鲁校董会有极强延续性，如果谁想搞掉全部校董，最短也要六年，最长则理论上可达十二年。最问在六年谁能耗得过十二年呢？总统也做四年而已。凝聚传统，竖如磐石，难以颠覆，这制度设计与大学的永续目标相符。

世界上没有千年的政府，但有千年的大学。大学之大，固然是不在于大，其实也不在于有大师。虽然大楼、大师都是题中应有之义。大学之大，在于永续，在于自由思想、独立学术提供空间，教书育人，服务社会。政府来来去去，大学永远伫立。

### — 3 —

从政府和教会的控制下，逐步实现财务独立、治理机制独立，终有学术的独立。今天耶鲁以一所非盈利的私立大学服务于公共利益。类似大学在美国很多，它们是多代社会的中间砥柱。个体独立与社会多元相辅相成缺一不可。只有真正独立的个体大量存在，社会才有多元可言；反过来，只有社会有纳多容空间，个体独立才有可能。一切处于一等的论话，哪里还有独立个体和多元社会？

在这个社会里，川普想从来没有那么容易，且不说什么三权分立，他拿耶鲁这样的机构就找不到什么办法。不光耶鲁甚至也不大什么，整个美国社会自身上下由无数大大小小不同的个体层层叠加而成，各有自己的根基。只要他们的独立性还在，强推社会学就还在。

说远了，拉回来。

像耶鲁这样的大学，本质上是两个共生的自治体相濡以沫的结果。一个是学术自治体，围绕教学、研究，自由思想，切磋砥砺；一个是校友自治体，它远不仅仅体现于校友会组织，更贯穿大学治理的主要环节，既在校董会执掌大局，又在大学、学院、讲席、项目等各个层级为大学发展筹集资金，贡献思路。

为什么校友对大学这么重要？直接原因当然是校友捐赠。深层原因则是大学与校友植根于同一基础。校友对于母校有什么期待？母校对于校友有什么期待？归根到底，就是简单一句话：我愿以母校为荣，母校愿以我为荣。大学与校友之间财力、智力、能力的相互支持，无不以这最朴素的善意为基础。声誉是大学与校友最美好也最重要的纽带。在一代代的传承中，校友成就与母校声名交相辉映，结成难解难分的声誉共同体，渗透落实到财务支持、治理安排，成为大学独立的核心支撑。

同在声誉共同体，校友是母校的天然盟友也是诤友。校友们会时时戒慎，既会奋力保护母校声誉免于外部威胁，同样也会揭竿而起抗议来自内部的侵蚀。如果一个大学校长丧失声誉，哪怕其一切所为表面合规，也只能下台了事，因为这个共同体是大学生命之所系，用声誉粘合。丧失声誉，最终丧失一切。

大学在长期中取决于声誉，在短期中需要金钱与人才。那些最优秀的大学已经形成长短期的正反馈：声誉带来更多财力，吸引到更优秀人才，又反过来创造更高声誉。这也许需要漫长到数百年的时间，但在竞争中站上塔尖的那些最优秀大学，以声誉共同体为基，以学术自治体和校友自治体为翼，已建立难以撼动的地位，有了永远伫立的基础。

以耶鲁为例，最好的私立大学的学费和生活费用都不菲，但你申请时不用担心能否上得起学。耶鲁世界学人项目请一位刚入学的本科生切尔西帮我们做些协调工作。她来自中西部偏远地带，家庭困难，从来没有离开过家乡，没有坐过电梯，没有吃过新鲜食物——从小到大吃的都是冷冻食品。

没有离开过家乡，没有坐过电梯，没有吃过新鲜食物——从小到大吃的都是冷冻食品。她到耶鲁求学，是因为耶鲁只要录取你，你就能获得财务支持，足够上完四年大学。资助不是基于你有多优秀 (merit based)——只要你能被录取，就被认为已足够优秀——而是基于需要 (need based)。根据你的家庭情况算出你需要多少支持，就给多少。这也不都是免费午餐，相当部分是贷款，你将来得还。帮你攀上人生阶梯的这些力量，直接来自录取你的大学，间接来自于你的校友。

这些资助有多少呢？以最近一个财年为例，超过一半耶鲁本科生获得了资助，平均获得的资助是48000多美元。

我愿以母校为荣，母校愿以我为荣。就是这么真实切切。

开始时提到耶鲁校产基金管理人斯文森，那个校产基金管理界的巴菲特。我问他，如果你成立自己的基金，个人财富增长几十倍应该不成问题，为什么不做？斯文森答道，我更愿意是耶鲁一员，为这个世界上最的机构工作。这使我快乐。

我又问，为这个历史比美国还要悠久的机构管理为其永续奠基的资金，你有什么体会？

斯文森说，这是世界上最好的工作，我很幸运。

# 第24周问答 | 保险最好是消费

D. X104361：可以说一下对保险的看法和建议吗？

- **王烁**
  - 保险是对风险的对冲。你担心什么大病就购买什么保障。如果你担心生大病的治疗费用太高，那就买健康保险；如果你担心房屋毁于火灾，那就房屋保险；如果你担心意外伤残死灰留下了老小无依，那就买寿险；如果你买了债券担心发债企业破产倒闭，那就买CDS，等等等。

买这些保险就是消费，消费是保险的本质。所谓“保险投保”，这一段经常在媒体上看到的保险会宣示，指的是这个意思。你付出保费，获得给定时间内针对特定风险的保障。如果给定时间发生，祝贺你；如果风险发生，你获保障。

保险存在逆向选择问题。比如说，医疗保险本质上时购买医保的人群的自我保险。由保险公司居中完成。保险公司向每个人收取保费，保费高低根据人群的患病概率等多种因素核算而来，成然是基于人群健康状态的均值，但每个人的健康状态及相应的治疗费用则不会是平均的。有的身体差治理费用高，有的身体好治疗费用低。身体差的，贴补身体差的，中间保险公司拿走点利润。

所谓逆向选择，就是预计到这种情况下，身体好的人不愿意参保，何必去补贴人呢？而身体差的人积极参与，不去占大便宜吗？而身体差的人极少，买保单的人都是身体极差的，保险公司怎么办？保险。保险公司要不傻吗，怎么会？提供保费。于是展开新一轮同样的博弈。继续亏则驱除良币。今天美国的奥巴马克医改就陷入了类似的陷阱，参保的人数减少，保费提升，保险公司亏损增加。有人说，就算公司不搞定，它也将持续了不太久。

但上述的逆向选择问题是无解的。否则世界上就没有保险公司了。每个人对风险的概率判断和价值判断都不同，这种差异就构成了买卖保单的基础。如果你很重视替代保险，就不会太介意事实上补贴了别人；千金之子，坐不垂堂，哪怕栋榫掉下来砸到他的机率微乎其微。只要投保人群数量足够大，每个人对风险的差异定价便使保险得以持续运营。

保险的另一面是投资，对保险公司来说投资是必须的。获得保障与支付保障之间是资金流。有一定保险公司总会持有一笔资金。保险公司对保险公司的资产不同，但先不说那么细，把它大致理解为巴菲特所说的“浮存金”（float）就好。浮存金可用于投资。事实上，从保险投资的角度看，你可以把保险业务理解成有获取浮存金运营收益权利的成本。保险投浮存金运作方式的权利的竞争极为激烈，以至于保险业务本身往往是亏损的，都指望从浮存金投资中挣回来。

这局你作为投保人基本没有关系，如果保险公司资本金充实保障能力强的话。但除了消费之外，对于投资人来说，保险仍然有投资一面，就是说，许多保险产品不仅提供保障，还提供投资收益。

听起来是不是很？

但世界上没有免费的午餐。你看今天保险产品他们越来越复杂，你看今天纯粹的消费品越来越少，消费与投资杂合的越来越多，甚至出现了几乎纯粹为投资的保险产品，知道投资者可不见得一定是好事。

首先是把产品复杂化有利于掩盖高定价，太简单让你看清了，保险公司的精算师也不就成摆设了吗？更重要的是，那些非正式为投资的保险产品，如何能呢，对保险公司来说实是短期融资工具，对投保人来说则无异于短期理财产品。

凡类保险的风险是相当高的。保险公司用保险产品做长期投资，甚至向海外人去这钱用来到对万科的敌意收购。应短期期限的惟一办法是滚动发万能险产品，而且必须规模越来越大，否则就有资金断流之虞。

用保险产品来做投资还有一层不利。就是保险的成本偏高，你购买保障的经纪人佣金或者渠道成本先吃走了你一大块，然后再用于投资，可谓输在了起跑线上。如果本意是投资，完全没有必要走保险，由你成本工具多元化组合非常定价，而成本很低。

对普通人来说，最简单也最好的方法是各管各。让投资回归投资，保险回归保险。记住保险是一种消费。你想管理好风险，就购买什么保险服务，这就是正确。
