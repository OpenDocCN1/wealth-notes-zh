# 大学优异的基因

![](bbox=[0.15, 0.18, 0.25, 0.22])

朋友发给我刘守英先生的文章《哈佛为何一流？》，建议我写篇随笔。其实姚玉在前，我何必继续？写鲁优异之处，又岂是我浮光掠影能否选？

想来想去，还是凝聚到一点，从耶鲁看那些最优秀的大学生何为基。

# — 1 —

耶鲁是私立大学。所谓私立，即其经费不由政府拨款而来。耶鲁大学每年预算中，最大宗收入来自耶鲁基金的贡献。校产基金主要来自校友捐赠及其复息，这对耶鲁至关重要。汇集各路捐赠，耶鲁校产基金现管辖260亿美元资金，在美国大学中仅次于加州大学，名列第二。过去五年中，为耶鲁贡献了超过50亿美元的运营资金，是最重要的资金来源。耶鲁也曾使用一些政府经费，主要是某些课题项目在政府资助下，但所占比例有限，部分散在大量课题里，并不集中，对大学整体不构成影响。

大学为何要有校产基金？大学之道，在明明德，本不在产。有产的理由，是以可永续的财务资产，创造稳定的收益，为学校教学、研究与扩张提供资金。大学首先应使善道，由此界说哲学，研究的旨向与规模，催生长期资金需求规划，倒推产业收益率目标，并形成基本制度；管理要专业、资产配置要多元化，要求给定收益目标下的风险最小化，治理结构要最大限度透明化。

耶鲁校产基金现由传奇管理人大卫·斯文森执掌，他以一己之力开创校产基金管理新路，收益率稳定地战胜市场，为耶鲁大学的永续在财务上奠基，其投资理论已统治整个大学校产管理界。在《大学论》中他已多次出场，想对他了解更多的话，请往前翻看专专栏文章。

> > 财务自由本身不能保证思想自由，但没有财务自由的话，绝对没有思想自由。

# — 2 —

与其他美国大学一样，耶鲁大学的最高权力机关是董事会，不过耶鲁大学董事会的名称不太一样，Yale Corporation，耶鲁法庭。耶鲁历史太悠久，1701年成立时全称即“学院”，1718年获南人伊莱·耶鲁捐赠560英镑，改为现名——这大概是历史上性价比最高的一笔冠名捐赠了。

耶鲁校董会共19名成员，校长是当然成员，另外两名当然成员是康涅狄格州州长和副州长。其余16名成员中，10名为继承校董 (successor trustee)，6名为校长实校董。

其实在多年以前，根据康涅狄格州宪法，州政府在校董会中有八位代表，除州长和副州长外，还有另外六名政府官员。1752年，耶鲁校史上的著名校长克莱普曾想将政府官员挤出校董会，以失败告终，因为耶鲁当时还必须要依赖政府资金。

两三百年来，耶鲁校董会全天然取消。州政府代表只剩正副两位州长，其余六名政府代表已全数消失，由六名校友校董取而代之。

继承校董也经历了相似的历程。耶鲁创立之初期属于教会。耶鲁大学的独立，是教育、研究、思想自由和学术影响等方面的历史，同样是从教牧会中独立的历史。耶鲁前身由十名牧师创建，所谓“十位创建人”，这十人被视为当然校董，后来按继承其位的人，则称作其继承者，因此有“继承校董”之称。直到近三百年后，耶鲁才于1905年产生了第一位不是牧师身份的继承校董。

今天，耶鲁大学早已彻底独立，早年由政府和教会统治的顶层结构焕然一新。校友校董也好，继承校董也好，现在的耶鲁校董会里，除正副州长外的17人，包括校长在内，全部都是耶鲁校友。

当然，还能看到许多历史遗痕。比如校董的选举方式不一样：继承校董的选举只在现任继承校董任期届满之后才举行，且只有前任六位继承校董有选举权，一旦选到的是朋友，六年任期。名名校董出任，服务一届也就是六年，六年才能梯次换完。谁来选呢？耶鲁全体校友，每年春天投票。

如此大牙交错安排，早年应是出自政府与教会相互制衡的设计，留下是今日，暗合进化论的逻辑：如果什么东西没坏，那就继续用着。同时它使耶鲁校董会有极强延续性，如果谁想搞掉全部校董，最短也要六年，最长则理论上可达十二年。最问在六年谁能耗得过十二年呢？总统也做四年而已。凝聚传统，竖如磐石，难以颠覆，这制度设计与大学的永续目标相符。

世界上没有千年的政府，但有千年的大学。大学之大，固然是不在于大，其实也不在于有大师。虽然大楼、大师都是题中应有之义。大学之大，在于永续，在于自由思想、独立学术提供空间，教书育人，服务社会。政府来来去去，大学永远伫立。

# — 3 —

从政府和教会的控制下，逐步实现财务独立、治理机制独立，终有学术的独立。今天耶鲁以一所非盈利的私立大学服务于公共利益。类似大学在美国很多，它们是多代社会的中间砥柱。个体独立与社会多元相辅相成缺一不可。只有真正独立的个体大量存在，社会才有多元可言；反过来，只有社会有纳多容空间，个体独立才有可能。一切处于一等的论话，哪里还有独立个体和多元社会？

在这个社会里，川普想从来没有那么容易，且不说什么三权分立，他拿耶鲁这样的机构就找不到什么办法。不光耶鲁甚至也不大什么，整个美国社会自身上下由无数大大小小不同的个体层层叠加而成，各有自己的根基。只要他们的独立性还在，强推社会学就还在。

说远了，拉回来。
