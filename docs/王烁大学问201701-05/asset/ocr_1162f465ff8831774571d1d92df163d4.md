# 投资软基础

国际货币基金组织负责中国的部门出了本新书：《现代化中国：投资软基础设施》(Modernizing China：Investing in Soft Infrastructure)。注意，标题中的现代化是个动词。几位作者要想常驻国际货币基金组织在中国的办公室，要么留在华盛顿总部但每年总来看中国。这次新书发布，情人节当天在著名智库CSIS（战略和国际研究中心）开讨论会，邀我参加。下面文章即来自我的发言，略作整理。

![](bbox=[0.3, 0.32, 0.7, 0.42])

与其隔壁兄弟机构世界银行一起，国际货币基金组织对于中国经济改革有重要作用。可以说，它们是中国经济改革的外部智库。中国发展到今天，并不需要它们的高低息发展贷款，也不大可能像希望今天这拨需要国际货币基金组织的救援贷款，但中国会长期需要它们的智力支持。记得多年前事采访时任世界银行行长斯蒂芬森，他说到时间调整与中国的定位，要变成中国的智力银行（intellectual bank）。三年前中国政府提出金融改革方案决定，不少政策改革要点中，确有少受益于此前世界银行与国务院发展研究中心合作报告《中国2030》。

所以说，如果在中国未来改革实践中看到国际货币基金组织这本书中建议的影子，我不会吃惊。

我想先把书要过来认真读了一遍，非常好，汇集了世界货币基金组织对中国相关研究的成果，完整地梳理了近年来的中国经济改革动作，围绕财税、金融、社保、国企、统计数据、改革鸿沟等，建议接下来的中国改革措施，并把这一切放到投资于国软基础设施的主题下，既及时又精博。我愿意把它推荐给所有关心中国经济的人，不光是国际读者，还包括中国读者，搞不好中国读者更需要。本书中文版大约会在三个月内在中国出版。

我们都知道，改革收效于长期，往往不会在眼前看到效果。如果眼前有什么效果的话，往往偏负面，因为改革中你主要是在付成本。恐怕这也是过去几年间决策者在结构与与经济指标刺之间反复权衡的原因。今天与经济学家讲经济上呢，经济需下去搞刺激。实际上呢，改革重，刺激容易。

但是，反复反复刺激几年后，现在情况也比较清楚了：刺激本身只能争取时间，改变了市场预期，做决定不性，要改变预期带来信心，有快决定性的改革动作。光发改革号召不够，得有决定性的不可撤回的改革行动。很多人说，信心比黄金更珍贵，我想即据此。

这本书里的几乎所有建议中，如果问我从哪里开始行动最容易的话，我看到两点：

第一，我特别同意书里的建议，明确放弃GDP增长目标。如果一定要定什么目标的话，改成其他更贴近合理的目标，比如就业，比如人均收入增长。

第二，金融监管必须跟上金融创新。中国金融监管四年完全没有跟上了。四五年前是传统银行存贷款业务绝对主导，今天已不是这样，影子银行规模已发展到传统银行业务的60%左右，而这份仅发生在近五年之中。中国金融正在处于又发生金融大爆炸。用美国前财长盖特纳（Tim Geithner）的话说，虽然中国金融仍然是高度管制，但从金融工具的角度上讲，没有什么金融工具是美国公司能在美国能获得而中国公司在国内无法获得的。
