# **第38周问答｜人工智能时代的择业假说**

+   **Water**: 我即将面临大学选专业。很苦恼，不知道选什么专业不会被人工智能所代替，不会失业。金融、传媒、艺术，还是其他领域。

+   **王烁**

第一，你想得太多，又想得太少。想得太多，指人工智能这件事，你既不太了解，又过于担忧，听任内心的不安发酵；想得太少，指你只看到人工智能这件事有可能带来影响，却不知道有无数因素会影响大到经济小到你的就业。这些因素多到你想不过来，又彼此放大数据此抵消，其间的动力复杂到无从预测。所以，基本上你是白烦恼。想不清楚的事，不必多想。

第二，以我对人工智能的粗浅了解，这一轮人工智能的兴起，主要是深度学习的突破，影响很大，却又是个很具体的事。影响很大，指在计算能力极大扩展、社会和经济普遍数据化时，深度学习算法已经获得的突破，可以在比较广的面推开，一个领域接一个领域地收获。很具体，指你不能线性外推，自己吓自己，以为人工智能在未来一定会像今天一样继续突破。人工智能下一次在哪条战线上哪种算法上取得突破，能否突破，都难以预测，如果不是无法预测的话。

第三，就这次深度学习带来的人工智能突破来看，哪些领域机器会有比较强的竞争力，已经跟人们预设的大为不同。比如我讲过几款阿尔法狗（AlphaGo）下的围棋，有人类创造力，极有创造性。以前认为人类在创造力上有优势，这看法是靠不住的。再比如，德州扑克牌是不完全信息游戏，人工智能近来战胜了人类顶尖牌手，说明以前以为人类在不确定情境中的决策上有优势，是靠不住的。可以说，如果有足够的计算能力支持，有恰当的大量的数据用于学习，那么，有样的算法，就可能呈现出什么风格的“智能”。

第四，我觉得这一轮人工智能进展多远，更多地取决于社会数据化的水平。那些越难以数据化、或者即使数据化但数据粗糙的地方，人工智能对于人的替代越难。

按此推理，至少金融市场上的投资是靠不住的。金融市场产生的数据是经济活动所产生的最粗糙一类数据。金融经济学发展那么快倒是因为数据又多又好，当然，金融这个堡垒东西很多。私募股权类投资（PE、VC）与金融市场上的投资不同，没有标准数据，主要看人。其实，现在的资产配置研究已经指出，对冲基金几乎不能带来稳定的超额收益，但私募股权投资有可能。另一点分布是畸形的，大多数私募股权投资机构不能但少数第一流机构能稳定带来超额收益。

第五，我还问传媒、艺术。先说媒体，我是新闻工作者，就谈文字。文字本是标准化数据，但其组合既是开放的，又必须基于社会共识。就是说，一方面，文字有任意种组合，另一方面，哪些组合为“对”，不取决于预定规则，取决于社会认可，这两点对今天的机器智慧都是很大挑战。如果机器能够写出我现在正在写的这篇回答的话，我就该退休了。

艺术是另一回事。它首先是创作者的个人表达，最终需要但不是那么马上就需要社会认可。我觉得机器创作出专家无法分辨出自人手还是机器之手的艺术作品，会很快，如果不是已经发生的话。同样地，很难想象机器创作的艺术作品会对人类的艺术作有强烈的替代冲击，因为表达是个体 的事，每个个体的表达都有独特价值，无法替代。

不过，艺术这个领域赢家通吃的性质太过强烈。站到金字塔尖固然后光无限，但如果站不到塔尖，人生都是个问题。你既然提出这种问题，说明一点：艺术这件事，你还是算了吧。
