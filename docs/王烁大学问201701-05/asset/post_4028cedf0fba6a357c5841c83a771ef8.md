
# 三、大家都靠硬实力的世界

衰落了，结果成为反向指标。80年代末书结，美国却在90年代后再创峰值。

美国赢得冷战，催生另一个著名预言，福山说，历史终结了。

福山长于宏大叙事又紧扣现实政治走向，当时在兰德公司担任政研员，发表文章《历史的终结》，随后与激进的学者合著《历史的终结与最后的人》，以冷硬的喀格尔斯史观，宣告历史终结于自由民主制，击中了“冷战”结束后的时代精神。书成后现象畅销，人成为那个时代的首席政治预言家。

当然，这个预测又错了。历史曾终结过？预测失败。克尔凯郭尔说，我们总是向前生活，向后理解。

风水轮流转，今天似乎正在印证亚伯拉罕·爱伦·爱伦·坡（或指其他历史人物，原文OCR模糊，暂存疑）的预测，尽管70多年。福山也肯绝自否定自我，以下两本巨著《政治秩序的起源》、《政治秩序与政治衰败》，再度撼动学界。在其中，福山特地强调政府能力（state capacity）建设，而对美国政治的判断，充分体现于他发表在《外交》季刊上的一篇文章的标题：《美国在衰败》。

我问福山，你的看法是怎样变的？福山回答：“我对基本问题的观点不变，即随着社会经济和现代化，历史会朝某一个现代化的方向演进。什么样的社会应该建立在现代化的方向的终点，与25年前一样，我们仍是那么具有固定形式的自由民主和市场经济社会。”也就是说，不是历史终结了，而是历史应当终结。

“应当”不是预测。

我对福山的采访发生在这次美国总统大选的初期，当时的舆论和预期中，川普不过是颗流星，转瞬即逝。福山认为美国衰败，不是针对川普，是针对两党竞争失灵，政治失效。“美国的问题主要在政府。我对衰败的定义是，强有力的精英集团能够获取政治权力，保护自身利益。在过去几十年，大利益集团和投机机构正在此上上升。美国的另一个问题是两党政治的极端化，这使得美国政府，使其在一些基本问题上都很难做出决定。”

当时，我们关心的还是比如政治门槛问题：在过去八届总统选举中，至少有六次竞选上出现了克林顿或者布什的家族。这不是美国政治衰败的表现？福山不认为是这个问题，“某个家族长期保有政治影响力的例子，各国都有，美国也不例外，至少在美国的选民是自由选择的，像一些已经形成政治的政治家族，克林顿和布什这两个家族的品牌就很有力量。”

不过，他并不认为布什家的杰布·布什能成为共和党候选人。“这个我们等等看。”至少这个，福山预测对了。

今天，福山说的政治极化、利益集团主导政策等等问题，在维政贷铁腕无法将解不再是问题，问题是一党对倒时执国家两局，总统川普会如何拨拢狂奔。历史一旦重演过，偏局之中想打破偏局，打破偏局则回到偏局，因为政治偏局终结之后，天平总是暴烈地倾斜，这是政治偏局的固疾。

福山最新文章《美国：政府失败》叹川普民族民粹主义兴起，预言不亚于冷战结束那样大的全球动荡。这次预怎会怎样？

预言美国衰落，从来没有像现在这样显得靠谱。冷战结束以后，美国硬软实力达到巅峰，然而不过十余年，衰败却已到来。

回头看，这一切始于小布什政府2003年入侵伊拉克。基于一个错误的逻辑，发动一场不必要的战争，一失误过，虚耗国力，最终始乱终弃，道义受过。

再过数年，2008年金融危机到来，美国经济遭受重创，金融界推出雷曼新音乐（应为雷曼兄弟倒闭等后续事件），其余依旧：大水灌溉固然是维持金融系统稳定了之不得，但刺激货币发行也是事实。左右两翼的极化加和行动的化也相趁登场，亲党（应为两党极化）、占领华尔街、桑德斯社会主义，然后川普异军突起，摘走果实。经济推动政治，在美国就是这样发酵到滴满。

对全世界特别是对中国人来说，2008年金融危机更重要的后果是全球经济包括中国经济以美为重的时代结束了。这是真正的范式变迁。

在中国巨人站起来之时，美国模式自己丧失了智识领导力（intellectual leadership）。这些早已明白地写宣在纸上，前财长索尔·保尔森在《到中国交通》（应为《国运无常》或类似译名，Dealing with China）里讲到，2009年，一位中国财政策者对他说，美国不再是老师。

接下来中国会为谁的？估计没有谁了。

按照约瑟夫·奈所说，软实力就是无德大棒威也无需威胁利诱，美国就当然能无大棒能也无需威胁利诱，然美国却无之。从一层层地，从伊拉克战争到川普上台，道义领导力、智识领导力、道德领导力渐次耗散。

川普会怎样执政固然说不清楚，但即使是对他最理想的情形也不过是成为为这样一总统：重商、轻智、凌骑，把美国利益更多建立在他和盟友之上。所谓不在政治正确，就是这般赤裸裸地不正确行事。我们对这种领导人并不陌生，倒很熟悉，全世界绝大多数以这些人如此政的总统想到陌生。

刚到即期时，我问刚历冷战的国历战事数授加迪斯（应为约翰·加迪斯），如果中美角力持续，会不会重回类似冷战状态？加迪斯说不，因为冷战两大阵营均有意识形态因素，今天如果回到过去，会回到力量平衡（balance of power）的时代。那个时代历史学家科林是1646年威斯特法尼亚的建立在民族国家体系于1945年联合国的立，事实上则更长，一贯到今天的立全部政冶上、外交、军事上。什么是力量平衡逻辑呢？就是秩序只保存在国家群体，国家之间没有终极解决机制，永远从状态（应为永久处于状态），没有永恒的朋友也没有永远的敌人，只有永远的利益。在所有对国家间关系的理解和实践中，他离政治正确最远。大家都靠实力。

查尔斯·希尔（Charles Hill）跟加迪斯一样悲观：于二战后形成的自由化、普世的国际秩序在危机中，美、俄、中、欧都在离开大体（leaving the building）。希尔是非常资深美国外交官，曾任基辛格的高级助手，现在那任教（应为任教）， “这个体系在无人维持。”

# 四、奥巴马短暂的变革

本章曾经讲过中位选民定理，即两党政治中，为争取最大数量的选民，两方政策取向会趋同。美国政治改革历史曾经相当符合中位选民定理的预测，但十几年来的政治实践离中位选民定理预测越来越远，极化越来越严重。

在一系列问题上两党相争，共识越来越少：怎样对待伊拉克战争？怎样对待酷刑？怎样对待同性婚姻？怎样面对人证（应为人口或人权？）？种族问题更是房间里的大象，不讨论，假装看不见，但政治动员力极强。

有分歧是政治常态，没有分歧就没有政治可言，但有分歧又有政治是型态（应为常态或变体）。两党合作空间越来越少，而政治撕裂越来越严重。美国政治是典型的钟摆政治，总是来回摆动，不会长期朝着一个方向狂摆。今天美国政治还没有脱离钟摆状态，但摆动幅度显著加大，有摆动夸张化态势。

奥巴马的成功之处也是其失败之源。他找到时机，在民主党长期势力的几条战线强行突破，比如普遍医保，又比如同性婚姻。只是，强行突破的后果都成功难以长久。对方一旦得势，反卷（应为反弹）来得会更加凶猛。奥巴马政策今天已难保全。

前民主党全国委员会主席霍华德恩思尔耶鲁法学系人们说（此句OCR严重破碎，大意可能是某位耶鲁法学教授或相关人物的评论），这一代台前的美国政治家们都应该读下来，**美国人民真正需要的是互联网**（此处存疑，可能是指技术或新思维），新一代领袖。我知道他的意思。换新元（应为换血或革新），带来新思维，放下一个历史包袱。若超越两党争斗已经从中间的历史一个泥潭（此句语序混乱，大意：若要超越两党争斗的泥潭），必须要重新表达问题，因为老问题已成死结。

奥巴马其实是近年少见的为美国总统（此处应为“卓越的”），卓越的战略家，在政治极化、僵局难破之际，仍抓住机会做许多他想做且承诺过要做的事情，但这些成果现在看都暂时取得成功难持久。高度、把握、激烈的政治博弈中，任何人、一时得手，无法持久。

# 第20周问答 | 汇率升贬值的三重逻辑

![](img/d0b39398554e3d9ba7f47bdd8890a825_14_0.png)

**雪飞鸿：** 系统讲下影响货币升贬的因素吧？

一国货币汇率的升跌，短期取决于市场交易动力，中期取决于国际收支情况，长期取决于对这个国家首先是对其政府的信心。

短期取决于市场交易动力，也就是买方与卖方的能量对比。新年以来离岸人民币市场出现罕见的人民币对美元大涨，就是一例，价格一度重回6.7区间，并使人民币对美元的离岸价格越过在岸价格，出现倒挂。因为离岸市场是自由市场，而在岸市场翻不出中国央行的手掌心，所以相当长时间以来是人民币离岸市场价格低于在岸价格，并有引领作用，尽管其规模相对于在岸市场来说小得可怜。此次利用离岸人民币流动性抽紧之机，多头力量突击空头，正如一位财经重量级人士所说的那样，择机夹了投机力量一下。

中期取决于国际收支，这又分成贸易和资本项目两部分。在中国，这两者现在处于背离状态，进出口仍然是巨额顺差，资本则是巨额流出。两者之差，再加上国际收支表上的“误差与遗漏”项，使得外汇储备从最高点的4万多亿美元节节向下，目前逼近3万亿美元。

资本巨额流出，首要因素是企业基于汇率预期调整资产和负债结构。预期美元对人民币升值，所以企业增加美元资产减少人民币资产，相应减少美元负债增加人民币负债，正如2005年以来，多年间因为预期人民币升值所以增加人民币资产减少美元资产，相应减少人民币负债增加美元负债。当年人民币面临的升值压力，今天人民币面临的贬值压力，主因都是中国企业基于汇率走势预期的调整行为所致，而不是什么海外做空势力。不然为什么去年以来会出现中国企业天量海外投资？因为要将负债留在境内，将资产置于海外。

如果说这次有什么不同，主要是中国家庭资产配置美元这个因素第一次变得重要。中国家庭的人民币存款总额已近60万亿元。由于外汇管制放松与人民币升值相同步（应为汇率波动或改革），中国家庭配置外币资产的比例极低，只要这个比例向正常水平靠拢，对人民币汇率和外汇储备数量就有持续压力。

长期中，一国货币的汇率取决于人们对国家首先是其政府的信心。法定货币没有固定的锚，价值完全来自政府信用。法治社会，长治久安，安宁幸福，和平稳定，这些是政府信用的根本，也是其币值的最终保障。

影响货币汇率的这些短期、中期、长期因素，时常各指一个方向，力量互相抵销。今天的人民币汇率应当还处于这种状态之中。真正需要担心的是影响短中期的因素形成合力，指向同一方向，这会释放出排山倒海之力，非人力所能抗。当年人民币启动升值进程，就一度处于这种合力之下，将中国推进了黄金十年。今天，中国相似但方向相反的合力形成，中国会被推到哪里？

但如果失败呢？

在虎妈看来，失败不可接受，因为它不应该发生。她在《华尔街日报》的文章说：

经常不经意中，虎妈提到了刻意练习的门（应为概念/理论）。

刻意练习适用于这类领域和技能的学习：

- 难度分级；
- 目标明确；
- 反馈清晰；
- 方法成熟；
- 改进具体；
- 过程艰苦；

成人的刻意练习与孩子的刻意练习有巨大不同。成人只能靠自己，孩子则必须有父母的角色。问题是这角色是什么？

虎妈说：“中国人父母懂得，除非你擅长，什么都不敢做。而要擅长任何事都必须努力。孩子一遇到困难就会想着放弃，这时父母要做的就是推动甚至不惜逼迫他们坚持，练习、练习、再练习，越过困难，进入正反馈的轨道：努力带来回报，回报激发努力。获得赞赏，建立信心，那些曾经恐惧的练习这时变得有趣。”

如果你面对挑战，准备不断加码，增加努力，确定你走在那条适合刻意练习的路上，因为不是所有领域都有难度层级。明确目标，清楚反馈，成熟方法，可具体改进的训练。刻意练习不适合用来开发新领域，养成习惯，获得快乐，而是用来精进，发展旧技能，获取新技能。如果你在这地方刻意练习（应为在不适合刻意练习的领域），套用虎妈公式，屡层加码，那就离悲喜薄（应为悲剧不远），最后结果是悲喜剧。如果是父母用在孩子身上，则是双重悲剧。

高标准，严要求，不找借口。如果你能接受这些虎妈公式，搞清它适用于那些地方，它有用，但不普适。
