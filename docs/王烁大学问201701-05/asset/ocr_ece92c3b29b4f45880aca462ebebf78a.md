# 你才知道会讲故事如此重要？

1974年12月的某一天，在布鲁塞尔饭店的两大会议室，约100位政策大腕正为拉弗曲线讨论。拉弗曲线的发明者，在拉弗先生向他和同事们做最后一次晚餐。拉弗向他的听众展示了一条曲线，并指出如果降低税率到某个程度，那么税收总额也会增加。

他点过烟之后，画了条曲线。

横轴是税率，纵轴是税收额。从这条曲线看，在任何一个税制下，都对应着两个税率，一个高、一个低，其税收总额相等。假设税率是零，那么税收总额是零；假设税率是100%，则同样你挣多少全都拿走，那税收总额也一定是零。

这条曲线的政策含义是什么呢？

给政府的建议是别制定特定的税收率，那么增税（率）不如减税（率）：到的税收收一样，但低税率环境于增税，增社会活力与创造的动力。福利予民，等等等等。减税创造就业，就是这样。

只有一个问题，故事的主角拉弗说，记得有这回事。

看别人写的拉弗曲线，这个故事是4年后的《华尔街日报》主编的阿瑟·拜瑟斯报道出来的。万一当量当你在场，发现了这条曲线，今天它已经进入了美国国（要看餐巾上的曲线，最好向左侧弯90度）。

![](bbox=[0.15, 0.21, 0.85, 0.34])

拉弗并不完全满意，多年后回忆，他说，这幅画是伪造的，我的从教育界，不是反对反对东西。言下之意，自己并不是在餐巾上画过这样的事情。

这个故事的真假，已经无从考证。因为拉弗曲线及其逻辑在后来的媒体与学术界提供的税收学曲线的时候，并非发源于某国，而是全球，影响从波兰及全球的小经济滞胀、通胀、科创等，成为那个时代的总体解决方案。这些也都是真得。

拉弗自己也写了一本长论文：拉弗曲线的过去、现在和未来。是啊，故事好，何不得其错误？

"人们都在做故事旅行"。讲到这里，耶鲁经济学家、诺奖得主罗伯特·席勒如是说。

希勒在 2017 年在国际经济学年会上作主题发言，并将在耶鲁大学经济学尝试，题目是 叙事 经济学 (Narrative Economics)。

叙事什么特点？

希勒说：

+   第一，它容易理解，可以口传暗。
第二，它直接与激情与利益相关；
第三，它完或不完全不重要，是故事还是笑话不重要，但我们愿意在谈话中提到它们，因为能激发情感、行动、关切与激情。
第四，它传播起来好像流行病一样；
第五，往往区分"我们"与"他们"，多少有点像阴谋论，常常涉及道德判断；
第六，它常常涉及身份认同。

会讲故事有多厉害呢？

餐巾上的拉弗曲线影响了美国乃至全世界的经济政策，但并不算什么。在希勒看来，刚刚当选美国总统的川普才是真会讲故事的讲故事的。

"我特别上了他的竞选网站看，刷的我不停。经济政策部分，全看是相互协调一致的叙事结构，绝大部分是假。"

如果天时地利人和俱备，讲着讲着故事，你就成了美国总统。

如果故事讲不好呢？那完全可能引发金融危机和经济危机。

希勒认为，如果忽视故事性，除了每个大周期的开端，全球需要关注往之，他专门了1929年美股的大条崩溃预测。股市崩盘，经济学家们恐惧，他们的预测错误将消费者从乐观到悲观，这只其一。神人也在新型病毒告知的危机。人们穿着变得更简朴。选果从股市崩盘中。

讲道理可你可能已经说过了，分析故事有问题。分析它本身就是就故事，隐性很强，为什么是这些故事放到了分析框架而不是其他呢？

希勒意识到这个问题，他我不知道哪些是事件能导致故事产生，而是选择传播，从而导致这些活动。也不知道什么在何时发生，但历史告诉我们"世界的故事"。

故事能力能自地出得者得而组合连续剧的世界。

报告中，希勒引了Baker-Bloom-DeSanctis的指标，指预测编制公式中，新增媒体传播故事要的数据来预测。也就是说，个指数能够衡量市场有效的影响。我也告诉你们大家分一下，当下全球政策不确定性处于有效风险上的最高点。

![](bbox=[0.05, 0.785, 0.95, 0.825])

其实希勒的叙事经济学一个是：三个角度，一个是真世界，一个是叙事认识，一个是人类行为。我们关心人类行为，而直接影响的类行为是叙事逻辑，叙事世界是故事关系人是不确定的，许多时候两者一致，但大多数是两者不一致的时候最重视，这时候就故事逻辑通过一种有效的方式人类行为会按照真实世界行事，跟着故事就起作用了。

希勒用google的Ngram搜索类发现，所有社会科中都可以追踪，这科学为什么不下那么难追踪呢？因为不最重要的就是经济学，金融学，无论，经济学和金融学使人们能追踪故事发生本质。

可惜，血肉之躯的真实完美不是这样的。
