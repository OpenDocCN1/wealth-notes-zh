# 第26周问答｜风险、活力与监管的金融困难三角

**轩烨**：金融创新花样繁多，监管要如何把握尺度，才能既防控风险，又合法法治原则，又不破坏市场活力？

**王烁**

此事古难全。防控金融风险，遵循法治原则，维持市场活力，或许还没到不可能三角那么严重，但至少是个困难三角。

我来告诉你金融风险是什么。说一道一万，手法简单也好复杂也好，其实看结果就是负债欠太多。欠钱太多，钱太多欠不到就刮了。这就是风险。反过来说，欠钱不多，本金相当多，就是富得流油，这就是安全。

同理，监管的本质就是看着金融机构杠杆不要放太高，至于用什么方法实现，在其心。

再来说活手法放杠杆，而主要办法就是资产表外的化风险转移，因为资产表上的东西，监管看得到，便要求披露，而且都有一定之规，违反就是违规，违规就有后果。何必呢？所以想办法做资产表外。

过去几十年金融市场最大的创新是什么，主要靠监管套利？把金融业务移表外，变成各种固定收益产品，储户变成固定收益产品的投资者，理论上风险就小了。美国到2008年金融危机，花了近40年才走到这一步。中国走到相同程度，花了最多十年时间，而大爆发是最近五年。

**说到金融监管，法律是必要的，但靠法律是管不过来的。** 业界总是跑在监管的前面。没办法，激励不同。一个要挣钱，一个不为太。

金融监管是个老游戏。从猫的难为题目，让老鼠不偷鱼也没有好办法。难道到今天金融界有老鼠也没有银行危机吗？照样有，形式不同而已。让金融界没有杠杆，让所有银行都关门，就没有金融风险了。但那样就没有经济了。所谓金融风险监管，就是让老鼠把鱼吃个够，同时保证猫也能活下来。

你尽可要问：“王烁你把它话都说完，你到底是什么意思？”

我的意思是说：

**第一，金融监管要有比较大的相机取款权力（discretionary power），这种权力并非来自专门立法，而为法律所不及。** 耶鲁大学学者各金融数学最高登说，如果美联储掌握哪家银行补充资本金，那么银行有什么权补充就不要关望那家银行。美联储就有补充，不关你的事。要让你补充就补充，别无选择。高登说，美联储需要这种权力，把所有权利都写成法律，对金融监管来说不是好事情。

**第二，相机行事的权力太大也不行。** 权力太大则难免独断，一是有可能打破市场的基础性共识，二是有可能令法规，搞损毁性。其次在危机来临时，市场总是想与监管者合作的，只要你给他机会。

**第三，金融监管指难搞。** 金融创新既难压也压不住更何况，压不住是好事，关键是让金融风险释放。谁敢赌下该倒就倒，倒得越快对总体越好，别拖着就太大而不倒。不说不该有，又能解决金融风险，但它就大定会有金融风险。

**第四，最终，我们恐怕得现实一点，要学会在一个时常爆发金融危机的世界里生存下来，而不是指望它不发生。** 没有一个经济体成熟到让从金融危机这门课中毕业，包括美国也没有。
