# 第28周问答丨共享单车与中国电信有个相似之处

TerryPan：最近共享经济比较火，滴滴的模式可以看到盈利，共享单车如何有盈利模式？

王烁：

虽然都叫共享经济，优步、滴滴代表的共享汽车和摩拜、ofo代表的共享单车商业模式的确认不一样。优步、滴滴把私家车的闲置能释放出来，对掉公众的打车需求，创造出真金价值，然后无非是和大众分成。问题在，起步阶段需要补贴用户和司机，投资极大，共享单车的商业模式本质上是极轻资本的：司机自带汽车，自负维修，自负保险，等等。一旦市场确定完成，停止补贴，只需要投资于平台建设和维护，运营杠杆极大，简直是躺着收钱。

共享单车的商业模式没有这么幸运。它不是车主自带自行车，而是公司向社会投放汽车，需要极大的初始资本：不幸的是自行车损耗严重，需要不停地追加投资。不仅是一开始，就等到市场整合完成的时候，它也仍然是个重资本行业。

重资本行业不是不可以做。举个例子，建电信网络需要极大的投资。怎么来的？你还记得初装费和入网费吗？装部电话要付初装费，手机入网要付入网费，就是用户们先给我一笔钱把网络建起来，然后使用再按量计费。

今天的共享单车做的事不太像滴滴，更像当年的中国电信。用户付押金相当于初装费入网费，摩拜和ofo把共享汽车的初始网络建起来，停车车放到大街小巷，然后使用时按次计费。

摩拜和ofo当然不能跟中国电信的能量相比，所以才不要装，是押金。初装费付了就可以，本金还能源，在公司账上是应付款，与无息贷款相似。

毛估一下市场规模。假设最终有1亿人用，对应1000万台单车投放，每人付200元押金，在每个人用一辆的购置成本是500元，那么，总共要花50亿元买自行车，而押金则是200亿元，完全够了。假设实际中是1元5毛，每天两次，那么一年就是365亿元收入。账这么算就明了：押金对应硬件投资成本，收入对应运营成本。

你是不是觉得我画饼画得太爽了？我相信摩拜和ofo的CXOs给投资者描绘的图景跟这个逻辑应该差不多，就是参数细节不同而已吧。当然，这个行业总市值估计，加到20亿。到了，从工作早做投资，历史为鉴，最后，通过竞争，并购，整合，市场总量估计适用于最后剩下来的赢家。问只摩拜和ofo谁是赢家？这个问题只对它们二者有意义，如果你是投资者，看好这个行业的未来，那么你该想两头下注。

最后，想你们已经看到共享单车重投资的关键所在了，就是有极大的内置杠杆：平台下来，一辆单车，多个用户，对应多少押金。我上面使用的比例是1:10，只是为了计算方便，实际的比例少可能是商业秘密。用这个杠杆撬动集合用户的投资，造出单车网络，逻辑上是可行的赢。现在细节之中。

还是那句话，事在人为。如果你也有问题要问，欢迎留言，我会周六答复。
