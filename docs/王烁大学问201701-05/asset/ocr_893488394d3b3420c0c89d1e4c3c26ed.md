# 第24周问答 | 保险最好是消费

D. X104361：可以说一下对保险的看法和建议吗？

+   - **王烁**
    - 保险是对风险的对冲。你担心什么大病就购买什么保障。如果你担心生大病的治疗费用太高，那就买健康保险；如果你担心房屋毁于火灾，那就房屋保险；如果你担心意外伤残死灰留下了老小无依，那就买寿险；如果你买了债券担心发债企业破产倒闭，那就买CDS，等等等。

买这些保险就是消费，消费是保险的本质。所谓“保险投保”，这一段经常在媒体上看到的保险会宣示，指的是这个意思。你付出保费，获得给定时间内针对特定风险的保障。如果给定时间发生，祝贺你；如果风险发生，你获保障。

保险存在逆向选择问题。比如说，医疗保险本质上时购买医保的人群的自我保险。由保险公司居中完成。保险公司向每个人收取保费，保费高低根据人群的患病概率等多种因素核算而来，成然是基于人群健康状态的均值，但每个人的健康状态及相应的治疗费用则不会是平均的。有的身体差治理费用高，有的身体好治疗费用低。身体差的，贴补身体差的，中间保险公司拿走点利润。

所谓逆向选择，就是预计到这种情况下，身体好的人不愿意参保，何必去补贴人呢？而身体差的人积极参与，不去占大便宜吗？而身体差的人极少，买保单的人都是身体极差的，保险公司怎么办？保险。保险公司要不傻吗，怎么会？提供保费。于是展开新一轮同样的博弈。继续亏则驱除良币。今天美国的奥巴马克医改就陷入了类似的陷阱，参保的人数减少，保费提升，保险公司亏损增加。有人说，就算公司不搞定，它也将持续了不太久。

但上述的逆向选择问题是无解的。否则世界上就没有保险公司了。每个人对风险的概率判断和价值判断都不同，这种差异就构成了买卖保单的基础。如果你很重视替代保险，就不会太介意事实上补贴了别人；千金之子，坐不垂堂，哪怕栋榫掉下来砸到他的机率微乎其微。只要投保人群数量足够大，每个人对风险的差异定价便使保险得以持续运营。

保险的另一面是投资，对保险公司来说投资是必须的。获得保障与支付保障之间是资金流。有一定保险公司总会持有一笔资金。保险公司对保险公司的资产不同，但先不说那么细，把它大致理解为巴菲特所说的“浮存金”（float）就好。浮存金可用于投资。事实上，从保险投资的角度看，你可以把保险业务理解成有获取浮存金运营收益权利的成本。保险投浮存金运作方式的权利的竞争极为激烈，以至于保险业务本身往往是亏损的，都指望从浮存金投资中挣回来。

这局你作为投保人基本没有关系，如果保险公司资本金充实保障能力强的话。但除了消费之外，对于投资人来说，保险仍然有投资一面，就是说，许多保险产品不仅提供保障，还提供投资收益。

听起来是不是很？

但世界上没有免费的午餐。你看今天保险产品他们越来越复杂，你看今天纯粹的消费品越来越少，消费与投资杂合的越来越多，甚至出现了几乎纯粹为投资的保险产品，知道投资者可不见得一定是好事。

首先是把产品复杂化有利于掩盖高定价，太简单让你看清了，保险公司的精算师也不就成摆设了吗？更重要的是，那些非正式为投资的保险产品，如何能呢，对保险公司来说实是短期融资工具，对投保人来说则无异于短期理财产品。

凡类保险的风险是相当高的。保险公司用保险产品做长期投资，甚至向海外人去这钱用来到对万科的敌意收购。应短期期限的惟一办法是滚动发万能险产品，而且必须规模越来越大，否则就有资金断流之虞。

用保险产品来做投资还有一层不利。就是保险的成本偏高，你购买保障的经纪人佣金或者渠道成本先吃走了你一大块，然后再用于投资，可谓输在了起跑线上。如果本意是投资，完全没有必要走保险，由你成本工具多元化组合非常定价，而成本很低。

对普通人来说，最简单也最好的方法是各管各。让投资回归投资，保险回归保险。记住保险是一种消费。你想管理好风险，就购买什么保险服务，这就是正确。
