# 世界学人这样破解难题

耶鲁世界学人个人都相当成功，但大家都是人，同样有压力有烦恼有挑战，所以当一位学人提议开一场特刊讨论，彼此贡献解决问题的技巧（life hack）时，讨论意想不到的热烈。围绕三大主题展开：

+   - 怎样自我管理，提升效率？
- 怎样在压力下增加适应能力？
- 怎样激励自己和他人保持创造力？

下面是成果整理，来自16个耶鲁学人的集体贡献，希望对你也有用。

无纪律地管理时间：充分利用最短后的高效时间段；保持注意；用番茄钟来协助保持专注；每次只做一件事，用25分钟，休息5分钟，为一个番茄钟，如果还想继续做，则再来一个番茄钟，依次类推。在日程表上为重要项目优先留出时间，其他事为此让路，并围绕重要性来重排时间。

主动设定日程：为短中长期目标设定优先级，并主动创建自己的日程，而不是被动应允。从每天固定时间的邮件做起，而不是邮件条来随回，这样你的日程表是被动的。

定期自问：我接下来的目标是什么？

随时记下想法：善用列表。

善用软件：Calendly.com（日程）、Doodle（小组会议）、Trello（任务管理）、Evernote（记录）、Slack（团队协作）。

保持开放心态：即使事情并不在你掌控之中，不要焦虑。

拥抱变化：旅行、听音乐、做菜、做瑜伽。

学习一项新技能：比如演奏一种乐器。获诺奖的科学家中会演奏乐器的比例远高于整个科学家群体。打破日常惯例，比如换条上班路线，换用左手刷牙……

走出舒服圈：听不同意的观点和想法；见陌生人，跟你更聪明更能干的人在一起。与能力互补的人合作。

督促你周围人的成长：给自己找一位导师，或者指导一位门徒。

大胆从别人那里“偷”想法。自己不会没关系，向他人求助。

下放任务：注重最后的结果，而不是下面的人用什么方式完成它。

读书，无论是传记、历史、小说还是诗歌，上下班路上听听有声书，衣服口袋里随时放着kindle，好事要多读，写长文章，每本书不必读完有益微。

最后，也是关键的，健康最最最重要，一定要定期锻炼身体。

我决定都试试。

最后告诉你我一个小办法：我是把手机和Kindle放在一起，并在大脑中植入一个if-then：想刷手机，then打开kindle。

理解自己，操纵自己，更好地管理自己。
