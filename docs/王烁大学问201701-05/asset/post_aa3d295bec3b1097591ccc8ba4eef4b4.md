
# 第 111 封信 | 澳大利亚日记 ( 三 ) ——墨尔本

宝宝，你好！

我在澳洲的第三站是墨尔本。如果你在澳洲要找一个最具有欧陆风情的城市，那么就要看墨尔本了。

墨尔本的历史并不长，它在 1835 年才开始建城， 1837 年以英国前首相墨尔本子爵的封号命名了该城市。到了 1850 年，殖民者在墨尔本周边发现金矿，于是来自世界各地的淘金者纷至沓来。因此，墨尔本也被称为“新金山”，而之前的淘金之都圣弗朗西斯科则被称为“旧金山”。

墨尔本的市区非常值得一看，那里有很多德国和意大利风格的建筑，非常漂亮。另外，它的皇家植物园规模很大，喜欢花卉摄影的朋友可以去那里展现自己的摄影技巧。墨尔本也是最早居住海外的中国人的聚集地，那里有规模很大的唐人街。

墨尔本最著名的景观是在它西边的漂亮海岸线。从市区出发往西沿着滨海高速公路——大洋路（ Great Ocean Road ）一路开，沿途是澳大利亚最著名的自然景观，和壮丽的海岸线穿梭于鬼斧神工的奇石美景中。

![](img/d0b39398554e3d9ba7f47bdd8890a825_22_1.png)

从墨尔本市区出发，大约一个半小时就能到达大洋路上的第一个景点，爱丽丝湾灯塔 ( Aireys Inlet ) 。世界上的灯塔大同小异，在澳大利亚最值得一看（或者拍照）的就是这座七层高度的灯塔了。在那里不仅可以欣赏灯塔和海岸峭壁一同构成的风景，而且可以在灯塔上眺望海岸。如果是当地的冬天（北半球的夏天）在灯塔上看日落应该非常壮美（夏天日落较晚）。

从爱丽丝湾灯塔往西开车大约 2 小时左右，就能到达著名景点十二门徒石 ( The Twelve Apostles ) 附近。这里第一个景点是吉布森阶梯（ Gibson Steps ）。所谓 Step ，就是阶梯，那里能走到海面上看悬崖。

如果是晴天到那里，可以看到湛蓝的水天一色的美景。我去的时候阴晴雨天，天色蒙蒙的，但是红色的悬崖峭壁和海水的绿色形成鲜明的对比，有一种打翻调色板的感觉。

![](img/d0b39398554e3d9ba7f47bdd8890a825_22_2.png)

沿着大洋路继续往西走，很快就能到达当地最著名的景点十二门徒石。那段海岸是由红土和沙石构成，质地松软，被海浪侵蚀后，切割成一个个小岛似的礁石，矗立在海中，一共 12 个，被称为“耶稣的十二门徒”。不过由于这些年海水的进一步侵蚀，只剩下八九个了。

![](img/d0b39398554e3d9ba7f47bdd8890a825_22_3.png)

## 归多的清算

![](img/d0b39398554e3d9ba7f47bdd8890a825_23_0.png)

站在耶鲁法学院斯特林楼121阶梯教室讲坛上，归多·卡拉布雷西（Guido Calabresi）声如洪钟：

“我老了，耳朵不行了，什么都听不见！你们向我提问，一定要用吼的！”

满堂哄笑，不过竟然有几十秒钟，没人提问。

与其说是冷场，不如说是亲昵和尊重。除了个别我这样的外来人，在座都是他的弟子、弟子的弟子、弟子的弟子的弟子，对他刚才讲座的内容早就烂熟于心，还有什么问题呢？

他们来听老归多讲座，有些是来见证活着的传奇，有些则是见一次少一次，能见一次是一次。

![](img/d0b39398554e3d9ba7f47bdd8890a825_23_1.png)

归多·卡拉布雷西，84岁，与罗纳特·科斯、波斯纳并列法经济学三位创始人之一，耶鲁法学院一宝，任院长多年，教鞭下出过三位美国最高法院大法官、法律界重量人物不计其数，现任美国联邦第二巡回法院高级法官。

今天来讲他2016年出版的书《法经济学的未来》（The Future of Law Economics），这是他历年来关于法经济学演讲的修订结集。他在自序里说，朋友们都劝我，快出吧，不要等老糊涂了想出都不行了。

归多的新书与讲座，都旨在为法经济学作一个路线问题总清算：法经济学，有法有经济学，孰主孰从？

![](img/d0b39398554e3d9ba7f47bdd8890a825_23_2.png)

在归多看来，当法经济学于1950年代兴起的时候，路子是正的，代表就是科斯的经典之作《公司的本质》。

科斯发现，如果市场像主流经济学家说的那样有效，那么公司这东西就不应该存在。你做任何件事情，需要什么物品、服务，临时从市场上买来整合就完了，何必要造永久性的公司呢？

可是，公司它事实上就存在着啊，哪里出问题了呢？

从这里出发，**科斯提出交易成本概念。市场和公司都有交易成本，哪个交易成本低，生产就更倾向于围绕哪个来组织。** 两者都有交易成本，而成本又有差别，所以既有市场也有公司，并塑造了两者之间的边界。

### 1.1.1写作方法

在讲座中，归多说，科斯既加深了人们对公司本质的认识，又拓展了经济学研究的边界，这就是他理想中的法与经济学的关系，那就是法与经济学，而不是法的经济分析。后者用经济学解剖来解释法律问题，并视不符合经济学推论的法律现象为不合理，必去合快。

> “在法与经济学中，法律不是经济学的婢女，应是平等的，法和经济学。”

归多所指的目标，是法与经济学的另外一位创始人，也有联邦法官之称的理查·波斯纳。将法与经济学的焦点从卢边扭转为用经济学单方面解读法律时，波斯纳成为以出为最大的正向波斯纳。波斯纳有一位朋友，诺贝尔经济学奖得主加里·贝克尔，芝加哥学派的旗手之一，多年来对其科斯很有经济学帝国主义之怨言，曾批评他的就是贝克尔。他走出来给法学首当其冲的第一批重量级经济学，将经济学分析方法用于家庭、社会学、犯罪、毒品问题研究。在他看来这很正常，人就是人，理性假设、效用最大化，用来研究哪种类行为不行呢？

敌人的敌人就是朋友，归多亦通此道。在经济学当堂中，归多引行为经济学为盟军，与他认为的法学经济学正道是相通之处；即根据现实调整假设，而不是把现实当作异现象。

这些不仅是学术派别之争，背后有着非常沉重的真问题。

归多自己也走过这个历程。他早年曾写过一本对法律经济学影响极大的书《事故的代价：法律和经济分析》，这本书讲，你不能只看事故造成的损失，还要看为了防止事故而付出的成本，公共政策应该建立在对两者的权衡之上。

《纽约时报》发表书评批驳归多，认为人为化。在新闻中，归多把自己想法的变化。他的第一反应是给《纽约时报》去信，建议《纽约时报》的运邮卡车时速一律不得超过每小时10公里，因为“人命无价”。但是，逐渐地，他意识到，尽管事上人命有价，但“人命无价”的道德观念在社会中具有统治性的地位，也是事实。两个事实同样真切，你不可能把其中一个脚脚来掉解决两难，它硬硬地还在。

包括生命在内，社会不接受为许多东西定价。为这些东西定价，会为社会带来负外部性，这种负外部性与经济学概念中的负外部性如污染不同，它是道德意义上的负外部性，制造极高的道义成本。

还有一类东西，社会大体接受其有价格，但很难接受按照已有的财富分布来作分配。比如说，人体器官，人体器官有价格，并不让人们感到特别不适，但如器官分配按照高者得来分配，谁有钱，谁获器官，谁活下去，那几乎没有社会能开接受这样的果，虽然这是大多数相关经济学论文的支持的做法。

人们对公平理论的强烈情绪与效率的改进同样是现实，同样重要，如果经济学看不到这点的话，是经济学的问题。

从出发，归多研究利他问题，市场与政府，剩下的都是历史，读《法经济学的未来》可见脉络。

我来听归多讲座还有一个原因，是我读他的名著《悲剧选择》（Tragic Choices），这本书的主题是“社会在分配悲剧时稀缺资源的困难选择”，专论社会怎么分配悲剧：怎么确定悲剧总量，以什么方式分配给谁。

> “我们都想活下来，但做不到；我们希望人人平等，但都不会；我们盼望苦难结束，但它不会。”

对这个题材，我是太感兴趣了：第一层，作为新闻工作者，和同事们每天都在耳边重复悲剧；第二层，去了解这些悲剧把它写出来就是我们的工作；第三层，作为编辑，我需要在社会分配悲剧之后，下判断后再报道资源的分配。

泰坦尼克号撞冰山，谁先下船？计划生育，如何分配生育指标？器官移植，谁优先考虑做器官？大病保险，哪些病能进名单……

回答这些问题，是全社会的事。决定投入多少资源去报道，是我的事。

在《悲剧选择》中，归多说，社会分配悲剧有四个策略：市场、政府、报筹、惯例，但**没有哪个能长期维持分配的稳定性。**

市场化分配是分散决策，但价格高者这一机，不可避免地将已有的财富不平等展到当下悲剧分配的不对称，并且注定将人们认为不可定价的东西加在命上价格。没有一个社会能允许市场分配一切。

政治化分配的好处是较能反映民意，如果政治背后力量对比产生选票的话；但这使得混合配成为现代政治的常态：如果直接提出分配不均，那就会为社会价值观冲突的目标；民意如潮水，总在分配前承受悲剧的政府无法稳定地保有民意支持。

抽签把一切交给运气，看上去是绝对平等的，但什么杀老孩子珍视的另一一些平等呢？为什么不把社会子？为什么不把让给那些有巨大贡献的人？而且，抽签撕下了面纱，让悲剧无法隐藏赤裸裸摆到社会面前。社会其实不能承受这种真相。

所以，社会也用惯例、习俗、文化来掩盖对悲剧的分配，比如印度现存至今的种姓制度。可是，这种表面上无可非议分配有代价：社会假装习以为常，**无比虚伪面上纱。**

**社会最得有道德自信，就得将悲剧的分配伪装起来。** 归多认为，单一策略的效果往社会要保有道德自信，就得将悲剧的分配伪装起来。归多认为，单一策略的效果往往不如混合策略，就是既不是全靠自己也不能全靠自己，而是两者杂糅。即便如此，稀缺永恒，每个社会都在做六个杯子五个盖的挪腾，能玩就玩下去，玩不下去了，社会就只好重置游戏。

这导向社会价值观的周期性切换：因为无法在冲突的价值观中作出取舍，所以都保有它们，但在时间上分叉。某个时段某个价值观占上风，直到它承载的负能量过多，终被另一个价值观所取代。风水轮流转，这是社会选择悲剧的跨时多元化策略，借以为相互冲突但都被珍视的基本价值观留下火种，并缓冲冲击。

# 深度工作法

深度学习是人工智能的事，深度工作则是每个人的事。

生活与工作被切割成一个个碎片，这已是既成事实，我们不可能也不会想回到碎片化之前的那个田园牧歌时代；但时间在碎片中迷失，却始于手机没有用处，就算手机非大碍极，未了还得自己决定接下来怎么办：生活是你自己的，工作是你自己的，把生活过得最为充实，把工作做到最高效率，责任只属于你自己。

必须在碎片化中找到深度工作之路，下面有一组办法。

第一，反复练习。

我们都知道大脑皮质，但大脑还有近50%由“白质”构成，即髓磷脂，也叫髓鞘素，它得以产生并包裹大脑神经纤维化使其过程叫作神经髓鞘化。神经髓鞘化能使神经传导速度变快，好比由粗管变成宽带，对高级动作技巧反应的学习来说至关重要。

神经髓鞘化会在两种情况下发生：小朋友在成长过程中自然获得，成人也可获得，但必须付出大量努力反复练习才行。

好消息是大脑的可塑性伴随我们一生，也就是说，什么时候学习都不晚，坏消息则是这并不容易。重搭大脑回路，需要大量、反复、有针对性的练习。形成肌肉记忆两件事：第一，反复练习，这告诉我们成人学心必由之路；第二，**正确练习**，仔细聆听反馈给你的信息，有针尖地调节练习方式同样重要——你不别大脑搭建错误的回路。

第二，善用注意力剩余。

你做当下这件事，与你做上一件事及下一件事，有关联。注意力是我们最主要的资源，时间碎片化对**我们的**消废，多就是来自于在多件事中来回切换，注意力随之损耗，于是忙碌、焦灼、效率低下。我们试图多任务处理以获得效率，结果却适得其反。我们不是人，人脑学不是电脑，做不到万花丛中过，片叶不沾身。

接受人脑的黏性，我们只能克制多任务处理的冲动，转而致力于两件事：第一，一个时间段只做一件事，不仅仅是因为专注才有效率；也分为专注才能找到工作本身乐趣。第二，前后相邻的时间段尽量做相关的事情，尽量不要跳到不相关的事情上。专注做一件事，会形成注意力剩余，对做相关事务有帮助，不要浪费它。把时间组织块，把相关工作组织块，善用注意力剩余，事半功倍。

第三，养成适合自己的工作节奏。

好习惯是最大大的，而坏习惯也是顽固的，所以最得养成好的工作习惯。习惯最有用之处就是自动克服拖延症，并对工作的焦虑化解为一道自固定流程，不再需要耗心理能量去启动，去克服。

好工作习惯不一种。比如说，美国小说家斯蒂芬·金的习惯就是每天白天自己在书房里，不写够字数绝不离开。有人拜访东欧某位笔耕数九的作家，在其书房发现书桌笔满书满架，大为拜服。这位作家大笑说，如果你把软塞起来，也能做得到！

这习惯多半不适合你，但你得形成自己的好节奏。不然，每天光你花决定何时开始工作件事，就够折磨你一整天的。

下面这些模式都行，看看哪个适合你：

- 隔绝模式：工作时与世隔绝，像僧侣一样；
- 双模式：在两种模式中切换，既像僧侣一般与世隔绝，也有正常生活；
- 节奏模式：定期，最好是每天，都固定做同一件事，形成节奏；
- 记者模式：记者有截稿期，按需写作。

第四，敢于关机。

确定一个时间，比如每天晚上8点，最后查一些邮件和办些杂事，然后结束工作，不再查邮件，不查看短信，不再刷微信朋友圈，最好关机。不在做无谓，至少把工作手机与生活手机分开，关掉工作手机。

第五，干票大的。

把视线从眼前事务中抽出来，往远方看，当然也不要太近。给自己定下未来半年到一年要做成的一件大事，然后去完成它。

高目标-任务分解-针对练习-反馈调整-朝一个目标设法提高，这是摆脱低效忙碌的终极大法。

最后，推荐《深度工作法》（Deep Work），作者是Carl Newport，麻省理工学院计算机博士，现乔治城大学计算机教授，几年前为了帮助学生决策开拓智能《学习骇客》（Study Hacks, http://cainewport.com/blog/）被视作最有用的自励类博客之一。本书于今年初出版后，《经济学人》杂志评论说：“深度工作是知识经济时代的杀手级应用。”亚马逊读者打分最高的平均分高达4.7，满分是5分。
