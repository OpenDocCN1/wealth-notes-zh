# 智别的话

![](bbox=[0.07, 0.07, 0.13, 0.09])

你们读到这篇文章时，本专栏如此期结束。我刚刚结束访学，回到北京，继续财新主编这份很有前途的工作。与诸位相处两个学期共九个月，我留下一些话，自问自答，希望有用。

知识有用吗？

答案似乎是不言自明的，其实不尽然，得看你是什么人，用处是什么。比如中国首富前三名，王健林、马云、马化腾，难道他们是最有知识的前三名？知识、技能、运气、胆色……条条大通罗马。有知识可能成功，成功不必有知识。

对那些致力于获得知识并运用它来尽量活得 好的人来说，知识才是有用的。这似乎是同语反复，但有其意义。芒格说，我的剑留给能舞动它的人。知识亦然，它选择自己的使用者。芒格本人就是活生生的例子，一生求知，既获得了众人意义上的成功，也获得了自己想要的成功，他历年的演讲，建议尽量找来都看看。

怎样快速了解一件事？

这个问题总有人问，我也回答过。这次讲得全面点。

如果你真想了解一个领域，最快最靠谱的办法就是读本教材，想差不多了解下的话，初级教材就可以；想了解更多的话，读中级教材；但是不要轻易去读高级教材，读完你可能拿到博士了。

你可能要问读什么教材。其实读教材这件事，读本永远远比读哪本重要得多。不要在挑选上想太多，任何一本美国大学常用教材都行，先读起来。

如果你像我一样主要需求是快速浏览某个主题，然后再确定是不是真想 了解下去，那么，我用维基百科，英文版最丰富最好。维基百科天天在其首页募捐，因为创始人认为知识应当是自由的免费的（free），所以拿着金饭碗讨饭。我捐过些钱，因为受益很多。作为知识的入口，维基确实很好。

怎样识人？

财新做过许多金融报道，我经常听投资家说一句话，投资就是投人。

我忍不住想投资家们到底是怎么成功的，因为人是靠不住的。
