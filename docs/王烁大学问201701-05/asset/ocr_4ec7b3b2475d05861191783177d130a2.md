# # 怎样识别不靠谱信息

UCSD政系新一代学术男神赖轶锴邀我跟学生们座谈。谈什么呢？谈时下最热门的fake news 吧，这个话题我碰巧知道真相。

不靠谱信息包括但不限有假新闻（fake news），我们从fake news讲起。

特朗普恨 fake news，我们也很 fake news，特朗普说的与我们说的是一个东西吗？

特朗普说的fake news很简单，他不喜欢的就是fake news，尤其是纽约时报、华盛顿邮报、CNN代表的主流新闻媒体，没注意华尔街日报有没有被他诅咒，目测在所难免。其实不分左中右，只要他不喜欢的就是fake news。他在新闻发布会上说的那句话：“泄密是真的，新闻是假的”，已成为时段雷音。

不过，除非是特朗普的粉丝，否则我们关心的fake news是另外一种现象：舆论场上，信息质量参差不齐，大量不靠谱，经常有假新闻。

重新表述问题后，答案自己就出来了。

第一，假新闻并不来自那些杆性新闻新媒**体**，相反，在这个假新闻泛滥的年代，他们仍在给大众带来高质量信息：在行业操守、新闻规范、流程管理、质量控制上，社交圈风**起**后，这些杆性媒体并无变化。他们面临的问题主要在于新闻行业变迁造成巨大冲击，社交媒体带来信息去中介化，作为专业媒体，新闻业需接受冲击严重。不难中立，今天仍在破，如何立就亟待寻路。反映在舆论场，就是专业新闻媒体萎缩、数量减少、音量变小，慢慢地被挤出主导地位。

第二，所谓**专业**，就是门槛、训练、投入、规范、质量这些东西。去这样做是必须的，因为这很难。举个例子，早在1990年代中，香港商人为品海投资北京的中华书局出书，商帮建立发行网络的成本就超过1亿元人民市，在那个时代是难以想象的一笔巨款。现在完全不同，社交媒体将发表门槛降低到接近于零，每个人只要会写普通通帖，想让新闻是电台，有部IPhone就是主播。声音嘈杂，带来舆论的去中心化、民主化，也释放各种角色各种动机各种质量的发声。

第三，主流新闻体主导舆论的时代，有一套信息质量控制系统，而今天社交媒体时代，没有质量控制，完全看自我发布。信息质量控制是什么意思？就是一系列要求，重要程度依次是准确、深入、全面、平衡，并且要事实与态度分开。这是百年来新闻行业的执业规范。如果说理想不能，谁给100%做到呢？纽约时报也不能，经常犯错，但你要说纽约时报不以此**为**理想，那也不对。

第四，就连专业新闻机构们，秉持这套信息质量控制理念并确实要于新闻操作过程，也是越来越少。现在所谓假新闻泛滥，不光是因为市民民主化导致信息质量失控，还因为大量媒体放弃新闻操守和专业素养。直白地说，整荡的最简单**办法**就是从社交体找回收（recycle）不靠谱信息，社交媒体又反过来回收被专业新闻机构回归的信息，彼此循环，互相为不靠谱信息的站台；整荡的最有效方式是专业新闻机构从绝对模式做成收线**纳**，放弃质量控制；整荡的最恶性情形就是整个新闻机构工具化，在中国新闻界已有案例。

第五，上面这些怪现象发生于专业媒体去产能过程中的，远不如多。互联网和社交媒体的技术会让不再需要原来的那么多的专业信息中介，新闻行业产能过剩，有待出清，给大量新闻工作者和新机构必须另寻出路，于是许多人改行不靠谱，一切出路的都吃相很难看，但许多曾经坚固的正在烟酒云散，读者到寻求避免受被骗。

第六，对新媒体的自我批评完毕，我再讲讲舆论场上不靠谱信息传播的其他驱动**力**：

首先是无恶意但低水平的信息制作者和传播者，这是谁呢？几乎是所有人。要不是水**平**低，群众当然水平低，但社交媒体上你可以见到各行各业的**专业人**士，他们对专业的了解胜过新闻工作者。但是，信息的收集、加工、整合、表述本身就是另一种专业工作。生产准确、广泛、深入、平衡的信息，克服自我态度乱入，这些需**要**刻意来要求，更需适应生产专业信息的职责意识。新闻法无一句话，任何人都能**做**自己的编辑；彭梅社为了求快，把新闻流**程**短到对两到眼睛跳过程就发，既高不经报道，但它至少不是一个个都是编辑，而已，社交媒体上，每个人都是自己的责任编辑和总编辑，全部加起来需两只眼睛。

别以为新闻工作者出身的就会好**多少**。许多同行转作自媒体后，多年的质量训荡荡然无存。原因是一是激励不**二**，质量控制本身是一套外在的刚性结构，它的根本在人性。没有这套制约，我们都会本色演出，出身新闻工作者也没区别。

这类信息质量下降还算相对正常，算是社会变迁大浪潮**中**的一部分，难免。但还有许多不正常的情况，是有明确动机故意制造假信息，可能是为了**导**流，有可能是专业水军受雇于商家走向引导舆论，也有可能是政治因素驱动。

现在的舆论场是这样的假现象：最优秀的新闻机构还在，做着一直来做的事情，提供高质量新闻，但是，这类机构**和**报道的绝对数量减少了，因为行业萎缩，关停并转；其相对比例也下降了，因为淹没在质量参差不齐的海量信息当中。这就是为什么特朗普说fake news大家都是共鸣的原因，只是冯克冯马洛，别被特朗普带到沟里去了。

在正在发生的信息质量全面滑坡面前，想靠别人解决问题，现在没有什**么**好办法。

+   ——政府审查？特朗普倒是很想审查，但他会来实现自己的**目的**，搞不好会先抓住**社**高质高信息量的标杆媒体当作 fake news给搞掉。

——社交媒体平台过滤？首先过滤技术看来并非不是问题；其**次**你并不真的想要互联网巨头们审查内容。英雄不问出处，老大哥也一样。
