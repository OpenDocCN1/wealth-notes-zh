# 伊格尔说

上文讲我在Bishop’s中学上课，讲了第二堂课，应试，第三堂课博辩论，第四堂课诗歌，唯独没讲第一堂课，因为要留给这篇文章。

老师把我们领进课堂坐下，不一会儿进来位老人，坐在主讲位置，两翼是准备提问的学生们。老师说，这是伊迪斯·伊格尔（Edith Eger），大屠杀幸存者。

我边听边记，如下：

我说自己是幸存者(survivor)，不说是受害者(victim)。幸存者强调活下来了，受害者则强调受害。你们永远不能允许他人把你应该是什么人的观念投射到你身上。

我是匈牙利犹太人，出生的地方现在归划捷克。匈牙利犹太人是东欧犹太人最被粹迫害最晚的一批。1944年，我16岁那年，某一天早上，一家人吃早饭，爸爸来亲我的额头说，“我爱你。”第二天，我们全家就被抓起来了。

那是粹纳对犹太人最终解决方案(final solution)的一部分，15个受过良好教育的聪明人，制定好计划，要系统地消灭犹太人。我们没能躲过。

我们被带到奥斯威辛集中营。进去的人排成队列，尽头站着一个纳粹军官，后来我才知道，他就是著名的魔鬼医生门格尔。他指左边，人们就往左边去；指右边，人们就往右边去。他把妈妈指向我，我报告我额头妈妈，门格尔叫住她，把我指向右边，对我说，“你妈妈先去洗个澡。”

后来我才知道，妈妈往左边去，走进了毒气室；爸爸则在刚到集中营时被枪杀了。

我没哭，没有感觉，完全处于震惊当中。使我活下来的是好奇心得，我想知道接下来会发生什么。

我从小跳芭蕾舞。门格尔喜欢艺术，有时要我给他跳舞，我就在他面前跳起来，看到我远处的焚尸炉冒出黑烟。每次跳舞，门格尔会多给我些面包。

进集中营之前，我已经有男朋友，他给我写信，信中说，“我想你的眼睛，我想你的手。”每当我觉得活不下去的时候，就读这封信时，心活下来。今天活下去，明天才有自由，有自由才能与他重逢。

但是他也被害了。

每当我在集中营遭遇折磨的时候，我就告诉自己：他们才是囚徒，我不是，我的良心是干净的。

1945年，美军第80师解放了我。我清楚地记得当年，我抬起头，看见嘴唇嘛，看见黑皮肤，那是我第一次看见黑人，他穿着美军制服。

从集中营出来以后，我才知父母和兄弟遭害，那是我痛苦的时候，也是我最想杀你的时候。挺过来。如果我们能做到，你就是做得过来。如果你对你们有什么建议，那就是不要太早放弃，不要因一时受挫便很久折磨。

我在医院里遇到了Eger，他是匈牙利显要家后代的人。后来有人问我，“你爱他吗？”我说，“他给我带匈牙利香肠。”

阔太日子没过几天，苏联来了，我们又变得一无所有。带着6美元，我来到美国。

与许多大屠杀幸存者一样，我为自己幸存感到内疚和羞耻。有30年之久，我守自己是大屠杀幸存者的秘密，直到70年代，我重画奥斯维辛。女儿劝我回来以后变了个人，我决定，自己的疗伤和善推要说出来，告诉别人。我的疗存在真正的开始。

在这之后，我才开始学习心理正，自己医生，帮助那些创后精神压力症(PTSD)患者。我告诉自己，幸存者内疚和怨恨本身关钠解，每个人要到自己心中的纳粹（find the NAZI in you）。

最后，不要让年纪成为你们做事情的障碍，我拿到博士学位时已50岁，今年要满80岁，但觉得自己己50年前还年轻。9月我的新书就要出版，书名叫做“选择”。

你们的人生必须是自己选择的结果。永远不要放弃。

# 重创伤之后如何疗伤

“知道为什么活着的人可以承受用任何方式活下去。” 尼采这话话，身身处逆境中人们的格言，也是一再印荡在《活出意义来》（Man's Search for Meaning）这本书中的强音。

维克多·弗兰克（Viktor Frankl），维也纳人，犹太人，心理治疗师，早年为奥斯威辛集中营中心，在集中营期间为囚徒做心理咨询。战后出版Man's Search for Meaning，融汇心理学来自犹太人的冷静，被迫苦者向死而生的内热，洞害人牲后仍存的宽厚，于绝地成起经济人的真知，真与善在地狱就为一炉。在弗洛伊德和利德维·齐，创立另一支奥地利心理治疗学派：意义疗法（Logotherapy）。伊格尔多年以后的心理学练起，也正是从意义疗法开始。

这是从集中营诞生的心理学派。
