# # Microsoft Office

刚刚说office同步速度不够快，回过头来就要表扬微软的这套移动套件。里面的Word是全功能的文字处理工具，就我的使用来看，看不出有什么对我有用的功能桌面版有而移动版没有。最大亮点是重排（reflow），能在不怎么大的手机屏幕上，在保有全部编辑格式的同时，自动重排出对视力友好的大字号。这是我的刚需，有它才有移动写作。

前面说过了，苹果系统自带的memo其实够好了，但好归好，它却不能在安卓手机上使用。再问一句我为什么非得用安卓呢？因为苹果有一个我心头之痛：只在手机上键位+五笔，但要流畅写作，手机+蓝牙键盘+五笔输入法是必需的，而iPhone就是做！不！到！一但接上蓝牙键盘，苹果就限定只能使用系统自带的拼音输入法。没办法，我在苹果、微软、谷歌三大系统间自动同步文本，方案虽多，选来选去，还是office套件最方便。

# # RIME输入法

顺势强力推荐一个输入法，中州的RIME( http://rime.im/)。都这个年代了，满地都是输入法，为什么还要推荐它呢？

第一，它是个开源的输入法平台，想外挂什么编码方案都可以，虽然仍属小众，已经是全平台、方言、输入法最多的平台，广东话、闽南话、吴语，都没问题。

第二，如果你是要在苹果电脑上用五笔字型的老板，那么你会发现，它比苹果系统自带的五笔轻快得多！

第三，如果你要手机外接蓝牙键盘用五笔写文章，哪怕是在安卓手机上，那么此时此刻，虽然输入法满地跑，但只有两款可用，一款是RIME的安卓版同名同文输入法，一款是搜狗，而同文输入法比搜狗要好得多，尽管它只是同人作品！

最后这个需求确实小众，但如果你像我这个就是有这么小众的需求，那就明白RIME / 同文输入法有多么可贵，记住去谷歌商店下载，国内下载的话在酷安网上搜。
