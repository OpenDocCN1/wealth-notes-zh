# 马云、刘强东答错了

在耶鲁全球政治课上，教授卡利瓦斯（Kalysa）问道：大数据、人工智能可不可以解决计划经济的问题？

巧合，中国两位企业家做出了回答。

“过去的一百多年来一直觉得市场经济非常好，我个人看法，未来三十年会发生很大的变化，计划经济将会越来越大。为什么？因为数据的获取，一个国家市场这只无形的手有可能被我们发现……相信数据到时代我们对国家和世界的经济、数据都能做的精确掌握，就像世界经济我们将会有一个X光机和CT机，所以30年以后将会会有新的理论出来。”

这段话出自马云，阿里巴巴创始人。

“因为机器人把你所有的工作做了，已经创造了巨大的财富，人类可以分享，或者可以放点艺术的、哲学上的东西。国家可以将财富分配给所有人，没有穷人和富人之分。”

这段话出自刘强东，京东创始人。

马云和刘强东是过去十年间中国乃至全世界最成功的商人，中国人看。崛起之快之猛，无论谁得刮目相看。问题来了，他们的上面两段话，对在哪里？错在哪里？

马云对在知道大数据使得获得信息变得极为方便而获得成本急剧下降，他错在忘记了影响人们行为的最重要因素是激励。

大数据解决不了激励的问题，因为人的偏好至少有两条，一层是外显的，一层是做出来的（revealed preference）。说出来的偏好，是给你听的，通过其行为揭示出来的才是更真实的偏好。

举个例子，冷战期间美苏最高领导人之间建立了热线联系，以防止误判引发核大战。不见得更好的沟通会降低了战争风险吗？更见得的理由是热线失效了，传来德罗诺夫急切的声言，我们一枚携带核弹头的洲际导弹升空，这是意外，不是攻击，重复一遍，不是攻击。里根恰好是不信好吗？

更多的信息、更直接的沟通，解决不了问题，只是换了解法。

类似马云的乐观情绪在几十年前计算机出现时曾经有过。吴敬琏先生在接受财新采访时介绍了一九六〇年代先在东欧流行一时的计算社会经济论。这种理论认为，计划经济的缺陷靠计算机“合理”价格的力量可以克服，有了计算机则应过。苏联后来的确建立了一个全国计算机网络系统，采集信息，汇总到国家计委。结果呢？没用。

计划经济的核心是上面计划下面执行，今天的数据增加了信息获取和处理能力，但正如当年的计划经济家们论只看到了算力一样，它没看到影响人们行为的是激励。激励从哪里来呢？命令体制压抑人们的真显偏好，只有市场才发挥激励性作用，让人在自发的交易中，用价格才能展示出真偏好，否则不过是在马背上画道途置充班底。

刘强东对在人工智能会创造更多财富，错在忘了这里的关键因素是分配。

无人怀疑人工智能会极大提升效率，创造更多财富。如果有什么分歧的话，只在于有些人会变得更比一些人更加乐观。不奇怪，看谁是专家，乐观预期也只会两种简单方法，一种是既有趋势的线性外推；一种是假设风险永远很小。面对人工智能近年来兴起，将其发展势头线性外推到将来，更加乐观。有人因此处于乐观，因为看到极大提升空间；有人因此处于悲观，因为机器什么都做于新还要人干什么。乐观与悲观，都是基于这个线性外推思维。

真正的智能专家反而会谨慎一些，如财新近期采访过的斯坦福大学人工智能教授李飞飞。技术突破不是线性的，大体上是随机的。他提醒，商业和资本最好回归理性，做好预期管理，不如不抱期待，会一旦泡沫过大而破裂，资本失望退出，将带来巨大的产业萎缩。真正研究AI技术及应用的公司及从业者，都会计是受害者。

此前，同样的事情在人工智能史上发生过至少两次。历史上的人工智能是周期性行业：突破带来极度热，然后卡在地方止步不前，然后冷静下来。这次也许有些不同，因为人类行为的数据化程度前所未见，即使算法的进一步突破需要很长时间，也足以支撑人工智能技术商用化保持长久动力。但相同之处也很明显，技术突破是不可预测的。下一次何时发生，没人知道。

刘强东是乐观一点，本身还谈不上对错，他错在忽略了这里的“关键是分配”。

从分配的角度看，历史上技术进步的影响是这样的：初期加剧分配差距，因为那些掌握和运用新技术及相应新技术的企业家们会获得极大财富，而新方式会增加许多老工作，两头拉大。但是故事没有结束，随着新技术渗透到整个社会，新工作会大批到来，更广泛的人群受益，最终减弱分配差距。

然而，对偏爱与分配方式之间没有简单对应关系，并不存在社会财富越多数均分的事这件事。北欧国富足稳定，人人羡慕，以至于福山在20年大作《政治秩序与政治衰败》中，他到斯达，弗被当个终极回题提了出来，即如果，一个国家的财富分配仍然从靠事分配，也就是说，跟所有其它国家一样，财富在人群中的分布也是金字塔结构形。区别之处是两点，一是金字塔的陡峭程度，二是层层的绝对生活水平高低。

不光财富，所有人群之中所作的分配，不管是啥，最终都表现为金字塔结构。人类文明的进步，不在于消灭这个结构，而是金字塔只会变得越来越平。金字塔层间在只离搞的利；接着来，增加：下而上的流动能力。能做到的这些的，就已经是和谐社会。

耶鲁课堂上，卡利瓦斯自答，大数据、人工智能不能解决计划经济问题：“因为人们会 与 系 统 博 弈 （game the system）”。

卡利瓦斯又问，假设所有的机器机器全做了，而所有人类高屋顶享，有相同的自由、富足和和平，是不是问题就都解决了？

“如果所有人都在同一层面，那它既是顶端，也是底部。人与人如果没有差别，做人还有什么意思？”稀缺是相对的，所以永恒。

马云和刘强东答错了。

## 第26周问答｜大补丸吃上瘾戒起来可难

> **葛洪雷：** 如果美国经济增长 6.5，岂不是要乐开花？为什么我们增长 6.5，全国紧巴巴？

**王烁**

解剖经济增长其实很简单。如果一个社会，能干活的人都有活干，而且都干他擅长干的活，那么从投入的角度看，这个社会的经济增长还剩下对两个问题的答案：一个是能干活的人能不能增加？这个取决于人口总量和结构变化，急也急不来。二是每个人干活的时间能不能增加。怎么说呢，现代社会以来，如果除掉早产运动女性大量进入职场的那个阶段，平均劳动时间一直在下降。我们的闲暇时间一直在增加。

当然，能干活的都干着自己擅长的活，这件事其实很难很难，要真实现了，经济增长问题已经基本解决完了。美国大概就是这样。

对许多国家来说，有两样东西使得它还未实现。第一是教育水平太低或者错配，第二是资本不足。农民种地需要拖拉机，工人产需要流水线，码农需要互联网，没资本这些就干不了。把这两层因素剥离之后，余下的部分经济学家称作**全要素生产率**，它反映一个经济体的创新能力，包含技术突破、组织创新、专业化，等等等等，本质上它是一个余数，所以叫作全要素生产率，它其实是后验的。

对于什么能促进创新，提升全要素生产率，人们有很多理论，本质上都是猜测。中国政府整天在抢答，答对这道题，就解开了当下中国经济转型升级的密钥。要我说的话，比较多的人，有比较多的自由空间，在比较正确的激励下，往比较多的方向探索，比较容易出现创新。

你的问题其实是两个，一个为什么中国增长比较快，一个是为什么稍微降下来一点就这么难受。

简单地说，中国经济增长快的原因不在于全要素生产率提升。全要素生产率对于增长的贡献只占到两成，而且近年还在下降当中。我们还是别提它了。于是答案就清楚了，增长的动力主要来自资本投入，而增长快的原因主要在于过去资本太态。就几年间持续不断的大补丸下去，于是我们看到农民离开土地进入工厂，中国成为世界工厂，加入 WTO，对接全世界消费市场。

什么东西再好，太多也不行，今天中国的情况已经变了，资本不是太少而是太多了。缺资本的时候，投入资本是效率最高的事情，今天正好反过来。但是大补丸吃了上瘾，戒可难。资本是从天上掉下来的，它是借来的，就是负债，也就是杠杆，本来是努着劲一直往上加，弓拉满，弦绷紧，现在必须慢慢把膀子撤回来。增长率下降 1 个百分点就要脱层皮，能不痛苦吗？

今天美国经济增长主要看全要素生产率变化，中国总有一天会变成这样但现在远远不是。

## 我与AI鏖战过

最近两天，我与围棋AI战过，连战连败，最后终于赢了。给大家写个战报。

讲下背景。我小时候喜欢下围棋，但没系统学过，11岁第一次摸到棋子。主要靠跟父亲在电脑上下棋。那正好是围棋很火的时候，当时四川少年围棋比赛第一名，上高中后最好成绩是市比赛第二名。这可能是业3水平，当时应该属于业余棋者，但没入职业。

这都是很久以前的事情了。棋盘已经不在，那时电脑里有个软件。那是2010年代，没多时，三、四年前。那是电脑和网上学棋。一直看视频，所有棋手都靠手机或电脑。现在水平上，主要是实力下降，实战水平也不差。

我对阿尔法狗（AlphaGo）有过研究，两年前沿传有深度学习方法能识别出棋形。当时去咨询了一位搞人工神经的专业人士，他说，这是围棋的进化。

后来，谷歌的阿尔法狗赢了世界冠军，击败了韩国世界冠军。它击败了李世石，证明了它的计算能力是顶级的。从它击败人类冠军看，它的计算是超前的，机器计算能力远超人类。

事实证明了这个判断是对的。阿尔法狗击败欧洲冠军（相当是业余5级水平），才过半年，击败了顶级高手；后来又半岁，大8岁，击败过顶级世界冠军。我击败了人类顶级高手，60比40，AI已经碾压了。

现在有两层：
- 第一个是阿尔法狗（AlphaGo）是世界围棋冠军。它的算法是计算机的。
- 第二个是阿尔法星（AlphaStar）是国际象棋冠军。它的算法也是计算机的。
阿尔法狗是1.0版本，阿尔法星是2.0版本，阿尔法狗能识别棋形，而阿尔法星是纯计算机算法，比阿尔法狗强得多。

现在有个机会：
我跟李昌镐（Leela）下棋。
自从谷歌团队把阿尔法论文公布在《自然》杂志上，阿尔法代码在围棋界是公开的，阿尔法代码在围棋界是通用的。日本将在3月16日举办UEC世界围棋锦标赛，腾讯团队参加。据说日本在围棋界很厉害，但这次输给了腾讯团队。

除去李昌镐（Leela）是围棋AI，阿尔法狗也是。UEC和谷歌（Google）和微软（Microsoft）也都有。阿尔法狗是免费的。

在所有对围棋有影响的AI中，阿尔法狗是最强的。阿尔法狗是谷歌开发的，它使用了深度学习和蒙特卡洛搜索。它的胜率是50.56%，击败了所有人类棋手。
