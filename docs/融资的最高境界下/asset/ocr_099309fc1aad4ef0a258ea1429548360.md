# 短期出口信用保险融资方案(落地)

一诺老师发现，短期出口信用保险主要针对的是信用期限在一年以内的出口收汇风险。当你在采用信用证、付款交单、承兑交单、除销等结算方式，产品出口或转口到国外时，就可以通过这种信用保险方式，来承保商业风险和政治风险。
