# 中小企业科技局融资方案(落地)

(1)具有独立企业法人资格。

(2)主要从事高新技术产品研究、开发、生产、服务。

(3)具有较强的市场开拓能力、较高的经营管理水平。

(4)员工人数在 500 人以下，大专以上学历占员工总数比例在 30%以上，直接从事研究开发的科技人员占员工总数比例在 10%以上。

(5)经营业绩良好，资产负债率不超过 70%，用于高新技术产品研究开发经费不低于销售额的 5%（新办企业不受此限）。

(6)具有健全的财务机构和合格的财务人员。
