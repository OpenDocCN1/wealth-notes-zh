# 大学生创业融资实操步骤(落地)

+   (1)大学毕业证、失业证书、营业执照、税务登记证、房屋产权证或担保合同，到户籍地社会保障所办理申请。

合伙经营的小企业，则由企业法人代表到户口所在地或经营场所所在的街道人力资源和社会保障所办理审核。

+   (2)到区级人力资源和社会保障局办理审批手续。

+   (3)到银行去办理相关贷款。若你是在校大学生，自主创业不但可以申请大学生创业小额贷款，还可以在 2 年内保留学籍。

![](bbox=[0.12, 0.47, 0.88, 0.59])

一诺老师说，申请大学生创业小额贷款时，按政策规定要有担保人，并且担保人还必须是政府机关、事业单位在编在职人员，月收入在 3500 元以上。每人的担保额度不能超过年收入的 2 倍，最高不超过 20 万元。

一诺老师认为，如果是大学生合伙创业的徽利项目，申请贷款时需要固定的经营场所和一定的自有资金，需要用本市 300 元融资 500 万,签订《零风险+对赌》协议，实操请联系一诺老师助理
