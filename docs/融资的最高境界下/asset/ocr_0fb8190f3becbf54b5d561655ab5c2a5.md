# 分期付款融资实操方案(干货)

分期付款融资和预收货款融资正好相反，对购销双方来说都能起到融资效果。由于买方征得卖方同意，把本来应该钱货两清的交易改成了分期付款，延后了付款时间，实际上就是把这部分延期付出的资金留在了自己手里，起到了融资效果。
