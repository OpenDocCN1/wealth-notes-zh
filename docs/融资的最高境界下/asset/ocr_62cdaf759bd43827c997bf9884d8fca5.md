# 补偿融资的实操重点(干货)

# (1)补偿贸易偿还期

这是衡量补偿贸易经济项目的一个重要指标，简称可偿还 期。通俗地说就是，将来你的产品投产后，每年的外汇收入在 扣除成本和其他费用后，可以支付多长时间的设备和技术 贷款。可偿还期越短，表明偿付能力越强，经济效益越高。

如果偿还期超过进口设备的使用年限，就表明这个项目的 经济效益不佳，就要考虑是否放弃这种融资方式了。
