一诺老师认为，如果这个壳资源以后要在股市上重新上市，需要花费太多的精力重新向当地证券交易管理部门登记、申报，这样，原来买壳上市的优势就可能会变得荡然无存。

买壳上市时双方都还会委派律师和会计师事务所进行审慎性调查，一诺老师说，这时候你应该向对方索取法律证明书，证明这家壳公司是可以正常交易和增发股票的，以绝后患。

# 三是壳公司的价格要合理

壳公司按价格从高到低可以分为以下四种类型：

+   (1)定期向证监委提出申报，并且至少有一个做市商在买卖该股票。你在收购这种公司后，3个月左右就能顺利上市交易。

+   (2)定期向证监委提出申报，但没有做市商买卖股票。你在收购这种公司后，一般4-6个月能顺利上市交易。

+   (3)没有向证监会提出申报，可是有做市商在买卖股票。收购这种公司后，一般需要6个月才能顺利上市交易。
