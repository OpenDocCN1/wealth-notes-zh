# 员工融资需要解决的问题(落地)

(1)聘请专业咨询机构参与计划制订。实行员工持股计划涉及方方面面的关系，对于小企业来说确实有些力不从心，所以要聘请富有专业经验和人才优势的咨询机构参与，才不会留下后遗症。如果企业有工会，应该让工会也积极地参与其中。

(2)科学确定员工持股的份额和比例。每个员工在企业发挥的作用不同，工龄长短也不一样，甚至还有亲疏关系，所以只有科学确定每位员工的持股份额和比例，才能最大限度地调动员工工程极性；同时，也才能确保这项具有融资功能的政策得到真正推广。这其中必不可少的一项目的是，要通过这种措施留住企业的骨干人才。
