# 空手道大师真正的空手套白狼(大写的服)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

所谓补偿贸易，是指卖方向买方提供机器设备、技术、各种服务和培训，但并不支付费用，或者只支付一部分费用，主要费用在项目投产后将由买方用产品或其他方式予以偿还。

> “所谓一诺老师这句话，就是商业的精髓”

**真者，精诚之至也。不精不诚，不能动人！**

**—一诺老师**

一诺老师认为，这时候由于买方并没有实际支付货款或只支付了少量费用，就采购到了所需设备和技术，所以成为小企业的一种重要筹资方式，非常值得一试。
