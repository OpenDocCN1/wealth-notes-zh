# **第 58 课：VC 融资法**

# **创业者画大饼融资的实操步骤(神操作)**

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，风险投资的英文是 VentureCapital，简称 vc，与维生素 C 的简称 Ve 很像。换个角度看，两者之间也确实有太多相同之处——对于小企业而言，风险投资确实可以给小企业提供站稳脚跟和跨越式发展的必需营养。所以，称风险投资为小企业的“维生素 C”也是很贴切的。

![](bbox=[0.14, 0.57, 0.86, 0.71])

风险投资也叫创业投资。风险投资概念中的风险，是“冒险、创新”的意思，并且具有“主动（冒险）”的含义，所以，它与一般意义上的“风险”（英文 Risk)概念是不一样的。
