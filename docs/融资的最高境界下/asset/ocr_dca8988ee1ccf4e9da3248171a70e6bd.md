# ### 本节课程干货提炼

+   1. 通过创业板市场融资的企业，主要是中小型高科技企业，所以也有人把创业板称为“高科技板”。这类企业普遍规模小，市场发展前景不明，赢利能力不稳定。但是因为其高科技概念特点，能够给投资者带来无限的想象空间。这样的企业去银行贷款是贷不到的，可是通过创业板上市融资就比较合适
