# ## 小企业包买融资的五大步骤(实用)

(1)在洽谈出口贸易时，就要与你所在地的中国银行进行沟通，了解具体办理手续，签订正式的福费廷业务协议。

(2)在签订出口贸易合同时，要明确表示使用福费廷业务，由买方提供担保。

(3)卖方在发运货物后，就把全套货运单据通过银行正常渠道寄给买方。

(4)买方把经过银行承兑的附有银行担保的汇票寄给卖方。

(5)卖方按照事先的约定，把汇票出售给卖方银行，办理贴现手续。

一诺老师发现，包买票据与票据贴现非常相似，可是它和一般的票据贴现还是不同的。

一般的票据贴现如果票据到期遭到拒付，银行可以行使追索权，要求汇票的出票人付款；而包买票据是没有这种追索权
