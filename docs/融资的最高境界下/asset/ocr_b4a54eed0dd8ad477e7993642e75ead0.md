# 可转换债券融资的基本条件(实用)

+   (1)企业最近三年内的加权平均净资产利润率要达到 10%; 能源、原材料、基础设施类企业可以略低，但也不能低于 7%。

+   (2)在发行可转换债券后，企业的资产负债率不能超过 70%。

+   (3)如果你是上市公司，发行可转换债券前的累计债券余额不能超过公司净资产 40%;本次可转换债券发行后，累计债券余额不能超过公司净资产的 80%。

+   (4)可转换债券利率不能超过银行同期存款利率水平，发行额不低于 1 亿元人民币，债券期限为 3 年以上、5 年以内，债券发行 6 个月后才能转为公司股权。
