# 非上市公司增资扩股融资操作过程(落地)

确定筹资数量和形式

增资扩股筹集资金的数量，应当由各出资方协商决定。如果你的企业中有国有股份，还必须经国有资产管理 部门或其授权部门同意。增资扩股筹集资金的形式，包括现金、厂房、机器设备、材料物资、无形资产等多种多样。其中最重 要的是现金投资，因为只有你有了现金，才能对外采购所需物品和支付费用，灵活方便。如果是实物、工业产权、场 地使用权等非现金投资，首先要确保是企业所需，然后才是作价合理。
