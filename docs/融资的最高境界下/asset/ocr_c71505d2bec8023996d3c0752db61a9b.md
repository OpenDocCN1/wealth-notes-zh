# 出口押汇融资前提条件(干货)

一诺老师认为的顾问经验摘告告诉我们：

一是预期在发货后、收到货款前资金周转会发生困难，需要短期融资；

二是在发货后、收到货款前虽然资金周转正常，甚至很充裕，但这时候遇到了新的投资机会，并且这种投资机会的预期收益率肯定会高于押汇利率，这时候通过出口押汇融资就是有利可图的；

三是预期汇率升值，并且你可以从这种汇率升值中获得比出口押汇融资成本更高的收益率。
