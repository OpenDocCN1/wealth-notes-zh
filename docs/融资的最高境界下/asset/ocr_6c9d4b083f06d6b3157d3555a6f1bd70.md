# ## 服装厂融资实操案例(实战)

一诺老师弟子黄老板，开了服装厂，妻子开了一家服装店，两家企业都是独立核算的，夫妻俩赚的钱各归各。服装厂因为要急于采购一批原材料，所以资金发生困难，需要融资 300 万元。这时候黄老板就想到，赶快把服装店要的货提前发过去。

就这样，服装店收到了服装厂的这 300 万元货物后，补签了一份购销合同，同时向银行申请开具承兑汇票。银行考察了服装店具体业务的合法性和真实性，在收取了服装店的汇票保证金和手续费后，给服装店开出了一张 300 万元的承兑汇票。
