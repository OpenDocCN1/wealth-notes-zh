# 第 55 课：并购融资法

并购或被并购都能融资的实操方案(包赢)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱？

跟一诺老师学习《融资的最高境界》！

一诺老师研究发现，跨国并购的实质是产权交易。但由于这种产权交易是跨国界的，更由于两国政治、经济、文化背景大相径庭，所以注定这种跨国并购融资和国内的产权交易融资有根本性不同，只能作为两种融资方式来讨论。

![](bbox=[0.13, 0.51, 0.86, 0.65])

从概念上看，跨国并购包括跨国兼并和跨国收购两种。
