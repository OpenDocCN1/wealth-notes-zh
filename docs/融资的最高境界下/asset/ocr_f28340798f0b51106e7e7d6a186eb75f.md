# # 押汇融资应具备的条件(实用)

一诺老师的经验告诉我们，在该银行要有人民币和外币往来账户，并且在该押汇融资业务下办理一切核算；信用证条款清晰、完整，符合国际惯例，经银行确认没有潜在风险。

你在向银行提出出口押汇申请书时，需要提供以下材料：企业法人营业执照复印件、企业授权书及签字样本、近期财务报表等。然后，填写出口押汇申请书和出口押汇质押书各一式两份，连同出口单据和正本信用证一起交给银行审核。最后，经银行审核无误后，即可办理出口押汇。

如果出现以下情形之一，

你的出口押汇申请将会遭到银行拒绝：

+   - 来证限制其他银行议付；
- 远期信用证超过 180 天；
- 运输单据是非物权凭证；
