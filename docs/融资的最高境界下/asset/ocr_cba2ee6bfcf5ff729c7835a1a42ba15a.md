# 本门课程干货提炼

(1)信用证的“信用“涉及商业信用和银行信用两方面。不用 说，银行信用总是高于商业信用的。所以，当你不了解对方 的商业信用或质疑这种商业信用时，就可以通过信用证制度， 把商业信用上升为银行信用，这样就能很好地解决这个问题， 顺利达成交易。

(2)信用证是一种有条件的付款承诺。也就是说，受益人只 有在按照信用证规定的要求提供相应单据后才能收到款项，并 不是说你拿到信用证马上就可以无条件收到货款了。如果你提 供的单证不符，对方有权拒付。
