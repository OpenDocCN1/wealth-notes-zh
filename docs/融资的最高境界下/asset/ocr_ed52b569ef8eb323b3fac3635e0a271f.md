# 二是选择项目包装融资资金

项目包装融资的资金从哪里来，这是这个环节要考虑的。

一诺老师认为，要解决这个建设项目中股本资金、准股本资金（优先股股票和可转换债券）、债务资金各占多少比重，以及各自的来源和形式。

为此，主要是要匡算出这个项目的资金需求总量、债务资金和股本资金比例、资金的合理结构、资本成本和构成等问题。
