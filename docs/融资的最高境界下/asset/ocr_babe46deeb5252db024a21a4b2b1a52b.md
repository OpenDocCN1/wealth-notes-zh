# 卖方融资实操方案(落地)

卖方信贷是指卖方从银行取得出口信贷，然后再向买方提供延期付款信贷。作为出口企业的你，为什么要自己办理贷款，然后同意买方用延期付款方式来达成交易，即期付款不是更好吗？不用说，能够即期付款当然是最好的；可是在买方资金困难的情况下，你作为卖方为对方创造了一种便利条件，更能促使交易的达成。也就是说，更有助于推动出口。

![](bbox=[0.14, 0.42, 0.85, 0.56])

必须指出的是，这种通过卖方信贷给买方提供延缓付款的条件，体现的是一种银行信用，与卖方直接答应买方可以延缓付款的商业信用是完全不同的，否则这种出口信贷也就没有存在的价值了。
