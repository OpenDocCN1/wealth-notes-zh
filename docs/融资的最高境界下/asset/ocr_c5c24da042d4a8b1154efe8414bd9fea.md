# 本节课程干货提炼

(1)西方流行一种比喻说，有人把企业当做“老婆”，别人不能碰，股权百分之百必须是自己的；有人把企业当做“儿子”，别人也可以抱一抱，分一点股权；还有人把企业当做“猪”来养，养肥了就是为了卖钱的。不同的心态对控股股权的理解和把握不一样，从拙资角度看，企业应当是“猪”。

(2)许多小企业是家族企业，并且刚刚进入第二代，所以不想让外面的人插手。在这种情况下，就不一定适合用股权出让方式未融资。因为这会分散股权和管理权，与企业最初的发展战略和长期发展目标不符。
