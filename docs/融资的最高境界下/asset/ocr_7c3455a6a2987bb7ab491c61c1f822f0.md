# 第 67 课：国拓融资法

搞定中央财政资金的全攻略(跪在地上唱征服)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》!

一诺老师说，小企业要想把产品和服务推广到全球，就必须注重国际市场的开拓。而在这方面，政府有一项专门用于帮助拓展国际市场的专项资金，助你实现这种心愿。这就是中小企业国际市场开拓资金，由各级经贸部门（商务部门）负责。

![](bbox=[0.13, 0.52, 0.87, 0.66])

国际市场开拓资金，是中央财政专门用来支持中小企业开拓国际市场业务和活动，由政府预算基金和地方财政安排的专项资金，分为中央使用和地方使用两部分，中央直接使用的资金占全年计划的 30%，地方占 70%；同样实行中央和地方两级
