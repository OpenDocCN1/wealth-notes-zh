# 大学生创业融资的三大关键(干货)

+   (1)必须有固定住所或营业场所，否则就很难证明你在经营。
(2)要有营业执照或经营许可证，并已启动。
(3)一定要有一个品利前景行好的项目，所投项目具备一定的自有资金，具有还本付息能力（这是最重要的，因为归根到底所有贷款毅终都是衙要还本付息的，银行极看重这一点了）。
