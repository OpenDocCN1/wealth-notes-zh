# 投资保险融资方案(落地)

投资保险解决的主要是政治风险。也就是说，当你 在国外的投资和已经赚取的收益，如果因为所在国政治风险而遭受损失，你可以从保险公司获得相应赔偿。不用说，这也是政府鼓励你对外投资的一项支持。

投资保险的内容具体包括：

汇兑限制，即所在国限制把当地的货币汇兑给你，或者以高于市场汇率的价格汇兑给你；征收，即所在国通过国有化、没收、征用等法律手段影响到了你的权利；战争及政治暴乱；政府违约；承租人违约；等等。当出现上述情形时，你将会得到合理的赔偿。
