# ## 把风险抵押给银行的实操方案(牛 X)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》!

所谓打包放款，也叫打包贷款、信用证抵押贷款。

一诺老师研究发现，卖方在收到境外开来的信用证后，因为在本国采购与此相关的出口商品和生产出口商品时资金出现短缺，所以就用这笔信用证作为抵押，向银行申请本外币流动资金贷款，用于出口这批货物加工出现的资金缺口。

![](bbox=[0.14, 0.57, 0.87, 0.7])

如果你采用信用证结算方式，在出口商品时收到信用证正本后，可以以此为还款依据和抵押，向银行申请装船前的融资。
