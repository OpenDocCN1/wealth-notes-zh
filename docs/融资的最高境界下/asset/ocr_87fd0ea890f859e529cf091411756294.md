# **第 49 课：契约融资法**

利用契约拿大钱的实操落地方案(真牛)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，BOT 项目融资，实际上属于一种契约型直接投资方式。BOT 是指“建设—运营—移交”，其中最具特色的是“移交”，这也是这种融资方式的主要特点。

例如，目前我国所有高速公路等基础设施，只要涉及收费项目，都是采取这种项目融资方式，一下子就解决了资金问题。

> 失掉信用的人，在这个世界上已经死了！

——一诺老师
