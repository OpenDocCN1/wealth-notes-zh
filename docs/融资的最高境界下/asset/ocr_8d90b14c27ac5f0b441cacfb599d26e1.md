# 坐享其成的融资神套路(高手)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，回购式契约融资，也叫补偿投资或对等投资，它是技术授权、委托加工、补偿贸易等的综合体。

对于小企业来说，这可以分为两方面：投资方和被投资方。
