# 第42课：包买融资法

贸易公司长期空手道融资的完整攻略(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，包买票据俗称“福费廷(Forfaiting)，来源于法语"aforfait"的音译，意思是“放弃权利”。

用在银行融资业务中，是指包买商（通常是卖方所在地银行）从卖方那里无追索地购买已经承兑的，并且通常由买方所在地银行担保过的远期汇票或本票。

![](bbox=[0.14, 0.57, 0.86, 0.71])

一诺老师发现，卖方在向买方提供商品和劳务服务后，就把收取货款的一切权利、风险、责任全部“卖给”包买商，并且在相关票据上加注“无追索权”字样，表示自己愿意无条件
