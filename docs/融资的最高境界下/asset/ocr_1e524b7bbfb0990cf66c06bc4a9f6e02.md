经济上一定是有利可图的。这实际上也就意味着你从这种企业并购中，已经降低了企业运作成本，创造了未来赢利预期，买到了一只“会下蛋的鸡”。

# (4)其他优势

这主要指其他看不见的好处，如有效降低进入一国、一个行业的门槛，获得这个国家、这个领域科学技术上的竞争优势，大幅度降低企业运营风险和成本，提高本企业的知名度和国际影响力等。

# 本节课程干货提炼

+   (1)无论是你对别国企业出售资产或股权，还是收购别国企业的资产或股权，都能起到融资作用。

在这个过程中，由于两国国情迥然不同，对股权和资产的价值判断标准不一，常常会捡到大便宜，非常有助于国际扩张。

+   (2)跨国并购融资的一大缺点是容易受别国反垄断法阻挠。
