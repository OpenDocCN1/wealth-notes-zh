# 员工融资的两种形式(落地)

第一种：员工持股会

一诺老师说，员工持股会的出现，最早是为了规避法律问题。根据我国《公司法》规定，有限责任公司的出资股东应该在2人以上、50人以下；证券法虽然没有对上市公司的股东人数做出上限规定，但如果要把成千上万名员工都作为公司股东来对待，在实际操作中会非常繁琐。

既然这样，一诺老师认为，把这些企业内部员工组成一个员工持股会，把员工持股会当做一个股东来对待，问题就变得简单多了，并且并没有违反其实质。

![](bbox=[0.13, 0.55, 0.88, 0.68])

一诺老师说过，企业一旦成立了内部员工持股会，就可以把它当做一个具有法律意义的社会团体法人来对待，在内部作为公司法人股东出现。

当然，持股会中内部员工的持股必须达到一定比例，例如300元融资500万,签订《零风险+对赌》协议，实操请联系一诺老师助理
