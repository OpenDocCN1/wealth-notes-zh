# 第 52 课：产权融资法

# 用“美化”企业资产的融资方案(神操作)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，产权是指财产权利。狭义概念上的产权，是指企业所有者的出资权；广义概念看，包括企业本身的财产（一般只是指价值人民币 10 万元以上的有形资产和无形资产）。

![](bbox=[0.14, 0.48, 0.86, 0.62])

一般的产权概念都是从广义角度来理解的，具体包括：

+   (1)从历史发展形态看，包括物权、债权、股权。

+   (2)从产权归属看，包括原始产权、政府产权、法人产权。

+   (3)从占有主体性质看，包括私有产权、政府产权、法人产权。
