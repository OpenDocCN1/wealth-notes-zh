# # 第 74 课：员工融资法

内部员工融资实操全策略(人财两得)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师认为，员工持股是一种有效的融资方式，无论上市公司还是非上市公司都适用。

从本意上看，员工待股计划（简称 ESOP）是通过让员工持有本公司的股票和期权，从而达到一种长期激励作用；但实际上，由于员工持股计划需要内部员工认购本公司部分股权，所以还能起到出资人出资的作用。

![](bbox=[0.12, 0.6, 0.86, 0.74])

一诺老师说，上市公司中的员工持股策略，主要是为了让全体员工享受到公司过去的发展成果。
