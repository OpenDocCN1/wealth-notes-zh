# 如何跟国拓资金主管部门打交道(实用)

一诺老师发现，在各级地方政府，同样也由商务局和财政局委托当地中小企业办公室，负责受理项目资金计划申请、项目实施申请、项目资金拨付申请，并且进行初审；根据项目资金计划申请情况，拟订年度项目资金计划安排；协助商务部门和财政部门对资金使用情况、效果进行跟踪和检查。

![](bbox=[0.14, 0.39, 0.86, 0.52])

从资助金额看，原则上不能超过所需项目金额的 50%，如果是中西部和老工业基地的小企业，比例可以提高到 70%。从资助方式看，有无偿支持和风险支持两种。

无偿支持容易理解，是指无论你是否取得成效，拨给你就是你的了；

一诺老师认为，风险支持则是指承担你开拓国际市场的部分风险，也就是说，如果你的开拓市场没有取得预期成效，就可以享受这种风险支持，如果取得了成效，就不能再享受国际
