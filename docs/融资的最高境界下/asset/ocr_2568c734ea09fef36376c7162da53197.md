+   (4)从客体流动方式看，包括固定资产、流动资产。

+   (5)从客体形态角度看，包括有形资产、无形资产。

+   (6)从具体实现形态看，包括所有权、占有权、处置权。

在上述基础上来理解产权交易融资，容易看到，所谓产权交易融资就是小企业通过出让部分或全部产权，来获取收益和资金。通俗地说，就是把你（出资人）的个人产权和企业产权作为交易对象从而变成现金。在这个过程中，当然会优化股权结构，有利于资源配置并提高资源使用效率了。
