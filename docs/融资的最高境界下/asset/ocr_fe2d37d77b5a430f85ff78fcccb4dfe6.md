# (2)补偿收益率

是指你在用进口设备和技术投产，每年挣得的外汇净收入在偿付了设备贷款和利息后，还有多少可以作为公司净收入，以及这部分净收入在整个公司净收入中占多大比爪。国际惯例认为，只有当补偿贸易的外资收益率商千 60%时才是可行的。

# (3)补偿贸易利润率

这是指这个补偿贸易项目最终能获得多少赢利额及共利润率。具体计算方法是，用补偿贸易的总收入减去总支出除以总支出。其中涉及的外汇牌价，都要统一折算成人民币来计算。
