# 第 65 课：天使融资法

# 创业初期如何找到自动资金(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

中小企业技术创新基金与本书前面风险投资中提到的“天使投资”概念有某些共通之处。

![](bbox=[0.13, 0.44, 0.88, 0.58])

一诺老师研究发现，所谓“天使投资”，是指一些自由投资者或非正式风险投资机构，对处于构思阶段的原创项目或初创企业进行的一次性前期投资。天使投资虽然也属于风险投资，可是它的资金主要来源于民间资本，投资门槛较低。他们只要觉得你这个项目有发展前途，就可能会愿意投入；可是这种状态下的企业对正规风险投资来说，可能就根本不感兴趣。
