# 第45课：专用融资法

# 申请国际最低利率贷款的方案(实操)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，出口信贷就是这种贷款的用途是指定的，只能用来购买贷款国出口的资本货物和技术以及相关劳务，属于一种“专款专用”。

![](bbox=[0.15, 0.49, 0.88, 0.62])

一诺老师研究发现，出口信贷具有以下特点：利率低，一般低于国际金融市场上的平均贷款利率；贷款期长，一般为 1"5 年，也有的会长达 10 年（但通常都是每半年还本付息一次）；贷款金额起点高，我国规定的起点是 5 万美元，国外的贷款金额起点有的甚至高达数百万美元。
