# 第 38 课：票据融资法

用"借条"向第三方借到大把银子(落地)

兵马未动，粮草先行！当今，大多数企业都死于资金链的断裂！如何融到永远也花不完的钱呢？

跟一诺老师学习《融资的最高境界》！

一诺老师说，所谓商业承兑汇票，是指买方需要购进商品却又缺乏资金，卖方又不肯欠账，所以这时候会考虑与卖方进行协商，由买方或卖方开出的一种表明债权债务关系的票据。

![](bbox=[0.13, 0.48, 0.82, 0.62])

商业承兑汇票居于正式收付款凭证，由买方负责承兑，期限从贴现之日起至汇票到期日止，一般不能超过 6 个月。

一诺老师认为，所谓承兑，就是在这张商业承兑汇票到期时，买方必须无条件按照票面上的金额支付给收款人。这样做，由于延缓了买方的付款时间，实际上就起到了融资效果。
