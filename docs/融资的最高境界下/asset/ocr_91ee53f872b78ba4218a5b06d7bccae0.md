中，卖方银行会要求卖方按质按量提供出口产品，而对买方信贷方面的财务安排，也必定会掌握在自己（卖方银行）手里。

一诺老师说，卖方银行是不会把贷款直接付给买方的，而是会在买方收到货后，根据单据，代表卖方付给卖方；但贷款的归还，是需要买方按期偿还的。

# 买方融资的量大实操方案(落地)

+   (1)卖方银行直接向买方所在地银行提供贷款。具体步骤是：

+   @ 双方签订进出口贸易合同后，买方预付 15%-20%的预付现汇定金。

+   @ 双方银行以进出口贸易合同为依据签订贷款合同，卖方银行提供贷款。

+   @ 卖方发货。

+   @ 买方银行把借到的贷款贷给买方。
