# 完全独立控制

你需要对你正在销售的产品拥有完全的控制权。这意味着你不能购买那些广泛地出售给任何人的产品，你的产品必须是
你能够独立掌控的。

换句话说，如果你的产品顾客可以从任何别的渠道得到，他为什么要从你的手里买？也就是说，你要从源头上掌控产品。

这是否听起来很不现实？需要巨额投资吗？一点也不需要，线下课上将向你展示如何在几乎没有任何投入的基础上，完全拥有独家经营的产品。
