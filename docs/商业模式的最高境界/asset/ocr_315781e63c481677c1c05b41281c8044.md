# 什么是产品的另类玩法？

卖沙发的可以发动一次征集创意活动，对老客户说“只要你能将沙发的其他用途创意出来，并发送照片给我们，就可以获得一份奖励”，从而收集到各种新的玩法。

比如，沙发当床睡觉、沙发当健身器材、做瑜伽垫、老公不听话惩罚睡沙发等，如果把这些娱乐的场景收录到本手册，并通过各个渠道发布，目标客户浏览之后，会对你的产品产生一种莫名其妙的情感，这也是隐形的顾客见证（属于情感式见证，后续会有专门的章节讲解）。

再比如，龙虾店可以发起“10 分钟小龙虾剥壳挑战”，随时可以来挑战冠军的记录，把每次挑战都拍摄下来，做成视频或手册，并配上吃虾快速剥壳秘诀，鼓励大家都来挑战最高记录，这样的教材在当地传播是非常迅速的。

创新的另类玩法主题，可以向顾客征集，除了能够增加感情，还可以形成非常强大的病毒传播效应。
