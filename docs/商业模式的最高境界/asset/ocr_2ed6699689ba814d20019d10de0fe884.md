# 第三块成本：运营成本

我这里说的运营成本，主要指产品线冗长，大而全，缺乏主线，这也推那也推，就导致你没有重点。

你一定要集中一个爆款作为前端的切入产品，不求大而全，也就是现在所有的店都是一两个主营的产品然后配合一个系列就那么三四款产品在做，而且主打一款，其他的都是配合的，这样就能够集中一个点去切入。

这样一来，你的产品研发人员、运输人员、仓储人员、营销人员都能聚焦火力，避免不必要的浪费，从而降低你的运营成本。

# 第四块成本:沟通成本

你可以搭建一个沟通平台，不管是微信平台，或者是邮件平台等等，你可以给客户一些奖励，让客户把问题、意见和建议在平台上提出来，从而更好的改良你的系统流程，从而降低沟通成本。
