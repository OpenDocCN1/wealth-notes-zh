# 第01节 最佳利益

我们要思考，在做顶层设计的时候需要哪些人参与。我们要满足每个参与方的最佳利益。

每个人不是被你领导，是被自己的价值观领导，员工不是在成就你的梦想，是在成就自己的梦想。他发现在你的平台上能成就自己的梦想，顺带替你做点事。

每个人都会选择最符合自己的最佳利益的行为。

员工为什么会流失呢？觉得跟你混没前途。客户为什么会被人挖墙角？别人家好处比你多了。经销商为什么会去卖别人的货？因为卖别人的更挣钱了。银行为什么不给你投钱了？他发现投到别人那里赚钱更多。钱喜欢往更大的地方去。为什么厂商第二年不给你供货了？他发现产品交给别人销量更高了。

你要反复问自己: 今天我的顶层设计是否满足了每一个参与方最佳的利益了？

所有的商业模式里都有创造价值的过程，今天这个时代，我们发现传递价值的方式发生了很大的变化，可是创造价值的人真正的开心了吗？
