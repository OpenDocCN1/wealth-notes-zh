# 什么是粉丝？

粉丝就是能够为你的梦想买单的人。

请问有多少人为你的梦想买单？

假如你也有一大群粉丝，你觉得你的产品好不好卖？

只要你有粉丝，就算你不卖产品，比如有很多网红，只要他粉丝够多，单接广告和收礼物都能让他月入百万，你相信吗？

请看下面的表格：

| 粉丝数量 | 成交量\n(假定成交率20%) |  | 单笔利润 |  | 收入 |
|---|---|---|---|---|---|
| 10 | 2 | x | 500 | = | 1,000 |
| 100 | 20 | x | 500 | = | 10,000 |
| 1000 | 200 | x | 500 | = | 100,000 |
| 10000 | 2000 | x | 500 | = | 1,000,000 |

你就会发现：

你的收入 = 粉丝 x 成交率 x 利润
