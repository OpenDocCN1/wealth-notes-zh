为不断前行。

# 三、淡泊名利

在当今这个物欲很重的名利场中，任正非在华为的股份很少，却让员工大量持股，这在业内是很少见的。特别是他深居简出，个人出行，一个人拉着行李箱去排队坐车，没有一个助手，没有一个保镖。能放下自己拿起华为是相当难能可贵。

# 四、远大抱负

1994 年，任正非在员工内部讲话说到：十年后，全球通信行业三分天下，华为占其一。如今我们知道，华为确实做到了，它让世人都惊叹其发展速度。

# 五、专注

说起华为的成功，正是因为华为坚定不移 28 年只对准通信领域这个“城墙口”冲锋。华为成长起来后，坚持只做一件事，在一个方面做大。

# 六、开放

“师夷长技以制夷”。任正非的华为从一开始创建就呈全开放的心态。在与西方公司的竞争中，华为学会了竞争，学会了技术与管理的进步。
