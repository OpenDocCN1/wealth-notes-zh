# 第01节 鸟瞰生态圈

未来企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争。

现在市场估值的时候，如果你是做产品的，估值也就几十亿；做平台的，估值百亿；做生态圈的，估值能到几千亿。

今天的 BAT 基本都是做生态圈布局的。

习大大提出的一带一路，这也就是布局生态圈啊！

比如：中国政府投一百亿，但是要用我们中国指定的供应商，指定的材料，这样一来 80 亿就进入中国人自己的腰包了。

过一段时间，好的地段中国企业都会进来，投的钱要付利息，过一段时间升值了，可以转让股权，关键是政治影响力。

未来的竞争是联盟的竞争，未来的生存环境要看整个生态圈。

你的位置决定你的角度，角度决定你的观点，观点决定你的世界观，你的世界观决定你的世界。

一个员工，站在职业的角度看，就仅仅是一个员工；如果站在整个企业的角度来看，他可能就是一个很棒的当家人、CEO；
