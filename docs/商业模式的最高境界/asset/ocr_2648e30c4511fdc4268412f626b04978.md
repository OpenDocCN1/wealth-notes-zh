# 第07节 案例：国家的顶层设计

今年（2019年8月22日）将是邓小平同志诞辰115周年纪念日。作为我国社会主义改革开放和现代化建设的总设计师，他以胆识胸襟，推动国家民族的前行，将社会主义中国带到一个前所未有的境界。

可以说，没有他，中国的经济腾飞步伐至少要晚十几年，甚至几十年。今天，他的理想和14亿人的梦想，仍在路上。

回顾《邓小平文选》，他谆谆嘱附：“要坚持党的十一届三中全会以来的路线、方针、政策，关键是坚持‘一个中心、两个基本点’。不坚持社会主义，不改革开放，不发展经济，不改善人民生活，只能是死路一条。基本路线要管一百年，动摇不得。”

一百年不动摇啊，这是国家领导人对整个国家的顶层设计。这些话高瞻仰嘱，分量够重了，永远发人深省。

解放思想求实事求是。

他是解放思想的伟大旗手。
