# 第02节 会员战略

第二个战略叫做会员战略。

今后你的店里不存在顾客也不存在消费者，所有的都是会员，你都要锁定他在你这里消费。

不少人说搭平台才能赚大钱。过去你眼中的平台是什么呢？就像淘宝一样，像腾讯一样搭建一个平台，建一个商城把大家都聚集起来？其实这是一个误区！

所谓平台，就是你把所有的生意都不是看作产品和服务来经营，而是看成一个平台来经营。

平台的特征是什么？平台的特征就是有大量的会员基数，这就是平台的特性。有会员基数，有会员粘性，会员的基数够大，会员的粘度够高，就是一个平台。

然后你把这些会员导入自己的微信公众号或者是微博或者是网站，这就是一个非常大的圈子和平台。我所说的搭建一个平台，就是搭建一个高粘度的圈子。这个时候就形成了一个平台，然后你去利用平台经营。
