# 第01节 利他思维

我们翻开历史书，去深入了解古今中外的名人，但凡那些在历史上名垂千古的人都是心中无我的人。

当置身在那种历史大背景下，如果只是为了个人私欲，那一定不会做出那种个人牺牲。

在一诺老师课堂上，反复给大家提到很多个伟人例子，就是希望大家能够至始至终有一个利他的思维。

因此，本书开篇仍旧要给大家定下一个基调。
