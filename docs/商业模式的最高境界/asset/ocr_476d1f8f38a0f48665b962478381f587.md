# 第08节 打造抽奖券卡类引流产品

什么是抽奖券卡类引流产品？

有诱惑力的抽奖或代金券，都可以刺激人们的行动欲望，是商业模式顶层设计高手们常用的引流赠品形式。

对于抽奖来说，奖品越有诱惑力、中奖率越高、抽奖次数越多，越能促使人们参与。同时，价格透明的产品，运用代金券，也能够立刻促使人们行动，在实践过程中，将代金券和抽奖卡同时配合使用威力更大。
