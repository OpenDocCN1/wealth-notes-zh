# ➢ 第一步：目标客户

你需要先明确你的目标客户是谁，你需要研究他。

比如说，我让你去广州找个人。你会问：“找什么人？”

我说：“找一个女人。”

你会问：“找一个什么样的女人？”

我告诉你：“找一个长头发的女人，这个女人长发及腰，她穿一身红色风衣，戴着黑色的墨镜，而且每天晚上9点钟会准时出现在天河体育馆东门前。”

你看，我这样一描述，你是不是就很容易找到她了？

营销中，你最容易犯的一个错误就是，并没有清晰界定你的目标客户是谁。

如果你没有明确目标客户，那么你的营销人员就不知道去哪里可以找到他们，同时你的广告媒体无法精准选择，导致广告投放的严重浪费，等于把大把的现金扔进了臭水沟里。更重要的是，白白浪费了自己宝贵的精力，从而把大好的时间浪费在众多无用功上面。

正确的做法是：明确你的目标客户是谁。

弱水三千只取一瓢，城有所不攻。
