# 第10节 打造基础套装类引流产品

人们使用产品、服务的目的 是为了解决问题或实现梦想，

然而，问题的解决和梦想的实现并不能一步到位，必须经过一个发展过程或做好多个方面的配合。

所以在包装产品的时候分阶段进行策划，把第一阶段的产品或服务作为基础套装类引流产品，是超级具有杀伤力的策略！

接下来透过一系列的案例教会你如何运用！
