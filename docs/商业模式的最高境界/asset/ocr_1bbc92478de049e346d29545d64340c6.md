【框架+绝招】是我们打造攻心绝杀技时的常用公式。

“框架”指的是事物发展的路线，并将路线分割为几个节点，对每个节点进行命名及结果的描述。

比如，英语 3 步拿高分，这里的 “3 步” 框架：

第一步：听力快速提升训练，4 大听力技术，让你轻松识别所有的音节；

第二步：语法强化训练，6 套语法训练公式，让你轻松掌握 3 个学期的语法逻辑；

第三步：100%解题训练，4 种绝密的解题套路，让你轻松破解各种题型；

通过以上 3 个步骤，让你的英语考试轻松拿高分。要想实现每个步骤所预期的结果，就必须要有方法和策略，这些方法和策略，我们称之为 “绝招”。

还是用前面 “英语 3 步拿高分” 进行讲解，第一步中 “听力快速提升训练” 的 4 大技术，每一大技术都是绝招，为了吸引学员在有需求的时候优先报名你的课程，在打造资讯教育类引流产品时，只能把一部分绝招讲解透彻。
