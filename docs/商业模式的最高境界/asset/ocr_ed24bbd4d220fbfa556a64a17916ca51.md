# 第一招：属丝逆袭成长故事的 4 大撰写步骤

之前一位学员写了一本针对创业者通过网络赚钱的电子书，讲述了她从一个辛苦的化妆品业务员，如何成为策划专家的故事，在描述她的成长经历和经验时，目标客户很容易被带入情景中。因为她经历的很多的苦难正是他们现在状态，同时，她获得的成果也成了他们所追求的。
