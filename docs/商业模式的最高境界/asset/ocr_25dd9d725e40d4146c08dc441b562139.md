# 第03节 梦想引航

大多数人莫名其妙地出生，稀里糊涂地活着，不知所以然地死去，总有一个不完美自己和一个完美的梦想。

人这一辈子都在追求，一直在赶着去做，还需要再做点什么。众生无主，每个人几乎都是不自信的。我们不确定明天会发生什么，内心深处需要更明确的力量，我们渴望被带领，被指引。

佛教有一个梦想叫西方极乐世界,道教有一个梦想叫仙境，基督教也有梦想叫天堂，共产党叫共产主义社会，一诺老师的梦想是：“让人类更文明更进步，造就一大批威震全球的企业家队伍，帮助企业家打造更多的世界级品牌”。

很多人渴望过上富足的生活，为了赚钱，不得不去见一些不想见的人，做一些不愿意做的事情，说一些不想说的话。

各位，要真正去读懂他人的需求，他的出路是什么？
佛法在卖什么？生、老、病、死、爱、恨、离…
