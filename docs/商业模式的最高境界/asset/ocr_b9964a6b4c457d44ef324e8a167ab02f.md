# 第02节 垂直供应链整合

接下来，我们谈一下整个产业链的布局。

未来的大企业通过裂变成平台，小企业通过聚变成平台。合纵联手，要么被吞并，要么联合。产业集群生态圈布局有3个重点：垂直供应链整合、水平价值链整合、内部系统化整合。

你先把你最擅长的、最好的，把它做到极致。在你自己行业里实现转型或转行。第一点先找垂直的供应链，首先是端对端，去中间化。

未来没有代理商，没有分销商，没有中间商，这是整个商业进化的结果，传递价值方法会发生巨变。你已经看到，李宁店关了上千家，百盛开始关门了，杭州关了一半的铺。以更便捷的方式更低的成本传递价值，这是必然的。

我们能不能提前先布局，很多零售商代理商现在过得很好，可是明天呢？通过互联网物联网，万物互联，甚至未来的心联网，意识传感，沟通越来越透明。
