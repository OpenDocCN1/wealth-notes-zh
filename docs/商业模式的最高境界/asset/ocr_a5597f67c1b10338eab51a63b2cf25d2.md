# 第04节 口碑战略

接下来，我们讲的第四个战略叫做口碑战略。

全世界最好的营销就是口碑营销，一传十、十传百，百而千、千而万，乃至于无穷。

你要把口碑上升到战略的层面，在你们当地、你的行业、你的圈子里，你要有这个目标——我要流传多少的故事！这点一定要切记！

你的品牌、你的影响力不是靠自己吹出来的，是靠消费者的口碑所建立起来的，那至于如何建立口碑，那后面呢，我们的课程会有，例如一诺老师网络基础班傍大款九招当中所提及：傍名人、傍历史，制造口碑故事的出处。

当你的产品打造到极致，本身就会建立成为口碑。这里所说的口碑不是负面口碑，一定是正面口碑，有意识地去打造制定口碑计划。

为什么说叫做口碑计划？因为口碑它不是自然而然的发生，口碑一定是策划出来的，你要把它上升到战略的层面，把它当作你事业的一个方向。
