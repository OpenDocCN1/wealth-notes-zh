# 先易后难：

市场开发当中，总有一些容易的入口，同时也会通到一些难的入口，怎么办？

先找容易的入口，就像果农在果园里摘苹果一样，有青苹果，也有红苹果，那க்க先摘红苹果，青苹果先放到一边，等养红了再去摘。

# 先慢后快：
