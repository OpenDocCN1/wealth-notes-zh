# 第05节 资源战略

第五个战略叫做资源战略。

其实我们所有的一切都是通过资源的组合，我们的事业的成功都是资源的组合，那我们这里所说的资源就包括了什么？

它包括你的人才资源、人脉资源，包括你外界所借的影响力资源，包括你的资金资源，所以说我们 está 这一方面也要制定好自己的战略。

比如说：首先我们讲人才战略，你一定要有自己的十大元帅，也就是说，你也一定要培养自己的人才。这是一个战略方向。

你一定要清晰地知道，你要做成一件什么样的事情，做成这样一件事情，需要什么样的人才来匹配，这个非常关键。

比如专门做品牌管理的，做互动的人才，需要专门管市场策划的人才，需要专门策划整个事件的人才，需要专门做管理的人才，需要专门维护客户关系的人才，这些必须要规划得很清楚。
