# 第02节 打造资讯教育类引流产品

针对目标客户的痛苦和渴望，打造出相关的资讯教材或方案，并免费赠送或低价销售给他们，让他们通过资料，找到解决问题的思路、方法和路线，这就是资讯教育类引流产品所要达到的目的。

资讯教育类产品，在免费赠送或低价销售给目标客户后，不仅能够获得跟他们接触与互动的机会，它还是一种教育潜在客户非常有效的手段，在他们还没有购买产品之前，已经认定了你的专家地位。

# 案例：疯狂引流DM广告经营者的电子书

我有一位朋友，曾在 2010 年撰写了一本专门针对创业者通过互联网赚钱的 PDF 电子书，这是一本典型的资讯教育类引流产品。书中除了网络赚钱的各种实战秘诀，还把获取更多秘诀的 QQ 群号留在了书的末尾，然后，在他的 QQ 交流群，免费赠送这本电子书。
