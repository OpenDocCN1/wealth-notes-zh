# 2、在描述正确经验的时候需要有故事情节

比如，在展示汽车保养的第一种错误做法时，你可以说

“其实我们以前也犯了样的错误，但后来发觉越来越不对劲，直到查阅了很多的资料，并到北京拜访了一些专家后才发现，原来以前很多的保养方法是错误的…”

知道吗, 这样描述你所说的东西将更加具备公信力，他们会从你的钻研与付出中产生强烈的信赖感, 这就是描述故事情节的重要性。

# 3、一定要配合强有力的证明，包括客户见证和数据展示

还是拿汽车保养来说，在指南中，你可以这样展示:

“这是张先生开了三年的爱车, 维修保养的过程中, 陷入 5 个误区中的第 3 个, 现在我来给你展示一下他的车出现了什么问题(配上图片), 通过我们现在保养后的细节是这样的(配上图片)……”

“王女士是某单位的干部, 她驾驶 4 年的爱车, 因为在维修保养时, 走入了第二个误区导致整体性能下降 27%, 下面为你展示出具体细节(配上图片), 通过我们正确保养之后效果如下(配上图片), 下面是具体的参数……”
