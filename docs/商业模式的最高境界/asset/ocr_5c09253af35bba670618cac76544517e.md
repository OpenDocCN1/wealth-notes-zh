# 第03节 商业模式的4个组成要素

商业模式由四个密切相关的要素构成，这四个要素相互作用时能够创造价值并传递价值，目前来说最重要的是创造价值。

# 客户价值主张（Customer Value Proposition, CVP）

凡是成功的公司都能够找到某种为客户创造价值的方法，即帮助客户完成某项重要工作的方法。

在此，“工作”的含义是旨在特定情境下需要解决的一个根本性问题。只要了解了工作的含义以及工作的各个维度（包括如何完成工作的整个过程），我们就可以为客户设计解决方案了。

客户工作的重要性越高，客户对现有方案的满意度越低，你的解决方案比其他可选方案越好（也包括价格越低），你的客户价值主张就越是卓越。
