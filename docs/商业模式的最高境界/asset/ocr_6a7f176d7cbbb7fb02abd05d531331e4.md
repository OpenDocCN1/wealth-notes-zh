# 第08节 顶层设计的核心

如果说商业模式是一套方法论体系，那么企业顶层设计就是实现“赢”的关键。

顶层设计应站在企业内外环境的角度思考企业经营。它包含企业家、方法论和核心团队三个支点。这其中最为关键的核心也就是企业家。

亚里士多德在《形而上学》中说：“一支军队的能率，部分决定于秩序，部分决定于将军，但主要决定于后者，因为将军并不依赖于秩序，而秩序却依赖于将军”

企业家经营企业的选择，决定了企业家的历史使命和重要性。

你们知道，现在中国哪家企业在全球范围内攻城略地，让美国都胆战心惊吗？

没错，是华为。它拥有全球最多的 5G 专利，它在国际的营收一直超过国内营收，它目标在 2020 年手机销售额超越三星成为全球第一。

华为是中国的骄傲，华为真正影响着世界。
