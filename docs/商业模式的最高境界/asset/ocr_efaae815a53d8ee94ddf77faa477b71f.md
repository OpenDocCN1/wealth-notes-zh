# 案例：高端女性消费类商家的联盟引流模式

高端美容店、化妆品店、服装店、箱包店、鞋店、咖啡店、美甲店等，整个链条的商家所需要的目标客户，几乎是同类人群，可惜的是，很多店并没有意识到联盟的威力，而是每家店各自每年投入大量的广告宣传，少则几万，多则十几万。
