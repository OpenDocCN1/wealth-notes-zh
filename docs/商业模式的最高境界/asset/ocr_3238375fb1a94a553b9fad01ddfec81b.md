# 第03节 利用客户终身价值设计引流方案

原理：以客户终身价值为出发点，依照锁定一个客户的终身价值为参照，计算出对应的买客户成本，从而选择和打造吸引目标客户进店的引流产品。

先了解下什么是客户终身价值。

通俗点讲就是：平均一个客户一生或一定周期内为你贡献的利润，我们称之为客户终身价值！

当然，在买客户思维中对客户终身价值的定义有所差别：锁定一个精准客户1年或终身给你创造的利润！

为了让你更透彻地理解利用客户终身价值买客户思路，还是通过实际案例进行讲解。
