# 成本战略到底会关乎哪些成本呢？

你会发现，在整个商业链条当中，从设计到加工，再到运输、仓储、代理、分销，最后到消费者手里，中间经历了很多个环节，几乎每个环节都会产生成本，都会发生费用，

而这些成本最终都算在消费者头上，有消费者买单，羊毛出在羊身上。

中间渠道商要赚钱，扣除他们的利润之后，还有零售门店的装潢，还有房租每年上升，这都是又一笔非常大的开支。而且零售商的门店租下来以后，还要宣传，才能打响自己的品牌，这样一来，在宣传的时候是不是又要大笔成本？没错。

光有宣传成本还不够，你还要有运营成本。通常很多店为了增加收入，不会只卖一样产品，而很多的产品系列将导致商家整个的运营成本变高，他不是单一的某一个产品切入市场，所以就导致这个也卖，那个也卖。

一个店好几个产品，几十个品类，这些也需要运营和管理成本的，而且你别忘了，你跟别人运营，也需要沟通成本的。

这样一来，你会发现商业链条变长，进而导致资金周转周期变长，现金流利用率变低。
