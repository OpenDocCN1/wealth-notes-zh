# 案例：化妆品店的客流倍增咨询录

老师：如果锁定1个精准顾客，1年时间，能够从他身上赚多少钱？

老师：如果吸引50个精准客户过来，通过你们的服务，有没有可能留住一个长期消费的？

王总：肯定不止，按照二八定律算，至少也得留住10个吧！

老师：如果是这样的话，你的生意就太好做了呀，我们来换算一下，锁定1个顾客消费1年，能够从他身上赚到5000元，现在花100元的成本吸引获得跟1个目标顾客接触的机会，进来50个留住1个就不赔钱，留住2个就赚了，按照你所说的留客比例，不做任何成交率的优化，瞎子碰鬼也能碰上几个呀！
