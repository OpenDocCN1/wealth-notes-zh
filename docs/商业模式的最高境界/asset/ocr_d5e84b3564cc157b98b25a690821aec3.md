# 秋，于无声处听惊雷。

智慧的人站高一线，他们能够趋利避害，先行而至，自可顺势而为，立于潮流之上，成为时代人物！

而那些醉生梦死的人，睡了一觉醒来，却发现变天了。打个盹睁开眼，发现碗里的被别人抢了，更过分的是连碗都被别人端走了。

因此，我奉劝各位老江湖：天气未报，风起云涌，行走江湖，英雄珍重啊！

今天的商业格局已经发生了巨大的变迁，刚才我们说过，新的中心在产生，旧的中心在消亡。
