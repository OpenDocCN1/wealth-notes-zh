# 第03节 时间战略

第三个战略叫做时间战略。这是重中之重。

过去以产品为中心的时代，我们讲的是空间战略，为什么呢？我们都是跑马圈地去圈各个地方，例如：国美苏宁大肆开店，百丽鞋业把各个高端商铺租下来，这些都是圈地。但是现在，你会发现高明的商家都在圈时间。

圈什么时间？圈消费者的时间。

各位，听懂这句话顿悟商业真谛：

> 未来商业竞争中的胜出者，是属于能够抓住更多用户时间的人！
—褚健辉

时间战略，什么意思呢？谁的产品、谁的圈子，能够让你的顾客，让你的会员关注的时间越长，你的价值就越高。

因为现在是一个注意力经济时代，当你能够有效的抓住消费者的注意力去关注你，能够愿意更长的时间跟你去沟通，更长的时间跟你去互动，他就愈加能够去了解你的产品，愈加能
