# 第03节 案例：果汁老板几张纸换来80亿

上世纪90年代，很多人都下海经商，我们的主人公（为了保护他的隐私，就叫他老李吧）在一家国营单位工作，端着个铁饭碗，可是，却厌倦了每天办公室里的一张报纸，一杯茶，混一天日子的工作状态！

总想着，如果就这样碌碌无为过完一生，老的时候连给孙子讲的故事都没有！

可是，如果辞职下海，自己又不会做游泳！

不会游泳想要下海游泳很危险知道吗？一不小心被淹死！

所以，他就寻思着学习啊，他从无数的书籍中总结出一个道理！
