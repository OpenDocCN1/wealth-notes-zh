# 故事一：

有一个武功高手，他找到一本武功秘籍《葵花宝典》，翻开第一页，看到上面写着：“欲练神功，挥刀自宫。”于是很兴奋又很纠结、他便拿出一把小刀，磨得非常锋利，想着男人就要对自己狠一些，于是就挥刀自宫，只听一声惨叫，英雄倒在血泊当中。

三天后英雄从血泊当中爬了起来，忍痛开始练功，当他翻开秘籍第二页的时候，看到上面写着：“无需自宫，也能练功！”这时英雄一声惨叫，又一次倒在血泊当中。这一次更痛，是心痛！

于是，又过了三天，英雄又一次从血泊当中爬了起来，他翻开秘籍的第三页，看到上面写着：“即便自宫，未必成功”。于是一声惨叫，再次倒在血泊当中，而这次，英雄再也没能醒过来。

英雄反应大快了，所以后果很严重。
