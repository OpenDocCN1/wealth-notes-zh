# 第01节 产品卖什么

任何企业安身立命之本，都是为用户提供价值，要么解决
问题，要么实现梦想。

听懂这句话顿悟商业真谛：

![](bbox=[0.14, 0.35, 0.85, 0.48])

请各位企业家仔细地思考：如何发现市场上用户的痛点和问题，如何理解用户梦想的生活方式是什么，如何以更具优势的方式为用户实现这一切？

你卖的不是产品，而是解决方案。

更进一步地说，你的产品永远要聚焦在用户真正想要的结果上，而且你要比竞争对手更具优势地满足这一点。

不管你用什么模式、平台、渠道营销，最终都要给用户输出价值，基于此，高价值的内容才是王道。
