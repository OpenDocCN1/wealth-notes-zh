# 第02节 吸粉七步走

移动互联网时代的到来，意味着人们进入了碎片化的时代，信息源和传播源在快速分化，受众也在快速分化，圈层效应明显，从前的单向传播变成了多点对多点的分散传播。

消费者在逐渐成熟，也在逐渐改变。这个时代他们不再是客户，而是“粉丝”。

本书的主题是商业模式顶层设计，这里不教你如何作自媒体营销。此类书籍在世面上也多如牛毛。当然，如果有机会你能学到一诺老师《营销的最高境界》，奇迹会在你身上出现。

为了能够通俗易懂地让大家理解，本小节将吸粉分解成7个具体的流程。按照下面7个步骤，每个企业、每个人都可以建立自己的粉丝。

# 吸粉七步法:

目标用户→生活场景→粉丝入口→合作方式→鱼饵诱惑→扫粉关注→完善名单
