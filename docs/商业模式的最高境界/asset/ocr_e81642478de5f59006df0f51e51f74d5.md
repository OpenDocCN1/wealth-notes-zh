# 前 言

本书作为内部学习教材曾于 2017 年第一次面向学员进行发售，此后学员好评如潮。

学员们的信任与支持是改变世界一直坚定地走下去的动力！

过去两年，我们也收到了很多学员们针对本书的宝贵建议特此再次对大家表示衷心地感谢。

为了能够给大家带去更好的体验，2019 年初我们决定对本书进行再版。

本书结合一诺老师本人亲身经历及策划的一系列商业模式、产品打造等，从心态、战略、战术三个方面对商业模式顶层设计进行解读,并对国内外众多知名企业的成功案例进行拆解和分析。

这些案例所包含的商业模式堪称经典创意之作，由此创造了无可限量的商业价值。

希望学员们通过对本书的学习，合理地运用此类商业模式，从中领悟其微妙之处，并运用到自己的企业中。
