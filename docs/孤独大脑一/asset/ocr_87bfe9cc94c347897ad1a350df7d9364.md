# 2、可复制性

生物、人、机构，其强大几乎都是基于某种可复制性，除了基本单元数量上的可复制性，还有“整体大于部分”的网络效应和复杂效应。

一万家川菜馆的利润都比不上一罐可复制的老干妈辣椒酱，马云 马化腾睡觉的时候服务器还在自动帮他们赚钱，海底捞派个服务员出去就能复制一个几乎一模一样的火锅店。

复制的概念，有资本上的，时间上的，空间上的，人力上的，技术上的，数字化的，文化上的，乃至梦想上的。

但是，你必须有一个强大的内核，就像印钞需要一个精密的 电版。
