# 孤犸词典100条

**跨界**：一无所长者的避难所。

**凿壁偷光**：古代的蹭wifi。

**智障**：1、智力上有障碍；2、智力成为障碍。

**时差**：人们总是在某一个年龄段，拥有另外一个年龄段才渴望的自由。

**冰箱**：将未必被抛弃的过去，和或许会发生的未来，都存储为某种静止的可能。

**饱暖思淫欲**：饱暖，人们要熟悉的；淫欲，人们要陌生的。

**现实**：你感受到的现实，是真正现实的外壳。~真正的现实要残忍得多。

**与人为善**：蠢的不是与人为善，而是认为对方应该回之以善。

**脱**：电影里男主角啪啪前，正派先脱衬衣，反派先脱裤子。但女主角正派反派都是先脱上面。

**衣服**：欲望不穿衣服。理想穿了太多衣服。

**撒谎**：为了让人觉得我是一个诚实的人，我愿意撒任何谎。

**iPhone**：一个越来越聪明的傻瓜相机。

**手机**：就是AI。

**角色**：那些在你的人生中出场的人，每个都带有命运导演的嘱托。
