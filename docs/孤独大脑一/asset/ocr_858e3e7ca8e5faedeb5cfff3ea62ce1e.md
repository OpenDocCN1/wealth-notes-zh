+   5、去拥抱你的队员。

杰克·韦尔奇说：

好领导就好像好教练，自己站在场外，看到队员有了出色表现时，会无法抑制内心的激动，情不自禁地欢呼雀跃，当选手们走出赛场时，他们会不顾选手汗湿的衣服而给予热情的拥抱，他们还知道如何跟每一个队员打交道才奏效。

# 最后

史蒂芬·平克在《当下的启蒙：为理性、科学、人文主义和进步辩护》说：

> “按启蒙运动的说法，我们可以通过理性和同情来促进人类的繁荣。”

杰克·韦尔奇不仅是企业界的启蒙者，他也证明了一个读书人，可以凭借真诚和勇敢，创造自己和公司的传奇，并收获财富和荣耀。

让我们用他的38句箴言，来怀念他。

+   1、让员工发现和看见自己的工作的意义及其实现机制。

+   2、好主意来自四面八方，点子的沟通应该随时随地。

+   3、对高级人才只要认为值得，付出绝不吝啬。

+   4、始终使用最顶尖的业务人才，不惜代价挖到手。

+   5、在用人方面，头脑里没有任何怪结，完全打破等级、门户、辈分之见。

+   6、只参与行业内最有前景的领域，割离没有创新空间的部门。

+   7、任何行业，只把眼光盯住龙头老大。
