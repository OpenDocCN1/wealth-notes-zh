# 四段重启

菲茨杰拉德写道：生命的活力不仅仅表现在坚持的能力上，还表现在敢于从头再来的勇气上。

别为过去辩解，别维护自己的“正确”。

要点：每一次都从头思考，每一天都焕然一新，每完成上一次认知闭环，就归零重新启动。AI阿尔法狗下棋时，便是如此。牛人亦是。做到这一点，我们需要构建自己的“精神装置”，并不断训练之。
