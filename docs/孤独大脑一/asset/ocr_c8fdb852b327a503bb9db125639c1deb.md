# # 聪明人如何成功?

第一部分，是我为谷歌前CEO埃里克·施密特新作《成就》写的推荐序；

后面两个部分，是我的两个预言：**教练**和社区，会成为创业者和公司的两个机会点。

第二部分（第一个预言），讲的是如何向最厉害的人**影响**。秘密就是主动寻找教练（导师）；

第三部分（第二个预言），讲的是一直被我们忽略的“**社区**”，可能成为个人和公司的新价值点。

三个部分合在一块儿，也不算太夸张《聪明人如何成功》这个心智的标题。
