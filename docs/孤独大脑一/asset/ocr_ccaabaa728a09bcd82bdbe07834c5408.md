# 如何看中国？

加倍下注。

+   1、 中国将比西方更早从疫情中复苏；

+   2、 现在是底部，挺过去，做好准备，为未来下注；

+   3、 在走出此次疫情带来的经济下行之后，中国很有可能会是全球范围最强的增长型国家。

+   4、 一些国家或公司计划将生产和供应链搬离中国，是为了避免过于集中的风险。

+   5、 中国在产业布局上的巨大优势，在可能的“逆全球化”形势下仍然领先。

+   6、 现在正是在许多行业内加倍投资中国的好时候，围绕科技和创新，包括互联网、人工智能、物联网，医疗卫生行业，生命健康领域，等等。
