# 规则三：繁衍

一个空格若与3个细胞相邻，则在下一轮时，这个空格内将产生一个新细胞，如下图中心打黄圈的细胞。

在每一代中，生死、繁衍都是同时发生的。每一代的细胞构成了一个群体，或者说"生命历史"中的一小步。

可以把最初的细胞结构定义为种子，当所有在种子中的细胞同时被以上规则处理后，可以得到第一代细胞图。按规则继续处理当前的细胞图，可以得到下一代的细胞图，周而复始。
