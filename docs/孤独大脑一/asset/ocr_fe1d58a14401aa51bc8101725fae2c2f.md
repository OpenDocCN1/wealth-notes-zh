# ## 流浪之城

# ### 1999年•火车

老喻：

你好吗？

让我们来做一个游戏。

+   - 你告诉我一个“早知道就好了”的道理；
- 我给你讲一个你忘掉掉的故事。

我是在去深圳的火车上给你写这封信。这是最早的一班，路上大约要两三个小时，但票价只有快车的一半。

从石碑村出发去广州东站时，天还没亮。火车还是绿皮的，音乐是《春天的故事》，天呐，1997过去这么久了，为什么还放这个音乐？

我一切都好。手上在做的⼯作正要发芽，尽管眼前仍无迹象，我心底早已看见。倒不是因为远见，而是别无选择。

可别人看不到。

为了躲避房东，我去中山图书馆混了一天，不过不是看书，而是看了两场记不住名字的录像。

再后来，搬去城中村。农民的房子，以不能更低的租金，成为这个城市最后的收留之地。
