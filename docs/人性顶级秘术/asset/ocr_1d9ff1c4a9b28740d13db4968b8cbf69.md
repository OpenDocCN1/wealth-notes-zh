# 13：贤妻为何变嫌弃？

贤妻为何最后变嫌弃？说心里话，我从没见过几个结婚之后，依然保持优雅的女性。

但凡是全心全意为家庭付出的女人，没有几个身上不沾染一些油烟味儿，嘴上不说几句牢骚话，总有一些不修边幅，偶尔还有些不讲道理，因为生活本就现实而琐碎。和睦、幸福的家庭背后，都是艰辛的付出与现实的苛且，你说漂亮的指甲怎么做事儿？华丽的衣服随时被孩子毁掉，锅里还烧着饭，怎么婀娜多姿，照顾父母，如何才能满足自我？聪明的男人都知道为妻难，有的男人可能就要说了，那为夫也难啊，是的，男人也有男人的累，生活都难！但从广义的程度上来说，女人对家庭的付出更多，这是不争的事实，她本想穿高跟鞋，可一想还要抱娃，算了，她本想穿裙子，可一想给娃喂奶不方便，算了，她本想画个妆，可一想娃的手和嘴巴，容易碰到或者吃掉，还是算了，男人总嫌弃家里的女人没有外面的漂亮，那是因为她没有照顾你的生活，没有给你生儿育女，没有给你操劳家务，哪个女人不想优雅，可最后，还是败给了生活。贤妻最后都变成了嫌弃，所以最后我想告诉各位，男人的成熟，是面对挫折，女人的成熟，是找回自我。
