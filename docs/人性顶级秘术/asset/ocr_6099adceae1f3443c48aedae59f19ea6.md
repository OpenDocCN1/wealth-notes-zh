# 8: 被碾压，才能赚大钱

被碾压，才能赚大钱，跟你揭秘一个赚钱真相，我有一个习惯，就是经常会去找在某方面能力强大，能碾压我的人。然后跟他交流，向他学习。可能你会觉得被别人碾压，是一种很不爽的事情，可是每当我被碾压，很不适应的时候，我就会很开心。因为我会觉得，自己碰到了一个很角色，我能从这个人身上学到很多东西。可是不大部分人都很喜欢碾压别人，喜欢跟不如自己的人打交道，这样自己的自尊心，就能得到很大的满足感。而跟那些碾压自己的人打交道，他们都是有个性，有脾气的人，他看你就是强者在看弱者，人都不喜欢被俯视，所以弱者往往不喜欢跟强者打交道，甚至背后会说强者的种种坏话，这一切都没有什么错，可是你有没有想过一个问题：那些被你碾压的人，能教你多少东西呢？想要求成长，就要往上看，走出舒适区。找到比你更强大的人，被他们碾压，被他们击碎，重新再粘合在一起之后，你就完成了一次重生。跟比你能量高的人做朋友，跟比你能量低的人做生意。圈子选错了，怎么玩都是输，做事之前，选择更重要。所以我说打架不重要，跟谁打很重要。你要跟一个禽 sh 打，只有三种结果：打输了，你不如禽 sh，打平了，你就是禽 sh，打赢了,你比禽 sh 还禽 sh，所以对手选错了，怎么打都是输。圈子选错了，怎么玩都是输。你跟谁混一起，决定你未来的方向往哪跑，三年后你在呢？你在干啥？你要成为谁？只要你现在回答不出来的，你现在就是在混。如果你觉得你现在很牛 x,不要高兴的太早，这只代表你是跟一群 lou 货混在一起，送你一句话，宁可做大哥的小弟，也别做小弟的大哥，因为大哥都是能带你飞的，而小弟只会成为你的拖累，兄弟，你大哥是谁？
