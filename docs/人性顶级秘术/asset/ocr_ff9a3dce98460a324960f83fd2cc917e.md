# 10：你快乐吗？很多时候我们都不是在做自己，而是在模仿别人。

我们不是在过自己的日子，而是在羡慕别人的生活。我们不是在追求自己的幸福，而是在抄袭别人的快乐。不可否认，我们一直都在比较，并且从生命之初就开始有了，读书的时候比成绩，立业之后比业绩，吃rem比好坏，穿衣比品牌，买房比大小，买车比贵贱，谈恋爱比甜蜜，婚姻比安定。

人不开心主要源于错误的比较，无论是过去跟现在比较，还是自己和别人比较，只要比较就会产生心理落差，结果可能是正向落差，也可能是反向落差。

前者还好是进步和愉悦，后者就差一些，是挫败和自我否定，哪怕跟别人比较，我们最羡慕的，其实还是那个理想的自己而已。生活在别处，所以我们看到别人的生活都觉得很幸福。到了自己确很残酷，失去都是美好，得到之后也不过如此。

我们太习惯拥有，总是理所当然，我们太害怕失去，总是不患得患失。如果人终其一生都避免不了比较，那不如换个比较的思路，去医院看一看，其实健康是最大的财富，全部都走一走，好好活着才是最奢侈。
