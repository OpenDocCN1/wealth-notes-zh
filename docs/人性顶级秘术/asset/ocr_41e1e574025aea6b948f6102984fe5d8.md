# 1：8条成年人社交的原则，关键时刻不踩坑

尤其是第八条，看懂了基本没有人能再伤害到你。

第一、不要随意嘲讽对方喜欢的人或者爱好，这样很容易让他觉得你在嘲讽他本人，且不尊重他。

第二、能在一定位置上的人，一定有他的过人之处，不管你多么讨厌他，都要跟他建立好的关系。普通人交朋友往往看人品，高手交朋友，往往只看实力。

第三、在别人不需要你提意见的时候，随便给出意见，并且是批评性的意见，会让别人会觉得被冒犯到，很多时候，人给意见并不是为了帮助对方改变，而是想显得自己有观点，这种时候收敛自己。

第四、任何时候不要替别人做决定，哪怕是非常亲密的朋友，甚至是家人，因为每个人的 人生都是自己的，你可以给出意见，但是做决定的，必须得是他本人，要不然决定做错了，他会怪你一辈子。

第五、答谢别人的时候要有一个行为上的回馈，可以请人吃顿饭，可以送上别人喜欢的东西，行动永远大过于语言的表达。
