# 6：你为啥活的焦虑迷茫？

你活的很焦虑吗，很多人口上说的最多的就是焦虑，迷茫，为什么会焦虑，因为他总在羡慕别人的生活。房子啊车子啊乱七八糟的。把自己弄得特别累。其实每个人的日子都是柴米油盐酱醋茶。谁家的锅底都会有灰。不要羡慕他的生活有多么的风光无限。只不过他的一些鸡毛没有让你看见。家家有锅酒，不漏是高手。其实过日子就像白开水一样，我们每天都在喝。不要羡慕别人的饮料有各种颜色。也许他的饮料未必有你的白开水解渴。

人之所以烦恼的两大误区。第一是生活给别人看，第二是总看别人的生活。你不累吗，猫喜欢吃鱼，可是鱼在水里。鱼喜欢吃蚯蚓，可是蚯蚓在土里。其实，就没有完美的人生。猫很自由，但它没有归宿。围墙里的狗，他虽然有归宿。但他一辈子，都低着头。人生这辈子啊。最大的失败只有两个字。叫做遗憾！
