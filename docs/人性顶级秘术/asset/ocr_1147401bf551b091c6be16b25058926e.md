# 20：一个人要混得好，这4点绝对少不了。

第1点就是谈钱。你从今天开始必须明白这个道理。跟跟任何人交往，谈钱大于一切。就是不管你找别人办事，还是别人找你办事。记住了，不要再谈什么感情，交情，或者什么故事情节。没用，把钱谈明白了，事儿自然就明白了。

第2点就是花钱。该花的钱一定要花。对自身有利益，能实现自身目的的时候。这种钱绝对不能省。越没钱越要做一个 иск大方的人。只有先穷大方，才有机会成富人。富人更了解人性。深知舍与得的关系。因为人们对钱，物，等有形资产特别敏感。而对比如知识，人脉，等无形资产。容易视而不见。穷大方的人。正是抵了自己。爽了别人。感动了财神爷。才能赚到人心，自然后续就能赚到更多钱。所谓的穷大方，不是叫你乱花钱。而是把钱花在对的人身上，对的事身上。
