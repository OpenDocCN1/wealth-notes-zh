# 9: 赚大钱的女人 6大特征

不管你现在是多大年龄，一定要看完，尤其是最后一条，你会发现自己无法翻身的真正原因！

第一个特征：叫做雌雄同体，她们既有女性的柔情和细心，又有男性的果断和狠劲，不管男老板还是女老板，她们通常都能打成一片，她们不娇情，不磨叽，做起事来雷厉风行，普通女人最大的错误就是太把自己当女人，总觉的自己是弱者，需要男人保护，总想去依赖男人，而能赚大钱的女人，别说不把自己当女人，她们狠起来的时候，根本就不拿自己当人，而是把自己当成赚钱机器。你再看看你，为了个男人都可以哭天抹泪，郁郁寡欢，你能干啥大事

第二个特征：有野心，目标感极强，一心赚钱，她们见面的时候绝不会聊什么，谁又跟老公吵架啦？自己婆婆怎么啦？孩子又怎么啦？他们只会聊有价值的问题，比如你最近做了什么项目，能不能合作，你需要什么资源？我有什么资源？她们脑子里时刻刻都明确自己的目标是什么。

第三个特征：没有情绪，他们绝不会在情绪和感情上浪费时间，做人做事，说话直接，对事不对人，凡事都是以实现目标为出发点。而不是以虚荣、面子、情感为出发点，不管受了多大的委屈，还是遇到挫折，他们都能默默消化，再想办法解决，因为她们都懂得一个道理，成年人只谈利益，小孩子才谈对错。

第四个特征：扔掉面子，他们从不会在意外界对自己的评价，更不会在乎有没有人喜欢她，记恨她，她们心中只有目标，因为她们清楚，这个世界化解一切矛盾
