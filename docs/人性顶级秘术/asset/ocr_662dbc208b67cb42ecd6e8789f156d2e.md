# 34: 能成为大人物的人，都是狠角色。

你如果想当老板，就要做头狼。你必须要学会下狠手。特别是对没有能力的人。千万不能对她好。你每一步都必须要把利益算清楚。不要觉得有什么于心不忍。

他在你这里吃喝玩乐，把你整垮了。拍拍屁股就走了，也不会同情你，然后还骂你这个老板没有本事。所以做老板一定要现实，打击弱者比安慰弱者更有效。因为安慰弱者，只会让弱者变得更弱，而打击弱者才能让弱者慢慢变强。任何一个员工都不是教出来的，而是在磨难中历练出来的。你要想救一个人，你就要拼命的磨练他大的磨难生出大的能力，小的磨难，生出的能力，没有磨难，就是个废物，从你创业开始你要明白，对谁都不要讲感情，只对利益感情，谁能给你创造利益，你就对他好一点，谁不能给你创造利益，你就让他离你远一点，没办法，你得活下去。你稍微讲点情面，公司就倒闭了，你投的所有钱全会打水漂，还会负债，人一旦动了感情，就立刻智商会为 0，就会变得特别愚蠢，所以你就明白了，为什么那么多美女，会被渣男骗的云里雾里，还不能自拔，就是因为动了感情，那你作为一个老板，一旦对员工讲的感情，对公司就是灭顶之灾。你就明白为什么古代的皇帝都叫寡人，都叫孤王，不是他们无情，而是现实要求他们，不能讲情。把利益关系放在第一位的人，才能大成，把感情关系放在第一位的，基本会一败涂地，不信你就试试看。每个老板都有 menar “血泪账” 实际上，老板在很多日常方面的花费，还不如员工潇洒，甚至被人说，老板就是很抠门，做老板的，往往习惯做什么都要算账，因为老板长期生活在成本和利润之间，花 Watkins，等等。
