# 36: 与人交往，3条潜规则

看透就好，别去拆穿。

1、你如果觉得身边的朋友，在慢慢疏远你，其实不是你们的友情变淡了，也不是你做错了什么，而是你越来越落魄了，你与身边任何人的关系，都是抛弃与被抛弃的关系，要么你混好了，慢慢把他们甩在身后，要么你停留原地，等着被他们抛弃，成年人的世界，没有感同身受，你即使受了天大的委屈，也不要去跟朋友诉说，因为他们首先会觉得你是个怨妇。其次认为你是个笑话。最后巴不得传遍全世界。当你混的很差时，不要指望你还能交到真朋友 ，因为朋友也是一场生意，谁又愿意跟你做亏本的买卖呢！

2、不要总想着改变自己，去迎合别人。通过合群给自己找安全感，是最大的愚蠢。你想要看书，你的朋友们想玩游戏。你为了融入他们，你也跟着打游戏。最后，考试一起挂科。大家有说有笑，你觉得和他们合群了。结果毕业以后，他们去了家里找关系的公司。你却拿着没有什么价值的简历，四处碰壁。迎合别人的人，往往丢掉的是自己的人生。

3、当你步入社会之后，你要明白言语中的重点。大多数人的发言，倾向于把重点放在，【但是】和【所以】之后，前面的往往都是铺垫，不要别人夸你两句，你就飘飘然了，好听的话往往都是假的，不经意流露的话，才是他心里一直想说的，朋友之间，最好不要借一些你赔不起的东西，例如单反，车，电脑这样的东西，这种东西小磕小碰一下，都会让主人很心疼。真出了问题，人家也不好意思让你赔，会显得自己很小心眼。但是也避免不了在背后说落你，友谊种东西，
