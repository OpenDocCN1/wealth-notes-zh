# 1: 5秒钟操控人的思想

有什么方法，能让你在 5 秒内操控一个人的思想呢？

今天我将分享一个心理学上的绝招，有的人靠这个方法呢，成功找到对象，成功脱单，还有人靠着这个方法搞定了大客户，赚了大钱，这条视频建议点赞收藏，因为视频可能会随时隐藏，首先呢，我请屏幕前的你和我一起做个测试，我来提问，你不需要回答，心里想一下就可以了，但凡懂得这个测试，那么这个方法你就学会了 90%。 

+   - 第一个：现在你千万不要想香蕉是什么颜色；
- 第二个：你现在千万不要想老虎长得什么样子；
- 第三个：现在你千万不要想柠檬是什么味道；
