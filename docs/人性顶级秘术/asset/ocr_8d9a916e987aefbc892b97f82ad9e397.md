# 27：养老院给我上的吓人一课

你知道孤独终老的后果吗？

前几天养老院给我上了一课，那天我跟一个开养老院的朋友吃饭，谈到养老院的一些内幕，让我感到心里拔凉拔凉的，太现实也太无奈，看完这个视频，估计很多朋友今晚睡不着觉了，朋友的养老院属于收费比较高的，所以我首先问他的是，你们收这么多钱，提供服务能值这个价吗？朋友犹豫了一下说，能花钱买到的基础设施，肯定是都做到位的，但很多事情也不是钱能解决的，护工的服务精神是个大问题，有监控在，一般也不存在欺负老人的问题。但是他们优先照顾谁？忽视谁？给谁脸色看？这些东西就直接影响老人的生活质量，我说你开养老院的，你难道不管吗？他说我想管可我管的了吗？你别看这些老人，每个月给养老院这么多钱，能给到护工手里的就是几千块，你能指望每个月几千块钱的护工，真能把每个老人当亲爹妈伺候吗。所以，养儿防老还是有必要的，我说护工照顾老人会不周到，但你的孩子就能更好吗？朋友笑了，他说我也不指望我老了时，孩子会照顾我，但孩子存在的意义在于，孩子存在的本身，就是对别的一种威慑，他说养老院是个半封闭的环境，除了老人的孩子会来看望之外，几乎没有外界舆论和道德的监督，那问题来了，在这样一个几乎和外界隔绝的小社会里，除了基本的法律，真正起作用的是什么？是弱肉强食的丛林法则。在养老院里什么叫弱？什么叫强，不是看你年轻的时候在社会上多有地位，赚了多少钱，而是看别人欺负了你以后，会不会有人找他算账？人生活到了这个阶段，会失去和大部分社会关系的联系，你老了的时候呢，除了你的孩子，你被欺负了以后，谁还能帮你找后账？谁又能能力帮你找后账？这就是弱和强的区别，养老院只关注老人安全的的生活，但没有办法关注到老人是否开心，因为只要老人活着，我们就能收费，
