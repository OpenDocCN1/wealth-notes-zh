# 26：教你一个心理博弈术，让别人不敢欺负你

在职场中也好，生活中也好，为什么有人敢欺负你呢？其实本质原因非常的简单，就两个。

第 1 个，别人之所以敢欺负你，是因为你做人没有原则。第 2 个，你有原则，但是你没有胆量去维护你的原则。

你看啊，一个人他之所以敢欺负你，就是因为他内心已经把你彻底摸透了。他觉得你这个人是一个软弱，又没有底线的人。所以他才敢在你的面前肆无忌惮，无所顾及。一个人之所以有胆量，敢在你面前做出让你非常不舒服的行为，或者说出让你不舒服的一些话，这绝对不是一天所形成的。而是你跟他彼此之间的交往接触，长时间的心理博弈的一个结果，最终博弈的结果是你输掉了，你处于相对低的一个位置。而她占据了一个你和他相处中更高的位置。你千万不要认为，对你很强势的人，对谁都是这样子。其实他对他身边的每个人态度都是不一样的。
