# 8: 冷眼观人

这个世界没有绝对的好人或坏人，也没有因此而衍生出来的关于好人的 人品道德，以及坏人的恶劣、低俗，一切都在于机会。

你说王思聪不专一，是因为他有太多机会，可以很容易就得到一堆美女。你说一个男人很专一，那是因为他压根就没有美女喜欢，他压根就没有不专一的机会。

当满足利的诱惑足够大，并且垂手就可以获得，好人也会做坏事，当满足名的利益足够大，并且垂手可得时，坏人也可能做好事。

比如一个十恶不赦的大坏蛋，可能在家里是大家孝子，在别人眼里可能是慈善家。穷人就是只以黑和白来看人，富人的世界都是用灰色眼光看人，无黑无白，即黑即白，只思考我能否给对方提供利益和价值

让对方因为利益被迫选择对我白，而非找到所谓的人品白的人，女人最大的悲哀就是总想找一个 人品好的男人。老板最大的悲哀，就是总想找一个 人品忠诚的员工，人品是后天的教化和约束，人性才是与生俱来的真相

可惜世人只以人品识人，而对人性一无所知，人品是擦脂抹粉后的掩盖，人性才是本来面目，所以人生的修炼，就是战胜自己人性的缺陷，看清别人人性的缺陷。不去伤害别人，不被别人伤害。
