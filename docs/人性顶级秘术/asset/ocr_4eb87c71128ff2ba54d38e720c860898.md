# 23: 4 个社交秘诀，让你看透人性

1、当有人在酒桌上跟你说，这杯酒你必须喝，不喝不给面子的时候，你该怎么办？告诉你，这杯酒你说啥都不能喝。因为这时候他是最不给你面子的人。他绝对不会跟他的领导，他的客户，以及比她身份尊贵的人说这种话的。所以他只是拿你当小丑，如果你要喝了这一杯，他就接下来把你当成了软柿子，一杯一杯又一杯。你以为他是把你当兄弟，他就是想让你出丑。所以你不用怕，也不用不好意思，直接果断拒绝。在外面混啊，姿态矜太卑微，有个性的人更能赢得别人尊重。有些人遇到大佬说话都发抖，其实越卑微，别人觉得你越软弱。不如挺直腰杆，勇于表达自我。更易赢得尊重。这个年代，退一步不一定会海阔天空，有可能会被人得寸进尺。
