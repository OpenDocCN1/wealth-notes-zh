# 35: 钱是最好的社交

经常有人教什么如何经营好人际关系.如何提高自己的情商啥啥的，我告诉你，那些都没啥用，记住，钱才是最好的社交，其它都是扯淡，当你没有实力时，认识谁都没有用。前些年我刚做教育时，在一个活动上，认识了一个同行的前辈，大家当时俯谈甚欢，于是，我就要了他的电话号码。回家后，我小心翼翼的发了一条短信∶今天很高兴认识您，希望有机会能向您学习。可过了很久都没有回复。后来觉得还是打去电话问候吧，结果却发现，他给的电话号码是个空号。那时的我，深深的感受到了什么是挫败感。多年后我在行业内有了一点成绩，一次聚会再次遇到了这个前辈。没想他热情的加我微信，还说有空一起吃饭。这时的我才知道，当时的自己有多天真。我们不再一个等级，就算发 100 条短信，吃再多的饭，他的资源也不会白白流到我这里，从商 15 年，我清楚的了解人脉也是分等级的。所谓的社交一定是势均力敌。社交中能力是 1，人脉是后面的 0。没有 1，后面再多的 0 也没有意义。所以当你不够强大时，不要想着，硬去靠近别人。因为实力不够，人家根本不会理你，只有强大自己，别人才会主动靠过来。你强的时候，放 p 都是对的，你弱的时候，呼吸都是错的，就是这么现实！
