# 5: 爱生气怎么办?

你今天是不是又生气了，瞧你那小心眼，告诉你，人生气的时候产生毒素，据说能毒死一只大白鼠。

爱生气的人很难健康，更难长寿。记住下面这4招，让你瞬间看开一切！

1、看开婚姻，你要知道破锅自有破锅盖嘛，啥人都会有人爱。这个世界上，完全能随你愿的事儿嘛真的不多，你能接受别人身上那些，不随你愿的事啊，耍你就去结婚。你要是不是想找那个完全随你心的人呢，你干脆就别结婚。因为这种人啊，地球上根本不存在。劝你去火星发展吧。

2、看开朋友，你身边的每个人，都有他自己的想法、性格和偏好。你有足够的价格，让他们心服口服。他们就会闲嗒，你没本事啊，请你闲嗒吧。这个世界上所有的人谁都不欠你的。不要整天怪这个萝卜怪你啊，怪那个对不起你啊，我告诉你，你今天所有的结果呀，都是在为自己的认知买单。要怪就怪你自己，太相信了别人，活该。

3、看开子女，生养孩子之前，最好自己先掂量掂量啊，自己有没有足够的担当，甘愿吃亏不要回报，那你就生养，如果没有的话，你就别生别养，不要自己生了养了，又去整天抱怨孩子，这个不行那个不中的，你累人家也累，我告诉你啊，孩子是上天给你的一张存单，可是却没给你取款的密码，你要做的就是只管往里
