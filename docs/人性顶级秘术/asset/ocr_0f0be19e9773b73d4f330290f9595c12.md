# 23：强大就是让自己开心

强大的标志，就是让自己活的开心！

而弱者，才总想着取悦别人，昨天一个学员给我发信息：说她特别爱她的男朋友，他男朋友喜欢吃川菜，于是她就去学做川菜。她男朋友喜欢瘦的女孩，她就努力把自己饿瘦。她男朋友喜欢被人照顾，于是她就辞职，专门照顾男朋友的生活。

但是她觉得男朋友还是不够爱她，对她很冷淡，问我是不是自己做的还不够好？这种人就是典型的取悦者。简称叫“舔舔型”人格，他们习惯性地让别人高兴、对别人好，想得到别人的认可，全然不顾自己的感受。就好像同学聚会，你明明觉得跟他们没有共同语言，却为了不冷场而强颜欢笑，没话找话，最后自己心累，别人还觉得你虚伪。每一个取悦者，他们都很忙。忙着感知别人的需求，忙着抉择是先满足 A，还是先满足 B，忙着焦虑的等待着别人的认可，忙着担心害怕——怕自己在别人眼里不够好，很累，很疲惫，但却停不下来。这仿佛是一个无限制的轮回，追求认可-害怕失去-追求更大的认可，在这个轮回中，取悦者就像极了一枚陀螺，被鞭子抽打着不停旋转。这其中，消磨了自己的时光，耗费了自己的心力，却把自己变得越来越卑微。强者最大的突破，就是不再为别人的看法而担忧。你只需要去做你认为该做的事，别人怎么看无所谓，你才能真正的获得自由。
