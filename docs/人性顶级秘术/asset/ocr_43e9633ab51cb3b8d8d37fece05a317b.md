# 25: 这4种人找你借钱，千万不能借

尤其是第四种，坑你没商量。

1、经济条件很差。夫妻两个都不上进，天天混吃等死那种。搞得房租交不起，孩子学费交不起。这种钱一定不能借。常言道借急不借穷。你不要试图去扮演上帝。扶贫不是你的事儿，还钱是需要很强的自律性的，而穷人最大的问题，就是不自律。

2、是做生意需要投资。手上钱不够，找你借钱。这种钱也不能借。他应该去找银行贷款。这种钱你借了之后，他赚了钱不会给你分红，亏了钱呢，你基本上就找不到他了。

3、是你以前的同学，朋友，同事，已经有一两年不怎么联系的人。这种人突然找你借钱，千万不能借。一两年都没联系了，为啥能找到你借？说明他把他身边的亲戚朋友都借光了，而且他还不好好还钱，在熟人圈子里的信用，已经彻底破产。才想到了你。
