# 第十三章 智慧人生，点亮心灯

# 1：如何修炼自己的人性？

世间所有的完美，都是经历和阅历的沉淀。就好比你看到一个女人很完美，情商很高。那么就可以必然断定，这个女人经历了很多事儿，很多事人。经历情感，获得情商，经历磨难，获得智慧。过去所学一切，都只不过是知识和素材。人的智慧，情商，不可赐，也学不来。必须靠经历和体验。每个人都应该无限感激，过去你所经历的不公，打击和挫败。因为所有失去背后，都无意间让你获得了：强大的心，智慧的脑，坚强的身躯。真正的成熟是，经历了世态炎凉之后的通透，饱经了人间沧桑之后的觉醒，看透不能说透的秘密是什么？

这个世界是由两套秩序组成的：第一套规则：感情、道德，礼节。第二套规则：是隐藏在背后的利益斗争。第一套规则的情怀是表象，第二套规则的利益是内在。

我们从小到大接触到的知识，大多都是第一套的表面规则。而人们无时无刻不在心里打的算盘，就是第二套的利益规则。高手都是以第一套规则做为幌子，为的是达成第二套规则的目的。几乎人人都会披上一层光鲜的道义外衣，然后千方百计的给自己谋取利益。第一套规则，人人都放在嘴上；第二套规则，人人都记在心里。所以啊，赶紧醒醒，千万不要被迷惑！
