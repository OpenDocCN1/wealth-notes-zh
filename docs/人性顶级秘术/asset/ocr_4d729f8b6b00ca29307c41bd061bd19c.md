# 8: 已婚不幸福的 5 大真相

根据数据统计，大部分已婚人士不幸福的，因为他们不清楚这五个婚姻的真相。

真相 1，世界上没有绝对完美的婚姻，劝大家不要对婚姻抱有太高的期待，人无完人，世上也同样没有完美的婚姻，恋爱是两情相悦，花前月下的浪漫，可是婚姻，却是寻常日子里的柴米油盐，无论跟谁日子，过久了都会发现磕磕碰碰在所难免，石头记里有句话是这样写的，凡事只追求相爱的最后都散了，凡是大伙过日子的最后都团圆了。

真相 2，婚姻怎么选都是错，长久的婚姻就是将错就错，这句话我很喜欢，选我所爱很容易，但是爱我所选，才能拥有自己的幸福，如果没有学会爱，就算嫁给了真爱，也未必能够快乐。

真相 3，包容是婚姻的稳定剂，有人说世上最幸福的婚姻，也有 200 次想离婚的念头，和 50 次想要掐死对方的冲动，而婚姻幸福的秘诀恰恰在于第 201 次的和好，和第 51 次的原谅。
