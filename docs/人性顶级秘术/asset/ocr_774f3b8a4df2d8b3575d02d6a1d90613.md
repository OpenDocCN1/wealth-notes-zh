# 75: 为啥借了钱的人，都不愿意还钱。

背后的真相让你倒吸一口凉气，你如果 你珍惜你的朋友，那最好就要没有任何经济上的往来，尤其不要把钱借给别人，因为那些经常借钱的人，在大概率上是不会还钱的，在心理学上有一个概念叫做损失效应，研究发现人在失去一样东西时感受到的痛苦，比他得到这样东西感受到的快乐，要大 2.5 倍。也就是说如果 你丢了 1000 块钱，那种心疼的感觉，需要捡到 2500 块钱才能平衡，损失效应是人的本性，要想做到欠债还钱，就要有强大的自律，来战胜这种本性，但是人之所以会借钱，往往是因为他在财务上管不好自己，本质上是一种不自律的表现，所以我们可以得出一个结论，让借钱的人还钱就等于让一个不自律的人，去做一件
