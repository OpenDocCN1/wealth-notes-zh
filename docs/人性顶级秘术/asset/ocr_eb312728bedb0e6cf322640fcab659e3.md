# 77: 放手吧，别再很傻很天真！

真正的失望不是吵，也不是闹，而是沉默不语，或许生气的时候，你还会抱怨对方，与对方沟通，但是心里已经麻木了，无论他说什么，做什么，都无法在你心里掀起任何波澜，你知道他在，但你不想找，你知道他的错，但你不想争，有那么一瞬间，你看着他，就像在看一个陌生人，他对你好不好，关不关心，在不在意，似乎这些都与你无obtained。人啊，非要把爱摔碎了，才想起来那是爱，可是满地的碎玻璃，无论你怎么拼，都拼不回原来的模样。世界上根本不存在破镜重圆这一说，一旦失去，就是永远，真正让你放不下的，不是某个人，而是你心存幻想的天真。
