# 53: 穷人永远悟不透的人性！

跟你讲一个穷人永远悟不透的人性，10年前我在深圳一家教育公司实习，周末出去逛街，钱包弄丢了，正好包里有一张公司报销单，上面有我电话，不久就接到一位大叔来电，说捡到了钱包，叫我过去拿，态度很热情，我特别感动，电话里千恩万谢，我拿到钱包感谢了他后，正想离开，这个大叔说话了，小伙子，你就这样走了吗？我一听，明白了大叔的意思，在钱包里拿出了50块给他，他看了看说这也太少了吧，我说我这个钱包不值钱，而且里面也没多少钱，他说我刚刚看了里面有200，你至少要给我100吧，刚刚的慈眉善目烟消云散，漏出了一副凶神恶煞的表情，那时候我不懂事，给完钱后，一直认为这个大叔是个恶人。直到我自己做生意，研究人性之后，才恍然大悟，其实我才是这个恶人，如果我这样的人多了，那以后有人捡到钱包，就再也不会退回来了，商业看似无情，但他最大的意义，在于用钱就能解决问题，如果有一天，这个世界不用付钱，那问题也会无人解决，这才是最大的问题，找人帮忙，一定要给钱，别人说不要，只是嘴上跟你客气，但心里还是想要，你只有不断的给好处，才能继续让他推磨，这个世界不存在免费的帮忙，都是交易，即使有人愿意免费帮你，也一定是你曾经帮助过他，人从生到死都在交易，这就是人性，不懂这个道理的，一辈子只能待在底层。
