如何提升自己为人处事的能力，让别人见人爱，花见花开，以下这10个臭毛病，你必须改一改。

+   1、改掉自己为中心的臭毛病，与人交谈时少用我，多用你，比如不要总是说我觉得，而是要多问问对方你觉得呢。

+   2、改掉口无遮拦的臭毛病，所谓交浅不可言深，尤其是对不熟的人，不要一上来就问别人隐私，更不要透露自己的隐私。

+   3、改掉好为人师的臭毛病，你可以分享观点，但千万不要教别人怎么做事，因为你说对了，别人不会感激你，但是你说错了呢，别人只会记恨你。

+   4、改掉背后议论他人的臭毛病，所谓议人是非者，必是是非人，比如领导问你，对小王有什么看法啊，这时候倘管你心里怎么想，但嘴上一定要说，啊我跟小王虽然一起工作，但私交不多，总体来说呢，他这个人还不错，然后说完立马转移话题。

+   5、改掉人前显贵的臭毛病，比如你最近换了辆新车，同事问你多少钱啊，这时候你千万别傻乎乎的直说，而是要学会诉苦，哎，别提了，这辆车啊，前前后后攒了两年的钱，还跟父母凑了点，现在搞得手头好紧张，日子难过啊。只要不是和你利益相关的人，你日子过的越开心，他就会越不开心。
