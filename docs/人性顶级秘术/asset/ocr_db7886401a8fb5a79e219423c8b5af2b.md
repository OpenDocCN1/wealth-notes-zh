人到中年，千万不要低估人性。毛姆在月亮与六便士里写道。卓鄙与伟大。恶毒与善良。仇恨与热爱。是可以互不排斥。并存在同一颗心。

前些年我帮一个客户做培训。当时谈好了，费用是 3 万块钱。他说课程结束后付给我。当时我也比较稚嫩就同意了。但课程培训完之后，跟他催款的时候，他左推右推，就是不付。

后来我就把这个事儿跟一个比较要好的朋友说了。他一听到这个客户的名字，他说这个人我认识啊。他说我帮你要。过了两三天，他给我打电话说钱要回来了。

我当时那个感动呀。嘴上连连道谢。他把钱转给我之后。我想虽然我们是好朋友，但也不能让人家白做这个事。然后我就转给他 5000 块钱。我说这个红包，是我的一点小心意，你一定要收下。当时我本以为，他会推脱不收。

但没想到，他回信息跟我说，你小子真行啊，我帮你赚回了 3 万，你就只给我 5000 啊！我一听，这脑瓜子都嗡一下子。这啥情况啊？然后我就说，这课是我讲的，我花了时间和力气的。咱俩这么好的朋友，你帮个忙，我转 5000 给你，难道我给的还少吗？他说我帮你赚了 3 万，没有我的话你一毛钱都要不到，你才给我 5000，合理吗？我説那你觉得给我多少合理？他说最起码要 55 开给我 15,000 吧。

我当时也是年轻，心里那个气呀。最后在另一个朋友的协调之下，ATTER了 1 万块钱给他。然后从此，我跟他彻彻底底交，再也没有联系过。事到今天我再回头想，其实是我当时就是没长大！我还把他当成是朋友。其实这个世界哪有朋友，只要从利益的角度去看，任何关系都一目了然的。他去帮我要这个钱之前，我就应该跟他问清楚，要回来之后给你这边多少钱。如果说他说想要 15,000，那我就直接说不用你管了，我自己要。
