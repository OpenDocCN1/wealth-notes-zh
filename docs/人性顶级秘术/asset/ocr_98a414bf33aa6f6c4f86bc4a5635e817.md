# 7: 一贫如洗，如何逆袭

如果你现在是个青壮年的小伙子，身体很好，大脑也不差，但你一贫如洗，你想达到人生巅峰，想逆袭的话，我给你几个建议。

1、就是你一定要有野心，如果你没有绝对的野心，想要彻底改变这个命运，像发誓一样的话，你说什么道理都没有用的，你去抱怨没有用，世界不会因为你抱怨而改变的。我过去家里人因为穷，总被亲戚朋友看不起，当时我心里就一个想法，我要拼命奋斗，让我爸妈因为有我这样的儿子，在亲戚朋友面前能模着走路，就为出这口气，我拼命奋斗，到现在，我做到了。所以你想想还有多少人看不起你，看不起你爸妈，想到这些你立刻就有野心了。

2、就是你需要有战斗力，越挫越勇，百折不挠，你必须这样，你不要跟人讲道理，你做键盘侠在这里头你就是喷我，喷死了你也得不到一毛钱，只有无能的人才到处汇报别人，厉害的人都是用一切时间去提升能力，去赚钱。

3、就是你需要有本事你得练硬功夫，你看看你现在能干什么，你那个能力，在市场上能交换多少钱。如果没有就马上练习，不要浪费时间跟别人争论。

4、就是或多或少都会有运气的成分，但是你要练好自己，等着运气出现，不要再抱怨出身，不要再抱怨世界，不要抱怨这些东西。

今天我之所以说这个，因为我 16 岁出道到现在，我每一分财富都是靠自己的手脚赚来的，那里边有运气成分，但绝大多数还是要自己练好功夫等运气。所以你要喷你就喷，我不在乎。我说的话是给听得懂的人，说的是给上进青年听的，窝囊废的青年，你爱怎么着怎么着。
