# 18: 与人相处，这四种人绝对不能帮。

尤其是第四个，很多人都犯了错，善良很贵，如果给错了人，换来的只会是受伤。

第 1 种人：过度敏感的人不能帮。这种人吧，特别的喜欢推理，猜忌，分析，你明明好心帮他，反而可能会引起他的疑心。她觉得你还对他有什么目的？敏感是什么意思呢？就是说一个人的反应速度特别快，对一个人对一件事能迅速的察觉和准确判断。敏感其实没什么问题，但是过分敏感就不===========
了，他会对任何事情都有些神经质。想 7 想 8，到头来全想歪了。最后呢，你就是费力不讨好。

第 2 种人：容易膨胀的人不能帮。你看你身边有没有这种人，他有点小成就，就不得了了。谁在他眼里都看不起了。巴不得走路都要横着走。这种人哪，你帮了他之后，他稍微有点小成绩，立刻就把你忘得干干净净，甩都不甩你。你明明把他当朋友，想跟他一起聚聚，人家还以为你是想去巴结他。到那个时候你才感受到什么叫做心寒。所以遇到这种，喜欢装又容易膨胀的人，一定要敬而远之。

第 3 种人：借钱不还的人。与人交往的时候，如果发现朋友有借钱不还的前科的时候。你就一定要小心这种人了，不管他多可怜，你都绝对不能帮他。人与人交往的目的，就是一种利益交换。而欠钱不还的人，就是强盗逻辑，你帮他，他不仅不会回报你，反而还会害你，他不会认为你是在帮他。他反而觉得是自己的计谋得逞。到头来还把你当成傻子一样耍。
