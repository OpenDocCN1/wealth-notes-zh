# 6: 怎么看一个男人能不能嫁？

做为一个已经结婚十年的老男人，建议各位注意观察以下 5 个细节

+   1、他的钱品好不好？夫妻之间很多的纠纷，大多数都与利益息息相关，一个钱品不好的人，他的人品也好不到哪里去，他会时刻刻维护自己的利益，然后将金钱放在首位。如果恋爱的时候都抠门，那就更别指望他在婚后变得大方了。

2、我们要观察他对第三人的态度如何？比如说外出去的时候吃饭啊，对服务员的态度，对朋友态度，还有对他父母态度，其实这些都暴露了这个人最真实的人品。

3、我们要看他能不能接受你的不完美？如果你想和他一起，去参加他朋友的聚会，他表现出来是不情不愿，感觉带你出去让他有点没面子，那潜台词就是对你有所嫌弃。

4、我们要看他如何跟异性相处，这点很重要，如果他不能够很自觉的和异性保持距离，那他一定不会为了你去拒绝其他暧昧。

5、你要看他是理性的爱你，还是冲动的爱你，真正值得你嫁的人，不是那些冲动之下，对你好的感天动地的人，反而是那些看上去，并没有那么爱你，但把重心更多的放在了构建未来的男人，过度的溺爱和包容，只会把你变成一个无理取闹的小公主，同时也架空了你的社会价值，好的婚姻，应该是相互共同成长，而不是一方不停的迁就另一方，一个人能极端的爱你，有一天也可能会极端的伤你。
