# 74： 3段现实的大实话，看透社会和人心！

1、金钱不是万能的吗？

有人说金钱买不到快乐，我觉得纯属胡扯，说如果买不到，那一定是你花钱的方式不对，以及，你的钱不够花，钱的力量是无穷的，因为有钱就不会穷，人家有钱人的事才叫事，我们穷人的事，就是没钱。

2、有人说，人生的起点都是一样的，我觉得胡说八道，我是在土房子里花 20 块钱，请的接生婆生下来的，你是在最好的妇产科医院，花几十万找的专业护理小组生下来的时间对每个人都是平等的？有人坐火车去北京要两天一夜，有人坐飞机去北京却只要三个半小时，谁说命运掌握在自己手里？当初我拿着各种毕业证各种资格证去应聘，结果对方向录用了老板的侄子，谁说不努力就一定不成功？要不要我带你去看看那个老板的儿子？有些鸡汤虽好喝，那你不要贪杯哦。

3、我在想为什么骗钱犯法，骗感情好像不犯法？这是为什么呢？是不是因为感情不值钱？为什么我去商场买东西，店家都会说，你要真心买，我就给你便宜一点，是不是因为真心也不值钱？在感情的世界里，有一种东西，叫甜言蜜语，我估计这种东西都是用酒精勾兑，不然angal上头？不知道这些年朋友们的感情都顺不顺，反正我是比较顺，因为一路上都没人。有人问我，没人爱和爱错了人，哪个更痛苦？我 accounted肯定是爱错了人更痛苦，这就好比是，没饭吃和吃到了 shi，你说哪个更痛苦？
