# 33: 想成熟，就要做个狼人!

成熟，就是一个把哭声，调成静音的过程，越痛，越要不动声色，越苦，越要保持沉默，年轻时，要把吃苦当资本，吃的越多，你中年时资本越丰厚，你必须得活出人样，即便说你现在一败涂地，没人瞧得起你

但你也要相信，十年河东，十年河西，耳朵根子要硬一点，听不进去的话别听，没意义的人就滚开，落到谷底，咬紧牙关，迈开步子，只要不是毁灭，就是收获，除了你自己，别让任何人有资格伤害你，永远只干跟自己有关的的事，永远去争取自己想要的东西，甚至感情，算个 p，很多时候，人性都是 e 心的，你越把他当成人，他越把你当成狗，你越把他当成狗，他越把你当成人。

所有伤害你的人，本质都是因你而来，你软弱了，欺负你的人就来了，你卑微了，轻视你的人就来了，你优秀了，嫉妒你的人就来了，你付出了，背叛你的人就来了，永远不要去责怪伤害你的人，好的给你快乐，坏的人给你经历，最差的人给你教训

成年人的世界，不管昨夜情绪如何崩溃，第 2 天清晨都要释然。生活就是这样，一边失望，一边充满希望。一边崩溃，一边自我修复。人这辈子，思来想去，就两样东西靠得住，一个是你的身体，一个是赚钱的能力，其他的，还有什么靠的住？，你知道成长最痛苦的那一课是什么吗？是你从未防备过的一个人，突然朝你开了最猛烈的一枪，砰...你就长大了。
