# 11：看透人性心理的 9 个绝招

1、常年不联系的人，忽然在微信上问你“在么”，那你最好别吱声。想吱声也行，先准备点钱，反正不是随份子，就是借钱。

2、越是在你面前点头哈腰、溜须拍马的人，一旦有机会爬上去，会立刻对你翻脸。相反，刚接触时不太好讲话，但是随着认识的加深，感觉还不错的人，通常值得深交。

3、一直生活在父母身边，被父母安排工作、操办婚姻的人，相对缺乏主见，男人往往是妈宝男，女人往往是公主女，遇到这样的人，即使你在喜欢对方，也不能结婚，否则，你会被他们一家子，搞的鸡犬不宁。

4、比起开口，女生更喜欢，用行为传递「好感」。比如目光温柔地注视着你、摆弄着揾摆或头发，都是想引起你的注意，异性之间的距离如果低于 50 厘米，就很容易擦出爱情的火花。当一个女生，没有拒绝与你近距离的接触，那么她大概率，已经被你吸引。

5、天天叫嚷着对公司的不满，说自己要辞职的人，很少会真正的辞职。他们只是对现状不满，又没有能力找到更好的。真正准备辞职的人，从来都是悄悄的，生怕别人发现。同理，一个天天吵着要分手的人，都不是真想分手的，而真正想分手的，往往嘴上啥也不说，只是默默的冷淡你。
