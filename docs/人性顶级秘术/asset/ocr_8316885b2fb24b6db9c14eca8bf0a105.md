# 4: 做生意需要投钱吗？

做生意需要自己投钱吗？瞎扯!很多人为啥选择打工，因为打工安全，做生意要投钱，万一亏了咋整？确实很多小白第一次做生意，亏的稀里哗啦的，正确的创业姿势是，根本别投钱，或投很少的钱，这样你就根本不会亏，那些创业大佬没有自己投资创业的，都是利用别人的钱创业，你会说，他们能拉到投资商，我又拉不到，瞎扯，拉啥投资商，拉你身边的亲朋好友就行了，马云最开始创业，就是带着朋友，亲戚，他教过的学生，就开干了，做起来之后在想投资商的事，那你会说，我又没做生意经验，他们怎么会投我？

首先，你要去镀金，别人不会相信你，但他们会相信你身上镀的金，咋镀金？镀金的方式就是，你找到你同行业最牛叉的公司，你杀进去去半年，俗称卧底，一进去就别应聘员工，而是应聘管理层，应聘不上就换下一家，搞个10来家，你就经验丰富了，应对自如，对各个公司说的头头是道，你应聘进去之后，不会干怎么办？你把全部员工召集在一起开会，让每个人写门店现在存在的3大问题，和改进方案，写的好被采纳的给奖金，他们写完你一看，基本就了解这个店的大概情况，然后把写的最后的几个个人拉出去吃饭，让他们接下来去执行他们写的方案，执行的好的给奖励，总之把这几个最厉害的拉扯成自己人，他们接下来怎么干，你就在旁边好好学，如果搞段时间老板发现你不行把你撤了，你就去换下一家，换几家之后你就经验丰富了，这时你就已经给自己镀了一层金，你在亲朋好友的眼里，就是这个行业的大咖，理解我意思吧？比如你在海底捞捞做过管理层，在真功夫做过管理层，这时你说你要开餐厅，让身边人跟你入股一起干，你觉得他们
