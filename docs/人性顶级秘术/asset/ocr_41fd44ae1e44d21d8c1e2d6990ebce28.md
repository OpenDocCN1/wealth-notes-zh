# 2：你会一直穷下去吗？3个赚钱方程式。

你了解金钱的真相吗？

1，大多数普通人的赚钱公式是：金钱等于工作后的薪水，这已经大错特错，我们从小知道要好好读书，考上好的学校，将来可以找到一份好的工作，这有什么问题吗？真相是，这样的方式，会让你永远都无法实现财富自由！我们所有人都有一种相同的资源，消失了就沒有办法再拿回来，那就是时间，常规上讲，你能赚多少钱，取决于你工作了多少时间，如果你每小时赚 20 块，每周工作 50 个小时，一个月 4 千块，你需要 20 年的时间，才赚到你的第 1 个 100 万。前提是你不吃不喝，不会生病，不请假，不发生意外情况，可怕吧，富人的财富方程式是什么？穷人，永远追着钱跑，而富人，永远追着问题跑（这两句话你要默念 3 遍）这就是本质区别，所有人都会抱怨明星的收入太高，包括直播做网红，收入都很高，为什么会这样？这里要提到一个关键公式：金钱=消费者感知价值！金钱和你的努力程度无关，每天辛苦劳累的农民工，收入永远都会低于坐在空调下面的工程师，为什么？因为在客户的感知价值里，农民工的工作价值，远远低于工程师，尽管这听起来很难听很刺耳，但农民工这份工作，任何人都可以做，学会做这份工作并不难，没有门槛。因此市场不会因为他更努力，而给他比工程师更多的工资。
