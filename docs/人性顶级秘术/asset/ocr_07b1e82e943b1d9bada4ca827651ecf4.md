# 57: 你可以相信人，但你不能相信人性

跟大家讲一个，关键时刻可以救命的人性心理学，叫旁观者效应，我们先从一个真实发生的案例开始说起，美国曾经发生过一起凶杀案，一名年轻女性，在回家的途中被一个陌生成子杀死，整个行凶过程持续了大约 30 分钟左右，令人惊讶的是，案件发生时受害人大声呼喊救命，现场有 38 位行人目睹了悲剧的发生，却没有一个人施以援手或者打电话报警，难道这些目击者都是缺乏勇气，没有爱心的人吗？为了寻找答案，心理学家做了一项与这起命案场景相似的实验，结果显示，当受害人遇到危险的时候，如果现场只有一个陌生人收到求救信号，那么他施以援手的概率是 90%，如果是 5 个陌生人同时收到了求救信号，他们施以援手的概率会下降到 20%，收到求救信号的人数越多，受害人获救的概率会越低，心理学家当时彻底震惊了，这个现象叫旁观者效应，也可以称为责任分散，如果你把一项任务分配给某个指定的人，他会有很强的责任感，并愿意积极主动的完成任务，，但如果你把任务同时分配给很多人的时候，就没有人会认为这是自己的责任，因为每个人都是这样想的：大家做，等于别人做，别人做，等于是我不做，做为案发时的 38 位目击者来说，当时每个人心里都在想，这么多人都看见了，肯定早就有人报警了，旁观者效应教会了我们 2 件事情；
