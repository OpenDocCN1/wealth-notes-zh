# 10：聪明人，三不会四不见

这真正聪明的人，不贪三件事，不见四种人

# 三不贪

第一、不贪赌，聪明的人不会贪赌，他们知道啊，十赌九输，赌场上收获的就是那些头脑简单的人，整天幻想着靠赌博去翻身，靠赌博呢，去赚钱，在赌博中输掉钱的人呢，他们输掉的不仅仅是钱，输掉的是智慧人品，家庭。

第二、不贪婚外情，婚外情是一个螺旋式下降的开始，他们往往以美好开始，以身败名裂而终，而真正聪明的人呢，都知道婚外情呢，就像是一朵剧毒的蘑菇，你看着漂亮，吃下去之后，你会痛不欲生。

第三、不贪友情，聪明的人，他们没有太多的朋友，因为他们早已经放弃了自己无用的社交，他们深知啊，人际交往的本质就是利益的交换。不能给别人带来利益的价值，那么自然在别人的心里啊，就啥也不是，朋友多了路好走，这句话应该反过来説，只有你路好走了，朋友才会多。
