# 10：毁掉普通人有多简单

摧毁身边的一个普通人，到底有多简单呢？否定他，你不要表现出任何的情绪波动，你务必耐心的、客观的、冷静的去否定他，当你跟他建立起一个良好的关系之后，就可以开始了，先去否定他很多的微小的行为，紧接着去否定他的长相，再去否定他的家人，紧跟着去否定他身边的朋友，再狠点心的去否定他的性格人品，期间，如果他提出任何的质疑，你千万不要发火，要仁慈的，甚至带着一颗怜悯的心跟她说，别别人怎么看你，我不管，我怎么会伤害你呢，最后你制造一个争执的机会，突然间爆发，把之前所有的伏笔全盘倒出来，高声的去责骂他，把他身上所有的缺点全部放大，让他都开始产生自我怀疑，第二回合，当他心里难过伤心崩溃的时候，你再去关怀她，告诉她你说这一切都是为她好，跟她再此建立起良好的关系，慢慢的再次取得她的信任，重复以上的举措形成一个循环，你会发现在那之后啊，她不需要你亲自动手。他学会了自我否定，变得多疑、多虑、瞻前顾后，敏感又自卑，甚至下意识的，去排斥向他靠拢的所有美好事物，你也成功地制造了一个假象。那个敌人就是他自己，这听起来是不是很恐怖，但这正是很多丈夫，很多妻子，甚至很多父母每天的日常，因为他们懂得多，他们是过来人，他们比你还了解你自己，他们不可能伤害你的，因为他们永远是对的，可是他们不知道，这个世界上最可怕的伤害，就是打着爱你的旗号来摧毁你。有的人用童年治愈了一生，而有的人，用一生都难以治愈童年。
