# 15：人际关系 7 个潜规则

人与人之间的关系再亲近，也不能忽视这 7 条潜规则。

1、最牢固的人脉关系，一定是金钱关系，人脉的本质不是互相认识，而是互相需要，钱是衡量人际关系的工具，利害关系越大的两个人，关系就越牢固，真正的朋友不是受欢迎，而是被需要。

2、优质的人脉圈，一定是利益至上的圈子，善良并不代表放弃利益，无论和谁交往，利益捆绑都是最高明的社交手段，不要做烂好人，如果你只讲人情不讲利益，那关系再好也会被背叛，因为人性的善恶，都是受利益主宰的。
