# 9: 看不惯的人，不必翻脸，默默离开就好！

年纪越大越明白，这世上哪有什么感同身受，哪怕你们有过相似的经历，也会有不同的感受。所以，永远不要指望别人理解你，人类的悲喜并不相同，你的悲喜在别人看来，都是无关紧要的小事，像一阵风就可以吹散的尘埃，那么轻，那么不值一提。

世间百态众生相，认真看，看的是一面镜子，折射出自己的人生；潇草看，看的是一场热闹，热闹完全别人，热闹自己。于你而言，天要塌下来的大事，于别人而言，不过是天上飘雪花一样的小事；于你而言，令你欢欣雀跃的好事，于别人而言，可能会是刺痛别人的遗憾。

你的难过，你的悲伤，在别人那里，有时只是矫情；你的快乐，你的喜悦，在别人那里，有可能是炫耀。无论快乐还是悲伤，能与人说的又有多少呢？苦而不言，喜而不语，或许才是最好的状态。这世间，感同身受本就是奢望，冷暖自知才是人生常态。

成年人的世界，没有谁能真正理解谁。每个人都有自己的心酸和苦楚，理解本就是稀缺品，指望别人理解自己，最后失望的一定是自己。所以，正应了那一句话： “他人难悟，悲喜自渡。” 人生在世，唯有自己，能真正理解自己。成年人的世界，没有告别，才是最好的告别
