# 26: 为什么你赚不到钱？

跟你讲一个受用终生的秘诀，调用用户思维，看懂了赚钱太容易，举例来说，小李有一次去了泰国，觉得泰国菜很好吃，于是就想，我回到国内开家泰国餐馆，一定生意很好。小李越想越兴奋，于是回到国内，马上准备开干，他从自己家的小区附近选了一个人流量很高的位置，把店也装修的很高端，菜品的价格也很高，在小李的一番努力之下，不出三个月，这家餐厅成功倒闭了。其实小李的做法，就是现在 90% 的老板的真实写照，满腔热血的开店，最后店开倒了还不知道是咋回事，还怪罪是大环境不好，因为他只站在自己的角度看待问题，没有真正验证用户的喜好，同样是开餐厅，如果按用户思维开，结果完全不一样，同样是这个案例，但不同的思维，结果完全不同，话说小王也想在小区附近开一家餐厅，但不知道卖什么菜系为主，于是就跟小区附近的居民聊天，调查之后发现，小区里多数住的是一些老年人，而且小区里南方人居多，他们平时更多的是家庭聚会，了解这些情况之后，小王决定在小区附近开一家装修简单，菜品以广东清淡菜系为主，价格亲民的中档餐厅，选择人流量一般的店铺，这样子房租成本就不高，并且每天晚上在餐厅门口，用音箱放广场舞的歌曲，吸引这些小区的大妈来这跳舞，并且提供免费的饮料和茶水。因为得到了这些老年人的信赖和推荐，这些老人的家里的，儿子女儿，都来这家店吃饭。开业之后没出三个月，店里的生意就非常火爆。这两个案例中，我们看到因为小李不具备用户思维，所以从选址，选品，定位，定价，都以自己的感觉来设计的。能否成功，几乎靠的都是运气。而小王则充分发挥了用户思维，一切都以满足客户的需求，解决客户痛点为导向。所以小王的每个动作，，都是围绕她的准客户，也就是这些大爷大妈，能够更方
