# 5: 被人羞辱如何回怼

有人当众羞辱你的时候，你都是怎么回怼的呢？是不是每次对完了总觉得自己没有发挥好，今天分享 4 个回怼绝招，既霸气又不失风度，让对手哑口无言，这最后一招啊，几乎是无敌的，绝对可以一箭封喉。

第 1 招，就是淡定回击法，任由她在那煽风点火，你就是安然不动，他越是在那使劲拿你开涮，你就越是气定神闲地看着他的用力表演，他说累了，忘词儿了，你还可以微笑地提醒他，哎继续啊，你别停，我们听着挺爽的呢，瞧你那一头汗，喝口水慢慢喷，你越是这样，就能越展示你的高度，他就越觉得够不着你，用尽浑身的解数，结果却打在了墙上，反而自己成了人群中的笑话。

第 2 招，叫做赞同回击法，这就好比打太极，先赞同他，再把他的力接过来，然后重重地回击过去，比如对方说你是垃圾，你可以笑着对他说，垃圾挺好，不都在搞垃圾分类吗？如果咱俩都是垃圾的话，你肯定属于那种不可回收的，再比如啊，对方说你是傻子，你可以说傻一点不挺好吗？傻人有傻福，难不成跟某些人一样，小肚鸡肠处处喷人吗？这可以瞬间让对方哑口无言。

第 3 招，叫做借力打力，就是用对方对你的话把她也拉下水，两个回合之后啊，他就哑口无言了，比如对方没好气的说，你这人有毛病吧，你可以这样回答，是啊，我也纳闷，刚开始还挺好的，怎么一见到你就浑身不自在了？肯定是被你传染，再比如对方羞辱，你怎么这么笨，像头猪一样，你也可以这么回答，我也纳
