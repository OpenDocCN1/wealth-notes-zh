# 54: 人性真相：任何关系，终究是利用关系。

一段话，让你倒吸一口凉气，在这个世界上，有人生来就有一张巧嘴，但不一定有一颗好心，很多人当面，把你夸的跟一朵花一样，背后把你贬的跟臭豆腐渣一样，用你的时候好话说尽，利益冲突的时候，坏事做绝，所有好处他全部揽光，如果你敢和他争，他就会把你弄得很难看，用到你时对你百般讨好，不用你时，转瞬把你当成陌生人，你要适应这种虚伪，不要迷茫，这就是人性，人和人之间的关系，终究逃不过利用关系，对你好是你有用，对你不好是你没用，天/ru下熙熙皆为利来，天下攘攘皆为利往，千万不要高估，自己在别人心中的地位，你所为之付出的，别人未必看得上，你所认为的好关系，其实也是建立在利益的基础之上，你身上如果没有对方看得上的东西，他不会愿意和你来往，有的人长得一副善相，但不一定是好人，有的人当面吃斋念佛，背地里可能坏事做绝，有利可图的时候阿谀奉承，无利可图的时候凶相毕露，所以看人不要只看表象，爱人不要全掏真心，有时候你付出的越多，反倒失去的越多，不是你不够好，也不是你不够真诚，而是你太过真诚了，反而容易被人利用。

# 55: 2条识人术，让你越混越好
