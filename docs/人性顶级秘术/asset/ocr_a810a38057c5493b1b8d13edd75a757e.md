# 11: 厉害女人都戒掉了 3 种弱势思维

真正厉害的女人，不是她有多霸道多强势，而是她早就戒掉了这三种弱势思维，尤其最后一点，简直是王炸。

第一、对金钱的态度决定你的高度，记住你的经济实力，是能让你拥有面对风雨的勇气，不必屈服的骨气，保持自我的志气。你努力赚钱，就不必旱葫芦藤依赖于男人生活。有人会问了，那女人有了钱就一定幸福吗？没错，在同样的境遇里，她肯定比没钱的女人有更多的选择权，钱就是你最大的底气，在婚姻中，女人的成本和男人的成本是不同的，女人婚后意味着要怀孕，生孩子，带孩子，一晃就是 5.6 年时间过去了，而女人最宝贵的青春，也就是 20 岁到 30 岁那十年，而男人婚后除了经济负担上大了一点，其他并没有什么不同，所以一个女人如果把青春都荒废在家庭主，如果找的是个负责任的男人还好，如果是一个喜新厌旧的负心汉，到时你既没青春又没钱，他把你在­一甩，你就傻眼了。

第二、别以为只要你善良，你就一定会有好报，大错特错。对于好人，你的善良他会感恩，对坏人，你的善良就是考验他恶的底线。所以，善良一定要有智慧，才能在这个复杂世界走得更远。

第三、无论你多爱一个男人，都要时刻清醒，你必须要先爱自己，无论这个男人给你多少感动和承诺，你都要明白，这些也都是他一时的行为，男人可以跟你说爱你一辈子，他可以当真，但你不能当真，这个世界没有免费的午餐，别人对你好，也只代表你暂时对他有价值，如果你不能长久带给他价值，那受伤也是迟早的事。永远不要给别人第二次伤害你的机会，有些伤害，只有 0 次和无数次，到了该说再见的时候，不要回头看一眼。
