# 5: 揭秘 7 条职场潜规则，你越早知道越好

1、刚进公司，就拿出 200%的力气，是最傻的行为。你的价值来自对方的期望值，你一上来就拿出 200%的力气，上级领导接下来的期望就在 200%，结果你慢慢累了，放到了 150%，领导就会觉得你懈怠了。反过来，你先从 80%的力气起步，别人的期望值就不高，再慢慢到 100%、120%，反而会让领导觉得你在不断进步、接下来每天都是惊喜。

2、职场中，没有真正的朋友，你千万不要跟同事把关系搞太好，适当保持距离，一味善良，容易被不怀好意的人利用，一定要学会给自己的善良加上条件。「好说话的老实」和「不拒绝的善良」是职场中最廉价的东西，因为你好歹吃而交的“朋友”，就像海浪，你能帮他们时，聚得比谁都快，你找他们帮忙时，散得无影无踪。
