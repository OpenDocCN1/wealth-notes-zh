# 28：人性的善变就在一瞬间

听完下面这段话，这一辈子再也没有人能伤到你。昨天我跟一个朋友去吃火锅，吃完火锅下大雨，我朋友就跟服务员说，能不能借雨伞用一下，服务员一开始不想借，我那个朋友就苦苦的跟他承诺，说你放心，我明天一定要把这个伞还给你。

这个服务员看我朋友这么真诚，于是就把伞借给了他，回路的路上，我朋友把这个服务员一顿夸，这个事过了 5*6 天后，我去朋友家，发现那把伞还在他那里，我说你借人家伞怎么没还回去啊？他说，我在他家吃火锅，吃了 200 块，难道送一把伞不应该吗？我跟你吃火锅花了 200 块，是老板赚了你的钱，这个伞是服务员自己的，你不还了，人家服务员就亏了。

他说我管不了那么多，反正我花那个钱，这个伞就当赠品了。各位有没有看懂人性啊？他借伞的时候呢，对这个服务员感恩戴德，那是绝对发自内心的，但是他第 2 天，又不思还了，把这个服务员抛在脑后，那也是毫不留情，发自内心的感激和毫不留情的遗忘，变化就在一天之间。

人性善变的速度，真是坐着火箭都追不上，这就像你朋友跟你借钱的时候，信誓旦旦的发誓，10 天之内保证还你，像个孙子似的求你，然后到还钱的时候，推三阻四，不理不睬，从孙子直接变大爷，曾经你那个男朋友，单膝跪地，在你面前说我会爱你一辈子，一生一世当牛做马，那一刻，他说的绝对是真心话

但是后来你俩在一起过了 3.5 年，他又遇到了别人，然后就想狠心把你丢下，丢下的那一刻，他也是毫不留情，所以这个世界没有好人和坏人，一切都在于他有
