# 25: 想赚钱，赶紧去失败！

很多人都以为智慧是学出来的，这是错误的，真正的智慧其实是干出来的。你如果成天什么都不做，就在那学学学学。就等于天天不运动就玩命吃，结果全变成垃圾，不说不要学习，而是要清楚学习的目的，是为了让你行动。人真正的智慧，是来自于经历和体验。一个人的子变懂事，说明他经历了背叛和失败，一个人一直很懂事，说明他还没到犯浑的时候。为啥一个男人会贪吃贪喝？是因为他过去好吃的东西吃得太少。为啥一个女孩，仅凭一个男孩的花言巧语，就能够上当？因为她过去谈的恋爱太少，经历的感情太少。经历太少，就一定会犯错。只要人就会有贪吃、贪色、贪玩，这些特点。而人放下的前提是，他已经全部玩够了。人都有欲望，这个欲望靠控制是控制不住的，只能去满足它，当满足了之后，自然会放下，就像小孩玩游戏，你怎么管怎么控制，他还是要去玩，因为他的欲望没有被满足。那为啥一个三四十岁的中年人，不喜欢玩游戏了，因为他从小到大玩够了。所以一个人越是在年轻的时候，越要大量的经历和体验，把他所有那些吃喝玩乐的欲望，全部满足掉。他到中年的时候，就会自动干事业，那些杂七杂八的欲望，就不会再干扰他。相反，一个人年轻的时候，什么都没经历过，中年的时候就要犯大错，年轻时犯的错越多，受的伤越多越好，这样中年之后就不会再犯错，小时候越听话从来不犯错，长大越容易犯大错。人可以晚点成功，但一定要早点失败，经历钱，才能放下钱，经历情，才能放下情，经历失败，才能看淡失败。体验过后，自然看透，你就开始有智慧了，一切的成功，都是无数次的失败积累出来的，所以，趁年轻，赶紧去失败吧！
