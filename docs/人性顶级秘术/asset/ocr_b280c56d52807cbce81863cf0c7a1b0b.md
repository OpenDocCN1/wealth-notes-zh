# 47: 男人娶老婆的秘密

每个男人都希望自己的老婆长得漂亮又善解人意，还勤俭持家，还做得一手好菜，但是很遗憾，法律只允许娶一个老婆。绣针没有两头尖，甘蔗没有两头甜。女人漂亮的下厨房，下厨房的没事业，有事业的没女人味，有女人味的乱花钱，不乱花钱的不时尚，时尚的又不放心，放心的又没法看。她怎么可能样样都占全啊，大哥，差不多就行了。我觉得我们作为一个穷二代，应该永远要感谢那个在你 20 多岁的时候，一直陪在你身边不离不弃的女人。因为 20 多岁的时候，往往是你人生中的最低点。那时的你既没钱又没事业，你啥也没有，啥也不是。而女人 20 多岁的时候，却是她人生中最灿烂的时候，全都交给了你。为什么古代的皇帝，会让第一任老婆做皇后?即使第一任老婆已经人老珠黄，但第一任老婆跟皇帝跟的最久，往往是最靠谱的所以真正最宝贵的人，未必是能力最强的那个人，而是忠诚度最高的人。人生在世，婚姻有时并不是让你你每一天都开开心心，也不能一直体会到激情和爱。很多时候，婚姻甚至是相反的，它会让你厌倦，让你疲劳，怀疑这家庭好像没有什么意义，于是就外面到处花天酒地，一个成熟的男人一定要明白，男人的幸福来自控制自己的欲望。玩弄自己的家庭，在你顺利的时候也许还不是问题，但如果到了人生的低谷，失去家庭你就真的一无所有了。
