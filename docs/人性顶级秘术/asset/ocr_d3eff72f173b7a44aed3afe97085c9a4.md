# 2: 做领导 4 绝技，技技都是必杀技。

第1、洞察人性，当你要对一个人委以重任前，一定要深入的测试他，通过对他辱骂冷落和不公对待，让其最阴暗的内心暴露出来，只有这样才能筛选出，真正追随你的人，然后委以重任，不让他栽跟头，不让他沉浮，你怎么测试出他对你是伪装，还是真心相随。当然，不是叫你对谁都这样测试的，因为大部分人是经不起测试的，但是特别重要的人，必须要测试，比如你找老婆也要测试，谈恋爱时适当让她过点苦日子，看她撑不撑的住，撑不住的就早点再见，好过结婚之后遇到点困难就跑路。
