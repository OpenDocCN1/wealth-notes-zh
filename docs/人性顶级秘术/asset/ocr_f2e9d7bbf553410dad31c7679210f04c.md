# 前方高能，用心聆听！

1、越好听的话，其实越虚伪，下次一定请你吃饭，改天一定联系，有空好好聊聊，你放心，钱过几天就打给你。这些话，都别当真!男女之间更是如此：我配不上你，意思是你配不上我；你是个人好人，意思是你适合做备胎；真的不是因为钱，其实就是因为钱，我们适合做朋友，意思是你是个穷鬼，滚远点，别人不说透，是为了给你留面子，你就不当傻子，如果你提出一个想法，对方没有爽快地答应，那就是拒绝。不要对人和事抱有太多期待，你只要落魄了，身边的人和鬼就都出现了！以十倍速度亲近你的人，会以十倍的速度离开你，大喜大悲看清自己，大起大落看清朋友。

2、如果一个普通朋友突然向你借钱，千万别借，八成是他已经把身边人的钱都借完了，借钱时话说的越动听的，越不能信，因为这说明他已经把借钱练出话术了，如果过去再要钱上不讲信用的人，你千万不要再相信他第二次，伤害过你的人，往往会再次伤害你。

3、交浅言深，人生大忌，你是否遇到过以下不愉快的经历？家里不常走动的亲戚一开口就问你：“买房子了吗？买车了吗？”小区里不熟的邻居一见面就问：“怎么还没结婚啊？怎么还要小孩啊？”“在哪工作？工资多少钱一个月？”你的朋友大都希望你过得好，但不希望你过得比他好。所以，最好的回答方式是：瞎忙，没钱。关系不熟，不要自说自话好为人师，容易被人当傻子。
