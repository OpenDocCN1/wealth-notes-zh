# 第一章 人性人心，识人读心

# 1：揭秘你不知道的 7 个人性真相

第 1、就算是你自己的儿子，你都不能给他太多，没有到临死前，不要去把钱给身边的任何人。爱，要细水长流。一下给太多，你就会失去这个人，这个人只会憎恨你。所以你要做一个带刺的好人吧。

第 2、不要期待被所有人喜欢，任何人osos不会因为你爱他而爱你。他们只会因为你优秀而爱你，人们呢不会雪中送炭，只会对你雪上加霜。：

第 3、不要随便接受别人的礼物。任何一个礼物都有他的目的，除非你能够回馈对方相同的价值。你对于人家那种邀请啊或者是聚会啊，要么假装非常高兴的参加。要么呢就假装非常痛苦的拒绝。

第 4、不公平。很正常，你会因为不公平而愤怒，那是因为你一定不是利益的获得方。你若是个人物，你走到哪里都会有人前呼后拥。你要是个废物。你到哪里去都会有人横眉冷对，凡是那种抱怨不公平的，都是因为你是一个弱者。

第 5、人多的地方，说话一定要小心。也许你谈论的人可能恰恰是对方喜欢的人，不要把你的秘密告诉风，因为风啊会吹过整片森林。不说废话，不讲碎语。有些问题啊，明显知道答案就不要问。比如说你还没有结婚吗？你还没有孩子吗？你还没有买房吗？废话太多，只会证明自己太愚蠢。
