# 7: 人际关系中的陷阱，就是捧杀

比如说，一个人想要来控制你的时候。那么他会贬损其他人，以此来表扬你。举个例子啊，说我特别不喜欢那个人，那个人就特别自大。但是你就不会，你特别的懂事，或者说你特别的温顺。我就喜欢你这样。那当你听到这个评价的时候。
如果认为自己被认可，而感到高兴。不管你是不是他说的那个特质，说你懂事啊，温柔啊，等等...你都不会自觉的被套入到一个逻辑里面，就是如果你希望继续被对方喜欢的话，那么你就必须表现的懂事或者温顺，这时你就进入了一个比较脆弱的位置。当你和对方在一起相处的时候，你就会小心翼翼的经常在想，我有没有表现的更懂事，更温顺，我有没有让对方失望。其实你大部分的痛苦，都来自于你活在别人的标准里，不是说别人的评价就完全不听，但也不能完全听，这里面的关键就是你是否认同于对方这个标准。当对方用这样的方式来夸奖你的时候，你不要掉进这个陷阱里面，所以核心关键不在于别人怎么样评价你。而在于你对自我的评价是怎样的。对方对你的评价，往往来自于她的期待或者说他的幻想。他的评价不论是好的是坏的，其实都没有那么重要，你高兴了就听，你不高兴了就不听，一个人如果能在你面前夸你贬低别人，那么他大概率也会在别人面前夸奖别人而贬低你，你品！
