# 5: 别人家的媳妇，真的更好吗？

很多老爸们都感慨，咳呀妈呀，结结婚早了，你看别人家的媳妇多好啊，停，别吵吵了，我就问你们，别人家媳妇儿，人家脾气好，修养好，气质好，哪来的，是人家老爹们宠出来的？你总觉得别人的女人，是一条靓丽的风景线，那个身材那个姿色，哪来的，拿票子砸出来的？你再看看你，你往你媳妇身上投啥了？光投脾气了吧，你往你媳妇身上砸啥了？光砸盘子摔碗了吧？所以不要看别人家的媳妇儿，你要是有那个能耐，你让别人来羡慕你家媳妇啊，那才叫本事，记住了，什么样的男人打造什么样的女人，你总认为自己的媳妇啰嗦叽叽双双，别的异性都善解人意，但事实上让你反感的那 些啰嗦叽双，都是实实在在的照顾和陪伴，而那些让你 (≈)惬意舒心的，所谓的善解人意，其实都是投你所好。哪个真心过日子的女人，不说几句真话，不发几句牢骚，鸡毛蒜皮的生活必然会让人疲惫，柴米油盐的平淡，总是不让人乏味，可这就是日子，至于那些总说你爱听的，夸你的，奉承你的，对你侧耳倾听的异性，那是因为她还没有和你过到一起。哈叫真正的合适，其实两个人放在一起就好比土豆和西红柿，他本来就不是同一个世界的，但为了走到一起，土豆变成了薯条，西红柿变成了番茄酱。从而成为了绝配，感情也是如此啊，我们每个人都是独立的个体，没有谁和谁是天生一对的，关键看你是否愿意，和他彼此理解和改变。共度浪漫是情不自禁，共过患难才是情深所致。
