# 38: 人际关系潜规则

敌人变朋友，会比朋友更可靠，朋友变敌人，会比敌人更危险。有些事知道了就好，不必多说。有些人认识了就好，不必深交。对任何人都要保留 30%的神秘感。穿着半遮半掩的女子最动人，有悬念的电影最好看。百分百的真心，就会百分百的受伤。不要总想讨好所有人，社交之所以累，是因为你总想表现出自己并不具备的素质。做人不能太方，也不能太圆，太方不懂妥协会伤人，太圆没有底线会被人伤，因此做人要楞圆，从来不知道低头认错的人，基本上一辈子，都生活在错误里。所以，碰到那种很偏执的人，你不用跟他计较，更不用跟他争吵，因为在他的世界里，他永远都是对的。你静静的看他错下去就好，颠倒看人性，逆向看商业。

# 39: 人心如狼，与人交往的 2 个铁律。

1、乞丐会羡慕富翁，但却会嫉妒比他要钱多的乞丐，能伤害你的都不是陌生人，而是身边人的嫉妒，5 年前我花 1 万块钱给我妈买了个手镯，邻居问我多少钱，我还没开口，我妈抢先收 50 块钱，我当时很不理解，事后我妈跟我说，这个世界因为你过得好而开心的人，永远只有极少数，人们来打听有关你的事，只是为了确认你活得比他们差，有句话很经典，我们都希望别人好，但是千万不要比我过得好，这就是人性，你要学会让别人低估你的优点，让敌人高估你的缺点，看到有人摔倒了他会笑着去搀扶，看到别人中彩票，却没有一个人愿意恭喜，你可以表示自己过得很好，但是一定要在后面加上一个不好的点，平衡他人的心态，也是保障自己的安全，如果出国旅游了，回来一定要说导游特别坑，如果你买车了，记得要跟别人说是借钱买的。
