# 05. 重玄

大家大部分都叫聊脱颖而出，我来反向提供团队出现震荡，做的比较失败的细节。主要是从来从自身跟朋友的经历展开。

1、自身经历（遭遇裁员）：主动离职

22 年的时候公司传出了裁员消息，领导也表示公司目前已经到了工资快发不出来了底部。由于那会儿也进入了职场倦怠期，听到消息没有慎重考虑，直接开始找工作，并且很快完成了无缝衔接。1 年多过去了，公司还是活的好好的，很多当初说要离职的同事也一直在职。回顾了下当初其实有点太冲动，也间接导致后续的一些职场危机。就像曹将的分享，这几年离职其实要慎重。
