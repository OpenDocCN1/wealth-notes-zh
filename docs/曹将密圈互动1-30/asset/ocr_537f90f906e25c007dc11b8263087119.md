# 08. 罗罗

刚好这两天有件事让我不吐不快，索性拿出来聊聊这场看似离我们遥远的「老年危机」

昨早上我上班的时候，我们仓保安王叔把我叫住，跟我说了一件让他挺苦恼的事情：他们保安小队长一大早就跟他说，以后每天的工资降10块钱。王叔问：为什么是谁扣的，小队长说：不知道。突然被扣工资，让他很无语，自己也没犯什么错，我说帮他问问。
