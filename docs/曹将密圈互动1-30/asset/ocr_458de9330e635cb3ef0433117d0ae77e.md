# 15. 普来米斯

大家好，我是普来米斯。虽然来曹大星球已经好久，但去年我才应届毕业生参加工作，所以至今才有些职场相关的想法与各位分享。这期的主题是“职场危机”，我想分享的是我所经历的。或许各位会有疑问，为何工作一年就开始有危机了？且听我道来。

# 【背景】

(1) 行业：国家扶持了很久但近几年才产出高质量产品的制造业行业，公司是行业龙头，但行业竞争激烈，技术壁垒不高

(2) 部门：去年新成立的、前沿技术研发相关的部门，部门业务范围包括技术预研、奖项申报和项目申报等。大领导博士毕业，因为业务能力被发掘，后因为做了副总的笔杆子再被提拔，不到十年的时间已经是部门老大，与其他干了十几二十年的大领导们
