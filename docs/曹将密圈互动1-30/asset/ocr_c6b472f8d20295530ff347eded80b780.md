# 05. PeterQiu

下属，缺点，包容。我会将这道题理解为如何建立团队信任。

首先是下属。上下级关系决定了你对下属比对一般的同事有更多的指导义务。指导建议只限于工作，避免让对方觉得你“爹味”太重。指导不要局限于具体工作，更要指导方法论。

其次是缺点。分两个方面，职业道德和能力。职业道德的培养不是一天两天，要像安全工作一样经常强调，而且咱们要对事不对人。能力方面的要求不宜过分拔高，要把合适的人放到合适的位置。

最后是包容。同事之间也讲缘分，并不是每个下属都乐意接受你的指导。一切指导最后的落脚点都是绩效。把控好产出才最要紧。
