# 07.  大可

大家好，我是大可。看到这个话题，想起了毕业后工作第一年：在老家的隔壁区里某政府单位上班。

如果非要抓紧学习什么技能，只有一个，就是：沟通表达。

那个时候是办公室最年轻的一个人，大家真的都特别照顾自己，那时候写材料还算可以。但是自己性格很慢热，甚至很木讷，一般跟着领导区所属的街道、乡镇下乡，或者接待市级、省级、厅级的领导，自己都不太会打招呼和唠嘘。一些工作之后的局，不抽烟、不太能喝酒、那时候也没有驾照，也不太会说客气的话，真的显得“格格不入”以及“不上路子”。
