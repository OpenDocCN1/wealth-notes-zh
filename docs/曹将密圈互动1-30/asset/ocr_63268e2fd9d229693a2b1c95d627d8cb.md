# 13. 琳琳

我只有离职的经验，因此从离职员工的角度来简单说说，从离职原因来分析看：

一如果是地域条件，家庭关系或者是更好的发展机会等客观原因离职的，建议就不要强行挽留了，分手见人品，这种时候就祝福即可，若是可以为其提供更多的帮助那就是遇到一个人品很好的领导了，比如之前有朋友因家远提离职，她的部门领导帮助其联系在家乡本地的分公司面试，同时还帮助其打听即将入职的其他公司工作氛围如何等，这个领导是从心底里想要帮助员工解决问题的，这种领导可遇不可求，需要很大的胸怀和很强的个人能力，因此离职员工也是心里很感激的。

二如果是工资或者工作压力提出离职的，说实话作为一个成熟的职场人但凡提出了离职，那就是经过深思熟虑的，很难去挽留，用提高薪资去挽留这个方
