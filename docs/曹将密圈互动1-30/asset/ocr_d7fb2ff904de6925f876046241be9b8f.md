# 二、梳理防疫工作重点，合理分工

虽然穆姐重心都在小孩身上，很容易迟到早退，但我通过观察，我发现穆姐干单纯的执行动作特别得力。所以我就把防疫物品盘点、发放、办公区消毒检查、餐饮留样等这种不用动脑，只需要去执行的动作分配给穆姐了，这样也节省了我大量的时间。
