# 03. wing 譞棋

恰巧是最近思考的问题，所以，看到这个问题就来分享一下我这边遇到社招新员工的培训想法啦~今天正好加入曹将星球半个月呢憋笑~

+   1. 背景：最近团队正好要新入职一个社招员工，新同事在公司职能序列按任职资格定级为最高级别了。我们 公司体量大概五六千人，本部门人数一千人左右，30%~40%的劳务派遣工，公司组织架构及部门组织架构相对有些复杂。

+   2. 分析：社招员工相对于校招生来说，优势在于会有相关行业、相关职位的多年经验，对于同岗位而言，基本的思考逻辑，做事方法基本已成体系，如果跨行业，可以整合不同行业的经验解决问题；劣势在于有越久的经验，就越有可能会看成定势的思维模式，跳不出相关思维定势。
