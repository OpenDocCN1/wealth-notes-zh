# 3 梳理职责精简工作

去年我们大老板问过我一个 问题：你们团队现在三个人干的活，如果我给你减掉一个，你如何开展工作？当时我的回答是：如果真的不得以出现这种情况，我是能够理解的，毕竟关键时刻【活下去】最重要，工作还是能够正常运转的，只是70分和90分的区别，我会给每个人重新梳理工作职责，进行优化合并重新分配，努力让工作保持正常运转，但是毕竟少个人，可能短期 内也做不到面面俱到，如果短期内指标达成有所波动，也希望公司也能够理解一下。老板挺满意的点点头。
