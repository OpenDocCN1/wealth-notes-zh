# 03. 防止被穿小鞋要避嫌

我有个同事，在晋升评估之前突然被人检举说跟供应商往来吃饭，清正廉洁方面需要公司核实。虽然该同事核实后没有被处罚，但是之后一段时间，也没有被提拔。其实他跟供应商那个人是关系不错的朋友，私交有几年了我们都知道的，在此之前我们都没有注意过这类事情，突然被举报他也觉得很无辜。或许我是幸运的，我从来不跟供应商吃饭或者有工作之外的各种交集，毕竟我是女孩子不方便跟他们抽烟喝酒，另外拿人手短，我必须对公司负责保持我工作的底气，供应商形容我是刀枪不入\ud83e\udd71\u200d\ud83d\udc81或许当我形成这样一种人设，慢慢那种灰色地带的东西和事情就会离自己比较远，不容易被牵扯粘连，行走江湖还是要爱惜自己的羽毛。
