# 01. 陈海生 Hanson

01. 真实的职场晋升，是不需要“相信”的，因为获得晋升的人，就是唯一。就是在竞聘之前，参选的人，都已经知道这个位置是他的，其他人都放弃竞争了。要有这样的实力，才是实至名归，剩下的就是走流程了。

02. 讲个案例：2021 年公司新成立了 A 区域、B 区域，需要在公司内部进行公开竞聘，一共有 3 位项目经理、1 位区域副总来应聘。在开始竞聘之前，3 位项目经理就对我们人事部的同事说：你让 X 总先选吧，他不用竞聘了，他选完，我们再竞聘剩下的区域。

03. 为什么 X 总，在公司有晋升名额的时候，所有人都认为他是不二之选呢？因为之前 X 总，就在公司最大的区域，担任区域副总的岗位，岗位职责、工作内容和片总没什么区别。
