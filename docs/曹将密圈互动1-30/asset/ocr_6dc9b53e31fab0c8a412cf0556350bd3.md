# 能力建设：打造全能多面手

未来的发展面临着很多的不确定性，我忘记在哪本书上面看到，未来需要的是一专多能的复合型人才。而我们仓体量适中且业务链路完整的特点是对全能选手培养的最佳优势，对于我们团队我需要根据每个人的特点发挥长处，并且逐步的补足短板，这样能够让大家在未来的职业竞争中获得更强的竞争力。关于全面能力建设，22 年我已经完成了五分之三，23 年把剩下的五分之二完成，幸运的是放假前跟大家沟通，都还是比较认可且愿意的～
