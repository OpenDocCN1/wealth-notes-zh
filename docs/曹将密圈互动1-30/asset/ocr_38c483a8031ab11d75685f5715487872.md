# 04. 小汪呀

首先，要理解晋升这件事，本身拼的不是谁有多努力，很多人会有一个误区：我之前天天加班，为什么不给我晋升？

职场的晋升永远不是拼谁加班多，晋升意味着升职，升职意味着要从做事的角度切换成管理人的角度，管理人意味着不再是盲目地做好手头的单点事项就够的。关于具体需要哪些点，小汪发现身边的高层身上都有这么4个特质，而这些事情绝不是临时抱佛脚够的，而是需要日常工作中体现。

+   1、向上管理能力：会借力，会向上求助
