# 11. PeterQiu

继续拆题：有效挽留，准备离职，同事或下属。

有效挽留。对方是不是一定要留下来才算有效。未必。挽留是一个沟通的机会，在沟通过程中，我们传递对方的不舍以及继续保持联系的意向也是有效挽留。如果能从沟通中获得有价值的信息就更好了，比如对方离职的真实原因，下一步的规划，等等。

准备离职。有离职的念头和已经找好下家是不同的。对于找好下家这种，只需要沟通工作交接安排；对有离职念头这种，可以和他或她一起梳理目前遇到的困难、解决的办法等等。

同事或下属。对于没有直接管理关系的同事，大可不必“自作多情”，挽留这个工作是他或她的直属领导要去做的。如果关系比较好，可以和他或她一起
