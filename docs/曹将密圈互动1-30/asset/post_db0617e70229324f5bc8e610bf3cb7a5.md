# 01. 罗罗

「曹将和朋友们」2023 年第 23 期密圈互动：“如何在一个团队内，快速获得认同感？”

由小助理星雨先开始。

1. **「不无脑」的真诚。**

真诚是最好的人际润滑剂，但不是「无脑」真诚，什么都掏心掏肺的说。主要是在沟通问题和困难点上，主动分析和思考。直说问题不说答案，或者不说思考过程和沟通过程直接下结论，都是太果断的表现。

具体来说，大家把困难都要在前期的时候沟通好，不要临时在进程中挖挑子，原因是一些前期可避免的客观因素导致的，这种会非常令人反感。同时，需要帮助的时候也一定不要一个人硬撑，需要同事的帮助和上级的支援，一定不要脸皮薄，要「真诚地」说出自己需要哪些具体的帮助，好的团队会发挥出力量的。

2. **积极处理问题，激情态度光环。**

我司有位领导被提拔上来，除了能力之外，个人觉得「激情」是大老板们很看重的一点。尤其是在大环境不好，公司整体运行艰难时期，是很需要这种人的，私下我们都叫他为「鸡血哥」，因为任何时候，他都是信心满满，即使有时候那个目标高得根本完不成，他嘴上也不会说有多困难，讲的都是 “没事，可以完成的！”。

另一方面，是积极的处理问题，这点具体体现在，事情多、事情杂的时候，抵抗住自己的负面情绪，不要为难，产生「就这样吧」的心理，而是表现出，即使知道困难大，自己想勇于尝试的积极心态。且「很主动」的让他人参与进来，并不断主动推动问题的解决。其他会被你的推动力和积极的态度感染，大多数都会配合项目进行，待完成后，无论是本部门还是跨部门的合作，都收获了第一次磨合成功的经验，后续就会有信任感，从而产生很强的认同感。

以上。

看到这个题目，感觉真正有挑战的是需要【快】且得【有效】，刚好结合最近学习的知识启发总结分享三点【心法】，希望对大家有点小启发。

1. **【Yes…and…】是获得认同感的关键公式**

我参加高研院第一课就是用即兴喜剧的方式破冰，其中核心关键点就是 Yes…and…这句话。想要表达的是：你想获得对方的认可与肯定，首先去认同对方，并且顺着对方的建议往下说，这样沟通更加容易持续。我就用了这种方式，组织一个小时的会议，既高效沟通了问题并且输出解决方案和行动步骤的关键点。很多会议沟通不下去，就是别人总想推翻别人的建议，觉得自己的最好，但其实综合大家建议的最终方案可能是最完善且容易推动的。

2. **【不是憋大招而是小胜利】及时行乐很重要**

这是脱不花老师的一个课程内容，给我很大的启发。很多时候刚加入一个团队或者组织的时候，总想着说要憋个大招，因为我们都被「不鸣则已，一鸣惊人」影响了太久了。但其实策划一些小的小胜利效果可能会更好，这是提升信心以及士气，增加影响力的关键。

3. **【我们终其一生不过是要：被看见】加大曝光度不做小透明**

分享日我们教练的一句话，我也不记得出处了，或许不一定100%准确，但我觉得很有道理。有句老话「眼不见，心不念」如果你都不能被看到，更不容易被想起，所以出镜率很重要呀，先被看见才有被认可的机会呢。所以史蒂芬·柯维说【积极主动】是高效能人士成功七要素之一，也不是没道理的。

**干货总结讲完了**

# 02. Hanson

这个问题，要从 2 个人物角色来分析，一是团队新人，二是空降管理者。

**一、团队新人，如何在一个团队里面获得认同呢？**

1. **找到认同的公司。**

面试过程中，对一家公司价值观进行了解，是入职的前提条件。你要找鼓舞人心的公司，令你从企业文化上就认同的公司，那么入职越久，你的行为越会趋向公司的价值观，企业文化也在塑造你。

举个例子，当初我加入现在公司，就是因为认同公司严谨的做事风格，因为我的内心深处就认为做事应该认真负责，细致严谨。所以在公司快速发展的时间里，工作也是舒服的。

2. **展现主动性。**

作为团队新人，一开始承担的可能就是一些简单的基础性的工作，当你无法展示专业价值的时候，充分提供情绪价值，也是你的价值。首要一点，就是展示主动性。领导安排给你的工作，积极承接，积极完成，积极汇报……他觉得这小子不错，下次有重要的工作可以找你，那就算是获得了领导的认可。

哪怕是在会议上，积极回应，也是一种主动性，因为作为会议主持的领导，最怕的就是会议冷场，大家都不发言，会议推进不下去。

所以加入团队之初，多承担一些责任、工作，你付出的是时间，收获的就是团队的认同。

3. **展示独特性。**

每个人都是独特的，都是独一无二的，你有没有想过自己有哪些独特性？我们部门在去年新加入一个同事，他的独特爱好就是研究电脑，包括电脑软件、程序等，结果他就在校招的时候，承担了系统调试的工作。

领导有些时候，不是不想启用你，而是更不知道你有什么独特性，因为你根本就没有展示过。

独特性，也是让你跟别人区分开的标志，这个标志可能是性格，也可能是一个故事或场景瞬间。例如，我们团队的人事专员小琴，她的工作是负责社保和劳动合同签订，平时说话也很小声，做事细致，所以部门会认为她是一个内向的人（先入为主的印象）。结果，有一次团建，部门在KTV唱歌，男同事敬了小琴酒，她直接把一瓶百威啤酒吹干了，还喝了几瓶面不改色。经过这件事之后，我们都记住了她吹瓶子的那个瞬间，都说她是扮猪吃老虎，哈哈，迅速建立了对她的认同。

**二、空降领导者，到了新团队，如何获得下属的认同？**

1. **提供安全感**

作为领导者，到了一个新团队，首先要给团队安全感，安全感会带来认同感，自然促进团队合作。领导起带头作用，无论是做目标任务的时候，身先士卒，还是在开会时，鼓励团队发言，都是在提供安全感，从而来带下属对自己的认同感。

2. **团结同盟军**

就是在团队中团结认同自己的人、有责任感的人，而剔除传播负面、拖后腿的人。

3. **承认会犯错**

在开团队会议的时候，表达自己也会犯错，希望团队成员可以指出自己的错误，自己会加以改正。对于提供建议的人，表示感谢。平时工作中，对团队提供帮助的人，也及时说“谢谢”。

以上两个角度，结合职场的两个场景：

作为新人，找到好公司，展现主动性，展示独特性；

成为领导，提供安全感，承认会犯错，团结同盟军。

祝各位职场生涯事事如意，人人安康。

# 03. Raine

关于认同感，我觉得有两个层面的理解。一是团队对个人的认同，二是个人对团队的认同。

围观各位圈友的回答，大多数基于团队对个人的认同来回答的。个体如何快速得到团队的认可呢？就这一层面，我也先谈谈我的想法。

首先，立人设，贴标签。

每个人都是多元的丰富的个体，但在职场里，我们不妨先给自己提炼几个标签，打造自己的人设。初次见面时可以贴上一些有趣的标签，让别人迅速记住你，比如“擅长做蛋挞”“喜欢新裤子乐队”“爱玩滑板”等。进入到工作中，我们要寻找到自己的闪光点、与别人的不同点，哪怕是微小的不同，并把它往极致努力。比如“有亲和力”“细心严谨”“social 能力强”“excel 小能手”等等这些正向标签。不必刻意打造，而是发掘自己的长板。

再者，让长板更长，拒绝木桶理论。

做到第一阶段的人设塑造，让别人记住自己后，就要不断让自己的长板更长。在高考时，我们要让自己全面发展，哪一科目都不能拖后腿。但在职场里，我们不需要面面俱到，也没有人能做到面面俱到，短板再短都没关系，但要让自己的长板足够长，逐步建立自己的不可替代性。

对于第二个维度，个人对团队的认同，我认为也是很重要的。个人和团队，应该是双向奔赴的。我们不要把自己放的过于卑微，去讨好别人，迎合别人，这并不是健康的关系。我，是否认可团队，团队是否值得我的付出，也是一项考量。团队需要我这一份子，我能为团队做出贡献，同时能获得成长，实现价值。这是最健康最理想的工作状态，希望我们都能实现。

# 04. 小彩

大家好，我是小彩，看到这个问题，我有亲身经历。

作为 hrbp，我在去年9月底接手了新的事业部。在工作初期我非常快速获取业务部门的认同和信任，以便工作快速开展。

想要获得业务的认同，首先要与业务建立信任。

**一、如何快速与业务部门建立信任？**

有以下几个关键工作原则：

- 1. 以业务为导向：将业务发展放在首位，根据业务需求制定人力资源策略。
- 2. 公平公正：在招聘、绩效评估、薪酬福利等方面保持公平公正，不偏袒，不徇私。
- 3. 积极沟通：与业务领导保持积极沟通，及时反馈信息，让他们了解人力资源工作进展。

**二、在建立基础信任以后，该如何获得业务的认同感呢？**

1. **了解业务领导的需求和期待**

我在接手新的事业部之初，跟我的上级领导以及业务领导做了深入沟通，了解新事业部现在业务发展的情况，以及组织和业务领导的需求和期望，明确了我下阶段性的工作重点：人才招聘及培养。

后面也在日常保持通过电话，参加会议，员工不定期交流等方式来了解不同阶段的业务的诉求和期望，以便更好地为他们提供支持和服务。同时会收集业务的痛点，做相信的分析，提出人力建议。

2. **建立良好的沟通机制**

建立良好的沟通机制是获取业务领导认同感的关键，定期向业务领导汇报人力资源工作的进展和成果，让他们了解人力资源工作的重要性和价值。

我之前是经常与业务领导进行面对面交流，只要她在公司，我基本上会与她当面沟通工作进度。当她不在公司时，我就会通过周报，业务经营日报定期向业务领导汇报工作进展、提供详细的数据报告等方式来建立透明的沟通渠机制。

当然，也在交流沟通过程中我也能积极听到业务领导的心声和建议，通过他们反馈我及时调整工作方式及改进措施。

3. **提供有价值的支撑和专业服务**

为了获取业务领导的认同感，需要在具体工作中提供有价值的支持和专业服务。比如为团队招聘的员工、给骨干提供专项培训和发展机会、制定有效的绩效管理计划与监督等。通过这些支持和服务，可以提高员工的工作效率和质量，从而提高业务部门的整体绩效。

4. **参与业务决策讨论过程**

积极参与业务决策过程，为业务发展提供人力资源方面的建议和支持。比如每个月的营销会议中，我会呈现相应的费用率（费用/销售合同比），提醒业务领导关注销售的投入与产出。

总之，要快速获取业务部门的认同感，需要了解他们的需求和期望，建立良好沟通机制，提供有价值的支撑和专业服务，并积极参与业务决策，为业务的发展添砖加瓦，只有这样，才能真正赢得他们的信任和认同。

以上就是我对快速获取业务部门认同感的经验和看法，欢迎大家点赞评论交流。
