# 2. 项目管理能力

初入职场，我毫无项目管理意识，差点误事。

当时老板让我负责一个课程的研发，之前完全没有相关经历，是个小白，还是老板提醒先统计这个课都涉及哪些书籍，然后大致以几天为一个周期，列一下把这些书都讲完需要多久。
