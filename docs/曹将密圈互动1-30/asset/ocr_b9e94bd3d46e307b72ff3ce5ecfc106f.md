# 【协同篇：下班开会的神仙队友】

其实做好计划以及管理自己的精力，都是自律的过程，很重要的一点是如何律他？自己兴冲冲的下班了，同事临近下班找你帮忙，老板下班找你开会，这种神仙同事最头疼。如何避免这类问题呢？直接跟别人说下班之后别找我，就好像不负责一样的。我的处理方式是，我们团队内部我会鼓励大家早下班，没人磨蹭加班也就少了下班找我的可能；对于外部同事，下班之后提需求的，我一般会通过电话了解清楚对方详细信息或者需求，然后告知对方次日或者具体什么时间能够给到回复，当我判断是紧急情况，我会远程对接处理掉。对于下班之后突然邀请我开会的，基本我都是会直接告知对方不好意思，我时间不方便。如果提前预约的，我也会微笑的告知对方，我之后有事
