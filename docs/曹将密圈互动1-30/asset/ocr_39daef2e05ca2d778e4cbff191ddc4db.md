# 2. 给到价值感，是钱，也是荣誉

离职的原因，其实大同小异。要麽钱不到位，要麽是不开心了。当时离开项目组的人，我和 BP 的小姐姐，会安排选一些人回访沟通，当时还和一个 “被气走” 的优秀销售管理吃饭，从她的口里听到了很多一线的真实反馈挺让我吃惊的。吐槽公司的领导开会发言没有温度，薪资制度不合理，把员工当做挣钱的工具等等……除了一些制度的原因，更多还有一些关于人的事情。后面我自己的团队做了两件事感觉挺对的，一是内部原创库和点子墙，所有大家的付出成果只要是原创和被采纳，会有积分奖励，二是去申请了预算，立项的项目会给人力和平台的支持，优秀的有现金和荣誉证书。很多小伙伴也非常乐意去分享，因为真正的有被看到。
