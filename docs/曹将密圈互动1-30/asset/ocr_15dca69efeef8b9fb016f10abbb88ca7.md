# 2 【不是憋大招而是小胜利】及时行很重要

这是脱不花老师的一个课程内容，给我很大的启发。很多时候刚加入一个团队或者组织的时候，总想着说要憋个大招，因为我们都被「不鸣则已，一鸣惊人」影响了太久了。但其实策划一些小的小胜利效果可能会更好，这是提升信心以及士气，增加影响力的关键。

# 3 【我们终其一生不过是要：被看见】加大曝光度不做小透明

分享日我们教练的一句话，我也不记得出处了，或许不一定100%准确，但我觉得很有道理。有句老话「眼不见，心不念」如果你都不能被看到，更不容易被想起，所以出镜率很重要呀，先被看见才有被认可的机会呢。所以史蒂芬柯维说【积极主动】是高效能人士成功七要素之一，也不是没道理的。
