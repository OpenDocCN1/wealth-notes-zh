# 07. 林子

重复性工作的可能性特点: ①做过很多遍，没有新鲜感，没有新意; ②对团队没有特别大的贡献，只能托底，不能引领; ③做多了会产生固定思维，不容易创新。

找到新价值的点: ①重复性工作中固定不变的流程可以转化成成熟的模式，便于工作的委托与转接。如写成指南文档内部分享，一方面是自己工作的实践总结，另一方面便于提前做好工作交接。 ②尝试用一些新的技术或工具改善或优化重复性工作的内容或环节，减少在简单重复性工作上面花费的时间和精力。 ③跳出当前工作的高度，不仅仅是作为工作参与者来做这份事情，如果有一天自己是该项工作的组织者或管理者，会希望得到什么样的结果。比如近期我们要填报一些数据，按照以往的做法可能是去各个平台找数据，然后截图，做 excel 表，这次我们就试着上升
