級點如果前後不足**3 天**（全部是**6 天**），就不是一個**明顯的基本點**，是不能使用的。一個基本點要**6 天**，**連接股價 X 線的兩個點**，當然需要**12 天**了。以前**12 天**剛好是 **2 個交易週**。因此，稱為**二週原則**。現在改為每周交易 5 天，仍然沿用**二週原則**。如果 AB 或 BC 都只有**10 天**如何？只能用來考量附近的短期變動而已。

# ### 7-3 交叉要單純

前面討論過，**股價 X 線**好像蹺蹺板，轉軸只能有一根。太多根就轉不動了。**股價 X 線**和趨勢交叉的地方，最好是一天或兩天，三、四天比較差，如果交叉的地方上下漲跌好幾次，就要打折使用。

初學者常以一個**底**和**遠方的頂**相連，中間會與股價趨勢交叉好幾次，形成好幾個 X。這是不權威的，可打折或配合其他**股價 X 線**使用。
