# 6-4 多條下降 X 線交叉於一點

和上升 X 線 一樣，有時 多條下降 X 線 會交叉於一點。一條 下降 X 線 是一種支撐，股價碰到會上升。兩條下降 X 線 交叉，支撐力量更大，回升更厲害。

不可否認，三條下降 X 線 會產生極強烈的上升。三條下降 X 線 會反轉。
