生反彈。反彈以後，股價又下跌，再一次碰到原來那條 下降 X 線。這一次股價可能不停留，繼續跌下去，也很可能第二次反彈。

假如，股價下跌碰到原來那條 下降 X 線，仍然反彈叫 二次支撐。第三次碰到也反彈，叫 三次支撐。三次支撐會反轉。

# ## 6-6 下降 X 線二度支撐

上升 X 線有二度阻力；下降 X 線有二度支撐。

股價第一次碰到一條 下降 X 線，產升反彈後迅速跌到該條 下降 X 線下方一段相當的距離（譬如 10 % 左右），然後在一個強烈反彈後，股價又迅速回升到該條下降 X 線上方。這是一個不尋常狀況，既然跌破為何又回頭了？莫非多頭硬起來了，或是空頭心虛要認敗了？

衝上原來那條 下降 X 線後，不久，又跌下來了，再次逼近原來 下降 X 線，逼近、逼近，但是，就是不跌破，在原來 下降 X 線上方，停下來了，重新上漲。

這種情形叫 二度支撐。二度支撐會反轉。
