# ## 10-3 股市的陷阱

股市是多頭和空頭鬥爭的場所，也是錢財輸贏的地方。多頭和空頭各使出絕招，務使對方認輸，新臺幣得以落入自己口袋。

人類具貪心本性，且容易受消息左右，加上沒有足夠的漲跌判斷知識，極易落入股市陷阱中。

因此，股市中人，十之八九虧損累累，有人負債跑路，有人憂憤成疾，不可不慎。

股市中，像錢財或股票被盜領，聽信消息錯買或錯殺股票這種陷阱，不是本書研究的主題。

本書具體的以技術性來分析股市陷阱，技術性分析則有股票圖為根據，股友努力學習，陷阱大都可以避開。

以技術性分析可以分為：多頭陷阱和空頭陷阱。

多頭陷阱是多頭跌入陷阱中，股票套牢，日夜操心，最終可能無奈殺出，或融資被斷頭，虧損累累。

空頭陷阱是空頭跌入陷阱中，股票被軋，日夜不安，最終可能無奈回補，或融券被強迫補回，虧損結尾。
