# B. 在空頭市場：

（1）碰到下降 X 線 2 天內沒有上漲，結果會在第 3 天或第 4 天，加速上漲，迅速回升到下降 X 線之上，也就是超出下降 X 線以下的部分屬於超跌，撐不了多久，漲回來還我們吧。

口訣： 超跌快漲回

（2）空頭市場起步時或未期時，大跌若干天，碰到下降 X 線，奇怪的是，第二天只有小漲（譬如漲 3%），這種情形第三天會開始再大跌，空頭市場起步，其下跌幅力很大。空頭市場末期時市場相當恐慌，下降 X 線反應猶豫一些，這也可以理解。空頭市場不輕易買股票，除非確認已到達了。

權威性的 股價 X 線，真正失效的情形很少，可以大膽的使用，十次有九次成功的機會。尤其是周線或月線上權威性的 股價 X 線，其準確性接近滿分。
