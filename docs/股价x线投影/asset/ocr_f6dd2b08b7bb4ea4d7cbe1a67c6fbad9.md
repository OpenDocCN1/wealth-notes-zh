立刻引來更多的賣出。

+   3. 未來景氣將走下坡，多頭只是被眼前榮景迷惑。

+   4. 多頭市場末期，市場已進入瘋狂狀態，任何上漲都會誤以為又要大漲，讓作手有可乘之機。

+   5. 一種股票曾經在多頭市場大幅上漲，反轉轉入空頭市場，歷經相當下跌後的反彈，誤以為漲勢再起。其實空頭市場尚未結束。

# ## 10-11 多頭陷阱形成的近因

多頭陷阱形成的近因有：

+   1. 作手判斷錯誤，想往上拉一段，發現跟進者很少，反手殺出股票，逃之夭夭。

+   2. 作手原來想拉一段，但是，遇到非預料的強大賣壓，資金不足，棄甲曳兵，落荒而逃。

+   3. 在前一盤檔區，作手未能把股票出完，製造假突破，把手中股票倒出來。常用手法是大單漲停板掛進，引誘散戶掛進後，忽然抽掉自己的買單，把貨倒出。

+   4. 作手利用眼前的利多，拉高好放空。
