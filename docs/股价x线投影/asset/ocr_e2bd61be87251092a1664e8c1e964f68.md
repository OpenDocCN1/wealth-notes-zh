# 多頭市場（Bull Market 牛市）

長期上漲大漲小回的市場 績優股小型股輪翻上漲 成交量漸大

# 空頭市場（Bear Market 熊市）

長期下跌股價大跌小反彈的市場 下跌速度快 壞消息出現即恐慌下跌 成交量漸減

投影片 18： 股價長期上漲的市場稱為多頭市場。多頭市場股價變化主要特徵是大漲小回。利空出現，而股價卻跌不下去。利多消息出現時，股價即上漲。新開戶人數不斷增加，新資金源源不斷湧人。除息、除權股票很快地就能填息填權。
當部分投資人開始疑慮，賣出手中持股。空方占主導地位，做多氛圍嚴重不足，稱為空頭市場。空頭市場最大特徵是股價下跌導致接手不積極，成交量萎縮。不時有恐慌下跌。
