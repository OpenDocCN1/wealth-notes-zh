# **7 股價X線**
**權威性試驗**

**股價X線**的最大好處，是碰線即回跌或漲升。

但是，用以連成**股價X線**的**頂點**和**底部**，是否具有代表性，這兩點和碰線位置三點之間的關係，我們仍要加以討論，以免囫圇吞棗。

權威性試驗就是指這條**股價X線**有多大的**權威**，有多**少的可靠性**。和趨勢線一樣，**股價X線**也必須經過權威性試驗，以確認它的可靠性，進而執行買賣。

一條權威性**股價X線**，可以幫您賺到錢，而不權威或錯誤的**股價X線**，可能會導致虧損，豈能不慎。

## 7-1 剪刀原理

剪刀是一種槓桿工具，槓桿構造有三點：

- 施力點（A）：剪刀把手施力的地方
- 支點（B）：螺絲固定處
- 受力點（C）：剪刀刀口

剪刀有三類型：
- 中等的（一般用的，$AB=BC$）
- 省時的（如剪布的，$AB<BC$）
- 省力的（如剪鐵皮，$AB>BC$）

這分類是和 $ABC$ 三點位置有關。

假如，有三條不一樣的**股價 X 線**，它們用以連線的 **AB** 兩點和碰線的 **C** 點之間的關係和三種剪刀相比擬，那麼可以分成三類 **股價 X 線**（見圖 7-1）：

- 第一類 **股價 X 線**：$AB$ 長度等於 $BC$ （$AB=BC$）
- 第二類 **股價 X 線**：$AB$ 長度小於 $BC$ （$AB<BC$）
- 第三類 **股價 X 線**：$AB$ 長度大於 $BC$ （$AB>BC$）

它們權威性依次排列：
- 第一類 **股價 X 線** 最好
- 第二類 **股價 X 線** 次之
- 第三類 **股價 X 線** 最差

雖然第一類比第二類權威，但是，第一或第二類 股價 X 線都可用來買賣股票。至於第三類只要 AB：BC 的比不要太大，例如 5：3 而已，仍然可用。若比達到 5：1 就不好了，達到 10：1 則不能用。

以上 AB 或 BC 至少有 12 天（週線圖上 12 週，月線圖上 12 月，圖上 12 根線就是）

所謂 AB＝BC 並非一天不差，相近即可。參看右表。

## 7-2 二週原則

以上三類 股價 X 線 中，AB 或 BC 的時間都要受二週 原則 的限制。

二週原則 是 AB 或 BC 的時間至少 2 週。（12 根日 線），週線圖上至少 12 週，月線圖上至少 12 月，圖上至 少要 12 根線 的意思，多一些更好。

二週原則 其實是用以 保證基本點明顯 而已。一個次級點如果前後不足**3 天**（全部是**6 天**），就不是一個**明顯的基本點**，是不能使用的。一個基本點要**6 天**，**連接股價 X 線的兩個點**，當然需要**12 天**了。以前**12 天**剛好是 **2 個交易週**。因此，稱為**二週原則**。現在改為每周交易 5 天，仍然沿用**二週原則**。如果 AB 或 BC 都只有**10 天**如何？只能用來考量附近的短期變動而已。

## 7-3 交叉要單純

前面討論過，**股價 X 線**好像蹺蹺板，轉軸只能有一根。太多根就轉不動了。**股價 X 線**和趨勢交叉的地方，最好是一天或兩天，三、四天比較差，如果交叉的地方上下漲跌好幾次，就要打折使用。

初學者常以一個**底**和**遠方的頂**相連，中間會與股價趨勢交叉好幾次，形成好幾個 X。這是不權威的，可打折或配合其他**股價 X 線**使用。

## 7-4 基本點要明顯

畫**股價 X 線**的基本點愈明顯愈好。

不明顯的基本點不要勉強使用，但是，電腦圖經過放大或壓縮，改變了基本點的**原始模樣**。電腦圖放大時，不明顯的基本點會變明顯，造成誤判。電腦圖壓縮時，明顯的基本點卻看不出來了，反而不知要畫 **股價 X 線**。如此這般，擾亂了判斷。

還是自己用半對數圖紙畫一些圖，不足部分再用電腦圖補充，比較實際。

## 7-5 其他試驗

**股價 X 線**除了受**剪刀原理**、**二週原則**、**交叉要單純**、**基本點要明顯**考驗外，尚須注意：

- （1） **空頭市場和多頭市場基本點互連**，特別權威。
- （2） 在同一**型態個變動**，如楔形、三角形、小幅盤局的基本點不要互連，連起來的 **股價 X 線** 不權威。好像親族不婚配一樣。即使勉強連起來，也只能考驗附近變動而已。

經過這些權威性試驗，您就可以確認一條 **股價 X 線** **可靠性**了。然後，據此以執行您的買賣，勝算很大。

## 7-6 失效情形

股價 X 線 也有極少數失效情形，這些不外：

### A. 在多头市场：

（1）碰到上升 X 線 2 天内沒有回跌，結果會在第 3 天或第 4 天，快速下跌，一旦下跌會迅速跌至原來上升 X 線之下，也就是超出上升 X 線以上的部分屬於超漲，撐不了多久，跌回去還人家吧。

口訣：超漲快跌回

（2）多頭市場起步時，大漲若干天，碰到上升 X 線，奇怪的是，第二天只有小跌（譬如跌 3 %），這種情形第三天會開始再大漲，多頭市場起步，其上漲潛力是很大的，這可以理解。

（3）基本點 不明顯、不符合 剪刀原理、二週原則，這種失效不能怪 股價 X 線 失效。

（4）未使用半對數紙。方格紙股票圖碰到 股價 X 線 時間不對。這是圖紙問題，非 股價 X 線 失效問題。

### B. 在空頭市場：

（1）碰到下降 X 線 2 天內沒有上漲，結果會在第 3 天或第 4 天，加速上漲，迅速回升到下降 X 線之上，也就是超出下降 X 線以下的部分屬於超跌，撐不了多久，漲回來還我們吧。

口訣： 超跌快漲回

（2）空頭市場起步時或未期時，大跌若干天，碰到下降 X 線，奇怪的是，第二天只有小漲（譬如漲 3%），這種情形第三天會開始再大跌，空頭市場起步，其下跌幅力很大。空頭市場末期時市場相當恐慌，下降 X 線反應猶豫一些，這也可以理解。空頭市場不輕易買股票，除非確認已到達了。

權威性的 股價 X 線，真正失效的情形很少，可以大膽的使用，十次有九次成功的機會。尤其是周線或月線上權威性的 股價 X 線，其準確性接近滿分。
