# ## 10-8 廣義的多頭陷阱 （看不見的陷阱）

股價一路大漲，碰到**上升 X 線** 的價位，是廣義的多頭陷阱。

股價上漲，碰到日線圖上的 **上升 X 線** ，會在當天或第二天就會下跌，買進立即見到套牢。是非常明確的多頭陷阱，而且事先即可預知。但是沒有畫 股價 X 線者，則一無所知，不知何處有陷阱？

![](bbox=[0.54, 0.36, 0.93, 0.59])

股價上漲，碰到週線圖上的 **上升 X 線** ，會在當週或第二週下跌，買進下週即見到套牢。

股價上漲，碰到月線圖上的 **上升 X 線** ，會在當月或第二月下跌，買進下月即見到套牢。

多頭在股價上漲，碰到 **上升 X 線** 時，買進股票都會下跌，立刻套牢。因此，股價接觸到 **上升 X 線** 的價位，就是一個多頭陷阱，雖然那裡沒有複雜交易區，也沒有一個看得見的坑洞。

在日線圖上，股價上漲接觸到 **上升 X 線** 價位，是一個小陷阱。
