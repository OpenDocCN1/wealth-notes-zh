# 10-12 空頭陷阱

空頭陷阱是空頭放空後，處於被軋空不能獲利的狀態。也就是空頭處於套牢。和多頭踏入陷阱一樣，也要緊急服下藥方（take his medicine），解決此問題，退出觀望，等待情勢明朗。下降 X 線是最明顯的空頭陷阱，沒有畫下降 X 線的人，根本不知道陷阱在何處。

長期空頭市場進行中，放空者每賣必賺，因為慣性，所以碰到下降 X 線時，當然也就賣下去，因為當時是證券市場氛圍最壞，利空最多，人心最脆弱時，不賣更待何時。可是下降 X 線是供需改變之處，反轉的地方（右上圖），也是空頭陷阱所在。

另一個空頭陷阱是破底翻（右圖），股價碰到權威的下降 X 線後，沒有立刻大漲。盤旋打底後破底，再碰到一條小的下降 X 線，空頭市場戛然而止，空頭正在等待暴利來臨，殊不知已踏入空頭陷阱矣。
