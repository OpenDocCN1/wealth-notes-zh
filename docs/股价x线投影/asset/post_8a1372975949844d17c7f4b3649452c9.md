## 5 畫上升 X 線

### 5-1 上升 X 線畫法

上升 X 線是一條直線，幾何學說兩點可畫一直線。要畫出上升 X 線，首先需要確認兩個點：一個是底部，一個是頂點。底部和頂點在股票圖上類似波谷和波峰，是連接各種線的基本點。

上升 X 線的畫法是：底連頂

- （1）一個底部跳過一個頂點和底部，和右上方的另一個頂點，以直線相連接（圖 5-1）。
- （2）一個底部跳過數個頂點和底部（或叫翻山越谷），和右上方的另一個頂點，以直線相連接（圖 5-2）。

以上兩者，交叉點要單純，否則權威性打折。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_81_0.png)

**圖 5-1 上升 X 線畫法。** 上升 X 線畫法是底連頂（至少跳過一個頂和底）。口訣：底連頂，底 A 跳過頂 D 與底 E 和頂 B 連。並須延長一倍以上，以備未來股價碰到這條線時，賣出股票。日線圖至少延長半年；周線圖至少延長五年；月線圖至少延長十年。周線圖及月線圖角度平緩者，可以延更長。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_82_0.png)

**圖 5-2 上升 X 線翻山越谷畫法。** **底連頂**，但是，也可以跳過數個頂和底，不過交叉點要單純。底連頂畫出的上升 X 線要延長一倍以上，以備未來股價碰到這一條線時，賣出股票。

簡單的講，**上升 X 線是底連頂**，不過，底和頂之間至少要間隔一個（也可以很多個）頂和底。

上升 X 線與**股價趨勢**交叉畫出，但是，**交叉點要單純**，交叉點複雜效用打折。

### 5-2 上升 X 線的作用

—— 2 天內回跌

一條上升 X 線畫出後，下一次股價若上漲，碰到上升 X 線，股價會在當天或第二天下跌（圖 5-3）。所謂碰到上升 X 線可能一毛不差，通常超出 3 % 是容許的。

這是上升 X 線最大的特色。準確率 99 %。

但是，這並不是說上升 X 線畫好在那裡，股價就一定會漲去碰，一條很陡的上升 X 線，股價也許永遠碰不到。碰不到的上升 X 線，暫時畫在那裡，也沒有什麼損失。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_83_0.png)

**圖 5-3 上升 X 線作用：** 股價上漲碰到上升 X 線會在當天或第二天下跌。即股價上漲碰到上升 X 線二天內會下跌。

### 5-3 上升 X 線如何使用

上升 X 線使用，因空頭市場或多頭市場而不同：

- (1) 在空頭市場，上升 X 線是反彈的極限。
  - 通常在碰線當天便會下跌，而且會下跌甚多。
  - 假定您是搶反彈的多頭，應在碰線當天出貨，出貨後不必急忙補回。
  - 假定您是空頭，在碰線當天或第二天加碼放空，同時在賣出價上面 10 % 地方作停止損失委託，此後靜觀股價下跌即可。
  - 如果您是空手者，切勿在碰到 上升 X 線 時買進，什麼時候碰到 上升 X 線，都不要買進。應另尋求時機，譬如碰到 下降 X 線 時。
- (2) 在多頭市場，股價碰到 上升 X 線，會在當天或第二天回跌，通常回跌 5～10 % 左右。
- (3) 在多頭市場或空頭市場不明時，無論如何，股價碰到 上升 X 線，賣出股票總是沒錯。然後等待碰到 下降 X 線 時買回。

### 5-4 多條上升 X 線交叉於一點

一個砲兵營，不會把十幾門大砲，全部擺在一個地方，而是分散在各地的砲陣地中。但是，它們可以同時朝一個目標發射，命中目標於一點。有的時候，遠近不同的兩條或兩條以上的 上升 X 線，會交叉於一點，該點好似多門大砲標的（125 頁投影片 103）。

一條 上升 X 線，本來就是一種阻力，股價碰到會回跌。兩條 上升 X 線交叉，阻力更大了，股價碰到交叉點，回跌劇烈。若有三條 上升 X 線 交叉，股價碰到交叉點，回跌非常嚴重，並有反轉的可能。

### 5-5 上升 X 線二次阻力和三次阻力

股價一路上升，碰到一條已經建立的 上升 X 線，會產生回跌。回跌後股價可能鼓足勇氣往上挺升，再次碰到原來那條 上升 X 線（冤家路窄），這一回股價很可能衝過去，也很可能再次跌下來。

假如，股價第二次碰到原來那條上升 X 線，仍然回跌，我們叫它二次阻力。而股價第三次碰到原來那條上升 X 線仍然回跌，我們叫它三次阻力。三次阻力股價會反轉。

### 5-6 上升 X 線二度阻力

二度阻力與二次阻力略有不同。

二度阻力可看成二次阻力的變形，前面談到二次阻力可能失敗，股價快速上衝，使原來那條上升 X 線落在股價下面了。

但是，一條有權威的上升 X 線不要輕易放棄，把它延長，靜靜等待。

股價有可能在一次較大的回跌之後，重新跌到原來那條上升 X 線的下面。不久，股價反彈上升，再次碰到原來那條上升 X 線，遭遇阻力而過不去，結束反彈，此種情形叫二度阻力。二度阻力股價會反轉。

### 5-7 B 型上升 X 線

上升 X 線是底和頂相連（至少間隔一個頂和底），是向右上方傾斜的，這是正統上升 $X$ 線。

另有一種上升 $X$ 線，它的底比頂高，畫出上升 $X$ 線是向右下方傾斜的。

向右下方傾斜的上升 $X$ 線，和下降 $X$ 線是會混淆的，因此另外命名為 B 型上升 $X$ 線。

### 5-8 很多股票碰到上升 $X$ 線

在同一時間，很多種股票碰到上升 $X$ 線（譬如有 20 %）。這會造成一種氣勢，尤其是領導股和熱門股，有一大半碰到上升 $X$ 線，這種情況顯示，大勢會有明顯回跌，也有可能反轉進入空頭市場。

### 5-9 利用上升 $X$ 線決定多頭市場終點

利用上升 $X$ 線決定多頭市場終點的方法：

1. 周線圖上碰到一條或一條以上權威的上升 $X$ 線。
2. 月線圖上碰到一條上升 X 線。
3. 日線圖股價碰到三條上升 X 線的交叉點。
4. 日線圖發生三次阻力或二度阻力。
5. 日線圖碰到一條由多頭市場起點，和多頭市場第一階段上升之後，中級回檔的中心點，所連成的上升 X 線。此點不容易懂，示範如下（圖 5-4）：

一張股票圖可畫多條上升 X 線，每一個底都要設法找一個頂去連，除非連起來是不權威的。股票圖愈長，能連出上升 X 線愈多。所以股票圖太短，對 股價 X 線 分析是不利的。像奇摩股市上的股票圖就太短，而且非半對數圖。以前的財訊快報盤後系統股票圖最好，只可惜現已停止運作，希望能恢復。

宏達電周線圖 X2 X3 交叉在 C2，此價位是 1300 元，當時一股賺 70 元，吸引很多人買進，可是有 2 條上升 X 線交叉，告訴我們會反轉，是賣股票的最佳點位。上升 X1 線在 C1 碰到，回跌幾周後因為業績實在好，又漲上去。一旦反轉，會迅速跌至 X1 下方。口訣：超漲快跌回。
