假如，股價第二次碰到原來那條上升 X 線，仍然回跌，我們叫它二次阻力。而股價第三次碰到原來那條上升 X 線仍然回跌，我們叫它三次阻力。三次阻力股價會反轉。

# 5-6 上升 X 線二度阻力

二度阻力與二次阻力略有不同。

二度阻力可看成二次阻力的變形，前面談到二次阻力可能失敗，股價快速上衝，使原來那條上升 X 線落在股價下面了。

但是，一條有權威的上升 X 線不要輕易放棄，把它延長，靜靜等待。

股價有可能在一次較大的回跌之後，重新跌到原來那條上升 X 線的下面。不久，股價反彈上升，再次碰到原來那條上升 X 線，遭遇阻力而過不去，結束反彈，此種情形叫二度阻力。二度阻力股價會反轉。
