忽然，股價以極高的成交量，衝出上限的阻力線。圖形分析者誤以為，又是新一段漲勢的開始，立刻買進。原來在高價區賣掉，自以為高明的人，現在發現沒有那麼聰明了，這種股票比想像的還好，趕快追上去買回來。另有些錯過上一段大漲，心一直癢癢者，鼓起勇氣，就買下去了。一些放空者，更是急急忙忙的補回來。

所有這些買進的股票，大多由陷阱的設立者(作手大戶)供應，因為成交量很大，一兩天就換手完畢，股價立刻下跌，所有買進的多頭，**均被陷阱捕獲了**。

**被捕獲的多頭愈多，回頭愈快**。

# # 10-6 多頭陷阱會跌多少

多頭陷阱短時間會有 **10~25 %** 的回跌，而且接著有 **25~50 %**的主要下跌。

並非每次突玻一個盤檔區，都是陷阱。有些突玻，確實會往上再漲一段。但是，突玻時若**成交量高得離譜**，或當股價回頭時，在上限支撐不住，就是一種警訊，等到連下限也跌破時，陷阱已經很明顯了。
