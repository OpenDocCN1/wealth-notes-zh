轉初期，因股市暴漲後，類似房子失火，大家搶著要衝出去，造成的恐慌下跌，叫**初期恐慌下跌**。

空頭市場末期，因壞消息不斷出籠，造成投資人信心崩潰的恐慌的下跌，叫**末期恐慌下跌**。

# # 11-8 初期恐慌下跌

初期恐慌下跌發生在空頭市場第一階段，也是承接多頭市場頂點反轉型態而來。

+   ▲ **遠因**

多頭市場末期，股價瘋狂上升，成交量大幅度增加多頭有過飽和現象，埋下危機。

+   ▲ **起源**

空頭市場初期恐慌下跌，凡在多頭市場末期狂飆的股票，已經連續衝過好幾條權威的**上升 X 線**，彷彿上升 X 線及一切指標都失靈。

這時，一旦反轉，即會恐慌下跌。

而一般程度上漲的股票，大都在完成反轉型態後，才開始恐慌。
