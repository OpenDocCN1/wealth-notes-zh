▲ 下跌特色 初期恐慌下跌，下跌速度非常迅速，中間反彈有限。

▲ 成交量 比多頭市場少得多，但不是極端的少。

▲ 尾聲 當股價下跌有三成以上，完成反轉型態的最小測量，週線圖上有權威的下降 X 線線碰到時，初期恐慌下跌會結束。

▲ 操作

（1） 利用 上升 X 線 確定多頭市場終點（第 100 頁），賣出你所有的股票，離開股票市場遠遠的。

（2） 若未能在多頭市場頂點賣出時，則在向下跌破一
