# 10-4 多 頭 陷 阱

股市**多頭陷阱**並非一個單獨的型態，或是一個如前所述，看得見的坑。

凡是使多頭買進後，立刻見到虧損，處於不能獲利的狀態，這個交易區或買進價，都叫多頭陷阱。簡單的說就是：使多頭上當被騙的一種買進 叫多頭陷阱。

多頭買進股票，是希望買進後上漲獲利，最好買進後立刻上漲，漲得愈快愈好。但是，事與願違，買進後不只沒有上漲，還立刻下跌，讓多頭大失所望，寢食難安，非常不愉快，有強烈被騙的感覺。

原來，買進股票的人，落入**多頭陷阱**了。**多頭面臨非常危險狀況，若不立刻處理，後果可能極為嚴重**。

# 10-5 狹義的多頭陷阱

狹義的**多頭陷阱（Bull Traps）**是指，股價已經有相當的上漲了，漲到了令人討厭的高價，然後在一個狹窄的範圍上上下下，交易一段時間。此交易區的上限可視為阻力線，下限可視為支撐線。
