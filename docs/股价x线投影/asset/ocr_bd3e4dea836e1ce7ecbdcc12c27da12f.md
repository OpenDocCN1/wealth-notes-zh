# 7-6 失效情形

股價 X 線 也有極少數失效情形，這些不外：

# A. 在多头市场：

（1）碰到上升 X 線 2 天内沒有回跌，結果會在第 3 天或第 4 天，快速下跌，一旦下跌會迅速跌至原來上升 X 線之下，也就是超出上升 X 線以上的部分屬於超漲，撐不了多久，跌回去還人家吧。

口訣：超漲快跌回

（2）多頭市場起步時，大漲若干天，碰到上升 X 線，奇怪的是，第二天只有小跌（譬如跌 3 %），這種情形第三天會開始再大漲，多頭市場起步，其上漲潛力是很大的，這可以理解。

（3）基本點 不明顯、不符合 剪刀原理、二週原則，這種失效不能怪 股價 X 線 失效。

（4）未使用半對數紙。方格紙股票圖碰到 股價 X 線 時間不對。這是圖紙問題，非 股價 X 線 失效問題。
