# △ 操 作

+   （1） 股價脫離上述八種型態的下限，假定你有股票，立即賣出，並且加碼拋空。

+   （2） 中途不要隨便搶反彈。

+   （3） 下跌幅度接近 50%，中途已有次級反彈，且周線及月線圖上有權威**下降 X 線**碰時，補空，並準備作多。

+   （4） 注意政府基金進場。

+   （5） 注意國安護盤基金進場。

+   （6） 注意國際恐慌指數已創高。

末期恐慌下跌結束之後，空頭市場即將結束，股價碰到周線圖上或月線圖上權威的**下降 X 線**後，開始買進股票，選擇股票方式以空頭市場跌最多（要判斷會倒閉否），成交量少，周線圖上或月線圖上有權威的**下降 X 線**碰到者，如果股價一時跌破權威的**下降 X 線，未來漲起來更迅速、更多！還可能恐慌上升！**
