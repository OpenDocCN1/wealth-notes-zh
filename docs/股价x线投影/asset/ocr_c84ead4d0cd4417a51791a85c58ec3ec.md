# 3-2 如何命名

股價 X 線 命名的理由有二：

+   （1）股價 X 線 具有神秘的力量，能精確透視股價反轉位置，彷彿 X 光可以透視肉眼所看不到的地方。

+   （2）股價 X 線 作圖時，係以頂和底，或底和頂連接，和股價趨勢交叉畫出，類似英文字母 X（畫法詳見後面數章）。

# 3-3 股價 X 線的區分

股價 X 線 分為 上升 X 線 和 下降 X 線 。

上升 X 線 畫法是底連頂，但是至少間隔一個頂和底；

下降 X 線 畫法是頂連底，但是至少間隔一個底和頂。

以上這樣講，讀者當然不明白，本書目的乃是針對讀者的困惑，加強投影解說，直到讀者完全明白且熟練為止。

讀者若能畫出權威的 股價 X 線，並據以買賣股票，十次有九次成功的機會。這一點筆者是敢肯定的。
