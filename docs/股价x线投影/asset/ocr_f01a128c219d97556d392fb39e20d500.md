# 10-7 誤入多頭陷阱如何解決

被陷阱捕獲的短線投資者，面臨痛苦，必須以最快的速度 **服下藥方（take his medicine）**，解決此問題，退出觀望，等待情勢明朗，**也就是立刻停損賣掉股票**。

長線投資者，必須在這個價位上，嚴格的檢視長線的股票圖、公司的前景、稅賦費用及景氣的循環。如果有利於公司，投資者可以選擇 *留在陷阱中 (stay in)*，*焦急的期待於陷阱外 (sweat it out)*。

*sweat it out* 這句話真是傳神，也是大部分套牢者的寫照。如果選擇留在陷阱中，未來的命運，還是不能由落入陷阱者決定，**被陷阱捕獲的可憐者！最終命運和前面所說的螞蟻有何不同？**

股票一旦下跌，往往不知伊於胡底？斷頭者有之；股票下市者有之，股民不得不想方設法避開，這也是本書出版的目的。
