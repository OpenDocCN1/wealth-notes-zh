# # 9-6 決定成交量刻度

成交量和價格是並存的，缺一不可。

成交量不採用半對數刻度，而採用相等刻度或方格紙刻度。請參閱下面二圖來訂價格和成交量刻度。如果股票圖只是用來畫股價X線，成交量不必畫出也沒關係，可以節省時間。不過極高成交量或極低成交量，有它技術性的意義。在頂點，高成交量是反轉信號之一。
