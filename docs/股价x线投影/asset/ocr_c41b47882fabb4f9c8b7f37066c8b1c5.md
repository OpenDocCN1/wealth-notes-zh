# # 2 證券市場漲跌

**證券市場** 是現代金融體系的重要組成部分。證券市場通過證券信用的方式融通資金，透過證券買賣引導資金流動，促進資源配置優化，推動經濟增長，提高經濟效率。

證券市場投資人除了領股息外，也希望藉由股票漲跌，獲取股價漲跌差額。因此，如何知道**股票要漲或要跌**，變得非常重要。自有股票買賣以來，各方神聖，無不窮盡辦法，去預測股票漲跌。但是，難有絕對把握。

本書作者在 **1979** 年發明 **股價 X 線**，提供投資人一種比較具體的，股票漲跌預測法。經過 **30** 幾年國內外證券市場印證，**股價 X 線** 分析股價趨勢轉折點，有相當價值。除了基因控制的生存本能外，任何知識都要經過學習。學習有精通與粗略，像股票漲跌知識粗略不得。愈快精通愈好。

作者十幾年來，時常開設 **股價 X 線精修班**，指導股友。當然還有相當多的讀者不能參加，今將精修班電腦投影片整理，除了不能演示動畫以外，投資人可用很少代價，透過本書加速學習。投影片的紙本發行，算是一種創舉。

深盼投資人善用本書，加速學習 **股價 X 線**，期能立足股市，減少常常套牢的 **股海之苦**。
