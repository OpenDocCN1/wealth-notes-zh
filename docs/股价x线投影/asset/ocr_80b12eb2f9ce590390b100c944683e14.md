# 3-4 股價 X 線的作用

一條 上升 X 線 畫出後，下一次股價上漲，碰到這一條 上升 X 線，會在 當天或第二天 回跌。

周線則會在 當周或下周 回跌。 月線則會在 當月 或 下月 回跌。

一條 下降 X 線 畫出後，下一次股價下跌，碰到這一條 下降 X 線，會在 當天或第二天 上漲。

周線則會在 當周或下周 上漲。 月線則會在 當月 或 下月 上漲。

# 3-5 上升 X 線的使用

在多頭市場，股價碰到 上升 X 線，會在當天或第二天 回跌，通常回跌 5~10%。周線則會在當周或下周回 跌。月線則會在當月或下月回跌。 上升 X 線用於賣出。

在空頭市場，上升 X 線是反彈的極限。

在多頭市場或空頭市場不明時，股價碰到 上升 X 線 賣出股票，必然沒錯，回檔後再補回。
