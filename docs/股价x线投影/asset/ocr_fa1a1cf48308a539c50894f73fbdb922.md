# 保護性停止損失委託

在買進價之下 $10 \%$ 設下

+   * 股價上漲一段後把停損價提高
* 直到碰到權威性的X線賣出
* 尋找下一次買進機會 $\Rightarrow$ 下降X線

# 逐次的停止損失委託

+   * 股價碰到X線仍不停止
* 股價走到可以獲利 的地方
* 已出現高成交量
* 一檔股票已進入狂飆
* 不能達目標但已搖搖欲墜
