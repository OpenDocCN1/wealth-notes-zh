# 8-6 交叉愈單純愈好

股價X線必須和股價趨勢交叉，股價X線好像一個蹺蹺板，交叉點好像蹺蹺板的轉軸，蹺蹺板的轉軸只能有一根，如果有好幾根轉軸，蹺蹺板是轉不動的。

股價X線交叉點不要太複雜，愈單純愈好，最好成一天交叉，超過三天就不好。因為交叉區太複雜時，支撐阻力已在複雜區改變了，股價X線沒有那麼準確了。

# 8-7 股價X線理論根據

股價X線是支撐和阻力的一種特殊狀況，一種斜的支撐和阻力。阻力演變成上升X線，支撐演變成下降X線。

不論上升X線或是下降X線，它們比一般支撐和阻力更明確，也更敏感些。只要在碰到股價X線的當天或第二天就會產生作用。

這好比一個從高處落下的皮球，碰到水平的地面和碰到傾斜的地面，反跳的方式不一樣。碰到水平的地面，只單純往上彈；碰到傾斜的地面，不止往上彈而且瞬間往旁邊跳開，比較敏感。您對股價X線有興趣了嗎？
