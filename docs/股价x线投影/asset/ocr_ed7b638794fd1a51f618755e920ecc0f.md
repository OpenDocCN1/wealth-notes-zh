# 挑戰司馬庫斯古道 ——來回要走20小時 單程要2天

司馬庫斯古道西起司馬庫斯部落，東至鴛鴦湖邊的100線林道，總長約20公里。司馬庫斯古道的山徑，翻山越嶺，是一段艱苦行程（見好詞：一剪梅）。

![](bbox=[0.76, 0.17, 0.94, 0.34])

早期物資缺乏，當地原住民必須利用這條古道，從新竹深山走到宜蘭，補充生活所需。

司馬庫斯古道少有人走，只見登山愛好者。正因為人少，這條古道才得以保持著原始自然環境，給與大自然愛好者的挑戰場所。讀者走一趟，舒展身心！

# 鴛鴦湖

位於新竹縣斯烏庫斯溪所在流域，亦是該溪主流塔克金溪的主要湖泊。海拔1670公尺的鴛鴦湖，所延伸的區域，包含了湖泊區3.6公頃，沼澤地2.2公頃及中華民國政府所規畫的天然檜木林保留區360多公頃，合計面積達374公頃，稱為鴛鴦湖自然保留區。
