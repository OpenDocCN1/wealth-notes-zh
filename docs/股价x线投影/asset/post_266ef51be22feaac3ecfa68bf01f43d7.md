## 6 畫下降 X 線

### 6-1 下降 X 線的畫法

下降 X 線是一條直線，幾何學說兩點可畫一直線。要畫出下降 X 線，首先需要兩個點：一個是頂點，一個是底部。頂點和底部在股票圖上類似波峰和波谷，是連接各種線的基本點。

要先確認頂點和底部，才能畫出下降 X 線。

下降 X 線的畫法是：頂連底

1.  一個頂點跳過一個底部和頂點，和右下方另一個底部，以直線相連接，並延長一倍（圖 6-1）。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_131_0.png)

圖 6-1 下降 X 線畫法。頂 A 跳過底 D 和頂 E，與底 B 相連。口訣：頂連底（至少間隔一個底和頂），並須延長一倍以上，以備未來股價碰到這一條線時，買進股票。日線圖至少延長半年；周線圖至少延長五年；月線圖至少延長十年。周線圖及月線圖角度平緩者，可以延更長。

2.  一個頂點跳過數個底部和頂點（或叫翻山越谷），和右下方另一個底部，以直線相連接，並延長一倍以上（圖 6-2）。但是，交叉點要單純，否則無效。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_132_0.png)

圖 6-2 下降 X 線的畫法。口訣：頂連底。頂 A 跳過數個底與頂，和底 B 相連，並延長一倍以上，注意交叉地方要單純。

簡單的講，下降 X 線是頂連底。頂和底之間至少要間隔一個（也可以多個）底和頂。

下降 X 線與趨勢線交叉畫出，但是，交叉點要單純就對了，交叉點複雜，權威性打折。

### 6-2 下降 X 線的作用

#### 2 天內上漲

一條下降 X 線畫出後，下一次股價若下跌，碰到下降 X 線，股價會在當天或第二天上漲（圖 6-3）。周線和月線在當周當月或第二周第二月上漲。所謂碰到下降 X 線可能一毛不差，通常股價向下超出 3% 是容許的。

這是下降 X 線最大特色，準確率 99%。

但是，這並不是說下降 X 線畫好在那裡，股價就一定會跌下去碰。一條很陡的下降 X 線，股價也許永遠也碰不到。我們只說碰到會漲，但不一定會去碰，特別澄清。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_133_0.png)

圖 6-3 下降 X 線的作用：股價碰到下降 X 線會在二天內會上漲。

### 6-3 下降 X 線如何使用

下降 X 線的使用，因多頭市場或空頭市場而不同。

1.  在多頭市場，下降 X 線（通常是 B 型下降 X 線）是回檔的最低價。碰線當天或第二天，股價便開始上升，而且會上升很多。
    - 假定您是空頭，應在碰線當天補空並翻多，切勿再觀望，最差操作者會在此放空，立即被軋空。
    - 假定您是多頭，在碰線當天加碼買進，並在買進價下方 10%，作停止損失委託即可。
    - 空手的人，可以在此時買進，順利上轎。

2.  在空頭市場，股價碰到下降 X 線，會在當天或第二天反彈，通常反彈 5～20%。
    
    反彈幅度依敏感度及下跌幅度而定。
    - 假定您是空頭，應在碰線當天或第二天回補一些，反彈上升後再放空。
    - 假定您是多頭，在碰線當天或第二天，酌量買進一些（不可全力買進），並於反彈稍有獲利時即賣出。買進股票仍受停止損失委託保護。
    - 如果，您是套牢多頭，切勿在碰到下降 X 線時，賠本賣出，應等反彈時機脫手以減少損失，最可惡的是空手或空手者，要在碰到下降 X 線時殺出股票。
    - 空手或空手者，要注意空頭市場何時結束，以便補空並翻多。如何利用下降 X 線決定空頭市場結束，後面 151 頁討論。

3.  在**多頭市場或空頭市場**不明時，無論如何，股價碰到下降 X 線，買進股票總是沒錯。然後，等待適當時機賣出獲利。

### 6-4 多條下降 X 線交叉於一點

和上升 X 線一樣，有時多條下降 X 線會交叉於一點。一條下降 X 線是一種支撐，股價碰到會上升。兩條下降 X 線交叉，支撐力量更大，回升更厲害。

不可否認，三條下降 X 線會產生極強烈的上升。三條下降 X 線會反轉。

### 6-5 下降 X 線二次支撐和三次支撐

股價一路下跌，碰到一條已經建立的下降 X 線，會產生反彈。反彈以後，股價又下跌，再一次碰到原來那條下降 X 線。這一次股價可能不停留，繼續跌下去，也很可能第二次反彈。

假如，股價下跌碰到原來那條下降 X 線，仍然反彈叫二次支撐。第三次碰到也反彈，叫三次支撐。三次支撐會反轉。

### 6-6 下降 X 線二度支撐

上升 X 線有二度阻力；下降 X 線有二度支撐。

股價第一次碰到一條下降 X 線，產生反彈後迅速跌到該條下降 X 線下方一段相當的距離（譬如 10% 左右），然後在一個強烈反彈後，股價又迅速回升到該條下降 X 線上方。這是一個不尋常狀況，既然跌破為何又回頭了？莫非多頭硬起來了，或是空頭心虛要認敗了？

衝上原來那條下降 X 線後，不久，又跌下來了，再次逼近原來下降 X 線，逼近、逼近，但是，就是不跌破，在原來下降 X 線上方，停下來了，重新上漲。

這種情形叫二度支撐。二度支撐會反轉。
