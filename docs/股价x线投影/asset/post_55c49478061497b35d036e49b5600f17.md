## 3 股价 X 线简介

### 3-1 何谓股价 X 线

**股价 X 线** 被视为近数十年来，最具创见的股票技术性分析法，是国内 **许金华** 先生于 **1979** 年所发明。

**股价 X 线** 是一条画在**半对数股票图**上的直线。

当股价上涨碰到 **上升 X 线** 时，会在当天或第二天下跌；而当股价下跌碰到 **下降 X 线** 时，会在当天或第二天上涨。并且约有 **99%** 准确性。

**股价 X 线** 是一条直线，画法简单。

股价上涨碰到 **上升 X 线** 即下跌；股价下跌碰到 **下降 X 线** 即上涨，时间不会超过第二天。

### 3-2 如何命名

股价 X 线 命名的理由有二：

- （1）股价 X 线 具有神秘的力量，能精确透视股价反转位置，仿佛 X 光可以透视肉眼看不到的地方。
- （2）股价 X 线 作图时，系以顶和底，或底和顶连接，和股价趋势交叉画出，类似英文字母 X（画法详见后面数章）。

### 3-3 股价 X 线的区分

股价 X 线 分为 **上升 X 线** 和 **下降 X 线**。

上升 X 线 画法是底连顶，但是至少间隔一个顶和底；
下降 X 线 画法是顶连底，但是至少间隔一个底和顶。

以上这样讲，读者当然不明白，本书目的乃是针对读者的困惑，加强投影解说，直到读者完全明白且熟练为止。

读者若能画出权威的 股价 X 线，并据以买卖股票，十次有九次成功的机会。这一点笔者是敢肯定的。

### 3-4 股价 X 线的作用

一条 上升 X 线 画出后，下一次股价上涨，碰到这一条 上升 X 线，会在 当天或第二天 回跌。

周线则会在 当周或下周 回跌。 月线则会在 当月 或 下月 回跌。

一条 下降 X 线 画出后，下一次股价下跌，碰到这一条 下降 X 线，会在 当天或第二天 上涨。

周线则会在 当周或下周 上涨。 月线则会在 当月 或 下月 上涨。

### 3-5 上升 X 线的使用

在多头市场，股价碰到 上升 X 线，会在当天或第二天 回跌，通常回跌 5~10%。周线则会在当周或下周回 跌。月线则会在当月或下月回跌。 上升 X 线 用于卖出。

在空头市场，上升 X 线是反弹的极限。

在多头市场或空头市场不明时，股价碰到 上升 X 线 卖出股票，必然没错，回档后再补回。

### 3-6 下降 X 线的使用

在多头市场，下降 X 线是回档的最低价。在空头市场，股价碰到下降 X 线，会在当天或第二天反弹，通常反弹 5～20 % 。周（月）线则会在当周（月）或下周（月）上涨。下降 X 线 用于买进。在多头市场或空头市场不明时，股价碰到下降 X 线 买进股票，必然没错。

这条牵涉股票涨跌, 极其重要的直线一定要发明。许金华承担此寻找直线任务。经由辛苦画图, 历经 4 年, 和唘大学一样的时间, 用科学方法, 分析研究, 并且实际在市场印证, 终于成功。这条直线分成和卖出股票有关的上升 X 线, 以及能精确掌握买进点的下降 X 线。本图是上升 X 线, 不必超级电脑分析, 只靠一支直尺, 一支尺只要 10 元, 够简单吧!

## 投影片 30：博采众长

发明东西要博览群书。硕博论文书写，一定要有一段提及前人研究。在前人基础上继续前进，才不会盲目。股价 X 线发明，要先看前人著作。John Magee 的股价趋势是骨干，其它股票书没几本，全部买来看。半对数图纸和工程用的对数图纸不一样，市面找不到，只好自己设计。请印刷厂印出，日夜作图，夙夜匪懈。分析大量股票图，终于发明 股价 X 线。但是数以百万的投资人，能看到 股价 X 线 的，比例很少。可惜！

## 股价 X 线如何命名？

- 股价 X 线具有神秘力量
  - 能透视股价反转位置
  - 好像 X 光能透视人体
- 股价 X 线和股价趋势交叉画出如 X 状

> **投影片 31**：医院不可缺少的 X 光，它在 1895 年由伦琴发现，没几个月便应用在医学上，伦琴因此得到 1901 年诺贝尔物理奖。X 光可以穿透体表，让医生看透人体，诊断疾病。很多人都有照 X 光经验。股价 X 线有神秘力量，能穿透证券市场，看到供需关系，透视反转位置。X 光命名有新的射线，且有点未知之意，股价 X 线它有神秘未知力量，且与股价趋势交叉画出成 X 状之意。许金华会不会得什么奖，谁来颁发？从股市去努力吧。

## 投影片 32：交叉的纯净度

图中看出上升 X 线和股价趋势交叉成 X 状，交叉处愈单纯，上升 X 线愈权威。交叉处复杂的，上升 X 线权威性打折扣，不过如果连线的基本点很明显，连成的上升 X 线仍然可以小心使用，做少一点就好。也可以配合其他上升 X 线形成 2 条或 3 条上升 X 线交叉，其威力变大许多。
