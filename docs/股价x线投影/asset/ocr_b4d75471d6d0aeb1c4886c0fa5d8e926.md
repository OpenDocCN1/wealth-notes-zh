大或壓縮，改變了基本點的**原始模樣**。電腦圖放大時，不明顯的基本點會變明顯，造成誤判。電腦圖壓縮時，明顯的基本點卻看不出來了，反而不知要畫 **股價 X 線**。如此這般，擾亂了判斷。

還是自己用半對數圖紙畫一些圖，不足部分再用電腦圖補充，比較實際。

# # 7-5 其他試驗

**股價 X 線**除了受**剪刀原理**、**二週原則**、**交叉要單純**、**基本點要明顯**考驗外，尚須注意：

+   （1） **空頭市場和多頭市場基本點互連**，特別權威。

+   （2） 在同一**型態個變動**，如楔形、三角形、小幅盤局的基本點不要互連，連起來的 **股價 X 線** 不權威。好像親族不婚配一樣。即使勉強連起來，也只能考驗附近變動而已。

經過這些權威性試驗，您就可以確認一條 **股價 X 線** **可靠性**了。然後，據此以執行您的買賣，勝算很大。
