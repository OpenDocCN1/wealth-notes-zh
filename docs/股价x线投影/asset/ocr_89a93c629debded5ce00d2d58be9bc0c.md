+   5. 空頭市場跌深後，作手想賺反彈，邊拉邊出，碰到上升 X 線，成交量放大，就跑掉了，留一個陷阱把散戶困在裡面。空頭市場中段也有陷阱。

有一個游泳健將，在冬天時，欲到日月潭游泳，後面跟著一群想游泳的人。他脫去衣服，站在潭邊許久，忽然跳入水中，一群人也跟著跳下水。游泳健將發現水溫非常低，不適合游泳，他後悔而不想游了，於是潛盾上岸，穿好衣服回家。留下一群人在寒冷的水中受苦。

此例子，用以比喻作手欲炒作某一股票，才開始買進，就發現情況不對，跟進者不如預期的多，於是鳴金收兵，留下的是一堆跟進而套牢的多頭。

事實上，作手是最先感覺氛圍不對的先鋒。作手原意有時也不一定是挖陷阱，但是，跟進者是落入陷阱了。

至於作手若真挖一個陷阱，散戶上當者將更多，套牢更久，結局更慘。

有的校長主張，校園裡為了安全，應該種一些沒毒的植物，以免學生中毒。少部分校長則主張種一些有毒植物，讓學生認識有毒植物，在校外才能避免中毒。

絕大部分股票書籍都叫人家怎麼賺錢，少有叫人避開股市陷阱的。本書特關股市陷阱和 股價 X 線 關係，避開陷阱才有可能賺錢，常常落入陷阱，遲早跑路，豈可不慎！
