## 4 畫線的基本點

初中學幾何時，老師開宗明義說，兩點可以連一直線，而且還說直尺不一定直，要翻轉再畫一次，檢驗直線是否重疊，若重疊，尺才算直。畫圖工具有一定精度，早年我畫圖的三角板，直角不是正好 90 度。設計半對數圖紙要很精密，畫了很久，覺得有某種問題，經查明三角板直角只有 89 度，原來毛病在此。

股票圖畫直線主要有二種：趨勢線和股價 X 線。電腦上畫線就不用尺了，只要找連線的二點連起來即可。

所以畫股價 X 線，只要找對二點。看似簡單，其實要相當經驗。畫對了買賣會賺，畫錯了錢會溜走，豈可大意。

股票圖上連線的二點稱基本點，有頂點和底部，是股價趨勢轉變地方，股價轉折很明顯的基本點，畫股價 X 線特別權威，買賣賺錢機會大。股價轉折不明顯的基本點，畫股價 X 線不權威，弄錯會虧錢，不可不慎。

電腦圖基於視窗要填滿，有些股價變動不大，但看起來好像波動很大，誤解基本點好像很權威。當發現股票目標時，最好用標準半對數圖紙自己再畫一張。尤其是周線和月線。如何選半對數圖紙，本書有介紹，請看第 9 章。

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_63_0.png)

通過一點要畫一條確定的直線，需要知道和水平的夾角，或者平面直角坐標系中稱為斜率，來表示平面上直線的傾斜程度。同樣股票的同一條股價 X 線，在不同圖紙上，或電腦視窗上，其斜率是不同的，但是半對數圖紙上的股價 X 線，準確度和斜率無關，按比例拉長或壓扁準確度也不變。為了好看，電腦股票圖可以用小畫家截切，放入 Word 中，把它上下拉長，放大波動，股價 X 線會比較好畫。

## 投影片 64

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_64_0.png)

通過一點可以畫出無限多條直線。股票圖上不可能這樣畫，畫出也沒有意義。

上升 X 線或下降 X 線是固定的那幾條，任何人來畫都是同樣的。若是可畫無限多條，條條都不同，要根據哪條操作呢？

況且，要畫無限多條，畫到老也畫不完。

## 投影片 65

![](img/be3636ae4a02929d76a1ecf2ccbc1b9e_65_0.png)

股票圖上找出頂和底，按照上升 X 線或下降 X 線畫法畫出股價 X 線。圖上只畫兩條不會亂，一張股票圖上可能要畫幾十條，必須訓練一下，電腦上還可以用顏色和樣式及線條粗細加以區別。上升 X 線是底連頂；下降 X 線是頂連底，不要畫錯，畫多條股價 X 線時難免會錯。多多練習，熟能生巧。

## 投影片 66
