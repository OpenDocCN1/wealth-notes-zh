# ## 11-10 恐慌上升

恐慌上升是空頭或空手的人**恐慌**，怕補不到股票。尤其是踏入空頭陷阱的被軋空頭。

空頭市場末期股價暴跌後，醞釀恐慌上升。因為股價跌過頭，價格太便宜，引起投資人極大的興趣。早期放空者獲利已多，末期放空者心急如焚。此時往往也是政府基金進場，扇風點火時。加上成交量不多，股價已碰到權威的**下降 X 線**，供需已經轉變，股價會急速上漲。經歷空頭市場，驚魂未定，損失慘重的大部分股民，還在害怕中，股價已悄悄快速漲了一大段。

恐慌上升分成**初期恐慌上升**，和**末期恐慌上升**。

**初期恐慌上升**接續空頭市場末期恐慌下跌後的反轉。如果**下降 X 線**跌過頭，容易**∨ 型反轉**。一般是要打底。

恐慌上升一大段後會陷入約一個月的整理，看當時的經濟情勢，有可能再急速上漲一大段，進行**末期恐慌上升**。要是經濟平平，末期恐慌上升後，在此會轉入短暫空頭市場。若經濟持續好轉，也可能繼續走多頭的路。

靠著周線與月線的**下降 X 線**有無碰到，有沒有**多條交叉**與發生**二次阻力**、**三次阻力**，或發生**二度阻力**，觀察市場氣氛是否壞到極點，政府基金有無進場，試圖買到低價。持有股票一段時間，應有不錯的獲利。
