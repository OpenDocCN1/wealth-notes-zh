
## 6-7 B 型下降 X 線

前面討論的下降X線，是頂和底相連的（至少間隔一個底和頂），它的方向是向右下方傾斜的，這種向右下方傾斜的下降X線，叫正統下降X線。

有一種下降X線的頂比底低，畫出的下降X線向右上方傾斜，叫B型下降X線。

B型下降X線和正統下降X線都是下降X線。它們的畫法、作用完全相同，只是傾斜方向不同。

## 6-8 很多股票碰到下降 X 線

在同一時間，很多的股票碰到下降 X 線（譬如有 20%）。這會造成一種氣勢，尤其是領導股和熱門股有一半左右碰到下降X線，這種情況顯示大勢會有明顯上漲，也有可能反轉進入多頭市場。
