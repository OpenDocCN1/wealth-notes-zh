成交量一格可以代表一千張（一百萬股）或五千張（五百萬股）或適合的張數，看這檔股票日常的成交量而定。偶爾超出格外是可以的，但是不要常常超出。成交量刻度訂太大或太小都不好。

成交量訂太大時，若每天成交量不夠多，看起來好像沒變化；成交量訂太小時，天天超出格外也不方便。

# # 9-7 半對數圖紙那裡買

市面上，想買半對數紙，找也找不到。

筆者精心設計兩款半對數圖紙，一種 **日線圖** 專用（可畫 7 個月）；一種 **週線圖** 專用（可畫 3 年），大小適中（長 31x高 43 cm），作圖及保管均容易。

**週線圖** 因時間長，變動幅度可能很大，採用 **4 段式（16 倍）**，這樣在很長時間內，都不必更動價格刻度，以保持股票圖的連貫性，可長時間準確使用 **股價 X 線**。就是在美國，好像也未見有週線圖專用半對數圖紙，他們是採用日線圖圖紙跳一行畫，以免太陡。

日線圖採用 **2 段式（4 倍）**，價格刻度放大，非常好畫。
