# 写在前面

2017 年 2 月 23 日，我开通了我的知识星球，截止目前第一期星球结束，共有 4600+ 球友加入，我的知识星球旨在帮助大家提升认知。

这份电子书，是从我第一期知识星球的 100 篇精华文章中选出来的我认为还不错的几篇，当然除此之外，其实第一期知识星球我还回答了大家将近 800 个问题，但是篇幅有限，不可能把每个回答、每篇分享都收录进来，有些分享我自认还不错，有些分享我觉得有些过时了，虽然只有一年的时间，但是变化就是这么快，希望送给所有第一期的知识星球球友留个纪念，我相信这些文章多少对大家是有点帮助的，希望大家的人生越来越好。
