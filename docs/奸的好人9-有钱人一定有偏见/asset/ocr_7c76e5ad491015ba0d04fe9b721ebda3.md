# 有做和没有做的分别

三种不能等下去的东西

一则故事说，有一个贫穷潦倒的年轻人寻找算命师开运改命，算命师八字一拆，摇头叹气地说：“小兄弟，你会倒霉到五十岁。”

这个年轻人先是心中一惊，但随即心念一转，充满“期待”地问：“五十岁以后呢？”

算命师再屈指一算说：“喔，你会习惯了贫穷赔命！”

这位年轻人很“后悔”来算命，他内心想：“妈的，‘早知道’不要给你批命。”

人类有三样东西是不能等的：第一，贫穷是不能等，当你“习惯了贫穷”，你就不能改变，习惯之后也不想改变了；第二，梦想不能等，当你“习惯了不能实现梦想”，就不可能完成梦想了，梦想永远只会是梦想；第三，父母是不会等你的，当你“习惯了让父母等你”，父母已经等待不及了。
