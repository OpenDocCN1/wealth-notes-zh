# “今天”从明天开始

郝广才
1小时前
明天是1月1日，我们的“今天”，就要从明天开始吧。
“今天”说的不 是“历史上的今天”，而是要探究哪里是创造历史的开端，是改变世界的起点。
三百六十五天，每一天真实的故事，都能拍一部电影。三百六十五天，每一天真实的梦想，都能改变这个世界。我从三百六十五个故事里，挑选了一百个有趣的问题，就像一百颗角色各异的糖果。在接下来的一年里，你会一个接着一个剥开糖果，尝到它们不同的味道：
