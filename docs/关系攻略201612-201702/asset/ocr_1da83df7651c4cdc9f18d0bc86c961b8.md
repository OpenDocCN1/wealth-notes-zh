# 早点裁掉筏人，对大家都是一种慈悲

早点裁掉筏人，对大家都是...

上次写了一个清理 妄人的攻略，当时预告了这篇《早点裁掉筏人，对大家都是一种慈悲》，有同学就特别着急地问我，妄人、筏人有什么区别。

我们重温一下妄人的三个标准：把自己看得太高、积极勇敢地行动、藐视规则和流程。

自忖，鲁莽，二百五。

筏人恰好相反，筏人把自己看得特别低，行动力很差，循规蹈矩。

筏人和鸽派是完全不同的两种概念，别搞混了，鸽派说的是交友原则，是跟别人的关系，筏人说的是能力问题。
