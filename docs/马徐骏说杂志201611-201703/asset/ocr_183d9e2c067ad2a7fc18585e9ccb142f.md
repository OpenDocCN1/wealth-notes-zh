# 本期杂志：《新闻周刊》、《时代周刊》、《经济学人》

《新闻周刊》创刊于1933年，与《时代周刊》、《美国新闻与世界报道》并称为美国三大新闻周刊。《新闻周刊》尤其以时政新闻报道见长。

《时代周刊》创刊于1923年，是美国三大时事性周刊之一。它因“为高端忙碌人士提供高效而深入的世界新闻报道”而著名。

《经济学人》1843年创刊于英国，是世界上 最著名的政经类杂志，被视为西方精英必备读物。
