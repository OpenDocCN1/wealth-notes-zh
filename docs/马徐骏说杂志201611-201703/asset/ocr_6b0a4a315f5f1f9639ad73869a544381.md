# 建立“累积优势”的因素表

+   **1、出众的要素**
其实品牌都是独立先发优势，世界领先的品牌如哈根一德士被宝洁激造的CEO乔布斯，罗尔森，罗利说：企业生产的**产品优势**，使**数据**精准，成本也越低。
所以**价格**的利基要素，**品质**优秀，**功能**完美，**体验**流畅，**服务**贴心。
比如，在快速洗液的洗衣机市场，次级品宝洁用上下两档电压，利牌也最丰的产为之一。达肤在1946年投向市场后，打下了洗液液浓液本的广告，宝洁甚至还为美国所有**节目**及文数投出一达洗液液浓液的广告，来培养用户使用习惯。这让洗液液浓液从云中抽解达出，打败洗衣粉市场。

+   **2、为习惯而设计**
公司在最开始设计和品牌时目标，目标就应该是让用户的使用它。
哈佛大学心理学家安纳·马克汉克认为，要设计这样的产品有两个原则可以遵循：首先，要让产品的使用元素保持单一性，让消费者即便是很迟的人也很认出品牌标志。比如苹果和显芭的LOGO；
其次，让用户融入人们的生活，就是说要做到设计身体的使用体感。

+   3、**陈**用产品内的创新要非常验
无论就技术还是其他方面，去进行创新，研究和用**积累**的改进比在产品的“累积”之上，两者都**非常**验。
洗达就是在这个面说过为，为了点断新出现的洗衣凝的市场机遇，宝洁公司在1975年时，推出一**款**洗衣凝水“Era”，但因为没有知名度，没能成为大品牌。
1984年，宝洁造了**了**的洗衣凝水，推出了洗流达液态本的说法，充分利用之前的“累积”优势，所有**产品**传递的信息都**简单**直，这就是说你喜欢的说法，只不过用了更多的产品。

+   4、始终保持简单的传递
行为学研究员亚当斯尼尔，卡尔尼在《思考，快与慢》一书中，将人的思考分成“快思考”和“慢思考”。
广告策划和研究员**发现**很多时候是“慢思考”，他们**动**心设计时每一环节，努力**让**产品的**传递**，但人类只关注“快思考”，用户**快**，**慢**思考，人们只在大**脑**的**信息**时，**大脑**会进行**思考**，**快**思考，人们在大**脑**的**信息**时，**大脑**会进行**思考**，**快**思考，人们在大**脑**的**信息**时，**大脑**会进行**思考**，**快**思考。
比如几年前，三星发布的手机和GALAXY S5的广告**复杂**。

# 三星GALAXY S5广告败北

三星GALAXY S5的广告诉以很**复杂**。首先展示了一款性能力不**如**S5的**对**手机；不动水，没有**儿**有**情**，接电也**很**慢。接着，广告**出**现了S5，**且**从**外**形上，**看**，S5和**之**前的三星手机**完全**不一样。
广告**新**品**面**现到了**最**上**面**的**新**机**形**，**可**你**知**，有多少人心**想**：“**看**广**告**？”，再**加**上广**告**设**计**和**知**的**多**的**信**息**流**，**而**广**告**者**本**意**是**让**相**对**面**向**的**单**一**简**单**信息**，大**家**听**到**三星的S5，就**想**起**对**的**新**知**。
实**在**上，**这**支广**告**很**明**确**给**了**三星**广**告**指**向**的**对**手**，也**就**是**果**果，果**果**广**告**单**简**，**次**次**传**达**的**信**息**很**明**确——我**很**好，我**非**常**好，我**非**常**好**，我**刚**好！
本**期**内**容**总**结

对**于**首**创**取**的**个**优**势**之**后**，如**何**保**持**这**类**优**势**？办**法**就**是**将**产**品**和**服**务**变**成**用**户**的**习**惯——设**计**之初**指**定**目**标**，取**单**者**为**，以**及**利**用**“**累**积**优**势**”，将**自**身**的**优**点**品**牌**清**晰**传**递**出**来**。
