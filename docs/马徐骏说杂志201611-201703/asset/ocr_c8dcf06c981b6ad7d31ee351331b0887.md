雷蒙德·罗威最有名的三个设计
第一个著名设计，是美国总统的座车。同一套命名法。罗威被选为了在白宫工作的朋友报纸，总统座驾“空军一号”华丽而不公。当时的美国总统肯尼迪把他到白宫办公室商量，最后将“空军一号”命名为白色机身、蓝色机头，前面还有突出的机头，像个鼻子。这个罗威的设计，沿用至今。

第二个非常有名的设计，是现代火车的命名法。老式火车头是白色彩绘，跑起来冒着蒸汽。1932年，美国宾夕法尼亚铁路公司委托罗威设计一个新的火车头，经过研究后，他选择了烟肉，把整个火车用一块铁包裹起来，这个就是现代火车“子弹头”设计的原型。

第三个设计，是给美国太空舱能够尽量舒适地生活和工作的区域。

# 什么是MAYA理论

罗威所有的理论都源于了一条理论，就是MAYA理论，这是由四个单词的首字母组合起来的词：Most Advanced Yet Acceptable。翻译过来就是，要极致得让人眼前一亮，但也能被人接受。

说得通俗一点，如果你要卖一些得于意料的东西，就要把它弄得尽量沟通一点，如果你要卖一些大很熟的东西，一定要把它弄得意外一点。

火车头大家都非常熟悉，罗威在设计时，进行了大刀阔斧的改变，打破了大家对于火车头这个形象的基本概念，给了一个很超前很形象的火车概念，就是Most Advanced.。

在设计空间站的时候，罗威特意在空中加了一个舷窗，让宇航员可以看到地球。空间站对于人来说是新的领域，但如果可以透过这扇舷窗看看自己的家园，这个就是Yet Acceptable，虽然很新，但依然是很大家熟悉的元素。

# MAYA理论的心理管理学

全球最大的流媒体音乐公司Spotify曾经做过一个项目，每周向一批用户新投放一歌曲，推送给用。但实验出现了一个结果，本来应该全部是新歌的歌单混入了用户听过的老歌。Spotify很快就进行了修正，可是想到，把老歌去以后，那个服务使用的人数减少了。

这是因为，对于用户来说，如果没有让人心悬着一又完全陌生的东西，信心降低，但如果是全在听歌，就有点无聊了。听过的新歌曲的熟悉和陌生感会让人对歌曲产生信任感，对信任的歌曲的歌声会更高，熟悉的东家还会产生安全感。

# 什么是曝光效应

二十世纪六十年代，有一个心理学测试，研究者会给受试者随机看一些单词，图形，甚至完全看不懂的符号，然后问他们哪个好。研究发现，被试者更喜欢他们熟悉的东西，这个是心理学上叫的曝光效应，也就是说，一个东西出现的次数越多、见得多，你认为它的好感也会增加。

这个在生物学上也有解释，从进化角度上来说，你能认出来那些动物或着植物，说明你在和它们相处的过程中，没有受到它们的伤害而不是死亡，不会产生危险，所以看上去很安全，会产生好感。

# 在安全感和新鲜感之间寻找平衡

曝光效应也有一个限度，太过熟悉，好感度反而会下降。

一方面，每个人都有求安全感，另外一方面，人们都求新鲜感，所以，设计就要在两个极端里，一方面追求安全感，另一方面追求新鲜的刺激感，做到平衡。这就叫MAYA理论所追求的。

# MAYA理论如何在生活中应用？

有调查显示，1997年至2013年的16年里，有15年好莱坞电影票房最高的，都是之前成功电影的续集，比如《星球大战》、从A到M理论来看，《星球大战》是人们熟悉的，所以产生安全感，再加上一点不一样的情怀和人物关系，就是新鲜的刺激。

2014年的时候，美国的哈佛大学生术150个人做了一个实验，他们准备了150个方案，请科学家评分。研究证明，这些方案里分量的是，那些最新超前的想法，一些很新颖的、没什么创意的方案，分数也不高。而评分最高的就是大家熟悉的但又有一点点创新的想法。

所以，如果一个人在创业阶段想要拿到投资，跟投资人谈的时候，尽量别跟他谈论听都没听的人，比如，你要做餐饮业的，可以大众点评，或者你要做服装领域的，滴打车。这样，既有他熟悉的元素，又有创新的点子，成功率是最高的。
