# 今日金句

“仲裁条款”为美国公司节省了大量的金钱、时间和人力，但却损害了普通人的利益，是美国法律中经常被指责的存在。

# 知识清单

格雷琴·卡尔森（Gretchen Carlson）前“福克斯新闻频道”（Fox News）资深女主持；1989年当选“美国小姐”；主持福克斯新闻的王牌节目《真实的故事》长达11年；2016年7月，格雷琴对“福克斯新闻频道”的CEO罗杰·艾尔斯提出指控，称“自己因为拒绝了艾尔斯的要求，以及抱怨艾尔斯严重的性骚扰，职业生涯被终结”。

2006年，美国女性上法庭打“性骚扰”官司，平均得到的赔偿金将近22万美金，但如果“性骚扰”事件用仲裁来解决，大概平均只能得到3万美元的赔偿金。

据美国公平就业委员会（EEOC）2016年的调查显示，至少有25%的女性表示她们在工作场所遭受过“性骚扰”，但真正会对簿公堂的，极少。女性会顾虑在单位里面很难立足，受人白眼，甚至有女性害怕因为控告，给自己带来更多的“性骚扰”。

美国“性骚扰”案很少上法庭，最核心的原因是——仲裁条款。

仲裁条款，是指当事人在合同中订立的，将今后可能因为该合同所发生的争议，提交仲裁的条款。

“仲裁条款”无处不在，不仅存在于格雷琴·卡尔森数百万美元级别的雇佣合同中，普通民众的雇佣合同、银行开户的协议，甚至在收费电视频道的协议中，都有“仲裁条款”的存在。

“仲裁条款”规定，有纠纷的双方通过仲裁公司来解决矛盾，而这些仲裁公司有时候仅仅是靠雇请退休的法官来判决策件。

# 知识加餐

福克斯新闻台9月6日表示，已经就前女主播格雷琴·卡尔森（Gretchen Carlson）指控前CEO罗杰·艾尔斯“性骚扰”案达成和解，并为此遭道歉。据报道，双方和解金额为2000万美元。根据《纽约时报》的报道，罗杰·艾尔斯已经在7月21日宣布离职，他可能将拿到4000万美金（约合人民币2.6亿元）的补偿金。

美国政治里有一个表达叫做“October Surprise”（十月惊奇），指的是在11月大选投票之前，两党都会特意（而且是利己地）安排好时间爆出新闻，提供能改变投票者想法、影响民意调查的证据，而此时不管证据是否真实，对方都不太有时间机会去挽回局面。

希拉里的民主党总统候选人，川普是共和党总统候选人，福克斯新闻频道是共和党的传播阵地。结合二人“仲裁条款”上的立场，此时爆出对共和党不利的“福克斯丑闻”，难免让人认为，其中别有深意。
