# 知识清单

# 《快公司》

全球三大财经杂志之一。

《快公司》和《哈佛商业评论》很有渊源，《快公司》的创办人曾是《哈佛商业评论》的主任编辑。

这本杂志致力于传达那些在快速发展的商业世界里，真正改变商业的故事和理念。也就是说，《快公司》既继承了《哈佛商业评论》深厚的管理理论的基础，又讲述了最前沿的商业故事以及想法。

如何坚持完成年初制定好的新年计划。根据美国大脑数据研究机构的调查，在制定新年计划的人群中，只有8%的人能成功坚持下去。92%的人则中途放弃了。文章就如何坚持完成“新年计划”，给出了4点建议。

第一点建议：放下宏大的新年目标，从能坚持做的小目标做起。很多人的新年目标总是很宏大的，比如说每天健身2小时，一年读完50本书。心理学家说，这其实自于一种掰掉自己身上缺点、重新做人的强烈愿望，当自己制定这种计划时，心中会产生愉悦感。但是，这些宏大计划的前提都很假。文章建议，不要制定那种秋风扫落叶一样的小计划，而是做可以持续执行的具体小计划，比如，与其制定每天健身2小时，不如从每周三次、每次2公里的散步开始。

第二点建议：重复行为，强化新习惯。制订新年计划的前两周是最兴奋的，这股兴奋劲儿退去后，“新年计划”也就被抛到脑后了。文章里说，成功实施了新年计划的人都有一个共性，就是他们善于利用重复的力量去养成新的习惯。一旦一个事儿养成了习惯，就可以依靠惯性坚持下去，但前提是培养新习惯。心理学家McCarthv指出，人们很难实现目标，因为大脑喜欢按惯性行事。人们长期以来的习惯，已深深演绎在大脑神经中，有自己的神经路径，难以改变。如果形成新的习惯，就得创造新的认知，更重要的建议，为新习惯建立新的神经路径。如何才能建立新的神经路径？文章给出的办法是，每天早上都重复自己遵自己的目标，最好是大声地重复出来，日复一日，一个新年目标就会在大脑中留下印记，心理学家McCarthv称之为有意识的大脑训练。

第三点建议：寻找榜样。文章里建议，多了解那些已经实现了目标的人，多听励志故事，这对于实现新年计划有两点好处：第一，这会让你对自己的目标更加熟悉和明确，更能增加信心，你会觉得“他们能做到，我当然也能”。第二，会让你的目标更加“可视化”。假如你的目标是健身成功，多看看健身成功的人的照片。这样，你在脑海中对于自己的目标会更有画面感，也就更有动力去执行了。

第四点建议：为可能出现的状况建立应对机制。我们之所以无法完成新年计划的主要问题有两个：第一，缺乏自控力；第二，因为中途的断档导致全盘放弃。所以，在制定目标之前，就要挖掘你可能出现的具体情况而做出应对计划。比如说，你会可能会说：“要是我没动力了怎么办？”那么应对方案可能就是看看自己的榜样，如果榜样也无法激励你了，文章建议，在制定目标时，写下最初的动力，不断提高自己想改变的原因。此外，文章还给出了另一个方法，就是和朋友组成搭档，彼此监督。
