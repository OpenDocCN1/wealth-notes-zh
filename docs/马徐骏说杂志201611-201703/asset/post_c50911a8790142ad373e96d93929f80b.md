
# 人工智能将如何影响你的生活

本条音频及文稿摘录《大西洋月刊》3月刊

![](img/2b1f55794a32401f6e1d5425100884b9_70_0.png)

## 内容简介

- 1. 在未来，人工智能助手会在哪些方面有所突破？会发展到什么程度？
- 2. 人工智能如何与人合作，共同协作进行艺术创作？
- 3. 人工智能未来的发展存在什么样的问题？
- 4. 中国在人工智能领域有什么样的地位和成就？

## 知识清单

### 人工智能助手

大科技公司都有自己的智能助手，苹果的Siri，Facebook的M4，微软的Cortana。名字不一样，但功能都是类似的，就是作为一个虚拟助手，为人类服务。

未来人工智能助手可以发展到什么程度：

- 1. 功能将更加多元化

未来，人工智能助手的功能将更加多元。

第一，用法会更多。比如小孩子，给孩子讲故事甚至是辅导孩子功课，未来都可以让人工智能助手完成。

第二，现在要用这些功能，还需要发出声音，未来，可以在耳中塞一个小耳塞，只要默念出需求，不需要发出任何声音，系统就能通过传感识别出来。

除此之外，耳塞还能在面试、约会等时候给你指导，比如约会时，对方要聊电影《爱乐之城》，你没看过，就可以用嘴型默念：“《爱乐之城》介绍”，人工智能助手就会把它念给你听。

- 2. 升级为智能个人助理

不管是讲故事还是不发出声音就能识别命令，主要都是聚焦在“对话式”交互上，需要给它一个指令，让人工智能助手去做，但这还处于“被动”阶段。

所以，人工智能下一步的发展，是使用场景和方式越来越多样。

比如，个人智能系统将会以代表你的方式去处理事务。微软的个人智能助理Cortana，中文叫“小娜”，是微软游戏《光环》里的一个虚拟角色。微软“小娜”的负责人Ryan Gavin说，也许在未来10年内，就可以实现这样的功能：你去商场买家具，看好后就给“小娜”下指令，说“小娜，去和他们的机器人沟通一下，安排下付款和送货”。

此外，人工智能还会朝越来越有“人情味儿”的方向发展，也就是情感智能。它能通过语音、表情、用词，更好地理解用户的性格和感受，不再是用户单方面下指令。

比如，你需要人工智能助手推荐一条路线，那么它不仅会推荐，还会主动向解释。例如根据你平时的表现，它知道你喜爱小径、风景优美的地方，所以上一次推荐这条路线给你。

- 3. 共同协作进行艺术创作

人和人工智能系统会有越来越多的合作，尤其是艺术作品创作。比如音乐领域，写诗就是人工智能的一个子领域，叫做计算机创造力。主要功能，就是仿造出一个可以进行创作的算法。

加州大学的作曲家David Cope就开发了一款作曲软件Emilv Heweli。只要提供某个作曲家的作品，软件就能分析出音乐组合的规律，也就是作品在旋律特征、音律结合后的新曲子。2010年，他还发布过名为Emilv Heweli的专辑。

### 人工智能可能带来的问题

比如人工智能能够在多大程度上代表我们，又能在多大程度上不？它们能代表我们支配我们的金钱么？如果我们要求它们做一些违法的事，这些服务于我们的人工智能是服从，还是违背我们的命令？

随着人工智能助手的普及，每个人都会拥有属于自己的智能助手，但如果有一天黑客突破了安全防线，控制了智能助手，就可能造成危及生命的后果。

总之，人工智能助手最大的问题用两个字来概括，就是边界。包括法律的边界、情感的边界、安全的边界等。如何界定好这个边界，将会是人工智能助手领域面临的最大问题之一。

### 中国在人工智能领域举足轻重

中国公司在人工智能这一领域举足轻重。美国人工智能促进协会，每年都会举办一次年会，这是人工智能领域的顶级会议之一。2016年，协会宣布2017年的年会安排时，发现时间正好是中国农历新年前后。由于中国的研究人员不能到场，会议将不能顺利举行，官方只好重新安排会议时间。

2016年10月，美国白宫发布了一项关于人工智能研究的“战略计划”，提到了人工智能领域的一大热门话题——“深度学习”，但在深度学习这个领域，中国才是大拿，是发表论文最多的国家。

## 知识清单

### 《巴伦周刊》

美国的金融财经周刊，内容主要围绕美国的金融市场和市场动态。这本杂志在基金和股票领域有着非常深刻的见解，每期都会介绍新的基金管理理念并给出投资建议，既服务于基金公司，也为个人投资者提供建议。

### 哈雷摩托车的诞生与发展

全称哈雷·戴维森，诞生于美国北部威斯康星州的奥茨堡。哈雷摩托车是这个城市最有名的两个代表事物之一，另一个是NBA的密尔沃基雄鹿队。

哈雷摩托有着非常悠久的历史。1901年，一个叫凯撒·哈雷的20岁年轻人有想要自己建厂的梦想，他的朋友戴维·戴维森一起，二人把发动机装在自行车上进行试验，成为日后哈雷摩托的雏形。

1903年，哈雷·戴维森品牌正式成立，名字来源于威廉·哈雷和亚瑟·戴维森姓氏的组合。通过不断改良，1920年，哈雷已成为了全世界最大的摩托车制造商。

在经历了一战、经济大萧条和二战之后，哈雷成为美国国家的象征和美国文化的重要组成部分。漫威电影《美国队长》里，美国队长总是骑着一辆哈雷摩托车，拯救世界。

哈雷的营销做得非常好，美国人崇尚个人主义，而哈雷营造出一种象征着反叛和追逐自由的精髓，很合美国人的胃口。同时，哈雷作为世界上最老的摩托车制造商，品牌忠诚度非常高，世界各地有很多死忠粉和车友俱乐部。

今年2月，美国新任总统特朗普在白宫见了哈雷的首席执行官Matt Levato，并感想，能有一辆哈雷·戴维森的摩托感觉真是太好了。

哈雷在股票市场的表现也非常好。在过去的十二个月里涨了35%，现在已经到了56.56美元一股。

### 哈雷摩托车面对的麻烦

第一个，固有受众群萎缩。

和很多人以为的哈雷的受众主要是喜欢自由、有反叛精神的年轻人不同，哈雷摩托的主要消费群体是非西班牙裔的中老年人。这主要是因为，哈雷摩托车的价格不便宜。哈雷80%的利润，是来自于3万美元以上的重型车。剩下20%来自附件、授权、服饰等等。要购买哈雷，需要一定经济实力。

但是贡献了哈雷60%利润的核心受众，在过去的十年里数量逐渐减少。现在哈雷试图吸引年轻人，甚至亚洲女性、黑人、西班牙裔，但效果并不太明显。

# “每天喝8杯水”真的科学吗？

本条音频及文稿参考《新科学家》3月11日刊

![](img/2b1f55794a32401f6e1d5425100884b9_72_0.png)

## 内容简介

- 1. “每天喝8杯水”的说法是怎么来的？有科学依据吗？
- 2. 碳酸饮料会导致骨质疏松？碳酸饮料不能多喝的真正原因是什么？
- 3. 鲜榨果汁是健康的好饮品吗？
- 4. 牛奶真的有营养吗？我们成年后还需要每天喝杯牛奶吗？哪个人群最需要喝牛奶？
- 5. 咖啡因有多难戒？茶就比咖啡更健康吗？

## 知识清单

### 关于喝水这件大事

本期内容来自最新一期《新科学家》的封面文章，主要内容是告诉我们如何正确喝水，其中不少知识颠覆咱们以往对水的认知，比如天真的觉得要喝8杯水吗？这个论断是谁提出的？又比如，同是提神饮料的咖啡和茶，到底哪个更好？还有，喝可乐不健康，那换成无糖可乐是不是就健康了？等等等等。总之，关于喝水这事，你能想到的文章都有提及，单单参与写作的作者，就有足足7位之多。

### “每天8杯水”有科学根据吗？

“一天喝8杯水”这句话我们不陌生，那这个论断是谁提出的？

2002年，美国达特茅斯医学院的生理学家Heinz Valtin就特意去查过，结果查到，在1974年出的一本书里，出现过这个倡议，但人家的建议是“一天喝6到8杯水”，这里的“水”不单单指清水，像茶饮、咖啡、牛奶，甚至啤酒，加一块要有6到8杯就行，而且这个说法没有什么科学依据。

关于“到底应该喝多少水”这个问题，美国科学与工程与医学健康研究局的食品营养委员会是这样建议的：对于绝大多数健康的人群来说，除了再喝水，就已经能满足每日身体所需的水分摄入了。

### 孩子才是需要多喝水的人群

虽然成年人完全可以“等渴了再喝”，但研究发现，孩子需要多喝水，一些研究已经证实，对于9-15岁的孩子，喝水可以提高他们的注意力。对此，作者是这样解释的，也许是因为这个年龄段的孩子更容易缺水，而缺水会引发反应慢、专注度低及记忆力下降，所以如果您家有孩子，要记得，他们要比大人喝更多的水才行。

![](img/2b1f55794a32401f6e1d5425100884b9_72_1.png)

### 远离碳酸饮料

碳酸饮料对身体不好，这个大家都知道，但我们要搞清楚的是：到底哪不好？它会如何危害我们的健康？

家里的长辈劝我们少喝饮料时会说，喝多了碳酸饮料会导致骨质疏松。不过这也是一个没什么科学根据的说法。到目前为止，关于碳酸饮料和骨质疏松之间的关系的研究，还是仅仅停留在问卷调查和统计学现象上，也就是说，没有强有力的证据，证明碳酸饮料一定会导致骨质疏松。

那是不是就可以放心大胆地喝了？并不是。碳酸饮料中最大的健康杀手是——糖。

糖主要会引起两个方面的问题，第一个就是体重的增长。第二个是会增加I型糖尿病的风险。平均每天喝一罐碳酸饮料，患I型糖尿病的风险就会提高25%。

既然是罪魁祸首，是不是喝无糖的碳酸饮料，比如说健怡可乐就没问题了呢？不是。

说来说去，问题还出在“糖”身上。

无糖饮料不是不放糖，而是把糖换成人工甜味剂。文章里引用了一个实验结果，说食用了人工甜味剂的老鼠，它们的葡萄糖耐糖程度也提高了，而葡萄糖不耐就是I型糖尿病的前兆，也就是说，即使是人工甜味剂，也有导致糖尿病的风险。

除此之外，人工甜味剂对人体健康的不良影响也不小。哈佛大学的营养科学家Vasanti Malik解释到，“人工甜味剂的甜度是天然糖的200倍，这会导致我们越来越喜欢甜食。”这只是第一层原因，Malik还说，“如果你总吃含人工甜味剂的东西，吃含天然糖分的事物时，身体也没办法正常消化了。”

简而言之，不管是碳酸饮料，不管含天然糖分还是人工甜味剂，最大的问题都出现在糖分上，糖不仅会让我们发胖，还会增加我们得糖尿病的概率。

![](img/2b1f55794a32401f6e1d5425100884b9_72_2.png)

### 多喝果汁有益健康？

果汁看起来很健康的选择——内含有纤维素、维生素、矿物质等等，但这也代表果汁喝得越多越好，其中有两点原因。

一、果汁中含有的纤维素其实非常低。举个例子，一个橙子约含纤维素大概是1.7g，而一杯橙汁约含的纤维素只有0.4g，足见相差4倍。

二、还是糖。世界卫生组织推荐的每日糖摄入量是25g，而一杯250ml的橙汁含糖量就有24g之多。也就是说，一天只要喝一杯橙汁，那么你这天的健康糖分摄取额度算是用完了。

### 牛奶和豆浆的健康谜题

关于牛奶，文章结论可以总结成两点：
一、只有人类这杂畜长大了还喝奶；
二、喝牛奶对于儿童很好。

咱们都听过一个日本“牛奶工程”的口号——一杯牛奶强壮一个民族。

1950年，二战刚刚结束5年，当年的全日本居民体质调查结果显示，日本成年男性的平均身高只有1.60米。60多年后，也就是2014年，再一次的调查结果显示，他们的“平均身高”已经变成了1.707米，排名全球第29位，而同时，中国男性的平均身高是1.697米，排名32位。

也就是说，日本男性在短短的两个世纪的时间里长高10厘米。

归根到底，这是饮食结构调整和体育锻炼强化共同的结果。上世纪50年代，日本政府提出了“一杯牛奶强壮一个民族”的口号，同时颁布了《学校营养午餐法》，以法律的形式要求小学生必须每天喝一杯奶。

牛奶对于儿童的好处主要也就是体现在身高上。最近一项在肯尼亚的关于儿童的研究表明，喝牛奶可以帮助那些生长迟缓，身材矮小的孩子在身高上加强发育。但注意，这也仅仅是追上那些不喝牛奶的孩子的正常身高。喝牛奶，并没有让这些孩子的身高，有超越平均的表现。

虽然孩子可以坚持喝牛奶，但牛奶对于成年人到底有没有特别的好处，到现在也没有定论。不过有一点，牛奶绝不是喝得越多越好。

2014年，瑞典的一项研究发现，坚持20年每天喝3杯牛奶的人死亡率，比一天喝一杯的人群的死亡率高。但如果是发酵的奶制品，比如酸奶、奶酪，就不仅可以降低死亡率，而且还能降低骨折的风险。

总之，孩子可以多喝牛奶，成年人可以选择发酵奶制品。

这里需要特别提一下牛奶的替代品、富含植物蛋白的豆浆，其实，豆浆也不是十全十美。

关于豆浆的好处和牛奶一样，到现在也没有确切的实验来证明，但一些实验却表明，喝豆浆会增加患乳腺癌的风险。

![](img/2b1f55794a32401f6e1d5425100884b9_73_0.png)

### 咖啡没那么“坏”，茶也没那么健康

咖啡最受人诟病的一点就是咖啡因成瘾性。

这一点在文章的一开始就被否定了。北爱尔兰食品与健康中心的Kirsty Poursahidi认为，人们对咖啡因的成瘾是很容易就可以戒除掉的，只要每天减量，4周就会有显著的效果。

咖啡还有一个好处是它富含绿原酸，这种物质可以减缓人体对葡萄糖的吸收，而且通过对喝咖啡的人群观察也显示，他们得Ⅱ型糖尿病的风险确实更低。

可以说，咖啡没那么“坏”。

再来说说茶。谈到茶咱们一般人的反应都是：喝茶有益健康。

茶对身体确实有好处，比如说红茶中含有一种叫做茶单宁的物质，能抑制身体吸收脂肪和淀粉，还能提高新陈代谢。

但这并不是说喝茶就可以减肥。研究显示，喝红茶对体重的影响是几乎可以忽略不计的，少喝和健康都没什么大关系。

文章建议说，千万别多喝。有一位女性，17年以来，每天居然能喝下100~150包袋泡茶，结果在47岁的时候满口牙全掉了。

当然这只是极端的情况，关于喝茶，适量就好。

## 本期杂志：《新科学家》

## 知识清单

### 联邦和邦联的区别

首先，最简单的区别就是小和大的关系。邦联里可以包含联邦，但联邦里不可能有邦联。举个例子，英国属于典型的联邦制国家，和欧盟就是一个邦联，所以英国可以是欧盟的成员，但倒过来不行。

第二个区别是，联邦有自己的中央政府，而邦联没有，它只有议会和成员国的首脑会议。联邦的中央政府的决定有法律效力，但邦联的首脑会议的决议，没有法律效力。这就是为什么英国政府的苏格兰要脱离英国那么费劲，但是英国要脱离欧盟虽然麻烦，却没那么难。

### 欧盟的历史

当初欧盟建立的基础，其实是一个梦想，就是要拧成一股绳，成为世界上一支举足轻重的力量。要了解欧盟的历史，只需知道两个文件，就是60年前的《罗马条约》和25年前的《马斯特里赫特条约》。

《罗马条约》

1957年3月25日，比利时、荷兰、法国、西德、意大利和卢森堡的领导人齐聚罗马，签了《罗马条约》。这条约由两部分组成：欧洲经济共同体和欧洲原子能共同体。

1967年，这两个共同体和1952年成立的欧洲煤钢共同体一起，组成了“欧共体”。它是欧洲主要国家政治和经济集团的联合，也是欧盟的前身。

《罗马条约》的主要作用，就是把原来联合的欧洲的理想，变成了现实的条约，所以《罗马条约》是欧洲国家联合起来的奠基石。

《马斯特里赫特条约》

1992年2月7日，在荷兰南部的马斯特里赫特市，12国代表签署了《马斯特里赫特条约》，创造了开放边境、使用同一种货币的政治、经济共同体。这个构想很接近乌托邦的国家联合形式——只用一种外币流通，只有一种公共身份，保证人们可以在超级集团内自由工作。也就是申根签证和欧元。

从《马斯特里赫特条约》开始，原来的“欧共体”变成了现在的欧盟。

所以，今年不仅是《罗马条约》签署60周年，也是《马斯特里赫特条约》签署25周年。

### 欧盟的作用

欧盟的作用非常大，它保证了欧洲政治和经济稳定。两次世界大战都是发源于欧洲，欧洲的稳定，对世界的安全和和平非常重要。所以，欧盟曾经在2012年时，因为促进和避免战争，获得了诺贝尔和平奖。这个超国家集团现在扩张到了28个成员国。

### 欧盟中的民族主义

法国即将进行总统大选，第一轮在4月23日举行。参与竞选的有“法国特朗普”之称的勒庞，她作为欧盟的质疑者，主张恢复法国自己的货币法郎，而且要举行脱欧公投。而且在这个月，英国首相将正式启动脱欧进程。

荷兰已在3月进行了大选，之前民调预测的激进民族主义政党——自由党没有获胜，但他们依然在荷兰下议院占了19个席位。这个自由党主张禁止《古兰经》、在荷兰“去伊斯兰化”，而且也要举行脱欧公投。

如果照现在的情况发展下去，欧盟存续的希望将会很渺茫。

### 欧盟的困境——无处不在的危机

比利时首相查尔斯·米歇尔说，“在过去的10到15年里，人们说起欧洲，基本上想到的只有一个词儿，就是危机：难民危机、预算危机、金融危机。我们必须建立一个全新的欧洲，如果没有把握住现在，再也不会有这样的机会了。”

欧盟如今的问题始于2009年，那年在全球金融危机和欧元危机之后，富裕的北欧人，和贫穷的南欧人之间的经济差距也就是贫富差距更大了。而各个国家采取财政紧缩，导致了欧洲发展停滞，引发了高失业率，也在意大利、希腊以及西班牙这几个欧盟成员国引发了公愤。
