# ## 知识清单

**美国《读者文摘》**
一本家庭月刊，作为当前世界上最畅销的杂志之一，它在美国非受中产阶级的青睐。在家庭年收入超过 10 万美元的家庭群体中，《读者文摘》的读者数量，比《财富》《华尔街日报》《商业周刊》三大刊物加一块还多。

**假期忧郁症**
Holiday Blues。就是越到假期，人反而越提不起劲，没什么活力，什么都不想做。美国《读者文摘》，给出了克服“假期忧郁症”的四种方法。

**别强颜欢笑**
面对本来不太喜欢的人，不用了为了面子强迫自己挤出笑容，心理学家指出，这对您的状态会有不好的影响。
2011 年，美国密歇根州立大学和西点军校联合做了一个实验，跟踪几十位公交车司机长达两周时间，观察他们对乘客微笑和假笑后，对自身会有什么影响。研究结果显示，当他们假装情绪很好，并勉强自己对乘客笑之后，他们真实的情绪变得更糟。这种情况在女性中更为明显。
加利福尼亚大学的研究证明了上述观点，就是越勉强自己开心，实际就越不开心。

**不要压制低沉的情绪**
为什么人越勉强自己开心，情绪反而越糟？加州大学伯克分校的 Oliver John 和斯坦福大学的 James Gross 认为，越是刻意压制悲伤、愤怒等消极情绪，反而会越来越强化它。原因是当我们表现出外在的开心，而实际内自并不开心时，两种状态会产生冲突，感觉会更糟。
更重要的是，当我们压制这些消极情绪时，忽视了它们起到的重要作用。悲伤帮助我们发现问题的问题，比如，悲伤是一个信号，代表有什么事让我们难过。如果我们没有意识到情绪背后真正的问题，就不会采取手段来解决。
所以不要压制不开心的情绪，要直面它，找出背后的原因，才能真正改善不开心的心情。
并且，有不开心的事不要自己一个人承受。作者说，对家人和朋友倾诉后受受到的安慰和关怀，不仅能够最大程度地缓解不开心，同时还能拉近他们的距离。而强行抑制，不仅没有从情绪中获得真正的开心，反而会疏远你们的距离。

**仔细观察你的情绪后，谨慎作出回应**
研究显示，当遇到消极事件时，有意识地主动感受自己的情绪而减少之后的压抑和焦虑，对身体有好处，比如可以降低心率，让自己更加平静。
科学家还指出，通过有意识地练习，是能够慢慢掌握这种感受情绪的方法的。

**干了这杯“情绪”调成的鸡尾酒**
文章说，不管是假期还是人生，总免不了会有起起伏伏的情绪，这些情绪带给我们的精彩感受，是我们生而为人最好的礼物。
2014 年，耶鲁大学、哈佛商学院和其他四所高校曾调查了超过 37000 人，发现，情绪的多样性和抑郁是负相关的关系，也就是说，你感受到的情绪越多，你的抑郁程度也就越低。研究还透露，那些情绪比较丰富的人更健康。
所以，一直开心和一直不开心，都是不正常的。悲伤、愤怒等负面情绪，没什么可怕的。努力平衡这些情绪，累的时候，就让自己休息一下。
