# 今日金句

新技术只是促使行业转型的因素，真正令行业转型的，是把新技术和市场需求结合在一起的商业模式。

# 知识清单

什么是商业模式？——一个公司创造和获取价值的方式就是商业模式。

你无法保证创新的成功，但你可以使你的商业模式与新兴技术紧密结合。二者结合得越紧密，你就越可能改变整个行业，从而脱颖而出。

新商业模式需要具备的六大关键要素

**关键要素一、定制化程度更高的产品或服务**
（A more personalized product or service）
很多新商业模式提供的产品或服务，与传统的商业模式相比，更能满足顾客个人当下的需求。采用了变革性商业模式的公司经常利用技术和有竞争力的价格来实现这一点。

**关键要素二、闭环流程**
（A closed-loop process）
很多模式用闭环替代了产品“制造——使用——丢弃”这样的线性消耗流程，使产品可以循环使用。这个转变降低了资源的总成本。

**关键要素三、资产共享**
（Asset sharing）
一些创新之所以能成功，是因为他们实现了最差的资产共享。比如Airbnb就使房屋主人可以和旅客分享他们的住宅，Uber就使车主跟别人分享自己的车。有时资产共享也可以通过供应链实现。这种共享主要通过双边在线平台，为双方解锁了价值：我通过出租闲置的房间赚钱，你得到了一个价格更低、也许环境更好的住处。
资产共享也降低了很多行业的门槛，因为进入者不需要拥有共享的资产，只需要充当中介即可。
