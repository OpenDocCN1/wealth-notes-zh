# 知识清单

+   • 人工智能助手

大科技公司都有自己的智能助手，苹果的Siri，Facebook的M4，微软的Cortana。名字不一样，但功能都是类似的，就是作为一个虚拟助手，为人类服务。

未来人工智能助手可以发展到什么程度：

+   1. 功能将更加多元化

未来，人工智能助手的功能将更加多元。

第一，用法会更多。比如小孩子，给孩子讲故事甚至是辅导孩子功课，未来都可以让人工智能助手完成。

第二，现在要用这些功能，还需要发出声音，未来，可以在耳中塞一个小耳塞，只要默念出需求，不需要发出任何声音，系统就能通过传感识别出来。

除此之外，耳塞还能在试、约会等时候给你指导，比如约会时，对方要聊电影《爱乐之城》，你没看过，就可以用嘴型默念：“《爱乐之城》介绍”，人工智能助手就会把它念给你听。

+   2. 升级为智能个人助理

不管是讲故事还是不发出声音就能识别命令，主要都是聚焦在“对话式”交互上，需要给它一个指令，让人工智能助手去做，但这个还处于“被动”的。

所以，人工智能下一步的发展，是使用场景和方式越来越多样。

比如，个人智能系统将会以代表你去处理事务。微软的个人智能助理Cortana，中文叫“小娜”，是微软游戏“光晕”里的一个虚拟角色。微软“小娜”的负责人Ryan Gavin说，也许在未来10年内，就可以实现这样的功能：你去商场买家具，看好后就给“小娜”下指令，说“小娜，去和他们的机器人沟通一下，安排下付款和送贷”。

此外，人工智能还会朝越来越有“人情味儿”的方向发展，也就是情感智能。它能通过语音、表情、用词，更好地理解用户的性格和感受，不再是用户单方面下指令。

比如，你需要人工智能助手推荐一条路线，那么它不仅会推荐，还会主动向了解释。例如根据你平时的表现，它知道你喜小径，风景优美的地方，所以上一次推荐这条路线给你。

+   3. 共同协作进行艺术创作

人和人工智能系统会有越来越多的合作，尤其是艺术作品创作。比如领域，写诗就是人工智能的一个子领域，叫做计算机创造力。主要功能，就是仿造出一个可以进行创作的算法。

加州大学的作曲家David Cope就开发了一款作曲软件Emilv Howeli。只要提供某个作曲家的作品，软件就能分析出音乐组合的规律，也就是作品在旋律特征、音律结合的新曲子。2010年，他还发布过名为Emilv Howeli的专辑。

+   • 人工智能可能带来的问题

比如人工智能能够在多大程度上代表我们，又能在多大程度上代表我们？它们能代表我们支配我们的金钱么？如果我们要求它们做一些违法的事，这些服务于我们的人工智能是，还是违背我们的命令？

随着人工智能助手的普及，每个人都会属于自己的智能助手，但如果有一天黑客突破了安全防线，控制了智能助手，就可能造成危及生命后果。

总之，人工智能助手最大的问题用两个字来概括，就是边界。包括法律的边界、情感的边界、安全的边界等。如何界定好这个边界，将会是人工智能助手领域面临的最大问题之一。

+   • 中国在人工智能领域举足轻重

中国公司在人工智能这一领域举足轻重。美国人工智能促进协会，每年都会举办一次年会，这是人工智能领域的顶级会议之一。2016年，协会宣布2017年的年会安排时，发现时间正好是中国的农历新年接上。由于中国的研究人员不能到场，会议将不能顺利举行，官方只好重新安排会议时间。

2016年10月，美国白宫发布了一项关于人工智能研究的“战略计划”，提到了人工智能领域的一大热门话题——“深度学习”，但在深度学习这个领域，中国才是大拿，是发表论文最多的国家。
