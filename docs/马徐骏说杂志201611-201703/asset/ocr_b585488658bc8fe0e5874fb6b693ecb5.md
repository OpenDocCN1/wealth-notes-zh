# 知识清单

《财富》杂志由《时代周刊》的创办者亨利·卢斯创办，至今已经有将近90年的历史。杂志主要经营指导问题的研究，被称为“职业经理人的指导手册”。

《财富》杂志1954年推出“全球五百强企业排名”，之后成为了在金融界、商界关注的焦点，它是一本在金融界和商界非常有影响力的杂志。

《财富》杂志推出的这份“年度商业人物榜单”的独特之处而在于，这份榜单并不是根据财富的多少和或者公司排名，榜单评估的是公司领导者或CEO有没有深刻地影响整个商业社会的能力，能否制定大胆和富有远见的战略，以及他们是否交出了一份令人满意的成绩单。

《财富》2016年年度商业人物排名的前三名分别是：

+   第一名，Facebook总裁扎伯格；
第二名，亚马逊CEO杰夫·贝索斯；
第三名，美国美容产品连锁店Ulta Beauty CEO玛拉·司伦。

另外，谷歌的母公司Alphabet的CEO拉里·佩奇排在第四，苹果公司CEO蒂姆·库克排在第十一位。

此外，还有四位中国商业人物上榜，马云排在第十位，王健林排在第六十位，马化腾排在第十八位，而中国排名最高的商业人物，是“滴滴出行”的创始人兼CEO程维，排在第八位。

Facebook在扎克尔伯格的带领下，已经拥有18亿用户，16000名员工，市值高达3500亿美金。在过去的四十年里，公司利润涨了整整五倍，而Facebook的股价在两年之内翻了一番。文章的分析认为，扎克伯格的成功，与他三种能力分开：远见、坚韧和商业布局能力。

1、远见

从哈佛寝室来做Facebook，并在短时间内做到全球这个行业的第二位，没有远见肯定办不到。扎克伯格的远见不止于此，他计划在未来十年里，让全球一半还没有使用互联网的人入口，他能用无人机来布置一个空中的全球网络，以实现自己的计划。

2、坚韧

扎克伯格虽然被认为是擅长写代码的神童，但他一直非常刻苦，扎克伯格在Facebook聚集了一群人才，通过不停探讨来测试自己的想法。

作为一个全球顶尖公司的创始人兼CEO，他对自己的要求始终非常高。正是这种坚韧不拔，帮助他在商业上一直精进。

3、商业布局能力

扎克伯格只要认准了一个投资领域，就会大胆坚持，不惜斥巨资收购。

比如，Facebook在2012年花10亿美金收购了Instagram，2012年Instagram的营收有望达到25亿美金。2014年Facebook又以190亿美金天价收购了WhatsApp，这个产品如今已经帮Facebook在一些新兴领域，取得了非常有力的战略领先地位。

文章认为，耐心总会是有回报的，哪怕是一家匆忙成长的年轻公司。

榜单上排名第五的是微软CEO纳德拉。2014年纳德拉接替费尔默成为微软CEO，此前他已经在微软整整工作了24年。

纳德拉接手微软的时候，微软已经到了生死存亡的关头，陷入了“增长危机”。

2010年，苹果公司在乔布斯的带领之下，抢走了微软“世界上最有价值公司”的头衔，这个节点也成为微软首次面临核心业务下滑的转折点。

纳德拉为了带领微软走出困境，做的最重要的一件事，就是改变微软的核心业务。

之前的微软专注于个人计算机（PC）领域，纳德拉将微软的核心业务转为专注于企业和云计算。
