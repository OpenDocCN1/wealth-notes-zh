# 知识清单

《新闻周刊》是美国三大新闻杂志之一，创刊于1930年代。它的价值观偏右，立场较为保守。

玛丽娜·勒庞

法国国民阵线党主席，有“法国特朗普”之称。

她是一位右翼保守派政治家，很多主张跟特朗普接近。

玛丽娜·勒庞已经取得了明年法国总统大选的参选资格，她承诺，一旦当选，就会召集法国民众，像英国一样进行一次“脱离欧盟”的公投。

如果法国“脱欧”，那么联盟就将真正的分崩离析，玛丽娜也因此被称为“法国最危险的女人”。

2015年，西方世界的右翼党派和“民粹主义”的势力还非常渺小。

但到了2016年，情况发生了巨大转变——上半年英国脱欧，下半年特朗普在美国总统大选中胜出——这标志着整个世界“民粹主义”的浪潮，正在声势浩大地席卷开来。

文章认为，冷战结束后，世界是第一次出现像今天这样，保守派如此强势地位的情况。

文章指出，这一轮全世界范围“民粹主义”的兴起，背后的根本原因有三点：

+   1. 贫富差距的加大
    今天的世界，贫富差距比25年前冷战结束时大得多，根据《福布斯》杂志的统计，世界上最富有的十个人，拥有大约5000亿美金的资产，这种量级的财富，甚至超过了许多国家。
    而这些富有的个人和他们所代表的势力，正用金钱影响政治，巩固自己的优势，后来者的追赶，变得越来越困难。

+   2. 全球化带来的移民问题
    在西欧的许多国家，普通老百姓没有享受到全球化带来的好处。
    但全球化，使他们的国家涌进了大量移民，带来了许多社会问题，他们如切切身的感受，比如教育、医疗资源分配不足、恐怖袭击越来越频繁，这些都让西方世界的平民感到不满。

+   3. 社交媒体的推波助澜
    网络技术带来社交媒体的繁荣，也加速发酵了民众的不满。

法国民粹主义，是由玛丽娜·勒庞的父亲老勒庞一手创立的极端右翼政党。

玛丽娜一直追随父亲从政，直到老勒庞的班，成为国民阵线党的领导人。

但是玛丽娜同父亲的政见有很多不同之处，相比父亲而言，她的政见更加温和。比如，老勒庞对二战时德国人屠杀犹太人可以为妄，但是玛丽娜对此极度谴责。

在政见上，父女两个人有很深的矛盾，玛丽娜甚至扬言要开除父亲的党籍。

玛丽娜·勒庞的政治主张主要有三条。

首先，她呼吁面对恐怖袭击，法国人必须武装起来，保护自己，从警察到军队甚至到海关，都应加强军事戒备。

其次，她排斥伊斯兰组织，号召关闭受极端主义思想影响的清真寺，驱逐那些在法国搞传播极端思想的外国人和无所事事的非法移民。

最后，在经济上，她主张退出“欧元区”，认为法国应当设立贸易保护措施，并要求对欧盟的各项条款重新展开谈判。

这些主张和特朗普以及英国“独立党”的主张非常相像，在法国有一定的民意基础。

文章认为，以玛丽娜·勒庞为代表的欧洲右翼势力，他们中间很多人并不是真正的“极右主义者”，而是“投机分子”。这些人在主流政治圈里，属于边缘人，现在想借机捞取政治资本。

各国右翼势力之间的政见也并不相符，存在着根本的利益冲突。

文章指出，这些右翼党派的主张，都是把自己的国家关起来，不跟世界接触，并且叫嚣把自己放在第一位。

而按照这个逻辑运行，他们之间一定会产生非非常大的分歧甚至是冲突。真正遇到利益冲突的时候，他们不会以“合作共赢”的思路来解决问题。
