# 知识清单

《纽约书评》是文学类的刊物，同时包含文化、时事的内容，还生于1963年纽约出版界大罢工的影响下。《纽约书评》很擅长分析，从一本以书为靶标，发表自己观点的报纸。

《华盛顿邮报》的一家报道指出，Facebook收集了近20亿用户的个人信息，多达30页。这些数据包括姓名、性别、族裔，收入以及婚态状况等。

+   1、利用人脸识别技术，自己上传的，比如面部状况，年龄等基础信息；
2、利用人机识别技术，Facebook能在网络中找出你。比如通过全校毕业照识别出你的脸，知道毕业于哪所大学；
3、可以通过用户的上网痕迹。即使用户在设置中关闭了“追踪上网痕迹”功能，但是只要用户点击了某些任何同界界中Facebook的广告链接，Facebook就可以追踪到你的上网记录；
4、Facebook还会向全世界的数据挖掘商用出售用户的个人数据。比如用进什么优惠券、工单量，甚至是用户家人的出生证、死亡记录、与公司注册的信息等等。

用户个人行为产生的数据，会由算法进行相应的广告定制，广告商甚至可以精准找出用户的“痛点”。比如说，广告商会给工作前景不太好的人推荐当兵的培训课程，或者信用记录不好的人，推荐“发零工资放”的广告。

发零日贷款
针对个人的小过贷款，一般在500美元左右，特点放放数的公司不会检查用户信用，哪怕无固定收入，只收取服务费，服务费率每个月10%-30%之间，贷款收取是借着放入下个月发薪的那一天，通过银行转账扣款来实行。这种发零日贷款往往会造成一个长期滚放，年化利总率能达到惊人的300%。
文森认为：“导读”，它算法会扫描你的网页，以得到入指。然面出你的个人信标来定你的网站，比如比如到了一下。

用户在网上产生的各种行为数据，经算法抓取后，会用来对用户本人进行评判。剑桥大学的心理理学研究中心的研，测一个个人在Facebook上的“点赞”行为，可以预测一个人性格的特征特质，包括外向性、开放性、开放性、宜人性、情绪稳定性等。

研究者为此编出了一个算法叫“预言引擎”，也就是说，你在Facebook上点赞的行为，可以表明你是一个什么样的人。
“预言引擎”被交给了一些公司，用来评判个人。比如，一个人给《纽约书评》写了评论，算法认为这个人的思维偏向女性，还有一些保守倾向；如果你是一个男性，那么算法会判定你有50%的可能性是同态者。

文森认为，这些“代表”的情况进一步发展，会在网上形成一个“虚拟的你”。而网络中“虚拟的你”，又会影响到个人现实中的方方面面。
比如说在Facebook喜欢的内容会形成了性格分析。公司可以以用来来决定你的作岗位。一个在网络上经常说发八卦的员工，文森认为，这个员工对公司的忠诚会很低。

Facebook还要发出一台套算法叫“关系网”，用来判别一个人的信用。
比如你有一个朋友在盒子里工作，你的信用分数会因此而有提升；如果你有个方因激废的艺术家朋友，那么你的信用分数就会因此下降。

文森认为，人们在认知上有一个巨大的误区，就是算法往往是客观公正的。但文森说，人们忘记了很重要的一点：算法也是人制定的，在制定算法规则的时候，已经包含了个人的偏见和态度。
