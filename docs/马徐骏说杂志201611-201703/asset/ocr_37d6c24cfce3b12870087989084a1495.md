# 内容简介

+   1. 现在，谁最热衷于延长人类寿命？为此投入了多少钱？
2. 在科技的帮助下，人们在延长寿命这件事上取得了什么样的进步和成就？
3. 现在有哪些方式，可以延长寿命，需要付出什么代价？
4. 对于普通人来说，有哪些切实可行的长寿建议？

# 知识清单

+   • 人类对于长寿的追求从未停止

从古至今，人类对于长寿这件事情的追求从未停止。《时代周刊》的专题列举了一张图表，讲的是从公元前1600年到现在，人类为了活得更久，都做过哪些努力。比如，人类吃过各种各样奇怪的植物，而中国传统的炼丹术里，就把各种重金属甚至是水银放在一起炼丹丹。还有把动物的组织移植到人的体内、喝血、用驴的奶水洗澡等等方法。

甚至在上世纪20年代，人类还认为辐射可以延长寿命，并且有人试过接受辐射，结果可想而知。

+   • 谁最热衷于延长人类的寿命

目前世界上对于长寿最狂热的，不是研究生命科学和生物的科学工作者，而是硅谷知名的企业家。

比如，甲骨文软件公司的创始人叫拉里•埃利森，他已经花了3亿3000万美金来专门研究衰老和治愈老年病。

谷歌联合创始人拉里•佩奇，甚至为此专门成立了一个公司，研究如何延长人的寿命。而创业教父彼得•蒂尔，光是给一个研究如何延长生命的非营利性组织——玛士撒拉基金会，就捐了700万美金。

这些硅谷大佬，将自己的巨额财富和最前沿的科技结合起来，他们不少人的目标，是要活到180岁，甚至更长。

+   • 人类目前能用什么方法来延长自己的寿命

《时代周刊》的报道列举了4种现有的延长寿命的方法。

第一个方法是输血。就是把健康年轻人的血，输给那些年长的人。在美国，有一家公司专门提供这样的服务，名字叫Ambrosia，翻译过来是神的美餐。大概有50人各花费了8000美金，从16岁到25岁的身体健康的年轻人那边买血，注入到自己的体内。这家公司提供的理论认为，年轻人的血液里有一些可以帮助细胞进行修复和再生的因子，这些因子年纪大的人身体里较少。所以，注入年轻人的血液，可以帮助老年人延缓衰老，恢复活力。

但加州大学伯克利分校的生物工程学教授Irina指出，这个事只在动物身上做过实验，虽然健康状况有所改善，但不是特别明显，并且在人体上的效果并未得到验证。即便有作用，对于老年人的帮助也是有限的，但对于那些大量捐血的年轻人来说，伤害其实很大。

第二个方法是给身体做一个全面的像素级别的检查，进行基因组的测序和生物切片。通过这样的方式，可以预知你可能患有的病变，以便预防，甚至是提前手术。

但检查花费非常昂贵，一次需要25000美金。到目前为止，美国只有400人做过这样的检查，他们从30岁到95岁，其中有40%被查出了健康上的隐患，比如癌症、动脉瘤甚至是心脏病。哪怕他们自己没有感觉到自己有什么问题。
