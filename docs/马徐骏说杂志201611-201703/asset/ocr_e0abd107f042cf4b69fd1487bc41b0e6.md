# 知识清单

《纽约客》是一份来自美国的知识、文艺类的综合杂志，涵盖新闻报道、文艺评论、散文、漫画、诗歌、小说，以及纽约文化生活动态等内容。

《纽约客》上大量的内容是关于纽约当地文化生活和报道。他由于杂志高质量的写作和严谨的编辑作风，拥有众多纽约以外的读者，享有世界声誉。

文章的作者Amy Davidson是《纽约客》的资深编辑，在国家安全问题、国际报道以及一些专题报道上功力深厚。她认为，特朗普可能是“本世纪最糟的一任美国总统”。

Amy Davidson指出了特朗普的两个问题：任人唯亲和公私不分。

1、任人唯亲

特朗普在总统权力过渡期里，炒掉了指派给他主导政权交接工作的官员，并把自己的儿子、女儿、女婿，带入了总统权力交接团队。

不光任亲信，他的带向和启用和自己亲近的人，特朗普任命的幕僚和总统，多为种族主义者或极端保守派。

比如，特朗普即将任命的美国司法部长Jeff Sessions就是标准的“种族主义者”，他对美国3K党持欣赏态度，而3K党是美国种族歧视的代表性组织。

特朗普即将任命的白宫“首席策略师”是位反伊斯兰分子，即将任命的中央情报局局长则一度号称要“处决斯诺登”。

2、公私不分

作者指出，总统应该同自己生意上的利益划清界限，至少不能亲自做生意，否则容易以权谋私。

但目前看起来，特朗普并不愿意放下生意。
