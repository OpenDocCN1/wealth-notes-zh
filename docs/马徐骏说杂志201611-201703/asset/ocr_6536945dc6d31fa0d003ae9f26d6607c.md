# 卡斯特罗的“革命之路”

本条音频及文稿参考《时代周刊》12月12日刊

![](bbox=[0.1, 0.09, 0.9, 0.12])

# 知识清单

《时代周刊》认为，古巴前领导人菲德尔·卡斯特罗可能是人类历史上最能代表“革命者”这个概念的人。大胡子是他最鲜明的标志，他的时钟曾说：只有在自我实现了革命使命的时候，才会刮胡子。直到90岁去世，卡斯特罗也没有刮标志性的胡子刮须。

有人认为，在卡斯特罗2008年交出权力之后，古巴仍然在延续着他的革命道路，这也证明了卡斯特罗的成功。

但文章指出，很难说卡斯特罗的革命还能继续保持下去，甚至在很多年前，从某种意义上说，卡斯特罗在古巴的革命就已经宣告失败了。

卡斯特罗的革命道路可以分为三个阶段：第一阶段，走上革命之路，成功颠覆旧政权，跟美国闹翻；

第二阶段，1960-1970年代，也是他在古巴最辉煌的十年；

第三阶段，自己衰落，直到卡斯特罗退出世界政治舞台。

文章指出，世界上大多数的革命都是由中产阶级领导的，古巴革命是个例外。卡斯特罗出生在一个中产富裕家庭，19岁时进入古巴哈瓦那大学读书，开始接触到左翼组织。

1953年，卡斯特罗弟弟劳尔·卡斯特罗，以及、格拉瓦一起组织了“古巴革命军”，跟当时统治古巴的巴蒂斯塔政府对抗。

1959年，他们推翻了巴蒂斯塔政府，建立了革命政府。

取得政权后，卡斯特罗出访的第一个国家就是美国。

古巴跟美国闹翻，主要出于两个原因：一是民心底层，古巴人对于美国干涉古巴内政很恶德憎。

二是因为卡斯特罗政权在古巴没收了一大批美国财产，同时清理旧政府，很多一批旧政府的官员、普通古巴人因此逃往美国，而美国收养了这些人，这导致了卡斯特罗的不满。

这些原因最终让古巴和美国关系走向破裂。

# 古巴“猪湾登陆”事件

1961年，在美国政府的支持下，1400名由古巴流亡者组成的反帝组织了一支部队，在古巴一个名叫“猪湾”的地方登陆。

古巴军队最终取得了胜利，参与“猪湾登陆”的1400名人中，100多名流亡分子被击毙，1200人左右被俘。击退“猪湾登陆”提升了卡斯特罗在古巴的声望。

# 古巴导弹危机

1962年，苏联在古巴布下用来发射核弹头的弹道导弹，这导致美苏关系进一步紧张，核战争一触即发。最终，苏联将导弹撤出了古巴。

1960-1970年代，是卡斯特罗的黄金生涯，他的第二个时期，也是他最辉煌的十年。由于在苏联的经济援助下，基本实现了温饱，并且还实行了全民免费医疗和免费教育。卡斯特罗的声望在这段时间达到了顶点。

但《时代周刊》认为，医疗与教育免费，并不代表当时的古巴的医疗景的是好的。因为当时有“冷战”大背景，来自苏联的援助，卡斯特罗才有底气实行免费的医疗和教育。

而美国当时的对古巴实行经济制裁，这也掩盖了卡斯特罗时代失败的经济政策，因为他可以把美国，作为本国经济不振的替罪羊。

1980年代，古巴革命开始走下坡路。一是经济停滞，古巴最主要的经济命脉——蔗糖出口，不足以维持整个古巴的旅行。

二是人才外流，1980年代，有125000左右的古巴人逃到了美国的佛罗里达，这些人有很大一部分受过高等教育。苏联垮台，古巴也在经济上失去了最大的援助。

由于身体原因，2008年，卡斯特罗将权力交给了弟弟劳尔·卡斯特罗。劳尔·卡斯特罗掌权后，改变了许多卡斯特罗原本奉行的政策。比如允许美国游客来古巴大量消费，并且在2015年恢复了间美州的邦交。
