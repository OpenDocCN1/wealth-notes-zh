# 知识清单

“职场倦怠”指的是长时期处在压力环境下工作，并由此产生了情感、态度和行为上的衰竭状态。

造成“职场倦怠”的三大原因分别是：行业大环境的改变、重复的工作、团队中的人际冲突。

“职场倦怠”的典型症状有三种：疲惫、去人格化和无力感。

对抗“职场倦怠”的三种方法：

一、改变视角
通过审视自己的状况，理辨“职场倦怠”产生的原因到底是什么。评估现状，找出问题，然后对症下药。

二、减压
你需要关注那些虽然很有价值，但仍然会引发不健康压力的活动和关系。关于你做什么、做多少，你需要让同事、客户，甚至是家人调整他们的预期。
与此同时，你要建立关于合作的规则。你可能因此遭到阻力，但你必须要知道，这些改变将提升你的长期生产力，保护你的健康。

三、建立积极的人际关系
“职场倦怠”最好的解药是寻求积极的人际关系。
多和人交流、请教一些建议，并从他们的经历中汲取能量和对你有用的东西。
与此同时，主动地为人提供帮助建议，也能特别有效地打破恶性循环。
能量的来源主要有四个，分别是——身体、情感、思想和精神。通过形成特定的习惯，以上每个来源都能为我们系统性地并且及时地补充能量。

你是否正一步步陷入“能量危机”？请在符合自己实际情况的陈述前打钩。

+   1. 身体
□ 我无法保证每晚至少睡7-8小时，醒来时常常疲劳。
□ 我经常不吃早餐，要么就是对付着吃些没太多营养的东西。
□ 我运动量不足（充足的运动是指每周至少3次循环系统的训练、1次力量训练）。
□ 在一天的工作中，我没有定时休息的习惯，因此能量得不到真正的补充；我要么根本不吃午餐，要么经常在办公桌前吃。

+   2. 思想
□ 我很集中精力开始善终地做好一件事，总是容易为杂事而分心，特别是被电子邮件干扰。
□ 我每天把大量的时间用来应付迫在眉睫的危机和需求，而不是专注于具有长远价值、蕴藏巨大优势的活动。
□ 我拿不出充足的时间进行内省、战略构想和创造性思维。
□ 我晚间和周末都要工作，几乎没有哪个假期可以不需要收发电子邮件。

+   3. 情感
□ 我发现，自己在工作时总是脾气暴躁、缺少耐心、焦虑不安，尤其是碰到棘手任务的时候。
□ 我没有足够的时间来陪家人和至爱亲朋，就算我在他们身边时，也是人在心不在。
□ 我没有多少时间来自我享受我喜欢的活动。
□ 我很少有空对他人表示赞赏，也不会享受成功带来的喜悦。

+   4. 精神
□ 我没有为自己最擅长和最喜爱的工作付出足够的时间。
□ 对于某些事务，虽然实际上说它们是我生活中最重要的部分，但实际上我为它们分配的时间和精力少之又少。
□ 我的工作决策常常受到外部需求的影响，而不是决定于内心强烈而明确的目的性。
□ 我没有投入足够的时间和精力，对他人或这个世介施加积极的影响。

你的总体能量如何？算出打钩的总数：
0~3分：能量管理技能卓越
4~7分：能量管理技能合理
8~10分：能量管理技能存在严重缺陷
11~16分：完全陷入能量管理危机
你需要在哪些方面加强努力？不妨算出——身体、思想、情感、精神——四大类分别打钩的数量。
分数指南：
0分——能量管理技能卓越
1分——能量管理技能优秀
2分——能量管理技能存在严重缺陷
3分——能量管理技能较差
4分——完全陷入能量危机
