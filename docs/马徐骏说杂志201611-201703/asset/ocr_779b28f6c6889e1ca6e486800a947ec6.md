# 奥巴马是不是一位好总统？

本篇音频及文稿参考《大西洋月刊》12月刊

![](bbox=[0.08, 0.1, 0.92, 0.15])

# 知识清单

《大西洋月刊》是一本综合性刊物，内容涉及政治、科学、文艺等方向，被誉为“美国最受尊敬的杂志之一”。这本杂志历史悠久，始终坚持无党派、无偏见，且文章具有很高的艺术性，包括海明威在内的很多重大文章，都在《大西洋月刊》上发表过文章。

### “幼儿园测试”

文章的作者认为，当一位美国总统，与当一位幼儿园老师在很多方面有相似之处，也就是说，他们都要有在工作结束之后，把手头事务处理干净、平稳交接的能力。而对于这种能力的评测，被作者称之为“幼儿园测试”。

文章指出，能在卸任时不留下大问题、通过“幼儿园测试”的总统，其实并不多。

第36任美国总统林顿·约翰逊离任时，留下了“越战”问题；第37任总统尼克松留下了“水门事件”的丑闻；而吉米·卡特总统和小布什总统都留下了经济不振的窘境。

文章的作者认为，奥巴马在这个问题上就做得很好，他通过了“幼儿园测试”，卸任时没有留下大问题。这相当于给继任的特朗普留了两份大礼：时间和自主权。

+   1. 时间。即特朗普可以快速开展工作，不用先花大量时间处理前任总统遗留的工作尾巴。
2. 自主权。即特朗普不用受到奥巴马施政纲领的影响，能够按照自己的设想治国理政。

作者认为，作为总统，奥巴马一共做好了五件事：

### 一、复苏美国经济

奥巴马接任总统时，美国的经济状况不容乐观，经过其八年努力，美国经济已经开始再现活力。并且奥巴马还解决了全球化、贫富差距和税制改革等一系列问题。特朗普接棒奥巴马时，无需为经济太过担心。

### 二、解决国内安全问题

奥巴马就任总统期间，美国的犯罪率达到了自1970年代以来的历史最低点。

重要的是，奥巴马是在全球恐怖活动升级的大背景下，做到的这一点，非常不容易。

### 三、推动医疗改革

在奥巴马的“医疗改革方案”提出之前，美国的医疗保健状况非常糟糕：普通人减少或不买医保，同时医保价格持续升高，形成死循环。

奥巴马的医改出台后，不参加保险的人数降低了近二个百分点，医疗费用的上涨速度也放缓了。可以说，奥巴马为美国的整个医疗系统争取到了非常宝贵的改革时间。

### 四、重视环境问题

相比较起美国人普遍对环境危机的冷漠态度，文章作者认为，奥巴马在任期内达成《巴黎协定》——美国将共同与未来世界的环境保护——是重要的政绩。

### 五、采取了灵活的外交政策

作者认为，奥巴马更好地处理了美国同伊朗之间的关系，使两国之间因为核武器等问题剑拔弩张的氛围，得到缓解，避免了武力冲突。

作者认为，能够把一场大的危机，化解为相对可控的问题，就是一场胜利。

当然，奥巴马也遗留了问题：

+   1. 在叙利亚和伊拉克的IS恐怖组织的问题上，奥巴马的处理并不妥当。但作者认为，他至少坚决没让这些局部的地区冲突，升级成美国需要进行军事干预的状况。
2. 相比于上世纪的越南战争，这对于美国还不算是太大的危机。

+   2. 奥巴马没有实现自己所许的“变革”。

奥巴马赢得选举是打着“变革”的旗号，他曾承诺要改变华盛顿当时的政治状况，但并没有做到。直到奥巴马任期结束，大家也没有明显地感受到所谓的“变革”，这也是很多人对奥巴马表示失望的原因。

文章作者认为，很多人对于总统所谓的“功绩”，往往有一种不切实际的想象，比如，认为总统就要赢得一场战争、取得巨大的外交胜利或者完成一次轰轰烈烈的改革。

但作者强调，这些人忽略了一点，就是一个总统可以干的坏事，要远多于他能做的事。他们坐在白宫里，身边遍布地雷线，稍微不当心就可能触雷，引发一场巨大的灾难。

“柯立芝繁荣”，是指“一战”之后美国经济的高速增长时期，这段时间正是美国第30任总统柯立芝的任期，因而被称为“柯立芝繁荣”。

小说《了不起的盖茨比》就是以这个时代为背景。
