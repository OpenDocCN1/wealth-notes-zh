# “睡眠清单”

美国的乔·斯蒂文斯在短暂研究睡眠问题后感到困惑，也想了解更多关于睡眠的知识。在这篇文章里，他想告诉大家一些关于睡眠的共识以及他自己的研究成果。

+   文章主要讲了三个知识点：
第一、我们到底需要多少时间的睡眠，换句话说这应该让自己少睡一点？
第二、用这些来保持怎样的节奏才能保持清醒，对睡眠友好还是有害？

人到底需要多长时间睡眠？
根据2014年发表在流行病学期刊的一项研究，女性一天大概需要7.6个小时的睡眠，而男性需要7.7个小时的睡眠。

美国神经科学家的一篇文章则指出，一天在24小时里，一个人至少需要6个小时，如果偶尔某天睡不到6个小时的话，很有可能被刺激得到，长时间缺少睡眠对心脏病、中风的发展都有潜在风险。

为什么有些人睡眠少，但看起来依然有活力？
史蒂称，世界上最长记录的不睡觉纪录，是1964年由一个17岁的美国男孩创造的，他坚持了264个小时，也是11天没睡觉，结果精神崩溃。在这个岁数里，他没有任何记忆性损伤。24小时里他的表现也未有受影响。

睡醒时不要看手机，因为这样人类天生如此。而且肯定说15%可以睡得少的人，他们也知道少睡会提高对他们的大脑代谢以及其他身体机能方面各种各样的影响。

少睡可以通过后天训练吗？
答案，不可以。

美国军方曾做这个关于这方面的研究，训练士兵少睡觉，结果每天睡不足6个小时的士兵，虽然第二天仍旧有战斗力，但实际出错的几率是正常睡眠的两倍，更不可接受的。

史蒂说，尽管他个人可以在24小时内保持清醒，但不太可能像那样工作。

我们可以怎样让身体第二天保持清醒？比如，测试题。
有报道称，大约90%的成年人，每天在下午都会有两次或更多的困倦感。人约85%的美国成年人每天在下午3点左右会感到昏沉，即使午休半小时，但这种影响没有多大影响。

认知信息处理的过程对我们有益的吗？
文章指出，当人感到压力时，大脑会迅速分泌肾上腺素。当我们感到危险的时候，血液也会涌上更多的肾上腺素，注入血液，导致我们平时做不到的事——让大脑更加紧张，更加警觉，更加充满活力。

由丘脑下部和海马体，通过连接杏仁核与海马的突触，形成整个情绪回路，让大脑让人醒来。为了保持，又会增加其他的神经连接。

什么会让我们更累？
大量光线刺激视网膜上的蓝光，抑制人的运动、食欲、心率恢复，也都影响人的情绪。增加兴奋度。例如晚上睡觉时暴露在蓝光下，在晚上分泌的激素（褪黑素）减少，进而调低我们的体温，并延迟进入深度睡眠的时间。

晚上，人体会分泌更多褪黑素，以压制大脑的活跃。因为晚上眼睛的光感受器对暗光更敏感，会影响对亮光的判断，对褪黑素的分泌减少，这也是为什么我们在黑暗中更难以入睡，而长时间的光亮让人保持清醒。

长期服用睡眠药物会有什么后果？
文章指出，大多数处方睡眠药物是作用于中枢神经系统的镇静剂，它们的作用时间比正常睡眠更短，因此可能会导致人在第二天感到昏沉。

用这些药物来改变人的生物钟，但效果并不如人意，甚至会导致严重的副作用，例如上瘾，药物耐受性，以及停药后的反跳性失眠。

+   三条睡眠建议：
第一，尽量在固定的时间上床睡觉，并在固定的时间起床，周末也不要例外，保持自己的生物钟正常运行。
第二，对那些固定的睡眠时间更有弹性，少减少对刺激或压力。
第三，睡前2-3小时避免使用电子屏幕，可以在床上看纸质书，或进行冥想或伸展运动。

所以以后怎么睡？
人的生物钟为入睡和清醒设计，如果在一段深长的睡眠周期中突然被吵醒，人会感到不适，一天可以只少两次，但如果你是在做梦的睡眠周期中突然被吵醒，这会更糟糕，可能会带来更强烈的不适感。

所以，如果你的目标是早上要早点起来，不要睡过头，立即起身。因为过一个完整的睡眠周期结束后，起来会更容易。
