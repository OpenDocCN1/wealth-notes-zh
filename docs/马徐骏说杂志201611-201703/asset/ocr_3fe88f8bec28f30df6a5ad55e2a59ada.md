# 特斯拉如何切入销售快车道？

本文源自《快公司》

![](bbox=[0.1, 0.065, 0.9, 0.12])

你好，欢迎来到《马斯克说杂志》。

今天，我为您从 Fast Company 也就是《快公司》杂志里面选了一篇跟特斯拉有关的文章。

咱们先来简单介绍一下《快公司》，这是一本商业杂志，主要是告诉读者，如何在全球商业模式中获得领先，就是在竞争

中怎么样才能胜出，所以它会关注那些高速成长的新兴企业。既像特斯拉这个领域，就是快道的信息，在快车道上，也是近几年商业领域绕不开的一个话题。

首先，特斯拉在电动车行业里做出的革新，我们很多人都知道，但这篇文章叫《特斯拉的快车道》，它讲的并不是特斯拉造车的方式，它要告诉你的，是特斯拉在汽车销售上也要刮开新面的，有自己的一套直营模式。英语的“Fast Lane”是快车道的气息，在快节奏上你可以知道油门通过其他车，对上这个词指忙碌而刺激的生活，在这里是个极好的双关语。特斯拉在汽车销售上，比其他人类了，面临也的挑战就更多了，也真的够刺激的。

文章的主笔是 Fast Company 的资深编辑 JJ.McConvey，下面我们就分享下这篇文章里提到的，特斯拉在汽车销售领域有些什么之处。

![](bbox=[0.1, 0.385, 0.9, 0.43])

文章讲了两个问题：

+   * 第一，特斯拉的营销模式到底是什么，以及跟美国传统的卖车方式有什么区别；
* 第二，特斯拉的这种方式在美国又遭遇了什么问题。

咱们先来说第一个问题，特斯拉的营销模式到底是什么。

美国一般传统的卖车方法是采用代理的方式，就是汽车制造商把车造好了之后，先卖给各个区域的代理商，再由这些代理商把汽车卖给消费者。特斯拉模式就不一样，它采取的是一种直售的模式，就是线上订购与线下的直营体验店相结合，这种方式，越过了经销商的网络。

特斯拉美国销售副总裁 Ganesh 认为，这种方式是非常重要的，因为只有这种方式才能保证销售模式的完整性，把特斯拉的使命与价值完全地传达到终端客户手中，而且在整个服务过程中每一个环节都不会打折。

特斯拉目前采取了5种展示和销售的方式，咱们一个一个来说。

+   1. 体验店
进店体验店你既可以试驾也可以购买，同时店里还提供充电、维修这样的服务。

+   2. 展示厅
这个跟体验店差不多，只是在这种展示厅里面，你是不能直接买车的，如果问价格，你就会转到网站或者找销售。

+   3. 直营店面
在这种店里可以进行真的购买，前提是特斯拉要美国的当地的这个，有销售许可才可以。你听了前两个也许会觉得：差不多嘛，为什么要区分两种模式？这个咱们要到第二部分再讲。

+   4. 游击店
什么意思？就是我们打“游击战”的那个“游击”，英文叫 Pop-up shops。Pop-up 就是突出出现的意思，这种形式主要在美国消费者眼里不太常见，比如说在北京上海这样的大城市，在人流密集的 CBD、或者商场，突然有个集装销过来，里面既没有车也没有销售人员，给你介绍，这种在商业区快闪店，设置的店箱来销售品牌的模式叫做“游击店”。

+   5. 网站
其网站是才是特斯拉的销售核心，作为消费者可以在线与上预约试驾或者进行购买，这种方式添加销售的方式就是特斯拉的直营模式。

那么这种直营模式在美国反响如何呢？答案是非常好！受到了美国顾客的青睐，文章中也说，在2015年埃普森（著名营销咨询公司）的调查中，75%的受访者都支持特斯拉的这种体验很好，因为（消费者）既可以下了解特斯拉的生产过程，同时价格也很透明，不用担心体验。
