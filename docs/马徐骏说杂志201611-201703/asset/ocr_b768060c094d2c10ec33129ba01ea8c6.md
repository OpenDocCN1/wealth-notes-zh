# 知识清单

通用汽车（GM）近些年也是麻烦不断。作为曾经备受赞誉的行业巨头，可以说是在美国最负盛名的公司，但现在已辉煌不再。经历了破产、政府救助，以及导致了139人死亡的点火开关设计缺陷风波之后，通用的形象已经完全变成了“经营不善”、“官僚主义”。

通用以“官僚主义”而闻名。文章给出了两个通用公司内部的专有名词：

第一个是“通用点头”（GM nod）专指会议上表示同意，但实际却什么都不做；
第二个是“通用敬礼”（GM salute）专指推卸责任，只会指责他人。

玛丽·巴拉（Mary Barra）着手进行了和Steve Jobs（史蒂夫·乔布斯）1997年回归苹果之后一样的两个举措：
第一个举措是稳定现金流，从而获取资金投入创新；
第二个举措是组建合适的团队，打造正确的企业文化。
这两个举措不论对传统公司还是初创公司，甚至是个人，都有很强的借鉴意义。

通用在短期内迅速构建了一个“投资组合”，这个组合由五部分构成。可以说，正是这个组合，为通用提供了未来在汽车 industry 赢取成功的必要要素。

# 一、平台

大多数人认为无线连接技术只有硅谷企业才能实现，但是在汽车行业，通用的OnStar系统提供了远程解锁及数据访问服务，这是其他的竞争对手无法提供的。

# 二、合作伙伴

今年1月4日，通用宣布向打车应用Lyft投资5亿美元，Lyft是美国第二大出行共享服务的公司。这个交易为GM提供了一个落脚点去测试和学习，以便在共享出行风头正盛的时候，迅速掌握主动权。

# 三、初创公司

在向Lyft投资的消息公布后的第11天，通用宣布推出专有汽车共享服务Maven。Maven旨在挖掘“个人移动”的另外一种未来：用共享代替个人所有。
Maven提供给用户一个APP，可以用来预定、解锁和开启车辆。
此外，Maven也为另一种可能性奠定了基础，那就是通用将打造和经营自己的无人驾驶车队。
所以，Maven是通用的一方试验田，也是进入市场的一个支点，一旦Lyft出现问题或被竞争对手收购，Maven作为一个备用品牌就可以上场。

# 四、汽车

Barra认为今年年底将售的新型全电动车Bolt将是一款里程碑式的产品。
早在2013年，Barra就与当时的CEO Daniel Akerson发起Bolt项目，目标就是开发一款全电动车——价格实惠，实用性强，保证里程至少200英里，售价仅为3万美元。
这个规格远超福特和日产等竞争对手。虽然价格和续航里程上，Bolt与特斯拉备受期待的Model 3相近，但它推出时间显然早于特斯拉。

# 五、技术

通用在今年采取了像Google和Uber那种更为激进的、一步到位的投资策略。收购了拥有领先无人驾驶技术的Cruise公司。现在，双方正在紧密合作，以实现更大规模的愿景：数百万客户，大多数是年轻人和城市居民，使用Bolt电动汽车实现共享出行。通用和Cruise今年6月份进行了试驾，使用新款Bolt电动汽车，Cruise的技术，最后取得了成功。
