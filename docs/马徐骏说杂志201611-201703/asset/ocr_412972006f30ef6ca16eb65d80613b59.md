# 卡乐星介绍

虽然卖的都是汉堡和薯条，但是卡乐星和肯德基、麦当劳有三个主要区别。

第一，卡乐星的价格更贵。比如在中国，卡乐星一个芝士牛肉汉堡25元，而麦当劳一个芝士牛肉汉堡只有8.5元，双层的多18元。

第二，卡乐星的品牌定位就是为了迎合年轻人的口味，汉堡有大饼和多加会溢出的酱汁，最重要的，就是让卡乐星变得油腻、过瘾、畅快。这也是卡乐星为何在美国流行多年的原因。

第三，也是卡乐星最不同的地方，就是它的广告风格。

肯德基、麦当劳的广告一般都是走温情路线，但卡乐星的广告策略，按照普兹兹普兹兹的说法，就是美国风，或者说很黄很暴力。

卡乐星所有的广告都一定有这样几个元素。第一是美国标志，比如国旗、国徽、自由女神像。第二就是知名女星、性感大明星，比如帕丽斯·希尔顿、金·卡戴珊、国际超模等等。克雷格等出演过卡乐星的广告。这些性感女星，穿泳装，吃汉堡薯条。2015年，卡乐星甚至还推出过一个让超模全裸出镜，只用蔬菜、水果挡住关键部位的广告。

卡乐星的广告在美国曾引发过抗议，家长认为，这些广告都是变向黄片，对小孩子的成长不好。安德鲁·普兹兹则回应：“Get a life!”——拉倒吧。这句话在英文里非常有不屑一顾的意思。

# 安德鲁·普兹兹生平

安德鲁·普兹兹出生于一个工商阶层的天主教家庭，年轻时很反叛、非主流，留长发，反权威。1969年时，还参加过华盛顿的反越战游行。他毕业于圣路易斯华盛顿大学，拿到了法律博士学位，后来成为堪萨斯城一位小有名气的律师。

纵观普兹兹的早期职业生涯，会发现他是个极具敏锐商业嗅觉的人。他开始接手卡乐星母公司CKE，仅仅是因为卡乐星在堪萨斯城有个位置，需要一位律师。然后他就成了CKE当时的老板Karcher的私人律师，然后当CKE集团升任为CKE在堪萨斯城时，两个一起的老板Karcher关系非常好，同年一起当圣路易斯律师。2000年时，普兹兹就成为Karcher，成为了CKE集团的CEO。

从1991年成为Karcher的私人律师，到2000年取代后者成为CEO。普兹兹一共只用了九年的时间。从个人才能上来说，普兹兹的确聪明、够努力。

# 安德鲁·普兹兹的理念

普兹兹有两个主要理念。

第一，他是“滴滑经济学”（Trickle-Down Economics）的坚定拥护者。

第二，他认为，提高最低工资标准是不合理的。他认为，如果最低工资标准提高了，餐馆就会引进机器人代替人类，因为机器人便宜，还更灵活。所以，不提高最低工资标准，是为了帮助那些老板吃饭。

# “滴滑经济学”

Trickle-Down Economics，中文也翻译作“下游经济学”、“滴流经济学”。“滴滑经济学”的核心，就是政府应该把税收的法律少一点，再多一点流入到个人企业和消费者的手中。最终，让人受益。简单来说，就是让先富裕起来，富人先得到好处，最终穷人也会跟着一起富裕起来。

# 卡乐星和安德鲁·普兹兹自身的困境

普兹兹被各种口口声声，比如种族歧视和性骚扰。即使他是特朗普亲自任命的劳工部长，后来也自己宣布退出了。《经济学人》曾指出，普兹兹传出这个职位的竞选，是因为被曝出，家里雇佣非法移民当佣人。

但即使普兹兹宣布退出劳工部长的竞争，他也一直面临着各种困境。卡乐星正遭遇业绩下滑，现在全世界都流行健康和轻食主义的风潮，大份的口味也开始变了。卡乐星提供高热量的食物，即使性感女郎的广告，也不再有那么大的吸引力。

就像加州的一个大型连锁店的运营主管说的那样，“市场在按自己的方式出牌，比基尼女郎的时代已经过去了。”
