# 知识清单

+   - 《巴伦周刊》

美国的金融财经周刊，内容主要围绕美国的金融市场和市场动态。这本杂志在基金和股票领域有着非常深刻的见解，每期都会介绍新的基金管理理念并给出投资建议，既服务于基金公司，也为个人投资者提供建议。

《巴伦周刊》创刊于1921年，和美国《华尔街日报》是姐妹刊物，都是道琼斯公司旗下的出版物。"道琼斯"就是这家族的名字编出来的。作为一本财经类杂志，《巴伦周刊》有比较强的学术和技术背景。

+   - 哈雷摩托车的诞生与发展

全称哈雷·戴维森，诞生于美国北部威斯康星州的奥茨堡。哈雷摩托车是这个城市最有名的两个代表事物之一，另一个是NBA的密尔沃基雄鹿队。

哈雷摩托有着非常悠久的历史。1901年，一个叫凯撒·哈雷的20岁小朋友和梦想要自己建一建厂，他的叫上是朋友戴维·戴维森一起，二人把发动机装在自行车上进行试验，成为日后哈雷摩托的雏形。

1903年，哈雷·戴维森品牌正式成立，名字来源于威廉·哈雷和亚瑟·戴维森姓氏的组合。通过不断改良，1920年，哈雷已成为了全世界最大的摩托车制造商。

在经历了一战、经济大萧条和二战之后，哈雷成为美国国家的象征和美国文化的重要组成部分。漫威电影《美国队长》里，美国队长总是骑着一辆哈雷摩托车，拯救世界。

哈雷的营销做得非常好，美国人崇尚个人主义，而哈雷营造出一种象征着反叛和追逐自由的精粹，很合美国人的胃口。同时，哈雷作为世界上最老的摩托车制造商，品牌忠诚度非常高，世界各地有很多死忠粉和车友俱乐部。

今年2月，美国新任总统特朗普在白宫见了哈雷的首席执行官Matt Levato，并感想，能有一辆哈雷·戴维森的摩托感觉真是太好了。

哈雷在股票市场的表现也非常好。在过去的十二个月里涨了35%，现在已经到了56.56美元一股。

+   - 哈雷摩托车面对的麻烦

第一个，固有受众群萎缩。

和很多人以为的哈雷的受众主要是喜欢自由、有反叛精神的年轻人不同，哈雷摩托的主要消费群体是非西班牙裔的中老年人。这主要是因为，哈雷摩托车的价格不便宜。哈雷80%的利润，是来自于3万美元以上的重型车。剩下20%来自附件、授权、服饰等等。要购买哈雷，需要一定经济实力。

但是贡献了哈雷60%利润的核心受众，在过去的十年里数量逐渐减少。现在哈雷试图吸引年轻人，甚至亚洲女性、黑人、西班牙裔，但效果并不太明显。
