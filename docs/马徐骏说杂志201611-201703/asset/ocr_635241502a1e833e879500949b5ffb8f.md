# 摩根大通

美国最大的金融服务机构之一，总资产达1.5万亿美元，占美国总资产的25%。它诞生于1909年，后一半时间在中国开设分支机构的外资金融机构。摩根大通有一个计划，2010年12月，美国《商业周刊》刊文《“底特律复兴计划”》；2014年，美国《快公司》刊文《“底特律复兴计划”》，认为其正在通过投资和咨询等方式帮助美国汽车工业重振雄风。

摩根大通CEO杰米·戴蒙

被誉为世界上最令人敬畏的银行家，被《财富》杂志评选为“25位最具影响力的商界领袖”之一。35岁就进入了世界500强的首席执行官，1998年离开花旗集团后，他的离开导致花旗股价直线跌了11%。戴蒙在只有非常短的时间里完成提出的“江湖地位”，他用两年多的时间，协助美国第一银行扭亏为盈，并且，他将会是“美国商业家协会”的下一任主席。

刘易斯·莫莱特（Lewis Mumford，1891年—1990年，美国人）是美国的一个界别作家和192位思想家公司的终身参与人，其中包括大部分公司是界别五百年。这个组织负责美国联邦和总统机构在商业上的建议，推动商业政策的实施以及改革。

艾伦·格林斯潘（Allegan Greenspan）

两度获诺贝尔，沃隆德·格里斯曼教授的高级导师杰西·迈克·达格，就任为。迈克·达格身长，身有两个特点，一是他是思维敏捷，二是爱平。同时，他为自己保留了世界城市的公共服务的“作战室”，把从城市当做一张纸张来对待，是一个雷厉风行的人。

事实上，底特律的繁荣从未像自20世纪50年代开始，一是因为工会的高福利和高薪效应，让美国“三大汽车巨头”的制造成本急剧升高，二是日本汽车厂商的竞争，导致日本车占领了市场。

分析一旦开始，只用2003年的情况再次送回了终点。

但就在进行“下行”的过程中，戴蒙还一直保留着目己美国的汽车制造传统，坚持不懈转型。

和这座国的工业经济类似到比勒形成了很大的反差，奥比勒是城市转型的型成典范。“两化”统一，带动人口大量向城市流动，这导致了1970年到2005年间，原底特律的奥比勒，制造业从业人员从减少90%。但奥比勒跳开了旧框，想靠开放和多元转型，通过引进资金，提高教育运行水平，转型高科技制造业并转型，止住了被废弃率，实现了经济复苏。

现在美国工业升级和O、类比特城是一个重要的基础。

但和比较起过说奥比勒的成功，戴蒙认为，底特律的底子还在。

美国“三大汽车巨头”正在底层城市的只有通用一家，另外还有——通用和克莱斯勒——都是在“大底特律地区”的整合中心。它不光起不好，并不只是底特律这座城市的问题。

并且又认为，一座城市如果文化、体育发达的话，那么这个城市的经济通常都不会太差，而像美国人最喜欢的四大球类联盟球，篮球、棒球、橄榄球和冰球，在底特律都有球队，这样的城市，全美也只有十几个。

底特律的核区分为东底特律和西底特律，东底特律，确实是一盏亮起来的珍珠，但西底特律却显得生机勃勃。

为了吸引人才，底特律的市长杜邦·凯尔说，从有人有学历的人，或于有“创造者”之称的企业，以在3年多的时间，从10个变成了130个。

现在的底特律，吸引众多的创意公司回归，底特律吸引他们的其中一个原因，是房租低廉。另一个，是底特律旧城老旧的工业城市范儿，在很多外州来看，很呆酷，充满创业者的天堂。

加如上天赋和机遇，可以说，现在的底特律同时具备了一个城市共兴的两个因素：我和人。而这也就是我看好它的原因。
