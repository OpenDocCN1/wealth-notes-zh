# 希拉里是美国“最好的希望“？

本文源自《经济学人》11月5日刊

![](bbox=[0.08, 0.13, 0.92, 0.2])

# 今日金句

经济环境的改变，以及曾经被珍视的传统的衰落（例如家庭、教会、工会等），都导致了美国工薪阶层的一种恐惧，那就是他们以及他们的孩子，会无法适应这个变化的世界。

本次美国大选的核心问题只有一个：种族问题。

# 知识清单

希拉里的支持者，主要来源于非白人群体、受过高等教育的人群，以及美国的Y世代群体。

Y世代（Y Generation）也称为千禧世代（Millennials），是指出生于1980年到2000年之间的人。在美国，约有7600万人是Y世代。

一般认为，川普的支持者主要来自中下层的工人阶级。在中下层工人那里，川普的支持率确实碾压希拉里，但实际上，这部分人只占川普支持者的1/3，绝大多数支持川普的人，是家庭年收入4~6万美元的人，他们属于美国的中产阶级。绝大部分支持川普的人，不但不生活在美国贫困线的上下，甚至还有不少来自比较富裕的家庭。

# Closer

支持率 单位：百分比

川普身上有一个极其鲜明的标签——他是自1960年的乔治·华莱士之后，美国总统候选人里，种族歧视最严重的一个。

支持川普的人，大多是对美国历史上“第一位黑人总统”奥巴马怀有敌意的白人，他们在川普的支持者里能占到60%的比例。

# Turning up

希拉里是美国“最好的希望”，不因为她在处理国内外政治问题上有经验，最重要的是，是因为希拉里是一个渐进主义者，她不相信激情澎湃的大革命后，所有问题就能在一夜之间都解决掉。她相信的是，只有一点一点的变化，才能最终达成目标。
