# 可口可乐换配方事件

上世纪80年代，可口可乐的竞争对手百事可乐做了一个街头实验，把两个品牌的可乐装在杯子里，通过盲品让路人判断哪个可乐更好喝。结果发现大多数人都认为百事更好喝。可口可乐迅速进行一轮公关，给出了同样的结果。
这导致可口可乐着手改进配方，1985年发布了名为New coke的新配方可口可乐。但新配方可乐都遭到了消费者的强烈抵制，公司接收到成千上万的投诉。最终在事件可以口可乐重新换回配方。

# 为什么公司领导层不愿重视品牌形象

文文的作者认为，这是因为很多公司对竞争优势有着严重的误解。很多企业和高层领导都认可，或正在努力建立，没有任何优点的公司无法生存。那么公司会在不断改变和建立上，比如推出创新产品，新的收购协议及新的销售方式。这一点在手机市场上非常明显。
但如果仔细观察竞争行业的领军企业，就会发现他们似乎并不是完全这样。
比如诺基亚在过去20年间造过的战鼓和思维变化根本就没改变。

# 累积优势

公司想要一直保持始终开始的竞争优势，就要对自己的独特目标并把它从竞争对手身上区分出来，同时去塑造、创造、增加、发展品牌的累积优势。
狗狗时，大脑是如何运转的
一位神经科学家的研究表明，人类的大脑只相当于20Mlb的电脑内存，随着社会的发展、经济的快速发展，人类的行为更加需要复杂的认知判断，而人的大脑在经历了近25年，创造性思维的能力只下降了约5个百分点。说明人类的大情报容易不堪重负。
所以面对选择时，为了节约资源，人总是倾向于把简单化，并转化为自动的行为。事实上这是一种习惯。
人最惯性生物，多数情况下惯性也表现出思维惯性，所谓的品牌黑店度也是种惯性的体现。
