# 知识清单

《哈佛商业评论》
哈佛学院院长的杂志，是为专
业管理精英及咨询、培训等管理咨询从业者提供管理资讯
的综合类管理期刊，以专业性和可读性著称。它以专业、
深入、前沿、实用的文章和文章解读，为专业人士提供管理
学知识，并以其独特的风格和管理理念，帮助管理人员解
决实际问题。

什么叫做初创公司的“规模化”？
对于“规模化”，很多企业
存在误区。有人把“规模化”
理解为公司规模越大，效益越好。
其实，“规模化”是公司
在快速发展过程中，实现组织、
管理、技术、资金等要素的
协调匹配和整合优化，从而
实现效益和效率的最大化。

如何实现公司的“规模化”？文章
提出了四个方法：
第一步：界定专业分工，让专业的人做
专业的事
第二步：根据公司扩张规模，增加管理
层次
第三步：系统收集分享信息，建立处理
问题的流程
第四步：坚定维护企业文化

第一步：界定专业分工，让专业的人做
专业的事
公司初创时，老板是唯一的决策
者，公司只有老板一个专业，其他
人都是业余的。当公司规模化后，
专业分工就变得很重要。专业分工
是指按照不同专业性质、不同技术要求
将工作划分为不同的工作岗位，并
由不同专业的人去完成。

引入专业人士，会产生什么问题？
1、早期员工有情绪
当公司进入专业化分工，早期员
工的贡献被专业化分工所取代，早
期员工会产生被边缘化的情绪，甚至
产生嫉妒心理。

解决方式：
公司要给早期员工以肯定，让
他们看到自己的贡献和价值。对早期
员工进行培训，让他们成为专家，
或者让专业人士和早期员工合作，
共同解决问题。

2、容易产生信息孤岛
专业分工会产生信息孤岛，即
各部门之间信息不通，各自为政，
不能协同工作，影响公司效率。
人的“部署本能”是指人们习惯
于按部门安排工作和解决问题，
而“跨部门协作能力”是指人们
习惯于按项目安排工作和解决问题。
专业化分工越细，跨部门协作能力
越难培养。

解决方式：
公司要建立有效的跨部门沟通
机制，如跨部门会议、项目制工
作等，培养跨部门协作能力。

第二步：根据公司扩张规模，
增加管理层次
公司初创时，老板既是决策者
也是执行者，没有管理层次。随
着公司规模扩大，管理层次自然
增加。

很多公司都在公司扩张初期，
业务上马速度极快，但管理层次
增加缓慢。业务扩张了，管理水
平没有跟上，就会出现管理真空。
管理真空是指管理层次跟不上
业务扩张速度，出现管理断层的
现象。

文章通过举例指出，公司管理者
可以通管理者的身份，对下属的
管理者的能力进行评估。通过评估
了解管理者的能力，以便针对性地
进行培养。

当然，随着公司增加管理层次
时，也要注意“过度管理”。“过
度管理”是指管理层次过多，导
致决策效率低下，甚至出现“上
行下效”的现象。过度管理会消
灭组织活力，降低管理效率。

第三步：系统收集分享信息，
建立处理问题的流程
初创公司面临的问题往往千头
万绪，而资源有限。如果不建立
处理问题的流程，公司就会陷入
“救火模式”，疲于奔命。

文章通过举例指出，公司管理
者可以通管理者的身份，对下属的
管理者的能力进行评估。通过评估
了解管理者的能力，以便针对性地
进行培养。

系统收集分享信息，是指公司
管理者要收集并分享公司各个层
面的信息，以便做出科学的决策。

第四步：坚定维护企业文化
在公司发展过程中，最关键的
就是企业文化。企业文化是公司的
灵魂，是公司在长期发展中形成
的价值观、信念和行为规范。

总结
作为一个创业者，首先得明确
自己的定位。你是想做“小而美”
的公司，还是想做大公司？

不同定位有不同的路径。如果
想做“小而美”的公司，那就聚焦
于细分领域，打造专业优势。如
果想做大公司，那就走平台模式，
整合资源。
