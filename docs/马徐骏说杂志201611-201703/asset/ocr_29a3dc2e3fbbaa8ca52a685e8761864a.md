# 阿联酋航空：土豪的“发家术”

![](bbox=[0.32, 0.055, 0.68, 0.125])

> > 访谈/速卓

阿联酋航空有多大？
2009年6月30日，当《彭博商业周刊》采访阿联酋航空CEO克兰克（Sheikh Ahmed bin Sattam Al Maktoum）时，它已经有78架飞机，包括34架波音747，54架波音777，比国际航空（A380）飞机要少得多。它每日运送8500名乘客，比美国（5400）和国际航空都多。阿联酋航空在迪拜和莫斯科之间，在迪拜和伦敦之间，都在伦敦和迪拜之间飞行。它的航空枢纽在迪拜，可以方便地抵达75个目的地。迪拜的航空枢纽也是世界上最繁忙的，一年只处理2500万个航班。阿联酋航空已经建立了许多国际业务，包括旅游、货运、酒店、餐饮、汽车、博彩和主题公园。它收购了英国Sky Emirates的7%股份，以换取迪拜航空8%的股份。

迪拜政府是怎么做航空业务的？

2003年，阿联酋航空的运营中心是迪拜的迪拜国际航空城。迪拜国际航空城是一个对航空和物流行业开放的区域，拥有30家航空公司，包括英国航空、荷兰皇家航空、阿联酋航空、卡塔尔航空、马耳他航空、埃及航空、斯里兰卡航空、印度航空、尼泊尔航空、孟加拉航空、孟加拉航空、斯里兰卡航空、尼泊尔航空和孟加拉航空。除了这些，还有其他许多航空公司在这里经营。

阿联酋航空的崛起归功于：

1985年，阿联酋航空的创始人谢赫·拉希德·阿勒马克图姆（Sheikh Rashid Al Maktoum）创立了阿联酋航空，作为迪拜国际航空城的一部分。在它的早期，它只拥有13架波音727飞机，飞往中东的八个目的地。到1991年，它已经拥有12架波音747，飞往16个目的地。到1995年，它已经拥有18架波音747，飞往20个目的地。到1999年，它已经拥有24架波音747，飞往30个目的地。到2003年，它已经拥有34架波音747，飞往50个目的地。

除了航空业务，阿联酋航空还拥有自己的酒店、旅游、租车、零售、餐饮、娱乐和休闲业务。这些业务都位于迪拜国际航空城内，为旅客提供了一站式的旅行体验。

阿联酋航空的成功也得益于迪拜的地理位置。迪拜位于中东的十字路口，连接了欧洲、亚洲和非洲。这使得它成为一个理想的航空枢纽，为旅客提供了连接这些大陆的便捷通道。

阿联酋航空的未来将如何发展？

随着航空业的持续发展，阿联酋航空将继续扩大其业务，增加更多的目的地和航班。它还将继续投资新技术，以提高服务质量和乘客满意度。阿联酋航空的目标是成为全球最大的航空公司之一，并提供最优质的航空旅行体验。

阿联酋航空如何吸引乘客？

1.  提供优质的服务和设施。阿联酋航空的客舱内设施豪华，包括个人电视、Wi-Fi、酒吧和餐厅等。它还提供了多种餐饮选择，包括清真餐、素食和特殊餐食。
2.  提供多种舱位选择。阿联酋航空提供经济舱、商务舱和头等舱三种舱位，满足不同类型乘客的需求。
3.  提供频繁的航班和广泛的目的地网络。阿联酋航空每天提供数百班航班，飞往全球75个目的地，为乘客提供了更多的选择。
4.  提供会员计划。阿联酋航空的“千禧”忠诚计划为乘客提供了更多的优惠和奖励。

阿联酋航空如何与竞争对手区分？

1.  提供豪华的客舱体验。阿联酋航空的商务舱和头等舱提供了私人套房、淋浴和酒吧等豪华设施，使其在高端市场中脱颖而出。
2.  提供多样化的餐饮选择。阿联酋航空的餐饮团队来自世界各地，提供了多种国际和当地美食，满足乘客的口味需求。
3.  提供优质的地面服务。阿联酋航空的地面服务团队专业且友好，为乘客提供了高效的行李处理、登机和安全检查服务。
4.  提供会员计划。阿联酋航空的“千禧”忠诚计划为乘客提供了更多的优惠和奖励，鼓励乘客重复乘坐。
