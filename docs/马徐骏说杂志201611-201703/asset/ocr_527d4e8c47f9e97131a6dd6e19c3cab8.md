# 知识清单

+   • 关于喝水这件大事

本期内容来自最新一期《新科学家》的封面文章，主要内容是告诉我们如何正确喝水，其中不少知识颠覆咱们以往对水的认知，比如天真的觉得要喝8杯水吗？这个论断是谁提出的？又比如，同是提神饮料的咖啡和茶，到底哪个更好？还有，喝可乐不健康，那换成无糖可乐是不是就健康了？等等等等。总之，关于喝水这事，你能想到的文章都有提及，单单参与写作的作者，就有足足7位之多。

+   • “每天8杯水”有科学根据吗？

“一天喝8杯水”这句话我们都 不陌生，那这个论断是谁提出的？

2002年，美国达特茅斯医学院的生理学家Heinz Valtin就特跑去查过，结果查到，在1974年出的一本书里，出现过这个倡议，但人家的建议是“一天喝6到8杯水”，这里的“水”不单单指清水，像茶饮、咖啡、牛奶，甚至啤酒，加一块要有6到8杯就行，而且这个说法没有什么科学依据。

关于“到底应该喝多少水”这个问题，美国科学与工程与医学健康研究局的食品营养委员会会是这样建议的：对于绝大多数健康的人群来说，除了再喝水，就已经能满足每日身体所需的水分摄入了。

+   • 孩子才是需要多喝水的人群

虽然成年人完全可以“等渴了再喝”，但研究发现，孩子需要多喝水，一些研究已经证实，对于9-15岁的孩子，喝水可以提高他们的注意力。对此，作者是这样解释的，也许是因为这个年龄段的孩子更容易缺水，而缺水会引发反应慢、专注度低及记忆力下降，所以如果您家有孩子，要记得，他们要比大人喝更多的水才行。

+   • 远离碳酸饮料

碳酸饮料对身体不好，这个大家都知道，但我们要搞清楚的是：到底哪不好？它会如何危害我们的健康？

家里的长辈劝我们少喝饮料时会说，喝多了碳酸饮料会导致骨质疏松。不过这样也是一个没什么科学根据的说法。到目前为止，关于碳酸饮料和骨质疏松之间的关系的研究，还是仅仅停留在问卷调查和统计学现象上，也就是说，没有强有力的证据，证明碳酸饮料一定会导致骨质疏松。

那是不是就可以放心大胆地喝了？并不是。碳酸饮料中最大的健康杀手是——糖。

糖主要会引起两个方面的问题，第一个就是体重的增长。第二个是会增加I型糖尿病的风险。平均每天喝一罐碳酸饮料，患I型糖尿病的风险就会提高25%。

既然是罪魁祸首，是不是喝无糖的碳酸饮料，比如说健怡可乐就没问题了呢？不是。

说来说去，问题还出在“糖”身上。

无糖饮料不是不放糖，而是把糖换成人工甜味剂。文章里引用了一个实验结果，说食用了人工甜味剂的老鼠，它们的葡萄糖耐糖程度也提高了，而葡萄糖不耐就是I型糖尿病的前兆，也就是说，即使是人工甜味剂，也有导致糖尿病的风险。

除此之外，人工甜味剂对人体健康的不良影响也不小。哈佛大学的营养科学家Vasanti Malik解释到，“人工甜味剂的甜度是天然糖的200倍，这会导致我们越来越喜欢甜食。”，这只是第一层原因，Malik还说，“如果你总吃含人工甜味剂的东西，吃含天然糖分的事物时，身体也没办法正常消化了。”

简而言之，不管是碳酸饮料，不管是含天然糖分还是人工甜味剂，最大的问题都出现在糖分上，糖不仅会让我们发胖，还会增加我们得糖尿病的概率。

+   • 多喝果汁有益健康？

果汁看起来很健康的选择——内含有纤维素、维生素、矿物质等等等，但这也 不代表果汁喝得越多越好，其中有两点原因。

+   一、果汁中含有的纤维素其实非常低。举个例子，一个橙子约含纤维素大概是1.7g，而一杯橙汁约含的纤维素只有0.4g，足见相差4倍。
二、还是糖。世界卫生组织推荐的每日糖摄入量是25g，而一杯250ml的橙汁含糖量就有24g之多。也就是说，一天只要喝一杯橙汁，那么你这天的健康糖分摄取额度算是用完了。

+   • 牛奶和豆浆的健康谜题

关于牛奶，文章结论可以总结成两点：
一、只有人类这杂奇畜长大了还喝奶；
二、喝牛奶对于儿童很好。

咱们都听过一个日本 “牛奶工程”的口号——杯牛奶强壮一个民族。

1950年，二战刚刚结束5年，当年的全日本居民体质调查结果显示，日本成年男性的平均身高只有1.60米。60多年后，也就是2014年，再一次的调查结果显示，他们的“平均身高”已经变成了1.707米，排名全球第29位，而同时，中国男性的平均身高是1.697米，排名32位。

也就是说，日本男性在短短的两个世纪的 时间里长高10厘米。

归根到底，这是饮食结构调整和体育锻炼强化共同的结果。上世纪50年代，日本政府提出了 “一杯牛奶强壮一个民族”的口号，同时颁布了《学校营养午餐法》，以法律的形式要求小学生必须每天喝一杯奶。
