# 知识清单

《哈佛商业评论》
哈佛商学院的标志性杂志。致力于给全世界的专业人士提供缜密的管理见解和最好的管理案例。

信任的力量
如果一个老板信任自己的员工，愿意把重要工作交给他处理，不仅可以使这个人获得更多展示自己的机会。同时，他因为感受到老板的信任，也会更有干劲，工作更卖力更紧，比别人更容易做出成绩。这种双向的正循环，就是信任的力量。
什么是催产素
催产素并非女性专利，男女均可分泌催产素。它减少对老成人脑内肾上腺素释放及激素的水平，从而降低血压。当心情压抑或者有强烈归属感时，心脏会分泌催产素，使体内组织的供氧量大量增加，压力得到纾缓。
信任背后的科学道理
文章的作者保罗·扎克，是美国克莱蒙特研究大学的行为神经学、心理学及管理学教授，同时也是经济心理学研究中心创始人兼负责人。经过多年的研究，他发现，信任与一种叫做催产素的人体激素，有着密切的关系。
作者做了一个实验，让一个人给陌生人汇款，无论谁少，对方都会得到3倍于汇出数目的钱数，对于收汇款者，可以选择把这多钱分给汇者一部分，也可以自己全部留下。
是否决定汇钱，就代表着汇款者是选择信用人，还是与收汇款者分享收到的钱，则取决于收款者是决定分享或被信任的人，在汇款者和收款者做出决定前后，研究团队抽取了这些人的血液进催产素的激素水平。
研究发现，收款者收到的钱越多，也就表示他被信任的程度越高，大脑分泌的催产素的数量也就越多，而越高水平的催产素分泌，也使得收款者更愿意分享自己收到的钱。
也就是说，一个人被信任的程度越高，这个人也就更愿意去信任别人，做出对彼此都更好的行为。这就是信任产生产力量背后的科学道理。
高信任度公司的表现为优
员工对组织的信任度极为重要，作者团队在2016年通过调查研究做了一项调查。他们在全美范围内收集了1095名各企业代表的数据。这些数据比较了对企业高度信任的员工与对企业不那么信任的员工。
数据显示，对企业高度信任的员工，要比企业没那么信任的员工工作得高16%，工作效率高出50%，请假少13%。高信任度公司的各种数据表现都极其优异。
在团队中创造出高信任氛围的八种方法
1、对员工优秀的表现给予认可
员工优秀表现得到认可，可以是公开认可，可以是私下认可，对员工的信任度都有着巨大的影响。要在公开场合，把员工做出的事项影响，进行表彰。这不仅可以提升员工对组织的信任，还可以让其他人起到榜样作用。
2、对员工施加适当的挑战压力
适当的压力也可以促进人体分泌和提高信任度的激素水平，所以管理者来说，可以以下属员工布置挑战性任务，让团队一起解决，还可以让团队形成紧密的关系网。
3、给员工更多的自主性
如果员工感受到自己对工作内容可以进行选择，可以用自己舒服的方式工作，拥有更多自主权，感受到的被信任感将会更强。但这并不表示管理者容许怠忽、降低期望。给员工更多自主性的目的，在于让员工自己承担责任，对工作更有清晰的认识，并担起责任，努力用于实现目标，提高公司效率。
4、帮助员工全面成长
高信任度的公司，不仅关注员工的工作能力，也关注员工的个人成长。管理者不仅帮助员工明确工作目标，让员工自主选择工作方式，还会关注员工个人的职业发展，并给出有效建议。同时，为员工成长，提供更多资源支持，这对于留住人才及提高员工的信任度都有看巨大的帮助。
5、适当示弱
对管理者而言，可以适当示弱，这会激发员工的责任感，同时对公司管理者更深度的信任，并且对管理者产生更大的信任。开源软件公司Red Hat的CEO Jim Whitehurst 说：“我发现，承认自己不会的东西，能产生超乎寻常的好效果，这帮助我建立良好信任。”
总结
这些方法不仅适用于团队管理，而且可以在两性生活、家庭生活和伙伴间都可以使用。比如，对自己的伴侣或朋友，如果你知道他表现优秀，要鼓励朋友表现一下，能增加彼此的好感度，提升彼此之间的信任。
