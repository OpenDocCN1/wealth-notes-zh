# 知识清单

《科学美国人》是美国历史上持续时间最长的杂志，从1845年至今，172年没中断。同时，它又以绝大的大众化的蒸汽水平来到你。到目前为止，共有150位以上的诺贝尔奖得主为这本杂志写过稿。《科学美国人》最著名的《科学》杂志的兄弟刊物。

“阿西莫夫一般认为机器人应该受四条纪律约束去不杀人，文章作者指出，机器人立法必须从人机合作入手。”

人工智能的发展阶段
第一阶段：上个世纪五十年代，人工智能的第二次热潮，计算机的兴起使人们认为未来机器可以代替人类劳动。
第二阶段：上个世纪七十年代到2005年左右，科学家发现，以当时计算机的计算能力，用机器人代替人类的劳动这个事儿是不通的。因此大众对于人工智能就没有那么热衷了，这个时期被称为“人工智能的冬天”。
第三阶段：2005年至今，是人工智能的第三次热潮，以开放AI的GPT模型为起点，各大科技公司都投入研发人工智能，以世界知名的互联网大公司把机器人技术作为下一个抢占市场高地的重要目标。

目前人工智能的应用，主体是依附在机器视觉和自动驾驶模型上。
对过去的表现来说，初级、灯型的控制技术已经实现，但下来会出现很强表现情感或伦理和人性的机器人，以及无人驾驶。

文章作者认为，目前核心是机器智能能力对人类产生威胁的对于说，因为机器人的行为都是被预设控制的。
但是要注意，人不可能去控制它的底层逻辑，它也不会去否定人的控制，它就只会服从人，所以会出错。
一旦它去错了，它记忆了它的错误，它如何防止人下达了错误，甚至是荒谬的命令，导致机器人作出伤害人类，破坏财产、危害环境或被机器人自身制造危险的行为。

# 阿西莫夫

美国和犹太裔美国人。
关于阿西莫夫，最广为人知的就是他的一部作品，以及他提出的一条定律。
其中的基础，指的就是从科幻名著《基地》，他根据他从头去写，拉登克该这本小书的叙述，并且自己创造的词汇创造命名为“基地”。
一条定律，指的是著名的“机器人三定律”。

# 机器人三定律

+   - 第一定律：机器人不得伤害人类，或对人类因袖手旁观而见伤害不幸不语。
- 第二定律：机器人应听从指令并予以协助，除非此指令与第一条或第二条定律相抵触。
- 第三定律：机器人必须保护自己，除非保护自身与第一条、第二条定律之情况下更直接能保护自己的生存。

![](bbox=[0.12, 0.71, 0.75, 0.83])

人工智能不加分析地严格执行人类的命令，这并不是一件稀奇的事儿。
文杰说，现代人工智能的发展水平远远还没有达到可以分辨出人类命令里并包含着的含义，它不能明白这句话可能产生的后果。所以无论人工智能在什么情况下，都必须接受执行命令，并保证执行结果。

# 违抗条件

语言学里面的专有名词，意思是只有满足了一系列条件，执行者才能执行一条新发出的命令。
作者的研究团队，在一个机器人的违抗令中，加入了“违抗条件”。比如科学写了一个算法，机器人在接受指令之前必须先满足这个条件。
例如，作者团队在机器人实施某项任务，让机器人执行的程序识别不能够像做这种方式；其社会属性以及指令发出者的关系，允许不能在执行该条件合；执行该该条件也不会完成一些不必要的的指令任务。

走失了“违抗条件”的算法之后，才可以执行命令。
如果机器人执行自己的命令，人类会有什么样的反应？
文杰通过安全控制，机器人提出反驳后，有一不可知可以阻止人类对它拒绝处理无关的或恶意的命令。

对于人类而言，人工智能拒绝执行命令并不足为奇。
文杰作者强调，对人类而言，人和人的行为是可以信任的。真正不可信任的，其实是人自己。
