+   - 彼得·蒂尔的1517基金

《新闻周刊》3月3日刊的封面是硅谷“创业教父”彼得·蒂尔的特写照，封面给出的副标题是：亿万富翁认为高等教育是一种巨大的浪费，他愿意花钱让你退学。

文章介绍的是彼得·蒂尔创立的1517基金会，基金旨在鼓励那些有想法的大学生勇敢地辍学出来创业。

彼得·蒂尔向来不以走寻常路而出名，他的一句批评现代科技的名言就是：我们一直想要一辆“会飞的车”，结果得到的不过是一百四十个字符。

但彼得·蒂尔厉害的地方在于，他预测事情的眼光时惊人地准确。比如他在Facebook刚启动的时候就果断地给马克·扎克伯格投资50万美元，最后获得了2000倍回报，同样的，在硅谷各界对特朗普一片骂声的时候，他却成为了特朗普在旧金山的竞选代表，最后的结果也是特朗普成功当选。

彼得·蒂尔的思维模式就是要找出被大多数人忽略的、重要的问题。比如面试的时候，他会问应聘者一个问题：请你告诉我们关于这个世界，你认为对，而大部分人认为是想法。

+   - 彼得·蒂尔为什么批评美国高等教育

关于高等教育，彼得·蒂尔也有跟一般人不同的思考，他认为高等教育是在浪费学生的时间。

彼得·蒂尔对高等教育的不满主要集中在三个地方：高昂的学费、值得怀疑的价值观，以及排他性。

# 一、学费高昂

美国高等教育学费昂贵，并且还在持续上涨，高等教育费用的上涨是通货膨胀的两倍。

这里可以做个比较，北大清华的学费，一年差不多是5千~6千，哈佛的学费是4.7万美金，相当于32万元人民币，耶鲁大学的学费是4.4万美金，斯坦福大学的学费4.6万美金，哥伦比亚大学、芝加哥大学、南加州大学的学费都在5万美金以上，这仅仅是学费，还不包含生活费。

能拿到奖学金的学生毕竟是少数，学生们为了上大学，就需要贷款，这笔负债，已经达到了1.3万亿美元。

这会带来一个后果，就是对于那些借了学生贷款偿还大学学生来说，在毕业后要花很长时间来偿还贷款，他们可能没有办法，毕业后做自己真正想做的事情，而这对人才是巨大的浪费。

# 二、价值观可疑

彼得·蒂尔认为，高等教育存在很大的泡沫，这可能是继科技泡沫和房产泡沫之后，下一个会破灭的泡沫。

他的观点是：如今美国那些名校，或者说精英大学，其实是过时的了，他们对科学研究是有价值的，但同时对对于科技进步贡献很少，而且最终会引发的是经济上的灾难性后果。

# 三、高等教育和名校的排他性

彼得·蒂尔认为关于高等教育的最大、最核心的谎言就是：名校管理者、毕业生们声称读名校是最好的、最积极的教育方式，是每个都应该参与的，但事实上这种做法让名校变得像是知名夜店，门口有很多排队的人，但最后只有很少的一部分人能够分享它。

如果说哈佛大学真想让全世界都受益的话，就应该把哈佛完全开放，让更多人能够得到教育资源，但名校管理者们一定不会这么做，因为这种做法一定会遭到愤怒的校友们的围攻。这些名校的校友，他们的骄傲和对身份的高度认同感来自于排他性，也就是对稀缺资源的占有。

以上三点：高昂的学费、值得怀疑的价值观和排他性，就是彼得·蒂尔对高等教育失望的原因。因此他创办了1517基金会，让辍学出来创业的年轻人们，可以在两年的时间里得到10万美元的启动资金，把自己的想法付诸实施，同时彼得·蒂尔还会提供机会让他们接触投资人和投资人，以便获得更多资金上的支持。

+   - 关于1517基金的争议

关于1517基金会的争议非常大。哈佛学教授拉里·萨默斯就对彼得·蒂尔的做法不屑一顾，他说：这个恐怕是十年来最具误导性的慈善行为。

第一，彼得·蒂尔批评了名校的排他性，但事实上，彼得·蒂尔的基金会每年也只招收三十个成员，可以说名校还“排他”。
