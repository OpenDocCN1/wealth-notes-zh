# 谷歌对网络暴力的技术性反击

# 知识清单

# 网络巨魔（Internet Troll）

指在网络世界中，用侮辱性语言挑起骂战，并从中获得莫名快感的的人。

Troll是一种源于北欧神话的怪物，体型巨大，头脑简单，暴力嗜血。在暴雪公司的大型网游《魔兽世界》中，“巨魔族”的英文即为Troll。

# 拼图组织（Jigsaw）

原谷歌的智库，今年2月改名为“拼图”，Jigsaw的一种词义就是指拼图，也可以用来表示“错综复杂”的形式。

拼图组织（Jigsaw）即将推出一个“人工智能对话系统”，利用算法和机器学习能力，自动识别网络上的侮辱性言论和骚扰。比关键字过滤准确，也比人工识别要快得多。

# 登月级别计划（Moonshot）

在谷歌内部，把所有听起来疯狂、夸张、需要花费大量时间和精力来实现的计划，都称之为“登月级别计划”。例如：谷歌眼镜、无人驾驶汽车、模块化手机等。

# 不作恶（Don’t be evil）

谷歌公司非正式的公司口号，全文是“完美的搜索引擎，不作恶”，1999年提出，沿用至今。

这本杂志经常会影响到一些我们耳熟能详的概念和名词，比如“长尾效应”、“众包”的概念，都是《连线》杂志首先提出来的。

今天说的虽然不是本期的封面文，却是一篇内容很棒的专题报道，说的是谷歌公司在酝酿的，一个对抗网络审查和暴力的计划，很值得一讲。

文章里说，现在社交网络越来越发达，在万丈光芒下，总会有黑暗的影子存在，如今在欧美网络上，类似Facebook、推特这样的网站以及论坛上，有一种被称为“网络巨魔”的人，英文叫Internet Troll，这种“网络巨魔”指的是，跟自己想不同的观点，实施网络暴力。主要是骂搞、侮辱，极端的，甚至会进行人身威胁。

比如说，美国有一个女脱口秀主持人叫Leslie Jones，是个黑人，她的头像被一些种族主义者，在网上给她做了一个黑猩猩的图片，还在她脸上P了很多黑白液体，就是很有侮辱性的那种，你懂的。

还有更极端的，比如一些专栏作家，因为自己发表的政治言论，而在社交网络上受到了极端分子的攻击，有扬言要一根根拔掉其头发的，有威胁要掠夺其器官的，更夸张的，还有说要暴人家只有一岁的女儿的。最后这些专栏作家不得不关闭了自己的所有社交网络账号，彻底离开了虚拟的网络世界。

文章的论点是，你作为“网络暴力”的受害者，好像像是进了一个广场，广场上有5万人，就你像进现在，在你。你光会着全世界对你都有敌意，那你首先肯定是闷骚，甚至你可能就觉得自己的生命都受到威胁了，你要保命，你得逃跑。

这不仅会造成非常大的心理伤害，而且会导致这些人从此有心理阴影，发东西之前先自我审查，这个不敢说，那个不敢讲，要么干脆就不再在网络上表达发表自己的观点了。

其实这种“网络暴力”现象，我们中国人并不陌生，只是在我们这儿对这些“网上暴力”分子，不叫“网络巨魔”，有别的称呼，比如“键盘侠”之类的。

这些年来，类似Facebook、YouTube这些社交媒体和网站，对这种网络暴力的主要手段，都是让用户体验出侮辱性的言论，进行举报，再由他们的员工进行处理，而这些处理问题的员工，也都是外包到像菲律宾这样的“第三世界国家”，一个是因为他们讲英语，还有就是因为人比较便宜。

但这样的处理方式，首先人力成本很高，而效率又非常低下；其次，对于处理这些侮辱性言论的员工来说，整天看着这些负能量的东西，他们的身心也会受伤害。

所以作者认为，这种方式对大规模的网络暴力，基本没什么用。

而最近谷歌一个叫“拼图”的团队，英文叫Jigsaw，即将要推出一个新项目叫做“人工智能对话系统”。这个项目主要是利用技术和机器学习能力，来自动识别网络上的侮辱性言论和骚扰。这个项目一旦做出来，按照他们自己工程师的话说，会比关键字过滤要快得多。同时，又比人工手动处理要快得多。这样就能够非常好地解决“网络巨魔”问题。
