
# 谁在决定奥斯卡的获奖名单？

本条音频及文稿参考《纽约客》2月27日刊

![](img/2b1f55794a32401f6e1d5425100884b9_65_0.png)

### 内容简介

1. 奥斯卡的评选机制是怎么样的？它可以成为世界上最负盛名的电影奖项？
2. 从1929年的第一届奥斯卡颁奖典礼至今，已经将近90岁的奥斯卡面临哪些问题与挑战？
3. 为什么中国电影总是和奥斯卡绝缘？
4. 中国买家家庭正以怎样的方式参与奥斯卡？本届奥斯卡大赢家《爱乐之城》和中国又有什么样的关系？

### 知识清单

- **奥斯卡乌龙事件**
  就在今年第89届奥斯卡颁奖典礼上，在颁发最后一项大奖，也就是最佳影片奖时，现场闹出了大乌龙。颁奖人先后说获得最佳影片的是《爱乐之城》，但在整个《爱乐之城》的主创都已经上台，并且激动地等待将近5分钟之后，工作人员打断了发言，是因为颁奖弄错了推荐名单。获奖的应该是，另一部叫做《月光男孩》的电影。场面十分尴尬。

- **奥斯卡，Academy Award of Merit**
  奥斯卡的全名叫做学院奖，英文是 Academy Award of Merit，Academy 就是“学院”的意思。
  之所以叫学院奖，是因为这个奖是由一个叫做“美国电影艺术与科学学院”的组织每年颁发的。
  美国电影艺术与科学学院的中文简称是：美国影艺学院。它不是一所学院，而是一个非盈利组织，由大约6000名电影专业人士组成。

- **奥斯卡奖是怎么评出来的？**
  奥斯卡目前设有20多个不同的奖项，我们比较熟悉的有最佳男主角、最佳女主角、最佳导演、最佳影片等等。每个奖项都有自己的评审委员会，评审委员由刚刚才提到的影艺学院的会员组成，但学院并不会公布各个评审委员会的会员名单。
  想成为会员也不容易，主要有两种途径：

  1. 在业内特别有名气，学院会邀请你成为会员；
  2. 由所在分会至少两名以上会员提名。比如，你是导演，那么你想要成为最佳导演评审委员会的会员，就得取得导演委员会里面，两名以上的会员提名。

  学院对于影片入围资格，也有严格的规定：

  1. 每个奖项的评委会，只能投票给该固定奖项。也就是说，导演只可以投导演奖，编剧只可以投编剧奖，演员只能投演员奖，不过最佳影片奖是可以全体投票的。
  2. 对入围获奖名单的影片的资格也有严格规定。除最佳外语片，其他所有的好莱坞电影都要求必须在年前1月1日到12月31日之前，在洛杉矶地区的影院放映，并且连续放映不少于7天。

  这也解释了为什么很多美国人认为不错的中国电影拿不到奥斯卡奖，因为只有影片首次在洛杉矶上映，并且连续放映7天以上，才有入围资格。

- **即将90岁的奥斯卡，存在那些被人诟病的问题**

  1. **权威性和公正性备受挑战**
     奥斯卡不仅是美国电影行业界里最重要的活动，也是目前最受瞩目的电影奖项之一。
     得到奥斯卡，不管对电影主创还是制作公司，甚至对市场的回报是极大的利润。因此每到“奥斯卡季”，也就是“Oscar Season”，电影公司都会卯足了劲去宣传作品，尤其是最佳影片奖，更是拉票的重灾区。为了增加入围最佳影片奖的机会，电影公司会花费数百万美元雇电影拉票人。
     奥斯卡当然不会忽视这一情况，获得最广泛的拉票行为。在2009年获得最佳影片的《拆弹部队》，其中一位制作人就因为过度拉票，被禁止出席奥斯卡颁奖典礼。

  2. **是否促进多样性**
     西方社会的种族构成多样，而人类之间的差别一眼就能看出来，比如黑人和白人，一眼就能认出来。在这种社会现实下，保持内部成员的多样性，以及获奖影片的多样性，就显得很重要。
     回到奥斯卡评委委员的多样性上，美国《洛杉矶时报》报道说，截至2012年，评委会将近6000名会员里，94%是白人，77%是男性。从数据上看，明显是过度白人化，而且男性占绝大多数。
     激起这个问题的导火索，是2015年和2016年的奥斯卡评选。连续两年，所有与演员有关的奖项里，被提名的人清一色都是白人。
     不少著名演员、导演拒绝出席颁奖典礼，以示抵制。还有人在推特上发起话题抵制奥斯卡的过度白人化，话题名叫#OscarsSoWhite，意思就是：奥斯卡太白了。
     奥斯卡也知道问题所在，今年的最佳影片奖就颁给了一部黑人电影，也就是开头提到的《月光男孩》，讲述的是一个黑人男孩的成长史，和他最终找到自己以及自己心爱之人之间的故事。

- **逐鹿世界电影市场的中国玩家**

  在“声动早咖啡”2月10日的节目《中国电影的世界野心》里，我们为你讲述了中国电影市场逐步开放，和中国资本收购美国电影世界的决心。中国玩家大手笔收购美国电影公司，院线巨头，可以说雄心勃勃。

  虽然中国电影人和奥斯卡无缘，但中国买家还是可以靠看奥斯卡大赚一笔。就拿《爱乐之城》来说，虽然最终获得最佳影片奖，但还是得到了14项提名，拿下了6个大奖。更重要的是，在中国市场那部分票房。这背后，是有中国电影身影的，湖南广电影业为这个片子投资了大约750万美元，拥有1/4股份。

  靠着《爱乐之城》赚钱的，还有成立不到3年，将电影引进中国市场的华瑞影业。这部电影在1月14日在大片场上映时，就已经有了金球奖，英国电影学院奖以及各大电影节大奖的加持，最终到2月27日，累计票房已经2.41亿进入院线了，奥斯卡金像奖颁奖典礼结束后，电影更是在非档期的2月28日拿下3000万票房。押对了宝的中国买家自然是赚得盆满钵满。

# 如何克服演讲中的紧张情绪

本条音频及文稿参考演讲杂志网站

![](img/2b1f55794a32401f6e1d5425100884b9_66_0.png)

### 内容简介

1. 为什么说全世界的人都害怕演讲？紧张是所有演讲者的共同痛点？
2. 如何克服紧张情绪？有哪些步骤可以实施？
3. 怎样在演讲中转移焦点？
4. 如何在演讲中设置暂停机制，使自己可以调整节奏，继续再战？

### 知识清单

- 几乎所有的演讲者都紧张

  怕做演讲，是我们共同面对的问题。几乎所有的演讲者都紧张，只是有人知道如何隐藏这种紧张情绪。

  教育家、公众演说家 Jonathan Robbins 在一篇文章中给出了应对演讲紧张情绪的**三个方法：练习十五遍，学会转移焦点，以及设立暂停机制。**

- 应对演讲中紧张情绪的方法一：练习十五遍

  作者认为，准备演讲，首先要有一个好的提纲。

  提纲是一个演讲的结构，包括你需要讲的几个要点，结构搭出来之后，可以看着这个框架上内容。很多演讲者首先从结构的准备上就有很多问题，要么不重视提纲，要么就没有提纲。很多人的提纲写得很好，但依然做出了一个很糟糕的演讲，因为他没有把这个提纲记到心里去，作者强调，这是一个大错特错。提纲一定要好好准备，烂熟于心。

  准备好提纲之后，要把整个演讲至少演练十五遍，可以是读，也可以是背。每准备一遍，都要在白纸上画一道杠记录。

  这个过程有一种仪式感，当你告诉自己，练十五遍有用，并完成了它，其实就建立了信心。

  这可以大大减少你的焦虑情绪，甚至是减少演讲里可能出现的废话、水词儿。

- 应对演讲中紧张情绪的方法二：学会转移焦点

  作者指出，要摆脱紧张，就要学会转移焦点。

  作者先举了个自己的例子，他在学校当老师时，要当着100-180位学生家长的面做演讲，特别紧张，直到有人告诉他说：家长并不在意你做了个演讲，我们只在意在意的孩子在学校表现如何。因此，人们在听演讲时，更在意的是信息，而不是信使是谁。

  将焦点从你身上移开是有方法的，如果你觉得站在舞台中央开演讲是一种让人焦虑的方式，那么可以换一种开场方式，例如，站在观众席上开始演讲，或者，如果有舞台的话，可以站在舞台后面或是幕布里面开始演讲。如果来的听众也不多，可以在开始前给每人发一张观众调查，转移他们的注意力，这样焦点就不会放在你的身上，你会觉得舒服很多，如释重负。

- 演讲依然需要交流

  但要注意，转移焦点不要矫枉过正，千万不要把辅助的手段，比如投影、幻灯作为全部焦点。回避观众的目光接触是不对的，演讲需要交流，而且并非需要眼神沟通，避免成为焦点，只是让你适应舞台的手段和方式，但还是要走进场，跟大家面对面。

- 应对演讲中紧张情绪的方法三：设立暂停机制

  在篮球比赛里，为了布置战术，或者在逆风球时为了打乱对手节奏、给队员一些喘息和重新掌控比赛的机会，这样会叫暂停。你也可以在演讲里插入这样的机制，一个最简单的方法，就是放几段小视频。哪怕只是一个3到5分钟的演讲，放到两个短视频是没问题的，听众不会觉得有什么奇怪的地方，相反，他们会认为演讲更丰富，更立体。

  而在这段时间的时间里，你可以抓紧重启一下状态，重新想想接下来要说什么，哪怕真的忘词了，还可以再看看提纲。

- 设立暂停机制的两个好处

  第一，不必苛求自己大段大段地讲述，因为给出一个一气呵成无比连贯的演讲，基本是不可能的。第二，这个办法可以减少演讲开始时的紧张和焦虑，因为知道接下来有“休息站”。作者打比方，暂停机制就好像是跳伞时的备用伞，你知道有一个备用伞，就会感觉有安全感，舒服很多。

# 彼得·蒂尔：高等教育的谎言

本条音频及文稿参考《新闻周刊》3月3日刊

![](img/2b1f55794a32401f6e1d5425100884b9_68_0.png)

### 内容简介

1. 美国高等教育的现状是怎样的？在美国读名校究竟有多贵？
2. 为什么彼得·蒂尔会抨击美国的高等教育？
3. 彼得·蒂尔的1517基金会做什么的？有多大规模？资助了什么创业项目？它真的可以有效地挑战美国高等教育体制吗？
4. 1517基金真正帮到的是哪些人？这个基金目前存在哪些弊端？
5. 1517基金会何争议？它的存在给高等教育带来了哪些启示？

### 知识清单

- 彼得·蒂尔的1517基金

  《新闻周刊》3月3日刊的封面是硅谷“创业教父”彼得·蒂尔的特写照，封面给出的副标题是：亿万富翁认为高等教育是一种巨大的浪费，他愿意花钱让你退学。

  文章介绍的是彼得·蒂尔创立的1517基金会，基金旨在鼓励那些有想法的大学生勇敢地辍学出来创业。

  彼得·蒂尔向来不以走寻常路而出名，他的一句批评现代科技的名言就是：我们一直想要一辆“会飞的车”，结果得到的不过是一百四十个字符。

  但彼得·蒂尔厉害的地方在于，他预测事情的眼光惊人地准确。比如他在Facebook刚启动的时候就果断地给马克·扎克伯格投资50万美元，最后获得了2000倍回报，同样的，在硅谷各界对特朗普一片骂声的时候，他却成为了特朗普在旧金山的竞选代表，最后的结果也是特朗普成功当选。

  彼得·蒂尔的思维模式就是要找出被大多数人忽略的、重要的问题。比如面试的时候，他会问应聘者一个问题：请你告诉我们关于这个世界，你认为对，而大部分人认为是错的想法。

- 彼得·蒂尔为什么批评美国高等教育

  关于高等教育，彼得·蒂尔也有跟一般人不同的思考，他认为高等教育是在浪费学生的时间。

  彼得·蒂尔对高等教育的不满主要集中在三个地方：高昂的学费、值得怀疑的价值观，以及排他性。

  1. **学费高昂**
     美国高等教育学费昂贵，并且还在持续上涨，高等教育费用的上涨是通货膨胀的两倍。
     这里可以做个比较，北大清华的学费，一年差不多是5千~6千，哈佛的学费是4.7万美金，相当于32万元人民币，耶鲁大学的学费是4.4万美金，斯坦福大学的学费4.6万美金，哥伦比亚大学、芝加哥大学、南加州大学的学费都在5万美金以上，这仅仅是学费，还不包含生活费。
     能拿到奖学金的学生毕竟是少数，学生们为了上大学，就需要贷款，这笔负债，已经达到了1.3万亿美元。
     这会带来一个后果，就是对于那些借了学生贷款偿还大学的学生来说，在毕业后要花很长时间来偿还贷款，他们可能没有办法，毕业后做自己真正想做的事情，而这对人才是巨大的浪费。

  2. **价值观可疑**
     彼得·蒂尔认为，高等教育存在很大的泡沫，这可能是继科技泡沫和房产泡沫之后，下一个会破灭的泡沫。
     他的观点是：如今美国那些名校，或者说精英大学，其实是过时的了，他们对科学研究是有价值的，但同时对对于科技进步贡献很少，而且最终会引发的是经济上的灾难性后果。

  3. **高等教育和名校的排他性**
     彼得·蒂尔认为关于高等教育的最大、最核心的谎言就是：名校管理者、毕业生们声称读名校是最好的、最积极的教育方式，是每个都应该参与的，但事实上这种做法让名校变得像是知名夜店，门口有很多排队的人，但最后只有很少的一部分人能够分享它。
     如果说哈佛大学真想让全世界都受益的话，就应该把哈佛完全开放，让更多人能够得到教育资源，但名校管理者们一定不会这么做，因为这种做法一定会遭到愤怒的校友们的围攻。这些名校的校友，他们的骄傲和对身份的高度认同感来自于排他性，也就是对稀缺资源的占有。

  以上三点：高昂的学费、值得怀疑的价值观和排他性，就是彼得·蒂尔对高等教育失望的原因。因此他创办了1517基金会，让辍学出来创业的年轻人们，可以在两年的时间里得到10万美元的启动资金，把自己的想法付诸实施，同时彼得·蒂尔还会提供机会让他们接触投资人和投资人，以便获得更多资金上的支持。

- 关于1517基金的争议

  关于1517基金会的争议非常大。哈佛大学教授拉里·萨默斯就对彼得·蒂尔的做法不屑一顾，他说：这个恐怕是十年来最具误导性的慈善行为。

  第一，彼得·蒂尔批评了名校的排他性，但事实上，彼得·蒂尔的基金会每年也只招收三十个成员，可以说比名校还“排他”。

  第二，受益与1517基金的都是些年轻人，在他们这个年纪，除了追求成功，同样也渴望有自己的生活。但是当他们加入到1517基金，就需要搬到旧金山的湾区，他们会感觉自己被孤立了，在这里没有社交、没有朋友。之前的幻想——搬去硅谷，整天碰到硅谷大佬们——也很快就会破灭，不是进入基金会，就能得到经常和 大佬们照面的机会。而且年轻人在大学时，还有人安排自己的生活，比如有人给他们建议、给他们课表，他们可以遵循，但现在全由他们要对自己负责。这对年轻人的自律性也是极大的考验。

  创业路从来都不顺利，如果能成为下一个Uber或者Airbnb的创始人，当然是一件非常棒的事情，但是每一个扎克伯格或者乔布斯这样离开学校的、成功创业的 名校友背后，都有成千上万怀着 自己的远大梦想，离开了学校，却最终 一无所成的人。

  第三，基金会的创业者的创业方向主要集中在生物、医学科技、运输和能源这些领域里，可以说这些创业者做的事，跟整个硅谷现在最擅长的那些事儿并 没有什么不同。问题在于这些项目，并没有超脱彼得·蒂尔的那条著名批评，也就是这些年轻人同样没办法给出“会飞的车”，最终还是只给出了140个字符。

- 1517的启示

  本文的作者认为，1517基金会的意义，并不在于给出了下一个马克·扎克伯格，或者说给了我们一辆“会飞的车”，而是引发了我们对于高等教育价值的思考。

  有人评价道，哪怕1517基金只是一个价值1600万美金的公关项目，只要基金会的出现能让父母们去思考，他们对于孩子和未来的投资是否值得？只要他们想了，那就可以说这个基金会获得了巨大的成功。

  1517基金的出现，引发了很多对于高等教育的补充形式的探索。

  比如说，现在有超过4000万的学生，可以通过网上的互动课程来学习编程，这个项目由哥伦比亚大学的一位辍学生创办，另外一些组织也在给孩子们，提供除了大学以外的其他学习途径和创业渠道。

  而更重要的是让学生们明白，他们有权力去选择自己接受的教育方式。传统的高等教育是菜单式的，你只能在规定好的范围内选择想学的东西，但是回归到教育的本质，难道不应该是学生，而不是高校管理者来决定，他们究竟应该学什么吗？

  最后要提一下1517基金的现状。在运行的6个月里，基金会一共接收了138名成员，只有12人回到了自己原来的大学，剩下的绝大一部，不是在继续坚持创业，就是去了大型科技公司任职。
