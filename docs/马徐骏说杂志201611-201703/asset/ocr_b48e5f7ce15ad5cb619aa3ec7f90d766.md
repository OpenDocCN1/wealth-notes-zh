她一共就做了两件事：一个是稳定现金流，另一个是组建人才团队。

其实这两件事儿，也是有先例可循的，就是现在被封神的乔布斯，在 1997 年，重新回到苹果公司的时候，也是面临着一个个烂摊子，跟迈恩斯的困镜几乎是一样的。而乔布斯就是先稳定住现金流，也就是说得先有钱把公司运营下去，才能考虑之后的事儿。

第三件事，乔布斯大胆地使用人才，把合适的人放到正确的位置上去，打造一个有战斗力的团队和良好的企业文化。虽然现在大家都常对乔布斯重口喷故后，是靠着一系列的创新，像音乐播放器iPod和之后的iPhone，把整个苹果公司重新带回了一条稳定的行刑。但要讲道，如果不是先做了稳定现金流和组建人才团队这两件事，苹果公司也不会之后有创新的源泉和基础，这点其实是很多人都忽略的。

而在Mary执掌通用汽车之后，既稳定好公司的现金流，又对团队的建设进行了大刀向手的改革，就包换了新的总裁，换了新的产品发展主管，以及财务总监。所以公司的经营，才明显有了起色。

通用汽车的这么口气儿，算是喘上来了，那接下来？Mary还有更大的目标和野心，她不但在继续也有建设了通用汽车的资产组合，还主动内，打破了自己公司的核心业务，这个真得有壮土断腕的根才气。

Mary Barra在公司未来的版路上，一共通过五件事进行了布局。

+   1. 搭住了一个平台

我们之前在《特斯拉的快车道》那篇文章里面讨论特斯拉车的方式，跟美国传统的汽车制造商是不一样的。美国的传统三大巨头，都是跟分销商之间买卖关系是松散的，所以是通分销量中是没有一个紧密的连接的，中间隔了一层。而通用公司在这方面是有先见，它仿对，也有公司有一个系统叫OnStar，其实对中国来说也不是，什样的东西一个系统叫做全五星，它的英文就叫On Star。这个系统可以确保通用汽车，可以直接迅速地触及时到，而且是是人工来为你服务的，不是机械者。我们常那些大的互联网公司的优势是平台化，但在这方面，其实通用是有自己的平台根基在的。

+   2. 寻找合作伙伴

美国最有名的出行公司是Uber，就像我们的滴滴出行一样，公司是次名次的公司，Lyft，它相当于我们以前的快的公司。Lyft跟Uber的竞争其实是的，也是Lyft在英国的竞争对手，今年早上的时候，通用公司叫Lyft公司，投入5亿美元，投资的道是为了能够有一个学习借鉴的渠道，是在共享出行行业做得好的，是能够现据掌握主动权。说白了，通用是想学习观察的用户，对出行交通工具的使用习惯。

+   3. 通用汽车推出了一个汽车共事的服务，叫做Maven

Maven这个英文词里面，是专家、内行的意思。这个词的模式是，有点像我们在中国的摩拜单车，也就是这个车放在这了，谁扫码就能够用，进去能用呢。那么一个一个就是，是通用公司进入这种分享服务的一个策略，万一当分享的那个Lyft公司出现问

题或者被竞争对手收购了，那么这个叫Maven的汽车共享事就是他们的又一张可以打出的牌，至少在事于这个领域通用不会被地出门、赶下墙桌。

+   4. 新产品的推出

在明年的年底的时候，通用公司会推出一款，全新的电动品牌汽车叫做BolT，这个词汇是闪电的意思，单名字上就让我，好像是通用公司要用闪电的速度绝地叫板，跟现在最火的电动车品牌特斯拉叫板。因为，这款车通用的电池对，无论是在价格，还是续航里程，额跟特斯拉要差一点，能开两百英里，售价是3万美元。这个跟特斯拉新车的续航比，是没有太多的，价格上比特斯拉要便宜5000美金，反正我本人感觉这个产品的推出，是想要截和特斯拉的意思。

+   5. 在新科技方面，积极主动地寻求突破

通用公司在前年收购了家，在无人驾驶方面比较先头的公司，叫叫Cruise。这家公司的英文名是“巡航”的意思，而且收购之后的Cruise公司跟着通用，在公6月份的时候，实行了一次无人驾驶，而且这次试驾是在美国旧金山这样一个山地城市，交通高峰的时候进行的，所以这个压力比在空旷的地方随便让车开，是要大得多的。结果，这个无人驾驶的测试，非常成功。

前面说了五条通用公司的新战略布局，最重要的应该是最后一条，也就是对于无人驾驶技术的探索。
