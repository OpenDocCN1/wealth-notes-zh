# 知识清单

《福布斯》杂志创刊于1917年，是全球财经界四大最著名的刊物之一，其他三个分别是《财富》、《商业周刊》和《经济学人》。

《福布斯》不仅关注金融、投资领域的消息，对于科技、科学、法律甚至时政领域的内容也有涉及。

《福布斯》最出名的是它推出的各种排行榜。从政治立场来看，该刊属于保守派的右翼杂志，偏向于共和党，也就是特朗普代表的党派。

特朗普究竟是靠什么赢得了此次美国总统大选？文章将特朗普成功的奥秘归结为：大选团的力量和他的竞选团队对创业精神淋漓尽致地发挥。

特朗普最大的秘密武器，是杰瑞德·库什纳，这个人物既是特朗普竞选团队的军师、智囊，也是特朗普的女婿，即特朗普大女儿伊万卡的丈夫。

硅谷“创业教父”彼得·蒂尔曾公开评价说，“如果把特朗普的竞选团队比作一家公司的话，那么特朗普就是这家公司的CEO，而库什纳就是公司的首席运营官COO。”他强调了库什纳在特朗普团队的重要性。

**杰瑞德·库什纳**

今年35岁，出生于犹太人家庭，父亲是房地产大亨。大学本科学业为哈佛大学，在纽约大学取得MBA学位，后又获得法律博士学位。

26岁的时候，库什纳就完成了当选美国《福布斯》杂志评选的“40岁以下最具影响力”商业人物，而这份榜单总共也只有40人。

为了帮助特朗普赢得竞选，库什纳主要做了三件事：拉关系、管钱和运营社交媒体。

+   1、拉关系  
特朗普是个管不住自己嘴巴的人，容易得罪人，而库什纳则完全相反：嘴严，脑子清楚，和他说话比较放松。库什纳因此帮助特朗普争取到了很多原本不可能争取到的支持者。传媒大亨默多克就是由库什纳搞定的。

+   2、会管钱  
库什纳负责特朗普竞选团队的财务管理，他主张把每一分钱都花在刀刃上。特朗普竞选团队最后花费的总额，仅仅是希拉里团队的一半。

+   3、善于利用社交媒体  
这是库什纳对于特朗普最不可或缺，也是帮助最大的一点。特朗普被称为“推特总统”，但他的社交媒体都由库什纳在运营。

库什纳雇佣了专业的数据分析公司，借助大数据的力量来精准投放广告，并且分析选民心态。特朗普竞选中的所有活动，几乎都由数据来决定：旅行、群访、广告、集会的地点，甚至是针对不同人群演讲的主题。

比如，库什纳会精投放竞选广告，竞选期间，每天发送超过1万份不同的竞选票广告给不同的目标选民。这样做一是省钱，二是可以有有效地影响选民。

没有政治经验是库什纳的短板，但他能够扬长避短，在做事情的时候完全从商人的角度来思考问题，拿最少的钱、花最短的时间、取得最大的利益。从这个方面看，没有政治经验也给了他另外一个优势，那就是不受传统竞选套路束缚，把自己的特长发挥到极致。最终帮助特朗普取得了看似不可能的胜利，成为了白宫的新主人。
