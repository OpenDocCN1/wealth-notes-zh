# 知识清单

+   - **奥斯卡乌龙事件**
就在今年第89届奥斯卡颁奖典礼上，在颁发最后一项大奖，也就是最佳影片奖时，现场闹出了大乌龙。
颁奖人先后获得最佳影片的是《爱乐之城》，但在整个《爱乐之城》的主创都已经上台，并且激动地等待将近5分钟之后，工作人员打断了发言，是因为颁奖弄错了推荐名单。获颁的说法是，另一部叫做《月光男孩》的电影。场面十分尴尬。

+   - **奥斯卡，Academy Award of Merit**
奥斯卡的全名叫做学院奖，英文是Academy Award of Merit，Academy就是“学院”的意思。
之所以叫学院奖，是因为这个奖是由一个叫做“美国电影艺术与科学学院”的组织每年颁发的。
美国电影艺术与科学学院的中文简称是：美国影艺学院。它不是一所学院，而是一个非盈利组织，由大约6000名电影专业人士组成。

+   - **奥斯卡奖是怎么评出来的？**
奥斯卡目前设有20多个不同的奖项，我们比较熟悉的有最佳男主角、最佳女主角、最佳导演、最佳影片等等。每个奖项都有自己的评审委员会，评审委员由刚刚才提到的影艺学院的会员组成，但学院并不会公布各个评审委员会的会员名单。
想成为会员也不容易，主要有两种途径：

一、在业内特别有名气，学院会邀请你成为会员；

二、由所在分会至少两名以上会员提名。比如，你是导演，那么你想要成为最佳导演评审委员会的会员，就得取得导演委员会里面，两名以上的会员提名。

学院对于按买影片的入围资格，也有严格的规定：

一、每个奖项的评委会，只能投票给该固定奖项。也就是说，导演只可以投导演奖，编剧只可以投编剧奖，演员只能投演员奖，不过最佳影片奖是可以全体投票的。

二、对入围获奖名单的影片的资格也有严格规定。除最佳外语片，其他所有的大国电影都要求必须在年前1月1日到12月31日之前，在洛杉矶地区的影院放映，并且连续放映不少于7天。

这也解释了为什么很多美国人认为不错的中国电影拿不到奥斯卡奖，因为只有影片首次在洛杉矶上映，并且没有连续放映实况7天以上，就连入围资格都没有。

+   - **即将90岁的奥斯卡，存在那些被人诟病的问题**

1. **权威性和公正性备受挑战**

奥斯卡不仅是美国电影行业界里最重要的活动，也是目前最受瞩目的电影奖项之一。

得到奥斯卡，不管对电影主创还是制作公司，甚至对市场的回报是极大的利润。因此每到“奥斯卡季”，也就是“Oscar Season”，电影公司都会卯足了劲去宣传作品，尤其是最佳影片奖。更是拉票的重灾区。为了增加入围最佳影片奖的机会，电影公司会花费数百万美元雇电影拉票。

奥斯卡当然不会忽视这一情况，获得最广泛的拉票行为。在2009年获得最佳影片的《拆弹部队》，其中一位制作人就因为过度拉票，被禁止出席奥斯卡颁奖典礼。

2. **是否促进多样性**

西方社会的种族构成多样，而人类之间的差别一眼就能看出来，象是黑人和白人，一眼就能认出来。在这种社会现实下，保持内部成员的多样性，以及获奖影片的多样性，就显得很重要。

回到奥斯卡评委委员的多样性上，美国《洛杉矶时报》报道说，截至2012年，评委会将近6000名会员里，94%是白人，77%是男性。从数据上看，明显是过度白人化，而且男性占绝大多数。

激起这个问题的导火索，是2015年和2016年的奥斯卡评选。连续两年，所有与演员有关的奖项里，被提名的人清一色都是白人。

不少著名演员、导演拒绝出席颁奖典礼，以示抵制。还有人在推特上发起话题抵制奥斯卡的过度白人化，话题名叫#OscarsSoWhite，意思就是：奥斯卡太白了。

奥斯卡也知道问题所在，今年的最佳影片奖就颁给了一部黑人电影，也就是开头提到的《月光男孩》，讲述的是一个黑人男孩的成长史，和他最终找到自己以及自己心爱之人之间的故事。

- **逐鹿世界电影市场的中国玩家**

在“说杂志”2月10日的节目《中国电影的世界野心》里，我们为你讲述了中国电影市场逐步开放，和中国资本收购美国电影世界的决心。中国玩家大手笔收购美国电影公司，院线巨头，可以说雄心勃勃。

虽然中国电影人和奥斯卡无缘，但中国买家还是可以靠看奥斯卡大赚一笔。就拿《爱乐之城》来说，虽然最终获得最佳影片奖，但还是得到了14项提名，拿下了6个大奖。更重要的是，在中国市场那部分票房。这背后，是有中国电影身影的，湖南广电广告为这个片子投资了大约750万美元，拥有1/4股份。

靠着《爱乐之城》赚钱的，还有成立不到3年，将电影引进中国市场的华瑞影业。这部电影在1月14日在大片场上映时，就已经有了全球大，英国电影学院奖以及各大电影节大奖的加持，最终到2月27日，累计票房已经241万进入院线了，奥斯卡金像奖颁奖典礼结束后，电影更是在非档期的2月28日拿下300万票房。押对了宝的中国买家自然是赚得盆满钵满。
