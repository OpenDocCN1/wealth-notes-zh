世界各地的基因编辑技术治出的白血病案例

文首提供了一个例子，一个叫Layla的女孩，早在14岁的时候该病已经得了白血病，医生已经束手无策。

在所有的传统治疗都无效之后，伦敦大学亚非医学研究学院的 Wassem Qasim 教授提出了一种通过干细胞治白血病的方法。对于这种治疗有一种叫“造父”的方法，干细胞可以治白血病和糖尿病，目前通过基因编辑过的干细胞已经能治白血病，通过干细胞治白血病已经能治糖尿病。

经过几个月的等待和Layla的治愈了，到现在已经快两年了，依然健康，白血球并没有发生异常，这是全球第一例通过基因编辑技术治白血病的案例。

# 基因改写历史

基因改写和基因编辑技术的背后并不简单，而是很精妙。

1953年，剑桥大学的 Francis Crick和James Watson两位博士生研究了DNA的双螺旋结构，这个成就奠定了人类对于人体基因组的理解。

1978年，首例试管婴儿生出来，

1981年，英国科学家最早在老鼠身上做了胚胎干细胞，胚胎干细胞就是在母体子宫里最后形成原始形态，最原始的形态，与之的身体癌细胞都是从胚胎干细胞中分化出来的。

1996年，名叫“多利”的克隆羊，也是英国科学家的新突破。

美国研制出基因序列方法。以前是乱剪，对健康基因的基因进行编辑，这可以比作修改的文件，甚至添加字信息。

# 基因技术到底能做什么？

+   1、治病
基因技术的最大用途，治病用来治病，以前像白血病这样的绝症很难治好，但Layla的医生告诉我们，这个病在基因里面可以修正的。
同时，包括治癌也可以治阿尔茨海默病，希望可以延长人类的平均寿命。

+   2、定制婴儿
定制婴儿这个词争议很大，婴儿可以像成品一样定制了，比如，扎着马尾辫，皮肤白白的，大眼睛大嘴巴，父母希望孩子有漂亮的发型，父母可以控制孩子的五官，甚至让父母的孩子有某种特定的基因特征。
如果我们对基因进行编辑，让基因发生突变，也有可能是下一代出现疾病，比如让女孩变成男孩，或者让男孩变成女孩，这在伦理和技术上都有争议。
总之，通过修改染色体、体细胞染色体，孩子的体质就会好一些，几乎就是一切完美的。

# 基因编辑的隐忧

+   1、不确定性需要再推测
基因编辑技术在中国团队中得到了。2015年4月，来自中国广州的科学家发表文章，他们使用了类似CRISPR的基因编辑技术，修改了胚胎细胞中一个重要的血友病基因。研究人员认为这项技术是可行的，但这一技术还在实验阶段，距离临床应用还有很长的路要走。
这种编辑引发了很大的争议，未来美国、英国和中国的科学家在伦理会议上，认为对人体基因进行编辑，风险是巨大的。

+   2、对后代的影响未知
现在，对于这项技术，基因技术发展的时间还是太短了，人们不知道基因编辑会对后代产生什么基因改变，一代一代传下去，会不会产生突变，或者引发更大的问题。

+   3、适应和公正性
美国从1998年开始，就禁止使用政府资助的基金去支持任何人类胚胎干细胞研究，因为进行胚胎干细胞研究必须破坏掉胚胎，这就会让胚胎形成胎儿在妈妈子宫里面的雏形。在很多人眼中，破坏胚胎相当于杀了一个孩子。
另外一个争议是基因检测，很多女性因为天生的基因而怕被自己孩子遗传。文章还提到一个案例，一位女性因为怀孕九个月却发现自己携带有致死基因，为了孩子健康进行了基因检测，结果显示孩子遗传了这个基因，她不得不面对选择，这很让人纠结。

+   4、对资源带来的机会不平等
基因编辑技术非常贵，不可能人人都能负担得起，所以有人担心，一旦富人可以使用这项技术，而穷人不行，那么富人就会越来越富有，而穷人则永远穷下去，这会导致社会的不公平。

# 总结

任何一种前沿技术在发展的过程中一定是意义不断扩，甚至涉及伦理争议，但有一些点必须注意，就是人类对于生物伦理的底线。对于DNA的改造技术也不该是非要改到尽善。
