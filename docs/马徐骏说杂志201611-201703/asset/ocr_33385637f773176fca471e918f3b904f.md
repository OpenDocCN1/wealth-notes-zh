# 知识清单

特斯拉电动车的直营模式，越过了经销商网络，保证了销售体验的完整性。

美国传统的销售方式依然采取代理方式，即汽车制造商把车卖给各个区域的代理商，这些代理商再去销售这些汽车。

特斯拉的销售方式：

+   - 体验店 (Showrooms)
- 展示厅 (Galleries)
- 游击店 (Pop-up shops)
- 网站 (Website)
- 直销店面 (Department stores)

目前特斯拉直营模式的问题主要来自两个方面：

+   1. 第一，美国本土的法律问题
2. 第二，来自于经销商和竞争对手的追赶与阻击

目前美国的汽车制造商反而被分销模式所拖累，这在全球市场也是别无二家的。

特斯拉现在需要做的，是找到更广的渠道合作，把产品展示给更多的顾客，来打动消费者。
