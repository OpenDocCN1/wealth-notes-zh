# # 排全球前三的CEO在担心什么

本文源自《哈佛商业评论》11月刊

![](bbox=[0.15, 0.075, 0.85, 0.135])

# ## 知识清单

上榜的100名CEO来自22个国家和地区，公司分布在19个国家和地区。其中16家公司，它们的总部，在其CEO的出生国家之外。

100名CEO中，24位有MBA的学位、24名有工科学位，30名CEO连续三年上榜。

他们成为CEO的平均年龄是44岁，并且在此之前，工作了长达17年的时间。

与去年的榜单一样，中国内地也仅有一位企业家上榜，那就是腾讯公司的创始人、董事长兼CEO马化腾，他的排名甚至也和去年一样，都是第45名。

今天这个时期对CEO们来说也非常有挑战性。全世界的经济增长都在放缓，政治动荡也降低了各个地区对长远发展计划的尝试。

企业高管有时会频繁更换。在2015年，全球的CEO离职率高达17%，而其中超过1/5都是被辞退的。

女性CEO特别少，100人里只有两名女性入选。文章表示，这并不是因为作为高管，女性的表现不如男性。主要是因为，在全球范围里，女性CEO本人人数就少，这次参评的公司一共886家，这些公司里只有28位CEO是女性，占所有候选人的3%。

现如今，年轻人的态度已经改变了。他们不会长期固定在同一个职位上，而是像蜜蜂采蜜一样，从一份工作跳到另外一份工作。

人们从一个机遇跳到另一个机遇，他们创建一个公司，然后再把这公司卖出去。打造长期的品牌，现在已经是一种正在“消退的艺术”了。

今天我给您分享的是《哈佛商业评论》最新出炉的，“世界百佳CEO”评选榜单以及上榜前五位CEO访谈的精华总结。

就快到年底了，《哈佛商业评论》对于全球商业上的一些变化和趋势，是有着自己的思考和见解的，他们最近的焦点，是关注“商业上长期主义与短期主义之间的冲突”，这是什么意思呢？就是在全世界的经济增长长期受阻的大背景下，有好多企业的股东，很多是“激进主义者”。

所谓“激进主义者”，也就是更关注短期收益的人，像是很关注股票是不是上涨啊？财报是不是好看啊？有着这种思路的人，就叫做做“激进主义者”，而现在这些人掌握了话语权，已经成为了对商业领袖和职业经理人的评判者。因此在短期之内如果CEO做不出特别瞩目的成绩，就很有可能会被更替换。

这篇报道还给出了具体的数据，2015年的时候，全球的CEO离职率已经达到了惊人的17%，而在这17%里面，又有1/5，是直接被迫辞退的。就是说，如果你干不好，没有达到公司的预期，那就走人吧！这也造成了现在的职业经理人，他们更加关注，公司在短期之内的表现是不是亮眼，而不是关注公司的长期发展有没有问题。因为短期的成绩才是跟他们手里的饭碗能不能端得稳，有直接关系。

这种关注公司短期之内强劲表现的行为就叫做“短期主义”。但是《哈佛商业评论》这本杂志，是不太赞成这种做法的，他们更加赞赏的是“长期主义”。

就比如说《哈佛商业评论》这份“全球百佳CEO”的榜单里，这些上榜的CEO，给股东创造了2000%的回报率。在这些人成为顶尖管理者之前，基本上有17年左右的工作经验，所以，他们当上CEO的平均年龄是44岁。

![](bbox=[0.15, 0.00102, 0.85, 0.00108])

而这份榜单的评选，自从2010年启动以来，一直到现在，采取的评比方式都是收集客观的数据，而不是看大众观点左右。就比如说，公众舆论不是太看好这个CEO？对这位CEO的媒体报道是不是多？这样的因素不会对上榜有影响。因为《哈佛商业评论》的编辑们认为，只有拿数据说话，出来的结果才是真实可靠的。其实这份榜单最早考虑的数据，就是CEO为公司创造的利润。
