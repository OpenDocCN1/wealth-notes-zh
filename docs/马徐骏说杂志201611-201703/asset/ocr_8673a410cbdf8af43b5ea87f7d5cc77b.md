# 知识清单

英语里，“慈善家”一词对应的是“Philanthropist”，这个词来源于希腊语。原意是对“人类的热爱之情”。慈善家指的是那些期望通过自己的付出，让人类社会变得更好的人。

文章认为，挣钱是困难的，把钱用正确的方式捐赠出去，比挣钱更困难。也就是做慈善、做慈善家，靠钱未必就能实现。

文章提出了一个观点，就是如果“做慈善”只是靠不停捐款，并且认为钱撒出去就能改变世界的话，那人类文明可能早就

不存在了。

慈善并不是捐钱这么简单，传统的慈善方式造成的后果，可能会适得其反带来破坏作用，因此“捐钱”这种慈善方式在一些地方，反而遭到了被帮助对象的抵制。

现有的慈善捐赠主要有三种途径：直接捐款、投资创业公司、捐钱给慈善组织。

+   1、直接捐款
effects往往较差，Facebook的创始人扎克伯格曾为美国新泽西州纽瓦克市的公立学校捐赠了1亿美元，意图在5年内扭转公立学校颓败的状况，但最终没能成功。

+   2、投资创业公司
这需要很好的判断力，没有投资经验，很难判断项目是否能成功。

+   3、捐款给慈善组织
这条看似最快捷可行的道路，也有问题，就是慈善活动不一定能够达成发起时的初衷，不一定能够真正帮助到那些需要帮助的对象。

2014年的一份对于贫困问题的调查研究显示，慈善组织这种为贫困国家捐款资金物资的方式，其实是造成这些国家始终处于贫困状态的重要原因。

当资金和免费物资源源不断地从发达国家输送过来的时候，这个受资助的地区最后必然发展不起来，这主要是因为：

+   1、这些输送使得当地人对免费捐赠更有依赖性。

+   2、受资助的国家和地区可能再也无法建立起自己的农业和工业，甚至当地原来比较成功的产业也会受到影响，无力参与国际市场的竞争。

文章认为，对于这些贫困地区和国家来说，不应只是给予他们免费的物资和金钱，更要帮助他们建立可持续的贸易和工业体系。这才是积极做慈善的方式，也是贫困地区和国家最需要的。

文章认为，对于资金有限，无法像比尔·盖茨那样支配海量资金成立慈善基金会的现代慈善家，可以尝试“罗宾汉法则”，这个法则取自一本名为《智慧行善的罗宾汉法则》的书。

“罗宾汉法则”
简单来说，就是使用成本效益分析法来做慈善。具体来说，就是先建立一个最终的目标，比如3年内要把某个贫困地区失学儿童的数量减少一半，接下来，将这个大目标拆分成各个可操作的小目标，一个个落实执行。然后设立节点，每到一个节点进行结果分析，看小目标是否实现。也就是说，做慈善就如同赚钱一样，也需要讲究方法和步骤。
