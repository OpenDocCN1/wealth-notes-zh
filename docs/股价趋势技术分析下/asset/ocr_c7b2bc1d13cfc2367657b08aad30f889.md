# 第33章 圓形戰術評論

![](bbox=[0.1, 0.13, 0.81, 0.41])

圖225. 這是NP在1944年的6個月期日線圖，其中有幾個支撐與壓力。價格在1943年與1944年出現一系列整理（此處只顯示其中一部份），然後發展為1945～46的漲勢，把股價推升到38。

事實上，本書提供的每份走勢圖，其中幾乎都有支撐與壓力的例子，讀者可以自行分析。NP走勢圖顯示的支撐與壓力並不特別。

由最左側的4月份開始，價格夾著大量下跌到14 1/4，然後回升到15 5/8，後者是前兩個星期的壓力區。接著，走勢形成等腰三角形排列，隨後以跳空缺口方式向上突破，價格直接挺進到17，在往後3個星期之內發生很小的矩形排列。然後，價格夾著大量向下突破矩形，這個走勢相當棘手，究竟應該視為等腰三角形突破之後的正常回檔，或是矩形的大量突破。

請注意，跌勢止於15，恰好是等腰三角形頂點的延伸，然後向上回升。漲勢直接測試矩形的上限，然後退回排列下限盤整三天，接著就向上穿越矩形上限。

7月份的頭部可以看成複雜頭肩頂或圓形頂，甚至可以歸類為矩形排列，向下突破之後，在5月的矩形上限附近稍做猶豫，然後繼續下跌，在4月份的上限16附近獲得支撐，但最後還是稍微跌破15。隨即股價跌破等腰三角形頂點支撐，但只勉強滿足3%幅度，這也是9月份底部的最低點。由這裡開始，股價再度攀升，最後在1945年12月創38的高價。
