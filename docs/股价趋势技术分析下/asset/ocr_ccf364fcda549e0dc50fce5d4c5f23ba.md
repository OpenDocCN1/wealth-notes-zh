# 第8章 進階研究

然後呢？實際經驗是不可取代的。

幽默作家Barry Le Platter說：「好的判斷力來自於經驗，經驗則來自於差的判斷力。」如果想成為交易者，就必須進行交易。沒有其他辦法。而且，我們都會犯錯。

犯錯是交易不可避免的部分。除非各位開始用實際的資金進行交易，而且是輸贏足以造成真正影響的大筆資金，各位就不能學到交易的教訓。紙上模擬不能取代實際資金的交易。如果沒有真正投入資金，就不能體會「期待」、「恐懼」、「貪婪」會如何造成影響。

另外，各位也要徹底瞭解交易的根本性質。透過這方面的知識，交易過程比較不容易犯錯，也比較容易由錯誤中汲取經驗。
