# 商品期貨

期貨是一種可供投資人按照目前價格買賣未來交割之根本商品的契約，期貨根本商品包括：農產品（例如：玉米、燕麥、小麥、黃豆、牲口等）；金屬（例如：黃金、白銀、白金、鉈等）；森林、纖維與食品（例如：木材、棉花、橙汁、糖、可可、咖啡等）；能源（例如：源由、熱燃油、汽油、天然瓦斯）；金融與其他衍生性產品（例如：美國公債等債務工具、股價指數、外匯等）。

美國的期貨產業起始於1800年代初期，最初是為了讓穀物生產者與使用者能夠讓未來交割的商品鎖定目前的市場價格，使得相關收益更穩定。隨著期貨市場的發展與標準化，開始出現一些投資與避險策略。目前，期貨與選擇權的根本商品，已經擴展到很多投資工具，而且也成為全球性產品。

實際經驗顯示，凡是在集中市場進行交易的股票與其他金融產品，都存在價格型態。商品交易也是運用這類圖形排列的另一個領域。交易活躍的資產，也同樣受限於經濟供需定律，其價格如果繪製為走勢圖，同樣存在有意義的趨勢與型態，就如同個別股票一樣，這些走勢圖也同樣可以看到上升趨勢與下降趨勢、密集成交區域、整理、反轉等。事實上，不論所交易的對象是股票或期貨，投機客的活動與投資人的根本心理，都是一樣的。

只要是交易活躍的商品期貨，例如：玉米、棉花、可可、咖啡、小麥……等，都適用技術分析的原理。可是，商品期貨與股票／債券之間還是存在一些本質上的差異，此處說明其中四點。
