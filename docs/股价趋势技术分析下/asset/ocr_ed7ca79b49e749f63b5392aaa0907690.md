# MACD超買／超賣

![](bbox=[0.15, 0.19, 0.93, 0.46])

圖187. S&P 500日線圖與MACD（1996年）。快速線向上穿越慢速線，代表買進訊號。反之，快速線向下穿越慢速線，代表賣出訊號。如果完全按照MACD的每個買進、賣出訊號進行交易，不難察覺其中的困難與風險。買、賣訊號分別採用不同的期數，可以解決其中部分問題，但運用其他指標也是一種方法，譬如：繪製MACD本身的趨勢線，通常也有助於判斷買、賣點。就目前這個例子來說，如果採用趨勢線，可以把9個交易訊號過濾為3個，而且方向都正確。

吉拉·亞伯爾（Gerald Appel）於1979年提出MACD，做為股市的時效指標。當初，對於S&P指數交易，他把MACD的超買、超賣水準分別設定為±2.50。對於紐約證交所指數，則建議採用±1.20。當差值線進入超買／超賣區域，就發出對應的買賣訊號。對於任何交易市場，也可以設定適當的水準來代表超買／超賣狀況，如此可以避免短期價格波動造成訊號反覆。MACD比較適合做為長期分析工具。
