# 圖解13. 風險分析

重點：投資組合風險報告。投資組合風險分析螢幕摘要顯示股票與選擇權專用的投資組合之插B獲利與數種風險衡量。

+   *   螢幕顯示：
*   股票代碼＝個別股票報價代碼；
*   股票部位＝所持有的股票數量；
*   δ值總計＝股票δ值與選擇權δ值的總和；
*   β值＝每支股票β值
*   β金額＝大盤走勢造成的風險金額；
*   β金額＝（δ股價）×β值
*   δ金額＝根據未平衡部位計算的年度化風險數據；
*   δ金額＝（δ總值×股票價格）×價格波動率
*   γ金額＝根據部位曲度計算的年度化風險數據。正數γ金額代表逆向價差交易，負數γ金額代表垂直部位：
*   γ金額＝γ總值×（股票價格×價格波動率）
*   θ金額＝假定股價不變動，部位每經過一天所發生的理論盈虧金額；
*   風險金額＝根據綜合δ金額與γ金額計算的部位年度化標準差；
*   風險%＝每個部位的投資組合風險%；
*   總計＝前述各欄的總和；
