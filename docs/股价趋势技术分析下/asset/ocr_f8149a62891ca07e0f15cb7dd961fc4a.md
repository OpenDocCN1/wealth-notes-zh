# 股價趨勢技術分析（下冊）

在頭部附近賣出。可是，當第三個峰位出現之後，我們決定不再進行類似交易。接下來，我們預期會有什麼發展呢？我們可能看到一段整理，股價可能展開中期整理跌勢，但也可能繼續延進。不論如何發展，我們都必須等待中期折返走勢，股價應該會大幅向下修正，但這可能要等待好幾個星期。然後，如果主要趨勢沒有反轉，我們將在中期走勢的支撐區尋找買點，後者通常位在前一波中期走勢峰位附近。次一段主升波很可能由這個支撐區起漲，所以是理想的買點。

當然，前述說法也適用於空頭市場。型態向下突破之後，可能發生一波、兩波、三波或更多波段的跌勢，中間所夾漲勢可能反彈到小型壓力區。然後（一系列跌勢通常以三波為準），可能會出現中期回升走勢。我們應該等待這波回升走勢結束，該波走勢可能由幾個小波峰構成，上檔目標區應該是在前一個中期跌勢的谷底，回升走勢預料會在此遭逢龐大壓力，所以這是再度放空的理想位置。

讀者心中一定會有些疑惑，最重要者可能是：我們如何判斷，預期中的支撐／壓力在什麼情況下，不能發揮作用？在什麼情況下，應該放棄既有部位？

這種問題處理起來，絕對不會讓人覺得愉快。舉例來說，某支股票上漲到25，我們準備在回檔過程買進，買單設定在23 1/2，因為前一波小型漲勢的峰位為23。結果，買單成交於非常沈悶的回檔走勢。隔天，股價又下跌到22 1/2，整天只有2、3筆交易。接著，股價又下跌到21 1/2，成交量還是很小。次一個星期，股價持續下跌，成交量很少，只要發生交易，價格就往下跳動，整個買盤似乎都消失了。這類下跌最後可能累積為中期折返，股價可能跌到15才會反彈。顯然地，這絕不是我們期待的結果，應該及早認賠出場。
