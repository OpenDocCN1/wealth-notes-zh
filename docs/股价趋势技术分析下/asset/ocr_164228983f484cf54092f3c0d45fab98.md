# 成交量做爲確認

每天的成交量型態被視爲常態，任何突然變動都代表背離現象。成交量的重要性不若股票交易，相關資訊也延遲公布。成交量雖然屬於整體資訊的一部份，但大體上只能做爲（事後）確認，協助解釋其他指標代表的意義。

圖191. 30年長期期公債，1997年3月份期貨契約。對於期貨交易來說，成交量不能推動行情，因為每個買方都對應一個賣方。成交量雖然很重要，但根據成交量預測後續發展，則非常不可靠。請注意11月份的情況，雖然價格繼續挺進，但成交量下降。

# 資金流量

未平仓量是透過一條曲線標示在成交量圖形上。原則上，未平仓量代表資金流入、流出市場的數量。如果交易雙方都建立新部位，未平仓量增加；如果某方新建立部位，另一方結束部位，未平仓量維持不變；如果雙方都結束既有部位，則未平仓量減少。
