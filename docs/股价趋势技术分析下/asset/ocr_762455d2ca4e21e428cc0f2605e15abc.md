# 股價趨勢技術分析（下冊）

三者相互衝突，就不能歸納出明確的折衷辦法。可是，多數情況下，我們將發現45%的折返點，剛好也是趨勢線的位置，同時也在支撐或壓力附近。當一波漲勢創小型峰位之後，折返走勢通常會到達（1）前一波漲勢的40~50%，（2）基本趨勢線，（3）先前漲勢的小型頭部支撐。所以，買進點需要綜合考慮這三個因素。如果根據某單一因素而「提早」買進，即使股價稍微繼續下跌，應該還不至於同時違背三個準則而引發停損。一般來說，買進點應該設定在三個準則顯示的最高價位，停損基準點則取三者的最低價位。當然，這三個準則顯示的價位，差距通常不會太大。前述討論方法也適用於空頭部位。

如果準備在中期修正走勢的下跌過程買進，或反彈過程放空，支撐／壓力的重要性可能相對高於折返幅度與趨勢線。我們當然會回顧股票過去的表演，最好先觀察週線圖與月線圖，評估主要趨勢發展，尋找重要的支撐與壓力水準，並估計中期修正走勢結束的可能位置。然後，將前述研究結果拿到日線圖上驗證，觀察更細微的技術結構。一旦中期修正走勢進入支撐或壓力區的3~5%範圍內，就必須留意不尋常大量；這也可能出現單日反轉線形。若是如此，應該立即進場，當然必須設定停損。否則，我們應該等待修正走勢顯得猶豫不決或趨於平坦，然後才進場；如果完全沒有前述徵兆，可以在支撐或壓力的3%範圍內進場。
