# 股價趨勢技術分析（下冊）

合來說，股價指數的獲利潛能雖然不能比擬，但後者的績效還是勝過絕大多數個別股票組合。

如果不準備涵蓋所有的類股，就應該挑選比較適合交易的類股。舉例來說，食品與煙草類股對於大盤的反應，敏感度遠不如鐵路類股；反之，釀酒與航空類股對於大盤的敏感程度很高。可是，各位也不需過分擔心選股的問題，如果最初挑選50支或100支股票，其中至少也應該有25支適合交易。不論最初挑選的股票如何，往後還可以加減減做調整，隨著經驗累積，總能夠挑選適當的股票。

> 編者附註：此處還有一點值得談論，「高科技」、「生化科技」或任何當時市場競相追逐的類股（幾十年後，太空飯店與宇宙旅遊類股可能是最熱門者），其獲利與風險性質都足以讓第17世紀的鬱金香投機客復活。對於一般的投資人與交易者而言，是否要把這些一時蔚為流行或狂熱的股票納入考慮對象，完全取決於個人的偏好與個性。沒錯，某人的香檳，可能是另一個人的毒藥。關於這方面的問題，第23章還會做進一步討論。

如果想要更簡單一些，投資人可以只追蹤下列兩支股票之一：S & P 500指數（SPY）的SPDRs或道瓊工業指數（DIA）的DIAMONDS。假定不只是單純買進，而且還賣出或做避險，則績效很可能超越大盤。這確實可以讓投資人的生活變得單純得多。
