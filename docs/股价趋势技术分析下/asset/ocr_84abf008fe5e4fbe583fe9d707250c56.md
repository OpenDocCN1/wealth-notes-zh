# 包寧傑帶狀與其他指標

由於包寧傑帶狀本身不會提供買賣訊號，所以需要與其他技術指標配合運用（例如：RSI或價格型態）。當價格觸及帶狀上限或下限，可能代表趨勢將持續發展，也可能代表趨勢即將反轉。包寧傑帶狀需要根據其他技術指標提供買、賣訊號（請參考第30章的支撐／壓力）。

如果與RSI或價格型態配合，包寧傑帶狀往往可以發揮強大功能。RSI是一種很好的超買／超賣指標。當價格觸及包寧傑帶狀上限，如果RSI讀數低於70，意味著上升趨勢將繼續發展。同理，當價格觸及包寧傑帶狀下限，如果RSI讀數大於30，代表下降趨勢將繼續發展。
