# 股價趨勢技術分析 (下冊)

![](bbox=[0.16, 0.11, 0.92, 0.55])

圖260. SOC日線圖，1962年6月~11月。評論11月份發生的突破走勢之前，

我們需要特別強調一點，在1961年10月份的古巴危機，這支股票並沒有跌破6月份谷底或創新低。這份走勢圖顯示雙重底的典型例子。雙重底的兩個谷底，價格不需完全相同，只要相當接近就可以了。重點是，股價跌勢在某一檔價位獲得支撐，然後上漲，不久之後又下跌，並且在先前的谷底附近再度獲得支撐。兩個谷底之間，應該有相當的時間距離，至少是6個星期，不過最好更多一點。另外，兩個谷底之間的價格漲勢，其峰位距離谷底至少要有15%的漲幅。當第二個谷底出現之後，價格一旦夾著大量穿越兩個谷底所夾的峰位水準，就視為型態完成。就目前這個例子而言，向上突破發生在11月13日星期二，並展開多頭漲勢，直到1963年5月出現高點1559為止，漲幅超過500點。雙重頂具有相反的意義；結構與雙重底很接近，兩個峰位發生在約略相同的價位，相隔幾個星期或幾個月，當價格跌破兩個峰位所夾谷底的水準，雙重頂排列即告完成。
