# 第 20-A 章 挑選適當的股票：長期投資觀點

交易工具，散戶也可以從事真正的分散投資。請注意，S&P 500指數成分股大約佔紐約證交所掛牌股票總市值的69%。買進SPDR，等於是買進整個美國經濟。至於道瓊工業指數的30支成分股，更是美國經濟、甚至是全球經濟的代表。不論在哪個市場從事投資，都絕對要留意這兩種股價指數的動向。整體股票市場的狀況，過去是由道瓊工業指數單獨代表，現在則由這兩種股價指數反映。

買進SPDR或DIAMONDS，等於是取得分散性投資組合。買進那斯達克指數或QQQQ，等於是投資風險較高的美國高科技產業。由於股票市場呈現長期的上漲偏頗，所以長期投資人有理由採用這兩種策略或戰術。當然，這并不代表投資人可以盲目建立部位，也不代表投資人可以不理會這些部位。事實上，剛好相反，各位應該還記得道氏理論的紀錄。即使是長期投資，也不該讓空頭市場損毀投資組合的價值。這些相關問題，已經在第18-1章做徹底討論了。

這些交易工具雖然很不錯，但還是要記住馬基的告誡（現在已經比較不重要了）：重點是很多股票構成的市場，不是單一的股票市場。換言之，當道瓊工業指數與S&P指數處於下跌時，即使是個別股票，其多頭部位的建立也要很謹慎，而且對於其漲勢要抱著懷疑的態度。另外，相較於精挑細選的個別股票，這種代表整體市場的指數型交易工具，續效表現可能差很多。舉例來說在1999～2000年期間，奎爾（Qualcomm）股價漲幅曾經到達240%，S&P指數的相同期間漲幅為24%。可是，那些在頭部買進奎爾，而在修正走勢底部賣出的人，會蒙受75%（$ 148）的損失。針對奎爾或其他類似股票進行交易的人，隨時都要留意股票市場的動靜，但SPDRs的投資者，可能每個禮拜才需要瀏覽股票市場的表現，或請經紀人在特殊狀況下（譬如：股價跌破趨勢線或逼近停止點）打電話通知。這些人可以吃得好好、睡得
