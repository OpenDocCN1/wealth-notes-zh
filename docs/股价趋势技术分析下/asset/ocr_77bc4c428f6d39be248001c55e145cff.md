# 第4章 進場

龜族採用兩種相關的系統進場，兩者都建立在董誼（Donchian）的通道突破系統之上。

談到交易系統，絕大多數人都會馬上想到進場訊號。他們相信，交易系統的最重要功能，就是提供進場訊號。

對於這些人來說，他們可能會覺得很訝異，龜族採用非常簡單的進場訊號，兩者都是取自理查·董誼的通道突破系統。

龜族採用兩套不同而相關的突破系統，分別稱為系統1與系統2。我們可以隨意決定採用哪套系統。某些人完全採用系統2，另一些人則把資金分為50－50%（或其他組合）而分別採用系統1與系統2。

系統1：屬於短期系統，運用20天期突破。

系統2：屬於較長期系統，運用55天期突破。

# 突破

所謂「突破」，是指價格穿越某特定天期的最高價或最低價。所以，如果採用20天期突破系統，只要價格穿越最近20天的最高價或最低價，就視為突破。
