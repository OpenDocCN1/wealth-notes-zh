# 股價趨勢技術分析(下冊)

候，最初都應該分別利用藍點與紅點標示前一頁圓形的最高收盤價與最低收盤價，我們將採用這兩個極端價位的區間，計算敏感性指數。當每張走勢圖繪製完成之後，可以衡量最高點（藍點）與最低點（紅點）之間的距離，表示為八分之一英吋的單位，然後把每支股票的區間距離加總，再除以股票總家數。結果是該期間內的平均區間，代表整體股票在該期間內的綜合或平均走勢距離。然後，挑選一個永久性的「正常」平均區間（設定為整體股票最近數期之平均區間的平均值），每當取得某期間的平均區間，就將永久性正常平均區間除以該期的平均區間，結果之數據代表該期間走勢距離相對於永久性正常走勢距離的比率倒數，我們稱此為「市場倒數」。舉例來說，如果某期間的市場倒數小於1（例如：0.65），代表該期的走勢波動相對劇烈，如果市場倒處大於1（例如：1.49），代表該期的走勢相對沈悶。

接著，每支股票的當期價格區間（表示為八分之一英吋單位），除以該股票價位正常或平均價格區間，再將計算結果乘以市場倒數。最後結果即是該股票在該期間內的敏感性指數。為了計算個股的整體或長期敏感性指數，我們可以計算各期敏感性指數的平均值。換言之，每期結束之後（繪製完成一張圖形紙），就可以計算該股票最新的長期敏感性指數。如果只有某特定一期的敏感性指數，數值非常不可靠，也沒有意義可是，當我們擁有第二期、第三期、第四期的資料之後，就可以取得相對穩定的長期敏感性指數。隨著時間經過，累積的資料愈來愈多，每支股票的長期敏感性指數將愈來愈穩定而接近常數；每增加一期資料，敏感性讀數可能只需要稍做修正。因此，我們可以透過敏感性指數預測個股相對於市場的走勢百分率。

請注意，此處是假定採用半對數方格紙，我們利用八分之一英吋為單位，藉以衡量價格區間的距離，相當於是衡量價格變動的百分
