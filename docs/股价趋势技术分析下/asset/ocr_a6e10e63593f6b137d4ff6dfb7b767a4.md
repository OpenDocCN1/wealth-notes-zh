# 艾略特波浪理論：觀點與評論

這個星期，我們很高興能夠參加紐約市場技術分析師協會（Market Technicians Association of New York，MTANY）的12月份聚會。

長期訂閱者應該清楚，MTANY曾經在1978年推選約翰·馬基為「年度最佳分析師」。當時的演講者是羅伯·普烈斯特（Robert Prechter，「艾略特波浪理論家」[The Elliott Wave Theorist]的發行者），他。根據艾略特的股票市場理論進行預測。

關於普烈斯特的評論，大家最有興趣的，是他對於技術分析本身的看法。艾略特波浪理論實際上只是股票市場價格走勢的一份「目錄」，顯示這些走勢如何一層疊著一層，直到所謂的超級或根本型態浮現為止；換言之，也就是純粹的技術分析。普烈斯特對於基本分析所做的定義如下：

+   1. 「首先，讓我們界定「技術」相對於「基本」資料的定義……技術資料是相關市場行為產生的資料。」

+   2. 「基本分析的主要問題，是其指標是由市場本身抽離的。分析師假定外部事件與行情走勢之間存在因果關係，這幾乎可以確定是錯誤的概念。可是，還有一點同樣重要而較少人留意的问题，基本分析在達成任何結論之前，幾乎必定要針對基本資料本身做預測。所以，分析師被迫採取第二步驟，他必須根據所預測的東西來預測另一項東西。技術分析師只需要採行一個步驟，這讓他們享有根本優勢。技術分析者不需預測所使用的指標。」
