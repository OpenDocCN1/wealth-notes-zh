# 第 28 章 何謂底部？何謂頭部？

會碰到模稜兩可的情況。雖說如此，我們還是可以設定一些運作上的判斷準則，而且這些準則失敗的機會不大。

關於多頭部位的停止單基準點，可以採用一種不錯的原則來判定最近的底部：當可能的低點發生之後，如果隨後三天的價格都高於該低點線形的最高價，則該低點將視為最近的底部。舉例來說，上升趨勢出現連續幾天的折返，某天曾經創低價 24，當天高價為 25。這種情況下，如果隨後三天的盤中價格都不曾低於 25 1/8，則 24 視為最近底部。隨後三天的整個價格區間，必須完全高於底部發生當天的線形（譯按：三天不必連續）。這就是所謂的「隨後三天法則」。相同的觀念也可以用來判定先前的頭部；換言之，隨後三天整個價格區間，必須低於頭部當天的線形。

這個法則可以用來設定最初的停損點，也可以用來調整後續的停止點。一旦隨後三天走勢決定底部之後，就可以把停止單移到最近的底部下側（第 27 章已經解釋如何根據最近底部為基準點而設定停止點）。

多頭部位的保護停止價位只可以向上調整；換言之，停止點設定之後，除非股票除息或除權（需要根據現金股利或權值向下調整），否則就不得朝相反方向調整。同理，空頭部位的保護性停止點，只可以調降而不能調升。（如果發生除息或除權的狀況，空頭部位停止點應該調降。）

某些情況下，很難判斷頭部或底部的位置；盤勢似乎出現整理或修正，但價格並沒有明顯朝次級趨勢方向發展。這種情況下（相對於一系列明顯的向上或向下波動），就必須仰賴個人的經驗與判斷，決定基準點位置。
