# 附錄 B

可是，我們希望強調一點，如果讀者準備深入研究技術分析，或打算以股票市場為終身工作場所，除了實際交易之外，還需要從事許多理論性模擬。如果想要進行具有統計意義的推論，至少需要有數百份類似案例。舉例來說，「這種交易機會有 75% 成功機率」或「這種交易方法的平均獲利，不足以彌補相關的稅金、佣金成與風險」。

進行理論性模擬交易，必須在預期走勢發生之前，於圖形上標示買進或賣出價位，根據實際情況假定委託單執行的價位，理論盈虧必須考慮佣金費用、略零股價差、股利與權值。針對模擬交易的結果「計價還價」，顯然沒有意義；唯有精確反應實際交易狀況，才能夠由這方面練習累積經驗。

記錄每筆可供交易的機會與所採取的行動，並分析事後發展，交易者將培養敏銳的感覺，在實際交易過程掌握可能的機會。眼見自己的預測逐漸實現，可以培養信心。如果詳實記錄所有理論交易，並將事前判斷、行情發展與事後結果標示在走勢圖上，可以反映自己的進步過程，用以對照理論交易與實際交易之間的差異。另外，如此也可以累積大量資料，可供深入研究之用。

初學者實際進行交易之前，最好利用幾個月的時間，從事理論性模擬交易（雖然我們知道，大部分讀者都不會聽從這項建議）。如果某筆理論交易獲利很高，不要覺得自己錯失機會。下個月或明年，市場仍然在那裡，還會繼續提供理想的交易機會。透過模擬交易，可以預先評估自己的反應，研究可能的後續發展。如果大部分初學者都有足夠耐心，願意在實際交易之前先做紙上模擬，就可以避開許多不必要的陷阱、損失與沮喪。
