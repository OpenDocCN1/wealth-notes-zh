# 名詞解釋

**Tangent**（切線）：參見「趨勢線」（Trendline）。

**Tape Reader**（判讀盤勢）：根據「紐約證交所」與「美國證交所」傳送的價、量即時資料，藉以擬定交易決策。

**TEKNIPLAT Paper**：一種繪圖專用的方格紙，垂直距離取對數刻度，水平距離取算術刻度。

**Test**（測試）：這是指股票或商品價格折返先前重要價位（例如：趨勢線、支撐、壓力……等），藉以測試其效力。

**Thin Issue**（成交量稀少的股票）：流通籌碼少、成交量低的股票。

**Three-Day-Away Rule**（隨後三天法則）：這是愛德華與馬基設定的法則，藉以判斷可能的小型頭部或底部。

**Throwback**（突破之後的回檔）：當價格向上突破區域型態之後，重新回檔到型態邊界的走勢。向下突破之後的反彈，稱為「Pullback」。

**Top**（頭部）：參見「擴張頂」（Broadening Top）、「下降三角形」（Descending Triangle）、「雙重頂」（Double Top）、「頭肩頂」（Head-and-Shoulders Top）、「三重頂」（Triple Top）與「圓形頂」（Rounding Top）。
