# 第28章 何謂底部？何謂頭部？

整，股價沒有明顯下跌。如果股價向下修正，可能會逼進或跌到前一個小型峰位（支撐）。另外，修正走勢也可能帶動價格回到基本趨勢線（銜接先前兩個或多個小型底部的直線），或是平行折返線（銜接先前兩個或多個小型峰位的直線）。如果修正走勢採取橫向盤整的方式，很可能會止於前述的兩類趨勢線之一。

不論修正走勢如何發展，觀察重點都在於「成交量萎縮」。新的頭部發生之後幾天內，不論價格折返或停頓，如果成交量萎縮（允許不規則發展，但整體而言必須有縮小的趨勢），則可以合理判定這是小型修正走勢。接著，如果股票繼續朝主要趨勢方向發展，而且符合「隨後三天法則」，就可以將該底部視為新的基準點（如果修正走勢採取橫向整理的方式，可以採用繪製趨勢線穿越的點，不一定要採用極端點）。

如果股價先出現一段橫向波動，然後進行突破，並展開新的漲勢；這種情況下，我們經常很難判斷最近底部位在何處。突破之前，可能出現好幾波不重要的走勢，成交量很小。若是如此，我們將以大成量為突破訊號，並將訊號發生之前的最近期低點，視為基準點。

前述有關多頭市場基準點的種種評論，也同樣適用於空頭市場，但向下突破不一定伴隨大量。
