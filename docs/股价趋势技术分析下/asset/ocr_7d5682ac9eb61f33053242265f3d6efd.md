+   1. 凸顯價格走勢圖不容易呈現的資訊。
2. 超買（70以上）或超賣（30以下）區域內的擺動失敗（swing failures），代表趨勢反轉的警訊。
3. 更清楚顯示支撐／壓力。
4. 價格與RSI之間的背離現象，經常是判斷趨勢反轉的有用指標。

RSI需要一些領先時間才能成功運作。

# 擺動失敗（W狀排列）

RSI出現突兀狀走勢而跌破30，然後向上回升，接著又出現突兀狀下降（但低點位置高於先前低點），當RSI再度回升而穿越兩個低點所夾峰位，代表買進訊號。同理，在超買區域也可以界定類似的賣出訊號；換言之，在70以上區域，RSI出現M狀走勢。

# 背離現象

對於任何技術指標來說，背離現象往往是最重要、最常見的趨勢變動訊號之一。所謂的背離，是指通常應該朝相同方向發展的指標，卻出現反向走勢，顯示當前的價格趨勢可能發生變化。背離通常是趨勢反轉的可靠訊號。我們所考慮的背離，可以發生在：道瓊工業指數／道瓊運輸指數、個別股票／大盤指數（譬如：S&P 500）、期貨價格／10—14天期RSI或其他。交易者往往會等待背離現象的確認，然後才實際進場，這是避開假訊號的有效方法之一。
