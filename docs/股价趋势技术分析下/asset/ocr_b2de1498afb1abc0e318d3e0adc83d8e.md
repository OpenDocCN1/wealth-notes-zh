# 第4節 夏普率

這個公式雖然不正確，但不會妨礙讀者瞭解夏普率（Sharpe Ratio）的觀念。可是，相信或不相信這種觀念，那又是另一回事了。夏普率的公式如下：

SR = (E—I) / sd

其中

E = 期望報酬

I = 無風險利率

sd = 報酬率標準差

這種毫無彈性的公式，在交易實務運用上毫無意義。這個公式假定標準差衡量的報酬波動率也就等於風險（學術界的普遍問題）。標準差計算沒有彈性，沒有辦法衡量交易者最關心的淨值最大減損，這也是交易者實際上可能碰到的最大災難。更明確說，這是最大期望損失，也就是由淨值最高點到最低點之間的距離。

# 第5節 價格波動率計算說明

計算投資組合的價格波動率，首先取得投資組合各期報酬率（Ri）與其平均數（µ）之間的差值。然後計算這項差值的平方（[Ri—µ]²），加總取得各期平方總和（∑[Ri—µ]²），再除以總期數減1（n—1）。結果就是變異數（variance）。取變異數的平方根，結果就是標準差，也即是價格波動率。
