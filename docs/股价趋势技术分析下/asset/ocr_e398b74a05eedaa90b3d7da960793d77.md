# 第 22 章 圖形選股策略 II

則圖形涵蓋的產業，應該儘可能分散。如此一來，當某些類股呈現沈悶或冷清走勢時，其他類股或許有交易機會。（可是，不要因此推論某個類股中的每支股票，都會有相同走勢。個股走勢經常受到特定因素影響，這些因素可能可能只涉及一支或幾支股票。可是，整個產業畢竟還是處在相同背景環境下，走勢的基調還是有某種程度的類似性。）

根據前述評論，繪製圖形應該儘量涵蓋每種重要的產業。可是，假定受限於能力，只能照顧少數的圖形，每個產業往往只能挑選一支代表性股票；這種情況下，應該如何挑選呢？舉例來說，假定我們想在鐵路類股內，挑選一支最具代表性的股票。編者附註：生化科技類股或網際網路類股。事實上，鐵路是一個非常重要、龐大的產業，我們或許應該挑選一支以上的個股，但暫時只考慮一支。第9版附註：更好的辨法，是直接挑選類股指數。換言之，挑選所有的成分股，而不是單一個股，這兩種選擇並不衝突。

應該是高價股或低價股？首先討論這點。

就鐵路股過去的資料來看，低價股的走勢百分率，經常超過高價股。一支 $5 左右的股票，可能在幾個星期之內上漲 100% 而成為 $10。可是， $100 或 $200 的股票很少能夠在幾個星期之內上漲 100%。如果整體產業狀況是以讓 $5 的股票上漲到 $10，則 $100 的股票大概只能上漲到 $140。所以，如果利用 $1,000 資金購買 $5 的低價股，可以賺取 100% 或 $1,000 的獲利。另一方面，如果購買 $100 的股票，只能賺取 $400 的獲利（股價上漲點數雖然較多，但百分率較少）。低價股獲利大約是高價股的兩倍半。
