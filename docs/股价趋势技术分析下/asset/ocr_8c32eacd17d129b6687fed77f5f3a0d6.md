# 股價趨勢技術分析（下冊）

![](bbox=[0.267, 0.127, 0.857, 0.375])

圖224. LV在1945年底到1946年初的日線圖，充滿許多跳空缺口。當時，LV正完成次級修正走勢，接下來將進行另一波漲勢（結果也是最後一波），試圖穿越1945年位在17的頭部。此處討論的情況，可以視為雙重頂（譯按：第二個頭部沒有顯示），因為價格在1946年夏天跌破兩個頭部所夾的谷底水準，然後繼續下跌到5。

不是每個缺口都具有意義；舉例來說，10月3日的缺口發生在狹幅整理區，成交量很小。11月3日的缺口發生在星期六，成交量增加一倍，顯然是重要缺口。當天的收盤價穿越幅度不足3%，所以稱不上真正的突破缺口，但多頭意涵已經表達得很清楚，可以在小型回檔過程買進。回檔過程，成交量縮小，沒有特殊意義。一直到1月份的第3個星期，我們才見到另一個缺口，看起來像是真正的突破缺口。1月14日，LV夾著大量上衝，1月16日的高價為15 7/8，收盤價為15 1/2，出現第二次大量。第一次大量發生時，如果多頭部位採用收盤價逐次停止單，將在15 1/2出場，如果在第二次大量採用逐次停止單，將在15 3/8出場。當價格折返到14 1/2，可以考慮重新進場。1月23日出現突破缺口，展開第二段漲勢。第二天（1月24日）又發生跳空缺口，如果視為逃逸缺口（衡掌握缺口），上檔應該出現17 3/4的目標價位。可是，1月28日又發生第三個缺口，當天線形為單日反轉，而且爆量高潮大量，清楚顯示這波走勢將告一段落，在收盤價設定逐次停止單，結果在16 3/4出場。請注意下跌過程的反彈走勢，曾經出現跳空缺口而在15形成單日的島狀反轉。
