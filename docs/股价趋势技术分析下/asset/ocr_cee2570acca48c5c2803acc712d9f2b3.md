# ## B、TEKNIPLAT圖形紙

如果從來沒有採用過這種半對數（比率或比例）圖形紙，這部分說明有助於各位瞭解與分析這類走勢圖，而且有助於各位自行繪製圖形。

對於工程師或有經驗的繪圖者，這種圖形紙絕對不會造成困擾，但很多人從來沒有繪圖經驗，或只利用垂直距離固定的算術刻度方格紙，他們對於不斷變動的一方格垂直距離，可能覺得很迷惑。可是，一旦熟悉之後，這種圖形紙更方便使用，因為不同價格的相同百分率變動，始終位在相同的距離之外，我們可以憑藉著肉眼判斷位置，不需參考左側的座標刻度。

如果圖形準備用來顯示工作時數、溫度變化或水深，可以采用一般算術刻度的方格紙，每個「小時」、「度數」或「英呎」都在圖形上代表相同的垂直距離。在圖形上，5呎與10呎之間的垂直距離，一定等於105呎與110呎之間的距離。

可是，股價變動不適合採用前述方式表示。沒錯，某支股票由$5上漲到$10，變動是$5，每100股的價值變動為$500；另一支股票由$100上漲到$105，變動也是$5，每100股的價值變動也是$500。可是，就後者而言，需要投入的資本顯然較多。

舉例來說，如果投入$1,000資金分別購買前述兩支股票。對於股價$5的股票，可以買進200股，稍後賣在$10，獲利為$1,000，報酬率是100%。對於股價$100的股票，$1,000可以買10股，稍後賣在$105，獲利是$50，報酬率是5%。

如果圖形紙的價格刻度是利用相同距離代表相同的百分率變動，就很容易比較不同交易的盈虧百分率。這也正是TEKNIPLAT圖形紙
