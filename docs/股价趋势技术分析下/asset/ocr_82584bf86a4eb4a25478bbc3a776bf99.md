圖解8. 趨勢行為顯示的買進準備訊號。

+   A. 貫穿上升的藍色趨勢線。

+   B. 貫穿水平狀藍色趨勢線。

+   C. 沒有其他型態或技術現象，只是價格穿越下降的藍色趨勢線，這並不足以代表結論性的反轉證據而買進。

+   D. 處在平行狀的上升趨勢通道，價格觸及藍色趨勢線。

+   E. 處在向外發散的上升趨勢通道，價格觸及藍色趨勢線。

+   F. 處在向內收斂的上升趨勢通道，價格觸及藍色趨勢線，不代表買進訊號，因為可能發生具有空頭意識的楔形排列。

+   G. 矩形排列的第5個反轉點觸及藍色趨勢線。

+   H. 上升三角形排列過程，價格觸及藍色趨勢線。

+   I. 價格夾著大量貫穿下降的藍色趨勢線，而且紅色趨勢線處於上升狀態（等腰三角形）。

處在上升趨勢，藍色趨勢線屬於折返趨勢線，當價格觸及折返線而拉回之後，根據最近兩個峰位重新製製藍色趨勢線，並在兩個峰位所夾谷底繪製藍色平行線，買點可以設定在藍色平行線附近。請注意，如果價格有效向上突破型態（例如：矩形或三角形），買點可以設定在40～50%的折返位置（參考正文）或下檔支撐。
