# 負值的綜合槓桿 

前文曾經談到，多頭市場的空頭部位（或空頭市場的多頭部位）具有「保險」功能，我們可以透過評估指數建立這類 的反向部位，藉以達成平衡效果。這些防護性放空或買進，一定會減少綜合槓桿或交易部位承擔的風險程度；事實上，這也正是這類策略之所以被採納的原因。

對於某推定的主要趨勢，將順勢部位承擔的風險表示為正數，逆勢部位承擔的風險表示為負數，則整體交易部位的總風險可以調整為零。換言之，理論上，我們可以讓整體交易部位幾乎不承擔任何風險，但實務上來說，並不太可能，因為這些風險衡量只是粗略估計，而且我們持有的每支股票隨時都可能出現意外走勢。

編者附註：自從布萊克·薛里斯選擇權訂價模型普遍運用之後，某些精明的交易者採用一種稱為「(中性) (Delta Neutral) 的方法從事選擇權套利。我在選擇權研究公司 (Options Research, Inc.) 的老闆布萊·胡爾 (Blair Hull) 就是這類最精明的交易者之一。所謂的「(中性)」是指極短期的行情走勢，不論上漲或下跌，理論上都不會影響選擇權套利組合的價值。這種方法曾經幫很多造市者賺進龐大財富。請參考史瓦格的《金融怪傑》。

雖說如此，我們確實可以透過反向部位，顯著降低整體交易組合承擔的風險。
