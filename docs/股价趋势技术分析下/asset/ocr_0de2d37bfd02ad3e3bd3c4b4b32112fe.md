# 保守投資的觀點變動

現實世界幾乎已經沒有第20章描述的所謂保守投資人 了，除了仍處於遠古時代的信託單位。當然，或許還有少數極端排斥風險的人，繼續採用前述描述的投資方法。銀行信託部門也可能繼續這麼做。為什麼？因為防止信託受益人控告他們。當然，即使是如此，信託受益人還是可能控告他們不勝任。可是，這正是信託機構之所以存在的理由：當信託受益人控告時，給予受託人法律保障（所謂的「謹慎管理人條款」）。目前，多數開明的信託機構或受託人，都會採用指數型產品，或其他更有效的策略，因為這才符合謹慎管理人條款的新定義。如果管理不當或績效顯著不彰，信託受益人需要另外尋找適當的管理人。
