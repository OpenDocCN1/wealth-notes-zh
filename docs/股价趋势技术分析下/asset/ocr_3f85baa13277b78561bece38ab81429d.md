# 股價趨勢技術分析（下冊）

![](bbox=[0.15, 0.13, 0.92, 0.46])

圖201.0. 恩隆週線圖。如果投資人只能由本書學到一件事，那就是這件了，這可以挽救他的投資組合、退休計畫（如果整個退休計畫都持有安隆股票的話）。反之，安隆的員工則犯下嚴重的錯誤，他們沒有分散投資，他們把所有的雞蛋都擺在同一個籃子裡，他們的投資與收入都依賴相同來源。可是，此處的真正教訓還不是分散投資。重點是：股價趨勢向下反轉時，務必出脫股票。這個教訓的輔助定理：絕對不可買進下降趨勢的股票。更重要者，當價格處於暴跌狀態，千萬不要買進。各位或許認為，這是非常明顯的道理。對於當時的某些專業玩家，情況未必那麼明顯；當安隆股票以每小時100英里的速度急墜時，邁阿密大學的投資組合經理人還繼續買進。沒錯，他們買進一家規劃非常精密（？）的公司。莫特利·富爾（Motley Fools）從頭到尾抱牢股票。
