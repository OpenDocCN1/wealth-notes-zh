契約口數只剩下1口，因為1.688的整數部分為1.0。對於小額帳戶來說，這種調整單位的影響很大，嚴重降低分散交易的效益。

# # 衡量風險的單位

龜族採用「單位」來衡量部位規模，而且這些「單位」是根據價格波動風險進行調整，所以「單位」同時衡量個別部位與整體交易組合的風險。

龜族必須接受風險管理條款的規範，在4種不同層次上，限制每個人特定時間所能持有的「單位」數量。原則上，這些規定會控制每位交易者所承擔的總風險，並侷限連續虧損期間或重大價格波動期間的虧損程度。

重大價格波動的一個典型例子，發生在1987年10月股市大崩盤的隔天。美國聯準會在一夜之間調降利率數個百分點，試圖強化股票投資人的信心。龜族持有大量的利率期貨多頭部位，包括：歐洲美元、國庫券與公債。當天發生的損失非常可觀。對於某些人，一天的損失高達帳戶淨值的20～40%。如果沒有部位規模限制的話，損失想必更嚴重。

相關的限制如下：

| 層次 | 類型 | 最高單位 |
| :--- | :--- | :--- |
| 1 | 單一市場 | 4單位 |
| 2 | 相關程度高的市場 | 6單位 |
| 3 | 相關程度低的市場 | 10單位 |
| 4 | 單一方向:多頭或空頭 | 12單位 |

單一市場：每個市場最多不超過4單位。

相關程度高的市場：對於相關程度很高的市場，任何特定方向的總部位不得超過6個（換言之，多頭部位單位，空頭部位6單位）。
