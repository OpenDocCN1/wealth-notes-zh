# ## 第23章

# 高風險股票的挑選與管理

新、舊世紀交替階段出現的網際網路類股，最能夠顯示價格排列的永恆性質。這些股票呈現一些屢試不爽的人性：鬱金香狂熱、淘金熱與迅速致富良機。網際網路類股展現的投機狂熱，實在無異於17世紀發生在荷蘭的鬱金香狂熱。在馬凱（MacKay）的經典著作《《非同尋常的大眾幻想與群衆性癲狂》，Extraordinary Popular Delusions and the Madness of Crowds》，整個國家的正常商業往來都被鬱金香球根取代了，很多交易者因此而致富。一個非同尋常的球根，價值可以等同於大筆房地產、釀酒廠或其他高價資產。馬凱在書中有一段我最喜歡的描述：「黃金釣餌吸引人們前往鬱金香市場，就像追逐蜂蜜罐的蒼蠅。每個人都夢想鬱金香風潮會永遠流行下去，世界各地的財富都會源源不斷送來荷蘭，聽任他們索求任何價格。」

這些狂熱最後的結局，只有一個「慘」字能夠形容。經過這段調整，或許能夠讓我們由比較正確的角度看待網際網路，這畢竟是該領域的科技與經濟基礎。我們不能用鬱金香來比擬網際網路類股的後續發展。另外，不可否認的，1849年的加州淘金熱確實讓少數人致富。
