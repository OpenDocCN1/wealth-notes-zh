# 第 4 版 序

本書第1版發行以來，已經有幾年的時間，但股票市場「還是遵循舊有的運作方式，相同的型態還是不斷重複發生。」第1版描述的重要技術現象，仍然在市場重演，我們沒有理由認定，這些股票的習慣性行為將在未來發生重大變化，除非整個經濟體系出現革命性的變動，例如自由市場經濟完全消失。

由於市場的基本性質沒有顯著變化，本書第I篇的「技術理論」部分，內容沒有必要做大幅更動。我們詳細研究前一版的内容，必要之處都更新資料。第II篇的「交易戰術」部分，修改層面較廣，主要是因為這部分內容與市場之間有較高的連動性，需要因為保證金或其他相關法規的差異而做調整。另外，我們也稍微修正技術方法在戰術層面上的運用，第II篇也納入這方面的考量。

本版比較不強調停損單的供能，因為有經驗的交易者並沒有採用停損單的迫切必要。為了透過平衡與分散交易達成資本保護的目的，我們也稍微修改「始終追隨主要趨勢」的基本觀點。為了避免「全有或全無」的立場，以及因此而可能引發的危險，我們介紹「評估指數」
