# 第37章 相同的舊有型態

假定我們真的放空LA。請注意11月4日（星期四）與11月5日（星期五）的「價漲一量增」關係；隔週的星期一與星期二，價格稍微收低，交易區間很小，成交量也萎縮。然後，星期三價格大漲，成交量顯著放大。截至當週結束的一週半整體走勢，基本上還是維持價漲量增、價跌量縮的傾向。等到12月的第一個星期（如果不是更早的話），已經可以清楚看出危險的訊號，應該回補空頭部位。

這種結果並不是一場悲劇，甚至不該覺得沮喪。某些交易者很容易因為些許損失而情緒激動；若是如此，將不能掌握反轉部位的機會。
