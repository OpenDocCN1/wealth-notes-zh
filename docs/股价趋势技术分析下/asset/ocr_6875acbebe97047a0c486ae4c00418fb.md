# 股價趨勢技術分析(下冊)

**Measuring Gap（衡量缺口）：** 參見「逃逸缺口」（Runaway Gap）。

**Megaphones（喇叭狀排列）：** 即是擴張頂排列。擴張排列有三種形式，分別對應於逆向等腰三角形、逆向上升三角形與逆向下降三角形。舉例來說，在等腰三角形的形式中，價格將沿著水平狀軸心波動，震幅愈來愈大，小型頭部愈墊愈高，小型底部愈來愈低。排列的上限與下限，呈現發散狀，上限向左上方傾斜，下限向右下方傾斜。擴張排列的結構相當鬆散而不規則，不同於對應的等腰三角形，後者的結構很緊密、明確，兩條相互收斂的上限與下限，代表相當理想的上升與下降趨勢線。擴散排列中，小型波動的頭部與底部，通常不會落在上限與下限的合理範圍內，而且經常出現突兀狀線形。

**Minor Trend（小型趨勢）：** 本書所謂的小型趨勢，是指短暫的波動（通常不到6天，很少超過3個星期）。一系列小型趨勢，將構成的中期（中級）趨勢。

**Momentum Indicator（動能指標）：** 一種利用成交量數據而預測當時行情強弱的市場指標，並判斷超買／超賣程度與趨勢轉折點。

**Moving Average（移動平均）：** 一種平滑資料的數學方法。這種方法之所以稱為「移動」，因為資料的期數為固定，但期間不斷往前移動。每當添入一期的新資料，最舊一期的資料就必須刪除，使得平均數得以隨著時間而移動。
