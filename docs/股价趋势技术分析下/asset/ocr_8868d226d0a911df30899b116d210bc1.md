# 名詞解釋

「突破缺口」（Breakaway Gap）、「逃說缺口」（Runaway Gap）、「竭盡缺口」（Exhaustion Gap）與「島狀反轉」（Island Reversal）。

**Graph（圖形）**：參見「走勢圖」（Chart）。

**Half—Mast（旗桿半途）**：參見「旗形」（Flag）。愛德華說：「旗形飄揚在旗桿中央」，是指直線狀走勢經常會在其走勢中途出現旗形整理。

**Head—And—Shoulders Pattern（頭肩型態）**：通常屬於主要反轉型態，但偶爾可能是連續型態。頭肩排列由四個部分構成（以下說明是以「頭肩頂」為準）：（1）一段延伸性漲勢結束而形成大量峰位，回檔縮；這個峰位稱為「左肩」。（2）出現第二個大量峰位，超過左肩的價位，然後回檔到大約左肩底部的水準，成交量縮小；第二個峰位稱為「頭」。（3）發生第三波漲勢，成交量顯著小於第一波與第二波漲勢，峰位不能超過「頭」的位置；這是「右肩」。（4）以一條直線銜接左肩與頭部的回檔低點，這是「頸線」，當收盤價跌破頸線的程度超過3%，即是確認頭肩頂排列完成。「頭肩底」或其他頭肩型態，也是由這4個要素構成。頭部與底部排列的主要差異，在於成交量型態。頭部形態可以夾著小量向下突破，底部型態必須夾著大量向上突破。最低衡量公式：由突破點朝適當方向衡量頸部到頸線的距離。

**Head—And—Shoulders Bottom（頭肩底）**：一種向上反轉的區域型態。參見「頭肩型態」（Head—and—Shoulders Pattern）。

**Head—And—Shoulders Consolidation（頭肩整理排列）**：一種區域型態，完成之後朝原先趨勢方向繼續發展。

**Head—And—Shoulders Top（頭肩頂）**：一種向下反轉的區域型態。參見「頭肩型態」（Head—and—Shoulders Pattern）。
