# 龜族系統停損的效益

由於龜族停損採用N為基準，會隨著行情價格波動程度而調整。行情波動愈劇烈，停損距離就自然放寬，但持有的契約口數也會相對減少。所有部位都採用等量的風險策略，更容易進行分散交易，風險管理也更健全。

# 第6章 出場

龜族採用突破為基準的獲利了結出場策略。

還有另一種說法，「獲利了結永遠不會讓你破產。」龜族不相信這種說法。過早結束獲利部位，換言之，太早獲利了結，這是順勢交易系統使用者最經常發生的嚴重錯誤。

價格不會呈現直線狀走勢；所以，如果我們想儘可能掌握趨勢，有時候就必須看著價格朝反向發展。剛建立部位的時候，這可能意味著我們必須看著既有的10～30%獲利轉盈為虧；處在中期階段，則80～100%的既有獲利可能縮水為30～40%。所以，交易者難免會遇到「鎖定既有獲利」的強烈誘惑。

在哪裡獲利了結，這個選擇可能是成敗的分野。

龜族是根據突破訊號進場。多數進場訊號並不能演變為明確的趨勢。換言之，龜族的多數交易最終都造成虧損。少數成功部位的獲利，如果不足以彌補多數失敗交易的虧損，最終結果將是賠錢。每套可行的交易系統，都有不同的最佳出場點。

讓我們稍微思考龜族系統；如果成功部位在1個N位置獲利了結，失敗部位在2個N位置認賠，這意味著成功交易的發生頻率，至少必須是失敗交易的兩倍，才不至於造成整體虧損。
