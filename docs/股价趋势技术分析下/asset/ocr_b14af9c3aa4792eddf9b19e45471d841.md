# 股價趨勢技術分析（下冊）

本上還是成立。編者附註：到了20世紀與21世紀的交接時期，很多人預測道瓊指數將上漲到36000點（我們不準備評估這種說法的可信度）。雖然股票市場具有長期上升趨勢，再配合市場近年來的發展（編者附註：1950年代與1960年代），我們還是可以合理假定未來的主要趨勢仍然處於下降狀態。事實上，過去幾年的多頭行情之中，許多重要股票都處於下降趨勢，例如：Celanesec、Kresge、Lorillard、Schenley與Studebaker-Packard。編者附註：比較1990年代多頭市場的情況，很多股票的2000年高價低於1990年，譬如：柯達、雅芳、全錄、通用汽車與IBM。
