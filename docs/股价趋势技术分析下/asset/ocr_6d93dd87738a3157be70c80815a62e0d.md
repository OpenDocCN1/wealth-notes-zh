# 第 7 版 序

100多年前，美國麻州春田市住著一個叫做查爾斯·道（Charles Dow）的人。他是一家偉大報紙的編輯：《春田共和報》(Springfield Republican)。離開春田之後，道氏又創立另一家偉大報紙：《華爾街日報》(The Wall Street Journal)。

查爾斯·道奠定了金融報業的基礎。

1884年，道氏利用11支重要股票的收盤價，建立股價指數，並開始做紀錄。這11種股票，包括9家鐵路公司。

道氏相信，股票價格走勢會反映投資大眾的判斷，所以也代表各種產業對於未來狀況的評估與看法。道氏把他的股價指數視為預測未來經濟狀況的工具。股票價格之所以具備預測功能，因為那些買賣股票的人，很多都各自熟悉多種產業的狀況。道氏認為，自由競爭市場內的證券價格，是取決於所有買賣該證券之市場參與者——包括：金融家、企業家、投資人、員工、客戶……等）——的綜合知識與判斷。
