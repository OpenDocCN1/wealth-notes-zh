# 第 22 章
圖形選股策略 II

繪圖挑選的股票，產業類別上應該儘量分散。各位並不是專心研究某特定產業，挑選的股票應該儘可能代表各種不同產業。所研究的股票，應該涵蓋礦業、石油、鐵路、化工、釀酒、娛樂、航空公司、公用事業……等。為什麼？不論哪種產業，多數股票通常都會有相同或類似的走勢型態，因為整個產業面臨相同的大環境。舉例來說，如果Allis—Chalmers（編者附註：或戴爾電腦）在一段急漲走勢之後，出現三角形排列，則Deere（編者附註：康柏電腦）、Minneapolis—Moline、Harvester與Case也會發生類似的急漲走勢，然後形成類似的三角形、矩形或其他整理排列。當Schenley處於長期下降趨勢，則Distillers—Seagrams、National Distillers、Publicker與American Distilling也會處在長期下降趨勢。編者附註：代表相同類型的名稱，就如同希臘神祇的名字。或者是尤里西斯與廖伯布盧（Ulysses and Leopold Bloom）。對於現代讀者來說，則是：英特爾、快捷（Fairchild）、國家半導體（National Semiconductor）或網康（3COM）。意思都是一樣的。
