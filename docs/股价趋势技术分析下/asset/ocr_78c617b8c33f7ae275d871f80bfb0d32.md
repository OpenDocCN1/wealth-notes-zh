因為下列原因，未平倉量分析顯得更複雜：季節性因素（作物收成期間的避險活動最活躍）；投機性意圖；契約是否屬於最近交割月份契約（最好觀察所有交割月份契約的未平倉總量，而不是個別月份契約的未平倉量）；相關市場；相同市場價差交易。

下列表格說明未平倉量與成交量之間的關係：

| 未平倉量與成交量之間的關係 | | | |
|---|---|---|---|
| 價格行為 | 未平倉量 | 資金投入 | 行情 |
| 1. | 漲 | 上升 | 增 | 強 |
| 2. | 漲 | 下降 | 減 | 弱 |
| 3. | 跌 | 上升 | 增 | 強 |
| 4. | 跌 | 下降 | 減 | 弱 |

價格上漲而未平倉量上升，代表新資金流入市場。賣方提高價格，買方願意接受（買、賣雙方的數量永遠對等）。這是行情偏多的狀況。

價格上漲而未平倉量下降，意味著新的買盤減少，資金流出市場。價格上漲的動力，可能來自於空頭回補。空頭回補在短期內雖然有助於價格上漲，但這類交易一旦告一段落，漲勢將無以為繼。總之，任何漲勢如果沒有新資金襯托，就不能持久；可是，空頭回補的時間也可能拖得很長。

價格下跌而未平倉量上升，意味著新資金投入市場，但代表的是賣壓，屬於空頭現象。

價格下跌而未平倉量下降，這與第2種狀況相反。空方持續留在市場內，多方逐漸離場。市場沒有新資金流入，短期偏空而長期偏多。當下降動能減緩之後，空頭很快就會回補，新資金也經常會回頭。
