交易規模是風險控制的基本單位。不論價格波動率如何，任何股票的500股風險必大於100股。

接著說明如何決定交易規模。首先，計算進場價格與停損價位之間的差值，這稱為「風險金額1」（$1）。取「風險控制因子」（也就是投入某筆交易之資金佔總資本的百分率）乘以「總資本」，結果是每筆交易承擔風險（Risk—per—Trade）。舉例來說，3%乘以總資本（TC）$100,000。前述結果除以「風險金額1」，便可以決定交易規模。

```
EP-SP=$R1
RCF×TC=RpT
$R1/RpT=TS
```

+   其中
TS=交易規模
EP=進場價格
SP=停損價位
$R1=風險金額1
RCF=風險控制因子
TC=總資本
RpT=每筆交易承擔風險

每天都衡量上述操作風險。把操作風險除以總資本，結果是投資組合操作風險因子。這個因子的讀數如果太高，就需要考慮避險或調整部位，刪除一些績效表現最差的部位。
