逐次停止單的使用時機，是當股價已經夾著大量到達合理目標區，或者已經完成目標價位而朝有利方向脫離趨勢通道，但也可以運用於價格不能到達目標區的股票。

舉例來說，股價處於上升趨勢通道，夾在上升趨勢線與平行折返線之間。突然之間，爆出很大的成交量。這種情況下，可以利用逐次停止單保護部位，防範發生失敗走勢。如果走勢沒有突破先前小型高點而爆出大量，絕對代表警訊與威脅，尤其是當天又發生跳空缺口或單日反轉。

有一種情況，當成交量突然放大時，不需調緊停止點：如果價格向上突破先前的峰值位，而且收盤價創新高。這種盤勢，通常意味著漲勢尚未結束。可是，走勢繼續發展的過程內，如果再發生大成交量，就必須調緊停止點，即使是在突破小型高點的隔天也是如此。

如同本書其他場合的用法一樣，所謂「大成交量」是相對於最近平均成交量而言。交投冷清的股票，1,000股也可能代表大量，至於交投熱絡的股票，10,000股可能還處於正常範圍。我們很容易由成交量走勢圖，察覺不尋常的大量。

請注意，前述逐次停止單是用來結束短線獲利部位，或在中期飆漲走勢的高潮階段結束部位。適用這類操作的極端狀況，雖然稱不上罕見，但也不至於經常發生。當走勢出現小型頭部，即使在趨勢通道內呈現明顯的突兀成交量或其他技術現象，許多交易者或投資人或許還是願意接受預期中的向下修正，不希望支付來回佣金而暫時脫離有利的主要趨勢。

總之，逐次停止單是一種工具，有時候非常適用，但通常只用來處理特殊、不尋常的狀況。

另一方面，保護性停損單普遍適用於一般交易者，如果沒有充分的時間隨時注意盤面發展，或沒有足夠的經驗，就可以透過這種工具侷限損失。這種工具可以迫使交易者結束不利部位，避免讓自己套在毫無指望的部位上，無奈地看著虧損持續累積。只要停損遭到引發，部位就會自動結束，如此可以保留足夠的資金從事其他交易，不需繼續擔心或指望已經泡湯的部位。

可是，如果具備足夠的知識與經驗，能夠判斷出場訊號，而且能夠判斷採取行動，就沒有必要實際遁入停止單。編者附註：編者個人認為，唯有真正的好手，才可以不用停止單而留在場內。讀者如果要知道自己是否屬於「真正的好手」，不妨檢驗自己的股票組合，看看是否曾經讓不必要的虧損持續擴大？是否曾經因為過早賣出而錯失重大獲利？若是如此，各位就還稱不上「真正的好手」。假定具備前述條件，停止單可能反而會造成妨礙，因為停止價位可能被假走勢或延伸性洗悶折返走勢引發。另外，對於長期部位來說，交易者或許願意接受次級折返走勢，停止單當然也不適用於這種情況。可是，對於一般投資或交易大眾而言，通常還是應該採用停止單，避免在60買進，然後看著價格一路下跌到29，或50以下。

## 隨後三天法則

本章並不打算談論主要或中期趨勢的頭部／底部，而是處理小型趨勢的頭部／底部。小型頭部或底部，可以做為許多技術運用的基準，能夠用以決定停損點、趨勢線、目標價位與支撐／壓力，這些都是交易者必須留意的重要關卡。

一般來說，小型頭部／底部的位置很清楚、很明確，但偶爾還是會碰到模稜兩可的情況。雖說如此，我們還是可以設定一些運作上的判斷準則，而且這些準則失敗的機會不大。

關於多頭部位的停止單基準點，可以採用一種不錯的原則來判定最近的底部：當可能的低點發生之後，如果隨後三天的價格都高於該低點線形的最高價，則該低點將視為最近的底部。舉例來說，上升趨勢出現連續幾天的折返，某天曾經創低價 24，當天高價為 25。這種情況下，如果隨後三天的盤中價格都不曾低於 25 1/8，則 24 視為最近底部。隨後三天的整個價格區間，必須完全高於底部發生當天的線形（譯按：三天不必連續）。這就是所謂的「隨後三天法則」。相同的觀念也可以用來判定先前的頭部；換言之，隨後三天整個價格區間，必須低於頭部當天的線形。

這個法則可以用來設定最初的停損點，也可以用來調整後續的停止點。一旦隨後三天走勢決定底部之後，就可以把停止單移到最近的底部下側（第 27 章已經解釋如何根據最近底部為基準點而設定停止點）。

多頭部位的保護停止價位只可以向上調整；換言之，停止點設定之後，除非股票除息或除權（需要根據現金股利或權值向下調整），否則就不得朝相反方向調整。同理，空頭部位的保護性停止點，只可以調降而不能調升。（如果發生除息或除權的狀況，空頭部位停止點應該調降。）

某些情況下，很難判斷頭部或底部的位置；盤勢似乎出現整理或修正，但價格並沒有明顯朝次級趨勢方向發展。這種情況下（相對於一系列明顯的向上或向下波動），就必須仰賴個人的經驗與判斷，決定基準點位置。

## 基準點

我們把設定停損的頭部或底部，稱為「基準點」（basing points）。多頭行情中，每個小型折返底部都視為基準點，只要符合「隨後三天法則」，就可以利用該基準點來設定停止單。我們也利用多頭行情的每個小型頭部做為基準點。同理，空頭行情中，每個漲勢頭部與每個小型底部，也都是設定停止單的基準點。

如果股價顯著主要趨勢方向發生一段重大走勢（譬如15％），然後股價折返先前走勢幅度的40%，只要股價再朝主要趨勢方向發展，折返走勢的端點，當然是基準點。可是，如果折返走勢的幅度小於40%，甚至是在先前順勢端點附近盤整幾個星期，然後又朝主要趨勢方向發展，則折返走勢的端點，也是基準點（當然還需要成交量配合）。

每天的成交量，就像醫生手中的體溫計一樣：成交量所蘊含的內容，遠超過價格本身透露的表面徵兆。三種情況下，我們可能發現不尋常的大量：
- （1）價格突破型態的當天，尤其是向上突破；
- （2）走勢朝主要或次要趨勢方向創新的極端價位，換言之，價格在多頭市場向上穿越前一個小型頭部，或在空頭市場向下穿越前一個小型底部；
- （3）當小型走勢完成或即將完成的時候，換言之，多頭市場的小型頭部附近，或空頭市場的小型底部附近。

除了前述三種情況，凡是順著主要趨勢方向發展的走勢，如果爆出大量，就代表該走勢告一段落了，不能完成預期中的漲勢或跌勢。

股價一旦穿越先前的小型頭部，則進入創新高的領域，這時候如果爆出大量，股價通常會拉回整理。一般來說，會出現幾天或一個星期以上的跌勢。可是，所謂的整理，也可能是好幾個星期的橫向盤整，股價沒有明顯下跌。如果股價向下修正，可能會逼進或跌到前一個小型峰位（支撐）。另外，修正走勢也可能帶動價格回到基本趨勢線（銜接先前兩個或多個小型底部的直線），或是平行折返線（銜接先前兩個或多個小型峰位的直線）。如果修正走勢採取橫向盤整的方式，很可能會止於前述的兩類趨勢線之一。

不論修正走勢如何發展，觀察重點都在於「成交量萎縮」。新的頭部發生之後幾天內，不論價格折返或停頓，如果成交量萎縮（允許不規則發展，但整體而言必須有縮小的趨勢），則可以合理判定這是小型修正走勢。接著，如果股票繼續朝主要趨勢方向發展，而且符合「隨後三天法則」，就可以將該底部視為新的基準點（如果修正走勢採取橫向整理的方式，可以採用繪製趨勢線穿越的點，不一定要採用極端點）。

如果股價先出現一段橫向波動，然後進行突破，並展開新的漲勢；這種情況下，我們經常很難判斷最近底部位在何處。突破之前，可能出現好幾波不重要的走勢，成交量很小。若是如此，我們將以大量為突破訊號，並將訊號發生之前的最近期低點，視為基準點。

前述有關多頭市場基準點的種種評論，也同樣適用於空頭市場，但向下突破不一定伴隨大量。

還有一種非常棘手的情況，假定股價經過一段直線狀飆漲走勢，然後出現顯然是旗形排列的折返。當折返走勢超過前一段漲幅的40%時，我們在成交量縮小的情況下進場買進，結果股價繼續下跌，沒有任何反彈或成交量放大的微兆。這是很不尋常的發展，但不論在漲勢或跌勢中偶爾還是會發生。面對這種情況，必須在日前價位之下尋找支撐，合理的支撐應該位在前一波下跌走勢過程（整理型態、多重的頭部或其他）。我們應該利用這些支撐做為設定停損的基準點，而不是垂直狀漲勢的極端低點。

關於前述情況，往往很難找到支撐力道夠強勁的基準點。所以，長期飆漲走勢發生整理時，通常不該進場買進，除非
- （1）股價下檔存在強勁支撐，可以做為設定停損的基準點；
- （2）股價創數年來的新高價，處在「海闊天空」的領域。

主要下降趨勢的空頭部位當然相反：上檔存在強勁的壓力，或股價創最近幾個月以來的新低價。總之，當股價出現延伸性快速、直線狀走勢，如果打算在隨後的整理走勢中進場，這些旗形或三角旗形排列務必要有成交量顯著萎縮的現象。

關於中期趨勢之內的短線交易，我們還希望提出一些警告。構成中期趨勢的小型波動，發展或許非常有規律；其中可能有明顯的趨勢線；小型折返幅度可能是前一波小型漲勢的40%或50%，價格可能拉回到先前的小型頭部。修正走勢過程的成交量可能萎縮。我們或許很容易在這些階梯狀走勢進行交易，預期後續走勢還會繼續先前的規律。可是，趨勢不可能永遠發展下去。任何小型頭部都可能是中期頭部。基準點的功能，是讓我們得以及時脫身：最好的情況下，當收盤價跌破基準點就應該出場；最糟糕情況下，所設定的保護性停止單會被引發。什麼時候應該結束中期趨勢之內的短線交易呢？成交量可以提供一些幫助。雖然頭部都會發生大量，但我們所關心的是遠超過先前任何小型頭部（或空頭市場小型底部）成交量的大量。趨勢內最後一個或倒數第二個頭部，通常都會出現爆發性「天量」，如果見到這類高潮狀的大量，就應該準備退場觀望，股價很可能會大波段的中期折返。幾個星期或幾個月之後，我們可能發現股價修正幅度高達前一波中期整體漲勢的40%或以上，而且成交量又萎縮到窒息程度。這個時候，我們可以嘗試尋找主要趨勢方向的交易機會。

# 第 28-A 章
基準點：個案分析

對於看起來不甚起眼的圖 210，愈加思考，愈覺得其中蘊含著趨勢與市場的振動。想想那些漲勢、跌勢、漲勢、跌勢……等循環。交易者或投資人只要不要在修正走勢中追價，正常情況下，都可以隨著趨勢發展到末端。可是，對於場內交易員、避險基金或那些試圖藉由價格波動獲利的人，非常瞭解一般投資人與交易者會把停止點設定在先前低點的稍下方。在正常交易情況下，如果這些人認為有必要引發大眾的停止單，他們就會這麼做。而且，有時候也是可能辦到的。所以，先前低點往往會因此而被貫穿。

傑克·史瓦格在《金融怪傑》（中文版，請參閱寰宇出版公司）一書訪問布魯斯·考夫納（Bruce Kovner），請教他如何設定停止點。他回答：「在他們很難動手腳的地方。」根據基準點與適當的濾網設定停止單，造市者與專業報價商很難動手腳；換言之，這些停止單一旦被引發，通常代表趨勢發生變動了。

所謂的基準點，就是標示先前的高點（峰位）與低點（谷底），而且充分瞭解多頭趨勢是由一系列不斷墊高的峰位與谷底構成。峰位與谷底一旦持續下滑，就代表趨勢正在或已經改變。這就是道氏理論的精義所在，也是針對更短期趨勢進行交易所根據的原則。當市場出現持續下滑的峰位與谷底，則趨勢線最終難免被跌破。

關於圖210，馬克吐溫提出一段精闢的評論。他說，任何想要搞清楚其中道理的人都會瘋掉，任何想要根據圖形來解讀價格的人，都會被槍斃。圖210保持一些無法解釋的謎題與衝突。讀者應該由觀念角度切入，不要將此視為某種課題。然後，請參考圖210.1。讓我把一些隱含的法則整理出來：

- 1. 價格創峰位，意味著當時沒有更高的價格。
- 2. 價格回檔而見底。這個谷底是先前峰位以來所出現的最低價格。當價格又開始回升時，留意整天價格完全高於谷底線形的天數。
- 3. 這類走勢一旦出現三次，先前谷底就成為基準點，多頭部位的停止點就可以向上調升到基準點下側的6%（或x%）處（參考第27章）。
- 4. 如果新高價較先前峰位高出3%，則該天低點成為新的基準點。

## 基準點範例

這種分析未必適用於每種情況。可是，這種方法畢竟具備典範的性質，值得做進一步研究。任何圖形分析技巧，使用上都必須謹慎，尤其要充分發揮判斷力，目前這種方法當然也不例外。某些情況下，這種方法非常適用於某些股票，但另一些股票則完全不適用。可是，即使是對於最不受規範的股票，這種方法的根本原則還是值得參考的，雖然方法本身並不適用。在這些前提之下，讓我們來看看圖 210.1。讀者或許會發現，這個例子只採用谷底設定停止點，並沒有像圖210一樣，在價格創新高的時候向上調整停止點。此處之所以這麼做，只是為了說明單純起見，方便一般投資人使用。對於程度比較高的玩家，則可以研究或採用圖210的技巧。

圖210.1實際上不只適用於講解。這是一個相當完整的案例，闡述基準點的運用，而且也說明多頭行情的完整分析，由進場到出場，整個市場週期的重要位置都做標示與註解。換言之，這個例子涵蓋了基準點、設定停止點、追蹤可能的假走勢……等。這份走勢圖所做的標示與註解，最初是運用做為金門大學研究所的教材。後來，我發現這份圖形對於實際交易也很有用。所以，讀者不妨嘗試與這份圖形做溝通，體會其用途。

## 走勢圖事件說明

- 1, 2, 3. 整個走勢如果讓我們昏昏欲睡的話，# 3應該會讓睜亮眼睛。這種程度的成交量很醒目，我們開始注意這支股票，也察覺先前醞釀的型態：圓形底或連續弧狀底部。
- 4. 這裡看到夾著大量的逃逸線形。價格突破# 2的水平線，代表很好的進場訊號。進場之後，停損設定在最近低點下側5%處。趁著強勢進場，很可能會遇到獲利回吐的賣壓，場內交易員也可能會驅逐一些意志不堅的機會主義者。
- 5. 開始出現修正走勢。每天觀察行情的發展，尋找可能的「基準點」（BP）。這發生在# 5，於是開始計算線形區間完全位在潛在基準點線形之上的天數。當# 5 確認為基準點之後，把停損點往上調整到# 5低價下側5%處。
- 6. # 5之後價格創新高，然後回檔到# 6，後者成為基準點。把停止點調高到# 6下側5%處。
- 7. 價格繼續攀升，# 7出現另一個基準點。整個程序很單純：尋找基準點，然後在基準點下側適當距離設定停止點。留意反向的修正走勢：或允許我們建立較高的基準點，或引發稍早設定的停止單。
