# 股價趨勢技術分析（下冊）

旗形經常發生在這類走勢的中央，也就是所謂「旗形飄揚在旗桿中央」。投機性漲勢如果出現旗形整理，當價格向上突破旗形排列之後，通常至少會複製一段先前的漲勢。第二段漲勢之後，可能出現另一個旗形整理，並繼續上漲。當然也可能不會。經過兩波段的這類走勢之後，最好退場，剩下的錢讓別人賺。只要觀察足夠多的走勢圖，涵蓋足夠長的期間，將發現很多這類完美的排列。當然也有一些失敗的例子。可是，由於成功案例蘊含的獲利可觀，所以每當飆漲走勢之後出現整理排列，我們往往就會忍不住進場。這類情況必須有嚴格條件配合：先前出現令人難以置信的直線狀漲勢，隨後出現成交量很低的狹幅盤整。如果狹幅整理或回檔整理超過3個星期，最好賣掉股票；這很可能屬於失敗案例。

前述情況當然也會發生在急跌走勢，交易上也可以「如法炮製」。第12章曾經深入討論跳空缺口的衡量意涵。逃逸缺口（連續缺口）是唯一具有預測意義的跳空缺缺口。這類缺口發生在快速走勢過程，大約可以代表整段走勢的中點位置；如果發生兩個或以上的逃逸缺口，需要根據成交量與先前走勢幅度來評估可能的中點位置，然後衡量可能的目標價位。

其他一些型態也具有衡量目標價位的功能，精確程度則各自有別。可是，整體來說，衡量目標價位的最理想工具，是趨勢線、支撐／壓力，以及重要的成交量訊號。

第9版附註：關於目標衡量，我的態度始終很謹慎。如果衡量目標不至於讓交易者沈迷於預期，並因此而忽略實際走勢透露的訊息，那就沒有關係。所以，做為一種簡單的參考工具，衡量目標確實有些用途。當價格抵達衡量目標時，永遠要觀察當時的實際情況。唯有這個時候、在這裡才可以擬定決策，而不是在先前衡量目標的時候。
