# 股價趨勢技術分析(下冊)

讀者或許應該重復閱讀前一段內容，這意味著我們並不嘗試在多頭市場「賣在最高價」，也不試圖在空頭市場「買在最低價」。我們不會故意逆勢而為，因為根據歷史資料顯示，主要趨勢通常會持續很長一段期間。

此處所強調的立場，與前幾版內容並沒有太大差別。請注意，我們並沒有說投資人絕對不可以在多頭市場放空股票，也沒有說不能在空頭市場做多股票。確實有很多股票的走勢，是逆著主要趨勢發展，就這些股票的技術面結構來說，或許有理由逆著大盤的趨勢進行操作。

可是，我們覺得，這類交易必須非常謹慎，投資人必須充分了解，絕大部分股票是呈現相反趨勢。舉例來說，我們可以針對部分個股的技術型態，建立逆勢部位，並以此做為整體交易組合的避險。假定多頭行情已經持續數年之久，而且推定繼續有效，但某些個股出現明顯的空頭走勢。對於這種情況，交易者或許可以繼續持有四分之三的多頭部位，但把剩餘的四分之一資金用來放空疲弱的個股。如果多頭行情持續發展，這些空頭部位或許必須認賠，但這部分虧損可以視為合理的避險成本。另一方面，如果整體大盤走勢轉弱，最後演變為主要趨勢反轉，則空頭部位的獲利，可以彌補反轉訊號發生之前的多頭部位損失。（第9版附註：這是編者主張的「自然避險」理論。現代股票市場的結構相當複雜，風險部位與避險部位實際上都可能同時獲利，這也是交易者希望達成的目標。）

除了大盤指數之外，如果還採用評估指數（Evaluation Index，參考第38章），則可能認定市場的多頭成分為60%或55%，而不是單純的兩分法。這可以反映一項事實：各種行情具備的多、空氣勢各自不同，投資人應該自行調整多、空組合，不需採用「黑白分明」的立場。（第9版附註：我稱此為「韻律交易」，Rhythmic Trading。）
