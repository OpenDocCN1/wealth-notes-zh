# 股價趨勢, 技術分析 (下冊)

要瞭解放空的意義。放空股票時，是向其他持有人借取股票，然後賣出，並承諾在未來某時間歸還股票。當然，這方面的交易細節，都是由經紀人處理。一般來說，大型股隨時都有股票可供出借，經紀人很容易取得這些股票。放空股票的整個程序相當有趣，可以請經紀人詳細解釋。可是，就實務上來說，交易者只需要告訴經紀人，想要放空什麼股票，其他一切都可以讓經紀人處理。

萬一交易者挑選的股票不能放空，經紀人也會告知。另外，放空股票需要承擔額外的稅金，但這不會構成重大影響。編者附註：放空股票賺取的資本利得，不適用長期資本利得稅。

就交易者的立場來說，應該以同樣態度處理買進與放空機會。不幸地，放空股票往往存在某種心理障礙。舉例來說，「放空美國」(selling American short) 就是一種情緒化而全然無關的口號。另外，很多人都覺得，放空股票是一種不道德的行為，屬於市場炒作者的下流勾當。另一些人認為，放空股票是把自己的快樂，建立在別人的痛苦上。本書並不特別鼓勵放空股票，但交易者如果打算買進投機性股票，也應該基於相同心態準備放空股票。可是，即使是相當有經驗的投資人，也经常質疑放空股票的道德問題與實務上的相關程序，所以我們覺得有必要提出一些辯解。

前述有關放空股票的種種看法，都可以歸納為「無稽之談」。放空股票的「罪過」，絕對不大於做多股票。兩者都是針對相對價值進行投機。事實上，鈔票也是一種商品，就如同股票一樣。借鈔票買股票，是因為我們相信股票的未来價值將相對高於鈔票；同樣地，借股票買鈔票，是因為我們相信股票的未來價值相對低於鈔票。前述兩種行為，不應該由不同的道德標準來衡量。不論哪種行為，投機客都必須根據自己對於未來相對價值趨勢的預測而承擔風險。不論哪種行
