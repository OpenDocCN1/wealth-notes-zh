# 股價趨勢技術分析(下冊)

Volume（成交量）：某特定時段內，股票或商品契約的交易數量（股數或口數）。

"W" Formation（W狀排列）：參見「三重頂」(Triple Top)。

Wedge（楔形）：一種區域型態，排列上限與下限相互收斂，而且朝相同方向傾斜。

Wilder Relative Strength Indicator（RSI）（相對強弱指數）：雖然這類比較個別證券價格與大盤指數之間相對表現的技術指標已經存在一段期間，但目前這個指標是由威爾斯·韋達（J. Welles Wilder）設計，最初發表於1987年的著述《技術交易新概念》（New Concepts in Technical Trading）。

RSI經常可以根據其讀數來判斷行情頭部與底部（RSI讀數介於0～100，通常分別採用70與30來界定超買與超賣）。RSI也適用於：

+   1. 凸顯價格走勢圖不容易呈現的資訊。

+   2. 超買（70以上）或超賣（30以下）區域內的擺動失敗（swing failures），代表趨勢反轉的警訊。

+   3. 更清楚顯示支撐／壓力。

+   4. 價格與RSI之間的背離現象，經常是判斷趨勢反轉的有用指標。

RSI需要一些領先時間才能成功運作。
