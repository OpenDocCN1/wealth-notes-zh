# 摘要結論

長期投資人試圖掌握主要的行情走勢，也就是道瓊指數上漲數百點、甚至上千點的行情，持續時間可能長達好幾個月或好幾年。

在這種時間架構上，長期投資人會針對次級走勢做出反應。至於反應的對策，則取決於投資人的性向，他可以針對次級修正走勢進行
