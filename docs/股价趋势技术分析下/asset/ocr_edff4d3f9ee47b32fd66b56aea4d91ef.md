# 第43章 堅持信念

身為投機客，各位的功能是提供市場流動性，嘗試阻止市場非理性的過度行爲。爲了達成這項功能，一方面必須保持自己資金的流動性，以便在必要情況下反轉部位。另一方面，各位也必須排除自己的非理性或情緒化行爲。如果能夠明智而穩定的完成這些工作，將可以爲整體經濟福利貢獻一份心力，而且市場對於各位的貢獻也會提供對等或更高的報酬做爲答謝。

第9版附註：但願讀者能夠在本書第9版得到一些可以堅持的新東西：龜族交易手冊（羅伯·考貝[Robert Colby]整理出股票方面的運用）；有關基準點的新教材，顯示更強化的功能；由新的角度分析道氏理論，進一步證明這套理論的有效性，而且不只適用於長期投資。最後，祝各位交易順利，堅持信念。
