# # 第20章
## 挑選適當的股票：投機客觀點

我們希望登錄的股票圖形種類很單純，數量也不多。我們要的是那些價格區間夠大，足以交易獲利的股票。換言之，價格走勢夠大而值得進行交易的股票。某些投資人主要關心本金的安全，以及收益的穩定性。有些股票確實符合這種條件。你可以（實際上或許也會）保留一部份資金購買這類股票。它們的價格區間很窄，具有強勁的抗跌能力，但跟隨大盤上漲的能力也（必然）相對有限。這類股票非常適合保守型投資人。可是，它們不適合於股票操作，因為價格擺動幅度太小，佣金成本將抵銷絕大部分交易獲利。另外，相對於投機性股票來說，它們缺乏明確而清楚的價格型態，通常會呈現圓弧狀緩慢走勢。（第9版附註：這段評論所反映的時代已經過去了。就像遠古時代的恐龍，這類股票大體上已經絕跡了。保守型股票在市場上已經沒有容身之地，除了債券之外，如果股價不動如山，將會因為通貨膨脹或美元貶值而喪失真實價值。即使是債券，也經常要用本書討論的工具重新評估價值。）
