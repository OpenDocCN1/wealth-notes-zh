# 附錄E

第9版附註：柯蒂斯·費司（Curtis Faith）是里查·丹尼斯（Richard Dennis）最初訓練的「龜族」（Turtle）成員，他非常慷慨地編寫了一份龜族的期貨市場交易系統。這份文件可以在orginalturtles.org找到，可以算是現代一般交易的主要模型。我個人擁有一些交易系統與程序的手冊。這些文件的主要目的與功能都很類似。我認為，費司的龜族手冊可能是其中最棒者之一，而且也是我最認同的。

我個人非常認同這份文件，主要是因為我偏好「自然」系統，而不是「數值導向」的系統。圖形判讀很自然地反映市場事實，就像手掌與手套很自然地結合在一起。高價／低價系統就像龜族系統，也像道氏理論根據市場韻律的自行調整。而且也像所有的機械化系統一樣，有其優點與缺點。機械化系統的最大缺點，就像真正的機械一樣，如果市場韻律與交易系統之間不能協調，就會讓交易資本像是進了絞肉機的牛排。慘不忍睹的血腥風雨。尤其是你自己養的牛被絞
