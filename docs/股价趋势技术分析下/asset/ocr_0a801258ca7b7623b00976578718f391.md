# 第 20 章  挑選適當的股票：投機客觀點

你之所以放空股票，是因為你基於某些理由認為該公司股價將下跌。

就技術交易角度來說，我們希望挑選投機性股票，股價在多頭行情內將大幅向上擺動，在空頭行情內則向下大幅擺動。適合投資的穩定性股票，通常不適合交易。某些範圍條件內（隨後將討論），股票的投機性愈強，愈適合交易需要。

機會與安全的比較。右圖是固特異優先股走勢圖，該股票每年都可以取得 $ 5.00股利，但沒有權利參與其他獲利的分派。左圖是固特異普通股走勢圖，可以取得公司清償優先債務之後的所有獲利。這兩份半對數月線圖涵蓋相同的54個月期間，普通股漲幅高達300%，優先股漲幅只有25%，由於後者的每股獲利最多只有 $ 5.00，股價只能上漲到投資人所願意接受的最低殖利率水準。
