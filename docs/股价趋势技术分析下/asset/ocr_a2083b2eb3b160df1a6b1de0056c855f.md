# 圖形的其他紀錄

圖形還需要註明很多其他事項。我們已經說明，如何在圖形上登錄各種可能交易機會與理論性模擬資料：何時買進、何時賣出、持有時間，以及扣除佣金、股利之後的淨盈虧。另外，還必須記錄實際買進與賣出的價位、股數、帳號（如果不只一個帳戶的話）與其他資料。這些資料可以登錄在圖形上側，多頭部位採用藍筆記錄，空頭部位採用紅筆，註明部位建立到結束的期間。

圖形換頁登錄時，重新謄寫尚未結束的理論或實際部位，以及相關停損。另外，所有圖形紙都應該在左上角標示序號（A、B、C……等），如此才方便於歸檔。

價格軸上，分別利用一個藍點與紅點標示前一張圖形的最高收盤價與最低收盤價。這是兩個重要的參考水準，如果價格隨後穿越其中某個價位，很可能会繼續朝該方向發展。另外，這兩個價位也讓我們知道先前52個星期的價格區間，藉以評估股價的發展速度，以及股票在相關期間內的敏感性指數（sensitivity index），後者是決定「綜合槓桿比率」（composite leverage ratio）的因子之一。

圖形的涵蓋期間愈長，參考價值愈高。圖形組合不要隨意更動，唯有必要情況下，才可以逐漸增添或刪除圖形。開始繪製一支新股票的時候，註明「新圖形」，將來才不會浪費時間尋找更早期的圖形。另外，新圖形涵蓋幾個星期或幾個月的資料之後，才有參考價值，如果想要在某支股票上建立部位，但當時沒有繪製圖形，需要回顧至少3個月的價格與成交量資料，然後繪製相關圖形。

编者附註：目前，相關資料也可以透過網路取得，沒有必要保存幾年的《華爾街日報》。
