# 過度交易與矛盾現象

這引發另一個問題。固定百分率的盈與虧，並不代表兩者的金額相等而可以彼此抵銷。這是很值得推敲的嚴肅問題，尤其是那些讓自己過度緊繃的交易者，這方面問題的影響更嚴重（問題雖然都存在，但如果懂得如何規劃，倒也不用太擔心）。

讓我們探討這個矛盾陳述：相同百分率的盈與虧並不相等。首先，考慮最極端的情況。某個人不論從事什麼投資，都投入全部資本，期待100%的盈或虧。如果第一次投資發生虧損，他將耗盡全部資本。若是如此，他就結束了，因為他既然已經兩手空空，就不能無中生有。反之，假定第一次投資成功，他會連本帶利地做第二次投資。如果第二次投資失敗，他也會被一筆勾消。所以，不論曾經成功多少次，只要一次失敗，就徹底失敗。編者附註：這是「賭徒毀滅心態」的問題，很多作者曾經做這方面的分析，包括倪德厚夫（Niederhoffer）的精彩說明在內（請參考附錄D的相關討論）。（倪德厚夫的相關著作《投機客養成教育》及《倪德厚夫的投機術》請參閱寰宇出版公司）。

我們想要討論的情況，可能比較沒有那麼極端。換言之，投資人不會讓全部資本承擔風險而期待「變成兩倍或完全沒有」。可是，我們仍然假定投資人相當具有冒險精神，每筆交易都願意承擔40%虧損，藉以換取40%獲利的機會。假定起始資本為$1000，連續發生10次虧損之後，資本只剩下$6（譯按：$0.6^{10}=0.00605$）。現在，假定隨後的10筆交易都很成功。結果會如何呢？經過10次成功與10次失敗之後，每次的盈或虧都是40%，剩餘的總資本將不超過$100。請注意，10次成功與10次失敗的發生順序並不重要，結果都一樣。換言之，投資人可能先遇到10次成功，也可能先是3次成功，然後4次失
