# 摘要結論

+   電腦是非常重要的分析工具，具備下列功能：

● 資料可以由網際網路或接撥站自動下載，成本低廉或完全免費。有些甚至提供即時資料，這可以讓一些沒有經驗的交易者很快破產；可是，對於一般投資大衆來說，在其進行交易的當天，通常都希望取得這些資料。這些網站提供的分析範圍很廣，包括正統的技術分析（通常太過複雜）。

● 電腦套裝軟體與網際網路投資組合網站，通常都能讓分析者輕鬆的管理投資組合帳戶，每天都按照市價試算組合價值，如此可以讓投資人避免搞混「現金」與「應計」會計。

● 電腦讓分析者可以處理一些過去難以想像的工作。分析者所能夠處理的股票數量，在電腦協助之下，幾乎已經不受限制。至於如何透過電腦挑選交易對象，請參考第20章與第21章。

○ 本書附錄D提供一些有關電腦套裝軟體的資料，這些軟體的價格相當合理。大體上來說，即使是價格最便宜的軟體，其功能也足夠一般投資人運用。另外，我選簡單討論一些網站與資料來源。
