隨機指標原始數值 = $ \dfrac{\text{最近收盤價} - \text{20天期最低價}}{\text{20期最高價} - \text{20期最低價}} $

%K是原始數值的3天移動平均

%D是%K的3天移動平均

# 隨機指標資料更新公式

%K更新數值 = 2/3先前的%K數值 + 1/3新的原始讀數

%D更新數值 = 2/3先前的%D數值 + 1/3%K

原始數值需要有20天的資料；20天期最高價，是指最近20天之內的最高盤中價格，20天期最低價，是指最近20天之內的最低盤中價格。

隨機指數有助於分析商品交易的趨勢變動。這項指標已經有30多年的歷史，運用績效有長期紀錄可供查核。雖說如此，但如同絕大多數分析系統一樣，隨機指標在實際運用上，還是應該配合圖形分析與普通常識。請注意，我們的交易對象是商品價格，不是隨機指標或其他技術指標。技術指標雖然能夠提供幫助，但這些指標永遠要擺在市場架構上觀察。

# 成交量與未平倉量

投資人總希望看到「價漲量增，價跌量縮」的現象。對於股票交易，成交量是衡量人氣的重要指標。成交量也是期貨交易的重要指標，不過性質不太一樣。
