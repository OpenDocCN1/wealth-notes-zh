# # 第2章 市場：龜族的交易對象

龜族的交易對象包括芝加哥與紐約之美國集中市場掛牌交易的高流動性期貨。

龜族都是期貨交易者，過去習慣稱之為商品交易者。我們從事美國商品交易所提供的最常見期貨契約。

由於我們的交易金額很大，所以不會選取那些每天成交量只有幾百口契約的市場，否則我們下單的數量會嚴重影響行情，必須花費大量額外成本才能建立或結束部位。龜族只介入流動性最高的市場。
