# 股價趨勢技術分析（下冊）

![](bbox=[0.2, 0.11, 0.9, 0.37])

圖221. 菱形排列。這份日線圖涵蓋1946年12月到1947年5月之間的走勢。首先，讓我們提供一些背景資料，AC在1945年10月創多頭市場峰位112。在多頭市場，高價續優股經常領先出現頭部，我們稍早已經提到這種現象。股價在第一波回檔大約跌到90附近，然後反彈到106左右。接著，股價一度跌破80，第二波反彈即是目前這份走勢圖顯示的情況。根據走勢圖觀察，股價有逐漸形成圓形頭頸部的味道，這是因為高價續優股通常不會出現大幅百分率的走勢。如果我們把價格刻度放大，整個排列就會顯示投機股的韻味。

型態的第一部份類似「擴張頂」。第一個小型峰位在96，折返到92。第二個峰位稍高在98，折返到91 ¼；第三波漲勢將股價推升到99。截至目前為止，我們已經有擴張頂的5個反轉點，只要價格跌破91 ¼，就可以確認這個空頭排列完成。可是，接下來的跌勢，並沒有跌破91 ¼，隨後幾個星期的價格波動震幅愈來愈小，呈現等腰三角形的排列。

最後，股價明確跌破89，這是多頭部位出場訊號，也可以考慮在次一個反彈過程建立空頭部位。事實上，隨後3個星期的反彈過程，股價再也沒有回升到等腰三角形頂點（94）之上。

雖然完成菱形排列，但股價並沒有出現嚴重跌勢，這是很容易理解的現象，因為先前的跌幅已經很大，整個大盤的氣勢還很強，而且這是一支續優的保守型股票。可是，價格也沒有回到94；事實上，隨後逐漸盤跌到80。

就菱形排列的一般性質來說，這是一種不常見的排列，有些類似於頸線稍微呈現V狀轉折的複雜頭肩型態。排列前半部類似擴張頂，後半部則類似等腰三角形。
