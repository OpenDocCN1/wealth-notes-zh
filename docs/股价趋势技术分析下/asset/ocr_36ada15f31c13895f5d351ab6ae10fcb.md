# 股價趨勢技術分析（下冊）

**Five—Point Reversal（五點反轉）**：參見「擴張排列」（Broadening Pattern）。

**Flag（旗形）**：屬於連續排列。這是發生在直線狀快速價格走勢之後的密集交易區間，排列期間通常少於4個星期。型態上限與下限相互平行，但傾斜方向可能向上或向下。上升趨勢過程，旗形通常發生在整段走勢的中央位置，所以又有「旗形飄揚在旗桿中央」的說法。排列過程，成交量應該萎縮，向上突破需要配合大量。最低衡量公式：由突破點計算先前快速走勢的距離，然後由突破點朝相同方向衡量該距離。

**Floating Supply（流通供給）**：任何特定時間，可供交易的股票數量。一般來說，這是發行股數減去鎖定籌碼。舉例來說，公司退休基金的持股，通常不會隨意賣出，這可以視為鎖定籌碼而不屬於流通供給。

**Formation（排列）**：參見「區域型態」（Area Pattern）。

**Front—Month（最近月份）**：一系列交割月份契約之中的最近到期月份。

**Fundamentals（基本面）**：公司營運方面的資料，通常都是關於盈餘與股利。在商品交易中，這是指足以影響商品供給與需求的經濟因素。編者附註：這方面的重要數據包括：盈餘、獲利、毛利、現金流量、銷貨與其他統計數據，有時候反而造成價值估計的困擾。

**Gap（缺口）**：價格區間內的缺口，可能來自於（1）某交易時段的最低價，高於前一交易時段的最高價；（2）某交易時段的最高價，低於前一交易時段的最低價。如果繪製兩個交易時段的線形，線形之間有一段為重疊部分，這就代表跳空缺口。參見「普通或區域缺口」（Common or Area Gap）、「除息缺口」（Ex—Dividend Gap）、
