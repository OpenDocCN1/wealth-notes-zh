# 交易與投資可供運用的工具

此處當然不可能把所有可供運用的股價指數、期貨與選擇權全部列舉出來，因為交易工具不斷推陳出新，而且處在網際網路時代，產品變化速度非常快。除了上文談到的交易工具之外，還有所謂的「世界基準股」（World Equiry Benchmarks，簡稱WEBs），這意味著全球性暴露風險也是可以處理的。

除了DIAMONDS與SPDRS之外，在本世紀初，美國證交所大約有30多種指數股或類似交易工具。費城與芝加哥也有類似產品，而且幾乎每天都有新產品推出。為了避免混淆，一般投資者只需要留意最具代表性的股價指數就可以了；交易工具的種類愈多，相關戰略與戰術也會變得愈複雜。所以，對於一般投資人而言，只需要留意道瓊工業指數、S&P 500與那斯達克綜合股價指數（DIA、SPY與QQQQ）應該就夠了。當然，交易者如果想要根據類股輪動或短期循環操作，就需要瞭解一些其他指數產品，例如：中型股指數、日經指數與其他等等。
