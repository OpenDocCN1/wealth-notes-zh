# 部位規模的重要性

分散交易是把風險分散到多種交易工具，藉以增加理想交易機會的掌握程度，也可以因此提升獲利。適當的分散交易，需要對於很多不同交易工具，進行類似（如果不是完全相同的話）的下注。

龜族系統利用市場價格波動程度來衡量每個市場的風險。我們利用這種風險衡量做為部位調整大小的單位，後者代表固定的風險程度（價格波動金額）。如此可以提升分散交易的效益，使得成功部位沖銷失敗交易的可能性。
