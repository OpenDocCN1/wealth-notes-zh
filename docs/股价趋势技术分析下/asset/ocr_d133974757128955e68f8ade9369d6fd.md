# 第 37 章 相同的舊有型態

![](bbox=[0.15, 0.13, 0.85, 0.49])

1月25日星期五，價格夾著大量跌破支撐。雖然當天收盤價買穿幅度不大，但排列的技術型態明顯惡化，還是應該立即賣出股票。下降三角形具有空頭意涵，即使在突破之前也是如此。突破之後，價格完全沒有向上拉高。因為我們不能仰賴突破之後的拉高走勢，所以最安全的做法是立即賣出，或當價格跌破型態時，立即根據收盤價設定逐次停止單（就目前這個例子來說，跌破型態需要考慮除息金額）。

請注意1月底暴跌走勢的大成交量。一般來說，重要跌勢不一定需要配合大成交量，但如果經過成交量確認，走勢的意義更顯著。

問題：由這份走勢圖判斷，1月底的股價，是否代表TXT很便宜了？各位是否會因為下列理由而買進：「股價不可能再跌了」、「應該反彈了」或「股價遠低於實際價值」。

假定TXT確實出現技術性反彈，各位認為反彈走勢可以回升到什麼程度？難道預期股價可以在短期之內向上穿越20嗎？1957年1月底，各位認為整個盤面呈現多頭格局嗎？
