# 股價趨勢技術分析 (下冊)

# 第 **18** 章
## 戰術問題

編者附註：馬基在本章探討「投機客」如何針對中、短期趨勢進行操作的戰術。有關長期投資人的策略與戰術，請參考第18－A章。另外，關於「投機客」一詞的討論，也請參考第18－A章。

在多头市場買進股票也可能賠錢；同理，在空头市場放空股票也可能發生虧損。各位對於主要趨勢的判斷可能完全沒錯，運用的長期策略也可能絕對正確。可是，即便是如此，如果沒有適當的戰術配合，不能妥當規劃交易細節，正確構想未必能夠轉化為實際獲利。

交易者（尤其是沒有經驗的交易者）表現欠佳，涉及的理由很多。買進的時候，如果沒有預先設定獲利目標，即使股價上漲，也不知道什麼時候應該賣出。萬一碰到股價下跌，也不知道根據什麼方法認賠。結果：既有獲利變成損失，些許損失變成鉅額損失。另外，這一切還涉及心理障礙。每當買進或放空股票，立即會發生佣金費用或啥零股價差。而且，結束部位的時候，還要發生類似的費用。由於交易者不可能掌握漲勢的最高點或跌勢的最低點，所以即便是一筆明
