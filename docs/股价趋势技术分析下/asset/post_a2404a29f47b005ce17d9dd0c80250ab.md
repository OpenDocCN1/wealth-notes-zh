
# 股價趨勢技術分析（下冊）

投資工具與基金推出所謂的「被動型投資」，實際上也就是專門提供給大額客戶運用的指數化產品。

這類或其他籃式投資組合的買賣，大概都採用「程式交易」（program trading）。

體察市場對於這類交易工具的需求，美國證交所推出SPDR，讓一般散戶也能夠採用相同的策略。為了評估這項產品受到市場的歡迎程度，可以實際衡量其交投狀況。到2000年為止，SPDRs的投資累積金額大約 150億美元，發行數量超過100,000,000股。透過這項產品，投資人可以買賣S&P 500指數的整籃股票或整個投資組合，情況就如同任何個別股票一樣。可是，這種產品的單價很低，所以一般人都可以買賣。

1998年，美國證交所又推出根據道瓊工業指數發行的指數股，稱為DIAMONDS（DIA），結構與SPDRs非常類似。所以，現在的投資大眾可以直接買賣道瓊工業指數，情況不同於馬基與愛德華當年的時代。

## 指數股與其他類似產品的結構

美國證交所發行的單位投資信託基金，是用來複製根本交易工具的表現。舉例來說，SPDR代表S&P 500一籃股票整體價值的十分之一，其本身在美國證交所掛牌交易，就如同普通上市股票一樣。SPDR也具備普通股票的性質。期限很長：SPDR信託基金契約持續到第22世紀。每季股利：SPDRs每季都發放現金股利，後者也就是其代表之S&P 500成分股的現金股利。甚至股利也可以再投資。正常交易時段內，信託憑證可以在AMEX進行交易。正常狀況下，SPDR與其代表的S&P 500價格應該沒有什麼差別。

# 第 20-A 章 挑選適當的股票：長期投資觀點

此處討論的SPDRs性質，適用於所有的指數股（包括：DIAMONDS、WEBs……等）。當然，運用指數股也涉及一些費用與成本，但程度遠低於一般基金。對於個人投資者來說，指數股的運用比較具有彈性。撇開其他優點不談，這種工具讓投資人得以控制稅金問題，這在基金是不可能的。

其他交易所也推出類似的證券交易工具、衍生性產品或期貨，藉以複製著名的股價指數。這包含追蹤羅素（Russell）、日經指數（Nikkei）的股票、指數股或期貨，也有期貨或指數的選擇權，還有一大堆奇奇怪怪的交易、投資、避險工具。這些產品之中，比較重要的有芝加哥期貨交易所的道瓊工業指數期貨與期權；芝加哥商業交易所的各種指數期貨（包括：S&P、日經225種股價指數、迷你S&P 500、S&P中型股400種股價指數、羅素2000與那斯達克100）；芝加哥選擇權交易所的S&P 100與S&P 500選擇權。當然，還有其他的交易工具。凡是比較重要的期貨或選擇權，通常都會顯示在《華爾街日報》的期貨報價與選擇權報價欄位。

本書並不打算深入討論期貨與選擇權。可是，這些相關產品還是值得一提，因為不論投資人或交易者都可以運用指數股或股價指數來進行避險，當然也可以用來從事投機。

簡言之，避險就是讓整體部位處於中性狀態，其價值不受市場行情波動影響。舉例來說，交易者可以做多DIAMONDS，並買進CBOT的道瓊工業指數賣權。如此一來，如果道瓊指數上漲，DIAMONDS將獲利，但賣權價格將下跌。反之，如果道瓊指數下跌，賣權價格將上漲，但DIAMONDS會發生虧損。請注意，避險並不是本書的主題，所以這只是一個過度簡化的例子。雖說如此，但這個例子還是點出避險的重要性。投資人如果認為行情可能發生變化，可以採取避險行動，沒有必要賣掉整個股票投資組合，因為後者可能引發種種麻煩，也會產生稅金問題。

## 交易與投資可供運用的工具

此處當然不可能把所有可供運用的股價指數、期貨與選擇權全部列舉出來，因為交易工具不斷推陳出新，而且處在網際網路時代，產品變化速度非常快。除了上文談到的交易工具之外，還有所謂的「世界基準股」（World Equity Benchmarks，簡稱WEBs），這意味著全球性暴露風險也是可以處理的。

除了DIAMONDS與SPDRs之外，在本世紀初，美國證交所大約有30多種指數股或類似交易工具。費城與芝加哥也有類似產品，而且幾乎每天都有新產品推出。為了避免混淆，一般投資者只需要留意最具代表性的股價指數就可以了；交易工具的種類愈多，相關戰略與戰術也會變得愈複雜。所以，對於一般投資人而言，只需要留意道瓊工業指數、S&P 500與那斯達克綜合股價指數（DIA、SPY與QQQQ）應該就夠了。當然，交易者如果想要根據類股輪動或短期循環操作，就需要瞭解一些其他指數產品，例如：中型股指數、日經指數與其他等等。

## 這些交易工具的功能：分散投資、緩和風險、稅務、技術規律性

這些新交易工具的重要性，很難被低估。首先，散戶交易者將因此取得過去只保留給大額投資人的特權交易工具；換言之，透過這些交易工具，散戶也可以從事真正的分散投資。請注意，S&P 500指數成分股大約佔紐約證交所掛牌股票總市值的69%。買進SPDR，等於是買進整個美國經濟。至於道瓊工業指數的30支成分股，更是美國經濟、甚至是全球經濟的代表。不論在哪個市場從事投資，都絕對要留意這兩種股價指數的動向。整體股票市場的狀況，過去是由道瓊工業指數單獨代表，現在則由這兩種股價指數反映。

買進SPDR或DIAMONDS，等於是取得分散性投資組合。買進那斯達克指數或QQQQ，等於是投資風險較高的美國高科技產業。由於股票市場呈現長期的上漲偏頗，所以長期投資人有理由採用這兩種策略或戰術。當然，這并不代表投資人可以盲目建立部位，也不代表投資人可以不理會這些部位。事實上，剛好相反，各位應該還記得道氏理論的紀錄。即使是長期投資，也不該讓空頭市場損毀投資組合的價值。這些相關問題，已經在第18-1章做徹底討論了。

這些交易工具雖然很不錯，但還是要記住馬基的告誡（現在已經比較不重要了）：重點是很多股票構成的市場，不是單一的股票市場。換言之，當道瓊工業指數與S&P指數處於下跌時，即使是個別股票，其多頭部位的建立也要很謹慎，而且對於其漲勢要抱著懷疑的態度。另外，相較於精挑細選的個別股票，這種代表整體市場的指數型交易工具，績效表現可能差很多。舉例來說在1999～2000年期間，奎爾（Qualcomm）股價漲幅曾經到達240%，S&P指數的相同期間漲幅為24%。可是，那些在頭部買進奎爾，而在修正走勢底部賣出的人，會蒙受75%（148美元）的損失。針對奎爾或其他類似股票進行交易的人，隨時都要留意股票市場的動靜，但SPDRs的投資者，可能每個禮拜才需要瀏覽股票市場的表現，或請經紀人在特殊狀況下（譬如：股價跌破趨勢線或逼近停止點）打電話通知。這些人可以吃得好好、睡得好。

SPDRs還有一些其他優點。對於指數型基金來說，如果經理人因為投資人贖回或其他緣故而調整投資組合，基金持有人可能就會承擔稅務的問題。反之，指數股的契約延伸到第22世紀，長期投資人沒有必要獲利了結而支付稅金。萬一碰到空頭市場，可以透過其他工具進行避險，例如：期貨、選擇權或其他一籃股票組合或個別股票，只需要處理後者之相關交易的稅金。

約翰·馬基曾經指出，由技術分析角度觀察，道瓊工業指數的表現比較具有規律性，很可靠。這些論點在有關道氏理論的討論中談得很詳細（參考第5-A章與第36章）。所以，相對於個別股票來說，指數股比較容易進行技術分析。

## 摘要結論

長期投資人與中期投機客通常只想掌握真正的長期趨勢（以及經濟循環），不希望因為短線交易而耗費佣金成本。

他們瞭解相關的風險，但也知道短線進出只會造福股票經紀人。長期投資人如果想要擁有大盤的表現，可以採用指數型基金、SPDRs或其他類似產品。雖說如此，他們可不願意抱著投資渡過空頭市場。當主要趨勢發生變動時，他們會出脫投資或進行避險。如果判斷行情進入空頭市場，他們甚至會放空股價指數。

如果希望操作績效超過大盤指數（採用本書建議的方法，自然就會達成），則除了基本投資組合之外，還可以買賣一些投機性個股。投資人隨時可以進行某種程度的避險，至於實際操作方式，則取決於個人的風險偏好。如果做多股價指數，可以考慮放空一些走勢特別疲軟的個股。反之，如果做空指數，則可以買進一些走勢特別強勁的個股。只要擁有合理程度的技巧與資本，投資人沒有理由發生長期虧損。

# 第 21 章
# 圖形選股策略 I

如果交易者根據「基本面」統計數據進行操作，他需要分析公司的盈餘、股利、管理能力、產業經營展望……等，這方面分析通常只能侷限在少數個股或某個產業類別內。

另一方面，技術交易者透過日線圖可以操作很多股票，因為他主要是關心股票的技術型態，不必深入研究每家公司的背景。事實上，股票本身的性質將反映在市場行為上，這方面考量的重要性，遠超過公司經營或盈餘狀況。股票雖然代表公司所有權，但資本結構、「槓桿」與股票流通籌碼將決定股價波動，而這一切與公司業務經營之間，未必保持穩定的關係。

我們經常發現，許多備受推崇的老牌績優股，雖然財務報表顯示最近獲利成長，股利分派的長期紀錄也很穩定，但當時股價未必代表適合買進的對象。股價或許高估，公司或許即將攤提大量費用。另一方面，某些股票的盈餘表現、股利紀錄都不理想，但突然出現一系列投機性漲勢，成為適合買進的對象。為什麼？因為紀錄只適用於過去，不代表未來；價格走勢圖經常反映一些投資大眾不清楚的事實。

讓我們透過一個例子來說明。假定有兩棟房子準備出售。其中一棟是設備新穎、獨門獨院的豪宅，地點很理想，售價是 20,000美元。另一棟是老舊的6單位公寓，地點相對不理想，售價也是 20,000美元。哪棟房子比較適合居住？答案沒有任何疑問。可是，就現況判斷，獨門獨院住宅的行情顯然低迷，公寓房子的需求旺盛。所以，如果想要投資的話，6單位公寓可能是比較適當的對象。

前文曾經談到保守與投機的問題，關於這個問題，我們往往不能根據公司經營的業務性質做判斷。某家公司的業務量很穩定，企業經營一向都很成功，但發行大量的債券與優先股，銀行貸款也很多，還有其他必須優先清償的債務。這種情況下，普通股價格波動通常會很劇烈。同樣地，另一家小型公司，發行籌碼很有限，其股價也將因為「槓桿作用」而呈現大幅擺動。

因此，篩選股票的時候，需要考慮股票的類型，在市場上展現的股性，而不是公司經營的業務性質。稍後，我們還會回頭討論這個問題，告訴各位如何擬定一份清單，涵蓋所有希望交易的股票。

另外，還有一個問題還沒有處理：應該繪製多少圖形？繪製的圖形愈多，愈可能涵蓋理想的交易對象。許多股票即使平常的交投非常活絡，股價也可能陷入長期整理，完全沒有顯示交易機會，實際上也沒有交易機會可以顯示。這類況下，圖形顯示的也是穩定的走勢，頂多只能在小幅盤整區的底部買進、頭部賣出。當情況發生變動時，圖形會提供很多資訊；一旦導致情況變動的消息公布，圖形會立即（通常是提早）顯示趨勢變動的訊號。如果平常追蹤的股票數量夠多，隨時都有某些股票顯示這類明確的上漲或下跌訊號。

所以，各位繪製的圖形應該儘可能多一點，但也不能因此而造成消化不良。你或許想要追蹤100支股票，但如果每天只有半小時左右的時間可供繪圖，頂多只能追蹤20、30支股票。反之，如果整天的大部分時間都可以用來分析股票，則可能繪製300支股票的圖形。可是，我們希望提出一個警告：有始有終。如果不能「有終」，就不要「有始」。剛開始的時候，不要貪多，慢慢來。如果你認為自己還有能力照顧更多圖形，再根據經驗挑選適當的股票。如果從一開始就繪製很多圖形，進度往往會落後，被迫在週末「加班」，如此將不能充分運用所繪製的圖形。編者附註：對於手工繪製圖形的人，這段警告仍然有效。至於採用電腦化設備的投資人，則有另外的問題。繪圖本身沒有問題，想要繪製多少圖形，就繪製多少圖形；可是，實際上能夠分析的圖形數量是多少呢？電腦甚至可以在這方面提供協助。交易者可以要求電腦根據每種條件篩選值得進一步分析的股票。譬如說，「電腦，請顯示股價高於50天移動平均而成交量有異常表現的所有股票。」

透過前述說明，各位知道繪圖技巧可以運用在任何自由交易市場。除了股票之外，還包括所有的商品、債券、貨幣市場工具、即將發行契約……等。如果想要把繪圖技巧引用到股票之外的任何特定領域，完全沒有問題。

可是，一般來說，最好只繪製掛牌公司股票圖形。當然，未上市公司股票走勢也可以繪製圖形，但這類股票通常只有買／賣報價，沒有每天的成交量與實際交易價格資料，所以繪圖上可能會產生困擾。因此，各位挑選的股票，最好是在某集中市場掛牌。這方面考量還有另一個優點，因為公司得在大型交易所掛牌，就必須符合某些條件，必須依規定公告資訊，遵守相關法則與規範。本書引用的範例，大多取自紐約證交所（NYSE）的掛牌股票。紐約證交所的掛牌股票有好幾千支，涵蓋各種類型的證券，包括最保守到最投機、最便宜到最昂貴的股票，也包括各行各業。在這些股票之中進行篩選最方便，因為大部分報紙都會刊載NYSE的交易資料，經紀商也能夠提供NYSE的即時報價。當然，各位也可以考慮美國證交所（AMEX）、那斯達克（NASDAQ）或其他國內的集中市場，甚至海外的交易所。就圖形技術分析而言，這些股票的型態與意義都相同。

第9版附註：一般來說，應該留意與繪圖的股票，经常会由草堆裡跳出來。偏好挑選股票的人，可以參考《投資人商務日報》（Investors Business Daily）根據CANSLIM系統篩選的股票（並非建議採用這套系統，而是建議各位留意各種系統）。那些突然出現在prophet.net或stockcharts.com等網站最活絡交易個股清單上的股票，都值得技術分析者留意。還有，具有選擇權交易的股票，如果選擇權的隱含價格波動率激烈變動，也值得進一步觀察。成交量突然暴增的個股，也要注意。透過國際網路與電腦套裝軟體，交易者可以要求電腦提供某些訊號，譬如：股價突破14天、44天、150天與200天移動平均。此處之所以特別強調14天，因為某些專業玩家認為投資大眾经常在這種時間架構上思考；44天則是因為某些人認為基金公司经常在這個時間架構上思考；至於150天與200天，則是因為大家都認為重要。

# 第 22 章
# 圖形選股策略 II

繪圖挑選的股票，產業類別上應該儘量分散。各位並不是專心研究某特定產業，挑選的股票應該儘可能代表各種不同產業。所研究的股票，應該涵蓋礦業、石油、鐵路、化工、釀酒、娛樂、航空公司、公用事業……等。為什麼？不論哪種產業，多數股票通常都會有相同或類似的走勢型態，因為整個產業面臨相同的大環境。舉例來說，如果Allis—Chalmers（編者附註：或戴爾電腦）在一段急漲走勢之後，出現三角形排列，則Deere（編者附註：康柏電腦）、Minneapolis—Moline、Harvester與Case也會發生類似的急漲走勢，然後形成類似的三角形、矩形或其他整理排列。當Schenley處於長期下降趨勢，則Distillers—Seagrams、National Distillers、Publicker與American Distilling也會處在長期下降趨勢。編者附註：代表相同類型的名稱，就如同希臘神祇的名字。或者是尤里西斯與廖伯布盧（Ulysses and Leopold Bloom）。對於現代讀者來說，則是：英特爾、快捷（Fairchild）、國家半導體（National Semiconductor）或網康（3COM）。意思都是一樣的。

所以，除非各位準備在每種主要類股內，都挑選好幾支股票，否則圖形涵蓋的產業，應該儘可能分散。如此一來，當某些類股呈現沈悶或冷清走勢時，其他類股或許有交易機會。（可是，不要因此推論某個類股中的每支股票，都會有相同走勢。個股走勢經常受到特定因素影響，這些因素可能只涉及一支或幾支股票。可是，整個產業畢竟還是處在相同背景環境下，走勢的基調還是有某種程度的類似性。）

根據前述評論，繪製圖形應該儘量涵蓋每種重要的產業。可是，假定受限於能力，只能照顧少數的圖形，每個產業往往只能挑選一支代表性股票；這種情況下，應該如何挑選呢？舉例來說，假定我們想在鐵路類股內，挑選一支最具代表性的股票。編者附註：生化科技類股或網際網路類股。事實上，鐵路是一個非常重要、龐大的產業，我們或許應該挑選一支以上的個股，但暫時只考慮一支。第9版附註：更好的辨法，是直接挑選類股指數。換言之，挑選所有的成分股，而不是單一個股，這兩種選擇並不衝突。

應該是高價股或低價股？首先討論這點。

就鐵路股過去的資料來看，低價股的走勢百分率，經常超過高價股。一支 5美元 左右的股票，可能在幾個星期之內上漲 100% 而成為 10美元。可是，100美元 或 200美元 的股票很少能夠在幾個星期之內上漲 100%。如果整體產業狀況是以讓 5美元 的股票上漲到 10美元，則 100美元 的股票大概只能上漲到 140美元。所以，如果利用 1,000美元 資金購買 5美元 的低價股，可以賺取 100% 或 1,000美元 的獲利。另一方面，如果購買 100美元 的股票，只能賺取 400美元 的獲利（股價上漲點數雖然較多，但百分率較少）。低價股獲利大約是高價股的兩倍半。
