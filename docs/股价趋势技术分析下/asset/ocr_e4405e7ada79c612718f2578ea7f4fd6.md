# 飆漲個股管理的細節技巧

第28章討論的漸次停止策略，當然是處理這種股票的方法之一。採用這種策略時，首先要找到股票的基準點，然後根據3天期原則調整停止點。另外，根據新的百分率高點向上調整停止點，也是一種辦法，特別適用於飆漲股。由於這屬於非理性的投機狀況，或許可以考慮採用「非常」戰術：少量加碼，或在一系列新高點分批獲利了結。處在需要密切追蹤的噴出行情階段，交易者可以在多頭反轉日或根據關鍵反轉型態（參考第10章）結束多頭部位，然後到海邊放鬆一下，順便算鈔票。對於那些來自德州的玩家，甚至可以考慮放空。

原則上，我將此視為股票發展階段的早期異常現象。所以，對於這類機會，我不會尋找長期投資對象。換言之，賺了錢，立即走人。絕大部分情況下，這類股票都會像煙火一樣，燦爛的光彩很快就消失在夜空。當然，也有少數股票會像微軟或雅虎。煙火表演結束之後，有耐心的技術析者會回到犯罪現場，觀察殘餘的灰燼。噴出行情結束，股價崩跌，最後總會出現底部，這個時候就可以考慮投資，機會總是存在的。網際網路、生化科技與人類基因等類股，存在非同尋常的潛能，將來很可能会浴火重生。
