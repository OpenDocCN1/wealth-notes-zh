# 第 5 版 序

《股價趨勢技術分析》第4版的16次印刷過程，內文很少做修改， 主要是因為羅伯．愛德華對於市場行爲的描述非常精確，徹底反映股 票市場的典型行爲。舉例來說，某些走勢圖範例非常適於說明重要的 技術現象，似乎沒有理由只因為資料發生在數年之前而刪除或更新。

本書再版過程增添的一些內容，事實上仍然顯示類似的範例，有 一部份甚至是取自最近市場的新行爲型態；這一切都說明自由競爭市 場的根本性質多年來並沒有顯著變動，人類行爲的「相同舊有型態」 依然產生相同的市場趨勢與行情波動。

第5版的最大改變、也可以說是最大改進，是幾乎所有採用 TEKNIPLAT圖形紙的圖形，都重新繪製與製版。修改過程中，某些 過去沒有察覺的小瑕疵（包括刻度、標題或其他方面的疏忽），全部 都做更正。

本版修正過程最困難的工作，是由繪圖室的兩位年輕人安妮．馬 霍尼（Anne E. Mahoney）與約瑟夫．史匹賽斯基（Joseph J. Speszski） 處理，他們兩人負責所有的繪圖與完稿程序，並做必要的修正。這兩
