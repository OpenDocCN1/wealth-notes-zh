# 第7章 戰術

關於龜族交易系統的其他雜項規定。

著名建築師密斯·范·德·羅厄（Mies van der Rohe），談到克制的時候，曾經說過：「上帝隱於細節」（God is in the details）。交易系統的情況也是如此。接下來，我們準備討論一些龜族交易法則運用上，可能顯著影響續效差異的細節。

# 進場交易指令

如同前文曾經提到的，理查·丹尼斯與威廉·艾克哈特建議龜族不要採用停止單（停損單）。龜族會留意行情發展，一旦預設的停止價位遭到觸及，才實際逃單。

另外，龜族也被告知，一般情況下，限價單優於市價單，因為限價單的成交價格與滑移價差程度都優於市價單。

任何市場都會有買進報價與賣出報價。買進報價顯示買方願意買進的價位，賣出報價則顯示賣方願意賣出的價位。任何時候，如果買進報價超過賣出報價，交易就發生了。如果流動性足夠充裕，市價買單會成交於賣出報價，市價賣單會成交於買進報價；如果市價單的規模很大，則實際成交價格可能變得更糟。

一般來說，市場價格多少都會呈現隨機走勢，也就是沒有明顯意義的波動。採用限價單，就是希望能夠成交於這種隨機波動的最有利一端。限價單如果不大，不至於影響行情；如果交易指令涉及的數量很大，限價單對於行情的影響程度，絕對會小於市價單。

至於如何設定限價單的價位呢？這涉及一些技巧，但只要經過一些練習，價格限定在市價附近的限價單，撮合價格應該都會優於市價單。
