
風險的有用指標。

我們可以根據自己或系統的經驗，運用第24章介紹的方法，計算個別股票的價格波動率。如果報酬率的離散程度超過我們能夠接受的水準，就把該股票剔除到清單之外。根據我的瞭解，這方面的相關文獻沒有提到這種考慮個人風險偏好的分析方法。透過這種針對個人風險偏好設定的程序，可以讓我們知道相關方法在特定案例運用上的可靠程度。不符合條件的股票，可以由共同基金經理人的投資組合排除。

## 投資組合的風險

如果對於投資組合管理有些經驗的話，也可以根據第24章介紹的方法，計算投資組合的價格波動率（就如同計算個別股票價格波動率一樣）。我們甚至可以製作投資組合報酬的次數分配圖，觀察報酬率偏離其平均數的程度，如此可以讓我們進一步瞭解交易系統或个人交易風格的性質。

學術界與投資經理人經常採用夏普率（Sharpe Ratio），用以比較不同交易系統或不同經理人的績效。相關討論請參考附錄D，透過這種方法分析投資組合風險，存在嚴重的瑕疵。本章稍後會討論這方面的問題；在此之前，讓我們看看專業玩家如何處理風險。

讀者可以自行判斷，究竟應該採用馬基建議的綜合槓桿方法（附錄A），或採用下文簡易介紹的現代投資組合管理與風險分析。綜合槓桿的目的，是透過某種程度的計量方法，衡量與控制風險，並評估獲利潛能。當今的投資組合經理人，則採用VAR的概念。編者做這方面的說明，只是提供大略的架構。最後，我會說明自己比較贊成的方法：實用投資組合理論（Pragmatic Portfolio Theory）。

# 第9版附注：風險與趨勢

趨勢判斷是否正確，會影響單一股票的風險與投資組合的風險。當恩隆（Enron）股票發生問題而價格持續下跌，如果繼續持有多頭部位，虧損（與風險）顯然會變大。反之亦然。不論個別股票或投資組合，如果順著趨勢方向操作，風險會降低。伯西第（Bassetti）與布魯克（Brooker）呈送給市場技術分析師協會（mta.org）的論文《剖析道氏理論》（Dissecting Dow Theory）認為，如果根據道氏理論辨識的訊號，順勢操作道瓊工業指數成分股組合，則組合風險會降低。圖9.1與9.2提供這份論文的一些其他資料，請造訪馬基的網站：www.edwards—magee.com。

# VAR程序

個別股票的報酬率決定之後，就可以據以計算投資組合的報酬率。這方面的計算，是取投資組合的某持有期間。所以，投資組合的報酬率（或價值）會每天波動，有時候增加，有時候減少，有時候為正數，有時候為負數。考慮某段期間的一系列報酬率，就可以計算該期間的平均報酬率，也可以製作報酬率的次數分配圖。這種次數分配的寬度，可以衡量投資組合的風險程度。所以，報酬率介於1%與8%的某投資組合，其風險程度小於（根據投資理論）另一個報酬率介於-1%與20%的投資組合。次數分配圖雖然可以說明風險，但缺乏共同基準來衡量兩個不同的投資組合。這部分是透過投資組合的價格波動率來衡量。

價格波動率是衡量報酬率偏離其平均值的程度。這也是統計學所謂的標準差（standard deviation），通常以希臘字母σ表示。根據學術理論，投資組合的價格波動率愈大，風險愈高。這是相當符合直覺的；所以，商品組合的報酬率，由於擴張信用的緣故，可能介於-30%到100%之間，但債券組合只會因為債券市場價格變動而變動，而且到期價值都等於債券面值。當然，如此計算債券風險，經理人完全沒有考慮鈔票購買力的減損，但這是我們一般債券分析師的小秘密，實在沒有必要拿這些來煩學術研究者或債券交易者，反正他們也不想知道。

如同前文提到的，如果對於投資組合操作有些經驗，很容易取得價格波動率。如果必須計算價格波動率的話，整個程序相當複雜，決定VAR需要一些統計知識與諸多資料。我們必須計算投資組合個別成分的權數，決定其相關性，計算相關係數，以及其他等等。如同孟德爾布洛特（Mandelbrot）在科學美國（Scientific American）所做的評論一樣，完成所有程序之後，我們還是搞不清楚在電影「天搖地動」（Perfect Storm）裡究竟應該怎麼辦。有關VAR計算程序的清楚說明，請參考菲利普·卓里恩（Philippe Jorion）的《風險值》（Value At Risk）。

# 實用投資組合理論（與實務）

我們或許不該自找麻煩去回憶大學時代的統計學，不妨試試一些比較簡單、務實，對於一般投資大眾有用的東西：實用投資組合理論（Pragmatic Portfolio Theory）。在學術圈子裡，以及華爾街的專業機構，大家瘋狂地想把所有的東西數量化，除了他們替客戶造成的風險與負債為例外。

讓我們透過簡單的計量方法，衡量個別股票與投資組合的風險，但我們知道「絕對精確」是不可能的。（即是專業投資組合經理人在諸多恐慌期間的績效：1929、1957、1987、1989。即是1998年差點把整個金融市場拖垮的長期資本管理公司，以及1987年造成股災的投資組合保險策略。）

## 實用投資組合風險衡量

### 決定單一股票的風險

股票的理論風險通常都以價格波動率衡量，後者請參考第24章的說明。所以，對於我們持有的股票部位，譬如100股微軟，假定市場價格為120，年度化價格波動率為0.44，其理論風險為：

```
理論風險＝價格波動率×部位數量×股票價格
V×Po×Pr＝T $ Risk
0.44×100×200＝$ 5200
```

- T $ Risk＝理論風險金額
- V=價格波動率
- Po=部位股票數量
- Pr=價格

所以，從理論上來說，微軟股票的年度風險為：價格波動率×股價（2000年的時候），相當於0.44×120，大約是$ 52。事實上，對於那些在120買進微軟的非圖形分析者，如果沒有設定停損或沒有嚴格遵守停損，則可能看著股價由2000年2月高點120，跌到2000年6月的（估計）底部60。

我們還可以考慮另一種更有意義的衡量：操作風險（Operational Risk）。操作風險也就是指特定交易的風險。舉例來說，我們買進前迹微軟股票，最初停損如果設定為市場價格的5%，則操作風險為：

```
操作風險＝（市場價格－停損價格）×部位數量
(MP-S)×Po=O $Risk
(120-114)×100=600
```

- O $Risk=理論風險金額
- MP =市場價格
- Po =部位股票數量
- S =停損價格

### 投資組合風險

計算投資組合的理論風險，程序相當複雜。原則上，這是把投資組合的價格波動率乘以投資組合的市場價值。聽起來好像蠻單純的，但投資組合的價格波動率，並不是直接加總個別部位的價格波動率，因為還要考慮不同部位之間的相關性、變異數與共變異數。各位如果想進一步瞭解這方面的計算程序，請參考附錄D。

投資組合的理論風險，簡單說是：

```
價格波動率×投資組合市場價值
MV×V= TP $Risk
```

## 第4.2章 投資組合風險管理

- TP $ Risk = 投資組合理論風險金額
- MV = 市場價值
- V = 價格波動率

正常市況下，簡單投資組合的操作風險（PO $ Risk）可以定義為，多頭部位操作風險加總和，減掉空頭部位操作風險加總和；換言之，就是：

```
PO $ Risk = （多頭部位O$Risk加總和）－（空頭部位O$Risk加總和）
```

如果碰到絕對負相關，這兩個因子可以加總。

### 衡量最大淨值減損

有關交易系統的設計與測試，或在實際交易過程內，大概很少人會關心標準差或那些冷冰冰的統計數據。我們在意的是「失血」的嚴重程度，換言之，可能遭遇的「最倒楣」狀況。在交易系統或交易方法重新糾正自己之前，我們可能遭遇的最嚴重連續虧損會到達什麼程度？也就是說，在我們能夠重新獲利之前，「失血」可能嚴重到什麼程度？曲線圖是呈現這種經驗的可能方法之一（曲線圖請參考圖 2.）。

觀察帳戶淨值曲線圖，衡量某段期間最高點到最低點之間的距離，就代表該段期間內的最大的淨值減損（maximum drawdown），這個金額可以讓我們大致估計所需要的交易資本與準備金，也讓我們瞭解可能遭遇的情況。如果淨值曲線圖存在許多（方向錯誤的）大風大浪，或許意味著交易方法需要修改，除非我們真的樂於享受這種起伏波動（而且千萬要瞭解這些冒險往往會真的發生慘不忍睹的事故）。

在沒有實際市場經驗的狀況下建構交易系統，所需要準備的交易資本至少要是最大淨值減損的3、4倍。

### 實用投資組合分析：衡量風險

分析投資組合的時候，首先要知道哪些東西最重要而需要衡量。想要控制風險，首先要能夠衡量風險。理論家利用價格波動率（譯按：報酬率分配的標準差）代表風險。這種觀念雖然存在嚴重問題，但我們還是暫時接受。在投資組合之內，我們必須能夠區分各種不同類型與權數的風險。就價格波動率來說，債券的價格波動程度顯然小於股票，沒有擴張信用部位的價格波動程度小於（譬如）期貨。同理，如果投資組合的風險不平衡，也就是說某種成分代表的權數過大，這就意味的危險。可是，如果投資組合只由S&P 500構成，情況顯然不同，因為這種組合根據定義就是分散性投資。所以，我們必須知道衡量什麼對象。（請參考菲利普．卓里恩的《風險值》。另外，有一套稱為「風險管理101」[Risk Management 101]的教學軟體也清楚說明這些概念。）

實務操作上，交易者最想知道的是操作風險，不是理論風險。另外，一般交易者也不認為報酬率向上波動是風險，至少不屬於負面因子。交易者可能會採用此處介紹的風險衡量實用方法。若是如此，交易者需要知道「投資組合普通或常態風險」（Portfolio Ordinary or Normal Risk，簡稱POR）、「時間風險」（Risk over Time，簡稱PRT）與「異常或災難性風險」（Extraordinary or Catastrophic Risk，簡稱PCR）。

### 投資組合普通或操作風險

首先衡量今天的風險。今天的普通風險很容易計算，首先取每個部位停損點與市場價格之間差距的價值，然後做加總。把這個數值除以配置資本（總資本，簡稱TC），這即是投資組合風險因子（Portfolio Risk Factor，簡稱PRF），也是交易者當天所願意承擔的風險因子。

```
POR=差值總和
PRF=PO $ Risk / TC
```

### 投資組合時間風險

前述數值進行年度化之後，可以顯示時間風險，當然也可以計算週或月的風險值。或者，這個因子可以在過程中取得。換言之，我們可以取每天的普通風險，然後加總為某特定期間的總值。另外，也可以計算平均報酬與其變異數，然後計算標準差。這是時間風險。舉例來說，年度化風險 $ = \mathrm{DR} \times \sqrt{365} $ ，其中DR表示每天風險。

### 投資組合異常或災難性風險

異常風險是指某天發生崩盤或恐慌性走勢的風險。關於這個概念，首先假定正常情況下，或發生每天可能見到的恐慌走勢。對於這種情況，假定所有的部位都發生最糟走勢而停損出場，考慮投資組合受到的影響。然後，繼續延伸這方面的分析，假定市場出現2個、4個或6個標準差的走勢，考慮投資組合受到的影響。碰到這種情況，專業報價商或造市者根本不理会我們設定的停止單，大家都争先恐後想要出場，那將會如何呢？換言之，市場正常機制完全瓦解了。這就是所謂的異常或災難性風險。

### 控制風險

對於這類災難性事件，信用擴張愈大的部位，風險愈高；風險最高的當然是選擇權空頭部位（通常是賣權空頭部位）。各位應該還記得，我的某位客戶曾經在1987年大崩盤虧損 \$ 5,700萬，他就是銷售賣權。某些造市者也曾經因為銷售買權而破產，但這相對罕見，通常都是因為根本股票成為被購併對象，或部位過度集中。

經過避險的投資組合，風險最低。最簡單的避險例子，莫過於同時買進股票與其賣權。某個部位的獲利，剛好等於另一個部位的虧損。另外，投資組合也可以擁有某些股票的多頭部位，以及一些股票的空頭部位，這也是某種形式的避險。或者，做多道瓊工業指數，放空道瓊期貨契約或其成分股。

現在，讓我們看看實用的方法。投資組合管理如果採用馬基的評估指數來衡量市況，據以調整投資組合，則不論由普通或異常風險的角度觀察，風險都會顯著降低。事實上，我們甚至能夠因為市場發生某些讓專業基金經理人失業的事件而獲利。

如果我們嚴守規範，完全按照市況發展設定逐次停止單，當股價創新高，則按照第28章說明的隨後3天法則調高停止點，即使碰到市場風暴，應該也能夠安然渡過危機。

### 風險與資金管理程序摘要

前述談論的程序，可以簡化為單純的公式，即使是數學恐懼症患者也能應付自如。

交易規模是風險控制的基本單位。不論價格波動率如何，任何股票的500股風險必大於100股。

接著說明如何決定交易規模。首先，計算進場價格與停損價位之間的差值，這稱為「風險金額1」（$1）。取「風險控制因子」（也就是投入某筆交易之資金佔總資本的百分率）乘以「總資本」，結果是每筆交易承擔風險（Risk—per—Trade）。舉例來說，3%乘以總資本（TC）$100,000。前述結果除以「風險金額1」，便可以決定交易規模。

```
EP-SP=$R1
RCF×TC=RpT
$R1/RpT=TS
```

- 其中
- TS=交易規模
- EP=進場價格
- SP=停損價位
- $R1=風險金額1
- RCF=風險控制因子
- TC=總資本
- RpT=每筆交易承擔風險

每天都衡量上述操作風險。把操作風險除以總資本，結果是投資組合操作風險因子。這個因子的讀數如果太高，就需要考慮避險或調整部位，刪除一些績效表現最差的部位。

經常重新計算停止點（對於交易者來說，每天都要重新計算），根據基準點法則進行調整。或者把停止點設定在支撐／壓力、趨勢線附近，或採用資金管理停止策略（譬如說，所承擔的風險不超過市場價格的8%）。這個8%不得超過總資本的X%。請注意，資金管理停止策略的彈性，在本質上就不如技術分析停止策略。

任何行情都會歷經其發展階段，這也反映出馬基評估指數的根本概念，部位會隨著行情發展而自然結束，然後再根據MEI的多、空讀數變化建立新部位。請記住，大盤頭部經常呈現讀數明顯偏高的MEI，大盤底部則呈現讀數明顯偏低的MEI。

專業風險經理人每天都會計算相關市場的異常風險，透過前述程序來管理下屬交易者，不允許交易者暴露在過高的風險下。事實上，恐慌與崩盤走勢很少莫名其妙發生。恐慌行情發生之前，通常都會出現可資辨識的微兆，尤其是在電腦的協助之下。出現在跳空缺口或向下長線形的關鍵反轉排列，其成交量都會因為內線與專業賣盤而暴增。重要股票的頭部排列（雙重頂、三重頂、頭肩頂或A型頂）幾乎必定會出現這些微兆。

想要爭取自由，就必須永遠保持戒心。投資成功也必須支付代價。

# 第43章 堅持信念

很多方法都都有成功潛能，只要長期貫徹某種合理方法，多年下來，就可以取得穩定的獲利。本書討論的方法（技術分析）也是這類方法之一。

可是，很多交易者並沒有設定最基本的策略，對於市場行為與發展也毫無概念，他們完全聽任宰割，被捲入每個恐慌、謠言、小道消息或任何風吹草動之中。金融市場原本就是各種力量相互競爭、相互衝突的場所，永遠受到各種憂慮、不確定與疑惑的牽扯。於是，當盤勢震盪或顛挫，很多人經常不考慮地結束理想部位；當市場出現一些利多消息，就忙著回補空頭部位；白天就拉長耳朵聽些閒言閒語，跟著別人傳播謠言，找些東西來強化信念或抒解恐懼；晚上則孤獨面對著期待與憂慮，猶豫不決，拿捏不定。

真正的災難總會捕捉這類交易者，因為他們沒有明確的指引，不知道交易什麼時候已經泡湯而應該認賠，他們總是緊抱著股票闖蕩地雷區，期待逆境很快就過去，希望自己有機會解套，但這類機會通常都不會適時出現。即使行情朝有利方向發展，讓部位得以獲利，處境也同樣棘手，他們不知道如何獲利了結。因此，他們可能過早出場而喪失主要獲利機會，或是停留過久而吐回幾乎到手的大部分獲利。

如果各位確實瞭解本書各章節討論的內容，就應該瞭解沒有任何技術排列或訊號絕對萬無一失。股價走勢圖會反映目前已知的所有訊息（包括：已經宣布或可能發放的股利，計畫中的分割或公司合併，政治事件對於股票市場的可能影響，世界局勢，公司管理，盈餘報鉤與其他等等）。走勢圖不會、也不能預測無法預測的事件，這些屬於任何人都不能預知的发展。多數情況下，走勢圖非常可靠。如果各位不認為如此，就應該更深入研究，或完全放棄圖形分析。

反之，各位如果認為圖形確實可靠，大體上能夠顯示股票未來的發展方向，那就應該嚴格遵守圖形提供的訊號，或直接採用我們提供的法則，或透過個人經驗修正法則，完全根據法則進行交易。總之，各位如果準備根據某套方法或準則進行交易，就必須嚴格遵守。這是交易法則能夠發揮效益的唯一途徑。

各位如果能夠辦到這點，從一開始就能掌握明顯的優勢：
- （1）各位永遠不會因為單筆交易結果而破產，不會讓單筆交易勾消全部交易資本；
- （2）當行情發生不利走勢，各位不會不知所措而讓虧損繼續累積，不會讓資金套牢而不能針對新趨勢進行交易；
- （3）各位可以冷靜擬定決策，清楚知道獲利了結的訊號，也瞭解認賠出場的適當限度。

這一切都意味著各位將心平氣和地進行交易。各位會接受損失，也會創造獲利。可是，不論發生哪種狀況，各位都不會徹夜難眠。各位必須擬定一些策略。如果交易發展很順利，會在適當價位獲利了結。如果行情發展不順利，則會即時認賠，另尋更適當的對象，只要資本沒有受到嚴重傷害，隨時都可以再度進場。

身為投機客，各位的功能是提供市場流動性，嘗試阻止市場非理性的過度行爲。爲了達成這項功能，一方面必須保持自己資金的流動性，以便在必要情況下反轉部位。另一方面，各位也必須排除自己的非理性或情緒化行爲。如果能夠明智而穩定的完成這些工作，將可以爲整體經濟福利貢獻一份心力，而且市場對於各位的貢獻也會提供對等或更高的報酬做爲答謝。
