# 第 28-A 章
基準點：個案分析

對於看起來不甚起眼的圖 210，愈加思考，愈覺得其中蘊含著趨勢與市場的振動。想想那些漲勢、跌勢、漲勢、跌勢……等循環。交易者或投資人只要不要在修正走勢中追價，正常情況下，都可以隨著趨勢發展到末端。可是，對於場內交易員、避險基金或那些試圖藉由價格波動獲利的人，非常瞭解一般投資人與交易者會把停止點設定在先前低點的稍下方。在正常交易情況下，如果這些人認為有必要引發大眾的停止單，他們就會這麼做。而且，有時候也是可能辦到的。所以，先前低點往往會因此而被貫穿。

傑克·史瓦格在《金融怪傑》（中文版，請參閱寰宇出版公司）一書訪問布魯斯·考夫納（Bruce Kovner），請教他如何設定停止點。他回答：「在他們很難動手腳的地方。」根據基準點與適當的濾網設定停止單，造市者與專業報價商很難動手腳；換言之，這些停止單一旦被引發，通常代表趨勢發生變動了。
