# 第３０章 支撐／壓力的運用

當然不希望只因為股價下跌到22 3/4就賣出，因為股價很可能隨時向上飆升而創新高價。可是，在持續性下跌過程中，我們終究必須決定：「股價已經跌破支撐；必須立即賣出認賠，避免損失進一步擴大。」這往往是痛苦的決定，因為當我們認賠之後，股票可能馬上變得「生龍活虎」而朝預期方向發展。

我們必須有接受各種可能後果的心理準備；這種情況遲早會發生。可是，為了避免過度焦慮，當初進場的時候，就應該預先決定給股票多少周旋空間。因此，當股票沒有按照預期發展進行時，就應該斷然處置，不要一天拖過一天。

如果是針對短線走勢做多或放空，可以考慮採用下列法則。多頭部位的基準點採用前一個小型頭部（支撐），空頭部位基準點採用前一個小型底部（壓力）；處理方式就如同第27章討論的停損點（第9版附註：另外也請參考第28章，以及第42章的風險限制程序）。這些基準點可以是盤中高價或低價，不一定要是收盤價。一旦價格穿越基準點到達某種程度，就應該推斷預期支撐或壓力不能發會作用。

如果是在主要或中期趨勢的支撐點買進，或是在主要或中期趨勢的壓力點放空，就可以給自己較充裕的周旋空間。這種情況下，應該觀察下檔支撐或上檔壓力，尋找力量的核心位置或主軸；換言之，嘗試尋找整個區域的重心，這通常是該區域內以成交量為權數的平均價，因為某價位換手的股數愈多，支撐／壓力的力量愈強。一旦找到這個基準點之後，就可以根據第27章討論的方法設定停損。

截至目前為止，我們只根據支撐／壓力的觀點，考慮如何認賠（顯然不同於正常的秩序），完全沒有談論如何進場或如何獲利了結。

關於進場建立部位，可以考慮三個準則（但三者的結論或許會相互衝突）：支撐／壓力、趨勢線、前一波走勢的40～50%折返。如果
