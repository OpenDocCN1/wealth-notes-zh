那些在120買進微軟的非圖形分析者，如果沒有設定停損或沒有嚴格遵守停損，則可能看著股價由2000年2月高點120，跌到2000年6月的（估計）底部60。

我們還可以考慮另一種更有意義的衡量：操作風險（Operational Risk）。操作風險也就是指特定交易的風險。舉例來說，我們買進前迹微軟股票，最初停損如果設定為市場價格的5%，則操作風險為：

```
操作風險＝（市場價格－停損價格）×部位數量
(MP-S)×Po=O $Risk
(120-114)×100=600
```

其中

O $Risk=理論風險金額

MP =市場價格

Po =部位股票數量

S =停損價格

# 投資組合風險

計算投資組合的理論風險，程序相當複雜。原則上，這是把投資組合的價格波動率乘以投資組合的市場價值。聽起來好像蠻單純的，但投資組合的價格波動率，並不是直接加總個別部位的價格波動率，因為還要考慮不同部位之間的相关性、變異數與共變異數。各位如果想進一步瞭解這方面的計算程序，請參考附錄D。

投資組合的理論風險，簡單說是：

```
價格波動率×投資組合市場價值
MV×V= TP $Risk
```
