# 長期投資人的策略

長期投資人的策略，是要掌握長期趨勢，也就是涵蓋好幾個月、甚至數年的趨勢。可是，這並不代表長期投資人要抱著股票組合陷入空頭市場。剛好相反，一旦察覺空頭行情訊號，長期投資人應該出清股票組合，或進行避險。本書第5章曾經討論道氏理論在這方面的表現，績效相當令人滿意，遠勝過買進－持有策略，後者在柯林頓及高爾執政期間又蔚為流行，因為當時出現1990年代的大多頭市場。
