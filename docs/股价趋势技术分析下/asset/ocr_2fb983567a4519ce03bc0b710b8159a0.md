# # 第$42$章

投資組合風險管理

前一章曾經談到，主要趨勢階段（或狀況）與其獲利潛能之間，存在某種關係。目前有很多機械化系統或計畫，可以處理這類問題，但我們不相信機械化方法能夠徹底解決問題。我們曾經提到一種方法，這是按照市場趨勢發展狀況，慢慢調整投資組合規模。編者附註：馬基的評估指數或MEI。還有一些根據趨勢進展而分批進出場的方法；也有一些逆著趨勢發展方向進行調整的方法，換言之，在空頭市場裡，隨著價位走低而分批向下攤平買進，或在多頭市場，隨著價格走高而分批向上攤平賣出。（第9版附註：這兩種方法都是自尋災難，絕對應該避免。）

關於何時買進、何時賣出的問題，這些方法本身都不足以徹底解決問題。本書的主要宗旨，是研究個別股票的技術現象。如果知道如何根據走勢圖尋找買點，而且清楚在哪種狀況下賣出，我們已經擁有交易成功的根本架構。反之，如果我們的買點與賣點總是造成虧損，那麼不論如何管理資本也不會造成具體差別，頂多只能影響資本萎縮的速度，但最終還是會消失。編者附註：投資人如果發現自己總是虧
