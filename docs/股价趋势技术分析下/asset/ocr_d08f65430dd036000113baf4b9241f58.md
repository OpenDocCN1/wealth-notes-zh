# 股價趨勢 技術分析 (下冊)

個反轉點進場（或型態內任何一點，因為我們預期這是連摵排列，而且不會發生長期整理）。

如果旗形或三角旗形的排列時間過長（超過3個星期），型態的有效性就值得懷疑。所以，我們需要按照一般做法，在排列最高點之上或最低點之下（取決於多頭或空頭部位）設定停損。旗形狀排列最後可能失敗，這是很不幸的發展；一旦建立部位之後，由於我們很難在整理過程主動放棄希望，所以需要設定3個星期的期限，儘量避免股價折返到先前設定的停損。另一方面，如果旗形排列確實屬於連摵排列，突破之後的走勢通常很快速，屬於最容昜獲利的行情之一。

這裡還需要處理另一種可能性：在旗形或三角旗形排列過程，我們原本已經持有部位。如果在上升趨勢持有多頭部位，或在下降趨勢持有空頭部位，一碰到旗形整理，顯然應該繼續保留部位。可是，如果嚴格遵守交易法則，這種情況通常不會發生。一般來說，在旗形排列之前的旗桿過程，通常應該會發生某種訊號，讓我們可以把部位停止點調整到收盤價附近的 1/8點位置。換言之，在先前快速走勢過程，部位應該已經獲利了結，出場點可能是旗桿的端點（當然，我們不能仰賴這方面的運氣）。

可是，萬一沒有發生出場訊號，當旗形出現時，我們仍然持有部位；碰到這種情況，千萬要保留部位。排列朝原先趨勢方向繼續發展的可能性很高。

假定我們在上升趨勢持有多頭部位，而且股價向上突破而創新高價，例如由20上漲到32。稍後。我們發現漲勢停頓，設定在30的停止賣單被引發，接著發生幾天的回檔，成交量急遽萎縮，幾乎完全沒有交易量（請注意，必須是「急遽萎縮」）。若是如此，我們可以重新進場，即使價格高於前幾天的水準也一樣。
