# 第28章 何謂底部？何謂頭部？

第9版附註：本章內容非常重要，我會繼續採用馬基所謂的「頭部與底部」，但目前習慣上都稱此為「高點與低點」，似乎比較不容易造成混淆。另外，由高點與低點的角度思考，本身就很重要。譬如說，所謂的多頭趨勢，是指一系列不斷墊高的高點與低點構成。這種型態一旦明顯中斷，交易者就要留意趨勢可能變化。還有，圖210的說明仍然保留每檔為 1/8點，但讀者應該知道目前已經改採小數報價。

# 隨後三天法則

本章並不打算談論主要或中期趨勢的頭部／底部，而是處理小型趨勢的頭部／底部。小型頭部或底部，可以做為許多技術運用的基準，能夠用以決定停損點、趨勢線、目標價位與支撐／壓力，這些都是交易者必須留意的重要關卡。
