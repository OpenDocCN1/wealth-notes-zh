# 股價趨勢技術分析（下冊）

的影響：風險與投資組合管理。所以，精明的投資人應該如何決定每筆交易的規模大小？

關於如何計算交易規模、控制風險的程序，我要在此感謝老朋友、兼同事威廉·史考特（William Scott）提供的資料。

首先，決定每筆交易所願意承擔風險的資本數量。就我所認識的專業交易者來說，很多人設定的百分率為2%或3%。為了說明方便起見，此處採用整數，假定有$100,000交易資本，每筆交易願意承擔的風險為$3,000。另外，假定準備買進價格$20的股票，停損設定在$5之外。如此一來，就可以透過下列方式計算部位大小：

股數＝3000÷5＝600股。

如果我們打算把停損設定在$10之外，則可以交易3000÷10＝300股。換言之，根據我們願意承擔的風險金額調整交易部位大小。

這是在個別交易基礎上，控制風險的簡單、有效辦法。
