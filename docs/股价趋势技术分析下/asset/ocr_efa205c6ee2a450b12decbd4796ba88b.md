# 股價趨勢技術分析 (下冊)

![](bbox=[0.15, 0.08, 0.85, 0.43])

圖230. 7月份與8月份的矩形排列長達6個星期，高限47曾經遭到3次觸及，低限在44位置。如同多數矩形排列一樣，7月19日發生第一個矩形反轉點時，成交量擴大；然後，排列發展過程，成交量萎縮；最後，8月29日向上突破時，成交量又再度放大。

價格向上突破之後，出現典型的旗形折返走勢，成交量顯著萎縮；折返走勢雖然跌破矩形上限支撐，但從來沒有穿越矩形下限。10月15日，當價格向上穿越9月初的高點，成交量放大。（類似現象也發生在12月中旬，當時價格向上穿越11月14日的高價。）11月下旬的折返走勢，成交量縮小，在9月份高點獲得支撐。這份圖形中，請注意52扮演支撐／壓力功能，這個關卡曾經是兩波漲勢的壓力，當價格由10月份峰位折返之後，則是隨後三波回檔走勢的支撐。

12月初展開的漲勢，又出現類似情況，57扮演壓力／支撐角色。當價格在12月中旬突破壓力創新高之後，回檔走勢停止於57。

趨勢的正常運作，如果沒有因為消息面因素受到干擾，主要趨勢都是由這些小型波浪起伏構成。如果市場或產業內發生重大消息，走勢可能出現長期整理或次級折返。可是，主要趨勢非常「耐操」。我們不該隨便假定主要趨勢發生反轉。
