# 股價趨勢技術分析（下冊）

投資工具與基金推出所謂的「被動型投資」，實際上也就是專門提供給大額客戶運用的指數化產品。

這類或其他籃式投資組合的買賣，大概都採用「程式交易」（program trading）。

體察市場對於這類交易工具的需求，美國證交所推出SPDR，讓一般散戶也能夠採用相同的策略。為了評估這項產品受到市場的歡迎程度，可以實際衡量其交投狀況。到2000年為止，SPDRs的投資累積金額大約 $ 150億，發行數量超過100,000,000股。透過這項產品，投資人可以買賣S&P 500指數的整籃股票或整個投資組合，情況就如同任何個別股票一樣。可是，這種產品的單價很低，所以一般人都可以買賣。

1998年，美國證交所又推出根據道瓊工業指數發行的指數股，稱為DIAMONDS（DIA），結構與SPDRs非常類似。所以，現在的投資大眾可以直接買賣道瓊工業指數，情況不同於馬基與愛德華當年的時代。

# 指數股與其他類似產品的結構

美國證交所發行的單位投資信託基金，是用來複製根本交易工具的表現。舉例來說，SPDR代表S＆P500一籃股票整體價值的十分之一，其本身在美國證交所掛牌交易，就如同普通上市股票一樣。SPDR也具備普通股票的性质。期限很長：SPDR信託基金契約持續到第22世紀。每季股利：SPDRs每季都發放現金股利，後者也就是其代表之S&P 500成分股的現金股利。甚至股利也可以再投資。正常交易時段內，信託憑證可以在AMEX進行交易。正常狀況下，SPDR與其代表的S＆P 500價格應該沒有什麼差別。
