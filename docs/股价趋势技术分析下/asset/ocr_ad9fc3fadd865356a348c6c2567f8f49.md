# 附錄 A

以下這份新整理出來的敏感性指數，是根據每支股票在1964～1973年期間每年之價格變動百分率，以及每支股票每年之中位數價格，所估計的個別股票相對敏感程度約估值。前述計算都針對股票分割與每年的整體行情區間做調整。前述修正，我們採用「市場倒數」，這是考慮所有股票的總價格區間，如此就能根據這份表格之10年期數據計算年度敏感性指數。
