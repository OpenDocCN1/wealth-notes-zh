# 股票趨勢技術分析(下冊)

可以控制 $2的股票，這即是2倍槓桿。

**Limit Move（停板走勢）**：契約交易價格到達「交易所」規定的最大變動幅度。

**Limit Order（限價單）**：限定價格的買單或賣單。舉例來說，如果限價100買進IBM，則實際成交價格必須是100或更低。

**Limit Up, Limit Down（漲停板，跌停板）**：對於某些商品，「交易所」往往會規定每天價格變動的最大漲幅或跌幅。

**Line, Dow Theory（道氏理論的狹幅盤整）**：道氏理論內，道瓊工業指數或運輸指數出現中期價向走勢，價格波動幅度（相對於平均價格）為5%或以下。

**Logarithmic Scale（對數刻度）**：參見「半對數刻度」(Semilogarithmic Scale)。

**Major Trend（主要趨勢）**：根據本書的用法，主要（或初級）趨勢是指至少持續一年而漲跌幅度至少20%的趨勢。

**Margin（保證金）**：買進或放空股票所需要的最低資本。目前，政府規定的最低保證金為50%。商品交易中，保證金也是買進或放空契約所需要的最低資本，通常是10%，但這個比率是由個別「交易所」規定。股票與商品交易的保證金性質不同。股票交易中，投資人繳納的保證金，屬於價款的一部份，剩餘價款則向經紀商融通，並支付利息。至於商品交易，保證金並不是價款的一部份，而是履約保證金，所以不涉及資金融通。

**Market On Close（收盤市價單）**：一種交易指令，由經紀人根據收盤時段的最佳價格進行撮和。

**Market Order（市價單）**：一種買賣委託單，根據交易指令到達場內當時的價格進行撮和。
