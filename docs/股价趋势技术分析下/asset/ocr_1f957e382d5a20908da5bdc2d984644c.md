# ## 第26章
整數股或畸零股？

各位可能會擔心一個次要的戰術問題：應該交易整數股或畸零股？（對於交易活絡的股票來說，整數股是以100股為單位；少於100股，就屬於畸零股。）

編者附註：處在網際網路時代，這個問題基本上已經不存在了。在馬基的時代，畸零股交易存在明顯的劣勢，除非資金有問題，否則不該交易畸零股。現在，透過SPDRs與DIAMONDS，投資人可以利用畸零股建立分散的投資組合，所以這個問題幾乎沒有討論的必要。當然，經紀商收取的佣金永遠都是問題核心，如果不論交易規模大小，經紀商都統一收取固定費率，那麼小額投資人就不需擔心。可是，實際的情況卻是：富者愈富。現在，小額投資人找到另一個新管道：不收佣金的經紀人。我原本認為這些不收取佣金的經紀人，是以量取勝。可是，除了佣金之外，經紀人還有其他賺錢管道，譬如說：把單子轉給那些需要「績效」的交易員。
