# 第9版附注：風險與趨勢

趨勢判斷是否正確，會影響單一股票的風險與投資組合的風險。當恩隆（Enron）股票發生問題而價格持續下跌，如果繼續持有多頭部位，虧損（與風險）顯然會變大。反之亦然。不論個別股票或投資組合，如果順著趨勢方向操作，風險會降低。伯西第（Bassetti）與布魯克（Brooker）呈送給市場技術分析師協會（mta.org）的論文《剖析道氏理論》（Dissecting Dow Theory）認為，如果根據道氏理論辨識的訊號，順勢操作道瓊工業指數成分股組合，則組合風險會降低。圖9.1與9.2提供這份論文的一些其他資料，請造訪馬基的網站：www.edwards—magee.com。

# VAR程序

個別股票的報酬率決定之後，就可以據以計算投資組合的報酬率。這方面的計算，是取投資組合的某持有期間。所以，投資組合的報酬率（或價值）會每天波動，有時候增加，有時候減少，有時候為正數，有時候為負數。考慮某段期間的一系列報酬率，就可以計算該期間的平均報酬率，也可以製作報酬率的次數分配圖。這種次數分配的寬度，可以衡量投資組合的風險程度。所以，報酬率介於1%與8%的某投資組合，其風險程度小於（根據投資理論）另一個報酬率介於-1%與20%的投資組合。次數分配圖雖然可以說明風險，但缺乏共同基準來衡量兩個不同的投資組合。這部分是透過投資組合個價格波
