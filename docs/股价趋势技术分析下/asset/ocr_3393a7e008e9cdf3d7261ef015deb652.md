# 第35章 技術性交易對於市場行為的影響

猜測一般人設定停止點的價位；某些情況下，當他們想要朝某個方向驅動行情時，總會先設法造成反向走勢，引發這些停止點之後，然後才正式展開行動。

期貨市場普遍採用順勢交易系統，有些人認為，這會造成整體系統都處於不利的狀況。換言之，交易者與投資人必須特別留意假走勢，以及市場脈動的变化。

沒有人能夠把圖形分析充分計量化，也沒有人能夠讓自己的操作行為不顯示在走勢圖上。沒有人能夠改變市場參與者追求私利的人性。

第9版附註：2005年，史密斯邦尼裁撤整個技術分析部門。這項行動的根本原因究竟是什麼，則有賴讀者發揮想像力。某些市場評論者認為，這是因為該部門對於後市看法明顯偏空，違背證券商必須堅持多頭立場討好客戶的根本原則。我個人認為，若是如此，則剛好證明技術分析的效力。如果我們必須射殺傳訊者，就證明傳遞的訊息具有意義。

另外，在舊金山技術證券分析者協會（tsaasf.org）的某次聚會中，我與賴瑞·威廉斯（Larry Williams）聊天，他表示，「我痛恨技術分析。」我確信他所謂的「技術分析」，是指數值導向的分析而言。
