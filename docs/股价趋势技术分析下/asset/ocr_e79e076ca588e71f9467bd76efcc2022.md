與谷底一旦持續下滑，就代表趨勢正在或已經改變。這就是道氏理論的精義所在，也是針對更短期趨勢進行交易所根據的原則。當市場出現持續下滑的峰位與谷底，則趨勢線最終難免被跌破。

關於圖210，馬克吐溫提出一段精闢的評論。他說，任何想要搞清楚其中道理的人都會瘋掉，任何想要根據圖形來解讀價格的人，都會被槍斃。圖210保持一些無法解釋的謎題與衝突。讀者應該由觀念角度切入，物要將此視為某種課題。然後，請參考圖210.1。讓我把一些隱含的法則整理出來：

+   1. 價格創峰位，意味著當時沒有更高的價格。

+   2. 價格回檔而見底。這個谷底是先前峰位以來所出現的最低價格。當價格又開始回升時，留意整天價格完全高於谷底線形的天數。

+   3. 這類走勢一旦出現三次，先前谷底就成為基準點，多頭部位的停止點就可以向上調升到基準點下側的6%（或x%）處（參考第27章）。

+   4. 如果新高價較先前峰位高出3%，則該天低點成為新的基準點。
