突破進場訊號發生當時，龜族建立1個「單位」的部位，當價格距離起始成交價格1/2N，再加碼1個「單位」。請注意，所謂的1/2N是由實際成交價位起算，不是由訊號位置起算。譬如說，如果成交價格出現1/2N的滑移價差，則加碼價位與訊號價位之間的距離將是1整個N。

# 加碼

加碼將持續到特定市場允許持有的最大「單位」數量。如果行情移動速度夠快，很可能在一天之內就持有最高的4單位。

# 範例：

黃金

N＝2.50

55天期突破＝310

+   1. 第1起始單位	310.00
2. 第2單位	310.00+ 1/2 2.50相當於311.25
3. 第3單位	311.25+ 1/2 2.50相當於312.50
4. 第4單位	312.50+ 1/2 2.50相當於313.75

原油

N＝1.20

55天期突破＝28.30

+   1. 第1起始單位	28.30
2. 第2單位	28.30+ 1/2 1.20相當於28.90
3. 第3單位	28.90+ 1/2 1.20相當於29.50
