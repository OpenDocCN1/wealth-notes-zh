# 股價趨勢技術分析(下冊)

彈，導致訊號反覆。處在下降趨勢，只要價格繼續停留在移動平均下側，就繼續持有空頭部位。如果移動平均本身朝下發展，但價格向上穿越移動平均，代表賣出訊號。如果價格朝移動平均方向發展，但沒有穿越移動平均，稍後又下跌，代表賣出訊號。

# 包寧傑帶狀

約翰．包寧傑（John Bollinger）是「金融新聞網」（Financial News Network）的首席技術分析師，他設計的包寧傑帶狀（Bollinger Bands）是位在20天移動平均兩側2個標準差的d − β（帶狀。如此建構的帶狀，其寬度會隨著價格波動程度自動調整；價格波動愈劇烈，帶狀愈寬，價格波動愈穩定，帶狀愈窄。（包寧傑相關著作《包寧傑帶狀操作法》請參閱寰宇出版公司）。

# 超買或超賣

包寧傑帶狀的主要目的，是評估價格漲勢或跌勢是否太過份。一旦決定超買或超賣之後，就可以根據其他技術指標（例如：RSI）進行交易。

# 個人偏好

使用者可以自行決定標準差的個數。對於50天期移動平均，有些交易者可能會把標準差個數由2個增加為2.5個。反之，對於10天期移動平均，很多技術分析者則把標準差個數由2個減少為1.5個。原則上，包寧傑帶狀的標準差個數設定，應該涵蓋絕大部分的價格走勢。
