# 股價趨勢技術分析(下冊)

數學系統來「擊敗市場」。各位如果心存疑惑，最好立即打住，深入觀察各位有興趣的這類「系統」，將其擺在實際的市場走勢內驗證。或者，各位不妨捫心自問，是否看過任何人單獨採用這類系統而足以成功？編者附註：馬基寫下這段評論之後，由於電腦科技進步，以及各種金融理論的發展，某些交易者確實能夠建立客觀系統，在金融市場獲得穩定的成功。可是，市場通常都會針對這些成功系統做出反應，發展新的對策來擊敗這些系統。所以，隨著時間進展，這類機械化系統的績效都會慢慢退步，甚至完全失敗。

另一方面，技術分析雖然引用數學，但絕對不屬於數學性系統。技術分析試圖尋找市場走勢的意義，所憑藉的是類似情況的過去經驗與圖形發展，認定市場是一種敏感的機制，任何個人或集團的行情看法，都透過競價式民主拍賣程序而簡化為單一數據，也就是證券當時的價格。我們所研究的排列或型態，絕對不是毫無意義的，也不是任意設定的。這些型態或排列代表的變動，可以反映真實價值、預期、希望、恐懼、產業發展，以及其他所有相關因素的影響。就任何特定排列而言，我們未必知道它究竟是由哪些希望、恐懼或發展形成，但重點是我們可以辨識這些型態，瞭解這些排列的後續可能發展。

各位或許認為，短線交易可以讓不規則趨勢「平滑化」，並提供市場所需要的流動性；所以，短線獲利是提供這些功能而收取的對應代價。相對於長期投資人來說，短線交易者願意迅速擬定承諾，願意隨時獲利了結或認賠出場。他們不會堅持在市場上持有某支股票的「部位」（雖然會根據市況而維持某種「總綜合槓桿倍數」[total Composite Leverage]，其結果也一樣，請參考後文解釋）。短線交易的每筆獲利，或許少於長期投資，但他們可以隨時退場觀望，重新評估市況，然後再進場。
