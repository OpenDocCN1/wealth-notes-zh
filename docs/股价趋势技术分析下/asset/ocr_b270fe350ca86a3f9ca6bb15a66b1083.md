# 股價趨勢技術分析（下冊）

濾網（馬基建議採用2%的突破濾網，但也可以根據市況而調整為3%，或直接透過行情實際的價格波動率決定濾網百分率）。至於執行戰術的交易工具，則包括前文提到的SPDRs、DIAMONDS、指數期貨與選擇權。

每種策略都要有出差錯的準備，針對可能發生的空頭走勢擬定因應計畫。如果一般人不堅持只從多邊進行操作，空頭市場並沒有那麼可怕。當紐約證交所的交易大廳染血之後，很多長期投資策略都被拋到九霄雲外。可是，對於準備充分的技術投資人來說，他們有針對這類狀況的因應計畫，而且也應該可以實際按照計畫出脫部位。

這些因應計畫，包括針對執行順利的部位持續調整停止點，至於執行不順利的部位則斷然認賠。不妨把投資組合看成一棵果樹，必須經常修剪雜枝，才能提升收穫。本書很多地方會討論如何設定停損（停止）（請參考第27章）。對於長期投資人來說，停止點可以設定在一一舉例說明而已，編者並沒有實際建議這麼做——價格跌破200天移動平均或／與跌破長期趨勢線。一般認定200天移動平均是長期趨勢指標，而這種普遍看法也讓該均線因此而扮演重要的角色。第9版附註：「200」只是一個參數而已，針對個別市場進行研究，或許可以找到更好的參數。

實際操作上，應該考慮的對象不只是200天移動平均或趨勢線而已。投資組合個別股票、以及整體大盤或類股指數的價格形態，也是重要考量因素。另外也要考慮各種股指數與其成分股的技術狀況：是否做頭、陷入盤整、呈現趨勢或其他等等。
