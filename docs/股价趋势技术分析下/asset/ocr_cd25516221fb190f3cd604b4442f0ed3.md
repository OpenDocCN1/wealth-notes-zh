# ## 投資組合普通或操作風險

首先衡量今天的風險。今天的普通風險很容易計算，首先取每個部位停損點與市場價格之間差距的價值，然後做加總。把這個數值除以配置資本（總資本，簡稱TC），這即是投資組合風險因子（Portfolio Risk Factor，簡稱PRF），也是交易者當天所願意承擔的風險因子。

POR=差值總和

PRF=PO $ Risk / TC

# ## 投資組合時間風險

前述數值進行年度化之後，可以顯示時間風險，當然也可以計算週或月的風險值。或者，這個因子可以在過程中取得。換言之，我們可以取每天的普通風險，然後加總為某特定期間的總值。另外，也可以計算平均報酬與其變異數，然後計算標準差。這是時間風險。舉例來說，年度化風險 $ = \mathrm{DR} \times \sqrt{365} $ ，其中DR表示每天風險。
