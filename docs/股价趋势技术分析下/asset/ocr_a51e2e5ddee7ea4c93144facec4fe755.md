# 第41章 實際交易的資本調整

票價格水準會影響股性（低價股的價格波動百分率大於高價股）。融資成數也會影響風險程度。

這方面的討論確實可以達成一些有意義的結論（否則就沒有必要浪費時間）；可是，在任何特定時間，究竟應該投入多少資金數量的問題，是否可以透過某種數學公式來計算答案，我們非常懷疑。編者附註：雖說如此，但還是有人試圖這麼做。

假定我們認為當時的行情屬於多頭市場，而且所處的階段值得投入80%的資金。可是，這時候有一個問題：如何選股？如果買進AT&T之類的高價股（編者附註：貝他值偏低），獲利恐怕很有限（如果判斷正確的話），但損失也不會太嚴重（如果判斷錯誤）；反之，如果買進低價股（編者附註：貝他值偏高），情況就截然不同了。同理，如果買進敏感指數（編者附註：價格波動率）偏低的保守型股票，盈虧程度應該低於敏感指數偏高的投機股。這些因素造成的影響，不下於投入資金數量。另外，如果想要評估下列問題，也不能忽略這些因素：「是否承擔過高的風險？若是如此，程度有多嚴重？」

讓我們釐清任何可能發生的混淆，假定我們決定投入80%資金（譬如說，$10,000中的$8,000），購買美國鋼鐵7%優先股。如果行情大漲，我們的獲利可能是4%或5%。反之，如果行情大跌，我們的損失可能也是4%或5%。可是，如果我們拿這筆$8,000購買某低價投機股的選擇權，在90天之內，我們的獲利可能是數倍，但$8,000也可能完全泡湯。

顯然地，行情發展過程，我們可以隨時調整自己的狀態，增加或減少所投入的資金，調整持股的性質，持有更多或更少的投機股，持有更多或更少的低價股，或是調整融資成數。
