# # 股價趨勢技術分析（下冊）

# ## 龜族停損

永遠設定停損，並不代表龜族會實際遞入停損單。

由於我們的部位規模很大，不希望因為遞入停損單而洩漏部位資料或交易策略。反之，我們是把停損設定在特定價位，一旦該價位遭到觸及，就必須採用限價單或市價單結束部位。

這些停止價位都不能計價還價。只要停損價位遭到觸及，相關部位就必須出場；沒有任何例外。

# ## 停損設定

龜族根據部位風險程度設定停損。沒有任何一筆交易承擔的風險可以超過2%。

由於1個N的價格走勢，代表帳戶淨值的1%盈虧，如果風險最大不得超過2%，相當於是2個N的價格走勢。所以，龜族多頭部位的停損，設定在進場價位下方的2個N距離，空頭部位停損則設定在進場價位上方的2個N距離。

為了儘量降低整體部位承擔的風險，如果部位加碼，則稍早建立的部位，停損必須調緊 1/2N。這種情況下，整體部位停損位置與新加碼價位之間的距離通常為2個N。可是，新加碼部位如果因為行情變動速度太快或開盤跳空而出現滑移價差，則前述距離將大於2個N。

+   *   原油
    *   N＝1.20
    *   55天期突破＝28.30
