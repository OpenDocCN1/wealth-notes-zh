# 股價趨勢技術分析(下冊)

![](bbox=[0.17, 0.12, 0.91, 0.58])

1945年上半年出現一個漂亮的楔形排列。這波漲勢是GFO大多頭行情完成的最後頭部。

楔形排列向下方突破之後，價格直接下滑到 $18\frac{1}{4}$ ，然後由這個8月份的中期走勢低點向上反彈，在 $23\frac{3}{4}$ 與 $26\frac{3}{4}$ 之間形成矩形排列，矩形排列突破之後，經過一系列崩跌走勢，1947年5月的低價為 $6\frac{1}{8}$ ！

對於楔形排列，我們很難判斷上側與下側趨勢線什麼時候會開始收斂。4月底的向上突破很正常；我們可以在次一個折返走勢進場買進。接下來，5月份高點 $23\frac{1}{2}$ 發生之後，銜接最近兩個高點的直線，顯然沒有與基本趨勢線相互平行，這時候趨勢線已經出現相互收斂的傾向。隨後三波漲勢還繼續確認楔形排列結構；在最後峰位，我們發現漲勢停頓。對於機警的交易者來說，或許應該在6月4日與5日的小型頭部出場，該處的成交量相當大。即使當時沒有出場，也應該調緊停止價位，防範價格向下方突破。
