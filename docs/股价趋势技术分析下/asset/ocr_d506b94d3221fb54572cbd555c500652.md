# 股價趨勢技術分析 (下冊)

果股票1股分割為2股或4股，這沒有什麼問題，只要把縱軸的價格刻度除以2或4，走勢圖基本上維持不變。可是，股票進行分割之後，交易可能趨於活絡（因為發行股數增多），圖形排列往後可能變得比較「粗糙」，但還是會「尊重」先前（經過調整）的壓力／支撐水準、趨勢線……等。如果股票分割不是2的倍數，而是1股分割為3股，或7股合併為4股，那就需要重新繪製走勢圖。新繪製的圖形，最好涵蓋分割之前幾個星期的走勢，只需要把價格除以3或4/7，重新登錄圖形。

圖形中或許也應該註明公司發生的重大事件，例如：兼併其他公司、減少債券發行數量、盈餘或其他重要報告的相關數據。雖然技術分析只考慮圖形本身，但這些「基本面」資料還是值得參考。

# 調整刻度

如果所繪製的某份走勢圖，股價最初在20附近，現在則上漲到40附近，而且可能突破40。碰到這種狀況，最好把40調整到縱軸中央位置。這段期間內，同時繪製兩份走勢圖（縱軸中央位置分別標示20與40），如果股價確實穿越40，我們已經擁有一份新圖形可以運用。反之，如果股價回檔到35附近，可以暫時放棄輔助用的新圖形。當然，如果需要同時繪製兩份圖形，唯有當股價到達新圖形的縱軸中央價位，才需要繼續繪製新圖形。

# 交易的圖形紀錄

我們可以進行紙上模擬作業；換言之，在圖形上標示、記錄理論而不是實際的交易。我們原本打算另闢一篇幅幅討論這個問題，列舉相關細節，但作者判斷很少讀者願意進行這類詳細研究、記錄與分析，因為這方面的模擬工作，類似於實際交易。
