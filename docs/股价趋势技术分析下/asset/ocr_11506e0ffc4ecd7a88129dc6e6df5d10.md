# 移動平均的困難處

移動平均運用上的最大困難之一，就是其代表的趨勢可靠程度。如果價格呈現橫向整理，那麼移動平均也會呈現橫向整理（請參考第11章討論的橫向盤整）。另外，如果行情變動非常快速，移動平均提供的訊號在時間上會顯得嚴重落後，因為移動平均會被早期資料拖累而反應遲鈍。加權或指數移動平均雖然可以改善這方面的問題，但移動平均會變得跟著行情起伏，結果使得移動平均喪失「平滑」效果，導致訊號經常反覆。所以，我們有理由不能單獨仰賴移動平均。不過，移動平均如果與傳統的價格型態配合，似乎是蠻理想的。

第9版附註：對於機械化系統來說，圓形分析的最大貢獻，無疑是讓投資人瞭解當下的市況。一位勝任的分析者，應該可以判斷趨勢明確與橫向走勢之間的差別；如此一來，就能採用適當的因應策略。不幸地，似乎很少交易者能夠採用「混合」方法。他們害怕「自由心證」的交易方式，不相信自己能夠處理期貨交易帶來的龐大情緒壓力。

# 移動平均收斂／發散指標（MACD）

移動平均收斂／發散指標（Moving Average Convergence Divergence，簡稱MACD）屬於擺盪指標，是把某個移動平均除以另一個移動平均。基本上，這是由3條移動平均構成的2條曲線。現代交易者幾乎都配備電腦，所以大多採用指數移動平均（EMA），讓移動平均能夠更強調近期資料的重要性。在圖形上，MACD是波動於水平平均線的上下。
