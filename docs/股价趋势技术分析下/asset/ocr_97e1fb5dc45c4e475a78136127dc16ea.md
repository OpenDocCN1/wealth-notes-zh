# 第24章

股票可能走勢

乍看之下，所有股票似乎都呈現毫無意義的起伏漲跌。所有股票經常齊漲齊跌，雖然時間不完全相同。可是，我們知道，這些漲跌走勢中，股票會遵循某種趨勢，呈現各種型態，其行為並非毫無意義。

一般來說，每支股票都有其特殊的股性，而且這種股性在一系列多、空循環中，始終都很穩定。在多頭行情中，某些股票會呈現強勁漲勢，但另一些類似價位的股票，只有中等程度的漲幅。然而，這些強勁向上擺動的股票，在空頭市場也會呈現類似程度的向下擺動，至於那些漲勢有限的股票，則具有顯著抗跌能力。本書附錄A將討論「綜合槓桿」(Composite Leverage)，顯示某些股票的走勢幅度，經常是另一些股票的好幾倍。舉例來說，我們不知道Glenn Martin（編者附註：微軟或Ebay）往後一年的股價將上漲或下跌；可是，不論該股票的價格走勢如何，我們相信其幅度都將遠超過AT&T。當然，這些股性差異是取決於發行股數、流通籌碼、公司經營業務性質，以及資本槓桿結構，我們稍早曾經簡單探討這些問題。事實上，我們並不特別在意這些差異為什麼存在。我們只希望瞭解這些差異是什麼，如何
