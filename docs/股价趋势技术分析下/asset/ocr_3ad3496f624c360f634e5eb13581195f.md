# 股價趨勢技術分析（下冊）

因此，從交易戰術的角度觀察，讓我們考慮一系列小型頭部與小型底部構成的趨勢。基於說明方便起見，並且做為一般指導準則，我們準備處理高度簡化的理想狀況（請參考「圖解」範例）。

為了避免混淆，我們需要定義一些名詞。銜接兩個或以上峰位的趨勢線，繪製為藍色，稱為「藍色趨勢線」（可以進一步細分為：上升趨勢的藍色折返趨勢線，下降趨勢的藍色基本趨勢線）。銜接兩個或以上谷底的趨勢線，繪製為紅色，稱為「紅色趨勢線」（可以進一步細分為：上升趨勢的紅色基本趨勢線，下降趨勢的紅色折返趨勢線）。某些情況下，我們希望在藍色趨勢線或折返趨勢線的下側某谷底，繪製一條平行線，稱為藍色平行線。同理，在紅色趨勢線或折返線的上側某峰位，繪製一條平行線，稱為紅色平行線。
