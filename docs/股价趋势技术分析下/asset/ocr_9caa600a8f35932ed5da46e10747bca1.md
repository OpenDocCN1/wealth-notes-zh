# 第 37 章 相同的舊有型態

圖270. PEG是很典型的公用事業股票。這類股票很多，主要是提供相關地區的水、電、瓦斯……等服務。公用事業股票經常有類似的表現，因為它們在性質上很類似。

沒錯，公司盈餘、股利與股價之間存在某種關係，但不論盈餘或股利，都不能完全決定股票「價值」，因為還有很多東西可能影響股票價值，譬如：盈餘穩定性、未來展望、稅金考量、公司的研究發展投資……等。

在大部分地區，公用事業都享有法律保障的獨占地位，收入相當穩定；而且，這類股票也有明確的成長能力，因為人們對於能源的需求穩定成長。這類股票價格長期以來都有呈現很固定的型態，類似此處的PEG。各位可以發現，公司盈餘由1959年到1970年之間，每年都成長。另外，除了1970年沒有變動之外，股利也是每年都增加。任何人如果想根據「本益比」之類的簡單公式衡量股票「價值」，因該認為1970年的本益比2.5倍（就如同1965年的情況一樣）很便宜。

當然，情況沒有那麼單純。如果有「好機會」的話，大型基金與大股東絕對不會放棄。股價走勢之所以低迷，實際上透露公用事業類股面臨的困境，包括：成本高昂的新設備、控制環境污染的設施，以及包括自由化在內的種種問題。
