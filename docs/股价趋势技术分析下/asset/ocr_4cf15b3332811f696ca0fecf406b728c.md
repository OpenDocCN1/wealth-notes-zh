# 旗形與三角旗形

很多情況下，上升趨勢發展過程出現的旗形排列，其回檔幅度可能到達我們根據一般交易戰術估計的水準；換言之，回檔幅度可能是先前「旗桿」長度的40~50%，或回到基本（紅色）趨勢線或藍色平行線。如果先前漲勢代表整個旗桿的第一段，或先前漲勢坡度不是很陡峭，則可以考慮在第一個機會買進，通常也是在藍色平行線附近。若是如此，回檔走勢很可能還會進一步發展，但我們應該以「及早進場」為主要考量，因為折返走勢可能很短暫，或許不會觸及另外兩個修正目標。拉回走勢過程，務必留意成交量變化。成交量必須縮小，而且維持偏低水準。整個旗形排列過程，只要成交量擴大，就會危及型態的可信度；當然，突破走勢開始時，成交量照道理一定會放大。突破走勢的勁道通常很猛烈，所以只要旗形或三角旗形發生大成交量，我們就可以把停止點移到收盤價下 1/8點處。如此一來，如果大成交量顯示型態失敗，我們很快會被停損出場；可是，如果大成交量代表突破走勢，停止單應該不會被引發，因為這類走勢通常不會折返，而且经常出现突破缺口。

如果主要趨勢屬於空頭行情，前述建議也同樣適用，但有一個例外。旗形漲勢的最後一天，可能爆出大量，當然也可能出現竭盡缺口或單日反轉。如果這一天發生大成交量、竭盡缺口或單日反轉，可以立即進場建立空頭部位，停損設定在旗形峰位的上方，防範排列發生反向突破。
