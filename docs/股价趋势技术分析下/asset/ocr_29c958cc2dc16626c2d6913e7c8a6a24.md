# 第**38**章
**平衡與分散**

「你認為行情怎麼樣？」一般投資人希望這個問題有個簡單、明瞭的答案。對於這類投資人來說，任何時候都只能夠是多頭市場或空頭市場。如果被迫回答這樣的問題，我們可能會回答：「你是指哪支股票而？」一般投資人可能會說：「喔！我是指整體行情而言。」

如果各位曾經深入觀察報章雜誌的金融市場行情報導，經常會看到很多投資顧問對於未來行情發展，提供「沒有經過避險」的看法，而這些看法通常是針對「整體市場」而言。

「股票總是齊漲齊跌的，」這種看法雖然有些道理，不過還是很危險的假設。舉例來說，我們可以根據某種準則（譬如：道氏理論）來設定多頭市場與空頭市場的定義。如果整體情況符合我們設定的條件，就可以非常精確地說，「根據我的前提，現在屬於多頭市場（或空頭市場）。」另外，長久以來，我們如果把道瓊工業指數視為一支股票，並且根據道氏理論進行買賣，應該有相當不錯的獲利。
