Round Lot（整數股）：股票交易單位為100股或其倍數。

Round Trip（來回一趟）：完成一筆股票或期貨交易的成本，包括進場與出場的 Kosten 在內。

Rounding Bottom（圓形底）：一種區域型態，趨勢由下往上，變動非常緩慢而平滑，左右對稱。價格型態都呈現凹狀，經常又稱為「碗狀」（Bowl）或「碟狀」（Saucer）。這種反轉型態的目標價位，沒有可供參考的最低衡量公式。

Rounding Top（圓形頂）：一種區域型態，趨勢由上往下，變動非常緩慢而平滑，左右對稱。價格型態都呈現凸狀，經常又稱為「逆向碗狀」（Inverted Bowl）。成交量呈現凹狀，隨著價格接近峰位而下降，然後隨著價格下跌而上升。這種反轉型態的目標價位，沒有可供參考的最低衡量公式。

Runaway Gap（逃逸缺口）：當漲勢或跌勢的動能加速發展時，所形成相對寬大的價格缺口。這種缺口又稱為「衡量缺口」（measuring gap），因為這種缺口經常發生在整段走勢的中間位置。最低衡量公式：計算最初突破到缺口起點的距離，再由缺口的對側衡量相同的距離。

Running Market（快速走勢）：價格朝某個方向快速發展，沒有或很少發生反向的價格變動。

Saucer（碟狀排列）：參見「圓形底」（Rounding Bottom）與「連續弧狀排列」（Scallop）。
