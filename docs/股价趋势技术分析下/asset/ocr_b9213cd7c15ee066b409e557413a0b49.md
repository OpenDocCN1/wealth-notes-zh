# 第19章 重要細節

同的。

你應該找一個適合繪圖的工作場所。如果是在家裡，餐廳或客廳應該不錯，但家裡的成員必須瞭解你正在從事重要的工作。工作的時候，需要把門關起來，不要受到打擾。燈光需要明亮，儘可能不要有陰影。（如果處理大量圖形，燈光因素很重要。）一般的桌燈可能會反光，最好採用吊燈，大約擺在頭等上幾英吋的距離。如果採用日光燈，可以用兩支40瓦的燈管。當然，前述建議是假定房間採光不佳，不能直接靠著日光工作。

工作的空間儘量大些。大型書桌或餐桌都可以，需要有足夠桌面來擺放圖形、方格紙、草稿紙、鉛筆、米突尺、計算尺或其他繪圖與分析工具。一般桌面高度大多是30英吋，並不適合繪圖工作，桌面距離地上的高度最好是28或29英吋，比較不容易覺得疲倦。

每個人可以根據自己的習慣，採用鉛筆或鋼筆繪圖。如果採用鉛筆，可以先試試各種不同硬度的筆。鉛筆硬度需要恰當，太軟會造成線條暈開，硬度太高又會造成線條不夠清楚。總之，如果使用的鉛筆不恰當，會搞得心煩氣躁。另外，要準備足夠數量的鉛筆，至少一打以上，每枝筆都削尖，每當鉛筆稍微禿了，就可以換筆。

利用活頁方式裝訂圖形，洞孔打大一點，翻閱才容易。每本圖冊不要裝訂太多圖形。如果圖形太多而不易翻閱，就另外裝冊。佔滿紙面空間的圖形可以歸檔，圖冊只需要保留目前繼續更新的圖形。儘可能採用7孔的夾子；2孔或3孔的夾子，圖形很容易脫落。

隨著時間經過，圖形涵蓋的期間愈來愈長，參考價值也愈來愈高。過去的圖形很重要，找個地方儲藏，按照時間順序擺放，邊製一套方便查閱的索引。另外，其他相關資料也應該編製為檔案，包括：經紀商的回報條與對帳單、股利通知書、公司財務報表、新聞或文章
