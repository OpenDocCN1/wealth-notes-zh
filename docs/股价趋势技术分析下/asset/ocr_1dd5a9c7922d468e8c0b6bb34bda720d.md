# 商品／衍生性產品交易的重要觀念：

+   價格可能受到氣候、供需等外部因素的影響。

+   相較於股票交易，期貨交易的參與者，大多屬於避險者與投機客，交易時間架構較短。

+   期貨交易的契約數量基本上不受限制。

+   期貨契約有到期時間，這會影響價格。

+   停損單是一種必要工具。

+   擬定買賣決策，最好使用兩種或以上的指標。

+   不論價格或技術指標，趨勢線都是最重要的型態。背離現象則是最可靠的訊號之一。

+   價格型態分析可以與其他技術指標配合運用。

+   交易對象是價格，不是技術指標。

+   宏觀的看法，需要研究較長期的週線圖或月線圖。

+   技術指標的期間長度可以做調整，使得指標的反應變得更敏感（縮短期間長度）或變得更平滑（延伸期間長度）。

### 注釋

+   4. 取自1989年9月份《技術交易者公報》[Technical Traders Bulletin]的「相對強弱指標（RSI)」。
