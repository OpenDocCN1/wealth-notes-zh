# 基準點

我們把設定停損的頭部或底部，稱為「基準點」（basing points）。多頭行情中，每個小型折返底部都視為基準點，只要符合「隨後三天法則」，就可以利用該基準點來設定停止單。我們也利用多頭行情的每個小型頭部做為基準點。同理，空頭行情中，每個漲勢頭部與每個小型底部，也都是設定停止單的基準點。

如果股價顯著主要趨勢方向發生一段重大走勢（譬如15％），然後股價折返先前走勢幅度的40%，只要股價再朝主要趨勢方向發展，折返走勢的端點，當然是基準點。可是，如果折返走勢的幅度小於40%，甚至是在先前順勢端點附近盤整幾個星期，然後又朝主要趨勢方向發展，則折返走勢的端點，也是基準點（當然還需要成交量配合）。

每天的成交量，就像醫生手中的體溫計一樣：成交量所蘊含的內容，遠超過價格本身透露的表面徵兆。三種情況下，我們可能發現不尋常的大量：（1）價格突破型態的當天，尤其是向上突破；（2）走勢朝主要或次要趨勢方向創新的極端價位，換言之，價格在多頭市場向上穿越前一個小型頭部，或在空頭市場向下穿越前一個小型底部；（3）當小型走勢完成或即將完成的時候，換言之，多頭市場的小型頭部附近，或空頭市場的小型底部附近。除了前述三種情況，凡是順著主要趨勢方向發展的走勢，如果爆出大量，就代表該走勢告一段落了，不能完成預期中的漲勢或跌勢。

股價一旦穿越先前的小型頭部，則進入創新高的領域，這時候如果爆出大量，股價通常會拉回整理。一般來說，會出現幾天或一個星期以上的跌勢。可是，所謂的整理，也可能是好幾個星期的橫向盤
