# 第 36 章
# 移動平均：自動化趨勢線

回溯到1941年，當時的技術分析還屬於未開發領域，我們認為自己只要認真研究，再配合一點精明的眼光與運氣，必定可以找到一套無懈可擊的公式或系統，足以解決股票市場的所有問題，然後我們可以搬到大溪地、瑞士、拿索，或任何陽光明媚、適合安享餘年的地方，運用這套方法，定期打電話給經紀人。

經過一段時間的磨練，我們對於股票市場多了一層認識（但願如此）。我們尤其瞭解某些事情不該做；避免重複觸犯相同的錯誤，我們得以顯著提升交易績效。我們也知道絕對沒有萬無一失的穩當方法或系統，即使是最有用、最可靠的預測方法，也只能由機率角度解釋，經常需要修正，隨時可能失敗。

趨勢線是最有效、最早被運用的技術分析工具。不論股票是處在整體性漲勢、跌勢或橫向趨勢內，主要趨勢通常都有繼續發展的傾向。當然，任何趨勢遲早都會停止，而且趨勢遭到突破的後果總是非常嚴重。可是，對於明確的趨勢線來說，繼續發展的機率總是遠高於反轉。
