# 股價趨勢技術分析 (下冊)

曲線形成的包絡，圍繞在長條走勢圖的上下兩側。包寧傑帶狀是以簡單移動平均為中心，然後分別在上、下個2個標準差的位置，繪製一條曲線。這是包寧傑帶狀與其他包絡之間的主要差異。一般包絡是在移動平均的兩側固定百分率處繪製曲線。至於標準差，則用來代表價格波動率；所以，包寧傑帶狀寬度，會根據市場價格波動程度而自動調整。行情波動愈劇烈，帶狀愈寬；行情波動愈緩和，帶狀愈窄。

包寧傑帶狀的中心概念，是反映市場的行為，而不是告訴市場應該怎麼行為。包寧傑採用標準差來衡量價格波動率，並用以決定帶狀寬度。一般而言，包寧傑是採用20天移動平均線，然後在均線兩側各取2個標準差距離作為包絡。包寧傑建議短線交易採用10天期移動平均，中期交易採用20天期移動平均，較長期交易則採用50天期移動平均。若是如此，標準差個數也要調整，10天期採用1.5個標準差，20天期採用2個標準差，50天期採用2.5個標準差。不論哪種時間架構都可以採用這種概念；換言之，除了日線圖之外，不論是盤中走勢圖、週線圖或月線圖同樣可以繪製包寧傑帶狀。

由於包寧傑帶狀本身不會提供買賣訊號，所以需要與其他技術指標配合運用（例如：RSI或價格型態）。當價格觸及帶狀上限或下限，可能代表趨勢將持續發展，也可能代表趨勢即將反轉。包寧傑帶狀需要根據其他技術指標提供買、賣訊號。

如果與RSI或價格型態配合，包寧傑帶狀往往可以發揮強大功能。RSI是一種很好的超買／超賣指標。當價格觸及包寧傑帶狀上限，如果RSI讀數低於70，意味著上升趨勢將繼續發展。同理，當價格觸及包寧傑帶狀下限，如果RSI讀數大於30，代表下降趨勢將繼續發展。
