# ## 股價趨勢.技術分析（下冊）

![](bbox=[0.18, 0.1, 0.88, 0.48])

圖210. 調整多頭部位的保護性停止單。這是ACR的日線圖，前一個多頭市場結末於1944年7月，股價隨後陷入整理，1945年夏天出現圓形底排列，9月12日夾著大量向上突破，往後的拉回走勢就代表買進機會。根據第27章的表格，第一個停損點可以設定在8月21日小型底部下側的6%處，相當於$9 \frac{7}{8}$。9月19日與20日的價格區間完全位在月17日線形的上側；另外，9月28日的走勢完成「隨後三天法則」，使得9月17日的低點成為設定停止單的基準點。將停止點調整到9月17日底部下側的6%處，相當於$10 \frac{5}{8}$。下一波漲勢中，10月11日收盤價創新高，高於10月1日小型頭部的3%。停止點調高到$11 \frac{7}{8}$（譯按：將10月1日的小型頭部視為設定停止單的基準點）。11月2日，收盤價再創新高，高於10月15日小型峰位的3%；停止點調升到$12 \frac{3}{4}$。11月15日，收盤價又創新高，高於11月7日小型峰位的3%；停止點調升到$13 \frac{1}{2}$。11月29日，走勢又符合「隨後三天法則」，使得11月26日的低點成為底部，停止點調升到$13 \frac{3}{4}$。12月5日收盤價高於11月17日高價的3%，停止點調升到$14 \frac{7}{8}$。最後，1946年1月3日，停止點遭到引發。

處在空頭行情中，空頭部位的停止點也是利用相同方法向下調整。
