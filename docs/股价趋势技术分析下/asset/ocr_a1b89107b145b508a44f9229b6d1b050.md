# 第 31 章 分散投資

> 編者附註：現在，即使是小額投資人，分散投資也變得非常簡單。

分散投資是非常重要的觀念，因為技術分析判斷只代表可能性，絕對不能打包票。如果全部資金都投入某支股票，或投入某單一產業的少數股票，即使大盤繼續朝主要趨勢方向發展，一波假走勢就可能影響我們的全部持股。透過分散投資，可以受到「大數法則」的保護，除非大盤或多數類股都發生意外的反轉，才會對於整體部位構成嚴重傷害。

明智的分散投資，需要深入考慮成本／效益得失，尤其是涉及小額交易的話。我們或許希望自己的投資組合能夠完全代表道瓊工業指數，或涵蓋所有的主要類股。可是，如果資金很有限，這可能意味著每支股票只能持有幾十股，如此一來，佣金費率將是嚴重負擔，完全不適合進行短線交易。對於長期投資人來說，這方面的成本比較不會構成妨礙，因為所買進的股票，可能持有幾個月或數年之久。可是，
