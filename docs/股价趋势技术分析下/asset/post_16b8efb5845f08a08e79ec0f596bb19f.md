
出。最初，他相信%D與價格之間的背離現象，代表唯一有效的交易訊號。稍後，他表示這種說法未必全然正確，如果完全遵循這種方法，可能造成一些麻煩。

雷恩表示，當行情處在上升趨勢，可能出現好幾個頭部，通常有雙重頂、三重頂（關於這些排列的詳細資料，請參考第9章），所以真正的趨勢反轉可能要經過一些週折才會出現。他稱此為「垃圾頭部」。

當價格最後真的向下反轉，底部很快就浮現，然後價格又立即回升，呈現「突兀狀」的底部。這種情況可能出現在上升趨勢。對於趨勢明確的市場，這方面的知識可能會有幫助。

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_394_0.png)

圖189. 燕麥期貨價格與隨機指標走勢圖（1997年5月）。8月底與10月初，當%D在%K之間變動方向，代表價格趨勢將反轉。7月中旬與9月底，收盤價群集最低價。10月底與11月初之間，由於%K與%D都顯示最低讀數，意味著收盤價群集最低價。

## 讀數0與100的誤解

當%K出現0%或100%的極端讀數，有些人會誤會其意義。即使%K的讀數為100%，並不代表價格不會繼續上漲。反之亦然，即使%K讀數為0%，價格仍然可能繼續下跌。換言之，0並不代表價格底部；事實上，情況可能剛好相反。極端值100%與0%只代表價格走勢的強弱程度 ${}^{2}$ 。這方面的誤解，主要是源自於「超買」或「超賣」的概念。當%K與%D呈現75%以上的讀數，通常代表超買。反之，當隨機指標讀數低於25%，通常代表市場處於超賣狀況（有些交易者根據80%與20%定義超買與超賣）。請注意，對於持續性走勢，即使隨機指標已經進入嚴重超買或超賣狀態，價格可能持續朝該方向發展很長一段期間。

## 檢視週線圖與月線圖

不論是隨機指標或價格走勢，永遠要注意更高一層或更細一層的狀況。假定我們通常都觀察日線圖，必要情況下，也要分析週線圖，才能瞭解更長期走勢的狀況。更長期的走勢圖，有助於我們判斷目前市況隨後可能的發展。

隨機指標如果配合傳統的圖形分析與普通常識，相信可以運作得很好。舉例來說，如果趨勢沒有被破壞，而且沒有出現整理或反轉價格型態，那麼隨機指標提供的訊號很可能是假訊號。反之，如果出現等腰三角形，而且趨勢已經被破壞，這等於確認了隨機指標的訊號。

# 股價趨勢技術分析 (下冊)

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_396_0.png)

圖190。玉米期貨，1997年3月份契約。即使隨機指標讀數逼近0，行情處在嚴重超賣狀況，但價格還是持續下跌很長一段期間。很多人以為，只要隨機指標讀數逼近0，就代表價格隨時會向上反轉。某些情況下，隨機指標可以長期處在25%之下。就目前這個例子來說，隨機指標在9月初就開始下滑，到了9月下旬，讀數就逼近0，但價格持續下跌，一直到11月初纔開始回穩（但沒有回升）。

## 隨機指標計算公式

繪製隨機指標圖形，需要下列三項資料：

- 原始數值
- %K
- %D

這三項資料的數值都介於0與100之間。如果原始數值與%K繪製在同一份圖形上，結果是「快速隨機指標」。快速版本的隨機指標，波動比較劇烈，對於當前市況的反應比較敏感。如果採用%K與%D，則是「慢速隨機指標」，也就是前述快速版本經過平滑化的結果。

隨機指標原始數值 = $ \dfrac{\text{最近收盤價} - \text{20天期最低價}}{\text{20期最高價} - \text{20期最低價}} $

%K是原始數值的3天移動平均

%D是%K的3天移動平均

## 隨機指標資料更新公式

%K更新數值 = 2/3先前的%K數值 + 1/3新的原始讀數

%D更新數值 = 2/3先前的%D數值 + 1/3%K

原始數值需要有20天的資料；20天期最高價，是指最近20天之內的最高盤中價格，20天期最低價，是指最近20天之內的最低盤中價格。

隨機指數有助於分析商品交易的趨勢變動。這項指標已經有30多年的歷史，運用績效有長期紀錄可供查核。雖說如此，但如同絕大多數分析系統一樣，隨機指標在實際運用上，還是應該配合圖形分析與普通常識。請注意，我們的交易對象是商品價格，不是隨機指標或其他技術指標。技術指標雖然能夠提供幫助，但這些指標永遠要擺在市場架構上觀察。

## 成交量與未平倉量

投資人總希望看到「價漲量增，價跌量縮」的現象。對於股票交易，成交量是衡量人氣的重要指標。成交量也是期貨交易的重要指標，不過性質不太一樣。

### 成交量作爲確認

每天的成交量型態被視爲常態，任何突然變動都代表背離現象。成交量的重要性不若股票交易，相關資訊也延遲公布。成交量雖然屬於整體資訊的一部份，但大體上只能作爲（事後）確認，協助解釋其他指標代表的意義。

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_398_0.png)

圖191. 30年長期期公債，1997年3月份期貨契約。對於期貨交易來說，成交量不能推動行情，因為每個買方都對應一個賣方。成交量雖然很重要，但根據成交量預測後續發展，則非常不可靠。請注意11月份的情況，雖然價格繼續挺進，但成交量下降。

### 資金流量

未平倉量是透過一條曲線標示在成交量圖形上。原則上，未平倉量代表資金流入、流出市場的數量。如果交易雙方都建立新部位，未平倉量增加；如果某方新建立部位，另一方結束部位，未平倉量維持不變；如果雙方都結束既有部位，則未平倉量減少。

因為下列原因，未平倉量分析顯得更複雜：季節性因素（作物收成期間的避險活動最活躍）；投機性意圖；契約是否屬於最近交割月份契約（最好觀察所有交割月份契約的未平倉總量，而不是個別月份契約的未平倉量）；相關市場；相同市場價差交易。

下列表格說明未平倉量與成交量之間的關係：

| 未平倉量與成交量之間的關係 | | | |
|---|---|---|---|
| 價格行為 | 未平倉量 | 資金投入 | 行情 |
| 1. | 漲 | 上升 | 增 | 強 |
| 2. | 漲 | 下降 | 減 | 弱 |
| 3. | 跌 | 上升 | 增 | 強 |
| 4. | 跌 | 下降 | 減 | 弱 |

價格上漲而未平倉量上升，代表新資金流入市場。賣方提高價格，買方願意接受（買、賣雙方的數量永遠對等）。這是行情偏多的狀況。

價格上漲而未平倉量下降，意味著新的買盤減少，資金流出市場。價格上漲的動力，可能來自於空頭回補。空頭回補在短期內雖然有助於價格上漲，但這類交易一旦告一段落，漲勢將無以為繼。總之，任何漲勢如果沒有新資金襯托，就不能持久；可是，空頭回補的時間也可能拖得很長。

價格下跌而未平倉量上升，意味著新資金投入市場，但代表的是賣壓，屬於空頭現象。

價格下跌而未平倉量下降，這與第2種狀況相反。空方持續留在市場內，多方逐漸離場。市場沒有新資金流入，短期偏空而長期偏多。當下降動能減緩之後，空頭很快就會回補，新資金也經常會回頭。

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_400_0.png)

## 新資金

期貨的每個買盤都對應一個賣盤，所以價格穩定與上漲，動力來自於新資金。對於股票交易來說，市場力道可能來自於買方超過賣方，或賣方超過買方。對於期貨而言，上升趨勢的價格漲勢動力來自於新資金。新資金進場，未平倉量與成交量就會增加，但這些現象如果要具有真正偏多的意義，價格也必須上漲。可是，當我們看到這三個因素（價格、成交量與未平倉量）相互配合時，其代表的行為可能已經結束。

成交量與未平倉量資料雖然有助於判斷行情，但相關資料取得的時間可能稍嫌太晚，用以預測短期市況，恐怕很不可靠。其他指標提供的資訊可能更可靠一些，成交量與未平倉量可以用來評估概略市況，或做為事後的確認。

股票市場的情況則不同，成交量資料很重要，因為這方面的即時資訊很容易取得，而且買、賣雙方可能發生不均衡的現象。未平倉量可能具有某種程度的重要性，但就交易而言，其可靠程度不如其他指標${}^{3}$。

## 韋達的相對強弱指標 (RSI)

顯示相對強弱程度的指標（換言之，比較某證券價格與S&P500指數之類的基準），雖然已經存在很久，但威爾斯．韋達（J. Welles Wilder）發展的相對強弱指標（Relative Strength Index，簡稱RSI）則是針對行情變動而提供買、賣訊號的系統。

RSI經常可以根據其讀數來判斷行情頭部與底部（RSI讀數介於0～100，通常分別採用70與30來界定超買與超賣）。RSI也適用於：

- 1. 凸顯價格走勢圖不容易呈現的資訊。
- 2. 超買（70以上）或超賣（30以下）區域內的擺動失敗（swing failures），代表趨勢反轉的警訊。
- 3. 更清楚顯示支撐／壓力。
- 4. 價格與RSI之間的背離現象，經常是判斷趨勢反轉的有用指標。

RSI需要一些領先時間才能成功運作。

## 擺動失敗（W狀排列）

RSI出現突兀狀走勢而跌破30，然後向上回升，接著又出現突兀狀下降（但低點位置高於先前低點），當RSI再度回升而穿越兩個低點所夾峰位，代表買進訊號。同理，在超買區域也可以界定類似的賣出訊號；換言之，在70以上區域，RSI出現M狀走勢。

## 背離現象

對於任何技術指標來說，背離現象往往是最重要、最常見的趨勢變動訊號之一。所謂的背離，是指通常應該朝相同方向發展的指標，卻出現反向走勢，顯示當前的價格趨勢可能發生變化。背離通常是趨勢反轉的可靠訊號。我們所考慮的背離，可以發生在：道瓊工業指數／道瓊運輸指數、個別股票／大盤指數（譬如：S&P 500）、期貨價格／10—14天期RSI或其他。交易者往往會等待背離現象的確認，然後才實際進場，這是避開假訊號的有效方法之一。

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_403_0.png)

## 時間長度

14天是RSI最常見的期間長度，但也可以採用其他期間。當日沖銷或短線交易者經常採用6天期RSI做為獲利了結的工具：當指數向上穿越75而重新折返，代表賣出訊號。短期RSI對於當時市況的反應比較敏感。某些交易者甚至採用3天期RSI，用以判斷非超買、超賣區（換言之，介於30～70之間）交易的重新進場點。金融期貨也經常採用10天期RSI背離訊號；這通常適用於股價指數、債券與外匯。可是，對於其他市場，週的訊號比較罕見而不精確 ${}^{4}$ 。

![](img/1d6bd8f62a9f7f0ac427f3300ba0344b_404_0.png)

圖194. 30年公債期貨契約，1997年3月。RSI讀數70與30，分別界定超買與超賣區域。8月底，RSI跌破30，但程度並不大，代表14天RSI的偏弱買進訊號。11月中旬到12月初之間，RSI穿越70而擺動失敗，而且價格與RSI之間呈現背離，代表顯著的賣出訊號。

## RSI公式

RSI的根本觀念，是比較某特定期間內上漲收盤價之差價平均值與下跌收盤價之差價平均值的關係。所謂的特定期間，通常是取14天，但也可以採用其他期間長度。

RSI=100－{100/（1+U／D）}

U=上漲收盤價的差價平均值（上漲差價的EMA）

D=下跌收盤價的差價平均值（下跌差價的EMA）

RSI是一種運用很普遍的逆向操作擺盪指標。在很多市場上，RSI可以穩定提供超買／超賣的訊號，也能夠透過長期背離現象，顯示主要趨勢的頭部與底部。RSI提供的買、賣訊號，通常很明確，但可以針對長期或短線交易而調整指標的敏感程度。

價格型態讓交易者可以根據肉眼觀察走勢圖的狀況，判斷價格的可能走向，以及趨勢反轉的可能性。雖然價格型態技術分析已經有很長的發展歷史，其效力已經無庸置疑，但還是值得觀察這種方法與擺盪指標、價格帶狀、移動平均或其他技術指標配合運用的情況。事實上，如果交易訊號只發生在某技術指標，但得不到其他指標的確認，那就非常值得懷疑。不論哪種技術指標，也不論其可靠性有多高，偶爾總是會出現令人覺得沮喪的假訊號；可是，如果綜合運用數種技術指標，彼此相互確認，受到假訊號誤導的機會就會顯著減少。經過確認的訊號與趨勢，配合使用者的經驗，就是創造交易績效的保證。

## 商品／衍生性產品交易的重要觀念：

- 價格可能受到氣候、供需等外部因素的影響。
- 相較於股票交易，期貨交易的參與者，大多屬於避險者與投機客，交易時間架構較短。
- 期貨交易的契約數量基本上不受限制。
- 期貨契約有到期時間，這會影響價格。
- 停損單是一種必要工具。
- 擬定買賣決策，最好使用兩種或以上的指標。
- 不論價格或技術指標，趨勢線都是最重要的型態。背離現象則是最可靠的訊號之一。
- 價格型態分析可以與其他技術指標配合運用。
- 交易對象是價格，不是技術指標。
- 宏觀的看法，需要研究較長期的週線圖或月線圖。
- 技術指標的期間長度可以做調整，使得指標的反應變得更敏感（縮短期間長度）或變得更平滑（延伸期間長度）。
