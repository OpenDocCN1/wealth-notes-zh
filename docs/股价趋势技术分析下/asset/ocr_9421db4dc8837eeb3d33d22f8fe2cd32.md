# 一致性

龜族得到嚴格的指示，務必遵守進場訊號，因為每年的最主要獲利可能發生在少數 2、3 筆交易中，萬一錯過其中一筆重要交易，勢必會嚴重影響續效。

表現最好的龜族，都是那些嚴格遵守進場訊號的人。至於那些半途而廢，或不能嚴格遵守每個進場訊號的人，績效通常最差。

# 第5章 停損

龜族採用N為基礎的停損，避免帳戶淨值發生嚴重損失。

有種說法，「市場上有年長交易者，也有勇敢交易者，但沒有既年長、又勇敢的交易者。」不採用停損，交易者就註定破產。龜族絕對採用停損。

對於多數人來說，寧可期待虧損部位能夠轉敗為勝，也不願直接認賠，承認失敗。

讓我們先釐清一點。斷然認賠是絕對必要的。不願認賠的交易者，就不可能成功（長期而言）。幾乎所有發生失控的金融機構，例如：霸菱銀行、長期資本管理公司與其他，都是聽任交易員不願及時認賠而累積虧損，最終演變為傷及筋骨的損失。

關於及時停損，最重要者，是在建立部位之前，就必須設定停損點。如果價格觸及停損，交易者就必須出場，沒有其他選擇，一次例外都不能有。關於這點，如果抱著討價還價的心理，遲早會發生災難。
