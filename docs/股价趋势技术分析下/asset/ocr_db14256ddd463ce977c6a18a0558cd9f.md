# 附錄 C

設定較寬鬆的停損。停損設定的太緊密，很容易造成挫折感，也會平添交易成本。另外，對於相同部位，經常反覆也會造成困惑，增添風險。

太過寬鬆的停損，還可以進一步透過其他方法做修正，譬如：數學方法（例如標準差個數）、觀察圖形排列或分析支撐／壓力。把停損設定在當時交易的正常區間之外，則只有市場出現反向的異常走勢，停損才會被引發。經過一番練習之後，也可以改善這方面的停損設定。把停損設定在較遠距離之外，可以避免部位反覆的困擾，比較容易控制滑移價差與佣金費用；可是，整體投資組合風險也會變大。交易者究竟應該採用哪種停損設定系統，重點在於一致性的立場，儘量不要擺盪於這兩個極端之間，否則通常都會造成兩面不討好的結局（請參考第2篇）。

# 週線圖

日線圖可以提供交易的細節資訊，所以很重要，但日線圖通常應該配合較長期的週線圖或月線圖做評估。長期走勢圖可以由「宏觀」角度觀察當前的趨勢發展。「趨勢是你的朋友」，這個說法不只是用於股票，也同樣適用於期貨商品。
