# RSI公式

RSI的根本觀念，是比較某特定期間內上漲收盤價之差價平均值與下跌收盤價之差價平均值的關係。所謂的特定期間，通常是取14天，但也可以採用其他期間長度。

RSI=100－{100/（1+U／D）}

U=上漲收盤價的差價平均值（上漲差價的EMA）

D=下跌收盤價的差價平均值（下跌差價的EMA）
