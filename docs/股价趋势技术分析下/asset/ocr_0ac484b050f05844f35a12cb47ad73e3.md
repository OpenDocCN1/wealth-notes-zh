# 時間長度

時間長度由使用者選擇。對於股票而言，最常用的時間長度為10 天、30天、50天、100天與200天移動平均。可是，多數技術分析者都 根據個別需要综合运用這些時間長度。請注意，沒有所謂的「正確」 時間長度。時間長度愈短，移動平均對於價格變動愈敏感。時間長度 愈長，對於價格的反應愈不敏感，移動平均愈平滑。
