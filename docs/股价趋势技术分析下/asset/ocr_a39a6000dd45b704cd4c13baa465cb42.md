# 建立新部位

+   1. 順著道氏理論（大盤）的主要趨勢方向，或是基於避險理由而建立少量的逆勢部位。

+   2. 突破頭肩排列。

+   3. 突破等腰三角形，但突破位置不可以在頂點的三分之一距離內。

+   4. 直角三角形突破。

+   5. 矩形突破，或許也可以在第 6 個反轉點接觸排列邊界的位置。

+   6. 擴張頂突破。

+   7. 突破雙（多）重頂或雙（多）重底。（所謂「突破」是指價格向下穿越頭部所夾的最深谷底，或向上穿越底部所夾的最高峰位。）

+   8. 突破楔形排列，或許也可以在楔形頂點的三分之一距離內建立新部位。

+   9. 旗形與三角形旗形排列內發生足夠幅度的次級或修正走勢；如果成交量與其他技術條件都強烈確認該型態，或許可以在型態內建立新部位。

+   10. 有效貫穿明確的支撐／壓力。

+   11. 突破缺口（或許可以）。

+   12. 在延伸性走勢之後發生明確而重要的島狀反轉。

+   13. 上升趨勢發展過程，價格接觸或穿越底部的紅色趨勢線，但兩條趨勢線都必須順著主要趨勢方向。

附註：突破與貫穿都是指收盤價而言，並且要得到成交量確認。突破的收盤價需要符合 3% 準則。
