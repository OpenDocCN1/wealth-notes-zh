# 附錄 E

收盤或隔天開盤。對於開盤跳空缺口，如果開盤時段出現突破，龜族在開盤進場建立部位。

系統1進場——如果盤中價格穿越最近20天的最高價或最低價，即使穿越程度只有1檔，龜族也會進場建立部位。如果價格穿越最近20天的最高價，龜族進場買進1單位，建立相關商品的起始多頭部位。反之，如果價格跌破最近20天的最低價，龜族進場放空1單位，起始建立空頭部位。

如果最近的突破曾經導致獲利，則忽略這次的系統1突破進場訊號。附註：就這個檢定來說，最近突破是指特定商品最近發生的突破，而不論該突破訊號被接受，或是否因為目前這個規定而被忽略。突破訊號被接受之後，在價格還沒有到達10天期獲利了結價位之前，如果朝相反方向出現2個N的走勢，則視為失敗部位。

最近突破的方向與這個規定無關。所以，失敗的多頭突破或失敗的空頭突破，其引發的新突破將被視為有效進場訊號，不論突破方向如何（可以建立多頭或空頭部位）。

可是，如果因為前一筆交易成功而造成系統1突破進場訊號被忽略，則要根據55天期突破訊號進場，避免錯失主要走勢。這個55天期突破被視為「萬全突破點」（Failsafe Breakout point）。

任何時候，如果我们停留在場外，總有某個價格會引發放空進場訊號，並有不同而更高的價格引發買進訊號。如果前一次突破訊號造成虧損，相較於前一次突破訊號造成獲利來說，新的進場訊號會更接近目前價位（換言之，20天期突破）；如果前一次突破訊號造成獲利，則新的進場點會距離目前價格更遠（在55天期突破位置）。

系統2的任何突破訊號都必須接受，不論前一個突破訊號成敗與否。
