圖190。玉米期貨，1997年3月份契約。即使隨機指標讀數逼近0，行情處在嚴重超賣狀況，但價格還是持續下跌很長一段期間。很多人以為，只要隨機指標讀數逼近0，就代表價格隨時會向上反轉。某些情況下，隨機指標可以長期處在25%之下。就目前這個例子來說，隨機指標在9月初就開始下滑，到了9月下旬，讀數就逼近0，但價格持續下跌，一直到11月初纔開始回穩（但沒有回升）。

# 隨機指標計算公式

繪製隨機指標圖形，需要下列三項資料：

+   ● 原始數值
● %K
● %D

這三項資料的數值都介於0與100之間。如果原始數值與%K繪製在同一份圖形上，結果是「快速隨機指標」。快速版本的隨機指標，波動比較劇烈，對於當前市況的反應比較敏感。如果採用%K與%D，則是「慢速隨機指標」，也就是前述快速版本經過平滑化的結果。
