# 第 21 章

# 圖形選股策略 I

如果交易者根據「基本面」統計數據進行操作，他需要分析公司的盈餘、股利、管理能力、產業經營展望……等，這方面分析通常只能侷限在少數各股或某個產業類別內。

另一方面，技術交易者透過日線圖可以操作很多股票，因為他主要是關心股票的技術型態，不必深入研究每家公司的背景。事實上，股票本身的性質將反映在市場行為上，這方面考量的重要性，遠超過公司經營或盈餘狀況。股票雖然代表公司所有權，但資本結構、「槓桿」與股票流通籌碼將決定股價波動，而這一切與公司業務經營之間，未必保持穩定的關係。

我們經常發現，許多備受推崇的老牌績優股，雖然財務報表顯示最近獲利成長，股利分派的長期紀錄也很穩定，但當時股價未必代表適合買進的對象。股價或許高估，公司或許即將攤提大量費用。另一方面，某些股票的盈餘表現、股利紀錄都不理想，但突然出現一系列投機性漲勢，成為適合買進的對象。為什麼？因為紀錄只適用於過去，不代表未來；價格走勢圖經常反映一些投資大眾不清楚的事實。
