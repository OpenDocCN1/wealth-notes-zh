# 股價趨勢技術分析．（下冊）

如果價格觸及包寧傑帶狀上限，而且RSI讀數大於70（可能逼近80），意味著漲勢可能反轉下跌。反之，如果價格觸及包寧傑帶狀下限，而且RSI讀數小於30（可能逼近20），意味著跌勢可能反轉上漲。

# 隨著市況調整

包寧傑帶狀的實際寬度，會隨著價格波動程度而自行調整，並不是採用某種固定寬度。換言之，這項指標是反映市場的行為，而不是規定市場應該怎麼做。圖形分析的基本立場也是如此，所以這兩項工具非常適合搭配使用。

# 隨機指標

隨機擺盪指標（Stochastic Oscillator）是喬治・雷恩（George Lane）根據證券收盤價位在特定期間內價格區間之相對位置而設計的技术指標。根據雷恩的理論，行情處在上升趨勢，收盤價會偏向最高價；反之，行情處在下降趨勢，收盤價會偏向最低價。上升趨勢愈趨於成熟，收盤價朝最高價靠攏的偏頗程度愈顯著；同理，下降趨勢愈趨於成熟，收盤價朝最低價靠攏的偏頗程度愈顯著。

# 群集

隨機指標嘗試衡量價格在上升趨勢過程，什麼時候開始向最低價群集，或在下降趨勢過程，什麼時候開始向最高價群集。根據雷恩的理論，這種現象代表既有趨勢即將反轉。
