# 股價趨勢技術分析（下冊）

![](bbox=[0.19, 0.12, 0.91, 0.42])

圖226. 這個例子顯示趨勢線如何發展為趨勢通道。我們曾經提到，趨勢通道比較容易由事後角度觀察，但發生當時很難掌握，股價走勢只會偶爾出現完美的通道。這些通道總會結束，而且經常是毫無預警地突然結束。就目前這個例子來說，長期趨勢通道可以提供反轉的預警。

1946年，FJ由48下跌到30支撐區。然後，由該處開始展現3個月期的漲勢，形成上升趨勢通道，將股價推升到2月份的頭部37。次一波跌勢向下突破通道，底部發生大量。如果長期觀察這支股票的走勢，將發現反轉點總是出現大量，而且總是發生在觸及趨勢線的位置。另外，下降趨勢發展過程，修正反彈走勢總是止於先前的小型頭部；反之，在上升趨勢發展過程，下跌修正走勢總是止於先前的小型頭部。在趨勢通道內進行交易，獲利相當不錯。2月份之前的次級回升走勢，是由1946年的底部40開始，然後由1946年的峰值48下跌到30，下跌過程可以在37放空。如果建立這個空頭部位，稍後可以在3月1日當週的第一次挫跌過程回補（33 1/4）。如果在34 1/2建立空頭部位，可以在3月15日的一週內回補於31 1/2。如果空頭部位建立在3月22日當週的漲勢過程（大約在31），將於5月24日當週的高潮大量回補；當天是夾著大量的單日反轉線形，代表空頭部位的警訊。由5月中旬開始的上升通道，屬於中期回升走勢，幅度應該相當有限，如果沒有明確理由，似乎沒有強烈動機建立多頭部位。
