# 第27章 停止單

能需要增加一半（就百分率而言）。換言之，停損應該設定在最近小型底部下側的7.5%處。為什麼？因為股價25的價格正常波動區間，根據統計是15.5%，股價5的股票，正常波動區間是24%。所以，5%×24/15.5大約等於7.5%。

同理，我們也可以根據敏感指數設定停損。如果前述股票（股價5）的敏感指數為1.33，則上述結果乘以1.33，停損距離是10%。如果敏感讀數是2.00，則停損距離是15%。如果敏感讀數為0.66，停損距離為5%。

總之，將股價的正常波動區間除以15.5，然後乘以敏感指數，再乘以5%。我們可以根據這種方法計算停損距離（表示為百分率）。如果透過計算機或電腦，這部分計算很單純。

對於一般讀者來說，前述討論或許太過複雜。我們非常能夠理解，大多數交易者都不會花費功夫計算精確的停損。可是，我們還是決定提出一套有系統的停損設定方法，讓讀者充分瞭解其中原理。如此一來，如果讀者決定根據自己的經驗進行調整，也知道如何著手。

下列表格式根據股票的敏感指數與價位，列示前述方法約估的停損距離。通常參考這份表格就足夠了。

### 停損距離(表示為股價的百分率)

| 價格 | 保守型股票 敏感指數低於0.75 價格波動率低於0.40 | 一般股票 敏感指數介於0.75~1.25 價格波動率0.41—0.79 | 投機型股票 敏感指數高於1.25 價格波動率超過0.79 |
| :--- | :--- | :--- | :--- |
| 超過100 | 5% | 5% | 5% |
| 40到100 | 5% | 5% | 6% |
| 20到40 | 5% | 5% | 8% |
| 10到20 | 5% | 6% | 10% |
| 5到10 | 5%ᴬ | 7% | 12% |
| 5以下 | 5%ᴬ | 10% | 15% |

附註:一般來說，這個價格區間的股票都不屬於保守型股票。
