# 第3章 部位規模

龜族採用價格波動率為基準的固定百分率風險，做部位規模控制。

對於任何交易系統，部位規模是最重要、但也是最容易被忽略的關鍵。龜族採用的部位規模計算方法，當時屬於最先進的觀念，因為部位規模是根據市場的價格波動金額調整，所以是把價格波動金額常態化為部位單位。換言之，不論哪個根本市場的價格波動程度如何，相同單位的部位規模，其每天價值波動都是一樣的。

為什麼？價格波動愈劇烈，每單位代表的契約口數會對應變小；所以，價格波動非常劇烈的市場，其每口契約的價值波動雖然很大，但由於部位的契約口數較少，整體部位的價值波動將類似於其他採用相同單位的部位。

這種價格波動常態化的程序非常重要，因為不同市場的部位，所發生的盈虧金額會趨近於相同。這可以讓分散交易更有效地降低風險。

即使某市場的價格波動很小，但只要出現夠大的趨勢，還是可以創造顯著的獲利，因為對於這類市場，龜族會持有相對龐大的部位。
