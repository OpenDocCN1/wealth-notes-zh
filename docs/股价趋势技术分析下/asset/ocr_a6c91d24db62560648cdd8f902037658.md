# 第23章 高風險股票的挑選與管理

交易者由網際網路狂飆行情中獲利，但最後得以避開重大傷害。很多經理人與交易者只能在一旁羨慕地看著，泡沫破裂時刻充滿著幸災樂禍的快感。

對於那些根據本書倡導原理進行投機與交易的技術分析者，可以在投機性狂熱行情中掌握重要機會，在恐慌性走勢中買進；換言之，當那些無知群眾競相追逐噴出行情時，他們繼續保持冷靜，採用既有的方法。另外，在很多重要方面，投機性噴出行情與大多數趨勢末期之間很類似。

所以，問題是如何在這類狂熱期間，取得一些利益。這類狂熱行情來來去去：有時候發生在生化科技類股，有時候是電腦類股，有時候是網際網路，甚至是基因藥物或火星房地產。請注意，相關獲利應該來自於多邊與空邊。投資大眾只知道由多邊致富。專業玩家與技術交易者（不論是否靠交易謀生）則知道如何由空邊獲利。

關於這些飆漲股票，最重要的觀念是：本書談論的所有技術與方法，都同樣適用於這些股票。除此之外，還有一些需要額外考量的性質。相關類股，不論是高科技、生化科技、網路科技、網際網路、太空旅遊……等，其本身就是一個市場，蘊含特殊的技術因素。整個市場的生命週期，由承接、吸引、上漲、狂熱，乃至於噴出等階段，在時間上都會高度濃縮，遠短於正常股票根據基本面資料發展的循環週期（請參考圖205.2的網康掌上型電腦Palm Computing走勢圖）。
