# 股價趨勢技術分析.(下冊)

綜合考慮前述幾個因素，價格在20附近的股票，通常最能夠提供有效的槓桿效果。股價的篩選區間，可以分別向下與向上延伸到10與40。如果股價高於40或低於10，就必須有非常明確的交易理由。所以，適合交易的大部分股票，股價應該介於10到40之間，除非有很特殊的緣故，才可以交易高價股或低價股。

可是，如果回顧這些股票過去的長期交易歷史，可以發現某些股票的價位非常接近，但行為模式卻截然不同。舉例來說，當大盤回檔時，某些股票可能跟著向下修正20%；換言之，股價由30下跌到24左右。可是，面對著相同的大盤環境，另一些股票的回檔幅度可能更深，或許是50%；換言之，由30跌到15。另外，還有一些股票，其回檔幅度可能與大盤相當。那些回檔幅度較緩和者，漲勢過程的上升幅度也相對有限。同理，那些大幅回檔的股票，多頭行情的漲勢也特別凶猛。這些現象與先前討論的高價股／低價股相對走勢之間並沒有關係，基本上是取決於股性；請注意，股性通常會保持很長一段時間。

我們發現，相較於相同價位的其他股票，某些投機性股票的價格攪動幅度較大。反之，某些價格比較低的股票，其價格攪動幅度也低於價位較高的股票。這個事實顯然違背先前談到的，價格相對偏低的股票，其價格攪動幅度通常大於價格較高的股票。唯有當我們考慮價位之後，才能察覺股性所代表的意義。瞭解這點，才能評估股價與股性的綜合影響。

. 前文提到，我們對於走勢沈悶的個股沒有太大興趣。我們偏愛那些價格攪動幅度大的股票。我們可以計算股票的基本攪動力量，稱其為「敏感指數」(sensiiivity index)，細節內容請參考附錄A。編者附註：馬基此處談論的敏感指數，可以視為「貝他值」(betas)的前身。某股票之貝他值，是指其相對於整體股票市場的價格波動程度。
