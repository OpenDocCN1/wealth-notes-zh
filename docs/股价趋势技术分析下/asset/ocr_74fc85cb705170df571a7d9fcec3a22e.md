# 第18章 戰術問題

最重要者，短線交易者可以因此而避免恐慌性行情。某些情況下（1929年絕對不是僅有的個案；編者附註：1987年與1989年也是。第9版附註：如果願意的話，還可以加上2001～2002年的例子，包括：2001-05-21，道瓊指數11350；2001-09-17，道瓊指數9062；2002-03-18，道瓊指數10673；2002-07-22，道瓊指數7532），長期投資人將眼見自己幾年來辛苦累積的獲利，在幾天之內被一筆勾消，但短線交易者可以透過停損單出場，接受些許虧損而保留絕大部分資本；一旦行情發展出新的趨勢，他們可以又是生龍活虎。編者附註：對於「現代」技術分析者來說，即使是長期投資人，也不該被動接受空頭市場。唯有銀行信託部門或華爾街的大型承銷商才會建議繼續持有股票，因為他們不敢建議一般散戶賣出而得罪主要的法人客戶。

最後，在我們正式討論戰術主題之前，希望釐清一點，此處所討論的操作，是針對小額或中等資金規模的交易者而言。我們建議進、出場的方法，涉及的股票數量可能是畸零股、100股、200股或1000股以上，實際數量取決於相關股票的市況與成交量。這些方法不適用於鉅額交易（例如：單筆交易超過10,000股者），因為這類數量的買賣，通常會嚴重影響行情。鉅額交易操作屬於特殊領域，雖然所考慮的基本趨勢與策略還是一樣，但必須採用不同的市場戰術。編者附註：有一次，馬基曾經對我說，老鼠能夠到大象不能去的地方。
