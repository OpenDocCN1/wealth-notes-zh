# 第18章 戰術問題

盈虧的認定，不論採用「實現」（交易結束）的基準，或採用「帳面應計」基準，兩者都沒有問題，但顯然不應該藉由某種方法來掩飾自己的錯誤，然後用另一種方法來凸顯自己的成功。這類觀念混淆，經常造成財務上的重大悲劇。（編者附註：就目前的環境來說，這種混淆態度可以說是「一廂情願」的行為。現在，市面上有投資組合管理的套裝軟體，這類軟體都是按照市價計算部位的價值，如此可以避免自欺欺人的行為。）

對於技術性交易者來說，或許應該採取比較現實的觀點，根據帳面的應計基準來考慮盈虧。換言之，某特定期間的盈虧，應該以股票當天收盤價為基準來衡量。

總之，我們應該（a）避免將股票與公司混為一談，不該將兩者視為一體或對等；（b）不可有意或無意地把股利孤立到股價之外，認為股利代表股票的「價值」；（c）避免混淆「實現」與「應計」的虧損$^{1}$。

技術交易者沒有必要採用「買進－持有」策略。某些情況下，顯然應該長期持有部位，甚至是數年之久。可是，某些情況下，合理做法事斷然出場，不論當時是獲利或虧損。如果市況顯示不該繼續持有某個部位，成功交易者——基於情緒緣故——絕對不會堅持已經變得不可能的看法，並斷然出場。

有經驗的交易者可以利用技術分析方法，掌握較短暫的中期趨勢攞動，使其獲利程度超過主要趨勢所允許的獲利幅度，雖然這類短線操作可能造成較高的佣金與稅金成本。
