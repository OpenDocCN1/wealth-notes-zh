Dow—Jones Utility Average （道瓊公用事業指數）：1929年，公用事業類股由道瓊工業指數分離，另外成立20支成分股的公用事業指數。1938年，成分股數量減少為目前的15支。

Downtick （向下跳動）：這是指證券成交價格向下跳動；換言之，交易價格較前一筆交易的成交價格低。

Downtrend （下降趨勢）：參見「下降趨勢」(Descending Trend)。

Drawdown或Retracement （淨值減損）：特定期間內，帳戶淨值由相對高點到相對低點之間的差距。最大淨值減損，則是衡量特定期間最高淨值到最低淨值之間的差值。

End Run （收場走勢）：當價格突破等腰三角形之後，重新折返三角形頂點的支撐（向上突破）或壓力（向下突破）。這個名詞有時候泛指失敗的突破走勢。

Equilibrium Market （均衡市場）：代表供需力量維持均衡的價位。

Ex—Dividend （除息日或除權日）：（或除權）而調整價格的日子。

Ex—Dividend Gap （除息缺口）：股價因為除息（或除權）而產生的向下跳空缺口。

Exercise （執行）：這是指選擇權持有人（買方）執行其買進或賣出選擇權根本資產的權利。
