# 股價趨勢技術分析（下冊）

![](bbox=[0.17, 0.12, 0.93, 0.49])

圖239. （左上）1956年底，大盤走勢沈悶而稍顯疲軟。可是，West Indies Sugar突破連續弧狀排列，展開自己的多頭行情。

圖240. （中上）1956年春天，大盤雖然持續創新高，但西屋電器較大盤提早一年做頭，展開主要的空頭走勢。

圖241. （右上）這是25年之前Eagle—Picher的翻版。許多類似如Kresge的藍籌績優股都沒有參與1953～56年的多頭行情。

這6份走勢圖都取自Graphic Stocks （F. W. Stephens, New York）。1927～30年的圖形是取自特別版，涵蓋1924～35年的700支股票。1953～56年的圖形是取自稍後的版本。
