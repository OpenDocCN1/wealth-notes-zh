# 第27章 停止單

我們將討論兩種不同的停止單（stop orders），也可以說是由兩個截然不同的角度使用停止單。

首先考慮保護功能的停止單（譯按：譯文有時候稱為「停損單」）。不論怎麼說，這都不是令人覺得高興的話題。這類停止單就像滅火器，使用的時候，心情都很不愉快。唯有當情況發展非常惡劣，而且大概沒有挽回機會時，我們才會運用這類停止單。

停止單不論設定在哪裡，似乎經常都會在最糟情況下被引發。對於多頭部位而言，停損可能設定在某個底部下緣的安全距離處。結果，股價向下穿越該底部，引發停損之後，馬上形成新底部而準備下一波攻勢，或立即向上反彈而創新高。雖說如此，我們還是要設定停損。建立部位之後，股票如果出現不合理的走勢，不按照牌理出牌，當然也不是朝我們預期的方向發展；面對這種情況，最好斷然出場，即使必須承認損失，總勝過隨後的種種不確定與焦慮。股票發生不利走勢，我們不知道後果將有多嚴重，如果不設定停損，可能會日復一日地期待那永遠不會發生的反彈，股價愈盤愈低，最後將發現（如同
