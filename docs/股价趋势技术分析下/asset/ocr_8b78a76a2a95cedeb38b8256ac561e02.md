投資組合絕對要定期評估一些重要的統計數據，避免無意之間承擔過高的風險。重要的統計數據包括：

+   每筆交易起始風險

+   實際發生虧損

+   每筆交易平均獲利與平均虧損，以及兩者之間的關係（平均獲利除以平均虧損）

+   成功與失敗交易筆數，以及兩者之間的比率

+   成功交易與失敗交易所花費的時間（部位持有時間很長，而且又發生偏高虧損，這是不祥的徵兆）

+   淨值變動：平均淨值減損與最大淨值減損

+   成本與費用，每筆與加總數據

+   每天風險、年度風險與災難性風險（按照下文討論的實用投資組合理論建議的方式計算）

# 單一股票的風險

傳統或學術界的風險分析，起點是探討價格波動率。

本書第24章曾經討論價格波動率的計算公式。相關公式與理論所做的一些假設，在實務上未必有意義。這類假設之一，是持股者接受股票本身的價格波動率。可是，技術分析的目的，是侷限前述接受的風險，同時還要實現獲利機會。因此，假定股票的價格波動率為30%；可是，當我們進行交易時，會透過停損策略來侷限風險在5～8%範圍（相當於總交易資本的2～3%或X%）。所以，相較於理論，我們的風險控制更具動態性。雖說如此，價格波動率還是衡量個別股票
