# 楔形排列

我們沒有必要詳述說明這種排列過程的交易法則，因為趨勢線相互收斂的情況一旦明朗化之後，支撐╱壓力與趨勢線的一般法則，應該可以讓持股人及早脫身。即使在最糟情況下，停止單也應該可以讓投資人在局面嚴重惡化之前出場（當然，前提是投資人必須設定停止單）。

如果考慮建立新的多頭部位（下降楔形向上突破）或空頭部位（上升楔形向下突破），應該要觀察成交易量變化：向上突破需要成交量確認，向下突破的第一階段不需明顯大量。新部位可以建立在突破之後的折返走勢（回檔或反彈）。

# 單日反轉

相較於先前討論的反轉或連續排列來說，單日反轉不是一種適合交易的技術型態。這種排列的主要功能，是用來判斷小型走勢的頭部與底部，藉以保護既有部位。當小型走勢發展數天之後，如果出現單日反轉、竭盡缺口或不尋常大量，都是既有走勢即將結束的強烈徵兆；其中任何一種訊號都值得參考；如果是兩種同時出現，可靠性更高；倘若若是三者同時出現，幾乎可以代表明確的小型頭部或底部。

如果希望根據單日反轉線形進行交易，不免有些賭博意味，而且只適合極短線的進出，性質上不同於本書討論的大部分交易。有關單日反轉的交易意涵與一般建議，請參考本書第10章。
