# 股價趨勢技術分析(下冊)

參見「複雜頭肩型態」（Complex Head— and— Shoulders）。

Narrow Range Day（交易區間狹小的日子）：當天的交易區間相對小於先前的交易區間。

Natural and Unnatural Methods or Systems（自然或不自然的方法或系統）：這是伯西第半開玩笑的說法，所謂的「自然方法」是直接觀察市場資料而進行分析，譬如：圖形分析；所謂的「不自然方法」，則是透過某種運算方法處理市場資料，間接進行分析，譬如：擺盪指標、移動平均等。

Natural Hedge（自然避險）：伯西第根據馬基構想而發明的一種技巧，投資組合永遠存在某種程度的多、空搭配，主要用以防範價格下跌（或上漲），屬於不完全避險。譬如說，做多DIA而放空相對弱勢的成分股。

Neckline（頸線）：頭肩型態中，這是銜接「右肩」折返低點（高點）與「頭部」折返低點（高點）的直線。當價格穿越頸線的幅度超過3%時，就可以確認反轉型態完成。在菱形排列中，頸線的定義也類似於頭肩型態，但形狀是V狀或A狀，參見「菱形」（Diamond）與「頭肩型態」（Head— and— Shoulders）。

Negative Divergence（負性背離）：兩個或多個股價指數或技術指標，彼此不能相互確認。

Normal Range For Price（價格正常區間）：編者附註：馬基發明的一項分析工具，用以衡量股票的價格波動程度。就目前觀點來看，這種工具太複雜，但很有趣。請參考附錄A。

Odd Lot（畸零股）：單筆交易數量不足整數股（整數股通常指100股而言）。
