# 第8版 編輯說明

修訂一部經典作品，壓力確實很大。關於應該如何修訂，每位批評者或讀者都有意見，包括是否應該不著痕跡地修改作者的原文，假裝作者當時能夠預知未來，讓整本書看起來像是在2000年編寫而不是1948年，其他還包括：編輯錯誤與年份錯誤是否應該保留，或者做註腳，以及其他等等……等等。（我不理解英文作文老師長久以來的抗議，仍然引用馬基最愛使用的「等等……等等」（etc., etc., etc.）因為我喜歡這種好像能夠召喚無限擴張宇宙的感覺）。

雖然每位讀者都可以有意見，但我相信所有批評者應該都希望在第21世紀，能夠繼續引用這本編寫於第20世紀的技術分析經典作品。
