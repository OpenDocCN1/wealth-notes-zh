# 期貨走勢圖技術分析
(採用數字導向的方法)

編者附註：這篇附錄是由第7版編輯理查·麥德莫特根據該版第16章內容重新整理而成，可以視為數字導向技術分析的一篇介紹文章。讀者如果想進一步研究期貨技術分析，請參考（高度推薦）傑克·史瓦格的《史瓦格期貨技術分析》（中文版，請參閱寰宇出版公司）。

第9版附註：讀者務必要瞭解這篇附錄與本書提到的數字導向技術分析，其目的與意圖何在。這篇附錄並非針對期貨領域的數字導向技術分析做全面性的介紹，而只是想讓讀者瞭解這方面發展的概況。本書作者（以及編輯）都屬於圓形分析師，採取自然系統。我相信，如果由勝任的圓形分析師進行這方面的工作，此處所介紹的方法可以運作得更好。
