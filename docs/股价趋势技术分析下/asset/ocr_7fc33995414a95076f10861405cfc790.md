# 導論

此處希望引用哈佛大學名譽校長詹姆士·布萊恩·康諾特（Jarnes Bryant Conant）的一篇評論《瞭解科學：一種歷史方法》（On Understandlng Science: An Historical Approach）做為本書第II篇的導論。

康諾特博士指出，學校教育告訴我們，科學是有系統的蒐集事實，經過分門別類、分析、檢視、整合與沈思，然後一套偉大的理論就產生了，簡潔完美，立即可以實際運用於工業、醫療或其他方面。

這是大多數外人對於科學的誤解，重大發現都是一點一點累積而成的，整個過程經常籠罩在疑問之中，唯有抽絲剝繭才能逐漸明朗化，形成一套精確而具有明確證據的理論。最後顯示在整齊表格內的基本資料，一系列的證明與核對，這一切在剛開始的時候完全不存 在，唯有透過時間、精力、智慧與經驗的彙整，才逐漸成形。事實上，這可能是另一批人的工作結果，他們提出部分結論，然後再被整合而架構為更完整的理論。我們不可能透過「頓悟」瞭解市場行為的相關理論。這些理論是由許多有經驗之交易者／研究者逐步累積而
