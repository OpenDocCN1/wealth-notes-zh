# 名詞解釋

量指標，由約瑟夫·葛蘭碧 (Joseph Granville) 發明。OBV的結構很單純：根據當天價格收高或收低，分別把當天成交量指派為某正數或負數。如果價格收高，成交量指派為正數；價格如果收低，成交量指派為負數。然後，根據收盤價漲跌而加減當天的成交量，結果繪製為OBV曲線。重點是觀察OBV的方向變動（而不是成交量數據）。

公式：

+   - 如果今天收盤價>昨天收盤價

則OBV=昨天OBV＋今天成交量

+   - 如果今天收盤價<昨天收盤價

則OBV=昨天OBV－今天成交量

+   - 如果今天收盤價=昨天收盤價

則OBV=昨天OBV

**One-Day Reversal (單日反轉)**：參見「島狀反轉」(Island Reversal)。

**Option (選擇權)**：選擇權買方有權利在特定期間內，根據固定價格，買進 (買權) 或賣出 (賣權) 100股根本股票或一口根本期貨契約。選擇權買方享有權利而沒有義務，必須支付權利金給賣方，賣方只有義務而沒有權利。

**Order (委託單，交易指令)**：參見「限價單」(Limit Order)、「市價單」(Market Order) 與「停止單」(Stop Order)。

**Options Research, Inc. (選擇權研究公司)**：布萊·胡爾 (Blair Hull) 創辦的機構，後來稱為胡爾交易公司 (Hull Trading Co.)，首先採用電腦化的B—S選擇權定價模型。

**Oscillator (擺盪指標)**：一種動能或變動率的指標，讀數通常定義在＋1與－1之間，或0%與100%之間。
