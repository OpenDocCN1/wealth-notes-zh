# 第 20-A 章 挑選適當的股票：長期投資觀點

此處討論的SPDRs性質，適用於所有的指數股（包括：DIAMONDS、WEBs……等）。當然，運用指數股也涉及一些費用與成本，但程度遠低於一般基金。對於個人投資者來說，指數股的運用比較具有彈性。撇開其他優點不談，這種工具讓投資人得以控制稅金問題，這在基金是不可能的。

其他交易所也推出類似的證券交易工具、衍生性產品或期貨，藉以複製著名的股價指數。這包含追蹤羅素（Russell）、日經指數（Nikkei）的股票、指數股或期貨，也有期貨或指數的選擇權，還有一大堆奇奇怪怪的交易、投資、避險工具。這些產品之中，比較重要的有芝加哥期貨交易所的道瓊工業指數期貨與期權；芝加哥商業交易所的各種指數期貨（包括：S&P、日經225種股價指數、迷你S&P500、S&P中型股400種股價指數、羅素2000與那可司達克100）；芝加哥選擇權交易所的S&P 100與S&P 500選擇權。當然，還有其他的交易工具。凡是比較重要的期貨或選擇權，通常都會顯示在《華爾街日報》的期貨報價與選擇權報價欄位。

本書並不打算深入討論期貨與選擇權。可是，這些相關產品還是值得一提，因為不論投資人或交易者都可以運用指數股或股價指數來進行避險，當然也可以用來從事投機。

簡言之，避險就是讓整體部位處於中性狀態，其價值不受市場行情波動影響。舉例來說，交易者可以做多DIAMONDS，並買進CBOT的道瓊工業指數賣權。如此一來，如果道瓊指數上漲，DIAMONDS將獲利，但賣權價格將下跌。反之，如果道瓊指數下跌，賣權價格將上漲，但DIAMONDS會發生虧損。請注意，避險並不是本書的主題，所以這只是一個過度簡化的例子。雖說如此，但這個例子還是點出避險的重要性。投資人如果認為行情可能發生變化，可以採取避險
