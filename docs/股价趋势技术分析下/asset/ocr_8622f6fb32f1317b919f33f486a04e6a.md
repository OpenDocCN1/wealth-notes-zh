# 股價趨勢技術分析(下冊)

另一方面，保護性停損單普遍適用於一般交易者，如果沒有充分的時間隨時注意盤面發展，或沒有足夠的經驗，就可以透過這種工具侷限損失。這種工具可以迫使交易者結束不利部位，避免讓自己套在毫無指望的部位上，無奈地看著虧損持續積積。只要停損遭到引發，部位就會自動結束，如此可以保留足夠的資金從事其他交易，不需繼續擔心或指望已經泡湯的部位。

可是，如果具備足夠的知識與經驗，能夠判斷出場訊號，而且能夠判斷採取行動，就沒有必要實際遁入停止單。編者附註：編者個人認為，唯有真正的好手，才可以不用停止單而留在場內。讀者如果要知道自己是否屬於「真正的好手」，不妨檢驗自己的股票組合，看看是否曾經讓不必要的虧損持續擴大？是否曾經因為過早賣出而錯失重大獲利？若是如此，各位就還稱不上「真正的好手」。假定具備前述條件，停止單可能反而會造成妨礙，因為停止價位可能被假走勢或延伸性洗悶折返走勢引發。另外，對於長期部位來說，交易者或許願意接受次級折返走勢，停止單當然也不適用於這種情況。可是，對於一般投資或交易大眾而言，通常還是應該採用停止單，避免在60買進，然後看著價格一路下跌到29，或5！

# 注釋

+   1. 根據推斷，如果股票已經完成預期中的獲利走勢，並且出現小型頭部的成交量訊號，隔天可以將停止賣單設定在前一天收盤價下方1/8點處。如果股票當天繼續上漲，沒有出現異常成交量，則保留原來的停止賣單不再調整，直到另一個爆發量或小型頭部訊號發生為止；換言之，唯有在發生大成交量、跳空缺口或單日反轉，才把停止賣單移到當天收盤價下方1/8點處。這種方法往往優於逐日調整停止單。
