# 第35章

技術性交易對於市場行為的影響

人們經常提出一項質疑：股票市場呈現的型態與趨勢，是否來自交易者採用的技術性方法？換言之，股票市場並非呈現客觀的現象，而是在某種程度內，反映交易者採用的技術方法。

這方面質疑似乎站不住腳。我們今天繪製的圖形，仍然遵循舊有的型態；我們有強烈理由相信，遠在技術分析者開始研究這些股價型態之前，市場行為長久以來就是遵循這些型態。本書第1篇曾經提到，保證金規定與人為操作限制等法規方面的變動，導致市場行為的一些調整，但完全沒有影響市場的基本性質。

股票市場是一個非常、非常龐大的機制，其規模絕對不是任何個人、企業或集團所能夠操縱。（第9版附註：到了第21世紀，市場規模已經不只是「大」而已了；事實上，已經是不可思議。）市場運作非常自由、非常民主，綜合反映每位買家與賣家的希望與恐懼。並非所有的市場參與者都是短線交易者。市場上還有投資人、企業家、公司員工，他們是為了持以股票而買進，唯有經過幾年之後才會賣出。總之，市場上存在各種身份背景與參與動機的買家與賣家。
