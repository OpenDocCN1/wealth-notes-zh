# 編者附註：分散投資與成本

馬基在本章的原稿中，討論分散投資可能引發的成本問題。就目前市場情況來說，投資人很容易採用SPDRs與DIAMONDS或其他類似工具，根據相當合理的成本，達成分散投資的目的。一般投資人也可以採用指數型基金或共同基金，從事分散投資，相關成本也可以得到控制。談到成本或費用的問題，共同基金的效能當然不如指數股 (Index Shares)，因為共同基金涉及一些指數股沒有的費用：管理費、滑移價差、碼差、周轉費用，以及實現獲利的稅金問題。散戶投資人如果小心的話，這些成本都可以避免。

某位國際著名的交易者曾經告訴我，而且不止一次，如果他是一般的交易大頭的話，那麼經紀人或專業報價商就可以從他的交易中賺走大筆財富。他擁有的最重要武器，就是芝加哥、紐約與舊金山等交易所的席位。

此處透露的訊息很清楚。一般投資人必須控制成本。雞蛋每過手一次，就會輕掉幾分。所以，交易頻率愈高，資本流失程度也就愈嚴重，得利的是經紀人、專業報價商、場內交易員、造市者、稅務當局、交易所本身，以及其他等等。甚至電話公司都可以分杯羹。

交易成本是經紀商最不願意談的問題。長久以來，佣金費率都是由華爾街交易機構與交易所控制，但進入網路時代之後，情況截然不同了：過去交易所不願意做的削價競爭，現在變成了削喉戰，而且證管會與商品期貨交易委員會也不阻止。

當然，本書並不適合做這方面的成本分析，因為處在網路時代，成本數據瞬息萬變，任何資料很快過期了。
