# 個別股票的綜合槓桿

我們可以根據這篇附錄第A章（編者附註：第7版的第24章）介紹的方法，計算每支股票的敏感性指數，然後再根據下列方法計算每筆買進或放空交易的綜合槓桿指數：

+   S代表股票的敏感性指數。

+   N代表價格正常波動區間（以最初進行交易的價位為準）。

+   T代表最初交易所支付或收取的總淨額。

+   C代表該筆交易的自付款。如果現金買進股票或支付100%的保證金放空股票，則這項數據將與分子的T相互沖銷。

於是，

綜合槓桿 =  $ \frac{SNT}{15.5 \times C} $

（請注意，15.5是股價25的正常波動區間，也是我們任意選擇的基準。）

# 整體交易組合的綜合槓桿

整體交易組合的綜合槓桿，即是成分股承擔風險的總和，計算公式如下：

交易組合綜合槓桿 =  $ \frac{Sum\ of\ SNT}{15.5 \times Total\ Capital\ or\ New\ Worth} $
