Averaging Cost (攤平成本)：投資人在不同價格分批買進股票或商品的一種方法。如果根據較低價格分批買進，稱為「向下攤平」 (Averaging Down)；如果根據較高價格分批買進，稱為「向上攤平」 (Averaging Up)。

Axis (座標軸，軸心)：繪製圖形的座標軸，是衡量刻度的一條基準直線。有時候，「軸」也代表排列內真實或想像的一條直線，整個排列能夠以「軸心」為準而旋轉。

Balanced Program (平衡式交易計畫)：將資本 (或一部份資本) 劃分為兩等份，分別做多與做空市場。

Bar Chart (長條圖)：又稱為「線路圖」 (line chart)。利用圖形表示價格資料的一種方法，以一條垂直線段銜接特定時間單位內最高價與最低價；開盤價在線段左側標示為小橫劃，收盤價在線段右側標示為小橫劃。長條圖可以取任何長度的時間單位，只要該時間單位可以提供繪圖用的價格資料。最常見的時間單位是小時、天、週與月。可是，隨著個人電腦與即時報價系統的普及化，交易者往往可以根據「分鐘」為單位繪製長條圖。

Basic Trendlines (基本趨勢線)：參見「趨勢線」 (Trendlines)。

Basing Point (基準點)：價格走勢圖上，決定停止價位的重要參考點。當技術條件發生變化時，基準點與停止點可以調高 (多頭部位發生有利漲勢) 或調低 (空頭部位發生有利跌勢)。參見「逐次停止單」 (Progressive Stops)。
