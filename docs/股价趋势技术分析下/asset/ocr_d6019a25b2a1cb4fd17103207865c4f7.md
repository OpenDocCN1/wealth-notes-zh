# 股價趨勢技術分析(下冊)

![](bbox=[0.18, 0.14, 0.92, 0.46])

圖205.1. 微軟日線圖。微軟提供諸多啟示。可是，短暫的樂趣。股價做頭之後，曾經試圖進行另一波攻勢，但動能顯然已經不足以了。1月份的逃逸線形，清楚顯示多頭陷阱，由10月份以來的短期趨勢線，應該可以讓交易者脫離多頭陷阱。採用第28章介紹的基準點技巧，也可以脫離陷阱。失敗訊號通常也是建立反向部位的進場訊號，目前這個例子就是如此。

首次公開募股（IPO）的時候，內線玩家已經準備出貨了。舉例來說，2000年，當網康掌上型電腦（Palm Computing）由母公司網康（3Com）分離而單獨上市，大約只賣出3%股票（故意減少市場供給籌碼，把股價推升到荒謬的地步），其市值甚至超過擁有絕大多數該公司股票的網康母公司。第9版附註：我們知道首次公開募股（IPO）有所謂的「架梯」（laddering）。客戶如果想要取得即將上市股票，承銷商要求他們在股票上市之後，透過公開市場買進更多股票。這是一種很高明的「火上加油」策略。我們不知道網康掌上型電腦是否有「架梯」。
