# 何謂投機客？何謂投資人？

自從馬基寫下第 18 章以來，「投機客」與「投資人」代表的意義已經截然不同。事實上，整個文化結構已經產生重大變化。紐哈芬鐵路被推崇為典型投資型股票的時代已經過去了。由本世紀以來，企業界發現投資人對於股利的看法產生變化。投资人要的是資本利得，更本不關心股利的問題。不發放股利甚至被公認為「成長型股票」的特性。所以，紐哈芬鐵路的時候已經結束了，當時所謂的投資人是為了取得股利而買進股票，而「投機客」則是馬基這類操作中期趨勢而買進「投機性」股票的人。

昨日的投機客，可能是今天所謂的中期投資人。
