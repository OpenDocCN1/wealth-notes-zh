# 股價趨勢技術分析(下冊)

也同樣棘手，他們不知道如何獲利了結。因此，他們可能過早出場而喪失主要獲利機會，或是停留過久而吐回幾乎到手的大部分獲利。

如果各位確實瞭解本書各章節討論的內容，就應該瞭解沒有任何技術排列或訊號絕對萬無一失。股價走勢圖會反映目前已知的所有訊息（包括：已經宣布或可能發放的股利，計畫中的分割或公司合併，政治事件對於股票市場的可能影響，世界局勢，公司管理，盈餘報鉤與其他等等）。走勢圖不會、也不能預測無法預測的事件，這些屬於任何人都不能預知的发展。多數情況下，走勢圖非常可靠。如果各位不認為如此，就應該更深入研究，或完全放棄圖形分析。

反之，各位如果認為圖形確實可靠，大體上能夠顯示股票未來的發展方向，那就應該嚴格遵守圖形提供的訊號，或直接採用我們提供的法則，或透過個人經驗修正法則，完全根據法則進行交易。總之，各位如果準備根據某套方法或準則進行交易，就必須嚴格遵守。這是交易法則能夠發揮效益的唯一途徑。

各位如果能夠辦到這點，從一開始就能掌握明顯的優勢：（1）各位永遠不會因為單筆交易結果而破產，不會讓單筆交易勾消全部交易資本；（2）當行情發生不利走勢，各位不會不知所措而讓虧損繼續累積，不會讓資金套牢而不能針對新趨勢進行交易；（3）各位可以冷靜擬定決策，清楚知道獲利了結的訊號，也瞭解認賠出場的適當限度。

這一切都意味著各位將心平氣和地進行交易。各位會接受損失，也會創造獲利。可是，不論發生哪種狀況，各位都不會徹夜難眠。各位必須擬定一些策略。如果交易發展很順利，會在適當價位獲利了結。如果行情發展不順利，則會即時認賠，另尋更適當的對象，只要資本沒有受到嚴重傷害，隨時都可以再度進場。
