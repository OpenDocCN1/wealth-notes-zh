# 股票趨勢技術分析(下冊)

Overbought（超買）：市場價格漲幅過大，速度太快。

Overbought / Oversold Indicator（超買／超賣指標）：一種技術指標，嘗試衡量速度太快而幅度過大的價格走勢，藉以判斷可能發生的折返。

Oversold（超賣）：市場價格跌幅過大，速度太快。

Panic（恐慌）：空頭市場的第二階段，買方不願接手而賣方急著脫手。價格突然加速下跌，成交量暴增，參見「空頭市場」(Bear Market)。

Panic Bottom（恐慌性底部）：參見「賣壓高潮」(Selling Climax)。

Pattern（型態）：參見「區域型態」(Area Pattern)。

Peak（峰值）：參見「頭部」(Top)。

Penetration（貫穿）：價格穿越型態的邊界、趨勢線或支撐／壓力。

Pennant（三角旗形）：三角旗形類似於旗形，但三角旗形的邊界相互收斂，旗形邊界相互平行。參見「旗形」(Flag)。

Point & Figure Chart（圈叉圖）：一種繪圖方法，據說是由道氏發明。方格紙的刻度可以任意設定，每天價格變動分別在垂直欄標示X（上漲）與O（下跌）。繪圖時，預先設定反轉格數，如果價格變動程度沒有到達反轉格數，則視為趨勢繼續發展，不需換欄繪圖。如果價格變動程度超過反轉格數，則換欄繪圖。圈叉圖不考慮時間因素。

Premature Breakout（過早突破）：價格突破區域型態之後，稍後又重返型態。最後，價格會再度朝原先方向進行突破。過早突破發生當時，我們沒有辦法判斷是假突破、過早突破或真突破。
