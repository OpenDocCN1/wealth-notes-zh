# 放空股票（建立空頭部位）

+   ☺ 放空準備訊號（顯示潛在放空機會）。價格穿越紅色趨勢線，收盤價創新（多數情況下）。（如果沒有其他型態或技術現象配合，只是價格穿越上升的紅色趨勢線，並不足以為趨勢向下反轉的結論性證據。）
   —價格觸及下降的紅色趨勢線，藍色趨勢線也在下降狀態，但兩條趨勢線不可相互收斂（換言之，必須是平行或發散的趨勢通道）。
   —價格觸及水平狀紅色趨勢線，藍色趨勢線也是水平狀或向上發展（向下突破矩形或下降三角形）。
   —價格夾著大量穿越上升的紅色趨勢線（不論成交量是否放大），藍色趨勢線處於下降狀態（向下突破等腰三角形）。
☺ 執行放空（放空準備訊號發生之後）
   —如果先前的紅色趨勢線處於下降狀態，繪製紅色平行線而在附近買進。
   —如果先前的紅色趨勢線為水平或上升狀態（換言之，矩形、三角形或其他反轉排列的向下突破），放空位置設定在價格反彈到前一波小型跌勢幅度的40～45%之間（前一波小型跌勢幅度，是指最近走勢極端谷底到前一個小型峰位之間的距離）。
