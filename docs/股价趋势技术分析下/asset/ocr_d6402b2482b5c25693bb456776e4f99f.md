# A、股票的可能走勢

(第7版原來的第24章)

乍看之下，所有股票的價格似乎都呈現毫無意義的起伏漲跌。股票經常齊漲齊跌，雖然時間不完全相同。可是，我們知道，這些股價漲跌走勢，大體上都會遵循某種趨勢，呈現各種型態，其行為並非毫無秩序。

一般來說，每支股票都有其特殊的股性，而且這種股性在一系列多、空循環過程內，始終非常穩定。處在多頭行情，某些股票會展現強勁的漲勢，另一些類似價位的股票，則只有中等程度的漲幅。可是，這些強勁向上擺動的股票，在空頭市場也會呈現類似程度的向下擺動，而那些漲勢有限的股票，則具有顯著的抗跌能力。本書附錄A的第B章將討論綜合槓桿，其中顯示某些股票的走勢幅度，經常是另一些股票的數倍。舉例來說，我們不知道Glenn Martin（編者附註：或微軟）往後一年的股價將上漲或下跌；可是，不論這支股票的走勢
