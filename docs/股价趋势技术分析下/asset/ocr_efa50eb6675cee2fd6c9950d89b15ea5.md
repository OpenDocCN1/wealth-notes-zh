# 到期展延

期貨契約到期展延為新契約之前，需要考慮兩項重要因素。

第一，很多情況下，最近交割月份契約的趨勢很顯著，但遠月份契約則沒有類似的價格走勢。所以，除非遠月份契約呈現既有部位的類似價格走勢，否則不做展延。

第二，契約展延必須在成交量與未平仓量還沒有顯著下降之前進行。何謂顯著下降，當然取決於部位規模。原則上，龜族都會在既有契約到期之前的幾個星期之前進行展延，除非當時持有的既有月份契約，其價格表現明顯優於遠月份契約。
