# 股價趨勢技術分析（下冊）

很好，某天你發現成交量突然暴增（假定當天不是突破先前小型頭部的第一天），你取消先前的停損單，決定在最新收盤價下方1/8點處設定有效期一天的停止賣單。舉例來說，假定當初在21買進股票，停損設定在18。隨後，價格夾著中等成交量上漲，但大量突破前一個小型頭部23，接著成交量又恢復中等程度，股價繼續挺進到23 3/4與24 1/4，最後在25爆出大量，該處的成交量甚至超過23的突破量。隔天早晨，你發現成交量警訊，於是取消18的停損，重新在24 7/8設定當天有效的停止賣單。一般來說，當天早晨的開盤價很可能會直接引發停止單，結果你的出場價格可能稍低於前一天收盤價。另一方面，由於前一天的成交量很大，當天的成交量應該不至於巨幅萎縮；所以，早晨開盤的時候，如果價格下跌，停止賣單應該可以成交，實際出場價格照道理不會距離昨天收盤價太遠。

可是，如果股票持續朝有利方向發展，你仍然持有部位，可以繼續獲利。當你把停止賣單設定在24 7/8之後，假定當天開盤價為25 1/4，收盤價為26。（典型的逃逸缺口，價格很可能收在最高檔附近 3/8。）隔天早晨，當天有效的停止賣單重新設定在25 7/8。假定開盤價為26 3/8，收盤價為28；隔天開盤之前，再把停止賣場單設定在27 7/8，假定當天開盤引發停止單，結果在27 5/8出場。這個例子中，相較於大成交量當天根據25賣出股票，你只在隔天多承擔 1/8點或稍多的風險，結果多賺了2 5/8點。請注意，這是額外的淨獲利，因為在25或27 5/8賣出股票，佣金成本大約相同。
