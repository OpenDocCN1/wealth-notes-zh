# 第33章 圖形戰術評論

![](bbox=[0.07, 0.13, 0.82, 0.64])

圖223. 旗形與三角旗形是快速走勢過程常見的整理型態，排列經常位在整段走勢的中點附近（其他結構緊密的型態也可能如此）。

MRT由1944年低點4，上漲到12附近，然後在10～12之間形成長達7 個月的矩形排列。5月初，價格夾著大量向上突破，然後出現3個星期的旗形排列。請注意旗形排列之前的快速漲勢，以及該波漲勢端點的大成交量。當價格進入旗形排列之後，成交量顯著萎縮。整個排列的折返幅度不大，在先前小型峰位14 1/2附近獲得支撐。

突然之間，價格又夾著大量向上突破，該波漲勢直奔24 3/4。如果交易者仍然持有股票，或在旗形排列買進（大約在15），應該會在6月6日價格到達19 7/8時賣出，因為當時的成交量顯著放大。
