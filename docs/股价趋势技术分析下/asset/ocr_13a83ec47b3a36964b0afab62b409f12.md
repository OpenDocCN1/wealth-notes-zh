# 按照市況韻律進行投資

另外，投資人或許可以按照行情發展的自然韻律，並配合馬基的評估指數，慢慢把投資組合由多轉空（這是本書第31章「分散投資」的內容重點）。這是本書作者與編者偏愛的策略。

當然，這一切都取決於投資人本身設定的目標、個性。如果各位準備整天泡在市場，或許就不是長期投資者。長期投資者通常可以吃得好、睡得好。至於短線交易者，則隨時覺得飢渴、準備採取行動（未必是為了錢）。每位市場參與者都應該瞭解自己是投資人或交易者。不過，各位最好不要在市場內評估自己的個性或類型，因為市場可能是尋找自我的最昂貴場所。

長期投資人沒有理由不能針對中期趨勢進行操作，這取決於投入資本的數量，也取決於個人準備花多少時間與精力於股票市場。長期投資策略不需花多少時間與精力。投資人只需要留意大盤指數與主要類股指數，在向上突破、底部盤整或拉回走勢中買進。然後在價格跌破趨勢線、計算基準點（參考第28章）與支撐區遭到貫穿的情況下賣出。

相較於中期交易者或投機客，長期投資人願意忍受更大的行情擺動。讓我們利用第28章的基準點方法做為例子來說明，投機客可能採用「3天法則」，長期投資人可能運用4星期的基準點。另外，如果願意的話，投資人一旦認定多頭行情已經接近頭部，也可以改採3天法則，甚至每天調整出場停止點。可是，請注意，專業玩家都知道很多投資人把停止點設定在前一天收盤價的稍下方。
