# 時間刻度

每張圖形涵蓋一整年的走勢圖，把橫軸劃分為53個星期，每星期佔6天，濃線（垂直方向）代表星期六，由於主要市場星期六都休市，所以星期六的位置通常都留白。濃線劃分讓我們很容易觀察每個星期之內的天地數，星期六留白不會顯著影響技術型態的趨勢。

如果碰到假日，圖形可以留白，並在橫軸適當位置標示「H」代表假日。

圖形通常都是由每年1月1日開始繪製，時間軸上，只需要在每個星期六標示日期，並將月份標示在適當位置。當然，我們沒有什麼理由一定必須在年初開始繪圖；如果準備繪製大量股票的圖形，最好分為四個部分，每個部分都由某一季的季初開始繪圖。譬如說，公司名稱稱為A～F者，圖形由1月1日開始繪製；G～M者，由4月1日開始繪製；N～S者，由7月1日開始；T～Z者，由10月1日開始。
