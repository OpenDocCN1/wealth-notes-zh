# 名詞解釋

都相隔很開，中間所夾的折返走勢相當平緩而幅度很深。三個峰位的成交量有下降的傾向。這種排列往往又稱為「W狀」，尤其是當第二個峰位的價格低於第一個與第三個峰位。當價格跌破三個峰位所夾的最深谷底時，三重頂排列即告完成。

200—Day Moving Average Line（200天移動平均線）：加總最近200天的收盤價，結果除以200。

Uptick（向上跳動）：這是指證券交易價格向上跳動而高於前 筆交易的成交價格。

Uptrend（上升趨勢）：參見「上升趨勢線」（Ascending Trendline）與「趨勢」（Trend）。

Utility Average（公用事業指數）：參見「道瓊公用事業指數」（Dow—Jones Utility Average）。

V／D Volume（V／D成交量指標）：這是價格上漲股票成交量 對價格下跌股票成交量的比率。所謂「價格上漲」是指當天收盤價高 於前一天收盤價；所謂「價格下跌」是指當天收盤價低於前一天收盤 價。就50天比率來說，分別計算價格上漲股票與價格下跌股票的成交量總和，然後將前者除以後者。

Validity of Trendline Penetration（有效貫穿趨勢線）：當趨勢 線被穿越時，透過下列三種方式判斷穿越是否有效（如果貫穿無效， 原來的趨勢線仍然維持功能）：（1）貫穿幅度，（2）貫穿過程的成交量，（3）貫穿之後的交易狀況。

Valley（谷底）：兩個峰位之間所形成的V狀價格走勢。參見 「雙重頂」（Double Top）與「三重頂」（Triple Top）。

Volatility（價格波動率）：根據股票過去12個月的每天價格資料，計算股價波動的程度。
