# 趨勢線

價格趨勢通常可以持續相當長的期間，順著趨勢發展方向建立的部位，績效通常比較理想。如同股票走勢圖一樣，上升趨勢線是銜接波浪狀走勢低點的一條直線，下降趨勢線則是銜接波浪狀走勢高點。很多圖形分析者會沿著波浪狀走勢的高點與低點分別繪製趨勢線，如此會呈現交易通道。繪製趨勢線，可以採用盤中高價或低價，也可以
