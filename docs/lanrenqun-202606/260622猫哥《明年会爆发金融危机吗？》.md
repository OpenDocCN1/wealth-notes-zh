 # 明年会爆发金融危机吗？

260622 猫哥星球

整理：公众号懒人搜索，懒人专属群精选
懒人微信：lazyhelper1

这个话题很火，也是很多星友关心的问题，今天就来给大家谈谈我的看法。

明年爆发金融危机，这个观点是高志凯首先提出来的，其依据大致有三点：

1. 老美债务不可持续，39万亿国债已经到了天花板，明年难以持续。
2. AI估值泡沫，一旦泡沫破裂将引发资本市场巨震。
3. 地缘政治冲突给全球经济带来巨大不确定性，比较典型就是中东冲突导致霍尔木兹海峡被关闭，高油价推升全球通胀与供应链危机。

我承认，以上都是我们需要关注的风险点，但是距离爆发金融危机还差一大截，就像是一个人去做体检，查出肺上有一个结节，然后就预言这个人马上就要得肺癌一样——高志凯的观点多少有点危言耸听了。

为什么？

首先，现在与2008年相比全球有几个比较显著的区别：

![](img/0d00e099848fde38e756642cc6274c54_0_0.png)

# 其1

老美与中国都没有较大的毒资产这颗大雷，这个很关键。2008年是全美MBS/CDO次贷打包卖给全球银行→雷曼倒→银行间互信冻结→全球信贷骤停。目前美债虽高，但它是全球无风险资产锚，没有同等规模的“有毒衍生品”在全系统泛滥。

美债39万亿规模是否是天花板，是否不可持续，这个不是某个人大嘴一张说了算的，而是市场投资者真金白银说了算。截止当下，老美长中短不同国债市场认购都保持在2.33倍这个水平，至少目前老美国债市场认购还是比较活跃的，目前未来较长一段时间，还看不到老美国债出现流动性危机的风险，换句话说，老美国债还远远没有到顶。

# 其2

现在全球各国的金融监管和防火墙已大幅强化。目前全球主要银行资本充足率、流动性覆盖率（LCR）要求大幅提高，大行抗冲击能力强于2008年前。新兴市场防火墙更好，多数新兴市场改固定汇率为浮动或有管理浮动，外储储备能力远远强于2008年，同时债务结构相比2008年也更为优化——短期外债占比下降，中长期外债占比上升，不容易出现大面积债务违约而影响市场恐慌的局面。

说实话，现在全球只要几个主要大国不出现债务违约，一些小国家出点问题其实都没啥大的问题。另外，值得指出的是，现在全球央行对于危机干预的能力更强，态度更坚决，比较典型案例就是2020年因为疫情导致美股系统性崩盘，然后美联储第一时间站出来宣布为美股提供无限流动性，一下子就稳定了市场的信心。

# 其3

AI企业估值目前确实偏高，确实也有泡沫，但是目前AI头部企业是有盈利支撑。头部科技股像英伟达、微软等都有真实现金流，不同于2000年纯概念网络股，即使回调更可能是修正而非连环崩塌。

最后就是地缘政治冲突，这个确实是难以预测的黑天鹅。但是也是有一定规律可循的。我们以美伊冲突为例。美伊冲突一爆发，当时我就有一个基本判断，这场冲突是不可能持久的，最多三个月左右，无论如何不可能持续半年，现在回头来看这个判断是基本正确的。

为什么我做出冲突难以持久的判断呢？原因无他，伊朗经济太脆弱，是没有条件支撑长期战争的。同时这场冲突也让我们看到另一个点，就是老美也没有想象中那么强，也没有能力维持长期战争。所以未来即便爆发黑天鹅地缘政治冲突，我同样相信，不管是强势方还是弱势方，其实都很难持久，所以地缘政治冲突对全球经济影响有限，远未到引发全球金融危机或者经济危机的地步。

以上就是我判断明年出现金融危机可能性很小的逻辑。

但是未来全球经济与金融也不是没有风险点的。

在债务市场，我看空日元汇率与日本国债，中方两用物资管控出口正在慢慢勒紧日本产业的脖子，这个效果不是短期呈现，而是随着时间的累积效果会越来越明显，叠加日本年年贸易逆差，日元汇率是非常脆弱的，当然，日本几十年积累还是有一定的家底，家底没耗尽之前，日元汇率会跌，大概率还没到崩盘的地步。

在资本市场，美股科技AI板块估值处于历史高位，若盈利不及预期，可能出现大幅调整。

地缘与能源冲击，中东局势推高油价、贸易碎片化、关税摩擦，加大输入性通胀和经济下行压力。

中国因资本账户管制、政策空间较大，受全球直接冲击相对可控，但外需下滑会影响出口。至于内需就要看房地产了，啥时候房地产企稳，居民资产负债表不继续衰退，那么内需消费才有可能摆脱目前疲软的状态。
