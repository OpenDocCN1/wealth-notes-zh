


# 新格伦火箭爆炸，暴露了美国商业航天的困境

文/卢克文工作室嘉宾 风雨如歌

当地时间2026年5月28日，美国私人太空公司蓝色起源的下一代火箭“新格伦”，在进行静态点火测试时突然发生爆炸，损失极为惨重。

说起美国的商业航天，大家可能只知道马斯克的SpaceX，没听说过什么蓝色起源。蓝色起源不是什么野鸡初创公司，它的创始人，是亚马逊创始人、全球第四富豪贝索斯。

特朗普和马斯克渐生嫌隙后，投入很多资源扶持蓝色起源，希望它能担负起抗衡SpaceX的重任。然而，这次大爆炸，彻底击碎了特朗普的厚望。爆炸不仅摧毁了蓝色起源的下一代火箭，还炸掉了发射台，彻底打乱了NASA重返月球的“阿尔忒弥斯”计划的节奏。

![](img/bcd068a353d67bb101170e35779add8a_0_0.png)

那么，这次爆炸是怎么回事？它暴露了美国商业航天的什么困境？

## 01

5月28日晚9时，佛罗里达州卡纳拉维尔角太空军基地LC-36发射台，新格伦火箭准备点火。

新格伦火箭高98米，直径7米，起飞质量约1500吨，近地轨道运力45吨，同步轨道13.6吨，核心动力是7台BE-4发动机和2台BE-3U发动机。显然，新格伦火箭对标的是SpaceX的王牌火箭“重型猎鹰”。

作为全球第二款重型可复用火箭，新格伦火箭在2025年进行了两次试验，均取得成功，很有希望正式服役。按照计划，新格伦火箭6月4日就要执行任务，在此之前需要进行静态点火测试。

起初，情况一切正常，但就在点火后的第2秒，意外发生了！最左侧的BE-4发动机，突然蹿出诡异的橘黄色火焰。

BE-4的燃料是液氧甲烷，正常燃烧时应该是蓝白色，火焰变成橘黄色，明显是出现了故障。最有可能的情况，是燃料泄漏。由于燃料泄漏，燃烧不充分，会产生大量碳颗粒，颗粒在高温下被烧得发红发黄，火焰看起来就是橘黄色。

点火后第3秒，橘黄色火焰开始从发动机舱，向外、向上疯狂蔓延，像贪婪的火蛇，吞噬箭体底部。一级燃料箱底部封头被高温烧穿，上百吨推进剂泄漏。

点火后第4秒，爆炸发生。巨大的火球瞬间吞噬箭体，并产生了巨大的冲击波，冲击波从底部向上传导，火箭的一级、二级箭体被炸成碎片。大爆炸形成的蘑菇云高达几十米，炙热的火光刹时照亮了整个海岸。

更严重的情况出现了。爆炸造成的碎片四处飞溅，最大的碎片重达数吨，砸落地面引发二次火灾。在这一过程中，LC-36发射台被火灾摧毁，脐带塔和避雷塔轰然倒塌，起竖设备几乎报废。爆炸还冲击了不远处的总装厂房，气浪直接掀掉了厂房屋顶，多栋建筑着火。

事后估算，爆炸当量约1100-1500吨TNT，是广岛原子弹威力的五分之一，据说几公里外一些房屋的玻璃，都被冲击波震碎。唯一值得庆幸的是没有人员伤亡。

目前，故障的原因尚未公布，但各方普遍猜测，问题出在BE-4发动机的涡轮泵密封件，密封件出现脆裂，直接导致了爆炸的发生。

这一部件之所以极易出问题，根源在于它必须在极寒与极热交替的极端环境中工作。火箭加注的液氧、液态甲烷，温度非常低，最低可至零下一百多摄氏度，推进剂流经涡轮泵内部时，会持续为泵体降温，让整体处于低温状态。而BE-4采用富氧分级燃烧循环，预燃室会产生上千摄氏度的高温燃气，驱动涡轮泵高速运转，高温燃气又不断炙烤泵体与密封结构。

一冷一热的剧烈温差，让材料反复热胀冷缩，很容易出现微小裂痕，导致燃气外泄，进而引发爆炸。就像一根棍子，一头冻得像冰窖，另一头又热如火焰山，时间一长，棍子就会变脆。

谁能想到，一场原本难度系数并不高的测试，会造成如此重大的损失。

## 02

这场大爆炸，不但暴露了蓝色起源的弱点，更暴露了美国商业航天的虚弱。

如今美国的商航竞争格局，是SpaceX一家独大，SpaceX这种垄断地位，显然会影响美国的国家安全和太空战略。

SpaceX为啥快速发展起来？根本原因是发射成本极低，报价足够便宜。但是，SpaceX垄断美国的发射市场后，立马换了一副面孔，动辄涨价，吃相难看。

比如2011年“猎鹰9”的发射报价仅为5000万美元，平均每公斤不到5000美元，是当时全球最低价。结果呢，猎鹰9一路涨价，2026年开年整体报价高达7400万美元，平均每公斤超过7400美元。

问题在于，“猎鹰9”火箭的制造成本大幅下降，从4000万美元出头，下降到不足1500万美元。SpaceX疯狂涨价割韭菜的行为，让美国国防部和NASA非常不满。

“美以伊战争”期间，美军为打击伊朗，使用了大量“卢卡斯”无人机。美军的用法，是给“卢卡斯”无人机装上“星链”，再按预定轨道飞行，相当于一枚便宜的导弹。

马斯克表示，五角大楼支付的“星链”费用标准，是民用版（每套大约5000美元）的，但你却用在了军事上，不行，加钱！必须加钱！可是，军用版“星链”的费用，要比民用版贵整整5倍。

对马斯克来说，只要美国政府重度依赖SpaceX，他就有极强的议价权。当然，马斯克不需要也不可能去硬刚五角大楼，他办法多的是，比如“星链”卫星发生故障，网络出现中断，技术问题啊，真不是我故意的。

如果马斯克在“星链”上做手脚，“卢卡斯”无人机可能就成了睁眼瞎。出于国家安全的考虑，美国政府急需扶持其他太空公司，打压SpaceX的嚣张气焰。

它们希望看到的局面，是SpaceX、蓝色起源、ULA三家相互制衡。ULA是波音+洛马合资，看似阵容强大，但波音这些年的拉胯有目共睹。

2024年6月，波音“星际客机”送两名宇航员上太空，原定8天返回，结果飞船一路掉链子，故障不断，把人困在空间站9个多月。最后还是靠SpaceX的龙飞船把人接回来。

波音有的毛病，ULA一个不落，烂泥很难扶上墙，稍微能指望的是蓝色起源。但是，ULA和蓝色起源，和SpaceX有个重要区别，很多核心零部件不是自己研发的，而是从全球各地买来组装的。

就拿蓝色起源研制的BE-4发动机来说，这款发动机是和ULA共用的，而且是用在两家公司最先进的火箭上。换句话说，BE-4任何一个供应节点出问题，都可能直接锁死美国两支最重要的现役/准现役重型火箭。

如前文所述，这次新格伦火箭爆炸后，初步调查就是指向BE-4发动机涡轮泵系统故障。而BE-4核心泵壳部件，主要由印度Aerolloy Technologies供应。外界推测，爆炸可能与这批外购铸件存在材料或工艺缺陷有关。

蓝色起源为啥不买美国供应商的呢？因为买不到。美国的基础航天工业正陷入衰退，零部件供应商数量大幅减少。

美国航天工业协会的报告显示，2000年时，密封件生产商还有超过10家，到了2024年，只剩下3家左右，产量极其有限。

这次出事的部件是不是来自印度，还不好下论断，但蓝色起源被迫引入外部供应商，本身就说明了问题。

当美国火箭的核心部件和材料，高度依赖于全球供应链时，会发生什么？一旦供应商那边出问题，或关键特种材料被限制获取，都会严重拖累美国的太空进程。

不要以为SpaceX就不存在这些问题。为什么竞争对手火箭爆炸，原本应该受益的SpaceX估值也同时下调了呢？因为所有人都担心供应链风险。

SpaceX的猎鹰9号，已经到了运力极限，根据SpaceX招股书，它未来几乎所有业务的增长，都以下一代火箭“星舰”按期商用为前提。

那么，星舰目前能不能按期商用呢？目前来看困难重重。SpaceX要实现年产万艘星舰的目标，据估算要配套33万台猛禽发动机，但是，SpaceX的猛禽发动机，目前也不具备大规模量产能力。

原因在于，虽然SpaceX零部件80%自产自研，但是，在耐高温合金、特种钛材等核心关键材料上，SpaceX依然需要依赖外部供应链。尤其是航天级铌钨合金、高温熔模铸件、箭体及发动机精密锻件等高精尖特种材料和外协件，SpaceX离不开中国供应链的配合。

SpaceX的另一个痛点是星链和未来的太空数据中心需要海量的高性能芯片，而高端芯片的关键材料镓和钪，都属于中国关键矿产的出口管制范畴。别说SpaceX，整个美国，都面临镓和钪库存的枯竭问题。

现在，新格伦火箭爆炸，光修好发射台就得18个月。在特朗普任期结束前，我们都很难再次见到新格伦火箭发射了。

如果新格伦、星舰不能量产，美国的登月计划将会大大受阻。实际上NASA已经将原定2027年的阿尔忒弥斯3号“载人登月”计划，改为了“在轨对接测试”。

说到底，新格伦火箭的爆炸，不是单一的技术事故。制造业空心化，让美国的航天产业链日渐脆弱，配套供应商锐减、品控下滑，就连密封件都难寻靠谱国货。

从客机口碑崩塌，到飞船频繁翻车，老牌航天巨头早已不复往日荣光。特朗普全力扶持蓝色起源，本想打破SpaceX的垄断，摆脱马斯克的牵制。如今伴随一声巨响，美国对蓝色起源的巨额投入打了水漂，制衡SpaceX的设想又一次落空。
