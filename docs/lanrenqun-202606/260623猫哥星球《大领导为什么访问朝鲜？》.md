


# 大领导为什么访问朝鲜？

看到星球很多人都挺关心这个事，外面有一些媒体解读有点邪乎，什么撬动地缘政治格局，什么下一盘大棋等等，实际上我们仅凭常识判断，这些观点都是不靠谱的。

这个世界一切都是靠实力说话，朝鲜那点经济实力不足一提，稍微有点样子就是军事实力，比如导弹与核——而这些恰恰是老中非常忌讳的，既然是忌讳就谈不上借用。

既然朝鲜的实力都摆不上台面，所以也就谈不上撬动地缘政治格局了。

那么，大领导为什么要去朝鲜呢？

首先我们要明确一个基本问题，老中对外交往的目的是什么？

睦邻友好？发展经济？这些都没错，但是老中对外交往特别是与周边邻国交往有一条红线是不能触碰的。

这条红线就是，老中周边地区绝对不允许爆发战争。这是我们的底线。

如果是一个小国内乱，呃！按照和平共处五项原则，内政我们原则上不干预。但是两个老中邻国要爆发战争，老中第一个不同意，毕竟战争一旦爆发就不可控，战争蔓延就会有溢出效应——城门失火殃及池鱼，老中是绝不容忍自己的和平红利被邻国战争破坏的。

所以，如果不是老中出手，几十年前印度就灭了巴基斯坦，现在印度但凡有点动作，老中一定会毫不客气地出手，5.7 就是这样的案例。

同样，老中在处理边境或者地缘政治纷争时有一个原则，绝不打第一枪！

中印，中菲都是这样，当然，以老中的实力，我们不打第一枪，你要是胆敢打第一枪，基本也没了打第二枪的机会。

基于这个原则，老中与印度，老中与小菲冲突都冷兵器化，都是狼牙棒或者消防斧这些玩意上场凑数。

那么我们盘点一下，老中周边，最有可能爆发战争的地区在哪里呢？

是的，就在朝鲜半岛。原因就是朝鲜不大安生，一会儿要搞核，一会儿要发射导弹，实事求是地说，朝鲜这些动作确实对韩国与日本造成了安全威胁。

同时也是造成日本军国化，以及美军加强在东亚军事力量最好的借口。

所以，过去老中对朝鲜这些不安生的行为也是很恼火的，曾经也在联合国对朝鲜制裁投了赞成票，并且一定程度配合了制裁。

这就是我前面说的，朝鲜的导弹与核是老中非常忌讳的原因。

因为以上一系列原因，朝鲜半岛是目前老中周边最有可能爆发战争的火药桶。

所以，大领导为什么要访问朝鲜？就是高调去续签《中朝友好互助条约》。

这个条约明确规定，一方受到任何一个国家或者几个国家武装进攻，那么缔约另一方应立即给与军事以及其他援助。

用大白话表述就是，谁要是胆敢侵略朝鲜，那么老中是一定会出手的。

最高领导亲自去续签这个条约，用美国人的话来说，就是老中对朝鲜的承诺坚如磐石。有了老中这个坚如磐石的承诺，那么不管是日韩还是老美都要放弃武力攻击朝鲜的念头，想都不要想了。

这种震慑就能最大地避免朝鲜半岛这个火药桶爆炸。

除了核心利益之外，俄罗斯是搞了很多小动作的，比如中欧班列查封，比如图们江修桥，比如与越南在争议地区开发能源等等，说白一点，俄罗斯还是隐隐将老中当做一个潜在的战略竞争对手的。

现在朝鲜的常规军事力量对俄罗斯还是很有用处的，如果老中与朝鲜关系变暖了，那么就有可能在朝鲜与俄罗斯合作方面发挥影响力，从而制衡俄罗斯的一些小动作。

最后总结一下，大领导为什么访问朝鲜？

其1，维护朝鲜半岛的和平；

其2，制衡俄罗斯的筹码。

其它的就没有了。
