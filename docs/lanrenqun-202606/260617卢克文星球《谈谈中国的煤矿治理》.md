# 谈谈中国的煤矿治理

260617 卢克文付费文

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

文/卢克文

5·22 山西长治潞州集团留神峪煤矿矿难已经过去快一个月了，国务院事故调查组已基本完成现场核查和前期取证工作。6月2日，长治市沁源县委书记接受调查；6月7日，沁源县应急管理局局长和执法一队队长接受调查；6月10日，山西省应急管理厅副厅长接受调查；6月11日，沁源县副县长和能源局一名主任接受调查。保险理赔和其他善后工作也正有序进行，这件事的热度也降下来了，现在可以聊一聊了。

我也不是瞎聊，因为2026年5月底，前后大概九天时间，我刚好从北到南跑了一趟山西，见了好些在山西煤矿工作的读者，还到山西一些煤矿看了看现场。现在所聊的信息，是综合大家的意见写出来的，并不是本人凭白无故空想出来的。

对于这次矿难，我们深表痛心，希望不要再发生这种悲剧事件，但也请大家宽心些。根据我在现场的访谈，现在山西、陕西、内蒙古对于煤矿治理其实已经非常非常严格，比起2000年代那种接二连三的悲剧矿难，现在已经减少了许多许多。

![](img/d00f9efca67e4c6af2a71ad99f8c490e_0_0.png)

这次矿难总共造成82人遇难。这种级别的矿难，再往前是2023年内蒙古阿拉善露天煤矿坍塌，53人遇难；再再往前，是2016年重庆金山沟矿难，33人遇难，内蒙古宝马矿难，32人遇难。

查了查资料，中国最近十年煤矿矿难，超过30人死亡的矿难共有这四起：

- 2024年河南平煤
- 2023年山西吕梁永聚煤业、黑龙江双鸭山双阳煤矿、黑龙江鸡西坤源煤矿
- 2021年新疆白杨沟丰源煤矿、青海柴达尔煤矿
- 2020年重庆松藻煤矿
- 2019年陕西神木李家沟煤矿

这些矿难都没有上面四起重大。

根据许多工作了几十年的煤矿工作人员反映，现在我国已经在科学范围内，通过严格管理，将矿难事故压低到一个很低的水平。除了一部分人为的管理失控、一部分灾害治理不到位、一部分人为了利益违法违规，通常不会发生矿难。一些国有大矿已经能做到多年零事故。

矿井深入地下，许多事情难以控制。一般瓦斯引发的爆炸和中毒是最频发、致死最多的矿难，其次是采掘时突然引发的透水事故、顶板垮落事故、煤尘爆炸事故。这几项是矿井常见灾难，尤其以瓦斯问题最严重。

另还有机电事故、运输事故、井下火灾、露天矿滑坡等其他事故，但最最严重的还是瓦斯问题。

2000年代国家已十分重视煤矿管理，主要分两部分：一部分是提高矿井门槛并合并管理。

2000年前后，中国关闭了年产3万吨以下的小煤矿2.5万家。这些小煤矿是80%重大或特大矿难的起源。2005—2008年三年，小煤矿基本都合并成大矿管理。山西、内蒙古、陕西三个产煤大省，矿井产量必须达到每年30万吨以上，2006年后一律停批30万吨以下新煤矿，从源头卡死事故。

新疆、甘肃、青海、宁夏、河北、东北、华东必须达到15万吨以上；川渝、云贵、两湖两广必须达到9万吨以上。

搞大煤矿主要是为了方便严格管理和机械化。只有大煤矿才出得起管理成本，理得清管理效率，投入得起机械化资金。中国一搞大煤矿后，矿难事故从2002年百万吨死亡率的4.64，下降到2010年的0.74。

另一个重点是危机防范，尤其加强对瓦斯事故的防范。

作为最常见、最严重矿难的起源，瓦斯是矿工们的头号敌人。为了解决瓦斯问题，国家投入了89亿国债和地方配套，建立了“先抽后采”系统。煤矿在开采前先抽瓦斯，把瓦斯浓度降到安全值再采。2010年大型煤矿瓦斯抽采率达到40%，2025年预估达到65%，高瓦斯矿抽采率预估达到76%以上。

正式开矿后，现在各矿还建立了全国联网的瓦斯监测系统，一旦浓度超标就会自动断电、报警，井下人员全员定位。小煤矿还会强制全风压通风，保证风量，杜绝瓦斯积聚。

煤矿的朋友告诉我，现在矿里如果瓦斯浓度不对，中央会比矿里的人更早知道，并且马上打电话过来提醒他们紧急处理，才大大降低了瓦斯事故。

除了这两项重大措施外，另还有非常严格的监管制度、安全生产法规、领导下井带班、风险抵押金、铁腕反腐、培训与标准化等一系列工作，将中国的煤矿特别重大事故，从2000年代初的每年8起以上，降低到了2010年后的每年0—2起。

我还去部分煤矿采访了一些下井工人，他们大多数能拿到一万左右月薪，公司住宿、食堂吃饭、交通出行一般免费或者出一点钱。下矿前的准备工作与回来的洗漱工作都井井有条，各方面管理确实科学有序。

但是矿井作业也确实是非常特殊的工作，违法违规、管理失控、灾害治理不到位，依然是现在造成矿难的三个重要原因。

其中，为了利益违法违规作业，是现在特大矿难80%的原因。

违法违规里，最常见的现象则是对上级搞阴阳图纸、隐蔽工作面。煤矿给上面一套图纸应付检查，实际在地下另开一面偷偷挖煤，不留记录、不上监控、不通风、不抽瓦斯。

这么做的原因就是为了偷偷采煤：上报30万吨煤，实际采了50万吨煤，这多出来的20万吨煤，就是利润极高的经济来源，甚至完全不用交税。

通常当地大煤矿要是偷偷搞这些，地方上的管理层是知道的，因为他们天天会去矿井检查，这么大动静瞒不过他们。所以一旦出事，肯定会有一批地方上的管理层被追查责任。

在山西时，我在大同、忻州、吕梁、长治接触了不少矿上的人。一位资深煤矿工作人员告诉我，现在一个大煤矿如果还发生瓦斯爆炸，一般情况下就是偷采盗采造成的。因为偷偷采，不敢上报，上面拿不到瓦斯监测数据，无法提前预警，才会发生这种悲剧。

他们还说，如果发生爆炸，可能遇难者并不是死于爆炸本身。在爆炸发生前，人就已经因瓦斯中毒去世了；爆炸是浓度达到一定程度后才发生的事情。

各个工作人员还说，我们听到的关于矿难的事情，那是很严重的情况。实际上，下矿还有个很常见的问题，就是容易受伤。

顶板、片帮落矸（gān）是排名第一的伤害源。矿下工作时容易被砸伤腰背、肋骨、腿部、头部等。井下工作空间狭窄，移动设备又多，各种磕碰、挤压、碾压造成的受伤，是第二大伤害源。风镐、钻机、钢丝绳、锚杆、管件回弹伤人，以及物料堆放滑落砸脚，是第三大伤害源。在井下作业时摔倒、扭伤、坠落，是第四大伤害源。

另外，长期在潮湿、磕碰的环境中工作，皮肤容易溃烂，关节容易劳损，也让不少矿工有多年小毛病。

从我自己在山西面对面访谈收集到的信息来看，中国对于煤矿的管理，目前已经达到尽可能严格的水平，但还是有各种意外、疏忽难以避免。同时，因为有一部分人的贪心，地方上的管理者与大型私人煤矿老板（通常是私人为主，国企难搞定那么多人）勾连，通过虚报产量、偷偷挖煤，才导致了重大安全事故。

管理制度是死的，但贪心的人，总会想各种办法钻空子。

这次去山西调研，极大地开阔了自己的眼界，我也深深明白了矿工们的不容易。矿井作业是高危行业，山西、陕西、内蒙古为中国贡献太多太多，我们应当记住这三省的贡献，也应当为矿工们的安危，尽职尽责做好各方面工作。
