


# 美加墨，为啥大概率被钉在耻辱柱上

260622 猫哥星球

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

这几天，身边不少老球迷被这届世界杯整出了戒断反应，不是因为球赛太精彩，而是因为赛程和乱象太离谱。

前两天还好，凌晨加早上，一天两场，和往届节奏差不多。但从第三天开始，画风就变了，从凌晨到中午，一口气端上来4场。且不说精力撑不撑得住，光是盯着菠菜赔率，脑子都快烧坏了。

看球嘛，大不了少看两场，主动权还在自己手里。但要是真去了现场，机票钱花了，酒店订了，那你就是案板上的肉，任人宰割。

我们一个一个来说。

首当其冲就是美国的做派。这届世界杯最讽刺的是，美国把世界杯当国土安全演习，主办国把参赛国当成了潜在威胁。

看伊朗就知道了，70人的代表团抵达墨西哥时，15人还没拿到美国签证，包括足协主席迈赫迪·塔杰。更离谱的是，因为美方明确要求比赛日入境、赛后连夜撤回、不得在美过夜，导致伊朗原本定在美国亚利桑那州图森市的大本营，也被迫改到墨西哥边境城市。三场小组赛（两场洛杉矶、一场西雅图）生生变成了跨境通勤模式。

![](img/3f6811566a74e35aef0adb49ba0bba6f_0_0.png)

这还没完。美国还单方面收回了分配给伊朗球迷的1.6万张官方门票配额，这就不是办赛，这是赤裸裸的歧视羞辱。

并且伊朗还不是个例，索马里裁判奥马尔，拿着美方核发的有效赛事签证，落地迈阿密被扣下盘问11小时，最终遣返，直接剥夺了索马里历史上首位世界杯执法者的梦想。还有海地、科特迪瓦、约旦、塞内加尔、伊拉克、埃及、加纳、厄瓜多尔等至少11个晋级国的后勤、记者、球迷遭遇高拒签率。

这就是2026年美加墨世界杯的荒谬现实，虽然参赛队伍扩军了，但真正能到场，已经被主办国筛选了一圈。

而国际足联呢？因凡蒂诺当年卡塔尔世界杯的"足球高于政治"跑哪去了？怎么才过4年，面对美国的骚操作，他双手一摊说：我们不是世界之王。不过，这也让大家再次看清楚了，原来足球高于政治这杆大旗，是专门用来插在中小国家头上的，到了超级大国面前，卵用没有。

其次，如果说政治操弄让人愤怒，那承办能力就是让人发笑。

加拿大开幕式，压轴的巨型充气大力神杯当着全球直播的面漏气瘪塌，被窝窝囊囊地降下去。几万观众坐在多伦多体育场里，看着本该最燃的时刻变成了一场街头事故。

英格兰队更惨，从佛罗里达到堪萨斯城的物资运输车被撬，凯恩和贝林厄姆的定制战靴、数十颗比赛用球、理疗床、战术设备、战术板几乎被搬空，只剩一个足球。一支夺冠热门球队的备战物资停在主办国境内都能被零元购，普通球迷的人身财产安全呢？想都不敢想。

还有检票瘫痪、危险品管控形同虚设、训练场地坑坑洼洼等等。才第一轮打完，互联网到处都是铺天盖地的吐槽声。说实话，就这承办能力，还好意思说是史上最豪华的世界杯，我认为及格线都够不着！不过这DNA很美国，很特朗普！

当然，政治干扰，承办能力拉胯都还只是开胃菜，真正的杀招是贵。

贵到什么程度？卡塔尔2022已经够贵了吧？美加墨直接把天花板掀了。可以说贵到离谱！

比如，决赛一类球票，卡塔尔售价约人民币1万多，但美加墨已经近7万人民币了。而决赛最低档，卡塔尔约1500元人民币左右，美加墨这边也接近翻了10倍。

但这还不是最黑的。FIFA今年推出了动态定价新机制。美其名曰随行就市，实际上就是看你急着要，我就涨价。人到了美国，主队晋级了，你不看吗？这时候价格就会开始跳，你急不急。

更绝的是官方转售平台，允许倒卖，买卖双方各收15%的手续费。比如一张1000美元的票，卖家到手850美元，买家实付1150美元，平台直接抽走300。也就是说，这次FIFA亲自下场当黄牛了。是不是很魔幻，美国黄牛看了都要递烟喊大哥。

还有线下消费，更是寸土寸金。之前出的赛场禁水令，要求必须在场内买水，一瓶5.25美元，因为后面反对声太大，才允许带1瓶入场。还有15美元的热狗，12美元的薯条等等。场外，酒店从150美元飙到500美元+，停车费有的已经喊到了300美元一天。甚至连公共大屏观赛区都收费了，想站在广场上看，以前免费，现在对不起，得交钱。

有人算过账，俄罗斯2018世界杯人均也就2-3万人民币，卡塔尔人均4-5万左右，而美加墨，起步5万人民币起，舒服点奔着10万+去。

所以你看，这届世界杯哪哪都不行，而且价格烫人，怎么不被人诟病，有钱人也经不起这样折腾，体验感太差，完全是打算把韭菜连根拔起。你看，美国收紧签证也不能说完全没道理，也许就是在暗示，没钱就别来了。

那么，问题来了，为啥一场4年一届的世界杯球迷盛宴，会搞成这样呢？

很多人把锅甩给美国，虽然我认为倒也不错，但也不能算对。因为在我印象中，不知何时起，只要由美国牵头承办掺和的事，多多少少都会出现翻车。而且美国办赛就是商业机器，就是吃相难看，你也不可能让它学会格局一下，对吧！所以，这不是根本原因。

根子问题还是出在国际足联自己身上。

实际上现在就能看得出来，不管是观赛还是比赛，32强世界杯和现在的48强，根本就不是同一个物种。这应该才是核心矛盾！表面上是增加了16支队伍，增加了40场比赛，但实际上呢？整个后勤保障和办赛协调全部上了一个强度，不光涉及球场建设、翻新问题，还涉及训练场、康复基地、健身基地等等一系列配套设施。还有要满足新增16国的球队、媒体、球迷的后勤保障，我们所想到的，包括公共交通、酒店、饮食、训练场、医疗、康复、甚至环卫等方方面面都要纳入进去。显然对于美加墨而言，在近五千公里纵深的网格里，塞下48支队，完全吃不消。

除了承办压力，还有比赛方面：比如，小组赛甚至32强比赛会出现大量实力悬殊的鱼腩局。比如，有些球队小组只要博一场3分，就能顺利晋级，有些强队1场后就可以练兵。还比如，末轮不同步，就可能涉及算分漏洞，默契球风险等等。

所以给看球的大家一个小建议，把小组赛忽略掉吧，直接等32强淘汰赛。

这里有个问题需要讲讲，当初在商定扩军方案时候，国际足联内部的反对声实际上很大，而且现在看，48强世界杯也并不精彩，单独承办压力很大，全球没几个国家能办到。那么，为什么非要扩军呢？FIFA打的旗帜是提高赛事的参与度，但实际上真正的核心就两个字——权力。

因凡蒂诺要对抗强势的欧足联。怎么对抗？1、给亚非拉送名额，搞统战工作。2、创收。目标很简单，营收从75亿美元干到130亿。多出来的55亿，自然就是扩军中去找变现。

当然，这里面还有个巨大的影响因子，那就是我们。你看亚洲名额从4.5个暴涨到8.5个，背后的逻辑很明确，国际足联打算亲自给我们铺上红地毯，这次你总该进去了吧。2022卡塔尔，国足没进，中国赞助商照样砸了近14亿美元，超美国成第一大金主，因凡蒂诺赌的是，一旦国足进了，赞助翻倍、转播权溢价、周边爆卖等等。这账谁都会算，但结果是国足连续第六届没进。

国足没进，就直接导致来自中国的赞助暴跌，连央视把转播权都砍到2010年的水平。只能说国际足联算准了中国市场的潜力，却算错了中国足球的实力。

更讽刺的是，为了蹭扩军的入场券，很多竞争力不够的国家疯狂收纳5大联赛的2-3线球员，上演一场双向奔赴，导致实力大增。因为很多边缘球员非常愿意加入，毕竟能在世界杯亮相，对身价和未来发展都是益处。你看，有没有一种国足亲手把国际足联因凡蒂诺战略构想打得粉碎的感觉。

国际足联真是两头不讨好，这边大鱼没上钩，钓上来都是小鱼小虾。那边，世界杯扩军也没有获得啥好口碑，大概率会被钉在耻辱柱上。而且，下届2030，多半也别抱幻想。因为更夸张，是六国联办。什么100年庆，听起来很浪漫，可能更拉。因为越多国家分羹，越没人兜底。

最后，给球迷星友提个醒，这届赛事的冷门可能会超过我们的认知！简单说一下逻辑：因为美国的不讲武德，以及3地联办模式，导致国际足联对比赛综合掌控能力在下降。那么，有些口子自然就会开更大。办赛能力拉胯代表什么，代表着从签证、转移、训练、饮食、休息、安保方方面面都存在隐患。一旦隐患发生了，就会影响球员的状态，大家想一想，会不会出现明天比赛，晚上停电3小时，空调无法使用的情况发生呢？这是不是就影响球员状态。

这届世界杯摆明了定位就是割韭菜，方方方面面的吃相都难看，难道菠菜会大发慈悲吗？所以，我认为更大的可能是上下沆瀣一气，场内场外联手割韭菜！

比如国际足联新搞的补水机制。上下半场各3分钟，我算了下，拖一拖基本就奔5分钟去了。以前也涉及补水时间，但是极端天气的个案，而现在是强制要求，下雨天也要补。说是更人性化，其实实际上说白了就是增加广告时间。最最关键不为人知的事，这个新机制明显是朝着锄强扶弱去的，对比赛影响很大。

简单举个例大家就清楚：如果是强队打弱队，弱队摆大巴，要进球就需要持续攻势，连番打击才能打穿防线。现在上下半场各给一个3分钟的时间，弱队正好喘口气，还可以趁这个时间重新优化排兵布阵。对强队而言，实际上是在上难度。比赛有个基本逻辑，要缩小强弱差距，最直接的办法就是压缩时间，比如打100分钟强队肯定赢，但打20分钟，就不一定了。现在这个补水机制，硬生生把足球比赛切成4段，像篮球比赛一样，就有这个门道。

懂的都懂，涉及审核问题这里就不展开，总结就是一个政治介入过多，办赛能力拉胯，场内场外都打着收割球迷标签的世界杯，外加全球经济不怎么景气，大家要防冷。如果要找个现实案例，大家可以回看上次也是联办的2002年的韩日，韩国是如何淘汰意大利、西班牙打进的4强的。

最后，祝大家端午安康，诸事顺遂。
