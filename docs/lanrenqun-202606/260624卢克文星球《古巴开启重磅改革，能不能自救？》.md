


# 古巴开启重磅改革，能不能自救？

260624 文/卢克文工作室 风雨如歌

整理：公众号懒人搜索，懒人专属群精选

最近，深陷经济困境的古巴，终于推出了它建国以来最重磅的改革。

2026年6月18日，古巴人大审议通过“全面社会经济改革方案”，提出覆盖23个领域的176项改革措施，改革力度前所未有。古巴将在金融、房地产、外汇、进出口贸易等国民经济领域，开启大规模私有化，并为外资打开大门。

那么，古巴能不能通过这次“改革开放”成功自救？

# 01

首先，我们来看看这次改革的核心内容。

改革主要有五大方面，先说最重磅的金融改革。

古巴银行都是国有的，几乎没有私营银行和外资银行，改革后古巴允许设立私营银行和外资银行。

古巴是个极其缺少外汇的国家，它的外汇来源主要是“出口”劳动力到美国、墨西哥打工，古巴裔再把打工收入汇回国内，此外就是旅游业。

![](img/ba9a7406612cffd371c3501bbbbab9c9_0_0.png)

这些跨境汇款业务，随着美国对古巴国有银行的制裁，越来越难以开展。

举个例子，海外古巴裔没办法直接汇款到古巴的银行，中间需要转来转去，倒好几次手。

这不光是麻不麻烦的问题，真正的问题是钱会流入地下钱庄、外汇黑市等黑灰色渠道，每个渠道都盘剥一笔手续费、服务费，外汇市场非常凌乱，导致国家和老百姓手里的钱全部变少。

古巴内政部在2025年破获过一个由迈阿密居民领导的地下钱庄，从2025年2月至9月间，这个地下钱庄转移了超过10亿古巴比索和近25万美元。

这类地下钱庄的运作模式是在美国收美元，然后在古巴黑市换成比索，挣得盆满钵满，古巴政府拿它们一点办法都没有，已经成了古巴经济的一块毒瘤。

既然收不到外汇，我为啥不干脆引进外资，直接实行汇率市场化，彻底打掉外汇黑市？

二是推动国企市场化改造，扩大国企在定价标准、内部薪酬分配、海外合作等方面的自主权，让它们有能力参与市场竞争。

这个很好理解，很多古巴国企效率低下，长期靠财政输血活着。改革后，长期入不敷出、资不抵债的国企可能面临关停或出售，能够减轻政府的财政负担。

三是拓宽私营经济边界。

过去三十年，古巴对民间资本参与产业发展有很多限制。2025年前，民间资本能够参与的范围基本上仅限于开小商店，至于生产制造、文旅开发、基建工程等核心行业，古巴原则上不允许民间资本进入。

2025年，古巴才开始允许民间资本创立小微企业，而这次改革进一步拓宽了民间资本的经营范围，民间资本可以进入景区开发、城乡基建等在古巴利润较高的行业，它们投资古巴的意愿也就提高了。

四是吸引外资和发展外贸，包括取消古巴国企的进出口垄断权，民营企业能够独立开展跨境贸易等等。

在古巴，只有国企才有从事进出口贸易的资格，哪怕是私人谈的生意，也得找一个国有外贸公司代为操作。

多一个中间商，不但会增加交易成本，也会让相关的官僚利益集团变得硕大畸形，这次改革主要就是向这些利益集团开刀。

再就是调整外资审批层级。

原本集中在中央部门的审核权限，将下放至各市县，地方政府可以自主审核辖区内中小型外资项目和策划招商引资活动，重点扶持赛道包括旅游、清洁能源等多个古巴的战略性行业。

古巴将光伏、风电等清洁能源作为重点发展方向，清不清洁是次要的，主要目的还是为了摆脱对进口石化燃料的依赖，一劳永逸地解决能源不自主的痛苦。

五是农业改革，包括简化土地使用权申办流程，赋予农户、集体农业合作社拥有更多自主经营选择权，放开农资采购渠道。

以后古巴的农户和农业合作社买化肥、耕作机械等生产物资，不需要再经过国有供销渠道中转，古巴希望通过这些措施降低农业成本。

但是，这些改革只是古巴为了自救不得已的举措，并不意味着古巴就要走资本主义道路了。

美国为了围堵古巴，不但实施严厉的金融制裁，更直接在燃料上卡古巴的脖子。

古巴80%以上的发电量来自委内瑞拉和墨西哥的石油，特朗普在2026年1月底签署新规，谁给古巴输送石油天然气，美国就要制裁和加收高额惩罚性关税。

委内瑞拉和墨西哥，现在都不敢再向古巴出口石油。由于缺少发电燃料，古巴从2月起就开始大规模停电，工厂停摆、设备停转，就连民生用电、医院供电都没法保障。

5月美国对古巴的制裁再度升级，海外银行只要和古巴国企有资金往来，就会遭到美国二级制裁，导致古巴的外汇渠道遭受重创。

特朗普还不断公开推演对古巴的军事方案，古巴的生存空间已经被挤压到极限。

所以古巴这套改革措施看起来很多很细，但核心就两个：最大限度减轻财政负担，极尽所能赚取和控制外汇。

不再无限制兜底国企、赋予农户自主权等措施，主要还是为了降低财政负担。我们主要聊聊外汇管控。

古巴不对外公布外汇储备，但外界普遍预测古巴当前的外汇储备已不足5亿美元。

对于古巴政府来说，回收和赚取外汇是最重要的经济议题。

外汇短缺导致古巴无法进口到足够的商品，货币严重贬值，通胀连年上升，2025年古巴官方公布的数据是14.07%。

这还只是总通胀率，如果单算食品的话，古巴食品物价甚至上涨了70%。

对于古巴来说，目前获取外汇最可行也最可控的路子，就是吸引海外古巴裔回来投资。

古巴和美国的关系长期剑拔弩张，遭受长期的经济和金融制裁，即便放开外资投入，美元英镑等私人资本未必多想进来，因为在古巴投资风险太大了。

在古巴国内，有钱投资的私人资本也不多。

古巴的本土居民比较贫困，但海外古巴裔就不一样了，他们见过世面，有一定积蓄和海外人脉，在古巴属于体面的中上产阶级。

以前古巴政府不是没想过办法吸引他们回来，但海外古巴裔对投资古巴有很多顾虑。

本质上，这不是他们爱国不爱国的私德问题，古巴的经济体制本身不允许私有经济涉足重要领域，更不允许他们发展壮大，即便投资也可能失去控制权。

改革后，古巴裔侨民可以持有本土民营企业股份，拥有对企业的控制权，他们也就吃了一颗定心丸。

同时我们要知道，古巴没有放弃国企对战略性行业的控制。

比如古巴虽然引入私营银行和外资银行，但银行业主体依然是古巴国有银行，古巴政府也不会一股脑地把国企统统卖掉，而是根据行业决定卖不卖。至于免费医疗、免费教育这些核心社会福利，改革方案也明确了绝不触动。

# 02

古巴的改革能不能实现自救呢？目前来看很难。

首先，美国不会眼睁睁看着古巴摆脱困境。

其实为了换取喘息空间，古巴已经在谈判桌上做了不少让步。

比如解除对海外侨民持股本土企业的限制，确实有利于吸引古巴裔的外汇回流，但凡是有另一面，古巴有近200万海外移民都在美国，混得最好的就是国务卿卢比奥，这些已经在美国扎根、获得社会地位的古巴裔，是海外古巴裔中最富裕的阶层。

设想一下，这些实际上已经彻底西化的精英古巴裔，有没有可能通过各种政策空子，大量持股古巴企业？古巴经济的命脉会不会落入他们手中？美国会不会通过这些“卢比奥”们，加强对古巴经济的渗透和控制？

完全有可能。

古巴不是不知道这样做的风险，但它也没有更好的办法。

用部分妥协的方式换取美国减轻封锁，恢复部分结算通道，已经是古巴目前最好的权宜之计。

但是在卢比奥眼里，自己母国作出的让步完全不够看。卢比奥多次公开表态，说古巴这些改革只是表面微调，根本不算实质性变革。

美国要的不是古巴那一丁点让步，是要像委内瑞拉一样全面变天。

“美以伊战争”后，美国对古巴的逼迫只会疯狂加剧。

为啥呢？因为特朗普对伊朗战事的处理，让美国共和党内部、MAGA基本盘感到强烈不满。

中期选举眼看就要到了，十分尴尬的特朗普需要一场“大赢特赢”来转移视线。

为了避免再次翻车，他大概率会拣软柿子捏，把下个阶段的主要精力用来折磨古巴。

古巴的军事实力和伊朗没法比，且身处美国后院，海上通道常年被美国封锁，而域外国家又很难给予实质性帮助。

对特朗普来说，欺负古巴既能洗刷伊朗战事的挫败感，又能提振阵营士气，完全是低风险高收益的事。

而在巨大的经济困难下，古巴内部的军心也有所动摇，不少人甚至巴望通过政治“变天”来谋取个人利益，甚至重新划分政治版图。

特朗普上台后，一直在拉拢卡斯特罗的孙子劳尔·卡斯特罗。劳尔本人到底是什么想法，我们不知道，但通过“私有化改革”让国家财富变成权贵二代的私有财产，也不是没有先例，苏联已经给我们演示过一遍了。

古巴这场赌上国运的自救改革能否顺利落地，我们还要继续观察。
