


# 所谓“经济上行期的美”，到底存不存在？

整理：公众号懒人搜索，懒人专属群精选  
懒人微信：lazyhelper1  

今天从一个最近很火的词说起，叫“经济上行期的美”。

你可能在社交平台刷到过这么一类内容。有人翻出几年前的老照片，然后感叹说：你看那时候的穿搭多有生命力啊，妆容明艳大气，处处透着生机活力。

再跟今天对比一下，很多人偏好的照片是，低饱和度、灰调、老钱风、安静奢华。好看是好看，但总感觉少了点什么。少了什么呢？这个少了的东西，大概就是网上说的“经济上行期的美”。当然，放在男明星身上，也可以称之为“经济上行期的帅”。

很多人把这种怀旧当成单纯的审美偏好。但事实上，它的背后有不少相关的研究。学者们花了大把的时间，测量了好莱坞演员的脸、Billboard 公告牌冠军歌曲的节奏、裙摆的长短，甚至社交平台上修图的幅度。

这些研究虽然范围不同，角度各异，但背后有一个高度统一的结论，这就是，你喜欢什么样的脸、穿什么颜色的衣服、听什么节奏的歌，这些偏好都或多或少，受到了经济周期的影响。

美国海岸卡罗莱纳大学有个心理学教授，叫特里·佩蒂约翰，在过去的20年里，他一直在研究这个课题。他还曾经提出过一个词，叫“环境安全假说”。大概说的是，社会经济好的时候，人们的审美偏向“娃娃脸”，但当经济不那么好的时候，人们就倾向于“成熟脸”。

比如，好莱坞电影。佩蒂约翰测量了1932 年到1995 年间，美国最受欢迎的电影女演员的面部特征。包括，眼睛大小、下巴宽度、脸型比例。然后他们把这些数据跟每一年的经济指标做对照。这些经济指标包含失业率、消费者物价指数、人均可支配收入等多项数据。

结果他发现，在经济繁荣的年份，最红的女演员往往是“娃娃脸”，大眼睛、小巧的五官、年轻感强。而在经济萧条的年份，最红的女演员反而是“成熟脸”。五官线条硬朗、眼睛偏小、下巴宽、看起来更有阅历。

你大概可以这么理解，经济好的时候，观众投票选出的是一张“让人开心”的脸；经济差的时候，观众选出的是一张“让人安心”的脸。

类似的情况不仅存在于电影领域，在流行音乐里也存在。

2009 年，佩蒂约翰和他的团队在《音乐心理学》期刊发表了一项研究。他们分析了1955 年到2003 年间，每一年的Billboard，也就是《公告牌》年度冠军歌曲。分析方式是，一方面测量歌曲本身的音乐特征，包括节拍速度、调性。另一方面请听众评估歌曲的情绪感受，也就是这首歌是让人振奋？还是让人沉思？

结果他们发现，经济繁荣年份的冠军歌曲，往往节奏更快、调性更明亮、歌词更轻松，也就是那种让你想跟着跳舞，站起来扭几下的歌。而经济衰退年份的冠军歌曲，往往节奏变慢、旋律更舒缓、歌词更有深度，就是那种让你安安静静听、越听越觉得“说到心坎里”的歌。

他们还有一个额外发现：经济困难时期的冠军歌曲，往往被认为歌词“更有意义”。也就是说，经济好时人们更倾向用音乐来“庆祝”，经济差时人们更倾向用音乐来“疗愈”。

2012 年，佩蒂约翰团队把研究更进一步。这回他们又增加了很多观察维度，包括冠军歌曲的BPM，也就是每分钟节拍数等等。结论依然是，经济好的年份，冠军歌的每分钟节拍数更多、更多大调。经济差的年份，冠军歌曲的每分钟节拍数更少、小调增多。

等到2014 年，研究者们又专门统计了歌手们的外貌，这个成果后来发表在《当代心理学》上。他们统计的是，1946 年到2010 年间，《公告牌》年度最受欢迎乡村音乐歌手的面部照片。用的依然是同样的方法，测量眼睛大小、下巴宽度、脸型比例，然后跟经济指标对照。

结果还是一模一样，经济好时，最红的歌手更“娃娃脸”；经济差时，最红的歌手面部线条更硬朗。文章里还举了个例子，歌手约翰尼·卡什，大眼睛、小下巴，他的经典热门曲目恰好出现在经济繁荣期。

按照佩蒂约翰的研究，不只是大银幕上的面孔，连人们爱听什么歌、喜欢什么样的歌手，都在很大程度上受到经济周期的影响。而且这个影响相当一致，经济好的时候，人们选择偶像的标准是“适合恋爱”，而经济差的时候，人们的标准变成了“适合结婚”。

注意，这只是人们对“外形”的审美偏好，并不是说，人们真的想恋爱或者真的想结婚。而且经济下行的时候，人们往往喜欢“更壮实”的外形。按照研究者的解释，这很可能是因为，在资源匮乏的环境里，大脑会自动调高对“储备能力”的评估权重。更壮实意味着更能扛过低谷和危机。这不是审美问题，这是生存本能在做选择。

之前经济学家乔治·泰勒还提出过一个著名的假说，叫“裙摆指数”。注意，是“假说”。这个词是1920 年提出的，说的是，经济好时裙子变短，经济差时裙子变长。这个说法流传了将近一百年，但一直被当成都市民间传说，没人正式验证过。

但在2010 年，鹿特丹伊拉斯谟大学的学者做了系统研究。他们搜集了将近一百年的时尚数据，对裙摆长度和经济指标做了严格的统计分析。结论是，裙摆指数确实成立。经济繁荣时裙子变短，经济衰退时裙子变长。

不过这里有个有趣的细节，裙摆的变化不是和经济同步的，它滞后大约三年。也就是说，经济先变好了，过了三年，大街上的裙子才开始变短。这说明审美的变化也许不是对新闻的即时反应，而是对“安全感”的反应。安全感的建立需要时间，它是慢慢渗透进人们的穿着、打扮和表达方式里的。

听到这，有人可能会说，前面这些研究，不是国外的，就是过去的。有没有最近的国内研究呢？

有。2025 年，四川大学和香港理工大学的研究者，在《远程通信与信息学》期刊发表了一项研究。他们从小红书上收集了43000 条“修图前后对比”的帖子，用计算机视觉技术测量这些照片对五官的修改幅度。比如，眼睛放大了多少比例、脸削瘦了多少、肤色提亮了多少。

然后，他们把修图数据跟用户所在省份的人均GDP 做对照。结果发现，经济越发达的地区，用户修图幅度越小，也就是越敢展示真实面貌。相反，经济越落后的地区，修图幅度越大，用户更强烈地把自己的脸修向标准的“白瘦美”模板。

换句话说，经济安全感越高，审美表达越自由、越松弛、越多样。经济安全感越低，审美表达越趋同、越紧绷、越追求“标准答案”。

好，前面的证据说完了。那么问题来了，知道这些，对我们有什么用呢？难道仅仅是多一个观察流行的视角？

当然不是，你看，既然经济环境能通过影响安全感来改变审美选择，那反过来，我们能不能通过主动选择审美表达来重建安全感呢？这些研究的另一重关键价值，就在于这条链路不是单向的，它可以被反过来使用。

2012 年，西北大学凯洛格商学院的亚当·加林斯基教授做了一个著名的实验，发表在《实验社会心理学》上。实验很简单：他让两组人做同一套注意力测试题。一组穿上白大褂，另一组穿便装。结果穿白大褂那组的正确率明显更高。

这个实验还有个有趣的后续，他又让两组人都穿上同样的白大褂。只不过这回，他告诉一组人“这是医生的白大褂”，告诉另一组“这是画家的罩衫”。结果，同一件衣服，被告知是“医生的”那组，注意力表现明显更好。

加林斯基把这个现象叫做“着装认知”。它说的是，衣服不只是给别人看的，它会反向改变穿着者自己的心理状态和认知表现。而且这个改变，取决于你赋予这件衣服什么含义。

英国赫特福德大学的心理学教授卡伦·派恩，还进一步研究了这个问题。她在一项实验中发现，当女性穿上“超人T 恤”时，不只是自我评价更高，她们在随后的力量测试中，实际表现出的握力也更大。也就是说，衣服不仅改变了你怎么想自己，还改变了你的身体输出。

除了衣服，颜色也有类似的作用。2015 年发表在《心理学前沿》上的一篇综述论文分析了大量实验，发现暖色调，尤其是红色和橙色，会激活人的交感神经系统，提升唤醒水平。说白了，穿一件鲜艳的暖色衣服，你的大脑会处于更活跃、更自信的状态。

音乐也一样。2013 年的一项研究发现，在经历压力事件之前听积极的音乐，受试者的自主神经系统会在事后恢复得更快。也就是说，一首舒缓的歌，能帮你在压力过后更快平静下来。

注意，这不是阿Q 的精神胜利法，而是利用大脑的“具身认知”机制来主动调节自己的状态。你不需要被动等待一个积极的外部信号，你可以从今天开始，穿一件你觉得“让自己感觉良好”的衣服，或者听一首快歌，化一个跟平时不太一样的妆。

所谓“经济上行期的美”，它不只是一个人的怀旧表达方式。它也提醒我们，审美也是环境的被动投影。但好消息是，一旦搞懂这个机制，我们就可以反向利用它，把它变成你主动管理情绪的抓手。
