# 欧洲为啥热死人也不装空调？

260630 文/卢克文工作室嘉宾 概略北方

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

万万没想到，欧洲的高温，上了全世界的热搜。

在酷暑的折磨下，欧洲人被热得死去活来，现在中国空调在欧洲那边被抢购一空。

天热了，空调销量上涨，其实也没什么大不了，但关键是，欧洲政客居然为“该不该安装空调”这种小事，吵得不可开交。

欧洲人热死也不装空调，到底是咋回事？

# 一

其实吧，欧洲没空调这个事，也不是一天两天了。要是在往年，肯定会有各种人跳出来解释，欧洲根本不热，不需要装空调！

这话对吗？放在之前，还是有道理的。

欧洲属于温带海洋性气候和地中海气候，夏天相对要温和得多。以巴黎为例，一年到头最高温度也就30度左右，而且可能也就维持一两个星期，忍一忍就过去了。

欧洲人从不装空调这件事中莫名生出了一种优越感，说我们都是环保建筑，根本不需要空调这种高耗能设备。

不过呢，气候变化，专治不服。

今年是“超级厄尔尼诺年”，热浪席卷整个欧洲，个别地方已经突破了45度，快跟印度有得一拼了。

现在欧洲因为热浪死亡的人数已经超过百人，光巴黎一个地方，下塞纳河游泳解暑被淹死的都有40人了。

欧洲人终于扛不住了，开始疯狂买空调。

接着魔幻的事就发生了，欧洲人虽然买得起空调，但安装空调那是非常难。

第一关是业主委员会。

欧洲老城大都是那种公寓楼，虽然房子是自家的，但外立面属于全体业主共有。

你想在外立面装空调，必须取得业主委员会的同意。

且不说你能不能找齐业主开会，就算你找齐了，投票原则也不是少数服从多数，而是一票否决，只要楼里有一个对噪声敏感的老太太，那整栋楼的人都不能装空调！

第二关是市政厅。

就算业主委员会都同意了，你还要把安装计划和安装图纸报给市政厅审批。

欧洲中心城市大多是老建筑，外立面都属于城市文化遗产，你在19世纪的外立面上装一个21世纪的空调，政府会说你这是破坏城市风貌。只要是临街的房子，申请装空调基本上没戏。

最后就算你走运通过审批了，可能也没人给你安装。

在欧洲，装空调这个职业被“空调安装协会”把持，所有安装工都要持协会发的证才能上岗，而发证多少不看你技术，而是看协会今年有多少会员退休，缺多少补多少，以此维持安装工人的稀缺性。

也正因为这种稀缺性，所以装空调特别慢，动辄一个月起步。如果8月份约，等你装上都10月了，那时候根本没必要装空调了。

更坑爹的是，一台普通的分体空调，机器本身也就七八百欧，但你猜安装费多少？动辄一两千欧！如果是高空作业直接四五千欧起！

这么算下来，一台空调从购买到安装，总共要花三四千欧起步，多的甚至上万欧，哪怕是中产，装个空调也是要肉疼一阵子的。

在各种繁文缛节的限制下，一个在中国随处可见的工业品，欧洲人就是享受不到，只能在热浪里煎熬。

# 二

有意思的是，哪怕都这样了，欧洲还有很多人抗拒安装空调。

法国左翼领袖梅朗雄宣称，“到处装空调本身就是一种生态破坏。”法国绿党也指责“空调只是逃避气候变化根源的捷径。”就连法国总统马克龙也明确不鼓励全民装空调，最搞笑的是，法国民调显示80%的法国人认同“空调不环保”。

表面上看，这是欧洲人都被环保政治正确给忽悠了，但在这些政治正确背后，其实还是利益。

首先，欧洲电网承载不了大规模装空调。

欧洲电网十分破旧，线路高度老化，而欧洲这些年大规模搞的绿电，由于变压器和储能系统不足，无法并网和调峰，所以经常是白天有电、晚上没电。

一旦因为空调用电量暴增引发大规模断电，任何一个欧洲政党都背不起这么大的锅。

第二，抗拒空调，透露出欧洲政界对中国制造进入欧洲的焦虑。

最近，欧洲正在对华贸易上疯狂发难，短短半年时间，欧洲就出台或生效了插混反补贴法案、《净零工业法案》、钢铁新政、传统工业品反倾销税、《外国补贴条例》（FSR）等等针对中国的新规定。

中国空调占全世界空调产能的80%，无论是核心零部件还是技术，只要装空调都绕不开中国，空调几乎就是中国制造的代名词。

刚刚还吼着要跟中国打贸易战呢，结果掉头就大批进口中国空调，身体是不是太诚实了？

对于政客来说，向中国低头，比热死几个人要严重多了。鼓吹空调有害，明面上是“环保”，本质上还是抵制中国制造。

最最关键的在于，在欧洲，环保从来就不是一个议题，而是一门生意。如果中国空调大举进入欧洲，这门环保生意可能就没法做了。

从碳排放交易市场，到各个大学的基金会，再到各国的绿党，已经形成了一个顽固的环保政商复合体。

这个利益集团的主要商业模式，就是媒体负责煽动气候恐慌，各路专家负责出来站台，然后政府“响应民意”推动立法，最后逼着全民去买指定企业的环保产品。

举个例子，欧洲政客收了建材公司的钱，配合建材公司忽悠欧洲老百姓，说你房子热是因为隔热不好，所以你要用环保建材把房子翻新一遍，隔绝外面的热量，房子就不热了。

然后你就去买建材修“隔热”房子。注意，这些环保建材是有严格标准的，比如外墙必须使用所谓碳足迹极低的“有机透气保温棉”，刷墙的涂料必须是声称能吸收二氧化碳的“生态浆料”，连窗户都必须是认证过的“高标准低辐射三层充气玻璃”，每个环节都养着一群公司。

这一套下来，再叠加欧洲巨贵的人工，没个几万欧是下不来的。

一个简单的降温需求，被硬生生做成了一个几十亿欧元的生意。如果这时候欧洲人直接换上中国空调，环保建材的“神话”会瞬间破产。

再举个例子，欧洲这几年一直在推动一种叫“热泵”的东西，通过环保立法，逼着老百姓淘汰便宜的燃气和燃油锅炉，换上最新的热泵（冬天取暖用的设备）。

这玩意本身就不便宜，再加上各种安装费、服务费，动辄一两万欧。

生产热泵的欧洲企业拿着政府补贴，去赚欧洲人的钱，赚了钱再给政党捐钱，完美闭环了。

现在欧洲人换上中国空调，立马就会发现空调不仅制冷效果好，冬天还能制热，那谁还去装热泵？

而且欧洲的房屋结构和我们的不太一样，通常配备水力辐射系统，他们在宣传热泵的优势时，给出的理由之一，就是热泵不用再打洞铺风管，不会破坏建筑风貌。

欧洲人一旦纷纷用上空调，会深刻改变欧洲房屋的管网结构，而如果政府默许你可以改变管网结构，相当于热泵一直以来存在的根基和意义都被完全否定了，靠着这条利益链吃饭的企业也会跟着倒闭裁员。

所以欧洲各国政府一直像防贼一样防着中国空调，设置了很多苛刻的准入条件，比如LVD低电压指令、EMC电磁兼容、RoHS有害物质限制、预扣报废处理费，还有冷媒GWP不得高于750等等规定，就是希望阻止中国空调进入欧洲市场。

只要能维持整个利益集团的利益，热死几个人算啥？政客只会宣传，你不是被热死的，你是为“保护地球”而牺牲的！

但他们千算万算，没有算到中国企业用一台美的德国研发中心设计、意大利生产的Portasplit空调，让欧洲政客苦心设置的壁垒全部破功。

这种空调其实是中国人比较嫌弃的一体式空调，比分体式空调占地方，噪声也更大，但就是这种空调，完美卡住了所有欧洲法规的Bug。

首先，它是一体式的，不用安装，拎起来就走，放家里就能用，不用去求业委会！

其次，它不用打孔，不用受欧洲安装大爷的气。

最后，它只需要一根管子往窗外一顺就行，不显眼，市政厅那帮官僚也没法说什么。

唯一一点小问题就是管子顺出去之后窗户关不严，但问题不大，义乌商家正在拼命往欧洲空运适配这种空调的窗户密封套件，很快就能解决。

这是硬生生从夹缝中开拓出来一个市场啊！

这款空调一出来，马上在欧洲爆火，原价1199欧的空调被炒到了1999欧。

有个德国人甚至还办了个收费网站，实时更新各个国家的美的空调库存，还有个德国人翻遍了德国商店都没货，最后开车几百公里去匈牙利抢到了最后一台。

欧洲道德婊天天说别的国家不高级、不环保、不遵守气候议程，轮到自己被热疯的时候，这嘴终于闭上了。
