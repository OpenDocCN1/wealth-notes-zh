 # 《给阿嬷的情书》在新加坡

一场关于身份认同、统战乃至认知战的激烈争论。

6月18日，在中国大火的电影《给阿嬷的情书》在新加坡上映，其中八场潮汕话原声版影片一小时内售罄。

在上映之前，这部电影在新加坡的舆论场当中已经成为热议话题，甚至点燃了一场关于身份认同、统战乃至认知战的激烈争论。

今天的新闻实验室会员通讯，我们就来聊聊这个话题。

### 一部日常与温情的电影

![](img/06636154e9df635d3ad66c254b6b1ea0_0_0.png) ![](img/06636154e9df635d3ad66c254b6b1ea0_0_1.png)

《给阿嬷的情书》投资只有约1400万人民币，但票房已经接近18亿。全片几乎都用潮汕方言拍摄，主演基本是素人，没有明星，没有特效。它上映后靠口碑自发传播，豆瓣评分一度高达9.2，刷新了今年华语剧情片的高分纪录。

电影讲述的故事并不复杂：上世纪40年代，潮汕青年郑木生为躲避战乱与抓壮丁而“过番”下南洋，把妻子叶淑柔和三个孩子留在老家。他辗转到了暹罗（今泰国），结识曼谷唐人街旅社老板之女谢南枝。后来郑木生在跑船时落水身亡，谢南枝却替他隐瞒死讯，继续以他的名义给素未谋面的叶淑柔寄“侨批”——汇款、糖果、衣物、咸猪肉，甚至自行车，一守就是十八年。两个女人垂垂老矣时才在泰国见上一面，而此时谢南枝已患上认知障碍。

电影的核心意象是“侨批”。它是19至20世纪海外华侨通过民间渠道寄回中国家乡、集家书与汇款凭证于一体的信件，又称“银信”。侨批既是经济命脉，也是跨越重洋的情感纽带。2013年，侨批档案以其独特性与完整性被列入联合国教科文组织《世界记忆名录》。有评论，《给阿嬷的情书》的成功反映了观众在快节奏的内卷时代里对根脉、家庭与慢生活的渴望。

这部日常与温情的电影，如果未能获得票房上的巨大成功，可能也不会引发什么和政治相关的讨论。但是，随着它的不断出圈，一些意外的声音出现了。

5月21日，新加坡《联合早报》中国新闻副主任、北京特派员沈泽玮发表了一篇专栏，标题叫《被侨批击中的统战焦虑》。她在文章里坦言，自己在被电影感动之余，脑中突然闪过冰冷的两个字——统战。

她的论点是：即便导演未必有此初衷，这也是一部“非常成功的统战片”，因为它“没有宣传口号，没有宏大叙事”，唯有“情义”二字贯穿全片，真正做到了“润物细无声”，直抵人心最软处。她进一步追问：那些不在中国出生长大、甚至不谙中文的华人，他们与想象中的中国究竟是何种关系？当下没了侨批，却有小红书、TikTok、微信、淘宝，正以更便捷的方式把世界编织进同一张由中国构建的信息网络。

这篇专栏提供的是一种个人观点，观点本可商榷。沈泽玮自己也写得也算克制——她甚至在文末厘清了自己的身份排序：“新加坡人、新加坡华人、祖籍福建东山”，与中国是“祖籍连接，而非祖国情感”。但在在这个年代，具备争议性的观点一旦发表，就很可能引发溢出了正常讨论范畴的后果。

### 从“去华人化”到“印度化”

真正让这个案例进入新闻实验室视野的，是《联合早报》前几天发表的另一篇评论。

专栏作者是该报所属的华文媒体集团副社长韩咏梅（曾任《联合早报》执行总编辑）。韩在文章中说，她对同事沈泽玮的专栏文章并不完全赞成，但令她感到不安的是，社交媒体上的相关讨论“像是把作者和早报丢进拳击圈里围殴。”

原来，“统战”的说法在社交媒体上引发了一轮群嘲和网暴。

韩咏梅称自己用开源情报（Open Source Intelligence）的调查方法对相关社交媒体内容做了一轮调查，发现：沈泽玮那篇文章出街后的48小时内，多个社交媒体平台上攻击《联合早报》、唱衰新加坡治理模式的内容“井喷式出现”，其暴增幅度形成了统计学上的异常曲线，并不符合自发性民间讨论的传播规律。她说，这些攻击大多回避对原文核心逻辑的讨论，而是用浅层的声讨，把事情无限放大为“新加坡官方系统性抹杀华人传统文化”的指控。

大约一周后，这股叙事又与一个此前几乎沉寂的种族议题嫁接起来，渲染新加坡越来越“印度化”——相关视频所用画面主要是2022至2024年印度裔节日高峰时段拍摄的旧素材。

的确，关于新加坡“印度化”的视频最近密集出现。以至于新加坡《海峡时报》的记者前几天还找到我，要我点评为什么来自中国的自媒体喜欢做这种视频——当时我还没有意识到，这股种族主义叙事的内容风潮背后，居然是《给阿嬷的情书》这部温情电影。

韩咏梅认为，网暴者们的手法还称不上深度伪造（Deepfakes），充其量只是“廉价拼贴”（Cheapfakes）：不需要什么技术含量，只要抓取一些无版权画面，用AI生成情感强度很高的文本，再以文本转语音批量产出——这正是内容农场的惯常操作。新加坡警方在6月6日援引《网络犯罪危害法令》（OCHA）调查了14个诋毁印度裔社群的贴文，但内容农场仍在继续发布类似内容。

这位资深媒体人对相关叙事的拆解是：它“将新加坡多元种族的社会治理歪曲解构为‘华人精英去华人化后的文化焦虑’，把攻击目标从境外敌意偷换成自己人的背叛，再以移花接木的族群画面放大裂缝”。换句话说，先制造文化焦虑，再煽动种族对立，两股叙事在同一时间窗口里相互强化。她将这个案例和后真相时代联系起来，因为“你不需要说服所有人，只需要在特定圈子里制造足够强烈的情绪。”

### 文化认同≠政治认同

对于《联合早报》的文章，《环球时报》回应说，“心里有鬼，才看什么都像鬼”。该报认为，一部素人方言片被当成“足以撼动国家认同的利器”，是某些人“自己心里装满政治算计”。

整件事情，的确变成了一种抓鬼游戏。

在最基础的层面上，是这样的事实：尽管新加坡七成人口是华人，但其在国家认同上强调自己是多元种族国家。新加坡政府刻意与中国保持政治和情感上的距离，政要们刻意不回乡祭祖。

基于这样的事实，不同的人会产生不同的情感。有人会认为这是复杂国际形势和东南亚周边局势之下的务实、明智选择。但中国的民族主义者会心存不满，认为这样一个华人为主的小国竟然对中国冷漠，是一种背叛。

而另一方面，中国国力的增长和软实力的提升，也让一些新加坡人产生了警惕。当地主流舆论非常警惕海外影响力的渗透，强调新加坡公民的国家认同，确保本地社会的发展不会被外部大国意志所左右。

《给阿嬷的情书》在新加坡和中国之间引发的舆论争执，正是在这种相互的警惕之下发生的。

《联合早报》沈泽玮的文章可以说是这种警惕心理的产物。《环球时报》的回击以及自媒体上那些关于“去华人化后的文化焦虑”和“新加坡印度化”的内容，则是对新加坡不满的心理催生的。

香港01的评论提供了一个结构性的分析框架。文章把这场争论解读为两套叙事逻辑的碰撞：在中国大陆的叙事里，“侨批”是连接两岸的“脐带”，“下南洋”的苦难被纳入“中华民族伟大复兴”、“海外儿女心向故土”的宏大叙事；而新加坡自建国总理李光耀以来的生存逻辑，恰恰是要向邻国和西方证明自己“绝非中国在海外的意识形态延伸或‘第三中国’”。于是，新加坡舆论要把中国定义的“祖国”郑重纠正为“祖籍国”，把“落叶归根”改写为“落地生根”。在这个框架下，电影里浓烈的“血浓于水”对新加坡构成了一种“无法拒绝的文化霸凌”。

BBC中文的报道补上了被前两种叙事都略去的历史复杂性。它提醒读者，“侨批文化”在中共历史上其实是一把双刃剑：改革开放后它被纳入统战叙事、象征爱国情怀，但在土改与文革时期，有侨汇收入的“侨眷”却曾被提高阶级成分、被打成“里通外国”的嫌疑对象，侨批一度遭检查没收。报道还采访了泰国潮汕第四代黄泰华——他会去看这部电影，把它当成探索家族根源的旅程，但明确表示“作为年轻一代，我们最主要的身份认同还是泰国人”。

在这些争论之下，最底层的两个概念是：文化认同与政治认同（或国家认同）。

研究海外华人的学者王赓武早就给出过经典的分析。他笔下的华人离散族群，指的是那些已在各国安家、成为当地国民的华裔，而非仍持有中国国籍的海外华人。历史上，南洋华人之所以维系“华人性”（Chineseness），讲方言、办华校、过节祭祖，更多是出于经商联络等务实理由，而非政治上的乡愁。他们很清楚要忠于所在国，“华人性”从不必然等同于认同中国这个国家。事实上，在今天的新加坡，方言乃至华语的使用都在快速衰退，“华人性”本身正在淡化。

韩咏梅的文章说，文化本身没有天然的政治性，但它会拉近情感、形成共同体，进而产生政治外溢效应，成为各方力量争夺和解释的对象。最容易被钻空子的，正是“文化认同”与“政治认同”之间的纠缠——让人误以为在文化上产生了共鸣，在政治上必然要认同。

这种模糊性极易被加工成左右舆情的武器。而要拆解它，靠的也正是把两者重新分清：在文化上欣赏“一诺千金”“饮水思源”，与在政治上认同某个国家，完全可以是两件事。

在一个文化输出与地缘政治越来越紧密缠绕的时代，类似《给阿嬷的情书》这样“情感引力”与“主权防御”相互拉扯的案例只会越来越多。学会把文化共鸣与政治认同分开来看，恐怕将是我们需要不断提醒自己的话题。
