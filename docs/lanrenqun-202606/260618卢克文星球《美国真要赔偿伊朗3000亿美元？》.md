


# 美国真要"赔偿"伊朗3000亿美元？

文/卢克文工作室 风雨如歌

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

昨天，网上开始疯传一个十分炸裂的消息，说美国同意给伊朗赔偿3000亿美元。

按历史银价计算，3000亿美元折合成白银超过37亿两（不精确），大清从1840年到1911年，总共也就赔了大概15亿两白银。

一个条约就赔偿37亿两白银，李鸿章都不敢签呀。那么，这所谓的"3000亿美元赔偿"是怎么来的？能不能执行？

## 01

这件事的起因，是6月15日，美国副总统万斯在接受采访时表示"伊朗可能得到3000亿美元的重建基金，由海湾国家联盟支付，只要他们（伊朗）履行自己的义务"。

话出自万斯之口，还是比较权威的。舆论很快炸了，不少媒体直接以《美国赔偿伊朗3000亿美元》为题发文，气得特朗普怒斥是假新闻。

那么，这是咋回事呢？我们先说说"3000亿美元"是怎么来的。

![](img/491b790b5c22bcfd4564b18d168ec8d4_0_0.png)

根据路透社报道，6月初，伊朗在计算了自身人员和设施损失后，认为战后重建需要4000亿美元，而且这笔费用该由美国支付，否则事情没完。

特朗普那么抠门，现在还要乌克兰赔美国的钱呢，他能同意赔伊朗一分钱吗？所以想都不用想，美方直截了当地拒绝了。

不过呢，伊朗手里有霍尔木兹海峡这个筹码，间接操控着全球油价，只要油价失控，特朗普随时可能因为通胀爆表，在中期选举中丢掉选票。

所以，美国的意思还是谈，但这钱不能我来出。于是，一个名为"重建与发展基金"（以下简称"重建基金"）的构想诞生了。

这笔钱有一个非常微妙的定位，它其实不是美国政府的赔款，而是一个由民间资本主导的投资机制，就是把美国、海湾国家、亚洲、南美洲和非洲的金融机构和其它企业，拉到一起商量未来在伊朗投资的问题。

一通讨价还价后，重建基金的投资总额敲定为3000亿美元。

综合各方消息，重建基金的资金来源主要有四个：

- 一是伊朗自己被冻结的资金，获准解冻；
- 二是海湾国家支付的资金；
- 三是来自外部投资者的资金，美国私底下找了韩国、新加坡、日本等盟友，希望他们投资伊朗的石油天然气产业，这些投资也算在基金里；
- 四是美国可能通过IMF等国际组织，给伊朗贷款一部分。

其中，伊朗获准解冻的资金约240亿美元，占比不大。外部投资者的投资和国际组织的贷款不确定性很高，比较能指望的还是海湾国家的资金。

伊朗拿到这笔钱的门槛其实不算高，只需要履行义务，根据白宫发言人的说法，"义务"是指废除核计划、消除浓缩材料库存并接受严格的检查和执法机制。

其实，这些都是2015年《伊核协议》的要求。

2015年《伊核协议》签订后，伊朗便将浓缩铀交给了俄罗斯，自身不再保有浓缩铀库存，并接受"国际原子能机构"（IAEA）的监督，IAEA的人员常驻伊朗。

等于特朗普闹了半天，只拿到一个和奥巴马相当的结果，还额外要付出3000亿美元的代价。

海湾国家内心肯定不愿意打钱，但除了打钱，他们也没有多少选择余地。

尤其是卡塔尔、阿联酋、科威特和巴林四国，进口和出口都十分依赖霍尔木兹海峡，在伊朗实控海峡的情况下，有的是办法让他们难受。

如果一时半会拿不出太多，可以分期付款，反正也没说必须一次性支付。

就在6月上旬，阿联酋一架飞机秘密降落在伊朗，飞机上满载着一箱箱美元，据外媒报道，就这一趟，阿联酋就向伊朗转交了约30亿美元，这还只是预付款，后续阿联酋还将转交100亿到200亿美元。

卡塔尔也可能向伊朗转交一笔钱，5月末，伊朗央行行长访问了卡塔尔，双方商讨的重点，就是伊朗资产解除冻结的问题。

卡塔尔提出先给120亿美元，等停战协议正式签署，再给120亿美元。

科威特和巴林暂未有向伊朗转交资金的报道，但他们和伊朗矛盾重重，很难躲开。

先说巴林，它的人口主体是什叶派（占比70%），王室却是逊尼派。为了维护统治，王室长期镇压什叶派，导致和伊朗关系不佳。

再看科威特。海湾战争时期科威特曾被伊拉克吞并，靠着美国出兵才得以复国，之后彻底依附于美国，是中东最亲美的国家之一。

本次美以伊战争，科威特和巴林也是伊朗导弹和无人机的重点打击对象。打钱这种事，怎能少得了他们？

唯一的例外，也许是沙特。

沙特有一条"东西石油管道"，能将波斯湾沿岸的石油天然气输送到红海沿岸，再装船出口，对霍尔木兹海峡的依赖度没那么高。

加之沙特是逊尼派老大，伊朗对于得罪沙特，还是比较忌惮的。战争期间，对沙特的打击相对克制，沙特有底气少打钱或者不打钱。

对伊朗来说，重建基金的最大意义，不是真能拿到多少钱，而是通过这些外资，一举打破过往数十年的困境。

## 02

一直以来，伊朗的最大困境就是孤立。

1979年革命后，伊朗在中东处于孤立状态，除了"抵抗之弧"之外基本没有什么朋友。美国和以色列长期玩离岸平衡，拉着逊尼派围攻伊朗。

伊朗周边安全形势复杂，动不动就被制裁，经济无法正常发展，很大程度上都是伊朗被孤立导致的。

假设你是一家沙特企业，想去伊朗投资，没准你今天刚在伊朗建好工厂，招好员工，启动生产线，想着热火朝天大干一场的时候，沙特和伊朗的关系突然恶化，那你的工厂咋办？

直接跑路吧，多年投入打了水漂；原地苟住吧，沙特政府不允许，沙特人也会骂你是内奸。

即便你的国家和伊朗关系还行，你也未必敢去伊朗投资。哈梅内伊活着的时候，伊朗政局常年动荡，内部暗流涌动，不知道哪天可能就改朝换代了。种种不确定性，使得周边资本对于进入伊朗极度谨慎。

以上原因，导致伊朗非常缺乏外部资金和技术输入，无法更新基础设施和工业设备，发展极为落后。

被孤立的状态，也严重限制了伊朗商品的出口。

以巴林为例，伊朗资本几乎不允许落地，就连普通的贸易都要严查，伊朗商品想进入巴林市场，难上加难。

沙特完全禁止伊朗能源产品进入，基建、工程绝对不允许伊朗企业参与，伊朗货物必须重点抽查，伊朗货物滞留港口的时间，通常比其他国家货物的滞留时间更长。

就算是和伊朗关系较好的阿联酋，也对伊朗资金和商品有着严格限制，大额贸易几乎不允许，只能停留在小额，也就是一些小商品。

中东市场体量并不小，但孤立状态却导致伊朗与中东各国的贸易困难重重，无法真正进入中东大市场，也无法通过出口赚取外汇。

后发经济体起飞靠什么？

从日韩到新加坡，再到中国香港、中国台湾，乃至越南，都是靠出口赚得第一桶金，再一步步向产业链核心部分爬升，伊朗想崛起也不例外。

老哈梅内伊活着时，不是不知道困境的根源，问题在于突破不了。

没有美国点头，海湾王爷们哪个敢放松对伊朗的限制？哪个敢大举投资伊朗？

按当时的趋势，伊朗政权看起来很难撑太久，所有人都以为伊朗政权就像一幢破房子，美国和以色列上去随便踢一脚就能推倒，但这次大家万万没想到，伊朗竟然和美国打得有来有回。

伊朗虽然自身损失惨重，但重创了中东美军基地体系，还实控了霍尔木兹海峡，迫使美国同意为伊朗设立3000亿美元的"重建与发展基金"。

如果特朗普都同意海湾国家投资伊朗，那么，中东王爷们投资伊朗就没啥顾虑了。

伊朗外资投资的问题解决了，出口也会得到改善，原因是现在大家的利益绑定到一起，想要掀桌就会有更多顾虑。

特朗普炸死老哈梅内伊的结果，就是老哈梅内伊没有解决的问题，在小哈梅内伊任内给解决了。

更重要的是，伊朗获得的不仅是外资和市场，还把美国的中东盟友体系撕开了一道裂痕。

阿联酋在开战后，原本一直配合美国，对伊朗采取强硬态度。

4月7日，美伊签署临时停火协议时，阿联酋还特意出动战斗机，轰炸伊朗能源设施，试图破坏停火。

结果呢？阿联酋非但没能破坏停火协议，自己还被特朗普要求向伊朗"投资"。

一旦自己的利益放在伊朗，那么以后当美伊、伊以再度爆发冲突，阿联酋为啥还要冲在前面？巴林、科威特这些美国盟友，同样会掂量得失。

也就是说，一旦3000亿投资真的砸下去，今后美国还想拉拢逊尼派围攻伊朗，难度就更大了。

此时此刻，最憋屈的应该是以色列。

回想三个多月前，以色列和美国联手，成功击杀哈梅内伊等一众高层，伊朗眼看就要完蛋，以色列眼看就要大赢特赢。

结果伊朗不仅没有发生政权更迭，还变得空前团结，硬生生靠导弹和无人机杀出一条血路，迫使美国停战，还拿到了3000亿重建资金。

形势瞬间反转，以色列从天堂到地狱，只用了短短三个月。

但是我们要知道，当以色列被逼到绝境，什么事情都可能做得出来，一定会破坏美伊谈判。

而且，特朗普撕毁协议也不是一次两次了，3000亿美元本来就是八字还没一撇的事情，伊朗未来想真的拿到3000亿美元投资，恐怕没那么容易。
