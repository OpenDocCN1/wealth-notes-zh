




# 德国留学生连环性侵案，到底怎么回事？

260609 文/卢克文工作室嘉宾 概略北方

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

5月18日，德国柏林州法院门口，被围得水泄不通。

这是中国留学生邵之霆出庭受审的日子。

邵之霆这个名字，绝大多数中国人很陌生，但是在德国的留学生圈子里却臭名昭著，因为他就是去年以来震惊中德两国的留学生性侵案最核心的案犯之一。

那么，这个案子到底是咋回事呢？

1

首先，我们要回到2024年，当时德国黑森州刑事警察局突然发布了一份中文警情通报，呼吁防范连环强奸犯。

为啥要用中文？因为连环性侵大案的作案者和受害者，几乎全是华裔。

随着警方调查的深入，一个隐藏在电报群组中的犯罪组织浮出水面——“德国老司机驾校”。

这个核心群组有8个人，清一色都是中国人，绝大部分居住在德国，其他人分布在荷兰和美国。

如果单看他们的学历，绝对亮瞎眼，国内985、国外名校硕博。

但这群高知人才在干什么呢？在迷奸同胞。

在他们这个群里，有一整套“黑话”。

他们把受害的女性称为“车”，女友、妻子叫“私家车”，陌生女性叫“野车”，把下药迷奸的行为称为“开车”，施害者是“司机”，用来迷奸的麻醉药物被称为“油”，下药叫“加油”。被麻醉后完全失去意识的女孩，被他们称为“死猪”，还有意识挣扎的叫“半死猪”。

这套黑话，其实不仅仅是为了逃避审查，更关键的在于，它是一种“无罪化”的自我洗脑。

很简单，一个人说“我要去迷奸一个女性”，他还知道自己在犯罪。但他说“今晚计划开一辆车”，他在心理上就把犯罪包装成了一次日常活动，就再也没什么负罪感了。

这个群组的主犯，叫张大鹏，1979年出生，2002年毕业于哈尔滨工业大学，2005年赴德国留学，就读图宾根大学计算机专业。

被捕前，他在路特斯跑车担任IT经理，看起来生活很体面。

但这只是他的A面，而他的B面，是一个死变态。

2020年，张大鹏接触到了电报上的一个暴力色情群组，然后就仿佛打开了新世界的大门，并迅速成为实践者。

一开始，他只敢打身边熟人的主意，范围包括同事、邻居甚至前女友。他会在请客的饭菜里偷偷投放麻醉剂，等对方失去知觉后实施性侵，并全程录制视频发到群里炫耀。

据调查，他有25个聊天群组，接触成员超过2300人。

到了2024年，他觉得杀熟不过瘾了，又开始盯上了其他同胞。

他的手段其实很简单，就是在小红书上假扮女性，盯上发布公寓出租信息的中国女性，先谎称替女友看房，等对方放松戒备后下手。

根据法庭文件披露的细节，张大鹏作案从不做安全措施，在犯罪现场肆无忌惮地留下自己的体液。有一次，他甚至在作案后，给受害者床头留下了紧急避孕药和一张手写的威胁纸条，大意是如果对方敢报警，他就会把视频发到网上去毁了她。

后来，警方在张大鹏电脑里查获了超过1000万份涉及性暴力的视频，其中甚至包括高达17万个儿童色情文件。

2026年2月，德国法兰克福地方法院判决张大鹏涉22项严重强奸、下药迷奸、偷拍等罪名，被重判14年有期徒刑。

法庭还附加了“预防性羁押”条款，也就是说，哪怕他服刑完毕，只要心理评估认定他依然具有社会危险性，他就永远别想从牢里出来。

而这，还不是张大鹏所有的恶，他最大的恶，是教唆他人模仿他。

每一次作案成功，他都会把过程包装成“开车成功”的经验分享，甚至还开直播。

这就是这个群组最可怕的地方，单个犯罪者也许会恐惧，会犹豫，会担心被抓。但一旦进入同类之间，他的羞耻感会被群体分摊，罪恶感会被互相鼓励抵消，进而互相壮胆，一起作恶。

很快，张大鹏有了自己的左膀右臂——蒋中懿和邵之霆。

蒋中懿是慕尼黑工业大学机器人专业的在读硕士，表面上是个品学兼优的好学生，但背地里是一个重度恋尸癖。

他甚至在法庭上承认：“我从小就觉得睡着的女性很美”，而他的侵害对象也是以熟人为主，甚至包括了自己的女友。

法庭查明，他在一年内就对女友下药迷奸了至少7次，连女友都要迷奸，充分说明他的心理已经变态了。

更可怕的在于，他还是团队的“试药人”。

要知道，麻醉在医学里是一门非常精密的科学，稍有不慎就会导致呼吸骤停，但蒋中懿根本不在乎受害者的死活，而是变着花样使用各种麻醉药。

法庭认定，有好几次受害者已经陷入深度昏迷，甚至出现了呼吸骤停和窒息的濒死迹象，但蒋中懿依然没有停手，继续实施性侵并录像，甚至将高跟鞋、香烟塞入被害人体内。

这就是为什么蒋中懿的罪名不仅仅包括性侵，还有“谋杀未遂”。

看起来这事就是个性侵案，但德国法庭认为，如果被告使用的药物剂量足以危及生命，而行为人明知这种风险仍然放任结果发生，那就不再只是性犯罪问题，而是故意杀人问题，受害者没死，只是因为受害者命大，而不是蒋中懿没有置人死地的风险。

所以，这不是诡辩“他只是想性侵，不想杀人”就能糊弄过去的。

2026年4月，蒋中懿因谋杀未遂、强奸罪等，被慕尼黑法院判处入狱11年3个月。

那么问题来了，蒋中懿这么丧心病狂，他的药理知识是哪来的呢？

来自团队技术顾问——邵之霆。

邵之霆，32岁，本科毕业于河北医科大学，后来考入北京大学医学部，拿到了肿瘤学硕士学位，2021年赴德国柏林夏里特医学院攻读博士。

在群组里，邵之霆专门指导群友如何用药，群里有人弄到了强效麻醉剂，邵之霆便利用自己的专业知识，教他们如何计算剂量，如何混合使用才能让女孩迅速失去意识且无法反抗，同时又避免当场猝死惹上人命官司。

他甚至连口感都考虑到了，为了掩盖麻醉药物的苦涩异味，他教群友在饮料或水中加入大量冰块来麻痹受害者的味觉，或者把药物掺入烟草中，让女孩在抽烟时不知不觉地摄入。

真是可悲，一个本来应该是救死扶伤的医生，却成了犯罪组织的技术专家。

除了做技术指导，邵之霆本人也是一个禽兽，根据德国检方指控，他在2019年至2021年间，对一名女性实施了多次下药性侵。

那么问题来了，这么复杂隐秘的一个犯罪组织，到底是怎么落网的呢？

还是从张大鹏开始。

自从中文警情通告发布后，多名受害者报警，然后线索逐渐指向同一名嫌疑人，就是张大鹏。

2024年10月，中德警方开始合作侦查，中国警方通过核查一些他们早期联络的QQ号，精准锁定了这群人的现实身份。11月14日，张大鹏在德国被捕。

从张大鹏被捕的那一刻起，“德国老司机驾校”的覆灭，已经是时间问题了。

三周后，蒋中懿在住所落网，警方破门前数小时，他刚刚侵害过一名受害者。

之后，其他群组成员陆续被捕。

比如负责走私麻醉药物的徐开元，在汉堡被捕后，深知自己罪孽深重，于2024年12月在狱中畏罪自杀身亡。

另一名核心成员翁偲喆，在美国洛杉矶被捕，他涉及的受害者包括他的儿时好友、同学以及在美留学的中国女生。

目前，8人中已有5人被起诉，其中3人的案件已结束一审。翁偲喆也在洛杉矶面临审判，可能面临25年的刑期。

天网恢恢，疏而不漏，不是不报，时候未到。

2

这个案件让人唏嘘的是，当这些案犯被捕时，周边的人都非常震惊，完全想不到自己认识的人居然是个丧心病狂的迷奸犯。

想不到，这三个字几乎贯穿整个案件。

他们看起来体面、热情、励志，而且还不缺乏幽默。但这恰恰说明，恶人并不总是长着一张恶人的脸。

现代社会最可怕的一类人，不是看起来凶神恶煞，而是拥有体面身份、高等教育，还能精准扮演无害者的人。

他们知道怎样让别人放下戒心，知道怎样在白天维持社会形象，晚上切换到另一个人格。这就是精英面具最可怕的地方，它不是让人变好，而是让坏人更会伪装。

不少人看到案件后，往往会感叹“他们这么高学历，怎么还干这个？”

这个问题本身就暴露了一个误区：中国人太看重学历了。长久以来，中国社会有一种观念，认为“读书好的孩子坏不到哪里去”。

但这个案子，恰恰证明了，学历只能说明一个人掌握书本知识和应试的能力，并不能证明他是好人。恰恰相反，有时候，这种高学历犯罪的危害更大。

你看，在这个案子中，懂医学的人，可以研究药物，懂IT的人，可以使用加密软件，懂外语、熟悉海外生活的人，可以在留学生圈当大神，轻易获得受害者信任。

所以这不是学历的问题，是人品的问题，正如刀在医生手里是救死扶伤的工具，在罪犯手里就是凶器。

那么，国内品学兼优的好学生，怎么出去了就变罪犯了呢？

你仔细观察这帮人，就会发现他们有个共同点：极度自卑。

说白了，他们在德国虽然有着体面的工作或学业，但很可能在当地的主流社会文化中处于边缘位置，而欧美文化中的择偶市场对亚裔男性的隐性排斥，加上他们在生活中的压力，也让他们在现实中极度压抑。

于是，他们在暗网里找到了同类，他们通过迷奸折磨女性，来重新获得那种在现实中得不到的成就感。

那为什么专挑中国女性下手呢？

很简单，无非也就是语言相通，容易接近嘛。

这其实反映了海外女留学生的一个普遍困境：到底该相信谁？

她们在异国社会里既是少数族裔，又面临语言、法律、社会关系上的一系列困难，对陌生环境本就不熟，只能更依赖同胞圈、留学生圈或者熟人介绍。

而老司机们恰恰利用了这一点，他们只要钻进这个网络，戴上一个同胞、学长的面具，就能轻易接近受害者。

所以这个案子摧毁的，不仅是几个女性的人生，还有女留学生群体对整个留学圈子的信任。

要知道，人一旦被这种方式伤害，创伤不是人被抓了就结束的。

因为很多受害者一开始甚至不知道自己被侵害过，他们只是觉得断片、不舒服、记忆缺失，却不知道发生了什么。直到警方上门，她们才被动知道自己曾经遭遇过什么。

这就相当于受到了两次伤害，甚至第二次的伤害要更大一些。

更可怕的是，你怎么知道那些可怕的视频没有被流传上网呢？一旦上网，就变成悬在受害者头上的刀，能威胁她们一辈子，这就是这种案子最可怕的地方。

案子曝光后，有些评论说“为什么你去看房”“为什么你喝东西”“为什么你不早点报警”。

但这种思路是错的，不能把安全责任全推给女性，真正该被要求改变的，其实是环境。

平台应该对租房、交友类风险有更强的提醒机制，海外高校和华人社团应该建立更明确的求助路径，使领馆、学生组织和当地警方之间也应该有更密切的联动，还有麻醉药物交易，也必须形成更强的国际协作。

否则，抓住一个“司机”，还会冒出下一个“司机”，打掉一个群，他们还会迁移到另一个群。

而这，才是这个案子之后，我们真正需要重视的东西。
