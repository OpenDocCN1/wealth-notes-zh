


# 公积金新政即将到来，利好哪些人群？

文/卢克文工作室嘉宾 云梦竹

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

6月5日，住建部发布了一份重磅文件，《住房公积金管理条例（修订征求意见稿）》。

相对于旧条例，未来的公积金政策将发生很多重大变化，而且每一个变化，都会直接影响咱们的钱袋子。

作为一个曾在房地产行业从业多年的老司机，我会为大家一一拆解普通人今后如何利用公积金最大化实现自己的居住权利，以及需要注意避开哪些雷区。

# 01

首先我们来看意见稿的内容，这次最显著的变化，就是极大地扩大了公积金的使用和覆盖范围。

一是覆盖人群的扩大。

公积金贷款的最大好处是利率极低，但过去，这份好处只有少数人能够享受。

![](img/e316e5d4bd1e2c9e01e18f3b5215218e_0_0.png)

我们大多数城市，都只有政府单位或大企业会给员工缴公积金，经济效益差的单位，根本没有公积金这一说。

根据中国人民银行的全国住房公积金年度报告，全国实缴职工只有约1.76亿人，而根据我国国民经济和社会发展统计公报，全国就业人员总量约7.34亿人，相当于每5名劳动者里，只有1个人有公积金。

但将来，任何灵活就业人员，外卖员、个体户、网约车司机，都可以自愿缴纳公积金，并享受公积金的低利率，也就是说，今后公积金将真正成为一项全民普惠政策。

二是适用地域范围的扩大。

以前你在哪里缴公积金，就只能在那里买房。将来，不同地区住房公积金可以实现贷款互认，以后大家可以跨地区贷款买房。

那么，“异地认贷”主要惠及哪些人群呢？其实是三四线城市的体制内人员。

三四线城市体制内的公积金缴存群体基数很大，但这些人可能已经在本地买了几套房，账户里的公积金长期处于“只缴不取”的闲置状态，同时，他们又有到省会或一二线城市买房落户的强烈需求，异地认贷政策无疑会支撑他们的购房需求。

其实此前已经有一些地方在推进这件事了。

比如今年4月，南京将异地贷款范围扩至安徽全域，苏皖29个城市的缴存人在南京购房都可申请公积金贷款。

5月，南京房市就显现出强劲的“虹吸效应”，有力拉动了安徽购房需求向南京释放，成为当月南京新房成交回暖的核心驱动力之一。

未来，房地产市场大概率走出“K型走势”：一二线城市需求支撑走强，三四线城市逐渐承压。

三是我们需要重点关注的，也就是提取范围扩大了很多。

在此前的政策中，公积金聚焦于“买”的阶段，但将来，你不仅可以用公积金买房，还能用这笔钱装修、维修、租房，甚至支付物业费。

一句话，只要是和房子相关的消费，原则上都可以提取公积金。

我们重点说说租房和维护。

本轮公积金全面支持租房提取，意义十分重大，因为现在中国人租房的需求，已经开始超过买房了。

国家统计局数据显示，2021年我国流动人口规模达3.85亿人，占总人口的27.3%，叠加每年约800万高校毕业生涌入城市，租房需求的基本面极其庞大。

现行的公积金政策不是不准用来租房，而是为了防止违规套现，租房提取门槛卡得很死，房租超过工资一定比例，超出部分才能提取。

很多地区要求租赁备案才能提，备案往往意味着租赁税，如果不备案，额度就比较低，比如成都非备案情况下每月只能提1200元。

另外，公积金余额一般情况下是和贷款额度直接挂钩的，公积金账户里的余额越多，可贷额度通常就越高。

租房族为了以后买房，不敢真的提取公积金来租房，所以现行政策几乎没有让租房族享受到实在的利益。

未来新政会有两个重要变化，一是大幅度降低提取门槛，二是规定租房提取不会影响今后买房的贷款总额，彻底免去了租房族不敢花公积金的后顾之忧。

公积金全面放开支持房租支付后，合同规范、备案合规的优质房源，尤其是国企系参与的保租房，未来很可能实现租金全额覆盖，甚至不需要走繁琐的提取流程，这样大家租房就非常方便了。

另一个容易被忽视，却能够实实在在给大家省钱的是房屋维修成本。

大家买房时，一般不会意识到以后房子会老化，需要维修，总觉得到时候再说。

但实际上，真到需要维修的时候，你会发现维护成本高得吓人。

我给大家简单算一笔账。

假设一栋30层高层住宅，2梯4户，一共120户，每户90平方米，那么整栋楼住宅面积大约10800平方米。以北京高层住宅专项维修资金200元/平方米的标准计算，这栋10800平方米的楼，理论上首期维修基金约216万元。

乍一看这笔钱不少，但放到高层住宅的长期维护基金里，其实并不经花。

这还是北京，很多三四线城市维修经费根本就没这么多，更别说各种挪用资金的乱象实在不胜枚举。

等到房屋必须维修时，突然发现维修的钱不够咋办呢？要么漫长地扯皮，要么地方政府出钱解决。

我们以电梯为例。

据报道，业内人士给出的住宅电梯更新成本是：国产品牌电梯本体约15万至40万元，拆旧和安装费用约5万至15万元。

也就是说，换一台电梯的总成本大约是20万至55万元。我们折中就算35万吧，一栋30层楼如果有两部电梯，未来一次性更新成本就是70万元。

北京某建于2004年的老小区，总计50部电梯需要更换，总成本1500万元。居民长期无法达成一致，最后是靠北京市出台超长期特别国债补贴政策，15年以上住宅老旧电梯每部可补贴15万，才把这事情勉强搞定。

除了电梯老化，管线老化也是个大问题。

以株洲某楼盘为例，这个小区由于设计老化，2019年之后，供水需要二次供水泵，水质检测、半年清洗一次水箱和日常维保，总费用接近15万元，业主和物业就费用问题吵得不可开交。

总之，上一波房地产高潮，催生了大批高层住宅，随着楼龄老化，它们将在未来十年二十年后集中爆发电梯更换、管线老化、跑冒滴漏等维护问题。

到时候，地方财政，特别是经济欠发达地区的财政，很难像北上深那样提供强力支持，到头来这笔钱必须由业主自掏腰包。

现在很多小区连物业费都收不齐，要指望业主出钱维护公共设施是很难的。

但以后，大家需要维修老化房屋，直接从公积金账户无痛划扣就行了。

总之，新意见中提到的“推动公积金服务于住房全周期”，是一个值得高度重视的信号。

过去的住房政策，重点是降低大家的“买房”成本，而未来的住房政策，将越来越多地支持住房作为一项长期资产的健康运转，大家未来更要考虑持有成本。

老司机给大家提几个实在的建议。

第一，手里攥着老破小学区房的朋友要留心，如果你的学区房周边冒出大量保租房，你就得重新掂量一下持有的必要性了。

由于国家的大方向是削弱学区房，促进教育公平，那么未来的城市公共服务配套，很可能进一步向保租房倾斜。

打算梭哈学区房的读者，需要谨慎再谨慎，今后很可能出现的情况是，你花几百万买的学区房，跟人家一个月几千的保租房共用一个学位。

第二，如果你的房产位于三四线城市，你最好和有公积金的人员做邻居，到时候房子老化了，大家都有公积金拿出来修缮。

如何研判小区的维修潜力呢？先看维修基金还剩多少，然后看楼龄，最后看小区住户结构。

如果楼龄低，维修基金多，年轻业主多、有稳定收入和公积金，未来维护能力会更强；如果楼龄高，维修基金少，出租率高、空置率高、老年住户还多，甚至现在连物业费都交不起，建议大家直接跑。

第三，要特别警惕三四线城市的高层老旧小区，特别是人口流入不足，地方财政能力有限的城市。一旦未来房屋老化，这些房子很可能会从资产变成负担。

# 02

这轮公积金新政，除了降低大家的居住成本之外，还有一个最核心的政策意图：

引导住房消费从侧重“买”向侧重“住”，把那些在金融系统里空转的资金，腾挪出来，打进实体经济的肌体。

过去，公积金数额巨大，但其实是一笔几乎不流动的钱。

根据中国经营报报道，截至2024年末，全国公积金缴存余额高达10.93万亿元，但超过一半的人是“只缴不用”。

但现在，你可以用来租房，可以用来付物业费，装修维护房子，甚至支持城市存量房翻新（城市更新），“死”钱就“活”了，并且直接流入了实体经济。

比如，用来付物业费，物业公司就会直接受益，用来翻修旧房，建材行业就会受益，用来装修房屋，家装和家具行业就会受益。

根据东吴证券的宏观研究报告，通过租房提取扩容、拓展装修物业费等使用范围、进一步降低贷款利率这三条路径，公积金改革合计可释放约5151亿元资金，按70%的消费倾向计算，理论上可拉动3606亿元消费，直接提升居民消费增速0.7个百分点。

之所以能够流入实体消费，是因为现在的年轻人，对住房的心态早就变了。

他们不想像老一辈人那样，为了名下有一两套房产，一辈子节衣缩食还房贷，降低自己的生活质量，他们追求的是当下享受。

就算是租房，他们也愿意花时间在网上淘精致的收纳架，动手贴一次性瓷砖贴，甚至改造阳台捯饬出一个微型花园，把房间收拾得整洁漂亮。

今后围绕“居住”的消费，不再是房地产商来当主角、赚大头，而是智能家居、可拆卸装饰材料、环保建材等行业登场。

在房地产野蛮生长三十年后，我们终于得以从冰冷的租售比、投资回报率中抽身，重新审视“房子”和“家”的区别，开始围绕着“美好诗意”的居住需求，产生一系列住房消费行为。

千亿级的住房消费，能够拉动一个千亿级的生活美学市场，而这，不就是我们一直提倡的刺激内需吗？
