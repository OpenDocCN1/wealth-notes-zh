# 王朝的名分

260629 印闲生

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

本篇是古代王朝史系列的第二篇，讲述晋朝的故事。

晋朝在中国历史上是一个存在感极低的朝代，远不如之前的三国时期。

晋朝也是一个很短命的王朝。

西晋灭吴统一全国是在公元280年，“八王之乱”发生在公元291年，满打满算过了十年好日子。

作为中国历史上最严重的皇族内战，“八王之乱”先后打了十六年。

由于一场内战打掉了政权的精华力量，使得中原地区的权力真空迅速被北方南下的少数民族占据。

![](img/5dca70d08010339406797b32f5b64c2c_0_0.png)![](img/5dca70d08010339406797b32f5b64c2c_0_1.png)

直接拉开了五胡乱华和北方近三百年的乱世。

西晋内战的源头除了晋武帝司马炎安排继任人选出现重大失误外，另一个重要的内在原因是其王朝的“基因”所决定的。

这个王朝大义的名分很差，和王莽的新朝类似。

为什么说大义的名分很重要呢？

因为王朝所拥有的最高权力需要慢慢积累，积累到足够，才能形成一种至高无上的权力。

这个中间过程便是王朝的大义名分。

而西晋，恰恰缺乏了这个过程。

下面来统计一下中国历代大一统王朝的建国模式和延续时间——

- 秦朝：开天辟地，短
- 西汉：农民起义，长
- 新朝：外戚篡权，短
- 东汉：贵族起义，长
- 西晋：权臣篡权，短
- 隋朝：外戚篡权，短
- 唐朝：贵族起义，长
- 北宋：权臣篡权，长
- 元朝：少数民族南下，中
- 明朝：农民起义，长
- 清朝：少数民族南下，长

从中不难发现，但凡是外戚篡权或权臣篡权上台的王朝，延续时间都不长。

而通过农民起义或贵族起义打下天下的，往往权力会比较稳固。

有朋友要问了，那宋朝呢？

北宋赵匡胤可是黄袍加身上台的。

一点都不矛盾。

因为北宋的主要统一过程发生在赵匡胤上任后，而不是之前。

赵匡胤和赵光义兄弟相当于继承了一家市值百亿的潜力企业，然后用了整整三十年的时间才把它做到了千亿规模。

这与几乎是白捡天下的新朝、晋朝、隋朝完全不同。

西晋和隋朝是在天下大势已定的情况下，留了一个江南小政权（吴国、陈）作为自己大一统的垫脚石。

模式非常类似。

另外，从时间线形态上去对比的话，隋朝和秦朝也有很多相似之处。

二者都是在经历了几百年乱世后，诞生的一个短命大一统王朝。

这部分我们留到隋唐篇里再去说。

西晋的兴起始自大家熟悉的司马懿。

公元249年，司马懿趁大将军曹爽陪魏帝曹芳离洛阳至高平陵扫墓，起兵发动政变并控制京都。

史称高平陵事件。

历史学家们一般认为，这是司马懿背后强大的“士族”力量对曹氏宗室的一次胜利。

所谓士族，可以通俗理解成世代为官的大家族，和“门阀”是一个意思。

中国古代在唐朝开科取士之前，官员阶层和平民阶层是完全固化的——

要么世代为官，要么世代为农。

比如司马懿，他的高祖父司马钧为汉安帝时的征西将军，曾祖父司马量为豫章（今南昌市）太守，祖父司马儁为颍川（今河南省禹州市）太守，父亲司马防为京兆尹。

全是大官。

再比如诸葛亮，刘备三顾茅庐去请的不仅仅是孔明先生的大才，背后还有他广泛的人脉。

作为从琅琊迁居荆州的大户，诸葛亮和荆州士族的代表黄家、蒯家和庞家关系都十分密切。

你中有我，我中有你。

诸葛亮的岳父黄承彦和刘表是连襟，蔡瑁是诸葛亮妻子的舅舅……

孔明先生原本就属于随时可以“出仕”的那种人物。

皇帝代代相传，将军、太守代代相传，县令、乡绅也可以代代相传。

这样以来，士族便会积累起类似“弱化版”皇权的权威，成为王朝金字塔结构的基石。

如果全国范围内若干个大的士族一联合，皇权就会受到严重的威胁。

全州范围内若干个中型士族一联合，太守便要滚蛋。

因此汉朝末年至两晋时期，皇权一般会选择与某几个大的士族进行联合，形成类似东晋时期“王与马，共天下”的局面。

东晋皇帝给王导的手诏总是用“惶恐言”、“顿首言”、“敬白”之类的语言。

正月初一王导上朝时，皇帝都要起立相迎。

其实从司马氏掌权的高平陵事件开始，司马家族就始终是士族群体的一个“代表”。

制约晋朝皇帝的不仅仅是鳌拜、多尔衮这样的个别“权臣”，而是整个国家架构的金字塔——门阀政治。

在彻底改变政权架构之前，晋朝皇帝们手中的权力与真正的皇权还有相当差距。

从这个意义上看，中国两千多年的封建王朝也是在不断进化的。

秦汉到明清，虽然金字塔尖的皇帝没有换，但整个塔身的结构却早已天壤之别。

门阀政治的现实使得西晋建立之初就自带庞大的权贵集团。

吏治领域丝毫没有革故鼎新的气象，贪赃贿赂之风盛行。

原本改朝换代过程中的社会“结构化”、“清零化”现象，在西晋这里并没有发生。

土地该在谁手里还是在谁手里，老百姓该为谁打工还是为谁打工。

这样以来，大家对于王朝的认同感就非常低。

对于一个初创政权来说，塑造一批坚定的王朝拥护者阶层非常重要——稳固基本盘。

一场大火过后，草原上生长出来新的花草树木。

原先的放牛郎成了官员，原先没有土地的拿到了土地。

这些旧时代的“放牛郎们”，便会成为新王朝坚定的拥护群体。

从发散思维的角度来看，王朝其实和我们今天市场上的品牌一样，有“IP”属性。

比如美国的“自由”，苏联的“共产”，都可以涵盖在这一范畴内。

漫长的岁月里，“IP”需要统治者（品牌经理）们去认真塑造和维护。

一个强大的“IP”可以延续很久，即使王朝灭亡了仍然有人去复兴它。

诸葛亮和蜀汉政权会一直高举“北伐中原，匡扶汉室”的大旗，说明当时的人心还非常认可“汉”这块牌子。

即汉这个王朝的“IP”是很强大的。

相对来说，晋就要弱得多了。

回到时间线上。

东晋的开国皇帝司马睿是司马懿曾孙，琅琊王（山东临沂）司马觐之子。

在八王们一番自相残杀后，司马睿和琅琊一带的士族领袖王氏家族一起南迁建立了东晋。

王氏家族的代表王导是一名非常成熟的政治家，他高度重视团结原先江南一带的大士族。

一番运作，东晋最终形成了司马氏当皇帝，王、谢、桓、庾四大家族辅政的局面。

东晋王朝浓墨重彩的一笔是发生在公元383年的淝水之战。

谢玄、谢安等将领率领八万北府兵与前秦大军决战，大获全胜。

战争这件事情就是这样，一旦赢了可以获得巨大的合法性，而输了则会丧失巨大的合法性。

是为“兵者，国之大事”。

赢下淝水之战的晋孝武帝司马曜此后权力迅速膨胀，成为东晋历史上唯一掌握真正皇权的皇帝。

而输掉的前秦王苻坚则从一代雄主的宝座上迅速坠落，不久即被人缢死。

一正一反，令人唏嘘。

淝水之战的另一个重大影响是诞生了历史上有名的“北府兵集团”。

凭借着巨大的战功，北府兵渐渐发展为一股超然于东晋政坛的军方势力，成为朝中各派争相拉拢的对象。

军功集团的迅速崛起对于王朝来说并不是一件好事。

此后东晋频繁爆发武将干政、武将叛乱的事件。

直到公元420年，凭借常年统兵积累起巨大人望的刘裕废除晋恭帝。

东晋就此灭亡。

毁誉参半的司马氏和王谢堂前燕一起，从此飞入了寻常百姓家。

宋朝的开国皇帝刘裕便是辛弃疾名词《京口北固亭怀古》中“气吞万里如虎”的那位，曾任北府兵参军。

刘宋王朝建立后，北府军成为其军事支柱，相当于后来禁军的角色。

回过头站在东晋的角度看，也真是难办——

太讲武德，军人干政；不讲武德，任人蹂躏。

尺度非常难拿捏。

不过整体而言，相对同样采用南迁模式的南宋来说，史书上给予不停北伐的东晋评价还算不错。

毕竟“王业不偏安”是政治正确。

中国历朝历代，都是在总结前人经验教训的基础上修正前行的。

笔者经常举一个小例子：

托李自成的福，清朝驿卒的薪水一直不错，属于大家羡慕的铁饭碗职业。

本篇的最后，我们就来总结一下两晋的历史教训。

# 1、王朝的名分

王朝的名分是王朝创立之初自带的“基因”，通常很难改变。

一旦有改变的机会，最高统治者绝不会放弃。

1945~1950年间，金日成始终执着于南下。（《朝鲜史书里的朝鲜战争》）

因为他知道北方的政权是“白捡”来的，缺乏大义的名分。

对南方的这场仗一定要打——赢了固然是盖世奇功，即使打平也可作为“淝水之战”，给半壁江山提供存在的合法性。

从今天平壤官方的表述看，他把1950~1953年的朝鲜战争作为“祖国解放战争”。

含义是不言而喻的。

# 2、军功集团

一个政权长期处于战备或对外军事作战状态，军功集团的地位会大幅提高。

长年累月，容易形成固化的“北府兵”模式。

如何在“战力”和“固化”之间取一个平衡，需要王朝统治者们仔细拿捏。

# 3、士族

古今中外任何一个政权建立，都要解决“谁来当官”这一问题。

总结一下，无非是以下几种模式或组合：

- 士族
- 科举
- 士族+科举
- 民选+文官体制……

西方政治生活中经常会出现所谓的“政治世家”，比如：布什家族、安倍家族。

从他们的身上，其实能看到一点中国古代士族的影子。

有些事物尽管发生在一千多年前，但经常会被包装一下重新上市。

如何包装，那便是政治的艺术了。

全篇完。
