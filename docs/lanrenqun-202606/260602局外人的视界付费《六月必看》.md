# 前言：熬夜写的付费文来了

整个五月市场是极度割裂的，科技抱团炒作，不断地创新高，其他的票则因为严重缺血，不断创新低。

之前我跟大家探讨过，市场这么走到底有没有错？

总有人会拿出那句屁话，市场永远不会错，错的是投资者。

如果你这么想，那就别炒股了，估值永远都是正确的，请问你怎么可能在低位的时候买得到票，又怎么可能在高位的时候卖得出去？

炒股本来就是合理地利用市场的错，市场永远在犯错，从一个错误走向另一个错误，并且也在不断地纠偏，就看你怎么去利用了。

所以大家没必要骂那些抱团的科技股了，你骂是因为没在你选的方向跟个股上抱团罢了，但话又说回来了，真到了天降馅饼的时候，你能接得住吗？

![](img/9b0dd739ca07dc12e6d61ef7eb7fae8f_0_0.png)

炒股炒久了，但凡炒出点水平来的人，最后都会成为哲学家，这里是人性的博弈场，技术是表象，人性才是真正的内核。

昨天跟一个朋友吃饭，他说自己被套在了商业航天，就不停地问我，不是说好了6月份马斯克的SpaceX上市吗？商业航天怎么会跌成这个样子。

从人性的角度来分析下，当大多数人都默认SpaceX能带动商业航天走高，请问你如果是少数的操盘手你会怎么做？肯定是先跑路啊，让大家傻乎乎地等着6月好日子到来，提前把筹码送给韭菜们，一挥衣袖，不带走一片云彩。

记住：所有人都知道的好消息不是好消息，所有人都知道的坏消息也不一定是坏消息。

从这个角度再看6月份的世界杯魔咒，它到现在还能算是个魔咒吗？

这一届的世界杯央视都能用超低价抄底，根本不给国际足联一点面子，这在以前你敢想？

听说世界杯在很多球迷心目中的地位甚至都不如苏超之类的地方联赛，那么在这个时候，你非得喊世界杯魔咒，非得逼着大部分既没有兴趣，也没有精力点灯熬夜看世界杯的交易员被世界杯影响，是不是有点过了？

之前为什么都喊世界杯魔咒，道理很简单，这是个博弈的世界，每个人都有自己交易的囚徒困境。你是中国的交易员，可能也不太赌球，但海外的交易员有在世界杯赌球的习惯，资金从一个赌场冲向另一个赌场，新场子人声鼎沸，旧场子自然就没啥人玩。

那么你作为交易员知道有这种事发生会怎么做？那当然是先跑一点再说，不然呢？在场子里被人抓了买单？

那么我们再分析下这一次的世界杯，反正跟东大无关，全世界的金融格局摆在那里了，中美在科技场上的角逐。

美帝现在压根不敢松懈，根本没办法让自己的AI泡沫戳破。

美帝这波还安排了两家大模型公司：OpenAI和Anthropic上市呢，那都是万亿美元级别的大家伙。

我看到好多人在那里写文章说三大抽血机，要把资本市场的血抽干了。

那么你为什么不换个角度来看这个问题？

全球存量市场，大家都没办法了，制造业跟东大PK，那都是让人绝望的存在，资金只能冲向未来，所谓下一个风口。

请问如果你把钱都投了美帝，那么在选边的时候，你会选谁？

所以OpenAI、Anthropic跟SpaceX都要争着上市，人家是要抢占生态位，钱在哪里，爱就在哪里，是不是这个道理？

即便你再悲观一点，认为美帝已经没办法了，这波AI泡沫一定要破，那么我问你，它会选择在六月份这个啥目标都没达成的时候自爆吗？

事实上，中美现在都在自己玩自己的，一起发力抽全球的血。这个时候既然美帝不肯自爆，那么你凭什么固执地认为东大会主动挑破所谓的泡沫呢？

当然了，我承认现在科技抱团一顿野蛮操作，对整个大A市场生态都起到了很不好的影响，批评的人很多。

我A的很多被爆炒的科技股本身科技含量并没有吹出来的股价那么高，我们也清楚东大最牛的科技企业，一向被各方黑的华为是没有上市的，上市的比亚迪也由于种种原因，股价各种被打压。

但这并不能否认科技股大涨在科技战中的号召作用。

还是之前我说过N次的理论，这就是千金市骨，让那些真正有能力的人看到，在大A小企业、创新企业是能走出自己的路，被市场给予很高的估值，而不必像在美帝那边，只能接受被大企业收编的路。

科技也好，人才也好，你是很难一早就看出最终的发展高度。就像牛逼的将军，没有谁是在学校里学出来的，都是在战场上各种拼杀最后赢出来的。站在上帝的视角，你能把大家评论得头头是道，但站在现在，你真知道会是谁能拿到最终的胜利成果吗？

发展是需要养蛊的，我在19年的时候曾写过一篇文章说新能源汽车产业链，当时很多人批评引入特斯拉，有了特斯拉大家才会重视新能源车这个产业，特斯拉在中国的成功会培养出强大的产业链，最后才有中国车直接对全球对手的碾压式优势。

你现在再看当年大家对新能源产业的批评，是不是觉得耳熟？

现在你再告诉我，今时今日，中美AI竞争格局有分出胜负了吗？如果没有的话，如果我们还在被卡脖子，你又凭什么认为资本市场已经可以靠边站了？

我A跟美帝走的是两个路线，我们是坚持资本服务于产业，美帝那边没有什么产业之上的说法，一切都是资本用来吸血的手段，不然你怎么解释美帝的大企业做到最后，都能给你干成负资产？

当然了，六月份美帝有很多经济数据是不够好看的，比如说CPI降不下来，新上任的美联储主席沃什总得干点什么，哪怕是口嗨式喊话，市场多少也要给点反馈，不然岂不就是太不给面子？

所以个人认为，六月份你想看我A大跌，那是不现实的；想看到大A咔咔暴涨，也是不现实的。

科技股抱团没那么快垮掉的，大家可以去复盘一下过去几轮抱团最后是怎么翻车的，比如说20年的白马、23年的新能源。

高位抱团的科技有些即便是鱼尾行情，但鱼尾巴也要反复抽打扑腾，这个过程里即便创出新高也很正常，撤退的时候都是边打边撤。

五月最后一个交易日被人看不起的老登股们集体崛起了，可以当超跌反弹来看，但现在科技这个方向各种套路、题材层出不穷，抱团完全可以换个标的来抱，总归既有话题，又能调动情绪，这不比那些老登有话题度？

当然了，你跟我说15万亿的城市更新有没有对老登估值有所提升，这个是肯定的，但还是那句话，股市就是故事，哪个故事更动听？需要我多说吗？

这波如果月初大盘继续再下杀，那就是行情给的捡钱机会，短线选手可以多留意那些弹性好的科技股，抱团就是这样，杀的时候厉害，拉的时候一样很给力。

免费的部分我跟大家分析过，科技到现在并没结束，中美两个大水泵都在抽全世界的血，美帝上市了三家大家伙，我A要上的也不少。

硬件存储两巨头、机器人，五月底又传出来，AI大模型两个大家伙也要回大A。

不要跟我说什么抽血，姐之前是做地产的，不晓得谁还记得地产最热闹的那些年，房价不断地大涨，怎么就没有抽血一说呢？谈起来大家都在那里回忆经济上行的美。

重申一下，我A绝对不是什么存量博弈，大家可以看看最近的政策，都不让你偷偷到外边玩，HK那边也在严查内地身份开户，很多资金能绕道出去的通道都被堵死了。现在更是没有人提炒房两个字，看看银行存款利率，只有活在梦里的人还在那里哔哔会有5%的年化。

之前还有傻叉大V在那里说什么通缩，缩什么？想缩也缩不动啊。这波中东乱了，能源价格暴涨，供需失衡，输入性通胀不可避免。

很多资金最后都会慢慢往大A里走，这个是趋势。

中美都想在AI时代里拿到控制权，从这个角度看，你认为对AI的各种支持是到头了，还是刚刚开始？

微软跟黄仁勋打算合作，搞AI电脑、AI本地化部署。微软有自己的操作系统，来个AI化升级，想想看，Windows操作系统的统治力，你不管它最终能不能搞成落地，且只说这个故事喊出来，市场会不会认账？

市场是绝对会认账的，故事相当动人，外国人的故事要比中国自己的故事更有卖点，所以这个方向又能炒一波了。

我A在炒AI方向上，吃硬不吃软，硬件票抱团屡创新高，软件应用却在创新低，我以为AI电脑这个概念会给应用开启新征程。

五月底我也提醒过很多粉丝，芯片跟芯片相关行业的炒作到现在差不多也到了鱼尾行情阶段。

这时候你在里面的，应该是逐步减仓，保住收益，争取不要被行情拉着坐过山车。

这时候你问我AI硬件能不能继续炒，我怎么说呢？除了个别的细分方向，比如说PCB之类的，还在相对较低的位置，再往外扩张一下，比如说消费电子，这里的想象力空间就是AI会重新定义消费电子，未来的市场空间更有想象力，最重要的是，这里很多票还在相对低位。

六月份方向一样非常简单明了，继续AI！

AI硬件方面，涨太猛了，减持、监管双管齐下，向上的趋势到这里即便没有打住，起码也要休息一下。

但是你别以为就这么结束了，记住我A的心法，一切都能AI，所以什么PCB、消费电子也会被拉进AI硬件概念里。

封装这个方向上个月走得很好，大概率本月就不会有那么强了，毕竟先进封装其实是喊了几年的，华为的π定律也不是今天才被市场热炒的，短期利好出尽不是什么好事。

我认为接下来AI到了软硬切换的时候了。中美都有大模型公司要上市，估值给得那是相当的高。

之前我们讨论过很久的应用，硬件不管你怎么暂时盈利，怎么猛地往下砸，但最后AI要实现盈利，不是靠着互相卖硬件吧？终归还是有应用，让大家都用起来，然后在客户端收费盈利。

当年的互联网泡沫、移动互联网泡沫，想想看，是不是都一个套路？

先是硬件供应商咔咔一阵猛涨，但到了最后，出来的大牛都是搞应用的，并且还是长牛。

记住，中美搞AI竞争，未来的格局就是赢者通吃。如果你站在这个角度去分析市场，你会发现中美都在着急想做出来一款能通杀全球的应用。

否则AI不就成了个笑话吗？

老粉丝都知道我蹲了很长时间的应用，也有人因为一直踏空抱团硬件行情而生气，但你得知道，人只有在做自己认为确定性最高的投资的时候，才能赚大钱，因为你敢重注，且能拿得住。

我A向来是跟着美帝的屁股跑的，大家可以看看美帝那边的软件票，从之前的被资本市场嫌弃，到现在又变成了香饽饽。

当然了，这里有资本的自救，毕竟太多私募信用贷款是被软件企业借走的，真暴雷的话，大家都要吃不消，搞点利好出来，大家都能缓缓。

谈到AI电脑，不知道你们有没有想起之前红过一阵子的AI手机？

系统自动给你办很多事，很多需要本人授权的权限都开放给了AI，那么里面到底有没有风险？

之前龙虾风靡，结果红火了几天就开始暗淡了，效率当然有的，但在安全面前，很多人自觉后撤。

如果未来的趋势是电脑、手机都要重新被定义，直接AI化，那么其中最大的需求难道不是网络安全吗？

所以提前埋伏在这个方向上，必然有收获。

# 老登股这个方向，我现在只推荐电力跟创新药

电力的逻辑大家都清楚，并且这一次中东危机，波斯跟美帝都没那么容易消停，这个我跟大家分析过很多次，大家有兴趣去看看我之前发的免费文。

70年代的石油危机彻底改变了全球工业格局。

怎么你们还那么天真地认为，这一次对世界没什么大的影响呢？

波斯最终不会让出霍尔木兹海峡利益的，这对全球能源供应意味着什么？大家心里都清楚。

当然了，这对中国是好事，全世界会加快进入到全面电力化时代。

AI新增的需求，原有能源供应格局被打碎，逼着世界作出改变。

东大电力全球断崖式领先。

不管是炒算电协同，还是电力出口，还是别的，总之电力这个老行业在新时代里被赋能了。

还有一个炒股口诀，冬炒煤炭夏炒电，本身夏天电力每年没事也会炒一波。

所以电力这个方向是很稳的。

至于创新药方向，这个依旧是在中美竞争的格局下，我们从5月底开始放松了对创新药进医保、商业保险的许多限制。

本身医药的市盈率就已经被干到了历史低位，便宜是最大的利好，再叠加一下产业政策支持，总归还是有点指望的。

# 15万亿的城市更新

这里主要的机会更多集中在地下管网这个方向上，当然了旧房改造，会带动跌成狗的建材相关板块。

但怎么说呢，这是国家给出来的稳存量的政策，投射到具体的股票上，无非是个止跌企稳；再想讲出很牛的增长故事，市场会买单吗？

当然了，结构性的机会肯定有一些，但那么点涨幅，在更确定的方向面前，就有点不够瞧了，同理各种地产票。

困境并没那么容易反转，关键是市场有非常明确的主线在那里咔咔吸血，这些板块到底有多少机会呢？还需要猜吗？

黄金长线当然看好，黄金的逻辑是美元信用崩盘，这个好像一时半会儿也没办法逆转。当然了，短线黄金受制于国际地缘政治，霍尔木兹海峡被封，全球能源供应出问题，那么很多国家就得卖掉黄金来买原油，抛售的多了，自然价格就要承压。

但这能影响美元的长期走势吗？美元未来在中东的控制力会进一步降低，一旦到新的平衡建成，那么各国央行依旧会转回来抢购黄金。

还是那个话，长线看好黄金不等于建议买黄金股。

有色、钢铁各种大宗商品未来必然还会创新高的，道理很简单，全球大通胀已经在路上了，最终大家都会拥抱真正的财富，各种资源。

但相关股票大家暂时还是回避一下，性价比太低了，毕竟沃什刚上班当美联储主席，哥们多少会干点事，控一下短期通胀，这就意味着短期没什么大的机会。

# 新能源板块

个人认为这个方向即便之前被略套，问题一样不大。

为什么这么说呢？道理很简单，全球能源格局彻底改变了，发展新能源从之前赶时髦变成一种必选项，这里市场空间想象自然就大起来了。

其中储能方向还可以跟AI搞搞互动，不定哪天你美帝就要拿着这个做点文章。

本身新能源汽车的龙头企业明显被低估，市场总在犯错，但市场的纠错能力一样很强。

6月份如果大盘搞幺蛾子、各种动荡，那么关键时候可以看新能源这个方向来避险。

不要太担忧什么美伊和好，和好不了一点，利益都摆在那里了。

# 大金融

不好意思，现在券商已经不是市场的晴雨表了，大家要密切留意，一旦券商无故被拉起，大概率是要砸一下科技票的。

这货已经成了反指。

保险跟银行已经成为主力维护指数的工具人，有人认为搞风险对冲，要配一点，那也无可厚非，但在这里选这个边，真的是意义不大。

继续长线持有被低估的中特估。

我们既然分析了六月份会很动荡，在这种动荡行情里某队必然会出手控制住指数，指数对他们来说很重要。

如此来之不易的牛市，难道就这么放生了？想想都知道不可能的。

这个时候就需要那些真正有价值、长期蹲底部的中特估了。

所以现在进去大概率就要当一阵子的“大冤种”了。
