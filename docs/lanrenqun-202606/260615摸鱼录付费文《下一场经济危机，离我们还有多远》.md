


# 下一场经济危机，离我们还有多远

260611 摸鱼录付费文  
整理：公众号懒人搜索，懒人专属群精选  
懒人微信：lazyhelper1  

今天晚上我们来聊一个大家很希望我去讲，然后我也很希望去讲了很久的话题：下一场经济危机，究竟离我们还有多远。

这一节课不一定会让大部分人赚钱，但大概率可以让你避免亏钱。

在上次证监会下重手处罚富途和老虎的时候，我就在文章里面说过了，我的看法是整个管理层预判美国的股票市场在不远的将来会出现一次非常大的下跌，其规模应该要远超于08年金融海啸，所以才未雨绸缪地做出那些处罚措施，来防止更多的人把钱投到美股这个大坑里面。

准确来讲，不仅是美股是一个坑，我觉得所有的美元资产在将来都是一种有毒的资产，包括美股，包括数字货币，包括美债这一系列锚定在整个美元体系上的金融衍生品，将来都有可能会爆发非常剧烈的波动，其持有者的财富会在波动中被直接清零。

![](img/02ffa2dc892c60bdada4da9a58a701df_0_0.png)

从我个人来讲，这一两年凡是遇到问我股票市场问题的人，我都会回答说我不是特别看好，不管是太平洋东边还是太平洋西边，我都不是特别看好。

对于太平洋东边的股票市场来讲，我觉得本身的制度还有更多需要完善的地方。从本质上来讲，股票市场还是更接近零和博弈的屠宰场，而散户进去是被屠宰的对象。

对于太平洋西边的股票市场来讲，我觉得虽然看似涨幅很厉害，很凶，但是给我的感觉就是泡沫末期的感觉。如果经历过2007年A股6124点之前那种大量所谓权重股大幅上涨的人，应该会有更深刻的体会。所以两边我都不看好，我个人觉得在接下来的时间要么手里拿着现金，要么如果真要有相当于08年那样规模的金融危机爆发，那它在前期出现流动性危机的时候导致了黄金大跌，那就是配置黄金的最好时候。

这是我的第1个公开的核心判断。

说白了，黄金它不仅是对法币的一种未来潜在可能发生的危机的未雨绸缪的准备，更是对将来可能会出现的混乱局面的一种准备。

如果让我用两个字来形容我对今年的判断，我可能会非常直觉地不假思索地用“混乱”两个字来总结。这不是一个非常唯物的，能够给出大量清晰逻辑的形容，这纯粹只是我个人的一种主观上的感觉。这种主观上的感觉，不仅来自于我对整个世界经济及政治地缘政治体系的感受，包括天气的怪异，给我的感觉也是一样的，有太多的东西是非常混乱的，给人的就是一种狂躁、燥热的感觉。我直觉觉得一场危机在酝酿，而我们身处危机爆发前夜的混乱。

说实话，这五六年来，我觉得最安稳，最让人觉得能够气定神闲的还是防控措施依旧存在的那几年。哪怕整个世界混乱无比，但是我们却好像仿佛身处暴风雨中的风眼一样，那几年是最为平静，也是我觉得过得最为舒适的几年。

自从防控措施在2022年年底结束之后，我觉得整个世界的稳态就急速地在崩塌。2022年年底防控措施的结束是始终让我觉得非常意难平的一件事。因为它代表了某种稳定秩序的消失，取而代之的是直接进入了一个混乱且动荡的未来。

从我个人接触到的样本来讲，我觉得似乎大家的生活并没有变得更好。不管是经济情况，个人收入，还是家庭幸福指数或幸福程度，我觉得这几年接触下来，大部分人的感受都不会特别好。听到的都是钱越来越难挣，生意越来越难做，健康状况也每况愈下。就连唉声叹气的人好像也比之前多了不少，很多朋友聚到一块聊天就是各种叹气。

虽然凭借着在黄金市场上的操作这两年我的收益率是比以往好了不少，但是从某个侧面来讲，如果黄金市场上能挣了不少钱，那反过来意味着整个世界已经变得更加凶险，更多人的生活水平和经济状况出现了下降。

对于我来讲，我觉得其实我们在防控措施还存在的那三年是存在非常好的机会去扭转我们的经济结构和经济增长的动力的，但是这个非常好的机会已经被错过了。

如果说经济是一艘大船，之前的舵手能达到85分到90分这样的分数，但是他不知道为什么莫名其妙就被换掉了，然后还掉进海里被淹死了，然后上来了一个真实水平只有50多分，靠作弊才能拿到及格水平的人，在影响着这艘大船。

就像整个经济变得非常的拧巴，每个人都不舒服，心里好像憋着一股怨气，不知道该怎么发泄。挣钱的，没挣钱的都不舒服，总感觉整个社会更多是弥漫着一种自暴自弃和绝望的氛围，整个社会的气场非常的负能量，非常的不好。

我不能在公开的渠道说某些政策是错误的，不好的，我只能说这些政策还有更多的可以改善的空间。是的，比如说主导经济发展的增量的政策，我们确实是有很大的改善的空间的。

大家都清楚，从我们国家的经济发展史来讲，经济增长一般是三个主要的驱动因素：投资、消费以及出口，这三者可以说是支撑中国经济发展的三驾马车。

但是现在中国人的消费是偏弱的，消费实际上从未成为最主要的一种增长力量，主要的原因在于它不像投资或者出口这样有爆发式增长的能力。因为老百姓的收入并没有出现一个肉眼可见的爆发式增长的渠道，这也就注定了消费是很难成为增长的一极，它可以成为稳住整个经济体系的一部分，但是没有办法说像投资或者出口那样出现比较剧烈的爆发。

从人类历史的发展来总结规律的话，中国居民的消费水平要出现跳跃的爆发式的增长，那得是我们像第2次世界大战那样，彻底将美国打败，取代美国，成为这个世界上最强大的国家之后才会有的事情。

因为消费本质上是果，不是因。强大的消费能力是建立在强大的、独一无二的、能够对外索取无数资源和吸收无数流动性的货币系统之上的。

而这样的一个货币系统，它的底座必然是对世界范围内的能源资源的控制和超强的军事实力，以及独一无二的科技实力。

我们现在还都不具备这些东西，所以靠消费去拉动经济增长，在将来很长的一段时间内都是一件理论上可行，实际上很难去做到的事情。

而对于投资来讲，自从房地产步入下行周期之后，大规模的基础设施建设肉眼可见是少了，也就是说，上面并没有打算继续拿这种大规模的投资作为推进经济增长的动力。这也就导致了在2022年年底防控措施解除之后，实质上走回了以出口来推动经济的老路。

如果大家有足够高的政治敏感性的 话，一定能够比较明显地感受到这些年一直在弱化GDP增长的影响，你在新闻上可以看得到已经不怎么喜欢提GDP增长多少多少了。

但是，你能够非常明显地感受到，这些年媒体上很频繁出现的是，今年我国的进出口贸易额又达到了多少万亿，诸如此类的一些报道。在我看来，本质上这就是风向变了的最直观的感受。

以出口来拉动经济好不好？我觉得可以，而且随着中国制造能力的增强，也确实到了这么一个阶段，让出口成为经济增长的一个非常重要的动力。

但是我理想中的以出口来推动经济增长的动力，还必须得配合两个我觉得必备的条件：第1个是必须配合人民币的国际化，第2个是要设计一个完善的制度，要让消耗了大量中国的资源和劳动力所生产的商品在卖出去之后，有一个合理的回流的制度，来让整个国家的人享受到超额利润所带来的福利。

我在5年前的讲汇率的那篇文章《未来五年中国金融市场波动的最核心变量：人民币汇率》里面，其实就提到了一个我自己的非常核心的观点，那就是支撑起美元霸权的几根柱子里面，除了工业血液石油，以及美国自身的军事和科技实力之外，最重要的一根是什么？是以中国制造为支撑的工业品美元。

整个美元体系要能正常运作起来，其实最核心的东西不仅是拿着美元能去买到以石油为核心的工业原材料，更重要的是拿着美元能在世界范围内去采购中国所生产的巨量商品。

来自于中国的工业品，实际上是维系美元霸权的最后一根，也是最重要的一根支柱。在某种意义上可以说，中国制造出来的这些大量的商品，本质上是在给美元那些泛滥的流动性提供了最坚实的物质基础保证。

美国人拿着印刷成本接近零的绿纸就能跑到中国来买回一大堆耗费中国人无数时间生命和精力生产的商品，我觉得是整个世界贸易体系里面最不公平的一环。

对于像沙特那些国家来讲，他挖原油的成本是很低的，说白了靠老天吃饭，打一口井插一根管子进去，地里面就冒出来了，这东西本质上对他来讲是没有什么成本的。

但是对我们来讲不一样，我们制造出来的每一样东西，都是我们的人民辛辛苦苦付出血汗和泪水，在生产线和工位上忍受着各种煎熬、痛苦和不适，消耗了自己的健康去生产出来的。

拿印刷成本为零的纸片去换开采成本也接近于零的原材料我觉得倒谈不上不公平，但是拿纸片来换蕴含了无差别劳动时间的商品，我觉得是相当不公平的贸易。因此任何不脱离美元体系的增加出口行为，在本质上都是一种资敌。

我在写证监会处罚老虎和富途那篇文章里面其实就说了，这几年下来，全世界范围之内，有着充裕的流动性，有大量美元在手里的其实就是中国这些从事对外贸易和出口的人。中国人民的血汗，成了他们的离岸资产。

让出口成为经济增长的一极没问题，但就像我上面说的那样，出口是为了什么？卖出东西是为了什么？是为了让自己的老百姓有就业，让自己的人民能够享受到发展的成果。现在就业是有了，但超额的利润和财富并没有回来。

我们现在缺乏一个像我上面提到的那个机制那样，我们现在光鼓励出口，但是没有很好地规划出口完之后赚了钱应该怎么办。我们出口了那么多商品，换来了那么多的流动性，实际上并没有浇灌和回流到我们国内的经济体系里面。

那些所谓的巨额出口，本质上这成为了一个离岸美元的系统，大量出口所得的外汇，是游离甚至是独立于中国的经济体系之外的，出去了就不会回来。

当年为了说服中东的王爷，让他们拿出口的美元继续投美国，购买国债，基辛格还亲自飞到中东，软硬兼施，胡萝卜大棒一起，才逼迫像沙特那样的国家去参与美元的回流。

但是我们今天却似乎在美国没有任何胁迫的情况下就任由那些持有外汇的人几乎没有什么障碍地将自己所获得的这些外币重新又投入了美国的经济循环里面。

美国人借债购买中国商品，中国的外贸行业拿到了大量美元，美元又回流到美国参与美股、参与数字货币，这个过程，美国得到了商品，重获了流动性，中国的劳动者只得到了996的福报，真特么讽刺。而我为什么觉得是中国这边的流动性去参与到了美国股市的上涨，是因为作为一个在金融领域混了很多年的人，还是能够明显感受到中美两国之间的投资风格其实是不一样的。

我们当年进去金融市场之前接受的教育，本质上其实都是师从美国人的投资体系，所以对于美国人的投资风格，还是很熟悉的。

在美国基金经理里面，以我个人是比较欣赏的彼得·林奇为例，我们去细究当年那些老一辈的美国人他们在金融市场上投资的方法，你会发现他们还是比较喜欢去研究那种小而美，很有美国自身本土特色的公司去获取超额利润的。

因为对于一个美国人来讲，这是非常合乎常理的一种模式，他生活在美国，他能接触到这些公司的产品，他能够去实地调研这些公司，所以他能找到那些十倍股。

但如果对于一个中国人来讲，我们要去投这一类的公司，几乎不太可能，为什么呢？因为我们自己不在美国生活，我们接触不到这些品牌，也没有享受到他们的服务，他们的产品线和技术实力对我们来讲是非常陌生的，隔着太平洋，我们几乎不太可能了解得到他们真实的经营状况。

因此，哪怕给了我们一个美股的账户，大概率我可能也不会去买那些压根不知道底细的、闻所未闻的小公司，哪怕它可能上涨幅度很大，爆发力非常强，我也不太敢去碰。

那对那些去投美股的中国人来讲，能买的是什么股票？你只能买你自己耳熟能详的几个股票，苹果、英伟达、谷歌。说白了就是你在街上随便问一个中国人，他可能都能说得出名字的这几家公司。

这也高度贴合美股这些年的走势，就是这几家你随便在街上拉一个中国人，都能喊得出名字的这些公司，这几年贡献了美股绝大部分的涨幅。

为什么我觉得这些公司就是被中国人买起来的？因为绝大部分中国人就只知道这些公司，你让他去投一家犄角旮旯里面的公司，几乎不可能。这种高度集中持股背后，就是典型的中国人的购买行为。

我没有办法说去计算中国这边的流动性到底给美股的涨幅提供了多大的助力，因为这涉及到大量的买卖数据以及明面上的和暗地里的通过各种渠道流出中国流入美国的资金规模。

但这结论其实就像是一个破案的刑警的直觉一样。因为它非常符合逻辑，像我这样的接受过美国的投资理念的人是能非常明显地感觉到，美股市场上现在的这些涨幅，它并不是老一辈的美国投资人的购买行为所推动出来的走势，反而是更像我们中国人控制下的资金所制造出来的行为模式。这就是为什么中国的证监会对老虎和富途这些专注于服务中国人出海炒美股的券商进行处罚之后，美国的股票市场会不断下跌的原因。

我觉得很难用这种所谓加息的预期，或者是美国经济数据很好这种逻辑来解释美股的下跌。

现在非常诡异，也非常搞笑的是，每当美国这边出一个经济数据，数据越好，股市跌得越厉害，而当数据不好的时候，股市反而会上涨。

用常规的经济理论是无法解释的，因为正常来讲，一个国家的股票市场，它是这个国家的经济晴雨表，出现这种经济数据越好，股票跌得越厉害，只有两种可能性。要么是第一种，大家默认这个数字是假的，造假造得非常厉害，要么是第2种，就是这个国家的股票市场跟他自身的经济情况是已经完全脱节的，不仅不是正相关关系，反而是负相关关系。

那为什么会出现负相关关系呢？那就说明推动这个国家的股票市场的很大一部分流动性可能并不在本国人的手里。

用一个什么样的逻辑可以来解释美股这种数据越好，股票跌得越厉害呢？有个非常搞笑的我觉得可以解释的就是，美国的就业数据越好表明美国的经济状况越好。

美国经济状况越好对中国来讲就是不好，中国要是不好了，那掌握中国这边的流动性的人，他就没有那么多钱去投，反而需要卖出股票来填补国内的亏空，这样美国就会大跌，这个逻辑倒是非常的通顺，因为中美现在就是一个跷跷板，退一步来讲，如果美国的经济数据不好，表明美国的经济状况不好，那就意味着中国经济状况很好，那中国经济状况好，掌握了流动性的人，他就有更多的钱去投美股，那美股就会上涨。这么一解释很多东西就说得通了，而且逻辑非常的顺畅，虽然非常不严谨。

而如果说来自于中国这边的增量资金在很大程度上构成了美股那几家都能叫得出名字的大公司这些年的上涨，那么现在这一批离岸流动性就非常的危险。

我们把自身的角色如果切换到美国金融市场的统治阶级来好好想一想，我们就能明白为什么我说这些游离在中国境外的流动性那么危险了。

对于美国金融资本的统治阶级来讲，在2008年之后，有一个非常核心的任务，甚至可以说远在08年之前，美国的统治阶级就有相应的构想。

如果我是一个美国人，在中国当年加入WTO的时候，我肯定会有一套方案，允许你参与到这个体系里面，不可能是为了实现你的利益的最大化，而肯定是为了实现我的利益的最大化。

那作为一个美国人，要怎么样才能使得自己的利益最大化？如果我们切换一下身份，把自己换到美国人的角度，其实就能很容易得出一个结论，把中国拉进来并不是最终的目的。

拉进来只是一个开始，中间让你挣一点小钱，对于一个完整的计划来讲，肯定还有最后的一步，就是怎么样去收割掉中国在这个过程里面挣到的财富。这是美国统治阶级的行为模式，也是他们的思想惯性。

加入WTO好比是一个饵，而后面肯定是藏着更大的阴谋，他不可能是为了增强中国的经济实力，拓展中国工业的出口份额，最终让中国的经济繁荣强大起来。

对于美国统治阶级来讲，最终最终最终绕不过去的一环，也是最核心的一环，始终是要谋划如何收割掉中国发展的这几十年所积累下的巨额财富。

我们去研究美国人的时候，这是最最最一定要记住的一点。在很大程度 上，美国这十几年所搞出的大量金融创新，在我看来都是为了服务这个目的而存在的。不管是之前的数字货币，还是所谓的元宇宙的概念，包括现在所炒作的AI的这种概念，我觉得都是骗局。
