# 第7章 波浪型態的順勢操作戰法

+   收盤跌破5日均線，賣出。

+   帶量突破盤整區，買進。

+   收盤跌破5日均線，賣出。

+   出現「頭頭低」，波浪型態改變，退場操作。

# 空頭趨勢的操作策略

+   1. 順著空頭趨勢放空。

+   2. 當股價漲到高档，頭部形成「頭頭低」下跌格局時，放空。

+   3. 反轉第一次出現「底底低」型態，帶量跌破前低時，放空。

+   4. 跌破後，反彈遇壓力再下跌時，放空。

+   5. 下跌行进中，股價深跌後反彈，反彈到高点，無法突破前頭高点而再次下跌時，繼續放空，稱為「反彈後下跌再空」。

+   6. 行进中盤整向下，跌破盤整區時放空。

+   7. 當中持有放空股票時，收盤前股價在5日均價之下時，持股續抱；收盤前股價漲回5日均價之上時則回補。

+   8. 操作弱勢股，獲利可加碼繼續放空，往下操作。

+   9. 進場設定停損、獲利目標，以自己所訂的交易規則，依據技術面進出，直到空頭波形改變為止。

> **放空：** 指手上沒有股票，先向證券商借股票賣出，等日後在市場買回再還給證券商。也就是先賣後買。如果賣出價高、買回價低，會歸到差價；如果賣出價低、買回價高，則會賠錢。

> **回補：** 指放空時向券商借股票賣出之後，在市場買回股票歸還。
