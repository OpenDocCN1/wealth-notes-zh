# 功能2：計算次日的操盤價（進出場價）

從下圖可以看出，2011年7月22日當天的5日均價為119.4元，均線往下，次日均價＝（597元－120.5元＋次日收盤價）÷5，因此，次日收盤如果高於120.5元，均線就會改成往上彎，而且收盤價站上5日均線，這時如依據5日均線操作做多，則可以買進。
