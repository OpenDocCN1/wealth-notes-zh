# 步驟 3: 掌握買股的黃金時段

+   1. 開盤 09:00 ～ 09:30 買當日強勢上漲股票。

+   2. 尾盤 13:00 ～ 13:30 買次日會漲的股票。

# 步驟 4: 把握以下進場的黃金時機

+   1. 打底完成底部高後，回測不破低點的上涨。

+   2. 盤整完成的大量突破。

+   3. 均線糾結的放量上攻。

+   4. 強勢股回檔後的強勢續攻的起漲點。

+   5. 創新高後回測有撐的再上漲。

+   6. 末升段的噴出行情。

# 步驟 5: 把握以下成功的關鍵

+   1. 選股能力要強。

+   2. 要有百分之百的執行力。

+   3. 短線比長線重要（獲利效率）。

+   4. 強勢比漲勢重要（時間成本）。

+   5. 執行比選股重要（紀律執行）。
