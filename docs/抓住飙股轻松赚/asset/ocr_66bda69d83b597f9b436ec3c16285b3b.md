# 判斷盤整波

除了上升波、下跌波之外的橫向走勢均為盤整波。盤整波有以下4種可能：

+   1. 頭不過前頭高點，底不破前面低點，呈現三角收斂。

+   2. 頭過前頭高點，底跌破前面低點，呈現喇叭狀。

![](bbox=[0.21, 0.42, 0.56, 0.55])

![](bbox=[0.59, 0.42, 0.93, 0.55])

+   3. 頭與頭高點相近，底與底低點略約相近，呈現箱型盤整。

+   4. 波形混亂，頭底忽高忽低，呈現方向趨勢不明。
