# 切線的意義

所謂的「切線」就是趨勢線，股市每天交易在前進時，股價都會朝一個方向進行，這個方向我們稱為趨勢。當方向確定後，無論走的時間是長或短，要轉變成另一個方向，都需要經過轉換的過程。

我們可以用切線來表示趨勢的方向，切線不但告訴我們行进方向，更重要的是，切線能夠告訴我們方向即將改變的訊息，同時，切線也提供支撐與壓力的作用。
