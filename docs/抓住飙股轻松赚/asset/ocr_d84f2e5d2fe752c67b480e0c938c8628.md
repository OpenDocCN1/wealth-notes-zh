# 學會辨認型態 股市無往不利

股票走勢可分為上升、下跌與盤整等3大部分，除了上升與下跌，大部分的時間多處於盤整階段。型態就是當行情進入盤整區的走勢，所呈現出的不同特定圖形，每一種型態會給予一個名稱。

基本上，這些特定圖形是反應不同的主力大戶進出股市當時的心理反應及策略運用，因此，在不同的階段會產生不同的圖形型態。
