# 三、操作能力

+   **策略** ▶ 1. 多頭市場：
(1)順勢做多。
(2)回跌後上漲再買（低買高賣）。
(3)操作強勢主流股。
(4)追高買更高（起漲發動股）。

+   2. 空頭市場：
(1)順勢做空。
(2)反彈後下跌再空（高賣低買）。
(3)操作弱勢股（強力下跌股、本夢比破滅股、飆漲結束反轉股）。
(4)殺低補更低（高檔起跌股）。

+   3. 盤整市場：
(1)多頭市場低買高賣。
(2)空頭市場高賣低買。
