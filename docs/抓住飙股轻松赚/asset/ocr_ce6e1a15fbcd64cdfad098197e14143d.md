# **判斷股價高檔、低檔的MA通道**

所謂的「MA通道」是指，結合移動平均線與乖離的組合通道，利用MA通道來相互確認K線型態與價位區，可以判斷股價位置目前是處於高檔或低檔。

K線和移動平均線都是判斷行情的指標，如果兩者同時發出「買進」的訊號，彼此之間也「互相確認」，那麼可靠度就會很高。
