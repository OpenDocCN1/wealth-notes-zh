# ## 第 3 篇

#### 學會切線操作應用 挑出贏股與弱勢股

# ### 綜合判斷K線及切線的賣出位置

+   1. 股價漲高，拉出長黑K線，跌破上升切線時。
2. 空頭反彈到下降切線時，又出現黑K線向下時。
3. 空頭反彈突破下降切線，但很快又跌破下降切線時。
4. 多頭股價上漲，離上升切線過遠，因乖離過大而回檔時。

▲上圖說明：

+   *   切線出現賣點，K線出現買點，是最佳買點。
*   切線出現買點，K線出現賣點，仍宜站在買方。
*   切線出現賣點，K線出現買點，宜站在賣方。
*   切線出現賣點，K線出現賣點，是最佳賣點。
