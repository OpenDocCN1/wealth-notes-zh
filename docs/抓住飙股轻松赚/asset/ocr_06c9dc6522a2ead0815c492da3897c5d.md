# ■ 技術分析4大功能 扭轉散戶投資劣勢

# 功能1：綜合評估交易結果

技術分析能綜合評估市場中所有「理性」與「非理性」的交易結果，基本面的資本額、本益比、淨值、財務報表等都是客觀、具體的數字統計，不過，這些數據仍然不足以解釋，為什麼許多表現良好的公司，股價會一路下跌，為什麼業績不好的公司股價本益比高達數十倍？
