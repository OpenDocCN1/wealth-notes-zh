# 善用均線乖離判斷超買或超賣

所謂的均線乖離是指，實際股價與移動平均價之間的價差，此價差相對於均價的百分比較為乖離率。舉例說明如下：

+   1. 正乖離：當天收盤股價100元，當日的5日均線的均價為80元。
兩者價差=100-80=20  乖離率=20÷80=+25%

+   2. 負乖離：當天收盤股價80元，當日的5日均線的均價為100元。
兩者價差80-100=-20  乖離率=-20÷100=-20%

當正乖離過大，表示股價離均價過大，容易造成獲利了結的
