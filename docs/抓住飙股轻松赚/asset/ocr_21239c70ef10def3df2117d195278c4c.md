# 2. 回檔幅度與趨勢強弱關係

上升趨勢的回檔幅度愈小，上升趨勢愈強；回跌幅度愈大，上升趨勢愈弱。

# 3. 反彈幅度與趨勢強弱關係

下降趨勢的反彈幅度愈小，下跌趨勢愈強；反彈幅度愈大，下跌趨勢愈弱。
