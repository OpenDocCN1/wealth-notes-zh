# 1. 波浪的前頭

支撐：當股價在頭的上方，回跌到前面的頭會產生支撐。

壓力：當股價在頭的下方，上漲到前面的頭會產生壓力。

壓力：當股價在底的下方，上漲到前面的底會產生壓力。

# 3. 盤整帶

盤整帶盤整的時間愈長，累積的成交量愈大，對日後的支撐或壓力的力道也愈大。

支撐：當股價在盤整帶的上方，回跌到盤整帶會產生支撐。

壓力：當股價在盤整帶的下方，上漲到盤整帶會產生壓力。
