股票投機的真諦，就是讓錢流向最會漲的股票。在股市中，越會漲的股票越能吸引大眾的追逐，形成「強者恆強」局面。投資則是傾向買進好公司的股票，投機是傾向買進即將上漲，或是還會再漲的好股票。

# 改變錯誤的股票操作習性

散戶操作賠錢，大多都有下列錯誤的操作習性，如果不能改變這些習性，縱使有再多的錢，學完技術分析，都不能改變賠錢的命運。一起來看看你擁有哪些正確的操作習性，請繼續保持下去！

+   - 不辨多空，市場亂衝。
- 往下攤平，愈攤愈平。
- 東買西買，每個都要。
- 不做停損，終將大賠。

# 錯誤的操作習性 Check List

+   - 追高殺低，賠錢第一。
- 套牢長抱，只等解套。
- 探聽消息，不學操作。
- 看盤操作，不知所措。

# 正確的操作習性 Check List

+   - 不猜高低，圖形為憑。
- 耐心等待，紀律守好。
- 不論長短，賺錢就好。
- 選到飆股，狠狠賺飽。

+   - 自己研判，不受干擾。
- 設定停損，跌破就跑。
- 集中火力，專心顧牢。
