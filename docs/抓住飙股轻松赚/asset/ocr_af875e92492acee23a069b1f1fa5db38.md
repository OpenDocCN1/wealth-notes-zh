# 8. 大量成交K線

支撐：股價站上大量K線最高點上方，日後此K線會產生支撐。

壓力：股價跌破大量K線最低點下方，日後此K線會產生壓力。

# 【支撐、壓力的應用】

為什麼你要熟記這些支撐及壓力？因為可做為以下投資決策的參考：

+   1. 決定進出位置。

+   2. 研判停損、停利的依據。

+   3. 預測走勢續多或續空。

+   4. 股市中常聽到「多頭時見壓不是壓，見撐多有撐」，多頭以支撐為觀察重點，看支撐是否跌破而轉折。

+   5. 股市中常聽到「空頭時見撐不是撐，見壓多有壓」，空頭以壓力為觀察重點，看壓力是否突破而轉折。
