# 彈性改變停損策略的 3 點原則

設定停損點一定要遵守的基本原則是，買進股票時，應先設定好停損價，當股價達到停損時，應果斷執行。不過，計畫有時趕不上變化，因此，以下提供 3 個可以改變停損策略的原則，做為參考依據。

+   當波浪型態改變，雖然尚未達到停損，可依當時整體狀況提早出場。

+   當進場獲利達 7% 以上，離停損點漸遠，此時應放棄原有的停損，改為設定停利的位置點。

+   逆勢交易時，無所謂固定停損點，做多時當 K 線翻黑，或做空時當 K 線翻紅，都要立刻停損。
