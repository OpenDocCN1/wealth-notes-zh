# ▎位 ▶ 位置 → 關係到進場風險、獲利空間

第三步看當下股價所處的位置，是位於剛剛起漲的底部區（山谷），還是上漲中的腰部區（山腰），還是已經漲了一大段的高檔區（山頂），這關係到你進場的風險，更關係到你可能的獲利空間。
