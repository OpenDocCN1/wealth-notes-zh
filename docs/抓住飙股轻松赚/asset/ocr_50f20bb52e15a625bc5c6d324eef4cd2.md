# ## 七、下降楔形

![](bbox=[0.13, 0.24, 0.73, 0.47])

註：為突破點，為低點，為高點。

+   1. 下降楔形屬於獲利潛能很高的排列，但此排列較少見。

+   2. 短期看多的反轉型態，發生機率90%。

+   3. 經常發生在空頭末跌段，然後反轉向上。

+   4. 收盤價突破經常都會成功。

+   5. 拉回測試頸線的機率近50%

+   6. 盤整區內成交量呈下降趨勢，大小量突破皆可。

+   7. 大量突破較易拉回。

+   8. 有30%的狀況會向下假跌破後又回盤整區內，再向上突破。

+   9. 型態盤整中，可採單向順勢操作；接近收斂點前，等待向上突破之後才買進。

+   10. 可在回測走勢完成而價格又開始上漲的時候買進或加碼。

+   11. 時程要大於20天，否則屬於旗形。
