# # 218【问答】无冥冥之者者，无昭昭之明

# 一、給

![](bbox=[0.05, 0.05, 0.95, 0.21])

思考题：

《千字文》中“户封八县 家给千兵”的“给”怎么解？

答案：

这里的“给”（jǐ市声）是充足的意思。他们每家有八县之广的封地，配备上千的士兵。

# 一、勤

![](bbox=[0.05, 0.31, 0.95, 0.47])

思考题：

有一个小故事，说曾国藩小时候读书很费力，有一天晚上他在灯下读书，一篇文章反反复复也就背不下来。此刻有一个贼正潜伏在房梁上，想着曾国藩读完全书去睡觉以后从房梁上跳下来，可是左右看看，曾国藩还在那篇作文，而他的贼早就听腻了。

最后这个贼忍无可忍，从梁上跳下来，把那篇文章从头到尾背了一遍，然后鄙夷地说：“就你这样的读什么书，扬长而去。”

如果用勤能补拙来形容曾国藩，那么有什么成语能够形容那个贼呢？

答案：

在荀子的《劝学》中，有这样一句：是故无冥冥之者者，无昭昭之明；无惛惛之著事，无赫赫之功。

# 一、和

![](bbox=[0.05, 0.61, 0.95, 0.77])

思考题：

“和谐”在现代汉语中是一个词，但字义各自还是有微妙差别的，请你分析一下，找出两个字的异同。

答案：

“和”表示不同声音，不同观点相互配合，同一节拍相合拍。相称，强调有差异而致同；
“谐”的本意是异口同声，表示相同的观点声音，相同的观点统一表达，有点像阅兵式喊正步。

# 一、忙

![](bbox=[0.05, 0.87, 0.95, 0.00103])

思考题：

杜甫在《新婚别》中有这样的诗句：

结发为君妻，席不暖君床。

暮婚晨告别，无乃太匆忙。

君行虽不远，守边臣有阳。

妾身未分明，何以拜姑嫜？

请结合上下文解读文中的“忙”字。

答案：

这个“忙”是急迫的意思。

古礼女子许嫁，要用五彩丝线系头发，新娘之由郎前解开，这叫“结发”。

洞房花烛之夜，夜子都没顾暖，头一天晚上刚结婚，第二天一早就得走。

“无乃”，是反问对方的口气，意即“难道不是”。

“匆”的本意是心情像被火的烟困，“忙”则是急迫的含义。

为什么有此疑问？原因是古代婚礼，新娘过了三天后，要先备家庙、上坟坟，然后拜见公婆，正名定分，才算成婚。现在一晚上就走了，理论上讲夫妻名分都还没有定。那不就是急迫了吗？

# 一、海

![](bbox=[0.05, 0.0011799999999999998, 0.95, 0.00134])

思考题：

请你分析一下古文中“海北”和“海里”。

答案：

你已经知道东汉的北海指贝加尔湖，所以海北泛指遥远的北方；“夷”是古代对少数民族的统称，“海”在这里表示偏远，海里指边境少数民族或者来自海外的外国人，相当于今天的“老外”。
