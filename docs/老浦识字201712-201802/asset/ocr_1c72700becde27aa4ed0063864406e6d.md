230【问答】“五福”中的最后一福：考终命

# 《政》

![](bbox=[0.1, 0.38, 0.9, 0.55])

+   - 思考题：

  你会怎样理解古人“五福”中的最后一福：考终命，也就是善终。

  希望你把自己的见解写在评论中。

- 参考答案：

  善终是自然死亡，没有痛苦地走完生命旅程，个人感受有三：

  1. 表达了古人对生命的认识，生老病死是人生必然，能好好走完一生就是福；
  2. 健康平和，身体自然衰老，这是无疾而终，一般人很难做到；
  3. 不做亏心事，不怕鬼敲门。一生坦坦荡荡，没有愧疚悔恨，这种善终确实是人生之福。

# 《恐》

![](bbox=[0.1, 0.99, 0.9, 0.00109])

思考题：

恐和惧同义，简体的惧化字已经看不出什么意义了，现在我告诉你，惧的金文是这样的 ，是这样的 ，篆文是这样的 ，楷书是这样的 。

你能分析一下这个字的造字原理吗？提示一下， 的本意是小鸟。

答案：

人在惊恐的时候会睁大双眼，所以“惧”最早就是瞪大 的双眼，后增加“心”，表示这是一种心理。篆文增加小鸟，表示眼睛像小鸟的眼睛，同时也利用小鸟受惊小惊飞的特点，强化惊恐的心理表达。

# 《建》

![](bbox=[0.1, 0.00131, 0.9, 0.0014])

思考题：

封建的“封”甲骨文 是一只手在隆起的土堆上种树，古代用种树来划定疆界。请你分析“封建”的原意。

答案：

封建是政治制度，即封邦建国，古代帝王把爵位、土地分赐亲戚或功臣，使之在各自区域内建立邦国，即封建亲戚，以藩屏周。

相传唐有为封建之始，至周制度始备。春秋战国时的诸侯国就是封建。欧洲中世纪也曾实行类似的制度。

秦统一中国，废封建立郡县。集权于中央。

现在常用来比喻思想保守，不开放。
