# ### 识字卡片

![](bbox=[0.1, 0.15, 0.9, 0.28])

我们现在已经进入农历十二月，也就是腊月了。为什么叫腊月？汉朝应劭《风俗通义》载：“腊者，猎也，言田猎取禽兽，以祭祀祖先”；或日，言田猎取禽兽，以祭祀祖先，新故交接，故大祭以报功也。

又载：“腊月十二月也，以是月腊祭百神，故谓之腊月。”意思是：阴历十二月，在这农历的岁末，打猎获取禽兽，以祭祀祖宗和神灵，辞旧迎新，所以称为“腊月”。

一进入腊月，感觉就要过年了。在外漂泊的你有没有心头浮动了吧？也许已经开始订火车票了吧。这让我想到了一个汉字“羁”，天涯羁旅的羁。

+   - 羁是马笼头

篆文“羁”是一个会意字。上面是网（罒），网里面是革，表示皮革和马。

合起来表示用皮革制成的网来络住马络住。本义是马笼头。

![](bbox=[0.2, 0.52, 0.8, 0.57])

由于是马笼头，自然引申为束缚、拴住。

魏晋时期有一个名人叫鲍康，他有一个相当高士上的朋友名远，经常聚在山间竹林中弹琴吟诗，人称竹林七贤。

七贤之一山涛出山做了官，后来升官，推荐鲍康接替他的官位。对于朋友的推荐，鲍康不仅不领情，还写信把山涛骂了一顿，这就是《与山巨源绝交书》。

其中有这么一句：“此犹鹰虎，少经驯育，则尠教叫群狼；长而见羁，则爪牙。即致山越后，企固挣脱羁绊它的绳索，即使赴汤蹈火也在所不顾；虽然给它带上金色的笼头，喂它最精美的饲料，但它还是强烈忍受着生活惯了的茂密树林和丰美的百草。

意思是说：我鲍康从小由松散惯坏了，这像鹰虎一样，如果从小就捉起来加以驯养，那么就会服从主人的管数约束；如长以后要加以管，那就一定会疯狂地乱蹦乱跳，企图挣脱羁绊它的绳索，即使赴汤蹈火也在所不顾；虽然给它带上金的笼头，喂它最精美的饲料，但它还是强烈忍受着生活惯了的茂密树林和丰美的百草。

这就是狂放不羁，名士风流。

+   - 羁是女孩子的发型

古代女孩三四岁～八岁，要把头发剃掉，只留头顶上的头发扎成小发髻，形如小犄角，叫男角女羁。

![](bbox=[0.15, 0.88, 0.85, 0.94])

+   - 羁是乡愁

由于“羁”束缚的含义，还由于这个字的本意涉及马，于是就有了离开故乡、滞留他乡的含义。

如旅居外地任官叫羁宦；寄居异地的愁苦烦恼叫羁恨；寄居异乡而又身世寒微叫羁屑；羁留他乡漂泊无定叫羁泊；表现这种心情的叫羁旅诗。

这里有一首典型的羁旅诗：

```
```text
春夜洛城闻笛一李白
谁家玉笛暗飞声，散入春风满洛城。
此夜曲中闻折柳，何人不起故园情！

# ### 总结

+   - 划重点

+   1. 羁的本意是马笼头，引申为束缚、拴住。鲍康的狂放不羁就是不愿意受到束缚；

+   2. “羁”是小女孩的一种发型，男角女羁；

+   3. 羁旅诗是诗歌中一个重要的类型，有很多著名的诗篇，建议你读一读。
