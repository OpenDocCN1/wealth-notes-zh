福字倒贴的来源有几种传说。

# 第一种传说：

明太祖朱元璋攻占南京后，命心腹偷偷去各民家，在门口贴上“福”字，以便第二天门上没有“福”字的人家统统被消灭。好心的马皇后为消除这场灾祸，让全城大小人家必须连夜在自家门上贴一个“福”字。

于是，各家各户都赶紧照办。其中有一户姓朱人家不识字，把“福”字给贴倒了。第二天，御林军前来巡查，全城家家都贴“福”字。只有一家把“福”字贴倒了，马皇后下令朱门一个不留全部杀掉。马皇后一看事情不妙，忙对朱元璋说：那家人知道是今日来查访，故意把“福”字贴倒了，这是言“福到”的意思吧？朱元璋听完后立刻转怒为喜，便消掉了杀人的念头，一场大祸得以避免。

# 第二种传说：

清代慈禧年逾月二十四，慈禧太后传旨，叫给翰林院翰林写当庆典恭贺的对策。并令写几个“福”字。太后从中挑了几张，让太监普皇帝带太监去宫里各处张贴。总宫里有个太监不识，把一个“福”字贴倒了，太后出来张望看到，她刚发完脾气就命太监把那太监杀了，太监快跑。太后大发雷霆：“老佛爷您别生气了，总不可能是奴才创意的。”慈禧一听，说，你福倒，就是福倒了，倒福了，不是大吉利吗？慈禧听后虽然还发了一会儿脾气，但没杀那个太监，还赏了他几两银子。

# 第三种传说：

满城非午间的某个春节前夕，蔡府王家专为讨主子欢心，写了几个头大的“福”字，叫人在库府和王府的大门上贴“福”字。有一家人听错了，蔡将大门上的“福”字贴倒了。为此，蔡家的满腹十分气愤，大骂管家（管家听得明白）“福”是倒了的，管家转达给主子，主子一听，转悲为喜，赏管家和这家人50两银子。

也有说法称，“福到了”需要张贴在特别的位置。大门贴正福，寓意开门“迎福”和“纳福”，可有进福之意。如大门的“福”倒着贴可被视为福到门外了。所以门福必须是正福。

倒着贴的福主要应该在这三种地方：第一种地方是在水缸和垃圾篓子上，由于水缸和垃圾箱里的东西是从里面倒出来的。为了表示这些地方的福气倒掉，便倒贴福字。第二种地方是在屋内的柜子中。柜子是存放物品的地方。倒着贴“福”字，寓意福气一直来到家里，屋和柜子。第三种就是倒着贴在牛棚、猪圈的门上才会倒着贴“福”字，寓意福到。

以上是网罗网上的资料，你发现了吗？所有的说法都有一个关键点，那就是张贴福的人和识字，把福字贴倒，别人会把错误的认知转嫁给说。如大门的“福”倒着贴可被视为福到门外了。所以门福必须是正福。
