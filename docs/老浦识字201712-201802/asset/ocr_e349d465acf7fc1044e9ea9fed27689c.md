# 《族》

![](bbox=[0.1, 0.23, 0.9, 0.47])

思考题：

甲骨文里有一个字形和“族”很相像，是旗帜下面一个“矢”，你来猜猜这是什么字。

答案：

这是“旅”，表示在同一面旗帜下共同战斗。古代同一氏族不但有血缘关系，而且共同游牧。

# 《张》

![](bbox=[0.1, 0.68, 0.9, 0.9])

思考题：

这个甲骨文是弓弦上有一个石块，请你猜猜看，这是什么字？

答案：

弹，本意是射击石子或金属弹丸，引申为弹射。
