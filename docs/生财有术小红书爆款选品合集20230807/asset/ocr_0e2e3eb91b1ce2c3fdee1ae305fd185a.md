# ## 2. 从第一个粉丝开始变现

很多朋友在做个人号的时候，往往会陷入一个误区，就是先涨粉，想着等粉丝多一点再引流变现。

往往的结果是涨了很多粉，每篇笔记的赞藏都很漂亮，但没人私信，评论可能也很少，更别说引流私域变现了。

我们以变现为目的的做账号，就应该从第一个粉丝就开始变现。

小红书的粉丝不值钱，私域粉丝才值钱。

从开始注册账号，发布第一篇笔记，你就要想好怎么吸引目标用户，怎么把目标用户引导到私域，到了私域才有变现的可能。
