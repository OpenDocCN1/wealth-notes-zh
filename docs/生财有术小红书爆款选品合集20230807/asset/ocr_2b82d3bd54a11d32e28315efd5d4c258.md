# 风靡小红书的 Tufting 到底是啥？

我原本是做油画体验的，去年 3 月在上海田子坊开了自己的「梦中情店」，主要在线下成交。一开始我靠着企业 B 端客户的团建合作以及商圈流量勉强维持经营。

后来疫情限流，再加上油画体验已是红海，同行恶意低价竞争愈发激烈，门店生意愈发惨淡、入不敷出，逼得我差点把店给关了。
