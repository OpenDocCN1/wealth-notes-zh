# 前言 成為不用為錢煩惱的人，一起變有錢！

本書重點在於提供各位「不必再為錢所困的方法」。一提到錢，總會給人航髀、貪婪、沒格調……的刻板印象；不過，人還是對錢趨之若鶩。但即使如此，我們仍然裝作一點也不愛錢的樣子。話說回來，我相信世界上應該沒人不想要錢吧！就像在我每個 household 都舉辦的心靈成長讀書會——心屋塾 Be 訓練課程中，人氣最高的聚會總是和錢脫離不了關係。 其實人人都愛錢，而且還希望愈多愈好。我在做心理諮商時，有「金錢方面的問題、煩惱」的人也不在少數；我聽到許多心聲都是：「如果有錢就好了」。我也曾為錢痛苦過，所以非常能體曾錢到底多重要。不過託各位的福，我現在已不再需要為錢煩惱了。

# 前言 成為不用為錢煩惱的人，一起變有錢！
