# 重・點・整・理

+   - 有錢的意思，就是擁有「選擇的自由」。也就是不需忍耐、想怎樣就怎樣、從實踐想做的事中得到喜悅和安全感。\n- 就算現在沒錢，只要認為「自己有錢」、「還會繼續有錢」，錢就會源源不絕地跑來找你。\n- 收入與自己認同的自我價值成正比。\n- 無論是金錢、富裕、愛情、還是魅力，都是每個人天生就「擁有」的，而且不會「失去」。認同這件事是非常重要的。\n- 覺得自我價值很低的人，是不會收下金錢的。認同自己的價值，則會理所當然地收下金錢。\n- 金錢並不是勞動的報酬；也不是努力得來的戰利品、或提供任何東西或服務得到的回報。\n- 沒有任何貢獻、只會造成別人負擔，能顯示這個自我價值的量表就是「存在薪」。\n- 像有錢人一樣高的「存在薪」。認為自己理所當然要過豐衣足食的日子。
