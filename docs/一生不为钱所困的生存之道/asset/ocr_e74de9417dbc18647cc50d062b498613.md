# 金錢和勞動並不會「成正比」

只要認為錢財和勞動、討人歡心、或是是否有貢獻的程度成正比的人，都會不斷付出精神、努力，努力去求取更多金錢。換句話說，這正是「勞動報酬||血汗薪」的想法。只要認為金錢||勞動報酬||血汗薪，就會無所不用其極地去追求金錢，甚至可能追到累垮身體和心靈，因為這些人根深柢固的觀念是：不應該做，就賺不到錢。其實，金錢和勞動的程度並不成正比，也不與自己被賦予的價值成比例；所以，要把潛意識裡的思想法轉念成：就算自己無所事事、無法對人有貢獻，也不需要拿住何東西交換；這樣的自己，原本就受到所有人肯定和認同。只要能轉變成此觀念，就能改變原先對錢的「預設立場」；援著，金流模式就會開始產生變化。
