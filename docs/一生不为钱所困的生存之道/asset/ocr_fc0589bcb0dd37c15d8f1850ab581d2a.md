# 富足會從意想不到的地方而來

![](bbox=[0.78, 0.12, 0.85, 0.17])

「我了解心屋先生的意思了。但就算意識到我『擁有』錢，難道金銀財寶真的就會從天而降嗎？我這個月非繳不可的房租、水電費之類的錢，會從哪裡跑出來呢？難道這些錢會憑空出現嗎？」

是的，這些你所需要的錢都會無中生有。

或許你認為，這是『無稽之談』，但其實你的『前提』本身就有問題。

「你說，你意識到『你擁有錢』。」，但其實你沒真正明白，以至於「不知道錢從哪來」。如果你還停留在這種思維，就等於還沒跳脫一般人 的『常識』。畢竟，人類很難意識到自己沒經歷過的事情。
