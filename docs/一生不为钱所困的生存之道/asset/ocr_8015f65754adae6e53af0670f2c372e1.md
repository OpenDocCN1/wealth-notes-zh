# 重 · 點 · 整 · 理

+   - 金錢和空氣一樣，能意識到「自己擁有」是非常重要的。呼吸時，完全不需要擔心「現在吸進太多空氣，將來就沒得呼吸了」，而且，空氣還會非常充足且平等地供給眾人。\n- 「不知道到底發生了什麼事」媽媽竟然給我一筆錢；「不知道到底發生了什麼事」有錢人家的千金突然非我不嫁；「不知道到底發生了什麼事」得到一筆意外的獎金……。\n相信「不知道到底發生了什麼事」的力量，就會有意想不到的驚喜從天而降。\n- 收下富足的人，不能讓財富停在自己手中，要能「分享、花費」是非常重要的。\n- 只要錢能「先用掉、被使用」，就會自己再回來。\n- 光是一直不斷地節省，就會讓自己的錢失去流動的力量；結果，會讓錢也無法回流。\n- 使用金錢是好事。之所以會這麼說，是因為自己花掉的錢，一定能成為別人的薪水、生活費、小孩的學費或享樂費用；所以使用金錢，能對他人有所貢獻。
