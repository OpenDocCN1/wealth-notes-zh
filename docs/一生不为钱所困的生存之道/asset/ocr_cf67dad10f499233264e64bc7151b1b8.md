# 試著說出「媽媽，妳很幸福」這句話

試著說說看「媽媽，妳很幸福」這句話。
一定很多人看到這裡，心中就浮現問號，不知道這句話跟變成有錢人有什麼關係；其實這句話跟變成有錢人可是大有關聯呢！
對金錢抱持悲觀、負面想法或態度的人，都是被成長背景、教育、所見所聞、或經驗塑造出來的。
然而，絕大部分都與自己的父母有關。如果說，你對金錢的「擁有方式」幾乎都是受父母親影響才變成這樣，那這麼做可…點也不為過！
像是沒有辛苦付出怎麼會有收穫、一分耕耘一分收穫、天下面沒有白吃的食物、吃的餐、不應該賺輕鬆錢，父母的金錢觀，是滲透到你內心深處的金科玉律，也是你根深柢固的「預設立場」。。
