# 我們其實「很有錢」，卻從來沒人告訴我們

怎麼能與金錢相提並論呢？金錢是眼睛看得到的东西，但金錢所帶來的富裕，卻沒有具體的樣貌，是用肉眼看不到的。這讓我們只專注在眼前的看得見的金錢，卻沒意識到，自己早已過著「富足」的生活，因此，才會導致我們心中不斷煩惱「怎麼只有這一點點錢」「已經沒錢了」「這點根本不夠用」「糟糕，沒錢了」等事。有些人就算擁有上億身家，依然沒意識到自己「擁有」富裕生活（||）。不收下富裕生活的人，他們仍會認為「錢不夠用」、「再不多賺一點就糟了」「用完了怎麼辦」而非常害怕。會感到「沒錢」的人不是真的沒錢，而是對金錢所帶來的富裕「視...」
