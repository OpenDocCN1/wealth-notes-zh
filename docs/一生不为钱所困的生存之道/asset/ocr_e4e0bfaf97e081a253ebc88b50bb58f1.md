# 重・點・整・理

+   - 錢之所以不來，只是因為你不拿而已。
- 貧窮的人有變貧窮的壞習慣（＝預設立場）；有錢人也有讓自己變有錢的壞習慣（＝預設立場）。
- 「不刻苦耐勞辛苦賺錢，就賺不到錢」、「不存錢的話，總有一天會坐吃山空」……小時候父母或周遭的人教我們的事，直到現在，還深深地影響我們的金錢觀。
- 為了不讓父母討厭、得到他們的愛，或是怕被他們嫌棄，對需要用錢的事，只能咬緊牙關一再忍耐，導致心門深鎖，拒錢於千里之外。
- 想到錢的事，就不自覺地有悲觀或無奈的感覺，原因就在於過去曾經發生的悲慘經驗。請原諒當初那個還沒得到寬恕的自己吧！
- 愈努力愈無法「錢」進。放棄努力，會有「超乎常理之外」的富貴來臨。
