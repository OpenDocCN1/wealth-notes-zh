# 是要700万日元还是要孩子？

再来看表4-10：年收入在500万—700万日元的23名男性中，夫妇双方共同劳动的合计不超过13%，而妻子为专职家庭主妇或外出从事计时零工的占到了60.9%。与此相对，年收入超过700万日元的13名男性中，夫妇双方共同劳动的共有8人，占61.5%，而这些家庭全部是没有孩子的两人家庭（“丁克族”）；妻子为专职家庭主妇或外出做些零工的有孩子的家庭有4人，占到了30.8%。
