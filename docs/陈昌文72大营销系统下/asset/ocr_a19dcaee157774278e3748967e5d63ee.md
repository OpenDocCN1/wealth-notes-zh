# 潜营销演讲模板

+   1、 每天列出 10 个话题作为案例；

+   2、 每个案例控制在 15 分钟内。每天直播时长 2 个半小时；

+   3、 讲完一个案例顺势打出一个广告；

+   4、 每天利用一个案例，讲解一个营销系统。

# 演讲大纲框架

+   1、 30%的思维（强者思维、彰显个性活出自我）；

+   2、 30%的干货（用故事、情感话题来展示更容易被接受）；

+   3、 30%的儒家思想（尊重自然规律与常识，打破粉丝的幻想，真实、真诚、感恩、虔诚）；

+   4、 10%的互动，回答粉丝问题时，用一个故事让粉丝自我对照，比直接给答案效果好百倍。
