# 自助者天助

自助者天助，是《易经》里的话。

我们首先要自己自力更生，自己努力，然后，我们才可以获得别人的
帮助，才有资格获得别人的帮助。做人首先要自强。

无钱方断酒，临老始看经。

人生的悲哀就是这样，没钱了，才知道喝酒不好，其实也不知道喝酒
不好，只是没钱了，困穷了，买不起了。

实啊，人一开始，就应该看经书，特别是年轻的时候，有老祖宗的理论指
导，走的弯路少些，成功的可能性大些。

但大多数人只是按照自己的个性活着，所以弯路走得多，而国学思
维，是希望大家一开始，就不要走错，年轻的时候，多读经书，少喝酒。
