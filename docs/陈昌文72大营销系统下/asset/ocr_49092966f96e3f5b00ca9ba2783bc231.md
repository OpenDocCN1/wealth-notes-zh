# ## 从一而终，品牌才有力量

做项目，最重要的就是从一而终，滴水穿石，绳锯木断。做项目，最重要的是要一辈子只搞一个项目，当您找到这样的项目过后，您就要重复工作，而不是放弃，而不是换新的。大多数人都非常有冲动换项目。因为他们总是觉得自己赚不到钱，是项目问题，是外因，而不知道，其实自己要是明白了经商的道理，任何项目都能做起来，要是不明白经商的道理，再换项目，也没有意义。
