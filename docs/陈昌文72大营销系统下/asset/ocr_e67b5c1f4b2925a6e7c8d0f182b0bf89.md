# 提升道德素质，是裂变的本 根

我们社群的核心根基，就是讲师。

我们对讲师的要求，就是道德素质高，事业有成，在以前的线下有自己的团队、组织，有过成功经验，或者现在是一个成功的老板、企业家。

讲师分为内部讲师、外部讲师。讲师的任务，就是裂变出来更多优秀的、有事业的讲师。我们为什么只要优秀的、有道德素质，有事业的讲师？ 因为这些人素质高，知道我们社群儒家思想的价值，陈昌文方法的价 值，社群营销的价值。我们的目标是把儒家思想、陈昌文方法普及给十亿人。有事业、素质高的人，知道我们为社会做出的贡献，这些老板理解我们。而没什么事业、钱财的人，他们理解不了我们。

讲师的任务是真正的帮助铁粉、学员。不要嘲讽，谩骂，侮辱学员，要让他们好高跟着学习，成长，赚钱，真正教会他们如何做抖音，做直播，做朋友圈，做广告，收单子。这样，我们的铁粉、学员就会越来越多。

一定要不断地让我们的铁粉、学员，无论是付费的，还是未付费的，都参与到宣传儒家思想、陈昌文方法中来。只要他们参与进来，获得了收益，迟早都会跟着我们干。
