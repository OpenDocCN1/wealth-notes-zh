# 如何做自我介绍营销系统

如何做自我介绍营销系统?

+   - 1、您是哪里人？
- 2、您是做什么的？
- 3、您有什么牛 B 的故事？
- 4、您创过什么业？
- 5、您有什么值得骄傲的成绩？
- 6、您有什么本事可以帮助大家？
- 7、大家为什么要付费给您？您的价值？
- 8、您的性格？
- 9、您的年收入？
- 10、上图片，上视频，上微博，上一切介绍。

自我介绍营销系统,必须完全真实,一句假话也不可以说。不要编造。假话多了,是犯法的。更不可以虚构成事实。

您的自我介绍,这个东西是公开的,可以更新到朋友圈,进一步吸引志同道合的人。自我介绍营销系统做好了,成交都是自动的。

自我介绍营销系统,是您飞黄腾达要修炼的一招。
