# 讲故事，是为了提高人格魅力

讲故事的核心特征是什么？是虽千万人，吾往矣。也就是有一种使命感的，而自己就是这种使命感的主人翁，这种故事最能感动人。讲故事 的目的是传达价值观，而不是为了赚钱。然后顺便收单就行了。

讲故事，一定是讲道，而不是讲赚钱如命的故事。赚钱如命的故事， 不能感动人，讲守死普道的故事才能感动人。

真正讲故事的高手是这样的，讲完后，粉丝觉得自己的人格也是伟 光正的，粉丝觉得自己是正义的。粉丝有了赞同感，您就无所不能了。有 趣的故事，是这样的，傻傻而有力量。偏强、吃亏，但有力量。弱小但聪 明智慧。有一个反差感，有一个制度的点，这让很多人觉得，这个人就是 他自己，他虽然有很多缺陷，但是有一个优点，可以靠着这个优点制胜。 讲故事，您虽然是一个孤独的英雄，但您要 把您的灵魂复制给您的听众。 让您的听众觉得，他们也可以，您这个故事就活了。

讲故事，虽然是天上下天下，唯一独尊的模式去讲这个人的英雄故事， 但是您也要关心您的听众，说些好听的话给听众，证明您感恩、低调、谨 虚，会做人，有礼仪。

人们吃这一套。人们希望看到一个孤独英雄保护他们，而不是高高在 上，而是俯视一切。女人的内心，都希望一个力大无穷的王字对自己温 柔。故事的模式，也是这样，故事是用来塑造自已伟大的人格魅力的，聪 明智慧，又温柔多情，对待各位小宝宝那是一个好啊。
