# 头脑开放，换脑才能换人生

人的失败，是因为头脑固化。以失败的思维模式在生存。以贫穷的思维模式在生存。如果您的头脑思维模式是富人的思维模式，营销人的思维模式，您的收入自然不会低。

人的失败，就是因为不愿意改变自己头脑里的想法。所以，高明的人，首先是开放自己的头脑，愿意接受比自己厉害的人的思维模式。而低能的人，总觉得别人洗脑他，混的一塌糊涂，却非常害怕被别人洗脑，什么都不听，不愿意接受，结果就只能保持现状，但是又特别羡慕富人，又想变成富人。这犹如明明想取暖，却跳进冰箱里，不想出来，主要是怕被火烧着，但是呢，又想取暖。很多人不明白，换脑就能换人生。

贫穷，是因为从小都是接收贫穷环境的意识，思维上有盲点。贫穷的人不愿意接受别人的帮助，总是觉得别人在坑他者。总是觉得别人要骗他。说白了，他一无所有，但是他就是怕别人骗他，其实，很多人根本就不值得骗。因为您本来就一无所有，您出去混，接受先进的观念，就是赚。

高手是相互帮助，相互支持，相互鼓励，不断地前进。低手，是相互拆台，相互诋毁，相互谩骂，原地踏步。高手一听到正确的建议，立刻改变自己的行为，改变是在一瞬间完成的。

只有头脑极度开放的人，完全放下自我意识的人，才会听从高手的建议。
