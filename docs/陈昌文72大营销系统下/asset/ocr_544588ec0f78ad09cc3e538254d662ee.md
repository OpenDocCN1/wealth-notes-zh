# 讲师裂变

利益驱动，是所有驱动中最核心的思维。只谈理想，是没有用的。必须谈利益，必须让利。讲师裂变的主要核心就是以利益驱动，您想要把生意做大，就要让利润出去，让您看您合作的人有钱赚。没有这个思想，您的生意是做不大的。想要把生意做大，您必须有很多合作者。没有合作者，做什么生意呢？裂变的核心，是招聘合作者、代理。但是注意，要咨询律师，不要陷入法律风险。裂变的核心，是您的产品、服务质量过硬。当然，您有没有种子客户相对非常重要。

# 产品

营销当中，很重要的一环，就是产品好。

有个老板说产品为王，我深以为然，产品好，系列化，精准定位，为王。

现代社会，很多人只喜欢吹牛，说什么赚钱了，有豪车，有豪宅，不断地秀，然后呢，找代理，压货。这个品牌、这个产品，做死了，做下一个品牌、下一个产品，下一个模式，继续吹牛，继续割韭菜。他们就是这样起盘，跌倒，割韭菜，继续赚钱的。
