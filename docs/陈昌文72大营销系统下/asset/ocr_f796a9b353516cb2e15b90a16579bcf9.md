# 真正的营销是引导式营销

真正的营销高手，是引导式营销，每句话、每个故事、每个案例、每个理论，最终都是为了卖主语。能领悟执行潜营销系统的人，也就算摸到营销的门槛了。

比如，我们社群叫做陈吕文老板社群，如果您是卖陈吕文老板社群，则您每个故事、每个理论，比如聚焦系统、减法系统，都是来自于陈吕文老板社群的研发。您的每个案例、每个故事、每个商业行为，都是来自于陈吕文老板社群的学习，实践。则，您的直播就看似没营销，但是销售很厉害了。

讲故事，讲案例，讲笑话，不是孤立您的卖点，而是所有的故事、案例、笑话，要么是来自于卖点，要么是辅助卖点，要么是衬托卖点。也就是您要必须几分钟出现一次卖点，而且要看起来一点也不违和。

现在很多人讲直播的特点是，只管自己嗨而跟卖点没关系，这样的直播是没有意义的，也是为什么很多人不赚钱的原因。这个潜营销系统，无论学习多少次，练习多少次，都不为过。要熟能生巧，要练熟巧妙的运营这个潜营销系统，您要不断地通过各种故事、案例、理论、话语体系、幽默的体系，过度到我们的卖点里，也就是陈吕文老板社群。只要客户记住我们的卖点，客户就会买单。各行各业都是如此。

“某会卖书，就是这个模式，这个理论来自于这本书，这个方法来自于这本书，我在这本书里有什么启发，建议大家看看这本书，我若是早点看了这本书我就会怎么样？我后悔没有早点看到这本书，这本书真是我见到的最好的书，有了这本书，我就有了理论基础，我就是按照这本书里的理论，来做人做事做生意的。”
