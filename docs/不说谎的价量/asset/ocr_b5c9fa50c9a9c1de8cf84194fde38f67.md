# 前言

> 對於那些願意研究、學習與辛勤工作的人來說，這是最好的學習時機……從過去的經驗學習，邁向未來的成功。
——羅伯特·清崎（Robert Kiyosaki,1947~）

對於我來說，這是一本意義非凡的書，也是我多年以來一直想寫的書。

現在，我終於有時間寫了！

我希望，各位一旦閱讀本書，也就是我想跟各位分享的一種交易分析技巧，將對各位的交易產生重大影響，就如同發生在我身上的情況一樣。多年két，我偶然發現這種方法，而且整個過程似乎不像是真的，當時我正開始對於金融交易產生興趣。現在，我很高興當初能夠有這個經驗，雖然我也付出了重大代價，如同各位稍後將了解的。學習這套方法，對於我的生命與交易生涯是個關鍵轉捩點。我希望這本書也能改變各位的人生。

所以，這種交易技巧究竟是什麼呢？其中有何特別之處？這種方法已經存在 100 多年，過去的明星級交易者一向都採用。雖然是歷史悠久的遺產，但當今的交易者很多都忽略，甚至不知道這種非常有效的方法。至於原因為何，我也不知道。對於我的交易和投資來說，這套方法過去 16 年來都是我憑藉的基石，而且到現在也還是如此。這套方法威力強大，從很多方面
