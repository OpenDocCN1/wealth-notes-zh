# Chapter 09 價格的成交量分析（VAP） | 207

價量分析（VPA）是一回事，價格的成交量分析（VAP）則是全然不同的另一回事，後者讓交易者可以一眼看出某特定價位的成交量密度。這是一種非常有效的工具，但多數交易者不懂得使用。行情一旦突破這些區域，只代表一件事：趨勢來了！如果再經過 VPA 確認，獲利幾乎就是保證！
