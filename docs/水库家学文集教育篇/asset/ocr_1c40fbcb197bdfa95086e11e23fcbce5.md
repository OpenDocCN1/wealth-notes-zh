# 现在大学教育主要培养的就是一种技能

背书。

只要你背书努力，天天起早贪黑，考试成绩就好。因为我们的教育首先规定，所有的问题都是有标准答案的。考察学生的能力，主要是看学生是不是能够写出标准答案。寻找标准答案这个逻辑思维，要贯穿你 16 年或者 20 年。很多高分学生大学毕业无法适应社会。因为社会上的各种问题并不存在标准答案，而是风险、风险、风险。
