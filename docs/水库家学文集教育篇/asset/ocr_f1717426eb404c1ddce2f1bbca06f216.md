# 那些年，我们曾经鄙视的下人

剃头匠，估计你不会正眼瞧的。前两天，我居然仔仔细细看去看了一眼。

他们穿的工作服，都是千元一件的特制短袖羽绒服（黑色长款）。我问他，为什么啊？他说，这是小钱，要有个形象。

他们不喝自来水，都是矿泉水，一大箱灌在那里。

他们午餐外卖，都是三十元以上的盒饭。

我估计一年到头，带国家 30-40 万存款是可能的。
