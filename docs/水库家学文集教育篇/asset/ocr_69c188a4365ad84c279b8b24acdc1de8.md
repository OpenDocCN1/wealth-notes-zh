# 2019 上海社保缴费基数

上热左孝顺：# 2019上海社保缴费基数# 上海社保缴费基数一年上调两次，不到10年就翻一番！ 仅以上海每年社保缴费下限为例，2011年为2338元，2012年为2599元，2013年为2815元，2014 年为3022元，2015年为3271元，2016年为3583元，2017年为3902元，2018年4279元，2019 年4月份为4699元，2019年5月份为4927元！无论是上海历史的纵向来比，还是与其他省市来比， 在当前党中央、国务院一直强调的降低企业社保缴费负担、稳定就业的大背景下，实在看不值信！！
