# 很多大学生被老副高教成 250

绝大部分大学生都会有一种错觉，自己有一个非常传奇的奇点思路，如果给我一个团队，设立 n 个部门，有条不紊的开展工作，最后保证做出优秀产品，成为一个优秀公司。现在就是缺一亿美元了。投资人惊呼，没看到这么一个优秀人才。

客观而言，确实有几个奇点爸爸公司，表面上真是这样起来的，但是私底下什么情况，我就不知道了。但实际上，正常企业不是这样发展的。

为什么年轻人会这样想问题？因为大学里的老副高一直幻想的认为，企业就应该成这样运作的，然后再加上自由度，希望超绝的教授孩子了。孩子年纪轻轻就被这些瞎忽悠着教傻了。

一个中小企业能不能赚钱，其实我看一眼就知道。如果老板什么都会干，每个岗位都熟悉，这种企业一般是赚钱的，除非行业本身不行了。如果一个老板只管管理，对各个环境不大会熟悉，完全靠副调各个部门经理，基本是倒闭的。

中国有几个特大型民企，已经无法用运气好来形容了，他的每一步都契合了社会经济重大改变的绝佳机遇，他希望什么改变，什么改变就来了，完全没有人想到可以和他竞争。但是，真正的企业不是这样靠运气的，我举个例子，大家就看懂了。

苹果和微软的发展历程。一开始都是几个创始人，只花了一点点小钱，在车库里做出一个简陋实用的样机，受到市场欢迎，生产，销售，回款，再生产，滚动发展壮大。到了一定阶段，大资本介入，一下子推向大市场，99% 的企业都是这样起来的。

创始人是非常累的，因为初期没钱，一个人要干几个部门的工作。三个创始人就可以下一个企业，企业三大块，生产，销售，财务库存发货等杂事，下一片干。如果产品首发的一炮打响了，钱就来了。因为新产品产不足，销售商愿意提前打款抢货，预付款就成为了新的扩充资金。熬上 1-3 个销售周期，投资人也来了。

做好企业，一开始不靠阴谋设计，而是你的产品成功。但是，大学里的老副高们彪形，他们去企业调研，往往是去成熟大企业。老板们一般都是极力营造当年的窘境，故意误导老副高看现代管理体系，漂亮的厂房办公室，最先进的机器，这些 250 以为，企业就是这样的。哪里知道当年创始人被嫌弃唾的漏雨跑的样子？

结论：年轻人创业，不要想入非非。你先做出一个市场高度认同的产品，只要质量好，性价比高，其他的事等自然都来了。漂亮的 PPT 书也会死摆烂打，只要你点个头就行。

# 大单位容易越混越平庸

大学毕业，意气风发，全国期刊发论文，加班是拼命三郎，上来就出彩了。这是很多 985 工作第一年的真实写照。但两年后，绝大部分人就开始平庸了，虽然才 25 岁，真没办法，现实就这样。

你看问题是站在自己角度看的，但是，别人不这样想问题的，小子，你真能干是吧？大单位里，本部门，综合部门，行政部门，几千岗位，能够给你派活的，不下三十多个人，你还不敢拒绝。这么多老油条，偏好资源，一看你能干，争先恐后把自己的活派给你，还好好好听话哄哄你，“小伙子，前途远大，加油加油，这个事情一批天下交”。

一开始，你觉得大家是器重你。阿一批送这么多事，人事部的泰科，不交给别人，单单交给我，这是对我的独爱，这是对我的信任。我要拼命干，997 都可以。人的精力是有限的。你干的越好，交给你的杂活越事多，反正你干活不要钱的，质量还好。最后，你挡不住了。做一个精品，也不是那么容易的。
