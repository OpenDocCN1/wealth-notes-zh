# 我家孩子测验不错，考试不行

某案，我家孩子课堂测验都不错，分数蛮高的，每次期末大考就不行了。为什么？

答：90%可能是课堂测验作弊了。10%是考场心里素质差。你不要以为孩子们都天真可爱老实，其实 99% 的孩子会作弊。1%的学霸不需要作弊。

# 幼儿园家长请注意

今天接到一个粉丝的诉苦，孩子已经小学一年级了，坐不下来，一看书就哭。这是规矩没做好。你要提前一年，培养孩子每天晚上半个小时，听故事，最简单数学，写写画画，反正养成一个习惯，坐得住半个小时。

如果幼儿园没有养成这个习惯，一年级就头大了。当然，这也没什么，随着孩子的成长，也会解决问题。但是，一年级成绩太差，对孩子的自尊心有一定影响。

# 现在的小孩子，是太要面子了

# 为什么学霸好像一天到晚在玩？

我读中学的时候，有件事情，百思不得其解。我们班上也有个学霸，每天课间休息就是说昨天晚上看的电视剧是什么内容，还和一大堆女生讨论。我真是他的雷古七了。我基本不看电视剧，就是看课本。

他下了课，在操场上玩半个小时再回家，晚上又看电视剧两集，那时候一般是 8-10 点，那他基本就不读书了。问题是，每次考试都和我差不多。我实在是接受打击。

工作多年后，我遇到他，旧事重提，才查出真相。原来是他妈妈喜欢看电视剧，然后第二天吃早饭的时候，他就问他妈电视剧的故事情节。他就背到张上吹，实际上他根本没看过电视。我被骗了很多年。

# 高中刷题有用吗？

刷題对数数化的最后两题是无用的，倒数第三题看情况。但对于前面的 125 分是有用的，超模有用。刷题就是单个知识点的反复巩固。

如果不想考清华，只想考上大武大，刷题就够。能不能考上说一个标准，前面 125 只能错一题。
