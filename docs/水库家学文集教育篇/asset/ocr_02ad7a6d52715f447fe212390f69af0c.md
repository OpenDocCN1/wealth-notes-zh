我现在也傻眼了。说吧得罪人，不说吧，这孩子倒霉。

# 孩子吵着要去培训班是什么情况？

现在，培训班已经完全商业化了。他们知道说服家长掏钱不容易，但是诱导小姑娘继续报名很简单。最常用的招数是：

+   一、对孩子进行物质诱导

例如表现好给两个五角星，积攒到一定时候，可以换奖品。表现不好，故意为难批评孩子。然后给孩子施压，让他勤学苦练。孩子练的越起劲，第二期缴费就越趁手笔。

二、欺骗孩子

明明是一般水平，但在班上听话的孩子，老师就经常性表扬，把孩子哄得以为自己了不起，非要练下去。

三、欺骗家长

装模作样的搞一些公司性质的比赛，给这个孩子一等奖，那个孩子最佳奖，有的还搞些视频剪辑，电视台下午空放时间播放一分钟，让家长在微信圈夸。

这些都是常见招数，非常有诱惑性和欺骗性。各位家长留个心。千万别一句话，不要指望这些家门口的业余教员能搞出什么花来。

# 幼儿音乐和舞蹈的建议

可能得罪人了。但我还是说一下。你花两百元找的老师，可能教的都是错的，业余的。混个业余考试，可能不是问题，但和职业打比赛没有一毛钱关系。

可以去学学，但不要勤学苦练。紧练小时候练琴五年，最后发现，那些业余老师教的都是错的姿势，就是小学生文艺晚会演个数的水平。知道真相后，大家真的很伤心。为了练琴，她还被打过。谁能想到培训机构教的是错的。

舞蹈不要练习危险动作，拉拉腿，活动活动就行了。什么芭蕾舞蹈脚尖的事情，我看你别搞了，十有八九是错的姿势。

# 不要过分的提前教育

+   一，家门口的艺术班

你就是花点小钱，让孩子感受一下艺术，千万不要以为这些职院校校淘汰下来的业余人才，能够让你的孩子走上专业道路。真的要学专业，打比赛，去音乐学院和舞蹈学院，找副教授。一年十万起步起。舍不得钞票，就不要胡思乱想。

二，英语班

我孩子报了一个英语课外班，我去听了一次，立马不去了，那老师大概是农村来的，发音非常含糊。

三，语数班

不要过度开发，认几个字，就当玩，不要一本正经的上课。

儿童成长是有规律的，儿童大脑发育有个过程，没必要提前抢先。绝大部分儿童的记忆力非常好，很容易让家长误以为自己孩子是天才儿童，我小时候还不认字的时候，有些教师子女已经可以背唐诗一百首。但是，他们这种提前教育，效果一般，到了五年级彻底没有任何优势了。
