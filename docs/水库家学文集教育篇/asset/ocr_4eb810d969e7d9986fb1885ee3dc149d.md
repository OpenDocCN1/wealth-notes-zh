回乡下。于是作为外地闲散人员，在燕滞留做点小生意。为什么这么多湖北人，就他一个去摆摊呢？这里有个背景，当时，大学生摆摊是被人家鄙视的，类似于现在挨家挨户借钱穷发水的待遇。

但是，刘同学无所谓，因为他本来就是穷人，一家门全部是农民，人在外地，也不存在什么脸面，摆挣就摆摊，who fits who？。其他城里孩子，名牌大学毕业，肯定是千方百计要去家长单位，例如他前女友，就是正规矩路子的常规打法。

人生第一步，他们事后者，完全符合了大时代的节奏，他自己又是聪明用尽，不发财是不可能他的，他后来成为几百亿的富翁，肯定是机遇。但是，如果没有这个几百亿的机遇，他到现在，肯定也是个上亿的规模。为什么？

+   1. 他没有北京房子。他是 1996 年毕业，1998 住房大改革。他是闲散人员，不可能有单位分房子，他肯定要买房结婚的。而且，肯定是买在中关村，上班近啊。这至少一千万来了。

+   2. 他肯定会继续买房。因为员工宿舍问题。他当时大概十八个员工，男女分开，至少买两套，这就三千万了。巧的是，他有这个资本。当时流行拿首付或者二成首付，与其到处借宿舍付租金，还不如直接贷款月供。

+   3. 他还会去买一套小房子，当仓库。因为中关村的仓库，又矮又小，租金也贵，不如附近买个破房子，一墙当仓库。

+   4. 这就四套了。当年，中关村附近三千元也不到啊，类似于城乡结合部。

5. 他就浑了中关村。这个年代进去的，基本上个个发财，只要不吃喝嫖赌，现在都是有钱人。

而他的同学肯定不是这样了。他们同学都是大单位，进去了，第一个反应都是等单位分房子。海淀区在 2000 年左右，还有各种乱七八糟的集资房之类的，大单位没人买房。因为买了房，就不是住房困难户，就不分房子了。傻子才买。

即使买了一套，也不会再买了。因为当时的人，把职级职务作正途，他们 985 档次的，一门心思都是单位干事业，不会三天两头关心楼市。那是被人鄙视的。当年，谁在单位里讨论买房子赚钱，基本就没有前途了。大家都知这种人是，不务正业，满脑子都是钱。现在好一点了。

就真想买二套房，也没钱。刘同学是做生意的，那些年中关村发财了，有钱啊。机关里的，月入 2800 元，想也别想了。

红眼了。北京那么多房子，房子哪来的？主要是大单位多次分房的结果，这里有很多你不知道的事情，到了 xx 级，父母分了俩套，自己分了俩套，丈母娘分房子的事情，非常多。再遇到拆迁，呵呵！真正有房产意识是 2006 年以后了。

刚解放的时候，上海滞留了很多富二代，主要是长子，留在上海学房子的。老父亲就带着女婿和尚子，还有几房小老婆逃香港了。当年的意思是，我们两头押注，你是长子，在上海学住房子，不能当无主产业被没收了。这个决定，害惨了太多的上海富二代。等待着这些富二代是几十年政治风暴。

这些富二代，别看平时吊儿郎当的，但大部分人家是有文化的，很多人有一些奇怪怪的业余爱好。在那个特殊的年代，这些毫无意义。但到了市场经济起步了，这些玩意儿就变成巨大概富了。
