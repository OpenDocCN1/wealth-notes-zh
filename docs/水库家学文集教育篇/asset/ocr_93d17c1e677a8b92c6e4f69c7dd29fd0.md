# 小时候打架

我小时候一直是好孩子，成绩好，不惹事的那种。班上的同学也客气，极少欺负我。这导致了你的懦弱，不太敢打架，甚至有点怕打架。

有一次放学后，其他班级几个不熟悉我的人欺负我，起因我已经记不得了，我当时是尽可能逃离。但那次倒霉，被他们堵在墙角里，一顿打。我也不敢反抗，心想挨几下揍也就算了，我还要回去写作业，也不知道怎么回事，脑袋裂个流血了。

血液从头上流满了半个脸，我手一抹，满手都是血。突然间，我内心最原始的本能被激发出来了。

具体表现是，我失理智，一心要报复，而且不考虑所有的后果，就想嫩死他。我就在地上捡起半块砖头，朝对方冲过去，对方以为我是包，哭嚎嚎的等着我，我直接朝他脑额砸，他挡了一下，撞到脑袋，对方一看我来的，就跑了。

我那时候已经发疯，拼命的追，非要嫩死他。他就拼命地跑。我因为手里有块砖头，很重的，跑不快，没追上。

我长大后，有时候就想回这个事情。当时为什么我会不计后果。真要打出事情了，我也完了。我的结论是，

+   第一，当一个人被激怒的时候，好像身体里会分泌一种激素，而这种激素会令人直接丧失理智，其实，冷静下来。我也是后怕的。

+   第二，有的人可能有嗜血的情绪。对方逃跑了，我的快乐极大，就想追上去继续揍他。我也无法解释，为什么那种快乐如此强烈。其实，理智的讲，我应该去包扎伤口。但那时候真是，不考虑，就想继续揍他。

+   第三，我慢慢理解了，曾国藩为什么能够把一群老本分，胆小懦弱的农民，训练成为所向披靡的湘军。
