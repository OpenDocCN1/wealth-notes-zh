# 重点小学到底有多大恩怨？

很多家长，可能自己当年读书不好，一心想着希望孩子从小学就进重点，一路重点，最后考到985，不惜一切代价，也要搞个重点小学附近的老破小，顺利报名。我简单说说，重点小学是啥样的？

重点小学分为两种：一是考试型。二是兼文体特产班。我重点说一下考试型。

大家都是人，重点小学也是人，不会比普通小学厉害多少。当然区别也是有的，就是提前刷题，多刷题。小学也没什么花头，成绩好都是刷题的结果。鸡兔同笼，算几只脚之类的。你要是没刷过，考场上肯定蒙蒙。老师起到的作用是，通知你尽可能多刷题。有些老师也是农村出来的，说话尖刻，阴阳怪气的。

有的家长认为，重点小学，家长更加重视。普通小学有外地人孩子，学风不好。其实，你真的误解了。现在，外地家长对小学生的重视程度，甚至比富人家孩子还要严格。大部分家长是在初中后，才会彻底放弃孩子。小学时时期，还是超级重视的。

有的家长，不顾现实经济情况，买个不居住的老破小，每天开车来回重点小学，接送孩子。这是不可取的。家长们如果真的对孩子成绩报以巨大希望，关键是自已抓，自己盯，如果能力有限，找个稳定家教，长期跟踪。每天路上这么多时间，至少五年，大家都累，还不如把这个时间用在学习上。

# 读书逆道的概率越来越小了

菜鸡是外国名校毕业的本科，现在卖塑料桶。我在当段子手。

我有几个熟悉的师叔师妹，国外读了八年，博士毕业了，回国就业。

2012年以前，一般的外国博士（世界排名中上，非顶尖人才），可以在京沪二末求个大学助理研究员，讲师的职位。以后就很难了。

2015年，我的一个博士小师妹回国，最后在三线城市二本里当讲师。年薪十万。为了买房，业余时间去外语补习班当老师！每小时小几百元。这不是个案。

你问问现在的欧美日加载的一般博士（哈佛耶鲁除外），有几个混的好？

当然，你要是可以在麻省理工毕业，那就你挑了，还有安居政策房周转几年。如果是考文革大学硕士，那就没人理你了。
