# 进入不同体制的同学们的经历

我现在四十岁出头了。回顾当年进入不同体制的同学们的经历，感慨万千。

+   1，进入外企的，现在基本是半死不活了。但是他们房子多，当年工资高，房价低，他们人均 4-5 套三居室。

+   2，进入公务员的，已经赶上来，绝大部分是中层干部，每年都有几个公示。

+   3，进入私企的，两极分化，主要是京沪广深。我们那个年代，国家包分配，哪来回哪去，一些穷地方的同学不想回老家，就自己出来找工作。两极分化很严重，穷的实在是穷，年收入一百万还不到，富的已经上市了。

+   4，进入国企的，基本到了省公司的中层，企业里的实权处级。

+   5，一开始就自己创业的，大部分是在京沪服务业，汽车修理厂，咨询公司，设计公司，收入不清楚，但几套房子是有的。这些人是精神百倍。
