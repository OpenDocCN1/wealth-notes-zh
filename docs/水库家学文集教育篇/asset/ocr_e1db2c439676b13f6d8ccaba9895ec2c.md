# 服务业，不起眼，但是真赚钱

我说你身边正在发生的例子。某娘俩年前买了个外地大别墅，去年交房装修了。装修第一件事情就是土建，砸墙，挖坑，填土，河沙水泥，浑身上下都是灰，脏的不得了。你知道土建的价格吗？我那个别墅，土建就搞了半年，30万，大概项目是挖土，砸墙，混凝土浇筑，地坪。

和我家打交道的是一个年轻人，三十几岁，读过辣鸡本科，我老买的是楼土，我家一开工，附近几十号邻居都来了，大家加了微信了。某娘也不隐瞒，实事求是讲了情况。这个年轻人，一共接到了42家订单，金额超过1000万，估计一年的纯利润超过150万。就他一个人，带了村里的一群老年农民。这钱都是到手的，没有拖欠。

居民愿意花钱的几件事情。房子，教育，医疗，婚庆，生育。你就琢磨琢磨，看看能不能搞出些花样。你不要怕，这几个领域，现在没有什么绝对大牌，只要你够努力，会做人，抢到一口饭，是完全可能的。

# 民企为什么重视人才？

民企是无极限的竞争，一年产品不好，就会巨大亏损。一切为了生存。人才就是武器，就是经济利益。优秀员工把技术搞定了，把销售搞定了，把钱款搞定了，老板除了老婆孩子，其他都会给他。副总不就是一个拍头吗。拿来销售。加价。也可以，咱们算一下，你为公司创造了多少价值，你分一部分，年终奖几十万也可以。

与此同时也，我们的有些特大企业是自然垄断，有没有优秀工程师，还真不是大事情。效率低一点，你也看不出来，因为没有相同的比较对象。只要不发生生产事故，谁敢说我不好？谁说我，我就给他扣个大帽子，一根子打残。

# 年底的这次提拔，没我的份

某某，我是硕士，总部办公室，主要是写稿子，今年三十岁了。年底的这次提拔，没我的份。刚才，主任专门找我谈心了一个小时，让我继续加油，今后还有机会。某某，我明年有戏吗？

答：没戏。你属于干活卖力，没有背景，随时可以弃子的角色，不要以为明年你就是本科室一号种子选手了。这是不可能的。所有的位子都有好几个人盯着。科室没有对手，随愿科长调一个过来也可以。

科室对于提拔你，可以怀事，但不可能成事。有决定权的，主要是某个副总帮你争取。目前看来，你的努力也只在科室内部。副总层面还看不到你，或者不感兴趣。

科室主任自己能再千多人，都是未知数。他这话，是对你工作努力的一种认可，但也仅此而已了，不要想多了。

建议：让一把手或者副总看到你的努力，这就快了。如果提拔前三个月，副总对你还是公事公办的感觉，基本没戏了。
