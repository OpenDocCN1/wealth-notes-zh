# 富人家的傻子？

富人子女，读书不好的比例，比穷人家低得多。但凡读书考试，好的差的比例是固定的，最大的区别是 40%中间人。

我见过几个富人家的孩子，人也不笨，就是读书成绩确实不好。这些孩子往往是家里的长子，在读小学的时候，父母大概是三十岁，一门心思赚钱，一天到晚忙生意，管不了孩子，也没有什么耐心，孩子们在中小学家长期没人监管，又有钱，就喜欢打游戏，时间长了，就废了。

但是，这些孩子到了结婚年龄，人品不差，见过世面也多，往往住父母给拍了几套内核城的房子，娶老婆一般也是发现 985 小美女，问题不大。

# 在上海认识一个普通东北人

那天，在小区里遛娃，碰巧发现对方也是同一小区的。四十多岁，男的，可能是商人。我们这个小区，最便宜的小房子是 1200 万，对方是业主，经济上应该还可以。那就闲聊几句呗。

上来就是利益。他首先是说，怎么联合起来和物业闹。因为物业的某个事情，让他不舒服了。我们刚刚认识一分钟，他就想使唤我，我是感到郁闷的。不是说物业不对，至少我们还没熟悉到一起去找别人吵架的地步。

接下来是秀肌肉。很快，他开始说他在这个小区里，他有多少亲戚，多少熟人。无形中给我一种巨大的压迫感，好像我将来某天得罪他了，在这个地面上就混不下去了。

然后是秀钞票。反正什么事情都有保障，司机。儿子如何如何优秀。

接着打听隐私。你干什么的啊，你房子多少钱买的？是开盘就买，还是二手房？我基本上是接不下话了，卖了个借口，继续遛娃走开了。

上海人一般刚刚认识，会说些轻松的话题，例如教育，购物，餐饮。这个家伙，不到十分钟，把我震得三魂破裂。有没有老铁？这兄弟奇葩，还是靠山屯差不多那样？

# 杠精是这样的

“我看不起吴晓波，我看不起罗胖，我看不起某某，我看不起（省略一百个名字）”。反正他看不起所有人，上下五千年都欠他的。

杠精自己是这样的：外地户口或本地中下层民，没有漂亮房子，长得丑，还口臭，学历一般，单位混的不如意，父母住老房子，土肥圆也看不起他。

杠精的一生，只是浪费粮食，不可能成功的。因为他没有合作意识，没有学习意识，没有明确的执行力。他以为抓到了吴晓波罗胖子某次小小的知识错点，就到处逍遥，你看我多么牛 b。其实，你达到吴晓波的知名度后再吹也不迟。

我没有看过罗胖的任何文章。我看吴晓波的作品，例如《上海滩的七张面孔》，吴晓波肯定没有系统的写过经济学论文，但他写的财经故事是上乘之作。我个人是比较认可他们的。因为他们在自己的领域里，走到了高处，成功买了好几套房子。

杠精除了一张嘴，啥也没有，纯粹是垃圾。
