# 富人一点也不猥琐，还很大气

我现在住的小区，顶楼是内环线复式江景房，有点像空中别墅，是这个小区开发商一家入住，这几年经常在电梯里遇到他们家。

其实，有钱人也是吃背菜，拖老母鸡，穷耐克，比你好不到哪里。他女婿女儿，男帅女靓，高个子，大长腿！富人一点也不猥琐，甚至还很大气，养眼。有一次，我的车胎出了问题了，他在地下车库主动跑 come 告诉我。

真正最猥琐的是屌丝，一张嘴就是别人不好，女人太势利。上下五千年，我最孝顺家里那个穷爹，但就是不出一钱。

# 别想多了，你还是民工！

很多外地985+一张职业证书(CPA, 一律，律师，医师)来京沪，就觉得可以自己白手起家了。

实际上，和你当年你父母找个组织里来打工的情况，区别不是很大。物以稀为贵，现在的文凭和证书，每复一年的批量生产，早已经铺天盖地，急剧贬值了。

你现在赚1-2万，内环线房价是10万。当年，你父母在杨浦大桥工地上刷水泥，月入800块，那时候内环线房价是4000元。

你觉得你进步了吗？别想多了，还是女民工。
