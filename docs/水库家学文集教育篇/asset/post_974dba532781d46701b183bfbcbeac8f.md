## 明清县衙的公务员

真的只有三五个人吗？胡说。

县机关编制分为三等，政务官，事务官，合同工。

- 一，政务官四个，知县、县丞、主簿、典史，吏部选造，皇帝任命。故称“朝廷命官”。
- 二，事务官六房。吏、户、礼、兵、刑、工六房。六房是县机关。有名额，无工资。称为吏。以上加起来就是，官吏。
- 三，合同工，六房下设的衙役，实际办事人员。衙役是本县居民，轮流担任，自带盘饭，不发钱。

从这里可以看出，三类编制，都是穷光蛋，怎么办？捞啊！

事务官，相当于部门领导，对上孝敬，对下盘剥。

- 一，征税贪污
- 二，包揽诉讼
- 三，办事做手脚。

合同工相当于基层办事员，直接面对农民。古代消息闭塞，上面又要征收粮食税，只要不糟出人命，随你怎么搞。衙役们就在各种事情上，盘剥农民，对上报虚账。例如我买一两银子，实际收了1.3两，对上保0.9两，克扣了四成，按照惯例，往上送一半。以此类推。

举例，各家征劳务，富人家出钱，找个农民顶替，衙役假装不知道，收点好处。

一般情况下，中等县，衙役大概是150人左右。
