我有个初步的想法，不知道对不对？大家也可以谈谈。像我这样的家庭，其他不担心，就是怕孩子学坏了。我准备从小引导孩子将来学法律系。据我的观察，法律系的人，几乎没有发财的，但他们很稳当，也几乎没有混成傻B的。

我希望孩子能够保卫生富，不需要再造创造财富了，已经够了，再多了就会惹麻烦了。我准备从小学一年级就开始误导孩子，让孩子觉得，学了法律系，今后可以称霸安检，替天行道。小孩子最喜欢这个。

# 尽心尽力，真有机会

年薪五百万，肯定是看运气。但是，年薪四十万，主要看个人素质。具体不讲了，各行各业，千差万别，但是，你尽心尽力，真有机会。

# 小细节，大素质

前两天，公司让几个应聘者，微信学历照片。我仔细看了一下，

+   1. 2个人拍照片的时候，手机镜头上估计有手印汗水，照片清晰度不够，看起来费劲。
2. 1个人拍照没照全，缺了一角，也没缺字。
3. 1个人拍照没发过来是倒的
4. 1个人拍照了，把桌子上的杂物拍摄进去了，直接发了。
5. 最后一个人，把手机镜头擦净，照片清晰，端端正正。

本来就是基础岗岗位，做事情马马虎虎的人，对上级都是如此，对客户岂不是随心所欲了？

# 抱团

刚才有个私信，说是单位里基本都是上海人，上海人抱团，欺负外地人。我差点一口老血喷在手机上了。我年轻时候在单位里，阿拉上海人也是互相不服气，出了名的不抱团，只管自己的。相反，外地人非常认老乡。现在的上海年轻人觉醒了吧？无法解释了。

# 千万不要找领导要什么！

我年轻时候，英语特别好。单位里有个名额，是培训学英语语。我非常希望我有能有机会去，于是，一天到晚陪陪人事处长打电话给我，但最后，这个机会是给了一个关系户。我心里那个难受啊。我就战战兢兢的去找了人事处长，问他能不能让我去。

人事处长和我打了一圈太极拳，我就滚回来了。但是，他算是讨厌上我了，今后很多事都没给我过好脸色。其实，我现在明白了。大单位对职业技能的要求是不高的，反正是独家生意，无所谓。单位里的任何好处，都是有分配规则的。如果你不服，就是挑战领导的面子，哪有什么好处架子吃啊！

# 大单位生存法则

一把手和分管领导，决定你今后10-15年的职业生涯。如果这两位都不认识你这个大小胖子，那么你人事部主任会在最短的时间内，把你的腰围搞搞，目光呆滞，啥也不想了。

你要做的是，尽可能向一一把手靠拢，混个脸熟，至少让他们知道你在方面的水平较好，即使是打乒乓球也可以。
