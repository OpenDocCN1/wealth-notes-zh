# 扩招，断了985的路

三十年前，某万人厂，一扎手的儿子比我大三岁，没考上大学，毕业后，只能按照工人编制分配工作。代大干，要经过非常复杂的程序，工转干，必须读完夜大学四年，满了离去，就要三十岁了。而且，还有很多人告状。

而男孩子只要是考上大专，21岁毕业就是干部编制。本科毕业就是科员。研究生直接是正科（那个年代）。据我了解，很多工农子弟通过考大学改变了命运。我们那时候没有富二代，房子也是国家分的。

现在的情况是，本科泛滥，一旦拿到了本科学位证，有关系的同学就直截一路绿灯了，你就算是985，怎么比得上他们啊！扩招，表面看是大家部上学了。但实际上，很多人的社会排名反而下降了。

# 给外地高中生家长的话

如果你没有五百万现金，那就不要考虑房贷了。什么儿孙自有儿孙福，那是骗自己的，不要拿去骗孩子。你还有6-7年的时间存钱，你大概算一下能够到哪个城市的六十平米首付，就让孩子考买得起的城市。

现在的孩子很敏感，你把他推到贫穷处境上，他真的很恨你。

# 从小考奥数，长大吃软饭

刚才，听了这位家长代表的发言，很有感触。这确实是个非常好的创新思路，儿子能力落，今后自然有姑娘带着房子和小孩子嫁过来。但是，这事请不是 1+1=2 那么直线思维的。下面，我谈几点要求：

+   一，色艺双佳是前提。

男的单独考试好，没用的。我大学本科班上，哪个不是学霸？有个鸟用，孤瓜裂一地，找个好看一点的小卖自都很费劲。男的必须有模样，否则，就一个干瘦四眼鸡，没有丈母娘会同意帖房子的。

以前说过一个四腿睡冬瓜，34岁博士，内环线 985 副教授，连个老破小妹妹都搞不定，最后被妹纸发了好人卡。

+   二，情商要高。

简单点，会嫁。学霸和会嫁，是很矛盾的人格分裂，能够做到的极少。荣棠某个极品，也是磨练多年才勉强达到。

+   三，婆家也不能太穷了。

我虽然想吃软饭的，但是我家里还是有几套老破小的。出手大方。荣婷那时候就觉得我是很有本事的。其实，穷光蛋一个。
