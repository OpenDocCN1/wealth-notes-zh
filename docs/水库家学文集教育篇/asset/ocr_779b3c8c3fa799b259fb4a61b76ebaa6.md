# 做个有良心的富人

+   建议实行”住房遗产税”。
理论上，各种遗产都应该交遗产税。但是，征收有困难。
1. 现金存款，转移容易，没法监管。
2. 不记名的贵重首饰古董，无法查证数量真伪和去向，难以实施。
3. 二手车，不值钱。
4. 公司股权，上市公司还好办。非上市的一般中小公司，很多是资不抵债的，如果放弃继承，大多数是要破产的。债权人和员工权益，难以保证。
想来想去，最靠谱的就是房子。也不要你当场出钱，产权份额划定三分之一，归入住房保障机构
