# 欧美国家的年轻大学生是怎么混社会的

我是见识过一些人了，基本还是分层面。

一，中上等

类似于 985 毕业，父母是有家底的，一般是在父母照顾下，进入一些高大上的单位，然后凭本事往上走。牛气哄哄的优质单位，推荐信很重要。这个就是看父母了。

这类学生，从小到大，学习成绩也算好的。所以，方方面年就出色了，至少流利的说两个外语。

立场偏右。

二，中下层

这类大学生往往是白左。父母是屌丝，他按部就班，进入一个本省本州的中等大学，成绩一般，混混毕业了，找个小公司上班，一边玩，一边抱怨社会没有机会。

这类年轻人对资本家富人非常不满。有个三十岁的白屌丝和我说，他妈妈一直是宾馆服务员，经常加班，很辛苦。资本家很坏，加班不加钱，只是调休到淡季。全家人这么多年，基本没有旅游过之类的。

他自己学习能力一般，考教师招聘一直没考出来，能力也不行，就是混日子。外语很差。

三，屌丝逆袭

这类学生超级刻苦，学习成绩非常优秀，极其自律，野心勃勃。

四，一烂到底

很多移民家庭，父母对孩子的教育，基本为零。社区环境也没有学习的氛围。一般到十八岁就不读书了。到处玩，打散工，什么也不会，盗窃毒品的最大受害者。结婚后，往往是靠福利为生。如果开窍了，中年之后找个体力活，例如工地打工之类的。若是不开窍，天灭惨的迷迷糊糊。

# 因材施教。美国大学招生的秘密

二 十年前大学时代，我看 GRE、gmat，我当时很奇怪，美国的高考考研之类的，教怎么如此简单？这个印象一直在脑海里。现在才知道，被骗了。

美国的高考数学，分为四档。GRE 那个档次的题，是最低级的相当于国内初二数学。这是给不喜欢数学的人考的。今后不想数学吃饭，例如戏曲编剧，文史哲之类的。

美国最难的高考数学，相当于 985 数学系一年级的水平。这个就超级难了。但是，讲麻在理工，就必须练这个，否则人家不要你的。

这里有个逻辑呀，因材施教。我读文院准备葡萄牙语专业，我没必要去研究抛物线的计算。但中国不强词个性，必须统一高考，考中文系也必须研究抛物线难题。

那我们能不搞分类高考呢？这还真不行！
