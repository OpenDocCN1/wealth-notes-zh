# 现在的小学数学

教学导向可能是错的，建议再商榷。

我看了很多小学题目，题目设计的出发点是，培养理论研究的思维，例如最常见的小学数学题是， 我规律。考卷设计出很多匪夷所思的规律，让孩子他们填。我也不会做。实际上孩子们是工不可能 在考试的几十分钟内找到思路的。最后变成了刷题，尽可能多记忆各种考试规律，在考场上快速找 验算答案。

低年级的孩子大脑发育还不成熟，高度逻辑思题的题目，只是展现了老师的出题水平，并不符 合儿童的情况。我们把大多数青少年最后成为熟练的操作工，例如会计，普通医生，手工，小卖 部经理，理发师，不需要非常强大的理论研究功底，有个正常人的思维就够好了。

但是，我们的教育体系为了提高难度，消灭打击一般学生，我喜欢解题，实际上孩子们也不 可能在考场上，一分钟内解题。现事中就变成了大批量刷题，刷过的，有印象，解题快，没刷过的， 你不会，我也不。

刷题教育，考常拼的是淮先学，日常拼的是时间和近化眼。大部分青少年近化，发育成绩 中下，身体没力气。很多学生性格古怪脆弱，是长期压力造成的。这种压力就是，不许自己丢一 半。高考看成绩，这不是问题才怪呢！

我们以前的大学生，是天之骄子，今后都是各行各业高精尖的骨干，研究能力，抗压力， 确实需要具备。但是，对于绝大多数人，这种自我身体的教育，毫无意义。

# 我们的教育

真的有点跟不上现实了。

高中毕业，放在五十年前就是中等知识分子了。现在不要说什么知识分子了，途个最简单的工作 都不会做。为什么？因为，学校只教你做怪题，翻题。我们是在同一个教育体系中溜出来的，为什 么有的孩子工作后迅速改变形象，立即切入角色，有的孩子极乎的错过了工作前几年的黄金期。
