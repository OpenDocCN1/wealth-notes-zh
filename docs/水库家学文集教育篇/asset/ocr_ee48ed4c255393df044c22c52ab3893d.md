# 非诉红圈所是什么样子的？

一般是混八块头的顶级场子。

每平米 8 租 8 元左右，总部主要集中在京沪宁，广深一般是分支。你站在外滩或者南京西路，往四处看一看，哪个大楼最漂亮，红圈所基本就在哪个大楼里的某一层。

这种大楼的公共一层是超级气派的，赔补膝盖踹到几个大楼的大厅等。电梯完全不同同我们日常见到的款式，非常豪华的欧式风格。电梯前有几个保安，简单的核对证件，防止闲杂人员。

到了红圈所，首先映入眼帘的是，比较精致漂亮的接待厅，地上一般是厚厚的绣花地毯。旁边有几个不隔音的会客室，因为吊顶，没说话音。隔音评价较高，达到听的清晰越差。

前台小姐非常漂亮，不至于这几年来的姐姐水平，99% 的访客，走到这一层，如果有事，前台电话会把律师叫出来。你永远不知道大楼最里面是什么情况。

推门进去，你基本上是大大失所望，办公室格局类似于菜市场，四周一圈是卖色变型的小办公室，合伙人的私人办公室，单间大概 6-10 平米，江景房。中间是一摊掉工位，类似于是卖有菜萝卜的。
