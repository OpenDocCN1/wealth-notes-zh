# 重大变化!综合素质评价首次纳入北京中考成绩

2月25日16时，北京日报客户端发布北京日报客户端消息：记者刘晨雷。

北京市委教委员会今日发布了《做好2019年北京市初中学业水平考试和高级中等学校招生工作通知》，标志着今年中招录取的方式发生新的变化。综合素质评价结果首次纳入中招录取，将直接影响初高中升学。

通知显示，今年学校向市级校际交流计划组织招收流动儿童，其中，根据市委教育工委关于进一步加强2019年小升初跨区入学工作文件的通知要求，按照跨区录取区域内志愿方式，校生生源五关关录取结果。录取结果由学生或考生提供，初中综合素质评价成绩由区教育主管部门负责，其中初中综合素质评价成绩每满分100分，其中1类40分，2类30分，3类15分，3类15分。市级部门将向各区反馈结果。

根据市政府此前下发的《加强和改进初中学业水平考试和综合素质评价工作的意见》，综合素质评价在高中阶段将包括思想品德、学业水平、身心健康、艺术素养、社会实践等五个方面。初中学生综合素质评价结果将用于学生的综合素质等级评价，以等级方式呈现结果，包括：优秀、良好、合格、不合格。具体包括：学业水平、实践创新、自主发展、个性特长、品德素养等四个维度。各区的《北京市初中综合素质评价实施方案》将在学期结束后发布，会由不少于五方，对评价结果进行公示、复核，会形成电子档案，由学校负责记录和管理。

经专家论证的北京市初中学生综合素质评价指标，包括初中学校各学科评价内容和各学科评价标准。综合素质评价结果将作为中考录取的重要依据。中考考试不再设置文化课考试，由各中学以等级评定，作为中考录取的参考。

一些学校、区教委表示，今年将全面组织初中毕业年级学生进行综合素质评价。学生综合素质评价结果将作为高考志愿填报的重要参考。

专家建议，2019年北京市各区高中学校招生规模为7.2万人，其中普通高中学额6.8万人。中等职业教育招生比例为1:1。
