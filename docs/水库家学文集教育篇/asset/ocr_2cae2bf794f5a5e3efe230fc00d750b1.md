# 一夜之间，省城户口变成烂市的大白菜了（2018.03）

随便抢，不要钱。这件事是长久的吗？

答：参见省域限购政策。五年前，南京杭州成都买房，随便买，求你买，你还一副高高在上，看不起省域的样子。哦，限购了，你哭去吧。

户口代表什么？至少是学情，低保，医院。省域忽的一下放开户口，在短期内，入户的普通人不会增加公共福利设施的需求。刚刚毕业，身体倍棒，这几年也不会马上生孩子，更谈不上孩子入幼儿园，读小学。户口放开初期，好处很大，基本无害。

+   1，省城年轻化了。来的都是年轻人，朝气蓬勃，会大大缓解劳动力不足的问题。四十岁以上的就不要了，回老家吧。

+   2，省域消费会持续火爆几年。进城定居后，各种物品要买了，至少全家顿一顿馆子吧，电视成为省城人。
