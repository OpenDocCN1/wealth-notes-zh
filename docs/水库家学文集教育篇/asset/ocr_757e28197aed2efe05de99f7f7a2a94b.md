# 富人有什么烦恼？

大部分中等企业家的内心是很烦恼的。因为很多事情已经超出了他的管理能力。员工下班路上一个车祸，就可能让他损失一两百万。哪个农民误操作，一台几百万的昂贵机器就毁了。如果遇到各种生产事故，分分钟就去把免费餐了，

市场风云变幻。今天抵押全家资产，贷款几千万投资一条生产线，说不定两年后技术就更新了，彻底报废了。就像原来的 3g，一夜之间被消费者抛弃。

还有各种坏账，纠纷，举报，投诉，每一件事情都是精疲力尽。发家难，守业更难。实在不行，就给孩子留两套婚房，也算体面退休了。

# 穷人思维往往是短程的

经常有 250 问我，你这段时间连续写了这么多，每天几千字，又没有赚到钱，又不著名，图什么？你是不是傻？这是标准的农民工思维，工龄日结，否则不开心。

做大生意，必须先投本。做自媒体必须光有信誉度。你的读者先要在内心认可你，你才有其他可能性。当有机会赚钱的时候，他们也觉得你值这个钱。如果你上来就急赚钱，接不到广告就不干了，风险大，你的路走不远。

做事情，要考虑长远利益和短期利益。没有短期利益（例如我的房租），日常生活会过不去。但是，你在解决了短期利益后，也要舍得投无效成本，去争取长远利益。短期利益是固定有限的，翻不了身，长期利益有可能是巨大的。

# 不要劝屌丝努力

你要是去劝屌丝学好的，例如学个技术，学个本事，好好干。他有一百句话等着你。大概意思是：说用的。谁推谁，就不就那样吗？你保证赚钱吗？反正，他最后能把你气的撑过去了。

屌丝的心态是这样的，必须日结。我干了一千年，是你让我干的，必须赚到钱。你能不能保证我买房？我省，我又不是你爹，我替你挣不挣钱？

我现在遇到屌丝，尽可能回避。回避不了，就赞美他几句，上知天文下知地理，国际形势了然于胸，国之天才。朋友，这群 250，还很开心。
