够让企业的技术水平和销售额领票亮的增加，所以给的工资是最高的。但在大环境不像前两年那么好的情况下，他们的成本和收益明显不成比例。企业不想要他们了。

# 二，中年人的技术可能落伍了

计算机技术，日新月异。会计审计法律金融，各种新知识，层出不穷。中年人整天忙于日常业务，家庭事务，天天算自己的 KPI 和奖金，没有静下心来好好看课本的心态了。如果业绩做不出来，销售额上不去，连做技术员的本钱，可能也不如 25 岁的工程师了。

# 三，中年人的傲慢让人不舒服

很多中老年白领是 985 出身，以前成绩不错，又是单位寄予厚望的，开始自以为是，强考资格，看不起年轻人，对公司乱提要求，时不时想升职加薪。以前业务忙的时候，只能是哄哄他，现在不忙了，看你就不爽。不开你，开谁呀！

# 四，劳动法逼得企业开人

劳动法要求，连续两次签订劳动合同，就算企业之爹了。企业不死他不走。理论上有很多办法，但实际上他不走，企业很为难。你总不能只招聘一个人，天天拿摄像机跟拍他是不是符合岗位要 求吧？即使不符合，那又怎么样，企业也要培训调岗，这实在是压力太大了。小门小户的企业，养不起你没没啥利润的大神，早走早了，两不伤亡。

# 五，建议

+   1、对于劳动者的最大保护，是企业盈利，扩大就业，而不是难以辞退。如果职工走能能不退，会极大的遏制本就就风险重重的中小企业招聘意愿。现在的中小企业，老板都是朝不保夕，哪里管得了职工一辈子啊！

+   2、机关事业单位国企，每年要留出一定比例专门招聘 45 岁以上老白领。总不能把这事全部 扔给民企吧？

+   3、劳动法也要根据经济发展情况，灵活应对，该修改就修改，该坚持就坚持，团结一致加油干！
