参加高考，其他大学一律按户籍注册制。考试及格，直接毕业，你就可以昂首挺胸就业了。每年 800万本科大学生，只录取 5 万研究生，那还没人踏折腾了。考研的时候，你就是成年人了，你被踢踹废了，是你的事情，你随意。

# 高考不是底层青年逆袭的最好途径

高考的最大受益者，是凤凰父母和中产家庭，绝不是农民工子弟。我在华年里干了这么多年，我太清楚农民工子女处的处境了。这么多年，我认识的农民工，孩子考上京沪 985 的，只有一个女孩子（上海交大）。她父亲是农民工出身，后来自己当老板，管了几十个人。这孩子完全是靠自己，其他是二本大专，小部分初中毕业就废了。

高考，说白了，就是运动员的训练方法。家里有钱，专业教练＋高自律性＋学校氛围好。现在的小学课程，三年级的题目，我都看的要发火。都是搞脑子的题目，好好一个题目，非要歪七扭八，搞得面目全非，去考孩子。我一个新招前的 top1 前队，更何况孩子？

+   1. 教练好，现在考 985，只有一个办法，大强度训练，刷题，刷题是有技巧的，要配备一个专业化教练，学生不懂的，立马有人解答。很多题目，如果不是补习课老师指点，一个小时也想要不出来。而每天留给每个课的复习时间只有 40 分钟。优质教练是要花钱的，一对一家教更加是花大钱。很多京沪中产家庭已经不着虑买三层房了，直接拿出一个人的工资做教育，每年大概 10-20 万。农民工家庭怎么可能比得过？

+   2. 自律性好。十二年一贯制的自律。农民工家庭，孩子读初中，父母正好是 35-45 岁左右，一般都是住企业集体宿舍，管不到孩子。孩子学爷爷奶带大的，不生病就算是大吉大利了，一个青春的叛逆孩子，自律性往往是不够的。一旦打游戏，谈恋爱，直接废掉了。只有中产凤凰家庭，有这个意识。孩子在身边，家庭学习须围强。

+   3. 学校氛围好，县一中，区重点以上中学。但是，要想进这些优质学校，农民工家庭绝大多数是不能够够的。主要中产家庭，例如父母是局里的副科，或者有点钱的小老板，买个学区房。农民工家庭大多数进入比较差的高中，大家一起混日子，老师对他们最大的希望是别在学校打摆受伤，其他随你了。考上二本就算优秀了。

+   4. 真正的公平是，本科阶段注册入学，合格就毕业，不要搞得比 369 等了。你是人才，考研阶段你去发挥。一般家庭的孩子就罢了，也不给你按博士学费了。

+   5. 底层青年的竞争对手，这不是富二代，而是中产二代。家族资产过亿的富二代在学习，工作，结婚，购房，无论任何方面，都不会和农二代发生竞争。你永远不会和臧圆宝有什么联系。真正的利刃见红，中产单位是勾心斗角的，实际上是中产二代和屌丝们的战斗。

大部分中产，希望通过学习碾压，直接降服屌丝，由他们牢牢占据中间地位，并随时往上逆袭。

+   6. 高考越来越需要金钱支撑和长架努力，实际上是制度性的加固了中产的地位，把农二代置于更困难的境地。当然，每年也有不少的农二代上 985。但总体上，985 里，城市中产家庭孩子的比例是越来越高，农二代越来越少。你不要用什么我们村考上了两个这种特例，985 招生办有数据的，他们心里清清楚楚。
