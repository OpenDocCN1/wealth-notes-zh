# 一，国企不会迅速进入新行业

新行业，意味着谁也不知道结果。如果投入小，国企是看不上的。如果投入大，国企也不想投。因为如果亏多了，那就是国有资产流失。没有一个国企领导会在主业以外，去投资一个不知道结果的新行业，例如斗鱼，抖音之类的。

# 二，外资也不会直接进来

新行业出现后，外资也不会直接来做。外资自己做的，必然是成功项目。也就是每国有个成功案例，例如亚马逊。现在，资讯发达了，只要有某个新项目（不涉及硬件），中国和世界是同步的。我们本土作战，如探知底，外资也没办法抢先。风险投资是，但也看本地人做。

# 三，新行业就是覆益逆袭的机会

第一代的新门户网站，第二代的网社交，第三代的短视频，这些新行业会得到巨大的关注，很快就会产生首富。举例，当年投资者为什么看京京东商城？因为公司化的网络直销，当时没人搞，没有其他人竞争而已。谁来竞去，就京京东靠谱。创始人是 985，有千万资产说明是真心干事业的人，公司也送了半年快遍了，经验丰富。现在这个条件看上去有点可笑了，但是，当年真没人了，那就她吧。

# 四，我看好 5G 时代

我没见过 5G，但是报纸上说，速度极快，适合高码流现场直播，这是非常难得的，相当于每个人获得了一个电视台。你想想看啊，如果给你当电视台台长，你干的好吗？

5G 时代，彻底改变发目的一切。影视明星可以自己调个小作品了，你岂不是自认为怀才不遇吗？直接上网！大秀英发，可以网络直播了，吵出水平，也是高人。现场做作业，一对一家教。你干得好，就有广告找上门了。那就发了。实在不行，也可以带个摄像机去看老走地鸡，现场买摘橘子发给给。

# 年入百万家庭的焦虑

刚才，一名著各大厂花车的前程序员和我聊天，让我对这个厂有了更加直观的认识，也理解了很多人对加拿大很激动的经济原因。

小花和小钢都是下岗家庭的优秀儿女，研究生毕业就进了这个厂的某地分公司。在男性成堆的码农世界里，也不怎么样好考的富览回瞅妹小花，直接成了万众瞩目的部门之花。他们在厂子里恋急结婚，买房生子，一儿一女。两人合计大概 90 万收入。

双方四个老人的退休工资加起来 10 万出头。八个人，年入 100 万。这坐家庭在杭州或证买了几双房子，有房车。也就是说，如果维持这个状态，他们的生活水平在当地、属于打工里的王乔。他们的生活状态，和往校的高三生差不多，十几年如一曰。做大体一，没有长假。当然，周六加班是自我认可，大家都这样，钱多也少不问题了。

晚餐是食堂，伙食好。吃完饭，在单位里面溜弯，然后继续加班，正常情况是晚上十点下班。第二天继续干。工作压力很大。厂子里两个资深领导：末位淘汰，八年清零。这就把他们逼到了高三状态。钱多，是康健腰换的，他们的孩子交给父母带，自己带不起。

他们的生活非常封闭，一天到晚上班，没有长假，手机随时开机，孩子都管不上。他们对现在的收入非常满意，普遍认为加班是幸福，不加班就该走人了。他们最大的想法是，能够继续在厂里干，保持这种超高工资。家里的亲属们也是高度支持他们，钱多子房少。

他们最大的恐惧是，离开这个厂子了，他们可能就找不到合适工作了。

一是专业不对口。他们不是在杭州，本地区附近三百公里，没有对口企业，辞退就要转岗了。
