# 单位技术一把手，就是升不上去

蔡蔡，我在单位里，技术业务是第一名，工作态度也超好，逢年过节领导要我加班，我是二话不说的。大大小小的先进，拿到手软，可就是升不上去。问题出在哪儿了？

答：问题出在：你太优秀了。

你走了，技术工作谁干？要是来个二把刀，技术出了问题，领导可烦心了。我以前也是这种货色，干的越好，越升不上去。因为所有的小头头都喜欢我现在的。你走了，领导就要培养一个新 人，烦不烦啊？

有一次，其他部门要调我过去接班，我们的老总去跑到大领导那里，又吵又闹，坚决不放。又跑到隔壁部门，指桑骂槐，说是他们挖墙脚。因为我走了，他就烦心了。最后，我的优秀把我的前途给害了几年。

# 竞岗演说稿，怎么写？

一，平铺直叙

自我介绍，近几年工作成绩，我的特点，将来工作打算，感谢所有人。

二，绝不要煽情

很多年轻人没有经验，总想什么一鸣惊人，以情动人。你千万别干蠢事。

首先，我不会感动。职场没有朋友，你说什么，我也不信。你说的再好，也没用。换掉不是看谁吹的好，而是日常工作业绩和态度。

其次，以情动人，很难把握现场节奏。你在那里千回百转，假装修情，听的人一身鸡皮疙瘩，真是恶心人。

再者，重要场合煽情，说明你这人思想还不成熟，扣分。

三，竞岗只是形式

职务，是一个单位最大的事情。你是你练几句嘴皮子就可以搞定的，没用。一切都 在不言中。有些女女为了职务可以弃小家，有的男人为了提拔可以一个月加班不回家，呵呵。你他娘的吹几句就可以了？

功夫在诗外。既然看明白这个了，那就规平平常，中规中矩。别人找不出毛病就行了。反正都做好了，你走完整套路就成功。

《我说的很乱，不要过于联想，谢谢）1
