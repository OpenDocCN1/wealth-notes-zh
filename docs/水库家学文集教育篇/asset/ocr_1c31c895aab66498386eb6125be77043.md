# 如何考奥数高分？

我非常讨厌奥数这种无聊的东西。奥数是培养数学家思维的，对普通人毫无意义。因为奥数的出题逻辑是反过来的，题目故意隐藏了很多信息，需要你去找规律，倒推逻辑。正常人是难以承受的，所以你拿孩子考不上清北，怎么办呢？

其实很简单啊。你去把市场上所有的奥数题买回来，多刷几遍，你基本就会了。只不过，你这样做，孩子就要熬到凌晨一点睡觉了。

现在的教育部门，无所谓你家孩子身体。他们只关心你家孩子能不能给学校挣面子。就算高度近视，佝偻病，肥胖症，这是你的事情。

# 教育利益链

这个利益链含金额极大，最喜欢中小学搞怪题，高考分数咬。只要高考还是怪题拉差距，发散决定论，他们就有无穷无尽的补课费收入。

我的看法是，985确实需要天赋，考试录入为主。其他二本三本，都是职校中专翻转过来的国民教育系列，就不要搞怪题了。让孩子们做正行人不行吗？非要搞成90%的近视眼，你当校长的舒服屏了？

# 奥数有用吗？

如果考985，还是有用的。因为数学物理最后几道大题，基本是按照奥数的思维去出题的。这种题目是隐藏信息，扭曲信息，误导思维，你按照正常逻辑是做不出来的。你要倒过来想问题，或者从第三个第五个信息入手，重新排列题目的已知项，15分钟内答完。
