# 四、建议

彻底汉化文凭。保留 985 补研类大学，其他大学一律改为注册制，不限年龄，不限学制，毕业给了个普通话等教育证书就行了，也不要搞什么这个大学那个大学了，反正都差不多的。六分析师范和上海师范的教育质量，有多大区别啊？绝大多数青少年，应该把精力放在锻炼身体和实践技能方面，为国家建设储备大批的一般劳动者。

# 黄金证书，我的理解是

+   1. 实习期合格，正常工作，就可以拿到社会平均工资，没有失业问题。
2. 第三年后，本地平均工资两倍以上。多数人可能是三倍四倍。
3. 有较大的自我发展空间。例如一建可以开个中小建筑公司，消防工程师师可以开个公司，cpa 律师可以开所。当然，这个要求的是拉单子能力，和考试无关了。

# 高考就是考熟练度

考清华北大复旦交大，每年合计招生近一万人，录取率千分之一。天才的比率是百万分之一，所以基本还是靠“疯狂刷题＋运气”，选择题蒙的全对。数理化最后两个大题，五分钟就有灵感。

考 985，录取率 9-12%，刷题刷到精神恍惚，四肢发软，80%有神经衰弱。

考一本，录取率 25%，刷遍市场上主流的练习题，记忆力中上。

考二本，每天刷题到晚上十点半。每周可以玩一天。

考大专高职，平时像个学生样子即可。

# 校外补课

是普通家庭逆袭的唯一办法。

我能考上 985，小时候就是补英文课，只不过那时候不给钱，我妈给老师家炒菜洗锅剥毛豆，逢年过节打毛衣，相当于劳动互助。

如果一刀切禁止补课，富孩子肯定是转入悄悄补课。现在是一对二，补课费便宜，今后可能是一对二，一对一，补课费飞涨。最后的结果是，富孩子占便宜，穷孩子倒霉。我认为学校老师其实是喜欢孩子补课的，他们也有考核压力，校长不可能管住几百万的家庭不补课，除非高考制度改革。
