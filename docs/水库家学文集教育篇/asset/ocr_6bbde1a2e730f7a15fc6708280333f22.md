# 我到了四十岁，才理解秦始皇的巨大经济学学意义

秦始皇统一了文字，度盘衡，马车零配件标准化等，这个意义实在是太大了。这一下子就把中国搞成了统一大市场。

从沛县走到汉中，几千里地啊，相当于从巴黎穿过整个欧洲走到了克里米亚，居然是同一种文字，没有任何交流障碍，哈都好办。

做生意要有度盘衡，分量，尺寸。老蔡也给你整合好了。一斗米，从南到北，都是一样的。不服？欧洲的量度衡就乱套了。

车同轨。汽车零部件标准化。牛 B 啊！从北京拉货到广州，一路上更换马车的零配件啊，没问题，全国一个尺寸，就像是标准化汽油一样。

# 历史趣闻

左宗棠镇定西北，带了六万步兵过去。你知道对方多少人？一百万以上，而且是骑兵。怎么打的赢？胡雪岩给左宗棠采购了一批，加特林机枪和小口径步枪炮。遇到骑兵就扫射，遇到寨子就炮轰。没有神不定的。只不过，粮台后励跟不上，只能慢慢打。

曾国藩是翰林，优秀的诗人和文学家，居然摇身一变，三年后成为清王朝最伟大的战争领袖，10 万人打垮了洪秀全的几百万人。我小时候一直搞不懂原因。后来终于明白了。曾国藩的兵营，用的是发射发丝屏弹的前装线膛步枪，就是后来的三八大滋，太平天国用的主要是鸟铳，射击距离不同，不赢才怪啊！

曾国藩最著名打伏，而是他神神道道人的人生哲学。广为流传的一句话是：结硬表，打呆仗。意思是，做人要踏踏实实，不能投机取巧，最后就会成功。妈卖批的，这种梓是桐说八道了。

曾国藩是读书人，讲究急行。所以，这个书呆子搞兵强一个要求：不要兵痞子，只要农民。但是，农民胆子小，一开始不敢打仗，只会挖墙跑。曾国藩也没办法，好说歹说总算留下了。但一打仗就像了子逃跑，怎么劝也不听，搞的老锦林几次要自杀。

后来，曾国潘想出了绝招，不让你们爬墙头冲锋了，改成工程兵，全部给我去挖墙沟。农民一下子来劲了。湘军是部队编制，工资高，干的又是老行，挖墙沟，兴奋的行了。曾国潘最出名的一仗就是打安庆。

曾国潘部队配备的是有膛线的远距离步枪，于是把安庆围起来，挖了一圈壕沟，士兵就在壕沟里过日子了。城里面的人没粮食，一年后，太平军就完了。后来打南京也是这么玩的，围了几年，就了。

曾国藩，外号曾剃头，是怎么回事？

中国的文化传统是，不杀降。意思是，投降也杀，以后大家都死雄了。但是，曾国潘专挑最喜着砍杀，听上去很残忍，但这里面是有原因的。
