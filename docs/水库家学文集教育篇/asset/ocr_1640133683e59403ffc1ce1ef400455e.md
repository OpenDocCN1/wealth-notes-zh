# 逃离北上广，今后的日子怎么过？

三线城市（中下省会，江浙粤地级市，燕郊），房价 2 万左右，居民服务业特别发达，例如社区餐饮，兴趣班，家政班，各种培训。某友商的孩子，小学一年级去学游泳，找了个被淘汰下来的奥运选手当老师，一对一，每节课两百元（一个暑假四五千元）。

+   1，三线城市，绝大部分岗位工资不高，很少超过八千元的，普遍是五六千左右。如果你有一技之长，自己单干（提成），月入过万，完全可能，还可以带动全家就业，小姨子收银，老丈人保洁，丈母娘做饭。
2，三线城市的商业楼，二楼以上大量闲置，房租不高，房东也不苛刻，有利于自主创业，快速起步。
3，最好做的生意是居民消费类，孩子，美容，保健，培训。不要做商业客户类的，三角债坏人。你找一个让消费者心动的理由，项目起步是很快的。三线消费者都是急功近利型的，这个心态要把握好。上次说到，男人植发，一次两万多，三线城市很受欢迎，暴利中的暴利。

建议：1，逃离北上广，回老家省城买房，最好带项目回去，否则，就业很狠心。
2，一定要选择那种居民接受度高，自己又有竞争力的项目。奥运选手教娃娃，没有可比性。但你可以考虑各种各样的培训，小孩，高考，成年人面试，职业考试，创业投资咨询，只要你的出点大家公认的专业和能力，你会比在北上广过得开心。
3，一无是处是白领。如果你是肯吃苦有实干的人，到哪都是紧缺人才。
4，现在没有合适机会，也不用急。过段时间就会出现契机。不一定要新项目，你比别人更强，也是绝佳卖点。

# 你把板端到到我嘴边

才算有诚意。

不少人问，什么是新行业？我举几个例子。

熟人老王做了一次植发，2万多。虽然我不知道他去的那家店，有没有合法资格，但就他那个抠门的劲，“亲疑从来不买单还要打包”的贪色，居然在这件事情上花了两万，目瞪口呆。植发效果看上去还不错，人精神不少。

还有专门做企业广告视频的，十万一条，就是两个刚毕业的使用工。

还有所谓的徐晦医（忽悠），成本基本为零，前两年也赚到了很多钱。

商业，说白了，就两个事情：一是更更快更强更好用，例如苹果手机，机械工程。二是更漂亮更好吃，美容，餐饮，外贸设计。

想发财，你就多动脑筋，求求你了，别弄烦我了。

# 大学生下乡的第一个难题

中西部的很多基层单位，例如乡政府的建设科，信访办等，招聘了不少县城三届室里长大的二大大学生。基层工作，第一件事就是下乡进村，访贫问苦，煞俗情就。就这个最不惹眼的事情，很多大学生吓得够哧了。为什么？狗患猖獗。

农村养狗，现在少了，但还有不少，特别是村口一养狗，司空见惯的。大学生一个人进村，立即会被一大群猛狂的土狗围起来狂叫，咬不咬，不一定，但这个场面，男生害怕，女生直接就哭了。我问过好几个人，他们说，一般是到了村口打电话，有村干部接，才敢进去，否则一群野狗围着。
