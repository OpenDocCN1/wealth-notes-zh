# 讲个真实的故事哈

章蓉娅医生：发生在家全国知名的顶级医院。

这个医院病看得好，进医院的药也是选得最好的，要么是进口的，要么国产里面最好的或比较好的。

有个偏远地区的进修大夫来这个医院进修，发现某病用某药效果特好，他们医院有这个药，但是之前没有这方面的治疗经验，就把这个治疗方案带回当地·····结果·····成分一模一样的药物，剂量一样的治疗方案，却一点儿效果也没有！治不好！！

进修大夫不甘，打电话来询问，顶级医院的知名专家也找不到原因——诊断，没问题；药物，没问题；药物剂量、用药频率、疗程天数，都没问题·····但就是没效果。后来专家没办法，就在自己医院开了药，给进修大夫带回去，再让病人吃，真是神了，带回去的药就有效！

同样的药物成分，不同厂家而已！

充分说明：不仅仅成药有质量区别，很多药物也是有差别的！

所以，我家人的药，都是想办法买最好的寄回老家去，效果差得挺大。有一段时间，医院一直用的某药断货了，改用了另外一家厂家的，结果发现效果就不行···我让我家人开药，医生都让我别开，让我去另外一个医院买，说只有那家医院的药还是原来那个效果好的厂家···

这个故事说明了一个什么道理呢？

大家自己体会吧·····

# 台北的医疗体系是值得借鉴的

但也是卫生局不喜欢的。

台北的诊所，类似于社区医疗中心，就像上海的律师事务所，会计师事务所一样，全部是私人性质的，遍地开花。他们的盈利模式完全是靠口碑，三代人经营一个小诊所，过上中产阶级生活。所以他们对名誉非常看重，绝不会干砸招牌的事情。

普通老百姓一般性疾病，甚至是生孩子，就是到小诊所去看病，三代人都在那里看，非常信任。遇到重大疾病，社区医生会立刻把他送到医院去。

这个问题的核心是，这个诊所是医生自己的，他要对该长远发展负责。我们的社区医疗基本上是走马灯似的换人。这个社区医疗中心搞得好还是不好，医生并不关心，他关心的是什么时候调到三甲医院去评职称，社区医生主要还是为了完成一个指标，评副高以上职称是要到基层去干一段时间的，也就这个原因，他其实对诊所信誉的积累根本毫毛兴趣。

# 生四个女儿就享福了？

我身边生四个儿女没有，生三个女儿的有。
