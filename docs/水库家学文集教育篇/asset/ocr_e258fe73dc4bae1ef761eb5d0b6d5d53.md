真正懂事的保姆，大概得要初中文化。例如填写个快递单，家里买个什么小配件，小学就不行了，初中的勉强，高中文化是最好的，但我不到。

# # 世界变了

做人做事，要脚踏实地。

# # 读大学有用吗？还是有点用

大学的绝大数专业，不培养动手能力，只培养思考能力。所以，大学和就业技能关系不大。这导致了很多大学生毕业后，很难适应职场要求。大学的最大收获，应该是：

一是学专业有个初步的认识。虽然你也记不住细的内容，但是，大体上你是知道怎么回事的。例如 m2 是货币的一种计算范围，财政和金融有什么区别。具体的，你也记不住。

二是培养自学能力。大部分学生，上课不听老师讲课，到了要考试了，拿班长的笔记背一下。四年至少 40 个课程以上，你背了四年，就学会各种专业课的逻辑结构。以后学习新知识，知道哪里入手了。

三是谈了 n 个恋爱，过了几把瘾，虽然丑了点，总比没有好。
