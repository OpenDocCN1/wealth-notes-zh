去她所在部门串门聊聊天，暗中观察一下。她在一次闲聊中，当面说某部门领导是直男癌，我非常吃惊。

后来，我直接否决了对她的培养。我写的理由是：说话不谨慎，对上级不尊重，不适合独当一面，年纪轻轻就有不服从上级的苗头。她五年后白干了，自己还不知道。

这个决定，对她是不是公平，我不评判。但各位年轻人要吸取教训。做人做事，要谨慎，不要在无聊的琐事上，得罪人。

# 行政，文秘，助理，前台，内勤

怎么提高自己的职场段位？

答：天马行空，胡思乱想，是不现实的。你可以观察一下你们公司：

+   1，哪个业务是你能够做的？
2，为什么你现在做不了那个位置？

原因无非是：经验，技术，职称。

+   1，经验类岗位：人事经理，销售经理。
2，技术类岗位：会计师，工程师，业务部门经理

如果你不是理工科背景，从头开始学技术，也没有什么意义了。你主要方向是：销售，人事，会计。这三个职位，简单介绍一下。

+   1，销售经理。这个职位没有门槛，但工资奖金风险较大，很累，来人，需要抗压能力非常好。例如你辛辛苦苦跑了一个月，玻璃鸡蛋个煤炭一掉了。但你没有开单，干的最多苦，工资最低。但是干好了，你个总公司，可以当一半的家。

2，人事经理。分为两种类型，一种叫搞得定，企业车闹里，婆婆妈妈的事情非常多，经常发生吵架，纠纷，加薪，辞退，你要有车才能把他们搞定，不给老板添麻烦。一种是法律型，现在劳动法和各地劳动政策非常复杂，社保五全都是技术活，你要懂法懂政策。

3，会计出纳。这个岗位的负责人肯定是老板心腹，很多小私企的财务经理直接管钱，和老板都是有各种关系的。经理下面有出纳，会计，是一个技术工作，挺复杂，你争取在技术领域实现突破，考个会计师。

大部分公司人员变动是比较频繁的，如果你一门心思往这个方向努力，肯定是可以有机会的。

# 大单位里的农村娃，主要有四种

一是农村精英家庭的子女，主要是村长，村会计，乡里包工头，这群孩子的战斗力爆表。最大的表现是，翻上踩下。农村是靠实力说话的地方，能够成为方圆五里地的顶尖家庭，都是有一套非常实战的生存哲学。对上面，舔起来是感天动地。对待同类，往往是冷血无情，见死不败。这种人，要百倍当心，可以“利益联盟”，互相辅助。

二是老农民家里飞出了金凤凰。这种孩子出身，因为天赋极高，考上 985，他人情世故不懂，满脑子孝敬父母，非黑即白。这种人往往在单位里尖酸刻薄，心胸狭隘，好出风头，典型的穷秀才。他们坏人不大，但是容易乱说话，你多多攻击他。技术厉害能力强，不要得罪他。可以“技术联盟”，点到为止。

三是各方面一般的农村娃，往往是有个在系统里当大头头的亲属舅妈。他们往往不知不觉为了猴子，专门收集单位各种人的言论表现。你别看平平淡淡的，厉害的很。
