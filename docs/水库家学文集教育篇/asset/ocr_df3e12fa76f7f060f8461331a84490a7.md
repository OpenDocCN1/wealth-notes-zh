# 上海年轻人去哪了？

我周围的上海年轻人越来越少了，特别是市区口音的。现在我发现了-一个小秘密。

上海年轻人考的上区重点中学的，英语基础非常好，很多人就去留学了，毕业后在美洲或欧洲踏潮。类似于，二本凤凰男，在内环线做低薪文职。

因为上海房价暴涨，老破小等于澳洲一个不错的房子，很多人在那里过得也还可以。但是，这些人的工资不高，工作内容要么是针对中国市场的营销，要么就是简单劳动，例如统计数据，财务发工资，公司打水之类的。

归纳：上海家庭，二十年全情投入培养出来的中上水平孩子，很多去移民国家打杂了。上海年轻人走了，腾出来的位子，给我们老家风凤凰男提供了宽广的舞台。

# 土豪的生活什么样？

几百亿的死鬼，天天在网上，装模作样，高谈阔论，人生哲学，其实是掩盖真正的发财原因。这种人迟早是要走背字的，倒不是我说话，这是有深刻原因的。钱来的太简单了，运气太好了，各方势力就一起盯上你了。

有的想打秋风，有的想敲竹杠，有的要连锅端，有的要玩了你。最后的下场，基本是肯定的，因为你没有能力一直打败和预防所有的对手，最后就是一个死鬼下场。他们怎么过日子，我不熟悉，但肯定是要作天作地，作几年的，否则以后会后悔。

我最熟悉的是，几个亿十几个亿的小富人。例如汽配厂的小老板，上市公司的二股东，小房地产，半栋大楼的房东等等，我用一句话概括：

房子车子好一些，其他内容和你差不多，区别是心态。你攒了三年也不舍得花的项目，他就当是买个自行车。

一晚五千元的宾馆，你也住的起，但让你疼。

一条雪茄五百元，送上门，你自己消遣，你也吃得起，但让你疼。

老破小换个乌兹拉带，你也做得到，但让你疼。

长途飞机，头等舱两万，三个人大大方方，你也可以，但让你疼。

就这么点差别，没有其他了。其实，想通了，也没什么。茅台酒和红花郎，也差不多。
