# 正常情况，孩子答不出来

需要参加这种名校考试的幼童，一般是家庭条件很好的孩子。而这种家庭一般是有轿车的，不会孩子去挤小公交车。正常情况下，孩子是答不出来的。这就造成了考分低。至于学校想让谁来，面试给谁多加几分就行了。我觉得，这不是考试，而是某种无法言说的那个。

有人说，这是考察孩子对生活的观察力。我日你姥姥！你是985，我问你的观察力。你天天用的马桶，距离地面有多高？你家有几个碗？你家有几个插座？你家上个月电费是多少？正常人不可能什么都观察仔细的，更何况是一个儿童。这题，我第一眼看到也懵逼了。社会其需要培养这种刷怪题的小眼贼吗？

我建议，这种没有答案的面试打分，应该向全体家长转播视频，公开打情况。而不是学校自己决定。这是关系到孩子升学的大事，绝不能看老师心情打分！

我家孩子读了什么小学，已经无所谓了。反正也不会差到哪里。问题是，一般家庭，你们要开始刷题了。

# 为什么说英语很难赚钱？

如果你喜欢世界和平，那多看多看狄更斯小说，这没问题。但是，英语真的很难赚钱。

欧美一般职员的工资，大概是 3000-3500 欧元美元，相当于 3 万 RMB。这还是好公司了。你如果是做以英语为主，没什么其他专业技能的，很难超过这个水平，实际上是打六折。

如果你是做外贸的，基本不需要高深的英语，一般大学四级+100个专业词汇就足够了，实在不行，微信扫一扫就可以了。关键是去加工厂压价格。

如果你是在外企，英语技能不会带给你太多的利益，多个三五千就差不多了。主要是看你的中文技术，例如劳动 HR 的政策，cpa，理工科专业知识。你很少有机会需要说半个小时，面对面汇报，最多写个电子邮件就够了。

如果你在秀水街，英语三百句就是御姐大当了。

如果你是正式编制，除了外办的接待服务人员，其他人不需要讲一句英语。

如果你是医生，你以为老外和药代一样吗？

如果你是证券公司拉单子的，写年报的，关键看预测结果，而不是英语有多好。

英语最赚钱的领域，除了个别奇葩岗位，主要是考试刷题类。其他也就是平常工资。
