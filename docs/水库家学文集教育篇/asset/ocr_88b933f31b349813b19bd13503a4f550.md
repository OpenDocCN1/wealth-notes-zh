+   5，垃圾分类的重点，应该不是居民家里那一小点垃圾，而是餐馆等垃圾大户。我估计每个餐馆要增加一个人手了。

+   6，过度包装问题的两难困境。垃圾分类的源头是减少垃圾。但是减少垃圾，收废品大爷就不高兴了。居民垃圾主要是过度包装，礼盒，快递盒子，塑料泡沫，酒瓶，都是可以卖钱的。

+   7，垃圾分类的财政成本很高。

一是人员成本，上海可能有近万个小区，还有无数的商业街，每个小区，两个监控人员，一个收废品大爷，天天在垃圾站边上，人数巨大！这些都是要花钱的。
二是运输成本。垃圾分类，就要分运。原来一次拉完，现在分成四种垃圾，可能就要分几次拉。
那么，垃圾站的用工和车辆也会翻倍。
目前的制度设计，收废品大爷增加了收入。监督者酷暑寒冬的，是不是有补贴（我不知道）。居民每天增加了很多麻烦，我没意见。

社会上，也有很多素质不低的居民。如果没有强大的监控威慑，再投入巨大的执法成本，把垃圾偷窃扔到花坛里的情况可能会反弹。我的感觉是，富裕地区做的起来，穷地方就需要专项资金补贴了。
