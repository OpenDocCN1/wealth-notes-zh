# 标准化的二本学历基本等于废物

读书肯定有用。河北毕业就是人才。但是，一般读书的出路，越来越狭窄了。

一方面，寒窗苦读十几年的二本大专，越来越垃圾了。现在，每年产生 800 多万大学生，至少 700 万是二本大专。啥也不会干，一天到晚，叽叽歪歪。最后都成了月薪三五千的格子间打杂人员。也有废物利用，变废为宝的情况，例如站街的中介，但和二本学历无关。

另一方面，初中毕业都困难的王二狗，靠着苦干加巧干，例如贴瓷砖，收废品，通下水道，偷工减料，浑水摸鱼，越来越发达致富了。农村种大棚蔬菜的王大娘，写封信都困难，花 50 元换了件衣服，就变成金牌月嫂了，月薪一两万，还罩住别墅，吃绿色食品，动不动就说不想干了。夜总会里唱歌跳歌的小妹妹，间诺不识，五音不全，一晚上赚个一两千元，都是起步价。

为什么如此荒唐呢？供求关系失衡。

那些实在考不上高中或大学的人，没投无路，被塞到各行各业比较累的岗位。通过一两年的简单重复，在单项技能上完全秒杀了二本大专狗。而且，这些人读书不好，想法不多，在辛苦的岗位上能够长期坚持，越炼越熟，要小贵的技能都练出精了。"好哥哥，再点个果盘吧，帮妹妹做个业绩！" 与此同时，二本狗好难啊！想往上走，被 985 直接拖在地上摩擦。来，复个微积分，瞧你那小样！

想往下走，铁合金狗眼只能打游戏，腰酸背痛不能贴瓷砖。想当段子手，还有亲戚这些大账号在那里挡着，就是过不去。怎么办呢？

其实，二本狗也有春天。桃战清北是没有话落的，但是秒杀夜总会的 Vivian，张翠芳，工地上的李队长，王眼镜，还是有可能的。二本狗有个特点，基本的学术规范，还是有点印象的，就是没经验。

建议，二本大专的，不要怕吃苦，坚持在辛苦岗位上，踏踏实实干几年，取得实操经验，然后理论提高总结，三十岁后，成为管理十个八个人小头目，是完全可能的。
