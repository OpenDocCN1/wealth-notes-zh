# 大部分人的职业生涯

是怎么度过的？

大学毕来，找工作。家里有点路子的，找个好工作，没路子的，就混个民生。按部就班，从底层做起，绝大多数人，是没什么出彩的能力，完全是熬年龄。

有销制的，整个二十一年，能够搞个基层小头头，部门副职，到了四十五岁，没人欺负你了，你也到了，等退休吧。当个市局局长的可能性，微乎其微。

没销制的，两年跳槽一次，跳到四十五岁，人见人烦，没人要了。然后苦学旁劳作法，和老板勾心斗角，唉声叹气。

以前的老大学生，机会多，房价低，京沪还可以散出 1-2 套房于，现在几乎不可能了。你一年十几万到二三十几万，京沪买房，很难很难。年近五十，子女婚嫁，你也拿不出几十万，索性不管了。广场舞走起！

本来，我也这条路走到底了。机缘巧合，我离开了既定轨道，做点小生意，买点小房子。当中无数次濒临绝境，运气好，又爬起来了。现在回想起当年经历过的噩梦，真的难以想象，我居然活着走出来了。

结论：要想走出僵制轨道，你就要拼死一博。如果你只是重复社会上的普通路径，很难出人头地。但是，离开大单位，你在社会上是很孤独的，谁都可以欺负你。

# 小山村里的暴发户

我在某风景区的山上，有个假别墅（复式）。这个地方是山区，算很穷的区县了。只有夏季七八月份，是一年中最好的季节，凉爽，不需要开空调，空气能皮度非常好，一眼望去，群山环绕，心情美美哒。

我就在那里买个房子，夏天度个假。买了房子，就涉及到装修了。死了一翻发现，这里的装修很有意思。装修公司不和你谈话，两个样板房，8 万，12 万，二选一，拷贝不走样。家具自己买。

实际上，这个模式很受欢迎，因为是夏天度假房，主要考虑是安全耐用，个性化要求几乎没有。一模一样的装修，采用最节约，最保守，施工最简单，工人们很熟悉，闭着眼睛都给你做好了。拉单子最简单，不还价，就这个了。装修都是邻居们互相介绍，价格一样，也没有什么讨价还价。业主还不要求工期。因为这种度假房，业主只有七八月份才会来，你只要六月份之前做好就行了。所以，一年到头都是忙忙碌碌，还没人管，真是开心得不得了。

这个小区有 1000 户毛坯房，基本都是装修转的，包工头出的吃饭时间也没有，赚翻了。当然，我估计他也要给物业公司交点管理费，请消费，毕竟人生的起盘很宝贵。

这种发大财的生意，你在内环是想不出来的。所以，你不要直接问我，做什么就发财，你最好点点鼠标就行了。你这么想问题，没希望的。
