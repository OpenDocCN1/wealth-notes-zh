# 我是 985 研究生，男，不知不觉到 37 岁了

+   1，25 岁毕业，进入一个效益比较好的省城国企当总部，到市中心开车 25 分钟。
2，25-28 岁，我在工作之余，考出了本行业最难的黄金证书。
3，29 岁，成为部门里的业务骨干。
4，31 岁，提拔为企业科级。
5，32-34 岁，经历了一场婚变，是女方劈腿。
6，35 岁，提拔为部门副主任（就是以前省国企的副处长，现在不这么叫了）
7，现在是副主任（主持工作），没有处长或主任。

我是底层家庭，父母双下岗，一路走来，倍感艰辛，但我觉得已经到顶了。
1，个人职务到顶了。我不可能成为总部的副总，估计是本岗位熬十年，抚正后再熬十年，over 了。

+   2，个人资产到顶了，省城一套 105 平米（无贷），还有一个 86 平米（贷款 100 万），我的收入大概是 20 万多一点，现在管得严，不可能发财。
3，个人婚姻也到顶了。二婚，钱不多，这个年龄了，还能怎么办？
4，父母对我很失望。没孩子。

我从小到大，一直超级努力，超级勤奋，苦了半辈子，现在已经不知道怎么办了！虽然心里不甘心，但是现实很骨感。

# 学霸的大结局

我们小时候没有学霸这个词，一般叫做尖子生。不幸的是，我从初二开始就是尖子生了，一路狂飙到 top。我们那个年代，家长的影响为主要是住房和求职这块，家长的作用几乎不存在，因为那个年代，不要说是 985 了，就是大专，都统一分配到对应的机关事业国企。我也随大流，进了一个大单位。我以为我的人生会迎来美好。没想到，惨的一比。

没房子找不到老婆，压抑到憋屈。搞弯首村后，我开始一门心思奔事业。大单位就是人际关系。本职工作不难，对于我们这种学霸而言，看个一下就全会了，然后是重复劳动很多年。

人际关系，就是互相说坏话（好话）
你和我是竞争关系，我暗中使绊子，挑毛病，恶心你。
我和你不是竞争关系，就尽可能的吹捧你，希望你以后在我提拔的关键时刻，说我几句好话。

但是你说这个人好话，说那个人坏话，会引起一系列的化学反应。你说老张好话，老张的竞争对手就恨死你了。以此类推。大多数人都是一致的，5-8 年后，人际关系就异常复杂了。

熬了十多年，你终于熬成了中层副职，但是也把很多人得罪了。他们没熬上去，心里讨厌你，破罐子破摔，时时刻刻找麻烦，这个时候，也是四十岁左百了。

升为单位副总的可能性是很小的，学霸也不行。于是，学霸的一生，基本就到此为止了，接下来就是自我安慰，比上不足，比下有余。退休后，吹个飞机头，成为“广场舞老王子”。
