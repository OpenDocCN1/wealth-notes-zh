完成任务，又想抢功出风头，争取被领导看中提拔。这局面一下子就复杂了。因为别人也是这么想得好处的。

大家一起去完成一个大单子。业务功劳谁最大，往往没有明确的衡量标准。每个人都认为自己才是那个最关键的因素，但提拔受奖的名额就一个，好是不够分啊。这就把大家搞毛了。二桃杀三士。

+   1，这个事情若搞成了，你最出风头，那我宁愿放弃，也不能让你做成本。

+   2，你千方百计做成了，别人嫉妒的直跳脚，背后还诬陷你：有私心，贪了钱，厚着脸皮，巴结领导，对同事恶言恶语。反正你就是个十恶不赦的坏人。

+   3，中产背你，是互相竞争关系。很多平时就嫉妒你，任何场合都不会说你好话的。故意把你的历史成绩轻描淡写，故意说几个打酱油的人是大主力。

看到这里，估计你已经火大了。我操他妈的，老子辛辛苦苦工作，做了那么多业绩，居然最后还是坏人了？不行，坚决反击。你说我会巴结，我说你搞破脑。你说我功劳少，我说是你二学历素质差。

只要开战斗，这事情就完说定了。中产都不能搞定对方，你来我往，无休无止，可以搞二十年，直到你调走，我还要写一份举报信投到你的新单位。

这就是职场。如果你没有背景，解决的办法就是，低调，只做老二，不出头。你要记住：任何单位，第二名是最容易得到认可的。

# 单位用人的规律

四十岁之前，公司会低估等待你。因为成本低，干活多，态度好，表面上会给你画个大饼，实际上塞你个小饼干，你就心满意足了，自动加班搞代码了。

四十岁之后，公司就是敲打你，老油条了，人见人烦，还不识相一点？

# 职业上升空间

现在的年轻人，最喜欢这句话，励志鸡汤喝多了。年轻人追求发大财，做高职位，做大生意，我可以理解。我年轻时候也这样。我是 top1 本科，风雨无阻二十年了，我来说说这个事情。

# 一，职场初期是高速进步

工作的前十年，只要努力，你会经常性的进步，这句话的前面会有余款。其实这个很正常，因为初级资源多，够你们分的。例如，大多数年轻人在 35 岁之前，都会评个先进，升个副科，小经理，拿到中级职称，开始带徒弟，成为单位中坚力量，慢慢挤入部门中层离职，看不起老底成了。但这档期到了 39 岁左右，就分水岭了。

# 二，二十八定律是永恒的

一个单位两百人两千人，分三层：基层是科员，中层部门，公司副总，董事会成员。一般情况下，70%以上的年轻人有机会得到一个级别，例如小的助理长，副科长，小经理之类的，一件事情分为四五六个糖果，不断的发给你们，把你们哄到四十岁。这些小发展会让您精神愉快，斗志昂扬，天天加班写代码，编程序，都不累。

但是，部门正职就少了。等小糖果都吃完了。你也快四十岁了。新的年轻人也上来了。你就走下坡路了。一开始以为，这次不行，下次还有机会。再拖拖，五十岁了，期间得过一次大的奖项。你完了。
