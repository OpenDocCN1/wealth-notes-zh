# 单位里的小头头老是哄我

这也不能怪他们，他们也是从年轻时就被“鼓励”到老的。单位里的小头头，权力钱少破事多。他最大的权力是指挥你干活，你要是不服，找茬，他真的很难办。他既不能提拔你，也不能开除你。他还能有什么办法呢？

理论上，他可以去找上级领导，一起来教育你一顿。但是，他要是真去了，他先倒霉，"你这个人，好歹也是个副主任了，一点管理水平都没有，怎么连个员工都管不好。你是不想干了，还是不能干了？不行就腾岗位。后备人选多的。"

你要是这个小头头，听了这个话，你是不是也够怂心的？所以，你不能直接去找上级，必须把眼前的事情，自己摆平。至于，你想黑一把那个老油条，必须在开会不经意的时候说几句，让副总心里留个坏务印象。
