# 平时成绩好，高考却不行？

为什么平时成绩好的人，有时候高考不一定好？道理很简单。

平时考试题目，都是以前的套路，没有哪个学校老师会重新写一套崭新的题目，另外编一套考题，这玩意很费人。那些刷题勤奋的同学，平时一般性考试就比较好。

高考的题目，基本是重新写的，很难在参考书上找到基本类似的题目，特别是两分以上的题目，这就看这个学生，会不会灵活变通了。

# 学霸不学霸，就看一个标志

学霸最喜欢看教科书，就是学校发的那个课本。不是学霸，只是成绩好的同学，基本不看教科书，只看参考书。这里面是有讲究的。

大道至简。教科书是无欲则不死的学霸研究出来的经典。你要是看懂了，真是牛人。参考书是给那些看不懂教科书的勤奋孩子刷题的。

# 怎样考清华本科？

这真不是学习能力，而是高手之间赌运气。废话不说了，前面的小题，基本都做对，就赌最后一个大题，特别是语文和数学。

+   语文作文题，现在的高考作文，在一个平平淡淡，耳熟能详，但又说不出什么门道的点，写出一篇八百字的文章。十分恶心人。

+   数学大题。这种题目只有一个解题思路，没有多个。这个解题思路是非常冷门的几个切入点凑起来的，表面上还给你搞了几个迷惑的路径，一般人在短时间是想不到的。

这种题目要做好，凭的是运气。如果是给你十个小时，优秀学生基本都可以搞定。但是，高考的大题，一般只有 30 分钟，包括写字。如果你在五分钟内，没有找到解题的线索，基本就完了。

解题的线索不是靠猜的，而是要迅速画出一个思路图，然后，你自己估计一下，从甲到乙的论证和证明，有没有把握？这是平时练的结果。高考的大题，就是避免出现傻逼砸运气。

考到高分的学生，往往是运气好。因为他思维练习多，让他第一次画出的解题思路图就是对的。如果时间多，优秀学生大部分可以做出来，但高考就是时间不够。
