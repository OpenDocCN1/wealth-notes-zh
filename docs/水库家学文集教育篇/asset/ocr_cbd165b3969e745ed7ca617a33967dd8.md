三是局丝逆李鸿章团。主要是曾国藩的湘军体系和李鸿章的淮军集团。这些人属于自学成才，苦干出来的，没什么靠山。想通过做大事，立大功，升大官。在剿灭了太平天国后，别出心裁，积极要求开展洋务运动。

洋务运动表面看是各种好处，追求生产力，但到了内部，本质还是抓权。谁具体去做，谁就有实权。洋务运动是李鸿章等局丝集团搞出来的。淮军已经稳定了军事，要是洋务运动给他干了，又抓到了钱袋子和声望名气，其他两个集团就该玩完了。所以，洋务运动是不可能让他干出成绩的，否则，文官集团该彻底废了。

洋务运动本质就两个大事情。一是海底浇水师，二是地上建铁路。其他开办工业农业是依附于这两个大目标的。

+   1， 北洋水师，主要是花钱，大海没有产权证的，还不缺乏各路人马的核心利益，李鸿章抓成了一半，搭个架子了。其他集团还把手头心思放进这个一半去管洋务，还就忍痛吞了。

+   2， 建设铁路。这是搭了马蜂窝了。

一是土地在宗亲贝勒夸手里，不舍的啊。二是资金在文官手里，转移到李鸿章那里，也不舍得啊。于是，宗亲和文官抵制铁路。

修铁路是刘铭传提议的。其他人不敢提，还敢玩意罪人啊，刘铭传是土匪出身，痴迷科技发展，250一个，打怪可以，做官没路子。他提出来后，慈禧也心动了。当时中国最大的问题是，边境线太长，防守俄国困难。海岸线太长，防守八国联军太难。总不能再招聘几千万湘勇守边界啊。有了铁路，运兵快方便了。

国防第一，其他人很难反对。但是，局丝们不愿意把权力交给李鸿章，想出了一个逻辑，害死了大清。比国防更大的是什么？慈禧的地位。逻辑新城说，如果修了铁路，太平天国一天就杀到北京了，慈禧跑也跑不掉啦。这个逻辑一出，再也没人支持修铁路了。大清铁路，这就算了完了。

以此类推，内斗毁掉了大清根基。这不是人蠢，而是利益。

# 杜月笙的悲剧人生，是天注定

1927年，杜月笙杀害了我们的汪寿华，拉开了蒋介石四一二反革命的序幕。解放后，黄金荣被扫大街。

1948年，杜月笙为了儿子利益，破坏了小蒋的经济打老虎计划，金圆券崩溃，小蒋颜面尽失。两头都得罪光了，杜月笙只能去香港躲起来，人生地不熟，被当地流氓地痞欺负，郁郁寡欢，很快死掉了。

杜月笙的辉煌期，实际上是1925年缎缎片起，到1937年上海沦陷。短短十二年而已。抗口期间，杜月笙在重庆小于小子，利用亲沪头帮的的优势，给戴笠帮带帮忙。战争期间，杜月笙没有部队，闲人一个。

1945年抗日胜利后，国府全面接管上海，青红帮头目已经被查变了，臭不可闻。杜月笙为什么在抗日前风水水起？原因是租界。

当时，上海是金融的一切中心，最好的地段是卢湾区附近，法租界。国共，青红帮，洋行势力，混在一起，乱成一团麻。

表面上，法国是统治者，实际上法国人不懂中国，管不了过细的。

乱底下，政管有实力管理，可以插手各种事务，但不能明确着来抓事者。

这就需要一个桥梁，表面上为法国人管理治安，乱底下为戴笠解决麻烦。这个人必须是两派都好，也就是工部局的华董（相当于内环税副市长）。

起初，黄金荣是华董，但是，黄金荣缺点太明显了。他不喜欢交际，摆老资格，比戴笠大30岁，资格差距大，戴笠对他也不感兴趣，黄金荣在抗战前得罪了浙江军阀，被小军阀绑架一次，跪地求饶，颜面尽失，加上年龄太老了，又贪财，江湖地位快速下降。
