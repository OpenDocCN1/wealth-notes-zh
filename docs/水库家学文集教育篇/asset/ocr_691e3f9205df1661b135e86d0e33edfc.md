# 生活中买一万一斤茶叶的人

“原丝无法理解，茶叶也不能炫耀，为什么要买这么贵的？我告诉你们吧。我有一次，我和两个老板在金鸡湖大房子里喝茶吹水，他们就拿一万元的茶叶，看上去，那个茶叶的做工很好，喝起来没有香精味道（大家都懂啦）。中午吃饭，拈出来一箱普洱茶台，就是六七百一斤的那种，随便喝。这里面有个逻辑，这就是我的待客之道，表示对客人的尊重。一杯茶用不了两茶叶，也就是几克，几百元一杯茶，但是客人感到非常有面子，交情就加深了。我比较老土，直接拿虫草泡茶，两个一克，也就两百元，不值大钱，谁都喝得起。但是，别人印象深刻，以后愿意愈来愈。”

吃饭买点所谓的土鸡土鸭，有机蔬菜，桑拿一下，也不贵。还有人装拐我。
