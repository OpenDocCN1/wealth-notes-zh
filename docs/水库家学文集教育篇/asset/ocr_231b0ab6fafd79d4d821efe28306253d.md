# # 私立儿科与公立儿科挂号价格差距

股社区：昨晚半夜儿子高烧 39.5 不退，实在没办法只能去挂号，到了儿研所已经是半夜三点，人山人海，到处是幼儿号诊和家长焦急的表情。去拿号，给了我 95 号，我看了排位表是 389，问护士是不是给错号了，护士说过了 500 重新记号，所以我实际是 595。

护士说可以排队先给医生开一些雾化缓解症状，我就顺着她指地到一个房间排队，进去后女医生一脸不耐烦的表情，责怪我插队。我懵逼，说是护士让我插队。医生说不是还有四个房间么，干嘛就偏要我这里。

我先话，我去了另外四个房间别人不照样替我嘛。

总之态度非常不好，蹶起鼻子似的数落我，说真的，我都忘记上一次有人用这种态度和我说话是什么时候的事了哥们。

出来后和媳妇抱怨了几句，媳妇说没办法，儿科医生大量流失，现在这个季节患者多，医生工作压力大，过育值班坐诊，服务态度就到要求太高了。

我点点头说私立医院贵有贵的道理，环境好，可以预约，排队的时候孩子可以在游乐区看动画片，医生态度也好，只是我们办了卡的那一家没有夜诊。

媳妇说还有另一家可以夜诊，但是挂号费 3700，我当时还为自己听错了，确认夜间急诊是3700, 单单挂号费啊，药费另算。然后我问那几研所这里诊费多少，答 70。

差了 50 多倍。

最后等我儿子看完病是 5 个小时候了，挂娃针回家是上午 10 点半。但我主要想说的是大家对公立医院的医生好一点吧。

菜菜，儿科开药少，粗扣少，心情不好，可以理解。骨科肿瘤科的态度好多了，一个疗程五万十万，来啊，来啊！
