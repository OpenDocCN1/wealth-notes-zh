# 家长的出发点是很明确的

很多家长说，我节衣缩食，精打细算，骑着助动车，开着比亚迪，风里来雨里去，送孩子练了十年钢琴，是为了陶冶情操。哈哈，我琢磨也不相信啊！其实，家长的出发点是有很明确的，

一是幻想孩子走专业道路，考入专业院校，但你找错老师了，业余老师就是卖时间赚钱快，自己也考不到上音副教授，哪里能够帮你孩子啊？

二是给个好人家的，这更祸根了，豪门媳妇和唱歌跳舞有半毛钱关系吗？最多是以后班主任让家长出个节目，你家孩子去班级联欢会露个小白脸。

三是全方位发展，到处撒一把，管他有用没用！这个思维是富裕家庭的玩法，你是中产家庭，应该是脚踏实地，专业化，做成最优秀。

结论：

+   1. 学才艺，根本目的是经济利益。途径是要拜名师，不惜代价。绝不是什么花点小钱的事情，是花大钱，半套房子是起步价，不要说一套自家款买的理由。

+   2. 孩子的时间非常宝贵，除了休息和玩耍，留给家长的每一分钟，都是金子般一样珍贵，千万不要耽误了。

+   3. 孩子们最好往专业级别发展，不要到处捡一把，打散弹，累个半死，还没收益。

# 大部分家长并不知道如何培养孩子的特长

家长认为，报个便宜的才艺兴趣班，弹儿首业余钢琴，跳两段业余舞蹈，就对付得去孩子了。其实，那是花钱打孩子，才艺是非常难训练的技术，成材率极低，解放前，拜师学艺，子女等都是学徒师，端茶水干家务，可能学到八九成的基本功。

目前，业余培训班老师，百分百是业余的，根本不具备教好孩子的能力，你孩子投入十年八年，勤学苦练，也不但是业余玩票，手弱，站姿，节奏，发音，胸气，气息，全都是错的高调，只不过家长看的热热闹闹而已，以前乐器考级，换来考试加分，你还有点回报，现在纯粹是败孩子。

才艺术承，最后成功的，基本都是家学，童子功，父母本身就是专业的，或者知道谁是专业的，拜师学艺，才可能练出来，你在小门口区，花个两千元，玩三个月，只是接着艺术的名头，给你带孩子两个小时而已。

小区门口极少有教书法的兴趣班，为什么？因为家长能够辨别，钢笔字写的好看不好看，培训班就不好端了。但是 99.99% 的家长看不懂钢琴和芭蕾，跳起来简单，快捷。跳来之后，再给孩子们发奖状，皆大欢喜。

结论，不要轻易学什么才艺，如果要学，一定要拜名师，低价培训班是毁孩子，学了很多年错的东西，还耽误了学习成绩。
