# （律师发不了财系列）

二手房买卖，不要中介，找律师把关行吗？

答：我们曾经遇到过这个事情，结果大跌眼镜。

中介费3%，房价六百万，中介费是18万。双方是自己认识的，谈的差不多了，去找律师把关，律师收费是3万，审核双方资料和签合同，价格还可以。

实际情况，买卖双方都没问题，问题出在了律师。收费低的律师，脑子转不过弯来。他把风险放在第一位，把商业成交放在第二位，给买卖双方讲了很多风险，甲方乙方听的脑都绿了。双方耽误了二十多天，给律师补资料。

你说不对吧，律师讲的也对。但是，律师的思维是把万分之一的可能性也要堵往，这就增加了时间成本。楼市价格变换很快，如果全部按照律师的搞法，房东耽误不起时间啊。他也要去买房。

后来，我们总结了经验，如果不经过培训，一般律师直接上去，可能把生意搞黄了。中介的打法，比较江湖气。他是先看客户再看资料，对你有疑问了，才反复审核。如果是正规家庭，律师事业嘛，往往是作为低风险处理，以快快快为目标。

这两种办法，各有利弊。

# 为什么我如此之穷？

很多年轻人大学毕业后，突然发现自己很穷很穷。工资五到七千（参考统计局数据），去掉生活费用后，吃喝好的都存拜，买个口红也心疼。是的，这种日子，我也过了很久。十万月居丝总抬头，也是穷坑里爬出来的，虽然偏霸门的姿势有点难看。

市场经济真的不缺钱。你站在内钱院墅，每一块砖头都是黄金，可我也没有。本科毕业季，穿上了平时舍不得摸的化纤西装，打背68的领带，拽着精心打印的简历，最后在职眠人潮中，被挤得东倒西歪，眼红止不住的说。

好不容易进入了一个半死不活的公司或单位，拿着微薄的工资，忍气声声，被人呼来唤去，一年到头看不到存款，什么都要节约。该个女票都没钱，更不要说买房了，且你进入这个大福环，你完了，你走进了一个看不到钱的地方。

与此同时，你再到装修工地上去看看，那么多人，赚的盆满锅满，大字不识几个，一张嘴就是翻倍报价。你再看看中介，在马路上发表小广告，介绍一套房子，直接拿走3%的总价。你再看香三甲医院，那么多药代在等你赏饭。某场杀生鱼卖鸟的，一天的营业额就是四万，直接翻倍利润。人和人的差距就是这么大。
