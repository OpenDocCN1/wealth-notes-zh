# （老板角度）

京东的打法，在商业上是合理的。

互联网生意到底有多少大的量，以前谁也不知道。前些年不缺钱，强调一个快，顾不上精打细算了，尽可能多招聘一部分人，抢占每一个市场份额，做出口碑，同时也没掉落在对手。

走到今天，大家终于明白，市场份额已经挖掘到底了。总量到了天花板，接下来就是提高利润了。这时候，精打细算是必然的。

总结：在总量未知的时候，尽可能快，在总量封顶的时候，不能指望通过扩大规模，摊薄成本了，这时候就要算小账了。

# 需要英语水平的工作

工资都不高，肯定不如杀鸡杀鱼的。

策展以前就是翻译，一天商务口译，参观走访类，不是法律谈判，劳务费八百元。这个算是奖励的单子，因为管一顿饭。如果你笔译做得少，这种单子还抢不到。笔译，主要是各种乱七八糟的机器说明书，会展说明书，干一天也就是五百百元。问题是，活不多，抢单子激烈。

中国几亿人学英语，从小到大，花费了无数金钱和时间。二十年后，你肯定看不懂酱品化妆品类英语说明书，还不但免费微信扫一扫，你的口语听力还不如淘宝宝上几百元的翻译笔。

不信？我就请你翻译一句，“我想买一件内裤在中？”大部分人直接蒙圈了。

如果不去国外长期生活工作，就是旅游一下，英语800句真的够了。我周围这么多人，没有一个人人仅仅因为英语好，收入超过卖肾的，开面膜的。

有钱人家的孩子，可以学一学英语，做点干净的办公室工作，反正也不指望赚什么钱。如果你真想赚钱，我建议你学习劳动技能，真正可以为居民群众创造实际价值的东西，哪怕是送快递，换灯泡，你不要太小看换灯泡，现在的灯泡很复杂，你可能连灯泡都拆不下来。

为什么很多人敢吹英语？因为他们是教英语考试的。

# 高级口译翻译的市场

一是大块头。一天忙十个小时，800块钱。大家都傻哈。主要是不高的走访参观，商务拜访，不涉及精专专业的初级谈判。这种单子是来走老走的体力活，累半死，除去打车钱，也就那么点事。更可恶的是，这种单子竞争很激烈，属于占糖果系列。翻译社给你，你还不要钱。一个月抢不到几个。

二是长包，一天近万元，这种是非常严谨的学术类，法律类翻译。例如某大教授来讲心血管内科，欧洲中世纪的文学，这个市场，基本被垄断了。因为这种单子的发包人，各行各业就那么几个单位，都有长期合作的翻译，一般人基本打不进这个市场，发包人也没有能力判断你的性价比是不是更高？出资方也不敢随便换人，生怕搞砸了。
