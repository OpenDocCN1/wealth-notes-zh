# 经常看到有些 250

用曲线或模型来计算预测房价。
这是很愚蠢至极的。没有一个曲线坐标可以计算出十年十倍的趋势。房价不是简单的推测，而是其他经济社会因素的综合反应。
迅速扔掉那些傻乎乎的专家曲线，到群众中去研究经济学。哪一天小龙虾价格下跌了，装修队态度好了，丈母娘不要房子了，娶老婆很容易了，房价就会爹了。

# 骗子喜欢谁？好吃懒做的

这么多年，我见过很多经济骗局的受害人，有些是我的亲戚，表面上有富人穷穷人，无一例外都有一个狂野的心。我见过一个老太婆(我三姨)，一辈子穷的叮当响，买个菜还必须顺两个大蒜头，否则一天不舒服，小贩最不喜欢她。
她最大的心结是，最怕被人看不起。前两年她遇到一个发财机会，签个字，一个月利息好几万，最后儿子婚房首付没了，在家里整死星活的，哭的撕心裂肺，惨不忍睹。
人要走正道，不要指望天上掉馅饼，特别是穷人，送上门的发财好事，想都不用想，都是骗子。人家为什么找你？因为富人不好骗了。
这么多年，我没有被骗过。因为我有个性律，不借钱出去，有点余钱就折腾房子，小换大，旧换新，啥也不操心。

# 年轻人越来越像了

我们这一代的城市人还不知道去菜市场买菜做饭，卫生又便宜，80 后的菜嫂，直接叫外卖了，说啥也不会去买菜，都是网上下单，如果没钱了，就找家长要钱，如果遇到屌丝家长，就剩下在网上喷了。
现在谈恋爱中的农民工子弟也这样了，一天到晚视频，刷点小眼镜，啥也不会了，一张嘴就是大词汇，你和他没法沟通，这些人中的绝大多数可能会过得不好，父母没有能力给他们在大城市定居，自己内心已经狂野了。我不知道他们今后还有什么办法成为亿富？
我们那一代 985，遇到了 m2 持续二十年的大爆发，啥都顺！
