上海的中产人群中，本地人很多。也有很多是考试出来的安徽人，江浙豫鲁也有。他们对考试有非常成熟的打法，超级重视教育，这是他们改变命运的唯一武器，肯定会用于子孙代代传。虽然外来中产现金收入高，但是没房子，大部分收入拿去买房了，结余不多，日子也紧巴巴的。

京沪也有很多比较穷的本地家庭。小夫妻也只是二本大专职普毕业，靠祖上积德，生在京沪，还留有房子和户口。但现金收入不多，夫妻俩年合计 20 万以下，日子真不好过。属于京沪有房子的穷人。他们本身学渣多，对孩子教育基本没什么经验，除了天才孩子，剩下就是请高手家教提高手救不了。

现在，最大的职场竞争就是，外地 985 对本地板砖客户的围猎。这一代人，基本可以打个平手。下一代的竞争，就更加激烈。你可以退出比赛，大家巴不得你退。如果不愿意退出，那就一起烧钱。

# 考试培训班真的有用吗？非常有用

孩子哪个题想不出来，看答案也看不懂，就必须老师解释一遍。我举个例子，打羽毛球。你自己练的再刻苦也没用，好的教练你带你三个月，就可以打遍机关无敌手。教练会把无数专家研究羽毛球几十年的经验，系统化的教给你了，你自己琢磨一辈子也想不出来的。

# 中小学教育不应该是烧钱比赛

中考高考还在唯分数！若不改年，疯狂的黄庄，还会继续疯狂！黄庄是北京海淀区的补课大本营。家长大把砸钱，辅导机构批量制造高中尖子生，挤压京沪孩子的 985 机会。把原本查天赋和勤奋的竞赛游戏，变成了“家长花钱拼教练员水平”的金钱游戏。

+   * 一，教育减负变成了教师福利

学校减负出发点是好的，但实际上变成了形式主义，教师少布置作业，少考试，淡化分数。部分低年级老师连作业都不开了。这不是给学生减负，而是变成教师福利了。但是，高考中考还是“分数论”，这就把家长逼上绝路了。现在是独生子女，在京沪大城市，考不上好的本科，大概率就是商场站柜台了。京沪市区基本没有什么是工厂了。

+   * 二，家长是被逼无奈

去黄庄补课，对于家长是非回痛击的，孩子学一遍，家长也要学一遍，否则跟孩子听不懂，就白花钱了。大人小孩，补课夹来回间路上的时间，外间吃饭的钱，补课费。精力同金钱的消耗战。长周期。但是，不去不行啊。这是十二年的长期竞争，你说家长撑不惨？很多家长，本来学收入不高，平时精打细算，节衣缩食，舍不得吃，舍不得穿，挖抠搜攒下几万元，全部被培训机构抽走了一，无比凄凉。

+   * 三，孩子也累的双眼发直

海淀区的补课班是对全市的，很多孩子住得远，也是不辞辛苦的来回跑，本来学校四就上课了天，下课又要加班十二年，大人都受不了啊，更何况身体没发育好的青少年啊？

+   * 四，培训江湖的海天盛蓝

我对培训老师没意见，这是劳动所得。我只是说一行下情。现在，培训班是名老师发财了，名师自己直接截发财了，收入高到一般人不可理解的种度，具体多少，我惜说出来你会精神崩溃。这些钱本来是广大家长和孩子们的，现在因为一个考试，全部完成了商业机构的收入了。
