# 土豪家的女婿，成才率低

父母赚有钱，姑娘找男人就会面临很多机会。如果没有十拿十美，文武全才的男人，最后只考虑了颜值或感情，而往往忽视了男性的能力，品德和意志力。与此同时，当男人成为了土豪女婿，衣食无忧，啥也不愁，往往也就失去了拼死一搏的勇气。

一是过于求稳。做事情，瞻前顾后，战战兢兢，生也出笑话，被丈母娘看不起。

二是一味放纵。有钱了，体面了，豪车开起，银行卡随便刷，boss 西装一穿，绝对不输漂亮女人往上娱。把握住不好，就弄下水了。

三是失去敬畏。很多土豪女婿，底子也不好，985，留学生，一表人才，但面对艰苦磨练，容易失去了耐心，就想着继承遗产。

四是失去生活目标。男人会这样想问题，“我再努力，也不可能赚几个亿，取得丈母娘的成就了”。我不如混混日子算了，等那两个老东西挂了，我自然就算出头了。

五是单位小领导的排斥。大多数单位小领导，对于土豪女婿是充满羡慕嫉妒恨的，他们认为，你这么有钱了，就不要和其他平民子弟争机会了，把提拔机会让给别人吧。如果老实人没有为他铺路，五年八年后，基本就是泯然众人矣了。

六是有人带坏你。社会上，有非常多的坏人，专门盯着这些富人家的儿子女婿，一旦你有什么贵潘奇的好爱好，你就算毁了。

结论：屌丝还是有机会逆袭的！

# 富人都是孤独的

人都有炫耀的欲望，但是，富人不能。父母，兄弟，亲戚，朋友，下属，友圈，小三，甚至爱人，都不能炫耀，一旦说漏嘴了，你不会得到幸福，只会招来嫉妒，借钱，怨恨。

某天，我一个人在西湖上坐船，就是那种人工手摇的船，150 元/小时，按时间算钱，我就在船上打电话。其实，我也不喜欢坐船，就是无聊。

小船回到码头后，我就往国宾馆的侧门那里抄近道回去。这时候，有个杭州本地姑娘看我像个游客，好心提醒我，那个地方不能去，有站岗的。我愣了一下，然后告诉她，我住在那里，没事。姑娘尴尬的一下，然后走了。那一瞬间，我内心突然非常郁闷。

人家好心提醒你，我却在那里假装犹豫，虽然我没那个意思，但人家觉得我有这个意思。我穿过警戒线，一个人坐在寂寞的西湖边，突然哭了。

人生为了什么?
