# 富人是傻子吗？

很多富人不太计较价格，富人是傻子吗？

富人可能是坏，但肯定是绝顶聪明的，二十年前，大家都是穷人，如果不聪明，他怎么富起来？很多富人，至少八成，在几千万的开支上，不多太计较，象征性的讨价还价，绝不会纠缠不止。这就是富人生意好做的原因。

富人傻于啊，为什么不讨价还价，再挤点肥皂呢？屌丝永远无法理解的。要告诉你，富人的精力和时间极为宝贵，举个类似的例子，京沪优秀的律师，cpa，股市大咖，一个小时的咨询费至少是三千元，一年几百万到手，但也太忙，每天精疲力尽，大多数人早已累的没能力出轨了。

他的时间超级宝贵，好不容易出来散散心，买个商品，吃个大餐，只要价格差不多，真没心思和你为了一两百元优惠费口水。屌丝的时间不值钱啊，为了进一俩两百元的外套裤子，可以去猫三天，到处举报投诉，无休无止。你吃的消吗？

结论：尽可能想办法做富人生意。富人不喜欢便宜，喜欢物有所值，值得信任。

# 我周围怎么看不到富二代？

如果是大房产的富二代，你一般是看不出来的。因为他们和我们看上去差不多。那些非常嚣张的富二代，大多数是老坟的小三生的。开个跑车，穿个潮鞋，一身怪里怪气的打扮。

我仔细看了几个身边的富二代姑娘，走在马路上，你会把她当做一般人，或者是中产家庭。那种珠光宝气一身韵整容妹，和富二代妹妹没什么太大关系，那是炒币子的。

富二代到底在哪里？房子肯定好。车子一般般。很多土豪非常注意影响，生怕招摇。现在社会，人心复杂，万一米个绑票仙人跳，谁也说不好了。个人物品高级一点，穿衣打扮也一般。要想穿的像个电影明星，必须是老天爷赏饭，有个名公众身材，大部分富二代也就是个普通人。
