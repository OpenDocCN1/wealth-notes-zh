# # 母校

我对母校没有什么情节。一来呢，我当年混的也不好，找个关系，还是系里的副科长。二来呢，现在有些校友太牛，动不动就是几亿捐款，搞得我们这些老屌丝实在是惭愧。我经常想，我要是有一半个亿了，会不会捐给母校？想来想去，真是舍不得。

母校，只是人生中的一个驿站，他教会我的，并不比老单位多。可从来没有给人给老单位捐款的。我想好了，如果我有钱了，我会把当年在同一个办公室的退休老同事叫出来，一起去天目山喝老酒。

我不知道他们会不会吃饱喝足后，在背后嘲笑我，“有点钱了，就开始显摆了”。估计会的。我大了解他们了。但是，我不介意。这才是真实的人生。

# # 买别墅的好处是

你不用宣传，每到新地方，三天后大家都知进了。我家孩子换个幼儿园或兴趣班，要写地址。我就写了个xx路6号（房产证上的准确地址）。一般情况下，班主任会打电话来问，6号几零几？我说，没有几零几，就是6号。是别墅吗？我说嗯。你家孩子就被归为优质客户了。社会就是这么直接。后来，我也学聪明了，改为6号101室。

# # 重点小学隔壁的房子

上学近，就是最好吗？

答：我曾经住在重点小学对面十五米处，这种房子真不爽。因为学校早上要开大喇叭做广播操，你这辈子不要睡觉觉了。每四十分钟就响铃几次，你自己看着办吧。每个学期，有1-2次大型活动，例如运动会，一天吵到晚。

# # 为什么要考资格证书？

举例，各行各业，包括cpa，实际工作中经常用到的知识，也就那几个，不考证书，也干的起来。但是，cpa的主要目的是收费，收费要有资格，否则叫无权收费。如果你没有证书，只能在人家手底下打工，别人出面收费，你只能算是个永远没有前途的无名助理。
