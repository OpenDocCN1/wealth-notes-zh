# 街道医院为什么没人去？不信任

现在回想一下，我小时候给我看病的医生亲戚，也不过是大专生，本科生，应该比不了现在的研究生。但我从小到大找他们看病，就是因为信任感。实际上，一般的发烧，咳嗽，呕吐，拉肚子，赤脚医生也可以。

我们不信任的原因是，他们显然是最末端的医院，但是是脾气暴躁不耐烦的臭面孔。一样受气了，我就找个大医院去受气。真有什么事情，还能犒赏！

为什么街道医院生意不好，态度也一律不好？因为收入死砸了。就这么多钱，一个患者多说五分钟，二十个病人就要多说两个小时，可还是那点钱，我懒得说。

# 99%的患者，根本不知道医生是谁

内地的实际是：只认医院，不认医生，99%的患者，根本不知道医生是谁。

这是计划经济条件下形成的模式，不看能力，只看单位和级别。

但这是不正常的。医疗是个渐进的过程，最好是一个医生跟诊到底，观察变化。现在做医生简单了，拿个化验单算公式，胃不下来，手机查百度，或内部网的资料库。

# 我小时候是怎么看病的？

我家有好几个医生，内科外科都有。我从小到大，基本不去医院，就是由家里医生看一下，然后吃点药。极个别情况，如果不见好转，再去医院拍片子之类的。这里面有个基本逻辑，信任感充分。

这个情况，和台湾很相似。台湾遍布各种小诊所，都是一家人几代人行医，做出牌子的。一个诊所，面对附近几条街，有几百个基本客户，一个医生负责这些人的日常保健。遇到大情况，立马转大医院。其实上，大多数情况也就小毛病。本地医生也不会瞎搞，因为口碑塌了，街坊生意就垮了。几代人的信誉，不容闪失。

但是我们的现行医疗体制，和解放初期差不多，主要是保证体制内的人低价免费看病，不允许私人医生竞争，导致私人医生彻底消失。随着医疗技术的发展，设备投入越来越大。高级医院服务高端人群，得到了最大的资源投入，所以资金投入，医疗技术和人才培养形成了良性循环，而街道医院变成了恶性循环。

我们是严格控制医疗价格，强制性医保，三甲医院和街道医院的花费差不多，大家自然就逃到去三甲。街道医院因为人才流失了，也只能听天由命。内地医院，患者是不能挑医生的，轮到哪个算哪个，这其实很荒唐。于是，大家最后一致选择去大医院。

大医院生意太好了，根本无所谓普通人的满意度，不满意你走起。而医生也不愿意离开大医院的金字招牌。因为，内地只认医院，基本不认医生。

最后形成了完美锁链。有关部门控制医院，医院控制医生，医生看病人地位，自动选择笑脸或冒火。医药代表负责让大家满意，除了患者。
