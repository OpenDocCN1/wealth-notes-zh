# 2000 年前出国留学的，过得咋样？

有没有 2000 年前出国留学，然后定居的？当年我和你们一样，但我选择了回去吃软饭。现在，你们过得咋样？

# 小语种，以后都没花头

使用人口低于一亿的文字，今后可能混不下去了。

翻译成本高，买单者太少，出版成本太高，阻碍了科技和交流。

北欧小国家，人口千万，有的只是几百万人口，母语已经是边缘化了，英语才是王道。那些国家的小孩子，英语好的和母语一样，就像是方言和普通话，自由切换。恃小语种，今后彻底没花头了。有的人想，我学小语种给他们当中文翻译，这简直是笑话，敢到中国来做生意的欧洲人，都是精英，英语好的- B (法国人除外)，一般不需要什么德语丹麦语的翻译。偶尔遇到几个，你也很难靠此为生。

# 啥也不会的大学生，不如学做卤鸡爪

有关部门垄断了学历，肆意注水，但市场根本不买账。

二本狗和他们在废品回收站打杂的父母，在经济地位方面，大差不差，二本狗的收入还不如收废品的，卖卤鸡爪的。

我家装修队的包工头，说儿子二本毕业，收入还不如工地拎灰桶的杂工。一个大学生，毕业啥都不会，还不如四年里好好学怎么卤鸡爪呢！

# 本科教育，都是烂泥

本科教育，如果不能取消统一文凭，就缩短为三年吧，反正都是烂泥的。

会计系毕业的不会做账，法律系毕业的不会排除证据，物理系毕业的不会修电视机。机械系毕业的，不会冲铣刨。医学系毕业的不会看病。化学系毕业的好一点，因为化学简单，容易上手，配个褪色灵还是可以的，也就是个高中兴趣班水平。

# 出国留学还是国内读普大？

杭州，现有一女初三，是花三百万上国际高中+国外读大学，或给她买个小房子养老？孩子成绩，就读国际高中 IB 课程，可申请全球前 50 位大学。如果读普高，大约也就是国内普通大学。孩子颜值自小明是众人眼中的美女，身高 1.72，个性比较温柔不好胜。除妹已备好杭州主城区优质二居。家庭收入起点落，悲观估计就是这三百万了。
