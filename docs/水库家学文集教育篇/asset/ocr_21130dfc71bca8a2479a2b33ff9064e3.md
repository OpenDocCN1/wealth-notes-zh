了三个儿子，每个孩子将来都是小门小户。有得必有失。我可以督促孩子考清华北大多985，也不是没有可能性，但是就要失去很多，例如童年快乐，锻炼时间，业余爱好。

我的思维是，捡重点。我的重点是：德智体美劳。智不是分数，而是各种实践知识。我不希望孩子把 20% 的比例扩大到 99%，失去了更加重要的事情，我们 985 毕业又怎么样？还不是另当一个？你拿 985 文凭能不花钱买房吗？

# 多于女家庭，没有什么好下场

这个事情，我们老上海见过了。以前都是 5-7 个孩子。孩子们长大后，就看钱。没钱人家，凑合过过，矛盾也没啥，但是质量差。有钱人家，那是鸡飞狗跳了。

+   一，平均分家

条件差的孩子不同意。老大老三都是研究生，工资高，老二老四的老婆家里有钱，我从小读书差，平均分，我就最穷了。

+   二，区别对待

其他人不同意。凭什么呢！

+   三，公开分

分完了，老人谁也不想要。

+   四，秘密遗嘱

大家巴不得你早点死。

所以，孩子多，没有什么好下场的。

# 富孩子不会天然比穷孩子蠢

大部分情况，富家孩子更加容易出彩。因为现在的教育环境越来越依赖缺钱。如果你给我 30 万一年，我可以全天候陪你和孩子，配合学校把各个学科抓上去。不说考清华，985 的可能性是极大的。12 年就是一套房子了。但我为了你一个学生，也耗去了 1/3 的职业生涯。我也没占什么便宜。优质教育是极其昂贵的奢侈品。一般人谈以为交了 300 元学费就是老师的事情了。那岂不是笑话？老师能怎么办？还不是放鸭子了。你学到多少，管老师什么事情？你富孩子考不上华师大，我一分钱工资不会少。

+   建议：1，家长要掌握教育方法，领悟教育思想，留出一笔钱。或者自己抓，争取把孩子培育成一个合格的劳动者。

+   2，给富孩子另外开通一个升学渠道，对接二本三本，不要和孩子比赛砸钱考清华。大家各得其所。

+   3，为孩子要利外，富孩子生下来就是 CEO，十八岁就会去巴黎名媛舞会，永远不会和你竞争的，你不要太敏感了。

# 为什么纨绔子弟越来越少了？

以前富人家，三个老婆，十个子女，老爷一天到晚忙着做生意，跑关系，管不到孩子。有些小老婆自己好吃懒做没文化，出几个纨绔子弟是很正常的。男孩子也不肯好好的，去矿上偷煤炭，去河里偷鱼，偷着大姑娘洗澡。咋样？

现在，都是独生子女了。二胎罕见。父母都有文化了，万元家财，旁规设权，一辈子心血，不就为了今日孩子接班吗，这个大学情我能马虎了？不可能的。我不重视考试，但我超级重视教育。考试和教育设置强关系，教育是德智体美劳，不仅仅是分数。
