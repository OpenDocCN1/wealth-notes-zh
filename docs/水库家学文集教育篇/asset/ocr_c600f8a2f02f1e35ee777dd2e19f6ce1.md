# 最稳定的员工是什么人？

我有个工厂，在工业园区，里面最稳定的员工是什么人？就是曾经当过老板，后来倒灶的那些小老弟。他们是宝贝，任劳任怨，还经常提出节约成本的小办法，例如水电气的合理化。

最不稳定的是管理人员，一天到晚要创业。去年有个中层哭天抹泪的要创业。我死皮赖脸的求他不要走。因为没人代替他。最后没走，折中一下，他老婆去创业了。今年上半年亏了他打工一辈子的储蓄，天天在家打老婆。他创业的初衷是觉得我赚钱了，功劳都是他的。与此同时他想留个企业给将来在家的儿子。

今年，这个中层立马老实了。看到我，满脸堆笑，生怕我不要他了。
