# 一无所有的我，想来上海

菜菜，我马上本科毕业了，男生，二本院校学校经济学专业，不值一提。我家安徽农村的，家里存款最多三十万。我什么技术也没有，长得也不算好看，也没背景关系。回老家县城和去京沪，对我来说是一样的，反正都是一无所有。我想来上海，第一年能睡够觉，有个床铺就行。锚点一下。

答：一，去热点郊区，例如周浦接头，徐泾佘山，罗店华高，奉贤金山，找个中介门店，自报家门。放心，肯住一屋子都是老乡，先安顿下来，中介店给你找个床位还是没问题的。

二，多干点活，混个脸熟。想办法找个离婚妇女，已约好，先打个谁，说不定有戏。

三，一年后熟悉情况了，慢慢赚钱。房产中介行业，大起大落，干得好比如医生村干部还发财。行情若不好，确实一比早年。但也无所谓，你不会失去什么。

四，混熟了，以后再找个老乡妹妹结婚，一起承包店面。

在上海，只要用心，就会赚钱。不要三两天就换单位。对你而言，不论去哪，都是屌丝，还不如老老实实干一行。
