# 我对小学生家长的建议：抓早抓好

小学生第一天上课，就要抓学习。回家 后，对照当天的课程表，逐一套盒。可能小孩子坐不住，哭哭闹闹，那只能殴打了。这也是没办法。自己舍不得打，将来被别人碾压。

如果家长学不下去，或者太忙了，必须找个全程家教。现在的大学生家教，都是为了赚零花钱，对教育本身没什么兴趣，只是讲解几道题目，一两个小时就灌完了；三百元给我。他们不可能给孩子们进行解题规律的系统性总结。因为这个太花时间了。

可以考虑，家长辞职一个，孩子学，家长也学。家长负责解题思路，家长负责归纳总结，为孩子们形成整体学科知识架构和拾遗补缺。这样做，孩子们才能成为聪明名。

孩子们如果一年跟不上，那可能就毁了，因为他可能失去了学习动力。所以，辞职一个家长，也是迫不得已。不要相信孩子会突然开窍之类的异想天开。现在不比以前了，我们那时候，家长都不管，自然生长。现在的985家长，简直是发病疯了。我认识一个理工科女博士，不上班了，就管孩子学习。

现在，京沪的很多985家长，思路已经很明确了。给孩子买婚房，那是不需要想了，但家长给孩子拼一个985学历出来，是可能的。儿子将来是喂丈母娘房子，还是去加拿大移民，你随意。

# 现在孩子们攀比财富的情况非常严重

我住的小区有几个小学生，经济条件好，但他们学校的大部分学生是住在老破旧。下课后，孩子们结伴同行，自然分群，各自回家。高档住宅小区，玩的地方大、设施多，富孩子和穷孩子一起滑车、捉蝴蝶、辨认树木，玩的不亦乐乎。老破旧小区、场地狭窄，没有绿化、车辆乱园，家长不敢让孩子在外面玩，回家玩手朮了。

我家对面有个简易棚小超市，老板娘孩子借读小学。孩子非常自卑，虽然是同行，但他不愿意和富人小区的孩子搭话，因为到了小区门口，富孩子就去花花了，穷孩子就去阴暗潮湿的简易棚了。

我和老板娘聊聊天，问了孩子的学习情况，属于后40%的状态。一个班35人，他大概是第20-25名。初二就要回乡下读学书了。等初三毕业，争取在上学个什么手艺，例如修车，做大概，实在不行，继续干小超市。

穷爸爸可能无法负担较高的补课费，孩子成绩差是普遍情况。少数自然开窍的优秀学生例外。现在，富人小区一般都会搞几个廉租房，本意是好的，但实际上，孩子们会不会更加伤心？这个需要进一步思考。

# 现在的小学生，两极分化严重

今天，我把小学1-2年级的数学课本看了一遍。

我的体会是，没有家教或者父母自学一遍，孩子的成绩会很差的。现在的数学题主要是逻辑思维题，例如找规律，猜猜谜，逻辑推思。这种题目，说白了一钱不值，但需要各种技巧，就像是猜谜语一样。仅自己研究，是打破脑袋也猜不出来的。
