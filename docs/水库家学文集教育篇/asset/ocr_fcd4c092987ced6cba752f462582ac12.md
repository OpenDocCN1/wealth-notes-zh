# 男人的主要作用

男人的主要作用是，给老婆和娃娃赚个面子。

我平时没什么事情的，但一开家长会，我就像是参加市府晚宴一样，西装革履，烫好了衬衫，吹好了头发，才出门。娃娃一看，哇，老爸真给面子。老师也觉得很我很重视。很多家长是下了班赶过来，邋里邋遢，一脸的汗，你说这行吗？

孩子和娃娃们私下郊游，我也去了，但没有参观景点，而是忙前忙后的安排各位家长的餐饮，点菜+买单，给家长赚点面子。午餐时，各位家长特别是中青年妇女，都夸我会办事。菜炒洋洋得意。

丈人丈母娘的老同学，带孩子来玩迪士尼，我敞前马后的，开车接送，买票买点心。老头老太乐了，回去后，逢人便夸丈母娘找了个热情大方的女婿。菜嫂也就满意了。

其实吧，我也就干了点这种小事情。
