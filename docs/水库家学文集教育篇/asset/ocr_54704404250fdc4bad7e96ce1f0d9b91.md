# 女同学迷上了微商

我是 35 岁妇女，有个高中三年的好友女同学，最近迷上微商。

女同学是省重点高中毕业，985 本科，毕业后进了好单位。但她从小内向，父母都是下岗工人，进了单位后不合群，被同事门排挤，被逐步换到了最差的部门，收入只有同事们的 1/3，没课题费，整天和老头老太混。

因为没有陪嫁，老公也是 211 屌丝。婚后生子，家里穷的什么都没有。她自认为，目前的困境是学历不高，于是申请停薪留职读研。因为没有收入，就被人拉去做微商。

她天天给我发神奇的减肥药，美白妆，我实在是没办法，就买了几百元，扔在家里了。没想到，这同学以为我是突破口，三两天头要来和我聊聊天，我都一直拒绝。很多高中同学已经拉黑她了，但我实在是忍心。

难道我也要拉黑她吗？除了我，她已经彻底没朋友了，很心痛。
