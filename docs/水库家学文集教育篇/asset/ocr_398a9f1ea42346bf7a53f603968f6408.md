是旧的父母衣服。你去看看，现在的 985，是绝北交旁，穷孩子已经不多了。大部分是城市中产家庭，十二年如一日稳定学习，衣食无忧，家教齐全。

大部分穷孩子，在成长的过程中，遇到各种父母婚姻变化，经济收人变化，很难一门心思读好书。即使自己要学，也会受到各种因素干扰。

举例，同样的智力水平，中产富裕家庭，有高水片教领，整理各种长资料，分门别类，有问必答，效率极高。原生家庭的孩子，都靠自己胡思乱想，天马行空，效率很低。当然，也不排除个别天赋极强的穷孩子，但这毕竟是少数。

降低考试难度，是育利于中低收入家庭孩子弥补差距，有利于中上家庭孩子增强身体素质。个别天才少年，可以在大学里组织一些全国数据化竞赛，前几名转学到清北复交。

# 读书不能改变命运

改变命运的是有用的知识。

在计划经济时代，大专文凭就是干部编制，干部编制和工人编制，就像是北京东城区户口和农村农村户口。这个巨大的鸿沟，般人是绝不可能跨越的。

现在，文凭和身份，已经没有什任何关系了。你是 985 毕业，不一定可以进大银行，我是二本文理学院毕业的，我可以进大银行管分行。不服？滚。

改变命运的是，有用的知识。喝样是博士，有人一年拿个一二十万工资，有人千万收入，被人称为抢钱。为什么啊？博士不重要，重要的是，有没有真正的知识。你也不要嫉妒，你写个论文看看，有没有上市公司千万年薪请你？

# 考试好，也不见得幸福

我有个女同学，精读 XX 专业的。这个女人是真见识过的，读书最聪明的漂亮女人，智商比我高高一截。在 top1 四年，她一口气搞了两个硕士学位，还跨专业领研，精通三国外语。我算是服气的。但又怎么样呢？到了单位里，由于性格强博，经常嘲笑人家，没朋友，没背景，混了二十年，一事无成。

唯一的成绩就是写了几本书。因为看不起领导，经常换单位，人到中年，事基上一笔吊落。婚姻不幸，没孩子，还被老公一脚踏了，最后倒是嫁了个老男人。因为长期压力，是有一点的焦虑症状态。最近听说当才女了，一天到晚写些乱七八糟的文章，惨的一比，比我倒插门还不如。

# 中小学教育基本是垄断的

学生家长在学校面前，基本没有话语权，这种发露的饭来，要是一般小餐馆，那个小餐馆老板早就在电视台工商局闹问了。但是，在中小学这种强势单位面前，家长们还是理性一点，尽可能找领导反应情况吧，否则，后果自负。

# 教育质量

我是考霸，这么多年，国内国升，公办私立，学历非考，各种考试都经历过。教育质量最好的，首推社会上的考证考研辅导班。这种辅导班，收费较高，自由竞争。老师们从来不收礼，不羞辱学生，全心全力的给你辅导，你去问题，基本都会讲清意。因为有竞争压力，如果口碑差，第二年就倒闭了。
