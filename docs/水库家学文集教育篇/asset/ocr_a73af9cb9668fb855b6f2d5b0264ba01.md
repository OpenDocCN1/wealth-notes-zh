# 刷题为什么可以考试高分？

基础教育三十多年了，各种考题基本已经被勤奋无比的市重点高中老师，全面开发出来了，再要出什么怪题新题，已经很困难了。即使再出来也无所谓，大家都不会，也就不存在竞争了。

一张考卷，绝大部分是以前的题型翻新版，只要刷刷题，看到考题，心里不慌，基本可以拿高分。区别是，你是不是粗心扣了两分。

高考数据化的最后两个大题是给清华学生的，你这个智商，不用看了。如果你只想考个人大武大之类的二流大学，刷是最好的办法。当然，近视眼的肯定的。
