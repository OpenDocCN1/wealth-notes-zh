# 某些小姑娘的自我感觉太好了

刚才，某妹纸私信我。剧情是，总公司派了分公司一把手过来，工作期间看上了妹纸，但也没说是。几年过去了，分公司一把手调回总部分，临走前一天，说喜欢这个妹纸，自己年薪 140 万，单身，这下子，妹纸睡不着了，千回百转，感慨惆怅，欲罢不能，又觉得男方大地十五岁，不接受。

+   答：这妹纸的情况我看了，除了年轻一点，其他没什么了。 
1，颜值一般，属于班级女生前 10 名的样子，不是大长腿。估计是湖北湖南一般姑娘的样子。 
2，家里经济条件，小地方，没什么钱。 
3，普通本科，职位一般。 
4，妹纸还说了细节。近两年，谈了两次男票，都失败了，可想面知了，她大概是个什么分致了。

其实，那位姑娘，你也不要纠结什么同意不同意的事情了。男的并没有和你结婚的意思，就是想用一下。估计他对很多人说了，只不过你回应了一下。因为你们结婚，会面临很多实际问题，这可不是所谓的年薪 140 万可以解决的。 
· 一是京沪住房改善。男方年薪 140 万，我估计不是很稳定的，国企的省公司一把手，拿不到这个数字。现在有一半就不错了。民企的，你当他是讲嘴炮火车。 
· 二是你的就业。你这个年龄，又没什么牛逼履历和强强战斗值，从小地方去京沪，你很难找到什么靠谱的岗位，大概率是小公司混混。等于男方要养你一辈子和你爸妈。 
· 三是男方没有真结婚的意思，我看了他的微信留吉，强调的是意思是两层：喜欢你，但是自己估计没希望了，后面那个意思，不是指你不要他，而是他各种困难，不想娶你。 
假如，男方真要和你结婚，你 99.99%会同意。但，并没有这个意思。
