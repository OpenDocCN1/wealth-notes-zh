# 为什么大学生逆袭越来越难？

我们那一波，机会太多了。各行各业都在加速改革，天南地北的经济发展在剧烈的变化，各种新机会计层出不穷。我班上的那个屌丝大专生，干了十几年，居然在三十岁左右，赶上了汽修业大爆发，现在上亿身价了（包括企业固定资产）

现在，键盘侠要打小老板的土豪，无休无止的吹捧各种更有钱的爸爸。富豪们建立宽大的护城河。制造业在艰难度日。医疗教育行业很难进去。国企总部招聘要求非常高，不是清北的，就别想了，类密资，鸡蛋饼，你又看不上。装修公司，的话，你嫌太累。好不容易搞了个无证补习班，还，被罚的关门了。

你是大学生，你先说。

# 男人为什么老想显摆？

某友和我差不多年纪，四十出头，二本科学历，内环线某半死不活公司的老板，开了个 80 万的车，一身名牌（不知道真假）。我知道他很穷，经常借钱，一两万元之类的都好意思开口。但是，他名声在外，貌似有钱人，他身边总是有各色各样的女人，对他很热情，从 22-42 岁，啥都有。

我出来装猴，一般穿个国产运动服，269 元。那是打七折的时候，我傻啊手头抢到一件。低调也是有代价的。现实中，从来没有哪个女人对我有一点点热情，好像我是他的驾驶员一样。可我是车主啊！

为什么会这样？我也想明白了。他在圈子里比我有名气。他愿意显摆，一直高调。很多女人以为他有钱，就会让他免费试吃两次，以便拉他个客户。他就靠吹牛，免费试吃了这么多年，还混的风生水起。我准备把他拉黑了！气人啊！

# 屌丝逆袭

我认识很多 55-65 岁的中型老板，反正几个亿的资产吧。他们个个都是屌丝逆袭，最高文化是中专，最低是小学。但发财之后，他们最喜欢娶个 985 研究生老婆，也算是互补了。

这些人出身非常卑微，100%是农村来的。我也奇怪了，怪是很少看到城里人。在他们身上，我看到了非常多的小老板性格：脸抠门，很狡猾，微热情，好打听，爱说谎，胆于大，能吃苦。
