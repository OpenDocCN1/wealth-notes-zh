# 留学。

以我实践经验看，不是top10大学的理工科学生，基本就是去旅游几年的意思，不要指望留学会带来任何经济收益。一般水平的孩子，拼捣几年，拿到博士学位，去地级市大学混个副教授是可以的，其他的，你想多了。

举例，会计，法律，金融等社科类的留学，基本就是去练练口语，增加一点见识，完全没有实战意义。你不可能留在当地国实操，回京沪也没啥实际作用，过了1~2年，也基本忘光了，就剩下一张旅游证书了。

富人家的孩子，反正也不靠学历吃饭，可以去玩玩，涨涨见识即可，玩三年回来，有没有文凭随他吧。穷人家的孩子，砸锅卖铁去旅游，完全是一场没有希望的豪赌。不要以为在国外可以拐囤拆迁楼，搭上富二代，不可能的。现在的孩子，比我们那年代精明多了，就算是一个学校的，第一个月你们就玩不到一起。

富人家的孩子到校后，照例是胡吃海喝去旅游，没有几万八千米美欧元，你选报团的机会都没有；第一个月，你们就分层了。接下来，富人和富人玩，互相请客。穷人和穷人玩，一起买便宜牛肉。你们最大的交易是，代写作业，考试作弊。

三年后回国，都是称父母。富二代有关系，直接高大上了，或者回家挨企业接班。穷人家的孩子，回到了房价钱了一倍的老破小，拿着差不多二本档次的工资，倚天长叹，今后怎么办啊！
