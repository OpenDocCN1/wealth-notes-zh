# 铲除医疗贿赂！


我们中小企业的职工，从牙缝里省出来的医保金，就这样轻轻松松被医生偷走了，我不服！我激动，我的眼眶充满愤怒的血丝。


华山医院的院长，你对得起患者吗？


你真的还有一点人味吗？


我很你，我要发出声音。全社会一定会形成共识，彻底铲除你们这些肮脏的医疗贿赂。

# 医生恶劣，比小偷还恶劣


我曾经在医院大厅看到，患者家属被小偷摸走了所有的钱，一家人哭的死去活来。我非常气愤。

现在，我不气愤了。


小偷是偷钱，医生也是偷钱，谁偷都是偷，只要进了医院的门，就是被偷。


患者没地方讲理。

医生还会让你回家借钱，负债累累，把钱拿来给他们偷。


医生恶劣，比小偷还恶劣。


# 说说心里话


现在，我应该不穷，也不太在乎医药费。上去去日本医院，也就两个小时。三甲医院估计吃不到我的回扣。这几天，我呼吁降低药价，铲除贿赂，更多是为了普通人。可我奇怪的是，多数人沉默不说，一群人对冷嘲热讽。我这几年被嘲笑上亿次了，完全接受。

过几年，很多中青年的父母，都要去三甲医院闯闯佬，花大钱了。你们真的喜欢送红包，吃回扣吗，过度医疗吗？我确实无法理解。某朋友家属重病，医疗费有多高，我是知道的。一年几十万是起步价，最新一代的进口药，一天就是几千元。药价是美国的几倍。高标准拖三年，最低也要1-200万以了。双方父母四个人，你准备百万零差不了多。

难道普通人的真的发大财了，好像也不傻啊？我同时时刻关注上海楼市，感觉大部分人没什么钱，几万元的中介费都要磨来磨去求打8折。买一套七八百万的房子还要贷款，家里也不富裕啊。是我脱离社会太久了，根本不知道8050后怎么思维了？

谁愿意和我说说，你准备多少现金给两个老人看病。我能承受100万美元的医疗费（卖掉一套房），或者再多一点。你呢？如果你们真的不在乎了，那我也罢了。但是，按照我的惯性思维，你们不至于这么富裕啊？好吧，我可是真。

# 以前一直说医生，今天来说说律师。


我一直对律师没什么好感，总觉得他们要赚我的钱。当然也不是很反感他们，毕竟也是手艺人，主要靠技术吃饭。


自己家里请律师打了一次和房子有关的官司，有点复杂的陈年往事，我发现，律师存在也是有原因的。我现在法院，对各种材料的要求非常苛刻，差一点都不行。我上次和律师一起在立案窗口排队，观察了两个小时，至少一半的人都被劝返，要求补材料，有一小部分人直接不给立案（原因不详），有人人大喊大叫也没用，有的人因为立案不成，在法院门外呜呜的哭。
