# 高考分数的

中小学校外补习班的最大根源是，高考分数制。大学从来没有设校外补习班。因为读大学容易毕业。真正减轻学生负担，必须摒弃唯分数论，改革高考录取制度。建议：除了985，其他大学改为注册制。校外辅导班一夜之间会基本消失。如果高考分数制不改变，每个家长压力巨大，课外补习很难减少，无非是大班变小灶而已。出不起大钱开小灶的家长，更加弱势。

# 高考公平吗？

表面看，一张考卷，大家公平。我是干军万马独木桥挤过来的top1，我不认为高考有多公平。我们那时候，没有家教，上完课，学校就不管了。我能考试成能很好，有几个重要原因：
一是舍得花钱。我把福州路新华书店和科技书店的高考参考书全部买回来了，当时是很大一笔钱，大概是一个农民家庭一年的收入。
二是请了家教。我们那时候不流行给钱。职工工资几百元，实际上给不起钱。但是，我家距离老师家最近，我妈给老师家里打毛衣，剥毛豆，油煎带鱼，老师抽出做饭的一个小时给我补外语。这个优势，大的超乎想象。
三是学校开小灶。我读高中的时候，学校为了保持升学率，把学生分为了三六九等。我是一等的，直接被安排进入了尖子班，一天到晚吃小灶。那时候没有复印件，老师就油印历年考卷给我
