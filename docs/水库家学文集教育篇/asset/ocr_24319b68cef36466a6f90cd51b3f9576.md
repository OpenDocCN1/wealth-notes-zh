# 初中辍学的农村孩子

经济收入上将全面超过京沪二本高职大学生。

美国的管道工收入，和哈佛大学本科教授差不多。澳洲的泥瓦匠日薪 300 澳元，是本地会计的三倍收入。京沪快递员，卖脆饼果子，收废纸的，修空调灶具的，收入已经和一般大学生已经持平了。手艺好的装修工，已经是五百强部门副经理的收入了。两口子贴瓷砖，月入五万是正常情况。

现在的大学生其实分为两种，一是聪明人，这批人无论什么时代都是优秀的。二是招扩招的普通人。后者本来是一般员工，读了个大学后，肩不能扛，手不能提，刮风下雨不出门，太阳底下一干活，没有空调不想活，但是自己并没有什幺强项技术。同等水平的大学生，每年如过江之鲫一股扑向就业市场，他们的日子越来越差了。

我家儿子不是 985 的料，今后怎么办？

一，笨孩子就不要折腾了。不是 985 的料子，家长也不要死逼孩子了。考个三本大专也可以接受。你指望他当教授吗？

二，学个技术，常市场吃饭。具体项目要看父母的社会关系。京沪主要是生活服务类。你是会计，孩子读个烂本科，以后也当会计。你是医生，孩子学个三本药学专业，以后做个药店经理。你是城建系统的，孩子学个工民建专业，以后也是行家。至少两个个体户经理不是问题。你是教育部门的，孩子读个师范，以后去辅导班绰绰有余。实在没啥路子，可以去当淘宝摄影师，简单培训三个月就出师了。

三，拼尽全力，给孩子准备个婚房。不要考虑什么会不会再跌一点之类的鸡贼心态。够的上就上。有个房子，即便少买了五平米，也可以生活。万一买不起了，才害人啊。

四，让一般孩子有个健康的身体。如果你家孩子是冲夺国际学术大类的料，你随意。一般家庭的孩子，不要去搞什么超高难度了。不带眼镜，练好腹肌，倒推门也是加分项目。
