# 穷人和富人的手腕不同

（以租个地下车库举例，你不要多想哈）

穷人去办个什么事，心里一直在算小钱，很多事情办的过程中，斤斤计较，双方都不舒服。富人不是这样的。如果富人意识到迟早就要找某人来办这个车库的，他在事情还没发生的时候就来，心急全部到位。现在没有任何事情，有事再联系。

对方一般有**两种反应**，一是好好好，你懂事的人，反正没什么事情找你，礼尚往来。二是不*要*。但他觉得你为人大方，给人面子，对你印象很好。真去办事了，他会很和谐的。因为你有信誉基础了。

# 穷人的最大本钱是时间

我二妈的教育女儿是这样的：你每次买菜，都要讨价还价，每天节约三块钱，一年就是一千元，一辈子就是好几万。

这种思维方式，是典型的穷人心态。因为她认为时间不值钱。和*小偷*小贩讨价还价，还是*要*浪费点水*的*。思想高度集中，问题对答如流，语言暗含逻辑，否则你很难赚到便宜几块钱。

你要是每天有*这个*时间力气*去耗*，能不能干个更有价值的事情？比如考个副多？多跑跑楼书，写写感情。或者做个大*V*，今后赚点广告费之类的？

结论：年轻人不要在无谓的小事情上，过多的浪费*时间精力*，特别是*写菜*这种毫无意义的事情。你要集中精力，像棋盘*的*干好几个大事情。其他就不管了。
