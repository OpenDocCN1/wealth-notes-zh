# ## 社保的成本研究

上海很多不規範的企业是按照平均工资 4279 元核算的，缴纳 1899 元社保，无论名义上是谁出，归根结底是企业出钱。现实中，上海大学生第一年大多是 5000-7000 元，三年后上涨就多了，近万元是比较多。

元日后，按照实际来追缴，社保成本应该是接近翻倍的。按照一个人增加 2 万元社保成本来算，超过 30 人的企业，你自求多福吧。据我了解，相当多的民企老板，一年的净利润到手，可能也不过是 50-60 万。第一年，可能还会挣扎一下瞪瞪蹑，第二年估计还不瞪蹑了。
