# # 大学生村官很流行

实际作用怎么样？形势大好，欢欣鼓舞。电视上都说了，我积极赞同。今天，我就说些个别的小事情（主流是好的，不要抬杠）

农村现在还剩下什么人？老弱病残孕幼，青壮年出去赚钱了。大学生村官的主要面对的，就是农村妇女，老太爷，好逸恶劳的二流子，有病不能干活的贫困户。这些人，你和他们谈高大上的事情，效果可想而知了。他们要是听得懂，也不会窝在村口晒太阳了。平时没事，大家统气气一下算了。如果有事，就热闹了。有个大学生问我。

农村的最大矛盾，争水源，争土地，争山林，争风水。怎么办？

农村的重大事情，带领村民发家致富。咱自己也是刚响二本毕业，还没工作过，怎么给大家赚钱？

农村最多的矛盾，大概是婆媳吵架，赡养老人。道理都懂，说白了就是，谁出钱。怎么管？

日常最大的矛盾，邻里纠纷，老王在院子里搭建了一个棚，影响隔壁老张的通风采光。一个是队长，一个坚决不拆，要打就打，谁怕谁。怎么手？长期幸福下去。

这些事情，哪是刚毕业的学生经营得着的？我们对这些事情，非常有经验，细节是不能说的。大就是意思，你给我村里一个面子，这次吃点亏，我下次悄悄补给你。若是给不面子，你掂量一下，现在的大学生，干两年就走的，怎么解决？

你是大学生，你先说。

# # 十年后，可能找不到装修工了

前两天，和一个装修队长聊天。他对现在的美好生活和良好治安，充满感激说。现在，装修队赚钱很多，又没有任何弥漫地指去敲诈他们了，幸福的不得了。于是，我又把话题引向深入。“你现在是队长，再提升一下，自己开公司，培养儿子接手”。长期幸福下去。

队长苦笑了一下，基本不可能。原因是，现在年轻人不愿意学装修了。有技术的装修大工，例如木工（吊顶），砖墙，批墙，水电，大致月入 1.5~2.5 万。夫妻两个搭配做呀，一般 3 方。文化程度是看得懂微信。

一个小区里，表面上有 5~8 家主力装修公司，但实际干活的人是一批。无论你说哪一家。所以，现在的装修时间，谁能越长，就是那几十个工人在支撑时间。现在的装修工人主要是 45~60 岁。少数 80 后，90 后基本为零。（专职干活的，不是办公室人员）

装修工，生活艰苦，吃住不行，灰大，脏。只有吃过苦的人，才能干得下去。读书出来的，就算毕业也不干。装修队长手下，还有几个二十出头的小伙子，斯斯文文，干干净净，原来是亲家的孩子，二本毕业，无所事事，来帮忙接待客户的，没人去学技术。

装修工的孩子，99.9999%放弃装修行业，从来没有听说过承父业去搬砖的。装修太差了，能够留下来的人，都是指望孩子从事体面工作。

有人说，如果经济不好了，就会有人才去干。我看不可能。我是经历过 98 大下岗的，从来没有听说上海人失业了去干装修工的。上海人就业的底限是，每天回家吃饭，否则不干。我在上海的人大多数是县城三层住宅习惯了的，给他盖个房，已经很委屈了，再工地吃灰，老子不干了。

有人说，欧美不也有装修工吗？确实有，主要是没有身份的民工，本地人读完二本，真没有自己干的。我们以后上那找这些人？印度还是孟加拉？
