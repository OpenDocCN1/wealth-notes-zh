# 中文系毕业做不了微博网红？

首先，中文系不是学习写作的，这一点大多数人可能不知道。中文系，绝大多数人是搞研究的，例如某个古籍，某个诗词，你写出一套不同的解释。所以，他们一簇适合做红薯 kol。

第二，网络传播和书面语不同。人们看微博，不是来学习的，而是来消遣娱乐的。你把上班的东西带来，250 才看呢！

第三，微博要的是言裁了当，爱惜分明。搞学问的人最不愿意表明态度，云山雾绕的，老子弄的烦了，直接删了你。

第四， 中文系一般都是书念得不好的才去考的。和我没法比。

# 要想做个区域性网红，

建议你们仔细研究一下我的文字。

写完之后，自己读一遍，要做到几个效果，

+   1，逻辑上一气呵成，中间不能断口气，让人不想看了。

+   2，用词要最简单。越简单，阅读速度越快，心里冲击力越大。如果写个繁体，很多人就可能卡在这里了，然后把先前铺垫好的意境破坏了。

+   3、贴近生活。你写的话题一定是读者想看的，而不是你自己吗，或者炫耀知识。你的知识网上都有，没什么稀奇的。你写的内容，要让读者身临其境，和你一起感受现场。

+   4，逻辑上直奔直去，文字上做铺垫，抖包袱。千万不要把逻辑搞乱了。
