# 富人群体在哪里？

私人银行俱乐部。

富人，如同黄沙里的金砂，要想把他们凑在一起，给他们开个会洗洗脑，那是非常难的。你根本不知道大街上哪些是富人。但有一个地方知道，银行。现在没人把现金放在床底下了，一般是存到银行。Excel 拉一下，全部出来了。

然后，银行客户经理开始有意识的接近他们。一般是先送点小甜头，办个黑卡，飞机贵宾室，单独安检，半购买服务，送点节日小礼物，生日送一捧花。溜熟了，邀请参加酒会。你要是愿意去，这就算入围了。

富人大致分两种。

一是不喜欢扎堆的，你说啥也不去。大佬平时非常忙，偶尔休息一下，看一个日本爱情片就算了。

二是也喜欢认识一些人的。这种人基本就是目标客户了。

私人银行忙苦天，可不是话雷锋。一般是两个目标，推荐存款数，销售各种私募之类的理财。富人都是千军万马杀出来的，见多识广，你要说服他们买理财，那可不简单。不过，也有套路。

+   1. 先放一批经济学家进去叫几场。不管你信不信，至少你会听一听。

+   2. 小规模的投资闲聊，主要谈宏观。目的是挑起你的想象力和贪欲。

+   3. 美女专导洗脚、男男女女的大老板，不一定相信这些 250，但也不会拒绝，看的开心，随你说什么。说着说着，就算认识了。

+   4. 日常关心，时不时联系一下微信。大佬总有咨询他们的时候。这就算是私人友谊了。

+   5. 重点宣传理财产品了，熟人介绍项目，一般成功率多：多多少钱，最后你都会买一些理财产品的。私募理财的销售业绩也就完成了。

+   6. 日常联络，酒会，雪茄，美食，偶尔会有一点安排，但也不多。真想玩，客户经理给你们定位子，自己去买单。

+   7. 个别欲望强烈的男老板，哈哈，你有本事，你自己去搞定，人给你弄到面前了，成不成，看自愿了。据说，有些金融女销售，是从影视艺术学院表演专业考进来的，非常优秀。

# 秀才的实际作用。

秀才乡里乡，文化传统的捍卫者，也是实际掌权群体的一份子。

秀才有一定的实际地位，见小官可以不跪，还可以举荐县太爷，还可以制造舆论恶心一下县太爷。所以，县太爷一般不会主动去惹秀才，时不时遇到时，还会礼貌几回。

秀才的生计，一是教书。二是当律师（讼棍）。三是在县具有没有编制的看钱点头（例如教育，征收，运输，房贷，文案）。四是师爷（财政，司法）。按照朝廷规定，每年还有少量的现钱补贴。
