# 小领导是最可怕的

绝大多数二本子工作能力是强的，但是混好的不多，大多数死在小领导手里，不死活路。现在的小领导，最怕你出风头。一旦你冒出来了，你就倒霉了。因为他年轻到了，又有你这个可替代人选，你上去，副科长主持工作，他就over了。怎么办使？使劲捏住你，说你坏话。什么一天到晚想往上报，和同事门关系紧张，喜交恶事，不服从安排，一盆一盆的脏水使劲泼，还有几个马仔替他背书。

你怎么办呢？想办法，绕开他，直接对接副总。在副总眼里，你和小领导都是干活的，没什么区别。不要被小领导吓唬住了。他永远也不会说你好话的。与其被他长期欺负，不如放手一搏，大不了，改换门庭，从头再来。

# 我真心建议大家发个副业
