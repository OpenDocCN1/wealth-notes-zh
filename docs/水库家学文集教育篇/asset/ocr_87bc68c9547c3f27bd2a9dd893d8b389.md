# 四十岁是个坎

过了这个年龄，你就是老家伙了。走在马路上，大学生会叫你叔叔。单位里，再也沒人把你当做希望了，也没人会精心栽培你了，也不会原谅你的少不懂事，也不会再给你什么试错的机会了。人们对你的看法，已经是标签化了。大家对你只会羡慕，不会再等待了。

你要么特别能战斗，别人家不定的，你没家摆平，要么你就是单位里人人见入嫌的老油条，这TMD那一把岁数了，居然还是个老混派，连个长也没混上。

我定个良好的标准，你看著：

一是熬到了大单位部门领导，还有希望能个副总，否则就算止步于中层了。

二是熬到了大城市两套灌笼房子，给孩子们有个交代了。

三是有一个燕裁日上，看得到前途的生意，虽然现在钱不多，但大有希望。

四是熬到了副高职称，可以人模狗样扮个专家，出去骗吃骗喝了。

如果你一条也没做到，恭喜你，不需要再努力了，你的人生基本就这样了。接下来的人生，你最好加紧锻炼身体，活的长，也是另一种成功！如果实在太难受了，怨怎么样，怨怎么样吧，KTV，小发廊走起，快活一天算一天。

# 大单位里

你在30岁左右，不能在同龄人中脱颖而出，遥遥领先，基本就没什大希望了。做生意，三年左右不能出现直线上升的局面，接下来基本也就是混混日子了。搞学术的，45岁必须到正高，否则也就是老东西了。如果上半场失败了，那么抓紧转至下半场。人生的机会，不仅仅是在你第一次选择的领域内。

# 菜单：写的不错

仙桥茅固主：今天和电力公司下属检修外包部门的大叔聊天，大叔属于一线检修人员，白天黑夜都在外面跑，解决各种故障。

我说我们现在招收的新员工都是来自哪些大学？大叔嘿嘿笑了起来，他说，哪来的大学生啊，高中生都不愿意来。

我好奇的问：这么稳定的工作，待遇也不低，怎么招不到大学生？他说，大学生都喜欢坐办公室，我们这工作整天风吹日晒，越是天气恶劣，越活多，没年轻人愿意干。我们班组现在没有年轻人，都是我们这些老师傅在干。

看来菜单整天说的那些故事是真的。

# 农二代的低薪就业热，

是不可持续的。

现在的就业形势确实很好，只要你愿意出力气。北京某工地，据说四百元一天都找不到人。以我的底层观察，建筑装饰行业确实非常繁荣，例如杭州的大马路上，到处都是建筑工地。上海的装修市场，贴瓷砖价格是工人说了算。

建筑业带动了上下游的经济繁荣，建筑农业农民工意外的引发了一个新的现象，农二代大学生的低薪就业。现在的建筑工地，大多数是四十几岁到五十几岁的农民工，工资较高，老婆也照顾不过来。
