# 大学教育是培养人文精神还是职业技能？

现在绝大部分二本三本大学生，毕业时基本是废物，手不能提，肩不能扛，交给它一个工作：两眼一翻白，不会。很多大学校长的意思是，大学是培养完整人格，培养人文精神，不是职业培训机构，不会干就不会干吧。一个漂亮的瓶瓶，直接甩给了企业和社会，他好像很骄傲一样。

大学的起源是精英教育。主要是为了培养完整人格和人文精神。内地大学在大清灭亡时期刚刚兴起，当时可能不到1%的富二代，官二代或者天赋极高的农家孩子，才能读大学，他们不考虑就业，也不缺钱，无所谓就业技能。

即使是清末的各类大学，还是很重视职业技能的。例如，协和医科大学，100年前的毕业生基本上就达到了一个优秀医生的入门标准。你去看看当时的学生笔记就知道了。再比如南开大学，立校的时候就非常强调职业技能。

现在大学扩张，每年有800万的大学生毕业，每个贫困地区村里都有好多大学生。如果再强调：什么华而不实的人格培养，而不是实实在在的生产劳动技能培养，这种大学必然是被企业和用人单位嫌弃。现在的民营企业基本不看学历，很多员工大学的毕业证书签了也不会去补。因为真的是没用，现在只有体制内的各种事情才需要大学证。

民营企业承担了80%的新增就业，如果我们的大学，特别是二三本，如果再放鸭子，这种大学民办公办，其实也无所为了。很多农村家长读出，大学无用论，并不是心血来潮，或者是观念落后。群众的眼睛是雪亮的，他们是针对现实提出的，是实实在在的用脚投票。城市居民子女读大学是为了一个面子，同时他们有更多的机会进入体制内。
