# 留学为什么？

能够去美国留学的，在国内大概是千分之一，去了能留下来拿绿卡的，又是百分之一。留美国，基本不看关系。这个能力，大概是十万分之一的佼佼者。有这个水平，你去美国打中低级的工，那不是吃错药了？

学知识？呵呵，不要搞笑了，除了极少数高精尖的罕见工程类知识点，其他在国内能用到的知识，国内也学的到。你去美国学会计，学法律，毕业回国后，基本用不到。两年后，忘得干干净净。五年后，连术语都不认识了。

留学唯一的作用是：文凭。但这种文凭实际没有多少意义。你去考公务员，美国州立大学毕业，不会给你加分，不会让你，美国的法学院，等于零。你考 CPA, 美国的会计学硕士，等于白痴。文凭的妙处在于，如果你有其它路子，就缺一个文凭了，那时候，这张纸才大有用。

留学文凭，找对象有用吗？如果你有太平洋，余山别墅，有用。否则，没啥意思的。我那于小区，一大半人家有留学背景，买房你也不打折的。

# 为什么读书好的男人，发财也少？

读书好的基本是一种发展路子，985 毕业，进入好单位，起薪高，一般是私营部门的三到十倍，光鲜亮丽，环境舒服，前途貌似很好。但是，当熬到 35 岁了，95% 的人就开始走下坡路了。没什么发展了。这些年一直是螺丝钉，技能单一，离开企业就是个 SB 了。

读书不好的人，起步很惨，一般是去小企业打工。小企业一般是三层级，一般是工人，主管，老板，老板和大部分工人也熟悉。这就导致了一个可能性，如果你在小企业里足够下力的认真，很快会进入企业核心圈（一般 3~6 个人），员工流动性很大，你干得好，上上下下都知道。你也熟悉和掌握了办企业的一切知识点和经验。

如果时来运转，你 35 岁有机会创业了，或者内部创业，发大财的可能性是有的。因为你的竞争对手都在高大的院家喝寻子楼里虚度光阴，而你已经在小企业里练出一副了。单说金钱，小企业老板，比一个五百强的部门总经理，可能要好的多，人也自由得多，一年赚百万，真的不算什么稀奇。

# 优等生的中年人生

外企有个隐性的发展曲线。毕业后的 10-15 年，如果你努力又聪明，你会飞速发展，“一年一进步，三年大进步”，从年轻到中年，一直是顺风潮水。
