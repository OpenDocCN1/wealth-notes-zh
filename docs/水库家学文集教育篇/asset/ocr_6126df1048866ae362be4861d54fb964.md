# 上海限倒垃圾

垃圾箱，每天只开放两次的措施，很难持续了。

我家小区已经恢复到三天前的原样了。我仔细观察了一下，确实有实际问题。

+   1，很多人是上夜中班的，早上开放的时候，他在睡觉，下午开放的时候，他在单位，你说他怎么办？只能是扔在地上了。

+   2，很多临时来的人，例如钟点工，不知道这个规定，把垃圾带到楼下，找不到垃圾桶，只能扔在地上了。

+   3，风俗习惯，垃圾带出门后，绝对不能再拖回来的！你不提供垃圾桶，他就放在垃圾桶的原地。

+   4，小区环卫工也烦。你扔在地上十几包垃圾，他是捡起来还是不管？只能捡起来，增加了工作量，还很脏。

+   5，执法也难。上海几十万个小区，几百万个垃圾桶，罚他五十元，还不够人力成本的，罚他五百元，就要扯皮了，怎么证明是他的垃圾？摄像头调出来，复制，也要人力的，涉及到取证成本。
