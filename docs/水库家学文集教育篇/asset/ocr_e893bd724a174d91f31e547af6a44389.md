# 考大学可以给人幻想

通过考试进来的，现在越来越不可能了。就算你北邮都即毕业，985，那又怎么样？你的工资买得起五环内的婚房吗？除了倒插门，你有任何办法吗？哪个女人敢陪你到四十岁，你会买得起西西二环的九十平米，还是靠捡破烂的可以打 95 折？

市场经济，最重要的不是考试。而是赚钱。你有个技术，可以做个生意。你会考试，可以做cpa，去四大大辅，卖苦力。劳动没有高低贵贱，钞票都是一样的面值。千万不要误以为文凭比劳动技能高贵，会谈英语网站，就比挖土方的农民工高贵了。

社会上，有很多年轻人读了大学，确实扶摇直上，平步青云，但那和文凭没一毛钱关系。那是人家三代人的努力兑现了。你为你的孩子做什么呢？除了给他压力，骂他，你还有什么？你自己不会飞，下个单，要求他会飞，合适吗？

我家装修一个雁荡山的农民别墅，小区里的一个包工头，承接了二十几家私人院子挖土方浇筑混凝土工程，每家 30 万，给现钱，他带着村里是老少爷们干，个人至少少年百万。挖土方，这话不难，就是若脏累。该大学倒好，窗明几净，工资五千。

# 农民工比大学生金贵多了

每年的新生儿大概是 1600 万，每年大学生 800 万，剩下的一半人没读大学，不一定去当农民工，自考大专，病残休养，服役，出国打工，接手家里的小生意，就算打工，也是做点光鲜亮丽的事情，例如中介，营业员，服务员等。

最后，在工厂工地辛苦活的人，反倒是稀缺了，远远比大学生金贵多了，这么多大学生绞尽脑汁赚来的小钱，最后被没考上大学的挖土方农民赚走了，你还不敢还价。

找两条腿的女大学生容易，找愿意贴砖挖土的农民工，难于上青天。

# 读书有用吗？

有用，但看你会不会用？

市场经济的职场开迁，不看学历，只看业绩。做小生意，也需要看货，算账，填表格，这个都需要文化，大家都懂，我说个小事请。
