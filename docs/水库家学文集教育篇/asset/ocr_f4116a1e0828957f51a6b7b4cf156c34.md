# ## 屌丝为啥穷？

屌丝为啥穷？因为你父母穷，你父母为啥穷？因为思维方式不对。你的思维方式绝大部分来自家庭，要记住，他们错了，所以穷。你应该仔细观察富人。不要说什么人家假冒伪劣，尔虞我诈，你这么好，为啥还穷呢？

举个最简单的例子：你读书的时候，成绩好，但不愿意和大家分享你的经验，考试不让同学偷看你的卷子，担心别人超过你了，工作后，什么事情都帮压压一人，显示你的水平高，期望上级提拔你。其实，这么做，你根本上不去了。因为你把所有人都得罪光了。

正确的思维是，愿意分享。世界这么大，钱赚不完的。你赚你的，我赚我的，我拉你一把，不求回报，至少你会送我几句好话。菜菜达人够意思，能够当兄弟，这就行了。单位里有 18 个处长位置，你也占一个位置，你帮人一把，又何妨？

坏人到处有，但是，大部分人是懂得回报的。不懂回报的人，走不远的，你放心，他绝对不会在下一个竞技场和你相遇，因为别人会干掉他的。

你做不出惊天动地的高科技，大部分人做不出来。大家都是平常人，就一句话，混人情，为什么混了这么多年，最后你富我穷？很简单，我对别人有用，别人就愿意把机会给我，而不是给你。

# ## 屌丝、中产、富人的思维

+   1. 屌丝的思维是：三天不见钱，做它干什么？
2. 中产的思维是：我努力几年，才可以赚钱了？
3. 富人的思维是：如果代表未来方向，那就先做起来，怎么赚钱，以后再说。大不了，不赚钱，又怎么样呢？
