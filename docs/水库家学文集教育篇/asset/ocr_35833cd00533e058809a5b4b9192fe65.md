# 女神退休了

过两天回沪，要去走亲戚。这位亲戚是我远房阿姨，也是当年大家心目中的女神级别。八十年代，她父亲是小城市的市委书记，妈妈是市医院副院长，自己凭本事考上了大学（当年考大学都是凭分数，没有保送），这个阿姨遗传了母亲的容貌，年轻时侯超级漂亮。

八十年代，小地方也没什么富人，也不讲究关系，找对象没什么讲究。她自己读了个大学男同学，毕业后，父母把他们安排到了一个大单位，男票是八十年代的大学牲，被单位列为后备干部，结婚。工作了一辈子，双双做到了处长退休。夫贵妻恩，一辈子很幸福，阿姨现在快六十岁了，还快乐的像个孩子。

经济方面，中等吧。省会中下质量的联邦别墅，省会附近风景区一个度假屋，二居室。儿子也算争气，靠自己干出了一点小小的成绩，比上不足，比下有余。

阿姨一辈子不会做饭，都是老公干家务。老公算好人，一辈子没有绯闻，一心一意照顾家人，现在老大要带孙，其乐融融。

这简直是完美的人生。

# 我对网民的理解是比较深刻的

甚至超过很多有关部门的研究人员。

我在微博写了十年，每天的互动大概是 3-9 万次（这个数据太惊人），我遇到的人，各种类型都有。我告诉你一个观点：你认为不可能的事情，实际上可能是很正常的事情。举个例子，我曾经坐过几次春x航空，这个奇葩航空公司在飞机上卖各种小礼品，几十元到一百几十元，包括儿童塑料飞机，玻璃模型，最奇葩的是空姐的小方丝巾。

坐春x航空的，大部分是贪便宜的乘客，例如我，她们居然不提供免费饮水。为了便宜，我也忍了。我就想，乘客们都是舍不得花钱的人，这种几十元一百多元，毫无使用价值的小礼品，怎么可能卖的出去？结果是，每次都有人买，我数过，每次至少超过 10 个人。那个飞机大概是 150 人。也就是说，6-7%的人思维方式和，我们不一样。

结论：不要以为我和我观点不同，我就是错的。或许，我是站在正确一边的人。房子买好了伐？

# 屌丝们为什么会有挫败感？

相比较初中毕业打工一辈子的父辈，绝大部分屌丝自小生活无忧，从来没有干过农活，肯德基吃到腻味，长大后读过高职大专，还有一部分二本，应该是大大进步了。但是，屌丝们还是不高兴，问题出在哪里？他们在追求和他们无关的东西。

一个河南富二代，抱怨买不起北京房子，这不是有病吗？你本来就不应该买得起。如果都买得起，北京岂不是拮得车都开不动了？等你买不起地级市房子的时候，房价就正常了。你本来应该是努力一辈子，买一套县城房子的，现在实现太容易了，你反而不高兴了。

钦州之道，要做绝格剃头。
