# 为什么初二 是 人生转折点？

很多女孩，考试成绩在初二突然就下来了。男生出现两极分化，一些人在初二开始学会混社会了，一些男生成绩突飞猛进。长期以往，很多人一直把这个情况解释为青春期叛逆，脑子开窍了，女生生病傻了等可笑的原因，我结合自己的体会，说一下原因，请各位家长提前警惕。

中小学教育分为两个阶段，一个是反复练习阶段，一个是逻辑思维阶段。转折点就是初一下学期，初二上学期。

小学到初一，基本属于反复练习阶段，女生比较听话细心，成绩相对较好，男生比较粗，但也能捣鼓得。

初二开始，数学科目一下子转为逻辑思维训练了，特别是几何概念，需要空间想象力，非常抽象。与此同时，化学和物理课程也来了，完全是理工科思维。这时候，很多学生是完全不适应了。女生这时候又面临例假，男生青春期发育，读书很困了，男孩女孩很刺激，一些学生熬了一学期，后面就派不上了。

理工科讲究的是连续性，不是一下子可以补全的。一转眼到了初三，面临中考的人生大选择。成绩不好的学生，思想压力很大，叛逆行为就出现了。

建议：利用初一暑假的两个月时间，找家教提前学习初二数理化学，让孩子适应这种思维转化。开学后，这种孩子领先于同班同学，自信心大涨，有利于自我深化。

# 改变命运，读书最多只占 50%

前面那个女学霸，毕业后进入了一个大外资，月薪一万多，当时上海房价是市区四万左右。如果没有其他意外，她很快会走上一条常规道路，外地孔雀女，长的不好看，家里穷，有个上海集体户口，买不起房子，找个上海国企的二本，匆匆结婚，婚后还要负担娘家，婆媳矛盾，房子小，迅速平庸了。

但她运气好，有野心，走出了一个漂亮的逆袭曲线。她被派到美国培训（这个机会还是很多的），迅速和一个华裔美国籍谈恋爱（目标明确），凭借全球五百强公司的光环（会吹会忽悠），骗定了华裔老公（内地去的博士生，需要一个大龄肤的老婆）。然后，五百强把她留在美国本土公司总部（裔外精英），她和老公贷款买了美国别墅，四十万美元（人生规划力极强）。国籍绿卡别墅，全部搞定，然后调理了几年生孩子（人生大任务完成），孩子五岁后，她主动要求回亚洲工作，在香港办事处当了一把手，和印度人搭班子。（走上巅峰）

回过头来想，如果没有美国培训机会，没有华裔老公，没有五百强的仁慈（调到总部上班），她是不可能逆袭的。在京沪，有学历的女生，千千万万，过的好 的也不是很多。

# 我们这一代人都 是读书拼出来的

那个年代没有其他的出路。我小时候是在大金业里长大的，有一次晚上进入厂区锅炉房，黑乎

乎的，虎耳欲聋。我当时还小，吓坏了。我觉得我要尽一切努力走出去，最好是当干部，坐办公室。所以拼命的读书。小时候，房子都是国家分的，确实没想过要挣钱，只是想坐办公室。

我读书特别好。但是，读书好都是拼身体拼出来的，为此也留下了很多身体后遗症。主要是神经紧张，考虑问题太细致，经常担心这个，担心那个，反复的做各种各样的预防设施，性格略微有些扭曲，医学上叫做强迫症。我经常走出去一两百米了，突然担心家里的煤气是不是没关？我又跑回去看一眼。

这些小问题困扰了我很久。后来有了手机照相之后，我才解决了这些问题。我出门之前，会把燃气灶拍个照片，大门拍个照片，以此确保燃气是关闭的，门也是关闭的，钥匙也是拔下来了。我从来不在外面用浴场的毛巾，我也不和任何不熟悉的女人握手，更不要说出轨，劈腿。

这些问题都是因为读书太拼，落下的后遗症。事实上，读书好确实给我带来了巨大的利益，但是我并不希望下一代也走过这条路，我觉得有个二批次本科就行了，没必要什么事情都出人头地，面面俱到。丝毫无恙的人生其实并不幸福，心太累，责任心太强。

当然，如果你家现在经济条件属于一般，你的孩子还是应该拼命的努力。只有努力，才可能改变命运，如果不努力，肯定是不行的。每个人的具体情况不一样，所以我的想法并不一定适合你。

# 普通孩子就不拼重点高中

最近大家都在讨论，重点高中教育质量非常好，远远超过一般的普通高中。这个题目还是有点荒谬，老师优秀，不代表所有的学生都优秀。重点高中喜欢研究超难度的题目，资质一般的学生在里面简直就是受虐。

你家的孩子如果具备考 985 的水平，那应该想尽办法进到重点高中去，如果资质一般，去不去都无所谓。你们家孩子的目标是考个二本专业，例如上海水产学院，北京印刷学院，没必要跑到复旦附中去受折磨。
