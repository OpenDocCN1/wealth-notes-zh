# 体制外的女行长拉存款

前两天，看了一个微博，忘记谁写的了。说是某一个体制外的女行长，主要任务是去拉存款，三天两头陪客户应酬喝酒，时不时，冷不防的还被人吃一下豆腐。她自己嘴说，年底一算账，还不如 KTV 小姐姐赚得多。我看完后一愣，总觉得哪里出问题了。但是，我想来想去也不知道问题在哪？

# 写给华裔的建议

在国外打工的华裔，大部分事业发展不太好，除了专门做国内生意的。

这么多年来，清北 985 毕业的在美国，说也有几十万人了。就没见过几个混到五百强中高层的，大部分还是实验室民工。这些人可是我们这里最精华的人才。说白了，语言不行，文化不融。

第二代 ABC，发展的也不怎么样，长大了只不过是居住国的少数人口而已，汉语只会说几句日常话，失去了第一代华裔的苦苦精拼，又没有人家的社会背景，父母也是老实的打工仔。总体而言，华裔在欧美的社会地位方面，还不是想象中的那么好。

我在留学期间看到，九十年代建博士出去的第十位华裔专家，少数人运气好，岗位还算体面，成为了专业池塘桥梁的中方。他们在国内的母亲大单位有合同，出去就找他们联系安排。那些年，中国文化热，这也给他们在欧美的专业领域创建了小小的话语权。第二代 ABC，基本就是打工人。

现在，欧美学术界的桥梁联系岗位，全部饱和了。新去的留学生，两头不靠，确实尴尬。我建议：

+   1. 人在京师，毕竟是主流人群。我们爽在发威好了，GDP 世界第二，几亿人的生活水平超过了美国小职员平均工资。如果有发展事业的志向，尽可能还是立足国内。欧美的绿水青山，看两个月就腻味了。
2. 有条件，出去游学一年半载，增长个人见识。但是，老外的钱很难赚，你的外语水平还不具备在国外找到好岗位的能力。
3. 在合法情况下，欧美加班，考虑买个度假房，就当是存折了。有什么想不开，过不去的了，也可以退隐江湖。
