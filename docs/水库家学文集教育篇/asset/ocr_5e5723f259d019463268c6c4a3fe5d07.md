# 我建议男孩女孩都去学武术（打架）

我有个熟人，他们家女儿在小学的时候，一直被班上其他三个女孩欺负了好几年，家长束手无策，干着急。那些霸凌女生下课后，围住小女孩，一般就是推她几手，拉在四处几句，把泥土塞进她书包上，没有大打，原因是看她不顺眼。

这女孩家有点钱，各种东西都是好货，时贵贵，时间长了，其他女生不爽了。一开始，小女孩不知道原因，后来知道原因了，就把各种好东西分给她们了，自己再也不敢带好东西去学校了，是挺可怜的。但家长也没办法，因为好几年都样，这女孩看上去非常胆小，让人觉得心服。

各位家长，如果你发现孩子放学后闷闷不乐，要找原因，很多是被人欺负了。虽然家长也帮不上什么，但是要鼓励孩子勇敢一点，实在不行，就带去学习跆拳道，上一帮师兄师弟，摔摔场子。据我所知，学校边的跆拳道班，一般和附近的孩子都认识，打个招呼，可能就好解决了。

# 我和莱煊有段时间迷上了下午茶

# 我认识一个业余学钢琴的姑娘
