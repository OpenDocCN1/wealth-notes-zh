# 人生有三次机会，十年一次

任何一个行业，大学毕业后再专研十年，必可达到专业高度，有能力成为行业新星。本科毕业后，有三个十年，22-52 岁。

我在第一个十年，一门心思熬级别，满盘皆输。

我在第二个十年，主要是搞塑料桶，基本输光。

我在第三个十年，准备成为优秀段子手，这个路子成功的可能性比较大。
