# # 二本子的意思是

大家都吃点亏，让我舒服的买房。

卖地款，少收点，教师工资喊一喊。

银行利息，不要收了，银行工资高，减薪吧。

农民工工资，太高了，打个五折。我是大学生，你是什么学历？

建材商，你们以前赚不少了，现在不能赚了，给我打折。

狠开发，你们都几百亿身价了，这次不能赚钱了。

等我买了京沪二居室，以后你们随意。反正我要占便宜！

# # 键盘侠的人生

你说什么，他都不信，除非你现在送给他一套京沪房子。

这种人有着极其强烈的自卑感，读书差，长得丑，家里穷，基因不好，运气不好。最大的爱好是喷。今天骂这个，明天骂那个。你让他努力，他反问你，包发财吗？不包，你说什么呢？让开，别耽误我喷。
