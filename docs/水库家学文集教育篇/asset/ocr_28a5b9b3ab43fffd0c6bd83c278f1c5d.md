小地方长大，所以您不懂。我给您讲个故事。

六七十年代，各地山沟沟里开了很多高大上项目，大批的清华北交学生，奔赴小地方，搞专业工作，也许了正高，但退休后一回顾，自己满意，孩子倒腾，献了青春献子孙。当然，我们肯定要向他们致敬。

科技类工作，三五年一个热点。专业是重要，但别太当真了。这两年香得慌，过三年是狗不理，京沪五年社保才能买房，你这岁数了，没房子，能不能找老婆都是问题。

当然也热心人，倒插门也是合法操作。

# 我们真有自己的想象的人格尊严吗？

我年轻时候以为有，老了才知道是没有。一旦不娶了，拉单子就没有心理阴影了。很多 985 输在了娶面子面上，永远的错过了机会。

# 99%的人

在 45 岁前，都会倒在某一个台阶上，其他人蜂拥而上，再跨上一脚，晋升之路，彻底断送。退休前给你个安慰奖。这不是你的能力问题，而是位子有限，资源有限，实在是没什么可以再给的了，只能找个理由打击你，甚至故意颠倒黑白。你也不要太难过。这才是 99%普通人的人生。房子买好了伐？

# 不要轻易和人结仇

我年轻时候在单位，因为利益，和某家结下梁子。也不能说谁对谁错，起初是互相说小话，抬高自己，贬低别人，一步一步发展到，顺手给对方挖个小坑，让他在单位里丢个面子之类的。其实，这种感觉太不好了。

我打击别人，别人也会打击我，互相在背后搞事，把正常的事情故意引申出对方是居心不良的金图，纯粹是乱来。其实谁也坏不了谁。对方也很大度，说，过去就算得了。今后多联系。我和某某当时都是夹子生，算是一等一的小嫩手。

事情的结果是，我在工作十年后，退出比赛了。我走人之后，专门找他道歉一次：当年我在背后说了你好几次坏话，我今天就是来坦白的。

建议：发生矛盾后，尽可能在第一时间找对方说开了。哪怕对方不认账，不理解，不高兴，一般也不会再恶意加深了。人很难迈出这一步。不要轻易反击，长期和人结仇的滋味太难受了。

# 永远只做第二名

我从不惹事，但还是有那么多同事同学说我坏话。其实，人在江湖，无论穷富，哪有不被人放暗箭的？

穷入，也被人恶搞，主要是看不起你。一般不太会挖空心思搞你，你也没什么油水，犯不着这个劲，就是顺嘴嘲笑你几句。

富入，也会被人陷害，但总体不多。富人倒霉，你也不会发财，富人也省力，搞起来没完没了，你也心里。除非非常之恨，杀人防路，一般不会轻易开敌。
