# 入深户

说一下我为什么要放弃东莞本地村民户口，入深户。

我虽然是东莞本地人，但是户口落在整个镇内经济倒数的村，从 1990 年到 2019 年，村民基本没有发展，大家主要经济来源就是靠借钱建成几层的房子，一层自住，三层出租，一家几口人靠收几千块钱租金过日子，基本没有人有真正的去打拼事业，对自己人生没有规划的父母，对孩子的人生也一样，不怎么重视孩子的教育，反正完成九年义务教育就差不多 了，很常见的就是父母做完了治安，儿 子辈的命运也是去做好治安，从来没有 人试着走出去农村，久了就没有人愿意走 出去了。

以前我们村也是短暂辉煌过，那时候经营工厂成本低，基本上整个工业园都是满的，全部是来打工的外来人口，人多起来，什么生意都好做，烧烤档，糖水店占了整条人行道，整个村里房子都不够租的。

但是房地产在 2016 年下半年火热起来后，人工成本大幅上涨，社保，劳动法，导致东莞的制造业越来越艰难，大型的工厂为了节省经营成本搬迁去更偏僻的地方，我妈的房子十年来第一次空了一半，现在每天愁眉苦脸的。

整个镇，除了非编制的医生，老师，银行职员没有任何高薪的职位，S8 线路一楼，都是请法足的，餐厅服务员，房地产类做的最多，整个市场死气沉沉的。
