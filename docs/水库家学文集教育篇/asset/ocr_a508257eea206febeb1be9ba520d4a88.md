# 厨丝要自强

普恩制的好处，对你个人意义是有限的。十五年前，你家要是有机有有小汽车，附近三个县的漂亮姑娘，你都可以去提亲。现在，你出不了隔壁村，找个二婚农村妇女，人家也不会多待见你几分。普恩制只有物质意义，没有精神意义。

厨丝要做的是，拼命考文凭，评高岗。开工就算了，本钱太大，玩不起。但是，考到京沪当个三甲副主任的可能性还是有的。我家，那么多销售女代表，天天闹着说你叉辣又辣又可爱，岂不是爽大了？

现在的问题是，考试越来越贪钱了，你说苦不苦？

# 农二代也有好逸恶劳的

我的2位保姆大姐非常勤奋，她们在45岁时，和老公一起努力，买了成都重庆的两居室和小汽车。儿子三本院校本科毕业，去年也开始工作了。我去年有点紧张，我以为她们很快就不干了，回去带娃了。结果没想到，她们根本不敢退休。

张阿姨的儿子是工科专业的本科生，大四实习是在一个外资机器厂，他们同学共30个，工厂把他们全部塞去烧电焊。这个活比较苦，必须站着或蹲着，反正不能坐。我一听大怒，这不是拣卖大学生吗？张阿姨说，这也没有，因为做五休二，每月给6000元实习工资，包吃包住。转正后，9000元打底。

小张也算是乖孩子，干满了实习期，拿到了2万元，全部给张阿姨了。但是，死也不去工厂了，说太黑了。于是，小张就在大城市里找了一个3200元工资的小公司打杂。每天开汽车上班。他们班的30人，没有一个留工厂的，全都跑了，都去小公司坐办公室了。

李阿姨的儿子是高职，学的是下水，专门做工地的，还可以考职称，第一年是月8000元工资。但是，小李干了八个月就辞职了。原因是，工地太脏了，到处都是泥水灰泥，远离市区，吃不好住不好，工资再高也不去。

小张小李都是标准的农二代，但是他们也不穷。老家三上三下的房子等拆迁，市中心90平米无贷款，亲戚朋友那里借款20多万，三个人上班，很快可以还清。儿子还有一个漂亮的小汽车，找老婆也很简单。女方基本和她们家族的家底，彩礼6-10万就行了。

但是，接下来两位保姆大姐都闷闷了。婚礼马上生张，女方和孩子就没收入了，儿子三千多元，刚刚够汽油和物业费，剩下的一切开支，全部要老夫妻承担。至少要每月倒贴五千元，才能活下去。

孩子们为什么不去机器厂的高工资？她们说，现在农二代其实远比城里孩子还娇生惯养。父母长期养在身边，觉得亏欠他们，所以节省吃信用，绝不肯让孩子被城市的中产家庭少半分子面子。这么长时间下来，孩子们已经和城里人彻底陌生了。机器厂，打死他们也不会去的。

孩子们将来怎么办？她们的想法是，上考公考题（公务员），中策开商店（做淘宝），下策小公司做行政，或者开滴滴。反正要干净干净，自由自在，绝不会打苦力工了。

各位小老板们，你们以后要是遇到啥也不会的小伙子，直接要六千元工资+社保，你不要奇怪，现在就这样了。你随意。
