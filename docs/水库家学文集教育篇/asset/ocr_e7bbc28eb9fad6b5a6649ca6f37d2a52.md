# 工作中出现了重大失误怎么办？

没有家学传承的屌丝，第一反应是推卸责任，找客观理由，证明责任不在自己，这是很愚蠢。你给上级造成了这么巨大的麻烦，你还哭找各种各样的理由，说明你的个人品行，素质不高，没有承担错误的勇气，遮遮掩掩，心胸狭窄。

正确的做法是：第一时间单独找领导说明情况，积极寻找弥补的办法，承担全部责任，然后痛心疾首，表示绝不再犯。领导看你态度这么端正，气也消了一半了，觉得你认识到了错误，一般不会再加重处罚了。

当然，领导对你办事不牢靠，也是有印象了，需要你在往后两三年中扳回来。

# 越是客气，越不把你当自己人

部门主任经常说一些鼓励我的话，好好干，有前途。是什么意思？这说明主任对你很不满意，但他不好意思直接说，同事之间要留点颜面。

你要记住一条，越是客气，越是不把你当自己人，越是不客气，越是把你当自己人。下了班之后，主任开车带你一段回去，说明是真把你当自己人了。

# 年轻人如何知道自己是否进入了圈子？

在单位里，部门主任和你关系热切，经常有互动，并不代表你就是他圈子里的人，也不代表他会提携你。

有一个标志性的内容，你要留心，部门主任在你面前私下抱怨，谁是谁的人，谁以前年轻的时候干过什么事？谁跟谁关系特别不好，或者关系好。你要注意和谁搞好关系？如果你听到这些活，说明你基本录取了。
