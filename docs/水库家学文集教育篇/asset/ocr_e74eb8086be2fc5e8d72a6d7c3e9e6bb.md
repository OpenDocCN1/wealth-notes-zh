# 立志做网红，行不行？

先说我吧，我算半个网红。但这真不是我的本意。我八年前写微博，主要是闲的发馊，尝试一下新事物，也是个心灵记录。

我写了好久，也没人看。我至今记着当时仅有几个粉丝，海碧，老张评论，金溪熊小子好像是后朱的。当时主要是写写经济学。有一次我说房价，这真是捅到了马蜂窝。2010年，时寒冰，牛刀，安道谢，各路野评家，如日中天，这些都是当年的大咖啊。他们为了卖书真是发疯了，像现在的杨红旭一样。天天喊暴跌喊，暴跌啦。你说不是的。于是，被所有人怒骂。

我当时说不会跌，是有依据的。n2。我是金融学的野科比命，n2在当时一般人根本不懂，是我天天喊天天喊，逐步普及开的。现在大家都懂了。

房价新闻化是牛刀干的，宏观经济学进入普及阶段，是时寒冰起的头。阴谋论上升到理论，是宋鸿兵的路，知识付费是是映波的第一批发明。微博卖包也是北京扇子，卖鸡蛋是肉唐哥。时政法律类，到现在基本全军覆没，我就不说了。

这批人多多少少懂点经济学新闻学的，大多数是本科文化。当时大家都在摸索，互联网怎么玩？他们走的路子太复古了，基本是半新闻半论坛的路子。但我认为，长篇大论，完全不适合互联网的快餐文化，也不适合绝大多数低收入人群的视角。

我就走了一个新套路，向脑白金学习。农村墙上刷logo。在楼市领域，我的标志性口号，是最牛的，一枪一个准，全部贯通你。这个套路，现在看，是符合当时的传播规律的。涨跌喊对了，不是第一重要，最重要的是，别人记得你。我的京沪永远互，翻倒拆迁徙，一套一套的，直接刷屏。

说了一大堆故事，我想说，要做网红，不简单，要有些办法和智慧。

+   1. 如果你要成为美女网红，你去学玛丽莱，玛丽蕾唱歌一般，但是刷 logo 很厉害，她的几首歌，全都是主打青少年，现在普及到幼儿园了。“泰国那帮奴印度尼亚，咖喱骨背斧，印尼几层塔”。还是有什么佩里矛势，适合班级联欢会。你玩一个试试看？

+   2. 如果你要成为楼市网红，你先干掉一个大 V，练练手。

+   3.  你要想成为专业大 V，医生，法律，高考，各行各业都有牛人，你去弄一个。

做网红是有前途的，但是，你要想好打法。至少一年内，你要找到套路。时间不等人。我是倒插门的，时间不值钱。你是卖钱去的，一寸光阴一寸金。

# 35岁以上一般求职者

我也不愿意招聘 35 岁以上的一般求职者（技术大牛除外）。原因：

+   1. 35岁还在四处求职，且无技术优势的人，说明其在其他单位也就那样了，素质可想而知。这些人最大的爱好是，劳动法维权，上班老油条。如果你原来干得好，老板肯定会留你的。其他单位也不会主动邀请你。或者自己事先给他们同行联系好，这群辞职，那里上岗。不至于四处投简历求职啊？

+   2. 35 岁以上的人，企业很难和平辞退，因为这些人，上有老下有小，背负全家重担，你要辞退他，他肯定发急。他可以，驴骑驴找马，三天两头请假去面试。但你不能辞退他，否则，必打官司、四处举报，企业撞上，半个命没了。

+   3. 35 岁以上的人，对于吃回扣，要红包，已经司空见惯了。有个别人还教唆年轻人做坏事，根本讲不通的。
