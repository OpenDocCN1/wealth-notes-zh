# 现在京沪实际收入是多少？

有没有超过 500 人的京沪大企业 HR，能不能说说，现在京沪实际收入是多少？

有关部门的数据，因为涉及个税，我估计不太准确的。

我周围的本硕白领，一般是 1~1.8 万/月，年薪不超过 20 万。

# 大学老师这个群体，要哭穷

这个群体哭穷厉害，但实际上不穷。

单位发的，一般是 12 万-15 万，但是，他们时间多，有职称，可以搞一些业余收入，比单位发的不少。

因为很多寒假急于评职称，应付考试，所以很多人没有时间去赚外快，所以暂时收入不高，但这是暂时的。

等编到副高，90%都牛了，除非情商特别低。
