# 说说我干的一个职场趣事

我曾经去一个单位挂职。去了没几天，部门一把手找我聊聊天。我是高度警惕，假装轻松。聊的也不错，无非是谦虚谨慎，赞美领导。最后，开始聊家常了，说到炒股票，我就大意了。我说，我们家人从 1992 年开始，就有亲戚炒股票了，这是一赚钱的，那玩意儿害人啊，当时我也是就随意说说。

没想到啊，这句话把我害惨了。那个一把手是股票迷，带动了部门里所有人都去炒股票。我们单位的电脑可以上外网的，每天上班就是炒股票，开会都是夜市后才开始。我把炒股票说的一钱不值，等于是在一把手脸上打耳光了。后来，我就又走背字了，直到他退居二线。

结论：在职场上，任何事情，包括业余爱好，都不要轻易表态。实在躲不开了，就说个不熟。

# 大单位的势力划分和地盘之争

任何大单位，都是有几十年历史了。哪怕是新建的大单位，也是几个老单位合并改名而来的，人还是那些人，圈子还是那些圈子。这么多年在一个锅里抢大勺，磕磕碰碰的事情多了。长年累月的积累，会形成各种恩怨情仇，大家互相划地盘，势均力敌，合纵连横。你不要以为老板或副总退休了，圈子就没了，不可能的，这种圈子可以延续好几代人。

现在的一把手老板，外面请来的是最常见的。但是，这种大老板是不可能打破内部势力划分的，只能是利用和引导。否则，你一来就鸡飞狗跳，工作成绩上不去，会被更高上级认为，你是个没本事的人。

大单位一般有几个势力，

一是老土地。这些人干了三十年，熟悉情况，成事不足败事有余。得罪他们，真会出大事。他们可能会找个要退你的人，和你死磕，一起玩完。

二是没啥背景的干活之人，单位也不能总是内部搞事情，也要到外面争面子，这就是他们的生存下去的原因。

三是空降兵，高中低都有，情况复杂。

四是子弟兵，老一辈就是在这个系统的，方方面面临都是叔叔阿姨。

五是傻逼，没人要的货，自己瞎玩。

算了，不写了。这玩意，越写越复杂了。
