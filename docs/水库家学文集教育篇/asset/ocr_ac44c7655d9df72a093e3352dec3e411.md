# 学龄前教育的体会：养成习惯，控制强度，寓教于乐

+   1. 每天固定时间，学个20分钟。孩子一到这个时间，就知道要学习了。可以用一年级课本，或者重点小学入学测试题。这个事情无须讲书。上海民办优质小学都是指尖的，你不学，别人学。
2. 强度不能大。四五六岁的孩子，耐心不足，强度大了，孩子就受不了。一天学几个拼音，反复练熟，熟能生巧。不要超过20分钟。
3. 一本正经和寓教于乐，互相结合。数学题可以在买东西的时候揉进去。英语题可以在路上看到什么叫什么。每天上学走过的路，就那几个东西，几句话，反复即可。
4. 激发孩子的好胜心。孩子们在幼儿园都会比。一旦比赢了，学习的劲头就大了。
5. 遇到学不下去了，完成20分钟，先放一放。过两天再试试看。
