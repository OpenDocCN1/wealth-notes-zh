# 屌丝为什么很难成功？

内骚很差，急功近利，没有耐心。

其他领域不敢说，我就说微博领域。很多屌丝看了马丁哈耶克，凯恩斯，就觉得老子啥都懂了。但是，作为穷二代的他，在现实中的所有领域，都是标准丐帮，彻底失败者，毫无价值。

一天，他发现，写微博好像可以快速出名，自以为找到捷径了，好大喜功，急功近利的习惯性思维立即使他脑子充血。他不想着一步一步脚印，认认真真构建理论体系，做好实践调研，而是开骂几个大V，希望引起关注。那些话我也看了，都是一些虚头巴脑，从理论到理论的二逼话。

不到三天，大V们全都把他拉黑了。他忙了半个月的微博之路，也结束了。

# 富二代的普通生活

你们不知道。

富二代，绝大多数是奇葩。他们那个年代，正常人是不回去做生意的。主要是一些社会边缘群体，单位的不得志人群，忍无可忍，胆大包天，才会去做生意。他们当中的绝大多数人，是以失败告终的，少数侥幸活下来的富人，其实脑回路超级奇葩。

他们不太相信逻辑，最喜欢相信直觉。因为在他们的发财过程中，机遇比逻辑更加有效。但是，这给富二代整出了巨大麻烦，富二代是求稳，已经几个亿了，安安稳稳保住胜利果实，也不错。但是，富二代不是这样想问题，遇到事情，完全凭感觉拍脑袋，这就造成了巨大风险。

很多富二代就是生活在明天可能一无所有的恐惧中。

# 个别富人的焦虑

可能表现为纸醉金迷。

中国的富人和英国不一样。英国是财富传承有序的地方，大家都有长期打算，很少出现花天酒地，纸醉金迷。但是，中国富人面临的不可测因素，实在是太多太多了。一个生产事故，一个合同纠纷，一个员工车祸，一个政敌变化，一个没想到的违规违法，企业就可能走不下去了。

你说防范，怎么可能性呢？我招聘一个员工，还要再雇几个人防范他出事故？这种焦虑，在身价较高的群体里，是默默存在，不乏先例的。富人无法完全避免这种风险，又没有足够的理论支撑去解决这种痛苦，只能是听天由命。

排遣这种长期焦虑，只能是转移注意力。很多时候，鸦片，桑拿，澳门，就成了为少数富人精神依赖的虚幻。外人看上去好像富人在乱花钱。
