# 我不主张幼儿提前教育

我在生活中，尽可能避免提前教育。孩子提问，我耐心解答，但我绝不会一本正经的安排计划。孩子怎么搞，我都不管。我的任务是，满足孩子对大自然的好奇心。孩子想知道什么，我就查资料，用最简单的话答复问题。

儿童的大脑发育是有客观规律的，提前两年死记硬背一些单词和认字，并不会让你的孩子获得超人的智慧，只是破坏了成长规律，耽误了其他部分的发育。我不知道儿童脑力发育的具体细节，但是我们对大自然还是要有一些敬畏。什么年龄做什么事情。

大锅蔬菜颠倒了生长阶段，只不过是一时的富裕，实际上不好吃。我小学读书也一般。我们班上有个教师子女，一年级是语文数学双满分。但到了初中就是中下水平了。因为这个同学的小学成绩都是激素催的，不是自然思维的结果。到了初中，需要自己解决问题的时候，他就没办法了。

# 现在的小孩子，个个是戏精

刚才，一个妈带一个小姑娘，在小区花园里拍照。小姑娘骑个滑板车，摆好pose，然后大喊：

"爷爷奶奶，你们给我的滑板车，我好喜欢啊！"

"外公外婆，你们给我的滑板车，我好喜欢啊！"

"爸爸，早点回家，我喜欢你的玩具。"

三级分开拍的。

拍完了，娃娃说：妈妈，我可以去玩了吗？妈妈答：去玩吧，骑慢点。

我听的直接晕圈了。然后，那个宝妈开始编辑微信短视频了。估计是分别发给三方的。

# 中国大学生

毕业初期的分层现象，不太明显。因为圈子尚未完全固化。

中国的富人，大多数是四万亿之后爆发出来的，到今天不过是十年。与此同时，中国富人群体不太稳定，经常发生瞬间破产的事情，起来再去，孩子们也不是经常性玩在一起。

公务员可以制约富人，在具体事情上，比富人的地位高，而且公务员的来源广泛，所以，现在的社会分层不明显。

但是，今后的分层情况，会有一定的出现。

+   一，教育体系分层了

中小学已经有区别了，主要是大学开始，欧美留学和去杭州读个本科，圈子就分开了。

+   二，住房分开了

中国明确不能形成集中连片的豪宅区，但是散灾区是不少的。今后，单价十万以上的豪宅区，卖房搬走的情况会越来越少，因为市中心新房罕见了。这个圈子，就近入学，慢慢会加强一些圈子交往。

+   三，老板等级增加了

例如，行业协会，工业园区，经营性组织大股东开会，时间长了，你来我往，过年之类的。但这批人变动很大，经常三五年就换了一批人。

+   四，奢侈品会员

你买一个百万的车，至少可以认识十个以上的玩车人。以此类推。
