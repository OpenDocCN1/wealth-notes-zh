# 退休金的差距

为什么厂里女工退休金明显低于教师干邵？

原因很多，但有个主要原因，她们的退休年龄不一样。

女工是50岁退休，工作和退休，都是28年。

女干部是55岁退休，一定级别的女干部还多延迟了几年，工作33年，领取23年，这个差距是比较大的。也就说，女教师领取养老金比女工少了5年，多交了5年。（怎么交的我我不知道）。

再加上女教师的工资基数比女工高，所以，算下来，女教师女干部的退休金，明显高于体力劳动妇女。

# 职工延迟退休的本质是

减少养老金支出。

现在，女工退休年龄是50岁，平均寿命是78岁。领取养老金年度，和工作年度，差不多都是28年。这钱哪来的啊？

假设，推迟到60岁退休，工作36年，领取退休金是18年，少交多取，企业成本下降，出口价格和商品价格才有少涨不涨的可能性。如果年年提高社保比例，企业利润越来越少，最后确实经营不下去了。

但这个问题不是那么简单的。女性工作者分为几种，情况不一。

一是体力工作者，例如女护士需要一定力气，女纺织工，包小馄饨，站柜台。这些女人是很难坚持到60岁的。所以坚决反对延迟退休。

二是脑力工作者，例如教师，医生，工程师，劳心但不是劳力，基本可以延迟退休。还可以拿高工资，基本赞同延迟退休。

三是女干部。非常非常赞同。因为她们超过55岁后，在机关里是老资格了，一点点累的活也不会让她们干。如果是带长的，那是更好了。

所以，每年提议延迟退休的都是这些有一定地位的女性。
