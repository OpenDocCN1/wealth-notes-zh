# 一，相同的行业思维

现在电视里经常说什么，“教师世家”，“铁路世家”，“医生世家”，子承父业，确实有利于言传身教，避免孩子走弯路。公办医生的女儿去做个体女演员，父母很难帮忙，女儿的演艺之路也只能充满坎坷，成功率不高。但是医生的儿子做医生，那就非常好。什么事情都可以具体指导，孩子们成长就快了。

# 二，考核方式的引导

凡是好一点的岗位，都是需要笔试+面试。我们不说面招打招呼这种事情（嗯，我相信肯定没有，或极少个别，嗯），关键是每个行业都有特定举例，要想在面试中脱颖而出，最好要熟悉本行业的思维模式，分清轻重缓急，面试就事就做了。举例，演员面试可以挺胸昂冒臂一点，电力局面试就要西装革履，落落大方。反了肯定不行。对吧？

# 三，我是农民，怎么办？

这种情况可能需要换行业了。建议换到技术工种，例如鸡农，养猪，挖下水道，劳动最光荣。相对而言，不需要太多的情感交流，情商不高也可以做好。尽可能不要去考那种需要进大单位的专业，现在的普通医学博士，都不能保证进京进三甲，进地市三甲更不多。你可以积极争取。

# 二十年来的一场升职记

我年轻时候，内环线研究所里有个升职明星小李，男生，没有背景，条件很差，升职最快。我们是社科专业单位，他是一个二本大学计算系毕业，进单位后分到后勤处（现在改制叫后勤部，处长改叫部长了）。

所里是以科研论文作为业务主项，小李属于彻底边缘人物，一天到晚，就个打钻机器，这是我们那个倒，那里挨个倒，忙忙碌碌，特别擅长打印机卡纸。我们为了显示自己高人一等，还经常叫他李工，不是工程师的意思，是工人的意思。

一年后，我们大跌眼镜了。他评上了一系列的优秀和荣誉，来着；我们也不尴尬，因为我们和他属于两条线，就像医生和电工。三年后，我们还是科员，他已经是科长，七年后，我们还是副科级，他 29 岁，已经是副处长了，这时候，我们算是傻眼了。

处长属于单位中层，单位办中层会议，我们被安排去做记录，已经是天大的面子了，他已经是堂堂正正的中层干部了。走廊上遇到，我们还要叫他李处长，实在是尴尬到家了。虽然，小李同学还很谦虚，但是我们是自尊心受到严重暴击。

说了半天，大家都奇怪，小李升职怎么能就这么快呢？说白了，也搞笑。我们是九十年代后期进单位的，当时上海正在普及电脑上网。这个是很天动地的大变革，他被招进来，也是这个因素。当年，电脑是普通人家里最值钱的大件，大概是 6~8 千，那时候，内环线一室小房子也不过 10 万左右，上钢新村（世博会区域），一套小户型，也就四万元。
