也是可能的，虽然不多。当包工头就设这个待遇了，没生意就喝西北风了。

但是，一旦过了中产假，包工头和 cpa 就是一个套路了，拉单子。单纯做会计，到头了也不过三十万。但是，你要是开个“会计工作室”，那就不一样了，年入百万的很多。其他同理。

在你做一个具体工作的时候，你一定要尽力掌握技术，目的不是为了加工资，而是今后自我放飞的时候，有管理能力，可以带队伍。

# 二木大学扩招

把很多农村孩子害苦了。

很多农民家长以为，考上二本，就可以找到好工作了，不惜一切的砸钱。实际上，三年高中毁了眼睛，四年大学，花了这么多钱，就学会打游戏了，还好好吃懒做，浑身犯懒。

当然，我也不是说，你别读二木了。我的意思是，反正是自己骗自己，大家能不能轻松点？也不要高考了，二木注册制、学费打五折，就当扶贫了。农村严重脱离实际，我也当不知道。我晚上打游戏，你也别管我了。

# 我拥护，但还有点建议

初中升考试成绩，人为打分占 30%，最后由学校确定。我首先是坚决拥护，热情讴歌，但也有些建议。

家长校长班班主任一定要搞好关系。大家都懂，就好像公司里互相评优，自评多是选自己，最后领导说了算。在思想发育还不完整的未成年人中，引入这种打分体制，确实是令人发指的。

假设，我家孩子一时情绪激动，顶撞了班主任几句，师徒打分肯定没了。

要是个别的校长找有单位的家长办点事情，你是办还是不办？这事情，头大了。个别的校长和老师能来找你，就不是什么好鸟了，你怕不怕？

当医生的家长，校长找你，你看着办吧！

# 操作流程要让我们放心

既然是对综合素质打分，我建议，每个学校参与打分的人，要在其居住地小区公示姓名，他本人的素质怎么样，是否有给其他人打分的资格，也要接受社会监督。打分人和分数，家长学生一查互相监督。如果谁敢对未成年人下手，以权谋私，违反纪律，毁掉了孩子的前途，我相信，党纪国法对他绝不会宽容，群众也不答应。

单位里提拔职务，这一次不行，还有明年。初中上高中，只有一次机会，基本决定了孩子前半生的命运，甚至一辈子的人生走向。这事啊，实在是太重大了。如果简单的交给没有打分经验的人才鉴定也不一定能够达到社会公认的那教师，我是觉得有点担心，建议教育司们在开展工作的时候，慎之又慎，稳妥确定打分的基本流程，取信于民，百分之百避免误判一个孩子的命运。

每个孩子都是国家的未来，民族的希望，今后也是新时代的建设者。保护孩子，是每个成年人的职责。

大城市初中升高中，竞争激烈，差一分，就差一个操场的学生了。差 30%，老母鸡尖叫了。这个人为打分的操作过程中，如何保证公平公正，如何避免以权谋私，是一个非常严肃的课题。

未成年人的心理素质尚未完全成熟，教师队伍里唯利是图的人也不是没有，大江南到处都有的校外补课，是谁搞出来的。大家都懂。如果因为人为打分，出现恶劣事件，是我们不愿意看到的。
