# HR 问：你有房子吗？

最佳答案是：公司附近有一套，贷款四成。理由如下：

+   1, 距离公司近，有急事，叫的到人，公司欢迎。

+   2, 有房子，说明稳定。

+   3, 有贷款，说明努力。

+   4. 不要说有很多房子，公司以为你是来混社保的。
