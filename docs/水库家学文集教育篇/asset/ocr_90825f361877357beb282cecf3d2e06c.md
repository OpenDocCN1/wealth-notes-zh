慢慢论落到底层，看不到任何翻身机会？主要是两个原因，

一是家庭。父母都是高级档次，来往的都是大行长，大主任，大老板，你在旁边端茶倒水，听个一两年，也懂的个七七八八了，随便那个叔叔阿姨给你个机会，你就上去了。而很多富二代，几十年都没机会和大头头说上几句话，更不要说给什么指点了。五年后，还是差到十万八千里了。

二是学堂。很多时候，我看到的只是一个人的成长结果，没人会告诉你他的培养成长过程。这就需要家学训渐了。小到说话，大到站队，事事皆学问。单位里，也不都是领导素成子弟，总会有几个精明强干的心眼。你能不能进入圈子，就看看你懂不懂事，有没有眼头光。这种事情，只可意会，不可言传。领导总不能说，我家老人住院了，你给我找个优秀保姆来。怎么办想？现在前头，记在心里，办在实处。

# 大学的红帽教育

除了top10，并不适合其他大学。

思辨教育的表现就是，“你说的不对！我不同意！我有其他想法！我要别出心裁。”说白了，就是批量培养杠精。我们读大学也是这么干的。但那时候，上海一年录取的985大概也就两千人左右，有几个杠精，不是什么大事。现在，几乎人人都大学了，要是都往杠精方向发展，岂不是乱象了。

技校培养比较直接：你操你x的，就这干于。做砸了，师傅上去直接就是踹一脚。

实际情况来看，大学生毕业，基本不会干活。技校毕业相当于一个初级工，还好些。大学生在工作后，很快会迫上来，但那不是大学教育的好，而是老大学学生学习领悟能力强。总体而言，大学教育，课程落后，思辨奇葩，除了少数工科类，其他的，没啥用。全靠个人在工作中的领悟能力。

我建过，大学生不要把这种执拗的杠精性格，带到工作生活中，那只会害了你。单位里的老油条，老资格，哪个不是人精？你去当奇葩，只会引来无穷无尽的嘲笑。绝大部分人的人生，就是服从，干活。不要想些什么奇迹幻想，你以为你是院士的那块料？滚！

# 目前的教育体制

实际上不鼓励孩子们成为一般劳动者。

目前的教育体制，有一些问题需要重视。

一，青少年体力视力太差

我们的教育体制，完全是刷题，摘题，要想取得老师们的表扬，就必须牺牲青少年睡眠和玩耍的时间，无休无止的刷题。从4岁的幼儿园中班，一直刷题，刷到22岁本科毕业。长期的搞题练，青少年视力体力越来越越差。

二，过水的本科文凭挑起了年轻人不切实际的幻想

很多大学，在二十年前只不过是中专技校，本来应该推广实践技能。这几年高校大跃进后，很多应该在生产一线踏踏实实工作，成为技术手，高级技工的孩子们，拿了个优质本科文凭，读了很多毫无无解的人生哲学，开始幻想一夜暴富了。这也是为什么投资理财火爆的一个原因。

三，青少年没有实际工作技能，只能从事劣质岗位

现在的教育，大部分学样，严重脱离实际。课本内容，根本用不上。孩子们毕业了，和个250差不多。我们那时候也是这样，但我们底子好，什么事情番几遍就会了，所以没问题。现在是扩招了，大部分二3本的学生，根本不知道怎么回事学习。毕业后，除了办公室打打字，房产中介打打电话，还没说什么技能。
