# 屌丝一直认为

官裕家庭会迅速衰败，败家子一堆。

我仔细回想了一下我周围的情况。富裕家庭，儿孙略有下降的有几家，例如父母是高级档次，自己混到了中偏上档次，几家大房子的遗产还没划完。但是，彻底败家的，我周围没有。

屌丝逆袭的也有几家，5-10%。还是因为赶上了房价这个特殊因素，大体套路是一样的。

+   1. 在扩容前考上了一本。
2. 九十年代中后期毕业，进入上海大单位，买房，分房，现在手里好几套了。
3. 2008-2015 年，留学欧美，读了博士，拿到国藉，买了别墅。

外地可能还有极个别的老老板，上海就样了，2010 年后，我再也没有听说屌丝逆袭了。

# 上海男公务员相亲也不吃香了

结婚就是过日子。看房子，看收入。

公务男，一年也就是十几万，如果不是三套的拆迁户，在市区没房子，找老婆也不容易。

希望只看爱情，不看房子的姑娘，给公务员男多一份青睐。公务员相比外科男医生有个好处，出轨极少。因为公务员天天被管的说想法了。当然，主要是穷。

# 上海最苦最累的公务员

上海公务员中，最苦最累的，首推派出所男，五天一个夜班，天亮了继续上班，不回去。如果当了副所长，在家的时间不保证，老婆来见一面，最好提前预约。

其次是法检，一般半个月值班一次，加班是司空见惯的。最好的是，区直属机关，例如卫生局教育局，不加班，没夜班，很多事情，大家心里有数。

# 男公务员的优点和缺点

京沪家里有钱的妹妹，找个男公务员，是很好的选择：

+   1. 公务员不出轨，是普遍情况。一旦出轨了，公务员是很容易被抓诈的。所以，大家都是心怀谦慎。

2. 公务员不会惹事，不会去做什么担保，投资之类的败家事情。

3. 公务员警惕性高，被骗的事情极少。

4. 医疗教育，相对便利。公务员直系亲属有事了，大家都会尽力协助，提供一些便利。

5. 普遍重视子女教育。他们是读书的受益者，眼珠子就这点。

个别男公务员的缺点：

+   1. 看不起人。他们接触的高大上人物多，有时候，脑子一热，以为自已也是高大上了。
2. 穷。

3. 自以为是。公务员可以看到很多资料，自以为什么都懂了。其实，他们对其他行业也是略知一二。

4. 固执。别人很难和他说道理，他认为的事情，必须按照他的做。这很容易导致两口子打架。
