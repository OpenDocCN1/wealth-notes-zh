当时，电脑是 win95 系统，经常性死机，自己又不会修，只能请人修。小李就是专门在所里修电脑的，所以，单位里大头发和小头发家里，他都去过，熟门熟路，而且和领导的家属也非常熟悉，上上下下对他个印象超级好，每个单位总是要挑几个年轻中层干部，他就成为所有领导一致认可的候选人了。

大单位有个特点，一步领先，步步领先，他是什么好事都轮上了，房子车子，都是单位给的。他这么年轻，就是大机构的高级处长，和一群老头秋天起早平坐，前途似锦，顺带也成为情场翘楚。多少土豪要把闺女给他呵。我们那时候挣的一毛，没房子没女人，他是羡慕随随便。

后来，情况急转直下了。因为电脑质量越来越好，基本不坏了，系统重装，屌丝们也会了。小李就失去了优势。他那个副处做快 15 年了，我们现在大部分都超过他了，他还是原地踏步。但是，他比其它同龄人好的是，不需要换老婆了。当年，所里很多优质青年，穷的一毛，找老婆都是凑合。只要是个女人，皮实便宜，能用就行了。现在，他们一个个都是高大大的潜货了，80%都换老婆了。剩下没换的，也是考虑升职，迫于无奈。

结论：人生的发展，不仅仅是自己努力，还要看时代机遇。女人也不要捡漏为股了，世界上没有便宜事情。

# 我叮嘱几句

很多阶丝马上就要踏进社会，进入单位了。我叮嘱几句：

+   1. 工作初期，绝对不要说人坏话，不要议论同事。你不知道那些什么人有什么背景，踩雷就完了。

+   2. 年轻时，多流行，多干活，不要学老头活。累活苦活，都是一种学习锻炼，不要抵触。

+   3. 不要轻易在单位内部谈恋爱，不要谈论性话题。

+   4. 在没有彻底搞清楚单位派系的情况下，不要故意进贴某个小圈子，风云变化很快的。

+   5. 不要向领导伸手要荣誉，要待遇，要机会。这些宝贵的资源，领导都是反复斟酌给谁的，不会因为你要而给你，反而让人厌恶你。

+   6. 积极参加各种集体活动，说不定有人会给介绍优质对象。

+   7. 认真穿衣，保持清洁，体面一点。

+   8. 不要占单位便宜，也不要炫耀家理有钱，平平稳淡，各方容易接受。

+   9. 出差回来送领导礼物，不要太贵重，不要体积大，要得体含蓄，表个心意即可。

+   10. 女生不要和男领导太亲近，容易被骚扰。你现实，也等三年后。

+   11. 男生说话做事要含蓄一点，这样老阿姨才喜欢，很湿的样子，人见人烦。

+   12. 千万不要得罪更年期妇女。
