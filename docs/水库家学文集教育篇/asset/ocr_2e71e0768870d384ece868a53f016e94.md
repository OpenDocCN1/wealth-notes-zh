# 怎么给女儿找个兴趣爱好

菜菜，我有个女儿，小学一年级了，想给她找个兴趣爱好。钢琴，舞蹈，唱歌，绘画，选哪个？

答：钢琴，现在考级不加分了，平时也不能炫耀，意义不大。就算搞成半专业的，最后可能还是去酒店大堂弹唱，或者做家务，性价比太低。

舞蹈，需要长时间练习，培养气质也看体型的，不是人人都有意义。舞蹈是个体育项目，对身体有一定伤害，例如拉抻柔韧度很疼。平时炫耀的机会，也很少，除非是春节联欢会。投入大，产出低。

唱歌，作为非专业选择，性价比最高。时时刻刻可以炫耀一把，可以软快融入各种圈子，也可以调节自我情绪。

绘画，适合比较安静的孩子，对高考和就业有帮助，例如建筑系，美术系，服装设计系等。

# 学校里的阶层分化

或许是不可避免的。

我们要做的是，如何教育引导孩子们正确对待贫富差距，尽可能淡化阶层差距，而不是通过阴暗的手段，增加这种分化的深度。家长混的好不好，跟学校没有什么关系。小学那么急吼吼的要知道家长的各种隐私，到底是什么心思，路人皆知。建议：

+   1. 教育部门立即停止收缴学生家长职务财富的各种隐私，有身份证号码，姓名，电话，邮寄地址即可。不要说什么关心孩子，因材施教，你想什么我们不知道？
2. 杜绝教育大纲外的各种秀才活动。这玩意就是比烧钱。校外文艺课，一小时几百元。学校周末还要组织学生们互相夸，真的没意思。真心喜欢的女学生家长，你们课外去艺术学校玩，不要在同学们面前炫耀了。
3. 逐步停止所谓的家访。孩子家里房子贵，你去家访一次就改变什么了？真有事，可以在学校办公室沟通，或者视频联系。

给孩子们一个稍微宽松的童年吧！他们长大后，各种拼爹的事情多了，没必要这么小就强化这种意识。
