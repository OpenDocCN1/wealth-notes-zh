司打车，房产中介，电话推销，跑销售等。

现在的情况变了。近年来，农民工已经越来越多的买城市房子了，很多人也落户了（拆迁、子女读书等原因）。结果是很明显的，农民工子女已经习惯了三室两厅的县城精装修，或者大城市的老破小。

我是目睹过 98 大下岗的。上海周边的乡镇企业，民企工厂，超级发达，但京沪的下岗工人不去，就算全家喝稀粥吃咸菜，我也没听说谁去宁波温州干。他们只会无休无止的去居委会申请补贴，他们习惯了城市生活，无法适应工厂的集体宿舍，也吃不惯工厂的饭菜。

现在的民企工人，35-55 岁为多，通过购买拆迁等，他们绝大多数有县城以上的房子。现在农村家庭的黄少年，可能是十年后的农民工，现在正在各城市里刷外语题，读芭蕾，弹钢琴，这些孩子肯定习惯了城市生活，很难再忍受集体宿舍这种艰苦环境了。等他们长大了，去当工人的可能性确实不大了。

当然，今后科技进步了，工厂需要的工人也会大量减少，暂时也不要担心。需要考虑的是，你家孩子今后做什么工作？

985+211，基本还可以混湿大单位。

二本大专高职，基本就是以前的中专高中技校了。理论上，二本还可以考中国部乡镇公务员，但实际上你去的可能性也不大。如果你家在省城没有强悍的关系和背景，学历也就是个二本研究生，那你真要好好细想了。

我的观点：

+   1. 父母做小生意的背景，例如小饭饱，小药房，定制飘钢门窗，尽可能目光长远一些，做一个可以传承的生意。

+   2. 父母都是手艺人，例如医生教师律师作家或者工艺美术大师等，尽可能自立门户，争取交下去一个完整的事业架构，子女也能参与。

+   3. 父母是大单位的，尽可能要会做人，留点人情，给子女铺个路。

+   4. 父母是打工的，尽可能学好技术，看看孩子能不能接手？除了大城市的 985211，学历真的不重要，没人因为你读过个山沟沟的二本学士，会对你高看一眼。我认识一个民企的驻场厨师，年薪三四十万，老板在财务科看得到，都要先发财，生怕他跑了。子女也做这个。其他人想偷技，门都没有。

+   5. 父母是纯雇丝，那就锻炼身体，不要吃喝赌抽，今后婆婆去给儿媳带娃，公买来做饭，让孩子尽可能有时间逆袭！儿媳就不要踢了。

+   6. 父母啥也不会，还好吃懒做嗜好，那就多喝酒，多抽多，多抽点，多抽点，争取早点丁了算了。
