# 京沪普通人马吗？

特别高的人罕见。但是全社会高工资的岗位都在京沪。不说医生码农了，这个比不了。很多好单位都在京沪。年收入二十万个人还是比较多的。某些国内五百强员工，小公司高管，就算一个沪士老师会计，十万也不稀奇，很多外地人只看到了棚户区的老工人。老厂子的退休人员，好像京沪普通人穷，这些人退休金不能和快递员比。上海人家，老夫妻有退休工资，小夫妻一年二十万到手，较多。很多人家反应，在外地，保姆工资不高，在京沪特别赚钱，就是民间支付能力强。

但是，京沪普通人也抠。因为房子支出房务。二十年房贷的利息相当于本金的70%。一套房子六百万，贷款420万。每月还贷2.3万。如果是中老夫妻卖二套房，大概是五万了。剩下的钱就不多了。而很多农民工，回家盖房子只要60万，县城买房是一百万，每年的存款很多。

结论，做生意卖货，要学习拼多多，去县城乡镇，农民有钱有钱。
