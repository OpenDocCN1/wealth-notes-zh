# 女性利用劳动法，隐瞒怀孕

合理合法的坑了小老板，是职场非常普遍的情况。但是，主要是坑了比较穷的小老板，实际上坑不到大公司。

女性就业也有高中低。越高端的职业，女性收入越高，也越重视长期发展。举例，一个算法女工程师，年薪 80-150 万，如果怀孕了，她是不愿意主动坑公司的，可能会坚持干活，或者讲清楚情况，放弃奖金，道理也很简单。这个行业，就那么几家大公司。你坑了马公司，你就算毁了，猫公司、狗公司也不敢要你了。高收入女性也懂这个道理。

中等公司里的女性，也要顾及脸面。如果耍赖的太难看了，就必然不停的撕逼，一个 211 孕妇，真要去撕逼撒泼，其实也是巨大的心理挑战。更何况，你的家庭住址，家人情况，公司也知道，闹开了，你也很费劲。你得点好处就算了，各让一步。

最倒霉的其实是，穷逼小老板。小企业的起源是失业人员互助，混口饭吃，本身实力差，开出的工资不高，招来的多是低学历，中低收入女性。高职毕业，就算是小企业的最优秀人才了。大家都靠底线操作，碰无硬忌。劳动法又炮枪偏架，帮助女性隐瞒怀孕的。

小老板也没办法，只能是自认倒霉，心里一万个骂娘。女性入职体检，不能解决恶意隐瞒怀孕。孕检主要是漏尿、找别人要，自己撑一点点，厕所门一关，你知道个鸟啊！

企业承担孕妇的成本是很高的。最低工资 2800，社保现在也高了大概在 2000 元左右。怀孕开始到孩子三个月，干不了什么活。成本大概是 7 万。企业还要另请人顶替。如果这个老板脑子笨，签了一个月薪的合同，他就自己可以去跳墙了。如果一胎接二胎，一个厂里出三个孕妇，这个小厂基本算毁了。

其实，我觉得也好，实力不强的企业倒一批也正常。留点钱，给儿子买套婚房，也算是百年基业了。
