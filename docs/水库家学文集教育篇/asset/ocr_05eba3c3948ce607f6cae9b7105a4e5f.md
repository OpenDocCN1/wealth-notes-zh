# 高二家长立即收藏

我仔细看了各地高考作文出题思路，基本上都是我们当年高考的套路。

+   一是考立意，先提出一个宏大的题目，让你无处下手，一大半的人就慌了神。

+   二是考落脚点。这么大的题目下，你要选择一个支点，展开阐述，这个落脚点，你可能有想到了几十个，不知道选哪个。这时候已经紧张的手发抖了。

+   三是考词藻。展开三段论，都是日常经验，大家都懂，实际上是看你如何组织优美的词句，迅速找到契合主题的古文诗词，历史故事，大部分人已经要哭了。

+   四是考升华，题目已经很大了，你再想升华，直接背古七了。

其实，这种考试，我们当年都有非常成熟的套路模板，没想到，这么多年后，还在玩这个。原来其中有几个语文老师，出了好多小绝招的。只不过，这种绝招不能普及，大家都这样，就没意思了。

# 高考只是有利于中产而已，

但是却给社会制造了几亿个白眼狼。

高考只看分数，分数是怎么来的？背书和刷题。什么样的家庭环境中，青少年的分数会高？不穷不富，非常平稳，朝九晚五的中产家庭。

+   一，贫穷家庭的孩子，在高考体系中是最吃亏的

农民工孩子，小学初中在城里，租的房子面积小，噪音干扰大，学习条件不好。父母也没什么能力给孩子讲课。高中在老家，爷爷奶奶只管吃穿，其他随意思。城市下岗职工家庭，请不起优质家教，买不起高价网课，房子也小，孩子容易被日常经济问题干扰。

+   二，富裕家庭的孩子，大部分可以不参加高考

+   三，中产家庭孩子，是高考的整体得益者

+   1，父母是大学生，有能力自己补课，或者有能力分辨补课老师的质量。

+   2，中产家庭，没有日常经济困难，孩子比较安心读书。

+   3，中产家庭，一般有二居室以上房子，房子隔音质量还不错，腾出一个房间或阳台，给孩子安安心心读十二年，完全没问题。

+   4，中产家庭精通各种考试报名技巧，大学生家长知道西南政和华政强多不档次，吉林大学，西安交大的汽车专业和交大接近。云南民大的东南亚小语种不比北外强。东南大学的建筑专业不清华差，而且，在行业内是公认的。中产家长们的口分不便宜，老农民可能就不知道了。

+   四，中产最维护这个高考机制

中产可以通过高考，整体上碾压富二代学历。富二代因为有家族企业或者重大资产，不会在求职竞争方面，和他们直接竞争。中产家庭就最好服了。
