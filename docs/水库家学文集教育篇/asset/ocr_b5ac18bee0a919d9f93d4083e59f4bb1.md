# 为什么超过四十岁，

无论男女，普遍不好找工作？

因为你没什么价值，还吃的多。

你要是有技术，六十岁还有人要。某阿姨 55 岁退休了，三甲医院立即返聘，看 b 超。还有几个体检中心也请她，一年十几万起步，再加上十万左右的退休工资，人生大不同。你要是有脉，退休之后，多少单位邀请你当顾问，拉单子！你要是有职称，随便找个建筑公司就拿钱了。你要是有体力，跑跑业务，拉拉单子，都是可以的。

可我们省很多人，在所谓的大公司混了一个漂亮头衔，乾忘乎所以了。等这个大公司消盘的时候才发现，自己已经没人要了。很多高福利高上大的好公司，其实对员工的工作并不满意，只是因为劳动作帐不敢开人，大家拖到一起完球了，很多人就傻眼。

站着员工的角度，即使你是部门总经理，也不要太得意了。你必须时时刻刻记住，要有一个过得去的技能，或带有决心创业，哪怕开是超市。按照现在的市场经济，很难保证一个公司中层，能够熬到退休。

生活就像过山车，有高峰也有低谷，无论眼下是好是坏，都只是暂时的。体制外的绝大多数人，在五十岁之前就快速坠落了。

我们要下半的优惠意识。

# 银行的人感觉在走下坡路？

如果看资产负债表，利润表，银行的利润还是在突飞猛进的。为什么自己感觉钱少了？答案很简单，人多了。

某银行十年前是 2 万多人，现在是近 8 万人。你熬十年，扣脸辞职退休离岗的人，你在本区县，至少是排名前 20% 的员工，业绩好的就是排名前 10%，搞个网点行长，专员，机关部门腐职，不是太难。

现在倒霉的是，人员结构稳定了，总量不再增加了，你今天再在什么位置，三五年后，还是什么位置。

银行利润虽然还在上升，但是抵不过人员增加的这度，平均下来，个人收入就下滑了，业绩考核就罚了。

民众遇到一些暂时困难，对于读者只不过是一个新闻，对于经手贷款的业务员，就是灭顶之灾了，坏账记录长期背背，难啊！
