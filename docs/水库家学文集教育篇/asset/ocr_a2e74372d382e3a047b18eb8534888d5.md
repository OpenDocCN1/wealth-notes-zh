# 我从来不相信快乐教育

人生三大苦：读书炼脂磨豆腐。读书的目的就是淘汰别人，抢占资源。985就那几个学校，你有我无，则刀见红。

快乐教育是骗章子的。高考快乐吗？你舍得取消吗？外地小孩子读书快乐吗？不快乐。

小孩子要想读书好就一个办法，提前教育（俗称预习），事后家教（俗称复习），天天刷题到深夜（俗称勤奋）。哪一个不是你们搞的花样？我是应试教育的过来人，你好意思昧着良心说假话？

# 德国职业教育体系

非常收到家长欢迎，社会认可。为什么？包分配。因为学生实习阶段就是为了每个企业量身打造的预备员工。学生们也习惯工作环境了，直接入职，顺理成章。我们这里不可能。因为90%的新增就业在民企，民企是为逼，没人感兴趣，我们就想去银行！
