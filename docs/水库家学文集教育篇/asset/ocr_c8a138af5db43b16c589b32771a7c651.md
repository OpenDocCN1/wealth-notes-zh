# # 怎么和领导搞好关系？

我肯定不能说你去给他送礼，我说一个我亲眼见过的例子。

有个头头，他孩子从幼儿园开始到小学四年级，七年时间，他没有时间去接送。正好有一个下属，他母亲退休了，她妈妈每天去买菜的时候，顺带接送一下，举手之劳，不足挂齿，合理合法，坚持了七年。下属没有送一分钱，没有请领导接过一支烟，但是领导全队对他非常感激。

像这种互相帮助，团结友爱，增加同事间友谊的事情，大家留意点，可能会有意外惊喜。

# # 大学生毕业后，进入体制还是主动创业？

1. 如果你没有非常优秀的家学传承，也不太懂人情世故和商业规则，属于一般普通家庭出来的，毕业七年内不要创业，想尽一切办法进入大单位。最好是公务员系列，级别越高的单位越好。

国家部委，省直机关，央企总部，最大的优点是做事非常规范严谨，考虑事情周到妥帖。你接触的人档次高，接触到的信息，是最真实最直接最及时的信息。你可以看到社会和人生的不同方面。特别是一些不常见的信息或者历史遗留问题。你在一般的小单位，一辈子都不会知道这些隐秘的事情。这个经历是非常宝贵的，对你从一个学生转变为一个社会上的人是非常有帮助的，如果你毕业后去一个小公司做文员，你永远不知道这个社会有多么的复杂。

毕业后的七年，你会面临人生的几件重要大事，第一是结婚，第二是买房子，第三是生孩子，孩子读幼儿园，你会遇到比较多的要求人的事情，那么体制内的人相对是比较受欢迎的。女性还可以顺利的休产假。

当你在大机关大单位锻炼了 5 到 7 年之后，你可以学会面对千头万绪的统筹安排，工作风格养成，做事做人的规范谨慎，这对于你今后出去创业非常有帮助。

在体制内，你还可以结交各方面的朋友，互相学习，取长补短，积累一定的人脉关系。我们不说要占人家便宜，但是遇到很多事情，认找人，不认识人，还是有一定区别的。例如你刚开始创业，有很多不懂的事情就可以找人咨询，他们会给你一定的解释和说明，尽可能少走弯路。

当你到 33 岁的时候，你就会知道，你是不是适合在这条路上继续走下去。一般情况下，体制内工作五年到七年，你应该升为副科长。35 岁左右，好的可以到处级，中下的一般要到科长，如果你都没不到这些台阶，还是 35 岁的副科长，那么你下定决心出来，毫不犹豫。
