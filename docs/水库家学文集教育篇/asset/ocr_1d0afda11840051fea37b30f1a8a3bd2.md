# 我们的教育

会把孩子们引入斤斤计较的思维中。

人生最重要的是方向。方向对了，也就是多赚少赚的区别。方向错了，越努力越糟糕。但是，绝大多数人没有这个意识。我们从小到大，从来不考虑方向问题。我们的教育体制强调的足，高考差一分，人生大不同。学校老师一天到晚让学生注意细枝末节，锱铢必较。

学校教育从来不研究方向。这就导致了我们很多人，对于买房前小区划算1%的技术，非常感兴趣，但是忽略了方向问题。很多人遇到事情，犹豫不决，拖拖拉拉，还嫌再便宜1~2%，最后错失机会。

# 一般家庭的小孩子

不要满什么虚头巴脑的歌舞琴操了。

文艺之路，除非是老天爷赏饭，否则很难有什么回报，但是付出极大极大。一抱好学就是几十万上百万，一个副高专业路你三年，没有七八十万是不可能的。

我给一般家庭指个方向：学点绘画。这个是攻守兼备，实用性极大，回报丰厚的东西。

今后，学习成绩好，可以考建筑系，设计专业。学迹就考三本类专之之类的，混个本科族人。生完孩子，再出来当补习班家教。一辈子不愁。

# 幼儿不懂社会

在他们眼里，好做一切都是正常的。

每天下午放学前后，一群小娃娃围在一起吹牛逼，基本上都是事实实说。小刚爸爸是土豪，小继爷爷是大领导，小姜妈妈是35岁，身高167cm，小花妈妈以前是女歌手，我都知道。

我不知道我家的娃漏露出了我多少隐私，反正我现觉得我基本是透明的。

小孩子吹牛逼是不甘落后的，有什么好的，立马就拿出来吹了，不吹赢，不过瘾。所以，你们在家说话，尽可能谨慎一点，说不定，明天下午，幼儿园里都知道了。
