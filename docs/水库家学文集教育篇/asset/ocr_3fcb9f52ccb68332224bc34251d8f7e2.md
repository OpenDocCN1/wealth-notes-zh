# 养二胎为什么比较轻松？

很多家长反映，第二个孩子，养起来很轻松，他们认为是自己有了经验，所以处理好，实际上不是的。生二胎的家庭，绝大部分第一胎是女孩。一般隔3年，会生第二胎。因为第一胎太小了，家里忙不过来，往往是等女儿进了幼儿园之后，开始养第二胎；那么等第二胎出来，两个孩子相差3到4岁。

等老二能够自行行动了，基本上是两岁左右。这个时候，姐姐已经是五岁或者六岁了。那么，姐姐就可以带着弟弟了，父母就会把看管弟弟的责任交给了姐姐。孩子很小的时候，有管理更小孩子的欲望，所以姐姐的积极性也是非常高的。时间长了，就形成了一种固定的模式。姐姐管理弟弟，弟弟依赖姐姐，而且因为是一家人，就显得亲密无间。

这时候，父母就轻松了很多。因为孩子一玩儿就可以玩几个小时，父母不要插手，他可以做自己的事情。那么父母就觉得越来越轻松了，等孩子拖到三岁半，进幼儿园了，反而是早晚接送，两个孩子，一个孩子工作量是一样的。

由于姐姐长期照顾管理弟弟，时间长了就形成了一种，思维定势。姐姐认为，弟弟的一切，自己都应该去爱护和管理，不知不觉的就到了成年。很多姐姐，如果不是独立思想非常强烈的话，在原生家庭里，会被父母诱导产生一种牺牲自己也要把弟弟托上去的念头。

这种思维模式是潜移默化几十年形成的，当事人是无法摆脱的，甚至是，不知不觉中立产生的。假设姐姐和弟弟相差12岁以上，基本不会产生这种问题。
