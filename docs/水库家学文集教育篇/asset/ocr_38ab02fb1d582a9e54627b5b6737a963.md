# # 中小学教育的个别新情况

现在，公办中小学老师是不能兼职补课的。某数学老师快四十岁了，也不可能当副校长了，职称津贴也没多少钱。家里还要还房贷，老人要药费，子女开支。他会怎么办？我相信，99.99%的老师是好的，以责任心为重，不计较个人利益，一心扑在工作上。

该说的好话说完了。再说点万分之一的话，前一段，某区较重 点学校毕业班，期中考试，班级平均分竟然掉到了年级最后，还比年级平均分差了很多。年级主任急了，倒查原因。

一是主课老师在闹离婚，没心情。

二是主课老师在私下收钱补课，上课就是人到心不到，把考试重点留在补课班上讲。课后来缴费的孩子，老师课要备课，直接打发走了，理都不理。那些交不起补课费的孩子，主要是中低收入家庭，家长只能打骂孩子笨，也搞不清楚成绩烂签的原因。

三是主课老师正在想办法调到私立学校，年薪很高的那种。对现在这点小奖金，已经完全不感兴趣了。老字八个小时在单位里，没有迟到早退，上课把教案读一遍，已经够了。学生爱听不的吧。

年级主任对这种情况，已经没法办了。因为个别老师已经不想好好干了。开除他？可以。我辞职去培训上班课，钱还多了，白天都不要出门挤地铁了。谢谢你。再说这事情也够不上开除，甚至连处分都不行。学生成绩签，怪老师？你看警溢同学，年纪第九名，也是我教的啊！

公说公有理，婆说婆有理。归根结底，原因是经济利益和唯分数论。怎么办呢？

建议：

+   1. 义务教育有保底，体现公平。部分家长有条件的，搞些特色学校，教师待遇可以搞得好一点。
2. 提高全民文化素质，大学普及化。985是国家的宝贵财富，一刀切，唯分数论，给寒门子弟一个优质出路。那些找中专改制过来的二本三本，就那么回事了，鼓励读书，愿意读的，交了学费就来吧。
3. 控制近视率，提高青少年体质，为国家的长远发展贡献力量。
