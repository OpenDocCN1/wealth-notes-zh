# 如果京沪家庭都生两个孩子

住房困难又将重新席卷大城市，8090年代的痛苦回忆，就像噩梦一般的在脑海中久久不能散去。

这么多年来，由于超高压的计划生育和史无前例的经济大繁荣，使京沪居民住房困难问题得到了较大的缓解。虽然现在还有不少居住困难的家庭，但是绝大部分已经达到了至少东欧的水平，少数人已经接近了西欧的水平。这是京沪几代家庭共同努力的伟大成果。

生育几个孩子都是对的。但是每个家庭应该为子女的教育成长、结婚住房，有一定的前瞻性考虑。不能只管生，不管她今后怎么办呐？现在京沪的房价，几百万上千万，而工作2-5年的年轻人，是绝无可能买得起住房的。至于说政策性保障房，只能是慢慢排队，部分满足，绝大部分的人还是应该靠家庭的支持。

建议，有关部门明确，如果生二胎，国家将给多少的住房奖励金。我觉得至少是本地30平方，小夫妻合计60平米，是符合目前经济发展现状的起步水平。否则，外浑情人墙的日子，可不好过啊！
