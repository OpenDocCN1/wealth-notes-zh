我的意思是，通过制度安排，引导富人家孩子不必急拼到底。你不是想读本科吗？我们给你一个出路，二本管够。把清华交大的机会，更多的留给一般家庭的孩子，你家娃本来是注定的 CEO，就不要刷题和抢我学位了。你好我也好。

# 我们应该考虑改革了

现在的教育环境，对于穷人家孩子是越来越不利了。我们应该考虑改革了。

现在，大部分老师，上课进度是针对全班第 20 名左右的同学。你家孩子要是前五名的水平，上课不可能提高分数。想考高分，完全靠课余时间补课。补课就是钱啊。

现在，报销生理化政地史，每一节课的价格，你去老师或者培训机构，大概是 150-200 元，这么多课要补习，你算算多少钱？富人有钱，还可以把老师请到家里来，一节课 500 元，免去孩子来回奔波的时间。可以多得 30%的时间。

这样搞下去，高考拼的就是金钱了，穷人家孩子，有多少钱可以跟随去补课？富人无所谓，一年 20 万，初三到高三，不过是 80 万。你家行吗？我说的办法，让一部分富人家孩子退出竞争，不要太累了，考个普通二本就不错了。把公企优质大学的机全让给穷人家孩子。

# 过多的行政审批，抑制了内需发力

例如，我们可以开拓特色高中的市场需求，形成新内需，新产业。

现在的教育系，你要想学古代诗本科，必须刷高难度的数理理化高考题，这是很幽默的。很多数理理化补课利益链上的人，会说的天花乱坠。实际上，你去问问问你的楼楼长，他还会不会数理理化高考题了？这不把包管理的服朋贴嘛！

高中不是义务教育，举办特色高中的法理依据是存在的。目前高中还是几十年不变的剧题。我不和别人家孩子抢饭碗，抢学也，我就想学个专业知识，读个全日制本科，不行吗？

现在的高中，纯粹是为了高考一涨卷设立的。全国几亿青少年，几十年一个样？我们哪需要那么多的数理理化技术兵啊？你老婆也是读过高中的，你问问她，还答得懂高考题吗？完全是浪费。理论上，职教也可以单点技术，但这就考不上本科了。

解决矛盾的办法是，进一步深化改革。

改革高考几十年不变的体制，创办特色高中，对二二三本人才。我家孩子喜欢画画，考个工艺美术本科。我家孩子喜欢金融会计法律，我能不考考物理化学？我家孩子将来想翻译，能不能只读文科？我家孩子将来想当护士，能不能不学古代诗歌？我给想学尼散打扫的时候，也不需要朗诵一篇《将军令》《出师表》吧？

美国的高考制度比较灵活，数理理化等那学，但他是统一卷卷，而是分类卷卷。

你考哈佛大学英语语文学专业，高考数学期大概是初中数学初二下学期。

你考麻省理工学院系专业，高考数学期相当于华师大数学系一年级的题目。

建议：

+   1. 高考试卷分档分，高低难度分开。

+   2. 传统高中不变，你家孩子可以继续读。

+   3. 增加特色高中，提前进行学科继续，主要针对二三本。

+   4. 教改目标是，毕业就能干活。而不是搞一群啥也不会毕业生，直接推向社会。个别大学还为了就业率，废废制假，自欺欺人。
