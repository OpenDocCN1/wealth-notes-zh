# 普通人留学毫无意义

普通人留学真的是毫无意义，除非为了转移资产。

+   1，中国的理工科教育，对于奥数全国二等奖以下的智商，足够你学了，
2，文史哲经，除非是为了嫁个外国博士文凭，回国当教授，否则，毫无意义。国内搞协方面，和专管员打电话就行了。
3，对外交流方面，主要是外汇票据和法律，以前是真需要这些人才，但现在早已过剩了。假设你智力超群，刻苦努力，熬了五年在美国拿个不能出庭的律师工作者证书，回来也不过是2万元收入，还不如在小区干中介呢！
4，真正有意义的留学是，家里爆有钱，两头配置资产，你先去熟悉一下当地的情况。
5，特别穷的，其实在哪打工都一样。在唐人街送外卖，工资高一点，但生活品质太差了。

# 出国解决不了任何问题

中产阶级把孩子弄到美国去，是不解决任何问题的。
如果这孩子不是985理工科的智商，去美国后很难留下来，本科毕业还是要回，或者黑下去。
欧洲日本的华二代，从小在当地国读书，拿到身份了，也基本是在当导游导游，浪费人生。

# 孩子是985学霸，那倒应该去留学

除了少数高科技，99%的普通留学，彻底没有意义，只是一次花费很大的旅游而已。
留学的知识在国内无用，在国外，你也不可能从事这类专业，最后都一样，去超市当营业员。
以前，日本工资是上海的一百倍，当营业员也很开心。
现在，差距不大了。
