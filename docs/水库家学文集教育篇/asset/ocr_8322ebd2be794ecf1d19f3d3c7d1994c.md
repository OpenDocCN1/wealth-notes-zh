# 安逸就是穷

我奉劝各位同学，不要贪图大单位的安逸。

安逸就是穷。

真正要赚钱，必须在大市场里拼搏，找顾客要收入，而不是找领导要薪水。

你提供更好的产品，更好的服务，找每个顾客多赚 50-500 元是可能的，顾客多了，你也做起来了。

但你找部门经理加薪 1000 元，比考交大难！

# 说说什么样的男人能当官？

我工作二十年了，看的也多了，我说的是大多数，极品不算。

+   一是相貌，身高 175 以上，胖一点的，方脸。有官相。

+   二是性格。内敛，沉稳，严肃。说话不能多，也不少，该发言的时候，积极发言，私下里少摆龙门阵。

+   三是人品，尽可能不要说人坏话，不要卷入搬调事件。这个事情往往看关系，有靠山的，一般不会遇到公开拆逼，和老王八蛋同归于尽的事。但是草根很容易遇到。

+   四是主动进入大领导视线。你在底层，一辈子和科长打交道，没用。

+   五是单位里的主要业务，你的水平要中上，太差了，只能去司政后。

+   六是要进大单位，越大越好，小单位实惠轻松，但没什么前途。如果一把手才是正科，你还有什么希望？

这几条做到了，四十岁到副调以上，可以指望。

# 如何走捷径？

要当单位一把手，基本没有捷径，必须是每一步都要到位。但是，你志向不高，业务不强，就想调个部门副职，实惠点，也有抄近路的办法。要怨就，找一个岗位，尽可能高频率的出现在一把手和二把手的视线里，如果没机会，你就自己想办法创造机会。我举两个例子。

+   1，我们单位是高天上的业务部门，后勤部门是鸡毛部门，大家都鄙视。但是，我们这一届最早当处长但就是这个部门的的小伙子。这家伙的性子，那时候刚普普及电脑，经常死机，他就到所有领导家里装电脑，混的风生水起。

+   2，一个小姐妹，做统计员，的，实在是想不出花头了。她两天加班，写各种各样的统计文章，把单位里大大小小的业务情况，前后五年的对比，分门别类的统计出来，变成可读性很强的文章，领导经常需要向上级汇报工作，宣传本单位光荣事迹，她的文章就越来越受到重视，也没人和她竞争，大家对她的印象很好，自然升了。

你服不服？
