# 上海垃圾分类一个月的初步体会

+   1，每个小区只设一个垃圾点，目的是方便监控。取消了其他垃圾桶，收废品大爷很满意，不用跑来跑去。你送过来，遇到下雨天，居民就难了。垃圾分类后，一般要带2-3个垃圾桶出门，很难打卡，垃圾站距离比较远，回来就是一身缝。这几天，上海连续降雨，深有体会。

+   2，人员配置：2+1。两个监督者，站在垃圾桶附近，主要是监督威慑作用。一个是收废品外地人，专挑值钱垃圾，例如纸皮箱，易拉罐。

+   3，定时倒垃圾，早晚各一次，方便了监控，但居民很麻烦，我们以前习惯是，出门顺便带垃圾下去。现在不行了，必须早晚上单独跑一趟。这对很多不是朝九晚五的人而言，确实有些困难。

+   4，上海居民素质较高，这么长时间，至少我没有见到纠纷。
