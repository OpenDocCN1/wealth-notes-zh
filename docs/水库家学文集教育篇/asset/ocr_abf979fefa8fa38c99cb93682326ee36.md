# 什么是土豪？

很多人以为，买个宾利（奔驰），穿个名牌，买点奢侈品，吹个牛，就是人生大赢家，木耳收割机了。其实，在富奢圈内，那些一身名牌的人，往往是鄙视链的最低端。

真正的土豪就一个标准：这么多年，没听说他欠人钱的，说好哪天钱到账，只会提前，不会拖后。这才是土豪，真正的专业级土豪。例如我。

那种开个漂亮车子过来，一说就是要账期的，我一般都不见了，直接让部门经理去回绝了。
