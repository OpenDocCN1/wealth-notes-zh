# 小学教育

把数学当做语文练，背出来就行了。

刚才看了一下小学数学低年级题目，如果用中学代数工具可以很轻松解题。但是老师不同意，必须要用幼师的挪题办法体现数学思维。我也不会做，直接傻眼了。想当年，我是top1理工科啊。我可以肯定，我都傻眼了，那些幼师出来的差生肯定不会。怎么办？我发现了一个漏洞。

为什么小学数学老师会做这些题目？因为他们刷题做过了。也就是说，他们这些小学250老师也不会做这些sb题目，只不过背出来了，所以好像会做。

这些妖里妖气的数学题，出题思路很怪，一般人想不出来，也就是说，题型就这么多了，你只要多背多练，全面撒网，就肯定会了。

# 高考考题是怎么来的？

找了一些老师，关起门来出题，然后选择了一部分题目发下去考。

老师面临很大的尴尬，他们怎么凭空出题？而且要保证万无一失，接受全国学生老师和专家检验，没有漏洞。这个要求很高。一般人猜不出来的。

出题老师接了这个烫手山芋怎么办？肯定是把以前的题目改一改，看上去改的面目全非，但是内在的解题思维不能改，否则就会出漏洞，被人嘲笑。
