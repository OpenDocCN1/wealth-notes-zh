建议教育局清理队伍，坚决不能和稀泥。

# （2）孩子是未来，不是敲钱的工具

希望省教育厅和教育部领导，严查查处小学校长和教师利用职权，向家长敲钱的恶劣行径。

这种风气非常恶劣。

这么小的孩子是国家的未来，不是教师去敲家长腰子的工具。

# （3）教育局领导不难受吗

浙江省宁波市教育局领导：

你好。

每个家庭，都有老有少，你局管辖的这个镇小学的校长和教师，采取如此恶劣的手段向家长逼钱，刁难小学生，我们看了很伤心。

请问，你们心里不难受吗？

# （4）你们心里还有群众吗

浙江省宁波市教育局，你们有什么政策依据逼迫家长给小学捐款装修？

这位家长看上去经济条件不是很好。

几百元对于教育系统的人可能没什么，反正你们工资高。

但是，对于普通家庭，那是孩子一个学期的零花钱，你们忍心夺走吗？

你们心里还有群众吗？

# （5）致敬视频家长

向这位勇敢的视频中家长致敬。

我若遇到小学向家长逼钱，我个性懦弱，可能没有勇气反抗。

但是，今天，这位家长勇敢的站出来了，我深深感动。

我人微言轻，做不了什么具体的事情，就转发一下，默默致敬！

# （6）一年级就遇到成人的潜规则

浙江省宁波市教育局：

这个孩子才小学一年级，就遇到成人世界的潜规则了，不交钱就坐到最后一排的破桌子。

您于心何忍？

# （7）热心家长，请不要道德绑架

致所谓热心家长：

你自愿掏钱捐钱，你可以去捐十万，把整个小学修一遍。

但你不要拉其他经济不宽裕的家长下水，不要道德绑架其他孩子的家长。
