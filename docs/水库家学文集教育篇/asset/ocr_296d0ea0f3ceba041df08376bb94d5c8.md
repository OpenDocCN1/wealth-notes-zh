# 菜叔，给您说说最近的困惑

我是安徽二本屌丝男，大学学的土木，毕业景没去干本行，现在上海从事低端金融行业，一年平均工资七八千吧。

前两天我叔（一代进城农民工，搞装修的）来上海做法，临走前我们吃顿饭，喝高了，他给我讲来这给人做话，17天一万块啊，业主还给我投了来回的高铁票，我这一天算算还没他挣得多，难受的不行，差点哭了。

从小一起长大的小伙伴们收入情况，更是让我欲哭无泪。初中毕业的猴子和瘦子，趁着伟大的城市化进程贷款买了挖掘机，干了几年贷款还清了不止，还给他们老子也买了一台，父子齐上阵，现在都在县城买了房买了车。

高中毕业的强子搞了淘宝卖衣服和土特产，这几年挣老钱了，娶了当年的校花，跑市区买房去了。

还有一个跟我一样的二本土木屌丝男，现在在大西北项目上，过年都不一定回的来，一个月四五千，至今今年工资还没拿到，跟我一样惨兮兮。

这些天了解到的真相，给我这二本屌丝一记灵魂重锤，难受的整夜睡不着掉头拨，我都毕业两年了还是一事无成。

看在老乡的份上，菜叔给指点迷津，今后何去何从啊？
