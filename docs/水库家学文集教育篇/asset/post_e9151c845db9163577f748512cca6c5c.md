
# 二、中年人的技术可能落伍了

计算机技术，日新月异。会计审计法律金融，各种新知识，层出不穷。中年人整天忙于日常业务，家庭事务，天天算自己的 KPI 和奖金，没有静下心来好好看课本的心态了。如果业绩做不出来，销售额上不去，连做技术员的本钱，可能也不如 25 岁的工程师了。

# 四、劳动法逼得企业开人

劳动法要求，连续两次签订劳动合同，就算企业之爹了。企业不死他不走。理论上有很多办法，但实际上他不走，企业很为难。你总不能只招聘一个人，天天拿摄像机跟拍他是不是符合岗位要求吧？即使不符合，那又怎么样，企业也要培训调岗，这实在是压力太大了。小门小户的企业，养不起你没没啥利润的大神，早走早了，两不伤亡。

# 五、建议

- 1、对于劳动者的最大保护，是企业盈利，扩大就业，而不是难以辞退。如果职工走能能不退，会极大的遏制本就就风险重重的中小企业招聘意愿。现在的中小企业，老板都是朝不保夕，哪里管得了职工一辈子啊！
- 2、机关事业单位国企，每年要留出一定比例专门招聘 45 岁以上老白领。总不能把这事全部扔给民企吧？
- 3、劳动法也要根据经济发展情况，灵活应对，该修改就修改，该坚持就坚持，团结一致加油干！

- 3. 35 岁以上的人，对于吃回扣，要红包，已经司空见惯了。有个别人还教唆年轻人做坏事，根本讲不通的。

己找好定位，就不要乱溜日子。光阴如梭，很快就踩线到年龄了。

# 人生发展的第一步是

认识到自己落后了，主要原因在自己。如果你还在怨天尤人，呵呵，光阴如梭，很快就35岁了。

如何看待自己？我以前有个办法，就是找曾经关系亲密的同事喝个饭喝个酒。在喝到一半的时候，我向同事问：我到新单位了，你给我提几个意见，我以前那里做的不够好，我今后改进。哪怕你说的严厉，也是为我好。

你把姿态放低了，别人一般会说几句真心话的。

- 1. 你和他没有利益冲突了。
- 2. 你的姿态低。
- 3. 酒都喝了，鸡也炖上了，你好意思翻弃着我？

问几个人，基本就找到原因了。切记，一定要喝上几杯，把气氛搞好了，打消对方的警惕心。

# 人口老龄化，京沪反而更好

或许是经济学的残忍和无奈。

地级市县城以下，老龄化越来越严重，这就导致了消费萎缩，招工困难，那么经商办企业的人就待不下去了。大家只能去人口密集的地区，例如京沪广深，南京杭州苏州等大城市。这些地方寸土寸金，不断有年轻人带着全家三代人的存款来找出路，住房紧张是可想而知的。

东北沈阳，现在房价不足万元，八九千，还不如海南的国家级贫困县。沈阳就这水平，还是靠下面的县市人口支持才能维持，因为城里的年轻人考上学就跑了。父母一看，子女走了，自己只能卖房予给孩子在异地读学付了，你说怎么办？其他小地方，同理。

建议：索性恢复户口严管制度。人口省内流动，不许乱跑。

# 职场新人要注意

大学生第一份工作，往往几个月后就辞职了。换工作的空档期，社保怎么办？必须续交，凑满购房资格。

- 1. 失业期间，自己去社保中心缴纳。上海政策是，停缴累计超过三个月，购房资格没了，重新计算五年。
- 2. 若养老，连续三个月或者合计六个月，医保就兑了。
- 3. 养老金，退休后才可以取出来。
- 4. 购房资格，目前和公积金无关。

# 青年人就业的大方向

大部分应届生已经上班了。绝大部分应届生的第一份工作就是骑驴找马，劳动法保护我们，先安稳下来再说。我就说个身边故事。

我的外地亲戚大部分是技术人员，他们中的孩子，这些年有几个大学毕业了。能不能在京沪扎根？其实就看一件事情，父母当年在哪里就业。

外地亲戚们工作单位也是换来换去的，往往是两个方向，一是外地大中城市郊区的特大企业，一是大中城市市区上班。从日常生活看，过去二十年，在郊区特大单位工作的人，生活稳定，工资较好。在城里小单位的，生活质量大数数不太好。城里小单位的工资也不高。

我有个亲戚，当年支援外地，去了小地方，九十年代一直想回上海，但是找不到上海单位要他。无奈之下，哭哭啼啼的去了杭州老市区。杭州距离上海比较近，也算是解了思乡之苦。他们家孩子逢年过节就回上海玩，口音还是上海话，但这孩子非常自卑，因为他是乡下人。前几年，他在上海读某一本大学，毕业后没办下户口，还是外地人。因为他的口音是上海市区话，顺利找了个上海郊区老婆，理论上，户口也算解决了。

他算是比较幸运的，顺利回沪了。但是还有几个亲戚家的孩子，相似情况，但找不到老婆，说白了，其实没房子。

外地户口的子女在京沪买房是很难的。唯一的办法是，父母外地的房子卖掉赡养首付。但是里面情况不一，在外地特大单位的亲戚，房子根本没人要。这些房子有的是产权不明，有的房子有产权但不在企业内部，距离真正的市区很远，周围居民也不要。卖不掉外地老房子，子女在京沪就是个外来流动人口，这日子可想而知了。京沪姑娘谁会看你一眼啊？

在杭州市区漫日子的这个亲戚，分了一个十几平米鸽子楼，自己后来置换了大一点。儿子在上海要买中环线婚房，父亲毫不犹豫卖掉了杭州市区房子，给儿子买了首付。新房入住当晚，老亲戚大哭一场，子孙终于回上海了！他自己在嘉兴郊区买了个当年不赚钱的小房子，天天很开心。

小地方的房子，今后可能不值钱，卖不掉。而流动性好的市中心房子，实际上是现金存款。现在存了面积，将来就有选择权了。京沪省会去不了，地级市也要去市中心。父母房子真的可能改变子女人生。

今后，人口流动趋势越来越集中于大中城市。建议，年轻人尽可能去市区上班定居，而不要在地方混日子。

祝各位同学，在漫漫人生路上，走出正确的第一步。

# 今后的就业趋势会如何？

现在，各行各业的标准越来越高，护城河越来越宽了，跨界挣钱玩，已经非常困难了。子走父路，女走妈路，成为最现实，效率最高的就业方式。举例，现在的著名演员，子女越来越多的也是走演艺圈道路，张艺谋来丹舟赴本山，都是这个套路，还有不哭精，姐妹精，姐弟精，敌不胜数。

其实，不光是高收入的演员行业，医生教师，铁路国企，烟草石化，银行电力，比例是相当高的。我说的不是同一个单位，而是父子在性质类似的行业，例如电力局的儿子去考事业编。
