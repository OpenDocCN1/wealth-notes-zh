# 人和人之间，应该比什么？

比考试分数，是毫无意义的。你考满分，关我什么事请？我们应该比工作质量，给别人创造了什么价值，为社会做了多少贡献？

你设计出了优秀的作品，你就可以拿高薪。

你的服务态度好，拉单子多，你就该拿钱。

你在街上，昼斗歹徒，见义勇为，就应当激励你。

这个社会不需要自私自利，不需要只考虑自己考高分的孩子。我们需要的是，真正做出成绩，大家共同进步，一起发展的氛围。

我们的教育体系，不要再引导孩子们，单打独斗，互相小心眼。真没意思了。
