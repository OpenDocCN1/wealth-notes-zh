# 最近烦恼不已，为孩子愁死

我有双胞胎一男一女，丈夫和我都在事业单位工作，都是调过读书分配到了好单位，深知读书的重要，从小就有两个孩子读书取得好成绩才能上好的大学，可是丈夫和我都不会教育小孩导致他们极其实逆，学习成绩一直不好，厌学，现在花钱让他们补课，他们也抵触，女孩养成好吃贪玩的个性，一件事不容应，立即在家掉门扔东西。男孩也是，甚至动手！我有时真是灰心丧气！觉得生活一点没有指望了~只要一管他俩学习他俩就反感就，和我顶撞！我一次次妥协，前一两年人间着要手机，我和他们订了个约定说你们成绩提高多少就继续给你们，提高了不就收同！结果两人有了手机成绩更下滑的厉害，要收回时两人那态度极其不配合，好不容易收回了，结果发现偷偷找同学又借了手机，天天玩猫捉老鼠，身心俱疲！！为什么孩子是这般，一点也不理解大人的良苦用心？难道没有办法让他们提高成绩?爱上学习吗？

# 高考大幅度降低数学难度

是符合孩子们发展规律的。

青少年最重要的是什么？身体，视力，性格。如果想学好数学，无外乎刷题！我们当年就是这么过来的，从7-18岁，无忧无虑的不断刷题，缺睡眠，导致了很多孩子的健康受损，长期精神紧张，青少年近视已经蔚然成风，年轻人四肢不动，没人愿意干活，都想坐在办公室刷题。

不要担心什么数学水平下降。大学理工科四年，抓的一点就行了。科学生至少本科读到博士，十几年时间，够你学好数学了。我们没必要提前折磨孩子。现在的情况是，大学松松垮垮，中小学搞得身体发育都受影响，傻话吗？

建议取消高考，除了清华等十八个大学自主招生，其他一律注册制。让孩子们回归自然，坚强体魄，完善性格，为国家建设培养健康（至少不近视）的劳动者！
