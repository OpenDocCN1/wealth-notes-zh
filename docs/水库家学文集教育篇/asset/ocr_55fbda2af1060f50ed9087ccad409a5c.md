# 看透高考考卷

高考考卷的题目难度是分层次的。假设150分。

60分是基本分，学渣也会。否则，家长就要闹情绪了，这是送分题，确保学渣进高职。

30分是专门为了二本狗，降低难度的。

30分是为了选出985-211。

20分是为了选清华北大。

还有10分，是专门为了显示出题老师很牛逼而设立的，确保消灭满分。

所以，最后30分，你彻底放弃是最佳战略。
