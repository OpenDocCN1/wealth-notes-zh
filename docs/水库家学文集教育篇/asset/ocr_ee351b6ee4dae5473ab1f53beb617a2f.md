# 知识和经验的区别

知识是，具体怎么做？

经验是，这事情能不能做到？预计会出现什么后果？目前缺少一两个条件，能不能替换？老师只教你怎么做，但却不敢告诉你，能不能这么做！绝大部分非理工科的事情，老师讲的，书本上写的，和实际情况，完全是两回事。
