# 凤凰男的经济情况，其实分几种

队长家，老农民家，大城市打工家庭，商人家庭。

一，队长家

这些年轻人非常有水平。长期看父辈们和乡里老干部打交道，套路繁多，耳熟能详，待人接物，礼貌周到。他们给人的第一感觉是非常好的。但是，他们特别能踩人。一旦你要考他们的事了，搞人的手段也丰富。

二，老农民家

这些孩子不会和人打交道。特别能吃苦，忠思，码宝，往往看重老家的一些破事。遇到不称心了，就变成酸秀才了，说话特别难听。

三，打工族

这些孩子的父母，大部分是技术人员，甚至是车间主任，农民工里的 小干部。性格脾气，类似于城里的贫困户，自卑感强，出人头地愿望强烈。遇到困难，往往是一蹶不振了。

四，商人家庭

这些孩子，有钱很重。不愿意加名字的。其他和城里人接近。

当然，我说的是普通情况，也有非常优秀的。我说这些的目的是，妹子们打交道的时候，注意看对方的优缺点，如果可以接受，就不要嫌弃凤凰男。凤凰男也想抱个老婆睡觉啊！
