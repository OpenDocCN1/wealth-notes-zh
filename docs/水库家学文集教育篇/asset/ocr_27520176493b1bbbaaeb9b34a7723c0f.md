# 怎么让头头满意？

额外付出。

一般情况下，你的岗位做得再好，头头们也觉得是天经地义。就好像你点馅饼的工人，洗碗的保姆，他们再辛劳万苦，你也不会有什么感觉。但是如果有额外利益，那就不一样了。

+   1. 替头头赚面子。你要是能给头头发表几篇文章，获个业内大奖，那就OK了。

+   2. 额外干活。我上次遇到一个会计师事务所的实习生，他的领导有个麻烦，孩子下午放学没人接，他自告奋勇，天天去接孩子三个月，顺利入职了。
