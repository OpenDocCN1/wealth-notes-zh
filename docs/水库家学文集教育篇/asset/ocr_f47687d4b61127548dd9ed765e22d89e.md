# 在京沪抱怨生活的外地人

大多数是贪慕虚荣，好逸恶劳。
老家村里，二屋楼空置多年，你为什么不不住？
县城房价低，你为什么不享受大面积，努力建设老家？
葛家庄的张胖花，不要房子，你为什么不娶？
说白了，还是贪婪，好高鹜远，失败后怨天尤人。
要吃苦，谁没有一点苦难？我当年在京沪，睡觉的床上有很多蚂蚁乱爬，冬天只能在没有玻璃的厕所里洗澡洗衣服，冻的牙齿打颤。夏天在铁皮简易房里，闷热的呼吸都困难，到处是鸡臭气味。
工资850元，我去怨谁？

当年，我和梁斌在浙江乡下的小厂子里跟单，被蚊子咬的满脸包，在草厕里上厕所，臭的要吐，吃的饭菜都是没洗过碗熏的。

你们现在的条件，比我当年好的多了。至少还有浴室和空调。
谁说有经历过人生的艰辛？幸福生活要靠自己努力，而不是等靠要。那种盼望牺牲别人利益满足自己的贪婪，是不科学的。建设美好家园，从小事做起。
吃不了苦，可以回老家享福啊！

# 为什么这么多人要去北京寻找梦想？

对于专业技术人员而言，包括医生，演员，码农，教授，北京是成名成家最快的地方。只要你在北京站住了脚，等于在国内站住了脚。
对于体制内的人，在北京工作过，例如总部机关，那是一个漂亮的资历，可以回老家吹三年了。去广州工作一年，那是出差，没什么好说的。
对于商人企业家，只有在京站住脚，开了店，进了总部，才算是全国性品牌。你在葛家庄做到全市第一名，算个球啊，土老帽而已。
