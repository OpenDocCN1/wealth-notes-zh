# 读书重要吗？

你看谁，滑北毕业，当了副总。实际上，读书不是第一重要。最重要的是，你在长期读书的过程中，形成超强的意志力，自律性，逻辑性，这个才是成功的秘诀。很多人没有读过大学，在其他道路上，例如打铁，下车间，做农活，在长期的实践中，也形成了强大的自律性，吃苦耐劳的品质，最后也成功了。

你去看那些大将将军、黄埔军校，是短期培训班，强迫算小中专，保定军校读四年，算中专，这就是第一流了。很多人就是小乡文化。唐耀涵是法国本科，孙立人是美国本科，孔祥熙是美国博士，那又怎样？还不是输了。孟良崮之战，张裕是师范中专，张灵甫是陆大本专科，黄百韬是高中，李天霞是本科语言学。

结论：不要迷信学历。重要的是，脚踏实地，干中学，学中干，向群众学习，向市场学习。

# 为什么要学徒三年？

第一年，不学技术，给师傅做杂务。经济学上看，师傅剥削徒弟。但实际上也有另外一层意思，从自由散漫的青年生，过度到职业生涯，心态就不不同了。你能不能忍受职场的空气，雾霾，怨恨，基本上通过第一年的磨性子，可以调整为职场心态。

第二年，干粗活。干粗话是口语，精炼说法是，重复劳动。无论学什么，都有个重复劳动的过程，例如学厨，杀鱼杀鸡，没有一毛钱的技术含量，就是干一天到晚不停的干。这一步，也是师傅剥削徒弟的免费劳动。但是，实际上是将你适应这个行业的工作氛围，激发你今后学细活的兴趣和积极性。

第三年，千辛万苦走到这一步了，自己也会珍惜专业学习的机会，否则，前两年的白苦了。这叫“沉淀成本”。这词洋气吧？

结论：任何经济学术语，其实就是老百姓的大白话，唬人的。
