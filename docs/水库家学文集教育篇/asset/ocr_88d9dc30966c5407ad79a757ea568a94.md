# 上海富人的日常生活

在上海，任何开放式厨房设计，都是群里房里的设计师干的。

这种人没有实际生活经验，完全是看电视刷，意淫富人生活。

上海富人的日常生活，其实和白领差不多，只不过，吃的好一点，房子大一点，车子好一点，时间多一点；家具贵一点，老婆漂亮一点，孩子在国际班，保姆多几个。和你家差不多的。

# 为什么穷人没见识？

我也是穷人过来的，谈谈感受。刚刚到内环线上班的时候，还租过联君房。某年冬天，玻璃碎了，冻了一个星期。所以，我当时认为，冬天住在曹杨三村，就是人生的最高目标。

富人买了好东西，享受一些奢侈，是不会告诉穷亲戚、穷朋友的，但会和其他富人分享，小到包个游艇，大到美加澳买房，各种细节，互相交流。前段时间，我买了个好东西，就告诉了几个小富家庭。同理，他们有什么好东西，也会告诉我。逐渐的形成了一个相似消费的信息沟通平台。

我的零花钱，买飞机购票不行，但买个好东西还是可以的，例如买个上海别墅，小区楼上网，这个倒也不是什么大事情。但是，我很有意识的，不愿意去刺激亲戚的。即使被他们知道了，也是轻描淡写的说，贷款付，没花多少钱。

这就导致了一个尴尬的现象，越是贫穷，越接收不到信息。于是，穷人们也开展了自己的信息平台，哪里打折了，哪里促销了，哪个时段的博物馆免费啦！慢慢的，我们越来越远远了！

愿你出走半生，归来仍是少年！

# 为什么少数穷人特别势利眼？

因为富人不需要势利，大家等价交换，还是朋友。

穷人没什么拿得出手的，只好去可以巴结，希望脸上被甩到几滴肉汤汁。但是，巴结别人，是很扭曲人性的，时间长了，心理都有问题。

富人巴结别人也没用，人家和你玩，就是为了等价交换，不是听你来吹捧的。

# 穷人家的孩子不应该胡思乱想

穷人家的孩子应该有理想，但是不应该胡思乱想。摆脱贫穷，需要一步一个脚印的去努力，而不是好高骛远，不切实际。对于连五星级大酒店也没住过的穷人家孩子，一上来就要办个旅游公司，实在是荒唐。

我觉得，老阿姨们的说法是合理的，先努力找一个工资高一点的工作，养活自己，养活父母，积蓄能力和经验，在合适机会去创业，从小生意开始，慢慢来，一代人能够上一个阶层，就是巨大胜利。

不要指望一步登天，童话都是骗人的。除非买了内环路的房子。

# 富人往往容易更富

假设，300 万，在某外环小区投资一个餐馆，即使失败率是 90%，富人如果感兴趣，完全可以接受。

而穷人往往无法接受高风险，绝不会参与。穷人对于 90% 以上成功率的时情，还会极度犹豫焦虑，这种咨询心理导致和富裕没关系了。不是嘲笑，而是事实。我以前就是穷人。
