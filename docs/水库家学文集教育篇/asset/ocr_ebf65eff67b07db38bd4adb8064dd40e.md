# 我们的教育理念

应该适当调整了，不要再鼓励二本子去坐办公室了。

现在的二本大学，一天到晚鼓吹：你们是大学生，你们很优秀。优秀个鸟啊。二十年前就是找校生的破料子，现在耍潮萃了？实际上，大部分二本子毕业之后，房子没有，老婆没有，钞票没有，干活怕累，赚钱嫌烦，就想喊几句大词语，分了别人的房子，打了别人的浮财。

我们应该鼓励大学生，向群众学习，向干重活累活的劳动人民学习，深入建设一线，流大汗，出大力，而不是在空调房里喊大词语。二本子的公平，其实就是别人给他白干活，盖好房子让他住呗，为什么？我会刷题，刷题，懂吗？我还！
