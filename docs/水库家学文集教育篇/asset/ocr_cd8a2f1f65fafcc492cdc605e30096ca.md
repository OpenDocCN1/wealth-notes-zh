# 有一半的孩子，没有参加高考

中国每一个年级的孩子大概是 1500-2000 万。但只有一半的孩子报名参加高考。没高考的是哪些人？主要是底层青年，特别是农村乡镇的孩子。这些底层孩子的生活坏境，纷繁复杂，很难有个良好的环境，能够让他连续十二年反复刷题。明知道考不上 985，二本也没用，索性不读了。

# 做个快乐的包工头吧

除了少量高精尖的项目，绝大多岗位，小中专就管了。打个基础，中学学，学中专。

红旗渠的设计师就是五十年代的中专生，创造了世界水利工程的奇迹。现在很多省分行的行长，也是原来银行中专毕业的，也不错的。

我们现在过于强调读大学，完全是 98 年扩张的后遗证。你看腾盛村的张二狗也读二本了，咱们不能落后。就这心态，最后，大学生多的用不完，各种单位就开始挑学历了。反过来又刺激大家考研，其实真没必要，我看过大棒几百篇近期的硕士论文，大多数是粗制滥造，毫无实际意义。

市场经济，不要太看重学历，如果你不是当导师的料，抓紧学个手艺，以后创业。会来事的，会说话的，考个正式编制。

前两天，遇到一个协和医学院毕业的博士医生，合法收入也就是二十万左右，一天到晚也忙的上火，各种各样的考试也多，还不如当个快乐的包工头。
