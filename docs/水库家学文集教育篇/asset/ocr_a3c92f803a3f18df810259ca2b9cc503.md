# ## 说个有前途的农二代

我在返回视频上看到一个河南农二代，在非洲当英语翻译。这种工作不差的，也就是五百个专业术语到顶了。他一年回国一次，两个月，一边工作，熟悉当地情况，一边宣传自己，坚持不懈发视频。

这个小伙子，今后有前途的，可以成为六培老师，甚至成为新公司的合伙人。但是，这活太辛苦了。夫妻分居，还在这么艰苦地方熬了五六年。

大部分屌丝根本做不到这个，还要叽叽歪歪的说一大堆。

我工作了这么多年了，也知道，给大部分屌丝，是一辈子也不可能赚大钱的，我只是希望个别人看到我的体会，有所启发，这就够了。你过得好不好，和我无关。

# ## 什么叫服务消费者

今天某私信我，他们小区 1500 户叠加别墅。因为楼板太薄，1.8m 床垫是搬不到二楼的，必须从窗口抬进去。每家二楼有两个床垫，收费 400-500 元。其他大件，另外算钱。无人竞争，做完这个小区一年能有 100 万，去掉一部分交际费，你懂的，赚个 60 万不是问题。零成本，就是出点力气。这就叫做服务消费者。

# ### （精品）

防止农二代沦为城市下岗职工。

普通制造业真的干不下去。年轻人不想来了，或者想来也来不了了。怎么回事呢？

内地农民工主要是两个去向：建筑业和制造业。建筑业很艰苦，脏乱差，招工更加困难，但建筑业没有外资竞争，成本高了就涨价，有能力开出非常高的工资招工，接近美国一般工人的七成。所以，现在的温州莆田猎港对于出国打工，已经没有兴趣了。

制造业是和国际贸易密切相连的，没有能力像房价那样涨，工人工资，这几年就涨不上去了。工人是很聪明的，当然更愿意去建筑工地拿高工资。

现在，制造业主要还依靠 35 50 岁的农村妇女熬日子，因为制造业也有几个优势。

一是室内工作，大多数是标准化厂房和宿舍，比较干净。建筑业是室外工作，很辛苦。

二是危险性。建筑业网上网下，到处是钉子，有一定危险性。工地死个人，司空见惯。工厂很安全。

三是体力。很多女性没有能力承受建筑业的风吹雨打，只能去制造业。

无论是建筑业还是制造业，都有一个共同特点：工作地点在偏僻乡下，集中住宿，夫妻分居。这对于四十岁以上的老一辈农民工，完全是习以为常的。他们在城市里没房子，孩子在老家农村。无需集中住宿，吃饭洗衣服还方便了。但对于 25 岁以下的农二代，很多人已经无法忍受了，俗话讲，吃不了苦。
