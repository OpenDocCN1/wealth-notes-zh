# 民企和大单位处理人际关系的区别

大单位是讲关系的，你是谁的亲戚，谁的关系进来的。有关系只是入门，还要会做人：对部门经理要会拍马，对手下要摆出各种架势，反正不管是 985 博士，还是德州职业学院毕业，大部分时间是在研究怎么处理人际关系。

民企不讲究关系，不讲究学历。老板请你来，是为了提高企业利润。你能够为企业提高技术，扩大市场问题，你就是老板的恩人。如果干不好，你就滚。企业没钱养你的。所以，民企的骨干都在研究把事情做好。

# 用一场艰苦的战斗，迎接中年

你在四十岁的时候，如果升值不值，我建议应立即停止手头工作。

参加一个本行业最难的考试，准备两年；把所有的知识点，彻底洗一遍，确保今后 20 年，你可以“有经验+新知识”，迎接下半场的人生挑战。
