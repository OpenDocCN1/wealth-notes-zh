明明是一般水平，但在班上听话的孩子，老师就经常性表扬，把孩子哄得以为自己了不起，非要练下去。

## 不要过分的提前教育

- 一、家门口的艺术班
你就是花点小钱，让孩子感受一下艺术，千万不要以为这些职业院校淘汰下来的业余人才，能够让你的孩子走上专业道路。真的要学专业，打比赛，去音乐学院和舞蹈学院，找副教授。一年十万起步。舍不得钞票，就不要胡思乱想。

- 二、英语班
我孩子报了一个英语课外班，我去听了一次，立马不去了，那老师大概是农村来的，发音非常含糊。

- 三、语数班
不要过度开发，认几个字，就当玩，不要一本正经的上课。

儿童成长是有规律的，儿童大脑发育有个过程，没必要提前抢先。绝大部分儿童的记忆力非常好，很容易让家长误以为自己孩子是天才儿童，我小时候还不认字的时候，有些教师子女已经可以背唐诗一百首。但是，他们这种提前教育，效果一般，到了五年级彻底没有任何优势了。

小学一年级确实很重要，但是，这种重要性不是学习成绩，而是学习自律性。幼儿要培养一下学习习惯。例如每天晚上，固定半个小时讲故事，学习。养成习惯，学多学少随意。这个习惯养成了，以后过渡到小学就容易。

## 我家孩子上了补课谈，也没用？

我以前给副总的傻儿子补课，采取的是体系教育法。我把整个物理课的结构图画出来，然后，我们讲每一个知识点在这个结构图中，处于什么位置。这个知识点的最后两个点，是什么内容，建立一个完整的知识结构。然后，老师教各个点，这样才有用，孩子也知道这个点是什么意思。否则就变成了难题解答。这个题会了，下一个题还是不会。

美国的高考制度比较灵活，数理理化等那学，但他是统一卷卷，而是分类卷卷。

你考哈佛大学英语语文学专业，高考数学期大概是初中数学初二下学期。

你考麻省理工学院系专业，高考数学期相当于华师大数学系一年级的题目。

建议：

- 1. 高考试卷分档分，高低难度分开。
- 2. 传统高中不变，你家孩子可以继续读。
- 3. 增加特色高中，提前进行学科继续，主要针对二三本。
- 4. 教改目标是，毕业就能干活。而不是搞一群啥也不会毕业生，直接推向社会。个别大学还为了就业率，废废制假，自欺欺人。

人丑就该多健身，多打扮，缺啥补啥。读书的目的是，看懂世界，顺势而为。一本书接着一本书的读下去，那是乡文化站的看门老头。绝大部分人的父母不能教给孩子什么立身处世的知识，孩子成年后，完全不懂社会的运行规则，自以为甚，头破血流。这时候，年轻人确实需要读几本书，聆听智者的思路，揣摩大师的想法。

读书是进步的阶梯，但不是让你和高尔基，萨缪尔森这些老家伙硬冲一生。上了楼，老椅子就没用了。你要寻找新的阶梯。在更高层面上，往往没有什么现成的经典书籍。大家都是聪明人，你读过的，我也读过，没什么稀奇的。

钥匙都是特殊的。人生阅历，读懂人性，个别经验，才是打开财富大门的钥匙。在高一级的层面上，没有什么普世好办法。不要以为“读了论语”就可以当官，“背了盐铁论”就可以发财，没这么简单。读书适可而止就行了，要用读书形成的经济学思维，去积极探索财富世界的奥秘，顺势而为，形成自己的打法。

普通人往往会陷入两个铁锅。

一是自以为是。一天到晚嘴炮党，论证这个事情有风险，那个事情指不发财。啥也不敢做，一天到晚，骂别人是贪官奸商。

二是故作非为。什么都敢干，辞职炒股，首付去买比特币，买房去捞沉 p，最后一地鸡毛，躺在地上睡。

合理的做法是：多想多看，谋定而动。既不要贪图“最低点吃到最高点”，也不要吓的一动不动不敢动。你不要和别人乱比。在上升波中，你吃到属于你的那一小段利益，可能性是很大的。

看书本，适可而止。看经济，用无止尽。

## 对家长的三个小建议

首先是学习成绩。今后，本科烂大街了，必须是过一本线。好单位就看齐这个。再过十年，二本狗主要是去小公司当会计和销售了。

第二是兴趣爱好。兴趣爱好，不能过多挤占学习时间和精力，时间安排要相对灵活；又要兼顾实战和儿童兴趣。我推荐艺术类，例如造型，色彩，绘画，雕塑。举个例子，我们一起开厂做滑板车，都是成熟技术。做的好看就可以发财，不好看卖不掉，就倒闭了。

吹咣弹琴，非常熬时间，成为专业苗子，至少三百万投入。如果不是上音乐学院同岗位的苗子，看看就算了，适当玩一下，别太当真了。钢琴十级就是个废纸。你二级说十级，也不会有人去查你的人事档案。

第三是心理健康。孩子的成长道路上，心理健康是非常重要的。我是失败的类型。我以前太注重名次了，输不起，一度失眠严重。后来辞职了才解决问题，现在睡到自然醒。

## 中产最大的焦虑在子女教育

中产有个无解回撤的问题，他们的赚钱之道，是无法传承下去的。机关事业部全国数医生，都需要层属考试。特功好的单位，录取还要公示结果。三本大专学历的中产家庭，很难进省级银行，二甲医院都不行。那子女今后怎么办？这就焦虑了。

现在好单位的人事科长，也有学历规划，你至少是 211 本科，相对好一点点专业，理工大学 的文管专业，农业大学 的法学系，基本没缘，不知名的小地方本科，考究京广深的公务员，还是有点难啊！既然路路明确了，那就刷题吧。

京沪初升高，淘汰一半。高考 211 以上，25%比例，也就是说，你要在同龄人中成为前 10% 的人，才有机会获得好的大学和业，端上银行铁饭碗。

京沪广深的孩子，要成为全省成绩前 10%同学，可真不容易。区重点中班级的前 20 名，皆高班级的前 3 名。家长就疯言了，孩子也惨了，一起焦虑了，怎么办？

- 一，扩大中国国际化教育，让有钱家庭去国外读书，不要和中产抢 985 名额了。大家都轻松一点。
- 二，提高私企的盈利能力，大家不要挤到有限几个的好单位，铁饭碗，例如银行烟草公司。
- 三，垄断企业岗位市场化，例如，每个人五年参加一次岗位考试，淘汰 5%？这样的话，大家就少一点焦虑，就业歧视也大大缓解了。

## 职业教育

不是把成绩最差的学生拎过去放鸭子。

我们把最差的学生弄去搞职业教育，这还搞什么？不如直接上班算了，师傅带徒弟，学多少算多少，还早点赚钱买房了。我们以前推广职业教育，不要十八岁就上班，那是因为当时就业艰难，大下岗，现在不是这个意思了。

现在是缺乏劳动者，制造业要再发展，必须精英教育+职业教育。除了 10% 的 985 富村生，其他学历一律格式化。高职一本二本，全部一锅烩，就一个教育局的本科学习证明就就行了，不要再区分什么学校了。反正都是当员工起步，干得好也可以提拔工程师，劳动吃饭光宗。

你要是读书厉害，你去读 985，高精英，理论研究，我就混个本科。社会分工就不需要那么多高精英，一个人设计，一百个技师也不一定能够做出来。要那么多连车床也不会开的工程师干什么？一天到晚就是张嘴，你有本事做一个我看看？

## 高考只是淘汰赛

选什么课程，目的是为了 pk 你啊。选物理的人也不一定喜欢物理，只是为了高考成绩最优化而已。大部分人初中毕业就可以了。大部分医生教师，公务员和工程师，现在连初二的教学都不一定会做，这也不影响我和你的生活。

我们的社会分工决定了，99%的人只需要重复操作一些动作就行了。你把鸡翅做好就是一辈子，你把塑钢门窗做好也可以买房。为什么要那么多设学习天赋的人去学非常刁钻的数理化选题，然后再花十年去忘记？我们就不能学修车拉吗？

我就非常赞同德国的职业教育，德国的教育系统核心，不是职业教育课程，而是职业教育和大学教育平等。（公众号：财宝主讲经济）我们现在搞学历歧视，不是本科，基本不可能进公务员和烟草公司，这就把职业教育彻底断送了。
