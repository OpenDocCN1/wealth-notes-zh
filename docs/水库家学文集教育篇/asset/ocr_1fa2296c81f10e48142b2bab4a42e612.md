# 年轻人要为 35 岁考虑

某大厂，工作八年一律解雇，重新录取。公司顶部大头也不认识你，说白了就是公司小头头考核你。如果小头头不喜欢你（总有一部分），你就人生到站了。这时候，上有老，下有小。一家人和房贷银行都在等你拿钱回来开伙。

35 岁很快就到来。不能年轻时稀稀里糊糊涂了。怎么办？

年轻时候一定要有有意识，结合自己的条件，谋个副业。一旦失业，可以立即开辟新天地。搞什么副业？我也不知道。实在不行就去学个葱油饼吧。这个也很难学的。有个人被骗了八万元也没学到真配方。

# 幸亏员工机智过人

因为离职补偿被企业谜进去蹲号子大半年，幸亏员工机智过人，靠一个私下录音救我，实在是太巧合了，这个员工命好，否则不敢想象会是什么下场。建议个别企业重视自己的不足，积极解决问题，而不是对围观群众上纲上线，一棍子下去，破口大骂。

# 中年人了！

**根慧**：你对未来有什么计划？现在最大的诉求是什么？

**李洪元**：（从华为离职后）我没有其它工作。我今年42岁，不适合去公司应聘，更适合创业。我在新宁所里遇到很多跟我有类似经历的人。不敢说他们很疯狂的，但觉得能做点什么。我希望未来能做做一些跟司法平台相关的工作。

我现在最大的诉求就是与华为高层达成一次沟通，但我们之间没有沟通的桥梁。我的社会地位无法和他们沟通，我在想是否能够借助更大的资源来促成这件事情。当然，这裡有我的一点私心在。
