# 小孩子还是要去幼儿园

现在，有些神奇家长，自以为是，觉得学校学的知识没用，不如自己教的。其实，这个很是愚蠢的想法。学校的课本知识确实用处不大。我现在初中底数学也不行了。但是，孩子们在学校还要学习集体生活，人际关系，互相斗争，各种朦胧也要看一看，例如偷东西，作弊，欺负弱小，拉帮结派，看看老师的褶子。

只有经过了这一系列的人生履历，这个人才格才基本塑型完整。自己在家教的，纯粹是在封闭空间长大，毫无意义。
