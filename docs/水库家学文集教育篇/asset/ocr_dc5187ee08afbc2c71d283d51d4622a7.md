# 中产操心的是教育

中产最大的烦恼是，辛辛苦苦一辈子打下的事业基础，不能传承。教授医生律师，程序员作家是中产收入人群，他们的收入来自于技术和职称。这个东西不能传承。如果他们的孩子不能考出个资格证书或者 985 硕士，他老爸就算是总行副总裁，985 校长，三甲院长，也不好意思招子女进来，更没办法给予子女发展稍路。

中产们长期脱离社会底层，他们只喜欢职务，技术和高薪，对未知事物和不确定因素，充满紧张不安的情绪，让他们眼睁睁看着子女在社会上上游荡，心理上是难以承受的。为了解决传承问题，中产对于女教育已经疯狂到无药可救了。

我劝这些朋友们别太紧张了。体制外的世界，并不是你想象中的充满危险。体制外也是有大量机遇的，不一定比当医生副教授强。

父母只是孩子成长阶段的一个同路人，之后的人生是他们自己的了，你也别想太多了。孩子能够读出来，自然是最好，如果读不出来，那就务实一点，让他练个靠家箱口的技术，哪怕是做个小生意，也是可以的。

为人父母，还是先严格要求自己。跨腿躲避打游戏，就不要搞了。多攒点钱，锻炼一下身体，老了别给孩子添麻烦，就好了。

只要你尽心尽力了，至少留个五十平米，孩子们不会怪你的。

# 留学回来有用吗？

一半以上的博士可以在地级市的高校，混个正式编制。其他情况下，确实没用，就当是旅游吧。我是老留学生了，这个事情我在十几年前就发现了。原因：

+   1，体制内，不是特别在乎学历。

+   2，体制外，需要真本事，或者肯吃苦。这和留学没有一毛钱关系。举例，你是学外观设计的，老板可以给你半手机会，你给我搞个爆炸头来。若可以，你就是副总经理。若不行，滚，没用的东西，浪费粮食。呔哑哑！
