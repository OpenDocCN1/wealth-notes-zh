# 再好的小学，也有的是差生

小学生的成绩，主要是看家长的辅导，而不是学校老师，很多人以为，一般学校可能会有很多卖菜的，卖鱼的小贩，也在里面读书，感觉档次下降了。这个担心在小龄阶段是不必要的。

首先，能够在北京，上海，广州这样的大城市读本地小学的外地人，一般都是有一定身份的，真正的卖菜的孩子是比较少的。

第二，现在的农民工家长，对小学生是有极大的希望。家长千辛万苦把孩子弄到了北京上海这样的小学，绝对不是为了让他在里面混日子的。很多外地人家长对孩子学习的辅导，可能比一些上海白领更上心。

第三，往往是到了初中，有部分家长才决定放弃孩子了，我们一般不需要担心小学。重点小学的孩子打架，也是常见情况。

结论：不要刻意考虑小学的学区房。

# 初中和高中最差生的区别

我这几天得到一些信息，令人惊奇地发现，初中倒数第一小王，居然混的不错。而高中中的差生普遍不行。（没有普遍意义，你就当看个小故事）

小王现在是电话手机公司下属的承包组，具体干什么不知道，看上去贼有钱，同学聚会费用全包，但我因为档期原因没去，听说的。读书时候，他比较佩服我的学习成绩。毕业后，再无具体联系。

小王现在应该叫老王了。他是真的成绩差，差到了只能去最尴尬位置的洗盘专业，某厂技校厨师班。我们初中班上最差的学生都去这个班。我读高中的时候，他在附近一个房子里切肉丝，我是亲眼见过的。

但是，他也有优点，脑转码，身体好，眼睛好，他是我们班上的群情大王。小时候玩几毛钱的赌博，他都能赢钱。他喜欢偷小东西，不偷同学的，就是偷辛路边的废铜烂铁，卖钱。因为废铜烂铁很重，他就去开锁别人的自行车，用自行车载货去卖，卖完了，他还把自行车回去。他身体贼棒，打架不吃亏。

毕业后没有做厨师，去了个没有编制的小公司打工。因为是上海人，聪明，就当了农民工的组长，后来拉队伍单干，现在发财了。

另外一个差生小李也是去厨师班，那时候我们把厨师叫做“饭乌龟”，没人愿意干。他后来去了日本打工，现在在已经是一个不错的日本餐馆老板，我也不知道他是那么拿到居住证的。后来找了个如花似玉的985留学生老婆。

搞行情经济的时候，我还念书，小王小李已经混社会了，聚一波摆酒会，做点小生意的上海人，大多数是赚钱的。那些年机会多，干啥都行。后来这批人中分化了。有些人吃喝嫖赌败家了。有些人乘势而上，例如那个鸡翅杯大帝，也是那个年代的，至于矮矬滴出小矮滴成大侠的，数不胜数。
