# 通过养老金制度

把大量社会财富，从年轻人手里拿过来，发给部分退休老人。现在退休职工的工资高于上班的大学生，已经是司空见惯了。看上去好像只是财富分配问题，实际上会导致经济结构畸形。

钱在不同的人手里，就会决定消费导向。

年轻人喜欢苹果手机，这会刺激科技发展。

中年人喜欢子女教育，这会刺激教育教学市场和读大学的消费。

老年人在终老之前，最大消费就两个：买长生不老药，投小本赚钱。问题是，这两个行业基本是骗子当家。如果全社会的大量财富，越来越多的集集到退休老人手里，等于是养话骗子行业。

我家门口的长生不老小店，开了近十年了，生意好的不得了。三天两头的健康讲座，发小袋养生大米，卖高科技床垫，还有小姑娘上门给你洗脚，陪去医院，最后搞个一个大钱走人，好多老年人被搞了还被，不敢承认自己愚赛。

投资理财更搞笑了。有些话不能多说，你去看官，一屁股坐在地上干嚎的是些什么人，大家心知肚明。邮政门口排队买理财产品的，基本是退休老太。

建议：迅速提高农村老年人的养老金，最少最低工资的平，至于那些养老金很高的老年人，适当降低一点吧，和谐。

# 社保（养老金）为什么减不下来？

社保的本质是：这代人养上代人。现收现支，略有结余，有的省已经亏空了。也就是说，需要支出多少钱，就要收取多少钱，否则，退休人员的工资就发不出来了。
