# 二胎后，女儿还会有嫁妆吗？

 近年来，大城市女性地位较高，主要是独生子女的原因。绝大多数女儿最后肯定能够继承一套房子，这就不得了了。现在二胎了，最大的难题是，一儿一女怎么办？

 大城市房价非常高，一般家庭买得起一套市区100平米就很好了，买得起两套的，凤毛麟角。子女结婚时候，老夫妻五十多岁，也不存在赡养房子的可能性。

 这就导致了一个很大可能，京沪的二胎女儿可能没嫁妆了，二三十万一脚踢。奇葩公婆甚至还要为儿子买房，索要彩礼，兜售高价姑娘。我们不要想当然的认为京沪就比农村人思想先进。

 与此同时，压力同样转嫁给了男方。女方如果有弟弟哥哥，除嫁妆基本没了，也不可能两家合力出资，男方必须承担所有的买房压力。男性结婚，也就工作五六年后，哪里买得起房子？归根结底，所有的压力都落到了男方家长身上。你儿子几岁了？倒计时开始！

 京沪八九十年代，因为没有房子，导致了多少婚姻不幸。我们还是后历历为目的，希望这一幕不要再重演了。建议：大城市，特别是京沪，为年轻人大力建设婚房和教改房，起步就来个五十万套，无偿或者超低价卖给年轻人，为二胎化添砖加瓦！

# 京沪首付变成了比亚迪

 我有个外地省城朋友，大学教授，夫妻两个收入较高，在省城买了两套漂亮小区。每套价值400万左右。他们就一个女儿，现在10岁左右。本来打算是，两套房子在女儿结婚前还完贷款，卖掉一套，给女儿在京沪当首付。

 前不久，二胎一个儿子了。现在的口气是，一套自住，一套给儿子，女儿结婚给个车就算了。这个女儿真倒霉，京沪首付变成了比亚迪，我谁说理去？不仅仅是将来，原来女儿上兴趣班，出国游，买漂亮衣服，眼睛都不眨的，现在扣扣搜搜了。
