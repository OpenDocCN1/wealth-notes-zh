# 西欧美国的教育体制

公立学校基本放开，同时注重培养孩子的生活能力，例如做饭，做家务等实用技能。少数精英家长花巨资送孩子到私立学校，从小培养考试。通过金钱和考试，两个门槛，把孩子培养成为 20% 的精英。

这对普通家庭确实有一些不公平，但对整个社会是合理的。社会需要的是大量身体健康的普通劳动者，而不是只会考试的近视眼。

在欧美，普通劳动者的收入不低于教授讲师。所以，不想读书的工人家庭孩子，也不觉得有什么。现在京沪的体力劳动者，例如装修工，送快递，收入基本和一个复旦讲师也差不了多。这个路子是可行的。只不过，你读书少，意味着面子小。但是，劳动最光荣，职业没有高低贵贱。对吗？你想成为大富大贵，其实不愿读书。马云也是个二本师范生。

# 教育减负

+   1. 几十年的竞争性教育，导致中学生普遍基本都是近视眼，体质差。一辉美国华裔学生和一群内地高中生，在你机场遇到后，不用说话，光看肌肉和体型，就可以百分之百区分。
2. 这个社会 80% 是普通劳动者，不需要锻炼身体拼分数。大部分考试对你的人生，基本没啥用。李自成哪一年进京，线性代数，化学分子式，小球抛物体，就算不睡觉背出来，又有什么意义？
3. 难点是，谁来当 20% 的精英？大家都不服气，教育部还组织高考中考，于是大家都知无意义，还要跳舞身，让孩子拼成近视眼。
4. 这不是教育局能够解决的。

# 菜菜，我有个困惑
