# 就是四个字，提前教育

太恐怖了，来自于水木社区网友。

![](bbox=[0.11, 0.34, 0.45, 0.42])

闺女中考考的不低，558：终于和早培班、创新班、2+4站在同一平台上了。

暑假，初中班里同学有去美国日本玩的，有去北极玩的。闺女被我按住了，在北京上了72节课的托福班，又自己被导学学习了高中数学必修一、必修二。因为心思被同学游玩吸引了，整天到班，高中物理、化学都没提前预习。

9月份，高中一上课，开始哭了：在北京最好中学之一的实验班，老师是以早培班、创新班的小孩的水平讲题的，并以此布置作业。老师讲课，课本基础概念大约讲5分钟，然后讲大盘的竞赛超强题。以化学举例：讲到Cl、Br、I、S、N全来了：刚讲到HCl；硫酸、磷酸、硝酸、碳酸全部进入体系；刚讲到金属；Fe、Al、Cu，甚至是SiC、CuH，都冒出来了，感觉好像是用2-3个月时间，把高中无机化学全部学完了

同理，英语、数学、物理、生物、地理；语文、历史、政治高中的大面积量和记忆，也成为观止。

直接导致后果是：孩子听不懂老师讲课，课后习题也不会做。包括政治题，“有限责任公司”“有限合伙公司”的区别。“混合股权公有制部分”等等都是新知的。

上上周是高一期中考试：语文、数学、英语、物理、化学、生物、历史、地理、政治，9大学科，总分1050分，全科比掉，

上周五，女儿优郁地告诉我：初中同学里属第二名，也考上实验班的男孩，竟抑郁症休学了；班里前三名的女孩，也是去北极玩的女孩，这次期中考试，2科在班里竟倒数，已经对高中学习绝望了；

而我们，语数英三门主课，因为暑假付出，在实验班咬牙坚持在了前10；

物理、化学、地理3门课，全部倒数，女儿整天叫唤我工作，回家！老师讲课听不懂，每天回家后靠翻书。

新高考制度，3+3：语数英3门必修课，+3门选修课，但是并不知道自己到底落在哪3门，所以，高一-3门课，齐头并进。
