# 普通人高考 985 的秘密

按照读五年，来规划高中，甚至六年。

安徽的农村高中培训，在上海热到连报名电话打不进。这是高考分数论的结果。这些高考工厂，我们二十多年前自己已经走过一次了，对青少年是一种高度的健康摧残，批量的制造小跳楼。

我有个一直不愿意谈论的秘密。我当年读 top 大学的时候，有几个教师家庭的孩子告诉我的。把三年高中读成五六年，绝大多数智力正常的孩子，是可以考上一本的（现在叫 985）。我们当年的高考政策是，大学录取了，你若不报到，第二年就不能报名高考了，所以，有些教师家庭里，故意不报大专，只报本科，甚至是只报一本。他们好些人都是复读考上 985 的。

但这有意义吗？我们需要这么多刷题机器吗？真是悲哀。

考 985 建议：

+   1.  把高中按照五年进行规划。你家儿子养了十八年了，多养两年又如何？
    2.  在正式高中里，各门功课要求踏踏实实，理顺知识体系，不求难题怪题。毕业后两年，找个高考复读班，专门练刷题，刷两年，刷到熟，刷到进考场就像去体检一样轻松。考个一本 985 是大概率。
