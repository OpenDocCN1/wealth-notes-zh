+   三，禁忌
不要涉及宗教，迷信，腐儒，伦理，色情，黄赌毒，你就玩点家长里短，最好是婆媳干部，农村婚礼。

+   四，坚持一年
第一年是实验期，你看看，那些话题大家喜欢，哪些写作方式比较顺手。
认认真真的干一年，每天保证三个输出，全职操作。成为一个冉冉升起的初中级明星，不是梦。

# 做新媒体商业号

必须是全日制打法。
大部分做自媒体是三分钟兴趣，业余时间玩玩，有事儿去搞，没事搞两条。这种做法不可能成功的，就像一个业余运动员，既考不上清华，也进不了省队。两头不靠，浪费芳华。
我决不是劝你辞职，而是告诉你：任何成功，都是厚积薄发。一万小时定律是必须的。你一天六个小时键进去，搞一年，必有小成。围绕运动员，一天训练 12~14 小时，坚持八年才能进入职业二级。
你一看要六个小时，可能搞啥啥的一下就麻木了。实际上，六个小时还不一定够。我告诉你这六个小时怎么安排的？

+   一，阅读其他热门权威账号
不是让你去看热闹的，是归纳今天的热点新闻。自媒体，本质是娱乐，大家喜欢看什么，你就写什么。今天是婆媳矛盾，那你也写一条。明天是情人节，那你也写一条。归纳今天的热门，仔细研读各种细节，找出你的题目，一个小时可能不够，两个小时才正常。财经类，新闻类，历史类，文学类，都有一些官媒网站。

+   二，写作或者创作
这个因人而异。写一个五百到八百字的微博，结构清晰，字句通顺，也不容易。要写出精彩转折，难上加难。写三条，修修改改，大概是两个小时。

+   三，分析读者反馈（新号是四处推广）
千万号写好了，怎么把微博推出去？新号往往没人看，你找些办法推广。推广非常累。
1. 找到你的基本盘在哪里：一般就在同类型的热门大号那里，你可以在大号下面评论，写优质评论，但不要骂人家。你骂就容易被拉黑了。你就和将来的粉丝基本盘彻底断斩了。
2. 通过优质评论吸引读者者点击你的账号。
3. 阅读粉丝反馈，在有一定阅读量的基础上，多多少少有点评论。看看大家有什么需求，你及时改进。
这套大保健下来，六个小时是非常紧的。你要是熬得住一年，恭喜你，你干掉了99.9%的竞争对手。你看看看你的微博，有几个人关注住"十年的全天候，高产量"？微乎其微。
你不要羡慕别人日进斗金，你也可以的，问题是，你能不能像一个园林运动员那样熬一年？
