# 未成年孩子要不要送出国留学？

答：未成年就出国 的孩子，从身体健康角度看，肯定是好一点的。体育馆炼多，食品卫生好，功课不忙，近视眼少，大部分人心理健康，但也有缺点，脱离了中国文化，回来就麻烦了。

中国人的传统观念，勾心斗角，思维逻辑，一般是中学大学形成的。如果你这 段时间不在国内，这种思维是没有的。

建议：

+   1. 移民的，早点去。
2. 家里几个亿存款的，无所谓。
3. 要回国发展的，没意思。孩子出去去了，人都快捷了，回来像个 250，既考不过国内的各 种证书，也不懂人情世故，最多当个蹩脚翻译，混混小资！
