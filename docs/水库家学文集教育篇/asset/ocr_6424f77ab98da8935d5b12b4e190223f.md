# 选大学专业的坑

千万不要选择带有“涉外，国际”这种字眼 的专业，包括，涉外法学，国际经济法，国际金融，国际会计，国际贸易，国际 xx，涉外 xx。这些专业，考分一般比去掉涉外两个字的 专业，至少高10 分以上。

例如，金融专业和国际金融专业，分数要差 10 分。但本质上，这两个专业 设么 么 大的区别，就业也没有区别。国内  部分  学习内容，基本还  实  一点，  学的那些花里胡哨的国际 xx 专业  课，毫无实战意义，和百度上看一眼的效果， 完全相同。

如果你对国际 xx 学感 兴 趣，那就直接留学。不要听那些 250 副教授瞎推比划。

# 如何学好外语？

目前的常规外语教育方法，是不科学的。六级都过，基本无法交流。但是，这也没  法 改。因为最科学  玩法 太费了， 们玩不  起  的。当年，我们学外语的 时候，是玩实战的，  当时因为一个特殊情况，需要我们 一个小 班在几个月内迅速掌握一门外语，然后马上去工作。于是，给我们上全套 了。

那才是最科学  的  法。 我简单介绍一下那个  限训练方法。

+   1.  全封  口，人不能出去，必须留  一个院子里，除了晚上睡觉，或者出去买点东 西。这个环境里，一半  外语老师，一半是学员。

+   2.  全部外教，没有中文老师。我们  时 一个外国字  也  不 识。 怎么教呢？简单，看图说话。先教单词，不管语法。然后教句子，不  原因，就  么说，  正也没有中文  师，  们连累都带，这回也好，不考虑对暗。

+   3.  激发潜能，每周淘汰一个人。这个是非常残酷的。每周的对  考试，简直是鬼门关。逼得你做梦都  在学。有一个学员被  的 神好像不对劲了。最后怎么样，我不知道。反 被  回去  了。

+   4.  任务  一，你没有其他任务，基本与  隔绝，我们  觉  闭  机，没有电脑。就是复  机。

+   5.  成功率  ；我们当  入选，都是精英，基本  好。经过 20 次淘汰 赛，最后大概有 40%的学 生，在 150 天内，  以达到专业水平的工作要求，当然，  作  水 平  较  ，只能  意，不能修 饰。
