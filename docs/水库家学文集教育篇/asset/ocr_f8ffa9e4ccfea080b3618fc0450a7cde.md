# 向年轻人致敬

微博上的各种观点，非常复杂。生活事业双失顺的喷子特别多，见不到别人好。这里面有个特殊原因，能够长期坚持内容输出的人，必是是困人。谁有时间呢？财富自由者，退休有儿套房子的，办公室因人，失业落魏者，卢瑟喷子，农村二赖子（五毛）。

财富自由，时间自由，文笔干练的人，微乎其微。真正有过辉煌经历和一线实战经验的人，我在微博上没看到几个，绝大部分是失业分子。这些喷子，按照研哥宜或有专业期刊的标准看，完全业务，连基本的经济学专业训练都没有完成，更不要说什么经验总结了。

我说这些的意思是，年轻人看问题，不能按照“我喜欢，我不喜欢”来划分，而是要按照合理性来划分。经济大趋势，肯定不是按照失败害个人愿望发展，而是有客观经济规律的。很多喷子大是各行各业失败的害者，内心扭曲者很多。他们对现实有很多情绪，不敢乱说乱动，只好找几个大 V 嗅嗅，喷就喷吧，随意。

年轻人要理性看待社会现实，尊重内心的呼唤，不要受喷子们的影响。他们已经没希望了，这几年，几艘直接把他们是送到农村养老老了。但年轻人的生活事业才刚刚起步，不要因为暂时困难，而放弃努力，直接成为卢寒二代。年轻人要留意几个事情：

+   一，考个超级证书或者专业技能，作为吃饭的保证。

二，不要迷恋稳定的围城内。那个地方，吃不饱饿不死，却消耗了你的黄金二十年。

三，找对象要合理预期。百鸟在林，不如一鸟在手。先用起来，条件好了再改善。

四，自创意事物，新行业，新变化，要用开放接受的心态，积极尝试，小心投入，争取成为新风口中最有准备的那个人。

五，大城市房子很重要，这是一家老小安身立命的地方，无论大小，先搞一个。

六，不要怕体制外的风险。体制外大部分人并不比勤奋努力的，你不过才熟悉了两年而已。找到一个机会，冒一次险，不要犹豫。

七，亲戚朋友都是普通思维，只会往下走的求稳心态，财富永远不会青睐你们，你尽可不要复制他们的人生。
