# 大家对学历有误解

实际上，top1 学历，华而不实。找工作很苦恼。一般情况下，没有公司要，因为 hr 嫉妒，老板心理也不踏实。所有的老板都认为，你为什么不去大公司，人到中年过来，就是当个跳板，做不了几天的。同事们也经常把难题推给你，谁让你吹牛？

我也遇到过这麻烦。但是，top1 学历在找对象的时候是真的好使。出个棒样子就行了。啥也不要操心，丈母娘全部倒贴，就怕你退货。

# 幼儿园大班相当于什么情况？

如果是幼儿园好学生，语数外基本相当于小学三年级。

语文：出门在外商店招牌都认识，不要求写。

数学：985 也不会做：妖里妖气的题目，感觉是奥数突击过的，很恶心。

英语：全分数。

还有各种花里胡哨的课外兴趣班，马术，高尔夫，跆拳道，游泳，唱歌芭蕾，是基本配置。没有几万块，你在班级里抬不起头。

学校里还有各种给孩子出风头的小项目，想去吗？绝大多数孩子非常想去。家长要懂事。

成本极高。

# 学乐器的孩子都是傻子乎

学校老师特别鼓励孩子学乐器，但是，老师的目的是什么艺术细菌，而是利益。学校最喜欢管弦乐队，因为学校运动会，或者迎接检查团有用。但是，音乐老师大部分对吹喇叭不感兴趣，因为吹喇叭的钱少。音乐老师最喜欢钢琴，还可以带家长去买钢琴，这个积极性最高。

现在，吹拉弹唱在考初中的时候不加分了，把大量写作业的时间浪费在吹喇叭上面，孩子学习成绩就差了很多。得不偿失。
