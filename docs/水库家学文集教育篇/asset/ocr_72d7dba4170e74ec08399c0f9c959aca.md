# 京沪一般家庭对就业

已经有新要求了。

不仅仅是实现就业，而必须是“体面就业”。什么是体面就业？原来上海有大批的人是做工的，种地的，现在已经完全放下锄头和锄头，必须是电脑桌，键盘，联网，上班可以炒股，驾驶员也必须配电脑可以上网（美曰其名开车要验线），否则就不舒服了。

京沪二本最喜欢带编制的打杂岗位，五大行，垄断单位的营业厅。三校生，职高，也必须是大连办公室，大专单位办公里的合同工，公司前台之类的。这么多年，我就没有见过一个上海人在物业公司做电工的。上海一般老板小程度喜欢的工作是事业单位，公司财务，物业经理，接电话前台，跑跑的文秘，或者在事业单位里办公桌子，也不讲究编制了，最低要求也是干干净净的超市营业员，否则不来了。就是必须体面。

京沪普通人为什的工资不高？正常人找工作，一般看不到高薪岗位，年入五十万往往是这样的。你在一个公司里干的特别好，老板实在是离不开你的能力。不断加钱到三四万月薪左右。但这个钱是你的工作业绩和能力，不是一开始就有的，必须是苦干起步，但是，京沪普通年轻二本子一开始就不想辛苦，也就没有后面的年入五十万的好事了。

如果你家孩子初中小学读书不好，我给你的个指道，读幼师。那些家长管他是个多厉害的单位，什么三甲，通通就像是小鸡羊一样听话。

# 大单位里不要炫耀

能够进大单位的人都是原因的。要么家里厉害，要么文凭厉害。这两样人是永远没有共同语言的。屌丝和世家子弟的区别是，屌丝特别渴望上去，又特别要面子。屌丝有什么呢？无非是清北 985 的文凭，几篇论文。屌丝要想踩别人，无非是炫耀这些。

但是，你在炫耀的同时，可能也深深地刺痛了小头头，他们不一定是清北的。你这是打人打脸嘛。炫耀就是把自己的幸福建立在别人的痛苦之上。

我有个同学，在单位里显摆了一句，我是 xx 毕业，结果被压制了十几年。

# 为什么公司不喜欢中老年人？

因为现在的老板都是年轻人，对于中年老油条实在是没有办。你漂到 35 岁了，还出来找工作，说明你实在太差劲了。看你的履历，前公司也没倒时间，怎么就漂不下去了？是不是你太难相处了？

现在的公司都愿意招聘年轻人，家里负担小，出差当旅游，加班拼命干。那些快四十的，上班网购，下班养生，天到晚都是偷奸滑，教年轻人揣摩老板。你这个年龄了，工作表现好的人还会出来找工作吗？
