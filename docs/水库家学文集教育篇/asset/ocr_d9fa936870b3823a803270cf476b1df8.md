# 最受欢迎的是小学老师

几个月前，和一群老安人及其家属吃饭，有中小学老师，正式编制那些人，搞金融的，开厂的，郁闷的几个棍子。

最受欢迎的是小学老师，每家每户都有这个需求，第二是搞金融的，有没有什么内部消息？帮我们发个小财？最惨的卖体企业小老板，没什么可以帮别人的，穿的也不好，还抓搜搜的，身上一股味，好像是在厂里集体宿舍住久了的感觉，惹人讨厌。大家都不搭理小老板，也不主动微信信，怕他过两天来开口借钱。

# 大学生想发财怎么做？

坚决去小公司。

千万不要去大厂。大厂是资本密集型，一个项目投人几个亿，你没有机会做省。最好去三正五格的小公司，你就踏踏实实战小看老板买赚钱的，几年后，你也可以拉队伍去干。我认识一个二本子，在小公司拉单子，就是给新客户介绍业务，他的同学很多去了大厂当螺丝钉，五年后，这个二本子也是小老板了，年入百万，还有几个前村花住拍乌尼尼。小王总，你年纪轻轻就这么多少钱，花不完怎么办啊。这个意思很明显了，他的同学还是二本子垃圾人，一天到晚写鸳鸯眼。

# 小领导批评你是为你好吗？

不是的。

绝大部份人批评你，纯粹是因为讨厌你，谈不上喜不喜欢。但是，他们也怕你今后记恨反制他们，所以做个蹶话骗骗你。

我从来没有考虑为了谁好去批评他，这是不可能的。将心比心，你也不会这样的。

这么多年了，曾经批评我的小领导始终是不喜欢我，从来没有帮忙过，落井下石倒是很熟练。结论，谁敢骂你，就是和你过不去，打回去。职场就是名利场，没什么客气气的。
