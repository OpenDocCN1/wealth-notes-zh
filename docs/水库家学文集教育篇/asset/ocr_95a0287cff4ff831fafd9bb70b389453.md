# 三，怎么办？

尽可能先读书，一本考不上，至少混个二本。然后，按照自己的兴趣发展。有的人大器晚成，苏大强今年 59 岁了，才红了不到十年。那个小晚君六岁就红了，现在离婚了。

+   1，有坐冷板凳的勇气。很多人想着两个星期就出名，你帮我转几发行不行？那是不可能的。就算我现在把这个账号给你，你也玩不好。我以前那个账号送人，又怎么样？

+   2，技术积累。网上，藏龙卧虎，什么高人都有，你要没有点真本事，压不住的，分分钟把你拆翻了。我一般是先拉黑他们。

+   3，合理预期。不要想做全搞走的通吃赢家，你没这个能力和精力。你就做好一点点，做到极致。人家一想起这个话题，就会想到你。那你就赢了。

+   4，不赚小钱。很多人，五万粉丝就开始卖身求荣了，自降身价。我给你一个标准，至少做到地级市前两名，才卖的起价。

+   5，不要想讨好别人。粉丝吃硬不吃软，拉黑就行了。只要有 1% 的人喜欢你就够了。

+   6，练好文笔或者表演。十年磨一剑，滔羽未尝试。打好底子，再出来混！
