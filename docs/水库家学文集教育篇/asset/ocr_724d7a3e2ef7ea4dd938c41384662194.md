# 领导喜欢什么样的人？

能够替他解决问题的 人。领导遇到的问题，大概是几种：

+   一是工作业绩。但凡是领导，身上肯定有业绩压力。你要是能够替他守好一个关口，不让他心烦，就是高分。或者工作上出个彩，给单位写几个论文发表，领导也是高看你一眼的。大好处不一定，小好处是有的。

+   二是个人苦脑。领导也是人，一样遇到各种各里的私人难题，买房，求医，入学，小舅子找工作，小姨子评职称。你要是能够（合法）提供资源，啥也别说了，直接乱聊。

+   三是热疮。领导有时候也遇到麻烦，需要有人挡一挡，甚至去背锅。你看不懂？单纯的个叛，人家也不感兴趣，这又不是纽约哈哈。人家还缺一口酒喝吗？

# 为什么领导看不上我？

这是绝大多数职场人的痛点。这不是什么态度好不好，姑不姑风的问题，而是一种必然现象。因为你和公司领导的利益点不同。

你参加工作，希望通过出色业绩，获得一把手点赞。但具体而言，做不做某件事情，怎么做，早做晚做，你和部门领导的看法可能不一样。如果你听领导的，最后不成，大家嘲笑你。如果你不听领导的，主管就恨上你了。

你可能因为这件事情十有八九会失败，不想背锅，不想做，而主管觉得问题不大，坚持要做，你就难了。

有的人平运直上，真的是运气好。因为他的直接领导水平高，千一个成一个，你当下属的，也赚足了面子，跟着升上去了。遇到一个水平不高的领导，有事儿他自己抢功，出事推卸责任，把你骂成猪头，还要到处说你连累了他。

大部分年轻人，在进单位第一年，遇到什么领导，基本决定了他的第一次提拔。这是很常见的情况。

# 做什么能肯定赚钱？

做你不愿意做的事情。

你要是可以做工程师，当然不愁了。但是，好多考不出工程师，也想赚钱，怎么办？那就做大家不想做的事情。男人挖土方，开泰卡，贴瓷砖，炸油条。女人做月嫂，带孩子，干发廊，做家教。反正，你不舒服了，就有人愿意给你钱，让自己舒服。人性都是一样的。
