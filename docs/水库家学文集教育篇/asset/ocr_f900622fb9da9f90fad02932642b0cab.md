# 考上985，只和补课费有关系

现在，大部分家长，月薪低于一万的，是不会得花二十万一年，给孩子补课的。家长们最喜欢的就是说，你看隔壁村张二狗家的儿子，也没花什么钱，考上上海理工了，你咋这么笨呢？呵呵，你怎么办？
考上985，和学校没关系，只和补课费有关系。
区重点，市重点，一个班级考上985，至少是前 five 名，省重点高中尖子班，你家孩子也考不上。
与此同时，重点高中老师的教学难度，是按照第20名，本科踩线就好的孩子来的。二本和985，当中差了50分。这差距，就必须拿钱去砸了。当然，你家孩子天赋暴表，我不说了。一般孩子，还是需要高手指点，节约时间，快速推进。
初三到高三，四年砸下来，30-60万，是普遍情况。你回家和老婆商量一下，你家生二胎，跟不跟？我得宠里！别给我说什么焦虑不焦虑，我也不想这么搞，但我也没办法啊。我家孩子就想读一个专升本，只能和你们竞争了。

# 我小时候没有补课家教

但我考试成绩好，其实也是花钱砸出来的。
小学三年级上英语课，我家没人会英语，社会也没有录音机，实在没办法了。我妈是聪明人，她带上去，到外语老师家里，她给老师做饭，红烧肉，清蒸鱼，炒香菜，煮毛豆，差不多一个小时，外语老师给我补习半个小时英语，每年冬天，我妈还给老师打毛衣，还给老师的女儿，老公，一人一件毛衣。毛线是老师的，我妈出力气。
到了高中，实在没有什么补课老师，但我妈有本事啊，她带我去福州新华书店，凡是常考考试这四个字，全部买下来，基本是一年去四次，前前后后花了很多很多钱。我就偷偷在家复习图书馆。任何不懂的题目，我至少有十几本参考书，可以查阅，再查不到也就算了。
我高中英语，是全校第一。因为我的英语参考书，大概有几十本，也不是全看，就是对比查阅。我的任何一门课，参考书比教研组长还多。他们出考题也是抄参考书的，我是一猜一个准。
那时候大家都是穷人，我就是这么拼出来的，你家行吗？

# 绝大部分的中产家庭

并不喜欢孩子一天到晚刷题，把孩子制成“啤酒瓶，豆芽菜，油瓶子”。但是，不刷题不行啊，否则逢个高中都不能读，父母脸都丢光了。富人穷人一样跑，从幼儿园开始血拼，抢学位，抢学区房，疯狂补课，读课外班。反正都是砸钱。你熬不下去就退出来。
很多人说，穷孩子自己悟，考高考，行吗？我们就知道，富人家长子不比穷人家长子弟，他们父母的智商更是高于一般家庭。人家是开着宝马奔驰，你是光个脚，还天天想怎么省钱。除了个别天才，绝大部分是吃亏的。
