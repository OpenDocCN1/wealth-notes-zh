# 来自「李晨」的主题

商业机会都是从发现信息差开始的，然后早起进入市场的人开始圈资源做规模，继而阶段性、区域性垄断细分市场（垄断核心要素资源）。再来就是从具体的资源性垄断到认识层垄断也就是做品牌，形成市场共识，最后就可以参与制定底层的商业规则。当一家公司可以制定行业标准 и 规则的时候，就一定是巨无霸了，因为它已经在用市场的力量参与政治利益的博弈了，比如缩短产品使用寿命。
