# 来自「贾万兴」的主题

如果是一个小孩，看到一个人桌上飘起来，他的想法是什么？可能是有趣，我怎样才能飘起来。

在这里几乎所有成年人都被 人不能飞 这个规则限制了，所以失去了可能的机会，这个例子看上去有些极端，但是你想过人为什么要工作？为什么要吃3顿饭，而不是5顿吗？
