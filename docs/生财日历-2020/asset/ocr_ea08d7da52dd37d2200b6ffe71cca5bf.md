# 来自「飞」的主题

如何认清自己的定位，不要和同行业的人交流，去跟不同行业的人做个自我介绍，抛弃你的那些行业术语和细节，你能否做一个三分钟以上的自我介绍，尝试以后你就对自己的定位有一个清晰的认识了。
