设计的三个层次：好看 < 差异化 < 驱动产品。

好看是设计题中之义，好看做不到，设计不及格。

差异化建立产品认知，你与别的产品区别是什么？比别的产品好在什么地方？这些不一样的点构成了你。

审美是一种生产力，绝大部分产品都走不到这一步，苹果做到了。
