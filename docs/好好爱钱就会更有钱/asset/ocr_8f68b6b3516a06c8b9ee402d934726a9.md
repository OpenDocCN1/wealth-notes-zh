# 04
不要把钱包放在「裤子后面的口袋」

大家在选购提包的时候，重点会摆在哪里呢？

必须具备时尚感？要以功能取胜？还是轻巧至上呢？

就我个人而言，一定会先看提包本身有没有「钱包收纳袋」的设计。

无论是多么令人惊豸的提包，假如没有一个尺寸刚好可以让「钱包先生」舒服地待在裡头的口袋，我是不会买的。

碰到得带着钱包在外头忙碌的时候，应该优先考虑把钱包放在提包裡，而不是摆在衣服的口袋裡。

既然要摆在提包裡，当然建议摆在提包的內袋。

**钱包跟著我们在外面奔波时，一定要把它放在「固定的位置」。**

有些人购物告一段落，在付钱的当下，常常东翻西找不到钱包，这就证明了这个人根本没钱包这个人一生中的重要够伴放在哪裡。
