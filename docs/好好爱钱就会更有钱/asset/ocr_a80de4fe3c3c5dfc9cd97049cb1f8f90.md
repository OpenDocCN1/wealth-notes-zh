# 知「足」

人真是不可思議，不管錢賺得多或賺得少，日子都過得下去。理由很簡單，只要收入能夠負擔實際的支出就辦得到了。年收入有二百萬日幣的人，住在經濟能力所及的公寓裡，在二百萬的範圍內建立自己的生活。年收入有二億日幣的人，「買了一艘遊艇，為了停一個比較好的港口，沒想到得花更多……。」「錢賺得多的人，也是花費不省。結果，無論收入有多高，永遠都覺得少了點：「哎，錢要是能夠再多一些，不知該有多好……。」
