# 擁有二個以上的收入來源

佛教有「身」、「口」、「意」的說法。

「身」是指如何行動？
「口」是指如何表達？
「意」是指做何思考？
「思考」、「言語」以及「行動」三者如出一輀，就是一種幸福的生存方式。
當三者之間沒有任何落差，只有和諧、一致時，可說是來到了幸福的頂峰。

然而，世上有很多人做的不是心裡想的事，說的也不是真心話。
譬如，言不由衷地說：「全部都被協理說中了，協理果然是協理！」
特別是完全倚賴一個收入來源的人，只會設法死守住這個來源不放，也因此使自己的身、口、意產生很大的不一致。
「萬一少了這筆收入的話……。」諸如此類的想法經常驅使本人為五斗
