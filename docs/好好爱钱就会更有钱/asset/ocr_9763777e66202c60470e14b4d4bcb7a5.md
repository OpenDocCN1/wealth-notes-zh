# 01  把「二萬日圓紙鈔」擺在最前面

雖然有點突然，但還是請你掏出錢包，打開來看一下。為什麼錢包一打開來，第一眼看到的是千圓紙鈔呢？萬圓大鈔被壓在千圓鈔的下方，是嗎？假如你習慣把千圓鈔擺在上面、萬圓鈔擺在下面，證明了你的潛意識一直在自我暗示：「我是一個只配使用千圓鈔的人。」為了提升財運，你必須告訴自己：「我跟萬圓鈔最合得來！」藉此重新塑造正面的自我意象（Self-Image）。馬上把鈔票的擺放順序調換過來吧！在打開錢包的那一瞬间，迎面而來的一定是「諭吉先生」。

（注1：關於諭吉先生的說明，詳見二三三頁）

請把萬圓鈔放在錢包的最前面，五千圓鈔則在萬圓鈔的後面，而放在最後頭的鈔票，必定是千圓鈔。
