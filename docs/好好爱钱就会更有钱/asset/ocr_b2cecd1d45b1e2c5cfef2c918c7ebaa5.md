# 36
做一個「有志之士」

金錢就是變形的「謝謝」。
金錢變成感謝的象徵，從一個人的手中傳遞給另外一個人。
金錢變成「感謝狀」，答謝你在工作上的付出。

「謝謝你為我們做出那麼好的產品！
「謝謝你給我們賓至如歸的服務！」
許多多的「謝謝」被說出口的時候，意謂著金錢正不斷地在循環。
反過來說，假如有一個人一天到晚抱怨：「手邊怎麼老是沒錢？」「可以想見這個人很少得到別人的感謝。不被感謝的人，誠屬可悲。
因為他在工作上的表現幾乎得不到別人的認同，沒有人願意向他說：「謝謝！」
有多少人都會感謝你正在做的工作呢？
你的財富盡在此。
