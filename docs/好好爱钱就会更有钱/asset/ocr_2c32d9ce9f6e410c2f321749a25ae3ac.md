# 08  錢包的生命週期是「1000 天」

你知道錢包也有使用壽命嗎？

錢包的壽命，開門見山直接說，就是「一千天」，大約等於「二年九個月」。

所以，我們每天使用的錢包，應該維持「不到三年就更換新品」的頻率。

一個使用超過三年、已經破損變形的錢包，如果還緊抓著不放的話，代表主人執著於負面的感情，處理起事情來也會拖泥帶水。

錢包必須定期汰舊換新的理由有兩個：

**1** 使用破舊磨損的錢包，會促使「貧窮」在潛意識裡生根發芽。

**2** 汰舊換新之際，正好趁機重新思考自己對金錢的態度。

利用這個時候重新審視自己和金錢的關係，或許該下定決心努力存錢了；

或許該停止浪費，把錢投資在自己的未來。
