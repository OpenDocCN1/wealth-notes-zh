# 用「綁鈔帶」做我們的幸運物

基本上，適合放進錢包裡的只有錢。不過，也有例外的時候，那就是為了吸引財運而放的「幸運物」。

從前的日本人把錢包叫做「蟾蜍嘴、蛙嘴」，習慣在「蟾蜍嘴、蛙嘴」裡放一個小小的青蛙吉祥物。沒錯！他們祈盼金錢快「回來」。（注5：關於青蛙吉祥物的說明，詳見「三三頁」）

幸運物能夠增強錢包的能量的。

露出滿臉笑容的個人照或全家福照片，也適合放在錢包裡做幸運物。龍是繁榮的象徵，與龍有關的物品同樣推薦。

把幸運物放進錢包的夾層袋，讓錢包充滿好運氣。

我們也可以在錢包裡放入「名片」。
