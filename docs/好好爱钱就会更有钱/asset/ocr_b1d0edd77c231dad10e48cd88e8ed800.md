# 錢包裡要擺「年齡 × 1000 日圓」的金額

你的錢包裡頭現在有多少錢？

# 標準。

究竟錢包裡該放多少金額的錢才夠？我們可以用「年齡 × 1000 日圓」來做比方說三十歲的人就放三萬圓，三十五歲的人就放三萬五千圓；依此類推，四十四歲的話，當然就是四萬五千圓。錢包裡的金額多寡要和我們的年齡相對應。

高中生錢包裡放的金額，當然就不應該和大人一樣。

對二十歲的人來說，感覺上是一筆「大數目」的金額，一定和四十歲人眼中的「大數目」不一樣。

錢包裡的金額如果不足「年齡 × 1000 日圓」的話，就好像在塑造「錢怎麼老是不夠用……」的意象。
