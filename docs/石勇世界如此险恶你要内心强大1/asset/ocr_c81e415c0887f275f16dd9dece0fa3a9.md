# 1. 怎样才能战胜自己

问：

我觉得，相对于这个凶恶的世界来说，更棘手的是自己本身。我们也许可以强大到面对任何人都很从容，但不一定能够战胜自己。我的意思是，战胜自己真的比战胜这个世界还难得。有时候运气好的话，可能莫名其妙就成功了；但战胜自己，从来就没有侥幸的情况存在。

怎样才能战胜自己呢？

我知道，我缺乏的就是所谓“行动力”，已经到了极为严重的程度。我曾经离家出走，去寺庙里求神的帮助。也尝试着学习尼采的“强力意志”，尝试着去接触那些所谓的“成功学”。但都没有什么用！我非常沮丧，并且有着时不我待的强烈感受。请指点。

答：

提问题的人思维就是错误的。这是所有想“战胜自己”的人的误区。

什么叫“战胜自己”？我们把一个能够“战胜自己”的人当成了不起的强者，他似乎在和自己的战争中赢了。但其实如果一个人和自己作战，他必输无疑，因为他会陷入自我的冲突与分裂之中。战胜自己绝不是和自己作战。心理强大的秘密之一是理智与情感、头脑与心灵的和谐，即自我没有陷入冲突。真正来说，我们不是和自己作战，而是惩罚外部世界用来控制、奴役我们的自我的东西，并把它们从自我的结构中清除出去，我们是在和它们战斗！我们要做的，不是对自己下手，而是了解控制我们心理的那些诸多规律，理性地审视它们，摆脱盲目被规律操纵的动物和机器人的命运。知道这些规律是怎样操纵我们的，你就可以防止别人操纵你。
