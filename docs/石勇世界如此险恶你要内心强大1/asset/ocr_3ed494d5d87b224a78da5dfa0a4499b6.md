# 21. 什么叫“在精神上毁灭自己”

问:
什么叫“在精神上毁灭自己”?

答:
假如你想骂我,又骂了我,我会非常难受,在我抗拒不了你骂我的情况下,我先把自己给骂了,这样,你骂我还有威力吗?当你看到我这样时,是不是感觉到奈何不了我,被我的气势震住了?我在你面前,是不是有了一种心理上的优势?这就是在精神上毁灭自己。

# 22. “我是个粗人”

问:
我在谈判中经常遇到这样的人:一开口就是说“我是个粗人”或者“反正我已经60多了,活够了。”然后说用他的游戏规则,基本上是蛮横的、违法的,比如“人是我打的,打回来可以,就不赔钱。”说几千块钱争议,打官司又不必要,行政处罚又解决不了问题。可谓人至贱则无敌。我往往觉得你这样的人无法沟通。

答:
无论这些人是不是人渣,演这一出戏是一种博弈策略。它的本质是:这些人在和你博弈时没有胜算的把握,智力和兴趣因素也不允许他去捉摸你的出牌,于是先行一步亮出“底牌”(无论是真的还是假的),从而制约你的出牌。他先把自己在道德上给贬了,精神上先毁灭自己,但不是以谦虚、坦诚诚恳的语气,而是以蛮横、挑衅的语气。这样,他就有一种心理优势,因为在你面前,他是一种威胁。他在暗示你必须按他的规则出牌,否则可能有麻烦。他们的弱点就是害怕你弄得比他们更野蛮。这样就会给他们造成心理震慑。
