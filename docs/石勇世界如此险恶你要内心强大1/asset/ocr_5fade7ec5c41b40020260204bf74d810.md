# （1）性格表现

攻击型的人从来做不成什么大事。真正能做 大事的，无论是对这个世界搞破坏还是搞建设，绝大多数都是自卑型的人、点有型的人、表演型的人。历史是这帮人书写的，现实也是这帮人构造的，未来更是这帮人描绘的，攻击型的人只有看戏的份。

马克思是自卑型的人、苏格拉底是表演型的人、毛泽东是表演型的人、华盛顿是点有型的人。但攻击型的人中，从来没有出现过这些人中的任何一个。

他们基本上就是社区长臂妇、街头混混、体制寄生虫、暴力机器成员、商业机构里或大或小的员工。

他们做不成什么大事，其原因在于，他们无法把自己自我的败坏扩大成这个世界对所有人，甚至只是一个阶层、一群人自我的败坏，因此其理想永远没有超出个人的范畴。

他们只能在生活 和工作中，或明显、或隐晦地发泄对这个世界的仇恨。而且，无论他们嘲笑他人、暗算他人、伤害他人，针对的永远是具体的人，而且是比他们更弱的人。他们永远不针对抽象的东西，比如价值体系、制度安排。

攻击型的人非常容易辨认：

①看他们的眼睛

自卑型的人的眼睛，或冷漠、或孤傲、或恐惧、或自信，变化多端。但攻击人的眼睛却永远只有一种光芒，那就是仇恨。当你和他在一起时，注意看他的眼睛，那是一双对世界冒出敌意的眼睛。

任何人的眼睛都可能闪出仇恨。但对于其他类型的人来说，那是愤怒引起的。而攻击型的人的仇恨，不需要任何理由，理由在他的性格结构里。

②听他们说的话

以为可以的攻击型的人正常地交流是天真 的。不能和他正常交流的意 是，你们 无法客观地、不带偏见地深入探讨任何一个问题，因为他所看到和理解的世界，仅仅是他心里的世界。
