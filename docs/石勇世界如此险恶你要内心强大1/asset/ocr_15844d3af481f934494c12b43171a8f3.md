头脑有什么样的认识，心有什么样的状态，我们就真正得到了改变。

以我上面的经历为例，我们分析一下，如何做到这一点，这里面有什么样的心理机制。

+   1.  当我认识到城市和乡村仅仅是人类鼓捣地球的不同结果，在这一状态中，我仅仅具有认知优势，而没有心理优势，也就是说，我的心理结构还被限定于那个关于贵潘和贱苔之别 的社会价值排序里。

+   2.  当我哭时，发生了什么？这意味着我感觉到了人类的荒谬和虚弱。这个时候，我的情绪已经被引发。

+   3.  当我集中精力保持思考，有恍然大悟之感，同时情绪也继续保持时，情绪就开始携带我的领悟，渗透我的心理结构的表层。

+   4.  领悟越深刻，引发的情绪越剧烈，渗透心理结构的能量就越大，它就越能真正改变我。

+   5.  假如我的心理结构得到了改变，那么，头脑的优势就变成了心理的优势，头脑的强大就意味着心理的强大。

只有思考引发了心的体验，我们才算是真正理解了某个问题。无论是就看穿袭而言，还是经其他的事情上，我们要得到改变，就必须把对问题的领悟转变为心的体验。
