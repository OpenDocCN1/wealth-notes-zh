# 3、装从来都是维持牛叉的必要手段

遇到挑衅，你对别人作出什么反应，往往决定了他对你的后续态度和行为。在别人不了解你的时候，制造出一个强大的印象，往往是**我们的一种自我保护**。在你造成的印象一开始不利于自己时，想挽救是很难的，因为这意味着要改变他人的心理结构！

装从来都是维持牛叉的必要手段。它是一个人炫耀权力、身份、派头、光环前的“宝典”。

有人曾对“领导视察指导工作”有过形象的描述。我摘抄如下，方便分析。

“领导在某组巾来到学校，师生在准备好的状态下发言、表态；领导看宿舍、教室、图书馆和实验室等，最后去则会议室和早已做好准备等在这里的师生代表进行所谓交流。师生代表一律是念稿，领导听后作指示。最后还少不了拍照留影。如此一番便是所谓重视教育，深入基层了。”

2011年1月，中国湖南，一个中学搞庆典，学生整齐列队，在风雨中手持花环，站立恭候领导视察讲话。时间持续一个小时。事件传开后，遭到舆论密集炮轰。

学校里的这种任何成功的表演都必须有一个主题。在这类表演中，它必须做到：

+   （1）突出领导的身份、权力和他们对教育的重视。

+   （2）显示出教师热爱教育、学生努力学习的风范。在表演开始前，参演各方对这两点都应该有所领会，否则将影响演出效果。
