# **关于本书**

从2009年1月起，青年学者石勇以ID“发梢回眸专用马甲”在“天涯杂谈”陆续开帖《在这个险恶的世界，你需要在心理上变得强大》及《装13社会，博弈法则》，围绕如何让自己心理强大这个主题，通过通俗风趣的语言、犀利深入的分析，并融入心理学、哲学等常识，如庖丁的解牛刀，刀刃剥开社会、人际、性格、自我心理的种种外衣，提出实用有效的应对之道，大受网友喜爱。帖子点击总量过百万，几万条留言，上百名网友专门给作者写长信反馈，说这两个帖子是“天涯难得一见的好帖”“非常受益”“从深层次上改变了自己”。

随后作者花一年多时间，把两个帖子融合、重组、整理，并加入更多案例、观点、分析，以及和网友的互动，并尝试更加通俗易懂的语言风格，重新写成本书。

本书不是鼓舞呐喊的励志书，不是哼哼笑着出世、看透的佛家故事，不是不痛不痒的心灵鸡汤，而是以积极入世的思路，另辟蹊径的解读，让读者从思维方式和心理结构上“重装系统”，由弱小一步步走向强大。
