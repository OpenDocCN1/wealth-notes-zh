# 12. 怎么培养男性特有的人格气质

问：
我想得您说起，一个男人可以一无所有，但一定要有顶天立地的气势。最近看了些欧美得电影，深以为然。可审视自身，完全不见这种气质。这种男性特有的人格气质该怎么去培养？

答：
当你利用你的思想和语言表达力把这个世界解释得井井有条，你在别人面前就重构了一个世界。在他们心理上，就相当于你操纵了这个世界。而他们无论手中拥有什么，在这个世界面前都是无力的。这样，一种光环就会笼罩在你头上，这就是气质、气势！
