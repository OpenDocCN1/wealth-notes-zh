# 形态之七：海底电缆

![](bbox=[0.355, 0.136, 0.58, 0.192])

海底电缆是指MACD指标在零轴以下运行很长时间（一个月以上），DIFF线金叉DEA线以后（零轴以下金叉），两条线不是强劲上升，而是与DEA线粘合成一条直线，数值几乎相等。一旦两条线开始多头发散，即可买入。零轴以下的海底电缆形态的形成，多为股价在下跌探底以后，将盘劳尽时出现的底部形态，这时主力介入，进入压箱顶吸货所致，应理解为捡机入市。
