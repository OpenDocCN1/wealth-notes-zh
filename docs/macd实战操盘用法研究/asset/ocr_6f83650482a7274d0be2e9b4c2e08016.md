3 次金叉形成的反弹失败后的 MACD 死叉必须也处在 0 线下。也就是发生连续 3 次金叉的时候，需要这 3 次金叉中间的金叉死叉发生位置都必须在 0 线下。这是很重要的。如果时而 0 线上时而 0 线下，那是震荡行情，不是我们要求的跌势，我们是要求跌势下，连续 3 次多方反攻，造成大反弹或者转势，从而我们在第 3 次金叉做多。

一个涨势中 MACD 如果在 0 线以上形成 3 次以上的死叉，表示虽然多方控盘，但是空方已经出现了 3 次反扑，这表明空方的力量通过三次反扑在增强，多方经过空方三次反扑力量大减，根据 MACD 极其有名的“事不过三”原则，0 线以上三次死叉，必定要么一波大回调，要么转势。因此，建议投资者一旦看到 MACD 在 0 线以上出现连续 3 次死叉，则可以考虑在第 3 次死叉的时候平多开空。如果出现 MACD 在 0 线以上出现连续 4 次死叉，应该坚决平多做空。MACD 在 0 线上出现连续 4 次以上死叉的情况比较少见，如果出现，肯定平多做空。值得我们注意的是，如果 MACD 在 0 线上出现 3 次以上的死叉，即使 MACD 不出现顶背离仍可以平多做空，如果出现顶背离，则坚决平多做空。如果 MACD 在 0 线上出现连续 4 次以上的死叉，不管 MACD 背离不背离，都坚决平多做空。
