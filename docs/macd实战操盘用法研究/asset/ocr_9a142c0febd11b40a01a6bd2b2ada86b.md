# 13.1 方大集团基本面介绍

2014 年 7 月 24 日查看股票行情时看到了方大集团，心中震惊，上涨的内在动力真是大。又遍看了所有 A 股，发现日线涨势最有力的就是方大集团，其次是国投电力、广东明珠、生益科技。查了基本面，方大集团和生益科技最好。选的涨势好的股中，网络这一块同花顺比较  好，这个行业看好。由此定下方大集团、生益科技、同花顺是未来主要炒作的股票。

第二天早上还是先买了长江电力、国投电力，后来又买了点方大集团。真是晕，最好的股，不去买，还是买相对较差的股，原因还是以前的恐高心理。本该买的三只股当天都涨了，两个电力买上都跌了。下周就等赚钱了，出来电力，买入方大集团（000055）和生益科技（600183），再少买一点同花顺（300033）。其实好股看企业介绍就看出来了，下面是这三家公司的基本介绍。
