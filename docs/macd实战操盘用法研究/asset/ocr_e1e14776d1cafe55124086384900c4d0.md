# 1.5 小结：本章的重点

0 线附近的金叉死叉非常可靠。如果市场是跌势，则每次 DIFF 和 DEA 两线反弹到 0 线附近形成的死叉，开空单获利的可能性非常大。如果市场是涨势，则每次 DIFF 和 DEA 两线回调到 0 线附近形成的金叉，开多单获利的可能性非常大。
