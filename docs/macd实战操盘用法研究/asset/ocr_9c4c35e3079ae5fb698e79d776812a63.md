直到圈 3 出现真金三角季价托，圈 4 出现 MACD 0 上金叉，市场重新转为涨势，我们平掉空单，建立中长线多单。空反多的人场点为圈 4 中的 MACD 金叉（这也是大跌以来的第一个 0 上 MACD 金叉），我们的空单获利非常巨大。

而圈 5 出现一个死三角季价托，由于 MA（60）虽然上升斜率变小，但是方向依然向上，因此这是一个假死三角季价托，后市仍未涨势，多单不该平仓。且此时圈 6 根本没有 MACD 0 下死叉，出现的反而不是 MACD 金叉，因此从 MACD 看，趋势也没有转为跌势，也不该平多单，因此多单需要继续持有。

在周线上出现这种 MA 与 MACD 结合选择的进场机会，那么获利更为惊人！
