# 图 9.23

上图 9.23 兴业银行日线图，大跌势第 5 波时出现了 MACD 底背离金叉，此时做多，基本上是抓底了，后市出现大涨，获利丰厚。

2. 根据波浪理论，顺势一般至少有五浪上涨，也就是至少涨三波；逆势一般要调 3 浪也就是 2 波。因此如果是涨势，它回调的时候，一般要调整 2 波后的 MACD 金叉再做多；如果是跌势，它反弹时候，一般等反弹 2 波后的 MACD 死叉做空，波浪理论对选择用哪个 MACD 金叉做多，还是很有用处的。
