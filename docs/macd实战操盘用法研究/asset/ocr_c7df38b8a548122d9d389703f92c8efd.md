# 1.4.3 MACD 0 下多次金叉买入法与 0 上多次死叉卖出法

MACD 在 0 下多次金叉要考虑买入，0 下二次金叉要买入，0 两次金叉更要买入，0 下三次以上金叉买入大涨的概率就更大了，0 下金叉次数越多，大涨的概率就越大。

MACD 在 0 上多次死叉要考虑卖出，0 上二次死叉要卖出开空，0 上三次死叉更要卖出开空，0 上三次以上死叉开空单大跌的概率就更大了，0 上死叉次数越多，大跌的概率就越大。

# 1.4.3.1 MACD 0 轴以下二次金叉买入法

MACD 指标的要素主要有红色柱、绿色柱、DIFF 指标、DEA 指标。其中，当 DIFF、DEA 指标处于 0 轴以下的时候，如果短期内（8 或 13 个交易日内）连续发生两次金叉，则发生第二次金叉的时候，可能发生暴涨。

使用“MACD 低位二次金叉”寻找短线暴涨股，需注意下列事项：（1）MACD 低位一次金叉的，未必不能出暴涨股，但 “MACD 低位二次金叉” 出暴涨股的概率和把握更高一些。（2）“MACD 低位二次金叉” 出暴涨股的概率和把握所以更高一些，是因为经过 “第一次金叉” 之后，空头虽然再度小幅进攻、造成又一次死叉，但是，空头的进攻在多方的 “二次金叉” 面前遭遇溃败。从而造成多头力量的喷发。（3）“MACD 低位二次金叉”，如果结合 K 线形态上的攻击形态研判，则可信度将提高，操盘手盘中将更容易下决心介入。
