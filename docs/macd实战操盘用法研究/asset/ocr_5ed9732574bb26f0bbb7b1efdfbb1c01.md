# 2. 十日均线操作法

10日线上买，线下卖。

当前策略的上上策：金盆洗手一段时间，多干点正事，股市不是唯一门路。等候下一波牛市。这是炒手的最高境界。上策：精研技术，只做中级。中下策：勤抄底，做反弹。在中国，技术面为主，基本面为辅。基本面中，多一些宏观的（经济形势），少一些微观的（分红，个别公告）。技术面，多一些古典指标（KD，MACD，MA），少一些现代指标（波浪理论，四度空间）。简易操作法：收盘价在十天平均线上才可以考虑买入股票。收盘价在十天平均线下必须卖出股票。
