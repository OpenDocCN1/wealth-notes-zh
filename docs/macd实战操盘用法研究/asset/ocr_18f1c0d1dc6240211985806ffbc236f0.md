# 15.3 期货十段

这是网上广为流传的期货十段评定标准，现在摘抄如下：

一段：你刚进入期货市场，非常的兴奋，决心要在期货市场大有作为，对市场里的一切都比较模糊或空白，各个货币合约的规定你也不太清楚，要买什么要卖什么你也没有什么主意，你的交易主要是看各期货经纪公司网站的评论，或者听听朋友的建议，你总觉得他们说得都有道理。基本上都是看着行情的一会儿上一会儿下凭着自己的感觉下单，凭着运气和胆量可能也会赚钱，你的交易主要是日内的短线，交易十分频繁，赚点钱你就急着平仓，生怕到手的利润飞了，亏了你就抱着，想着总有解套的时候。听不进也听不懂风险忠告，大多很快就赔没了或是爆仓。三到四成的投资者已经爆仓。

二段：你很不甘心失败，连续追加资金，非要把亏的钱赚回来（勇气可嘉），但就是不去总结失败教训，直到血本无归，退出战斗。很多人从此不再相信期货市场能够赚钱。少部分比较有理性的人才能走过这个阶段。六到七成的投资者再次经历爆仓。

三段：你开始知道什么是技术面什么是基本面，你也知道了一些技术指标，移动平均线 MA、MACD、KDJ、RSI、DMI 之类的，总觉得它们有时准，有时又不准。你也关心基本面情况，今天都有什么重要经济数据，当前都有哪些热点问题和重大事件。你总是第一时间上网查查看。你的交易比较频繁，时赚时亏，但总的来说，账户是亏损的。

四段：你在市场上已经交易了一段时间了，但总的来说账户是亏损的。你觉得要在期货市场赚钱真的很难，你急着想翻本，可你不知道该怎么办。你看了一些关于交易的书，可你觉得他们说的是一回事，拿到这个市场中实际操作又蛮不是那么回事。你觉得还是指标不够精确，于是你试着调整参数，可它们仍然是有时准有时不准。你上论坛，希望得到高手的指导。可他们也是有时准有时不准。
