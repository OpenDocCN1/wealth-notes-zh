# 4. 均线稳定性因素

主动修复均线一般是产生在均线大幅发散的状态下，而被动修复均线一般是产生在均线发散的程度有限时。

# 三、均线系统的运作过程详解

均线的趋势转势动作的口诀是一靠、二出头、三穿越、四回踩、五拉升。一个跌势末期，趋势要想转势，股价必须先靠均线，也就是碰到均线股价拐弯向下。然后再有反弹时候刚过均线出点头，就无力站到均线上，立刻下跌，不能有效突破均线就跌下来。然后是再次反弹有效穿越均线，穿越均线后，回踩均线。均线发生支撑作用，股价拐弯向上，发动波新的拉升。跌势是类似的。下面我们看图仔细讲解。
