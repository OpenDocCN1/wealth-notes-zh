# 1.2.2 MACD 指标中的柱状图分析

在一般的行情分析软件中通常采用 DIFF 值减 DEA（即 MACD）值而绘制成柱状图，用红柱状和绿柱状表示，红柱表示正值，绿柱表示负值。用红绿柱状来分析行情，又可以起到明显的效果。

+   1. 当红柱持续放大时，表明市场处于牛市行情中，股价将继续上涨，这时应持股待跌或短线买入，直到红柱无法再放大时才考虑卖出。
