# 9.1.1 五升三降是波浪理论的基础

波浪理论认为：股票市场的发展遵循着五浪上升，三浪下降的基本型态，从而形成包含八浪的完整周期。前面五浪所组成的波浪是股市运行的主要方向，而后面三浪所组成的波浪是股市运行的次要方向。图中的第1浪，第3浪和第5浪称为推动浪，第2浪和第4浪则称为修正浪。
