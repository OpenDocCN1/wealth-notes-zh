# 1.4 MACD 指标的超买超卖与0线法则

# 1.4.1 0线的压力支撑作用与超买超卖的划分

使用 MACD 必须注意，0 线是其多空分界线，DIFF 和 DEA 两线在 0 线以上，则市场可以看作牛市；DIFF 和 DEA 两线在 0 线以下，则市场可以看作熊市。这就是 MACD0 线多空分界法则。

图 1.17 多空市场的划分

DIFF 和 DEA 两线离 0 线过远，则处于超买或超卖区域。如果 DIFF 和 DEA 两线在 0 线以上距离 0 线过远，MACD 处于超买领域，虽然市场为多头市场，但应该考虑多单平仓观望，谨防获利回吐下跌。

还有 DIFF 和 DEA 两线在 0 线上距离 0 线过远形成的金叉，并不可靠，尽量不要做多，如果非要做多单，最好短多。

然而，当 DIFF 和 DEA 两线在 0 线以上距离 0 线过远形成死叉后，接着形成金叉，这个金叉的位置离 0 线很远，后市很可能涨幅不大就开始下跌，此时的下跌形成了死叉，这种 0 线上方距离 0 线很远的二次死叉非常可靠，后市一般都会大跌，此时多单一定要果断出场，空单可以大胆入场。即使市场不转势，后市至少也会有大幅度的回调下跌。
