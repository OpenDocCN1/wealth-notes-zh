特别值得注意的是，短时期内 MACD 高位死叉非常可靠，后市必跌。短时期的含义是图形中最近两次 MACD 死叉的位置距离很近，这一点的重要性必须强调，远距离顶背离则不准确，有时可靠有时不可靠，但是近距离背离死叉非常可靠。MACD 将金不金，非常可靠的是——后市必跌。

# 1.4.2.2 MACD 将死不死买入法

MACD 低位形成将死不死，也就是 MACD 在低位将要死叉但是没有死叉接着上涨，后市必然大涨，要么转势，要么至少是一个大反弹。此时一定要买入，这就是 MACD 将死不死买入法。

MACD 低位形成将死不死的走势，回到更小的时间架构，一定是 MACD 0 下远离 0 线的二次金叉，并且这种二次金叉往往是上升双底形式的二次金叉，后市上涨的可靠性很大。因此 MACD 低位形成将死不死，后市一定会大涨。

作者认为最可靠的低位二次金叉，是同时发生 MACD 近距离底背离或者将死不死，事后必然大涨。这里必须强调一下，MACD 远距离底背离有时准确有时不准确，近距离底背离必定总是准确！
