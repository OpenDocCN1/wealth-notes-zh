# 1.4.3.2 MACD 低位多次金叉要买涨，高位多次死叉要放空

一个跌势中 MACD 如果在 0 线以下形成三次以上的金叉，表示虽然空方控盘，但是多方已经出现了三次反扑，这表明多方的力量通过三次反扑在增强，空方经过多方三次反扑力量大减，根据 MACD 极其有名的 “事不过三” 原则，0 线以下三次金叉，必定要么一波大反弹，要么转势。因此，建议投资者一旦看到 MACD 在 0 线下出现连续三次金叉，则可以考虑在第三次金叉的时候平空买涨。
