# 1.3 MACD 背离详解

# 1.3.1 顶背离和底背离

MACD 指标的背离就是指股价 K 线创出新高或者新低，技术指标 MACD 没有相应的创出新高和新低。MACD 指标的背离有顶背离和底背离两种。

# （一）顶背离

当股价 K 线图上的股票走势一峰比一峰高，股价一直在向上涨，而 MACD 指标图形上的由红柱构成的图形的走势是一峰比一峰低，即当股价的高点比前一次的高点高、而 MACD 指标的高点比指标的前一次高点低，这叫顶背离现象。

顶背离现象一般是股价在高位即将反转转势的信号，表明股价短期内即将下跌，是卖出股票的信号。
