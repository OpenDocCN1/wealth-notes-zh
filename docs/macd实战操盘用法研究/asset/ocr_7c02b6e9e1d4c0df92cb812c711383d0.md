# 图 1.15 连续的顶背离更为准确

以上是原则，一般顶背离较准，看到逃没错，下面至少有 15% 的跌幅，逃错了无非是少赚点，底背离买点就只能供参考，不能保证买了一定有 15% 的赚头，买了不涨只有止损。

还有一种背离叫做隔峰底背离或隔峰底背驰：第二次金叉出现底背离，第三次金叉位置比第二次金叉位置低，但是比第一次金叉位置高，相比第一次金叉也形成了背离，这就是隔峰底背离或隔峰底背驰。

隔峰顶背离或隔峰顶背驰：第二次死叉出现顶背离，第三次死叉位置比第二次死叉位置高，但是比第一次死叉位置低，相比第一次死叉也形成了背离，这就是隔峰顶背离或隔峰顶背驰。
