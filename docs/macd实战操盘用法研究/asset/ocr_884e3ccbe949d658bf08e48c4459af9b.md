# 2. 5. 2  MACD 与葛兰威尔八大均线法则的经典配合使用

葛兰威尔八大均线法则固然很好，但是很多人做股票或做期货心态不好，如果选点不对，先被套一段时间后才能盈利，很多人可能就在被套的时候割肉出局了。怎么样才能开上就基本不被套接着赚大钱呢？这就需要用 MACD 选取葛兰威尔八大法则的进场点。也就是发生葛兰威尔买卖点的时候，等待 MACD 金叉死叉选取进场点，并以随后的 MACD 金叉死叉出场。
