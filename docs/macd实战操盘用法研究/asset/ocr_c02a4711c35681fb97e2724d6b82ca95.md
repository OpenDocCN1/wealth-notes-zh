# MACD 实战操盘用法研究

进场。偶尔还有死扛单的时候。

第四年：经过三年多技术学习，这一年开始形成了比较准确的交易系统。前三年是在试用不同的交易方法和交易理论，试用过程伴随着不断亏损的代价，到这一年已经定下了交易方法。这年是这个方法在不同时间架构试用，不知道自己适合操作哪个分钟的图。有时觉得自己适合炒周线，有时觉得自己适合5分钟，在各个周期不断试错。

第五年：交易周期初步定在下，对多数期货人而言，这一年定下的操作周期基本都是15～60分钟。多数是30分钟或60分钟。

第六年：感觉自己距离成功只差一步之遥，有些期货人已经有过赚钱经历，甚至年度赚钱经历了，甚至交易回本了。

第七年：第四年到第六年总体上赚钱回本或者大赚，到今年重新走入亏损，因为赚钱的自信，导致了自己操盘资金迅速增长，自己受不了这么大的资金，自己具备稳定盈利的能力，实盘也必然稳定亏损。这个道理就是我们具有在20厘米高走钢丝的稳定盈利，但是100米的钢丝，同样的技术和方法，再走钢丝，必然稳定失败。

第八年：回头仔细回味，还是周线大势浩浩荡荡，第一次明白了什么势，第一次真正明白了逆势的可怕，并决定真正顺势交易。明白要想期货交易稳定盈利，必须从其他方面提高自己的修养，开阔自己的心胸，找到自己的信仰，开始让自己变得更好、更包容。只有如此，才能得到长期交易自信，心才能坦然，才能真正成为高手。

能稳定盈利的交易者，比例大约是5%，最终赚大钱的交易者大约是0.001%。根本的原因还是综合素质。成功的交易者，极少数是在5～8年开始成功，8～12年开始赚大钱；多数是在8～10年开始成功；10～15年开始赚大钱。对多数交易者而言，八年是一个坎，连续潜心交易八年，就处在了量变产生阶段性质变的临界点上了。最终的成功，无一例外是脚踏实地，勤劳敬业，自信乐观，坚持不懈，是人类共同的这些真正美德造就的。最后，成功就等于美德。期货最后的成功，就是集人类所有成功人士的共同诸多优秀品德于一身，才能成功。还没有成功的日子里，是因为自己还有一些优秀品德不具备，所以你才会不断尝受到失败的痛苦滋味，让你觉悟，让你放弃坏的品德，培养出这些优秀品德。

我做炒股、炒期货的根本原因和内在动力是什么呢？根源就是我是非常正直的人，想通过自己的智慧理财，即君子爱财取之以道。
