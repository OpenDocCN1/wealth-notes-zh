# 图 1.27 0 轴之上，多次死叉试探性做空

空。必须注意的是 MACD 在 0 线上连续 3 次死叉到底是什么意思？有什么技术要求？个人认为这 3 次 0 上死叉，必须保证第 3 次死叉前的前两次死叉形成的回调失败后的 MACD 金叉必须也处在 0 线上。也就是发生连续 3 次死叉的时候，需要这 3 次死叉中间的金叉死叉发生位置都必须在 0 线上。这是重要的。如果时而 0 线上时而 0 线下，那是震荡行情，不是我们要求的涨势，我们是要求涨势下，连续 3 次空方反攻，造成大回调或者转势，从而我们在第 3 次死叉平多反手做空。
