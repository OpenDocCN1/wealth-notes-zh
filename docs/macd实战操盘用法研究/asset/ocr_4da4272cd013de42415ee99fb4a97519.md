# （二）2B 法则

在上升趋势中，如果价格已经穿越先前的 Tên高价而未能持续挺升，稍后又跌破先前的 ♡高点，则趋势很可能会发生反转。下降趋势也是如此，只是方向相反。这两个法则不论是中长线的趋势中还是短线当日交易中都可以加以运用。

二、如果 是涨势，只要每波低点比前波低点高，则大胆在每次回调时候的 MACD 金叉做多，死叉平；如果是跌势，只要每波高点比前期高点底，则大胆在每次反弹时候的 MACD 死叉做空，金叉平。

激进交易者在次高时的 MACD 死叉下空单，次低时的 MACD 金叉出场；在次低时的 MACD 金叉做多，次高时的 MACD 死叉走人，长线做单，获利很大。
