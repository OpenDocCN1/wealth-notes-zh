# 图 1.18 0 轴之上，二次死叉做空

卖领域，虽然市场为空头市场，但应该考虑空单平仓观望，谨慎获利回吐反弹。还有 DIFF 和 DEA 两线在 0 线下距离 0 线过远形成的死叉，并不可靠，尽量不要做空，如果非要做空单，最好短空。

然而当 DIFF 和 DEA 两线在 0 线以下距离 0 线过远形成金叉后，接着形成死叉，这个死叉的位置离 0 线很远，后市很可能跌幅不大就开始反弹，此时的反弹形成了金叉，这种 0 线下方距离 0 线很远的二次金叉非常可靠，后市一般都会大涨，此时空单一定要果断出场，多单可以大胆入场。即使市场趋势不转势，后市也至少有大幅度的反弹。
