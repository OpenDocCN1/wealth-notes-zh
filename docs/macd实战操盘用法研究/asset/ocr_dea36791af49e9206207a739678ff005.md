# 2.2 均线系统的核心精髓与葛兰威尔均线法则详解

# 2.2.1 均线系统的弹簧板原理：均线系统的核心思想精髓

均线就是一个弹簧板，股价在弹簧板之上将不断上行，每次回落到弹簧板附近都会被弹上去，继续上行。数次之后弹簧板的弹力减小，股价开始刺穿弹簧板，但是弹簧板仍有弹性，仍可以把股价弹上去，股价仍可上涨，此时就比较勉强了，因为弹簧板老了，旧了，不堪大用了。最终弹簧板终于坏了，不行了，股价终于有效跌破弹簧板的支撑，这时候弹簧板成了每次股价反弹的新压力，弹簧板从旧的支撑弹簧板，变成新的压力弹簧板，股价从涨势转为跌势，股价每次反弹碰到弹簧板，都会掉头向下继续下行，数次之后，压力弹簧板变旧，不堪重负，股价随后的反弹开始刺穿弹簧板，然而此时的弹簧板虽旧，仍可以勉强把股价弹上去，最后终于有一次，股价彻底有效跌破弹簧板，旧的压力弹簧板就变成了新的支撑弹簧板，股价再次转势。

在我们的弹簧板原理中，关键的思想精髓要注意一个极其重要的万事相互转化的原理，阴阳互转的原理，新旧互转的原理。也就是股市刚开始反弹有效冲破旧的压力弹簧板，旧的压力弹簧板失效，新的支撑弹簧板形成。这时候，股价每次回落甚至不用回落到均线附近，甚至碰不到均线就立刻拐头向上沿着均线指引的方向前进，这也说明涨势的初期，看涨的力量非常强大，获利回吐的人很少，获利回吐造成的价格稍微下跌甚至仅仅横盘，就会有大量买进的人进来，导致股价甚至不必调整到均线就恢复上涨。

随着时间的推移，股价会回落，且回落到就要碰到均线，然后又再涨。再往后，股价又会下跌，通常会跌破均线，但这次是无效下跌。接着股价又会逆转上升，但上升持续不了多久，又会下跌，而这次是有效下跌，然后开始沿着均线一浪一浪往下跌。新的下降均线就是我们新的压力弹簧板。趋势转势了，然后股价沿着新压力弹簧板的下跌过程，股价的每次反弹，上涨过程的每次回落，道理是一样的，我们不再细讲。整个均线系统就是这样运作的，它是宇宙的一种自然规律，完全有规律可循。股价的运作完全是按它自身的规律运作，均不是随机的。只要把握了这个规律，达到长期稳定盈利完全是可能的。
