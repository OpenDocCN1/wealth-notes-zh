了，我们的错误总结完了，改正好了，慢慢地我们的棋手开始能偶尔胜李昌镐，最后胜李昌镐也水到渠成司空见惯了。至少不至于世界各大围棋赛的冠军奖杯基本全被李昌镐囊括吧？至少最近两年李昌镐拿到的世界围棋冠军奖杯就很少了。

这就是事物的本质，我们做期货也这样，只能长期失败，长期改正自己的操盘缺陷，坚持下去，最终是一定能胜利的。

# 2.6 小结：本章最主要的理论贡献

并向三线开花的最大要求是开花时（即 MA（20）金叉 MA（120）时），MA（120）已经金叉 MA（250）。而后边的顺向三线开花，开花后才形成 MA（120）已经金叉 MA（250）。而再后边的逆向三线开花则是开花后却形成 MA（120）死叉 MA（250）。这就是三种三线开花的本质差别。

回头望月是 MA（20）金叉 MA（120）后，股价回调到 MA（120）附近再涨，这是股价回踩 MA（120），就叫 120 跳马；快马加鞭是 MA（20）金叉 MA（120）后，股价高位横盘不回调等 MA（120）上来后再涨；顺水推舟是 MA（20）金叉 MA（120）后，股价慢慢涨上来既没有大回调，也不是强势高位横盘，自然上涨。

顺向火车轨是 MA（120）金叉 MA（250）金叉后，一直平行前进，后市必定长期大涨。类似的空头市场的顺向火车轨是 MA（120）死叉 MA（250）金叉后，一直平行前进，后市必定长期大跌。

小均线汇聚后，要么顺势服从要么扭转大均线，一旦出现均线汇聚，我们开仓的时机就快到了。小均线汇聚后，如果对大均线只出头不穿越，或穿越后不能有效回踩，回踩时接着回破均线，则是均线服从，后市按大均线方向前进。如果小均线汇聚后，对大均线穿越且穿越后有效回踩不破大均线，则是均线扭转，后市要转势，大均线方向要改变。

长期大跌后，MA 出现真金三角季价托和 MACD 出现 0 上金叉，两个条件同时发生，我们研判趋势转为涨势。入场点是真金三角季价托后的第一个 MACD 出现 0 上金叉进场做多。

激进交易者也可以仅仅根据真金三角季价托判断趋势转为涨势，入场点为真金三角季价托后的第一个 MACD 金叉（这里不要求 MACD 0 上金叉）。
