
离差值 DIFF 和离差平均值 DEA 是研判 MACD 的主要工具。其计算方法比较烦琐，由于目前这些计算值都会在股市分析软件上由计算机自动完成，因此，投资者只要了解其运算过程即可，更重要的是掌握它的研判功能。另外，和其他指标的计算一样，由于选用的计算周期的不同，MACD 指标也包括日 MACD 指标、周 MACD 指标、月 MACD 指标、年 MACD 指标以及分钟 MACD 指标等各种类型。经常被用于股市研判的是日 MACD 指标和周 MACD 指标。虽然它们的计算时的取值有所不同，但基本的计算方法一样。

在实践中，将各点的 DIFF 和 DEA（MACD）连接起来就会形成在零轴上下移动的两条快速（短期）和慢速（长期）线，此即为 MACD 图。

## 1.2 MACD 指标的一般研判标准

MACD 指标是市场上绝大多数投资者熟知的分析工具，但在具体运用时，投资者可能会对 MACD 指标的运用的准确性、实效性、可操作性上有很多茫然的地方，有时会发现用从书上学来的 MACD 指标的分析方法和技巧去研判股票走势，所得出的结论往往和实际走势存在着特别大的差异，甚至会得出相反的结果。

这其中的主要原因是市场上绝大多数论述股市技术分析的书中关于 MACD 的论述只局限在表面的层次，只了解 MACD 的一般分析原理和方法，而对 MACD 分析指标的一些特定的内涵和分析技巧的介绍鲜有涉及。

本节将在介绍 MACD 指标的一般研判技巧和分析方法基础上，详细阐述 MACD 的特殊研判原理和功能。

### 1.2.1 DIFF 和 DEA 的值及线的相对位置

- 1. 当 DIFF 和 DEA 均大于 0（即在图形上表示为它们处于零线以上）并向上移动时，DIFF 向上突破 DEA 时，一般表示为股市处于多头行情中，可以买入或持股；可以开多单并持有多单。
- 2. 当 DIFF 和 DEA 均小于 0（即在图形上表示为它们处于零线以下）并向下移动时，DIFF 向下突破 DEA 时一般表示为股市处于空头行情中，可以卖出股票或观望。可以开空单并持有空单。
- 3. 当 DIFF 和 DEA 均大于 0（即在图形上表示为它们处于零线以上）但都向下移动时，DIFF 向下突破 DEA 时，一般是股市的获利回吐，可以用于平仓多单，但是一般不能用来开空单。
- 4. 当 DIFF 和 DEA 均小于 0（即在图形上表示为它们处于零线以下）但向上移动时，DIFF 向上突破 DEA 时，一般表示将会出现一波反弹，股票将上升，可以短线买入股票。期货可以作为空单平仓条件，但是不推荐开仓买多单，最多只能做短多。

### 1.3 MACD 背离详解

### 1.3.1 顶背离和底背离

MACD 指标的背离就是指股价 K 线创出新高或者新低，技术指标 MACD 没有相应的创出新高和新低。MACD 指标的背离有顶背离和底背离两种。

#### （一）顶背离

当股价 K 线图上的股票走势一峰比一峰高，股价一直在向上涨，而 MACD 指标图形上的由红柱构成的图形的走势是一峰比一峰低，即当股价的高点比前一次的高点高、而 MACD 指标的高点比指标的前一次高点低，这叫顶背离现象。

顶背离现象一般是股价在高位即将反转转势的信号，表明股价短期内即将下跌，是卖出股票的信号。

## 图 1.10 MACD 顶背离

#### （二）底背离

底背离一般出现在股价的低位区。当股价 K 线图上的股票走势，股价还在下跌，而 MACD 指标图形上的由绿柱构成的图形的走势是一底比一底高，即当股价的低点比前一次低点底，而指标的低点却比前一次的低点高，这叫底背离现象。

底背离现象一般是预示股价在低位可能反转向上的信号，表明股价短期内可能反弹向上，是短期买入股票的信号。

### 1.4.2 MACD 将金不金卖出法与将死不死买入法

#### 1.4.2.1 MACD 将金不金卖出法

MACD 指标两曲线发生金叉时股价会上升，这是常识。但是，有时 MACD 两曲线高位死叉后股价也会上升，而且有时还会创新高，这就令人感到迷惘了。MACD 两曲线高位死叉后股价为什么也会上升？我们知道，当一列火车高速运行时，刹车后要它立即停下来是不可能的，巨大的惯性会使火车继续向前冲一段路程才会停下来。MACD 两曲线死叉发出卖出信号后股价还继续上升，如同火车惯性前冲的道理一样，是形成的上升趋势的惯性作用，是一波上升行情的最后一冲。随着股价惯性上升，高位死叉后的 DIFF 会勾头上行与 MACD 将要金叉

（未金叉），然后 DIFF 再勾头下行，形成“将金不金”的形态。MACD 两曲线“将金不金”形态出现，后市将会产生新一轮下跌。

MACD 两曲线高位死叉后形成的“将金不金”形态会引发新一轮下跌，对这一走势特点，有些投资者不了解，把 MACD 两曲线死叉后股价惯性上冲，误认为是一波新的大上升行情又开始，追高买入，结果跌进了“多头陷阱”，被高位套牢。我们在实际操作中，只把 MACD 高位死叉后的上升认作只是惯性上冲，采取快进快出的策略，才会避免跌进“多头陷阱”。DIFF“将金不金”后开始勾头下行，便要卖出，或者开空单。

其实到处常见的 MACD“将金不金”卖出法，只不过是 DIFF 和 DEA 远离 0 线后形成的二次死叉而已，不过多头势力较弱，第二次没有形成金叉，从而也没形成二次死叉。但是如果把时间架构变小，MACD“将金不金”卖出法肯定就是 MACD 高位二次死叉。如果日线形成 MACD“将金不金”，则 2 小时图或 1 小时图一定形成 MACD 高位二次死叉。

作者认为最可靠的 MACD 高位二次死叉卖出法是 MACD 高位二次死叉的同时出现顶背离或将死不死，后市必将大跌。

## MACD 实战操盘用法研究

特别值得注意的是，短时期内 MACD 高位死叉非常可靠，后市必跌。短时期的含义是图形中最近两次 MACD 死叉的位置距离很近，这一点的重要性必须强调，远距离顶背离则不准确，有时可靠有时不可靠，但是近距离背离死叉非常可靠。MACD 将金不金，非常可靠的是——后市必跌。

#### 1.4.2.2 MACD 将死不死买入法

MACD 低位形成将死不死，也就是 MACD 在低位将要死叉但是没有死叉接着上涨，后市必然大涨，要么转势，要么至少是一个大反弹。此时一定要买入，这就是 MACD 将死不死买入法。

MACD 低位形成将死不死的走势，回到更小的时间架构，一定是 MACD 0 下远离 0 线的二次金叉，并且这种二次金叉往往是上升双底形式的二次金叉，后市上涨的可靠性很大。因此 MACD 低位形成将死不死，后市一定会大涨。

作者认为最可靠的低位二次金叉，是同时发生 MACD 近距离底背离或者将死不死，事后必然大涨。这里必须强调一下，MACD 远距离底背离有时准确有时不准确，近距离底背离必定总是准确！
