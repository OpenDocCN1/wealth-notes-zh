# MACD 实战操盘用法研究

过于远离 0 线时候，多方才不得不调整一下，形成远离 0 线的 DIFF 和 DEA 死叉或者远离 0 线的 DIFF 和 DEA 二次死叉，市场调整一下，把 DIFF 和 DEA 调整到 0 线附近，如果 0 线支撑继续有效，则市场开始新的上升之旅，DIFF 和 DEA 也形成新的一浪比一浪高的上升之旅。

市场如果是跌势，则 0 线是 MACD 的强大压力线，每次 DIFF 和 DEA 反弹到 0 线，或略微涨破 0 线，必将受到 0 线的强大压力，而从 0 线弹开，继续下跌远离 0 线，因为跌势的核心就是要求 DIFF 和 DEA 必须不断下降，形成一浪比一浪低的下跌态势。只有确实 DIFF 和 DEA 过于远离 0 线时候，空方才不得不调整一下，形成远离 0 线的 DIFF 和 DEA 金叉或者远离 0 线的 DIFF 和 DEA 二次金叉，市场调整一下，把 DIFF 和 DEA 调整到 0 线附近，如果 0 线压力继续有效，则市场开始新的下跌之旅，DIFF 和 DEA 也形成新的一浪比一浪低的下跌之旅。

MACD 红绿柱子远离 0 线和靠近 0 线，利用 0 线对 MACD 红绿柱的支撑和压力作用做交易的方法，其核心思想也是远离 0 线的柱子要靠近 0 线，靠近 0 线的柱子要远离 0 线。

0 线附近时：0 线上，0 线对红柱子构成支撑；0 线下，0 线对绿柱子构成压力。

远离 0 线时：0 线上，红柱子远离 0 线要下找 0 线；0 线下，绿柱子远离 0 线要上找 0 线。

可见精确理解 0 线的支撑压力作用，以及 DIFF 和 DEA 远离 0 线必将被 0 线吸引回找 0 线的远离，就是我们正确理解运用 MACD 的一大核心。
