# 7.5.2 利用 MACD 形态可以提前预知市场趋势转势

MACD 出现底部反转型态时，我们可以猜测市场趋势转为涨势，或至少有大反弹；MACD 出现顶部反转型态时，我们可以猜测市场趋势转为跌势，或至少有大回调。月线 MACD 出现底部反转型态时，一般都是趋势转势。
