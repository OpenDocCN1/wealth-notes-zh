# （二）底背离

RSI 的底背离一般是出现在 20 以下的低位区。当 K 线图上的股价一路下跌，形成一波比一波低的走势，而 RSI 线在低位却率先止跌企稳，并形成一底比一底高的走势，这就是底背离。底背离现象一般预示着股价短期内可能将反弹，是短期买入的信号。
