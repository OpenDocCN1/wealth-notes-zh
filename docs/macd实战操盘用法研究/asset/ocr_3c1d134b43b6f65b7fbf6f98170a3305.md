0 线附近的金叉死叉非常可靠。如果市场是涨势，则每次 DIFF 和 DEA 两线反弹到 0 线附近形成的死叉，开空单获利的可能性非常大。如果市场是涨势，则每次 DIFF 和 DEA 两线回调到 0 线附近形成的金叉，开多单获利的可能性非常大。顺势单，MACD 背靠 0 线开多开空；逆势单，MACD 超买超卖区域开多开空。

市场如果是涨势，则 0 线是 MACD 的强大支撑线，每次 DIFF 和 DEA 跌到 0 线，或略微跌破 0 线，必将受到 0 线的强大支撑，而从 0 线弹开，继续上升远离 0 线，因为涨势的核心就是要求 DIFF 和 DEA 必须不断上升，形成一浪比一浪高的上升态势。只有确实 DIFF 和 DEA 过于远离 0 线时候，多方才不得不调整一下，形成远离 0 线的 DIFF 和 DEA 死叉或者远离 0 线的 DIFF 和 DEA 二次死叉，市场调整一下，把 DIFF 和 DEA 调整到 0 线附近，如果 0 线支撑继续有效，则市场开始新的上升之旅，DIFF 和 DEA 也形成新的一浪比一浪高的上升之旅。
