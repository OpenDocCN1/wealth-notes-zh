# 图 1.21 下破 0 轴，MACD 回抽 0 轴后继续跌势

上图 1.21 第一个箭头处表示出现一波大跌，随后的回抽 0 轴，没有站上 0 轴，后市继续下跌，即图中第二个箭头所指的大跌。

到图中第二个圆圈处再次回抽 0 轴勉强稍微站上了 0 轴，但是随即跌破 0 轴，又回抽 0 轴失败，于是再次大跌，即图中的第三个箭头。

可见精确理解 0 线的支撑压力作用，以及 DIFF 和 DEA 远离 0 线必将被 0 线吸引回找 0 线的远离，就是我们正确理解运用 MACD 的一大核心。
