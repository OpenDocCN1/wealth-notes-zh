# 图 14.36

图 14.36 是玻璃 1501 五分钟图。

21 日早上的 5 分钟趋势顶背离，被下午的 5 分钟底背离化解，后市将继续上涨。这给我的启发是绝对不能做逆势单，日线是涨势的情况下，5 分钟的趋势顶背离下跌空间也很小，并且很快重新转为涨势。绝对不能对下跌空间有大的期望或担心，对分时不好的图形绝对不要认为要大跌，或者要跌到某个价位。事实上跌到 15—30MA30 附近时就不大可能跌了。
