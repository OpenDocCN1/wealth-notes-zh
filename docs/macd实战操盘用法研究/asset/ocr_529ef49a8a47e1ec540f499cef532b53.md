# 12.1 缠论的基本概念和基本理论

缠论是 2005—2008 年由缠师独创的技术分析理论，该理论博大精深，深受投机人士喜爱。在投机领域，笔者真正发自内心佩服的中国人并不多，缠师是笔者真正佩服的第一人。个人认为他是世界上最伟大的投机大师，他的理论是世界上最伟大的理论，他开创了技术分析领域的科学研究之门，此前的研究有些是不着边际的，从他以后，技术分析才首次真正成为严谨的科学。

他发现的这个理论是解释价格波动的终极理论，这是真正的天机。个人认为缠师是因为泄露了天机，而在 2008 年被神收走，刚刚写完这个理论就仙逝了。缠师的另一个伟大在于他无私地贡献了他独创的全部理论，缠师是谁？他是男还是女？现在还是未解之谜。他是仙逝了，还是退隐了，个人还是觉得仍是未解之谜。个人觉得他可能还活着，但是如此天机居然公布于众，估计是犯了天条了，可能真的被收走了。

笔者对缠论的理解还有很多很多不到位的地方，笔者以后的时间里会继续研究缠论。笔者也要学习缠师伟大的情怀，毫不保留地公开自己掌握的技术分析精华，去普世救人，力争做一个伟大的爱他人如爱己的人。这方面缠师就是我们行为的典范。
