# 4.5 小结：本章最主要的理论贡献

一、对 RSI 的金叉死叉，按顺势逆势情况做了区分，顺势的才做中长线单，逆势的只做短线单。

二、市场趋势是涨势时，RSI 至少两次达到 80～100 区间；市场趋势是跌势时，RSI 至少两次达到 0～20 区间。

三、对 RSI 形态和 RSI 背离做了详尽分析。

四、明确了 MACD 与 RSI 同周期共振进出场技巧。

MACD 与 RSI 同时发出买入信号，后市必涨，按 RSI 金叉进场做多，死叉平仓出场；MACD 与 RSI 同时发出卖出入信号，后市必跌，按 RSI 死叉进场做空，金叉平仓出场。

五、明确了 MACD 与 RSI 形态共振做单技巧。

MACD 与 RSI 同时出现看涨形态，就进场做多单，RIS 金叉进场，以 RSI 死叉出场；MACD 与 RSI 同时出现看跌形态，就进场做空单，RIS 死叉进场，以 RSI 金叉出场。
