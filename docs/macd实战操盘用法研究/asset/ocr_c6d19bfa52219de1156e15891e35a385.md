# MACD 实战操盘用法研究

场点为真金三角季价托后的第一个 MACD 金叉（这里不要求 MACD 0 上金叉）。

长期大涨后，MA 出现真死三角季价托和 MACD 出现 0 下死叉，两个条件同时发生，我们研判趋势转为跌势。入场点是真死三角季价托后的第一个 MACD 出现 0 下金叉进场做空。

激进交易者也可以仅仅根据真死三角季价托判断趋势转为跌势，入场点为真死三角季价托后的第一个 MACD 死叉（这里不要求 MACD 0 下死叉）。

# 图 2.23 豆油

上图 2.23 是豆油连续日线走势图。2006 年 5 月到 2008 年 3 月豆油的超级大牛市，让很多期货死多头发了大财，那么这样的牛市何时转为熊市呢？我们该什么时候进场做空呢？

图中圈 1 之前没有出现过死三角价托，圈 2 之前没有出现过 MACD 0 下死叉，因此圈 1 和圈 2 之前市场为涨势，绝不能入场做空，只能大胆顺势做多。图中圈 1 出现了一个死三角季价托，并且是真死三角季价托，圈 2 出现了 MACD 0 下死叉，表明此时趋势转为跌势，此时平了多单入场做空。入场点为圈 2 中的 MACD 死叉（这也是第一个 0 下 MACD 死叉）。我们发现在圈 2 MACD 0 下死叉入场下的空单，就一直处在盈利状态之中。
