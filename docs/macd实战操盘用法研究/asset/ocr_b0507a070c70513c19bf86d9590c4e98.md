# 2.1.1 MA 的计算方法

均线指标（MA）实际上是移动平均线指标的简称。由于该指标是反映价格运行趋势的重要指标，其运行趋势一旦形成，将在一段时间内继续保持，趋势运行所形成的高点或低点又分别具有阻挡或支撑作用。因此均线指标所在的点位往往是十分重要的支撑或阻力位，这就为我们提供了买进或卖出的有利时机，均线系统的价值也正在于此。均线向上是均线多头，均线向上产生的交叉是金叉，反之是死叉。
