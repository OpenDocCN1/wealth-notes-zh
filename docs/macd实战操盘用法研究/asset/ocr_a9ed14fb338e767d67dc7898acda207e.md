# 七、收盘价的使用与横线的存在

道只依据收盘价。他相信，平均指数必须收于前一个波峰之上或前一个波谷之下才有意义。道不认为日内的突破是有效的。

当交易者提到平均指数中的横线时，他们是在指有时出现在走势图中的水平形态。这些横向的交易区间通常在调整阶段扮演重要的角色，而且通常被称为现固。在更现代的名词中，我们可能称这种横向形态为“矩形”。
