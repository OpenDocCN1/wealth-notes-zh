当然按照 MACD “事不过三” 原则开仓，如果不能获利，后市必须止损的。如果开的是多单，开后一直被套，可以等 MACD 死叉后坚决止损出场；如果开的是空单，开后一直被套，可以等 MACD 金叉后坚决止损出场。

如果 MACD 出现连续三次以上 0 下金叉，第三次金叉形成了底背离或隔峰底背离，后市涨的概率大大增加，一定 sdk0平空做多；如果 MACD 出现连续三次以上 0 上死叉，第三次死叉形成了底背离或隔峰底背离，后市下跌的概率大大增加，一定 sdk0平多做空。
