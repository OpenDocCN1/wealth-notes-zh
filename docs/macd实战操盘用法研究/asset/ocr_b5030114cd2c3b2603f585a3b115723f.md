# 7.5 MACD 与形态理论的配合

# 7.5.1 利用 MACD 提前预知价格形态，提前高位放空低位做多

猜测是看涨形态则利用 MACD 金叉做多，是看跌形态则利用 MACD 死叉放空。猜测是持续形态，当前涨势，则按 MACD 金叉做多；当前跌势，则按 MACD 死叉放空。

例如价格涨到前期顶部涨不动了，出现 MACD 死叉，我们可以做空，猜测后市出现 M 头，如果价格跌破颈线前 MACD 金叉了，则空单止损。例如价格跌到前期底部涨不动了，出现 MACD 金叉，我们可以做多，猜测后市出现 W 底，如果价格反弹到颈线前 MACD 死叉了，则空单止损。
