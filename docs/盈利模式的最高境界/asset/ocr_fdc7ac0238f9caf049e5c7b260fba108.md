# ## 第六点：不可抗拒的独特卖点

我们介绍这个案例的时候，你可能会更有感觉一点。但是你的一个营销是冲着一群人进行的，对吧？比如说你的杂志、广告往那里一登是冲着一群人的，这一群人对某种特征的需求是不一样的。比如说你的产品有一二三四五个卖点。

然后你应对三个特征人群。

那么一个人群他可能会把一二三四五个卖点列出来；

另一个人群可能列出的卖点是二三四五一；

第三个人群列出的卖点可能是三四五二一。

每个人群的重点是不一样的。一定是这样的，就是说不同的人群会优先不同的卖点。那么这里面有几种不同的哲学。
