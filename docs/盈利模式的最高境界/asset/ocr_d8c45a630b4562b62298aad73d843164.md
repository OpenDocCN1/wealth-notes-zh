# 第一个密码：最有效的增销

增销就是说他买了一个东西之后，花了 1000 元，然后你说我们还有 1500 元的版本，价值是那个 1000 元钱的两倍。

就是在他原来的销售额的基础之上提高销售额。

![](bbox=[0.12, 0.35, 0.88, 0.48])

例如 2017 年之前一诺老师的课程就是阶梯定价，1980 元网络基础班，5980 元网络高级班，如果你觉得初级班好，就可以补差价升级高级班；

上完高级班，还可以补差价上线下全能班，当时线下全能班 19800 元，结果大家因为上了基础班和高级班受益了，就毫不犹豫加钱升级更高的班级，这就是增销。

不过现在一诺老师创立的【改变世界】APP 几千万粉丝，而且还在不断的裂变，因此一诺老师重点放在搭建平台，而且现在一诺老师的音频/书籍等，终极弟子推广拥有 100%的分润。
