# 第七大元素：不可抗拒的送货条款

送货条款有各种各样的，比如说现场提货，那当然是最好的，交完钱马上得到产品，非常有吸引力。

如果说 xxxx 天内送货上门，它的吸引力没有现场提货这么好，但是有时候客户没法现场提货，这时你可以说我用特快专递，

24 小时发货，而且告诉你快递公司名称，这样吸引力又增加了。

一诺老师在 18 年前卖自己的课程 DVD 光盘和书籍的时候，曾经了解到很多客户顾虑，全国各地的，比如“我的朋友都说我一定 会受骗的，请你帮我发货好吗？”这体现出了客户的心态！

![](bbox=[0.13, 0.55, 0.87, 0.68])

当你的发货日期离付款期越近，你成交的可能性就大，因为你 降低了对方的忧虑，降低了对方的担心，你在给他创造价值，所以 “发货方式”影响你成交主张的吸引力。
