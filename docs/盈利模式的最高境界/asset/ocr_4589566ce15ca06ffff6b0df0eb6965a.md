# **第七节：潜在客户资格框定**

在这里有几个重要因素，就是潜在客户的框定非常重要。一诺老师曾经讲过两种方法。

# **第一种框定：身份限定**

因为你提供了一个**无法抗拒**的主张，你不希望所有的人都进来，你要对你的潜在客户有一个限定。

比如说你卖保健品，你可以限定你的潜在客户的年龄，或者是限定一个街区，住在这个地方的并且有你以前体检的历史的人。

![](bbox=[0.13, 0.54, 0.87, 0.65])

每个情况不一样，你需要慢慢地限定。就是说你通过逐渐的更好的限定你的客户，使你的变现率更高，你的成本更低。

很显然，你这里如果能够通过某种资格的排除，把一些非你的潜在客户排除，那么你的变现率就提高了，你的整个吸金成本就降
