# 第一节：疯狂吸引用户

这里边非常重要的就是你的企业，任何时候你想成立一个企业，就说明你在某一方面具有的优势，然后把它演化成产品和服务，你们为某种特定的人群创造价值，能够帮他实现某种梦想，这是你创立企业的一个重要的价值。如果你不能说道过我的产品和服务为一部分人创造价值，那其实你的企业就不应该存在。
