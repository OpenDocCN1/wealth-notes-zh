# 第九节：描绘美好愿景

描绘愿景是一个非常重要的技术。

因为大部分人都模模糊糊的有一个愿景。

比如说我为什么要购买这个东西？

我为什么要参加一诺老师的课程？

没有人只是为了--一诺老师的课程而学--一诺老师的课程。

没有人只是说我钱没地方花了，我就想购买一个结婚戒指，其实他的结婚戒指对他的人生，让别人看到他的戒指就知道他是已经结婚的，是成了家的等等。一整套的思想，他有一个梦想。

![](bbox=[0.18, 0.52, 0.82, 0.65])

但是 99%的人无法用自己的语言描绘他究竟要达到的是一个什么样的梦想状态。

比如他买电脑也是一样，他没有说没事干了买一台电脑。
