# 第四节：追售的最佳主张数量

追售的主张数量不要太多，不要既追售500元的产品，又追售2000元的、3000元的产品。最后把客户给搞困惑了。

追售的额度，一个是要测试，另外一个要根据信任的程度而定。

如果你卖他一个500元钱的卡，你还有机会卖给他5000元的产品。如果你卖他5000元的产品，他不要，如果你销售的方式不好，那么你可能永远失去了这个机会。

![](bbox=[0.13, 0.46, 0.86, 0.59])

例如：购买《猪买单》3980元的学员，这样的学员一般都是骨灰级的粉丝，非常相信认可一诺老师！

那么一诺老师的助理和弟子就可以顺便问一下，要不要带一套《全球疯狂吸金》1本才398元，如果他说好吧，很便宜买1本。

后来发现，这么便宜多买几本、甚至其他弟子的书也带上。但是弟子在推荐的时候，只能先推荐1本，这样他们觉得便宜。
