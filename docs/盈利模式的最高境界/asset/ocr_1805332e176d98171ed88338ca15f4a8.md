# 第五个密码：最有效的搭销

搭销跟增销是有区别的。“增销”是提高客户购买的金额，比如一诺老师的《商业模式·顶层设计书籍》298 元，通过你的主张，最后他买了3980元的《猪买单》，这叫“增销”。

而“搭销”是指卖完一个产品后，又卖了另外一个相关的产品。就像客户买西服后又买领带的故事，这是“搭销”。

例如：一诺老师的粉丝很多，因为他们喜欢、认可、热爱一诺老师和整个平台，那么很多弟子出书，也放到【改变世界APP】上面卖，别人一看原来是一诺老师终极弟子写的书，作者是：一诺老师+某某弟子，于一是一诺老师的粉丝爱屋及乌也顺便购买一本。

很多终极弟子的书《成交心法》、《品牌魔力》、《万能演讲模版》、《营销设计》、《勾魂攻心》等，就是靠着一诺老师这颗大树，靠着【改变世界APP】里面有海量的粉丝，每月卖书都有几万进账。
