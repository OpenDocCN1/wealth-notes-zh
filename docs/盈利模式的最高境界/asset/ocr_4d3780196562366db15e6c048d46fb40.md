# 第 3 个核心：快速引爆精准鱼塘

究竟是什么样的潜在客户 (鱼塘)?

很多人说，所有人都是我的客户。就像他卖眼镜的一样，所有人只要戴眼镜的都是我的客户。你说的对，如果是不要钱也许他们会要，但问题是你的产品是需要钱购买的，就不一定都是你的客户，你需要找的不仅是需要你的产品的那些人，需要你的产品有很多人都需要，但是想要才是关键，想要他才愿意付钱。

一诺老师的弟子都知道，其实只要认真的看一诺老师书籍，或听天一诺老师音频课程者都能够受益。但是很多企业老板会去看吗？他不会，也许他认为他什么都懂；也许他已经有了其他的想法；也许他根本就不认为有方法可以解决他的问题……有各种各样的原因。

也许下雨没打伞的人认为培训还要收费，开什么玩笑，不就是想法嘛！对吧？有各种各样的因素决定他需要，但他不想要。
