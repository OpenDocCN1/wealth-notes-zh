# 第十节：破解人本灵魂密码

如何成为吸金大师，就是你要观察，人性是共同的，但是表现的方式是各种各样的。就像学建筑的一样，力学的原理可能并不多，但力学原理表现的形态太多了。

人性也是一样的，但表达的方式不一样。刚才说的积分卡的这种方法，你们很多人都可以用，但是你得思考怎么去用上它。就是说怎么帮助顾客迈出第一步。

![](bbox=[0.11, 0.47, 0.89, 0.6])

举个例子，如果你让客户从现在坐火车去上海，你对你的客户说你去做车站坐火车去上海吧，可能很多人不会去。你对你的客户说我都帮你买好了去上海的火车票，明天上午10点整出发，你去吧，可能有更多比例的人去。你对你的客户说明天我陪你去火车站，可能性又更在一点。你说我不仅陪你去火车站，我还陪你一起上火车，然后走了一站之后你下车了，那他去的可能性就更大了。
