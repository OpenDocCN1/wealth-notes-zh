# 第二节：变现主张的核心

然后我们看大部分人的主张，99%的主张都可以看到这种情况。

说你现在付 5000 块钱给我，下一次你去取产品，到阳光大酒店 8 楼去取产品，然后取完之后至于说行不行我们不能保证退换。

如果是这么一个主张，很显然，是 很难把产品销售出去的。但是很多人的主张都是这样的。

如果你去看所有的广告，把它所有的枝 节给分离出去之后，最终它的核心主张是什么？
