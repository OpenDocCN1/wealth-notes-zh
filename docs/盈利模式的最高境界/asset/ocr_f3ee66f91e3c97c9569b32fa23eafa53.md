# 第十节：完美的变现流程

变现流程也是非常重要的。为什么呢？

变现流程是一个客户从来没有见过你，对你没有任何的信任。你通过一个什么样的流程？通过一个什么样的过程，然后把他变成你的客户，变成你重复购买的客户，变成你忠实的客户。

这个流程是非常重要的。你的任何的销售，当你和顾客接触的时候，你必须要说你给什么具体的价值，你要说清楚他给什么好处，什么报酬。领取价值 500 元的耳坠；或者参加这个价值多少钱的培训，或者是接受什么样的检查。
