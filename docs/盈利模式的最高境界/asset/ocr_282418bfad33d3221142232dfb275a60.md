# 第十一节：变现时机的策略

一诺老师还有很重要的一点就是变现的时机把握，

一个就是他已经确定拿好了这个赠品之后，然后你说：“也顺便跟你说一下，我们这个星期有个特别的促销，只对新客户。这是我们的 150 元的套装，现在只需要 70 元钱，但是只能对新客户。如果你走了，我们就不能给你了。”

![](bbox=[0.15, 0.42, 0.88, 0.55])

你需要在他前面一个阶段完成之后，再进行一个追售的说服。

但是主张不能有强迫性，如果你觉得他在抵触，你就不要再推了。没有关系，你就是不要有太强烈的追售意图。

如果他要有抵触，你还硬推，那么人家就会觉得你前面为抓粉免费赠送的东西不是真诚的，你真正的目的根本不是要我价值，你的目的还是要赚钱。
