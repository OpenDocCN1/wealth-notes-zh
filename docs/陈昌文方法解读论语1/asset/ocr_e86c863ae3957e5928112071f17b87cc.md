# 6. 如何算是一个合格的领导人

原文

季康子问：“仲由可使从政也与？” 子曰：“由也果，于从政乎何有？”曰：“赐也可使从政也与？”曰：“赐也达，于从政乎何有？” 曰：“求也可使从政也与？” 曰：“求也艺，于从政乎何有？”

陈昌文解读《论语》：

季康子问孔子，仲由有能力从政吗？管理政治，做领导吗？端木赐呢？冉求呢？孔子说，这些弟子都可以从政，管理政治，做领导。仲由这个人果断，有决断，来得快。端木赐这个人通达，聪明智慧，闻一知二，会变通，灵活。
