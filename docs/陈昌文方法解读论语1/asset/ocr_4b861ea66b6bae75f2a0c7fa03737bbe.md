# 30. 人命关天，要关心别人的生命

原文

厩焚，子退朝，曰：“伤人乎？”不问马。

陈昌文解读《论语》：

厩，养马的马厩，厩焚，马厩失火了。

子退朝，孔子退朝回家知道这个事情了。

首先就问，伤到人了吗？而不是开口就问，伤到了自己的马吗？

在古代，马是非常昂贵的，说不好听一点，在那个时代甚至比普通老百姓都贵。
