# 3. 毋固。

不要固执己见，错了就错了，早点认。不要继续固执，给自己，也给别人，甚至是整个组织造成更大的损失。有些人明明错了，自己也知道，但还是要固执己见，为什么？面子问题，觉得承认自己错误是丢脸的。如果您客观上，就是没别人厉害，就是错误的，您承认了，并不丢脸，反而显得您聪明、智慧，格局大，心胸开阔。如果您继续固执，大家就只能离开您了，您在大家的心里，其实是非常愚蠢的。
