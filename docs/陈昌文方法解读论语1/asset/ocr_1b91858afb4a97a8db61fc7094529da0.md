# 21. 见\[到\]对的，立刻学习，
见\[到\]错的，立刻反思，有错就改

原文

> 子曰：“三人行，必有我师焉。择其善者而从之，其不善者而改之。”

陈昌文解读《论语》：

孔子说，三个人同行，一定有可以做我老师的地方。看到对的，善的，值得学习的，就跟着学与做。看到错误的，不善的，反思自己有没有这个毛病，立刻改正。三个人一起做事，一起学习，一起修德进业。您总是能发现一个人的优点，也能发现一个人的缺点。不是非要比您强，才能做您老师。比您弱，也可以做您老师，当反面教材嘛。
