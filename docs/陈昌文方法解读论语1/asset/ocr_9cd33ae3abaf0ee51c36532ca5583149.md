# 陈昌文解读《论语》：

信是什么意思？就是你要讲信用，你说过 的话，必须兑现。说过的话要 兑现，就不要乱说话，要看准了才说，要做得 到才说，所谓：“轻诺必寡信。” 你说话，经常不兑现，以后就没人相信你了。觉得你这个人不靠谱，你就没 公信力，也没有领导力了。

人无信不立。商鞅徙木立信，就是为了建立政府的信用。

义是什么意思？

就是义理，合实际的，应该做的，有道理的事情，在自己能力范围内的事情，自己 也愿意去做的事情。

满足不了这几条，你去承诺给别人的事情，怕就要食言了。

恭是什么意思？

就是对人、对事，都要恭恭敬敬，有态度。这样，你就是一个懂礼的人了。比 如，我有一个员工小张，对老板、客户都是大喊大叫，虽然工作干得好，但是不懂 得尊重人。结果，有一次就被客户当着面侮辱了。小张就觉得自己非常没面子，但是 也没办法。这就是受到了侮辱，所以，做人恭恭敬敬，有礼貌，所谓：礼多人不怪。就 可以远离一些耻辱。

再比如，我们经常看到一些新闻，几个朋友在一起喝酒，吹牛。结果，因为有些 人开玩笑，没分寸，就骂起来、打起来，甚至闹出人命的。这都是不懂得恭敬，不懂 得礼数的后果。

其实，一个人懂了礼数，懂了恭敬，会碰到很多贵人的。如果不懂礼数，得罪 人，一些本来想帮你的人，看你这个样子，就默默地走开了。当然，叫你恭敬，并不是 让你谄媚，让你阿谀奉承，一个人习惯性谄媚，阿谀奉承，也会被人瞧不起，这属于自取 其辱。所以，很多事情，都讲究一个平衡。
