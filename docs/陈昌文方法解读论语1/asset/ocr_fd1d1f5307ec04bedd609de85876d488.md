# 27. 礼数到位的本质，是心到位了

原文
乡人皡，朝服而立于阼阶。

陈昌文解读《论语》：

乡里乡亲的，也会祭祀，驱逐疫鬼。
就是乡间的驱鬼祭祀活动。
这时候，孔子就会穿上朝服，立在自己家门东边的台阶上。
为什么要立在家门东边的台阶上？是为了守护自己家里的祖先，自己家里的祖先牌位放家里祭祀，怕这些驱鬼的活动惊扰了自己家里的祖先。
自己穿着朝服，立在门口东边台阶上，家里的祖先就安心了。
这就是祭神如神在。
家里摆着祖先的牌位，不是摆着就摆着了，而是时时刻刻的想到有这回事，每个步骤，礼数都要做到位，礼数到位的本质是心到位了。
