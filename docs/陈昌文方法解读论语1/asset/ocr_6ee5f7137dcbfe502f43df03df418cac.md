# ## 10. 如何看透一个人

原文

子曰：“视其所以，观其所由，察其所安，人焉廋哉？人焉廋哉？”

陈昌文解读《论语》：

所以、所由、所安。分别对应目的、手段、心安于何处。搞清楚一个人的目的、手段、心安于何处。这个人就被你看透彻了。视其所以的意思，就是看一个人的目的、目标，这个人到底想要干什么？想做一件什么事，想成为一个什么样的人？成为一个商人吗？成为一个罪犯也无所谓吗？

比如，我读小学的时候，我们班里有一个同学，非常崇拜电视里的黑社会。说自己以后就要成为那样的人。最后，就跟街上的那些无赖流氓玩在一起了。这就是这个人的目的。有的人呢，想成为一个好人，一个富有的有钱人。这也是他的目的。但是，我们要观其所由。也就是要看他的手段、方法。他是为了实现自己的目的不择手段吗？比如，我们有的人做项目赚钱，就做色流。做色流，是能赚钱，而且很多项目都用在色流在养活自己，比如壮阳、阳痿、早泄等互联网项目，好多人都用色流在养活自己。这就是手段不正当。这也体现了一个人的人品。圣人是不用卑鄙、恶劣的手段实现自己的目的的。我们要用正规的手段，赚干净的钱。
