# # 15. 学习的本质是行动，而不是批判谁

原文

> > 子路有闻，未之能行，唯恐有闻。

陈昌文解读《论语》：

子路听到有用的道理，还没做呢，还没来得及实践，就怕听到其他道理， 因为其他道理，也是要来实践的，上一个道理没有实践完毕，就不敢听到下 一个道理。这是一种非常好的学习观念。就是学习，是用来实践的，不是嘴 上争斗，不是我懂了一个道理。

比如，您知道一个赚钱的方法，赶快去实践，而不是争论，探讨，讲说。
