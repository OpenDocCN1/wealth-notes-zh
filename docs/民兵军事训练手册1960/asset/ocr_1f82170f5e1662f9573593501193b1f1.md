跑步回隊，后面部隊亦照樣派出标兵，如此挨次交代，一直到最
后。

# 連絡員的動作。

夜間行動的時候，擔任連絡的人數和各人之間所取的距
離，應當按照兵力和明暗的程度決定。派出的連絡員在兩名
以上，應當指定連絡長負責。

連絡員的動作，應當力求靜肅、迅速，並且必須熟悉以下
幾點：

+   1. 進行連絡，一般用快步行進。跑步會妨礙靜肅并且容
易跌倒，在接近敵人或者在不齊地行進，更絕對禁止跑步。行
進的時候要顧及前、後的連絡，不可以圖自己方便，自由行
動。

+   2. 距離敵人很近的時候，報告和連絡都不可以大聲。在
前方的連絡員，若是用記號向後方報告，後方受報告者明了報
告意義後，要立即用記號回答，前方連絡員亦要等回答“明白了
”的記號之後，方能停止報告動作。

+   3. 遇有叉路，要設置記號或者留标兵，指示行進的道路。
設置的記號可以用樹枝、稍梢阻塞不能通行的路口，在行進路
上撒白粉箭頭或者用石頭、土塊压住白紙條。

+   4. 前面部隊停止，連絡員應當立即停止，以免隊伍擁擠。
後面部隊距離拉的過遠或者失去連絡，連絡員應當迅速報告
連絡長，加派連絡員去尋找，連絡長并且應當報告前后的部隊
指揮員。

# 教學實施方法。

+   1. 先在白天練習，確實了解要領後，再在夜間練習。

+   2. 音响、光號的連絡，事先規定好，使戰士在白天練習時
記熟。有能学鳴叫蛙叫的戰士，應當要他个别着重練習。
