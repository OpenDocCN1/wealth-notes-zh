# 一 地形、地物的識別與利用

# (一)地形、地物的識別

什麼是地形地物？地形是指地面上高低起伏的形状，如山地、丘陵、平原等。地物是指地面上天然的（河淺、沼澤、森林、沙漠和草原等）和人工的（居民點、建築物、道路等）固定物體。

# 地形地物對軍事行動的關係：

地形地物的條件對軍事行動有著密切的關係。如進行攻防戰、行軍、宿營、觀察、射擊等等，都必須考慮到地形地物的影響。尤其是在戰鬥中，如果能很好的利用地形地物，可以以少胜多；取得戰鬥的勝利；如果不善于利用地形地物，則會增加傷亡，遂成戰鬥中的困難。在現代戰爭中，對原子、化學武器突擊的防護，地形地物條件更有著重要的作用。因此，每個民兵都必須了解地形地物對軍事行動的關係，以便在不同的地形地物上正確地、靈活地行動，以達到歼滅敵人、保存自己的目的。
