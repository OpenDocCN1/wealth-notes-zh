# 原子武器的杀伤破坏作用

原子武器爆炸后，有四种杀伤破坏因素：

1. 冲击波：冲击波是原子爆炸时最主要的一种杀伤破坏因素。这是由于爆炸后形成的一股气流，急剧地向四周扩张，就好像一阵猛烈的飓风扫过大地。冲击波的威力大、速度快，在二秒钟内就可到达距爆炸地点1000米（一公里）以外的地方。它能吹坏500米内的坦克；700米内的火炮；1200米内的汽车；并能把房屋树木推倒。被冲击波推倒的房子、吹毁的石块等，对人的伤害也很大。不过，距离爆炸点愈远，冲击波的力量就愈小；冲击波的速度再快，也还要有段时间。所以我们可以抓紧这极短的几秒钟时间，采取适当办法避免冲击波的伤害。例如趴倒在地面，躲入坚固的房屋和物体内等（图4）。

2. 光辐射：原子爆炸所形成的火球，比夏天太阳光的强度还大许多倍，这就是光辐射。由于它的光线极强，可以烧着或熔化各种物资，引起火灾；照射到暴露的皮肤上，就会灼伤皮肤。
