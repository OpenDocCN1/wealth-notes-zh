情。遇有障碍物（如拒馬等），先觀察有沒有加強的爆炸物（系有手榴彈、地雷等），如果有，可以用掛鉤的繩子拉動引信，或者用手榴彈投擲誘發爆炸，然後將障碍物抛出壕外，繼續迅速前進。遇到敵掩蔽部，應當向里面投擲手榴彈，消天內部殘存的敵人。

# （五）教學实施方法

+   1.精講多練。對必須講解的部分，可由教員（或民兵干部）講授，然後讓大家討論，也可以先由大家討論，提出問題，再由教員講解。必須掌握精講多練的原則，騰出更多的時間進行練習。

+   2.基本動作練習，必須反覆進行，達到確實與熟練。練習時應當在現地進行。先以連或排為單位，按照每個動作，隨講要領，隨做示範。各班排開後，按照情況可以分組練習；由動作較好的同志當小先生，也可以自由結合，互相糾正動作，共同研究，取长补短。

練習中也可以采取在較遠的距離上設上假設敵（注意不要派人太多，以免影響學習），觀察運動時的姿勢是否過高，如果過高，可吹哨示警引起注意。

對於動作較好的同志，可以在全連作示範表演，启发大家研究，學習。

+   3.每一個動作都熟練以後，應當把各個動作連貫起來進行綜合練習（參看下頁附表二）。

# （一）防禦戰鬥的目的

防禦是戰鬥類型的一種。防禦的目的是固守占領的陣地，利用有利的防禦工事，以火力和反衝擊，抗擊敵人優勢兵力。
