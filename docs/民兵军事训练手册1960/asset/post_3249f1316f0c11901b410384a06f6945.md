
（１）以各种顔色的旗子、燈光等，分別代表某一事物或言語；

（２）以手勢、鉄鍬、旗子等作出各種形状。如高举、左右摇动、划圈等，或以信号灯、手电筒发岀长短不同的燈光，分別代表某些事物或言語。

（３）用各種不同声音的变化，組成各種代表不同事物的信号、暗号。如：哨音—長一短，代表开始射击；号角—長声，代表敌人逃跑，等。

在实际运用的时候，可以把各種顔色、声音、动作和形状，結合使用，这样可以变化无穷，使敌人难以捉摸。

使用信号、暗号应当注意：①信号、暗号的显示要簡明、确实，不要混乱，模糊不清；②信号、暗号的显示要熟練，显示時間不可太短，以对方能确实收到为度；③显示时对敌方要力求隐蔵，对我方要容易发现。

## 六、夜間教育

夜間战斗，往往能够以出敌不意突然的袭击，完成战斗任务。但是夜間視力減低，往往感到行动困難，因而也可能遭受到重大損失。因此，在平时必須加強这方面的鍛炼。

### （一）听力、視力的鍛炼

夜間執行任務，耳目都需要使用。通常是以听为主，因为夜深人靜的时候，极細微的音响，在較远的距离都可以听到。但是仅用听力，有时也很难达到目的，还必须用視力补助。一般人在夜間的視力可达50米，如果經常鍛炼，还可以提高。

夜間觀察和听取音响的注意事项：

- 1. 應該使注意力集中，才能迅速确实的发现情況。行动的时侯必须心思平静，并且选择安静的地点。
- 2. 观察目标，应该由下向上，由侧旁向中央。观察某地物的时候，应该先获悉该地物的受光方向，在黑暗处观察。对透视天空和易于投影的地物，须要特别注意。对各种隐蔽地的边缘和阴影与月光的结合部，也应当注意。
- 3. 选择的位置要低，伏在地上，可以增大视力、听力。耳与地面接近，以手挡耳，也能增大听力。如果在硬土地上挖个孔，里面放个瓷罐，四周用土塞紧，将耳贴近罐口，更可以增大听力。

### 视力与各种景况的关系：

- 1. 在黑暗处观察，我易见人，人难见我；还看得远。在明亮处观察，人易见我，并且看不远。
- 2. 对小物体及模糊的东西，容易误近为远；大物体或明显的东西，容易误远为近。
- 3. 在白色的地面（如雪地）上，除白色的东西外，都容易发现；在黑色的地面上，除白色的东西外，都不容易发现。

### 听力与天气、地质和姿势的关系：

- 1. 天气晴朗、空气稀薄的夜间听得远，云雾、黑暗的夜间听不远。有小风的夜间，在下风听得远，在上风听不远。在冰雪和冻地上行动听得清，在没有结冰的薄雪上行动听不清。
- 2. 在软地上行动听不清，硬地、高地上行动听得清。在低处行动听不清，走石头地听清。
- 3. 听树林、禾苗地里的声音，站的较高听的远。听地面上的足音，耳朵贴近地面听的远。在村落内，将耳朵贴在墙角上听的远。
- 4. 人少行动声轻，所以听不清，人多声噪所以听得清。

### （二）静肃行进

夜间行动，最重要的是保持静肃。因为夜深人静，稍有声响，就容易被敌人发觉，这样，必将遭受重大损失或影响任务完成。

夜间行动，出发前应当注意的事项：

- 1. 一切装具、服装都要扎紧，以免发出音响。凡是能碰响的东西，应该用草和破棉花等包起来，或者不放在一起，以免互相撞击发声。
- 2. 如果穿大衣，应当在腰部把大衣扎紧。穿新鞋容易发出响声，可以先用水浸湿；或在鞋底上裹上破布、旧棉花等。
- 3. 出发前应当切实检查（或相互检查）装具，并且做跑远跳高的动作试验一下，确实没有声音以后，再行动。

夜间行进中应当注意的事项：

- 1. 持枪要紧握枪身，并且提得稍高一点，以免使枪碰地或者碰击其他物体。
- 2. 行进的时候，要精神集中，经常注意指挥员的信号，不要低着头走路。行进中，不得说话、吸烟，不得任意停止或者脱离队伍，禁止咳嗽，不得已时，应该以衣袖或者手巾掩口。队伍停止，也應該立即停止，并且注意不要与前边战士相撞，或者拥挤在一起。
- 3. 遇到小的沟、坎、陡坡，应当小声互相传告，以防跌伤；万一跌倒，不要呼喊，并且注意不要丢武器。遇到障碍物，不可惊慌，应当按照通过障碍物的方法通过，并且向后传达。如果发现可疑情况，应当小声报告指挥员，严禁惊慌喊叫，以免影响部队行动。

### 行迸的方法：

- 1. 在浅草地上行走，脚稍提高，足尖先着地。在深草地中行走，脚稍低些，足跟先着地，再用脚尖将草压倒，慢慢行进。在浅水地及泥濘地行走，脚应当提高些，行走稍緩慢。
- 2. 上坡以脚尖先着地，下坡以脚跟先着地。通过急坡的斜坡，前边的战士应当鑿整一下地形，以便后未的通过，或者帮助后面的战士通过。碰上沒有放牢固的石板等，先头的人应当用草或土垫好。
- 3. 通过高的禾苗地、矮树丛，应当先用手将树枝、禾苗分开再前进。
- 4. 通过困难地形后，前边的应当等后边的齐后才再前进。

### 教 学实 施 方 法 ：

- 1. 白天先在各種地形上边講边做，确实了解掌握后，再在夜间选择各种复杂地形练习，并且逐渐增加人数与携带武器。
- 2. 測驗战士跌倒后是否惊叫或丢失武器，可以选择难通过的地形，或者在行进路上秘密安設几个数寸深的陷阱，使战士经过的时候忽然蹚人（但必須注意安 全）。
- 3. 在演习区域内，设假敌，专门听取运动者的声音，如果听到，即吹哨音表示警告。

### （三）夜间联络

部队在夜间行动时，联络极为重要。因为黑夜作战，没有确实的联络，会使各部队间互不联系，各自为战，力量分散；这样战斗中必然遭受严重损失。夜间行动中的联络员，一般是选派身体健壮、机敏灵活、沉着勇敢的战士担任；必要的时候选派干部。

**夜间联络常用的方法：**

- 1. 绳子联络法：通常是在特别黑暗、通过复杂地形的时候使用。绳子前端由先头战士握住，一端引至后方，各战士都握住此绳，相随前进。
- 2. 音响联络法：采用这种方法，通常是在不知道自己部队位置，发现敌人或者可疑征候，招呼比邻战士前进、停止和注意的时候。音响联络的记号，应当事先规定好，如敲枪托、刺刀、竹筒，吹哨，打响噫；学狼、狗、猫、鸡叫等。但是必须注意适合情况，如在没有居民的地方学鸡叫，反而更会引起敌人注意。
- 3. 光号联络法。通常是在距离很远，没有别的联络方法的情况下才使用。主要的有：①烽火。因为联络范围较大，通常由上级命令规定才能使用。②火柴、火鞭、手电筒、信号枪、隐显灯等，主要是火光和手电筒。用手电筒的时候，可以在手电筒头部包上红绿布，这样可以利用不同颜色的光芒代表几种联络信号。③利用白纸、白布、石灰等的反光，如在行道路上撒下白纸条或石灰（但是后边必须留人负责收起），行进中战士背包后边贴白纸或臂上缠白布等。
- 4. 在叉路口设立标兵，向后边部队指示行进方向后，自己跑步回隊，后面部隊亦照樣派出标兵，如此挨次交代，一直到最后。

### 連絡員的動作。

夜間行動的時候，擔任連絡的人數和各人之間所取的距離，應當按照兵力和明暗的程度決定。派出的連絡員在兩名以上，應當指定連絡長負責。

連絡員的動作，應當力求靜肅、迅速，並且必須熟悉以下幾點：

- 1. 進行連絡，一般用快步行進。跑步會妨礙靜肅并且容易跌倒，在接近敵人或者在不齊地行進，更絕對禁止跑步。行進的時候要顧及前、後的連絡，不可以圖自己方便，自由行動。
- 2. 距離敵人很近的時候，報告和連絡都不可以大聲。在前方的連絡員，若是用記號向後方報告，後方受報告者明了報告意義後，要立即用記號回答，前方連絡員亦要等回答“明白了”的記號之後，方能停止報告動作。
- 3. 遇有叉路，要設置記號或者留标兵，指示行進的道路。設置的記號可以用樹枝、稍梢阻塞不能通行的路口，在行進路上撒白粉箭頭或者用石頭、土塊压住白紙條。
- 4. 前面部隊停止，連絡員應當立即停止，以免隊伍擁擠。後面部隊距離拉的過遠或者失去連絡，連絡員應當迅速報告連絡長，加派連絡員去尋找，連絡長并且應當報告前后的部隊指揮員。

### 教學實施方法。

- 1. 先在白天練習，確實了解要領後，再在夜間練習。
- 2. 音响、光號的連絡，事先規定好，使戰士在白天練習時記熟。有能学鳴叫蛙叫的戰士，應當要他个别着重練習。
- 3. 夜間演习，应当选择复朵地形，将战士散开运动，或者假敌友邻与上级机关，派战士前去連絡，以測驗他是否能正确的运用这些連絡方法。
- 4. 以連为单位，扩大各排、班的間隙距离，做夜行軍或者接敌运动，以練习用石灰、白粉条或者用粉笔画箭头和派連絡組等的連絡方法。
- 5. 这些动作，在做其它課目的往返途中，都可以練習。

### （四）夜間对敌照明的处置

夜間照明，在戦場上常用的是探照灯和照明弾。探照灯携带不便，須要專門人才使用，所以多用于阵地战。照明弹使用便利，用炮射、飞机投擲、信号枪射击都可以。飞机投下的照明弹，照明持續時間一般为6分鐘左右；炮兵射出的照明弹，照明持續時間一般为20秒左右；信号枪射出的照明弹，持續時間更短。

遇到敌人探照时候的动作。

敌人用探照灯照射或者敌机投擲照明弹的时候，凡是光芒射到的地方，应当立即停止活动，并且臥倒隐蔽。如果距离敌人很近（四、五十米），或者已被敌人发觉，应当以勇猛的動作冲向敌人。在森林或高草地内的，可以利用蔭影繼續动作。

臥倒位置应当选择在公路两侧，利用树木、草丛、水沟、地貘等地物的蔭影。在河边，可以利用石头蔭影或沙沟隐蔽。遮蔽后不要看光芒，这様容易目眩，不便于以后行动。

敌人对居民地探照的时候，很难将内部情形观察清楚，所以这时可以繼續活动，但是必須注意利用街道两旁的蔭影行进，沒有蔭影的地方，可以利用墙角臥下。

敌人对我照射的时候，需要隐蔽；但是同时也可以充分利用光芒来观察前后连络和比邻部队的情况，以便恢复部队间的联系；观察前方地形地物的状态和敌方情况，并且留意前进的目标，选择前进的道路。

光芒熄灭后应当保持静肃，迅速回到原来位置，继续行动；同时把敌人探照时观察所得的情况报告上级。

### 教学实施方法。

- 1. 演习时以班、排为单位，行进时可以用手电筒等作为探照灯照射；或者在树上，高处挂上马灯或点着预置的照明材料，代表炮兵或飞机投射的照明弹。
- 2. 设置假敌和友邻部队，照明熄灭后，要演习者报告对敌情、地形地物及友邻的观察结果，锻炼战士利用敌人照明进行观察的能力。

## 七 进攻战斗中的战士动作

### (一) 进攻战斗的目的

进攻是我军战斗行动的基本类型。进攻战斗的主要目的，是为了干净、彻底、全部歼灭敌人。

战士在进攻中的基本任务，就是隐蔽的顽强的前进，迅速的接近敌人，以射击和白刃格斗歼灭或俘虏敌人。为此，战士必须熟习各种战斗动作；熟练的使用手中武器；善于利用各种地形地物；并且应当发扬坚决、勇敢、积极主动的战斗精神，对敌人进行猛烈的冲击。

进攻战斗可以在与敌直接接触的时候开始，也可以在接近敌人防御地带后开始。

### (二) 进攻中运动的基本动作

在浴火下运动，要善于利用地形地物。 从这一隐蔽地向另一—隐蔽地运动之前，就应该选择好前面的停止位置、行进路线和运动方法。到达新地藉以后，应当立即就射击位置，必要时进行近迫作业，并且随时随地注意伪装。

#### （一）各种运动方法和动作要领

运动的方法，是根据地形、地物和敌人火力来决定的。在敌人火力射击不到的隐蔽地运动，可以根据隐蔽物的高度采取直身前进、曲身前进或者偈倾前进；在开阔地运动，要善于利用敌人火力减弱的瞬间，或者敌人火力被我火力压制住的时候，迅速逐段跃进。各种运动方法的要领如下：

1、曲身前进 有高低两种姿势（图96）。掩蔽物高于1.4米，可以用高姿曲身前进；低于1.1米，可以用低姿曲身前进。

![](img/b41346f815189f79888890b5225a828a_107_0.png)

（1）低姿曲身。目视敌方，上体挺直，稍向前倾；两臂尽力下垂，使两腿尽力弯曲，步度要大，行进的时候脚跟先着地，右手持枪离地，枪口向前倾。

(2)高姿曲身。要领和低姿曲身同，不同的是两膝微曲。

2. 匍匐前进 是在敌人步枪火力封锁的数小地段上，有较低遮蔽物掩护的时候采用的一种运动方法。匍匐前进的距离不宜过长。

匍匐前进分为低姿匍匐、高姿匍匐和侧身匍匐三种。

(1)低姿匍匐前进。 右手握背带（靠近上背带孔），将枪放在右小臂上，身体贴于地面，屈回右（左）腿；同时左（右）手尽量前伸，用右（左）腿和左（右）臂的力量，使身体前移；在前进的同时屈回左（右）腿，伸出右（左）手，按照上述方法继续前进。在前进中，头不得过于抬起（图97）。

![](img/b41346f815189f79888890b5225a828a_108_0.png)

(2)高姿匍匐前进。 两小臂和两膝支持身体，屈回右（左）腿，同时向前伸出左（右）手，使身体前移，直到右（左）腿伸直为止；在前进的同时屈回左（右）腿，并伸出右（左）手；按照上述方法继续前进。携枪的方法同低姿匍匐一样，也可以将枪横托在两手掌上，或者右手掌上（图98）。

![](img/b41346f815189f79888890b5225a828a_108_1.png)

(3)侧身匍匐前进。 身体左侧卧下，左小臂支起上体，左腿尽量收回，右手提枪（也可以将枪放在左腿上）；右脚收到左小腿处，右脚跟着地；用左小臂的支撑力和右脚的蹬力使身体前移。每次都以右腿伸直为度，左腿姿势不变。按照上述方法继续前进(图99)。

![](img/b41346f815189f79888890b5225a828a_109_0.png)

听到“某人，向某处——匍匐前进”的口令以后，应该先选好前进路线和暂停地点，关闭保险机井且作好准备；然后，采取适当姿势匍匐前进。在匍匐前进中，应该目视前方，保持前进方向。到达暂停地点就停止，必要的时候，可以射击。到达指定地线，即利用地形地物准备射击。

3.跃进 是在敌人火力下，迅速通过开阔地的一种运动方法。跃进的时候应该屈身快跑，右手持枪。每次跃进的时间不应超过3-5秒钟，距离一般为20-40步，根据敌人的火力和地形决定。

听到“某人，向某处——跃进”的口令，应该先选好前进路线和暂停地点，关闭保险机井且作好准备，然后迅速跃起快跑。在跃进中，应该目视前方，保持前进方向。到达暂停地点，应该立即卧倒，可以稍向前或者稍向旁移动，必要的时候，可以射击。到达指定地线，即利用地形地物准备射击。

4.滚进 卧姿时为了迅速向左右移动，隐蔽地迅速通过某一段地，或者在敌侧斜坡运动，采用滚进动作。

要领是：卧倒后两腿夹枪，枪稍向外，两脚的腕部交叉，右手握枪背带下端附近，用力拉紧，左手遮住枪管(准星下边)，两臂尽力贴紧，全身用力，向移动方向滚进(图100)。

![](img/b41346f815189f79888890b5225a828a_109_1.png)

5.前进卧倒 在前进中听到“卧倒”的口令

以后，右脚顺脚尖方向迈出一大步；左手在右脚前支承，向新方向迅速趴倒。 趴倒后，两脚离开约与肩同宽，脚尖向外，左小臂横贴在地上，手握拳，掌心向下，枪轻贴于身体右侧，枪面向左；上背带孔和第一道箍之间放在左小臂上，目视敌方（图101）。

如果要射击，可以立即出枪射击。

![](img/b41346f815189f79888890b5225a828a_110_0.png)

**6. 发进动作** 就是我们从停止到再前进时的起跑步动作。我们一运动，从隐蔽转到暴露，正是敌人射击的机会。因此，运动的时候应当选择敌火减弱、转移或者敌人装填子弹的瞬间，秘密突然发进。在发进前应该选定前进路线、运动方法和停止位置，关好保险机；运动开始的时候，应该象赛跑时起跑的动作一样机敏，以便保护自己，避开敌人火力；为了欺骗敌人，在发进的时候应该秘密向左或向右移动几步，或者以假象来迷惑敌人（如用帽子、草把、土块等），然后再突然地发进；这样可以避开敌人预先的瞄准线。

听到班长口令或者已经选择好了发进时机后，即甩左腿于右腿上，同时右手将枪稍向上提，左小臂向里合，然后，以左手和左脚的支撑力将身体支起，同时右脚向前一大步，用左脚迅速前进。

### （二）射击位置和射击

运动的目的，就是为了迅速的接近敌人以便向敌人射击。因此，应当随时地观察敌人、地形和地物。对射击位置的选择，不但要能隐蔽自己，更主要的是能够发扬火力，并且不应当妨碍友邻的射击。

就射击位置的时候，应当在隐蔽物后面（约2—3步）先跌倒，然后用匍匐前进或左右移动一下再就射击位置，这样才不致使敌人知道你真正的位置。就射击位置后，应该先观察敌情（但是注意头部不要过高），进行伪装，然后再出枪进行射击。如果是利用很小的隐蔽物，应该适合地物一下子跌倒，跌倒后尽量不再移动，以便迅速射击。

射击，有时是在班长的口令下参加全班的“齐射”，或者自己发现有目标自行瞄准射击。例如，听到班长的预告：“第×班，目标——正前方敌人散兵，表尺3，瞄准点腰部”以后，迅速定好表尺，举枪瞄准，听到“放”的口令，就击发，并且立即推上另一发子弹。
