# 3. 用手起出地雷的方法

對触發地雷，起出的步驟如下：

（1）先仔細察看屬於那一种裝置的地雷，如果判斷不清，可以在一個先挖小坑看清后再起；

（2）用手輕輕除去四周伪装土；

（3）慢慢撥开伪装板（如是繩、線連粘，要剪斷或除去）；

（4）如果是踏、拉雷，先剪斷拉繩；

（5）插上保險片，取出引信。

對拉發地雷，起出的步驟如下：

迅速剪斷繩線（張線過緊的，要防止敵人的松發砲雷），再慢慢取出。

4. 不能起出或難起出的地雷，用炮兵射击或用手榴彈、炸藥包誘發之。

5. 如果發現地雷后当時不能排除，就应当用石灰、小旗等标出，以免后續部队踏上。
