# （三）小组的战斗队形

小组在进攻战斗中，通常分为一路队形和散开队形两种。战士的间隔距离一般为6—8步（4.5—6米）。*组长通常在组的先头、中央或一翼，以便于指挥連絡。

组长使本组成一路队形前进的时候，口令是：“第*组成一路跟我来！”组长在先头对正目标前进，各战士按次序取适当距离，随组长前进（图106）。

组长使本组由一路队形成散开队形前进的时候，口令是：“目标——（方向）某处——散开！”这时，以组长为基准，对准目标前进。第二、四名向组长左方，第三名向组长右方，迅速散开前进（图107）。
