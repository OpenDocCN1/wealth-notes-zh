# 战斗勤务

# 一 侦察

# (一) 侦察勤务原则

1. 侦察是获得敌人情报的一种手段。确切的情报是指挥官正确下定决心的重要根据。因此，侦察员是部队行动的耳目。

侦察员的任务，是用一切手段，捕捉俘虏，缴获敌人的文件，力求发现敌人行动的一切征兆，如：敌人的兵力、兵种、技术兵器等。最有情报价值的是捕获敌人的军官和传达连络人员。

侦察的方式很多，有化妆侦察（便衣侦察）和武装侦察。除此以外，每个战士都有收集敌人情报的责任，都应该将自己直接看到或者间接听到的情报随时报告给指挥员。

2. 这里着重介绍的是武装侦察，就是战士被派出担任一定的直接搜索任务。武装侦察通常是由两至三个侦察员（或战士）组成侦察小组，一人任组长。侦察小组有被专门派出搜索某一地区的，或者是派出在部队前方、侧方和后方担任侦察、警戒任务的。
