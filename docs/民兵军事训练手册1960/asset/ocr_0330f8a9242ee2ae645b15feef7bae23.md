+   ⑧空軍；坦克和毒气警报的信号。

观察的时候应该注意一切征候，如路上的尘土飞扬，村寨中狗的狂叫，人畜奔跑，武器的闪光，射击的声音，飞机的出现，夜间的灯火，可疑的便衣人员等。从这些征候中判断敌人的行动，兵力的多少，和距离的远近。 要善于从武器、服装和运动序列的不同来辨别情况。

+   4．对于一切重要的发现，无论是敌人的，友邻的，或者是自己各分队的，观察员都应尽快速的报告指挥员。

# （二）观察勤务动作

观察员位置的选择：最好的观察所（位置），要能够观察到所指定的地带，便于报告，而且不容易被敌人发觉。

白天应该在高处，如树上、山顶、楼房等。一但是要注意不要利用明显的物体和遮蔽天空的地方，因为利用一个孤立的大土堆不如利用有许多草丛和小树丛的地方更隐蔽。站在很高的没有隐蔽的山顶上，很容易被远处的敌人发现。

对于背景的明暗也要注意。如穿黄色或灰色的衣服站在白色物体前面，比站在黑色物体前面，目标要明显的多。

夜间的位置、姿势，都应该低些，这样可以听得多、看得远，特别是对于遮蔽在天空的目标，更容易发现。伏在地面上，容易听到远处的声音，伏在石地、草地、禾苗地附近，可以听得更远一些；但是不应该靠近有声音的河边、风车、水磨以及有杂乱声音的地方。 在刮大风的夜里，选择的位置要避开大树。
