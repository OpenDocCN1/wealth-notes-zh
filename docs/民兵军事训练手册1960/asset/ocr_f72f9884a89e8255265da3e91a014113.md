| 故障现象 | 故障发生的原因 | 排除方法 |
|---|---|---|
| 不发火 | 撞针尖端损坏 | 撞针尖端可自行修正，短和损坏可送厂修理；撞针簧无力，垫一段铜簧；击锤内部不带火引或底火被油污和装错。 |
| 弹壳退不出 | 弹膛弹壳没磨开，抓子钩损坏，弹壳膨胀，撞针后没有立即开枪机 | 注意擦拭，射击后立即开枪机。如弹壳炸裂可用铜或铜条拔出或撑出，抓子钩损坏送厂修理。 |
| 击发后枪机后面出烟 | 撞针尖太长磨掉了子弹底火，或底火装置过于自由 | 关紧枪机，修理撞针尖（磨去一点）。 |
| 击发后枪机退不出 | 涂油少，枪机和机槽不干净 | 擦拭涂油，射击后迅速拉开枪机。 |
| 枪身炸裂 | 枪膛未擦干净，有东西塞住；未拔枪口帽；第一及第二发，误用长枪子弹；在极端的地方射击 | 射击前注意检查枪膛是否擦净，子弹有无裂纹，拭去枪口帽后再射击；射击时如无未出枪口，应用通条推出枪膛内的弹丸或用较轻的空包射出；在极端的地方射击，应将枪尖在土尖内保持温暖。 |
| 不能保险 | 保险机内生镸，保险室失去作用，保险室及保险转键棱角磨光 | 擦拭涂油，送厂修理。 |
| 滑机走火 | 扳机头和卡铁棱角磨光，扳机卡住自行滑动，复簧失去作用，扳机头压不出来 | 送厂修理。 |
| 表尺准星发亮影响瞄准 | 由于保管不好致使 | 用火柴熏黑。 |
