# （一）原子武器

什麼是原子武器呢？要了解原子武器，必須先弄清楚什麼是原子能，什麼是原子。

我們周圍的一切東西，都是由極微小的原子組成的。 原子小得很，用倍數最大的顯微鏡也看不見它。 原子本身則是由更小的原子核和電子組成的。 原子核由質子和中子構成，位於原子的中心，重而精尖，電子則按照一定的規律，不停的繞着原子核回轉(圖1)。原子共有 100 多種，不同種類和不同數量的原子結合起來，就是各種不同的東西。
