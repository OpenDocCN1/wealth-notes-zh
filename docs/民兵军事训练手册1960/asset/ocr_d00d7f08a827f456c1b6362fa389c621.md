# ## 附表三 防御中的战士战术作业进程参考表

| 研究事项 | 教 者 的 指 导 | 学 者 的 动 作 |
| --- | --- | --- |
| 构筑工事 | 一、给战士示范，选择射击位置，挖掘散兵坑。<br>二、说明情况，指示战士挖掘散兵坑的位置、深度和种类。<br>三、检查战士的射击位置，然后命令战士开始构筑工事。<br>四、检查战士构筑工事的动作，待战士挖好工事后，找出好、坏典型进行讲解。 | 一、注意示范动作。<br>二、在指定的位置上选择挖掘散兵坑。<br>三、挖掘散兵坑。 |
| 观察员的动作 | 一、赋予观察任务：<br>1、指定观察位置和方向；<br>2、敌人可能出现的方向；<br>3、观察地物；<br>4、报告的方法。<br>二、检查战士对任务的了解（可以指定战士复诵）。<br>三、以红白旗简单的信号显示第一号目标（作信号时不露战士知道），或者再以另外信号，显示另外的目标，可以依照练习的情况自己规定。 | 一、接受任务，进入观察位置，熟悉观察地物的地形地物。<br>二、报告观察的情况。 |
| 向进攻中的敌人射击 | 以红白旗左右摆动的信号，显示正前方400米处，出现第二号及第三号目标（入象靶），并且以敲钟或者其他响音，表示敌人的进攻开始。 | 定标尺，向敌人射击。 |
| 在敌人炮火下的动作 | 一、以敲炮或者其他人响音，表示敌炮火向我第一号阵地射击。<br>二、以敲炮或者其他人响音在离炮后200米处置第四号目标（入象靶），并且以敲炮或者其他人响音在离炮后400米处置第四号目标（入象靶），并且以敲炮或者其他人响音在离炮后200米处处置第四、第五、第六号目标（入象靶）。 | 一、进入掩蔽部，或者俯卧在弹底隐蔽。<br>二、就射击位置，猛烈射击，击退敌人的步兵冲击。 |
| 击退敌人坦克的动作 | 以红白旗左右摆动的信号，显示正前方40米处出现第七号目标（坦克靶或者以其他东西代替坦克）。 | 用枪托手臂击坦克，击退敌人坦克的冲击。 |
| 说明 | 一、这个表内所写的演习内容，是不全的，如战术动作等就没写。这个表只能作为参考，在练习的时候可以根据具体情况，适当的增减演习的内容，受这个表内容的限制。<br>二、地形上的方向物和目标的距离，也不是固定的，应该根据当时具体情况适当的调整。 | |
