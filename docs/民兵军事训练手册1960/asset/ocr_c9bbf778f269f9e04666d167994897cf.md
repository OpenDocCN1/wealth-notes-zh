# (三) 使用、保管方法

使用的时候，拧开保险盖以食指（或小指）取出拉火环，套入小指根，握弹柄对正目标投出。

![](bbox=[0.62, 0.14, 0.8, 0.38])

保管方法：放在空气流通的地方，免得受潮，特别是本柄容易吸水，防止太阳曝晒或火烤；携带时不要和武器碰撞；没有用以前严禁打开保险盖，并且注意不要使保险盖脱落；不要用手榴弹敲打物体。

# (四) 手榴弹投掷方法

练习投弹的方法，可以多种多样，不要拘泥一种样式。左、右手投弹都可以。练习的时候，可以先分成几个动作练习，再综合练习，最后结合实战情况练习，达到各种姿势都能投的远，投得准。

1. 原地立姿投掷 口令：“准备手榴弹”“目标××投”。

听到投弹预备的口令后，将枪交于左手，枪托着地，枪刺靠左肩，左臂从枪前伸过左手握弹袋底，右手取出手榴弹交左手。
