# 遇到敌机空降特务時候的处置：

1．发现敌机空降特务，应該迅速組織力量前往空降地区， 搜側；同时迅速通知友邻；报告上級及附近驻軍派人圍剿。

2.当敌人空降特务着跗后，应该按照 划分的 警戒区域戒 严，动员群众配合民兵四出巡邏，严密封鎖，防止特务逃跑、分 散隐藏。 一发现空降特务，就要坚决、勇敢、迅速地消灭之。 在战斗中应该注意利用地形地物，不要混乱和拥挤。 如果因 为我兵力限制不能立即消灭空降特务，應該将敌人包围，待增 援部队到达后，共同消灭。 在警戒的時候要严格注意被管制 分子、潜伏的反革命分子等的活动。

3.围剿特务的民兵，如果是两个不同建制单位，應該組織 統一指揮部，加强通信連絡，密切协同动作；配合作战，切忌各 自为战，互不联系，特別不应該爭功爭战 品，以妨碍作战任 务的完成。

4.到达空降特务着跗地点，如果特务已經逃跑，應該細心 观察敌人的各种痕迹，判明敌人可能逃跑的方向，組織力量跟 踪追击，务必作到全部彻底干净消灭空降特务。

5.在搜剿的時候應該提高警惕，注意敌人 化装我方人宾 来欺騙我們。必須認真盘查行人，严格清查戶口；将来历不明 的分子，送交上級审查处理。

6.夜間搜剿困难，可以严格戒严，晨层包围，待天 明后有 指揮有計劃地进行搜剿。 但是在有月光的時候，就不一定要 等天明后才進行圍剿。
