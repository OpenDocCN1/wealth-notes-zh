# 视力与各种景况的关系：

+   1. 在黑暗处观察，我易见人，人难见我；还看得远。在明亮处观察，人易见我，并且看不远。

+   2. 对小物体及模糊的东西，容易误近为远；大物体或明显的东西，容易误远为近。

+   3. 在白色的地面（如雪地）上，除白色的东西外，都容易发现；在黑色的地面上，除白色的东西外，都不容易发现。

# 听力与天气、地质和姿势的关系：

+   1. 天气晴朗、空气稀薄的夜间听得远，云雾、黑暗的夜间听不远。有小风的夜间，在下风听得远，在上风听不远。在冰雪和冻地上行动听得清，在没有结冰的薄雪上行动听不清。

+   2. 在软地上行动听不清，硬地、高地上行动听得清。在低处行动听不清，走石头地听清。

+   3. 听树林、禾苗地里的声音，站的较高听的远。听地面上的足音，耳朵贴近地面听的远。在村落内，将耳朵贴在墙角上听的远。

+   4. 人少行动声轻，所以听不清，人多声噪所以听得清。
