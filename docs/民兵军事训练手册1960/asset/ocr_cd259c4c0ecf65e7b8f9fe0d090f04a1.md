# （三）冲击准备和冲击

+   1. 冲击准备：听到连长“冲击准备”的口令以后，应当停止射击，并且作好如下准备：

+   (1) 装满子弹，以便在冲击中保持对敌人不间断的射击；

+   (2) 准备好手榴弹，将弹盖拔松，便于及时迅速的向敌人投出；

+   (3) 整理好服装和装具。服装、鞋子应当穿着好，弹药、土工工具（小圆锹等）、化学防护器材等应当携带牢固，不致碰撞或者丢失脱落。携带不好，在行动中也会增加疲劳；

+   (4) 做好跳出塹壕的准备，左脚踮踄踏是孔，左臂及腰部挌紧臀座，右手持枪将枪斜置于胸前臀座上，这样便于四肢同时用力跳出塹壕。

在冲击准备过程中，应当不间断的监视敌人，并且看清自己前进的道路。

+   2. 冲击 冲击的时机是：

+   (1) 上级发出冲击口令或者信号的时候；

+   (2) 我炮兵和空军火力转向敌人纵深射击的时候；

+   (3) 我坦克越过冲击出发地线的时候；

+   (4) 发现敌人混乱或者企图轉移位置、逃跑的时候。
