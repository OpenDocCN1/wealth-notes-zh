# 防空、防原子、防化學常識

未來戰爭的様式，将是按电鈕式的，这就是說，敵人在发动戰爭的時候，不是先将部队运出来作战，而是首先在他早已設置好的各种軍事基地上，按电鈕，发射导弹，射击 他預先瞄准好的目标。因此，戰爭的突然性是很大的。 帝国主义历来慣于背信弃义，使用突然袭击的手法。 在导弹、原子武器、氢武器和化学武器时代，这种突然性就更大。 美帝帝国主义者，有所謂“戰爭最初六十天制勝”論，当然这是一种妄想。 但他们采取这种手段，将会增大战争的突然性和破坏性，尤其是战争的初期，对政治經濟軍事文化中心、工矿重点和交通枢組地区，更是它主要的破坏目标。 在袭击的同时，还可能对緩深地区实行空降，那时战争將没有前后方的分別。 这样看來，我們民兵在和平建设時期，就应当提高警惕，防止帝国主义的突然袭击。

大家都知道，打仗要有武器，要有人，武器是人來制造和人來掌握的了。 因此人是戰爭中的决定因素，但也不能藐視武器在戰爭中的重大作用，尤其是原子、化学武器。 因为它是一种大規模的杀伤和破坏性武器。 它对于部队的战斗行动、后方 补给、交通运输和人民的生命财产等等，都会有很大的影响。 这就需要我們在和建建設時期，經常做好對現代武器的防護准备工作，进行深入的 政治动员，构筑必要的 防护工事，
