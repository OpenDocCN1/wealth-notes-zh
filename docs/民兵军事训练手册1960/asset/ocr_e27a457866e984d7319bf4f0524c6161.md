# 为什么会打不准？

打不准的原因很多，下面我们就来分别谈谈：

（一）操作技术上有那些毛病就会打不准：

+   1. 射击姿势不好就会打不准。比如，卧姿射击的时候，身体所对的方向和目标斜的太大或者太小；两肘过于向里合和向外张，使据枪、贴腮、瞄准的时候很别扭，当然打不准确，另外，这样的卧姿不舒服，不能持久，也会打不准。

![](bbox=[0.14, 0.55, 0.57, 0.85])

+   2. 据枪的动作不正确，就会打不准。如枪面偏左，射弹就偏左下，枪面偏右，射弹就偏右下（图48）。
