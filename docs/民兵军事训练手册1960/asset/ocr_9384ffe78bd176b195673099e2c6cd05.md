+   3.夜間演习，应当选择复朵地形，将战士散开运动，或者假敌友邻与上级机关，派战士前去連絡，以測驗他是否能正确的运用这些連絡方法。

+   4.以連为单位，扩大各排、班的間隙距离，做夜行軍或者接敌运动，以練习用石灰、白粉条或者用粉笔画箭头和派連絡組等的連絡方法。

+   5.这些动作，在做其它課目的往返途中，都可以練習。

# （四）夜間对敌照明的处置

夜間照明，在戦場上常用的是探照灯和照明弾。探照灯携带不便，須要專門人才使用，所以多用于阵地战。照明弹使用便利，用炮射、飞机投擲、信号枪射击都可以。飞机投下的照明弹，照明持續時間一般为6分鐘左右；炮兵射出的照明弹，照明持續時間一般为20秒左右；信号枪射出的照明弹，持續時間更短。

遇到敌人探照时候的动作。

敌人用探照灯照射或者敌机投擲照明弹的时候，凡是光芒射到的地方，应当立即停止活动，并且臥倒隐蔽。如果距离敌人很近（四、五十米），或者已被敌人发觉，应当以勇猛的動作冲向敌人。在森林或高草地内的，可以利用蔭影繼續动作。

臥倒位置应当选择在公路两侧，利用树木、草丛、水沟、地貘等地物的蔭影。在河边，可以利用石头蔭影或沙沟隐蔽。遮蔽后不要看光芒，这様容易目眩，不便于以后行动。

敌人对居民地探照的时候，很难将内部情形观察清楚，所以这时可以繼續活动，但是必須注意利用街道两旁的蔭影行进，沒有蔭影的地方，可以利用墙角臥下。
