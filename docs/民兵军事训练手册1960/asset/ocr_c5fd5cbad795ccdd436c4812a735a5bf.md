# 一 步(騎)枪的构造和战斗性能

射击是軍事知識的基本内容之一。学习射击,具有精确掌握手中武器的本領,就能在战斗中以准确的射击杀伤和歼灭敵人,取得战斗的胜利。

现在各地民兵使用的步(騎)枪,有几十种,很复杂,这里仅介紹几种数量較多的,“七·六二”、“六五”、“七九”三种步(騎)枪于后。 因为步(騎)枪的构造原理,使用方法以及战斗性能等,天体上是相同的。 能够了解和掌握了这几种主要的步(騎)枪,其它也就能掌握和使用。

(一)七·六二步(騎)枪

现在使用的七·六二步(騎)枪有两种,一种是 1891/30 年苏式步枪,另一种是1944年苏式騎枪。 两者的区别只是重量不圈(步枪4.5公斤,騎枪 3.9 公斤),枪管长度不同(步枪带枪刺 180 厘米,騎枪帶枪刺 133 厘米),枪刺不同(騎枪是折迭式的),其它战斗性能和构造原理等是相同的。

苏联造的1944年式騎枪,我国于1953年制造成功,命名为1953年式七·六二毫米騎枪,简称53式七·六二騎枪(图劃),这种枪构造簡單坚固,不容易发生故障,使勿力太,命中精度特別良好。是过去战争中世界上最优良的步兵武器。从下列
