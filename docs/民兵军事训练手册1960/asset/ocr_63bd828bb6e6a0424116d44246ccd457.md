# 行迸的方法：

+   1. 在浅草地上行走，脚稍提高，足尖先着地。在深草地中行走，脚稍低些，足跟先着地，再用脚尖将草压倒，慢慢行进。在浅水地及泥濘地行走，脚应当提高些，行走稍緩慢。

+   2. 上坡以脚尖先着地，下坡以脚跟先着地。 通过急坡的斜坡，前边的战士应当鑿整一下地形，以便后未的通过，或者帮助后面的战士通过。碰上沒有放牢固的石板等，先头的人应当用草或土垫好。

+   3. 通过高的禾苗地、矮树丛，应当先用手将树枝、禾苗分开再前进。

+   4. 通过困难地形后，前边的应当等后边的齐后才再前进。
