口卡佳弹簧的搖摆螺栓，然后放松托弹机，盖上弹仓盖。

捧上通条———将通条插入通条槽內，擰紧。

打开枪刺———将枪托放在地上，左手握枪口部分，右手将枪刺管向下拉，然后从右向 上 轉开枪刺到尽头，使駐彈孔套在枪口上。

裝上枪机———左手握枪頸，食指扣扳机，右手装上井关上枪机。

# 4.故障的預防及排除的方法。

| 故障現象 | 故障发生的原因 | 排除方法 |
| :--- | :--- | :--- |
| 将子弹装入弹仓时弹仓盖自行脫开 | 彈夹盖卡鈀齿損坏或螺絲松勭 | 不用弹夾而逐个将子彈装入机槽，射击完后經修械所修理 |
| 子彈不能入膛，发生卡弹 | 装彈时沒有将子彈压到鎗完與鋸背之下，鎗完鈌損坏 | 把子彈扶正，送人彈膛，如重復发生这一故障，可送交装械—射击后經修械所修理 |
| 子彈在枪膛中卡紧，关梭机时需要用力 | 子彈变形或膛火凸出，弹膛發鉍 | 退出不良的子彈，用通条擰試枪膛 |
| 子彈不发火 | 哑水受澗，撞針尖突出的程度不夠。撞針折斷或磨癈，撞針簧力弱，机件彈孔內有積鐵 | 換子彈后再射击，如重復发生这一故障，检查撞針尖突出的程度，如机件扎孔內有疤铁，試式井除淨油。撞針、撞針簧損坏时，經修械所修理 |
| 不能拉出彈膛內的彈壳 | 攝子鈂損坏或污話太多 | 如有污垢，分解清試；如損坏，送修械所修理；脫困弾壳用通条痛出 |
| 退彈时彈壳(子彈)不能投出 | 發完彈鎗被彎曲，或發完鎗鉤磨癈有汚垢 | 用手取出彈壳(子彈) 擦試汚垢，如發完鎗損坏，经修鉏所修理 |
| 拉枪机向后时枪机潑脫 | 拨机鎗螺絲过紧，拨机阻簧或通架凹槽面整磨損 | 把机机装螺絲上紧，如枪机阻鎗鈂鎗磨損經修械所修理 |
