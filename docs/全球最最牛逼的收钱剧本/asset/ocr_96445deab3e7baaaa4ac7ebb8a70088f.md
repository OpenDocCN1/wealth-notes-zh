# 一个结果……

他被好莱坞美国电影协会等，30 多家媒体巨头联合起诉侵犯版权，索赔 2.5 亿美金！他成了真正的“天下第一负翁”。为了不蹲班房，只好卖掉公司宣布破产，这也帮他免去了巨额债务。又左借右借才凑了 100 万美元给那些大佬当和解费。

陷入低谷的他，成了坑爹一族，吃喝住行都得伸手问父母要钱。可消沉过后的他，野心又燃烧了，他决定要把赔掉的钱，全部赚回来！

![](bbox=[0.13, 0.525, 0.85, 0.662])

2001 年，他又开始第二次创业，创办了一家科技公司，主要业务是改进企业文件，用网络的传播方式，提高文件传输速度，同时，可以帮企业节省服务器开支。可是这家公司，一直都没盈利过，让他穷到吐血，他去参展时，没钱住酒店，只能睡租来的汽车。第二天，再跑到赌场的卫生间去洗澡。
