# 改变世界商学院 世界企业家的摇篮 《全球赚牛日的收钱剧本》一诺老师专用

他就是严彬，也许你可能不知道严彬是谁，但你一定知道他公司旗下的一款产品，“困了累了喝红牛！”。

![](bbox=[0.13, 0.281, 0.852, 0.415])

今天，一诺老师带你一起学习的，就是他的艰苦奋斗史和传奇的创业历程。

1954 年，严彬出生于山东一个贫穷的家庭，16 岁初中毕业，作为那个年代必须上山下乡的知识青年，严彬来到河南省插队。

在那个与山西交界的极贫困地区，他干了整整一年，却只得了 92 元钱。他每天的口粮只有红薯，几乎连白面都没有见过。

因为穷怕了，于是严彬选择了去泰国寻找新的生路。

刚到泰国，人生地不熟，语言又不通，严彬就在曼谷的街头流浪，一个星期就把从家里带的干粮吃没了。

第八天，他饿迷糊了，恍惚中被人拉到一个隐秘的诊所去卖血。报酬是 100 泰铢，外加一盘炒猪肝。

正是靠着卖血的那 100 泰铢，严彬在曼谷安顿了下来。
