# 改变世界商学院 世界企业家的摇篮 《全球赚牛日的收钱剧本》一塔老师专用

地理：韶山人，而且是毛爷爷对面邻居；

人和：丈夫也姓毛！所以叫毛家饭店，有毛爷爷最爱吃的韶山菜和红烧肉！

另外你可能会问，汤妈妈叫汤妈妈吗？当然不是，汤妈妈一生豪爽乐善好施，她老人家做过的公益事业不计其数，例如：

汶川地震，汤妈妈把家里所有的现金全部捐出去，镇里面捐款，邀请她捐款！县里面邀请她捐款！市里面邀请她捐款！到了省里面，她就把全部的钱一分不剩的捐完了。
