# 第三招：超市计划。

产能上来之后，飞科通过自己的拳头产品，打开了尚处于空白的，中端市场，但是，如果飞科扩张不够快，机会稍纵即逝。

几经考察后，李丐腾提出了“超市计划”。李丐腾研究发现，一般人都会在超市和商场中购买日常用品，飞利浦等国外大牌已经占领了商场的专柜，因此飞科瞄准了超市渠道——那里还没有厂家进入，是空白市场，一片蓝海。

虽然飞科的高管们心里谁都没底，但老板一声令下还是听话着做，李丐腾明白重赏之下必有勇夫，于是，把返点提高了 30 个点，这时候超市卖疯了。
