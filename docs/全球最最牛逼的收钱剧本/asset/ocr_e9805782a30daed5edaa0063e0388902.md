# 第三个时代：品牌时代

随着市面上同类产品越来越多，一些厂家为了从同类产品中脱颖而出，开启了品牌时代！

随着生活水平的提高，消费者也开始有了品牌意识！

因此，人们看重品牌的原因：有的看重质量保障！

有的看重性价比！

有的看重服务！

有的看重品牌彰显的身份！

因此，最先抓住品牌机遇的厂商和最先代理品牌的经销商获得了丰厚的回报！

# 第四个时代：电商时代

所谓贸易，就是赚信息的差价，就是知道的赚不知道的钱！

这个时候，阿里巴巴出现了，让中国的厂家信息透明化，一下子几乎将所有行业的利润暴漏在阳光下。

因此，颠覆了很多传统的批发渠道！

阿里巴巴左手整合了厂家，右手整合了经销商！

其实，传统零售业的噩梦才刚刚开始！
