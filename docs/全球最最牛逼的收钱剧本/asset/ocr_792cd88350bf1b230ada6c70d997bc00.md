# 第十一：不做广告，做口碑

广告是自己说自己好，时下用户仅凭一个广告就买单的时代已经一去不复返，消费者更愿意相信自己认可群体的口碑。

就像一诺老师一样，所有的教学都来自于实战案例，所有的书籍、课程都来自于 100% 的实战案例，所以企业家听着很有感觉，就一传十十传百，一诺老师从来不做广告，而是秉承一诺出品必属精品的鉴定信念。坚持打造最实战的商业案例！最落地的实操经验！

![](bbox=[0.13, 0.53, 0.85, 0.66])

未来，口碑是品牌传播的最有效途径，如何打造口碑，必须把握好以下三点：

+   1. 引导口碑，即，你希望你的品牌传播什么样的口碑，你就引导产生如此的口碑。

+   2. 宣传口碑的平台和群体很关键，每个人都毫无防备的愿意相信权威、专家、著名商家、成功人士等。
