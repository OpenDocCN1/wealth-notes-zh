# 第08课：傻子太多聪明人明显不够用【石头模式】

大家好！我是一诺老师。当今企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争！一诺老师教您《商业模式·顶层设计》。

在很久很久以前，有一个叫【吃瓜村】。

吃瓜村附近山上都是奇形怪状的石头，吃瓜村民们每天都在辛勤劳动着。突然有一天，e来了位商人，问吃瓜村民说：你们山上的石头卖不卖？

商人说：石头会给人带来好运，时来运转。

商人说：只要吃瓜村民把长得像猫呀，狗呀，龙呀的，像动物的石头弄来，每一个给100块钱。

吃瓜村民不知是真是假，试着搬了1块石头，商人果然给了100元。于是全村的人都去找石头，因为吃瓜村民认为，这比种地简单多了。

所以，商人为了交易方便，还专门开了一个交易市场。
