# 改变世界商学院 世界企业家的摇篮 《全球晩牛日的收钱剧本》一诺老师专用

常热情地接待了老李，带他到处参观，然后讲解设备如何如何好，中午还热情款待了老李，最后那个德国厂长问：李总，请问您对我们的设备满意吗？

老李说：“非常满意！”

德国厂长说：“那您看，我们的设备只要 3000 万，您什么时候开始订购我们的设备呢？”

老李说：“我没钱！”

德国厂长说：“没钱，那你还来看设备？你也太开玩笑了吧？”

老李不慌不忙地说：“你别着急，我没有钱，但是我的合作伙伴有！”

德国厂长说：“你的合作伙伴是谁？
老李说：“是全世界第二大果汁经销商，台北果汁！”
出于保护隐私，这里就叫台北果汁！
德国厂长一听：“什么？你的合作伙伴是台北果汁？”
老李说：“是的！所以，我们来谈一下合作你有没有兴趣？”
德国厂长一听，当然有兴趣了！
