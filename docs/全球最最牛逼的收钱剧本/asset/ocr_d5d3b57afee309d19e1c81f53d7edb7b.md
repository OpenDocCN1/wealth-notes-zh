# 改变世界商学院 世界企业家的摇篮 《全球最牛日的收钱剧本》一诺老师专用

犹太人居然把死驴卖到2000元，因此犹太人赚了1888元。

什么？一头活驴才1000元，一头死驴居然赚了1888元？

是的，这就是犹太人的聪明之处，那他是怎么做到的呢？

各位，没有不可能，只有想不到！

![](bbox=[0.13, 0.36, 0.86, 0.5])

犹太人印了1000张，每张面额2元的彩票，供人抽奖。

他说：2元面额的彩票中奖了就可以得到一头驴。

由于2元钱不多大家都想碰碰运气，心想万一中奖了呢？

所以，1000张彩票很快销售一空，获得2000元。

但是，中奖者发现驴是死的，所以不要死驴，

于是，犹太人就按照中奖者购买彩票的本金，退还了2元。

再减去购买死驴的本金100元，彩票纸张10元，一共成本112元。

那么2000元减去112元，就等于剩下1888元。

这样犹太人净赚1888元。
