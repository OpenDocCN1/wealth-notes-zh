# 记住这句话，顿悟商业真谛！

![](bbox=[0.13, 0.235, 0.86, 0.37])

有一天晚上，有个人提着饮料还有水果，就找到春天家。

说拜春天为师。

春天说：“大哥，别开玩笑了，你比我大呀！”

他说：“有志不在年长！”

春天说：“那也不行，我不会教的，我又不缺钱，一个月都赚好几万。一年随便宜赚几十万。”

后来他说这样，我出一万块跟你学。

春天一听，顿时就很是生气：“你一边凉快去吧，开什么国际玩笑，你就是给我二三十万，一年也就赚回来了。没想到，你出一万块，就想学这个，我很生气，不要用钱来侮辱我。”

讲到这里，细节就不多讲了，故事的结局是他求春天收他3万块，而且春天很生气地，很勉强地，才收下的。

不好意思，春天是被逼的！
