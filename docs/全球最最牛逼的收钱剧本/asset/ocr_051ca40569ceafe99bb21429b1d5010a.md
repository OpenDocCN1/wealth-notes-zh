# 第18课：珠峰哥一个动作身价上亿【用师模式】

大家好！我是一诺老师。当今企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争！一诺老师教您《商业模式·顶层设计》。

上个世纪，成功学开始风靡中国，很多都去学习成功学、励志课程、教练技术等课程。

有一位叫珠峰哥的人也去上了成功学，可珠峰哥上了课程之后，跟别人的心态不一样！多数人上课之后，总想着称王称霸，想着自己成功，想着超越老师！

而珠峰哥不这么想，珠峰哥认为：上完课程之后，有些人成功了，但是更多人是失败的！因为，毕竟成功者占少数，永远是 20%的人掌握 80%的财富，而 80%的人，只能有 20%的财富。

珠峰哥琢磨着，如果自己去创业，成功率也许只有 20%，八成的可能性会失败。他一边听成功学，一边想，这个讲课的老师，如果能够让他为我工作就好了！
