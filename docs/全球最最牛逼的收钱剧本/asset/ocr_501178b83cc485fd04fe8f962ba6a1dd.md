# 改变世界商学院·世界企业家的摇篮《全球艘牛日的收钱剧本》一诺老师专用

心理活动，猪看到稀拉拉的饲料，吃得很不开心，很郁闷！即使吃饱了，心情也不好，心情不好就睡不着，睡不着就不长肉。

于是乎，阿狗心理想，要让猪吃得开心，睡得开心，怎么

做呢？

![](bbox=[0.123, 0.362, 0.842, 0.495])

阿狗喂猪只喂干饲料，在干饲料里加盐，就是食用盐。

由于加了盐，这猪吃了干饲料之后，就会口渴，于是拼命地喝水，

喝饱水之后，撑得走不动。

走不动就躺下来呼呼大睡，睡醒之后，觉得怎么肚子里都是水，空空的，于是乎，猪又去吃干饲料，吃完之后，又觉得太咸，就继续喝水……

于是乎猪就进入了这个吃喝睡的过程！

重点来了，这猪为什么会大口大口地喝水？

因为猪的饲料里面有盐，所以会喝水，那是因为找到了借力的点。这个点，就是干饲料和盐！
