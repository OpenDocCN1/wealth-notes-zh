# 第二招：生产外包。

由于销量猛增，原先的代工厂跟不上了，李马腾找到两家大厂想做代工。

但对方却说：“就是你白送我们100万，我们也不可能帮你贴牌，如果让你占领整个义乌市场，就等于占领全国市场，到时你再把我们一脚踹开，工厂就废了。”

为了消除对方的顾虑，李马腾把核心的生产模具以及 60% 的订单当作“人质”交给对方生产，并用 10% 的利润当作“恩惠”送给对方。

有人觉得李马腾这么做不是傻嘛，放着钱不挣？

![](bbox=[0.13, 0.61, 0.86, 0.75])

李马腾明白，从始至终企业都要走“轻资产”路线，将大部分的生产外包后，就能集中精力攻研发和营销。

企业要把公司做小，把市场做大！

我来问大家，富士康多少员工？120万人！
