# 改变世界商学院 世界企业家的摇篮 《全球最牛日的收钱剧本》一诺老师专用

李丐腾会干活能吃苦，所以李丐腾很快就成了公司的模范教科书，自然受到老板赏识，不仅给他升迁成主管，还经常带他去参加活动。通过经常跟老板去参加活动，认识了很多同行业的大佬级人物，建立了属于自己的人际圈。

在行业里摸爬滚打了一段时间，他渐渐发现剃须刀行业都在拼命的打价格战，要想胜出就必须做品牌。他的老板小富即安，觉得这就可以啦。

但是，李丐腾不这样想，李丐腾想的是赚大钱，把市场做大，做全国市场，他认为不能将自己的未来托付给格局如此溯小的人。于是李丐腾就决定，你不干我干，下定决心自己当老板。

机会总是留给有准备的人。
