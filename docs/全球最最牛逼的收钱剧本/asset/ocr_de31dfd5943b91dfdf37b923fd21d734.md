# 改变世界商学院 世界企业家的摇篮《全球赚牛日的收钱剧本》一诺老师专用

韶山红色管理学院、党性教育基地，刘院长亲自迎接，并在韶山国宾馆正门口打出标语：

热烈欢迎改变世界商学院院长们莅临韶山。

第二天一早，改变世界全体院长及学员们列队前往毛爷爷铜像广场，由武警托住花篮带头，我们紧跟其后，整齐地、怀着无比庄严和崇敬的心情向毛爷爷敬献花篮！

![](bbox=[0.132, 0.448, 0.855, 0.582])

研修期间，学员们通过学习《毛泽东思想商战》，进一步研究华为集团、万科集团、立白集团、万和集团、温氏集团等多家上市集团公司的创业史及商战策略。

学习期间，我们瞻仰了毛家祠堂、毛爷爷纪念馆、毛爷爷易物馆、毛爷爷故居、滴水洞、虎歇坪等，并祭拜了毛爷爷的祖父！

在学习期间，我们特意安排了去毛家饭店总部，并荣幸邀请了毛家饭店创始人汤妈妈。
