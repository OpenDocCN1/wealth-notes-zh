# 改变世界商学院·世界企业家的摇篮 《全球暖牛日的收钱剧本》一诺老师专用

来海边开会，想先看看房间，挑几十间合适的客房，就在此人上楼的时候……

旅店主拿着 1000 元，跑到隔壁张屠户家付清了肉钱。

张屠夫拿着 1000 元，横过马路付清了养猪的生猪欠款。

猪农拿着 1000 元，到饲料商那里付清了欠的饲料款。

饲料商拿着 1000 元，付清帕帕帕小姐的过夜费。

这帕帕帕小姐冲到旅馆付了她所欠的房钱。

旅馆店主忙把这 1000 元放到柜台上，以免旅客起疑心。

此时富商游客刚好下来，拿起 1000 元，声称没一间满意的，把钱收进口袋，转身离去了……

这一天，没有人生产了什么东西，也没有人得到什么东西，不可思议的是——全镇的债务都清了，大家很开心。
