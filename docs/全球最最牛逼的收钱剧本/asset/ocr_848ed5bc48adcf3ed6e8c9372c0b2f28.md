# 改变世界商学院 世界企业家的摇篮 《全球搅牛日的收钱剧本》一诺老师专用

别的学徒睡到8点钟才起床，他5点钟就起来到院子里打扫卫生，做好工前的准备工作。自古天道酬勤，皇天不负有心人，不到两个月被老板任命为经理。

自1974年始之后的10年间，他先后在房地产、贸易、旅游等公司干过，初步掌握了各行业的业务运作。这些经历都成为成就他后来创业辉煌的基石。

30岁那年，严彬攒到了人生的第一个20万，他在曼谷买了第一套公寓。半年后，公寓价格就翻了30%。

就在房价飙升期，他做出了一个大胆的举动：他把曼谷的房子卖了，成立了华彬集团，“进军房地产领域”。
