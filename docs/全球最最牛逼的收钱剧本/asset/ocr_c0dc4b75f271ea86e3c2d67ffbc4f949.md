# 改变世界商学院 世界企业家的摇篮 《全球最牛日的收钱剧本》一诺老师专用

天，所以，屁股决定脑袋！这句话是对的！

后来就兼职做二手房地产买卖中介，当时的中介非常简单，就是到处贴广告！有时候见到熟人，还被嘲笑，但是莫总心里想：“虽然被嘲笑，但是口袋鼓起来了，笑就笑呗，反正又不会少一块肉！”

你想呀，上个世纪九十年代末，一个研究生能够拉下来这个脸上街去贴广告，真的需要相当的心理素质。

![](bbox=[0.135, 0.487, 0.86, 0.623])

紧接着，莫总开了几十家地产中介店铺，生意越来越好。

可是好景不长，随着同行业的不断进入，莫总的生意开始逐渐下滑。从之前的几十家店铺，萎缩到只剩一家店铺。

正当他对这个行业失望、无助、想要放弃的时候，她的太太向他推荐了一诺老师的书籍《全球疯狂吸金》，他一遍又一遍地看，足足看了 10 遍，每一遍都认真地做笔记，兴奋地失眠了五个晚上，后来跟太太抱头痛哭，终于有救了。
