# 改变世界商学院·世界企业家的摇篮《全球贿牛日的收钱剧本》一诺老师专用

88岁的汤妈妈听说我们要来毛家饭店总部,早就准备好了,为我们准备了贵宾厅。

当我们正在品尝毛爷爷最爱吃的红烧肉和韶山特色菜,开席没多久汤妈妈就进来迎接远方的客人,给现场的每位同学和校长们都送了一枚毛爷爷像章。

她在改变世界商学院的邀请下,讲述了她的创业史。

![](bbox=[0.12, 0.444, 0.84, 0.578])

1946年,汤瑞仁嫁到韶山冲毛凯清家。

她的家在谢家屋场,就是现在的毛爷爷故居武警警卫班所在地,离故居相隔一个池塘的距离。

毛凯清祖上与毛爷爷家是邻居,关系挺好,毛爷爷离开韶山前,还为他们家送过米、砍过柴。毛爷爷是一个念亲情的人,在汤瑞仁生活困难之际,主席还自掏腰包,给她寄来了8丈呎呎布,让她给家里人做衣服。
