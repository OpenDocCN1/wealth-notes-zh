# 改变世界商学院 世界企业家的摇篮 《全球景牛日的收钱剧本》一诺老师专用

1908 年，正值酸奶和乳酸菌的市场最高峰，而在那一年诺贝尔奖项竟然把诺贝尔生理学和医学奖颁给了梅契尼科夫。

手捧诺贝尔奖的他，在世界范围内变得更具权威。

![](bbox=[0.13, 0.32, 0.86, 0.46])

而为了提高酸奶的销量，他把酸奶的功效描述得更为离谱。

他告诉法国记者：我这里的最新研究显示，喝酸奶可以让人轻松活到 2000 岁，甚至可以长生不老。此语一出，立刻在欧洲引发了一波，全民渴求长生不老的酸奶销售狂潮。

酸奶狂潮席卷欧洲整整 8 年之后，最讽刺的事情发生了。

1916 年，梅契尼科夫死了，他只活了 71 岁。这和他描述的 150 岁、200 岁，甚至 2000 岁简直是天壤之别。很多人开始怀疑他言论的真实性。1917 年，科学家重新做了调查，发现保加利亚人根本不长寿，保加利亚也没有长寿村。
