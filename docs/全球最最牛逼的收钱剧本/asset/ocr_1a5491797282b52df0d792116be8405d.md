# 第22课：孙二娘坟山开坟门客栈年赚百万【傍租先模式】【傍文化模式】

大家好！我是一诺老师。当今企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争！一诺老师教您《商业模式·顶层设计》。

浙江龙门镇有座坟山，在本地农民的眼中是一个阴森恐怖的地方，是龙门镇专门用来埋葬死人的地方。山上密密麻麻地布满了 400 多个坟头。除了清明节去上坟以外就没人再上去了。

镇上的人，突然发现，这座坟山上经常出现一个女人的身影。人们不但白天能看到她，晚上还看到她一个人上山，这个人的出现，让镇上的人们，在茶余饭后，有了谈论的焦点。

这个经常出没在坟山的女人，叫孙法娣。这孙法娣为什么要住进这座坟山呢？正是因为她发现这座荒山里有一个可以开发的商业模式，为了这个可以创造财富的商业模式，她与 400 多座坟墓为伴，坚守 6 年。
