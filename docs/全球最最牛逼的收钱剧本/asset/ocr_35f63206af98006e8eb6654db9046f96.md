# 改变世界商学院 世界企业家的摇篮 《全球暖牛日的收钱剧本》一诺老师专用

成长在改革开放的春风中，汤妈妈 50 岁那年，看到很多人都来瞻仰毛爷爷故居，汤妈妈想做点好事，就把家里的绿豆粥拿出来给来往的客人吃，当时汤妈妈纯粹的是做好事，就是让外地游客感受韶山热情。

当时，很多客人吃了粥之后，就非常感激，虽然汤妈妈不要钱，但还是很多人给汤妈妈钱。

汤妈妈 1 块钱的绿豆，7 毛钱的白糖就靠摆地摊起家了。
有一次客人喝了绿豆稀饭，喝完之后感慨：这绿豆粥是热的，感受到了韶山人民的热情，可是这稀饭也吃不饱肚子呀，如果哪里有地道的韶山菜，那该有多好？
