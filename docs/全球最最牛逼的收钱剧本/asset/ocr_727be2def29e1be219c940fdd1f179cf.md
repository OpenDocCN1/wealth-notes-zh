# 改变世界商学院 世界企业家的摇篮《全球赚牛日的收钱剧本》一诺老师专用

各位，重赏之下必有勇夫，他管理烟厂时，想到烟厂上班的人挤破头；现在管理果园，想到果园干活的人也是挤破头。

这个已经 85 岁的老人，跌倒了没关系，重头再来，面对挫折和波澜的人生，迷茫过、伤心过、痛苦过、流过泪，也曾黯然神伤，但是他，选择坚强！

今天，经过评估，褚时健的身家又已养过亿。

他的那种面对人生的磨难所展示出来的淡定，让他作为企业家的气质和胸怀呼之欲出。王石不禁感叹道：如果我在他那个年纪遇到挫折，我一定不会像他那样，而是在一个岛上，远离城市安度晚年。

褚时健在红塔集团时，带出了三个徒弟，他们分别是：红河烟厂、曲靖烟厂、云南中烟集团的掌门人。

褚时健在曾经最辉煌的时候跌倒了，但在跌倒后，又一次创造神话，凭什么？
