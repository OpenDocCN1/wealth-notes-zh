# 改变世界商学院·世界企业家的摇篮 《全球最牛日的收钱剧本》一诺老师专用

国内的生产设备，都要考虑性比价，怎么会考虑一家外资公司的世界级的先进设备呢？

重点来了，利乐公司的商业模式是：伊利只要付 20%的设备费用，就可买下利乐公司的整条牛奶包装生产线，什么？疯了吗？比日本、德国的生产线还要便宜？而且，只需要付 20%，就可以拥有世界级的奶制品灌装生产设备？

你没有听错，只需要付 20%……

是这样的，那剩下的 80%设备款，采取“承诺购买一定数量的包装纸”的方式进行支付。

你想呀，在竞争白热化阶段，少支付 80%的设备款就多 80%的费用投入战场。乳业巨头伊利在当时对利乐公司啊，是感激不尽。在利乐的帮助下快速提升了产能，迅速地抢占了市场。

后来，伊利在利乐公司的帮助下，把奶制品销往全国各地。销量以几何式的倍增，终于啊，成就了今天的中国乳业巨头一
