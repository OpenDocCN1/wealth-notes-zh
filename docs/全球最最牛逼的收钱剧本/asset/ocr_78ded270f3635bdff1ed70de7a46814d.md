# 第10课：从负债千万到10万家分店【瓜分世界模式】

大家好！我是一诺老师。当今企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争！一诺老师教您《商业模式。顶层设计》。 

这个案例可以说是业界的神话。很多次在深圳开课，会选出3至5位优秀学员代表，我带他们来参观这家企业。

这家企业，曾一度频临倒闭的边缘。后来创始人力挽狂澜，3年时间拥有10万家便利店。

对，你没有听错！3年时间！10万家便利店！

你是不是觉得不可思议！

10万家店？平均每天开业91家，这还没有算上选址、装修、进货等等，一系列筹备的时间。

假设是每天开业91家，每15个小时，开业1家。

所以，如果每家店开业都去剪彩的话，24小时不睡觉、不喝水、不吃饭，半夜都在剪彩，你知道吗？
