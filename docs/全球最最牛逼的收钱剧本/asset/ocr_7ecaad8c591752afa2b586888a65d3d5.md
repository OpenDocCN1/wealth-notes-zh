# 第 02 课：一个啪啪啪故事让你秒懂商业真谛

大家好！我是一诺老师。当今企业之间的竞争，不再是产品之间的竞争，而是商业模式之间的竞争！一诺老师教您《商业模式·顶层设计》。

有一个啪啪啪小姐学了《商业模式·顶层设计》后，秒懂了赚钱的真谛，离开夜场应聘了一家贸易公司，用了一个月的时间，啪啪啪了 20 个已婚男同事，然后辞职。
