# 2、一个想富贵的人，必须养成颠覆自己的习惯

能颠覆自己的人总是少数。为什么一个穷人变富是
非常困难的？因为一个人要变富，要颠覆自己的思维，要颠覆自己的
行为。也就是说，这个人要自己推翻自己认为正确orr东西。

人最大的敌人就是自己。推翻别人，这种事情，我们经常做，
做得也很顺手，但推翻自己，就特别不容易。一个聪明人，不
应该去关注别人，而只应该关注自己是不是有钱。自己若是没有钱，
就不断的找自己到处哪里错了。

每个人的思维都是因为他的社会环境与自己的见识综合合作
用的结果。假如他没有见过富贵的环境，没有见识过富人的思维，
他要凭空产生富人的思维，或者仅仅靠推理获得富人的思维，
然后用这个思维去指导自己的行为，让自己变富。这就特别困难，
只有极少数智慧的人能做到。
