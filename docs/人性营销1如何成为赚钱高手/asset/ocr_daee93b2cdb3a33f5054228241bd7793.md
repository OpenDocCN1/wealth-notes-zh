# 3、如何避免成为一个穷人

只关心如何成为富人。

有的老板问我，你只关心成为富人，为啥来讲穷人的事情？
我的答案很简单，世界分阴与阳。稍想要了解阳面，最好要清楚晓阴面。想成为一个富人，自然是要清楚如何避免成为一个穷人。
你避免成为一个穷人了，就自然富了。

每个人都知道和穷人多打交道没什么好处，但有时还是不自觉融入穷人的队伍当中。我自己也是这样的。不过现在我已经改变了很多。穷人要打翻身仗，就要脱胎换骨，甚至换血，主要是换头脑的思想与观念。人与人走近、靠近，成为朋友，很多时候 Ancient 因为个性相近。
