# 16、这个时代最优的赚钱方式

大部分人宁都以为自己的赚钱方式是天下间最好的赚钱方式，这是极其愚蠢的，所謂一叶障目，不见泰山。只有认识到了社会上的赚钱方式是多种多样的，我们才能够选择最赚钱的方式去赚钱。
