# 8、改变别人命运的同时，也就改变了自己的命运

告诉你穷富的根本原因，其实，一个人只要不断地做好事、利他、释放价值，就会富起来，就会过上好日子。这就是赚钱的全部秘密。

一个人赚不到钱，就是因为他是坏人，他品行恶劣、懒惰、欺骗自己，也欺骗他人。品行好的人，不可能穷的，他会为了自己的父母、妻子奋斗，会为同事、公司奋斗。一个想方设法奋斗的人，是不可能贫穷的。只有品行低劣的人，才任凭自己父母、妻子过差的生活。
