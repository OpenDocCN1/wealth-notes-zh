# 4、如果你逆反你的天性，那么你就不会有什么成就

大部分人一辈子也没有搞清楚自己是谁，所以根本不是用自己擅长的工作方式工作的，更不用说能找到自己的特长了。每个人都是天才，都可以成就一番事业，但如果你不知道自己到底擅长什么，到底适合什么样的工 作方式，你就不可能有成绩。

本人在初中、小學的時候，成績非常非常的好。在高一的時候，成績也是好到極致。本人的英語成績基本上接近滿分，化學、數學、物理成績幾乎也是接近滿分的存在。但高二的時候，英語開始不及格了，化學成績也開始變得很差。這並不是因為我不努力，因為我高中的時候學習是很瘋狂的，別人’intervento去玩的時候，我依然在教室裏做習題。更不是因為我的智力變低下了。我當時也是百思不得其解，現在我反思為什麼高二的時候成績下滑得這麼厲害，才恍然大悟。
