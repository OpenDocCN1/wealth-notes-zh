# 1、什么是真实的世界

大部分人都活在虚假的世界中。

什么是真实的世界？假如你邻居是开棺材店的，他天天烧香祈愿，希望多死点人。每当有人死了，他必然欢天喜地，并不是他心肠歹毒，只不过“利”字当头。

同样的，一个82岁的男人娶了一个28岁的才貌双全的女子，也并不是女子厚颜无耻，卑鄙下流，她只不过想缩短发财的时间。

这个世界上没有人会无缘无故的做坏事，也没有人愿意无缘无故的出卖他人。但由于有利 益的诱惑，每一个 人都有一个价钱，很多人会为了某个价钱出卖灵魂，出卖父母，出卖兄弟，出卖好友，出卖左右邻右舍就更加容易了。如果利益诱惑非常的大，很多人连性命都不要了，更何况出卖亲情与感情。
