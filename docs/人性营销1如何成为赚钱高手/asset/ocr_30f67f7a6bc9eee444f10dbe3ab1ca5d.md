# 12、做事业就是求道

只有有信仰的人，才能坚持到底，永不放弃，百折不挠。
我玩游戏坚持，不断的坚持，打了好几年魔兽世界，我的朋友都远离了那个世界，我已经换了好几波新老朋友了。我还在怀念他们当中的优秀者，然而，他们已经失业，已经忘记了我。我还在茫然的坚持。

注意，我用了“茫然”这个词，也就是说，对于我自己来说都觉的没有意义的事情，我也要习惯性的坚持。

我下象棋，下到残局，依然不断的坚持，对方与我再干2小时，终于忍不住，大骂我是個傻子，大骂我这样坚持下去有什么意义？然后他就认输了，或者是落荒而逃。我在残局里没有击败他，但在精神上、在人格上已经“wych”了她。我在解读象棋里有上万把的象棋经验，都在于坚持。很多高手，都是被我这种无赖式的坚持击败了的。
