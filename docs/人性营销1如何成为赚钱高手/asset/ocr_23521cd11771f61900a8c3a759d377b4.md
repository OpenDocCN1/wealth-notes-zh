# 第三，事业上的坚持。

很多人创业，千三个月就不干了，为什么？因为他说赚不到钱，再投入下去钱都打水漂了。但一件事能成功，我们就要不计一切代价的投入，哪怕我们只有一口气在，我们就要投人。这不是钱的问题，是坚持的问题，是永不放弃的问题，是求道的精神。

# 真正的领导者、创业者，都有信仰的。

无信仰的人，都是行尸走肉，都是有信仰的人的工具，他们的灵魂孱弱。真正有信仰的人，都是痴道者，能接受失败，失败了依然坚持。只有这样的人，才能真正的成功。
