# 只要你愿意动手，你就不会迷茫。

创业这件事，对很多人来说最难的就是营销，而最应该做的就是营销和推广，这件事是要长期做下去的，所以，更加没有时间去迷茫了。你成天去发广告，去推广，去收钱，你怎么可能有时间迷茫呢？

你找到一些客户需求，然后天天去满足这些客户的需求，你从早到晚都有事做，自然不迷茫了。很多人迷茫，说白了，就是懒，不想行动。有的本就是普通人，或许迷茫就是他的命运。而创业者，是没有时间迷茫的。
