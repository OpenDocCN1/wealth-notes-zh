# 第一部分 理论框架

# 一、头游就是硬道理

# 头游定胜负

竞技规则中最重要的内容是胜负规则。

+   ❏  一局的胜负是由头游决定的。其它游，只影响胜负的大小。

+   ❏  一人头游，全队升级。

+   ❏  头游就是硬道理：本来能拿头游，因为失误弄丢了，至少损失 2 级。双上的牌，结果被打双下，就是损失 6 级，需要打 2 个双上才能弥补。这一点影响全盘。

# 二、头游的 4 种主要方式

了解头游的主要方式，有利于抓住每一个头游的机会。

# （一）炸弹胜

炸弹多，需要护送的小牌少，最后剩 1 张或更多的炸弹。

这就是传说中的好牌。胜利了，只能获得一般的快乐。

# （二）闯关胜

倒数第 2 轮出的牌恰好无人能敌，也就是炸弹或大牌刚好把小牌护送完，没有浪费。

牌力弱于炸弹胜。
