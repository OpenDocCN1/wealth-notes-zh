# （三） 上家控制技术

一般来说自己是上家控制的对象，老攢们都会说：上家打我，活该；我打上家，不该。从牌理和位次关系看，老攢手的经验之谈确有道理。

在我们的局牌中，平均每家要打 9.6 手牌，垫手多达 33.6%，而通过上家直接垫出的又占了其中的一半多，可见上家出牌对你有多大的意义。

“轻易不接对门牌”是攢蛋界公认的，因为每个主打牌的人都会有自己的战术意图，总希望牌局向自己预期的方向发展，所以，作为对门方，若非十万火急或十分有把握控制局势，你不要去接对门的出牌，同时，拦截对门是对手的责任，而非对门的义务。

当然，垫牌不在此限。这个招法强调“慎”接，若同时具有极大极小的同类牌则可以接转。

那我们对上家走牌有什么原则要求吗？非常遗憾，这个环节没有定式，有的只是大概的经验和感受。

首先要预判上家可能走的牌型，如果能为你带牌的，放任通行，甚至可以暗中帮他的“忙”，诱使其打出你能垫上的牌型。如果上家所出牌型与你根本不对路，应立即封杀。

第二，如果上家传牌，要即时予以阻止，即便你有需要垫的牌。因为这个时候不是垫牌的时候，如果你贪图便宜去垫，你是垫上了，但下家也走完了。

第三，对上家的冲刺牌，除非你对对门有绝对的把握，否则应在自己的位次上拦截上家。有的时候，明知对门可以接住或拦死这样的冲刺，但你也要算笔帐，算什么呢？因为拦住冲刺是目的，所以只要拦住就可以了，这时要算的是以最小的付出拦牌。

在这里不得不再次提醒攢友，一定要以小的付出来达到目的，否则会有极其遗憾的结果发生。
