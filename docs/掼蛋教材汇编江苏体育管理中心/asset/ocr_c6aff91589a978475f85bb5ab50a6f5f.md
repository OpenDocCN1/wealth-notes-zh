# 2、小牌不是绝对的

下家没有单张时，你反打小单张就不算是小牌。如果对家听单张，你出的小单张更像是精准的子弹。

所以出小牌的时机很重要。

此外，如果牌力使用不当，炸弹和最大牌也可能变成累赘，被对手大炸闷在手里丢失头游。这种情况下，就要及时认真总结。
