# 二、掼蛋的战略

掼蛋的战略远比技术重要。很多牌手组牌、记牌、算牌等技术都很出色，但始终不能成为顶级高手，就是因为不懂战略。掼蛋每一场比赛有每一场比赛的战略，每一局也有每一局的战略，不同的规则、不同的时段有不同的战略，制定战略的前提是战略分析。

掼蛋的性质：两人配合作战的数学策略游戏、博弈游戏。

掼蛋的目标：团队利益最大化。

# （一）决定战略成败的要素

+   1、资源配置，即组牌；

+   2、竞争优势；

+   3、团队配合。

# （二）战略分析（课堂详解）

# 1、战略分析的前提

①已知信息：绝对牌力和贡还牌；

②概率计算。

# 2、战略分析的方法

①引入 SWOT 分析法、波士顿矩阵；

②外部环境：机遇和威胁；

③内部条件：优势和劣势；

④轮次与大牌。

# （三）战略定位（课堂详解）

掼蛋定位：根据自己牌力的相对强弱确定自己在本副牌博弈中的位置
