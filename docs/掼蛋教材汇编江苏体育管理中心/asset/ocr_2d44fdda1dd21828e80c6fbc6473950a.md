+   强牌策略：当仁不让，力争头游。

+   中牌策略：边打边看，把握机会。

+   弱牌策略：放弃头游，力助队友。

那如何衡量牌力的强弱呢？

# （一）感觉艺术法

+   强牌：炸弹多、大牌多、牌整

+   弱牌：炸弹少、大牌少、牌散

+   中牌：介于强牌与弱牌之间。
