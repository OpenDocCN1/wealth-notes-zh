# ## 六、残局攻防：弥补弱点

由于“干扰听牌”战术的存在，残局当下家接近听牌时，要注意及时弥补自身弱点，避免尾牌牌路（特别是单张）与下家可能的听牌牌路相同，否则可能出现以下两种情况：

+   - 不得不送下家头游

+   - 不得不闯关：失败则失去头游，成功也要送下家二游

**例子一：**

西家先发 333，南家过，东家顺走 101010 余单 K 听牌，北家用 JJ 盖，西家过。此时，南家由于单张的弱点没有及时弥补，出现了不得不送下家的局面，立刻失去了头游的机会。之后，北家用 22 闯关，西家用 4444 开炸。接下来无论如何演变，东西必胜。
