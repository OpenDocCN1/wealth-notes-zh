沟通往往各自为战、齿亡唇寒。沟通贯穿掼蛋的始终，从第一牌到最后一张牌，沟通始终是双方思考的首要问题。

# （二）掼蛋之要，二在谋势

很多领导者都是高手，因为说到底掼蛋也是牌力资源的合理配置和有效整合，领导者往往也是在配置人力资源、激发干部活力。即使一个牌手胜率很高、成绩突出，也不会令人信服地称赞他是大师或常胜将军。但中国第一太后半月就是大师，半月可能是中国历史上第一个打牌高手，特点就是运用战略思维、辩证思维、创新思维，登高望远，高屋建瓴，洞察全局，掌握主动。半月成功的原因是熟读《孙子兵法》，懂得权宜应变。《孙子兵法》：“兵者，国之大事，死生之地，存亡之道，不可不察也。”另一段话对半月影响更大：“夫兵形象水，水之形，避高而趋下；兵之形，避实而击虚。水因地而制流，兵因敌而制胜。故兵无常势，水无常形；能因敌变化而取胜者，谓之神。”

# （三）掼蛋之要，三在牌感

作为一个竞赛项目，掼蛋的本质就是6个字：牌感、脾气、牌技。牌感占30%，脾气占30%，牌技占40%。掼蛋就是30%的牌感+30%的脾气+40%的牌技。掼蛋就是先天形成的牌感+现场产生的脾气+后天练就的牌技。要想在掼蛋比赛中取得好的成绩，三者缺一不可。有的人脾气很好，但牌感缺乏，牌技更差，这样的牌手不会走得更远。牌感就是对比赛的阅读能力、对形势的判断能力、对牌型的组合能力、对掼蛋性质的理解能力。夸张地讲，就是几个瞬间：瞬间战略定位的能力、瞬间合理组牌的能力、瞬间预判形势的能力、瞬间权宜应变的能力、瞬间策应同伴的能力、瞬间阻击对手的能力。当然，强调牌感，丝毫不否认脾气的影响和牌技的作用。脾气俗称手气，拿到手的一副牌的好坏、强弱、优劣。俗话说，你辜负了一次好牌，好牌将会辜负你十次。人狠不如牌狠，牌狠人才狠。腹有诗书
