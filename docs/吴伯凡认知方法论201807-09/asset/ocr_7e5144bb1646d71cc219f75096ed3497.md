# 本单元总结

+   1. 第一节课

我希望能破除你对知识的一个误解：我们经常说的一个词叫“知识点”。但是，一个有用的知识，一定不是一个知识点，而是知识网。哪怕是最简单的一个概念，如果你深入了解它的話，也不是一个点，而是一个非常复杂的知识网。所以不存在单纯的知识點。就好像俗话说的，微尘中见大千，刹那间见永恒。而单纯的知识點，应用场景十分有限，也就没有什么实际价值。

+   2. 第二节课

我们说，在庞大的网络之下，知识可以分为两类：真知和熟知——真知是你真正知道的知识，而熟知不过是你觉得熟悉，但是经不住考验，类似于孤立的点而没有形成网络的知识。而一个人的认知优势，就体现在真知占整体认知的比例上，比例越大，认知优势也就越大。

+   3. 第三节课

我们讲了我们面对世界的三种立场，分别是物理立场、设计立场和意向立场。物理立场是你接受世界本来的样子，无论它是什麽样子，你都认为它不受你的支配；设计立场是如果面前的东西出了问题，你认为你有责任去改变、修正它；而在意向立场下，无论你面对的人还是事出了问题，你都会认为是对方的问题，对方应该怎样，甚至去责备他。一旦陷入意向立场，就会提高情绪左右，对认知造成障碍。这三种立场可以组成一个非常有效的反省机制，一旦你出现了不当的情绪，就可以思考一下，是不是用错了立场导致的。

+   4. 第四节课

我们通过几个例子体会了意向立场给认知带来的阻碍，以及一旦从意向立场转换到物理立场或者设计立场之后，会给我们的情绪、事态的发展带来多大的影响。所以，我们要做的是努力成为立场的主人，而不是奴隶。

+   5. 特別放送

最后，我不仅给你准备了这个单元同学们的精彩留言，还在下方列出了我筛选精彩留言的方向和标准。写这些的目的只有一个，就是希望留言区能成为见证你认知进步的地方。我一直在课程里强调学习和练习的关系，以及练习的重要性，我希望你能把我们课程中讲到的每一个概念、方法都在生活中反复演练，如果成功了就写在留言区跟同学们分享你的喜悦，如果失败了，我们也可以一起来帮你找问题。这才是我们设置精彩留言板块的真正意义，奖励的书不过是一个附加价值而已。

# 什么样的留言会成为“十大精彩留言”？

+   1. 课程内容的正向补充

比如，我们在讲“认知与客观化”时提到了人们以为自己掌握了很多能力和知识，但事实未必如此，针对这一点，Ligaking同学作了如下补充：

# Ligaking

每个人所掌握的知识和能力，可以分为以下几类：

+   1. 不必学习就“先验”掌握的，比如对空间、时间的感知，对光线、色彩的分析能力，记忆和思考能力，对移动、速度的判断等等，感谢亿万年的进化，让这些技能镌刻在本能里，而不必每一个个体都从头学起；

+   2. 经过系统学习和训练掌握的基础知识，比如四则运算、拼音、语言、写作等等，它们并不直接影响生活，也很少出错，但可以帮助我们作判断；

+   3. 综合各种数据对事物作判断的能力，所谱生命的过程就是不间断地作价值判断的过程。恰恰是这个判断能力，因人而异，千差万别，因为正确的输出需要两个前提：正确的数据和正确的解释过程；

+   4. 我们以为自己懂了，其实是一知半解，甚至是错误的知识；

+   5. 我们懂了，但从未被我们有效用于正确判断的知识；

+   6. 我们一直抗拒的、以为是错误的知识，其实彼此才是对的，只是我们不愿意承认；

+   7. “超验”的，我们根本不知道自己不知道的知识，那是被整体认知黑幕笼罩的世界，无法想象。

我知道我知道，我知道我不知道，我不知道我知道，我不知道我不知道。认知的层次，就在于你在多大程度上察觉到这些状况的存在。认知的错误，就是因为这些知识在互相影响，都致力于参与你的决策过程，而认知者使用了错误的数据和错误的解析方式造成的。

+   2. 课程内容的横向延伸

比如，我们在讲“认知断舍离”时，从认知的角度分析了人类大脑的原始性，大唐同学从科学的角度作了延伸：

# 大唐

我听过一期《罗辑思维》节目，讲到人脑其实是分为五层的：

最里一层是鱼脑，我们祖先最开始是生活在水里的；外面一层是两栖动物脑；再外面一层是爬行动物脑；再外面一层是哺乳动物脑；最后一层是人脑，也就是大脑皮层。

我们的逻辑思考和自我意识就是来自大脑皮层，但是这一层的大脑是最“年轻”的，而其他大脑是“长者”级别的了，而且是潜意识的。我想Cookie就是隐藏在这些潜意识的大脑里的，通过启动Cookie来调动潜意识的大脑占据大脑的领导地位，乌合之众的原理就是这样。

所以把自己“客体化”很重要，这样是让大脑皮层做主角，不让潜意识大脑有可乘之机，这样能更清晰地看到自己。

# 终身思考

今天有两处概念貌似与之前的有矛盾，其实是有明显的区別。
