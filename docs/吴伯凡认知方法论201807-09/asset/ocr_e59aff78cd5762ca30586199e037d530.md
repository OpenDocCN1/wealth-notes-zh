# 1. 认知的“上不封顶，下不保底”

@越过大山

提升个人认知如此之难，人类整体的认知进步会有上限吗？

应该说“上不封顶，下不保底”。

大家还记得到我们在前面的课里讲过，不管是蝙蝠的超声波，还是蛇对红外光的感知，认知的本质是一种生存工具。这个场景和挑战不存在了，这个工具就没有了意义，或者说，有外在的工具、技术来代替我们的认知工具的话，我们的认知就自然逐渐退化，甚至消失。

《哈佛商业评论》主编尼古拉斯（Nicholas G.Carr）在《浅薄》（The Shallows: What the Internet Is Doing to Our Brains）这本书里写的就是这个道理：当互联网越来越成为我们的认知工具和手段的时候，我们的认知能力就会自然而然地变得浅变薄。

这既不是一个哲学化的判断，也不是一个情绪化的判断，这是富有实证科学作为支撑的：有人对就两代出租车司机的大脑进行扫描以后发现，他们的大脑有整体性的明显差异，原因很简单，年轻一代的司机越来越多借助于GPS导航，而老司机只能用他们的大脑作为工具。

![](bbox=[0.15, 0.68, 0.85, 0.00145])

“上不封顶”是什么意思呢？就是：某些认知能力由于特定场景的出现，可能会进化出新的认知能力。比较极端又浅显的例子就是盲人的触觉、听觉和直觉可能比我们普通人要高得多。

人的认知能力和认知能力的分布，呈现出一种动态的趋势——我们在这个意义上说“上不封顶，下不保底”。

当然，人的认知越来越被机器化，人本身的认知能力就会逐渐下降。但是，借助机器，人机一体化的认知能力会越来越强，也就是说，我们借助大数据几乎可以拥有未卜先知的能力。

# 2. “客观化”的重要性

@小顺意

要想思维和认知有进步，就必须客观化，这是说要把事物具体化，而不是在脑中抽象化的意思吗？

我们大脑中的认知不仅仅是抽象化，往往呈现混乱和模糊的状态。当你把你的想法说出来的时候，你就会意识到你的很多想法其实是模糊、混乱、不成形的。不在客观化的镜子映照之下，你是不知道这一点的。不借助客观化，仅停留在头脑中的认知，由于没有一个支点，它的进展是没有方向的，会呈现“布朗运动”的状态。

所以荀子说，“吾尝终日而思矣，不如须臾之所学也”。培根说，“不要用头脑去思考，要用笔去思考”——他们说的都是客观化对于升级人的思维，提高人的认知的重要性。

最简单的例子就是找你的朋友下一盘盲棋：不借助客观化的棋盘，体验一下你的思维有多模糊、多混乱，甚至是没法进展的。

# 3. 代替性工具导致“认知残化”

@鑫燕

思维工具的进化是为了方便思考的深化，客观化的思维工具节省了大脑的认知资源，利用客观化是否有“认知残化”的可能？

我们有两类工具：

+   - 代偿性、代替性的工具，比如有了车，我们不用走路，车代替我们走路；
- 辅助性工具，假如你的腿伤了，你可以借助拐杖——拐杖不能代替你行走，只能在你能力不足的情况下辅助你往前走。

“代替性工具”往往会导致我们的“思维残化”，而“辅助性工具”会给我们的认知赋能。

比如你列清单、做几何题把图形画出来、下棋的时候用棋盘，这些都是给你的认知赋能的，它们给你的认知一个支点，撬动你没法撬动的东西。
