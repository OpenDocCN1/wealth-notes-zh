从对话到潜对话

欢迎来到《吴伯凡·认知方法论》。这个单元咱们的主题是“从对话到潜对话”。

第一节课我们区分了两种认知，一种是对于“表面”的认知；另一种是对于后台的认知。我们的感官感受到的世界，就是对表面的认知：比如听到的音乐，闻到的花香，吃到的水果等等，都是对表面的认知。它背后的机制，比如科学家研究出来的背后的原理，就是对于后台的认知。

第二节课我们说，一个好界面的征服力和杀伤力是无比巨大的，比如水果表现出甜美，人表现出性感，但是，往往最简单的界面也是最难完成。

比如水果，就是借助了进化的力量，通过复杂的后台演化才让你喜欢吃它，进而达到自我繁殖的目的，其实水果是给你制造了一个虚幻的控制感，这种手段我们管它叫强助推。大自然的产品逻辑就是：起点的高度复杂和终点的高度简单才是真正的友好界面。

在第三节课里，我们复习了一个概念叫达克效应，说蠢人是很难发现自己的愚蠢的，因为发现自己愚蠢是需要相当高的智力的。

这个效应在本单元讲的界面和后台的关系上也非常适用：要达到界面的简单友好，让人看不出复杂技术的痕迹，这是需要相当高的技术。要达到这个水平，可能需要经历从“看山是山”到“看山不是山”，再到“看山是山”的这三个阶段。

最后一节课我们说，人的互动，其实现和我们前几节课一直在讲的界面，也就是人机对话的方式是一样的。对于人机对话来说，它经历了从复杂到简单的过程，最高级的对话是机器可以识别需求，人的互动也是这样，最高级的互动就是从场景、状态中就解读出对方的想法和需求，这就是我们本单元要讲的从对话到潜对话，具备了这个能力，你就成为了互动高手。

## 特别放送 | 第一模块重要概念与认知训练方法

吴伯凡

今天的课带你一起复盘：我们在第一模块里学了哪些重要的认知概念，以及相应的解决方案、训练方法有哪些。

# 概念：

> 刷卡式认知···
福尔摩斯能够瞬间识别一个人的身份，闻谈他就能很快地建立信任关系，这能力有非常短的时间内直击问题本质、快速通关的能力，就是刷卡式认知。所以谓的“认知优劣”，很大程度上就表现为快速识别。

> 认知专线···
从本质上来说，认知就是神经元之间的连接。这个连接越隐敛，认知行为产生的就越快。当连接积累到一定程度形成了认知专线，那么就能瞬间解决问题的高手，就是形成了认知专线的人。

# 认知训练法：锁定目标+刻意练习

想要提高速度就要满足一个条件——目标明确。雷达能快速准确地识别物体，就是因为它只识别目标物体，其他物体全部忽略。我们要想拥有快速识别的认知能力，首先就要确定：你要识别什么？你的具体目标是什么？你是要快速识人还是明事？是要训练自己的观察力、创造力、执行力还是领导力？

有了明确且集中的目标，接下来就是找更加具体的场景刻意练习。举个例子，如果你想想象福尔摩斯一样，能识别出陌生人的身份，那么从观察陌生人开始，通过他的行为举止、穿衣打扮做出自己的判断，如果有合适的时机，再去验证获得反馈。通过刻意练习的方式，逐渐建立这方面的认知专线，拥有刷卡式的认知能力。

# 概念：

> 认知之树···
认知之树代表的是层层认知形象：既要有树干——树一个领域纵深式的认知，也要有树冠——广大丰富的知识面，缺少一部分都不能形成真正的认知。

# 认知训练法：找到属于自己的洞穴空间

在高度互联的今天，获得广泛的知识一点也不难，难的是挖掘认知的深度。我们需要找到一个能够蔽噪音的空间，在这个空间里，你能静静地思考，能发现具有统摄性的规律、方法、原则、算法——这个空间就是“洞穴空间”。“洞穴空间”是什么形态不重要，可能是一间卧室、一个茶水间，一个咖啡厅，甚至没有实体，关键在于你要能在里面进行深入思考，这样才能拥有纵深式的认知。

# 概念：

> 钟型思维与云型思维
钟代表稳定性，我们并不确定性。如果条线从任何事情都是“钟型思维，钟型管”，那就是典型的“线性思维”；相反，如果你相信事物并不一定恒定，也可能波动，那你就具备云型思维，生活中大部分重要的事情是云型的，比如创业、职业发展、婚姻等等，需要依靠不确定的视角去待。

# 认知训练法：火力侦察

面对生活中大量的不确定性事件，我们怎么判断事态？比如对手的实力如何？我的胜算有多少？应该什么时候出击？从狮子身上我们可以学到一个方法——火力侦察。

狮子在捕杀羚羊之前都会先做一个动作——假装攻击，这样就能找到羊群中最容易下手的那一个，这就是典型的火力侦察——通过制造真实的战斗画面来观察对手的实力，从而找到出击的机会。只有在动态中获得的情报才最真实；只有在博弈中获得的认知才最有效。

所以，说到底，在复杂问题面前，不要闭门造车，不要空谈空想，去行动，你会在博弈中发现新线索。

# 概念：

> 认知缺省···
缺省是一个计算机术语，安装软件时带的“缺省设置”就是安装默认版本的意思。认知缺省就是说：我们的认知安装的也是默认版本，无法验证，所以它有很大的缺陷。要记住：任何认知都是有缺陷的，需要不断验证，不断被迭代。

# 认知训练法：双环学习、矩阵式认知

因为认知缺省的存在，我们就要时刻注意，不要让自己的认知陷入片面、偏执的死胡同，要不停地从客观的视角审查自己的认知。双环学习和矩阵式认知就是告诉我们，要跳出原有的认知维度：如果原来的认知是一个闭环，那就打开一个缺口，重启一环；如果原来的认知是一条横轴，那么再拉出一 条纵轴，形成一个矩阵。

如何做到？你可以尝试着给自己培养一个习惯——在理所当然中寻找问题。比如理所当然的商业模式、理所当然的风俗习惯、理所当然的习俗见等等等。

# 概念：

> 选择压···
蝙蝠为什么是眼睛退化却耳朵灵敏？还是因为视觉的光线在地下洞穴里几乎微弱不明显，而听觉却在洞穴中可以更好地探知位置。蝙蝠可能饿死。所以，选择压力大的环境下就迫使它的视觉系统退化，反而发展出优秀的听觉系统。我们如果处在自己所处的环境，环境的认知老是被迫退化的压力下，如果自始没有在竞争，那就不会出现认知的进化。所以，要想认知升级，就要给自己制造选择压。

# 认知训练法：找到自己的生态位

生态位其实就是生存的要素。对于蝙蝠来说，它生存黑暗的空间里，如果它不能进化出视觉之外的识别物体的能力，就会面临生存危机，这种选择压让它进化出了超声定位能力。换句话说，如果没有黑暗环境这个生存要素，蝙蝠也不会具备超声定位的优势。

所以，选择压的根源还在于生态位。想磨练自己的意志，就去一个艰苦的环境生活；想成为一个谦逊的人，就多和比自己厉害的人在一起；想锻炼某方面的能力，就到能培养这个能力的环境中去。

# 概念：

> 认知周期···
认知周期简单说，就是从相信到怀疑的一个过程。比如，我们之所以会经常怀疑，就是因为结束了第一个认知周期——从相信父母绝对权威到怀疑父母权威，开始建立自己的权威。不管，怀疑只是一个中转站，继而再开始相信，再从相信到怀疑，不断地在新的认知周期，才能保持认知迭代。组织时间内，经历的认知周期越多，认知迭代越快。

# 认知训练法：找到权威崇拜

既然相信是一个认知周期的开始，那么不断在怀疑过后重新找到让自己相信的人或事，重拾敬畏，就非常重要。找到让自己敬畏的权威，让自己自卑形秽，感受到自己明显不足、缺少，这时候，你会自然进入一种敬畏和空杯状态。

我当时很奇怪，因为我是和别人一块儿去参观的，事先并没有告诉他们我会去参观。后来我想…

我在现场还问了一个很“小白”的问题，“这种技术是不是模式识别呢？”

接待我们的人说：严格说，是错的；大致说，是对的。我们是通过摄像头捕捉到你的脸，生成一个模型，然后根据这个模型在网上搜索——这种技术已经不能叫“模式识别”了，而是“机器学习”。

我后来还仔细看过一些相关东西后发现，这两者确实有很明显的差别。

简单说，“模式识别”是一种非常经典传统的 人工智能，甚至可以说是“古老的技术”。这种技术在上个世纪五十年代就有了，它通过对某些图像、声音进行分析，生成一个模式，然后把这个模型放入计算机，让计算机按图索骥找到跟这个图形、声音相关的信息和文件。

在今天，“模式识别”这一技术已日益式微了，因为一种仅有相似性，但在性能上远超乎它的新技术出现了一——机器学习。

# “自下而上”的机器学习

用我们熟悉的话来进行区分的话，“模式识别”是演绎，“机器学习”是归纳。

“演绎”是有了一个成形的模型判断，再用这个判断去规范、衡量众多信息，然后找到某些信息，得出相关结论和作出某种预测。这种方法对于识别简单的信息是有用的，比如，在一堆几何图形里把三角形找出来，是很容易的，但在…

我们平时很容易就能感受到“模式识别”这种技术的缺陷，比如在网上看到一些书…

而“机器学习”的特点，在方法论上，它不是“自上而下”的，而是“自下而上”的。也就是说，“机器学习”是不带成见和偏见吸纳大量数据的。它从大量的、非结构性、没有指向的数据当中，生成一些模式，然后再在大量的数据中寻找符合这个模式的东西。同时，这个过程不是一次性完成的，它是一个反复迭代的过程。

举一个我们熟悉的例子：当我们在手机上手写输入的时候，有“模式识别”和“机器学习”两种选择：

+ 1. 模式识别

在手机里，已经存储了某些字的固定模型，只要你进行手写，就会给你呈现给你“你可能要写的字”，然后你选一个就可以了。

如果你写的字不是太规范，比较潦草，它往往就认不出来，或者，它的选项就特别发散，什么不搭边的字都呈现给你——这是“模式识别”技术很容易出现的结果。

+ 2. 机器学习

每一次你输入的时候，它会根据你的笔记跟字之间的对应关系，逐渐形成一种专门针对你的具有个性化特征的模式，这样一来，准确率会越来越高。这个过程是“自下而上”，基于大量非结构性数据、不带成见、实时互动的生成模式。

之后，再用这种模式进行识别。当识别过程中出现任何错误，都会再回馈到机器当中，机器进一步修改它已经生成的模型——这样，就会越来越精确，越来越智能。

“模式识别”和“机器学习”的最大差异就是：一个是“自上而下”，一个是“自下而上”。用我们以前说的话就是：一个是“创世论”，一个是“演化论”。

# 认知的“模式识别”和“机器学习”

今天和大家分享这个话题，是因为我们的认知也都同时包含着这两种特点：

+ 1. 模式识别——我已经被输入了某种固定的模型，我根据这个模型去做识别、判断、选择等等。

+ 2. 机器学习——我在茫无头绪中面对一个陌生的世界，自己慢慢摸索，逐渐形成了一些所谓的规律，而这个规律是一种暂时的、不那么扶着的规律，我要怀着谦卑之心，拿这种规律和模式去跟世界碰撞。如果我是…

查理·芮格说，“很多人的认知是钉锤型的认知”，就是手里拿把钉锤，什么都用钉锤来解决， 尽管眼前这个对象根本不是钉子。造成这种现象的原因很简单：你的工具太少。当你的工具很单一的时候，你就会不由自主地使用这个单一的工具，以固化、老化的知识去对应一个复杂 的、实时变化的世界，那你一定会出错。

针对这一现象，查理·芮格给出的建议是“往脑袋当中输入各种认知模型和思维方法”。当你的工具库里有足够多工具的时候，你总能找到恰当的工具来应对突然出现的新情况。

但是，查理·芮格没说这些工具到底该怎么来，他的意思是“不断地看书”，当然，他自己确实在不停地看书。我给大家讲过，他有一个习惯——每次跟人约会总要提前45分钟到，一方面表示对对方的尊重，另一方面，他觉得这45分钟看书的效率非常高——作为一个90多岁的老人，查理·芮格还在不断地往自己的工具库里加工具。

当然，更多的工具也不是简单地从别人的书里拿过来的，而是通过自己跟世界不断地接触和博弈、冲突，逐渐演化出各种各样的工具，并努力使自己的工具呈现多样化的态势，避免“钉锤式”解决问题的方法。

# “既可能又不可能”的终身学习

下面我们要谈的，是一个经常讨论的话题——终身学习。终身学习既可能又不可能。

关于人的神经元的轴突和树突，青年人、中年人以及老年的不同形状，一眼就能看出来：青少年阶段，树突可以用“枝繁叶茂”来形容，分叉很多；逐渐地，会变得稀疏。

一方面是“用进废退”，另外也和生理上的老化有关。这就导致了“接触的信息越来越单一”，因为连接的概率会越来越低。这就像在一个舞会上，人多，意味着你可以跟很多人跳舞；如果只有两个人，你就永远只能跟那个人跳。

随着年龄的增加，神经元的树突变得稀疏的时候，人对世界的反应方式就容易显现出“钉锤化”——模式越来越单一，或者于脆就不反应。这也能够解释老年人固执、嗔、保守的现象，这是人的认知老化、固化的不可逆过程。

反过来，一个天真活泼的少女和一个大妈之间的反应模式也有非常明显的不一样：少女看什么都好奇，遇到什么东西都有热情，从语言、行为、表达方式到搭配选择，她都呈现出一种多样化的状态；而五六十岁的女性，无论是从反应、表达、行为上，都呈现出比较单一的方式。

这首先包含了“生理基础”：树突如果是枝繁叶茂的，那么多点对多点的连接就会产生丰富的知识、信息、感受等等。如果你知道“用进废退”的道理，那么到了年老的时候，你的树突也不至于显出光秃秃的样子。
