# “大自然没有说明书”

@ YAN

界面越简单，用户体验越好，是不是用户也变得越来越依赖界面，而不去思考背后的逻辑呢？

@ 求学君

强助推有什么坏处是需要我们有意识来避免的？

用户是没必要去思考背后逻辑的。设计界有一句大家都很认可的话：大自然没有说明书。

孔子也说过类似的话，“天何言哉，四时行焉，风雨兴焉”。意思就是，天不用说话，春夏秋冬也会这么运行，风雨雷电也会如是发生——它们都没有说明书。

蜜蜂不需要先读完一本书再去识别花香，找到可以采蜜的花；猴子猩猩不需要你在树上贴个字条“这里的果子可以吃”——自然界的东西就是“所见即所得”的，而且得到的东西本身就是一种“超级刺激”，不需要有人告诉它们“吃了这个东西对身体有好处”，它是以一种极其直观的界面告诉你、激励你，让“用户”按照大自然事先设定的流程去完成规定的动作，而用不着去思考背后的逻辑。

“强助推”就是一种超级刺激。由于它强烈的刺激和吸引力，把一种强制行为变成了“迎合性行为”，把“操控”变成“服务”——这也是一个好产品的逻辑，并且是“强烈的操控”变成“最优质的服务”。

“助推”其实是强迫：它的界面是吸引和刺激，而它的底层是强制，包含着强烈的“成瘾性依赖”。

# “起点的复杂”和“终点的简单”

@ Alan取舍之间

认知是一个从简单到复杂，再回归简单的过程，那么最终回归的简单与最初的简单有什么区别呢？两个阶段看的山水会有什麽不同呢？

类似的问题也有，比如大巧若拙、大智若愚等等，还原成我们在课上讲的话就是“界面语言和后台语言的差别”。我们反复强调的“界面语言的简单”，恰恰是要依赖于“后台语言的复杂和精妙”，只有做到“精于心”，才能够“简于形”。

韩愈曾经给一个叫李翱的学生写过一封信，告诉他怎么写文章：

> 将薤至于古之立言者，则无望其速成，无诱于势力，养其根而俟其实，加其膏而希其光，根之茂者其实遂，膏之沃者其光晔。仁义之人，其言谆如也。

韩愈的这段话其实说的是“根和果实之间的关系”：根系要非常发达，果实才能够长得很壮实。果实的“简单”是建立在底层复杂的基础上的。这也有点儿像古人点的油灯，只有加进去的油膏足够多，光才足够亮。

归结成一句话就是“仁义之人，其言谆如也”：一个内心丰富的人，他的表情、语言反而是很平易和谆的，那种表情的不和谆是因为内心的不丰富——这就是“起点的复杂”和“终点的简单”。

无论做产品、做人，还是做企业，我们都要把复杂和困难留给后台，留给自己，而给别人呈现一种简单和平易。
