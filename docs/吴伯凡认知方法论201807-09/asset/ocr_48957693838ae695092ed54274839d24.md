我们上节课提到一个词：恃才傲物。所谓“才”，大致相当于我们所说的“认知”，也就是具有高认知的状态。对有些人来说，认知的提升，或者感觉自己认知提升的时候，往往会傲物——轻视那些没有智力含量的 方法、工具和对象，最终形成一个巨大的障碍。很多怀才不遇的人都自带恃才傲物的特点，这种习惯可能就是他的致命伤。

我们这节课要讲的话题是：认知的提升和工具之间的关系。

# 工具：促进科学的发展

人类认知的进展，也是人类认知工具不断增加的过程。

“=”

“数学”在相当程度上就是一个认知工具。我在一本讲科学史的书上非常吃惊地发现，我们今天觉得特别简单、天经地义的“=”（等号），一直到16世纪才被发明出来。在此之前，至少没有一个大家公认能接受和看懂的符号，来表明两个东西之间是相等的。由于没有等号，很多时候表达起来就会特别费劲和不方便。

“0”

数字“0”也是这样，就这么一个圈，却是人类历史上最伟大的十大发明之一。要理解“0”，我们不妨假设：一把空椅子代表一个位置，0的这个空椅子上没有数字，但这个位置也不能去掉——11和101，差别就是位置的有和无。就是这么一个简单工具的发明，导致了现代自然科学，更导致了今天计算机科学的发展。

大家可以想象一下，如果没有“0”，我们怎么做数学？怎么区别11、101和1001？

“九九乘法表”

欧洲在中世纪的后期出现了大学，你知道当时大学里最难的课程是什么吗？除了亚里士多德那些形而上学很玄的东西以外，最难也最有用的课程就是：九九乘法表。

中国的汉字和拼音文字不一样，是很整齐的一个音节又一个音节，所以，我们有五言诗、七言诗，也能用汉语编出一个听起来像诗一样上口的口诀——九九乘法表。但欧洲没有，所以做乘法对他们是极其费劲的一件事情。

“九九乘法表”这个工具，现在连小学一年级，甚至幼儿园的小朋友都会背，使得一个很复杂的乘法变得非常简单了。

默顿法则

16世纪的时候，英国有一些顶尖的科学家形成了“默顿学派”，他们提出了一个“默顿法则”，看起来有点儿不像人话：物体从静止状态开始持续加速所经过的距离，和以加速物体最高速度一半的速度运动的物体，在相同时间内经过的距离相同——很像绕口令对不对？即使会念，都很难明白讲到底是什么。

即便得出这个法则非常不容易，但怎么跟别人交流？怎么让别人不用费老大 的劲，经过反复思考以后才能明白？后来有人发明了几个符号，其实就包括“=”，默顿法则用这个表达式就很简单了：

```
1/2at²=1/2 (a*t) t。
```

这个表达工具一旦出来，第一，它变得非常简洁；第二，如果出错，就特别容易知道。

而当这个工具没有出现的时候，你出了错都不知道，甚至你连出错的机会都没有，因为没有一个类似于检测的机制在里面。

科学的历史其实是这样：今天一个普通六年级学生懂得的数学知识，都要比14世纪最前沿的科学家还要多；而一个28世纪的儿童脱口而出的东西，也可能是我们今天21世纪科学家弹精竭虑才明白的东西。这里面很重要的一个原因，就是人们发明了相应的工具。

# 思维的发展=思维工具的进化

《思维简史》这本书对我最大的触动是：人类思维的发展、进化的历史，就是思维工具进化的历史。

比如“0”这个符号，我们今天看起来平淡无奇，但它对数学和自然科学发展的贡献，可以说怎么高估都不过分：没有“0”，就没有现代数学，也没有现代自然科学。而“0”不过是一个圈，代表一个数的 位置。

数学再往前推的话，就是几何学，研究的对象是现实世界根本不存在的东西：点-线-面。几何学是非常空灵高远的学科，也是最形象、直观、感性的学科。

做几何题一定要画图形，我们可以把这个图形理解为一种特殊的棋盘，借助它，我们的思维能够在上面进行各种各样的推理和论证——如果没有几何图形，我们的思维就是一个失重状态，没有方向性，充满随意性。

几何学研究的对象是“看不见摸不着”的，但它又必须地要借助于看得见的图形来展开。可以说，几何图形是管理我们思维的一种“筐”办法，避免我们的思维失重到完全没有结果的状态，让思维变得有重量，从而有方向和进展。

几何图形跟我们前面课程里讲到的棋盘、篮球的网、乘法口诀等都有一个共同的特点：将缥缈精神的东西变成一个直观简洁的东西，让我们的思维借助了这种工具运行——这个过程就是“客观化”。

思维事关我们的大脑，是主观的东西；纯粹主观的东西没办法进展；想要思维和认知有进展，就必须“客观化”，我们下节课就来讨论“客观化”的问题。
