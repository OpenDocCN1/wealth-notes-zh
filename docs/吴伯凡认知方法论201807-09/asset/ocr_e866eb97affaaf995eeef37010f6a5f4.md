# 示例：

# 鸳

想起一个故事。有一个极其有名的音乐大师，在授课的第一天，他给自己的新学生一份乐谱。“试试看吧！”他说。乐谱的难度颇高，学生弹得生涩缓慢、错误百出。“还不成熟，回去好好练习！”教授在下课时，如此叮嘱学生。

学生又练习了一个星期，第二周上课时正准备让教授验收，没想到教授又给他了一份难度更高的乐谱：“试试看吧！”上星期课教授也没提。学生再次挣扎于更高难度的技巧挑战。

第三周，更难的乐谱又出现了。这样的情形持续着，学生每次在课堂上都又被一份新的乐谱所困扰，然后把它带回去练习，接着再回到课堂上，重新面临两个难度高的乐谱，却怎么样都追不上进度，一点也没有因为上周练习而有驾轻就熟的感觉，学生感到越来越不安、沮丧和气馁。

这样过了三个月，学生再也忍不住了，他必须向钢琴大师提出这三个月来何以不断折磨自己的质疑。

教授没开口，他抽出最早的那份乐谱，交给学生。“弹奏吧！”他以坚定的目光望着学生。

不可思议的事情发生了，连学生自己都惊讶万分，他居然可以将这首曲子弹奏得如此美妙，如此精湛！教授又让学生试了第二堂课的乐谱，学生依然呈现出超高水准的表现……演奏结束后，学生怔怔地望着老师，说不出话来。“如果，我任由你表现最擅长的部分，可能你还在练习最早的那份乐谱，就不会有现在这样的程度……”钢琴大师缓缓地说。

这个故事用今天吴老师的认知周期的角度来理解，教授所做的就是不断将学生带进一个又一个“飞来横祸”式的场景，觉知自己的漠沙，重回谦卑的状态，不断进入下一个认知周期。

这样的恩师可遇不可求，在没有外力帮助的情况下如何突破自大呢？关键在于自省吧！虽然这很难。套用一句烂俗的话：海之所以可纳百川，是因为它把自己放得最低。

# 获奖留言

# 悠悠然

我在高速公路工作，常会遇到一些使用导航走错路的人。当我疑惑地问他们为什么会误行，或是突然强行变道时，他们会理直气壮地回答，“导航就是这样指的路，我能怎么办”。

这个时候，他们的注意力都集中在一个知识点，就是导航这个工具上。忘了在他们车轮下的是 一条四通八达的公路网络，和随即变化的路况信息。其实，只要稍加考虑，就会发现自己回答的不合理性，直到有人提醒他们，如果是你的导航坏了，或者没有及时更新，你还要跟着它走吗？这才能够跳出自己思维的局限。

这样的情景生活中比比皆是，知识点和知识网络之间，有一种叫做“洞察能力”的连接线。大多数情况下，我们的下意识动作，都是只盯着大脑中的一个知识点存量，缺少“洞察能力”，而忽略了这个知识点所连接的其他信息。

# 建力

我们会不会跌入意向立场，有一个关键的限制因素，那就是一个人权力空间的大小。一个如果大权在握，就很容易对看不顺眼的事情感到愤怒。每个领导多少多少都有大声呵斥下属的经历。但他们却几乎没有这样呵斥过陌生人，其中的区别就在于权力空间的不同。包括父母对孩子的要求也是 一样，因为他们的权力不对等，所以他们不会自觉地将自己的意愿强加在孩子身上。权力能够让我们体验快感，也能充盈我们的头脑，让我们跌入一种认知暗昧。
