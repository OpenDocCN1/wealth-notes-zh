欢迎来到《昊伯凡认知方法论》。这个单元咱们的主题是“认知断舍离”。

第一节课我们从伪科学讲到了接口问题。伪科学是特别容易混淆视听的一类谬误，而且我们说，越是稍微聪明点的人，越可能被伪科学感染，因为这些人在接受各种知识的同时，也可能给病毒、伪科学留下了很多接口。所以说，当我们还不足够聪明的时候，最好去学习金庸小说里思维简单的郭靖，而不是杨康。

第二节课我们讲了奥卡姆剃刀——如无必要，勿增实体，这个理论是因为对抗繁 Chelsea 哲学而提出的，但在认知中也非常有用。要记住，在认知升级前，你要先准备一把剃刀，把认知中没用的概念全部剔除掉。

第三节课我们讲了两种认知类型，刺猬型和狐狸型，结论是这两种并没有优劣之分，当我们在解决问题的时候，都是一个先由简入繁，再由繁入简的过程，所以不要期待一个简洁的、拿来就能用的工具。

第四节课我们讲的是认知中的Cookie。电脑里有一种缓存叫Cookie，它既能给我们提供方便，比如保存用户名和密码，但同时也会给我们造成安全隐患，而认知中也存在这样的东西，既是正资产，又是负资产。认知中的Cookie越多，就越容易被伪科学、伪认知入侵。所以我们一定要小心认知中的Cookie。

以上就是本单元的主要内容。希望这个单元的课程对你有所帮助。

认知升级其实有两个途径，一个是让自己变得更聪明，另一个是让自己变“傻”；一个是让认知升维，另一个是让认知降维；一个是给认知做加法，另一个是给认知做减法。

# 大唐

我听过一期《罗辑思维》节目，讲到人脑其实是分为五层的：

+   最里一层是鱼脑，我们祖先最初开始是生活在水里的；
外面一层是两栖动物脑；
再外面一层是爬行动物脑；
再外面一层是哺乳动物脑；
最后一层是人脑，也就是大脑皮层。

我们的逻辑思考和自我意识就是来自大脑皮层，但是这一层的大脑是最“年轻”的。而其他大脑是“长老”级别的了，而且是潜意识的。我想Cookie就是隐藏在这些潜意识的大脑里的，通过启动Cookie来调动潜意识的大脑占据大脑的领导地位，乌合之众的原理就是这样。

所以把自己“客体化”很重要，这样是让大脑皮层做主角，不让潜意识大脑有可乘之机，这样能更清晰地看清自己。

# 大胃

这种感受让我想起当初学车考驾照的过程。一开始因为对驾车和路面情况不了解，心里很紧张，脑子里充满各种想法，每次学车后感觉很疲惫，因为这个时候认知是在做加法，增加新的认知是一个痛苦的过程。后来拿到驾照，开车半年后，这种感觉慢慢消失了，因为脑子里做了减法，把一些不必要的担心逐渐去掉，剩下的就是最基本的操作规范，只要遵循各行其道的原则，慢慢地，驾车就变成了一种很自然的与体感结合的操作。

# 其他精彩留言

# 头发末梢的遗憾

真正决定眼界和格局的，是认知工具，确切地说是辅助性工具，而不是替代性工具。在此，我想到突破认知的五个工具。

+   1. 逻辑三怯。王东岳老师总结的：自怯，他怯，续怯。
2. 可证伪性。假设粗糙，假设错误。
3. 榫橼化检验。比如通过清单去整理验证一个决策是否正确，可以调用通用决策原则、专用决策原则、高手判断、短期和长期价值检验等等。
4. 反共识。放弃第一想法，跟随高手学习思考和判断。
5. 我错了。只有先认定自己是错的，才可能接受新的不同意见。
