# 本单元总结

+   1. 第一节课

我们提出了一个思维模型——三位一体的思维模型。通过这个模型我想向你传达的是：让我们眼花缭乱的现象背后总有相当简单的要素在起作用，而且很可能这些要素最后只是三个要素。我们的认知也一样。

+   2. 第二节课

认知包含哪三个要素呢？第二节课——认知三原色，我们就揭示了这三个要素，分别是：理智、欲望和恐惧，改变认知其实就是改变这三原色在认知中的配比。

+   3. 第三节课

那么这三个要素之间是什么关系，是什么决定了哪个要素掌控我们的认知呢？第三节课我们就讲了这个问题——认知的董事会里没有固定的董事长，此刻谁掌权，主要取决于场景。

+   4. 第四节课

我希望你能通过这个单元意识到：你的认知不是你的认知，而是几个要素在做一种类似三体游戏的行为，你以为的不一定是你以为的，你现在以为的也不一定是接下来你以为的。当你有这种意识的时候，面对自己的认知就会有一个客观的判断，进而控制自己认知的董事会成员。

# 获奖留言

# 紫水晶

认知三原色=认知判断+欲望+恐惧。细细一想，还真是这么回事儿。我们对同一个人的认知判断和所处的场景有关。场景不同，判断不同，因为这三者的配比不同。

# 朱超文

有些明白之前吴老师讲的“助推”和“Cookie”的意思了，在某种程度上是从内部来改变我们的认知董事会的结构。老师讲的内容我们在生活大都经历过，说服别人的过程中一味讲道理，没有观测到别人真正的需求是什么，别人的欲望和恐惧是什么。反而我常被自己内心的恐惧牵引而不自知。不过要去真正地观察他人需要刻意的练习，需要从自我视角切换到他人视角也很不容易。在很多优秀的人身上，我都看到过这种他人视角。这节课又让我深刻地感受到了自己的无知，自己需要成长和进步的地方：他人视角，多观察他人的需求，他理想中的自我，他的人生目标，他的恐惧，他的边界，他的认知董事会结构。
