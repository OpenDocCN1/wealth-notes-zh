# 认知阈尾 | 本单元十大精彩留言

第二模块
认知治理与心智管理
认知阈尾

欢迎来到《吴伯凡·认知方法论》。这个单元咱们的主题是“认知阈尾”。

第一节课我们讲了“认知阈尾”这个概念，我们说，有些行为、认知在一开始是有明确目的的，而且是非常理性的，但是在经过长期重复形成了一种“自动化”之后，它就有可能凌驾于理性之上，成为一种近乎本能的习惯，这些习惯在有些时候是无意义的，甚至是有害的，也就是我们所说的认知阈尾。

第二节课我跟大家强调了一个观念，就是：优化认知的第一步，也可能是最后一步，就是“切除认知阈尾”，而切除认知阈尾最重要的一步，就是意识到认知阈尾的存在。因为认知阈尾通常是在你完全不自知的情况下给你制造麻烦，比如贪吃、口头禅等等，了解了它们的形成过程和原理，或许有助于你意识到它的存在。

第三节课和第四节课，我们分别介绍了一个明显的认知阈尾。一个是迷信，一个是对等级的迷恋。

学完这个单元的课程你就已经知道了，迷信的根源在于贪婪和懒惰，因为这两种心理的存在，我们才会去迷信那些不应该相信的东西。当你追求捷径的时候，其实就是贪婪和懒惰在作怪。

而对于等级的迷恋，是人类在进化过程中被写进基因里的东西，所以才会有很多争吵、语欲胜人症的存在，这些问题的本质都是对等级的追求。
