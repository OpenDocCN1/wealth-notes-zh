# @ 多多和空空的哲学

大妈买菜和买股票的例子可以看到，“认知阈尾”是把适用于A场景的认知，不自觉照搬抄袭到B场景，或者是扼杀了B认知。当我们身处B场景时，要警惕A认知的袭扰。那么有一个疑问：在B场景下，A认知确实是一种“认知阈尾”，而在A场景下，A认知仍然适用，我们仍需要切除A认知吗？

这几位同学的问题虽然表面不一样，但实际是相通的。

# 1. 遗产的重负

我先讲一个概念：遗产的重负。

这是很多管理学家和商业评论家在评价一个公司的时候特别爱用的概念，它指的是：一个公司积累起来的巨大资产，很可能是一个巨大的重负。

# 2. 隐身的“高利贷”

查尔斯·汉迪（Charles Handy）说过：企业和个人应该时刻意识到，我们现在是一个悖论的时代，两种很矛盾的东西永远交织在一起，当你想去掉一个东西的时候，另外一个东西也去掉了；你想拥有一个东西的时候，另外一个也就潜伏着进来 了。

# 3. 切除“认知阈尾”：不可能的使命
