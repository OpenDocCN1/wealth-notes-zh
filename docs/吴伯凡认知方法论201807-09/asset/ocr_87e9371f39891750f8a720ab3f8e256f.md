# 从“见山不是山”到“见山还是山”

首先问大家一个问题：我在这里给你打电话，你在一万公里之外就能听到我的声音，这个过程是如何实现的？

显然，这和你坐在我对面，听到我跟你说话不是一码事。

我在这里跟你说话，说话的过程是发出声波的过程：声波借助于空气传到你的耳鼓，通过耳朵里的一套复杂机制，传输到你大脑，使你最终获得了一些意义。而实际上，这个声音是不存在的，它只是我的声波借助一些介质和机制，最后生成的意义结果。

如果我借助于电话跟你说话，同样也存在着声波转化，但有一个过程是面对面说话没有的：

我发出的声波被编码，形成数据包→数据包借助通讯网络在整个系统里传递→通过基站→通过手机→你通过你的手机听到我的声音。

简化一下这个过程就是：声音被编码后又被解码，还原成声音。

# “消除技术”本身就是一种技术

我们现在有些很糟糕的产品，只有前面的两个阶段，第三个阶段可能也有，但是很不完全，这就导致显现在你面前的这个产品，不是在满足你的需求，而是让你在跟技术纠缠。

# “半吊子产品”来自于“半吊子认知”

# 总结

+   1. 将直接的需求上升为间接的认知和技术，是一个必不可少的阶段，但比这更重要的是：如何将间接的、非直观的复杂技术和算法，还原成直观需求，变成一个友好的、平易近人的界面，这需要更加复杂的，然后还是非直观的算法还原为直观友好界面，这需要更加复杂的技术的使命是“消除技术感和认知感”；
2. 最高的认知不是为了“展示你的认知”，而恰恰是“将这种认知最大化隐藏”，直接显现为一个非常平易、有亲和力的日常友好化状态；
3. 这既是做产品的逻辑，也是做人的逻辑。
