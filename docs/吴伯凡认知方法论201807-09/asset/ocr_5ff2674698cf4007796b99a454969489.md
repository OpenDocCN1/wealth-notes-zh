# 1. “父母都是老小孩”的立场转换

我的一个朋友讲过一个很有代表性的事情：他爸爸要去旅游，第二天就出发，前一天晚上跟他说，“我要带狗一块儿去”。大家知道，带狗坐飞机的手续是非常麻烦的，何况时间还这么紧张，他就有点儿抓狂。但在时候，他突然想到了 一句话——“父母就是老小孩”，之后他心里一下就平静了。该怎么就怎么办呗，最后也 很顺利地把手续办完了。

这个朋友之所以开始会抓狂，是因为他自动选择了意向立场，觉得他爸爸“应该被别人着想”等等。

但是，“父母就是老小孩”这句话，让他想到自己的爸爸其实也就是一个上了年纪的小孩，有很多儿童甚至幼童的特点，把他归到“小孩类”的时候，他自己的立场就从意向立场切换到了物理立场。

一旦立场改变，被意向立场困住的心智能量就能发挥作用了，不再做没有结果的挣扎和纠结了。

# 2. “如何摆脱渣男”的意向立场

很多女生都会问：摆脱一个渣男怎么那么难？

通过我们上节课的内容，这些女生可能就会清晰一些。一直以来，她们的认知被意向立场所扣留，没法对世界和他人进行“可控和不可控” 的二分——也就是“可控”的话，那就不改变他，“不可控”的话就适应和接受他。

一个生气、愤怒的人，往往是没有进行二分的人，当他对某个东西极其不满，甚至非常愤怒的时候，他还抱有对方“应该怎么样”的期望，并没有把对方当成是一个物种来看。

解决这个问题的一个很简单的方法就是：

+   第一步，分析他是一个什么样的物种，有哪些性状，这个性状在短时间内（至少一辈子）是没法改变的——这些是不可控的。
第二步，如果不可控，就只有一个选择：接受或者适应他。如果你就是没办法接受，今天、明天、后天......今后每一天都没办法接受，那就摆脱他。
第三步，如果他的这种状态能够改变，是可控的，你就去改变它，从意向立场转到设计立场。就像钟表出了问题，你可以凭你的力量把它修好——接下来，你就可以和他过下去。

这本来是一个非常简单的选择，但由于很多女生没办法从意向立场转到物理立场和设计立场，所以就一直纠结和焦虑，一会儿觉得是可以解决的，一会儿又觉得是不可改变的，但即使你觉得他不可改变的时候，心里还是残存着期待，想去改变他。这样的结果就是：始终没办法进入物理状态和设计状态，认知已经失调了。

# 3. 《头脑特工队》：意向立场妨碍认知

当认知失调的时候，另外的东西就会出场——情绪。我们以前讲过，情绪好像和认知没什么关系，但其实关系极其密切：

认知是在情绪底下做事的。就像如果要判断你能在一个公司做多大的事儿，就必须知道所在的这个能量场和权力体系。用休谟的话说，“理智永远是情绪的奴隶”。一旦情绪出场，理智要不就是退场，要不就做了情绪的狗腿子。

尤瓦尔在《今日简史》里特意提到了电影《头脑特工队》，说“这部电影非常深刻”。它的英文叫《Inside Out》——把里面的东西表现出来。

![](bbox=[0.12, 0.0029, 0.92, 0.00375])

《头脑特工队》这部电影的主人公是一个叫“莱莉”的小姑娘，而实际上，在主人公的大脑后台（大脑控制中心）运行的是五个小孩：乐乐——管高兴；怒怒——管生气；忧忧——管悲伤；厌厌——管厌恶；怕怕——管恐惧。

莱莉只是一个界面，真正后台运行的代码是这五个小孩，她每一刻的变化都是这五个小孩轮番在操纵台上按按钮实现的。她现在是什么状态，取决于这个时候按按钮的小孩是谁。

莱莉的性格，她此刻的状态其实是一个动态调色板，是快乐、恐惧、忧伤、厌恶、愤怒在这个画板上调出来的整体颜色，但是某一时刻，可能会出现缺位的状况。
