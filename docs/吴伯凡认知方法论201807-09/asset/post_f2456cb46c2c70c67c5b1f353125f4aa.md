# 父子关系：个人与权威的关系

最近在听李宗盛的新歌《新写的旧歌》，这首歌的主题是一个很陈旧的话题：父子关系——可以说，“父子关系”是男人一辈子要面对的问题。

我身边一些四五十岁的朋友，有的甚至已经年过半百，但他们和自己父亲之间还处于“似乎永远不能和解的状态”。一个男孩跟父亲的关系，从和谐相处到发生冲突，甚至势不两立——这种“势不两立”可能会延续一辈子。

“父子关系”是一种很世俗日常的关系，但它其实也是一个深刻的隐喻：是个人和超越个人之上的权威之间的关系。

西方基督教里常常把人和神的关系直接表述为子与父的关系——“上帝”被称为“天上的父”。这里包含着和谐相处以及叛逆：人被上帝责罚之后，又试图回到上帝身边等……等等。只要回想一下自己跟父亲相处的……就容易明白了。

德国哲学家黑格尔把这种关系直接描述为一种“精神成长的历史进程”，用今天的话说就是“认知不断迭代升级的过程”。

# 失望：打破“伊甸园式”的和谐

多年前我写过一篇叫做《直面失望》的文章，里面描述的就是“每一个做父亲的人，都应该有一种直面孩子对自己失望的心态”。

乔布斯曾经讲过他对自己父亲失望的故事：乔布斯小时候的所有问题，他的父亲都能解决。直到有一天，他从外面拿回来一个坏了的电动玩具，他认为万能的父亲一定会帮他修好的，但是他父亲看了以后，完全不懂这是一个什么东西——心灵手巧的父亲在这一小小的玩具面前显得非常无能的时候，乔布斯一下子就对父亲失望了。

事实上，每个男孩都会经历过这种阶段。我小时候也会对父亲的失望，我也体会过我儿子对我的失望。

# 自大狂：认知周期的破产

在哲学上，这是一种“人的自我意识的觉醒”，它不是通过“被告知”来认知世界的，而是对原来全知全能的权威产生了失望以后，觉得以前都被骗了，没有什么是靠得住的——父亲靠不住，权威也靠不住——必须要用自己的脑袋来想问题了。

当一个男孩开始“自我意识觉醒”，就会发生一种戏剧性的逆转，黑格尔称它为“自大狂”：只要父亲说的话，我就一定认为不是那样，甚至是正好相反的。哪怕在某一件具体的事情上他说的是对的，我也已经形成了一种习惯模式，有了一种自动追加的算法——父亲的每一句话都加一个否定词，他只要开口就是错的。

# 一种“反脆弱机制”

上节课我们讲到了“认知周期”：人生第一个认知周期结束后，有些人会陷入到一种“自大狂”中而不能自拔，没办法开启下一个认知周期。

一般人在十三四岁这个阶段，会对父辈的权威产生一种真真切切的失望，几乎会全盘否定权威和父辈的价值，同时，又会反过来将自身的认知绝对化——他人说的都是错的，自己认为的都是对的——这样一种“你说东我必然说西”的叛逆，或着“自大狂”的状态是一种危险的状态。

但我们很少有人意识到这种危险，而是沉浸在虚幻的自大感、成就感中，设置一系列认知和情绪的防御工事，不断向自己证明自己的正确性以及别人的错误性。

处于“自大狂”状态的人，在不断感受到外界的冲击挑战的时候，会产生一种思维机制——“习惯性防御”和“熟练的无能”。面对一个真实复杂事件，你的认知明显是拙劣为止，但你会用一套自带的意识形态告诉自己：

这个事件是被权威、被父母控制的，是在跟我作对的不公平事件。

我之所以遭遇种种挫败，是因为他们时时刻刻都是为难我。

# 认知周期3 | 逃离致命“中转站”

认知周期3 | 逃离致命“中转站” ↓

这是我们第一模块第十一单元的第三节课。这个单元的主题是：认知周期。

# 认知的“启蒙”过程

我们的认知是自带缺省且不自知的，换句话说就是“我们看到和感知到什么，就以为那是什么，就像在集体食堂吃饭——给什么就吃什么”。

人的认知过程是逐渐从这种默认缺省状态中醒过来的过程。我们在孩子时期时，要经历一个启蒙的过程。所谓“蒙”就是在黑蒙蒙的黑暗当中什么都看不清，都没有开始的状态。“启蒙”是打开一扇门让光进来，让黑蒙蒙的状态结束的过程。

我们的认知从来不是一蹴而就的，它有一个个周期。我们开始一个“启蒙”过程的同时，也开始了一个不自觉被蒙骗的过程——我们的“启蒙老师”常常也是“蒙”我们的老师，尽管他自己不知道，我们也不知道。

在人生的启蒙时代，我们在接触很多知识的同时，也夹带着诸多谬误。比如问你自己是从哪里来的，父母会告诉你“从垃圾堆里捡来的”，或者是“从田沟里捡来的”等等，但这不要紧，经过一个周期，我们会逐渐清除认知当中所夹带的这种谬误。

一个“认知周期”就是从不加批判、满怀敬畏地接受一种东西开始，到逐渐怀疑已有认知当中的种种谬误——从这个意义上说，当我们意识到我们认知当中有，甚至充满着谬误的时候，就意味着一个认知周期已经结束了。

与此同时，当你意识到这种谬误的时候，我们要说一句“欢迎来到一个充满怀疑的世界”——这证明你的一个认知周期已经完成了，或者说，你有可能进入下一个认知周期。

认识到“认知谬误”并不意味着你的认知就成熟了，而只意味着“你又开始下一个认知了”。

洛克菲勒（John Davison Rockefeller）和他儿子之间有这么一个故事：洛克菲勒喜欢把自己的孩子往上颠，然后接住，再往上颠，再接住……突然有一次，他一下子把手散开，小孩一下子就摔在地毯上。当然，摔得也不是那么严重，但小孩很疼。洛克菲勒就对儿子说：我就是想告诉你，你要想在这世界上活着，必须意识到老爹也是不值得相信的。

洛克菲勒的这个故事告诉我们：人越早开始怀疑，就越可能进入下一个认知周期。

当然，像洛克菲勒这样的人不是太多，有一些人一辈子都没完成一个认知周期，而是一直在接受既定灌输给他的东西——这种状态是很不幸的。当我们开始怀疑的时候，应该说是一件很幸运的事情。

# 怀疑：认知的中转站

上个世纪八十年代，流行过一首让很多人都很有共鸣的诗《我不相信》：告诉你吧，世界，我不相信。

正如我们在前两节课里讲的：每个人都会经历由相信到不相信的“怀疑期”或者“叛逆期”。“叛逆期”是一种认知的象征：在我们十二三岁、十三四岁的时候，越来越多的事情开始挑战并颠覆我们的认知，原有的权威开始动摇甚至坍塌，原有的认知框架和思想范式开始土崩瓦解，我们人生的第一个认知周期往往是在我们“叛逆期”的时候完成的。

怀疑也好，叛逆也好，都不是一个目的，而只是一个中转站。

在电影《黑客帝国》里有这样一个情节：尼奥突然失踪了，他的同伴们都找不到他了。后来他们才知道，尼奥被困在一个通往矩阵世界的中转站——那是一个小火车站，它既不是真实的世界，也不是一个虚幻的世界。这个时候，尼奥必须搭上一辆火车通过虚幻世界，才可能回到真实世界。他的同伴崔妮蒂和莫斐斯就开始想办法营救他，否则他就可能永远滞留在那个中转站。

怀疑、叛逆就是一个我们认知的中转站，而且很可能是一个“致命的中转站”，一个作为“超级陷阱”的中转站。

怀疑是可贵的，但怀疑是手段，不是目的。套用一句哲学名言，“信而不疑则盲，疑而不信则空”——信一个东西，而没有怀疑的话，就是盲目的；怀疑中没有相信的成分，就是一种空洞的怀疑。

认知是怀疑和相信的一个编织体，就像我们编草席的时候，用纵向和横向的草条能编织出一个草席出来——任何一个认知里都包含着相信和怀疑，只有怀疑或者只有相信，都不构成一个认知。

这让我们马上想到著名的“猜想与反驳”理论：怀疑是认知周期的终点，相信是下一个认知周期的起点。只有怀疑，人们就会陷于怀疑的泥潭无法自拔，滞留在一个自我营造的舒适区里苟且偷安，成为一种“浅人、妄人和狂人”三位一体、未老先衰的人，永远开始不了下一个认知周期。

# 逃离舒适区，进入新周期

我有一个中学同学脑子很好使，但他有个问题：在做数学题、物理题、化学题的时候，他有一个习惯——遇到不会做的题，他马上的反应是“这题出错了”。

有几次，老师真的把题出错了，他还真说对了一——用我们现在的话说“那是个伪命题”，当然，伪命题就不值得做了。由于他这样的经历，时间久了，就形成了一种习惯——遇到不会的题，就是“题错了”。

后来我知道，这个同学使用的方法在哲学上的说法是：解决问题的最好办法是否定问题。有时候，当我们陷入一种情景的时候，很容易通过否定问题来解决问题——问题都用解决了。

而之所以说这是一种“惰性”，是因为它隐藏着一种“不想受痛苦，不想努力，期望轻松解决问题”的欲望——这种状态是一种舒适区。

我们讲过：只要是舒适区，就是处于非认知状态。如果你停留在这种永远在质疑、怀疑、挑剔的状态，就会享受到一种特殊的快感和舒适感——这种状态很有诱惑力，或者说，它能把人套牢在这样一种状态里，最终形成一种很可怕的局面——让自己成为一只懵懂的小鸟，从懵懂的青年一直活到懵懂的老年，心智上一直是一个可怜的小孩子。

为什么这么说呢？因为你的认知周期已经结束了，没办法开始一个新的认知周期，说白了，你只完成了一次认知周期——我们要获得真正的认知，就像我们经营企业一样，需要把资产不断周转，不断获得利润，加快资金的循环，才能使企业快速成长。

人最重要的资产就是我们的认知：我们需要不断成长，不让自己滞留在青春期、叛逆期。

吴伯凡

我在和世界、他人打交道的时候，是相信的成分多，还是怀疑的成分多？
我是否已然走出了“叛逆期”？
我的“认知周期”的数量有多少？
我的心智是否一直滞留在十三四岁的状态？

# 认知周期4 | 从怀疑到相信

# 避免不自知地陷入 “中转站”

上节课我们讲到了 “前不着村，后不着店” 的可怕 “中转站”，那是一种 “怀疑” 的状态，它能够给我们某种舒适感，而这种傲群雄、笑傲江湖的虚构快感，让我们可能滞留在 “中转站”，始终没办法开启下一个认知周期。

那么，如何避免不自知地陷入和被困在这个 “中转站” 呢？

# 1. “醒” 的矛盾性

韩少功先生的《马桥词典》里有一个词条，让我印象特别深刻——“醒”。这个词条以屈原为例，因为屈原就是一个 “世人皆醉我独醒” 的典型。

但是在南方（湖南湖北），有一个词从屈原所处的年代一直流传到现在，就是 “醒气”。这个人很 “醒气”，意思就是这个人较真、死板、爱反驳别人、谋求某种认知优势、追求需求性胜利，易暴、易怒、轻举妄动、不听人劝。

# 2. “醒” 的成瘾性

“醒” 是有 “成瘾性” 的：它越远离建设性，就越追求 “代偿性” 的满足，自己与真正的优势和胜利就会越远。当一个人处在这样的弱势中无法自拔，就会对照永远的成就感亦不疲。

# 3. 怀疑自己的怀疑 & 相信自己的相信

开启下一个 “认知周期” 的方法很简单：逃离 “舒适区”，让自己的心智恢复到一种 “对于各种可能性都能敞开” 的状态，或者 “延迟和抑制自己的否定性判断，逐渐放弃简单粗暴的反应，让自己保持一种对于他人和世界的拥抱状态”。

> “拥抱” 就是接纳和相信——尽管你还是有怀疑的，但是你要保持这种接纳和相信；你可以怀疑一切，但是这一切必须包含你的怀疑本身——怀疑你自己的怀疑。

# 从怀疑到相信

有一个父亲跟孩子之间的故事：一个星期天，父亲在家加班做一个很重要的文件，这时候呢，小孩就不停地在客厅里又吵又闹，父亲就出去让小孩 “安静点儿，不要影响大人工作”。但过了一会儿，小孩又开始闹了。

这个懂一点儿心理学和哲学的父亲就提醒自己，“我现在要做的不去教训孩子，而是要教育孩子。教育最好的办法就是影响，我要用一种委婉曲折的方法让孩子理解，最好呢，是让他自己得出结论”。于是，父亲就把儿子叫过来，说：

+   父亲：你还记得你过生日的时侯，爸爸送你的那个漂亮的玩具小汽车吗？
小孩：我记得啊！我生日第二天早上醒来，就看见这个玩具车在我的枕头边上，我特别高兴！
父亲：那你知道爸为什么要把它放在你的枕头边上吗？
小孩：我不知道……

化。

这既是指父子关系，也同样适用于我们和世界及他人的关系：保持开放，保持相信，同时要存有怀疑。

吴伯凡

# 认知周期 | 本单元十大精彩留言

认知周期 | 本单元十大精彩...

欢迎来到《吴伯凡·认知方法论》。这个单元咱们的主题是“认知周期”。

第一节课我们提出了“认知周期”这个概念，我们说，子女与父母的关系很可能就是每个人都会经历的第一个认知周期——从把父母视为权威，到失望，再到建立自己的权威，这就是一个认知周期。而有些人呢，在经历了这个周期之后，他的认知周期就停滞了，这样就形成了“自大狂”的现象。

第二节课我们又提出了两个概念，一个叫认知留级，一个叫认知曲线。所谓认知留级说的就是第一节课的“自大狂”的状态，他的认知在经历第一个周期之后就没有再迭代了，而这种留级就表现在认知曲线的平缓，甚至是下滑上。我们知道小孩子的认知曲线是上升最陡峭的，但成年以后，如果我们不主动提升自己的认知，可能就会进入到认知曲线平缓，或者说认知留级的状态中。

第三节课我们说，怀疑在某种程度上是好的，但如果你一味地怀疑，对周围的任何事物都充满怀疑，进入一种愤青的状态，那可能就陷入到了致命的“中转站”。之所以说怀疑是中转站，是因为怀疑并不意味着你的认知成熟了，而是你要开始下一个认知了，如果你一直停留在怀疑的阶段，就永远无法开始新的认知周期。

最后一节课的内容，也是我这个单元最想跟你说的，如何从怀疑的中转站走出来，办法就是一句话：怀疑你的怀疑，相信你的相信。只要你愿意“怀疑自己的怀疑”就会发现自己的可疑之处和不可靠之处；只要你愿意相信他人和世界，一定会找到这个世界和他人可以相信的地方。这就是与世界和他人相处的终极之道。

好，这就是咱们这个单元讲的主要内容。希望这个单元的课程让你有所收获。

# 获奖留言

很多古今中外的小说，男主角都有一个特点：“无父无君”。无父无君本来在中国古代是一个贬义词，形容一个人私扒了伦常。但很多中西方英雄的出世，都有“无父无君”的背景。无论是“杀父娶母”的俄狄浦斯，还是从小父母双亡的蝙蝠侠，“父”和“君”存在的意义已经超过了一个关系、一个角色本身，更多的是影响主角独立性格产生的原因。

金庸武侠也便是一个“无父无君”的典型。主角基本上都是早年丧父，如萧峰、令狐冲、郭靖，要不就是不知道自己亲生父亲是谁，如虚竹、段誉、小宝。这时候会有做一个叫做“师父”或者“义父”的人重建他们的原始“和谐”，但是他们却不能完全取代原始父亲那种“坚固”的初始价值观的位置，所以主角才可以充分地野蛮生长，而又不至于完全跑偏。

所以我想说，作为一名真正的父亲，应该适当地像这些“假父亲”一样，适当树立孩子的价值观而不要过度强制和权威；而作为一个孩子，也应适当把父亲（原始和谐和权威）和自己片面偏激的自我（第二周期的自大狂）维持一个平衡，这样才能更有利于进入第三个周期，我猜这应该是二者有机结合后的一个圆融的时期。

> 来自：认知周期1 | 父子关系与“自大狂”

我可以怀疑一千次，但必须有一千零一次相信。一个以怀疑为终点的人，必然是一个丧失理智的人。

> 来自：认知周期3 | 逃离致命“中转站”

七岁看大，一个人在七岁的时候，最能看出这个人的将来。今天老师帮我了解了这一现象，7岁时，是陡峭的学习曲线的峰值，这时如果你保持一个敬畏和谦卑的状态，对世界充满好奇，对知识充满渴望，对理想坚信不疑，那你的学习曲线一定是缓慢地变平缓，你将来的成就一定不差。

相反，如果此时你就进入了认知留级生的状态，你的未来一定是混然众人。人生七年，七年一晃眼就过去了，现在的你是由上七年的自己决定的，这已无法改变，但你可以决定下一个七年的自己。既然回不到最好的7岁了，不如活在当下，珍惜眼前，尽量缓解学习曲线的平缓度，至少不让它倒退。
