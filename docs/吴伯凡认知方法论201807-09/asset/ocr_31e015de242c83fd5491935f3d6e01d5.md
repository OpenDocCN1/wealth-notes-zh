# 保持开放：避免“伪科学”病毒

# @ 长青葳宁

关闭病毒入口的同时，是否同时丢失了开放交流与学习升级的机会？

# @ 及时雨

我理解的“伪科学” 是基于某种目的故意制造混淆，但什么属于科学素养还是不太清楚。有科学素养就是指有开源状态吗？被伪科学侵蚀是指有科学素养，但一味开源而不去思辨吗？

大家可能都注意到，对“伪科学”缺乏免疫力的人有一个优点——虚怀若谷，特别容易相信一个东西，而且平时他们会比较 nice。

那么为什么他们会对伪科学和伪科学思维没有免疫力呢？因为他们缺乏真正的科学素养。

什么是真正的科学素养呢？我们通常说科学有两个工具，数理工具和实验工具，或者抽象一点儿地说，一个与逻辑有关，一个与证据有关。

我们提出的一个命题在没有经过逻辑和实验验证之前，就是一个猜想，而你首先要看这个命题所陈述的事情是否符合数理和逻辑的规则。

比如有个朋友在朋友圈发了这么一句话：

> 洗车是祈雨的最有效手段。

我知道他发这句话的时候，一定是刚洗了车就下雨了，而且他之所以这样说，肯定不是因为这一次洗了车就下雨，而是可能经历过两次、三次、五次……这样的事情。“一洗车就下雨”是一个典型的伪科学命题。

但为什么会得出这么一个结论，而且还坚信呢？是因为逻辑上和证据上都有漏洞。我们可以问他“这一年你洗过多少次车”，他一定说不出来，因为他的证据本身就有问题，等你再问他“你洗了车以后不下雨的次数是多少呢”，他就更回答不上来了。

而出现这种情况，是因为洗了车不下雨，你是毫无感觉的；洗完车就下雨，你就会很痛苦，会在记忆中留下不可磨灭的印象，等又出现第二次这种情况时，你就会强化这个判断，第三次、第四次出现的时候，你就坚信不疑了。但同样的，完全有可能10次、20次洗了车不下雨，这样的记忆是被我们自动忽略的——无论在逻辑还是证据上，这些都是站不住脚的。

“伪科学” 不一定是以科学的形态写本书，写一篇文章，它是一种思维方式，是你浑然不自知地违反逻辑和证据，并且在证据不足的情况下得出结论。

我们讲过“奥卡姆的剃刀”，其实还有一个概念——“奥卡姆的扫帚”。就是当你要得出一个结论的时候，你会把对你有利的证据显现出来，而把对你不利的证据用一把扫帚悄悄扫到角落里。我们有时是有意识地用这把扫帚，但更多时候，我们都是无意识地用这把扫帚，把不利证据都给扫到角落里去了。

大家可能还体会过一种现象，比如你突然想到好久没联系的某人，你也不知道为什么会想到这个人，然后早上想的，下午他就给你打电话了——你觉得很神奇，马上得出一个结论：心灵感应！

如果你有反省的愿望和能力的话，我首先要问你，“你一天出现过多少个念头？想到过多少相干不相干的新朋老友？”

大家应该都听说过，我们一天有6万个念头，想到的相干不相干的人名数量每天可能超过100个。所以，如果你忽然想到的这个人打来电话，你根本不知道你想过他，而当他打了电话，你就会突然记起来早晨想过他，并且得出结论，“人与人之间是有心灵感应的”。

这也是一种“伪科学”思维，所以，既想保持开放性，又要避免大脑受到各种伪科学病毒的入侵，没有别的办法，就是“保持开放”，同时要知道世界上town笔。利用逻辑学、数学，包括统计学对命题进行验证的同时，你要想到支撑你的论点的论据是否充分和足够。

# 避免被“伪科学”所骗的基本防火墙

# @ 勇春君-机器人机械:

现在有很多伪科学，它的论证过程和逻辑毫无破绽，但是在使用证据的时候，只使用那些支持它结论的数据。

这句话本身逻辑上就是不成立的：“论证过程和逻辑毫无破绽”，但只是“使用了支持它论据的数据”。

我们的思维时刻处在非逻辑、非理性思维的汪洋大海之中，稍有不慎就会被感染。想要避免被“伪科学”所骗，没有立竿见影的办法，但是有一些基本防火墙。

你可能在电视上看过不少数字魔术，还有所谓“读心术”的魔术，比如你现在想一个数字，然后把它写下来，我就能知道你想的是哪个数字。或者你现在想一首歌，我就知道你想的是哪首歌。这些魔术最后的结果都让我们特别吃惊，感叹“真是料事如神”。

但其实早有人揭露过这种魔术的流程，比如你进入一个大剧院之前，会在几个主要交通要道入口，看到处心积虑设计的各种内容的广告牌，听到播放的音乐，等你在剧院坐下的时候，表面上你突然想到一首歌，是一个随机行为，实际上在你进入剧院之前，已经被植入了Cookie。

同样，在日常生活中，有时候你会发现自己莫名其妙哼同一首歌，其实，是你旁边那个人，或者你经过某个地方听到了这首歌，只不过当时你不知道你听到了，然后你就一边没完没了地哼那首歌，一边奇怪这是怎么回事。

还有一种以科学手段做的骗术，是一种特殊的广告，利用了人视觉暂留的原理。我们看电影，其实是照片在非常流畅地播放，每张照片出现的时候，都有一个视觉残留——在极短的时间内，下一张照片出现了，它们衔接起来没有任何漏洞。

平时我们看广告的时候，是知道自己在看广告的，但“特殊”的广告，是以极短的时间闪现在你正在看的一部电影或一个视频中间，过一段时间再闪一下，这个闪的过程时间非常短，以至于你自己根本意识不到它闪过，或者你感受到了而不自知。

广告的一个法则 是，当你真正注意到一个东西之前，这个广告一定会在你面前出现过6次，你要到第7次才能真正注意它。而前6次你其实注意到了，但你没有留意，不知道自己已经注意到了。这个骗术广告，就让你在自己还不知道的情况下，多次看到这个广告。

所以我们感觉很多的路牌广告都被我们自动忽略了，其实并没有。在这些广告牌反复出现，你看见它超过6次以后，你在第七次一下子就注意到了。如果不出现前面的6次，你对它还是会自动忽略的，所以实际上，它玩的是一个在你头脑当中快速植入Cookie的游戏。

通过这个游戏流程，它悄悄在你头脑当中设置了一个无障碍通道，一下子闯进你的大脑当中了。我们大脑被感染各种病毒的可能性并不比电脑少，只不过入侵大脑的方式更加隐秘和巧妙罢了。
