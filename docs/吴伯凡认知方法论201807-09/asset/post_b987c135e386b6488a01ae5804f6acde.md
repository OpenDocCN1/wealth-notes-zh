## 1. 认知的“上不封顶，下不保底”

@越过大山

提升个人认知如此之难，人类整体的认知进步会有上限吗？

应该说“上不封顶，下不保底”。

大家还记得到我们在前面的课里讲过，不管是蝙蝠的超声波，还是蛇对红外光的感知，认知的本质是一种生存工具。这个场景和挑战不存在了，这个工具就没有了意义，或者说，有外在的工具、技术来代替我们的认知工具的话，我们的认知就自然逐渐退化，甚至消失。

《哈佛商业评论》主编尼古拉斯（Nicholas G.Carr）在《浅薄》（The Shallows: What the Internet Is Doing to Our Brains）这本书里写的就是这个道理：当互联网越来越成为我们的认知工具和手段的时候，我们的认知能力就会自然而然地变得浅变薄。

这既不是一个哲学化的判断，也不是一个情绪化的判断，这是富有实证科学作为支撑的：有人对就两代出租车司机的大脑进行扫描以后发现，他们的大脑有整体性的明显差异，原因很简单，年轻一代的司机越来越多借助于GPS导航，而老司机只能用他们的大脑作为工具。

![](img/274b424b97ce4eb2f1045ee5c4c6fac4_73_1.png)

“上不封顶”是什么意思呢？就是：某些认知能力由于特定场景的出现，可能会进化出新的认知能力。比较极端又浅显的例子就是盲人的触觉、听觉和直觉可能比我们普通人要高得多。

人的认知能力和认知能力的分布，呈现出一种动态的趋势——我们在这个意义上说“上不封顶，下不保底”。

当然，人的认知越来越被机器化，人本身的认知能力就会逐渐下降。但是，借助机器，人机一体化的认知能力会越来越强，也就是说，我们借助大数据几乎可以拥有未卜先知的能力。

## 2. “客观化”的重要性

@小顺意

要想思维和认知有进步，就必须客观化，这是说要把事物具体化，而不是在脑中抽象化的意思吗？

我们大脑中的认知不仅仅是抽象化，往往呈现混乱和模糊的状态。当你把你的想法说出来的时候，你就会意识到你的很多想法其实是模糊、混乱、不成形的。不在客观化的镜子映照之下，你是不知道这一点的。不借助客观化，仅停留在头脑中的认知，由于没有一个支点，它的进展是没有方向的，会呈现“布朗运动”的状态。

所以荀子说，“吾尝终日而思矣，不如须臾之所学也”。培根说，“不要用头脑去思考，要用笔去思考”——他们说的都是客观化对于升级人的思维，提高人的认知的重要性。

最简单的例子就是找你的朋友下一盘盲棋：不借助客观化的棋盘，体验一下你的思维有多模糊、多混乱，甚至是没法进展的。

## 3. 代替性工具导致“认知残化”

@鑫燕

思维工具的进化是为了方便思考的深化，客观化的思维工具节省了大脑的认知资源，利用客观化是否有“认知残化”的可能？

我们有两类工具：

- 代偿性、代替性的工具，比如有了车，我们不用走路，车代替我们走路；
- 辅助性工具，假如你的腿伤了，你可以借助拐杖——拐杖不能代替你行走，只能在你能力不足的情况下辅助你往前走。

“代替性工具”往往会导致我们的“思维残化”，而“辅助性工具”会给我们的认知赋能。

比如你列清单、做几何题把图形画出来、下棋的时候用棋盘，这些都是给你的认知赋能的，它们给你的认知一个支点，撬动你没法撬动的东西。

# 社会性愚蠢

德国思想家朋霍费尔写过一篇很著名的文章——《论虔人》，定义了“社会性愚蠢”：如果你对一类人进行智商测试的话，他们的智商没有太大问题，甚至很高。但是，他们就是“蠢人”，因为他们的思维、表达方式呈现出一种格式化状态。

朋霍费尔说：你面对这样的人，跟他谈话，是永远没办法进行推心置腹的交流的。你接触到的永远是一堆立场和口号——他的思维好像已经被别人作弊了，他说话像是在播放录音——不会针对你的观点、态度和当下的场景作出反应，而是原封不动地将他既成的观点像录音机一样播放出来。这种表达是“打印式”的一一在电脑里设置好打印程序，不断进行打印。

多年前我曾经采访过一个人，我当时几乎要崩溃了，因为这个人的回答跟我的提问没什么关系。后来，我跟另外一个也采访过这个人的人交流，他说，“我去采访他听到的那些话，跟你采访他听到的話是一样的”。

事实上，我们的每个问题都被他编号了一—1号问题播放一个既成的答案；2号问题，再播放一个既成的答案……当你心有不甘再来反问，或者进一步追问的时候，他又开始播放1号问题的答案，也就是那些已经预置好的东西。

这种状态就是朋霍费尔说的“社会性愚蠢”——丧失了思考能力，永远在播放那些既成的口号。我们之所以把这种状态称为“愚蠢”，是因为他的思维已经脱离了认知，被彻底地格式化了。

完整的认知过程是获取、提炼、整理数据，将数据变成信息、知识，然后上升到智能状态，作出反应。而社会性愚蠢已经把所有这些过程都省略了，用预置的方式跟世界和他人进行所谓的“对话”。

我们如何判断一个“说话的人”是处于认知状态还是播放状态呢？我们的思想在多大程度上是处于认知状态，又在多大程度上处于播放状态呢？

一个人的思想没有纯粹的认知状态，一定有很多既成的东西播放出来；同时，也没有一个人是完全处于播放状态的，他多少会有一些认知。

不同的配比显示出不同的智能状态。比如对于一个围棋高手来说，他的认知状态是很高，但是下棋的时候，一个真正的 <|start|> 高手不是处于播放状态，而是处于认知状态。

# 播放状态和认知状态的区别

有一个拿破仑和士兵的故事，可以让大家更好地理解播放状态和认知状态的差别。

拿破仑检阅自己的军队时喜欢单独跟某个士兵对话，但一般因为时间紧，他几乎都只问三个简洁刻板的问题：

- 1. 你多大了？
- 2. 你参加我的部队几年了？
- 3. 我的两次大战当中，你参加过哪一次？

拿破仑有一次要来检阅的军队里有一个不太懂法语的士兵，由于事发突然，这个士兵的同伴就告诉他：如果拿破仑问你这三个问题的时候，不管你听不听得懂，你这么回答就对了：

第一个问题，你回答“25（我今年25岁）”；

第二个问题，你回答“3（我参加这支部队3年了）”；

第三个问题，你回答“都有（两次大战都参加过）”。

当然，这三个问题是按照既定的序列设置的答案。

拿破仑检阅的时候果然就问到了这个士兵，但是，他把问题的顺序颠倒了：

拿破仑：你加入我的部队多长时间了？

士兵：25。

拿破仑：25年？（心想）我的部队都没有25年……那你多大了？

士兵：3。

拿破仑（吃惊）：是你疯了还是我疯了？

士兵：都有（两个都疯了）！

这虽然是一个笑话，但很生动地体现了播放状态和认知状态的差别。所谓“播放”就是用既成的、固定的认知对应一个复杂 的、不断变化的世界。

我们都说“终身学习”，现在不妨从另外一个角度对“终身学习”作一个定义：如何避免自己的认知处于播放状态。

你是一年活了365天，还是只活了1天，但重复了365次呢？你是做了100件事情，还是做了一件事情，但把这件事情重复了100次呢？这就是播放或者打印，和认知的差别。

在一个“终身学习”的时代，“如何避免让自己不知不觉处于播放状态”对我们每个人都是一个严峻的问题。

# 洗脑：强行让你的大脑停留在播放状态

我读过一本讲“洗脑术”的书，书很厚，但浓缩起来就是一句话：洗脑不是内容的事情，而是形式的事情。

这句话的意思就是：洗脑不是把你原有的思想全部洗干净，装上一种新思想，而是装入一种新形式，强行让你的大脑停留在播放状态。

跟接受过洗脑术的人对话，你会感觉是在跟录音机对话，或者说，是一个存储量很小的搜索引擎：当你在说话过程当中提到了某个关键词，他立即就启动了头脑中既定的内容，呈现出所谓“相关性”的内容。无论你说什么，他呈现出来的都是那几样东西。

# “无意识播放”的可怕之处

播放状态的可怕之处不在于“播放”，而在于“没有意识”。

年轻人经常抱怨老年人爱唠叨。“唠叨”就是播放状态，是老年人不自知地播放。比如几分钟之前他说了一个事，过了一会儿又跟你说这个事——他不记得他曾经播放过，但播放的内容记得非常清楚。

人衰老的一个标志就是短期记忆特别模糊，甚至忘了一千二净，而长期记忆特别清晰，永远在讲过去的事情，重现既有的、说了100遍的观点——这个状态是衰老，也是认知状态的终止。

当然，不是有年老的人容易陷入到播放状态：如果没有强烈的“终身学习”意识和“认知迭代”的欲望，你也很可能不知不觉让自己的大脑陷入到播放状态。

# VUCA：对事物认知的四种状态

上节课我们讲到：一个围棋高手下棋的时候，是认知状态，而不是播放状态。他的每一盘棋局都不一样，但是，不变的是底层的東西，界面的東西是在不断变化的。针对新的变化，他会一方面调动底层算法，一方面优化底层算法——这就是认知状态。

我们很多时候对事物的认知呈现为一种状态，这种状态借用一个词来描述，就是VUCA，美军培训时候使用的一个概念。

VUCA是一个指挥员在战场上面对的四种状态，或者四种特性：

- 1. Volatility（易变性）：
本义是挥发性——一个东西本来是这个样子，但是很快就变成不是这个样子了；
- 2. Uncertainty（不确定性）：
“易变性”是你能够比较清楚地看见一个状态，虽然它很快不是这个状态了，而“不确定性”是你现在看到的这个东西都是不确定的，始终是一个不确定的状态；
- 3. Complexity（复杂性）：
“复杂性”是不但要素总量多，要素之间产生新的变量也很多，所以面对它，你往往是一种捉襟见肘的状态——“攻其一点，不及其余”；
- 4. Ambiguity（模糊性）：
这种状态就像我们看云，是像一只羊呢，还是像一头牛呢？都是很模糊的。

VUCA本来是用来描述客观事物的，但我们的思维，我们对一个事物的认知往往也呈现这四种状态——我们的认知起点往往是一种混乱状态。

# 洗脑：终止你的认知

这就解释了“讲学=学讲”：真正的“讲学”不是播放式的，把你已有的内容播放、打印、倒出来，而是你在讲学、表达、备课的过程当中，不断将你在相应程度上处于混乱状态的认知清晰化。

不管是棋盘还是几何图形、认知清单，各种各样的表格、逻辑，都相当于杂技演员玩杂技时候随身的保险带，或者钢丝演员手里拿着的那根平衡棒——让你清晰地看到你可能偏离了应该保持的位置。

我们 在上节课讲到了播放状态的两个特点：

- 1. 只有存量，没有增量；
- 2. 是屏蔽对话、互动的一种方式。通过这种方式，屏蔽VUCA——思维与表达的易变性、不确定性、复杂性和模糊性。

无论播放、打印，还是念稿子，都是通过“播放状态”来终止认知，终止跟认知相关的VUCA。

正如我们说过的：认知是一种很危险的行为，它包含着各种变量，我们要借助各种手段让我们的认知从混乱到有序，同时还要避免在认知过程中随时可能陷入的各种跟VUCA相关的状态。

我们在上个单元里讲到一个观点：我们说话，一方面是为了“让别人听见我们说什么”，更最重要的是“让我们自己听见我们自己说什么”。

“让我们自己听见我们自己说什么”是要让我们已有的相对模糊、混乱状态的思维，用客观化手段，实现跟自己的对话，并且在这种对话当中，实现认知增量。

但是很多对话其实是“伪对话”，就像我们前面讲到的“播放”：习惯于播放状态的人，表面上是在跟别人对话，实际上是在“自说自话”。

# 实现真正的对话

怎么才能实现真正的对话呢？辩证法。

辩证法的本意是：通过对话和辩论来证明某个结论。这里的“证明”和几何学的“证明”不一样：几何学的“证明”是先有结论，再接下来去证明这个东西；辩证法是开始是一个对话，最终得出对话者双方都没有意识到的一个结论。

如果仔细观察和反省的话，我们会发现很多认知的获得都是这种状态：我们持某种观点跟另外一个人进行真正对话的时候，最后得出了一个双方都认可的结论，而这个结论是远高于你们最初持有的那个结论的。

这个对话的过程可以用一句很拗口的话来描述——把作为语言的语言带向语言。

不论你是在跟别人对话，还是演讲，当你一旦使用了客观化手段把它说出来，我们的自我就分成了两个自我：自我一和自我二：

自我一是“言者”，自我二是“听者”；

自我一“言者”说出来，自我二“听者”听到了以后，会进行思考，悄悄提出自己的观点，然后，面对“听者”提出的观点，“言者”也会作出适当的反应；

这个过程就像下棋：在棋盘上开始下棋，过程就展开了，最后达到一个出乎意料又在意中的结果；

无论是“自我表达”还是“对话”，都是一个让“言者”变成“听者”，又让“听者”变成“言者”的过程；

说话的人听到一段话以后，进行了一个对弈，最后得出一个新鲜的、高于认知存量的结论。

# 《追求卓越》的诞生：两个自我的对话和博弈

著名的畅销书作家汤姆·彼得斯（Tom Peters）是这么写出那本畅销全球的《追求卓越》的：

这完全是一个偶然的事故，汤姆·彼得斯原本是一个管理咨询顾问，他有一次参加一个会议，会上的一个演讲者没到，主办者就希望他能代替那个演讲者做一个演说。汤姆·彼得斯觉得这个任务非常重大，开始还有点儿不愿意，但又不得不去做。

演讲那天，他很早醒了，用铅笔在酒店的便签纸上写下了八条要讲的内容——写出这八条内容的时候，汤姆·彼得斯自己都觉得哎呀，“原来我的思想是可以分为这八个层次的”。

接下来，他按照这个前一天晚上都还没想好的提纲进行了演讲，效果非常好，他说，“我居然有这么多新鲜吸引人的思想”。通过这次演讲，他终于听见了自己的声音，知道自己知道这些什么了。

演讲过后，汤姆·彼得斯觉得应该把自己已有的这些观点进行更深 入的阐释，于是，在接下来的几个月，他开始做这件事情，后来就写成了一本书。

汤姆·彼得斯说：如果没有那一次演讲，我就不会写这本书。这本书的内容不是我简单地从大脑输出来的，也不是有一本书在我的裤子里打印出来了，而是当我开始表达的时候，就开始了两个自我之间的对话和博弈，然后这两个自我互相追问、追问、辩论，使得一些新的认知出现在我头脑当中了。

这就像棋手下了一盘很 好的棋：棋局不是他事先能够想到的，他只是在棋逢对手的情况下下出了一盘好棋。

# 辩证法：知识存量→知识增量

我们再来看辩证法：它通过辩论来证明一个未知的，但又不是凭空出现的结论和认知，是两个人或者一个人的两个自我之间的一场有品质的对话产生的认知结果。

无论演讲还是写作，都是一个辩证法的过程：通过两个自我的辩论，把认知存量转换 be认知增量。

写完一篇文章以后，我们会修改，就像很多作家都说过，“文章是改出来的”——改的过程是一个自我跟自我对话的过程；文章只有写出来以后才能够看到其中的缺陷，也只有看到其中缺陷的时候，你才可能去修改——反复修改的过程，也是一个迭代的过程。

没有客观化，就不可能有迭代；没有迭代，就不可能有真正的认知。

正如哲学家海德格尔（Martin Heidegger）认 为的，思想有名词和动词两种形式：

- 我们的认知结果，通常叫做thought（思想），但是认知的本质不是thought；
- 一个处于播放状态的人，他的思想是一个名词、一个过去式，而真正的认知是一个进行时——thinking；
- 一旦停止了thinking，认知也就终结了——它不是一个通过建设性的 深刻对话实现认知增量的过程。

至此，我们对辩证法这个概念有了一个新的认识：

- 1. 它是一个对话；
- 2. 它是有认知增量的。

辩证法的整个过程是不同于播放式、打印式的生长和展开的过程，我们必须强调的是：

辩证法是对话，但对话不一定就是辩证法，二者最重要的差别是包含的规则和谜锢；

如果没有规则和谜锢，对话很容易变成“自说自话”，甚至是对抗、“语言的跳蚤板”——双方分不出胜负，并且都力图把对方压住，最后形成不任 何增量；

有人说，“90%的对话都是无效的”的原因在于，它们都是没有逻辑、没有规则的跳蚤板和游戏。
