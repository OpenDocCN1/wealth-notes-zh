# 王强

吴老师通过拆解迷信告诉大家，不要迷信吴老师。

科学之所以厉害就在于不迷信，合理怀疑一切直到当下不可再被怀疑。不管你是学术泰斗还是普通人，都要而且只要按照科学范式进行研究，给出的结果必须经过质疑到无可再质疑，才会承认结论，迷信是要求上来先信的。

但是科学研究成本实在太高，对于个人来说几乎没有可能完成其中一小方面，所以即使科学家在其不熟悉的领域也不得不先信再说。另外，由于科学的质疑是在不断严格，不断进步的，所以科学本身也不是真理，而是不断逼近真理的一个模型，只是人类在当下认知下不得不接受的一个最不坏解，但它永远不会是终极解。如果没有意识到这点，即使身份是科学家，也从事科学工作，但是实际上只不过是个科学教徒而已。

# 认知阑尾 3 | 迷信是如何产生的？

# 陈陈

只做最重要的事，也是一种剔除“阑尾”的筛选。

在日复一日的日常生活中，我们会慢慢地形成自己的生活模式，比如：起床、晨练、早饭、上班、下班、晚餐、休闲娱乐或学习充电。慢慢地我们就会对这种生活模式形成习惯，不用多加思考，每天都会按部就班。

在追逐目标的过程中也是一样，为了实现目标会有一些任务需要完成，为了完成这些任务，我们会形成一些固定的行为模式，慢慢地就会形成这种可以自我运转的习惯。所以说有一个好的习惯，直接决定着你最终收获什么样的结果。而每天只做最重要的事情，实际上就是对自己行为的一个筛选，让你忽略那些不必要的事情，不必要的精力耗费，也就是这里面所说的“阑尾”，把有限的时间都放到最重要的事情上去。
