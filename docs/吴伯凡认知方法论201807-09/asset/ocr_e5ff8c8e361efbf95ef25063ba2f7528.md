# 表盘与表面

今天我们从一个大家很熟悉的很小的一件事情说起——表盘，手表的盘。

![](bbox=[0.22, 0.6, 0.88, 0.77])

表盘是近代产物，最初的功能是为我们提供时间信息，但现在表盘作为一种思维和表述的工具，已经渗透到了很多方面。比如很多科幻电影、警匪片里，当两个人处于紧急状况，进行交流的时候常常会用到表盘的意象：

> “你往11点钟方向。”听的人一下就能明白，马上可以去执行这样一个命令。

从这件事情上，我们可以明白：一个概念，一个意象，甚至一个图像，都可以成为一种思维工具。所谓“工具”，就是把特别复杂繁重的事情用很简单的方式解决——表盘，已经成为了一种思维和表述工具。

在我刚学英语的时候，对钟表盘的英文是face感到很诧异，更诧异的是，指针居然是hand——钟表盘相当于钟表的脸，你一看它他的表情，就明白你想要的信息了。

汉语中还有一个词跟钟表有关：表面。

> “表面”就是外表的、面上的东西，实际上就是表盘face上的东西。很多机械手表的反面是透明的，能看到钟表在如何运行，让人觉得很奇妙。手表的正面和反面能让我们明白：什么是“表面”，什么是“后台”。

> “表面”是直接了当给你一种信息，“所见即所得”。不管反面的东西是如何运行的，用户要看的是这个“表面”，而工程师和工匠们要做的是“后面”的东西。“表面和本质”这对哲学概念，我们透过一只手表就看出了出来。

# “表面的认知”&“本质的认知”

我们的认知分为两个层面：一，对于“表面”的认知；二，对于后台的认知。

我们的感官感受到的世界，就是一个表面的认知：听到了鸟语，闻到了花香，吃的水果是甜的等等，都是一种认知行为，是对表面的认知。科学家要做的，就是把支撑“表面所呈现样子”背后的机制给弄出来。如果找不到那些机制，表面的东西是没办法呈现出来的。

举一个简单的例子，吃水果的时候觉得甜，这在科学家看来，甜就不是那么简单了。我们的味觉感受细胞上有一类名为“G蛋白偶联受体”，这些受体能与外界特定的化合物结合，然后产生激发一连串反应，最终形成神经信号。这个电信号传递到大脑的相关部位，最终形成了关于甜味、苦味和咸味的认知。

我们在以前的课程里讲过，味觉是跟人类的生死有关。比如在灵长类动物进化的过程当中，甜味代表的是能量密度，苦味代表的是有毒物质。

我们喜欢甜的而不是苦的东西，是因为人在进化过程中，大自然给我们安装了一种系统和设备——实际上，不是安装的，而是自下而上进化出来的。这个设备有利于我们以最高效率达到我们所要的目的。

# 图形界面技术：表面的认知

下面我要讲到另外一种技术：图形界面技术。

在计算机科学历史上，早期的计算机都是以字符和命令行的方式来操作的，非常费劲，因为这些代码在我们生活中是没有的——我们生活中都是“所见即所得”，也就是最简单，最快捷的方式。后来，为了迎合人性，人们改变了字符和命令行这种反人性的人机对话模式，新的模式产生了：GUI，简称“图形用户界面”，它是施乐公司发明的。

施乐公司意识到，计算机是给用户用的，不是给专家用的一——早期的计算机确实是给专家用的，但当它成为一个产品的时候，如果想要得以通行，就必须要把“后台的认知”转换为“表面的认知”，也就是说，我们戴手表不需要管里面的齿轮，只需要知道表面——现在是几点。

图形操作界面，提供的就是一种“表面的认知”。比如当你不需要一个文件了，就用鼠标拖着代表这个文件的图标，丢进回收站——直观是吧，从来没用过电脑的小孩也能知道。当“图形操作界面”这种技术思路出现以后，立刻势不可当了。

# 乔布斯：把复杂留给自己，把简单留给用户

据说乔布斯曾假装去参观施乐公司，他说他只是看看又学不会——的确，看了施乐公司的这套技术以后，乔布斯是不清楚技术，但他知道了一个非常重要的、对于我们今天所有开发产品的人也都非常重要的一个理念：用户体验是第一位的——把复杂留给自己，把简单留给用户。

乔布斯在“图形操作界面”里提炼出了一种对苹果公司影响巨大，也对于我们今天所有企业都有非常大影响的产品哲学：

+   越来越好的技术，就越是别人感受不到的技术。如果一个技术让让人感觉到“这是技术”，它就不是好技术；
KISS原则。KISS=Keep It Stupid and Simple，一个产品要保持很稳很简单，连傻瓜都会用。

在我看来，这也是乔布斯的一种特殊的禅。

今天禅宗的真正创始人可以追溯到很远，但其实就是中国人惠能。而惠能的特点是什么？Stupid和Simple！惠能不识字，是个文盲，他的《坛经》虽然是重要的佛教经典，禅宗经典，但是是他口述出来一个东西：慧能的核心就是“不立文字，直指人心”。他认为，人们要的不是读经典，而是新的开悟和解脱。何必读经典呢？文盲都可以悟道。

对一个产品来说，用户要的不是技术，而是好用和方便。在乔布斯看来，只有那些根本不开窍的像比尔·盖茨这样“没有品位又不懂用户的人”，才会坚持说：我的技术是很好的；我的产品好不好就取决于我的技术好不好；你连这个技术都不懂，你不是我的用户。这几种思路在乔布斯看来，都是非常没有品位，又是非常危险的产品思路。

我们一开始就讲到了“表面”。作为一个用户，我们只需要看手表上我们看得见和看得懂的那三根针所指向的东西就够了，甚至于后面的东西，把它交给工程师和企业。

好的产品是对用户的要求接近于零的产品，或者用乔布斯的话说，“好的产品是不需要说明书的产品”。说明书很厚的产品都是坏产品，苹果的说明书只有一页纸，那是应付工商部门的一——产品都要有说明书，你非让我弄，我就弄一张纸——其实每个苹果的用户都是不看那张纸的。
