# @小太阳

从另一个角度来看，模式识别是存量思维，机器学习更多是增量思维。但增量不可能是无限的，它是和我们的生理极限相关的。那如何才能通过机器学习不断拓展自己的思维认知？我认为可以从以下三个方面做起：

①大量输入:之前觉得自己的信息流太多了，其实算下来，看得最多的还是得到，如果能够识别好的信息源，还是要尽可能地多输入。

②反复练习:反复练习分两种，一种是重点能力的刻意练习，它能短时间内提升自己的某项能力，另一种是平时不间断的无意练习，它可以锻炼自己的认知敏感度，从潜意识中提升自己的认知能力。

③抓紧时间:既然生理极限突破不了，那我们就努力抓紧宝贵的青年时间，不断学习和提升自己的认知与思维，快速发展出属于我们自己的认知专线。这样才能在年老之时不会后悔。

# @菜菜要长大了

基于数据的世界观，人的一切后台运行都是经过数据积累而稳定运行才可以快速解码，现在可以理解“书读百遍，其义自见”这句话了，也是需要数据的积累才能获得。

套用这个思想，以后干什么不顺了，不会去埋怨别人的原因，只能说你还没有准备得充分，你吃的苦头太少了。你不懂不会，只是因为你看得太少，做得太少。你的复杂的后台系统撑不起你简单的界面。

# @头发未梢的遗憾

把事实还原成故事，需要有机整合大量的数据信息，鉴别，输入，提纯，保存，反复加工，不断整理，偶有心得，继续努力。这也让我想到一种读书方法，检视性阅读。不断在字里行间找到信息，然后通过联想，串联起作者的观点或者故事。这也是长期训练的过程，首先要熟悉作者，其次对于这类专业书籍经常跟踪、阅读，头脑中形成认知系统，碰到新书可以驾轻就熟，快速阅读完毕，还原故事。
