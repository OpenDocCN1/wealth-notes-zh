上节课我们讲到几个观点：

+   1. 我们实际知道的远低于我们以为自己知道的；
2. 我们头脑当中有很多的“知识幻觉”和“知识错觉”；
3. 我们的知识当中存在着许多触目惊心，但我们不知道的漏洞。

由于你地位的提高，别人在对你的评价越来越好的时候，你就把自己限制在一个特定的场景当中，使你对自己无知的那一面完全没有意识——在这个意义上说，职位越高的人可能越蠢。

从这个观点发散开去，不管你拥有多高的认知，都摆脱不了我们身上的两重性：在今天的高科技时代，我们享受着各种科技带来的便利，获取知识的途径变得空前方便和快捷，但我们容易忘记自己还有一个身份——在非洲大草原上拿着一块石头找食物的祖先，我们身上仍然流着他的血。他在我们基因当中的占比远大于我们自己的想象，他始终是我们认知最大的、不可 slammed 的控股股东。

# “套”工具解决“老大难”问题

我经常忘东西，有一年暑假回家，一个东西放在哪儿一会儿就找不到了，我有个亲戚就很认真地问了我一个问题，他跟我说：你是怎么考上大学的？你这个记忆性，上学认的那字不是得甩头就忘吗？你能大学毕业吗？

这个疑问对我的打击很大，我试图说服他，“其实我并不是你想的那么一个记忆很差的人”，但我找不到一种他能听懂的理论来告诉他，“我其实不是你看到的那么蠢”。

我们在生活和工作上没有进展的原因，常常是那些“我们不以为是缺陷和障碍的东西”。你如果真想去解决这种障碍的话，并不难。

# 1. “伸手要钱”

我知道自己“忘带东西”这个毛病以后，每次出门的时候都要反复想象“什么带了”“什么没带”，很费劲。后来有人告诉我一个特别简单的方法，或者说就是一个工具，四个字：身（伸）手钏（要）钱——身份证、手机、钥匙、钱包。这四样东西记起来很费劲，但当这个东西被压缩成一样东西的时候，我就都记住了。

后来我才明白：在事务繁多的时候，能够记住的东西数量是有限的，我们必须要寻找一个“收纳包”，把很多事项放在不同包里。比如50件事情，收纳在4个包里，或者项⽬在7个包里，这样就能轻松解决老大难问题。

# 2. 棋盘

只有绝顶高手才会下盲棋，不需要棋盘。当高手对弈，外行听上去就好像两个人鉄那儿背口诀，高深莫测；而我们普通人，甚至不那么普通的人，还是要有棋盘来下棋的。

棋盘没有什么智力含量，但是一旦没有了，你的高智商往往无处落地，显得极其可笑和笨拙。而那些看似可笑的东西，能够一下子把一个老是解决不了的问题变得非常简单。

# 3. 篮球框的网

我小时候一直不明白篮球的框下面为什么有一只网：投篮的时候，你投一个空心球，“根本没有碰到那个框，进去了”和“根本就没投进去”，在视觉上是很难以辨别出来的。用“网”这个方法，一下子就解决了——一旦有这个网就能很简单地判定球是“进去了”还是“根本没进”。这么一个很笨的小方法一下子把一个很难的事情变得非常简单了。

棋盘也好，篮球框的网也好，都是工具，都是及时监测、校正，避免你犯错的，或者你一旦要犯错的时候，就马上调整的工具。

# 4. 清单

我们有时觉得“列清单”是一件很无聊的事情：你写在清单上的东西，是一个存量，并不是别人告诉你的，而是你本身就知道的。问题是，一旦写出来，我们就要照着那个东西去办事，这是不是有点荒唐？

一个没有增量，只存量的东西，成为比我们更高的东西——它是一种客体化、客观化的工具，有了它，我们就能实时检测、调整我们的行为，知道我们走到哪里了，做了和没做到什么——借助一个并不比我们更聪明，甚至就是我们自己做出来的工具，让我们更聪明。

# 认知的两栖动物

这似乎是一个悖论，但也是一个不可否认的事实：要想提高我们的认知效率，必须首先承认我们是一个认知上的两栖动物。

一方面，我们的智力和认知水平在快速提高；另一方面，不管你这方面的认知提升速度和程度有多高，有一些东西是没办法提高的，我们必须借助看起来似乎没有什么认知含量的工具来帮助我们解决那些问题。

生活中有一种现象，有些人看起来智商很高、见识很高、视野很广，别人认为他是“高人”，但他往往一事无成，或者做出来的事情和人们觉得他该做出来的事情之间有一个非常大的落差。

出现这种情况是因为这样的人往往没有意识到自己的两栖性：他不属于用那些没有智力含量的东西，不能正视自己认知当中永远提不高的那一面。同时，他也不属于用那些很笨的，但与这种提不高的认知相关联的工具去解决那个问题。

他一直处在恃才傲物的状态，从来没有意识到“物”的重要性。

# 总结

我想提醒大家的是：

不要以为我们的认知进化了，我们的智商就越来越高。我们的智力当中，有可以越来越高的那一面，但是，还有一面是受制于一种神奇的地心引力，永远提不高，永远很笨拙。

要解决现实问题，我们一方面要做一个“眼高手低”的高手，另一方面，要学会做一个低手，不恃才傲物——“才”很重要，“物”也很重要，甚至很多时候更重要。就像一个缺少了棋盘的围棋高手，他的最⾼明的算法无以施展——有些工具看上去毫无智商含量，但对于发挥我们的智力起着举足轻重的作用。

工具的重要性不仅表现在行动和实践上，而且对于提高我们的认知也起着非常重要的作用，我们会在下节课着重讨论这个问题。

不少同学可能都听说过“富兰克林的十三种美德”：富兰克林提出这十三种美德，不是一个观念清单，而是一个自我管理的方法。他把这十三种美德写在一张纸上，每天睡觉之前把这个清单看一下，发现今天的哪件事反映出他在哪一种美德上的欠缺，就在这个词的旁边打一个黑点。比如说“缄默”，一想今天说活有点多了，就在这旁边打一个黑点。

富兰克林做这件事情好似是没有信息增量的——不是由别人告诉他的，是他自己告诉自己的。但是，这种看上去很笨的方法和工具，是造就富兰克林这个高手的一个非常重要的原因。

大家可以想一下，生活当中有没有遇到过这样的人：是一个高手，但是造就这个高手的往往是那些看上去很初步笨拙的小方法。
