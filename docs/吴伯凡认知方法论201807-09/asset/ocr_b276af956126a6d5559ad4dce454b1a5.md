# 天算：洞悉老天的“算法”

有句话叫“天机不可泄露”。得到天机是一种凶兆，而不是吉兆：老天会惩罚知道它算法的人。

+   1. 任何物种都是由众多个体构成的；
2. 个体之间是有差别的；
3. 所有个体在特定时间段面临的是特定的环境。由于这个环境是“不变 量”，导致有差异的个体与环境的适配性就不会同。只有跟环境最适配的个体才可以拥有繁殖的机会，其他没有适配性或者适配性很差的个体就会在繁殖之前被消除。

物种就依据这么一个非常简单的法则或者算法不断进化。
