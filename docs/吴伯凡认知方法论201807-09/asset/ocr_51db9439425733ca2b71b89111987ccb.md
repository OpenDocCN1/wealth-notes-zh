# 直觉与数据主义 | 本单元十大精彩留言

欢迎来到《吴伯凡·认知方法论》。这个单元咱们的主题是“直觉与数据主义”。

第一节课我们讲到，“认知”有两种方式：一种是“自上而下”的，一种是“自下而上”的。要保持认知的活力，就要尽可能让自己的认知处于一种“自下而上”的状态，或者说“让自己有一种饥饿感、愚蠢感”，这是优化认知，实现“终身学习”的一前提。

第二节课主要讲的是，一个人的认知优势主要来源于后台，也就是看他能将多少认知沉底，变成冰山在水底看不到的那部分，沉底的部分体量越大，认知优势就越强，而我们不断接触新事物、跟事物格斗的过程，就是将认知沉底的过程，渐渐地，就可以培养出当机立断、急中生智、熟能生巧的能力。

第三节课我们主要讲了一个观点：人与人之间认知能力的差异，主要是数据的差异。那些有超强直觉的大师，他们的直觉也都是表象，背后是大量数据的喂养。所以，要想提升认知，根源还是要扩大自己的数据库。

最后一节课我们进一步分析了神奇的模式识别背后的原理。比如曾国藩的快速识人能力，本质上其实是将眼前的事实还原成故事的能力。由此我们还可以得到一个启示：光扩大数据库是不行的，你还要从中提取、生成有效的模式，不然再大的数据库也只是没有意义的材料罢了。

这就是咱们这个单元讲的主要内容。希望这个单元的课程让你感到有所收获。

# 获奖留言

@清风徐来

今天讲的韩愈的故事，让我想起了竹子成长的故事。

一根竹子，用了四年时间仅仅长了三、五厘米，但到第五年，却能够以每天三十多厘米的速度疯狂生长，仅仅用了六周时间就长到了十四、五米高。为什么能有如此惊人的速度？是因为竹子在前四年的时间里，让自己的根在土壤里延伸了数百平方米。

我们常说一句活，叫“画虎画皮难画骨，知人知面不知心”。画虎皮、画虎廓容易，但你想画出虎的神骨，其“后台”不知要积累多少的观察与信息。每个人的外表都是眼耳口鼻面，简洁可视，但你想视其面而知其心，却不知要拥有多少广泛阅人的经验。

竹子成长的故事和画虎知人的喻意都表明，人生的精彩、事业的成功，其背后都有一个“疯狂”扎根和壮大“后台”的艰辛过程。终点的简单，并不意味着起点与过程的简单。

直觉与数据主义 3 | 认知差距的本质

@He00

在乡下农村里，发现有一些老人特别有智慧。他们有些人甚至没读过什么书，不懂什么科学，但是处理事情来，总是让人觉得跟算命先生一样，什么都知道，而且还很准。这样的老人就是从实实在在的生活中共收集的数据，首先他们会从老一辈那里继承大部分数据，然后又通过自己的生活收集数据，到了一定的年纪，在那么小的生活范围里，就能对周围的生活了如指掌。

为什么只有很少的人能做到对周围数据了如指掌？我应 应该是跟他们用不用这些数据有关，虽然我们都是数据训练出来的智能产品。就像老师之前讲的，如果你没有把自己置身于这样的选择压里，你就不会对出现的这些数据有感，也就不会收集这些数据，驯化这种能力。最后这些数据只会散落在记忆，毫无用处。就像散落在大地 的草，你不收集起来进行编织，就不可能成为草席。
