
# 问答17 | 数据和信息的差别是什么？

数据不是万能的，没有数据是万万不能的

@ 时间的朋友

数据在现实生活中又代表哪些事物呢？
信息吗？

这是一个特别初步又很关键的问题：数据和信息的差别是什么？

数据、信息、知识之间的关系，有一个框架性的描述：这个框架是金字塔型的，最底层、面积最大的部分是“数据”；往上更高一层，面积比较小的是“信息”；再往上，面积更小的一层是“知识”；最顶尖上的是“智能”或者“智慧”。

![](img/274b424b97ce4eb2f1045ee5c4c6fac4_42_0.png)

数据是形成信息、知识和智能的原材料，是最底层的原料；它和信息最大的差别就是：

+   1. 数据的量非常大，信息的量要小一些；
2. 数据是非指向性、非结构性的，信息是有指向性和结构性的。

“信息论”的创始人香农对“信息”有一个很经典的定义：信息就是“消除的不确定性”。也就是说，你把存在着的不确定性消除了，就是“信息”，而大量的数据本身就是不确定的。

举个例子：你要跟一个不认识的人做一桩生意，谈一桩业务。当这个人出现在你面前的时候，他的服装、发型、说话的声调、预期、某一个小动作、喝咖啡的样子等等，所有这些你没办法马上下结论的东西，都是数据。还有一些数据你感知到了，但是好像没进脑子——实际上，已经进入了你的大脑中。

我们有时候会突然发现，跟一个人打交道久了以后，有一天对这个人一下子形成了一个明确的判断——这是一个好人，这是一个讲义气的人；这是一个小人，这是一个背信弃义的人，这是一个虚伪的人……等等。

当你获得这个人的信息的时候，有很多你曾经忽略的，好像没有走心的数据，可能是他说过的某句话、某个小动作、对人的某种态度，甚至某一个很微妙的表情，一下子汇入到你的头脑中，这些东西都是“数据”。

所以，数据是散乱、非结构性、多指向性的，而且它是相对隐性的。总的来说，这些数据是形成信息、知识和智能的原材料。

如果没有原材料，你的信息、知识和智能就无从说起。所以有人说“在智能时代，数据是新的石油”。可以理解为：石油是能源，但还有大量的化工产品都是从石油里头提取的；而数据是最基本的，数据不是万能的，没有数据也是万万不能的。

# 被数据接管的生活

日常生活当中，我们越来越依赖于通过各种仪器来感知世界。

在手机没有计步功能之前，我们每天虽然也在走路，但是并没有看“今天走得了多少还是走得少了”——实际上，你自己非常清楚“走得多还是少”。

最有意思的是，当你发现今天只走了4000步的时候，就会觉得身体好像有点儿累赘的；而如果你看到显示已经走了2万步，甚至立即可能觉得腿都有点儿酸痛的感觉了。

再比如家里的温度计上有表明湿度的数 据。当你看到湿度是40的时候，立刻觉得周围的环境“好湿啊”，而显示20的时候呢，立刻就觉得“真是干得不行了”。

现在，我们正被各种各样的数据掌控我们的感觉，这也是数据对我们生活的接管——事实上，人体本身就是一个数据册。

我们在前面的课程讲过，人体就是一个数据处理设备，用来接收周围各种各样的数 据和信息，然后根据这些数据和信息作出各种各样的反应——哪怕是见到陌生人的第一秒，你就可能已经开始在接收数据、处理数据，并作出反应了。

# 没有变成明确指标的“消极数据”

我们注意到，生活当中的有些事情很奇妙，比如两三岁的小孩子，会叫一个人“爷爷”、“奶奶”、“叔叔”、“阿姨”或者“哥哥”、“姐姐”，一般都不会叫错。让很多女性很焦虑的一件事就是一个小孩叫她“姐姐”还是“阿姨”，童言无忌嘛，这些两三岁的小朋友能够准确地识别你的年龄。

这就是我们前面课程里讲的“模式识别”：尽管从未见过你，但是他的头脑中已经形成了一种模式，可以从你的整个外貌和体态认出你的年龄——这是一种非常常见而容易忽略的“模式识别”。

# 一般来说，我们把不能明确变成一个指标又确实存在，并且能左右我们判断和认知的数 据，叫“消极数据”。

你没有在自己的脑门儿上写自己的性别、年龄，但小孩能认出来，就是通过这种没有变成明确指标的“消极数据”。

我们说“春江水暖鸭先知”，不用说人，就是鸭鹅这种生物体，都是一个数据处理设备：立春以后，水会有微妙的、极其小的差别，用一般温度计可能测不出这个温度的变化，但鸭子在水里游，就能知道春天来了，这些就是“消极数据”。

# 郑人买履：用“积极数据”替代“消极数据”

事实上，我们生活当中作出的很多判断都是根据“消极数据”而不是“积极数据”。但是，现在越来越多的“积极数据”正在接管我们的生活——用各种各样的数据处理设备来代替我们的感觉。

说起来有点儿悲哀，早在2000多年前，中国的哲学家韩非子就写过一个《郑人买履》的寓言，这个故事告诉我们“消极数据”和“积极数据”到底是什么。

郑国有个人要去买双鞋，他照着自己的脚画了一个鞋样子——这是一个明确自己脚的大小的数据，但是，他还有一个自常的数据——脚本身，这个数据包含着关于他的脚的所有数据，但不是指标化的。

《郑人买履》里的郑人，用“积极数据”代替了“消极数据”：他上街以后发现鞋样子没带，赶紧跑回去取，结果再回来的時候，鞋市已经散了。他不信任“脚本身”就是数据，或者说，他对这个数据完全没有意识，而要把积极数据作为他的行动准则。当这个数据设备的某些功能失调，坏了的时候，他没办法处理“消极数据”，而只能依赖一些“积极数据”。

我们是不是也越来越像这个郑人，用越来越多的“积极数据”来取代我们本身拥有的各种“消极数据”呢？

# 人工智能的目标：“解风情”

前些年流行的一個观点说：我们现在的教育越来越倾向于工具理性。简单说，就是我们的教育越来越像职业教育、工科教育，这样培养出来的人“只会解题，不会解风情”。

“解题”是典型的“用积极数据来进行推演”，但“风情”这个东西是一个“消极数据”。如果我们越来越习惯于用积极数据代替消极数据作判断和选择的话，就会陷入到一种很可笑的“有学问的无知”当中。

大家可能会觉得“人工智能和电脑是一回事”，在我看来，本质上的确没什么差别，都是机器，但人工智能和电脑最大的区别就是：电脑只能用“积极数据”进行计算，输入明确命令，输出明确的结果；而越高級的人工智能，越能对大量非结构化的数据进行处理，得出一个非线性的结论，作出有别于“非黑即白”、“非0即1”的判斷和認知——这其实也是“解题”和“解风情”的差别。

真正的人工智能，它的目标就是“解风情”，而不是“解题”。解题，别说计算机，计算器都可；解风情，是一件非常难的事情。

比如一个女生说“我好冷啊”，“解题”的男生会说“那我们一起跑步吧”——我们觉得这个人有点儿二的原因就在于，他是一个习惯了用积极数据来处理问题的人，不解风情。

# 认知里的“盲维”

我们都渴望升级我们的认知，但是大家一定要记住：认知是一个多面向、多维度的东西。如果你的认知越来越趋向于“单维”，你就会越来越退化，形成“盲维”。“盲维”形成以后，不管你在单独维度上多么精进，使用的技术手段多么强，最终得出的都是一个没有多大价值的认知。

这个原则不仅和生活有关，也跟管理经营一个企业有关：一个好的领导者，很多时候是根据“消极数据”来作决策的；而糟糕的领导者特别喜欢用能形成报表、柱状图、饼状图、咨询公司报告的“积极数据”来作决策，这样作出来的决策是非常危险的——因为他的认知里出现了“盲维”。

前几天我一个朋友告诉我，有一天他跑步，跑了两圈以后，突然发现自己的App没打开，他简直心死了——跑步就是跑步，但现在如果跑步不生成数据的话，他就觉得是一件非常亏的事情。事实上，你跑步是“你自己在跑步”，这本身就是你生命活动的一部分。

据说自从有了计步器以后，招财猫的销量就明显提高了：很多人为了让自己的步数在群里很高，不惜通过招财猫的手摇来制造一个数据——这听起来都有些儿可笑，但仔细反省一下，我们在生活当中常常会犯这样的错误。

# “计分卡”产生的谬误

每年高考过后，媒体都免不了讨论一个永远说不完的话题，“高考状元今何在？”

有一个省就曾经把已有的二十几届的高考状元做了一个调查，但最后只找到了五个 人，其他人他们销声匿迹根本找不到了——在信息如此发达的时代，找一个人是比较容易的，这就说明，这些“社会性失联”的人在社会上已经处于相当边缘的位置了。由此，媒体得出一个结论：当年的高考状元如今的这个结局，说明高考的计分和衡量方式是有问题的。

当然，这种计分方式的确是有问题的。现代社会，我们衡量一个东西，必须有一种由明确数据构成的计分和评估体系，比如高考，我们一般算的是总分，但两个同样考了700分的人，能力差别可能是天差地别。但大学录取只看总分，很可能一个人低了几分，就不被录取了。这种情况就导致了一个问题：“计分卡”的评估标准会产生明显的谬误。

这种现象在管理当中也很常见，比如我们衡量一个公司的价值，评估它的成长性的时候，肯定要用各种各样的财务数据——你不能说“我 的公司经营得很好”;“我的公司是高成长公司”……无论是投资者还是媒体都不会认这个，大家要用数据说话——数据是最能够终结各种争论的，当双方争执不下的时候，我们就来看数据。

但是，我们忘了一点：任何积极数据，也就是说，由一个个指标构成的评估体系本身，都是自带偏见的。它之所以形成一个评估体系，是因为它事先设定了一些自知或不自知的标准。

我们说一个国家“强”或者“不强”，这个国家“快速增长”或者“停滞”的时候，总要用一些指标来评价。这些数字写在纸面上没有问题，但有时候得出的结论让我们觉得匪夷所思：选择数据是有标准的，而这个标准本身值得考量。

我们经常只考量数据，不考量标准，但是，大前提错了以后，数据其实变得无关紧要。

# “聪明”的错误

最愚蠢的错误往往都是最聪明的人犯的；最愚蠢的结论往往都是用看上去特别真实、坚硬的数据来支撑的。

# 1. 平衡计分卡

管理学界曾经经历过一场范式转移（Paradigm shift）。上个世纪九十年代，两个管理学家提出了一种新的方法——平衡计分卡（Careersmart Balanced Score Card），这种新的方法包含着一种新的思维范式：

+   - 我们看一个企业的健康程度和成长性，不能够完全按它已有的指标；
- 我们的视野不仅要集中在白纸黑字的数据上，还要看到那些没办法形成白纸黑字，但却真实存在的数据——消极数据。

举个例子，一个企业前一年的财务报表不太好看，盈利没有达到投资者的预期，怎么办呢？

企业领导人首先想到的是，有很多业务、很多部门不是“投资省，见效快”的业务和部门，干脆把它们削减，甚至完全砍掉。结果，第二年的第一季度，财务报表一下子变得非常好看——因为有些很贵但是没有马上推出的好产品的员工给裁掉了，企业成本大大下降了，同样收入显示出来的就是盈利非常好的状况了。

那么，作为一个投资者，你是继续持有，甚至加持这个股票呢？还是卖掉这个股票？随着成本一起被削减的很可能是公司的未来，而买股票其实买的就是公司的未来。

“平衡计分卡”作为一种新的会计方式，实际上已经是超越“会计”的会计手段了，它让我们真正看清一个企业：

+   - 不仅看你现有的表现，还要看未来可能的表现；
- 不仅看你现在的能力，而且要看一个企业的学习能力——我们知道，学习的特点是“付出很大的成本，但是效果是逐渐显现的，不到某一时间点，这个效果没法显 现”。你要不要为学习买单？如果一个企业不为学习买单，或者只是买很少的单，那这个企业是没有未来的。

# 2. 从to have到to be

事实上，“平衡计分卡”背后的思维方式是“从to have到to be”的一个转变：这个企业“拥有什么”和这个企业“是什么”是两回事。

正在奋斗和挣扎中的朋友马上就会想到一句 话：我虽然没拥有什么，但“我其实是什么”。甚至你这样说服一个女生：你别看他很有钱，拥有很大的资产，但他骨子里是一个穷人；别看我现在很穷，没有多少资产，但我骨子里是一个富人，我将来会有很高的价值——这就是to be和to have的区别。

再进一步还原，这其实就是“消极数据”和“积极数据”的差别。to be往往对应的是“消极数据”。

你说这个人“是个好人”，“是个能人”，“是一个巨大的潜力股”——一下这个判断的时候，依据的往往不是“积极数据”，因为他的积极数据看上去乏善可陈，能力、视野这些东西是你一定要看，但没办法形成积极数据的。

反过来，那些在各种各样的评估体系里考分很高的人拥有非常好看的“积极数据”，这个积极数据掩盖的可能是他非常糟糕的“消极数据”，比如我们说的“高分低能”，“高考状元的落魄结局”，都包含着这个问题。

# 3. 避免“表面增长谬误”

企业要经营，人生也要经营。人生的经营必须 要保持好“消极数据”和“积极数据”在你整个经营过程中的平衡。你不保持这种平衡，就会被“积极数据”所绊架。最后你会发现，你的所有“积极数据”都表现很好，但你自己是一个失败者。

上面这种情形在生活中不难发现，尤其是从一个更长的时间段看的话，无论评价一个公司还是一个人，都会发现评估的效果很不一样。

这时候，我们一定要避免一种“表面增长谬误”：表面看是在增长，实际上是在停滞，甚至衰退。这种状况借用经济学的话就是“滞胀”：停滞，而且通货膨胀。

比如有时候我们觉得自己的认知在增加，实际上，你认知的“黄金储备”并没有增加，你只是发行了很多很多的纸币——“超发货币”并不是获得新的认知，而是用一些旧的东西看一些新的东西，得出一个好像是“新”的结论，获得一种本质是旧的“新”认知。

“滞胀”现象在生活当中很多，比如在交往当中也会出现这种现象，表面上我的圈子是在扩大，微信好友越来越多，5000个名额都不够用了，是在增长，但实际上，你的人脉真在增长吗？你的社会资本、社交资本真在增长吗？有可能并没有增加，甚至在衰退。

# 总结

今天这一课就是要提醒大家：人作为一个数据处理设备，一定 要保持“消极数据”和“积极数据”之间的平衡，要保持过去和未来的平衡，否则，我们很可能因为要应对眼下暂时的一个评估体系，而让自己的认知和资源配置出现结构性失衡。随着时间的推移，这种失衡越来越显现。最后导致两种结果：滞胀，或者衰退和崩溃

+   - 做企业可能风光一时，但几年以后势不可当地衰退；个人成长也可能陷入到这样一种状态当中。
- 我们千万不要被那些暂时的评估体系、某些“积极数据”所绊架，而忽略了大量由“消极数据”所构成的生态体系。
- 我们只要把“表面增长”和“实质增长”的所有这些要素都纳入到“平衡计分卡”里，才能够保证一个组织、一个个人的可持续增长，而不是表面的增长。
