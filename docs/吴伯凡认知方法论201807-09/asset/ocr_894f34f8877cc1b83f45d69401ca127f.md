# 问答13 | 脱离场景的学习是无用功吗？

问答13 | 脱离场景的学习是...

大家在“生态位与选择压” 这个单元的课后提了很多问题，发言非常踊跃，可见这个听起来很抽象很学理的问题跟大家的现实处境的关系很密切。

生态位决定了我们的认知，因此，要提升认知，必须要在情景中才有可能。不需要的认知我们永远也发展不出来——这也让我产生了因惑：我们现在所谓的“学习”，是不是在做无用功呢？因为没有在具体场景应用，所以也谈不上建立新的认知？

这个问题非常重要。

我们以前讲到过“刀锋竞争力”：真正决定一把刀功用的竞争力，是它的刀锋。但是，世界上不存在着仅有刀锋的刀——必须强调的是，重要的不在于我们拥有多少认知，而在于你的认知里有多少是能够形成真正竞争力的。
