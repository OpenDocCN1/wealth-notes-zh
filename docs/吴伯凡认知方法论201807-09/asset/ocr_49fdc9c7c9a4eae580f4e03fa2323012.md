第二模块 认知治理与认知智能管理 认知断舍离

我们在前面的课程里提到过一个概念：尤瓦尔·赫拉利（Yuval Noah Harari）的“知识错觉”。所谓“知识错觉”是你觉得你知道了很多东西，但实际上这个知识的质量非常低，是不管用的。

我们在参加一次重大考试，比如高考之前，有些人就会有比较多的知识错觉，觉得自己都知道了，但遇到稍微严格一点儿的检测，知识错觉就在那一刻灰飞烟灭了。

很多怀才不遇的人都是有比较多知识错觉的人，他们以为他们知道的量和质都大大超出了他们实际知道的量和质，所以就会产生一种“我满腹才华，但其他人都不承认，别人对我不公平”的感觉。

与“知识错觉”相关的一个概念是“隐形的认知负资产”。这些负债在我们头脑当中，让我们以为自己获得了很多知识，但其实只是给谬误提供了接口。

# Cookie：隐形负资产

我们在清理电脑的时候，很容易体会到什么叫“隐形的负债资产”。比如我刚开始用防病毒软件的时候就发现，你打开杀毒软件，它会显示电脑里有多少个Cookie，你就眼睁睁看着它报出来的数字不断增加。

当你访问过一些网站以后，你的电脑就会留下很多痕迹，其中一些痕迹就是Cookie。Cookie给了我们带来了很多便利，比如你在访问一些网站的时候，就可以避免重复做那些你不愿意做的事情，但Cookie在提供方便的同时，也无形中给你的电脑留下了很多的安全漏洞。

比如你收邮件的时候，如果选择了记住密码和用户名，方便的同时也意味着你的一扇门被悄悄打开了，或者说，你已经给这个网站预留了后门。“凡走过必留下痕迹”，不管是行为，还是思维，都遵循这样一个规律。

我们的思维、认知在运行的时候，都会留下类似于Cookie的东西，它给了我们提供了某种惯性：前面的行为和动作可以封存不动复制到这次的行为当中，所以，你觉得省力了，但这同时也意味着，你接下来的行为和思维悄悄地受到了某种控制，或者是给一些具有威胁性、操纵性的观念留下了可乘之机。

为了保证自己的信息安全，我们要定期、不定期地清理Cookie，否则就会很危险。

# Cookie：希特勒的“群众效应”

电脑有帮助我们清理Cookie的软件，但人脑就没有类似于“能够准确发现其中的18250个Cookie”的软件。

一方面，Cookie是你的认知正资产，相当于给你进行了赋能——有了这些熟悉的观念、套路、方法，你在思考认知的时候，不用太费事就能找到你所要的答案，不假思索地作出决策。我们使用工具、方法都是为了省力，所以在这个意义上说，Cookie就是一个正资产。

但显而易见，它也是负资产。

有一个历史学家在分析希特勒的《我的奋斗》这本书的时候说：看着这本书，你很难想象当时它产生的那种力量，很难相信居然会产生那么大的影响力，有那么多人几乎把它当成了《圣经》。希特勒的每一次演讲、每一个表情、音调、手势都会引发极其狂热的反应。

这本书里充满着各种在今天看来极其可笑的观念、概念和所谓的“科学结论”，比如关于雅利安人的起源等等，关键就在于“它真能产生那么大的作用”。

希特勒对自己的话术很得意，他自创了一个概念“群众效应”，就是在你讲的时候，一定要讲人们头脑中已经有的诸多类似是非的东西。你的观点精彩与否，不在于你的观点本身，而在于是否能跟人们头脑中的观念形成句连。用今天的话说，你要先找到群众头脑当中的那些Cookie，然后用很简单的方法一下子进入到他的头脑当中。最重要的是，这些“乌合之众”不认为自己受到了演讲者的盅惑，你只是像助产婆一样把他们头脑当中的观念给接生出来而已，而不是告诉他们这样想。是他们自己这样想的——这就是那些Cookie的作用。

希特勒这么说，不是在玩弄政治权术，事实上，现代市场的营销行为都在利用这种“群众效应”，更准确地说，就是“Cookie效应”。

# Cookie：头脑中的卧底

我们可以把Cookie简单理解为：悄悄植入，卧底在你头脑当中的那些暗中接应者。

Cookie的作用就是里应外合，最重要的是，它作为一个细如隐藏在你的头脑当中，你完全没办法意识到它的存在，而它的接应是在一瞬间完成的。

如果我们把“传播一种观念”“说服别人”看成是打开某个人的头脑，那么由于Cookie的存在，你根本不需要知道密码和用户名是什么，只要一开机，就自动进去了——这就意味着，你头脑当中的Cookie越多，那些具有威胁性和操纵性的观念、伪认知，悄悄溜到你头脑当中的可能性就越大。

我们可以用软件给电脑、手机定期清理各种Cookie，清理各种无效无用的缓存，但至今还没有一种软件来查找并清理我们自己的Cookie。

最困难的是，我们分不清哪些Cookie是有用的，哪些是没用的。我们不可能没有Cookie，因为我们要有自己的认知储备，要升级。而真实的情况是，不是我们在思考、认知、作决策，而是Cookie的发布者和使用者在使用我们的大脑做他们自己的事情。

明白了这点，我们就知道为什么会有那么多的astrologist（占星学家）、保健专家、制造意识形态的专家在帮助我们作决策和选择了。

总有同学问：“众愚成智”和“乌合之众”之间有什么不同，现在，我们就更知道什么叫“乌合之众”了，就是那些头脑当中太多Cookie的人，他们在非常精明、阴险地使用这些Cookie实施一种看不见的控制。
