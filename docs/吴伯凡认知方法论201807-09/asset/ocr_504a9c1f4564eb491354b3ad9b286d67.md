# “灯式认知”高于“镜式认知”

@陈莉

说到镜子，很多游乐场会有哈哈镜，站在他面前，我们会瘦亦或很胖。镜子反映出来的是真实的我们自己吗？不是。镜子有反映出来我们自己吗？有。通常我们说以史为镜，经验参考，名人偶像崇拜模仿，但是这些更多成分的是一个哈哈镜吧！如果人生注定是一个人在黑暗中摸索，踽踽独行。那“读史使人明智”，这样还有意义吗？

@Albert

想到了“镜子”的另外一种变形——哈哈镜。相比经常一般情况下使用的镜子，这种“镜子”对真实的事物进行了扭曲。现实当中有很多“哈哈镜”，面对这些扭曲的镜像如何辨别呢？是否需要很多“镜子”进行纠偏呢？

@Kersin

镜子就是按照它自身反照一切。然而我的心镜已经被识、信仰、认同的概念、接受的信念等所改变。这镜子不再是平面镜了，它有时凸、有时凹或者变成了哈哈镜。老师；这样经过自己所照的一切还会是他本身的样子吗？

在“镜与灯”这个单元的课后，很多同学不约而同地提到了一个问题——哈哈镜。当我们说到镜子的时候，很多人在头脑当中的第一反应是“世界上你有一种镜子叫哈哈镜”。“哈哈镜”不是用来反映真相的，而恰恰是用来扭曲真相的。通过这种扭曲提供的某种娱乐，让我们的思想情绪放放假。

在说到“镜子”的时候，其实有一个前提：我们对世界的认知，是我们依据特殊的流程和技术，制造出来一个认知产品，它从一开始就是被扭曲的，不是原物的真实反映——在这个意义上，所有的镜子，也就是所有的认知都是“哈哈镜式”的认知。当我们承认这点的时候，我们自然就会抱有一种认知上的谦卑，或者敬畏。

我们这个单元并不是单独讲“镜子”的，而是与另外一个隐喻相对照的，那就是“灯”。我试图和大家分享的观点是：我们的认知至少分为两种类型——静态、直观、一次获得的镜式认知；以及灯式认知，一种过程性的认知。

更学术的说法是：“镜式认知”是理论理性，“灯式认知”是实践理性。“镜与灯”跟我们前面讲到的“钟与云”这对概念相关：

+   “钟”表达的是世界确定性的面相，而“云”是世界不确定性的面相；
世界本身同时具有确定性的一面和不确定性的一面；
如果不是同时使用这两种视角看世界，就很可能陷入到巨大的迷惑和困境当中；
“镜和灯”这两种认知方式恰恰对应于“钟和云”这两种世界状态，所以我们的认知也具有两面性，也就是“镜灯二象性”。

任何一个人的认知都具有这两面性，但在每个人的认知里，镜和灯的配比是不一样的：如果“镜式认知”占比很大的话，你可能是一个认死理的人；如果“灯式认知”占比很大的话，你可能是一个随机应变到极致，以致成为投机主义者的人。

认知的起源是“求存”，而不是“求真”。从这个意义上说，“实践理性”高于“理论理性”——“灯式认知”高于“镜式认知”。

有人概括说，“科学的发展就是让一个小学六年级的学生拥有300年前顶级科学家的认知”，但实际上，即使你拥有了这样的认知，仍然不足以应对这个世界——我们始终处在一种黑暗状态中，或者说，你始终是在跟一个未知的、不确定的世界打交道，所以，“实践的智慧”永远高于“理论的智慧”。

# “接受别人既成的认知”是“镜式认知”

@littlebear

我们不可能获得所谓的“镜式认知”，只能拿着灯去摸索。但我觉得我们可以参照别人的经验，比如在没有学习认知方法论之前，我们并不知道什么是“母体舒适区”、“知行合一”的真正意识，生态位决定认知等等，学习了以后，就可以通过这些方法去指导自己的选择和行为。这是不是像是拿着镜子去照别人，然后来指导自己？如果只是 agreement 一味地摸索，不仅效率低，成本也高。所以我的问题是：学习别人的经验，算是“灯式”还是“镜式”？

“接受别人既成的认知”是一种“镜式认知”，它有几个局限：

+   1. 可以形成生产力，但很难形成竞争力。

九九乘法表能够增加你的生产力，但不能增加你的竞争力。

+   2. 任何可以编码、写在课本上、短时间就能直接输送到你头脑里的认知，都是有相当的局限性的。

换句话说，你知道了这些东西，但这些东西还只是道理，只是你认知的一部分，还不是你的认知。要真正成为你的认知，必须启动你的“灯式认知”。在一次次的认知地震和认知震荡中建立属于你的个人认知，也就是一种“只可意会、不可言传的、不可编码的“个人化知识”。

我在《伯凡·日知录》里讲过：真正形成竞争力的是那些“别人没办法从你身上直接拷贝的”不可编码的知识。只有通过内省、自下而上产生的认知，才是真正属于你的认知。借助这种认知才可能形成你的竞争力。

“可编码”和“不可编码”的知识是认知硬币的两面，这也就是说“认知具有镜灯二象性”的原因。
