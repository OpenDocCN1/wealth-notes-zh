# 本单元总结

# 1. 第一节课

我们通过对比鸟的眼睛和人的眼睛，得出了一个结论：你关注什么，以及你如何逸抒你的对象，决定了你如何构造你的认知特性和模式。

就像鸟，以飞虫为关注对象，它的眼睛的配置就更高。而人眼与鸟眼相比，显得捉襟见肘。马、食蚁兽，不需要准确定位食物和猎物位置的时候，它们的双眼并不在一个平面上；而人、老虎关注的是个体的位置，所以他们的眼睛在同一个平面上，方便聚焦。也就是我们关注的对象，我们捕获的对象，决定了我们最终的认知的特性，也决定了认知的优劣。

# 2. 第二节课

我们把认知模式的形成原理又往前推进了一步，在关注点的背后，是场景决定了认知的优劣。任何一个认知能力，都可以还原为一个故事。在这个故事里，一定包含着极其生动、细致、精微的场景，而这个场景就是一个生动的认知故事。

# 3. 第三节课

我们把这个问题又往前推进了一步，真正有效的认知是场景化的认知，而场景化认知与非场景化认知的差别，说到底是数据量的差别，认知的迭代、进化，就是特定场景下数据的积累，以及从积累起来的大数据上，涌现出的一种优化模式。

这就是从低配认知向高配认知演进的历史程。

# 4. 第四节课

通过安迪·格鲁夫、富兰克林等人的例子，我们真切地体会到场景赋予人的边缘竞争优势。有些技能和知识必须在长期的细微场景里获得。离开长时间的、在特定场景下的刻意练习，是不可能获得真正的优势认知的。

# 陈欢

不是先有认知，才有的对象，而是关注的对象决定了认知模式，生活中有很多问题和矛盾的产生，都是因为关注对象的不同。有个故事让我印象深刻，就是有一个妈妈很喜欢带着5岁的女儿逛商店，但是女儿每次都不愿意去，这位妈妈感到非常奇怪，商场里琳琅满目、五颜六色的商品那么多，小孩子怎么就是不喜欢呢？

# 姜燕81550653

有了孩子，看了大量的关于儿童教育的书籍，归纳了一些育儿原则，比如平等、关系大于教育，尤其是关于孩子学习方面的肯定和督促的平衡。可是每天具体的育儿实践中，我仍然做不好，只好带着深深的挫败感入睡。伯凡老师说：学习书法知道如何握笔，如何握正确的姿势等能够明确保传达的知识，是我们做好一件事的必要条件。成为育儿高手的话，还是需要大量的场景化知识，也就是在每天的实践中，不断地总结经验，不断地尝试新的方法。

# 老孟

以前的我喜欢考取各种资格证书，都说“技多不压身”嘛，而且每次通过一门考试后都会有一些成就感，但后来我发现，如果只是通过了考试，却没有去真正从事相应的工作和实践，这样的知识其实已经掌握的知识其实就是一个知识点，根本没法形成完整的知识体系，而且随着时间的推移，这些知识点也就慢慢生疏、遗忘了。

经过反思，我调整了想法和策略，即只针对与自己当下工作岗位密切相关的能力进行重点培养。这样做的理由由简单，就是我有现成的工作场景对所学的知识和技能进行运用，本质上就是将我的认知和我当下所处的“生态位”进行适配：一方面，我的知识技能可以指导我的工作实践；反过来，通过在工作岗位上的不断实践，又可以检验、优化我的知识技能，我想这就是伯凡老师一直强调的“认知产生迭代”的过程。
