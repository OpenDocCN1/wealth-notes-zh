# 1. 伪科学 vs 迷信

这节课首先和大家分享几个特别有意思的数据：大家都相信我们处在一个科学极其昌明的时代，那么，现在是科学家多，还是伪科学家多？

大家可能没听说过“伪科学家”这个词，但“伪科学”都是知道的，而我们说到“伪科学”的时候，又经常把它跟另外一个概念混为一谈——迷信。

“迷信”和“伪科学”不一样，它带有自身的标签，一看就知道那是“迷信”，而“伪科学”以科学的面目传播一个错误的观念。“伪科学”长得特别像科学：各种的术语、概念体系，包括研究过程，甚至为它背书的机构等等，都带有明显的科学特征，但它的结论是错误的。

科学的特点是等待被证伪。比如，我提出一个假设，然后根据现有的实验和推算，演算出它是这样的，把这个成果放在科学共同体上等待大家的反驳和质疑。如果大家针对这个结论，用数学和实验的方法没办法证伪的话，它也仍然保留被质疑、被反驳的空间。

# 2. “伪科学”的病毒无孔不入

我们知道，英文单词后面带“ist”一般是专家的意思，比如scientist，科学家。现在我们要说的是astrologist，相信知道这个词的人就会默默笑了，这个词是占星学家、占星术士。如果你不认识这个词，光看ist，就会认为这是专家，事实上，他们也是专家，只不过是另外一种类型的专家——在美国，保守地说，这些astrologist的数量是天文学家数量的20倍。

我们生活当中是不是有这样的人，拿了理学工学的博士，特别相信科学，但是也会相信星座这些东西——伪科学的病毒无孔不入。

在保健品、化妆品领域，也有很多的专家，他们做的一件事情就是：做科学状的医学和保健品、化妆品的意识形态。

比如维生素B17，大家可能都听说过，后来经过研究，根本不存在B17。有一段时间，维生素B17很流行，据说有一种药加上它以后，可以抗癌，一度还很畅销，当然，它是骗人的。

“研究”出来B17也是需要费用的，这个“研究”要做什么呢？首先，要有相应的研究机构和研究流程，也要有实验报告，甚至会发表论文，最后，弄出来一个成果。在信息不对称领域，比如病人和医学专家之间，信息和知识永远是不对称的，我们就只有相信的份。如果他做出看上去很像科学的东西，我们就相信他，这就是“伪科学”。

一个保守的估计：美国每年花在这样的研发上的费用超过10亿美元。有的化妆品机构里雇用了很多专家，提出很多的概念——“在化妆品里加了一种新研究出来的、具有药用价值的某种化学成分XX，起到了什么什么效果”——这些都是“科学状”的营销理念。化妆品公司的大部分研发费用都花在这个上。

我听说，人类只有两样东西2000年来没发生过变化，一个是造纸，一个是化妆品。古人也有肤如凝脂的，她们肯定没用过“什么雅”“什么蔻”，但是，她们的皮肤可能比我们现在要好得多。你看看现在，每年出多少保养皮肤的神器，那大家的皮肤是变好了还是变坏了？

但你就是没法拒绝：当你抹上去，可能当时的效果会好一些，一旦开始使用这种东西，你就被迫成为“成瘾性依赖”——不管你对它有没有瘾，它所形成的一种外在强制，都让你必须持续使用它。而且，有时候，它制造出一个毛病，又研究出一个新的东西来解决这个问题。

就像“整容业”是一门很好的生意，因为在整了一次以后，会暂时解决你的问题，等你很快出现新的麻烦时，再继续整，这么持续为你创造价值、解决痛点——这些都是“伪科学”。

# 3. “伪科学”的预留接口

我提到“伪科学”和这些让人很吃惊、出乎意料，也在意料之中的数字，是想提醒自己和大家：我们相信自己是有科学素养的，但我们很容易受到“伪科学”的感染，而且相对于没有科学素养的人，自认为有科学素养的人更容易受到伪科学的感染。

若干年前有个“全国牙防组”，后来查出来，那是5个退休的牙科专家组成的“组织”，某个生产牙膏的公司利用这个具有科学特征的机构，或者伪机构，来推销它的产品。

我们受过科学教育的同时，就意味着我们给“伪科学”留下了接口。

举一个大家都听说过的例子：在《射雕英雄传》里，黄老邪觉得郭靖是夺走他女儿的人，第一次见面首先想到的是把郭靖的武功给破了。黄老邪有一支类似于魔笛的笛子，他吹出来的曲子，听到的人武功就废了。但是，当他对着郭靖反复吹他的魔笛的时候，郭靖的武功一点儿都没有破——因为郭靖太傻了，他跟魔笛之间没有接口。

我们经常说“要提高认知水平，要升级我们的认知”，有时这种就无意当中给伪科学预留了接口。有人把这种“伪认知”的东西叫“污染智程序”，如果你头脑当中没有这个接口，那些程序是没办法装到你头脑中的。这也解释了“为什么好多聪 minh人更容易相信一些更玄所思的事情”。

如果我们缺乏反省能力，认知升级的结果很可能就是认知退化。辛辛苦苦给自己头脑当中装了好多新知识的时候，也意味着让那些懂得伪科学的黑客攻击你的头脑留下了巨大的机会。

我以前经常用Windows系统的电脑，后来有人给我推荐苹果电脑的时候，我还有点儿犹豫，但最后还是买了一台苹果电脑，原因是他们告诉我“针对苹果电脑开发的病毒特别少，基本没有”。所以，使用苹果电脑的时候就省心多了，因为那些病毒程序入侵的可能性被大大减少了。

大家有没有想过这样一个问题：我们有什么办法让我们的头脑变成一个类似于苹果电脑的东西，让针对Windows开发的病毒程序没法入侵我们的头脑？如果这样的话，即使不用太升级，你也不可出现认知失调和思维障碍。

如果你的智商不够高，不够聪明，而且似乎也找不到一种法子让自己很快变得聪明，你不妨做郭靖，而不是杨康——预留了那么多接口，同时受到东邪和西毒的入侵，最后让自己的认知崩盘。

如何通过类似于降级的方式来升级我们的认知，我会在后面的课程跟大家继续分享。
