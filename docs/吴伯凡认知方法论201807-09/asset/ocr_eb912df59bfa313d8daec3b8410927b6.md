# 一飘饮

有竞争力的认知都是场景化认知，都是经过大量的刻意练习后形成的认知。这也是为什么看了“30天学会编程”、“30天学会PPT”这类书我们仍然不会编程、不会做PPT的原因。要掌握一项技能，成为自己不同于他人的竞争力的，除了将自己置身于特定场景下刻意练习，别无他法。

# 仕伴功倍

关于场景对于认知的重中性，我想起了一句话：“所谓一本好书，或者一部好的电影，是那种值得你反复阅读、反复回味，而且每次再看都有新收获、新感悟的经典之作。”这句话跟“场景”有什么关系呢？

我们应该都看过《少年派的奇幻漂流》这部电影，如果你是一个小孩子，估计你只会对里面的各种动物、美丽的大海和奇特的小岛所吸引，但如果你是一个中年人，相信你会嗅出电影通过这些画面和故事想要传达的深刻寓意和哲理。小孩子和大人产生这种感受差异的原因，就是大人比小孩经历了更多现实生活场景的洗礼，自然会对电影的解读达到更高的水平，而且随着经历的增长，每次再看时都可能会产生新的感悟。

“外行看热闹，内行看门道”表达的也是同样的道理。面对同一个事物，外行和内行之所以看到不同层次的东西，就在于二者经历场景的数量有天壤之别。没有经历足够的场景，便不会对事物产生充分的认识和理解，也自然无法实现“真知”。

# 龙剑

觉知自己的三种立场，可以做到随时切换自己的三种立场，在恰当的时间采用恰当的立场应该是我们追求的认知升级，以一个旁观的自我来驾驭这三种立场，该用意向立场时使用意向立场，该用设计立场时采用设计立场，该用物理立场时采用物理立场，只要知道自己在干吗，为什么采用这种立场，有什么收获就行，不必纠结于采用什么立场。

问答 24 | 意向立场完全没用吗？

# 洛洛

意向立场是设计立场的一种派生物。当你持有设计立场的时候，同样会产生“应该怎么样”，但是这个“应该”不是说对方应该主动地怎么样，而是把改变这种状况的责任归结到自己，这是一种设计立场。

万事万物自有其发展的规律，不以人的意志为转移，但是人可以了解、认识这个规律，掌握它利用它。人想利用水，水就“应该为人类服务”，于是，人们利用“水往低处流”的规律，利用水位差的力量发电；沙漠是大自然的产物，你也搬不走它，人想要治理“风卷黄沙”，就在沙漠里栽种红柳、胡杨、沙冬青等适合沙漠生长的植物；一亩水稻的产量是有定数的，要解决人多吃饭难的问题，“水稻之父”袁隆平研究杂交水稻，让水稻高产900公斤/亩……

你看，这些就是“意向立场”由“设计立场”科学地派生出来的效果，意向中有设计，设计中有意向。
