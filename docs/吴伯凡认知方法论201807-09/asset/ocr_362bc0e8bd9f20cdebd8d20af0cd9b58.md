# 1. 认知的“思维经济原则”

@ 勇春君-机器人-机械

一个知识点背后会有一个支撑它的知识网络。那么，读书要掌握一个知识点，也需要全部理解它背后的知识网络吗？时间不允许，怎么把握这个度呢？

正如庄子说的“吾生也有涯，而知也无涯”。我们要面对的一个世界，是一个知识海洋，以我们有限的能力和时间，只能掌握其中一点点，连牛顿都说并没有到过大海，只是在海滩上拣了几个知识的贝壳。

人类认知遵守的一个原则就是“思维经济原则”：认知是生存的一种手段，我们有限的能量不可能用在无限的认知上。
