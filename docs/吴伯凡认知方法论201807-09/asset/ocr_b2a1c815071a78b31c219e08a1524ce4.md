# 1. 认知是生态位的反转表达

@ friend

我不认为是“生态位决定认知”，而应该是“认知决定生态位”。因为一个人的认知能力提升了，他的职位就会上升。

我在这里特别要强调的是，《认知方法论》不是一个关于职业生涯的设计课。职位和生态位，即使不是说完全不是一码事，至少相当大程度上不是一回事。

我们说“生态位决定认知”，是说每一个人的认知状态都反映了他在整个生存当中所处的位置，而不是你现在在公司里所处的位置。

比如你在家里是老几？老大，老二，老三，老四……绝大部分的环境都是相同的：同样的父母、经济状况，受教育也可能是同样的，但为什么认知水平相差很大，行为习惯又那么不同呢？原因就在于兄弟姐妹每一个人的生态位是不一样的。

曾经有一家媒体分析了某著名公司的CEO在家里的排行。他有三个姐姐，他在家庭里所处的生态位是被包容、被呵护、被迎合的，所以媒体认为，他的行为和思维中表现出明显的单边色彩，以至于他的公司成了一个“铁打的营盘，流水的兵”，只有他一个人始终在那个位子上。这个CEO已经是老大了，但是他的性格、认知水准一直停留在一个相当畸形的水准。

一个公司做到什么样子有很多的决定因素，并不完全是由CEO的认知决定的。很多时候是由于某种产业趋势，某一个特定时间把一个人或一家公司推到了一个位子。趋势除了各种大的宏观环境以外，还有很多的小气运，但是，一个人所处的职位并不能改变他个人所携带的生态位，他的认知水平和状态会深刻影响他经营和管理这家公司的方式和思维模式。

尤瓦尔在《人类简史》里说：现代社会的认知，现代人的认知，在相当程度上是低于古代人的认知的。为什么这么说呢？因为在游猎采集时代，人是需要综合多方面的认知才能活下来的，而工业社会导致了普遍的社会分工，哪怕一些认知能力非常片面，甚至各方面能力都很差的人都能找到一个饭碗。

我们不要把生态位和职位混为一谈。一个人的处在什么职位是有相当大的偶然性的，而且是间断性的，而一个人的认知能力是由他此前，尤其是早年在家庭中的社会化过程中决定的。

关于生态位和认知的关系，我们可以用另外一种表达方式：认知是生态位的反转表达。

在数码相机之前我们使用的是胶片，也就是反转片。当你看反转片的时候，如果有想象力的话，是可以想象洗出来的照片是什么样子的；反过来，你也可以从洗出来的照片想象反转片是什么样子。照片和反转片看上去完全不一样，甚至正好相反，但是照片和反转片之间是相互映射的。

一个人的认知状况、认知水平，就是他生态位的反转表达。

一个公司里，同样职位上聚集着许多认知状态非常不一样的人，他们都携带着一个隐性的生态位，这个生态位反映和隐含着他的认知水准，也决定了他在这个位子上待成什么样子、待多久、最终会处在什么样子的位子上。

# 2. 生态位决定构造

@ 大旺

狮子和人的眼睛在头部的分布位置有很好的解释，可是鹰类呢？老鹰的眼睛也不在同一平面上，但它的捕食对象也是单个的可数名词，怎么解释？

![](bbox=[0.18, 0.0028, 0.82, 0.0033799999999999998])

一想到鹰，我们看到的都是一个侧面照，因为侧面照很容易凸显鹰作为猛禽的凶悍，尤其是带钩的喙。但如果大家看鹰的正面照的话就会发现它的眼睛虽然分布在两侧，但其实是在同一平面上的。

![](bbox=[0.18, 0.00365, 0.82, 0.00422])

最典型的例子就是猫头鹰，它是完全在同一平面上的，而且，由于猫头鹰和它捕食的猎物之间的距离比普通的鹰距离短，以至于它的脸部结构和眼的结构已经跟陆地上捕食的走兽一样了，所以看起来它长得跟猫一样。

鹰眼跟人眼有很大的不同，一个是晶状体的后面有一块肌肉是钳着的，用来变焦；一个是鹰眼的后面有一个小坑，相当于鹰眼拉长焦的时候预留的一个空间；同时，鹰眼的分辨率也非常高，使它视野的清晰度远高于人。

鹰飞在高空，但要快速俯冲下来捕捉猎物，所以鹰眼才具备长焦、快速变焦等能力。鹰眼的结构更能说明一个事实：生态位决定认知。眼睛的构造、能力是由于它跟它的猎物之间的距离决定的。

# 3. 仅靠记录无法实现传承

@ 雨中漫步

吴老师讲到瓷器的故事，说国人没有记录的习惯，导致走不出瓷器发明、失传、再发明、再失传的怪圈。而欧洲人在发明瓷器时，对瓷器的成分、工艺都有详细的记录，从而可以仿制出欧洲历史上任何一款瓷器。“默会知识”是否可以转化成“可编码知识”？“默会知识”如果不可转化，瓷器制作的例子是不是就是很好的证伪？如果可转化，那是不是又违背了不可编码的特性？

中国失传的好东西不仅仅是瓷器，还比如中国古代的很多音乐、乐曲也失传了，现在叫同样名字的乐曲都是近代人重新凭想象创造的，因为我们找不到一种记录乐谱的好办法。

西方也是很晚的时候发明了五线谱这样一种记录工具的。借助于五线谱，西方人才准确记录了乐谱，而不再是嘴口口相传，师徒相传的这种方式。

对乐谱和瓷器工艺的记录都不是对默会知识的记录，他们记录的都是可编码的知识。比如琵琶弹的《广陵散》，他在弹完之后说，“《广陵散》于今绝矣”。我们今天听到的《广陵散》很可能不是他当年的那首，因为没有很好的记谱法把曲谱记下来，即使记下来，能把《广陵散》弹得跟嵇康一样好，一样动人，仅仅凭谱也做不到的，只有在长时间的练习当中，用“不可言传，超越言传”的意义的程度，才能弹好那首曲子。

同样，西方人可以凭借成分、工艺的详细记录仿制出一个年代的瓷器，但是想要做到跟那个时代的瓷器一样的水准，仅靠这个记录是做不到的，还要经过反复练习，反复试错，从可言明、可编码的知识， tiến vào到不可言明、不可编码的知识。

那么，如果具备竞争力的知识都是不可编码的默会知识，是什么力量保证人类的不断进化呢？动物的进化显然不是根据某种记录和谁的指导来进化的，它是在场景当中通过大量的试错而实现的。
