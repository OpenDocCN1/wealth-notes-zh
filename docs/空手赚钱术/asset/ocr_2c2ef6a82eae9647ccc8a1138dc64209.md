# （3）被拒绝是好事

无论你多聪明，无论你多有能力，被拒绝都将常伴左右。为什么会 被拒绝呢？因为你有一些地方做得不够好。所心，拒绝就是信号，提示你改进的信号。

我们一般都是这样做的。凡是客户拒绝时，我们必定向一个问题：

“您觉得还有什么地方不满意？”

被拒绝，却不问原因的人是纯犽的蠢人。因为拒绝时，就是客户教你 的时候，你多问个问题，实际上就多学了一些知识。

所谓的经验，就是犯错后才领悟的“知识”。你犯错了，却不学习， 那 不是蠢人是什么？

所以，如果你养成了多问一个“为什么”的习惯，你将受益终身。
