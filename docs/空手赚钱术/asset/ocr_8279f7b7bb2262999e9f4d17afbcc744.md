| 以租代售计算表 | | |
| --- | --- | --- |
| ①房屋市场价 | ￥220, 000. 00 | 当前的房产市价 (更多的表现为房东的心理价位) |
| ②房屋交易价款 | ￥245, 000. 00 | 与买家商定的交易价格 (一般要比市价高出 10% 左右) |
| ③定金 | 5. 00% | 一般“以租代售”要交纳一部分定金，为交易价格②的 5% 左右。 |
| ④定金实际金额 | ￥12, 250. 00 | 由②×③得来 |
| ⑤租售年限 | 3 | 即合同有效期，同时也是租期。以 3 年为宜。 |
| ⑥租房押金 | ￥4, 000. 00 | 双方商定的押金。一般两个月租金即可，即为⑩×2 |

| ⑧市场平均租金 | ￥1, 500. 00 | 为市场同类房产的平均值。也可以看作该房产的过去租金额。 |

| ③到期后预付金合计（不包括押金） | ￥23, 400. 00 | 计算方法为⑩×⑤×12 |

| ⑤加上首付后收益合计 | ￥82, 450. 00 | 计算方法为④+④ |
| ⑥扣除预付金后房款（扣除租房押金与定金） | ￥203, 350. 00 | 计算方法为②一④一⑥一③ |
