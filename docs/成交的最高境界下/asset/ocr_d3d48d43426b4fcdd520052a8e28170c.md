# **第 43 课: 第四步骤 · 明确需求**

# **步骤 2: 还有其他的吗?**

这个步骤就是问客户，还有没有其他的需求没有说，你要找出来。“好，现在如果考虑采光的问题，你要的是一个楼间距大，能常年照射到阳光的房子是吗？”（详细列出需求确认）—“是的。”

“如果考虑交通问题，你要的是一个离地铁站很近的房子对吗？”（详细列出需求确认）—“对。”

前面已经做完详细列出需求的步骤，接着，下一句话就说：

“还有其他需求吗？”(**还有其他需求吗**)

答案只有两种，一种是没有，一种是还有。

![](bbox=[0.14, 0.61, 0.88, 0.75])

如果客户说还有，你不用紧张，因为这说明客户很渴望改变，他的需求很强烈，这是对我们有利的，你要让客户说出来还有什么没说清楚，然后你再列出来。
