# 第 41 课：第四步骤 · 明确需求

步骤 1：详细列出需求确认·问题是需求的前身

刚刚前面举的例子，是客户有一个需求或者两个需求，如果在前面你发现客户有三个问题，你就一个一个来确认，确认最好不要超过三次。

详细列出需求确认，就是把前面你找到的问题，以相反的角度来确认。

![](bbox=[0.15, 0.45, 0.89, 0.58])

+   - 问题是成本很贵，需求是要便宜实惠的。
- 问题是档次不够，需求就是档次要高。
- 问题是售后服务不好，需求就是要维修服务好。
- 问题是常常死机，需求就是要品质高。
- 问题是采光不足，需求就是要楼间距大的。
- 问题是离地铁远交通不便，需求就是要一个离地铁站近的。
- 问题是汽车常常故障，油耗很高，需求就是要品质好很省
