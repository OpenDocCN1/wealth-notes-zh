# **第 42 课：第四步骤·明确需求**

# **步骤 1：详细列出需求确认·实战案例 4**

现在把上一阶段连起来——“根据我的理解，你对物业服务费很高感觉到很吃力是吗？”（确认问题）“是的。”
“还有其他要注意的事吗？”（还有其他要注意的吗）
“没有了。”
“你希望解决这个问题吗？”（承诺改变）“希望。”
“你说的物业费问题，你现在要的是一个物业费低的，省钱的一个住所是吗？”（详细列出需求确认）—“是的。”

![](bbox=[0.15, 0.54, 0.88, 0.68])

这句话客户一定会回答的！因为前面已经摆明了，问题已经很明确了，客户已经说那个问题他不想要，已经自我承诺要改变，所以他的需求就是问题的另一面。另一面就是他追求的快乐。当客户说是，接下来下一句就是——还有其他的吗？
