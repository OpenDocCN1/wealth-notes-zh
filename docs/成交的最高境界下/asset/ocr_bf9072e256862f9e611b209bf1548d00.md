# 研究背景补充：实战案例 6

如果你要卖他的是旅行车，你应该怎么问？

“你家里一共有多少人啊？”

“一家三代都出去玩的时候，你们都坐什么车？”

他一定会告诉你说：“坐不下，很挤!”那怎么办？

坐公车，坐火车。于是你就有机会去介绍你的旅行车。

如果你要卖的是豪华的轿车，你该怎么问？

“你做生意的时候，客户看到你车的几率有多少次？”

“你觉得如果总是开一台普通的旅行车，越野车，对你的商务形象你觉得会有什么影响？”
