# 第 39 课：第四步骤 · 明确需求

# 步骤 1：详细列出需求确认 · 实战案例 2

比如一诺老师卖一台电脑，客户嫌他的电脑维修很费力气，维修服务不好，又经常死机。通过前面的背景探测，一诺老师找到了问题，也确认他要解决，现在要详细列出需求确认。

![](bbox=[0.16, 0.365, 0.88, 0.495])

“根据我的理解，你现在考虑换一台电脑的话，你要一个使用起来很稳定的，不死机、品质比较优良的电脑是吗？”（**详细列出需求确认**）——“是的。”

“还有你现在要的电脑，是还要能够在维修方面，能够及时维修，降低维修成本，甚至有免费维修服务，你要的是一个售后服务好的公司是吗？”（**详细列出需求确认**）——“是的。”

这就是详细列出需求确认。
