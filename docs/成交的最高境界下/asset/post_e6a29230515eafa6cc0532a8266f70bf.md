# 第 28 课：第二步骤·分析问题

### 研究背景阶段探测不出客户有问题怎么办？

在《成交的最高境界》课程上，有很多学员问：“一诺老师啊，请问您啊，我见过很多客户，我问他很多问题，可是不管我怎么问，客户的回答我看不出他有任何问题！问他什么，客户都是很好、很满意，当客户没有问题，我也不能去形成问题放大问题，请问一诺老师，我该怎么办呢？”

![](img/37f6f6df625cee17ef8fa27d99402eaa_113_0.png)

当我们在研究背景阶段探测不到客户的问题。

这种客户第一，要不就是不信任你、不想说实话给你听，他不想承认他有问题。

第二、也许他真的是对自己的现状很满意，或者他自己有问题他自己也不知道，在客户十大心理学当中，这种就是很典型的自我满足阶段的客户。

对于这两种客户不管是哪一种，一诺老师一句话就能化解。

# 一对一收钱《成交的最高境界·下》把话说出去,把钱收回来的能力!

像一诺老师刚刚问到汽车的时候，一诺老师也感觉好像他对现在的车已经很满意了，一诺老师再问下去也是很难找到他的问题的，还记得吗?

![](img/37f6f6df625cee17ef8fa27d99402eaa_114_0.png)

一诺老师问了一句：“开了这么久，你觉得哪一点还可以更好，哪里你觉得还可以改善？”(引导问题)

客户说：“档次不够高。”

如果一诺老师不直接来这一句，一诺老师还 可能继续问，也很难找到问题。

如果一诺老师直接问：

“你对目前的车有不满意的地方吗?”(X)

有的人会回答说出不满意的地方,但也有的人会说很满意，还不如直接问哪里可以改善?

这样任何人都会说出可以改善的地方，只要客户信任你，他不是刻意刁难你。

所以记住，当你问不出客户问题的时候，你就问他——

- “哪里可以改善？”
- “哪里可以提升？”
- “哪里可以更好？”

这是万能的一句话，当客户说出可以改善提升的地方，就是他不满意的地方，也就是他的问题痛点，然后你再把这个问

题深挖。

![](img/37f6f6df625cee17ef8fa27d99402eaa_115_0.png)

当有一天，你成为了—一诺老师的亲传弟子，我相信这一切

都不是问题！
