# 第 87 课：第八步骤·化解抗拒

# 化解客户抗拒的八个万能密码

如果你前面的流程做得非常好，找到了客户的问题，确认了需求，也了解了详细的定义，当你介绍完产品之后，你问客户：“这是你要的方案吗？”

![](bbox=[0.13, 0.36, 0.88, 0.5])

客户的回答只有两种，如果你前面的流程做得够好，第一、客户回答 YES，那这时候你就可以直接进入成交阶段。

如果流程做得不够好，第二，客户回答的是 NO，比如客户回答说不是，那怎么办？

很简单，你就问他为什么？

客户就会告诉你原因，或者客户直接回答你。比如，太贵了，这个不好，那个不好，我要考虑一下等等。

当客户出现这些抗拒，我们该怎么化解？
