# **第 28 课：第二步骤·分析问题**

# 研究背景阶段探测不出客户有问题怎么办？

在《成交的最高境界》课程上，有很多学员问：“一诺老师啊，请问您啊，我见过很多客户，我问他很多问题，可是不管我怎么问，客户的回答我看不出他有任何问题！问他什么，客户都是很好、很满意，当客户没有问题，我也不能去形成问题放大问题，请问一诺老师，我该怎么办呢？”

![](bbox=[0.14, 0.46, 0.87, 0.59])

当我们在研究背景阶段探测不到客户的问题。

这种客户第一，要不就是不信任你、不想说实话给你听，他不想承认他有问题。

第二、也许他真的是对自己的现状很满意，或者他自己有问题他自己也不知道，在客户十大心理学当中，这种就是很典型的自我满足阶段的客户。

对于这两种客户不管是哪一种，一诺老师一句话就能化解。
