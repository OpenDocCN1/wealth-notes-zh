# 分析问题 · 实战案例 5

为什么客户不回答你的问题？

在一诺老师课程上有很多学员问：“请问一诺老师，客户常常不回答我的问题，客户不配合我，请问这是为什么呢？”

一诺老师告诉我们，这其中有两个很重要的原因——

**第一、你没有和客户建立良好的信任**

客户的心门还是封闭的，你说什么客户都不相信你，他不 想回答你。

所以，你要注意自己的言谈举止，在客户面前一定要热情！ 懂得赞美客！认可客户！要站在客户的角度为他去着想！

让客户感觉到——你问他问题是想要帮他、是在关心他！

一诺老师经常教导我们，一定要有利他思维，否则客户感 觉你有目的性，就是想要赚他的钱！
