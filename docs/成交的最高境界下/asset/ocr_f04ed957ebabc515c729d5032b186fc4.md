# 一对一收钱《成交的最高境界·下》把话说出去,把钱收回来的能力!

问：顶层设计+商业模式梳理+训练团队。

在训练团队的时候，一诺老师知道要做整形费用还是比较高的，少的动个鼻子要一两万，大的整形要十几万，所以客户常常说太贵了，就这一问题就令他们的销售顾问很烦恼，很郁闷，老是被同样的问题拒绝。

常常抱怨对老板说：“我们的整形费用能不能再便宜一点，我很多客户本来就要做了，但是发现费用那么高，就说太贵了，不做了，让我损失那么多业绩。”

所以，这个公司的老板和员工的关系并不是很好，这也是老板很困惑的地方，一诺老师在训练他们团队的时候，就训练过他们如何化解这个问题？
