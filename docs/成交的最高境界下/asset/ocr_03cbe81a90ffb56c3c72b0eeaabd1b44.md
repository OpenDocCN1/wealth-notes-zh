# 第3课：第一步骤·研究背景

# 研究背景步骤 1：闲聊

当你见到客户之后一开始不要直接进入主题。

我见过非常多的老板，他想要去整合别人，想要让别人跟他合作，见到客户就说：“我们的项目非常好/公司非常好，有什么样的优势有什么特点，如果你成为我们的合作商你能有多大的好处。”这个老板讲了一大堆，最后客户说我再考虑一下。

![](bbox=[0.14, 0.45, 0.86, 0.58])

我见过无数个销售人员想要卖产品给客户，见到客户就说：“据我所知，贵公司的仪器效果不是很好，导致贵公司流失客户损失业绩，刚好我们公司的仪器效果非常好，美国进口的，让我来给你详细介绍一下。”

结果客户说我们不需要！然后客户想要赶他走，为什么会这样呢？
