# 研究背景步骤1：闲聊 2 兴趣爱好

一诺老师有一位弟子，他的企业一年也就可以做到六个亿。

大家都叫他李总，他做企业做了几十年，他的销售技巧非常厉害，几乎企业一些大的订单，大的合作商，优秀的人才，都是他成交的，他怎么会这么厉害呢？

每一次李总见到有意向的客户都不是直接讲解他的公司、他的事业，而是跟他们闲聊，当他发现客户很喜欢喝茶，他就陪客户喝茶，他发现客户喜欢喝酒，他就陪客户喝酒，他发现客户喜欢历史就聊历史。
