# 第 70 课：第八步骤·化解抗拒

# 化解抗拒前奏·预先化解抗拒

其实成交的十大步骤，如果在前面七个步骤做得非常好，从研究背景，到分析问题，一直到建议解答，整个流程做的都非常完美，事实上第八个步骤化解抗拒就不需要了。

为什么？因为真正的成交高手他懂得预先化解抗拒！

![](bbox=[0.14, 0.455, 0.86, 0.58])

高手知道在成交之前就埋下了很多伏笔！

在跟客户沟通的时候，预先就化解了抗拒，到成交的时候，其实客户已经没有抗拒了。

所以当你流程正确，步骤正确，发问的技巧正确，你是站在客户的角度，引导客户一起解决问题，你是利他的思维，为客户着想，成交是水滴渠成的事情，客户的抗拒就会很少。
