# 第 40 课: 第四步骤·明确需求

# 步骤 1: 详细列出需求确认·实战案例 3

再举一个案例，比如一诺老师卖汽车：“根据我的理解，你现在对你的本田汽车最不满意的地方，是它的档次还不够高，有碍你做生意是吗？” (确认问题)

“是啊。”

请问这一句话是在做哪一个**小步骤**？

千万别搞混了，这个问句是确认问题阶段。

现在是确认需求，要把问题转换成需求，继续往下。

“还有其他我要注意的吗？”(**还有其它要注意的**) 

“没有了。”

“你希望解决这个问题吗？” (**承诺改变**)

“希望。”

“好，如果考虑档次的问题，你现在是要一辆能代表你形象、地位、身份、品味的车子是不是？” (**详细列出需求确认**)

这一句话就是详细列出需求。
