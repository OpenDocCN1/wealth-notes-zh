# 化解客户抗拒的能力来自学习

在过去20年教育生涯中，一诺老师培训过很多人，一诺老师发现很可悲的是——大部分人明明知道化解客户抗拒很重要，但是真正用心去研究如何去化解客户抗拒的人很少！很少！

大部分的人，每天几乎都是被客户同样的问题难倒，这一次不会解答，下一次遇到同样的问题还是不会。

![](bbox=[0.13, 0.46, 0.87, 0.59])

就好像你每次在跟客户交手的时候，对方总是用左勾拳，但是你却不知道，这个左勾拳又要出来了，你又被左勾拳给打倒了，你觉得这种情况多不多！好不好笑？

所以这就是无数人变普通的原因！

根本就没去研究、没去琢磨、没去总结如何化解，每天下班之后宁可玩手机玩电脑，也不去研究销售。

一诺老师的实战知识来自于长期的阅读和学习习惯！一诺
