# 第 52 课：第六步骤 · 明确定义

如果客户不知道怎么回答你的定义怎么办？

一般情况下，你问客户需求的具体定义，只要你发问正确，95% 都能回答你。

只是有很少一部分人会回答得很模糊，如果客户回答得不清楚，这样是不行的。

![](bbox=[0.15, 0.4, 0.85, 0.55])

“你觉得怎样的房子才算是阳光充足呢？”（你是如何定义的）

“就是要阳光充足一点啊。”

假如客户的回答他自己都不清楚，这时候你可以自己说出来让他确认。

“如果一个房子南北通透，周围都没有挡的，一年四季可以照到充足的阳光，你觉得这是你要的吗？”“是的。”

客户说他要品质好的产品，你应该怎么问？
