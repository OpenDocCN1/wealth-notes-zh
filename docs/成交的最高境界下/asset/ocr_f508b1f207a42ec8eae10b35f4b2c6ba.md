# 第 2 课：第一步骤 · 研究背景

# 找对关键人物决策者

记住，跟你交谈的人除非决策者是他，否则我们没有必要浪费时间去研究。

![](bbox=[0.16, 0.33, 0.89, 0.49])

我们想想看，假如你是一名医生，有一天你帮一个大叔看病，大叔跟你讲，身体不舒服。

你说哪里不舒服？

他说胃不舒服，结果你照了半天发现没事啊。大叔说真的不舒服。你又照了半天真的没什么事啊，大叔说很痛，真的快要死掉了。

你对大叔说，你看起来没死啊。

大叔说，不是我，我是帮别人来看病的。请问如果你是医生你会不会继续给他看病？医生不看了，一定要叫本人来。

所以你就会发现，无数人都在犯这样低级的错误！
