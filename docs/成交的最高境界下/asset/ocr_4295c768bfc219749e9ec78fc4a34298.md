# 你的收入来自化解客户抗拒

在做销售的时候，客户常常会拒绝你！

一个不懂得化解客户抗拒的销售人员是，是没有办法赚大钱的，因为——

![](bbox=[0.16, 0.38, 0.89, 0.5])

你知道为什么那些在工厂上班的人，或者公司一些岗位一一像后勤人员、行政人员、客服人员，他们的收入通常比较固定，也很少有 机会赚大钱！为什么？

因为他们的工作不需要去化解客户的抗拒！

好处是——他们的工作没有风险、没有压力、只做好份内工作、收入比较稳定……所以呢，他们只能拿死工资！

同时也永远没有机会有高收入！一个月发多少薪水的权利，永远掌握在别人的手里！
