# 第 53 课：第六步骤 · 明确定义

明确定义步骤 2：有这样的你会选吗？

说这句话的目的就是——让客户对他所说的这些定义和条件做一个承诺。

![](bbox=[0.15, 0.33, 0.88, 0.48])

“我工作的时候，如果有一家公司满足你说的这些条件，你会加入吗？”（有这样的你会选吗）

“如果有一款产品能符合你说的这些条件，你会选吗？”

（有这样的你会选吗）

“如果有一个好的项目满足以上所有的条件，你会做吗？”

（有这样的你会选吗）

“如果有一笔生意符合你刚才说的这些条件，你会做吗？”

（有这样的你会选吗）

“如果有一栋房子符合你说的这些条件，你会考虑吗？”

（有这样的你会选吗）
