# 建议解答步骤2：建议方案确认

当你得到客户的确认之后，表示客户已经相信你了，接下来你再去塑造你的产品你的项目。

在《成交的最高境界》课程上，有人会问一诺老师：“一诺老师，那万一客户回答我不会那怎么办？”

那就表示客户对你这个人还不够信任，你只要问客户一句：“为什么？”

客户就会告诉你你拒绝你的原因，关于如何化解抗拒请参阅下一阶段，化解抗拒里面我会详解。
