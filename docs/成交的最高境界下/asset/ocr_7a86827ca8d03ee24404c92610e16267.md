# 塑造解决方案五大步骤 2：优点

什么是优点？优点就是你的产品、项目最大的特色和最大卖点！可能你的竞争对手很少有的，那就是你的优点，比如你卖的子房子优点是，视野特别好，绿化率特别大，是同类房子所不具备的，那需求和优点应该怎么做列顺序呢？

![](bbox=[0.14, 0.41, 0.88, 0.55])

比如客户想要的房子是阳光充足，离地铁站近，你就先讲客户的需求。我们的房子最大的特色就是——阳光充足离地铁站近，客户的需求要重点去塑造，然后你再讲房子的优点，视野特别好、绿化率特别大。

你的优点一带而过，作为一点红利，因为客户最在乎还是他的需求，假如客户拒绝你，你要重点反复讲客户的需求，还有要讲需求——前面的痛点问题去刺激他。
