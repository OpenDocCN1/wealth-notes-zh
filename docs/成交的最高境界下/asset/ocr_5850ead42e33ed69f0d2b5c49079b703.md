# 第 23 课: 第二步骤 · 分析问题

# 分析问题 · 问题要一个一个挖

在前面研究背景阶段，你要了解客户的信息要问很多问题，拿个探测器拿个听筒，探探探，东问一下、西问一下。

发现客户说功能有点少，维修成本贵，这是两个现象，你把它记在心里。

到了分析问题阶段，就把这两个现象引导成问题，再把这两个问题一个一个地深挖。

第一个问题形成问题再放大问题，然后第二个问题形成问题再放大问题。

如果你发现客户有三个问题，你也是一个一个地挖，最好是两个和三个问题，不要太多，要不客户觉得你啰嗦。
