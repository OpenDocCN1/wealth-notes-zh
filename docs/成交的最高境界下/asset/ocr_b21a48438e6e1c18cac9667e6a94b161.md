# **抗拒之七：我没有时间，我很忙**

比如你想让客户办理会员卡、健身卡、美容卡、英语学习卡，你想让客户报名你的舞蹈培训班等等。

凡是占用客户时间的，客户都会说我没时间，我很忙。

这个抗拒该怎么化解呢？

![](bbox=[0.08, 0.395, 0.91, 0.515])

不是，每个人的时间都是安排最重要的事情。

比如叫你现在去挖一个金矿，你会说自己没时间吗？

比如说你的梦中情人想约你去旅游，你会说自己没时间吗？

所以很多企业家不来学习，是因为没有看到课程的重要性和价值。
