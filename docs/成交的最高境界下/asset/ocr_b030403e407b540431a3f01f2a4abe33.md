# 研究背景补充：实战案例 4

如果一诺老师是卖 SPA 水疗小型机器的，应该问客户：

“你每次去美容院做 SPA 的时候都去哪家做，花多少钱？”

“一个月做几次啊！”

“哦，很麻烦啊！”

“如果你出差去外地不知道哪里有怎么办？”

![](bbox=[0.16, 0.45, 0.89, 0.59])

为什么一诺老师问这样的问题呢？

因为这样的问题可以引导出，“不方便、很昂贵、很多成本、浪费时间” 这样的话。

为什么一诺老师要让她说出这样的话呢？

因为一诺老师卖给她的机器是可以带着出差的，放在家里就可以做的，跟外面的有所不同，这是我产品的优势，所以问题就是答案。
