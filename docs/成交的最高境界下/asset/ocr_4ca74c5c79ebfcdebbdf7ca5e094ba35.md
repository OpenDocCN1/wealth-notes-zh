# 第二、你没有按照成交的流程来问话

客户不是不想回答你的问题！有的时候客户自己都不知道该怎么回答。

你的问话没有逻辑性，其实在背景探测的时候你就应该问出一些小问题，客户为什么不好意思回答你？因为你的问话顺序让他感觉不太合理，没有连贯性，不符合逻辑。

当你在背景探测的时候，都没有问出一些小问题，你就想直接进入分析问题阶段，你就想去形成问题，放大问题，你太快了。

![](bbox=[0.14, 0.52, 0.87, 0.65])

你没有按照成交的流程来，所以他就会不好意思回答你，有种被强迫的感觉。

就好像在前面有讲过的，警察不会在一开始就问嫌疑人犯：
“你有没有抽那个牌子的烟？”

嫌疑人通常都不敢承认。
