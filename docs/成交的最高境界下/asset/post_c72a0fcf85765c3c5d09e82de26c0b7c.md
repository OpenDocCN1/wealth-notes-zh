# 第 21 课：第二步骤·分析问题

### 什么是分析问题？

分析问题阶段是在研究背景阶段，你已经找到了客户的一些线索，发现了可能存在的一些小问题。

你再通过引导，让客户感觉到这是一个问题，然后让他意识到问题的严重性放大问题的痛苦。

这一阶段的重点就是让客户从认知不足阶段，快速走到决定改变的阶段。

因为客户不解决小问题，客户只解决大问题。

![](img/37f6f6df625cee17ef8fa27d99402eaa_84_0.png)

分析问题阶段有三个步骤：

- 一、引导问题
- 二、形成问题
- 三、放大问题

这三个步骤怎么理解呢？

讲到这里，一诺老师曾在课堂里给大家讲过一个故事：

在古代一个钉子造成一个国家的灭亡。

你看完这个故事你就知道这三个步骤怎么理解。

“把钉子钉入马蹄时，遇到了什么困难？”（引导问题）

“有些钉子会断掉。”

“钉子多久会松掉一次？”（形成问题）

“半年。”

“钉子掉了，对马蹄铁会有什影响？”（形成问题）

“马蹄铁会不稳定。”

“马蹄铁不稳定，马会怎么样？”（形成问题）

“马会乱跑。”

![](img/37f6f6df625cee17ef8fa27d99402eaa_85_0.png)

“马乱跑，马背上的人会怎么样？”（形成问题）

“人会摔伤。”

“人受伤了，如果他是送信的，信会怎么样？”（形成问题）

“信就会送不到。”

“如果军队少了一封很重要的信，会对战争造成什么影响？” **（放大问题）**

“军队会打败仗”

“军队打败仗了会对国家造成什么后果？” **（放大问题）**

“国家会灭亡”

这三个步骤是成交流程中非常重要的步骤，很多人都不懂这个，为什么客户常常拒绝你，说下次再说，我考虑考虑？

就是因为不懂这个技巧，客户感觉还不够痛，无所谓。

![](img/37f6f6df625cee17ef8fa27d99402eaa_86_0.png)
