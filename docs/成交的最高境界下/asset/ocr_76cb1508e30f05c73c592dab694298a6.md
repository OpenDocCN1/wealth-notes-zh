# 第 8 课：第一步骤 · 研究背景

# 研究背景步骤 2： 背景探测 2 别谈客户痛点

在这一阶段有的人会直接问客户：“贵公司的业绩做得怎样啊？贵公司产品效果好不好啊？贵公司在拓展市场的时候有遇到怎样的难题啊？生意好不好做啊？”

一旦你问出这样的问题，客户心里面就会想，我回答你好呢？还是不回答呢？

![](bbox=[0.14, 0.44, 0.87, 0.58])

回答你，是不是有答案在等着我？

你解决了我的问题，我待会是不是要向你买产品了？

我待会是不是要跟你合作了？

我待会是不是要刷卡了？

所以客户感觉到你问的这个问题是有目的的，太直接了，他就不想回答你，也不敢回答。

所以，这些问题不是说要问，而不是现在问！
