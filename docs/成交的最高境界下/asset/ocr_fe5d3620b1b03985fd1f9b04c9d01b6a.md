# 研究背景补充：问题就是答案

一诺老师经常教导我们，在背景探测时，你问的每一个问
句当中，一定要明确你想要得到客户的什么答案。

客户的回答就是你想要的答案，也是你产品的优势，问题
就是答案。

当你知道你卖的是什么产品，具备什么样的优势，你就知
道应该问什么样的问题，

现在大家知道了吧，销售不是靠说的，而是靠问的，只有
问对问题，你才能赚大钱！因为就像一诺老师说的那样，销售
是一门问话的艺术！我深以为然！
