# 第74课：第八步骤·化解抗拒

化解抗拒万能公式2：测试成交

“如果我能让价格便宜一点，你会买吗？”

“如果这个不是问题，你会跟我合作吗？”

“如果我能跟老板申请到优惠价，你会买吗？”

“如果我能……你就会……吗？”

![](bbox=[0.15, 0.42, 0.88, 0.55])

如果客户是钱的问题，客户说会，接下来你只需要去解决钱的问题就好了！

如果他说不会，表示钱不是问题，钱不是他的主要抗拒点，表示钱的抗拒是假的，客户是骗你的，或者客户还有其他的抗拒没有说出来，你就问他：

“你能告诉我，你还有什么问题，没有跟我说明白的吗？”

“你能告诉我，你还担心什么问题吗？”
