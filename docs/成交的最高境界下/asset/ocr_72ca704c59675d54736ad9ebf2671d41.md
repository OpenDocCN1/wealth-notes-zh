# **第 80 课：第九步骤 · 成交阶段**

**成交阶段四大步骤 4：**向客户保证

什么叫向客户保证？

大部分你的客户之前为什么这么难成交？

这么多步骤，尤其最难的是——

第一阶段：研究背景；

第二阶段：分析问题阶段。

为什么这两个阶段是最难的呢？

因为要通过客户最困难的第一个决定，我要不要解决问题，这是最难的！那一关没过，后面都不可能。

![](bbox=[0.15, 0.58, 0.87, 0.71])
