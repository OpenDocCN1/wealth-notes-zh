# 第 54 课：第六步骤 · 明确定义

# 如果客户说 NO 怎么办 1

曾经有弟子问一诺老师：如果我问客户，但是客户回答我 NO 怎么办？比如：

> “ 买房子的时候你会以这个为依据吗？”

> “ 我还要考虑一下。”

> “ 如果有这样的产品能符合这些条件，你会选吗？”

> “ 我还要再看看？”

> “ 如果有这样的生意符合你刚才说的，你会做吗？”

> “ 不一定。”

竟然不回答你 YES，遇到这种情况怎么办呢？

![](bbox=[0.14, 0.61, 0.88, 0.74])

如果你听到客户这样的回答，你就不要继续往下走，客户回答你 NO，你再怎么塑造产品的价值也是没用的，你继续往下等于是自找麻烦。
