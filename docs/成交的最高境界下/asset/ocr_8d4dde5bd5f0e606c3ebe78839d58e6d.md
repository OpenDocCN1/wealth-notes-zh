# 第65课：第七步骤·建议解答

塑造解决方案五大步骤 4：说明

什么是说明？当你介绍完一条优点比如：“我们公司的设备品质非常好，也就是说这样可以为你提高生产效率，降低维修成本，毕竟你说过你要的是一台品质优良的设备对不对？”（X）

“对”

客户听完这些话表面上他会对你讲：“对。”

其实他在心里面他会想这是真的吗？真的有用吗？真的品质这么好吗？他在心里会怀疑，你讲的这么多好处，到底是不是真的？

所以什么叫说明？

![](bbox=[0.15, 0.62, 0.86, 0.72])

说明就是很多人最喜欢的产品介绍的那些讲解，比如我们的产品含有氨基酸、高科技蛋白、ISO国际认证、纯天然、绿色、植物精华、无污染、全球网点、无副作用等等。
