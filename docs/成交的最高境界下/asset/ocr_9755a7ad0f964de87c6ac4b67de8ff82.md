# 一对一收钱《成交的最高境界·下》把话说出去,把钱收回来的能力!

像一诺老师刚刚问到汽车的时候，一诺老师也感觉好像他对现在的车已经很满意了，一诺老师再问下去也是很难找到他的问题的，还记得吗?

![](bbox=[0.16, 0.27, 0.9, 0.4])

一诺老师问了一句：“开了这么久，你觉得哪一点还可以更好，哪里你觉得还可以改善？”(引导问题)

客户说：“档次不够高。”

如果一诺老师不直接来这一句，一诺老师还 可能继续问，也很难找到问题。

如果一诺老师直接问：

“你对目前的车有不满意的地方吗?”(X)

有的人会回答说出不满意的地方,但也有的人会说很满意，还不如直接问哪里可以改善?

这样任何人都会说出可以改善的地方，只要客户信任你，他不是刻意刁难你。
