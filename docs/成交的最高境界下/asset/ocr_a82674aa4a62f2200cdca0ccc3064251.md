# 抗拒之一：价格太贵了 5 打击法

假如你的产品卖 2000，客户说贵。

我：“什么，2000 你都觉得贵，不会吧，看你不像拿不出 2000 的人啊，2000 现在这个社会能干嘛，也许你请人吃顿饭买 一件衣服就没有，可是你知道吗，只需要花 2000，就能让你的 全身细胞都健康，每天充满能量，你觉得好不好？相信我，我 都买了，你还不相信我吗，你学完会让你震撼的。”

![](bbox=[0.14, 0.49, 0.86, 0.63])

这套方法针对支配型性格的人，这种性格的人好面子，这 就是激将法，但其他性格的步态适用，要学会分辨客户的性格。
