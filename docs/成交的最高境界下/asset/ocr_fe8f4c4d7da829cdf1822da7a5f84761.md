# 第 1 课：第一步骤·研究背景

# 什么叫研究背景？

一个医生给病人看病，医生还没有给病人开药方之前，一定是先拿听筒听心跳，听脉搏，测温度，看瞳孔等等。

医生会问病人很多问题先诊断病因，各种查病的过程，一诺老师称为研究背景。

![](bbox=[0.16, 0.42, 0.9, 0.56])

所以我们在面对客户的时候，你要先研究一下，这个人身上到底有没有可以被你解决的问题？

就像拿一个探测器，在地上探探探，探出哪里有金矿，哞咩咩咩，你探出金矿了，你朝那个方向挖，你挖到底才能挖到金矿。

可是很可悲的是，很多人都没有探测到金矿的地点，就在那里挖矿，挖得非常辛苦，挖到最后什么也没挖着。
