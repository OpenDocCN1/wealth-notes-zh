# 抗拒之一：价格太贵了4 免费法

一诺老师问：“什么，2000 你都觉得贵？如果有一个免费  产品你想不想要？

客户说：“想”

一诺老师说道：“要不这样，你先交 2000，这套产品你先  拿回去用，如果你用完之后，要是感觉没效果，对你真的是没  有帮助，我自己私人掏腰包，我把 2000 退给你，如果你要把我  当朋友你就相信我一次，这套产品绝对会令你震撼的，你觉得  这样好不好？”

这套方法针对熟客或者朋友，语气要坚定，让客户相信你。
