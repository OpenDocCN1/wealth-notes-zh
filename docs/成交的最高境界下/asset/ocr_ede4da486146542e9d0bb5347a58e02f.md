# **也就是说……因为……毕竟你说过……**

![](bbox=[0.14, 0.18, 0.87, 0.31])

讲客户前面承诺过的需求，因为你会讲这三点，都是因为客户告诉你的，所以，产品介绍最厉害的地方就是——提醒客户这是他说，不是我说的。

所以，客户不断地说——是啊、对啊。

产品介绍的时候你只需要不断地让客户点头，说是、好、喔、哇、想、对。

如果有的人没有学透，他没有完全弄懂整个成交的流程，他直接就说：“毕竟你说过景观优美对你很重要是吗？”

客户说我没说过啊！

为什么会这样？

因为你在前面没有问出客户的问题、需求、定义、承诺，你就直接来个毕竟你说过，你就会遇到客户的抗拒，明白了吗？

所以成交是一门大学问，这本《成交的最高境界》是汲取
