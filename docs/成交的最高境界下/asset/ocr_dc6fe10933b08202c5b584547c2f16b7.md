# 塑造解决方案五大步骤 3：利益

什么是利益呢？

利益是对客户的好处。

比如有很多公司都会有一些专有的名词，比如说我们的产品含有氨基酸，高科技蛋白、纯天然、绿色、ISO 国际认证、无污染、纯植物精华、科学证明、全球网点，还有一些什么复合配方、无副作用等等。

这些词一般都是很多人很喜欢讲的，很多公司也是这样教的。可是很多客户一般都听不懂啊！
