# 第 51 课：第六步骤・明确定义

明确定义步骤 1：你是如何定义的？

比如你想要成交投资者把钱投资给你，该怎么说？

详细列出需求确认：

“你要的是投资额度少，回报率高，风险比较低的项目是吧？”（详细列出需求确认）“是的。”

“还有其他的吗？”（还有其他的需求吗）—“没有了。”

“哪一个排第一，哪个第二，哪个第三？”（哪一个对你最重要）

“风险排第一，投资额度第二，回报率第三。”
