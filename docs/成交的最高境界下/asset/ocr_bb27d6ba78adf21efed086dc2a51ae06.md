# 第 92 课：化解抗拒

# 抗拒之一：价格太贵了 3 对比亚法三招

什么叫产品对法，也就是说客户的头脑里面，根本不搞清楚你的产品到底贵多少，或者说他想要花多少钱买，或者说你的产品为什么会这么贵，他都不清楚，他很模糊！

![](bbox=[0.15, 0.37, 0.88, 0.51])

所以要怎么办呢？

给你分享一个，一诺老师给美容整形企业做顾问设计话术的案例，化解价格太贵第二种方法，这个方法有三招。

# 第一招、你跟什么比

比如我是销售顾问，客户说：“整形费用太贵了。”

我说：“你跟什么比？”

客户说：“我以前在我家楼下的街上一家美容店问过，把鼻子垫高一点他们只需要 7000 块，而你们这边要两万多，太贵了。”
