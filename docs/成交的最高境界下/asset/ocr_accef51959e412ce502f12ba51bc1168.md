# 五、提出没有被满足的需求的解决方案

“刘姐，如果有一款产品也是国际品牌效果非常好价格实惠，而且美白，抗衰老祛斑效果都比欧莱雅好，你有没有兴趣想了解一下呢？”为什么这句话要这样讲？

第五招的意思就是，我有产品能符合你现在产品所拥有的123，而且还能满足你现在产品所不具备的ABC。

当客户听完之后一定会说，那你说说看是什么新产品。于是这时候，你再去介绍产品。

这些方法只要你把它学透，不管你做什么行业卖什么产品，其实原理都是一样的，你要做的就是把它融会贯通，根据这些方法去设计出适合你公司的话术，当然要做到这一点并不容易，不会设计的，可以请教一诺老师。
