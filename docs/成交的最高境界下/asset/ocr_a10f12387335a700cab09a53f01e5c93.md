# 抗拒之五：我到时候再买

很多客户常常会告诉你：到时候我再买，我过两天再来买，我下个月再来买，半年后我再买。

这些“到时候我再买”的抗拒该怎么化解呢？

首先，你要先确认客户是不是真的到时候就要买？

是客户真的有一些原因还是说是骗你的？

如果是真的，你能够让他现在就买！如果不是的话，要套出真相，找出真正抗拒的原因，确认是真的，我们再米化解。
