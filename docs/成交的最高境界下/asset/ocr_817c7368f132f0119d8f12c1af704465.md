# 抗拒之九：我不相信产品有效果

当客户说他不相信产品的效果的时候，很多人都会说我们的产品效果很好，产品有什么成分，有什么功能，价格多低，你说一大堆，客户还是不相信。

现在我把一诺老师的方法分享给大家，教你怎么化解，很简单用讲故事的方法去化解——通过一个故事去证明。
