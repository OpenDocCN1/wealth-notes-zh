# 成交阶段四大步骤 3：要求选择

什么叫要求选择？

当讨论完售后支援之后，客户已经回答了你的问题，表示他已经默认要买了。

要求选择这个步骤，就是要求客户付款！

要求客户现在做一个选择，不管客户选哪一个，都是确定要成交的，在这个步骤一定要用封闭的问题，二选一的问题。

这句话就是一个成交动作。
