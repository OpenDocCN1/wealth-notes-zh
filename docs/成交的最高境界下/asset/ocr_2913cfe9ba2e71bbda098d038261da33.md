# 化解抗拒万能公式 3: 解释并确认

解释就是——确认客户的真正的抗拒之后，再来解答，一定要找到真的抗拒。

> （关于解释，化解抗拒的话术在后面一个章节中，有专门详解的化解方法）

解释就是化解抗拒的话术，确认是当你讲完之后，比如客户说太贵了，当一诺老师解释完之后，一诺老师最后来一句：

> “你还有其他的问题吗？”

> “你还有其他的疑问吗？”
