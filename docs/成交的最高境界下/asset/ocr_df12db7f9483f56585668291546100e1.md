# 第 46 课：第五步骤 · 排列顺序

# 注意区别问题和需求

有很多人学到这一段的时候，经常会问一诺老师：“一诺老师啊，道理是没错，可是我很容昜混淆这两个阶段，好像感觉确认问题和详细列出需求确认很像。”

问话的语句好像把之前的重温一遍。

其实不是这样的，这说明你还没有真正融会贯通！

![](bbox=[0.15, 0.45, 0.88, 0.58])

比如我们再来看看卖房子：“阳光不充足和地铁太远的问题，让你感觉很困扰是吗？”（确认问题）—“是的。”

“还有其他的问题吗？”（还有其他问题吗）

“没有了。”

“你希望改变这种状况吗？”（承诺改变）

“希望。”

“那你现在想要的是一 个阳光很充足的房子，是不是？”
