# 第 30 课：第三步骤 · 确认承诺

# 什么是确认承诺阶段？

在前面分析问题阶段，我们已经找到了客户的问题，放大了客户的问题，客户已经意识到了问题的严重性，但客户并没有说他要解决他的问题，他也没有说他想要听你的解决方案。

在这一阶段，我们要让客户自己说出来，他要解决他的问题，在这一阶段就是——客户的十大心理，对应决定改变阶段。

![](bbox=[0.16, 0.44, 0.86, 0.57])

客户从认知不足到决定改变，我们要做的就是确认他真的要改变，我们要得到客户的承诺，得到客户的允许，然后客户才有兴趣、有耐心听你讲解产品。

确认承诺有三个步骤：

+   一、确认问题。二、还有其他要注意的吗？三、承诺改变！
