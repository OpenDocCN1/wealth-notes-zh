# 第29课：第二步骤·分析问题

做好记录，为下次做好准备

如果你发现在分析问题阶段，实在是找不到客户的问题，客户真的是对他现在所使用的产品，没有任何的缺点，你问他哪里还可以改善？他说对他的现状很满意，他对你的产品根本没有任何的需求。

这种客户就是全球为数不多的自我满足阶段！

当你发现客户是处在这种阶段，你向他介绍你的产品也是没有意义的，所以遇到这种人该怎么办？

![](bbox=[0.16, 0.53, 0.88, 0.66])
