# 研究背景步骤 2：背景探测

什么叫背景探测？

背景探测就是了解客户的背景信息。

用发问的技巧找到客户可能存在的一些小问题，以这些小问题为切入口。

背景探测就是——对应客户十大心理学的第一阶段，自我满足阶段，让客户从自我满足到认知不足。
