# 第 32 课：第三步骤 · 确认承诺

确认承诺步骤 2：还有其他要注意的吗？

接下来第二步：还有其他要注意的事吗？

> “还有其他要注意的吗？ ”（还有其他要注意的吗？）

> “没有。”

当你问客户这一句话的时候，你的目的是——看看客户有没有其他没有被问到，没有被发现的问题。

如果客户说没有，表示你已经确认他，没有其他的问题了，你就继续下面的步骤。

![](bbox=[0.14, 0.53, 0.87, 0.68])
