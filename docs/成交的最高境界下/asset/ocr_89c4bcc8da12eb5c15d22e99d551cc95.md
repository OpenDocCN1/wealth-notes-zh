# 第 56 课：第六步骤 · 明确定义

# 客户说 NO 的三大原因

为什么客户会说 不，有三种原因。

# 第一、你还没有列清楚客户的需求

你要记住，即使客户说不会，那也不代表客户是拒绝你，你也不要担心，客户拒绝的是——他还有一些没有列清楚的需求，他还有遗漏的地方没有讲出来，他并没有拒绝你，你的工作就是确认他没有讲出来的，然后再确认一次就好了。

# 第二、客户还有其他的问题

就算真的是客户拒绝你，那你现在就要知道，总比到后面拒绝你更好，为什么？

因为他有问题不跟你讲，到后面你花那么多时间介绍产品，介绍完了之后他还是拒绝你！
