# 研究背景步骤2：背景探测 4 背景探测文化技巧

20年前，一诺老师的一位亲传弟子介绍了一个顾问案，这个顾问案的公司是做美容仪器的，公司老板叫马总，有一天马总通过助理跟一诺老师约了电话——

电话里说：“请问一诺老师，我们公司的销售员每天工作都没状态，业绩也不太好，有一些销售人员都辞职了，您可不可以来给我们训练一下团队？”

![](bbox=[0.14, 0.49, 0.85, 0.63])

一诺老师在电话里了解了公司的一些信息和现状，一诺老师发现——原来很多销售人员在做销售的时候根本就没有一套成交流程，不懂得正确的销售技巧，也不知道该问客户什么问题，该聊什么话题。

因为以前没有接受过专业的销售技巧老师的训练，有的也只是讲一些理论不够实战，导致销售人员每天在用错误的方法
