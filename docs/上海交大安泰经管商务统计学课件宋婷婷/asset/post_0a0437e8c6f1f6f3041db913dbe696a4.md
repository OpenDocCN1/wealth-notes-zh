
## The Procedure

- Rank the combined data from the lowest to highest values; the tied values are assigned the average rank
- Sum the ranks for each sample
- We use the sum of the ranks for sample 1 as the test statistic W

## Sampling Distribution

- It can be shown that
- $\mu_W = \frac{1}{2} n_1 (n_1 + n_2 + 1), \qquad \sigma_W = \sqrt{\frac{1}{12} n_1 n_2 (n_1 + n_2 + 1)}$
- For large samples (i.e., $n_1 \ge 7$ and $n_2 \ge 7$), we can use normal approximation.
- In our example, $n_1 = 12$, $n_2 = 10$, $\mu_W = 138$, $\sigma_W = 15.1658$, so the p-value
- $p\text{-value} = 2 \times P\left(N(0,1) \ge \frac{169.5 - 0.5 - 138}{15.1658}\right) = 0.0378 < \alpha$
- and we reject $H_0$.

## Wilcoxon Signed-Rank Test

- The Wilcoxon signed-rank test is a procedure for analyzing data from a matched samples experiment.
- The test uses quantitative data but does not require the assumption that the differences between the paired observations are normally distributed.
- It only requires the assumption that the differences have a *symmetric* distribution.
- This occurs whenever the shapes of the two populations are the same and the focus is on determining if there is a difference between the two populations’ medians.

## Example

- A manufacturing firm is attempting to determine whether two production methods differ in terms of task completion time.
- The hypotheses:
  - H₀ : medianₐ = medianᵦ, versus Hₐ : medianₐ ≠ medianᵦ
- The level of significance is set to be α = 0.05.
- 11 randomly selected workers completed the production task two times, once using method A and once using method B.
- The method that the worker used first was randomly selected.

## The Procedure

- Discard the differences of 0 and compute the absolute differences
- Rank the absolute differences; for tied values, each is assigned the average of the ranks
- Compute the sum of the positive signed ranks, $T^+$

## Kruskal-Wallis Test

- The Mann-Whitney-Wilcoxon test has been extended by Kruskal and Wallis for cases of three or more populations.
- The Kruskal-Wallis test can be used with ordinal data as well as with interval or ratio data.
- Also, the Kruskal-Wallis test does not require the assumption of normally distributed populations.
