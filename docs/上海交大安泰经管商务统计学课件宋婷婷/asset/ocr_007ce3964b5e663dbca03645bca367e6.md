# Multiple Comparisons Procedure

+   - When rejecting $H_0$, how to determine where the differences between population proportions exist?
+   - We can use a multiple comparison procedure known as the **Marascuilo Procedure**.
+   - First, compute the three sample proportions.

BYD Han: $\bar{p}_1 = 69/125 = 0.5520$

Toyota Camry: $\bar{p}_2 = 120/200 = 0.6000$

Tesla M3: $\bar{p}_3 = 123/175 = 0.7029$

+   - Then compute the absolute value of the pairwise difference.

Han and Camry: $|\bar{p}_1 - \bar{p}_2| = |0.5520 - 0.6000| = 0.0480$

Han and M3: $|\bar{p}_1 - \bar{p}_3| = |0.5520 - 0.7029| = 0.1509$

Camry and M3: $|\bar{p}_2 - \bar{p}_3| = |0.6000 - 0.7029| = 0.1029$
