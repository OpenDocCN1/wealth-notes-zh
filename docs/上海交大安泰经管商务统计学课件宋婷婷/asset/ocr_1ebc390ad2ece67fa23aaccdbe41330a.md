# Step 5: Arrive at the decision.

+   - The conclusions are not always correct because they are drawn based on random samples.
+   - Two types of errors
+     - Type I error: Rejecting H₀ when it is true (False positive, 均质性)
+     - Type II error: Accept H₀ when it is false (False negative, 均质性)

| | Population Condition | |
| | H₀ True | Hₐ True |
| Conclusion | Accept H₀ | Correct | Type II Error |
| | Reject H₀ | Type I Error | Correct |
