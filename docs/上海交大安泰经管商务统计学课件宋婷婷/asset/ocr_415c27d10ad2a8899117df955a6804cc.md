# Critical-Value Approach

+   - We first specify a critical value for the test statistic.

+   - The critical value serves as a benchmark for determining whether the value of test statistic is small (or large) enough to reject.

+   - Given the critical value c, the rejection region is (−∞, −c] ∪ [c, ∞).

+   - How to determine c to achieve a significance level of α?
+     Significance level = P(Reject H₀|H₀) = P(|z| ≥ c|H₀) = 2Φ(−c) = 2Φ̄(c)

+   - The significance level α is achieved by letting c = zα/2 = Φ⁻¹(α/2).
