# Interval Estimation of Variance and Standard Deviation

+   - Denote \(\chi^2_{(1-\alpha)}\) to be the \(\alpha\)-quantile of the chi-square distribution
+   
+   - Then there is a \((1-\alpha)\) probability such that
+   
+     \[
+     \chi^2_{(1-\alpha/2)} \leq \frac{(n-1)s^2}{\sigma^2} \leq \chi^2_{\alpha/2}
+     \]
