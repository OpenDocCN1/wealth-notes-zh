# p-Value Approach

+   - P-value provides additional information: the strength of the rejection or not to rejecting.

+   - p-value: the probability of observing a sample value as extreme as, or more extreme than, the value observed, given that H₀ is true.
+   
+     p-value = P(|z| ≥ |z_obs| | μ = μ₀).

+   - In the statistical test, the p-value is used as a measure of the evidence against H₀ provided by the sample.

+   - Smaller p-values indicates more evidence against the null hypothesis.

+   - Step 5: The rejection rule using the p-value approach is to
+   
+     reject H₀ : μ = μ₀, if p-value ≤ α.
