## Summary of Testing About Two Population Variance

|  | One-tailed Test | Two-tailed Test |
|---|---|---|
| **Hypotheses** | $H_0: \sigma_1^2 \leq \sigma_2^2$  $H_a: \sigma_1^2 > \sigma_2^2$ | $H_0: \sigma_1^2 = \sigma_2^2$  $H_a: \sigma_1^2 \neq \sigma_2^2$ |
| **Test Statistic** | $F = \frac{s_1^2}{s_2^2}$ | $F = \frac{s_1^2}{s_2^2}$ |
| **Rejection rule: Critical value approach** | Reject $H_0$ if $F \geq F_{\alpha}(n_1-1, n_2-1)$ | Reject $H_0$ if $F \geq F_{\alpha/2}(n_1-1, n_2-1)$ |
| **Rejection rule: p-value approach** | Reject $H_0$ if p-value $\leq \alpha$ | Reject $H_0$ if p-value $\leq \alpha$ |

## Testing the Equality of Population Proportions

Three or More

- Using the notation

$p_i =$ population proportion for population $i$

### 1. State the Hypotheses: the equality of population proportions when $k \ge 3$ are as follows:

$H_0: p_1 = p_2 = \cdots = p_k$
$H_a:$ Not all population proportions are equal

- Fail to Reject: If $H_0$ cannot be rejected, we cannot detect a difference among the $k$ population proportions.
- Reject: If $H_0$ is rejected, we can conclude that not all $k$ population proportions are equal.
- Further analyses can be done to conclude which population proportions are significantly different from others.

## Construct Test Statistics

Expected Frequencies

- If $H_0$ is true, how many BYD Han owners would you expected to indicate a ‘Yes’?
- If $H_0: p_1 = p_2 = p_3$ is true, the best estimate of the proportion in the overall sample proportion $\hat{p} = 312/502 = 0.624$.
- Therefore, we would expect $0.624 \times 125 = 78$ BYD Han owners to indicate they are likely to repurchase the Han.

- In general, the expected frequencies under the assumption $H_0$ is correct

$$e_{ij} = \frac{(\text{Row } i\text{ Total})(\text{Column } j\text{ Total})}{\text{Total Sample Size}}$$

- If a significant difference exists between the observed and expected frequencies, $H_0$ can be rejected.

## Construct Test Statistics

Chi-Square Test Statistic

- The test procedure for comparing the observed frequencies with the expected frequencies involves the computation of the following chi-square statistic:

χ² = Σᵢ Σⱼ (fᵢⱼ - eᵢⱼ)² / eᵢⱼ,

where

fᵢⱼ = observed frequency for the cell in row i and column j
eᵢⱼ = expected frequency for the cell in row i and column j

- The test statistic has a chi-square distribution with k − 1 df.
