# Point Estimation

+   Typical point estimators (点估计量) are shown as follows.

| | Population Parameter | Point Estimator | Statistic |
|---|---|---|---|
| Mean | μ | x̄ | Σx_i / n |
| Variance | σ² | s² | Σ(x_i - x̄)² / (n-1) |
| Proportion | p | p̄ | x / n |
