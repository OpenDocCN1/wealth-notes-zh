## Goodness of Fit Test: Normal Distribution

- We can also use the chi-square test to conduct goodness of fit test for a normal distribution.
- **Basic idea**: continuous-valued sample data ⇒ discrete categories.
- In our example, we can divide the normal distribution into 10 equal-probability intervals (with sample size = 50, expected frequency in each interval is 5).

![](img/ea9cdfad8dc7821ead4e68fc7aaa5ca3_257_0.png)

- How to determine the endpoints of these intervals?
- In general, define *k* intervals of values so that the expected frequency is at least 5 for each interval.
- Compute the value of the test statistic.

$$\chi^2 = \sum_{i=1}^{k} \frac{(f_i-e_i)^2}{e_i}$$

**Note:** The test statistic has a chi-square distribution with *k − p − 1* df, where *p* is the number of parameters estimated by the sample. In our example, *p = 2*.

- **Rejection rule:**
  - *p*-value approach: Reject $H_0$ if *p*-value ≤ α.
  - Critical value approach: Reject $H_0$ if $\chi^2 > \chi^2_{\alpha,k-p-1}$.

## Summary of Chi-Square Tests

- We have introduced several hypothesis tests based on chi-square distribution.
- Test statistic:
  - χ² = Σ (Observed Frequency − Expected Frequency)² / Expected Frequency
- Degrees of freedom:
  - (1) Testing the equality of population proportions for k populations (d.f. = k − 1)
  - (2) Testing the independence of two categorical variables (d.f. = (n − 1)(m − 1))
  - (3) Testing whether a probability distribution for a population follows multinomial distribution (d.f. = k − 1) or normal distribution (d.f. = k − 3)
