# Test of Independence

+   Compute the value of the test statistic.

```
χ² = Σ_i Σ_j (f_ij - e_ij)² / e_ij
```

Note: When there are n rows and m columns, the test statistic has a chi-square distribution with (n − 1)(m − 1) df provided that the expected frequencies are 5 or more for all categories.

+   Rejection rule:

+   p-value approach: Reject H0 if p-value ≤ α

+   Critical value approach: Reject H0 if χ² > χ²_{α,(n-1)(m-1)}
