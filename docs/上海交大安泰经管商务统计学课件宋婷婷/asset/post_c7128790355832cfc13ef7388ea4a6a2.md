
## Test with Binomial Distribution

- There are 7 “+” out of 10 samples. Suppose we want to use significance level α = 0.1, what is the p-value?

- Suppose H0 is true, then X ~ B(n,0.5) with n = 10

- p-value = 2 × P(X ≥ 7) = 2 × Σ_{k=7}^{n} C(n,k) 0.5^n = 0.3438 > α

- Therefore, we cannot reject the hypothesis that the population median is 450.

## Test with Normal Approximation

- When the sample size $n$ is large, we can use normal approximation to simplify the computation.
- Since $\mu_X = 0.5n$, $\sigma_X = \sqrt{0.25n}$, then for large $n$

$$Z := \frac{X - 0.5n}{\sqrt{0.25n}} \sim N(0,1)$$

- When the sample size n is large, we can use normal approximation to simplify the computation.
- Since μ_X = 0.5n, σ_X = √0.25n, then for large n
$$Z := \frac{X - 0.5n}{\sqrt{0.25n}} \sim N(0,1)$$
- With the normal approximation, the rejection rule is obtained.
  - Critical value approach:
    reject H₀ if |Z| ≥ z_{α/2}.
  - p-value approach:
    reject H₀ if p-value = P(|N(0,1)| ≥ |Z|) ≤ α.

## Mann-Whitney-Wilcoxon Test

- This test is another nonparametric method for determining whether there is a difference between two populations.
- This test is based on two independent samples.
- Advantages of this procedure are
  - It can be used with either ordinal data or quantitative data
  - It does not require the assumption that the populations have a normal distribution
- Instead of testing for the difference between the medians of two populations, this method tests to determine whether the two populations are identical (两个总体相同)
