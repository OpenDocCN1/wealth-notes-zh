# Sampling Category

Probability sampling: The element in population has an equal chance of getting sampled.

+   - Simple random sampling (简单随机抽样)
+   - Stratified random sampling (分层随机抽样)
+   - Cluster sampling (整支抽样化聚簇抽样)
+   - Systematic sampling (系统)

Non-probability sampling (非概率): The element in population is based on the subjective judgment or convenience of the researcher rather than random selection.

+   - Convenience Sampling: by convenience
+   - Judgment Sampling: by expertise
