
## Hypothesis Testing for Two Population Means

- In general, there are 3 forms of hypothesis testing:
  - **Two-tailed test:**
    \(H_0: \mu_1-\mu_2=D_0,\quad\text{versus}\quad H_a: \mu_1-\mu_2\ne D_0.\)
  - **Upper-tailed test:**
    \(H_0: \mu_1-\mu_2\le D_0,\quad\text{versus}\quad H_a: \mu_1-\mu_2>D_0.\)
  - **Lower-tailed test:**
    \(H_0: \mu_1-\mu_2\ge D_0,\quad\text{versus}\quad H_a: \mu_1-\mu_2<D_0.\)

If we want to test whether there is any difference between the mean ages of the two computer populations, how to formulate the hypotheses?

### Two Population Means when Variances are Known

Consider the two-tailed hypothesis test

- Step 1: State the hypotheses

  \(H_0: \mu_1 - \mu_2 = D_0\)   versus   \(H_a: \mu_1 - \mu_2 \ne D_0\).

- Step 3: **We need a test statistic whose distribution is known under \(H_0\).**

When \(\sigma_1^2, \sigma_2^2\) are known, the test statistic is specified by

\[
z = \frac{\bar{x}_1 - \bar{x}_2 - D_0}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}}.
\]

Step 4: Under \(H_0\), we have \(z \sim N(0,1)\). Therefore, the decision rule of Z-test will be used.

### Test Procedure when \(\sigma_1^2, \sigma_2^2\) are Known

- The test statistic is the same, but the rejection regions are not.
- The p-values are also different.
  - Two-tailed test: p-value = \(P(\lvert z\rvert \ge z_{\text{obs}} \mid \mu_1-\mu_2=D_0)\)
  - Upper-tailed test: p-value = \(P(z \ge z_{\text{obs}} \mid \mu_1-\mu_2 \le D_0)\)
  - Lower-tailed test: p-value = \(P(z \le z_{\text{obs}} \mid \mu_1-\mu_2 \ge D_0)\)

|  | Two-tailed Test | Upper-tailed Test | Lower-tailed Test |
|---|---|---|---|
| **Hypotheses** | \(H_0: \mu_1-\mu_2=D_0\)<br>\(H_a: \mu_1-\mu_2\ne D_0\) | \(H_0: \mu_1-\mu_2\le D_0\)<br>\(H_a: \mu_1-\mu_2>D_0\) | \(H_0: \mu_1-\mu_2\ge D_0\)<br>\(H_a: \mu_1-\mu_2<D_0\) |
| **Test Statistic** | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) |
| **Rejection rule: Critical value approach** | Reject \(H_0\) if \(\lvert z_{\text{obs}}\rvert\ge z_{\alpha/2}\) | Reject \(H_0\) if \(z_{\text{obs}}\ge z_\alpha\) | Reject \(H_0\) if \(z_{\text{obs}}\le -z_\alpha\) |
| **Rejection rule: p-value approach** | Reject \(H_0\) if p-value \(\le\alpha\) | Reject \(H_0\) if p-value \(\le\alpha\) | Reject \(H_0\) if p-value \(\le\alpha\) |

### Two Population Means when \(\sigma_1^2 = \sigma_2^2\) are Unknown

- In practice, the population variances \(\sigma_1^2\) and \(\sigma_2^2\) are often unknown.
- For point estimation, we can still use \(\bar{x}_1-\bar{x}_2\).
- However, for interval estimations and hypothesis testing, we need to estimate its standard error \(\sigma_{\bar{x}_1-\bar{x}_2}=\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}\).
- Basic idea: use sample variances to estimate population variances, and use t distribution instead of normal distribution.
  - When \(\sigma_1^2=\sigma_2^2\), it works
  - When \(\sigma_1^2\ne\sigma_2^2\), it works approximately

### Test Procedure when \(\sigma_1^2=\sigma_2^2\) are Unknown

- A weighted average of \(s_1^2\) and \(s_2^2\), called the **pooled estimator** is used,

\[
s_p^2=\frac{n_1-1}{n_1+n_2-2}s_1^2+\frac{n_2-1}{n_1+n_2-2}s_2^2
=\frac{\sum_{i=1}^{2}(n_i-1)s_i^2}{\sum_{i=1}^{2}(n_i-1)}.
\]

- The t-test statistic then follows a t distribution with \((n_1+n_2-2)\) df

\[
t=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{s_p^2(1/n_1+1/n_2)}}\sim t_{n_1+n_2-2},\quad\text{under }H_0.
\]

- Test procedure works as follows.
  - Critical-value approach: reject \(H_0\), if \(\lvert t_{\text{obs}}\rvert\ge \lvert t_{\alpha/2}\rvert\).
  - p-value approach: reject \(H_0\), if p-value \(=P(\lvert t\rvert\ge \lvert t_{\text{obs}}\rvert \mid H_0)\le\alpha\).

### Two Population Means when \(\sigma_1^2 \ne \sigma_2^2\) are Unknown

- Next assume the population variances \(\sigma_1^2 \ne \sigma_2^2\) are unknown.
- Step 1: Consider the two-tailed hypothesis test

  \(H_0: \mu_1 - \mu_2 = D_0 \quad \text{versus} \quad H_a: \mu_1 - \mu_2 \ne D_0\).

- Step 3: The \(t\)-test should be used and the corresponding \(t\)-test statistic is

  \[
  t = \frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}}.
  \]

- Even under \(H_0\), the distribution of \(t\) is **not known**. Why?
- A Student \(t\)-distribution approximation for \(t\) statistic is constructed as

  \[
  t \sim t_{df}, \quad \text{under } H_0,
  \]

  where

  \[
  df = \frac{(s_1^2/n_1+s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1}+\frac{(s_2^2/n_2)^2}{n_2-1}}.
  \]
