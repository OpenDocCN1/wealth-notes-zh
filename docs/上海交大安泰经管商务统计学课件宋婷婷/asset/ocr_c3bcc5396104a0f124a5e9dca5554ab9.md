# Relationship with Interval Estimation

+   - For normal population with σ known, the (1 − α)% confidence interval for μ is given by
+   
+     \[
+     \bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}
+     \]

+   - We know that (1 − α)% of the confidence intervals generated will contain the population mean

+   - Therefore, we can also use confidence interval to conduct a two-tailed test $H_0: \mu = \mu_0$ versus $H_1: \mu \ne \mu_0$
+     - Select a simple random sample and develop the (1 − α)% confidence interval
+     - If it contains the hypothesized value $\mu_0$, do not reject $H_0$; otherwise, reject $H_0$.
