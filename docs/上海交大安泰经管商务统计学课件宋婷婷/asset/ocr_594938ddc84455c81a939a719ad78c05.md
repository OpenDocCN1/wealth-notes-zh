# Example: Reed Manufacturing – Fisher’s LSD Procedure

+   - LSD for Plants 2 and 3
+     - Hypotheses (C)
+       H₀: μ₂ = μ₃
+       Hₐ: μ₂ ≠ μ₃
+     - Rejection Rule
+       Reject H₀ if |x̄₂ − x̄₃| ≥ 6.98
+     - Test Statistic Rule
+       |x̄₂ − x̄₃| = |68 − 57| = 11
+     - Conclusion
+       The mean number of hours worked at Plant 2 is not equal to the mean number worked at Plant 3.

Hypotheses (C)

H₀: μ₂ = μ₃
Hₐ: μ₂ ≠ μ₃

Rejection Rule

Reject H₀ if |x̄₂ − x̄₃| ≥ 6.98

Test Statistic Rule

|x̄₂ − x̄₃| = |68 − 57| = 11

Conclusion

The mean number of hours worked at Plant 2 is not equal to the mean number worked at Plant 3.
