# Summary of Nonparametric Tests

| Nonparametric Test | What It Does | Parametric Counterpart |
|---|---|---|
| Rank Test | Compare 1 median with a specified value | 1-sample Z-test/T-test |
|  | Compare 2 paired medians | paired samples T-test |
| Wilcoxon Signed-Rank Test | Compare 2 paired medians | paired samples T-test |
| The MWV Test | Compare 2 independent medians | 2-sample T-test |
| The Kruskal-Wallis Test | Compare 3 or more medians | 1-way ANOVA |
