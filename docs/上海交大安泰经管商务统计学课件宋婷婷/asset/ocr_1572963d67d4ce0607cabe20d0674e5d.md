# Properties of Point Estimators

+   - **Efficiency（三么性质）**: If a random sample can be used to provide **two unbiased point estimators** of the same population parameter, we would prefer to use the point estimator with the **smaller standard error**.
+     - The point estimator with the **smaller standard error** is said to have **greater relative efficiency** than the other.
