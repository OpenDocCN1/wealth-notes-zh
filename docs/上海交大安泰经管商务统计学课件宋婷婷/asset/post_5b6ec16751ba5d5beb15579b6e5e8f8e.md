
## General Steps of Testing for Three or More Proportions

- Step 1: State the null and alternative hypotheses
  - $H_0: p_1 = p_2 = \cdots = p_k$
  - $H_a$: Not all population proportions are equal
- Step 2: Select the level of significance $\alpha$.

## Multiple Comparisons Procedure

- When rejecting $H_0$, how to determine where the differences between population proportions exist?
- We can use a multiple comparison procedure known as the **Marascuilo Procedure**.
- First, compute the three sample proportions.

BYD Han: $\bar{p}_1 = 69/125 = 0.5520$

Toyota Camry: $\bar{p}_2 = 120/200 = 0.6000$

Tesla M3: $\bar{p}_3 = 123/175 = 0.7029$

- Then compute the absolute value of the pairwise difference.

Han and Camry: $|\bar{p}_1 - \bar{p}_2| = |0.5520 - 0.6000| = 0.0480$

Han and M3: $|\bar{p}_1 - \bar{p}_3| = |0.5520 - 0.7029| = 0.1509$

Camry and M3: $|\bar{p}_2 - \bar{p}_3| = |0.6000 - 0.7029| = 0.1029$

## Motivations: Testing for Independence

- Independence: Two variables are independent or not?
- Example: Parents' income ⇒ Children's education
  - A survey is conducted of 175 young adults on their highest level of schooling (university, high school, or neither).
  - Their parents are classified as wealthy, middle class, or poor.
- Sample data: The results are summarized as follows

| Parents | Level of Schooling | | | |
|---|---|---|---|---|
| | University | High School | None | Total |
| Wealthy | 20 | 15 | 10 | 45 |
| Middle Class | 40 | 25 | 20 | 85 |
| Poor | 8 | 14 | 23 | 45 |
| Total | 68 | 54 | 53 | 175 |

- Question: Is the person’s level of schooling independent of their parents’ wealth?

## Test of Independence

- Chi-square test can be used to test for the independence of two categorical variables.
- Set up the null and alternative hypotheses.
  - $H_0$: The column variable is not affected by the row variable.
  - $H_a$: The column variable is affected by the row variable.
- Select a random sample and record the observed frequency $f_{ij}$ for each cell of the contingency table.
- Compute the expected frequency $e_{ij}$ for each cell.

$$e_{ij} = \frac{\text{Row } i \text{ Total} \times \text{Column } j \text{ Total}}{\text{Sample Size}}$$

- Compute the value of the test statistic.

$$\chi^2 = \sum_i \sum_j \frac{(f_{ij} - e_{ij})^2}{e_{ij}}$$

Note: When there are $n$ rows and $m$ columns, the test statistic has a chi-square distribution with $(n - 1)(m - 1)$ df, provided that the expected frequencies are 5 or more for all categories.

**Rejection rule:**

- p-value approach: Reject $H_0$ if p-value ≤ $\alpha$.
- Critical value approach: Reject $H_0$ if $\chi^2 > \chi^2_{\alpha,(n-1)(m-1)}$.

### Example

**Observed frequencies**

| Parents | Level of Schooling | | | |
|---|---|---|---|---|
| | University | High School | None | Total |
| Wealthy | 20 | 15 | 10 | 45 |
| Middle Class | 40 | 25 | 20 | 85 |
| Poor | 8 | 14 | 23 | 45 |
| Total | 68 | 54 | 53 | 175 |

**Expected frequencies**

| Parents | Level of Schooling | | | |
|---|---|---|---|---|
| | University | High School | None | Total |
| Wealthy | 17.5 | 13.9 | 13.6 | 45 |
| Middle Class | 33.0 | 26.2 | 25.8 | 85 |
| Poor | 17.5 | 13.9 | 13.6 | 45 |
| Total | 68 | 54 | 53 | 175 |

- Test statistic:
  $$\chi^2 = \frac{(20 - 17.5)^2}{17.5} + \frac{(40 - 33.0)^2}{33.0} + \cdots + \frac{(23 - 13.6)^2}{13.6} = 15.82$$
- $\alpha = 0.05$ and d.f. = $(3 - 1)(3 - 1) = 4$
- p-value approach: p-value $= 0.003 < \alpha$
- Critical value approach: $\chi^2 > \chi^2_{0.05,4} = 9.49$
- We reject the null hypothesis and conclude that the level of schooling attained is not independent of parents’ wealth.
