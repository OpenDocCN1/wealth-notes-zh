# Summary

+   Step 3: Use sampling distribution to justify the precision of estimator

+   Suppose a priori belief about rating is that μ = 6, σ = √3, n=1200.

+   Precision for μ
+   E(\bar{x})=μ=6; σ_{\bar{x}} = σ/√n = 1/20.
+   The probability that |\bar{x} - μ| ≤ 0.1 is
+   Pr {5.9 ≤ \bar{x} ≤ 6.1}
+   = Pr { (5.9 - E(\bar{x}))/σ_{\bar{x}} ≤ (\bar{x} - E(\bar{x}))/σ_{\bar{x}} ≤ (6.1 - E(\bar{x}))/σ_{\bar{x}} }
+   ≈ Φ(2) - Φ(-2) ≈ 0.9544

+   The probability that sampling error is less than 0.1 is 95.44%.
