# Sign Test: Testing for Two Matched Samples

+   - For each customer,
+     - record a plus sign if Citrus Valley is more preferred
+     - record a minus sign if Tropical Orange is more preferred.
+     - record nothing if there is no preference (deleted in later analysis)
+   - Let $p$ denote the proportion of customers who prefer Citrus Valley orange juice. This becomes a hypothesis testing for population proportion:
+   
+     $H_0: p = 0.5,\quad\text{versus}\quad H_a: p \ne 0.5.$
