# Example

+   - A manufacturing firm is attempting to determine whether two production methods differ in terms of task completion time.
+   - The hypotheses:
+     H₀ : medianₐ = medianᵦ, versus Hₐ : medianₐ ≠ medianᵦ
+   - The level of significance is set to be α = 0.05.
+   - 11 randomly selected workers completed the production task two times, once using method A and once using method B.
+   - The method that the worker used first was randomly selected.
