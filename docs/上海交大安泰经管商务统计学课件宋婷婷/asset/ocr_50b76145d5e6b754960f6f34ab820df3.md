# 回顾统计动断的来交

方差检验与多比例是否

+   1. 整体好的现实总问题 ⇒ 能够定量什么和的问题。
+      - 方差基本：污水处理，公交车违停，雪发现现在量产茶，EDG机冠
+      - 比例和样：重复频对比

+   2. 多级机抽样(Random Sample)获得代表性样本。
+      - 整理抽样：计算样本均值，样本方差
+      - 频数率性统计

+   3. 构造方差或者比例定量次数
+      - 到计：这计和机是到计
+      - 假设检验的核心统计量：
+        - 单方差多比例：(n-1)s²/σ₀² ~ χ²
+        - 皆方差对比：S²₁/S²₂ ~ F(n₁-1, n₂-2)

+   4. 对现实总的问题给出科学的定量结果或者判断。
