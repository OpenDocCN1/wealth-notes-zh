# Test with Normal Approximation

+   - When the sample size n is large, we can use normal approximation to simplify the computation.
+   - Since μ_X = 0.5n, σ_X = √0.25n, then for large n
+     $$Z := \frac{X - 0.5n}{\sqrt{0.25n}} \sim N(0,1)$$
+   - With the normal approximation, the rejection rule is obtained.
+     - Critical value approach:
+       reject H₀ if |Z| ≥ z_{α/2}.
+     - p-value approach:
+       reject H₀ if p-value = P(|N(0,1)| ≥ |Z|) ≤ α.
