# Extensions to Other Hypotheses

+   - An overview of the lower tail, upper tail and two-tailed tests is as follows.
+   - The test statistic is the same, but the rejection regions are not.

| | Lower-tailed Test | Upper-tailed Test | Two-tailed Test |
|---|---|---|---|
| Hypotheses | $H_0: \mu \ge \mu_0$
$H_a: \mu < \mu_0$ | $H_0: \mu \le \mu_0$
$H_a: \mu > \mu_0$ | $H_0: \mu = \mu_0$
$H_a: \mu \ne \mu_0$ |
| Test Statistic | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ |
| Rejection rule:
Critical value approach | Reject $H_0$ if $t \le -t_\alpha$ | Reject $H_0$ if $t \ge t_\alpha$ | Reject $H_0$ if $|t| \ge t_{\alpha/2}$ |
| Rejection rule:
p-value approach | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ |
