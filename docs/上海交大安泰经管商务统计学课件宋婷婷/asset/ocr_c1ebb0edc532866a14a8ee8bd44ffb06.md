# Chi-square distribution

+   - **Definition:** \(\chi^2(k)\) is the sum of \(k\) squared independent standard normals.
+     - If \(X_i \sim N(0,1)\), then \(X_i^2\) follows chi-square distribution with degree of freedom 1, represented by \(X_i^2 \sim \chi^2(1)\).
+     - If \(X_1^2, X_2^2, \ldots, X_k^2\) are independent \(\chi^2(1)\) variables, then \(\sum_{i=1}^{k} X_i^2\) follows chi-square distribution with degree of freedom \(k\), represented by \(\sum_{i=1}^{k} X_i^2 \sim \chi^2(k)\).
