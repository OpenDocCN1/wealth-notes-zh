# Notations

+   - A simple random sample of size $n_j$ has been selected from each of the $k$ treatments.

+   - $x_{ij}$: value of observation $i$ for treatment $j$

+   - Sample mean and sample variance within treatment $j$ are
+   
+   $$\bar{x}_j = \frac{1}{n_j} \sum_{i=1}^{n_j} x_{ij}$$ 
+   
+   $$s_j^2 = \frac{1}{n_j - 1} \sum_{i=1}^{n_j} (x_{ij} - \bar{x}_j)^2$$

+   - The overall sample mean between treatments is
+   
+   $$\bar{\bar{x}} = \frac{1}{n_T} \sum_{j=1}^{k} \sum_{i=1}^{n_j} x_{ij}, \text{ where } n_T = n_1 + n_2 + \cdots + n_k$$
