# Example: Reed Manufacturing – Fisher’s LSD Procedure

+   LSD for Plants 1 and 2

+   Hypotheses (A)
+   
+   H₀: μ₁ = μ₂
+   Hₐ: μ₁ ≠ μ₂

+   Rejection Rule
+   
+   Reject H₀ if |x̄₁ − x̄₂| ≥ 6.98

+   Test Statistic Rule
+   
+   |x̄₁ − x̄₂| = |55 − 68| = 13

+   Conclusion

The mean number of hours worked at Plant 1 is not equal to the mean number worked at Plant 2.
