# Terminologies

+   - A **factor** (因素) is a variable that the experimenter has selected for investigation.
+   - A **treatment** (处理) is a level of a factor.
+   - The **experimental units** (实验个体) are the objects of interest in the experiment.
+   - The **response variable** (响应变量) is the variable that responds to the changes of factors in the experiment.
+   - **Question:** How does the factor variable affect (影响) the response variable?
