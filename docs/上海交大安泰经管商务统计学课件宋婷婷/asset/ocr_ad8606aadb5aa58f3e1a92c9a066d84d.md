# Interval Estimate of Population Mean: σ Unknown

+   - **Interval Estimation**: point estimator ± Δ
+   - **Key point**: What is Δ under σ is unknown.
+     - When σ is known, we choose Δ = z_{α/2} σ/√n so that there is 1 − α probability that the error x̄ − μ is less than ±Δ, i.e.,
+       P{ −z_{α/2} σ/√n < x̄ − μ < z_{α/2} σ/√n } = 1 − α
+     - Now we only know sample standard deviation, s.
+     - How to define Δ? ⇒ The key is to find the distribution of
+       t = (x̄ − μ) / (s/√n)
