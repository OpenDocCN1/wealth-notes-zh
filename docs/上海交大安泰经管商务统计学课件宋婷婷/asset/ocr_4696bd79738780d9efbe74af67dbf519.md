# Test Procedure when \(\sigma_1^2, \sigma_2^2\) are Known

+   - The test statistic is the same, but the rejection regions are not.
+   - The p-values are also different.
+     - Two-tailed test: p-value = \(P(|z| \ge z_{obs} \mid \mu_1-\mu_2=D_0)\)
+     - Upper-tailed test: p-value = \(P(z \ge z_{obs} \mid \mu_1-\mu_2 \le D_0)\)
+     - Lower-tailed test: p-value = \(P(z \le z_{obs} \mid \mu_1-\mu_2 \ge D_0)\)

|  | Two-tailed Test | Upper-tailed Test | Lower-tailed Test |
|---|---|---|---|
| **Hypotheses** | \(H_0: \mu_1-\mu_2=D_0\)<br>\(H_a: \mu_1-\mu_2\ne D_0\) | \(H_0: \mu_1-\mu_2\le D_0\)<br>\(H_a: \mu_1-\mu_2>D_0\) | \(H_0: \mu_1-\mu_2\ge D_0\)<br>\(H_a: \mu_1-\mu_2<D_0\) |
| **Test Statistic** | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) | \(z=\frac{\bar{x}_1-\bar{x}_2-D_0}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\) |
| **Rejection rule: Critical value approach** | Reject \(H_0\) if \(|z_{obs}|\ge z_{\alpha/2}\) | Reject \(H_0\) if \(z_{obs}\ge z_\alpha\) | Reject \(H_0\) if \(z_{obs}\le -z_\alpha\) |
| **Rejection rule: p-value approach** | Reject \(H_0\) if p-value \(\le\alpha\) | Reject \(H_0\) if p-value \(\le\alpha\) | Reject \(H_0\) if p-value \(\le\alpha\) |
