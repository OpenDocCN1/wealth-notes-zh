# Assumptions of ANOVA

+   - **Normality:** For each population, the response (dependent) variable is normally distributed.
+   - **Identical:** The variance of the response variable, denoted by σ², is the same for all of the populations. (But we do not assume it is known.)
+   - **Independent:** The observations must be independent.
+   
+     ⇒ εᵢⱼ ~ i.i.d. N(0, σ²)
