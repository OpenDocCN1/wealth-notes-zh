# Properties of Point Estimators

+   - **Consistency（ 一致性）**: A point estimator is **consistent** if the values of the point estimator tend to become closer to the population parameter as the sample size becomes larger.
+   
+     $$\lim_{n\to\infty}P\{\hat{\theta}=\theta\}=1.$$

+   - Is the sample mean $\bar{x}$ a consistent and unbiased estimator of $\mu$?
+     - For example: $E(\bar{x})=\mu$, is a consistent estimators. Recall that $\sigma_{\bar{x}}=\frac{\sigma}{\sqrt{n}}$
+     - We conclude that a larger sample size tends to provide point estimates closer to the population mean $\mu$
