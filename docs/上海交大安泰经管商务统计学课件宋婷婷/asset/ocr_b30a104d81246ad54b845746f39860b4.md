# Test Procedure when σ₁² ≠ σ₂² are Unknown

+   - The test statistic is the same, but the rejection regions are not.
+   - The p-values are also different.

+   - Two-tailed test: p-value = P(|t| ≥ |t_obs| | μ₁ - μ₂ = D₀)
+   - Upper-tailed test: p-value = P(t ≥ t_obs | μ₁ - μ₂ ≤ D₀)
+   - Lower-tailed test: p-value = P(t ≤ t_obs | μ₁ - μ₂ ≥ D₀)

| | Two-tailed Test | Upper-tailed Test | Lower-tailed Test |
|---|---|---|---|
| Hypotheses | H₀: μ₁ - μ₂ = D₀
H₁: μ₁ - μ₂ ≠ D₀ | H₀: μ₁ - μ₂ ≤ D₀
H₁: μ₁ - μ₂ > D₀ | H₀: μ₁ - μ₂ ≥ D₀
H₁: μ₁ - μ₂ < D₀ |
| Test Statistic | t = (x̄₁ - x̄₂ - D₀) / √(s₁²/n₁ + s₂²/n₂) | t = (x̄₁ - x̄₂ - D₀) / √(s₁²/n₁ + s₂²/n₂) | t = (x̄₁ - x̄₂ - D₀) / √(s₁²/n₁ + s₂²/n₂) |
| Rejection rule: Critical value approach | Reject H₀ if |t_obs| ≥ t*_{α/2} | Reject H₀ if t_obs ≥ t*_{α, ν} | Reject H₀ if t_obs ≤ -t*_{α, ν} |
| Rejection rule: p-value approach | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α |
