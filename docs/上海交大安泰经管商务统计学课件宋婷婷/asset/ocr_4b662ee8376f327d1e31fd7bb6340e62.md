# Hypothesis Testing About a Population Variance

+   Three forms for a hypothesis test about a population variance:
+   - Two-tailed test:
+     H₀: σ² = σ₀², versus Hₐ: σ² ≠ σ₀²
+   - Upper-tailed test:
+     H₀: σ² ≤ σ₀², versus Hₐ: σ² > σ₀²
+   - Lower-tailed test:
+     H₀: σ² ≥ σ₀², versus Hₐ: σ² < σ₀²
