# Example: CI with $\sigma$

+   - **Example:** 很简略平规到
+     - **史以置量学生显项饭很费的标集差是** $\sigma=5$ 元，$z_{0.025}=1.96$
+     - **通常** 校抽样（$n=36$），得到学生显项饭很费的样本均值 $\bar{x}=20$ 元
+     - **采用前面的公式**，我们谈得得到学生保费均值的95%置信区间为 $20\pm1.96\times\frac{5}{\sqrt{36}}=20\pm1.63$ 元

+   - 思范：“有95%的概率以为致者会学生保费的总体均值吗”？对吗？
+   - **Note:** True population mean is a fixed unknown value that is either inside or outside the CI with 100% certainty.
