# Control Type II Error (备注这里有发现丁丁)

+   In general, for lower-tailed Z-test procedure, its Type II error probability is
+   
+   β = P(Type II error) = P( (X̄ - μ₀)/(σ/√n) > z_α | Hₐ ) = Φ( z_α - √n(μ₀ - μₐ)/σ ).

+   Determine n, the number of samples required, to ensure the Type II error probability is no larger than β,
+   
+   z_α - √n(μ₀ - μₐ)/σ = -z_β ⇒ n = (z_α + z_β)² σ² / (μ₀ - μₐ)².
