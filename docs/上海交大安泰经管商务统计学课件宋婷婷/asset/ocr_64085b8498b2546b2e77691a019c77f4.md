# Measures of Association

# Two Variables

+   Covariance: sample: $S_{XY} = \frac{\sum_{i}(x_i-\bar{x})(y_i-\bar{y})}{n-1}$; population: $\sigma_{XY} = \frac{\sum_{i}(x_i-\mu_x)(y_i-\mu_y)}{N}$

+   Correlation Coefficient: sample: $r_{XY} = \frac{S_{XY}}{S_X S_Y}$; population: $\rho_{XY} = \frac{\sigma_{XY}}{\sigma_X \sigma_Y}$

+   Example: Golfing Study
+   A golfer is interested in investigating the relationship, if any, between driving distance and 18-hole score.

![](bbox=[0.25, 0.55, 0.75, 0.75])

+   Sample covariance: $S_{XY} = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{n-1} = \frac{-35.40}{6-1} = -7.08$

+   Sample correlation coefficient: $r_{XY} = \frac{S_{XY}}{S_X S_Y} = \frac{-7.08}{8.22 \times 0.89} = -0.9631$
