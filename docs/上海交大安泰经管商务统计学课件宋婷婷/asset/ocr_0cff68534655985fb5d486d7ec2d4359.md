+   - Does the test scores in the undergraduate English Proficiency Test follow the normal distribution?

+   - A sample of test scores for 50 randomly chosen students

+   - x̄ = 68.42, s = 10.41

+   - Hypotheses:

H₀ : The population does not differ from a normal distribution with μ = 68.42 and σ = 10.41

Hₐ : The population is different from a normal distribution with μ = 68.42 and σ = 10.41
