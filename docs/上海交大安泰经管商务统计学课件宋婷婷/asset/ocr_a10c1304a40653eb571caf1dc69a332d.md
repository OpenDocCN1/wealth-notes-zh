# Interval Estimation of Variance and Standard Deviation

+   - Performing algebraic manipulation, we get **interval estimator** for variance
+   
+     $$\frac{(n-1)s^2}{\chi^2_{\alpha/2}} \leq \sigma^2 \leq \frac{(n-1)s^2}{\chi^2_{(1-\alpha/2)}}$$
+   
+   - Taking square root, we get **interval estimator** for standard deviation
+   
+     $$\sqrt{\frac{(n-1)s^2}{\chi^2_{\alpha/2}}} \leq \sigma \leq \sqrt{\frac{(n-1)s^2}{\chi^2_{(1-\alpha/2)}}}$$
