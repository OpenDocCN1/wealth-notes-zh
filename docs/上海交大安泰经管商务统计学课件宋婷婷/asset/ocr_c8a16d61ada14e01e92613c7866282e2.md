# Two Population Means when σ₁² = σ₂² are Unknown

+   - In practice, the population variances σ₁² and σ₂² are often unknown.
+   - For point estimation, we can still use x̄₁ − x̄₂.
+   - However, for interval estimations and hypothesis testing, we need to estimate its standard error σ_{x̄₁−x̄₂} = √(σ₁²/n₁ + σ₂²/n₂).
+   - Basic idea: use sample variances to estimate population variances, and use t distribution instead of normal distribution.
+     - When σ₁² = σ₂², it works
+     - When σ₁² ≠ σ₂², it works approximately
