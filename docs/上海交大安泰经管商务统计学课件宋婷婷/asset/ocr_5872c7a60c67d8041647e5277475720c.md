# A/B 试验构件步骤

+   1. 设计A/B实验
+      - 实验：要多大样本量？
+        - 样例构型两端大概关二什效应力（课件注释常类则误二第二类测试构权法！）
+        - 直接用样样确定自？→ 如果依靠衡时真是让真多构用样
+        - 全序分成立，样概大，总效应
+      - 实验：要连行多频时直？

+   2. 运行实验密数值（小型化查志记单）
+      - OEC构答本教
+        - 分组信息

+   3. 分析结果
+      - 对假值构件验：单假值，双假值，多假值(ANOVA)
+      - 对方向构件验：单方自，双方向

+   4. 从结果到决策：运行A/B之试构向指标该构策数硼，分析数硼，进
+      问题解决策
+      - 用欲窗会计显南大构梁果与，进背步思有方效构整本
+      - 会计器构想（厚泽程度）
