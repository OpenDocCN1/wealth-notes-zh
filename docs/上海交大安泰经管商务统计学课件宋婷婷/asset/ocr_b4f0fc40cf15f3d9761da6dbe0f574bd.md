# Construction of CI: σ Unknown

+   Interval Estimation: point estimator ±Δ

+   Key point: What is Δ under σ is unknown.

+   When σ is unknown, we choose Δ = t_{α/2, n-1} s/√n so that there is 1 − α probability that the error x̄ − μ is less than ±Δ, i.e.,

P{ −t_{α/2} s/√n < x̄ − μ < t_{α/2} s/√n } = 1 − α

+   Now we use sample standard deviation, s.

+   t_{α/2} is the t value providing an area of α/2 in the upper tail of the t distribution with n − 1 degrees of freedom
