# Sampling Distribution of $\bar{p}$

+   - The population distribution is **Bernoulli distribution**. So the sampling distribution of $\bar{p}$ is not exact normal.

+   - Recall that:

+     - Suppose we randomly pick up $n$ i.i.d. students. Here $X_i = 1$ indicates a female student and $X_i = 0$ indicates a male student, i.e.,

$X_i \sim \operatorname{Bernoulli}(p),\ \text{for } i = 1, 2, \ldots, n.$

$P(X = 1) = p$

$P(X = 0) = 1 - p$

$\mu \equiv E(X) = p$

$\sigma^2 \equiv Var(X) = E(X^2) - E(X)^2 = p(1-p)$
