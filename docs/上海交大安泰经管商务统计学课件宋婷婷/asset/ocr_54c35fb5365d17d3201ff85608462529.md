# Example——蜜雪现城

+   - Consider the production process of filling Ice Lemon Tea in mi xue bing cheng (蜜雪现城).
+   - **Real problem:** We are interested in estimating the population variance for the Ice Lemon Tea filling process.
+   - **Statistically:** A sample of 20 containers is taken, and the sample variance for the filling quantities is found to be $s^2 = 0.0025$.
+   - Our interest will be in developing confidence interval with $\alpha = 0.05$.
+   - Since $\chi_{0.975}(19)^2 = 8.907$ and $\chi_{0.025}(19)^2 = 32.852$, the C.I. is
+   
+   $$\frac{(19)(0.0025)}{32.852} \le \sigma^2 \le \frac{(19)(0.0025)}{8.907},$$
+   
+   i.e.,
+   
+   $$0.0014 \le \sigma^2 \le 0.0053$$
+   
+   $$0.0380 \le \sigma \le 0.0730$$
