# Sampling Distribution of x̄

+   - The practical value of sampling distribution for x̄
+     - We cannot expect the sample mean x̄ to exactly equal the population mean μ.
+     - Given the sampling distribution, we can provide probability information about the gap between x̄ and μ.

+   - Example: 纸. 组织(计算误差在0.5分以内的概率)
+     - Given that μ=6, σ=1 and sample size n is 16.
+     - E(x̄)=μ=6; σ_x̄ = σ/√n =0.25

Pr{5.5 ≤ x̄ ≤ 6.5}
= Pr{ (5.5 − E(x̄))/σ_x̄ ≤ (x̄ − E(x̄))/σ_x̄ ≤ (6.5 − E(x̄))/σ_x̄ }
≈ Φ(2) − Φ(−2) = 0.9544

+   - The probability that |x̄ − μ| ≤ 0.5 is 95.44%
