# A Quick Overview of Hypothesis Testing

# Step 1: State the hypotheses

+   - **Two complementary statements** in the hypothesis testing
+     - **Null hypothesis (原假设)** $H_0$: a statement which you want to challenge (想拒绝)
+     - **Alternative hypothesis (标杆假设)** $H_a$: a statement which you hope to support (想是了)

+   - There is usually a **not** or a **no** term in the null hypothesis.
+     - In the Lady Tasting Tea, $H_0$: She can **NOT** distinguish the sequence of milk and tea.
+     - In the COVID-19, $H_0$: The person does **NOT** have coronavirus.

+   - **Two results:**
+     - **Reject**: the sample provide convincing evidence that it is false. What is the Conclusion?
+       ⇒ The **alternative hypothesis**: what you conclude if you reject the null.
+     - **Fail to reject**: DON'T mean the hypothesis is **True**.
