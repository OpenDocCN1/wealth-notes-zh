## Hypothesis Testing

- A **hypothesis** is a statement about the **population**.
  - Population mean \(\mu\)
  - Population variance \(\sigma^2\)
  - Population distribution (normality)
- **Hypothesis testing** is a procedure based on **sample evidence** and **probability theory** to determine whether the hypothesis is a **reasonable statement**.
- Basic steps of hypothesis testing:
  1. State the hypothesis.
  2. Select a level of significance.
  3. Identify the test statistic.
  4. Formulate a decision rule.
  5. Take a sample, and arrive at a decision.

## A Quick Overview of Hypothesis Testing

### Step 1: State the hypotheses

- **Two complementary statements** in the hypothesis testing:
  - **Null hypothesis (原假设)** \(H_0\): a statement which you want to challenge (想拒绝)
  - **Alternative hypothesis (备择假设)** \(H_a\): a statement which you hope to support (想支持)
- There is usually a **not** or a **no** term in the null hypothesis.
  - In the Lady Tasting Tea, \(H_0\): She can **NOT** distinguish the sequence of milk and tea.
  - In the COVID-19, \(H_0\): The person does **NOT** have coronavirus.
- **Two results:**
  - **Reject**: the sample provides convincing evidence that it is false. What is the conclusion?
    ⇒ The **alternative hypothesis**: what you conclude if you reject the null.
  - **Fail to reject**: doesn't mean the hypothesis is **true**.

### Step 5: Arrive at the decision

- The conclusions are not always correct because they are drawn based on random samples.
- Two types of errors:
  - Type I error: Rejecting \(H_0\) when it is true (False positive, 假阳性)
  - Type II error: Accepting \(H_0\) when it is false (False negative, 假阴性)

| Conclusion | \(H_0\) True | \(H_a\) True |
|---|---|---|
| Accept \(H_0\) | Correct | Type II Error |
| Reject \(H_0\) | Type I Error | Correct |

### Step 5: Arrive at the decision – How to control the errors?

- Type I Error:
  - Significance level \(\alpha\) sets the maximal probability of making the Type I error.
  - Significance tests: hypothesis tests that only control Type I error.
  - In a significance test, we usually use the term ‘Not Reject \(H_0\)’ instead of ‘Accept \(H_0\)’.
- Type II Error:
  - Controlling for Type II error in hypothesis testing can be done through Power Analysis.

## Formulation of Hypotheses

- General formulation of Null and Alternative Hypotheses:

  \(H_0: \theta \in \Theta_0 \quad \text{versus} \quad H_a: \theta \in \Theta_0^c,\)

  where \(\theta\) is the parameter to test, and \(\Theta_0\) is a closed set.

- Examples: the typical tests for the population mean \(\theta \equiv \mu\)

- Two-tailed test: \(\Theta_0 = \{\mu_0\}\)

  \(H_0: \mu = \mu_0, \quad \text{versus} \quad H_a: \mu \neq \mu_0.\)

- Upper-tailed test: \(\Theta_0 = (-\infty, \mu_0]\)

  \(H_0: \mu \le \mu_0, \quad \text{versus} \quad H_a: \mu > \mu_0.\)

- Lower-tailed test: \(\Theta_0 = [\mu_0, \infty)\)

  \(H_0: \mu \ge \mu_0, \quad \text{versus} \quad H_a: \mu < \mu_0.\)
