
## Summary

- An overview of the lower tail, upper tail and two-tailed tests is as follows.
- The test statistic is the same, but the rejection regions are not.

|  | Lower-tailed Test | Upper-tailed Test | Two-tailed Test |
|---|---|---|---|
| **Hypotheses** | H₀: μ ≥ μ₀<br>Hₐ: μ < μ₀ | H₀: μ ≤ μ₀<br>Hₐ: μ > μ₀ | H₀: μ = μ₀<br>Hₐ: μ ≠ μ₀ |
| **Test Statistic** | z = (x̄ − μ₀) / (σ / √n) | z = (x̄ − μ₀) / (σ / √n) | z = (x̄ − μ₀) / (σ / √n) |
| **Rejection rule: Critical value approach** | Reject H₀ if z ≤ −zₐ | Reject H₀ if z ≥ zₐ | Reject H₀ if |z| ≥ zₐ/₂ |
| **Rejection rule: p-value approach** | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α |

## Testing Population Mean when Variance is Unknown

- Assume we collect *n.i.i.d.* samples $X_1, X_2, \ldots, X_n$, and $X_i \sim N(\mu, \sigma^2)$.

- Step 1: state the null and alternative hypotheses  
  $H_0: \mu = \mu_0,\ H_a: \mu \ne \mu_0$.

- Step 2: select the level of significance $\alpha$.

- Step 3: when the variance $\sigma^2$ is unknown, the test statistic is specified by

![](img/ea9cdfad8dc7821ead4e68fc7aaa5ca3_155_0.png)

where $\bar{X}$ is the sample mean and $S^2$ is the sample variance.

- The test procedure based on the $t$ statistic is often called $t$-test.

- Under $H_0$, the distribution of $t$ is known, i.e., $t \sim t_{n-1}$, where $n-1$ is the degree of freedom.

## Step 4 & 5: Formulate the Decision Rule & Make a Decision

- **Critical-value approach**
  - Set the rejection region is (−∞, −c] ∪ [c, ∞), and
  - significance level = P(Reject H₀|H₀) = P(|t| ≥ c|H₀).
  - The significance level α is achieved by letting c = tₐ/₂.
  - The rejection rule is to
    reject H₀ : μ = μ₀, if |t| ≥ tₐ/₂.

- **P-value approach**
  - The p-value, as a measure of the evidence against H₀ is
    p-value = P(|t| ≥ |t_obs| | H₀).
  - The rejection rule is to
    reject H₀ : μ = μ₀, if p-value ≤ α.

## Extensions to Other Hypotheses

- An overview of the lower tail, upper tail and two-tailed tests is as follows.
- The test statistic is the same, but the rejection regions are not.

| | Lower-tailed Test | Upper-tailed Test | Two-tailed Test |
|---|---|---|---|
| Hypotheses | $H_0: \mu \ge \mu_0$<br>$H_a: \mu < \mu_0$ | $H_0: \mu \le \mu_0$<br>$H_a: \mu > \mu_0$ | $H_0: \mu = \mu_0$<br>$H_a: \mu \ne \mu_0$ |
| Test Statistic | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ |
| Rejection rule:<br>Critical value approach | Reject $H_0$ if $t \le -t_\alpha$ | Reject $H_0$ if $t \ge t_\alpha$ | Reject $H_0$ if $|t| \ge t_{\alpha/2}$ |
| Rejection rule:<br>p-value approach | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ |

## Testing Population Proportion: Motivating Example

- Over the past year, the ratio of male students to female students in a student club at SJTU was 4:1.
- A special promotion at the beginning of this term is designed to attract female members.
- One month later, the club president wants to know whether the proportion of female members had increased.

## Testing Population Proportion

- Suppose the population proportion is $p$, and we want to test whether $p$ is greater than $p_0$.
- Step 1: this is an upper-tailed hypothesis testing:
  
  $H_0: p \leq p_0$   versus   $H_a: p > p_0$.
- Steps 2-5 to design test procedures.
  - Specify the significant level, test statistic and the rejection rule.
  - Collect a random sample of $n$ members and count the sample proportion $\hat{p}$.

- For the i-th member, let Xi = 1 for female and Xi = 0 for male. Then
  
  Xi ~ Bernoulli(p), for i = 1, 2, ..., n.

- Step 3: We construct a test statistic whose distribution is known
  
  p̄ = (1/n) Σ_{i=1}^n Xi, where Σ_{i=1}^n Xi ~ B(n, p)

- Step 2 and 4: Denote the rejection region as [c, 1], and the significance level is
  
  sup_{p ≥ p0} P(Type I error) = P(p̄ ≥ c | p = p0) = Σ_{k = nc}^n (n choose k) p0^k (1 - p0)^{n - k} = α.

- It is very complicated to solve the critical value c for given α.
