# Example

+   Hypotheses:
+   H₀: σ₁² = σ₂²
+   Hₐ: σ₁² ≠ σ₂²
+   Population 1 represents the one providing the larger sample variance.

+   Test statistics:
+   F = s₁² / s₂² = 1.768 / 0.700 = 2.53

+   Rejection Rule: Reject H₀ if F ≥ Fₐ/₂

+   The F distribution table shows that with α/2 = 0.05, 9 d.f. (numerator), and 9 d.f. (denominator), F₀.₀₅ = 3.18.
