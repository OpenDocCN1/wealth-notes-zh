# Different Values of “Average”

+   - Q1: what is average? [mean, median, mode, ...](#)
+   - Q2: what is average for? [To measure the central tendency](#)
+   - [“Three Counting Problems”](#): How high is the wall?

+   - **Mean**: arithmetic mean
+     \(\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i\)
+   - **Mode**: most frequent value in the data set
+   - **Median**: middle value that separates the higher half from the lower half
