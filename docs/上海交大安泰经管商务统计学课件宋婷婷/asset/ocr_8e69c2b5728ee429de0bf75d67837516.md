# Test with Binomial Distribution

+   - For each observation, record a sign “+” if it is greater than 450, and record a sign “−” otherwise.
+   - If the median is 450, there should be 50% plus signs and 50% minus signs.
+   - Generally, the number of “+”, X, follows $B(n,p)$ for some $p$.
+   - The sign test converts the original hypotheses about the median into the hypotheses about the binomial probability $p$:

$H_0: p = 0.5$, versus $H_a: p \ne 0.5$
