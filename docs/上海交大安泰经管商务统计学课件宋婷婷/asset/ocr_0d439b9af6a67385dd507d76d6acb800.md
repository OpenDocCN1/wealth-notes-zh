# Sampling Distribution

+   - Kruskal-Wallis test statistic

$$H = \left[\frac{12}{n_T(n_T + 1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i}\right] - 3(n_T + 1)$$

where $k$ is the number of populations, $n_i$ is the number of observations in sample $i$, $n_T$ is the total numbers of all the samples, and $R_i$ is the sum of the ranks for sample $i$

+   - $H$ resembles the computing formula for SSTr in the ANOVA

+   - If $H_0$ is true, the $H$ has approximately a $\chi^2_{k-1}$ distribution

+   - In our example, $n_1 = 7$, $n_2 = 6$, $n_3 = 7$, and $n_T = 20$. Therefore we can calculate $H = 8.92$, and the p-value

p-value $= P(\chi^2_2 \ge 8.92) = 0.0116 < \alpha$

and we reject $H_0$.
