# Simple Random Sampling

Simple Random Sampling: Given sample size n and population size N, each possible sample of size n has the same probability of being selected.

Example (美纸纸纸): 假设该行校为 乱三9000复学生，我们想从中抽取1200复学生，若概何在简单纯为抽样？

+   1. Assign the students the numbers 1 to 9000.
+   2. Generate a table of random numbers.
+   3. Select random numbers from the table in groups of four digits.
+   4. Discard the number if it is larger than 9000.
