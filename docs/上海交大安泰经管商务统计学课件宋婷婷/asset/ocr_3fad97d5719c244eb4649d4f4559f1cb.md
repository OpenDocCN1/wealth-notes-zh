# Extensions to Other Hypotheses

+   - The test procedures are similar for the upper-tailed and lower-tailed hypotheses.
+   - Step 1: Consider the upper-tailed hypothesis
+     $H_0: \mu \le \mu_0 \quad \text{versus} \quad H_a: \mu > \mu_0$.
+   - Step 2: select the level of significance $\alpha$.
+   - Step 3: Using the same test statistic $z$.
+   - Step 4 & 5: We reject $H_0$ if $z \ge z_\alpha$, where the critical value $z_\alpha$ is chosen such that the significance level is $\alpha$.
+   - P-value approach: p-value = P($z \ge z_{obs} | H_0$).
