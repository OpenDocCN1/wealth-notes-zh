# ANOVA: Summary

+   - The goal of ANOVA is to split the **total variation** of a set of observations into **different** sources, such as
+     - Treatment adjustments αj (One-way ANOVA, Two-way ANOVA)
+     - Error terms εij (Benchmark under the H0)
+   - Between-group Variance: Treatment adjustments αj + Error term εij
+   - Within-group Variance: Error terms εij
+   - It motivates us to construct a **test statistic** as a variability ratio
+   
+     **Between-group Variance** (组间离差)
+     -----------------------------
+     **Within-group Variance** (组内离差)
+   
+     and reject H0 if this ratio is sufficiently large.
+   - To formalize this idea, we shall introduce some assumptions and terminologies from the field of **Design of Experiments**.
