# Test of Independence

+   - Chi-square test can be used to test for the independence of two categorical variables
+   - Set up the null and alternative hypotheses.
+     - $H_0$: The column variable is not affected by the row variable
+     - $H_a$: The column variable is affected by the row variable
+   - Select a random sample and record the observed frequency $f_{ij}$ for each cell of the contingency table.
+   - Compute the expected frequency $e_{ij}$ for each cell.
+     $e_{ij} = \frac{\text{Row i Total} \times \text{Column j Total}}{\text{Sample Size}}$
