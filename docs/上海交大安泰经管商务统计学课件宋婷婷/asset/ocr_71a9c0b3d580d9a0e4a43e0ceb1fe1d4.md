# Randomized Block Design (随机区组化设计)

+   - When single experimental units are sampled among highly **heterogeneous conditions** (异用性), it is unlikely that these single units will adequately represent the populations and repeated sampling is likely to yield very different outcomes.
+   - **Blocking** can be used to form homogeneous groups, resulting in a Randomized Block Design.
