# 回顾统计功能的来文

均值估计

+   1. 生整那的现实生活问题 $⇒$ 能够是要件和的问题。
+      - 均值：交大美食评价，在量产率，生产效率
+      - 比例：女士品茶，人口比例
+   2. 多过骏机抽样(Random Sample)获得代表性样本。
+      - 整理数据
+      - 假设显著性统计
+   3. 构出均值宽度次数
+      - 到计：过初计和观见到计
+      - 假设分析：均值 + 背均值 + 四位样本
+        - 核心统计量：$\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$
+   4. 对现实生活的问题给出科学的定量结果或者判断。
