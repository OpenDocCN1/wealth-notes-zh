# Summary

+   - An overview of the lower tail, upper tail and two-tailed tests is as follows.
+   - The test statistic is the same, but the rejection regions are not.

|  | Lower-tailed Test | Upper-tailed Test | Two-tailed Test |
|---|---|---|---|
| **Hypotheses** | H₀: μ ≥ μ₀  
Hₐ: μ < μ₀ | H₀: μ ≤ μ₀  
Hₐ: μ > μ₀ | H₀: μ = μ₀  
Hₐ: μ ≠ μ₀ |
| **Test Statistic** | z = (x̄ − μ₀) / (σ / √n) | z = (x̄ − μ₀) / (σ / √n) | z = (x̄ − μ₀) / (σ / √n) |
| **Rejection rule: Critical value approach** | Reject H₀ if z ≤ −zₐ | Reject H₀ if z ≥ zₐ | Reject H₀ if |z| ≥ zₐ/₂ |
| **Rejection rule: p-value approach** | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α | Reject H₀ if p-value ≤ α |
