# Measures of Relative Location

+   - Empirical Rule: Three-sigma Rule of Thumb (68–95–99.7 rule)
+   - For a data having bell-shape (or normal) distribution,

+   - Approximately 68% of the data values will be within 1 standard deviation of the mean.
+   - Approximately 95% of the data values will be within 2 standard deviations of the mean.
+   - Approximately all (99.7%) of the data values will be within 3 standard deviations of the mean. (3 – σ)
