# ANOVA: A Graphic Interpretation

+   - Given observations of sample means, how to determine if they come from Model 1 or Model 2?
+   
+   - **Basic idea:** When the **variation between the sample means** is large, then Model 1 ($H_0$) is more likely to be rejected.
+   
+   - **Question:** What is the benchmark for comparison?
+   
+   - The benchmark for comparison is the **variation within each group**.
