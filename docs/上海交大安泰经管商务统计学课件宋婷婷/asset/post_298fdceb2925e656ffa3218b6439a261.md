
## Test Procedure when σ₁² ≠ σ₂² are Unknown

- The test statistic is the same, but the rejection regions are not.
- The p-values are also different.
- Two-tailed test: p-value = $P(|t| \ge |t_{\mathrm{obs}}| \mid \mu_1 - \mu_2 = D_0)$
- Upper-tailed test: p-value = $P(t \ge t_{\mathrm{obs}} \mid \mu_1 - \mu_2 \le D_0)$
- Lower-tailed test: p-value = $P(t \le t_{\mathrm{obs}} \mid \mu_1 - \mu_2 \ge D_0)$

|  | Two-tailed Test | Upper-tailed Test | Lower-tailed Test |
|---|---|---|---|
| Hypotheses | $H_0: \mu_1 - \mu_2 = D_0$<br>$H_1: \mu_1 - \mu_2 \neq D_0$ | $H_0: \mu_1 - \mu_2 \le D_0$<br>$H_1: \mu_1 - \mu_2 > D_0$ | $H_0: \mu_1 - \mu_2 \ge D_0$<br>$H_1: \mu_1 - \mu_2 < D_0$ |
| Test Statistic | $t = \frac{\bar{x}_1 - \bar{x}_2 - D_0}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$ | $t = \frac{\bar{x}_1 - \bar{x}_2 - D_0}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$ | $t = \frac{\bar{x}_1 - \bar{x}_2 - D_0}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$ |
| Rejection rule: Critical value approach | Reject $H_0$ if $\|t_{\mathrm{obs}}\| \ge t^*_{\alpha/2}$ | Reject $H_0$ if $t_{\mathrm{obs}} \ge t^*_{\alpha,\nu}$ | Reject $H_0$ if $t_{\mathrm{obs}} \le -t^*_{\alpha,\nu}$ |
| Rejection rule: p-value approach | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ | Reject $H_0$ if p-value $\le \alpha$ |

## Matched Samples: Motivating Example

- Suppose that employees at a manufacturing company can use two different methods to perform a production task.
- To maximize production output, the company wants to identify the method with the smaller population mean completion time.
- Begin by tentatively assuming that the two production methods have the same population mean completion time. Then, the hypothesis test is written as $H_0: \mu_1 = \mu_2$ versus $H_a: \mu_1 \neq \mu_2$.
- Matched sample design:
  - a random sample of workers is selected
  - each worker first uses one method and then uses the other method
  - the order of the two methods is assigned randomly to the workers.

## Test Procedure for Matched Samples

- Assume that we collect the completion times by *n* random workers using two different methods
  - $(X_{1,1}, X_{2,1}), (X_{1,2}, X_{2,2}), \dots, (X_{1,n}, X_{2,n})$ are i.i.d. binormal distributed (bivariate normal distributed).
  - $X_{1,i}$ and $X_{2,i}$ are matched and correlated samples.
- Step 1: Consider the two-tailed hypothesis test $H_0: \mu_1 = \mu_2$, versus $H_a: \mu_1 \neq \mu_2$.
- This can be reformulated as one-population mean hypothesis testing.
  - Let $\mu_d = \mu_1 - \mu_2$ and $Y_i = X_{1,i} - X_{2,i}$ for $i = 1, 2, \dots, n$.
  - The null hypothesis is equivalent to $H_0: \mu_d = 0$.
- Step 2-4: Then, the one-sample t-test can be used to reject or accept $H_0$ based on the new samples $Y_1, Y_2, \dots, Y_n$.

## Matched Sample V.S. Independent Samples

- **Matched (paired) samples:** the members of one sample can be used to determine the members of the other sample.
  - Pre-test/post-test: collect the data from the same individual units before and after an event/treatment/intervention.
  - Cross-over trials: individuals are randomized to two treatments and then the same individuals are crossed-over to the alternative treatment.
  - Matched samples: individuals are matched on personal characteristics, e.g., smokers and non-smokers of the same sex and the same age.
  - Duplicate measurements: the same biological samples, e.g., twins
  - Others: any circumstance in which each data point in one sample is uniquely matched to a data point in the second sample, e.g., married couples
- **Advantages by using matched samples:** the s.d. of the differences of the matched pairs will be smaller than unmatched pairs. Why?
- **Answer:** Few differences should exist because of the correlation between the two groups.

## Testing for Two Proportions: Motivating Example

- A tax preparation firm wants to compare the quality of work at two regional offices.
- By randomly sampling tax returns prepared at each office, the firm can estimate the proportion of erroneous returns prepared at each office.
- Step 1: The firm wants to test if there is a difference between these proportions: $H_0: p_1 = p_2$, versus $H_a: p_1 \ne p_2$.
- This is a **two-tailed test for two (independent) population proportions**. In general, the test could be two-tailed, upper-tailed and lower-tailed.
