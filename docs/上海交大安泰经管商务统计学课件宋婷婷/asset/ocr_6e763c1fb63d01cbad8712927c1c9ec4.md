# Summary of Testing About One Population Variance

| | Lower-tailed Test | Upper-tailed Test | Two-tailed Test |
|---|---|---|---|
| Hypotheses | $H_0: \sigma^2 \geq \sigma_0^2$
$H_a: \sigma^2 < \sigma_0^2$ | $H_0: \sigma^2 \leq \sigma_0^2$
$H_a: \sigma^2 > \sigma_0^2$ | $H_0: \sigma^2 = \sigma_0^2$
$H_a: \sigma^2 \neq \sigma_0^2$ |
| Test Statistic | $\chi^2 = \frac{(n-1)s^2}{\sigma_0^2}$ | $\chi^2 = \frac{(n-1)s^2}{\sigma_0^2}$ | $\chi^2 = \frac{(n-1)s^2}{\sigma_0^2}$ |
| Rejection rule:
Critical value approach | Reject $H_0$ if $\chi^2 \leq \chi^2_{1-\alpha}$ | Reject $H_0$ if $\chi^2 \geq \chi^2_{\alpha}$ | Reject $H_0$ if $\chi^2 \leq \chi^2_{\alpha/2}$
or $\chi^2 \geq \chi^2_{1-\alpha/2}$ |
| Rejection rule:
p-value approach | Reject $H_0$ if p-value $\leq \alpha$ | Reject $H_0$ if p-value $\leq \alpha$ | Reject $H_0$ if p-value $\leq \alpha$ |
