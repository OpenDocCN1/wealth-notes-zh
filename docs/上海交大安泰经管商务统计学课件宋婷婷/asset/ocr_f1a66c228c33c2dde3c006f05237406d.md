# Sampling Distribution of $\bar{p}$

+   - **The Practical Value of sampling distribution for $\bar{p}$**
+     - As similar to $\bar{x}$, given the sampling distribution, we can provide probability information about the gap between $\bar{p}$ and $p$.
+     - **Example:** 统 组（假设对这 组，给定 25 个 6 的人数占主打人数的比率 $p=40\%$，随机为抽取 25 位学生的组织算到地计值 $\bar{p}$，计算 $\bar{p}$ 的误差在 0.05 以内的概率）
+       - Given that $p=0.4$, sample size $n$ is 25.
+       - $E(\bar{p})=p=0.4$; $\sigma_{\bar{p}}=\sqrt{\frac{p(1-p)}{n}}=0.098$
+       - $Pr\{0.35\leq\bar{p}\leq0.45\}=Pr\left\{\frac{0.35-E(\bar{p})}{\sigma_{\bar{p}}}\leq\frac{\bar{p}-E(\bar{p})}{\sigma_{\bar{p}}}\leq\frac{0.45-E(\bar{p})}{\sigma_{\bar{p}}}\right\}$
+       - $\approx\Phi(0.51)-\Phi(-0.51)=0.39$
+       - The probability that $|\bar{p}-p|\leq0.05$ is only 39%
+     - Similarly, the **larger sample size** provides a **higher probability** that the sample proportion is within a specified distance of the population proportion.
