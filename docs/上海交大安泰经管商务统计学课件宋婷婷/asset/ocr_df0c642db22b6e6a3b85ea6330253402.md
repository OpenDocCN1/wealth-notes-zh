# Test Procedure when \(\sigma_1^2=\sigma_2^2\) are Unknown

+   - A weighted average of \(s_1^2\) and \(s_2^2\), called the **pooled estimator** is used,
+   
+     \[
+     s_p^2=\frac{n_1-1}{n_1+n_2-2}s_1^2+\frac{n_2-1}{n_1+n_2-2}s_2^2
+     =\frac{\sum_{i=1}^{n_1}(n_i-1)s_i^2}{\sum_{i=1}^{n_1}(n_i-1)}.
+     \]

+   - The T-test statistic then follows a t distribution with \((n_1+n_2-2)\) df
+   
+     \[
+     t=\frac{\bar{x}_1-\bar{x}_2-d_0}{\sqrt{s_p^2(1/n_1+1/n_2)}}\sim t_{n_1+n_2-2},\quad\text{under }H_0.
+     \]

+   - Test procedure works as follows.

+     - Critical-value approach: reject \(H_0\), if \(|t_{obs}|\geq |t_{\alpha/2}|\).

+     - p-value approach: reject \(H_0\), if p-value \(=P(|t|\geq |t_{obs}|\mid H_0)\leq\alpha\).
