# Example

+   - **Real problem:** Suppose we want to compare the quality of thermostats (温度表) produced by two manufacturers.

+   - **Statistically:** A sample of 10 thermostats (温度表) from each manufacturers were selected and placed in a test room at a temperature of 18°C. Readings are recorded as follows.

| Manufacturer | Readings | Sample Variance |
|---|---|---|
| ThermoRite | 17.4 17.8 18.2 19.5 17.0 | 0.700 |
|  | 18.1 18.6 17.9 17.2 19.3 | |
| TempKing | 17.7 16.4 19.2 20.1 19.5 | 1.768 |
|  | 19.7 18.1 16.6 17.3 17.5 | |

+   - Test whether there is a difference in the population variances with α = 0.10.
