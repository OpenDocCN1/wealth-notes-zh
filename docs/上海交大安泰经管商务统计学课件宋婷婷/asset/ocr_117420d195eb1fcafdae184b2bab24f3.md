# Interpretation of Interval Estimation: σ Known

+   How to understand "confidence level?"
+   - Any sample mean x̄ will provide an interval estimation for population mean.
+   - However, only the intervals constructed by the sample means within μ ± zα/2σx̄ will include the population mean μ.
+   - 100(1 − α)% of all the intervals constructed using x̄ ± zα/2σx̄ will contain the population mean.
