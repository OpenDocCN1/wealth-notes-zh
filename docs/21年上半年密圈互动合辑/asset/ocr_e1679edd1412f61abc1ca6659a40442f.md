# 09. Rehe

遇到和气场不合的同事合作的情况，首先得主动达成合作共识，其次得主动拿出行动方案，在合作过程中如果遇到合作不畅的问题，寻求双方的共同 leader 来做判断指导。具体来说：

首先达成合作共识环节，主要是得先理清合作事项的背景、目的和意义，带着这三点去跟对方提出合作要求，哪怕遇到对方的询问，也能够及时给出合作的理由，保证双方对此次合作的重要性 and 必要性先达成共识。
