# 01 什么是预期管理？

预期管理应该分为两类，自己对自己的预期管理和他人对自己的预期管理，为了贴合题目，只讨论他人对自己的预期管理。

既然身在职场，既然谈到管理，相信每个人都希望通过管理他人对自己的预期，来达到一定的目的，这个目的可以是自我成长，可以是同事关系融洽，可以是得到领导重用和栽培。

我理解的预期管理，就是当领导交代一项工作，或者需要配合同事一项工作的时候，拿出百分百的认真态度去完成它，这时候领导和同事对自己有一个初步的预期，且相对不低；在下一次的时候可能会交代难一点的工作任务，这时候还是拿出百分百的认真态度去完成它，自己的能力得到锻炼和成长，领导和同事对自己的预期也会提高，将会鞭策自己更努力提升自我，从而完成更有难度的工作任务。这样形成一个
