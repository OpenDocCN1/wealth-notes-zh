# 2. 以不变应万变：稳住情绪该咋咋地。

职场并没有稳定不变，黑天鹅或许才是常态。
上线系统会有 bug，系统稳定会有新需求。特别是在今年特殊的外部原因影响下，杂乱的工作需求更加接踵而来，各种工作冲突人际冲突也极易爆发。情绪稳住不要崩，一步步拆解不同的工作即可，自然可以将杂乱梳理至有序状态。但情绪一崩，杂乱的工作内容更易随之崩塌，又反作用于情绪，形成恶性循环。
