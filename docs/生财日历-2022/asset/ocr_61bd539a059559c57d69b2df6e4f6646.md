# 如何做好
私域流量的运营？

蒋晖

电商培训平台 “猫课” 创始人

每个行业的用户不同，私域的服务体系也不同。在电商培训这个竞争激烈的小赛道，关于私域流量运营，我认为最核心的，是做对用户有价值的事情。

这就需要我们在团队搭建及考核上，将设定的目标和客户利益保持一致。比如，销售的定位是 “用户的顾问”，如果客户不需要，就不允许推销产品。而这一点也贯彻在团队的薪酬设计上，我们不使用提成制度，不把业绩作为奖金参考，仅作为次要考核指标。

私域要与用户交朋友，长期来看，要把价值观看成非常重要的运营成果。
