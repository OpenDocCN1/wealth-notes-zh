# 快递行业有哪些需要避开的坑？

安信
7年电商领域创业者

我见过很多靠做快递赚到钱的，但他们都在这个行业里摸爬滚打了很多年。当然，我不是说快递不可以做，这个行业多是脏活、累活，很辛苦，同时，刚入行容易踩一些坑。

我以做快递一年亏掉了几十万的经历告诉你，一定要注意防范以下风险：

+   1. 最好的网点，不会轻易让你加盟。
2. 网点的一部分业务其实不赚钱，但报给你过高的估值，以提高转让费。
3. 中转费随意调价，成本不受控制。
4. 快递丢失、派送延误会带来高额罚款。
