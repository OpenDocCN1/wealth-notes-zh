# 做了新产品，
怎么发售效果更好？

鱼丸
“生财有术”社群运营

好的发售效果是新产品成功的一半。想要让一个新产品获得更好的发售效果，应该在发布这个产品前，先发布一个其他的小产品做测试。

这样做，能做好势能积攒，获得浪潮式发售。要知道，“做产品，就是把千钧之石，推上万仞之巅，积蓄势能，然后通过营销、渠道的方法，把势能转化为动能，覆盖尽可能多的消费者”。之后，才能趁热打铁，乘胜追击。

当首发做得好，趁热推出新产品，还可以使用宣传文章、主动投稿等方式，扩大影响力。
