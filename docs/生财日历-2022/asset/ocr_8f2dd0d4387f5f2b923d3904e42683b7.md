# 如何从线上连接大佬？

郑小焦

高端酒店前经理，现跨境电裔创业者

人际关系中最令人向往的是礼貌和真诚，从线上连接好友，更需要你的礼貌和真诚。

在加好友前，请想想为什么要连接这个人，并主动对他做一些了解。如果没有目的，不妨等一等。

在申请好友时，说明和对方的关系，比如是谁介绍的、同在一个群等，以及你添加的目的。

加上好友后，及时介绍自己、说明来意，在提问前可以多做些准备，珍惜对方的时间，并给到及时的反馈。
