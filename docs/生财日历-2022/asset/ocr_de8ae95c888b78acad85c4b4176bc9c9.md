# 如何快速学习
他人的成功经验和认知？

刘小排
“猎豹移动”前产品总监

想要用好别人的经验和认知，我有一套独家心法——“守、破、离”：

+   1. “守”：进行“像素级”的模仿，不要偷懒、不要取巧、不要偏见，别人怎么说，你就怎么做，动作一丁点儿都不要变形。用一句话总结——做一个愿意下笨功夫的聪明人，直到获得成功。

+   2. “破”：从模仿走向超越。有两种方法：第一，比别人做得好10倍；第二，壁垒的差异化，你需要为项目创造一个新的套路，而这个套路，与你的特有技能相关，你能做到，别人几乎做不到。

+   3. “离”：借用其他项目的招式，组合和创造新的项目。
