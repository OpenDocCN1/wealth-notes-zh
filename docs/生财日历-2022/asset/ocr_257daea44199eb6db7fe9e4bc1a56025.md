# 如何培养发现
信息差商机的敏锐度？

派大星
跨境电商数据分析师，流量获取专家

想要靠信息差赚钱，能赚钱的信息来源是整个过程最核心的一环。因为同样一个信息，大部分人反应是：“哦，这样的啊。”但有敏感度的人下意识都会想：“这个有利润，做起来！”后者几乎肯定会更快地赚到钱。

所以，我会刻意训练自己的信息敏感度：

+   1. 加入同类圈子，让自己长时间浸泡在高浓度的信息里，提高接触频率，这类似于环境对人的影响。

+   2. 积极了解过往的赚钱项目，并做好横向迁移。比如我之前做外卖淘客项目时用过一些获客方法，我再去做别的需要获取流量的赚钱项目时，就会去思考是否能将同样的思路复用。
