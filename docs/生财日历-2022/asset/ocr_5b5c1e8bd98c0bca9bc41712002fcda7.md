# 怎样挖掘“隐形商机”？

老华

米课创始人，投资人，“老华带你飞” 主理人

市场的隐形商机往往来自“感觉”，这并不是通过数据“分析”得出的，而是通过体验、挖掘，凭借自己的敏锐度“做出来”的。

我曾经在新西兰的一个平台上买到过一辆价格远低于市场价格的二手车，几周的时间转手赚了6000新西兰元。随后，通过挖掘它的公开信息，找到了一个大部分华人都不知道的商品交易网站。通过在这个网站出售电子产品，8个月获得净利润100万元。

很多落地并赚到大钱的项目，可能和最初的想法完全不是一回事。再厉害的MBA 也无法计算出隐形商机，隐形商机都是靠“做出来”的。
