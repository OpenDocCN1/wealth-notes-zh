# 传统行业转型
互联网发展的核心是什么？

蒋超
“EWG1990仪器学习网”创始人

传统行业的实体企业在进入互联网之前，大多对互联网的感知都在前端，但我认为，传统行业进入互联网的核心关注点应该在后端。

对于传统行业而言，重要的是“能不能解决问题”，而不像互联网社交和游戏，对体验要求那么高。所以对于传统行业，进入互联网就要少花点时间在设计上，先做好最强大的基本功能——要有服务，随点随到。

不论是轻资产互联网还是重资产互联网，只要是在传统行业，优势机会还是在行业人手中，毕竟这需要理解行业和整合产业链，不是开发一个 App 就能迅速解决的。
