# 提高个人影响力
要注意哪些问题？

范米索
中小企业主业务增长顾问

在做个人 IP 和社群之前，先反问自己四个问题：

+   1. 如何获得他人的关注？
2. 如何获得他人的持续关注？
3. 如何维护粉丝忠诚度？
4. 如何提供给粉丝不一样的价值感？

做 IP 不是仅仅做 IP，更要做自己。伪造的人设，终有一天会面临崩塌。每个人都在追求独特性，但是都避免不了迎合市场喜好去做人设。然而，通过投机而获得的大量粉丝和关注，用户会在发现问题或遇到一个比你更完美的人时，随时将你抛弃。
