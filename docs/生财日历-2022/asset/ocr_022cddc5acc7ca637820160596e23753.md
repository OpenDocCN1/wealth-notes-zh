# 如何避免
一天天的时间被荒废？

易仁永澄
目标管理专家，“幸福进化俱乐部”创始人

一天的时间没有利用好，大部分人反思起来，大概是这样一些原因：畏难拖延、状态不好、不专注、动力不足、坚持不下去……

很多人觉得，这是自己的状态问题，于是拼命地希望自己更自律、更有自驱力，但其实状态是一种结果，而不是原因。

核心的原因是，你内心并没有一个明确的目标——我到底要一个什么样的东西？这个目标要有一些特点，比如说它要有名字，要具体而明确。第二，是你特别想要的，你心中得憋足了劲儿。

所以，关键在于找到明确的目标，这样就能避免一天天的时间被荒废。
