# 如何在主副业中
做出正确的取舍？

周森 Forest
索尼（中国）签约摄影师

当你提出这个问题时，一定是因为主业不能让你完全满意，但又对于主业给予的一些事物，比如金钱、名声等有所依赖，短期内不可能脱离。

所以，当你问出这个问题时，最好的办法是在维持主业的同时，努力去寻找一个符合自己内在驱动力的副业。

我在主副业切换的过程中，看似是完成了一次职业身份的切换，但内在其实是我对自己所需、所想、所要的答案越来越清晰，进而决定了我的外在选择不断调整。副业，就提供了一个帮助你低成本寻找内在追求的机会。
