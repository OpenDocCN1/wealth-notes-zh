# 都说放眼未来，
为什么有人说要少提愿景？

鱼丸
“生财有术”社群运营

创业路上，大家都说要放眼未来，但其实也需要少提愿景。不要纠结愿景，要多试错。现在的创业环境是很拼速度的，愿景搞得太远，其实等于没有愿景，少吹硕大的牛，多去迎合市场需求，才是比较好的做法。

同时，打造价值观相同的好团队比把愿景挂在嘴边有用得多。而比起寻找愿景，打造经营体系更为重要。比如虚心接受所有的不同的声音，认真发私信给客户聊行业和需求，切实帮客户解决问题等，这些才是比较好的做法。
