# 如何做好视频号？

萧大业

创业导师，天使投资人，视频号博主

视频号本质上帮助解决了连接和信任的问题，这对于任何生意都是一把利器。但是需要明确一点：视频号不是朋友圈，受众基本上是陌生人，对你不了解。

关于如何做好一个视频号，我想分享以下五点经验：

+   1. 定位精准，需要确定是以人为主、打造个人IP，还是选择垂直短内容输出。
2. 要有复盘思维，每个视频播出后都需要关注五个数据：浏览、点赞、评论、转发和收藏。
3. 向优秀的人学习。
4. 一定要以内容为主，运营相辅。
5. 努力打造爆款；因为1支爆款视频带来的正反馈可能高于10支普通视频。
