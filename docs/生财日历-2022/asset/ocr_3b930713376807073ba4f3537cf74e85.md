# 如何判断一个产品
值不值得做？

Kris

“一行 DoMore”创始人，“Kris 在路上”主理人

从众多的产品中，判断一个产品值不值得做，其实质就是在思考如果要做，“为什么”做这个产品。

这时，我通常要问自己三个问题：

+   1. 这件事是不是我最想做的？要让使命和价值观先行。

+   2. 我有没有资格做？我说的，一定是我做得到的。

+   3. 我能不能让大家拿到结果？比如像“生财有术”这样一个专门教人赚钱的社区，让普通人赚到钱是最“结实”的交付，比更多的产品功能、再贴心的服务都更要有力量。
