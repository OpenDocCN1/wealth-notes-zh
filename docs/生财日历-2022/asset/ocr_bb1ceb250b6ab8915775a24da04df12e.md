# 运营从业者
如何持续成长？

龙共火火
“霄霞互动”创始人，《高阶运营》作者

在具体工作中，运营从业者通常要养成五个习惯：

+   1. 良好的时间管理习惯。包括建立自己的计划表、执行贯彻计划、及时复盘。

+   2. 写日报、周报的习惯。比起汇报工作的复盘，更重要的是对自己每天工作的复盘。

+   3. 常发、刷朋友圈的习惯。培养网感，增加自己对热点事物的预判能力。

+   4. 探究事件本质的习惯。不要人云亦云、跟风表态，多去提升发现、分析、解决问题的能力。

+   5. 多讨论交流的习惯。结交圈内好友，多与他人探讨、交换意见，不要孤军奋战。
