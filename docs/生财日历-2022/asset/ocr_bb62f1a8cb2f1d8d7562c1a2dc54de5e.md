# 如何成为一个
合格的管理者？

丁邱洁
前科技企业高管，现律师

什么是“合格的管理者”？简言之：事办妥，人优秀，能为新人提供明确指引。

+   可以通过以下路径成为一个合格的管理者：
1. 为自己设定一个带有时间长度、精细到每一天的目标；
2. 回归岗位，多思考，多问自己：这个岗位存在的价值是什么？
3. 超预期交付本岗位职责后，提炼出属于本岗位的 SOP，与岗位的上下游轻松协作；
4. 提升格局，在大小事务中做到以企业利益为重；
5. 学会跨界，在精通本领域的基础上，通过超强的学习能力，跨行业学习强关联领域；
6. 在自我管理达到极值后，带领团队推进，达成企业目标。
