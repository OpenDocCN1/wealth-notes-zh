# 如何通过参与社群
收获更多价值？

周进
内容创作者，网络营销咨询顾问

很多朋友希望社群里有很多可直接复制的信息，自己照抄就可以。但是，这种被动的等待，永远不可能获得最好的效果。当你为一个社群付费时，就要学会主动去获取价值。

我总结了以下五步：

+   1. 通过大量的信息输入，不断颠覆固有认知，改造自身。
2. 在所有的庞大的信息量当中，抓到自己真正内心想关注的，然后聚焦。
3. 与社群内成员互动并积极参与社群内的活动。
4. 当你在面对大量信息并能够足够从容时，输出自己的思考。
5. 学会之后，实践、实践、再实践。
