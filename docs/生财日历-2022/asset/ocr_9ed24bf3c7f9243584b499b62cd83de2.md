# ## 如何高效地模仿
## 爆款视频？

阿扶 frits

B站42万粉丝科普类博主

爆款视频意味着高度的流量关注和更好的变现能力。模仿爆款视频，简单说就是我们成功路上的捷径。

形式的模仿相对简单，比如画面和音频上，找到标志性的画面素材和 BGM（背景音乐），就可以模仿得差不多了；文案这一块，需要学习别人的叙事风格，看原视频如何开头、结尾，会用哪些口头禅和“梗”（哏）。

不过，想要极大程度的还原，做一次成功的模仿，还需要理解创作者背后的内核。只有当你真正理解想去模仿的那个人，愿意去相信他们所相信的东西，模仿才可能注入灵魂。
