# 创业公司如何获得
更多政策扶持？

罗建国
石油天然气科技公司总经理

政府给创业公司的优惠政策五花八门，学会找到有利的政策也是企业需要具备的能力。

常见补贴有：大学生创业补贴、初创型企业补贴、企业高层次人才认定补贴等十多种。常见补贴方式有：现金、场地、贷款减免、资源等。

想要了解这些内容，最直接的方式是多关注政府各个部门的网站，搜索补贴政策，寻找适合自己企业的项目。不过，这些补贴的信息都散政府在政府各个部门，如果你的时间、精力有限，建议可以找中介聊一聊。
