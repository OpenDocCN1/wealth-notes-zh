# 如何在各种视频平台
创作属于自己的爆款视频？

俊一
区块链创业公司商务总监

爆款视频有几个重要意义：能给你带来大量的关注、增加很多微信好友、帮你对自己的变现产品产生订单……

而爆款视频又不是凭空而来的，每一条爆款视频背后都是平台用户的喜好，在不同时间内有着相似的规律。

深入研究平台上足够多的爆款案例，尤其注意拆解、分析其中每个细节和亮点，学习它显性、隐性的各种框架、表达、节奏、设计，然后模仿，根据数据反馈做优化，慢慢就能创作出符合自己风格的爆款视频了。
