# ## 如何避免 “小富即安” 的心态？

陈朝昌
“一码当先”创始人

在创业圈里，本来没有人的内心希望自己小富即安，但依然有很多人不知不觉陷入舒适圈，在能够维持缓慢增长的情况下，也没有对自己的产品不断迭代。

想摆脱小富即安，你可以这样做：

+   1. 找到一个有野心的圈子。深度学习某一个领域的知识，建立新认知，习惯为别人创造价值。
2. 给自己足够多的心理暗示。互联网是一个新的行业，每个细分行业都有机会成为头部，多问问自己：为什么不能是我？
3. 积累成功经历。对事业有更高的要求，同时提高对自己所在行业的认知。
