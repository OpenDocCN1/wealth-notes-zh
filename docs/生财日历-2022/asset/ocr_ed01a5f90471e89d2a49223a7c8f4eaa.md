# 普通人值得去做个人 IP 吗？

**花爷**
商业分析师，自媒体领域创业者，“花爷梦吃换酒钱” 主理人

我认为不管是有生意的创业者、副业者，还是有优势的普通人，自媒体 IP 这件事，都值得去做。
有生意的人，可以用个人 IP 来提升影响力，并进一步扩大生意：大企业有品牌，而对中小企业主、创业者、副业者来说，做品牌太难了，建立影响力和信任就要靠个人 IP。
有某方面的经验、资源、特长、爱好，但是还没有做成生意的普通人，凭着自己的优势做 IP，可以扩大业务。而随着业务扩大，个人 IP 的影响力更大，从而连接到更多“牛人”，并与之合作。
