# 创业团队在招人之前
要做好哪些准备？

许范范
世界500强区域人力资源部门副总

对于招聘标准而言，最重要的不是岗位职责，也不是来之即胜任的要求，而是岗位价值梳理。同样是销售岗，有些岗位的价值，是为新开拓方向客户提供解决方案，以解决公司新领域突围问题；有些岗位的价值，是为销售团队提供销售技能培训，以提升团队整体能力。

所以，在招人之前，你需要想清楚设立这个岗位是为了什么，以及你招这个人能为我创造什么样的价值。以终为始，尽可能拆解出招聘岗位的需求。
