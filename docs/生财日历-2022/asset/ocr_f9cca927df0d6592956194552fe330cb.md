# ### 如何在火热的直播带货行业中差异化创新？

**杨洪进**
互联网产品专家，“蝉妈妈”“蝉大师数据”联合创始人

现在的互联网市场中，“前三以下”就意味着辛苦并且没有头部赚钱，这也是为什么强调需要保持差异化创新。

具体到直播带货行业，除了产品要极具竞争力，还需要做好以下三个关键点：

+   1. 深耕兴趣电商，化被动营销为主动影响，吸引兴趣消费者进入直播间，通过直播内容的互动性和趣味性提升转化。

+   2. 数据化运营直播间，多维度分析直播数据，对标头部找差距、找原因，再找解决方案。

+   3. 差异化选品，提高覆盖率，将品类、价格、适用人群有序分布，方便各级消费力群体下单。
