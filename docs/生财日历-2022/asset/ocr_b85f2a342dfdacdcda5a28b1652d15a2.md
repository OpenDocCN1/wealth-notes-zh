# 如何避免陷入舒适圈？

白一皓

自我教练教练，组织发展教练

每个人都有自己的舒适圈，做舒适圈内的事，不用动脑子就能很舒服，但没有成长。舒适圈的外面一层是能力圈，是过去知识和经验的积累。那里面的事，稍微有点不舒服，但是能做，失败的概率比较低，即便失败了也能快速调整。而能力圈以外一层，就是错觉圈，在那里你既无法有效地思考，也不能高效地完成事情。

大多数人会高估自己的能力，尤其是看到“舒适圈”时，这也是我们难以坚持的原因。我们应该不断提升认知能力，清楚意识到自己的能力圈，缩小错觉圈，把目标定在能力圈之内、舒适圈之外。
