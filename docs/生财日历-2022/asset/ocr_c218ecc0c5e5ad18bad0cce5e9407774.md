# 想做一个带货 IP，
有什么注意点？

天枢
5年新媒体策划人，知乎带货达人

带货，是一个很宽泛的词汇。想成为一个优秀的带货 IP，更是要注意下面这四项：

+   1. 选择自己要做的品类，在垂直领域进行深挖。定位品类的三个判断标准是感兴趣、有能力、市场需要。

+   2. 在打造 IP 前期，目标是积累粉丝，通过树立人设并获取信任，提高权重，在这个过程中，打磨自己的内容，确立更新频率。

+   3. 用户的消费链条是“关注→决策→购买”，所以我们的内容要帮助用户决策。

+   4. 当单个账号跑通后，可以增加品类，打造新的 IP，做账号矩阵。也可以成为付费玩家，通过在平台购买付费流量，提高收益。
