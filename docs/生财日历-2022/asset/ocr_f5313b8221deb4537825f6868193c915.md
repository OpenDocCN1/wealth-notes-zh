# 如何培养个人写作能力？

天枢
5年新媒体策划人，知乎带货达人

永远不要等到准备好了再开始写，而是边写边提升。

如果你不知道如何动笔，没有值得写东西，可以从收集这五类信息开始，积累写作素材：

+   1. 选题库，关注你认为值得学习或有团队的大号，收集他们的选题；2. 标题库，把你平时看到后自己都想去学的标题收集起来；3. 故事库，可以是自己的经历、听来的经历或者是网友的经历；4. 金句库，收集让你感觉到醍醐灌顶的一句话或者一段话；5. 思维模型库，可以帮助我们构思文章框架，比如“黄金圈法则”“六顶思考帽”“九宫格分析法”“十条清单体”等。
