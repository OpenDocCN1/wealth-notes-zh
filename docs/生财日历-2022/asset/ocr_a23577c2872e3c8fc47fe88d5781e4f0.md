# 有哪些价值观 适合初创团队快速成长？

黄小鱼 “生财有术”运营，“生财日历”项目负责人

在团队价值观统一时，我们设置了这样的六条价值观，供你参考：

+   1.  主动沟通，敢于暴露问题。 2.  如实反馈，不怕得罪任何人。 3.  开诚布公，有事放上台面聊。 4.  言出必行，重视约定和截止时间。 5.  长期主义，不拘泥于小失败。 6.  持续精进，善于通过复盘成长。

打造一个鼓励说真话的团队，让团队成员能随时表达自己的真实想法，不要怕争吵。在这样的背景下，价值观能更好地落地。
