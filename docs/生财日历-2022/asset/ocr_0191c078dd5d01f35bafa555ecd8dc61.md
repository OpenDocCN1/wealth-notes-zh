# 怎样通过思维优势
在传统行业“降维打击”？

入海

360旅游原负责人，私家车托运行业创业者

传统行业的大部分公司从网站、客服、品牌到用户体验等各个环节都有极大的优化空间。

从更惊喜的用户调研，到通过投放和SEO获客，再到高辨识度的形象、Slogan（宣传标语）等品牌设计，最后到系统化的流程沉淀、系统搭建、用户体验与风控，都是传统行业可能欠缺的地方。

因此，带着互联网思维找偏传统行业的细分市场，深耕细作，是一个很好的切入方向。“竞争对手”是传统行业的“打法”，其效率、能力、思维差距很大，留给你试错的时间和空间都很大，也很容易形成“降维打击”。
