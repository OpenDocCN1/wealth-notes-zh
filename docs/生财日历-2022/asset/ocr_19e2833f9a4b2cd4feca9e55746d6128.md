# 如何理解
社群与 IP 的关系？

花爷

商业分析师，自媒体领域创业者，“花爷梦吃换酒钱”主理人

以前做线下生意，门店位置非常重要，它直接决定了人流量大小。现在，人都聚在自媒体的粉丝里，在各个社群里。

社群就像是房地产，不同属性的人，住在不同的小区。拿住了优质地段和优质用户的小区，自然就有了很高的价值。而抖音、微信这些平台，顶多算是小区物业，他们可以触达用户，但和用户没有深度连接。

真正跟用户深度连接的，是社群里的 IP。IP 就像“包租公”，最厉害的不是收房租、做转化，而是能更有效率地连接资源。因为你身为“包租公”，能认识更多的人，信任和资源利用的门槛更低。
