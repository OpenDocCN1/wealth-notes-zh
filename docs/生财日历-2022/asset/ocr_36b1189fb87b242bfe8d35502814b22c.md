# 品牌现在值得布局抖音电商吗？

赵鑫
自媒体创业者，“老赵营销笔记”主理人

抖音电商是品牌商们的新战场。无论是抖音直播、抖音短视频还是抖音 SEO（搜索引擎优化），都将会是品牌获得更多新客户的重要手段，且它们直接相互配合，不可分割。抖音电商 = 兴趣电商 + 交易电商。这个平台让我们看到了品销合一、缩短购买决策链路的可能性。

在我看来，品牌布局抖音电商是必然的，可以从以下三个角度分析：

+   1. 品牌在“淘系”获得的流量可能会越来越少。
2. 抖音自身电商闭环的形成，会使得它向“淘系”引流逐渐变难，且成本上升。
3. 抖音电商是当下的风口，会给品牌带来更多商业可能性。
