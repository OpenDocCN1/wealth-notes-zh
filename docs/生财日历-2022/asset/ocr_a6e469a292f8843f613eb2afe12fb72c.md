# # 什么样的销售团队
# 能够吸引人才?

华子
16年软件销售管理者，擅长软件服务销售

吸引人才，标杆非常重要，只有树立好标杆后，才能让销售人员感觉到不仅能看到钱，还能赚到钱。

至于留住人才，没有想象中的那么难，下面的三点中能做到两点，就已经足够留住人了：

+   1. 赚到钱。大家在北上广深一线城市，都不好混，都想要赚钱养家糊口。

+   2. 学东西。大家都是为了自己的发展和职业规划，所以要能学到东西。

+   3. 交朋友。有一帮能没事一起吃个饭喝个酒的朋友。
