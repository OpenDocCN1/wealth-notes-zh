# 如何提升自己
持续赚钱的能力？

亦仁
连续创业者，“生财有术” 创始人

支撑“持续赚钱”这件事的，是更高阶长期主义的思考力，是以持续创造价值来应对市场与商业不确定性的实践力。在“生财有术”，我们将这种思考力与实践力，并称为“生财力”。

提升“生财力”，需做三件事：第一，提升商业认知，增强判断力。这很难。包括坦诚、笃定、自驱、皮实、长期主义、辩证思考力，等等。第二，纵观行业案例，拓宽视野。可能是从理解跨境电商卖家、短视频玩家、独立开发者、形象规划师、精算师、战略顾问、连锁超市老板、家政公司创业者等何以在商业丛林中立足开始。第三，认识更多同频高手，看见榜样的力量。向那些和我们一样，但是已经凭借自己的双手改变了人生局面的普通人学习，给自己更多信心和耐心。

生财之路，道阻且长。但相信我，这条路上，你并不孤独。
