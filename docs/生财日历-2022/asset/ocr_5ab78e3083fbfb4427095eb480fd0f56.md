# 有哪些渠道
可以获取高价值信息？

张秋兴

区块链领域研究者

很多人对高价值信息有需求。有需求，就有机会。

高价值信息往往有一个特点：不会很快地大范围流通。

可以通过高质量的微信群、付费圈子、小众高手、垂直领域平台来了解和获取。

但还有一个特别的思路：把自己打造成高价值信息的中心。

创建并维护多个群，供那些和自己有同类信息需求的人做信息互换、生意合作。前期免费，并大力维护，自己也贡献通过各种渠道获取的信息，久而久之，认识我的人越来越多，和我有过合作交易的也越来越多，群价值与日俱增，逐步吸引更高价值信息的流入。
