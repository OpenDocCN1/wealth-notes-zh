# 电商行业竞争那么激烈，还有赚钱机会吗？

佳境
“柒个梨”创始人、蓝海店铺创业者

电商的竞争越来越激烈，作为普通人，想要赚到钱，选品至为重要。

这里推荐一种选品思路：把微商在私域里卖得好的产品，迁移到淘宝等电商平台去卖。虽然不一定能打造成爆款，但往往能稳定出单。

背后的逻辑很简单：

+   1. 这样的产品没有太多同行竞争，这意味着你不需要烧太多的钱，没有价格战。
2. 当用户在私域消费时，相比传统平台，往往需要更高的信任度才会下单，把私域里卖得好的产品搬到传统电商平台上卖，相当于“降维打击”——因为公域平台对用户来说是信任度更高、成本更低的通道。
