# 普通人如何“破圈”成长？

光合
战略咨询顾问，“生财有术”合伙人，“华与华”前项目总监

人生是不断“破圈”的过程和结果，每一个圈子都会影响我们的认知、行为和成长。想要“破圈”成长，需要我们具有高阶输出能力，能给别人输出更多价值，最后你会发现，“破圈”只是个顺带的结果。

+   而拥有高阶输出能力，需要做好以下四件事：
1. 读，是普通人最低成本获取优质信息的核心途径。
2. 听，是你要先连接到某些人，还要能让他愿意真诚分享、倾囊相授。
3. 写，会激发更深层次的思考，倒逼自己持续获取大量信息，经过消化后再继续写。
4. 说，是面对别人，将你深化思考的东西讲出来。
