# 赚快钱对心态
有哪些负面影响？

夜息
SEO 专家，“百康科技”CEO

很多挣快钱的业务做多了，会让人非常非常的膨胀和没有耐心。

比如，我的一个朋友，做惯了流量挣钱的业务，对挣钱的容忍度已经非常低了。他说，一个业务如果在一个星期内挣不到钱，他就会怀疑这个业务还能不能做。他对很多业务已经失去了持之以恒去研究的能力。

所以赚快钱有必要，但会消耗掉战略定力。最开始为了生存、为了培养自己的市场敏锐度，可以尝试。但你不能指望靠赚快钱来发大财，最后还是要选一个行业认真做，并且是一个具体的业务，一个能上台面的行业。
