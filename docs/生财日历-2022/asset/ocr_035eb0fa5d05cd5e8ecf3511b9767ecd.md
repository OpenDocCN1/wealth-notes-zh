# 普通人如何通过“拆解别人”打开圈层视野？

小夏
木杨夏子文化传媒工作室创始人

什么样的人算生意场上的普通人呢？没有团队、不懂技术、没有资源、不了解行业、信息落后的，但这样的人依旧有很多赚钱的机会，只要他拥有执行力，能多拆解案例。

当然，拆不是毫无目的地拆，有这样三个方向：

+   1. 关注别人宏观的商业模式，这样才能在自己做的时候调用、借鉴，想出更多的玩法。

+   2. 在很多时候过程做好了，结果是自然而然的，所以在拆案例时，要关注别人的操作细节，而不是成功的结果。

+   3. 进行“活人拆解”，以年份、年龄为线索，把大佬的个人经历盘点一遍，看他在每个关键节点是怎样思考和行动的。
