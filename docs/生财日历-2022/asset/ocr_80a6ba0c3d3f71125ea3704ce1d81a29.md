# 如何做好  
一个垂直类短视频 IP？

艾乐  
“96编辑器”COO，商业类短视频博主

打造垂直类短视频 IP 的五个核心点：

+   1. 打造 IP 的核心是打造标签。通过内容来反复强化这些标签，从而让用户记住你。

+   2. 不要让你的专业绊倒你。对用户适用的“专业内容”一般具有普适性、低门槛、简单易懂、获得感强等特点。

+   3. 做用户喜欢看的内容，而不是你认为的好的内容。

+   4. 先模仿再超越。短视频新手，先模仿再创新，无疑是最高效的方式。

+   5. “好内容 + 好运营”是标配。内容决定 IP 能走多远，运营决定 IP 能走多快。
