# # 不懂技术的人
# 如何培养数据意识？

痴海

数据挖掘工程师，自媒体创业者

培养数据意识的核心，是想清楚目标，在拆解目标的过程中倒推需要的数据。

假设我的目的是提高工资，而工资的高低和自身能力的强弱有关：能力越强，则工资就越高。能力的提升，一定程度上取决于学习时长。

这时候就可以量化成：我每天花若干小时，才有可能提高某项能力，从而提高自己的职场竞争力，达成薪资翻倍。于是，核心数据指标之一就是学习时长，关注并优化它即可。

时常拆解生活中的小目标，日积月累就能培养出数据意识。
