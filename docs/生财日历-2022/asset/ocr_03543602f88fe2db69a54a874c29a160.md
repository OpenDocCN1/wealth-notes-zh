# 招聘时，
怎么判断面试者的能力？

尹晨

尹晨俱乐部创办人，直播带货创业者

+   以面试直播主播为例，我会从业务经历、实战能力、行业判断、个人意愿这四个方面去判断：

1. 业务经历。在哪里直播过？卖的是什么品类？有哪些账号？如果描述经历时比较模棱两可，就不用继续了。
2. 针对经历追问，深度挖掘他在项目成果中创造的价值。
3. 让他描述自己的业务模式，因为目前带货打法比较集中，根据他描述的清晰程度可以判断他的能力。
4. 问为什么选择来我们这边？一般做运营厉害的人，对公司是非常挑的，而不挑的人，大概率是包装了数据，哪家价格给得高就去哪家。
