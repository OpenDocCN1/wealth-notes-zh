# 如何给自己的社群做定位？

芷蓝
“玩赚新媒体”创始人
“社群定位”课程主理人

社群定位准确，才能不断吸引精确的人群，让社群发展形成正向成长。

因此，首先需要想清楚做社群的原因、做成什么样的结果、如何开始操作。

然后，通过三个方面来定位社群：

+   1. 这事能赚钱，保证未来能通过社群变现。
2. 内容可持续，持续地在群里输出内容，维持社群运转。
3. “这事我喜欢”，心怀领域内的理想与热情。

在实践过程中，不断地迭代与修正社群定位，以迎合更多成员的需要。
