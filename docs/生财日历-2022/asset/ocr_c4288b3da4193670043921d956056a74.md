# 创业者如何保持
自己的身体健康？

梁靠谱

三甲医院主治医师，科普类博主

健康相关的内容展开聊起来会很多，以下重点说下和工作、创业比较相关的六项：

+   1. 饿了吃，吃饱停，困了睡，不憋尿。

+   2. 减压用运动、唱歌等方式，戒烟忌酒。

+   3. 持续运动，尽量持续运动多年。

+   4. 不要讳疾忌医，重视身体发出的信号，及时调养、就诊，定期体检。

+   5. 在自己常待的地方放置健身器材、血压计，常提醒才会常敬畏。

+   6. 有意识地通过内服、外用药作为保健方式，但途径要正规科学，不听信偏方，辩证看待非专业的家人朋友提供的传统医疗经验。
