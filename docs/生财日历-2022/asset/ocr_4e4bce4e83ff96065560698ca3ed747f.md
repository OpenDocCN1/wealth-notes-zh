# 进入一个新的行业，
如何快速走上正轨？

小鹿

抖音小程序领域创业者

我从化工厂裸辞后，入行抖音小程序。第二年赚到40万，团队收益100万。回顾这次冒险，能在全新的行业快速站稳脚跟，走上正轨，我认为我做对了三件事：

+   1. 抓住机会，虚心学习，在还没有入门的“小白”阶段，认真研究所有资料、规则，遇到比自己做得好的朋友就虚心请教。

+   2. 互帮互助才能快速成长，分享的同时自己也是一种新的学习，在“小白”群有突出的表现也给了我机会进入更高的交流圈子。

+   3. 珍惜时间成本，善用知识付费——自己摸索不如花钱快速学习别人几年的经验，缩短回本周期。
