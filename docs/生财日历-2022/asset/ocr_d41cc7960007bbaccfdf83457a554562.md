# 赚钱路上
如何提高执行力？

明白
技术专家，自媒体人，“多元思维 Hack”主理人

提高执行力，本质上是在提高学习和适应的能力，核心在于两点：
1. 行动层面。提高自己的学习能力，把一件复杂的事情，拆解成可以直接上手的小步骤。这可以通过大量模仿来完成，看做成这件事的人是如何制订计划、拆解任务的，模仿他们即可。
2. 心理层面。增强自己做事的动力，在做事前想象一下，这件事能给自己带来哪些巨大收益。你想象得越清晰、越有色彩，你就会越兴奋，动力就越强。
做到这两点，执行力自然会更强。
