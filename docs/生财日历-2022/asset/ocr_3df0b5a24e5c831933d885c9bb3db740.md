# 如何找到
打击竞品的切入点？

小马宋
小马宋营销咨询创始人，战略营销专家，“得到” App 营销顾问

首先要思考顾客购买竞品的目的是什么？其实顾客购买一件商品，本质上是想让这件商品帮他完成一项任务。

顾客购买婴儿纸尿裤就是为了完成照顾小孩子拉尿的任务；但购买劳力士的顾客想要完成的任务并不确定，有的是想随时知道时间，而有些顾客则是为了获得一个传达身份地位的物品。

当你去思考顾客的任务的时候，开发产品的思路也就完全不一样了。“顾客并不需要一个四分之一英寸的钻头，他只是需要一个四分之一英寸的洞。”

“钻头”只是产品，“打洞”才是任务。
