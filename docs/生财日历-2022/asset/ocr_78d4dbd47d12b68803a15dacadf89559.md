# 想利用自己的技能去做副业，
但是无从下手怎么办？

亦仁
连续创业者，“生财有术” 创始人

做副业的第一步，就是要有一个开放的头脑。

绝大多数人，脑袋里面跳出来几个赚钱的点子就以为是全部了，而实际的情况是，没什么成功赚钱经验的人，脑袋里面跳出来的前几个点子，都可以抛弃掉，因为随便使用都能得到的，一定不赚钱。

正确的做法应该是：首先，执行“头脑风暴”，拿出一张纸，围绕你的技能，至少列出50条赚钱的想法，靠谱的、不靠谱的都写下来。然后，去各种带搜索功能的内容库里检索，找个看跳出来的文章，以及延伸的关键詞，做好调研。最终，你会带着自己的经验，判断出几件可以做的事情。
