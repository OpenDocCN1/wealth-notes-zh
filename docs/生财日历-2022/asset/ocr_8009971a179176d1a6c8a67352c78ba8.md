# 如何看待
下沉县市的拼车业务？

孙策

线下拉新领域创业者

很多人觉得拼车生意在一二线城市更为火爆，但其实在下沉县市也可以有做成年赚百万生意的机会。该业务主要切入点是10千米以上的跨县拼车，通过搭建免费发布拼车信息的平台，让乘客与司机联系，收费则靠信息置顶和精准粉丝的二次复购。

它的成功主要归因于三个方面：

+   1. 都是同城流量，获客精准。
2. 把拼车用户沉淀到私域流量池里，产生长期复购。
3. 将拼车与多个垂直业务结合，低频积累，不断提升打开率。
