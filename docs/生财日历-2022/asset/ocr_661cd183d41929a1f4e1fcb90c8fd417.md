# 外卖品牌加盟
有哪些需要规避的坑？

闫寒

餐饮服务机构“闫寒餐饮智库”创始人

外卖品牌加盟看起来很红火，其实能持续赚钱的加盟品牌非常少，市面上许多月销过万的热门品牌都是通过让利或增加成本才堆起来的，纯靠加盟费盈利。新人入局要特别注意规避不靠谱的品牌。

总的来说，有以下六点需要规避：

+   1. “三不管”坑。没有公司的服务支持会寸步难行。
2. “产品”坑。调研产品的经营历史，不做新产品。
3. “盈利周期”坑。看商标，先认“®”，再考虑“™”。
4. “供应链”坑。产品统一走供应链的比例越高，越能赚钱。
5. “营销资源”坑。品牌投入了哪些真金白银的宣传。
6. “外卖运营”坑。不要幻想自己几天就能学会。
