# 普通人如何在
社群中结交贵人？

红忠哥耿律师
律师，互联网法律业务专家

我在加入一个高手如云的圈子后，刚开始也会觉得自己格格不入，后来我做了这样五件事：

+   1. 寻找社群“网红”，快速了解社群发展路径，挖掘自己身上的闪光点。
2. 连接官方人员，确定发展计划，充分展示自己。
3. 用金钱敲门，初步产生信任，快速撬动资源。
4. 分享、倒逼输入，让别人感受到真诚，建立影响力。
5. 成为官方活动的组织者，在官方的加持下，进一步影响他人。

在圈子里有了一定的影响力之后，我连接了不少大佬。
