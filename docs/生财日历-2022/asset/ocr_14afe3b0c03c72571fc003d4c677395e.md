# ## 怎样看待
## 个人影响力建设?

刘大猫
星火集团董事长

对于个人影响力，一定要重视根基建设，也就是自己实实在在的经验、经历、能力。

真正的个人影响力，无法依靠单纯包装、炒作而实现，而是要真正稳固根基，做一个有结果的人。这样，哪怕你没有任何所谓的名气与个人 IP，你依然能远胜过那些所谓拥有个人影响力但没有根基和成果的人。

那些只能靠包装、炒作维持影响力的人，时过境迁后都会被人发现是在“裸泳”。以“生财有术”创始人亦仁为例，他并没有关注表面的个人炒作，而是数年如一日地持续打造社群的根基和组织能力，在这样的过程中，他的个人影响力自然不会差。
