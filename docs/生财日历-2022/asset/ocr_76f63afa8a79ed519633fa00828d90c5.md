# 如何通过跨越圈层赚到钱?

花爷

商业分析师，自媒体领域创业者，“花爷梦吃换酒钱”主理人

赚跨越圈层的钱，其实质是让价值流通，就像以前商人把南方的货物卖给北方人，再把北方的特产卖给南方人，只不过我们的货物变成了信息，它有这样三种方式：

+   1. 利用圈层基数复制生意。一个圈子里能做成的生意，在另一个用户基数更大的圈子里也能做成，比如在抖音爆红的老照片修复、头像定制等，都是原来就有的生意。

+   2. 圈层降维。简单说就是利用信息差，比如年轻人知道而老年人不知道的，就是向老年人输出价值的机会。

+   3. 圈层升维。就是把信息打包，比如小红书里常见的各类清单、测评，都是这种模式。
