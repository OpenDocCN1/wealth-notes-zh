# 有哪些适合
普通人的致富路线?

北冥乘海生

科大讯飞前副总裁,《计算广告》作者, “计算广告”主理人

以下三条, 是普通人可以参考的致富路线:

第一条传统致富路线是人脉的路线, 适合擅长交友的人群, 需要娴熟的社交技巧, 依靠信息差、人脉来做生意, 壁垒在于自身资源。

第二条传统致富路线是人气的路线, 适合感染力极强的人群, 需要高超的感召能力, 依靠内容与体验服务来做生意, 壁垒在于表达力、组织力和获得信任的能力。

第三条路线, 靠逻辑与思考找到数字世界里微小的商业机会, 然后利用技术的力量将其大规模重复。

这三条路线各有优劣, 也各有风险。
