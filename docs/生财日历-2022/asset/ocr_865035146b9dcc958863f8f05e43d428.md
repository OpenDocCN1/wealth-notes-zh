# 如何快速成长， 超越同龄人？

傅超人

“知乎好物”平台创业者，内容带货课程导师

如何快速成长？我认为，“模仿，模仿后的总结，实践，实践后的总结，动力带来的执行力”，五者缺一不可：

模仿：确定模仿对象，探索其成长轨迹，在认知和执行方法论上模仿。

模仿后的总结：自省在认知和做事方法上是否有提升。

实践：即“像素级”模仿，因为往往脑子里想的，跟实际不一样。

实践后的总结：总结行为最本质的底层逻辑。

动力带来的执行力：“王侯将相，宁有种乎？”
