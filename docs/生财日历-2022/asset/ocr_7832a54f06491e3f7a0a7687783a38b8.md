# 如何卖爆一个产品？

甄希
营销广告人，连续创业者

想要卖爆一个产品，很重要的一点是要找到高频次的消费场景。

典型的案例就是“怕上火喝王老吉”。

找到高频消费场景的切入点有三个方向：

+   1. 横向时间轴。以“年”为单位，四季中有什么重要节日，它们都是节日场景。
2. 纵向时间轴。以“天”为单位，一个人从早到晚都要做哪些事，它们都是日常场景。
3. 纵向再拓展。不同类型的人群，每天都分别要做些什么？这些是不同人群的日常场景。
