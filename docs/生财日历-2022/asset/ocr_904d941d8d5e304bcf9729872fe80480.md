# 赚钱路上如何做好时间管理？

粥左罗
写作专家，向上生长学院创始人，“粥左罗” 主理人

赚钱路上的时间管理，具体的任务清单、“番茄钟”、“四象限法” 都是工具，更重要的是这些理念：

+   1. 要等得起。赚大钱往往不是朝夕的事情，要有战略耐性，敢以年为单位做规划。

+   2. 减少“赚钱时间”，留出“增值时间”。你接下来想赚到的钱数，靠现有业务、现有能力惯性推进能不能达到？如果不能，就要规划出时间，备战另一种可能性。

+   3. 80% 的时间做决定成败的事。赚钱路上要学会取舍，在无关紧要的事情上追求完美，特别耽误赚钱。
