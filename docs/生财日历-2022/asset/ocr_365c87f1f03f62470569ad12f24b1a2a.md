# 通过淘客生意赚钱
有哪些必要条件？

狗哥
6年淘客经验的95后创业者

淘客生意本质上是流量生意的一种，所以保持这三种思维模式是很有必要的：

+   1. 流量思维。任何流量皆可转化，要理解热点流量、精准流量、线下流量的获取和引导，多试错。
2. 复制思维。淘客行业变现路径较长，即使流量没有新增，也可以增加不同的渠道，提高整体利润。
3. 用户思维。淘客是复购率极高的行业，一个优质的用户一年可以产生上百次复购，还会推荐很多朋友成为你的用户，所以要对他们的需求足够敏感。

在这三种思维之下，做淘客赚钱的空间会更大。
