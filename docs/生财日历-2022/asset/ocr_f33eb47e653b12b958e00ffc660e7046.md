# 运动爱好者
有哪些生财机会？

老虎
跑步类社群创业者

每个运动爱好者都会有不同的生财方式，我可以分享下我这几年通过跑步运动赚钱的经历，供参考：

+   1. 广告。跑步类自媒体广告是我赚到的第一笔钱，从最初的600元一单到现在1.5万元一条，广告费是我的重要收入。

+   2. 带货。很多商品可以一键分销，基本清除了压货风险。

+   3. 活动。通过付费跑步活动，提供社群交流、打卡、计划、督导、颁奖等服务，满足大家的运动和社交需求。

其实还有很多与运动相关的机会，如办比赛、自产品牌、开发 App、做赛事主持、出书、知识付费、训练营……适合自己的才是最好的。
