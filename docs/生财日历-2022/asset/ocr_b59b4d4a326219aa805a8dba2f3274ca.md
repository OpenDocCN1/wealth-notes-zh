# 创业应该深耕一个行业，
还是多线发展？

阳光杉木
国际物流、华人外贸领域创业者

这个问题在不同阶段有不同的答案。

初期，一定是广泛寻找、尝试，找到适合自己的项目。当然，不要 “这个做几天，那个做几天”，然后都没法获得正反馈，最后就觉得没有哪个项目适合自己。

深耕期，就是要全身心投入单个行业，争取做到前三。即使做不到也应该极力研究，争取成为行业的专家，积累资源和人脉。

扩张期，可以围绕已有资源和用户横向拓展业务，放大收益。

回归期，减少原有项目时间投入，再继续寻找新项目，重新出发。
