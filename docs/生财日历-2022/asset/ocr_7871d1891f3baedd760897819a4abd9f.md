# 如何通过
打开公开象限建立信任?

达叔

企业销售总监、“达叔经济学”主理人

人与人之间的交往，有三个阶段——从陌生到熟悉，再到信任。不同阶段关系的衡量标准，就是信息密度。依次对应的是：公开信息、半公开信息、隐私。

信任前置，是一种快速帮你从陌生跨越到信任的方法，也是我很多生意机会的来源。

如何做呢？简单说，就是通过你的主动连接，去披露自己的信息，获取对方的信任，从而换取对方的信息，或者愿意让你参与他们的事情。
