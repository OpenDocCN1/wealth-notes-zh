# # 创业者拿投资的过程
# 要避免哪些坑？

李自然
电商和软件行业创业者，“李自然说”主理人

+   要注意以下三点：
1. 了解投资人的背景。不仅仅是投资人对创业者要做背景调查，创业者也需要调查投资人的背景。
2. 一切以协议为准。投资人的口头承诺，你认为比较重要的，都要争取落在协议上。
3. 钱不到账，融资就还没成功。切记，即便是签好了投资协议，钱不到账就可能有变数。

有些创业者签了投资协议，甚至签了投资意向书就去庆祝，我觉得有点太早了。等钱都到了账上，才算真正融资成功。钱到账之前，要尽快把钱催要过来。
