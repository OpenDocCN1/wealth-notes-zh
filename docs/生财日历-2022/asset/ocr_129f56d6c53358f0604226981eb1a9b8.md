# 为什么要坚持
利他主义?

小蚁

新西兰旅游房车领域创业者

不经意的利他小事件，出乎意料地给我带来了很大的回报。这让我开始明白：利他也是一种战略，能让你的路越走越宽，越走越顺。

比如，我之前做旅行房车的生意能成功，得益于两次主动让利：

我有位能装修房车内部的师傅，而这位师傅，是我助理的爸爸。由于我平时处处替助理着想，让利于助理，他主动介绍了退休的爸爸来给我设计和打造旅行房车。第二次让利是我给助理的爸爸在原价的基础上主动让利，他又给我介绍了其他木工师傅长期与我合作。这两件让利的小事，让我的房车生意越走越顺。
