# 有哪些创业初期
需要重视的创业方法论？

钱钰
“化龙巷” 创始人，区域互联网研究者

创业方法论，就是你的创业价值观。我提炼了下面四条：

+   1. 建立多方受益模型。无论是做社群、商业模式，还是经
营公司，都要尽可能地建立一个多方受益的模型，让每个参与
者都能受益。
2. 坚持 “先利他，后利己”。用 “先利他，后利己” 的氛围
感召、激励每个成员不断为他人贡献，最终实现对自己的超额
回报。
3. 做到超预期交付。只有超出预期的口碑，才是裂变和续
费的基础。
4. 永远真诚、真实。保持真诚、真实，让更牛的人愿意相
信你，和你一起共事。
