# 如何取一个
自带流量的公众号名称？

杨先生

自媒体人，亚马逊平台培训机构流量运营主管

一个好的微信公众号名称，它应该符合一个标准，就是能被大多数人搜索到，带来自然流量。

怎么做到呢？有两点经验想要分享给大家：首先，通过百度指数、微信指数查询数据高的关键词。比如：搜索垂直行业资料相关的关键词有“免费资料”“某某资料”“资料库”。其次，是把关键词组合起来，如“免费某某资料库”。

这样，搜索上面的关键词时都可以带来自然流量，就是一个好的微信公众号名称。
