# 如何让自己的人生
持续拥有“复利”？

杨涛
流量专家，持续创业者

个人或公司的成长路上，每一个选择都不是孤立的。当下的行为或决策，必须能对下一个行为或决策有帮助。这样，就会像“复利”一样，形成正向的增加，逐步拉开和他人的距离，而差距就是财富的来源之一。

所以，有人生“复利”的决策就是正确的决策，这样的“复利”有四种：

+   1. 技能的“复利”，即一旦学会终身可用的技能。

+   2. 钱的“复利”，就是你对资源的购买能力，能跑赢通胀。

+   3. 人的“复利”，这里的人，就是能够再次触达，并为你创造财富的人。

+   4. 影响力“复利”，就是调动人、财、物的能力始终在增长。
