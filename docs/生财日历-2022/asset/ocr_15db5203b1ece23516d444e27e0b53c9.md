# # 如何做好
## 线上训练营项目？

**西门吹花**
前电视媒体人，健康类训练营创业者

我的线上训练营，售价 999元，半年卖出2万多份，还衍生出了其他业务。回顾这段历程，我有六点建议：

+   1. 帮助用户达成目的比输出知识更有价值。
2. 陪伴成长是一项美好的商业模式。
3. 社群产品一定要有一个值得让用户推荐的理由。
4. 商业模式不如从1000个深度陪伴用户开始。
5. 专注一个领域会很有生命力。
6. 要站在用户这边，替用户思考，用户会推着你往前走。
