# 如何提升付费学员的
学习体验？

北野

游戏化设计师，游戏化训练营专家

让学员在过程中感觉到有趣、好玩、有料、有用，就更能激发他们的内驱力，提升体验。具体可以从以下四点出发：

+   1. 遵循用户视角，根据学员的不同特点设置不同方案，打造个性化学习体验。

+   2. 借助体验曲线，管理每一天、每一周的运营动作，及时营造峰终体验。

+   3. 搭建系统化运营团队，有人专注于教学体系优化，有人关注持续性激励，有人记录学员的荣耀时刻，有人落地各种超预期的活动。

+   4. 让数据说话，借助榜单、徽章、进度条等各种可视化工具，嘉奖表现好的学员，激活表现有待进步的自由学员。
