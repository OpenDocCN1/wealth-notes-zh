# 在赚钱路上，有哪些敏锐度是需要刻意培养的？

Kosan
职业教育领域创业者，流量转化专家

总体来说有三个方向上的敏锐度：

+   1. 热点敏锐度。热点来了立刻行动，不要犹豫。
2. 平台敏锐度。平台规则一直在变，要不停摸索规则变化后的玩法，抓住第一波红利。
3. 项目敏锐度。每个行业都有自己的重要节点。比如我是做教育的，每年国家各类考试都会公布今年的考试时间，公布后这些时间很容易上各平台的热门。平台不会第一时间关注到这个时间变化，但行业内的我们肯定会知道，可以提前准备起来。比如我每年都会提前1个月准备好相关问题和回答，等公告一公布，就马上去知乎提问并第一个回答，迎接并吸引我的潜在用户。
