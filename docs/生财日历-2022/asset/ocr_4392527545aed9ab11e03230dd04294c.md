# 实体生意如何管理与顾客的关系？

Moni

实体餐饮创业者、美业连锁公司创始人

实体生意要维护好和顾客的关系，本质上是要让顾客跟你的信任感不断加深，归纳为以下五点：

+   1. 除自身形象干净整洁外，还必须具备“温柔”：讲话要柔，微笑要柔，讲解也要温柔耐心。

+   2. 常给顾客的朋友圈点赞。

+   3. 买顾客的商品，产生交易深度连接。

+   4. 尊重顾客的每一次意见，哪怕是错的。

+   5. 记住顾客每一个重要的日子，如生日、亲属生日、生理期等。
