# 怎么和用户搞好关系？

俊一
区块链创业公司商务总监

在我看来，和任何用户搞好关系都只需要以下三步：
第一，证明自己是一个能为对方提供高价值的人。
第二，思考自己如何与他们合作，或如何帮助他们，甚至不谈合作。
第三，和我们的客户真正互动起来，不断地给他带去新问题、新话题，主动地去找一些有意思的事情，让我们的客户共同参与，一起做一些事情。
