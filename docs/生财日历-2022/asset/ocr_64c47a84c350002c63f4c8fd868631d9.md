# 初创公司
如何设置股权？

钱钰
“化龙巷”创始人，区域互联网研究者

初创公司的股权设置要注意以下四点：

+   1. 股权不宜太分散，2至3人较好，并且一定要有一个核心股东。

+   2. 所有的投入要“货币化”折算，不能货币化的和不确定的投入不能折算成股权，比如未来可以投入多少精力和时间，这种不建议算成股权，更建议在兑现时给他多开一份工资。

+   3. 后进入的高管要有一定磨合期，设定合理的考核机制和时间点，逐步落实股权。

+   4. 给早期员工的股权不如多发钱实在，因为早期的股权激励效果不大，员工还可能会有老板发不起工资用股权糊弄人的想法。
