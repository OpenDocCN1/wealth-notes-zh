# 如何快速给自己的品牌
起一个好名字？

小马宋

小马宋营销咨询创始人，战略营销专家，“得到”App 营销顾问

取名字的核心，是要有“陌生的熟悉感”。

对于名字来说，熟悉和容易记忆是最重要的。我们可以用“通俗的词语 + 差异的品类”这个方法来取名，比如手机品牌里的小米、苹果、锤子，都是极其熟悉的名词。

但这里有个原则，你想取名字的这个品类，要跟你的名字属性不相关。

比如可以叫小米手机，但如果你的品牌是做面包的，你千万不要叫小米面包。为什么呢？因为小米牌面包就不会有陌生的熟悉感，很可能会误解为这种面包是以小米为原材料的。
