# # 如何复制一个
# 成功的直播间?

尹晨

尹晨俱乐部创办人，直播带货创业者

想要复制一个成功的直播间，需要注意以下三点：

+   1. 不是所有的直播间都可以复制，从经验上看，流量模式的直播间是可以较快复制的，IP 人设类的就比较难。
2. 对主播来说，他已经对上一个直播间付出了很大的精力，复制时，很难有第一次做直播间时的激情感、兴奋感、期待感，所以我们需要在薪酬上给他创造这些感觉。
3. 复制直播间时要注意平台规则的变化，比如去年做低价引流是可行的，今年随着规则变化就不太行，那这类玩法就不应该再复制过来。
