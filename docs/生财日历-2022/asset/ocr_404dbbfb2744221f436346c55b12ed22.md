# 创业公司怎么在面试中招到合适的人？

许范范

世界500强区域人力资源部门副总

在探讨这个问题之前，你需要明白，成年人是很难被培养的，创业团队也很难有精力去培养。面试是为了帮你筛选出合适的人，而不是找到一个能培养的人。

所以，在面试时，考察一个人的能力如何，不要听他说了什么，而是要听他做了什么。有些人可能对事情的看法夸夸其谈，但是说得多做做得少。

具体在面试过程中，你可以问以下这些问题：

+   1. 这三年内，你做的最有成就感的事情是什么？

+   2. 你所经历过的最有挑战的团队合作的事情是什么？

+   3. 你所经历过的最遗憾的事情是什么？
