# 实体店创业要有哪些心态上的准备？

云多

认证营养师、减脂训练营创业者

在我看来，实体店创业需要有以下心态上的准备：

+   1. 不要刚起步就立刻想起回报你投入的那一点点设备钱。
2. 线上做销售，依托三感吸引客户：好感、信任感、新鲜感。
3. 千万不要因为刚刚开始就把自己的价格定得很低，对自己的产品不自信就多扣题。
4. 做好销售记录。为了来年你能清楚地跟客户沟通。
5. 用对待朋友一样的热情，去对待你所有的顾客。
6. 如果感觉自己精力不足了，尽早安排自己的后路，别勉强自己。
