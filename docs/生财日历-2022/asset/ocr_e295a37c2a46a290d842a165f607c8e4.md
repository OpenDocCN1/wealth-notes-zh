# 第一次做独立项目
要注意哪些问题？

米笠

流量领域从业者，外卖 CPS 创业者

第一次做独立项目要注意以下八点:

1. 项目写起来很容易, 执行起来还会有困难, 着手于开始, 就是成功的第一步; 2. 认真选择一个适合自己的渠道, 不要贪大、贪多; 3. 多分享, 多交流, 多学实操经验, 会对项目很有帮助; 4. 所有的引流渠道的引流路径都是一样的——利他→留存→转化; 5. 先做起来, 再想着如何更进一步提高转化, 否则, 白想一场; 6. 要结合你自身对成本的考量和具体需求, 判断投入的高低; 7. 先模仿, 再优化; 8. 执行永远是第一位的。
