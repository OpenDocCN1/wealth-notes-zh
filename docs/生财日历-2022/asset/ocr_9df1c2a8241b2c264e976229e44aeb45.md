# 如何避免流量运营中
多层分销的法律风险？

唐梦
律师，门萨俱乐部成员，前金融交易员

+   第一，是否收取“入门费”是多级分销是否构成刑法意义上的“传销”的重要判定标准。
第二，尽量以折扣、实物或服务奖励、抽奖活动等方式而非返利形式给予优惠。
第三，注意活动海报图文内容，避免被微信等平台认定为诱导分享。
第四，在“无讼”和“裁判文书网”搜索相关案例，刑事案件的追责看的是行为实质而非名义形式，所以并不是把包装改得和既有判例不一样，就可以自认为高枕无忧。
第五，做重大的决策时，比起自助式的法律检索，更建议提前咨询法律专业人士，获取更有针对性的帮助。
