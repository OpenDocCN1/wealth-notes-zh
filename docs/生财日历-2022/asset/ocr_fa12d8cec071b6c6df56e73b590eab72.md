# 如何在一个细分领域里
做到“出圈”？

黄浩在观察

数码影像工作室创始人

在打造个人IP的经历中，我总结了四个重要的关键词，就是“敢做”“敢当”“入圈”“出圈”：

+   1. 敢做。敢于多多“曝光”自己的行动、作品，给关键人物看到，最大化提升自己的影响力。

+   2. 敢当。敢于接受额外的任务和事务，在看得到成长性的前提下，尽可能多地拿下原本不属于自己的事情，并且尽全力做出好结果。

+   3. 入圈。进入新的不同的圈子，增加自己的信息摄入，扩展自己的认知。

+   4. 出圈。跟入圈不一样的是，出圈是突破现有的圈子，让圈里人看到自己的成长，从而获得大家的支持。
