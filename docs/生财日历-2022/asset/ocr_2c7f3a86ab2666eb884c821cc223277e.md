# 如何判断自己的项目
是否靠谱？

刘小排
“猎豹移动”前产品总监

当你判断一个项目是不是靠谱时，应该先学会判断一个产品好不好。

别问客户：“你觉得产品好不好？”而是要问：“您愿不愿意买这个产品？”决策人要拥有和结果绑定的勇气，这个决策才是真实、可信的。

同理，如何判断自己的项目好不好呢？更好的问题是：“如果你要你马上辞职，和我一起创业做这个项目，你愿意吗？”

一个项目再好，如果不在你的能力范围内，无法唤起你的热情，对你而言，都不是一个好的项目。只有当一个项目既是你热爱的，又在你能力范围内，它才是一个靠谱的好项目。
