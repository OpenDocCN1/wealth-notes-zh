# # 游戏领域中
普通人有哪些机会？

焦波

游戏行业15年从业经验者 · 游戏创业者

以普通人来说，切入游戏领域的机会，可以按三种门槛划分：

低门槛：打游戏赚游戏币，游戏陪玩，游戏代练，账号相关服务。

中门槛：需要对游戏有较深的理解，通过游戏账号交易、做游戏交易商或游戏初始号赚钱；也可以给游戏引流，例如直播带货，或者通过抖音小游戏、快手小游戏等引流。

高门槛：游戏脚本开发，做热门游戏的合法辅助脚本，以月卡形式出售；或者自己开发游戏，以成本较低的方式切入文字类游戏，例如《传奇》《梦幻西游》这样的热门游戏；开发区块链游戏，结合 NFT（非同质代币）的玩法，有获利空间。
