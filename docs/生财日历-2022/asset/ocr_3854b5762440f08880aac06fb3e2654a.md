# ## 普通人做副业，
## 如何构建壁垒？

子瑜
广告优化师，连续创业者

在说如何构建壁垒之前，你需要知道为什么我们必须构建壁垒。

普通人做副业，要在一片红海中杀出血路，只有当你构建起壁垒后，才能用时间打败成本，用努力搏击资本。

那么，如何构建壁垒？有这样三个方向：一是分析对标竞品，挖掘真正的差异化；二是找准着力点，在一个点上做到极致，维护好你的用户；三是扩展你的赚钱模式，做好二次变现。
