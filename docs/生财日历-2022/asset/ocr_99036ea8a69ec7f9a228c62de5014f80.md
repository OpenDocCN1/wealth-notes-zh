# 想通过内推扩大企业规模，
有哪些注意事项？

张钰
人力资源专家，“万人 HR”社群创始人

并不是所有岗位都适合内推，销售和程序员的内推很有效，但中层或者重要岗位，内推需要慎重。

尤其是大部分公司在内推时，只放一张海报，一个 JD（工作说明），推荐人并不了解你的需求，只知道公司在招聘，只是简单地发发社交平台，有人想来就给推荐了。

这其实并不能体现内推的好处。内推需要公司对岗位有一个非常详细的需求，让推荐人能够知道什么样的人 是合适的。这样在面试的时候，只要看人品、三观是否合适团队就可以了。
