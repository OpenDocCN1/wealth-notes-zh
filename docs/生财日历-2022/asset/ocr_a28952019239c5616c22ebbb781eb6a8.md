# 赚钱有哪几个维度？

光合

战略咨询顾问，“生财有术”合伙人，“华与华”前项目总监

赚钱这件事随着时代在不断地变化，在我看来赚钱有四个维度：

+   1. 靠利润赚钱。二十年前的中国，在人口红利和投资红利下，“躺着”都可以赚到钱。

+   2. 靠成本赚钱。通过规模化、精细化运营来降低成本，提高效率。

+   3. 靠结构赚钱。针对用户规划产品结构，提供不同的产品和服务，靠结构或者矩阵来赚钱。

+   4. 靠品牌赚钱。建立自己的品牌，增强自己对顾客的溢价能力。

最后再补充一点：规避风险，一定要规避政策风险。
