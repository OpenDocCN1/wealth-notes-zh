# 产品是如何体现
一家公司的价值观的？

Fennng
资深互联网人，“无码科技”创始人，“小众消息”主理人

产品本身就会传递出价值观，好的产品最终是好的价值观驱动出来的，而有些产品之所以变坏，多少跟团队价值观的迷失有关。

比如，下载某个软件时跳出的一键下载“全家桶”，我们就可以想到，这是团队为了达成占有率、下载量而想出的歪点子。从目标上来说，是成功的，但有点为了达成目的不择手段的味道，因为留给用户的是无穷无尽的烦恼，自己把自己口碑玩坏了。
