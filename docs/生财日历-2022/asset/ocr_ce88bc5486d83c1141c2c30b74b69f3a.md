# 做自由职业者
要做好哪些心理准备？

纯洁的微笑

“微笑科技”创始人，自由职业者

有三个准备是必需的，也是非常重要的：

+   1. 自由职业收入不稳定，建议准备可供两年消费的存款，以应对未来的各种不确定性。

+   2. 先积累一些小的成功案例，再从事自由职业来放大收益，尽量不要一时冲动从零开始。

+   3. 自由职业并不意味着拥有无限制的自由，想要真正享受自由职业，需要有较强的自律性，自我驱动、自我管理、自我约束。

还有一个很容易被忽略的重点：即使是做自由职业，也一定要持续交社保。
