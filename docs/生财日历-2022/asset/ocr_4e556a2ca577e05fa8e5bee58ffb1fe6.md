# 市场广告该如何
帮助销售做精细化运营？

毛勇
企微领域创业者，360渠道前华东负责人

不仅要通过广告带来客户，还要记录客户是如何来的，通过捕捉和洞察客户的关键意图来帮助销售成交。

从线索到订单，一套记录销售线索的全流程动向包含两个方面：

首先，记录客户在公域里的行为，这样在客户来私域之前，就能知道他有没有加销售为好友，看过公司哪些内容，初步判断出客户的意图是什么。

其次，持续记录。客户进入私域后并不意味着就不在公域活动了，要持续跟进公域行为并反馈给销售。
