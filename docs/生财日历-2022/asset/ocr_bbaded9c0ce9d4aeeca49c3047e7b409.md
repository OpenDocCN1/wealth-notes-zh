# # 如何理解长期主义？

张辉
《人生护城河》作者，“辉哥奇谭”主理人

长期主义是每件事都不凑合。对长期主义者来说，要么不做，要做就做好，没有“凑合做做”的中间状态。
在践行过程中，我总结了六点经验：

+   1. 不盯着眼前的利益，而是着眼于未来的价值。
2. 不预测变化的东西，而是聚焦于不变的东西。
3. 可以忍受短期内看不到回报，但是期待更长期的回报。
4. 内心想到的回报曲线不是线性曲线，而是一个指数曲线: 前期波澜不惊，后期增长迅猛。
5. 对待人方面极有耐心，不求短期利益交换，而是更长期的认可，能释放更长久的价值。
6. 对长期有信心，对短期有耐心。
