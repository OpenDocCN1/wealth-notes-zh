# 普通人做公众号
还有机会吗

别 sir
空乘领域自媒体创业者

与其去分析做公众号有没有机会，不如分析一下自己适合哪个平台。我承认，公众号的鼎盛期已经过去了，但新媒体的机会还有，各个平台都是机会。对于普通人来说，我们不应该局限于做公众号能不能赚到钱，更应该考虑新媒体给你带来的新机会和新平台。只有把你自已展示出去，才可能遇到更好的合作机会。

比如我，身处三线小城市，如果不是通过做公众号这项副业，看到了更大的世界，也许就过着赚点小钱、知足常乐的日子。这份副业带给我的精神收益远超物质，也给了我“不信命”的信心。
