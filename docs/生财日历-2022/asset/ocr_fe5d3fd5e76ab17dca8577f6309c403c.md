# 为什么要
重视私域流量？

尹基跃

“私域研究院”创始人、《可复制的私域流量》作者

因为私域是流量的终点和沉淀之处，不做私域是对流量的极大浪费。

流量是一切实质的本质，而流量不断在发生迁移。从早年开个门店就能自动获客，到电商让用户习惯通过搜索来消费，再到现在用户的注意力每天都在朋友圈、抖音、快手……用户在哪儿，流量就在哪儿；流量在哪儿，流水就在哪儿。

以至现在的一个群公告，效果堪比五年前小区里的宣传单。

私域提升了用户的触达率、消息打开率，降低了购买决策的难度，拉高了用户全生命周期价值，所以要非常重视。
