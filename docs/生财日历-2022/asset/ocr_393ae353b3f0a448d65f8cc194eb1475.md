# 个人如何获得和增加自己的影响力？

池建强
“极客邦科技”总裁，“极客时间”创始人

不是所有人都能在公众面前建立影响力，但每个人都一定可以在自己的生活和工作中具备影响力。

分享三个在工作中建立影响力的做事原则：

+   1. 选择困难的、紧急的和重要的工作去做。只要这些工作能够推动业务发展，不管这些工作无聊不无聊，都努力去完成。

+   2. 拥有解决问题的能力。解决别人无法解决的问题。

+   3. 成为专家。如果你是某个领域的技术专家，那么你在 个领域里将会产生巨大的影响。
