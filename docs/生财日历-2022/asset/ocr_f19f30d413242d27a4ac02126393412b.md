# 如何 做好 技术 自媒体？

sitin 涛哥
安全公司技术负责人，“涛哥聊Python”主理人

简单总结一下我的经验，做好技术自媒体有以下四点：

+   1. 重内容。内容才能带来持续的流量和影响力，好的内容在哪里都是稀缺的。

+   2. 懂技巧。比如流量获取、内容分发、音视频方式做二次演绎等。

+   3. 会工具。了解市面上能提高效率的主流成熟工具，降本增效。

+   4. 守规则。想要走得远，一定要注意平台规则、版权、法律等。

其实，底层逻辑非常简明：在平台规则下，创造优质的内容，通过一些工具辅助，吸引各大平台读者，持续输出价值。
