# 私域和电商结合，
会有哪些机会？

徐志斌
“见实”创始人，私域流量专家

所有和私域紧密关联的词汇，都和效果相关：转化、复购、转介绍、客户终生价值、数据资产……

因此，机会在于：

+   1. 用私域做电商，本身就是机会。
2. 构建自己的私域流量池，不论是自建、做服务商，还是搭建私域分销网络，都是机会。
3. 提供工具和系统、数据服务、代运营服务等，也各是机会。

2022年，“私域电商”尚在早期，行业的长期市场值得看好，越细的服务，将越有机会。
