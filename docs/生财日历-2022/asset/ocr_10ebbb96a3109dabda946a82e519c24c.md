# 如何快速跑通项目全流程，打造高效复用的SOP？

木锋

200万粉丝公众号运营者

打造 SOP（标准操作程序）最核心的任务是：借助已经成功的 SOP，取长补短，多元素搭配，再融合创造出自己适用的流程。看→拆→想，三步就能快速建立自己的 SOP。

看：研究别人的 SOP。在自己经验不足又缺乏把握的情况下，模仿他人已经成功的方法论，是走向成功的最快捷径。先借鉴，后超越。

拆：不需要全部拿来，选其精华，找准对你最有用的模块，拆解它的每一个操作细节。

想：所借鉴的 SOP 一定是符合自己的业务需求的，可以通过单价、人群、周期、流程这四点进行判断。
