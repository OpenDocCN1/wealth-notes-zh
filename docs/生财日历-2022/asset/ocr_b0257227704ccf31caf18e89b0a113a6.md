# 认真做事且做成了的人，
都有什么样的特性？

吴都

“挖土机少儿编程” CEO

一个人取得一些成绩，一定是做出了一系列正确的决策。

这类人做决策时，往往能在纷杂的业务线中找到多个适合的突破口，然后在远胜于普通人的经验基础上，旁求博考，选择最有效率的一条开始行动。

然后，他们还会快速执行、落地、推进。在这个过程中，他们会付出相比于普通人多10倍的努力。碰到没有成功经验借鉴、超出自己认知范围的时候，他们会翻阅大量的书籍。

任务推进过程中出现决策失误，需要迅速调整执行方式，甚至需要重新来做；当遭受外部质疑以及自我否定时，能够进行适当的自我心理建设。
