# 公司该怎么处理
销售人员的贪腐问题？

NEO
“龙进信息”创始人，ToG领域创业者

坦诚地说，贪腐现象没有办法杜绝。每个人都有“天使”的一面，也有“魔鬼”的一面。我们唯一能做的事情就是不断地放大“天使”的那一面，抑制“魔鬼”的那一面。

这有点像“心灵鸡汤”，但在我的实际销售经验中，确实如此——要量化出一套标准非常难。

公司要做的是：

+   1. 计算好成本，加上保底利润，剩余的部分就是弹性空间。
2. 对于“吃相”特别难看的销售人员，要主动淘汰，并告诉他，这种行为是走不长的，迟早会被“反噬”。同时，把这种精神传递给所有的销售人员。
