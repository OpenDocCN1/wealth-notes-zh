# 如何看待亚马逊这个平台？

夏冰雹

Shopee 平台从业者，跨境电商公司 COO

在我看来，亚马逊已不适合轻小型玩家进入。主要原因有以下三点：

+   1. 平台的红利与势能转移，呈现出“红利见顶与衰退”。

+   2. 平台已经步入成熟期，亚马逊已经成为一个重资产游戏平 台。

+   3. 平台销售端涨价，物流端策略变更，产品转型升级，2021年已成为跨境电商的分水岭。

综上建议：亚马逊平台的竞争日益增加，轻小型（无供应链 资源、总资金少于50万元、无3年以上经验积累）的玩家在选择 主营亚马逊平台前，建议需要慎重考虑。
