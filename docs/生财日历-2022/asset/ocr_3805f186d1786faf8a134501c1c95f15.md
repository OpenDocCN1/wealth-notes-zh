# 对于赚钱该如何思考？

**成甲**
查理·芒格思维研究者，《好好学习》《好好思考》作者

真节能赚钱。不在于了解的多少，而在于了解的都是正确的，错误一定不会亏钱。我们要在正确的方向上，用正确的方法，做正确的事情。这是最可靠的赚钱方法。
具体而言：1. 我们不能仅仅从“得失判断”来考虑问题，还要在道义上值得信赖；2. 真正能够赚钱的原因是得某些事，而不是泛泛地知道很多；3. 赚钱的本质是价值交换，物以为贵，只要你的能够优秀，你就会赚钱。
总结一下，赚钱的方法就是：通过精通某一领域从而形成优势，不断为他人创造价值，这是最可靠的走正道的赚钱方法。
