# 做好相亲服务的核心是什么？

茶矛
10余年区域互联网领域从业者

做好相亲服务的核心就是：帮用户找出找不到对象的原因——是社交原因，还是人格性格原因，或是其他的心理原因。

这么做的理由也很简单：信息配对只是一个售卖方式，没办法做出差异化，但咨询服务可以做高客单价，提升你的利润空间。

比如，大部分看起来高质量但找不到对象的用户，往往很聪明，但同时也意味着爱挑剔，自尊心强，自我感觉很好，如何让他们发现自己的问题，就是我们服务的溢价空间。
