# 公司 CEO 有哪些品质
更容易获得投资？

子柳
投资人，淘宝技术大学前校长

合适的领域、优秀的团队、顶级的 CEO，三者齐备才是一个值得投资的项目。
其中，判断 CEO 是否优秀，可以从三个方面入手：

+   1. 能力非常全面。无论是兵法上讲的“智信仁勇严”，还是 EMBA 课程里面要求的“影响力、创造力、执行力、学习力”等，当你见到符合这些条件的人时，会由衷地想到一个词——人中龙凤。

+   2. 对专业和人性有一种直达本质的认知，甚至达到某一领域认知的边界——他的家庭关系、财富观、人生观能让投资人放心地把钱交给他。

+   3. 一定非常热爱自己的事业——创业很难，唯有热爱才能坚持到底。
