# 老板如何招到
专业能力超过自己的人？

坤

“二三三数字科技” CEO

在我看来，这样的人是招不来的。我的方法是：进入一个新领域，先了解这个行业的基本逻辑和方法论，通过自己的人脉去搭桥，以请教的方式去认识这个领域的高手。

等我请教完，我会大概介绍一下我的情况，然后问：有什么事我能够帮助到你？这个时候你就会发现，高手也是需要合作伙伴的。一件事情，原来他自己干，他可能做到0.1，结合了我的资源，可能做到1，他和我合作能分到0.6。对他来说，整个的收 益就提高了5倍。这时候，比我厉害的人，自然就愿意和我合作了。
