# 普通人创业，
如何做好团队管理？

夜息

SEO 专家，“百康科技” CEO

创业路上，好的团队大于好的业务模式。就拿我来说，以前自己单干的时候，觉得自己无所不能，但创业后才发现，一个人的精力总是有限的，靠自己单打独斗，能做的事非常有限。可以说，创业的第一课，就是教会了我，不要什么都自己来。

在创业团队管理中，有三点很重要：

+   1. 任何工作的安排，一定要落实到位，而不是停留在“希望”做什么的层面，因为员工不会干你想干的，只会干你检查的。
2. 树立“什么都能做”的团队思想。
3. 价值观的制定要能决定企业做事的方式，而不是一些套话，比如诚信、勤奋等。
