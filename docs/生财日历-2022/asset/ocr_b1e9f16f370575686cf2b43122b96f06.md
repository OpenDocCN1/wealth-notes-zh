# # 如何建立用价值观
# 驱动的社区？

赵新龙
“TGO 鲲鹏会”业务负责人

在我看来，建立用价值观驱动的社区有三个步骤：
第一步，找到团队早期核心成员都认可的核心品质，以此制定价值观。制定好的价值观要不断地重复，直到内化于心、外化于行。

第二步，对社区成员进行面试，过滤不合适的人，并进行新人培训，宣传贯彻理念和规则。让合适的人加入，远比不做筛选、长期同化更有意义。

第三步，把价值观的内化、外化落实到仪式感中，比如在季度会议上公开提问，广泛传播用户案例，用文字和故事的方式反复诠释等。
