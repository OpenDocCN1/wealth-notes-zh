## 哪种销售方式能深入人心？

贺嘉
《成交力》作者

不同的销售方式，注定给销售人员带来不同的结果。

三流的销售，讨好客户，处于弱势方。

二流的销售，和客户做朋友，处于平等等方。

一流的销售，改变客户认知，处于强势方。

改变客户认知，就是解决用户“为什么要买”的问题。这背后就是发现客户的痛点，洞悉客户的潜在需求。

比如一名收纳师，在销售时并不会讲“我帮你做收纳”，而会说：“房价这么高，很多人都买的小户型，如果有人帮你设计收纳方案，就能让家里的面积在现有的基础上多一大块，简直省下了几十万。”

3. 圈层升维。就是把信息打包，比如小红书里常见的各类清单、测评，都是这种模式。

2. 高客单价的溢价，来源于 IP 本人和客户对 IP 的信任感，是基于信任的交付，在这个阶段，产品和宣传再做多少提升，对转化的影响没有那么大。
3. 高客单价的生意依赖销售推进，千元以下“运营 + 直播”基本够了，到万元以上单价的生意，更需要一对一追进，不断提供产品价值。
4. 有实力的话，从线下拉升用户的渴望，提升体验。

当你真的对产品和服务足够用心，对自己领域内的势能足够自信，高客单价是很值得一试的。

## 如何避免掉入“穷忙”的陷阱？

贾万兴
“小小包麻麻” CEO，内容电商创业者

在回答这个问题前，首先要知道“穷忙”的本质是什么。

忙，很可能是大部分人追求的一种状态，也很容易因此得到周边人的认可。而“穷忙”，是为了忙而忙，忘记自己忙的目标，在忙碌的状态里陷入自我满足，意识不到自己处在停滞不前的状态。

想要避免“穷忙”，只有先认识到这个恶性陷阱，有意识地抗衡，总结出让自己更高效的方法，构建一条走出舒适圈的路径，引导自己跳出舒适圈。
