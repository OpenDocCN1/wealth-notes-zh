# 创业初期设立团队价值观时，有哪些值得参考的方向？

七对
9年产品经理，“心竺教育”创始人

好的价值观能增强团队的向心力，帮助创业者更好地管理团队。因此，创业初期，带领团队树立好的团队价值非常重要。以我自己做教育类公司的经验为例：

+   1. 遵守规则，才能活得久。

+   2. 树立客户第一的用户价值理念。

+   3. 生存才是第一位，找到突破点了，就必须要全力投入。

+   4. 团队要一条心。

认同公司的价值观与文化。“善弈者，通盘无妙手”，价值观的背后是对未来看得透、在当下活得久。
