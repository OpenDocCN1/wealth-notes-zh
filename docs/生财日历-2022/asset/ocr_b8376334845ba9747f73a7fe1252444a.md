# 如何在新的城市
搭建稳定团队？

张钰
人力资源专家，“万人 HR”社群创始人

搭建团队，很多时候没有捷径可以走，只能一个一个慢慢去招。想要快速搭建团队，可能留人比招人更重要，需要在人员流动性比较大的情况下，持续保证人员的稳定性。

想要保证稳定性，分公司的负责人是关键，通过出让更多的股份，让负责人能够把运营公司当作是自己的事情来做，他们会想尽一切办法，在当地招到更多的人。同时，老板带着员工冲到一线去奋斗，员工的稳定性会比较高。
