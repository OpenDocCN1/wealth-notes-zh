# 如何找到小众的商机？

宋大航
11年互联网人

小众需求变成有收入的服务，通常有一定的“天花板”，但并不困难。

原因很简单，我们自己遇到的问题，很多人一样会遇到，但是大部分人解决问题就结束了。如果我们把解决问题的方法归纳、总结，然后输出，就能成为有价值的内容或服务。

这些方法的总结，很多人都需要。既然有需求，就能赚钱。一方面可以做成教程、服务，直接变现；另一方面可以写成文章或者做成视频引流。

比起赚到钱，更多地验证自己的想法是否行得通，也是一种修炼。
