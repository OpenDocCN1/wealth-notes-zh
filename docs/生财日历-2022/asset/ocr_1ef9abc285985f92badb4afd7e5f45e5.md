# 如何提升自己的投资认知？

胭脂王

二级市场投资者，金融领域独立咨询顾问

+   提升投资认知，我一般通过五个维度：
1. 找到这样的人：和我们的人生轨迹相近，已经实现一定程度的财务自由，也经历过在业余时间做投资，最终投资在其资产配置中所占的比重越来越大。找到这样的人后，我会看完对方的所有文章和案例，有机会就深入交流。
2. 读那些已经出版了10年以上而依旧被无数次重印的书，或者高人们推荐的书。
3. 把资金放到市场上去实践，“Just Do It”（去做）。
4. 在决策做完以后，尽快记录并复盘，然后时不时地回顾，寻找可以改进之处。
5. 通过多分享，“拷打”自己的认知。
