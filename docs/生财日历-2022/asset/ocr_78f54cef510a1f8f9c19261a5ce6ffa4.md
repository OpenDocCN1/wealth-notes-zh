# ## 如何把盲盒玩法
结合到自己的项目里？

甄希
营销广告人，连续创业者

这个问题背后，是找到业务与盲盒的关联。

上游：IP。包括 IP 孵化、创作、授权，盲盒开发、生产等，面向艺术家、设计师、版权方、原创者、开发者、资源方等。

中游：渠道。包括电商、智能终端、实体店等，面向智能终端玩家，线下实体从业者，拥有资源的渠道方、流量方、运营方等。

下游：衍生品和交易平台。有衍生品开发、潮玩社区平台、二手交易、炒卖等业务，并面向衍生产品开发方、社群运营方等。

若找不到，避免强行套用盲盒玩法。
