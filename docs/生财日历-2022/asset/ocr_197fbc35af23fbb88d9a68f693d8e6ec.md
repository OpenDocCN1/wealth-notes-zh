# 如何与用户
建立长久的信任？

螃蟹唐
“伯虎螃蟹”创始人，知乎知识类博主

用户信任的前提，一定是认真做好品控和服务。在那之后，与其让用户相信产品或品牌，不如让用户相信你，把自己“卖出去”。

比如说，我是卖螃蟹的，那么我就会输出各种与螃蟹相关领域的干货知识，从而体现专业价值，分享有趣的冷知识，增加人与人之间的“温度”，同时做好互动——聊得开心就送螃蟹、送全套餐具，方便买家拍照传播……

比起直接“卖货”，不如先“卖自己”，超越冷冰冰的产品，给用户一个有情感的个人形象。与用户交朋友，真正创造价值，这样的信任成本更低，也更长久。
