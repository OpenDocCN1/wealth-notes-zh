# 淘宝客行业
有哪些主流的生意模式？

老胡
12年资深淘客，“离线索”CEO，“淘客公园”创始人

淘宝客行业的生意模式多种多样，可以分为五类：

+   1. 做普通商家直接推荐产品，门槛最低，有好友就能做，
考验私域运营和选品文案能力。
2. 做返利机器人自动化查询推荐产品，适合有一定基础的
人，难在规模化和风控安全，考验低成本获客能力。
3. 做招商团长，帮助商家做产品推广，适合有多年沉淀的
团队，考验销售、渠道合作、商家服务能力。
4. 开发独立导购平台，不建议普通人入场，也没有任何
红利。
5. 做工具服务商，成为“向掘金者卖铲子”的人。
壁垒越高，门槛越高，收入量级越高。
