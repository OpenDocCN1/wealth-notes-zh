# 把产品“卖爆”？

周先生
线下教培机构招生顾问

一款产品想要去“卖爆”的“爆单”，谁都需要通过客户的认知。
它可以是价格上的认知，也可以是品质上的认知。
如何建立用户的认知，这一点尤为重要：

+   1. 最好选择在自己熟悉的领域内，深耕用户需求做扩展。
2. 精准深挖出客户真正的需求，而非伪需求。
3. 设计出超出客户认知、让客户尖叫的产品。
4. 营造势能，找到关键转化人物，并帮助转化人物降低成交难度。
5. 借助各方流量来获取用户，让一切流量为我所用。
