# 与高手连接

拱卒

电商创业者，知乎全案咨询顾问

这个时代再也不是单打独斗的时代了。信息的高度饱和，决定了创业者再也不是点对点地做生意，而是点与点的交合。这个交合需要怀着开放的心态去扩大圈子，去“破圈”。
方法就那么两种：

+   1.  你给高手提供价值。成年人的社交很简单，你有价值别人才看得起你，人性就是这样，只会追随强者。
2.  花钱买高手的时间。这其实也是一种利他思维的应用，没有价值，那就花钱去学习别人的思维，开拓自己的认知，争取让自己以后更有价值。闭门造车不是不行，但需要你承担大量的时间、机会成本。
