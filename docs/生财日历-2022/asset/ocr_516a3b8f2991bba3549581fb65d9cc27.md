# 开公司如何选址？

孙永华
10年跨境电商经验，私域美妆创业者

如果你的业务是刚开始发展的，就到人才多、业务火热的城市去。比如做直播，那一定是去杭州，因为上下游产业完善，配套设施也好，适合快速发展。

如果业务已经很成熟，对挖人的需求没那么强，可以反其道而行，选择业务没那么火热的周边小城市，避开行业内卷，人员的流动性也不会那么大。

最后还有一种特殊情况是，尊重业务骨干的意愿。如果他想回家乡创业，而且他的家乡也适合业务发展，可以在这些城市开分公司，借助业务骨干的社会人脉来开拓市场，帮助他们开展自己的事业。
