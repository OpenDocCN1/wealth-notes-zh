# 在投资过程中，
有哪些思维方式需要掌握？

杰森李

独立投资人

+   投资其实是个混沌系统，总结起来，一定要掌握这样四点：
1. 你的目标决定了你的投资方式和策略。
2. 向外抓住趋势。和趋势做朋友需要眼光和运气，避免趋势下的遗憾需要理性和常识。向内明白自身的天赋和弱点所在，用规则约束弱点。
3. 发挥主观能动性，调用一切可以调用的资源逼近真相，你就离获胜更近一步。
4. 要有足够的勇气把握转瞬即逝的机会，有足够的耐心等待漫长岁月的回馈，有足够的智慧区分两者的不同，有足够的定力坚守最初的选择。
