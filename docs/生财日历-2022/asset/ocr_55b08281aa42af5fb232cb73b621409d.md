# 职场人如何
快速实现收入增长？

青十五

算法工程师，策略产品经理

普通打工人获得收入的途径就是出售时间，但通过这种方式，想要提高收入，只能靠增加工作时间赚加班费，或提升能力多赚基本工资。所以，想要快速实现收入增长，就需要在原来的收入基础上加杠杆：

+   1. 时间杠杆。复制时间，就是用更长远的视角去理解时间的价值，而不是仅仅获取时间现在的价值。
2. 管理杠杆。用更低的价格去购买别人的时间。
3. 金融杠杆，这考验的是投资能力。

我们每个人都可以在不同的杠杆上分配精力，实现收入增长。
