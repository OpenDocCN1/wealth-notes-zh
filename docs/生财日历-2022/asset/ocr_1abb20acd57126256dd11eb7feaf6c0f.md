# 如何判断
自己用户的真实需求？

金金
女性成长平台 “Momself” 合伙人

做用户调研时，经常遇到一个困境：明明按照用户讲的需求做了调整，为什么数据依然不好？
这是因为，用户“无法描述自己的真实需求”，就像乔布斯说的：“他们根本不知道自己想要什么。”
想要真正去了解你的用户，有三点原则可供参考：
1. 不去专门提问，而是回收用户在各种场景中主动提出的问题。
2. 不去做调研，直接观察用户的每一步行为。
3. 思考用户为什么会这么说，为什么会这么做，洞察用户在语言和行为背后的感受，这样才能更接近真实需求。
