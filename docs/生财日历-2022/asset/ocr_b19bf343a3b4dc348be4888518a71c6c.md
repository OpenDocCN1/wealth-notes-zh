# 如何看待保险行业?

郑静

保险经纪人，自媒体人

大部分人对保险的印象，可能还停留在入职保险公司做一个全职销售。其实，我们还可以作为独立经纪人，把保险发展成副业。

这也是我很推荐的一种方式。因为保险销售是没有底薪的，全职会没有保证。至于保险类的自媒体，我个人是不太推荐的，一方面是对专业知识要求比较高，另一方面是它的变现周期比较长。但如果我们作为独立经纪人，能销售的险种很丰富，佣金也很高，而且在日常生活中，就会有很多销售的机会。作为一份副业，年入10万可能难度不大，对很多普通人来说还是非常友好的。
