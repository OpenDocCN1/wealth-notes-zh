# B 端渠道代理怎么做？

波波
“爱盈利” “抖查查” CEO，移动互联网创业者

做 B 端代理首先要看业务市场的成熟程度。在还没有头部企业、市场占有率不高的业务环境里，要想做好代理，前期围绕这六个字：肯让利，树标杆。具体如何做，有三点供参考：

+   1. 创始人或负责人出来做分享，打造行业知名度。
2. 找目标人群相同的异业去合作代理。
3. 给新代理必要的资源或培训。
