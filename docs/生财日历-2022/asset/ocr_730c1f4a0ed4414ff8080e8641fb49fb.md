# 打造专业型个人 IP
有哪些具体的方法？

花爷
商业分析师，自媒体领域创业者，“花爷梦呓换酒钱”主理人

想要打造个人 IP，有三种渠道助你实现梦想：

+   1. 抖音直播做高价咨询。把高价咨询当成业务，看看有没有人愿意买单，如果有，就可以通过投放获取持续的用户流量。
2. 在公众号做内容。选择垂直专业类的领域，先写5篇、每篇大概五五千字的干货长文。
3. 在各个短视频平台拍干货类视频。干货类视频的成本其实没那么高，一次可以拍很多条，比起直播所消耗的精力要少许多。

想打造个人 IP，可以选择一种你擅长的方式做起来。
