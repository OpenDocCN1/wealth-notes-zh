# 如何看待虚拟现实
这个新兴行业？

老黄牛
投资领域博主，市场观察者

虚拟现实相关技术，就是我们常说的VR（虚拟现实）、AR（增强现实），以及MR（混合现实）。这一领域其实在2016年就曾火爆一时，后来又快速消退了。

繁荣没有延续，主要是因为：一是技术不够成熟，导致产品价格高、体验差；二是内容产业的生态一直没起来，缺乏优质的娱乐内容。但2021年发生了三个重要事件，证明这一行业的机会再次到来：

+   1. 标志性事件：美军采购微软的AR设备。
2. ARK（方舟）基金的“圣经”揭示AR前景可观。
3. 各大巨头，比如苹果、Facebook，纷纷开始重视AR、VR业务。
