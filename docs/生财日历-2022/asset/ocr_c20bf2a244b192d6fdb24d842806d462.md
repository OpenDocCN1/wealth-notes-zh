# ## 什么样的人
适合做直播带货主播?

腾大
淘宝美食直播机构创业者

以下五类人适合做直播带货:

+   1. 粉丝陪伴者。会关注所有弹幕，然后找出最有表达欲的事情讨论。

+   2. 消费引导者。是给消费者提出购买理由的试用者，是给消费者提供购买指南的布道者，还是给消费者发出购物指令的引导者。

+   3. 技能型主播。在某些领域颇有研究，比如懂搭配、懂潮流的服装主播，懂成分、会化妆的美妆主播。

+   4. 分享者。能有理由地喜爱商业化产品，并且愿意分享这些心得。

+   5. 表达者。表达能力强的个体，每次表达都有理由，除了产生金句，还能寓教于乐，让人爱听。
