# 持续没有正反馈、
坚持不下去，怎么办？

李荣禄

7年餐饮业经验，内容领域创业者

这种心理状况背后，是缺乏拿到结果的经验 and 自信心，是对新挑战产生了下意识的畏惧感。所以，去做离正反馈更近一些的事情。

正反馈让你无须坚持，距离目标越来越近亢奋，能在潜意识里激发行动。

+   1. 首先，认清自己的能力范围，不要一上来就做离能力圈太远的事情。

+   2. 同时，用好资源优势，避免在没有积累的赛道从零起步。

+   3. 专注，调低预期，不被细节拖垮，不被负面信息干扰……

只要有了 一次正反馈，强化了自信心，剩下的，就交给时间吧。
