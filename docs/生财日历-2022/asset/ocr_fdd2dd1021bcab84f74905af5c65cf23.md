# 如何判断
所获取信息的准确性？

金马

区块链行业创业者

首先，任何信息都有可能存在错误或者偏差，我们要用辩证的眼光看待信息，实事求是地去怀疑。

其次，努力寻找信息的源头，因为信息在传递的过程中，翻译或转述都会降低信息的准确性。

最后，如果无法获取信息的源头，就需要进行多渠道的确认，以及看其他人如何解读信息。这个过程就像写论文，调查、分析和对比都不能少。

不存在绝对准确的信息，我们能做的，是在有限条件下避免被误导。
