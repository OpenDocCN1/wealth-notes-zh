# 致《生财日历2022》用户的一封信

你好，感谢你对这本《生财日历2022》的认可。我是“生财有术”创始人——亦仁。

当我们提到“财富自由”，并非是在讨论究竟要赚到多少钱，而是聚焦于“如何掌握更多自由选择的权利”。支撑这件事的，是更青睐长期主义的思考力，是以持续创造价值来应对市场与商业不确定性的实践力。在“生财有术”，我们将其并称为“生财力”。

提升“生财力”，需做三件事：

+   1. 提升商业认知格局，登高博见。破局、重构、笃定、践行；并秉持着长期主义的价值观，必然能在每一次选择与决断中提高胜率。

+   2. 总览行业多元案例，拨云见日。跨境电商卖家、短视频玩家、独立开发者、形象规划师、精算师、战略顾问、连锁超市老板、家政公司创业者……遍布不同领域的数千个真实案例，令人大开眼界。

+   3. “看见”榜样的力量，见贤思齐。每个看似平凡无奇的普通人，凭借双手在物质与精神上获得的极大自由，用他们的真实事迹激励、鼓舞并引导着我们。

在“生财有术”，有超过30000位不同领域的从业者、创业者，共计分享的数万篇主题讨论、3000余篇精华文章中，聚合了无数人深邃的认知与思考，凝合了在不同行业、项目、商业环节上的细节复盘，收录了不同起点、不同经历、不同境遇过后的创业心路历程。

这本日历的内容、案例，选自“生财有术”近一年来与“生财力”相关的人与事。我们将赚钱路上值得关注的问题分成12类，每月讨论其中一类。有道、有术，同样有榜样，与你一同领略，三百六十行高手的商业分析思路。

日历正文的篇幅有限，每篇内容背后，会额外附带一份音频内容，围绕当日的问题，提供更完整的案例、思考、总结，帮你从更广、更深、更具体的维度打磨“生财力”。

生财之路，道阻且长。但在这条路上，你并不孤独。希望接下来每一天，这本小小的日历，都能给你带来启发。
