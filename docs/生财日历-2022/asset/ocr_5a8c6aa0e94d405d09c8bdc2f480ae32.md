# 高手是如何谈判的？

老赵
天使投资人，“三夫户外”董事

+   成功的谈判是双赢的，好的谈判应该得到这样的结果：
1. 我得到对自己有利的谈判结果（我挣得了“里子”）。
2. 让对手特别开心（对方挣得了“面子”或者“好的心理感觉”）。
3. 我自己也开心、放心（我也得到了“面子”）。
4. 双赢：对手也赚钱了，这样更便于长期合作（对方也得到了“里子”）。

谈判更高深的境界，在于了解各方真实需求，创造价值，把资源总额做大。所以要更关注双方一致的地方，建立信任，展开整合性谈判，获得双赢。
