# 近些年，有哪些商业价值被重新定义了？

Caorz

“CNZZ” 创始人之一，技术、产品专家，“caoz 的梦呓” 主理人

商业价值重新定义，即一个产品或者服务，可能背离其原有人们熟知的目标、用途、价值体系，产生了新的跃迁。在竞争激烈的市场中，谁成功进行了商业价值重新定义，谁就可以脱颖而出，成功破局。

我认为，有三种商业价值重新定义的方向：

+   1. 受众人群重新定义，比如可口可乐从药剂糖浆到饮料的改变。

+   2. 价值锚点重新定义，比如劳力士手表从工具用途到身份地位象征的转变。

+   3. 商业路径重新定义，比如 360 软件从用户付费到流量入口的变现。
