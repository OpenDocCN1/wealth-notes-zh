# 普通人入局社区团购的
比较好的机会是哪些？

孙策

线下拉新领域创业者

社区团购初期有这三种入局思路：

+   1. 当团长，是参与社区团购最简单的方式，其实就是成为某平台的代收点，收取存放订单、群发订单的佣金。

+   2. 做拉新，也就是通过地推团队替平台拓展商家，规模化运作，赚取拉新收益。

+   3. 代运营，类似于租用商店或快递点的场地来当团长，同时也通过拉群的方式赚取团长身份的佣金。

任何本地生活类平台在扩张期，都会给普通人带来这三种入局的机会，不局限于社区团购。
