# 如何理解
“风控”和“羊毛党”的关系？

半佛仙人

风控行业专家，“半佛仙人”“仙人jump”主理人

这两者，其实是“相爱相杀”以及互相依存的关系。

如果没有“羊毛党”，那么“风控”就没有存在的意义；如果
没有“风控”，“羊毛党”就从智力游戏变成体力游戏，进而
内卷化。

实际上，很多“羊毛头子”就是“风控”出身，很多“风
控”私下也做“薅羊毛”的操作。双方本身都是对于规则的“玩
弄”，无非是保护哪一方利益的差别。

“风控”会根据“企业利益最大化”原则来调整对“羊毛党”
的治理力度，当然，这就是另一个维度的事情了。

两者都不过是“工具人”的一体两面而已。
