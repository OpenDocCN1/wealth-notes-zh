# 如何提升裂变效果？

文林
抖音电商操盘手、裂变活动策划人

想要提升裂变效果，最核心的一点就是利用“用户熟悉的场景”去进行海报包装。

把目标用户每天熟悉的各个场景、画面拆解出来，看哪些场景、画面能够化为自己的包装所用。例如：用“群二维码”作为裂变的海报；用“手机微信聊天”的界面做裂变海报；在进行Excel 课程裂变时，用 Excel 表格为背景制作裂变海报。

这个方法背后的深层原因是，熟悉感会带来天然的信任感，也会带来用户的下意识行动。
