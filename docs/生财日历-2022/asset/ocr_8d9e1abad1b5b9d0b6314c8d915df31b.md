# 普通人如何做好
短视频内容？

杨涛

流量专家，持续创业者

普通人想要做好短视频内容，有三个最重要的问题：

+   1. What——内容是什么？

内容可以是：来自所在的行业的百科，把书面语和专业术语
变成大白话进行演绎；把已经爆过的内容“像素级”地照拍一
遍。找到适合的传播环境后，内容本身就不再是最重要的了。

+   2. How——怎么创作？

无须纠结好的设备，打开提词软件，用后置摄像头克服镜头
恐惧，记得在视频中带上你的联系方式。

+   3. Where——去哪里发？

视频做出来，除了发抖音，记得把它同步到今日头条、微博
等所有能同步的地方，只要分发成本足够低，就可以填补这些生
态位。
