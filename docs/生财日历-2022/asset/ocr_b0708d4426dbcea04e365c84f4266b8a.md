# 职场上，如何让老板看到你的价值？

Caoz
“CNZZ” 创始人之一，技术、产品专家，“caoz 的梦呓” 主理人

让老板看到你的价值，核心就是要做好向上管理，学会和你的上司沟通，并且获得对方的信任和支持。有这样五个小技巧：

+   1. 建立信任基础。信任来源于履约能力，就是答应的事情能做到，承诺的东西能实现。

+   2. 目标对齐。明确自己的工作目标和价值体现，如果不清楚或者理解不透彻，及时和领导沟通。

+   3. 边界控制。管理上，职场上有容错性，但容错需要有边界。

+   4. 权益争取。作为管理者，需要替团队争取权益，维系积极的情绪，提升团队的价值产出。

+   5. 有效反馈。所谓有效反馈，很重要的是换位思考，站在上层的角度看待自己的反馈。
