# 创业选赛道，
是当“鸡头”还是当“凤尾”？

Yan Yu
产品专家，“微友助手”CEO

“鸡头”和“凤尾”如果只能二选一的话，我会选“鸡头”。原因有三：

+   1. 只有做到顶级，才能得到势能上的巨大优势，哪怕只在某个小领域里也能因为势能快速传播，在短期内取得成绩。

+   2. 红海行业的末端玩家很难向相邻领域做辐射和扩张，“鸡头”正相反，势能可以让我们成为产业链条的上下游或提供业内其他产品和服务。这种优势，能让你在新赛道成为新的“鸡头”。

+   3. 只有处于头部甚至形成垄断才有足够的利润空间，有利润空间后业务发展和创新维度就会多一个次元。
