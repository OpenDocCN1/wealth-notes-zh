# 技术人如何
通过建立 IP 稳定接到项目？

卢灿伟
自由职业者、产品、游戏、工具爱好者

技术人都接过外包工作，但很少有人能把它做成副业。因为大多数人的外包工作都是熟人介绍的一次性项目。

想要把外包工作变成自己稳定的副业，需要打造 IP，让别人知道你是谁，你有多厉害。

可以做这样四件事：1. 身份打造。在各大技术社区和网站打造自己是“自由职业者”“独立开发者”的人设。2. 内容输出。针对性地输出文章，丰满人设，让用户觉得你有价值。3. 制作产品案例。通过制作产品案例让客户了解你，方便用户去询问和体验。4. 社交认证。通过输出有价值的内容，获得技术大佬的认可背书。
