# 是选择视频号还是抖音？

晴矢
“创业海盗”“副业岛”CEO

抖音更适合电商业务，生态比较成熟，用户在上面更多是“看热闹”。它基于算法推荐，只要内容有特点，很容易获取到大量用户。而微信视频号更适合普通人尤其是内容从业者，原因有以下三点：

+   1. 微信正在大力建设微信生态（“公众号 + 视频号 + 个人号”的闭环运营），对于普通人来说机会更多。
2. 微信视频号采用“社交 + 算法”的推荐模式，更有利于打造有深度的内容，让粉丝产生信任感。
3. 微信视频号不希望出现头部账号垄断，以及内容过于同质化的视频。
