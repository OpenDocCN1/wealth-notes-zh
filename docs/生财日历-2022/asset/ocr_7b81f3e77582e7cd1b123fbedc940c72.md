# ## 第一次创业有哪些特别容易踩到的坑？

Albert

1998年出生的连续创业者，跨境电商研究者

如果低估创业这件事的难度，常常会踩到这些坑：

+   1. 没做市场调研，选择了自己擅长但没有市场的方向，或没有任何优势、经验、资源、红利的方向。
2. 创始团队没有壁垒，盈利依赖外界资源和政策，没有意识到世界总在变化，不确定性是常态。
3. 起步阶段没有合理的资金预算或者没有控制好成本，遭遇资金链断裂，“创业未半，花光预算”。
4. 搞所谓“完美主义”，导致业务没有进度，缺少先完成、再完善的意识。
5. 想法太多，精力太过分散，不能专注做好一件事。
