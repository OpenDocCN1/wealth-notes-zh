# 抖音短视频如何快速起号？

孤狼
电商领域创业者，抖音电商IP 博主

想要快速起号，第一步就是粉丝破万。怎么做呢？

+   1. 参考同行的爆款选题，精选10个作品。切记只参考选题，不参考文案。
2. 每天发2条作品，每个作品投100元“抖加”，选择涨粉，测投产比。
3. 如果100元带来超过100个粉丝，就继续追投500元，之后带来超过500个粉丝，那就再继续追投。
4. 如果你的视频没有爆，那说明你文案不行，但在这个阶段不用管，可以换2条继续发。
