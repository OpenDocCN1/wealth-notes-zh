# 如何理解抖音电商？

赵鑫
自媒体创业者，“老赵营销笔记” 主理人

抖音电商被定义为兴趣电商，因为抖音会根据你的喜好，推送你想要的东西，更精准地实现以兴趣为主要维度的“人货匹配”。

抖音电商正在逐渐起势，而且无论是抖音直播、抖音短视频或抖音 SEO，都是品牌获得更多新客的重要手段。通过对花西子的深度解析，我得出了一些经验：1. 一定要抓住平台的红利；2. 直播、短视频、抖音 SEO 三者相辅相成；3. 一定要重视爆品，没有爆品就没有 GMV（商品交易总额）；4. 必须重视抖音小店的运营，这是做好抖音电商的基础；5. 建议做店铺群，最大化地获取平台推荐流量和搜索流量。
