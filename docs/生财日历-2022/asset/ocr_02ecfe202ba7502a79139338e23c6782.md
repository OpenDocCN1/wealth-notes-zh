# ## 如何提升知识付费产品的价值感？

条形码

中科院硕士，“好成绩教育”联合创始人

在目前的商业环境中，凡是边际成本为零的模式，都可以用来打价格战。所有的竞争，最后都会走上比拼成本的老路。随着知识付费越来越热，我们要怎么捍卫自己的定价权，告诉用户我们的产品真的值这个价呢？有这样四点：

+   1. 在行业窗口期内，尽快做起来，积累到足够多的资源和利润。
2. 从大众普适的爆品课程向较为小众的类目开发。
3. 积累自己的品牌力。
4. 想办法把行业内的人聚集起来，成立类似行会和行业联盟的组织。
