# 怎么看待那些
大众存在偏见的项目？

温虾米
私立学校合伙人，自由投资人

越是存在偏见，越有赚钱的机会。因为投资是认知的变现：颠覆性创新就藏在偏见中。

每个人都带有偏见，都会对某些事情带有刻板印象，从而无视潜在的机会。如果你能看清某些趋势，寻找不确定环境中的确定性，提前布局这些项目，就能赚到钱。

比如，几年前，无数人不看好新能源汽车，嘲笑我们买了“电动爹”，特斯拉的股价也在质疑中被许多机构做空。当我们逐渐消去偏见后，特斯拉股价应声上涨。

投资是个很有趣的游戏，用钱来验证你的认知是否正确。如果正确，市场会给你奖励。
