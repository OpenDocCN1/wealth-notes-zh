# 如何拥有战略性思维？

小马宋

小马宋营销咨询创始人、战略营销专家，“得到”App 营销顾问

战略从本质上来说就是一个选择，而选择决定了终局。战略思维就是拥有准确判断和选择规划能力的思维，我们要研究现在做什么才会有未来，一定不要从众，一定要有自己独立的优势，一定要看得远，一定要超越眼前的困难和眼前的利害。

因此，在培养战略性思维时，需要重点考虑以下四个问题：

- 第一，如何形成差异化或取得优势？
- 第二，如何有效发挥企业的资源禀赋？
- 第三，有没有压倒性投入来支持这个战略选择？
- 第四，供应链是否足够稳定？

这些问题，都是一开始定战略就要思考清楚的问题。
