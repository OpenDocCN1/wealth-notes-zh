# ### 竞争激烈的环境下
### 如何坚持长期主义？

张茗程
“禾葡兰”联合 CEO，美妆私域领域创业者

不同的人在竞争中会给出不同的答案，从我的角度出发，更重视以下五个方面：

+   1. 竞争激烈的环境，更需要重视产品力的提升，帮客户解决问
题是走下去的必要条件。
2. 一切以人为中心，员工和客户都需要创业者来成就，这
也是企业持续发展的根本。
3. 持续创新，跟上发展，一把手、操盘手尤其要保持敏锐。
4. 长期主义一定会遇到很多问题，这时我会少计较得失、
多思考对错，逐步提高决策正确率。
5. 一家企业的长期主义，会体现在品牌力上，多得用户和
员工的心，好过一切包装。
