# ## 如何更好地打开市场、获得用户？

杨洪进

互联网产品专家，“蝉妈妈”“蝉大师数据”联合创始人

如果说，获取免费流量和付费引流是“开源”的话，做好服务提高口碑就是“节流”。开源节流双管齐下，就能实现用户积累和拉新，打开直播市场。

+   具体而言，可以使用以下四种方法：
1. 通过短视频沉淀粉丝，令直播信息触达用户。
2. 提升直播间内容质量，通过提升时长率、留存率、互动率、涨粉率撬动公域流量。
3. 通过合理的付费广告投放获取商域流量，快速获取流量的同时撬动自然流量。
4. 做好服务，实现二次消费和拉新，使用户的积累呈正净增。
