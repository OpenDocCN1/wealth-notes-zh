# 做好短视频文案，
需要关注哪些细节？

Ducky
保险理财行业创业者

关于短视频文案，我有四点建议：

+   1. 讲故事而不是讲道理：不要上来就讲理论和知识，而是用真实状态呈现这个故事，让观众觉得是和自己息息相关的。

+   2. 展示不完美：不要想着在观众面前呈现一个高高在上的完美形象，而是要以一个他们身边的同行者，通过展示自己的不完美，增加 IP 的真实感和亲近感。

+   3. 提炼生活碎片中的价值：从生活日常里提炼出对他人来说有价值的东西，就会是一条好的视频。

+   4. 知识价值和情绪价值结合：提供知识价值体现专业度，提供情绪价值建立和粉丝间更强的黏性。
