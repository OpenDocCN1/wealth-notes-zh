# 利他思维是怎么影响
一家企业的？

小马宗

小马宗营销咨询创始人，战略营销专家，“得到”App 营销顾问

利他，是古茗这家企业重要的价值观之一。古茗的加盟系统有这么四个特色：

+   1. 加盟店必须赚到钱，不用广告的方式去招揽加盟店。
2. 品牌不赚加盟费，只赚供货费，努力让加盟店的销售额更高。
3. 规定60% 的新店由老加盟商加盟。
4. 明确要求新加盟商必须要自己管店，拒绝只加盟不管店的投资客。

而这带给古茗的结果就是：出生在“骗加盟”横行时代的古茗，其他那些骗一把就走的公司早已销声匿迹，古茗却变得不可战胜——目前古茗已经有超过4500家门店，单店营业额日均5000元以上。
