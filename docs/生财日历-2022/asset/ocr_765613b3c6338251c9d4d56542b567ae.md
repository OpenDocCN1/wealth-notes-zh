# 2022年，
有哪几类副业机会？

紫菜

社群创业者

如果在2022年想要做副业，你可以从三个方向去寻找机会。
第一个方向是分销返佣：分销本质上就是卖货，将认可的内容、产品，通过网络售卖出去，从销售额中抽取佣金；第二个方向是售卖技能：利用写作、设计、摄影、翻译等兴趣特长，提供差异化服务，本质上也是通过付出劳动换取收入；第三个方向是通过买流量、资源置换，给自己的平台流量引流，促成成交，获取收入。

建议在工作之外，起码要掌握一种以上的专业技能，来应对未来的不确定性。
