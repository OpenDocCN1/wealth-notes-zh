小红书作为一个内容平台，用户以年轻女性居多。在小红书上赚钱的方法很多，但内容上，离不开平台的内容核心圈层，比如美妆、穿搭、美食、家居等。

具体方式包括：

+   1. 创作优质内容 [UGC（用户原创内容）、KOC、KOL]，接笔记商业广告或者直播带货赚佣金。

+   2. 建私域，私域带货。

+   3. 做 MCN（多频道网络），赚取广告分成费和推广策划费。

+   4. 开“薯店”，入驻小红书商城。

+   5. 小红书达人授课。
