# 如何理解沉淀成本？

老胡
12年资深淘客，“离线科技”CEO，“淘客公园”创始人

我先举三个例子：

+   1. 喜欢一个姑娘，苦苦追求半年多，请吃饭、买礼物、献关心，但她就是不明确表态。
2. 招到一个人并安排入职，你一直培养和锻炼他，但对方还是有很多地方不如人意。
3. 做了一个项目，投入大量的财力、物力、人力，一直没起色。

你付出的金钱、精力、情感、时间，都是沉淀成本。

在生活工作中，这些沉淀成本随处可见。随着时间的推移，金钱的占比降低，时间、精力和情感投入等无形的成本越来越高，我们常常被其“绑架”，踏上无尽深渊。这时，就该回头想想，自己的初心到底是什么，果断决策。
