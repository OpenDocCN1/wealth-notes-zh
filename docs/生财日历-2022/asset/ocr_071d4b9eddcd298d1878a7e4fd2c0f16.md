# ## 微商思维
## 有什么可以学习的地方？

云帆

“解散咨询”创始合伙人，电商数据研究者

很多人看不起微商，但偏见中，总会有赚钱的机会。作为老板与操盘手，在创业过程中，我越来越意识到，使用微商思维发展业务，真的是屡试不爽。

那么，要如何借助微商思维来帮助自己赚钱呢？

+   1. 微商模式最吸引老板的是前置的现金流和负成本搭建销售团队。
2. 好的代理不是培养起来的，而是筛选出来的。微商模式最吸引代理的是“躺着赚钱”的逻辑，对于大多数人来说，微商的本质就是资源变现。
3. 微商模式最重要的是招商，而招商的本质是吸引。
4. 驱动代理最大的激情动力不是美好的希望，而是残酷的现实。
