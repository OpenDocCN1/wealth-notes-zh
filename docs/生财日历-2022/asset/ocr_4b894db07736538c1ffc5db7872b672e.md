# 怎样借力大平台
挖掘自己的商业空间？

柳柏林
线下拉新团队创始人

国内绝大多数一线平台都有持续的流量获取需求，这就催生了线下拉新的生意机会。
线下拉新的模式并不复杂，重点在规模化放大。
首先，确定一个合适的平台，快速组建团队，制定流程和标准，先通过赚到1000元积累经验，再放大到1万元。
然后，可以横向复制经验到其他平台和业务上，拓展团队、快速布局，也沉淀用户到私域。
单个平台线下流量接近饱和时，不要恋战，及时转型，通过服务私域用户以战养战，寻找下次机会。
