# 如何经营好
自己的人生总时间？

光合
战略咨询顾问， “生财有术” 合伙人，“华与华” 前项目总监

时间在哪儿，结果就在哪儿，一切都是时间的成果。
每一个人都要去经营自己的“人生总时间”，对于每一天、每一周、每一个阶段的时间，都要有相应的规划，一步一步经营好自己的人生总时间。
重点关注以下五点，可以让你更清晰地规划人生总时间：

+   1. 时间要用在有价值的事上。
2. 做和自己目的有关的事情。
3. 时间要日日不断地用，相信时间复利的价值。
4. 时间要大段大段地用，提高思考的深度。
5. 自己的时间不要轻易给别人用，拒绝无效社交。
