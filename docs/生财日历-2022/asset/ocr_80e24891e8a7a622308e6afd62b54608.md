# 现在做实体小生意
还有机会吗？

码迷
“码迷 SEO”创始人

机会肯定是有的。实体销售和互联网销售一样，只要懂得找流量、做产品、精细化运营，发家致富并不难。
就拿我的早餐店来说：

+   1. 找流量、选位置时一定要有人流量。我在选摊位时，要求地理位置必须靠近车站或学校，确保人流量。
2. 做产品。店里主打的是无矾放心油条，保证产品绝对不差。
3. 精细化运营。针对不同时间段的人流量，做相应的价格策略调整。比如学生早餐的特点是集中、不砍价，我就提前打包，拼速度，且明码标价，自助找零；针对本地居民，我推出了8点半特价产品，满足很多人“占便宜”的需求。
