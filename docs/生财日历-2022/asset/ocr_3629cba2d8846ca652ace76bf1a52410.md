# 如何在竞争激烈的市场，
打开溢价空间？

闫寒
餐饮服务机构“闫寒餐饮智库”创始人

无论是餐饮、电商还是知识付费，只要是大众品类，就都脱离不了价格战。但是如何做到理直气壮地卖得比别人贵，这是一个比打开销量还要重要的问题。

想要打造“高利润 + 高单量”的模型，就要做到：

+   1. 原汁原味地打造一个有文化底蕴的品类，获取认知溢价空间。

+   2. 要在一个细分品类上当“老大”，而不要在大众品类里当个“普通人”，以获取垂直流量空间。

例如，高度“内卷”的快餐行业，会有品牌把菜单设计成“剧本”风格，他们的目的并不是“独特”，恰恰是“差异化的最佳体验”。
