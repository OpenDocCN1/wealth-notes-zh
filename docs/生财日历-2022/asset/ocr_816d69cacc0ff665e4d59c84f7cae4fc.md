# 在职场进阶，  
要选大公司还是小公司？

黄有璨  
“有趣学社”创始人，《运营之光》《非线性成长》作者

不同阶段有不同的选择。  
如果你才刚刚进入职场，对于自己擅长什么、将来要做什么  
还不太么清晰，自己也不属于那种特别折腾、野蛮生长能力特  
别强的选手，那么第一份工作可能还是无论如何先进个大公司待  
个一两年见见世面比较保险。  
但当你目标明确，有了相对清晰的认知后，一定要关注能否  
长期形成自己在整个行业内的竞争力。这时，首先看重的事是  
自己的成长，于是“宁做鸡头，不做凤尾”，在二线战场成为一个  
毋庸置疑的头部选手，再携带头部势能重返原有的一线战场。
