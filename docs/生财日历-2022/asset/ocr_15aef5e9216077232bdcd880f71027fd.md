# 独立开发者找副业要避免哪些误区？

壹树

资深产品经理：独立开发者

独立开发者找到副业，往往不是因为他们技术有多好，而是因为他们能看到用户的需求，并能帮用户解决问题。

很多时候，我们会依赖技术，但在赚钱这件事上，代码只是一种方式，插件也只是一种方式。只有直面用户，满足他们的需求，通过持续地收集用户反馈，让一部分用户满意，钱自然就来了。其实，赚钱这一步是后置的，优先的是帮用户解决问题。
