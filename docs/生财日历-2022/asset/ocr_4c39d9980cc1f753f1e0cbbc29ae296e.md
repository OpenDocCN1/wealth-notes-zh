# # 参加线下活动，
# 如何收获更有价值的信息？

**家蒙**
“知乎好物”作者，内容带货创业者

参加线下活动更有收获的两个小秘招：

+   1. 在听的时候要学会屏蔽噪音，找到质变的点。通过抓住重点，积极提问，引导分享者把关键信息讲出来，这才是最有价值的部分。比如我做知乎好物，第一个月挣了500元，第二个月挣了16000元。多数人会聚焦在我赚了多少钱上，但最需要关注的应该是“如何一个月从500元做到了16000元”。
2. 保持最好的参会状态，尽量找到两样东西：一样是可以合作的资源，另一样是榜样。
