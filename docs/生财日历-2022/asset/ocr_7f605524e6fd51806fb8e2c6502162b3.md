# 如何看待
电商的店群玩法？

孤狼
电商领域创业者，抖音电商 IP 博主

每年都有人说店群行不通了，但一直有人做。如果你把店群看作是一种玩法，那么会玩死。因为随着玩的人变多，效果会变差，平台也会根据大家的玩法改规则。如果你把店群作为一种底层思维，那它就能一直玩下去。

比如2017年至2018年，店群曾出现过大批量采集，把别人店铺的宝贝采集到自己店铺，加价格或吃佣金赚取差价，并以量取胜的玩法。2018年年中，开始玩裂变，给一个宝贝做上百个标题，最低成本覆盖关键词搜索流量。现在，开始玩蓝海，通过生意参谋后台，拉取竞争小的蓝海词，做成标题再去选品上传。
