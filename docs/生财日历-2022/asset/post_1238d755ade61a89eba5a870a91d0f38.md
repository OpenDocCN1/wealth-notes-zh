# 什么是品牌 IP 化？

付圣强
“ONE/ 有树文化” 总经理

品牌 IP（知识产权）化其实就是让品牌变得不只是个商标，而是像 IP 一样，成为某种符号化的认知。让品牌成为占领用户心智的入口的过程就是品牌 IP 化的过程。

品牌 IP 化分为四个层面：

- 点：品牌核心识别，是品类占位。
- 线：传播线和用户互动，包括定位、信任状。
- 面：通过用户体验路径的全触点管理，完成持续的营销运营动作。
- 体：面的交错融合，相互借力而又各司其职，合力抢占目标市场。

徐十胖
产品专家，“西瓜视频”签约博主

短视频流量起步的规模很大，但周期短，流量不易持续稳定，适合爆发性带货；中长视频让用户有足够多的时间“种草”商品，尽管流量刺激小，却能因为长尾流量而持续出单。

B. 一个月更新20条，有5条广告。

对照你的产品，长期去看，哪个选择平摊下来的成本更低、收入更好，哪个就是更适合你的变现模式。

# 2022年，有哪几类副业机会？

紫菜
社群创业者

如果在2022年想要做副业，你可以从三个方向去寻找机会。

- 第一个方向是分销返佣：分销本质上就是卖货，将认可的内容、产品，通过网络售卖出去，从销售额中抽取佣金；
