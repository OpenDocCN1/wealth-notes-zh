# # 如何在带货平台
## 写好一篇“种草”文？

徐宿
内容带货创业者；自媒体人

随着各个内容平台都开始带货，平台对于“种草”文的质量要求越来越高，因此，“种草”文要以内容的效果和质量作为目标。记住，“种草”文的核心目的是影响读者的消费决策，促成交易。

这八个影响读者消费决策的细节要重点关注：头图、标题、故事引导块、目录、正文、衔接润滑块、转化通道、结尾互动引导。

拿头图来说，核心就是制造效果幻想，因为欲望产生冲动，冲动促进行为。所以，选择头图的标准是：看了这个图有没有想要点进去了解的欲望。
