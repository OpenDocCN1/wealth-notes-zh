# 自己想做 IP 但精力不够，应该招团队做吗？

颜过
13年外贸电商领域创业者

管理者出现精力有限的情况很正常。精力不够，可以选择先缓一缓，或者把一部分工作分给下面的团队做。但不论选择哪一种，都要求管理者自己想明白要做的核心是什么。我们当然可以招一个人，甚至是一个团队过来帮你做 IP，但是管理者自己首先得把框架搭好，再让底下的人去负责。

当我们在犹豫要不要招一个团队时，本质就是你没想清楚需要什么样的人。但当你把核心想明白，搭好了框架后，你自然就会知道，你要招什么样的人，他们进来能帮你做什么。
