# 为什么要打造“个人代表作”？

卫夕  
“卫夕指北”主理人，互联网行业观察者

作品，是花费你大量心血，能拿出来让人惊叹的东西，它可以是一个项目、一篇文章、一次演讲。同样是投入精力，做出十件平庸的东西，往往没有人记住你的产出。而作品的特点就是能让人啧啧称赞，是有可传播性的东西。它的能量可能超出你的想象，而且它会持续地产生价值。

比如，《罗辑思维》的制片人在微信上找到我，说罗振宇老师看中了我一年前的一篇文章，想要将其制作成一期节目，问我能不能授权。我说当然能。一周后，随着《罗辑思维》节目的上线，两天之内，我的公众号粉丝数涨了40%，大概等于我半年的涨粉目标。
