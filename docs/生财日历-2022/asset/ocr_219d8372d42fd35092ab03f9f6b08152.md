# 公众号进入稳定期，如何快速涨粉？

sitin 涛哥

安全公司技术负责人，“涛哥聊 Python”主理人

公众号进入稳定期后，单独靠内容主动涨粉其实很困难，而给公众号引流涨粉，则需要一些运营技巧，不能纯靠内容。

我的引流方式主要有以下五点：1. 视频引流。在视频号的视频、直播或者留言区设置一些引导文案。2. 活动引流。通过送书抽奖活动增粉，一来可以吸粉，二来粉丝也比较垂直。3. PC 网站引流。通过到公众号发送“关键词”获取验证码以继续看文章增粉。4. 付费引流。一来有大佬背书，粉丝更信任，二来也有一定的品牌曝光度。5. 资料引流。需要注意标题要过关，内容通用，不标“原创”。
