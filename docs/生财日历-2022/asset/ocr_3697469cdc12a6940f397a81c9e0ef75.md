# 利他思维对获得用户信任
有哪些帮助？

张集慧
6年流量领域创业者

当你为什么获取用户信任发愁时，说明你还在用传统的流量获取模式，使用各种容易触发感性冲动的素材广泛分发以获取客户。

想要解决信任问题，核心就是用利他思维，从最初就站在为用户服务的角度，而不是一上来就想转化他。这样做的好处是：

+   1. 在前期就筛选出了目标用户，用户精准。
2. 你为平台提供了有价值、受欢迎的内容，平台对你的流量获取和商业化会相对包容。
3. 你吸引来的用户，都是主动关注到你的，信任已经初步培养好了，后期做转化时，只要不是跨度太大引起用户反感，成交率是很高的。
