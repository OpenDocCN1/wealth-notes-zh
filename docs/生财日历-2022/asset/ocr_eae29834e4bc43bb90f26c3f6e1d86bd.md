# 创业初期，有什么注意事项？

王新
热干面品牌创始人，实体餐饮创业者

我们是一家定位地方特色菜的初创餐饮品牌，以下是我认为在创业初期需要注意的五点：

+   1. 不要小看餐饮市场的复杂性，选择正确的土壤进行创业无比重要。
2. 务必正确对标，从0到1的餐饮创业者，一定要选模式已被市场充分验证过的品牌去对标。
3. 艰难时刻信心比金子更宝贵——新冠肺炎疫情期间全靠外卖业务，虽然杯水车薪，但能让团队看到希望。
4. 传统餐饮人要想把外卖做好，就得先低下头去学习电商行业的运行规律和平台的玩法规则。
5. 从“高毛利”“快出餐”和“低衰减”的优势产品立基，重新设计外卖产品的 SKU（库存保有单位）。
