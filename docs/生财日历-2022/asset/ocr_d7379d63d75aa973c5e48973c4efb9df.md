# 投资人是怎么选择投资项目的？

大韩
“众拓投资”联合创始人兼 CEO

我会通过以下三点选择投资项目：

+   1. 通过身边的朋友和人脉资源去找感兴趣的投资项目。选择最熟悉和信任的直接关系，亲友介绍可以减少大量沟通的时间成本。

+   2. 找靠谱且实干的 Leader（领导者）和团队。做好一个企业需要有战略组织力的领导者 and 强有力的执行团队，二者共同决定公司未来能够走多远。

+   3. 调研行业是否具有足够的市场空间和增长潜力。充分利用网络筛选相关信息；深入企业基层了解运营情况；多与领导层进行沟通——好的领导者由使命驱动，三观正且有远大的愿景。
