# 小公司如何通过校招
找到合适的人才？

中林

7年制造业 HR，现自媒体人力资源输送者

在学校办招聘会，效果最好的肯定是大公司，比如华为。
没有什么名气的小公司，想要效果好，就要额外下功夫。比如提前去学校踩点，提前小范围和学生沟通，看看这一届学生，他们更关心什么，有什么诉求，在招聘会上有针对性地进行调整。
除了传统招聘，还可以前置化招聘。企业把需求梳理出来，学校按要求培养学生，企业还可以提前和学生接触，比如派企业的老师到学校上课。这种模式被称为“订单班”，相当于这个班就为这个企业定制，目的也是为了后期的人才输送更加顺畅。
