# 四五线小城市，
有哪些可复制的赚钱机会？

詹伟平
新媒体矩阵创业者

对四五线小城市来说，本地自媒体的赚钱模式已经非常成熟了，推荐以下三种：

+   1. 本地资讯类公众号。一般人都对身边的事很感兴趣，这类公众号的打开率很高，变现方式主要是流量主收益以及本地广告。

+   2. 本地吃喝玩乐公众号。和资讯号类似，但后端的变现能力更强，因为爱吃喝玩乐的粉丝，消费欲望更强烈。

+   3. 本地图产资讯类公众号。房价是中国人最关心的话题之一，关注群体大。通过房产中介细分后，变现途径可以是接软广告、自己当中介卖房、房产咨询服务等。
