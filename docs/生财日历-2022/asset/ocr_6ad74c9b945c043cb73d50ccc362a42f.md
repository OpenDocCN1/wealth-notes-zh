# 如何向用户传达价值
并挖掘用户的价值？

西门吹花
前电视媒体人，健康类训练营创业者

当有了第一批老用户之后，你会发现，老用户的需求会在日常运营中逐渐浮现。挖掘老用户的更多价值，是公司持续营收增长的关键所在。当你有了第一个爆款产品，围绕老用户研发新产品就成为第二重点。

所以，我们在进行所有新产品的研发时，都会针对老用户，推进以下四个步骤：

+   1. 全程告知用户，我们现在在干什么，你们有什么需要。
2. 我们正在进行的改进和优化。
3. 建立核心用户群进行体验。
4. 听取老用户的反馈，并正式上线。
