# 创业初期需要注意什么？

Jennifer

区块链领域从业者

创业跟打工不同，打工时，只需要把业绩做好，提高自己的工资收入就可以了。而进入创业阶段后，会发现每走一步，都考验着自己的综合能力与把控能力。

回顾我的创业经历，有这样四点总结分享：

+   1. 一个人的精力是有限的，通过招人提高效率，将精力集中于战略方向。

+   2. 现金流为王，控制风险，能省钱尽量省钱，还需要重视省时间。

+   3. 执行力很重要，任何想法都要想方设法尽快落地。

+   4. 当有一款成功产品后，要尽快提高自身产品的壁垒。
