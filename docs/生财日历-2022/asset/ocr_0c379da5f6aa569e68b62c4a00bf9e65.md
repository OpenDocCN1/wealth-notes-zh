# 从一个创业个体转变为一个创业团队，要注意哪些事？

吴大白
7年流量领域连续创业者，技术专家

很多时候，一个人能做得很好，一但团队化运营就出问题了。在我看来，从创业个体转变为创业团队，最重要的一个原则是：先有人情，再讲制度。

在团队的不同时期，关注的重点也各不相同。

人情，在早期阶段，先用人情把团队凝聚在一起。

奖惩，在中期内阶段，在业务推进中慢慢筛选出业务能力强的人，完善奖惩制度。

管理，在稳定阶段，等业务发展到了团队需要进一步扩大时，再开始重视制度，用规则去管理团队。
