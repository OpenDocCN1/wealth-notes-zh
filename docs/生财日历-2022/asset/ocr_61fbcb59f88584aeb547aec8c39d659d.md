# 什么样的生意
算“好生意”？

盛添财
“连在一起”CEO，内容分销平台创业者

从理想化的角度出发，有以下五条判断规则：

+   1. 好生意的商业模式一定利他，甚至能带来社会价值，绝对不是“零和博弈”。

+   2. 好生意一定是可以长期持续复利增长，不要刚建好“护城河”，“城”就倒了。

+   3. 好生意要有想象力，有大空间，很多资源型生意都有很明显的瓶颈。

+   4. 好生意参与方越少越好，因为越多越不可控。

+   5. 好生意的产品，用户上手后能感受到好，能认可你的品牌。

当然，创业未必一定要找到十全十美的好生意，但了解哪些因素能决定生意的好坏，很重要。
