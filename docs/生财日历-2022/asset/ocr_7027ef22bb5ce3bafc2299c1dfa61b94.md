# 私域如何通过社群
10倍扩大商业价值？

刘容
“知识星球”市场负责人，《绝非偶然》策划

很多人把社群当成“训练营内容沉淀中心”或者“付费朋友圈”，但在私域中，这未必能带来10倍商业价值。真正的破局点在于：

+   1. 通过社群，筛出第一批铁杆粉丝。
2. 服务用户，比如，激励他们主动分享。
3. 通过分享，挖掘更多团队成员。
4. 二次分发社群内容，就像“买家秀”，巩固价值感、品牌，吸引新用户。
5. 组织线下活动，促进内部连接，产生大量照片，让准用户看到。

社群既是交付工具，也是增长工具。让成员深度连接，让品牌开始自我繁衍，才能带来10倍商业价值。
