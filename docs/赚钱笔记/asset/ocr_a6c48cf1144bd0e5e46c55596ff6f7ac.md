# 籌開「賺錢筆記」空白處

重點提示 TIPS

+   在筆記的空白處寫下自己的省思
可掌握自己用錢的傾向
防止一些看似「消費」實為「浪費」的開銷

筆記例

| | **消費** | **投資** | **浪費** |
|---|---|---|---|
| **〇月〇日** | 便當 480 | 商業書 1,365 | 雜誌 980 |
|  | 茶 135 | | |
|  | 水 100 | | |
|  | 午餐 1,200 | | |
|  | 總計：4,260 | | |

在晚輩面前點了太高檔的午餐，
好像有點打腫臉充胖子……（死）……………像這樣寫下自己的省思
