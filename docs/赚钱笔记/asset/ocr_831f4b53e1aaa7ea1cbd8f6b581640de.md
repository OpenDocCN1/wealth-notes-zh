# 用「PDCA」循環降低風險

重點提示 TIPS

在思考資產構成的時候，最講求投資的「PDCA」循環
「PDCA」循環是一種將風險最小化、利益最大化的指標

步驟 step by step

+   1) 計畫 (Plan)
先拿筆記本或一張紙，畫一個圓形圖表，寫下自己理想的
投資組合。

+   (2) 行動 (Do)
寫好投資組合後，就依照計畫開始投資。

+   3) 確認 (Check)
資產是每日變動的東西，請定期確認一次。

+   4) 改善 (Act)
順利的話就增加投資額度，遇到意外的損失，就從資產中
除去該項投資標的。

只要「PDCA」發揮機能，
就算投資失利，也能馬上進行修正！
