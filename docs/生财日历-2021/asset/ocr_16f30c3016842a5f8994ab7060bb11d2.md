# 抖音运营的八点经验分享

书选自 “张小何” 的主题

+   1. 一开始就要有具体的产品；
2. 一开始就要有清晰的商业变现路径；
3. 一开始的人设越要越清楚，不要变来变去；
4. 垂直最重要，越垂直的粉丝价值越高；
5. 为粉丝带来价值；
6. 不要任意播放量；
7. 不要在意粉丝量，慢慢积少成多；
8. 不要灰心，不要轻易放弃。
