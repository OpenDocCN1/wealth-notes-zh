# 要降低对“存在感”的诉求，
关注自己的成长

节选自“弥己”的主题

我发现不少人对存在感的需求比较强，而我对存在感的需求比较低，也不太在乎，存在的话有自然有，最后还是被安分力。没有实
力，再怎么表现，明眼人一眼就看出来。对存在感的需要弱，也是
我“生物有术”植群的一个优势。

不管你现处于什么状态，按住自己对存在感的需求，发掘自己
人的优点，不管不外地交流，关注自己的成长。这样，反而会吸引
己交到越多靠谱的朋友。
