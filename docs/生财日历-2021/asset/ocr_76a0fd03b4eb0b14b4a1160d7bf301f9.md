# 普通人如何培养自己的用户视角？

节选自“明白”的主题

要明白“用户视角”不是方法、技巧、技能，而是经验，是为了尊重及理解的感觉。想要培养用户视角需要有意识地观察他人。

可以先从身边整个用户群体开始，发现他们的问题，总结出共同点、槽重点，再去观察其他群体，如果某个槽点相同，说明这是用户的共同属性，而不是某个细分群体的属性。这种刻意练习的用户越多，观察的用户群体越广泛，用户视角就越强。
