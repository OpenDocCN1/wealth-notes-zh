# 小公司生存和发展的关键是
“错开”

节选自 “天雪地铁” 的主题

—

+   产品线：错开研发产品、研发试验、因为成本太高；
流量线：错开竞争，尽量在蓝海巡游，我们也将不起眼；
变现线：错开流失，最大化承受范围。
想办法错开并时刻对自己团队不利的服务线、前期错开高成本，然后随着目标、高效投入，尽可能降低损失。

+   建立某个司的优势抢先拿到，错开越多，利润越大。
要活着，保证要错开一个，剩下错一要求做的，就是快速快速再快跑。
