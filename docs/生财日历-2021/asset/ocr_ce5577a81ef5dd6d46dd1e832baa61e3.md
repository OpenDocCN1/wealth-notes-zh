# ## 如何从数千个微信群内，
找到超级节点、超级代理人？

节选自“陈俊强”的主题

方法就是跟取有人群：把每个微信里的人的昵称、wxld（微信号）导出来，然后合并，我们发现有好多人在我们的群内出现。再根据wxld在多个群内出现的次数去添加联系人。
这个方法主要的用处是发展代理或者分销商，或者是可以让其他人聚力于活的关键点。
