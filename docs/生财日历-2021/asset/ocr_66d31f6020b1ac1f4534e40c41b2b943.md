# 拖延症不是状态不好，是目标不明确

节选自“潘多拉的清单”的主题

+   1. 你的状态并不是原因，状态是一个结果，不要跟状态死扛，扛不过的；

+   2. 拖延症的本质不是状态不好，是没有目标；

+   3. 注意力不要放在情绪上，先分清自己处于哪一个行动状态：维持状态、推动状态，还是调适状态；

+   4. 只要进入“需要状态，立刻开始驱动，驱动紧马上就要推进状态；

+   5. 这是利用好“一”天的时间的基本功；

+   6. 做事要结果导向思维，不谈具体任务，该做成什么，这是最尖锐的；

+   7. 事情越多，越是聚焦关键，不要平均分配，而是单点突破；

+   8. 事前投资，为因解决矛盾更多的资源；

+   9. 不要想着一口吃个胖子，保持迭代。
