# 社群服务相关的
四种创业模式

节选自“肚小哥”的主题

+   1. 社群培训+顾问、先培训，培训后有一段时间用于答疑，适用于中大型企业。
2. 社群动销服务：
在两三周内密集化运营，配合作企业微线上“爆破”活动，产生高销量，适用于有很多粉丝的微商企业。
3. 社群策划+指导服务：
给企业必要的社群方案和日常指导，适用于会议营销、连锁门店等中型企业。
4. 社群策划+代运营全包服务：
帮助全职操作，适用于以快消品为主的大型巴戟企业。
