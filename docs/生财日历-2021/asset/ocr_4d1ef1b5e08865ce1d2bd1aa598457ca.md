# 从“为我赚钱”到“帮你赚钱”

节选自“盗问”的主题

初心不一样，那么其细节和结果也会完全不同一样。打开思路以后，我让自己的运营技术、运营思路、运营资源毫无保留地贡献出来，并且还要想办法让他们更好地理解吸收。

对内，我的目标不是要做一个优秀的运营，而是要培养出无数个优秀运营。我的目标不是要帮员工打造一个成长平台，让那些着靠普通、顺路设计的年轻人，在我这里的成长并日得到钱。

对外，我的目标不是要赚一百万，而是要帮助一百五十个人赚到一百万。我帮助这些人赚到钱，那么我就要钱也是自然而然的事。
