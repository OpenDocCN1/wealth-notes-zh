# 如何迈出创业心理上的第一步？

节选自“第15玲”的主题

有的人感到创业总是迈不出第一步，我的办法是把人生的镜头拉长；

比如你站在一个第三者角度纵观你这一生，你有什么是不可失去的？珍贵的经历？你做出创办的这个选择你会失去这些吗？如果不？甚至得到比失去的多，那问题不解答不会只是自己人生的牺牲或者是自我从众呢？

很多困难都可以用把镜头拉长这个方法来解决，我们的生命也不过是沧海一粟。
