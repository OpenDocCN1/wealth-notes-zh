# 如何理解 “创新”?

节选自 “V先生”的主题

天阳下没有新智事，太阳底下都是新智事。前半句说的是回忆事物多，但总结起来，范特的思维模型还不是那么几个。后半句说的是思维和思维模型存于你的主观世界，而在真实的客观世界里的事物，却早就以百万计，家认式时不发生。如果你带着模型和书本知识，不深入市场一线、不深入消费者，是无法真正了解事物是怎样变化的，也无法做出创新。
