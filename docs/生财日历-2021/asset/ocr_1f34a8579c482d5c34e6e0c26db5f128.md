# 节选自「天赋」的主题

+   1. 不定期地总结刻板的自己，发现问题、解决问题；
2. 在不影响生命正常的前提下，有想法就通过试错、后验证验证自己的精神冲击，往往可能比失败的结果更大；
3. 优先到与自己同类型的人完成一个项目的小闭环，可以快速的判断这个项目能不能做；能否当做事业去做；
4. 听父母的话，但或许不要反叛他们的话去做事；
5. 工作的时间与思维时间应同比分配。
