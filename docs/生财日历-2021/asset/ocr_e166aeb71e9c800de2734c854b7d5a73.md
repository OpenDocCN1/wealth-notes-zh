# 技术类公众号粉丝增长经验

节选自“sirin”的主题

我的公众号在2018年12月底时，有500多个粉丝。那时候，每月几个号主在做读书活动，既能“赚粉”，也能给粉丝带来一些福利，就想要自己也办可以试试一下。

在回复“@上海小陈”的帮助下，我联合两个号主做了一次读书活动。这次活动让我的公众号“囤粉”，超过800个，微信好友增加了100多个。

于是我又组织了第二波、第三波的读书活动，一直做到了2019年下半年。就这样，我几乎零成本“囤粉”2000个左右。
