# 快速见效的“老照片”项目

节选自“摄影”的主题

有一个设计师，利用文字特效，加上简单的转场特效，开始做老电影的视频。很简单的操作：一张剧照，一张FaceApp处理之后的图片，加一个转场特效，就做成一个视频了。

作品是把剧照发到网上，做视频的预告作逐步邀请。X起来的时候是100元做一个视频，一天就有十几人来找他做创意。一星期时间估计赚了小10000元。
