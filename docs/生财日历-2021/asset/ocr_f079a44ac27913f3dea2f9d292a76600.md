# ### 视频号运营的五点经验分享

节选自“皮卡丘”的主题

+   1. 在选择内容方向的时候，除了考虑账号价值，还要保证能持续做下去，这才算关键；
2. 在垂直类目下坚持发布作品；
3. 多参考头部 “大V” 的分发；
4. 作品一定要迎合用户的爱好；
5. 做好每一个视频选题对用户的情绪，但不要过于追求宗教主义。
