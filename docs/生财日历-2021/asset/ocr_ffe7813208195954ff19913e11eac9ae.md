# 新媒体增长方法从哪里找？

节选自“龙共火火”的主题

+   1. 参考迁移：

很多增长方法，包括其他行业、领域的玩法，可以迁移到自己行业进行应用；

+   2. 等提到一手信息：

想要获取信息，最好让自己成为信息源。很多特别有价值的信息，更多的是或下或在小圈子内传播；

+   3. 简称无效信息：

掌握了很多方法之后，不可能全部都做，做一个渠道规划表，从获客成本、粉丝质量、增长可控程度、团队投入、渠道数量、产出验证时间等进行打分，根据需要做些切换。
