# 简单重复正确的事情，
往往是世间最难的事情

节选自“唐珍”的主题

前些年有个最火的抢读游戏，给你一张纸一支笔，一小时内从1写到5000，不许写不允许错。报告书10元，只要写完，就送一只巨型玩偶。

看着多简单，简直是纸送福利。毕竟，谁还不爱捡钱呢？至于时间，平均1分钟写20个数，可以算是相当宽松了。体力方面，800字的手写作文谁没练习过？

然后，实际参加是，能够成功通过挑战的，十中无一。简答重复正确的事情，听起来简单，但因为“反人性”，反倒极难以坚持。
