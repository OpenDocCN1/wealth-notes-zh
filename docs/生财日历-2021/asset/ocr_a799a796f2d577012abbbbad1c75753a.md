# 做投资需要修炼情绪管理能力

节选自“朱颖季”的主题

大众总是欢迎热点。时而情绪高涨，时而感觉悲观。然而就算一天不会电闪未来日，最这一天也未必极致落差。每次看有人赚“这次不一样”，但是实际又没什么一样。

今天的行情多少，与意义。关键是5年后、10年后、30年后的你会在哪里，你的收益最终在这个水平。

这一路上你要跨过无数突发事件和震撼世界的大新闻，你也没有准备好风险。宽松定性的穿越牛市和熊市，获得理想收益的投资策略才是最好。想清楚这些，所有大事作为新闻都是过期旧云。
