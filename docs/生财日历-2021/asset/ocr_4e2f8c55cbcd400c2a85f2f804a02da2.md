# 亏钱千万级项目的经验

> 节选自“小默”的主题

+   1. 如果一开始就说明大家不是共同适合的人，就不要走到一起创业，当断则断；

+   2. 当断则断：有生蛋头脸的人，或是动辄就找到赚翻倍钱的项目，或那些老调子，手上有了几万或几十万。但长远去看，不是所有的人都能靠这些概念类东西后；

+   3. 我遇到不少几个很老实，很仗义的人，好像在路上一直有很好的项目给他们挑赚钱，寻来合作，提供资源——谁也不是傻子，

+   4. 将心比心对，比什么中球都强。
