# 抖音实操：七步新餐饮品牌
“爆店”回本盈利

节选自“徐小敏”的主题

+   1. 找到当地发布过同类产品的美食品，通过定位找到感兴趣的人；
2. 私信要微信联系方式，募集人数60到100人不等，之后建群；
3. 拍摄10到200个关于品牌装修、产品及人物的视频；
4. 在店面拍摄试营业状态，每天下午6点发布视频，并在商圈6公里内投“Dou+”，发布周期为3天；
5. 每天30人次买中品鉴产品，买走抖音集赞奖励活动；
6. 安排开业仪式，每天定量放入顾客，人场氛围不停发抖音并带定位；
7. 接得上门咨询加盟顾客。
