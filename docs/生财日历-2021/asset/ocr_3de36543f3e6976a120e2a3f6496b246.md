# 任正非和马化腾的灰度管理哲学

节选自“百川”的主题

有很多人，毕生都在追究安全感，为了得到对未来的确定性，他们愿意做任何事情。

而另一些人，则非常能容忍不确定性。他们对世界的复杂性与深度有认识，习惯在高度不确定中做出决策。

任正非把华为管理哲学的核心总结为“灰度理论”，马化腾也把腾讯的成功归基于“灰度哲学”。

所谓“灰度”，是介于黑和白之间的一种状态。世界不是非黑即白的，很多地方有广阔的灰度空间。认识灰色，接纳灰色，学会接受没有安全感和不确定性。
