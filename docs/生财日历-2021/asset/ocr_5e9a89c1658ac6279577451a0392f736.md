# 如何通过淘宝商家后台
挖掘投资机会？
节选自“券商牛”的主题

淘宝商家后台有一个叫作“生意参谋”的工具，可以查看淘宝平台的一些数据分析结果。如“电器”或“食品”等，看在生意参谋输入某一产品词语，假如成交数额很高，但并没有显示在二级市场里有面成交的数量，但并没有显示在二级市场的股价上，这就是一个大的机会。

一、排名第一的品牌通常是头部厂商，但其实有很多排在第二、三名的品牌，某地是地区性龙头，某些具有差异化优势。
