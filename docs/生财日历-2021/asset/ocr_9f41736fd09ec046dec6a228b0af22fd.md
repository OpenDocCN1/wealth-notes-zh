# 淘宝服务市场有哪些创业优势？

节选自“天际段子”的主题

落锁近，背景大好耐潮流，竞争相对小。淘宝卖家有良好的付费习惯，即便在移动支付尚未兴起的2010年也是如此。

而它将同一软件做成工具平台，同时服务大量卖家的这种销售模式，单个卖家的付费成本很低，更不会存在拖款、赖账等问题。每个月都有付费，商业模式具有很好的持续性。
