# 早期创业的 三个注意点

节选自 “王华荣” 的主题

+   1. 早期做项目，一定不要同时做好几个，因为你的人才结构跟不上，一定要考虑清楚：自己认同的“防火墙”是什么？在护火墙加固之前，最终你得住各种诱惑。要耐得住寂寞；

2. 尝试新业务也要围绕自己的核心业务来做，这样你的新业务实际上也是在加固你的防火墙；

3. 早期一定要找合适的人，而不应该找极聪明的人。
