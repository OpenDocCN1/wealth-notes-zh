# 做本地订阅号 的五点经验

节选自 “一个人看夕阳” 的主题

+   1. 任何平台，不是没有红利期就不能做了。朋友的美食推荐订阅号，每年营收1000多万元；

+   2. 不要说别人都做了，自己就没什么机会了。用心去做，坚持去做；

+   3. 做一个项目，如果没有不一样的思路，就把它做精做深，把服务做到极致；

+   4. 做什么事情都要专注；

+   5. 想真正做一个项目、平台，要经得起 “耗钱” 的折腾。
