# 耐心玩“拼图”
才可能找到“金矿”
节选自“Caoz”的主题

很多时候赚钱的游戏是个拼抢游戏，很多有价面的或者会写文章的面包屑，散落各处，需要你看动，仔细思考，再谨慎地拼凑出完整的模式，真正欣赏是拼图的，都是过眼的面包屑。没过眼的，你只敢从各中只片中看中过整篇，然后自己去拼。
伸手党觉得这里是是“收割智商税”的，因为每个碎片都无法用于实践。
但如果你是耐着心玩拼图，不能从面包屑中找到线索，去拼凑真实的商业逻辑，那里藏的就是金矿。
