# 国内自由软件
出海淘金的标杆案例

节选自“CaoZ”的主题

美国是车轮上的国家，20年前汽车更新换代没那么多，车载CD非常普及，很多车型还有能够插接MP3设备的接口。

当时网上最火的是MP3音乐分享的网站，很多人可以做为方便地下载自己喜欢的音乐，这样就产生了自己刻录CD放在车上听的迎需求。

而这种需求那些软件巨头是无视的，于是有家公司依靠把MP3刻录成CD这项技术，每个月稳定地赚到几千万美元。

现在，他们每年能在欧美市场卖出PDF、视频编辑软件，能有一个十亿的利润。
