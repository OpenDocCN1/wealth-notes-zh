# 做事情要有闭环思维

节选自“主题 Mike”的主题

![](bbox=[0.06, 0.64, 0.14, 0.7])

闭环思维就是：搜集、学习、内化、输出、体系化、实践、再优化的过程。

在如今的社交大竞争下，只有把每一件从进的小事彻底做到“闭环思考者”才有可能获得收益。

更重要的是，只有小事的闭环，才有可能去成就大事的闭环。

1件大事等于100件小事的和。

100万元人民币等于100个1万元人民币之积。
