# 产品开发的四个要点

节选自“范德福”的主题

+   1.  要有硬需求：产品能够有稳定收入。最关键的一条就是它有真实的社会需求；
2.  快速迭代：客户有需求，尽量用最低的成本、最快的速度，做出一个可感知的产品。因为客户在变，市场在变。
3.  人无我有：一个软件，一定要有几个其他软件没有的功能。
4.  降低门槛：客户永远比你想象的谨慎，客户的习俗永远比你想象的要谨慎。让客户用你的产品代价低一点，那么产品被客户接受的可能性就会高一点。
