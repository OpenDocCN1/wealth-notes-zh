# 如何精准找到创业的
切入点と定位?

节选自“零叛”的主题

对于创业者来说，行业是杠杆，切入点和定位是支点。通过对行业，找准切入点と定位，就能定义创业成功与落败的兩個核心变量。
我翻統計复数超过3000多个项目，其中超过八成的项目落地发度不管怎样，主题原因都是“切入点定位找得不够精准。切入点と定位更能解决三个问题：核心用户是谁？核心用户的需求痛点是什么？在解决这个需求痛点上我的独特优势是什么？
