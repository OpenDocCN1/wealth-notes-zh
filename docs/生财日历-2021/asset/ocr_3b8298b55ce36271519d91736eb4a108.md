# 互联网赚到百万后的总结

节选自“说划大大”的主题

+   1. 互联网时代并不是比努力程度，而是对于趋势的选择；
2. 永远要保持对于学习的需求，互联网抓住的本质就是3天一 个小要求，3个月一个转变，不进则退；
3. 永远要要搞点ROI，如果投入小于产出，重置积累就是多；
4. 如果投入小于产出，并且你认为值得投入，那么千万不要停止，立马去全方位的放大；
5. 看看机会不要想资源，并且要去全方位ai in，一个人用心做系统和“帮系”，故事，及其完全想两件事。
