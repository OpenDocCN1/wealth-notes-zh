# 靠一篇软文为公司创造
1000万元利润后的五点经验

节选自“高智商”的主题

软文效果的上下限差距非常大，想要通过一篇软文挖掘巨大的价值，精准把握转化目标客户，还需要注意：

+   1. 提高线上线下连接的效率，首先准备一份自我介绍——我是谁？我能够提供什么？我要做什么？
2. 微信的情绪抵抗：加了好友之后，主动发自律介绍，然后去对方的朋友圈，转前几次的动态点个赞；
3. 当你引入你其实是有个机会的时候，评论一下这件事对多少人有利，越是多赢的局面，越可能是一个机会，反之，很可能就是一个陷阱；
4. 能力、资本、资源、受欢迎，你手里的牌越多，当遇到选择时，你的主动权就越大；
5. 成大事者不纠结，一旦决定，就全力以赴。
