# 赚钱三板斧：认知差异、品牌设计、合适渠道

节选自‘蔡叔’的主题

从消费行业来看，关于衣食住行的任何一个细分行业，市场规模都特别大，商业模式也高度成熟。想赚钱，一般都是遵循低买高卖的道理，投入产出容易计算出来。

尤其是今天！中国制造业和供应链管理无比强大，你想到的任何产品都能找到代工，这给我们提供了一个平台级的基础设施。我们现正在需要找到认知差，设计好品牌，并找到合适的渠道就有机会赚到钱。
