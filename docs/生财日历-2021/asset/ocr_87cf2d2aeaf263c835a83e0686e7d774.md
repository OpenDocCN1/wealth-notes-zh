# 一年时间从0到1000万粉的短视频定位建议

节选自“潇潇”的主题

+   1. 根据期望的工作、产品类型、生活需要选择让你觉得舒服而不是你自己征服，别老想着去做自己的兴趣爱好，期待做着做着就变大了。通常，做着做着你就放弃了，还开始讨厌自己的爱好。

3. 通过作品内容控制人群：24岁以上女性越多越好，17岁以下的未成年人越少越好。
