# 豆瓣引流的方法

节选自“李土豆”的主题

+   1. 豆瓣小组：
在豆瓣小组上引流有两种模式：在别人建立的小组引流，以及自己建立小组。

+   2. 日记引流：
每周在豆瓣上发2-3篇内容，文章内容以下拉群和获取文章中提到资料的方式来置引钩子。尽量不要太显眼勾子，或者以字母ID按照的方式来操作。

+   3. 活动广场引流：
利用两个豆瓣账号一问一答引流，用豆瓣用户感兴趣的包信号图引流。
