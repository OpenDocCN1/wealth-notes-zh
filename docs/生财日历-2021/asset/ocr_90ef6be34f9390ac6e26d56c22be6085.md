# 互联网产品的投入和价值并不成正比

节选自“一备枸杞”的主题

在当互联网上的产品，技术成本趋高，不代表产品价值就高。
有些一闪而过的小想法，本身就已经成为一个人让自己的生活更美好的产品，轻盈或实现出来即可，如果没能够实现也就轻易放下了。
很多需求都是一个微信群或一个EXCEL表格又轻就能解决的。
为了一个小需求就投入大的物力，往往得不偿失。
