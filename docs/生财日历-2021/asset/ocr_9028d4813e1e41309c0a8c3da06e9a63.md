# 何为人处事之道？

节选自“脑科”的主题

有效意：咨询问题时，先发个红包或直接地分享收获与资源，并提出问题；咨询介绍资源，这样问题才引起反感。

有边界：有些话不该说，面对强者不躺贴，面对弱者不戳穿。

有心意：合作结束后给对方送礼物，心里胜于言语。

有重来：做事当断不断反受其乱，很多时候优先级需要以大体为重。
