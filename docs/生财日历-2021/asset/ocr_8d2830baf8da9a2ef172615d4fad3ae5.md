# 跟大公司打交道的五点经验

节选自“Jack”的主题

+   1. 这是一场博弈；在他博弈逻辑中，专业性是第一条要，如果不管专业，我们被压价，直到会丢单；

+   2. 千万不放松；没必要听对抗，一切都从专业角度出发即可，有理有据，不要不充；

+   3. 如果要跟项目中人，就一定要让他发挥好对接作用，有些事情让中间人去沟通协调；

+   4. 尽量让所有内容和模块化、流程化，拟定固定的SOP（标准操作服务），这样既提高效率，又能降低沟通成本，提高沟通效率；

+   5. 商业竞牌很关键，知己知彼，就算不能百战百胜，至少增加获胜的概率。
