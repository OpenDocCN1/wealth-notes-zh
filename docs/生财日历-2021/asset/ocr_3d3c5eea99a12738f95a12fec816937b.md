# 抖音短视频的新手注意事项

节选自“盗神”的主题

+   1. 选择一个一台手机能完成内容创作的项目，对视频质量要求别太高，不要有复杂的后期剪辑；
2. 要做离受众最近的事情，不要在剪辑炫富、点数量，只能注意别用多少；
3. 内容要垂直，只有垂直的粉丝才值钱，粉丝一定要精准，越精准的粉丝，转化率越高；
4. 避开红海区，发掘自身的价值点，做自己有行业的延伸，内容的价值要求更高；
5. 初期以最低的成本去尝试这个项目，成为后注MCN的方可发展，流水线包装复制。
