# 研究自己比研究项目重要

书选自“乔里奥”的主题

我们计划开启一个项目时，一定不要迷失在对项目的研究上而忽略了对研究自身情况。

事实上，研究项目和研究自己应该是并重的，甚至研究自己比研究项目更加重要。

拿短视频举例来说，相对于研究平台规则、研究视频模式、研究带货逻辑，更重要的是先研究什么视频适合自己去做。

找到一个自己能够低成本长期坚持做下去的方式，才是这件事能不能做成的关键，它的本质在于自身所用资源与成事所需资源的匹配程度。
