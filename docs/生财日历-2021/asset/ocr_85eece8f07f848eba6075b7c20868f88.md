# 电商免费流量的蓝海期

节选自“顾寻”的主题

流量分免费流量和付费流量，很多時候我们对付费流量没有优势，而免费流量则是绝大多数商家的短板，发现这一点后，我把自己包进了免费流量。

那么免费流量从侧跟来？与其思考这个问题，不如思考：“线上的同店在哪里？”这样思考下来，就会发现这个事情简单许多。像人最多的地方充于媒体平台：天涯、豆瓣、知乎、小红书、微博，这些都是现成的流量，而且都是完全免费的。

当然，几乎没有开发免费流量意识，就像深海里很多的宝藏，很多人看不见，有些人看见了也不知道如何去捞。
