# 如何通过折扣卡玩法从心理学上刺激用户消费？

节选自“饭”的主题

充值100元送1000元折扣卡刺激消费，用户会持续使用吗？

从消费者心理学和行為经济学来看：用户付100元买的卡，不用就会觉得“亏了”，这叫沉没成本；

成为会员，消费几次之后会适应价格，不觉得贵；这叫适应性锚定；

卡里的钱等于现金，得到只需100元，丢时要损失1000元，这叫损失回避心理。

所以我认为值得会持续使用。
