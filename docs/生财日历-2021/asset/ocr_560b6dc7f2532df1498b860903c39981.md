# 怎样才能快速在互联网上
赚到第一桶金？

书友君 “天涯” 的主题

其实无分写三点。

+   1. 选对项目；

不挑战小概率事件，只做有盈利的事情。不碰灰色项目和“热门项目”。永远追求增量，不在存量上厮杀。

+   2. 跟对人；

做项目的路上，不要耍智就是最快的捷径。最直接的方法是向已经拿到实践结果的人学习。

+   3. 进好圈子；

赚钱的圈子人人努力，一天到晚都在做完故事。

总结：选定场景，和同源、有结果的人在一起，“杀进去”拿
下一桶金。
