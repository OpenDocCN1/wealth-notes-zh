# 新手如何做好淘宝?

节目自“聂鲁达”的主题

+   1. 坚持学习平台提供的免费课程：淘宝大学、万堂书院做得好好学习，不管是新手还是大牛，学习都是持之以恒的道理；
2. 思考基础原理：我当初读李宇怀孕了淘宝直通车后台的动手操作建议、生意参谋”每一次小结、“生意参谋”中市场各项数据的变化；
3. 不断实践：不能拿出真金白银去操作，珍惜每一分花费。从添加计划，添加关键字，到修改时间折扣、定向调价、标品修改、直通车图制作，都是边学习边操作的。
