# 品牌IP化的点、线、面、体
书选题“付玉强”的主题

品牌IP化都是品牌成为流量入口的过程，分为四个层面：
1.点，是品牌核心识别，是最美占比位；
2.线，是传播链和用户互动，包括定位，信任状；
3.面，是通过用户体验路径的全触点管理，完成持续的宣传运营动作；
4.体，是前面的交错融合，相互着力而又各司其职，合力抢占目标市场。
