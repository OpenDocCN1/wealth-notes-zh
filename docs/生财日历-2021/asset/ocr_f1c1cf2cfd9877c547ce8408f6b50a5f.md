# 如何用软件的邀请功能获得
稳定的被动收入？

书选自“游园”的主题

很多软件都有邀请好友的功能，我们的目的就是找到一个邀请好友稳定，且能给钱激励的产品：

然后运营一个公众号号，名字要扣定这个产品有一定的关联度，利用微信的自然搜索流量来排名公众号号，用一些自动发优质文章的运营工具，每天发文章吸粉；

接着配置公众号的文章挂件，名字取得吸引人一些（比如领取微信免费券）；

再配置上自己的邀请图，等着被动流量上门即可。
