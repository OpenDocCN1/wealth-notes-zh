# 直接“找”产品，绝不碰研发

节选自 “天堂地狱” 的主题

小公司产品的核心是低成本，因为成本的原因，我会直接“找”产品，绝对不碰研发，根据我自己的项目壁垒，我为“我”产品定义了几个标签，用这些标签来定位好好的产品，然后找到它拿到它。

+   1. 产品标准化，天猫+大公司，用户针对性强，潮流类产品、传统产品互联网化、天使产品等。
2. 个人理解：定义产品标签的基础逻辑开竞争。
