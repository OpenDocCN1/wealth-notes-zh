# 如何通过线下获客
及信息差获利1.5万元以上?

节选自“三十一”的主题

起初我意识到办公室停车场很堵，不过内部有一些免费停车的福利，只要达到标准就可以享受。
通过与办公室的管理部门多次沟通协调，我成功争取到了20个免费停车位的福利。
在此之后，我马上印发了一些“停车位租用”的广告名片，价格略低于办公室的直营停车费用，并询问办公楼附近的超市小店附近有没有意向继续停在这里的客户，向他们提出停车位的租用服务。
利用这个信息差，我在很短的时间里获取了15000元以上的利润。
