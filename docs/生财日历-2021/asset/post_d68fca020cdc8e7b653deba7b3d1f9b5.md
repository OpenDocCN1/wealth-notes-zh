# 精益创业请注意这六点
节选自“V先生”的主题

在做生意的过程中，不管是规划，还是实操，都是复盘。好在琢磨以下六条，都能抓住要点，不至于陷在海量的信息和琐碎的事务中。

- 1. 三差：卖什么，卖给谁，怎么卖；
- 2. STP（营销策略三要素）：细分市场，目标选择，品牌定位；
- 3. 营销“4P”：产品、价格、渠道、宣传；
- 4. SWOT（态势分析法）：外部机会和威胁，自身的优势与缺点；
- 5. PPM（项目规划矩阵）：明星，现金牛，问号，瘦狗；
- 6. 赚钱公式：销售额=流量×转化率×客单价×复购。
