# 创业要做好哪些心理准备？

节选自“鱼丸”的主题

+   1. 在遇到每一个问题后, 就反间自己: 能通过对比这个问题的解决
找到钱么?
2. 要敢创业, 要能从市场中干, 降低创业风险。
3. 最好从自己的需求中挖掘业务, 更轻盈上手, 同时时代红利,
有效利用互联网资源。
4. 主动宣传, 做了好事要留名, 主动出击展示自己。
5. 看到他人需要帮助时, 要带着其他他需要帮助的人能取
暖、一起做强。
