# 提升生财能力的方式

节选自“亦仁”的主题

+   1. 最重要的提升智慧自己想想什么，不要太在乎别人的想法；
2. 多参与/与人分享，让参与/回报形成正向循环；
3. 多到机会后，尽快实现产品化、自助化、规模化、矩阵化、团队化；
4. 要打造自己的产品，不要没有积累的事情，长期打磨，慢慢优化；
5. 达到一定临界点后，产品会释放出极大的能量；
6. 必须有自己的小圈子，大家才可以深入交流；
7. 保持足够的信息输入量，特别是一手信息，信息越多，越有价值；
8. 赚钱，得趁早。
