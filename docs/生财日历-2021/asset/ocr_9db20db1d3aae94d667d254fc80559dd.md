# 可赚钱可省钱的海淘知识

节选自“Albert”的主题

同一件商品在不同国家因为货币、关税、定价等因素存在价格差，加上关税和运费甚至比国内价格还低，买了可以自己用也可以卖给别人。

海外电商平台包括各国外亚马逊、ebay、deil、屈城、耐克、Vans、丝芙兰、梅西百货、ThinkPad、GPM、MyBag等，如何做到低价：

+   1. 仅买打折商品；
2. 信用卡返利；
3. 返利网站（如mrebatesme）上，大部分品牌素有10%-20%的返利；
4. 礼品卡：海外电商平台基本上都有礼品卡，通常可以5s-8折买到。小日用户中可以到“万能”的淘宝，搜索关键词“xxs礼品卡”，会稍微贵一点，仍然是划算。

这是一个信息差，目前还存在，并且还会长期存在。
