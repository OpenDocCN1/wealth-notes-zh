# 优质的训练营的核心本质是什么？

节选自 “知识巨量库”的主题

本质是通过训练营的运营服务把普通用户变成超级用户。

10000个普通用户不如100个超级用户，超级用户指的是那些非常爱你、愿意为你付出、为你的传播的核心用户。

做训练营，不应该是用同样一份力气平均分给给所有的用户，而是要把更多的爱和介值关爱到你的超级用户，激励他们。
