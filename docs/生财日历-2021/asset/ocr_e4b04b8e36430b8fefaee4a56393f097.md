# 实体店如何通过微信在陌生城市做裂变营销？

书选自“骏马”的主题

+   1. 找到一个流量大的地方，如超市门口，通过送礼品，拉群子用户进群；

+   2. 设计海报，用免费产品引流到微信群，并目鼓励朋友进群也可以领；

+   3. 发送各类产品图片、海报图片、红包互动，用胖子用户进行群裂变；

+   4. 统一鼓励微信朋友圈内用户领产品，拍摄领取的视原及图片，不间断群内发送，继续裂变；

+   5. 客户领取产品时积极营销，使客户以低于市场的价格，付钱购买更多数量的产品。
