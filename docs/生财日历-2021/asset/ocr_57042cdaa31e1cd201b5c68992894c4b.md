# 进步源于认识到自己不行

节选自“亦仁”的主题

能够认识到自己不行，跟赚钱这件事一样，越早越好。

最好是少年时候，就连身上发生一些求而不得、反复求而不得的事情。尽快认识到自己能力其实有限，接下来的人生会幸福很多。

最怕是人到中晚年，才慢而深刻地承认现实——“哼呀，我真的很没有用，那时候已经很痛苦了。绝大多数上述的人，基本都会在某一个点上，认识到自己不行，没啥不好意思的。”
