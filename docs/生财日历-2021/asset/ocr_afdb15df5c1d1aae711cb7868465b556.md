# 五个销售思维和技巧

节选自“销售一”的土壤

2. 同一件事，不同位置的人、难易度是不一样的。所以办事要找更高层的人；
3. “人”和“利”这两者越深层次的关系线和难度，没着这两条线出发去分析，推出的答案永远不会错人；
4. 销售必须要会包装自己或“伪装”自己，让自己看起来像个“成功人士”；
5. 真正优秀的销售是要去找划、去创造。
