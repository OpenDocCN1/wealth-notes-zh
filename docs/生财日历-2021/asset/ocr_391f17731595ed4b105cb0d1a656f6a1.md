# 做好线下门店（托班）的六个建议

节选自《芥仁》的主题

+   1. 尽可能做到鸿蒙最丰而不单单只做门店生意；
2. 要有变观价格，能一季多吃或者做复购；
3. 沉淀客户，成为做微好友，相应地要经常发朋友圈；
4. 设定仪式感，让客户有可以传播的内容；
5. 引流成本可能远高于预估，要写内容得较大降低引流转化成本；
6. 安全是最重要的，家长最关心这个，任何一起安全事故可能会毁掉几年的苦心经营。
