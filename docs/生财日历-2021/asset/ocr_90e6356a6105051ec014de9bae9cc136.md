# 普通人启动项目要从 “赚钱的事儿” 做起

书选自“秦成”的主题

对于普通人来说，初期的启动项目尽量选择“赚钱的事儿”，而不是“值钱的事儿”。这两者的区别在于，赚钱的事儿，核心是基于利益，现金现结，将本保利；值钱的事儿，核心是结构价值，它的兑现时间在未来的某个时间点。
大多数人创业起点低，资源少，创业的主要目标应是赚钱改善生活；融资估值匹配起点高的大V，毕竟他们的机会成本高，不满足于赚小钱。
