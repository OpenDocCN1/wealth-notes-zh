# 公司员工超过20人是一道坎

书选自“AVI游戏”的主题

可以关注这个阶段是最低谷的，因为团队管理的很多方面要进行巨大转变，才能完全进入生新的阶段。如果没有注意到即将面临的 变化与挑战，就会出现问题。
