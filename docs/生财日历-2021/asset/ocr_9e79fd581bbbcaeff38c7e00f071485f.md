# 如何找核心用户？

节选自“黎叔”的主题

核心用户中的“核心”，是以自己为核心，而不是以产品为核心。如果愿意加入创业，尤其是以赚钱为目的的创业，核心用户一定要从自己的朋友圈中找，千万不要脱离自己的朋友圈，不要做无源之水，无本之木。

你的朋友圈就是你的创业池，在这里面临生意的成功概率更高。想去别人家的池子里做生意，其难度之高非他人所能及。
