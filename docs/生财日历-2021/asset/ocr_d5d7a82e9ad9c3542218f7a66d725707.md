# ### 如何通过VideoScribe制作原创视频赚钱

节选自 “蜗牛君”的主题

视频号需要大量原创视频，VideoScribe里有很多卡通动画，
但制作原创视频相对比较简单。主要需要写好脚本，然后按照
本册加图片，合成动画。内容可以涵盖：思维提升、生活感悟相关、
各个垂直领域的视频等。

如何赚钱？

+   1. 视频号+公众号导流广告；
2. 视频号+公众号带货；
3. 给公众号导流；
4. 视频教学培训；
5. 卖号。
