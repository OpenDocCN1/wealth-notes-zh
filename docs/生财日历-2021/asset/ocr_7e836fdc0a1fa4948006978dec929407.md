# ### 营销推广底层逻辑
节选自 “02男孩” 的主题

互联网上任何目的营销推广，底层逻辑都是一样的：
找到目标群体→用产品或服务引起他们的兴趣→建立信任关系→转化/成交。
用专业术语来讲就是，曝光→点击→交互→成交。
这是一个漏斗营销模型，所有的互联网营销推广都是围绕这个公式去不断验证和优化的。
