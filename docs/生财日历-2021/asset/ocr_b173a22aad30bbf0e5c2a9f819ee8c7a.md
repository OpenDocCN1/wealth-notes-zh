# 我本人定义的流量红利要符合以下几点

书源自“刘大谢”的主意

+   1. 产品本身够独立正确、好用，且同时BAT（百度、阿里、百度、腾讯）级别平台有重大战略意义的功能或产品，且产品、公司从流量端给予开放；
2. 主流世界、主流人群认可；
3. 可以结合出切实有效的商业模式，单纯的平台型政经论说起来根多，但只能存在于“讲神的道理”，真落去起来没几个人能真正长期获取收益。
