# 如何给社群起名字？
节选自“光合”的主题

好的名字真能体现几个特点：让用户有熟悉感、有画面感、有感染力，能让用户一听就懂，还能帮他召唤关系。同时也要避免有生僻字，拼鲁或不让人容易理解的关键词。
具体可以用“说给别人听”这个方法测试起名字的好坏。最重要的是，要用文本思维查看待创造问题。创意不是玄之又玄，是用求裸低容辩传播成本的，起名字也是这样。
