# 如何真诚地介绍自己？

节选自“百川”的主题

核心是“期待+价值观：真诚的态度”

+   1. 强烈推荐使用文字介绍，方便他人熟悉自己；
2. 把自己的个人介绍浓缩到几句话里说明清楚；
3. 选好玩的地方写，让对方阅读更有趣；
4. 思考一下你对接的这个人，你给他/她讲什么？或者你自己前端做的，哪些能直接展示你的价值；
5. 真诚很重要，我每次介绍自己从来不想过能从别人身上得到什么，只是觉得他/她很优秀。
