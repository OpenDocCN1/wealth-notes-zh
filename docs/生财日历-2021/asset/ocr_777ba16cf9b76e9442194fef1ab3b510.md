# 如何知道一家奶茶店
能不能赚钱？

节选自“杨芳”的主题

+   1. 去盘点；
2. 算叫号牌：一天能叫多少个头号；
3. 算叫号平均消费多少杯；
4. 这个店面约几平方米，租金多少，每次前台和后厨多少人，几位；
5. 加上你知道的所有包料的成本，再加上一个10%的“安全溢
出”。
话：
这样之后，你大模就能算出来它是否赚钱还是写亏。
