# 活多少钱只有死工资怎么办？

节选信 “亦仁” 的主题

1. 认识到 “所有的问题都是自己的问题”；

2. 想学习什么新技能，关键是要工作之外投入的时间，而非工作时间；

3. 成年之后，任何人的评价都不重要，重要的是你自己想要什么、想过什么样生活，并为此付出什么努力；

4. 再基础的岗位工作，都可以学到东西，如果遇到瓶颈，就及以上走；

5. 公司不满要没有任何经验，且看不到主动性的人；

6. 能力不够之前，不要轻易辞职。
