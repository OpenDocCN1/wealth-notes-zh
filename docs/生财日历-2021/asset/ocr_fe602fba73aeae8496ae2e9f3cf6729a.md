# 给兼职做电商创业的几个点建议

节选自“裴志”的主题：

+   1. 保证时间、精力，并且找到靠谱的合规合伙人；
2. 转变学习，研究规则，舍得花钱去学；
3. 重视选品，起步阶段求稳、做细小类目；
4. 学会总结，把事物流程化；
5. 懂得积累资源，建立门槛。比如积累拍照的资源、模特资源、制作详情页工作室的资源、美素秀的资源、供应商的资源等。
