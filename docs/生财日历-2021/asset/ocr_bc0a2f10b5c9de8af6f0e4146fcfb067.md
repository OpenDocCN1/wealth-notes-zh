# 团队每天写复盘的规则

节选自“办厂”的主题

+   1. 为了保证能将长周期目标参必得改单，每天三条问问；
2. 当日得失、收获或踩坑记录尽量抽象，形成方法论；
3. 团队成员互相打分，当日得分最低的，重新写复盘；
4. 每天限定时间把复盘发出，没完成者有惩罚；
5. 每月做一次总结，奖惩得分最高者、惩罚得分最低者。
