# ## 如何抓住服务业的大机会？
节选自“副机智”的主题

以30年为期看中国社会发展，改革开放后是商品生产的30年，未来30年要提倡起服务文化的输出。
在商品和文化的之间，有最后的30年黄金发展周期，本质是商品丰富。
供大于求后，提高用户的服务体验是机会。而服务产业中，服务人员群体未不是最核心、最主要的效率和机会：
1. 则提高服务人员的工作提高效率，降低成本、隐入服务中；
2. 从业人员的职业培训、婚恋、小孩上学、老人养老等。
