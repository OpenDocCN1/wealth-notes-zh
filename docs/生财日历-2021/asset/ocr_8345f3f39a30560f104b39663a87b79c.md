# 近几年做亚马逊还有机会吗？

节选自“seven”的主题

+   1. **绝对有机会**：新手依然可以入局，只是“门槛”变高了，最好有产品选得好、避免踩坑和走很多弯路。行业内的入局者，请多多交流。
2. **一边上班，一边做副业**：借助朋友的账号、仓库等资源，基本可以做到零成本起步，就算做亚马逊不成功，也还有退路。一个产品开发做到了以后用考虑全局。
3. **不一定非要做亚马逊**：不同的经历着拥有不同的资源，有适合自己做不同赛道。比如投入很少比如好物，投入1万元以内的合购SEO与Niche网站联盟营销；投入1万—2万元的淘宝直播带货打法等。用时间去做链接，完成原始积累后，要思考如何提效率并去创造财富，走一条有长线价值、有复利的路。
