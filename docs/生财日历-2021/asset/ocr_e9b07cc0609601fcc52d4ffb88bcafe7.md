# 如何分析一个互联网项目的可行性？
节选自“战功不大”的主题

+   1.  看起来是否合法正规，不碰灰色项目；
2.  不能不能长期操作，至少是半年或者一年以上；
3.  做项目的过程中能否为下一个项目积累资源或者人脉；
4.  尽量选择大平台；
5.  看是否是市场需求；
6.  看公司背景、创始人背景和实力，投资方及融资情况；
7.  看能否适合自己，人脉、兴趣、直觉缺一不可；
8.  最重要的，看看这个项目到底有没有真正地方消费者着数。
