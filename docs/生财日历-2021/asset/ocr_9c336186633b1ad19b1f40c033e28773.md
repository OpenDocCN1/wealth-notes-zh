# 如何让一份流量反复成交？

节选自 “沉小管” 的主题

+   1. 向用户展现的东西是要足够好，要超出他们的预期，一般般的东西没有复购；
2. 要让用户的的产品体系是重复成交，即你是告诉他也要做复购，提供的服务让老客户服务想要比你新客；
3. 解决痛点的同时也要会包装；
4. 要做用户分层，表示强化；
5. 优先考虑老用户复购，你的用户内频次致越多，信任越强。
