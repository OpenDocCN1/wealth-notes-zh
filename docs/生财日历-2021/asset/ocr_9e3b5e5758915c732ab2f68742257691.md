# 5年收入翻50倍的投资人
给出的四个创业感触

节选自“张琦学”的主题

+   1. 方向比努力重要：从一开始就要对自己有一个清晰的定位；
2. 信心比能力重要：当我真的不服苦难不断尝试后，许多难题也真的找到了解决方案；
3. 迭代比规划重要：产品经历思考与解决问题的模型，包括发现问题、分析需求、提出方案、试验验证、收集反馈、不断改进；
4. 成长比天赋重要：优秀的创业者往往是激进型人格，即相信一切范畴的东西都可以不断学习和训练来优化，知识盲区可以补，性格缺点可以改，一切皆可被塑造。
