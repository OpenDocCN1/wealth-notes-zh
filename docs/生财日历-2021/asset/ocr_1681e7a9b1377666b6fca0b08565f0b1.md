# 如何了解用户的真实想法?

节选自 “明白”的主题

产品一定是给人的用，所以，我们需要了解用户的真实想法:

+   1.  用户想要什么功能？

+   2.  用来做什么事情?

+   3.  他们现在是怎么解决这个问题的?

+   4.  他们是否愿意付费?(先谈在差，完成产品雏形)

+   5.  能不能作为种子用户、邀请来做方案?

这些事情, 我们都可以进市场分折阶段、在开发产品之前、全部搞清楚。
