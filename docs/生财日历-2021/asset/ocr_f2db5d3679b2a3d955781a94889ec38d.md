# 如何做到同行里的最好？

节选自 “杨清”的主题

我们都知道，开 bodies 体就是个非常细致的活儿，尤其会涉及送包装材料，必须细细到包装箱上的每一个文字或图案。

那怎样才能做到最好呢？

你可以买下所有同行的产品，看他们的包装细节，包括拆开箱体逐中，同行是怎么操作的，先取他们的优点，再做到比同行更好。最终做到：别人没有的我有，别人有的我做做得更好，别人优秀的我做到四决的水平。
