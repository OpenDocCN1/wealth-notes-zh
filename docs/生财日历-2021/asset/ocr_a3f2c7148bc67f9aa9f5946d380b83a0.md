# 使用众筹来启动项目的好处
有哪些？

节选自 “Jack” 的主题

可以用于自己完善想法、验证市场、接触新客户、零风险生

产、获得种子用户、启动口碑营销（或直播带货），甚至能获得融资的

机会。

从想法到落地的整个过程都不会涉及过大的风险和投入，完美

地展示了精益创业的本质。

众筹无法唯一的准点。在于对于产品的需求比较高，要给用

户足够的惊喜感、信任感和参与感，使对方成为你的倡导者。

另外，众筹也不只限于 “从零到一启动项目”，很多人还把众

筹当做产品的平台。对于大品牌而言，众筹转化率不如电商直接

买，大品牌做的是曝光和造势，顺带赚钱。
