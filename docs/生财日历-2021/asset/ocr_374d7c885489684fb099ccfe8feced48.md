# ## 如何在淘宝快速找到不同行业的风格店铺?

书选自“Seven7”的主题

+   1. 寻找冷门产品蓝海：挖掘在淘宝首页创意推荐产品，通过首页推荐找到这些产品以及店铺，并复制到笔记本；
2. 采集到风格独特的店铺后直接搜索该店铺，通过“查找相似店铺”的功能“裂变”。同类型店铺，再用其他店铺继续“裂变”。
关注信源分只有几个站，店铺单品只有几百销量率的店铺，这类店铺的款式极具潜力。
