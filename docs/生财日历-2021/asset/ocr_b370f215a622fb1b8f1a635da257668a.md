# 如何分析赚钱规律?

节选自“明白”的主题

同样一件事，有人能做到需求做产品，获取流量赢得收益，原因是为一个“赚钱思维导图”，遇到任何案例都会分析四点规律:

+   1. 需求: 什么类型的客户能赚? 为什么?
2. 流量: 获取流量的方式有哪些? 为什么?
3. 营销: 如何营销产品，促进容易卖出? 为什么?
4. 变现: 不同类型的产品该如何赚钱? 为什么?
