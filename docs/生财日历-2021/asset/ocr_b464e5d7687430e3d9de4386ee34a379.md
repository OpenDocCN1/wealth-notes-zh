# ### 如何深入研究行业？

书卷目 "一袋知己" 的主题

广告行业的何丽收到了一个电器行业调研的任务，经验丰富的她，没有去搜索引擎上搜"电饭煲"，而是直接在打开东搜"电饭煲"，品牌、型号产品、主要参数，一目了然。品牌调研往后，她又进入了各个产品的详情页，关注了各大体的几个营销痛点以及使用场景。各个品牌主打的几个营销痛点以及使用场景。这花多少时间，就搞定了大量的资料。
