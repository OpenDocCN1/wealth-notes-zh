# 为什么用“卖人”思维做微商？

节选自“云帆”的主题

“卖人”的生意本质就是卖服务，有两大优势：

+   1. 认知成本低。如果你听过一个人的分享，你就对他专业，你
可能就找回合作了。细微的差别在于认知流程缩短，认知成本降
低。
2. 营销资源聚集。投广比一定是高。所有的营销资源全部投入在
一个点上，投入产出比是最高的。
