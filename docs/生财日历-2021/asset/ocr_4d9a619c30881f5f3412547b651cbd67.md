# 普通人在赚钱方面的四个痛点

节选自 “光合” 的主题

一是没有认知：自己活在信息房里。如果连认知都没有，谈谈赚钱呢？

二是没有方法：这里包含两层含义，一个是没有认知导致的方法没有，没有认知譬如只知道去抄方法，就在自己的圈子来回滚；另一个是自己掌握的技能太方法太多了，行业里圈子太多，普通人不知道怎么分析和选择，也不知道自己适合哪个。

三是没有行动：很多人有认知，也懂痛点也抄了方法，但是就是不行动。没有行动，一切都没意义。这点我就差不多说了，包括我自己也算是 “一日空指数”。

四是没有资源：作为普通人，当然没资源。没资源很正常，关键真不知道怎么找资源，甚至不知道自己需要什么资源。
