# ### 春来人的几点创业经验分享

节选自“鱼丸”的主题

+   1. 公司的使命一定要明确；
2. 创始人(核心意见领袖）的力度可快速实现品牌宣传；
3. 优质内容是增长引爆器，要创作有复利价值的内容；
4. 要有长期思维的意识，提前做好风险抵御策略；
5. 从更长远的角度帮助员工成长；
6. 标准化流程可以极大地提升工作效率；
7. 学会赞美别人；
8. 要比竞争对手做更多的工作。
