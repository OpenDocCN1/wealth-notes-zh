# 如何选择 一个靠谱的副业？

节选自 “哇哈哈”的主题

+   1. 副业要跟主谋考密，考核的重点是单位时间收益；
2. 副业须具备可持续发展性；
3. 珍惜同事，选出有核心竞争力产品，真正帮助客户而不是消耗人品；
4. 务必考察清楚公司、投资方、团队长等是否靠谱。
5. 空杯心态：当你真的想做一件事，先把自己旧有的观念扔扔，也许就是它阻碍了你获得收益；
6. 赚钱的路径是真的很创新，找到平台，跟对强干牛人，“坚韧 + 勤奋”，起来！
