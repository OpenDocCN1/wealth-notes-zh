# 怎么找到“天赋”？

节选自“龙东平”的主题

一定要确保自己擅长的内容，这样才能够持续和长久。梁宁老师说过：“什么事情让你没进不挠，什么事情让你特别满意，这就是你的命的所在；能让你不开心其闲去做的事，就是你的天赋所在。”
怎么找到天赋？首先看你对什么事情感兴趣；其次，看你在做什么事情让你做做的时候，是不是就让你就停滞了；最后，看你是否会不讨厌就也做，可能还乐着“猪开快乐看”的感觉。
