# 互联网赚钱利器——信息差

节选自“天风”的主题

很多人都说，很嫌通过互联网赚到钱，那么也不知道如何切入。其实，一般来说，在互联网上你只要能找到信息差，并满足一方需求，你就可以大单赚到账。相对于还是比较容易的。

比如，研究一个具有同一关键同的群体；挖掘这个关键词群体的需求，然后写一篇相关的公众号文章，或者开一个淘宝店铺，或者拍一个抖音、快手视频，如果能满足这个群体的需求，那么赚钱就不会很难。需要主意的是，次级产业千千万不能触碰。
