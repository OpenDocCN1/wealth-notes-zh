# 自己说自己好不算好，
别人说你好才是真的好

节选自“仲老柏”的主题

东汉名医董奉可能是历史上少有能会害到自己的人之一。董奉年
轻的时候做过官，行医只重业余爱好，所以董奉从不收费，只让治
愈的人在自己家门前种橘百棵，时间长了就成了一片小杏林。
杏林结果了，他也不卖钱，让人拿粮食来换，并在路边设立粥
铺，免费提供路过的患者喝粥。

董奉没有任回的医考学写留下来，却位列中国古代十大名医，还
留下个典故、杏林春暖。
