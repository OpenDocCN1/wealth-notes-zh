# 拆解张勇在湖畔分享的《领导者如何“落子无悔”》
节选自“自一遍”的主题

+   1. 一上来就感叹平台，基本做不成，不管是吃透行业，还是最终独到核心行业，都需要打开你的核心能力；
2. 做CEO（高频执行型）是需要基于对水位的认知水军；
3. 战略最大方向，是必须让CEO来把控的，要有原则和“我不做 什么，边界；
4. 笃信隐忍的主意不长久之，因为门槛太低；
5. 不确信 隐忍常态；
6. 面对成功，要正确地归因；面对失败，要冷静无情地修正决策逻辑，做等过程；
7. 领导者和CEO没有说“我不知道”的权利。当手下的人都不能解决问题的时侯，你要责顶上。那个时侯，谈“CEO不该插手业务细节”没有任何意义。
