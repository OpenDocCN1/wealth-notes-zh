# 企业入驻抖音时要注意的几点

节选自“短鱼儿 Parke”的主题

首先要明确是做品牌发声渠道还是效果营销渠道，如果是前者，可以做品牌自己的账号，粉丝可以尽量触达；后者的效果和曝光都比公众号好。

但如果企业只是利用流量赚钱，那么只需要考虑ROI，重在选择KOL和营销渠道。

如果自家品牌做网红孵化，还要注意：

+   1、资产不稳定性，KOL的管理履约问题；
2、自己不是流量主的内地方，容易在内容调性上失去定力，自己生产内容为自己导流，团队的积极性将不是特别高；
3、网红流量和品牌价值是两回事，时效强避免网红带来的流量不能转化。
