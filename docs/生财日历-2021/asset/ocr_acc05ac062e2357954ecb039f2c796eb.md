# 怎样写出神级文案？

节选自“白一喵”的主题

+   1. 使用受众熟悉的、有感觉的、能在脑子里产生联想的、形成画面的字眼；
2. 使用原意熟悉的名词和数字；
3. 让表达的主题，是原答案中的“自己”。

把潜在顾客时刻放在心上，站在他们的视角去读自己写的每一句话。反复读读自己写的东西，读出声来。

想想：关键句能不能为原顾客所熟悉？关键句是不是原顾客所熟悉的？能不能让他们代入，形成自我投射？
