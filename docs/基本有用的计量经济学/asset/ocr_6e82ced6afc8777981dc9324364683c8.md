# 第四节 总 结

总体回归函数和条件期望函数有着密切的联系。如果条件期望函数是线性的，两者完全一致(定理 5.1)。如果条件期望是非线性的，回归函数是对条件期望函数(均方误差最小意义上)的最优线性近似(定理 5.2)。如果条件期望函数有因果效应的解释，回归函数就有因果效应的解释。如果满足条件独立性假设或条件均值独立性假设，回归系数可以解释为总体的平均因果效应。在回归分析中，引入控制变量的目的就是希望能够使条件(均值)独立性假设成立。
