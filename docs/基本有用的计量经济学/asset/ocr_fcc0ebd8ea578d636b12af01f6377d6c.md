其中 π₁₀、π₁₁ 是对方程(7.6)进行 OLS 估计得到的回归系数，根据上述样本回归方程得到 Dᵢ 的拟合值 D̂ᵢ，并用 D̂ᵢ 替代结构式(7.8)中的 Dᵢ 进行第二阶段的回归，即：

Yᵢ = Xᵢ′α + τ D̂ᵢ + [ηᵢ + τ(Dᵢ − D̂ᵢ)]  (7.13)

因为

Cov(D̂ᵢ, ηᵢ + τ(Dᵢ − D̂ᵢ)) = Cov(D̂ᵢ, ηᵢ) + τ Cov(D̂ᵢ, Dᵢ − D̂ᵢ) = 0

所以，第二阶段回归(7.13)可以得到 τ 的一致估计，其中第一项 D̂ᵢ 是 Xᵢ 和 Zᵢ 的线性组合，由工具变量的外生性条件(7.3)，第一项为零；第二项 Dᵢ−D̂ᵢ 是第一阶段(7.6)的回归残差，根据回归系数的性质(5.9)，回归残差与解释变量 Xᵢ、Zᵢ 是正交的，D̂ᵢ 是 Xᵢ 和 Zᵢ 的线性组合，因而，回归残差 Dᵢ−D̂ᵢ 也与 D̂ᵢ 是正交的，从而第二项也为零。对(7.13)回归得到的估计量称为两阶段最小二乘估计量，但要注意一点，直接对(7.13)进行回归，得到的标准误差是不正确的，因为直接回归得到的残差是 ηᵢ + τ(Dᵢ−D̂ᵢ)，而不是 ηᵢ，正确的方法是利用两阶段回归估计量计算出正确的残差：

η̂ᵢ = Yᵢ − Xᵢ′α̂₂sls − τ̂₂sls Dᵢ  (7.14)

并利用其估计正确的标准误差。当然，很多软件中均有相关的命令进行处理，比如在 Stata 软件中，ivregress 命令就可以直接进行两阶段最小二乘法的估计，并且得到的标准误差是调整后的正确标准误差。很容易证明两阶段回归估计量是工具变量估计量，观察第二阶段回归(7.13)，利用(5.10)可以将两阶段回归估计量写为：

τ̂₂sls = Cov(Yᵢ, D̃ᵢ) / Var(D̃ᵢ)  (7.15)

其中 D̃ᵢ 是 D̂ᵢ 对 Xᵢ 的回归残差。因为

Cov(Dᵢ, D̃ᵢ) = Cov(D̂ᵢ + (Dᵢ − D̂ᵢ), D̃ᵢ)
= Cov(D̂ᵢ, D̃ᵢ) + Cov(Dᵢ − D̂ᵢ, D̃ᵢ)

其中第二项中 Dᵢ−D̂ᵢ 是第一阶段回归(7.6)的回归残差，根据回归性质(5.9)，回归残差 Dᵢ−D̂ᵢ 与 D̂ᵢ( D̂ᵢ 是 Xᵢ 和 Zᵢ 的线性组合)不相关。而 D̂ᵢ = D̃ᵢ + ( D̂ᵢ − D̃ᵢ )，即 D̃ᵢ 是 D̂ᵢ 的一部分，因而，回归残差 D̂ᵢ−D̂ᵢ 也与 D̃ᵢ 不相关，从而上式第二项为零。则

Cov(Dᵢ, D̃ᵢ) = Cov(D̂ᵢ, D̃ᵢ) = Cov(( D̂ᵢ − D̃ᵢ ) + D̃ᵢ, D̃ᵢ)
