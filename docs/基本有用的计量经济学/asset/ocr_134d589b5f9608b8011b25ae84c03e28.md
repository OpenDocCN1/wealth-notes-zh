V̂_neyman = s_c^2 / N_c + s_t^2 / N_t (3.8)

其中， s_c^2 = 1/(N_c - 1) Σ_{i:D_i=0}^{N_c} (Y_i - Ȳ_c)^2,   s_t^2 = 1/(N_t - 1) Σ_{i:D_i=1}^{N_t} (Y_i - Ȳ_t)^2

因而，如果数据来自于完全随机化实验，因果效果的估计非常简单，干预组和控制组观测结果之差 τ^dif 即是平均因果效果的无偏估计。当然，也可以 días 使用线性回归分析。上一章我们已经证明（参见（2.26）式），观测结果 Y_i 对干预变量 D_i 的简单回归系数 τ^ols 实际上等于两组观测结果平均值之差 τ^dif。因而，对于完全随机化实验数据，我们可以采用简单线性回归方法，回归系数 τ^ols 将是总体平均因果效应 τ_ATE 的无偏估计量。

在线性回归分析中通常施加一个关键假设，零条件均值假设或正确模型设定假设（洪永森，2011），要求以解释变量为条件，误差项的条件期望值为零，即 E[ε_i | D_i]=0。在应用中，这一假设无法检验，也无法保证，但是在随机化实验中，这一条件可以得到保证。下面进行简单推导以证明这一点。

首先，观测结果 Y_i 可以用潜在结果和干预变量表示，即 Y_i = D_i Y_{1i} + (1 - D_i) Y_{0i} = Y_{0i} + (Y_{1i} - Y_{0i}) D_i = α + τ_ATE D_i + ε_i (3.9) 其中 α = E[Y_{0i}], ε_i = Y_{0i} - α + D_i (Y_{1i} - Y_{0i} - τ_ATE)。注意，误差项可以写成： ε_i = { Y_i - α   如果 D_i = 0 ; Y_i - α - τ_ATE   如果 D_i = 1 } (3.10) 则 E[ε_i | D_i = 0] = E[Y_i - α | D_i = 0] = E[Y_{0i} | D_i = 0] - α = 0 E[ε_i | D_i = 1] = E[Y_i - α - τ_ATE | D_i = 1] = E[Y_{1i} | D_i = 1] - α - τ_ATE = 0 上面两式的推导均运用了完全随机化实验的基本特征，干预分配独立于潜在结果，即（3.1）式。因而，在完全随机化实验中，回归方程（3.9）总是满足零条件期望假设 E[ε_i | D_i]=0。在完全随机化实验中，这一条件并不是假设，它的成立完全来自于分配机制的随机化。所以，对于来自于完全随机化实验的数据，完全可以利用线性回归进行分析，构造下列模型： Y_i = α + τ D_i + ε_i

得到的回归系数 τ^ols 就是平均因果效应参数 τ_ATE 的无偏估计。
