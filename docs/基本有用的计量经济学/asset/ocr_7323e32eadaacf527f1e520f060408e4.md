min_{a_l,b_l} sum_{i=1}^N (Y_i - a_l - b_l·(X_i - x_0))^2 · 1(x_0 - h ≤ X_i < x_0) (9.12)

和 min_{a_r,b_r} sum_{i=1}^N (Y_i - a_r - b_r·(X_i - x_0))^2 · 1(x_0 ≤ X_i ≤ x_0 + h) (9.13)

估计上述两个方程得到的拟合值为：
\hat{μ}^- (x_0) = \hat{a}_l + \hat{b}_l (x_0 - x_0) = \hat{a}_l
和
\hat{μ}^+ (x_0) = \hat{a}_l + \hat{b}_r (x_0 - x_0) = \hat{a}_r

从而得到在断点处的平均因果效应其实是两条局部线性回归曲线在断点处的截距之差，即
\hat{τ}^{SRD}_{ATE} = \hat{μ}^+ (x_0) - \hat{μ}^- (x_0) = \hat{a}_r - \hat{a}_l (9.14)

另外，也可以利用下面的回归方程得到断点处平均因果效应的直接估计 (Imbens and Lemieux, 2008)：
min_{a,b,τ,γ} sum_{i=1}^N 1(x_0 - h ≤ X_i ≤ x_0 + h) · (Y_i - a - b(X_i - x_0) - τ D_i - γ D_i (X_i - x_0))^2 (9.15)
