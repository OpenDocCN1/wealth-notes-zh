层。每层内进行完全随机化实验，用 $N_t(j)$ 表示 $j$ 层中接受干预个体的数量， $N(j)$ 表示 $j$ 层个体总数，则 $N_t(j)/N(j)$ 是 $j$ 层个体接受干预的可能性，也称为倾向指数（propensity score），不同组内倾向指数可以不同。$N = \sum_{j=1}^{J} N(j)$，干预组个体数为 $N_t = \sum_{j=1}^{J} N_t(j)$，控制组个体数为 $N_c = N - N_t$。总体平均因果效应可以表示为：

$\tau_{\mathrm{ATE}} = E[Y_{1i} - Y_{0i}]$
$= E[E[Y_{1i} - Y_{0i} \mid G_i]]$
$= \sum_{j=1}^{J} E[Y_{1i} - Y_{0i} \mid G_i = j] \Pr[G_i = j]$
$= \sum_{j=1}^{J} \tau_{\mathrm{ATE}}(j) \, p(j)$
其中，$\tau_{\mathrm{ATE}}(j)=E[Y_{1i}-Y_{0i} \mid G_i=j]$，$p(j)=\Pr[G_i=j]$。根据矩估计方法原理，可以用下列估计量估计总体平均因果效应：

$\hat{\tau}^{\text{strat}} = \sum_{j=1}^{J} \hat{\tau}(j) \cdot \frac{N(j)}{N}$ \tag{3.15}
其中 $\hat{\tau}(j)=\bar{Y}_t(j)-\bar{Y}_c(j)$，$j=1,\cdots,J$。可以证明：

$\hat{\tau}^{\text{strat}} \xrightarrow{p} \tau_{\mathrm{ATE}}$ \tag{3.16}
并且，

$\widehat{\mathrm{Var}(\hat{\tau}^{\text{strat}})} = \sum_{j=1}^{J} \left(\frac{N_j}{N}\right)^2 \cdot \mathrm{Var}(\hat{\tau}(j))，\quad \mathrm{Var}(\hat{\tau}(j)) = \frac{s_c^2(j)}{N_c(j)} + \frac{s_t^2(j)}{N_t(j)}$ \tag{3.17}
对于分层随机化实验产生的数据，也可以用回归分析方法进行分析，可以构建下列回归分析模型：

$Y_i = \tau D_i + \sum_{j=1}^{J} \beta_j \cdot \mathbb{1}(G_i = j) + \varepsilon_i$ \tag{3.18}
其中 $\mathbb{1}(\cdot)$ 为示性函数，条件成立取 1，不成立取 0，在上式中实际上是不同层的标识变量，如果个体 $i$ 属于 $j$ 层，则 $\mathbb{1}(G_i=j)$ 取值 1，相当于引入了 $J$ 个虚拟变量，代表不同的群组。上述回归实际上是一种饱和回归，在第五章中还会有详细介绍。不过回归方程(3.18)的回归系数 $\hat{\tau}^{\mathrm{ols}}$ 并不是总体平均因果效应 $\tau_{\mathrm{ATE}}$ 的一致估计，它实际上趋近于下列参数：
