# 附录

全期望公式(5.2)的一个证明。

E[Y_i | X_i] = E[E[Y_i | X_i, Z_i] | X_i]

证明 假设 Y、Z 为离散型随机变量，

E[E[Y | X = x, Z] | X = x]
= Σ_z E[Y | X = x, Z = z] · Pr[Z = z | X = x]
= Σ_z Σ_y y · Pr[Y = y | X = x, Z = z] · Pr[Z = z | X = x]
= Σ_z Σ_y y · Pr[Y = y, X = x, Z = z]/Pr[X = x, Z = z] · Pr[Z = z, X = x]/Pr[X = x]
= Σ_y Σ_z Pr[Y = y, X = x, Z = z]/Pr[X = x]
= Σ_y Pr[Y = y, X = x]/Pr[X = x]
= Σ_y y Pr[Y = y | X = x]
= E[Y | X = x]
