

# 普京胜利在望

251023  文/卢克文

整理：公众号懒人搜索，懒人专属群独享
懒人微信：lazyhelper

很久没有写星球了，助理说我身为公司老板，但老是不写星球，是在公司带头偷奸耍滑摸大鱼，天天上班只知道打炉石，要打断我的腿以警示全公司同事。

为了下半生不在轮椅上过日子，老头子我只能赶紧硬着脖子过来写星球。

最近特朗普和泽连斯基又开了个会，按《金融时报》报道，以及现场视频来看，双方谈得不太愉快，特朗普“始终在严厉训斥泽连斯基”，甚至将泽连斯基递过来的前线地图扔到一边，说自己“厌倦”反复查看地图，很不耐烦地说，“这条红线我根本不知道在哪里。”

特朗普引述普京的原话警告泽连斯基，说“如果普京下定决心，他会摧毁你”，并建议双方按当前战线“划界停火”。

他的理由甚至是，“本来这个地区（顿巴斯）就是俄罗斯人为主体”，把乌克兰团队听得一愣一愣的。

![](bbox=[58, 144, 823, 266])

我看了现场视频，泽连斯基会谈时，还说他们能生产大量无人机，美国现在有战斧导弹，两边刚好互补，可以用乌克兰无人机换美国战斧。听到这句话时，特朗普跟万斯忍不住抱着胸相视一笑，好像这句话十分滑稽，然后特朗普态度强硬地拒绝了泽连斯基的军援要求，战斧没有，其他武器也不给。

双方这几小时的谈话不太愉快，美乌双方不仅没有新闻发布会，特朗普还不允许泽连斯基单独在白宫草坪搞新闻发布会，泽连斯基被迫在白宫马路对面支了个小摊，以白宫为背景搞了个发布会。

在我印象中，这是俩人这一年第五次碰头，3月份白宫大吵一架，4月底教皇去世，两个人搬把椅子在梵蒂冈面对面争了半天，后来8月泽连斯基穿着西装再访白宫，双方气氛缓和了一些，欧洲七国领导人及北约秘书长护着泽连斯基一起谈，会后宣布将推动美俄乌三方领导人会晤。

然后，大家都知道了，特老头8月15日一个人去阿拉斯加见普京去了，没带欧洲人，也没带泽连斯基。

谈完后可把欧洲领导人急得，法德英欧话事人赶紧带着泽连斯基一起同访白宫，生怕美俄两边单独签了协议，特朗普只能在白宫当面安抚了一番。

8月这次特朗普和普京谈完后，应该在等普京这边给个回复啥的，战争也一直没停，每周俄乌双方大概有五千人战死在前线，特朗普候得老不耐烦，10月14日，特朗普在公开场合说，对普京没结束战争感到非常失望。

当天他也对媒体说，17号泽连斯基要过来访问，“我知道他想要什么，他想要武器，想要射程 2500 公里的战斧巡航导弹。”

到14号的时候，特朗普还挺心烦，一想到老基友普京就不开心，咋到17号泽连斯基来访，突然就当着世界媒体的面，这么不客气地叼人家呢？

新闻要连起来看，一连起来，逻辑就清楚了。

2025年10月16日，也就是特朗普发完牢骚的第二天，泽连斯基突然来访的前一天，普京给特朗普打了个电话。

而且这通电话，长达2.5小时。

注意这个“电话”，并不是我们指的拿起手机跟对方通话，事实上这种国家领导人的沟通，都是视频电话，而且并不是两个人单独聊，通常美国这边视频前坐5-10个人，俄罗斯那边也坐5-10个人，两个话事人说话沟通，其他人在一旁出主意记笔记，看到老大有啥话没说对的，就赶紧上前附耳几句。

也就是普京团队跟特朗普团队在视频里，面对面聊了2.5小时。

具体聊了什么，我当然不知道，我要知道，我不成了全球头号情报头子了吗，那我还会在这苦哈哈写啥自媒体，光给俄乌卖情报都够我下半辈子了。

虽然不知道，但我们可以根据双方事后发的声明，大致推算发生了什么。

16日通话结束后，特朗普发文说，他跟普京主要讨论了“结束俄乌冲突及其后的俄美贸易问题，通话取得很大进展。”

俄总统助理乌沙科夫则说，普京向特朗普详细阐述了对乌克兰局势评估，指出俄军已完全掌握战略主动权，但俄坚持外交途径解决乌克兰问题，美国要向乌克兰卖战斧导弹不会改变局势，只会对俄美关系造成重大损害。

我翻译一下：

这次会谈，美国认为俄乌战争必须结束了，甚至把战后跟俄罗斯做生意的蓝图都绘制好了，双方谈得很默契，美国很满意。而俄国认为优势确实在我，乌克兰别闹了，你美国别卖战斧添乱了，免得后面我们俩生意也不好做。

那么8月普京与特朗普见面，为啥到了10月才有了下文？

阿拉斯加美俄领导人会晤是8月15日，8月22日晚上的时候，普京在萨罗夫会见核物理专家时，公开说了句很重要的话，他说“俄美关系看到了隧道尽头的曙光。”

全球地缘政治格局，为之一震。

从8月15日到10月16日，整整两个月的时间，双方应该都在内部完成调解协商工作，特朗普一直在等着普京的回信，等得都发了点牢骚。

那为什么在10月16日，普京给出下文了？

因为17日泽连斯基要上门要战斧导弹了，这时候必须再公开一下自己的路线执行图，以及自己整体意向，避免特朗普做出误判。

而在10月21日深夜，大消息传来，西方各重要国家，包括法国、英国、德国、意大利、波兰、挪威、芬兰、丹麦、欧盟委员会、欧洲理事会领导人，以及泽连基本人，都发表联合声明，强烈支持特朗普在乌克兰问题上的立场，即俄罗斯与乌克兰立即停火，以当前战线作为谈判起点。

那如果不出意外，事情还是朝着我们几年前判断的大方向在发展：

即俄乌极有可能以战线停火，签署停火协议，但有可能不签署和平协议。

我再把逻辑简单讲一遍：

特朗普铁了心要联俄制中，至少要改善跟俄罗斯的关系，这次吸取了上届做总统的困境的经验，一边在国内搞清洗，一边主动跟俄罗斯谈判。

而俄美之间最大的问题是乌克兰，8月15日美俄两国会谈，应该是谈妥了利益交换，美国要求乌克兰停火谈判划界，俄罗斯出让经济利益——极有可能跟石油天然气有关，换取跟美国关系恢复正常。

大家要知道，普京接手总统以来，自小布什后，对整个美国政坛高层深恶痛绝，我看好多回忆录，记叙他跟克林顿、奥巴马谈判时的情景，因为被美欧不断地欺骗，谈判时，都是美国人在谈判桌上开腔，普京一脸不屑地倚在椅子上玩笔，根本不想理会美国领导人。

而今年8月跟特朗普谈完，他居然说：俄美关系看到了隧道尽头的曙光。

各位，这不是俄乌战争即将停战这一件事，这后面还很可能是：俄美关系缓和、俄罗斯经济崛起、俄欧能源重新谈判、欧洲重新投资俄罗斯、俄罗斯停止向印度卖石油等一系列反应。

如果情况再恶化一些，甚至有可能俄美两国战略绑定，对中国形成很大的压力。

阿拉斯加美俄会谈，极有可能成为俄国外交史上的重要转折，普京胜利在望。

随着俄乌战争停战在望、美俄关系剧变，全球的股市、大宗资产价格、黄金、比特币等都会受到极大的冲击，越早能做出准确预判的人，也会在后期收获越多的个人财富。

当然啦，我们暂时不能把话说死，毕竟在这个美俄变化的转折点，谁也不知道欧洲的反对派，或者美国民主党搞出什么幺蛾子，又来个恐怖袭击或者军事冲突，又能把美俄关系打回几年前。

总之，盯紧时事发展，紧跟时事解读，多看看我们的新闻分析，大体上是没错的。
