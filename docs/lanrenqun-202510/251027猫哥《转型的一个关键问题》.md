

# 转型的一个关键问题

251027 猫哥

懒人微信：lazyhelper

今天要赶高铁，写一个简短的。

昨天与朋友喝茶，提出一个很重要的问题——一个国家或者经济体要顺利实现转型，最重要的因素是什么？

我的答案很简单，最重要也是最关键的是需要一个威权型领导人。

为啥？讲几个案例。

第一个是反面典型就是泽连斯基，我们都说泽连斯基将乌克兰推入深渊。

但是，泽连斯基上台之后还有其他的选项么？实事求是的说，没有。

2014 年乌克兰爆发颜色革命之后，反俄就成为乌克兰的政治正确，2019 年泽连斯基当选总统，他面临的情况就是，国内是反俄政治正确大环境，国际上依赖的西方不断拱火，所以泽连斯基没有改善对俄关系的选项。

作为一个政治素人，缺乏足够的威望，泽连斯基的政策只能从阻力最小的方向去制定，反俄或者说对俄强硬就成为必然。即便泽连斯基开了天眼能预测到 2022 年之后的俄乌冲突，他也无法改变，只能一步步走入深渊。如果泽连斯基逆流去缓和对俄关系，估计他这个总统三个月都干不了。再来一个。

我们都知道，中国经济腾飞是从小平同志的改革开放开始的。

为什么小平同志能制定改革开放的政策？这个政策的基础是中美建交。

没有中美建交，就没有与西方关系的缓和，没有与整个西方关系的缓和就没有开放这一说——美帝苏修的政治环境下，对谁开放？

没有开放这个前提，就没有改革的需要。这是一环扣一环的。

那么是谁主导了中美建交？是教员。也只有教员才有这个崇高的威望，才能破除当时中国几十年形成的反美帝的政治正确，才能为小平同志奠定了改革开放，经济转型的基础。

我们反过来想一想，如果教员没有在他有生之年干成了中美建交，后面就麻烦了。现在的中国大概就是另一个样子。

即便教员奠定了基础，小平同志推动的改革开放经济转型也遇到了巨大的阻力，差一点就夭折了，还是小平同志在有生之年通过南巡讲话，以自己数十年巨大的威望生生逆转了形势。

中美建交有教员，改革开放有小平，国家幸甚，民族幸甚。

对比一下教员与泽连斯基就可以看出，一个国家重大国策能否实现转型，威权型领导人是关键中的关键。

# 说说当下

从十四五开始，中国也面临着一个经济转型的问题，明眼人都能看出，过去经济增长模式——依赖城市扩张，依赖房地产模式已经不可持续。

但是要实现转型谈何容易？

一个城市扩张，一个房地产开发牵扯多大的利益集团？牵扯无数人的政治利益，要放弃这种模式，转型为新质生产力这个阻力不是一般大。

在这个时候，我们同样需要高度威权型领导人，才能推动中国经济的顺利转型，转型周期越短越好，但是越短阵痛越大，阻力越大。

但是如果不转型，那么我们就只能眼睁睁看着城市无限扩张，地方与居民债务无限膨胀，最后就是一条不归路。

随便举一个例子，东北居住人口只有9500万，年年人口负增长，但是东北绝大部分城市规划的未来人口竟然高达2个亿，这是不是巨大的资源浪费？所以，在这个时候，必须要中央对城市扩张叫停，对房地产进行遏制，要做到这一切中央没有足够的威权是很难的。

## 再举一个例子。

现在我们稀土牌打出来威力巨大，为什么过去中美贸易战没打这张牌呢？原因很简单，就是过去稀土走私猖獗，这个走私不仅仅是一些企业利欲熏心，而且得到地方政府的庇护。如果稀土走私无法杜绝，那么打稀土牌就是一个笑话。

那么现在为什么又能打这张牌呢？

因为这两年我们把过去稀土走私猖獗的一些地方官员整体撸了一遍。

答案就是这么简单而且朴实无华。

所以，我们这个国家在转型的关键时期总能出现威权型领导人，这是我们的幸运。这个结论我觉得是经得起历史评价的。
