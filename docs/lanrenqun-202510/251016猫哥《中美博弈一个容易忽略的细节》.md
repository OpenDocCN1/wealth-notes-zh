

# 中美博弈一个容易忽略的细节

251016 猫哥

整理：公众号懒人搜索，懒人专属群独享

懒人微信：lazyhelper

![](img/1bec79e6e1933a75b8513cfb5c26ffad_0_0.png)

中美博弈最近有点对抗升级的趋势。但是有一些很重要的细节被大众忽略了，而这些细节却可能是揭开中美博弈升级原因的钥匙。

最近媒体报道，在中方发布稀土新规之后，美国贸易代表格里尔给中方打电话，却被中方拒接了。

这就有点奇怪了。

最近商务部发言人就公开表示，谈的大门敞开，打的奉陪到底。

既然有这个谈大门敞开的表态，为什么又拒绝接格里尔的电话呢？这是不是有点自相矛盾呢？

这还真不是自相矛盾。

与老美斗了好几年，过去我们对老美的基本态度是，谈的大门敞开，打的奉陪到底。这个表态是谈在前，打在后，而最近这个表态文字没变，但是次序却变了，变成打在前，谈在后。

这可不是简单次序变化，而是对美斗争策略重心的变化！

谈在前，意思就是以谈为主，实在谈不拢了再打，这是一个相对比较克制的力求维护斗而不破的策略，

打在前，意思就是以打为主，真把老美打痛了，我们再坐下来谈，这是一个坚定的不怕与老美脱钩的斗争策略。

为什么有个策略的变化？

因为老美太傲慢，太言而无信！

自中美贸易战之后，中美双方在伦敦、在西班牙、在瑞典连续谈了好几轮，虽然后续没什么进展，但是双方基本达成一种默契，就是不能单方面升级非贸易壁垒。

结果呢？

中美马德里谈判结束才过了二十几天，老美商务部就整出一个大动静，把中国大量公司列出出口管制的实体清单，并且通过所谓的“股权穿透规则”无限制扩大制裁范围，导致高达几千家中国企业上了老美的制裁清单。

与此同时，老美还执意推进针对中国海事、物流、造船的301措施，并且以芬太尼为借口，对我们化学公司进行制裁。

在美国人眼里（以格里尔为代表），美国可以肆无忌惮打压别人，而不用付出任何代价。

这还怎么谈？

谈多久，谈什么都没有意义了。

也只有打了再说，至少也要把美国人打痛了再说。这就是中方调整对美斗争策略重心，将打放在前面的原因。

为什么不接格里尔电话？

因为你格里尔与贝森特都是9月份中美马德里谈判的参与者，结果中方在TIKTOK做出让步，让你们欢天喜地回去给特朗普报喜，然后你们反手就给中国搞出几千家公司的制裁名单出来！

说实话，中方还算是客气的，换做是我，接了格里尔电话直接就是劈头盖脸先骂了再说！

那么在中方反制之后，这两个马德里美方谈判代表是什么反应呢？

格里尔面对媒体采访时这么说的：中国不能一边反击美国，一边觉得自己认为自己做的事情是合理的..

你看看，格里尔还是美国优先那套思维，美方言而无信对中方的遏制与打压视而不见，反而指责中方的反制做得不对。

贝森特面对媒体采访时这么说的：他认为这个稀土措施是中方下级官员的独走，领导可能都不知道这个事。

这个表态就有点耐人寻味了。

首先，中美之间打交道这么多年，过去有过下级官员独走的先例吗？

没有，从来没有！

其实稍微对中国体制有点了解的，就不可能得出这样的结论。

贝森特当然不是傻子，那么他为什么这么说呢？两种可能。

- 其一，给特朗普找一个台阶，把中美现在剑拔弩张归结为某个中方下级官员的“独走”（不是领导的意思），然后试图找到一个让双方都缓和的空间。
- 其二，给中方暗示，过去美国商务部搞出的那个庞大的制裁清单，其实是“下级官员”的独走，特朗普都不知道。这也为未来中美会面创造机会。

但是问题在于，如果特朗普无法约束手下人独走，那么未来中美即便会面，也不可能谈出什么名堂。

中方将打放在前面，放在对美斗争策略的重点，目的就是如此——如果美方一味奉行美国优先的事项，随意扩大贸易争端，随意对中方企业发起制裁，中方只会与美方继续打下去，一直打到美方愿意坐下来老老实实遵循协议或者承诺。

在短期内中美贸易争端是扩大化趋势，暂时还没有看到有缓和的可能。
