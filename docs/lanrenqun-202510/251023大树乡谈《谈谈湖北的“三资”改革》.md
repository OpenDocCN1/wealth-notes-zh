

# 谈谈湖北的“三资”改革

251022 大树乡谈

整理：公众号懒人搜索，懒人专属群独享

懒人微信：lazyhelper

![](img/a54d7698b2f7b4ced085e44ca32a7ddc_0_0.png)

想尽办法增加财政收入的大方向是对的，但口号有待商榷。

10月16日湖北召开了全省深化国有“三资”管理改革推进会，所谓“三资”指的是国有资源、资产和资金。这次会议被广泛关注，主要是因为口号很抢眼。提出了“一切国有资源尽可能实现资产化、一切国有资产尽可能推进证券化、一切国有资金尽可能运用杠杆化”的三个原则，还提出“能用则用、不用则售、不售则租、能融则融”。客观地说，两句话虽有争议，但符合国家大方向，起码比2024年一些地方提出的“砸锅卖铁”温和多了。

但需要明确，无论“砸锅卖铁”还是“三资”改革，都不是变卖国有资产，重点是存量资产的盘活，这也是国家确定的大方向。比如2022年5月国办19号文《关于进一步盘活存量资产扩大有效投资的意见》，还有小镇去年11月在公号写的《严厉监管新规的背后，是刻不容缓的改革》，谈的是去年11月12日地方国企改革和监管工作视频会议，会上提到一个全新概念“强化覆盖全级次子企业的穿透式监管”，小镇认为强化监管的目的就是为了做好存量国有资产的盘活。

具体谈谈湖北提出的“三资改革”。这一改革理念最早是岳阳提出的“资源资产化、资产证券化、资金杠杆化”方案，岳阳的经验得到湖北省的认可，2023年9月湖北以化债为切入点推进大财政体系建设，当时就明确提到“过去依靠‘土地财政融资推动发展的模式、粗放型投资驱动模式越来越不适应新的要求”，因此需要探索新的资源配置和投融资模式。

很快开始全省推广试点，安排了武汉、宜昌、襄阳、黄石、黄冈五个“全套试点”地区，还对全省国有“三资”进行了“确认、确权、确值”的基础性工作，到2024年10月10日召开大财政体系建设座谈会的时候，前期准备工作基本就绪了，就到了全面落实的时候。

于是就有了2025年更进一步的推进，6月印发了《湖北省深化国有“三资”管理改革推动大财政体系建设走深走实总体工作方案》，在这个方案中已经明确了“国有资源资产化、国有资产证券化、国有资金杠杆化”原则，以及“用售租融”的具体方式。所以10月16日的这次会议只是口号喊得更响了，加上了“一切、尽可能”的句式，还把“用售租融”展开说了。

湖北的这套做法很快得到了最高层的认可，2024年专门去湖北调研过，“三资”改革、大财政体系建设等理念也写进了去年的三中，比如去年提出的探索实行国家宏观资产负债表管理就与湖北的改革模式高度契合。

一个地级市提出来的理念，很快在全省变成一套系统改革，又迅速成为国家的战略方向，可见这项改革有多么急切。

这也是没办法的办法，原来地方上缺钱了，卖块地就行了，别管地是怎么卖出去的，终究把地方投融资运行下去了，也有了钱去搞城市建设、民生、化债等工作。但现在问题是土地财政搞不下去了，财政也没钱了，又面临严峻的债务危机，但城市建设、民生、化债乃至未来发展等都需要钱，如何确保财政增收、打造有别于土地财政的新投融资模式，成为全国各地最重要的工作。

地方财政可持续增长，已经成为“十五五”期间关系到中国经济、地方发展的根本性问题。而当前最紧迫的就是化债，化债之后则是地区进一步发展必须解决的投融资新模式问题，要想办法在卖地之外搞出来新的模式，难度非常大。

目前全国除了少数地区靠发展新兴、未来产业重新获得了不错的未来收益，大多数地区还没有找到出路，都在想办法。比如还有矿山等自然资源的，那就卖出去经营权，尽可能维持财政；有的自然资源也没有，于是就找到低空经济这些新概念，把低空经济30年特许经营权出让了，从中可以看出来地方财政的窘境。

在各地的探索中，湖北“三资”改革是最成体系的，尤其是大财政体系这个理念。

显然单靠传统财政手段已经难以维持，于是就有了大财政体系，就是把财政、金融、投资三大块统筹联动，想办法实现财政增收，其中国资是关键，目前看，这条路至少理论上可行。正因此，当湖北率先提出“三资”改革之后，立刻得到了最高层的关注，也有不少地方前往湖北调研，尝试把湖北的这套做法推广开。

参考湖北6月印发的《工作方案》，还是很细致的。比如列明了矿产、林业、水利、能源、土地、数据等六类国有资源、实物、股权、债券、特许经营权、未来收益权等五类国有资产，资金方面则确定了低效、闲置两类，然后每一类都进行了细化。

绝不是为了变卖而变卖，也明确划定了三条红线：不得虚增财政收入、不得虚假化债、不得新增隐性债务。

从文字规定上，还是比较完善的。但问题在于，当前实际最迫切的还是化债，这就导致现实执行中，原则很可能会被突破，而且想要盘活存量哪有这么容易，既然会变成存量，就说明经济利益不大。

比如最常见的盘活就是闲置房地产。10月16日湖北调研国有“三资”管理改革，提到了一些具体案例，提到盘活水利堤防设施和老旧堤岸码头，建设为“城市公共客厅”和“婚庆产业园区”，坦诚地讲，对一个城市而言，婚庆这种产业能有多少收益？说直接点，过去国资根本看不上，但现在也得想办法盘活，能有一点收益是一点。

还提到了将行政事业单位低效闲置资产改造为高端健康养老中心，这种做法也有不少地方尝试，但问题在于高端健康养老的需求量并不高，市场上已经有一些民营的高端养老，但多数经营并不好，目前做得比较好的也就是一次性收几百万，然后以利息支付养老费用的模式。这也是小镇在《有些生意，“骗”字当头》一文曾分析的当前老年人受时代思维拘束，老年人的生意往往“不能赚只能骗”。

湖北发的新闻稿提到的案例，落到具体的基本就是房地产、土地相关盘活，其他还不太成熟。但房产盘活也面临挑战，那就是房地产整体下行，市场上本就有大量闲置房产，在这种情况下，政府把自己手头的房产也推向市场，会不会导致房产收益的进一步下降？这挺难算清。

而且湖北这两句话本身也是有待商榷的。

先说“资源资产化、资产证券化、资金杠杆化”，首先“一切..尽可能”肯定是不妥的。

“资源资产化”这个争议不大，比如国家目前正在推进的自然资源有偿使用改革就是这个思路。

但“国有资产证券化”就有争议了，而且也不可以“一切尽可能”，当前原则是一企一策、一事一议，讲究宜混则混、宜独则独。2024年1月，国资在谈到改革深化提升行动落地的时候，也强调实施“一企一策”“一业一策”考核。

而“资金杠杆化”实际是空话，因为当前没有上杠杆的企业才是少数的少数，如果能上杠杆，肯定早就上了，地方债务危机一大来源恰恰是杠杆太高，所以近些年国家推进的改革，就是降低企业杠杆率。

比如2018年印发《关于加强国有企业资产负债约束的指导意见》，提出国企降杠杆的硬约束，要求到2020年末比2017年末低2个百分点，央企资产负债率也要控制在70%以内；今年7月又印发了《关于积极稳妥降低企业杠杆率的意见》，重点还是有效防范和化解债务风险。

而国资除了帮助财政增收，还要注意国有经济的控制力、影响力以及防风险能力，更要提高国有企业的核心竞争力和核心功能。在这种情况下，实际能够做文章的空间很有限。

至于“能用则用、不用则售、不售则租、能融则融”没啥可说的，实际工作也只能这么干，关键问题是能实现多少，而且也绝不是为了变卖国有资产，国有资产保值增值的要求并没有放松，变卖一定是最靠后的，谁也担不起国有资产流失的责任。

总之，湖北的“三资改革”肯定符合国家大方向，2024年至今各省盘活国有资产也取得了不错的成绩，就体现在非税收入的大增上，非税收入中罚没是小头，今年的暴增主要就是盘活。具体小镇6月星球问答《读者提问：房地产税出台时机、非税收入暴增和土地财政缺口弥补》（链接：感谢提问，2024年非税收入增长》一文已经谈过了，2024年非税收入增长25.4%，很大程度对冲了土地出让金的衰退，主要就来自盘活国有资产。

但小镇当时也提出来，闲置国有资产哪有这么容易盘活，这么简单的话早就干了，短时间内迅速增长，难免存在水分，这可能会导致对财政能力和化债风险的误判。这也是接下来需要关注的。
