

# 胡塞武装总参谋长身亡，会不会元气大伤？

251020 文/卢克文工作室嘉宾 朱染

整理：公众号懒人搜索，懒人专属群独享

懒人微信：lazyhelper

10月16日，也门胡塞武装发布通告，称其总参谋长穆罕默德·加巴里少将，成为了抗击美国和以色列的“烈士”。

组织已经任命了另一位少将优素福·马达尼，作为他的接替者。

消息一出，外界纷纷议论，许多网友一度将其阵亡视为“胡塞武装二号人物战损”。

那么，加巴里究竟是不是胡塞武装的二号人物？

总参谋方阵亡，会不会让胡塞武装元气大伤？

## 1、
先来看看加巴里是何许人也。

穆罕默德·加巴里，年龄约四十多岁，来自也门北部哈杰省。该省和邻近的萨达省一样，山区遍布，人民普遍信仰什叶派宰德学派，是胡塞武装起家的“龙兴之地”。

加巴里于2003年加入胡塞武装，曾经作为组织里的精干力量，被派往海外接受过黎巴嫩真主党和伊朗的军事训练。2007年，他因为作战表现突出，擅长运用无人机和导弹袭击，长于打游击战术，被组织任命为一处训练营的指挥官，负责新兵培训。

2014年，胡塞武装乘着政府内讧，进军首都萨那，加巴里在老家拉起一支部队，与胡塞兄弟一同攻破都城。他在此战中，击败了也门政府军第310装甲旅，并在萨那被夺取后，以城防司令的身份快速构建防御。此后，挫败了也门政府军和沙特联军进攻萨那的活动。

因此在2016年，他被胡塞武装最高领袖阿卜杜勒·马利克提拔为总参谋长。要知道，加巴里之前的上一位“总参谋长”就是马利克本人。由此可见，加巴里颇受马利克的信任。

在此期间，加巴里还多次策划了对沙特境内的导弹袭击。2020年，他一度替代马利克的弟弟阿卜杜勒·哈利克，指挥马里卜省的战事，使得胡塞武装拿下了该省的大部分土地。

2023年加沙战争发生后，加巴里又发挥了他的专长，组织了对以色列的多次导弹+无人机袭击。胡塞武装红海沿线的一系列军事活动，也是由他负责，给以色列带来了不小的麻烦。

就军事作用而言，加巴里是胡塞武装从游击武装转向正规化的重要人物，是远程打击战术的鼻祖级大师。

就政治关系而言，加巴里此前多次在伊朗受训，与伊朗关系深厚，是胡塞武装与伊朗沟通的重要人物。

他的死，意味着胡塞武装失去了一位经验丰富的指挥官，以及一位与伊朗沟通的桥梁，的确是一个重大损失。

有意思的是，加巴里的死亡时间也充满了一丝神秘色彩。

胡塞武装在其发布的通告中，只说加巴里和他13岁的儿子及少数随从死于美国和以色列的侵略活动，并没有提及他死亡的时间和更多细节。

倒是以色列国防部长卡茨，在加巴里死讯传出后，一口咬定加巴里死于先前以军在8月28日组织的空袭中。那次空袭，以色列击杀了包括胡塞政府“总理”艾哈迈德・拉哈维在内的13名高官。

当然，加巴里的阵亡细节倒不是要紧的事儿。毕竟，从胡塞武装的组织架构来看，加巴里的作用虽然很大，地位也很高，但绝不至于是胡塞武装的“二号人物”，胡塞武装也不会因为他的阵亡而元气大伤。

胡塞政权的组织架构模仿了伊朗，玩的是“双头政治”和“教权监督世俗”。

在这套体系下，胡塞政权的核心首脑是阿卜杜勒·马利克。他虽然不担任公职，也不怎么在公众面前露脸，但却拥有类似于哈梅内伊的宗教领袖地位。情报机构、内卫部队、政府和司法机构直接对他负责，是绝对的No.1。即便是胡塞政权的“总统”、“总理”等文官班子，也要对其负责。活脱脱一个缩小版的伊朗。

而围绕在马利克身边，决策国家大事的常设机构，实际上是“最高政治委员会”。该机构主要由胡塞家族的成员和他们的同乡控制，其委员长是马利克的堂兄穆罕默德·胡塞。此人才是真正的胡塞政权二号人物。

加巴里所属的胡塞正规军，也要接受最高领袖和最高政治委员会的指令。而且，在加巴里的总参谋部之外，胡塞武装还有大量分散在也门全国的地方指挥官和部落武装。

即便没有加巴里的指挥，这些地方指挥官和部落武装也能独立作战，又或者直接受最高政治委员会和马利克本人的指挥。其分散化部署的特点，使得加巴里的死对胡塞武装造成的打击是有限的。

真想想让胡塞武装的领导层元气大伤，怎么也得斩首胡塞家族的成员，打击到最高政治委员会的层次才能有效果。

如今，随着胡塞武装新任总参谋长优素福·马达尼上任，胡塞武装的军事指挥层空白也得到了填补。这位马达尼总参，也和加巴里一样接受过伊朗的特训，同样擅长组织无人机+导弹和水雷+小艇的袭击模式。

不出意外的话，他对付以色列的招数，不会和加巴里有太大差别。

## 2、
值得注意的是，胡塞武装在加巴里的讣告中还着重提及，他们要为此复仇，直至“解放耶路撒冷”的内容。最高领袖马利克也表示，以色列与哈马斯近期达成的加沙停火协议“非常脆弱”，且胡塞武装是否要继续袭击以色列，要视情况而定。

这意味着，胡塞武装还会继续与以色列保持战争状态。

要知道，胡塞武装与以色列开战的直接原因是2023年的加沙战争。如今，哈马斯和以色列已经在10月初停火，黎巴嫩真主党和伊朗也跟以色列暂停了冲突，胡塞这个时候继续和以色列对抗，颇有孤军奋战的意味。

胡塞有继续打下去的意愿，以色列也不遑多让。

毕竟，胡塞武装从7月开始便恢复了对红海沿岸商船的袭击。这对于以色列的港口贸易、物流造成了严重的损失，抬高了以色列的物价水平。且胡塞武装此前多次向以色列发射导弹、无人机，这笔仇以色列还记着。

在眼下以色列与伊朗、黎巴嫩真主党、哈马斯的冲突均告一段落的情况下，胡塞武装是唯一实力没有遭到重创的“抵抗之弧”力量，胡塞武装积累的导弹、无人机和水雷依然有能力对以色列造成威胁。

这种情况下，以色列极有可能在未来把矛头对准胡塞，对其进行打击。

难怪，以色列总理内塔尼亚胡在近期强调“胡塞是恐怖主义链条的另一环”。

从以色列空军先前打击伊朗的情况来看，以军具备对也门全境展开空袭的能力。以军如果能在情报工作到位的情况下，采用战机空袭+无人机/导弹出击的模式，很有可能会给胡塞武装造成不小的损失。

而胡塞武装受制于武器装备的落后，能对以色列造成的直接伤亡是有限的。其最主要的反击手段，还是袭击红海上的商船，让他们不敢在以色列南部港口卸货，从而对以色列造成间接的经济打击。

而无论是美国这种超级大国，还是伊朗、沙特等周边国家，实际上都没有能力改变局面。

毕竟，且不说美国是否有能力约束以色列，美国在红海地区部署的舰队也无法做到无死角护航商船，美国没有能力阻止胡塞武装发动袭击。

至于伊朗，他们实际上也没有制止胡塞武装的报复，因为伊朗与也门地理阻隔太远，他们对胡塞武装一向采取的是“支持而非控制”的扶持战略。胡塞领袖马利克将袭击以色列当做是“圣战义务”，而非听命于伊朗的决定。

更何况，胡塞武装在接收伊朗援助之余，也实现了部分弹道导弹和无人机的本土化生产，他们有能力绕开伊朗，单独行动。

总而言之，红海现在是，未来一段时间里，也将是全球最危险的海。
