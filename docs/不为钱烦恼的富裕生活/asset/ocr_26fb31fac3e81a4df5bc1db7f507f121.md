# 前言

這是一個以真實事件為基礎的故事，內容集結了許多為錢煩惱而來向我尋求諮商的人們的故事故事。除此之外，這也是過去長年任職於血汗企業，人生幾乎被沒有財富和時間的生活拖垮的我，重新起死回生的故事。

說到這裡，很多人會說自己根本沒有受過什麼金錢教育。事實上的確如

此。

在日本，一般人幾乎沒有機會學習金錢相關的知識。大家從小的成長環境便缺乏金錢教育，也曾思考過「如何靠自己賺錢」。日本的孩子唯一跟金錢有關的學習，就只有父母對待金錢的態度。

假設父母經常掛在嘴邊、以身作則為孩子示範的態度是：「我們家沒有錢。」
