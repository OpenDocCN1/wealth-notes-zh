# 均線的「方向」與「排列方式」是獲利關鍵

相反地，也有另一種手法是利用趨勢的轉換而趁機買賣股票的。「當股價與5日線往下穿過朝上的20日線，又持續再跌的話，就賣出」；「當股價與5日線往上穿過朝下的20日線，又持續再漲的話，就買進」。

5日線與20日線一起上漲時，除非5日線先開始跌，否則20日線是不會跌的。由於均線是這樣子設計的，百分之百會如此。只要20日線維持朝上，在5日線暫時下跌又復漲時賭在買進上，是極其正確的做法。

等到5日線朝著20日線的下方而去，20日線又轉為朝下時，再來考慮壓在賣出上，而非買進上。

股票投資不用勉強逆勢操作，而是要輕鬆地看待事情，才會成功。

> 藉由只鎖定在「均線」上，就能催生出不管誰來做，不管在哪種狀況下做，都能成功的「可重現性」。
