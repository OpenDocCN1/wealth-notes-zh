# 「7日法則」可助你採取最佳策略

思考更短期的股價上下波動時，「週期」一樣很重要。我親身體會到股價的節奏有所謂「7日法則」。意思就是「無論什麼樣的走勢，上漲或下跌只要維持七天，就會一度稍微停歇」。

股價就是反覆上上下下，持續波動。不管看哪一檔股票的線圖都能了解，沒有任何一檔股票從上市以來持續上漲從不下跌，或是呈一直線下跌完全沒漲過（除非該公司已破產）。

在這樣的背景下，只要股價上漲，在低點買進的人就會賣出；股價下跌時，在高點放空的人就會回補。這就是投資人的行為。

股市裡常聽到有句話說，「沒有人會長抱著股票進棺材」。別說是進棺材，「獲利的股票很少人抱著超過七天」這句話確實沒錯，而且道盡了股市本質。因此，one、two、three、four、five、six……到這裡時，股價走勢差不多就會失去了原先的力道。
