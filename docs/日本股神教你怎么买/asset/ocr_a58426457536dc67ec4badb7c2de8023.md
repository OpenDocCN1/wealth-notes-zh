# 以「多空對沖」避險，擴大獲利

設股價的變動如圖 8-9 所示。整體來看，股價從①到③上漲，但在這段時間內上下震盪幅度很大。看了圖之後說「在②買進，到③時賣掉就賺了一筆」！這只是紙上談兵。當還沒看到未來時，到了⑥點比買進價格下跌許多時，難免會擔心莫非預測不準？也有人會在此認賠停損。

要是運氣好一點，等到股價從⑥又漲上來，雖然抵銷了潛在虧損，但股價上下震盪的結果，從④到⑤只能賺到微幅的價差。相對地，藉由買進與放空的「多空對沖」，一顆心不必跟著震盪的股價七上八下，這就是將獲利擴大到極限的「部位操作」。

例如，在④時買進，之後當股價跌到前一波高價的⑤時放空相同的數量。這麼一來，在⑥之後的下跌走勢中，買進的潛在虧損雖然增加，但相同數量的放空出現了潛在獲利，損益打平。
