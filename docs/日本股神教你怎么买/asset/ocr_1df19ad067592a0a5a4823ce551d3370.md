# 只靠下半身／反下半身也可使用散彈槍投資法

要買進就專注買進，要賣出就專注賣出，這種單純的性質就是散彈槍投資法吸引人的地方。不過，如果能搭配多種買賣訊號及指標，加上相場式的各種技法來判斷是否交易，應該會提高致勝率。
