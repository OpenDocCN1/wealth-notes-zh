總。可 是，離差的加總和顯然是零，因爲離差有正、有負，而且正、負値必定剛好相互抵銷。所以，如果真的想衡量資料點偏離平均數的程度，必須避免負值的離差。最簡單的辦法，是直接取消負號，結果就是絕對離差（absolute deviation），這也是我們最初考慮採用的計算方法。取前述離差的平方，也可以避免負號——負數乘以負數，結果是正數——這就是標準差採用的計算方法。

最後步驟很簡單：計算離差平方的加總和②，然後計算這個加總和的平均數，最後再取平方根（表 7.1）。

# 表 7.1 標準差計算公式

```
σ = √[ Σ(xᵢ − μ)² / N ]
```

其中
x=資料點
μ=平均數
N=資料點的數量
