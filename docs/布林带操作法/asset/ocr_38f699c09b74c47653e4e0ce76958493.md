# 表 8.1 %b 計算公式®

（最近價格−帶狀下限）／（帶狀上限−帶狀下限）

![](bbox=[0.15, 0.22, 0.84, 0.55])

圖 8.1 Nokia：包寧傑帶狀與%b 指標，250 天資料。%b 指標顯示目前價位與帶狀的關係。

① 如果讀者熟悉技術分析，應該發現這個公式與喬治·雷恩（George Lane）的隨機指標（stochastics）公式很類似。隨機指標的基本公式為（最近價格−n 期最低價）／（n 期最高價−n 期最低價）。雷恩稱這些指標為%d、%k 或其他類似名稱。所以，依據他的系統，以及我的系統緣由，我也採用他的命名系統，稱這項指標為%b（經過查證，雷恩並沒有使用相同名稱）。雷恩來自於美國中西部，多年來都在 Cessna 210 傳授商品交易技巧，對象主要是農民。他帶著濃厚的宗教色彩，演講內容也非常強調信仰。我永遠會記得他！他讓我瞭解，價格經過三次衝刺而創高點的觀念，整個過程令人懷念。這是一種隨著時間經過而歷久彌新的觀念。他利用隨機指標來診斷三次衝刺而創新高的現象；我則運用包寧傑帶狀與成交量指標。如果雷恩比較重視股票而不是商品的話——前者可以立即觀察成交量，後者的成交量資料落後一天，而且只有總量——我懷疑結果是否還是如此。
