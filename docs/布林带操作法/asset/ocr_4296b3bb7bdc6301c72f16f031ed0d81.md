# 第3章

# 時間架構

本書考慮三種時間架構：短期、中期與長期。這些都是大家非常耳熟的名詞，但實際意義可能因爲個人觀點與交易方式而不同。在某個意義層面上，它們對於不同投資人各自代表不同的意義；在另一種意義層面上，它們又蘊含類似 的心理概念。每位投資人會根據自己的觀點解釋這些名詞的意 義，但仍然依據這些時間架構來組織各種工作與功能。所 以，對於某位投資人來說，所謂的「長期」可能代表一年， 但對於另一位投資人而言，「長期」很可能代表隔夜的意思。 可是，這些投資人對於時間架構的解釋或許截然不同，但還 是按照短期、中期與長期的分類來組織投資工作。

一直到 1970 年代末期之前，短期通常是指日線圖而言， 中期則是指週線圖，長期是指月線圖或季線圖。雖然我們依 此稱呼走勢圖，但實際上是指每支線形——不是整個走勢圖 ——涵蓋的期間而言。所以，根據定義短期日線圖的每支線 形代表一天的價格交易紀錄。到了 1980 年代初期，金融市場 的步調明顯加快。隨著股票指數期貨的引進，肯薩斯期貨交 易所（Kansas City Board of Trade）開始提供價值線
