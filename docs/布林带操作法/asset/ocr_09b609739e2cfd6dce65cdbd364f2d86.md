# 名詞解釈

Acceleration 加速指標 一種技術指標，衡量變動率的變動率，可以視為價格的第二階導函數。這項指標提供趨勢變動的早期警訊。參閱 Velocity [速率]與 Rate of Change「變動率」。 

Accumulation 承接 這是「大玩家」或「內線」預期價格即將上漲而買進股票的過程。也是技術分析者所希望觀察的行為。很多技術指標專門強調這項過程，尤其是成交量指標。大體上來說，在股價發生重大走勢之前，通常都有一些精明投資人會預先知道股價即將上漲，開始承接股票。參閱 Distribution [出貨]。

Accumulation Distribution 承接／出貨指標 這是根據每期開盤價與收盤價關係而計算的成交量指標。這項指標由拉利·威廉斯（Larry Williams）發明，與日本陰陽線觀念有密切關係，所以也稱為「日本成交量指標」（Japanese Volume）。計算公式：[（收盤價−開盤價）／（最高價−最低價）]×成交量。參閱 Money Flow
