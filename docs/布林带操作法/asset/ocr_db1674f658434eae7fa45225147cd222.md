# 常態化技術指標

包寧傑帶狀的運用，沒有必要侷限在證券或價格指數的範疇內。讓我們點出幾個可能的對象：比率、經濟統計資料、基本面數據、成交量或技術指標。不論這些數列屬於擺盪指標的性質，或者完全沒有上、下限。每種情況下，包寧傑帶狀提供的功能都相同——界定相對高點與低點。這種處理方式具備的洞察力，經常是那些傳統絕對標準或法則所不能比擬的。

讓我們以相對強弱指數（RSI）爲例做說明。根據傳統解釋，每當 RSI 讀數超過 70，屬於超買狀態；RSI 讀數低於 30，屬於超賣狀態。關於這項指標，最普遍的運用法則可能是：每當 RSI 由下往上穿越 30，視爲買進訊號；每當 RSI 由上往下跌破 70，視爲賣出訊號。這種處理方式顯然有些問題——70 與 30 有時候可以精準界定超買與超賣，有時候則很離譜。
