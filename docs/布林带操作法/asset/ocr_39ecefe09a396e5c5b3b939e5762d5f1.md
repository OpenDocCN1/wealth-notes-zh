# 表 11.3 美林對於 M 頭與 W 底型態的分類

| 技術型態 | 美林的型態 |
|---|---|
| 上升趨勢 | M15, M16, W14, W16 |
| 下降趨勢 | M1, M3, W1, W2 |
| 頭肩底 | W6, W7, W9, W11, W13, W15 |
| 頭肩頂 | M2, M4, M6, M8, M10, M11 |
| 三角形 | M13, W4 |
| 擴張型態 | M5, W12 |

美林與李維分別採用不同的濾網，前者採用固定百分率，後者採用價格波動率。我們採用的包寧傑方格則是兩者的結合，藉以過濾價格擺動與波動，並且預測未來可能發生的走勢。事實上，這套方法也是我們的交易平台——型態動力（PatternPower, www.PatternPower.com）——的核心所在。

M 頭與 W 底分類有一個重點，可以藉由包寧傑帶狀與相關指標來釐清型態。由於性質差異，我們將在隨後兩章內分別討論 M 頭與 W 底，說明這些型態如何與包寧傑帶狀結合，提升預測精確性。第 14 章更納入相關技術指標。

# 本章內容重點

+   ■ 價格濾網可以用來過濾雜音，協助辨識型態。
■ 股票最適合採用百分率濾網。
■ 包寧傑方格是非常傑出的過濾系統。
■ 所有的價格型態可以分類為一系列不同的 M 頭與 W 底排列。
