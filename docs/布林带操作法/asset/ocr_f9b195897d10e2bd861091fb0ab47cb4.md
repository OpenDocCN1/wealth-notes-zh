# 第 9 章

# 統計學背景資料

首先，提供一些背景資料：

測量一群人的身高，標示每種身高（165 公分、166 公分……等等）的人數，分別繪製為柱狀圖。如果人數夠多，身高將呈現常態分配（normal distribution，圖 9.1）；換言之，以平均身高為中心，呈現左、右對稱的鐘鈴狀。大多數人的身高都在平均數附近，平均數也是鐘鈴狀分配的最高點。身高愈遠離平均數，人數愈少。對於非常高或非常低的身高，人數都很少。
