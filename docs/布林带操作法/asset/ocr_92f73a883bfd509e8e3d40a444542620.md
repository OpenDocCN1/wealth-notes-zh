# 謝 辭

任何事物都不能單獨完成。

首先是我的父母——父親讓我瞭解數學的樂趣，教我如何飛揚；母親信賴我，把她的生活憑藉完全交由我決定。

如果沒有我的妻子桃莉，這一切都不可能；我的女兒卓爾則是太陽能夠升起的動力。

我剛認識瓊·瑞納（Jon Ratner）時，他是貝克公司（AG Becker）的經紀人，現在則是一位好朋友。他促成很多事情，尤其是透過他的介紹，我認識了查爾斯·史佩思（Charles Speth）與霍利·漢德立克（Holly Hendricks），讓我有機會學習交易。後來，瑞納又說服公司經理，提供給我一套報價機與櫃檯，使我能夠進行操作。

厄爾·布萊恩（Earl Brian）是金融新聞網的董事長，感謝他信賴我與電腦化技術分析。
