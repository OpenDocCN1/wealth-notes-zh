# 第 20 章

# 交易方法 III：反轉系統

方法 III：當價格觸及包寧傑帶狀邊緣，藉由技術指標的行為，預測趨勢反轉的可能性。首先考慮兩種情況，第一，價格重複觸及帶狀上限而技術指標惡化；第二，價格重複觸及帶狀下限而技術指標轉強。其次，我們單獨觀察價格觸及帶狀邊緣的現象，技術指標當時呈現相反狀況——技術指標在帶狀下限顯示強勁表現，在帶狀上限顯示疲弱表現。

大約從 1970 年代初期的某段期間開始，我們看到一種流行的技術交易方法，這是把價格均線分別向上與向下平行移動特定百分率，形成價格包絡。換言之，你只要把價格移動平均乘以 1 加上某特定百分率，就可以繪製帶狀上限，再把價格移動平均乘以 1 減去某特定百分率，就可以繪製帶狀下限。當時個人電腦尚未普及，只能仰賴算盤、鉛筆、草稿紙或計算機，前述這種簡單的計算程序比較適合人工處理。
