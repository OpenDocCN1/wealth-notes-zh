Last 最近成交價 特定時段內的最近成交價格，不論該時段是否已經結束與否。參閱 Close [收盤價]。

LEAPS 長期選擇權 集中市場公開交易的長期選擇權。相對於根本資產來說，長期選擇權對於價格波動率的相關假設更敏感。所以，不熟悉長期選擇權訂價理論的交易者經常抱怨其價格波動。

Line Chart 曲線走勢圖 利用曲線銜接資料讀數的走勢圖。換言之，每個時段只取單一數值，這種圖形通常適用於資料只有單一讀數的情況，或者資料非常複雜而只取某代表性數據。

Liquidity 流動性 大體上，這是指交易的方便性而言。流動性愈高，交易愈方便。舉例來說，房地產的流動性較差，可能需要六個月或更多的時間才能完成一筆交易——流動性高的證券，通常只需要幾秒鐘就能完成交易。流動性愈差，交易成本愈高。

Log Scale 對數刻度 圖形座標採用的一種刻度，相同距離代表相同百分率變動量，但絕對差距則不相同。假定價格圖形的縱座標採用對數刻度，不同價位起算的相同垂直距離，都代表相同的價格百分率變動量，但它們代表的價格變動量本身並不相同。對於長期走勢圖來說，對數刻度特別有用。參閱 Arithmetic Scale [算術刻度]。
