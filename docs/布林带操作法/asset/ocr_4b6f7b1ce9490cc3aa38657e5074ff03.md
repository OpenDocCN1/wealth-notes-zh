跌家數）／（上漲成交量／下跌成交量）。參閱 *Open Arms Index* [開放型阿姆斯指數]。

Backup 回升 參閱 *Retracement* [折返]。

Balanced Fund 平衡式基金 大體上來說，這種基金同時投資股票與債券，並且根據兩種市場的情況發展，調整股票與債券的持有比率。最近，同時持有多頭與空頭部位的基金也稱爲平衡式基金。

Bands 帶狀 根據某種中心趨勢衡量方法繪製的價格帶狀。參閱 *Channels* [通道]與 *Envelopes* [包絡]。

BandWith 帶寬指標 由包寧傑帶狀衍生的技術指標，計算公式：（帶狀上限–帶狀下限）／帶狀中心。參閱 *The Squeeze* [擠壓]。

Bar Chart 長條圖 記錄特定期間內價格資料的圖形，縱軸標示價格，橫軸標示時間。對於每支長條圖，頂端表示特定期間的最高價，底端表示該期間的最低價，左側小橫劃表示開盤價，右側小橫劃表示收盤價。

Base 底部排列 證券價格經過一段下跌之後所呈現的狹幅整理走勢——底部排列一旦完成，通常都會出現一段漲勢。最近，市場習慣把橫向整理統稱爲底部。
