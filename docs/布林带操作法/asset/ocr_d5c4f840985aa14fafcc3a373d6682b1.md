圈叉圖（point and figure chart）是一種類似擺動圖的過濾方法，這可能是西方世界最古老的股票繪圖方法，只採用價格擺動的資料，完全不考慮時間或成交量。圈叉圖採用方格紙繪製，價格座標標示在縱軸。

圈叉圖早在 1800 年代末期就出現在文獻紀錄上，交易所營業大廳把這種圖形稱為「數字圖」（figure chart）。現在，我們採用×代表向上擺動，O代表向下擺動。剛開始，「數字」圖確實採用 3、21、57……之類的數字，藉以記錄價格行為。當時的場內專業交易員在交易單據背後記錄這些圖形。稍後的圈叉圖則利用 X 來同時表示向上與向下的擺動，並且利用 0 或 5 來標示個位數字為 0 或 5 的價格；狄威里亞（deVilliers）與惠仁（Wheelan）兩位分析師都採用這種繪圖方法（圖 11.7）。
