Close 收盤價 某特定時段的最終交易價格。參閱 Last [最近成交價]。

Closed-End Fund 封閉型基金 在證券交易所公開掛牌上市的一種共同基金。交易價格可能高於或低於基金淨資產價值，分別稱為溢價（premium）或折價（discount）。

Commissions 佣金 證券經紀人提供服務所收取的費用。

Confirmation 確認 價格與技術指標對於當時市況的看法相互一致，彼此確認。參閱 Multicollinearity [多重共線性]。

Congestion Phase 盤整階段 價格出現一段漲勢或跌勢之後，所呈現的橫向狹幅整理階段。一段沒有明確趨勢的階段。參閱 Pivot [樞紐]。

Consolidation 整理 強勁走勢之後的整理期間。又稱為樞紐（pivot），因為強勢股的相對強度曲線在這個期間內會趨於平坦或甚至下滑。
