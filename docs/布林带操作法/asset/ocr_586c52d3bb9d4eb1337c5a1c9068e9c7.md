# 第 5 章

# 扮演自己的主人

本書將提供很多不同的觀念與法則，推演相關的時間架構，推薦適當的交易指標，討論各種處理方法。我們的建議在某些情況下非常明確，在另一些情況下則故意模糊。所有這一切都有一個共通點：如果你打算成功，就必須以自己爲準。

某些投資人在認賠出場之前只能忍受少些許的損失，另一些人則爲了追求中、長期獲利而比較願意忍受短期的價格波動。對於短線投資人，目前非常流行一種準則：如果發生 7% 或 8% 的損失，就應該認賠出場。這顯然非常荒謬，因爲投資人應該自行決定自己準備遵守哪種紀律規範。8% 的停損法則或許適用於某些投資人，但對於另一些投資人可能是賺錢的障礙，甚至造成持續性虧損。請注意，沒有任何死板的法則能夠普遍適用於所有投資人。

此處有兩個例子可以說明投資人如何按照自己的需要，彈性運用既有的架構。
