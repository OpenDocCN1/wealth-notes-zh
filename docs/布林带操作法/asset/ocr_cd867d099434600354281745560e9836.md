# 第 22 章

# 當日沖銷

在當日沖銷的圈子裡，包寧傑帶狀運用得非常普遍。不論是每檔跳動走勢圖或其他時間架構的走勢圖，都完全適合採用這項工具，而且可以透過不同方式運用。關於技術指標方面，採用包寧傑帶狀的大多是趨勢或動能指標。成交量指標雖然也適用，但當日沖銷者較少用。

挑選哪種走勢圖？這是當日沖銷是否能夠成功的重要關鍵之一。每檔跳動圖是最詳細的走勢圖，多數交易者手邊都會準備一份跳動圖，供短線進出參考之用。除了成交價格之外，這類走勢圖應該也標示買進或賣出報價，雖然這些報價會讓交易較熱絡的股票走勢圖看起來相當繁雜。平滑的跳動圖經常會造成誤解，使得交易者不自覺的相信價格結構呈現根本不存在的連續性。跳動圖涵蓋一、二天的行情，通常沒有問題，但股票交易如果非常熱絡，圖形可能太過繁雜而難以運用。在這種情況下，或許應該採用時段更短的圖形，例如：半天。
