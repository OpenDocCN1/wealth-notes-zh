# 表 18.3 成交量指標計算公式

能量潮 = 成交量×變動符號
成交量-價格趨勢 = 成交量×變動%
負値成交量指數 = 如果成交量下降，累積價格變動
正値成交量指數 = 如果成交量增加，累積價格變動
盤中強度 = (2×收盤價－最高價－最低價)/(最高價－最低價)×成交量
承接／出貨 = (收盤價－開盤價)/(最高價－最低價)×成交量
MFI = 100－100/(1 + 正値價格×成交量總和／負値價格×成交量總和)
VWMACD = 12 期成交量加權平均收盤價－26 期成交量加權平均收盤價
VWMACD 訊號線=VWMACD 的 9 期指數平均
