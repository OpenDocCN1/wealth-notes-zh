# 第 18 章

# 成交量技術指標

關於我們建議的方法或你所採用的方法，如果希望稍作調整，本節的資料非常實用。如果讀者患有數學恐懼症，可以考慮省略本章的後半部分，但至少應該閱讀隨後幾段。

對於技術分析來說，成交量指標屬於最重要的指標類別之一。它們在分析架構內引進一項新的自變數——成交量——直指供、需方程式的核心。在某種程度內，所有的成交量指標都反映一個根本觀念：「量」是「價」的先行指標。舉例來說，在股票打底過程，精明的投資人會慢慢承接；在漲勢的末期階段，精明資金會在頭部發生之前出場。

成交量指標在運用術語方面遭遇很大的困擾。對於任何兩套交易軟體，相同名稱通常都不代表相同東西。為了避免誤解，表 18.1 列舉一些成交量指標名稱與發明人，至於相關計算公式，請參考表 18.3。如此一來，讀者就可以確定交易套裝軟體與我們討論的成交量指標是否相同。
