# 第 16 章

# 交易方法 I：

# 價格波動率突破系統

關於包寧傑帶狀的運用，本書準備提出基本構想完全不同的三套方法。我們不能說哪套方法最好，因爲這完全是個人偏好的問題。每種都試試看。不妨根據自己的喜好修改。觀察這些系統提供的交易機會，看看自己是否能夠接受。

我們將利用日線圖——也是在操作上的主要時間架構——說明相關技巧，但短線交易者也可以把這些技巧運用到小時走勢圖或 5 分鐘走勢圖，投資人則可以考慮採用週線圖。事實上，只要按照使用者的風險／報酬準則進行調整，然後依據使用者的交易方式與交易對象進行測試，不論哪種時間架構都應該不至於造成實質差異。

我們爲什麼不斷重複強調個人化的重要性？爲什麼特別注重風險／報酬參數的設定？因爲一套系統不論多麼棒，只要使用者覺得不對勁，就不可能成功。所以，只要覺得不對勁，你很快就會發現相關方法不對盤。
