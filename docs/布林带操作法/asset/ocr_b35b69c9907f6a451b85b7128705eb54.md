# 第 15 章

# 擠 壓

前文已經討論如何運用包寧傑帶狀來協助診斷頭部與底部排列，並且觀察漫步帶狀邊緣的動態走勢。第 IV 篇還會提供一些技術指標，藉以擴充我們的決策矩陣，但首先希望在此討論一項重要的包寧傑帶狀單獨運用——擠壓（The Squeeze）。

在包寧傑帶狀的內容範圍內，「擠壓」引起的爭議最大，也是最值得重視的論點之一。包寧傑帶狀往往會出現一段延伸性的緊縮走勢；換言之，帶狀寬度變得非常窄，經過相當期間之後，行情又突然變得劇烈，帶狀寬度也隨之放大。本章準備先探討「擠壓」現象的意義，提供某種衡量工具。其 vítimas，我們準備討論價格波動率的一些背景資料，並考慮如何針對擠壓現象進行交易。

包寧傑帶狀是由價格波動程度決定，擠壓現象則是純粹反映價格波動。一旦價格波動率下降到歷史最低水準，就進入擠壓狀況。帶寬指標（表 15.1 的定義）可以衡量擠壓現象①。就
