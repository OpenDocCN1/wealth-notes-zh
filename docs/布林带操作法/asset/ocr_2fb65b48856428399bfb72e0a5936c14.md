Overbought 超買 價格上漲幅度太大、速度太快的情況。過去這個名詞是指非常極端的情況。

Oversold 超賣 超買的相反情況。

Pairs 一對 性質相反而相互匹配的兩種證券——避險基金經常利用這類投資沖銷風險。

%b 顯示最近成交價相對於包寧傑帶狀位置的技術指標。如果最近成交價位在包寧傑帶狀上限，%b 等於 1.0；如果最近成交價位在中心點，%b 等於 0.5；如果最近成交價位在包寧傑帶狀下限，%b 等於 0。計算公式為（最近成交價−包寧傑帶狀下限）／（包寧傑帶狀上限−包寧傑帶狀下限）。

Persistence 堅持程度 最近 n 天期間內，某指標讀數呈現正值的發生頻率。經常是指盤中強度指標而言，這是指最近六個月內，資金流量呈現正值的天數百分比。

Pivot 樞紐 強勢股的相對強度曲線呈現平坦狀的整理走勢，隨後將恢復明確的趨勢。另外，勁道變動指標顯示的折返訊號。

Point and Figure 圈叉圖 一種價格走勢圖，只記錄價格資料，完全不考慮時間。參閱 Bollinger Box [包寧傑方格]。
