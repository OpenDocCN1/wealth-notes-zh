# Relative Strength 相對強度

相對強度是指某投資標的相對於指數或一籃標的的價格表現。就最簡單的例子來說，某股票的價格除以 S&P 500，就代表該股票相對於 S&P 500 的表現。同理，所謂的相對強度，也可以比較兩支股票或投資標的的價格表現。

# Relative Strength Index (RSI) 相對強弱指數

韋達（Welles Wilder）發明的技術指標。這是比較某證券在特定期間內收盤價上漲量與下跌量之間的關係。實際上，這代表證券強勢程度與弱勢程度之間的比率。參閱 Money Flow II [資金流量Ⅱ指標]。

# Resistance Area 壓力區

走勢圖上，位在目前價格之上的特定區域，可能阻止價格上漲。壓力區經常是過去的密集交易價位，由於很多投資人在此買進，這些部位目前都處於虧損狀態，一旦價格重新來到這個區域，投資人就可以解套賣出，使得價格漲勢受到阻力。

# Retracement 折返

主要趨勢的反向修正走勢。折返走勢的幅度，經常是主要趨勢幅度的三分之一、二分之一或三分之二。很多人利用費伯納西數據來計算折返目標。

# Risk-Adjusted Return 風險調整後報酬

如果負數貝他值大於 1，則把證券的年度化報酬率除以負數貝他值。原則上，風險調整後報酬就是下檔價格波動率經過調整之後的年度化報酬率。
