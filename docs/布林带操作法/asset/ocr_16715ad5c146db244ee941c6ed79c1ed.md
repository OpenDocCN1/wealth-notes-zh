Transaction Costs 交易成本 進行交易所需要的成本——主要是滑移價差與佣金費用。

Trap 陷阱 一系列的狀況或價格走勢，使得交易者建立錯誤部位。「多頭陷阱」(bull trap) 就是一個例子，價格向上突破，使得交易者誤判行情將走高，結果價格在向上突破之後又反轉下挫。

Trend 趨勢 價格的大體發展方向。

Trend Line 趨勢線 走勢圖上繪製的直線，藉以協助判斷趨勢發展方向。趨勢線通常都由重要高點（或低點）銜接而成。

Triangle 三角形排列 價格進行密集整理的區域，價格波動率通常都會穩定下降。

TRIN 參閱 Arms Index [阿姆斯指數]。

Typical Price 代表性價格 特定時段內最具有代表性的價格，通常採用某種平均價格。常見的計算公式包括：(最高價+最低價+收盤價) ÷ 3 或 (開盤價+最高價+最低價+收盤價) ÷ 4。

Upside 上檔空間 預期的價格最大漲幅。通常是風險／報
