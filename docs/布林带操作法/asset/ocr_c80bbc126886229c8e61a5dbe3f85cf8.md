我希望藉此機會感謝馬克·柴京（Marc Chaikin）、史提夫·路索（Steve Leuthold）、唐·沃登（Don Worden）與吉姆·葉慈（Jim Yates），他們讓我瞭解很多技巧與概念，尤其是亞瑟·美林（Arthur Merrill）所設定的超高標準。

本書走勢圖與測試程序所採用的資料，都由布里集公司（Bridge）透過布里集網站（Bridge Station）http://www.bridge.com 提供。大部分測試都採用微軟的 Excel 軟體進行。本書的走勢圖大多透過一種公開的科學繪圖軟體 gnuplot 繪製。我利用微軟的 Visual BASIC 語言編寫 gnuplot 處理軟體，然後透過 DDE 下載布里集的資料，最後編寫走勢圖的資料檔。

公用軟體讓我可以活躍於電腦領域，我由衷感謝很多傑出的程式設計師，他們無私地貢獻自己所研究的作業軟體，例如：Linux 與 gnuplot。如果讀者需要 gnuplot 的進一步資料，請上網查詢（http://www.gnuplot.org）。如果讀者希望查詢公用軟體，下列兩個網站是很好的起點：The Open Source Initiative（http://www.opensource.org），Free Software Foundation（http:// www.fsf.org，自由軟體運動的創始者）。
