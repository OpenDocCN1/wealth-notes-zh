# 第 6 章

# 歷史緣由

交易帶狀（或包絡、通道……等名稱）的運用已經有很長一段歷史，發展過程很有趣。本章只準備討論一些重點，讓讀者大致明白這項技巧的起源背景，瞭解它在整個技術分析架構上的地位①。

我們或許應該由名詞定義著手。交易帶狀（trading bands）是沿著某中心趨勢之上、下建構的帶狀，例如：以某移動平均線爲中心，分別乘以某百分比而向上與向下平移（譯按：界定交易帶狀、包絡或通道之上、下兩個端點，譯文分別稱爲「上限」與「下限」）。交易帶狀的上限與下限不一定對稱，但是兩者必須以某中心點做爲基準。包絡（envelopes）是建立在某價格結構的上、下兩側，例如：包絡上限定義爲每天盤中最高價的移動平均，下限定義爲每天盤中

① 技術分析的歷史發展過程模糊不清。我已經儘量嘗試把一切解釋明白。很多原始資料最初刊載於通訊刊物或輔助論文。眾多文獻已經遺失或被故意毀損。這方面的知識與技巧很多都密而不宣，實際瞭解這些技巧的鑑賞家在過世之後也經常把「密技」帶入地下。各方面的說法往往相互衝突，那些能夠統合各種說法的人，又經常別有意圖。如果任何人能夠就帶狀、包絡，以及相關指標或系統提供額外的資料，我們將非常感激。
