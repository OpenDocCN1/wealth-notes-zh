# Double Bottom 雙重底

一種底部排列，價格經過一段下跌之後，向上反彈，然後又下跌而重新測試先前的低點。如果測試成功，價格繼續上漲，一旦穿越兩個低點所夾的高點，雙重底排列即告完成。

# Double Top 雙重頂

一種頭部排列，價格經過一段上漲之後，向下修正，然後又上漲而挑戰先前的的高點。如果挑戰失敗，價格反轉向下，一旦穿越兩個高點所夾的低點，雙重頂排列即告完成。

# Elliot Wave 艾略特波浪理論

這是 R. N. Elliot 發展的一套理論。他認為，所有的市場活動都呈現有秩序的型態，包括 5 個主要波浪與 3 個修正波浪。這種型態可以適用於所有的時間架構；換言之，任何波浪都可以進一步細分爲 5-3 的結構。這種自我對稱性所反映的市場碎形性質，廣受後來的研究者推崇。艾略特波浪理論與甘氏理論（W. D. Gann）可以視爲是市場內部結構研究方法的代表。這些方法經常被認定爲創造財富的途徑。事實上，這些理論非常「能言善道」，似乎可以解釋過去所發生的—切，但對於未來則很難提出具體看法。

# Envelopes 包絡

圍繞在價格結構上下的帶狀，但沒有反映中心趨勢。舉例來說，沒有藉由價格移動平均來反映中心趨勢而界定相對高點與低點。參閱 Bands [帶狀]與 Channels [通道]。
