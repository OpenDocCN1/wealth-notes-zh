# 第 14 章

# 漫步帶狀邊緣

我們已經談論了頭部與底部排列，但持續發展的走勢又如何呢？當趨勢持續朝某個方向發展，這可能是最難以處理的困境。關於帶狀、包絡或通道，一旦價格觸及帶狀上限或帶狀下限，很多人就盲目的賣出或買進，這或許是運用上最嚴重的錯誤之一。如果這類觸及帶狀邊緣的現象，屬於更大反轉型態的一部分，或不能得到技術指標的確認，也許真的代表賣出或買進訊號——但也可能不是。當價格走勢觸及帶狀邊緣，這個現象本身絕對不足以代表交易訊號。
