Index[資金流量指數]與 Volume Indicators[成交量指標]。

Advance-Decline Line 騰落線 每天計算上漲家數減去下跌家數的差值，然後累積加總到前一天的餘額，以這種方式繪製的曲線，稱爲騰落線。相對於大盤指數來說，騰落線的長期表現不佳，很多交易者認爲這是沒有多大用途的指標。可是，如果配合價格帶狀運用，21 天期騰落線是相當不錯的時效工具。

Alpha α值 剔除整體市場的影響之後，α值衡量個別證券的報酬。「股票交易者網站」(EquityTrader.com) 分別計算上漲與下跌行情的α值。

Arithmetic Scale 算術刻度 圖形座標採用算術的刻度。不論價位如何，圖形上的相同距離都代表相同點數。參閱 Log Scale [對數刻度]。

Arms Index 阿姆斯指數 這是理察·阿姆斯 (Richard Arms) 發明的技術指標，顯示股票市場買進與賣出力道的消長。計算公式考慮的數據包括：上漲家數、下跌家數、上漲成交量與下跌成交量。指標讀數 1.0，代表買、賣力道均衡；讀數大於 1.0，代表賣出力道較強；讀數小於 1.0，代表買進力道較強。由於股票市場存在長期的上升偏頗趨勢，所以指數的長期平均值大約是 0.85。這是有趣的時效工具，而且可以另外建立開放型阿姆斯指數。這項指標又稱爲 TRIN。計算公式：(上漲家數／下
