# 2、如何选择创业合伙人

首先谈一个话题，什么样的人适合一起创业？该股权分配之前有必要说一下，对于合伙人的选择问题。

我创业选择合伙人必须有三点，

+   - 第一，价值观一致和事业方向认同。
- 第二，人力资源互补。
- 第三，大家能开诚布公，有什么就说什么。我拒绝那种把话藏在心里，背后又不断嚼嘴的人。

大部分创业团队散伙要么是由于创始团队价值观不一致或不认同，产生严重分歧；要么是其能力或资源对公司发展没有带来核心价值，被迫出局。股东之间的理念、性格以及信任程度决定了公司的生死，不能扭咸椒待，也合作不了多长时间。在找合伙人之前应该问问自己，为什么要找合伙人？
