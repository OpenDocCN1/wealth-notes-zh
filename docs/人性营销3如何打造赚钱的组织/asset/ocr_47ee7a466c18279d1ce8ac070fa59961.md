# 第三，大量启用年轻人而又逃恋工作的人。

很多年纪大的人太顾家了，已经没有拼搏的动力了。我们给他们讲工作很重要，他们非常世故，也学会了敷衍，听再多，有文化也没什么改变。我们招聘年轻的、有热情的人就行了。很多时候选对人最明智，改造人是非常愚蠢的行为，因为我们的时间非常宝贵。

# 第四，结交到什么样的人，就有怎么样的未来。招聘到什么样的人，公司就有怎么样的未来。

最好招聘在学校的时候就相当过关的，这些人可以迅速培养成领导者。公司是需要很多具有领导精神的人，有领导精神的人更加有责任心。

# 第五，对员工严格要求，拒绝员工迟到，给每一个员工的工作施加压力，没有压力就没有动力。

没有人可以轻轻松松赚钱。大家以为网红只要裸露就能赚钱，这都是肤浅的认识。网红都是经过大量努力的。大家不拼命的工作，公司盈利能力肯定下降。在公司天天宣传排命工作，员工实习惯了也就会拼命了。辛勤工作不会致人于死地，无聊、闲着的人才会早死。人活着注定要生活在压力中，压力无处不在。不管是战争年代，还是和平年代，皆是如此。生于忧患，死于安乐，只有主动迎接压力的人才能过好人生，干好公司。
