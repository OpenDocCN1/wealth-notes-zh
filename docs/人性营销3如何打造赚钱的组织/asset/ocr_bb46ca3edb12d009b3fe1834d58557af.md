如果你做的工作发挥的是你的弱项，那么你就倒霉了。你找不到任何快乐，你也不可能做好这份工作。其实每一个人都有他擅长的地方。人的成功就是在自己擅长的地方工作。如果你不擅长你的工作，那么必须找到你擅长的的工作。

# 第二，只有当你找到你擅长的工作的时候，你才有机会把你的工作变成一个娱乐活动，你在工作中能找到成就感，又能赚到钱，这个时候你就欲罢不能了。越是欲罢不能，你的业务能力就会疯狂提升，然后你工作起来就如同玩游戏一样，你会爱上你的工作。

# 第三，要习惯性的放弃垃圾客户。

这个世界很大，有很多优秀的客户，我们要想尽办法为优秀客户服务，我们才能赚到很多钱，并且自己很快乐。不要为没钱的客户服务。没钱的客户是非多。

我以前做了几个实体项目，拖欠工程款的非常多。后来我做了电商项目，从来没有拖欠款项的事情，最多只有中通快递、顺丰快递的周结账、月结账，基本没有拖欠现象。

与没钱的客户在一起，就会有很多垃圾事情，比如送礼、醉酒、要钱等等各种事。这些事做了，又不能让自己赚到更多的钱，只是拿到自己本来就应该拿到钱。而在优质客户面前，这种事情是不会出现的。
