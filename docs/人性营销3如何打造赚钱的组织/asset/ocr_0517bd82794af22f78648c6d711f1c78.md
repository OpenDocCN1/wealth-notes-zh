# 20、钱只是正道的附加产品而已

我们在刚创业的时候，追求的是金钱。有了钱了，过好日子，吃好饭，有点社会地位，带点团队，做个企业，有点权力，感觉很好，这就是谋食的阶段。

为什么很多人的企业做不大？还有就是做大了没有动力了，容易倦怠，就会出大问题，然后倒闭了事。倒闭倒还好，有的甚至会给自己惹一身麻烦。这一切就是因为企业主该获得的都获得了，又没有新的目标导致的有钱了，有地位了，该享受的都享受了，人还没死，活得就特别无聊。所以，真正想成为一个企业家，就不能只知道挣钱，要给自己找一个道。

这个道，就是你要成为一个什么样的人，不断修炼自己的人格。要为社会解决一个什么样的的问题，为社会做出什么样的贡献。终其一生，要为社会把这个问题解决到极致，永无止境的追求。
