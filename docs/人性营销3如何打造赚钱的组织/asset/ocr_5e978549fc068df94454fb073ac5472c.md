# 39、如果一个人只有名，而无实的东西，这个人就没有名

# 学员：

老师，我是裴下面的一个市场领军人推荐我的。他说，总裁，你过来肯定会不一样，因为你各方面起点比较高，所以我就过来了。您太有智慧了。能够跟着一个可以赚钱的老师，比我们这些所谓职场总裁牛逼，我们没有钱，只有一个虚名。

# 陈昌文：

所谓实至名归，是先有实才有名。如果一个人只有名，而无实的东西，这个人就没有名，这个名只是自己给自己封的一个假名。社群里有赚钱的老师，年入千万级别的也有，自己找出来学习，多听课。空心态，空掉一切。如果认为自己很厉害，有包袱，则很难前進。
