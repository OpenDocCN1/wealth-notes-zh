# 18、做到这两点，就好像成为一个企业家

做到这两点，就可以成为一个企业家。

一、做一件事不感到厌倦，愿意永远做下去，不管遇到什么挫折都不断的干，会把一件事情干到透彻。把一件事情干透彻了，自然成为这个领域的专家，就靠这一件小事去赚钱。能赚钱，你就可以养活自己，赚的多了，还能养活两个员工，能养活两个员工，最多算是小老板，是成不了企业家的。

那么如何才能成为一个企业家呢？就拿出来第二点。

不厌其烦的去教导新人，让新人也会做这件事，并且能让新人超越自己。

所有的企业家本质上都是教育家，都是引路人。假如你只是自己会，不愿意教别人，也懒得教别人，你就只能做个小老板。假如你不断的教人，教了很多人和着自己混，永不厌烦的教，总是有会学会出来，并且跟着你做事，这样你就可以做强做大。
