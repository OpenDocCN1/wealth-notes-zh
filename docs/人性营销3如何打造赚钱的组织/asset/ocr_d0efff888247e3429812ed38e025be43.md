# 1、带着大家赚钱，要有道德，有人格魅力

企业家关心的是组织的问题，是用人的问题，是策略、思维的问题，是项目、方法的问题，是选择的问题，是因队的问题，是矩阵的问题，是集团化的问题，是同盟的问题。

企业家的思维、思想不行，则什么都不行，企业家是靠思想、智慧、思维活着的。

企业家要不断的培养德才兼备的人才，找到德才兼备的人才，吸引德才兼备的人才。不要战争，要和平，要发展经济。
