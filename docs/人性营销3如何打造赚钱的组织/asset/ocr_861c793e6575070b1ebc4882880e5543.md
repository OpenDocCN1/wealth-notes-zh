# 1、如何把招聘这件事做对

公司的人是公司最重要的资产，不管是国家，还是企业，只要有了人才，就有了未来。

从春秋成国秦柔国的崛起，西汉刘邦的崛起，三国曹操的崛起，都揭示了人才战略获胜的结果。现代公司要想成功，都要人才战略的获胜。

我在创业的过程中赔过很多钱，也赚过一些钱，赔钱的原因差不多都是招聘失败。

下面细数一下我犯过的错误。

一、刚开始创业的时候，我甚至没有搞清楚我到底要干什么，只知道我要干互联网。于是我就招聘了做网页的人、写程序的人，花了好几个月把这些人招聘起来，非常盲目，不知道让他们干什么，浪费了大量的金钱。所以我们一定要知道我们到底要干什么，有了具体项目的时候，才开始招聘对应的人才。
