# 智慧与经验来武装自己。

什么是大数据，就是你知道的方法、经验、智慧多了，你就可以用这些东西来武装自己的人生。在互联网上做生意也是这样，你必须借用别人的经验，但别人是不会主动教你，也不会免费教你，你就必须得付费。天下没有免费的午餐，不管你喜不喜欢这顿午餐，你都得付费。养成付钱的习惯才有赚钱的习惯。什么事情都是这样，没有付出就没有收获，只有付出才有收获。

你或许会讲，我付钱了并没有收获，我以后不付钱了，这是愚蠢至极的想法。不是每一次都有收获，或许下一次就有收获了。我们付钱干什么？就是付钱让别人帮我们解决问题，而不是我们自己去解决问题。什么是老板，老板就是付钱让别人帮我们解决赚钱这个问题的人。你根本不用自己解决问题，你只要养成付钱的习惯，就有人帮你解决问题，就能养成赚钱的习惯。这个逻辑是通顺的，我们是实践得来的，但对于普通人来说是逆反个性的。
