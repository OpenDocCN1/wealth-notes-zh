# 11、真正的赚钱模式是，找到一帮会赚钱的人来赚钱

真正聪明的人就是无为而治，教员工把一切都干好。

员工能干好吗？员工不能干好。怎么办？两个选择，开除或者培养。其实最好的办法就是开除，开除一个员工，我们就有多余的资金顶来招聘更加优秀的员工。

真正的赚钱模式是找到一帮会赚钱的人来赚钱。我们找好方向，考核好这些优秀的人的业务能力就行了。赚到钱了，就分一部分给优秀的员工。对于优秀的员工，分钱一定要狠，就是要分到他感觉不跟你干就是傻子，背叛你就是没良心的程度。
