# 1、团结一切可以团结的力量

很多人都想赚大钱，但却不知道赚大钱的本领到底是什么？
所以不管做什么，学什么，都不能赚到大钱。

我的父母曾经让我去学医生，他们讲：这个医生学会了，就衣食无忧了。我还听见了一些人说去学律师，或者程序员，这些岗位挣的钱多。其实这都是错误的方向。

有的人能做一个项目，卖一个产品，带一个团队，生活能比一般人过得好，赚的钱也比普通人多，但这也不是赚大钱的方向。有的人就拼命学习管理，认为管理能让自己赚大钱。我就碰到一个高材生，他的梦想就是学会管理，然后成为一个高管赚大钱，这也是错误的方向。

事实上，要想收入比普通人高很多，非常简单，记住两个字“合作”。深入一点讲：团结一切可以团结的力量。只要自己有赚头，就不断的去团结人，找到跟自己一起干，那么你就很容易赚大钱！就这么简单。

也就是说，赚钱的精髓，不在于你学得什么技能，不在于你会不会做一个产品，也不在于是你会不会销售，甚至不在于你会不会管理，只有一招，就是不断的与人合作。这个世界上，最难的事情就是与人合作，特别是与不同价值观、不同阶层的人合作。

为什么大部分人的企业都做不大？因为他只能跟他看得顺眼的人合作。稍微不顺心，他就暴跳如雷。岂不知，一个企业需要有只能做执行的员工，也需要有有企业家精神的职业经理人，更加需要比自己聪明的投资人参与。

高明的老板就是能把不同阶层、不同理念、不同技能的人整合到一起工作的人。最聪明的可以把一群精英整合到一起，让他们自动工作，自己只负责团队的使命与梦想。

如果你打造的团队，还需要你亲自参与具体的工作，那么你就永远赚不了大钱。你需要做的仅仅是缺什么，你就找什么，然后把这些要素组合起来，形成一个完美的团队，你在旁边看着就行了。甚至最高明的人是连“找什么”这件事也有专业的人来代劳，自己就完全全做到无为而治，打造了一个完完全全的自动赚钱机器。

总而言之，大家记住一句话：赚大钱的方法就是不断的找

入合作，而不是自己去学一门技术，或着自己去领导一个团队参与其体工作。至于靠一门专业技能去赚大钱，这就更难了，除非你的水平达到世界级顶尖，所以我不建议大家靠一门技能去赚大钱。

# 2、互联网时代千万不要单打独斗

一个人也能赚钱，当你懂得一些互联网营销技巧的时候，你的日收入也能破几万。互联网赚钱，微商也赚钱，确实比实体行业赚钱容易多了，靠的是智力生产，卖的是虚拟服务。最重要的是很多人都不懂，也不相信，于是这个行业竞争不是那么激烈。一个中学生、大学生都能在这个行业赚钱，于是出现了很多年轻人，二十几岁就能买车、买房，这些人就是靠互联网赚钱。

靠互联网赚钱的人不要单打独斗。因为大家没有经验，所以很容易陷入单打独斗的模式。单打独斗能赚钱，确实也能过得很滋润，但我们必须开启群体奋斗模式，团队的力量绝对比个人的力量大得多。一个个人不可能修一座大厦，不可能修一座

大桥，但一个团队可以。阿里巴巴，一个人是建立不起来的。
华为，一个人也是建立不起来的。所以我们必须组建团队。

我们能挣钱，我们的钱就必须用来搞招聘，招聘更多的人
聚焦到我们的项目上，不断地搞营销赚钱，越早越好。包括后勤人员，大家都来搞营销，老板亲自带队去搞营销。我建议老板就是专注管理，根据自己的现金流不断地扩大自己的团队，然后亲自带领大家搞营销赚钱就行了。

我建议每个互联网时代的企业家都要把自己的公司扩张到五百人以上，人数是有优势的。你如果没有扩张的意识，你的团队就很难增长。如果你有扩张的意识，你的团队长得就比较快。

很多企业家容易犯的错误就是觉得人多了不一定赚钱，人少，赚钱多。而且他在实践的过程中招聘了一些不合格的人或者新人，刚开始不懂他的业务，这些人就是纯粹的支出，没有为公司带来效益，老板就可能认为扩张不赚钱。于是就不扩张了，就用自己的老员工混日子，这是绝对错误的认识。

必须意识到韩信将兵，多多益善，必须意识到人多力量大。
扩张团队的时候是有一些牺牲，但这些牺牲都是有益的，适应了过后，只会让你赚到更多的钱。

所以我们必须尽心尽力地把团队做到五百人以上，组织更多的人跟着我们奋斗。组织更多的人，我们才能轻易的成为亿

万富翁。

# 3、收入高，不等于你是一个企业家

必须成为企业家，而不是高收入的个人。有的人的志向是成为一个高收入的人，比如一个月能赚30万。一个个人做到月赚30万，在互联网上很多，能够带几个个人跟自己一起干的，做到这个收入的不在少数。但是假如这个团队离开了你，就不能运作了，你就是一个高收入的人，而不是一个企业家。你会累死在你的工作岗位上，你会工作到死。只要你不工作了，就没有钱了。我不希望大家成为这样的人。

我们必须成为一个企业家，企业家就可以培养一些职业经理人，打造一个管理层为自己工作的人。企业家可以离开自己的公司，更多的思考战略层面的问题，而不是天天在技术上优化。战略问题统统交给管理层，交给职业经理人。自己只搞方向性的东西，编制制度的东西，编理论性的东西。

要成为一个企业家，要投资自己的团队，让团队给我们赚

钱，而是我们自己去管理，去赚钱。慢慢的，成为一个资本家，成为一个投资人，看着他们把公司做好，看着他们给自己赚钱就行了。

年轻的时候，我们精力充沛，带着团队一起赚钱。年纪大了，我们长时间的持续死磕，身体也是受不了的。如果我们一放松，收入就滑坡，那我们还不是一个企业家，我们打造的团队有问题。我们的经营思路还有待优化，我们的企业结构还有问题。

我虽然热爱工作，但是我拒绝工作把我累架了。我工作的目的是打造自动赚钱机器，帮助我的核心伙伴打造自动赚钱机器，帮助我的客户打造自动赚钱机器，而不是自己成为自动赚钱机器的一部分。

# 4、社会关系，要强过自身能力

在社会上混了这么多年，我们普遍认为鼠人打交道的工作，其实是最优于跟物打交道的工作的。人类之所以能够战胜自然，主要避免，关键还是在于协同、合作。

单个人类不管多强大，技术大拿脱离了社会，你还能徒手建一个太空堡垒不成？其实你连铁都炼不出来。这不是技术的问题，而是很多工作必须有很多协作才能完成。

当老板，本身就是一个组织人协商与合作的工作。就人生来说，你能走多远，能有多大成就，关键得看你凝聚在一起，或者是你能够整合哪些人给你做事。也就是社会关系要跳过自身能力的，当然我们也可以把经营关系、社会交际看做是一种能力。

我个人是天天修炼社交能力、营销能力的，只要跟客户的关系搞好了，客户就会买单。只要跟员工的关系搞好了，员工就会主动做事，有时候比给钱都好使。

我也喜欢从事营销工作，这是一个和人接触得比较多的职业，比技术岗位更有利于建立社会关系，更有利于锻炼社交能力。

营销是个很大的范畴，如果你也想把营销做好、做到位，其实需要更多对人性、对社会的了解。这样，人类学、社会学、传媒学，包括历史、哲学、艺术，这些全部都要纳入学习的范畴。

我们得去研究人的欲望，人会被哪些因素吸引，除此之外，还得研究社会，包括伦理道德，弄清楚各种观念、习惯的成因。这样你才能解决一个看起來十分简单的问题——选择。人们会选择什么和为什么那样选择？只有我们明白人们怎么选和为什么，

才可能去设计一个他们非选不可的选项。

营销是有意思的，当有一天，你对人性、对社会有很深的理解之后，你能做的何止是多卖出去一些商品呢？所以，要尽量多做跟人打交道的工作。
