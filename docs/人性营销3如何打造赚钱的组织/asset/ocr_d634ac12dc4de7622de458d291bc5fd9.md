我们尽量给员工好的待遇，年终了尽量多给员工奖金。企业不养没用的、贪玩的闲人。一个总是想着玩，基本就被社会淘汰了。他的经济水平、道德素质都不会高到哪里去。

# 5、如何团结更多有智力的人

让大家和谐的生活在一起，让大家和谐的工作在一起，一起奋进，相互帮助，竭尽全力的把工作干好。
