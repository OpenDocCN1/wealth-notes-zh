# 应该招聘熟练的员工。

谁喜欢培训新手，我们就鼓励他去培训，而且要在一周之内搞清楚这个员工能不能为公司做出贡献。若是不能做出贡献，坚决开除。为了不违法，我们必须付给他这几天的工资，这已经是一个损失了。

老板的一个非常重要的功夫，就是在短时间内找到合格的人。公司应该一直不断的招聘，宁缺勿滥，只招聘有用的人，一定不要有淡人数的心理。

所以新员工的试用期必须控制在一周以内，拖时间就是拖掉自己的生命，拖掉企业的未来。我们能走多远？看我们与谁同行。仔细看看你周围的那几个人，他们到底是资产呢，还是负债？
