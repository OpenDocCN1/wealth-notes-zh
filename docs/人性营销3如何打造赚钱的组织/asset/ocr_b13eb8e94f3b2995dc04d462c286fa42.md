# 团结一切可以团结的力量

当领导不在于能管理别人，而在于能管理好自己。一个노
能管理好自己，自然就有同样能管理好自己的人过来跟你一起做事。优秀的人，吸引优秀的人，渣子吸引渣子。知道自己不行，立马改正，善莫大焉。

公司要专业化，我只做思想传播、文化服务、投资理財。
我们公司的资产就是我的思想，每一个人都在卖我的思想。当然，这个思想会演化出策划组、推广组、语音组、视频组，会演化出一些我们投资的公司。每一个优秀的人才，在我们公司都将受到重用，都有机会被培养成老板。

愿意来我公司的，比愿意走的人多，就说明公司在进步。
我能吸引到多少优秀的人才跟我共度人生，就看出我自己的水平有多高。以铜为镜可以正衣冠，以人为镜可以明得失！
