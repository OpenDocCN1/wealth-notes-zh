# 21、修好了天爵，才有人爵

一个人的修养决定一个人的成败。失败都是有原因的，成功也是有原因的。

周亚夫曾经帮助汉景帝平定吴、楚七国叛乱。汉景帝为什么要用他？因为汉文帝去每个军营查看谁把军队治理得好的时候，去别的将军的军营，别 的军队的首领都是出门迎接汉文帝。而到了周亚夫的军营，周亚夫不但不迎接，还不许皇帝的马在军营内奔跑。见面了，也不下跪，仅仅以军礼拜见皇帝。

汉文帝就认为，其他将军事理军队跟儿戏一样，而周亚夫才是一个可靠的将军。死的时候，就告诉汉景帝，如果要打仗，就重用周亚夫。后来楚越叛乱，汉景帝就启用了周亚夫。周亚夫果然不负众望，不到三个月就平定了叛乱。
