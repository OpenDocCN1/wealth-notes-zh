# 8、老板就是付钱让别人帮我们解决赚钱这个问题的人

由于我自己天天搞招聘工作，见过不少人，也带过很多团队，也见过不少笨的人总是喜欢自己创新，喜欢发挥自己的思维，结果经常把事情搞砸，搞得客户不喜欢，领导也不喜欢。聪明的人就是按规矩、按规则做事，大家都非常喜欢，客户也很喜欢。

老前辈早就定下来规矩了，老前辈也知道如何解决问题，但是我们有的大学生以为自己很了不起，怀才不遇，就是与众不同，要发挥自己的智力，结果经常浪费大量的时间给公司生产垃圾。

孔子讲过，愚而好自用，贱而好自专，就是说愚蠢又卑贱的人喜欢凭自己的主观臆想做事。

其实你碰到的所有赚钱问题，别人都碰到过。愚蠢的人是自己去发明电灯，以为这样省钱。聪明人直接购买电灯，直接点亮，然后就可以 了。我们必须不断的向别人学习，用别人的
