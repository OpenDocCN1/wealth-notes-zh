# 2、人到底靠什么能力混社会

人到底靠什么能力混社会？你可以理解成人到底靠什么能力赚钱也可以。

我把混社会需要的能力分为天赋能力、劳动能力、技术能力、研究创新能力、管理能力和领导力。

这几种能力不分高下，以赚到了钱的数量为衡量标准。世法平等，无有高下，意思就是手段不重要，重要的是自己适合用哪种能力去赚钱，就用哪种能力。
