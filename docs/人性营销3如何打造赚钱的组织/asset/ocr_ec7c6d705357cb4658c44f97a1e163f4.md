人很有可能因为分配不公而抛弃你，另起炉灶。
我们注重的是，在做的过程中，谁的贡献最大，这个股份就应该给谁分配多些。

# 第二，杜绝拖延该谈股权分配，越早明白越好。

很多时候创始人不愿意谈论股权分配的问题，这个话题不容易启齿。我们中国人都害羞，所以他们要么完全回避这个问题，要么只是说一些模棱两可的约定，比如，我们是平等的，先做好其他的事，或者说我们之间还有什么好说的，以后再说吧。如果有3个或者3个以上的创始人，这种讨论就变得更加困难了。

创始人基本上都会犯这个错误，没有在第一天就把股权的分配问题谈清楚并写下来，股权的分配等得越久就越难谈。随着时间的推移，每个人都会觉得自己是项目成功必不可少的功臣，关于股权分配的讨论就会变得越来越困难。
我的建议是尽早进行股权分配的讨论，并达成共识。

# 第三，股份绑定，分期兑现。

这个我认为是最重要的，仅达成股份比例的共识还不够。如果一个创始人拿了很多股份，但后来做事不给力怎么办？如果有人中途离开公司怎么办？股份如何处置？答案是采用股权绑定机制。什么意思呢？公司的股权按照创始人Corn在公司工作的年数和月数逐步兑现，任何创始人股票都必须待在公司做够起码一年才可持有股份。
