# 因为我们的时间最宝贵。

我们要把我们的时间放在最有生产力的地方，我们要赚钱，要解决更多值得解决的问题，帮助更多值得我们帮助的人。我们没有精力，没有时间去跟那些无聊的人对骂。如果我们选择报复他们，其实我们是在浪费我们的生命，我们的损失将会进一步扩大。

# 第六，享受付出的快乐，不要期望他人感恩。

我们付出是我们自己的事情，他们感恩是他们的事情，他们不感恩也是他们的事情，我们无权、也无理由干涉。

# 第七，对得到的帮助心存感激，必定回报别人。

为什么？因为只有这样，才会有更多的人帮你，不然，别 人骂你是白眼狼，那么你的恶名远扬，以后就没有人帮你了。

# 第八，假如你的起点非常低，不要抱怨。

因为抱怨除了浪费时间以外，还会给你产生负能量。不如把困难当成挑战，想办法克服。

# 第九，不要认为别人错了，永远都认为是自己错了。

我们能改变的只有自己，我们想要改变世界，首先要改变自己。赚不到钱，就是自己没本事，不怪经济危机，也不怪社会不好混。一个习惯性优化自己的人，必定会成长为一个事业成功的人。一个老是认为别人错了的人，终身只能一事无成。
