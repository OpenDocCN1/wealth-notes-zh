# 11、创业的五点心得

创业的五点心得：

第一，创业首先要相信自己能成功。

你都不相信自己能成功，不相信自己的项目能做成。那么你工作起来就会很沮丧。你的团队伙伴也会感觉到你不相信自己能成功，故而他们也会很沮丧，导致工作效率降低，成功就更加渺茫了。

第二，尽可能说服更多的人跟你干，人多，力量大，要学会做别人的思想工作。

老板必须是思想的巨人，也必须是行动的巨人，还必须是一个导师，你必须指导大家如何做。企业招聘一个高人帮你搞定一切，帮你赚钱，这只能是做梦，只能用来吹牛，骗骗小白创业者。
