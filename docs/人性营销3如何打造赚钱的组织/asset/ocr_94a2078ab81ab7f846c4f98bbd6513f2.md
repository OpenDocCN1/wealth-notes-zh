# 14、《恋爱与情感的智慧》也可以定位高端人士

# 学员：

一直不喜欢《恋爱与情感的智慧》，也不想卖《恋爱与情感的智慧》读书社群，这两个月把自己喜欢的《老板三法》与《论语》修完。今天听老师讲课，突然思维转变，很喜欢《恋爱与情感的智慧》，发现自己可以帮助很多类似群体，只攻高学历或创业型。自己也有很多优势，学过形象打造，学过色彩搭配，学过形体塑形，精懂厨艺，差的就是修心性。让与自己一样同类女性找到自己，精准认识自己，不断提升自我价值，而不是陷入毫无价值的情感漩涡中，突然很喜欢《恋爱与情感的智慧》。

# 陈昌文：

《恋爱与情感的智慧》也可以定位高端人士。《恋爱与情感的智慧》流量大，变现快，这是我推《恋爱与情感的智慧》的原因。当然，实在是不喜欢《恋爱与情感的智慧》的，做其它的读书社群也可以。我讲《恋爱与情感的智慧》读书社群，实际上，就是为了帮助大家扭开流量口子，降低变现难度。我其实也不喜欢谈恋爱、情感问题，但是，人呐，总是要现实点。
