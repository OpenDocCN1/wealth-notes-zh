# 15、普通人玩股票、基金，一定亏本

# 学员：

有个问题我让生气，最近一段时问啊，我家先生在网上学财经，他不和我说就买了基金和股票，三四百万。我知道了，我很生气，我这两天心情一直很低落，他说给我挣钱。我和他交流，他说我不懂，我说我有知情权吧。我这两天早上不起来，也做饭，心里不舒服，您说我该怎么办？他才学了一个多月，我也是担心。老师，百忙之中帮忙给个参考，感恩您。

# 陈昌文：

正规的基金、股票，都是可以退出 flood的。一个   月，按道理，也损失不了什么钱。您生气，是跟您老公理念问题，这个无非就是要退出，还是一直在里面玩的问题。普通人玩股票、基金，一定亏本。有人脉、关系，能找到真大哥带的人，能赚钱。或者自己是天才，很懂的人能赚钱，其他人就算了吧。
