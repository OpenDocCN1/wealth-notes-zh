# 第三个，我们换一下技术能力。

随着科技的发展，世界分工越来越细，发展出来很多需要一定技术的工作，而且社会上需要大量的技术工。

我们国家现在在产业升级，以后会更需要各种各样有技术的人才，所以只要你有技术，一般都能找到工作。如果你想混的更好，那么你必然要比大部分人的技术都更加的高明。

比如，我们团队很擅长做网络营销，包括网络推广的很多工作。如果我们出去找工作，要看我们愿意为谁干，而不是别人愿不愿意要我们，因为我们有技术。

当然有了技术，你想混的更好，还是要有与人相处的能力，包括个性是否随和，是否有合作精神，是否敬业等等。如果这些能力都具备，那么做起技术来就会如鱼得水，很快也能混个一官半职。

哪些东西算是技术能力呢？比如说电焊，比如说编写程序，比如说做社群营销，比如我们部分舅嫂项目需要制作图片，用ps等等，都是属于技术能力。

技术能力实际上是最好混社会的能力。对于个人来讲，你拥有一门技术，人也会过得稍微有一些尊严，收入也会随着自己的技能而提高。

学一门技术，对于大多数人来说是非常好一个选择。
