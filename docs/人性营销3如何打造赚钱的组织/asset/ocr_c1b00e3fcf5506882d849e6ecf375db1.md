# 3、收入高，不等于你是一个企业家

必须成为企业家，而不是高收入的个人。有的人的志向是成为一个高收入的人，比如一个月能赚30万。一个个人做到月赚30万，在互联网上很多，能够带几个个人跟自己一起干的，做到这个收入的不在少数。但是假如这个团队离开了你，就不能运作了，你就是一个高收入的人，而不是一个企业家。你会累死在你的工作岗位上，你会工作到死。只要你不工作了，就没有钱了。我不希望大家成为这样的人。

我们必须成为一个企业家，企业家就可以培养一些职业经理人，打造一个管理层为自己工作的人。企业家可以离开自己的公司，更多的思考战略层面的问题，而不是天天在技术上优化。战略问题统统交给管理层，交给职业经理人。自己只搞方向性的东西，编制制度的东西，编理论性的东西。
