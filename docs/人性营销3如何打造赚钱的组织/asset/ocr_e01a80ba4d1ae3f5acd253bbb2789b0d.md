# 8、创业初期如何分配股份给核心人员

我曾经跟一个人一起创业。我与这个人一起招聘了十几个员工，准备大干一番。而这个人倒好，把所有的股份都弄到自己手上，结果大家认为公司是他的，跟大家无关，也不愿意跟他一起吃苦了，根本就不愿意听他指挥，就散了。

我们刚创业，本来股份就不值钱，分给大家嘛。大家跟你混，本来就是为了名，为了利益、股份。你不给大家，大家怎么肯拼命奋斗呢？

那么应该如何分配这个股份呢，这里面是有技巧的。

第一，持有股份的人必须是能够独当一面的人。分摊股份本来就是为了给自己减轻压力的，如果一个人就是个普通员工的料，那么是不应该给他股份的。

第二，必须是一个一个的入股，有时间先后顺序，不要一下子给所有人股份。一下子给大家，每个人都一样，就没什么感觉了。要让他们求着你入股，然后入股者要付出金钱的代价。
