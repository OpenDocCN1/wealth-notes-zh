# 5、为什么你要掌握企业的关键技术

技术创业者实际上更有优势。比如，你懂一门技术，你就靠这门技术吃饭，然后贩卖这门技术，你就更容易赚到钱。我们懂网络推广，我们就靠网络推广这门技术，找一个产品在网络上起来，就能够赚到钱了。

我觉得技术非常重要，一般的技术人员都很少创业。我发现的现象是，很多非技术人员总是有颗创业的心，可能非技术人员工作不稳定，而技术人员工作更稳定。有些是管理人员创业，不愿意研究技术，认为只要我们有钱，招聘几个技术员来实现我们的产品，或者销售，就行了。谁做的好我们就奖励谁，谁做不好我们就开除谁，其实这都是理想主义。

在实践的过程中，当我们是一个创始人的时候，我们不懂团队的关键技术，我们就只有不断的鼓励员工努力，其实非常被动。

那么员工不努力，我们有办法吗？我们一点办法也没有。
