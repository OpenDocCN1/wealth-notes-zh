# 1、打仗不可以靠友军

我是做了好几个团队，算是摸索了一些经验，职业经理人是靠不住的，为什么？因为他们不会晚上十二点了还在考虑公司的事情，职业经理人也不会周六、周日、国庆、元旦工作，他们想的是终于要休假了，可以旅游了。

我是不给职业经理人高位的，主要是他们的人生理念跟合伙人、创业者不一样。我的合伙人大年初一还在工作，我们是为了工作而生的人，我们知道娱乐对我们毫无意义，工作与金钱才有意义。

我们不是歧视职业经理人，我也是一个团结一切可以团结的力量的人，但我知道打仗不可以靠友军，友军都是推托拉，真正要打仗还得靠子弟兵。有的人天天在我们身边，但他是陌生人，非常的陌生，一旦有点事，一旦有点责任，他们都是不愿意承担的。
