# 2、我把一切当成游戏，
团结一切可以团结的力量

创业公司，必须有人在公司里一直奋斗，一直为目的不断的奋斗，否则，这个公司很难做起来。所以，要打造一个一直奋斗的团队，永远在奋斗的团队。有几个带头人，不断的奋斗，才能让这个企业做起来，否则，是做不起来的。有内容，有产品，有营销推广，一直在干活，才能做起来，所以，我们必须调整输出的强度，要人一直干活。

我带团队，就是要超高强度的进展。你跟不上我的节奏，或者跟我半年支持不下去了，你自然就被淘汰了，就走了。留下来，都是跟我一样，能够高强度、高持续性、业绩爆表的超级战士与将军。我只需要工作狂，只需要有事业心的人燃烧自己的生命，不断的为社会创造价值的人。只问耕耘，不问收获，自然富甲天下。
