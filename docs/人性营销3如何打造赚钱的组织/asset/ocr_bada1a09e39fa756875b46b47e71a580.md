# 12、专业技术人才与管理人才的差异

管理人才大都是从专业技术人才成长起来的。我做业务做得好就成了业务经理，后来就成了业务总监，最后就自己当老板了，所谓专而优则管。为了更好地培养管理人才，下面谈谈专业技术人才与管理人才的一些差异。

# 第一，对象不同。
