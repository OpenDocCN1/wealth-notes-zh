# 7、商人的本分是什么

商人的本分就是赚钱。一个如果搞不清楚自己的本分，那么他就搞不清楚自己应该做什么。

很多创业者去参加各种聚会，或者在公司里举办各种活动，这些事情只要不是围绕着“让公司赚钱”这个核心，就是在要流氓。

一些小孩子创业很容易进入要流氓模式。比如，我曾经招聘到一个刚毕业的大学生，他就不容易进入工作状态。当我一些奇怪的建议。比如在 QQ 群里发红包活跃一下气氛，比如跟里不能只有钱，还要去娱乐。我就把他开除了。他不知道他也是我们拿赚来的钱养活的，他想要把钱花了，应该去马戏团，不应该来工作。

只要你清楚了公司只有一个目的就是赚钱，你就清楚了哪一件事情应该做，哪一件事情不应该做。这就如同照妖镜一样，可以把一切无关的事情通通灭掉。
