# 7、经历得越多，就越理智

小老板特别不容易，主要还是因为自己在不断的蜕变，还不是特别熟悉如何当老板。

比如，公司小的时候，老板招人没经验，就认为招聘不好招，优秀的人不愿意加入自己的公司。于是把一些没什么本事的人当成宝贝，结果这些没本事的人不能给企业创造业绩，白白损失公司的现金流。

我认识一个老板，由于以前坐过监狱，自己也没什么文化，居然把自己的狱友带出来开公司，结果他的狱友并没有什么本事，白白的浪费钱财在他的狱友身上。其实，这样的老板只是没经验而已。
