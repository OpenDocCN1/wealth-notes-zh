# 3、这个世界是只有你能够挣钱，你才有价值

一个人只要活的不单纯，这个人就很难有前途。因为人的精力是有限的，你的注意力只要被那些没有用的东西吸引，你就会变成一个傻子，你就浪费了生命。

比如无聊的朋友，比如没有用的聊天，比如无聊的电视剧、无聊的游戏。这些事情都会浪费你的生命，而只要你没有特别注意社会中吸引你的注意力的东西，你就注定被那些东西浪费掉你的生命，你自然就一事无成。

我们人生当中最宝贵的就是我们的时间、我们的注意力。因为我们的生命就是由时间和注意力组成的，我们可以用我们的时间、注意力换取事业，说白了就是钱。但我们也可能被别人浪费掉我们的时间，然后让我们一无所有。所以每时每刻我都在问自己是否有人在浪费我的时间？我手上的事情是不是值得继续做下去？我身边的人真的对我有价值吗？
