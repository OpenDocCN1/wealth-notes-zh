# 第四个能力是研究与创新的能力。

这种能力在科技创业公司非常常见。比如说，滴滴打车，以前没有用打车软件打出租车的，现在有人发明了这个方法，这就是一个创新。比如说，第一个做电子商务的人，这也属于创新。比如说，第一个做电动汽车的人，这也属于创新。

互联网现在比较火的各种 app，以前是没有的，现在智能手机上面有很多 app，也是属于在手机上面的一个创新，也是互联网行业里面一个创新。

腾讯拥有 QQ，后来张小龙同时又发明了微信，这也属于一个创新。

把别人的事情复制过来，重复做，这个是模仿，自己搞一个新的体系出来，就被称为创新。创新是获取利润最大的一种能力，但对一个人各方面的要求是非常高的。

# 第五个能力，管理能力。

管理能力是怎么体现的呢？你能够把一帮人组织起来，把一件事情做好，就算一个人有管理能力。做事情有计划，能够在程序和结果上体现出自己的控制力。不太要求对具体事情有一定的专业知识，而是要求有一定的 despai 关系处理能力、协调人的能力，这就是管理能力的一些体现。
