而刘邦则对众人说，我不如韩信，我不如萧何，我不如张良，带给了部署成就感。所以一个人的位置越高，越要忍受寂寞与孤独。将外面的成就转化为内心的成就感，不要与部署去抢功。

所以有人文相轻态度的 人则更多的像专业技术人才，高人都 是认为别人行。比如，你当保安当的好，你扫地扫的好，你当前台当的好，你当总经理当的好，你当营销经理当的非常好，那么你们就去做这些事，最后我当老板当的好就行了。

# 第六，情感韧性。

专业技术人才脸皮薄，而管理人才则要脸皮厚，能经受得住表扬，受得了批评，更要得了委屈、挫折。所以生活中好面子的人从特质上来说，更像是专业技术人才。

# 第七，人际态度。

专业技术人才是外方内方，而管理人才是外圆内方。外圆内方的含义是原则不变，结果不变，做事要有效果，而采用的方法与过程可是变通的，不拘泥于细节。

# 第八，事物范围。
