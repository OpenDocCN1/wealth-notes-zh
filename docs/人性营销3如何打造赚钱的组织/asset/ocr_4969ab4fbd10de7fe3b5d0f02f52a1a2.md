# 7、陈昌文内部讲话

# ——世界是由你的心设计出来的

人一定要善良，诸恶莫作，众善奉行。为什么要多做好事？因为你的念头、行为，在召唤这个世界。这个世界，就是你的世界。所以我们讲陈昌文读书社群是为了善度众生。若我们坏，我们就会召唤她狱众生。

你身上的自由意志，若恶魔的意志力苏醒，你就变成恶魔。你身上的自由意志选择在天堂，在善良的地方苏醒，你就变成天使。

这个东西如何运用？也就是你的自由意志选择在抖音看小姐姐，大长腿，这些幻象就会影响你身体这个幻象，你跟贫窭的、虚假的东西纠缠在一起，你就去了地狱。你的自由意志选择了复制赚钱的视频、直播，并且早起早睡，锻炼身体，你就生活在天堂幻象，你就变成了天使。
