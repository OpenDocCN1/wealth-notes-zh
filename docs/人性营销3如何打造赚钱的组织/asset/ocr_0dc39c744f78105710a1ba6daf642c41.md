# 5、有了异于常人的言行，自然有异于常人的地位

普通人特别在意周围人的看法，他很怕自己做了什么，从而受到周围人的批评与嘲笑。实际上，如果你想成为出类拔萃的人，你想成为人上人，你做的动作肯定会让周围人不适应。你的言行大家是不会接受的。如果你的言行大家接受了，就说明你按照普通人的价值观在说话做事。那么你的结果就是一个普通人。虽然没有人嘲笑你了，但你的代价就是成为他们中的一员。

很多人承受不了来自别人的舆论、批评、嘲笑的压力，所以一事无成。而强者是面对很多人的嘲笑、谩骂、甚至侮辱，依然能够谈笑风生，依然能心静如水。这就是了不起的人。有了异于常人的言行，自然有异于常人的地位。就算现在不是，以后也会是的。

普通人要成为一个成功者，最重要的就是价值观跟普通人
