# 14、什么是企业的军队

为什么罗马帝国每到一个地方，首先建立军营？罗马帝国每到一个地方首先建立军营，然后由军营发展成城市，修建非常及时、好用的大路。大路和大路相连，四通八达，既方便军队快速移动，也方便老百姓生活和迁移。

有句话说，条条大路通罗马。罗马的道路确实是路路相通，最后真的能到达罗马。

在我的世界里，不管我讲什么，都是一个东西，这个东西都能四通八达。孔子讲，吾道一以贯之。我的也是—以贯之。

我们建立一个企业就是要有军队。企业的军队从人口结构上来说，必定是销售部门，而不是人事，不是财务，不是生产部门。所有的部门都必须服务于销售部门，因为我们首先是靠销售开疆拓土，赚到钱，养活大家的。企业的每一分盈利率都是销售于出来的，所以销售员出身的创业者容易成功，其他部门出身的创业者成功的几率比较小。
