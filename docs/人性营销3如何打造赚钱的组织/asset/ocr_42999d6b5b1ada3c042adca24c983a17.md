# 9、把创业的激情注入到员工的血液里

创业者的首要任务不是营销，也不是管理，不是研发，也不是进货，不是推广，也不是奇货可递，也可以说不是招聘，招聘当然非常重要，你要招聘到合适的人进公司，但招聘进来还有一个更重要的事情，创业者单枪匹马是很难成事的，必须要有下属的协助。创业者本人一般都很激情，但只有创业者本人有激情，不能调动员工的激情，项目也是很难成功的。就算是你很有钱，也有其他的资源，但是你的员工没有激情，项目就很难成功。

相反你没有什么资源，甚至钱也很小，但你很有激情，并且能调动员工的激情，他们认为跟著你干这个项目有意义，上下同心，那么项目成功的可能性就非常大。
