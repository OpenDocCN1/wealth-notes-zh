如何根据自己的生意模式、团队里的具体情况、社会关系去修正你的经商套路。

总的来说互利分三种模式。

# 第一种模式，实质上的互利。

比如，我们一起下象棋，少一个人就 चल नहीं，必須相互配合，這象棋才能玩起來。如果會不會，我就想跟你玩。 再比如，我們共同組建一個團隊去做一個產品，我會銷售，你會做產品，這就是互利。

這種模式你要提高你的話語權，你就得把你的個人能力展示出來，跟你合作的人才會越來越多，也就有錢賺了。

# 第二种模式，信息共享。

比如，公司里有人搞破坏，有一个主管来告诉我了，我调查过后属实，就把破坏公司业务的人开除了。当然我就对这个业务主管另眼相看，并且奖励。

再比如，我们在网络上聚集粉丝，你需要分享很多有价值的信息。比如如何赚钱，如何做营销，如何当领导，如何创业。你知道的越多，分享的越多，聚集的人就越多。这里面自然就有愿意思付费跟你进一步学习。这就是通过信息共享的模式互利。
