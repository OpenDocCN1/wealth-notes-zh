# 2、管理员工必须尊重常识

经营企业就是要尊重常识，但大部分人都不尊重常识，因为现实是非常残酷的，大部分人都向现实妥协了。习惯妥协的人就非常难成功，也很难走上正轨。

没有规矩不成方圆，经营企业最终是按照规矩来办事的。我把员工分为三种。

**第一种能够主动做事。**我们不安排他，他也能找到重要的事情去做。为企业创造效益的这种员工，我们选他做主管、做领导。

对于能主动做事的人，我们只要讲好了企业的大方向，讲了企业文化，教会这些主动做事的员工一些哲学问题就行了。比如，必须注意业务的细节，必须提高工作效率，必须降低成本，提高投入产出。比如，这个月的业绩要达到五十万。我们只要提出正确的理念与目标，这种主动做事的员工自己就会去把事情做好了。老板最重要的任务就是招聘到很多主动做事的员工加入企业。但这样的人太少，可以说可遇而不可求。很多
