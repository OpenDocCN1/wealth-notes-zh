# 6、我们社群已经是一个强大的学习型组织

我们的陈昌文读书社群和老板社群是学习型组织。我们在一起，就是为了不断的学习，不断的进步。我们这个圈子里，加进来，就是做好一辈子学习的准备。学习就是生产力，只有不断的学习，才能提高社会地位，提高自己的收入。

我们社群就是疯狂的学习，学习，还是学习，不断的学习。学习变现，学习流量运作方式。学习，维度不一样，收入不一样。学习、见识，决定一个人的未来。朋友、组织、团队、思想、思维模式、经济模型，这些决定着一个人的未来。

团队、组织、策略，带着每一个人赚钱。
学企企业家思维、爆品思维，死磕内容，才会有未来。没有内容，就没有未来。书籍、文学性要好，才有未来。文字、视频、直播，都是内容，而我们的书籍就是内容，所以我们必须死磕书籍的内容。
书籍内容不好，就没有未来。反复讲书籍，讲透彻。
