# 8、陈昌文内部讲话——圈子营销

高端的人解决人的欲望，高端的人建设高端的团队，与高端的人交往，更聪明，更懂事，更有执行力，更具有财富。

高端 т的阳光财富，都是需要更高端的人来建设。而低端的人在真正的财富面前，是没有意义的，他们只是人生、精力、财富、物质的负债。

人脉圈子，可以建立更高等的财富。我们社群输出的就是这种更高端的智慧。
