# 9、创业必须让更多的销售员参与进来

直销为什么那么赚钱？就是因为他不断的在发展新的销售员。保险公司为什么那么赚钱？也是因为他不断的在发展新的销售员加入。凡是赚钱的公司都是疯狂的发展新的销售人员。

公司的文员多了，行政人员多了，是公司的负担。这个社会很奇怪，公司的行政人员却以为自己最重要，他们有的甚至给在外面跑的销售人员穿小鞋。凡是碰到这样的行政人员，必须开除。

对于有钱的老板，你就是要想尽办法让公司的营销做到极致，就是要大量投入金钱，精力到公司的销售部。公司能赚钱，就是销售做的漂亮，自然要多培养销售人才。

对于刚创业的新人，答案已经很明显了，你必须重视销售，多拉销售员进入你这个创业团队。
