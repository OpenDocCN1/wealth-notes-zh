# 1、团结一切可以团结的力量

很多人都想赚大钱，但却不知道赚大钱的本领到底是什么？
所以不管做什么，学什么，都不能赚到大钱。

我的父母曾经让我去学医生，他们讲：这个医生学会了，就衣食无忧了。我还听见了一些人说去学律师，或者程序员，这些岗位挣的钱多。其实这都是错误的方向。

有的人能做一个项目，卖一个产品，带一个团队，生活能比一般人过得好，赚的钱也比普通人多，但这也不是赚大钱的方向。有的人就拼命学习管理，认为管理能让自己赚大钱。我就碰到一个高材生，他的梦想就是学会管理，然后成为一个高管赚大钱，这也是错误的方向。

事实上，要想收入比普通人高很多，非常简单，记住两个字“合作”。深入一点讲：团结一切可以团结的力量。只要自己有赚头，就不断的去团结人，找到跟自己一起干，那么你就很容易赚大钱！就这么简单。
