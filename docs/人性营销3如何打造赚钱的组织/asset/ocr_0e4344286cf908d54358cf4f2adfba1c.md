# 12、为什么说企业内部及时沟通很重要

人类的事业之所以能推动，很大程度上都是沟通的结果。人类的事业之所以失败，很大程度上也是沟通有障碍。

企业内部沟通有障碍，就会造成内耗严重。比如，我们公司发生的一件事，我们想要招聘一个程序员，解决一个软件问题。经过人事的预约面试，经过我们技术部门的反复面试，最终认为这个应聘者合格了。然后我们去找到用人部门，跟用人部门一探讨，用人部门的人说，这个问题在几天前已经解决了，我们现在不需要这个人了。

我听到这个消息后大吃一惊，我们花了这么多金钱与时间来招聘这个人，却发现我们根本不需要这个人，这是典型的干无用功。所以我马上与大家商讨以后如何避免这种状况再次发生，答案就是每个人都应该随时随地的沟通自己在做什么。如果计划有调整，应该随时通知与自己配合的人，尽量减少这种信息不对称给公司造成的损失。
