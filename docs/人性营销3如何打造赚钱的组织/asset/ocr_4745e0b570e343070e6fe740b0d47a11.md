# 有机会社结人。

四，当我们的生意做的越来越大，就有很多人关注我们。

假如喜欢骂人，一定会得罪小人的。小人无聊、没钱，也没有什么本事，但有的是时间。他就会记住恨你，到处做你的负面信息。

人可以得罪君子，但不要得罪小人。我就得罪过小人，于是小人就会不断的做我的负面信息。

我们根本不知道谁是小人，谁是君子，故而我们通通把大家当小人处理，于是小心谨慎，我们就不得罪任何人。这是一个商人的基本修养。你要想做大，就必须这样。你如果想赚点小钱，那么无所谓了，得罪人也能赚钱。因为天下很大，总是有买单的。

总结上面四点，只夸人，只表扬人，永不骂人，不说人坏话。
