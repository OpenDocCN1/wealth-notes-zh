
对这个现象的解释其实很简单，整天跟你混在一起的人，干着跟你相似的事，甚至想办法和你分外接近，你不知道的机会和信息，他们同样也不晓得。而此时只有弱关系才有可能告诉你一些你不知道的事。

弱关系的真正意义是把不同社交圈子连接起来，从圈外给你提供有用的信息。根据弱关系理论，一个人在社会上获得机会的多少，与他的社交网络结构很有关系。而此时人脉的关键不在于你融入了哪个圈子，而在于你能接触多少圈外的人。换句话说，弱关系理论的本质不是人脉，而是信息的传递。

亲朋好友很愿意跟我们交流，但是话说多了就不再有新意。最有效的交流，也许是跟不太熟悉的对象进行的。

如今，弱关系理论已经被推广到了任何新消息或者新想法中，不管你是仅想坐学东西、找工作、找对象，还是创业，你都应该避免成熟圈子中的强关系，而更多地走出去去追求弱关系。比如去健身房，去咖啡馆，去什么协会。

已经有统计表明，来自弱关系信息的影响力远远超过强关系。也就是说，尽管人们重视强关系，但人们的大部分知识还是来自于弱关系。从弱关系那里获得想法，乃至于与弱关系合伙创业，都更有利于提高一个公司的创新能力。而从社交网络来看，你的社交网络越多样化，你的创新能力也就越强。

那些拥有高度多样化社交网络的企业家，他们既有强关系也有弱关系，还接受从未打过交道的人的意见，其创新能力是那些只有单一社交网络的人的 3 倍。

各位老板也可以开始建立自己复杂的社交圈。人们很难拒绝强关系的诱惑，这就是路径依赖。比如在我们心目中，风险投资这个行业的人应该是比较理性的，或者至少应该是比较冷酷无情的，然而越是精明如这帮人，也同样会犯追求强关系的错误，同样的会为这个错误付出相当痴痛的代价。

其实创业最佳的合伙人，最好是一个不曾跟你进过同一所大学，从未跟你供职过同一家公司，与你不是一种种族的高学历者。

弱关系总是那么不安全，但是请记住，有风险才有机会，因为人都需要安全感，所有人都喜欢强关系，我们愿意跟他们在一起混，愿意给他们打电话，愿意转发他们的微博。然而熟归熟，工作归工作，当我们考虑找人创业、找人合作，哪个是找人了解什么信息的时候，请记住弱关系才是最佳选择。
