# 只问他们要结果，不问他们要过程，就是管理新一代员工的绝招。

当然更狠的招数就是以夷制夷，就是用新生代管理新生代。
不过，最终你还是得面对几个新生代员工。

以前我们招聘，习惯性的招聘一个员工进到公司里来培养他，花费大量的人力、物力、精力，好在以前的员工学会了也不怎么跳槽，继续在公司干。现在的员工，如果你花费大量的人力、物力、精力去培养他，一般情况下他学会了都会跳槽。
因为他会发现他根本不喜欢这个工作，他们也会发现跳槽是极其容易的，成本也是极其低廉的。

所以现代社会我们招聘的时候就直接招聘专业的人，他已经有工作经验了，那么他到了这个岗位上，专业对口，跳槽的可能性就降低很多。

这些年轻的员工，他们也不喜欢以前社会那种等级观念，他们受到平等民主的思想影响比较多。所以公司里也不要划分等级制度，大家平等交流就行了。谁的专业技能强、业务能力强，谁当项目的头就行了。
