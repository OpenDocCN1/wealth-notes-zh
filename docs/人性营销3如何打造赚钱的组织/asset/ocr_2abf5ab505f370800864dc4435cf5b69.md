# 就是这么个道理。

这个道理可以用来做抖音吗？当然如此，你刷的每一个抖音，都是你自由意志的召唤物。你发的每一个抖音，视频、直播，也是你想要召唤的世界。所以，我们是复制富足的视频、直播、文案，我们就获得富足的关注。

真正对世界、对宇宙本质认识的智慧，与那些在幻象中认识宇宙的智慧完全是两码事。我们懂了宇宙规则，然后在幻象中，做游戏，过得好，这是目的。有些人是幻象中的技术，而真知灼见，是宇宙本身。幻象就是实有，实有就是幻象。

高等智慧，完全靠兴趣与慧根去学习，喜好，运用与改变自己的生命状态。部分人是与这些东西绝缘的，就如，部分人绝缘于编程一样，你不喜欢编程，怎么教育你都 болуы。

灵魂与实验是两码事，很多人以为一切都靠心理学，以及实验证明，这种人跟更高级的同学、智慧无缘了。任何事都靠缘分，选择就是缘分，向好的方向思考，去做，就是缘分。

极高智慧的人，灵性、灵魂的人，有人骂他们，他们一点仿佛都没有。骂人的人，只不过是另一个自由意志。他选择了那样活着，跟我们这个观察者无关。他是另一个宇宙，当然也是一体的。
