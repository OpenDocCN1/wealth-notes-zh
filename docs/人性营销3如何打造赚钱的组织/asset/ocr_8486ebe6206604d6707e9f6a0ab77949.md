# 陈昌文：

带行的人，不带不行的人。宇宙百态，什么都有。念头不行的人，就要隔离。这些人永远存在于宇宙中，只是我们不召唤这些人。

付费的人，我们尽可能正面引导。没付费的人，就隔离掉。我们营销的对象越来越高端，有能力，脑袋清晰，道德素质高。人的差距，往往是道德素质差 + 能力差。

尽可能成本就来懂的人进来。这世界上有些人就是较差，他们就是不懂，所以，我们要收的是道德素质高、能力强，还有慧根的。不要以为收钱就爽，人收多了，有一天会被反噬。反噬的力量会非常大，所以，要提高个人标准，要过滤好人。

低级角色理解不了牛人的价值，理解不了思维的价值，理解不了富人的价值，所以营销他们，跟他们链接，没有意义。只能跟高人、牛人在一起。低级角色没有任何价值，不接触，社群只接触高级人。我们的力量、我们的精力、我们的链接，只链接高级人。外围低级角色，可以无偿免费学习，不链接，不发生付费关系，避免给我们找麻烦。只跟牛人交往，只跟牛人接触，定下这一条。
