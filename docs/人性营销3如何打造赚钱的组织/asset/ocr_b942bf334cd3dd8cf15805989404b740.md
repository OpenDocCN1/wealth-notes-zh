# 9、忘掉你的情怀

什么样的人是牛人？就是实事求是。完全以实际发生的事情、唯一准则去做事的人。一般的人都做不到。一般的人感情比较重，他们就活在自己给自己构建的那个虚幻的世界。这个世界与真实的世界不能重合，有误差，故而这样的人经常会受到损失。

经商的过程就是让一个人变得越来越理智、现实的过程。
有点情怀的人都要倒霉。

我也是一个有情怀的人，我经常受伤。比如，我认为员工不用管理，他们应该能做到上班不迟到，下班不早退，故而很长一段时间，我们公司都没有指纹打卡，如此麻烦就不断发生了。有别的员工甚至迟到1个小时，甚至大部分人都习惯了迟到，因为无所谓嘛，反正又不罚款。本来想给大家减少麻烦，结果天天让自己生闷气。
