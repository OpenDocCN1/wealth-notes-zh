# 4、讲好话，才有机会团结更多的人

一、别人做错了，别人不对，别人混的差，其实跟我们没有任何关系。不要去攻击别人，奖赏他就行了。任何人都喜欢被人家夸奖。你夸奖他，他就夸奖你，如此，你就可以获得实在在的利益。
