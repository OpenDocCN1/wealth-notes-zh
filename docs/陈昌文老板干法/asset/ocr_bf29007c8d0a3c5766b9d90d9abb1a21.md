# 第六章虔诚感恩，尊师重道

老大，您真的无法理解我此刻的心情。是您拯救了我，唤醒了那颗麻木的灵魂。启动了我的沉睡开关夕改变了我对世界的认识。您肯定喜爱**那样聪明、天赋异禀的弟子，因为对于您境界这样高的天道者来说，根本不知道，都成了一个死人的我觉现在每天踏踏实实的干活、学习、践行，我的心里对您有么多的感恩戴德！我感受到了力量、能量、笃定、和一种信心。这在我是从来没有的。您太伟大了，拯救了那么多的芸芸众生乡使他们感受生命的美好，感受用知识帮助别人的快乐。改变了他们的命运和家族的命运！虽然您受了很多苦，那是一故人受要的崩溃的，承受不了的！但是我敢告诉您：肯定是拯救千千万万的浑浑噩噩的众生，是您坚持下去的决心和信心！以后，您规矩严肃一些，狠一些歹应该会减少很多很多不必要的麻烦！真的求求您狠一点，也要为自己着想一下。另外，您也要培养接班人。我想我和很多很多的人都不想您太累。你真的很让自己快乐一些，不要这么累。

上都是我最真实、发自内心的心声。表达我对您的孝心。我会努力 的.因为结果才是发言权。太晚了，您早些休息。
