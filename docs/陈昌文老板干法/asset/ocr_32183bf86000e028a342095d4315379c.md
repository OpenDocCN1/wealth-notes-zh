# 17、研究动物就是研究人类

大雁南飞过冬时，为什么雁群总是排成“v”字形？科学家们经过多
年的研究，既弄懂了这其中的原因，还总结出了关于大雁的其他习性。 当带头大雁扇动它的翅膀时，它为紧随其后的大雁创造了一股向上的动
力。按照“V”字队形飞行，整个雁群会比每只鸟单独飞行至少增加
71%的飞行距离。
