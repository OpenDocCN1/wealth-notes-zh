# 8. 爬向社会上层的症斋功夫

大多数人都想爬向社会上层，他们会怎么办？他们会更加努力的工作，他们想用工作时间更长、投入更多的精力来爬向社会上层。他们认为，成功就是拼命工作，把工作做得比别人好，自然就成功了。我想说，大错特错。努力的人很多，努力并不是通向成功之路。而聪明才是通向成功之路，要不，牛都成功了。

忙碌的建筑工人终其一生也买不起房，而且这个社会上有能力的人多得很，而成功的人确是少数。

成功的人必须先为自己考虑。首先，他不是想自己能为公司做什么，能为别人做什么，而是在想公司能为自己做什么，另!，人能为自己做什么，对自己没好处的事情，他是不干的。所以，他会选择一个好公司，一个有发展方向的公司，也就是说这个公司的发展水平高于同行，要不然他会离开的。他还会选择一个有成长性的行业，比如现在的互联网、金融、健康、财务、咨询行业等。这些都是服务业，也是朝阳行业，都是发展迅速的行业。
