# L 想成大事者学必须选择好自己馥鼠仓

李斯在做秦国丞相以前贾在楚国上蔡那里做看守粮仓的小文书，这是一个吃不饱，但也饿不死的职位。他最大的爱好就是在上班时间溜号，带着自家养的一条黄色的土狗，带着自己年幼的儿子，出上蔡东门贾到野外追逐野兔。

李斯有一个幸福美满的家庭，房子不大，但已足够居住，薪俸不高，但尚算衣食无虞。然而贾一件偶然而有趣的事情发生了。有一天贾李斯同学忽然内急，他捧着肚子，弯腰夹腿简直狂奔厕所而去。厕所里的几只老鼠正不无哀怨地吃着粪便，见有人来，吓得惊惶逃窜。李斯同学无暇多思，先畅快淋漓地解决了内急问题。

李斯在边系裤带边往回走时，便悲叹起厕所中那几只惊恐的老鼠来，它们不过就是想吃点根本没有人要的东西罢了，可是就是这么一个小小的需求，对它们来说都显得那么艰难。只要有人来，它们就吓得四处逃窜。哪怕是来一只狗，也要让它们心慌好久。运气不好的，还会掉到粪池里丧命。刚好李
