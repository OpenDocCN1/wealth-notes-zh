# ## 2、不要要求员工有忠诚度

与其说商业上有“忠诚度”，不如说交易上要有“诚信度”。你别 欺骗顾客，顾客下次需要这个东西了，他的选择成本就低，因为他不知 道其他商人是不是会骗人。
