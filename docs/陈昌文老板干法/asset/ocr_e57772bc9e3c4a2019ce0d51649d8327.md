# &古代皇帝一个人为了什么可以统治几亿人

很久以前，当我在电视上看到皇帝在朝堂上大声训斥那些大臣，而大臣们一个个唯唯诺诺、战战兢兢的时候，我就在想，那些大臣为什么不上去给皇帝一板砖呢，我们这么多人，皇帝却是一个人啊。有人跟我说，那是因为皇帝有侍卫，大臣们还没动手就被侍卫抓起来砍头了。那我 又问到，那侍卫为什么要闻皇帝的活啊？有人又跟我说道，皇帝有军队，谁敢不服！我又问到，那军队成上千上百万的，为什么要听皇帝一个人的？这人想了 想，跟我说，那是因为皇帝有很多鱼肉吃，有钱发。我又问到， 那他们这么多人干嘛不抢啊，把皇帝的肉给抢了不就行了？那人不说 话了。

其实这里面隐藏着当老板、当领袖、当老大的核心秘密。

在最初的原始社会，每个个体都是独立的，没有谁统治谁的问题。 甲身体强壮、性情桀烈，就可以肆无忌惮的抢夺别人的食物，威胁他人 的安全。但是他仍旧没有统治其他人的想法。和甲相比，乙身体弱小， 平时获取猎物很困难，还要随时应对同伴的抢夺。和乙有同等情况的， 还有丙和丁。面对残醋的自然环境，还有凶恶的同伴，同病相怜， 怜的乙、 丙、丁为了生存，结成了联盟。狩猎，我们三个人合作，抢夺别人的猎物，我们也是三位一体。乙丙丁三人虽然身体弱小，但是兄弟齐心，合体无 敌。逞强仗大而凶狠的甲，也不是他们三个人合起来时的对手了。甲平日 里习惯了优势欺人，为了恢复往昔局面，对乙丙丁三人说道，我要加入 你们，有好处跟我一起分，有强硬我帮你们打。你们要是不答应，我就 跟别人合伙，干掉你们。乙丙丁权衡下，答应让甲加入。于是三人变四人，战斗力再度加强，他们也不去狩猎了，专职抢夺别人打回来的食物，在 抢夺食物的同时，他们还严防别人像他们一样结党，一旦看到其他人有 团结的苗头，就坚决打压。渐渐地，当地所有的人都开始受他们的胁迫， 四人团体开始领导和统治整个部群，部落形成了，四人
