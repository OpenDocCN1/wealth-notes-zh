# 20. 多元宿爱展的误区

《孙子兵法》里面有句话：守则不足，攻则有余。是什么意思呢？

就是说自己力量不够的时候，要想着防守。其实很多老板，包括经营了很多年的企业，力量都不是很强大，除非你是行业第一，一般你都有强大的竞争对手。自己如果想去进攻别人，那么，你必须要有多余的力量。
