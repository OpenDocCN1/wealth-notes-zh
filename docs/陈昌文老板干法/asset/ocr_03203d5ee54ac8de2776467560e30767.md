# 22、老板必须在思想上养成的 5 点习惯

老板必须在思想上养成的 5 点习惯。

+   第一，必须要知道自己的时间应该花在什么地方！时间是非常有限 的，善待自己的时间，绝不要去打麻将，去喝酒浪费时间。每个企业都 有许多事情要处理，要思考。你把时间花在什么地方，你的业绩就在什 么地方。
