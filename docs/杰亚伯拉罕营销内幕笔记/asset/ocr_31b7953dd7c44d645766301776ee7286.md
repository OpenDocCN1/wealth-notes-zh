# 逆转风险的 3 个方面：

+   A、全额退款再加奖励刺激。
B、情感风险逆转，即增加潜在客户对于所购商品的信心
C、风险逆转的步骤

+   - 步骤 1：从现金角度来说，报告最广的证明或个案研究，即从你感到满意的客户或买家那里得到的可以衡量或量化的反馈是什么.
- 步骤 2：如果你的客户或潜在客户保持现状，会受到什么惩罚
- 步骤 3：你的竞争对手的最有力、最优越的保证是什么。
- 步骤 4：要让别人选择你的企业并建立业务往来。你能保证满足的最低期望值是什么。
- 步骤 5：你情愿给别人提供的最具体的最低保证是什么。
