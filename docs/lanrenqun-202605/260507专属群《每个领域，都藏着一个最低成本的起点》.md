

# 每个领域，都藏着一个最低成本的起点

260507
整理：公众号懒人搜索，**懒人专属群**精选
懒人微信：lazyhelperl

最近，有一个消息在动漫圈引发了不少讨论，就是《蓝猫》宣布 IP 重启。对很多 80、90 后来说，蓝猫是实实在在的童年记忆。而重启，也让很多人重新思考一个问题，就是一个国产动漫 IP，到底是怎么长出来的？

其实，去年夏天，这个问题就有了一些新的答案。2025 年的暑期档，有个很有意思的变化，动画电影成了票房的重要顶梁柱。《浪浪山小妖怪》票房一路走高，成为中国影史二维动画票房冠军。《罗小黑战记 2》作为续集，同样获得了不错的市场反响。

电影的具体内容，我们就不多说了。今天换个角度，我觉得真正值得注意的，不是这些动画电影的票房数字，而是这些 IP 诞生的方式。

你看《罗小黑战记》，很多人可能不知道，这个 IP 最初来自一个叫木头的动画爱好者。他原本是学艺术设计的，曾经在路边捡到一只流浪猫，取名叫“小黑”。这就成了罗小黑的原型。从 2011 年开始，他一个人在网上发布罗小黑的短片动画，采用“慢更新”的模式，10 年更新 40 集，每集 5 分钟。

再看《浪浪山小妖怪》，这个 IP 同样经历了一个漫长的孵化过程。它来自《中国奇谭》第一集《小妖怪的夏天》，这部短片在网上热度很高。先有这个基础，才有了后来的大电影。

你发现没有，这些 IP 都有一个共同点，它们都不是一夜之间诞生的，而是经历了漫长的孵化过程。

注意，真正值得关注的，也许就是这个漫长的孵化过程。为什么？因为这或许意味着，国内已经有了一套让创意慢慢成长、慢慢试错、逐步筛选的机制。

你可别小看这个机制，这套模式一旦跑通，就可能让国产动漫具备持续输送 IP 的能力。

为什么这么说？我们可以看一个现成的参照系，日本。类似的模式在日本已经运行了很多年。

有人曾经算过一笔账，全世界播放的动画片里，有 60% 是日本制作的。什么概念？就是当你不管在全世界哪个地方，只要打开电视或视频网站，看到的动画片就有一半以上来自日本。更夸张的是，据说目前全世界有 8 亿人是日本动漫的粉丝。

而且，这种影响力似乎还在持续。日本几乎每隔几年，就会出现一批新的现象级 IP。从早年的《龙珠》《灌篮高手》，到后来的《火影忍者》，再到最近几年的《鬼灭之刃》《一拳超人》《进击的巨人》等等。这种持续的 IP 创造能力，在全世界范围内都比较罕见。

那么，这个能力是怎么来的呢？

关键之一就在于，日本是全世界为数不多的，具备大规模漫画产业的国家。

注意，是漫画产业，不是动漫产业。很多人习惯把动和漫放在一起。但这本质上其实是两件事，漫画是用铅笔画出来的，成本很低，而动画是一个团队的制作成果，成本更高。

为什么说有漫画这点很重要？因为动画也好，游戏也罢，还有所有周边产品，最初的灵感来源都是漫画。**漫画就像金字塔的塔基**。漫画里的好作品，有机会往上一层变成动画。动画里的好作品，有机会再往上一层，变成塔尖的超级 IP。

而整个产业链条是否稳固，不取决于塔尖上的超级 IP，而是取决于塔底的那些海量的基层从业者。

为什么？

首先，漫画提供了一个更低的门槛，只需要一个人、一支笔、一张纸，就可以开始创作。不需要团队，不需要设备，不需要资金。任何有创意的人，都可以参与到这个行业中来。

但是动画的门槛就高得多。你想想，拍一部动画需要什么？钱啊，团队啊，每一个 3D 特效都是经费在燃烧。这样的门槛，注定只有少数人能参与。但漫画不一样。这种超低的参与门槛，让日本拥有了全世界最庞大的潜在创作者群体。

更重要的是，这等于建立了一个巨大的试错池。你看，创意这个东西，很难预测哪个会成功。假如你有一个足够大的试错池，让成千上万的创意同时尝试，那么总有一些会最终胜出。而且更重要的是，这背后的裁判，不能是制作方，也不能依靠行业专家，必须是真实的观众。

这就像生物进化一样。为什么自然界能产生如此精妙的生物？因为有足够大的基数，有足够多的变异，然后通过自然选择，让最适应环境的个体存活下来。日本的漫画产业，本质上就是在模拟这种自然演化机制。这也是为什么，论那种世界级的大 IP，日本未必有“白雪公主”“米奇”这样穿透全球几代人的形象。但论 IP 的持续输送能力，日本动漫几乎可以毫无悬念地进入世界第一梯队。

在有了大量的创意输入之后，接下来就是筛选。日本的漫画杂志连载体体系，建立了一套极其残酷但高效的筛选机制。

比如《少年 TUMP》周刊，这本杂志号称“问卷至上”。每期杂志都会附带读者问卷，读者可以对每部作品评分。编辑部根据这些问卷，对所有连载作品排名。排名靠后的作品，就等着被腰斩吧。

这个机制有多残酷？有人统计过，新连载作品的存活概率只有 2000 分之 1。也就是说，2000 部开始连载的漫画中，最终只有 1 部能够长期连载。

同时，各大漫画杂志都设立了新人奖，专门发掘有潜力的新人漫画家。比如手冢奖、赤冢奖等，每年都会从大量投稿中选出优秀作品，给新人提供出道机会。

比如，岸本齐史创作的《火影忍者》，这是近 20 年日本最成功的动漫 IP 之一，就是从这套筛选机制中诞生的。1995 年，还在大学读书的岸本齐史，画了一部叫《机器人》的短篇漫画，获得了《少年 TUMP》的新人奖。获奖后，岸本齐史获得了在杂志上发表作品的机会。但是，成功并没有立刻到来。从 1995 年到 1999 年，整整 4 年时间，岸本齐史一直在创作各类短篇作品，尝试不同的题材和风格。这 4 年，就是试错的过程。

直到 1999 年，岸本齐史终于找到了自己的方向。他创作了《火影忍者》的第一话，投给了《少年 TUMP》周刊。编辑部看中了这个作品的潜力，决定给它连载机会。注意，这时候《火影忍者》还只是一个漫画连载，创作成本极低。假如读者不喜欢，随时可以腰斩。但假如读者喜欢，就可以继续连载，然后考虑动画化。

结果我们都知道了。《火影忍者》连载 15 年，成为全球现象级 IP。

还有很多成名的作品，都得益于这套漫画筛选机制。而且更重要的是，**这套机制不依赖天才，不依赖运气，而是通过大基数的参与、残酷的筛选、完整的培养，让最好的作品自然涌现出来**。

有人统计过，2024 年，日本漫画市场规模达到 7000 亿日元。每年有数百部新作品开始连载，但只有极少数能够动画化。而那些动画化的作品，成为全球 IP 的概率，远远高于其他国家直接制作动画的成功率。

现在，让我们回到中国。

你看，中国动漫现在的情况，是不是和当年的日本有些相似？

只不过，**咱们中国的孵化机制，不是由几家大型出版社主导，而是以二次元网站和社区为基础，由网友直接筛选**。个人创作者可以很容易地发布自己的作品，门槛很低。用户的点赞、转发、评论，就像日本读者的问卷调查，形成了真实的市场反馈。

而且，这个趋势还在加速。就在今年第一季度，国产 IP 的周边产品销售额，在国内首次超过日本。换句话说，国产 IP 的变现能力，正在越来越强。

当然，至于动漫市场的发展目标应该是什么，是给儿童提供优质内容，还是要发展全民动漫，这都是另外的问题，不在今天的讨论之列。我们今天只是借着动漫领域，来观察一个创意行业是怎么一步步壮大的。

而对个人来说，这个过程或许也能提供一点借鉴意义。

首先，假如你想进入一个领域，或许可以先问问自己，这个领域有没有一个门槛相对较低、可以大量试错，能够获得真实反馈的起点？

比如你想成为作家，那么写公众号、写小说连载，这可能就是你起步的地基。也许不需要等到有了完美的构思才动笔，可以从每天写 500 字开始，从记录生活感悟开始，从模仿喜欢的作者开始。重要的是开始写，然后看读者的反馈，看哪些内容更受欢迎，慢慢调整方向。

比如你想做视频创作，那么短视频平台可能就是你的试错池。不需要等到有了专业设备，也不需要等到掌握了复杂的剪辑技巧。可以用手机拍摄，用简单的剪辑软件，从模仿热门视频开始。关键是要持续发布，观察哪些内容获得更多点赞和评论，然后不断优化。

比如你想创业，那么小规模的产品测试，可能就是你验证想法的起点。你不需要等到有了完美的商业计划，也不需要等到筹集了大笔资金。你可以先做一个最简单的原型，找几个朋友试用。假如反馈不错，再逐步完善。假如反馈不好，就快速调整方向。

最后，借用一句话，作为今天的结尾吧，来自著名的漫画家手冢治虫。据说他在临终前说的最后一句话是，“请给我一支铅笔”。

一支铅笔，一张纸，就是整个日本动漫产业的起点。这个路径放到其他地方或许也成立。找到你的地基，拿起你的“铅笔”，然后，永远不要停下。
