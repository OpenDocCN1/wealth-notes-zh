# “人生如戏”的社会学解释

茶馆是一个公共场所，这戏园里的每个人，都有潜在心里，他们要在舞台上表现什么？不愿意表现和真的在说，他们是在按照自己的意志和真相性说做事，也是在表现某个社会身份，职业身份应该有的样子。

这时我想到一个叫戏仿剧论的社会学理论，就是社会生活是可以跟戏剧互类比的，这个理论在 20 世纪早期有影响的美国社会学家 "欧文·戈夫曼"，他在代表作《日常生活中的自我呈现》和《正常规》里，从社会学角度，解析什么是戏剧里的 "世界是舞台，人人是演员"。

互动论的含义：人类就常因为人类的社会文化性存在，这就像台上都称为舞台，是因为有戏剧上演。我们遵守由社会规定的脚本，就常由社会规定的脚本。我们的行为，就是受其支配。

从这个角度说，我们在不同的环境里，在家里，在工作单位，扮演的不同的角色，就因为是受这个角色的礼仪和脚本规定，比如去接受各种各样的礼仪、语言、动作等等。社会学会称之为社会角色。所以代表社会学理论，称为社会互动论。

而我们互动时，所有的行为都是传递符号，传达某种意义，从而获得彼此回应。

比如，我在朋友圈发一张在餐厅的照片，潜在是希望获得肯定。你在我身上看，是希望我给你一个健康自然的形象。你接我话，就我在扮演一个好的主人人点。以便下回来给到我孩子的照片点餐。

你可以说，这描述太尖酸刻薄，我们的互动，是出自真诚和友善。但高曼的理论认为，对社会互动的观察，真诚与否，不妨碍社会行动的结果。

我们每个人像演员处理角色一样扮演自己的角色，有的属于技术演员，有的属于高曼，而社会就恰像一个舞台一样运行。

说到这儿，你清晰明白了，我们按照自己的互动规范表演自我的某一部分，掩饰自己的一些部分，并不等于撒谎，而是一种社会义务。人类生活就是这样运行的。

# 《茶馆》中的"戏中戏"

下面，咱们就可以把这种观感，代入到《茶馆》里。

《茶馆》至今震撼我们，就是因为在我们生活的社会生活剧里，距离当年并不遥远。

茶馆在当时的社会功能，已经决定了它是很好的社交舞台。在前两集，有个胆小怕事的松二爷，他为常四爷和于二德子办案时，说 "咱们也都是外场人"，在北京，总 在街面上活动、人情练达的人叫外场人。

每个客茶，就是拿出自己的外场人设来表演——这里说的表演，不是京剧角色的表演，而是社会中你表演的社会角色。

再就着松二爷。在第一幕里，他并不比常四爷狂，但细书已经透露，他这时并不富裕。穷酸，他仍是他的外场人设。松二爷夸他 "体面"，你看，老爹子定多少就 "体面"。

第二幕，松二爷已经彻底败落了，他最过的表现是什么，说 "看见我这身衣服，我还会看什么人？" 他不是说贫穷难过，而是惋惜自己连基本的体面都没法维持，这种体面，用刚才的方式解读，就是维系社会身份的姿态。

咱们来再看一场人物互动的戏。第一幕，一对乡下穷父母来吃面。秦仲义说 "要出去"。在舞台上演出，比他更实惠，他是先说 "我出去"，又让 "他出去" 自己，在微弱的国家，不必多说妇人之仁。

常四爷自我人设是我内场人，仗义执言，立刻施舍了两个铜板面。但是也是 "外场人"，顺服场合和规矩，特别讲究 "带劲儿" 和 "有门儿"。老舍在人设里打样，也说得 "咱们外场儿" "出去说"，不能给老主儿难堪。

对话角色会最懂得最好，最老练来的是王利发，作为茶馆掌柜，戏要不停地说走，不停地表演角色，因为要不停地看，要观看，应对突发情况。

这时候，王利发看见秦仲义住不了，赶紧过来帮一把，说 "你意兴，" 王利发 "再来四碗面，" 又给 "我告诉你，这路子太少了，谁也别" 一桌酒，显示自己见识多。

秦仲义一席是一副架子的，这就是他的人设。这时，他听着台下听戏，先托一个茶馆掌柜，说 "这国家灭亡不会给穷人一顿饱饭。" 再干 "我开自己厂开自己厂，国家。显示自己的见识和实力。

焦菊隐导这部戏时，就要求演员们先进入角色，让观众完全进入角色，让观众看到观众，让三位主角对谈非常激动。直接面向观众，让他们的情感被自由地抒发出来。

为什么呢？因为这戏模的三个主人，只探讨了 "国家心碎" 的核心，是只能探讨具体人物形象和一般意义的表演，可以直接就观众看了。

所以说，不能推演成戏剧社，正是因为有社会角色表演，社会就是。还有退路和底牌。如果真的彻底地暴露自我，很可能是遇到了绝境，甚至社会出了某些问题。

再说，随性说出自心底的话，对听者也是冒犯。在小说里看来，本来把自己的内心演得好好的，突然接触到他人最真实、最无助的心里事，就是不知道怎么办啊。

# 人生如戏，并不消极

照这个思路，咱们来来说，人生如戏，人人演戏，这难道不该悲观？

刚才说，从社会学家来看，表演是社会行为的必然，是社会中的义务。就是我们和 "精神疾病"，或成见的人，或家人，或朋友， "我不愿自己人，我想做我家人"。 "我想想孩子吧"。这可以解读成：你家里还要求你扮演父亲和儿子，你关心的人还需要你进行互动。

我们再从哲学上来说。哲学自从诞生，就一直在问自我意识，人格和意志自由这些问。康德说，精神是最高的，是唯一的 "谜"。科学能思考它，但也能解决它。

既无法彻底把握，人对于自己的精神，也就无法彻底地 "反思"。人所表现的某个，只是精神的一部分。或者就是某个层次。

这种有意识的表演形式上的判断，就是这种表演，表演成形式，依据的是自己的人生体验。每个人都如此，是与善恶、真诚或虚伪无关。

接受这个观念的意义在于：我们既要抗拒自我的表演意义，又不能只信表面的真诚。事实上，人能够的最大真诚，基础是意识到我们永远也无法隐藏自己的虚伪。所以，我们才能真正地直面自己，从外部看到自己，让自己更接近自己愿望成为的那群人。

很多人把我 "老舍" 说 "人戏" 是 "自我设计", 其实正好好转了，这种行为恰恰是 "我是自我认识"，从不进行自我反思。
