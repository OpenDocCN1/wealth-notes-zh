# 16结语 | 再见，老舍：谁的人生不矛盾？

说古论今天下事，拍案奇书贯行家。

你好，我是贾行家，这次我们一起来读老舍。

老舍自己解释过，他这个笔名来自他的字“舍予”：老姓老姓，舒服的舒，舒字拆开是舍予，于是古文中的我，舍予就是舍弃自身。

老舍不光在小说里展示了他的人生总结，他的名字也像一种预言。这看起来有点儿宿命，其实也没什么意思。他或者他的小说人物左走右走时触水自沉，那是因为他在试图寻找一个会遭遇什么，但可以避免。

我们前面讲过，好小说家在小说里是隐藏不了自己的。

写作还有一个现象，一句话写出来，就是永恒的。它的概念意识，变成了具体的存在，而不再复。所以，严肃的作家对文字都很敬畏，甚至可以说是信仰。

在现实世界，更好解释，就是“一学入公门，九牛拉不回”。写杂文前书的时候，应该可以写出来，但既没有权利，在现代社会，一个完全无能力人在法律文件和契约上签字，是决定性的。

最后一讲我想让大家知道，老舍经历了很长时间，我不愿意讲老舍的漫长结局，我只想用一个眼神给你，然而他却在微笑的老舍。

但不论他的1949年回到1966年在于太平沦落之间的事，老舍就没说过。

你得仔细理解，谈论这件事有困难之处。好，关于这个话题，已经有很多种探讨了。我们可以通过他入世的经历，只对老舍自己，说说他身上存在的诸多矛盾。

除了传说中的完人或者魔鬼，没有人是不矛盾的。但老舍的矛盾，明显得普通人要严肃。这一点他自己也是承认的，了解他的人都承认。这些矛盾，有的成就了他；有的，则构成了他精神世界的最后崩落。

关于那个矛盾，简单地看是解决着他，也可说这是在许多地方无法解释，他也选了和谐名、和小说人物一样的处理方式。

# 第一对矛盾：悲观与幽默

在他身上第一对矛盾是性格矛盾，他也可以说是世界观冲突的反应。

我们前面讨论过这个话题：老舍是一个悲观者，也是一个最幽默的人。这种性格，他的小说也有一个好例子。乐观就是性格，让他的幽默显得深沉，富于层次。

上世纪三十年代，老舍经常为倡导幽默，他政治的《论语》杂志与编与当时，他被视为“论语派”的一员。但比起“论语”的门人胡适，老舍的《骆驼祥子》开始，就超越了一般意义的幽默文学了。

很多人可能不知道了，在上世纪三四十年代，林语堂是传播老舍文化的中国作家，在美国布鲁克林大学保持了二十周教师，在1940年、1950年，都被提名诺贝尔文学奖。

但在今天，在国内外不同的版本的近代文学史中，林语堂很少出现，老舍亦不可少。最明显的一个原因就是：林语堂活得太顺当了，而老舍对人生多有悲凉和伤怀，对他自己在深切地同情着。

有人说，那时候受委屈的人多了，老舍反倒得那么激烈，是之前太顺了。

老舍反复讲究过：畜牛呢，母亲就传身教，任何时候都显得童趣，讲客气。也就是说，做人的根子，是要有尊严。悲观者的尊严是什么？不是说宁可不做，你命能，那就是你的根子。我不能忍，我生命中不能有些东西。

下面这件事，最能体现老舍的悲观、尊严和幽默：1944年，日军从贵州方向杀你重庆。有人说老舍，万一重庆也被打，你怎么办？老舍说：“不用再见了，坐着死的好。嘉陵江上又有十几个小舟。”愤怒、悲伤的不忘总得发泄，这就是老舍。

# 第二对矛盾：中西文化

老舍身上的第二对矛盾，是中西文化冲突在他的观念和人格上的显见。

青年时代，老舍对社会革命没什么兴趣。五四运动他也并没有参与，他成了一个完全依存个人思想，在小说里自由表达的作家。这是成就他的一种风格。

在文学史上，老舍和巴金、茅盾放在一起的，但老舍一直关注的都是个人命运。今天读老舍的人，比读巴金、茅盾的人要少得多。

老舍很熟悉西方文化，他在1922年正式受洗是基督教洗礼，他讽刺那些信仰教好时，他们半洋半土，正是因为他对基督教教义的理解很深。

他年轻时是杂记者：我愿将“双十”（也是辛亥革命纪念日）解释作有两个十字架，为了铲除旧的恶习，我要预备牺牲；创造新的社会文化，我们也不必留牺牲，和个人肩负起两个十字架——耶稣只负责一个。这和他为自己取的名字，也很相称。

老舍赞同西方的自由、平等、博爱理想。也正是比标准的儒家思想更理性。我们可以说老舍小说里的民族文化底蕴，也是老舍思想上的情结。

老舍始终的小说家优势，他的情感作品相当经济学家的精巧，他的感情是和老百姓没有隔膜的。但是上面这些文化基因，他也未能完全摆脱。

老舍过去一直是自由作家，哪一派都不。回国以后，一开始时过得很顺当。五十年代时，受国家鼓励。但很快，各作家都来了，全国人民都喊他“人民艺术家老舍先生”。这种让人腻的东西，对自我意识的冲击，是冷漠和打击都严重的。

他很自然地就把完成歌颂宣传任务作为自己的使命了，这也叫完全属于陶铸。从《骆驼祥子》开始，他认为个人主义不能改变中国，他对新中国的感觉是真诚的，也是天真。作家的起作从来不是个体，大天真的，就奉为圭臬，就放弃为某种观念的自觉，而放弃忠于自我的自觉。

在摊牌以后，他还自言自语地说，他们不挑拣，我是有用的，我写的单戏、快板，当天晚上就能演。我感到这段，真意是忍不住：一个文学大师，下意识里，还是怨恨自己的价值，要别人来定义。

# 第三对矛盾：个人与时代

在1966年，第三对矛盾爆发了，也就是老舍个人和时代大潮的矛盾。

我很欣赏《老舍全集》的做法，它用历史的办法，恢复了老舍的全部作品，很多作品是收录了自己不满意的部分。像五四时代，他参与批判了吴宓、胡风、丁玲，写了很久，很激烈的文章。

老舍当时的地位很高，是党外人士，代表了一个时代。需要的，要表态。从这个时候到很多文章中，对区反民族和政治，自我和群体这些关系，他是很困扰的。

这只是我刚才说的，文字真是很有意思。只要你写过、就永远追到你头。同样的，只要你干过，到了什么时候都有份。

如果一个人偏颇，没有十分自尊意识，他会说我无所谓，我们的意思，如果别人问我是否人自助啊，或者我本来好年太大吃，忘了什么。但忘不干净——你“心说家”的事，现实发生过的事儿，要求好跟着你。

反思和面对的真正对象，不只是过错，而且是自我。要想去挥回痛，就把这一辈子的意义变得不多了。

老舍写过实话，我不十分懂政治，我只认识一些小人物。这是实话，他确实不懂，能对他影响的时候，绝大多数人，不能对形势做清醒判断。

有一句很厉害的理性警告，叫“你不理财，财不理你”。也有一句很厉害的话，叫“你永远不该碰，碰也碰不受伤身”。老舍就这么自己一种自也要彻底死，积极参与，最后成了焦点的牺牲品。

最后，他觉得一切都变了，其实，他不明自自己一直未参与。到底变什么？他比较值得情的一点是：不能退出，不能选择不承担。

这给了我们一个最直接的提示：面对未知的命运，陌生的领域，就像面对一份不知道内容的合同，要尽可能地保留谨慎，甚至是恐惧。有权愿承担尽量的责任，因为，一旦签下名字，一切后果，就要自己承担。

从投资我们到各种朋友那里那些回报的推荐项目，我不说太好，我只是问你：你知道这个东西是什么，怎么玩的吗？你就把积蓄都投进去了？
