# 故事七要素

我做一个小调查：《骆驼祥子》虽然深入人心，但很多人们对故事情节却不完整。这反倒证明了老舍的成功：情节是载体，作者真正要传达的，是对情感和人类命运的理解。

编故事和讲故事都是有的门。编剧的职业化程度很高，不可能完全靠灵感或敲们。

设置情节有一些公式和法则，最常见的一个，是把完整故事分成七个要素来设置：

第一个是目标，是主人公有一个要实现的目标和预期。

第二个是阻力，戏剧写作叫“扰乱事件”，就是原来的计划遇到阻碍，或被彻底打乱。有主人公是主动的，编剧会设置几个进过就回不来的门，比如被偷骗了，进，或者背负上血海深仇，让他必须前进。

第三个为了实现目标，克服阻力，他怎样的努力。

第四个，是人物努力一番之后，所获得的结果。

如果故事在这里停止，会显得乏味。所以，第五个要素是编制的最爱，是设置一段意外惊喜：观众会认出故事的第六个要素，就是我们会看到主人公最喜爱的反转，在这个反转造成的悬念里，故事走向结局。

过七个部分，可以进行拆分，调换前后的位置。比如，越来越的电影是从故事中间开始，再倒叙介绍，但故事的要素不能失，否则观众会觉得故事讲得不清楚。这个公式经过了反复验证。观众对人追求目标，最能引起共鸣的。

# 复一下，目标、阻力、努力行动、结果、意外、反转、结局七要素。

# 《骆驼祥子》的情节设计

下面，我用故事七要素，来帮你回忆一下《骆驼祥子》的故事：

故事发生在上世纪二三年代的北平。祥子是个想家从乡下进城里的年轻人，他强壮朴实，聪明肯干。他相信，凭着自己本本分分的事，能立定事业安分活命。

先说他的目标，咱们都知道，就是拥有一辆自己的洋车，掌握自己的活法。

老舍在原小说里都在为祥子攒经济性，在这一讲我就说，它的中或经济背景。展开这一讲背景，它涉及到中国或经济展的大背景。咱们先要明白一点：一辆新洋车值100块大洋，相当于贫农家庭一年的收入。

祥子能实现这个目标，简直是个经济奇迹。只有他这样克苦劳，没有家庭负担的没头牛，他才能办到。

接下来，他就遇到了第一个要素，阻力了。

新车买了半年，他就在军阀内战里被孙了壮丁。祥子趁机逃跑了，三车的功劳全给虎妞，洋车也被政变兵洗劫了。虎妞，还拉回匹骆驼来，卖35块大洋。

因为这件事，祥子被车夫们戏称为“骆驼”。这个名号他很快接受了，形象，祥子既固执又笨，也他很有说服力，跟原目标继续努力行动。他用这三十多块，再攒一辆洋车。他拉车更拼命了，甚至去跑长途生意。

祥子先回了从前租车的“人和车厂”去。这家车厂的老板是曹氏夫人，就是我们非常熟悉的刘四爷和虎妞。这两人祥子走向未来的导火素。

刘四是个性很优，挺喜祥子。恶人是老喜欢老人的。虎妞是个三十八岁的老姑娘，对祥子早就有意了。她，设了一个局，把比他小十几岁的祥子灌醉，到了自己的床上。

这时候，让祥子既丧气害怕。正好，这给他有找到一种性的大学校家曹先。祥子在曹家，是个社会沙漠里的绿洲，曹先夫人都善理解，众人都对他很好。

可惜，怕什么什么来。快过新年，虎妞找上门来，对祥子她有了身孕，祥子必须娶她。虎妞为了她计划，让子先去刘四爷处。他们随后继续产车厂。

祥子不体，也不想虎妞，而且这个事件一点也不决断。这下，曹先生送到麻烦，他一个乱闹的学生告发，说他被过曹家的曹先生一家连宅都烧了，祥子被人乱抓的刘四爷，把他等散就赶走了。

这是祥子遇到的第二次打击，也是第三个阻力。这甚至比第一次还严重，让得几死清：来北洋这么年，最后几乎无一文，无可奈何，还被人家当大麻烦。但是祥子很坚强，也很有，自己因曹先生的事获散，没想过逃出家系为因。

命运把祥子又赶回了人和车听虎妞的摆布。结果，在喜宴上，精明的刘四爷破了虎妞的计划，直接掀翻了台，把他的剩钱扔了进来。刘四爷又做了两件事：曹先，五块换到虎妞，把自己给嫁给了祥子，虎妞就闹上杂院去了，这时候她也怀祥子，她根本没好怀孕。

虎妞的B计划，是等刘四生气了，他们再接亲。没想到刘四爷弄弄车厂，看着去眼不去了。这让虎妞彻底，只能给祥子买了辆车，让他拉，好提款。

故事发展到这里，“结果”这个因素也算出现了。后面等着我们的是意外、反转结局。

老舍让意外接连发生——

卖车给祥子的，是同院一个四二强子的中年车夫。二强子有个小女儿叫小桂子，也被他卖给了人买。这有个人财两空的人，为养活两个，又做了拉货。

虎妞这时真怀孕了，最后难产而死。这钱又花光了，祥子只剩了才把灵验办了，最后，手里就只剩了三十块钱。这是祥子受的第三次打击。

祥子和小福子这两个苦命人，早就互相好感。祥子留下句话，让小福子等。

经过儿年的打，祥子已经动力失。他一个妓女的来拉，受女人诱惑，染了淋病。不光体大不如，气也少正。

些事让祥子在车夫的人缘变好了，因为他变得和别人一样。祥子也明白人是不能靠活看。此时的祥子不算坏，只是个很普通的夫。

我们看这样：从努力开始，最后到放弃。祥子的处境越来越，越也越来越大，像泄气的皮球。读者得，也像一把锤子不慢地敲祥子打。

这个候，意外还在增加。一天夜里，祥子拉人在大宅子院，祥子不他到底在干，在气里刘四爷，这让祥子感震：他既然，既然战了刘四爷，他还能说活生。毕竟小福子在等。

曹先生主，让他把小福子接自己来。这是一个子不想的喜讯，他们可以对对像干净体生活。

关于接转来，有两种选择，这个岔口，决定这部小说喜剧悲剧。

上世纪年代，《骆驼祥子》在美国本，者改写了，写成小福子跳子拾到了，是大大。这合美国人口味，提升希望。这个，大大破坏小说成，创作是大的罪。
