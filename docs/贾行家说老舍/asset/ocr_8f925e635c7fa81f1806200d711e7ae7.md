# 08 为什么祥子有车没车都是死路？

雨行深说老舍

说古论今天下事，拍案看书画行家。

你好，我是贾行家，这一次我们继续读老舍。

上一讲我们回顾了《骆驼祥子》的轮廓，这讲，我想来替祥子算算经济账。

小说里写道：祥子是个车迷，既不肯改行，也不愿意离开北平。那就会放松他的经济目标。他就竟没有头大洋车，也实现不了人生目标。

假如只分析情感、只谈情感和性格，也许我你不是很。咱们就从这个时代的社会经济角度看看。

《骆驼祥子》写于1936年，是老舍成职业作家之后的第一部长篇，也是他写作成熟后的标志。小说灵感来自老舍听来的两个车夫的故事。

《骆驼祥子》里的每个车夫，都是有代表性的：

最初的祥子是高车夫，甚至到梦想要开车厂。有个中年车夫，家里有五个孩子要养，拼尽全力在路上奔跑，也就仅够糊口。那个二强子，靠卖女儿买车，又因为酒后打死老婆，给老东家抽了。最让人心悲的是有个，和相的老头，和十二三岁的孙子合力一辆破车，最后，小孙子追不起就死光了。

说到底呢：车夫想的：拉车的那么凄惨吗？那他们为什么还非来拉车呢？不如咱们找一些历史资料，来论证一下这个疑问。

# 北平车夫的生存状况

我们先通过一组数据，来说说车夫这个群体。

说起来老北京究竟有多少车夫，可能会吓你一跳：1927年，全市车夫有五万五千人，到1936年的大约九万人，占当时北京市总年男性人口的六分之一。无论是历史会这么个数字很夸张，我们可以这么说：那个时代，至少每6.5个北平人，就有1个是靠拉洋车为养活的。

在这个数字代表的现实里，可以解读出很多道含义。

# 社会背景

从政治、社会和经济构成上看，车夫是民国北平最最大的社会群体。也就是说，关于车夫的需求，社会要影响城市治安和民生状况，很容易上升为政治事件。

老舍没有明白故事的时间，但我们可以推理。祥子拉北的那一代背景，应是1928年的国民政府到北平。为什么不是这五六年前的事？因为小说里，祥子是向国民党北部的黄先生。

国民党上主后，地方势力和北平府，都旧势力，都在混战的权力和车夫。洋车夫总会当然是各派系的斗争之地。

小说结尾：出典祥是作为运动车夫关史，被写入历史中是明枪的。这些事的史原之一，是1929年的北平洋车夫打砸电车事件。那次有司引发全成活动，事件平息后，有记者组织掀起舆论，这事件的推手，是国民中的两派在争夺工会控制权。对这个背景，老舍只能是暗示。

说完政治背景，再来看洋车夫引起的社会题。

民国时期的首都是南京。1928年，北京改名北平，降低为直辖市。所以，要讲北京，1928年之前的城市，我只能是说北京。

大量权育和富有商迁向机关城市，成了北京各行各业的大家庭。全市三万多家商，平均倒闭了3500家。而且，我刚才说了，北平这个已经有电车，到1929年，连环线都成了。

你看，市场急剧缩，替代的产业已经成气候。而洋车夫的失业却是多增加，占人口比重也越来越大，这是不争的。
