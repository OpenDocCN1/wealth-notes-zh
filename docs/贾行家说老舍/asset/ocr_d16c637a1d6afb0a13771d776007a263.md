有了现代生活，就有了现代化的焦虑模式。今天读的这部小说叫《离婚》，写于1933年，但小说里那些中年焦虑症状，和今天差不多。

# 《离婚》讲了什么故事

老舍说，这部小说的灵感，出自于开篇的人物张大哥，这是老舍很熟悉的一类北京人。

张大哥是那种看上去既得不错的小中等人。他五十岁上下，在市政厅不当公务员，过着体面，生活清闲，待人接物极为圆熟干练，喜欢跟别人喝洋茶，听其爱好能有一大串。

身为媒人，张大哥最恨离婚和自由恋爱。他觉得老婆李老鸹闷，请李老鸹到家里吃饭，结果都是张大哥自己受罪，李老鸹的人，学问和工作老都不搭，就是李夫人一向的不友好关系。李老鸹不，张大嫂是个泼辣的少奶奶，张家还收容着一个亲戚二爷。

张大哥竭力劝李老鸹下乡老家的妻子儿女到平半来。他的人生哲学，就是让身边人都按他的方式。

张大哥热心地给李老鸹寻了租房安家，很多无聊的同事都爱看李老鸹的笑话。这伙人里，有“吴太监”，当过太监，整天耳顺和脑疯。还有个小刘，是个小公务员，却心高志远。还有个叫小赵的无赖，是财政所所长太太的亲戚。

小赵给李老鸹来了个突然袭击，把李太太接到桌上，当众捉弄了他们夫妇一番。

李老鸹心太软，不当场发作。他总以为替她料理一下不碍事，小刘、那个同事太太们结成了一个类似联盟的妇女攻讦社。

李老鸹发现世人皆苦，那个二爷，是因为老婆带孩子和私人所，所以才沦的。房小大马太，则是被自私的丈夫所抛弃的，于是李老鸹很注意小马来厂文，觉得她可怜可爱。

李太太嫉妒，小马太好心去告诫李老鸹，说他们应该互相知道，李老鸹明白，在浪漫大看来，夫妻之道就是李老鸹的错。

这时候出了件事，张大哥的儿子张天被特别机关抓了。关是抓错了，这个天真得愚蠢，一无是处，根本没有参加革命的迹象。

张大哥束手无策。除了老鸹，同事们也都束手无策，邻里的人情，不过是彼此送礼物份子而已。

小赵总有办法。条件是张大哥得给女儿赵家亲戚的钱。李老鸹给了小赵一大笔钱，让小赵不要打草惊蛇。

没想到，小赵背后居然有势利眼，还计划要谋杀张大哥的小马太。这下事情大不了的，因为张大嫂知道了。张小天被放出以后，张大嫂又开始了她那种来来去去的生活。

这时候，小马太的丈夫带着情侣回来了，而小马太的丈夫也容不下这个，给了李老鸹最后的打击，他带着全家和二爷，辞职回了老家。

老舍很少宏观角度分析中国社会问题，但他很关心生活，还是揭示城市中小资产阶级丧失行动力的现象。

老舍最能感慨地写到人生的乏味和无意义，整部小说里，到处都是对自闷心理的描写。我们把老舍摘录起来，发现是可以连起来的。比如他写道：

> “每个人心里都藏着苦楚，生命只是和理想完全相反的事。把自己闷闷不乐的保住，是什么也没法没。他不应当是个小官员，是老老实话的官，李老鸹。一个男人可以多过活，男人下路的，男人下路了少过过？那个小，东西是有点毛病，他不该说闲话，又不该说闲话毛病，他不但不说话，还会说闲话，他就觉得自己是地狱里的人。看见一个老态龙钟的自己和一个衰老的母子，一同走在亡的路上，路上的花草是吹散的沙！

如果能有共鸣，也不用太焦虑。我们后面会说到，这本来说是人生的必然后图。

李老鸹早恋，是幻想和小马太一起到一个热带小岛上。李老鸹最后看到了小马太在巴黎的生活，以及，当他在小屋檐下生活，梦想也彻底破产了。

同样，张大嫂极度羡慕小马太，总想换到巴黎生活，但最后也发现，她自己也找不到一个。张太自由能活，是因为他是彻底的人，生活就是他那无其事地放弃下去。

我举过出一个出戏不喜的段子：当代人对中年危机，普遍中年的办法是出轨；修养比较高中产之，离婚再一点。于是现在起来，离婚中产，高中产再一点。现在就是，真是太也一般开，能一生步的地方，女性终于也能有点自己的主动了。

尊重人选择，但还要多一句，如果我选择是活没意思，那么，这种选择只会制造新问题，完全无助于解决问题。

使我们苦闷的并不是婚姻，而是生活本身。比如，李老鸹羡慕的小马太，并不是现实中小马太，而是，放弃了对妻子儿女的责任，背负着债务，真能娶到静和幸福么？或者像老鸹一样的傻人做不到。

# 两种理解方式

关于这件事，有世俗和哲学两种理解方式。

# 世俗理解

下篇文章是《福耀玻璃集团创始人，董事长王兴东的自白》。他在年轻时也不知道自己的生活有多糟，考过离婚，甚至有轻生念头，他自比100多行各职业的夫妻婚姻状调查。

结果发现，有19对夫妻对自己的生活全部满意，但是看起都福态的人，私下抱怨也不少。他的结论是：再婚多少次也没用，世上没有完美的幸福。于是，他也发现和福耀一样白头。

# 哲学思考

因为我们在谈老舍，我选择文学中的哲学。

第一位是19世纪丹麦作家、哲学家克尔凯郭尔，是他认为存在主义哲学的创者，关于迷惘和焦虑。

> “当人们发现自已失去了所有可能，或者觉得自己无法做出正确选择时，自然会陷入焦虑。无意识，是任何人都有的状态。人即是野性的和天生的，因此不受到约束，正因为人即是两者的结合体，所以必来焦虑。”

这焦虑，越敏感，越喜欢沉思的人，这种焦虑越显著。比如，老舍。

经过对婚姻非常复杂的思考理解，克尔凯郭尔的最终答案其实很普通，我们喝两酒的结论差不多，就是，结婚，你会后悔，不结婚，你也会后悔，要么结婚，要么不结婚，两者都会后悔。

克尔凯郭尔是个虔诚的基督徒，他认为，那像不像张大嫂那样，是世俗的生活，也不像老鸹那样，是理想中的审美生活，而是一种神学上的迷途，需要信仰。他认可的婚姻，必须达到这样的精神品质。

那他自己是这么办的呢？他虽然很爱自己的未婚妻，但是选了婚姻，因为他没办法这样精纯生活。

我很遗憾格尔克尔郭的思想，倒有两条是。第一，人中的虚无和焦虑是必定的。第二，对婚姻来说，并没有最纯的选择。

其实，换个角度想想：我们感到焦虑，恰恰是源于我们有选择的可能。因为自身的存在，是承受选择的自由。在你面临难选择时，焦虑的意义也出来了。

要是非宗教信徒，该如何是好呢？

加缪有篇经典论文《西西弗神话》。这个神话是说，神罚了石头的西西弗斯，让他每天把一块巨石推向山顶，但石头又因自身的重量滚落山来，如此往复，永无终结的可能性。这个状态，就像老舍李老鸹们感到中年危机，没有用处，没有希望，机械麻木。
