# 11 好端端的一个人，怎么就当汉奸？

说古论今天下事，档案斋里书行家。

你好，我是贾行家，这一次我们一起读老舍。

这一讲，我们来说说《四世同堂》里的汉奸群体。

我们在网上和陌生人交流，因为是虚拟身份，容易失去控制情绪。在争论中，很多人动不动就指责别人是“汉奸”。

我觉得，比起指责别人，下面这个让人不舒服的问题才更重要：在抗战时期，我不会去下杀手救汉奸？你别发火，也别急着否定，先冷静地想想，你坚决否定的依据是什么？

我可以从《四世同堂》里，找到两点原因。

# 汉奸的人格

第一个因素是个人性格。汉奸并不是什么怪胎。不是到特殊年代，大部分汉奸都是普通人。这也是为什么人们常说“不要去考验人性”，考验下去的结果，我们可能接受不了，而且也不会去了。

老舍有个观察：“假若完全是道德修养的积累；汉奸恰恰相反，是道德修养的削减。”咱们来看看，这个群体，人格上都具有什么状况？

对于里的汉奸，咱们从最简单的祁家开始。战前，瑞丰是军校职员，也算中产分子。但小说特意讲：他所受的那种教育，只是收学费和发证书罢了，既无了半点实际知识，也不给他建立思考力和判断力。老舍没有说他的教育工作，这应该是经过普通观察的。

瑞丰的关键词是无聊。就喜欢凑热闹，逢朋友的事都帮着张罗，为着穿白绸夹的小家碧玉。把北平看作也看成了一场丧事，有热闹看，能占小便宜就好。

蓝东阳找他去庆祝日本战胜的游行当领队。他居然答应，觉得这是出头露的机会。连他最后道念，都是因为装日本特务吓唬人。

当然，即使没受过学校教育，也该知道不能当汉奸。对这一层，小说里有个隐姓游水案：瑞丰发现某君时，这老头儿就冷淡东西。这类生活品位，是老舍向来讽刺的。

老舍觉得，能遵循传统道德文化的，就算不识字，也会懂得恪守伦理。中国文化的个人内部，是头头是天天然就存在了人的内心，只要向内去坚持，去挖掘就可以了。

而瑞丰夫妇喜欢“洋味儿”，是连中国人的传统都丢掉了，处于无文化里。他们既丧失旧道德思想，也化摸得到新文化的精华。不过，我们不完全同意老舍的这个估值，后后在会说到。

至于冠晓峰的精神世界，比瑞丰复杂一点。他晃荡着有本儿几岁，在军阀时期，做过县长大长，专门吃饭玩乐，会吹拉弹唱，尤其善于在官场里的迎来送往。

冠晓峰可以用“民族”“社会”这些名词溜须，但毫不在乎。在他的价值体系，生命可等于生活。他的生活，就是追求物质、女人、俸俸、金钱，其他的都不重要。

一个人眼里最崇高的人生目标，对另一个人来说，可能毫无价值。冠晓峰就是道德感没有意识的，权算，死不得才是一种真理，他还得人，只懂得利益这一种语言，没法在道德里面沟通。

被人抄家以后，他哀嚎：我做了什么错事，该受这样的报应？他可以说是一个很单纯的汉奸。

冠晓峰心直，胆子却不大，不像大赤包那样想得出格。是种人会不会考虑少，不是说，道德是能力问题。

# 汉奸根源的文化土壤

在人格、道德和教养上存有缺陷的人，什么时代，任何国家都有。如果我们仔细观察这些汉奸的形成，我们就看看属于中国传统文化的相关性了。

比如，蓝东阳是典型的变态者，有明显的反社会人格和妄想狂。他的阴影是病理性的。

有的研究者说，这个人物写得太夸张，缺乏深度感，但也值得注意的一点是：这种人现实里是有有的，尤其是在民国时期风行风发。

除了心理变态，蓝东阳并没有什么特长。战前，他在学校里当混子，是因为同事们都让上，老舍写：这个人身体虚弱，胆子也小，逢着给他个嘴巴，他连行李都不敢回来收拾。

可北平人（其实也是传统文化形成的典型人格），是要么很厉害的，要么则是和平，对侵犯总想要报官，这才让他得寸进尺。
