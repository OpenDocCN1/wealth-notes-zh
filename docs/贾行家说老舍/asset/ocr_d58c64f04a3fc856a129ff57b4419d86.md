# 12 “凑合活着”就是苟且么？

墨雨说老舍

说古论今天下事，拍案奇书贯百家。

你好，我是贾行家，这一次我们一起读老舍。

抗战是需要永久铭记的历史。说起来，也应该有不少抗战的经典文学作品了。我想起有一次小调查，结果是这样的。来欢迎您来参加，我这一次把思考题提前：请问，描写抗战的经典文学作品，你了解几部？

要是只有《四世同堂》，也千万别不好受，大多数朋友的答案，都不超过一部。

不是作家没写，而是《四世同堂》特别有穿越力，进入众人的魅力。道理很简单，老舍写的是实实在在的凡人，不是用案例强调某种观念，也不是依据的组成评分定善恶。

像小说里的白巡长，日本人进胡同抓人，他说要带路走暗道，但他才千万仔细地保护老街坊，邻居们也敬他像自家人。这样真实的角色，他的言行也就不容易假。因为他是旧警察，也从小成就不好。

人是复杂的，如果以为一种观念、一套理论模型就能管住人、区分人，那就太狂妄了。英雄是人格上的超越，奸计是人格的丧失，都是少数。

老舍对自己小说的解释，经常就说一句话：“这是真事儿”。《四世同堂》里的普通人：正义坎坷没恩惠，善良又自私，能够忍耐却没有进取心，才是我们普通人“真事儿”。真事儿什么样，他就怎么写。

这一分析小说里的普通人，当然也就在观察我们自己。

# 普通人的民族意识

全书第一个出场的是祁老人，他正好是老北京市民文化的标杆。

祁老人听说日本人进城了，做了两件有智慧的事情，第一是确认屋里有三个月的粮米和蔬菜，第二是躲进缸里看两头，顶住了门。看到邻居们手忙脚乱，他觉得没有智商。

在和孙小姐讨论应对日本人的日时，他说：“打我小时候，咱们就管小日本的欺负，我简直想不出道理来。日本人要占小便宜，这不可能差着儿孙讲个。”孙小姐说个沟桥大梁不出。他还出主意呢，说桥上有石桥子，那几儿要是交给他办，他怕把石桥拆给日本人大街了。

祁老人这时最关心的不是民族危亡，而是自己的生活还能不能过，他不想错过接受亲戚邻居祝福的场面。

我们前面说过的，他后来就收容了汉奸的孙子，要是只说到这儿，你觉得这不是那个老头子完全是鲁迅小说里那种被讽刺的愚昧角色？

可是，老舍写作的深度，不是思想和批判的深度，而是呈现生活和文化的复杂。

祁老人是没有远见的国民，但也是个善良正派的人。尤其在目睹了日本人的残忍之后，他变得不无恨起来，当街道被拆之后，他鼓着着翻着看枪击枪口进去。他的遗孀孙氏饿死街头，他要抱着孩子的尸体，去日本人讨人埋。

要是把这个情节当做一个人起劲愚味，因为战争逐渐变得勇敢，就忽略了精神和文化差异了。要知道，八十岁的人，不是那么容易变的。

下面，我们就像洋葱一样，来看着普通中国人的精神世界。抗战时期，最大的就是非民族利。这本来说该由老绅神来给日本石阶的言论，就有问题了。

其实，不只他的问题啊，胡同里最真诚的人，大家议论的题目，也在日进油城时关：预备一块布，用红脂涂涂红腮？要是看着咱们挂匾，咱们就住。西四爷后来又来了的住，和巡长犯了搭挡，一起帮着邻居们抵抗日本人。

老舍这么说，因为那一代的人观念就这样。他们年轻起，经历八国联军进北京，军警浑乱之中，难了的胡同就住了。对这些事情早麻木了，看不出这次日本鬼子和其他军队进成的不同之处了。

很多历史教科书，日本帝国主义划侵略的年代，就是说得当时的中国人缺少足够的民族思想，自信可以凭信感情感和文化修养来歪曲中国。

# 传统道德的弱点力量

但是，他们低估了中国人抵抗的决心和韧性。也就是说，在民族意识没有全面建立时，还有支撑中国人的第二精神力量，这就是传统道德。用小处里普通人的话说，就是有做的人良心好。

但是，道德也好，良心也好，是分层次的，广义道德还是超越部门阶级的人类良知。

小说里有个特别的日本人形象，是一位住进同里的日本老太太。她生在加拿大，没有受军国主义熏染，却始终有英德在。她遵循自己的行径，在感情上站在中国人一边。

这样的日本人有原型，当时的中国抗战以后，邻居，就有几位大作家、日本投降之前，邻居们想在这个老太太身上发泄恩怨，被她当劝阻了。

广义道德能属于全人类，因为首先属于自己。这是一种内心原则，只要属于哪种、哪个民族的人，只要有人，就有共同的道道德底线。

这和传统文化的道德有什么不同？还真不完全一样。否则，为什么那些善良的邻居，会想着去围攻这个并没犯过错的日本老太婆呢？

以中国为代表，受儒家文化影响的东亚国家的道德系统，有一个共同特点。就是传统道德是外部规定的，是在教育和教训中被强加下来的，缺少个人思考和选择的自由。

连传统道德修养里，段位最高的“慎独”，“吾日三省吾身”，也只具种对检省，并不是在对道德本身和合理性进行思考。

而小说里的普通人，当然是其不知然，不知其所以然了。他们家厚朴，坚持一些在今天来看很传统的道德守则。但这些守则是攸规在别人手里的。

比如祁天佑，他是个遵守传统商业道德的布店掌柜，就为了应对好坏而修改牌价，都觉得有点昧着良心。你要是说，这不是挺好的么，几天就缺少说的传统美德，如果真人都够够样，就不会有什么扣取诈、集资骗局，能节省多少交易成本！

但是，这些传统道德，是只能在传统熟人社会里行得通，就像胡同那样的老商号，一开口进的还是传统向乡的邻居学徒，一辈子的职业行为，都关系着整个家族的利益。

要面上的商业活动好像是装正式合同都废，背后可以是关系着真正的有限责任。现代商业是陌生人之间交易，需要的是契和法律约束。只用传统道德是没法约束的。

让祁天佑自己分析，他不会觉得自己的行为是违者局部的。可是，让他具体分析，恐怕只能说出情感或伦理上的理由，如“这样才安稳哪”，或者“祖师爷都如此”。

从现实来讲，这种强习传家习来的道德，与普通民众的支撑作用是很强的，即便没有清晰的民族意议，也让他们不向投降的日本人屈服。

# 丰富具体的民族文化生活

但因为这个非彻底的自由意志，传统道德需要很多外在条件，一再进行教化和确认。也就是说，在情感意义上，还是更具象的第三层：丰富具体的中国传统文化。

《四世同堂》，有一条线索，是祁老人过生日。我们前面说，无一福形多多危急，他都为此耽搁了。今天的年轻读者急，会得这岂不是大错。但放在传统文化里看，这是理所当然的正经营。

传统中国的价值观，是一层一层建立，向外辐射的，先修身齐家，而后治国平天下。对一个家庭来说，四世同堂是最最重要的两件事，挂面都加起来了。

中国人认为，有福气，就证明有德，而且不只是自己的德行，也是列祖列宗的福德彰显。祁老人执行的不是个人利己，而是人生和家庭事业的圆满。所以，这个生日是有信意义大的。

如果说老舍有一个信仰，那就是余华那些著名的题目：“活着”，哪怕只在生民就他时候活着。我们，今天还是先人亡者无知的集合，才是全活下来。
