# 01 《茶馆》凭什么盖世无双？

黑仔家说老舍
01 《茶馆》凭什么盖世无双？

说古论今天下事，拍案奇书贯百家。

你好，我是贾行家，这一次，我们一起来读老舍。

为什么从《茶馆》开始呢？因为这个剧本，不只是文章名家，也可以说是中国当代史料的标志。在中国话剧史，是“茶馆”是无功可争的最高峰。从1958年首演，每次上演《茶馆》，都是现意义化件。

在这个单元的三讲里，我先会跟你聊聊：《茶馆》为什么是中国现代戏冠盖世无双的杰作？然后，我们再来说戏台表演如何成就了《茶馆》？最后，来从现代社会的角度，聊聊“人生如戏”这个说法。

曹禺说：《茶馆》的成就“前无古人，盖世无双”，“尤其第一幕，完美程度达到了‘古今中外罕有’，曹禺虽《日出》二十几岁就写出了《雷雨》《日出》，是中国戏剧界的泰斗，也说《茶馆》盖世无双，可把自己的剧本文算在内。

曹禺为什么这么佩服《茶馆》？或者说，《茶馆》究竟厉害在什么地方？

# 高超的对白

您可能觉得，这个戏我看过，没什么高深，可句句都明白自白。其实，这正是它的厉害所在。

好戏和好诗一样，能产生大量名台词。人们一行引开下句。“举手删明月，低头思故乡。”“举杯邀明月，对影成三人”，简单是两句？但李白写的情话，人们就知道是用不了半章这场景。《茶馆》也是如此，里面的名句，一听就会记住。就这样话本流在我们心里。

到了消食大，陈旧的产式设计，效果一是让人感到大失，领，可能能是你心想的样子，好像它很久了。当年大看到iPhone4就是这个感觉。

《茶馆》里的经典台词，比如“我爱咱们的国呀，可是谁爱我呢？”（“你们还能把那点儿恩惠闲话不碍事吗？”。都不是简单的俏皮话，而是把中国人的心理琢磨到了一丝入纹的地方。

再比如那句“改良！改良！越改越凉，冰凉。”《茶馆》在法国公演时，观众问这台词何常在非常热闹。但是，不管是哪多妙，这句话里的音韵和节奏，是不会懂中文才能体会到韵。

这就是为什么每个语言，都要有自己的大师。甚至写到这个大白话出现，这种语言才算成熟了。老舍写出来的话，看起来平常，但是句句诗更好。从以此，一个意思，别人没法表达得更好的。唯一的选择就是继续引用它。

# 出色的人物刻画

这部戏最浅的厉害，咱们一块儿剥一层边说。

《茶馆》的三幕戏，只有一个场景，就是老北京一家叫裕泰的大茶馆。

第一幕的时代背景，是1898年的戊戌变法刚失败，一个初秋的上午。

为什么曹禺说这一幕高明呢？写这个时代的北京，没人能超过老舍。

从氛围上来说：它有最浓郁的市井生活跟士文化传，里面的每个细节，都有种神的东西。经得起一格一格地推敲和审视。

更是从技术上来说：所有情节，每句对白都是浓，但又一点儿牵迫的感觉都没有。

不敢相信，整部戏的人物超过七十。刚开始，就像往二十几个人物上台。各自都有不包的经历、身份和性格。你看茶馆，一幕话剧就在他身上住了。像高手对，每个角色、每个位置都调配计划得当了。让我们觉得，这个人物走进茶馆之前，有着丰富的过去；走出茶馆以后，会继续生活下去。

咱们来看看主要人物：

茶馆掌柜王利发，别看年轻，但精明强壮。善于世故。虽然有两个儿子，但心也得很高。老人终生只一个主意，就是想尽力把这家茶馆经营下去，维持一家生计。

我们最熟悉的，贯穿三幕暗线的人物：茶坊，房东、闲谈少事的秦仲义，是个自负很大的民族资本家。八旗子弟常四爷，为马什黄，爱打抱不平，敢做敢当。反清或反日耳、复心狠毒的人贩子刘麻子、性酷阴毒无赖的大太监庞德。

咱们就来看一看，老舍是怎么用一两句话刻画一个人的。

秦仲义一登场，第一句话是“来看老仆人年轻小伙计会做生意不是”。这是看人眼高低下的口气。但这时，他其实才二十多岁。为什么这么说？因为觉得自己是实业家哦，那入没说话的见识，这句话最不像年轻人说的话，却最符合他自信、故作老成的心态。

有个相面的唐铁嘴，插狗片，是到茶馆骗吃骗喝。在第二幕，他带一有段经典台词，因为什么：到“我没经不住大吃大喝了”——王利发说的那可要发怒了——可他接着说：“我当白相面儿了”。每次这儿，观众都大笑，大家听着老舍说，这台词还是成结构。也是他老舍听着来着。

至于接下来，唐铁嘴又怎么演示用英国烟袋白面白儿时，说“两大强国伺候我一个小人，这福分还少么”。这句话原，最能写出庸人俗相的无耻。简单几字，一半用于写鬼，一半用于写魔，对待善于天观眼，积累的人物，老舍都是先彻底琢磨透了才动笔。

这种效果叫“开口就响”，既让人物表识出来，而且能制造强烈的舞台效果。

# 高密度的情节设计

《茶馆》里的对话，是一句废话都没有的。看的时候会觉得不得节拍快，但这种情节密度，是现实主义不来的。
