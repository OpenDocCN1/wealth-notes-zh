# 你做好应付这些紧急情况的准备了吗？

现在是时候检查你的急救箱了...因为，夏天的事故发生率高于其他任何季节。

事实上，在夏天平均每天意外死亡人数高达 280 例，更不用说无数的烧伤，割伤，擦伤等。

所以，当遇到小伤，甚至更严重的伤害时，知道该做什么，不该做什么，非常重要。

治疗小伤：如果及时处理，大多数小伤都能迅速愈合，但如果感染了，伤势就会变得严重。处理伤口的第一步，就是用流动的温水清洗伤口。然后，用敷上温和的消毒药，用无菌纱布包扎伤口。

如果你用的碘是已经开封的，记住，开封的时间越长，它的药效会越强，就不能再用原来的方法消毒了。

治疗严重点的伤口：摔倒可能会导致严重的伤害。如果你怀疑摔得骨折了，不要移动伤者，除非必须这么做。要让伤者保持保暖、舒适，及时获得适当的医治。

如果发生了事故，你不能确定它的严重程度，要立刻打电话给医生，告诉他伤势如何，你做了什么，以及伤者目前的状况。医生这个时候会给你提供一些建议，告诉你你迫切需要采取什么措施。

为了帮助你在正确的时间给予伤者正确的护理，大都会人寿保险为你准备了一份新的急救图。它会告诉你许多常见的突发伤害该怎么处理。它里面还配有插图，还有说明，以及人溺水后的急救方法。
