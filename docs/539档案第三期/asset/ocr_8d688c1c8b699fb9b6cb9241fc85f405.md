# 舒适之奖

一个很喜欢户外休闲的人，透露了衣服的秘密：
C.R. 史密斯，美国航空公司总裁

“我的假期，选择了在加拿大魁北克大注苏河捕捞大西洋鲑鱼。从多年的经验中，我知道，要度过一个愉快的假期，你需要羊毛服饰。

“凉爽的天气，需要羊毛衬衫或毛衣。寒冷的天气，需要羊毛内衣。夜里需要羊毛毯子。晚上去圣劳伦斯河旅行，需要一件羊毛外套。还需要一条羊毛裤子抵御冰冷的水。防水靴上需要羊毛毡鞋底，避免在岩石上滑倒；里面要穿羊毛袜。

“羊毛对我们非常有用，让我们的生活更加愉快。没有羊毛带给我们的这些实质性好处，我们的生活会变得艰难。”

史密斯先生能如此依赖羊毛的舒适和性能，是因为大自然赋给羊毛纤维很多独特的特性。
