# 令人难以置信的 Zippo 打火机的故事
——一个相信打火机应该永远不坏的人的故事

Zippo 打火机之父，现在仍然是 Zippo 公司的促要负责人，他在父亲宾夕法尼亚的机器店里学会了做生意。

他在那里学会了手艺。他熟练地掌握了机械制造。而且，他还学会了一件事。

他学会了热爱工艺本身。根据 19 世纪美国的传统，他顺理成章地成为了一名工匠——制作工艺用品的人。做了很长一段时间。

如今，他制作了一款打火机，Zippo。对每个 Zippo 的制作，他都非常仔细，能够提供美国商业史上所有产品给出的最好保证。

如果你如的 Zippo 打火机不能用了一一不管你是什么时候买的，现在用成什么样了一一他都会免费帮你维修。

一些现代商人认为 Zippo 的产品过时了，所以，不是特别尊重 Zippo 人的商业理念。

但他做得很好。每天上床睡觉时，他都感觉特别好。这种感觉来自他制造出了实用的产品。一次又一次，一年又一年，一代又一代。一直很好一一即使有点小问题，他也会免费修复。
