# 我们能够让心脏不过快衰老吗？

有一天，我们将会知道。

因为，医学将一点点地解开风湿性心脏病、心绞痛和其他心脏疾病的秘密。

在美国医疗中心和制药公司的研究实验室，科学家们开始着手研究一些常见的原因：来寻找方法；控制每年因心脏病——国家头号杀手——死亡的人数。

通过一段时间的硏究，科学家们找到了希望，并取得了一定进展。一些新的药物和治疗方法，可以减缓心跳过速，减少致命的血液凝块的形成，加强心脏肌肉的供血能力。

今天在医生手中，这些医学武器，为保护生命献上了重要的礼物。例如，噻嗪类药物，能够降低高血压的危险。

这些成就令人欣喜，我们相信经过研究，未来会有更大的进展。因此，我们相信医生能够拯救因心脏病早逝的病人的日子越来越近了。

这就是现代药物的价值——保护健康，减少疾病带来的危害。

这则广告由数家处方药制造商，药品制造商协会成员共同赞助，其目的是通过研究，不断发现更好的药物。
