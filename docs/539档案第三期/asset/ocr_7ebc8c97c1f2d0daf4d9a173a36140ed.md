# 对年轻妈妈们的一次跟踪观察

这次跟踪观察，从一家大型超市门口开始的。这位妈妈很年轻——大概有 22 岁，或 23 岁。带着她的小男孩（也可能是一个女孩——通过服饰，你很难判断性别！）

她穿着雨衣和皮鞋——看起来更像一位高中生保姆，而不像一位母亲。但是，不要让她的外表欺骗了你。

她和年龄比她大一轮的妈妈们一样，熟知各类美食的制作过程，以及对孩子的喂养和抚养。这很奇怪吗？其实，她的大部分智慧来源于她的母亲，虽然她们可能都意识不到这一点。

她知道所有孩子喜欢吃的美味佳肴。她也熟知各类维生素、蛋白质以及矿物质对她那个正在换牙，长个的儿子的重要性。

看着她快速的从一个货架，到另一个货架——挑选着质量、营养和价格最佳的产品。最后，看到她停在了一个浓汤品牌前，聪明地拿了一系列金宝汤。

她选择了西红柿和蔬菜类，这是他们一家人最喜欢的，因为它们给家人带来了维生素和矿物质。她还选择了奶油浓汤——鸡肉味或芹菜味——因为它们的口感太嫩滑了。她用牛奶煨这些汤，进一步增加了食物的营养。

当然，她至少还会买一两罐培根豆，牛肉或青豌豆——因为比尔和小比尔对这些是百吃不厌（而且，她也知道这些汤对身体健康有好处）。

今天的年轻妈妈，并不像她们看起来那么无知，那么不成熟。

她的菜篮子，和身体健康的家人说明了一切！

每天.....一天一次.....鲜美汤品！
