# 这可能将是你读到的最有争议的一本书

因为在书中，这位具有改革精神的法官，为疾病——尤其是精神方面的疾病——的治愈，带来了新的希望，从根本上动摇了人们对药物的传统看法。

1920 年法官汤姆·R·布莱恩还是一位执业律师。自 1942 年以来，他一直 которой在俄克拉何马州当法官。那时候，他就开始怀疑很多“疯疯的”人，少年犯，以及罪犯，都遭遇着一些困扰，因为他们患有低血糖；也就是说，他们的大脑没有得到足够的食物。

通过和医生，以及实验室的研究人员共同研究，他证明了自己的理论，并进行了进一步的深入探讨。事实是，几乎任何人，任何年龄，只要缺乏活力，身体不是特别健康，精神萎靡，都可能是低血糖的受害者。让血液中血糖含量恢复正常，最好、最安全、最简单的方法是食品和食品补充剂——正如法官布莱恩在这本具有开创性的书中说的那样！
