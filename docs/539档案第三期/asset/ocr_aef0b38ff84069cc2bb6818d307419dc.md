# “科学贪吃”——一个能有效控制体重的新方法

在饮食中加入糖，可以让体重控制变得更容易，而且更可能长期坚持下去。

一茶匙糖，热量只有 18 卡路里。但这些快速功能的卡路里，可能让你吃饭时吃得更少，更容易满足。

人体最基本的需求是能量。工作，玩耍，运动……维持心跳都需要能量。这些能量来源于血液里的糖，而糖又来源于食物。

这种能量需求持续不断，从而保护你的大脑和身体的能量供应不会短缺。国内外著名院校的研究都表明，当你的血糖水平很低的时候，你就会感到饿。

提升血糖水平最快的方法，就是吃或喝含糖的东西，从而快速供应人体可利用的能量，并满足食欲。

这就是为什么许多新兴的饮食配方,通常都建议在两餐之间,摄入一些含糖零食,或饮料,从而防止饥饿感的侵袭。某权威营养师称之为“科学的零食”。

糖类通过限制食欲失控,让你的食量大大减少,减少了过量饮食,它才是肥胖的真凶。
