# 科技让洗得发硬的面料恢复柔软

从女人在溪边岩石上，用棒槌开始洗衣的每一天，女人們就一直寻找着让衣服洗得更干净的方法。

和许多其他领域一样，洗衣领域也有了很大的发展，如今的洗衣液清洗污渍的能力，可以说是已经发展到了极致。但依旧有一个问题。通常，洗的洁净如新的织物，同时也失去了它应有的柔软...它的纹理遭到了破坏...而且常常起球，这让人感到很失望。

甚至，其他现代的洗衣方法，如自动洗衣机和烘干机，甚至干燥晴朗微风的天气，在室外晾干，也无法克服我们用最好的方法清洗的织物变硬，失去光泽的结果。

不久前的一天，一个女人在杂货店的货架上找到一款神奇的产品。仅仅用了一次之后，她就把这个好消息告诉了她的朋友，她的尿布不仅变得很干净，而且似乎变得比刚买来时更加柔软，蓬松。她的毛巾晾干后，几乎变厚一倍。她的普通羊毛衫，洗后感觉像羊绒一样。普通的棉布床单和枕套洗后，变得像昂贵的高级密织棉布一样。孩子的尿布、衬衫、毛毯不再会划伤和擦痛孩子的肌肤。

这位主妇在洗衣服时做了什么？秘密就在伊利诺斯州的迪凯特的洗衣粉以及其他产品研发实验室里。

当意识到洗衣日的乌托邦尚未来临后，A.E. 斯坦利制造有限公司的化学家发明了一种神奇的液体，叫做 Sta-Puf®奇迹洗衣液。只要把它添加到最后的冲洗衣服的水里，Sta-Puf 就能给已经洗的发硬的织物带来新生。

毛巾布、绳绒线、灯芯绒会变得和以前一样柔软，舒适。大多数毛巾等织物晾干后，都不会变皱，很少或根本不需要熨烫。Sta-Puf®
