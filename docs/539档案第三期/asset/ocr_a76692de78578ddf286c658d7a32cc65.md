# 如何在 90°的高温热浪中
让自己感觉像春天般温暖

这是专栏作家，《基督死的那一天》
《林肯被枪杀》的作者 Jim Bishop 发表的一个悖论

达拉斯的夏天十分炎热。7月份的时候，温度会高达 90°，并持续不下。不过，那时候，内曼·马库斯商店的羊毛毛衣销量却非常高。过去的两年中，销量直接上升到了 53%。在其他许多城市，轻薄羊毛的销量也在上升。

为什么会这样？答案是空调。我们现在生活在一个温度相当稳定的时代。全国各地，从波特兰到泼特兰，从德卢斯到布朗斯威尔，我们的办公室、剧院、餐厅、商店和家中都装有空调。

如今汽车上也装有空调了。空调能控制温度，让人不再受热，是一个造福人类的发明，但同时也让体表感到冷。改变这种状况的方法就是羊毛——轻薄的羊毛毛衣、长裤、西装,两件套等。

不过，许多人在夏天穿羊毛制品，我依然觉得非常奇怪。所以我询问了几个专家。他们给出了答案。我引用一下，“羊毛卷曲的纤维，能把热空气锁在面料中，把冷风，冷空气挡在外面。然而，因为羊毛吸附性比较强——让人在湿热的天气，不再有那那种黏热的感觉。和羊毛松散的纤维，能在燥热的天气里，让凉风通过。所以，轻薄的羊毛制品非常适合燥热的天气穿——在凉爽的室内或炎热的街头都可以。”

从那时起，我就知道羊毛的作用了。当我看到大街上许多男男女女都穿着，或拿着羊毛制品——或发现我女儿金妮穿着羊毛长裤，推她的双胞胎孩子在炎热的午后逛商店时，我不会再感到惊讶了。我之前不明白为什么鸟儿都要躲在树叶下乘凉时，人们却穿着羊毛
