# 不管你开的什么车，

# 这里的方法都能让你更加安全地驾驶!

每次驾驶出行，你都有很大的责任。只有你小心、谨慎、礼貌地驾驶，我们的道路才会更安全。这里有一些安全驾驶的建议：

检查你的速度—每年大约 3/10 的致命交通事故，都是因为司机超速行驶。夜间，以及交通、天气状况不是很好时，请减速驾驶。

检查你自己—大约 1/14 的致命交通事故，都是因为司机身体不适，或精神状况不佳——比如，忧虑、疲劳、犯困—这些都会导致交通事故。永远不要在心烦意乱或疲劳时开车。

检查你的车—保证你的车况良好是你的责任——而不是你的车的责任。你可以自己判断刹车、轮胎、方向盘、灯光和挡风玻璃、雨刷等是否正常。如果你发现任何问题，请立即维护。不要要等到下半年一次的汽车检查，才去维修甚至是一些微乎其微的小问题。

检查你的驾驶习惯—即使最熟练的司机，偶尔也会有点粗心。他们可能变得对其他司机，以及行人不再那么有耐心——偶尔也会违反交通规则。记住，所有的规则都是用来帮助你，而不是妨碍你的。当你违反了交通规则，你就可能遇到交通意外。

所以，请把每次驾驶都当做生命一样重要！它确实很重要！
