# 眼睛里进东西后，我们该怎么做

因为你要看东西，你的眼睛必须露在外面。所以，我们的眼睛天生带有一些自我保护功能。眉毛（除非你把眉毛替了，画了个假眉毛），以及睫毛能阻挡周围空气中的灰尘进入眼睛。对一些突然飞过来的异物，你的眼睑会不自觉地突然闭上——要比你下意识的反应快很多。

但是，时不时地总有一些被风吹过来的异物，速度更快，直接进入了你的眼睛。眼睛的敏感神经瞬间开始反应。眼泪流了出来，眼睑眨动，试图冲去异物。然而，剧烈的不适，让你根本顾不上去弄出这些异物。

你的眼睛系统可能很快会自动清除这些异物，但如果它们失败了，采用下面的一些建议，你会免去很多痛苦：

+   1. 不要揉眼睛！揉眼睛会导致异物摩擦你的眼睛，或粘在眼睑，或眼睛表面。此时，你可能会感觉它们似乎“消失”了，但随后，它们可能会引发严重的感染。

+   2. 通过镜子，努力查看异物的准确位置，上下左右转动眼球。

+   3. 把干净的手帕的角护成一个小点。通常，用手帕上的这个角点，轻轻接触，就能轻松粘出异物。不要试图用镊子或其他锋利的东西去取异物。
