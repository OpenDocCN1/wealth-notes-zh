# 每个人只有两只

![](bbox=[0.208, 0.225, 0.791, 0.343])

你有没有认真想过一句古话，“以眼还眼”？这是 5000 多年前，一只眼睛和生命有着同等价值的时代，某法典里的一句话。

难道今天，我们的眼睛没有以前珍贵了吗？不是的，现在我们对眼睛的依赖程度，依然大于其他感官，醒着的每一刻，我们都要依赖它。我们仍然把它当做我们整个教学和学习系统的基础。

然而，现在和以前不太一样。实际上有很大的不同。现在，我们对眼睛的要求，远高于以前。

以前，我们用眼睛观看远处的游戏。或观测远处的敌人，一旦发现敌情，快速应对。而现在，我们花数小时阅读、看电视、缝纫、操作机械。都是近距离观看。

以前，我们驾驶马车，骑马。这种是正常距离的观看。而现在，我们开车。高速行驶。驾驶速度，要求我们的眼睛以闪电般的速度调整。我们的眼睛高度紧张，接受着巨大的压力。

以前，我们几乎只在白天的正常光线下用眼。而现在，我们长时间在灯光下近距离用眼。

这一切，请注意，都说明我们需要我们的双眼。真正令人难以置信的是，我们的眼睛一直创造着奇迹。
