# 说到啤酒的好处

# 两个国家的医生都表示认同

美国医生：医生，您觉得德国人的成功源于什么？

德国医生：源于一点，我亲爱的医生，他们不喝酒。

美国医生：但是，医生，我们觉得你们德国人喝酒很多啊。

德国医生：啊，但是，我们喝的是啤酒。而其他民族喝本民族的葡萄酒、威士忌、伏特加等，这些酒含有大量的酒精，食物价值却很少。我们的宗旨是，啤酒要含有营养丰富的大麦，能强身健体，而酒精度只含 3½%。

美国医生：你说酒精度只含 3½%，似乎是说这种成分对我们的健康无益。

德国医生：我不是这个意思。我们发现，少量的酒精，对人健康有益，而且可以让人精神振奋。但是，如果酒精含量过高，就危险了，一般的酒中，酒精含量不可能像啤酒这么少。

美国医生：可能你们民族之所以这么优秀，就是因为你们啤酒质叠比别的国家好。

德国医生：别误会。我们其实非常喜欢你们国家的喜力滋啤酒。它证明了自己在酿制过程中，每一步都非常谨慎。它口感浓厚，独特的制作过程，给人带来了大麦的浓香。它用活性很强的优质酵母酿制而成。它没有一点细菌，说明了在酿制过程中，对待杀菌的谨慎。它不会引起身体不适感，证明它成熟性好。

美国医生：简直太好了，医生。我一直在我的临床上使用啤酒。当我的病人需要食用易消化、且有滋补价值的食物时，我会给他们服用啤酒。而且，我发现，在外科手术后，病人吃不下其他东西，
