# 奇怪，我们并没有善待自己！

有时我们自己是自己的最大敌人。我们忙于照顾丈夫、孩子，家——于是，我们忽略了自己的健康。

“哦，我挺会照顾自己的，”你可能会说。“我在吃上相当讲究。我合理地控制着体重。当然，有的时候，我会失眠……早晨起来很疲惫。但这可能是事实吧，也许我真的老了，不像年轻时睡眠那么好了。”

这种隐藏着危害的“女性谬辖”对你的家人和你自己来说都是不公平的。

当你烦、喜怒无常的时候，你和很多女人一样，会找借口说是“天气”…或其他原因呢？

有时候，可能真的是这样——但是，如果你一天天都感到“难受”，那就不是这些原因了。

有可能你是自己养成的一个习惯的受害者……对能让人快速恢复“状态”的咖啡（或茶）中的咖啡因的依赖……

你的医生可能会告诉你——对某些女人来说——给她们敏感的神经系统带来最严重的影响的一种东西，就是咖啡因。

日复一日地饮用这种能提升精神的饮料，会让你变得紧张，易怒，烦躁不安。

然而，如果你无法改变这种习惯，你还希望不受它的影响：

你只要把咖啡因含量高的饮品，换成这种让人爱不释手的热饮——速溶马黛茶，以前根本没有这种产品。

它不会让你紧张，失眠，或头痛，因为它里面不含一点咖啡因。
