# 辛辛那提的家庭主妇

# 露出了真面目

从小一直肥胖的弗朗西斯·谢尔曼，脱变成了一位亭亭玉立的美女，过上了崭新的生活

在弗朗西斯·谢尔曼还是个孩子的时候，就有点肥胖。18 岁时，她的体重已经达到了 180 磅！

结婚后，她曾试过很多减肥方法，包括节食。这些方法让她变得暴饮暴食，非常想吃东西，结果总是反弹，甚至比减肥之前还胖。大量的运动，让她感到很疲惫。

那些日子，弗朗西斯几乎没有精力参加社交活动。她本身活泼的性格，似乎被一身肥肉禁锢了。

在多年不断的减肥尝试和失败后，她又尝试了斯托弗家庭减肥计划。

短短几周内后，“真正的”弗朗西斯似乎慢慢地回来了！她的身材变得更加迷人，她周围的世界变得更加精彩了。她的社会活动多了起来，与她的孩子们也有了更多的乐趣。

她的丈夫，一位成功的汽车经销商，房地产投资人，感到非常骄傲。
