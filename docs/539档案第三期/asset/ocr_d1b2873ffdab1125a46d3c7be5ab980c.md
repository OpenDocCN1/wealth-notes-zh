# 我不再因为我的假牙而不自在！

我曾经都不好意思和我的学生说话。我假牙上的气味，他们肯定能闻到。最后，我去看了牙医。他告诉我，只要我用牙膏牙刷刷牙，我的假牙就会有不好的气味。下面是他给出的假牙护理建议。

> “假牙的气味，是假牙缝隙中的食物残渣和细菌引起的。用牙膏刷牙——看起来也许是最好的办法——但是，却很难真正地清洁假牙。因为牙膏只能清洁牙齿‘表面’。而无法清洁导致假牙异味的食物残渣和细菌。”

> “如果你知道清洁能拆下来的假牙，最好的方式不是用牙刷一个个刷，而是直接完全浸泡到特制的假牙清洁剂中时，你就明白清洁假牙有多么简单了。”

> “这种特殊的假牙清洁剂，叫做保丽净。最近的一项调查显示，90%的牙医都推荐保丽净，而不是牙膏，因为它对假牙的清洁效果更好，更能有效地防止异味，而且使用方便。每天只要把你的假牙浸入水中，然后加入保丽净粉。立刻就会产生无数无形的氧气泡，去清洁你的牙齿。这些泡沫以及其他清洁成分，能够彻底地深入牙齿缝隙，除去食物残渣、细菌，甚至溶解烟草污渍和泛黄的牙渍。很快你的假牙就会变得非常清洁，甚至那些令人尴尬的假牙异味也会立刻消失。”

我的牙医说的没错。每天使用保丽净清洁牙齿。我的牙齿真的感觉非常清新——看起来洁白亮泽——在学生面前，我自信多了。
