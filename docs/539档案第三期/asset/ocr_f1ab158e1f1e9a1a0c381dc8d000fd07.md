# 当 “燃烧的小宇宙” 逐渐熄灭后

你可能遇到过这种情况……可能你还记得，当你刚开始工作时，你可是办公室里的红人。

工作简直是小菜一碟。老板喜欢安排一些艰难的工作给你，因为他觉得你是有能力的人。你就像一直 “燃烧的小宇宙”。

但是，几年来，你渐渐地感到不安，感到似乎在开始失去什么……就像一个投手，感觉自己的球失去了那种冲劲。

但是，医生却说你没有生病。而你却感到每天早晨起床时越来越疲惫。你感觉工作的压力开始变得像座山。

曾经有那么一段时间，你开始给自己找借口……但是这些借口太无力了。可能你几乎每天都感到紧张，疲惫……你不知道别人是否看出了你的变化。他们是不是也和你一样有相同的感觉？他们的 “小宇宙” 是不是也在逐渐熄灭？

你可能了解到，很多人都和你一样有同样的烦恼，当你知道这些烦恼的根源，其实来源于日常习惯后，你会感觉好很多……

你的医生会告诉你，对一些人来说，影响微妙的神经系统的最严重因素之一就是咖啡或茶中的咖啡因。

日复一日地饮用这种让人兴奋的饮料，可能会使你紧张，易怒，烦躁不安。但是，如果你真的无法改变这种习惯，该怎么办呢？

你应该把咖啡因含量高的饮料，换成这种让人爱不释手的热饮——速溶马黛茶。

它不会让你紧张，失眠，或头痛，因为它里面不含一点咖啡因。
