# 是不是一夜比一夜糟糕？

在寂静的夜里，你躺在床上好几个小时了，却无法入睡。

你不能判断自己为什么不能放松下来。你不断告诉自己，一切都会好的。

你之前也有过很多像这样失眠的夜晚。太多了。

躺在那里，所有的紧张和不安侵袭而来，你努力不去担心任何问题。天亮了，你希望自己不用起床。

很多夜晚，你都尝试入睡，可当你一个人的时候，你发现自己在沉思，甚至悄悄哭泣。

是的，每天每夜都是这样，确实不正常……

如果你一直情绪低落——焦虑，紧张——很可能是一个看似正常的习惯的受害者，那就是对能让人快速提升精神的咖啡或茶中的咖啡因的依赖。

如果说偶尔喝一杯咖啡或茶，里面的咖啡因就会让你感到焦虑，紧张；这很不现实——但是，如果你一杯又一杯地喝，一天又一天，一周又一周，一年又一年地喝呢？？？

你的医生会告诉你，对一些女性来说，影响微妙的神经系统的最严重因素之一就是咖啡或茶中的咖啡因。

日复一日地饮用这种让人兴奋的饮料，可能会使你紧张，易怒，烦躁不安。但是，如果你无法改变这种习惯，该怎么办呢？

你应该把咖啡因含量高的饮品，换成这种让人爱不释手的热饮——速溶马黛茶。

它不会让你紧张，失眠，或头痛，因为它里面不含一点咖啡
