# 一个适合发展的小镇

明尼苏达州南充市奥斯丁是一个典型的商业小镇，镇上一共有 24000 人口，他们中的一些人，仍然记得 1981 年乔治·荷美尔，还有他的朋友乔治·彼得森，在这里开了第一家肉店的那一天。奥斯丁如今有超过 4500 人，在这个雪松河边上，荷美尔包装工厂工作。这里是斯帕姆、丁提·摩尔、玛丽厨房、荷美尔火腿、小辣椒，还有其他 693 个全国知名肉类产品的发源地。

像许多在如“家乡”般亲切友好的环境中成长的企业一样，荷美尔公司对奥斯丁的感情是真实的。德克萨斯州、内布拉斯加、加利福尼亚州和马萨诸塞州的荷美尔人,都感觉奥斯丁就像自己的家，他们为奥斯丁的进步和成就而骄傲。

乔治·荷美尔&公司认为奥斯丁独特的风情和性格，引起那些寻找理想的中西部“家乡”，像荷美尔那样扎根，成长的行业和制造商的注意。

这就是奥斯丁：高素质的居民。勤劳，善解人意的劳动力。优质的地下泉水。大量的污水处理设施。便利的州际公路和铁路运输。拥有全国最好的学校之一，还有一个地区职业学校，能直接提供各种培训。它的降水平均每年 29 英寸。农场繁盛，产量稳定，品种多样。

如果你想进一步了解奥斯丁，它的居民，以及它能提供的机遇，请给我或奥斯丁工业发展公司来信。这是我的家乡，我希望我可以帮助你。

H. H. 科里
