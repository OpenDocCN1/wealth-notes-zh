# 关于冰茶，美国人教会了我什么

来自：格雷西·菲尔兹

“请看这里，亲爱的，”我对女主人说道。“我知道你们美国人都充满激情，生活节奏很快。但是，你是不是说得有点过于夸张了？

“当你的丈夫给我拍照，几秒后，就能把相片递到我手里时，我还能保持镇定。当你从一个小包里舀出几勺粉末，几秒钟就做成了巧克力布丁，我也还能保持镇定。

“但是，现在你告诉我，你要做速溶冰茶。作为资深饮茶爱好者的英国人，我想，我还是喝茶叶泡的茶吧，谢谢。”

“英国人传统的固执，”我朋友坚定地说。在我说“要上等红茶”之前，她把我拉到了厨房，把因斯坦速溶茶叶的勺子取出来，伸进了一个高大的玻璃瓶里。

“看好了，”她得意地说道。天哪，她直接打开了水龙头的冷水阀。出现了大量的冰！我品茶的时候，她充满期待地看着我。

好吧，这让我感到惊讶！“它尝起来和真正的茶一样，”我告诉她。

“傻瓜，它就是真正的茶。因斯坦速溶茶是 100%的纯茶...没有任何糖类添加剂，口味绝对纯正。”

天哪，我们英国人在犯错时，就会勇于承认...当我坐船回家时，我又带了几罐因斯坦速溶茶！
