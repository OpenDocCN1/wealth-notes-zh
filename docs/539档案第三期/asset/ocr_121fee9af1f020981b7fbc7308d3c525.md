# 我受够了

# 一年只有 8000 美元收入的日子

# 所以，我开始读华尔街日报

来自：一位订阅者

我在一个大城市工作。经过一段时间的观察，我注意到，读华尔街日报的人都穿得更好，吃得更好，开着更好的车，住着更好的房子。

“我受够了一年只有 8000 美元收入的日子，”我对自己说道。

“我要去看看华尔街日报是否能帮助我。”

长话短说。经过尝试，它确实帮到我了。因为自从开始读华尔街日报后，我的收入从每年 8000 美元，上升到了每年 14000 美元。

但这只是故事的一部分。华尔街日报不仅告诉我怎么赚钱——还告诉我怎么从我花的钱中，获得更多价值。

比如，日报中的一篇汽车文章，就教会了我在正确的时间里，去汽车交易市场购买二手车。一篇关于建筑用品的文章，给了我一些装修建议，让我节省了 900 美元。

关于食物的文章，教会了我如何在对的时间囤货省钱。关于税收的文章，教会了我怎么把税费降到最低。

这个故事很典型。华尔街日报可以帮助工薪人员每年多赚 7500 —30000 美元。它对喜欢做小生意的人非常有价值。对年轻人来说，是无价之宝。
