# 关于作者

约瑟夫·P·赫拉霍韦茨医学博士，欧洲大学的医学学位。现为抗衰老分子生物学教授，也是加州大学的老年医学中心副研究员。在过去的七年中，他一直在洛杉矶加利福尼亚公共卫生学院，进行公共卫生营养生物化学研究。在那里，他担任项目总监，和首席研究员，获得了美国国立卫生研究院的支持。

他之前是纽约大学医学院的研究员，哥伦比亚大学的内科和外科院研究员，巴黎索邦大学研究员。他在医疗和老年医学学术期刊上发表过许多文章。赫拉霍韦茨博士，还是老年团会员，纽约科学院的会员，美国生理协会，美国公共卫生协会，科学促进协会会员，现在是老年化研究与发展委员会顾问。
