# 写了 53 本美食书籍后

# 我被因斯坦速溶茶征服了

来自：艾达·贝利艾伦 《美食博览》作者

我想，在写完 53 本美食书籍后，觉得自己知晓了几乎世间一切美食，应该是人之常情吧。

这就是为什么今年夏天，当我从一位年轻的主妇那里得知一种我从未听说过　的食物后，感到格外惊讶。她给我斟上了一款冰茶，这是我喝到的最好的冰茶。然后，她说这是一款速溶茶，让我感到格外惊讶。

“哦，不是吧，”我回复到。“每款新速溶茶出来后，我都会去品尝一下——速溶茶不可能这么好喝。”

事实证明，我错了。好像真的有一款全新的速溶茶，叫做因斯坦速溶茶，是唯一一款 100% 纯茶。没有任何添加剂；口味绝对纯正。

做起来简单吗？我这位年轻的朋友，只是把一勺纯茶晶体加到了一小杯开水中，搅拌一下，然后在水杯里加上冰和自来水，就搞定了。不用等待，也不用去除滴水的茶包。

从写第一本美食书以来，我就养成了在写作之余，出去喝杯茶的习惯。从现在开始，我就可以不用出门，就能喝到因斯坦速溶美味冰茶了。
