# 6-8 岁儿童的神奇世界

这是 6-8 岁儿童的神奇世界，一切都那么忙碌、那么美好。当他们从家“毕业”，开始上学，独立生活后尤其如此。

你的孩子进入这个更广阔的世界，并不总是一帆风顺。“妈妈”和“爸爸”的指导，支持和安慰，和孩子蹒跚学步时一样重要。

例如，孩子上学早期通常都非常困难。孩子可能会变得害羞，胆小，或焦虑。这种行为告诉我们，孩子需要的是肯定，我们要给他信心，让他安心......而不是对他施加压力或刺激。在家庭和学校正确的支持下，孩子通常会有一个好的调整，获得勇气和信心。

父母对孩子在学校的功课，表现出浓厚的兴趣和热情，对孩子来说是最重要的。你要花时间去倾听，表扬孩子的进步、鼓励孩子不断成长。

即使你的孩子看上去很健康，也不要忽视常规的医疗和牙科检查。一定要问孩子的医生，孩子可能需要的任何“辅助药剂”，帮助孩子预防小儿麻痹症，破伤风、白喉和其他疾病。

因为孩子离开你的时间越来越长，一定要反复强调安全的重要性。告诉孩子什么时候能过马路，强调只有在绿灯时才能安全通过。

如果你的孩子学校功课做的比较吃力，那么要经常给孩子做一些测试。可以纠正的错误，通常是导致孩子成绩不好，最终不喜欢学校的原因。
