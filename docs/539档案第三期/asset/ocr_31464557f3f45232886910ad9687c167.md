# 对抗“葡萄球菌”的一场战争

来自：吉恩·威尔伯恩
休斯顿 nämlich事儿报医药新闻作家

一种致命的微生物正挑战着医学界。它的名字就是“金黄色葡萄球菌”，又称“葡萄球菌”。

最近，这种微生物在德克萨斯州托儿所夺走了 16 名婴儿的生命，引起了公众的关注。实际上，任何年龄，不论男女，都可能感染这种细菌。甚至没有生病的人也可能携带这种病菌。

更糟的是，“葡萄球菌”对很多种抗生素，以及其化疗药物都有耐药性。“葡萄球菌”已经发展成为一个全国性的社区问题——家庭的问题。

因为，它可以进入任何家庭——即使是最干净的家里也可能沾染这种细菌。皮肤即使没破损，也可能感染“葡萄球菌”。爬行的婴儿，游泳的人，都可能在看起来最干净的地板上染上这种细菌。

这就是为什么我们要改变我们之前的消毒方法。由于浴室是病菌传播的关键区域，所以浴室清洁剂，应该有杀死“葡萄球菌”，以及可能潜伏在浴室的其他可能致病细菌。

发表在权威刊物上的实验室测试表明，肥皂或者一般的松树油，都没有办法杀死“葡萄球菌”——我们所谓的“消毒液”也不是真正的杀菌剂——它无法杀死它接触到的所有病菌。

有一款家用产品，已经被证明是一种有效的杀菌剂。那就是来苏尔消毒剂。它能杀死所接触到的病菌——甚至包括“葡萄球菌”，以及许多致命病毒。
