# "长途直拨" 的神奇世界

上午时分，金色的阳光洒满了厨房的地板，一位年轻的纽约家庭主妇，拿起电话给远在旧金山的妈妈打了过去。随着她拨号完毕，一个设计精巧的全国通“机器”开始运转了。几秒钟后，她便听到了母亲开心的问候“你好。”

如今，由于长途电话系统:直接拨号系统,越来越高级，电话那端友好的声音传播速度也越来越快。这个出色的电话系统，可以让你不用电话接线员的帮助，就能轻松地拨打长途电话，就如给街对面的邻居打电话一样。今天，大约 400 个社区,超过 500 万电话用户，都能直接拨打 3500 万个长途电话号码。

在这个出色的电话系统背后，是一个错综复杂、迷宫般的电话设备——包括人类迄今为止建造的一些最复杂的设备。所有这些都是西电公司，贝尔系统的制造和供应单位制造的。

今天，我们的工作就是，大量生产这些复杂的电话设备。这些电子设备能像闪电般快速交换单位，确保每个电话都能接通......确保每个电话都像通过自动交换中心那样，以最直接的路径到达全国各地。机械电话簿系统能自动保留完整的通话记录。永久地为你记录通话记录，以及通话时长。

什么时候我们所有人都能用上“长途直拨系统”呢？明年年底，从东海岸到西海岸，超过三分之二的贝尔电话系统，都将覆盖长途直拨服务，近 800 万用户都将享受到这项服务。到 1965 年，预计所有贝尔电话系统，都将连上长途直拨网络。同时，西电公司将会在拨号交换中心制造、安装新设备.....让整个美国都尽在你的指尖上。
