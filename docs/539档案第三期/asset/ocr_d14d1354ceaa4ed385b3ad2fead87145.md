# 一块神奇的布，如何为你节省家务时间

科学的发展已经帮许多主妇减轻了大量家务工作，但大多数主妇仍然使用旧抹布除尘，清扫房屋。殊不知，你使用的抹布，会给你的家务量，以及做家务的时间带来很大差异。

其他用途的布上有许多线头，其实增加了工作量。或者那样的布和专门的清洁布结构不同，不能吸附灰尘和污垢。

如今，奇科皮制造公司投入了 100 多万美元，终于研发出了两种神奇的清洁布。这种布料并非编织——而是采用优质人造纤维，通过纹理和线头控制技术，粘合而成。

这种除尘布就是多蒂防尘布。它如丝般柔软，里面添加了适量的硅胶，在你清洁灰尘时，能够起到抛光和保护作用。研究表明——可能是“静电”使尼龙具有了吸附作用——这种神奇的除尘布，能像磁铁一样吸附灰尘！通过家庭主妇们的测试调查，许多人都反馈，她们打扫灰尘的频率是之前的一半，用了多蒂除尘布后，家具表面附着的尘埃变少了！
