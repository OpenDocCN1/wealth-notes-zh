# 如何赢得 “减肥大战” 的胜利

肥胖是健康杀手...它们是你必须立刻减肥的一个标志。记住，98%的肥胖都是因为吃的太多造成的。

在开始节食前，请咨询你的医生...尤其是为你提供蛋白质，维生素以及矿物质，保护你身体健康的食物。

许多食物都能提供这些营养。下面是你每天可以借鉴参考的一些饮食：

生奶...每天至少需要一品脱——最好是脱脂牛奶——包括平常烹任用的牛奶,或牛奶制品,如奶酪。

肉、鱼、家禽、鸡蛋和奶酪...每天食用两到三次。肉可以烤或煮。多食用瘦肉。

土豆...中等大小，烤或煮。

麦片和面包...每餐一片全麦面包，或营养面包。

蔬菜...每天至少吃 3 种蔬菜,包括绿叶菜或黄色蔬菜。吃任何你想吃的蔬菜沙拉，但只能用柠檬汁或醋酱拌。

水果...每天吃 2 个,包括柑橘,或其它含维生素 C 的水果,如西红柿。不要选择水果罐头。

黄油或人造黄油.....每天 3 小块，包括烹任时使用的量。

如果你把饮食调整为这些食物，避免高热量的甜点，油炸食品、肉汁、酱汁、餐前小零食，或吃得过饱，你多余的体重就会慢慢消失。

你的新饮食习惯，能够让你的体重持续下降，让你更健康，更长寿。
