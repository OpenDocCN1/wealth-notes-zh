# ## 如何广告优化？

> 节选自「MOJI」的主题

广告优化实际就是一个慢慢缩小范围的过程。

就像出海捕鱼，为什么要用渔网？因为我们不确定鱼在哪里，首先要选定一个渔网能够覆盖的范围，撒下网后，还需要一定的时间等鱼儿游到渔网覆盖的范围内（收集的数据达到一定的统计意义），然后再慢慢收缩，最后把网拉上来，扔掉小鱼，死鱼（排除转化率不高的人群），继续撒网。慢慢地我们就知道哪个海域，什么时间段，会捕到什么样的鱼。
