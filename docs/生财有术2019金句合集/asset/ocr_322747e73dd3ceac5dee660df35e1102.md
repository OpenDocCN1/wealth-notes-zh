# 大闸蟹一生要逃离几次舒适区？

> 节选自「贾万兴」的主题

当我们有了对人对事的方法论，以及对外界对自身的认知体系后，那种感觉就像一个螃蟹，我有一个壳，在这个壳里我过的很安全很舒服，这就是大家常说的舒适区或者说边界，这个边界会给你相对的自在，但是也会封死你的成长。

很多同学可能不知道，大闸蟹一生要脱二十几次壳。

每一次脱壳对大闸蟹来说都生死攸关，他把保命的壳脱下去，这时候天敌可能去攻击他，但是大闸蟹只有不断的脱壳，才能变得更强大，更成熟。
