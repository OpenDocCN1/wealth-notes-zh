# 抖音带货不仅仅是追求ROI

节选自「赵鑫」的主题

很多品牌在讨论抖音带货这件事的时候，仅仅是看到了消费者购买这个行动，至于如何产生认知，如何勾起消费者兴趣，如何在消费者做深入研究的时候，更多的展现自己正面的东西，如何让消费者给出正反馈，这些提升转化率的事情统统不管。

根本没有搞清楚营销推广的核心，也没看到整个销售过程的全貌，盲目在追求ROI。
