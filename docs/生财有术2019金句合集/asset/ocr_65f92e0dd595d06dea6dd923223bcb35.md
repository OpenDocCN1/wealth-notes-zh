# 赚钱要找到适合自己的方法

节选自「阿彪」的主题

很多东西在尝试之前，看到博客，看到别人赚钱怎么怎么厉害，非常兴奋。自己去干的时候，其实并不是那么美好。几天的功夫可能就证明，这个方法在这个方面可能不适合。

所以，要尽快找到适合自己方向的方法，然后下猛药，火力全开。方法不要多，往往绝招就是那么一两个。关键的是尽快找到那个适合你自己方向的招数。
