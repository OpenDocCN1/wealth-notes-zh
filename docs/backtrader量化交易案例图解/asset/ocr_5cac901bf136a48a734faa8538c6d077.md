# 8.10 K线图绘制

在BackTrader程序中绘制不同风格的K线图非常简单，只需修改style参数即可。

实际上，很多专业可视化图表模块库，本身都没有内置的K线图模块。并不是开发者不想增加K线图函数，而是因为K线图涉及很多金融专业的细节，包括时差、数据补缺、交易日历等，非常复杂。比如，大部分金融交易产品都有休息时间，还有节假日，这个时候就会出现“数据跳空”问题。如果采用传统的绘图模式，就会出现数据缺失，但在K线图中，又必须作为正常的连贯数据。
