# 3.4 策略编程模板

BackTrader策略的编写，对于初学者来说有一定的门槛，所以笔者特意开发了一个策略编程模板，方便大家套用。大家可以通过该模板，编写出风格一致的策略程序。

策略编程模板代码如下：

```
class TQSta001(bt.Strategy):

    def log(self, txt, dt=None):
        # log 记录函数。
        dt = dt or self.datas[0].datetime.date(0)
        print('%s, %s' % (dt.isoformat(), txt))

    def __init__(self):
        # 默认数据，一般使用股票池当中下标为 0 的股票，
        # 通常使用 close, 作为主要分析数据字段。
        self.dataclose = self.datas[0].close

    def next(self):
        # next 函数是最重要的 trade 交易 (运算分析) 函数,
        # 调用 log 函数，输出 BT 回测过程当中，
        #工作节点数据包 BAR, 对应的 close 收盘价。
        self.log('Close 收盘价, %.2f' % self.dataclose[0])
```

策略编程模板当中的log输出函数主要用于信息输出和编程调试。在策略代码模板中，最常用的两个核心函数如下。

+   - init： 初始化函数。
- next： 节点策略执行函数。
