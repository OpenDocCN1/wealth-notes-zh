图8-15 默认vol成交量参数运行图

默认绘图函数代码是：

```
cerebro.plot(style='candle')
```

这其中省略了两个和volume成交量相关的参数，这两个参数都是布尔格式：

+   - volume布尔变量参数，默认为True，表示绘制成交量图形，若为False，则不绘制成交量图形。
- voloverlay布尔变量参数，默认为True，即使用叠加绘制模式。若为False，则表示非叠加模式，采用独立的sub子图绘制成交量图形。

在默认模式下，plot函数调用代码：

```
cerebro.plot(style='candle',volume =True,voloverlay = True)
```
