源码中的信号函数定义代码如下：

```
class SMA_Signal(bt.Indicator):
    #定义信号名称 lines=
    lines = ('mysignal',)
    # 定义MA均线策略的周期参数变量period, 默认值是15
    params = (('period', 15),)
    # 调用初始化函数
    def __init__(self):
        #增加一个信号参数 mysignal
        #mysignal信号源自当前的价格数据
        #与SMA均线价格的差值，默认是收盘价Close
        # >0:long, 多头信号, 买入
        # <0:short, 空头信号, 卖出
        # =0:None, 无操作
        self.lines.mysignal = self.data -
            bt.indicators.SMA(period=self.p.period)
```

信号交易的类定义源自Indicator指标类，而不是Strategy策略类。
Signal信号交易模式基于买卖点信号，源自Indicator指标类。从某种意义上来说，可以将交易信号视为一个自定义指标。理论上任何一个金融指标都可以被视为买卖信号。
信号函数定义代码的第一行必须是lines，用于定义交易信号变量名称。lines在BackTrader软件中有特殊含义，其是一种基于时序的数据组链条，相当于Pandas中的Series数据列。
一个lines就相当于一组数据。大家看看Pandas的金融数据，有开盘价、收盘价等不同的纵向字段。其中的一列就相当于BackTrader的一个数据组。在案例源码中，使用变量名称是mysignal（我的买卖信号），也可以修改为其他名称。
信号模式编程的代码相对简单，next策略执行函数也可以省略，甚

至只要一个init初始化函数即可。函数中的信号变量名称和lines代码中定义的名称必须是一样的。

在BackTrader量化软件中，买入价格默认都是收盘价，也可以改为开盘价、最低价、最高价等。

mysignal信号计算结果有三种情况：

+   • 大于零，就是多头信号，可以买入。
+   • 小于零，就是空头信号，可以卖出。
+   • 等于0，无须操作。

在BackTrader量化软件中内置很多与long信号和short信号相关的专业函数。最简单的信号模式编程，就是把与信号函数相关的代码放在一起，通常放在init初始化函数中，步骤如下：

第一步设置量化入口变量；

第二步初始化参数，读取交易数据，添加数据；

第三步，编写add_signal添加信号函数。
