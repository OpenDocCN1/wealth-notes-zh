sma = bt.indicators.SimpleMovingAverage(self.data, period=15)

plotinfo变量采用的是dict字典格式，常用内置参数设置如下：

```
plotinfo = dict(plot=True,
    subplot=True,
    plotname='',
    plotskip=False,
    plotabove=False,
    plotlinelabels=False,
    plotlinevalues=True,
    plotvaluetags=True,
    plotymargin=0.0,
    plotyhlines=[],
    plotyticks=[],
    plothlines=[],
    plotforce=False,
    plotmaster=None,
    plotylimited=True,
)
```

以上参数，常用的有subplot、plotname、plotskip和plotabove。对于普通用户而言，比较常见的plot绘图参数是subplot和plotname。
