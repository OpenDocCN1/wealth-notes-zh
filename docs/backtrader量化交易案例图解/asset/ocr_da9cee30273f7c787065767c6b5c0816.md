# 1.2 进入神奇的Python世界

本书使用的是zwPython集成式开发平台，在TopQuant极宽量化网站可以免费下载。有关zwPython的介绍和使用，请参考zwPython内置的中文用户手册。

zwPython采用“开箱即用”模式，无须安装，解压即用。自2016年起，zwPython只提供Python 3.x-64位的版本，只支持Windows 64操作系统。为保持版本的稳定性，方便用户开发学习，自2019年起，zwPython每年定期升级版本。

为统一开发环境，zwPython必须解压到安装盘根目录下，建议为D盘根目录，默认为d:\zwPython。笔者建议，将其安装到SSD固态硬盘。

zwPython 2020版，是平台自发布以来最大的一次升级，其特点如下：

+   - 面向大众用户，重组架构体系。
- 增加了大量的面向入门用户的模块库。
- 增加了vscode开发平台，并内置了大量Python开发插件。
- 集成Spyder-v4版，用户界面支持中文菜单格式。
