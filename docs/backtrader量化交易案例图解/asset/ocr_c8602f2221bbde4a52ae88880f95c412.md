为文件数量太多，而且案例也没有涉及，一般只需要复制与案例相关的数据即可。

在进行实盘交易时，对于回测时间周期，一般设置为30天。所以回测起始时间，一般为30天以前。

如果回测起始时间和回测终止时间都设置为空字符串，则表示对全部数据进行回测分析。

