在参数设置环节，有一行过滤器函数代码：

```
#----ha-k
data.addfilter(bt.filters.HeikinAshi)
```

BackTrader的过滤器函数addfilter可以用于很多领域，比如数据梳理，以及对回测结果的筛选。

在BackTrader量化程序中，Filter过滤器部分是通过Filter子模块完成的，其中的核心是filter.seesion子模块，如图8-21和图8-22所示是两个模块库的架构图。
