佣金设置采用的是小数模式，不要使用百分比符号。在策略类函数 next 函数中的买单、卖单环节，没有做任何修改。

在策略类 notify_order 订单管理函数中，当订单执行完成后，在输出数据代码中增加了一组佣金输出数据。

```
if order.status in [order.Completed]:
    if order.isbuy():
        self.log('买单执行 Buy Executed,成交价: %.2f,小计 Cost: %.2f, 佣金 Comm %.2f' % (order.executed.price,order.executed.value,order.executed.comm))
        self.buyprice = order.executed.price
        self.buycomm = order.executed.comm
    elif order.issell():
        self.log('卖单执行 Sell E Executed,成交价: %.2f,小计 Cost: %.2f,佣金 Comm %.2f' % (order.executed.price,order.executed.value,order.executed.comm))
```

在输出信息中增加了佣金信息，以及总的成交费用。

系统后台会自动计算具体的佣金数据，通常在订单设置后的1~2天，会根据设置找到匹配的市场价格，执行交易操作。

如果市场波动比较大，或者价格设置不合理，那么成交的时间节点就会晚一些，或者最终未能成交，出现滑点情况。

在佣金计算方面需要注意的细节是：在“设置订单”时尚未正式扣除佣金，所以在计算“最终资产总值”时，最终的佣金数额会有少许误差。
