# 4.3 next策略执行函数

next策略执行函数是策略编程的核心，也是具体执行策略运算的代码。很多人认为策略中的next函数是一个未来函数，这是一种错误的观点。

next函数是当前时间节点的数据分析 к 策略执行函数，是一个按时间节点迭代模式调用的函数。
