由图9-2可以看出，函数主要相关的子模块库有： Cerebro、 btrun 等。

量化分析编程主要有两个环节：

+   （1） 在主程序源码中的数据设置部分，设置各种常用的分析指标，并增加addanalyzer分析指标，添加函数块。

+   （2） 当量化程序运行完成时，在量化回测结果数据中提取各种分析数据。

在量化回测结果数据中提取各种分析数据，需要从量化回测的返回值中获取分析数据。

```
print('\n#3,调用 BT 回测入口程序, 开始执行 run 量化回测')
results=cerebro.run()
```
