# 10.4 案例： PyFolio量化分析

本节案例程序文件名是： btr_e015folio.py，用于介绍PyFolio模块的使用。

本节案例在运行时，有时需要等待一下，因为PyFolio需要读取国外的大盘数据。PyFolio源码内置SPY标准普尔指数，也有德国/法国等金融市场的指数，数据源默认是Yahoo（雅虎财经）。程序在生成PyFolio图表时要读取实时的SPY标普数据，在读取国外数据服务器时网络可能会比较卡，甚至可能网络会中断，从而出现延时或者无法生成图表的情况。如果遇到这种情况，就要重新连接网络，或者换个时间重新运行，也可以屏蔽PyFolio相关语句的输出。
