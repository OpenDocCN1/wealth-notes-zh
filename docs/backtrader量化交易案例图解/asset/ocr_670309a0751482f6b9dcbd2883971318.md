init初始化函数：

```
def __init__(self):
    # 默认数据，一般使用股票池当中下标为 0 的股票，
    # 通常使用收盘价作为主要分析数据字段。
    self.dataclose = self.datas[0].close
```

案例策略中的交易价格数据，采用的是收盘价。程序代码使用 dataclose，作为收盘价的别名或者短名称、变量名。

在本案例中只有一只股票，如果有多只股票，则数据代码会有所不同。

本案例中策略编程的重点是next节点策略执行函数，代码如下：

```
def next(self):
    # next 函数是最重要的 trade 交易（运算分析）函数，
    # 调用 log 函数，输出 BT 回测过程当中，
    # 工作节点数据包 BAR，对应的 close 收盘价。
    self.log('Close 收盘价，%.2f' % self.dataclose[0])
```

本案例的策略编程使用的是空策略，所以系统只显示每天的交易价格：收盘价数据。输出的收盘价，交易数据是按日期的正序排序的，最新的日期输出在最后面。

next节点策略执行函数，主要负责对买卖点交易时间进行筛选。实际交易时间是第二天或者后续时间，所以用next作为函数名称，表示下一个交易节点需要处理的事情。
