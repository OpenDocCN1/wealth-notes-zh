# 11.1 量化回测分析流程

从本章开始讲解BackTrader的实盘操作。前面章节讲过，一个完整的量化回测分析/交易流程可以分为四个步骤：

+   - 第一步设置一个回测主函数。
- 第二步设置量化回测参数。
- 第三步调用量化回测程序，开始run运行量化回测分析。
- 第四步回测数据分析，或者根据回测推荐结果进行交易。

其中，第二步的量化回测参数的设置相对比较复杂，包括设置数据源、起始资金、回测数据、读取数据、添加数据，以及进行数据清洗等预处理工作，然后，添加策略和与策略相关的变量参数、策略分析参数。

第三步的调用量化回测程序和第一步的设置回测主函数类似，都很简单，通常都只有一行代码。
