# 5.2 Smart Staking智能动态仓位管理

在进行买卖操作时可以灵活设置买单和卖单，而在程序中运行买单和卖单时，默认的交易单位为一手。但买卖函数中的参数size可以灵活地设置动态交易数额，这种模式属于智能动态仓位管理Smart Staking，如图5-2所示。

每个参与市场交易的人员，都在努力建造自己的“系统”，并参与到市场竞争中。

量化软件通过智能动态仓位管理Smart Staking，动态调整买卖数额参数来调整策略的买卖行为，让原本无利可图的策略变成能够盈利的策略。如图5-3和图5-4所示，这两个图都是采用简单的SMA均线交叉策略的操作图，同样的交易数据，同样的时间周期，但图5-3使用的是传统的策略操作模式，图5-4结合了智能动态仓位管理Smart Staking对策略进行了优化。
