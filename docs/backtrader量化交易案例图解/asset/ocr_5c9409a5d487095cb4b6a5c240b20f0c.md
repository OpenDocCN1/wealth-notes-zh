BackTrader的策略函数源自Strategy类函数，一个完整的策略函数至少包括以下两个策略函数。

+   - __init__：策略初始化函数。\n- next：策略执行（run）函数。

此外，较常用策略函数还有如下几个。

+   - notify_order：订单信息管理函数。\n- notify_trade：交易信息管理函数。\n- stop：策略回测结束函数。\n- log：自定义输出函数。
