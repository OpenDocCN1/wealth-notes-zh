# 图8-4 美式K线图

在K线图中，每天的图标信息都包含开盘价、最高价、最低价和收盘价四组价格数据，但曲线图通常只有收盘价一组价格。在绘制K线图时，通常只使用1～3个月的数据，这样使得细节更加突出。

K线图和蜡烛图一般都是使用月周期数据进行分析的，很少使用年度数据，如果回测周期比较长（比如超过6个月），那么在细节方面就难以表达清楚，通常都是用最简单的价格曲线模式。

ohlc美式价格曲线也称为美式K线，每天的图标也包含开盘价、最高价、最低价和收盘价四组价格数据，这种格式相对比较少见。
