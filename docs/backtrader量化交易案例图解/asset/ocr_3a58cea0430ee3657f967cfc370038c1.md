# 10.5 解读专业量化分析图

在第10.3节的案例程序中，调用PyFolio模块库能够生成多组专业分析图，本节对这些图进行一些基本解读。

通常，运行量化程序最终只生成一张图，但运行PyFolio案例程序会生成多张图，其中价格曲线主图和原来的相同，然后PyFolio会根据回测结果数据，生成多张专业量化分析图，PyFolio生成的这些图被称为梭张图（tear sheet），也被称为泪滴图，下面对PyFolio生成的一些图进行展示。

如图10-9所示为价格曲线图。
