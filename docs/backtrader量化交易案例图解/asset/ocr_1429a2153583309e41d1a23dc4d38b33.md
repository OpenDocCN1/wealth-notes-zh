# 图12-5 时间周期参数测试结果图

由图12-5可以看出，当时间周期参数为5天时，盈利最多；当时间周期参数超过30天时，开始出现亏损情况。

测试策略的目的除了测试回报率以外，更要测试策略的稳定性。

可以使用“3M测试原则（即多品种、多周期、多项目）”，来衡量量化策略的稳定性。

大家使用多品种测试数据时，品种要多，每轮可以测试10～50个品种，且必须使用股票池模式进行测试。

多周期，就是采用多种时间周期，一般采用1个月、3个月、6个月和12个月这四组周期模式。

使用多项目测试数据，是因为同样的一个策略，在不同项目领域使用效果的差别是很大的。同样的策略，可能在股票市场收益很好，到了外汇和数字货币市场可能收益就不好了。同样，在外汇市场盈利的策略，在股票市场使用也不一定能盈利。而且同样的策略，在不同的项目中使用，策略的参数也可能完全不同。
