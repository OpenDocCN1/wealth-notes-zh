由图10-7可以看出，在PyFolio子模块中，库主要的分析属性有 AnnualReturn、SQN、TradeAnalyzer等。

此外，需要强调的一个细节是UTC时区问题。在使用PyFolio时，需要使用to_utc函数对数据进行时区转换，不然会出现数据混乱。

```
xret=to_utc(xret)
```

to_utc函数是时区设置函数，源自PyFolio.untils工具模块。PyFolio默认使用的是美国东部时区标准，在使用PyFolio时需要进行时区转换。

很多用户在使用PyFolio时，会出现数据不同步等问题，主要就是因为时区设置问题。

使用create语句创建分析图表也是PyFolio中最核心的函数，如下：

```
pf.create_full_tear_sheet(xret
,positions=xpos
,transactions=xtran
,benchmark_rets=xret
)
```

QP公司的其他量化分析模块，包括多因子分析，也通过这类create语句生成各种专业化的分析图表。

create_full_tear_sheet图表绘制函数，位于PyFolio模块库的Tears子模块当中，也是Tears子模块的架构图，如图10-8所示。
