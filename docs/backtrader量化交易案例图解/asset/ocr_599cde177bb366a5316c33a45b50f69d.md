至只要一个init初始化函数即可。函数中的信号变量名称和lines代码中定义的名称必须是一样的。

在BackTrader量化软件中，买入价格默认都是收盘价，也可以改为开盘价、最低价、最高价等。

mysignal信号计算结果有三种情况：

+   • 大于零，就是多头信号，可以买入。

+   • 小于零，就是空头信号，可以卖出。

+   • 等于0，无须操作。

在BackTrader量化软件中内置很多与long信号和short信号相关的专业函数。最简单的信号模式编程，就是把与信号函数相关的代码放在一起，通常放在init初始化函数中，步骤如下：

第一步设置量化入口变量；

第二步初始化参数，读取交易数据，添加数据；

第三步，编写add_signal添加信号函数。

add_signal添加信号函数代码如下：

```
print('\n\t#2-3,添加 BT 量化回测程序对应的买卖点 signal 信号参数')
print('\t# 案例当中是把 MA 均线与当前价格的差值作为买卖点信号')
print('\t# 买入 long, 卖出 short 信号, 都是采用这个')
cerebro.add_signal(bt.SIGNAL_LONGSHORT, SMA_Signal,period=15)
```

在传统策略模式案例中，这个步骤是添加策略函数add_strategy，本案例是添加信号函数add_signal，即添加交易信号。
