# 13.1 Indicator指标模块库架构图

BackTrader量化软件支持两种交易模式：

+   - Strategy，传统策略模式，即策略类函数模式。
- Signal，信号交易模式，通过设置买卖点信号进行交易。

如图13-1所示是BackTrader量化软件中的Signal信号交易子模块属性示意图。
