# 11.4 实盘交易及其隐性规则

目前，大家对于BackTrader的使用属于准实盘交易阶段，准实盘交易和实盘交易最主要的差别在于以下两个方面：

+   - 数据源的实时更新。
- 操作资金的实际投入。

如果做实盘交易，必须使用每天的最新数据。在第11.3节案例程序的输出信息中，在2018年12月18日有交易数据，如果在18日收盘时运行这个程序，程序会推荐买入股票代码为2046的股票（买入价格是6.78元），再通过交易软件设置买单就可以了。
