# 11.5 Stake交易数额和Trade交易执行价格

在第11.3节的案例中进行买卖操作时没有说明具体的交易数额，而是使用用户预设的默认交易数额，但每次的交易数额都可以通过参数进行设置。

在主流程中，设置每次交易是10手。

```
print('\n\t#2-5,设置每手交易数目为: 10, 不使用默认值: 1手')
cerebro.addsizer(bt.sizers.FixedSize, stake=10)
```

使用固定的交易数额的方式，相对来说更简单方便一些。

交易数额的变化不一定都是正优化，也可能是负优化。初学者在Position设置和Stake交易数额这些环节，无须使用过于复杂的操作，通常简单设置即可。

下面看看交易执行价格。

BackTrader设置买单、卖单操作时，默认会根据当天的收盘价设置相关的价格标的。当市场出现符合设置的标的价格时，系统再执行买单、卖单操作。但这个标的价格并不是固定的，而会上下浮动，具体浮动范围也可以设置。

有关的买卖操作都是系统在后台自动完成的。用户设置好交易订单，当买单价格与卖单价格相同时，就自动纳入交易队列，按订单先后
