# 1.3 TOP极宽量化工具函数库

在BackTrader软件的使用方面，大家遇到的问题主要来自安装设置方面。

TOP极宽量化团队根据国内用户的实际需求，针对BackTrader量化软件特色，专门开发了一套量化工具函数库：TopQuant。

TopQuant量化工具函数库，在功能方面做了以下扩展：

+   - 便于设置使用，量化入门用户通过使用TopQuant量化工具函数库，也能轻松使用BackTrader软件。\n- 简化代码编程，使用简短的程序代码，就可完成全部的量化流程，如数据导入、回测分析、图表生成等。\n- 集成第三方专业数据分析模块，功能更加强大。\n- 内置大量的量化策略模板，支持策略参数自动寻优。\n- 支持国内的金融交易数据，以及非股票类数据。\n- 优化股票池（stock-pools）设置，强化多数据、多周期分析。\n- 增加指数池（index-pools）数据源。

本书案例程序，配套的是简化版的TOP极宽量化工具函数库，全部经过代码测试，足够读者入门学习使用。

TOP极宽量化工具函数库，还支持PyFolio专业量化分析图表。

PyFolio模块库，包括大量的量化参数指标，如最大回报率、最大回撤、夏普指数、Alpha、Beta、SQN策略评估指数等。

PyFolio图表分析模块，一般会生成一组具有多张图表的量化分析结果。图表中经常出现SPY这个代码，这是标准普尔指数（简称为标普）的意思。

需要注意的是，zwPython 2020以前版本，集成的PyFolio模块库与BackTrader不兼容。因为PyFolio的函数接口改动很大，BackTrader无法直接调用。

TOP极宽量化团队，修改了PyFolio模块库和多个第三方关联模块库的相关底层源码，才成功解决BackTrader调用PyFolio功能的问题。
