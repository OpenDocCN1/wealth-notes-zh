# 10.3 PyFolio简介

严格来说，PyFolio专业量化图表分析与第9章所讲的回测结果分析，都属于量化回测数据的分析，之所以拆分为两个独立章节讲解，有以下两个原因：

+   - 第9章讲解的是BackTrader内置的分析模块，但PyFolio使用的是第三方独立的量化回测分析模块库。
- PyFolio本身功能复杂，内容繁多，需要独立章节进行讲解。

PyFolio模块库不仅可以分析投资策略的风险，还可以分析策略的运行性能，例如运行一个策略需要花多少时间等。

PyFolio模块库可以提供非常强大的专业量化分析功能，包含很多专业的量化分析参数，如Alpha（阿尔法）、Beta（贝塔）参数等。

使用PyFolio图表分析模块，通常会生成一组多张量化分析图表。在图表当中经常出现SPY这个代码，这是标准普尔指数（简称：标普）的意思。SPY是做外盘时经常要使用的，类似于国内做A股的上证指数、深证指数。

由PyFolio生成的量化分析图被称为tear sheet样张图，也被称为“泪滴图”，如图10-1～图10-4所示。
