# 9.7 案例：底层数据分析

BackTrader的内置指标使用比较灵活，指标类型也非常丰富。在BackTrader的回测结果中，保存了每一笔交易，每一张订单的具体信息，类似于分笔数据、底层数据。

本节案例文件名是：btr_e014anzExtb.py，介绍如何读取这些底层数据，并通过专业的分析函数对相关数据进行解读。

BackTrader底层数据分析属于扩展指标，分析一些交易数据相当于做一个交易清单。BackTrader会自动记录每一笔的交易数据、每一次买卖情况。

BackTrader软件有很多专业的统计分析函数，可以协助用户处理这些底层工作，不需要人工查看每一笔数据，大家可以在这些基础上再进行交易分析。

以下是案例程序，main主流程部分的代码：

```
print('\n#1,设置 BT 量化回测程序入口')
cerebro = bt.Cerebro()

#
print('\n#2,设置 BT 回测初始参数: 起始资金等')
dmoney0=100000.0
cerebro.broker.setcash(dmoney0)
```
