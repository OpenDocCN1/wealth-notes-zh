本节案例有两处代码需要注意：

第一，在调用plot绘图函数时，使用了numfigs图形数目，数值为5，结果图被切分为5张独立图片，而不是常见的一张图片：

```
#numfigs, 默认值为: 1
cerebro.plot(numfigs=5)
```

通常，在调用plot函数绘制曲线时，很少需要独立设置numfigs图形数目，而是使用默认数值1。

第二，设置时间周期代码：

```
#t0str,t9str='2010-01-01','2018-12-31'
#t0str,t9str='2018-10-01','2018-12-31'
t0str,t9str='',''
```

量化回测起始时间和终止时间使用的都是空字符串，表示使用全部的时间数据。

在前面章节的案例中，我们只使用3个月的日线数据，以便于查看图中的细节。本节案例介绍多图拼接模式，要求数据量大，所以使用了从2010年到2018年的日线历史数据。
