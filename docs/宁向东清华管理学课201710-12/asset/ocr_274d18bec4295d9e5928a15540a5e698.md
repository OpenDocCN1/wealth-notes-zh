# ## 1.西南航空如何实现“快速专场”

我第一次坐美国西南航空的飞机，是1996年，从芝加哥飞到圣路易斯，再飞到拉斯韦加斯，然后是返回芝加哥，一共是四个起降，竟然是同一个航班的两个航班。这不仅是让我看到了我的打听着，我4个起降一共只花了68美元的价格来实现。我坐过第一次才知道廉价航空这件事，也是第一次见识了美国西南航空。

后来，我多次乘坐过美国西南航空的航班，除了公司的便宜，还喜欢它的地点，即便飞已经可以便宜，它都会带准时地时间回来。2001年“9·11”之后，我乘巴西西南航空的机回国，在芝加哥机场，当飞机起飞的时候，我觉得当天肯定是赶不上回国的飞机了。可是，居然它就能够在一个小时的旅程里面，拉出一个多小时的，让我佩服得不得了。

你也许不知道，对于航空公司来说，准时不仅为乘客重要，对于航空公司自己也很重要，因为如果你没有说，航班到得迟了，转机的时候快就，航空公司运营成本就高。票价就可以便宜，什么都想要便宜，机票最低的成本之一，就是使用机场设施的成本。如果飞机每天大量的时间都在天上飞，那么你的航班。美国大型航空公司一架飞机每天在天上的时间，只有9个多小时，而美国西航公司只有12个小时左右。这种经营性的对比，是天壤之别。

那么，西南航空靠什么来实现快速专场呢？主要靠它独特的经营设计，比如说它的客舱配置统一，不分头等，经济舱和公务舱，而且这个座位一样。不实行“对号入座”，而是乘客先到先坐，等等。这样安排，乘客上下飞机很自然，也就节省得出来了。另外，西南航空基本不在飞机上向乘客们分食食品，现在很多航空公司发给东西，基本也属于现意思思，如三五颗花生米。这样就不会产生较多的垃圾，客舱内垃圾可以保持。而对于那些少量垃圾，公司希望乘客们在飞行的过程中，及时进行清理。

那么，空乘人员是否认真配合呢？这就取决于他们对于公司的感情。对于公司的态度。很多人一谈到公司文化，就想很固定。其实，对公司所要求的东西，是服从遵守，还是从根本上服从和遵守，就反映了企业文化。从这个企业文化背后组织，就是员工对于公司、对于老板，对于他的直接领导者，是信任，还是不敢信。

# ## 2.西南航空的“人才选拔”

西南航空让员工对公司建立信任，从企业入职时就开始开发了。我们每个人都接受面试、入职的经历，很多人参加面试的感觉，都是诚惶诚恐，心情都紧张，基本没有想法。到了一个新地方，一切都很陌生。而你去的人，都是严肃板着看着，都是考官。但是西南航空，求职者的感受是完全不同的。

每个面试者来到西南航空，都会有一名事先安排好的老兵全程陪同，那个老兵虽然和这个新人不是相识，但像跟个熟人一样给这个新人很多帮助，那种感觉就像“老回头”。老兵和你们一起看，尽量帮你们去面试房间，一边鼓励他，一边安慰你不要太紧张，一边给新人提示，帮助新人放松心态、应对紧张。每一个应聘的新人，都不会感觉到公司是一个冷酷的公司，而是充满了家庭般的温情。

我曾经有一次和西南航空的人聊天，那是一个基层管理者，他在西南的招聘是有所不同的，在公告上招聘。第一节课，公司在面试之前非常确地安排好，给候选人，而公司会安排一种面试。这种面试，西南航空是通过这种安排，教会每一个可能成为同事的人，怎样看别人，怎样看待公司的同事。

西南航空格外注意选人，适合合自己文化的人，也选择常雇着老雇员的人。所以，在面试时，常常是老员工选择新员工。每一次，航空公司的招聘，西南航空就会派出一组人员到招聘厅。招聘者会在现场将亲身办法给他选择人的标准，核心是判断这个人能不能融入西南航空的文化。

选新人时，面试是由同事来定用谁不用谁。据说选聘一个新厨师，会安排新人和35个厨师同时，这些新人是面试的时候，面试者会格外注意新人在表述中是用“我”这样的第一人称，等等细节。他们格外注意新厨师是有什么合作精神的人。因为，在西航航空里面，任何工作的状态都是可以改变的，但工作态度是无法改变的，所以，选到同的人格外重要，在不断确立了选不到正确的人情况下，西南航空建立了试用制度，在试用期结束的时候，如果有人不行就会果断放弃，我们一定要化到从内心行为，都有助于保证关系文化落到地的合适的人。

有一点特别有趣，西南航空的人不反对“开夫妻店”。这一点和我们讲办公室文化情形一样。它体现了一种很意思，像你我亲密，在西南航空有1000对夫妻同时工作，公司飞行员工，老板都夫妻公司工作，是优秀的。老的要让位给夫妻工作，也是别人因为1000多对夫妻有助于公司形成一种家人式的关系。

1990年，西航航空把它的人力资源部门改名为People Department，翻译成中文直不知道该怎么翻译，直接把“人力资源部”改译为“人员处”，人员管理“来源于human resource”，很有市场味道，而people的意思“人民”，多了点家人式的。所以，中文“以仁为怀”也体现了，准确的词，表现出这种变化，但是，从英文上，我们可以从中感受到这个文化变了市场的味道，增添了关怀家的味道。

有了这一套东西，西南航空的员工就有了对于公司文化的认同，对于公司所要求的，在工作期间，时刻地地清洁工作，保持机舱卫生。就更关系成员的工作了。更何况，说不定哪一天，董事长也会出现在你旁边，帮你一起去整理呢。

# ## 3.来自关系文化的竞争力

![](bbox=[0.08, 0.78, 0.92, 0.86])

所以，西南航空通过它的一整套做法，就把老板的个人文化一点不地转化为公司的关系文化，并让这种文化深深地植根在员工的心里，在整个组织中充满了。而西南航空比它家，是一个大家族。宾之同而亲情，有就像的感觉。然后，齐心合力创造奇迹。我曾经亲眼见证过民航在把它机种之后，去用服务员的整理服务。机场，这种机场帮助乘务员的整情，可以说这些机会，在全世界都少见。而大家服务的主要目的，就是希望飞行员尽快地，这样就可以节约成本，提高点率，在市场上形成良好的口碑，一方面降低航司成本，廉价客可以赚很多钱；另一方面呢，飞行准点，品牌好，客户多，公司要去发展呢。

可以说，西南航空从1973年租来的3架飞机起步，发展到今天这样一个规模，靠的就是来自关系文化的竞争力。而在这种关系文化下形成的竞争力，就像是我上。
