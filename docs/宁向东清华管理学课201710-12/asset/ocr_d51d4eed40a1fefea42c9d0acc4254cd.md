# 122讲：客户营销 | 从4P到4C

你好，欢迎回到《宁向东的清华管理学课》。

在数字营销出现之前，一个公司的营销策略，在落地的时候，必须得借助于一个有效的营销组合。这个营销组合应该紧扣特定的客户群，保证一个产品最大程度地满足消费者的需求。

# 1.4P模型

有效的营销组合，主要应该考虑四个因素。由于这四个因素的组合，都包含一个字母P，所以，被称为4P模型。第一个是P，就是产品（Product），企业确定了产品之后，企业需要考虑如何给这个产品定一个价格（Price）；这是第二个P。第三个，企业必须要找一个最好的通路，能够让这个产品送到客户的手里，这就是要把产品放在哪里Place；最后，为了实现你的销售业绩，企业还需要考虑使用促销的手段，这是第四个P，Promotion。就是说，4P模型是营销管理、销售管理中最经典的内容，每个企业要想做好营销，都要认真地考虑这4个P。

在中国企业营销的成功案例中，有一个案例，我是特别喜欢的，就是“怕上火，喝王老吉”的那个案子。王老吉是一个老字号，有着将近200年的历史，可以上溯到明朝的道光年间。我最早去广东，住上三五日，略有不适，广东的朋友就会劝告我，是因为什么，要么是内心太火气原团。说老实话，我来到我在广东，我有一个经验，有两样东西经常喝得没有坏处，一个是老火汤，第二就是周边的凉茶。王老吉，就是一个地方的凉茶名牌。

![](bbox=[0.1, 0.32, 0.8, 0.4])

但王老吉的发达，成为了一个全国性的饮料品牌，源于我所在加多宝的公司借道集团经营后的广告。药集团把红色包装的王老吉凉茶的经营权授权给了鸿道集团，鸿道集团原来的朋友也授权给了他们的子公司。冯楚健总想了想，一个月，想出了前面提到的那句广告语：怕上火，请喝王老吉！我们开玩笑，我觉得这句话，至少值十个亿。

![](bbox=[0.05, 0.49, 0.2, 0.54])

讲到这里，扯两句闲话。就是说知识产品，很便宜，比如，就是上面这句话，再看书，不能再好了。但是，如果事件给它定位，广告会花十亿亿就是这一句话。而且，你广告花了，广告亿就烧了，等对于知道后，很多人花10亿万不愿意进行知识产权保护，用市场方式来定价的一个例子。

回到主题。为什么我这么喜欢这句话？这个产品，要变成全国性产品，就得这样一句话。上火，是怎么回事？火，是什么？说实话，我也很难说清楚。我活了这么多年，好多事我都想明白了，但就是这个“上火”，我一直不清楚。你听，也别说我说，我偏，我要试验试试自己究竟通不通，特别是我看，想一个老外，让他讲一遍什么是“上火”，如果能把一个中国文化痕迹无知的老外讲明白了，我觉得你就是真懂什么叫“上火”了。

不过，不管你懂不懂这个火是什么，全国人民经常性地处在一种“上火”的状态，倒是不争的。所以，老冯妙笔一改，上火！天天喝水，上火！换碗粥改了一碗，上火！甚至吃了一碗火锅，也会上火！反正“上火”是无处不在，所以，到处就是王老吉的市场。很多企业把产品的问题，是最愁的事是市场细分，考虑一类客户的需求，看什么产品能够满足这一类客户的需求。但王老吉不，它是男女老少通吃，4P定位非常清晰。

那段时期，王老吉的广告铺天盖地，那是一个电视广告杀伤力最强的时代，所以，电视上经常看吃着火锅，开一罐王老吉的画面广告。这是很快活的最最直观，而渠道，餐饮大超市的解决方案，让王老吉凉茶在全国人民面前的曝光率非常高。可以说，它的铺货是能够走通的，但我们特别留意了一方，就是能看到王老吉广告的地方，身边就一定能买到罐装的王老吉凉茶，价格也跟着王老吉，所以，全国人民一旦上火，一边想着王老吉效力，公司的知名度很快迎来了大爆发。
