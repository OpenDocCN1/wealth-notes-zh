# 1.定价是个技术活

说到定价，它是一个技术活。这一点，我是在年前年的一次出国过程中才深刻感受到的。那次旅行的记忆至今令我深刻的印象。我记得是乘荷兰航空公司的飞机，那时候钱，喜欢和人交谈。飞机飞了没多久，我就和邻座交谈起了。无边界的聊天，购买到后的票位，位置相邻，但是，买票的价格相差30%。这给了我很大的震撼。

后来，我机会去航空公司服务，我才知道了民航的机票定价非常有讲究。首先，机票在定价有个叫做“收益管理系统”的计算机程序来定价，用今天时髦的话说，就是算法决定价格。不同的时间买，价格会差异非常大。

![](bbox=[0.1, 0.53, 0.9, 0.65])

当年，航空公司就是通过对不同时间点的票价管理维持着定价能力。而航空公司的收益管理系统在全世界是最高级的。所以，商航的很多利润都是靠这个方法得以实现的。未来，我会加入到越来越多的对价格，当时航空公司利用客户差异性，也会更高。以后，你买飞机旅行的时候，可以留意一下，你坐物理机位有物理舱位，舱位价格，座位，经济位，位置相邻，购买同一种物理机位的飞机不同，标准出舱位会有完全不同。有Y舱，有K舱，有A舱，有E舱，有C舱。有26个字，每一个字母都对应着一种客户的类型。

总之，定价是个技术活，你千万不要拍着脑袋。两个公司，相同的定价方法，不同的看对客人的数据一样，利润上的结果是完全不同的。这是本节课要强调的第一点，也是到前三次课程的全文总结，我想重点讲一下最近几年来越来越多的一个定价现象：免费。

# 2.为什么会有“免费”

有一本书叫《免费》，作者叫安德森，是一个媒体的主编。他写书有非常大的影响。一个叫《长尾理论》，讲的是亚马逊和模式，它后面有一本，是另一套模型提到的《创客》。还有一本，就是我们所说的《免费》。

为什么会有“免费”这件事？就是希望这个令人不“抵抗”的代码来吸引顾客，赚取更多的利润。免费是什么？以前最早，100年前，美国，就有人开始用免费送你一个剃须刀的刀架，然后不断给你送“刀”钱的例子。刀刀架是免费的。但是，你要持续使用，经常要刮头，刀架的钱和后面剃刀片所赚的我收入相比，你的手机例子不挣钱？现在还经常有人举出的手机例子是，我不是很记得，1998年的美国，移动电话根本不是免费的，但你买手机的时候，要购买该公司两年的服务。这是最早期的免费策略。

第二种免费的感觉，是以少博多。比如，免费，可以规定每天请多少客户来。是免费的。免费就是每一个客户，为了吸引更多付费的客户。我当年在大学的时候，班里的费用要大家来平摊。当时挣钱的办法，就是周末借一个食堂举办舞会。清华的政史生，比划舞会，所以，得当着的一些做法就是学生参与舞会，免费。食堂一旦聚集了女生这个基本盘，就不愁男生不来了，然后，男生就是一块钱一张票。所以，班里主要靠男生参加舞会的男生的钱。这是营销时代的免费。

安德森在《免费》一书中直接提到的“免费”，与前面的免费，都不一样。是现在，在互联网的时代，企业也不能靠免费因为无穷的需求，而满足这些需求的成本是非常有限的。所以，这一个时期的免费，英文对应的是“freemium”，这个词的英文意思就不再是“免费”，而是“免费增益”，即通过免费创造收益。

安德森说：免费的本质就是，让我们不同的平台、不同的人群之间，在我和未来的利益有商机的客户为付费用户之间进行有利于商家的转移。在上述“免费”的交易过程中，免费者似乎并没有付出什么东西，他们很实际获取了服务，他们看上去并没有损失，但实际上，免费是一种可见的，现存的，容易被以生成者消化掉的免费，可生成者的免费是为了改变消费者的消费习惯，在数字经济时代的每一个免费后面，隐藏着更大的商业利益。

# 3.“免费”的案例

![](bbox=[0.1, 0.00145, 0.9, 0.00157])

我给你讲一个免费的案例。在美国，有一家公司叫Evevoute，是2008年开始在美国国内的，中国业务应该是2012年前后得以开展的。中国业务的名字叫“云储存”，（好像云盘）。这家听所听使想的都是一个人上了存储空间，大部分创一个朋友用的存储盘上。每个人都经常更新电脑和手机，而这些设备中存储大量的数据都会产生，这些内容是非常分散的。用户一旦买断了设备，查找旧文件是非常困难，没有检索，而且还要相应的存储设备。非常方便。所以，如果在云端给某人一个空间，一个账号，这就吸引给更多人。

这家公司最早是全部免费的。2010年，它的用户突破3000万人，然后，它继续通过免费产产品继续吸引用户，同时，它开始增加付费产品，就是从免费逐渐走向付费，从Freeium向收费Premium。公司发现，如果用户向付费用户转化的时候，大约有0.5%的免费人转化成费用用户，而6个月后，转化率可以达到1%。两年左右可以达到2%。到公司就可以基本只有1%的人转化付费用户。它可以减低成本。

其实，中国的很多互联网公司，都是从免费开始的。就说我们现在使用的“得到”APP，是不是也是走的是免费的道路。在安德森的书里，这种模式被称为“免费+收费”的模式。

# 4.附笔：学会品书
