# 有效沟通的18条清单

宁向安

这个周末，我在外地出差，所以不方便录音，等回来后为你补上。

今天看的是复盘，我们能够换个形式，用沟通，来看看复盘部分能够完成得怎么样。

当然，我希望的是，我们能够结合平时的沟通，参照这18条，经常地打磨自己的沟通潜力。

+   1、不是面对面坐在那里长谈，开会才是沟通，所有涉及到与他人在进行信息交换的事情，都是沟通。沟通无处不在。

2、人和人之间的沟通潜力，是有差异的。但是，人们可以通过练习，发展出有效的沟通潜力。这些潜力既可以用来解决生活和工作中很重要的沟通问题。

3、沟通是由思想深处的动机和价值观主导的，但别人无法了解你的动机和价值观，所以，他们只能从你的行为上反推你的动机和价值观，所有沟通的偏差，都是因为沟通行为和方式的不当而引发。

4、任何沟通，都发生在特定的情境中，所以，可以事先设计。沟通是可以被控制的。有经验的人可以使沟通向对自己有利的方向发展。

5、沟通前，可以问自己四个问题：沟通对象有什么特征？沟通要达到什么目的？怎样可以最有效地接受和传递信息？最恰当的信息传递方式是什么。

6、沟通前，要明确沟通的性质：是发起一个倡议？还是争取大家理解？是在执行中向大家通报，交流，亦或是总结。

7、沟通双方的共识，会极大地影响到沟通的效果。共识越多，沟通的效果就会越好。沟通前，要判断共识，共识的情况，然后，对沟通进行设计。

8、沟通中的倾听极其重要。倾听，不仅仅是用耳朵，更要用头脑，投入身心。倾听，是一种能力，是一定非常认真地投入，才能做到的事情。

9、倾听过程中，一定要听懂对方的意思。避免一边听着别人说话，一边想着自己要表达的话。对于绝大多数人，双心思是非常很难达成的。

10、有效倾听，是一切沟通的基础。倾听的目的是及时而审视形势，判断局面，审视是控制沟通过程的重要环节。

11、不要忽视沟通中的非语言信息，比如身体语言所传递出来的信息，要综合语言信息和非语言信息来理解对方的看法。

12、要学会控制沟通的走向，要及把握沟通对象的反应，并据此来评估沟通的过程和形势，及时对沟通策略和方法。

13、沟通中，要很据自己占有信息的相对多和对对方对问题的讨论意愿，来决定谈话的数量和传递方式：是指示，告知，还是说服，或是协商，亦或是群策群议。

14、一次沟通中，可能会上四种情况都会遇到，要懂得根据进程及时切换表达方式和讲话逻辑。

15、沟通中的表达要根对手的信息情况来看，当对手有信息基础的时候，可以先讲话，再讲细节，再举证据，来先出，否则，需要先铺垫，再给结论。

16、沟通不是-锤子买卖。平时要加共识的建设，培养和包容心有助于和更多的人建立共识，做到有共识。

17、沟通是一个连续的过程。共识的形成，往往在潜移默化中形成沟通基础。很多看似无关的事情，其实都是沟通的准备。

18、在沟通中，如果结果不能达到预想结果，要当中，巧妙地结束本次沟通，并为下一次沟通留下一个比较有利的情境，要学会暂停和放弃。
