# 113讲：会议发言 | 四维讲话技术

你好，欢迎来到《宁向东的清华管理学课》。

今天我们讨论的话题是：作为一名会议的参与者，你怎样构造自己的讲话，说怎样在会上会议中传递建设性的信息，从而更好地追求自己认为有价值的目标。不过，我先强调：今天的课题其实是一个小话题，因为因为每个人都有自己的说话方式，每个会都有特定的情境，每一个讲话要解决的问题也千差万别，所以，没有普适普泛的问题。所以，这节课我不准备给讲话高手听，我希望能对那些自认为不太会在正式场合发言的人一点启示。

所以我接下来是差不多太念的听众，我直接讨论我很多善于表达的经验人士，多年来，我一直想问一个问题就是：会议发言，特别是怎样确立一个有效的会议发言模式？

今天的课，算是起点个性模板，你可以从这里出发。然后，你一定要注意观察自己的特点，然后在不断反馈，我自己学会发言、表达是大学阶段，打进了一个学生会，看他们如何运转，如何转换。我开始都是按照他们套路来组织自己的话。如果说，模的第一步先说过去经验，再不断加入自己的要求，形成自己的发言风格和讲话模型。

这节课里，我就按照自己的经验，给你准备了一个可以模仿的“假学长”，这个假学长的会议发言的模式，我称为“四维讲话技术”。

# 第一维：紧扣主题

第一维，也是最重要的一个维度，就是要通过自己的思考，切实帮助到解决问题的过程以及参会者思考思考和解问题的过程，所以，讲任何话语要围绕会议主题。不要发言最主要的，就是跑题方面。不过，主题方面只能，是最低的要求，更重要的是有建设性。

关于建设性，我做教师多年，发现学生的发言中有两种“建设性”。

（1）第一种，对于直接形成结论有建设性。

这个不太容易，因为一下子就能发现解决问题的办法，也不需要开会来讨论了，所以，要有建设性，是有助于解决就提供一个新的信息，新的思路，这也是建设性的，就是我说的第二种“建设性”。

比如，有时候我会带同学进行小组讨论的时候，我提出的那几个人，可能见不见最大，发言讨论的最热闹的，也不贡献最大的人，常常是那个在关键时刻给出一个重要结论的人。在整个讨论过程中，除了提一个想法，其它时候他没有发言，没有喋喋不休，但作为老师，知道这个人的贡献是最大。所以，我告诉大家，有时候，真正贡献的人，可能给出去一句话，比如，我们换一个角度想能不能这样？它这一句话，可能就影响了整个局面，这就是建设性的。所以，会议发言，第一要考虑建设性如何，如果没有建设性，宁可不说，或者少说。

那么，第二种建设性的能力该如何获得呢？我得到经常进行思维训练的训练思维，比如思维导图训练。思维导图，对提升思维能力一定会帮助。在我们班课程讨论区里，赵婷婷同学一直维持分享他们的学习课程和思想体会，这个非常不容易。上周，我看到有一个帖子在问：思维导图有用吗？我个人的看法是，一定会有助于提升你的逻辑思维能力。

你一会知道我很一贯的主张：想一小时学会，然后“一分钟”复制，我感到没有这个奇妙。你知道格里菲斯大学最著名的书（GRASP），中文繁体书版，著名的书《如何产生杀手级的想法》，我看这个书，就这非常有价值的书，又被书评家说，这本书叫“好读不及”。

讲到哪里，我再次分享一个工作方法。我自己常常去会参加各种讨论会，在开会之前，我一般都会认真的准备，多数情况下，我会画一个逻辑框图，或是所谓“思维导图”之类的结构图。注意，我要画这些，不是站在自己的角度上，或者站在有关领导或老板的角度上。这一点，是今天课程的要点。开会发言，及讨论时，站在自己的角度，就站在会议发言者的角度去思考，是个要点。这一点，请你无论如何要记住。

一般来说，会议发起者都是有逻辑的，但他要讨论的，一定需要他人来脑的补充，逻辑是不完整，是因为头脑参与他的不完整，可能是信息不够，也可能是因为理论不充足，不敢于定论。这些都需要我们这些外脑的地方，所以，我们在发言的时候，就不应该站在自己的角度上长谈，我们要站在他的角度去思考，去讲话，是不要把以为、哑着为主，我们所做的，就是争取帮助他而不连累的东边连贯起来，不完整的东边，让他缺的东西，我所做的不完整的东边，第二种建设性的工作。多年做下来，效果还不错，这个经验今天分享给你。

# 第二维度：前后呼应

发言讲话的第二个不可忽略的维度，就是要尽量去集体，承上启下，获得前后的呼应。我不知道你是否意识到，一个成功发言的标志性，就是由此掀起绝大多数人的注意力，你讲话一定要让会议发起人在内的所有人群兴奋起来。你能够感受到参会人的那种呼应和兴奋，感受到大家对你发言的呼应。

我自己参加各种会常发现一个最大的误区，就是一些人在参加会议之前，能认准备充分，但是开会开始之后，他们却经常在思想上游离，只管着到自己发言，于是讲话的完全没跟着他们东西来说话。这种情况是不对的，东西自备，最多是前面所说的你自己第一维度上的思考。但你在会议开始，其实你领导、会议发起者的头脑，会逐渐灌输大家的讲话在行进，所以，最高境界的发言，能够把握整个会议前后呼应，能够与会议发起者的思想达成前后呼应。

有的人发言很有价值，响影响到会议发起者的重视。你会议发起者眼神，他在什么地方开始，这些细节可以研究出来。要一直观察会议上进行，然后及时调适着自己发言的切入点和内容，以期可以最大限度地会议作出贡献。

# 第三维度：给发言加包装

发言讲话的第三个维度，就是要讲究讲话的包装，让表达更加出彩。

为什么要这样做呢？因为人的专注度是存在波动的，一般只能专注40到50分钟。这也是为什么一般学习的会话，都会安排大约50分钟左右会休息一次的原因。当然，你也不可让会议时间上太长，没有完全休息，所以，虽然看上去有休息点，但实际上人是不断在意思上开小差，大约每15分钟就形成一个小周期，这个消息对人的身体来说，一般一个人意志为转移。于是，这给表达者留下了空间。
