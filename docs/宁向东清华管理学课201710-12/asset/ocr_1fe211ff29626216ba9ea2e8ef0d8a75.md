控制员工的惰性。

+   1.  选人用人：明白事理的成年人，而不是聪明的混蛋（案例：网飞）；
2.  把决策库当成交给员工，采取倒金字塔结构（案例：HCLC）；
3.  建立与之匹配配套的企业文化（案例：HCL的创客家精神）。

# 017讲：愿望与能力｜了解他人的两条线索

从动机到愿望，从愿望到努力，再从努力到目标，这其实就是管理的逻辑。

利用“能力-愿望四象限坐标图”更好地管理。

# 018讲：双因素理论｜如何管理80后、90后

双因素理论：要想带出一个好的团队，不能仅靠保健因素，一定要依赖激励因素，使员工对工作产生正面的情感。

+   1.  给任务的时候一定要明确；
2.  善于把大目标分解成中目标和小目标；
3.  一定要给年轻人即时反馈；
4.  不要高效鼓励。

# 019讲：窄化效应｜离职率高不下的原因

“窄化效应”，就是偏好出了问题，因为它关注了某个时刻某一个点的偏好。

几乎全部的知识劳动都是情绪劳动。管理者要学会驾驭他人，必须首先要了解每个人的生理状况。

# 020讲：经验分享｜哈佛课堂三十分种

商业世界只有问题，没有理论。很多问题的答案都蕴含在经验，而不是经验论上。

问、想、仿、改、磨，是我通过经验分享来学习的五字心经。

# 021讲：格局修炼｜当骨干前来辞职

对于一个管理者来说，“格局影响观念，观念决定招法，而招法会决定结果”。

要把处理辞职，当作一次关系经营。

# 022讲：互恩合作｜离职员工的关系网

本质上，职场中人和人的关系，就是一种互恩合作的关系。作为员工，是一种交换的形式，作为辞职者，依然可以建立起另外一种交换形式。

# 023讲：公平感｜领导者的内功

我们在管理工作中，在解决薪酬安排、晋升安排中，一定要注意：你怎么做，才能为组织创造出更多公平感。

# 024讲：管理基准｜幸福感？进取心？

管理工作的目标，应该基于员工的“进取心”，而不是直接追求“幸福感”。

进取心就是一种“自我启动的工作行为”。

# 模块2：领导力

![](bbox=[0.1, 0.67, 0.9, 0.82])

# 026讲：权力基础｜有了权力不一定有领导力

权力并不等于领导力。

领导力，就是存在于领导者和被领导者之间施加影响的一种关系，领导力不是来自职位授予的权力，而是来自超越职位的影响力。

# 027讲：超越职位｜深耕领导力的途径

超越了管理者的自我定位，通过专业能力的积累和魅力的展现，走进了下属的内心，你就超越了一个简单的管理者，而成为一名卓越的领导者。

# 028讲：领导特质｜凭什么你来当“头”

领导特质中重要的十六个字：自信乐观、诚实正直、自我驱动、勇于担当。

# 029讲：领导力修炼｜演一百遍，演的就是你

领导力不是天生的，是后天造就的。

做领导，在某种意义上，就是一种表演，要精心准备，反复练习。

# 030讲：有效追随｜一个提高影响力的极简工具

领导者要超越管理者的层次，把更多的下属转化为追随者。

为你推荐管理工具：“追随着表格”。

# 031讲：硬权力领导｜当重大机遇降临时

“硬权力领导”模式，核心逻辑就是，权力几乎全部保留在领导者手里，而下属只有听命的全局。

你需要让下属觉得正在和你做了一件了不起的事情，要让他们看到胜利的成果。

# 032讲：能力型领导｜防止被推下山崖

采用“能力型领导”模式，要注意及时放权，不要被下属拖垮。

人的精力是有限的，分配精力其实是要考虑回报率，只有把精力配置到回报率比较高的事情上，人的生命才过得比较划算。

# 033讲：情感型领导｜选秀还是选贤

“情感型领导”模式的核心特征就是用人，用自己是懂得别人，它往往是特定时期里巩固自己领导地位的一条策略。

成功的领导者会一直保持下属“忠心”的水平，让“忠”的水平在悄悄提高。

用“四象限坐标图”管理下属的“忠心”与“能力”。

# 034讲：团队型领导｜从阿里的老师傅

“团队型领导”模式，是指组织成员通力合作，共同实现组织目标。它把权力为一个人或极少数人配置到多数人手上，其次，它也是把权力从管理者手中配置到工作者手中。

# 035讲：战略型领导｜致敬早年的乔布斯

“战略型领导”能力，就是由公司设定愿景，利用他的直觉为公司找到发展方向，恰恰把握机会，为组织赢得竞争能力。

“战略型领导”要能够引领第一流的人投入到工之中，为此要建构一个愿景，让他们知道他们正在做改变历史的事情。

# 036讲：权变理论｜学做领导的极简指南

不存在唯一最优的领导模式，“权变领导”，就是要分析行为，追随者特征和环境情态，寻找找到一个平衡点，以达到有效影响他人、完成组织任务的目的。简单来说就是懂得因时因地制宜、有所区别地解决问题。

用“四象限坐标图”找到你的领导风格。
