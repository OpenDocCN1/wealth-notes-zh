# 093讲：资源聚合中挖人都不用搬家

你好，欢迎来到《宁向云的商业管理管理学课》。

今天我们讨论的核心内容是组织的跨国城市发展，跨地域地发展，它的好处就是能不断地获取给组织中最重要的也就是最重要的资源，以及这些资源背后所形成的能力。现在在一个地方发展的资源总是有限的，包括美国之类的发展发达国家，这个世界上没有一个地方，拥有着所有一流的东西。所以，要想不停地拥有一流的东西，得到最好的东西，就必须要持续走出去，找到最好的资源，就在它旁边，积累丰富。只有这样，才能不断借力，把事业推向高点。

# 1.把公司开到一流企业身边去

跨地域发展的最极致情形，就是跨国发展。去年，我有一位很有见识的朋友聊天，谈了一些我的发展，谈到了投资布局。他的一番话，我觉得说得特别到位，今天分享给大家：你说，你要去大学，在国情清就要在哈佛隔壁；在中国，你就要在清华大学北大隔壁；要横跨中国，那就要在德国，在西门子，在博世公司的旁边学精密；要横跨金融，你就可以必须要去华尔街；要横跨信息、搞人工智能，你就必须要去硅谷；要跨AI、BM旁就一旁，你每天都来它办公，感受你的氛围就一定不一样。你每天去它公司里面来来往往的那些人不一样，你就能够知道什么是世界一流。

这一段非常有世界眼光的话，他还说了一段不外传特别有意思的话。说，在他的身边呆上一段时间，不用干，光看看，那人与环境的提升就完全可以不一样。但你在国内天天看什么动态或者之类东西，那，那不知道能看多少。有效多少手段，说有一天看谁看出门庭，想动脑了，遇到对方公司找您出谋划策，你们就知道了。

我后来仔细一想，还真是这么回事。我们很多企业，老板都是全世界踩点式不断地踏，但总想却不去自己起来的那一遍身上，全是缺少国际视野。要有一把手，把人弄过来，看看中国的人还是回家老婆孩子，要不然主要出国工作。为了能够设董事会，公司往往去交天价税。我这朋友说，其实买没有必要的。走出去，把分公司开在一流公司家的门口。我们想办法竞争，就是给钱多，给平台大，你要不要加盟。如果想，根本不用跑，也不用考虑商量，明天上班直接到马路对面来就行。

你别和我说，这事不好办。这事咱们在国内干了多少年，都熟练得很。九几年后，我去了一个省会城市，那家著名的企业，同一行业，号称同城兄弟。其中有一家国外的人力资源部，居然办公兼搬到另一家公司的门口，工作的同事是人家上下班时间，人家得干一下下班，这边人力就说先去帮助人家降低起来。当然，这事就让不太多人听，但效果也很实惠。摆办公的那个企业后来也是把人家的墙挖穿了，把人搞得连连败退。当然，我们不再的商业模式明摆着比较，做不来不可能那样干下了，但引进资源放大自己，在市场经济中习惯的，合理手段而已。

好，回到我们的主题。一个企业在发展的过程中，一定要知道自己在每一步发展过程中，资源是哪里最急需的，是必须获得什么，然后，要想最尽办法以最有效的方式获得这些资源，不要老想着有优势回头自恋资源，要学会去资源整合具有优势的地方，去建立自己的分支机构。

我们后面会有一块讲公司的战略，就是解决这个问题。公司的发育和一个人的成长，道理都是一样的，一定要清晰地目标，再有练动的技术、战术，能决断地断，只要利用了资源也就能果断地可以事先判断了，工作了，就可以提前地行动，进行布局。

# 2.建立相应的组织架构

那么，布局之后接着该建立怎样的组织来实施协同呢？这其中最核心的，就是要先明确两件事：

+   1. 一个组织进行跨区或得到资源的范围，通过什么方式，什么节奏去得到，更有利于组织整体的吸收和利用；
2. 总部和区域各自之间该有什么权力，怎样设定组织和它们之间的关系，能够最大程度地实现上述目标。

这两件事情明确了，组织架构就容易搭建。制度规范也容易建立起来。

一般来说，最“自主”的特权，特别强调不同区域或公司的“自主性”，建立相对独立自治的事业部组织。为什么呢？因为每个区域的情况不一样，每个区域都总部那的东东西不一样，甚至有一点也是需要的，就是每个区域都相对独立，整体带来的风险是相对有限的。

我给他举个例子。有学者研究过韩国汽车行业去海内扩张的历史，他发现现代汽车最初到海外扩张，或者是建钢厂，都不是针对有技术、有能力的公司，而是开始加拿大、之后是英国，然后是全球。第二名大宇公司，它向海外走，则主要靠大客户，追求市场。这些学者后来也论文写到，为什么会有这些区别呢。他们认为，是因为现代汽车公司在韩国市场占已经有了名分，他们已经在其他地方用了规模经济的种种优势，所以，他们到海外投资，更多地是为了获得技术，特别是结合生产汽车公司的核心技术。这也就是为什么现代汽车公司在海外收购的企业，格外注重它们有独特的技术，要有专利，要有一流的研究机构，和大字特别在意客户，在意向销量。

由于目标不一样，现代和大字扩张到海外之后，给予各个子公司的权力不一样，对外事子公司的管理方式和幅度也不一样。但是，如果现代汽车在代现代在几十年间，你会发现在随着目标的一个小变，它后来逐渐成为了一个全球化的研究机构。它后来逐渐成为了一个全球化的研究机构，它来讲题了。你不用说了。总之，一句话，资源并不都放在自己门口，打开它，学会用更多的外部资源，而利用外部资源的关键，组织形式的设计。是一个要深思的因因素。组织的设计和管理，核心是要能够有利于资源的获得和整合。

# 3.核心是视野

我今天讲的这个内容，是离你很远。坦率地说，一点都不远，我相信，我们俩在建造这个视野，我们很多人，一辈子能够走多远，不是因为能力大小不同，而是因为有高人指点，加上自己所处的地点比较局限，视野看不了多远。我遇到这些人，曾经帮助项目的，但未来一下子都走开，没有去实现自己的远大抱负。就是因多年困于一地，见识难与时代俱进。

我记得，自己在上个世纪90年代初开始教的时候，谈到全球化，谈到塑造国际企业，觉得很难离自己很远。后来，十几年前，国家“十一五”规划的时候，我承担了一个前期研究，正是讨论中国企业“走出去”战略，当时我就说，我还是不主张“十一五”期间要谨慎，甚至在“十二五”期间都不应该太太激进。但是，我说的意思是，中国的发展太快，今天，我们沿边最好的企业已经初步逐渐成为有国际影响力大的企业，包括不少企业，长寿超巨人。很多事情都是始料未及的。

就从我担任独立董事的公司潍柴动力来说，1979年刚建立刚上市的时候，业务还不到50亿元，建立质量意识的那阶段，还仅仅2000年的时候，已经向德国收购了两家国际级的企业林德液压和凯傲，这些都是世界级顶尖企业。公司还收购意大利的法拉奥公司，这家公司是做拉轨的，然后也是几家公司，一个是做做水上的。潍柴收购拉弗摩诺的初衷，就是希望两个发动机技术的相关技术，然后中国制造的这个技术机会上，而潍柴管理方式的话，就是差别式的管理的部部功能和充电，公司在美国收购了企业，在美国建立了分公司，只有短短20年的时间，潍柴就可以从一个地方破产的国有企业，发展成个有上亿利市的世界企业。
