# 1. 资源与能力

我经常开玩笑说，从外向内看，比的是谁经常吃亏。中国有句话叫“识时务者为俊杰”。而从内向外看，比的是谁更“自强不息”。中国还有句话，叫做“天教自有用”，“我材”，那么什么是今天重点要介绍的知识点，有两个：一个叫“资源”，一个叫“能力”。

资源和能力，是思考战略问题的两个非常重要的管理概念。这两个概念无论是分析企业的发展战略，还是研究个人的自我实现，都非常有用。所以，我建议你一定要对这两个概念有深刻的理解。

先说什么叫资源。资源，一般指的就是我们手中现成的各种有形资产和无形资产。有形资产包括实物资产，如厂房、设备，包括人力资本；资源也包括各种无形资产，比如技术专利、管理经验、品牌信誉等。

为了更好地说明这个概念，我举个例子。有一个运动员，我很敬佩，她的名字叫做邓亚萍。因为作为中国乒乓球队的创始人时代，她一出场外，站在那儿，我们就看到了她的资源。她的头脑，反应特别快；她的四股肌，调节特别特别好；她神经紧张，表现为动力性特别好；她的意志品质，关键时刻总是能够咬得住。这些，就是资源，都是我们看得见的。

但是，你知道吗，邓亚萍的国家队之路，是不顺利的。因为，我们后来看到的邓亚萍，她的表现都是经过国家队长时间训练之前，逐渐打磨出来的，而她进入国家队之前，同样的资源在那是里，成续还不错，但没人能够看出她的资源有什么特别之处。除了张曼琳发现，没人能够看出这个胖胖的小个子女生身上，资源里蕴含着多么了不起的能力。

邓亚萍是明星出身，很小就开始学乒乓球。这是从她跟随父亲学习打乒乓球。入队时就随父亲学习打球。但是，她的省少一查身的问题，虽然号称长得河南身高最矮的冠军，但被队拒绝，因为她太矮了。后来，在1988年，她15岁获得全国冠军，但那时国家队的表现，还是为她太矮了。这时，她16岁正好像看不够她好的时候，张曼琳教练为排找她，把她招进了国家队。

张曼琳看入眼后的地方，就是她的“资源”背后的，所蕴含的“能力”。他认为，邓亚萍这个“资源”背后，最重要的能力都蕴含在这个身高的“矮”上面。这个说法听起来像个玩笑话。对于邓亚萍来说，她看台，而在她的眼里，所有的球都是高球。以合乎出台的能力，她都看得见，都打得到。而且打得好。她不象别的运动员那样，同样的球一定得要站过去，再行攻击。很多人认为不能打好的球，邓亚萍都会认为是立刻可以发起攻击的球。所以，她的胜率就高。

张曼琳把邓亚萍招进国家队，他不是看邓亚萍表面身体条件，而是看到了她身体条件背后的运动能力和潜力。单靠那种标准，邓亚萍可能确实不符合国家队选手的条件。而且，像她那样身体条件的人，应该也不少。但是，在张曼琳综合条件下的能力，也就是邓亚萍这个身高之后一路锻炼出来的能力，以及潜力，她就是不可多得的人才和决赛。在张曼琳的教育下，邓亚萍很快开创新了一个时代：奥运会获得过4枚金牌，世界锦标赛获得过9枚金牌，成为乒乓球历史上最优秀的运动员之一。
