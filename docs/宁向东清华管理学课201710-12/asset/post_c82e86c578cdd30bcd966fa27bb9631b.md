
# 110讲: 强硬策略|谈判斗狠的十招

![](img/3148dc16965f9a57e897fce984cfd348_73_0.png)

你好，欢迎回到《宁向东的清华管理学课》。

在日常的谈判中，我们经常会遇到的一个问题，就是要不要强硬。比如，在讨价还价的时候，坚持一个价格，绝不让步，或者是持续自己的看法和原则，绝不妥协，甚至，为了不谈判破裂，这样做的结果会多不好。下节课讲这讲的内容。下节课的内容，就是要告诉你，当你作出了“强硬策略”的选择之后，你该按照怎样的原则来行事。今天，我们就分享这一方面的内容。

![](img/3148dc16965f9a57e897fce984cfd348_73_1.png)

## 1.比你更狠

在《特蕾西是谈判者》中，罗斯提到了在谈判的时候如何用强，他总结了强硬策略的十个细节。下面，我们就来看看本书提到的细节。给你一条一条知道。今天的课程有点像演讲，请你放下思想准备，不过今天的课会之后，起码在未来3年时间，你的机会会瞬间变得更多。

按照罗斯所言，特蕾西说强硬策略的第一步，就是要做到“比你更狠”。罗丝说，如果你与邻舍比你更狠，你就会赢得更多的利益。这一点在谈判中非常重要。

## 2.少说话

不过，罗斯也说，在确定强硬策略之前，一定要反复确认，看看自己是不是值得，如果要强硬的，要有本意确认强硬策略。而一旦确定了强硬策略，就要有背水一战的决心，一开始就定，保持到底。所以，第二招就是随着一开始而得到的，就是一旦选择了强硬策略，就不要再多说话了。

我可以给你们一个亲身经历的案例。那几年，我的一个好友，他刚毕业，刚在某个小区，在看房的过程中，我发现他非常喜欢那套房子，但他想跟开发商谈价，谈价的话，就要让一步，但朋友不要了，他直接砍到，最后什么也不要。

毕业了，朋友说了几句赞性的玩笑之外，介绍业主和我认识。之后没有做任何尝试，直接提出降价50万。业主说，如果业主同意，买价可以上150万，签字，到手。所以，他不需要贷款，是全款买，所以，他可以选择快速让业主拿到房款，而交易的条件很好。但看到业主有点犹豫，事先告诉，对业主：不好意思，我还有事要赶，走之。那时候房子卖价一波新潮即将启动的前夕，小区里有十几套房主正在说，所以，这给了业主一定的压力。

我想，即使交易有竞争，但朋友的还价也是未必太低了。1300万的房子砍到50万，按照这个小区房价的升值路数，还价点也是小区。在旁边的酒店大堂坐定，我就问朋友，他真的想买这房子吗？朋友笑着回答说，对。是的。我想为他和我的朋友。他环境对我说，看到他为我留下了业主的号码，从网上的看上面，我知道了业主的名字。我想，我怕他知道了。

都不能让，这是坚持强硬策略成功的关键。在这个案例中，我的朋友已经展示得淋漓尽致了。

罗斯还提到另外的两招，分别是“尽可能地扩大自己的谈判空间”，以及“用变更来获取更多信息”，限于篇幅，我今天就不细讲了。

## 谈判者的素质：

最后，我想讲一点谈判者的素质。坦率地讲，像我这种性格的人，最不能胜任的工作，就是谈判。道理我都懂，但缺少那个耐心和软磨硬泡的能力。我曾经旁观过一个恨不得想打人的谈判，那是很早的事情，给我留下了极深刻的印象。谈判的标的是几万块钱，但买方恨不得一块钱、一块钱地往下压价，而卖方则是五毛钱、五毛钱地往回谈。价格刚刚谈好，这边又问：有没有可能把服务时间从原来的半年扩展到一年啊？有没有可能把付款期限拉长一点啊？

那一次的经历，让我理解了谈判是什么。多数的谈判就像是打乒乓球时的推挡，一方把球推过去，另外一方再把球挡回来，不许扣杀，就这样推来挡去。商业上如此，职场上与人打交道，其实也是如此。所以，多年来我一直秉持如下观念：进行谈判这一类的工作，绝不能着急，绝不能图省事，绝不能讲实话，绝不能把交易条件一步讲到位。很多时候，你很真诚地开了一个不能再实在的价格了，可对手还是会找你讲价。也许这就是人性中，我们不喜欢的那一部分。

# 本周内容复盘 | 谈判清单

又到了每两周做下周有关谈判的内容进行复盘。

在复盘之前，我先说一件既有重点重要，也不是太重要的事。为什么要说这件事？因为最近一直有同学给我留言，鼓励我不要气馁，我都在下面写下数字，我我们的专栏阅读量真不高，还有我在清华教授过的几位学生，还有几位同学还发我私信鼓励我，安慰我。

我和你讲，能给老师发私信鼓励老师，这是需要勇气的。我衷心地感谢同学们，但是，虽然我为此非常骄傲，我还是建议你，后在职场上做这种事情要慎之又慎。有时候，你真心为了领导好，但一旦把话说出来，领导心里某种意上将你视为什么都刚强住你的事上面了。所以，这是一种有刀有剑，是帮衬，你一定要把握好；但如果你的领导不可能会把你的心，如果他是，如果你不能碰上水上治我的一代领导文人化，你就有可能“好心不得好报”。

今天，我们可以告诉大家，请大家放心下来。我们专门的打开率一直不错。具体数字我就不说了，反正相当不错。大部分所看到我的数字，只是打开数字做简单阅读，文章阅读的字数字。不怎看文稿的人，后者是一个大头。如果我们两种人都在一块，数字更是准不错的。这一点，向大家报告，也是请大家放心。其实，我开始看到这个数字也有点不安，因为最近有谈设计上的原因，领导“得于”，要求这么一个指标去决定，免得像新用户，其实，我觉得无所谓。因为我自己，判断力和主见，是决定一个人能否成功的关键。

下面，我们复盘两周的内容，也是我总结的“谈判十原则”：

- 1. 谈成败的前提，是要关注对方的需求，对方方案，这是所有的谈判最能决定的，在这个谈判过程中，最主要的就是你自己，最要的就是人，所以，要尽力一切，去发掘、分析、判断对方的核心诉求和延展要求，然后，推断出对方需求的交易范围。
- 2. 谈判，是努力创造信息的不对称，在知道对手的信息越多的前提下，尽量不让自己对了解到更多的真实信息，要要学会对对手，有选择性地披露。
- 3. 要有底线思维来设计交易结构。要审时度势，不断地判断用自己的什么东西去换对方交换，才能满足对方的核心诉求，以及延展需求。同时，这个交换也可以满足自己的核心需求。
- 4. 要有一个变通的观念，谈判对象从来都是一个组合，而并不一个简单不变的单一选项，我们在谈判中，容易发现自己的想象力，创造性地指出交易方案。
- 5. 要明确谈判在多大程度上靠力量，多大程度上靠智慧，这是情境。面对人际矛盾和利益冲突，解决问题的，这种方式完全不一样，不能盲目用组。讲道理，是弱转谈判，要思考对方的要求，要让对方能够感受到你希望他们感受的事情，触动对方的心理支点。
- 6. 要善于在谈判中找到一个切入点和支点。切入点，最能打动对手，让他坐上谈判的东西；支点是指该自己诉求的或求成，让自己稳坐在谈判桌上的东西。切入点不能引导，没有支点不稳的谈判，缺乏可能的力量，无法持久。
- 7. 谈判一定要遵循先顺序渐进的逻辑，逐步深入。谈判的目的，当然是为了追求最后的最大收益。但一时没有达到预期目标，也并不能全盘计划有效。要全面在于过程的及时调控应对策略，更要仔细地已经及后续目标，寻求对双方有利的目标和方案，或者为了后面可能的谈判，留下伏笔和机会。
- 8. 要发现和利用人性的优点，正面的，或者负的，既能是甜头，激励对方，让对方愿意应对与交易效用，有获得感。同时，也能够在对手，并使用欺骗和威慑等负方法，力劝导反对目标。平时就留意积累一些使用的手段和平台。
- 9. 谈判很容易陷入僵局。有些僵局是很好打破的，但另外一些僵局，可以是打破的。所以，要留出足够的空间，要预作设想，安排好打破僵局的途径。
- 10. 谈判的韧性，要耐得住性子，就是“心理战”。不能急躁，不能冒进，不能一步到位，很多时候要学会“磨”和“拖”，要张弛有度，紧一下，松一下，有时动，不动也软磨硬泡，下一次谈判，在有限的空间，不同的点位中，就意味机会一次的谈判，不到进情时，就可以利用你的优势。

所以，在谈判局面的时候，要能够想到改变情境。

最后，提一条课上没讲的内容，仅供参考。君子爱财，取之有道。谈判要求较多的收益，只是人的天性，但某笔时候，其他也是人性的底线。谈判的对象比你更多需要的是金钱，你做的必要会杀死你的事，能不多最好可以。市侩是冷酷的，但人性是有温度的。举个例子，在机场的用100元一斤的水果，我觉得多余来杀价格；但是，对于边远老实多交的摊块摊农，只要是不要过分讨价还，多交一块，一块钱，好像不用过斤斤计较。

# 111讲：会议设计 | 有些会议，注定失败

你好，欢迎来到《宁向东的清华管理学课》。

这一周，我们讨论一个非常重要的内容：开会。如果你是一个职场人士，这一周你一定要会参加一些会议，可以用我给你的观念的角度去看你即将参加的那些会议。

从今天起，我会用很大的精力，让你将会议设计一些会议，让这些会议更加有效率；你也会参加一些会议，冷眼旁观，看到那些低效率会议的弊病，然后你也有机会一天去开，去参加一个会议。如果能像先生讲，浪费他的时间是浪费财富的人，你错过了开会技巧，就会在别人的话，送生命。

本周五，我们要讲五个话题：今天，我们讲会议效率的第一步，是有效地设计会议；明天，我们讨论如何有效地组织会议；周二，我们讨论如何在会议上发言；周四，讨论如何用互联网等手段提高会议效率，它的利和弊；周五，我们会讨论会议与工作关系问题。

## 1. 3步设计你的会议

今天，我们先讲会议的设计问题。如何有效地设计一个会议，我简单给你一个套路，分为三步。

第一步，明确地界定会议的目标。比如，你需要有一个决策会议，还是想要一个行动计划，或者仅仅是为了更深入地引发讨论。不同目的的会议，设计上是不同的。

第二步，就是你想要搞清楚，需要通过怎样的讨论过程，才能够达到预想的结果。

第三步，就是你考虑清楚哪些人来参加这个会议，才可能满足这个会议过程的需要，并且能够达成预想的结果。

这三步就是“目标-过程-人员”模型。希望有明确的，我在下面，还提供了一个安排会议的表格，是我自己总结提的一个工具，希望帮你对安排会议有帮助。

| 维度 | 类型/角色 |
| :--- | :--- |
| 会议问题 | 明确的问题 / 模糊的问题 / 不明确的问题 |
| 会议形式 | 会议 / 研讨会 / 谈话会 |
| 人员 | 需要决策的人 / 需要信息的人 / 需要提供建议的人 |

## 2. 注定失败的会议

下面，我们通过一个案例来分析如何改善会议效率。

我曾经在一家企业做过调研，就是看他们在企业内部开会，会是如何开成的。我发现，这家企业的会议主要定在三天时间，绝大多都时间都在会议上，有一位竟然有超过20个小时的时间在开各种各样的会。这说说明，一方面对时间管理得很不健康，另一方面，由于这些会议缺少设计和准备，效率极低，既浪费了很多参与者的时间，也没达到会议预期的目的。

有一个会议是这样的，会议召开时间预约是在下午三点到五点。

那个会，一共有四个议程，按照道理，应该是每个小时讨论一个议程，这样才可能在指定的时间内完成所有的议案讨论。第三个议程属于决策型，没有太多的利益冲突，也没有太多的讨论，无论大原则，还是小的细节，会议公司都已经表态，所以，大家也没有对公司说。

但最后的第二个议程提前很快也出现了问题。由于参会的人中间，有两位参会者在这件事上存有异议利益冲突，其中的一位发言开始提出反对，并讲了一些具体细节。这时，有一位参会者提出来看，我看他样子应该是去洗手，去了一个一会儿，可这个回去，我主持人说，等等某人回来，再听听他的想法，于是，大家就开始等。有人会非常希望他快点回来。隔了一会儿，去洗手间的人回来了，并开始了他最擅长的批评，一边说着，一边翻坐在他旁边的会议记录，应该是属于下级部门的，对批评者进行说明，于是，批评人很快花了个多小时，而且没有任何结论。

这时，老大果断地叫停此项讨论，然后，开始了第三项议程。第三项议程讨论结束后，很快就已经过过五点，老大说，我们就休息一下，接着过第五、六项议程。可是，这个时间，已经接近成说，必须要先去一下事了，有一个客户要接待，但是，而事实上，最后一项议程才是最重要的。

当天的会议结束，已经过了六点。也许大家已经习惯了这种形式，每个人的表情都很平静，但是，可以肯定地是没有人都会满足，至少对第四项议程的最大利益相关的。我知道这件事解决有很多问题没有在这次会议上得到解决，因为老大最后还是下一句话，我们再找时间专门议一议。

## 3. 效率低下的原因

那么，为什么这个会开成了这样呢？我觉得，最直接的原因就是这个事情并不简单要开会。但也不是按照需要来安排开会，而是按照人来安排会议，把不相关的议题都堆在一起，把不同的人都弄到一个会议室，他们就以为这是开会。但这样的开会，至少是低效率的会议。

首先，会议的主题差异非常大，而且，四个议题的目的，几乎涉及了完全不同的会议类型，有的呢，主要程序性讨论问题，有的则是要需要深入的讨论。而且，议题所要涉及的人范围也完全不一样，但想要安排在一间会议室，于是，无论是什么议题，总会将近一半的参与人没有相关，要么没有参与的状态。但他们没有议题，也完全不参与。其实，他们完全可以不用参加这个会议。或者到了讨论公司完全没有关系的议程时，再让他们参与讨论。

其次，会议中要讨论的内容，有些议题实际上相关人领导，他们事前都没有发任何相关材料给有关领导，并且没有得到相关的反馈，甚至他们没有任何领导前的沟通。也有办法，领导不愿意，前面的沟通，工作也不做好，张大脸就开会，所以，会议讨论这些问题，就是一个通病。

事后，一个基层负责人和我讲，这种情况，他们公司经常要经过三次会议，才可能进入正常程序。第一次会议，就是像刚才所说的那样，一次碰头。主要说清楚了有这么一个重要的事情。第二次会议，搞一个专题讨论会，进行工作分解和利益，第三次会议，大会基本上，然后下面的人才开始做细节工作。一个都熟，没有人说，没有人太认真，但人人都可以胡说上那么一番。

开成会这样，是不是偶然现象呢？真不是，很多企业都会这样。

## 4. 三星的“开会法则”

几年前，我在清华上课时，讲到韩国三星公司，他们都“开会法则”，由于三星非常注重公司，都是靠PPT，而我使用几张PPT，一般也不会去给学们的PPT，他们就会拿出来。让我感到震惊的一个时候，就是在三星到开讲话要的时候，偶然听到了一次三星的开会法则。当时，我就会讲说，那天又碰巧听了大韩去三星，我就顺便给PPT给大家播放，真的，没到在那，座管理者们，很多企业的高层经理，居然都很有兴趣。

那么，三星的经验到底有什么呢？就是八条，我就在这里讲一讲。
