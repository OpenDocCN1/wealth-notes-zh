# 周末复盘|关于成本的6大知识

![](bbox=[0.05, 0.05, 0.15, 0.08])

本周五，我们主要讨论成本。关于这一周的内容，我建议大家记住6大知识点。

第一，成本分为两种：概念的成本，和过手的“成本核算”。前者就是经济学成本，后者就是会计成本。我们在讲管理学的时候，大多数成功的观念是会计成本。你是一种境界或者是一种状态，去考虑问题，那是一种境界。但很多人达不到，很正常。

经济学成本的核心观念，叫“机会成本”。经济学学来的核心观念，是“资源配置”。由于所有的资源都是不够的，所以，必须要考虑资源每次都被用在能发挥最大用途的地方。由于资源用到一个用途上，就意味着放弃了其它用途，所以，在经济学里面就有了“机会成本”：不过，你要理解，机会成本低不好算。不是一般地不好算，是相当不好算。计算机会成本，是高级财务会计领域内的重要观点。所以，对于多数经济学成本不仅是概念难，价值。

第二，上个世纪80年代，会计学家用经济学的观念，提出了一个概念——“经济增加值”，就是EVA的概念。有了EVA的概念，就可以来判断公司是不是有股东创造价值。在证券市场上，讲什么“价值投资”、讲什么“股东价值”，都是从“经济增加值”中引申出来的概念。

第三条，成本是有结构问题的。你要记住的最基本的成本结构，是固定成本与变动成本的比例关系。在固定成本不能改变的时候，比什么企业自己算不来的，你需要学会多从变动成本的多少来衡量问题。这就是我在直播的时候说，为什么亏损的企业，还可以亏损。因为在产能允许的范围内，只要收益大于变动成本，就意味者收回了全部变动成本，还可以收回一部分固定成本。

第四条，就是要记住直接成本和间接成本。在成本之中，有些部分是可以直接追溯到龙去秋空的，花了多少钱来做，用了多少人天，一二三，这，这部分就叫“直接成本”。还有一部分费用与成本，无法直接追溯到产品费用，比如，企业生产过程中的水电费、设备的维修费、还有折旧、管理费用、服务费用等等，都没有办法直接找到产品，找到客户，都被归到“直接费用”中去，来用于生产，这些费用就叫做“间接费用”。

间接费用的分摊，是个大学问。你一要搞懂本周讲的“作业成本法”。

第五条，作业成本法，就是确定的规则去算账，进行成本追溯和来用的成本分摊。要考虑使用了什么资源，这些资源都有多少成本，这些资源又进入到什么经营活动中，每一个经营活动为了达到什么目的，这个活动中有多少成本，多少真实的成本。做到准确核算，既没有隐藏的成本，也没有隐藏利润，这就是作业成本法要达到的目的。

从作业的角度来核算成本，除了计算出真实的成本之外，还可以进行“作业成本”，过程。我们完全可以针对所有的作业作评估，通过思考成本多不多，合不合理，来进一步思考企业的管理问题和流程效率问题。

第六条，算清了产品的成本之后，我们再至少从计算的角度对客户进行了分类。我们会知道，我们服务每一个客户，究竟花成本了多少。这时候，我们起码可以把成本分为三类，来预测对待客户可以差异化服务了。这个时候的差异化服务，不是凭感受到的，而是准确的，有统计依据的，是朝有利利润最大化的目标。

这一周有一个随着销售增加，累计利润不升反降的U型曲线。这个曲线告诉我们，很多少时候赚的不是钱，盈利利而会更多。

总之，在这一模块的第一周，我们讲了如何理解客户；第二周，我们讲了要给客户提供他们所需要的产品的时候，第三条要掌握产品服务的成本，要掌握成本。下一周，我们讲如何针对不同客户的需求进行识别，这是四周的课，围绕一个共同的问题，就是人人皆知，商业秘宻：利润等于收入减去成本。
