# 1.核心能力

核心能力这个概念，在80年代开始流行。为什么流行呢？就是因为在80年代管理学界开始注意到，很多大公司当时还活得好好的，说不行，就不行了。那么，为什么一些企业一下子就垮掉呢？大家开始从竞争力方面找原因。最后，大家有了共识：就是大公司最拥有强大的资源背后，能力在退化，尤其是核心能力在退化。

1994年，有两位具有哈佛背景的学者提出了一个更细概念的核心概念来描述核心能力的重要性。这个概念叫做竞争力。这两位学者认为，核心竞争力是超越产品和市场的一种综合能力，当一个企业可以用它的核心优势去开发、协同的技术、知识及各种资源时，这个企业就能够产生出核心产品，这些产品就可以撑起一块业务。

# 2.案例：富士的转型

我给你举一个例子，这个例子于你了解，同样行业的另一家企业富士却活下来了，而且到现在为止还过得相当不错。富士为什么能够活下来呢？很重要的一个原因，就是——它一直紧盯自己的核心能力，并且围绕着核心能力做转型。

富士是柯达材料中的起之秀。虽然很多人都知道柯达和富士的较量，但如果我们了解内情，你会发现，富士与柯达相比，根本就不是一个量级的。富士是个后弟弟，就是一个小兄弟。可因为它是小兄弟，规模没有那么大，历史没有那么大那么厚，所以，它没有积淀下那么多陈旧观念，也容易看清自己的核心能力到底在哪里。

柯达是胶片领域中的老大，而且大得还不是一点半点。当柯达准备做数码技术洗牌的时候，它觉得进去大富都是柯达的胶片来照相，本来也应当用柯达的产品来记录影像，大家1000多年使用柯达了，凭什么今后就不用柯达了？在柯达看来，照相这个事就应该是柯达的事情，自己要做的，只不过是能把感光材料换成记忆卡，把相机换成摄像机了。

而富士却不这样看。也许它是一个追赶者，它一直需要知道自己的本色是什么，所以，当数码技术是大牛，它就该是什么。它很快就开始不把自己当成一家影像公司了。它知道自己核心能力是在光化学领域，所以，富士就决心想办法先让自己的光化学技术在新市场里找到出路。

富士的社长，就是公司的总经理，名字叫古森重隆。他对形势的判然清晰，这一点很令人服气的。他说：富士的核心能力就是对光化学技术进行应用的能力。所以，富士就不需要找子影像领域这么一个新资源，只要坚守在光化学领域，能够把技术知识与人才重新整合，找到新的业务领域，找到新的客户、新的市场，一切就OK。

富士的第一步，就是组建了一个超过1000人的研究所。在这个研究所里，聚集起大量来自医学、光学、化学等专业领域的研究者，都是些技术大牛。他们每天想的都是把这些专门、技术工具在哪些新市场中使用。他们的讨论完全没有边界，根本不受既有业务的限制，完全是天马行空。

比如，其他人每天还是在那里讨论胶片，但他们讨论的中心已经不再是照相相关的胶片，而是能够用在医疗行业电磁波辐射的透明片，或者说是可以在X光下使用的胶片。所以，这个研究所的工作完全打破了过去的传统“专业”概念，他们努力把所有分散的专业技术联系起来，使得原来不管考虑过的商业领域进入了公司转型选择的视野。

比如说，胶片必须要防止老化，所以，富士有很多限制自制品、防老化的技术，研究人员提出这些技术专利可以运用到制药领域。再比如，感光材料的质地与纳米技术的关系，当富士的涂胶技术与纳米技术的结合，所以，有人提出过富士的一些技术可以用到医疗与分析医疗器械领域。这个例子都可能是天做的了。富士通过收购控制了一批老命的医药公司、化妆品公司，最后把这些看重的领域都占住了。你如果看一下最近几年富士的财务报告，这些业务都是富士挣了大钱。

总之，根据研究所的建议，富士的管理层后来果断地把光研做成了“光学”和“精细化学”领域，然后，让这两个领域的人才充分发挥创造性。比如，富士后来和施乐合作，用日本市场交换美国技术。我们在用市场、也是小场卖给施乐也减了多年的使用市场技术，但减了这么多来，市场没了，技术好像也没有施展。这一点，我们很善于学习富士与施乐的合作经验。富士“市场统换技术”的策略成功前在使日本公司75%的领域，组建了日本在日本复印机市场仍然蒸蒸日上的富士施乐公司。

前几年，我甚至听说富士竟然已经进入到了电子材料领域，它是从印刷化角度出切入。TAC是制造液晶屏后面防紫外线的重要材料，据说富士已经占有市场70%的份额。而且，由于技术壁垒高、客户很忠诚，所以，富士已经没有了对于需求不稳定的控制力，在必要时甚至可以占产业链进行扩张。

所以，你说什么是富士的核心能力？我个人觉得，富士的核心能力不是那些生产机器、那些市场与客户，而是这些研究人员，以及他们所掌握的技术知识。而富士的核心竞争力，就是管理者在关键时刻作出的判断力，以及对技术资源进行整合的能力，越是在公司转型的这种关键时刻，你越能看出一个公司有没有核心竞争力，以及这种核心能力的要性。

# 3.贝恩公司研究

你也许还会说，老师，你经常给我们一个案例来证明一个道理。一个成功的例子，到底能不能说明一个规律？下面，我给大家一个统计研究，我们更广阔，也更深入的视野下来理解核心能力的重要性。

2000年，贝恩咨询公司的两位学者做了一个非常重要的研究。他们选择了包括美国、澳大利亚、日本、法国、德国、意大利和日本的185家上市公司，本公司的销售额在18亿美元以上。然后，他们为这些公司设定了三个标准。

第一个叫销售总额标准。研究着看看，在们所跟的80家公司中，从1988年到1998年，一共是10年时间，销售者增长10倍每年在5.5%以上的有多少家？你如果达到这个标准的企业，在185家企业里有多少只？答案是大约四分之一，家数只有只占全部销售额总数的27%。我要重说一下，只有四分之一多的公司能部能到高于5.5%的销售额增长率。

那么，两位研究者接下来又设置了第二个标准，有多少企业会计利润达到10年中的平均增长率能达到5.5%？答案更加令人震惊。我和讲，销售额和会计利润都能保持在5.5%以上的公司仅占全部样本公司的1/16。
