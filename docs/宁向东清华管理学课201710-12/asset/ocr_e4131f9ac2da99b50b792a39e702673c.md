# 周末荐文：学习方法｜你敢用青春赌明天么？

宁向东

这周末的荐文，是我之前写过的一篇关于学习的文章。更精确一点，我称为它，"学习方法论"。因为这篇文章，是我即将在周四做的直播课的内容有关，这里算是一个预告、一个引子，希望能够给大家一些启发。

正文:

我们这一代，注定是学外语的一代；而未来的中国人，则一定是有"世界"观的人。这个念头，几乎是从我幼小时候就冒出来，最近一两年则不断在我头脑里强烈地冒出来。我现在就是依据这样的观念在教学生，鼓励年轻人。

以下讲述的，是发生在我身上的故事。

大约半年前，我们的老教授给我打电话，他的宝贝儿子正在老苏的清华大学经管学院做本科毕。朋友和她的妻子二人筹划让儿子参加海外交换项目，一家三口，想出去完全不一致，大到去哪个国家，什么学校，小到交换的选择什么课，考虑得很多，很纠结，但是他们听我的意见，说让我这个"专家"帮着看个主意。

这朋友与我有三十多年的交情，他的孩子就是我说的孩子，我花了一个小时的时间，与孩子随意聊天。对这个孩子进行诊断，然后提出了我的建议。我觉得这个孩子的风可考，考试能力强，他的爸爸本本好强，家风也好，如果重点历练未来，有更多可能性的机会，应该会有非常好的前途。我，我就不要他早早去专业交换，而是建议他去就坚持早早上专业课了，要多花些时间去看看世界。

首先，去哪里。我建议他先去欧洲一学期，然后到美国一学期左右。我当然说，总之是需要在半年左右的时间里，把两边都转一圈。我推荐的一个方案。我为什么，在这个孩子的生命中，不论学什么，还去工作，在英国的可能性远大于去欧洲。也是欧洲，孩子来去以非旅游者的身份去美国的，可能要远超一个欧洲。所以，欧洲可能也是会加上一些板块。

其次，就是选择什么学校，学些什么。我的建议我找个有城市的学校，那些历史和文化方面的课程。我的原因是，在欧洲，进一学校在与别的国家的历史文交处交换到，两学科的学习就为世界史，感受一下在外美国的话就讲了，也不超过十二门课。在英美也是一样，学一门美国史，如果有可能再学一门美国人的世界观，也就够了。

我对这孩子说，如果我对大学的学习有些大错小错，学校会对课上课的大错，水平都不会多好多，不会好到哪里去，坏也坏不到哪里去。就像找劳伦斯，全世界的都差不多。所以，我找个好学校，选两门课意思意思，有个学生身份，是个"有组织"的人，就行了。我特意对他说："别把上课大讲回来，重要的是旅行，与人接触，交谈，到处去看。"

我当大过去哈佛访问学习三个月。临走前，赵洪均老师问我，半日呢，他说我多听听，多问，多走，是学习。我父亲对我们老师听多讲、执行得比较到位的，大概就这件事。但是收获大。每月10000块人民币的补贴，我就用来看两本书了。一是请老师吃饭，二是买他们推荐的，哈佛教育的书。请他们吃下，他给你两本，结果，私有里看到的，比不上他来的更有启发性，都是真货实在的硬货。

我个人的经历，我没有和孩子说说，所以，当孩子听我说了他上我讲得差不多。但当时，我发现我已经讲得偏了。但我还是坚持问他去哪里旅行，看些什么之类的线路。他回答我，就以博物馆和美术馆为兴趣点。为什么去博物馆历史城市名城面的校呢？就是为了一个方便，名城里面可看的东西多，比如，去周边看其它的名胜，交通上一般也方便。

我和孩子说，就我最喜欢的大都会博物馆，卢浮宫和大英博物馆来说，随便来一个月，都值得转两个月的目的。可看世界之丰富和之大。所以，你的判断，其专业也丰富而优秀，但我看你尚未发展，是你的视野。我和他爸这代人是先天不足，没过三条命，我英文不够的，一天，快三十岁了才出国，英文不过是关，看世界也就是看个皮毛，而你们这一代人也有条件在更早时间把语言关过了，有你们有条件，能够到实地去感受世界文明。一句话，我们看看书，你们靠亲历，境界完全不同。

我说，用博物馆了解世界文明，是个捷径。很多人的想法可能不一样。我的体会是，也有很多人照旧去。每月我通常会一幅，但这一幅画，就会给你讲述一个时代，讲述无数真实，有头有尾的故事。很多时间，为了搞清楚这幅画的背后，我甚至会回到图书馆找书看，了解一个画家，了解画中的故事。无形中靠画画与很多历史的人物和事件。一幅画看，有时又会讲出好几次的历史。

渐渐地，你的所看所到，就和史书、野史，以及文学作品有了勾连，人的精神世界就开始成型。兴趣和理想也开始生长丰满，它形成了。这时，你对思考独立思考和独立判断的本领，就是所谓的"见识"。去博物馆看，并不是单纯的为了看那些展品，那些东西就是些无用的由头，离开了这个由头，就没这个趣。但只为了那个由头，就因小失大了。

我对这孩子说，多看几本好的中文历史书，最好还是看中国的上古课本。你刚出国，虽然外语基础不错，但那种应付考试的能力，出去听课交流时也会有点问题。特别是历史和文化领域，专业词汇多，估计光靠英文书写得很难全搞清。记得住，上外，对个短平快，对英财照准进考，所以考试考的是记忆力，中考则往往去考记忆，考考学生是否小，才是对时间的投入。总之，考不重要，考得开眼界，看开天下更重要。

- 2、不要怕误事；
- 3、不要想着看自己是管管专业的；
- 4、不要功利，老看有什么用，什么没用。

这时的我发现这孩子已经完全情障了。我再继续放讲下去，对孩子说："你回去就把我的话转给你爸妈，你爸爸是位记过清华的人，如果信我，具体事情他去操办就行了。"

孩子礼貌地告辞，临出门疑惑地问："叔叔，这样行吗？我早就想这样在外面混两年，好多好多学分呢？" 我平和地说："回去吧，和你爸妈商量商量，说叔叔就这这说的。"

朋友下午打电话来感谢，没有说结果。我也没好意思问他们的想法。我想了想，也帮大家都算是他之后的事了。我想起了一本大辞典中的句话，"要下雨，就要嫁人，随他去吧。"

半年来，我一直回想这件事，经常问自己：如果事关我自己，我会作这样的选择吗？想来想去，我觉得还是事关自己。这样想的话，可能结果是非常事人的。也就是说，如果再给我一次年轻的机会，我至少会有50%的概率做这件事。道理很简单，这会改变一个人的生活。

一般人不作这种高耗通的选择。更多地是基于学习的角度，就像孩子临走我问我的问题。学分多吗？但我清晰，第二，在本科生的专业课么？次，清华和第一大学怎么样呢。所以，在思想上都一样，对于清华经管学院的学生，用三年时间填满本科，是学不完的专业，也是不学完的。把这两个问题想明白了，问题的本质就是靠出，就是用半年海外交换的时间，学学西方的历史，也许不是的。

至少对于这个孩子，我愿得能。我个人认为中国孩子对于世界文明的认知比欧美肤浅，特别是对人类学和社会学这些领域，所以，在对未来一代中国人才里面，需需建立起准确的世界观。这是中华文明的希望所在。

过去，我们因为穷和落后，对西方的认识多停留在"西装革履"的层面上，过于手段。现在，中国富了，应该有一些人去看去理解，去对话了。
