# 1.罗伯与《特朗普谈判术》

![](bbox=[0.1, 0.26, 0.9, 0.35])

《特朗普谈判术》这本书，出版于2005年，那时特朗普还没有当总统。本书的著者名叫罗伯，罗伯是美国房产交易，十年前曾经经手过702笔名地产交易，平均每14周至少有一笔物业交易的谈判，是老资格的谈判专家。罗伯27岁的时候，罗伯为特朗普做过多笔房产交易，特朗普更成交了一组几乎不可能谈成的物业交易，从此深受特朗普信任。特朗普说，罗伯是谈判高手。

那么，谈判是不是很高端很神秘呢？罗伯说，其实不是，会哭的孩子有奶吃，就是人类早期的谈判。你爸给你说不要使用任何语言，这是一个角色和谈判的过程。人们长大后之后，谈判更是无处不在，单位里高强度的工业谈判，在居家安排上买车买房，这都需要谈判。甚至，夫妻之间每天的柴米油盐，也是谈判。在这本《特朗普谈判术》一书中，罗伯创造了个新词，叫：特朗普策略。他说，这个策略用于谈判，对买车、买房，以及和老板谈加薪，都有用。

# 2.特朗普谈判策略

什么是特朗普谈判策略呢？

我们先从一个故事说起。特朗普在纽约最先的一块地产就是特朗普大厦，而要涉及到特朗普大厦的建筑目标，就必须买到一栋相邻的大楼。这栋大楼正位于叫康得尔的人手里。特朗普通过调查发现，这位康得尔老资格的地产商，精明至极，很难对付，而且是极度看重地段，房地产，康得尔看得越重，他越愿意收购，而不是说，所以，直接去找康得尔买房子，想要成交是很难的。特朗普意识到：第一步，必须想办法把康得尔拉到谈判桌前；第二步，把目标调整到康得尔可以接受的范围之内。

![](bbox=[0.25, 0.55, 0.75, 0.6])

那么，特朗普是怎么做的呢？

特朗普首先去购买由另一家公司所拥有的康得尔大厦上方的空间权。没有空间权，特朗普大厦的计划根本不实际的，所以，第一步先把权利拿到手。美国这个国家，产权界定非常清晰，而楼盘的地，产权也是清晰的，楼房上面的空间是谁的，分得很细。所以，康得尔的楼，以及下面土地上虽然康得尔是房子的，但是，康得尔家楼顶上的空间不是康得尔的，所以，想把楼上卖的意思，先得和有权利的一方商量好，处理权利合同问题。

现在，有很多中国人买房，其实有些楼，买了也是不能乱动的，比如你不能够随便拆高。这一点和国地的情况不同。我们现在的小区里面，很多业主是在顶楼加建，其实这是违法的，甚至违法的。因为楼顶的产权，其实并不完全属于个人。在美国，这方面的权利界定是非常清晰的，侵犯别人的产权，是界定是法律责任的。

非常有意思的是，特朗普在购买这个空间权的时候，突然发现这个空间里的合理里面，包含了一个夹缝，就是当所有人大权要用这个空间权的时候，他不可以市场公允的价格购买康得尔的房子，这，也就是，特朗普一旦买下了这个空间权，要用这个空间权去盖楼的时候，他可以按照市场价格去收购康得尔的房子。这谈判为了有这个东西后，特朗普有了讨价还价的权力了，这么个简单。这里面关键就是“市场公允价格”怎么确定。市场公允价格，是一个资不抵债的术语，你不用研究，意思就是出个价公道。

你想想，你如果看中了你邻居的房子，假设你邻居买房的条款，你同意见有一条款：如果你想买他房子的，也必须同意我买你的房子。不过，价格要公道。这一条，是对你有利的，是设防的有利。最后，如果双方说不拢，肯定要打官司，打官司如果成本高，就是两个效供博弈的情形。两效供，肯定是一个无效谈判的目标。

特朗普在这个案子里最聪明的就是，他改变了计划，不再以购买康得尔地块和物业为目标，而是改为一个长期租权合同，这样，一块土地你租100年，和你买块土地，区别大吗？于是，特朗普根据实际情况，就交易环境，果断地调整了目标。但是，这是发生在他的手里，他向康得尔发出了收购要约，康得尔不开价。康得尔开了一个特朗普不可接受的价格，于是，一场旷日持久的法律诉讼就变得更加难避免了。

对峙之中，康得尔率先示弱，他向特朗普提了一个解决方案，是问特朗普：我不要了，出租也行？条件是问好。而这是特朗普希望他有的目标。于是，特朗普的厉害就开始了，他没有直接答应，他继续作出要强势购买的架势。他反问康得尔：如果你想卖房，拿一大笔钱，有什么不好？卖房了，这是特朗普明讨价还价。于是，康得尔不示弱，摇头向特朗普说道：第一，我不想每次都卖空一块块，第二，你想房子孙每一笔能够收到租金的房子，而不是给我们现钞。这就是为什么他不肯卖，希望出租的原因。这也是康得尔的底线。

听到这里，特朗普开始演出了，他说：利威，你听：特朗普此时是威赫着康得尔先生的大名，特朗普这件事，我原来根本就没有想过出租这件事，我是想卖掉。现在我知道了你为了孙子的忧虑，那就说定了吧，你啊，能让让你，那就可吧。然后，他说出法律规定，我要两步来做：第一，一定要保证康得尔先生的权益；第二，一定要签订一个保护亨利特朗普大厦建设的合同。特朗普的谈判一下子营造了信任的气氛，康得尔也作出了令人意外的回应：由特朗普的律师负责起草合同。特朗普的律师倒也特别聪明，如此表示：一定要保证道琼斯的选择一家就代表康得尔的利益。你知道吗？这位律师，也是《特朗普谈判术》一书的作者，后来竟然也成了康得尔的私人律师。
