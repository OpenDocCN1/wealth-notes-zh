# 143讲：组织能力 | 日本制造凭什么崛起

你好，欢迎回到《宁向东的清华管理学课》。

今天我们讨论的概念，叫做“组织能力”，这是顺着从资源能力到内，到能力的核心，能力背后最根本的驱动力，从能量到能力的过程，我们说是一种能量的提升，是一个核心概念。

# 1.TPDS

我们今天讨论的案例分析，是日本的丰田公司。年轻一点的同学可能不太了解，在80年代，席卷整个汽车市场，叫丰田生产方式，简称TPS。丰田生产方式的背后，就蕴含了一种最深层的竞争力：基于人的组织能力。

你可千万不要以为这种“丰田生产方式”说的那么简单，机械化。很多管理学家常说，丰田汽车当年能够杀入江湖，核心不是你机器自动化，而是人，是流水线旁边不断去创造的化“一个人”。今天，时间已经到了21世纪，我们说一张嘴就是大数据、人工智能、自动化工厂，不可能。但我依然觉得，人的力量是不能低估的。最后，决定这个社会运动的关键因素，依然是人。

上次直播的时候，我说：我们的管理课在内容上出现断层。就是说，虽然我在后面的内容里更多地从商场竞争为主来话题，但你可千万不要把市场组织管理为话题，讲过的团队，讲过的企业文化。我说我后面的课程可能和前面的内容不是那么协调，形成断层。今天就是第一次。这几天，我们讲资源、能力、核心能力，在核心能力背后更深层的内容是什么？其实是人的力量，是组织的内容，没有组织能力，所有的技术、设备，都是无源之水、无本之木。

# 2.案例：丰田的崛起

如果你不信，我们接着看丰田的故事。

丰田公司的起家，你是在汽车行业的商业系统史里，你不会知道：丰田起家的行业，是纺织机械。丰田创始人丰田佐吉了不起的地方，就是在1899年前后，开始纺织机械发明，英国人是英国是世界第一的纺织大国，第一流纺织大国买你的纺织机，无非就是说明你的东西世界一流的。丰田当时对于日本经济是第一个头头和梁，很有点今天华为的意思。

不过，丰田佐吉后来遇到了一点麻烦，就是他的唯一的儿子丰田喜一郎（喜一郎是丰田唯一的口误，我有一集是丰田喜八郎的儿子）死活不肯跟他搞纺织机械，而是想在日本搞汽车。在那个年代，日本老大的儿子不找实业，就在中国一个地产业板的儿子，决定把全家的家给投资去搞丰田车，然后放弃对于人生太投入太坚持这一种，丰田就着急上火，这不是娶亲吗？但后来怎么办，谁也挡不住，索性由着儿子去干了。结果，谁也没想到，经历了大半人60年的折腾，丰田汽车终于做成了。

![](bbox=[0.25, 0.59, 0.75, 0.71])

80年代，丰田汽车杀入美国市场，给美国那个“雷震得”，不用说了。美国是车轮上的国家，汽车文化汽车那个规模：早先美国人，美国人人看日本人那个规模啊？这种日本车？首先太小，因为日本小，90年代，我在美国亲眼目睹过一次撞车，丰田撞了雪佛兰。我撞车，记得很清楚，丰田开了出来，而那个雪佛兰完全没事。那次，关于丰田车的撞车实力，真是给我留下了深刻的印象。

可是，汽车不是用来撞的。虽然撞着不灵，但开着好开，最重要的是便宜，还省油。70年代几次世界范围内的石油危机导致汽油价飞了几倍，于是，日本的优秀一下子就显露出来了。你不知道丰田车卖在美国哪里，中国台北。哈佛最高的东方问题专家Yogel，文中写了一篇文章，《丰田车》。当时还有一本书，在美国特别流行，叫做《日本战略家》，包括丰田车、本田车，还有电视机等等一大批东西大举进入美国市场。

在所有的日本产品里，丰田有点不一样，有两个特点：

+   1. 它的产品质量不错。我们现在好多企业经常说，要成为世界级的企业，要把产品卖到德国里面，甚至卖到不好卖，要干啥谁谁，我说你，真我找不着了，把衣服卖到美国，都把德国、汽车卖到美国，那是全乎的一个概念。衣衣质服品不行，了不起欠你50人买的。汽车和家电，那都是维修的。你的东西，如果质量不行，美国人工资，光一支你团队的人出去就要把地弄了。丰田让团队去，它的质量当时还算在美国住下了。

+   2. 没过几年，它又推出了凌志汽车。凌志汽车从设计到推出来时，一下子就让美国市场里找到了属于自己的一席之地。总之，就这两点，丰田震惊了整个世界。

于是，美国人就开始研究这个不起眼的日本公司，它怎么能够保持很低的成本，很高的过程，生产出质量有竞争力的产品呢？研究了半天，美国人把丰田的一整套东西，整理成了“丰田生产方式”。不同的美国人的企业里学，还把它写进了美国的MBA课堂。起码20多年的时间里，丰田生产方式，都是时髦的教学内容。

# 3.丰田的理念

那么，丰田生产方式到底是什么呢？很简单，说就是两条：

+   1. 即时生产；
2. 包含人的自动化。

首先，是“即时生产”，英文叫“just in time”。你知道吗，在80年代学习工业会计的时候，这里花很多时间讲，学习时分生产流水中的资金占用时间。那个时候一厂，每台机器旁边都堆着很多半成品。那些半成品都是些，单考虑生产多少，但加一部分就是一笔巨大的数字，把这部分去掉，丰田的生产方式就厉害。它力求把这些东西在所有过程中闲置的资金，全部都减到最低程度。下一个工序刚开始要用的时候，上一个工序生产完毕，让工序之间没有半成品，这就是“即时生产”。

而且丰田的“即时生产”原则不仅仅是体现在制造活动的这个环节里面，而且是在几乎所有的经济活动当中，机器不闲置，人员不闲置，材料不闲置，总之，努力消灭一切“浪费”，消灭一切不能创造价值的“行为”。

丰田生产方式的第二个法宝，是包含人的“自动化”。它要求在制造过程中的“管理”要素，让每一种方法追求机器自决，避免浪费，所有的办法，我说一下自己的理解，也帮你解读一下。

![](bbox=[0.15, 1.0, 0.85, 1.0])

大规模生产制造，美国是典范。我们在说的时候，就讲过效率机器，福特和普罗通过科学管理，建立了大规模制造的繁荣模式。如果你理解了美式的管理生产，你应该知道它的核心就是一机器操作员。人生怎么样？生产系统是一个机器体，人算什么？人就是生产体系的附属品，老就着按机器来工作，人只需要上班就可以了。我根本不需要你的头脑。

“丰田生产方式”厉害的地方，就是它彻底颠覆了机器管理、谁是谁？是人，而不是机器。一线人员是机器操作员来制造良品，所以，一线人员有权利决定怎样可以以最大限度地发挥机器效能。所以，生产线的核心人员、维修人员和一线作业人员，应该一起参与“改善”活动，联手让作业效率不断提高。
