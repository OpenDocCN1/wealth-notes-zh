# 066讲: 下属第一步｜领导？行业？选什么？怎么选？

找到一个愿意帮助自己成长的老板，是展现下属力的第一步。可以用“就业与跳槽策略”来权衡行业与领导。

千万不要以为领导比行业重要。

# 067讲：超额预期 | 好下属胜于胜于

好胜于，“超额期供应”是下属胜任的最标准。

打造下属力，可以追求工作的“独特性”，职位的“不可替代性”、工作成果的“标志性”。

# 068讲: 学习力 | 发展前途的分水岭

在今天这个信息时代，快速学习的能力，或者叫“学习力”，是下属力的重要内容。

“学习力”的逻辑：问题性学习、针对性学习，核心是快速学习。

# 069讲: 业绩导向 | 让自己立住的数据指标

数字是最有说服力的东西，常用数字说话，就会呈现出业绩导向，显示出下属力。数字分为数字表现力和数字实现力。

用管理工具：“目标行动表”打造自己的下属力。

# 070讲: 交出结果 | 给人打工请做好这四步

一个合格的下属，就是要经过积累经验、深度分析和加工，然后逐渐找到可执行、解决问题的路径，才能“交出结果”。

LEAD模型：想、听、分析、做。

# 071讲: 训练下属 | 从提议管理开始

企业的决策问题分为四个环节：提议、批准、执行和监督。提议的环节是企业行动的第一步，一定要把提议交给下属。

可以用管理工具：提议思考表格，辅助决策。

# 072讲：专有信息 | 什么岗位最有利于你发展

在职场中，你有两种信息。“通用信息”，比如操作手册里写的信息，可以用简单语言就能传递，成本很低。

越是专有信息多的地方，有关下属掌握的决策权限就越多，领导越需要有本事让下属用好权力。

# 073讲：有效授权 | 从放手到放心

用管理工具：工作规划表格，对下属进行有效授权。

# 074讲：LMX理论 | 领导者的人际交换奥秘

领导成员交换理论（LMX理论）：领导者关注个别下属的需要，各击攻破、帮助它们解决问题，它们就会产生“圈内人”的感觉。产生对领导者的信任、尊重和使命感，就会努力领导者之所想，急领导之所急。
