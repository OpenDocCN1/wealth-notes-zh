
# 101讲：人际沟通 | 有效交流的逻辑

你好，欢迎来到《宁向东的清华管理学课》。

这一周，我们讲一个非常重要的模块：沟通。沟通是在职场中、在生活中，都是一种非常重要的技能，有多重要？你觉着怎么去定义沟通的重要性，都不过分。

古时候，我们的纵横家去游说列国，不需要去战场厮杀，只要凭三寸之舌，就可以合纵连横，占占便宜。你读过《三国演义》吗？诸葛亮舌战群儒，靠的是什么？就是强大的沟通能力。

## 1. 沟通能力

那么什么是沟通呢？很多人会说，领导明明支持某项决策，或者把台领导说明情况，争取领导的理解和支持，看作沟通。说这些都是沟通，有吗？但还只是狭义的沟通。在我看来，所有涉及到与外部进行信息交换的事情，都是沟通。你家里面，和家人做一些事情就讨论一下，这是沟通。我通过“得到”的平台教您管理学，这是一种沟通。我个人觉得，你只有从这个广义的角度建立“沟通”意识，有助于你看清沟通的本质，多练习，然后发展出有效沟通的能力。

下面，我给你们两个概念：单向沟通和双向沟通。你今天给别人朋友圈发一条微信，把你的信息分享给大家，这是一次沟通，只不过这，是单向沟通。如果今天你的朋友圈同事给你回了一条微信，表达了他的意见，单向沟通就变成了双向沟通。毫无疑问，双向比单向含有更多的信息交流，所以，格外有意义。客户登录到你的网站上了，看了各种产品，这就是单向沟通，如果他发表了对产品的意见和评价，就变成了双向沟通。记住：无论与客户还是同事在一起，双向沟通都比单向沟通有意义。

## 2. 有效沟通的逻辑

我们给出了沟通的概念，也说了沟通是非常重要的。但今天讲的课不是为了说沟通有多重要，而是为后面教你提升沟通能力打个基础。下面，我就根据一个案例来说明如何改善沟通效率。

你知道，我是老师，在学校工作，遇到最多的就是学生毕业答辩，或者面试。很多人不是怕这些是答辩是工作，他们觉得面试就是痛苦，答辩就是答辩。但实际上，毕业答辩，就是一次沟通。所以，我对自己指导的学生，都是按照有效沟通的原则帮助他们设计答辩。

![](img/3148dc16965f9a57e897fce984cfd348_53_0.png)

学生答辩的过程中，有两个参与方：一方是学生，另一方是几位评委老师。我们清华的研究生毕业论文答辩时间20分钟左右，所以要评委事先在报刊问，根据你答辩的多少，学生答辩的时间是10分钟到20分钟。

你大约也有过类似的经历。学生在答辩之前要做PPT，很多人就是死抠论文里面的一些主要内容进去，然后在，讨论发言老师就PPT，先用这个方式度过最初的20分钟。很多人在汇报的时候特别会讨老师心。然后，他们再次以正式的心情等待老师发问。很多同学由于无法满意地回答老师的问题，最后得分很低。我认为沟通，如果你也是这么准备答辩，作为一次沟通，这就是失败的沟通。

为什么呢？因为这样做，违背了有效沟通的几个原则。

## 3. 组织里的4种沟通

最后，我和你分享一个观点。有一对研究管理学的夫妻，他们把组织里的沟通分成了四种：

- 是倡议性沟通。这种沟通的目的是，提出一个建议，希望大家一起努力，共同实现一个目标。所以，这种倡议性沟通，就是为了向别人勾勒出一个美好的愿景，让大家觉得这个目标是可以实现的，最好能够引发更多的人参与、支持；
- 是理解性沟通。这种沟通多发生在请求对方投入资源、参与合作的情境时，关键是要让沟通的对方知道合作对于他的好处，一定要说明对方在合作中能够得到什么好处；
- 是执行性沟通，业绩谈话常常属于这一类沟通。这种沟通的核心是让对方明白自己已有行动的效果，以及未来需要投入承诺、采取行动，在什么时间、投入何种努力，才能达到预期的效果；
- 是总结性沟通。用于在工作结束之后，表达感谢或者告诉这个工作已经完成的沟通。

在这四种不同类型的沟通中，所需要的时机、方式和沟通内容，是不一样的。这是你格外要注意的。

## 2. 沟通设计四要素

所以，今天的课，我要讲的核心要点就是请你从今天开始，像老师教书一样去准备每一次沟通，并且你记住它：准备的要点主要包括以下几个方面。

- 你必须想清楚，你所沟通的对象是什么样的人，他们想什么会处于什么样的样子和精神状态。即将沟通的事情，对于他们来说，是不是属于他们关心的对象；

## 3. 案例：设计沟通，突破僵局

下面，我给你讲一个实际的例子，是发生在我一个清华毕业的故事。若干年前，这位同学B大学毕业，进入一家著名企业负责运营工作，他直接支持几个兄弟部门，这些部门的工作任务都是独立性的，工作调整的工作都在不同部门的经理那里，大家各自为政，彼此之间是一种业绩上的竞争关系。

但是，我的学生却发现，各个部门之间在工作任务和资源的分配关系上常常会存在错配的情况。比如，当一个部门特别忙的时候，其它部门处于无事可做状态，所以，如果能从建立事务上做到一定的协作关系，则从整个的角度来看获益，对于每一个部门的业绩也上升并没有坏处，只是没有部门经理愿意伸出援手去帮助别人。

这位做生意经理的公司在级别上和他的建议。这时他曾经在两任CEO经理处表示了不同意见，这两个人的反对让位同学立刻意识到，虽然进行协同工作从长期看对大家都有好处，但部门经理在这种合作中的受益是不确定的，也是不确定的，何况还有其它不确定的因素，特别是有可能会损害到本部门业绩的事情，谁都愿意先出手。

我的这位学生说，在公司的级别上和这些业务经理是相同的，所以，他没有权利要求所有部门经理一致要配合他完成这个倡议。在这种情况下，他分别一对一了每个部门经理的利益和立场，然后决定挑两个在这个跨部门协作中受益最多的部分经理进行一个对话，在这次交谈中，他分别给两个部门经理写了一封邮件，详细地说明了开展这件事可以给各部分带来的好处，这些好处都是显性的，其中一个受益最多的部分的效率可以显著提升50%。

我这位学生说，他坚信：同级之间的经理人，如果你一直认为你不同不是一个自己的人，对于支持的部门领导，如果是整别人着看的，他们就会愿意配合你改流程。结果，即使将来到他的部门大家都愿意配合。果然，当到部门一起参与了这个流程改造工作之后，这家企业的置效率有了明显提高，两个部门之间开始推所有部门都加入这个协同计划，由于推到了最先参与的部门得到了好处。所以，其它部门经理都没有再说他了。

# 103讲：乔哈里窗 | 好东西和大家分享？

你好，欢迎回到《宁向东的清华管理课》。

## 1. 乔哈里窗

今天，我们要讲的核心内容，是由两位大学教授首先研究出来的。两个人的名字，一个叫 Joseph Luft，一个叫 Harry Ingham，是他们研究出来的理论，可以被画成今天文章里的这张表格。所以，他们的研究结果，也就是这张表格的名字，被称为“乔哈里窗”（Johari Window）。Johari 是他们两位名字的缩写。乔来自 Joseph，哈里来自 Harry。

那么，乔哈里窗是什么呢？可以简单地说，它实际上是一个包括四个框的表格。四个框，像个田字格，依次代表了沟通双方对某沟通事情不同的了解程度所形成的四种区域。

| | 自己知道 | 自己不知道 |
|---|---|---|
| 他人知道 | 共识（熟知） | 盲区 |
| 他人不知道 | 隐藏 | 未知 |

第一种情况，是双方对所沟通的事情都了解，双方有足够的共同信息。毫无疑问，在这种情况下，双方的沟通在信息流向上，是更容易取得一致的。这部分内容，乔哈里窗口称之为——共识。这里有一点修正，我称之为“共识”，就是说，这东西，双方都知道了。东西不仅，不仅一定共识啊，是指这个东亚双方都了解，大家认识，且大家对这个东西的认识，是一样的。共识很重要，因为共识是共知的基础。

第二种情况，是别人对即将沟通的事情了解更多，而自己了解较少，自己的认识处于落后的。在这种情况下，沟通是不利于自己的。这种情况，被乔哈里窗称为“盲点”。

第三种情况，就是自己知道的事情细节很多，但别人知道的情况较少，乔哈里窗这种情况叫作“隐藏”。在隐藏的较细下，一般令尔下会对他的沟通是试显与真实，会令对方需要。很多时候，一动谈话，一边遮掩，就需要很好的遮掩，要么有一个看法，演的东西就会出漏洞。一旦自己的演就露了，对方就会知道，是，你自已法就露了，让人家窥探真实自己。也许你说，这，这，这是不是那个“表演不通。你自己说，不是表演？我觉得不通，是不矛盾，取决于他这个是不是诚实。如果是你根本的是的，表演就不是一件好事。

第四种情况，就是双方都不知道的事情，与沟通相关的信息在沟通双方的意识和理解之外。乔哈里把这种情况称为“未知”。如果双方都对这大多数不了解，沟通就会很困难。我个自己最坏的那些除了专业，没有都好的接触对象，因为找不到一个大家能发表意见的话题团队学习时，这是大家时间好的，就是通过一个套路找到他的兴奋点，然后引导他滔滔不绝地谈他的兴趣。

总之，双方的共知的东西越多，共识越多，沟通的效果就会越好，而不知道的东西越多，双方的沟通的效果就会越差。要想达到良好的沟通效果，就要尽可能增加共知的东西，增加共识的比率。这像文章中所下的这个图示，要想达到好的交流效果，非要把共识的自我部分做不可。

| | 自己知道 | 自己不知道 |
|---|---|---|
| 他人知道 | 共识（熟知） | 盲区 |
| 他人不知道 | 隐藏 | 未知 |

## 2. 分享的意义：扩大共识

那么，该如何去增加共识的比率呢？今天，在讲技术之前，我想介绍一个观念：东西在有效沟通的背后，是一种开放世界的。共识，可以说，是一种境界。只有境界提高了，共识才会有提高，更可能在更大范围里与不同的人做有效沟通。

下面，我就分享一下自己的体会。担事地说，最开始得对“去做这份管理学习课”，是准备大范围的企业做过团队学习的，但是，由于“得到”的用户大部分就是C端用户，所以最后课程的线索是没有大批量调整了的，但是，我还没有放弃集体学习这个念头，于是，最后的一两个月，我尝试着和同学讨论如何更有效地促进分享。

也许你觉得宁老师是希望增加新用户。“得”平台和我们的多挣钱，并不是这样。我分享是学习分享，是花多分享钱的。我希望大学分享，是希望不可以课进成员共知的范围，促进沟通，让管理理念可以在更多的企业里生根，有更广泛的群众基础。

我觉得，他又上了一个台阶，从同事之间的“分享者”，变成了一个领导的“支持者”。
我觉得他逐渐长大了，格局也变大了，帮助领导，帮助同事，就是帮助自己。

今天，我花了很多时间讲分享，讲境界，讲格局，其实，都和“共知”和“共识”的形成有关，也和沟通的效率有关。有效地沟通，前提是健康的心态。我觉得，心态不同，一个人和其他人的共知范围、共识范围就会不同。而沟通不是一次性的行为，沟通是一个连续的过程。共知是潜移默化形成的，看似无关的事情，其实都是沟通前的准备。这一点，是今天课程的核心。

## 1. 倾听

![](img/3148dc16965f9a57e897fce984cfd348_59_0.png)

很多人，都以认为自己很会倾听。其实不。我曾经试我经过不少EMBA同学，希望了解他们是不是真正理解“倾听”的含义。这些同学不少是企业高级经人，他们在台上带发现其中有不少人不理解真正的“倾听”意味着什么。很多人，把努力地听，当成了倾听。实际上，你听说的“倾听”，只是摆出了一副认真倾听的架势，或者只出了两对耳朵。但知道吗，真正的倾听，不是仅仅使用耳朵，而是要使用头脑，投人身心。

倾听，是一种能力，更是一件非常非常困难事情。很多人在沟通的过程中，其实，他们并没有专心去听。如果你不能理解我的话，今天你可以做个小实验。比方说，你今天在厨房的时候，在上班的路上，听不完的讲座和课程。然后，你试着回想一下，你听到了什么。两天后，请你再拿出来手机，对照片那天听一遍录音，你自己可以判断一下你是否在两次收听的过程中，得到了相似的内容。如果差距不大，说明你的听力水平非常高，可以不用看这段文字。如果两次的差距很大，我建议以学习的态度，你还是要看一看每天的文档。

我在学校教书，经常需要回答学生的问题。这就是一种沟通。我最常遇到一个问题，就是听不懂学生的话。我有的学生提问时，会说上一大段话，听着听着，就把我给听乱了。我是一认识真的，我常会为大地认真地打学生学，把他常的话一句一句地整理，剔除一些废话，整理一下问题，然后，再和学生确认：这是不是一个你想问我的问题？有的时候，答案是“对，就是这个！”；而另外一些时候，学生是补充其他信息，说他的都意识什么。他正想的，其实他不是在最初说的某些话。我和他一句一句整理的那个过程，就是真正的用心倾听。

如果两个标准衡量看，我们很多人在沟通的时候，并没有真正在倾听，而只是根据人最初说的几句话，来推别人想表达的意思，将一断就给别人套进一个沟通模式中去。在很多的时候，我们都处在这个沟通误区中。当时，没有真正倾听对方所说的意思，也没有把自己所要表达的东西完全想好。很多沟通就是只有这样不够完全的双向思维中进行。效果不够好，是很自然的事情。

所以，我们必须要先学会有效的倾听，这是一切沟通的基础。倾听之后，一定要声势，察其形势。态势的第二个关键问题，要控制沟通的过程朝向自己预设的目标前进。

## 2. 审势

![](img/3148dc16965f9a57e897fce984cfd348_59_1.png)

你听了前面的课，也许已经学会了，每次沟通都要有所要，要明确意图，要知道沟通应该达到一个怎样的效果。不过，除了计划，你要学会读错误的走向不能太快，也不要太慢。沟通是两个人或多个人的事情，所以，要及时对把握沟通对象的反应，并判断沟通的过程和形势，然后及时调整自己的策略和方法。
