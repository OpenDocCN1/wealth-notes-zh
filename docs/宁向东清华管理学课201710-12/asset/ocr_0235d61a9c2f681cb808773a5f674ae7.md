# ## 1. 客户接触点

客户接触点，是营销管理或者销售管理中的标准词汇，是我在研究优衣库的过程中学来的。优衣库的创始人柳井正是对最关心的，叫客户接触点。客户能够触到的东西：比如店面，商品广告。这些客户能触到的东西，是所有客户能够展露产品的起点，不能把这些起点当文章做，后面的事情那就根本没法说。优衣库，柳井正就说：很笨不是广告。

柳井正说，既是广告，就不能不理解客户的心，柳井正喜欢研究客户心理。优衣库一定要写出让客户会心动，然后会大老远地跑到店里来的事情。

从菜市场到超市的很多统计研究，从全世界不同地区展示了非常类似的结果，有超过一半的商品销售，在于客户的临时起意。插着购物车，一边走一边选，到结账的时候再付账。而有些商品就是原来并没有在买计划之中的，都是不知不觉中被选进购物车的。所以，一个按照营销中的规律性，来总结客户一个个接触点，是商的基本功。所以，说到底，还是说充分研究人员学，了解客户，按照客户需要去设计营销战略和销售战略。

这个过程有点像试错，是不断和客户发生互动，抓住不存在于一手就抓住客户兴趣完全抓住，而为一劳永逸这件事。再说，客户本身的需求也会随着时段的变迁，经济环境的变化，乃至文化时尚的变迁，而发生变化。2010年，我还是当代置业集团的董事会成员，那一年，我们的董事会会，管理层踏事实实地去做了几个调查访问，我记得，我当时的日记了十几名多各类型的房地产企业，看有上千年历史的纯木古造营，也看最前沿的东京东丽大厦的现代能源系统。

一路从关西杀到关东，有很多印象深刻、历久弥新的收获。其中，有一点是我在大阪接触到和地产研究的“样本”，一栋住了20户人家的楼。这个楼的标间，我配在了今天的文里，希望你有朝前看一下，和今天的话题，那是我在35年前，和大地产人约20户住宅签了一个协议。

这个协议就是住进这个楼里的这20家住户，在几十年的合同期里是不允许搬家的。为什么呢？因为我们现在是大地产业的“户口体系”。大和不动产也是这些家庭的，然后通过观察这些家庭的人员结构等方面的变化，比如孩子长大了，孩子搬出去住了等等，进一步来研究这些数据对于房屋使用的需求。然后，再试试公司能为这些家庭做些什么，那些新产品是能够满足客户的需要。

这件事给我印象是极为深刻的。每次当我想到“客户接触点”这个概念的时候，我都会写上想到大和地产的栋实验楼。多绕一大步，和大和最早时尝试这件事的时候，在20世纪80年代初日本的泡沫经济时代，在日本的房价价格，比今天的北上广深一点都不差，但是，在这样的环境下，我觉得房地产商还能花大气去做这种百年大计的事情，很了不起。

# ## 2. 商业的本质

我有一个判断，不见得对，供你参考。我觉得，大数据的发展是可以被预见到的。日子里，终归会有一个峰值，虽然就目前还没有到这个峰值，我们看看东西还是要考虑，还要考虑西德一点数字化、信息化的趋势，但是，商业的本质并不需要为数据化，而是为了去满足客户的基本需要。

商业是一种关系，它不是机器对人的关系，而是人对人的关系。所以，在可以预见的将来，影响到人与人之间的互动联系，如果能够达到互动，还是会有竞争优势的。这就是我猜想的，一部分“夫妻老婆店”还是会有生命的。而不同的，这点也不一定是被人称为“夫妻老婆店”，店主也许不是目不识丁的老人也带着孩子的妇女，有可能会有着硕士、历龄能熟练操作各种设备的高知年轻人，也可能不再像那种排摆着酒柜茶馆，而会呈现出另外一种样。会体现出新时代的、人与人之间的商业关系。

# ## 3. 未来的店长

今天的课，是我这几个准备起来最难的，难免我一直犹豫，要不要去担作个预测。后来想，供大家参考参考，也无需。所以，今天这节课，什么逻辑呢？就是我觉得，未来的一个非常重要的职业，叫店长。各种类型的店长，不同的品牌、不同经营策略线下端口的负责人。我觉得，店长会成为未来线下竞争世界的新节点，也更多企业里面关键级的骨干，为正是借助这个机会，企业连通着客户界面，店长的经营管理和“客户接触点”，企业所有的经营数据，最后都通过这个界面去，所以，我觉得，店长在未来将会非常值钱。

我们前面讲过Zara和优衣库的案例。这两家公司是世界上最优秀的企业，但它们在经营模式、产品风格、战略格局等方面，有太多太多东西是不一样的。比如，优衣库本质上是一家服装企业，而Zara实质上则是一家零售型企业。不过，这两家有一个东西是高度相同的，就是都把长店长的权限给得十分重。在优衣库，柳井正说：店长的公司的主脑，由于每一家商店处在位置的不同、面临的目标顾客都是不一样的，所以，店长应该有权利把每一家店当作一个独立的店面去经营。

在优衣库，店长分为四级：普通店长、明星店长、超级明星店长、还有加冠店长。店长的分级是通过考试（包括笔试和面试），然后还有你的工作业绩、企业规则约定的参考和表现，以及队长带的能力，综合，综合权衡后作出。店长的级别不同，首先倒回会带有很大优惠，优衣库超级明星店长的报酬水平，可以达到200万日元左右以上，其次，不同级别的店长，权限也有很大不同。比如，超级明星店长，可以自己选择进货的商品，甚至可以决定是否自降价。你看，这就有点独立经营的意思了。
