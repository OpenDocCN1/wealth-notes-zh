# 1. 价格弹性

这两句话记住了后面，我给你们举个例子，来讲这个价格弹性的概念，你会有些体会，我们常说，客户是不同的，有多种多样的不同，其中最明显的一个不同，就是对商家特别有定价上的不同，也就是他们价格弹性的不同。我们经常说，要对客户分类，要细分市场，除了研究客户的主要主张之外，落实到最后一定定位上，你就要看他的价格敏感程度有没有什么不同。具有不同价格弹性的客户，对于他们的定价策略是不同的。

研究表明，多数人的价格是相当敏感的，是敏感到了骨子里面去，价格弹性的研究历史已经有很多年了。基里斯里面，绝大多数人，只要是到促销广告和打折的样子，神奇地立刻就会开始询价你。你买一单，你不自觉地要增加去购物，就像条件反射一样。

过去逛庙会，你要掏银子，起码还有一点克制。现在电子支付，你就不用掏手，所以，不11元的，往往就是买的更大件开无要求的东西，这就如我们常说的“需求效应”和“从众效应”，打折，给人一种心理的框架，因为价格太便宜了，所以，必须要买。

我和你讲，产生必须要买的冲动，是正常的。美国有学者做过研究，在食品品类的过程中，对价格最敏感的，就是那些中产阶级，不是最富的，也不是最穷的。由于这些人对价格是非常敏感的，所以，商家在客户经常购买，容易记忆价格的商品上，轻易不会提高价格，而是采用其它的办法。

比如，历史上曾经出现过花生的成本上升，对花生生产厂商的公司可能要涨价，才能维护生产收益，可是，企业怕涨价，会受到影响销重，所以，企业利用商品，最后选择了减少商品分量的办法。他们的涨价，就是花生的分量比原来少了一些，这样，虽然名义价格没变，但是，实际上是变相涨价了。另外，在如果我们遇到了商品包装，就换外一，你公司所的商品包装，也不是少。以前的方便面、切片面包之类。

总之，多数的，对于价格敏感的，价格弹性的。你一张价，他就死光了；你一降价，大家就蜂拥买。这是一个基本事实。如果，你所要分的人，不同人之间的类型，三根香烟里面。所以，在价格弹性，但是，大多数是有分的。有人更在乎价格，而，在一个特殊的购物环境中，对于价格不敏感的。

# 2. 差异定价的方法

![](bbox=[0.0, 0.63, 1.0, 0.7])

我给你举个例子。到机场或者机场，去里面去苹果和香蕉，那都说是卖东西，销售的苹果和香蕉，和超市买水果是一样的，但超市卖的苹果是一个大的一瓶。每一块都有青有黄，而买苹果，超市里面几块钱就可以买到一斤了。你不到便利店去卖苹果和香蕉，情况就完全不一样了。

以北京地区的便利店7-11来说，它卖苹果，都是独立包装的。苹果一般是两个装和独立包装里面。品种非常细。个头大和成熟度可以按比例，非常大的包装一般是两个，售价是98，平均每一个苹果里面是四块，售价是9块钱，平均每一个苹果里面是3块。这个价格在超市里不得不买两斤了。香蕉是一种单独包装的，比三个，香蕉有长一点，看上去相好也一点，价格4.5到5.5。

为什么便利店会比超市那么多？道理很简单，就是对于这些便利购物者来说，为了方便，于是对价格的敏感性就小了。也就是说，方便第一，价格反而变成了不太重要的因素。所以，价格变得不敏感，也可以接受，对于价格不敏感的，价格弹性也比较小，而相对于那些价格敏感，还有，为了节省一点或者节省到一点的人来，便利店和超市是单点的。不过，如果你买五毛钱的香蕉，和买三根的是的，为了让你三毛五块钱看起来贵得合理，香蕉的价格和单根的价格比较好一点。

以上就是根据不同价格弹性不同来区分，以及差异定价的一个例子。还有一种精准，是针对于不同的客户群，进行差异化定价，如价格弹性有关。比如，有些餐厅专门针对人群，价格可以看作是针对他们要求的消费，属于一种价格差异。还有，有的保险公司会对年轻司机收取更高的汽车保险，这些汽车是较难保证。设计，的保险公司，年轻的人开车风险高，这两种不同的消费者，价格弹性不同，是因为，年轻人更加容易做出一些保险行为，他们也会更容易采取风险。弹性注意的是，这两个例子都是精准差异定价，并并不是因为价格弹性不同。这个差别，请你一定注意。

# 3. 常见的降价策略

![](bbox=[0.0, 0.98, 1.0, 1.0])

最后，我跟你分享一下降价的招式。常见的降价方法，就是打折，还有买一送一之类的办法。下面，我们比较一下“买三送一”和“打七折”两种策略，有没有不同的，通过这两个例子，帮你熟悉一下降价策略的逻辑。

我们先简单算个账。比如，一件衣服单件是100块钱，如果打七折，就是70块。如果你是十家顾客和成本都是50块，你直接打折，每一件衣服，商家只能赚到20块钱。因此，买三送一，是商家为了增加销量，只能选择一个买一个，七折的话，消费者可能选择买一个，七折的话，就达到了卖三件的销量，也就是说，打折的策略在走量上作用不大，不太适合走货的这一类。

那么，要想在走量上和“买三送一”一样快，你就必须要规定买件件，才能享受三件折扣优惠。这个，对于消费者就有强制性了。不太容易。但如果有买四件打八折。那么，在“买三送一”的出货策略上，一五折，这时，商家赚到的是40块钱。买一送一，四件可以赚到40块钱的利润。

我们再来看看“买三送一”的策略，效果会怎么样？首先，这个对于绝大部分客人的吸引力，是打折的字眼，好太多了。这一点，请你一定要记住。买三送一，你一件衣服会是不确定的，所以，一送，白得，你发现它，对消费者有极大的杀伤力。其次，它可以让你销量一单就变成四件。

我在北京曾经遇到了一次打折促销，就感觉“买三送一”不是常见的“买三送一”。后来，我一直在想，在什么情况下，是买一送一的策略，比打折划算？什么时候是买三送一，什么时候我看到你看到的是买三送一，打折。

比如，你到超市去买，穿着西装的，而衬衫都是打折买，洗衣液，洗发水比较多。西装的衬衫是打5折买，不衣服就卖40块了，西装就卖500块。其实里面，比较易耗的，于是，一次买四件，应该是很寻常的事情。
