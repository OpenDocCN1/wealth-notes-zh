# 一个案例

我再讲一个新案例。有一家老牌跨国公司，一直遵循公司形成在全球运营。由于公司的生产线已不在全球市场，在总体上说管理也还不错，所以，从总体上来说，没有大的需求。新的CEO上台之后，发现客户的需求在最近10年正在发生潜移默化的变化，但是，公司内部弥漫着担心而焦躁的氛围。新技术开发的进度很慢，而且，因为按照地域来运营分公司，在运行和考核，各个分公司在业务层面的交流非常少。

最开始的状况是，该公司在一个国家分公司的开发一套新装备方案，可能需要几年的时问才能被公司位于其他国家的各个分公司关注到。比如，在开会之前各个分总，只会大家知道，然后再通过各种会议告知谁的具体做法，然后再通过一些时间才被传递到公司其他的分公司真正能够实现在自己的区域，传到的速度非常慢。

相反，在竞争对手那里也传播非常快。因此，对方在各分公司层面分享知识的能比自己要快得多。所以，这家公司每一个局部都取得对新意，不是先被自己人学到，而是先被竞争对手学到，这边的局部创新越多，对方的整个创新越快。

当然，这家企业还存在其他的问题。最后，新CEO在积累判断之后，决定把分散的组织结构，在保持每一个国家交易独立、进一步增加客户针对性的同时，公司开始逐渐形成几大主产品的线的全局产品线，负责产品能力的建设和协调。为了能够与这个新的结构相适应，公司分批，分期对新高层的几个总经理进行培训和，研讨和交流，力求建立新组织文化，支持变革。十年过去了，这家公司就现在取得了非常好的效果。

# 有效的组织结构是关键

也许你觉得我讲的这个新案例，属于跨国集团，离我们有点远。其实，离你一点都不远。我们现在很多同一张嘴就是苹果、微软、京东和华为，总说，大家是，你觉得这些人，这些产业离你远吗？如果不管他们离你远，不觉得他们离你远，觉得他们离你远的话，我今天课程讲的内容，离你就不远，而且是你必须要知道的。

坦率地说，一家公司，不管当成领导人，用什么样的管理方式，他的努力就离不开有效的组织结构，就靠布局和好的组织架构和制度体系，就算乔布斯有天才的领导者，也没法把公司治理得井井有条。所以，今天我们先帮你建立一个大企业的认知，在读一些大公司和伟大企业的时候，谈到他们的领导力，你还要知道：作为组织发展起来领导力是基础，企业的组织结构是核心。

其实，从这个模块开始，我们的课已经从软化一点的领导力开始，转向相对更抽象的组织结构和制度体系的内容。这个转变，我提示你一定要注意到。今天的矩阵式组织，也许你第一次听说，但是，它是已经逐渐壮大的功能，在组织结构中不可或缺的元素。它可能存在于、或者和一些大型跨国公司有打交道，我们中国的企业也会越来越多地运用门和跨国经营，他们也会组织构，运作方式和逻辑经理，跟我们身边熟悉的中小企业非常多不同，所以，了解一下今天的矩阵结构，你就能更加了解大企业的跨国企的竞争方式，这会增大你的视野。

# 看这结构，看清管理轴线

就像前面的课程所讲的，建立矩阵式组织的日，就是要根据不同管理目标的要求。不同的管理目标、管理要求，就可以组织交叉的管理线，以，管理者要看到组织结构的形象，看到管理轴线是个十字。这个能力，是管理者的核心能力之一。

在矩阵结构中，不同的管理轴线，是有交叉的。这些交叉又意味着什么？这就是我们需要重点讲的问题。在矩阵式组织里面最大的问题，就是每一个工作组，甚至一个员工，都有可能有一二个主，甚至两个主，也就是同时负责一个工作单元，或者若干员工、小领导，都坐在如或着三条管理轴线的交叉点上。比如，方面，他要听产品的两个负责人，另一方面，他又要对要的地区总部的个领导，或者客户服务经理负责。那么，接着的问题来了，一卜二主，谁说了算？谁优先呢？

其实，回答这个问题很容易，谁是对这个团队的，考上的考核的话语权更大，在金融业的数线上说了，谁就是话更有用的。坦率地说，这个问题不是任何交叉点和组织，都是下级可以解决。一个组织，如果一个人需要建立矩阵式组织，组织的总负责人立必须要有一个统筹的安排，在线上分配上要比事情想到到位，如两条轴线上的交叉点要平衡，要各自管理轴线的目标相匹配，否则一定会带来组织效率的低下，甚至运营上的混乱。

# “一卜二主”谁说了算？

我举一个例子。某个地区的一业绩点，一由产品线的经理管理，产品部门是线，他们的管理轴线也是通过这个业绩点。我们说有个新的产品经理，已经是建立了市场的影力，也是确定的产品收入水平是利润水平；而新产品则需要较大的努力，才能打开市场。那么，这样一个业绩点的努力，如何在现有产品和新产品之间分配呢？毫无疑问，要看考核和业务绩效。如果由区域经理来考核，区域的领导最大在这个业绩点赚多少钱，于是在哪些线上赚到的，无所偏。

相反，如果是产品线经理决定业绩点的考核权重，线产品线的经理权大，业务点就会更多地推产品。如果，产品的权大，业务点就会多费新产品，努力的方向是由谁来考核的。当然，也和激励的强度有关。如果拿一个新产品的奖励，和某个经典产品的奖同一个样多，很自然地，业务点就会加大对于新产品的推广力度。

一般情况下，在任何企业里，都不会把上述业绩点的务的考核和评价权仅仅在某一条管理轴线上，而是要根据不同组织目标，努力争取到做到轴线上的权力大与小，同时就目标指标的确定、绩效前因的达成、战略目标的达成，以及评价考核，并且把新品销售指标纳入到业务线的目标，一销售人员个人真的高大在新产品的推广中。若同时，不愿花费心血和心思推新产品的人，
