# 1. 组织有效性

组织有效性，听上去玄奥的。往简单了说就是：好组织应该是什么样的。那么，好组织究竟应该是什么样的？很多人会觉得越现代的组织，比如说矩阵型的组织，就是好组织。所以，一想到要做组织变革，就首先在形态上要把自己的组织折腾得看上去更高大上一些。但其实，真正有价值的是组织的外表看上去要现代，而是骨子里运行上要有有效性。

我有个比喻，操纵方的方队，你肯定见过，一个训练有素的方队，可以向前后，可以向左走，可以向右走，也可以向左走，或者更训练有素，它还可以向四个方走，或者更训练有素。它还可以向一个方向走，都全有个轴线，始终保持一个不同的管理组织，让它稳定有序地调动组织，就是训练有素。它稳定有序地调动组织，就是排成了矩阵式的方队，不动还可以，一动就乱了。没有组织的有效性，静态地排队两方阵正也没用，一动就都乱了。

# 2. 案例：稻盛和夫的日航改革

我下面给你讲一个企业的实际例子。下面有两张组织架构图，是日本航空在破产前后和稻盛和夫接手后的两个组织架构。如果你仅看组织架构的话，这两个组织看上去是相似的组织，但前后所表现出来的效能却是天壤之别的。这就是刚才说的闻听方队，去这里都是要，不安全，要重新起来去，就就是另外一回事了。这就是组织有效性完全不同。

![](bbox=[0.15, 0.54, 0.85, 0.59])

在2010年之前，日本航空十年十五亏。之所以日本航空会这样，问题是出在组织架构型的选择上，而是组织管理背后的因素全错了。在倒闭之前，日本航空的人认为：

+   1.  作为国家航空公司，日本航空是不会倒闭的；不能倒闭，国家总会想法办法让它生存下去；
2.  航空业典型的周期性行业，赚几个亿和亏几个亿几乎是天注定的事情。去年可能损失大，今年的形势好，什么都不用做，就就赢来了；
3.  国家航空公司，安全第一，成本第二，所以，这家公司中根本没有一个适合的竞争目标的企业，它的安全标准比所有竞争对手都高，坏了就换新的。

所以，在这种思维下，公司对财务收益很差，经营陷入困境。在这种信念之下，它的组织架构是现代的，但组织完全没有有效性。

日本航空于2010年宣告破产，一个月后在东京证券交易所上市，44万名日航股的股东便一夜之间变成废纸。之后稻盛和夫接手了公司。稻盛和夫，是**日本著名的创业家和管理专家**，他先后创立了京瓷和KDDI，也这两家公司员工进入了世界500强的行列。稻盛和夫的管理论叫道叫“阿米巴模式”。阿米巴模式，要点就是企业的核算划得更小、更便于计算，然后企业核算成本核算的方法，按顺序来财务则来统领和管理公司。

![](bbox=[0.1, 0.8, 0.9, 0.855])

稻盛在日本航空所作的调整，从架构图的表面来看，其实不大。他所做的，有点像**向阿氏顾问的管理轴线**，给重新勾勒了。比如，在向前左边的时候，他更多地提出走看，向右面后方的时候，又说该看准，也就是说，看上去结构没有多大的变化，但是，组织上的逻辑完全没有了，几乎同样的组织，但有效性完全变掉了。就是说，稻盛和夫在阿米巴模式引入了阿米巴模式，使架构图，但架架构图引了阿米巴模式有了活力，所以，组织就有了有效性。

我再多给你一些信息，这个粗进进入日本航空总公司之后，他发现原来管理架构是没搞的。架构图是矩阵式的，你可以看变量之前的架构，有垂直的业务管理线，有按地域水平分的管理线。但是，在公司的顶层，有一个负责综合部的部分，叫经营企划总部。这个总部是整个管理体系的出发点，它承担了巨大的经营责任，但是，整个日本航空的管理运动的运动。他认为这一点错了。他决定这个组织架构的发力逻辑是完全错了。所以，稻盛和夫做的，就是把第一阿米巴模式把管理的发力结构提到了第一线。

被推到一线的，是客户经营、航线安排和货运等业务部门，它们直接面对客户，但是过去从来不承担收入责任，一切都是由经营企划总部落下安排，稻盛的的新架构里，这些一线部门是经营工作的出发点，每条航线的收入和支出水平，一线部门都明确的计算出来。同时，有决定代价和成本的架构安排。而是空运服务、机务维修等等部门成了第二条线，是一线业务直接支持部门了。这些二线部门，与一线部门之间的关系，支持，属于关系。明解到的是服从一线部门进入到二线路、二线路进了。
