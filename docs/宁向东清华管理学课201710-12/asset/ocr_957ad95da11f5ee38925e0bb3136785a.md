企业的客户管理，说起来复杂，其实也简单，就是两件事：

+   1. 把已有的客户服务好，包括逐步改善你的产品，不断刷新那些沉睡的客户，增加客户满意度和忠诚度；
2. 通过各种手段，把各种非客户都转化成客户。

从越来越多的客户非客户变成客户的时候，企业就是在走向成功。

昨天的课，我们讨论了如何唤醒沉睡的客户，也就是第一个问题。今天，我们来讨论如何增加客户，也就是第二个问题。

# 1. 三种非客户

企业的非客户，可以分成三种人：

第一种人，叫做企业的准非顾客，这种人已没有客户感，企业说的非顾客，他的满意边界离你的产品距离很近，比如说，他每天都在馄饨馆吃早饭，但在隔壁卖面条，也是出现在他眼前，可他说我要来买面条，他会不会成为你的顾客呢？这意思，就是说他的准非顾客，准，在这里的意思是，他确实现在不是你的顾客，是非客户，但这个非客户，又不是一点成功的可能性也没有，他已经和你的客户标准很近了。

第二种人，叫做拒绝型的非顾客，这种客户也因为消费观念方面的原因，也由于现在的产品和现有不能满足他们的要求，所以，他们对现有的产品和服务做出了一种拒绝的倾向，这些拒绝型的客户，也有可能永远不成为你的客户，但也在作出拒绝的时候，也在你的最得你研究的群体，因为一旦你为他们打开了一扇门，这些客户可能是你最大的蓝海。

第三种人，是企业从未探知的客户，比如，我的管理课，习惯上常被以为是给管理者或者是管理工作者的人听的，可是要有一定的工作经验，不过对于完全没有职场经验的大学生，甚至中学生，是不是可以说也可以学习管理学课程？比如说，如果给中学生讲，完全是可以讲，即使在中学生里也有很多管理问题，比如时间的管理、自我管理、自我管理，比时间的管理，不过讲给中学生，就要用另外一种方式，一种适合他们习惯的方式，所以，中学生们，学习这门课程的问题，但他们的客户群，我以后也没想过如何让中学生从我的学生。所以，中学生是我的管理课从未探知的客户，类似地，家庭主妇、退休的老人，也有很多人应到管理学思想的地方，他们也是我从来探知的客户。

# 2. 转化关键：抓住价值主张

那么，接下来的问题就是，如何把这三类人分别转化为你的客户呢？当然，对于不同的人，转化结果会不同，当然，转化也可能完全不同，不过，最关键的，就是完全相同的，不当，虽然成功转化转化的比例会不一样，但转化的核心都要基于客户的“价值主张”分析。

还记得上一周我讲过一个概念，客户的“价值主张”吗？我再强调一次：所有客户价值工作的基础，就是客户的价值主张，就是清楚、分析、满足，对于客户价值主张和本身主观性的，它要满足，而不是产品或服务本身所有的、客观的东西，所以，企业要向客户提供产品或服务的时，必须要深入探察客户对于产品和服务的感受是什么，你的服务是否能够满足他的价值主张，如果你能搞清楚客户的价值主张，你就可以实现对于客户的转化，你就会创建超乎寻常的经营效果。

# 3. 案例：达美乐披萨

下面，我们分享一个公司的案例，达美乐披萨（Domino's Pizza），你能从我都没听说过这公司的名字，不过，我应该告诉你，这是全世界第二大生产力，西萨店的连锁餐饮集团，这家公司现在在全世界拥有2万多家店，年收入20多亿美金，大约150亿人民币。

这达美乐披萨创立于1960年，说起来像是故事，他的创始人莫纳汉（Monaghan）当时企业缩小，他的想法，就是没没想过把大家伙儿的头，他是想快点赚点钱，没啥大想法，1965年，他就把这家店的名字改成了现在的Domino's，就是中文对应的多米诺骨牌的“多米诺”，没想到这家店真的就像多米诺骨牌一样发展起来了。

![](bbox=[0.1, 0.89, 0.9, 0.92])

达美乐披萨，最多卖得也快，为什么？因为吃披萨在欧美，就像我们一般的吃汉堡一样，不容易做出吃名，我给你讲个我亲身经历的故事，最极端的例子，有一次，我去美国人家里吃饭，那主人就拿出两个比萨，比萨No.1和比萨No.2，家庭主妇就是做了从店里买来的比萨，虽然，就是那种不很对劲的比萨的面饼，然后在上面放上并不好吃的芝士，然后，水里煮着什么青菜，香肠，切一点蔬菜在上面，然后放进烤箱了，这是一道美国家庭最常见的，一种披萨的做法。

所以，莫纳汉就想到，价格和质量可能并不是客户价值主张所在。客户之所以从外面在家里买回家，可能最关心的是距离多长时间可以送到，那么，关心的时间是否合适，我觉得，这个时间的确定，是莫纳汉最大的价值，他说，你，如果在自己家里做披萨，就算面饼，在超市也已买好的，烤好了，然后，你要半个小时，莫纳汉就说承诺客户的，半个小时一定送到，否则白送，莫纳汉的店就开在密歇根大学校对面，你知道校园里面有多少学生吗？两万人，所以，就是圆，这达美乐几乎没多久就赚了一个盆满锅满。
