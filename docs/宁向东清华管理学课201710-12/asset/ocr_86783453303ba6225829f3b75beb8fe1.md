# 0831讲：十一寄语 | 学习就像打江山

今天是十一国庆节。祝大家节日快乐。

每年国庆节，我都会回想共和国的发展史，回想那些关键的时期。今年夏天，我在武汉，特意去了七八次历史纪念馆。我一直认为1927年召开的这次会议，是中国复兴中最重要的历史会议。在那次会议上，毛主席发表了一句非常重的话。后来，这句话被总结成‘枪杆子里面出政权’。这有了我们现政的基础。

其实，学习一门课程和打江山的道理是一样的，从一块土地根据地出发，一点一点把知识学到手，理解了，巩固了，知识的边界就扩大了，地盘就大了。知识之间是有联系的，有逻辑的，能够不断回到原点，又不断从熟悉的知识点中跑出来，跑到相关的内容中去，就像在不同的地区之间修了公路，形成了联系。

到今天为止，我们的课程已经讲了四周。我们讲了人性、领导、团队、下属四个模块。我总有一个感觉，我们已经到了1937年，我们已经在延安站住了脚跟。我们知道，敌我毛主席的是，作为一个伟大的战略家，在延安时，敌军在平、在北京、在上海、武汉的炮火里，他只看到了“战略的防御、战略相持和战略反攻”的三个阶段，他还能清楚地看到了全局解放的趋势，看到了全局解放了时间问题。

所以，借着国庆节，我和你分享一个坚持的观念。哪怕你是一个在职的大学生，你没有任何管理工作的经验，只要坚持学习一年，一定会改变你人生。

今天和你分享四个字：点、线、网、通。

我们每天学的知识，都是一个“点”。每周的复盘，就是把这些点连成一条线。在同五的复盘中，也许你体会到了，三周下来，我们讲的东西，这四条线。就像公路一样，把五天的知识点联系了起来。每一个模块的复盘，我们做的是一个网。这是我们自己的事情。而我们要做的，就是遇到一个问题，或者有空的时候，来复习这些点、线和网。就像坐在汽车，在知识的知识中巡视，巡视的结果，就是把你打通了。

点、线、网、通，就是知识体系，在计算机互联网时代，在碎片化生活的处境下，碎片化学习、体系化复습的新型教学模式。这是我们的努力，我也看到了很多同学的笔记。比如李嘉诚，曾鸣老师，还有那位经常在学小圈里发言的漫谈者，学了更多的同学，我就不再一一提你的名字了。总之，谢谢大家来跟随我的三万多，你们是我努力改进课程的动力。

在学习后，我写的一句叫“枪扎进步，步步为营”。一句叫做“星星之火，可以燎原”。后一句，是毛主席的话。我觉得比什么“一万小时练习”之类的，更让我有共鸣。请你记住，在一个人成长的道路，有快乐，但更多的是付出努力。我是不相信学习有什么捷径的。我在读大学的时候，知道了一句名言，我深说它的一句话，这句话几乎影响了我的——学习，就是把钱省在很里面，想未来一定有回报的。

最后，送给大家一句话：管理学的最高境界，就是无招胜有招。无招胜有招，要招招学起。学一招，没有招，没有招式，有一天，你一定有招胜有招的本事。

明天开始，我们开始学习一个新模块：组织。我们明天见。

# 一周精选留言

今天的课程让我回去复习了三篇文章，[理性注入]。从根本上管理就讲的是人的命运并不是完全由基因决定的，人的意识和行为是可以有科学的方法来改变。管理张杰是一个实际操作，通过情绪注入和理性注入来冲淡原有的情绪，从而缓解情绪。情绪：从生产、情绪的从情绪影响人的决策，是决策的一部分。状态自等[管理他人的切入点，所谓理性人应该从尊重他人开始，从下属理解他的心情。当下属表现不佳时，当领导的不负责任，否则会影响下属的情绪，知道让他的表现更好。正确的方法是尊重下属的同时，给予下属关键指导，用你的行为来影响下属的行为。

宁教授今天分享的前馈管理，我是比较认同这种方式，因为如果前面沟通不好，后出了问题往往很难去补救。在我安排工作时，我一般不会只说一个任务，我会给背景说一下，为什么要做，对于下周我统一思想，因为目标清晰了，其他工作是方法和创新，不一定非要按我的想法去执行。如果团队中有新的见解，我会采纳。如果我发现问题和偏差，我会及时纠正。比如团队中有人偷懒，我也不会直接说，而是大家一起讨论未来半年的大节和工作重点进行了讨论和安排，时间节点、具体要求、完成标准，责任人都清楚，每周和你工作进度通过周报和月报反思，这样保证不会出现没有节点工作有序推进，我想这个也属于前馈管理。

同理心需要经历，或者看小说？[黑魂牌]，没生理性反应的只是换位思考，和同理心还是有层层的区别。年轻时却很理解一切都是不得已。

宁老师，今天课中先开启启动批评的顺序问题，让我想起前几天在一本书中看到的一句话，“木桃之后，胡萝卜才显得分外香甜”。对于领导的批评，我一般首先看看我批评的原因和目的。如果我赞同工作中出现的失误或者个性问题，为了让我快速提高，无论多严厉的批评，我都乐于接受。如果是因为多情的情况，不是意外中“冒犯”，我是把耳朵去听，如果只是因为拉拢不住，想要让我不敢轻易的服从，即使会公开反抗。从一个领到岗位批评，就可以看出他的为人，以及值不值得追随。

团队的重要性不言而喻。就像一支军队，招之即来，来之能战，战之能胜；而要达到这个结果，团队构造是其中必不可少的一环。所以，团白这个过程就是不断赋能（分权、放权、观念灌输、行为指导，而不提不能成过程赋能的过程，也是下属的下属不断提升过程，最终形成一个有战斗的团队！向心力、凝聚力、战斗力的提升之一！
