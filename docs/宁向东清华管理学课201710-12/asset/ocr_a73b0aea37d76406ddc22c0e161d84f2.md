# 1.新零售的未来图景

其实，今天这个课逻辑很直接，就在刚刚，某集团消息称，有零售商超过三分之一的股份。现在，里里外外不只有线上有的，也有线下的店铺，也有线下的批发、和批发收入的超过千亿人民币的，在中国零售业里保持第一年。阿里完成并购之后，马云发布的一系列言论，其背后信号已经昭然若揭。

![](bbox=[0.05, 0.25, 0.95, 0.34])

去年，马云曾断言：纯电子商务的时代很快要终结，新零售在崛起！马云说，电子商务没有冲击传统商业，而是正在创造一种新零售的时代。那么，新零售到底是什么呢？阿里研究院给了一个定义：就是消费服务与线上、线下通过数据来驱动的零售形态。如果说，在阿里并购消息宣告之前，我们还是很清楚这是什么，在阿里公布之后，我们都清楚感觉到，这个新零售的形态，将全面彻底地包含了传统的大规模卖货，形成形态的升级。

这一点，和去年亚马逊并购全食超市（Whole Foods Market），给人异曲同工的感觉。这些收购都解释了明确的信息：线上与线下全面融合，客户、商超与物流全面融合，将不仅是数字层面，而且是规模上的整合。该类整合的效果，可能会发出类似于核聚变一般的效果。

如果说，以前的沃尔玛可以跟客户一站式卖所有的商品，那么，这种大规模交换平台和深度服务，再加上这种大交换平台（也就是平台），的深度介入，将会导致怎样的协作效应，这是目前很难去想象。不过，有这种新零售理念在难题能在细节上如何落地，有这样一个工作一定是保证消费者体验，最重要的工作。

# 2.数据对职位的新要求

首先，很有信息技术背景的首席运营官和首席，非常有对学生的启发，如果你去管理者一定要有财务背景，那么未来的管理者一定要既有信息技术，又懂数与零售的。当你通过上下线结合，把服务体验，到非常关键，而做到这一点，很不容易，需要一个素质的全面的管理者，大家当。

新零售，从模式上就是一场立体战，线上像空军，居高临下，通过数据可以与打精准，而影响大下，辐射范围广，也有一个大战场，线上像陆军和守军，它能够及时与客户体验，可以便捷地与客户交流、线上营销，但是，一家企业，线上、线下网，是要协同配合，配合互补，需要优势互补，优势互补，也是新零售的特征。

这类管理者最重要的帮手，是该去“首席数据”，英语叫chief data officer。这个人的工作任务，就是对公司可以获得客户数据，进挖掘和分析整理，有一个方向，叫做数据官，这在十几年前就有的时候，多学一点，建好你的时间关注的。我觉得这是未来时代的一种重要工作技能。这么做叫数据官，我觉得未来数据和挖掘的数据，技术挖掘，了解客户，公司技术数据挖掘技术，我觉得未来这类人会很吃香。

目前，好像还没有公司设置首席数据官这样的职务，有目前的商业，高管们数字就会发生很大变化，我前儿，我朋友公司的朋友开发服装，根据实际其实是可以买衣服的。买飞机餐的时候，把衣可下机，下飞机就可以拿到衣服了，它不是卖不是来下机就可以拿到，有时候外出参加会议，少带一件衬衣，下了飞机专门去买，所有如某航空公司还提供衣服，一定会有市场。
