
## 0831讲：十一寄语 | 学习就像打江山

今天是十一国庆节。祝大家节日快乐。

每年国庆节，我都会回想共和国的发展史，回想那些关键的时期。今年夏天，我在武汉，特意去了七八次历史纪念馆。我一直认为1927年召开的这次会议，是中国复兴中最重要的历史会议。在那次会议上，毛主席发表了一句非常重的话。后来，这句话被总结成“枪杆子里面出政权”。这有了我们现政权的基础。

其实，学习一门课程和打江山的道理是一样的，从一块土地根据地出发，一点一点把知识学到手，理解了，巩固了，知识的边界就扩大了，地盘就大了。知识之间是有联系的，有逻辑的，能够不断回到原点，又不断从熟悉的知识点中跑出来，跑到相关的内容中去，就像在不同的地区之间修了公路，形成了联系。

到今天为止，我们的课程已经讲了四周。我们讲了人性、领导、团队、下属四个模块。我总有一个感觉，我们已经到了1937年，我们已经在延安站住了脚跟。我们知道，敌我毛主席的是，作为一个伟大的战略家，在延安时，敌军在平、在北京、在上海、武汉的炮火里，他只看到了“战略的防御、战略相持和战略反攻”的三个阶段，他还能清楚地看到了全局解放的趋势，看到了全局解放了时间问题。

所以，借着国庆节，我和你分享一个坚持的观念。哪怕你是一个在职的大学生，你没有任何管理工作的经验，只要坚持学习一年，一定会改变你人生。

今天和你分享四个字：点、线、网、通。

我们每天学的知识，都是一个“点”。每周的复盘，就是把这些点连成一条线。在周末的复盘中，也许你体会到了，三周下来，我们讲的东西，这四条线。就像公路一样，把五天的知识点联系了起来。每一个模块的复盘，我们做的是一个网。这是我们自己的事情。而我们要做的，就是遇到一个问题，或者有空的时候，来复习这些点、线和网。就像坐在汽车，在知识的空间中巡视，巡视的结果，就是把你打通了。

点、线、网、通，就是知识体系，在计算机互联网时代，在碎片化生活的处境下，碎片化学习、体系化复习的新型教学模式。这是我们的努力，我也看到了很多同学的笔记。比如李嘉诚，曾鸣老师，还有那位经常在学小圈里发言的漫谈者，学了更多的同学，我就不再一一提你的名字了。总之，谢谢大家来跟随我的三万多，你们是我努力改进课程的动力。

在学习后，我写了一句叫“枪扎进步，步步为营”。一句叫做“星星之火，可以燎原”。后一句，是毛主席的话。我觉得比什么“一万小时练习”之类的，更让我有共鸣。请你记住，在一个人成长的道路，有快乐，但更多的是付出努力。我是不相信学习有什么捷径的。我在读大学的时候，知道了一句名言，我深记它的一句话，这句话几乎影响了我的——学习，就是把钱省在很里面，想未来一定有回报的。

最后，送给大家一句话：管理学的最高境界，就是无招胜有招。无招胜有招，要招招学起。学一招，没有招，没有招式，有一天，你一定有招胜有招的本事。

明天开始，我们开始学习一个新模块：组织。我们明天见。

## 082讲：组织的细胞|什么是好工作

欢迎回到《宁向东的清华管理课》。

从今天开始，我们进入一个新的模块：组织。这一周我们从讲组织的基本逻辑开始，今天我们就从你可能经常听人讨论的一个话题“什么是好工作”讲起。我希望通过今天的这个讨论，帮你学会看懂组织的底层逻辑。

我曾经接到一个熟人的请求，希望能帮她的孩子说个话，换一份工作。 我问她为什么要换那个工作呀，她的儿子是去国旅最近，每天去换一下小时，她说她孩子，"你的身体不好吗？"她说，没有，就是那个工作环境，所有人都不知道，我觉得能够和总公司说话，所以说，那可以，就来到我单位。她一说，我就很无语了。作为母亲，我特别能够理解她想帮孩子有个轻松的工作环境的想法。这类孩子，本来就靠他给出课，讲进组织的逻辑，后来一想，人家就求我这么一个，你成不成就无所谓一回家，你给人家上一堂课，像是批评教育一样。想想就输了。

这堂课一开始没有太什么，有点感动。不好意思，我给你写个信，希望你能够懂得我想的意思，这道理，以后等考虑工作的时候，得得不要像那位母亲一样简单。

### 设置岗位的基本原则

任何一个组织，都是为了完成特定目标而成立的。在达成目标的过程中，组织必须变成很多任务，这些任务就是一些小完成单位，你要把它们分别到不同人的头上，放在不同的人头上。所以，要了解组织的逻辑，必须要首先了解岗位。

你可以把组织想象成饭碗，工作任务想象成水。如果你组织的所有工作都是升水，如果一个杯子最多可以装一杯水，你要放在八个杯子里呢？正常的话，应该是水放在几个杯子里，咱们把水装进水。但是，我和你拿个基本的观念，如果这样去设定岗位就太危险了，因为这样设计的话，每个杯子的水太多了，也就是说，每一个岗位的任务过于饱满，很容易出现问题。

那到底该如升水呢？一般情况下，原则是放7个杯子到底水右或者1杯，所以，应该找7个杯子，至少要找6个杯子，每个杯子都要半装得太满。这样，就比较从容，水也不会溢出来。但是，原则往往来自岗位任务基本原量位，显然，刚才所拿的朋友的杯子里的每个每天只干4小时的岗位，大部分，少的工作，都是不充分的，于是，那个岗位就成为了大家都要去争抢的香饽饽。

以上讲的是，把任务变成岗位的第一个原则，就是把工作岗位任务化，然后，再去这些任务是完成不同的岗位。每一个岗位的负责要适度，都要装个七八分，不要装得太满。这是设置岗位的基本原则。

### 问题一：工作能力的差异

理解了这个最基本的原则，我们再去讨论更复杂的问题。充的容是第一个问题，就是在现实生活中，杯子的容量是不一样的。

什么意思？就是有人像个大杯子，容量大，能力强。有人是小杯子，容量小，能力弱。那怎么办，这样装，按原装的设计，就无法一定能够装下计划工作，甚至是导致工作目标无法正常实现的问题。如何解决好这个问题，公司人力资源部可能需要考虑组织的问题。除了要找到的点的人，还要考虑有满的或满责任的人，在组织内部还要考虑组织具有的人的，及时调整在每一个大小不等的杯子里装上最适当的任务，进行工作流程的适当调整。

这个问题解决得不好的情况，就是有些杯子小，有些杯子大，人的能力差异较大。于是，就太大杯子多装，但想要小的杯子，就会去少水。甚至更严重的问题，有人本来就小，能多装，但实际上都没人装进去了，对于组织而言，这是小，这就造成苦乐不均，累的累死，闲的闲死。如果按比例原则，就不能有效地解决多劳多得的问题，很多组织就会不匀速进良币，最后有能力的人要么不愿意多干活，要么就会流动掉。

### 问题二：节点性岗位的设置

第二个我们需要讨论的问题，是有一些岗位是用于多种工作任务的连接的点，其是，也又确定需要多少任务的。比如，在某些部门、与其它业务条线关联性强的岗位，要求的不仅仅是水，还有饮料，各种工作任务多少还是要去交给个人，所以，这个岗位要多种技能，而且需要和多个部门成员交流，需要协作和支持。这种岗位就是所谓的“节点型岗位”，对于一个组织非常重要。

任何组织，本质上都是晶体结构，组织能不停摆着走，关键是要有能分解。组织不能形成一个完整的结构，我无法，组织中的节点主要两类：第一类是领导；第二，就是这些各部门工作、负责连接不同工作线条，在工含不同性质工作任务的骨干。

如果这些节点型岗位的骨干，推脱工作的动机强一些，推脱能力大一些，相关部门的人力资源的压力就要大一些，家族的杯子里面东西就少一点，组织的协同效率就会比较低。反之，如果这个工作能力强的人比，如果这个人的工作能力强的人比较少，别人工作有液体，他的杯子液体就不太健康量，这就导致一个节点上的人工作效率低，影响组织一大片的问题。

### 问题三：任务的波动性

第三个值得讨论的问题，就是任务波动性比较大的情况。

在一个组织中，其实有很多岗位是属于这种性质的，有的工作任务的有是均匀的，这样，就好把一条公路，有的时期车多，有的时期车少，这里边的核心问题，这条路足够设计几个车道，如果来保证这条路来稳的话，那就要按照车多车少的情况进行设计，但不能有问题的，这是多少的问题，道路会很难受，这是资源的浪费。所以，最理想的情况，就是设计有弹性公路，正常的时候四车道，车少的时候八车道，车多的时候两车道，当然，这只是一个形象的，在公路设计上，是做不到的。

但是，在岗位设计上，这是有可能的，就是在工作的时候，岗位的设计，一般的工作任务水平来安排。在工作任务来的比较多的时候，有岗位容量过大，要是100%满的有工作，是否还能加100%，什么是超过100%呢？就是在换大杯的基础上，还要增加工作时间。我常拿喜欢开玩笑说，就是加大杯、无期限吃。这就难了，然后，在工作任务不饱满的时候，增加休息，实现一种动态的平衡。

现在，很多组织的问题，从岗位层面上说，就是各种不平衡。

- 第一，任务不饱满；
- 第二，不同的人，苦乐不均；
- 第三，有人常年都是无限碗饭。

以前，你还许只是抱怨加班、苦乐不均等表观现象。但今天这个课，我希望你能理解一个组织最底层的结构。还记得，请你记得组织的细胞就是每一个工作岗位。一个组织的基础时是什么？就是看岗位和工作任务之间是否形成了一种动态的平衡关系，是否有你助于组织的综合效率。

前段时间，有一个人在学小力量留言问我：怎样转向，一位好的人才力量经理。我回答他，可以选择一只聪明的骨子员工，因为力源人力资源，为什么这么说要改好组织的效率，而其中最重要工作，就是任务和能力之间的关系调整、匹配关系。对小型公司，了解人力资源的专业技能很重要。

所以，专业人士从事人力资源工作，有助于深度地认知公司管理计划，及时协同组织资源，有效地业务管理实现协同。

最后，我们再回到今天最初的故事：为什么我会给那个私人今天这堂课呢？每发回来，我只要看工作一两个小的管理问题。来思考，只要是工作。因为管理时简单，在定期根据的情况下，努力越大越低，净收益越小。但是，随着它的逐渐深入，组织一定会不断调整它的组织结构，岗位会精确，这滴满的工作会越来越精

岗位会精简，这种清闲的工作会越来越少。我小的时候，很多人就是一张报纸一杯茶，那才真叫清闲。可这些人后来的日子多数都不好过，因为失去了宝贵的锻炼机会，变懒了。

人一辈子貌似很长，但真正能学本事的时间，其实很有限。我觉得：对于年轻人，什么是好工作？不是那些清闲的工作，而是那些能学东西，岗位上装满了任务的工作。年轻人苦上十年，只要你练出了一身本事，后边可能是享不尽的收获。不过，这些话对一个母亲讲，不容易讲出口。

总结一下今天的课。我们的重点是组织的底层逻辑，把工作任务装在不同的岗位上，装得合理，这是任何组织建设的基础。至于怎样把不同的岗位，结合成为一个部门，形成组织内部的结构，是后面要讲的内容。

## 083讲：组织类型 | 为什么销售不嫌事大

欢迎回到《宁向东的清华管理课》。

昨天的课，我们讲了要把工作任务装在不同的“水杯”里，形成不同的岗位，接着，我们就应该把这个岗位分成不同的组，形成不同的小组织。那么，我们再应该去形成哪些小组织呢？也就是说，究竟应该把哪些标准相同的人岗位放在一起，形成小组织呢？这是今天课程的重点。

### 一个真实的案例

在讲这个道理之前，我先给你讲一个真实的故事。

好多年前，我曾经为一家上市公司担任管理顾问，这家企业的业务是技术类业务，它的大头问题是业务部门的矛盾冲突非常大，领导有大量的时间是在做协调工作，而且没有好的什么解决办法。我带着团队进来之后，发现它的业务部门有四个：技术研发部门，负责新产品和新技术的开发；售后服务部门，是一个呼叫中心（英文叫Call Center），24小时服务。

所有的问题都是在呼叫中心开始的。客户的系统出现问题之后，首先会打到服务中心，服务中心再做记录，然后转给技术系统的运营维护部打电话维修，那个时候互联网还没有这么发达，主要是电话来进行沟通，通过电话一线线，客户的系统就修复了，或者解决了。也麻烦解决了，因为很多人都是系统开发过程中产生的问题，所以，还要转到我，我研发部门，有时候费了半天劲，找到我部门的某人去解决，但是人却很难解决不了。为什么？就是某一年的小软件系统。这是被外包出去的，接着我的维修员，供应商那边呢，他当时是清华北大的几个研究生包的，这几个学生已经毕业了，所以，一路追寻下去，就成了无头案。

客户的问题迟迟解决不了，总经理很着急，所以我们提出了个解决方案。

经过仔细调查之后，我发现，问题其实特别简单，主要出在销售部和研发部门的矛盾上，矛盾点在哪里呢？在销售签单的时候，根本不考虑研发部门和运营维护的能力。什么话都好说，而且单子越大越好，只要客户提出来，销售人员就不考虑研发成本和成本，满口答应，因为只要签下单子，销售人员就有奖金，单子越大，奖金越多。所以，他们不管三七二十一，签单就是硬道理。

销售签下的单子，接着来到了研发部，研发人员就会说：这干不了，那个干不了。怎么办，就是外包。这时公司技术外包的管理相当混乱，所以就出现了学生一毕业，连真正的研发人员都找不到的情况。于是，研发部就开始要求重新开始，有程序打下手，甚至是博士后加博士，博士干客户打过单干不出去的缺陷，不停打电话找服务公司，服务中心也炸多了，服务态度差，客户来投诉老板，老板就转给研发部。研发部又来找老板，研发部和运营部之间互相推诿。最后就把老板基本给逼疯了。

我后来跟老板说，别着急，只需要把组织结构的轴线调一下，问题就会好很多。

### 组织结构的轴线

什么是组织结构的轴线？前面我们说，当岗位和结构确定了之后，接着就该不同的岗位往一起分配，怎么拉呢？

最常见的拉织方法，就是按照职能来组合工作、组合岗位。职能，就是专业，比如研发、设计、运营、施工、生产、销售、财务等等，都是职能。还有一些辅助性的工作，如财务、人力、后勤行政等等，也是职能。

公司发展的最早时期，都是按照职能来划分组织的，也就是按照职能来组织工作岗位。然后，再根据职能发展的需要，在小组织内部增设新的岗位。这类组织，被称为线性职能制组织，专业为基底，管理层从上级，是垂直度的。直线职能制的最大好处，就是专业化程度高，同一专业的人在一起工作，便于专业信息的分享和交流。

但是，直线职能制组织的最大问题，就是不同类型的交叉之间就有缺少交流，甚至是出现部门之间的争利。对于大老板的要求很强，大老板有能力判断所有矛盾，在大集团，还是需要能力不断协调对错，谁该做什么，并且给大家服气。如果大老板没有这个能力，就会出现问题。我举的这个例子是交叉功能，整个组织内部冲突矛盾，无法有效地满足客户。

我说的转变轴线，就是找另外一根编排岗位的线，把存在联系，但专业性质不同的岗位放在同一个小组织之中。比如，我注意到，案例中公司服务的客户类型是不同的。所以，我建议把他们分成小部门，为他们设立不同的业务部门。比如说，给他们拆了三个事业部，大公司客户事业部和小公司客户事业部，每一个部门负责一位总经理，对公司负责。

然后，每位总经理先确定工作流程和工作任务，最后，根据各自完成需要的再去考虑设定岗位，把不同的任务组合成岗位，比如，在不同的事业部，可能研发人员、运营人员和销售人员，事业部总经理对客户承担责任，所有客户问题，总经理负责解决，也就是管理的轴线从纵向的直线职能制，转变为横向的基于客户的事业部制的组织。

### 管理学的基本功：看懂组织架构图

学会看组织架构图，大致可以看懂一些企业的状况，是管理学的一个基本功。

今天的课后，有一个推荐阅读，是关于不同典型组织结构的优点和缺点的，请你看一下，最好把它记住。这是管理者的看家功夫。

当外部环境在变，公司组织架构就需要配合着发生变化，你有了这个看家功夫，一看公司架构的变化，大概就能够判断出高层怎样对未来进行规划的，新的架构也势必会带来什么样的问题。

很多公司都采用事业部制的部门式结构。事业部制除了可以按照刚才说的按客户类型划分，也可以根据产品线来划分。当然，还有一种就是按照地区来划分，成立部门化组织。这种组织在业绩上独立考核，如果分权机制到位，它可以充分针对特定市场上的客户，根据它的特点，更好地利用专有信息来做决策，反应速度会很快。而一旦取得好的业绩结果，也很容易按照业绩水平来支付报酬，激励机制比较容易设计。所以，这种组织形式也深受老板们的喜爱。

### 推荐阅读

**客户事业部制的优点：**

- 1. 鼓励组织更加以客户为中心
- 2. 清晰地识别重要客户
- 3. 能够理解客户需求
- 4. 积极以客户为中心的管理者和员工能够得到发展

**客户事业部制的缺点：**

- 1. 不鼓励不同客户部门之间的协作
- 2. 助长了不同部门之间在资源分配上的冲突
- 3. 当有些客户没有得到其他客户相应的特权的时候会感到不公平
- 4. 问题解决只限于每一个客户部门内部

**区域事业部制的优点：**

- 1. 生产和/或分销的设备和员工都集中在一个地方，可以节省时间和成本
- 2. 能够形成一种解决某个特定区域问题的专业知识
- 3. 能够理解客户的兴趣和需求
- 4. 使生产更接近于原材料的产地及供应商

**区域事业部制的缺点：**

- 1. 在每一个地区都不同程度地存在在智能的重复设置
- 2. 区域目标和组织目标的冲突
- 3. 额外的管理层次以及规章制度的广泛运用以协调和确保各地区质量统一

**产品事业部制的优点：**

- 1. 允许产品生产线的快速变化
- 2. 使得更大量的生产线成为可能
- 3. 鼓励管理者和员工关注客户的需求
- 4. 能够为每一条生产线清晰地界定责任
- 5. 善于跨部门考虑问题的管理者将获得发展

**产品事业部制的缺点：**

- 1. 部门之间的沟通不足
- 2. 产品优先次序的冲突
- 3. 部门间协调的困难
- 4. 关注部门目标甚于组织目标
- 5. 在某一狭窄领域有专长的管理者的发展问题

**直线事业部制的优点：**

- 1. 支持技能专业化
- 2. 减少资源重复、增加职能范围内的协作
- 3. 提高职能范围内的职业发展和培训
- 4. 使得上下级能够共享专门知识
- 5. 促进高质量的技术决策

**直线事业部制的缺点：**

- 1. 不能有效地利用技术和资源
- 2. 不鼓励不同生产线之间的协作
- 3. 助长不同生产线之间资源配置的冲突和斗争
- 4. 限制员工在自己的生产线之外的流动
