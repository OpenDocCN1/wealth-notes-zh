# # 101讲：人际沟通 | 有效交流的逻辑

你好，欢迎来到《宁向东的清华管理学课》。

这一周，我们讲一个非常重要的模块：沟通。沟通是在职场中、在生活中、在一种非重要的技能，有多重要？你觉着怎么去定义沟通的重要性，都不过分。

古风候时代，我们的井台聊天，见得不能够去战略地，用那些交也需三寸之舌，就可以以合纵连横，占占便宜。你读过三国演义吗，诸葛亮舌战群儒，靠的是什么？就是强大的沟通能力。

# ## 1.沟通能力

那么什么是沟通呢？很多人会说领导明明支持自主作出沟通，或者把台领导说明情况，争取领导的理解和支特，看作沟通。说这些都是沟通，有吗，但还只是狭义的沟通。在我看来，所有涉及到与外部进行信息交换的事情，都是沟通。你家里面，和家人做一些事情就讨论一下，这是沟通。我通过《得到》的“平台教您管理学”，这是一种沟通。我个人觉得，你只有从这个广义的角度建立“沟通”意识，有助于你看清沟通的本质，多练习，然后发展出有效沟通的能力。

下面，我给你们两个概念。单向沟通和双向沟通。你今天给别人事条发一条微信，把你的信息分享给大家，这是一次沟通，只不过这，是单向沟通。如果今天你的事条，同事给你回了一条微信，表达了他的意见，单向沟通就变成为了双向沟通。毫无疑问，双向比单向含有更多的信息交流，所以，格外有意义。客户登录到你的网站上了，看了各种产品，这就是单向沟通，如果他发表了对产品的意见和评价，就变为了双向沟通。记住：无地是与客户，还是同事在起，双向沟通都比单向沟通有意义。

# ## 2.有效沟通的逻辑

我们给出了沟通的概念，也说了沟通是非常重婴的。但今天讲的课不是为了说沟通有多重要，而是为后面教你提升沟通能力打个基础。下面，我就根据一个案例来说明如何改善沟通效率。

你知道，我是老师，在学校工作，遇到最多的就是学生毕业答辩，或者者面试。很多人不是怕这些是答辩是工作，他们觉得面试就是痛苦，答辩就是答辩。但实际上，毕业答辩，就是一次沟通。所以，我对自己指导的学生，都是按照有效沟通的原则帮助他们设计答辩。

![](bbox=[0.05, 0.69, 0.95, 0.77])

学生答辩的过程中，有两个参与方：一方是学生，另一方是几位评委老师。我们清华的研究生毕业论文答辩时间20分钟左右，所以要评委事先在报刊问，根据你答辩的多少，学生答辩的时间是10分钟到20分钟。

你大约也有过类似的经历。学生在答辩之前要做PPT，很多人就是死抠论文里面的一些主要内容进去，然后在，讨论发言老师就PPT，先用这个方式度过最初的20分钟。很多人在汇报的时候特别会讨老师心。然后，他们再次以正式的心情等待老师发问。很多同学由于无法满意地回答老师的问题，最后得分很低。我如沟通，如果你也是这准备答辩，作为一次沟通，这就是失败的沟通。

为什么呢？因为这样做，违背了有效沟通的儿个原则。
