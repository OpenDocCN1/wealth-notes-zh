# 1.倾听

![](bbox=[0.2, 0.32, 0.8, 0.42])

很多人，都以认为自己很会倾听。其实不。我曾经试我经过不少EMBA同学，希望了解他们是不是真正理解“倾听”的含义。这些同学不少是企业高级经人，他们在台上带发现其中有不少人不理解真正的“倾听”意味着什么。很多人，把努力地听，当成了倾听。实际上，你听说的“倾听”，只是摆出了一副认真倾听的架势，或者只出了两对耳朵。但知道吗，真正的倾听，不是仅仅使用耳朵，而是要使用头脑，投人身心。

倾听，是一种能力，更是一件非常非常困难事情。很多人在沟通的过程中，其实，他们并没有专心去听。如果你不能理解我的话，今天你可以做个小实验。比方说，你今天在厨房的时候，在上班的路上，听不完的讲座和课程。然后，你试着回想一下，你听到了什么。两天后，请你再拿出来手机，对照片那天听一遍录音，你自己可以判断一下你是否在两次收听的过程中，得到了相似的内容。如果差距不大，说明你的听力水平非常高，可以不用看这段文字。如果两次的差距很大，我建议以学习的态度，你还是要看一看每天的文档。

我在学校教书，经常需要回答学生的问题。这就是一种沟通。我最常遇到一个问题，就是听不懂学生的话。我有的学生提问时，会说上一大段话，听着听着，就把我给听乱了。我是一认识真的，我常会为大地认真地打学生学，把他常的话一句一句地整理，剔除一些废话，整理一下问题，然后，再和学生确认：这是不是一个你想问我的问题？有的时候，答案是“对，就是这个！”；而另外一些时候，学生是补充其他信息，说他的都意识什么。他正想的，其实他不是在最初说的某些话。我和他一句一句整理的那个过程，就是真正的用心倾听。

如果两个标准衡量看，我们很多人在沟通的时候，并没有真正在倾听，而只是根据人最初说的几句话，来推别人想表达的意思，将一断就给别人套进一个沟通模式中去。在很多的时候，我们都处在这个沟通误区中。当时，没有真正倾听对方所说的意思，也没有把自己所要表达的东西完全想好。很多沟通就是只有这样不够完全的双向思维中进行。效果不够好，是很自然的事情。

所以，我们必须要先学会有效的倾听，这是一切沟通的基础。倾听之后，一定要声势，察其形势。态势的第二个关键问题，要控制沟通的过程朝向自己预设的目标前进。

你听了前面的课，也许已经学会了，每次沟通都要有所要，要明确意图，要知道沟通应该达到一个怎样的效果。不过，除了计划，你要学会读错误的走向不能太快，也不要太慢。沟通是两个人或多个人的事情，所以，要及时对把握沟通对象的反应，并判断沟通的过程和形势，然后及时调整自己的策略和方法。
