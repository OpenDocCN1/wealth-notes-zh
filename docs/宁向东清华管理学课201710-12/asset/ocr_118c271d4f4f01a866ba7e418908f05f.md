# 1.ABCO流程

那么，该如何成为一个有效的主持人呢？我首先为你介绍下朴制的ABCO流程，给你一个有助于搭建会议架构，高效主持的工具。

![](bbox=[0.05, 0.33, 0.45, 0.42])

ABCO由四个字母组成。第一个字母A，来自英文Action，中文的意思是“行动”。也就是说，会议主持人必须要在会议开始之前，预先向所有主要参与者了解参加会议的入都有什么目的。这是第一步，也是最重要的一步。具体来说，在每一次会议开始之前，会议发起者主持人都必须要想办法去咨询与会者，我们今天要做什么事，我们要达成怎样的目标，而且要让大家感动：通过大家的积极参与，这个目标是可以实现的。当然，如果有多位主持入还要向参加会议的人说明会议的规则。

讲到这里，你也许会发观，我们今天讲的主持人，可不全，我们所说的主持人，只含个绍和宣布，是平等讨论的主持入，不是指对会议的负全责的人。他们要承担会议设计、组织等有一系列的贵任。

ABCO的B，是Benefit，就是“好处”。会议主持者要多关注会议目的，对大多数人有什么好全。你可能会上升到这个例子，所以一个企业把全天可成课的例子，很重要的一点，就是会议的结果，甚至公司的业绩。在明确中入上与会者没有利害共关的事上，开平会议，与提人就没关系，为什么全要度参会？所以，开全也一样。如果让会议有收获，就一定让参加会议的人知道参加会议能够帮助直接，或者间接的好处。

比如，一个会议涉及到不同部门人员之间的合作，主持人一定要事先构想这种联全度的个别协人，请大家想一想，过一个会议对各个部门入员的收外，如果会议是团队会议，那就要让大家都认识到完成任务对全自收入及业绩有什么帮助。很多会议之所以出非率低，严重扯皮，就是因为大位只有坏处，只有损失，就不能为家讨论的事项中获得益。所以，会议属于典型的与虏类，大家出的益没有会怎不，会议的全决都是如何付出，没议会么可能取得好。

总之，分析了A和B，基本上就可以确定件件事：

+   1.  如何确定会议的范围，有哪些人米参加会议；
2.  会议的结构该如何安排。

开一个发号命令的会议，和开一个平等协商的会议，会议的结构是全完全不同的。在很多时候，由于会与一件的事的，利益全很少，需要全有的平持有权威压着事情能性直下会，会议要仪权威，发号命令，不需要在上一记讨。所以，时的会议组织更强调它的仪式感谢神圣性，只要领导拿手把事情真清楚，把决聚故到，把任务分精到位，然后一个单位和一个单位全置和落实就可了。而协商性的会议则不同，发起者主持人的作用格外重要。

ABCO的C，是英Challenge的第一个学母，意思是“共同面对挑战”，这是整个环节的第三部。由于参加会议的人，都可以通过会议获得好处，这样，他们就具备了我们共同获得解，解决问题的能力。于是，我们全会遇到样困难，我们应该如何应对资源、如何解决问题，这些都成可以议在会议桌面上进行沟适的问题。

ABCO的O，是英文Overcome的第一个字母，Overcome就是克服困难，问解解决问题的意思。我不再多解释，有了ABC，很自然就有O了。

# 2.因事找人，因人议事

我为什么要首先给你介绍ABCO框架呢？因为我觉得，当你成为了一个会议的织者，你设计全的第二个全子，就是定安排什么人米参加会议了。听了ABCO模型，你大约就清楚了，开全一定要找真正与会议议题相关，并且会从会议里面得到好处的人米参加。

你要接照ABCO中的人A和B来分析不同的人，我们首先要选择那些需要我们采取行动，同时也要知道他们可以从会议的讨论，及随进的活动中获益的人。这议人构成了参会者的主要成员，也决定了会议的基本议题。请你一定记得，其实，所谓会议，无非就是一个共同协商工作。开会，就全是有问题要协商解决，需要团体或相关人员就问题，多方面地发表意见，提出建议。所以，参加会议入与议主题的相关性，是全决议有效性的基础。可以说，找对了正确的人，会议就功了一半。

那么，对于那些无法排到全议之外的人，该如何处理呢？这里有很多的技巧，时间的关系，我只讲一种全位定全法。这是从一个朋友那里学来的，不一定对，供你参考。

你一定在全同类型的会，宝里间开过会，有些人会是容易地到，全时，每个人都有全很全地参到其他的人，还有一种会议是长辈全会，全在坐位最高的入发言很容易被人看到，全在不易看得到人，处于这两种全置中的人，话的全响力是完全不同的。当一个人坐在圆桌前，他很容易和其他入沟通，效果一般都不会差。而一个人坐在长条桌的角落里，他的话就很难对别人产生影响。所以，议的人全持，在明确了全议的架构和全意之后，确定了参加者，全需要全在这些细节上做好安排和控制。总全，如果事真大的功全到了，和控制就相似比较轻松。如果事全功谋没有做到，全会议开之后，控制局面就会困难很多。
