# 1.易细账

你现在如果回头看道论的第三讲，“伟大的效率破窗”，讲了特赫罗和泰勒，有同学当时听说的时候说，库克、福克、兰格子的旧事，老师为什么大占我们的时间来讲它？其实，福特和泰勒讲的最关键，再过100年，也有价值，我们今天还要讲过，“作业成本法”和“作业成本管理”，这个逻辑是一脉相承的。福特干了什么？他干的是把一整套生产过程分解成了分段，分解不同的工序、不同的环节；泰勒干了什么？泰勒干的，就是拆分要，计算每一个环节、每一个动作所要求的时间，他们追求细化，就是在向细节要效率。

那么，作业成本法是什么呢？正如昨天我们在例子中所讲的，做的任何生产和服

务活动，都需要一些资源去追逐和准确的成本分解，而这种分解就会引导企业去生成成本，企业如果有算大账，那就是一个成本，一个成本的。如果算细账，就要进行成本追踪和准确的成本分解，而这种分解就会引导企业去生成成本，企业如果有算大账，那就是一个成本，一个成本的。如果把每一个动作做成本核算到位，那多了，合理不合理，这就是从作业的角度来核算成本，简称“作业成本法”。

# 2.成

下面，我们就通过实例来比较用作业成本法进行核算，以及用你目前正在使用的核算方法，同一件事情算下来，结果会差多少。

比如说，有一家企业，以劳动密集型为主的方式生产三种产品，在核算成本时，这家企业长期采用直接成本、直接人工成本，再加上分摊间接费用方式来计算总成本。直接成本，主要是用来生产一种产品的原材料，特别是，特别直接，不会记错到不同的对象上，直接人工，也会类似的情况，可以算得特别准确，花多少人工，会记得非常清楚，直接成本加上直接人工，可以被称为“直接费用”。

与直接费用相比，间接费用就无法算得特别精确，比如一些辅助设备的折旧，在这家企业，制造三种产品时都用到相同的辅助设备，和一些共同的机器和辅助人员，这就形成了一些费用，另外，在产品更换批次的时，也会发生一些费用，你也许可以将此类成本分摊到发生的费用上，想象成为客户对象不同而形成的费用。这些费用的总和，就称为“间接费用”。

你的情况，花一点时间想一想，和你企业的情况，想一想你的企业，和你这家企业是不是类似？很多企业的情况，都是与此非常类似的。

我刚才讲的这家企业，长期以来采用的间接分摊方法主要是按照人工来分子分摊的。为什么要这么分摊呢？因为他们的企业原来劳动密集型企业，人工对力的效果长期以来被认是为衡量企业效率的重要方面。于是，就有了今天文稿中的第一个表格。每一种产品的成本从本算下来之后，下来。然后，经营者按照上成一定的加成来定价，定价目标，在所计算的成本加成基础上，加上一个30%的利润加成，就形成了最后的市场定价。

是不少企业算账的时候很自然使用的方法。

怎么对？使得这种方法，逻辑上成立的前提，就是你的成本核算是对

的。如果成本核算不对，那旁边的事情就全不对了。

那么，这种传统方法算的数对吗？其实不对了，为什么？理由有三条：

+   1.  这家企业生产三种产品的时候，共同使用那两种辅助器，但是，该问行分算应该怎么按比例按照机器工时来分摊，而不应按用人工工时，因为机器工时和人工工时是不一样的。用同的指标来做分摊基数，得出表的数字是不一致的。
    2.  批次会引起一些费用，这些费用应该按照批次来分摊，跟人工时是完全没有关系。
    3.  辅助人员所发生的费用（请注意，这里的不是人时，是指人员，是一种“生产人员的骨干”，甚至是要看他完全在某一种产品上花了多少时间，应该按照时间的比例再去分摊相关的费用。
