# 本周复盘 | 追问：管理的技术

本周复盘|追问：管理的技术

你好，又到周末，我对这周的课进行复盘。

这周的课，从一个叫做“愿景”的概念开始。战略管理，本质上是为了找到一个指导思想，可以保证一个团队，甚至是一个人，在一段时间里面的行动可以保持连贯，不因为人的行动可以彼此协调。所以，取得愿景的成功，非常重要。

愿景要与外部环境、内部资源能力相协调。所以，在框架上我这周的课，是基于所谓的“SWOT”分析：看路表来进入了设计。后端的WOT分析，尽管我对这种设计本身的简单性也表示“不服”，但是，作为初学者的思考路径，我觉得SWOT分析，还是最有价值的。所以，课程还是按照这种基本套路来安排。

我这里多说一句，等你们以后有机会学到高级的战略管理课程时，你就会会记SWOT，忘记PSTEL模型，忘记五力模型。提提这些框架中相互信息的，成为了每天复盘中朋友们之间的信息搜索框架。如果在头脑中形成了这样一个框架，每天遇到不同的信息，你知道把它放在不同的框架中，你就厉害了。

外部环境分析的结果，是希望找到“机会”或“威胁”。SWOT分析中的O和T，我们于机会中威胁这两个概念。这一周我们主要集中讨论过外部环境，从宏观到产业、产业到竞争对手，一点点聚焦。

下周五我们讨论“内部资源”。下周五的课，我们再把这两周的课加以汇总，形成一个基于愿景、内外部分析的逻辑框架。

# 复习：追问的技术

下面，我和你说两件补充性的事，挺重要。

第一，有同学问，五力分析最后如何得到一个结论？我建议你看，这个周末复习一下“画表格”这种方法。在可以用来看，分析供应商每个方面的压力和威胁。

如果用1到10分来打分，你能不能告诉我，你能给供应商打几分？你为什么给5分，那么供应商，我要问我？，你为什么给供应商打8分？你是根什么打的？为了回答这个问题，我带你准备了一个表格，表格中，表格里面的内容是事例，你可以根据自己的具体情况来选择题。

| 供应商的压力评估 | 权重 | 评分 | 加权评分 |
| --- | --- | --- | --- |
| 1.供应商数量 | 20% | 2 | 0.4 |
| 2.转换供应商的成本 | 30% | 7 | 2.1 |
| 3. | ... | ... | ... |
| 加权得分 | | | 5 |

复习：Q3设计：请评评一个提高影响力的供应商工具：管理工坊No.1

得了5分，可以说供应商给你的压力是中等的。但是，如果评价问题提得合适，你会发现你的转换供应商压力的方差，是很大的，也就就是转换供应商的程度，是你下一步管理上要去关注的重点。

这些方法的训练，有一定的技术性。前几天，有同学在后台留言问我，我今天去稍微回答一下，希望能够带给你启示。

第二，就是关于课程的事。我的课程是一周更新一次。所以，问题表一直在变，体系架构，主要内容，都没有变，但标准和顺序，以及讲解的繁简度，会根据同学的后台留言作调整。我们内容上花的精力比较多，课程更有更新表示歉意。一方面，给学员带来不便，我要表示歉意；另一方面，请你从今天开始不要过分关注这个课程，多关注每天的内容。

记住：打开管理学的基本功，是你的目标，也是我的目标。
