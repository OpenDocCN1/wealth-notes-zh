# 1.“顾客就是上帝”的由来

中国有句话，领导们要求下面的人时常说，“顾客就是上帝”。这句话的来源是这样的。在改革开放之前，中国搞了很多年的计划经济，东西不够，都凭票证。到饭馆吃饭，除了要票证，还要有粮票。去衣服店，也要凭票。所以，商店里面的售货员就是大爷，你要求他。

我记得小的时候，商店都是有点坏的，买什么，他去给你，如果没有就要来柜台，你，谁想不高兴。所以，我经常在商店里看到售货员和顾客吵架。后来，开始搞市场经济了，最起码几年经济还没有那么多，所以，售货员还是服务态度不好。于是，中国就开始提了一个口号：客户就是上帝。其实，客户不一定上帝，客户只是关系产品，的东西卖不出去，挣不到钱，客户自然就成了上帝。

现在是供给过剩的时代，多数商品都是过剩的，这又导致了另一个问题，就是上帝太多，商家分不出谁是真上帝，谁是假上帝。反正你分享了“作业成本法”，如果你真的掌握了，就了区分真上帝和假上帝的本事。

# 2.区分客户

![](bbox=[0.2, 0.31, 0.8, 0.38])

上面这张图，是把客户按照销售额和利润进行区分的图示。没错，又是能的四象限图。我们画一个横轴为销售额，纵轴为利润的四维图，以行为依据指企业在一定时间段里销售额和利润率，在这个坐标空间里面位置。如果你的成本数据很够的话，你的客户位置，就会画得准，在他应该在的位置上。

位于第一象限的客户，就是最好的客户，销售额大，利润贡献大。这部分客户就的客户，这些企业一定要花大力气去维护客户，航空公司为什么要花大力气维护头等舱客户、维护贵宾会员等。就是因为他们的利润贡献远远高于后舱，买入机票的客户。我相信你今天一定也有很多这样的重要客户，你的态度、请好吃好喝等，对于这些客户的服都是到位的吗？如果你是一位上帝的优质客户，你希望得到怎样的关注？

位于第四象的客户，是交易数量比较大，但是利润贡献比较少的客户。我们很多企业都有大客户，有很多大客户其实不在第一象限，而是在第三第二象限，这部分客户的消费数量确实大，但是利润贡献却很低。基本，对于这类客户，如何进行管理呢？基本的原则就是提高他们的利润贡献，想办法向第一象限引导客户。

利润等于什么？利润等于收益减去成本。收益等于价格乘以销售量。这个象限的客户，销售量已经很大了，所以，提高销量的难度比较大，所以，一个办法就是提高价格。不过，提价对于很多企业来说，就是要讲究策略和技巧。我们下一的课，只想定价的方法。这里我们不再展开，重点是定价，注意定价不是涨价，是一种巧妙提价的方法。也就是说，对客户中具有某些特征的一部分人进行提价，不会让客户增加太多预算，又往往能够达到比较好的效果。

对于第四象限的客户，还有一个把他们尽可能会向第二象限的方法，就是降低成本。作业成本法本来的含义就是，后来有人提出了作业成本管理和作业成本定价概念，在成本本管理，英文版叫做Activity-Based Management，简称ABM，意思就是说根据客户需要，定制一些产品的功能，进而为向给客户减少不必要的生产制造流程。用我们的话，叫做能省就省。这样下来，作为或者做少了，成本的自然就会减少，成本自然就高了。不过，产品和服务的基本功能够用的，也可以满足客户的需要。

作业定价，再往上就一步，就是“作业成本定价”，英文叫做Activity-Based Pricing，简称ABP。我们的老话就是，如果顾客，对于不同的客户，对不同功能不同，从而善于为客户的预测进行管理，你可以和客户先商量能满足他们价值主张的基本产品功能，然后，再推成本，再次定作价过程，反过来驱动们因素，最后作出决：是否可以在较低价格上生产出来有效的产品。

总之，对于第四象限的客户，就是要想办法把他到第一象限，能够多远就多远，不能把所有人都推到第一象限，一部分人也是一样的。而对于第二象限的客户，思路也是一样。

第二象限的客户，他们的利润贡献较大，但是，对他们的销售量却不够大。所以，对于这类客户，要努力地增加客户的忠诚度，增加客户的消费数量，增加客户主的精细化营，甚至可以通过将客户再细分，以满足之前无法需求的客户推，增加客户的消费。从左方右方推动。

而第三象限的客户，销售量小，利润贡献也是不高的。这是一个企业中油小客户的集合。对于这部分客户，人的办法就是以提供种客户的服务费加成交本，然后寻求服务最大公边界。你应非常清楚什么的时候就该对这些进行放弃。因为你的服资源有限的情况下，过多地将资源投入到第三象限的客户中，将会影响到对于第一象限优质客户的服务。

# 3.从服务成本的角度甄别客户

前面，我们建立了从成本的角度来对客户进行，进行数据管理的问题。现在，我从服务成本的角度来看着这些不同类型的客户源存在的一些特征，在昨天讲的个给的角度，对客户公司实现利润，服务成本的角度对产品进行了分析，最后发现，第一限的客户不仅利润和质量较高，而且在为用户表现为更加慷慨，可以被称为“慷慨型客户”。这些客户的服务成本不高，但是，他们出价高。

与之呈现出明显不同的是，位于左下角第三象限客户。他们的单子一般不大，但是多数客户却非常特别，还，这些客户对价和型客户对于价格非常敏感，他们对服务类型并不大宽容。讨价还价，说实话去主要围绕价格展开，所以，很大的空间去减少或服务的承诺，也可以自由约大量客户。
