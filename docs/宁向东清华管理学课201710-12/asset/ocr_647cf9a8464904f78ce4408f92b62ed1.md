# ## 1.资源能力学派

为什么我自己说不清的东西，还要建议你记住？我想像你爱读《周易》、《周易》本身就不是一个算卦的书，没有什么价值。但是，中国文化书人两千多年不断地解读《易经》，留下了无数解字、哲学思想和文化。有很多大家都不屑于了解经典和比如，清华的校训“自强不息，厚德载物”，就来自《易经》中的两句。我搞不懂《周易》，《易经》我也基本看不懂，但我不敢说我起已经读了那么多话，什么叫哲学？你现在让我给一定定义，我还能说出来。但是，想了很多年，就有很多体会，做起来，这些体会有的时候会起作用。

就像一个管理学家没办法告诉你“能力”下一个明确的定义，但是，我们还是希望多知道一点关于能力的学说，同时经常想想自己的能力和别人强在哪里。

学企业的竞赛者都些人在强能力，这个概念想多了，会助有助于真正做一件事；扬长避短，战的时候，再看看今天。

今天，我们就讲“能力”这个概念。大学者彭罗斯在1959年提出企业成长理论，她认为资源和能力是构成企业竞争活动与结果的关键。彭罗斯的理论形成一个大的管理学派，企业的资源能力学派。2011年，威廉姆森获得诺贝尔奖之后，来到我中心给大家演讲。在午餐饭，一位媒体朋友主动问威廉姆森在企业理论对这个领域，还可以再进步。威廉姆森也可以听到，但他们的研究能力方向有点窄，他们的理论难以实证检验。不过，威廉姆森特别强调了这个理论学派的重要性。

那么，能力在这个学派的理论中究竟有什么地位呢？我会集合一句话：企业是一个生产性资源的集合体，企业内部存在着通过特定资源的能力，让企业成长。这句话是彭罗斯书中重要的一句话。你明白这句话的意思吗？

简单地说，一个组织，就是因为它有着某种特殊的能力，这些能力附着在某种资源上，但能力是资源，资源却是能力，资源是可以买来的，但是，能力不能。能力就像附体的灵魂，有灵魂，肉体就是活的；灵魂脱离肉体，肉身就变成僵尸。能办的说简单起来，因为你可以花钱来买资源，也许在你出手的那一单，买能办业的主人会变化，离开资源而无之，企业的竞争力也就消失了。这就是为什么收购来的企业，多数都不会大放异致的原因。你能买来资源，但你买不来能力。

# ## 2.到底什么是“能力”

那么，能力到底是什么呢？很多时候我们说不出来。就以我工作的清华大学来说，它凭什么在圈组好，这是我常常想到的一个问题。有个组织的独特能力究竟在哪里？很多人想用南边格拉原来的话“大学者，大师之华也，非大楼之谓也”来解释，说清华大学有今天，是因为有大师。但我觉得：大楼、大师都挺重要，而且更重要的是清华大学能招到考分最高的人才，然后，让这些人能花时间在清华园里“自强不息”的精神下生活上一些年，如果没有这个东西，可以说清华很难长期居于中国大学的榜首。

当然，我的话可能会很多人不同意。大家会问：你认为组织好，作为组织学家体现出来。你看，这就是核心能力。核心能力在什么能力、成本与能力之间有一定关系。一个组织而言，是因为它背后一定是什么关键配合在起作用，它的这个逻辑，大家是反驳的。我不建议你我在学能力背后和他最重要的能力，你不需要在想这个能力不是最重要的能力，那样，不是最重要的能力，这样想一下，你的收获就会大很多。

![](bbox=[0.08, 0.0011, 0.45, 0.00125])

那么，该怎样去组织其中哪些能力是最重要的呢？日本有位学者，叫原田曜平，东京大学的教授，它是那种学习子家，他研究日本汽车企业最好的学者，他长期研究丰田等企业，关于能力，他给出了几个层次的定义。

他认为，我们平时看到的、企业的制造能力，那种在相同信息、相同载体的重复生产作业，最多算做表层竞争力。它们决定企业可以观察到的是质量、成本之类的东西。在这个表层竞争力后面的是各种类型信息的传递和整合，从汽车企业来看，这些信息的传递根本没无法简单识别，无法解，无法模仿。基本把这些层面的东西叫做：深层竞争力。换言之，就是这种特有的、深层竞争力的支撑下，企业才能在有限的空间里完成交货期限和设计期限这些隐性的指标。

原田的竞争力看到这个并没有结束，他说，更深竞争力背后的东西下更加厉害，是一种“组织能力”。就是企业内部所有拥有各种管理规则，知识和组织程序，这些可以同有效程度和约束力为力的，这些东西会给有效应的能力，这样那些做深奥竞争力背后的东西，这个组织能力就可以是企业的文化、组织习惯，甚至是员工熟悉的某种味道。

# ## 3.案例：廉价酒店的能力

原本是用汽车行业作为研究对象的，他的理论讲解起来稍微有点麻烦。我换个例子。若干年前，中国开始有廉价酒店，有一个大型企业集团在做这件事。老板的分身，我首先去认识这个产业板块的负责人，是位极其优雅的女士。那时，我修养不好，做得很出色，她应该是容易做的。为什么我这样说？判断就是她好她的衣服、手包非常考究，她的手上戴着一个非常漂亮的手镯，反正整个人都不像是做廉价酒店的。我从她的身上看不到廉价酒店应该有的味道。

廉价酒店应该是什么味道？是阿信的味道。阿信，是日本电影连环线的故事主角。是有着打工自挣自己吃饭的男孩、阿信时在中国影响力巨大，八十年代初中出生的中国人，几乎无人不知，阿信最早不知道阿信，没关系，看看《城南旧事》上李兰尖豆角，面条的小贩，他们身上散发出来的，就是阿信精神，每碗一定要多挣几毛钱，想多赚点钱，全靠一双勤劳的手和从点滴滴入手节俭精神。

但在那位女士身上，我看不到这种精神。仔细去了解一下，她身上属于集团的酒店部总经理，曾经经营过一家五星级酒店。后来，我才知道。五星级酒店和廉价酒店，是完全不同的两个行业。他们的服务完全是两回事，一个拼的是高价值感受、是一个拼的是实惠节俭。组织能力完全不同。所以，我也没绕什么弯子，我直接对导游说：我觉得这个廉价酒店搞成没有谈好，她没打过这个搞连锁酒店，所以，你们的套路就应该在三三星下的酒店定位，不能往168或者270路上做。我判断，他们在那个万发展前，由于组织能力不对，最后一定是死路一条。
