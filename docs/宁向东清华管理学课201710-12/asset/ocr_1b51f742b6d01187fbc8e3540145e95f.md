# 1.企业的目标

企业的目标：满足客户需要，同时有利可图。

在图中，最核心的一条线索，串起了一些概念：主客户、客户、价值主张、关键资源、服务、解决方案，最后是企业。我个人觉得，这几个概念体现了一切商业的逻辑。

对于做企业的人来说，每天在所做的事情，其能够提供的产品和服务在中，找到能够提供的产品和服务，能够帮助客户解决问题、满足需求的产品、服务、或者解决困难。赢得这个客户。企业内部的所事项，都由你的员工做，包括你的模式、组织和流程，包括你的领，一切，都和顾客无关。对于客户来说，只看一条，你的东西行不行，能不能满足我的需要。

而对于企业来说，收入不能覆盖所有的成本，没有净利润，是不能持续的。所以，企业要想办法搞清内外部的事情，要“让客户说”，让员工的“钱”，让一切说“好”，在说“好”之后，还得赚钱，所以，最应该股东“利”。这个生意才能持续下去。这里面就有一个让这条联系主线牵连起来的条件：

+   1. 如果客户所感受到的价值，远远超过了他的实际付出，他就会对你的产品和服务有重新评估，这就是所谓的忠诚度、亲密度，就是一种价值和信任。
2. 如果企业的收入大于成本，做这件事有利润，企业才会给客户提供服务，企业的生命力，就形成了一种关系，一种品牌，一种承诺。

# 2.了解客户的方法

了解客户的方法：多渠道，多形式，讲实效。

要想把上述逻辑线讲清楚，就必须要不断嵌入客户的情境。在信息越来越多、体验需求越新、融入人性也越来越难到刻画的时代，线上与线下相结合，全方位、多渠道的商业化互联网正在渐渐到来。

未来的线性趋势，是逐渐增加到智能支持的。因为消费者在很多时候有需求具体产品，或者购买前会做足功课，所以，零售店面不仅不会消失，有可能还会重新定位，这个走势不是简单地回归，而是会呈现新格局、新样貌。

在新零售时代，线上的大数据更加显现它的价值。企业与客户未来竞争的战略制高点，是让客户更多的信息，以及使用这些信息的精准度。数据会比线上商店的销售额更重要，在经营逻辑、供货关系的转变下，“大数据”、“云计算”和所谓“人工智能”的泡沫也许会吹速下降。

总之，企业将逐渐回归到新零售的本质层面，将有效资源为满足客户价值观主脉服务。以上两点构成了框架图第二层的逻辑线索。

# 3.战略

企业应该是独特的，独特性体现为战略。

下一模块，我们讨论战略。所谓战略，就是满足客户需求的方向与节奏。在这一模块里，与战略关系最紧密的部分，是4C模型，4C模型是AC框架中的4个C：他们客户需要什么？他们的支付能力和意愿？他们在什么时候可能会想到产品和服务？他们什么时刻会对销售感到满意。

然后，针对4C，企业能够做的，就是能从战略的高度回答AP模型所涉及的那四个方面的题，达到你的企业在前面第一条时提到的企业获利能力。首先，企业必须要找到真正满足客户需求的产品和服务。后面，我们会讲，好的产品和服务，一定是需要差别的。至少我个人坚信，只有差异化的产品和服务，才活得下去，更有价值的机会和空间；差异化的企业，才能实现机会和盈利能力。第二个就是科学定价，特别是利用行为科学的一些成果来科学定价。第三，就要找到一个最有效的渠道，增加客户到达率。第四，要考虑使对恰当的营销手段。这四个P，都根植于企业最核心的战略目标。

# 4.客制化、接触点

客制化是趋势，接触点是战场。

客户有需最，我有产品与服务，我接受你的产品和有服务，但是并不代表你有忠诚度。从非客户到客户，是市场开发，客户转化，这个工作很难；但与此相比，保持客户不变成非客户要更难，这就是要不断通过创新，来满足客户的需求。和人在关键时刻需要朋友帮忙一样，企业在很多时候也需要朋友帮忙，企业的朋友就是你的客户。

你的客户凭什么帮你，就看一个东西：你是靠谱值信任。我家楼下有一家面筋店，功能非常相近，我什么总去一家，就是那家店长的感觉，靠谱，信得。他答应从没有食讨，说点什么，几点，从来都没有食讨。同样的条件下，他的生意会更好一些。如果经营若干年，的日子会比另外一家好过，虽然人数、客制化是趋势，值得你关注，但是，特别是对于小型店铺，估计是企业通客户的“软连接”部分，企业所有的经营策略，最后都通过这个人来落实、展开、店长和终端经理会是非常关键的人物。

关于这一点，请记住我上一句：顾客离开你的时候，他们从来不扫尾；当顾客支持你的时候，他们也是默默伏在你的身。客户的情感，就像银行账户的储额，平时储备多多，在关键时刻才能取得更多。千万不要把客户的情感当成信用币，它既没有免息期，也没有一定的交换，请记住在第一块就讲过认说的交换原理，不要奢求带客户的情感。很多时候，店面人员的声招呼和一个笑脸，其效果超过企业的巨款广告。
