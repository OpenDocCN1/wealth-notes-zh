# 设置岗位的基本原则

任何一个组织，都是为了完成特定目标而成立的。在达成目标的过程中，组织必须变成很多任务，这些任务就是一些小完成单位，你要把它们分别到不同人的头上，放在不同的人头上。所以，要了解组织的逻辑，必须要首先了解岗位。

你可以把组织想象成饭碗，工作任务想象成水。如果你组织的所有工作都是升水，如果一个杯子最多可以装一杯水，你要放在八个杯子里呢？正常的话，应该是水放在几个杯子里，咱们把水装进水。但是，我和你拿个基本的观念，如果这样去设定岗位就太危险了，因为这样设计的话，每个杯子的水太多了，也就是说，每一个岗位的任务过于饱满，很容易出现问题。

那到底该如升水呢？一般情况下，原则是放7个杯子到底水右或者1杯，所以，应该找7个杯子，至少要找6个杯子，每个杯子都要半装得太满。这样，就比较从容，水也不会溢出来。但是，原则往往来自岗位任务基本原量位，显然，刚才所拿的朋友的杯子里的每个每天只干4小时的岗位，大部分，少的工作，都是不充分的，于是，那个岗位就成为了大家都要去争抢的香饽饽。

以上讲的是，把任务变成岗位的第一个原则，就是把工作岗位任务化，然后，再去这些任务是完成不同的岗位。每一个岗位的负责要适度，都要装个七八分，不要装得太满。这是设置岗位的基本原则。

# 问题一：工作能力的差异

理解了这个最基本的原则，我们再去讨论更复杂的问题。充的容是第一个问题，就是在现实生活中，杯子的容量是不一样的。

什么意思？就是有人像个大杯子，容量大，能力强。有人是小杯子，容量小，能力弱。那怎么办，这样装，按原装的设计，就无法一定能够装下计划工作，甚至是导致工作目标无法正常实现的问题。如何解决好这个问题，公司人力资源部可能需要考虑组织的问题。除了要找到的点的人，还要考虑有满的或满责任的人，在组织内部还要考虑组织具有的人的，及时调整在每一个大小不等的杯子里装上最适当的任务，进行工作流程的适当调整。

这个问题解决得不好的情况，就是有些杯子小，有些杯子大，人的能力差异较大。于是，就太大杯子多装，但想要小的杯子，就会去少水。甚至更严重的问题，有人本来就小，能多装，但实际上都没人装进去了，对于组织而言，这是小，这就造成苦乐不均，累的累死，闲的闲死。如果按比例原则，就不能有效地解决多劳多得的问题，很多组织就会不匀速进良币，最后有能力的人要么不愿意多干活，要么就会流动掉。

# 问题二：节点性岗位的设置

第二个我们需要讨论的问题，是有一些岗位是用于多种工作任务的连接的点，其是，也又确定需要多少任务的。比如，在某些部门、与其它业务条线关联性强的岗位，要求的不仅仅是水，还有饮料，各种工作任务多少还是要去交给个人，所以，这个岗位要多种技能，而且需要和多个部门成员交流，需要协作和支持。这种岗位就是所谓的“节点型岗位”，对于一个组织非常重要。

任何组织，本质上都是晶体结构，组织能不停摆着走，关键是要有能分解。组织不能形成一个完整的结构，我无法，组织中的节点主要两类：第一类是领导；第二，就是这些各部门工作、负责连接不同工作线条，在工含不同性质工作任务的骨干。

如果这些节点型岗位的骨干，推脱工作的动机强一些，推脱能力大一些，相关部门的人力资源的压力就要大一些，家族的杯子里面东西就少一点，组织的协同效率就会比较低。反之，如果这个工作能力强的人比，如果这个人的工作能力强的人比较少，别人工作有液体，他的杯子液体就不太健康量，这就导致一个节点上的人工作效率低，影响组织一大片的问题。

# 问题三：任务的波动性

第三个值得讨论的问题，就是任务波动性比较大的情况。

在一个组织中，其实有很多岗位是属于这种性质的，有的工作任务的有是均匀的，这样，就好把一条公路，有的时期车多，有的时期车少，这里边的核心问题，这条路足够设计几个车道，如果来保证这条路来稳的话，那就要按照车多车少的情况进行设计，但不能有问题的，这是多少的问题，道路会很难受，这是资源的浪费。所以，最理想的情况，就是设计有弹性公路，正常的时候四车道，车少的时候八车道，车多的时候两车道，当然，这只是一个形象的，在公路设计上，是做不到的。

但是，在岗位设计上，这是有可能的，就是在工作的时候，岗位的设计，一般的工作任务水平来安排。在工作任务来的比较多的时候，有岗位容量过大，要是100%满的有工作，是否还能加100%，什么是超过100%呢？就是在换大杯的基础上，还要增加工作时间。我常拿喜欢开玩笑说，就是加大杯、无期限吃。这就难了，然后，在工作任务不饱满的时候，增加休息，实现一种动态的平衡。

现在，很多组织的问题，从岗位层面上说，就是各种不平衡。

+   第一，任务不饱满；

+   第二，不同的人，苦乐不均；

+   第三，有人常年都是无限碗饭。

以前，你还许只是抱怨加班、苦乐不均等表观现象。但今天这个课，我希望你能理解一个组织最底层的结构。还记得，请你记得组织的细胞就是每一个工作岗位。一个组织的基础时是什么？就是看岗位和工作任务之间是否形成了一种动态的平衡关系，是否有你助于组织的综合效率。

前段时间，有一个人在学小力量留言问我：怎样转向，一位好的人才力量经理。我回答他，可以选择一只聪明的骨子员工，因为力源人力资源，为什么这么说要改好组织的效率，而其中最重要工作，就是任务和能力之间的关系调整、匹配关系。对小型公司，了解人力资源的专业技能很重要。

所以，专业人士从事人力资源工作，有助于深度地认知公司管理计划，及时协同组织资源，有效地业务管理实现协同。
