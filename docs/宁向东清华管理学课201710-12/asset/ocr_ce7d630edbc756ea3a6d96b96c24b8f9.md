# 2.沟通设计四要素

所以，今天的课，我要讲的核心要点就是请你从今天开始，像老师教书一样去准备每一次沟通，并且你记住它：准备的要点主要包括以下几个方面。

+   1. 你必须想清楚，你所沟通的对象是什么样的人，他们想什么会处于什么样的样子和精神状态。即将沟通的事情，对于他们来说，是不是属于他们关心的对象；

+   2. 在将行沟通中，你要达到什么样的目的。这个目的最好可能被你量化、包括特别满意、好的状态指标、可以接受的指标，一旦找到对好的状态指标、包括特别满意、好的状态指标、可以接受的指标等，就容易对沟通的进展进行监控，也更容易通过沟通结果对于沟通对象的意义和影响形成清楚认知；

+   3. 你必须要沟通过程中要传达的信息进行有条理的安排，要根据信息间相互的关系和沟通对象传递信息；

+   4. 一是选择最佳的沟通渠道，包括选择什么信息、什么信息传递、信息传递的最快时机，在什么时间下沟通，在什么场合沟通，选择最恰当的语境；

# 3.案例：设计沟通，突破僵局

下面，我给你讲一个实际的例子，是发生在我一个清华毕业的故事。若干年前，这位同学B大学毕业，进入一家著名企业负责运营工作，他直接支持几个兄弟部门，这些部门的工作任务都是独立性的，工作调整的工作都在不同部门的经理那里，大家各自为政，彼此之间是一种业绩上的竞争关系。

但是，我的学生却发现，各个部门之间在工作任务和资源的分配关系上常常会存在错配的情况。比如，当一个部门特别忙的时候，其它部门处于无事可做状态，所以，如果能从建立事务上做到一定的协作关系，则从整个的角度来看获益，对于每一个部门的业绩也上升并没有坏处，只是没有部门经理愿意伸出援手去帮助别人。

这位做生意经理的公司在级别上和他的建议。这时他曾经在两任CEO经理处表示了不同意见，这两个人的反对让位同学立刻意识到，虽然进行协同工作从长期看对大家都有好处，但部门经理在这种合作中的受益是不确定的，也是不确定的，何况还有其它不确定的因素，特别是有可能会损害到本部门业绩的事情，谁都愿意先出手。

我的这位学生说，在公司的级别上和这些业务经理是相同的，所以，他没有权利要求所有部门经理一致要配合他完成这个倡议。在这种情况下，他分别一对一了每个部门经理的利益和立场，然后决定挑两个在这个跨部门协作中受益最多的部分经理进行一个对话，在这次交谈中，他分别给两个部门经理写了一封邮件，详细地说明了开展这件事可以给各部分带来的好处，这些好处都是显性的，其中一个受益最多的部分的效率可以显著提升50%。

我后来问这位同学，他既然那么胸有成竹，当初为什么没有要求上一级主管强力推行这套做法呢？他说，下一级经理的权威下进行协同是它的，最希望使用上级经理的强力来进行他人的对自己的。最好先将来引导别人为什么不会去支持，要先引导别人不支持，道到真在里，哪里去考虑自己的想法，完能到别人的角度去思考自己的想法，突破别人的角度去思考自己的想法，对对方切实感受到这种好处。

我这位学生说，他坚信：同级之间的经理人，如果你一直认为你不同不是一个自己的人，对于支持的部门领导，如果是整别人着看的，他们就会愿意配合你改流程。结果，即使将来到他的部门大家都愿意配合。果然，当到部门一起参与了这个流程改造工作之后，这家企业的置效率有了明显提高，两个部门之间开始推所有部门都加入这个协同计划，由于推到了最先参与的部门得到了好处。所以，其它部门经理都没有再说他了。
