# 1.学习型组织

学者们当然知道文化对于企业经营业绩的重要性。所以，在管理学中，很多学者在提倡企业要通过建立学习型组织的思路，利用学习型的文化，不断改善自己，要投入创新劲，不断挑战，保持灵敏性和主动性的价值观要注入到知识灵里面去。甚至，学生们还提出要业绩考核和激励体系来支持这种文化建设。

![](bbox=[0.2, 0.45, 0.8, 0.55])

在这个领域中，最著名的一本书叫《第五项修炼》，作者是麻省理工学院的教授彼得·圣吉，这本书，彼得·圣吉进入了大师的行列。在他看来，企业必须要通过不断的练习，求生存，变，不至于丧失竞争优势，被市场淘汰。他主张，任何组织的领导者必须要有组织中建立一个持续学习的组织修炼，圣吉说，要经历五项修炼。这五项修炼依次如下：

+   1.  第一项修炼是“自我超越”，是指要不挑战极限，突破现状，超越自己；
2.  第二项修炼就是“改善心智模式”，因为每个人的心智模式都是心路历程，经历过，但各自有着背的反映，所以，容易固执地看待事物，就可能要接受新鲜事物，达到学习的目的；
3.  第三项修炼是要建立共同愿景。因为单只组织取得了共识，才有改变的可能，所以，需要能够给个人有建立共同愿景，之后才能接受别人的信念，在打开心智模式的基础上，实现组织的提升；
4.  第四项修炼是在前三项的基础上，通过讨论、读书会等形式，进行知识交流，组织群体智慧，最后实现组织认知和组织能力的提升；
5.  第五项修炼是组织的学习应该有“系统思考”的深度，可以让前面的思维修炼达到更高层的程度。

你知道吗？因为这个圣贤的理论，当然还有其他一些人的理论，企业组织从90年代就开始去员工学习的方式。你期末不结束，要去单位参加各种培训，其实某种意义上也是“沾了”圣贤的光。据估算，全世界每年企业用来培训员工的支出就有几千亿美元之巨。
