
# 038讲：创业领导力 | 你快乐，别人就会帮你

创业者展现领导力，记住三个词：未来、现场、吃饭。

- 未来：如果你开心，别人就愿意跟着你干。
- 现场：影响他人的，是你努力工作的背影。
- 吃饭：耐心倾听下属在饭桌上的声音。

# 039讲：女性领导力 | 身段柔软的力量

未来世界最善于发挥女性长处的组织，是有前途的组织。

雌雄同体：在处理同事关系这件事上保有女性的特性，但是，在决策行为上却表现出比男性还要强硬的刚毅感和坚定感。

# 040讲：中层领导力 | “画圆”的艺术

管理者的技能一共有三类：技术性能力、人际概念能力。

对于中层领导，横向的人际能力格外重要，而如果要继续进步的话，就要锻炼自己的概念性能力。

# 041讲：领导争锋 | 为什么合伙人制长久

按照经济学的基本法则，企业就是“资源集合”。所有参与企业的人，都提供了他们的资源，然后获得相应的回报，这就是企业的本质。

你一定想知道什么时候资源的互补性就消失了，而消失的那一刻，就是股东关系失去基础的时刻。

# 042讲：领导权配置 | 一个人说了算好不好？

企业做任何事情都有一个责任人，盈亏需要他最后负责，既然是他负责人，也一定要由他一个人能说了算。

做稳定发展时期的领导者，要学会坚定地公布目标，然后带领大家向前走。而做变动时期的领导者，要善于动员大家讲话，自己少讲话。

# 043讲：谋划力 | 真正的舞台在后面

# 模块3: 团队

# 046讲：任务、锦标 | 我们为什么需要团队？

团队最重要的特征，就是成员之间存在互动创造的协同效应。

有人认为团队的目标就是建立大家庭似的兄弟组织。错了，我们的目的就是合伙来赚钱。

# 059讲：建设性冲突 | 人人都用得上的管理工具

冲突是一把双刃剑。

领导者必须要在团队的合作和相互沟通中，刺激团队保有一定程度的“建设性冲突”。可以用管理工具：选项归纳表格，处理冲突。

# 060讲：搭便车 | 团队建设的大难事

集体行动的困境：除非存在着强制或者其他手段，当人数越多的时候，每个寻求自我利益的人越不愿意采取行动去追求共同利益，或者团体利益。

避免搭便车现象：尽可能地减小评估范围，尽可能建立起一个团队成员个人努力、业绩和收益之间的对应关系。

# 061讲：公司政治 | 争夺资源控制权

公司政治：通过非正式权力来影响公司决策的行为、过程和结果。

公司政治的危害：出现派系和非正式组织。

# 062讲：派系的逻辑 | 斗争与制衡

派系产生的原因：高层力量的斗争与制衡。

派系的力量，在绝大多数时候，就是一种负向的隐权力，它会直接削弱公司的正式权力体系，以达到权力的平衡。

# 063讲：晋升通道 | 良禽择木“爬梯”

领导的最高境界，是努力通过自己的价值观和行为来引导组织，用正式权力和正向的隐权力去抵制和对冲掉负向的隐权力。

# 064讲：道德领导 | 正大光明的力量

什么是决定领导者权力运作水平的关键因素，我觉得是价值观，是领导者的道德水平。

单靠权谋和手段，领导者是走不远的，团队更不会长久，应该相信“正大光明”的力量。

在今天这个信息时代，快速学习的能力，或者叫“学习力”，是下属力的重要内容。

“学习力”的逻辑：问题性学习、针对性学习，核心是快速学习。

# 069讲: 业绩导向 | 让自己立住的数据指标

LEAD模型：想、听、分析、做。

可以用管理工具：提议思考表格，辅助决策。

# 072讲：专有信息 | 什么岗位最有利于你发展

# 073讲：有效授权 | 从放手到放心

用管理工具：工作规划表格，对下属进行有效授权。

# 074讲：LMX理论 | 领导者的人际交换奥秘

中国企业的领导者必须学会双线管理：一方面要有制度，另外一方面中心还要有人，以及人和人之间的关系。

### 1. 减少会议

![](img/3148dc16965f9a57e897fce984cfd348_92_1.png)

我们今天要讲的第一家公司：亚马逊。

亚马逊的创始人，叫贝佐斯，听见顾客一观念，就是他特别不愿意看到顾客主动联系公司。他说：一旦有顾客来找了公司，那就是意味着，你的产品和服务一定有什么问题。仔细想一想，想起这些服务公司，我们从一家公司购买以后产品，最好的结果就是一拍两散，买好它也不会是这个产品和你发生什么联系。如果我们想要联系这家公司，有两种情况，最好的情况是因为我买了这个东西，买其它东西；还有一种，是会比较常见的一种，就是产品出现了问题。联系得频率，可以来统计说明问题，公司说明你所没有产品有问题。

贝佐斯的这个观念很怪，难怪他在思考问题的角度上，但看问题的思路一点也不公司。老早来，贝佐斯觉得顾客太打公司来，说明公司的流程一定有问的。贝佐斯想，公司的会议多，会议时间长，意味着需要大家讨论的事情更多，公司里的小问题就更多。所以，以如何在如何上好会上大大提高文章，比如把会议保持往极低程度。按照他的管理理念，把会议作为公司管理水平的标准，通过减少来调整，组织运作效率越高。这是一种很值得关注的理念。

亚马逊的会议时间是少的。所有的会议都按照规范来走。什么规范呢？就是任何人都不要发表议论，先能写讲话的PPT的，而要用讲述的文件把要讨论的问题搞清楚。第二，还要自己先提出来问题支持，比如数据、图表和分析等详细资料，并交给开会的人，会前要先读这些资料，按照公司标准每页的6页纸，提前写好，五分钟，发给开会的人。然后在全员的时候，开始计时，开会，主持人时间朗读这页PPT的内容，之后才是讨论环节。

坦率地说，对于贝佐斯的这一套会议理念，我并不是特别，也非常喜欢，的，存本质是一个群体沟通人群。存在着某个交换，平时很忙碌的，在要事时点人聚在一起，商量一些大家都很关心的事项，这是开会。但开会是人群的交互，交换。这种交互，既包括信息的交换、交互，知识的交换，也包括情感的交换、利益交互。由于交互主体比较多，交互极其复杂，所以，从事情上说，把会议开好，是非常不容易的。可以说，一定要在组织的框架里，淡化会议的功能。当然，这是一种，我对供需观念和做法的个人理解，不一定对，供你参考。

最近，有一本书又开始引起人们的注意，那就是那本为了有效决策而写的《罗伯特议事规则》，有这本书可以稍微谈一下这本书。这本书的背景就是觉得大家开会总是不能有数决策，于是研究了各种场景，寻找每一种情形下的有效表决方法。但读了这本书，如果你真以为可以找到某个开会套路，然后议事效率的问题就迎刃而解，那你就把问题思考简单了。所以，对于多数普通公司，我建议你要做的第一件事，就是努力把会议数量减下来。

我自己非常擅长的一个管理小领域，叫公司治理，其中很重要的内容就是股东怎么开会，董事会怎么召开。我自己也参加了很多股东会，很多董事会。我这么多年来参加了无数次，这么多的会议之后，我的一个很重要的感受就是真理常常是在少数人手里，所以，一定要不要依靠会议、依靠群体来决策。当然，这是个人观点。

家公司里，哪怕是只开一个电话会议，都会有一个跟进的备忘录。

这家公司备忘录的写法我也和你分享一下，主要包括四个部分：

1. 会议的总结和结论；
2. 进一步需要讨论的问题；
3. 谁来承担什么责任，包括启动下次会议；
4. 下一步的努力方向和目标。

上次，我和这个公司的老板吃饭，他的办公室主任在饭桌上向我罗列了会议低效的几个标志。请注意，是办公室主任。这说明了老板的会议主张已经深入到下属之中。在这个公司，如果开会出现如下情况，一般被认为是会议组织有问题。

- 第一，主持人问：谁先说一说啊。这说明会议计划不好。
- 第二，主持人说：请注意发言时间，再给你五分钟。这说明发言者缺少准备。
- 第三：主持人不停地解释自己：比如不断说“我刚才说的情况，其实是一一”，这是事先准备不够。
- 第四，有人说“关于这件事，我们已经讨论过很多次了”。
- 第五，就是会议一结束，有人说：总算结束了。最后一项，被认为是灾难性的。

1. 用会议衡量管理的组织水平。不同的权力结构，不同的领导模式，相应地就有着不同的会议形式。然而，在不同的会议形式中，只有在效率最高而成本最低的形式，会议质量是组织管理水平的一个体现。提高会议效率的关键，在于领导者的认识。
2. 从文化建设角度看待会议。改变会议质量的方法，关键是要形成会议规则和会议文化，比如规范提案形式，比如，会议记录是组织的有效，是会议是否达到了目的，实际上是组织文化的一个反映。
3. 建立有效的开会模板。在一个组织中，往往在不同的层级，不同的工作场景，所以，会议不可能千篇一律，但好的组织，一定要有高效会议的模板，包括召开不同类型会议的模板和最佳做法的分享体系。
4. 不召开没有准备的会议。会议是一种群体沟通的形式，不存在着组织起个、流程之外的状态。应该像飞亚达组织一样，将待会议的议题、召集人、时间、形式、人员，明确召集人、人员，并预判会议难度与日程，然后，由此来确定议程，会前作出积极准备。
5. 明确区分务实会务虚会。务实就是务实事，务虚就是务虚虚的会子。每个会议都应该有一个清晰的议程，要明确是否需某个议案先于议事中作审议，不需要事先决定，就应该是务虚的；务虚的内容控制相关程度，不能将来务实的内容，不适合会议讨论，一般不会作为务虚会的内容。
6. 建立会议的两个责任人。召开务实会，就是对一个作出明确的责任人。决定之前要有对于务实会决策负责的责任人，决议之后要有高效率会议决策的人责任，通过明确的意志和责任进行计划来反映会议决议。明确两个责任人，是对会议结果落地的体系保证。
7. 用奖来提高会议效率。会议的目标，最后一定要实现目标，而是一个结果一致的和绝对的长远目标。年度目标是一致的，应该根据结果来实现相适的考核。只有当企业，基本都业绩评价考核度较高的企业。
8. 恰当安排会议的具体部分和虚拟部分。随着组织规模扩大和移动互联网等技术，组织结构、成员之间的界限方式已经多元化，所以，工作联系和联系的方式已经为实体联系取代和虚拟联系方式，会议，作为具体接触的方式，也对会议大盘做大的部分，不过，究竟是谁，微信或者其他工具，都应该扬长避短、有地加以使用。

宁老师觉得三星的开会原则简明清晰，是因这些原则看起来不难理解，而且聚焦多人沟通的本质，但实际情况并非复简，我能理解到这些学习手机前的总结部分。首先是一个企业的开会风格是否自下而上，取决于老大的开会需求和表达风格。如果老大过于漫不经心，习惯发表意见，甚至情绪化，会议流程很难管理，这很多企业不是一通；而是沟通传达出现信息不对称，何况多人沟通，很多时候召集会议的人也不清楚信息流程和决策目标聚焦到过程中，还是就是会议决策目标聚焦到过程中发生，开始讨论时就变成别的问题了。我觉得组织中会议效率低本质是企业的一把手的起点，一把手指是信息的汇聚点和流出起点，他直接决定了信息的传导分享模式和利用效率。

**来信：南罗刚**

用“填充法”组织会议，分享一个“私货”，是当兵的时候学到的。那时候工作基本不允许出错，那时候带班，几乎天天开会，领导的工作计划是简单，会开得非高累，搞得我每天都要睡觉。怎么办？被批了以后，我学会了一套表格管理工具。一开始是，先开会，包括老师后面思考中要求的详细提纲，一共有两页，左边是会议写的内容，右边的项目、会前、会后、会议记录内容，右边的项目根据工作实际简情况订，我做了标准模板，事前写好，下面留了空白和备用，打开来会先开会写了会议目的、会、主题，开在一个表子。项目管理难度，时间、地点、主持人、与会者、应到及到者及原因、议题、决议、待落实事项、负责人、时间节点、跟进汇报等。需要会议的决议，还是会议记录，而是会议纪要的封面，这里不需要写发言记录，只要把记录记录结果，主要是安排会议的。会议记录要求要求另出一个表格而已，用表格管理工作，做到管理简洁，可以避免遗忘。学习到的，疑惑的问题简化，这是学到的知识、理论落地的一个好办法，推荐给大家。
