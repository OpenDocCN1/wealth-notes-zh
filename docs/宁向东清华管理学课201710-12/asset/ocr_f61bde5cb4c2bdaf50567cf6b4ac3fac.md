# 本周内容复盘 | 谈判清单

又到了每两周做下周有关谈判的内容进行复盘。

在复盘之前，我先说一件既有重点重要，也不是太重要的事。为什么要说这件事？因为最近一直有同学给我留言，鼓励我不要气馁，我都在下面写下数字，我我们的专栏阅读量真不高，还有我在清华教授过的几位学生，还有几位同学还发我私信鼓励我，安慰我。

我和你讲，能给老师发私信鼓励老师，这是需要勇气的。我衷心地感谢同学们，但是，虽然我为此非常骄傲，我还是建议你，后在职场上做这种事情要慎之又慎。有时候，你真心为了领导好，但一旦把话说出来，领导心里某种意上将你视为什么都刚强住你的事上面了。所以，这是一种有刀有剑，是帮衬，你一定要把握好；但如果你的领导不可能会把你的心，如果他是，如果你不能碰上水上治我的一代领导文人化，你就有可能“好心不得好报”。

今天，我们可以告诉大家，请大家放心下来。我们专门的打开率一直不错。具体数字我就不说了，反正相当不错。大部分所看到我的数字，只是打开数字做简单阅读，文章阅读的字数字。不怎看文稿的人，后者是一个大头。如果我们两种人都在一块，数字更是准不错的。这一点，向大家报告，也是请大家放心。其实，我开始看到这个数字也有点不安，因为最近有谈设计上的原因，领导“得于”，要求这么一个指标去决定，免得像新用户，其实，我觉得无所谓。因为我自己，判断力和主见，是决定一个人能否成功的关键。

下面，我们复盘两周的内容，也是我总结的“谈判十原则”：

+   1. 谈成败的前提，是要关注对方的需求，对方方案，这是所有的谈判最能决定的，在这个谈判过程中，最主要的就是你自己，最要的就是人，所以，要尽力一切，去发掘、分析、判断对方的核心诉求和延展要求，然后，推断出对方需求的交易范围。

+   2. 谈判，是努力创造信息的不对称，在知道对手的信息越多的前提下，尽量不让自己对了解到更多的真实信息，要要学会对对手，有选择性地披露。

+   3. 要有底线思维来设计交易结构。要审时度势，不断地判断用自己的什么东西去换对方交换，才能满足对方的核心诉求，以及延展需求。同时，这个交换也可以满足自己的核心需求。

+   4. 要有一个变通的观念，谈判对象从来都是一个组合，而并不一个简单不变的单一选项，我们在谈判中，容易发现自己的想象力，创造性地指出交易方案。

+   5. 要明确谈判在多大程度上靠力量，多大程度上靠智慧，这是情境。面对人际矛盾和利益冲突，解决问题的，这种方式完全不一样，不能盲目用组。讲道理，是弱转谈判，要思考对方的要求，要让对方能够感受到你希望他们感受的事情，触动对方的心理支点。

+   6. 要善于在谈判中找到一个切入点和支点。切入点，最能打动对手，让他坐上谈判的东西；支点是指该自己诉求的或求成，让自己稳坐在谈判桌上的东西。切入点不能引导，没有支点不稳的谈判，缺乏可能的力量，无法持久。

+   7. 谈判一定要遵循先顺序渐进的逻辑，逐步深入。谈判的目的，当然是为了追求最后的最大收益。但一时没有达到预期目标，也并不能全盘计划有效。要全面在于过程的及时调控应对策略，更要仔细地已经及后续目标，寻求对双方有利的目标和方案，或者为了后面可能的谈判，留下伏笔和机会。

+   8. 要发现和利用人性的优点，正面的，或者负的，既能是甜头，激励对方，让对方愿意应对与交易效用，有获得感。同时，也能够在对手，并使用欺骗和威慑等负方法，力劝导反对目标。平时就留意积累一些使用的手段和平台。

+   9. 谈判很容易陷入僵局。有些僵局是很好打破的，但另外一些僵局，可以是打破的。所以，要留出足够的空间，要预作设想，安排好打破僵局的途径。

10. 谈判的韧性，要耐得住性子，就是“心理战”。不能急躁，不能冒进，不能一步到位，很多时候要学会“磨”和“拖”，要张弛有度，紧一下，松一下，有时动，不动也软磨硬泡，下一次谈判，在有限的空间，不同的点位中，就意味机会一次的谈判，不到进情时，就可以利用你的优势。

所以，在谈判局面的时候，要能够想到改变情境。

最后，提一条课上没讲的内容，仅供参考。君子爱财，取之有道。谈判要求较多的收益，只是人的天性，但某笔时候，其他也是人性的底线。谈判的对象比你更多需要的是金钱，你做的必要会杀死你的事，能不多最好可以。市侩是冷酷的，但人性是有温度的。举个例子，在机场的用100元一斤的水果，我觉得多余来杀价格；但是，对于边远老实多交的摊块摊农，只要是不要过分讨价还，多交一块，一块钱，好像不用过斤斤计较。
