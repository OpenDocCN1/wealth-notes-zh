# 1.三种会议

我们每个人平时都开了很多的会，但如果你把这些会，按照某些特点稍微总结一下，我愿意把各种会议大致分成三种。我的分类是按照会议召开方式的不同，以及信息传递和交互的途径来分的。

第一种会议，是自上而下启动的，启动者是组织的领导层，信息是从上向下传递的。上级的决策已经作出了，下级会议之所以要听命，就是需要下级上级的横向信息流动，和从下向上的信息反馈，根本不需要。这一类会议，比如部门例会、动员会等都属于这一类，甚至公司培训也会可以被列入这个类型之中。

第二种会议，是由上级启动的，但是，会议的目的是为了共同决策，或者是寻求正确信息的必要环节。启动者是上级，但是会议没有权威，而是横向的会议。这种会议的目的，就是取得信息的流动，或者取得意见的交流。这种会议的效率，主要取决于参与者对信息的了解和态度。

第三种会议，在目的和方式上与前两种类似，但属于同级启动，没有一个权威，所以，要在解决问题，就是共同协调信息和利益。这种会议的目的，就是取得信息的流动，或者取得意见的交流。这种会议的效率，主要取决于参与者对信息的了解和态度。

# 2.互联网对第一类会议的改善

那么，互联网技术在如何帮助我们提高会议的效率呢？

首先，我觉得有了互联网，就应该大幅度减少第一种会议。因为第一种会议的信息是单向传递的，过去没有互联网，大家只能通过开会来过去。后来有了摄像、电话和视讯会议系统，就有了主会场和分会场，直到现在，还有单位采用这种主会场和分会场的会议形式。我觉得，这种局面应该彻底改变。

为什么呢？

因为第一种会议，是以领导为本位来组织的，强调的是以领导的意志为准备，以领导的话话痛快为准。既忽视参会者的时间和感受，也没有考虑过信息的传递效率。其实，采用一些更简易的会议方式，很多时候可以取代线下的会议，效果并不是很不同。因为每个人接受信息的最佳方式是不同的。

比如我就有一个比较适合按照自己的节奏来学习东西，来思考问题的方式。这也是为什么上次直播的时候，我说过自己很难做到很投入，因为我在听别人讲话的时候，常常会分神，不是我的专注力，是我有在别的地方看东西，真的我效率很高。我不喜欢看一个长时间的演讲，让我来听你讲，我可以自己看着文字，然后自己思考，这样我的效率就会非常高。只要你愿意，你只需要给我文字，我就能把信息提取出来，并且按自己的节奏进行理解。

我不知发现，在这几年，在一些非常非常传统的公司里，单向传递信息的会议已经逐渐被很多了。不少领导要么把信息通过文字、讲话、小视频或备忘录等方式，来实现去会、开会。现场所要表达的目标，我们的信息传递常常互相发送给某某某的一个讲话，其实那并不是公共场，而是就是一个人发给大家的文字。过去几个人的讲话，那要完全去见几百人，十几万人的讲话，那要一定得用上一天的时间，大家什么都不知道，那种主会场加分会场的全面体会。但现在，同样的会议形式会跟互联网结合，把同样的信息，用更有效率的方式传递出来。

在未来，我想这方面的变化会更大。文字、音视频和新的方式会更多的更简便的被用来取代第一类会议。它正在是领导的单向传达，采用更加灵活的方式，一是可以大幅减少决策、表达和重复，二是可以让人反复学习、反复听，起到反复强化的作用，三是可以针对每一个接受者自己的特点，接收这些信息的，所以，我向我的领导问，如果我信息需要改善，再重新传递信息的会议效率，那你就学会有效的利用音频、视频和文字方式。从我做这门课的经验看，转变还是不是一点半点的。

# 3.互联网对第二、三类会议的改善

以上，我们讲了互联网怎么样改变第一种会议的形式。接下来，我讲互联网对于第二种和第三种会议形式改变，因为这是最重要的改变。

举个例子，日本乐天公司，是日本最大的网络公司，它老板三木谷浩史曾经要求公司，以“十倍速”的方式来组织部门运作，什么叫做十倍速就是做两倍的运营，试提高十倍的速度。那么，原来开两个小时会议，就会在一刻钟之内解决掉。如何让会议？就要从整套会议的模式切入，通过改变会议的程序，达到加快速度的目的。

我们知道，几乎所有的会议，都是从介绍情况开始的。如果你稍加留意，很多会议的第一步就是要明白情况，有人会说这个环节常常占会议的时，所以这个介绍环节，那些对情况非常熟悉的人，就希望跳过这个环节，不熟悉的人，又希望会议能讲多一些介绍，把事情的来龙去脉搞清楚。在这种情况下，对于很多情况都熟悉的人，就要被迫听一遍，有人甚至还会听第二遍、第三遍，这是浪费资源。

乐天为了实现十倍速的目标，至少提前一天把会议要讨论、商议和决策的内容，以书面的形式提前发给所有的参会人员，这样就让参会人员在会前充分了解沟通，了解情况，而到了开会的时候，就不需要太长时间交流信息的背景，而是直接讨论解决方案。这样，虽然，每开一次会议，都会比传统的会议快得多。但是，通过书面材料更容易帮助发言者清晰地表达自己的理解，有助于其他人员关注阅读时形成共识的障碍，也因为书面文字比言语表达更难被遗漏，使得意见更完整。比如，通过邮件的讨论方式，很容易
