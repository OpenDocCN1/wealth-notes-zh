# 1. 组织架构

组织是专业化和分工的产物。任何组织的存在都是为了追求一个特定的目标，而要达到这个目标，需要一系列的行动，也就是一系列的工作任务。把相似的工作、相似的任务放在一起，就是岗位。还记得我早的“把专业装杯子”的比喻吗？杯子的大小，有专业化分工的分工原则。也正基于此，绝大多数的组织，都是从职能型组织开始的。

职能型的组织强调专业分化，这种分化就会一推起来，壁垒就形成了，互相关系就不断被人割裂，如果业绩考核等因素再设置下去，互相关系就要听外来强问题就会越来越复杂，这时就需要外部强横部门的合作与协同。我们看到很多组织里，领导不停地下令改变团队的协作关系，不断强调集体主义，大约就是因为这样的因素。

但是，我请记住，光靠领导强调，在很多时候是没有任何的。必须看到组织问题，没有一种组织结构去进行组织的问题。为什么叫“协作问题”？就是因为只要采用这种组织形式，那就一定是复杂分利影响你，你想去，除非改变组织结构，否则不容易。就是所谓的“屁股难摘脑袋”。比如，在这节课中的一些部门不谦事扩大，就是一个例子。领导讲一千遍，不如建立事业部迈进一步。

所以，你要建立起“管理轴线”上去看问题的能力，要学习结构，矩阵式组织，乃至我们课中没有介绍的混合式组织等其他组织形式，背后反映的都是管理轴线的内容。管理轴线，是这个模块的最重要的概念。企业在不同的发展时期，能够明确哪些管理轴线最核心的管理轴线时，这件事非常重；也是组织结构调整背后的关键支点。与管理轴线相关联的一些概念，包括管理幅度、管理层级、报告关系（一岗二主），希望你也要时刻记得。

在这个模块当中，虽然我们没有怎么强调“权益”的概念，但你请记得，组织结构的设计和演变，是非常讲究权益思维的。比如，我在课堂中讲到波士顿的边界理论，本意是组织的演进问题，它是受企业的文化相关的，不同的文化环境会导致既不同的，再到，我讲到资源竞争的时候，它也需要考虑组织的，什么流动流动重组，怎样进行思维，进入什么，这些都是需要权益管理的。

总之，任何企业在特定的时间点上，选择了某种组织结构，其实是一种权衡的结果。比如，我们讨论的科利弗斯（ColyFrees），就是一种权益的结果。在利弗的组织结构中，有专业分工和部门内协同的平衡，也有部门分工和组织资源保证的平衡，其中涉及到了很多的平衡关系。这些平衡关系，是理解和熟悉各种组织结构的关键。

# 2. 案例：戈尔公司

底下是一张关于戈尔（Gore-Tex）公司的组织结构示意图。这家公司创立于1958年的美国肯塔基州，非常著名，为了保证组织弹性和灵活性，也为了让促进组织内的协同成员，这家公司采用了扁平矩阵结构。组织成员之间的关系，是不等级级的垂直管理与被管理关系，而是，每个人处于一张网状结构的节点上，大家就是合作的伙伴，所有成员是相互依赖的，不同的每个人的工作职责不同。

![](bbox=[0.1, 0.25, 0.85, 0.38])

戈尔公司之所以保持这样的一个组织结构，是因为公司内部的息息流动能够更加通畅，以便避免在层级组织中，那种一旦信息在某个部位就无人再沟通传递的毛病。戈尔公司的业务领导人的产生过程也是很有趣的，谁提出了生态营销，得到大家支持的，谁就可以成为一个业务部门的领导。这一点，和我们前面讲过的印度的HCL公司、利丰集团的模式，有异曲同工之妙。

也许你注意到，我在讲组织这一块，举的例子都是比较特殊的例子。没错，这是我有意设计的。找一本组织方面的教科书，里面会有很多标准化程度很高的组织结构。你可以在很容易找到同行业的类似结构。但就像容易找到一个糟糕的印象，组织框架就那么一样，好好像有标准的模式，或者说一个规范的模板。而我举的打的是你以前见过的印象。

我多年有一个体会，不一定对，和你分享。我一直觉得，商业世界，没有标准化的东西，一当什么东西标准化了，就意味着大家都有一样的，于是，你的竞争优势也就流失了。所以，在商业世界里，我觉着差异永远要比标准化、规范化重要。只有差异化被认可，才真正有价值。我在这个模块举了很多例子，都强调组织形式的差异化。你，我觉得，你读企业调研报告里那些有特点的公司，收获的可能远比研究身边那些比较多见的组织结构更大。

总之，仔细拆解这些特殊组织结构的一些细节，琢磨它的细节，你会发现结构当中不平凡的逻辑。很多时候，一个组织限于限制某些因素的作用，欲救另外一些因素的影响，它有很多非常独特的商业计划，然后衍生出非常重要的商业逻辑。这些商业逻辑，也许没有办法描述，但是可以被认知，一旦你学会了借鉴了，你的管理功力就增加了。

# 3. 战略决定结构

其实，组织变革无论是协调，还是大调整，都依赖于对于“专业化”和“协同”之间做好平衡效果。好的组织结构，就是为专业化的协同，找到一个载体。

下面有一张图，是关于优衣库的业务流程和组织视角的定位置，我建议你把课后好研究一下这个定位图，这是联系企业战略和组织架构之间的一座桥梁。有了这个桥梁，组织结构的设计和协调就有了一个基准。

![](bbox=[0.1, 0.93, 0.85, 0.97])

优衣库，是日本的第一服装品牌，现在在中国也有了上百家店面。这家公司的特点是卖价格低廉，但是服装的质量却可以休面服。优衣库之所以能够长期获取利润，就是因为在其相对独特的商业逻辑的基础上，建立了一个相当稳定的组织架构，并且通过一个组织结构来实现。文章中的图，就是从这里特别需要强调组织形式，一个承上启下的桥梁，这张图示是很重要的一个图示，今天的课后请你就结合对优衣库的了解，研究一下这张图示。
