# 1.固定成本与变动成本

今天，我们就挑最重要的一个比例：固定成本和变动成本之间的比例，来做个讨论。

通俗地说，固定成本本就不随产量的多少而发生变化的成本，比如厂房、机器设备，都要用到它。固定成本固定一次投进去，需要较长的时间才能慢慢收回来。而且，不管盈亏与否，固定成本一旦投下去，总是有一个时间段的，你是没有办法变动的。变动成本则不然，它随着产出的水平而发生变化。比如原材料，人工，大多属于变动成本。变动成本可以根据情况及时调整，产品滞销，如果企业能够马上停产，就可以让变动成本为零。

以上说的，是固定成本和变动成本的概念。下面，我们说说固定成本和变动成本之间的比例关系，这个比例关系的含义是很深刻的。你看，政府办那些大中小学，就重金全银投进去建大校舍，这些大建筑就是固定资产，形成的是固定成本。所以，清华大学办学，是以大作为主导，它的固定成本是成的大比例，是固定成本占大。这是理想的话说，就是走“重资产”的路线。所以，清华北大要想好，那成本是非常大的。

与清华北大类似的，还有一些民办机构，它也叫MBA、EMBA，也很有名。但它最开始的时期，都没有投资建多大的学校，就是租写字楼。它的费用就不仅是EMBA的价格比清华的EMBA还贵。这是没有投资，但学校和教室，都没有，随时可以关门走人。它的成本主要就是教师资源，它把钱全部用在聘专家来讲，少去租写字方面，有些学校主要师资招来比较稳定了，才去考虑建自己的教学楼。所以，这些学校走的就是“轻资产”的路线。

重资产和轻资产哪一个好？很难讲，要看从长远来说，企业准备采用什么样的策略。本节课的副标题是：“其实顺丰最可怕”，反我的个人一种认识。我们都知道，在中国发展最快的物流行业里面，与有名的“三通一达”相比，顺丰采用的是重资产模式，它的货运也有自己飞机的，2016年为止，它的飞机就有40多架飞机。虽然它的资产收益率不算很高，只有不到2%，但是，在这样的投资水平下，还可以保持利润为正，就非常厉害。

![](bbox=[0.2, 0.63, 0.8, 0.71])

我非常尊敬顺丰这家公司，很重要的原因，就是它这个企业的重资产模式，有很多固定资产的企业，一般都会给客户以很高的安全感。就像清华北大一样，有一个很厚重，特别有历史感企业文化，有的校，你怎么看看比在商区租个写字楼办公的机构，显得更加靠谱。

顺丰的重资产模式，经常让我想起100年前的美国企业卡内基公司。卡内基对于成本的经理几乎到了偏执的程度。卡内基的竞争策略非常简单，就是大低规模、高技术标准，追求别人很难的成本。卡内基地巧妙地调整固定成本和变动成本的结构，用固定成本换规模，用低规模效应来成本在不断降低，这样，在市场方好的时候，卡内基价格比高，把产能打足；而市场手感一般气的时候，卡内基地价格低到对手手底不起的时候，别人已经赔钱，而卡内基却还有得赚。

所以，我总觉得：只要顺丰这几年能够稳健经营，不出的战略问题，后面一定会一个很令人感到恐惧的公司，因为当很多物流公司在靠快兔小灵打天下的时候，它已经很好的在陆海空协同作战的状态下，获得了很大24小时服务，而且这一切却是在资产收益率不错之情况下取得的，这就非常有价值。

# 2.案例：24小时超市的背后

好，通过固定资本和变动资本的对，我们可以对成本结构的认还是不比我以更深入一些？下面，我们再来讨论一个案例，希望再带你深入到。这个案例的核心的点是你曾经人认知，在许多情况中，对变动成本进行更细致的分析非常重要。

清华大学旁边有一家不大不小的超市，九点钟打样。我们经常会想，为什么是九点钟打样，而不是晚一点。比如十点，或是十一点下班呢？为什么不能是隔壁的7-ELEVEN一个，二十四小时全年无休呢？即便不能整个都二十四小时服务，不是它的一个部分可以经营得更晚一些，甚至是24小时呢？
