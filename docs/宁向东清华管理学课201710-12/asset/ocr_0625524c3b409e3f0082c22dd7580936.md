# 十万份责任！高效会议的八原则

周四夜里，这门课的学员数超过了10万。这对于我，主编辑部，以及广大的同学们，都是一件大事啊。从上一周开始，罗刚（主要是罗刚本人）和几个同学在学习小组“水产学院”里，开始接龙，期待着这一刻。很多同学都来给我留言，感谢这一刻。现在，目标实现了，放心吧，感谢大家。

五个月来，我们一起学习，已经结成了亦师亦友的关系。教师节期间，十一期间，大家在后台留下祝贺的话，在我思考的时候，在同学团反复关切和祝福。这个课堂，让我感受到清华那个实体课堂一样的温暖。作为老师，我只能回报给大家更好的课程。

趁着这个点，我做两个通知：

第一，后面八个模块的课程设计，结构上不会变，但前后顺序和内容我会做一些微调。微调的依据，是打开、阅读、收藏、等数据，和留言中体现出大家的不同的需求。有了这些微调，一方面，大家会得到更多的干货；另一方面，对于同学，也可以随时进来到，随时可以从旧的那个周一开始，就可以跟上老同学。

下面，我对本周的内容作个复盘。我希望能通过这一周的课，提升同学们对会议的认识。

![](bbox=[0.05, 0.41, 0.95, 0.48])

+   1. 用会议衡量管理的组织水平。不同的权力结构，不同的领导模式，相应地就有着不同的会议形式。然而，在不同的会议形式中，只有在效率最高而成本最低的形式，会议质量是组织管理水平的一个体现。提高会议效率的关键，在于领导者的认识。

+   2. 从文化建设角度看待会议。改变会议质量的方法，关键是要形成会议规则和会议文化，比如规范提案形式，比如，会议记录是组织的有效，是会议是否达到了目的，实际上是组织文化的一个反映。

+   3. 建立有效的开会模板。在一个组织中，往往在不同的层级，不同的工作场景，所以，会议不可能千篇一律，但好的组织，一定要有高效会议的模板，包括召开不同类型会议的模板和最佳做法的分享体系。

+   4. 不召开没有准备的会议。会议是一种群体沟通的形式，不存在着组织起个、流程之外的状态。应该像飞亚达组织一样，将待会议的议题、召集人、时间、形式、人员，明确召集人、人员，并预判会议难度与日程，然后，由此来确定议程，会前作出积极准备。

+   5. 明确区分务实会务虚会。务实就是务实事，务虚就是务虚虚的会子。每个会议都应该有一个清晰的议程，要明确是否需某个议案先于议事中作审议，不需要事先决定，就应该是务虚的；务虚的内容控制相关程度，不能将来务实的内容，不适合会议讨论，一般不会作为务虚会的内容。

+   6. 建立会议的两个责任人。召开务实会，就是对一个作出明确的责任人。决定之前要有对于务实会决策负责的责任人，决议之后要有高效率会议决策的人责任，通过明确的意志和责任进行计划来反映会议决议。明确两个责任人，是对会议结果落地的体系保证。

+   7. 用奖来提高会议效率。会议的目标，最后一定要实现目标，而是一个结果一致的和绝对的长远目标。年度目标是一致的，应该根据结果来实现相适的考核。只有当企业，基本都业绩评价考核度较高的企业。

+   8. 恰当安排会议的具体部分和虚拟部分。随着组织规模扩大和移动互联网等技术，组织结构、成员之间的界限方式已经多元化，所以，工作联系和联系的方式已经为实体联系取代和虚拟联系方式，会议，作为具体接触的方式，也对会议大盘做大的部分，不过，究竟是谁，微信或者其他工具，都应该扬长避短、有地加以使用。

来信：南罗刚

用“填充法”组织会议，分享一个“私货”，是当兵的时候学到的。那时候工作基本不允许出错，那时候带班，几乎天天开会，领导的工作计划是简单，会开得非高累，搞得我每天都要睡觉。怎么办？被批了以后，我学会了一套表格管理工具。一开始是，先开会，包括老师后面思考中要求的详细提纲，一共有两页，左边是会议写的内容，右边的项目、会前、会后、会议记录内容，右边的项目根据工作实际简情况订，我做了标准模板，事前写好，下面留了空白和备用，打开来会先开会写了会议目的、会、主题，开在一个表子。项目管理难度，时间、地点、主持人、与会者、应到及到者及原因、议题、决议、待落实事项、负责人、时间节点、跟进汇报等。需要会议的决议，还是会议记录，而是会议纪要的封面，这里不需要写发言记录，只要把记录记录结果，主要是安排会议的。会议记录要求要求另出一个表格而已，用表格管理工作，做到管理简洁，可以避免遗忘。学习到的，疑惑的问题简化，这是学到的知识、理论落地的一个好办法，推荐给大家。
