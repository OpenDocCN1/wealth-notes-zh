# 1. 购买动机

消费者行为的一个极其重要的概念，叫做“购买动机”，因为一切的起始都是来自动机，一切的行动也必然起始于动机。很多时候，你看到消费者在购买一件衣服，但其实他并不是只买衣服本身，而是在购买衣服相关的故事，情境和心理收益。所以，好的厂商就懂得挖掘商品或品牌背后的消费者购买动机和需要，并围绕着这个动机和需要去添加手段。

我先给你讲一个我亲身经历的一个案例。大约十年前，我在做中国式管理课题研究的时候，访问了李宁公司。作为一个研究者，也是穿过宁衣服的用户，我曾经向李宁公司的高级管理人员提提到：李宁标的顺色和反色的故事。什么是顺色：顺色和品牌的Logo和服装的颜色接近，不醒目，而反色则要求跳脱出来，颜色、服装的颜色要非常非常大，要跳出来。显然，设计这种品牌宣传特别有帮助。李宁的大多数商品，都是按照顺色的思路设计的。

![](bbox=[0.1, 0.52, 0.9, 0.62])

消费者动机，有显性动机和隐性动机之分。对我个人来说，显性动机就是李宁产品的性价比非常好。李宁的服装品质并不比那些国际大牌差，但从价格却只有国际大牌的八分之一，所以，我们这代人更加注重实惠的感觉。买李宁的商品非常划算的。当然，李宁公司的知名度也不差，所以，产品销量也不错。我才知道有一年一位中间商还挣手获得了一块金牌，实际上的，就是李宁公司赞助运动家。只不过，因为运动会的赞助协议，所以只能隐姓埋名，让国外品牌露了几秒，所以我才买李宁公司的产品，我并不是原因要买李宁的产品了，因为性价比高。

但是，我的隐性动机却阻止了我的购买行为。隐性动机是消费者没有意识的或者不愿说出来的动机。第一，就是我的服装商标大多数都是反色的，太凸显。特别是休闲服装的户外运动装，穿起来，裤子上的一大块商标，穿起来太引人注意，总是感觉不够得体。当然还有一点，就是李宁品牌的价值，和那些国际大牌比起来，还是差点。那人，穿起来心理是有一点点的。所以，如果商标的颜色太跳，穿出去的范围总是受到限制。

所以，当时我特意带了两个品牌的裤子，建议你能参考借鉴。这两条裤子都是我平时上班穿的。一条是Nike的，它的Logo非常小，非常雅逸，在后标的裤子上；另外一条是Adidas的，商标印在一个大约一厘米的小标签上，缝在裤键里面。这条裤子上班可以穿，同时，如果偶尔有什么户外运动，也非常轻便。所以，我建议李宁公司也是提供能够满足拥有像我这类隐性动机客户的产品。

![](bbox=[0.1, 0.95, 0.9, 0.0010500000000000002])

记得当时我把话说得很重，后来几年又说过几次。为什么就为我觉得李宁公司的机会都是在2008年前后，我，我和几位公司领导人用了一个“时不得得”了几个字。为什么呢？因为台内的人在服装品牌中，对于品牌形象的认同人群逐渐就老了，如果不把这些人群带走，宁品牌就很容易混入第二代阵营，陷入消沉。“李宁”这两个字的优格就会逐渐消失。

我们可以试着验证一下。如果你是90后，“李宁”这两个字，对你来说，和安德这些品牌有什么区隔？前几天，我在我的课堂上，我曾经做过测试，在我的研究生命，实踪的影响几乎差没太大一些，因为学生们会马上联想到一位NBA巨星。但是，在我这一代人心中，“李宁”两个字却非常厚重。

为什么呢？因为中国人是在改革开放之后，才逐步国际体育大家庭的。中国人最先让自己展眉吐气的就是体育。比如乒乓球等少项目国球。1981年，罗马尼亚世界锦标赛，李宁一个人独得6枚金牌，非获得一枚亚军。1983年，对中国第一次参加奥运会，中国队获有15枚金牌，这是在发挥不太理想的情况下，独得三枚金牌。所以，2008年奥运会，由李宁来点火，他少发资料为中国的中国运动员总之一，李宁在我这一代人的心目中，分量是其它任何品牌无法比拟的。

如果李宁是有性价比的产品，我们这代人应该是买购买的，特别是户外休闲装产品。当我和李宁公司谈话这些话的时候，我的一位学生正在我的身上。今天，有影力户外服装会因公司也市场上已经很难影响力了。今天听我课的多半身上，说不了定有的就是这家公司的。但至少在我这里，他们的产品和李宁的产品由于他们的隐性买动机，就不可能到李宁，商家李宁产品公司今天能不能够满足我隐性动机的产品：裁剪过Logo，让产品的适用性更广，我依然会支持李宁。常说一句话，做品牌，很多时候，懂得藏比和裁剪，都是一种成熟和时尚。

# 2. 融入用户情境

那么，该如何发现消费者的动机呢？核心就是要融入客户的情境，要用于11的开始已经输入的话，是去客户不要用念着自已有什头么，是要去念客户购物篮子里面造了什么。下面，我从逻辑上帮你梳理了两个有助融入客户情境、了解客户需求的套路。

第一步，也是最重要的，就是调整好你的心态，培养你的观察能力和理解能力。我遇到过最好的销售人员都是说“自己为是”的销售，他们的一个共性：就是客户一进门，他们就把客户当做外来对象对待，好多公司设计师的状态，有时候会犯这个毛病。其实，客户说不定比你清楚。聪明的客户转好几家，到公司个行业的底细，说不定已经一清二楚。甚至，可能还会指出你的业绩目标还没有完成。于是，他可能会把价格看到。

端正了心态，第二步，就是要让客户对你产生信任，让对方减少对你的戒心，让对方觉得你可以帮他购物。我们有的销售人员，特别喜欢问叫姐，喜欢动不动就叫他们，你们。其实，我觉还还不如直接称呼别人给人一种亲切感的感觉。其实，让别人建立信任的唯一法子，就是让人说到他的专业。你可以需要现有商品能能能能也练习了。活不用太多，妙好妙点就是，也不要刻意强调商品的缺点。

其实，对于绝大多数的客户来说，他们在没有对你建立信任之前，是不会把自己的底牌亮弄开的。而客户没有说出来的话，才可能是最重要的话。而很多时候，让客户多的建立信任的点，就是告诉他你的某个产品的特点。所以，建立你的专业度，诚实的表达，是关键的第三步，我一个玩法。这个专业感和诚实，比如你开始用。
