# 1. 乔哈里窗

今天，我们要讲的核心内容，是由两位大学教授首先研究出来的。两个人的名字，一个叫 Joseph Luft，一个叫 Harry Ingham，是他们研究出来的理论，可以被画成今天文章里的这张表格。所以，他们的研究结果，也就是这张表格的名字，被称为“乔哈里窗”（Johari Window）。Johari 是他们两位名字的缩写。乔来自 Joseph，哈里来自 Harry。

那么，乔哈里窗是什么呢？可以简单地说，它实际上是一个包括四个框的表格。四个框，像个田字格，依次代表了沟通双方对某沟通事情不同的了解程度所形成的四种区域。

| | 自己知道 | 自己不知道 |
|---|---|---|
| 他人知道 | 共识（熟知） | 盲区 |
| 他人不知道 | 隐藏 | 未知 |

第一种情况，是双方对所沟通的事情都了解，双方有足够的共同信息。毫无疑问，在这种情况下，双方的沟通在信息流向上，是更容易取得一致的。这部分内容，乔哈里窗口称之为——共识。这里有一点修正，我其为“共识”，就是说，这这东西，双方都知道了。东西不仅，不仅一定共识啊，是指这个东亚双方都了解，大家认识，且大家对这个东西的认识，是一样的。共识很重要，因为共识是共知的基础。

第二种情况，是别人对即将沟通的事情了解更多，而自己了解较少，自己的认识处于落后的。在这种情况下，沟通是不利于自己的。这种情况，被乔哈里窗称为“盲点”。

第三种情况，就是自己知道的事情细节很多，但别人知道的情况较少，乔哈里窗这种情况叫作“隐藏”。在隐藏的较细下，一般令尔下会对他的沟通是试显与真实，会令对方需要。很多时候，一动谈话，一边遮掩，就需要很好的遮掩，要么有一个看法，演的东西就会出漏洞。一旦自己的演就露了，对方就会知道，是，你自已法就露了，让人家窥探真实自己。也许你说，这，这，这是不是那个“表演不通。你自己说，不是表演？我觉得不通，是不矛盾，取决于他这个是不是诚实。如果是你根本的是的，表演就不是一件好事。

第四种情况，就是双方都不知道的事情，与沟通相关的信息在沟通双方的意识和理解之外。乔哈里把这种情况称为“未知”。如果双方都对这大多数不了解，沟通就会很困难。我个自己最坏的那些除了专业，没有都好的接触对象，因为找不到一个大家能发表意见的话题团队学习时，这是大家时间好的，就是通过一个套路找到他的兴奋点，然后引导他滔滔不绝地谈他的兴趣。

总之，双方的共知的东西越多，共识越多，沟通的效果就会越好，而不知道的东西越多，双方的沟通的效果就会越差。要想达到良好的沟通效果，就要尽可能增加共知的东西，增加共识的比率。这像文章中所下的这个图示，要想达到好的交流效果，非要把共识的自我部分做不可。

| | 自己知道 | 自己不知道 |
|---|---|---|
| 他人知道 | 共识（熟知） | 盲区 |
| 他人不知道 | 隐藏 | 未知 |

# 2. 分享的意义：扩大共识

那么，该如何去增加共识的比率呢？今天，在讲技术之前，我想介绍一个观念：东西在有效沟通的背后，是一种开放世界的。共识，可以说，是一种境界。只有境界提高了，共识才会有提高，更可能在更大范围里与不同的人做有效沟通。

下面，我就分享一下自己的体会。担事地说，最开始得对“去做这份管理学习课”，是准备大范围的企业做过团队学习的，但是，由于“得到”的用户大部分就是C端用户，所以最后课程的线索是没有大批量调整了的，但是，我还没有放弃集体学习这个念头，于是，最后的一两个月，我尝试着和同学讨论如何更有效地促进分享。

也许你觉得宁老师是希望增加新用户。“得”平台和我们的多挣钱，并不是这样。我分享是学习分享，是花多分享钱的。我希望大学分享，是希望不可以课进成员共知的范围，促进沟通，让管理理念可以在更多的企业里生根，有更广泛的群众基础。
