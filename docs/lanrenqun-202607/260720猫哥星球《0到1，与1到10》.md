


# **0到1，与1到10**

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

这几天邹市明夫妻几年亏掉2个亿的话题很火，网上对此的热议很多，包括冉莹颖野心太大，能力太差，甚至在转移资产等等。我有一点不同的看法。我觉得这两口子最大的问题就是基本思路犯了方向性错误。为什么？

其实我们可以把每一个人的奋斗都看成0到1的过程，0到1很难，所以成功者总是少数。但是邹市明在拳击这个赛道绝对是拿到了远大于1的成果，拿到1的结果最该做什么？就是将这个1放大到10，相比0到1，1到10要容易得多。

而且邹市明如果按照1到10的思路去执行，大概率是能拿到10的结果的，原因就是当时签下邹市明独家经纪合同的是盛力世家，这是体育领域全国最顶级的专业经纪公司，不但有顶尖团队而且还有顶尖的资源与人脉。

但是邹市明两口子怎么做的？不惜付出赔偿金也要与盛力世家毁约，然后又做什么？又去陌生领域干0到1的事情——开健身馆、做服装、做餐饮、做P2P，做虚拟币。

![](img/614909359e4ecd5f14b9ed2b4d37fd6b_0_0.png)

任何时代0到1的几率太低了，所以任何企业与项目第一笔投资都被称为天使投资——国外还有另一个说法叫做慈善投资，慈善是啥意思？意思就是投出去的钱就不要指望有物质回报了！所以一般来说天使投资一定是亲朋好友来投的，不是特别好的关系，没有人愿意给你做慈善。

所以邹市明两口子干的事情就是——放着好端端的1不去做1到10，偏偏要回到起点重新去干0到1。这是什么？愚蠢！

所以别看冉莹颖读过大学受过高等教育，但是连最基本思路都是错的。不但基本思路都是错的，而且还大大高估了自己的商业能力，但凡有点头脑了会基本反思的都不大可能连续踩这么多坑。网上说冉莹颖是转移资产的，我是不大信的。为何？

现在冉莹颖每天直播十几个小时，直播十几个小时啊，没干过这个行业可能不知道，这样强度的直播就是拿命在拼——张雪峰大家知道吧，他的身体健康恶化就是每天直播4小时，这两年肉眼可见的衰老下去，一直到猝死。

所以，如果不是被债务压到极致，但凡还有一口饭吃，没有人会愿意这么去拼的。所以邹市明的家产是真的已经亏光了，不但亏光了而且一定欠下巨额债务。这个巨额债务不但包括银行的，还有亲朋好友的。

这个案例对于我们普通人有那些启示？每个人都有成功的欲望，但是一定要清楚0到1太难了，不要被欲望控制了自己的行为，对1看淡点，该你的终究是你的，不该你的不要强求。任何情况下都不要去投资0到1（除非你真愿意为特定的人做慈善），正确的思路永远是只投1到10甚至1到100，不管这个1是自己的还是别人的。
