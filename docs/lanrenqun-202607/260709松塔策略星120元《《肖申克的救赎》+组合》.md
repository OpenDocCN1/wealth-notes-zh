# 一、市场

资金从来是聪明的，观察资金的流动，可以给我们带来启发。

自从2025年科技元年开始，科技股吸引了大批的资金进场，并连续创造了千元股、百元股普遍存在的现象，创业板也超过主板指数200点，成为一种现象，并可能短期继续超越。

![](img/5d5f643c6e77e438748dfc5ca842033d_0_0.png)

这时候，我们需要留心的是，部分业绩良好，基本面扎实，分红相对高的个股的机会。

如果持有6-12个月，会有30%-60%的收益率，不知道有多少人愿意？

这里需要关注的就2点：

1. 市场成交量是否持续放大，以前一天2万亿出头，现在3万亿，多出来的就是机会。市场资金多了，赛道就那些赛道，自然就会溢出新的方向。
2. 部分绩优股底部放量，是否持续？短线与持续放量的区别，就是底部量能，连续堆积，形成信号一样的增长。

同时需要注意的是：部分无业绩支撑的个股，在高位放量滞涨，就代表需要撤离了。

电池、白酒，曾经都有过50-80的PE，资金热捧，最后依旧回归。现在反而被压制的厉害，不得不感慨一句：5年河东，5年河西。

一切都是周期，既然是周期，我们就需要布局一点点在底部的股票，享受业绩增长+周期反转+资金流入的红利。

# 二、加仓的类型

我们提供保守、平衡两种风格进行搭配选择，简单来说就是：

保守的人，选择相对盘子大，超级龙头为主来配置，适合风格稳健，可以死拿的朋友，基本面也不会出现问题——目标-10%到+30%。

平衡的人，选择相对中等盘子，弹性相对大一点，这种配置就会相对波动大一点，上下区间都会比较大，目标-15%到+50%。

### 2.1 保守型的策略搭配演示

1. **泸州老窖**：周线接近2020年的启动点位，白酒龙头，承诺分红比例超过70%，股息率接近7%，低位估值。建仓价格72-75附近，目标110-120附近。

2. **万华化学**：MDI寡头垄断，量产POE光伏胶膜材料，未来MDI波动往上概率大，预计二季度利润会稳定增长，分红承诺30%，外加布局新材料，估值相对安全。建仓价格66附近，目标78-88附近。

3. **迈瑞医疗**：医疗器械龙头，海外收入增长稳定（占比50%以上），估值处于上市以来的1%分位，估值安全，赛道壁垒高。建仓点位135-138附近，目标170-220附近。

4. **牧原股份**：养殖业龙头，成本优势明显，一旦生猪企稳，业绩会爆发，就算生猪周期需要时间，安全性也相对较高。建仓点位35-36附近，目标45-55附近。

以上可能很多人会觉得价格高，适合资金量相对大一点的人群，如果资金量不大，就需要选择我们下面的配置了。

5. **华鲁恒升**：稳定盈利，一季度57%增速，周线接近跌透，目前规划新材料TDI及锂电溶剂替代，这股中报如果持续，未来空间会比较大。建仓价格22-23，目标33-38附近，利润50%以上。

6. **回盛生物**：与其博弈生猪周期，不如博弈兽药+宠物用药，他是泰乐菌素等龙头（养猪及养鸡专用），这股市值低，弹性大，外加回购，预计今年突破新高没有问题。建仓价格21.66附近，目标45左右（重点关注二季度业绩，如继续增长，可以加仓）。

7. **中国化学**：化工工程出海+新材料替代+业绩稳定，目前股价已经破净，股息率4%，这股相对安全，实际有己二腈及POE材料，定价严重低估。前几天涨停有资金在运作，预计后面会有不错的表现。建仓价格7.3，目标10-13元。

8. **越秀资本**：业绩良好+金融属性+对外投资，持有中信证券股权8%及并购北京控股（港股），预计会在金融修复下，有一个修复的动作，看最近走势有触底的样子，介入价格8元附近，目标10-12元。

9. **中国船舶**：在手订单充分，业绩优秀，这种估值也是后期防御的一个选择。

# 三、板块方向

此配置建议持有一年，单独设立账户，季度会同步更新收益率。

本人配置计划，考虑到盘面波动及个股风险，我会做以下的配置：

- 泸州老窖10%仓位——白酒板块是否可以逆转，需要时间验证，不配置过高
- 牧原股份15%+回盛生物10%：养殖业触底阶段，持有2者，兼顾弹性与稳定性
- 华鲁恒升（20%）+中国化学（10%）：化工股弹性+中字头个股均衡
- 创新药ETF（159748）25%：也可以选择医疗股龙头，不过ETF更安全一点点，预计下半年会爆发
- 越秀资本（10%）：金融股配置

这种中长线股票，需要均衡，我们化工+养殖业+白酒+医疗+金融，市场在无意外风险下，会有不错的表现。

这里需要提示：长线账户，与短线需要区分开，医药股考虑到我们本身就持有仓位，如果觉得个股有风险，其实也可以布局创新药ETF，会更稳妥一点点。

坐牢组合，尽量不要频繁操作，也不存在做T，建议用个人账户总资金的30%布局即可。
