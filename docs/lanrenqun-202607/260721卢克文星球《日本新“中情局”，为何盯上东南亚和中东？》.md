




# 日本新“中情局”，为何盯上东南亚和中东？

260721 文/卢克文工作室 风雨如歌

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

美国媒体报道，日本新的情报机构“国家情报局”已经开始组建，其中“海外情报局”将工作重点放在了东南亚和中东。

那么，日本到底打的什么算盘？

# 1

我们之前给大家分析过，二战中日本依靠特高警察、宪兵队、陆海军情报本部、内阁情报局这套集权特务体系。二战后，美国为了打残日本的自主全域情报能力，是不允许日本设立中央级情报机构的，盟军总司令部明文禁止日本建立单一、统一、直属于首相的国家级中央情报总局。

日本钻了个空子：好的好的，我不设立中央情报总局，我把情报职能分散在防卫省、外务省、公安厅和警察厅四大部门总可以了吧？

这四大部门之上还有一个名义上的统筹机构——内阁情报调查室，但调查室是个空架子，手里没有实权，实际上管不了四大部门，且各部门情报互不共享，零敲碎打，不成体系。

![](img/f4762cb2398b992372f96e1df9aa6906_0_0.png)

日本一直希望将情报权收归内阁，而随着形势变化，美国也需要利用日本遏制中俄朝，对日本情报能力的限制逐渐松动。

日本右翼情报集权化的努力，从安倍时代开始加快推进，高市早苗上台后，终于敲定了全新的改革方案，组建了右翼心心念念的“国家情报局”。

随着相关法案顺利通过，预计日本国家情报局将在2026年末正式投入运行，并成为日本最高情报机构。

日本国内对此的反对声不小，尤其是左翼，非常担忧有了统一情报机构后，自己的一举一动，都会被执政党自民党所监视。

2026年4月23日，在《国家情报会议设置法案》（设立国家情报局的法案）的众议院审议环节上，各方就爆发了激烈交锋。

不但日共极力反对，最大在野党立宪民主党也全力发难，试图把法案打回去。但自民党在众议院的席位数超过六成，法案通过几乎是板上钉钉的事。

立宪民主党、日本共产党、令和新选组三大反对党，深知众议院无力翻盘，随即调整策略，将重心转移至参议院，开启终极博弈。

同时，日本的舆论反对声浪全面爆发，朝日新闻、每日新闻、东京新闻等日本主流媒体连续刊发专题社论，大批特批自民党。

5月26日，参议院表决前夜，超3000名东京市民、反战团体聚集国会门前集会，高举反监视、反战争标语抗议，入夜后仍有数百人留守持续发声。

但日本政坛右倾严重，左翼一共三个党，其中日共、令和新选组都是没几个席位的小党，只有立宪民主党有一定规模，实力完全不对等。立宪民主党内部相对偏右的派系，不反对设立国家情报局，只要求设置监督机制，稍微制衡权力。

最后，大部分政党都支持《国家情报会议设置法案》，反对努力最终统统失败。

5月27日，参议院以187票高票赞成、58票反对的结果，通过了法案。

日本国家情报局完成组建，只是日本内部的决定吗？显然没这么简单。

外媒曝出，澳大利亚前情报局局长安德鲁·希勒直接参与了日本国家情报局的组织架构设计，FBI承诺为其提供专业培训。

而对于日本加强情报集权，美国也一声不吭，等于默认。

日本国家情报局扮演着“五眼联盟”外围组织的角色。据日本《读卖新闻》披露，国家情报局下属的“海外情报局”，工作重心是东南亚和中东。

这两个方向既有日本自身的利益考量，也和美国、“五眼联盟”的诉求对齐。

# 2

我们先说中东。

“美以伊战争”爆发后，特朗普要求日本出兵中东，帮美军分摊压力。日媒《选择》杂志爆料，高市早苗倾向于同意特朗普的要求。但是，在内阁参事今井尚哉等人的“死谏”下，高市最终作罢。

只不过，事情哪能轻易翻篇？美国和伊朗的战事还没结束，“停战谅解备忘录”成了一张废纸，随时可能再度爆发大战。

美军想摆平伊朗，必须增兵。

问题在于，哪怕开战前，美军多数航母编队、两栖戒备群就长期处于船坞维修状态，无法调遣部署，能投入中东战区的机动战力本十分有限。

美军水面舰队的核心是航母和两栖攻击舰，开战前能够投入中东的航母编队，仅有“福特”号、“林肯”号和“布什”号三艘。

能够前往中东的两栖戒备群，只有“拳师”号、“的黎波里”号、“马金岛”号和“硫磺岛”号。

目前，“林肯”号、“布什”号和“的黎波里”号已经部署到中东；“拳师”号发生机械故障，“福特”号更是出现了一场诡异的大火，两者短期内都无法返回战场。

美军没有航母能调往中东了，两栖戒备群也只剩“马金岛”号和“硫磺岛”号。这两支编队，是美军眼下仅剩的海上机动力量，不能轻易调往中东。

减轻压力最好的办法，就是让盟友们上。

日本海上自卫队的实力相当可观，有大量的驱逐舰、护卫舰可以动用，对美军来说是很好的补充。

高市早苗倾向于出兵，日本已打算向位于巴林的美国海军第五舰队司令部派出高阶自卫官。日本国家情报局在中东的布局，短期内来看是为后续军事行动做情报准备。

但长期看，日本也有自己算盘。

日本原油进口90%来自中东，霍尔木兹海峡是日本的能源生命线。日本配合美国在中东的行动，显然是希望得到美军在中东完整的情报库数据。

目前，日本已在约旦、阿联酋、沙特、埃及等国使馆增派防卫情报专员，同时借助超过1500家日企在中东的商业网络，隐蔽而长期地收集沿岸港口、导弹阵地、航道水雷、各国驻军部署等纯军事情报。

一旦日本在中东建立起自主的情报能力，终极目标还是摆脱美国限制。

中东本身是现代战争重要的数据库。中东战场上的电磁信号特征、目标识别参数、突发事态响应流程等等核心数据，都是和平环境下无法模拟的珍贵数据。

日本在中东布局情报网络后，可以打着“保护航道”“反对恐怖主义”之类的幌子，不断验证自卫队海外作战和情报如何配合效率更高。等这套模式验证成熟后，再复制到台海、东南亚以及印度洋，最终形成一张完整的、覆盖中东、西亚、南亚、东南亚的弧形情报网络。

海外情报局的另一个重点——东南亚，就是为日本之后的行动做准备。

日本和东南亚的防务合作，有一个“三步走”计划。

第一步，是RAA，互惠准入协定。

第二步，ACSA，物资劳务相互提供协定。

第三步，GSOMIA，军事情报保护协定。

三个计划，咱们一个个解释。

互惠准入协定，指允许双方军队互相入境驻留、演习、停靠；物资劳务相互提供协定，就是两军互相补给燃油、弹药、维修、医疗物资等等；军事情报保护协定，指的是两国军方涉密情报安全互通、保密约束。

从防务角度，和日本签署了三个计划中的第一个，说明双方关系比较密切，有成为准盟友的希望；签署了第二个计划，也就是ACSA，双方即成为准盟友；进一步签署GSOMIA，就是事实上的真盟友了。

日本试图通过三步走策略，将东盟各国一一捆绑到自己的战车上。

目前，菲律宾已经和日本签署了RAA和ACSA，GSOMIA的谈判也启动了，外界大都预测，最终签署没有悬念。

日本希望其他东盟国家效仿菲律宾，但老挝、柬埔寨、缅甸三国毫无意愿，马来西亚、文莱、泰国的意愿也不高。

日本自知这七个国家机会不大，目前只是象征性做工作，重点发力越南、印尼、新加坡。

越南和中国有南海争端，是合作希望最大的一个；新加坡担心哪天美国退出，自己深陷孤立，有意提前准备一条退路；印尼一直觉得自己才是东盟老大，在产业、地缘方面和我们有不少矛盾。

东南亚对中国的重要性不言而喻，不但是我们的外贸基本盘，国内大多数能源进口都必须经马六甲海峡运输至国内。

这时候，国家情报局会成为日本的一把尖刀。

平时，日本可能还只是通过情报系统，盯住中国在东南亚的重要项目，见缝插针、暗中破坏。

一旦发生极端情况，这套体系马上就会转化为日本的战争能力，并和日本在波斯湾、印度洋的海外军事体系协同。

从明治时期开始，吃下东南亚就是日本右翼的既定战略，这一点从未改变。

日本地狭人多，本土资源极为匮乏。东南亚有人口、水稻、天然良港和黄金航道、大量油田，以及军工制造必需的锡、镍、钨、铁、铝土矿、天然橡胶等矿产和作物。

二战期间，日本从欧美手中抢走东南亚后，疯狂屠杀当地人口，掠夺水稻和矿产资源。东南亚成为日本事实上的后勤和补给基地，是日本维系战争能力的核心。

二战后，日本仍时刻惦记着“大东亚共荣圈”，通过经济援助、文化交流等方式，一步步重建在东南亚的影响力。

美国一度限制日本在东南亚的扩张，允许经济文化的扩张，但军事和情报扩张免谈，日本只能蛰伏，一等就是数十年。

现在美国陷入多线作战，抽不出多余资源，需要日本分担在亚洲的防务压力，默许日本向东南亚进行军事和情报扩张，日本才再度迎来机会，筹建统一情报机构，深耕东南亚。

毫无疑问，美国的松绑变相释放了日本的军事情报潜力。

日本会打着和“五眼联盟”协同的幌子，趁机发展自身军事情报能力，时机成熟时再将美国撇开，实现日本的野心。

“大东亚共荣圈”的妄想正在卷土重来，我们不可不防。
