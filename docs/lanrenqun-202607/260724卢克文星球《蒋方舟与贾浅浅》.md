# 
## 蒋方舟与贾浅浅

260724 文/卢克文

整理：公众号懒人搜索，懒人专属群精选

懒人微信：lazyhelper1

蒋方舟与贾浅浅的事情大家都已经知道了，热度即将过去，跟大家聊点有深度的东西吧，聊太表面的东西没啥意思。

我以前住在东莞的时候，好像是2020年左右，同小区有一位邻居是医院院长，具体职务可能有记错，反正是医院的一把手或二把手。有一天这位院长被带走调查，不知道是不是牵扯范围实在太大还是什么原因，院长夫人突然有一天在自家上吊身亡。

这件事在我们小区引起很大的轰动，但除了我们小区，就没有见任何场合有人讨论过这件事，就好像一切都没发生过一样。

那几年医疗腐败查得很严很严，我一个其他省的医生朋友，说他们院长也在那段时间被抓了，最后判了三年半。那院长在他们院口碑还不错，在的时候医护人员的工资比现在高25%，院长被抓后工资也降下来了，等他坐完牢回来，行业还是挺认可这人，又去别的私立医院做了名义上的副院长。

医疗行业反腐这事，实际上除了这个行业的人，外行人压根没几个知道，一直在悄悄进行的，医疗反腐打掉了整个行业的一些食利阶层，让老百姓看病变得更便宜了。

顺嘴说一下医生，以前医生这个职业很受期待，毕竟越老越吃香，但现在大家发现医生不咋好干，工作强度大、夜班伤身体、医患矛盾突出、公立医院扩招放缓、投入周期长收益时间慢，加上医疗反腐这些事等等，现在医科专业的录取分数线下降了不少。2026年除了协和、上交医、复旦医、华西等头部院校还能高分录取，普通“5+3”一体化、地方二本医学院临床专业都明显降温。

从2016年到2026年，除了大家都知道的体制内公务员反腐，其实一直在悄悄有一条暗线，就是对权力集中、资金密集、资源富集行业开展系统性、专项化反腐。

主要有十大行业。

金融第一个跑不掉，银行、证券、保险、信托、资管、金融监管部门整治违规放贷、内幕交易、利益输送、政商旋转门、监管失守、不良资产处置腐败等，将国开行、工行、农行、光大、中信、恒丰银行、证监会、原银保监会等大批高管或干部进行了严惩。

第二个是央企与地方国企全域反腐，在基建、冶金、汽车、通信、航运、地产类国企整治招投标、物资采购、资产并购重组、境外投资、工程发包、关联交易、影子股东、侵吞国有资产等，某些著名的汽车老总就是倒在这一批。

三是能源领域，包括石油、煤炭、电力、新能源领域，对中石油、中海油、国家电网、南方电网、五大发电集团干部，在资源审批、项目承揽、工程建设、设备采购动手脚的进行惩处。

四是政法系统的法院、检察院、公安、司法行政、监狱系统，对徇私枉法、违规干预案件、充当黑恶势力保护伞、执行腐败、司法掮客进行处理。

另外还有粮食购销、工程建设、烟草、土地矿产、教育科研、体育等行业进行过系统性反腐。

长达十年的对权力集中、资金密集、资源富集行业专项化反腐，一直在低调进行当中，普通人是完全不知情的。只是在各重要人士的新闻中，偶尔知道只言片语，或者只有处在那个行业的人，并跟同行业长期交流，才能敏锐地发现是整个行业的系统工程。

我个人是因为长期从事这一行，对事情喜欢刨根问底，所以邻居家的事情一发生，我就开始留意相关信息，才慢慢梳理出了一些内容。

专项性反腐属于治疗最严重的病症，等这些病症解决了，才会慢慢处理一些不急切的疥癣之疾。

比如在教育科研领域的反腐，以前通过持续开展高校系统专项巡察，主抓高校基建、设备采购、校办企业、招生、科研经费挪用、学术资源交易这些大案要案，毕竟这些事情牵扯到了大量金钱与资源，要迫切优先处理。

其实像蒋方舟与贾浅浅这类事情，教育系统里真的只是疥癣之疾，老百姓看不惯，但也没贪污受贿，也没造成国有资产损失或侵吞资产啥的，犯不着动用大量人力物力去处理。

现在普通单一受贿厅级案件，如果无窝案且链条简单，一般专案组核心办案人员都要8—20人；中等复杂的厅级案件，有多名行贿人、跨区域、多年违纪违法这种，专案组需要20—35人，得从各地纪委监委抽调骨干；重大厅级案件，专案组就需要40—50人甚至更多。

反腐也是有成本的，有些事情鸡毛蒜皮的，不值得这么多人去处理。

放在整个教育行业体系里，蒋方舟与贾浅浅学历的事情，真的太小太小了。

那为啥最近对这种小事动手了呢？

我个人认为，两大原因：一是教育系统最重要的人和事，都处理过一遍了，现在有精力来处理小鱼小虾。二是耿同学学术打假打得惊天动地，学术作假这事必须有人站出来管管了。

耿同学那是盯着行业大佬打假，同济大学长江学者、国家杰青、生命科学与技术学院原院长的王平，南开大学国家杰青、生命科学学院原院长、院士候选人陈佺，中山大学国家杰青、国家科技进步奖二等奖、肿瘤防治中心原实验研究部副主任康铁邦，中山大学国家杰青、生命科学学院原副院长邝栋明，上海大学长江学者、转化医学研究院原院长苏佳灿等都被耿同学锤了一遍，好些还受到了严肃处罚，被免职、降职等。

学术腐败在整个行业相对不是棘手大问题，只是支流中的支流，细微处的细微，但耿同学你把事情闹这么大，那就不是二级支流了，是必须提前处理的大事。

蒋方舟与贾浅浅的学历问题，只是这一波反学术腐败的标志性人物。

2003年贾浅浅本科毕业时，其父贾平凹就任西安建筑科技大学人文学院院长，贾浅浅一个本科生，直接进入西安建筑科技大学任教。一个公办本科院校极少招收本科毕业生当专任教师，贾浅浅这么巧到父亲所在学校任教，让很多人不免生疑。

而且她研究方向是贾平凹作品，跟圈子里的熟人资源高度重叠，很容易获得发表、评奖机会，后面一路顺风顺水做到副教授。

贾浅浅自己写出来的诗，也长期被网友批评水准低下，其人生简历及才华，和现在所任职务严重不匹配，才会被网友盯着骂，并被网友“抒情的森林”查出多篇期刊论文、硕士学位论文存在大量抄袭，最后才被拉下马来。

蒋方舟差不多一个意思，她会被清华大学降60分录取，是因为号称天才写作少女，与平常自主招生普通降20—30分相比，已经是天大的顶格优惠，属于占用顶级教育资源，但她后来表现出来的文学才华平平，网友们认为是普通人里中上文字水平，与“天才美女作家”人设不符，跟“神圣罗马帝国”才是一路。

成年后她很少出作品，也没有一部被称赞的好作品，少年时的代笔传闻又从未停止。她就读人民大学硕士，也不是自己考上去的，而是人大文学院的“创造性写作专业（作家班）”。这个班不需要参加每年12月全国硕士研究生统考，面向已经正式出书、拥有创作履历的成熟作家，听着这里面就充满了人情世故。

蒋方舟高考靠特殊方式，读硕士又靠特殊方式，好作品又写不出来，最后又被查出硕士论文有9处正文段落，直接照搬台湾大学陈重仁《中外文学》期刊论文文本，必须要翻车的。

贾浅浅与蒋方舟都指向了一件事情：在国家正规体系里，获得国家正规的名利，必须才德配位。

中国民众自小都受过很严格的平等教育，对于才不配位的人，天生充满反感，尤其是去体制内获得相关利益的人，更多反感。

但回过来一想，才不配位这种小事，跟前面提到的大反腐相比，又算个毛线嘛，真的是鸡毛蒜皮的事情。

所以蒋方舟与贾浅浅的事情说明了啥？

那就是：

历经国内长达十年的各行业大反腐，重要事项估计已经扫清，经过耿同学的发酵，目前已经转向了其他影响较广但情节较轻的人和事。体制内的人尤其要千万小心，才德如不配位，后续必有灾祸。
