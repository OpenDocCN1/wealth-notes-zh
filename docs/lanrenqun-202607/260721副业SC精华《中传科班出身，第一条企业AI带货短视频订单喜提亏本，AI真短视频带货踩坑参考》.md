一分半的 AI 带货短视频，报价 250 元，我做了两三天，最后亏了我几十块，并拒绝了 200 条的企业级订单，及后续的其他订单。一个小小的踩坑经验，分享出来供大家参考。

大家好，我叫 nana，02 年，中国传媒大学电视学院本科，香港大学商学院硕士。去年 7 月开始做 B 站好物带货，现在是 B 站好物深海圈答疑教练。今年转向 AI 自媒体，算是把内容 + AI 这两条线并在一起跑了。

这个背景主要是想说明，我不是一个对内容生产完全没概念的人。中传本科，电视学院，学过编导，学过摄影。虽然不是什么正儿八经的编剧导演专业，但分镜、镜头语言、视觉设计这些东西，我是有底子的。

最近我接到了一个 200～400 条的品牌 AI 真人带货短视频的需求，报价是 150～250 元。

我看了一下他们给的案例。短剧化的场景：开头 → 人物遇到问题 → 产品出现 → 问题解决 → 产品推荐融进剧情 → 最后美好结局。时长为一分钟到一分半。

说实话，视频质量不算很高。我脑子里过了一遍 AI 视频工具的流程，觉得不难。

# 视频脚本第一关

所以我一开始的做法特别简单粗暴，把品牌方的产品文档丢给 AI，让它直接出脚本。确实是快，脚本加分镜几分钟就出来了。

品牌方的回复也很直接：这种视频我们自己也能做。

他们问我的问题很精准：你知不知道这个产品的功效？针对什么人群？解决什么真实需求？

我说实话，这一层调研我没做。

第二轮我认真出了两版脚本，都配套了故事分镜版效果、人物三视图、场景参考图。脚本一版是弱剧情——人物身心状态因为产品带来的前后转变。另一版是强冲突短剧——开场矛盾激烈，产品出现后反转打脸。

我平时刷抖音短剧刷得多，大概知道那个感觉。但真的要自己写，才发现把冲突拉到最满，是需要系统拆解过优秀剧本的。我当时没那个时间，就按脑子里的短剧理解，先构思了一个故事梗概，再让 AI 生成。

强冲突那版过了。

# 视频制作第二关

然后真正头疼的部分来了——视频制作。

我用的方案是 Codex 调用 Seedance 2.0 的 API。Seedance 2.0 效果确实好，成本高一点，但觉得在报价范围内还算可控。当时是这么想的。

第一件事就卡住了：真人脸审核。他们要真人型短剧，AI 生成前会卡你的真人脸。这个还好，小红书马上找到方案——在人脸上打网格就能解决。

开始生成之后，第二个问题：前后镜头接不上。第一个镜头看着还行，第二个镜头出来，跟上一个完全不搭。

原因我当时才反应过来——前一个镜头的尾帧，没有作为下一个镜头首帧的参考图给进去。而且你直接拿尾帧当参考还不行，得先处理人脸。

第三个问题是场景细节一致性。办公室场景，前后镜头所有人坐的位置不一样，办公桌的细节不一样，PPT 不一样，群演也不一样。

这时候我才意识到，提示词得写到什么程度——场景里所有人物的位置关系、镜头会照到的每一个物件细节，全部要写进去。少写一个，AI 就自由发挥了。

第四个，人物声音不一致。生成到第二条才意识到要注意这个问题。小红书上找到的解决方案就两条：给 Seedance 上传参考音频，或者不生成音频，全部后期配音。后期配音等于再加一道工序，我选了前者——让 Codex 截取第一条的人声，后面一直当参考音频用。

第五个，提示词一模糊，AI 就乱来。镜头怎么摆、人物什么动作、跟镜头什么关系、动线怎么走，这些不说清楚，AI 真的会——手指去戳一个明显不是触屏的显示器，或者一个人在一个场景里机械重复，没有任何镜头变化。

这五个问题里面，前四个是流程问题，有方案就能解决。第五个是最吃经验的——你得知道什么叫好的镜头语言，才能在提示词里把该写的东西写全、写好。

我自己看到画面能立刻判断哪里不对、为什么不对。但如果换成完全没有影像训练的人来做，很多问题可能根本意识不到。

还有一个小细节。我每次都会跟 Codex 强调“注意我之前提到的所有问题”，规则也沉淀到 skill 里了。但偶尔，真的只是偶尔，它还是会忘掉一两个点。对一条视频来说，可能就是返工一个镜头。如果批量跑 200 条，这就不是“偶尔”了，是系统性的损耗。

成片跑完，交付之后还有一件事。

品牌方提了几条修改意见。一个是说女主和女三的脸太像了，形象要重新生成。但人物三视图一开始就给他们确认过，是通过了的。另一个说情节设计不够、画面表现不够。分镜本前期也确认过。

后来我自己在剪映里调了剪辑节奏和一些画面细节，这部分倒还好，我自己剪片子是熟练的。

但整件事让我意识到一个问题——有时候可能甲方自己也不清楚自己到底要什么。一开始觉得要求不高，看到成品之后，审美和期待自动往上调。而你前期过了审的东西，后期照样会被推翻。这个边界如果一开始没约定死，后面的修改全是沉没成本。

# 最后算账

一条一分半的视频，我做了整整两天。每天五六个小时，在等生成、验收、改流程、修错误之间循环。好在我没遇到太多抽卡问题，修改返工的轮次不算多，所以成本没有失控得太夸张。

但就算这样，第一条还是花了 300 多。Seedance 的 API 调用占大头。

品牌方结算 250。

合作方最初说的是，如果验证了我有批量化能力，可以给 200 条左右的打包。

做完第一条之后，我认真想了一下。

要跑通批量交付，我至少得花 30% 的时间专门扎进这个赛道——脚本类型、分镜模板、不同品类的镜头语言体系，这些都得吃透。不是“流程跑通”就够，是“变量全摸清”才能稳定出量和控成本。

我现在手头的情况是：B 站有一块业务在跑，AI 自媒体是未来的重心。如果把三成精力砸进 AI 视频交付，另外两条线必然受影响。

更深一层想，在现在的 AI 视频生产链条里，纯交付方这个角色其实夹在中间——品牌方压你单价，平台和工具方收你 API 费用，你靠时间和精力去换较薄的利润。200 条看着是量，但如果你没办法把单条成本压到报价一半以下，200 条就是 200 次亏损。

我也不是说这个赛道不能做。沉下心去做，肯定能赚到钱。

等后面没那么忙了，有整块的时间和精力，我其实挺想回头把这件事认真做一下的。不是继续手动一条条磨，而是花时间搭一个能跑通批量交付的系统——把脚本模板、分镜规则、提示词约束、审核规避、音画衔接这些东西全标准化。到那时候，200 条就不是 200 次亏损，是真的可以变成一个稳定产出的事情。

以上是我第一次做 AI 带货视频交付的真实经历。如果你也在接类似的活儿，或者有想法尝试，希望能帮你少踩几个坑～
