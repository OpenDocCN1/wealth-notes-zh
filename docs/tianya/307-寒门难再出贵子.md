


# 寒门再难出贵子

本文是一位银行的HR写的，他工作了10年，接待了一群到银行实习的实习生，然后观察他们发生的一系列故事。像小说，但比我们看过的小说更精彩；像现实，但比我们了解的现实更残酷。文章中的寒门，还不是家庭贫困，而是小城市、小城镇的学生。讲述了好几个残酷故事，应该是真实的故事。否则我不信作者有这个水平虚构出来。文章来源天涯社。

作者：永乐大帝二世。

现在越来越清楚 “性格决定命运”, 性格这东西是熔透于骨髓的，性格的培养和学校教育没有大关系，大多决定于家庭背景，和成长环境。从大学毕业出来的第一步，往往起到至关作用的是家庭背景，也就是从起跑线普通家庭的孩子就输了一大截。

在一个物欲横流的时代，当金钱决定一切，成为人的终极信仰的时候，这时候也是“门阀”、阶层相应出现的年代。

## 一群实习的大学生

本文由公众号[老庄日记]整理编辑发布，更多免费好书分享，请微信搜索关注。结合我自己近半年来的观察，我在银行人力资源部上班。去年招了很多学校的实习生，实习可不是正式录用了。以前自己年龄也相对年轻，没有太多关注以往的实习生，今年正好我负责这些孩子，在我们这里招了大约60名实习生，其实最后录用不会超过10人。这些实习，其实就是银行的噱头，可以找些一个月几百块钱对银行来说的免费劳动力，对学校，对外宣，对社会某种义务交代吧。但是进入银行实习的都是学校推荐的所谓好学生。

银行这种单位，在我们的体制下，纯国家垄断机构，待遇优于其他行业待遇还是比较高，在银行工作可以获得优惠的贷款利率，买房子贷款都相对容易。总之一句话是那种世人眼里比较羡慕的单位。

接下来来讲讲这些孩子人生的第一步究竟是怎么迈出，怎么的实际结果。有时候相处了这些比我小将近10岁的孩子，真的觉得一切的理想主义都是狗屁，只有现实无法再接触的现实。

大学毕业，更何况是大四，还是一些孩子。去年的2月份我接待了我们这个省最好大学的这批孩子，来到我们单位，从中可以看出这些孩子都是都是一个名牌211重点大学即将毕业的学生，可是他的组成成分又分了这么几种：

- 一类，农村家庭出来就是学习很努力的，在学校很优秀的，大概有20多个；
- 另一类就是家庭县城的孩子，有那么十几个；
- 再就是所谓的大城市的孩子十几个，这就是当时看到他们的资料的印象。

印象很深的是去年三月份，他们第一次来到银行。因为第一天报到，我们准备了一间办公室，早上等着这些孩子来报到，上班后开始等着这些学生的到来，我的同事跟我说：“我告诉你，我知道哪些孩子来的早，哪些孩子进来会和我们门打招呼，哪些孩子会和我们聊几句，哪些孩子会进来会给我们倒水。打赌的结果是中午请他必胜客……”

然后，他输出了一大堆简历说这些孩子会来的相对早点，然后把这部分简历交给了我。真的当时的结果，最早来的十几个孩子都拿是他我的那些简历里面的。

慢慢的陆陆续续来的这些孩子，然后有的进来很紧张一句话不多说，有的笑嘻嘻的和我们聊几句；有的自然的说：“以后你们是领导了，给你们倒点水”；有的孩子会大咧的。其结果是我同事预测的，错误率只有两个。当时我就惊奇了，中午请他吃饭，我说：“你怎么看的？”他说这不是他的绝招，是以前跟着副行长接待实习学生从副行长那里得到的一个启示。其实很简单，看简历资料户籍、所在地、工作单位，能归纳出群体来，相应的能归纳出几种孩子的性格特点。下面是同时分析的过程：

- 来的很早的孩子，大多是农村的孩子，因为他们重视学校，自然来得早。
- 进来很紧张的孩子，大多是学校推荐的。
- 倒水的孩子，自然是重视家里。
- 进来大大咧的孩子，家里都是经商的，小这种态度很灵活。
- 还有那么三个，感觉挺傲的，属于那种不卑不亢的。
- 属于大城市的孩子。

一例外，我开始觉得很有意思，开始应该去分析这群孩子。我内心清楚，实习的结果只有几个可以留下，大多数得找工作。保留他们的联系方式，看看半年后、一年后、一年后，他们走向成人的样子。没想到我身边的朋友、同学、同事。

这种理智派很少，大多数孩子也包括我们这群成年人，都会为了一个飘渺的希望，希望自己比较幸运，去努力去争取。从这些孩子中，我获得了一个很有价值的思维：如果有能力一定去争取，因为既然大家都说这件东西好，既然世俗的认知都认为是好的，那么它一定是好的；不要自认为自己能够打拼出另一个天地。如果全面衡量觉得这块蛋糕取不到，马上转换思维，不要做自己力有剩余的事情。因为努力了，争取了，你的条件达不到，最后伤心还是你自己。这一点很重要，非常重要。

也不知道是出于好心善意，还是出于什么，差不多每个孩子都开始知道我手里有名额，当然这事目前只有我和副行长知道，只有两到三个。从那天开始，我的办公室和我的手手开始忙碌起来。刚开始被要走的几个孩子，自然是拉着家长，拉着银行的同事，开始多次要约我吃饭。这个是自然，人之常情。我知道我自己那点权利，只有两个名额，这个谁也不想得罪，就一直拖，找个理由告诉电话的人：“我没有这个权利，我也要听一听这个孩子如何如何好，也许他是全世界最优秀的孩子。”接着也有孩子的家长，开始直接找到我的家，提着东西。呵呵，鉴于我手里那点可怜的权利，这礼物我没法收，即便能收也不想，因为我觉得我确定一个孩子，那就意味着另一个孩子要去满世界的面试。

第二天，就是给他们安排部门。哪个单位都一样，有的部门自然是舒服的要命，自然有的累的要死。其实哪个部门也想要跑腿的小孩，但是对来说跑腿，对他们来说也是好部门，不好的如果被安排做大堂经理就要一直站着，挂个横幅，一天在大堂跑来跑去；安排的老总办公室外边就是接电话，复印个材料；安排到监察部，对不起，跟着去安装提款机和指挥工人安装摄像头吧。因为实习不能安排做窗口业务，大多就是内勤，外联，和打杂了。

俗话说，有人的地方就有江湖。别看小小实习，斗争就开始了。第二天一早我总共接了五个电话，也有直接去办公室的级别高点的、低点的普通同事，开始跟我打招呼：“哪个部门？”

## 小胖和他爸的故事

按照约定俗称就叫他齐小胖吧。这个孩子当初主动要求当堂经理，因为姓齐。我说大堂经理挺累，他还自动要求可以减肥、照顾同学。然后自己太胖，不适合干细致工作。呵呵，这个小家伙告诉我什么叫“人熟就是宝”，这绝对没错。这个孩子家庭条件不错，父母开了一家不错的家居饰品店。这个小家伙学习也蛋（此处应为学习挺好），从二级城市来到省会大学，这孩子的性格很有意思，那开玩笑从不会烦，见谁都笑呵呵的。这个孩子后来没能留在银行工作，但是因为性格好，比较活，虽然没有进来，因为家庭条件可以提供一下支持。他在银行实习的六个月，混了个和谁都挺热，最后因为在银行实习，自己开了家公司，主要是给银行安装提款机。因为这个行业是个稀缺行业，一旦坐上了就很难别人再替代。一年的时间，小家伙买了房子，结了婚，也是时常给我打电话的。当时他想做这个，和他爸爸交流了意见，因为我比较熟，他爸爸专门跑来找我，请我吃饭，也就是这次聚饭。他爸爸教给他，也是教给我一个很重要的人生道理：“人熟就是宝”。他吃饭的时候自然少了一大堆奉承话，然后喝了点酒，就说到了自己没文化如何干成了一个家具城。当时我就觉得这么小胖的爸爸有点思维含量，他告诉我说：小胖学习挺好，是个好孩子，估计想留在银行，家里没有门路，但是既然既有条件在银行实习了，那就可以有规划。

周周的工作就是这群孩子工作了一个月之后，大多隐约知道，这个群体有可能留下的只有几个个人。因为在这里实习，多少了解商业银行的工资，待遇，相对于其他单位还是很有诱力的。就这样开始了。和小胖那样的理智派很少，当然这种理智来源于父辈的见识，父亲的能力和经济能力和人生智慧。这种孩子很少，就那么一个。



精神，很勤快。在风控部实习，很不错的孩子，经常看着抱着一省一省的资料跑上跑下，风控部权利最大，业务最多，资料，文件自然最多，这点比较累，没完没了的复印文件，没完没了的开会。治国被安排在风控部实习。

风控部几乎是银行工资最高的部门，因为要求的太多，当然饭局最多，当然部门收到的小礼品也最大。治国家是农村的，从小学习很努力，篮球打得很好，在大学里成了一个公认人物，在这群女孩中也很受欢迎，当治国听到实习名额的时候，这个消息是从风控部总那那里听到的，好几次下班的时候，看见我在停车位那里，见了我我就打招呼，连着好几天。

我知道他想干什么，有一次我坐我的车吧，正好经过你们学校，这样不用打车了。那天正好我老婆去岳家看孩子，我也没饭局，就是想开车转悠一下，就拉上他了。开始孩子很拘谨，很拘束。我说在风控部很好吧，好好努力争取留到风控部，那可是银行最受伤部门。治国接着这个话题开始了了他的语言。感到学校他说大哥到这请你吃饭吧。当时我觉得这孩子挺有意思，一路说了那么多敲路边鼓的话，到学校附近说请我吃饭，肯定这孩子盘算着近的饭店很熟，在经济范围内请我吃饭，可是一想银行一个月就给他们800块钱的实习工资，还不知道这八百家里还给不不给生活费。我说我请你吧，等你上班了，再请大哥。就这样没有听他选择的饭店，我选择我熟一点的一家饭店。开始一场谈话。我说开车我不喝酒，让他喝点，刚开始还拘谨，喝了一瓶啤酒后，治国讲起了他的身世。

家农村的，还有一个弟弟，父母纯农民，父母对他有很大的希望，通过在银行的实习，觉得要是能留下真的就好了不过了。这时候我突然心里很压抑，不知道该对他说什么，他还是个孩子，没有经历过几次饭局。我劝他喝了了两瓶啤酒后，就开始给我掏大实话，告诉我风控老总来说告诉其名额的事，说如何如何想留下，说自己已上学如何的努力。我发现了一个问题，这孩子不讨厌，但是总是说自己，还太小，太渴望留下工作。突然有点不忍，但我能说的只有好好表现。最后我告诉他，说你们部门的老总，风控的老总在行很有分量，他比我管用。但是治国说了一句话，说老好好干，没说别的，是部门同事告诉他，我这里可能有名额。自然我只能说一堆空套话，就在他的诉苦中我把微醉的他送回了学校。

后来治国跑我家里来送礼，一条烟，还有一些特产，我没有收。后来还因为一次外联活动，给他报销了500块钱。后来风控的老总说，治国他给你送了一些土特产，风控的老总的老婆嫌干净给扔了。对于老总来说那是个笑话，但是我知道，治国你在学校也许很优秀，你这孩子挺努力，但是在在这个拼家庭的社会，也许已经没有这份工作了。因为风控的老总觉觉得这孩子挺傻，送礼送了了一些扔货。治国很快快，也会说话，在学校做学生干部，要是是在三十年前也许前景很好，但是现在，治国没有人稀罕你的土特产。治国，这不是一个使劲干人就说你你好，肯为你说话的时代。治国长得很很帅，男孩子没用，没有人指导他，没有人告诉他怎么去做，什么都是他去摸索。也许治国以后会出人头地，但是40岁之前他的命运已经确定了，要让现实碰到碰头破血流在知道社会的真相，才能磨合好自己……

治国后来没用留下，几经面试找了一份保险公司的工作，很辛苦，后来逛街见过一次，看得出的感觉挺累，挺辛苦的。但是我觉得治国还可以，我就想不通，为什么风控老总不肯为其语句话？如果他说的话，我也许会给他点助力。这是后来的我和风控老总一次饭局的谈话，风控老总说有一次看见治国把接待烟，往口袋里塞了两盒，这事让他彻底的否定了治国。后来让我小胖治国拿烟做什么，小胖给我的答案是治国想回家的时候带给父亲抽，因为中华父亲没抽过几次，我当时的感觉，真是觉得一个字：哎。。

还是小胖点醒了我，说治国国家不是很好，也没啥心，就是想给父亲那点烟抽。我一下明白了，风控老懒得去明白，也不想了这孩子为什么把接待烟装走，但是这个细节让他彻底否定了这个优等生，这不是什么大事但是这个细节让其觉得治国讨厌。治国觉得有那么多中华，父亲抽烟，不经意拿几盒给父亲。

## 小东和原子的故事

以下是关于小东和原子的故事总结及逻辑分析：

### 核心观点：父母思维方式的影响
- 父母的思维方式决定了孩子的命运。
- 孩子的家境虽然是因素，但更多取决于父母的教育。
- 孩子由于父母的思维方式决定了一生的定位。
- 优秀与否的根本因素，是父母的思维框架。

### 案例对比：原子
- **背景**：极其聪明的孩子，乡镇普通家庭。
- **性格**：聪明，或许有心计，实习时嘴很甜。
- **经历**：追了一个市区的女孩，早结婚，通过父母家拿了十几万首付买了房子。
- **结果**：虽然表面优秀，但因为父母的思维方式，导致在面对房贷、养孩子、工作等压力时，生活得非常累。

### 案例对比：小东
- **背景**：家境比原子差。
- **性格**：幽默、开朗。
- **经历**：喜欢一个实习时的女同学，但父母坚决不允许（认为女孩是县城的，对将来没助力）。小东与父母闹了架，最终同学女友分手。后来通过相亲找了一个爷爷战友的孙女，家境更好，家里有套房。
- **结果**：听了父亲的话，晚了结婚，目前生活得比较从意。

### 总结与建议
- 刚踏入社会的时候，父母的意见非常重要。
- 在没有积累的时候，不要去做承担不了的事情。
- 必须要有自知之明，明白自己的条件、能力和背景。
- 人生有规律，年轻时的选择要慎重。



# 第一：是去找一份工作，一份等待较好，有发展前景的工作。

可能有人觉得什么叫好工作，好的，什么河蟹，银行，电力，我根本不去。我作为一个工作了十年的人经验是这样的，如果你是大学本科毕业的，不能读研究生就不要读研究生了，因为本科，研究生工资差了几百块，所谓好工作，不是说进去养着的工作，是你里面却是可以学到东西，将来不再这家单位做了，因为在这一单位工作学习的经历，能让你很快找到下一份同类型的工作。

尽量最初选择入职的几年，能进大机构就不要选择小公司，因为大机构接触的层面高，即便将来、将来有能力，大机构本身就是一个机器，你可以选择为这个机器机器服务，自己也能开创辅助大机构服务的行业，这样路不会走死。

要选择那些社会地位较高的单位，因为接触的人脉不一样，不要忘记了人脉就是宝。

在初期的时候最好不要自己创业，因为这这条路很难走，没有经历，没有资金，没有技术，很难。即便是你是IT天才，也希望你服务大机构几年后，各方面条件成熟了再自己创业。

第二，是选择一个他或者她结婚。

楼主朋友有离婚的对，几年前还恨不能长在一起，最近闹离婚的，相爱的人几乎成了仇人。

楼主的看法是感情世界是一个纯粹的想象世界，哪里没有性价，没有安全，只有各种生活物品的价格。但是婚姻的本质是交换，没有比这更真实的东西，不要去幻想你是例外，结婚的时候，没有想离婚的，那些离婚的也不傻。

无论你是男孩还是女孩，你一定记住你一定要有自己的工作。因为工作不会抛弃你，不会嫌弃你。在婚姻里安全感和舒适是你需要的提供给对方的，然后从对方那里再获取安全感和舒适感，婚姻的基础是爱情，但是物质是基础中的基础，请相信无论你是女孩还是男孩子都不用放弃工作，因为放弃经济自理就等于失去自我。

如果你是异地留守工作的，尽量不要选择同时异地的伴侣，因为孩子、老人很麻烦，都是现实的问题。最好有办法是，最好有一方是父母在本地，这样你可以生活得相对轻松。

无论是男孩子还是女孩，在选择结婚的对象的时候一定牢记一个原则：选择爱你的那个人结婚，而不是你爱的那个人结婚。如果你有条件追到条件优于你的家庭的对象是你福气，但是最好别比你的家庭差。
