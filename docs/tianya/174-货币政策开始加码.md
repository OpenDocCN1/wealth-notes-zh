最近，小川的言论耐人味。

人们必须以全新的思维应对即将到来的负利率时代，这已不是遥远的事。

1. 金本时代，货币与商品相对应，有多少货币，就只能生产多少商品，超出货币的商品只能销毁。
2. 传统上的信用货币与商品和债务对应，一个经济体到了经济失去增长潜力的后期，信用货币的发行几乎完全依据债务数额发行货币。
3. 信用货币的历史似乎已经到了尽头，单纯依靠信用货币的手段无法对负利率时代。
4. 当前市场上流行的数字货币，从严格意义上，不是货币，只是个虚的数字符号，因为它没有对应的商品。

只要读过一次货币史，就能明白，信用货币终将像金本位一样，走到尽头的一天。货币史，对于一定经济、金融知识的人来说，它是经济、金融书籍，反之，它只是历史书籍。金融史，不仅讲述了货币何时会诞生，金本位的成立与取消，历次大的货币变革与经济危机的应对。更重要的是：每一次应对危机的手段，不管成败，更关键的是，对于成功的经营，更多的教训。

数字货币频繁出现在媒体上，加上一些人的言论，这不是空穴来风。

即使今天，很多通缩者，未必搞清楚，15年下半年开始，为何房价翻倍的方式。

货币是源头，看懂经济现象，必须搞清楚到底什么是货币？

- 金本位后期，货币发行脱锚了，这时期，从信用货币过渡的过程。而现在的状况，似乎是从债务发行的比例不断扩大，距离极限越来越近，货币本质就是要有与之对应。
- 信用货币发行，这个锚就是对应的商品和服务产出。
- 创造多少货币，超发，就会造成货币贬值。

股市各行业的走势不仅反映行业的盈利能力，更是宏观经济政策的预期。

货币时代，抗通胀，永远是资产的主题。
