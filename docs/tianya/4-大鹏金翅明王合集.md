现代社会的活力严重依赖打破奴隶与奴主的阶级限制，激发双方的创新能力，它的策略可以是自由、民主、高效、创新，这是历史的教训和启示。现行的制度有意让奴主拥有特权，了解社会运作的逻辑，而奴隶没有。因效率的社会，其信息本质是很高的，远超个人能力，奴主可用低价通过人才买到信息，并且信息的代价是与资本比例的，奴隶即便取得也不值，因其本人资本太小。如你花十万买一条股票会翻十倍，可惜你剩余的钱还有八千，你会去买吗？你当然不会，你只会用你的千万去博傻。

人们对于市场制度之一观念就是相信它可更好的分配社会资源与财富，给每个人带来机会和好处。然而中国的市场，只是权力与资本的博弈市场，是少数人的市场，没大众什么事儿。这就如同羊群听到两个带头的牧羊人在定价后，斗智斗勇，目的是为了分配羊肉，划分羊群的支配权，而牧羊人依靠的是暴力和智慧，这两种东西最后都演化为“权力”。

在推高房价的过程中，牧羊人与羊群之间的矛盾在不断扩大，因此涨价事件的实质是官商联手，席卷人民若干的劳动成果，虽然它刺激了人民的工作欲望，却成了少数人的成功，但也因此严厉地击了大面积的人。毕竟能够买得起的人是少数，高高耸耸的房价让人民仰望之遥，只有氧气与绝望的份额了。为了，他们用购买小产房来应对。

你现在该知道为何政府对小产房不松口了吧，因为它拆送了政府的财源。政府的说法是，中国人多少地，应该由政府来控制土地资源，人民币要是过度使用土地，就会出问题。但为什么政府收地那么便宜呢？他们为何不把向开发者卖的钱数退还？

世俗的幸福取决于健康、教养、社会地位、财富、政治权利、道德能力、生活态度、良好的人际关系等因素。幸福并不是很抽象的，它很体现现实。作为一个努力工作的普通人，经过长的时间的寻觅，应该幸福的基础放在财富上。财富最容易易见的好处是，当我们拥有了，我们便不会再因各种琐事而麻烦别人。我们与别人关联可以不再涉及一切，我们不再忙了，我们不再为小事比较，我们会变得较为宽容。在现代社会，每个人必须为闲暇的时间，也须为人生的决定付出。无知的人可能等到，幸福是有要求的。

最适合人类居住的地方，往往也是底层的地方。连续学习与求知也需要较高的生活，追求真理同样需要付出。大大多数人追求平静与自由，多半更容易得到，古代都是贵族。人类活动是在占有资源的基础上进行的，所以与同类争夺资源，在日常生活中也一样。任何地方都会有一天，位置填满，直至停止。若获得方便，必须付出一种代价，那就是财富与权力。权力是一件复杂的事情，里面有暴力和手腕，而财富相对单一，事实上这两项都是指向“自由”。财富是一种缓冲，我们的生活拥有一种弹性，使我们不动处于极端或敏感的状态。在现代社会，如果是贫穷，招来的多半是哀。

一个无的人，就是再高尚，也没有能力发挥他的高尚。这个世界上只有极少数人有能力改变自己，大多数人无能固执信信念，因为大多数愚愚贪婪。只有很少人理解世界上正在发生的什么，因为信息只汇集在他们那里，而信息成本高，多人无法支付。多人只有努力工作，对任何人的观点微笑同意，用以维持一个像榜一样的外表。社会大机器运行在奴隶身上，也只有在奴隶身上拧紧绳缚，以保证机器有效的运行运转。看一个人对金钱的态度，可以大致知道他是一个样的人。在经济社会里，如何挣取并支配金钱，许多可以直接透视出一个人性性格与道德标准。人在挣取时往往不道德，而在支配时却表现得很道德。而根据二八法律，世界上永远只有少数人拥有一种智慧或权力，可以高效地配置人类社会的各种资源。

- 1. 商品价格一般是由三个部分组成的：地租、劳动（含脑力劳动）、资本利润。
- 2. 由于分工精密和人口增长劳动力的原因，一般情况下劳动者得到的回报仅仅维持劳动力正常运转而已，除非非这种劳动力供给范围极其狭窄，或者获得这种劳动力的成本相对较高。
- 3. 对于劳动者的需求只可能社会整体资本的增长而增长，没有后者的增长，就不可能前者的增长，劳动工资提高是在社会财富不断增长的过程中被体现出来，劳动工资最高的地方是在世界上富有的国家，而在最兴旺或致富最多的国家。一个国家即使非常富有，但如果长期停滞不，就不可能有多高的工资，随着供给饱和和和平条件下人口的激增，劳动者的人数会成倍地高，就业机会是劳动力不得不为了挣取工作而陷入竞争激烈，那么自然无须高价去挽留劳动力。所以劳动酬优渥是国民财富增进的必然结果。反，贫穷劳动者生活维持费不足是社会停滞前的主要表现，而劳动者处于饥饿状态，那就是社会急速退步的体现。

- 4. 需要指出，历史告诉我们，并不是在社会达到绝顶富裕的时候，而是在社会处于进步状态的时候，大多数人幸福快乐的。社会在静止状态下，人民的境遇是艰难呆滞。而退步状态就是绝望和反抗了。劳动报酬丰厚能够鼓励人的增长，进而产生超越能力的消耗，再次导致劳动报酬降低，人口随之减少。同样劳动工资的增加抬高商品价格中的人力资本，减少该商品的消耗，但会扩大商品生产的规模和效率，反而再次减少劳动力的使用，提高平均单个劳动价格。
- 5. 资本恰给恰恰，资本的增长提高了工资，就会导致利润下降。利润的波动很频繁，一般用数据固定，不过可以从货币利的变化可以察，在使用货币能够获得大量利润的地方，通常对货币的回报很高。因此国家财富资本利润这一块必定随着……
