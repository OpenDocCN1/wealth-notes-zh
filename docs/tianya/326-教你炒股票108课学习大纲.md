


# 教你炒票 108 课学习大纲

雏中课已经说过了，刚开始写“教你炒票”这个题目的，虽然“全国中没有第二人比我 ID 更适合炒票的”，但是开始写炒票的时候，并没有什么主意，只是浅浅谈谈。

“后来开始写与 ID 逻辑有关的东西，开始，就是想把一些用到的结论按照顺序告诉各位，因此课程不是按照正式的逻辑框架的”。

也如此，雏中说“教你炒票”108 课课程在逻辑上并不是完全按照顺序来的，而且有些课程与雏中逻辑理论没有什么关系，对于初学者，特别是自学能力和逻辑能力匮乏的，学习雏中逻辑自然免要走些弯路。
