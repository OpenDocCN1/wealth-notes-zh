


# 四地地理——无论是“四地”，是我现在的想法

这是很早就想写的字。记得年前，报里提到地理和地图可以帮助自己更快地更新对世界认知，我曾试图查阅地图、书店、商店寻找，也许我能够找到自己打算的地方并不容易的，这个愿望变为现实，现在有了《地球册》来看世界了。

《地球册》是几年前的12月16日国际地理日出版的。当我读到它8年后，我发现地球是如此巨大——所有的细节都无法想象的。直到那时我开始查阅这些细节，后来看着地图上的人脸，当我需要找客户的地址时，用手机屏幕上点一下，我才意识到我是在用手机软件操作的。后来我把手机里的旧手机换成了新的，地址就是手机好查了！我的梦想在几年后实现了。

初学的时候，我觉得地图很难准确地找到某个地方。地图的局限性在于：它不是一个精确的比例尺，对来说，它不能准确地显示的边界，但通过这些边界，又让我更愿意去理解地理的力量了。

随着阅读深入，我对地理的理解比以前更深刻了，同时也对地理的兴趣越来越浓厚了。在不同的地图上，我看到不同版本的地理呈现出来，有的是真实的，有的却和我所认为的完全不同（并不是说我是错的）。只是我从不同的角度来看，我觉得地图还可以做得更好呢！通过这些地图，也许我能从不同的视角观察世界出发，当我离开家乡，我才感受到了对“地理”的真实含义。

古人云“以图载意”，我对于地理应该如何定义为“四地”？在这个信息的时代下，我愿意成为地理学家。问题是，没有一个模型来告诉我，我设计的地图应该包含哪些信息的类型。

既然有了“四地”的概念，我现在的想法有三个了。所谓“四地”，简单来说就是我通常的地理平面。这类地理是最基础的，行政区域的范围，足以让人理解其最基础的位置。

并不是世界上所有地方都是地理的，对于平均只有2000人的地方来说，地理面对的任何一个地方，可能都值得关注的。如果一个地方不能被地理化的呈现，那么它的价值就没有意义了，它将从人类的记忆中。

如果再升华一点的话，我们还需要给地理在海中已经构筑的地理中加入，加入一个“时间地理”。

“时间”对于地理学来说是非常重要的。或许一个世纪，或者一个甲子考察地理变化的空间的过程，我们可以称之为“时变地理”。历史的发展，决定了地理学的定义变得越来越重要。尤其是在关注历史地理的研究中，研究一片土地的历史，人与地理的关系，是地理学中重要的任务。

如果以具体的线条画在地图上，加入“时间”的概念，让历史的地理随着政治变迁、兴衰演变等清晰可见，这样可以让自己自由学习地理，以提高其他人们对地理的兴趣。这需要足够的时间，就是加入了“时间地理”后的“四地地理”。

我想了很久，我觉得地理应该如何去描述这个世界，或许需要逐步加入地理政治、人文，这就是所谓的“三地地理”。

而且不需要被一些特定的地理信息删掉，让它消失在某个角落，而是作为地理服务的内容的所选择。这也是地理的目的之一。

“四地地理”（或地理政治）是我八年来一直在推的一个概念。对于地理来说，叫做“三地地理”的程度，即以地理为基础，加入了所有的信息就可以被称为“时间地理”。

写到这里，想起小时候经常在老师所说的，对老师说地理只有“五百字”。其实对于地理来说，对于地图来说，或许我不知道什么叫地理？只是地理，将自然、人文、历史信息有机结合在一起，这才是“四地地理”——“地球地理”，这应该帮助我们去理解一个不断变化的世界。
