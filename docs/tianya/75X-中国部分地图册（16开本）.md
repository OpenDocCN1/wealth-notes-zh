


# 四维地图——也许这就是我想要的地图

这是一篇早就想写的文字。记得多年前，顿悟到地理和地图可以帮助自己拨开迷雾，更准确地观察世界时，曾经遍寻图书馆、书店，希望能够找到心中所想。也许是自己的地方还不够，这个愿望并未实现，于是便有了《地缘看世界》这个贴子。

《地缘看世界》贴子是2009年7月12日在天涯国际观察板块所发的，今天已经整整8年了，自制地图算是它的特色。说起来画地图这事儿，还要感谢我的无聊。年轻时数码拍照片碎片，看得有人在拼接，将客户所拍之后面后期，用电脑拼接到婚照上打印出来，觉得很是神奇。问问对方所用的不是photoshop软件所做，便去书店买了本价最低的工具书（至今得十块钱）。不想当时的无聊之举，后来竟会在做地图上。

初写这种贴子，其实也不知道自己到底做到什么样的地图。明确的是有两个点：首先是必须用图形；其次是色彩分明、对比强烈。这不仅是个视觉冲击力的问题，更是如此，能够明确表达出地形的差异，并通过这些差异，让大家更直观地感受到对地图的理解力。

随着地图越越多，自己对地理的理解比之前更深刻了，现在越来越多的以地图的文章开始在平台出现。有些在底图的选用上，还会与自己以往的地图趋同（大概是向我借借鉴的）。只是看过之后觉得，有些地方还可以做得更好一些的；另外这些年的写作，包括这次出，也有机会在这个方面作交流，发现专业领域以后感觉到了读者对“地图”的渴望，但地图要怎么做才能满足大家的需求，其实是有困惑的。

古人云“文以载道”，其实地图又何尝不能做到“图以载道”呢？在信息泛滥的时代，我能够承载丰富信息的地图能传千言万语。问题在于，没有一个模型来告诉我们，一张好的地图应该包含哪些类型的信息。今天在这里分享的，便是自己归纳的一点心得。如标题标题所示，我心中的理想地图该是一张“四维地图”。

既然推出了“四维地图”的概念，自然前面会有三个层次了。所谓“一维地图”，简单来说就是我们最常看到的平面地图。此类地图是各类地图的行政边界的标定，能够满足人们基本的的位置需求。

然而我们生活的地球并不是平面的，对于平均身高不超过200公分的人来说，地球表面的每一个变化，都可能造成巨大影响。如果用地球地图显示的话，它反映出来的信息，往往让人非常困惑。如此在平面地图上，你根本无法感受到“蜀道之难，难于上青天”的心情。因此，如果把“一维地图”升到“二维地图”的层次，就必须运用地形地图为底，将山脉、重要山口/通道定清晰，并把“三维地图”中作为流域边界，切割出一个地理单元，以影响地形形状对人类的影响。

以地形地图为底的，无疑极大的提升了地图的品质。只不过是这样，毕竟影响世界的，不仅仅只有山形水势，还包含气候、植被、矿藏等许多因素，以及种族、宗教、民族、语言等信息。就像如果不考虑湿度和温度的影响，就无法解释长城本质上是古代农业技术，由人类奔劳而成的“农耕线”的本质相同；同样，明白法、德、三国主体民族的渊源，就难以理解西欧的兴衰的历史。

现在我们明白了，想要更好的通过地图去理解这个世界，需要进一步地添加能够说明问题的自然、人文信息，将之升级为“三维地图”。当然，并不是说要把所有的各种信息都进去，这样只会让地图变成一个大杂烩，应该是根据制作地图的目的，包括所有辅助文字的内容可以选择。“地线”（而不仅仅是地理），这是我8年来一直在推广的一个概念。以地图线条的话，能够做到“三维地图”的程度，即以地图为基础，加入所有表述的自然、人文信息即可被称为“地线地图”了。如果再升华一点的话，我我们需要对绘图中已经构筑的三维地图，加入一条“时间线”。

“时间”对于地缘研究来说非常重要。一般半世纪，或者一个甲子是考察地缘变化的最小单位，我们可以称之为“地缘量变”。历史的跨度越长，可供比较的“地缘量变”就越多。有此于，在大历史的框架下，研究每一地图的历史、了解人与地缘关系变迁，是地图研究的重要手段。

具体到地图的问题上，加入“时间”信息的方式，除了在地图上标注定期的地名、政治边界、战争路线等信息以外，还可以在空白处进行文字标注，以帮助读者的思维进入特定时段。需要特别说明的是，加入了“时间”概念后的“四维地图”，并不能简单的归结为历史地图。就像我这些年来一直在沿着时间轴，一步步地推进全球区块的解读工作，本质并不是重塑历史。“时间”和“历史”在这里只是工具，一个验证平台。为的是总结、验证理论，为未来的发展指明方向。

写到这里，忽而想起小时候经常在书里听到的，对军师级人物的一句语句——“上天文，下地理；前知五百年，后知五百”。其实对于地缘研究，对于地图来说，何尝不是如此呢？下一秒即未来，一张能够将自然、人文、历史信息有机结合在一起的地图，你管它叫“四维地图”还是“地缘地图”，应该都能帮助我们了解这个不变的世界了。

温逸锦
