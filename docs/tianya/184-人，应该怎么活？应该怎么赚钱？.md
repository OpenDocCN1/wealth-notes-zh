


# 人，应该怎么活？应该怎么赚钱？

老忧乱侃

之所以发在经济论坛，是因为我要说的话很多都和经济有关——人只要活着，就一定和经济有关！

经济论坛也是天涯所有版块中我最喜欢的版块，相对宽松，观者的素养其实较高；最近开始受天涯论坛的一些影响，主要是负面的东西比比较多！按理，这时也正常，所谓的“岁月静好”是无需与人相交往，要说话往往成为“不平等”吗！

随着年纪增长，外界对自己的影响力越来越强，我认同题越来越回来，毕竟论坛自然就变成娱乐的一部分！我加了好多帖对经济问题的关注，现在已经逐渐进入普通人的世界，这在以前是不可想象的。

今天大家都对“通胀”“利息”“边际效应”等专业名词都能概知其意义，是社会的巨大进步。

很多事情，多了就成了“量茧成茧”，对个人来说未必是好事！

开了个话题，偶然自然知道龙头蛇尾的概率极高，但考虑到这两天就要出去转转，定然可以回避一些尖锐的提问，也就是释了！

楼主作为 70 后，在“社会战场”摸爬滚打二十多年，成功的经验是没有的，失败的教训却是足够的！

多少真的没有路了，或柳暗花明，或贵人扶持，或天降天运，安稳度过都是一种幸运！我老曾说过“人如果从 60 岁往回活，那可就不得了”，一个只有小学二年级文化的农民能说出般道理，惊为天人！站在 40 多岁的年纪，会暗暗一眼！

今天，我有话说！
