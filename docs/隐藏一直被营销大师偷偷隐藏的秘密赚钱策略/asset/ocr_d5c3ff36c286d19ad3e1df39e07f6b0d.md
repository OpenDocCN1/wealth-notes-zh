# 六、特洛伊木马:

现在人口中的“木马”是指病毒的意思，而“木马”一词来起源 于希腊的一个战争故事，希腊王率兵攻打“特洛伊”，10 年久攻不 下，最后天斌异禀的“奥德修斯”献上一计……

他让士兵全部上船，假装撤退，同时让工匠做了一个有轮子的，巨大的“中空木马”，让一队精英士兵藏于其中，然后把木马留在了 城墙外的空地上……
