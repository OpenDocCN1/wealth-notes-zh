# 二、设计成交主张:

打造一个无法拒绝的成交主张, 其实有 8 个步骤, 但是我认为你一下记不下来, 所以我决定跟你讲一个浓缩版的, 威力巨大, 只有 4 个元素, 请看公式:

主张=超级赠品+零风险承诺/负风险承诺+稀缺性+紧迫感

什么叫 “无法拒绝”, 就是说, 你一旦对你的用户说出这个主 张, 对方就很难抗拒, 就很想立刻与你成交, 为什么 会这样, 威力真 的有我说的那么夸张吗?
