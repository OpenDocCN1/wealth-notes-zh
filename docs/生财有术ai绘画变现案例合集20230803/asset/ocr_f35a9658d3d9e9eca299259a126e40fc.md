# 二、AI绘图体验营时期（新手）

不要觉得40元很少，它不止是40元，而是代表了，有人愿意为它付费。

# 1. 产品产生

有设计师伙伴看到了我卖的攻略，找到了我，说，我们来办个体验营吧，我帮你做设计和二改，她就是豆子，一个二次元鬼神文化爱好者游戏UI界面设计师。我还在文案改来改去的时候，她觉得差不多了，不想再墨迹了，直接把海报发到朋友圈了。这也是我参加生财小红书航海的时候，既然都是写图文，就用朋友圈练练手好了。

这个时候我有什么呢？

只有你看到的那两篇整理文章的水平，也就是说，你现在能卖40元，你就可以开一个体验营。

# 2. 产品宣发

体验营怎么招生的呢，不怕大家笑话，就是提前7天发朋友圈，告诉大家我要办一个一周的AI绘图体验营收银29.9元，帮助营内小伙伴体验文字绘图的快乐。

最初营内只有我的妈妈还有一个尝鲜的小伙伴共四五位伙伴，没有人来。但是我知道这个东西很吸引人，所以我坚持至少每天群里发一次预热，并且用群里的出图和攻略每天发一条朋友圈。尽管群内没人回应，朋友圈也没人互动。
