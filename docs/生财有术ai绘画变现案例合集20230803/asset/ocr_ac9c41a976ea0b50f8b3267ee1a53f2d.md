# **⑤我自己做了什么**

刘润老师说，所有的生意都是把“人”（消费者）和“货”（商品）连接在一起，同时你要知道“场”在哪里。我个人选择的场是小红书，货就是我制作的画。

我从来没有亦弄过小红书，纯粹小白一个，什么都不懂，我也不知道观众喜欢什么，我也并不清楚是否会有人喜欢我的画，我能做的就是对标，找到我自己感兴趣的号主，看看别人的思路，保持一直发。

一开始发了两周也一直没有流量，小眼睛基本不过百，点赞也只有个位数，评论根本没有。其实挺丧气的，也去问过天辉。告诉我在没有爆发前，号都是属于在泛流量的小池子里，没有平台不知道谁喜欢你的，没有流量很正常。要么蹭热度，要么保持一直发。

我自己倒是觉得先试试看，反正边学边做边思考，于是就是一直坚持发。直到有一篇小红书点赞过百了，突然觉得挺有趣了，正向反馈总算是来了，更有动力去坚持了。

同时也在开始想要做原创的念头，于是精心制作了poker系列， 但是效果很不理想。

因为平台的规则，它是一个流量池一个流量池向上逐级递增的，刚开始的小号，粉丝基数少平台也不知道把你推给谁，这个时候的推送就是泛粉，点开某个标签进来看看的粉。他们并不定喜欢你的作品，不看你的作品也是正常事情。但是我初期突破不了小流量池，无法获得大的推送流量，主打的原创系列，直接被这个随机性被埋没了。

天辉告诉我，前期这个阶段就是要追着流量走，哪里流量大，哪里有热点，就往哪个方向追，也就是要去蹭热点。先把粉丝基数堆起来，把曝光几率拉高，让第一时间看到你笔记的人，有更多想要点进来看的欲望，快速去突破初级的流量池。这样你的笔记才会有更大几率被更多的人看到，人多了，自然就会有喜欢你的人，形成一个良性循环。

在无人关注的阶段，要先追寻热点，快速起流量。

当你出现爆款时，追着爆款发，积累起垂直粉丝。

当你的粉丝多起来后，之前的爆款不新鲜了，这个时候再求变化。
