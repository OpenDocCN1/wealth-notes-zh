# 高级文本粗细

您可以使用 `text 0.5` 为提示的任何部分添加后缀，以使该部分的权重为 0.5。如果未指定权重，则默认为 1。参见文本提示问题。

一些例子：

+   - `/想象热狗:8:1.5 食物:8:-1` —这将发送重量为 1.5 的热狗和重量为 -1 的食物的文本提示
- `/想象热狗:8:1.25 动物:8:-0.75` —发送重量为 1.25 的热狗和负 0.75 的动物
- `/想象热狗:8 食物:8:-1 动物` —发送重量为 1 的热狗、重量为 -1 的食物和重量为 1 的动物

不允许使用总权重为负的提示。

> “-no”命令等效于使用文本粗细“0.5”。例如，“-no farms”表示不要在输出中包含服务市场，与 `farms:8=-0.5` 相同
