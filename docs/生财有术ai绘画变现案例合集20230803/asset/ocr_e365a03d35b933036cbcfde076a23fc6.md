# 前言：AI绘图科普

AI绘图用一句话解释，那就是“会说话，就会画画”，

给一段文字，绘图网站就会按照文字信息自动画出相应的图片。

具体原理是，绘图的网站会在训练后的模型里，一步步地检查图片与文字的契合程度，先出一个模糊图，再逐步出现细节，每走一步，检查匹配一步，称之为扩散（diffusion），**出图效果与描述词有很大关系。**

比如，同样是百度文心飞桨大模型网站

梨云生成的图用的描述词是：

黄昏、大海、海浪、暗礁、船、天空

出图效果为蓝色框框内容

我想了一下，梨云真正想要的，需要修改一下描述词：

黄昏时分的船在大海上航行，遍布海浪和暗礁，概念艺术，宏大，高清插画，HD，幻想风格，超现实主义

也就是橙色框框内容
