# （一） 一段好的提示词是什么样子？

# 1.思路

首先，我们要明白AI绘画是能将你脑海中的画面呈现出来的工具。那么你脑海中的那副画面是要描述？那是怎么样子的一幅画？画中具体有什么？是一个人嘛？是人的话，是一个怎么样的人？人的具体情况是如何的？TA长的什么模样？穿的什么服装？在做什么？

你可以把它理解为你在拍写真照是拍古风？动漫？现代？民国？描述词，就是围绕拍照的这个人来由你给他穿衣服，化妆。

设定好了主体人物人物，接下来，画面有没有背景？背景长什么样子呢？背景中有城堡？湖泊？还是其他？有什么特点呢？是黄昏下的海边，还是夜晚的森林？
