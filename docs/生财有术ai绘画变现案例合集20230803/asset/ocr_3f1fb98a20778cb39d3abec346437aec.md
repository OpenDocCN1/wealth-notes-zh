# 4. 如何看图推提示词

很多人都遇见过一个问题，我只是在抖音/小红书等平台看到一张图，觉得很好看，但是找不到它的关键词要怎么办？

①根据图片中的画面去“画廊”中寻找类似的图片，运气好可以直接找到原图。

②“画廊”中也找不到，那么试试AI识图，反推提示词。

③我没有现成的工具怎么办？那就自己来“看图猜话”吧！

怎么做？还是基于公式 主体+环境+前后缀

先去观察画面中什么是最主要的部分，有什么特征，先写下来。接着去观察整体画面的环境、背景中有什么内容，接着是加上识别的画风和一些常用提示优质画风的词语。

![](bbox=[0.26, 0.65, 0.48, 0.9])
