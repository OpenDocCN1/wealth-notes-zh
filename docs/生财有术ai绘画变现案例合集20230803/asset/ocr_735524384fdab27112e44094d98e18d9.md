# ## （三）如何运用AI

# ### 1.AI绘画会冲击谁

+   ①低端画师
②创意素材
③低端广告设计师

低端的一些简单的头像定制、人物图、同人图、创意素材，平面广告设计肯定是会受到冲击的，还有之前流行过的照片转手绘，随着AI绘画越来越强大注定是要被取代，这也是倒逼画师们、设计师们精进自己，越来越强，否则只能是被AI劝退。

# ### 2.变现的几个方式

①卖关键词
卖关键词已经在淘宝、咸鱼等平台屡见不鲜了，虽然价格低，但是量大依旧能赚不少钱。

②做教学课程、做社群
当你有了一定的技巧和稳定的输出能力，那么做教学和课程也是能够赚到钱的，卖铲子一直都会是门好生意。

③接定制
定制头像、图片、壁纸，SD工具上的私人模型，都是可行的。

④做平台
程序员做好前端，把已有的平台通过API的形式去接好，做平台也是可以的。这一块我没有这个技术，只能是说个大概。
