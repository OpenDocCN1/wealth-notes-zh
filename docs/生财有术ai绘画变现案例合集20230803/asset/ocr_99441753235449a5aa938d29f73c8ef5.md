# 五、AI绘图其他

只要是用到图的，都可以用AI绘图再想一遍。

AI绘图不仅能画现实中有的东西，也可以画现实中没有的东西。

芷蓝姐举的应用场景：动漫、游戏、比如批量生成纸片人老婆、画CG爱好者的各场面等都是可以的。

我目前打算以及在做的方向有两个，

+   - 一个是研究小书的爆款，试着模仿和拆解图背后生成的参数和描述词
- 另一个是深度优化自媒体人学习路径，最终效果是保存1篇目录文档，30分钟内熟悉相关信息，1小时能够进行个性化应用。

以上均为理想型，比较难，但我会试一试。

当然，应用也不限于此，我也会同步保持相关信息的更新。

AI绘图，对于我来说是一个从无到有的建立全过程，希望我的经历能够帮助到更多犹豫不前的伙伴们躬身入局试一试，至少在AI绘图上，你可以0金钱起步，像素级复刻，重走一遍我的路径。

当然，0金钱不代表0成本，投入的时间精力等都属于广义的成本，但容错率很高，失败了不会造成什么毁灭性的打击，多掌握一门技术，多一项能力。
