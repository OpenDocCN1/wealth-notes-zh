# (四) AI绘画到底意味着什么

AI绘画终究是一个工具，并不能完全取代画师，但是起码可以帮助普通人，用较低的成本去描绘出脑海中浮现的画面。

同时，他在高级创意人员的手中，成为了创意辅助者，可以快速的开启头脑风暴，生成草图，极大的加快了整个设计进度。

还意味着一个 “内卷” 的时代开启，普通人也拥有了一般画师、设计师的水平，倒逼从业人员研究新的生存方向。

说到底，个人觉得AI绘画本质就是光影的艺术，到了最后比拼的还是基本功和创意思路。比如艺术鉴赏能力，分析组合能力，对工具的掌握熟练程度。AI只不过是帮你快速把脑海中的图像呈现出来，然后给出很多方案去选择。现在有了chatGPT，有很多差距更可以被抹平。或许，AI这个工具不是用来追一张图的效果，而是从一张图拿到灵感去创作属于自己的作品。
