# 6、国术馆内的亿万富豪

提早打开的鬼门关

日复一日再一日。

李老板派遣的功课，也一件一件的给它解决掉但解决不掉的是心中那份找不到数据的虚无。

慌了。

慌的是，万一高版税泡汤——妈的，难得老板心情好调高版税！

乱了。

乱的是，答应老板的事情却可能做不到。

我是有责任的阳光男孩！（恶什么？）

完了。

完什么？

我家比较偏僻了些，附近只有住宅，吞一顿饭要走一段路，我很热爱走路运动！

汽车被爸开走上班，机车被老妈骑走串门子，我的古董脚踏车被误认破钢烂铁回收了，碰到不想面对的人事物，只要借口够合理、够美，心里都会舒坦好过，骗了自己也能唬过别人。

但！当我开启家里那扇大门时，我找不到任何瞎掰借口来让自己好过——「有缘人你好！」

彷彿听过的厌恶之声，从我家对面遥遥传来，穿入我的耳内。

我抬头一看，哗！不禁竖起双手大拇指。

「你在演戏吗？还是在偷窥？」我看得目瞪口呆。

达摩师傅站在一根木棍上，这根木棍插入电线杆上洞穴中，离我高度大约有三米：「你忘了我是国术师吗？有轻功的！」

这个死达摩，整身穿者仿达赖喇嘛死猪肝色的衣袍。

有病，在这种接近三十五度的大热天！
