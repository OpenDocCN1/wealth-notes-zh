# 12、在森林内被诱惑出超级成功学

男优动作细节解析图。

「你是不是要问我第四道问题？快点问，我赶飞机，差不多要离开了。」量

大也随手拿起桌上他带来的 AV 界成功信息。

「为什么你要诈骗你的顾客，说你可以解决任何企业问题呢？我有问你问

题喔。」说完这句，我叫龟蛋和达摩师傅说：「抄快一点！他要回家了，书本

要被收走了啦！」

「嗯，这点不能说，这是有关企业营销秘密方案。」量大师翻着书籍，指给

达摩师傅看：这个动作一定要记录。

喔喔喔，那就让我来自由发挥了：

成功致富要点：只要装扮成「大师」，随便乱读书上招数，并按照上面的致富

要点实施，收取超昂贵价格，企业老板就会相信、依赖一大堆蠢意见。

「量大师，请问你最后一个问题：你骗人的成功见证都怎样来的？」

「成功见证就是成功见证啊，我的见证有好几万人……不好意思，如果你

要问下去，是要付高额费用的。」量大师用很快很快的速度，把桌上的书籍一扫

而空，放进公文包里，站起来与达摩师傅握手，随后离去。

这个量姓江湖佬还是没说实话。

不过，只要我有笔、有纸，就能替对方倒出一切事实。

成功致富要点：与对方利益交换，让对方帮忙做伪证。

「我的精华部分都抄好了，你们也拿出来共享吧！」我写到手痛死了，在空

气中甩着手。

大家把笔记本放在茶桌中央。

龟蛋翻着我的笔记看着：「谋略，你记录得好少喔。」

「谋略啊，不是我爱说你，像老树盘根这种危险动作，细节很多，但我还

是照抄起来了。你看你的笔记好像东抄一点西少一点，乱七八糟！你的字体，

相信只有医生和乩童看得懂！」达摩师傅超级爱抱怨。

这时，达摩师傅和龟蛋对看一眼。

马上收起自己的笔记！

「你们狼狈为奸，不给我抄！」

我仰天怒吼！
