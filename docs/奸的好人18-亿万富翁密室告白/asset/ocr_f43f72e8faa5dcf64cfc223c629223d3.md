# 2、谋略的「热血」奋斗期

# 做回谋略

身处于小说工作室的我，也做过不少平常压根不会去做的事，譬如我不看漫画书，却要去书店找漫画来恶补；譬如我不说笑话，却要我收集笑话集锦；譬如我对风水毫无兴趣，却得花钱假装去算命，询问一些鸟细节……

哈哈哈！写小说真有趣啊，乐在其中！

我拥有男人的热血，面对所有李民杰交代下来的困难挑战！

放鸟屁！

虽然碎碎念及爱抱怨是我的天性，其实到最后我还是会想尽一切胡乱的办 法，凑成故事与剧情，连自己都不敢相信，我曾以不可思议的创意敲打着键盘，完成李民杰近乎痴心妄想的任务。

虽然常被退稿，也常被要求重写，然而，稿子完成之后，那些谩骂与吐苦 水的言论，就彷彿新陈代谢后的宿便一样被排掉啦，之后便等着下一个毫无头 绪、不知所云的挑战。

挑战我的青春年华时间！

挑战我脑中的 DNA!

因为我还没收到李民杰所安排的工作，当然有「美国时间」，带着愉悦的心 情写写以上这番心情言论。

但也就是说，当我收到工作室信件时，当下心情就很……很「那个那个」 了。

不会假装内心多有正义，不会装神弄鬼让自己很热血！这就是我！

# 写小说的正规方法

我依稀记得，教人写畅销小说的老师说，要塑造一位为目标而奋斗的男主 角。

但是我……好像违反了这样的标准理论，没为自己虚张声势……

因为我不是这本书的男主角。
