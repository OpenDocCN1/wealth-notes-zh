# 第二男主角—邻居兼炮友龟蛋（不好意思，应该是「炮灰好友」）

龟蛋的角色很特别，聪明中带有一点白目，但若逻辑思考一下，如果连龟蛋都能够大学毕业，那么那个教育制度岂不是……哦，那是题外话。

龟蛋的身材圆润，头形呈长方形，两头又有点尖尖，照这样看来，他应该不是人，而是外星人ET！如果这是一部科幻片，干脆就请外星人ET来客串好了。龟蛋的选角也就省了，反正他是第二男主角，不是女主角！

如果要用在线艺人的话，这个角色便非纳豆莫属，-我总觉得谋略也在暗恋纳豆，而特地为纳豆打造龟蛋这个角色。从过去的「0800」和「鬼屋」等台湾著名游乐园广告，以及一些综艺节目中，可以观察到纳豆这一个艺人的可塑性极高。纵使从综艺访谈节目中也可得知，纳豆在夜店的受欢迎程度是登峰造极的，不过这无损于纳豆饰演《谋略号一：亿万富豪密室告白》中可爱又白目，或者是白目得很可爱的龟蛋。

如果《谋略号一：亿万富豪密室告白》中的龟蛋可以留长发（这要问小说中的上帝谋略先生了），那么一个蘑菇头发型将很符合龟蛋本色。更登对的是，简谋略与纳豆的滴窝很麻吉（match，日语发音你懂不响啊！）。
