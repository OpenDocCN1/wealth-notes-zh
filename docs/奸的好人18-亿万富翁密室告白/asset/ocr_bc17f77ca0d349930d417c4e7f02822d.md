# 如何用手指展示力量

收到这则简讯时，将近中午，同一时间门外传来一声：「谋略！挂号！」

「谋略？哪有这样的怪名字，他爸妈也真是的。不好意思喔，我们家没这个人。」我老妈子站在门口和邮差说着。

「有！有！有！」我马上下楼箭步冲了出去。

「就是我，我是谋略。」我把右手举得高高。

老妈用死鱼眼看着我。

「很多事大人不懂的啦！你就先进去忙，这里有我挡着先！」我压低声音传给老妈。

「请签名，少年仔。」邮差拿着收据递给我签名。

当我正眼看他，感觉到一股寒意，这邮差戴着全罩式黑色安全帽，看不清楚底是何方妖孽。

妖孽来着！

「签好了，谢谢！」我抬头向他礼貌性的道谢。

他的安全帽正面对着我。（应该）

我也不落人后，双手插腰，学我老妈用死鱼眼注视着他。
