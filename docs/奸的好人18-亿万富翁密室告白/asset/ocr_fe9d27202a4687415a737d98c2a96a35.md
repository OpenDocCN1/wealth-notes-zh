# 李民傑董事長

「办不到！神经病，李民杰写小说写到疯了。」

我看着这封蕴含威胁成份的电邮，拿下眼镜悬挂在台灯上，揉揉了发酸的眼睛，眉头皱了起来不停骂着：「妈的！妈的！妈的！」

故事，就从这里说起吧。

我是平凡出版社「你家班工作室」编写员之一——简谋略。

每天晚上，我除了上色聊天室纯交友纯聊天，或者到各大专院校贴贴交友自我简介之外，就是用胆颤心惊的心情，去完成李民杰在信件中所提到的不简单任务！

（特别注明：如果没看过《神棍》的读者，不知道我说什么，请你购买一本《神棍》，以支持我这位参与编写过的作者，因为《神棍》是「你家班」的第一部作品，而我走上写作之路，首要的条件就是成为老板的秘密写手。）

在人世间，男人偷养牛郎的刺激也好，或者女人包养二奶的欢愉也罢，为了享受生活，必须尽心尽力工作赚钱。

工作意啲着成为卧薪尝胆的过河卒子，解决老板吐给你的烫手山芋问题，不然老板请员工来干嘛的！

但我还是以心有余而力不足的心情，敲了三个大大的字，回信给李民杰: 「不会写！」

掷地有声的三个字，加上一个怒气冲天的惊叹号，一目了然。

是的！
