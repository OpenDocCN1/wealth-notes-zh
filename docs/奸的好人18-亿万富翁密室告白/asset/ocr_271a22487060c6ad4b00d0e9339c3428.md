# 9、谋略看鬼听神的真实经历

不祥的预感：

妖术、巫术、法术、仙术……

很多人傻傻分不清楚！

了解的看「门道」，不懂的看「热闹」。

不要轻忽这江湖门道一点诀喔。我暗暗沉思：「如果这江湖戏法巧妙用于生意中的话……」

嘿嘿嘿。

这就是「乱世炼金术」。

如果各位觉得这玩意太邪门，可以不用经过我的同意跳过此篇（原本我不打算采用此篇，但良心来的！因为我的良心发作起来，谁都拉不住啊！)。

但是！

李民杰为了多提高几本书的销售量，就泯灭良知，滥用老板的淫威，逼我涂鸦上架。

真是业障、业障啊！

（附注：「如何写好小说」的书籍有教导：一定要有危言耸听的开场白，才会勾引读者更多的好奇心，继续阅读下去。他妈的有够瞎瞎扯的啦！)

一大早，我习惯和老妈坐一起在沙发上，看晨间新闻。

她是正经八百的武则天坐姿，而我是懒懒的手托下巴侧卧，摆出睡佛躺姿。

看早晨新闻这习惯，可能是因为我心系于国家大事的安危，连我老妈也暗中观察出来了。

（谋略按：钟杰克与李民杰读这一段说觉得好笑，我不知道他们是不是耻笑我。我开设脸书粉丝专页时不是说过：「各位善信大德双脚进入此地时，可以疯狂大肆留言，随性涂鸦。但请不要批评我，请不要指教我，男儿心是脆弱的……」吗？他们两人哈哈哈。表示什么？耻笑吗，妈的，迟早让你们知道我是真正关心国家的，请耐住性子读下去吧！我一定会把国家的阴暗解读成企业家的光明！)

所以老妈每次一打开电视，就是先看整点新闻。
