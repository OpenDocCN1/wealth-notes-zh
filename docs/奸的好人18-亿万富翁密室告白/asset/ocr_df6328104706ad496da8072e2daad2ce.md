# 13、哭笑不得，真相中的真相

「怎会这样？我看看，这电风扇为什么有电池装置！」

我把龟蛋的臀部搞到出血了！

龟蛋痛到整个人趴在瓷砖上，转头对我说：「你是天生邪星！」

我蹲下看龟蛋穿着一件很薄很薄的运动短裤，渗漏出血滴来，我马上脱掉龟蛋的短裤。

「干！你不穿内裤的喔！」我恶心地大叫。

「这种运动短裤不用穿内裤啦！快帮我止血啦！快快快！好痛！」他也七手八脚，帮忙把自己的短裤脱到最底。

这时。

最可怕的状况来了。

可以说是毁灭人性的一刻。

隔壁有一个我暗恋许久的女生，我都找不到机会和她说话。只有晚上倒垃圾的时候，能偷看她几眼，我就觉得人生不虚此行。

现在，这个女生站在我家对面的步道上，傻眼看着我。

而我正在脱一个大肥猪的短裤，而且整颗头还贴着对方屁股。我瞧见她对我摇摇头，随后立即走开。

「千千干干！」我这辈子什么都洗不清了啦！

我大叫一声「完了」，拿着脏抹布用力往龟蛋的臀部伤痕一甩。

「痛！你在干什么啦！」龟蛋双手握拳想打瓷砖。

「我的心比你更痛！」我一边看着门口，一边双手用脏到不行的抹布，上下挤压着龟蛋的伤口止血。

「谋略，他妈的！不要闹我了，这不是心脏，不要这样上下挤压，这样更痛！」龟蛋痛苦不堪，回头看我：「这是什么布？」

「抹布，擦电风扇的抹布。」我心不在焉说着。

「给我拿开！」龟蛋痛吼！

「一直流血，这样不行啦，我帮你叫救护车来送你去医院好了。」我站到门口，拿起挂在腰间的手机。

欧伊欧伊欧伊……
