# 11、用有色的眼光看正义之路

法官脸部终于出现一点无奈感，说：「这过程很复杂，年轻人不用懂。」

龟蛋趴在桌上，用唇语问我：「这位莫尔特法官避难就轻，不说清楚啊。你还要写吗？」

我也趴在桌上，以唇语回应龟蛋：「对我来说很简单啦，李民杰就是看重我这点，录取我的啦。」

我抬起头来，在笔记本里端正写着：

法官致富之道 6：

法官暗示说：一开始他与阿貽有交情，但看着社会趋势渐渐朝向阿涵兄，他马上翻脸不认人，为求在朝自保，就改判阿貽重罪。所以归纳起来致富秘技就是：要当一个墙头草、两边倒的人物。

「不行了！我受不了啦。」黑人保镖顿然狂性大发，马上、马上、马上打开扁平皮箱！

当下这一秒钟。

「干！我死定了！」我眼睛闭起来，紧紧抱住龟蛋大吼：「好兄弟，来世不要再相遇……」

「操！我要报废了啦！」龟蛋眼睛紧闭，双手抱着我大叫：「好哥们，来世不要当邻居……」

「老板，你刚刚血压升太高了，这里有降血压的药，请先服用。」黑人保镖从果皮箱里面拿起血压计，帮老板测量。

「老板，我帮你扎一下，让手指头流一点血出来，看看血糖指数，刚刚是时间到了，要帮你量，都被你制止下来了。」黑人保镖拿着血糖机帮法官测量血糖指数。

「老板，你颜面神经失调，不要说太多话。」黑人保镖很关注老板的健康。

「……简谋略……你刚刚说的什么杀手保镖？什么皮箱武器？」

我笑着耸耸肩。

龟蛋松了一口气，肚腩又跑了出来压着皮带了。

「老板，我们该走了，你不能太过操劳。」黑人医护助理打了一通电话，叫上面的人打开铁片栓。

我们跟随法官和黑人医护助理后面，一起上楼去。
