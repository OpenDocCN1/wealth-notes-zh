# 谋略是练武的材料

「不要踩！那可是价值连城的太空陨石！」师傅上前把我从石头上拖了下来。

「太空陨石？」我双手触摸这颗怪异的丑石头。我把鞋子脱下来，从鞋内倒出一些细碎的小石：

「哈哈哈……那这几颗是恐龙膀胱内的小结石，无价！」

「快点坐好，不要搞怪了！」

（拜托啦，到底是谁怪？）我瞥了他一眼，坐了下来。

我慢慢脱下上衣，边问：「师傅，你真的得过奖吗？」

师傅从抽屉拿了奖状证明书，伸过来又给我看了一次，「你看！」

「哇塞！你看看你的胸肌，真是练武的料。」师傅食指触碰着左胸肌，滑到奶头处。

我用尽力量把胸肌给硬了起来！我满脸通红叫给师傅看：「浑然天成！」

刚刚坐在大门口，听着里面说胸肌太大要被铁器撞击穴道的事，我已完全忘了。

「很好！百年难得一见的国术体格。」师傅食指滑过右胸部乳头，摇摇头赞叹着：「哇塞！你看看这个腹部肌肉，呈现王字肌的曲线。」

我坐着微弯上身，腰出力，让线条更加明显，连青筋也爆了出来。

「我的腹肌是有灵魂的！」我又叫师傅观赏我的腹肌，这时我趾高气昂起来。

「好！好！好！」师傅右手拿着夹茶叶的夹子，刺刺我的腹肌，左手摸着他脸上大把大把的落腮胡。

我又恢复一脸正经样：「我是肩膀痛，你要开始推拿了吗？」

「转身。」师傅如教官那样命令。

「你左肩膀痛吗？哇！背肌的线条也那么明显，简直是国术界奇葩！」师傅很兴奋的双掌贴上我背部。

「我不当鸡巴，我要当个轰动武林，惊动万教的小说家！」我转头，对师傅气势万丈地说。
