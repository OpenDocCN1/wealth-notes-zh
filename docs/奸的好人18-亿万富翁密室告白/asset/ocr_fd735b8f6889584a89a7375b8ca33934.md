# 自创派别的小说家——你有没有热血的创业精神？

别人说它是本恶搞小说，你就把它当成是恶搞小说来阅读吗？

那你的眼界太小，损失也太大了！

张大春先生在他的《认得几个字》里头提到一个观点：「看事情不能只看在一个点上。」

我想，这是为什么有人能够成功，有人却只能平凡；为什么有人能常突发奇想，有人却总呆若木鸡；有人能举一反三，有人却冥顽不灵的原因。

与其说它是本恶搞小说，我在里头看到的，是一个有潜力的小说写手，拔剑而起，自创派别，打算在小说市场里头杀出一条血路，轰动武林，惊动万教的奋力一搏；

我还看到的，是出版社老板的慧眼识英雄，愿意冒险栽培新人的热情，以及在书中反复宣传自己出版过的书籍，毫不掩饰地大量置入性营销的权谋策略；

更让人惊艳的，是它在冥冥之中鼓励所有有心从事写作的年轻人，大胆走自己的路，努力毛遂自荐，站在巨人的肩膀上，试图看得更高更远……

在这本书里头，你将一次学到创业的权谋，搞笑的功力，说故事的方法，微笑面对人生挫折的智慧。连我都想赶紧把自己构思的小说想法，透过邮件寄给李老板和谋略，看看能不能赌一把，一起搞出更大梦想。

你，还在等什么呢？

——搭讪教主郑匡宇推荐
