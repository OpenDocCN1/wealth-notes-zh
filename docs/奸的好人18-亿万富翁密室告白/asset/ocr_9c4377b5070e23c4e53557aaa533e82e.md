# 11、用有色的眼光看正义之路

# A 片女优也有爱国的情怀

「谋略，看A片算不算犯色戒？」

「少啰唆！昨天你鬼鬼祟祟的落跑……」

我被龟蛋的电话给吵醒，躺在床上睡懒觉的我，大型小叮当布偶的头趴在我的下腹部。

「好啦，你也少啰唆，你我都是犯色戒的同修人，你有没有研究过，沉迷了『色』的境界里，会怎样吗？」我感觉到龟蛋的声音有点紧张畏惧，好像急着我找一句可以自我合理化的答案，方得心安。

我怎么可能搬出合理化的答案让他好过，我头侧转，电话直接平放在耳边，我双手用力挤压小叮当的头说着：「你命在旦夕了！像你这种半生不熟的佛教界败类，触犯佛教中的大罪，名为『波罗夷罪』。」

「是喔，那会怎样啊？」龟蛋开始感到人生道路上的彷徨了。

「听说……下地狱之后，小小鸟会单独被黏在火烧铁柱上……」妈的！虽然是自己胡说八道，但也感到一种腿软的意境。

「是喔，算了！」龟蛋在电话另一头释放出一种绝望的磁场。深入到我耳里。

「算了？」我眉心挤在一起，小叮当的头再度被我双手用力挤压。

因由龟蛋一句诡异的「算了」，作为男人的我，感受到他一定有不能说的秘密。

「你……是不是暴霪狂的习性被逮到了？」我慢慢感觉事情有点不对，这个变态死宅男淫心作祟！

「你……是不是去、嫖、妓、了？」我想，他可能干了我想干但还没干成功的事。

龟蛋回答：「这是你潜意识中想做的事吧？我是说，我手上 有《性欲工房》、《名门菊花王国》的A片，同学借我的，我还没看。」

这时候，我不知道龟蛋的手在干什么。

「谁演的？」我懒懒的问，我尝试着再次闭上眼睛，睡着就算了。
