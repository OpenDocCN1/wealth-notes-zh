# 前言：如果我是名导演

钟杰克

李民杰发了一封很严肃的电邮给我：

杰克，麻烦你写一篇序文出来，这篇序文的方向是：（假如我是名导演）。然后你就说，这部小说、这个人物应该由谁来饰演，直接将对这部小说的感想与期待，全部都写出来。

我乍看之下，简直就是气炸了，直接把电邮给删除。冷静思考之后，又如小说中的谋略一样，把李先生的信件从电邮垃圾桶里拖出来。气炸的原因是，如果我是《谋略号1：亿万富豪密室告白》的导演，我根本无法为自己谋到任何福利，完全没有，一丁点都没有。

当导演的好处之一，就是……如……好像……我说不出口啦，难道要如广东话俗语所说的「画公仔要画出肠」（坦白直接，讲个明白）吗？这样对我也太残忍了吧。
