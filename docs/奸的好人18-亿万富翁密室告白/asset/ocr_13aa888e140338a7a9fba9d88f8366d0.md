# 话说当年勇

老大双手交叉于胸，看着左上方的鹿角摆设，回忆着「想当年」的陈年往事。

「想当年，我在当看门小弟的时候，跟随着老大，与敌方在某家餐厅贵宾室谈判油水区如何划分。对方准备的人马是一群参加过健美比赛的兄弟，块头之大，犹如西班牙斗牛一样勇猛，如果那些斗牛看这些兄弟使劲展现岩石般肌肉的时候，那些牛匹都会吓得纷纷转身回去低头胡乱吃草吧……

谈判过程中，在门外的我听到对方主子摆了一句：『这样不公平吧！』，我心中油然生出一股「谁敢对我老大放肆」的护主情怀，从门外单手拿起铁椅，便冲进去要解决对方主子！

当时自己的十多个兄弟都纷纷拉住我的手，老大看了我一眼，点了一个头，我双眼瞪着对方主子不放，死都不放的瞪他！瞪死他！

事后，老大从各角头、街头大哥那边，查询我这位小弟名号，猛夸我有种、有狠劲，这种顾主而牺牲小我的精神很少见，他便下令叫我追随在他的身旁。」

「哇！这真的有「狼」的气势，难道你不怕那群健美兄弟把你给折成两断吗？」我捏着牛肉片乱撕一通放在盘子内。

老大双手握拳放在茶桌上，我感觉他似乎有点发抖：「会！我怕死了，当时我瞪着对方主子不放的原因其实是：『我吓傻了』。因为对方二十多个健美兄弟都准备冲向我而来。」

我把堆着牛肉丝的盘子推给了达摩师傅：「那你为何有勇气单枪匹马冲进去？」

「喂！牛肉片好像被轰炸过一样，看起来都没口感了！」达摩师傅随手拿了一块支离破碎的牛肉丝展示给我看。

我对他不加理会，继续问老大：「你为何敢冲进去呢？你是不是都做好准备要轰轰烈烈大干一场吗？」

「是的！我都准备好了，前天晚上上我已经偷塞大红包给当天要一起出门的各位兄弟，希望他们能在我冲进去的时候，赶紧用力拉住我！」老大笑了出声，继续说：「在江湖上，有钱好办事啊！」

我愣住了！

我拿起笔记本起来，头脑已经无限期当机。
