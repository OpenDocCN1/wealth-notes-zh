# ## 与大师共享喷饭饭局

「师傅！你是几天没吃饭了？慢慢吃，但不要吃太多，我每餐都有预算的。」我拿着筷子，看着师傅正在猛虎扑兔吃饭的模样。

「什么预算？」饭粒沾满了达摩的鼻子。
