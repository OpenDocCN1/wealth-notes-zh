# 亿万富豪密室告白

◎封号：黑道界成吉思汗
◎拿手绝活：泡茶「解决」江湖事

我和龟蛋低头看着那些破碎的瓜子壳。这时，龟蛋贸贸然点出一个很有智慧的哲学问题。

「谋略，你看大佬喝的瓜子壳，是不是散发出一种杀气腾腾的伟人气势？」他很小声的悄悄说着。

我的弄种程度比龟蛋更胜一筹：「废话，我早就知道了！不只杀气，这些瓜子壳隐藏着一股黑道义气的风范！」

我很有礼貌地站起来立正问道：「请问你，不，您的……（干！不太敢问）『旗下事业』有哪些……？」

「坐下来聊，我还要请教你嗑瓜子的技术呢。」老大亲自帮我再倒茶，我也吸了一口气，干了吗，不太敢随意呼吸。

龟蛋现呈死人样，脸部僵硬看着前方乱问：「老大，你有没有杀过……」

我立刻用手盖住龟蛋嘴巴，我可不想死在这个全世界没人知道的地下密道，人间蒸发是无法名留青史的啊！

「我经营的业业有：『商业融贷』、『科学精算管理』、『保安』、『出口贸易』、『药物管理』、『生意合股』、『爆破管理』……等等。」

老大不急不徐地缓缓道来他所经营的重大产业，看我喝完茶，又帮我续倒一杯，然后我又假装不怕烫的一口干完。

我再度很有礼貌的起立弯腰用敬语请教：「请问可以解说那些产业是什么内容吗？麻烦您了，谢谢！」

这次换我帮大佬倒了一杯茶，八分满。

「烫，小心慢喝。」我恭敬对老大说，其实我是希望，老大从我恭敬的态度中看到我权谋手段式的提醒。

「我嘲？帮我倒一杯吧！你这个过桥拆板的大小眼。」达摩师傅把茶杯高高拿给我瞧——他没茶了。

我装作没看到、没听到。
