# ## 3、假借民意图谋己利的臭老板

# ### 高手过招鬼见愁

◎谋略功课

寄件者：“kofflee kofflee” kofflee@gmail.com

收件者：smsmsmsn@yahoo.com.tw

谋略，你虽然已陆陆续续完成工作室一些作品集，但我不知道你是瞎写内容还是胡搞剧情，好在有杰克来帮忙审阅修改。虽然你呆呆的，但还是有点努力的心，不然，我早就学川普名言对你说：“You are fired!”

你是可以自行创作小说，不过……

你还记得我的冠军书《有钱人的偏方》里面写了一段话：「带你到书店，蒙着双眼，双手在商业或心理励志类的书架乱摸，你也一定会找到一本教你如何成功、教导如何变成有钱人的书」吗？

书中我也写了一段故意破坏商业书法则的话语：「很多商业励志书和上过很多课程的人，都一直在找寻变成有钱人的法则或定律，结果一一尝试之后，人生还是没有改变……」

就是因为有钱人把一些不可告知的黑暗秘密，锁在保险箱里，根本不会写出来。

好了，你就去搜集那些富豪地下真实黑暗秘密，改编成小说公诸于世。

《偏方》一书我是写心态调整，暗中破坏成功学，那你的功课就是把诡诈的手法给写出来。你不要给我写得和市面上教导读者如何成为亿万富翁的言论一样！不可以给我抄袭！

我开始脸红脖子粗，不厌其烦从上往下阅读一次，再由下往上浏览一回。「你这个李民杰喔！还不一样是工作室的作业！哪来自己的创作啦？」

我往后靠拢椅背，手持着原子笔不断敲着桌沿，望着右前方的台灯，不禁感觉到老板是不是……

想搞死我？

他这样就是假借民意、图谋己利的行为！
