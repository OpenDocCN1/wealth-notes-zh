# 10、政坛的黑心告白，商场的良心解读

# 真的假不了，假的真不了

访问过国术馆过师傅所介绍两位「亿万」富豪（？）后，我心中实在有种不是滋味的滋味——真的假的两种想法，一直天人交战。我边看笔记，边整理思绪，手指飞快打着键盘输入文字，累了就躺在地板上休息。

睡着、睡着，眼泪与口水流湿地板。

我一拳敲在地板上：心中极度不服气，想到这个出版社的恶魔老板，从没见过他有过好心肠；他写过十二本书，本本都由我和钟杰克在背后当写手，李老板这卑鄙小人，文章到他手中，名字一换就变成他的著作。每次完成一本著作，他就哄骗我说，下一本书一定全力追捧我，真的假的？每次都许下这样的承诺，但每本书都没放我的名字，就连个鸣谢都没有啊。

正如这本书，要我冒着生命危险在地下室访问「亿万」富豪，李老板说这是为了给我出版属于我自己的作品《谋略号一：亿万富豪密室告白》，我高兴不到三天，就警惕自己——小心被他这种没良心的恶魔欺骗。这个李姓恶魔还告诉我，他一生中最大的使命，就是拿起魔术棒对着灰姑娘随意一挥，打造独特美丽的伪装。

他还说会为我在台湾办签书会，靠，真的假的？

这恶魔，还担心我交不了稿，一天传二十六则简讯给我，内容都只有两个字：

加油！

（妈的，我简谋略不会受你蒙骗啦！）

看到这些假希望，我忽然感到心情郁闷，跑去脸书上发发牢骚，用婉转的口气传达我对这个恶魔老板的不满。我说：清道夫的责任是什么？看到地上有猫猫狗狗的排泄物，即使你心里有一千个、一万个不愿意，但你还是得扫地。

没想到，老板竟然和我同时上线，他看了我的脸书，假意留言附和。

然后，马上传来一则手机简讯：

谋略，你要问自己两个问题：一，你每年有没有一个小变化？第二，你够拼命
