# 第一男配角—国术馆达摩师傅

至于达摩师傅，小说里描述他是一位穿着浅灰色袈裟，头顶光亮无比，有茂密落腮胡，大约五十五岁的老头。

曹查理？当然不可以—查理哥外表堂堂高大威猛，不适合那么不正经的角色。

黄秋生？好像肚子饿了，想要吃叉烧包的感觉。

不如就选发哥，因为看了发哥在《孔子》中的古装造型，觉得发哥演达摩师傅必定有过之而不及，但又好像有一点浪费人才。《亿万富豪李老板我肯定请不起，还是算了啦!）

其实我还在正考虑两个喜剧大前辈——吴孟达以及罗家英。

两者除了共同参与多部分十分受欢迎的喜剧之外，还有一个共同点——都跟周星驰闹翻。

这两个喜剧大配角，曾长期与周星驰合作，相信很多观众一看到他们的脸，就会会心一笑。关于这一点，有学过NLP的人都知道，这就是心锚。当他们做出风趣表情，或说出一些搞笑对白，你就会笑，所以日后你看到他们，你自然会想起什么。

大声一点，我听不到啦！

版本一：如果用吴孟达，他曾经和周星驰合作无间，可谓周星驰身旁的超级大龙套。他是出镜率最高的配角，合作时期最久的演员，最具知名度的绿叶。况且，吴孟达更在早期的金庸电视剧演过丐帮长老一角，这样一来，在订造型方面己可以省下很多功夫，连面试也可以免了。

版本二：如果用罗家英，他在《凌凌漆大战金枪客》中的表现，以及在《西游记系列》中饰演的唐僧角色，让人印象深刻。《西游记仙履奇缘》中的Only You，更是经典一唱。如果选了罗家英，就能凑齐三个有酒窝的男主、配角，果然是酒窝界的壮举。
