# 要来的始终不会不来

卡在树枝上的风筝飘下来，掉落到这个小孩的头顶上，我拿起风筝来看。

上面有一段丑丑字体写着：

今天不来，后悔终生……

国术达人：过师傅上

他上次说认识男优，会不会来真的？

假设这次介绍男优，我是不会好奇啦。

但如果男优带着女优同来呢？

干！

「上面的！今天是国术馆的年度女优日！」我抬头对龟蛋呼喊着。

我不等你了啦。

「碰！」

我眼睁睁看龟蛋从天而降，比出名不用替身的成龙大哥在《警察故事》中，

从六层楼高悬的吊灯上顺着柱急速滑下的场面，还要叹为观止！

「真的假的？快！快！快！」

龟蛋以酷似忍者蹲姿降落着地，接着往前以百米冲剌的速度跑。

「色情狂，你还跑得真快！」我看者他往前冲，连兄弟我都不顾了，果然是

我认识的龟蛋。

龟蛋忽然停下脚步，回头看着树下的小弟弟：「那个小弟弟，干嘛躺在树下

睡觉？」

「小弟弟醉了罢。我猜年少轻狂又好奇心过重，偷喝你刚掉下来的啤酒，

酒醉了吧……」龟蛋眼眉毛撑高惊呼：「这个小幼童才大约七岁，就那么成才，

练习喝酒喔！」

「快啦，我刚在树上看到有人来了！」龟蛋又马上冲出去。

「废话，你看到的不是人，是啥？」我跟随在后，也小碎步跑着。

「屎你个鸟蛋！」龟蛋大惊失色的拿着贴在机车上的黄单子……上面写着违

规停车的红字。

「原来你在树上看到交通警察喔！」我惊觉这排路上压根没人停车，只有我

们这台胆大包天的机车。
