
# 国术馆女优日

「算了，佛经不也常常说：徒弟们，放下吧！」我说得很轻松，因为罚钱的不是我，站在朋友道义上，假装捏捏龟蛋的肩膀象征式安慰一下。

「放个你屁！」龟蛋气冲冲的上车，我眼见不对劲，赶紧自动坐在后座，否则他一定会失去理智，不顾我而自行驶去。

发生事情前，你我都能一口正面积极的好话。
发生事情中，才能看到最真实当下的自己。
至于发生事情后……
你我又忘了教训。

《金刚经》说，过去心不可得，现在心不可得，未来心不可得。现在你最想点那颗心呢？

「谋略，今天真的是国术馆女优日吗？我在树上有听到你的呐喊。」龟蛋骑着机车，头又往后靠，问我问题。

「嗯……应该是，因为达摩师傅说没来会后悔。」我在逆流的风中回答他的问题，不小心吞了好几口夹着小虫子的冷风。

我看着后视镜中的龟蛋，好像笑嘻嘻的样子，舌头还舔了一下上嘴唇。

他会不会只听到「是」这个字？

到了国术馆，超级兴奋的龟蛋又横向停车，钥匙不拔马上冲进去。

而我呢，当然龟蛋在开门的瞬间，从旁钻进去。
龟蛋算是替我开门啦。

站在大铁片旁。

「龟蛋，你看我领子有没有拉好？」我转身看看身上有否不整齐的地方。

「你穿圆领T恤，哪有领子。」龟蛋把裤子衣服重新塞好在裤腰里，系紧皮带，似乎用尽力气挤压着皮带下的肥肚肉。

「谋略，我头发有没有被安全帽压扁？」

「嗯嗯。你理个大平头……扁个屁啦！」我用食指戳着龟蛋的头。

龟蛋手汗狂流，双手来回的摩擦：「我好紧张喔！」

「夭寿喔！我也心脏蹦蹦跳！」我抓着龟蛋的手摸我那壮如石块的胸肌，心脏地带有不规律的强烈余震。

「你在这种四处没人的地方，抓我的手摸你那里，你有何居心？」龟蛋很正经的问。

「没事啦！」我打开了大铁片，双脚踏进去，与我美丽的女优天使见面时间到了。

「哦哦哦哦哦，我来了，死达摩师傅。」我站立在楼梯口，发出泰山大驾光临的口号。

龟蛋把楼梯五步当做两步往下飞奔。

「干！」龟蛋看到我站住，他来不及反应，撞到了我。

被撞击后，我往前走了几步，龟蛋也顺着力量贴了过来。

「龟蛋，你现在下面顶着我屁股，又是什么意思？」我拉长脸，回头看着龟蛋。

「喔喔喔……对不起！」龟蛋马上弯腰退离说：「你干嘛忽然在楼梯口停下来啦？」

「龟蛋，你看……」我的脸再惨悴不过了。

「这两位，是谁啊？」龟蛋肚子上的肥肚肉，好像有股失落感的被挤出皮带上沿了。

「过来坐，给你介绍。」达摩师傅拿着木槌敲着桌子，「碰、碰」响着。

「刷！」我和龟蛋同时听见上面的大铁片好像自动上栓。

龟蛋不留情面的捏着我右手臂：「你这个死谋略，你不是说女优日吗？」

「其中一位应该是女优……的父亲吧……女儿等等就会来了！」我说的话只是过度的奢望。

我和龟蛋坐了下来。

# 患有变装癖的卷发老人

「谋略我问你，这位老人家为何戴着贝多芬的灰色卷毛假发啊？」

「龟蛋我也问你，这位老先生干嘛穿着好像博士毕业黑白相杂的长袍服装啊？」

我和龟蛋面面相觑，问来问去。

「这位是被司法院和法界誉为『台湾包拯』的最高法院法官，他很有钱。」达摩师傅拿着木槌敲击我和龟蛋的头说：「肃静肃静！」

「妈的！很痛！」我和龟蛋双手揉搓着头皮，我继续问：「那旁边这位黑人穿着西装笔挺，是干嘛的啦？」

「应该是保镖，电影上好像常看这样的人物出现。」龟蛋问着达摩师傅：「今天没有泡茶，也没有茶包喔？」

「今天犹如来到法庭，不宜泡茶吃点心。」达摩拿着木槌想敲我的头，被我中途双手夹击到。碰一声，保镖拿着黑色大皮箱用力放在茶桌上，眼睛盯着我们两位年轻人看。「对对对……这位可能是总统级的杀手保镖。」我眼睛看着黑人保镖回答龟蛋问题。「但在台湾，总统保镖群中好像没有黑人啊！」龟蛋也凝视着黑人保镖。

「应该是从泰国请来的保镖，泰国人也黑黑的。」我继续提供可说具有专业素质的答案。

龟蛋慢动作转头看着我：「为何请泰国人？」

「笨！你这个死龟头，泰国人最厉害的就是泰拳，四肢都可以当成杀人灭口的武器，尤其是攻击大象！」

「嗯……是保护大象吧。」龟蛋眼睛无神的看了我一眼。

「我最喜欢长相如外劳的武打巨星Tony Jaa演的『拳霸』！他的招牌招式并不全是泰拳，而是融合了巴西柔术、柔道、跆拳道、体操、成龙式的功夫等，不知道是不是因为融合那么多的拳路，所以他能在空中多停留好几秒……实在是不简单啊！」我用超慢的速度转头面对龟蛋，嘴巴却一口气念出托尼贾功夫的精髓。念到快要断气了！

「你刚说的四肢当杀人武器，为何不是五脏？」龟蛋仔细地问，眼神看了我下盘一眼。

「龟蛋！我这本小说，是连我老板李民杰的一岁儿子小李子都可以看的，不要讲到情色话题！」

「请保持严肃！」达摩师傅拿着木槌当家法，往龟蛋的头直下打，龟头顿时肿成猪头。

我眼见情势不对，赶紧双手过去护住龟蛋的龟头。

「靠！这次更痛啦！」龟蛋双手揉着更用力，脸部肌肉都挤成一块：「你干嘛中途抽手啦？」

「喔，我只是想看看这次达摩师傅的力道如何。」

「贱！」龟蛋边揉龟头边对我咆哮。

「闭嘴！」达摩师傅木棍拿着高高的，识相的龟蛋马上鼓起嘴巴闭着嘴。

# 神秘的杀手皮箱

第四位出场的亿万富豪简介：

- 不知名的法官
- 年龄：五十二岁
- 专长：运用各种管道，收钱替对方办事
- 司法明辨度：
  1. 完全以死法规为准则（没贿赂金时）
  2. 完全以灵活变通度为守则（付出少量贿赂金，可以压低罪行）
  3. ……、（付出庞大贿赂金，可以完全脱罪）
- 自我要求对外口号：清廉！责任！无私！
- 生存手法：哪个政党势力大，就往那边倒！

「请问这位好像被火烧焦的黑人保镖，皮箱里面是什么啊？」我尝试询问以满足旺盛的好奇心。

法官左手按住皮箱，提醒保镖先不要打开：「还不是时候。」

「两位年轻人，你有什么问题，可以对我发问。」法官连说话都面无表情，和丧尸的脸没两样。

「好的！谢谢你，尊敬的法官大人，让我想想看……」我站起来对法官弯个腰敬个礼，马上坐下，我也怕被法官误会我藐视法庭啊，所以又把话吞进肚子里。

「简谟略，你猜里面是什么？」龟蛋眼珠飘移到左眼角，小小声的问我。

我眼珠飘移到右眼角，用他妈的没种音调回答龟蛋。

「这里面一定是保护元首的武器。开关应该有五百万伏特的电击棒，打开开关时，电力可能会强到漏电，而电昏自己。」

我现在的回话再正经不过了。

「听你放鸟屁！自己都电晕了，哪能保护元首啦！」龟蛋像在骂我不懂，但又憋着不笑。

「你对战略毫无研究！自己都快被电昏了，坏人一看马上吓到腿软爬回家，这是顶级的武力恐吓招数！」

「谋略，你连电击棒都有研究啊，你真行！」龟蛋在茶桌下翘起肥油油的大拇指称赞我。

「里面一定有一把枪界中最威的左轮手枪，这把手枪的后座力强到让整个人瞬间双脚离地往后退，如果撞击到墙壁会马上晕死。」我觉得，我不当一名枪械解说员，真是太浪费我的才华了。

龟蛋双手在在茶桌下竖着的手指，从拇指换成了中指：「你嘴里放狗屁！这样保镖不是自己先挂！」

「达摩师傅！龟蛋对你不敬！」我拉起龟蛋的双手对着达摩师傅。

「他妈的雪特！竟然敢对师傅不礼貌！」达摩师傅举着木槌，重重击到龟蛋的天灵盖。（谋略老师教学：天灵盖就是头顶）。

「吼，『很痛』啦！」龟蛋低头摸着头顶，边笑着说：「你也会骂外国语言，还给我中西合璧喔。」

法官在旁边『噗嗤』笑了一声。

我就是喜欢龟蛋苦中带笑的性格。

可能这也是一种低等动物的另类智慧吧。

「其实里面有一个武器是最泯灭人性的武器——法鞭！」我的脸部呈现关云长的威严感。

「你是说在日本 A 片中 SM 对方的鞭子吗？」龟蛋头脑尽是这些不伦不类的攻击性武器。

「你的见识太浅，法鞭的鞭头为眼镜蛇的蛇头状，用两条粗麻绳七七四十九交叉编制，用力一挥都啪啪作响，其威风凌厉，令妖魔闻之丧胆。」我抽出裤腰间皮带双手拉紧着，一幅「滚开！让专业的来！」的气势。

「你是没有吃神经病药喔，那是吓鬼的，有啥鸟用？」龟蛋有气无力，想说我的不是，又不敢说太多，可能顾忌到我不请他吃麦当劳吧。

「你头脑还没完全发育，这种鞭子不打则矣，如果打到敌人的身上，会震怒敌人的情绪，产生一种想与你同归于尽的士气出现。」我边摇头扁着嘴边说着。

「你以为现在大学生有那么好唬弄吗？都一起死了，还保护个啥屁！」龟蛋已经打哈欠了。

「你不是当事人你不懂，敌人找保镖一起同归于尽，主子不就可以当场活命了吗！」

我用手比着一把无形刀割自己的脖子，散发出保护主子的义气与决心，这正好符合了关云长所散发出的「忠义」之气。

「谋略！你对军事武器真的有透彻的研究，黑瓶子装酱油，真的看不出来喔！」龟蛋在大腿旁边翘起大拇指。

我拉拉我的圆领子并对龟蛋点点头表达谢意。

「你们研究好了没？」黑人保镖把黑色扁平皮箱踩在脚下。奇了！这个黑人保镖又怎知道我们在研究。我听他的华语真的不太好。「到底你们俩是不是硬要逼我们的大法官在听你们胡闹鬼扯吗？要不是我们的法官修养好，早就……」达摩师傅作状举着木槌，要往我们的天灵盖攻击。

「等等，法官大人，我有问题要问。」我立而起，及时阻止达摩师傅无情的攻击。

「法官大人，我很好奇，你为何要戴莫扎特的假发和博士毕业服装出庭啊？」我随便先从外型问起，既然他对装扮那么讲究。

「戴白色、灰色假发和黑色长袍，可以使人显得年长，所谓世事洞明、人情练达，裁决便容易让人信服。」法官不苟言笑回答我。

我翻开这几天都在使用的致富秘法笔记本，再次纪录：

法官的致富之道 1：
这位法官暗示人前要一个屏样，人后要另一个屏样，这叫做装模作样伪装术。

「法官啊，贪污是不是可以赚到很多钱……就像你……」

龟蛋问到一半，保镖已经拿起扁平的皮箱放在桌面上准备打开，我马上用皮带套住龟蛋的嘴。

我压着龟蛋的头，替他说：「不好意思！对不起！」

法官对保镖说：「放下吧！」

我松了一口气。双手抓着龟蛋的双耳，希望他能清醒点：「你不要乱说话啦！他是法官啦！有钱判生，没钱判死的法官啦！」

法官脸部依然没表情说着：「收钱办事叫贪污，收钱没办事叫诈欺，我两种都不触碰。」

我翻开笔记本下一页写着：

法官致富之道 2：
这位法官暗示，他两方面都经常接触，收了钱一定要办事，收了钱没办事，则是要看谁给得少而定，想要稳赢，就要叫对方学着多付费，这叫做款项越高，胜算越大。
附注：我真是个破解对方言语的天才！

「法官啊，你会不会打麻将，输钱多还是赢钱多啊？」龟蛋也学我站起来说完话，鞠躬敬礼坐下，我想龟蛋害怕保镖打开扁平皮包拿武器对付他吧。

「不太会打，却幸运的很少输过钱……可能因为我打麻将的频率不高吧。」法官终于笑逐颜开，深陷的法令纹旁还露出浅浅的酒窝。

龟蛋这次聪明了，问出重点。

我翻开下一页笔记写着：

法官致富之道 3：
法官不明着说，要假借打麻将暗示对方故意大量输钱给他，这是一种收取金钱的好方法，要借由某个休闲管道，输入贿赂款项，这招叫做借尸还魂吸金法。

龟蛋再次起立，问着法官：「你赚的钱，是不是都来自法庭上的被告？」

在旁的保镖看着法官神色，马上又抬起扁平皮箱放在桌上，双眼像牛铃一样大的瞪着龟蛋。

龟蛋马上弯腰，伸手轻触着皮箱外壳不让保镖打开，并说着：「学校老师和我有问题一定要问，不要放在心里面，否则会得内伤。」

「没事、没事，放下去吧。」法官很有威严，果真一点表情都没有，说话没有语调高低差异，这让我联想到电影中的机器人配音。

我察言观色后得到一个秘诀，马上写下来：

法官致富之道 4：
法官用脸部表情暗示——商场向上与人谈判，从头到尾要有一张死人脸，还要有机器人说话的声音，不带一点情绪，如此铁定会赢。
附注：我有一种很奇怪的感觉，这本黑暗地下致富术会秒杀销售，因为透露太多实情，瞬间爆红！

「法官大人，有一个案件是有人强暴鸭子，为何你判强暴者无罪呢？」我为了充实笔记本的内容，继续拨云见日、开门见山询问。

「根据法律上的条例：被强暴者若没有反抗之意，被告者是无罪的。」法官脸部一点情绪都没有，这招很难学。

我低头问龟蛋：「鸭子要如何反抗？翅膀都被抓住了。这是天大的冤情！」

龟蛋也低头回我说：「对啊，这个冤案如果没有包公来审，鸭子一世冤屈！」

我忽然有了一种灵感，迅速翻开笔记本继续写着：

法官致富之道 5：
法官暗示他接收被告的贿赂，我猜法官有卖一些假古董，透过人脉管道，提示被告用超高额价钱来收购他的古董。这阴招老是抓住对方弱点，大量借机取财。

# 与死神擦肩而过的瞬间

「喂！龟蛋你看我们的达摩大师，双手摸胸睡着了。」我用下巴指着达摩师傅。

我看着龟蛋——贱笑！
龟蛋看着我——贱到出汗的笑！

我继续为我的读者粉丝谋福利，继续大胆问下去：「阿贬兄捞钱，当时你为何迟迟未判，现在又要将阿贬兄关到身上长虱子？」

黑人保镖迅速看着法官的脸，又很快把扁平皮箱拿起来，迅速打开。

「慢着、慢着，让我讲讲话……」法官单手压住已经打开三分之一的皮箱。

当下，龟蛋整身冷汗。
当时，我冷汗整身，还有点尿急。

龟蛋在桌底下伸来左手给我，我帮他把脉是否还有跳动。
换我把右手伸出去给龟蛋，让龟蛋帮我把脉，确定是否还有规律跳动。

# 11、用有色的眼光看正义之路

法官脸部终于出现一点无奈感，说：「这过程很复杂，年轻人不用懂。」

龟蛋趴在桌上，用唇语问我：「这位莫尔特法官避难就轻，不说清楚啊。你还要写吗？」

我也趴在桌上，以唇语回应龟蛋：「对我来说很简单啦，李民杰就是看重我这点，录取我的啦。」

我抬起头来，在笔记本里端正写着：

法官致富之道 6：
法官暗示说：一开始他与阿貽有交情，但看着社会趋势渐渐朝向阿涵兄，他马上翻脸不认人，为求在朝自保，就改判阿貽重罪。所以归纳起来致富秘技就是：要当一个墙头草、两边倒的人物。

「不行了！我受不了啦。」黑人保镖顿然狂性大发，马上、马上、马上打开扁平皮箱！
