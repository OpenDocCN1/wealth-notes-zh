# 1、他会是我生命中的导师吗？

「改天！」、「下一次！」气得我马上切断这个情色聊天室。

（李民杰叫我在书中宣传他的课程：「权谋兵法道」，我只好在这里偷偷将真相写出来。）

我的心情马上转换，改去别的聊天室，从另外一群红颜中找寻「知情人」，这就是李民杰在《有钱人的偏方》一书中所教导的：「要懂得选择放弃！」

（老板说，这是广告他的书籍最好的方法：《有钱人的偏方》）

此时我很无奈，左掌拖着脸，懒懒对侨中说：「神经病思维的诅咒啊，你说一段话，我尝试用神经病方式回你一段话，当你说我很像神经病的时候，应该就接近成功了吧！」

在练习对话时，侨中老是离题，和我东扯西聊，感觉他好像无心练习，难道他比我捷足先登，踏上放弃之路吗？

但最后我才发现，他的功课是另外一本书！

他妈的逼！

我还是继续在死拉着侨中，和我练习神经病的思维对话……

最后我渐渐发现，侨中脑袋瓜里的思维压根不用练习，摆明就是顶尖神经病的逻辑与想法。

边听他发疯，我边敲着作业，边寻觅聊天室知音人在何方……

# 三十分钟的的精神病交流之旅

哈哈哈！

蓝天不负努力人，我在此感谢拥有精神病基因的侨中，让我顺利在电话中完成作业，感恩神经病侨中！

「传送！传送！传送！」我用食指不断狂按「信件发送」钮，回信给李民杰，对着秀出「传送中」三字的屏幕，比出饱含阳刚气概的三寸中指。嘿嘿嘿！老子终于写好了。常听智慧者言：「当日落西山时，就是面临吞噬灵魂的黑夜。」按下「传送」的霎那间，我以为棘手的问题过了，误认为迎接我的会是万里晴空。谁知道，接下来发生的事竟然会是……
