# 《谋略号》将会是让你上瘾的毒品

写短短的段子笑话，只要你捉摸到模式，不难也不易；

拍一部搞笑喜剧电影，难；

表演一场脱口秀或相声，在台上滔滔不绝说足两个小时，让听众从窃笑到大笑，很难；

画出图文并茂，有连续故事性的笑话，超高难度；

写一本长篇恶搞小说，难上加难。

金盛完稿后，我为了做一个实验，分别将稿件寄给中国大陆、台湾、香港、新加坡、马来西亚等地的二十五位朋友阅读，以询问他们的意见。结果，不同文化、数个国家与地区的人都一致认为，这部小说每隔三五页就会让你大笑到昏倒，换句话说，这部小说还未面市，已经有二十五个人大笑到昏倒——呵呵，这当然是超夸张的形容啦!

意思是说这部小说，未上市前所做的实验，就已经非常成功了！

写屎尿、性话题、恶心、粗口的笑话来令人发噱，已经算是不简单了，但谋略的故事，是透过文字描述，让你在黑字白底，没有声音、没有图像的情况下，仅仅透过剧情的起伏转折，人物的极端滑稽对白（这些对白已经接近唱双簧了），就足以令你开怀大笑，不用天才来形容他，你还有什么形容词?

这部恶搞爆笑、怪笑、毒笑、黑笑揉合而成的小说，是会让你上瘾的毒品——这个人肯定就是简谋略，记住这个人的名字，帮忙大力推荐这个新一代的爆笑天皇。

读完这部小说后，我、李民杰和钟杰克都有一种感觉：很怀念周星驰当年的电影。

——刘敏慧（平凡图书出版社发行人）
