# 12、在森林内被诱惑出超级成功学

# 谋略解开怨恨心的无上密法

什么「你家斑工作室」？

坦白说，这个工作室名字根本就是老板李民杰取自李姓的谐音而强加上去的：「你家斑」作品系列—《神棍之遗失的记忆》面市前，老板还特意用 98% 的「诱拐」手段，哄骗我为他写「你家斑」的介绍词。

在你家斑小说工作室这段日子，唉！

想到就心酸了。

常常被老板李民杰刁难，许多麻烦的工作都交给我们做。

这个工作室，我应该将之形容为「李民杰刁难工作室」。

他在脸书上吹嘘自己是出版界的金手指，问题是：他出版的书，到底有哪一本比得上《哈利波特》？既然比不上，这金手指之说，又凭什么来鉴定呢？

说到在工作室写小说的过程，有时我会偷偷到脸书上抱怨好几下，或在计算机前骂无数次的脏话，骂完后，也就乖乖的回到自己写小说的岗位上，然后认真敲打文稿，反正被老板骂也不会死，骂老板他也不会痛啊！

有气度的老板当然是肚里能撑船，大人不计小人过啊！（这段文字是特地写给我老板看的，事实上被骂的人不会痛，也不会死，但肯定李民杰知道后一定会很生气、很愤怒，嘿嘿。）

这样私底下暗渡陈仓，技巧性的互骂，这就是工作上的礼尚往来啊。

至于找寻亿万富翁的秘密小说这档事，是我从头干谯到现在，骂得最彻底、骂得最体无完肤的一件棘手工作！

但一到晚上，我通通都忘了那些白天被骂或者被刁难的辛酸事，可能我是无可救药的乐天派、投机分子吧！

我想，乐天派的重心始终不外乎来自——

没错！

找寻良朋益友，就是我乐天花心的来源。

我打开计算机。
