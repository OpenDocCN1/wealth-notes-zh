# 4、怀有冲天大志的无间道作家

# 高人一筹的置入性营销

九把刀的小说里，潜移默地把彰化八卦山的大佛观光景点给营销出去，头脑很聪明，我想大佛会在功德录上狠狠记他一笔。

我也来模仿一下，试试看把我家乡基隆的名胜古迹也给推销出去。在小说中偷偷摸摸的发扬光大，让「基隆有谋略真好！」这个响当当口号流窜街巷。

嗯！写定了啦！

彰化八卦山有大佛，基隆中正公园也有观世音顶天立地，但这样了了无新意，写下去可能会被告（模仿？抄袭？），所以先不请观音现身好了，虽然观音和大佛本是同根生。但基隆地区也不是省油的灯！不写观音娘娘就黯淡无光了 吗？才没有这回事！

除了顶天立地的观音娘娘外，还有——「基隆铁路街」。

铁路已经不再是铁路了，重点在铁路附近有一条著名的烟花街巷，俗称「公娼街」。

从日据时代发展至今，当日离乡背井、只身前来北部打天下的英雄好汉们， 全都在这里，洗涤、打通他们生理上的额外筋脉。

内心藏着一颗敬业的心，却夹杂着郁闷的情，扛着任道而重远的十字架， 为了让基隆地区再度红不让，踏着昔日好汉的步伐，感受抛「头颅」洒「热血」 的狂放，此时的我现身于这条历史繁华的公娼街。

值得！值得！

（谋略附注：也许你们会奇怪，为何只有观音娘娘的照片，却没有铁路街的照片呢？理由是，我在那里拍照时，遭某位黑道人物的扶持，他说这部小说出版之后，要免费派送送这条街所有的妓女，而她们会小心阅读，看里头有没有被我偷拍的照片，有的话，就……惨了。如果你们真的要看看，下好写电邮给我。)
