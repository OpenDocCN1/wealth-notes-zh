# 5、国术馆的奇人达摩师傅

# 早起的虫儿被鸟吃

凌晨三点四十分，抱着大型小叮当布偶，我奋力挤进沉睡状态。

在床上翻来覆去，睡不着就是睡不着。

你以为我还在思想浸淫那位被马克思称为「计件工资劳动者」那样出卖肉体的甜心儿？

不了！

很痛，但不是心痛没瞧到有风尘味的裸体，而是左肩膀隐隐作痛。

嗯嗯……不能算隐隐作痛了，是「明日张胆」嚣张的痛——我是一个作家，李氏垫座下的御用写手，我知道「明日张胆」嚣张的痛不是可以这样乱用的，希望大家不要骂我，因为我的老板会将这种错用文字，当作是有趣创意。

管他真的还是假的，反正在出版社眼里，卖得不错就是好作品。

整个懒趴在小叮当布偶背上磨蹭的我，一直注视着闹钟，居然祈求赶快天亮，赶紧去看医生，不然我勇猛的左肩必然废掉！

第二天的早上七点三十分：

「妈！我打篮球跌倒，肩膀痛，要去看什么科？」我双手握紧拳头出尽力气，坐在马桶上大号。

「以前我海痆你老爸时，他好像都去和平岛的国术馆治疗啦！」这个令人发指的语气，像幽魂般传入正在等待「发泄中」我的耳里，忽然感觉老妈在神气什么似的。

「瘦弱不堪的老爸被虎背熊腰的老妈狂扁，还能撑到现在……嗯！这个国术馆一定有效！」

我怀疑，肩膀的内伤间接导致结肠蠕动功能减退，进而导致我排泄不畅。

我坐在马桶上苦等，无聊之余，边刷起牙来边读书。

出了厕所，拿起饭桌上的早餐。一口塞入一片抹着不知哪种动物的奶油，口中灌入老妈准备好的仙人掌汁：「嗯！」

不能再等了。
