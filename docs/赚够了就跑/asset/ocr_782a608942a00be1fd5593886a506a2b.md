# 對抗人們心中根深柢固的觀念

我從來不需要質疑人面獅身對於政府的法規了解多少。他年紀比我大，比我更德高望重，當他說出建議時，你最好洗耳恭聽。我非但沒有告訴他不必擔心這些公司會有什麼問題，或是他們可以很順利地應付政府修改法規的趨勢，反而非常認真地思考他說的話。我開始問自己，到底漏掉了什麼，或許我和這個產業貼得太近，也可能我並沒有很客觀地檢視眼前的證據。

我決定不要再讓自已繼續當醫療管理產業的啦啦隊長，最好開始撰寫一篇報告，深入探討產業所面臨的問題，尤其是政府法規對這個產業可能形成的衝擊，然後預估這些問題對未來的獲利到底有什麼樣的影響。
