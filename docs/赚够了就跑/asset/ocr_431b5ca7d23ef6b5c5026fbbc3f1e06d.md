# # 第一次買畫就上手

進軍藝術品市場

一九八五年八月五日，奧黛莉生下了我們的兒子，一個漂亮、六磅十一盎司重的小紳士。同年十一月，奧黛莉被醫師診斷罹患了乳癌。這個打擊，就如同我們在一九八一年失去第一個孩子一般沉重。

但我們也因此更加確信一件事：人生在世，要及時行樂。在接下來的春、夏季裡，奧黛莉決定把家全部重新裝潢。她打掉牆壁、放進了一個新廚房、重新裝修浴室、把所有窗戶換新，並全部重新粉刷。這次整修，花掉大把的鈔票，但我並不介意，我仍然是冠軍操盤手，仍然能夠賺得比花得快。

事實上，我正準備要花更多錢。
