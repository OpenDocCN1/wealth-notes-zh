這份報告很可能對我們兩個人的事業產生永久且具有毀滅性的影響。沒有人想看負面的研究報告。信託部門需要能幫他們解套的報告。他們會把報告放進檔案中，一旦股價下跌，就拿了出來說：「看吧！寫這玩意兒的傢伙比我聰明，薪水也比我高，我是看了他們的報告才買了這檔股票的。」

此外，我奉勸你離人面獅身遠一點。人面獅身很想、也很有能力毀了你。為了你自己，好好想想吧！

# 第⑨堂課

# 別靠小道消息，因為它會讓你就沒力量

我很喜歡說自己是一個完全不靠小道消息或謠言來操作的人，因為利用謠言來操作，達不到了。

我認為想要在市場中成功最重要的一個基礎——努力工作。努力工作使你堅強；當你依靠小道消息操作時，一點力量也沒有。

通常當你聽到一則小道消息時，已經慢了一步，而且手中不會有足夠的資訊。如果股價下跌，你就一點退路都沒有。在智能上你將會形衰弱，而當你衰弱時，將處於最容易受到傷害的環境地。和每一個市場中的玩家一樣，我也免不了因為聽了市場傳言而吃虧。
