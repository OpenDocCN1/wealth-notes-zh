# 失敗，總比什麼都不做好

父親是家中四個孩子中的老大。祖父母是隨著家族從東歐逃難到美國的移民。在一九○年代早期，祖父在康乃狄克州紐海文市（New Haven）當裁縫師，他一針一線辛勤工作、努力儲蓄，但從來沒存下多少錢。

家中真正有主導權的人，其實是祖母蘿絲。她擁有一間糖果店，並決定讓我父親進大學就讀，希望他在日後能夠成為一名專業人士。身為長子，我父親受到最深的期盼——能把家族帶到更好的境地，把美國夢帶給家中每一分子。

父親的確盡過最大的努力，卻沒有達成家人的期盼。畢業於雪城大學（Syracuse University）的他，拿到畢業證書的那一年是一九二九年，所謂的美國夢已經變成了美國噩夢——他遇上經濟大蕭條。直到一九三八年和我母親結婚之前，他和其他數以百萬計的美國人一樣，都過著沒有長期正職的日子。
