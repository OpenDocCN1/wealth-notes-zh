# 你告訴我，我在上廁所⋯⋯

我對這個狀況早已心知肚明，不禁回想起當初在一九九九年夏天我第一次到亞斯本度假，決定創立沙伯林納合夥公司後，和從布朗克斯（Bronx）來的波奇（Bogey）之間的會談內容。

我在波奇門外等了將近一個鐘頭，心中不是很痛快。我希望盡快回去繼續交易。但是當你開始經營一個基金時，就得乖乖去找其他在這個領域中有經驗的人，求他們幫你介紹一些有大爺們來投資基金。

幾天之前，我才打了一通電話給艾萊澤（A.Z. Algo），他是沙伯林納合夥基金及沙伯林納海外基金的結算公司研究部負責人。艾萊澤曾經答應要自掏腰包出錢投資我的基金，所以我認為他會是一個很好的介紹人。〔當然可以啦，馬丁。〕艾萊澤對我說：〔我和波奇是好朋友，而波奇一直是個很好的介紹人。

但是在心裡很清楚地重拾健康是當前我必須全力以赴的第一要務。如果操作基金將使我的身心無法維持在正常的狀態下，我就必須放棄這些基金。

我沒有辦法享受這個度假機會，我還是得讓基金保持運作。

我買了一部筆記型電腦和一部傳真機帶到度假地去，並且利用亞斯本的各處電話亭下單交易。

再一次，我們租下山腳下的那幢度假小屋；但也再一次，我還是無法停止交易。

在我們的計畫中，這次的假期應該是在空氣清新、氣溫涼爽怡人的山中度過的，遠離紐約市區的喧囂和市場所帶來的精神壓力。
