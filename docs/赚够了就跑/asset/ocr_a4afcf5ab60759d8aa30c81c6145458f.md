證交所掛牌股票最後成交價上漲或下跌檔數的差異值。我的朋友庫克發展出幾種用這個股價淨變動指標為依據的操作策略，這些策略應用在現代化的程式交易中相當有幫助。例如，一個非常極端的負面指標，像負一千出現時，常常就會是空頭走勢中反手作多的最好時機。因為過於極端的負值代表市場中出現了過於迅速的賣盤（可能是由突發的新聞或是程式交易所引發），在這種狀況下，市場很可能出現強勁的反彈走勢。情況反過來時也適用，當這個指標值為正一千時，通常是由電腦程式式執行大筆買單所導致。等這個程式買盤結束時，市場很可能出现一個短線上的回檔。另外一個交易上的小技巧是當D JIA開高，而TICK值為負二百時，這通常代表股市整體的賣壓較重，DJIA只是受到少數幾檔股票的支撐而暫時走強，所以你通常可以在這個時點作空。

# 3 短線操作指標（Short-Term Trading Ideas, TRI）

主要是短線操作工具。它的計算方法是取以下公式的比值而來：

TRI = （上漲檔數／下跌檔數） ÷ （上漲成交量／下跌成交量）

如果上漲股票的成交量比下跌股票的成交量大的話，TRI指數值將會小於一，如果下跌股票的成交量比大的話，則TRI指數值將會大於一。當TRI指數值低於O．八時，就顯示市場整體力量比較大；反之，如果TRI指數值大於一．二時，顯示市場空方的力量比較大。這個指標可以幫你了解市場是不是處於強勁的多頭或空頭當中。
