# 一、熟悉某一领域业务的人才

这类人主要指的是公司运营人员，这类员工与公司业务关系不大，但又是公司运营必不可少的，如财务、人力、法律，在很多地方可以帮助公司省去很多麻烦，这类员工的价格往往有公允定价，各个水平的人才有明确的价格，公司可以根据自身能力选择。但对于您这种规模的公司，建议您去诸如软件上找一些熟练工，硬件可以不要要求过强，只需要把事情做好就可以了。

# 二、业务团队执行者
