# 第六步：第5天，收单会

收单会放到周六或周日举行，因为周六日是家长小孩都休息的时候。收单会很忙一
定安排好人手，各司其职。营造出：欢乐、喜庆、激情的氛围。目的只有一个，让上
门的人不能空手而归。

+   1. 选课补尾款。

+   2. 增加活动曝光度，群发活动链接，可抽红包一次。

+   3. 带小孩的让其参观学校或上10分钟体验课+评测课。

准备工作：

+   活动横幅、易拉宝。

+   礼品区、抽奖区布置（抽奖？）

+   物料准备（收款收据、收款码、选课表、音响、话筒、投影等。）

+   咨询接待工作人员安排。

+   咨询资料（学校价值体现内容册、升级套餐内容、老学员相关资料）
