
我在知乎引流了有5万粉丝到公众号，5块钱一个粉丝，相当于我透过知乎赚了25万的潜在收益，虽然知乎给我带来的实际收益只有1万。

因为我没有上面这个思路的话，几年过后，你会发现效益也相差很大，我最多可能就引流个几千人，相当于少赚了20万的潜在收益。

如果你是在做小红书B站，你都可以尝试一下在视频放个钩子，但要注意平台是否允许，今天的内容就到这里，后面可能会再谈一下我在小红书和B站放过的钩子。

## 一、拍摄口播视频的常见问题

- 1. 剪辑问题，剪辑不流畅，留有停顿气口，声音过大或过小。
- 2. 语速问题，本身语速或后期加速过快，有吞字，听不清（如果没有字幕更雪上加霜）。
- 3. 画面问题，如过亮过暗，加奇怪的滤镜，画面较模糊。
- 4. 眼神问题，眼神跟着提词器走，或紧盯一个地方。
- 5. 语气问题，语气不自然像念稿子。
- 6. 表情问题，面部表情僵硬，面无表情或笑容不自然。
- 7. 场景问题，背景太单调（如白墙、纯色窗帘），没有空间感【当然如果你的表现力和内容极强，这条也可以忽略】。
