# 如何鉴别真实性

+   - 粉丝和人设
- 赞粉/回复比
- 波动性
- 评论

+   - 评论账号假：机刷评论（评论账号非真人号）
- 评论内容假：真人互赞评论（从内容维度可以判断）
- 评论量假：评论量大于赞藏量（社会讨论类文章除外）
