注：以上测试出图均来自“画了个画”小程序，目前的AI绘画技术主要是基于Diffusion这个技术来的，只是框架和源码模型不同。各种工具的玩法其实差不多，大同小异。基础的写作理论都是通用的，你既可以用于 画了个画，也可以用于SD，还可以用于Midjourney、NijiJourney，当然也可以用于Novel AI。

总结： 根据公式 主体+环境+前后缀

然后将你想要的内容套进公式里，每一项都进行丰富，就可以得到一个好的提示词

# 4. 如何看图推提示词

很多人都遇见过一个问题，我只是在抖音/小红书等平台看到一张图，觉得很好看，但是找不到它的关键词要怎么办？

+   ①根据图片中的画面去“画廊”中寻找类似的图片，运气好可以直接找到原图。

+   ②“画廊”中也找不到，那么试试AI识图，反推提示词。

+   ③我没有现成的工具怎么办？那就自己来“看图猜话”吧！

怎么做？还是基于公式 主体+环境+前后缀
