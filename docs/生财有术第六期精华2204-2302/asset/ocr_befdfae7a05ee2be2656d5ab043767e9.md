# 1. “汽车代购”是什么？

老纪的「豪车毒」，大家或多或少应该都在抖音等平台刷到过。

那么为什么我们这类车贩子中间商的存在能给客户购车省钱，同时还能赚钱呢？

我先在来给大家梳理一个汽车销售的大致框架：

从汽车厂家直接拿货的叫一级经销商（4S店），从一级经销商拿货的叫二级经销商（分销商、零售商），汽车代购其实就是二级经销商，俗称汽贸，就是和很多家的4s店进行合作，汽车来源主要是来自于当地4S店或者是来自于外地4S店。

一般一级经销商（4S店）为了做批发业务，普遍会给二级经销商一个比正常零售价格（4S店销售就是正常零售价格）低一些的价格，保证二级经销商的利润。

举个栗子：一台车A正常零售价格是20万，4S店给二级经销商的价格是19万，那么如果二级经销商给客户19.4万，则相当于客户少花了6000元购车，二级经销商赚到来车价里的4000元。
