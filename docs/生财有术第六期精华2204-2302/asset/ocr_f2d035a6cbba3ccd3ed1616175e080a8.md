后面可以加上ASO、CPL的板块，曲线救国可以做游戏联运？

后来确实也对接了闲玩等做CPL的游戏内容。结果发现做出一个平台的样子真的很简单，但是要运营起来，要做起来，很难。创业中不确定因素太多，变化也比计划多，想象能曲线救国，可能就真的曲了。（这部分没有故事，只有事故）。

但是路都已经走到这里了。只能接着打磨下去，基于自己拥有的资源去做迭代。

# ## 2. 转换思路，继续前行

通过复盘，我们发现其实完全可以换个思路，因为本身就是渠道团队，有技术，有运营，也有审核单子的客服，更有线下运营经验，那不如做个CPA平台工具好了，解决这些拉新工作室渠道、交单、审核等一系列问题，同时给他们做赋能，平台资源对接完全免费，平台也免费用，我们只是收取部分服务费和会员费用。

回到产品本身呢？市面上自己有开发团队技术团队能够做这样APP产品的，主要是做积分墙和悬赏平台产品为主；

那做CPA拉新充场项目的呢，基本上都是到处买个源代码就换个皮上了（主要是招商赚钱），或者是拿来做加盟的一个背书而已（因为很多这类型的平台都是从我们这对接任务），并没有真正从行业痛点去为行业的推广者解决问题。

所以这就是我们的一个差异点了。把平台看作一个工具：一个提供给做线下APP拉新行业推广人员的推广工具。因为我们本身就在行业多年，行业痛点、行业需求这些我们实在是太清楚了。
