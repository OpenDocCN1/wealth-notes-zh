# 整店曝光

我在西湖、太湖、等各种湖开了10家店，每个店铺门口每天路过1万人，我整店曝光**今天就是10万**。

而影响曝光的就是你的这个链接，以及这个账号是否有权重，系统给你曝光，是基于你的数据表现好，系统尝试给你去做推广，再举个例子：

+   A，今天曝光1万人，进店1000人

+   B，今天曝光1万人，进店100人

思考点

你是平台方，你愿意给谁更多曝光？

谁能帮平台留住客户，显然是A，那如何让店铺进去就引刚才的大长腿女孩的故事了，把主图做成浏览同类产品中最吸睛的那个。

④ 浏览

西湖边开着的这家店铺门口经过了1万人，装修的很好，吸引了1000人进入，这变成了你的**浏览数**，也就是进链接的数量，这代表生意进门了，那这1000个有几个成交，要看你的内功了。
