# 一.家电清洗这个行业到底是什么？怎么赚钱的？

家电清洗主要是以清洗油烟机，空调，洗衣机，冰箱等家用电器的家政服务。目前还是有很多我不知道，家电是有专业的清洗服务的，容易以家政保洁混为一谈。

两者的区别性质非常大。我从以下这几个方面分析：

| 家电清洗 | 日常保洁 |
| --- | --- |
| **工作内容** | 主要清洗家用电器 | 主要打扫家里的卫生 |
| **专业性质** | 需要一定的专业技术能力 | 专业性不强 |
| **服务人群** | 更广(客户自己取代不了) | 小众(客户自己也可以) |
| **工作人群** | 年轻，中年男性为主 | 中老年女性为主 |
| **复购** | 半年或一年一次 | 一周或一个月一次 |
| **飞单** | 容易控制 | 难以控制 |
| **公司模式** | 自营为主 | 中介 |
| **分享裂变** | 容易 | 很难 |
| **sop标准流程** | 容易执行 | 难以执行 主观性比较强 |
| 单个师傅服务的最高客户每日增长数 | 8个 | 2个 |
| **单位小时师傅时间薪资** | 平均70元一小时 | 平均35元一小时 |
| **单位小时单个师傅公司利润** | 平均50元一小时 | 平均15元一小时 |
| **每日公司单个师傅利润营收值** | 300元以上 | 120元 |
| **场地** | 有或无都可以，前期完全可以没有，除非想做培训 | 无 |
| **机器在未来是否会替代人工** | 完全不可能 | 不能完全替代，但洗地机，扫地机器人，擦窗机器人，软装清洗机等可以影响订单量下滑。 |
| **风险抵抗能力** | 自营家电清洗公司可以购买保险 | 中介性质的保洁公司购买不了保险 |
