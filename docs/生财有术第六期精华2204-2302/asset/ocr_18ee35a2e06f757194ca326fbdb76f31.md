# 如果我知道自己会死在哪，我就不会去哪里——查理·芒格

# 【1】先学习如何失败

1、无脑跟风：什么火就去追什么，完全没想明白自己为什么要去做这件事情。适不适合自己

2、不懂平台玩法：不了解各个平台的游戏规则和基本玩法，不了解平台调性和内容爆发的底层逻辑

3、不懂自己：做自己没有积累的项目，难坚持，没有结合自身原有的积累优势，选了喜欢但不了解的领域，结果每天就是为了数据去更新，越做越没劲。

4、不懂借力：坚持自己试错，不找标杆学习

5、不懂规划：完全没有规划，就听别人说小红书现在特别好做，红利很大，什么都没想清楚，也没有商业思维，然后就直接入场了。没有以终为始，没有完整的商业模式，导致流量来了之后，无法变现。

6、沉迷自嗨：没有用户思维，只想满足自己的表达欲，自我感动。
