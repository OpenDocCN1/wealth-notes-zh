# ## 七、建立壁垒

我们主要从三个方面建立壁垒。

# ### 1. 知识产权/图片

开发的产品卖爆之后，我们会及时去申请专利和拍摄图片，然后把线上的产品图片全部换成自己的网图。

这样的目的有两个：

+   * 防止国外的网红、律所投诉我们侵权；
* 如果竞争对手跟卖我们，专利和原图就是我们限制同行的独家武器。
