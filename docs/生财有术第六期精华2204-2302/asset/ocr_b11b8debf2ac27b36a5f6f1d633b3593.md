# 01 我给自己店的定位

关键词：产品集合店 多元化变现 增加附属收益 降维打击

我开的这个店主打品牌是徕米，一个广东的本土品牌，这里讲一下为什么我不选悦刻和柚子那样主流品牌？或者是自己创一个集合店？

打差异化，像我们这个地区的悦刻、柚子合在一起都有20多家店了，主流品牌可以说是烂大街了，就算再大的品牌也会被稀释流量，形成一个狼多肉少的局面，选一个差不多的品牌而且这个品牌在这个地区的门店比较少就更容易给客留下记忆点。而创一个集合店太麻烦，直接在门口贴上你还卖什么品牌就完事了，店铺的品牌方也不会管你什么的，反正给他打了招牌就行了～多元化变现买电子烟的都是什么人？不用想都是年轻人而且消费能力还不低，不然几百块钱一只你也不愿消费啊，去过酒吧的圈友应该知道，酒吧的那些小妹妹基本人手一只，年轻人还喜欢什么？潮牌啊！那不就可以和我们的现有潮牌业务融合了吗。

# 降维打击

1.价格战

品牌店铺受品牌方管控不能乱价，那我们进货的悦刻、柚子，这种大品牌因为我们不是他们旗下的店，我们就可以不用统一这些产品的零售价，可以低于他们市场价的10%去卖，形成价格优势（不要低太多不然会被打）
