# 八、如何解决家政公司最大的痛点，飞单问题？且他们乐意还愿意把订单往公司送？

很多朋友在了解家政公司项目的时候，都说到一个问题，就觉得这个家政公司事业开展不下去。

运用下面几个方法，就可以基本解决飞单的问题，可以不依靠**SCRM**私域管理软件（这个在之前的文章中有提到这个软件的运用）

在今年的公司运营中，我们发现无论公司在初始阶段还是在上升阶段都可以用这个方式。这个方式可以解决员工飞单问题，而且解决了订单裂变问题，还抵御了同行的价格战问题。

这个方法需要三个要素组成：工作手机+工资薪酬比例提成制+群SOP等方式可以放心的跟同行打价格战，因为你的利润空间只是降低了一点，因为订单大多在你手里，师傅也做不了反抗。

3）群sop，就是信息员将客户和师傅的工作手机微信号拉入同个群中，进行订单维护，及促发客户分享裂变，客户再怎么加，也只能加到师傅的工作微信。
