# # 一、用“爱”找到你的驱动力

在亦仁的收藏夹里，他分享过《<span style="color:#1084d8">人生有两种驱动力</span>》，一种是<mark>vision（愿景）</mark>，一种是<mark>pain（痛苦）</mark>。

他说：“能做到<mark>vision driven</mark>的很少，但适合<mark>pain driven</mark>的人很多；大多数人因为有痛苦，而改变。”对我来说，“<span style="color:#1084d8">爱</span>”或是“<span style="color:#e64646">恐惧</span>”就是我的原始驱动力。
