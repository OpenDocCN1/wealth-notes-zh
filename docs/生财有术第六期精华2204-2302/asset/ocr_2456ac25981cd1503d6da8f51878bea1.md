# # [精华帖](170赞)一封给一时冲动想辞职创业的人的劝退信

作者： 咏含Hellen

日期： 2023-02-23

hi，大家好。

我是咏含Hellen，13年经验设计师，1年自媒体创业。

去年我经过了职场裁员离开了十多年的职场，决定开启自媒体事业，一年收入16w+，在创业中经历了小红书爆文变现带来的喜悦，也经历了情绪低入谷底的心路历程。

总之，在这个1年的过程我对自己怀疑、不坚信，贪恋职场的舒适。反复折腾又去职场上了2个月班，今年再次离开职场，我又重新开启自己事业的新篇章。

这次我摆脱了纠结不坚定的情绪，对自己要做的事业充满很强的一种精神力。

这种精神力来自我清楚了自己要做什么？成为什么样的人。

我想把我过去的一些经历分享给大家，如果大家在职场中有萌生不想工作了，一冲动就想辞职创业的想法。

我想过去一年我经历的18点总结会有一些启发。

这是一封创业劝退信。

劝冲动不够坚定的人，劝一遇挫折就心如死灰的人，劝没有自知的人。
