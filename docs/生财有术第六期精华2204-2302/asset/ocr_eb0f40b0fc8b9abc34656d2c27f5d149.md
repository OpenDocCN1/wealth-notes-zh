# **6.平台区 别化运营**

刚刚说的唯一指标，在其他平台也是一样的，比如知乎，我定的唯一指标是：以回答**问题数量为唯一指标，头条运营我定的唯一指标：以踩到的关键词为唯一指标（做SEO流量），每个平台的运行机制都不同，只要抓住其核心，就能区 别化运营，这一点，只要研究一个平台的slogan就明了了。**

知乎的slogan是：有问题就会有答案，所以切入的唯一指标就很简 单的——“做好回答”

今日头条的slogan从“你关心的就是头条”改成“看见更大的世界”，前者是你关心=兴趣推荐，后者更大的世界是加注搜索市场，现在，你发现头条在搜索这个板块做得很优秀，这也是我做头条定的唯一指标的理由。
