# # (精华帖)(323赞)我单人和珠宝厂合作引流，0粉丝从快手起步到月盈利 10W 的经历分享

作者： T拿铁

日期： 2022-04-12

抖音上什么火就拍什么，先快速积累粉丝，然后再找供应链带货。比如抖音的爆款剧情比较火，我前期就通过招募群众演员，翻拍爆款剧情号，迅速积累 10W+ 粉丝，后期转型钻石供应链直播带货实现变现。

今天我就来讲一下具体是怎么做的。

大家好，我是拿铁，2018 年首次加入生财有术社群，一年到期后没有续费，直到 2021 年在朋友圈到处可见生财有术，然后又回来了。

今天主要分享一下我个人与珠宝厂合作引流，在 6 个月的时间内从快手 0 粉丝起号运营到月盈利 10W 的经历。

在正式分享前，先简单说一下我的工作经历。

2017 年，我在 1 间 MCN 机构做内容运营，手下管理 5 个女性小网红，从 0 粉丝素人开始制定一切内容包装，包括策划她们的成长风格、视频和直播内容，以及多平台帐号运营等。小网红账号主要通过视频和直播的形式向用户推荐服装，引导用户到天猫上购买，然后引流微信私域再继续转化其他美妆类产品。
