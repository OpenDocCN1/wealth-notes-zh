# **品牌故事**

# **發 立 方**

發立方发财酒
是为那些赚钱不兑LOW，赚钱不伤感情
追求人生时尚但又不想话或装酷的人们而生的酒。
这瓶酒从出生就努力远离那些套路满满的“老油条”，
它希望鼓励那些勇于打破常规，忠于自我内心的朋友，
抚慰他们曾经被动喝那些严肃、呆板、老土，还老被套路灌下白酒的痛苦经历，
让这些忠于自我内心、打破常规的一群人，
以中国传统“發”文化为主题，
以真诚利他之心“ I WANT YOU FA FA FA”为口号
找到一种在酒桌上本该的轻松，有趣、有范、有敬、有爱、有感的状态，
凝聚一群三观统一，精神契合的伙伴，一起去创造人生财富与梦想。

一瓶酒，一群人，一种新的沟通方式。
