两种模式跟运营无关系，顾客都是在自己公众号里。

对接好平台开始用公众号申请微信支付服务，选择外卖平台或者餐饮类目，微信支付手续费为 0.6%，这是固定成本。

# 2. 如何将平台入驻到校园呢？

如果你是在校生就省去了“进校门”这个流程，直接去搞定食堂入驻就可以了。

这里主要讲一下针对校园外的伙伴如何与学校合作。

学校的管理模式一般分为两种：

+   学校后勤餐饮科-食堂分包给餐饮公司-餐饮公司进行商户招商或自营
学校后勤餐饮科直营-商户招商/招聘厨师

大部分学校都是第一种模式，下面以第一种模式进行说明。

首先确定下餐饮公司是如何对商户进行收费的，目前有三种收费模式：

+   纯租金形式
抽点模式，按照营业额来收取20%-30%的服务费
租金+抽点混合模式

第一种收费模式可以谈合作的有学校后勤、餐饮公司、商户，三方都可以谈，因为是纯租金，餐饮公司对商户的控制并不是太严格。（运气好的话，只需要跟商户谈就简单了）
