# # [精华帖](346赞)「个人IP」我用一年时间做了 30W 粉，从偶然到必然

作者： 比高

日期：2022-06-20

大家好，我是比高

在生财待了很久了，第一次分享，以前我是一直做幕后的，网红孵化，IP打造，也做出了不少成功案例，不过对外吹牛逼，总会面临很多质疑，毕竟在罗永浩直播间扫地的阿姨，对外都会给自己贴上“罗永浩团队核心人物”的标签，再加上孵化别人，总有很多不稳定性在里面，所以在去年的今天，我决定干脆打造自己，起名“比高”，开始个人IP的旅途。

在这个节点分享，是因为我参与了航海计划，从这个实操活动中寻找新的突破，当然，我也希望我的分享，能对正在参与这个计划伙伴，提供些可参考的经验。

# 做出了啥？

我是从2018年全力扑在抖音上的，算下来，抖音总粉也有5000W+，不过在今天看来，都是往事，这期间做得最正确的选择，就是切入私域，做比高这个IP。

目前公众号粉丝近20W，个人微信好友10W+，社群16个，付费会员近8000人。
