# 一、**web3**：下一代互联网的新征程

师出有名，聊**web3**，我们就从它的定义开始聊。容我先给大家科普一下，“到底”，什么是**web3**？

先说结论：简单地说，**web3**就是下一代互联网（**wordl wide web 3**）。

说到这个，我们就有必要对**web1**和**web2**时代进行总结回望：

# a.**web1.0**时代

以“互联网之父”蒂姆·博纳斯·李 设计制作第一个网页浏览器**world wide web** 为标志，以**内容**（**content**）为中心，以**PGC**（专业生产内容）和**OGC**（职业生产内容）为主要载体，主要表现形式为：可读。范例为国内早期BBS论坛、网易、新浪等门户网站。这一阶段，多数人的角色是Consumer（消费者）。

# b.**web2.0**时代

该概念最早出现于**1999年**，正式得到普遍认可是在**2004年**首届**web2.0大会**（由蒂姆·奥莱利旗下公司O'Reilly Media 联合主办），以“**人（human）**"为中心，以**UGC**（用户生产内容）为主要载体，主要表现形式为：可读+可写。范例包括微博、微信、抖音（及海外镜像应用）。这一阶段，Consumer（消费者）变为**Prosumer**（生产消费者）。
