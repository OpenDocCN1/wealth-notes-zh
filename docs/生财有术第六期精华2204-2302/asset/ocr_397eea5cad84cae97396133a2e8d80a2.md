# （1）抖音具体引流的方式

抖音引流基本上都是被动添加的形式，让用户主动添加微信，然后慢慢的验证回复消息就可以了，微信也比较安全不会出问题。有个别好友会回复自己的微信号，我再进行主动添加。

联系电话：这个就是上面提到的企业号的好处，企业号添加联系方式，绑定一个好记的手机号，有些用户知道可以通过手机号添加微信，会直接添加微信，这里就节约了很多时间；

![](bbox=[0.15, 0.53, 0.85, 0.75])

企业号添加联系电话截图

用户私信回复：第二个就是用户直接私信（这里也有一个很好的话术就是抖音这里没办法发送产品链接，添加微信给你发链接可以挑选款式），我给微信绑定了个短位的QQ账号（如果一个账号加的太多，还可以把这个QQ账号绑定到其他的微信号上面，这样也做到了分流），私信回复给用户，方便用户搜索添加；
