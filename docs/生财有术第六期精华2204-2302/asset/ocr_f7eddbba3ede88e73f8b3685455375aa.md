# 3、置顶笔记+主页+收藏

置顶笔记一定要利用好，一定不要浪费这个功能，最好写一篇软文+诱饵，比如送一些资料或产品让粉丝添加你留下的微信。

如果做营销的话就简单直接一点，在置顶内容直接放微信号。

还可以用小号发布一个带微信号的内容，你去收藏，然后引导粉丝看你收藏界面。

# 导流方法三：置顶+笔记+主页

+   - 置顶笔记
  - 发布一篇带有微信号的笔记，可以是图片、可以视频，不要放二维码
- 笔记内容
  - 发布笔记内容的时候，可以选择一张图片色彩丰富的图片，在图片里面放置微信号
