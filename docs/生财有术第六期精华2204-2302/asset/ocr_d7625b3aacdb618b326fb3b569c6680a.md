# 好高呀

按照我们的理念，能把学员带到这样的程度，我们针对这个人而言，基本上就已经可以宣布胜利了。除了会给到一些鼓励之外，基本上就不会再给到其他的干涉了。

单单就以这份收益为动力，再加上现有的写故事技巧，她们也会主动地、自发地坚持写下去了。

其实做写作培训，不就是这个样子的吗？无外乎是我们先自己赚到真金白银，然后再把我们的全部经验，悉心教给学员。等他们尝到了甜头，自然而然就会自发地努力起来。我们就完成了教育的“激发”本质，我的任务也就算是完成了。

此外，我们第二周还做了两件重要的事情，那就是鼓励大家升级写作工具和素材库。
