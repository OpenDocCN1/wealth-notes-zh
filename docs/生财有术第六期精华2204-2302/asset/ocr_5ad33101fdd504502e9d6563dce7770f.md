# ⑥产品交付及迭代

有多年工作经验的程序员，转岗做过产品经理，上述条件可以独自完成。但更多的情况，还是需要一个小团队来分工协作，达到效率与质量的最大化。

上述技能岗位结构如下：

+   1. 项目/产品经理：找到风口、找到需求、解决痛点、设计整套产品的完整逻辑、产品迭代

+   2. UI设计师：产品的设计、产品包装

+   3. 前端工程师、后端工程师：代码的编写

+   4. 营销人员：产品的推广

+   5. 售后人员：产品的交付

具体需要多少人分工协作，要看项目的功能复杂度，如果小型的短期风口项目，一两个人来完成整套系统也很容易，后面会有相关案例介绍。

值得注意的是，售后是一个很重要的环节，毕竟客户的水平有高有低，需要一遍遍的培训乃至手把手的指导，才能帮客户真正的搭建运营起来。
