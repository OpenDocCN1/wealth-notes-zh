开放麦: 一般开放麦上可以聚集一些脱口秀爱好者, 再从中挑选或培养一些有潜力的新人。开放麦也是营收的一种, 可以上售票平台卖票, 而且无需给演员费用, 还能快速积累第一批观众。

我们最初就是从开放麦起来的，直到现在依然会有当初开放麦的忠实观众来看演出。更甚者上海有一些俱乐部就以此生存下来，周末商演门票卖不出，只做低价的开放麦，也能月营收十几万。

劣势: 培养人的速度慢。

培训班: 培训班也算是营收的一种形式，但是要求较高，需要 有课程内容或者外请导师。

劣势: 难度较大, 周期也长。

# b. 外请

这个是最省时省力的，目前有很多厂牌只做商演就是直接请成熟演员，本地没有就外地，只要预算够高，总能请得到。

劣势: 好演员档期难求，成本高。
