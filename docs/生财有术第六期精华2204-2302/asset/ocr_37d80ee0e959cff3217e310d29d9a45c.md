# # (精华帖)(118赞)面对 OpenAI 不要焦虑，挖金矿和卖铲子

作者: 斩天

日期: 2023-02-13

这几天，圈内圈外引发了关于OpenAI的狂议。

很多圈友开始感到焦虑，因为他们感觉到红利终于在此时此刻已经到来，必须抓住这波红利。

迫切想要抓住机会，生怕稍纵即逝，后悔一生。

很多人在焦虑中不断思考如何应用OpenAI获利 比如做个app 小程序等等。

我就纳闷了，这东西不是年前就火了吗？怎么又火上加火了

甚至朋友圈里很多不是搞互联网的都在炫这个了。

谁在背后推波助澜？

因为是百度seo pc时代残留下来的老兵。

去年OpenAI刚问世的时候，我大批量购买了账号，每天生产20多万篇文章，1个api 18美金大约可以生产定格字数300-400篇。

那时独立账号的市场价格在8-10元不等。我们拿的渠道进货价格只有1.3元。

后面官方开始大量账号被封，文章生成速度也变的蜗牛起来，再加上文章生成结果其实并不理想，尤其是大批量生成时，很多文章除了遵循格式规则 八股文模式外，实在很劣，还需要人工筛选。后面虽然解决了封号问题，但是考虑到质量问题以及有更优的方案，最终还是放弃了继续使用OpenAI。
