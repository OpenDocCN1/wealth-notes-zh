# 那什么时候适合去整合，什么情况下要自己去培养？

+   a, 项目周期短，利润高，急用的时候去整合，这样方便去快速跑起来，整合后如果不能转化为核心负责人，就要去培养新人，以防万一。

+   b, 团队实力强大了，被整合的板块能力远低于母团队时，不担心他被轻易挖墙脚了，这时候去整合别的小团队可以让团队快速的发展。

+   c, 但是在团队项目进入平稳期的时候，这时候要注重各个板块新人的培养防止断层，保持团队的活性和战斗力。

当团队体系比较成熟的时候，我们的是的最优合作对象时，我觉得这种整合是更舒服的，我可以选择把吸收进来，成为核心，这样我们团队业务板块就+1。

如果不喜欢加入被束缚，也可以选择把该业务交付外包给他，这样我们会很省事，互相合作，既可以扩展团队的业务，也可以让我更有选择权。

情感方面：按我这种方法培养起来的校园团队，感情占比很大，不会轻易被挖走。

生态位方面：我的生态位置决定了，我就是校园市场的天花板，能提供更优选择的人，看不上这个市场，在学校的學生不会比我的资源更优质，我只需要保证综合优势足够大就行。

团队机制方面：我鼓励大家去开疆扩土，甚至可以倾斜团队资源去扶持你，你可以站在团队的肩膀上做事，拿到结果后我可以带着团队去和你一起放大复制，咱们谈利润分成。
