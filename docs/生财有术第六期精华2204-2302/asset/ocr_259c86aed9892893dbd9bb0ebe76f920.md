各种玩法和技巧都是术，个人 IP 的才是道。一个营销工具过几年有可能会消失，但是你的个人 IP 是需要用一辈子来经营的。

在我的思维里，只有去做那种 10 年、20 年甚至 50 年都不会变的事情，才是正确的事情，才是有复利的事情，所以我选择了个人 IP 打造这个定位。

最后，希望大家都能够再次思考自己的个人 IP 定位，往细节上想，换一个角度去想，也许会有新的灵感蹦出来，而这个灵感就是你的下一次顿悟。

# 20、打造个人 IP 应该输出哪几类内容？（内容篇）

有人觉得自己没有什么擅长的技能，就无法通过内容输出来打造个人 IP，其实这里有很多技巧，你只是没想明白。

# 1、实操型内容

没有人生来就擅长某个技能，都是经过一次次的实操积累下来的。所以，如果你现在没有特长，那分享自己一次次实操的经过，甚至是踩坑的经过。

过程是有价值的，在实操的过程中，你会产生很多想法，这些想法对于不了解这个领域或者行业的人来说，等于是一种“VR”体验，你写的越详细，用户看的就越上瘾。

牛人有牛人的实操，小白有小白的实操，小白实操要着重突出自己的感受，和外界给你的反馈。
