# 1、持续赚钱始于认知革新

我认识亦仁是在2016年，那时候他还在做一个关于版权的创业项目，帮助公众号作者针对抄袭等侵权行为维权。那时候我有一篇爆款文章特别火，叫《大学生上课为什么一定要认真听讲》，有好近千个公众号未授权转载，包括一些央媒。那时候亦仁正对接我做这件事情，他把导出的侵权列表发给我的时候，我想的是怎么把这些号都通通搞一遍。他却对我说，你为什么不试试加上这些公众号的运营，这样以后他们可以继续转你的文章。

他这番话倒的确给了我启发，毕竟我从来没这样想过要和抄自己文章的人建立联系。于是我就照着操作了一下，还真加到了一些编辑，也建立了一个群。后来呢？后面就没有然后了，因为我后面就没有写过特别火的文章了，所以他们也没必要转发了。这个价值链也就中断了。

但是回头看，亦仁当时给我的一个启发是，一些我们以为必须如何的事情，可能有其他的看待问题的方法。而这里“加上好友”的思考问题的方式，现在在生财的精华帖里，经常能看到，后续我才发现，遇到流量加上好友，就是一种赚钱的基本功啊！就是现在所谓的“私域流量”了，在那个时候，亦仁就有这个理念了。所以你看到，一个社群的生长与发展，是和创始人的思考问题的角度，有关的。
