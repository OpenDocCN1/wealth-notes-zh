# # (精华帖)(203赞)视频号小店店群，大量铺货月入10W+的实操分享

作者： Summer

日期：2022-11-29

视频号后端能挣钱的根本原因是因为后端商品的缺乏，视频号选品库整体依旧还是不够多不够丰富的，达人想带什么品在选品中心搜不到很正常。

所以即使现在去做暴力铺品依旧能出单，而且一定要做店群，去多做店，数量越多越好，越多越稳定，最起码要做5个以上的店铺，要用矩阵思维来对抗不确定性！

我干无货源后端没多长时间，也就8个多月，总收入100多w，到年底应该会超200没什么问题，主要干的还是视频号后端。

视频号无货源店群关键操作有：开店，入优选联盟，选品上架，拍单发货。真的是从0开始的，有结果后再一步步放大的。

好多年之前虽然就知道无货源项目但是一直没去做，今年初的时候在前端失败后才去试了后后端，可能时机恰好，选的平台可能也恰好正确，又恰好很快的得到了正反馈，所以才能够一直坚定的走过来，在碰到困难也会去想方法设法的去解决着，去随着平台的规则去研究并更新玩法。

感慨几句，我干过的大大小小的项目太多了，出身普通家庭所以一直想赚钱，从读大学时就开始搞副业了，之前一直顺风顺水，想要的都能得到。
