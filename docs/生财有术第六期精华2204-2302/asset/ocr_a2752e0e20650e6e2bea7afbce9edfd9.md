# 备注：

+   1. 看不懂配置没关系，毕竟我们不是搞硬件，反正一个原则就是需要运行流畅，不然会像个老牛一样，处理速度慢到你怀疑人生。

+   2. 个人建议手机和剪辑电脑用苹果，使用流畅且反应速度快，而且设备之间投递文件非常方便高效。

+   3. 如果有条件的话，再备一台Windows（有独立显卡）做辅助，就更好了。

+   4. 以上建议不是非必须，只要有电脑和手机就可以了

# 准备工作：

（因为这套【混剪厨房】的方法，逻辑和做披萨很相似，为了方便理解，表述的时候加入了一些做披萨的比喻。）

+   1. 想好吃啥披萨：确定产品-定好你的项目近期要卖啥？

+   2. 准备肉：根据产品找好原视频-要用哪个内容素材做二次加工？

+   3. 处理肉：原视频混剪加工-根据你的需要重新组合语句，去掉多余部分，裁剪成你需要的比例，导出备用。

+   4. 准备配菜：根据去重方案搜集画面素材-需要什么画面？背景？场合？人物？物品？行为？产品？

+   5. 清菜：画面素材初加工-去原音，剪去多余部分，裁剪所需比例（和初加工的原视频比例一致），调整画面亮度色彩清晰度，导出备用。

+   6. 切菜：画面素材切片-将素材画面分割成小段，建议是5秒一段，每个画面准备许多段。可以手动分割，也可以借助工具自动分割，效率更高。
