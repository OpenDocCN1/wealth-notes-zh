# （2）引导用户分享

进行旅行的过程中，我们会进行跟团摄影和打卡点分享，然后用优惠券或小礼品引导用户进行朋友圈分享或小红书分享。

线下会进行较多的分享暗示，但不会明确告诉用户一定要分享，这个方面做下来也为我们带来了不少精准的客群。

旅行结束后，会有一个发游记领取大额优惠券的分享活动，来增加小红书上的搜索热度。
