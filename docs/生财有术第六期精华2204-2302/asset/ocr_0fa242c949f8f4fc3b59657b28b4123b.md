# 3）小程序导流给公众号

**目的**：小程序是即用即走的类型，所以需要使用公众号来囤积流量，得到多次消息触达给用户的机会！

由于是工具类的小程序，我们可以通过**UnionID**把微信小程序和微信公众号用户打通了，可以强制让用户使用小程序某一项功能时候，必须关注微信公众号；

当然这个看你怎么描述，既让用户去关注，然后微信官方也不处罚你了，如果写了太明显，微信官方会处罚小程序违规的！

# 4）小程序里面iOS支付问题

在微信里面iOS用户是不能支付虚拟产品的，我们是经过了下面几个阶段，逐步测试，目前找到最合适的解决办法，运行了一年多，没有被处罚过了。

**最初方案**：

+   ① 在微信小程序里面有文案，直接提示用户关注公众号充值文案；

+   ② 通过小程序客服接口，让用户扫码关注微信公众号，在小程序里面有相关的提示用户关注公众号充值文案；

+   ③ IOS端公众号里面菜单里面有充值，会员购买相关文案。

以上这些，全部会违规处罚你的小程序或者是微信公众号。
