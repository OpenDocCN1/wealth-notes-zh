# ## 1. 付费社群

我是今年2022年2月12日正式开始做的付费社群。

开始做之前，我前前后后花了三个月的时间，在自己去年总结出的《启四可转债投资指南》文字版基础上，增加了更丰富的案例和进阶教程，并用视频录播的方式演示操作方法和思路，做好了一套视频课程。

由于之前还不会剪辑，我的每个视频都是从前到后一口气录完，中间如果有差错，就删掉重录，再加上我的主业是程序员——大家都知道的——很忙的一个职业，所以我只有每天晚上下班后，匆匆吃完饭写完公众号才能录，经常要录到半夜两点，所以搞了这么长时间才录完，中间一度绝望到想放弃，现在回头看，还好坚持了下来，也庆幸自己坚持了下来。

第一批种子用户来自我之前建立的免费粉丝群，2个群1000人，第一天就有大概40人付费，半个月的时间很快社群就积累了200多人。
