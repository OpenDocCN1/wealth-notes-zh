
- 一个外置摄像头（摄像头买相对好点的，不要买100以下的）
- 一个手机三脚架
- 一个声卡

这就是直播用到的所有必要设备啦。当然，实际操作中，最好多准备几台手机用作鱼塘（下文会讲解）。

## 2）账号准备

很多人都关心，直播前账号要不要养号。

正常来说，如果是平时自用的账号，经常刷抖音，没有开过直播，是不用特别养号的。但是如果是全新注册的抖音号，或者准备用其他人之前的抖音号开播，账号换到你的手机上产生了异地登录的情况，那么是要去养号的。

养号的方法也很简单，就是每天刷一会抖音，模拟真实用户的行为即可，做一些互动，如短视频点赞评论，直播间评论加粉丝团，直播间购物等，各种操作都可以做一下，提高一下活跃度。

一般3天即可，稳妥起见也可以7天。用于直播账号的账号和手机，要保证一机一卡一号，不要轻易再去切换。

养号完毕后，要开通商品橱窗。0粉开商品橱窗的方法比较简单，就是利用每个抖店都可以绑定5个营销号的原理，绑定成为抖店的营销号。如果自己没有抖店，在某宝解决即可，或者联系我也可以帮忙开。

后台开通橱窗后，还要在创作者服务中心进入商品橱窗界面，实名认证，缴纳500元作者保证金，之后就正式完成橱窗的开通了。

另外，如果不想实名，也有利用半蓝机制不实名开通橱窗的办法，需要自备营业执照，这里就不详细讲解了，大家可以自行百度。

账号的名字和简介等设置，自己对标同行的进行设置即可，性别最好设为女性。关闭直播手机系统的GPS定位、关闭允许抖音定位权限、关闭抖音的同城设置。

以上，就完成了我们的账号养成和设置工作了。

## 3）选品准备

对于电商来说，选品永远是重要的一环。对于大类目的选择，比较建议大家做垂直类目的内容，直播间标签比较好打，竞争相对女装、食品、百货、书籍等品类也较小。

目前比较常见的类目有：家居、3C、母婴用品、美妆、渔具、玩具、绿植、宠物用品等。

虽然说是垂直类目，但是在类目选择时，品的内容要能够丰富，因为我们不是卖单品，这种直播间逻辑，就类似“xx超市”。

举例来讲，以渔具为例，常规的直播间一般主卖鱼竿鱼箱等产品，因为这种产品价格和利润都比较高。但是我们的直播间，就可以以鱼线、鱼饵等低价位产品为主打，补充这个类目的空白，和常规直播间错位竞争。同时我们也提供鱼竿鱼箱的选择，这样很多人看到后，如果觉得便宜不错也会顺便就加到购物车。

大家可以通过蝉妈妈或者飞瓜的数据商品大盘来详尽分析，并结合自己的经验优势来最终确定赛道。

在选定后也要注意去看有没有同类直播间，如果一个同类直播间都没有刷到，那很可能并不是我们真的找到了一个蓝海，而是这个品类的商品并不适合做半无人直播的模式，这一点我们在选品时一定要注意。

选定了大类目之后，我们就要去精选联盟选择自己的商品了。登录巨量百应，进入精选联盟，这里可以看到我们可以带货的货的售价和佣金，加入到自己橱窗后，可以在橱窗看具体的SKU。

我们可以用第三方数据分析工具，如蝉妈妈、考古加等，来查看类目中的近期爆款产品，同时还可以用当日视频榜，来寻找潜在的热门款。很多小伙伴会无脑的选择高佣爆款，但其实选品是一件较为复杂的事情，绝对不是把爆款堆上去这么简单的。

![](img/a50ad26370b1cd7f67818735c6f556a8_1206_0.png)

上橱窗时，我们不要只上100款，而要求架几百款，同时最好用表格进行分类，把商品分为10%的福利品A、20%的承接品B、70%的利润品C三种。

福利品我们不赚钱甚至补贴亏钱，承接品微利，利润品才是赚钱的。在直播的不同阶段，根据流量情况，对上架产品和话术进行组合。比如人少时，我们要放福利品+憋单，吸引用户停留做数据，而人多时，则主推利润品来做成交转化。

另外一个捷径的办法就是直接抓取同行直播间里的商品到自己的橱窗，再去进一步优化。这里要用到一个付费软件：黑核百宝箱。

![](img/a50ad26370b1cd7f67818735c6f556a8_1207_0.png)

对于我们的半无人直播间来说，在排品时也要注意。因为我们主打的就是“优惠清仓”，所以1-10号链接产品的价格都要较低，至少要有一个很低的sku吸引用户做点击。而10号之后的链接，要高低结合，如果一味地把低价品放在前面，会给用户一种“越来越贵”的感觉，不会再往后点击。

## 4）直播场景准备

直播场景，就是我们直播时绿幕播放的内容啦。一般为一张静态的背景图片或者动态的视频，搭配上诸如“清仓处理”等吸引人的文字即可。建议提前准备2-3套素材，如果万一素材出现违规提示，可以直接进行切换。

![](img/a50ad26370b1cd7f67818735c6f556a8_1208_0.png)

![](img/a50ad26370b1cd7f67818735c6f556a8_1208_1.png)

以这两张图为例，主体部分为均为一张静态图片（渔具店&仓库）+文字，而实景搭建部分都在画面的正下方。

左边的渔具账号，使用的实物产品+主播出镜的模式，而化妆品账号则是实景化妆品摆放的模式。看上去很简单，相信大家一看就能明白。

场景对于吸引大家点击和留人都很重要，通过场景和文字尽量做到用户的高停留。对于场景文案的使用，在初期可以参考同行直播间，后期驾轻就熟之后自己编写就可以啦。

对于场景素材的处理，原始素材可以使用搜索引擎找图，可以录制其他直播间画面，也可以去淘宝购买，最后用剪映进行处理。都是很基础的操作，做过短视频或者个人IP的圈友们应该都会。

需要注意的是，如果用淘宝购买的素材或者录制的其他人直播间，要对素材进行去重操作，这样才能通过平台审核，要不然很容易被判违规。

关于去重，最好用的方法就是添加2-3层正片叠底的蒙版，然后把透明度设为3%左右即可，从人眼视角看不出太大差别，但能够比较有效的通过平台审核。

# 3. 起号阶段

起号的方法应该是大家最关心的内容了。其实起号的底层逻辑也很简单，核心要点就是我之前总结的两点：

- 起号的前几场，数据要做螺旋递增。平台对新号的一个重要考核数据就是数据增量。
- 递增后的数据要优于同赛道同行的对标直播间。

明确了这两点之后，我们要把起号期间的直播计划写下来，规划好把每场直播的目标数据，每场直播把数据做够，就能顺利达到我们的预期目标。大家可以按照我下图发的这个模板来简单编写。

目标有了，我们要怎么做才能保证完成预期的数据目标呢？在起号期间我们确实需要使用一些套路和策略，来确保数据达标。目前关于起号的方法有很多，比如鱼塘起号、AB链起号、憋单起号、亏品起号、高返起号、随心推起号等。

考虑到实用性和实操难度，本文重点给大家讲解鱼塘起号和亏品起号的方法。

## 1）鱼塘起号

关于鱼塘的概念，做过淘系的圈友都能明白，简单来说就是自己养的托号，可以模拟真实用户来进行数据干预。

在直播时，我们的鱼塘号可以给我们起到几个作用：

- 帮助账号打标签
- 干预电商数据
- 烘托直播间气氛

由于平台的算法考核机制，**1**和**2**，基本都是一次性的操作，购买过之后再补足数据虽然有效，但是对推流权重起到的影响非常有限。**3**的作用是长期有效的，在每场直播时有鱼塘号进入，可以非常好的帮助配合主播带节奏。

鱼塘号的养成方法很简单，模拟真实兴趣标签的用户进行操作即可。

初期可以搜索找到同行的对标直播间，进去停留，点击商品，加粉丝团，每天刷1小时左右的同行直播间，基本3天左右，当你刷到的90%直播间都是同品类同种类直播间时，就意味着这个号的用户偏好标签已经打上了。

之后我们要做电商数据，也就是下单，在同行直播间隔内下单1-3次即可，商品客单价最好与自己直播间的主力商品对标。

鱼塘号和我们的直播号，一定不能建立直接的联系，不能连接同一个wifi，更不能互相关注，也不能通过搜索进入直播间，只能通过自然的feed流推荐滑进去。

那么怎么样确保我们的鱼塘号，能顺利的通过feed推荐刷到我们的直播间呢？最简单的办法就是提前建立亲密度的方法。

在开播前，我们让直播账号和鱼塘号都刷到一个同行的直播间，都停留20分钟左右，然后直播账号发放一个5分钟后领取的红包，我们的鱼塘号都通过领这个红包来关注直播号，就可以和直播账号建立亲密度。

半小时后开播，鱼塘号上线，就能刷到我们的直播间了。注意，尽管已经关注了，千万不要点关注页去刷，而是要通过推荐页刷进去。

鱼塘号的概念很好理解，当我们数据达不到预期目标时，自己干预来搞定。这种方法也是直播运营时的一种非常基础的方法，不管使用什么方法起号，如果条件允许，都建议大家能够自己准备5-10条鱼，这样在运营时灵活度会很高。

![](img/a50ad26370b1cd7f67818735c6f556a8_1212_0.png)

要提高成功概率，准备6台以上的备用手机很有必要

## 2）亏品起号

亏品起号，也是一种非常基础的玩法。简单来说就是，当我直播间刚开始起步，没有权重，主播能力也不够，做不好数据，那怎么办？降价贴钱亏本卖，甚至只送不卖。东西卖不出去，总能送的出去吧？

相比鱼塘起号，这种方法更为安全，因为给我们做数据的全部是真实用户，我愿意亏钱来做，也是完全无可厚非的商业策略。

而且这种方法的成本也并不高，假设我们有50单数据通过这种方法来做，每单我们亏10块，也就是500块而已，每单亏5块，仅仅需要250元。

一单随心推的价格，相比能给我们带来的收益而言，这个投资并不算高。如果我们自己有工厂或者较强的供应链，甚至我们不用亏本就可以做到。

和鱼塘的玩法一样，亏品起号基本也是运营直播间的一种必须掌握的玩法。像憋单起号、高返起号，其实都是在亏品起号基础上的衍生。

那我们怎么来实操呢？

两种方法，可以自己开抖店来配合自己的直播间来操作，也可以在精选联盟中，找到福利品商家，电话或者微信联系，让他给我们做定向链接或者主播券，我们之间再来单独结算，由我们来补贴差价。

做好链接之后，一定不要直接一直挂在小黄车上，而是由运营配合我们的直播节奏，进行限时限量秒杀的操作。

另外在实操时，还有一些要注意的要点：

- 用来操作的品最好是高需求标品，就是大家都能知道价值且无论当前是否需要都可以下单的东西。比如6瓶可乐，大家都知道价值10多块钱，那我们做一元秒杀，这时候大家都能明确认识到自己是占便宜了，下单欲望会很强。
- 亏品玩法适用于垂直赛道，我们要选择垂直商品来做。比如我们做宠物号，不能拿纸巾来做福利，因为这样下单的很可能是羊毛党，并不适合我们的精准用户。而如果我们用猫粮来做福利品，不养猫的人，送给他都不会要，下单的肯定是精准用户，能给我们打上精准标签。
- 一定要选择体验分高的商家，最好是4.9分以上的商家。因为抖音上，35单后会出达人的带货口碑分，这个分数是由近期达人带货商品的综合情况决定的，如果选择一个信用分低的商家，很可能会拉低我们的口碑分。如果口碑分低于4.4，就会影响我们的流量，低于4.2，那更是限流严重，所以前期在选品时，店铺信用分很重要，千万不要因为贪图低价高佣而选择分低商家。

# 4. 起号后期

一般我们按照自己的预期计划，每场顺利达标，把数据螺旋做起来之后，3场左右就能给我们的直播间打上精准标签。在不触发平台风控的情况下，在第5场或者第6场就能有一波比较大的精准流量。我把这场直播称为决战之播。这波流量如果可以承接住，把这一场的数据做好了，我们的账号就能获得一个较高的权重，进入一个大流量池。

所以在这场中，我们要准备好一种高性价比的承接品，配合提前准备好的话术做微憋单，把停留和转化数据做好。如果万一没有做好，plan b介入，及时用鱼把数据补够。

# 5. 稳号阶段

## 1）稳号阶段的直播方式

一旦把账号做起来之后，我们就进入常规的平播阶段，踏踏实实在把每一场的成交做好即可。由于我们的做主播的能力有限，在平播阶段以念话术和解答用户问题为主，不用太复杂的套路。不过也有一些小tips，如果把握好细节，也能很好的帮我们提高各项数据。

- 不要完全平播，也要准备好店铺的1-2款爆款商品。平时不放链接或者把链接放到小黄车后面，每15分钟左右，根据直播间在线人数来搞“送福利”活动，其实并没有优化，只是通过话术来营造优惠的感觉，能很好地促进利润爆款的成交。
- 主播要有做数据意识，主要指的是转粉和加粉丝团两项数据，要养成随时给用户要数据的习惯。这部分话术要进行优化，不能站在主播的角度告诉用户“帮主播点个关注”，而是站在用户角度，告诉他“加我们的灯牌/粉丝群能获得什么xxx福利”，或者实实在在的给大家发福利，“我大气一些，直接给大家发个抖币福袋，大家领完后拿出1抖币给我加一个粉丝团，其余的留着”等。
- 一定要根据后台大屏数据，直播时不停调换商品顺序。同时每天每天都要根据平台趋势进行商品调整，不要一成不变，一味和其他直播间卖同样的商品，这样转化率不会太高。要学会带节奏，带趋势。
- 在直播中学习微憋单话术技巧。所谓憋单，就是先王炸预告后面有福利品，但在实际放链接前多说很多“废话”，起到让直播间用户多停留的作用。掌握一些微憋单的小技巧，可以大大帮我们提高直播停留时长这项数据。

## 2）双（三）频共振

在我们常规直播阶段，如果我们某场数据稍有拉胯，下一场就很容易导致我们的推流减少。为了保证我们有一个相对稳定的流量，一直保持账号的高权重，我们要适当用短视频和千川付费的方法来帮我们的直播间带来更多的流量。

以短视频和直播间为例，拍摄商品介绍的短视频，如果短视频爆了，通过短视频进入直播间的，都是精准客户，他们的成交数据会好于常规推流进来的客户，会拉高直播间的成交数据。

反过来，如果我们的直播间爆了，通过主页看到我们短视频的客户，也会大概率看完我们的视频，继帮助短视频进入下一个流量池，反哺直播间，起到了“共振效果”。

用千川付费的方法同理，只要有合适的ROI，我们也可以用来付费来拉高直播间数据。不过我们此篇攻略只探讨免费自然流玩法，如果大家对付费投放感兴趣，改天我可以单独讲一下千川的玩法。

关于短视频的拍摄，由于我们是小团队，必然不可能在这投入太多的时间。所以我们的视频还是以搬运和二审为主。一定不要拍没有意义的视频，要么做直接的产品安利视频，要么做可以引起大家购买想法的争议视频。

比如我看过一个渔具的直播间，发了一个烧渔具的视频，配文类似是烧掉了渔具，以后不再钓鱼了，这样的视频很契合直播间的主题，而且很容易火，直接爆了80多w的播放量，连续给直播间带来了三天的大流量。

我们目前的视频拍摄方式，是采用的出镜自拍视频开头+自己配音+二剪热门素材的方式，既保证了文案和音频的原创，又能蹭到热门视频的热点。

每天发3-5个视频，如果有视频跑的不错，可以适当投放dou+进行加热，涨涨粉，单个粉丝的成本如果能控制在0.3元以下，是不错的投放比。

这样的目的是尽快提高账号权重，增加视频的基础播放量。在我们短视频权重增加上去之后，短视频对直播间的提升就会很明显。

在有一定粉丝量的基础上，每个短视频的如果能带来2000+基础播放量，稍微热门一点的能有5000+播放量，那每天3-5个视频能给我们带来1w左右的间接流量，在我们直播时通过短视频渠道进入我们直播间的人数就能有大概800-1500人，也就是给我们带来1000+的场观。

如果我们能把UV价值（每个用户在直播间的平均消费金额）做到0.5以上，换算成直接收益就是500元。如果某个视频爆了，这时候配合直播，直接可以把单场GMV直接做到3w+，所以长远来看，拍短视频来配合直播间是非常香的。

# 6. 在视频号上举无人直播的玩法

其实我们在选择项目初期，二月份开始就有在做视频号。当时是采 用暴力搬运的方法，爆过几个视频，拿到了接近万元的佣金。但是可能是方法不对，后来我们就没有深耕坚持了。

在当时我们的认知看来，视频号短视频带货的逻辑根基并不稳定，可以有结果，但从某种程度来说还是看天吃饭。

同时在做视频号搬运的过程中，我们发现同样是带货，直播的收益更加稳定，上限更高，所以开始慢慢把方向转到了直播上。在抖音跑通直播闭环之后，我们也想到了是不是回到视频号这个蓝海，打通短视频和直播的闭环。

所以我们从6月开始，也重新布局了抖音视频号。目前还在摸索过程中，变现还没有达到1w，所以没有特别成熟的内容分享，只有几点小经验分享：

- 视频号的选品是关键。因为公众号的受众没有抖音涵盖那么广，主要群体还是二三线的中老年为主，所以如果选不好赛道，在开始就注定了无法成功。
- 视频号没法像抖音一样0粉开播，使用推流至少需要1000粉丝，所以初期还是要用短视频先快速积累粉丝。
- 如何快速涨粉，大家可以变换思路，如果直接用商品视频不容易爆，可以曲线救国，用目标群体同样喜欢看的内容来涨粉，之后再开播，同样不会打乱我们的标签。举例来说，假如我们卖老年女装，发直接发商品图文视频难涨粉，那是不是可以先发容易火的广场舞视频，爆发涨粉到1000后，再去做老年女装的直播呢？
- 视频号的稽核制度与抖音不同，半无人绿幕直播也很容易违规。对抖音来说，如果我们用绿幕作为背景，同时有摄像头拍摄真实场景和真实主播，基本是不可能违规的，但是同样把这个方法放到视频号，也会经常莫名其妙的判定为录播违规。目前找到的解决方案是把真实摄像头的窗口范围放大，至少占据到直播画面的一半，这样就基本不会再被判定为违规。
- 视频号直播的推流算法与抖音还是有一定的区别，更偏向于熟人社交，所以可能直播间分享的权重会相对较高，我们在直播时可以尝试加入诱导分享的话术来做数据。（目前视频号直播经验不多，这方面的成熟内容也较少，此条仅为个人经验，不保证完全正确。）
- 视频号的用户群体目前还不成熟，直播中间到最多的问题是“怎么买”，所以在前期，我们花了很多时间来解答这个问题，导致直播节奏被切的稀碎，转化效率并不高。后来我们尝试在场景中加上购买方法提示，有一定效果。
