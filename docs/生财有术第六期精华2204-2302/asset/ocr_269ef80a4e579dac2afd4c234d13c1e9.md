# # 【精华帖】(168赞)同行一句话让我抓住美团电商红利狂开30家店

作者： 刘家齐

日期：2022-11-11

大家好，我叫刘家齐，齐家治国平天下的家齐，过往在美团有接近八年的销售及管理经验。

刚刚过去的几个月，我们的淘宝店群业务从上半年高速增长进入了低谷期，开多少店，补多少单，团队状态拉多满，这种战术上的勤奋然而仅仅是止住颓势，连续的加班让淘宝合伙人小Z和团队状态非常的低迷，我也很清晰不尽快恢复增长，我们的裁员也只是时间问题。从第三季度开始淘宝对于店群的打压是空前的，行业内哀嚎遍野，面试了很多同行业裁员离职的姑娘，很多群内也是满满的负能量，这在上半年利好的环境很难遇到的。

一个人走在深夜加班回家的路上，点了些青岛啤酒和烧烤，坐在马路边看着过往的车辆，零星的路人，那段时间交流了一圈老板，之前的玩法在近几个月市面上已经没有成功案例，像一艘没有灯塔指引的船，令人绝望。

转折点出现在八月末，从发现到入局不到两个月的时间，美团电商成长为团队的第二曲线，类目不同单店月利润6k-12k（零运营未优化），扭转了我们的淘宝店群的颓势。本篇文章全流程复盘我如何通过淘宝同行老板一句话透露出的商机落地一个项目，希望能给各行业搞钱路上的朋友一点点启发。从发现项目、跑通最小MVP、梳理流程团队入场、从平台历史中找共性以及项目的总结复盘，全文共计五部分。

# 一、发现成功案例，做有心人
