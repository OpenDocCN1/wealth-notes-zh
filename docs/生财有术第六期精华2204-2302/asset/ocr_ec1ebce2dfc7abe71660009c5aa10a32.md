有冲动的成分，我靠着之前剪辑的经验，前面选品磨练出的技能和执行力冲进了书单赛道。我启动两个账号，单账号每天3个视频，为提高剪辑效率，在生财找了很多批量剪辑的帖子，从精华帖到高赞帖子，磨练出文案和素材匹配度之后，1小时可以剪7-10个，一天可以剪完两账号一周发的。

起号跟素材（选品）和文案有关，也很玄学，我其中1个书单号起号三天就出了爆款，预约直播，周末连着俩天开播出了一单，赶忙进行了迭代，尽管有太多不足，但走出直播第一步很重要。

# 2. 直播试错，学习新技能

我在书单号直播了几场，在出单之后，又兴致冲冲跟风直播，调动1个书单号和1个带货账号进行试错。结果1个千粉账号掉橱窗7天，1000＋投流打水漂。我真该深刻反思的，当时应该拿新号去试错的，已成熟的账号成本太大，粉丝体量又不匹配，还容易出现未知问题造成损失。

尽管有些损失，但不妨碍学新东西，在来回翻看抖音、视频号直播实战手册和请教圈友下，我学会了怎么快速简单搭建虚拟直播间，怎么进行快速简单获取透明背景贴片，怎么用 手机摄像头替代电脑，怎么进行投流，怎么录制直播间，怎么迭代话术，直播情绪张力...

直播情绪张力只能多练，每场直播都能有进步，就是不差的结果，人均场观能有1分，足以见有天賦。
