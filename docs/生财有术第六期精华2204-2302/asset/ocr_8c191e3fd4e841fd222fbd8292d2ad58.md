Analytics里最直观的几点：

# ① 浏览时长

YouTube在判断一个视频好坏的最重要的因素就是视频的浏览时长。因为整体都会是中长视频。浏览总时长比完播率会更重要。（还记得申请YPP需要的4000时长的要求吗？）

# ② 浏览数

浏览数的增加，直接影响账号的权重，前期拼的就是浏览数，中后期更看中浏览时长。

# ③ 用户量

对YouTube来说很简单，如果你没有足够的用户关注，证明你的内容不够优质。用户量也是保证基础推送的底线。

数据分析，它将会贯穿我们整个运营的周期，学会如何去看分析数据将是你必须课之一。

今天一个视频好，一个视频浏览量高，一个视频的互动率高，我们要知道是为什么？什么人喜欢看？
