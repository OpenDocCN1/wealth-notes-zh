首先我们知道新媒体的渠道大致可以分为如下

+   1. 短视频: 抖音、快手、微视、视频号、小红书等等;
2. 中长视频: 企鹅号, 百家号, B站, 知乎等等;
3. 图文平台: 知乎等等。

那我自己制作出来的短视频，既可以在抖音发布，当然也可以在快手发布，也可以在B站发布，这叫做一次制作，多次发布，我们制作成本是固定的，只要动动手指，多发几个平台，那么就可以获取多份流量。

# # 2.多渠道的意义

多渠道当然有很多意义，比如获取多份流量，现在互联网的流量是分布在多个渠道里面的，可能有些人看抖音，有些人看快手，有些人看B站，所以一个视频只发抖音，可能就500播放，但是快手跟视频号也发，那么可能就是多了1000的观看，所以意义之一就是可以增加很多流量。

意义二：我认为意义二才是最关键的，就是增加你出单的概率，我这里说的出单是泛指，比如你一个视频播放量突破第一个流量池，比如抖音你破了500播放，到了2000播放，我就认为是出单了。
