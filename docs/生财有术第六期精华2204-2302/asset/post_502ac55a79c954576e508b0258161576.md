# 夜幕

无限的白昼，黑暗的夜晚。万物有且而活。

你说，休言万事转头空，
你说，来日方长终可待，
可我抬眼，已是半生。

如果时光能倒退，
如果岁月能重来。
我们还会不会
有突如其来的遇见和始料不及的喜欢。

![](img/a50ad26370b1cd7f67818735c6f556a8_1820_0.png)

2021年3月份，听说这位DM照着我的原创故事、立意、人物塑造，重新写了一个新的剧本。但庆幸的是，后期交涉此次抄袭事件我曾看过对方剧本，文笔之稚嫩犹如中学生作文，根本没有用心打磨就准备销售，我便放心下来。

后来果然在展会销售中，此作者的这一部作品，成交额竟然以零本打破了展会的记录，果真是牛人。

新手作者切记，靠谱的发行团队和写作过程中的辅助团队尤其重要。写作无门槛，但是剧本杀写作的门槛恰恰在门里面。

所以大家在投稿中，尽量优先投出思维导图框架以及立项书，来确定自己的构思能不能得到市场认可（对于导图和立项书模板，感兴趣的朋友可以评论区留言）。

### 5.2 成为剧本杀店家

（1）关于门槛：

店家需要自己有些对剧本杀的爱好和打本的经验是最好的。

相对比较简单，就是资金。对于资金的金额要看店铺的定位，比如装修风格，平米数大小，房间多少，服务类别等（类似我们装修房子）。

正常在一二线城市，如果选择低成本开一家门店，起码要准备20-30万，如果选择开高成本门店，可能需要花费60-100万。

（2）关于风险：

开实体店的风险非常多，想必做实体的朋友都了解。以下我们通过客观角度分析，会有一些犀利（当然生意好的剧本杀店太多，有很多运营不错的店打本都要排队预约，一不小心就要排到两个月之后）。

- A. 剧本杀店盈利天花板相对较低，剧本杀玩家几乎都是下午出没，固定的时间，固定的房间数量，固定的接待玩家量，房间利用率在周末或者节假日最好的情况可以达到三车：下午车，玩车，修仙车。正常工作日人流量有可能会比周末少一半。
- B. 关于专业DM的待遇问题。专业DM需要具备影视表演、播音等专业素养，同时还要求颜值在线。DM的底薪却低得可怜，主要靠提成，有些城市DM的底薪不超2000元，而且DM的出勤时间可能会在12-14小时，一般店家都不会给DM解决社保问题，种种原因导致DM流动性极大。数优秀DM可遇不可求，大多数DM都是从新人培养，成本较高。
- C. 店铺运营者更是需要具备超强的能力，精通社群管理（剧本玩家拼车群），需要面对多人进行协调，考验情商、智商、应变能力、控场能力等。一般运营好的店这个位置都是老板自己，或者是老板亲信，在这期间，这个位置的人要具备一定的抗压能力，会很辛苦。
- D. 门店剧本的选择问题也是极其重要，作为门店两大核心一是DM，另一个就是剧本。剧本的质量决定了玩家的体验，玩家的体验决定了运营的成败。如果对行业不懂，对产品不懂，那如何能把产品最好的一面展示给玩家呢？
- E. 城限本的秘密——有一些好的城限本宣传不到位，好不容易抢到也无法引流。而爆款城限，人人都想要，作为新店家想拿到也不容易。在选本的过程，时间，更新的速度都是要研究的。
- F. 疫情当下，开店抗风险能力特别差，停业一月是哪个店家都受不了，可是又没办法。

以上风险如果不了解，几乎新手老板所有坑都要踩一遍。

# 5.3 加盟剧本杀店也是一条不错的路径

（1）门槛：需要一部分加盟费，选择靠谱的店铺去加盟，或者扶持自己创始自己的品牌。

（2）风险：如果加盟费在自己承受范围之内，几乎无风险。

（3）加盟服务一般包括：

- 品牌支持（授权使用品牌名，并且享有同品牌其他店面的客源引流）；
- 装修支持（提供装修标准统一设计）；
- 运营支持（日常新用户引流、老用户挖掘、节日活动策划等）；
- 培训支持（对店长、店内DM进行培训、定期复训等）；
- 物料支持；
- 管理支持；
- 宣传支持（品宣一般由总部进行）；
- 网络支持（在线提供店面管理咨询）；
- 剧本支持（加盟期间，持续为门店提供剧本更新）。

# 5.4 成为剧本杀发行方

（1）认知门槛：对剧本杀行业有所了解，好的作品需要营销。

（2）团队配置门槛：

- BOSS：行业认知、行业人脉、把控行业风向、剧本把控（防止方向跑偏）；
- 监制：目的-爆款/防止风险；
- 要求：文字功底（趣味性、代入感）；逻辑思维（剧本核选、环节设置、手册编写）；
- 校对：通篇阅读（找bug-错别字、标点符号、断句等），校对成语；
- 销售（宣发）：炒本、推广；社交牛逼症患者；剧本卖点提炼能力；
- 签约作者：固定签约作者 2-3个（至少）；按照年限签约，保证稳定性；
- 售后团队：1-2人，专人专本，服务店家（道具、内容等等），尽量保证白班夜班；每隔1-3个月，确保对剧本的了解程度，发送更新授权名单（城限、独家）；
- 后期团队：（含美工）制作相应的音视频、美工设计（考虑给绘侵权问题）。

（3）剧本签约门槛：

- 收稿流程：初稿审核（文字功底较强、确保逻辑顺滑、抄袭剧本禁止）；
- 剧本打磨：专人专管（类型划分、领域分类）—确保本子质量提升；市场认知、故事内容、游戏性等更为迎合市场；要么特色，要么商业，二选一；演绎是否添加、添加环节、添加效果等需要考虑；与作者深入沟通，考虑其想法，进而确定更改方向，尊重的同时服务于商业价值提升。

（4）剧本定稿环节门槛：

- 剧本成形、完成度较高后，则需要为剧本准备文字润色、音视频润色，如先导视频、教学视频等，影响店家、DM对剧本的了解，甚至是保姆级教学视频等；确保BGM等切合玩家状态，方便DM调整；
- 美工—显眼性，确保封面、剧本等吸引人，根据剧本内容等设计，而非泛泛。

（5）剧本宣发门槛：

- 时间节点：市场现状，如展会冷门品类，但主要考虑市场需求；紧跟时事，但要考虑受众情绪，落点要正，积极乐观正能量；
- 上展：2-3个DM，确保对剧本的理解足够深入，打好基本功，上展会时把本带好、演绎效果拉满—通过眼神传递情绪、情感；举例《云知道》，攻克视觉效果呈现；
- 授权意向书/意向表：登记信息，按表排序（私车＞公车＞ob）；
- 向作者传递：这是一个游戏，而非一部小说；
- 心态：心平气和。在展会心态很容易炸，要控制。

### 5.5 资源型切入点

其实，剧本杀周边还有非常多可以发挥的资源，可以说我们的资源用户在哪里，或者相契合的资源在哪里，我们就从哪个点切入。

- （1）拥有天然的销售群体

比如有公众号、抖音、小红书、B站等多媒体账号带货能力，可以挂链接销售C端剧本，销售单价30-60，约等于一本书的价钱。每销售一本都能得到很高的利润。

- （2）景区资源

剧本杀游戏逐渐朝着规模化、产业化的路径发展，对于部分剧本杀爱好者来说，单纯的室内景量已无法满足他们对于沉浸式游戏体验的要求，更多玩家开始对逼真场景展开期待。

在此背景下，不少旅游景区开始尝试与剧本杀游戏进行跨界合作，剧本杀游戏也因此随着玩家脚步，从桌游店里，走向了大漠孤烟、走进了流水人家。

对接景区剧本杀项目景区落地，从剧本创作的内容到服化道排练演员，从了解景区，到匹配产品，到帮助景区引流，最终达成项目的诞生。

![](img/a50ad26370b1cd7f67818735c6f556a8_1826_0.png)

目前“文旅+剧本杀”的主流运营模式有三种：

- A，景区外包，专业剧本杀团队负责运营；
- B，景区自营；
- C，各自独立对等合作（场地和团队各投资一半）。

这种新玩法由于时长增加，人均消费提高，未来有望成为剧本杀市场的一大重要板块。

### (3) 政府资源

从剧本杀拉动旅游业的角度来看，红色剧本杀以其独特的历史主题讲述了城市历史，丰富了城市的文化内涵；从城市景点对剧本杀的意义来看，特定空间与历史的联系赋予了剧本杀历史的沉重感，这无疑对于以沉浸感为追求的剧本杀是珍贵的。

6月30日上午，在洛阳抗战纪念馆里，一场别开生面的沉浸式实景党课开讲了。现场采用纯实景构建，巧妙运用西工兵营旧址年代感极强的近代建筑，以洛阳抗战历史上的英雄人物和重大事件为原型和线索，带领体验者迅速进入角色，体验我党抗战历程的艰苦卓绝，感悟伟大的抗战精神。

### (4) K12教育资源

近几年剧本杀在年轻人中大受追捧，随着“双减”政策施行，儿童剧本杀游戏也逐渐兴起，在全国的不少城市，不少家长都带孩子前来体验尝鲜。

跟成年人的剧本相比，儿童剧本没有那么烧脑，也不会追求恐怖刺激的感官体验，更多时候是通过角色扮演的沉浸式演绎，培养和提升孩子在阅读、语言表达、推理等方面的能力。剧本内容也往往会结合古诗、名著、历史、数学等学科知识，达到寓教于乐的目的。

双减政策下，大部分K12机构无法销课，全行业倒闭、失业。于是又不少K12机构转型到儿童剧本杀，用剧本杀的方式做到机构销课，继续运营。K12群体的接受程度远高于传统教学和知识点的补习。

所以造就了剧本杀授课转型之后很多机构小朋友的到课率达到了百分之百。

# 5.6 剧本杀创作教育培训、剧本杀DM培训等职业教育

剧本杀带动了更大的教育市场。包括剧本杀写作培训、剧本杀DM培训、儿童剧本杀写作培训、K12教育培训转型剧本杀、文旅产品剧本杀定制、红色剧本杀定制、剧本杀发行培训等，整个产业链中教育机能发展的兴趣爱好培训和职业技能培训产业都在迅速增长。

全国六万多家注册剧本杀店，导致中游链条中的发行方有了很大的市场，加剧了市场对剧本杀作者的需求，也就催生了剧本杀作者培训行业。

很多加盟店精品店的出现自然也加剧了DM的大量需求，而市场一时间缺少专业化的剧本杀DM，自然也就出现了DM培训机构。带动了原本不知何去何从的众多教培机构。

K12教育培训转型剧本杀救活了一众岌岌可危的K12教培机构，利用剧本杀的娱乐性，更容易被小朋友接受的特性。达到了大规模短期的销课，也带动了儿童剧本杀写作和课程研发的发展。

# 六、投资建议及风险提示

# 6.1 行业竞争加剧的风险。

剧本杀行业目前处于快速发展期，随着大量资本入局，行业竞争日趋激烈，或影响剧本杀产业链各方的收益。

# 6.2 行业监管趋严的风险。

剧本杀行业目前处于快速发展期，暂无针对性的法律法规和行业政策对行业发展进行规范，监管政策的变化对于行业发展的影响存在不确定性。

# 6.3 新冠肺炎疫情持续时间及对线下娱乐的影响存在不确定性。

全球新冠肺炎疫情下，用户线下消费意愿仍存在较大不确定性，进而对剧本杀产业链各方的收入影响存在较大不确定性。

# 6.4 盗版内容影响优质内容产出的风险。

剧本杀产业链上游依赖优质剧本内容产出，大量盗版版本的存在导致上游编剧收益受损，或影响其创作积极性。

# 七、自身破圈成绩

# 7.1 自身创作之路-成为作者

**2020**年春节，一场疫情打乱很多人的节奏。而我也一样，赋闲在家，突然看到一篇帖子，是关于剧本杀征稿的内容。我萌生一个想法，我是不是也可以试试，写一部剧本杀作品呢？

**2019**年，一次偶然入圈剧本杀，当时玩的本子叫做《谍影重重》，我所体验的角色是一名特工，生于苏联，被派到美国做间谍，美国又把我派到德国，我成为一名“谍中谍”人员。那是我第一次体验剧本杀，这个东西居然可以这样玩，让我忍不住热爱起来。从那天开始，我便入坑。

经过一次又一次的打本体验，加之从小到大就有点写作功底。说干就干，马上立起思路，开始构思我的第一部作品《天际情劫》。

写作的日子，毫不含糊，停止刷剧，停止打游戏，每天工作至少八小时。短短十天，我就写出了这部五人情感本格推理本，人均八千字，加线索设计，主持人手册，大概五万字左右。（当时觉得自己挺厉害的，现在回头看看，像个小傻子）

我满怀信心开始投稿到三家发行，得到的反馈却是，这作品如果作为小说，很OK。但是作为剧本杀，体量不够，人物之间交叉不够，挖坑不填，很多NPC出现没起到该 有的作用……

我满怀信心，却被打击。但我不甘心失败，因为被隔离，几乎不能出门去线下剧本杀店，我打开手机线上百变大侦探APP，专门研究别人的剧本，别人的设计。似乎找到一些法门，经过修改，再次投给济南一家发行。

终于，发行发来了合同，对方要签下我的作品，一次性买断，我可以不用再花心思，作为C端剧本，稿费6000元到手。

之后，我知道自己有很多不足的地方，开始不停研究那些成功作者的写作法门。同时开始我的第二部作品，关于盗墓题材的《离心镜》。

这一部的创作历程，经历了几个月。而写好之后，我没着急投稿，而是自己亲自带人测试。一次又一次，当玩家反馈出好的效果和口碑，那一刻，觉得一切都值得。

（2021年6月份由业内头部发行-黑桃皇后工作室发行）

![](img/a50ad26370b1cd7f67818735c6f556a8_1833_0.png)

2020年下半年，陆续写了很多C端本，以及微剧本。而C端本收入平均在6000-10000元。（虽然不多，但是找到了一些方法论）

之前的作品，是对方看了决定要不要。很长的一段时间，是发行方主动约稿制，提出要求，人数，题材，截稿时间，价格等，我来操刀。可是一个人的力量比较有限，我想要一个专业的剧本杀创作团队。

2021年春节，经过一年的研究，我和合伙人（浙江大学研究生）创建了一套剧本杀写作使用技巧方法论，通过这套方法靶向构建框架和故事，结果刷新新纪录，10天写完一个相对难度的八人剧本，赚得稿费 10000 元。

2021年3月份，亲自前往南京参加剧本杀作者提炼班，这个培训班上的干货内容几乎为零。比较好的事情是，见到一些成功作者的分享。在更加印证这套方法论的可操作性和厉害的同时，我心中又开始了新的征途。

# 7.2 从创作者变成创业者

2021年5月份，专门成立了剧本杀创作团队-春藤夏院。一边培养作者，一边继续深耕行业，打磨内容，创造价值，试图把写剧本这个技术活儿快速复制给其他想创作的朋友。

在打磨内容的同时，正好遇到新作品筹备上展会，人的精力永远是有限的，那段日子，没有一天是在凌晨3点以前睡觉的，我一度怀疑自己会猝死。
