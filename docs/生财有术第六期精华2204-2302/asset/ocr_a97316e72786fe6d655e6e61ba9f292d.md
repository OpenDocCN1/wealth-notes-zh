我是做个人成长类社群的，我的社群风格就是“三个全面”（全面日报、全面分享、全面复盘）“打破小透明”。就是在读书会中，所有人都要每天读书、每天答题、每天交作业，如果有缺就要移出，补完才能回来。很多人认为，这样太严格不友好。这样说的人，没有看到，如果你真正想要成长进步，那就要做扎实的、大量的甚至有一些无聊的行动。这些行动就是我们个人突破的基本功。

在个人成长中，基本功有：

+   （1）读书，不因为主题不喜欢而停止阅读，只要是自已应该会的，就能认真学完

+   （2）学习，不因为难度太大无法承受而放弃，只要是想学的，总会尝试突破

+   （3）听课，能集中注意力不走神，可以同步记笔记，听完就能输出

+   （4）复盘，参与了一场学习与讨论，能快速梳理出要点，整理收获体会

+   （5）遇到情绪波动，能抵抗得住放弃的诱惑，仍然保持前行

这些都是需要通过大量的行动才能训练出来的本领，是需要日日之行之功，不是一蹴而就的。而且这些道理也很简单，就是要持续行动，要去做。

亦仁曾经问过我，赚钱有没有什么类似个人成长学习的基本功？我说把赚钱的动作拆解开，然后反复练习，其实就可以。我列举几个：

+   （1）阅读精华帖，写阅读分析与评论，梳理作者思路，并总结可以借鉴的方面。

+   （2）在互联网上看到广告、文案时，不要马上跳过，分析这样写的原因。

+   （3）看到一些广告的微信可以加上好友，搞调研。

+   （4）持续用数据思维看问题，测算你看到的商业行为的运营数据，积累对数据量级的敏感性。

+   （5）见到你觉得文章写的有启发性的人，把你的阅读感想发给对方，不要只发自我介绍。

赚钱其实像一种技能，尤其是对于生财有术的赚钱的项目，更是实操型、机会型的多，那更要有大量的行动来突破，当然这也伴随着许多失败的风险。但是当你做一件高风险的事情的时候，想要提升成功率，能做的就是用更大的行动量爆破。

最基础的、最省事的，就是看帖子、写总结、写梳理。看上去不难，其实不简单。

# 3、赚钱守与时俱进

这部分内容稍微高级一些，就叫“有命赚，也要有命花”。

我以为，赚钱是一个结果，不是一个目的。比“怎么赚到钱”更重要的问题是“赚到钱以后怎么办？”给你钱的人，会怎么看你？你赚钱的行为，有什么影响？如果以赚钱为唯一的目的，多半会许多次兴灾患，这些灾害很可能会让你没命花这个钱。那你想想，即使你把这笔钱赚到了，又是给谁赚的呢？
