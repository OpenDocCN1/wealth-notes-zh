# 第一步：前期准备工作

裂变活动选择礼物的第一步，是先要了解家长的需求和喜好，建立起自己学校的用户画像，"投其所好"选择奖品才是裂变成功的关键。

引流卡价格及课时设计：定价根据学校以往体验课+评测课活动价格为主，及周边竞争对手价格做参考。

线上活动100元以内配合实物是非常容易成交的，价格超过100元以上需要付出更多的活动运营成本。市场主流价格是68元4节课。

我们本次活动主题：68元抢8课时精品课程

+   开团礼：榨汁机或蒸蛋器二选一。阿里巴巴采购成本30以内。

+   成团礼：涮烤一体锅或驼绒被一个。阿里巴巴采购成本30以内。

+   朋友圈裂变礼：多功能学习桌或收纳箱。成本8元内。
