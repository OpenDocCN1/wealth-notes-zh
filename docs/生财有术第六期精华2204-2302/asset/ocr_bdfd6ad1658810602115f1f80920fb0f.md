# 9、小红书数据维护

小红书的数据维护是很贵的，粉丝、点赞、收藏、评论，都是单独计费，而且不像其他平台做数据几分几毛就可以下来，在小红书上想做数据，单个量最低都在1元起。

通俗点说，1元一个粉、1元一个点赞、1元一个收藏，而且单独计算，我说的价格是保守数字，这个价格应该还算便宜的。

既然贵肯定是有原因的，以前有机器的，价格很便宜，现在都是人工刷，而且容易掉数据，小红书在数据这一块检查非常严格，很多人利用做假数据来接商业合作，对平台良性发展是一种障碍，但是刷数据需求量很大，如果谁能解决数据这个问题还是很香的。
