# ## 02 选品逻辑

魔术道具的品类其实特别多，99%都是大众没见过或者不会操作的，那么如何从中挑选潜力爆款，适合短视频1分钟内呈现，又有很强的视觉冲击感—— 不断测试，用市场反馈数据说话。

整体来说我们选择：新奇特，价格低，成本低，操作简单易上手，表演效果还比较强烈的。

# ### 1. 契合人群

+   - 儿童魔术道具（5-14岁）
- 成人魔术道具（18-60岁）

面对选品，任何类目思路都一样，契合目标人群我认为非常重要。

比如创意礼品，那么针对的就是18-24的年轻受众群体，可以是搞怪的，浪漫的，怀旧的... 男女朋友礼物清单之类，中老年人的肯定就不适合。

# ### 2. 产品独特性

+   - 新奇特（符合抖音特质）
- 视觉化呈现效果好
- 操作简单
