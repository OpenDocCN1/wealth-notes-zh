同理，当你的问题不准确，或没有经过思考深挖根源时，也很难找到答案。

# 案例1 你真的是想涨粉吗？

圈友A做公考培训，自己运营抖音号，问他现在遇到了什么问题，他说有很多，得梳理梳理梳理。

我马上发现，这本身就是个问题。跟他说如果不聚焦，不知道哪个对自己最重要，就会分散精力，最后一个都解决不了。

先挑一个问题，解决了再去想下一个。之后他聚焦了一下，说公考培训的抖音号怎么涨粉？

涨粉是自媒体永恒的话题，但如果你继续深挖，去找问题本质，就会进一步打开思路。

有人会说，不是已经确定问题了吗，为什么还要深挖，太麻烦了啊？

深挖问题是思考的过程，一方面可以把大问题拆解成小问题，更容易解决；另一方面能让你把答案真正记住，而不是一看一过，最后全忘了。

方法很简单，就是明确问题后，再追问自己5个问题！问着问着，你自己就想出答案了，思路也捋清了。
