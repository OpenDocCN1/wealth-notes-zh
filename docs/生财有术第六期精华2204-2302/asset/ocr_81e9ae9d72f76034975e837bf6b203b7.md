为什么很多人一直效率很低，因为工作方法从没有标准化，做事的节奏一直是乱的。

所以做IP要让自己高效率的工作起来，那就标准化工作。

很多人是这样的情况，「今天我心血来潮，我写个文章吧，明天我心血来潮，我做个直播吧。」

总之一切都是心血来潮的做，事情做的就很乱，那么结果一定是乱的。

简单拆解下IP的相关工作（简单罗列）

+   ①竞品分析：对手产品，吸粉，转化，运营，各方面的优势，实时追踪。

+   ②文章创作：话题选择，写文章，文章分发

+   ③视频相关：话题选择，写文案，视频拍摄，剪辑视频，分发视频，视频平台运营。

+   ④朋友圈：朋友圈素材收集，朋友圈配图制作，朋友圈分发。

+   ⑤社群运营：社群日常互动，社群分享，

+   ⑥课程运营：准备课件，课程讲解。

+   ⑦直播运营：直播素材手机，准备直播内容，直播

+   ⑧销售转化：客户转化，客户私聊。
