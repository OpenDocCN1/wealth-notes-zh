# 十二.未来优化师的核心价值在哪里？

反正不是投放，为什么？还是我朋友那个2天2夜的课程为例：只有半天在讲投放，其他的1天半，讲的是短视频素材创意的制作，标题，文案，选品。。。还是那个笑话，你愿意2天2夜都听“空气炸锅的说明书”么？

这里我必须要短视频和直播分开来说，再次强调：<span style='color:red'>直播间其实本质上就是一个动态可交互的落地页</span>。

+   1. 在短视频上，优化师的核心价值在于短视频素材，也就是创意的的迭代。之所以用迭代而不是创造，是因为其实创意不是优化师来做的，但是只有优化师才能指导创意的下一次迭代方向。
2. 在直播上，优化师的核心价值在于直播间的人货场，优化师相当于要跟场做半场控的工作。
