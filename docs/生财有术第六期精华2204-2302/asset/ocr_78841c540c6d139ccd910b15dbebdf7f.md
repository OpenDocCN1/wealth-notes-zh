# 2. 能够赚钱的时候一定要手软

上海限行政策加码以后，出现了流量的峰值，那个时候还看什么 ROI 呀，尽力去抢客户就好啦。

当行业出现机会的时候，一定要尽快地、把势能拉起来。现在客户总量在减少，但自己的客户体量还算稳定，主要是当时抢到了很多新客户，然后很多转介绍。现在只后悔晚抢了两个月。

# 3. 赛道选择：大江大鱼，小河小鱼

沪牌行业的整体体量、地域限制以及政策限产，决定了它就是一个小众行业。

这个行业没有太多的公司存在，绝大部分都是像我这样的个体创业者或者小团队，不是大家不想公司化运作，而是因为市场的天花板支撑不起来大公司的利润。当时的自己，完全没有认识到这一点。

不过，当时的自己还没有赚到主业以外的钱，没有挑的资格，如果对项目挑挑拣拣，到现在都可能一事无成。但对于有一定能力的朋友，选项目的时候一定要关注赛道的大小。
