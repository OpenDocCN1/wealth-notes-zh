定位这个事情，从自己的角度来说，你要考虑的是成本，比如我之前给大家分享的“3+1”定位法则，首先你就要找自己已经跑通的商业逻辑，因为这个是降本最低的，然后才是自己擅长的和自己热爱的方向。

而从用户的角度来说，你考虑的一定是需求，这个需求就暗藏了很多细节，比如都是想通过副业赚钱，但是用户更喜欢什么样的学习方式呢？

价格更高的一对一手把手指导？

价格低一下的训练营大班学习？

价格更低的标准课程自己学习？

不同的需求，就要适配不同的产品和不同的细分定位，比如我见过的一些副业高手，人家不做会员也不做训练营，只做一对一的陪练服务，一个人一年收**5万**块钱，帮你把副业的基础能力培养出来，并且提供适合你的项目，更细节的指导方式。

人家也是副业达人，但是做的服务跟你的不一样，结果就不一样。

# 3、做复盘，深思考

定位真的不是终身不变的，我自己的定位在这几年也是更换了**3次**，从最开始帮助用户通过朋友圈营销变现，到后来转移到社群这块，再到现在帮助自媒体创业者/品牌创始人通过打造个人 IP 深度变现。

其实最后一次的定位更换，就是我自己深度复盘和思考的结果。因为我发现，无论是朋友圈营销还是社群运营，或者是任何私域上的玩法，底层逻辑上都是在把你的**个人 IP** 转化成钱。
