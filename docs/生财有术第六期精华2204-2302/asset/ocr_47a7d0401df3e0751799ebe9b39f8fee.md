# 一、项目整体情况介绍

这次主要讲的是微信和QQ小程序生态，因为这两个生态的小程序分发机制和引流机制完全不同，而且这两个生态里面的目标人群都不一样，这样可能导致同一个程序在不同的生态下表现完全不一样。

# 1. 微信小程序生态

从2019年初上线的两款素材保存相关微信小程序（功能一样，UI修改成不同），累计服务用户有150多万人，公众号粉丝40W，引流到企业微信2.2W人。

值得一提的是这个程序从2020年4月份开始，几乎就没宣传和维护了，完全是靠产品自有机制，和外网以前的宣传来的搜索流量获取用户。

目前盈利情况是：平均一天被动添加好友人数在100-200之间。累计产生广告收入30W+，内购流水170W。
