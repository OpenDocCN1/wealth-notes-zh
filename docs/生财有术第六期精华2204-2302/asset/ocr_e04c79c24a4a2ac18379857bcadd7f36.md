# 【你在做或者想做的是什么项目】

创作一个NFT系列作品

# 【你的目标是什么】

+   1、作品交付：创作一个自己满意的IP形象，并通过丰富属性、合成的方式形成一个至少1000+件作品的系列；并相应思考IP形象的世界观、故事，为后续的创作做铺垫。

+   2、作品发行：走通发行一个NFT的流程。一期先建立IP网站介绍，暂不考虑社群阵地；加入更多相关社群，在社群、肚版上以空投方式发出。

+   3、项目效果：空投能够在3天内全部锁定；进一步目标是，作品能产生实际交易，从而获得收入。

# 【目前进展怎么样】

+   1、调研学习：学习了2个国外独立个人发NFT的经验总结，需要进一步仔细消化；油管上找到的1个经验总结视频，待看。

+   2、作品构思：结合自己之前的一些创作脉络，有了1-2个比较喜欢的形象idea，待花时间画出初稿。

# 我们在进行什么比赛？

NFT发行，目前不是一个创作比赛，而是「运营比赛」。

# 我们怎么得分？

战略上是靠「运营」得分。如果自己不懂，那就找懂的人合作。

战术上是靠「串联」得分。比较类似上面提到的淘宝蓝海小航海， NFT发行项目，需要串联起来的环节也非常多。谁有本事串起来那么多环节，每个环节都不漏水，谁就牛。
