用一句话来概述为：将全网引流的医美用户，通过公司销售团队进行一对一服务筛选后引导到全国合作的医院去消费，成交后医院按比例支付服务费用——我们统称转诊业务。

2、信息不透明真假难辨，
3、用户需求旺盛，颜值经济时代，谁都想把自己刮伤得更好看一些。
4、确保用户的信任——直接影响后期转化率

# 千亿级医美市场快速发展，增长快于全球

+   全球医美市场：规模稳定增长，2013-2018年全球医美市场规模由905亿美元增至1357亿美元，复合增速达8.4%，预计18-22年保持7.0%的CAGR，2022年全球市场规模将达到1782亿美元。
中国医美市场：2015-2019年中国医美市场（受监管市场）规模由 648 亿元增至 1436亿元左右，复合增速达 22.5%，增速快于全球医美市场，预计 2024年将达到 3185 亿元。
