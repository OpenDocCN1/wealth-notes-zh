后来广州本地对文娱市场把控开始严格，适合的场地资质寥寥无几，最后在2021年10月份我们才决定开始做属于自己的剧场。所选的位置就是客村，起势的位置。

# c. 现阶段流量（目前观众从哪来）

+   ·最大的公域流量来源：猫眼/大麦

+   ·少量售票平台：票星球/摩天轮/一些本地商家活动平台

+   ·少量私域流量复购/企业团购

+   ·本地商家互推or联动

+   ·商场部分广告位

随着我们演出场次的增多，目前已有的渠道流量已经不太够了，因此正式尝试新增渠道：抖音团购和小红书，月底开始做，还不太清楚效果如何。

# 2. 场地如何选择

一般先在人流旺的商圈，仔细逛一圈，然后留意那些地方的空间是否适合做脱口秀，目前酒吧、书店、艺术空间都比较适合脱口秀的氛围。最好是室内空间，以及整体较为聚气的空间最佳。

租场 （非固定）：有目标场地后，直接上门与负责人洽谈即可，现在疫情之下，大家都想增收，只要利益分配妥当，合作是没问题的。

场地合作 （固定）：这种可遇不可求，一般是商圈或商场想吸引年轻流量希望引进脱口秀，邀请厂牌入驻，一般这种类型的合作可免租金以及装修成本，后续谈分成。
