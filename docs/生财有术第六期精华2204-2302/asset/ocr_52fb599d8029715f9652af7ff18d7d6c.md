我担心自己永远卡在「做不出成绩」的阶段，无法逃出天大。后来我能跳出来，得益于六个字，就是「开始做，做完它」。

因为认定了这个目标，我从纷杂的情绪抬起头来，落实到做的每一件小事上，又从每一件小事上得到鼓舞，从而转起一个飞轮得到更大的正反馈。

其实每个项目的结果都是在实现和验证自己的想法。如果对了，就赚到钱。如果错了，就停止，然后再重新找方向。人生没有白走的路，每一步都算数，即使那时看起来做过的无用功。

相信我，只要你完成 1 个 从 0 到 1，你会迷上这种超越自我的感觉。
