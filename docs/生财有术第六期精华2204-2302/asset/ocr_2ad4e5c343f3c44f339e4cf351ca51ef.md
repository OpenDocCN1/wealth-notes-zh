接下来就根据这些年的实战经验，分享下中小企业如何通过互联网低成本引流获客。

# # 一、中小企业低成本引流

其实中小企业想要成功的通过互联网推广获客，要牢记一点：知行合一。

在营销层次可以这样看：

+   1. 知=信息差（了解到足够多的信息才能做对决策，节省成本，提高效率）  
2. 行=执行力（只有行动才会产生结果，没有执行力，什么都没有）
