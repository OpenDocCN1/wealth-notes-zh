# -审稿过程

+   审稿阶段（时间线请绕开双休，尽量从初稿到发布档期留足三个工作日）

+   一稿件名称（脚本、图文）：稿件命名需统一，在达人交稿前通知其命名格式（一般名称中包含品牌名，达人名及达人属性（koi或koc）），同时一次过的可能性不太高，需用【初稿】、【修改稿】加以区分。

+   一稿件内容：脚本——检查达人的稿件中是否有提及必要的卖点，逻辑是否顺畅，有无语病，太过平庸的脚本可结合当下的流行趋势、达人以往爆文或做出一些新鲜的内容创新，一同给到品牌完善脚本。

+   图文——文案和标题需仔细审核，图片需美观清晰。

+   视频——脚本反馈给达人时，再重复一遍品牌重视的点（例如产品细节的拍摄，美观清晰，时长），视频按照脚本定稿的版本来拍，检查画面和卖点是否对应，视频节奏不可太慢，否则可看不性不强。
