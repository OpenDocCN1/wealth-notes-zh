线上：联系学校的表白墙/万能墙，基本上每个高校都有是 QQ 上的校园自媒体，可以付费进行广告宣传；发布带校园话题的抖音，进行附近宣传，可以发一些优惠后的订单截图；各个高校群里进行轰炸宣传。

在宣传之前最好上架好力度大的活动，例如满 8-4 或者新人立减 5 元，这样可以促进首单。

# 四、过程中有哪些可复用的经验总结

# 1. 商户们不配合怎么办？

商户们不配合一般都是以下个问题：

# 1）嫌麻烦，本来就挺忙没时间整外卖，刚开始也没啥单子，或者岁数挺大也学不会

解决这块就尽量把商户的工作都由咱们来做，一开始的时候只拍菜单，由咱们的工作人员上传商品，完善商户信息，最大程度上减少商户的工作压力，有条件可以给商户搭配联网打印机，就告诉他按小票上的出餐即可。

# 2）资金问题

怕你卖了钱跑喽，这块直接给商户们开放每天都可以提现，秒到账，基本上商户们都没问题。
