其中，1 决定购物车转化率是否能最大化，尽量减少弃单，2、3、5 决定是否压资金，6 决定税务成本以及合规风险，4 决定投放 ROI 能否最大化（很多运营不知道这个点在损耗 ROI）

目前国产通道在 1、2、3、4、5、6 上都不同程度有短板，有些国内特殊环境以及卖家不诚信等原因导致这些问题并不能解决，因此形成一个长期无法解决的刚需痛点。

本来，国外通道对这一块是一个很好的弥补，比如以 stripe 为代表的国外通道，几乎可以解决以上所有问题，但目前 stripe 由于过于严格的风控，导致几乎没有办法成功注册并长期稳定使用。

# # 4. 用 stripe 做一个印钞机

如果你有一个可以稳定使用的 stripe 通道，那么你的独立站或者聊单支付链接可以享受到：

+   1. 高达 95% 的支付成功率
2. 支持 apple pay、google pay、wechat pay、alipay 以及众多国家的本地支付接口
3. 无保证金不需要同步物流信息，最快第二天或第三天全额回款提现，对比国内通道最多少压 90% 资金
4. 通过结汇公司可以出金到私人银行账户
5. 独立站无缝集成，不跳转，不弹窗

但是目前美国、欧洲、日本、澳洲、新加坡、香港的 stripe 均无法百分百成功开户，即使开户成功也几乎都会在使用一段时间时候封掉。造成这个状况的主要原因，还是中国的不发货不对版卖家，以及一些 xi 钱（洗钱）的交易太多。
