# H5 （10）稳定发布频率

如果可以，最好保持一个固定时间发布，比如一月一更，每个月1号，15号等。

一周一更，你可以固定在周三，周五，或者其他日子。

我们测试出来，有些日子视频观看量就是低，在前期的时候避免那几天发视频。在你 能接触到最多用户的那天发视频，对前期播放量影响是巨大的。

# H5 （11）直播加成

在YouTube上直播非常重要。直播对你账号的权重的提升不止一点点。

如果有时间精力有能力做直播的，我是非常建议大家做直播的。

直播在YouTube上流量挺大的，特别是游戏直播，近期世界杯体育内容也有流量加 成。
