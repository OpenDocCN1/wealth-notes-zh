#个人最佳金句推荐:

竭尽全力是最轻松的工作方式

这句话出自自读客创始人华楠，让我深有感触。

华楠需要打磨两块石头，然后找了一个打磨石头的工作室来取，一周后送回。拿到打磨的石头后，他觉得打磨得根本没有用心，其实打磨石头的要求很简单，只要用心打磨，就一定可以做好。

但他们就是不想好好干，对付一下就送回来了。

华楠讲了两句话，我很有感触：

+   1、 无论你做什么工作，只要竭尽全力就可以，竭尽全力是最轻松的工作方式。

+   2、 他们心不在焉，莫名其妙地失去了一个可以长期给他们好价钱的客户，然后继续抱怨人生多艰。

豆瓣上被称为神作的老电视剧，我一直没有看，去年才集中看完，如果我早10年看的话，估计会更加震撼。

虽然背景音乐实在是太很想吐槽……

个人最佳电影推荐：《否认》

这部电影并不主流，拍摄于2016年，根据《审判历史：我与大卫-欧文的双论》改编，讲述了因为纳粹大屠杀事件，历史学家黛博拉·利普斯泰特与大卫·欧文在法庭上对峙的故事。
