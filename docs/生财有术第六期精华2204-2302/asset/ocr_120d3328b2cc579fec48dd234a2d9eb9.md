# BPO测算案例

以2000员工为例（每人每月平均薪资6000元）测算结果如下：

| 做灵活用工 | 自雇形式 |
| :--- | :--- |
| 1. 人数 2000 | 2000 |
| 2. 劳务费金额 6000 | 6000 |
| 企业社保成本 1860 | 0.0 |
| 企业社保总额 5270000 | 0.0 |
| 员工社保成本 615 | 10 |
| 5. 纳税成本 1155 | 108 |
| 6. 税后收入 37345 | 38000 |

通过测算
①社保：通过BPO模式社保可节约372万/月
②个税：通过BPO员工每人每月实际薪酬增加626元

# 8、我想要采用灵活用工模式该如何做

1) 需要去排查公司那些岗位或者项目需要做灵活用工

简单概括就是：不需要交社保或者应该交社保但是能操作成不交社保的人；目前采用现金模式、不入账、两套帐的人，如果实在不会排查，可以直接找灵活用工服务商来帮忙分析。

2) 见面并选择灵活用工供应商

这里需要牵头负责的部门，基本在财务／人力／运营三部门之一，主要看自己企业内部分工，简单来讲谁负责要做灵活用工那部分人的发薪，就由谁来牵头。

3) 选定灵活用工供应商之后进行签约，由灵活用工供应商来安排与员工签约
