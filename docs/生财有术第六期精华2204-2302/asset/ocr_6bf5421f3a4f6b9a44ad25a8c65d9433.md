# 三、过程中有什么需要注意的地方

# 1. 心态要沉得住气

这个自发货到亚马逊 POD 模式成本比较小，主要成本是亚马逊店铺每个月 39.99 的美金+你的时间。

所以时间就花得比较多，快的话一个月出单，慢的话 2 个月，第三个月开始慢慢赚钱。

前三个月一天要按照 10 张图的数量来要求自己，后面出单了就不用做那么多图，转变为精做图。

小白尤其要有耐心，因为是主要是做这个的，所有业余时间去做的 话，是重复上班的内容，相对来说阻力会比较小。对于新手可以找美工合作，你找图给他做，然后你去批量上架到亚马逊店铺，运营出单。

# 2. 亚马逊平台规则的变动

众所周知，亚马逊这两年封号比以 前多，所以还是建议自己有资料去注册店铺，这样下来的店铺比较稳。

# 3. 规避侵权

第一类：

热门电影，比如漫威系列，你会发现是有不少人在做，可能一两个月不会抓，又出单很好，但是亚马逊可能会秋后算账的，要看你的承受能力。
