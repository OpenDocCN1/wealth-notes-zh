# ## （1）如何简政

我们社群开训练营时，原则就是怎么简便怎么来，怎么快速怎么来。总而言之，就是先让大家先都动起来，跑起来，无论有什么BUG，未来慢慢再修补就好了，绝不能把时间都浪费在前期的准备阶段里。

出课程的原则也是如此：能用一节课说明白的，就不用两节课；能用文字就不用音频，能用音频就不用视频，因为后两者浪费时间不说，迭代起来还比前者更慢，这样不符合我们打快攻的需求。

我们宁可摒弃正规的训练营形式，也要把速度追求到极致。
