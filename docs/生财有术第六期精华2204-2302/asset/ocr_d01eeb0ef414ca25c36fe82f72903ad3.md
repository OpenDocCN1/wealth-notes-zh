# 无价的家庭记忆

我们家花过的最值得的钱，应该是很久之前买的一台微单相机

从那时开始，我和老婆开始有意识的记录生活

生活是由无数个幸福的小片段组成的，这些片段会搁置在我们大脑的“遗忘区”。如果没有外界唤醒，可能我们永远都想不起来。

摄影，就是最好的唤醒方式了。

我和老婆都不是搞摄影的，那就学呗~

我们开了一个空间，专门记录家庭的点点滴滴，目前已经1.5万张照片了。

又过了两年，抖音的出现给了我极大的启发，原来记录生活不仅仅是拍照，还可以拍视频！视频能讲述的故事更多！

我们又购置了两套vlog设备，一套大的，一套小的。大的记录重要的家庭时刻，比如生日、过年、聚会、旅游等等。小的随身携带。

于是，我们家变成了，老婆拍照，我拍视频，每次出门摄影器材都要一大包

再之后，我开始了一项庞大的计划——每年给家里拍一部《家庭纪录片》！内容涵盖了对对我重要的家人们。从孩子到老人，记录他们的日常生活
