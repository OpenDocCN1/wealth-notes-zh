# 三万份问题地图全部销毁，中国人必须要有“版图意识”

长安观察
2019-03-30 16:41 | 北京日报报业集团 | 专栏

在保密部门的指定场所，803箱、28908份“问题地图”被运上粉碎机传送带，化为通粉。

一张地图不大，却直观反映着国家的主权范围，体现国家的政治主张。如此重要，如此敏感，自然不是小事。最近几个月，各地警方、海关连续收缴“问题地图”数十万张，阻止了国家利益遭受重大损失。

有的还会有对应的罚款。
