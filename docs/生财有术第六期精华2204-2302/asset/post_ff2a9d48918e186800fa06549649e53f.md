
有线下渠道加上线上工具，再去和同行谈合作，熟人相互推荐也是我们的一个客源。

## 2. 网络上引流

在知乎、抖音、微信、副业星球等平台上发布拆解项目的文章，找到对APP拉新感兴趣的人。

- 知乎主要是铺问答。通过5118，把知乎上和副业相关的问题找到，然后逐个铺文章回答。不得不说，知乎虽然反馈慢，但是很长线。很久之前发的文章时不时还会导流进来。
- 在抖音上试过直接发app拉新的副业宣传，是通不过的。需要换着方式做，先做副业IP，再代入这类项目。如果你已经有这部分的副业IP流量，也可以和我们谈合作。我们负责产品后端交付。
- 微信上我们主要就是发公众号文章，占据重点的搜索关键词，如“APP拉新怎么做”等。
- 知识星球上，我们也做过分享。在不同的星球发帖，有创业副业的圈子里。成本就是门票费。

如果你问，做平台工具赚钱吗？我会回答你，一般吧。主要是觉得这个事情有复利性，就养着做着。但如果你问，这个项目做招商加盟的很赚钱吗？那我一定会回答你，是的。

你在抖音上去搜那些做“试玩工作室加盟”的，全都是这类，行业里面叫做“充场工作室”，经久不衰。他们跑项目的逻辑就是把项目包装好，把公司装修有模有样的，收了加盟费，然后花钱投广告，然后再收加盟费。

和买量投放逻辑一样，只要投放ROI能回本，就不断投广告和收加盟就好了。

所以，市面上有利用这块信息差做招商加盟的，一个加盟商收个小几万，或者加个QQ群拿单子（对接交单，也就是下面的截图）就交个小几千，很多很多……反正这种事情我做不来，不想昧着良心去收这种代理加盟的钱。

我们没这招商的基因。所以老老实实做个工具，提供免费会员和资源对接，让客户先试用，觉得合适自己的再深入做项目就好了。

这样一来，好像反倒成为了清流（可能在同行里面算泥石流）。别人收入群费的我们免费，别人收加盟费的我们免费。

别人各种鼓吹项目多好的，我们劝你先看先学，用好了觉得合适再开会员，因为做充场这块利润可观，但是我们这几年接触到的各种各样的代理同行也有大几千了，但是真正能沉淀下来的十不存一。有人进圈，有人退圈。

既然有这平台，你们就别再当韭菜了。有一回有个新代理找过来，说早点遇到我们就好了，刚交了几万块，我也很无奈。

先搜一搜找一找资料，试用或者最小成本试错，避免走弯路。有的项目看着别人能做也未必适合每一个人都能做起来。

# 四、项目怎么做？普通小白能不能做？具体怎么做？【针对CPA拉新项目本身】

## 1. 你能不能做？

逻辑上，这项目是人人人都可以做。尤其是通过平台，自己注册后有针对性把平台上自己能做的单子做一遍起码几百到手、或者有资源的就自己去做推广，赚推广佣金，或者成立线下工作室。

结算、推广我们都做成工具了。只要按要求做单就可以拿到推广佣金（就是自己用自己的信息去注册新用户，薅平台推广奖励）。

## 2. 具体怎么做？ 推广方式有哪些？

目前业内CPA拉新主流的模式主要有地推、网推、APP充场工作室这几种，下面简单介绍这几种方式

### （1）地推拉新：

就是在大街上让人扫码下载APP送礼品那种，一般都是单一的产品或者组合产品，如京东、淘宝、快手等，一天基本能推个三五十单，做得稍微好些的每天收入基本能在500+以上乃至几千。

### （2）网推方式：

也就是在线拉新，这种方法就比较简单了，在渠道那里拿到任务，自己选一些合适任务放在网上找兼职做，可以通过QQ群、微信群还有一些流量较大的平台通过帖子软文的方式引导及悬赏平台来招人，按完成任务数量结算，正常一天也能有个300+（当然这个最终还是得看你的资源和能力）。

如果你有骚操作的引流方式，比如抖音上通过某些噱头引流，量大起来收益就很可观。仅靠一款APP的拉新任务也是够了。

### （3）充场工作室模式：

是以招聘兼职的形式，招人到工作室做任务，工作室把各渠道CPA任务汇总起来形成一个任务集，由客服统一引导兼职操作，每个兼职正常一天能完成30个任务左右，收益基本可以达到500~600，而成本就是兼职的工资大概120-180/天。

行情好的时候比如年初的时候有农行一拖十的单子，我们团队基本能做到单人产值一千左右。就按一个兼职平均500产值算的话，那平均利润大概在300/人，如果一天能招10个兼职，收益就是3000/天，一个月就10万左右了，能做到这个产值的前提你必须得有渠道能找到10个兼职，然后你的任务渠道也能满足每个兼职做到30个任务，最后你还得有一个以上合格的带单员。

# 五、如何对接一手/二手拉新资源平台

好了，前面我们提到快手极速版的价格问题，“别人快手极速版不是70块钱吗，到你这里怎么20元了”。

要回答这个问题。

## 1. 首先要理解这个产业链

给出结算推广佣金的是厂商。也可以理解为甲方爸爸。

比如快手极速版，那甲方就是快手公司。甲方爸爸要冲量的时候，肯定会多方面多渠道收量，那量就有很多种。

CPA这类推广裂变的量也算一种，所以产品也是看周期看甲方推广政策的，比如电商类的APP双十一要冲榜啦，那就大力收一波量；最近要冲些数据啦，那就放高点价格，所以佣金价格有时候会变化，任务形式有时候也会变化，这都是甲方爸爸决定的。

那么，做推广的大渠道，就会拿到一手单子，然后再放给二、三、四、五、六手等等。这个转多少手都没问题，核心问题是你自己的资源，你自己的流量够不够多，量多则能往前走，接近源头。

这里的放单逻辑无非就是层层下放，量多则价高。

网络上随便说自己是一手的都不是一手。至少也是三四手以后吧。作为厂商来说，一定是对接有大量的渠道主。能整合资源跑起量的，自然能拿到的价格就高。

否则就算你知道这个单子是从哪里接的，就算你找到这个人，也无济于事，别人要看你能跑多少量，才会给多少价。

简而言之：有量有价。

这里提个题外话吧，做大渠道呢，也需要承担风险。就是要垫资。甲方或者上家没有结算下来，结算周期月结或者次月结的时候，得有能力有资金自己先垫资，把自己的下家结算好了。

如果夹在中间，结算了下家，上家跑路了，这种情况也常有发生。

所以，找单子接单子，安全靠谱，结算稳定是非常重要的。有的单子确实接过来价格高个几块钱，但是最后没办法结算，那白搭；或者结算的时候扣单，100单做了，告诉你只能结算80单，回到头来，可能还不如那个价格普通但是结算满的渠道好。

很多推广的单子都是有梯度的。就是达到多少单可以结算多少价格。

所以想做好CPA拉新，稳定的渠道和兼职来源缺一不可。

# 六、平台打造过程的问题和解决思路总结

总结一下我们平台开发过程中踩过的坑：

**1. 没有一步到位的工具，只有根据需求一步一步迭代。**

一开始我们就想着一步到位，所以我们第一版就直接把APP版本做出来了，结果因为没结合市场实际需求给到我们代理使用后反应一般，主要一点就是APP下载太麻烦了，测试一段时间后我们果断放弃。根据使用反馈采用了H5+公众号的模式。

**2. 站在用户角度去思考：**

我们一开始平台是只有一个版本的，然后我们想平台内容更丰富一些，就增加了很多的模块，比如CPS，社群，训练营等，但是在推广过程中发现很多代理是不需要的，甚至有点排斥，因为他们担心太多的我们平台的内容会影响他们的用户，所以根据他们的需求我们重新做了一个纯净版本（只有CPA拉新任务模块），结果纯净版的使用率比我们主版本使用率还更高。

**3. 成本优化，提高效率，还原工具的本质：**

因为在平台开发之前我们就是做渠道的，关于任务渠道资源的管理和任务审核，一直都是我们比较头痛的问题，因为渠道都是我们自己对接，然后客服审核这些都是我们在做，所以高峰的时候我们任务审核客服都备了8个。尤其是平台上线后8个客服都忙不过来。

后来考虑了一下这样运营太重了费用也高了不符合我们做工具的初衷，我们得先把自己的痛点解决，所以我们又开发了一套商家系统，让每个商家入驻负责审核自己的任务，然后又增加了在线客服功能解决线上咨询和任务复查问题。目前我们8个客服只保留了2个，节省了一大笔的开支。

**4. 利他才能利己：**

平台上线后很多行业小白进来，尤其是很多新开的会员，完全是对这个行业不懂的。虽然我们初衷只是为他们提供一个效率工具，但是新会员进来毕竟是付费了，付费你就得有交付啊，你不可能人家小白进来就丢给他们一个平台说明书，你自己看着玩去。

这部分小白用户是我们一开始没考虑到的，因为我们这个工具原计划就是给我们现有的代理会员去使用的，他们只需要了解功能就可以了，不需要对项目的培训。

所以针对小白用户所以我们又开发了一个打卡训练营工具，同时也上线了21天打卡成长训练营，帮助小白用户从0到1再从1-100去落地项目，训练营分为付费（保证金形式）和免费的。

# (精华帖)(205赞)加入生财 3 年我在北京买房交首付，自媒体人怎样实现收入指数级增长？

作者： 芷蓝

日期：2022-12-27

上个月花了 400 万在北京搞定了一套房子的首付，全职自媒体 5 年，真正实现收入指数级增长就是在加入生财的这 3 年，其实我并没有去做什么项目，而是通过在生财大量阅读精华帖，不断地优化我自己思考问题的方式。

![](img/a50ad26370b1cd7f67818735c6f556a8_4119_0.png)

当然如果非说项目，其实一直在跟亦仁学社群运营，生财的运营框架和运营细节才是给我最大的反馈。

年底了，和大家分享一些我做自媒体的小感悟，希望对生财的各位小伙伴有一些帮助。

首先我有 1 个认知：不创业一定不会拥有大量财富，而创业失败的概率是 90%，所以注定只有极少一部分人才能成为年入百万甚至千万的人。

当然，好好上班也并不影响你做自媒体，年底了，有些人可能又要琢磨着明年初辞职，这里芷蓝还是劝大家慎重+慎重，你看到很多人赚钱，并不是持续稳定的，不要把自己和家人的生活质量当做创业赌注。

# 一、努力也要看运气

很多人觉得，自己不成功或者说赚不到钱的原因就是不努力，在我看来只说对了一半，这要看你说的这个【钱】到底是多少了？

赚小钱，靠努力就没问题。

生财里有大量项目可以供你选择，我也来了 3 年了，看到很多圈友通过社交电商、知乎好物（内容电商）、抖音视频号带货、闲鱼无货源等项目赚到了钱。

甚至是出去摆摊做拉新，聪明一点的去人流量大的地方摆摊，再聪明一点的，把买过你小商品的人都加到微信上做复购，再再聪明一点的还可以把这些人都放到你建的社群里玩团购。

当然，就算你把这些都尝试了，且一直在坚持，可能你一个月也就多赚个 2-3 万块钱，而且不稳定，这个就是努力赚来的小钱。

以上这些，你都没有逃脱一种模式，那就是靠出卖自己的单位时间价值来换取收益。在这种模式下，拼的是肉体的能量极限，也就是你干得就多赚的多，不干就没钱。
