# 二、如何找到合作商家？

# 1. 行业积累

行业积累是很大的一方面，我自身做教培8年之久，并且在国内最大的教培公司做全国1万+校区的运营服务，客户量比较大，生源需求量比较大。

艺术类机构和摄影店的合作非常频繁，我们拥有的摄影店资源相对比较多。再一个我媳妇是做大健康产业，养生店的资源也是OK的。

关于资源积累这块，可以从身边的亲朋好友下手找突破口，还是可以的。当然拉新这个业务是每个行业都需要的，看你如何去谈，如何去策划。

# 2. 电销拓展客户

可以借助58同城、美团、本地信息网、行业信息网，某宝和某多有无商家信息采集软件的。

当然，你也可以一个个的进行咨询，加微信。采集软件更便捷一些。数据采集完毕以后，可以进行电话陌拜，再加微信进行沟通需求，最终定到店服务档期。

也可以采用模拟手动输入加人软件进行批量添加，注意验证信息即可，通过率可达到80%。
