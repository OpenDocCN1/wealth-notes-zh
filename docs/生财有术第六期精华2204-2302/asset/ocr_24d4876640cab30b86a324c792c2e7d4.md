# 三、复盘总结及难点

# ### 1. 不断迭代

要想获取更高的销售额就要更加精细化的运营，现在引流和私域转化方面还是比较粗放的，需要在横向和纵向上进一步迭代。

横向上，一是总结起号标准流程，扩大矩阵账号数量；二是继续扩大销售团队。

纵向上，一是要提高账号流量；二是进一步优化和打造朋友圈营销内容；三是提炼高转化话术，形成话术本。方便扩大销售团队。

# ### 2. 销售团队

一定不要试图自己来培养销售人员，提供平台进行赛马就好。
