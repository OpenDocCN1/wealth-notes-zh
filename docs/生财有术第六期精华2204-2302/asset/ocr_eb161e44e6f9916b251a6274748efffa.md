# 运营工具

+   *   工具类
    *   文字：推荐：花样文字
*   图片类
    *   拍摄&修图 简易好用：VSCO
    *   拍摄&修图 复杂处理：推荐Snapseed
    *   拼图：推荐Yango
    *   范围推荐：天天P图或Piestart
    *   加字：推荐 黄油相机
    *   海报推荐：创客贴
*   视频类
    *   简单带模板：剪映或者VUE
    *   专业剪辑：Videoleap
    *   相对专业且相对易用：Vlo或闪
*   数据类
    *   个人G品牌：免费且易用：小红书App品牌合作中心
    *   个人G品牌：付费且全面：千瓜数据
    *   个人G品牌：免费且全面：数旁数据
*   广告盈利类
    *   官方平台或MCN：小红书品牌合作平台
    *   广告类一般比较安全：个人简介留邮箱
    *   广告类不太安全：朋友圈广告及ED广告（务必注意核实真实性）
*   涨号关注
    *   流量获取的渠道：模仿经营多号或者创作者小站号

# 01.把小红书当朋友圈发

小红书是我们表达自己的地方吗？

当然...不是的。

我们做小红书是想引流获客，最终是要做生意的，当我们不是IP、没有粉丝，把小红书当成朋友圈发生活，结果还是没人看，我们既然运营小红书就是有意的商业行为，就是想让更多人看到。

其次，随意表达坏了标签，今天这明天那，平台都不知道你是谁，怎么知道把你推给谁呢？
