# 原创内容

可在抖音搜索并加入“伙伴计划”，加入后同步原创内容享受抖音、西瓜、头条的流量分成

前期对新号来说，直接同步中视频计划，会导致难以破流量池，不利于我们起号。

所以前期选择不同步，等抖音这边播放数据稳定上万，并且粉丝量起来打上标签以后，在通过西瓜同步到抖音。

或者通过作品同步的端口，从抖音同步到西瓜并勾选原创，从而更好的获取流量，获得中视频计划收益。

2.西瓜视频发布：

西瓜端发布时，一定要上传横版**16:9**的视频，并勾选原创内容，才能参加中视频计划获取收益。

西瓜视频的标题很重要，限制是**30个字**，我们要尽量都用上不要浪费。
