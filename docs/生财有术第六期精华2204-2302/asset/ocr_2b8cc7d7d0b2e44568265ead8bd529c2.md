# 3. 精准客户是谁？如何找到他们？

通过上文，咱们可以知道，“SAAS源码”的精准客户就是全国中小型，没有研发实力的网络公司！

找到他们非常的简单，他们就在那，每当有新的风口，他们都在疯狂的寻找能包装成他们自己产品的“SAAS源码”。

这也是“SAAS源码”行业对“程序员”最有吸引力的地方，你只需要把风口选好、产品做好，哪怕不推广，都会有客户找上门来。

当然如果初期系统的名气不是很足，需要做一些适当的推广，主动去获客。

+   ①电销或加微信（毕竟网络公司的联系方式非常好找）

+   ②一些站长平台上投放广告（卢松松、A5、站长站、巨量引擎）

+   ③放一些开源的系统出去，吸引客户（码云、Thinkphp平台、各大源码平台）

+   ④互联网圈子（微信群、QQ群、软件协会）

+   ⑤私域流量
