# # 降本增效

一方面是它对人类信息利用的降本增效。

首先，ChatGPT 的出现帮助人们改变信息和知识获取的交互方式，它通过训练语料库识别语法、语义和情感分析，可以稳定高效的支持我们对内容总结、机器翻译等等需求。

通过向ChatGPT提问，你几乎可以定向了解到大部分领域所需的信息，这可以让我们在海键的思考与逻辑梳理上拥有更多的时间。

降低我们的获取信息的门槛，节省我们整理信息的时间，这些都是降本，且同时降本本身也是一种增效。
