# # 6、对抗焦虑，最好的办法是做具体的事情

我很喜欢华杉的这段话：

> 你想要的东西你没有得到，然后你手上的东西，你又没有认真去干，就会焦虑。焦虑，就是有欲望，但是没得到满足。

但是在这种情况下，如果手上的活很投入、很认真的去干，也就顾不上去焦虑那个未来的那个事情了。

所以，我觉得这是个最重要的哲学，就是大家要认识到人生的一切都来源于运气，包括你的本事，你的本事也是你的运气。

我们要保持大材小用，你不要觉得现在在你做的这个事情你不满意，你要觉得现在做的这些不满意，然后你想做别的事情，唯一的路径就是把现在的事儿做好。因为你把现在事儿做到极致了，机会就来了，必有事焉，而务正必有事焉，就是一定要用功。

人就是要进步，太容易了，你多用一点心，你能够获得的东西远远超过你的那个想象，近悦远来，所有东西都不是你去争取来的，都是你在自己手生的事几上上下工火，他自己来的，你必定要就这来。
