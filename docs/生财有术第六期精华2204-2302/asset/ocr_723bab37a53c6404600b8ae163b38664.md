# 4.财务思维，受益终身

一个项目到底值不值得做？就是3个判断逻辑：

+   1）有没有人做、做了多久、做的结果怎么样。

+   2）做的人资源怎么样、你是否可以复制、要找什么样的团队。

+   3）投入多长时间、投入多长时间内、预计收益多少。
