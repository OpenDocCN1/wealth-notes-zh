+   1.有天赋

+   2.你热爱

有天赋，就是你干某些事情，轻轻松松就能比别人干得好，学得比别人快。

这样你有更大概率完成一步步的必要推进动作，更大概率建立正循环。

热爱，就是你可以废寝忘食的干那个事情，没收入也乐意，别人干起来痛苦，你干起来快乐。

这样在开头难的阶段，你有更大概率坚持下去，因为做这事你体内比其他人会分泌更多的多巴胺，往往离变现，就差那么几次无收入时候的执行。

所以，如果符合有天赋、你热爱这两点，在成本上你就天然比其他人有优势。

如果还能再用上你以往某些经验就更完美，一样的干，你都自带壁垒。

# 2 启动成本低

为啥澳门说不怕你赢，只怕你不来。（因为你去的次数够多，以他能占城市一半以上经济的算法，你还不会输么？你又不是发哥）

反过来，在副业上，你能有无限初始筹码，无限次上场机会，你只需要赢一天，你觉得没有这一天么？

所以启动成本多少，决定了，你有多少次上场机会。

成本足够低，就意味着你有无数次上场机会！

只要你不放弃，大概率就能有一次成功，就够支撑你未来所有梦想了。

最坏结果，即使一个项目失败了，也不会有很大损失。
