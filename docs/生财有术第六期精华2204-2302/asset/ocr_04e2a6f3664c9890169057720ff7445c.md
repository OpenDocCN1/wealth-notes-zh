# 一、简述代拍行业的产业链

沪牌每个月发放牌照 1W 多张，去年每个月大约 20W 人参加竞拍，从业务规模来讲，客户有限，是一个小众行业。但这个小行业的分工其实十分严密，从产业链条上来讲，一般分为收单团队、代拍团队、软件商以及码工团队。

# 1. 收单团队

也就是我们常说的黄牛，作为流量方在市场上进行收单。

上海的朋友在商超都能看到有 XX 代拍，这个行业最早就是由线下发家，做的早的在线下网点已经形成了规模效应，对线下流量有一定的垄断能力。直到现在，线下获客还是主要渠道。但是线下成本比较高，需要租场地并且至少要有两个员工进行倒班。对于刚入局的新手来说，我选择了成本更低的线上平台。

除了头部两家知名的品牌以外，大大小小的线上线下收单团队也特别多，数量估计在几百家以上。

数量众多的原因是这个行业属于弱势品类，客户不会指定必须要某个品牌，只要能帮客户搞定即可。小的收单很多是 4S 店的工作人员、驾校教练、二手车行业的从业者，利用自身的资源进行收单，然后再交给代拍团队拍牌。
