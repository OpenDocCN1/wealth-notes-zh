# b) 解决需求但供给无效

我将将这一类统称为黑五“保健品”，比如壮y，减肥，生发等。毫无疑问这些也是刚需（但是东西到手后，并不立即见效，一段时间后如果无效，则需求一直在），稍微了解的人都知道，这些几乎都是“绝症”，现代科学并无真正解决方案。下面我们逐个分析下，这里面藏着我们本次探讨的快钱选品的核心底层逻辑。

针对ED（x功能障碍）虽然西医有完善的副作用很小的正规药品，但跨境电商黑五卖家并不卖西地那非，他达那非这种正规药（没有资质，也没有暴利空间），他们卖的往往是采购成本只有几分钱一颗的药，而售价为几美元或者十几美元一颗，实际成分和面粉本质上没太大区别。

ED有心理性也有病理性，个体差异很大，即使正规药，每个人的剂量和用法也不一样，所以吃了没起效，是一个常见的情况。既然有不确定空间存在，那么对黑五卖家来说，卖面粉和卖真药的纠纷率不会相差太多，自然他们会选择成本更低的。

肥胖也是个个体差异很大的问题，实际不可能有一种药可以让所有人成功减肥，如果有则是很明确的伪科学。

脱发（雄秃）则更是明确的绝症，但与对ED和肥胖的认知一样，大部分人的科学素养达不到正确理性认知，因此存在非常大的非理性刚需消费。

黑五卖家能长期赚钱的把戏正在于此，为这些刚需的，缺乏常识的，非理性的，无解的需求，提供看似有效（虚假宣传）的解决方案。
