# 一、选择大于努力

我为什么选择做教培、养生、瑜伽、健身房、摄影店、水果店的拉新？

疫情当下已经改变了我们的生活方式，实体店的倒闭潮来的更猛了一些，线上的服务层出不穷，这也出现了很多的帮助线上增长的业务。

比如盛极一时的知识付费分销，社区团购拉新，APP注册拉新等等，太多的拉新裂变可以让我们挣得一笔丰厚的佣金。

随着ZC影响，很多拉新做不了了，而且及时可以做的单价也相对比较低了。互联网烧钱拉新的时代基本结束，这个时候你再做一款APP，基本注定失败。

互联网虽然对实体店冲击非常大，但实体店一定会存在，只是存在的形态不一样。
