+   3. 通常需要维护多个网站，增加开发维护成本。

使用 Sub-directories 子目录实施国际 International SEO 的优点和缺点分析

优点：

缺点：

+   1. 对搜索引擎的国家地区信息很弱，地区排名较弱

+   2. 难以根据受众地区单独优化提速
