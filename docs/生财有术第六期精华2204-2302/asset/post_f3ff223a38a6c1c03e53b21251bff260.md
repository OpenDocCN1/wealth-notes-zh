# 三、如何进行高效创作内容

小红书是一个种草平台，种草的本质，是改变心智。

意思就是，通过你的内容，构建用户对你的认知，当他们遇到困难需要解决的时候，第一个想起的是你，而不是其他人。

就像一提到空调，你就想到格力，一提到赚钱项目，你就想到生财有术，一提到做小红书，你就想到梨云。

这里的关键，就有三个因素，第一，内容专业能解决问题，第二，内容要吸引用户完成心智影响，第三，内容要持续输出巩固记忆。

### ① 内容专业

很多创作者对内容专业有误解，以为写的像百度百科、学术论文，才叫专业，结果就导致很多在领域里特别有积累的人，来到自媒体平台，根本做不起来。

什么叫内容专业？就是用通俗易懂的表达，解决用户的问题。

因为用户不是内行人，他问你怎么做爆款封面，你一张口就是色相色彩饱和度，单色明度群体化，他会直接因为看不懂，而跳出你的内容。

但如果你像《梨云绿》这样抽丝剥茧、大白话说出来，不仅好理解，而且用了真的能出效果，那么专业的认知就构建起来了。

小红书这个短快平的平台，更是如此，所以在给方法的时候，一定要注意这3点。

- 方法要流程化，可落地，并且简单有效。
- 方法表达过程中极其简短，能用一句话说清楚的绝不用两句。
- 复杂的、1000以内讲不清楚的内容，不适合放在小红书上创作，这也是为什么你公众号、知乎写的牛逼，来到小红书就不行的核心原因。
