# H5 为什么要写系列教程呢？

一是，想和同行形成差异化，我发现大多数同行们都是根据当天的行情输出一篇自己的思考或者指导意见。诚然，这样会吸引到很多“勤奋”的喜欢追逐消息面的投资者，但是可替代性太强，门槛太低，写系列教程可以加深自己的“护城河”。

二是，我想有自己的代表作，这个作品能经得起时间检验，让人们愿意反复阅读。我当时关注的B站up主，像「雨说体育徐静雨」、「阿斗归来了」都有自己的代表作和系列作品，很容易吸粉和形成粉丝黏性，能给别人关注自己的理由。

三是，为做课程铺路，写好了系列教程，再稍微优化一下，就可以直接做视频课程了，是一件有长期价值的事情。
