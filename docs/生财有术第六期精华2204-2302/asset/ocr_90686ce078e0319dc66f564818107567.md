# 5.时间，每天是否可以抽出2小时做闲鱼

这个副业虽然是手机就可以做，但需要找图、上新、补单、聊客户，每天零散时间2小时还是要花的，想发布产品后就躺赚是不现实的，你本职工作都得一天花8小时，这个只不过是花一份时间赚双份收入。

# 6.设备，2-3号起步最佳，单账户有点太局限，起来的时间比较慢

现在没以前那么好做，所以单号流量不确定性太高，建议2-3个手机开始做，买4G内存的手机就可以做闲鱼了，两三百块钱一台就可以，流量卡9.9一个月就可以做起来，一个人可以实名认证3个闲鱼号。

# 六、经验分享

我自己也做了10年销售了，目前也是工作+副业的形式做，有一份稳定的后端收入保障生活，可以让自己可以毫无顾忌的去折腾挺好的，无非就是赚的多和赚的少的差别。

副业可能会超过主业的收入，但轻易别放弃主业，你做副业的目的可能是想更轻松地生活，可能是想有更好的发展机会，但这一切都建立在自己付出的努力有多少，自己的认知差到哪种地步上，我自己个人是主业*副业，很香。

当你没有一技之长的可以努力去学，当你有了一技之长的可以抱团取暖寻找组织，自己可以做那个组织的开创者也可以加入别人的组织，有人可以交流的时候可以少踩很多坑，但真正的干货，都只能是自己摸索出来。

我从低客单转到高客单历时几个月，从自己卖到搭建纯做摄影的代理团队，如果没有前期的积累也不会有现在这个做供货商的角色，唯有不变的是变化。
