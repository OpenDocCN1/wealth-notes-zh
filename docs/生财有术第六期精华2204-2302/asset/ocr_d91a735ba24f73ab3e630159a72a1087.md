# 1、启动资金（综合公司为例）

项目启动资金一般是 5-10 万就够了（房租没算，差异大）

60% 工资＋10% 日常＋10% 宣发＋20% 备用（双月）

# 2、办公环境等备

+   - 公司注册＋对公账户（一般纳税人）
- 办公室 5 人标配设施（网络、饮水机、办公用品、打印机、电脑、白板等）
- 统一收款信息：支付宝、微信、银行卡、对公账户
- 招聘：BOSS 直聘、兼职推荐等，集中招聘，5 人一起入职
