（这句话，生财圈友是不是很耳熟？）

所以，他现在会三个月办一次线下游学，这就极大提升了影响力。

因为内容很容易获取，但永远无法替代线下体验。

而因为线下见了很多人，就会获取很多信息，把自己当成一个信息情报的中转处理站，这些信息处理一下就是新的作品，别人就会认为自己很厉害，其实只是自己见得多，获取了很多信息。

# 8、每年都做大事件，让别人“哇塞”的同时记住你

做生意，不怕你做不好，就怕别人不记得你了。

很多人，刚入行做IP的时候踌躇满志，过几年就发现，没几个人在活跃了。

而要让别人知道你现在还在做，还能想起你，就得做出让人震撼的事情。比如连续1年日更朋友圈，比如减肥减了30斤，比如一个视频播放量冲到100W。比如去年3月，猪先生连环了一百场的论语直播。

生财过去就有很多圈友，靠着事件让更多圈友记住，比如分钟冲到了榜单前三、连续拆解了100天精华帖等等，这条路已经有无数人走过，期待下一个做出大事件的人是你。

# 9、内容输出得先达到一个量级，才能引起质变

做IP，最重要的是内容产出能力。而内容输出就是三件事：人，事，物。

+   第一，背后要大量地见真实的人，才能用到产品设计和内容上。
第二，是观察生活中的事物。比如去吃饭也可以观察这个饭店的生意。
第三，大量做分享，激发自己产出更多内容。

比如今天在生财看了项目分享有启发，能不能更5条朋友圈？

做了一场直播，能不能切出200个视频切片？

如果量都没上去，一周发两三条朋友圈，那就无法让自己达到质变的临界点。

# 10、自己活得真实、有能量，就会给别人带来能量

自己内心喜悦、内在丰盛，是非常容易感染别人的。而如果自己每天都很疲惫、脸上就写着累、不满足、焦虑，也会让别人远离。而且，自己也很难坚持做下去。

线下看到猪先生，在分享的时候充满了快乐，讲到精彩处手舞足蹈，台下也笑成一片。这种感染力，会让人产生冲击，远胜于文字信息。

之前听说过一句话：快乐、好玩，是第一生产力。如今又有了新的理解。
