2）看客户的信息，如果是本地的，大概率也是，pass 掉。

不管是抖音和快手，每天的关注和私信动作都是有限的。一定要珍惜每个机会，最大限度地与精准客户发生关系，让更多客户看到我们。

# 2.2 同行的直播间

我们会筛选没屏蔽用户信息的直播间，然后用私人号（产品号会被踢）进直播间看。我们一旦看到有咨询主播，或者问价格的，我们就会点开这个用户的主页，记下抖音号，然后用工作号去搜索、关注、私信，基本的操作跟同行短视频评论一样。

# 3. 把精准客户从平台导入到微信

找到精准用户之后，就需要把他们导到我们的微信里成交。我们一般有有以下这三种导流方法。

# 1）评论直接问价的：

关注且直接私信，然后打开主页，找一个作品简单评论一下。

# 2）评论但没问价的：

先只关注，如果后续对方回关了，我们再进行私信（回关说明大概率有意向）或语音沟通。语音通话中直接问客户要微信加上。这种客户最精准，重点跟进。

私信的文案，内容大概 50 字左右，复制粘贴。粘贴完，修改其中至少 30% 的内容，再进行发送，只要意思不变即可。避免被判定为相同内容，私信骚扰。
