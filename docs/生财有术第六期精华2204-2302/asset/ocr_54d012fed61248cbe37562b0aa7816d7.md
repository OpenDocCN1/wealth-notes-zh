# # （4） 公众号爆款的原理

说完收益的来源，我们还需要弄清楚流量的来源。我猜很多人都会想：我们已经知道，就算公众号没有粉丝，文章也有可能被系统推成爆款。那么问题来了，<span style='color:red'>文章要写成什么样，才会被系统推成爆款呢？</span>

根据我们的经验，需要满足以下的两个条件。

> 硬性条件是，正文的完读率要好

只有读者把文章看完，才能完整展现全部的贴片广告。当所有的贴片广告都得到展示之后，不仅我们能挣到钱，平台也能得到很多好处（广告曝光+用户沉迷时长），所以平台愿意给这样的文章，以更多的流量推荐。

<span style='color:red'>所以，文章字数在1500-2200字的范围之内，是最好的。</span>如果写短了，公号正文的广告会被强行取消一个，收益会下滑；写长了，文章完读率则会严重下滑，推荐量会随之降低，收益也会随之下滑。所以正文字数，控制在这个范围内是最好的。
