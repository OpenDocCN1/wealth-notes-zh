### 一.家电清洗这个行业到底是什么？怎么赚钱的？

家电清洗主要是以清洗油烟机，空调，洗衣机，冰箱等家用电器的家政服务。目前还是有很多我不知道，家电是有专业的清洗服务的，容易以家政保洁混为一谈。

两者的区别性质非常大。我从以下这几个方面分析：

| 维度 | 家电清洗 | 日常保洁 |
| :--- | :--- | :--- |
| **工作内容** | 主要清洗家用电器 | 主要打扫家里的卫生 |
| **专业性质** | 需要一定的专业技术能力 | 专业性不强 |
| **服务人群** | 更广(客户自己取代不了) | 小众(客户自己也可以) |

| **飞单** | 容易控制 | 难以控制 |
| **公司模式** | 自营为主 | 中介 |
| **分享裂变** | 容易 | 很难 |
| **sop标准流程** | 容易执行 | 难以执行 主观性比较强 |

- 1）家电清洗和日常保洁的服务人群不一样，且数量上更具优势
  家电清洗的受众人群会远远大于需要日常保洁的人群。大多数请保洁的人群，要么家里要入住，开荒保洁，要么是自己比较懒，想要找人代替自己。而家电清洗则是，你只要正常入住，你就是我的目标客户。
  家电清洗是客户自己处理不了，没有能力，他必须要专业的人来做这个事。懒与不懒的客户，都需要家电清洗，并非仅仅是“懒”的这部分群体。日常保洁的客户慢慢可能会随扫地机器人，洗地机，擦窗机器人的进入，慢慢地减少购入服务，而家电清洗目前没有可替代的机器人可以完成这项服务，需求也在逐渐递增。

- 2）家电清洗可以老客户复购，老客户同时也会带来新客户。
  日常保洁在于阿姨的服务是否刺激客户的稳定复购，复购频率是一个月一次，或一周一次，但在这个过程，容易产生阿姨和客户直接跳过家政公司。而家电清洗的复购周期比较长，需要半年甚至是一年的时间。因为这个“缺陷”。也就导致了，跳单率比日常保洁低很多，而且家电清洗它有存在机器洗坏的风险，客户为了安全，不质的“家政公司。因为阿姨因为文化层次的不同，对自身的要求不同，就很难做到统一要求，统一的服务内容，哪怕是招人培养，阿姨都会标准偏差，以及流失。所以索性放弃，做中介性质，直接在家政群里丢单子，让群里的阿姨抢单。变成了博概率事件，永远也不能保证这个阿姨服务会很好，因为她也不认识阿姨。

- 5）而家电清洗公司为什么是自营模式，不是中介性质？

  并非是的行业都可以采取“众包模式”，当专业的技术门槛存在时，就很难实现，反而自营模式能够走的更远。

  家电清洗是根据清洗机器台数计算的。所以会出现这种情况。
  日常保洁一般是上午4小时加下午4小时，那么就是一个阿姨每天最多的服务客户数是2，甚至全屋保洁，需要两三个阿姨同时服务一个客户的情况。
  家电清洗如果同样工作8小时，那么就是一个师傅每天最多的客户数最多可以达到6户以上。
  客户基数增长数量也会很大程度影响裂变速率。当然是客户基数越大，你的订单量就会越稳定。
  单位时间内计算产值上面，两者也有很大的不同。保洁一般市场上比较高的价格是50元一个人一小时，结算给阿姨35元一小时，那么公司一小时是赚15元，一个阿姨给公司一天赚的钱是120元。
  面家电清洗是若半小时清洗一台挂式空调，一小时就是清洗两台空调，那么公司一小时是50元以上，一个家电清洗师傅一天给公司赚的钱是400元，你可以抛去路上的时间成本，一个师傅一天仅仅工作6个小时，给公司创造的利润是300元以上。一个师傅给你赚300元一天，十个师傅那就是3000元一天，抛去信息员的工资两百元一天（一个信息员可以匹配十个师傅没有问题），再减去会计的工资150元一天。（如果不做培训项目，不需要太大的场地，场地成本可以忽略不计），那么一天的利润是至少两千元以上。

### 三.家电清洗一年可以赚多少钱？

这个问题就好像，我现在加入都抖音电商可以赚多少钱？我现在做小红书可以赚多少钱？本质上是一样的，没有人可以告诉你进入某个行业可以赚多少钱，更多的时候展示的是平均值，就像宁波平均人均工资在八千多元，但真的是每个宁波人是八千元的工资吗？其实大家心里都清楚。我见过家电清洗一年赚百万的，也有一年赚十万的，我不能直接给大家一个值，事是做出来的，钱是赚出来的，事在人为。创业是很多不确定因素的总和，也不要给你自己设上线，我只能说用合适的方法可以让自己少走一些弯路，或许"小白"的你未来比我优秀很多很多。我只能说起码，目前来看，这个生意，可以让你做一生一世，减少对未来的焦虑感。

至于赚多少钱，它其实也是可以算出来的，主要在于你的乘的倍数是多少？

像前面已经提到过，一个师傅带来的单日利润值是300元左右，那么你一天几个师傅，就乘以这个数字就可以了。而且你的师傅越多，你的客户累计额就越多，你的裂变速度就越快，它是呈指数形式增长的。公司文员只需要信息员一个人就可以了，她的单日工资最高值在200元这样，一个师傅就可以抵掉这个成本。所以说一年赚多少钱，就在于你手上有多少个师傅。十个师傅一年带给你的纯利润多
