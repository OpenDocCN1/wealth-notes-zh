# 二、如何实操，详细步骤拆解

首先，要做这个淘宝逛逛项目，我们需要准备什么东西呢？

主要的就两个，店铺和软件：

一、可上传视频的店铺；开通好淘宝店铺后，不能直接使用的，需要开通对应的权限，才能够上传视频。

二、准备软件；这个是我们省掉90%人力成本的核心所在。

软件是用于批量剪辑视频，批量上传视频的，做过视频方面的都知道，剪一条视频是非常费劲的活儿，那我们有了这个软件就可以省掉大部分的时间成本。

接下来，我就从最基础的内容开始带着大家从0-1操作一遍下来。

# （1）、开通可用店铺，逛逛第一步

开通淘宝店的步骤比较简单，我在这里就不过多赘述，把操作步骤和大家说一下好了。

开通淘宝店步骤：

+   步骤一、进入淘宝网首页，点击“卖家中心”，在弹出的下拉菜单中选择“免费开店”。

+   步骤二、输入淘宝账号进行登录，选择“个人店铺”。仔细阅读开店须知，点击“我已了解，继续开店”。

+   步骤三、完成支付宝实名认证和淘宝开店认证后即可成功开店。
