所以，案例和理论体系一个都不能少，没有理论体系，用户就没有使用的方法，也没有传播力。（上过我朋友圈训练营的同学，可以回一下朋友圈的“四有系统”）。

# ③ 实操技巧

有案例和理论体系了，你还要告诉用户，在具体实操过程中需要用到的技巧或者说动作。

拿写作这个技能来说，标题要用什么关键词？第1段开头，用什么方式？结尾写精华句的时候，上哪去找？这些都是具体的实操技巧。

实操技巧其实解决的就是具体场景问题，你可以把自己在做某一件事情时，遇到的问题，和解决问题的方法记录下来，这个就是实操技巧。

# ④ 工具使用

道法技术，最后一个当然少不了“术”了。做任何一件事情你都需要用到工具，有了工具可以帮助你快速提高，解决问题的效率。

相对于上面三个模块，工具这个模块还是比较简单的，把自己平常在用的，或者说，网上大家推荐的，整合在一起就OK了。
