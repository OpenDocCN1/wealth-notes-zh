# (精华帖)(225赞)浅谈一下，如何在生财有术建立自己的影响力？

浅谈一下，如何在生财有术建立自己的影响力？

首先，什么是影响力？

影响力这个词，你问每个人是什么意思，每个人都回答的不一样。

但是有一点是共通的，就是你对别人的思想、行为上造成的影响，从而留在别人的印象里。好的销售转化往往建立在有影响力的个人IP上。

影响力在生财的评判标准有：

- 你名字出现在公共视野的频次（你本身的活跃度和被讨论的频次）；
- 在生财圈友中的认知（第一印象、口碑）；
- 个人产品的销售转化（是否买你的帐）；
- ......

作为生财社群拥有专属表情包的我，斗胆来聊聊我认为的影响力产出方式。

知道了什么是影响力，那么建立影响力的维度有哪些？

## 1、权力

权力属于影响力的初始流量，这一点在互联网社区表现有：

- 你是BBS的版主，你有删帖的权限，别人进入就会看到你；
- 你是社群的管理员，你可以邀请人踢人，别人第一眼看就会看到你；
- 你是星球的分享嘉宾，在身份标识上就比别人亮眼......

在生财社群里，除去官方工作人员，代表权力的角色有：

- 嘉宾：官方认证大佬；
- 教练：官方认证的专业领域的高手，给上千航海船员传授经验；
- 领队：能够掌控航海节奏、维持秩序的人；
- 志愿者：服务小范围人群，在小组内话语权最高；
- 夜话官：活动组织者，拥有活动解释权；
- ......

以我个人为例：

我加入生财是在**22年的9月份**，进入后参加了**9月航海**，身为一名船员怎么在航海内创造自己的“权力”层面影响力？

我的做法是——卷精选日志！每天认真学习、认真归纳，除去自我介绍篇，每篇日志都是精选。

在小组内，鼓励其他人跟上航海的节奏，也用专业知识解答大家的问题。

很容易，就在小组内创造了自己的影响力，因为我是那个精华日志最多的人！

这些都是标签，都是你的最强战力。

不要用自己的“弱标签”去PK别人的“强标签”，这样越比越不行，越比越焦虑。

拿出自己最强的部分，田忌赛马，用你的上等马去打别人的下等马，这样最容易形成自己的战力标签。

降维打击、不在别人的战场上打架。把别人拉入到自己的领域内，窥视全场、疯狂输出，占“标签”为王。

别人谈起你，会说：那个做XX领域喊牛逼的人。提到关键词，第一时间想到的就是你。

举个例子：我复购了好多次盖洛普的测试，无论谁问我，我第一反应就是推荐醒醒。这就是她的最强战力

不吹牛逼地讲，生财有术里做无人直播的也没人比我牛逼。

怎么展现你的最强战斗力？发精华帖就是最好的方式！没人知道你这个小透明，你反思一下你有几篇龙珠文？

### 3、共生（利他、互惠）

什么是共生，就是和别人有关系。

你再牛逼，你和我没关系，你的钱也不给我，我会和你有联系？

没有关系怎么发生关系？就是利他。

你的内容、你的价值，一定是帮助到别人，和别人产生了联系、互动，才会“有关系”。

- 我发布的风向标，让你抓住了几个最新的赚钱思路；
- 我在群聊里的互动，让你受到了一点启发；
- 我在线下活动的积极发言，让你觉得“生财的氛围好好”；
- ......

这些都是“利他”的分享行为。不计回报的利他，会为你换来更具象的影响力。

比如大师兄杨涛，大家在他的影响力标签会说：涛哥人很NICE，像哥们一样教会我人生的道理。

### 4、价值原则

我一直同意价值交换原则，都是成年人了，谁也别白嫖谁的价值。

与人交往前，先想想自己能提供什么样的价值，点赞评论**666**可不算“有价值”。

你在生财价值体现在哪里？

- 能力价值：我可以发布我专业领域的技巧、感悟，让别人学到东西；
- 交换价值：等价值资源、信息交换；
- 情绪价值：我没有牛逼的能力，但是有我 在场的场合大家都相处很舒适，不会冷场；
- 当韭菜的价值：别人推出付费项目的时候，我能真金白银的买；
- ……

如果不满足以上任何一条价值，那真的很难和别人建立“平等关系”。

你提供给别人的价值，就会让别人记住你，从而产生“影响力”。

我记得有个圈友的影响力标签是：特别爱买项目，买了50多个付费项目，所有人都知道他是散财童子，买了不看。

### 5、破局能力

这个是破局，而非破圈。

破局=你在细分领域内的创新、创造行为。

这种行为会给人非常深的印象，比如前几天的脚气药的精华帖，非常明显打破了传统脚气品牌的商业模式，老树又生春。
