之前在用户积累阶段开启了广告收入后，浏览量直接下降了30%，然而收益微乎其微。

老板的想法很简单：增加收入渠道，多多益善。

然而现实情况是，在你的数据足够好之前，开启广告只有反效果。

根据K12项目特性，整体内容不像娱乐搞笑类别的视频，看看广告再回来继续之前的视频。如果还要等待广告时间，瞬间就会失去用户的注意力。

失败的经验：验证了3个月，看了数据，老板同意关闭广告。

这里需要你自己，对于整个项目的定位，发展阶段有清楚的认识，在什么阶段就做什么事。达到YPP门槛以前，先想着如何提高粉丝量，观看时长。

# （2）项目成本

# 1）生产成本

生产包括你的设备，房租，水电，人员费用，第三方合作费用，服务器，推广费用等。随着时间点推移，设备成本是最低的，人员成本是最高的。其他弹性成本根据项目大小会有变化。

小项目：拍摄剪辑后期=1人。

有条件的：文案脚本、拍摄剪辑、后期=3人可以高效地保证更新频率的创作了。
