# 2. 代拍团队

代拍团队主要靠拍牌照盈利，一般来讲，他们自己的收单能力有限，大多需要从收单团队来购买牌照，每次拍牌都要支付费用。

> 拍牌照的确是一个技术活，一张牌照要成功拍到，需要好的设备、软件、出价策略、码工以及运气。

对代拍团队来讲，中标率的高低是收单团队放单时衡量的标准。好的团队不愁没有标书拍，而连续几个月表现都很差的团队很可能就此出局，没有收单团队愿意放单给他们。

作为核心竞争力，有的团队会有自己的软件，并且只供自己拍牌使用。但更多的团队并没有软件研发的能力，则需要购买别人的软件，于是催生出了软件商。

# 3. 软件商

这个行业的软件商是按照效果收费，如果使用其提供的软件，拍中车牌的话，一张需要支付 500 元。软件商的利润很高，但这个需要很强的技术实力才能做到，好的软件商年利润超千万，但是存在一定的法律风险。

# 4. 码工团队

要拍到车牌，并不是有软件就可以，软件解决不了验证码验证的问题。所以需要人工来进行打码，于是要衍生出了码工这一职业。码工头子负责组织招募码工以及进行培训，做码工的多是在校学生。
