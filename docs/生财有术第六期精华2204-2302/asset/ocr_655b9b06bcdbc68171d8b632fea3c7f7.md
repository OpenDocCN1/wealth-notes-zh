# ### 一、运营的定义

# #### 定义

广义: 对产品的一切人工干预

狭义: 懂技术的营销人员, 在国外也被称为增长黑客 (growth hacker), 互联网三大职能之一 (其他两个是产品、技术)

作用: 找到用户, 引导用户使用产品, 并促使用户持续长久的使用

终极目标: 用户增长
