下面说说我对互动游戏直播的预测：

+   （1）开播门槛低，会有更多入局；

+   （2）达人们28定律，只有2成是有流量能赚到钱的；

+   （3）互动游戏工作室会赚钱。

以我现在的小游戏小组为例：

人员配置：4人（2个产品、1个技术、1个玩法打板）

实际产出：每周一款新互动游戏（大多数是换皮）

收益构成：

+   （1）自有账号批量直播，获取打赏收益；

+   （2）游戏接口卖给要开播的达人，一个游戏的月费基本在399-599不等；

+   （3）与渠道方合作（如网吧、多电脑闲置的公司），把账号挂在工会内，矩阵开播获取收益。
