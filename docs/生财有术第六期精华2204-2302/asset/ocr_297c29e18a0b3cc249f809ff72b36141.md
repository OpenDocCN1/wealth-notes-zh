+   1.能做家长流量更建议做家长流量，学生消费能力有限，家长则很愿意为孩子的教育买单。

+   2.与博主合作虽然简单粗暴，但终究不完全受自己控制，还是建议有自己的账号，这样能保证基本盘的正常运行。

+   3.最好是多平台同步进行，想要引流效果好合作形式就得简单粗暴，而简单粗暴就很容易被平台限制。所以需要不断地调整合作形式，多平台同步进行更稳固，即使在某一个平台被严重限制，那其他的平台尚能正常进行。

+   4.与博主合作，关系的确要搞好，但也要有约法三章，不然宽容成了纵容，钱花出去了没效果。暑假是绝对的旺季，这个时候不仅流量是爆发季，学生的需求也是最大的自然转化率最高，毫不夸张地说“一年忙俩月，俩月吃一年”。
