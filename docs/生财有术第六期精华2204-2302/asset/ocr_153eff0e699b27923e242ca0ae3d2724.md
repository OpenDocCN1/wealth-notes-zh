# # (精华帖)(360赞)29岁博士毕业，30岁加入生财，我实现了一年顶十年

作者： 梁靠谱

日期：2023-01-19

年末的时候我发了一条朋友圈，说这是我的副业三周年，也是我过得最快乐的三年，因为终于拿到了人生的主动权，有了安全感。评论区有一条评论是这么说的，人人都在说三年，只有你的三年，不太一样。

我是梁靠谱，主业医生，副业经营一家基因检测公司，是几家生物和医美公司也进入了龙珠俱乐部，这次加入，认识了很多后面对我影响意义深远的贵人，比如合伙人，比如帮我对接客户的朋友，这是六月。

再下一个月，河南大水，当时我正在NCP线上救援，帮一些不方便就医的朋友提供医疗支持，链接了很多河南的圈友，球球姐在做云上夜话，我们做了一次连麦，帮大家科普大灾之后防大疫。
