# 4. 店铺的运营

# （1）合理运用店铺的营销工具

Lazada平台拥有的影响工具有这些：闪购，捆绑销售，优惠券，包邮，满减多件多折，分享礼，新客券等这些，我们要善于利用好这些营销工具。

东南亚买家对折扣比较敏感，比如说，10块的产品不打折，和原价30元的产品，打5折，折扣价15元。大部分的买家是会去选择打5折的产品，因为他们觉得打折的东西更划算，这个和他们的消费习惯有关系。

所以我建议我们的产品可以提高价格去出售，然后设置折扣价，直接打到最低，打五折（五折是Lazada允许的最大折扣）。
