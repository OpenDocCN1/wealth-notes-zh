# # A号尝试，小爆一波，开启第一场带货直播

当时我做了两个号，这里称它们为A号和B号，11月3号晚-4号凌晨，我就决定用A号来尝试操作，我屏蔽很多外部信息，细看手册。看了之后，立马再次跟着步骤细致操作了起来。

开新号！选品！选视频！怼他！

咔咔咔20条！对，直接怼！

我开始看分享课，觉得晓文老师只是示范怎么上传视频，才会这么连续上的，因为之前看过其他的说是每条视频要间隔1-2个小时，当然，我也只是猜测，反正我就这么怼了！

上了一波，刷新看看有没有数据出现~

然后接着再上一波~

咦？有了！有了！有了！红点出现了！

好像越来越爆了？！

再刷新！每按一次多几百几千的，肯定爆了~

这个时候要做什么？

开播呀！！！

我当下的第一反应是：我不会啊！

但是另一个声音告诉我：不！你学过直播！@一桥老师
