销售人员不是培养出来的，是筛选出来的，不行的人怎么督促也不行，2个月不出单直接淘汰。

# 3. 专注自己优势

做实体行业蓝海类目，要利用自己的优势去找人做资源整合，不要自己吃全部，一定要找在市场存在3年以上的成熟中小企业合作。

另外，能不能自己做实业，就不要自己做。做自己擅长的就好，实体生产行业内的水不是一般的深。

# 四、关于蓝海

# 1. 什么是蓝海？

按照通俗认知就是绝大部分人不知道的，竞争小的就是蓝海。

但是我认为只要在某个领域你具备高势能，这个领域对于你来说就是蓝海。这个势能可以是品牌、信息差、技能、资源、资金量。

# 2. 怎么发现身边的蓝海？

我认为最好的方式就是从自己熟悉的领域、环境入手，匹配自己当下的资源，来挖掘蓝海项目，因为作为行业内的人，相对行业外的人天然具备信息差优势。
