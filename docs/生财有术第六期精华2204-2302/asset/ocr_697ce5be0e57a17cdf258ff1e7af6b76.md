# # 第二阶段

其实那个时候我的粉丝量还没有增加多少，直到我开始发布了一个纯代码的视频，那个视频开始，粉丝量开始暴涨，我的大概是从1000开始暴涨，那个时候几乎每个礼拜都会新增1000粉丝，2个月时间就增加到了1W，然后粉丝增长就开始停滞，当然按照我对短视频的观察，基本上大多数都是这个规律，有一个粉丝猛涨期，到了那个数值，就会停滞下来。
