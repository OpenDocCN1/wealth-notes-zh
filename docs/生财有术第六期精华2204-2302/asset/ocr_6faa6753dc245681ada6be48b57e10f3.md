# # (精华帖)(203赞)解除焦虑最好的方式，是把眼前的具体的事情做好！

作者： 安夏

日期: 2023-02-17

这是给匿名圏友的一封信：

你和亦仁说，你被开除了，存款少，还要还房贷，压力很大。想要在3个月内赚到**10W**，解除现金流危机，但又拿不出什么钱做投资。你現在是有必取之心，但又不知道如何做出最好的必胜的选择？你问亦仁该怎么选。

我知道，你现在感觉压力很大、焦虑，你想向亦仁求助，这一个非常好的办法。可你没有告诉亦仁

+   1. 你现在有什么？
2. 你擅长什么？
3. 你的经验技能点是什么？
4. 你的专业、工作经历是什么？
5. 除金钱外，你拥有的优势和资源是什么？
6. 你在哪些方面学得比别人快、容易坚持？
7. 哪些事情别人需要折腾很久才能搞定，对你来说却很轻松搞定？

你也没有告诉亦仁：

+   1. 别人在遇到什么问题的时候，会第一时间来找你？
2. 做什么事情没有回报甚至倒贴，你也会一腔热情全情投入？
3. 你在什么事情上投入了大量的时间金钱？
