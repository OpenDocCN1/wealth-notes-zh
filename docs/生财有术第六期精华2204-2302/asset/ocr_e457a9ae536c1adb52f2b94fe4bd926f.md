这是我们的认养海报，18年开始有了第一个认养的客户，到现在有了大几百位私人茶园主。

目前卖的最好的就是半亩私人大红袍茶园，一万元，提供40斤私人定制包装的大红袍，同时给客户制作认养牌和纪念证书，还有一个高端私人茶园主群，认养后可以自己喝或者送礼，也可以拿去卖，当成一个副业。

与其更好，不如不同，打造差异化的新农业品牌。

# ## 二、获客方法

认养的模式做出来了，但是客户怎么找呢，这个是绝大多朋友都关心的问题。

目前我们获客方法有下面几种：

+   1. 得益于早期的零售，积累了几千个客户，信任度都是很高的，本来他们自己每年也要买几十斤茶，现在有了自己的私人茶园，喝的放心，也更有逼格有面子。其实就是同一批客户低客单价转高客单价。

+   2. 我们的客户群很多都是创业者老板们，哪的老板最多，当然是创业者付费社群，所以这一年多来，我疯狂加付费社群。当然我们进群不会发广告，这个太low了，进群就是做个自我介绍，发个红包，送点福利（一晚上度假民宿免费体验）。不主动加人，更多是靠吸引。从去年到现在加了100多个付费社群，花了10多万，市面上主流的创业者社群都加了个遍。

+   3. 新媒体引流，我自己有个公众号《新农人黄尹唯》，分享自己的创业生活，篇均阅读量在一千多，经常也有客户看了我们公众号成交。
