# 7542系列之白布条—501

![](bbox=[0.13, 0.19, 0.39, 0.43])

**特征与来源:**

所谓的白布条，是指整件茶的竹筐上，用麻绳绑着一条白色布条，上面写有“责任公司说明书”字样，因此茶友直呼其名“白布条”。

**问：**怎么样区分501白布条和非白布条?

**答：**内票文字不同，501批7542非白布条，落款为勐海茶厂出品，底部英文翻译为两行，右上角有大益商标logo。

501白布条则印着“勐海茶业有限责任公司”，底部英文翻译为一行，且“云南七子饼茶”一行后面没有大益商标logo
