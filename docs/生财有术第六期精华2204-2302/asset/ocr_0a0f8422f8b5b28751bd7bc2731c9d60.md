# # (精华帖)(153赞)亦仁：一时加精一时爽，一直加精一直爽

作者：亦仁

日期：2023-02-02

自从一月初调整了生财有术星球加精规则后，，我的感受是：

一时加精一时爽，一直加精一直爽。

我的加精速度从周甚至月，调整到了天，甚至小时，比如刚刚一篇帖子，，发布十分钟后就被我加精了，这样圈友们可以更及时更高频地看到被我加精推荐阅读的内容。

加精数量上也大大提高，从原来几乎是长文，到现在风格多元，不仅仅是长文教程，也有很多鼓舞人心的案例、复盘、认知分享等，还有一些我鼓励更多人去看到的可能性。

不过，为了避免被加精的圈友没看到一月初规则调整的通知而产生误解，我还是要再划一下重点： 从2023年一月开始，不是所有被加精的文章都能获得一颗龙珠，区间是1 颗龙珠碎片到 2 颗龙珠。

另外，我还要提醒一部分阅读分享的圈友，别老是动不动就在评论区要分享者的微信私下交流，评论区的讨论互动有价值的信息，也是龙珠发放数量的重要参考依据，如果真的觉得分享者内容对你有帮助，那么评论区有价值的提问和互动，对原文的重要信息补充，都是反向的给分享者提供了价值与回馈，也是我非常期待看到的事情。

比如这篇，，评论区的讨论是对正文的重要信息补充，真诚的分享，高质量的讨论，相得益彰。
