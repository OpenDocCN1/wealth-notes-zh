# 3. 大学生商场拦截

很多店面员工在店面都是坐店等客的模式，但其实家居建材商场就是一个客流很大的场所，而且都是精准装修客户。

不过在很多建材家具商场，品牌员工是不能在商场进行拦截的，被商场管理人员抓住就会罚款，当然，就算是能够拦截也最好不要让老员工拦截，没有激情且容易打消自信心，老员工主要在店面负责接待和签单就好。
