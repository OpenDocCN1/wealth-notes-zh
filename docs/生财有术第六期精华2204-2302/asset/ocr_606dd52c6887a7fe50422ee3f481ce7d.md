# ## 【精华帖】(420赞)出去交流不是为了改变想法，而是为了坚定想法

作者： 亦仁

日期： 2022-07-26

我出去学习，包括在各种圈子里面，其实不指望改变我的什么想法，大家都是成年人，改变想法是很难的。

而且身处这样的一个信息密度很高、交流质量不低的圈子，大概率已经有的想法不会太差，只是还不坚定。

我的目标，往往是希望坚定我的一个想法，通过看别人的成功案例，和有结果的人交流，让我意识到：这个事情其实没那么难。

一旦突破了这层心理障碍，就会变得勇敢去干，而结果往往都是这样干出来的。
