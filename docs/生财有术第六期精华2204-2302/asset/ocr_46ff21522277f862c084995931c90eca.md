# 第三步：研究这三篇内容的特点

很明确的一点是，三个都是同行发布的。三篇文章的共同特点就是，简单粗暴告诉大家能够快速中标。

第一种，以自己的角度发的，简单粗暴，不过容易被举报。

第二个写的太简单，虽然引流的功能实现了，但是转化率可能一般。

第三个内容，以客户的角度来发布，并且给了自己拍牌的建议，显得十分诚恳。3个建议分别是，不用找大平台，不用找淘宝店，找个能签合同的，实际上已经为自己下一步的转化做铺垫了，发布时间在 2 月 26 号。

近一个月中，有 140 条评论，其中 60 多条都是求推荐！私信的人数该更多，我那篇留言和私信的人数大约是1：2，估算这个内容应该引流了 100 多位个客户，成交额应该在几十万。

# 3）先抄后超，杠杆超越

摸清楚什么是能够赚钱的内容后，我们就可以模仿他了。但是只模仿不够，我们要想办法给这篇内容加个杠杆。

我的策略是，多写几篇这类文章，然后多找几个账户批量发布，找到其中数据好的内容，把账户补到 500 粉，之后就可以在小红书上投广告，进而开启收米模式。
