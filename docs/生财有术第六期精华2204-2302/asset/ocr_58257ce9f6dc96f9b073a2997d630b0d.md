国外哈佛等教授来授课的模式基本已经被挤满了，客单最低也是3万多，一般来说渠道的返佣20-30%之间。

2.游学产品：把学生送到海外参加一些学校的参访、有些会带1-2门授课的模式。特点：偏小众，客单底、利润薄，疫情来了之后，不可控性比较大。

3.实习产品：客单高的也可以达到4-5万，以某投行实习为例，高顿财经比较常见的售价在3.5-4万之间，学生普遍接受到的价格也在2-3万。

但这类背景的最上游渠道成本、或者自己联系资源开发：基本在1万上下。因此里面能出现1-3万的利润空间。

# # 2.差异化业务突破复购(常见国际教育类中小公司)

1.语言互推合作：市面上比较常见，一般机构都会互相推荐。留学的学生会有语言需求，跟语言机构合作，推荐学生给语言机构。拿学生返佣盈利，一般市面上比较多的返点在10-20%之间。

2.留学全套产品拆解各模块，增加一些产品：

目前常见的留学全套产品，会包括择校、文书、申请。可以把服务拆出来变成单产品进行销售。
