+   1. 客户只是来问个价格，可能他自己还没看过车，套个价格再去4S店谈，所以这种客户我们一般不报价，或者报大概价格。

+   2. 客户去看车，也问过价格，但是会谎报价格给我们，比如说一台车店里给客户的**价格**是29.8，客户会说店里**报的**是29.3，当然要先辨别这个价格是否真实，然后在跟客户沟通，不是客户说多少就多少。

+   3. 外地4S店价格更优惠，可以有更多的利润，但是客户只愿意在本地4S店提车。先沟通，告知附近的城市提车更优惠，可以让更多的利润给客户。如果客户不愿意去，可以沟通用板车托运回来。还是不同意的话，那就只能在本地去提车了。
