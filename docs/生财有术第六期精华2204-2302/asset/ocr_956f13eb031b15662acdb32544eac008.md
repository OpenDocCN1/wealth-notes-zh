# 非官方变现

广告商、私域打赏、独立站、商品带货、CPS、只要你想的到。

广告商就是视频合作，也分独家和非独家。

+   1. 独家通常会签多少条视频，多少钱，在每个视频里预留多少s的广告时间。
   这个模式在YouTube上广为接受，主要集中在how to分享里。
2. 非独家，就是独立视频，独立内容。

私域打赏：直接跳外站，请作者喝杯咖啡。

私域会员：Patreon。
