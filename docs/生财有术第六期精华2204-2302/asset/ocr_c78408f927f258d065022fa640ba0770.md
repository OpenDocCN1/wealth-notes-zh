# Copy 审核流程和 Tips

流程：

->确认达人 list（PR），拉群

（群命名方式：可以群名为【xx项目】+KOL 名）

->和达人确认档期、金额及下 bf(如有特殊要求，需单独拉出来给达人确认，收地址

（brief 需给达人类型开始讲起，删除不必要信息，如发放环节、用 PDF 版本）

->写前前提醒达人注意事项

->审核（一般不超过 2 稿，视频需要审核2次；按营销需求提给小红书审核/后台勾选\"广\"）

->发布，登记发布链接

->每日发布项目进度给客户

-定期看发布后的互动数据（如评论区分，出现差评及时联系达人删或改差评）

Tips：

+   - 一、与客户确认 key milestones：

+   ■ 审稿前：

+   -主题：根据客户确认达人稿件的主题、方向、倾向，避免后续品牌方要求来回改主题。

+   -服装：有特殊服装要求的，需提前和达人沟通服装方向，服装在拍摄前与客户确认。

+   -合集：如为合集，需要提前和品牌确认合集产品，排除竞品。

+   （调性保持一致：产品调性若是高端，合集产品也需要高端）

+   - 二、审核注意事项：

+   ■ 审稿中：

+   -脚本：检查达人脚本是否有必要卖点、逻辑尽量流畅、达人提及的关键信息可在脚本备注同步给客户。

+   -视频：视频按照脚本定稿的版本，检查画面和卖点是否对应写细节

+   -图文：文案和标题需仔细审核，图片清晰、不杂乱。

+   - 三、如何选题文：

+   □ 研究达人以往的数据：找出他容易产生爆文的方向，作为主题方向，或者看有同类型的其他达人，他们最近比较火的方向。

+   □ 结合当下流量趋势：多刷小红书，借鉴当下流行的内容趋势，增加爆文的几率。

+   □ 内容创新：多刷、多看“多平台”内容，其他品类内容，开动脑洞，创新内容玩法。

抖音星图流程：

客户审核后的视频 ->发热播审核群（审核提至少提交前一天）->确认后让达人上传（至少提前半天）->

>按照星图的热播群反馈达人修改后再上传 ->下单公司上传视频 ->下单公司点击确认后即时发布（可选项定时）

*注：下单时如果设置了脚本审核，下单方还需要点击确认脚本*
