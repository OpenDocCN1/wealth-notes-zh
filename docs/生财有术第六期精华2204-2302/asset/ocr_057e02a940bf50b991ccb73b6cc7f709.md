上文提到去观察了解对方的人员规模情况，这里我要讲的是，要去了解对方的部门、岗位分工情况。反观自己的团队，是否具备这些人才。如果团队不具备，是否能快速招聘、挖掘到对应需要的人才。负责人强，还不够，最终能不能搞起来，还是要看团队的整体战斗力。

# 【5】一个负责人专注一个项目，提高项目成功率

对于项目，我倾向一个项目一个负责人，最终决策权只能给一个负责人。如果是两个人同时负责情况下，哪怕是分板块负责，也会导致很多不必要的意见分歧。这些分歧，管理不恰的情况下，很容易让团队陷入不必要内耗，降低了项目成功概率。

一定要相信人的精力是有限的，负责人作为项目的操盘手，决定项目成败，专心于一个项目，才能提高项目成功率。

# 【6】独立经营，合理分红，提高项目成功率

如果是团队作战，更多的赋能团队，赋能操盘手权利，给他们钱，给他们场地，给他们资源。保持经营的独立性，不做过多干涉，当然前提是你的负责人要靠谱，汲取经验，提升自己，为下一次项目做准备。
