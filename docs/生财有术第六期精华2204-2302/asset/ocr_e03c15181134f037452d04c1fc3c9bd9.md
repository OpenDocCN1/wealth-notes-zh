# # 二、如何获客

我是如何获取自己的用户的呢？

# ## 1. 免费粉丝交流群

我做公众号是从2019年9月份开始的，大概在2020年我建立了自己的免费粉丝交流群，交易日会每天分享资讯和投资早报，这样积累了第一批种子用户。

但是交流群毕竟人数有上限，长期维护运营也需要耗费不少精力，如何能将自己的文章传播和触达给更多用户呢？

做过公众号的朋友都明白，公众号是没有公开推荐机制的。所以即使你的文章写的非常好，也很难带来大量的关注和粉丝。

所以我目前又采用了下面三种方式。

# ## 2. 干货引流

亦仁有一个著名的理念：靠一篇精华文足以打破圈层。

如何让更多人知道自己？记住自己？要有自己的代表作，越多越好，有打造精品+系列的意识，给别人关注的理由。
