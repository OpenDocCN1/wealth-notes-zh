# 三、总结

## 1. 先有产品还是先有流量

做副业变现，做课程变现也好，最常见的误区就是先去做流量。

很多人做了很久都没流量，有的人做了几年几十万百万粉丝了还不知道怎么变现，少数能变现的也不是很稳定，太长时间粉丝也失去了粘性。所以不要迷信什么我要多少粉丝了才能变现才开始变现，先保证自己不要饿死。

## 2. 想清楚你用什么变现

副业的本质是，先有产品再搞流量或者边搞产品边搞流量。

副业、变现、赚钱、商业本质其实就是「生意」，就是商品交换、价值交换。你只有粉丝没有产品，别人想给你钱都不知道怎么给。所以如果你有实物产品很好，你的定位很清晰。如果你是虚拟产品，比如社群、服务、课程，那么你需要先设计好想好你的产品是什么。

## 3. 用最小 MVP 验证这个产品是否有市场需求，是否可行

最小 MVP 可以是免费产品，也可以是超低价产品。如果免费的都没人要，那么这款产品说明没有市场，如果低价很多人要，那么你可以设计一套系统化的阶梯式的产品。（前提是如果你的粉丝是你的目标用户，是精准的）

## 4. 知识付费小白到大神你会经历四个阶段

1. 小白不知道怎么定位，做什么课程、什么服务。

梳理你的学习经历、工作经历、兴趣爱好、特长，把关键词写下来，把不擅长不喜欢的删除，再从中挑选市场上你觉得最有市场最有需求的，留下1-2个即可，这个就是你可以定位的方向。

如果不知道哪个市场有需求，微信指数、百度指数、淘宝拼多多京东当当搜一搜关键词，数据低销量低的代表需求量少，相反就是需求量大。

2. 新手阶段，确定好你的定位，开始设计打磨你的最初级的产品雏形，这个过程都需要测试

比如时间管理的课程和服务都分为很多种：打卡群、每日早起、早起陪伴、早起攻读、时间管理课程、时间管理训练营，高热能、时间管理工具等等，人群：职场人、宝妈、学生党、高管。不同的人群你做的产品也不一样。

3. 打造属于你的「里程碑」「冠军」「第一」「首个」事件

比如短视频播放量累计100万，XX万粉丝、XX平台签约博主、获得XX奖、分销第一名、畅销书第一名、XX平台最XX的博主等等。这个时候你赚钱靠你的IP影响力。

4. 打造系统

课程系统：免费引流、低价成交、会员产品、高价产品、超高价(合伙人/代理人)产品。这个阶段你赚钱靠团队、靠系统。

举个例子：免费送 28 个时间管理工具表、9.9 元 7 天时间管理课、999 元 XX 金币会员、3999 元 XXX 年社群、9999 元私董/合伙人/轻创客，这个时候你不仅需要有团队，还需要有 **好的服务和交付能力**，带团队的能力。
