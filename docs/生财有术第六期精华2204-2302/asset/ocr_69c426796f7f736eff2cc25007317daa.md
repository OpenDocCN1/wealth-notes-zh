+   * 多sku形成高复购

# 3. 满足目标人群需求

+   * 学得难易上手，太复杂的学不会，影响冲动消费

+   * 生活中应用场景多。年会，演出，社交聚会，家庭生活逗乐等等，我看到你的产品，就能联想到自己演奏会是什么样，很向往被众人崇拜。

+   * 社交价值。朋友面前炫耀的资本，值得付费获得。

通俗来讲，针对目标人群，创造需求，匹配“契合”的产品，把它卖出去。

# 03 蓝海选品

道具上架接近150个品，并不是所有都是爆品

我们测试出的经验：

+   1. 统计近3个月内所有爆品，分析产品特性，在其他产品中寻找相似属性

+   2. 看同行最近1个月发布的产品，排除大量雷同，寻找差异化产品

结合以上2点，选出2-3款产品，发布5条视频测品

第三步，优质视频内容创作

# 01 创作方式

我们目前主要是原创+半原创的方式

原创，是指自己设计脚本，拍摄剪辑

半原创，是指混剪网络素材+原创内容，结合成为一条视频（这是目前抖音比较火的内容形式）
