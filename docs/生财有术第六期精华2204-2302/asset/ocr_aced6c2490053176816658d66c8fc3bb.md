抖音博主与用户交集点在哪里？1.私信 2.抖音群 3.评论区，这3个交集点是最好的引流切入，还有人说封面，主页简介，这也算是交集点，但是接触不频繁，意义不大，没办法把引流触达最大化。

所以我在内容引流的时候，首先就是引导私信拿资料，然后建立抖音群，用小号在群里引导添加，同时小号也会在评论区引导引流。

# 4.引流封号问题

引流没有绝对安全的，都是有封号风险的，毕竟这是和平台做对抗，如何降低封号概率，下面一定一定要注意！

+   1.不要在私信里留微信，被举报必封

+   2.账号一定要认证蓝V，白号封号几率太高了

+   3.除了私信得用本号回复，抖音群和评论区这2个交集点完全可以用小号去引流

+   4.小号最好也认证蓝V，小号放心搞，封了就封了，继续注册就行，稳住主号别出问题。

+   5.另外，号被封了别骂我，我都已经被封了5个大号了，小号更是被封无数，看了我的这篇分享后可别脑子一热就去干，出了问题跑来骂我哦。

关于交集点的问题，每个平台的交集点都不同，交集点主要还是看用户在这个平台的使用习惯决定的，为啥抖音的3个频繁交集点是私信评论区和抖音群呢？你只需要站在用户的角度来想想，作为一个用户，刷抖音是不是习惯性打开评论区，如果认可对方想找到对方，是不是习惯性去私信，如果私信暂时没回复，是不是习惯性进抖音群，问问其他的群成员如何找到博主联系方式，用户的行为决定交集点，交集点决定引流切入，引流切入去模拟用户行动成本，降低行动成本决定引流效率，这就是我梳理出来的引流体系。
