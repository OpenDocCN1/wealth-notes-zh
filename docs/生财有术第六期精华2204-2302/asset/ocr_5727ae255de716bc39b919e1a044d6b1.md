# **a）普通人创业的一些问题**

自嗨和跟风是两个常见的错误创业动机。

动机错误的创业者，往往对需求和供给/解决痛点的理解，是意淫式的。

我的建议是要么把时间花在让自己变的更专业再去创业，要么把时间花在认清自己打破意淫并寻找捷径上。

没有能力分析需求，就抓一成不变的刚需需求，没有设计产品解决用户痛点的能力，就选择不需要真正解决用户问题的“大保健”产品。

合格的创业者，成功的老板，几乎都有套利的底层思维，并有能力解决流量或者转化这两点至少一点。

套利底层三个点：信息差，成本可控，确定性。（套利这三点的详细解析可以翻我的第一二篇精华帖）

在此基础之上，会玩流量或者会玩转化都能成功。

生财大v中，玩流量的代表：盗坤，他的转化靠为精准人群匹配CPS分销解决(视频号项目)；

玩转化的代表：seven (组合创新热点嫁接)，他的流量靠亚马逊解决。

会玩一个就可以成为大咖。

如果在这两点上都不专业，就不要贸然创业，不要贸然谈市场谈产品。最多也就是试试本文的“大保健”思维来作为创业的切入点，因为对人的要求真的不太高。
