# 1. 内容创作

在YouTube上一定是内容为王。内容不一定有深度，但一定要有特点。

同样的内容，为什么别人要来看“你”的视频，不是竞争对手的？

可以是内容独特，说话搞笑，人长的好看，教学方法好，思想深刻，球踢的好，稀有特长，画面拍的美，特效做的好，自带光环大IP等等。

YouTube的特性会偏好中长视频，以下内容没有特别说明都以中长视频为基础。

# （1）项目方向
