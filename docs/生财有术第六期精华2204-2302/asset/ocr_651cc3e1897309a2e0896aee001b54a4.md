# 选择快手平台起号试错

在小成本试错的前提下，我们选择主攻快手平台，抖音只作为辅助平台。为什么是主攻快手而不是抖音呢？

以下是有关快手与抖音的用户群体分析：

快手的目标用户以 2-4 线城市及农村人群为主，集中在 25-34 岁年龄段，占总体用户数量的 43%；快手平台的男女用户比例比较协调，女性用户占 57.8%，男性占 42.2%；在学历方面，快手用户分布较为均衡，高中及本科以上用户占比最多，分别是 32.8% 和 31.9%，普遍受教育程度低。
