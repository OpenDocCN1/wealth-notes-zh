# 1. 剧场和演出报批事项

广东地区需要有二级消防证与营业性演出证，每个地区的报批事项不一致，最好是去到需要演出的地区问当地文化局后，再做资料整理。

# 2. 售票小窍门

大麦和猫眼这种较大的售票平台基本是靠“搜索品牌名以及订单量”排名，前期项目若排名靠后，则可以找人刷一定量的订单或者好评，保证排名靠前能被用户看见。

新项目或销量较好的项目，可联系BD负责人置换平台广告位。

# 3. 如何成为一个脱口秀演员

如果本地有脱口秀俱乐部的话可直接咨询，是否有开放麦或者培训班。笑果和单立人也有比较好的培训课，不过会筛选，比较难进。

一般行内规则是不能外传导师课程资料，上次评论区有位小伙伴说我不到比较好的学习资料也是如此。

所以如果真的想学习建议付费学习，包括我们的合伙人几乎都会去上海北京学习，一方面是学习理论知识，另一方面也算是扩充圈子，未来也可让导师推荐演员来自己的俱乐部演出。参加比赛也是同样的道理。
