当然也有非常多的海外游戏项目方需要全球市场，我们即使不出国，也可以成为链游的全球宣传大使，成为社区管理员甚至地区营销负责人。

早期参与项目运作的建设者，不仅可以获得游戏早期通证额度，还可以及时获取游戏发展动向，甚至领取游戏项目方开出的工资。如果负责的游戏非常厉害，内部人员获得消息，就有很大的早期优势，提前早一步布局，看清游戏走向。

# ## 2）游戏公链

链游需要在区块链上进行发布运行，链游公链目前优势相当于聚合平台，类似 steam 等传统游戏平台，一款爆款游戏就可以带火整个公链的治理通证，玩游戏不仅需要消耗公链 Token 作为 gas 手续费，还可能需要公链 Token 作为游戏资产交易媒介全 都赋能或使用自己平台 Token 进行交易，那这样的平台其实更容易被价值发现，因 为游戏的好坏，立马会反映到平台 Token 表现上。
