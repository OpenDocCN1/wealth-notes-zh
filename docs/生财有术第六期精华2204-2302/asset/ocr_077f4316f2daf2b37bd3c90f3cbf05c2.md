# ## (精华帖)(844赞)关于视频号带货扎心的真话

作者： 盗坤

日期：2022-07-13

视频号很火，在大火的时候，我来给你们说些关于视频号带货扎心的真话。真话很难听，不过我还是希望可以可以看到更真实的世界。

时代的红利，落在穷人身上轻如毛，落在富人身上重如山。时代的动荡，落在富人身上轻如毛，落在穷人身上重如山。

日本人侵略中国的时候，对于贫苦百姓，惨淡不堪，是战乱连绵，是妻离子散。而对于地方军阀，地方士绅，他们凭借手里的资源可以摇身一变，成为地方保安团，入职地方政府。如果权衡利弊，他们也可以退守重庆，又或者远赴香港美国。当日本人快要战败了，撤退了，老蒋为了打击我党，这些伪军杂牌，这些地方士绅又可以摇身一变，重新回到国民政府的怀抱。

事是个事，就挺扎心的。当时代变化的时候，富人可以快人一步地获取优质信息，可以凭借他们的社会关系，权力资源从而快速获取时代红利。即使在动荡年代，他们也可以凭借手里的资源，让自己能够从容着陆。就好像现在的乌克兰又或者是斯里兰卡，他们的权贵，或者稍微有点资源的人，都可以润出去了。

最近一个月，我明显地感觉到了视频号的内卷了，出爆款的概率下滑，零播放的变多了。基于这种情况，有很多很多人会给你们分析，我没那个心情，与其说出一些玄学，还不如给你们说出真相，因为我早一眼看穿了事实。

我盗坤从去年就开始关注视频号，今年二三月份顺利接档视频号红利，此后持续优化玩法，投入更多的人和资源，我们在6月份运营了80多个账号，赚取了一个非常可观的利润。

但是我知道，我的结果普通人无法复制。

我们所取得的结果，经验很重要，信息很重要，执行力很重要，然而能把这个经验信息放大的核心，还是资源。我们四个账号就贡献了八十多个账号利润总和的一半的，这是巧合，是运气，更是实力。因为如果没有这80多个账号的基数，我们绝对跑不出来这四个赚大钱的账号，或者说出现这四个账号的概率会大大降低。而我这80多个账号，背后的团队也不是普通人短期内就可以快速组建的。
