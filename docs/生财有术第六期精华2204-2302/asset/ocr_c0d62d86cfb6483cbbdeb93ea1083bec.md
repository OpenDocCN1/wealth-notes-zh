# 1. 开启暴力分享机制

定义：如果用户要使用一个功能，必须分享后才能使用该功能点，分享在QQ生态里面绝对是中之中的功能点，一个产品分享率高，有如下好处：

① 有专门的模块给你曝光（现在已经下线）

② QQ群资料页面长期曝光

③ 个人资料页面曝光

④ 通过产品设计，让个人排行榜里面曝光你的产品（目前小程序端好像已经下线）

⑤ QQ空间曝光

⑥ QQ说说模块有可能给你顶置的曝光位（该功能已经下线）

获取了初始流量以后，后面肯定是希望更多的用户分享我们的产品，这点在微信小程序生态当时也是这样的，但是我们经过了几点这个优化，让用户尽量分享我们产品。

虽然这个对产品的体验不是太好，但是在平台蛮荒阶段，还是非常有作用的，而且这个时间窗口很短，你如果把握住了，你就可以快速的获取到大量的流量！

我个人认为，在QQ生态里面，用户分享你的小程序的意愿远大于微信生态，而且QQ生态对这种诱导分享的管控没有微信生态严格。
