+   a.单卖挖掘机产品卖不动：

客单价高；

缺少视觉冲击力和应用场景；

购买动机和购买决策分离：消费者是孩子、购买者是家长，除非特别刚需（比如为了学习），否则卖只能是小众产品。

+   b.但是把产品包装成儿童游乐项目，体验式游玩，以按时收费的方式取代直接购买，消费场景瞬间戳到很多男孩和父亲的痛点（每个男人都有个工程建造梦），原理参考乐高。

+   c.恰逢过年，赶上流量高峰期，视频一下子就爆了。

综上，得出结论：这个项目，赚钱是必然，不是偶然。
