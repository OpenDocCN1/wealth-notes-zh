随着社群人数的增多，要做的事要越来越多，精力不能兼顾，加上副业收入差不多是主业4倍，我就自然而然地副业转正了。

最后，还有一些浅薄的心法经验，也分享一下。

# **1.做减法**

找准一个赛道深耕，要相信一切都是积累。

我之前尝试过TikTok、知乎好物、红包封面、视频号书单等等项目，虽然都做出了一点点成绩，但最终都放弃了。

放弃的原因主要有两点：热爱度，能否形成赛道积累。

吴军老师在他的《见识》一书中说过：“**<u>要做的事情精简到最少，把握住一个方向，往往能走的更远。</u>**”

于是，我经过反复的利弊权衡，最终决定还是深耕公众号赛道，回到我最喜欢的理财上来，既能学习技能，又能致富，还能不断积累。

# **2.代表作思维**

要有自己的代表作，越多越好，有打造精品+系列的意识，给别人关注的理由。
