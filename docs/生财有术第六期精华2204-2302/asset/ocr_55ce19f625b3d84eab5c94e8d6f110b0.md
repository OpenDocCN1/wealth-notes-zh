+   1. 无论在手机还是电脑上，连同一个wifi，会显示同个IP（即若手机和电脑都连同个wifi，则显示同个IP）
2. 电脑无论是连所在环境wifi，还是连手机热点，IP地址都是相同的（即对于电脑来说，若网络从所在环境wifi且为用自己手机的热点，IP地址不变）
3. IP和用哪个浏览器打开无关
4. 同一个手机同个流量卡显示同个IP，同一个手机用不同流量卡显示不同IP
