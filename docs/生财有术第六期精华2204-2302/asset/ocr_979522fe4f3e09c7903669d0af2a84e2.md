# # 一点心得体会

能够有这次奇迹出现，更多成分是运气，当然，最离不开的，就是得下场去干！个人认为，高手分享的玩法，关键点都在他们分享的字里行间，请认真细品！还有落实去干！

下面说说我学习了晓文老师的玩法后，自己执行的一些关键点：

+   1. 开新号一定要设好**PID**。可以减少结算时间，也方便出单后号废了可以直接更换管理，快速用新号继续葱，可以参考圈友未来的操作：[`<关于微信小商店带货佣金集中的操作>@未来`](https://example.com)。

+   2. 选品过程跟老师的一样。具体过程可以查看：[`<选品思路&答疑-郭晓文>`](https://example.com)。

+   3. 选好几个品，或者供应商提供爆品主推

+   4. 每个号只推一个品，这样每个号流量更准、转化更高

+   5. 不断参考最多点赞和每天最新视频

+   6. 我是什么电脑和网线都没关系，关键是要用浏览器的无痕模式登陆。

+   7. 上传视频没有讲究，往死里怼，间隔一个小时就把200以下的删掉，一天后再把3000以下也删了。

+   8. 账号是耗材，没有就要去收集这些资源了

+   9. 除了做视频，也不要忽略直播技能，不然爆了也不一定接得住。（看下面收益构成，直播和视频可是5050啊！）

+   10. 找到好的供应商非常重要，可以给到你意想不到的帮助和资源。

+   11. 由此往复，干就完了。

+   12. 想不明白就干明白！（明白老师对不起，但这句是真管用）
