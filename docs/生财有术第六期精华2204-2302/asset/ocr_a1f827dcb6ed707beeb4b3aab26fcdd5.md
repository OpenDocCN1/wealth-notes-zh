# 1、批量思维

当你想找**一个好老公，会很难**。换个思维，如何找**一批好老公**，就容易了。

想找**一个**“爱读书的老公时，很困难。难道在相亲时逐个问：你爱读书吗？

换个思维方式，找**一批**爱读书的老公，这就容易多了：让自己更优秀，混各种读书会，让老公们找你。

**1+8+27+64=100**

**1³+2³+3³+4³=10²**

**1³+2³+3³+...+n³=(1+2+3+...n)²**

第一道题是复杂的，当变成第三道具有普遍化的等式时，就简单清晰多了。

这是波利亚《怎样解题》里的“创造者悖论”：**更宏大的题目，更容易解决**。

利用归纳法将问题普遍化。解决普遍性问题，比解决特定类型问题更容易，因为通过归纳抽象出本质与共性。

草根出身的人思考“我如何才能成功呢？”，不如换个思维方式：“草根们都是通过什么方式成功的？”

当你想写一篇好文章，不如问“我如何写一批好文章”，你可能会早睡早起清晨写作，找到优秀信息源，找优秀写作人作伴，找写作模板与技巧等。这样你更容易写出一篇好文章。

这也是矩阵思维

如何开**一批**赚钱的淘宝，做一批赚钱的自媒体，多账户打新。这就有了淘宝店群、MCN机构等很多批量化、自动化的操作。
