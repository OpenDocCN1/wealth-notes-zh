# 四月：FACE、APE、OK TAKI打新

face涨了15倍，只吃到3倍，怎么卖飞的，好像是因为在外面喝酒，反正我一出门就有行情，我一出门就不是卖飞就是踏空，已经总结出规律了，习惯了。。。。

APE：APE是个优质机会，有猴地的利好预期在，价格涨了一倍。这个确定性是很大的。我吃到一部分利润但是离做到极致还差得很远，有做到极致的人这波APE上赚麻了。我后知后觉，对机会的研究也不够，没吃透是正常的。

还是那句话：

顶级的事件就是顶级的流量，顶级的流量带来顶级的财富，等于顶级的机会。

哭了。。。。。

OK TAKI打新：这次打新真是哭笑不得。因为前面FTX、OK的两期打新活动都很赚钱，有些人能赚7位数，所以，新的打新活动再来，肯定是要参与了。我也带着群里小伙伴参与。从零学，搞服务器搞账号什么的，有非常多的细节。工作量比想象中的大很多，我一个人干了两天一夜。狗的是结果出来90%的账号都被封了，账算下来不仅没赚钱还小亏了点，我真的很会谢。。。。处理收尾工作，总之这次活动消耗了我很多心力。

时间刚好跟猴地挤在一块也直接导致了我没怎么关注猴地做准备，没参与上。

选择呀，brother!

关键点上的一次选择，大于平时的百倍努力。
