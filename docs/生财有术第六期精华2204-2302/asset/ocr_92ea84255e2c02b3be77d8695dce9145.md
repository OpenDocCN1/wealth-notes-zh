# # (精华帖)(109赞)怕什么时间不够，进一寸有一寸的欢喜

作者： 凡灵逸尘

日期：2022-08-22

【如何利用校园业务形成闭环，通过劳务年入百万】

生财圈友们大家好，我是郑州圈友凡灵逸尘。自从之前被生财负责内容运营的小姐姐邀约写了教培转介绍的文章，就想多输出一些不同行业的内容用来分享。生财多数是互联网相关，我身边则是线下行业居多，但在这三年中通过生财学习很多多互联网知识。同时运用了很多在生财学到的内容进行线上线下相互结合，使我在低谷时看到了更多的可能。

这次想给大家分享一下劳务派遣行业，如今22年9月份大学新生即将开学，也希望此篇文章给想在大学期间挣钱的圈友们及需要学生群体的各位圈友们提供一些思路。也通过劳务派遣及校园业务和组建团队方面，可以给圈友们更全面的视角。

说起来我大一期间挣得第一笔超过5位数的钱就是通过劳务派遣。后来之所以转行做教育，有部分原因也是因为劳务这行遇人不淑，说起来没少经历劳务的坑，过程是美好的，结局是悲惨的，人生的第一笔负债也是劳务带给我的，但也因此成长了不少。

因此只要在生财看到有关于劳务派遣相关的文章，我都会第一时间发给我的朋友，看看能不能给他带来收获。他从大学开始接触至今已经从业六年，虽然也经历很多的挫折，但最终在这个行业深耕收获了不菲的战绩。但是之前有些圈友把这个行业形容的过于简单化，为防止小白入坑，所以他就生财写了一篇劳务派遣的文章想和大家交流一下，最后也引起了很多圈友的反响。

后面由于种种原因，这个文章就一直搁置到现在，都搁置一年了，总不能继续让其搁置下去。于是就由我代笔把这篇文章写完，也给之前评论区的圈友一个交代。顺带帮你们鞭策他不断的成长，这篇分享也包含他上篇文章中的提问，最后附上他原文链接，欢迎大家一起学习交流。
