# ### 3. 私域销售及运营

目前微信私域销售7人，全部为宝妈，均是经过2~3轮的筛选和淘汰的留下的。

显著特征就是家庭条件一般，对赚钱有强烈的欲望，自我驱动能力强，不需要耗费太多管理精力。

销售人员每月底薪2k，提点为销售额的4%，人均收入旺季在1w左右、淡季收入在5~6k左右，工厂所在县城，人均收入在3k左右，这个收入在当地属于高收入了。

多劳多得，自愿加班，销售部单设在县城城区，不耽误接送、伺候孩子，所以员工还是比较知足的。

因为来的都是精准意向客户，私域运营比较简单粗暴，主要是靠销售人员的个人持续跟单，由于养殖场客户一般为男性，利用女性优势，定期沟通，说话要甜，持续跟单、逼单。

女性更容易获取信任，并且不会对过度的营销行为感到反感。

拉开收入差距的主要原因是个人努力程度，由于时差问题，西北地区晚上九点天还亮着，如果销售人员想要更多的成交，就需要跟着熬夜。
