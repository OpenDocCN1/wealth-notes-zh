# 1. 如何养成一个好的直播账号

区别于纯无人直播，我们的玩真人绿幕的半无人直播，目的是为了打造一个能持续带来收益的“下金蛋的鸡”，所以我们需要对账号进行精细化运营，慢慢的打造账号权重，从而保证每场直播都有不错的基础推流。

账号分为起号期和稳号期两个阶段，起号期就是开始的7天，这个阶段我们的直播，主要目的是给账号打上直播标签，同时做到螺旋提升，数据一场比一场好，在第5场之后保持一个相对优异的数据，这样就能使我们的账号获得较高的权重。

而稳号阶段，每一场的推流其实都是由上一场直播的数据和本场直播的数据决定的，所以每一场都不能拉胯。

这时候我们为了保证流量数据的相对稳定，要发短视频来给我们的直播间流量进行补充，甚至介入付费来补数据，从而稳定账号的数据模型。
