# 二、我们做了哪些事

# 1.找到了源头厂家，了解产品成本

一位小伙伴专程跑到广州，找到源头厂家，拿下更低的设备价格，确保成本控制在25%，为了防止售后返修，还跟厂家签订了保修保障。

# 2.确定招商政策

我们在项目的合作价格上做了调整，竞品收费4W/家，我们直接腰斩，定价2W/家，这样在有价格压制的前提下，还有50%的利润。

# 3.搭建体验场地，制作内容素材

我们在苏州大本营发动所有人脉关系，在一周内找了十几个商场，最终在一个天虹商场拿下了中庭的点位。

接着，从竞品的一个本地代理商那拿到了施工图纸，开业后连续5天，设计了一套充值活动，每天忍着拍了几十个视频素材。（项目确实不错，果然很多大人小孩来玩和充值。）

中间还碰到了很多场地谈判的坑，一些商场的招商人员，会要求跟你签各种霸王协议条约，以及吃拿卡要，这方面大家如果做开店生意的，给大家分享几点踩坑经验：

+   a.很多商场的点位，空置率都很高，都是可以谈的！不要被对方市场人员套路，年付、半年付、押一付一、流水抽点等等，能灵活尽量灵活！不要占用太多资金成本！
