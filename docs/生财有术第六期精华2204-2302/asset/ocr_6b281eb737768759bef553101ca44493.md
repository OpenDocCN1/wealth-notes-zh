# ### 新手入门建议

+   1. 理性尝试和认真选品，不建议上来就选暴利产品，易封号正反馈少。

+   2. 99.9%的问题在生财都可以找到答案，多参考下方的百宝书和选品库案例，善用生财2.0搜索工具

+   3. 坚持，以1个月为时间线，保持学习，保持输出。

+   4. 同行是最好的老师，每天多刷视频=分析同行+选品
