# 五月： 审慎、Luna崩盘

审慎： 五月小体验了把国内NFT的快乐。

H带我们玩了一个国内数藏平台——审慎。

审慎是一个优质机会。审慎是5月同期最优质的数藏平台了。我们群里从最早开始玩，抢最早的创世暴富猫，第一次白名单买59，第二次公售买99，二级上线没过几天涨到了2万，200倍。国内NFT真疯狂！然后接着创世优先购的前四五个系列，上线都是直接20倍以上，有的四五十倍。我的一些创世暴富猫几十倍陆续陆续出掉了。最开始我问H“你创世暴富猫打算搞多少只？”，H说100只。我心想那我也搞50只吧，成本没几块钱。谁知道审慎二开级这么快，我还没收多少呢二级就开了上线直接十几倍。大写的后悔。

深刻的反省就是： 投资交易里，觉得重要的应该做的再难也要立刻去做去执行不要被一些困难障碍限制拖延； 而有一些可能导致系统性风险击穿下限的隐患再小也不要去碰。

国内数藏相当傻板式，玩正经的NFT你还得带点脑子，玩国内NFT（数藏） 就是直接让你觉得脑子是多余的，你只要会点买入会点卖出。说是你但凡复杂了点就会让用户多动些脑子就会减少参与的用户数，绝。

我就非常随意地在玩，几乎没花什么时间，不管NFT赚钱也好国内数藏赚钱也好，我还是一直都是很专注的，主要精力始终是放在币的项目的研究上。

我相信赚大钱真正靠的是积累，我相信积累的力量。

后面出来一堆国内数藏平台，属于台子满天飞。国内真的是太卷太卷了，你但凡发现一个赚钱的生意，一窝蜂而上，都能把你卷死，太可怕了。幸好crypto因为一些各种维度的门槛，国人参与得少，不卷。后面冒出的那些平台全部都是垃圾，我买的其他平台的一个都没卖，现在都不知道怎么卖。
