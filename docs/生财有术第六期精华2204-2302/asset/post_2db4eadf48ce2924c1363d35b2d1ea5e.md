### 1. 跨境电商还有哪些蓝海机会

铺货、追热点、跟单，这些是十几年前就开始玩的东西，现在有没有用，我不知道，我只知道未来十年再搞这些肯定没用，前提是你是按长期主义来入行跨境电商的。我在走穴时也经常提一个观点：未来十年甚至应放弃爆款思维。

我给蓝海市场（高客单高毛利）有如下定义：1. 发达国家 2. 人口大于1亿 3. 有一定进入门槛

所以在我眼里做东南亚的都是没有蓝海思维的，也不太懂选品。因为选品的第一步就是选蓝海市场。连这个概念都没有就去卖货的人，要好好检讨自己是不是真的适合做生意。

#### a) TK是蓝海吗？

Tiktok卖货还有没有机会？我甚至不认为tiktok是蓝海（尤其东南亚的，算了下文不再提东南亚了，太low了），为什么呢，因为tk的流量跟咱们跑display广告是同一个本质，就是货找人，想要流量跑到正好要买这个货的人那里（精准流量），这个是地狱级难度，我见过的国内顶级投手也不敢保证有这个本事，何况小白和新手。

但很奇怪小白和新手却特别喜欢做TK，这只能说明大部分人是**不懂流量**的。

流量分为两种性质：search搜索性流量（人找货）和display展示性流量（货找人）。

前者比如亚马逊，电商平台内的流量基本都是人找货的，这种流量的转化率是百分之几这个数量级。好转化，缺点是要参与比价竞争，但这可以通过差异化选品以及精准长尾词来解决。

后者比如TK，FB，INS等，这里自然流量的转化率是万分之几这个数量级。不好转化，但优点是不参与比价竞争，因此同样的产品独立站可以比亚马逊卖贵2-3倍也仍然可以爆单。其实也必须卖贵，因为display流量成本很高。

因此tk引流独立站成交还要做低价杂货的是真的不懂流量，tk小黄车或者独立站上产品，全网比价然后定到最低价上架的是真的不懂流量。

认为客户也会全网比价才考虑是否下单的是真的不懂电商，因为有这类行为的客户比例极低。

凡是过分关注temu和shein的我认为不懂流量，也不懂选品。因为1. 不同渠道之间流量相对独立 2. 做蓝海高客单选品的不会太care这些低价平台的流量和产品。

亚马逊不是低价平台，虽然亚马逊有很大低价产品，有人做慈善搞某二极和低价螺旋，做这部分产品的，以及铺货追热点跟卖的是要考虑考虑temu的影响的，但做差异化和蓝海选品的，在亚马逊空间仍然很大，亚马逊在这部分产品上是蓝海平台。

针对热衷TK的朋友我问两个问题：

**1. 拍产品的视频，能跑出多少自然流量？有确定性可言吗？个别播放量好的，有可复制性吗？**

**2. 如果自然流量不能保证跑出去，为什么不用付费去解决这个问题？付费不仅可以解决流量确定跑出去，还可以选择投放的人群标签，把精准和转化的问题也部分解决了**

**我经常说90%学TK的新人是两条腿都断的，一条是流量，一条是选品（只带货不选品）**

两条腿都断的却想奔跑甚至飞起，怎么可能呢。

对流量的确定性，转化的确定性，没有任何概念，自以为懂流量懂产品，还迷信大力出奇迹和all in。

凡是喜欢讲“大力出奇迹”的都不适合做生意。

#### b) 跨境电商卖货类，我认为的蓝海方向

- 1. 流量端：

有相对低成本获得search流量的能力的，或者有私域的（包括红人营销），或者有本事把display流量ROI优化到3左右的。

具体来说，平台类卖家要选择蓝海市场蓝海平台，做垂直/蓝海/差异化选品，布局精准低价长尾的search流量

独立站卖家优先选择GMC或者search ads流量来测品（GMC如果ROI低于3，基本可以认为是选品不行，就不要去FB烧钱了）。

- 2. 转化端：

蓝海选品，简单点的比如合规平替、海关壁垒（我之前的精华文有涉及），复杂点的比如痛点迭代、微创新、差异化

如果你觉得跨境电商主要卖的就是卖货，那么卖货的蓝海方向基本就这三个：垂直（包括DTC）、定制、差异化，这篇文章不讲这些，以后会有别的文章讨论，今天我们主要讲不是卖货的那些蓝海机会。

#### c) 跨境电商服务类还有哪些蓝海机会

相对卖货类而言，服务类里面的蓝海机会非常多，偏门蓝海也非常多，我个人肯定无法说全，我只能说几个大方向，并提供一个刚需蓝海的案例。

大家熟悉的结汇公司，物流，货代，广告代理商，支付通道，软件，知识付费课程，培训，店铺账户买卖，其他账户买卖，申诉/法律咨询等等都是跨境电商的服务商。

这些服务大类目，看上去都是面向全卖家的，从全人群这个角度，是谈不出蓝海的。

凡是涉及发掘蓝海空间的，一定是先发掘某一部分人群，卖货类的蓝海之所以在垂直、微创新、差异化、定制等等也是一样的道理，垂直就是针对精准的有长尾标签的一小部分客户。

比如针对仿牌卖家这个人群，仿牌物流（包含COD），AB跳软件，斗篷软件，黑帽seo工具，群控软件，支付通道等等这些都是服务商中的蓝海，单价和毛利都非常高，其中有一些甚至是市场空白，但却有刚需。

针对小白和新手人群，你也要去分类，因为差异非常大，不分差异就做这类人群的课程和培训，基本可以认为是比较恶劣的割韭菜的，就算能赚到，也赚不长。有一部分小白新手，是工厂，贸易公司，或者工贸一体的，还有一部分是有一定文凭或者海外留学背景即认知还比较在线的，这两类我称为有钱的和有脑子的，前者其实脑子也是有的，毕竟已经是生意人，认知跟那些想搞副业的财迷比起来还是要好很多，针对这类人群的课程和培训必须要通过高客单高质量建立门槛，筛掉那些没有付费能力的认知低的小白。

所以TK相关服务这里有没有蓝海，我就不讨论了，不然得罪太多人了，哈哈哈。

跨境电商服务类可做的产品非常多，也比卖货好赚非常多，要找到你熟悉的有资源的是哪部分细分卖家人群，然后找他们目前的痛点。

下一节我就举个例子，实地找一个需求很大，供给很少甚至几乎没有供给的服务产品案例。

熟悉我的朋友会发现，我在做跨境电商的卖货、课程、服务这3个方向上的产品几乎都是这个尿性——抓刚需中的蓝海。长期规避竞争，有的甚至垄断了n年。

任何生意入门都是先具备蓝海思维。

### 2. 精准人群：黑灰产长线良性卖家，以及他们的刚需

作为一个马上入行13年的老卖家，没有碰过黑灰产是不太可能的。所以我们自己对于仿牌和黑5的各方面细节也比较清楚，也有一些这方面的同行朋友。

最近两年来，由于独立站不发货不对账的盛行，国外信用卡通道比如stripe、square、2checkout等，风控越来越严格，要么难以开户，要么开完很快就封掉，paypal原本对中国卖家的支持非常好，但是现在不仅提高费率，而且新账户老账户的封号也特别严重，几乎到了没办法用的地步。

仿牌和黑五这个卖家群体里，其实数量和交易量是非常庞大的，日流水在十万刀这个级别的不少，他们也分三六九等，比如莆田鞋大部分纠纷率在5-6%，拒付率在3%左右，这其中又分为在线成交和聊单成交，后者拒付相对少一点，基本上来说，拒付可以控制在2%以内的我们称为长线良性卖家，如果他的产品是超A，性价比又很高，聊天或者邮件客服的售后服务很及时解决问题能力很强，拒付是可以控制在1%以内的，包括黑五卖家也有很多可以做到这个拒付率。

负责任的发货，负责任的售后，拒付率1%以内（拒付率的概念可以自行百度），从数据上讲这就是一个支付通道很喜欢的长线良性卖家。

只要他们能提供普货网站和资料去申请通道，并用AB跳等手段，从敏感品类的A站跳转到普货B站去提交订单给支付通道刷卡交易就可以正常使用。但国内外大部分的通道都有AB跳反查的技术，一旦查实通道就会关闭，资金就会冻结。

这些长线良性敏感品类卖家，还包括虚拟产品比如游戏打金/装备，增粉，梯子，交友等。只要长期拒付率小于1%，通道未发现他的真实品类，他们从订单优良程度的大数据结果上来看，就是好卖家。

他们的刚需就是稳定的收单回款，尽量快的结算周期，尽量不要收取保证金。这类数据良性的卖家，是值得长期服务，也可以带来长期服务收益的。目前针对这个细分人群的并能达到这个要求的支付通道是没有的，是个市场空白。

### 3. 国内外支付通道的现状

我们从以下几个指标来衡量国内外各种通道的好坏（具体名词不懂可以百度）。

- 1. 是否跳转
- 2. 是否收取保证金
- 3. 是否需要同步物流信息
- 4. 支付成功率
- 5. 结算周期是否小于一周
- 6. 出金是否可以入私账

其中，1 决定购物车转化率是否能最大化，尽量减少弃单，2、3、5 决定是否压资金，6 决定税务成本以及合规风险，4 决定投放 ROI 能否最大化（很多运营不知道这个点在损耗 ROI）

目前国产通道在 1、2、3、4、5、6 上都不同程度有短板，有些国内特殊环境以及卖家不诚信等原因导致这些问题并不能解决，因此形成一个长期无法解决的刚需痛点。

本来，国外通道对这一块是一个很好的弥补，比如以 stripe 为代表的国外通道，几乎可以解决以上所有问题，但目前 stripe 由于过于严格的风控，导致几乎没有办法成功注册并长期稳定使用。

### 4. 用 stripe 做一个印钞机

如果你有一个可以稳定使用的 stripe 通道，那么你的独立站或者聊单支付链接可以享受到：

- 1. 高达 95% 的支付成功率
- 2. 支持 apple pay、google pay、wechat pay、alipay 以及众多国家的本地支付接口
- 3. 无保证金不需要同步物流信息，最快第二天或第三天全额回款提现，对比国内通道最多少压 90% 资金
- 4. 通过结汇公司可以出金到私人银行账户
- 5. 独立站无缝集成，不跳转，不弹窗

但是目前美国、欧洲、日本、澳洲、新加坡、香港的 stripe 均无法百分百成功开户，即使开户成功也几乎都会在使用一段时间时候封掉。造成这个状况的主要原因，还是中国的不发货不对版卖家，以及一些 xi 钱（洗钱）的交易太多。

百度和知乎上关于怎么开通stripe的文章已经很多，但目前没有一个有实际参考意义。

目前可以比较确定开户能成功的，主要是美国stripe官方的一个白名单渠道，这个知道的人非常少。

美国stripe官方这个白名单渠道在国内也是我们独家代理对接。

开户成功后，还有复杂和漫长的养号/养通道的周期。

根据我们的经验，把一个stripe成功申请后，再通过重重审核，进入可以跑大流水的完全体状态，要经历下面几个状态：

1. kyc ok
2. face check ok
3. stock check ok
4. first withdraw ok
5. all ok new
6. all ok growing
7. all ok major

其中1是初始状态 2 3 4不分先后顺序 5 6 7对应不用养量成熟度

具体的养通道的策略为：

5之前都是每天1-2单养号

从5开始进入养量

- 养量第一个月每天500-1000刀

没问题进入状态6

- 第二个月每天1000-1500刀

- 第三个月每天2000-3000刀

- 每个月比上个月单日加量20-30%

第6个月进入状态7

- 每个月持续加量20-30%

如果能通过3-6个月时间，解决如上问题，那么恭喜，你就可以用这个stripe制造一个印钞机。

- 1. 写一个订单中转和分发的程序，接受在线支付或者聊天链接支付的所有订单
- 2. 通过这个中间程序把订单送给相应的stripe刷卡结算，养号养量直至成熟
- 3. 当对接其他站点在线支付或聊单客户支付时，仍通过这个中间程序屏蔽产品信息后提交给stripe

这其中还有一些技术细节不在本文赘述。

当通过养号周期，stripe的风控已经认可并习惯这个中间层程序，理论上只要通过这个中间层递交的订单，不管是伪牌还是黑五还是其他敏感品类，stripe都会照单全收，只要所有订单的长期拒付率在1%以内，这个模式就可以一直运转下去，目前已经验证的单账号可以跑的流水金额在数十万美元每天。

这个中间层就是一个印钞机，因为你可以把它开放给所有愿意对接的长线良性敏感品类的卖家，然后抽取一个固定佣金，这个可以因客户的流水金额和拒付质量而异，由于黑灰产比较暴利，一般来说抽水6-10%是可行的。

我们假设一天跑5万美金的流水，抽成10%，每天的净利润就是3万人民币，一年的净利润是过千万的。

其实5万美金是很保守的一个客户流水金额，我的文章虽然每一篇标题都很耸动，但仔细看过的人都会知道我其实对于赚钱效应的估算还是比较保守的，熟悉我的人也都知道其实我是个说话很实在的人。因为我们做什么都是蓝海，确实切入了很多极易成功和赚钱的项目，虽然结果听上去有点吹牛逼，但其实都是事实。

过去三年我们通过代理stripe开户对接了1000多个独立站卖家，自己也沉淀的不少使用2年以上的stripe老通道，如果这些老通道我们自己独立站都不用都拿去做抽点服务，可以算一下我们一年利润可以做到多少，1000万真的很保守了，而真正需要的全职人工可能也就一个。这也是为什么我一直说跨境电商里面有很多蓝海，做起来比

### 5. 软件化：黑名单、前置风控、AB跳转、封装、自动养号

我们结合自己和客户目前的需求，进一步把这个中间层做了功能扩展，形成一个软件产品

1. 黑名单

把我们自己和各个黑灰产卖家所遇到的恶意拒付买家维护进一个黑名单，所有客户共享这个大数据黑名单，大家帮助大家。

2. 前置风控

一些重复失败和重复提交成功的订单，由我们来拦截，避免stripe拦截造成怀疑洗钱导致封通道

这一块前置的风控规则和经验，目前我们已经累计了100多条，如果这100多种情况都直接提交给stripe，基本上很难使stripe稳定使用下去。

3. AB跳转

这个没有技术门槛，也是老技术，但是整合进来降低大家另外集成的成本。

4. 自动批量养号

根据我们上文的养号流程，针对各个stripe账号不同的状态层级，智能化的分配订单量。

5. 封装

我们的封装技术让stripe无法抓取真实成交的产品和网站，只要客户数据够健康良性，就可以长期稳定使用，享受stripe的众多优点。

# (精华帖)(95赞)做了 5 年账号租赁类目，扒一扒游戏租赁行业的坑

作者： 石头

日期：2023-01-12

这是一篇分享心得的帖子，进入生财半年多了一直没有好东西可以分享的今天把我一直在做的项目拿出来给大家进行一篇分享。做了五年的账号租赁类目，扒一扒游戏租赁行业的坑。

6.7年前开始做手游账号租赁的年轻人们，现在应该都实现财富自由了吧。

游戏租赁这个板块很大，项目稳定，市面上能做的长久的游戏有很多。

![](img/a50ad26370b1cd7f67818735c6f556a8_4941_0.png)

17年-19年的时候吃了王者和吃鸡的红利期，当时的回报率非常高，账号在1-2个月内可回本，回本之后就都是利润。那个时候基本靠暑假两个月就可以干的盆满钵满，现在回头再来看，其实游戏租赁项目也是一个比较稳定的项目，5年前能变现的账号现在依旧能变现，只是多与少的区别。

很多人问现在租赁行业还能加吗？

答案是肯定的，不论你在平台上做，还是发展自己的客户圈子，现在账号租赁还是能做的，一个游戏租赁项目，最重要的是看玩这款游戏的群体有多少，拿比较远的游戏，比如穿越火线，英雄联盟等，这几款游戏当年都是火遍大江南北，现在也依旧有他小部分的游戏群体，只要这个游戏没停运，账号就可一直租赁，持续性的变现。

拿近的项目来说，就是王者，和平，火影，飞车。这些游戏几年前的回本周期大概在几个月到一年不等。回本完之后剩余的都是利润，在加上你的账号本身的价值，例如1w买的账号，干了一年回本了，在怎么差这账号还是可以卖个几千米的，这个是账号价值。账号是可以长久变现的。回本之后无论以什么价格出租出去的都是利润了。

还有的人问账号租不出去怎么办？

租不出去是因为方法有问题，平台有平台的玩法，私域有私域的方法，方法对了账号就好租出去，租号这行从选好买号这步就有的说法吗，比如上哪里去收低价格的账号，账号内要有什么皮肤，什么武器比较好出租，平台的话就是要在什么时间段去上货架热度，标题如何吸引客户，如何让客人在你这里二次消费等等，私域的话也有很多方法，例如从哪些渠道引流，怎么帮客户上号等等。方法能用对的话账号是非常好租赁出去的。例如100个账号的店铺能做到每天80%-90%的账号能够出租的出去，每个月都有稳定的收入。
