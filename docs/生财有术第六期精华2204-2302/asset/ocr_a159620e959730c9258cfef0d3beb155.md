# 一、脱口秀项目的基本介绍

# 1. 脱口秀娱乐新方向的背景

自从脱口秀大会和吐槽大会火了以后，线下的脱口秀市场越来越火热。而社会的快节奏发展，年轻人们的生活和工作压力大，渴求一种能够缓解压力的新休闲方式，所以大笑了了解压的良药。

脱口秀演员们在朴素的舞台上，一个人一支麦讲着自己的原创段子，短短几分钟或许就能让观众体验生活的另一面，狭小的空间里，笑声会传染，也会有共鸣。

而后疫情时代，大型演出的缺失，让**200人以内**的小剧场现场演出迅速崛起。目前除了北京上海，脱口秀市场基本属于蓝海阶段，无论是场地地方还是个人想做该项目都可以有一定的利润空间。
