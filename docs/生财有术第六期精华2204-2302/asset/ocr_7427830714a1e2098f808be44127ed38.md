# ### 副业开启前，要搞清楚自己的优势劣势，不妨先梳理以下几个重点：

+   1. 你现在有什么？
2. 你擅长什么？
3. 你的经验技能点是什么？
4. 你能满足他人什么需求？
5. 人们愿意为这个需求付费吗？
6. 市场上有人靠洞察这个需求而赚到钱吗？
7. 这些人在哪里，以怎样的方式赚到了钱？
8. ......

# ### 如果没有人引导你挖掘优势，你通过回答这3个问题，也会清晰起来：

+   1. 别人在遇到什么问题的时候，会第一时间来找你
2. 做什么事情没有回报甚至倒贴，你也会一腔热情全情投入
3. 你在什么事情上投入了大量的时间金钱
