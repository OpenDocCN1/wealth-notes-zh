# **7.5** 一些延误战机的感悟

回想那时候的自己，多少是欠缺一些生意头脑。作为一个内容创造者，没有及时的抓

紧流量的红利。选择了免费的流量转化，没有及时的抓紧流量的红利。

没有稳定公司的收入和私域流量池的搭建。过于依赖个人IP引流，靠天吃饭，不确定

数量，不确定流量是否稳定。自然也无法快速复制，无法快速发展剧本杀写作项目。

只有稳定的流量，保证数量的前提下，才能快速复制团队，提高招生数量。

项目成立初期，没有注重流量转化SOP，单纯靠个人IP引流到的客户自己做决定，没

有提升转化客户的能力，也没有复制销售团队的能力。

当时的决定，还是属于自我发展，局限于自己的后端员工做流量转化工作，没有区分

开前端后端的工作内容，导致在发展的过程中，除了向合作方，合作机构，输出我们

的项目价值，我们也吸收，吸纳了不少有共性的项目，如知乎变现，抖音探店，闲鱼

翻身，等一系列低价课程。

简单易懂，容易复制，变现周期短。都由我们来制作SOP交付流程。像剧本杀一样，

从前端销售一直到后端交付。我们真正做到可复制，易复制。可变现，易变现。可团

队，可个人。无限制，零成本合作模式。
