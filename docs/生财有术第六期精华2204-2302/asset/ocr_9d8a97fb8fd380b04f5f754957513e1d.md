我们这个训练营的运营班子，一共有三个人。分别是我自己，徐言随谈，还有妞妞。每个人领一摊活，多一个闲人也不要。

妞妞是主导师，她的作用自不必说。这一次的 课程/点评/一部分答疑，都是 由她来完成的。

副导师徐言随谈，是今日头条最强大的微头条导师，也是龙珠俱乐部的伙伴，各位生财圈友对他应该都不陌生。这一次，他在群中承担另一部分答疑工作/拉群工作，属于是训练营的实际组织者。

我，渭水徐公，是整个主社群的发起人，整个社群的流量都绑定在了我的身上，所以我负责的是招生，以及负责在训练营里充当吉祥物，来提振士气。

毕竟写公众号是需要日更的，作者们两眼一抹黑，根本不知道哪天会得到流量，这是很难坚持下去的。当作者们陷入迷茫时，我就会跳出来振臂一呼，让大家更好地坚持下去。这样，就会有更多的人能坚持做下去。

# # （3）如何交付课程

除了教注册，教简单的运营之外，我们直接给出了一个简单粗暴的故事写作公式。这个公式，是妞妞从另一位老师那里学来的。到了公众号这边之后，她把原有的套路做了简化，最终得到了这个公式。

写故事的公式：一个故事=标题+主人公+故事的主干+结局。
