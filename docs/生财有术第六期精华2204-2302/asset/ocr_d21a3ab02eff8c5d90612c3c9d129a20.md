# ③ 这些项目会出现哪些问题，又如何解决

其实所有的项目共性问题无非就是：

+   1. 担心被骗，有所顾忌=信任问题；
2. 回复信息不及时，对接不及时=沟通问题；
3. 最后甲方结账后如何保证后期服务的问题。

合作之初，不管是甲方还是乙方都是需要有人先去迈出第一步的，这时候一般都是我们作为中间人去迈出这一步，去交付信任去作信任背书。

因为我和我的团队，我们彼此之间的信任是很坚固的，我只需要考核甲方即可，甲方靠谱我就可以带着团队全力去做，去放大。
