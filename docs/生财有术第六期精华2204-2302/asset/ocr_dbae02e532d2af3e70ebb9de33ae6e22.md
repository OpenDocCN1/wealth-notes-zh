# ---- 远程搬家

一次搬家，感觉又收获了很多不同的经验，分享给有需要的朋友们。

+   1. 首先需要家庭分工，老葫芦擅长打包和合理摆放包装里的东西，我擅长找规划搬家流程和整理家里东西。

+   2. 比价3家提供宁波到香港搬家服务的公司，一家报价3600元，一家报价1万，一家报价1.5万，对比三家提供的服务，最后按照我们的货物需求点，选择了3600元（注意点，每个报价背后都有价值，根据自己的需求，选择适合自己的就可以）

+   3. 搞清楚需要到货的时间，合理安排，设立适合的流程图，这方面我觉得自己特别擅长。昨天到家里，床垫比我们先到房间里，自己随身带着床罩，解决第一晚的睡觉问题，是最重要。

远程搬家总结：所需时间2周，最重要的是：列出自己需要做的所有事情和时间表，分清事物的轻重缓急
