# 三、流量承接服务

> 有明确需求的精准流量，我们怎么承接才能做好后端的转化？前面讲到因为客单价高，医美项目有一定的风险，因此决策周期长，我们的做法是把客户引导到私域后一对一跟客户建立充分的专业沟通，了解客户的各种诉求，帮客户做初步的分析，最后引导到医院。通过这种方式来缩短决策周期，这个角色叫医美咨询师。

# 1. 医美咨询师具备的条件

+   • 医美知识：具备有一定专业度的医美知识的咨询师才能让客户信服，通常情况下是由公司老员工进行培训和邀请医生不定期脱岗培训
• 美学知识：这是一个求美的行业，我们需要在看到客户面部的情况下能快速给出美学建议。
