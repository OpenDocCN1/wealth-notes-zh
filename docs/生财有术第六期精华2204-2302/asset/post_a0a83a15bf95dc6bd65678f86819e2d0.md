为什么花那么多时间？

一来数据是自己手动填，有时还要在桌面版看，或小程序看数据。

3. 这个人做得比我“烂”那么我，凭什么他能赚钱？
4. 这账号有群，让我用小号潜入敌军看看她是怎么变现的？
5. 这个号的内容质量很不错，为什么粉丝那么低，先记下来，观察观察。

7. 对呀，这篇文章就写得太偏激了，怎么好意思发呢？而且还一直发类似的文章。但是这评论实在是太猛了。

3. 一看就知道有没有真正的需求？
