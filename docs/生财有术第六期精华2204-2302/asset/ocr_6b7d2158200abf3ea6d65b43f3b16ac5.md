# 一、我探索过的三种TikTok变现玩法

# **1. CPS玩法：**

CPS就是通过引流用户注册某类软件，用户在上面产生了消费，从而有佣金提成。我们做的是交友软件注册，搬运各种美女素材涨粉挂链接，引导用户注册软件，从而赚取佣金。当时众多号中爆了一个视频，一周涨粉12万，当天后台点击近3万次点击，转化变现3000+，同时引流到Ins，一个号涨粉2200+，一个号600+。
