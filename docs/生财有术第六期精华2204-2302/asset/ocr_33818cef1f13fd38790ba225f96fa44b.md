# 总结

小白：今天有一个很好的领悟，人是在这个大的经济环境中的一员，其实就有点像全息图这个概念，你算的是一个人的账，但它是宏观经济状态的一个反应。

我觉得， 风险控制 这件事情隐隐约约贯穿在今天整个对话里面。我发现，当你说这个底线的时候，跟我原本想的底线还不太一样，你的这个底线是悲观底线，但蛮多人想的是乐观底线。

海程：乐观底线，悲观底线，我觉得都会有，就像炒股有止盈止损一样。 我会认为首先是不战败，立于不败之地就有可能性战胜。

我从小在军区里长大，后来学的经济和战争史，我经常会用一个军人的方式去思考这个世界，《孙子兵法》里有句话“知彼知己，百战不殆；不知彼而知己，一胜一负；不知彼，不知己，每战必殆”

一个人如果不知道他在他那一组是什么位置，其实就是不知己；而不知道自己的目标能不能达成，其实就是不知彼

而算了很多人的账，就像打了很多场仗一样，能够更好的看到不同打法的結果如何，哪些是有效的打法，那些打法内在有结构性的矛盾，是不可延续的。
