这种号的生命周期很短，基本新号从第一场直播到没有流量，就在3-5场的时间。除了违规，最主要的问题是这种低质量号无法持续稳定获得流量，基本就是一波流后自然死亡。

所以运营这种号的最大难度并不在于怎么做，而是在于怎么找到很多人帮你做实名认证，做更多的号来放大收益。

# 2. 耗费精力

纯无人直播号看上去很简单，不用出镜说话，但并不代表真的是“无人”，放在那里睡觉就能出单。

纯无人最考验的就是直播间运营能力，想要运营好一个号，要不断在后台打字做直播间互动、根据数据调品排品、适当人工干预补数据等，最重要的是，纯无人的号需要拉时长，一个号一旦开播，往往要播十几小时甚至几十小时不下播。

人毕竟不是机器，总要去休息，这时候要么把号放在那里，冒着中间流量来了互动不够没有破更高流量池的风险或者违规不调整导致下播的情况去睡觉，要么几个人轮流值守。由于我们起步时只有两个人，虽然赚钱但精神上还是很疲惫，即使去睡觉了，做梦也是在看直播间。

玩法不适合所有赛道，只适合比较宽泛的产品。尤其是做的最多的容易出业绩的类目还是女装。但是女装这个赛道真的很坑，出单虽然容易，但退货同样多，动辄 40%+ 的退货率，往往看着GMV计算收益时很开心，但实际拿到佣金时却打了个打折，真的是让人觉得很沮丧的一件事。
