# # (精华帖)(627赞)来了，6月航海实战正式开放报名

作者：亦仁

日期：2022-06-09

来了，6月航海实战正式开放报名。

报名不用抢票，别急，先看完下面的内容。

+   1. 先看看我下午发的这次航海实战背后的思路和理念，帮助你更好的从这次航海实战获取到价值

+   2. 还是要强调一遍，参加航海实战不能立刻帮你赚到钱，但能为长期赚钱做准备。

我们每天会有很多理由，不去做那些真正重要的事情。比如从隔岸观火到下场行动，参加这次航海实战，大家一起抱团前行，一起互帮互助解决遇到的问题，能够坚持下来的概率更大一点。

这次航海实战不是手把手教，也没有船长带，主要是建立一起实战的氛围，通过机制让我们持续实战21天。

+   3. 不鼓励报名多个实战项目，每个项目都有机会赚到钱，参加多个项目，并不会提高整体赚到钱的概率，恰恰相反，会降低概率。

很多项目会重复航海实战，这个月赶不上，下个月觉得还是想报，到时候再来。

建议只报名一个初始或者高阶的实战项目。

为了让你不再纠结摇摆，上船后不支持中途退保证金下船，除非航海结束完成航海任务后才会退保证金，航海目标设定不高，往期保证金退款率都是80%以上。

如果要报名多个，填写多次表单即可。

+   4. 虽然生财团队之前已经有很多次组织大型航海实战的经验，但这一次，又基本推翻之前的大半模式，所以对生财团队来说，也是新的挑战和尝试，很多地方会没考虑好。

如有体验不周，欢迎大家来吐槽，将会持续改进和迭代。
