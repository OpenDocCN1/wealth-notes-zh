# ## 5.规避纠纷与法律风险：轻交付 重思维提升

# #### a）服务B端靠专业 服务C端靠“骗”？

过去三年我服务了1200多个跨境电商卖家，基本都是已经入行，有一定专业度的老板。

做B端服务，转化只靠一点，就是在某个点上够专业，往往对方老板一个电话过来，聊五分钟，就知道够不够专业，挂了电话就成交了，掏钱也不费劲，对价格也并不太敏感。

这是因为对方也具备一定的专业度，有能力区分你是否专业。

C端服务则不是这样，因为C端客户大多不专业，所以无法区分你的专业度，你为了完成转化，就必须包装自己，包装产品，做出一些夸大型承诺，给出一些过分量化的结果数据。
