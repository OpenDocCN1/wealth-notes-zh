# (2) 循环录播

我们在做无人直播的时候，使用了大量的账号进行素材测试，发现从18年到现在，抖音起码经历了多此的检测标准。

最开始是5分钟，后来15分钟，半个小时，1个小时...

超过1个小时的不重复的素材，暂时就不会被检测，我们实操的时候一般准备3-8小时不重复的素材进行直播。

# (3) 前后比对

这个是最近才测试出来的，平台会对比你的本场直播和前后两场，用来判断是否是同一素材重复播放（只要被举报，人工一定会这样核查）。

# (4) 多人直播

如果你用了a素材，其他人也用了a素材进行直播。平台就会判定多人直播，一样定性违规。

# (5) 主播人脸识别

这个是最近才开始在主播之间推出的一项功能，比如你的视频内出现了迪丽热巴，系统自动会判定“迪丽热巴出镜了”。

也就是说，如果你没有小杨哥的授权，你在直播间使用小杨哥的脸，会被立刻判定违规/品牌侵权/肖像侵权/盗录。
