# 2. 如何与小二联系

店铺开通后，后台可以下载一个Knock的软件，然后通过给自己开通Knock账号，使用这个账号就可以登陆Knock了。

登陆后一般类目小二会把你的账号拉近商家群里，这样就可以看到小二平时发的一些消息，也可以在群里跟其他商家交流。
