# 【第十三章】赚想赚钱的人的钱

赚想赚钱的人的钱，从来是门好生意。

生财做的是这个生意，我做的也是这个生意。只不过，生财做得大，我做得小；生财做社群，我做训练营；生财什么都做，我专注一个小领域，做到极致。

你会一个赚钱的法门，自己亲自去做，可以赚到钱；但如果你去把这个方法交给别人，就可能赚到更多的钱。

关键点有四：

+   1、自己只要能赚到钱；
2、你要有足够的流量来源；
3、你要会做成交易；
4、你要擅长教人，能让学员出结果。

凡尔赛一点说，这四点我都比较擅长。

所以我才能把短视频带货训练营连做9期，而且越做越好。

我想赚更多钱，当然会尽量让学员都赚到钱。

学员赚到钱，跟我赚到钱，目标是一致的。我要努力让学员赚到钱，我才可能
