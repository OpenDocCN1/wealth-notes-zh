# 2.1.1 Country Code Top Level Domains (ccTLDs) 国家域名

使用 ccTLDs 国家域名实施国际 International SEO 的优点和缺点分析。

ccTLD 是指 country code Top Level Domain，它相对于 gTLD，即 global Top Level Domain。.cn, .sg, .co.uk, .co.jp 这些都属于 ccTLD，而 .com, .org, .net 这些都 属于 gTLD。

ccTLD 是一个强指引，它说明该网站是专门服务该国家使用。因此相对于使用目录或者 gTLD 的子域名，ccTLD 在排名上有着较大优势。

这里的排名优势是指 www.domain.co.uk 的网站在 www.google.co.uk 上相对于选择 www. domain.com/uk/ 和 uk.domain.com 有排名优势。

但是 ccTLD 也存在一些缺点，其优缺点如下：

优点：

+   1. 对搜索引擎有很强国家信息，在特定国家排名有优势

+   2. 通常有独立网站，有自己的sitemap和robots.txt，

+   3. 其他国家的网站受惩罚（如熊猫算法）不会被“连坐”

+   4. 可根据受众地区单独优化提速

+   5. 目标地区受众能享受到本土化的亲切感，容易获得信任

缺点：

+   1. 每个网站有单独的 DA(即 Domain Authority 域名权重是 Moz 的提法)，全新网站需要重建 DA 。
