# # (精华帖)(305赞)什么样的人值得帮

作者： 郑小焦

日期：2022-09-08

大家好，我是小焦。

两年前我有幸在生财认识了一个人，收到他转过来的一笔款项，按照当时我的工资要省吃俭用三五年才存得上。

于是，我用这笔钱作为启动资金踏上亚马逊创创业之路，并获得还算满意的成绩。更有幸持续获得帮助至今，在这两周年之际，回顾过往经历并尝试做一道自问自答题。

希望以此让圈友获得一点点启发，无论是发出请求帮助的“受助者”，还是帮助别人的“大牛”。愿：

助人者，帮值得帮的人，少些心寒。

求助者：竭尽所能回馈，莫要辜负。
