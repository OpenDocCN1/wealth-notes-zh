# ## 一、如何用赛道标签客观分析定位

越来越多人开始重视定位，但仍然忽略了一个点：做定位，从来都不是一步到位。

绝大多数人都要经历调整甚至推翻重来，我也是定位失败了好几次，才选对了教育赛道。

自从我小红书做的小有起色之后，有位大兄弟来问我，为什么自己那么用心发布了那么多篇笔记，点赞还是个位数，数据差的特别想放弃。

我瞄了一眼他的定位，其他都不用看了，就知道铁定凉。

①主观决策：我问他，你是怎么做定位的，他满脸自信地说：我喜欢什么，擅长什么，选取重合的那个点，就是我的定位！
