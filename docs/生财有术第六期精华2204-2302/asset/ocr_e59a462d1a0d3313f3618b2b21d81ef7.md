很多人看完后可能会说：就这？改成黑色就完事了？

甚至有人刷到这个账号，分享给我的时候，还说了一句：这是什么阴阳配色？

封面让人大跌眼镜，但是你们别忘了，数据表现是何其出色，篇篇爆款，10w粉丝的账号都做不到的流量稳定，一个1千粉的新号做到了！

现在，你可能会非常好奇，梨云黑的成功，是怎么做到的？

使用场景：定位依然是学生人群，因为我是够了解这类人群，他们在线活跃时间更多是在放学的晚上。

那么，从用户体验的角度出发，什么颜色，会更适合在夜间光线不足的情况下使用呢？

跨行借鉴：我猜你已经想到了，没错，就是手机上的暗夜模式！

那么，我能不能把这个模式，借鉴到小红书的封面上？以封面颜色舒适作为吸引观众第一眼 的钩子？

说干就干，笔记发布之后，数据直接破千赞，验证了暗夜封面模式的成功。

颜色迭代：不久后我发现，梨云黑封面不能完全融入手机的暗夜模式，这意味着这是两种不同的黑。

如果仔细观察iOS和Android系统的暗色模式，你会发现他们都没有使用颜色代码为#000000纯黑色。
