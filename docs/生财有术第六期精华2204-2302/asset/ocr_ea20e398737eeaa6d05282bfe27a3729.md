例如我这个品标题是【餐饮业创业计划书 美食餐饮业项目介绍商业计划 经营方案策划书】，

他的词根有哪些？有餐饮创业计划书、美食餐饮项项目介绍、商业计划书、经营方案、经营策划书等。

可以拆缘5-6个词根，我们又可以用这个词根去找边更多的品，以此循环去选品，也可以把这个标题复制到天猫，会自动分解出多个词根。

# 蓝海产品选品的标准

这个产品10人以内、3人以上在做，3人以上在做是以防是独家产品，上架后怕有坑，10人以内在做是为了产品是够蓝海，能够快速出单。

我们选好品后还要去查商标还有著作权，都没有问题的话就可以上架到多多了。定价这块稍微比同行低价一些就可以。

我们做的就是截流出货。像截图的产品同标题只有8个人在做，没有涉及到商标还有著作权，那么我们就可以做。
