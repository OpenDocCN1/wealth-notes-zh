# ## 4.我的多渠道经历

我的多渠道之路大致可以分为两个阶段

+   阶段1：广撒网阶段

+   阶段2：聚焦阶段

阶段1：我选择了大概有10个平台一起发布，比如抖音，快手，微视，视频号，B站，知乎等等，那会我的感受就是，短视频平台的流量确实是最厉害的，最不济也有500的保底播放，但是同一个视频，我发布到B站，可能就几十万播放。

这个其实跟平台的性质有关，像B站这种是货架式，是别人点进来来，但是短视频是系统推送的，所以短视频平台的播放量大这个也是显而易见的。

然后广撒网一个月，那会我每天晚上做好内容发布10个平台，然后第二天就时不时打开手机看播放量，每次看都希望可以给我惊喜，但是有些平台的播放量真的是惨淡经营，只有位数，偶尔会有极少数比如说企鹅号里面，我发布的视频有两个几千的播放，那叫一个激动啊，但是也才2个，后面我观察了1个月数据之后，把很多平台就撤掉了，进入到了第二个阶段。

阶段2：聚焦阶段，经过一个月的实操，我就留下了抖音，快手，视频号，B站这四个主力的短视频平台，当然B站不仅仅是短视频。

这个是我做的一个减法，因为我实操了一个月，一个月之内这个平台就起不来，我干脆就阶段性的放弃了，留下的这4个，其中快手表现最好，抖音次之。
