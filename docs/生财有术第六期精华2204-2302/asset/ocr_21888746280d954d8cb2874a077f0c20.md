# 一、提供的是什么服务，如何发现的商机

主营海外留学生的大学补习业务和求职业务。

**2016 年**：当时我大三，坚持做了 3 个月讲座，分享我的大学申请/大学如何保持高分/大学选课等话题，收获 **1500 名大学学学弟妹的喜欢**。当时我并不清楚自己想做什么，但找到了种子用户。

**2016-2018 年**：开设海外大学补习业务。踩到了蓝海红利，竞争少，需求大，很快 **公司年营收破 1000 万了**。

**2018-2020 年**：补习机构红利期逐渐消失，机构成了名师的打工人。寻找新机会，发现大学生补习最终还是为了求职，便研发了求职系列产品：证书培训，求职课程，实习内推，简历定制，面试辅导等；于 **2020 年彻底放弃补习业务，转型求职**。
