# # （2）如果不在生财有术，怎么找甲方？

+   1. 社群渠道：微信/百度上搜一搜，学校名+兼职群，找到QQ群/微信群，去找群主聊，他们会有一堆甲方。
2. 兼职app：去【兼职猫】等兼职类app搜，找合适的兼职，联系负责人。
3. 电商渠道：去闲鱼搜【副业】【兼职】，找合适的项目，联系负责人。
4. 内容平台：去抖音、知乎、小红书等平台，搜【大学生兼职】【大学生赚钱】等关键词，同上，联系博主沟通。

其他方式可以自行拓展，反正就是在多渠道，搜关键词，联系内容发布人并进行沟通。

# # （3）如果是甲方，如何获取大学生资源？

常规的渠道如下：

+   1. 各种线上校园小程序及QQ频道也可以进行寻找。
2. 校园渠道：联系学校学生会或者社团，通过学生会或者社团的外联部门做活动赞助。
3. 生财渠道：生财或其他社群资源帖。
4. 公域平台：贴吧，小红书，知乎，抖音各大高校的官方账号下面的评论区留言：知乎相关高校问题的回答下评论引流，小红书发帖招人。
