# 一、我的产品

## 1. 产品介绍

目前的主要变现产品有：理财社群（包含可转债课程+策略网站）、广告收入、券商开户佣金。变现平台主要是公众号。

## 2. 关于产品

我为什么要做这样的产品？

### 1）思考历程

大家还记得亦仁曾经在2021年的时候，发起过的翻倍计划周复盘吗？

那个时候，我每周都写复盘，成功完成了主业翻倍后，我在副业上开始犹豫不定。

那一段经历，非常充实也非常迷茫，自己的主业是程序员，副业运营公众号，当时的港股打新/知乎好物/视频号又如火如荼，我想迅速把副业发展起来，但始终拿不准该做什么方向，能做的太多了，想做的也太多了。

木易哥在朋友圈说：“越是这种时候越要向内求，只有自己才最了解自己，把想要的东西，遇到的问题逐一列出，回溯一下该反思的点位，该成长的点位，越深刻越好，越详细越好”。

涛哥的文章也提到了：“抽整段不受干扰的时间，列个T型图，左边，先把你个人的技能树列出来，12345，然后右边，把你现有的信息里有可能去做的项目，列出来，尽可能多，12345......”。

【本周思考总结】

1、我没有真正动手，太墨迹了。我不太喜欢「成长+探索+反思」，为什么是复盘呢。想来我是不是需要换换呢！很大程度上是因为我自己没有足够动力和信心去改变，却把一部分时间用来说话和计划，减少行动量。结果无法完成，于是开始怀疑自己，无法信任自己。

2、包括，不踏实真的，不行动只想推测结果就过去了。原本是靠实践性，估计直接就开始忙正了，要实际行动。有问题。因没动手，所以也没真正反思过。

3、之前我从来没有意识到我时间都浪费在哪里了，只有我才打开了我自己，我感受的东西多，我对时间浪费，列出来看了一下：反思我自己的，该出来的时间点，该到的到达时间，该到时的到达，比如该到时间时，也拿到了为加数据不断干活的时间，列入计划。左边：我把个人的生活时间预测，13345，然后右边，把列项的信息尽量有可能去的数据源，列出多，尽可能多。13345……，把自己的生活和思考可能去做的列项拉出来，发现自己还是处于相对忙碌状态。就继续往下做，做的再多一点。除了实际上和人一样的行动外。

### 2）选择写系列教程

从我开始认认真真不急不躁写系列教程开始，突然任督二脉就被打通了，不再焦虑，也不再迷茫，我的公众号阅读量从400到800到2000到4000，从开始接到第一个广告到开始变现第一个学员，最后到辞去工作专职副业，一年多的时间我就变现了100万。

> 有这么一句话：始终坚持走在正确而艰难的道路上，走着走着，你就发现竞争对手会越来越少。

最开始，我的公众号变现方式只有两处，一是推荐粉丝开户获得券商佣金，二是公众号的流量主收益，都很微薄。

那时还没有做理财社群和策略网站的想法，只想认认真真写好系列教程，让公众号阅读量起来，能接商业广告变现，最后做出自己的课程。

# H5 为什么要写系列教程呢？

一是，想和同行形成差异化，我发现大多数同行们都是根据当天的行情输出一篇自己的思考或者指导意见。诚然，这样会吸引到很多“勤奋”的喜欢追逐消息面的投资者，但是可替代性太强，门槛太低，写系列教程可以加深自己的“护城河”。

二是，我想有自己的代表作，这个作品能经得起时间检验，让人们愿意反复阅读。我当时关注的B站up主，像「雨说体育徐静雨」、「阿斗归来了」都有自己的代表作和系列作品，很容易吸粉和形成粉丝黏性，能给别人关注自己的理由。

三是，为做课程铺路，写好了系列教程，再稍微优化一下，就可以直接做视频课程了，是一件有长期价值的事情。

写系列教程肯定要有层次和结构，那最佳的对标对象就是书籍。

但是我发现市面上的可转债书籍，要么是案例和规则落后——由于书籍出版有多方面限制，所以市面上的书对很多可转债套利的细节不便详细描述，且可转债规则变化非常快，所以书籍中提到的方法很容易过时；要么是不够通俗易懂——专业术语太多，很容易形成学习障碍。

所以我的教程就从通俗易懂+实战案例入手，借鉴了市面上所有可转债的书籍，形成自己的章节目录，然后用自己的语言风格将每个章节的每个部分写出来。

# 3）发展出三个产品

系列教程写完后，自然而然地我的课程文稿也就有了，用视频的形式录下来，就形成了我的第一个产品——可转债课程。

可转债课程开始推广销售之后，我将学员拉入微信群，逐渐人越来越多，就形成了第二个产品——理财社群。

人更多之后，我发现大家需要即时获取我的策略名单，为了提高用户体验，于是我就利用自己的程序员本行能力，又做了一个网站，就形成第三个产品——策略网站。

可以看到，每一步都是自然而然逐渐形成的，并没有提前刻意规划。

# 二、如何获客

我是如何获取自己的用户的呢？

## 1. 免费粉丝交流群

我做公众号是从2019年9月份开始的，大概在2020年我建立了自己的免费粉丝交流群，交易日会每天分享资讯和投资早报，这样积累了第一批种子用户。

但是交流群毕竟人数有上限，长期维护运营也需要耗费不少精力，如何能将自己的文章传播和触达给更多用户呢？

做过公众号的朋友都明白，公众号是没有公开推荐机制的。所以即使你的文章写的非常好，也很难带来大量的关注和粉丝。

所以我目前又采用了下面三种方式。

## 2. 干货引流

亦仁有一个著名的理念：靠一篇精华文足以打破圈层。

如何让更多人知道自己？记住自己？要有自己的代表作，越多越好，有打造精品+系列的意识，给别人关注的理由。

我将自己写的干货文章，整理成系列教程，发布在语雀平台，不定期更新，并公开免费分享。

在公众号每篇文章底部也会引导大家去阅读，这样就形成了较强的粉丝黏性，并且还会有很多粉丝觉得获得了价值，分享传播给朋友。

## 3. 外部引流

外部网站引流，我主要是通过雪球网、知乎、今日头条。

雪球是专业的财经论坛，但是引流限制越来越严格，简介中严禁出现自己的公众号/微信等联系方式，只能偶尔在评论区中引导一下，但是聪明一点的粉丝还是会根据名称id找到自己的公众号。

知乎的引流限制则是越来越宽松，能在个人简介中加上自己的公众号/微信，也能在每天发布的文章中带上自己的公众号文章链接。但是知乎的文章引流效果有限，还是需要多答题才行。

今日头条的引流限制也比较严格，某一天，我的账号突然莫名其妙就被封了（应该是涉及荐股资质合规问题），我也就没继续在今日头条发了，个人感觉影响有限。

## 4. 大V互推

这一点，是我能把公众号做起来的一大原因。

能写出干货只是做自媒体的一部分能力，能让更多人看到干货并心甘情愿来关注更重要。

自媒体时代，尤其是做公众号，不能信奉“酒香不怕巷子深”的理念，必须要主动出击，互利共赢。

我从2019年9月开始写公众号，吭哧吭哧写到2021年9月，2年时间平均阅读量也不过才800。

但是从我找大V互推之后，阅读量很快就达到了2000，截止今年2022年9月，平均阅读量已经到了5000-6000。

事情是这样的：

偶然的一次机会，我在加入一个自媒体交流群后，发现业内一些大V经常在次条互推。于是我主动联系到这些大V，询问是否可以互推。

在沟通之后我得知，互推的规则是长期累积阅读量互推。

大概是这样：

> 互推双方建立一个腾讯文档。
> 互推对方文章，删除时把阅读量记录在共享文档里。
> 最终阅读量累计，双方大概一致即可。
> 发文间隔不限，由阅读量少的人控制节奏。
> 文章自选，分享为主，不用写推荐语。

比如A的阅读量有2000，B的阅读量有4000，那么A需要推荐B的文章2次，补齐阅读量。

关于互推还有几点要注意的：

- **1.1）** 互推只是手段，阅读量想真正做起来还得靠自己的原创干货能力，很多和我同期互推的博主，阅读量依然停留在2000-3000无法前进；
- **1.2）** 怎么找到大V并成功让别人和自己互推，就需要考验为人处事的能力了，成年人交往的本质就是利益互换，所以我一般会先做付出的那一方，让别人感觉到舒服；
- **1.3）** 要对互推的人做审核，质量太差就不要做，会消耗粉丝的好感和信赖度。

## 5. 工具引流

我自己做了一个工具策略网站，这个网站包含了可转债策略名单实时更新、实时估值等功能，通过这个网站可以实时选股，捕捉盘中机会，也是我的很多付费会员非常看重的一点。

我会在公众号文章中展示数据，展现价值。

# 三、如何变现

我目前的变现方式主要有三块：付费社群、广告收入、券商合作。

## 1. 付费社群

我是今年2022年2月12日正式开始做的付费社群。

开始做之前，我前前后后花了三个月的时间，在自己去年总结出的《启四可转债投资指南》文字版基础上，增加了更丰富的案例和进阶教程，并用视频录播的方式演示操作方法和思路，做好了一套视频课程。

由于之前还不会剪辑，我的每个视频都是从前到后一口气录完，中间如果有差错，就删掉重录，再加上我的主业是程序员——大家都知道的——很忙的一个职业，所以我只有每天晚上下班后，匆匆吃完饭写完公众号才能录，经常要录到半夜两点，所以搞了这么长时间才录完，中间一度绝望到想放弃，现在回头看，还好坚持了下来，也庆幸自己坚持了下来。

第一批种子用户来自我之前建立的免费粉丝群，2个群1000人，第一天就有大概40人付费，半个月的时间很快社群就积累了200多人。

![](img/a50ad26370b1cd7f67818735c6f556a8_5042_0.png)

作为一个从来没有尝试过大规模变现的副业探索者来说，那时的我只觉得一切辛苦和熬夜都值了，完全没有敢想象到今年能做到1000人的规模。

之后我就继续保持日更公众号，研究策略，开发策略网站，提升会员福利......

社群初始定价是388，一步步阶梯涨价，现在一路涨价到888元，目前社群成员已经有1000+人了。

后面来的会员基本上都来自于我的公众号，有大概5%是会员口碑介绍转化。

这部分的收入不是线性的，会随着行情的好坏有起伏，5-8月是我的策略最赚钱的几个月，收益率达到30%+，那时单月最高有345人加入社群。

## 2. 广告收入

公众号的广告收入一般是以阅读量来计费的，理财类公众号报价一般是0.7-0.8乘阅读量，每个月会有很多媒介主动来寻求合作，我一般会接3-4个广告。

## 3. 券商合作

理财类公众号做久了之后，几乎每天都有券商找来寻求合作开户，因为选项众多，所以我会精挑细选一些费率最低，条件最优的券商合作。

这部分我做的也比较佛系，只是将合作链接长期挂在我的引流文章中，偶尔有粉丝在群里问我时，我会结合他的需求推荐一下。

这些费率低的券商其实就是一个信息差，粉丝当然也需要交易费率最低的券商，这样就形成了三方共赢的局面，但这部分收入也是最低的。

## 四、经验分享

随着社群人数的增多，要做的事要越来越多，精力不能兼顾，加上副业收入差不多是主业4倍，我就自然而然地副业转正了。

以上就是我的整个思考历程+实操路径，毫无保留分享给大家了。

最后，还有一些浅薄的心法经验，也分享一下。

### 1. 做减法

找准一个赛道深耕，要相信一切都是积累。

我之前尝试过TikTok、知乎好物、红包封面、视频号书单等等项目，虽然都做出了一点点成绩，但最终都放弃了。

放弃的原因主要有两点：热爱度，能否形成赛道积累。

吴军老师在他的《见识》一书中说过：“要做的事情精简到最少，把握住一个方向，往往能走的更远。”

于是，我经过反复的利弊权衡，最终决定还是深耕公众号赛道，回到我最喜欢的理财上来，既能学习技能，又能致富，还能不断积累。

### 2. 代表作思维

要有自己的代表作，越多越好，有打造精品+系列的意识，给别人关注的理由。

这个借鉴自亦仁的“靠一篇精华文破圈”理念。

### 3. 必须坚持

知识星球出版的那本书《绝非偶然》，记录了21位头部自媒体的经历和感悟，

不同起点，不同行业，不同人生，但当我提炼出每个人的成功经验，却发现几乎所有人都有共同特征：

坚持、读书、输出、勤奋、复盘……

如果只留下一个特征：那就是「坚持」。

我再忙也会坚持每天日更文章，风雨无阻，甚至结婚当天。

找对方向坚持下去，量变就会产生质变。
