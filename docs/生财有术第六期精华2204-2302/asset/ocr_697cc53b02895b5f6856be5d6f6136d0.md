# 技巧二：不敢看镜头，干脆不看镜头

+   1. 可以用侧面采访视角拍摄，有对话感。

一般是30度-45度会比较自然。当然你要找到自己最好看的那个角度！！

翻翻自己自拍的时候，最多的侧脸角度是哪个，选那个就好了。

如果不爱自拍，还有个**小办法。调整好光线和位置，把手机放在正前方，拍一段小视频：一边讲话，一边慢慢转动你的头，从左边到右边。再从视频里找到你觉得最好看最自然的那一帧，选那个角度即可**。

采访视角拍摄口播案例很多，我们看个好看的姐姐。
