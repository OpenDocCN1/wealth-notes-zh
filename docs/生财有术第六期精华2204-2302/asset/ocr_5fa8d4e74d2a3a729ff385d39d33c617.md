# ① 能力强的和态度好的，选哪个？

选择大于努力，筛选大于培养，好的选择可以在根本上杜绝掉很多问题。

那在最开始的找人和选人的环节，我们是找已经有一定能力但是不听话的，还是找现在能力一般，但是听话的呢？

大家常见的错误想法和错误选择：

错误想法1：

学校里面有能力的学生=学生干部（学生会主席，社团负责人，班长等等）。

错误想法2：

他们面对的学生群体大，我直接找他们，让他们直接跟着我去做项目，可以省去很多事。

我曾经也多次尝试过，我发现，我错了，尤其是我刚开始做的时候！

原因有以下几点：

+   a，班干部和学生干部确实比一般人有能力，但是他们的能力是受到平台加持了的，脱离这个平台做别的事情的时候就不会那么得心应手了，因为学校不会培养他们赚钱的能力。

+   b，他们要花费大量的时间去处理班级事情或者学生会事务，没有足够的时间去做别的事情。
