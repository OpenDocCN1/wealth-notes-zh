# 3.5 VR、XR高技术融合，实景布局提供沉浸式体验

➢ 2021年伊始，虎牙直播联合优酷和小黑探推出全国首档沉浸式剧本杀直播综艺——《最后赢家》。该综艺将剧本杀与XR技术结合，播出以来广受好评，提升了观众和潜在玩家对这类技术的认可度。

➢ VR技术已应用于一些线下剧本杀门店中，为部分玩家所接受与喜爱。如《明星大侦探》官方合作的“芒果探案馆”已在各地铺展，自带高科技光环，打造跨次元VR实景剧本杀体验。

VR技术与剧本杀的结合体现在用虚拟现实代替真实的门店场景布置、玩家搜证环节，在令玩家享受到创新型游戏体验的同时，也为剧本的创作带来更大的空间和想象力。
