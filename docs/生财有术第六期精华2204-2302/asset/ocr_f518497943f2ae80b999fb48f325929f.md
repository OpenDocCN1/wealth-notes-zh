# # (精华帖)(71赞)风向标：如何把握我们的赚钱机遇

作者： 沐文

日期： 2023-02-06

很久不曾发文，最近一段时间对所谓“赚钱的机遇”感触不少，赚到钱除了个人的能力、努力、技巧、方法，贵人的指引，其实恰恰有种不可言说的“能量”，我们落地一些的称之为：机遇，也是一种势能，也就是在对的时间做了对的事情，那么往往成功来的会比较出乎预料，放在咱们生财就是“风向标”，普通人在红海中挣扎机会往往小于风险，而当在势能正向，把握住风向标的时候，往往赚钱的可能性大很多。

> 什么是生财的势能，我个人的理解就是：个人对赚钱机会的嗅觉，并且实际把握住了稍纵即逝的机会，这个机会可能是时间、可能是某个节点、可能是某一个巧合，而这些势能的风向标，又是有迹可循的，也有一定的逻辑进行梳理，结合风向势能，我更多的把赚钱的思路梳理为这个公式：

风向（热点、政策、趋势、节点、时间）--需求--内容（流量）--产品--转化率--赚钱，其中在风向之后有诸多的变星因素，会将这个势能放大或者缩小，大部分势能窗口期往往很小，机会稍纵即逝，只有个别风向势能有可能成为现象级的存在，站在这个口子上，跟对人做对事，猪就起飞了。

今天和大家简单聊啊，几个方面：我个人理解到的风向势能的表现形式，往往是时间为（并且是尽可能可预判的）、如何尽可能的把握住势能。本文尽可能进行了列举，相信哪怕不能直接的帮助大家赚到钱，但是多拿几个风向标也是完全没有任何问题的。
