# 六、变现方法

我简单说下，就不给人家小程序做推给了，这个大家可以自己搜下看看：

> 我们变现的原理：视频热门后，有人找你要图，那么我们引导用户去小程序里取图，成功取图后，我们就有收益。

这个小程序，我们说下：有很多种小程序，例如火箭取图、推图社、毒图君、萌虎取图等。

加入的步骤都很简单：就是先去抖音搜小程序的名字，然后进入后，会引导你加入创作者，基本上都说加作者微信或者关注公众号，然后成为创作者。

> 用户要图的时候，可以发取要求给用户，基本上就说私信和签名两种（多去分析对标）
