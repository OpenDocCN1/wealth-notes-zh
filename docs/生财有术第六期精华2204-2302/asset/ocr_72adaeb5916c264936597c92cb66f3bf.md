# # (精华帖)(163赞)用商业模式画布的方式写生财干货文章

作者：深圳刘宁培

日期：2023-01-06

我叫刘宁培，长期在深圳，龙凤胎奶爸，主业企业咨询：股权设计、企业经营管理、商业模式板块。

+   关于亦仁大哥说的星球文章是否改成3000字的短文，
关于最近的《生财有术项目精选》及拆解地图，
关于真传一句话，假传万卷书，
关于有的圈友进圈快一年了，因为文章太长了，一篇完整的精华都没有看过，

在这里提个解决方案，看是否可行：

+   一、首先，不认同真传一句话，假传万卷书这个说法。
大家都知道，钱是内行人赚的。
这句话成立的一个大前提是，传授之人跟被传授之人，都是内行人，都是知识密度差不多的人，才能差一句话就能点透。如果是内行人传外行人，一句话能讲透，开玩笑，不都是高在上的鸡汤文，谁不知道富在术数，不在劳身，利在势局，不在力耕。

+   二、有没有简单、通用的方法论，可以从道术器用四个角度讲清楚所有项目。
有，站在巨人的肩膀，看得更远。
工具：商业模式画布。（之前生财发过4个商业分析工具，第三个就是商业模式画布，链接如下：）
书籍：商业模式新生代

+   **1、道的层面：**
一句话阐述商业模式：我用一个XX产品/服务，解决了XX客户的XX痛点，赚XX钱。

+   **2、术的层面：**
①解决谁的问题，一个企业（产品）想要接触和服务的不同人群或组织；
②解决什么问题，为客户创造价值的系列产品和服务；
③怎么让用户找到，如何接触和沟通客户来传递其价值主张；
