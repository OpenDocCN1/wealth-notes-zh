# 3、灵活用工主要应用的行业

目前应用灵活用工最常见的行业，有直播行业、MCN机构、视频平台、在线教育行业、出行行业、低端服务业业务外包行业（比如城市清洁工、绿化工人、保安、保洁、实体店服务员）、众包行业等，这些行业和岗位的用工模式就是标准的灵活用工模式，符合国家对于灵活用工的定义和业务逻辑，这一部分业务和人员进行灵活用工操作没有任何的风险，完全合理合法合规。

另外还有因为疫情影响，应对成本管控而产生的部分行业新的用工变化的行业，比如酒店行业、餐饮行业、连锁服务行业。这一部分行业和岗位需要进行一定的操作和调整。
