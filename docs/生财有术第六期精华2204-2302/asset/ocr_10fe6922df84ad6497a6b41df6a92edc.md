# **5我想想要**

你店铺里的进来了1000人，会有2种情况：

+   **a，** 进来看了一下发现华而不实，图片好看，实际没有他需要的东西，转头离开，一句话都不和你多说。

+   **b，** 觉得图片好看，有兴趣购买，点我想要和你沟通一下，成交就买了，不成交就走了。

第1种情况就是产生了浏览，但没产生我想要，光靠主图吸引进来了，达不到客户的预期。

第2种情况是有浏览，有我想要，要么成交要么流失。
