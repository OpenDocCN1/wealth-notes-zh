# 移民家庭全球税务筹划

**案例** 王先生 50 岁 企业主，生息主要在国内，有一男一女两个孩子，孩子和妻子都是美国身份定居国外，自己由于企业性质禁止外迁，所以没有获取美国绿卡。父母健在，家庭和睦，大儿子在美国读高中，小女儿在美国读小学。王先生在国内有多套房产，在美国也有置业，客户考虑退休后去美国生活。

![](bbox=[0.14, 0.15, 0.67, 0.26])

**沟通重点** 客户目前的资产都在国内，退休后去美国生活，变成美国税务居民，将受国际美国的税收制度，可能要征税收益资产税，赠与税以及财产增值部分的所得税。所以我们建议客户要成为美国税务居民，在移民过程中建议选择增量通道方案，避免分红需要缴纳税费的情况。同时建议客户保留在美国签署不可撤销的个人保证信托，以后客户如回因美国可以保持原有的身份做提取后退与继承。合理利用美国法！

# 用寿险产品管理风险，后盾无忧地进行投资

**案例** 杨先生 42 岁，为某大型企业高管，他的太太与他年纪相仿，两人在同一家企业，太太担任财务总监的职位。两人育有一个可爱的孩子，10 岁出头。杨先生在该行业资产盘 1000 万+，客户觉得保险产品无法满足他对于投资理财的回报率诉求。

![](bbox=[0.14, 0.61, 0.67, 0.72])

**沟通重点** 和杨先生的沟通中，杨先生强调未来给孩子的教育金是必须要准备的，同时他希望能保证的养老金让自己和妻子的生活品质保持现有水平不下降。了解过年金产品收益对于产品的收益并不满意。我们给到客户的建议是选择储蓄保险，因为这类产品的现金价值很高，如果需要做存款金补充的时候可以提取现价补充养老老养老。传承给孩子的资金用杠杆来调动，通过杠杆撬动出来的资金可以进行投资获取更高收益，保责可以用投资获利的一半来支付！
