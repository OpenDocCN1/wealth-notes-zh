目前灵活用工中最常见的岗位，有直播公司/MCN公司/各品牌公司的各类主播、各种视频平台的博主、在线教育行业/线下教育机构的兼职老师、出行行业的司机、保安公司/保洁公司/劳务派遣公司的保安/保洁/服务员、众包平台的设计师/任务者/外卖骑手/快递员、酒店和餐饮行业的服务员等。

# # 5、灵活用工的政策基础

无论是从国家层面还是各地政府层面，灵活用工都是目前民生保障方面的重要一环，国家十三五规划和十四五规划都提到了这个方面，这就保障了灵活用工的合理合法地位。

国内灵活用工的业务，兴起源于金税三期上线和社保保险费由税务部门统一征收，以往在企业中可以采用的一些避税的不合规的土方法都不能再用了，而且也出现越来越多因为还使用不合规的土方法被查被罚款的案件，企业开始去寻求一些符合逻辑的、合法的降本避税方式。

同时，由于2020年新冠疫情爆发，直播行业/视频行业/线上行业爆发，新兴的“兼职”工作量激增，而传统行业受到冲击，企业停工停产员工失业也开始增多，灵活用工业务就随之爆发，国家也开始极度重视灵活用工的模式和发展。

李克强总理连续三年在多次会议中，包括两会和国务院常务会议上，重点提到灵活用工和灵活就业模式，并鼓励和支持灵活用工的大力发展，取消对于灵活用工的各项限制，保障灵活用工的各项权益。

国家各相应部门也出台了各种保障措施，全国31个省市也都出台了关于灵活用工的相关政策。
