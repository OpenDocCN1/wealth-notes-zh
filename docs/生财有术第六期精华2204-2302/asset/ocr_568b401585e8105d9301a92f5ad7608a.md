# 1.3 本地SEO 的实施案例及成果

对于生财有术社群中对 Google SEO 感兴趣的个人创业者或小团队，其实去做谷歌本地 SEO 的项目成功的概率会更大。

因为一般中国 Google SEO 的创业者，通常都只会把目标放在发达国家，比如美国，英国等，但通常这些国家的 SEO 竞争非常激烈。而本地 SEO 通常会在某个特地的城市或特定城市的某个小区域，所以竞争会小得多。

本地 SEO 一般跟地理位置信息强相关联，比如线下培训课、水管工、电工等需要地理就近的服务。

如果你有网上店铺的话，可以做一些不同地点的网上店铺信息页面来扩充自然搜索流量。

比如，以“杭州羽毛球培训课”这个关键字举例，肯定没有“杭州市滨江区羽毛球培训课”这个关键字这么精准，“杭州市滨江区羽毛球培训课”肯定没有“杭州市滨江区海外高层次人才创新创业基地附近的羽毛球培训课”这么精准，同时因为关键字长度越长竞争度也大大降低了。
