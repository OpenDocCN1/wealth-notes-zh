+   2. 更多的客户还是来自于我们同城的，与此同时也面临来自同城更多二级经销商的恶意竞争，打价格战损人也不利己。不是只有我们做抖音和小红书的引流的，同行看到也都跟上了也在做了。

+   3. 服务：汽车销售行业的标杆当属「豪车毒」，但是对于我们的客户来说，给他们省钱能更优惠的提车其实更重要，这也就让我们没有更多的利润可以提供更多的后续服务了。

+   4. 你所在城市的商业中心，比如万象城、万达广场等商业中心的一楼现在是不是能看到很多门店都摆放着展车。逛街顺便定一辆车，已经很正常的一件事。**4S店**有资金扩张这类门店，也有足够人员可以安排接待讲解，一个小小的二网没有这种体量的。

+   5. 新能源汽车行业已经高速发展，用户坐在家里，就可以直接在他们的官网下定一台车，绕过了我们这些中间商，他们提车的店也不再叫做**4S店**，而是叫做交付中心。如果未来更多车企选择这种模式，我现在想不出来二网该怎么生存。

# 9. 最后，说几点我对于这个行业的一些思考

我试过是不是可以推出这样一个平台：

+   1. 这个平台涵盖了畅销车的主流车型，客户在这个平台上预定，会比在官网预定更优惠（这里说一点：肯定是可以比在官网预定更优惠的，至少保险返点这一块就可以让利给客户），同时客户自己的信息在官网也是可查的。

+   2. 对于传统燃油车，车企还没有开始流行在官网预定，那个时候我们平台可以推出在线预定燃油车和新能源汽车甚至是近期流行的机车，再附加一些服务，比如礼盒送车到家。

+   3. 另外这个平台还需要加入在线远程办理车贷，以及可以参与汽车分销，在合规的情况下人人都可以做分销。

+   4. 在节省人工的情况下，可以直接跟全国各地现有的**4S店**或者二级经销商合作，哪里的客户就在哪里交付提车。
