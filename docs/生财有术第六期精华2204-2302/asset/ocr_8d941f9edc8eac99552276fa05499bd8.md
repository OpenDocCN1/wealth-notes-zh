# ## 坏人不可怕 可怕的是

心机深又会演戏的假好人

![](bbox=[0.24, 0.16, 0.7, 0.56])

当然，可能会问我：这个项目怎么去变现？其实最开始我们也在纳闷这个是怎么变现的，后来实操一段时间，发现这个就是壁纸项目，只不过大家习惯叫它"毒文案"，而且抖音圈也比较火。

那么，既然是壁纸项目，变现就简单了，我们可以通过小程序拿图去变现，就是用户看到这个视频里的壁纸做的很漂亮，就想问创作者要这张图，而创作者就可以给小程序的识别码，让用户去搜小程序输入识别码，然后拿图，当然了，这个要看完广告才能有收益，拿图一次是2-3毛，基本上一天下来 30-50的利润单号是可以做到的，前提是热门的情况下。

目前抖音上在做壁纸项目的还是很大的，而且大家都是做的不同的壁纸项目。而我们发现这类项目可以放大，且整体变现还是不错的，所以这个市场还是很大的，只要你找好赛道，完全可以复制放大。
