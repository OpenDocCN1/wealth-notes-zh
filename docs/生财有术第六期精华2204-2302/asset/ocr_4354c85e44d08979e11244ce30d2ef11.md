# 2）什么达人合适？

前期不知道怎么找，除了客户的brief仔细看，看历史客户投放过的达人类型外；还可以看做的好的竞品是怎么投的，从千瓜上都能拉到数据。

熟练后，好的媒介，可以不看数据，靠手感直接捞人，甚至帮品牌找到很多其他同行没有做过的破局KOL。

快速找到达人的方式：

+   A. 进达人群。如果自己写小红书笔记，会遇到一些同类博主，可以给他们 在评论区互动，相熟后加wx，找到有群的达人，进相关领域达人群

+   B. 联系到A达人后，让A达人推荐另外达人，这个裂变很可观

+   C. 进PR群，如果接过小红书广子，可以让相熟的PR拉进群（PR群里的达人一般质量比较偏低，只能应对初阶客户，高阶客户无法应对）
