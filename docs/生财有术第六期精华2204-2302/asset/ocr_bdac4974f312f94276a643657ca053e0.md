# # 5.软件化：黑名单、前置风控、AB跳转、封装、自动养号

我们结合自己和客户目前的需求，进一步把这个中间层做了功能扩展，形成一个软件产品

1.黑名单

把我们自己和各个黑灰产卖家所遇到的恶意拒付买家维护进一个黑名单，所有客户共享这个大数据黑名单，大家帮助大家。

2.前置风控

一些重复失败和重复提交成功的订单，由我们来拦截，避免stripe拦截造成怀疑xǐ钱导致封通道

这一块前置的风控规则和经验，目前我们已经累计了100多条，如果这100多种情况都直接提交给stripe，基本上很难使stripe稳定使用下去。

3.AB跳转

这个没有技术门槛，也是老技术，但是整合进来降低大家另外集成的成本。

4.自动批量养号

根据我们上文的养号流程，针对各个stripe账号不同的状态层级，智能化的分配订单量。

5.封装

我们的封装技术让stripe无法抓取真实成交的产品和网站，只要客户数据够健康良性，就可以长期稳定使用，享受stripe的众多优点。
