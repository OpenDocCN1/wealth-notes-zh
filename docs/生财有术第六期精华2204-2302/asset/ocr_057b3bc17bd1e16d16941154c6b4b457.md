# 三、认养十众筹裂变

除了认养外，真正让我们爆发的是认养后端的众筹。我会要每一个想赚钱的认养客户，在微信朋友圈发起一个茶园众筹，找别人一起来众筹茶园，因为他自己已经认养了半亩茶园，再去宣传我来一起认养也有信任背书，相当于成为了我们的经销商。

这周五共享茶园项目就要上线了，欢迎到时刻各位朋友加入我们，一起喝茶一起旅游，一起赚钱😜

然后我们会给这个客户一定的佣金，可能他自己认养了半亩1万（一亩1.8万），但是众筹最少就是10亩起，18万，佣金给他30%。他赚钱，我们也赚钱。

我把我们核心众筹的解析拆解出来，这个一般都是保密不外传的，但是在生财分享一定得要真诚，我就不藏着掖着了。

后端众筹模式：

自己认养半亩/一亩茶园后，在朋友圈铺垫自己和茶园的故事和收获，然后2个月后上线众筹。
