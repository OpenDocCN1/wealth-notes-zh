③ 邀请达人探店（包含新媒体平台和售票平台），提高剧场搜索量

尽量提高场地利用率，可与企业联系团购或包场等，出租场地（在这里小小打一下广告，大神们需要场地或者团购演出，请求给个机会~）。

除了活动外，我们做得比较多的是微信及社群运营，朋友圈活动（一些比较新奇的玩法技巧），低价抢购等。

# 三、 项目存在的问题以及潜在风险和对应门槛

# **1. 项目存在问题**

+   ① 资金问题

建剧场前期所需资金比较大，售票渠道基本是隔月提现，因此容易造成后续演出回笼资金跟不上，如果出现断档就容易导致剧场营收产生问题。

+   ② 文化管控

有些地方对于语言类演出管控比较严谨，在一些重要节日会暂停演出，如果是地方，语言类演出暂停需要有预备方案；如果是俱乐部，需要找一些限制没那么多的地方进行演出。

甚至转换为课程之类，或者增加一些社交体验活动等。

+   ③ 同行恶性竞争
