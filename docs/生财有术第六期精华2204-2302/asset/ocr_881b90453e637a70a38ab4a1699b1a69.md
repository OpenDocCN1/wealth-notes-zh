# 想和大家说

这里还是得再强调一下晓文老师说的：

每一个项目，其实都有很多种玩法。每一位老师给你讲的都是已经跑通可行的；但是呢，生财里面那么多老师那么多玩法，我们可不要把各位老师的方法搞混了！混在一起可能就不管用了！我们只需认准了其中一位老师的玩法，就跟听话照做执行到底！（六脉神剑，先练好第一重！）

遇到问题了，先去航海手册和百问百答里面找答案，基本都有答案！千万别说你很少用百问百答，只要是有落地去认真实操的，肯定会遇到问题！你说你没问题，那就是最大的问题！而且在找答案的时候，还能看到“自以为是”而所忽略掉的关键问题，圈友和教练们都在里面有提到的，这可是宝典啊！

综上所述，找到其中一位老师的一种玩法，先贯彻执行到底，遇到问题就想尽办法去解决。

到现在，我依然记得一桥老师在直播中的金句：“想都是问题，干才有答案”。

这句话一直很应景，尤其是咱们在做项目的时候，不去想怎么躲避平台规则，只要我们坚持做、持续做、并且把发布的作品数量加大，这样我们可以用数量来换取更大的成功概率！
