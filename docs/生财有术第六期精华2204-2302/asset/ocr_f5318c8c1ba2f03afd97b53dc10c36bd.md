3）新主播第一天让主播有镜头感，快速适应镜头、熟悉基本的操作。（大部分新人刚开播会紧张，通常开始直播后一天内基本就会熟悉）

4）第二天教主播如何自行开播、下播、统计数据（要学会基本查看数据，当直播间一场直播同时在线人数不过 100 人时。要学会看流量来源，基本上正常数据一场流量的来源 90% 以上都是来源于直播广场）

# 3. 主播的复制

第一个主播的习惯很重要，因为第一个主播的行为，后来的主播都会模仿，如果第一个主播不能做一个好的标杆，那么后面主播就会出现很大的问题。

# 4. 主播的管理

# 1）定目标

直播时长！我们规定主播每天直播时间不能低于 5 个小时。这个直播形式，主要靠的刷礼物的人多，而不是那个大哥刷大礼物，直播时长最重要。所以务必要保证直播时长。

# 2）薪资结构（以下只作为参照）

+   形式一：0 底薪+奖金（20%）（奖金含直播时长奖励，达不到降低奖金比例）

+   形式二：固定底薪+奖金（15%）（底薪含直播时长奖励，达不到降低底薪）
