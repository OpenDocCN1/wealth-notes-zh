# 4.2 远期国内剧本杀市场空间有望实现两千亿元规模

市场成熟发展带来客户群体提升。据国家统计局及弗若斯特沙利文数据，2019年中国城镇人口8.5亿人，其中15-39岁人口占比约34%，估算长期水平下中国剧本杀目标受众{15-39岁人口}约3亿人。

假设线上剧本杀相关营收模式能够随着商业发展逐渐成熟，客户付费意愿提升，预计线上线下合计单次游玩价格能够达到200-300元范畴。

同时由于当前剧本杀行业仍然处于发展阶段，未来口碑效应和剧本杀的社会属性会吸引更多玩家群体，用户的渗透比率预期将会提升至30%至40%的范畴。

资本入局带来新发展机遇。借助线下厂牌和线上资本的良性互动，更多具有新鲜感和体验感的元素将会注入剧本杀的主题之中，客户的游玩次数将会有进一步的的提高，线上线下合计将能够达到5-7次。同时剧本杀可以实现和各个主题的联动，进一步拓展受众的规模。

剧本杀产业玩家群体数量以及付费能力都将得到提升，远期收入体量预计可达一千五至两千亿量级。当渗透比率为40%，单次消费价格250元，年均游玩6次的情况下，剧本杀市场规模将达到1800亿元。
