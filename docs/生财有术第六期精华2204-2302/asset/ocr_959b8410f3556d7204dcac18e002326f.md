比如，前几天有个圈友问题，如何进行原创视频混剪，因为有很多渠道方需要用原创视频发布到本地抖音宣传。那这个用户需求，基本上连锁或者加盟体系的用户都会有。

所以 RPA 工具方向很多：

+   - 微信批量群发、添加用户至企微等工具
- 抖音批量评论获取工具
- 电商竞品价格监控工具
- 等等

# ## 四、RPA + 新技术结合创新

这一块分享下 RPA + 新技术结合的，这块属于难度比较大，建议大家不要轻易尝试，因为失败的概率更大。

比如，5G + VR 让元宇宙或虚拟现实如此火热； 比如，AI + 直播让换脸直播成为可能； 比如，区块链 + 其他业务让 Web3 如此可期待；

新技术的结合，会让旧产业逐步变革。就像我们用的软件体验会越来越好一样，几十年前古董软件基本都消亡了。

那 RPA 和什么新技术结合会产生火花呢？比如：

+   - RPA + OCR：批量自动化图片转文字
- RPA + 音视频转文字：批量自动化音视频转文字
- RPA + 机器学习：通过自动捕获新发布的评论数据 -> 机器学习处理数据以及生成用户友好的数据图形来加速分析并提供清晰、可操作的报表等
- 等等
