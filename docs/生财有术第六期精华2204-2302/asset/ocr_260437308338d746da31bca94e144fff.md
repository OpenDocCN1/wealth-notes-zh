# （5）理解运营的思路

这边我附上一张我写的运营思路思维导图，电商平台的运营思路都差不多的，哪个板块缺了就在哪个板块想办法优化，流量比同行低了那就想办法优化产品链接，转化率低就可以适当补单，刷些好评等。

当然再好的运营方法，没有选对合适的产品也是不行的；选对合适的产品，但是没有比较强的价格优势也是不容易做出爆品的！
