# 二 普通人辞职的路径及方法

我们都是普通人，成长路径无非是好好学习，考上大学，毕业找个好工作，凭借自己努力，升职加薪跳槽，买房买车成家，然后换更大的房子，更好的车.....

有了孩子也是希望，不要输在起跑线上，从小学甚至幼儿园就开始内卷，然后重复我们的路。

这没什么不对，毕竟大多数人都是这样度过的。但可悲的是仅靠打工，根本无法真正致富，很难实现财务自由。

打工的本质就是在，出卖你的时间和体力换取收入，你永远不敢停下来，因为手停口停，甚至担心哪天被裁员。所以不敢辞职的原因其实是：只有工资一条主要收入渠道！

所谓副业刚需，人生永远要给自己留一个Plan B，就是让你有随时说不的权力。想有底气的辞职，转换人生赛道，以下三个经验供你参考。
