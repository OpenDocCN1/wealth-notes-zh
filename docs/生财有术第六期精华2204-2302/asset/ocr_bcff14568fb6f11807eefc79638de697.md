①不是你说自己是谁就是谁，用户觉得你是谁才是谁。你给别人的印象就是一个知识分子，那么你输出的内容就不要充满市井气息。

迎合用户，才能加强自己在用户心智里的标签感，有了标签感，用户有需求的时候才能想起你。

②个人 IP 不能一下子做出来，而是一点点通过内容经营出来的，你一定要有这个认知。做出来的个人 IP 是没有核心价值的，没有核心价值你怎么做交付？

# 3、构成个人IP 的 3大要素是什么？

①核心价值

怎样用内容来体现你的核心价值？

倒推法：你要赚钱→需要有一个产品→你要把产品卖出去→这个产品对用户有什么用？

举例：正蓝需要赚钱，那我就需要有一个产品，我的产品是玩赚新媒知识星球，这个星球可以帮助用户通过自媒体赚到钱的。

以上就是一个简单的推导过程，无论你想通过什么赚钱，你的产品是什么，都可以用这个推倒过程，把自己要输出的内容搞清楚。
