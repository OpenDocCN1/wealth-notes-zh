# ## 二、培训后端交付体系

根据我对“培训的交付性”的理解，我列举了5个最重要的组成部分，分别是课程、微信群优秀学员分享、直播连麦辅导和保姆式解决问题。我团队目前全部执行了这5个部分。

一个基础的项目培训交付体系，最少要包含下面罗列的1和2。目前市面上大多数是只有1，其他的4点都是缺乏的。你们带队培训的时候，自行做加法或者减法，根据自身实际情况来。

> > 新手做培训，不一定我这5点全部要做到，但是如果你真的全部都做到了，并且项目也是跑通了，那么项目交付水平起码也是95分了。
