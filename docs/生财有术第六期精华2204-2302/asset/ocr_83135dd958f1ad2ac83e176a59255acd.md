# 项目流程

# 赚钱步骤

注意：

1. 需要快手急速版新用户即可（不限制快手新老用户，必须快手急速新用户）

2. 至少看7篇快手急速视频。获得金币，签到

3. 必须走二维码下载，然后默认邀请注册，或者填写二维码扫码出来的邀请码。

扫码其中一个链接，建议截图保存，以防忘记，如果没添加成功就在APP添加邀请码

# 步骤一

1. 微信扫描记录邀请码，然后下载，打开软件，手机号一键登录，默认邀请绑定成功截图（没有的话去软件里面填写邀请码后截图都可以）没有默认邀请绑定成功的，自己在软件里面填写扫码出来的邀请码，必须绑定的

# 步骤二
