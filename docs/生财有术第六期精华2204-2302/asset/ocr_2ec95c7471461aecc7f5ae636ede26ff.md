# ①回复速度

闲鱼任意一个链接点进去下拉都可以看到24小时回复率，平均是多少时间回复客户的，你可以去看几个我想要多的店铺和我想要少的店铺，他们的回复时长做对比，数据好的店铺，回复时长都很快，回复的效率很高，而生生意不好的，动辄一小时、两小时。

为什么回复时长会重要，先从平台层面来说，我给你推流了，客户来找你了，你接不住，我怎么还放心把更多流量给你呢？

从经验上来说，如果客户过来，你秒回，有概率马上又给你推流量进来，如果你又是可以快速回复，马上又会给你几个，系统表现出的是在给你测试承压的状态，同时如果你是客户同样卖的很好的店铺，一家回你一家不回你，你会在哪家买？
