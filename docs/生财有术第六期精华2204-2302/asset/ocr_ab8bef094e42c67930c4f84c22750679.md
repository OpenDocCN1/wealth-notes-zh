# # ([精华帖](119赞)新人小白30天利用AI作画技巧，让我的作品快速变现的经验分享

作者： 饼公子

日期： 2022-12-12

哈喽~大家好，我是本次AI绘画入门航海的船员饼公子。毕业之后一直都在江西南昌的保险公司就职，主要是负责公司的某一条线产品管理和设计。

加入生财8个月，很幸运今年在11月读了天辉教练的精华帖，于是去链接天辉老师。在天辉老师的教导和指点下终于有了一点点小成绩。

目前是“智慧之星”星球的联合创始人，AI绘画关键词小群主讲人之一，接触AI绘画一个月，一周时间通过教学、关键词、定制画赚了小四位数，相比各位大佬的水平，还是略有不足，我相信能赚到第一块钱，那么未来有无限的机会。

随着航海一天天进行，我相信大家都已经对AI绘画有了尝试，最基础的出门槛都已经踏过了。渐渐的大家都从直接复制粘贴，开始转向对如何制作一个精美的图片和按照自己的想法出图的研究了。

那你有没有这样的疑问：提示词prompt（以下均称为提示词）到底应该怎么写才好？如何才能达到自己想要的结果？为啥人家写的可以出好看的图，我不能呢？今天就分享一下好的提示词基本的书写方式和如何改写。
