+   3. 其他国家的网站受惩罚（如熊猫算法）不会被“连坐”
4. 可根据受众地区单独优化促进
5. 不需要为每个国家和地区购买多个域名

缺点：

+   1. 每个网站有单独的 DA(即Domain Authority域名权重是Moz的提法)，全新网站需要重建 DA 。
2. 见效慢，一个新网站要重新被索引
3. 通常需要维护多个网站，增加开发托管维护成本

我们可以看到使用子域名是比较折衷的做法。在三者的比较中，它却显得最鸡肋。

# 2.1.4 多语言网站选择

多语言网站的选择通常是子域名 subdomains 和子目录 subdirectories。

# 2.1.4.1 多语言子域名网站

+   - 通常每种语言对应一个子域名网站，比如英文网站是 en.domain.com 中文网站是 zh.domain.com
- 这种比较适合公司有非常多网页的情况，如果单一的网站由于网页非常多影响爬虫索引，其他优缺点可以参考以上子域名的优缺点。

# 2.1.4.2 多语言子目录网站

+   - 通常每种语言对应一个子目录，比如英文网站对应子目录 www.domain.com/en 中文网站对应子目录 www.domain.com/zh
