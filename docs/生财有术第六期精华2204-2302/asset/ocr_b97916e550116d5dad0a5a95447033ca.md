# 线上剧本杀

线下剧本杀游戏面对面的模式社交性相对线上更强，适合大板块时间组局消遣，并提供配套道具和服饰，代入感极强。

同时，剧情复杂度和剧本质量普遍较高，能让玩家更好地融入剧情。另一方面，线下剧本杀的不足之处在于需要提前预约且时间空间人数均有限制，攒局有一定难度。

费用相对也较高，人均单次消费基本都要上百元。时间消耗也较长，一般每一场在3-4个小时。

# 线下剧本杀分为以下几个类型：

+   1）桌游版剧本杀：最大的特点是形式比较简易便捷，只需要桌椅和剧本卡片就可以开始游戏。

早期多在桌游吧进行，现在逐渐出现专门的剧本杀门店。桌游版剧本杀只需要根据剧本佩戴胸针以说明身份，并以卡片形式取证完成推理，玩家可以通过换装达到身临其境的效果，过足“戏精”瘾。
