
2. 商品审核：发布成功后商品进入选品池，等待小二审核，急的话可以直接把SKC发给小二催审。

3. 寄样：商品审核通过后，需要把实物寄给小二看，有时候会改成后台直接上传实物视频与图片，这个主要看小二和类目要求，如果小二太忙没时间看样品，也可能会免寄样的。

如收到寄样要求，可以直接在后台样品管理里按要求操作就好。

![](img/a50ad26370b1cd7f67818735c6f556a8_3642_1.png)

4. 核价：小二主要会参考同款商品以及亚马逊的价格，看在商家的供货价的基础上加上运费，能否比亚马逊热销款的价格低，如果小二觉得价格高了，会议价的，到时系统后台会收到议价消息。

5. 图片审核：Temu目前是最少5张最多10张主图+详情+sku图+可上传主图视频的形式，主图和sku图要求尽量不要有牛皮癣，我们主图基本放的都是干净的场景图，把商品介绍尽量放到详情里，然后图片里不能出现亚裔面孔，文字要求是英文的，计量单位要求必须有美制，可同时展示国际计量单位，如长度需用inch feet yard mile，重量需用pound oz，体积用gallon，温度用F等。

6. 申请备货：一般首批备货每个SPU申请个20-50个就行了，等商品卖起来后，如果动销好，后面申请备货的时候在多申请一点，这样比较稳妥，防止因为动销过差导致商品被平台下架。

下架后商品会被退回给商家，运费需要由商家自己承担，这是一个风险点，一定要注意！目前应该是产品连续7天无真实销售，会被清退。

7. 产品包装要求：刚开始的时候要求包装和说明书不能是纯中文，一定要有英文，后面可能是为了加快商家上品节奏，调整成了包装接受纯中文，非复杂操作的产品说明书也接受纯中文（需小二审核），所以，如果是日常使用的家居百货产品，国内中文版的货现在也都能直接上架。

但是我不太建议，毕竟后面平台正规化后，肯定还是会要求纯英文化的。另外像纺织品水洗唛、产品操作页面、产品操作提示音等影响消费者正常使用的位置的文字必须是英文的。

8. 配货入仓：按照自己申请的数量进行备货，然后在Temu后台中创建发货单，发货时填写好收货地址和收货信息，可以在后台直接预约快递上门取件，目前听说是一箱的由中通取件，超过一箱的是顺丰取件，邮费由拼多多承担。

## 4. 相关注意事项

- 1) 关于售后：目前我们做了2个多月了，还没有遇到过，问过几次小二，他们也没有明确的规则，只是说：非商品质量问题导致的售后损失，全部由平台承担。

那么相应的，如果是质量问题导致的损失，就是都由商家承担了。所以，一定要抓好品控，否则后面可能会出现较多的售后，导致较大的损失，而且目前Temu还支持90天内免费退货。

- 2) 关于供货价：目前平台是可以随时调整供货价的，如果商家不同意平台的议价，可能会被清退。

随着某个产品的类目的商家越来越多，会导致该相关产品的供货价也越来越低，毕竟你不报低了，总会有人往低报，这样产品的利润会越来越少，尤其是标品类的，太好比价了。

所以我们的重心是放在非标类的商品上，目前来看，非标类的议价会比较少，首次供货价审核过了后就都基本没议价过。

# 三、 如何打造出爆品

从上线到现在2个多月过去，Temu入驻的商家已多达几万个，sku数量也高达几十万个，而Temu又是供货的模式，这意味着平台上已经上了的款式，还想要高价给平台供货，是绝对不可能的。

之前我也跟小二聊过，他们会给商家预留10%左右的利润空间，对商家中报价超过1688同款比较多的，直接视为没有诚意，会减少跟这类商家的合作，就算选中，也会把供货价压到跟1688价格差不多甚至更低。

所以如果本身没有外贸产品，想要依靠去1688低价进货然后高价给Temu供货这种模式，会比较难，但并不意味着不能做，毕竟1688的价格都还可以谈，而且如果是稀缺商品，小二对价格把控的不会很严，很可能报一个相对1688较高的价格也能被选上。

此外，还有一些可以定制的类目，甚至是材质不一样的商品，小二都不太好比较价格。综上，想要在**Temu**上赚钱，选品将会成为重中之重，品的好坏直接决定了它会不会成为爆品。

## 那我们是如何打出一个最高日销近**5w**的爆品的呢？

首先，基于我们现有供应链体系，把所有有海外资质的厂家都筛选一遍，然后在有资质的厂家中，把所有有现成英文版包材的商品在筛选出来，在这些商品中优先选择：

- 1）工厂有现成直接能用的英文图片的商品，保证产品转化率以及最快的上品速度；
- 2）对起订量要求比较少，每个款式第一批只要拿货50/100个的，减少后续库存风险；
- 3）客单中上，而且产品价格相较于亚马逊的热卖价格带还有很大空间，意味着产品售价会有优势且利润会相对较高；
- 4）**Temu**上相关产品比较少，亚马逊上销量又不错的商品，意味着平台稀缺，供货价要求会没那么严，而且又有市场，前期只要选上可以躺着赚钱；
- 5）在北美有热度的品类，这个需要自己去搜索查资料。举个例子：比如最近马上要开始的世界杯，那相关周边产品会不会好卖？再比如假设是欧洲市场的话，是不是可以想到最近的能源危机，那冬天保暖类的产品会不会好卖？

把产品筛选出来后，我们前期报的供货价一般是成本的1.2～1.3倍，保证毛利率平均下来能有个25%左右，因为我们选的品基本是平台上相关产品比较少的，所以报价一般都能通过，如果是平台上已经铺了很多的产品，想要有这么高毛利率肯定是不太可能的。

到目前为止我们已经大概上了30来个产品。如果能基于这套方法，辅上10个以上的产品，那么大概率会出现1-2个卖的还好的小爆品的。

目前来看，Temu更倾向于与源头工厂，或者有稳定低价渠道的贸易商合作，以及本身就在做国外市场的跨境电商玩家，相对而言没任何优势的纯小白商家在Temu上会比较难生存，最后总结一下现阶段的Temu适合哪些人：

- 1) 本身就在做跨境，有跨境产品直接拿来就可以上架卖的。
- 2) 本身有跨境供应链，只需要稍微整合一下，就可以上架卖的。
- 3) 平时时间充足，可以自己去找1688/阿里国际站上不断找相关商品和厂家的。
- 4) 本身在做拼多多店铺的，现在平台对商品外包装并没有做强制英文要求，可以把自己的产品图稍微翻译一下就可以上架了。

# 一、 是什么？

无货源搬运已经出来这么多年了，基本概念就不用我讲了，所有自己不发货代发的都是无货源。

而且所有电商平台都存在着无货源，不用怀疑。

先给大家说几个问题，这么多年，我想大概也就是今年行业震动最为频繁。

- 1. 拼多多，淘宝，抖音都出了买家虚拟号，保护买家隐私，虽然拍单还能拍，但是买家收不到取货码短信，虚拟号也是有时间限制的，碰到意外情况过时间了根本联系不上买家；
- 2. 7，8月拼多多、抖店拍单都出了限制，拼多多限拍风控退款，抖店直接封橱窗；
- 3. 拍单软件基本上都没法玩了，大大增加了的原先没有的成本；
- 4. 而且拼多多现在所有单子都会给收件人发短信提醒，表明立场让不要被赚差价，直接就导致了拼多多货源的退货率直线上升，多出来太多麻烦；
- 5. 几个平台对无货源打压太严，比如抖店，明确了规则禁止无货源，动则违规罚保证金封店。

以上问题我会穿插在文章内讨论，大家看完帖子也就知道答案了。

一定要做店群，去多做店，数量越多越好，越越多越稳定，最起码要做5个以上的店铺，要用矩阵思维来对抗不确定性！

以上只是一般情况，并没有考虑到爆单。要知道短视频和直播都有爆的时候！达人每爆一次都是加餐，每个爆的利润都会有几万。我们每个月也都会碰到几次。

## 2. 为什么能挣钱

视频号后端为什么能挣钱，最根本的原因还是因为后端商品的缺乏。

是的，别看这半年进场这么多人，你以为卷了，其实还早呢，抖音都卷成这样了还能做无货源。视频号选品库整体依旧还是不够多不够丰富的，达人想带什么品在选品中心搜不到很正常。所以即使现在去做暴力铺品依旧能出单，不信你随便问个做过的人，出单多少的区别而已。

假如你现在进场，就走走暴力铺品就行，把量先铺上去，在做着的过程中再去优化。尤其是30号后只剩下小店了，商品内容最起码会减少一半以上，已经很保守的数据了。有打算做的要趁早进场了。

当然了，开视频号小店纯做后端的话，不自己带货的话，是必须要进优选联盟的，不然根本没有入口进店，自然也就没有任何流量了。只能通过优选联盟去展示自己的商品去通过达人获取流量。
