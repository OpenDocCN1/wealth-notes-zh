# 第三步：写课稿

当你把提纲列出来之后，接下来就是去填充课程的内容，导致很多人迟迟下不了笔的原因，无非以下几个。

+   1、没有应用原理

应用原理是串联，这节课中知识点的一个工具，你不把这个东西给它沉淀出来，那么你的知识点就会显得很零散，用户记不住就算记住了，也不知道怎么用。

而且应用原理可以起到一学员学完课程之后，想跟别人介绍推荐你的课程，总得用一句话让别人知道你这个课程的价值在哪吧！

+   2、没有具体案例

案例就是用来解释应用原理的，应用原理一定是抽象的，怎么把抽象的东西具象化，那么就需要一个，真实的营销案例。

这里需要注意一点，案例优先使用自己的，然后再使用和自己有关联的，比如你的学员或者会员。

不用自己的案例，真相只有一个那就是你还没有通过他赚到钱，所以你只能用别人的。

+   3、没有实操方法

原理逻辑给人讲清了，你还得把流程步骤给列出来，否则用户的感觉就是：你说的都对，但是对我有啥用處呢？
