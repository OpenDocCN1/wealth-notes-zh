# # 【保姆级教程】从零到一打造一个高质量交付的训练营

2020年11月5日，发了个帖子，预测说会有越来越多的机构做训练营。
并指出，一个可以切入这个机会的点是：做一套训练营的SOP。

我相信，这个需求，现在依然是存在的。
一套高质量的训练营SOP， 技能让有成功经验的人，能够更好的将经验复制给别人。
也可以让学员有着更好的学习体验。

去年，我和生财，用实战日的形式，合作开展了三期训练营，当时的反响非常不错，学习的学员，也产出了四篇龙珠贴。

后来，我也把这套训练营模式，尝试开展了其他项目的训练营。
实际测试出来，效果都还不错。

今天，我把做训练营的思路，尽可能详细的写在这篇帖子里。
希望能帮更多有成功经验，想做好交付的圈友，打造出自己的训练营产品。

# # 也能希望借此，间接帮到更多想做项目的圈友，成功跨出搞钱第一步。
