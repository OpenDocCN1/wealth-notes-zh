# 2、抖音、巨量学官方培训（适合公司运作）

介绍：巨量学是巨量引擎（字节）旗下专注于短视频、直播、电商、广告营销领域的一站式数字化职业教育平台。针对从事短视频行业的人员提供各类专业化辅导及证书培训（学习、实战、认证、就业）等服务。

电商方向：店铺运营营销师

创意方向：内容创意营销师

运营方向：短视频运营、选品运营、直播运营、网络主播等营销师

广告方向：信息流广告、巨量千川、营销科学、搜索广告等营销师

机会：越来越多的短视频平台从业者、希望入局短视频平台的个人、借助短视频平台实现营销目标的企业，大多都是在市场上找第三方机构学习，割韭菜抱怨居多，而官方（字节旗下）的学习平台推广并未真正完全普及。

重点：围绕官方（学习、实战、认证、就业）平台进行线上、线下学习培训。
