# 代持风险的解决方案

刘先生31岁，和银行的理财经理认识2年，银行资产100万，过往主要做大存单和短期理财，保险专家陪同面谈时，理财经理发现自己并不知不道自己为了什么销售客户。客户主动向专家提到，自己从大学就开始创业，目前经营着三家企业，但都不在他名下，他的父母还代持了大量的现金资产。客户有一个姐姐，两个孩子很小，分别只有5岁和2岁。

这个客户要综合风险梳理，通过高杠杆寿险+长期年金+重疾，来解决三大问题：首先父母代持的100万现金可以部分回到自己手里，购买寿险及年金，继续代持的部分签订代持有协议；企业经营情况不确定，孩子未来十年婚的教育费用，需要安全持续的现金流，通过年金保险来解决；客户作为家庭唯一的经济支柱，还需要考虑万一发生重疾或者身故，对家庭收入来源的影响，因此配置100万重疾险以及800万的寿险。

推荐保险产品组合
投保人：刘先生 被保人：刘先生
受益人：两个孩子及妻子
保障一：5年年交，100万年交保险年金保险 保障二：100万重疾健康险（免体检）
保障三：5年年交，600万保险终身寿险
方案：终身寿险及年金做转入信托

# 基金盈利50%以上的客户不满保险收益如何促成

M先生32岁，是一家外企的中层管理，年薪50万。由于业务往来关系，M先生觉得能结交一些投资方而相当有心得的客户。于是从今年起开始尝试基金投资，并在几个月内盈利50%以上，理财经理觉得M先生的资金适合90%在亏损期可以及基金里，不太科学，建议他配置一些中长期稳健的年金保险，客户嫌收益太低。M先生父母生身体均时间较早，母亲刚退休，父亲仍在工作。

对于客户来说，所有风险点都是我们可谈的，稳动了客户。如加上刚才说到的收益偏好良好的保险产品本身就比较顺应成长客户不太担心收益。于是，我们从客户心理转变处去切去帮客户认知到风险的可性，第一，基金收益好，现在不跌的，投资还有风险，我们都预测出他们什么时候考虑退出，客户经常觉得过几个月就能打回本甚至下一波，此时他觉得可能只是接受损失。在不确定的将来会有打算风险。第二，客户感觉自己现在生活周围区域父母都有压力，预计比他会到20年后，现有资产或增加如果发生变化，需要花掉地方多更多，他意识到计划需做出多必要的。

推荐投联寿险
投保人：M先生 被保人：M先生
受益人：M先生的父母
产品方案：20年*10年增额寿险
将来可增长为假设500万的身价保证或养老现金流
如果M先生成家以后，还可变更受益人为太太或者孩子
