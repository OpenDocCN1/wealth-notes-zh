# 三、为什么我会做工业品

+   - 客户复购率高：目前在1688上的复购率基本都是在20%以上。

![](bbox=[0.15, 0.14, 0.88, 0.3])

+   - 客户积累：疫情原因，很多地方的生意都下滑了，但是义乌市上半年进出口总额达2222.5亿元，同比增长32.8%，很多客户都来不了，为什么生意还能火爆，这就是客户积累的力量。

+   - 竞争者五花八门：很少出现一个大鳄能垄断整个行业的。

厂家有厂家的优势，经销商有经销商的优势，谁也别想把谁干掉。

我曾经给竞争对手店铺导流一万多个访客一天，也没有把竞争对手打下去。

我星球里面一个圈友，她也不是工厂，一单4080，含泪赚了3000多。
