# # 一个打新套利者，忙碌的一天

2019.1 猎人笔记 2019.1.5.6.2555

今天忽然发现，作为一个打新+套利的羊毛党，一天下来还是很忙碌的。

# ## 12:30-13:00 证券分级溢价套利

每天中午还有一个项目，就是证券分级的套利。一个分级基金能够持续溢价这么久，我也是服气的。

每天中午，先把前一天申购的盲拆掉，然后看看溢价率情况，再继续申购。

正常是应该下午2:30后再检查溢价率，然后决定是否申购的。不过分拆的时候既然打开了账户，就顺便把申购也做了吧。

万一2:30以后有其他事情，没有时间处理分拆呢。

虽然现在分级基金不存在了，但是这种积少成多的基金套利机会还是会持续存在的，比如挂钩原油的一些油气类基金，像华宝油气、南方原油等，再比如挂钩港美股的一些 QDII 基金，像纳指 LOF，标普科技 LOF 等。
