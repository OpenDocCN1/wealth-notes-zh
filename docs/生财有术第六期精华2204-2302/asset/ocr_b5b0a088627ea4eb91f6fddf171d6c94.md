虽然目前全国各地政府为了争取到更多的纳税收入，很多地区都给出了相应的税收优惠，但是有一些地方政府在实际的操作中做不到向企业承诺的税收优惠政策，或者对于优惠政策打了折扣，这就造成了灵活用工服务商的极大风险，从而牵连到服务商所服务的企业。

比如江西某地就发生过很多这样的问题，所以服务商选用的是什么地区的税收洼地就很重要了。

另外，不同的税收洼地对于企业所处的行业和灵活用工的工种有特定要求，所以企业要根据自身的实际财务需求去匹配相应的税收洼地，从而选择相应的服务商。

# 2. 平台体量角度

目前不同灵活用工服务商的体量存在比较大的差异，并不是大体量服务商就一定 是最好的。还是要根据企业自身体量去进行匹配。

如果企业自身体量并不是特别巨大的情况下，原则上并不建议去找大体量服务商进行合作。

一是大服务商因为体量问题，本身就一直在监管部门注意之下，可操作空间比较小，同时比较频繁地被稽查，对于一些企业的业务开展不是特别有利；

二是大服务商对于体量并不特别巨大的客户服务度和关注度不够，甚至干脆就不接体量一般的企业客户。

我更建议大家选择具有一定经验、体量并不太大但是安全可靠的服务商。
