# 二、玩法拆解

## 1.如何去确定以及规避哪些类目

A. 做店我们首先要明白怎么样跨出第一步，第一步就是怎么样让店铺获取流量，没流量的店铺那肯定是产生不了盈利的，首先看我们的主题就应该比较清晰明了。

咱们不依靠主流的补单玩法，因为我感觉对抗平台规则偏黑一点，而且平台规则在一直不断的完善中，越早的熟悉顺应平台规则才是主流，流量分两块，达人和自然流量。

我们今天获得的全部是自然流量，自然流量又分多种，其中包含就有搜索流量和推荐流量两大块。有心者应该可以看到，抖音商城主页也有拍照搜同款这一项了，那就意味着搜索端的截流，是在不补单的情况下现有的最快获得流量的方法。

B. 当我们知道抖音给予流量的途径之后，那我们就需要去确定一条赛道，去扎进去，去探索。

当然我们也不能盲目的去随便选择，现在这个年头，依靠大数据就可以帮我们解决很多问题，一个不会看数据的运营，和客服没什么两样的。

下面我就放张图片，给大家看下如何依靠抖店后台找到现在季节有流量的词和类目。

如果你是这种品或者品里面包含这种词都可以获得流量，或者商品包含这个词通过搜索是可以进行展现的，我们可以根据季节搭配后面的这个分析，来去确定我们的类目。

我们半个月前做的文具类目，在8～9月份临近开学得时候，搜索流量是最大得，做的有很多细分词，比如笔记本，笔袋。店铺品类单一，但是成交几乎全是搜索流量如下图：

## 2.选品和上品以及定价

A.当我们懂了上面的思路之后，我们就可以开始第一步【选品】，店铺能不能出单最重要的一点还是看自己选品能力如何，我们选品可以跟进两大平台，分别为抖音和拼多多。

先说第一个平台【抖音】，此时的选品思路我们要去契合直播中的，达人购物袋中的商品。

比如你确定做一个手机壳类目。那我们就可以去直播间去挑选款式，这种直播间我们可以通过软件去找到。

![](img/a50ad26370b1cd7f67818735c6f556a8_2606_0.png)

通过搜索之后，我们就可以看到很多近期卖的比较爆的款式，以及可以去分析新品趋势。

B.第二个选品平台是【拼多多】，直接通过搜索关键词（手机壳）去搜索即可。这个不做细讲哈，这时候大家就会有疑问，选品大家都会，那么我们的如果选到之后直接上架，货源去哪里找，抖音不行，拼多多拍了退款，这是最近我很多的朋友咨询我的问题，答案是【陶特】。

整个流程就是，选到你想上要的品之后，通过搜图，搜同款，去陶特里面包吧同款链接复制下来，然后通过上品软件去上架就行，因为服务市场上面的软件受淘宝的影响都不可以上架淘宝类的品类，所以只能通过外部软件上架。

![](img/a50ad26370b1cd7f67818735c6f556a8_2607_0.png)

复制和识别依靠软件即可，把你精心选择的品找到，复制上传即可。

C.回到最开始我们有说过不补单这一个问题，那么不补单，有没有销量，所以我们只能靠价格和内容。

当我们在选品阶段，已经把内容做好之后剩下的就是价格了，我这边是把价格定价为3倍上架，利用新人折扣券最终的成交价比成本价亏10%~20%左右。

毕竟我们需要去盈利，如果亏得很多，我们价格纠正的会很慢。店铺稳定后我们正常出单的盈利点为25~35%。

# 商品访客数趋势

![](img/a50ad26370b1cd7f67818735c6f556a8_2608_0.png)

当你的今天访客明显比昨天高的时候就可以把后台的折扣券，由2.9变为3.2折了。频率为一天最多调两次，一次+0.3折。加到你心里的利润空间为止。

因为用户心里有一杆秤，他知道这个品，什么价位买来合适，什么价位买来不合适，所以调整过之后，要看未来几个小时的变化。

如果访客逐渐往下减少30%左右，是没问题的，如果直接没流量或者直接降了70%，这个时候可以把价格适当的再去回调折扣到3折。让抖音慢慢的帮你调整价格带人群。

上品我们是如果是精选品的话，我们会上到总共上300-600个品左右，连续三天，每天上100-200个新品，去测品。不建议走大范围铺货模式，毕竟现在抖音查的严格。

## 4.售后问题以及体验分问题

A.售后问题以正常的无货源模式走售后就行，新手不明白可以咨询我，主要是体验分问题。一定会有一个疑问，比如【我们不补单，万一后台出现了差评，中评，没有好评支撑可以吗，那体验分不直线下降】，以图为例：

![](img/a50ad26370b1cd7f67818735c6f556a8_2609_0.png)

中差评非常多，占15%左右，但是评分却一直降不下去，因为这些买家都是真实买家，并不是我们人工干预刷的，之前我们做补单的时候，先大量的刷好评，然后再去自然出单，结果一个差评就给干到3点几分。

因为他们权重不高，所以才会出现如此问题。当然大家也不能不重视这个问题，尽可能的维护售后可以让店铺流量持久的曝光。
