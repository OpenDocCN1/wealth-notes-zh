# 祝您躺着把钱赚了

配图为来源网络

一个能躺着的项目意味着什么？意味着你的价值生产，完成以后，收入能持续产生，你的时间可以腾出来开拓更多的收益项目，你有更多的时间可以思考、学习。

我在失败经验汇总宝典里看到有人给 @郭晓文 说过一句话，怎样能把项目做成？如果说有人每个月定时转你5万给你花销、生活，你就能把项目做成。

这很显然，根据统计学，如果有条件给你做无数次的情况下，你只需要1次成功，那是大概率出现的。

但从来找给我们5万一个月的人？不是每个人都那么会投胎。

没关系，我们可以自己给自己。

自己给自己？没开玩笑吧？啥叫自己给自己？

“昨天的我”给“今天的我”。

“昨天的项目收益”给“今天的我”。

这就是躺赚项目的好处。

有这样的项目，可以支撑你以后做任何，你想做的事情。
