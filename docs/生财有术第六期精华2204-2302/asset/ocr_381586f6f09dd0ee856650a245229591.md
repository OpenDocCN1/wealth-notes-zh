# 一、从“定位”三要素角度分析

+   1. 擅长：自身一技之长的放大器

+   2. 喜欢：当你喜欢一样事物，就更愿意花时间去研究，更容易出结果，快速启动或许你自己都‌不知道的“天赋领域”

+   3. 适合平台的特质，符合“短视频”的呈现形式

当不知道做什么领域，可以从自己喜欢和擅长的入手，这样能保证持续输出内容；有真实的体验，懂得消费者心理，创作内容更容易获得正反馈。

目标是做到**在用户心智中与众不同**，魔术这个类目一听名字就特别，加上独特的展现，耳目一新很难不引人注意，这就实现了短视频的第一步——**吸引停留**

+   1. 稀缺性
