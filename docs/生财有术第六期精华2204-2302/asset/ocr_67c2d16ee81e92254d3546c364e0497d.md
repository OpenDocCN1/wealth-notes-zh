# 3、招聘软件（boss直聘、实习僧、青团社）

圈友们可以去注册招聘账号，去针对大学生发布校内线上兼职，在上面咱们可以根据学历、专业，去筛选艺术设计类的大学生，这种专业的学生一般都是美术生，有一定的审美基础和设计能力，稍微培训下就可以用。缺点便是需要有几天的招聘周期，没有QQ群反馈的及时，而且通常要给软件付几百的会员费~

这三种方式，大家可以自行选用~
