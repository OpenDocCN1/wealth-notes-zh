# 三、 梳理流程 团队入场

# 1、 在平台上搞钱一定要注意吃相

1） 新平台，没有前人经验借鉴，最重要的不是选品运营，而是了解平台规则，很多人不喜欢这种枯燥无趣的文字，花了大概两天的时间，把美团电商的所有规则仔细研读了一遍，对于平台有了一个大致的了解，记得之前刷到的抖音强势文化图文号里面有句话非常好，平台规则内的事情大胆放心干，规则外的事情计算好投产往死里干；举个小例子，譬如平台的超时发货订单只有30%进行处罚剩下70%警告，在没有做特殊履约报备的情况下最高的一家店一个月只处罚了210元，在当下的店铺单产和操作难度下，你品。

2） 划重点，做美团一定要关注新航路评分：这是一个类似淘系灯塔的评分体系，不过美团的处罚更苛刻，连续低于三分的店铺3-6个月会被清退。从三分钟回复率、到发货时效、再到售后完结、平台介入率等等，各平台大同小异，换汤不换药，像极了那年暑假闷在寝室抄同学作业的我。
