- 1) 低价送福利，比如福袋抽奖，有送抖币的也有送衣服商品实物的

- ①引流品（低价）
- ②承接品（中等价格）

# 七、容易踩的坑

抖店招商的是非常适合小白做的电商项目，它的逻辑很简单，你自己把自己抖店里面的商品开好佣金后，挂在精选联盟里面，然后去找抖音里面的达人给你带货，达人赚佣金，商家赚利润，不管你是做无货源还是自己的货，都是最简单最容易出单的。

做达人招商最容易踩的坑也有很多，字在这里帮大家总结一下我们刚开始做抖店招商的时候亏了6W多经验，能帮大家省钱。

## 1. 定价的问题

抖音小店的商品售价计算公式如下：

售价=供货价 + 快递费 + 毛利 + 达人佣金 + 平台服务费 + 运费险

- ①平台服务费：开店的前一个月是技术服务费是1%，过了一个月后就会恢复，不管你有没有过新单期。

- ②毛利率：计算售价时毛利率最低标准是10%，千万别低于10%去跑，这是一个保本线，去年11月份我们就是因为踩了这个坑这个大概亏了有3W多。

去年11月份你们推爆了一款儿童裤子，为了和同行抢主播，我们就把利润降到了8%左右，忽略了退货运费和货品损耗的问题，结果每单亏了大概3块钱左右，我们店铺每天光这个单品跑了大概2000多单，大概跑了5天左右，亏损了3W多，大家一定要记住不要再踩坑了。

- ③运费险：在计算运费险的时候一定要按照最高标准去算，因为运费险是根据你店铺的退货率去调整的，不是固定的。

- ④售价：我们商品的售价和佣金一定要根据选品广场中同行的数据去定，不过一定要记住千万别打价格战。

## 2. 找达人的问题

刚开始做的时候因为忽略了我们商品客单价、着急出单，就降低了找达人的标准，在邀约达人的时候只要她发地址就给她寄样，因为我们是做童装的，平均客单价在40左右，不到一周大概寄了有1W多块钱的样品出去，结果就出了十几单。

有很多主播都是来白嫖样品的，他们收到样品的时候要么不回复，要么就会拉黑你，所以大家在找达人的时候一定不要降低标准，要多去了解一些关于直播和产品的知识，要学会降维打击，跟达人聊天的时候一定不要当舔狗，要学会依赖一群主播，而不是一个。

## 3. 选品问题

达人的换品节奏很快，基本上一个品最长的周期大概在2周左右，也就是说一个品在达人的直播间不会待过2周左右。

为了保证我们店铺有持续稳定的单量，我们必须要保证我们寄样品的速度要跟得上达人换品的速度，在达人换品之前一定要保证新的样品已经到达人的手里，一定要算好时间成本。
