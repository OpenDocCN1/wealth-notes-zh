# 四、行业空间测算

# 4.1 瞄准都市中青年群体，中国剧本杀行业增长迅速

❮ 据艾媒数据中心的资料，2021年中国剧本杀市场和2021年中国密室市场规模分别能够达到约170.2亿元和101.2亿元。

玩家以初入职场的年轻群体和事业稳固的中年群体为主。玩家更多的选择剧本杀作为休闲娱乐、解压以及社交方式，其扮演、推理、悬疑、社交的属性切中都市人群，需求和门店的互动增长将进一步抬高未来市场规模。

❮ 随着市场规模化以及线下门店规模和内容的全民化，预期未来除了剧本杀、密室逃脱之外，也将有其他沉浸式或其他社交属性的元素整合，一站式“麦赋”会馆将会更多的出现。我们预期，整体市场规模预期能够在2022年远超360亿元。
