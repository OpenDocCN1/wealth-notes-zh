涌入人**群越来越多**，为了走到最后，**11月初**我就进行流程化管理，记录账号每次微调动作。将原作品类进行迭代进新的知识库，对细分类目进行迭代升级，将学习的技能、实操进行记录。

也庆幸双十一买了两台笔记本，加上流程化管理，现在已经有了**记录文档**，防止知识流失的习惯；周末录制实操视频，编写实操文档，手把手教学之后，终于将重复性动作剥离出去。我把控选品，老婆进行**选择、下载、上传视频**。后续经历全国哀悼，审核问题之后，又新增记录当日各账号播放情况表格。
