2022年，我如何使用生财有术？

+   1、发帖，分享干货，实现知识与创业的链接，制造创业兵器库。今年发帖总数量为【21】篇长文，【3】篇移入茶馆，累计15万字，参与3次航海项目、写了【3】篇作业帖：累计辅导圈友的创业企业10家，给姐夫罗律师输送圈友案件50+【未完全统计、包含办结与启动项目】；1-7月累计为圈友提供1000+免费轻咨询、8-12月提供百来个收费咨询【交个朋友价】。延续惯例，给我辅导的优秀创业者送出2张门票，并辅导创业者使用生财有术发帖。

+   2、写书/发售新书，编辑干货，实现创业与外界的互联，出版创业十日谈。今年由圈友@滕腾引荐法律出版社优质编辑老师，顺利出版处女作，并由亦仁、等星球圈友联络推荐，等星球嘉宾写序、推荐，并受到500+圈友在朋友圈、视频号、抖音等渠道挂车推荐，最终也于11月实现加印，入选《中国出版传媒商报》10月好书（财经类）推荐；并且，在年底，终于配套书出了第一套【法财税人·理论课】。圈友还帮我实现5个城市开签售会，深圳/武汉/桂林/北京/惠州顺利收官，期待广州与杭州签售会。书也上了嘉宾@Caoz和冯大辉@Fenng的直播间推荐。

+   3、夜话/日话，输出/输入干货，实现知识与应用的结合，生产商业合作。今年在大湾区发起了2场广州夜话、多场深圳夜话，大湾区的百来创业者参与并贡献了诸多想法，也链接了不少创业者，有些专注做赚钱的生意，有些已经开始爬坡、思考如何成为创业者，还有一些在向企业家转型。其中，结识了不少跨境电商朋友，如自称小透明的跨境玩家媛媛、Jacky和她可爱的女儿，冷雨夜驱车数百公里送我回深圳又返回广州的优秀创业者阿文。我也为离开大湾区创业的圈友送行。
