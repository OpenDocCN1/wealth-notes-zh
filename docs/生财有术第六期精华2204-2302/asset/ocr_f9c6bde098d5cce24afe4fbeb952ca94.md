# 闲鱼小技巧**5**：素材来源

小红书，电商平台评论区，闲鱼同行复制（用存图宝自动去水印），实拍（效果最好，避免同质化）。

我们做投影素材怎么解决的，通过小红书去搜投影仪，会出来很多素材，也可以通过咸鱼复制同行的爆款图片，去下水印，改一下**MD5**值（咸鱼最近9月份出现盗图的举报，有团队专门干举报这些事情，不只是投影遇到，其他类目的朋友也反馈有遇到很多举报盗图的，举报售假的）。

有拍摄功底的最好就是实拍，这样别人盗你的就举报，出你拍的图的爆款了你就是全网独一无二。
