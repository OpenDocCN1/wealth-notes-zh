# 7. 新人想做的一些门槛和建议？

新人做这件事的门槛，无非就是两件事：没有汽车资源，没有客户资源。

那么上面已经说过如何解决车源和客源的问题了。

对待客户态度要好，一定要维护好老客户的关系，老客户转介绍要比开发新客户的成功率高很多。

如果你想无成本做这件事的话，可以跟你当地的二级经销商合作（高德地图搜“汽贸”），请他们吃饭，向他们请教，同行不是竞争对手，而是合作伙伴，当地的汽车资源他们是可以跟你共享的，保险和贷款可以从他们店里走，毕竟你用的人家的资源，最好给他们一些分成。

在有一些行业经验积累之后，这个时候你可能已经跃跃欲试准备自己单干了，不用租很大的门店，有个地址办个营业执照就可以。

然后要跟银行签订汽车贷款协议，谈好返点，这里插一句，我们有个同行现在已经不卖车了，他专门给江苏省各城市的大小二级经销商做车贷，邮储银行跟他谈的条件是一年车贷放款1个亿，银行返100万。很多行业都能赚到钱的。

汽贸的门槛很低，不一定要卖车的，还可以尝试做汽车自媒体，不一定要靠卖车赚钱，接广告，也有很不错的收入。

有转型的同行现在百万粉丝广告报价是5位数了，一个月能接3-5条。想想你刷到过的汽车类视频，有多少博主是专业的呢？如果你不愿意视频出镜，这条路不要走，你走不通。

这里说句中肯的话，要有积累才有收获。千里之行，始于足下。

# 8. 目前遇到的一些问题：

- 汽车销售是有淡旺季的，不会每个月都能好的销量。淡季的时候4S店的价格也会优惠更多，在价格相差不大的情况下，客户还是更倾向于直接在4S店购买。懂车帝等app上车主晒成交价，也让价格越来越透明。
- 更多的客户还是来自于我们同城的，与此同时也面临来自同城更多二级经销商的恶意竞争，打价格战损人也不利己。不是只有我们做抖音和小红书的引流的，同行看到也都跟上了也在做了。
- 服务：汽车销售行业的标杆当属「豪车毒」，但是对于我们的客户来说，给他们省钱能更优惠的提车其实更重要，这也就让我们没有更多的利润可以提供更多的后续服务了。
- 你所在城市的商业中心，比如万象城、万达广场等商业中心的一楼现在是不是能看到很多门店都摆放着展车。逛街顺便定一辆车，已经很正常的一件事。**4S店**有资金扩张这类门店，也有足够人员可以安排接待讲解，一个小小的二网没有这种体量的。
- 新能源汽车行业已经高速发展，用户坐在家里，就可以直接在他们的官网下定一台车，绕过了我们这些中间商，他们提车的店也不再叫做**4S店**，而是叫做交付中心。如果未来更多车企选择这种模式，我现在想不出来二网该怎么生存。

# 9. 最后，说几点我对于这个行业的一些思考

我试过是不是可以推出这样一个平台：

- 这个平台涵盖了畅销车的主流车型，客户在这个平台上预定，会比在官网预定更优惠（这里说一点：肯定是可以比在官网预定更优惠的，至少保险返点这一块就可以让利给客户），同时客户自己的信息在官网也是可查的。
- 对于传统燃油车，车企还没有开始流行在官网预定，那个时候我们平台可以推出在线预定燃油车和新能源汽车甚至是近期流行的机车，再附加一些服务，比如礼盒送车到家。
- 另外这个平台还需要加入在线远程办理车贷，以及可以参与汽车分销，在合规的情况下人人都可以做分销。
- 在节省人工的情况下，可以直接跟全国各地现有的**4S店**或者二级经销商合作，哪里的客户就在哪里交付提车。

# 二、视频剪辑

这个玩法对于视频剪辑要求不高，用手机电脑都可以剪辑。

剪辑的常规思路，就是把原素材的冗余镜头裁掉，把时间压缩到三分钟左右就行。

太长了会显得文案过于啰嗦，不利于在抖音的传播，但是也别太短，影响中视频收益的单价。

剪辑的实操视频上传不了，大概操作是剪辑冗长的镜头，加转场、滤镜、水印、抽帧，变速。

（剪辑去重演示）

关于手机剪辑，我们需要注意是镜头转换之间的细节处理，尽量避免出现冗余镜头和跳帧，提升视频画面的流畅性。
