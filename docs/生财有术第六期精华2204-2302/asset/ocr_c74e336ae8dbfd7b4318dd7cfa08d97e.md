给用户贴上标签、让观众看到他喜欢看、想看的内容；给客户贴上标签，让买家买到他喜欢的、需要的商品。

所以，一个靠平台喂流量的店铺，一定要知道平台为什么给你流量。

这其实也是为什么我觉得玩抖音不应该用传统起店方式操作的原因。因为除非你的人群资源账号标签和你的商品匹配，否则就是在打乱抖店对商品所匹配买家标签的判断（抖音的稽查算法也可以依靠买家的账号标签来判断是否违规）。

这同时也是为什么传统起店方式有时也可以起店的原因，因为资源的人群标签刚好匹配商品的买家标签，这就成了概率性事件。

为什么我不建议玩无货源抖店做百货，因为百货人群标签太杂了，很难控制。

而细分类目的商品曝光给精准需求的人群，转化率一定是最高的。

关于店铺的上品类目，我的建议是：前期允许泛，但一定是越来越垂直的，越垂直，店铺的标签越集中，曝光的人群越精准，转化率就会越高。

这里推荐几个类目，因为这几个月类目对应的人群标签比较集中，同时因为上架资质原因，竞争小，新品流量就会更多，更容易出单。

+   ①美妆个护（国产普货需要电子备案和包装标签图）

+   ②玩具乐器（需要 3C 认证资质）

+   ③时尚饰品（最近刚免费开放的类目，之前需要报白）

除此之外肯定还有很多其他竞争小的细分赛道，有尝到甜头的圈友也可以互相交流一下。
