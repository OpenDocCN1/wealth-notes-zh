因为达人或者达人的商务每天都会有很多的供应商找他们合作，只要是个中部或者腰部主播，大家都会疯狂去舔主播免费给主播寄样，为了抢主播，就会给主播养成那种拿样品不回复的习惯，播不播都是主播说了算。

3. 要地址，登记达人、所寄样品信息以及快递单号

寄出样品之后一定要把单号和所寄样品的信息以微信消息等形式发给达人，打电话让达人确认，收到达人回复的确认信息之后，就可以把样品寄出去了。

4. 提醒达人收样品

估算好快递到的时间，提前在日程表里登记好，快递到目的地的时候需要打电话去问达人有没有取到样品，如果长时间不取样品，容易出现样品丢失。

5. 给达人发商品的介绍卡，跟达人确定好开播时间，如果不能开播要问清楚原因，给达人换样品，然后把退货地址发给达人，让达人把样品寄回来，寄到付。

介绍卡里要包括商品的详细介绍、卖点、发货时间、库存、价格、佣金和链接等信息。

6. 在达人开播之前检查商品链接是否做好的，检查商品价格、库存、佣金、发货时间、主图等是否正确，在开播之前再发一遍给达人。
