# 三、投影仪类目玩法

## 1.进入流量前

### 1）铺量玩法

普通号上满50个链接做轮动，小铺号上满500个链接做轮动，每天上3-10个，稳定上新就可以，一个链接最少给500-1500的曝光，也会有固定的浏览和咨询，客户找你的会很多。

但这种玩法就不一定会成交，过来的流量很泛，自提和奇葩客户居多，简单来说，流量不精准，系统检测到你在做事情，为了留住你继续在这个平台活跃，给你点信心，给你灌一堆机器人流量勾引你。

解决方法：做轮动上新以外，选出数据不错的链接，把这些链接进行补单，补单你就会发现这个流量进来的多起来了，而且精准起来了。

简单来说就是人工引导系统给你精准的流量，你既保证了上新，让系统认为你在这个平台有粘性，又通过转化把标签。

### 2）精细化玩法

上一个链接补一个数据，做筛选，数据好的留，不好的下掉，保持在10个以内的数量就可以。比如我今天上新5个链接，每个链接我都做一下补单，让他从最普通的链接里有一个转化数据，稍微提升一下排名。

其中这些数据中会在同等上新时段里面有数据比较不错的链接突显出来，那个链接就是我们主要做的链接，可以去细致化的补单，观察这个链接的数据通过你的补单，他的曝光搭配浏览，搭配我想要是否是你想要的比例，如果靠近优质链接，那这个链接就可以着重去做为一个主推链接。

而这个链接起来后，别的链接会被带1-2个次新链接起来，在观察数据是否有优质的比例，选出次新链接重复主链接的操作就可以。

这个玩法就不是重复每天上新，而是靠筛选出数据好的链接，精细化的去做这个链接的数据，走精品店铺的路线，让店铺里的链接都是我想要很高的。

现在闲鱼有一个情况是到了1000我想要的，链接可能就容易被系统干掉，不是没权重了，就是被提示乱七八糟的违规，哪怕恢复后也没权重了。

### 3）爆款裂变

顾名思义就是把爆的链接重复裂变，一个产品爆，大概率第一要素是主图决定的，一张好的图，可以吃很久的生意。

那我们就把这个爆的主图重复利用，改下MD5，然后第2-8张图改一下，文案改一下或者换一套就可以，主要是这个图，用矩阵账号，或者矩阵链接去铺这个爆款的主图，来实现流量的灌入。

把这个爆的链接用精细化+铺量的玩法结合起来，让这个已知爆款更多的曝光在用户面前吸引流量，你做好后端承接就可以。

### 4）补单方法和选词逻辑

通过下拉框选出你的核心的词在加一点长尾的开始去做补单，也就是客户常搜的词是什么，你就去做这个词的转化率，让系统认为搜这个词找到你，能给他带来更多的转化。

选词可以通过下拉框，同行或者淘宝标题常出现的关键词去搜就可以，至于如何补，可以找朋友，也可以Q群，很多这种互补群，里面有一个逻辑是原价最好，群里一般都是补10-20的低价，没人补可以去找群里。

补的目的是为了系统给你流量，而不是说靠补，可以把一个本身不优质的链接干爆，哪怕干爆了，也只是运气好而已，不会持续的。

## 2.进入流量后

### 1）低价引流低价成交

闲鱼很常见的就是低价引流，引流进来如果转化不了，客户觉得价格存在相差很大就不会不买，这个方法就是找到一款你直接可以标价卖的，并且有利润的机器来进行流量承接。

399引流即为卖价，直接卖399-599的机器，转化率会高，价格匹配发布链接的价格，让成交变的简单。

标价为299，流量会更大，但这个价格的产品质量跟不上，退货率就会上来，会接近50%，比较容易废号。

闲鱼刚入门需要学一下基础知识，但入门后就是专研平台的玩法，规则，以及流量动态等，每天都会遇到新的问题和新的挑战，不会一成不变，学习能力强一点，做起来快一点。

拿投影仪举例吧，内容比较多，详细有讲解课程，看他自己用不用心去学去记，我们有的代理是群里看到别人在问问题，都可以解答别人问题，到自己身上就不会了，还是没用心，实际会了后就这么一点重复性的问题解决掉就可以。

# 一、东南亚房产选择的底层逻辑

做海外房产投资，宏观上来说，先选择具体的城市，而我主要从以下几个逻辑来做一些市场方面的选择：

- 国家政策是不是支撑房地产市场发展？是否有较好的金融政策？
- 土地供给量怎么样？人口多不多、是不是足够年轻？是不是人多地少？人地矛盾冲突严重？
- 经济发展怎么样？是不是长期看高速发展？

那具体的量化指标主要如下：

## 1. 首先在人口方面，

城市人口规模要大于1000W，不断要有净流入。同时，人口出生率要大于1%，年龄中位数要低于35岁，越小越好，要足够年轻。

因为人口红利不光意味着人多，还意味着人口要足够年轻。因为只有年轻人多，才会对新房有需求量，老人对新房是没有需求量的，而对新房没有需求量的房产市场，不会有发展大量发展空间。

## 2. 在房屋供给方面，

房子数与人口数比值要低于1：10，这样的矛盾相对就大，而这个比值，也是决定了一个房产市场租售比高低的关键。

像上海这样的780万套商品房住宅，对应2500W的人口，基本上1：3的比例，故上海的房子的租售比很低，或许听过在上海买不起房子，但是很少有人听过上海租不起房子的。

我们再看日本，日本因老龄化严重，经济发展空间小，所以导致日本房价上涨潜力低。

但是东京、大阪等地区的房价租售比却很不错的，基本上可以做到6-7%左右，租金较稳定，原因就是人口太多，土地房子太少，比如东京就有3000多万人口，而老人多不多没关系，因为老人也要住。

## 3. 那经济层面上呢？

我认为最重要，房产投资是一件时间的艺术，要讲究合适的时机入场。过早不行，国家经济太穷，发展周期太长；而过晚也不行，国家经济都发展起来了，房地产市场也完善了，那就没什么投资的机会了。

那这个时间点怎么衡量呢，我的指标是一个国家的人均GDP在3000-8000美金这个阶段，最适合做房产投资。

这个观点，万通董事长冯仑在2017年接受采访时也讲过，他说：“如果你今天要转型，就去人均GDP3000美金往上的地方，通常人均GDP在2000-8000美元时，是住宅成长最快，是‘赚大钱的时候’。这是规律，全球范围都没跑出这个圈来。而抵达8000美金的人均GDP 的时候，房产市场的发展则趋于稳定。”

那我们举例，我们国家的房地产市场发展，也基本上符合人均GDP3000-8000美金这个规律。我们国家在2008年的时候，进入人均GDP3000美金，在2017年进入8000美金左右的水平。

相信这9-10年时间，我们可以感受到的是，但凡是城市房价就会涨，当然这些与09年的4万亿注水，15年的三去一降一补等政策也有关系。

而2019年开始至今，全国房地产市场基本横盘或者说开始下跌，当然除去北上广深以及一些新一线城市之外，这些城市会因为人口的净流入或土地供应少，从而促使房价保持稳定或者稳增长。
