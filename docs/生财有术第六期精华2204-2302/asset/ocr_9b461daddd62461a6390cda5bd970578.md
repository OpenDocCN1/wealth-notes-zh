# 十一月：gala套利、FTX暴雷

gala套利：gala这波套利有些人赚了不少钱，几百万，应该也有千万的。这种就是顶级的机会，送钱的机会。但是需要相关的套利认知和经验的积累。这件事包括上面的APT空投都越发让我意识到团队的重要性和不可或缺，在最大化捕获机会和利润方面，团队是至关重要的。

FTX暴雷：反正发生的时候还是挺震撼的，虽然有预防，但还是活久见。

给我一个很强烈的感受就是我觉得我们这个市场行业真的是极度地符合墨菲定律的，就是什么呢：可能发生的事情就一定会发生。

luna、三箭、FTX，一次次的深刻教训，反复给我们明示了一个道理：在这个市场上，绝对不要抱有任何的侥幸心理。有侥幸心理必死。

这三大雷，上千亿美金的代价，真的里面有很多深刻的东西值得我们去思考，警钟长鸣。

还有很多其他的交易，忘记了。

不同行情，适用的策略真的很不一样。

2021年，我知道的有个小伙伴，3万本金，做到了1000多万。难得的是他没有使用杠杆，靠的是纯现货做上去的。

怎么做的呢？他只专注做一个事情：关键点突破追高。
