大众喜欢的是直接教我怎么赚钱，而不是提升能力去间接赚钱。

这个结论成为一个很关键的结论，后面我就想，想教人赚钱没错，那好吧，自己先赚钱证明给大家看看。

其实本质还是靠元能力的提升，只不过大部分人是心浮气躁的，沉不下来学提升能力的东西。

所以接着我去学抖店，这个生财是没航海的，最后实践发现当时抖音环境做后端是很困难的，这个项目也是做失败了，不过让我发现了前端的优势，就有下一个参加航海学前端。

# 《抖音带货航海》

在这个航海里变现了20多元，但知道了短视频的制作原理，也打开了眼界，制作短视频并没有自己想象那么复杂，也并非只有原创途径。

其实现在看来，最快的路径可以先选一个大概率能做成的项目，先做成，再同步慢慢去提升元能力，和对主项目有用的周边认知。

后面2022年，那当然全部选择视频号带货航海了，前端能做成功，后端不是自带流量了么，ip不是很容易了么。

# 《视频号带货航海》

第一次视频号航海的时候是2022年6月份，第一个月跟很多的人都一样，0变现，但至少掌握了基础知识。

第二个月，7月开始变现，但也很坎坷，第一批起了5个号，不出单或限流，一个广场舞号呢，有流量但不变现。

差点想放弃，那个月就看斗罗大陆、斗破苍穹，来释放压力。

唐三飞升了、萧炎也飞升了，小说也看完了。我就在想，一直这样下去可不行呀，再这样下去我也要“飞升”了。
