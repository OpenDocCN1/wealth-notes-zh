这个时代是对普通人最好的时代，你可以在各个平台打造个人品牌获得流量，个人品牌是一件长期复利的事，低成本获得流量和曝光，多香呀。

# 三、总结

# 1. 先有产品还是先有流量

做副业变现，做课程变现也好，最常见的误区就是先去做流量。

很多人做了很久都没流量，有的人做了几年几十万百万粉丝了还不知道怎么变现，少数能变现的也不是很稳定，太长时间粉丝也失去了粘性。所以不要迷信什么我要多少粉丝了才能变现才开始变现，先保证自己不要饿死。

# 2. 想清楚你用什么变现

副业的本质是，先有产品再搞流量或者边搞产品边搞流量。

副业、变现、赚钱、商业本质其实就是「生意」，就是商品交换、价值交换。你只有粉丝没有产品，别人想给你钱都不知道怎么给。所以如果你有实物产品很好，你的定位很清晰。如果你是虚拟产品，比如社群、服务、课程，那么你需要先设计好想好你的产品是什么。

# 3. 用最小 MVP 验证这个产品是否有市场需求，是否可行

最小 MVP 可以是免费产品，也可以是超低价产品。如果免费的都没人要，那么这款产品说明没有市场，如果低价很多人要，那么你可以设计一套系统化的阶梯式的产品。（前提是如果你的粉丝是你的目标用户，是精准的）
