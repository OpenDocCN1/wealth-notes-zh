我简单的算了笔账，不禁眼里发光：130个城市*4W=520W，我又翻了一下他们抖音账号往期的时候，发的都是单个玩具的展示视频，一直都是不温不火的几个十几十个赞。家公司不是厂家，只是经销商，源头厂家是广州某玩具厂。

## 2. 分析火爆原因

- a. 单卖挖掘机产品卖不动：
    - 客单价高；
    - 缺少视觉冲击力和应用场景；
    - 购买动机和购买决策分离：消费者是孩子、购买者是家长，除非特别刚需（比如为了学习），否则卖只能是小众产品。
- b. 但是把产品包装成儿童游乐项目，体验式游玩，以按时收费的方式取代直接购买，消费场景瞬间戳到很多男孩和父亲的痛点（每个男人都有个工程建造梦），原理参考乐高。
- c. 恰逢过年，赶上流量高峰期，视频一下子就爆了。

综上，得出结论：这个项目，赚钱是必然，不是偶然。

## 3. 判断可复制性

- a. 定目标：他1个视频赚500W，我复制他们，赚个几十万行不行？
- b. 定策略：先了解成本，定代理政策，再复刻体验场景，最后选择投放渠道，等待数据反馈。
- c. 盘人手：召集了2位小伙伴，定好分工。

# 二、我们做了哪些事

## 2. 确定招商政策

我们在项目的合作价格上做了调整，竞品收费4W/家，我们直接腰斩，定价2W/家，这样在有价格压制的前提下，还有50%的利润。

## 3. 搭建体验场地，制作内容素材

我们在苏州大本营发动所有人脉关系，在一周内找了十几个商场，最终在一个天虹商场拿下了中庭的点位。

接着，从竞品的一个本地代理商那拿到了施工图纸，开业后连续5天，设计了一套充值活动，每天忍着拍了几十个视频素材。（项目确实不错，果然很多大人小孩来玩和充值。）

中间还碰到了很多场地谈判的坑，一些商场的招商人员，会要求跟你签各种霸王协议条约，以及吃拿卡要，这方面大家如果做开店生意的，给大家分享几点踩坑经验：

- a. 很多商场的点位，空置率都很高，都是可以谈的！不要被对方市场人员套路，年付、半年付、押一付一、流水抽点等等，能灵活尽量灵活！不要占用太多资金成本！
- b. 谈判时要迅速判断对方实力，不要拉扯；如果沟通超过3个回合，对方还未有实质性的推进，果断舍弃换一家。
- c. 找关键决策人，尽量不要从下往上打关系！

## 4. 定引流策略

竞品的爆款视频，偶然性太大，不太适合我们，我们选择了双管齐下：抖音投放+私域渠道合作。

### a. 引流渠道1：抖音投放

流量端我们准备了6个抖音账号。

其中3个用来发布内容，每个账号每天发2个视频，每个视频固定投100块钱，保证有基础播放量。

另外3个用来做评论区水军引导，水军话术都是参考的竞品视频“怎么加入”、“我也想在我这边搞一个”、“看着我都想玩，大神求带”……我们找了几个刷赞刷评论的qq群（直接搜索即可找到），每天保证视频有基本播放量和水军带节奏。

随后监测视频数据，12小时内，只要任意一个视频有5个以上有效咨询线索，立马翻倍投放，再跟进8个小时，如果咨询线索增加到20个以上，再次翻倍投放，直至3天时间截止。

同时我们把账号的粉丝，根据意向度进行分层，并制定对应策略：

| 粉丝行为属性 | 意向度评级 | 首次接触策略 | 二次跟进策略 |
| :--- | :--- | :--- | :--- |
| 主动私信 | S级 | 15min内私信回复 | |
| 发表意向评论 | A级 | （钩子：项目介绍文件+赚钱秘密）<br>评论区回复+主动私信回复 | 8小时后再次私信询问是否添加微信成功 |
| 收藏视频 | B级 | 2小时内主动私信回复 | |
| 当日点赞/转发/新关注 | C级 | 每晚18点，逐一私信，引导加微信 | |

几个建议：

1）创业类粉丝价值巨大，不要只把运营重点放到私信粉丝上，流量来之不易，不要漏过任何流量；

2）没加上微信的粉丝不是好客户，不要怕客户厌烦，要么他把你取消关注，要么他加上你微信；

3）不要怕封号，提前准备3个账号，封了1个另外两个继续干，同时再注册新号。

加上微信后，我们同样准备了一套招商的SOP，分为私聊、朋友圈、社群3个部分。

私聊框架：开场白+项目卖点介绍+文件+对方应答后跟进话术+对方不回复的应对话术。

我们当时是前面2天私聊跟进，第3天做社群宣讲，主要卖代理定金卡，后面7天朋友圈宣传，第10天把未成交的客户再集中拉群做一波返场宣讲，邀约到现场考察。

# 三、经验分享

## 1. 保持饥饿，保持敏感

我们在选项目的时候不要在自己的封闭环境里苦思冥想，而是要多到大环境中去肴。百度上的广告、抖音上的视频、公众号中的文章，只要他持续出现在你视野里超过3次，就值得去研究。

我常常在想：那条视频的1000多万的浏览数据里，我如果仅仅是停留了几秒钟，或者只是点开评论区简单翻了一页后，留下“卧撩牛逼”、“我也想玩”这些心理活动之后就划过去，那就真的只能当分母了。

## 2. 先有项目，再做营销

抖音只是营销渠道，不是赛道。这也是我从生财一位大佬身上学到的，以前经常迷茫，到底该不该all in做抖音，后来意识到，抖音也好，私域也罢，你只有找到了1个好的项目，转化率、团队稳定了，才能在这些渠道中发力。

所以，我们最近也在自己孵化了一些项目，找转化率稳定的项目方合作，我们做流量，产品交付交给专业的人。

## 3. 学会拆解，无新鲜事

做项目，有各种各样的业务细节。这时没有人可以帮你，没有经验没做过怎么办？怎么降低自己的试错成本？很简单，拆！

不懂引流？去拆20个同行账号。

不懂规避平台规则？去拆50个同行的私信话术。

不懂销售转化？去拆100个同行的转化链路。

拆解后再提炼出共性，加以完善，这样最起码能拿到70分。

一个好的赚钱项目=发现机会>>拆解案例>>评估可复制性>>玩法微创新>>收获结果。

## 4. 财务思维，受益终身

一个项目到底值不值得做？就是3个判断逻辑：

- 1）有没有人做、做了多久、做的结果怎么样。
- 2）做的人资源怎么样、你是否可以复制、要找什么样的团队。
- 3）投入多长时间、投入多长时间内、预计收益多少。

然后我们再分析一下东南亚市场的特点，

- ① 人口红利：东南亚人口年轻化，人口数量庞大，整个东南亚6亿多的人口基数，而且移动互联网渗透率高；

- ④ 东南亚人民对中国产品的青睐程度比较高，比如说菲律宾尤其喜欢我国的电子3C产品，东南亚各国工业产能不是特别高，因此国内不少产品以极大的性价比获得东南亚市场的认可；
- ⑤ 对于东南亚电商老卖家而言，当地的电商品牌数量不多，因此能够打造当地的独立品牌对于进一步占领市场有重大帮助作用。

# 二、什么是Lazada电商

## 1. Lazada的概述

### （1）Lazada简介

Lazada（来赞达），创建于2012年，是东南亚地区最大的在线购物网站之一。在2016年，阿里巴巴集团投资控股了Lazada，自此Lazada集团成为阿里巴巴集团东南亚旗舰电商平台。

iPrice2018年度报告显示，Lazada以27%的访问额占东南亚电商在线流量排名榜单第一，2020年8月4日，《苏州高新区·2020胡润全球独角兽榜》发布，Lazada排名第58位。

近年来新冠疫情在全球肆虐，进一步深化了东南亚用户的网购习惯，同时也扩大了东南亚的网购用户群体。所以Lazada直到现在无论是用户数量还是成交金额每年都在以恐怖的数据上升。

截止至2021年三月底，Lazada上一财年的年度订单实现三位数的同比增长，年度活跃用户已经超过1个亿。

### （2）Lazada与Shopee的对比

有人说提起东南亚电商，只知道Shopee，不知道Lazada，所以在这里我做一个简单的对比。

## ① 发展阶段

Lazada成立于2012年，但是和Shopee正面交锋的时间，应该是从2018年开始。

2018年3月，阿里集团追加20亿美金投资，持股达83%，彭蕾出任董事长，Lazada自此完全成为阿里系的平台，征战东南亚电商市场。

虽然Lazada创立之初的总部在新加坡，但业务范围随即覆盖马来西亚、新加坡、菲律宾、泰国、越南和印度尼西亚这六个东南亚国家。

而后起之秀的Shopee于2015年成立，腾讯占股39.8%是最大的股东，最初也是在新加坡设立了总部，但后期业务很快覆盖了新加坡、马来西亚、菲律宾、泰国、越南、巴西、墨西哥、哥伦比亚、智利等十余个市场。

2019年底，第八市场巴西的开辟，宣告Shopee正式走出地区，跨向全球。虽然两者成立时间有所不同，但是两者都处于快速增长的东南亚电商增量市场，两大平台都在快速发展。

## ② 流量差异

Lazada和Shopee流量平分秋色，市场和用户高度重叠，总流量是Shopee更大，某些站点Lazada的流量表现更好。
