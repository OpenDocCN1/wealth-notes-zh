# 二、航海干货分享

本周一、三、五每晚 8 点，每条船上的分享节目如约进行，有教练直播分享实操、解答问题，也有船员的在航海中分享实操干货，为大家的航行之旅补充弹药。

在周一晚上，「抖音-半无人直播」教练 @Erik 再次突破直播时长，这次接近 4 个小时的干货分享，教练找了很多案例给大家拆解，非常值得多次回顾学习。（戳文末的资料汇总查看）

「视频号-视频带货」的船员 @肖江波 在群内分享了《航海视频号带货第 6 天，小白从 0 到变现 5400 元，我是如何做到的？》

他分享了他是如何突破新手期，他说特别认同郭晓文老师说的一句话「找到一个有成果的人，只听他的方法，只执行他的方法」。
