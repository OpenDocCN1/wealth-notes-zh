# 技巧十三：俏皮方言

口音戒不掉，干脆打造成slogan。

之前我们团队孵化的一个达人是成都的，普通话带一点川普的味道。因为业务是房地产，具有本地化属性，所以干脆加强方言这一点，每个视频里都融合了那句特色明显的成都话。

效果就是川渝地区的人刷到感觉亲切，外地的有些听不懂在评论区问还增加了互动。因为只有一句话，所以也不会影响整体视频内容的理解，是一个小亮点的作用。

# 最后

我们孵化做口播的达人，是从销冠、客户经理里面选拔出来的。

样貌姣好，口齿伶俐，反应机敏。

但即使如此，在开拍的第一天，却有人崩溃大哭，觉得自己做不好这件事。

台词讲不下来，镜头找不到。天热人烦躁，一遍遍的重拍让人崩溃。好想放弃，不如回到自己的舒适区，老老实实做个销冠。

但是所有人都知道，这件事是有意义的，只要你肯坚持，它一定会给你反馈。
