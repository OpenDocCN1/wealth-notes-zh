# ## 1 找项目的本质

以下是某篇精华帖内容，你有没有相似的经历？

> 当然也在不断的尝试各种项目，淘宝客、抖音小程序、书单号、知乎好物、闲鱼无货源、线下拉新、搜地推、外卖cps等等。但凡自己觉得能试一把的，都试了一遍。

**不出意外，这些项目都没成。**

说实话做任何一个赚钱项目，都很难让你短期赚到大钱。拿到结果的人，前提是投入了大量时间和精力，还有能力、经验和资源等方面的隐性条件。

所以才说，别人的成功你很难复制。比如富翁有钱是继承了遗产，比尔盖茨还有个厉害的妈妈……

谁都希望副业能超过主业，然后干掉主业。但为什么即使副业做的不错了，让你辞职也会犹豫。

因为打工是最容易的挣钱方式，收入稳定，能摸鱼，单位好说出去好听……副业却可能收入不稳定，能干多久也说不准，用的全是自己的业余时间……
