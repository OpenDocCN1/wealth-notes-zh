分类管理起来，以后都可以用

如果你觉得画面素材的准备和分割小段太麻烦，实在不想弄。有一个简单快速的方法，就是找我要。你可以拿去直接用，这样能节省省60%的工作量。

小样剪辑：

（为了方便理解，依然用作披萨来比喻。）

+   1. 放饼胚-将混合好的基础素材拖入剪映主轨，背景设置成“模糊”关闭主轨声音。
2. 放肉-将初加工好的原视频放在第二轨，音量调到合适大小，人物智能抠像。
3. 放调料-识别字幕，调整样式，校对，断句。第一句和最后一句顶头顶尾。
4. 放配菜-哪个时间段需要出现特定的画面，将画面分别放在对应位置（借助字幕可以快速确定位置），占第三轨，关闭本轨道声音。
5. 装饰-根据需要加入音乐、音效、贴纸、特效、动画。
