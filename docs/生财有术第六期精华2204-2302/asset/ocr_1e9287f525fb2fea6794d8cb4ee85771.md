# 一、搞流量

所有的商业模式出的问题，几乎都是流量问题，我把模式/体系理解成一辆车，流量理解成是“油”，若是没有油的驱动，再好的车都只是花瓶，毕竟开不动的车，没有太大的意义。

# 1.流量考验布局能力

我不迷信单点流量带来的效益，虽然确实很多博主在其中受益，就拿抖音来说，很多人都迷信抖音爆款，ALL IN抖音流量，能做通还好，做不通只有等死，毕竟需要一直投入成本，很少有人能坚持到底。

我反倒是认为，做IP的成功，是必然的，并非靠运气，或者某个平台爆了个视频，具有偶然成分，把偶然变成必然，就需要超强的布局能力。

布局相当于建立起一个体系，有前端有后端，有流量有转化有交付，体系完成后，剩下的就是交给时间，我这么说有些故弄玄虚，但我内心想表达即是如此，不如我再说明落地。

布局点有很多，我把内容属性做了归类：短视频、中长视频、文章、SEO、社群交集等等。

然后再针对内容属性找主流流量平台，比如短视频主流平台：抖音+快手+小红书+TikTok，中长视频主流平台：B站+头条/西瓜+爱优腾+YTB，文章类主流平台：知乎+头条+百家+各论坛/站点，SEO主流方向：百度+搜狗+抖音SEO+头条SEO+知乎SEO，社群主要是行业付费社群。

也就是说，我只要针对性产出内容：短视频、中长视频、文章、SEO、社群交集，就能分发布局到各个平台。
