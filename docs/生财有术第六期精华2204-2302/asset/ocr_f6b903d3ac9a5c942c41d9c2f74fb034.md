# ② 个人态度

你的信仰是什么？你支持什么行为？你讨厌什么？你极度反对什么？

你要通过内容把以上这些表达出来，态度才是个人 IP 溢价的根本影响要素，核心价值的交付力在这个时代同质化程度太高了，你说你会弹吉他，会弹吉他的人太多了，别人凭啥喜欢你，凭啥买你的吉他课，你得有态度啊，你得有那个范儿，有人就喜欢你说话的那种感觉，她就买您的。

# ③ 外貌特征

这个算是个人 IP 的一个构成要素，但不是用内容表达出来，这里暂且不谈，不过很好理解，比如周星驰的大笑，扎克伯格的恒久不变的T恤，乔布斯的牛仔裤，马云的小毛衣等等。

最后总结一下，其实就一句话：干货 + 态度

首先保证你的内容有用，再保证你的内容有情绪，持续这样输出，你的个人 IP 就出来了。
