+   1.1. 合作形式：乙方自媒体平台原创内容创作与发布推广；

+   1.2. 具体合作内容：

+   1.2.1. 发布推广内容时甲方品牌名称： [空格] 乙方自媒体形式为： [空格] 发布平台：小红书； 乙方自媒体账号： [空格]

+   1.2.2. 乙方可根据甲方品牌传播主题及产品核心特点，结合自身风格，以用户的角度，构造甲方品牌传播核心信息，推广甲方产品。 简单合作协议

+   1.2.3. 发布内容以甲方提供资料为准，乙方提供内容策划、拍摄剪辑和发布工作。且乙方需在正式创作之前向甲方提供内容脚本，经双方确认之后将其作为本合同附件。乙方需依照附件内容进行创作，发布前内容给到甲方预览，最终以双方确认的内容为准，甲方有权根据甲乙双方事先确认的标准，提出符合其行业属性的，正常合理合法的意见修改意见和建议并要求乙方按其实施。乙方应按照甲方的修改意见和建议提供服务，为避免争议，一般修改外，内容按至多两次方向性修改。

+   1.2.4. 广告发布时问：12023 年【2】月【1】日-【2024】年【2】月【1】日

+   1.3. 广告发布及项目合作期限：发布日距发布平台保密时间不少于6个月。双方合作期间，乙方不得接甲方同类目的任何其他品牌的推广活动。若乙方或乙方经营或自有的自媒体违反上述约定给甲方造成损失（包括但不限于诉讼费、律师费等）的，乙方应负责赔偿。
