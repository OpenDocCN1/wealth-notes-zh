# # 一、内容为何成为竞争底牌

大量玩家的入局让赛道更加拥挤，批量化工具快速降低了生产成本，爆款选题成为万众瞩目的对标，当同质化越来越严重，选题、排版难以再出色时，内容成了全村的希望。

思维决定行为，行为决定结果。如果想要用内容进行突围，首先一定要在认知层面打破偏见，即不重视和太重视。

不重视：认为用了爆款模板，或者搬运了爆款内容，自己的数据就会起飞。

太重视：有原创情结还自嗨，完全不管读者喜不喜欢，太想写好内容却没有方法论而难产。

对内容的态度两个极端，怎么办？接下来我就帮你打破这道认知枷锁。

梨云绿这套爆款模板拿下的战绩，大家都有目共睹，但你有没有遇见这种情况：即使用了爆款模板，笔记数据起来的也有些艰难。
