# 1.5 从剧情向看剧本杀类型

按剧情向，剧本类型主要可分为推理本、情感本、还原本、阵营本、恐怖本、机制本等。

（1）推理本：游戏主题一般是找出隐藏在玩家中的凶手角色，剧情本来自于推理小说，比较重视逻辑推断，看重证据线索这些细节的挖掘。

推理本内部本身又分本格和变格：本格更注重于作案手法和严谨的逻辑推理，理论上杀人手法在现实中是可以实现的；

而变格是由离奇鬼怪、穿越等元素组成，通常以营造诡异恐怖氛围为主，往往会出现现实中不可能的作案手法，需要玩家发挥想象力。
