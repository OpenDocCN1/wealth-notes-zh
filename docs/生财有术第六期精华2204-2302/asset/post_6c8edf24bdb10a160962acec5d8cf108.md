# ## (精华帖)(348赞) 程序员可以在生财有术干什么

作者：刘小排

日期：2022-04-11

不知道大家有没有这样的朋友，明明是互联网大厂的程序员、产品经理，拿着百万的年薪，却热衷于在生财有术里找一些低杠杆、拼体力的副业做，每个月挣一两千块辛苦钱。

每次看到这种现象，我都感觉痛心疾首。

你能写程序、能近乎零成本地指挥机器千军万马做你想干的事，你就拥有了这个世界上最厉害的杠杆之一。何必去和别人拼体力——这个世界上最不厉害的杠杆呢？

> 不能充分发挥自己的天赋，是对自己生命最大的浪费。

我也是程序员出身。希望能够给程序员朋友们一些建议。

程序员朋友可以在生财有术干什么，才不至于浪费自己的天赋呢？

至少有四件事可以做：

1. 低端劳动自动化
2. 做IP卖课
3. 卖工具
4. 关注Enabling Technologies，改造现有产业

我们先从最简单的说起。

## 一、低端劳动自动化

我多次在生财有术里推荐盗坤兄弟的电商思想。

本文再多说一个，盗坤有一个很了不起的电商思想 —— 财务逻辑，把账算清楚。

举个例子，如果你想做抖音号，你雇佣一个人，给他开6000元的月薪，他一个月能出多少视频、多少流量呢？

盗坤兄弟的想法是—— 我就招一个6000元月薪的普通人，他不用懂什么视频制作的专业技 术，他只帮我二次剪辑就好，别瞎创新。这样的活，每条视频的制作过程只需要20分钟， 他每天可以产出20个视频，每个月可以产出600个视频。

我们简单算一算。

考虑到他的月薪是6000元，也就是说，我们每个视频的成本是10元。

抖音的流量推荐逻辑是，只要账号过了风控期，一个视频能够带来至少500的播放。偶尔 有一些爆款视频，并且随着账号标签的积累，出爆款的可能性可以变大。实际测试，编辑 视频的时候精心一些，在大约一个月后，平均每个视频可以带来2000的播放量。

那么，我们10元成本，就保底买到了2000的精准流量。

由于我们的账号一直在开直播，对于这2000的精准用户来说，直播间就是我们的收银台。大约会带来200超精准的用户，进入到直播间。

也就是说，只花了10元，买到了200的精准用户进入直播间！更何况，抖音还会根据你的粉丝，推荐直播流量到你的直播间呢？

这个投入产出比，不比用千川投放，要香好几十倍吗？

作为普通人，看到这里，你会感觉很兴奋，跃跃欲试。

但你不是普通人，你是程序员啊。

你会发现，单条视频的成本是10元，似乎也有点高。你完全可以写个程序，自动做视频的二次剪辑，把它的成本再降低一到两个数量级。

嗯，这不是我的想象，其实已经有很多圈友这么做了。

## 四、关注Enabling Technologies

最后讲难度最大，也是想象空间最大的部分 —— 关注Enabling Technologies。

这也是我自己喜欢干的事。我每天都会花很多时间泡在Hacker News、Github上，关注新技术，思考它们或许会带来的可能性。

中文世界对Enabling Technologies的翻译大概是“使能技术”。

我尝试解释一下。

“enable”在字典里意思是“使能够；使成为可能”。

"Enabling Technologies"的意思是，某项新技术，它的存在可以以以前的某件事，从不可能，变成可能。

比如，4G + GPS 定位，让Uber打车成为了可能。在没有出现4G + GPS的十年前，是没有办法做出滴滴打车或者Uber的。

我们的操作方式是：

1. 对新技术保持日常紧密关注
2. 对生财有术的帖子保持紧密关注，了解别人在做什么事。
3. 结合1和2，从而哪些新技术属于Enabling Technologies，然后去改变旧的做法。

我们举个例子，

例如，你可以关注到，

1. 新技术。从2021年开始，直播换脸技术走向成熟。（再早几年时间，可以视频换脸，但换脸的直播相对困难一些）
2. 旧产业。你从生财有术了解到，差不多也是从2020年、2021开始，中国人开始在TikTok上直播，出国卷老外。有相当多关于如何做TikTok的训练营，开始日趋火爆。

那么，直播换脸技术，就是一项enabling technology，它让“中国人把自己的脸变成外国人，在TikTok上直播”变为可能。以前必须雇一名同时懂中文和英文外国人才行直播，现在可以招点英语专业的中国大学生就行，节省了不少成本。

![](img/a50ad26370b1cd7f67818735c6f556a8_64_0.png)

有了这个洞见以后，作为程序员的你，可以干很多事情。

比如：

- 提供换脸直播教程，针对在中国做TikTok生意的公司定向销售。
- 降低换脸直播的使用门槛。用户是技术小白，能换脸直播吗？用户只有一台手机，没有拥有强大显卡电脑能啊，能换脸直播吗？能啊——你想办法把它做成云端方案，就可以让这项新技术走进千家万户了。
- 做直播换脸的垂类社区。
- 打造直播换脸技术的IP。（挺蓝海，据我所知，目前国内还没有）

生财有术，帮你寻找需求。

新技术，尤其是Enabling Technologies，帮你解决技术问题。

而你，负责连接两端，解决产品和变现。

# 总结

1. 不能充分发挥自己的天赋，是对自己生命最大的浪费。程序员就别和小白拼体力了，多想想怎么用自己的天赋。
2. 程序员在生财有术，至少有四类事情可以做：低端劳动自动化、卖工具软件、做IP卖课、关注Enabling Technologies，把它们用到各行各业。
3. 三和四有点难，如果缺乏经验的话，可以从一和二干起。

# ## [精华帖](478赞) 持续赚钱的学问

作者： scalers

日期：2022-04-22

持续赚钱的学问

大家好，欢迎来到新一期“生财有术”。

我是Scalers， 《持续行动》《刻意学习》作者。接到生财的作业，要我写一篇“持续赚钱”主题的文章。正好，我的第三本书《学习的学问》昨天开始预售了，所以今天就借着“学问”的关键词，以“持续赚钱的学问”，写一些自己的心得体会，仅大家参考。

## 1、持续赚钱始于认知革新

我认识亦仁是在2016年，那时候他还在做一个关于版权的创业项目，帮助公众号作者针对抄袭等侵权行为维权。那时候我有一篇爆款文章特别火，叫《大学生上课为什么一定要认真听讲》，有好近千个公众号未授权转载，包括一些央媒。那时候亦仁正对接我做这件事情，他把导出的侵权列表发给我的时候，我想的是怎么把这些号都通通搞一遍。他却对我说，你为什么不试试加上这些公众号的运营，这样以后他们可以继续转你的文章。

他这番话倒的确给了我启发，毕竟我从来没这样想过要和抄自己文章的人建立联系。于是我就照着操作了一下，还真加到了一些编辑，也建立了一个群。后来呢？后面就没有然后了，因为我后面就没有写过特别火的文章了，所以他们也没必要转发了。这个价值链也就中断了。

但是回头看，亦仁当时给我的一个启发是，一些我们以为必须如何的事情，可能有其他的看待问题的方法。而这里“加上好友”的思考问题的方式，现在在生财的精华帖里，经常能看到，后续我才发现，遇到流量加上好友，就是一种赚钱的基本功啊！就是现在所谓的“私域流量”了，在那个时候，亦仁就有这个理念了。所以你看到，一个社群的生长与发展，是和创始人的思考问题的角度，有关的。

这应该是亦仁最早给我带来的认知革新。我们对待同样一个问题，会有不同的看法，而这种不同的看法，会引发后续一系列的演进与变化。当然，假如你要问我，有人在未授权转载的情况下用我的文章，我仍然还是会有意见的，如果在公众号，我还是会去投诉的。

持续赚钱始于认知革新。而认知革新比较简便的上手方式是，有人出现在你面前，天然自带一种与你不同的想法。而且对方天然认为这种想法正确合理，但是你却没有考虑到，于是你感到了不同，于是有了革新的感觉。

这种感觉，我相信是你在这里能够持续获得的。毕竟，持续有人输出精华帖，分享自己在赚钱里面的实践，而一项实践的背后，往往会有认知的差异。我们通过一篇又一篇的精华帖，看到的就是一个又一个天然与你想法不一样的人。而这种不一样的鲜活的人，就是源源不断的认知革新的来源。

当然，认知革新不代表自我否定，也不代表你以前想的做的是错的。只是通过认知的革新，你能看到世间有千万条道路，你开始主动思考、选择、坚守自己的道路，这才是最重要的。

我们选择什么道路，会决定我们会遇到什么样的人，遇到什么样的事，甚至，赚到多少钱。

## 2、赚钱发于行动突破

人有很强的适应能力，既能适应各种困境，也能适应各种客观环境，既包括“没钱”的状态，也包括“有钱”的状态，还包括“赚不到钱”的状态。

我有一个不成熟的观点，大多数人是并不需要或者并不是真心想赚赚钱的，他们只是享受表达自己想要赚钱的欲望的时候的自我认同。一群人在一起，相互交流一下自己想赚钱的欲望，然后就回家睡大觉，第二天继续重复这样的事情，三年五载过去了，钱没赚到，花了不少，还嘴硬说自己一直在找机会、混圈子、抱大腿。还有一些人也并不是真正喜欢赚钱，而是喜欢花钱，喜欢享受，喜欢满足自己的欲望，但是又不想付出投入，只想投机。于是慢慢地就会变成，通过键盘与口头表达，来收获快感，不管在什么场景下，都反着来说话，借此表达自己的理性、中立和客观，从而代偿自己需要的成就感与重要感。

以上行为都没有什么问题，只是每个人都在塑造自己的生活 的轨道而已。而假如你想真正要赚钱，或者想要自己生活有一些改变，那在认知革新的基础上，行动突破是关键所在。

我是做个人成长类社群的，我的社群风格就是“三个全面”（全面日报、全面分享、全面复盘）“打破小透明”。就是在读书会中，所有人都要每天读书、每天答题、每天交作业，如果有缺就要移出，补完才能回来。很多人认为，这样太严格不友好。这样说的人，没有看到，如果你真正想要成长进步，那就要做扎实的、大量的甚至有一些无聊的行动。这些行动就是我们个人突破的基本功。

在个人成长中，基本功有：

1. 读书，不因为主题不喜欢而停止阅读，只要是自已应该会的，就能认真学完
2. 学习，不因为难度太大无法承受而放弃，只要是想学的，总会尝试突破
3. 听课，能集中注意力不走神，可以同步记笔记，听完就能输出
4. 复盘，参与了一场学习与讨论，能快速梳理出要点，整理收获体会
5. 遇到情绪波动，能抵抗得住放弃的诱惑，仍然保持前行

这些都是需要通过大量的行动才能训练出来的本领，是需要日日之行之功，不是一蹴而就的。而且这些道理也很简单，就是要持续行动，要去做。

亦仁曾经问过我，赚钱有没有什么类似个人成长学习的基本功？我说把赚钱的动作拆解开，然后反复练习，其实就可以。我列举几个：

1. 阅读精华帖，写阅读分析与评论，梳理作者思路，并总结可以借鉴的方面。
2. 在互联网上看到广告、文案时，不要马上跳过，分析这样写的原因。
3. 看到一些广告的微信可以加上好友，搞调研。
4. 持续用数据思维看问题，测算你看到的商业行为的运营数据，积累对数据量级的敏感性。
5. 见到你觉得文章写的有启发性的人，把你的阅读感想发给对方，不要只发自我介绍。

赚钱其实像一种技能，尤其是对于生财有术的赚钱的项目，更是实操型、机会型的多，那更要有大量的行动来突破，当然这也伴随着许多失败的风险。但是当你做一件高风险的事情的时候，想要提升成功率，能做的就是用更大的行动量爆破。

最基础的、最省事的，就是看帖子、写总结、写梳理。看上去不难，其实不简单。

## 3、赚钱守与时俱进

这部分内容稍微高级一些，就叫“有命赚，也要有命花”。

我以为，赚钱是一个结果，不是一个目的。比“怎么赚到钱”更重要的问题是“赚到钱以后怎么办？”给你钱的人，会怎么看你？你赚钱的行为，有什么影响？如果以赚钱为唯一的目的，多半会许多次兴灾患，这些灾害很可能会让你没命花这个钱。那你想想，即使你把这笔钱赚到了，又是给谁赚的呢？
