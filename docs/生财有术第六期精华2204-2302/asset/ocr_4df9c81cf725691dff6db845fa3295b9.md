而C端客户永远满足二八法则，就是**至少80%的人的执行力是有问题的**，你再专业，再喂饭，他也不一定拿的到结果，因此**即使你不是骗子，最终也会成为他们口中的骗子**，因为loser非常擅长把问题归咎于别人。

这跟跨境电商做黑五一样，对部分人来说，面粉和药都一样没效果，那为什么不卖面粉呢。正是看到C端培训难以避免纠纷，所以很多做C端知识付费和培训的，干脆就真的骗。比如一键铺货一件代发躺平赚钱，就是从动机开始就是骗的，如果还有更恶劣的，就会涉及违法。

# **b）如何解决C端培训/课程的纠纷率**

我的建议是，把课程选题专注在提升学员思维，或者专业度，以及个人成长上。

并尽量减少或去掉量化承诺，尤其是对赚钱的量化承诺。

即：*做有价值的轻交付*。

陪跑，承诺变现效果，以及其他的现实效果，过分放大个案学员的成功，都属于在往重交付的坑里跳，这样的知识付费做不长，即使你的课程真的很有价值，因为二八法则的存在，也一定会遇到很大比例的差评和纠纷。

在课程中，每当你输出了价值和信息差，你要立即强调或者与学员确认他有没有获得专业的提升，认知的提升，或者自我的成长，这实际上就是把交付打散到每一个价值输出环节，只要学员接受了你的强调，就是一次instant（瞬时）交付。

*如果你的课程有满满的* ***instant*** *交付，这就是个成功的轻交付的课程，并且一定能做的长久。*
