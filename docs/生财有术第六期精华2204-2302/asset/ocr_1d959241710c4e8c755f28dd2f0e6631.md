# 五、新人想做会有一些什么样的门槛

1.执行力、执行力、执行力

三天打鱼两天晒网，做任何项目都干不好，选择一个项目先干**100天**，不管结果如何，你在这个行业里会超过**80%**的同行者。

2.对新事物的学习吸收能力

闲鱼刚入门需要学一下基础知识，但入门后就是专研平台的玩法，规则，以及流量动态等，每天都会遇到新的问题和新的挑战，不会一成不变，学习能力强一点，做起来快一点。

3.数码产品知识的理解

拿投影仪举例吧，内容比较多，详细有讲解课程，看他自己用不用心去学去记，我们有的代理是群里看到别人在问问题，都可以解答别人问题，到自己身上就不会了，还是没用心，实际会了后就这么一点重复性的问题解决掉就可以。

4.对金钱的欲望是否能够强烈

没赚钱的野心是做不好事情的，虽然一个月只能赚个几千上万的，但实际是没上限的，如果你抱着一个月赚**1000**的心态去做，能赚**500**就不错了。
