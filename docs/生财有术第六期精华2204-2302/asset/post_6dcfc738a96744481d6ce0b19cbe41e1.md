# (精华帖)(70赞)我如何自建小红书运营团队，通过矩阵引流月变现 20万+

作者： 魏晋北

日期：2022-08-15

先来问一个问题，“大家买车是不是只能想到去4S店，然后在同城多家4S店对比价格，最后选一家价格合适服务好的店买车呢？”绝大多数人都是这样做的吧。

但其实汽车销售这个行业中，普通人也是有赚钱机会的，同时还能为购车的消费者省一笔钱。

现在我们平均一个月要交15台车，单台车的利润3000-20000。

关键字：汽车代购项目，抖音小红书拓客，抖音直播，4人团队，不需要投入大量资金。

大家好，我是第六期生财的新人，14年毕业之后在大众点评网工作，后来回大学当了一年的行政老师，这几年开过奶茶店干过餐饮店，现在是一名“车贩子”，在做类似于「豪车毒」的新车代购业务。

接下来我将从这几个方面分享下这个项目：

- 1. “汽车代购”是什么？
- 2. 购车过程有哪些利润点？
- 3. 怎么做？做的时候会遇到什么问题？
- 4. 我们的目标人群是哪些？
- 5. 怎么拓展这些人群？（这个在后面重点讲了）

# 6. 新人想做的一些门槛和建议？

希望你看完后，先不谈赚钱，至少可以为你自己购车省下一笔钱。

# 1. “汽车代购”是什么？

老纪的「豪车毒」，大家或多或少应该都在抖音等平台刷到过。

那么为什么我们这类车贩子中间商的存在能给客户购车省钱，同时还能赚钱呢？

我先来给大家梳理一个汽车销售的大致框架：

从汽车厂家直接拿货的叫一级经销商（4S店），从一级经销商拿货的叫二级经销商（分销商、零售商），汽车代购其实就是二级经销商，俗称汽贸，就是和很多家的4s店进行合作，汽车来源主要是来自于当地4S店或者是来自于外地4S店。

一般一级经销商（4S店）为了做批发业务，普遍会给二级经销商一个比正常零售价格（4S店销售就是正常零售价格）低一些的价格，保证二级经销商的利润。

举个栗子：一台车A正常零售价格是20万，4S店给二级经销商的价格是19万，那么如果二级经销商给客户19.4万，则相当于客户少花了6000元购车，二级经销商赚到来车价里的4000元。

# 2. 购车过程有哪些利润点？

刚刚第1点所说的车价的差价就是利润点之一。

第二个利润点，购车都是要买保险的，汽车保险的返点是第二个利润点，之前返点比较多的时候，能返60个点（60%），比如10000块钱的商业险能返6000块钱。

第三个利润点，如果客户是贷款购车的，那么客户做贷款，银行也是有返利的。一般车贷的年化利率是3%，三年返3个点，五年返3.8个点。

例如贷款10万，分3年，那么客户一年的利息是100000*3%=3000，3年利息就是9000。同时银行返3个点（3个点就是3%）给我们，贷款返利就是3000块钱。

综上所述，一般而言一台车的利润点就是 车价差价+保险返点+贷款返点
4000 + 6000 + 3000 = 13000

当然这只是理想情况，正常情况下，我们是要让更多利润给客户的。

# 3. 汽车代购怎么做？

这个内容会比较多，我会从如何从4S店找车源，以及定车的流程讲一下。

最快的办法，就是在你当地找一个做的很好的汽贸店，带着学习的心态先去上班。

那从0到1怎么做呢？最基本的一步是，你要以消费者的角色进入某一家4S店了解正常的购车流程。

确认要做这件事之后，你需要开始加微信了，那么是加谁的微信呢？加你当地4S店销售部领导的微信。加微信的目的是，4S店领导会给二级经销商群发车型以及当前的优惠价格，另外方便找他定车转定金。

一个4S店的销售部从上至下的职位一般是销售经理-展厅经理-大客户经理-二网经理-销售顾问，而有的4S店销售部的职位就直接是销售经理-销售顾问。

而我们就是要加到负责给二级经销商（二网）发车的人的微信，并告知他们我们是在哪里做的汽贸，以后想从他们店拿车。

怎么找到这些人呢？

方法一：直接打电话到这些店，“你好，请问咱门店给二网发车的经理的电话是多少啊，我想找他拿个车”，这个电话正常是4S店的前台接的，一般会告知你电话的，这个时候请备好纸笔在旁边，赶紧记下来，因为前台挂这类电话很快的，会有些不耐烦。

方法二：一家店一家店的拜访，直接进店找销售经理（或者二网经理、大客户经理，不管是什么经理，就是给二网发车的，就是我们想要的），表明自己是做汽贸的，想加个微信进行合作，以后方便从这家店拿车。

方法三：我们这一行，在4S店领导跟二级经销商之间还有一群人，他们专门联系全国各大区域的4S店，然后把价格发给我们这些二级经销商，他们一般一台车赚个500-1000，全靠跑量，主要就是中间递个信息。

对于二级经销商而言，询价方便，能了解到及时的汽车优惠行情；对于4S店而言，长期稳定的熟人合作，风险较小。

以上三个方法还只是解决了报价和车源。

第一步：明确商业定位，我们就是卖车的，可以给粉丝更优惠提车。

第二步：明确内容定位，（三有原则：有用、有趣、有共鸣），因为我们是卖车的，所有决定先输出有用处的内容，比如如何选到好的车牌号，30万预算该选哪个车，某个车型该选哪个配置性价比更高，两个车型在纠结推荐选哪个，等主题内容。

其次我们的视频内容还有给粉丝提车的视频，这个是为了增加客户的信任，同时可以在这类视频可以增加一些话题，我们要清楚一件事，并不是每个人都去4S店买过车的，要把客户当小白，可以在提车视频中讲解一些提车的注意事项。

第三步：账户搭建，主要就是 头像、昵称、简介、头图。头像可以用真人头像；昵称要垂直，体现行业关键词，就是某某干什么的，简洁明了；简介中介绍自己能提供什么样的服务，体现内容价值，有价值传递，简介里就不要明目张胆的留联系方式了；头图呢，就是抖音或者小红书个人主页最上方的图片，这个是可以更改的，一般可以用通用的“关注我”。

第四步：超级符号，就是让用户记住我们。这个可以是你每个视频中必须说的一句话，也可以是每个视频肯定出镜的产品或者形象，也可以是昵称，超级符号可遇而不可求，并不是每个人都能做到的，比如“papi酱”，“大logo”，“鸟啦啦”...这个不强求,可以在做的过程中去挖掘。
