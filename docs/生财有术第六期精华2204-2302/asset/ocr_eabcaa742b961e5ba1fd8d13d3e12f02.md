去年我给长白山鲁能的新媒体部门讲小红书，他们也觉得要养号。

我说现在就是滑雪的旺季，用户搜到你的内容，就是带着需求来的，不然也看不到你，你养号做什么？等着明年滑雪再来找你吗？

本身在内容获客的逻辑里，每一次浏览和触达都是针对目标用户的一次连接，我就是冲着交易和提供服务来的，既然连接了，用户有需求，你能提供服务，为什么还要扭扭捏捏地等“1000个粉丝”再说呢？

你发再多的内容就是争取一个和目标用户的连接机会，怎能轻易地擦身而过呢？

这是理解上常见的几个误区。

# 五、做好小红书的10个忠告

+   1.干货笔记引流、单条笔记承接交易，并不需要所有笔记都要带货，不是所有笔记都需要有好的曝光，笔记的目的很重要。

+   2.怎么写是战术，写什么是战略，清楚哪些笔记可以引导私信 可以评论，可以转化，每一篇笔记都要有目的，目的出发---结果导向，中间填充的是手段和方法，否则越做越迷茫，浪费了时间。

+   3.先模仿再创新，模仿解决70%的问题。

+   4.100篇平庸不如一篇精雕细琢。

+   5.比你要什么更重要的是知道平台需要什么？用户需要什么？创造用户和平台都喜欢且需要的内容，站在平台的角度和用户的角度，不要站在自己的角度思考。
