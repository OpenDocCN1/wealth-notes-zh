# # (精华帖)(228赞)低成本创业，2万的私域宝妈好友变现超100万的思路分享

作者：小白

日期：2023-01-09

你有在抖音上刷到过胎毛纪念品的视频吗？会不会联想到这是一个低成本创业的项目？

我也是机缘巧合下发现这款产品市场需求大，网上做的人很少，只有一家淘宝店在做，而且销量很高，从评价上看用户反馈也不错，是一个很好的机会。

而且投资很少，试错成本低，去阿里巴巴采购材料包配件只需要几百元就可以满足需求，大头其实就在包装盒定做，也就只需要几千块钱就可以搞定，所以做这个项目最初总投入不到一万元，我一般比较喜欢做小投资的项目，就立马行动了起来。

做胎毛纪念品的用户基本上都是刚生宝宝的宝妈，或者即将生产的宝妈，这个时候的宝妈对胎毛纪念品的兴趣最大，都想给孩子制作一份有意义的纪念品进行长久保存下去，所以人气比较高，一款产品价格100-200元，另外包含亲子款、一家三口款等，这样一单的客单价就做到了400-500元左右。

结果从抖音导流2万私域的，都是精准的宝妈好友，完成了7000单的胎毛纪念品变现。

再结合私域流量用户分析，刚生宝宝的宝妈基本上都会在家带孩子，没有办法工作，对副业赚钱需求比较高，所以也会带她们一起做副业赚钱，由于之前有过胎毛产品的成交，产品没有质量问题，有一定的信任基础在，所以大大减少了转化成交的成本，完成了30万+的变现。
