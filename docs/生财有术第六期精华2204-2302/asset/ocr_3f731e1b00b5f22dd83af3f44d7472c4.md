这就是正确的事重复做，最后就能出来的效果，这句话是有数学依据的，概率计算可得出。反过来就是，澳门你总去，一定输。

# # 3 边际成本低

边际成本是经济学和金融学中的词汇，先看定义：

边际成本指的是每一单位新增生产的产品带来的总成本的增量。

这些都是学术型的定义，轩辕来拆解下：

+   1. 持续做，你的成本投入（可能主要是时间），是越来越多，还是越来越少？
2. 每复制多一个，你的成本投入大不大？
3. 赚每100、1千、1万，你的投入是否成比例上升的？

答案是啥，显而易见：

+   1. 需要越做越轻松，投入时间能越来越少，甚至后期把部分环节交给合适的人，自己时间投入能极少或为0。
2. 复制用不了多少成本，可以快速复制。
