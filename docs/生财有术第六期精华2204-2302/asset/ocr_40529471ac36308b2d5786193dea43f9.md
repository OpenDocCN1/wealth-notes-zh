# H5 （4）SEO 标题简介优化

如果你日常熟悉谷歌的SEO，YouTube上手会非常的快，大体上他们是一套逻辑。

几个重点 SEO,

+   1. 一定要简洁精准
2. 不要堆砌关键词
3. 说人话

在标题里可以把你的系列名字写上，也可以在末尾用1，2，3来表示。

比如说。张三笔记。张三杂谈。张三语录。

这样的好处是机器可以自动识别出你这些视频是属于一个系列的。

简介里的内容要精准，同时也要丰富。

+   1. 首先用一句话说明，你这个视频讲什么
2. 后面可以补充视频的背景，链接到上一个视频
3. 如果你有一个独立站的页面对应着这个视频，把链接也写上
4. 最后也可以写上你社交媒体的联系方式，在哪里可以找到你
5. 特别长的视频，可以通过分段导航的方式做一个目录，方便跳到对应的段落，直接看内容。
