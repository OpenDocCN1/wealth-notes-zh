# 第七步，基础运营。

刚刚开始直播的时候，可能会没没人，前面进来的都是大头娃娃，这里各路英雄玩法不同，有的人会踢大头娃娃，有的人会留。最根本的还是要自己亲身实测，因为你会看到很多东西很多的玩法，只有自己测试看看效果好不好才知道，通过测试总结出一个自己舒服的姿势。

就像前段时间学抖音视频直播，很多学员会问，我这样行不行，我那样行不行，其实谁也没有准确答案，只能说去测，看看哪个方案效果更好，更明显。

这里说一个基础的运营方法，也是大家比较常用的，适合完全不懂的小白开播后的操作。

方法是：开播后，先不用管人多少，先播着，人数上来稳定在10几个人后，可以逐渐踢掉一些大头娃娃，人数如果还在上升，就持续观察稳定后的情况，发个福袋红包。如果没有上升，直接发个福袋，观察情况。
