# 案例 生财作业

【你在做或者想做的是什么项目】
做私域，主要是朋友圈，卖一款抗衰产品。
【你的目标是什么】
2022年，每月收入稳定在2000；
【目前进展怎么样】
处于产品自测阶段，还未有进账；
【做了哪些尝试】
目前，只是偶尔朋友圈宣传；有跟好朋友说这事儿；
【遇到的问题或者困惑是什么】
不知道如何开出第一单；
【希望被解答的问题是什么】
微信好友500，有没有可能靠副业月收入稳定在2000？

# 我们在进行什么比赛？

我们在进行「在微信生态内，通过私域的方式积累信任，从而成交」的比赛。

# 我们怎么什么得分？

得分点有两个

+   1. 私域规模

+   2. 信任强度

题主说自己只有500粉丝，那么「私域规模」这个条件不满足，答案是不行。

怎么才能行呢？很简单，先想办法扩大「私域规模」啊。谁规定你的微信好友，永远只能是500人呢？有时候，我们以为是质量问题，其实是数量问题，量变引发质变。
