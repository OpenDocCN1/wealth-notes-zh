# # 1. 主播的招聘

# 1）英语四级以上优先

英语越好，和粉丝互动的内容也就越多。越容易获得粉丝的认可。当然如果英语没有 那么强。那么平时需要多准备些话术。

# 2）男主播优先

原因：

+   • 这种形式男主播只有几个，国外的女粉丝刷起礼物很害怕的！而且女粉丝消 费更偏感性，很容易引起榜一和榜二PK！
• 男主播通常可以夜间直播，这样一个直播间可以两个主播换播。

关于招聘难度：

因双减政策和Y情原因，其实英语类的目前非常好招聘。正常招聘，我一天基本可以 收到 3 至 5 份可以面试的人员。

# # 2. 主播的培养

1） 先读 TikTok 社区守则 （很多主播账户被封就是因为主播连社区守则都不读）

守则传送门： [https://www.tiktok.com/community-guidelines](https://www.tiktok.com/community-guidelines) （需要海外的网络）

2） 主播常用话术培训

三段论：第一段：表示欢迎（welcome to my room...)  
第二段：互动 （wow, you have many follower...)  第三段：认可 （I love your  make up...)
