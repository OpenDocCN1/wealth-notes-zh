# H5 3、制作内容模板

一般图片都是用创客贴，视频就是用剪映。做好模板之后，每次替换对应的板块，就可以快速输出新的内容。

这种账号，主要做的就是量，在发上几篇，确保这种模板输出的内容，在平台搜索是可以搜得到的情况下，每天发100、300篇或者更多，可以做短期内快速看到效果。

# H5 4、如何引导客户添加到私域

+   1、抖音可以认证蓝V，蓝V可以直接在主页留手机号（抖音账号可以认证到一半，然后不缴纳认证费用，这时候账号会有添加手机号的权限，想节省费用的可以试试）。

+   2、抖音的简介、封面、合集都可以添加联系方式，新账号添加上后容易提示违规然后被清除，可以在账号做了一段时间后，权重高之后添加。

+   3、可以做一篇引流的视频或者图文置顶。

+   4、小红书对引流卡的很严，可以拿一个账号发布联系方式，然后用矩阵号收藏引流笔记。

# H5 5、账号养号及运营情况

不需要养号，账号注册下来就可以开始发，亲测抖音一天发个十篇、二十都没什么问题。只要内容过关，保证搜索时能展示出来就可以了。
