# 二、我在短视频平台是怎么挖掘精准客户的

其实这部分内容，简单来说，就是给每个宝妈准备两个账号；之后用个人号搜索关键词，找到大量做到比较好的同行账户，并进行关注；最后在同行账号的评论区或者直播间找到潜在客户，用工作号去搜索、关注、私信。

# 1. 短視頻账号配置：

既然决定要做，那就要先对账号进行配置。

每个员工我都配了 3 个工作号，1 个个人抖音号（快手同步），作用分别如下：

# 个人号：

跟普通用户的抖音一样，随便发几个视频就行，不要求视频内容质量。个人号通过搜索关键词等，找到大量做到比较好的同行账户，并进行关注。

# 工作号：

当成微信朋友圈来发。

主要内容：

+   - 在工厂接待客户的视频；
- 客户现场扫码付钱的签单视频；
- 工厂的生产视频；
