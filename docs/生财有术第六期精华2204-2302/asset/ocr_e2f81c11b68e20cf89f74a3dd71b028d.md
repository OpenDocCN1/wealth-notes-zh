# ## 4. 这项目适合谁做？

+   1) 对拉新项目好奇的。自己注册平台，自己薅自己一遍试试。

+   2) 手上有网推资源的。比如自己有不少粉丝的公众号；自己有些网络兼职粉丝群、宝妈群、推广群、社区群、同城群等等。

+   3) 有地推资源的。自身有招聘能力，做劳务招聘的，做技培老师的；自身有办公室并且具备人流量的，比如汽车工厂宿舍，做外贸生意的、开菜鸟驿站的等等。
