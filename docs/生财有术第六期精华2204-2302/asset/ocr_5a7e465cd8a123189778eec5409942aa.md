# 三：人群痛点型

公式：人群+痛点+如何+解决方案

怎么去用：针对人群的痛点进行提问，然后根据正文，后面给出解决方案，核心是问题需要针对痛点去提

+   *   举例：淘宝新店不刷单如何引流？你得想明白这件事

*   举例：实体店生意惨淡怎么办？怎么引流客源最快？
