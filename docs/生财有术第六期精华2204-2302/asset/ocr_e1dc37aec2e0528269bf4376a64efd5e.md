这对初入创业的人是个极大的考研。

如何快速修复坏情绪呢？打破自我限制呢？

关注到正向的事情，关注到好的事情，同时接纳坏情绪，接纳负面，并去找到解决的途径。

# 17、有迭代生长能力。

人生就是不断进步的过程，很多人一套产品吃过红利了，却忘记了自己也需要不断迭代生长的。

每年都要不断有新的产品和内容出来，而不是指一招鲜吃遍天下。

这就像我们在饭店点菜，每个月还会有新品出现。

人的成长也需要不断向上迭代生长。

# 18、持续收入模式的终身事业，坚守长远目标

有时候短期的变现，并不是能力的体现，而是时代带给我们的机遇。

我们需要找到一份以热爱为始，可以去守的终身事业，并能持续不断带来收入的事业。

成大事者必胸怀大志，而往往出错的时候是出在了一些小水花的溅起。

小水花溅不起大浪，却容易迷失方向。

坚守大目标。

# 第三，强健的体力

在创业初期，模式还没跑通前，永远会觉得时间不够用，点灯熬夜是必不可少的，甚至会减少睡眠时间。

这个前期的煎熬一定需要具备一个强健的体力。抗摔抗打的体格，才能迈出初期第一步。
