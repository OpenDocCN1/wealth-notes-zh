# ## 二、谷歌国际International SEO

国际 International SEO 通常指跨越多个国家的 SEO 策略，其实不是所有国家的搜索引擎都使用谷歌，比如中国主要用百度，俄罗斯主要用 Yandex，韩国主要用 Naver。

但海外大多数国家的主要搜索引擎都是 Google，Google 在海外占据了超过 90% 的搜索市场份额，所以这边我们主要讨论谷歌国际 International SEO， 也就是跨越多个使用 Google 为主要搜索引擎的国家的 SEO 策略。

# ### 2.1 实施谷歌国际 International SEO 的途径

国际化 SEO 要考虑是否多语言， 多国家和多网站的问题。比如，你现在有了一个国际网站www. [domain.com](https://domain.com/)，你该如何部署你的地区网站。

通常你有三个选择：

+   1. [domain.uk](https://domain.uk/)

+   2. domain/uk/

+   3. uk. [domain.com](https://domain.com/)
