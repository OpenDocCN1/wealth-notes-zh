封面的设计应该要反映你的品牌形象，搭配你的个人风格。显然你不会用水彩画去描述硬核的登山技巧。

### 3. 定期复盘，做好下一步计划

当你做完上面几步之后，你应该也经营账号有一段时间了，你对整个项目应该有一个宏观的感受。

你应该可以清晰的看到，你花了多长时间，花了多少成本，做了多少视频，数据量又是怎样？整体的数据是否在增长？

根据前期定下来的目标，比如在一个月，两个月，三个月，要做到多少粉丝多少观看量有没有达到？

如果没有达到，是什么原因没有达到？那目前的成本开销是否支持你做下去？你是否有其他的盈利的业务来支撑你前期的投入？

如果三个月没有做起来，六个月也没有做起来，你是否能够接受整体的损失？

如果项目有增长，但是增长比你的想象比你的预期要低很多，还有什么方法没有试过，还有什么渠道没有用上的？

这些问题我相信在日常其实你都会思考。但是通过定期的复盘，你会有一些更精准的数据支撑。

不同的项目不同的情况，如果你只是用YouTube作为一个分发平台，那对你来说其他的都不太重要，闭着眼睛直接发就可以了。

### 2. 深挖不同内容种类

当你开始有一定经验之后，你对你的内容一定要有更高的要求。我们可以在视频的深度和广度上进行提升。

*深度* 上你可以对内容进行深挖。做别人没有做过的角度。

比如大家都在说手机性能那么好，摄像头像素那么高的时候，你谈手机的使用体验。找到你所擅长的角度，去做有自己特点的内容。

*广度* 上是开拓更多的内容。比如你今天是做体育的，专门做足球的。在临近世界杯的时候，除了做正在发生的事情。

你是否可以做关于每个球队的专题，人物的专题。甚至是赞助商的专题。如果你能提前一个月把内容做好，那大概率你会有很好的流量。

比如说你一开始是做创业内容的口播。这个时候找来 **10** 个创业者来讲他们成功和失败的经验。

当你采访完这 **10** 个创业者之后，你是不是能够总结出一个创业避坑指南。

整体内容瞬间就丰满了，就像填坑一样，填到后期，你就造出了一个高楼大厦。

我们的项目就是这样做的。

我们前期通过对新的教育政策的分析和解释，帮大家做出更好的选择，做 *时事类的解说*。

接着做了特殊院校*学生*的采访。

比如说一些日常你不太常见的职业，面包师等，让你知道这个职业学习的过程会经历什么，给你一个未来的方向。

*创业*学生的专辑，他们为什么要创业？在什么时间点做了什么决定，过程是什么样？失败还是成功？

*合作伙伴*的采访，他们有一些什么新的项目可以给学生什么样的帮助。

*How to*视频，怎么领取补贴。当地政府对学生政策上有一些补贴，满足要求的同学可以领取。这一条主线把学生校外生活的信息填充的非常饱满。

![](img/a50ad26370b1cd7f67818735c6f556a8_4506_0.png)

另一条线是，K12教育内容。除了校外，我们决定把内容延伸到校内。

我们找来了在职的教师。日常的教学内容他们都已经有 了，我们只负责录制、剪辑和上线。当然有一个同事会负责将他们的稿件数字化方便拍摄和剪辑。

每个老师的教育方法不同，有的人1分钟可以说清楚，有的人要铺垫2，3分钟。

当我们测试了上百条视频后，根据数据显示，5分钟的视频，大家只看3分钟。3分钟的视频，大家只看1，2分钟。后期对于大多数视频，我们都力求不要超过5分钟，能简单说清楚就不要过度铺垫。

这一块就是持续输出，做到100%内容覆盖，花了2年上线了3000+的视频，实际数量还多一点点。

## 四、走前人未走过的路

做这个项目的时候，没有竞品可以对标，K12没有那么火，国内巨头也没火。很多时候都需要自己去思考能做些什么，下面两个都是探索性项目，结果带来了10倍以上的收益。

### 1. 发掘市场空白-填补空白-360度驾考实录

在我们覆盖的K12的内容和校外生活的内容之后，频道保持着稳定的增长。同时也在思考怎么样将视频的经验复制到其他技能内容上。

法国路考是上路驾驶20分钟，每一个路口遇到的情况都是不可预见的。你要在不同的情况做出正确的操作，没有经历过的都会有未知的恐惧。

在我看别人跳伞视频的时候想到，能不能通过360度的视频来展示整个路考的过程？这样用户可以直接看到整个考试过程中发生了什么？为什么会这样做？如果一遍没明白，还可以回头不停地看。

提出想法之后领导也表示非常感兴趣，直接开始测试。

| 项目 | 详情 |
| :--- | :--- |
| 项目成本 | 1W |
| 测试时间 | 1个月 |
| 录制时间 | 2周~3周 |
| 后期时间 | 2周~3周 |
| 回报 | 10倍以上 |

对于这种测试项目，通常都是没有太多预算的。先买了市面上当时为数不多的360度相机，能用，但是效果一般，只是为了先看一看可行性。

**难点：** 要解决的安装摄像机的问题。

相机装在车外，虽然能够看清楚所有的路况，但是看不到个人的反应，无法看到考官是如何作出准确的判断和对应的操作。

相机装在车内。如何固定减震，收音都是问题。用的都是私人的车，没有办法给车进行内部的改造。

后来收音使用了另一套系统，后期制作的时候再加进去，经过一番折腾测试得到了可用的结果。

拿着可用的结果，找领导批了新的预算，买了一个品质好一点的360相机，开启了疯狂录制模式。

![](img/a50ad26370b1cd7f67818735c6f556a8_4520_0.png)

最后的结果是，我们是市场上第一个也是唯一一个做到360度驾考视频实操内容的。直接将其他竞争对手甩在了身后。

这个视频在我们的网站和APP都做了内嵌。用户在浏览视频的时候，直接给**YouTube**反向增加流量，提升视频权重。

**Google Play**的产品经理看到我们**App**更新时，觉得这个内容非常棒。直接给我们做了6周的首页推荐。

**App Store**也有推荐，力度小于**Google Play**。

**App**的下载量大幅的提高，注册用户激增，比我们在**Facebook**投广告换来的用户要便宜的多。

除开人力成本，这个项目单独采购设备的费用只花了不到1万块，其他都是现成的设备。

最后的成品视频最少有20条，每一条的成本只有500块。

现在回头看在制作上还有不少问题需要改进，但在当时我们完全是瞎子过河，边做边优化，没有案例参考，也不知道是否会成功。

### 2. 法国高考直播助力、媒体联合

前面不是我们覆盖了K12的教育内容。当时发现一个问题，就是很多学生来看了之后，他也不说话，他看了就走了，视频有浏览量但是没有互动。

为了提高互动率，让整体的数据更好看，我们就开了几期直播。

| 项目 | 详情 |
| :--- | :--- |
| 项目成本 | 人工成本+第三方费用 |
| 人员配备 | （前期）一个摄影，一个中控。（高强度时期）一个摄影，一个中控，一个产品经理，一个运营。 |
| 持续时间 | 1个半月 |
| 回报 | 10倍以上 |

直播的流程非常简单，我们会提前放出预告给大家，说我们周几几点会上线，请大家预约。
