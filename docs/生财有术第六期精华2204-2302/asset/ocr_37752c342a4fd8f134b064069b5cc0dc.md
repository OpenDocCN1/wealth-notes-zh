# 产品重点

# 重点1：用户体验流畅度

变现闭环中吸引用户自主传播，并且留住付费用户的关键点就是用户体验。

所以，设计的重中之重就是必须要保证用户有一个完整的体验流程。

> 模板分类->选择模板->上传照片->生成视频(非必要：插入广告加速选择)->最终效果->直接分享/下载低清晰度视频->付费下载高清无水印视频

流程中的每一个步骤，切记把不需要出现的按钮统统去掉。唯独留下最重要，做的最显眼的按钮引导进入下一个程序。

如果某个页面必须要由多个按钮，就应该分出按钮权重。一般来说，需要出现多种选项的页面都出现在最后。

绝对不要偷懒将按钮设计的都一样，用户会迷茫。我们应当为用户排除阻碍，让他们获得心理价值，从为了继续体验而消费。

即使用户拒绝付费，我们也可以借鉴目标产品的那一套。直接将用户跳转到模板选择页面，用更多选择留住他们。
