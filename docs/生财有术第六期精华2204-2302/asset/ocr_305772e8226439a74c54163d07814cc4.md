下半年在淘宝我们付出了远高于上半年的精力和补单费用，但收获甚微；以前总以为自己是够努力赚的是实力的钱，经历了上半年几个月淘系红利期，看过了暴力的视频号，再到美团电商两个月时间超过了淘宝店群一年多的努力，才明白我们赚的钱都是红利的钱，这是今年最大的感悟之一。

# 3、边干边学边输出

这是我特别喜欢的一句话，这句话涵盖了做好一个互联网项目的两个核心要素：

+   1）完成比完美更重要，不需要全部搞懂，先动起来，哪怕只有60分。

+   2）多分享多输出，太阳底下没有新鲜事，认为自己的某一项技术和骚操作市场独一份是一种非常愚蠢的行为；输出可以让我们像店铺链接一样获得更多曝光，这种真诚的交流获得的信息密度能让我们在赚钱的路上发生基因突变。讨喜的是在上月淘宝业务也找到了新的成功案例，过往一年多的交流和分享，这位老板毫无保留的把自己付贵近十万的新玩法分享给了我们甚至还给我们做了飞书会议培训。

# 4、不断强化网感

发现美团电商项目红利，更多是基于过去一年的积累。之前几年对于很多圈子的精华帖仅仅是停留在了刷的层面，而最近的一年我开始每天写读后感，拆解互联网项目和日常业务心得感悟复盘，这种不断的刻意训练，商业敏感度有了明显的提升。更意想不到的是，一年下来线下很多老板朋友加入了打卡，我们一起把断更的小惩罚作为我们小圈子聚会的小金库，我们几乎每个月都聚一次分享业务新知，创业路上并不孤单。

历史在不断重演，不管是在商业还是其他领域，抓住转动的历史车轮，我们一起加油，做时代的弄潮er~
