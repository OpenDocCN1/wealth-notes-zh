# # (精华帖)(188赞)你看不起的项目，别人正在偷偷赚钱

作者： 阿锋，我们的老朋友

日期：2023-01-06

好久没分享，马上过年了，给大家分享个实操思路，多关注一些不起眼的项目，说不定会给你惊喜。 你看不起的项目，别人却在偷偷挣钱，远比想象中的滋润。

2022年年初就注意到有一大群人在做中医这类短视频带货，以书单号为主，4月份转到视频号，那时候想这个肯定是短期项目干不长久，说实话有点看不起。没想到被啪啪打脸，一直做到现在，甚至一个朋友单人可以月入十几万，这个利润是接触到的绝大多数项目都不具备的。

12月直播团队解散以后，开始跟大量朋友交流才发现，短视频带货原来这么容易月入过万，并且有朋友也跟我一样的想法，最初都是看不起的项目，现在反而扎进去全身心的做这个。说干就干，没想到1周就出效果了，运气好还小爆一下，所以给圈友分享一下这个思路，有时候财财圈友分享的一个小项目，反而可以让你今年值得全力以赴招员工去干的。

说明一下，学会短视频打法，可以一通百通，反正都是免费流量，只要选的品免费流量别人能跑出来，你也大概率能跑出来。最重要的反而是学会复制粘贴，生财里最不缺项目，找到自己的一个突破点，今年破100万收入问题不大。感谢 提供全方位的指导。
