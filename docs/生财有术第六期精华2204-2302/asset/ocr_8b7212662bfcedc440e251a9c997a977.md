实不相瞒，我卖了 2 年保险，我亲戚都不知道我卖保险，省报记者卖保险去，上谁那都觉得这人有点问题。由于父母不阻拦，我爸妈统一对外口径是，和别人创业去了，具体干啥不清楚。

别人问我，我就说在一个公司打工，业务比较复杂，一句话说清楚。创业初期，集中全力，不要分心。

# # 五、觉得别人都是大神，自己干啥啥不会，怎么破？

终于进入正题了，我进入生财第一年时候，那情绪就是焦虑带着愤怒，焦虑是为啥别人都赚钱，别人啥都会，愤怒是干嘛我要看这些，本来也就很烦了。

拜托，你是新手，你怎么能指望上来就和别人一样的结果，一年级小朋友和大学生一起考高等数学，你说谁赢？你只看到了别人赚钱，却不知道对方的背景和积累，这让你妄自菲薄。

新入场第一件事一定是承认自己的笨拙，任何人脱离舒适区都会不适，要给自己适应时间，我一开始搞知乎，真的是硬着头皮搞了半年才开始赚钱啊。
