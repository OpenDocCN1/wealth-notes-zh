# 拍摄说明

我们会在你接受合作后将产品寄出，接收产品后首先查验是否和聊天中提及的产品数量一致，并及时试穿是否合身，拍摄过程中请维持服装整洁，合作完成后需将产品寄回（邮资到付）

小姐姐需在接收产品2日内开始拍摄，并在规定时间内交付全部照片。

拍摄场景尽量选择光线充足的瑜伽室，有氧操房内，拍摄模仿下面的示例

一个文胸（上衣）+一个裤子称之为为一组搭配，一组搭配至少拍摄7张照片，要求2张全身照，1张文胸特写，2张裤子特写，1张服装展示照+服装细节照，其余可增加训练中拍摄的照片
