说完了客户，我想来聊聊工厂的对接。我们不是自有的工厂，属于小经销商。

合作方式也很简单，员工拿到客户需求，找工厂报价。工厂报最低出厂价，我们加价 **30%**  报给客户，最终成交利润会在 **25%**  左右。

为了保证工厂的报价合理，我考察了大概有 3 家工厂，每个月订单都会分散给这三家。在报价、对接、售后等多个维度，三家工厂直接会相互牵制。

成功交付后，客户满意度比较高的，或者有转介绍的，我们会给相应工厂再返 **5%**  的合作愉快金。

客户满意比较差的，我们会踢出一家，再找一家新工厂合作，整体上一直保持着三家工厂合作。

我们实行员工提成阶梯制，**3%-6%** 不等。交付之后，会给相应一起对接的工厂技术人员，分 **1%** 的奖金。

到这里，其实整个项目的模式就已经讲完了。最后，我还想再跟大家简单聊聊这个方法下，我认为存在的弊端跟可能性。

# ### 弊端:

+   1) 方法相对简单，过度依赖短视频平台，有可能后续封控会越来越严，导致引流失效，毕竟平台对倒流微信的政策在;  
2) 产品流水相对还好，但是净利率相对较低。

# ### 可能性:

同样的方法，可以挖掘不同的产品、拓展不同的平台去操作，也是很有想象空间。
