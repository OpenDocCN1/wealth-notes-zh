我们只需要给他们提供高转化率的货就可以了。这个时候我们就可以找到跟我们目标达人相近的直播间，数据做的好的，找到他们最近卖爆的款，提供给他们，给他们把最近的数据给他们看，因为一些爆款他是自带流量的，所以转化率也会比其他的款式要高一点。

# 七、容易踩的坑

抖店招商的是非常适合小白做的电商项目，它的逻辑很简单，你自己把自己抖店里面的商品开好佣金后，挂在精选联盟里面，然后去找抖音里面的达人给你带货，达人赚佣金，商家赚利润，不管你是做无货源还是自己的货，都是最简单最容易出单的。

做达人招商最容易踩的坑也有很多，字在这里帮大家总结一下我们刚开始做抖店招商的时候亏了 6W 多经验，能帮大家省钱。

# 1. 定价的问题

抖音小店的商品售价计算公式如下：

售价=供货价 + 快递费 + 毛利 + 达人佣金 + 平台服务费 + 运费险

+   ①平台服务费：开店的前一个月是技术服务费是 1% ，过了一个月后就会恢复，不管你有没有过新单期。

+   ②毛利率：计算售价时毛利率最低标准是 10% ，千万别低于 10% 去跑，这是一个保本线，去年 11 月份我们就是因为踩了这个坑这个大概亏了有 3W 多。
