# # (精华帖)(85赞)2023 年币圈不能错过的几个热点，抓住热点就会抓住市场的主旋律

作者：金马

日期：2023-02-11

最早这个问题是张潇雨老师让写一下2023年对币圈的预测和展望，但是因为我不是太熟悉宏观经济，所以我从币圈的周期预测下2023年，需要注意，我的预测都是非常主观的，经常是"屁股决定脑袋"的判断，很可能是拍脑袋。

**2022年年底**：真没想到今年会这么差。

**2023年年底**：真没想到今年会这么好。

2023年整体是比较期待的，如果看币圈的4年周期，2023年整体处在周期的上升期，所以是充满希望的一年，虽然不一定有像2019年那样有那么大级别的暴涨，但是等2023年过完再回看K线的时候，大概率是一个向上的趋势。

不过，看到了趋势也不一定赚钱，就像2022年初的时候，我也对2022年的大趋势不看好，觉得2022年不会好过，但是一来没想到会“那么糟”，二来还存在侥幸心理觉得"可能会有别的剧情"，导致2022年资产市值回撤很大。所以，判断趋势后，更重要的问题应该是，2023年是充满希望的一年，我该如何跟着趋势前行（强暗示）？

**2023年不能错过的是几个热点，抓住热点就会抓住这个市场的主旋律。**

首先看看ETH，因为我 ETH 现在仓位最大，随着2022年9月份 ETH POS 合并成功，2023年3月份会完成上海/Capella升级，主要会完成 ETH Staking 的资产的 Withdrawal 赎回，现在这个事情是"利好"还是"利空"还是有些分歧，很多人觉得赎回开启后会卖盘砸回硬盘，毕竟很多人抵押的时候价格比较低，因为信标链在 2020 年12月份就上线了，但是如果了解其中的数据细节，以及本来就可以很方便进行二级交易的stETH、BETH等，还有“线性”的赎回机制（按现在的ETH每天最多可以赎回5w+个），这些事实都让"赎回硬盘"站不住脚，所以如果稍微把眼光放长远点去看，上海升级一定是利好大于利空，Withdrawal 功能的上线让ETH Staking 生态变得完整，完整的生态才会有更多的资金愿意进来抵押，毕竟现在 ETH 的抵押率并不高，大约16%。
