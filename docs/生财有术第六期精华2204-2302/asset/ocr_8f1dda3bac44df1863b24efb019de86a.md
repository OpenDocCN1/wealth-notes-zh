作者： 森林

日期：2022-05-07

来了，大航海结束后，说好要免费送给大家的抖音商业 IP 2.0 课程，上线了。

大家好，我是森林，这次抖音商业 IP 2.0 课程的出品人。

就在半个月前，我们刚刚结束了为期 45 天，主题是「直播+课程」的抖音商业 IP 2.0 大航海，在这里再一次感谢船队的 @高放、@刘佳 两位船长。

新来的朋友可能还不知道，老朋友就比较熟悉了。我再说下这次航海的成绩：**1669** 位船员一起航行，累计变现超过 **984** 万元。其中有一位圈友 @水松张阳 在本次航海里变现了 **1000w**，但由于他已经是**有经验船员**，来参加大航海主要是看看大家怎么玩，故不作成绩收录。

在这期间，我们沉淀了大量的资料和船员的实操经验，也做了一份航行指南用来承接这些内容，截至目前，它的访问记录达到了 **42110** 次。

但是，也有船员向我们反馈，内容太多了，要不是因为有船长和教练们带着学，很难看完。

更别说那些还没上船的圈友了。

为了解决这个问题，我把这 1600+ 名船员的实战经验，航行过程中沉淀出来的一手资料，无数教练积累的工具包，避坑指南等，经过重新梳理、打磨，整理成了这份课程。

你可以把它当作是一个学长笔记，可以通过各个模块找到你需要的内容，也可以按照学长们的学习经历，重新走一遍，完成他们做过的作业。

那么，怎样领取这门课呢？
