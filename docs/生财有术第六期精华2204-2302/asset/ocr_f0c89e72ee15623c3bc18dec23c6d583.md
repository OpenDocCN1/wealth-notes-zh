# 1. 什么是达人？

这里所说的达人其实就是抖音上做带货的主播，达人也有等级划分，我们一般按照达人直播间账号的等级和主播的带货能力（场均 GMV ）将主播分为尾部、腰部、头部主播。

一般来说一个店铺每天只要有三个腰部主播或者一个腰部一个头部主播来给你带货，你的店铺每天都可以稳定千单以上，每个月的 GMV 也可以做到 100W 左右。

# 2. 如何区分尾部、腰部、头部主播？

这里以童装主播举例：主播档次的高分主要是靠账号的等级、直播账号的场均 GMV 和直播平均在线人数来划分的。

尾部主播的等级在 LV0-LV3（不包括 LV3 ）之间，场均 GMV 在 0-10000 之间。
