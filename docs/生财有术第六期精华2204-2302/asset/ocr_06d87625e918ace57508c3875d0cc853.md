# 6. 可能遇见的风险点有哪些？

我现在给大家讲解一下这个项目的运营方式和现在其它人在做类似项目的痛点。

痛点一：直接搬运明星和达人的视频混剪容易判搬运，轻则违规降权没流量，重则永久封号；

痛点二：没有达人肖像授权好不容易爆视频举报下架视频，转化高的带货视频不能投放广告；

痛点三：大量人使用素材重叠度高，没有播放，容易触发系统判搬运；

痛点四：拿了授权后不懂得如何运营，每天浪费时间没有产出成效；

以上这个四个问题都是现在大量人遇到的。
