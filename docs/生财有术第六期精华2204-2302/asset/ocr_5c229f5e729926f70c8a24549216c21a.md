# # (精华帖)(43赞)教育规划类项目，为留学生群体提供语言、升学、求职等产品，实现单人单月产出增加10W+

作者： 徐迪驰

日期： 2022-12-07

留学生群体在疫情前连年增长，有近50万的留学生，其中90%以上都是自费留学。

虽然2020年疫情之后人数降低，但总体大家对学历的诉求越来越高、国家对出国留学的鼓励持续保持、以及目前整体就业形势差 & 考研人数暴涨导致国内硕士竞争激烈，因此整体的学生留学需求还是有的，而且需求还在加剧。

随着疫情政策发生变化，总体还是看好国际教育行业的大发展。

圈友们好，我是徐迪驰，之前深耕国际教育、职业教育方向6年多。今年通过朋友推荐来生财，收获良多。

今天主要给大家分享针对留学生群体，这一类高净值用户群，怎么通过语言、升学规划、职前教育等产品满足留学需求，下图是核心业务逻辑。
