+   2、 国内保险市场需求量大，业务员素质普遍低，即便是达到 **60** 分的专业程度就能秒杀一众业务员，市场空间大；

+   3、 国家扶持的朝阳行业，政策风险小；

+   4、 最重要的，这个行业有复利效应，越有经验越值钱；客户会不断积累，服务的好客户会介绍客户，行业天花板高， 年入千万的顶级业务员也有。

+   5、 保险经纪人是一份自由职业，工作赚钱的同时还能方便照顾孩子，我似乎看到了兼顾工作和家庭的办法。

基于上述思考，2018 年底，我决定开始干。正如我上文分析的一样，如果我干不好不是行业的原因，只有我自己的原因。

在事业启动阶段，如果让我总结一句话送给大家，那一定是：勇气是这世界上最重要的才华。从我的经历里，你应该可以看出 来，我是个喜欢折腾和突破的人，但这是非常反人性的，因为很少有人会主动愿意去改变。改变，意味着要去舍去现有的一切，去寻找一个不可知的未来。而促使我改变的一个强大的源动力：就是对现状的不满， 这种不满让我痛苦到无法自拔。

所以，就像我选择去做保险，我一开始并没有认为自己能一直做下去，甚至觉得失败的 概率极大，因为我并没有销售经验，也害怕做销售。支撑我下决心的，是我认为这个选择是我在那个当下能够逆风翻盘的最佳选择。

我经常会想自己临终前会怎么评价自己：我宁愿是我尝试了很多，虽然未成功，但成长了很多，而不是我后悔当时没有做什么事。毕竟，试试成本不高，错过损失很大。
