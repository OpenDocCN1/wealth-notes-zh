# # (精华帖)(94赞)亦仁问答：如果只做好一个点，哪个核心点让参与者更有收获？

日期：2023-02-15

提问：

亦仁哥你好。我的问题是：小范围主题分享，如果只做好一个点，哪个核心点让参与者更有收获？

我介绍下背景。最近组织织圈友线下聚会，大家提出以后定期组织，每次请一位圈友做主题分享。第一期大致敲定一位做**tiktok**直播东南亚市场2年多的女生，现在一个月**GMV**大概**10w**刀。这个事中参与方的价值：①分享者可以借机梳理自身业务逻辑，并获得其他人的反馈。②参与者可以了解赚钱玩法，获得启发。③我个人能收获组织此类分享的流程，作为MVP产品，可以复制到餐饮行业。

这个分享在取得分享者的同意下，我想录制视频，分享到生财。也是跟上社群推动视频分享的动作。

回答

非常棒的想法，支持录视频分享到生财。

小范围的主题分享，如果只做一个点，哪个核心点让参与者更有收获？

我认为是让参与的每个人都要真诚分享，不一定要很干货，但需要真诚，然后持续组织活动，持续的把不真诚的人都踢出局，组织的能量就可以起来了。人真诚不真诚，你是很容易感受到的。

另外，有人问我，组织什么样的线下活动是被生财官方支持的？

我就一句话： 因为你建的小群，或者你组的活动，参与的生财圈友对生财有术的认可度是增加了还是减少了？

增加或者减少，你其实是很好判断的，群里面的人也是能感受到的。

我反对的是，打着生财圈友的名义组织活动或者拉小群，但却不断有意无意的让参与者离生财有术越来越远，这样的情况我当然很反对。
