# 信息差二：各个渠道如何进行获客？

一般我们的获客主要以两种结果为目标：一种是获取客户的联系方式，比如电话、微信号等。一种是让客户添加到我们的微信或者QQ。

而平台是否可以留联系方式，一般会作为我们区分平台以及选择重点运营平台的依据。

比如可以留微信号、手机号二维码的平台：微信公众号、小程序、微信、微信群、微博、论坛、网站等，发布的文章可以直接留联系方式进行引流。

在留联系方式上比较严格的平台：抖音、快手、小红书、头条号、网易号等短视频和自媒体平台。
