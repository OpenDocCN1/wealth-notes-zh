百度和知乎上关于怎么开通stripe的文章已经很多，但目前没有有一个有实际参考意义。

目前可以比较确定开户能成功的，主要是美国stripe官方的一个白名单渠道，这个知道的人非常少。

美国stripe官方这个白名单渠道在国内也是我们独家代理对接。

开户成功后，还有复杂和漫长的养号/养通道的周期。

根据我们的经验，把一个stripe成功申请后，再通过重重审核，进入可以跑大流水的完全体状态，要经历下面几个状态：

1 kyc ok

2 face check ok

3 stock check ok

4 first withdraw ok

5 all ok new

6 all ok growing

7 all ok major

其中1是初始状态 2 3 4不分先后顺序 5 6 7对应不用养量成熟度

具体的养通道的策略为：

5之前都是每天1-2单养号

从5开始进入养量

*养量第一个月每天500-1000刀

没问题进入状态6

*第二个月每天1000-1500刀

*第三个月每天2000-3000刀

*每个月比上个月单日加量20-30%

第6个月进入状态7
