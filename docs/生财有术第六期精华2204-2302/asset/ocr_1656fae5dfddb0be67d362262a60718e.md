胎毛纪念品包含项链、戒指、手链手串等，可以组合成情侣款对戒、情侣款手串、一家三口款手链等，另外也有一些车挂、钥匙链等配件，都可以把胎毛放进去进行手工diy，这些组合搭配都是提高客单价的方法，也提供一些定制款，比如在纯银材质上进行刻字，或者阿里巴巴上AB胶的模具也有很多款式，都可以定制出各种类型的纪念品款式。

如果宝妈没有时间制作，也会有代制作的需求，这里额外增加定制费，制作完成再邮寄给客户就可以了。

2. 产品从哪里来？

发现这个需求后，就直接去网上买了同行的产品回来进行拆解，产品包装里面有提供详细的制作流程，制作完成发现并不复杂，然后就开始根据里面的材料包去找货源，发现产品基本都是通过采购组装出来的，比如各种制作工具：银饰品、AB胶、模具、搅拌棒等等各种配件，都可以在阿里巴巴上进行采购，这样整套产品的材料包就凑齐了，产品包装、手提袋就找到本地的包装厂进行定做，整套产品所需要的材料基本上就这样顺利解决了。

如何才能把产品款式找的更全面：像材料包中的制作工具，量杯、搅拌棒、打磨棒、模具等等，提供的厂家比较多，都可以很容易采购，像主产品都是纯银材质的半成品，货源厂家也很多，但是同款很少，就可以通过阿里巴巴拍照识图功能进行找同款，如果阿里巴巴没有，再去淘宝上通过这种方式进行查找，基本上就可以全部找出来所有的款式了。
