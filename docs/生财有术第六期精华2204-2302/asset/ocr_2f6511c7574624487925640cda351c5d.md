# ### 什么是账号权重呢？

账号权重就像百米冲刺的前10米，权重养的好，咱们接下来乘胜追击，取得好成绩的概率就会很大。如果权重养的不好，咱们也不是没有翻盘的概率，但需要比别人付出更多地努力，因为一开始你就被落在起跑线上了~

# ### 如何养小红书账号的权重呢？

一、先注册账号，推荐用移动、联通、电信三大运营商的实体卡注册，账号资料要填写完整，名字不要随便起，想好再写，因为小红书满7天可以修改一次名字，随便起后面改起来会麻烦~
