# # (精华帖)(221赞)亦仁问答：普通人赚钱，不用做宏观分析

日期：2023-01-24

# 提问：

亦仁，我现在要到40了，有两个孩子，教育费用比较高。我们两收入还过得去，但年纪大了，比较担心裁员或意外发生，不过没有想过要创业。👩‍👩‍👦‍👦我自己的工作比较轻松，所以想通过闲余时间赚点钱。如果工作没得做，也能帮家里补充家用，或通过自己副业找到工作——总之，不求赚大钱，但求平安小康生活。👩‍👩‍👦‍👦我有2个方向，都想做，也能持续做。最大的问题是自己没有信心，如果反馈太慢，可能又会放弃。这两个方向是：👩‍👩‍👦‍👦

+   1. 内容网站 - 担心自己不能持续创建好内容，在公众号写过，但是只有1000多粉丝，变现方式是生财有术佣金而已。担心自己的变现能力差。但喜欢写内容，而且网站可以放广告，联盟，长期赚钱潜力大。

+   2. 电商站 - 我没有做过，之前也一直抗拒，因为我不喜欢销售。不过做过客服，做过采购，做过管理，对公司整体运营，各部门职责都了解。在闲鱼挂着一个商品，是自己偶尔发现的好物，没有做任何经营，5个月出了13单，只赚260元。👩‍👩‍👦‍👦我想做内容，是因为自己喜欢写作，写作也帮助我提升能力。而电商似乎反馈会比较快，有反馈就会有钱赚。👩‍👩‍👦‍👦我担心自己是过于沉迷自己的内心，总想创作内容，但创作运营能力其实很一般，这几年都是跟风般努力，可能网站赚钱能力不够。

而以前不喜欢电商，可能只是自己的刻板印象，也以为自己做不了。👩‍👩‍👦‍👦我想问一下亦仁，你会怎么做，会怎么思考自己的选择？

# 回答

做内容或者做电商，这都是很宏观的思考方式，我自己要赚钱不会这么思考。

我的思考方式是，我在什么场合下，发现什么东西竟然卖的很好，看上去很赚钱，有啥壁垒，我能不能卖，从哪里开始切入，今天我就干点啥？

我认为，只有赚到过大钱的人再次创业，才有能力从行业角度去分析哪种更适合自己。

普通人赚钱，不用做宏观分析。
