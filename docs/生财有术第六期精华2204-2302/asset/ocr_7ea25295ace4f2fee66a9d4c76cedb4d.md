# 21、同一个领域，如何找到有竞争力的差异化定位？（定位篇）

今天有个微信好友跟我交流，他现在的一个卡点就是无法在自己的定位下找到新的竞争力。

其实这个问题之前很多人也问过我，比如说你的标签是“副业达人”，定位是帮助职场新人或者大学生通过副业赚到人生第一桶金。

OK，这个定位没有问题，但是做这个定位的人太多了，网上有大量做副业的人，一旦自己跑通整个项目，或者说跑通了多个项目后，就开始在这个定位下做知识付费服务，包括卖课程，卖付费会员，做各种训练营等等。

问题来了，全网那么多副业达人，你的核心竞争力在哪呢？你的优势在哪？用户为什么一定要买那你的课程或者会员呢？

我估计很多人都被这个事情所困扰，说实话之前我也被困扰了很长时间，好在后来我慢慢地想明白了。

> 记住一句话：同一个定位下，你在用户的心智中还有很多标签可以做。
