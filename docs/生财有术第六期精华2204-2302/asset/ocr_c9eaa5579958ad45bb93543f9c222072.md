# 9、不赚钱，也要做产品！（产品篇）

做一套知识付费产品，如果卖没没赚到钱，是不是就算无用功了？

当然不算！制作一套自己专属的知识付费产品，只是个人 IP 变现的一个途径，但不是唯一途径。你观察一下，自己身边只要是自媒体玩的不错的人，是不是都有一套课程，你甭管人家卖的好不好，但都有，对吧！（没有的，可能人家出书了）
