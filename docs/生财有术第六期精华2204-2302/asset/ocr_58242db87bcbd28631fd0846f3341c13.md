# # [精华帖](155赞)对话小白：算不清账，多少钱都照样慌

作者： 海程

日期: 2022-06-27

生财的老板们大家好，我是海程，生财四期的老圈友，擅长算账和规模化套利，之前写了精华帖《给两百多个老板算完账以后》 https://t.zsxq.com/03iQRjMbm

我的好朋友小白 @白一喵 做了一个访谈"小白的专家网络"，我很喜欢这次访谈，小白懂我，也是一个很好的提问者，在和他的对话里，回答我内心很多小问题，同时我觉得生财的老板们也可能对这些问题有同样的困惑，比方说：

+   - 方向感不足：大家都很努力的赚钱，张口就是一个亿，但并不清楚这个目标是否现实，用现在的打法能不能实现目标

+   - 安全感不足：每天在群里天天看到别人都日入十万、日入百万，只有自己没那么赚钱，久了感觉特别特别焦虑

+   - 控制感不足：有的老板有钱了，但心里还是非常慌，他知道生意有一些问题，但不能量化出问题有多严重/多不严重

因为我和小白延续我和小白来索聊《空无一物》的风格，所以访谈稿很长：

+   01. 通过算账知道自己在金字塔的哪个位置

+   **02. 人的命运看上去各有不同，实际上非常相似**

+   03. 从财务状况，看出行为模式

+   04. 盲目个人成长不能解决财务问题

+   05. 哪些人需要把自己的账盘清楚
