# # 趋势二、个体经济的崛起

有技能有专长的人，在小红书很吃香。

我身边有做演讲培训的，通过小红书分享沟通干货，2个月时间涨粉近30w，并且引流了2w+人到微信转化。

还有宠物博主分享养宠日常和干货，接广告接到手软，收入甚至超过了自己的主业。

再比如ppt制作、手帐制作、绘画、平面设计类的博主，在小红书也都有生存空间。

他们有的做课程卖课，有的接广告变现，有的是接单或多种变现方式结合。

而且这类博主的内容其实不难，不要求你有很高的文字功底，只要你有一定的图片审美，会制作好看的封面就可以了。

所以，技能型的个体，很适合在小红书发展。

有的小伙伴可能要问了：那没有技能的人怎么办？是不是就不能做小红书了？

没关系，请继续看趋势三。
