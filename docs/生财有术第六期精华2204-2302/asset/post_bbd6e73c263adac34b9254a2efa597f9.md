# (精华帖)(136赞)短视频换脸项目复盘（从App市场复刻到微信生态）

作者：荚子加油

日期：2022-07-21

来生财有一段时间了，一直潜水学习大家的各种项目。投桃报李~刚好前段时间在一个私董会内部会上分享过团队的一个短视频换脸项目。我花了半天整理，发出来供大家参考。

正文：

前阵子我们注意到，有一款换脸产品FaceXXXX，突然登上了App Store的Top3。也不奇怪，AI换脸每隔两年就要爆一款产品，ZAO、蚂蚁牙黑到FaceXXXX。

先进行项目拆解，下面是变现闭环：

![](img/a50ad26370b1cd7f67818735c6f556a8_1313_0.png)

目标产品刚发布的前几个月，知名度并不高。后来抖音忽然开始冒出一些带#Facexxxx标签的视频，而这些视频几乎都来自一些中小网红。

因此可以判断，目标产品团队是联系了一些小网红社群进行了大范围布局。

这种小网红发布一条视频的价格不高，而且能够大量发布#Facexxxx标签，辐射范围非常可观。对于初创团队，这样的打法是最经济实惠的。

毕竟视频内容并不难创作，也不需要他们进行拍摄，只要生成视频并配好文案发布就可以。价格控制在一条200上下，算比较适合。

目标产品在消费体验上也下了功夫。首先，整体UI就非常的干净清爽。素材都被整理归类，要找什么类型的换脸素材一目了然，节省用户精力。

整个视频制作流程的体验，全部都是为了最后一步——分享转发。UI设计中，抖音还拥有专用一键转发功能，可以说是事无巨细的在帮用户排除分享障碍。

另外一点很值得提的就是他们的付费页面。任何时候，只要用户选择拒绝，就会落地到模板选择页面。这个细节很好。

面对用户拒绝付费的引导是为消费者提供更多有价值的模板视频，换取用户存留。只要用户留下，总有一条能够为用户提供足够的付费价值。

最后再看看它的两个价格，17元的周卡和198元年卡。这两个刚好相差11-12倍的价格，乍一看很多人会以为17元是一个月的费用。如果只是体验一下AI换脸又不仔细小字的付费用户，往往会选择17元。不太差钱的用户则会选择年卡198。

注意，大部分选择订阅的用户都会忘记取消订阅，或者以为这是月卡的人根本就不会意识到自己需要一周内取消订阅。这部分忘记取消的收入也不少。

OK， 目标产品拆解完成。那下一步我们要筹备自己的项目。

要复刻目标产品，肯定不能在同一个市场下。那么，思路无非两条：

1. 做海外APP市场
2. 做国内非APP市场（最大的就是微信小程序）

团队海外基因不算强，我们毫不犹豫选了微信小程序。

# AI技术

第一个要点是换脸技术，开发通过抓包，发现目标产品的接口：

![](img/a50ad26370b1cd7f67818735c6f556a8_1315_0.png)

通过网站联系上，结果人家最低提供2QPS。我们刚起步，不想买那么多。最后可能是我的“美人计”起了作用，给开了1QPS。（解释一下，QPS是接口每秒的请求数）

所以，世上无难事只怕美人计。

# 产品重点

### 重点1：用户体验流畅度

变现闭环中吸引用户自主传播，并且留住付费用户的关键点就是用户体验。

所以，设计的重中之重就是必须要保证用户有一个完整的体验流程。

> 模板分类->选择模板->上传照片->生成视频(非必要：插入广告加速选择)->最终效果->直接分享/下载低清晰度视频->付费下载高清无水印视频

流程中的每一个步骤，切记把不需要出现的按钮统统去掉。唯独留下最重要，做的最显眼的按钮引导进入下一个程序。

如果某个页面必须要由多个按钮，就应该分出按钮权重。一般来说，需要出现多种选项的页面都出现在最后。

绝对不要偷懒将按钮设计的都一样，用户会迷茫。我们应当为用户排除阻碍，让他们获得心理价值，从为了继续体验而消费。

即使用户拒绝付费，我们也可以借鉴目标产品的那一套。直接将用户跳转到模板选择页面，用更多选择留住他们。

### 重点2：素材推荐机制

在设计推荐页面的算法时，可以设置成根据每个素材的点击率、生成视频数、分享率等算出数值。之后，再根据计算出的数值进行排序。

**AI换脸吸引用户的主要原因是新奇有趣**，所以要确保排名靠前的都是点击量最高的视频素材。

最新视频可单独做出个类目给想尝试新视频的老用户。

首页是为吸引新用户，而新素材则用来刺激老用户继续参与换脸，目标不同设计也不同。

可以多准备一些视频经常更新替换数据不好的素材，保证跟上抖音的流行趋势，连接各种节日和热点。

建议刚上线的时候准备好50个视频素材，然后每周增加2-3次，一次10个视频这样。软件成型的时候，数量可以维持在200个左右，但种类稍微多一些没关系。

总之一句话，视频素材必须是用户发到抖音上会让人称赞或羡慕的类型。

### 重点3：整体UI美观度

**AI换脸的用户群体是年轻人为主**，所以整体风格更倾向简约风，略带高级感是最好的。

实在没有那个审美，至少要保障做到简洁大方。如果设计师不知道什么叫高级感配色，那就找度娘。

切记，尽量不要用高饱和度的颜色，什么荧光粉之类的。用不好就很俗气，而且看久了容易眼睛疲劳。

### 重点4：小程序专属要点

小程序必须要遵守平台规则。以下这些是防封经验：

1. 不要增加分享送积分的机制，只要用量起来特别容易被封
2. iOS上收费要做开关，可以在晚上8点到第二天早上8点进行收费
3. 量稍做起来后，一定要做照片鉴别是否敏感人物

小程序需要持续运营，主要分内容运营和流量运营。每个小程序和运营人员能力都不同，所以会有个体差别。

我们团队的运营模式差不多是这样个路数，仅供参考：

- 内容运营：跟APP类似，先上50个视频，每天增加2到5个，到200个为止。（用户会觉得每天都有新的，能够增加付费动力并且愿意回来成为稳定流量）
- 流量运营：找一些阅读量在5000以上搞笑公众号合作嵌入他们的菜单和文章。最少要做到每周一到两个号的频次。我们选择的合作模式是直接付钱，不分成。建议以这种模式为主，免得后续扯皮。
