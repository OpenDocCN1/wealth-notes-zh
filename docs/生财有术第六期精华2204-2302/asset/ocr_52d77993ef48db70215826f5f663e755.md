# 一、 为什么我会采用这样挖掘精准粉丝的方法

我在本地招聘的 3 个员工都是宝妈，学历普遍不高。我们曾经尝试模仿同行内容拍摄短视频，效果很一般，数据起量也很慢，前期根本没有咨询量。

我们也尝试过做直播，发现实时的内容，对员工的专业能力要求比较高，而且宝妈因为要照顾孩子，没办法长时间做直播。所以通过自己员工拍短视频和直播卖产品的这 2 条路，我们都没有取得没有很好的结果。

后来，我有一次在刷抖音的时候，刷到一个博主说：私信的都是骗人的，有粉丝收到私信，买东西被骗了。
