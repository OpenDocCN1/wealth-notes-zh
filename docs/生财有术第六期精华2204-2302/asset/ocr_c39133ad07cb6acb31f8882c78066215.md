A 是相互压制的四角，团队就是疯狂压制的三角：傻呵呵的演员啥也不懂，被哥哥蹄腾着做错事，让姐姐揍，或者偶尔反杀哥哥。但是反杀的基础建立在自己不断受欺负 的前提上，10 集才能有 1 集反杀，要不然观众就看腻了。

接下来我介绍一下三幕剧。

![](bbox=[0.13, 0.38, 0.87, 0.55])

三幕剧里的每一幕都是一个事件

+   1. 第一幕让观众参与到角色和故事中。

+   2. 第二幕保持和增强其对故事的情感投入。

+   3. 中点，角色落人事件谷底，心情也落人谷底。

+   4. 第三幕结束故事，把观众带人令人满意的结局。

接下来我就用三幕剧的方式去拆解一个视频

第一幕：A 走进 B 房间，阻挠 B，B 陷人 A 给定的任务。

第二幕：B 为了完成任务，接受 A 的各种恶搞，（为了拿到手机打开一个满是锁的 箱子）
