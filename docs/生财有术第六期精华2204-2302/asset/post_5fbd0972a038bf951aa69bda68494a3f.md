# 3. 如何获得媒介生意？

进入这个圈子的方法有很多种，只要实现了0-1第一步的跨入，后面的路会越来越顺利，单子也会越来越多。

1. 认识上游agency，问对方要外包项目

江浙的agency人力成本高，很多agency在旺季缺人的情况多，到了大促旺季，会外包项目出来。如果没有相熟的agency，可以在boss找找类似媒介的工作，问对方是否接受线上兼职。

同样的方法，小红书上有很多PR号、MCN号，可以私信对方，问是否需要兼职PR。

2. 创作各个类目笔记爆文内容

垂直的爆文内容，一般会接到商家广子，在接广时，可以问询商家，自己也认识很多同类达人，是否需要帮忙更多达人，可以外包一并报价。

3. 私信商家品牌号

私信小红书商家品牌号，毛遂自荐推荐自己做媒介运营，大品牌可直接pass，一般不会通过这个渠道招聘vendor，本土小品牌可尝试。

# 4. 如何做给品牌做合适的内容？

1. 和品牌的信任感

双方信任你的专业，也愿意分享内部投放数据，不然就是瞎子抹黑走路，只有前端互动和阅读量，没有任何后端数据。

2. 熟练的手感

多看、多刷、多积累。不仅是KOL和内容的积累。内容要刷全网，因为优质内容都是互通的。

另外，市场投放的上层框架也要有。也就是策划planning能力。

这里比较推荐我认识一哥们的课，他曾经是众引合伙人，后来做了奶酪博士等品牌投资人，现在在做0-1内容投放IP, 能讲会总结，我让我们公司小朋友都在学，这是小朋友听了第一堂课做的框架（我再在内部发起了大家的学习课，有一半同学参加）。

别的地方也有很多课程资源，比如得到上梁宁的课、华杉的课、蔡钰的商业观察。

# 5. 媒介注意点

## 1）对客户

- 规避合作风险
  - 要求预付：与新客户对接时，需要对对方预付50%+来兜住成本，以防事后不付款。
  - 合同细则：与合作方一定要签合同，里面几处细节要注意--达人是否免费授权、达人内容出现侵权风险是否由PR背责、达人内容可留存时间、付款时间账号形式等都要确认清楚。
  - 特别注意，KOL素材不是免费或者无条件可以给品牌使用的。
  - 尤其是未成年kol（萌娃、初高中生等）素材要特别注意，如果被品牌用来做成素材在店铺宣传带代言等字样，如果被举报会有未成年人代言的风险和广告费1-4倍罚款。

- 掌握时间进度
  - 制作进度表
    - 执行前：预估每个keymilestone的时间，提前和客户沟通好。
    - 执行中：记录每个KOL的进度表，是否寄样、交初稿、发布。（自己不容易遗漏，也让客户知道进度）
  - 避免多次改稿（审稿前做）
  - keymilestone确认
    - 在前期就要和客户align好容易出现认知分歧的地方：
      - 如产品必提的卖点及产品的展示方式（例如拍摄产品细节，产品部分的视频出现时间，产品部分时长等等）
      - 如为合集，需要提前和品牌确认合集产品、排除竞品（合集中的产品需调性一致）
      - 如果对KOL的调性和拍摄服装有要求，需要提前确认拍摄服装等。
    - （以上具体要看这个客户的需求，客户的需求很可能是一次次冒出来的，所以好的媒介对于挖掘客户需求提前规避风险的能力很重要）
  - 事先沟通可修改的次数：一般建议2次内

## 2）对达人

- 规避双方认知不同
  - 询价时要明确价格细节
    - 价格形式（抖音：走星图/不走星图——视频；红书：报备/非报备——视频/图文）
    - 是否含税
    - 是否保价到合作档期、返点是对公或对私（对公需问清返点税点哪方承担）；并且告知达人合作中无法避免的点，询问其是否能接受
    - 确认合作后，把确定的形式和价格再**wx**让达人确认

  - 格式参考
    > 宝子~咱们确认合作啦~您看看合作信息
    >
    > 项目：xxx
    >
    > 档期：7月
    >

    >

    >
    > 确认后请确认，并回复以下信息
    >
    > 图文初稿：
    >

    > 审核需要时间请提前3个工作日提交审核哦～

- Brief到位
  - Bf中文件不是丢给KOL就完了，要把客户注重的点、容易出错的点，再微信单独拎出来沟通。

- 审稿过程
  - 审稿阶段（时间线请绕开双休，尽量从初稿到发布档期留足三个工作日）
  - 一稿件名称（脚本、图文）：稿件命名需统一，在达人交稿前通知其命名格式（一般名称中包含品牌名，达人名及达人属性（koi或koc）），同时一次过的可能性不太高，需用【初稿】、【修改稿】加以区分。
  - 一稿件内容：
    - 脚本——检查达人的稿件中是否有提及必要的卖点，逻辑是否顺畅，有无语病，太过平庸的脚本可结合当下的流行趋势、达人以往爆文或做出一些新鲜的内容创新，一同给到品牌完善脚本。
    - 图文——文案和标题需仔细审核，图片需美观清晰。
    - 视频——脚本反馈给达人时，再重复一遍品牌重视的点（例如产品细节的拍摄，美观清晰，时长），视频按照脚本定稿的版本来拍，检查画面和卖点是否对应，视频节奏不可太慢，否则可看不性不强。

# (精华帖)(196赞)全职自媒体5年，我沉淀下了一张个人IP经营图谱

作者： 芷蓝

日期： 2022-07-01

人，有时侯会有顿悟的那一刻，比如说突然就想通了流量的变现逻辑，比如说突然就想通了自己的核心竞争力，再比如说我突然就在今年把个人 IP 经营的所有关键节点想通，并串联在了一起。

![](img/a50ad26370b1cd7f67818735c6f556a8_1457_0.png)

有点简陋，当时我突然就想通了经营个人 IP 的 5 个主要步骤，然后赶紧用一张纸把自己脑子里的东西画下来，一边画一边开始回忆这几年来我一直在学习+实践+沉淀的东西，紧接着那些动作就开始在这 5 个步骤上逐渐展开。

其实这 5 个步骤很简单，即 定位→内容→流量→产品→变现。我觉得大家从各个渠道一定看到过很多关于经营个人 IP 的方法和技巧，大部分都是正确的，你看完之后挑不出毛病，但是看完又有一种迷茫的感觉，说的都对，但是到自己这里应该如何开始第一步呢？

出现这个问题的原因就是：你在大脑子里还没有把自己学习和时间过的东西相结合，并且把他们沉淀在一个系统框架里。这个也是为什么很多知识管理达人都在说：你要建立一套自己的知识系统。

有了这套系统，你会得到以下 3 个好处：

1. 只要看到觉得有用的新知识，就可以把他按照你的知识框架逻辑塞进自己的系统里，和旧知识进行链接。当你链接之后，新旧结合，认知版图开会向外延伸。
2. 对外输出的时候，无论你是拍视频做口播，还是写文章回答问题，或者哪怕是和别人交流传递想法，你都可以用自己这套框架来组织语言。对我来说，输出就是一件“以不变，应万变”的事情，不变的是自己的框架，变得知识各种内容形式而已。
3. 知识框架可以帮助你提高自己的学习能力，当你的框架越来越大，你对外延伸的速度就会越快，就像乐高一样，局部地区已经拼插过很多回了，再遇到新的结构，你就知道应该怎么组合了。这也是为什么有些人阅读和输出速度很快的原因，因为他在这个结构下已经操作过很多回了。

回到个人 IP 这个话题，当我想通了这 5 个步骤后，就发现以前自己的有些动作走不通的原因，比如说：

定位其实是服务于内容的，一个符合自己的科学定位，可以为你降低内容生产门槛，可以让你持续不断的生产优质内容。

内容是服务于流量的，优质的内容自带流量，还可以把流量变成留量，而暴力获取流量的那一套玩法，你获得的只是一堆数据而已。包括什么是优质的内容（情绪价值、时间价值和认知价值）等等，都通过这个 5 步模型延展开了。

流量是供给产品用的，有了流量＋产品，自然就有了后端的产品变现。

ok，有了这 5 个模块，我发现自己之前分享的各种内容，就都可以依次放到他们该有的位置了。

于是，我开始更新我的《个人 IP 经营 100 个小技巧》（1-21）

# 21、同一个领域，如何找到有竞争力的差异化定位？（定位篇）

今天有个微信好友跟我交流，他现在的一个卡点就是无法在自己的定位下找到新的竞争力。

其实这个问题之前很多人也问过我，比如说你的标签是“副业达人”，定位是帮助职场新人或者大学生通过副业赚到人生第一桶金。

OK，这个定位没有问题，但是做这个定位的人太多了，网上有大量做副业的人，一旦自己跑通整个项目，或者说跑通了多个项目后，就开始在这个定位下做知识付费服务，包括卖课程，卖付费会员，做各种训练营等等。

问题来了，全网那么多副业达人，你的核心竞争力在哪呢？你的优势在哪？用户为什么一定要买那你的课程或者会员呢？

我估计很多人都被这个事情所困扰，说实话之前我也被困扰了很长时间，好在后来我慢慢地想明白了。

> 记住一句话：同一个定位下，你在用户的心智中还有很多标签可以做。

## 1、同定位，多标签

举个例子，还拿“副业达人”这个标签来说，虽然很多人的定位都是帮助xx通过做副业赚到钱，但是那你核心能力是可以不一样的。

比如我的一个合作伙伴，他也是副业达人，这个大家都知道，带着咱们会员小伙伴做过抖音同城团购项目，做过视频号卖货项目。

但是，在我的心里，他的标签更加具象化，你们知道是什么吗？

3个字：会选品！

没错，同样是视频号带货，他选的品一件利润能达到1500元-2000元以上，这可是一件的利润啊，非常爽的。

之前抖音同城选商家也是这样，他总能根据当下的一些热点，比如说节日或者某个新闻事件，找到可能会爆的品，这就是一个很牛的能力。

那还有什么其它标签呢？比如说每次你看到新的副业项目都能以最快的速度跑通，或者能在同一个时间段内跑通多个项目。

这个标签就是“执行力”，让用户感知到你有超强的副业执行力，让他觉得跟着您学，也能学到这种能力。

除了执行力，还有迁移能力、放大能力、沟通能力等等。都是副业达人，但是在这个大定位下，你可以重点突出你的小标签，吸引那些喜欢你的人为你付费。

## 2、多尝试，找需求

定位这个事情，从自己的角度来说，你要考虑的是成本，比如我之前给大家分享的“3+1”定位法则，首先你就要找自己已经跑通的商业逻辑，因为这个是降本最低的，然后才是自己擅长的和自己热爱的方向。

而从用户的角度来说，你考虑的一定是需求，这个需求就暗藏了很多细节，比如都是想通过副业赚钱，但是用户更喜欢什么样的学习方式呢？

价格更高的一对一手把手指导？

价格低一下的训练营大班学习？

价格更低的标准课程自己学习？

不同的需求，就要适配不同的产品和不同的细分定位，比如我见过的一些副业高手，人家不做会员也不做训练营，只做一对一的陪练服务，一个人一年收**5万**块钱，帮你把副业的基础能力培养出来，并且提供适合你的项目，更细节的指导方式。

人家也是副业达人，但是做的服务跟你的不一样，结果就不一样。

## 3、做复盘，深思考

定位真的不是终身不变的，我自己的定位在这几年也是更换了**3次**，从最开始帮助用户通过朋友圈营销变现，到后来转移到社群这块，再到现在帮助自媒体创业者/品牌创始人通过打造个人 IP 深度变现。

其实最后一次的定位更换，就是我自己深度复盘和思考的结果。因为我发现，无论是朋友圈营销还是社群运营，或者是任何私域上的玩法，底层逻辑上都是在把你的**个人 IP** 转化成钱。

各种玩法和技巧都是术，个人 IP 的才是道。一个营销工具过几年有可能会消失，但是你的个人 IP 是需要用一辈子来经营的。

在我的思维里，只有去做那种 10 年、20 年甚至 50 年都不会变的事情，才是正确的事情，才是有复利的事情，所以我选择了个人 IP 打造这个定位。

最后，希望大家都能够再次思考自己的个人 IP 定位，往细节上想，换一个角度去想，也许会有新的灵感蹦出来，而这个灵感就是你的下一次顿悟。

# 20、打造个人 IP 应该输出哪几类内容？（内容篇）

有人觉得自己没有什么擅长的技能，就无法通过内容输出来打造个人 IP，其实这里有很多技巧，你只是没想明白。

## 1、实操型内容

没有人生来就擅长某个技能，都是经过一次次的实操积累下来的。所以，如果你现在没有特长，那分享自己一次次实操的经过，甚至是踩坑的经过。

过程是有价值的，在实操的过程中，你会产生很多想法，这些想法对于不了解这个领域或者行业的人来说，等于是一种“VR”体验，你写的越详细，用户看的就越上瘾。

牛人有牛人的实操，小白有小白的实操，小白实操要着重突出自己的感受，和外界给你的反馈。
