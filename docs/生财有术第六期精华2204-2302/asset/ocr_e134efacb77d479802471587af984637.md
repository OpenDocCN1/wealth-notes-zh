# 1.跨境电商“黑五”保健品：抓刚需 做无效供给

我们这里的“黑五”，不是亚马逊购物节那个“黑五”，而是指常见的黑灰产产品，比如成人用品，仿牌，壮y，减肥，生发，美白，增高等等。“黑五”只是一个统称，不一定只有五个。近1年来盲盒也在跨境电商黑五卖家中很风行，所以黑五的范围还是很广的。

我们从有无真正解决客户需求和痛点来把黑五产品的范围分为两类：

# a）解决需求并有效供给

成人用品和高质量仿牌属于这一类，所买即所得（东西到手用上，需求就暂时clear了），并且都是刚需，之所以成为黑五产品，主要是这两类产品属于敏感/侵权品类，在公域投流和支付通道回款上，是有很大障碍的，常见的有通过AB跳转和IP遮盖来解决这些问题。本文不详细讨论。
