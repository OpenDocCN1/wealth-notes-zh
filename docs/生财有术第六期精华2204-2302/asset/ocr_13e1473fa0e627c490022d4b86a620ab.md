# ②吸引用户

很多人方法论也遵循了奥卡姆剃刀原理，即方法论简洁有效，但曝光还是不行，为啥？

因为一上来就丢方法了！他少了一个让用户看下去的理由！这就像没告诉病情直接给你药，你会接受吗？

你只有让用户意识到了，噢！我确实遇到了这个问题，现在我需要解决它，请给我方法！

如此，他才会自发的把文章看下去、看完它，三个常用的爆款开头方法，分享给你。

共情开头法：写共鸣的、真相的句子，把用户没有说出来的话、有体验但是找不到文字表达的话，你替他们说出来。

场景开头法：假设一个场景，让用户看文字的时候，仿佛置身其中，这里有一个写作技巧，多用名词和动词，少用形容词和副词。

恐吓开头法：比起正面的，人对负面的信息更敏感，通过描述负面切中对方的痛点，从而激起他们渴望改变的心理需求。

这些方法的底层逻辑是，让他们瞬间代入：没错，我就是这样，你太懂我了，然后呢，我该怎么办？
