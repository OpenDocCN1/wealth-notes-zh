# **1） 前期准备**

在招募助理之前，要有一个前提，你的收入足够养得起助理和你自己。也就是你的月收入要大于1.5万的样子，当然这是个虚值。不同地区的成本不同，

还有一个很重要的前提要租一个办公室场地。前期民商两用50-100平的空间足够了，小地方一年的租金2-3万，大地方，一个月也差不多1万元。

我个人是一直提倡办公室办公，而且我一直提倡必须有助理。为什么要在办公室办公，效率会很高，而且会有个自我约束。

如果居家办公，会很容易让自己陷入边做边玩当中，你的有效工作时长自己可以去计算一下，绝对没有办公室效率高。

你在家里一天的活干两天，在公司一天的活，半天干完了，前后的效率就是4倍，但是时间上的差距就是4年，这才是最可怕的。

主要是要进入办公的那个场，让自己知道到公司就立马开始做事。下班了就立马进入生活状态，学会状态切换，也是效率提升的一种方式。
