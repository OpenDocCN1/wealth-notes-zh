# **3. 用户群体都有哪些？**

做胎毛纪念品的用户基本上都是刚生宝宝的宝妈，或者即将生产的宝妈，这个时候的宝妈对胎毛纪念品的兴趣最大，都想给孩子制作一份有意义的纪念品进行长久保存下去，所以人气比较高，一款产品价格**100-200**元，另外包含亲子款、一家三口款等，这样一单的客单价就做到了**400-500**元左右。

如果是宝宝已经几岁的宝妈，可能已经丢失了想要制作的想法，另外宝宝的胎毛可能也已经找不到了，所以找到精准的用户群体很重要。
