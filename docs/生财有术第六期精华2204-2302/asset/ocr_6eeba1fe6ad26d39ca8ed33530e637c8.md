我甚至觉得，流量是不需要转化的，事做足之后，对方会主动提出需求，主动为你送钱，我搞社群也是，很多人都说，比高建个社群吧，你建我马上进，当有很多声音这样提出的时候，我觉得可以建个社群，然后从去年9月份建群，每个月1-2满群的增速在进行....

# 2.交付与超预期交付

别人想要的，和实际得到的，一旦有了落差，对后端是很致命的，我助理在发朋友圈时，一旦有诱人的收益数据出现，我立即让她删除，批评一顿，为了成交而拉高对方的心理预期，后续是很难做交付的。

我把这个体系分为两大板块，前端和后端，前端做流量，后端做交付，初期前端极其重要，但一旦体系跑起来了，就是在拼后端，很多IP前端做得很猛，流量源源不断，但后端交付做得稀烂，这种IP一定是不长久的。

# 3.IP与品牌

我更喜欢把IP理解为一个品牌，个人就是做商誉，有一天，我发个朋友圈借钱，有无数人愿意借给我，就是商誉。

品牌呢，像小米，苹果，完美日记，他们如何经营品牌的？

品牌一定是高歌猛进的，而品牌旗下的产品却必须严谨，个人IP就是品牌，旗下的培训也好，课程也好，社群也好，都是属于品牌的产品，就拿完美日记来说，它的品牌可以大张旗鼓请明星，各平台重金做投放，但是产品上却马虎不得，若是出现一款烂脸的产品，那这个品牌的受损度就严重了，不单是这款产品有极大影响，也会关联到品牌的其他的产品。

而品牌效应，都是无数次正面反馈后，累加的一个结果，在iPhone13还未面世时，早就预定售罄，为啥呢？因为用户相信，iPhone13会是一部好手机，为啥会相信一个还未看到的产品呢？因为这个品牌在iPhone45678X1112都没有让它的用户失望，每次产生的交易接触都是正向反馈的，于是品牌效应持续累积，哪怕一部手机上万，也会被人抢着买，难道便宜的手机选择少吗？
