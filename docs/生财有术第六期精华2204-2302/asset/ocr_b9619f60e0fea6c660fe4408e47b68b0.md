# H5 1） 自主媒体

包括不限于网站、App，Facebook等其他社交媒体软件，在这里你有控制内容的全部能力，保证你发布的是想看到的。

我们有自己的网站，YouTube视频直接内嵌到网页里了，在用户浏览网页的时候直接可以免跳转观看，体验顺滑同时又增加了浏览量。

同时也会在各个社交媒体发布视频信息，尽最大可能的增加初期浏览量。

YouTube在视频破特定播放量的时候会检查流量来源，我们之前是300（可能随时变化）。它会看浏览数据是否有异常，以保证不是通过作弊手段在刷量。

# H5 2） 合作媒体

如果你做产品类的，可以和新闻站，科技站，自媒体投稿联系，让他们来报道你的产品。别人的报道会让你的IP和产品更加生动，更加丰满。
