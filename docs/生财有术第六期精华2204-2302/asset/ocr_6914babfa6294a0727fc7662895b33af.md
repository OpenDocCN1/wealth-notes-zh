# # (精华帖)(95赞)做了 5 年账号租赁类目，扒一扒游戏租赁行业的坑

作者： 石头

日期：2023-01-12

这是一篇分享心得的帖子，进入生财半年多了一直没有好东西可以分享的今天把我一直在做的项目拿出来给大家进行一篇分享。做了五年的账号租赁类目，扒一扒游戏租赁行业的坑。

6.7年前开始做手游账号租赁的年轻人们，现在应该都实现财富自由了吧。

游戏租赁这个板块很大，项目稳定，市面上能做的长久的游戏有很多。

![](bbox=[0.18, 0.46, 0.82, 0.62])

17年-19年的时候吃了王者和吃鸡的红利期，当时的回报率非常高，账号在1-2个月内可回本，回本之后就都是利润。那个时候基本靠暑假两个月就可以干的盆满钵满，现在回头再来看，其实游戏租赁项目也是一个比较稳定的项目，5年前能变现的账号现在依旧能变现，只是多与少的区别。

很多人问现在租赁行业还能加吗？

答案是肯定的，不论你在平台上做，还是发展自己的客户圈子，现在账号租赁还是能做的，一个游戏租赁项目，最重要的是看玩这款游戏的群体有多少，拿比较远的游戏，比如穿越火线，英雄联盟等，这几款游戏当年都是火遍大江南北，现在也依旧有他小部分的游戏群体，只要这个游戏没停运，账号就可一直租赁，持续性的变现。
