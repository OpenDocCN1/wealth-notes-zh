# 如何鉴别真实性

+   - 粉丝和人设
- 赞粉/赞藏比
- 波动性
- 评论

赞粉比（互动数/粉丝数）：
一般账号：赞粉比>3
干货类账号：赞粉比>4
仅个人魅力大的人设性账号（如明星，头部帅哥美女类账号）：赞粉比可能到1
赞藏比：
干货类文章：一般藏>赞
人设型/情感型/剧情类文章：一般赞>藏
问题账号：大部分文章赞藏量相似
