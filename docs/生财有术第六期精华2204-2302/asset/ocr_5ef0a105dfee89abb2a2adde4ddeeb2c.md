# 六、总结

+   - 高客单价项目一定要精准粉丝越精准越好。
- 通过搜索的用户意向度更高，更容易转化，所以用户愿意搜索的平台都是我们需要布局的平台。
- 优化你的账号，内容，整好这个信任的景，做好用户对你的信任为后端转化做好铺垫。
- 通过人工一对一跟进的的用户后期转化率更高，转化周期更短。
- 实力不足或者分成比例合理的情况下能交付外包的业务可以先交付外包。
- 尽量合规化合法化赚钱，你会省掉很多不必要的麻烦。
