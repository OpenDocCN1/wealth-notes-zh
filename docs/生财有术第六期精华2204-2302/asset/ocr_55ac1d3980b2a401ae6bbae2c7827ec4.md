一般我们一栋寝室楼是6层，一层25个房间，一个房间6个人，一层楼大概是900人，所以我就一栋楼找一个负责人，去同楼开展。

# 要求：

2天时间群里拉够本楼层的300人。

# 政策：

大于等于300人1人按1元钱结算报酬，不满300人每个人按5毛去结算。

结果是成功拉了10个群，人数3000+，有俩个做的是比较好的。

+   A 写了基本话术和大概流程，在兼职群里按15元/小时找了6个本楼的兼职去扫楼，要求每小时每人工作量不得低于30人，拉了340人，但是自己没有花费什么时间，赚了340-2*15*6=160。

+   B 是个女生，也是按A的方法做的，但是她自己又找了个同寝室楼做美甲小店和代领快递跑腿的同学，给大家提供美甲服务和代领快递跑腿服务，收取了一些他们的进群+广告费用，也把这个群给盘活了，群里进了470多人，赚了470-2*15*6=290+50+50=390。

通过他们的操作，我可以协助他们去做出详细的SOP流程，去团队扩大，尤其是B同学，值得我去定向培养为核心负责人，让她负责这块业务，给她团队分红，继续深挖她的能力。
