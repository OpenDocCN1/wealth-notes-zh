# ## 2. 朋友圈应该发什么内容？

# ### 2.1 日常生活圈

个人品牌首先要是个人，所以一定要自己的生活圈●，用户是跟人打交道的。

任何成交都建立在信任的基础上，如果你的朋友圈没有生活状态，你的微信好友会认为这仅仅是一个营销号，无法对你有更深的了解，也就很难跟你发生金钱关系，起不到潜移默化宣传的效果。

优秀的成交者，都是在生活中将产品卖给他的用户。生活内容可以从学习、情感和休闲等角度，去分享正向的生活态度、价值观、专业知识等。

让你的微信好友在翻看你的朋友圈时感到有趣、有用、有能量，这是与好友建立信任感的重要一步。比如我会偶尔晒晒蛙，偶尔晒晒出去旅游拍的美景，偶尔晒晒好吃的，好喝的。
