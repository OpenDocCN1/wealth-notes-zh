# 【在交集处，做价值传递】

“人以群分，物以类聚”，一群人之所以可以聚在一起是因为有共同的交集；

比如，老乡见老乡，两眼泪汪汪，一是对于老家思乡情的交集，二是对于身在异乡，漂泊感的交集；

卖方和买方也是如此，卖方因为亲身经历过**100天的持续打卡减肥**，深刻知道，肥胖对于自己的影响，生活不便，工作受挫，也明白减肥这件事的难度到底有多大，需要多强的意志力，每留一点汗需要付出的努力，以及成功减肥后，自己发生了哪些翻天覆地的变化；
