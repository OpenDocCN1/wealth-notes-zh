# # (精华帖)(35赞)如何利用校园业务形成闭环，通过劳务年入百万

作者： 安木释

日期： 2022-08-31

5月份，我在星球发了一篇帖子，想看看如果我分享关于脱口秀剧场的从0-1，大家会不会感兴趣，没想到点赞的朋友不少，评论区有不少留言，问题也层出不穷：

+   · 演员和观众如何积累？剧场如何选址？

+   · 项目存在哪些问题、潜在风险及对应门槛？

+   · 如何成为一个脱口秀演员？

.....

这次分享，我会试着解答这些问题，也给大家讲讲运营一家脱口秀剧场背后的逻辑。

大家好，我叫安木。是个90后脱口秀剧场创业者，目前在广州经营两家百人小剧场。从去年10月份到6月份为止，在广州海珠区开了两间300平方左右的小剧场，最大容纳人数为180左右。

9个月营业额在150w左右，成为猫眼平台华南区单项目销售第一。除去装修等成本，总利润在75w左右，单剧场在月利润在5-10w，其中受广州疫情的影响，有所波动。

这在生财各位大神面前不算什么，但对于我一个普通人来说，能让爱好转成职业，某种程度上也改变了我人生原本的轨迹。在一开始运营的时候也想来星球里寻找一些经验，不过目前还没有人分享。
