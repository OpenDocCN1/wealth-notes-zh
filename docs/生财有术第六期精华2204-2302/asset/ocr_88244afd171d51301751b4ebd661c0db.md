# 一、团队背景

我叫悠途，前大厂产品经理，前在线旅游资深从业者，负责业务年GMV过亿，在团队中主要负责操盘、投放，上播测品，偶尔顶主播。

团队核心5个人，主要负责供应链、短视频、主播这些。虽然大家之前都没有什么电商从业经历，但是好在我们团队十分稳定，互相信任，也非常能吃苦，肯钻研。这也是我觉得这么长时间起起伏伏，我们能一直坚持下来，并且有所收获、有所突破的核心原因。

深以为，创业路上，有好的合作伙伴，就成功了一大半。
