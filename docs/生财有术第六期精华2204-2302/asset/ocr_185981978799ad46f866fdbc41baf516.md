《采访上千位成功创业家后，提练了内容创业的17个技巧》

本文通过一本美国内容创业宝典，插入生财有术精彩案例与模型，对内容创业者具有很好的参考性，希望对大家有帮助。

这是上架不久的好书，亚马逊评分为4.8分 **《the common path to uncommon success》** ，还未有中文简体版。

作者的播客《火力全开的创业家》超过**1亿**人收听。本书采访了上千位成功创业家，提练出他们的成功和失败经验，美国内容创业者视为宝典。

这不是一本鸡汤书，而是提供了具体的创业技巧和执行策略。加上生财有术的精华帖后，是一个很好的内容创业框架。
