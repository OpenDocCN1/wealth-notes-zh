# # [精华帖](96赞)疫情 3 年小红书盈利 50w+后，机票代理人该如何突破困局？

作者: 迟婧

日期: 2023-02-21

哈喽, 生财的圈友们大家好, 我从 2021 年本科毕业以后, 一直从事国际机票销售的工作, 在疫情寒冬的 3 年里, 通过转型小红书引流售卖国际机票, 目前据不完全统计盈利 50 w +成绩。

疫情管控恢复之后, 市场随之发生了巨大变化, 面对无法把握的未来, 我曾一度想放弃, 非常感谢生财让我重拾信息, 继续在这个流量为王的时代深耕。

今天, 我从在疫情寒冬通过小红书变现为出发点, 分享疫情寒冬3年来一步步小红书引流的经验, 讨论机票代理人如何突破“流量为王”的市场, 获得更多的引流方式。

希望有更多人可以受到启发, 有所帮助, 一起探讨探讨~
