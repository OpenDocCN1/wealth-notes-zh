# ① 组建团队的基本流程

做团队的第一步：**找人**！

只要找到各个项目负责人，然后再招聘一些外围的人员，一个团队就搭建起来了。

找什么样的人？如何去找到给力的项目负责人？

这需要我们去设置门槛做筛选。

怎么做设置门槛如何筛选呢？

根据需求，设置相对应的问题，筛选出我们想要的人。

筛选出来合格的人员以后，能直接拿到好的结果吗?

不能，需要给他们培训，为他们初步赋能，然后开始实操项目，再通过赛马机制去选拔优秀的人才。

所以组建一个团队我们需要：

找人—一设置门槛筛选出合格的人—一然后为合格的人员做培训—一实操优选。
