筹备期：竞调分析，自身优势分析

# 第一步，需要了解整个行业水平

+   - 自己处于哪个梯队，有哪些打得过的优势
- 对手目前的月销，店铺设计，上架产品爆款出过哪些，转化率如何等

# 第二步，结合优势分析

+   - 商品及佣金设置比例
- 有哪些合作达人

前期在精选联盟或第三方工具可查，后期多刷视频也能看到

+   - 寻找同价格供应商或自有供应链价格优势

运营期：优化细节

+   - 日周月数据复盘（制表记录）
- 每日监测竞品账号，研究爆款机制
- 定期寻找新品上架
- 跨圈交流，持续成长

提升期：

+   - 重视店铺体验分，稳定店铺评分不低于4.6
- 达人邀约保持每天定量递增
- 需要时刻了解行业发展，敏锐捕捉抖音趋势和规则变化
- 多开店铺，建立护城河

1）被封店下架产品的概率在，多备选能让你和达人快速换新链接上架橱窗；

2）用数量对抗概率，也算是流量的承接放大
