# 3. 你该怎么看待

+   1.  缺乏目标
2.  光说不练
3.  浪费时间
4.  低效学习

缺乏目标。就缺乏奋斗的动力，不知道自己想要学什么为什么而学。

光说不练。光想着自己做一个有目标的人，没有开始行动。

浪费时间。没有合理的安排时间，有很多内耗浪费太多时间。

低效学习。不知道科学的方法来学，在错误的时间内学习，导致效果低效。

在正确的时间内做正确的事情。
