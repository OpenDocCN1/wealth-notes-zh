第二类，是没挣到多少钱，但仍然坚持打卡的人。他们如果坚持到月底的话，还可以把押金拿回来，这总体来说也算是没亏了。至于胡乱打卡凑天数的人，我看在眼里也没声张，也就这么听之任之了。

第三类，就是彻底摆烂的那一类。这些人知道自己完不成任务，也就早早放弃了，所以到后期，他们的任务就是在群里聊聊天，跟着我们凑一凑活跃度了。

所以，我才将会这段时间，命名为“垃圾时间”。除了第二类人里，有少数人在后两周爆发了之外，其余人的结局基本已经提前注定了。

在训练营的末期，还出现了一个小插曲。训练营有一个学员，拿着我们的课程，在自己的公众号里，开了个同款地训练营。这意味着一个问题：既然我们揭开了这个风口，它必然会以这种形式传播出去，我们无法禁止，也无法把它捂住。这是每一个风口的最终归宿。

在这么卷的国度里，任何一个风口，都将成为人挤人的闹市区。所以想靠这个赚钱的朋友，一定要早动手，越快越好，否则真的就来不及了。

# 一、内容为何成为竞争底牌

大量玩家的入局让赛道更加拥挤，批量化工具快速降低了生产成本，爆款选题成为万众瞩目的对标，当同质化越来越严重，选题、排版难以再出色时，内容成了全村的希望。

思维决定行为，行为决定结果。如果想要用内容进行突围，首先一定要在认知层面打破偏见，即不重视和太重视。

- 不重视：认为用了爆款模板，或者搬运了爆款内容，自己的数据就会起飞。
- 太重视：有原创情结还自嗨，完全不管读者喜不喜欢，太想写好内容却没有方法论而难产。

对内容的态度两个极端，怎么办？接下来我就帮你打破这道认知枷锁。

梨云绿这套爆款模板拿下的战绩，大家都有目共睹，但你有没有遇见这种情况：即使用了爆款模板，笔记数据起来的也有些艰难。

同时，你在刷大量笔记的时候，也会遇见另一种反直觉的爆款笔记：排版很烂甚至没有排版，竟然还能爆款！

这里起到决定性的，就是内容，为什么？因为小红书的笔记推荐逻辑。

一篇笔记发出去，小红书也不知道这篇笔记好不好哇，怎么办呢？交给用户去判断，赞藏评粉就是分数，分数越高，系统就会认为这是好笔记，进而推荐给更多的人，你就获得了更多的曝光。

是这套算法，决定了我们做内容，必须围绕数据出发。

爆款封面和爆款标题，完成的是把曝光量转化为小眼睛的任务，用户点击进来后，发现内容一点不好，他就不会给你点赞，于是，你会看到小眼睛和赞的比例远远大于 20:1，那就和爆款无缘了。

当我们抱怨数据不好的时候，本质上是在抱怨用户：你为什么没有把最宝贵的不可再生资源——时间，给一个素不相识的博主我呢。

为啥？因为存在一条永恒不变的法则：价值交换。

我们用有价值的内容，去交换用户的注意力、信任、行动成本，进而是金钱。

要想写出有价值的内容，首先我们要知道，哪些内容，是有价值的。

这就得搬出你梨云历时半年时间，做了16个小红书账号，经验总结出来的内容价值金字塔了。
