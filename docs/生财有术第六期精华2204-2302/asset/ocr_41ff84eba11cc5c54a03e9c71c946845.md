# 五，确立竞争优势

竞争的目的是利润，而不是打压对方。

但是在电商这个平台，经常要面对竞争对手的价格战，从而陷入囚徒困境。

![](bbox=[0.15, 0.29, 0.82, 0.59])

那么如何克服价格战的囚徒困境,确立自己的竞争优势：

+   1. **优化自己的供应链。** 同样是塑料，国产的比进口的便宜，回收料比新料便宜，20%的回收料80%的回收料价格比100%的新料便宜。

不同的产地价格也不相同，通常山东的比河北的便宜，河北的比义乌的便宜，义乌的比广东的便宜。一吨的差价能达到几百上千元。

+   2. **优化自己的产品**，实现产品的差异化，如产品功能，颜色，尺寸等等。

+   3. **增加自己的软实力。**
