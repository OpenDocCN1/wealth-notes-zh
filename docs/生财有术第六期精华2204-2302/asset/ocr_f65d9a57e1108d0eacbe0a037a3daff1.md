2）还有不少人是采集的抖音爆款。

爆款链接可以手动去精选联盟采集，选品类按销量排行，全部手动采集据链接，比较准。能采多多彩多少，哪款出单真不一定 的，往往你特意选的品可能没什么反应，无意间随手上的个链接可能都一直会出单。但是要相信大量出奇迹。

想省事也可以用第三方工具来导链接，考古加、蝉妈妈、飞瓜都可以，不过都是付费的。

# 3. 拍单发货

# 1) 拼多多拍单

拼多多的风控退款没有办法避免。

目前还在做拼多多货源的主要采用两个方式，一是联系卖家微信走线下发货，这种适合绝大多数有单量的情况，是可以避免风控退款和平台短信的方式；二是我找拍的资源去代拍，要让出一单2，3块的利润。

其实自己多准备些号也行，拼多多号太容易整了，微信一个号qq一个号手机号一个号，一个手机能整3个号。我们测试的一个号一天拍10单以内不会被退，当然不是连续批量拍，需要岔开时间，然后价格30以上的品一般不会被退。

所以单子少自己拍，单量大就联系卖家走线下，基本差差不多是够用的。
