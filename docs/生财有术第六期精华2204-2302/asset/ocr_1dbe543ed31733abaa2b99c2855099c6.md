# ## 【精华帖】(120赞)给两百多个老板算完账后，我发现了财务上的三个「雷」

作者： 海程

日期： 2022-05-10

生财的各位老板大家好，我是海程，第四期的圈友，也是龙珠群的老会员了，之前没怎么冒泡。

今天想给大家分享一个比较有意思的话题，就是算账思维。

我这两年在做一个业务，就是帮老板们算账，我发现大多数老板对业务非常精通，很会赚钱，但会遇到三个大痛点：

痛点1：公账、私账、投资混在一起，对钱的控制感弱，给自己埋很大的雷。

不知道老板们有没有这种感觉，就是自己模模糊糊知道现在肯定是在赚钱，大概也知道今年的营收有多少，但对实际有多少钱，有多少立马能用的钱，有多少不能动的钱没有明确感知。

再加上账期的滚动（比方一个生意，货有账款，也在投放，别人有账期在拖你，你也有账期在拖别人）

再混杂上孩子的奶粉钱、老婆的买包钱，买的基金和股票等等，具体赚了多少其实心里是没底的，所以根本不清楚自己在工作上是越来越趋近目标，还是在逐渐远离。
