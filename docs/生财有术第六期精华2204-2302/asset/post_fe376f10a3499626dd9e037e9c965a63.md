
其次，并不是一定要做短视频才能赚到钱，事实证明一些拥有高付费能力和意愿的用户，恰恰不喜欢刷抖音，不喜欢看那些短视频平台上的内容。他们喜欢读长文，喜欢非碎片化的内容，喜欢阅读文字，并且愿意深度思考。

只要他们觉得你的文字或者服务对他们有价值，会毫不犹豫的为你付费，因为他们知道，时间才是最宝贵的。

## 11、你的内容有联动，你的IP才能持续火（内容篇）

我不知道你们爱不爱看美剧，这10年来我看了不下上百部美剧，但在我心目中，评分最高的依然是那部《绝命毒师》。

好看到什么地步？当年我在追剧的时候，最后几集舍不得看，放了两个月，找了一个晚上，特意准备了一顿大餐，叫上我的朋友一起看的结局。

但是再好看的剧，只要完结了，这个内容IP也就结束了，你能够占有的只是一部分对他极其喜爱的老粉丝，但新粉丝怎么办呢？你不能总是做广告去推一部已经完结好几年的老剧吧。

所以，如果你想让这个IP一直延续下去，让他能够一直吸粉变现，你就要推出能够和他产生联动的内容。

没错，就是，这两年一直在更新的《绝命律师》，同样好看到让你吃不下饭。

当然今天不是要给大家推荐美剧，我是想给大家分享一个内容生产的逻辑：关联性。

### 1、为什么要做内容联动性？

先来复习一下芷蓝的个人 IP 5步法，定位-内容-流量-产品-变现。

优质的内容，是打造个人IP过程中不可缺少的一环。但你不能靠一两个爆款内容火一辈子，毕竟中文互联网上每天都会有大量的优质内容出来。

怎么才能让用户不忘记你？而新的用户还能找得到你之前的爆款呢？

那需要做内容之间的联动，比如我出了一套教人做朋友圈营销的课程，那我还需要在这套课程里面引入一些社群营销的玩法，引导新的用户通过这套课程找到我的另外一套课程。

比如你在知乎上回答问题时，时刻都要想着在文章里面留下一些钩子，插入一些之前回答过的内容卡片，让一个新粉丝通过阅读你的一篇文章，然后去发现你的其他回答。

如果你的每一篇文章，都能这么操作，那就能保证只要让一个新用户阅读到你一篇文章，那么，他就可能阅读到你其他的所有文章。

做到这一步，就可以保证你的个人IP一直能够火起来。

### 2、什么是内容的联动性？

很简单，就是内容与内容之间要有逻辑支撑。

如果你是漫威的粉丝，那么一定不会错过每部电影结束之后的彩蛋。

这个彩蛋大概率会引导出，漫威漫画里面的一个新角色，也就是一个新的IP。

所以说，漫威是用整条故事线，来做内容联动性的逻辑支撑。

你在打造个人IP生产内容时也要有自己的一套逻辑，比如说构建私域流量池的时候，从成交到复购，从复购到裂变，从那边到引流，从引流再到成交。

这就是一个逻辑，每一个环节都可以是一套课程，每一套课程你都可以置入其他环节的钩子。

### 3、怎么做内容联动性？

- 第一步：建立你的整个内容输出框架。比如说我的个人IP打造5个步骤，还有刚才提到的私域流量池的构建闭环。
- 第二步：找到你内容与内容之间的过渡逻辑。比如说漫威漫画里面的时间线，你要先让哪个英雄出场，再让哪个英雄出场，在时间上面不能发生矛盾。
- 第三步：持续不断的生产新的内容节点，让新节点与旧节点之间发生更多的关联性。

比如说我打造个人IP的第1步是定位，那么定位下面你还能拆出需求分析、细分赛道和优势能力等知识点。

而需求分析又可以和 IP 5步打造中的『流量』这一步骤产生联动性。

你生产的新节点越多，每一个知识点往下拆分的越细，你的IP就越不容易被别人忘记。

好啦，希望以上内容能够帮助你在打造自己个人IP的时候，有一些新的启发。

## 10、一个好问题就是一套好课程！（产品篇）

前2天我在星球里给大家分享了做课程的一个小技巧，那就是一套课程不要做全，要做成一个系列。

然后就有同学私信问我，做课程到底要如何开始呢，我第1步应该做什么？我的答案是：你要选择一个问题，一个好的问题就能做出一套好的课程。

### 1、蓝海选题

做课程就是要把一个很具体的问题，给大家讲明白。比如说，你在打造个人IP的时候，已经确定了自己的定位是帮助用户提高学习力。

那么你的课程就是要把怎么提高学习力的方法给大家讲清楚。但这里有一个问题，学习力它包含了很多种类型，比如说英语学习力，比如说数学学习力，比如说语文学习力。

你也不可能擅长所有的学习力提升吧，你自己现在的背书，或者你所取得的成就，一定是某一个领域的。

所以你的课程就不要覆盖全部的学习力内容，你要挑一个自己验证过的，有真实案例的领域去做课。

- 比如：如何提升语文学习力？
- 比如：如何提升中小学生的语文学习力？

无论你做什么定位，做课程的时候一定要往下细分，细分到你没办法再往下分了，这个问题就是你的做客主题。

### 2、四大模块

如果你觉得一个细分的问题，要分享的内容太少了，那你就错了。

一套课程分为几大章节，而每个章节里面你至少能够分享出4大模块。

#### ① 具体案例

一定要先放自己的案例，因为既然你做出课程来，说明你已经通过课程里面的方法取得了成果。

你看有一些知识付费课程，导师就在那一边画导图一边分享理论知识，这种课程一定不要买，因为他自己都没有，通过这种方法赚到钱，他只是单纯的给你讲理论方法而已。

如果你放完了自己的案例，就可以再放一些你的学员的案例，或者说你身边的朋友的案例，可以填充你课程的内容含量。

#### ② 理论体系

有案例还不行，你要自己沉淀出一套理论体系。就好像美索不达米亚人是希腊人的老师，在商业书写系统以及科学上都是率先做出成就的。但是相对于希腊人来说，古巴比伦人，缺乏思维能力和抽象的逻辑推理能力。

换句话说，就是古巴比伦人他没有能够把这些科学知识沉淀，并且按照逻辑整理的能力。

拿我的朋友圈营销训练营来说，就是把之前写过的100个朋友圈营销技巧，按照理论体系整理出来的。

所以，案例和理论体系一个都不能少，没有理论体系，用户就没有使用的方法，也没有传播力。（上过我朋友圈训练营的同学，可以回一下朋友圈的“四有系统”）。

#### ③ 实操技巧

有案例和理论体系了，你还要告诉用户，在具体实操过程中需要用到的技巧或者说动作。

拿写作这个技能来说，标题要用什么关键词？第1段开头，用什么方式？结尾写精华句的时候，上哪去找？这些都是具体的实操技巧。

实操技巧其实解决的就是具体场景问题，你可以把自己在做某一件事情时，遇到的问题，和解决问题的方法记录下来，这个就是实操技巧。

#### ④ 工具使用

道法技术，最后一个当然少不了“术”了。做任何一件事情你都需要用到工具，有了工具可以帮助你快速提高，解决问题的效率。

相对于上面三个模块，工具这个模块还是比较简单的，把自己平常在用的，或者说，网上大家推荐的，整合在一起就OK了。

### 3、上架课程

上架课程这个事你真的不用想太多，有的会员在问我是上架小鹅通好呀，还是上架千聊荔枝或者学浪这些平台好呢？

难道你还嫌自己的课程流量多吗？小孩子才做选择，成年人当然全部都要。

只要能够上架的地方，你就全部上传，每一个平台都是你的流量导入器，你课程曝光度越高，卖出去的数量就越多。

产品制作是我的个人IP打造5步法里的倒数第2步，未来我还会为大家分享更多的相关技巧，感兴趣的同学可以持续关注芷蓝。

## 9、不赚钱，也要做产品！（产品篇）

做一套知识付费产品，如果卖没没赚到钱，是不是就算无用功了？

当然不算！制作一套自己专属的知识付费产品，只是个人 IP 变现的一个途径，但不是唯一途径。你观察一下，自己身边只要是自媒体玩的不错的人，是不是都有一套课程，你甭管人家卖的好不好，但都有，对吧！（没有的，可能人家出书了）

为什么要做？因为 IP 无法自传播，它要依托于产品来传播！很多人都是通过某个产品，某节课程，某个 PPT 图片知道某个牛人的！甚至，当你还没有什么数据背书时，你还可以说自己是《xxxx》课程的作者，对不对？

所以，只要你在某个自媒体平台，某个行业领域赚到钱了，别顾虑太多，无论钱多钱少，先出一个 1.0 版本的课程，未来随着你的变现程度加深，再一点点的迭代课程就行。

初期，这套课程你可以低价，9.9元，19.9元，甚至是免费分享给你身边的好友，但是随着你自己的成长，这套课程就会随之越来越之前，而前期学习的用户又成为了你的天然裂变传播者，如果你再深入一点，你可以像芷蓝一样，通过付费社群＋训练营的模式进行二次变现。

这一切的基础，都是需要你有一套自己的产品才行，所以每个圈子有每个圈子的玩法，知识付费圈子就是这个玩法。

## 8、从0开始打造个人IP先要做什么？（定位篇）

之所以会聊这个话题，是因为咱们会员群里有很多小伙伴都在问我“打造个人品牌需要掌握什么技巧？”

这里就有一个很大的误区，其实个人IP，是无法被凭空打造出来的，如果让我来说，“提炼个人IP”会更精准一些。

因为“IP”存在的其中一个意义是为了解决产品或服务的同质化问题。

举一个例子，八十年代你只要对产品，你只要能交货，就能赚钱，那个时候拼的是谁有生产力。

紧接着大量的货物出现在市场上，这个时候，如果你能搞创新，你的功能比别人多一点，那么消费者就买你的，你就赚钱。

但你看看现在的市场，同等价位的产品在功能上基本都一致，无非是品牌不同，那么消费者喜欢哪个品牌，就买哪个品牌，觉得哪个品牌的调性，和自己一样就买哪个品牌。

所以针对个人也是一样的，你得先有货有服务，然后卖出去，才谈得上去打造品牌。

说白了就是你得先赚到钱，无论是通过什么方法，然后再用个人 IP 去优化你赚钱的路径，或者说扩大你赚钱的规模。

个人 IP 是不能凭空制作不出来的，就好像咨询公司不会帮助企业去扭亏为盈，而是帮助一家做的还不错的企业变得更好。

总结一下：要先“成事”在做IP。

## 7、定位不是标签，也不是身份（定位篇）

你不理解这个，就没办法通过自媒体去赚钱。

昨天在朋友圈训练营中分享了第一课【定位】，然后我发现很多人在打卡完成作业的时候，虽然知道了怎么去定位，但是把定位和【身份】与【产品】混淆了。

举个例子，医生就是一个身份，儿童润肤露就是产品，或者说小几推拿这种服务也算产品，专注于帮助儿童解决皮肤问题，这个才叫定位。

定位，一定是解决目标用户人群的一个痛点，或者满足他们的一个需求，或者是给他们创建一个新的场景，而不是说把自己的身份或者产品直接拿去当定位。

就好比摩拜单车是产品，而它的定位是满足地铁站到公司最后1-3公里的交通工具需求，对标用户是那些职场人群。

他们没钱买车，或者摇不上号买不了车，或者有车但是交不起写字楼每个月的停车费等等，所以摩拜单车的定位满足了他们的需求，所以人家做起来了。

记住我昨天在朋友圈训练营分享的那句话：定位是用户为你付xx钱，购买你的产品或者服务，来满足他们的xx需求。

这里有几个重点：

1. 你要有产品。
2. 你的产品和服务是可以让用户付费购买的。
3. 你解决的用户痛点不是伪痛点，是真实存在，且用户愿意付费解决的。

所以，大家再次思考以下自己的定位，看看是不是更清晰了一些，如果还是很混乱，觉得拿不准，可以来找芷蓝聊聊。

## 6、有调性没价值是假 IP，有价值没调性是傻 IP（定位篇）

之前给大家分享过一个做个人 IP 的 5 步打造法，如果你觉得整个流程有一些复杂，那芷蓝再给你一个个人 IP 的简易模型，那就是“价值 + 调性”。

### 1、个人 IP 里的价值是什么？

- ① 你能够帮助别人解决一个问题。比如说他失眠，那么你可以通过某种治疗方法或者卖他一个你家的产品，解决这个失眠的问题。
- ② 你能给他创造一个新的需求。比如说某个人只是随便刷刷抖音或者小红书没啥需求，突然看到你正在分享如何利用某个厨房用具，做一道好吃的菜品。这个时候他有需求了，他也想做这道菜，然后就买了你推荐的产品。

另外，除了创造需求，创造情绪也是一个价值点。就比如说我自己非常喜欢看海岩的小说，因为他的小说都特别悲凉，能给我很强的代入感，让自己沉浸在小说的故事情节里面享受。

### 2、个人 IP 里的调性是什么？

调性就是你的说话语气，就是你的文化素养，也可以理解为你的世界观价值观和人生观。

做个人品牌就必须让一部分人喜欢 你，而另一部分人不喜欢你。

喜欢你的人就会愿意，多花钱去购买你个人品牌溢价，啥叫溢价，就是本来这个课程我花 99 元就能听，但是我就愿意花 9999 元，去线下听你讲。

虽然讲的内容都一样，但是我 可以现场看到你，感受你的说话语气，感受与你面对面交流的气氛。

你想象一下，如果你说话的腔调和态度，与课程里面用 AI 机器人配音出来的语调是一样的，那别人为什么要多花那些钱来，面对面听你讲呢？

### 3、IP 是卖出来的

之前就跟大家分享过，个人品牌这个东西无法凭空制造，其实是一种萃取。

萃取的是什么？萃取的就是势能！

势能是怎么出来的？势能是卖货 卖出来的，势能是做圈子做出来的，是 能是搞事情搞出来的。

所以，你一定要敢卖，也不用总听别人说，卖知识付费产品就怎么内卷之类的，只要你最后能成交有销量，这个就是“起势”！

### 4、一开始没人买怎么办？

这里还是有小技巧的，先卖低价，先免费服务别人。

比如你做的课程可以先卖9.9元，有10个人买，就能有一两个成功案例，把这两个成功案例补充到你这一套课程里面你就能把价格提高到19.9元。

以此类推，随着成交的数据越来越好，成功案例越来越多，你的课程就越来越值钱，沉淀下来的用户数据就会越来越多。

做服务也是一样，一开始没有人买，你可以先去免费服务别人，做免费咨询，给别人免费做规划，给别人免费做设计。

往河里扔下一个石头，一定会泛起涟漪，哪怕波纹再小，也会有个结果。

我们要做的就是，连续往下扔石头，让所有的波纹连成一片，你的个人品牌就出来了。

### 5、个人 IP 别做知识号，要做成长号！（定位篇）

做知识号，你永远都不会成功的，因为“讲的不好没人听，讲的太好被人抄”。

举个最简单的例子，如果于谦老师的段子不是郭德纲来讲，你还会觉得那么有意思吗？

不会，因为于谦老师的故事里面必须要有郭德纲才好玩，而且这个故事必须得从郭德纲的嘴里而说出来，大家才会笑，就是这么简单。

所以，有人设的成长号，无论你是带货、卖课、接广告还是付费咨询，总是会有粉丝支持你。但是知识号，除非你是某个领域的专家，自带权威背书，否则做的再好，用户也记不住你。

同样都是教人知识，你要把你的知识融合在自己的成长过程中，这样用户在学习的时候，还会有一种**围观你**，看着你慢慢百年强变大的隐形需求。

比如说，我的小红书账号定位是减脂健身，那么如果我光分享各种动作技巧，轻食做法等内容，肯定不如健身大V，或者那些专业模特厉害啊，谁愿意看我呢？

但如果我和粉丝做一个约定，30天内减掉xx斤，在这个减脂的过程中，我去分享自己的运动+饮食日常，分享各种有用的小技巧，那用户看起来的感觉就不一样了。

因为他们是在看着我成长，看着我向着某个目标在努力，这里面还有一层情感上的共鸣，这种共鸣是那些专业选手给不了的。

这样，你的自媒体账号价值就做出来了，最后无论你是成功还是失败，那已经不正要了，重要的是你让用户参与到了这个过程起来。

## 4、流量=被稀释的干货（内容篇）

今天在抖音上看到这句话，非常想分享给大家。我之前给大家分享过，在打造个人IP的过程中，定位服务于内容，而内容决定了流量。

好的内容一定为用户提供三个价值：时间价格、情绪价值和认知价值。

很多同学都觉得如果想为用户提供这三个价值，一定要让你的内容里充满了干货。让用户看完后，就觉得自己学习到了很多知识，然后给你的这条内容点赞，收藏加转发。

这就属于典型的自我视角内容生产方法。为什么给小孩子讲道理要用伊索寓言？因为寓言里既**有道理又有故事啊，小孩子能听得进去啊**。

为什么谣言的流量大于真相的流量？因为谣言里面有水分呀，有供大家讨论和娱乐的空间啊。

同样是找旅游路线，为什么大家不喜欢去看官方景点看旅游指导，已经要去马蜂窝上找个人攻略呢？因为个人攻略里面掺杂了创作者的情绪，和个人喜好嘛。

你看，同样都是分享干货内容，如果你太干了，干的没有水分，干的只剩下知识理论和公式推导，那么用户就会有天然的抵触心理。

再说了，你分享这些内容，用户不用在你这里看，他们去书店里买一本书一样能看，而且逻辑性要比你强。打开抖音，打开知乎，打开小红，人家是要娱乐性的内容嘛，如果娱乐性的内容里面再掺杂了一些有价值的东西，这不就让人觉得超值了嘛！

那么怎么干货里面掺水呢？我们小区最近也因为疫情被封了，在家没事干，就看美食教程给孩子做饭呗。

然后我就发现，同样都是分享美食教程，但是有的人会用方言，同一个地方的人听到之后瞬间有好感。

有的人会在这个美食教程里面加入了一个情感故事，比如他说要做炒土豆丝，一开始做不好，然后给老妈打了一个电话，才知道原来老妈以前给自己炒土豆丝，竟然要耗费那么多心思。

有的人就像以前年庙会里那些一边跳舞一边烤羊肉串的人一样，带着超嗨的情绪来做一道菜。

你看，加入了情绪，加入了方言，加入了情感故事，同样是炒一盘西红柿炒鸡蛋，你的内容就要比别人好看很多。

所以，想要流量就要把你的干货进行稀释，往里面加入情绪、故事、文化等要素。但你要注意的是，稀释不是替换，干货还是一定得有，你不能让你的内容里都是水货。

最后再复习一下芷蓝的个人IP打造5步法：定位→内容→流量→产品→变现

从这五大步骤里会细分出更多的知识点，我未来会慢慢地分享给大家。打造个人IP是一个系统的工程，你千万不要把它想象成几个小技巧，也千万不要去自己凭空制造 IP。

## 3、无课程，不做 IP（产品篇）

昨天给我的一个合伙人做咨询，发现一个有意思的事情，原来大多数人心里依然存在着完美主义，更糟糕的是，这个完美不仅是内容上的，还是体系上的。

她跟我说，想做一套私域成交课程，而且要把关于销售的所有内容，全部放进这套课程里去，力求让用户买了这套课程，就不需要去买别的了。

乍一听，好像没毛病，仿佛那句“学习成交，不必东奔西跑，来我这里一套课程全部搞定”，其实却犯了个人 IP 变现的大忌。

先回忆一下芷蓝的“个人 IP 5步法”，即定位→内容→流量→产品→变现，敲黑板，第4个步骤的产品，指的是产品体系。

啥叫体系，你得做一系列的知识产品，用来满足用户不同阶段和不同类别的需求。

### 1、不同阶段

举个例子，我自己玩赚的产品体系是按照用户分层来的，从单独的199-299元的引流课程，到498元的玩赚新媒会员，再到咱们的各种训练营，最后到我的玩赚合伙人。

这个分层就是用户阶段，低价引流课程让用户知道你，付费会员是提高用户的粘性，增加私域的触点，通过运营做低转高购买训练营，最后是高客单价的合伙人产品，做个人 IP 陪跑和赋能。

一个 IP，如果想满足不同阶段的用户需求，至少需要 4 个以上的产品，才能实现有节奏的变现。

### 2、不同种类

果断放弃。这种课凭我的经验，里面肯定有很多口语废话，本来知识产品就是为了给用户提供时间价值，不是给用户浪费时间的。
