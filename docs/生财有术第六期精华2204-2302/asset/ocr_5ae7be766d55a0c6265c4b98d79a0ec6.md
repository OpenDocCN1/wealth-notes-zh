如果出现因为标题或者封面的原因导致视频下架，你可以修改视频封面或者标题，然后重新发布即可。

有时候作品发布了大半天，流量一直没动静，也有可能是标题封面的问题，可以修改下试试。

# 五、发布和运营

# 1、抖音的发布：

视频制作好以后，手机端的发布很简单，直接在抖音点击+上传就行，前期可以选择不同步到头条西瓜。

不参加中视频计划，可有效避免抖音起号只有几十播放的情况。

上传时我们可以选择蹭同领域爆文的热门音乐，选择音乐然后调成静音即可。

发布时标题直接用西瓜的标题，下面标签加上手工、全手工制作、动手能力、小发明、手工爱好者等相关的标签即可。

任选几个加就行，注意添加标签时不用加太多个，适合最重要。

加好标签以后，记得在作品同步里面关闭同步至西瓜视频和今日头条，下面的原创内容也先不勾选。
