# 1、我的训练营概况

今年初开始做个人IP，两个月后开始做训练营，目前已经做了6期。每一期结束后我都会用问卷星给学员发放完全匿名的调查问卷，去了解他们对训练营的看法。

问卷调查的主要结果如下：

+   （1）对课程的满意程度（95%满意）

+   （2）训练营结束后，对自己下场做一个同类工程有没有信心（85%有信心）

+   （3）是否愿意把本训练营推荐给朋友（94%愿意）

+   （4）是否愿意报名进阶课程（94%愿意）

从问卷结果可以看出，这门训练营还是比较受学员欢迎的。
