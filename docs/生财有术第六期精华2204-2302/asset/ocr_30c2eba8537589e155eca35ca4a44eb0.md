而且有人可能会因为你每天坚持发，他们也有途径顺便看看这个群，看到这个群存在，也许会自发的交流变成活群。

当然，我并不在意“死活”，因为这就是个免费群，或者低价加入，实际上有没有什么责任去做的很好，我每天提供一本书，其实大家也很喜欢这种模式。

甚至没有人一个人交流，也很很多人喜欢，因为这是他们觉得最安静的群，偶尔想看书，那就在群里往下翻翻翻就好了，反而不喜欢有人聊天，因为往上拉就很辛苦。

# 2/ 别怕没人交流

每天发一条的好处就是，你可以保持群的“活跃”，起码有一个人每天发一条，那就不算死群。

# 3/ 想要把大家加到微信，一定要要对方得到些什么。

例如我用读书群的方式吸引大家加我微信，和单纯的只放二维码，效果可能长期来看会相差10倍，也就是我没有读书群，我原本是加10个微信号，现在可能只加了几个而已。
