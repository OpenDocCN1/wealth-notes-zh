# 1. 坚持很重要

短视频本身就是一个搏爆款视频，在还没有爆发的之前，不断坚持发视频就显得很重要，因为不知道哪一个视频会爆，我们能做的就是做好每一个细节，静静等待爆发的那一刻，而这个等待的过程就是“坚持”，而我就是一个木得感情的坚持机器人。

# 2. 实践出真知

不是说看过了就明白自己会做了，有时候就算完全照着教程来，也不一定能得到想要的效果，需要不断去探索，更改方法和调整细节，实实实在在把动作到位了，才能有自己的体会：原来这样也可以。千万不要因为厌烦情绪而放弃，万一这就是黎明前的黑暗呢。

# 3. 众人拾柴火焰高

一个人走得快，一群人走得远。有时候一些短视频的优化细节，就是大家一起总结出来的。在生财里，航海上，勇敢发声，勇敢和大佬做链接，可以帮助我们更快做出成绩，少走弯路。

做TikTok这么久以来，每次有困惑的时候都会来生财看精华文章和航海手册，每次来都会有新的发现，以前理解不到位的地方，下一次总会迸发出新的灵感。
