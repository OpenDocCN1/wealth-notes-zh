+   * ......

这些都是标签，都是你的最强战力。

不要用自己的“弱标签”去PK别人的“强标签”，这样越比越不行，越比越焦虑。

拿出自己最强的部分，田忌赛马，用你的上等马去打别人的下等马，这样最容昜形成自己的战力标签。、

降维打击、不在别人的战场上打架。把别人拉入到自己的领域内，窥视全场、疯狂输出，占“标签”为王。

别人谈起你，会说：那个做XX领域喊牛逼的人。提到关键词，第一时间想到的就是你。

举个例子：我复购了好多次盖洛普的测试，无论谁问我，我第一反应就是推荐醒醒。这就是她的最强战力

不吹牛逼地讲，生财有术里做无人直播的也没人比我牛逼。

怎么展现你的最强战斗力？发精华帖就是最好的方式！没人知道你这个小透明，你反思一下你有几篇龙珠文？

# ## 3、共生（利他、互惠）

什么是共生，就是和别人有关系。

你再牛逼，你和我没关系，你的钱也不给我，我会和你有联系？

没有关系怎么发生关系？就是利他。

你的内容、你的价值，一定是帮助到别人，和别人产生了联系、互动，才会“有关系”。

+   * 我发布的风向标，让你抓住了几个最新的赚钱思路；
* 我在群聊里的互动，让你受到了一点启发；
* 我在线下活动的积极发言，让你觉得“生财的氛围好好”；
* ......

这些都是“利他”的分享行为。不计回报的利他，会为你换来更具象的影响力。

比如大师兄杨涛，大家在他的影响力标签会说：涛哥人很NICE，像哥们一样教会我人生的道理。
