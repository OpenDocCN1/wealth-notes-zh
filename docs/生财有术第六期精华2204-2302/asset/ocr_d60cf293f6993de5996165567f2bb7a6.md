# 二、精准定位

选择大于努力，方向不对，努力白费

在一个优质赛道中深耕所能带来的效益在大多数情况下是比一个低质赛道高很多的

现在几乎每个赛道都是大蓝海，只要用心浇灌，就能生根发芽，结出果实

账号的定位很重要，不管你是想卖PPT模版还是想卖幼师资料还是其他

一定要在做账号前留给自己找好方向

方向如何选择呢？

建议可以从自己的职业或者兴趣爱好入手，比如你是一个教护理的老师，你可以选择专攻护理医药赛道

你是一个设计师，你可以选择日常会用到的相关软件对应赛道，比如PPT
