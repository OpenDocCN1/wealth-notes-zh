# **文案这样写**

+   1.核心是：让客户产生购买的冲动，感觉很重要！

2.站在用户的角度读产品，切忌自嗨！

3.文案中植入热度词，增加搜索曝光；长度跟紧！

4.文案建议从创始人的角度，写创业故事，价值说分群，对行业的思考，让你的文案更有血肉，调动看群情绪，而不是冷冰冰的产品卖点

5.始于我在小红书并不讨喜，让你的文案几个逐势，先用魅力吸引，再用修养拿下

6.社交：态和沟通，多双向沟通，少单向 输，更要是自强

# **图片这样拍**

+   1.一组图最好在7张左右

2.前两三张团展示产品基本图：解决看客这是啥？

3.后面两张图展示产品细节或卖点图：告诉看客哪里好？

4.最后两张图展示产品全部规格（全家福）告诉看客都有哪些？

5.最后可以再加一个已下单客户反馈图：借他人之嘴，打消看客最后的疑虑

6.如果实在不会摄影，记住：干净就是美，少及至多

（杂乱的背景可以用苹果手机人像模式虚化背景，突出主体）

爱听故事是人的天性，尤其是在女性用户比例如此高的小红书平台，故事是调动你文案情绪的催化剂，一个好的故事可以既能引发讨论吸引流量，又能对你新人吸引精准流量导向往付

下面这几个点，是我总结出来的一些高询单内容的秘密，另外整理了几套内容模板供各位参考

感觉很重要！！
