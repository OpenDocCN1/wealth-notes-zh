# 如何配置可转债轮动组合呢？

可转债轮动组合就是通常说的推大饼，顾名思义，就是通过买入一攥子转债进行组合配置的投资方式，一般 10-20 只左右，然后根据一定的阈值或者周期进行轮动，希望获取一个市场的平均收益。

具体筛选的方法也可以很多，一般都是根据可转债的一些关键指标进行筛选，比如：

+   ①价格：越低越好，价格越低越安全；

②溢价率：越低越好，溢价率越低进攻性越好；

③剩余规模：越小越好，因为规模越小的转债越容易被市场资金炒作；

这些指标在一般的券商行情软件里都有，也推荐大家使用集思录网站的转债页面，上面的信息更全面，还支持通过这些指标进行筛选，非常方便。网址：

[https://www.jisilu.cn/data/qdii/#qdii](https://www.jisilu.cn/data/qdii/#qdii)
