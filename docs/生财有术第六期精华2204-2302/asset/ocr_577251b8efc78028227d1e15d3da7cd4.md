# 4.3.4 商圈

商圈最好是周围有居民区的商圈，太远的话会导致客单价下降，顾客不会购买太多的东西带走，有居民区的话不会产生太大影响，且可以发挥便利店的作用，会有很多零散的小客单客单子。
