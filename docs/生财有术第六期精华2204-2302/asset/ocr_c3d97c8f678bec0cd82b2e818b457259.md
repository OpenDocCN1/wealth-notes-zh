无论是哪个平台的直播，数据推流都是由算法决定。简单来说，哪个直播间数据做的好，能把观众留住更久，能卖更多的东西，就给他推送更大的流量。

所以对于半无人直播间来说，核心是运营。这种直播间弱化了对主播的依赖，因为我们不是专业的主播，一般不会使用传统直播间的“憋单-放单”脚本，而是采用平播的模式来开播。

同时身兼主播和运营二职时，我们要对各项数据都很敏感，根据数据随时调整直播的策略和话术，补充我们对应的数据，这就是半无人直播的核心方法论。

# 2. 准备阶段

在开播前一周，我们要先为账号启动做好准备。需要做的工作主要有：设备准备、直播账号准备、直播场景准备、选品准备。

# 1）设备准备

直播设备的要求很简单：

一台专门用于直播的手机（iPhoneX以上最好）

一台电脑（i5/16G内存，独显最好）

一块绿幕（根据房间大小准备）

一张流量手机卡（淘宝自购）
