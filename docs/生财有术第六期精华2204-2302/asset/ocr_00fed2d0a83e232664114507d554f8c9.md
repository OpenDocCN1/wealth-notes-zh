面家电清洗是若半小时清洗一台挂式空调，一小时就是清洗两台空调，那么公司一小时是50元以上，一个家电清洗师傅一天给公司赚的钱是400元，你可以抛去路上的时间成本，一个师傅一天仅仅工作6个小时，给公司创造的利润是300元以上。一个师傅给你赚300元一天，十个师傅那就是3000元一天，抛去信息员的工资两百元一天（一个信息员可以匹配十个师傅没有问题），再减去会计的工资150元一天。（如果不做培训项目，不需要太大的场地，场地成本可以忽略不计），那么一天的利润是至少两千元以上。

# 二、家电清洗，是适用于什么城市，像我们这种三四线城市，甚至五线城市可以做吗？

| | 一二线大城市 | 三四五线城市 |
|---|---|---|
| 家电清洗现状 | 基本为红海，价格战厉害 | 基本为蓝海，专业服务的家电清洗公司少 |
| 竞争对手数量（美国数据） | 百家以上 | 10家以内 |
| 服务商平台 | 基本有稳定的承包商，能再进去的新服务商机会小 | 没有专业的家电清洗公司承包，都是由维修安装类公司兼职，机会大。 |
| 家电清洗认知度 | 大城市家电清洗认知度高，宣传难度低 | 小城市知道的少，就说明机会大（那个去荒岛卖鞋的故事） |
| 回归裂变 | 操作容易性高 | 操作容易性低 |
| 人工成本 | 人工成本较高 | 相对较低 |
| 入局状态 | 被迫竞争 | 可以做“土皇帝” |
| 需要几个人干 | 大城市最好以团队形式出现，不然吃不到肉 | 小城市一个人就可以吃的饱 |

任何生意都需要结合行业本身性质，以及“入局者”本身的条做判断。不能以城市等级来做判断。我也可以告诉你几个“扎心的数据”，其实，家电清洗这个行业，一线城市确实很火热，但同时作为小白的你，劝你如果要进入一线城市，建议你要慎重考虑考虑，因为家电清洗在一线城市，已经属于红海市场，价格战，竞争对手是相当的多，除非你有不错的平台资源和雄厚的资金。
