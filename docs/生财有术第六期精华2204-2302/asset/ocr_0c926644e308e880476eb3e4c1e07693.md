# 三、定价（提高转化率的方法）

正常操作方法如下：

搬家时设置 200% 的价格；

限时限量购里设置 5 折（时长嫌麻烦可以拉1年，勤奋的就每天设置）；

然后再设置优惠卷（优惠卷就是我们的起店成本，可以设置新人直减券 1-3 元，再高就不建议了）

价格一样，也可以不设置限时限量购。直接设置大额优惠卷，但我嫌麻烦，因为每个商品价格不一样，这样每个商品都得单独设置。

先通过这种低价方式出单，那什么时候可以调高利润？

+   1. 零散出单 的品，销量到 20 左右（不一定出评价），就可以调高。
2. 好几天销量连续递增的品，这种有爆款潜力，可以消耗多一些，等商品销量和评价合适时再调高利润。
