
# 赚大钱，靠的是借势+模式的转变

比如我在5年前毅然辞职，决定去做付费社群运营，也是看准了当时得到app的崛起，这个是借势。

马云无法再创造出一个阿里巴巴，因为互联网大势已经过去了，BAT大佬们都没办法再复制出自己的商业帝国。

如果当初我没有选择社群运营＋知识产品分销这个机会，我也不会快速收到反馈。借势就是站在巨人的肩膀上做事情，起点就比别人高，你走的一定比别人远。

之前关于社群运营更新了3万多字的连载内容：https://t.zsxq.com/09PQFGIds

借用金枪鱼大叔的一句话：**借钱不如借势，借钱要还，借势不用还。**

咱们生财圈友的优势就在于：**可以通过观察生财星球某一个时间段内的帖子内容方向，找到未来的「势」在哪。** 你看关于AI绘画这个项目，在我看来就是明年的一个势，其它圈子或者互联网上还没有过多的内容，咱们就有圈友已经把项目变现跑通了，这里可以看看@天辉 最近分享的内容。

所以，我觉得咱们在看生财帖子的时候，不光要聚焦到某个项目的具体玩法，还要看未来6月内的可能存在的机会，早点下手，早点布局，一定能吃到红利，或者找到自己的生态位。

## 二、模式转换

上面已经说过了，想要赚大钱，除了需要借势，还需要一个好的模式。

什么是好的模式？在我看来就是学会分钱，在我做自媒体创业的这几年，每一次的转机和拐点都跟分钱有关系。所以我最近总和别人说一句话：知道怎么分钱，比知道怎么赚钱更重要。

### 1、学会给自己分钱

怎么判断一个人是创业者？就是看他知不知道自己的单位时间值多少钱。

我当初就有一个很明显的感觉，从公司辞职以后，突然发现自己有大量的闲散时间，开始莫名感觉很兴奋，觉得自己终于实现了对自由的向往。

但是一个月之后，发现自己没有任何收入，突然就有一种恐惧，是那种对时间的恐惧，在相等的时间里，我没有任何收益，相当于过去一个月我的时间凭空消失了。

所以，如果你正处于创业初级阶段，一定要把自己的时间单价算出来，也就是说，如果你一个月打算赚 **10万** 块钱，平均的每天 **8个** 小时，你每个小时值多少钱？

这是对创业者的初级压力，可以让你感到时间很紧迫，不会随意挥霍自己的时间，会强迫你自己制定目标和实施计划。

### 2、学会给员工分钱

如果你很幸运的通过创业赚到了钱，而且业务在稳步提升，那么终将有一刻将体验到：超出自己肉身所能承受的交付压力。

一个人的精力是有限的，而赚钱就要付出成本，这个成本可能是身体上的，也可能是精力上的。

但无论是什么成本，我们肉体凡胎的承受能力是有限度的，你成交一个客户赚1万块钱，那么你就得为这1万块钱付出相对等的价值。就算你个人能力再强，交付效率再高，不可能一个月成交1000个客户，因为收钱都会让你受到非常疲劳。

走到这个阶段，说明你该分钱来购买劳动力了。这个逻辑就是你要拿出自己的一部分收益，去实现重复劳动的批量交付。

敲黑板：很多人在这个阶段会想不开，他会觉得自己一个人赚钱多爽呀，赚的钱都为自己，稍微努点力，熬几次夜，一个月赚几十万，非常开心。

但你要明白，这样做不光对你的身体造成损害，更重要的是会把所有精力全部放在战术上的重复，根本没有时间再去研究战略导向。

过了一段时间，你就会发现自己的业务没有任何增长，没有新产品，也没有新玩法，吃光了这一部分老客户之后，你的收入就会急剧下降。

所以，学会分钱给员工，提高自己的生产力十分重要。

### 3、学会给合作伙伴分钱

只要你妄图赚所有人的钱，我确定最后你会丢掉自己的生意。

从底层逻辑上来看，给合作伙伴分钱是在优化一个行业。以前我也不知道，甚至一根半导体的天线都要分成几个厂子来制作。有专门制作最下面那一段的，有专门制作最上面那一段的。

极具细化的分工协作，可以应对市场不断更新的消费需求，很多大厂，就是因为生产线太重，最后市场技术革新，被硬生生地拖垮了。

拿我自己来说，如果没有合作伙伴帮助我不断地生产新内容，不断地拉新流量，我的社群也不会实现快速增长。

而我把社群品牌＋运营转化过来的收益分给我的合作伙伴，又可以让合作伙伴有更多的收益和继续生产内容的动力。

我前2天在朋友圈分享了一个小感悟：当你去花钱去购买一件商品时，这个世界的熵就增加了，频繁的交易，让这个世界变得极其复杂，复杂的背后就会诞生各种新的商业需求。

所以，如果你想拥有更多的财富，必定要学会在用分钱的方法解决复杂系统的运转问题。

## 三、个人 IP 营销

老话题了，我的收入从以前每个月10万到30万，再到现在差不多50万，背后的逻辑就是我知道了自己到底在帮助谁解决什么问题，在帮助哪个群体建立新的需求场景。

个人 IP 不是打造出来的，也不是包装出来的，而是本身就存在的，我们通过优化它来放大自己的影响力，并不是创作出一个叫做【个人 IP】的技能，在每个阶段，个人 IP 会帮助你完成不同的成就。

比如说工具人这个阶段，你提供的就是时间价值，帮助用户节省时间；陪伴者这个阶段你提供就是情绪价值，陪着用户一起去完成某个目标；KOL 这个阶段你提供的就是认知价值，给用户一个认知工具去解决各种具体场景下的问题。

给大家分享一张图，是我自己的认知工具，我不否认别人的 IP 营销逻辑，只是自己沉淀出来的更好用而已。知识体系这个东西，不在于谁对谁错，而在于它是否适合你，是否能够贴合你的逻辑思维方式，帮助你高效的解决问题。

## 一、高净值用户群分析，如何找到小众市场蓝海

**用户群分析：** 留学生群体在疫情前连年增长，有近50万的留学生，其中90%以上都是自费留学。

虽然2020年疫情之后人数降低，但总体大家对学历的诉求越来越高、国家对出国留学的鼓励持续保持、以及目前整体就业形势差 & 考研人数爆涨导致国内硕士竞争激烈，因此整体的学生需求还是在的，而且需求还在加剧，只是因为疫情被迫部分转到国内考研。

个人感觉目前在等一个疫情政策变化，一旦变化就会出现一次井喷。总体还是看好国际教育行业的大发展。

针对本科 & 硕士留学的学生，该类群体现有教育消费主要集中在留学中介服务、语言服务上；随着近些年申请竞争加剧、导致要求越来越高，市面上开始出现背景提升服务（科研、实习、游学等）。

**该类群体付费能力：** 总体都是高付费用户群，能够付费几万、几十万甚至近百万的付费。

**项目背景：** 这两年，学生求职、留学申请竞争加剧。针对留学生群体各项服务中，除了一些细分领域（申请马来西亚等小众申请）、目前留学申请、语言服务都比较多，常规机构竞争比较激烈。且常规留学服务，属于服务权重大、投入服务成本大的行业。

注：为了方便圈友们了解，一些行业术语的解释。

- **升学规划**：针对学生，做本科、研究生的升学规划。结合规划服务，为学生推荐课程学习、素质锻炼、英语学习、留学申请等各项服务。
- **职前教育**：主要面向在校大学生到第一份全职工作之间的用户群，通过职业辅导、实习等方式提升学生职场竞争力。
- **语言产品**：英语、日语等语言学习。如新东方。
- **背景产品**：面向大学生，为了留学申请，打造申请的背景。背景主要有实习经历、科研经历、校园社团经历等。

## 二、常见教育规划类项目剖析与特点分析＆差异化业务突破复购

**业务核心逻辑展示：**

| 业务核心逻辑 | 端 | 策略/特点 |
| :--- | :--- | :--- |
| B端：为留学机构提升获客，增加利润点 | B端 | 利用更低的产品采购价 足够与B端机构让利进行合作。 |
| C端：通过与市场的差价，吸引用户采购 | C端 | (核心：实习产品) 与市场上有1-2万差价 的利润差价； 客单价高、用户群体本身可复购。 |
| 留学生群体复购产品 | 产品细分 | 语言：语言推荐；留学：拆成单服务，增加意向人群；科研产品、实习产品 |

### 1.常见教育规划类项目剖析与特点分析

1. 升学规划：结合学生背景，对其本科、研究生等阶段进行规划辅导。里面会细分本科（国内三位一体招生、国外留学申请）、硕士（国内考研服务、国外留学申请服务）；
2. 求职规划：现在市面上比较火热起来的职业教育细分领域（职业教育领域）、以及更小众的背景规划（实习、科研、论文等背景经历规划）

其中背景提升规划中：

- 1. 科研产品：常见产品模式是找海内外高校教授带学生固定课题，小组做科研、发论文。如科研头部的中科浩博去年一年已经达到了一亿的体量，但这类比较吃海外教授资源。国外哈佛等教授来授课的模式基本已经被挤满了，客单最低也是3万多，一般来说渠道的返佣20-30%之间。
- 2. 游学产品：把学生送到海外参加一些学校的参访、有些会带1-2门授课的模式。特点：偏小众，客单低、利润薄，疫情来了之后，不可控性比较大。
- 3. 实习产品：客单高的也可以达到4-5万，以某投行实习为例，高顿财经比较常见的售价在3.5-4万之间，学生普遍接受到的价格也在2-3万。但这类背景的最上游渠道成本、或者自己联系资源开发：基本在1万上下。因此里面能出现1-3万的利润空间。

### 2.差异化业务突破复购(常见国际教育类中小公司)

1. 语言互推合作：市面上比较常见，一般机构都会互相推荐。留学的学生会有语言需求，跟语言机构合作，推荐学生给语言机构。拿学生返佣盈利，一般市面上比较多的返点在10-20%之间。
2. 留学全套产品拆解各模块，增加一些产品：目前常见的留学全套产品，会包括择校、文书、申请。可以把服务拆出来变成单产品进行销售。另外针对相对低消费群体（不愿意花几万中介费的用户群），如把留学申请拆成课来卖；原先全包的申请服务拆解一部分出售。
3. 背景产品：留学生本身缺背景，很多学生无法自己解决；因此做额外产品复购的。目前市面上常见背景服务：游学服务、论文服务、实习服务、科研服务。游学、论文：若有较好的渠道、资源也可以进行合作洽谈。

以我对行业的了解，各种产品的利润如下：

- 科研产品：常见售价3万，合作返佣比例在20-30%之间。每单可获利润：4000-6000（高价 适合高中申海本、有钱的本科学生；用户稀少）
- 游学产品：常见售价1-2万不等，但成本高，往往比例只在10%。每单可获利润：**1000-2000**；
- 实习产品：常见售价1-3/4万不等。我这边可以拿到的成本往往在4000-15000之间、为各个合作机构提供价格也常在5000-17000。每单利润空间预计在6000-15000之间，甚至可以让更高（比学生市面上价格低一截、且付费采购高）

并且就实习而言：一些美本英本的学生，容易多次采购。今年我这边有两个美国本科的学生，采购过一次实习，2个月之后又采购了一次实习。

这样一个用户单次采购就可以变成多次采购了，且在签约前后都有产品可以推荐。

## 三、职前教育、背景提升教育里实习产品特点解析

**实习服务：** 投资、互联网大厂、四大等全球大公司，远程带实习证明、实地实习、全职实习等。

**类似机构：** 目前市面上比较大单位：高顿财经、职业蛙。

1. 本身属于偏灰色，一般也不会到处说。因此价格没有标准，同样的实习有的可以卖1万、有些可以卖2万，基本可以根据学生消费能力去定制。

## 四、用户从哪里来

1. 跟各个机构谈B端合作：作为产品渠道供应商，给留学机构提供产品，留学机构自己卖给学生。
2. 通过自媒体（以留学生实习为切入点）然后引流到微信端，然后进行日常的通过实习资讯、优惠名额等洗用户，销售用户。
3. 本身有的留学学生，可以让学生知道有这个产品服务、一般来说英本美本的学生往往比较愿意来采购。

## 五、过程中的一些经验分享

1. 项目难点：在于后段服务上、服务资源获取甄别上。
   - 若需要搭建后段服务，人力主要耗费在；需要搭建后段的各个公司的实习渠道；
   - 若跟市面上的渠道合作：本身质量优劣不齐、本身灰色行业又容易出现骗子，特别低价格的会出现大学生假冒公司职场导师给学生发任务的情况。往往甄别需要通过不断的踩雷。
2. 留学机构的洽谈：有部分留学机构不愿意做这种事情，因此本身有一定的筛选性。根据我合作的近千家机构来看，一般15%左右的机构是比较愿意的且能真实推学生的。
