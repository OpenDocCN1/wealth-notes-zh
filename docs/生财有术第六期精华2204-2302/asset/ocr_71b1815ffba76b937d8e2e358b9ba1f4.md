# 一、Temu介绍

名字：Temu，取自“Team Up, Price Down”，直译后可以理解为“拼着买，更便宜”，与拼多多在国内的定位异曲同工，在这里可以看出Temu主打的也是低价路线。

模式：与拼多多国内不同，Temu商家只需要提供产品，在产品被平台选中后，拼多多会安排快递上门取件，把货送到拼多多自己在国内的仓库，然后销售、推广、发货都由平台决定，商家只是给平台供货，类似于平台自营，商家只要提供竞争力的产品，对应的售价、物流、客服、仓储都由Temu承担。

目前入驻不用交保证金，但是后续在货款中会扣掉1000块当作店铺保证金，平台没有扣点，供货价按照人民币结算，模式比较简单，费用除了寄样外基本上没有什么额外费用。

流量：目前Temu在北美持续推广投流，据说每月广告预算达10亿，新客获取渠道很丰富，之前看到一篇报道说大概Instagram占到30%，Facebook 30%，Google 20%左右，剩下比如Tiktok、Youtube等占大概20%。

此外，Temu还为新用户提供30%的折扣力度，而且前三单免邮费，三单后购满99美元可免邮费，90天内免费退货，还有很多商品首单只要不到1美元甚至1美分，新人福利很大。

而且最近貌似还推出了“砍一刀”的功能，用户可以通过WhatsApp、Messenger、Facebook向朋友分享链接并获得相应奖励。
