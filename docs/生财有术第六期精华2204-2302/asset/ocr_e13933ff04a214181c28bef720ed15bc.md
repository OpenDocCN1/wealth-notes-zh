# ## 二、一度迷失了自己

到了2020的12月份，全港中小学因为香港的第四波疫情停课，孩子只能全天呆在家里，而我对自己未来的变现之路，也越来越迷茫。

我们母子二人，每天睡觉睡到自然醒，起床吃饭后各玩各的。我躺在床上看看小说和连续剧，孩子自己画画和玩，可是不知道为什么这样相互不打扰，并且毫无压力的情况下，亲子关系却没有变得更融洽。
