# # (精华帖)(450赞)亦仁：我人生中注册的第一个域名

作者： 亦仁

日期：2023-02-01

今天早上，收到一封邮件，godaddy提示我的一个域名要续费。

打开邮件，是我人生中注册的第一个域名，大概 15 年前，那时我还在上大学，具体时间记不清了。

注册完这个域名之后，还去淘宝买虚拟主机，在谷歌上搜索了差不多一周时间，跌跌撞撞才把一个wordpress博客搭建起来，开始雄心壮志地写英文博客。

那时候，屁都不懂，真的是屁都不懂，也找不到人问，也没有圈子，全靠谷歌搜，走了非常多的弯路，浪费了太多时间。

这个博客的主题是免费网络电话合集，我在网上找到能用的免费电话，按照一个文章模版就开始写，第一段介绍，第二段讲步骤，第三段讲注意事项，一篇文章500字左右，一天写几篇，也不知道效果，反正就是听说能赚钱，就是傻傻的写。

现在想想，要不是因为那时时太穷太想赚钱了，中间的无数挫折都会让我放弃。

写了差不多有上百篇，几个月，一天有了几百个用户访问，才申请到广告，这个时候大概一天几美元开始赚。

后面有了更多项目后，这个博客也就不更新了，但我每年都会续费这个域名，作为纪念，也一直在提醒我：在赚钱这条路上，即使像我一样一无所有，也能靠自己的努力实现逆袭。

前几天在风向标共创群，我聊到，其实我最想帮的圈友，可能就是类似早期的“我”这样 的人：刚起步，找不到方向，没人带没人帮，但肯花时间，愿意折腾，踏实积累。

我坚信，这样的人，迟早都能赚到大钱，至少在财富上超越这个社会的绝大多数人。
