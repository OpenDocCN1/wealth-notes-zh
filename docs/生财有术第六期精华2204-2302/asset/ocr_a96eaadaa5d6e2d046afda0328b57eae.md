# 经历收获

那段经历给我最珍贵的收获，就四个字：长期主义。

单一短期的行为，也许微不足道，但时间会放大所有的努力。

就像我在自媒体上的内容输出能力，是硬输出200w字炼出来的，就像我的文案素养，是在大学期间，写了几千条广告文案单子磨出来的。

正是因为相信人生没有白走的路，所以第一次失败了，我会继续战，第N次失败了，我还能再战......

这样看来，长期主义其实是一种信仰，是因为相信，所以看见，如果你在很早的时候告诉我，这玩意儿我要写6年才会有起色，也许一开始我就会放弃。

这也让我明白，每个优秀的人，都有一段沉默的时光，那段时光，是付出了很多努力，却得不到结果的日子，我们把它叫做扎根。
