# ## # 1.熟人圈子推荐

本身做APP拉新、充场工作室的圈子，熟人相互推荐。

在做这个工具之前，我们开过好几家线下工作室。总部在广州。在广州、重庆、南昌、南宁等几个城市都开过直营的线下充场工作室，从选址、租房、招人到搭建运营。代理的工作室全国都有。所以对这个行业圈子比较熟悉，也了解线下工作室运营的需求难点。

做这个事情都知道最头疼的就是，渠道不靠谱交单怕被吃单跑单，一个是结算到账不及时。我们工具里面面对这两个需求都处理了，推广的每一个单子都可以查看审核的状态，审核通过与否及原因，没通过的可以重新补交。

结算的话，通过审核的单子，直接就显示到账了，然后自己随时进行提现即可。（单子和结算稳定是我们的优势之一）。
