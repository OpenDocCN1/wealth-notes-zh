# 四、其他关键点

先再补充几个关键点：

+   1. 每个店铺上架1000个就行了，因为优选联盟只能进1000个。

+   2. 一个企业可以开5个小店，一个微信只可开一个。

+   3. 一个工可以负责5-10个店，从客服到拍单发货，从上品到维护优化，特别熟练也可以负责10+，因为我这边给员工们按业绩提成，所以给他们按人头包的店。

+   4. 小店开完后暂不支持退店注销，开成功之前可以注销。开店成功后想注销只能去注销视频号，小店也会随之注销。

+   5. 小店客服只能是企业微信，一个企业微信可以绑N个小店。但是正常的询单看不到买家信息，可以服务市场买个客服工具。

+   6. 小店延迟发货可以选择最下边的报备，但是最近报备没什么用，忙不过来审核。

+   7. 小店暂时不支持运费险，估计后边会加。现在想要运费险只能去服务市场看看相关工具，据说可以，我没用，无货源的运费险是鸡肋。

+   8. 目前无法无物流发货，必须上传单号。

以上大概就是视频号后端无货源店群的玩法，也是今年我这边主要的收入。

但是无货源远不止视频号，所有的电商平台都能玩。
