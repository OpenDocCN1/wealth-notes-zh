你会发现，为了体现强大，或者很多，我都用到了数字来表现，这个特别有效，还包括：超过多少人、快多少倍、只用多少天……

然后，你又发现，我的标题似乎不仅仅只有数字强大这一招……没错，标题都是组合拳！

# 好奇——悬念钩子

还记得我前面说，黑色封面，要配上神秘感的标题，用好奇驱动“点击动作”。

《学霸不为人知的25个学习习惯》，对学习习惯进行了神秘化，就是在前面加上不为人知，然后用上刚刚收集的特定词“学霸”对用户进行筛选，把非学生党排除在外。

《学生党警惕，挥霍青春7种行为》，挥霍青春的行为是哪些？没说，让人好奇，然后学生党也是一个特定词，进行用户筛选。

总结起来，就是用数字来体现你内容的牛逼，用悬念来修饰你的标题，最后融入特定词提升吸引人群的精准度。

拟写标题，一定要有钩子意识，你知道为什么这么写，为什么这样措辞，不然，再怎么模仿，都只是学到皮毛。

# 三、数据拉升，引导决定成败

为什么我的内容，即使是用0粉新号，也总是能冲出500的基础浏览量？因为标题吸引用户进来之后，笔记没有让他们失望，并且激发了他们的互动行为。
