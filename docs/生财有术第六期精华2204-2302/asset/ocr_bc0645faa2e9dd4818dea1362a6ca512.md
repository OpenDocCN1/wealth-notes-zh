# 一、 初识AI绘画， 很快得到正反馈

去年（2022年）11月初，我从北京回西安休假，那时北漂2年多的我就考虑23年要回西安发展，找个项目做做。（当时定了要往互联网方向发展）

3号晚上刷生财周报，看到了天辉老师写的<生财的一句话，衍生一个“AI绘画IP">精华帖，内心深处一下子就被吸引了，这不是我想要的嘛，立马添加了天辉老师的微信，开启了AI绘画之路。

一入AI深似海啊。感觉像触了电一样的感觉，为AI发电，每天乐此不疲的学习着AI技术。过了些天，天辉老师让我选择一种类目垂直下。当时我看星空等比较火，但我更喜欢衍纸风格类型，我觉的衍纸变化会更多，不论哪个类型好看的内容，都可以用衍纸来体现。
