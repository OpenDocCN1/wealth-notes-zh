能克制住自己的本性就十分不易。

所以，如果十分喜欢工作的安逸，那就请好好珍惜上班吧。

# **13、耐力忍受能力**

初期是一个极其磨练耐力和性子阶段，可能前期会做很多无用功，看到身边一个又一个人已经出现成绩，就会按耐不住。

每个人这个时期长短不一，有的人需要一个月，有的人需要一年，随时做好一个长跑耐力选手。

# **14、总结复盘能力**

每一次行动都会有不一样的结果，总结复盘中往往能找到哪些是需要优化的，哪些是需要进一步放的。

比如我的爆款变现，是一个势能累积到一定高度，通过快速行动力的产品课程带来的转化，那就需要接下来后面进行多爆量的行为。

# **15、有表达目标的欲望**

对于创业者除了需要坚信信念外，还需要有适度的目标表达，比如完成帮助100个人成长的想法。

这是从潜意识中加强对这个目标的意识，也是让更多人看到，知道。

# **16、快速自我修复能力**

每个创业者不可能一直都是饱满的状态，也会遇到低能量的学员、不好的负面评价，对于没有好的心理素质的人很容易被带入坏情绪。

而我去年就是进入了这样的低情绪状态，进入了自我怀疑。感觉自己付出了心血般的努力，但收效甚微。
