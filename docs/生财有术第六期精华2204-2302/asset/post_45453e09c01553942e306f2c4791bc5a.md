## 19、怎么打造一套个人 IP 变现课程？（产品篇）

课程即产品，有了产品你的个人 IP 才能变现。很多人每天坚持做内容输出，从公域引流用户到 私域，私域每天继续输出和用户做互动。

请问，你做这些的意义是什么呢？你后端有产品吗？能把这些流量转化成钱吗？不能变现的 IP 只能叫客服。

问题来了，怎么才能快速打造出自己的这套付费产品呢？有几个关键步骤呢？就4个，我来分享给你。

### 第一步：选课题

课程好不好卖，全看你的课题选的好不好，这里千万记住：你的课程是帮助用户解决某个具体问题，而不是告诉用户一些知识。

怎么选？在你所擅长的技能里面，去找用户的痛点，把这些痛点全部罗列出来，从中挑选一个你最擅长解决的。

这个就是你的课题，围绕着这个课题，去给出一系列的解决方案就OK了。

### 第二步：列提纲

好的提纲，用户看完之后就有获得感，就有下单的欲望。不好的提纲用户看完之后，感觉不到自己能学到什么东西，不知道该从哪里学。

列提纲要记住以下几个重点：

1. 标题不要太学术性，最好能用一些有网感的词汇，比如：让老板一眼就喜欢的PPT，到底藏了哪些秘密？

2. 提纲数量千万不要太多，尤其是新手做课程，5到7节也OK，挑那种用户痛点最深的问题去写。你的课程节数越多，用户的完课率就越低，用户的获得感就越差。

3. 你的提纲要有结构性，结构性的好处就是，让用户知道自己正在学的这个知识点，它的意义是什么？它在整套课程中起什么样的作用。

### 第三步：写课稿

当你把提纲列出来之后，接下来就是去填充课程的内容，导致很多人迟迟下不了笔的原因，无非以下几个。

1. 没有应用原理

应用原理是串联这节课中知识点的一个工具，你不把这个东西给它沉淀出来，那么你的知识点就会显得很零散，用户记不住就算记住了，也不知道怎么用。

而且应用原理可以起到让学员学完课程之后，想跟别人介绍推荐你的课程，总得用一句话让别人知道你这个课程的价值在哪吧！

2. 没有具体案例

案例就是用来解释应用原理的，应用原理一定是抽象的，怎么把抽象的东西具象化，那么就需要一个真实的营销案例。

这里需要注意一点，案例优先使用自己的，然后再使用和自己有关联的，比如你的学员或者会员。

不用自己的案例，真相只有一个，那就是你还没有通过它赚到钱，所以你只能用别人的。

3. 没有实操方法

原理逻辑给人讲清了，你还得把流程步骤给列出来，否则用户的感觉就是：你说的都对，但是对我有啥用呢？

第1步要做什么？第2步要做什么？第3步要做什么？这个就是实操方法，其实就是流程。

### 第四步：萃取核心理论

核心理论是一套课程的灵魂，也是你个人IP定位的高级表现形式。

啥叫高级表现形式？比如你是一个医生，你的IP定位是帮助3~6岁的儿童解决各类皮肤问题。

解决这个问题，这个就叫做普通表现形式，但如果你能提炼出一套皮肤护理方法论，这个就是高级表现形式。

那么你在别人意识里的标签就是：xxx医学方法论创始人。

这个定位是不是更高级了？如果能有这个定位，你的课程是不是可以卖得更贵？你的个人咨询是不是也可以卖得更贵？

OK，以上就是打造知识付费产品最核心的4个步骤，有了这4个步骤你就可以快速的制作，出一套还不差的课程，你的 IP 打造才有意义。

## 18、学会借力，才是升级个人 IP 的高级玩法（流量篇）

打造个人 IP 是一个漫长的过程，踏踏实实做内容固然没有错，但是高手通常会抓住某个机会，靠借力来完成个人 IP 的阶段性升级。

什么是借力？就是在明确自己目标的前提下，有策略地通过外部力量来达成自己想要的结果。

如果你想通过借力来升级自己的个人 IP，那就需要从以下 3 个方向去操作。

### 一、向人借力

踩在巨人的肩膀上，哪怕你是个无名小卒，也可以享受万人瞩目的感觉。

这个“巨人”就是在某个领域有影响力的人，比如说你的个人 IP 定位是：帮助别人通过打造私域流量池获客变现。

那么在这个领域里，一些资深的老玩家，例如媒老板的坤龙老师，就是你需要借力的对象。

明确了自己的借力对象是谁，接下来就是如何去借力。

其实方法也很简单，那就是和他建立社交关系。如何建立社交关系呢？要不就是成为他客户，要不就是成为他的学员。

反正最快速的方法就是：给钱。

买他的服务，买他的课程，买他的产品，别人的时间都是宝贵的，你想和他成为朋友，想让他帮助你背书，那就要舍得投资，去花钱买别人的时间。

### 二、向话题借力

热门话题的传播速度永远是最快的，如果你能够搭上这班快车，你的个人 IP 将会在短时间内被大范围的曝光。

刘畊宏，搭上了#上海疫情 这个超级话题，瞬间火遍全网。

一天之内，中国一半的网民都知道了刘畊宏是一个热爱运动的家庭爱美暖男。

结果从第二天开始，本草纲目、刘畊宏男孩、刘畊宏女孩、毽子舞等二级话题瞬间铺满了社交媒体。

知识博主开始分析为什么刘畊宏会火，运动博主开始改编各种毽子舞的动作，音乐博主开始给你讲解《本草纲目》这首歌曲的旋律。

总之，只要你想为自己的 IP 曝光，就一定要蹭一下刘畊宏这个话题。

当然，向话题借力也需要注意几个问题：

1. 不要强行借力，不搭边的事情，做了用户也不买账

2. 要有道德边界，不要为了出名，做一些触碰道德和法律边界的事情

3. 速度一定要快，如今的中文互联网每天都有热门话题，一个热点很快就被人忘记了

最后，推荐大家关注微博热搜排行榜，时刻对舆论保持敏感，知道当下正在发生什么热门事件。

### 三、向品牌借力

大品牌的每一个动作都能在互联网上掀起一波热浪，比如每年苹果发布新机型，比如微信更新的一个新功能，比如某个奢侈品牌又出限量款了。

如果你向品牌借力，就需要明确自己的个人IP定位和哪个品牌有着相同或相近的关系。

如果你是做智能手机测评的，那自然就要借苹果的品牌，在自己的内容当中尽可能地植入品牌名称和品牌新闻。

如果你是美食博主，那就要借新零售品牌的热度，比如钟薛高的高价冰棍、或者是卫龙辣条的网站图片等等。

借品牌的力，需要注意一个问题：品牌的调性就代表着你的个人调性。

1. 核心价值

2. 文化特征（调性）

3. 外表形象

调性对了，借力成功，调性错了，白忙一场。

## 17、流量裂变的2个基础要素是什么？（流量篇）

有流量＋有产品，才能实现个人IP的变现，那么除了自己通过内容去不断的搞流量，怎样才能已有粉丝帮助你自动裂变流量呢？芷蓝给您分享2个玩法。

### 1、物质奖励

你知道通过物质奖励可以促使用户去做分享，但你可能不知道怎么设计分享的动作，如果设计错误，不但没有新流量进来，还增加了你的运营成本。

举个例子，比如你自己做了 3 套知识付费课程，有个用户买了一套，现在你想通过给他分享一个课程优惠券，引导他购买省下的 2 套产品，你该如何发放这个优惠券呢？

很多人会说，直接给他一个面额 xx 元的优惠券不就行了吗？比如说你的另外一套课程是 999 元，然后给他一个 199 元的优惠券就 OK 了。

错，这样其实就等于给了他一个优惠，并没有任何裂变的因素加进来，正确的做法是把这张优惠券设计成分享才能激活的形式来使用。

你可以把优惠券的面额设计的高一些，比如 399 元，但是需要分 3 次分享才能使用，分享一次获得 100 元。

这样不但用户自己占到了便宜，还能在分享的过程中，帮助你的个人 IP 曝光。

### 2、精神爽点

物质激励是驱动用户分享的一个动作，而精神爽点是用户自发分享的一种行为。

你需要为用户制造一个高光时刻，让用户觉得自己分享你的内容可以给自己加分，体现出自己的优越感。

比如各种训练营的入场券、开营证书、结营证书、打卡满分记录等等，这些素材都是需要为用户制作的，最好能把分享的文案也直接给到用户，这样他就可以一键分享到朋友圈了。

回忆一下，你去各种景点做缆车，或者游乐场玩一些刺激的项目，是不是都会有一个自动拍照的机器，玩下来之后，会问你要不要购买照片，如果你买了，其实就是为你的高光时刻买单。

另外，大家一定要记住，流量来源于你的好内容和好服务，就算知道了所有的裂变玩法，但是只要内容和服务跟不上，用户就不会把自己的时间消耗在你身上。

## 16、如何优化你的内容选题逻辑？（内容篇）

### 一、反认知

你要颠覆大家平常的认知，这样才能抓住用户的注意力，用户才愿意停下来多看你 3 秒钟，就这 3 秒钟对平台算法至关重要，它决定了你内容的传播层级。

具体的方法就是：一语惊人＋合理解释

举几个例子：

正常逻辑：每一个成功者都是完美的

反认知：丑闻才是对成功者的奖励

合理解释：完美人设是不存在的，丑闻决定了你的人设丰满度，而你对待丑闻的态度决定了你的认知高度。（选自金枪鱼大叔）

这样的例子还有很多，但需要注意2个事情，你的解释必须合理，你的选题一定围绕着你的IP定位。

### 二、做细分

做细分的好处就是能让用户觉得，你写的东西和他们是有关系的，每个人只关心和与自己有关系的事情，否则就算你写的再精彩，他们也用不上，他们也看不到。

你需要给用户一种感觉：这篇文章就是为我写的，我看完之后会解决自己的某个问题，或者能知道一些对自己有用的信息。

具体来说，有以下3种细分维度：

1. 身份维度：大学生、职场新人、程序猿、医生、职场精英、宝妈等等。

2. 场景细分：面试、约会、旅行、打架、运动、开会等等。

3. 标签细分：大众经济男、宅男宅女、二次元、霸气总裁、灰姑娘等等。

你需要做的就是把常规选题和这些细分维度做结合，比如用运动+宝妈，你就可以写《3种运动快速拯救宝妈的身材》，比如用减脂+宅男宅女，你就可以写《宅男宅女的减脂餐应该怎么做？》

选题+细分其实就是之前的九宫格选题法，大家可以回顾一下上节课的内容。

### 三、换视角

同样的一个选题，换一个视角，就会有新鲜有趣的答案。

其实这个方法咱们在学生时代就学习过，比如说同样是写春天，一个孩子看到的和一个燕子看到的就完全不一样，视角不同，感受力就不同，看到的景色和心理的想法就不同。

比如说拿最近社会争议很大的唐山火锅店伤人事件来说，成年人的态度一般都是：这伙人太恶劣了，一定要抓上周严惩。

但是转换一个视角，作为一个小学生，怎么看待这个新闻呢？这个是年龄的转换，如果是身份的转换，比如说医生怎么看待这种伤人事件呢？

再举几个例子：

老人是怎么看待王者荣耀这款游戏的？

娱乐圈是怎么看待郭德纲的？

小学生是如何看待知识付费行业的？

如何才能找到转换视角的选题？

第一步：先列出各种身份，比如男人，女人，孩子，大学生，老板，相声演员，歌手，运动员等等。

第二步：找到一个选题，尝试用他们的角度去聊一聊。

### 四、做系列

这个大家就很熟悉了，比如常见的《100个xxx小技巧》系列，就是最简单的系列内容选题方法。

抖音上也能看到很多这样的选题方向，比如《100块钱怎么花系列》、《100天减肥日记》、《挑战和100个陌生人要联系方式》等等。

做系列选题的好处就是能够降低选题难度，而且一旦某个选题内容爆了，用户看到你这是个系列性的内容，就会关注你，订阅你的更新。

## 15、如何用内容经营你的个人 IP？（内容篇）

你要相信内容是个人 IP 经营和传播的唯一工具，你只有相信且尊重内容，才有可能通过它来帮助你把个人 IP 做好。

### 1、成功的个人 IP 有什么用？

① 增强信任感：信任感就是成交的基础，缩短成交周期，增加成交几率。

② 溢价空间大：一样的产品，如果我的个人 IP 比你强，我卖的价格就比你高，用户多支付的那部分钱，就是我的 IP 溢价。

③ 忠诚度较高：只有用户不愿意离开你，才能永远在你这里消费，才愿意帮助你传播个人 IP。

### 2、经营个人 IP 的2个误区

① 不是你说自己是谁就是谁，用户觉得你是谁才是谁。你给别人的印象就是一个知识分子，那么你输出的内容就不要充满市井气息。

迎合用户，才能加强自己在用户心智里的标签感，有了标签感，用户有需求的时候才能想起你。

老罗又要创业了，我就非常不看好，本身就是搞流量的，就应该继续去搞流量，卖自己的个人IP 就行了，再做产品我觉得 70%的概率还是死。在我心里，老罗就应该是讲PPT，卖课我觉得会更好。

② 个人 IP 不能一下子做出来，而是一点点通过内容经营出来的，你一定要有这个认知。做出来的个人 IP 是没有核心价值的，没有核心价值你怎么做交付？

### 3、构成个人IP 的 3大要素是什么？

① 核心价值

怎样用内容来体现你的核心价值？

倒推法：你要赚钱→需要有一个产品→你要把产品卖出去→这个产品对用户有什么用？

举例：正蓝需要赚钱，那我就需要有一个产品，我的产品是玩赚新媒知识星球，这个星球可以帮助用户通过自媒体赚到钱的。

以上就是一个简单的推导过程，无论你想通过什么赚钱，你的产品是什么，都可以用这个推导过程，把自己要输出的内容搞清楚。

② 个人态度

你的信仰是什么？你支持什么行为？你讨厌什么？你极度反对什么？

你要通过内容把以上这些表达出来，态度才是个人 IP 溢价的根本影响要素，核心价值的交付力在这个时代同质化程度太高了，你说你会弹吉他，会弹吉他的人太多了，别人凭啥喜欢你，凭啥买你的吉他课，你得有态度啊，你得有那个范儿，有人就喜欢你说话的那种感觉，她就买您的。

③ 外貌特征

这个算是个人 IP 的一个构成要素，但不是用内容表达出来，这里暂且不谈，不过很好理解，比如周星驰的大笑，扎克伯格的恒久不变的T恤，乔布斯的牛仔裤，马云的小毛衣等等。

最后总结一下，其实就一句话：干货 + 态度

首先保证你的内容有用，再保证你的内容有情绪，持续这样输出，你的个人 IP 就出来了。

## 14、实用类课程有什么好处？（产品篇）

今天上午一直在写《个人IP商业变现5步曲》这套课程，写到“如何制作个人知识付费产品”的时候，突然想到一个问题。

很多人喜欢去做“通识类”的课程，其实是不对的，在你没有个人 IP 的时候，尤其是想通过制作一套课程来帮助个人 IP 的变现和传播时，你一定要选择“实用类”课程去做。

实用类课程有什么好处？

1. 能够帮助用户解决具体的问题

2. 课程制作成本低

3. 可以聚焦更细分的行业领域

4. 课程交付成本低

你再看看通识类课程，比如说我自己很喜欢历史类的内容，在得到 APP 上买了《熊逸讲资治通鉴》《西方经济50讲》等课程，这些课程的内容量都非常大，基本属于年度更新系列。

作为一个普通人，你能付出这么大的工作量吗？作为一个普通人，没有得到 APP 这样的平台推荐，和强有力的学术背书，即使你做出来了，有人会买吗？而且做课还要磨课，谁给你磨课？磨人是需要在某个领域有一定知识储备的，通识类课程知识点那么多，你能找到吗？

而实用类课程，比如《7节课帮你变成美妆达人》、《14天PS小白变大神》都是很短小精悍的课程，相比通识类涨知识的课程，用户的收获感会更强，下单门槛会更低。

所以，做个人 IP 一定要做课程，做课程尽量选择实用类课程！

## 13、 你得给自己设定一个“IP敌人”（内容篇）

抖音上做知识付费的玩家总是互相锤来锤去，一锤就是好几个月。

做内容你就得给自己设立一个“IP敌人”，否则一个人演戏很难的，就好像没有于谦，郭老师去调侃谁呢？

你想象一个场景，骂人是不是很爽，自己也爽，看的人也爽，骂人者的情绪很自然的就出来了，围观者的情绪也出来了。

情绪对于内容有多重要，这个芷蓝之前说过，而 IP 敌人就是引导话题＋情绪最高的工具和玩法。

举个例子，比如说芷蓝现在的定位是：帮助自媒体创业者/品牌创始人通过打造个人 IP 来实现深度变现。

那么我的“IP敌人”就是那些每天狂发广告，不停消耗自己的 IP 信用和 IP 形象的那些人。我就可以针对这些人的营销动作，去输出自己的观点，自己的玩法，自己的一套营销价值体系。

这个过程是怎样的呢？

1. 先找到一个和自己 IP 对立的角色，不必要非得是某个具体的人，当然如果你敢怼也有时间去怼，也没问题，根据自己的性格来操作即可。

2. 把这个角色的核心价值、行为特征和外贸形象一一列举出来，越具体越好。

3. 逐一去反驳这个角色的各种行为和价值观，但是你在反驳的时候要把自己的干货植入进去，就好像现在小关老师一样，在骂李一舟的同时，把自己做生鲜带货直播的各种技巧植入进去。

大家一定想明白，一个强 IP，必须有自己看不惯的人，想骂的人，想怼的人。一个人的脱口秀很难演，对你的创作能力要求非常高，但是 2 个人演一台戏就轻松多了，观众也爱看。

## 12、到底什么是内容？（内容篇）

到底什么是内容？

宽泛来讲，文字、图片、视频是内容的3种基础形态，而文字和图片属于冷内容，视频属于热内容。

用户接受热内容要比接受冷内容更容易些。比如说西游记这部小说，读原著对于人们来说是最难的，稍微容易一点是看连环画，最爽的就是看电视剧和电影了。

为什么会这样？

因为冷内容需要人们主动去思考，而热内容创作者利用图片+声音+文字的形式，降低了用户的思考难度，降低了用户接受信息的门槛。

这就是为啥很多人不愿意读书，却喜欢刷短视频的原因。

但在这个时代，只要你的内容是够优质，越是高价值的用户，越愿意主动参与到与你创作冷内容的深度链接中。

很多人问我：芷蓝你不做短视频，只写长文，能赚到钱吗？有人愿意为你付费吗？现在都是短视频时代了，你不做短视频，是不是在和时代对抗？

首先，我不是不做短视频，而是不擅长做短视频，我也做，就是做的少而已，没有镜头感，对着镜头说话会比较别扭。
