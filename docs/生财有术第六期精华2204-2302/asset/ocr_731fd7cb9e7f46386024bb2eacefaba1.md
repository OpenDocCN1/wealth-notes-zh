2. 我对他们负责，但是他们没有要负责的人
3. 对团队归属感不强
4. 沉淀成本不够大

那这些问题怎么解决呢？

# 1） 遇到的困难大于个人能力，拿不到结果，不想做了

增加我们和学生联系的频率，多夸奖鼓励，多提问教导，让遇到超出能力范围的问题会来主动咨询我，以此让他们保持能力和所做的事情难度相匹配，不光能做，而且还能做好，做出成果。

# 2） 他们没有人需要负责的人怎么办？

给这些能力较强的负责人，赋能增加责任，帮他们去搭建自己的小团队，让他们也成为管理层，这样他们由单一的对我交付转变为对多方交付。不仅不会挑桃子，还可以增加他对我的粘性和信任度。

# 3） 归属感不强怎么办？

增强吸引力，多元化赚钱、提升能力、提供好的环境、交志同道合的朋友、开拓眼界。

不用单一的赚钱来吸引他们，不管做什么学到和赚到总会有一样，其次通过一些技能去增加他们的能力，通过认知思维培训+案例拆解去提升他们的眼界思维。
