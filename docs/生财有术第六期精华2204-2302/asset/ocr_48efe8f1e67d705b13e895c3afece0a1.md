# 1. 内容模版

这个属于神奇效果能直观呈现的魔术，按照「爆点前置+教学」的脚本模版，配口播讲解

# 2. 他的重点在口播文案——

+   1）统一视频开头：“好，大家仔细看哈”语音提醒，仔细看什么？引发好奇

+   2）边做动作空手出烟，边讲解

> “空手在这里搓一搓，诶，奇迹出现，就像神话里传说的一样，手指搓一搓就会产生魔法般的烟雾”

观众一看，确实好神奇，为什么你的手冒烟了？

+   3）视频第10秒有引导点击购物车的动作，之后才开始正式教学

“道具在这边”目的：下语言行动指令，并用手指向左侧购物车，提高购物车点击率

引导也可以放在最后，但完播率会影响点击率，一部分没等看完就滑走
