# 五、新人想做的门槛

1.建议先确定好自己的变现方式，尝试先自己做账号。

有了明确的变现方式，无论是自己做账号还是投放，都会有侧重点，这样会更符合客户的需求，更容易引流和成交。

自己做账号可以做深度的经验分享，也可以做最简单的资料分享。投放需要一定的成本，一上来就盲目投放会打水漂的，所以不能着急，欲速则不达。

2.把整个流程路径梳理好。需要何种需求的粉丝，如何将他们引到私域、引到私域如何进行成交。

3.个人要有一定的精力甚至能力。大家应该看得出来，无论是我还是上述同行的玩法，其实有一个共同点就是，一个人要身兼数职，一个人就是一个团队。

4.坚持，大力出奇迹。一定要坚持，无论是自己做号还是投放，都需要一定的积累和摸索，不可能一蹴而就的。

5.需要持续的输入和输出。学习类的内容很容易依赖自己的经验，而往往自己的经验是有限的，要多去输入外来的知识，这样才能保证持续的高质量输出。
