# 【一】前期准备：账号定位、主播、产品

# 1. 账号定位：就是要做什么类型的直播间

大家根据自己的经验和资源来选择方向，一定要选择自己擅长的，而不是哪个热做哪个。

普通标品还好，像服装这种非标品如果不懂尽量别碰。我之前做过男装、开箱、家居等，都能做起来，就觉得任何品类只要去学都能做。但这次做女装，不懂品真的踩了非常多坑。

开始我是做朋友那批oversize国潮女装，是有供应链优势，但是自己完全不懂这类穿搭。

由于做的早，在抖音还找不到对标账号。自己做了四五个账号，数据一塌糊涂。后来转型做牛仔裤，拍的视频是偏辣妹风格，这个风格我更有把握一些，也能找到对标账号，通过模仿爆款视频，数据一下就起来了。

像抖音销量榜上，好的女装直播间，核心主播或老板娘好多都是开过档口或者服装店，对服装有多年的积累，不是外行进入轻松做起来的。

当然也不是说服装不能做，我一个是直男也在做女装牛仔裤。但是团队里一定要有人懂品，自己不懂就找个产品负责人。
