+   · 上市、擱滿6個月且非外幣買賣的受益憑證

至於融資融券的成數，在一般情況下，上市股票融資成數為60%（上檔50%）、融券需繳的保證金為90%（上檔100%），也就是說，融資的自備款是40%或50%，融券則需準備保證金90%或100%。另外，融券賣出時還要繳「借券費」，是成交金額的萬分之八。

以融券賣出為例：

# 買賣計算題

阿明融券賣出聯電股票五張，成交價15元，融券成數90%，借券費萬分之八

```
融券借券費=15× 5,000×0.08%=60
融券保證金=15×5,000×90%=67,500
手續費+交易稅=75,000×0.1425%×0.3%=332
交易成本=67,500+60+332=67,892
```

另外，融資是券商借錢，融券是支付保證金借股票賣出，兩者都需計算利息，不過融資是投資人需要支付利息給券商，融券則相反，券商需付你利息。計算方式分別是：

```
融資利息支出=融資金額 × 融資利率 × 天數 ÷365
融券利息收入=支付保證金 × 融券利率 × 天數÷365
```

目前各券商的平均融資貸告利率約5～6%，融券利率則很低，通常不到1%。
