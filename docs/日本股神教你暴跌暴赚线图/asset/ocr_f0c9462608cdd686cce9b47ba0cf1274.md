# ○ 世界上最安全的賣空技術

賣空就像一把剪刀，對從來沒有用過剪刀的小孩來說，剪刀是危險的尖銳物品，但只要能正確使用，就是方便又安全的工具。

賣空也是一樣。若能學會這門技術，就會是一項安全又便利的工具，讓你不只上漲能賺，下跌也照樣賺錢。

正因如此，我希望你不是只會做多，也要習慣做空。無論是股票每天零碎式的下跌，或是大暴跌，我希望大家都能把下跌反過來看成是「機會」。

那正是打從心底裡深愛著股票的我，最大的願望。

如果大家能藉由本書，不只學會用「買」，更懂得用「賣」來賺錢，並且百分之百、甚至百分之千的喜歡上股票投資，那我真是再高興也不過了！
