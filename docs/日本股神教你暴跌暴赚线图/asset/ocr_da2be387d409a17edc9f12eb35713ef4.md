# ⊙ 一旦學會賣空，勝出機會就是兩倍！

在股票上漲時做多，下跌時做空，如此一來，股票所有的價格波動都能轉換成利潤！

既然股價注定得不斷上上下下，那麼，如果只在上漲時才買，機會就只有50%。

學會在下跌時做空賺取利益，才真正能發揮100%的功用！

拒絕從事賣空的股票投資，就像是從一開始就放棄一半機會的乏味人生一樣。不會做空的投資者，一旦看到報紙出現「股價暴跌」四個大字，就開始心慌意亂，只能抱著「再也不敢碰股票了」的心情從股市退出。

對我而言，那些因為股價暴跌而紛紛放棄投資的人，才更令我感到傷心扼腕呢！
