下跌趨勢下，股價與均線從上往下，以20日線＞5日線＞股價的順序排列，三者維持一定程度的間隔，並保持平行往下跌的型態——此刻的蠟筆，才正是做空賺錢的時機。下跌蠟筆發生前，若能事先布局做空，再配合蠟筆確定亮燈後所建立的空頭部位，即可提高獲利。

相反的，下跌蠟筆的排列順序要是崩塌了，就應該考慮暫時先獲利了結（請見下頁圖2-17的 a）。

圖中雖然沒有顯示3日線、7日線，但是使用線圖軟體練習，或是在實戰買賣時，建議在5日線之外，再加上這兩條線。當位於下跌蠟筆狀態的3日線與5日線轉而往上，或是轉向持平，並與7日線交接的時候，就可以視同下跌獲利了結的時機。

# # 鳥嘴

5日線由下往上突破20日線的時候，兩者成銳角型的交叉，就是「鳥嘴」訊號。相反的，5日線由上往下以銳角穿破20日線時，則是「反鳥嘴」，股價的趨勢轉為往下走，顯示投資人的角力關係由多頭優勢轉變為空頭優勢。

5日線與20日線的傾斜度越陡，角度越銳利，便可判斷鳥嘴訊號的趨勢轉換力道越強勁。

一般稱短期均線與長期均線的交叉為「黃金交叉」「死亡交叉」，但是當長期均線持平時，經常出現看似交叉、隨後股價卻又糾纏進入 B（盤整）的情況。
