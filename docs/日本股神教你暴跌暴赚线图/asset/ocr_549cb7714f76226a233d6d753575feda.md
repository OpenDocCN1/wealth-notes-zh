# 10 進化版的「忍術K線隱身術」練習法

我的股票交易，正在不斷地升級進化。

我一直思考：「有沒有什麼思維方式、手法、技術，讓初學者也能簡單又輕鬆的賺大錢？」

總之，對初學者來說，最高的門檻莫過於「股價」本身。

「股價」這小子就是反覆無常、見異思遷，像桀驁不馴的野馬一樣令人傷腦筋。與橫衝直撞的「股價小子」交手，確實是辛苦又折騰的工作。

對此，你需要一項已經很熟悉的技巧——「忍術K線隱身術」。

K線有時會純化我們的判斷，因此首先只顯示均線，把股價真實的走向深深烙印在腦海。之後再同步顯示K線，根據純均線圖中所看到的走向，進行買賣。按照這兩個步驟進行交易，才能做到正確無誤。

此外，為了使這招「K線隱身術」更加進化，我決定迎接新的均線夥伴。

那便是3日線、7日線，還有10日線這種短期均線。
