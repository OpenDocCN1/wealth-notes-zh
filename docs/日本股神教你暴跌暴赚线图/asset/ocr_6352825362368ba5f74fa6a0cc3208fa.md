# 06
在心裡描繪上漲或下跌的「故事情節」

總之，詳讀過去的線圖，若能看到將近 1 萬年份，就能得到各式各樣的啟示：「開始下跌時，會發生中期及長期均線密集靠攏的狀況。」「下跌行情從反 N 大訊號開始。」「下跌是否持續，是以 5 日線的低點往下走來判斷。」「用均線的排列方式來判斷趨勢的變化。」

藉由無數次反覆解答股價的考古題，在腦海中建立思考迴路：「那樣的話，就會變這樣。」「這樣變動的話，接下來會那樣，然後再接下來會這樣變動。」在心裡描繪出各種模式的「故事情節」，是投資時很需要的關鍵。

# 🔍 如何在下跌過程中判斷止跌的時機

若你深信「下跌或上漲都不是永遠的」，那麼上漲的時候就要預測什麼狀況下會停止上漲、開始下跌；下跌時便預測之後發生什麼狀況會止跌起漲。養成「預測未來」的習慣。
