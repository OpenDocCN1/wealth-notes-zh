# ## N 大、反 N 大

N 大是分歧的變形，也是在趨勢轉換的初期階段經常出現的訊號。

反 N 大的情況是指，在20日線上方的5日線越過20日線開始下跌，又暫時反彈上升到20日線附近，然而沒能超過20日線，又再次開始下跌，並相對於20日線畫出大寫 N 字型後下跌。

也就是先出現烏嘴，再形成分歧的情況。

發生趨勢轉換的最初期階段，經常會發生 N 大，此時很可能會發展成一波大行情，因此要特別注意。
