# 圖 4-14 20 日線、60 日線死亡交叉前後的價格波動

![](bbox=[0.2, 0.15, 0.85, 0.45])

這時候回顧過去的股價波動，會發現趨勢的轉換雖然是發生在死亡交叉的 A 點，但實際上，下跌趨勢早在交叉發生前就開始了。

也就是說，以20日線與60日線的交叉來看，若能在6億年持續上漲期間內的黑線③附近就開始賣出，即可賺到更可觀的跌幅。

圖中的粉色區塊雖是上漲趨勢，但股價持續下跌，某種意義上來說，這是準備迎向下一波下跌趨勢的助跑期，也可以說是一種「非武裝中立地帶」。

橘色的區塊顯示，若在前一波趨勢轉換中已經做多的話，由於5日線與20日線的上升「饢峯」也結束了，此時即是實現多頭利益的時間點。
