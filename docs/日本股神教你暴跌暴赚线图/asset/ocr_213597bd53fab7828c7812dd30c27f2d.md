# 13 風險與回避①

# Q 為什麼可以賣出並未持有的股票？

把跟朋友借來的愛馬仕包拿去當鋪、換成現金，等到不還不行的緊急關頭，再繳交本金與利息來贖回包包（把典當的物品取回）。若被發現把包包拿去當典，朋友應該會跟你絕交吧。

但是，股票的賣空就很類似這樣的概念。藉由賣出並未持有的股票，即便得支付利息，還是可以賺到錢。

我想，初學者應該很難理解為什麼竟然可以賣出並未持有的股票，這是因為有人會借股票給你。

世上很多金融機構、年金基金、公司老闆及母公司等等，他們並不是很在意股價的上下上下下，必須長時間持股、絕不賣出。這樣的投資主體相當多。

也有一些投資者是單純長期持股，以獲得股利，暫時無意交易。因此會把股票借給別人，藉此賺取融券利息。

為回應這些投資者的期望，「證券金融公司」便會透過證券公司扮演「把錢跟股票借出去」的角色，負責實際營運「制度信用」。
