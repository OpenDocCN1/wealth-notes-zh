# 04
# 多空雙賺的相場式訊號&法則

想在準確的時機買賣股票，就得仰賴優秀的買賣訊號，以及足以用來判斷買賣的可靠基準。

我在投資股票36年後，將這些知識集結、編寫成各種獨創訊號，每一個訊號都擁有相當獨特的名稱。目前雖然尚未申請專利，但是這些訊號的性能，我都可以掛保證。

在我先前出版的著作中，已經詳細解說如何進行「這裡要買／賣」「這裡要獲利了結」的判斷時，運用哪些訊號。不過，接下來我會調整為放空專用的形式來介紹。

# ### 「下半身」「反下半身」與均線的排列

「下半身、反下半身」——這個聽起來有點怪怪的、令人不禁噗嗤一笑的訊號名稱，是相場式交易的代名詞。

由K線與5日均線交織而成，是非常浪漫的愛情訊號……不對，是股票訊號。

圖2-8即是此概念圖。K線柱體部分以穿越5日線的形式，形成一根由上到下穿破的黑線，就是宣告股價要開始下跌的「反下半身」。
