# 圖 4-9 從 PPP 到純 NON 的後續走勢，都可以靠賣空進攻

「從 PPP 變成純 NON」就賣空，從「反 PPP 變成純 NON」就做多

![](bbox=[0.14, 0.2, 0.82, 0.47])

不過，單純擁有知識，與確實擁有技術，完全是兩回事。

總之，知識是否真的能活用，有賴於「現場」實戰。

請你嘗試觀察各式各樣的個股線圖，找出「從 PPP 變成純 NON」以及「反 PPP 變成純 NON」的過渡期，或者是相反的局面，並實際套用上述的手法。

我說過，股市中有六成行情是 PPP 類，剩下的四成是純 NON。但是在某種意義上，純 NON 就像「蟲蛹」一樣，顯示趨勢行情的最初期階段。也就是說，它是在蛹蛻變成蟲、即將產生正式的趨勢前，能夠最快察覺趨勢即將發生的階段。
