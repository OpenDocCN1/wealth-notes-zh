# 圖 3-18 日經平均股價指數暴跌後，止跌→反彈上升的狀況

![](bbox=[0.145, 0.162, 0.804, 0.466])

來到這附近之後，就越來越少出現連續的黑線，紅線數量開始變多。原本一直往下走的20日線開始轉為盤整，當穿越20日線的紅線④與5日線突破了前一個高價之後，此處出現的紅線⑤，即可視為正式做多的大好機會。

要注意的是，股價數度嘗試往下的同時，20日線卻呈現持平沉睡。在急速下跌的行情後，首先位於高價的20日線會成為阻礙上升的障礙，有時候則是60日線會形成阻礙，但是20日線從往下走轉為持平的話，就表示行情要往反彈上升的趨勢轉變了。這可說是我們從圖中解讀出來的心得。
