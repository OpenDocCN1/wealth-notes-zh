# 03 需要的武器
只有 K 線與均線！

想讓股票交易更順利，就必須反覆練習、鍛鍊、修行，成功關鍵是不能光在腦中死板思考，而是要成為一個可以自然活用手與身體的「股票職人」。

優秀的職人都擁有保養遇到的「工具」，而且工具數量以少為佳。因為買賣股票時，要定點觀測價格變動，趁早察覺變化；太多的工具，只會使你迷惘而已。

誠如許多人已經知道的，我所使用的工具，就只有「K 線」與「均線」而已。這項原則不論做多還是做空都適用。在此，我們先介紹在「賣空」上特別優秀的工具吧。
