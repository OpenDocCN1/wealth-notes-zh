# 圖 2-1 K 線的形狀與期間內發生的價格變動

> 觀察 K 線的形狀，該期間中的價格變動就會立刻浮現！

| | |
|---|---|
| **大紅線** 幾乎是一直線往上漲 | **大黑線** 幾乎是一直線往下跌 |
| **上影紅線** 上漲後雖然失速，仍以上漲告終 | **上影黑線** 上漲後失速墜落，以下跌告終 |
| **下影紅線** 下跌後反彈上揚，以高點作收 | **下影黑線** 上漲後反轉下跌，但跌幅縮小 |
| **小紅線** 上下大幅震盪，但結果以小漲作收 | **小黑線** 上下大幅震盪，但最後以小跌作收 |
| **十字線** 雖有大幅震盪，但結果不變 | **倒 T 字線** 急漲後又急跌，結果還是不變 |

即便是同一種 K 線型態，期間也會有各種價格變動，感覺也會有微妙的不同
