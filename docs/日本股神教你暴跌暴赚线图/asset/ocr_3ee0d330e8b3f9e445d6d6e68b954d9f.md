# 5日和20日線交織而成的訊號一覽

我的口頭禪是「人生只看紅與綠」。紅就是女性……抱歉，我是說5日線，綠就是男性……不，是20日線。

線圖上的5日線與20日線都在蜿蜒蠕動著。5日線可以直接反映出股價的震盪變動，因此「曲折度」較高。兩條線忽近忽遠忽而交錯，以各種型態移動，指示我們股價的方向性，也就是趨勢的持續、加速、失控、轉換。

我過去的作品曾提過，5日線與20日線上出現的許多訊號，都對做空的買賣判斷頗有幫助。

雖然稍微扯遠了，不過我們可以先看一下子這些訊號的使用方法。

# 蠟筆

相場式訊號「蠟筆」是指5日線與20日線保持間隔距離，並呈現平行狀態，往同一個方向上漲或下跌。

在下跌「蠟筆」持續的期間，繼續賣出的話，獲利就會越來越多。下跌速度加快的話，兩者的間隔會從平行方向逐漸擴大，但仍可視為蠟筆訊號持續。

5日線與20日線同樣持平的時候，即便看似平行，也不可以視為蠟筆。
