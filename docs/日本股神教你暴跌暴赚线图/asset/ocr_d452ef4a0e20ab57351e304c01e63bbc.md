# 🕒 用實戰線圖來看下半身、反下半身

如何區分「買賣中可使用／不可使用的下半身、反下半身」呢？以下就以具體的線圖來解答。

圖 2-14 是 2017 年 11 月到 2018 年 3 月，三井金屬的日線圖。圖中除了 5 日線之外，也顯示了 20 日線、60 日線、100 日線。如此一來，相信你應該能夠判斷：「在哪個反下半身賣出的勝率會比較高？」「哪個下半身即便買了也很難成功？」

基本上，60 日線、100 日線等長期線往上揚的時候，長期線會扮演阻止股價下跌的緩衝角色；買在隨後出現的下半身，才是正確答案（例如圖 2-14 ①）。當 20 日線往上走的時候，買在 20 日線上方發生的
