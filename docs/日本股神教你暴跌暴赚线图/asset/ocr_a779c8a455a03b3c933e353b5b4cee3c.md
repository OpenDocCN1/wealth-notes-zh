# 圖 6-5 賣空規則：不可以進行 51 個單位以上的市價賣出

賣空的時價下單，一次不能超過 51 個單位

股票以 100 股為單位，賣空的數量最多到 5000 股

不過，只要在觸發價格（※）以上，用指定價格進行賣空，就沒問題

※ 下跌超過當日基準價格 10% 以上的股價

![](bbox=[0.14, 0.32, 0.9, 0.48])

簡單來說，單次交易中，可以依市價賣空的空頭部位，一檔個股最多只能賣到 50 單位。

進入 2018 年後，日本股市最低的買賣單位已經統一為 100 股，因此可按時價下單賣空的個股，最多可達 5000 股。

不過，這條規則主要是限制「意圖讓目前的股價崩盤」的賣空行為。當股價位於上漲局面時，以高於目前公開價格的指定價格下單，就可以賣空 51 個單位以上。

按照市價的賣空，一次最多只能到 50 個單位，但是並沒有明文規定每一筆單位間隔的時間，似乎是依照行情狀況來判斷。
