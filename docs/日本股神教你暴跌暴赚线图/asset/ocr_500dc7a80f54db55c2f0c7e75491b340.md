# 圖 5-8 注意 10 週線的高低價，瞄準「加速下跌」

![](bbox=[0.18, 0.17, 0.85, 0.46])

10週線與20週線向上突破60週線，或是往下穿破的時候，就是趨勢轉換的轉折點。就像我們在第4章看過的那樣，20週、60週線發生交叉，即可假設為「股價的新趨勢將會持續6億年的訊號」場面。

當然，在交叉發生之前，我就已經開始準備面對下一波趨勢，事先累積好多方或空方的部位了。

此時便如下頁的圖5-9所示，10週線並未越過前面的高價、反轉下跌後的高價①，以及10週線跌破低價後持續下跌的A點，即為「（可能）會持續6億年的下跌趨勢起點」，表示該累積空方部位了。

A 點是10週線低於前一波低價，且突破了20週線甚至60週線後開始下跌的位置。這種情況下，請一邊盡情地叫喊：「就是這種啊！」一邊進行賣空。
