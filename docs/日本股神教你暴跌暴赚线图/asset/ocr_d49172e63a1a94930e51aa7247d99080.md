+   - 均線排列呈現為 PPP 的時候，占所有股價變動的26.5%
- 反 PPP 的時候，占17.5%

（二者合計為44%）
- NON 的時候則占56%
- NON 當中，準 PPP 占13% （整體的7%）
- NON 當中，準反 PPP 占16 % （整體的9%）
- 純 NON 占71 % （整體的40%）

以上是日經平均股價指數的資訊，講白一點就是：「股票的價格起伏，約有六成是趨勢行情（剛才定義的 PPP 類的狀態），剩下的四成是無趨勢行情（純 NON）。」
