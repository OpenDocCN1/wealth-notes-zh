# 注意「整數的股價大關」和 3 個月、6 個月的「時間區間」

相場式投資法中非常重視股價波動的轉換點，即為「整數大關」。若是三位數的股價，即為 100 點或 200 點，1000 點也很容易成為一個大關卡；其次是 150 點或 250 點這種以 50 點為單位的數目。

四位數的股價的話，就是 1000 點或是 5000 點容易成為關卡，再來則是以 500 點為單位。如果是像日經平均股價指數一樣，達到 2 萬多點左右的時候，1 萬點或是 2 萬點大關是最重要的，接著就是 5000 點，其次是每 1000 點的關卡。
