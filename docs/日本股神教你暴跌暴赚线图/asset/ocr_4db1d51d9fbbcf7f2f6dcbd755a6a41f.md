# 不斷練習，凡夫俗子也能成為賣空高手

說到賣空股票，大多數人都抱有根深柢固的印象：「很可怕、會賠很多、很難」。可能是因為這樣，賣空總是給一種必須皺眉苦思才能展開行動的「氛圍」。

有些人會想得很複雜：「少子化、高齡化且持續低成長的時代，股票不可能上漲。」「最近年金基金也大量買入股票，但是考量到年金支付及行情下跌時的操作惡化，感覺會有巨大的賣壓。」但是一定要想得如此艱深，才有可能在賣空上獲得成功嗎？很多人抱持著先入為主的成見，認定像自己這樣的初學者絕對不可能辦得到。但這真是天大的誤會。

除了剛才介紹的「股價的關卡」之外，股票職人相場師朗還擁有許多技術。

只要將本書傳授的各種技術好好練習一番，不斷練習累積，凡夫俗子也能成為「放空高手」。請你儘管放心吧！
