# 日本股神的獲利有六成來自「賣空」

當然，「安倍經濟學」初期的2013年上半年，或是川普當選總統後股價急速上漲的2016年年底等，在強勢上漲的行情中，無視價格、只求買進的股票「現價買入」現象，也會造成股價以相當快的速度飛漲。

即便在這種情況下，也會因為不少投資人認為「已經賺夠，該賣掉了！」而獲利了結，因此股價也不是一直線往上涨。

若股價持續急速上升，便會有對風險敏感度較高的人擔憂「漲太多了，好可怕」，使上升態勢減緩。

股價傾向緩步上升、急速下降，因此做多與做空的買賣方法也必有所不同。

做多的時候，由於上漲速度是緩慢的，因此要配合「突破這個高價就買入」「降到這個低價後，一旦反彈就買入」，這種退一步、進兩步的上下律動，即可穩扎穩打地進貨。

相對的，做空的時候，就必須磨練出比做多時更敏銳的觀察。

雖說股價下跌是急速的，但這個下跌是不是真的跌得又急又多，誰也無法事前預測。

正因如此，對於「明明之前漲勢很好的，卻無法創新高」或是「碰到500點或是1000點這種整數股價的時候就會轉下跌」這類在價格波動中發生的細微「變化」，能否敏銳地察覺，是比做多的時候更看重的能力。
