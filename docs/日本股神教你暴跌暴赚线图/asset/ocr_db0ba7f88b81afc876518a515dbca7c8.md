# 在實戰線圖中預測「下下一步」

若能夠預測股票的「下下一步」「未來走勢」，那麼就算出現煙火般的急速上漲，或是遭遇槍林彈雨似的大暴跌，也能對當下發生的變動歡欣鼓舞，無須感到恐懼或沮喪。

最重要的是「冷靜地看，冷靜地思考，冷靜地應對」。
