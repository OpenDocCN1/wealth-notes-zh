歡的短期買賣中。如此一來，全新的「零K線」減肥法……不，是「股票交易法」，就這樣誕生了！

有一句古老的日文名言：「若隱若現才是美，毫無遮掩則不美。」

把K線遮掩起來，反而更能清楚看出K線的動向，這種手法對「賣空」極為有效。

# 「來回閱讀」掌握走向

首先，第一步是將線圖上的K線消除，只顯示從超短期到中期的均線：3日線、5日線、10日線、20日線、60日線。

然後按照時間先後，依序觀看線圖，一直看到現在的最新線圖。這一階段完成後，再反過來從現在回溯到過去，再看一次。利用這種反覆閱讀的方式，把股價的走向深深烙印在腦海中。

透過日本PanRolling研發的「線圖集錦」（Chart Gallery），或是我本人在2018年秋天獨創研發的線圖軟體「SHIRO指標」，就能看到股價30年來的波動狀況。（編按：台股的歷史走勢線圖，可參見台灣證券交易所或各大券商網站服務。）

圖5-1是日經平均股價指數在2017年～2018年間走向。請特別注意均線的排列、交叉以及傾斜度。
