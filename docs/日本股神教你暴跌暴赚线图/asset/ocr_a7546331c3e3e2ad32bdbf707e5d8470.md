# 台股的融資融券與借券相關規定

唐祖貽

第6章提到日本股市關於融資融券交易的相關規定，日股的融資融券交易分為「制度信用」與「一般信用」兩類。前者相當於台股的「融券交易」，是受到證券交易的管制才能進行的交易。

台股有關「融資融券交易」的規定其實和日股的「制度信用」大同小異，同樣要先開立「信用交易帳戶」。至於開立信用交易帳戶，需要具备的條件有：已開立普通買賣帳戶滿3個月，且最近一年買賣成交10筆以上，累積成交金額達所申請融資額度之50%，另外申請時需附相關的財力證明。

目前台股的信用交易額度共分15級，從最低額度50萬到最高6000萬元。投資人可以視自己的財力狀況與交易記錄，決定申請哪一級。

另外，以台股來說，要成為融券交易的標的，需符合以下三個條件之一：

+   ·上市、櫃滿6個月且每股淨值在票面（10元）以上的普通股股票。若無面額或每股面額非屬10元者，為上市滿6個月且財務報告顯示無累積虧損

+   ·上市、櫃滿6個月且財務報告顯示無累積虧損的臺灣存託憑證
