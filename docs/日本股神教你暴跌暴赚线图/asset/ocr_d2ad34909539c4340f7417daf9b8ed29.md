# 拼命練習，誰都能成為股票高手！

股價的本質就是反覆地上上下下。而它的價格波動可說是一半上漲、一半下跌。被買進的股票，幾乎都一定會面臨「被賣掉」的命運。

也就是說，如果僅以「做多（買入）」來迎戰股市，勝率就只有一半。

而且如此一來，就連要將這一半的機會全部轉換為獲利，也是非常困難的事。想持續獲利，就必須擬定這樣的戰略：「上漲」時就以「做多」取勝；「下跌」時就以「賣空」取勝。

若能充分利用賣空，即便下跌行情也能持續賺錢。「上漲」與「下跌」是兩種完全相反的波動，但對股票市場的獲利來說，卻是「缺一不可」。本書即是聚焦於將「下跌」化為獲利的「賣空」技術。各位讀完我的相場式技術之後，覺得如何呢？

你是否會心想「這種事怎麼可能做得到！還不就是事後諸葛而已」？然而，本書的內容，都是我和我的「股票私塾」學生在實際交易後，所檢討的思考方式與部位操作手法。
