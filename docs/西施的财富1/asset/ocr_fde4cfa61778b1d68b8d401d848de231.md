# 十、年轻人就业指南——田忌赛马：
如何更容易成功

如果说事业的成功有捷径的话，那就是选对行业，选对手。
选择竞争力较弱的行业，选择实力较弱的对手，那就更容易胜出。

鸱夷子皮说完，猗顿和白圭喜形于色，兴奋异常。

第一位同学默默站起，走了。第二位同学走到鸱夷子皮面前，对他深深地鞠了一个躬，说道：“鸱夷先生，我叫秦越人，爱好钻研道家的阴阳变化之法，对金融投资也有浓厚的兴趣，虽然风险意识不符合您的要求，但我请求您收下我这个学生，以后我一定发奋努力，以勤补拙，弥补我的不足。”
