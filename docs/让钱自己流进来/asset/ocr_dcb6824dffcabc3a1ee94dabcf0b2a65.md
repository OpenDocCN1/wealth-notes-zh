# 【自序】
**只要願意，就能擺脫貧窮**

我努力奮鬥十多年，但卻一直無法真正致富，
直到我發現了永不缺錢的秘密！
我告訴自己我不是有錢人的後代，
但我將是富人的祖先。

一瓶礦泉水在大賣場賣25元，擺在五星級飯店賣100元，而在社舞帆船飯店就要300元，但如果是在沙漠裡，對一位即將渴死的旅人來說卻是無價的。一個人的價值不在於他本身是怎樣的人，而是在於他所處的位置。多年來我一直在思考的問題，就是如何能創造更好的人生價值。

回想小時候，出身於一個非常貧窮的家庭，父母不識字又養育6個小孩，因此媽媽一個人兼4份工作。在我10歲那年，母親懷有8個月的身孕，卻依然每天騎腳踏車出門工作。有天她出了車禍，在家只躺了3天，就急著出門上班，我流著淚說：「要是我們家有錢，就好了！」媽媽告訴我：「我們對人生或許有失望，但不能絕望！張家以後就靠你了……」
