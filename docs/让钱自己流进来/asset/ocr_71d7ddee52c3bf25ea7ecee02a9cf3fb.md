# 【推薦序】

# 貧、富間只站在了兩個字「觀念」

對富人來說，
金錢是拿來投資並創造財富的「資產」；
對窮人而言，
金錢的功能只是取得生存的工具。

陳光是我求學時代最要好的同學。他在我心目中，是一位樂於助人、並散發陽光氣息的男孩。記得大學時代，我們一起研究財經、投資新趨勢，那一段令人難以忘懷的學生歲月啊！彷彿整個社會經濟部掌握在我們研究生的報告裡。

某些特定的因素，讓陳光長期且持續關懷貧單。看過陳光的《工蟻》、《學富致富》等書，在在告訴大家：貧窮，只是一個觀念，絕不是口袋裡金錢的多寡問題。由於M型社會的衝擊，這次陳光與景富攜手合作共同推出《讓錢自己流進來》一書，直接點出許多民眾對於財富知識的不足，長期陷入金錢追逐的無辜。書中結合兩人專業的財經背景與長期豐富的實務經驗，道出貧者與富者在觀念上的一些差異。
