# 二、選擇賺小錢或是大錢

量大，是致富的關鍵。

一般平凡人想的是一夕致富，短期內賺快錢、賺大錢（最好中樂透頭彩），但大財團所思所想的，卻是賺籠大客戶群持續消費的小錢，例如：大哥大業者擁有500萬個客戶群，如果每個門號僅收200元月租費，至少也能月入10億元。
