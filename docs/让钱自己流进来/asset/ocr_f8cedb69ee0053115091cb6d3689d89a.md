# 貧窮，是教出來的。

賺錢是一種遊戲，
這個巨大的遊戲，
如果我們不清楚遊戲規則，
根本贏不了！

巴菲特說：「如果你玩撲克牌遊戲，經過二十分鐘還不知道誰是凱子，那麼凱子就是你。」賺錢是一種遊戲，這個巨大的遊戲，如果我們不清楚遊戲規則，根本贏不了！

貧窮，是教出來、會遺傳的。從小養成舒適型的消費，是讓貧者越貧窮的最大原因。財富要是透過學習而來，一般的父母，只會教孩子多讀書，很少教孩子理財知識，學校的課程也很少設計（通常老師自己不知道），每個人自己摸索一輩子。長時間與資產的耗損，因此拖垮一生，也連累好幾代的命運與未來。

如果看過《富爸爸，窮爸爸》這本書，將會發現，大多數E象限與S象限的人，是因為聽信其他同象限人的建議，才會走不出貧窮。賺錢是一種遊戲，大多數人不知道如何玩
