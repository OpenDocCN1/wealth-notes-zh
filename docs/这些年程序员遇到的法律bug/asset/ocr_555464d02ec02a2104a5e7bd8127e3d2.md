# 夫妻共同财产问题的处理

问：婚姻无效的情况下财产如何处理？

叶星云与叶嫣然两个是表兄妹。两个人在一起时间久了，双方成了情侣。为了，能够在办理结婚登记手续，叶星云与叶嫣然隐瞒表兄妹的真實情况。后来双方感情不合请求，请求法院判决婚姻无效，并且分割夫妻共同财产。

按照《婚姻法司法解释一》第九条的有关规定，婚姻宣告无效，夫妻共同财产问题，还是按照离婚的有关程序处理。

《婚姻法司法解释一》第九条规定：“人民法院审理宣告婚姻无效案件，对婚姻效力的审理不适用调解，应当依法判决；有关婚姻效力的判决一经作出，即发生法律效力。涉及财产分割和子女抚养的，可以调解。调解达成协议的，另行制作调解书。对财产分割和子女抚养问题的判决不服的，当事人可以上诉。”

问：如果一方转移财产，在不离婚的情况下可以分割夫妻共同财产？

叶辰和安雪结婚后，因叶辰身患疾病向安雪提出需要医疗费治病。但是安雪为了防止将婚后共同财产全部被叶辰治疗，偷偷的将家里的财产分次转走。为了保证自己的医疗费能有着落，叶辰无奈向法院提起诉讼。

在夫妻生活期间，在一方隐瞒财产的情况下或者一方有重大疾病的情况下，是可以在不离婚的前提条件下要求法院分割夫妻共同财产的。但是仅限于一方隐瞒财产或者一方有重大疾病的情况下，其他情形是不能直接要求分割财产。

《婚姻法司法解释三》第四条婚姻关系存续期间，夫妻一方请求分割共同财产的，人民法院不予支持，但有下列重大理由且不损害债权人利益的除外:(一)一方有隐藏、转移、变卖、毁损挥霍夫妻共同财产或者伪造夫妻共同债务等严重损害夫妻共同财产利益行为的；(二)一方负有法定扶养义务的人患重大疾病需要医治，另一方不同意支付相关医疗费用的。
