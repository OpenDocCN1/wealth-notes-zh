# 这种情形码农可以直接向人民法院起诉！

## 案例

2016年2月5日，中恒公司项目的负责人程某以中恒公司名义向程序员沈某出具欠条，内容为：今欠到程序员沈某（欠条上写程序员沈某）工资142300元。并备注：其工资款以中恒公司最终审核为准。中恒公司的工会主席杨某以证明人身份在该欠条上签名。

当日，程序员沈某等7名项目部人员在一份内容为打印的承诺书上签名，承诺内容如下：一、承诺于2016年5月1日之前将全部源码资料上交给中恒公司测试部门，确保完整合格。二、同意剩余工资款经中恒公司审核后源码资料全部验收合格后一个月之内支付完毕。

程序员沈某后于2016年4月29日通过测试验收，中恒公司拒绝向程序员沈某支付工资款。程序员沈某起诉至法院，要求公司支付工资款，庭审过程中，公司提出：该案件属于劳动案件，应当先经过仲裁前置程序。法院经审理后，判决支持了程序员沈某的诉讼请求。

## 说明

从事IT行业，经常出现公司不能按时支付报酬，有的公司会向员工出具欠条，而有的公司则只会用口头的方式告知。对于有欠条的码农，在公司不支付工资的情况下，可以直接向法院起诉。根据最高人民法院《劳动争议解释(二)》第3条明确规定，劳动者以用人单位的工资欠条为证据直接向人民法院起诉，诉讼请求不涉及劳动关系其他争议的，视为拖欠劳动报酬争议，按照普通民事纠纷受理。

首先，对于用人单位拖欠劳动报酬，劳动者直接按普通债务向法院起诉的条件是较为严格的：诉讼请求的支持证据为用人单位出具的工资欠条，诉讼请求不涉及劳动关系其他争议。也就是说，双方对于劳动报酬发生之事实、劳动报酬未按法律规定或约定支付的原因、劳动合同效力等，用人单位和劳动者都没有争议。只有同时满足上述两个条件的情况下，劳动者才可以普通债务直接向法院起诉。

其次，按照《劳动合同法》第30条还规定，用人单位拖欠或者未足额支付劳动报酬的，劳动者可以依法向当地人民法院申请支付令，人民法院应当依法发出支付令。因此，对于符合前述条件的劳动者，不仅可以直接向法院提起民事诉讼，而且还可以选择优先申请支付令。

# 单位不缴社保，码农败诉，怎么回事？

## 案例

程序员白某称其曾于2012年9月6日入职某IT公司，于同年9月18日离职。欧格林公司称程序员白某曾于2012年9月13日入职，于同年9月18日离职，公司提交过程序员白某的社会保险参保材料，但由于程序员白某的工资不足以缴纳社会保险个人负担部分，后撤回，没有实际缴纳社会保险费。程序员白某诉至法院，要求欧格林公司缴纳社保。后法院直接驳回其诉讼请求。

## 说明

原因在于：社会保险争议属于劳动争议。但是，用人单位、劳动者和社保机构就欠费等发生争议，是征收与缴纳之间的纠纷，属于行政管理的范畴，不是单纯的劳动者与用人单位之间的社保争议。因此，对于那些已经由用人单位办理了社保手续，但因用人单位欠缴、拒缴社会保险费，或者因缴费年限、缴费基数等发生的争议，应由社保管理部门解决处理，不是人民法院受案范围。根据《劳动法司法解释三》第一条，对于因用人单位没有为劳动者办理社会保险手续，且社会保险经办机构不能补办导致劳动者不能享受社会保险待遇，要求用人单位赔偿损失的，则属于典型的社保争议纠纷，人民法院应依法受理。所以，程序员白某的诉讼请求被法院驳回，不是因为法院不支持，而是因为程序员白某用错了诉讼策略。

# 错把劳务关系搞成了劳动关系，纵然努力也枉然！

小王在某互联网工作做码农，因撸码能力风骚，效率彪悍，很受公司领导的青睐。一天，公司CFO张三私下跟小王说，自己手里有个私活，但是因为技术难度超出天际，部分BUG有待修补，想请小王利用空闲时间做一个技术外援，并愿意按照每小时给予小王报酬。因张三是自己的领导，加上自己囊中羞涩，故答应了张三的要求。小王按照张三的要求帮助其修复BUG后，因张三耍赖不愿支付报酬，后小王遂向劳动局起诉公司，被劳动局驳回。

![](img/8bf480dc4432e799d299f98ca8474e98_5_0.png)

![](img/8bf480dc4432e799d299f98ca8474e98_5_1.png)

> 《劳动法司法解释二》第七条第（四）项：小王在这个事件中与公司无劳动关系，与张三之间劳务关系参照家庭或者个人与家政服务人员之间的纠纷，故小王不能以劳动关系起诉公司，只能以劳务关系起诉张三。因小王搞错法律关系，故无法胜诉。
>
> 《劳动法司法解释二》第七条下列纠纷不属于劳动争议:
> - (一)劳动者请求社会保险经办机构发放社会保险金的纠纷;
> - (二)劳动者与用人单位因住房制度改革产生的公有住房转让纠纷;
> - (三)劳动者对劳动能力鉴定委员会的伤残等级鉴定结论或者对职业病诊断鉴定委员会的职业病诊断鉴定结论的异议纠纷;
> - (四)家庭或者个人与家政服务人员之间的纠纷;
> - (五)个体工匠与帮工、学徒之间的纠纷;
> - (六)农村承包经营户与受雇人之间的纠纷。

# 一年内不提诉讼，有理变无理！

程序员孙某2012年3月到民鑫公司工作。程序员孙某在职期间双方未签订书面劳动合同。程序员孙某向劳动局申请仲裁请求双倍工资，仲裁委裁决驳回仲裁请求。程序员孙某不服起诉至人民法院。民鑫公司提出程序员孙某未在满一年内提出，现已经超过仲裁时效和法律规定的诉讼时效，没有仲裁时效中止、中断的法定情形，人民法院应驳回起诉请求。

![](img/8bf480dc4432e799d299f98ca8474e98_6_0.png)

在劳动纠纷案件中，很多程序员与公司发生矛盾后，碍于情面没有及时主张权利，导致有理也变无理，最终承担不利法律后果。按照《中华人民共和国劳动争议调解仲裁法》第二十七条第一款、第五十二条的规定，当事人自知道或者应当知道其权利被侵害之日起一年内申请仲裁，仲裁机构予以受理的，人民法院应予认可。也就是程序员孙某需要在一年内主张，因此法院驳回了程序员孙某的请求。

# 从什么时候确定你是他的人，如何确定你的入职时间？

2019年5月1日，小马到一家IT公司应聘码农，经过激烈的竞争，小马成功胜出。公司通知小马于2019年5月8日，来工作办理入职手续。小马因面试通过，欣喜若狂。不料天有不测风云，小马未如期而至。于2019年5月10日，入职公司。因工作期间，双方未签订劳动合同，后引发纠纷。小马诉至劳动局，双方对入职时间产生争议。

依照《劳动合同法》第10条规定，已建立劳动关系未同时订立书面劳动合同的，应当自用工之日起1个月内订立书面劳动合同。意即对于已经建立劳动关系，但没有同时订立书面劳动合同的情况，《劳动合同法》规定了自用工之日起1个月的宽限期，要求用人单位与劳动者订立书面劳动合同。这项规定看似比较宽松，但是，用人单位逾期不签劳动合同的后果也是非常严重的。即用人单位自用工之日起超过1个月但不满1年未与劳动者订立书面劳动合同的，应当向劳动者支付2倍的月工资。超过1年仍不与劳动者订立书面劳动合同的，视为用人单位与劳动者已订立无固定期限劳动合同。

# 学生实习期间在单位的两个梗：实习是否可以构成劳动关系？

![](img/8bf480dc4432e799d299f98ca8474e98_8_0.png)

梗1：小明在学校实习期间与IT公司签订了《实习协议》，实习协议上明确约定：“双方之间不存在劳动关系”，那么小明与公司之间则可能不属于劳动关系。学生基于学校的安排到校外企业实习是学校教学内容的延伸和扩展，学校和企业都负有一定的安全教育和管理义务。学生在校外企业实习期间进行与其所学知识内容相关的实际操作，不认定学生与企业之间存在劳动关系。学生在实习过程中受到的伤害，应按一般民事侵权纠纷处理，根据有关侵权的法律规定，由学生、学校、企业按过错程度承担相应的责任，可以参考一下《最高人民法院公报》公布的王俊诉江苏雅维橡塑科技有限公司、徐州工业职业技术学院人身损害赔偿纠纷案（宿迁市宿豫区人民法院民事判决书）。

梗2：小花即将毕业的大专院校在校学生，以就业为目的与IT公司之间签订劳动合同，且接受用人单位管理，按合同约定付出劳动；IT公司在明知求职者系在学生的情况下，仍与之订立劳动合同并向其发放劳动报酬的，该劳动合同合法有效，应当认定双方之间形成劳动合同关系（详见《最高人民法院公报》郭懿诉江苏益丰大药房连锁有限公司劳动争议上诉案（南京市中级人民法院二审民事判决书）。

![](img/8bf480dc4432e799d299f98ca8474e98_8_1.png)

从以上两个梗，还是可以看出来，是否构成劳动关系还需要看双方订立合同时，是带着一种什么目的订立的，如果是带着建立劳动关系订立的，就是劳动关系，否则就不是劳动关系。

# 小明的试用期从什么时候开始？

## 案例

2018年5月1日，小明面试一家IT公司Python程序员，成功通过面试后。公司给小明发出了入职offer。在offer上写明了小明的入职时间为2018年5月8日，试用期为三个月，到2018年8月7日。但是小明因家里有事，未能如期赶往公司办理入职手续，经过与公司协商，小明于2018年9月1日，正式入职。那么小明的试用期该怎么计算呢？

## 说明

《劳动法》和《劳动合同法》并无明确规定，试用期的起算无非有两个方法，一是从订立劳动合同起算，二是从用工之日起算。无论实际用工的时间和订立劳动合同的时间是否一致，试用期的起算点应当是实际用工的时间。

第一，《劳动合同法》第10条第3款规定：“用人单位与劳动者在用工前订立劳动合同的，劳动关系自用工之日起建立。”按照这逻辑关系，试用期也应当在用工之日起开始计算。第二，从实际用工之日起算试用期符合试用期的本意。试用期是用人单位考察后决定是否聘用劳动者的一个时间段，自然应当从试用之日起即用工之日起起算。第三，从小明这个案件的实际情况来看，如果以合同订立之日作为试用期起算点，由于此时小明还没有参加劳动，有可能会导致实际用工之日时，试用期就已届满的后果。所以也不符合实际情况。

# 未约定试用期，如何确定试用期？

- 2018年5月1日，小明面试一家IT公司Python程序员，成功通过面试后。公司给小明发出了入职offer。在offer上写明了小明的入职时间为2018年5月8日，但offer上并未约定试用期。
- 在双方未签订劳动合同而又无其他证据证明有试用期的情况下，应当认定用人单位放弃了试用期，双方劳动关系中不存在试用期问题。这就要求用人单位通常必须在建立劳动关系时就要订立劳动合同，或至少就试用期达成约定，否则此后再订立劳动合同就可能无法约定试用期。

# 口头变更工作岗位，不可不知的知识要点！

## 案例

小黄在公司从事Python后台开发。2018年3月15日，因公司业务发展，Python后台开发部门被公司裁撤。公司口头通知小黄转Java前端开发部门报到。小黄从未接触过Java前端代码，更不懂UI设计，为了配合公司早日晚上项目，小黄早七晚十二，每周7天，奋力拼搏。2018年5月15日，终因技术不熟练未能完成项目工作被公司开除。为此，小黄十分愤慨，起诉至劳动部门。

## 说明

按照《劳动法司法解释四》第十一条变更劳动合同未采用书面形式，但已经实际履行了口头变更的劳动合同超过一个月，且变更后的劳动合同内容不违反法律法规、国家政策以及公序良俗，当事人以未采用书面形式为由主张劳动合同变更无效的，人民法院不予支持。所以小黄在一个月内没有向劳动部门提出仲裁，承担败诉风险。

# “末位淘汰”解除劳动合同可以要求支付赔偿金。

## 案例

东哥在电商公司从事IT算法推荐工作。公司在KPI中规定，每个程序员每月需要完成付费点击推荐任务20万元。同时，每个月KPI排名最后的，公司将解除劳动合同。2019年8月，东哥在KPI考核中绩效达到了每月30万元的任务量，但东哥在同岗位竞争时，排名最后，被公司无情解雇。

## 说明

解除劳动合同条件需符合法律规定，“不能胜任工作”的举证，以及对末位劳动者采取的不同处理形式等多方面，进行具体分析。按照劳动合同法第四十二条规定，用人单位不得依照本法第四十条、第四十一条的规定解除劳动合同。在不解除劳动合同的前提下，用人单位可以依据合法的规章制度或者劳动合同，对考核居于末位的劳动者予以待岗培训、调整工作岗位等处理。考核中“末位”总是存在的，用人单位必须将不能胜任工作而处于末位和能胜任工作而处于末位区分开来。如果劳动者能胜任工作而处于末位，则用人单位根据规章制度或者劳动合同，可以对劳动者进行待岗培训、调整工作岗位等处理，而不能单方解除劳动合同。如果劳动者不能胜任工作而处于末位，那么用人单位须先对其进行培训或调整工作岗位，只有仍不能胜任工作，才可以依法解除劳动合同。所以，东哥虽然排名最后，但是每个月还是达到20万元以上最低的工作任务，是可以要求经济赔偿的。这里我们可以参考一下中兴通讯(杭州)有限责任公司诉王鹏劳动合同纠纷案(最高人民法院指导案例18号)。

# 有了这些证据，提前三十天辞职，老板不批不行！

## 案例

黄天在“有心人”IT公司上班，因多年来没有找女朋友，家里人给其物色了一个女朋友。为此，黄天特向老板步云提前三十天辞职。三十天到期后，老板以黄天项目未完成不准许黄天辞职。

## 说明

《劳动合同法》关于劳动者以书面形式通知用人单位，解除劳动合同的规定，强调是书面形式，一般是书面通知用人单位劳动人事部门、办公室或者董事长办公室。劳动者证明已经通知了用人单位的最佳方式是用挂号信的形式邮寄给用人单位，保留挂号信回执。另外，劳动者还可以采用证人证言的方式证明其已将书面解除劳动合同的通知送达给了用人单位。所以IT老铁们只要收集好以上证据就可以顺利离职了。

# 竞业禁止

## 签订了竞业限制和保密协议，应当承担怎样的保密义务？

《劳动合同法》第23条第2款的规定也可对该结论提供佐证。第23条第2款规定的“对负有保密义务的劳动者，用人单位可以在劳动合同或者保密协议中与劳动者约定竞业限制条款...”这里的保密协议或竞业限制条款并不仅仅限于劳动关系结束后即劳动者离职之后，因此保密协议或竞业限制条款所约定的期限当然可以包括在职期间。换言之，只要当事人在劳动合同中未明确排除，该义务即附着于劳动合同而自始存在。劳动者在职期间的竞业限制义务允许当事人约定排除。劳动者在职期间的竞业限制义务，在范围上应当仅限于知悉用人单位商业秘密，其目的是为了防止这些劳动者利用这些商业秘密损害用人单位的竞争利益。

![](img/8bf480dc4432e799d299f98ca8474e98_15_0.png)

> 用人单位为了**保护自己的商业秘密**,往往与劳动者订立竞业限制协议,**有的协议约定了经济补偿,有的则未约定。对于没有约定经济补偿的,如何处理?**

### 主要关键

竞业限制的重要内容主要有两个:一是劳动者应当履行竞业限制义务;二是用人单位应当支付经济补偿。竞业限制经济补偿金不能包含在工资中,只能在劳动关系结束后,在竞业限制期限内按月给予劳动者。有的用人单位和劳动者虽约定了竞业限制但未约定经济补偿，而劳动者又履行了竞业限制义务的，此时，如果认定竞业限制无效，则对劳动者不公平。

### 问题结论

因此，在承认双方的约定有效的前提下，责令用人单位承担支付经济补偿的责任，更有利于保护劳动者的合法权益。但由于双方未事先约定经济补偿的计算标准，因此，可以按照《劳动法司法解释四》第六条约定来执行。如果用人单位连续三个月没有支付补偿金，可以按照《劳动法司法解释四》第八条，劳动者无需再承担保密义务。
