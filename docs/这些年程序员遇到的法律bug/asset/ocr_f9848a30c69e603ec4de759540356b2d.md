# 知识产权问题

# 要点1

+   专利法第三十三条中原说明书权利要求书记载的范围的理解

（2013）行提字第21号行政判决书

关键要点：

基于先申请原则，专利申请人对发明和实用新型专利申请文件的修改不得超出原说明书和权利要求书记载的范围。为了鼓励专利申请人在申请日充分公开其发明创造，防止专利申请人将其在申请日未公开的发明创造通过修改纳入申请文件而不正当地获得先申请利益。

# 要点2

+   专利法第三十三条 当事人的意见陈述的理解

（2010）知行知第53-1号行政裁定书

关键要点：

当事人的意见陈述在通常情况下只能作为理解说明书以及权利要求书翻译的参考，而不是决定性依据。至于其参考价值的大小，则取决于该意见陈述的具体内容及其与说明书和权利要求书的关系。尤其需要注意的是，如果当事人意见陈述的内容超出了原说明书和权利要求书中记载的范围，则该部分內容将完全丧失参考作用，不能继续该意见陈述的相关内容对说明书或者权利要求书进行解释。

# 要点3

+   专利审查、修改

（2011）知行字第53-1号行政裁定书

关键要点：

专利申请人对申请文件进行修改，国家知识产权局依法行使对专利申请进行审查职权，并不负有也不可能负有保证专利授权正确无误的责任。申请人对其修改行为所造成的一切后果应自行负责。
