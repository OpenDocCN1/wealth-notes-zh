# 单位不缴社保，码农败诉，怎么回事？

案例

程序员白某称其曾于2012年9月6日入职某IT公司，于同年9月18日离职。欧格林公司称程序员白某曾于2012年9月13日入职，于同年9月18日离职，公司提交过程序员白某的社会保险参保材料，但由于程序员白某的工资不足以缴纳社会保险个人负担部分，后撤回，没有实际缴纳社会保险费。程序员白某诉至法院，要求欧格林公司缴纳社保。后法院直接驳回其诉讼请求。

说明

原因在于：社会保险争议属于劳动争议。但是，用人单位劳动者和社保机构就欠费等发生争议，是征收与缴纳之间的纠纷，属于行政管理的范畴，不是单的劳动者与用人单位之间的社保争议。因此，对于那些已经由用人单位办理了社保手续但因用人单位欠缴拒缴社会保险费或者因缴费年限缴费基数等发生的争议，应由社保管理部门解决处理，不是人民法院受案范围。根据《劳动法司法解释三》第一条，对于因用人单位没有为劳动者办理社会保险手续，且社会保险经办机构不能补办导致劳动者不能享受社会保险待遇，要求用人单位赔偿损失的，则属于典型的社保争议纠纷，人民法院应依法受理。所以，程序员白某的诉讼请求被人民驳回，不是因为法院不支持，而且因为程序员白某用错了诉讼策略。
