# 小明的试用期从什么时候开始？

案例

2018年5月1日，小明面试一家IT公司Python程序员，成功通过面试后。公司给小明发出了入职offer。在offer上写明了小明的入职时间为2018年5月8日，试用期为三个月，到2018年8月7日。但是小明因家里有事，未能如期赶往公司办理入职手续，经过与公司协商小明于2018年9月1日，正式入职。那么小明的试用期该怎么计算呢？

说明

《劳动法》和《劳动合同法》并无明确试用期期的起算无非有两个方法，一是从订立劳动合同起算，二是从用工之日起算。无论实际用工的时间和订立劳动合同的时间是否一致，试用期期的起算点应当是实际用工的时间。

第一，《劳动合同法》第10条第3款规定：“用人单位与劳动者在用工前订立劳动合同的，劳动关系自用工之日起建立。”按照这逻辑关系，试用期也应当在用工之日起开始计算。第二，从实际用工之日起算试用期符合试用期的本意。试用期是用人单位考察后决定是否聘用劳动者的一个时间段，自然应当从试用之日起即用工之日起起算。第三，从小明这个案件的实际情况来看，如果以合同订立之日作为试用期起算点，由于此时小明还没有参加劳动，有可能会导致实际用工之日时，试用期就已届满的后果。所以也不符合实际情况。
