# 学生实习期间在单位的两个梗：实习是否可以构成劳动关系？

![](bbox=[0.1, 0.185, 0.22, 0.57])

梗1：小明在学校实习期间与IT公司签订了《实习协议》，实习协议上明确约定：“双方之间不存在劳动关系”，那么小明与公司之间则可能不属于劳动关系。学生基于学校的安排到校外企业实习是学校教学内容的延伸和扩展，学校和企业都负有一定的安全教育和管理义务。学生在校外企业实习期间进行与其所学知识内容相关的实际操作，不认定学生与企业之间存在劳动关系。学生在实习过程中受到的伤害，应按一般民事侵权纠纷处理，根据有关侵权的法律规定，由学生学校、企业按过错程度承担相应的责任，可以参考一下《最高人民法院公报》公布的王俊诉江苏雅维橡塑科技有限公司、徐州工业职业技术学院院人身损害赔偿纠纷案（宿迁市宿豫区人民法院民事判决书）。

梗2：小花即将毕业的大专院校在校学生，以就业为目的与IT公司之间签订劳动合同，且接受用人单位管理，按合同约定付出劳动；IT公司在明知求职者系在学生的情况下，仍与之订立劳动合同并向其发放劳动报酬的，该劳动合同合法有效，应当认定双方之间形成劳动合同关系（详见《最高人民法院公报》郭懿诉江苏益丰大药房连锁有限公司劳动争议上诉案（南京市中级人民法院二审民事判决书）。

![](bbox=[0.1, 0.575, 0.22, 0.875])

从以上两个梗，还是可以看出来，是否构成劳动关系还需要看双方订立合同时，是带着一种什么目的订立的，如果是带着建立劳动关系订立的，就是劳动关系，否则就不是劳动关系。
