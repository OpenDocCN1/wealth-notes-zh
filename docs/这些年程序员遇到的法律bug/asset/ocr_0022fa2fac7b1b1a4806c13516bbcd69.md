# 一年内不提诉讼，有理变无理！

程序员孙某2012年3月到民鑫公司工作。程序员孙某在职期间双方未签订书面劳动合同。程序员孙某向劳动局申请仲裁请求双倍工资，仲裁委裁决驳回仲裁请求。程序员孙某不服起诉至人民法院。民鑫公司提出程序员孙某未在满一年内提出，现已经超过仲裁时效和法律规定的诉讼时效，没有仲裁时效中止、中断的法定情形，人民法院应驳回起诉请求。

![](bbox=[0.12, 0.2, 0.2, 0.3])

在劳动纠纷案件中，很多程序员与公司发生矛盾后，碍于情面没有及时主张权利，导致有理也变无理，最终承担不利法律后果。按照《中华人民共和国劳动争议调解仲裁法》第二十七条第一款、第五十二条的规定，当事人自知道或者应当知道其权利被侵害之日起年内申请仲裁，仲裁机构予以受理的，人民法院应予认可。也就是程序员孙某需要在一年内主张，因此法院驳回了程序员孙某的请求。
