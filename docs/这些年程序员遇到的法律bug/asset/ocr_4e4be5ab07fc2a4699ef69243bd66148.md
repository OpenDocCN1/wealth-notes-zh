# 婚姻家庭纠纷

# Question4

抚养费用增多，可以要求另一方支付子女抚养费？

陌上花开因为双方之间感情不合，一起去民政局协议离婚，协议离婚时双方对小孩的抚养权和抚养费作出了特别的约定。小孩抚养权归陌上所有，花开不承担小孩任何抚养费用。几年过后，陌上因为遭遇变故，导致欠下大量外债，一人无力承担小孩的抚养费用。为了能够正常抚养小孩，陌上向法院提起诉讼，请求花开承担小孩一半抚养费。

# Legal Analysis

法律分析

父母与子女间的关系，不因父母离婚解除。离婚后，子女无论有父亲还是母亲抚养，仍是父母双方的子女，离婚后，父母对子女仍有抚养的义务，如果经法庭审核实双方经济情况有无变化，子女的生活费有无增加，从而作出是否变更或维持原协议的判决。在陌上经济情况发现变化后，法院是可以判决花开承担小孩一半的抚养费的。

# Laws

法律规定

> 《关于人民法院审理离婚案件处理子女抚养问题的若干具体意见》第15条：离婚后，一方要求变更子女抚养关系的，或者子女要求增加抚养费的，应另行起诉。
