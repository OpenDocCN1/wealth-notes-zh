# ## 婚姻家庭纠纷

# ### Question2

+   - 登记时未满婚龄，起诉时已到婚龄，这样处理！

沐橙与少天两个人是高中同学，都是18周岁。两个人早恋后，沐橙怀孕。为了，尽早的办理结婚登记手续，沐橙的家人通过熟人帮助沐橙和少天在民政局办理了结婚登记手续。结婚后，随着两人性格之间的差异，两个人的感情越来越差。五年后，少天向法院提起诉讼，称自己与沐橙两人之间因结婚时未达婚龄，请求法院判决婚姻无效。

# ### Legal Analysis

+   - 法律分析

按照《婚姻法司法解释一》的有关规定，少天在起诉时，如果沐橙和少天确实没有到达法定婚龄，法院应当宣告婚姻无效。但是如果起诉的时候双方都已经达到法定婚龄了，法定的无效婚姻情形已经消失了，那就只能依法向法提出离婚。

# ### Laws

+   - 法律规定

《婚姻法司法解释一》第八条规定：“当事人依据婚姻法第十条规定向人民法院申请宣告婚姻无效的，申请时，法定的无效婚姻情形已经消失的，人民法院不予支持。”
