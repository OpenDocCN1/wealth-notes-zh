# 冒充名牌大学，走你！

![](bbox=[0.11, 0.18, 0.23, 0.51])

妞妞刚从大学毕业，通过58同城搜索到一份离家附近不远的高新区正在招聘web前端美工。公司招聘网站详细写明招聘的最低学历要求为211院校，月薪15K，高额的薪水是妞妞理想的工作。为能顺利拿下，妞妞使出奇淫技巧，自己动手制作了一份百分之百原汁原味的211毕业证书，致使外人无法看出任何纰漏，顺利的通过公司面试，并成功拿到了offer。后公司法务部门在对员工档案进行复检的时候，发现妞妞在学信网的学历证书无法查询，才得知妞妞学历造假，公司后解雇妞妞。

![](bbox=[0.11, 0.53, 0.23, 0.88])

公司在招聘时对被招聘者学历有明确要求，而被招聘者提供虚假学历证明并与用人单位签订劳动合同的，属于《劳动合同法》第26条规定的以欺诈手段订立劳动合同应属无效的情形，用人单位可以根据《劳动合同法》第39条的规定解除该劳动合同。因此妞妞无权要求公司承担赔偿责任。
