# **这种情形码农可以直接向人民法院起诉！**

# **案例**

2016年2月5日，中恒公司项目的负责人程某以中恒公司名义向程序员沈某出具欠条，内容为：今欠到程序员沈某（欠条上写程序员沈某）工资142300元。并备注：其工资款以中恒公司最终审核为准。中恒公司的工会主席杨某以证明人身份在该欠条上签名。

当日，程序员沈某等7名项目部人员在一份内容为打印的承诺书上签名，承诺内容如下：一、承诺于2016年5月1日之前将全部源码资料上交给中恒公司测试部门，确保完整合格。二、同意剩余工资款经中恒公司审核后源码资料全部验收合格后一个月之内支付完毕。

程序员沈某后于2016年4月29日通过测试验收，中恒公司拒绝向程序员沈某支付支付工资款。程序员沈某起诉至法院，要求公司支付工资款，庭审过程中，公司提出：该案件属于劳动案件，应当先经过仲裁前置程序。法院经审理后，判决支持了程序员沈某的诉讼请求。

# **说明**

从事IT行业，经常出现公司不能按时支付报酬，有的公司会向员工出具欠条，而有的公司则只会用口头的方式告知。对于有欠条的码农，在公司不支付工资的情况下，可以直接向法院起诉。根据最高人民法院《劳动争议解释(二)》第3条明确规定，劳动者以用人单位的工资欠条为证据直接向人民法院起诉，诉讼请求不涉及劳动关系其他争议的，视为拖欠劳动报酬争议，按照普通民事纠纷受理。

首先,对于用人单位拖欠劳动报酬,劳动者直接按普通债务向法院起诉的条件是较为严格的:诉讼请求的支持证据为用人单位出具的工资欠条,诉讼请求不涉及劳动关系其他争议。也就是说，双方对于劳动报酬发生之事实劳动报酬未按法律规定或约定支付的原因劳动合同效力等用人单位和劳动者都没有争议。只有同时满足上述两个条件的情况下,劳动者才可以普通债务直接向法院起诉。

其次,按照《劳动合同法》第30条还规定，用人单位拖欠或者未足额支付劳动报酬的劳动者可以依法向当地人民法院申请支付令,人民法院应当依法发出支付令。因此,对于符合前述条件的劳动者,不仅可以直接向法院提起民事诉讼，而且还可以选择优先申请支付令。
