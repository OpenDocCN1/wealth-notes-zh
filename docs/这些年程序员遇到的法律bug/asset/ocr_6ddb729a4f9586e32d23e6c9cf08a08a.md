# 口头变更工作岗位，不可不知的知识要点！

# 案例

小黄在公司从事Python后台开发。2018年3月15日，但因公司业务发展，Python后台开发部门，被公司裁撤。公司口头通知小黄千万Java前端开发部门报到。小黄从未接触过Java前端代码，更不懂UI设计，为了配合公司早日晚上项目，小黄朝七晚十二，每周7天，奋力拼搏。2018年5月15日，但终因技术不熟练未能完成项目工作被公司开除。为此，小黄十分愤慨，起诉至劳动部门。

# 说明

按照《劳动法司法解释四》第十一条变更劳动合同未采用书面形式,但已经实际履行了口头变更的劳动合同超过一个月，且变更后的劳动合同内容不违反法律法规、国家政策以及公序良俗，当事人以未采用书面形式为由主张劳动合同变更无效的，人民法院不予支持。所以小黄在一个月内没有向劳动部门提出仲裁，承担败诉风险。
