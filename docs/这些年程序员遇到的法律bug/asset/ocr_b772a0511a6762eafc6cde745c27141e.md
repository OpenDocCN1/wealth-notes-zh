# “末位淘汰”解除劳动合同可以要求支付赔偿金。

# 案例

东哥在电商公司从事IT算法推荐工作。公司在KPI中规定，每个程序员每月需要完成付费点击推荐任务20万元。同时，每个月KPI排名最后的，公司将解除劳动合同。2019年8月，东哥在KPI考核中绩效达到了每月30万元的任务量，但东哥在同岗位竞争时，排名最后，被公司无情解雇。

# 说明

解除劳动合同条件需符台法律规定，“不能胜任工作”的举证，以及对末位劳动者采取的不同处理形式等多方面，进行具体分析。按照劳动合同法第四十二条规定，用人单位不得依照本法第四十条、第四十条的规定解除劳动合同。在不解除劳动合同的前提下，用人单位可以依据合法的规章制度或者劳动合同，对考核居于末位的劳动者予以待岗培训、调整工作岗位等处理。考核中“末位”总是存在的，用人单位必须将不能胜任工作而处于末位和能胜任工作而处于末位区分开来。如果劳动者能胜任工作而处于末位则用人单位根据规章制度或者劳动合同，可以 对劳动者进行待岗培训、调整工作岗位等处理，而不能单方解除劳动合同。如果劳动者不能胜任工作而处于末位，那么用人单位须先对其进行培训或调整工作岗位，只有仍不能胜任工作，才可以依法解除劳动合同。所以，东哥虽然排名最后，但是每个月还是达到20万元以上最低的工作任务，是可以要求经济赔偿的。这里我们可以参考一下中兴通讯(杭州)有限责任公司诉王鹏劳动合同纠纷案(最高人民法院指导案例18号)。
