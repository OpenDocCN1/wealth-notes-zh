# 婚姻家庭纠纷

Question5

+   问：怀疑小孩并非自己所生，妻子不愿意做鉴定怎么办？

+   宁少与妻子结婚后，发现妻子经常与其他异性频繁沟通，怀疑妻子有出轨的嫌疑。妻子怀孕后，宁少担心小孩并非自己的亲生小孩，想给小孩做个亲子鉴定，但是妻子不愿意配合。此后，宁少与妻子之间的矛盾日益深刻。后来宁少向法院提起离婚诉讼，庭审时，宁少向法院申请亲子鉴定，但是妻子拒不配合。

Legal Analysis

+   法律分析

《最高人民法院关于适用<中华人民共和国婚姻法>若干问题的解释(三)》第二条夫妻一方向人民法院起诉请求确认亲子关系不存在，并已提供必要证据予以证明，另一方没有相反证据又拒绝做亲子鉴定的，人民法院可以推定请求确认亲子关系不存在一方的主张成立。当事人一方起诉请求确认亲子关系，并提供必要证据予以证明，另一方没有相反证据又拒绝做亲子鉴定的，人民法院可以推定请求确认亲子关系一方的主张成立。因此，法院可以判决宁少与小孩无血缘关系。
