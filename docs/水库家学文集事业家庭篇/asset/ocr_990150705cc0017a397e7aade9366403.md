# # 人长大了，就只有熟人

大学老同学群，二十年后，混的高中低都有。大过年的，群里一句话没有发，全部是发红包和祝福。想想也是，说什么呢？每个人的心态都不一样，还是不说得了。人长大了，就只有熟人，没有朋友了。

# # 人长大了，就没有朋友了

# # 年轻时候要拼搏

人到中年，就要想开点了。官再大，还比你更大的。钱再多，还有比你更多的。你们有几栋房子，有几千几万备用金，差并不多。不要总觉得自己是开飞机的，看不得自己前面居然还有人。人家的马子再漂亮，咱们也不能打主意。

# # 人性的黑暗
