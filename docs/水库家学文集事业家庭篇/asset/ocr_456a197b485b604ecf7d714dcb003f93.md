事实上，只有既不出口，也不进口的行业，可以通过转嫁成本，维持社保负担。例如房地产、互联网、医疗教育养老、烟草电力等。这些行业的成本通过无休无止的涨价，维持了就业人员的各种诉求。他们能够降价，无非是别人不能参与竞争而已。

# 一、互联网行业

这个行业诞生了无数的快递员。互联网分为两种销售模式：

京 x 是自负快送，看报表，京 x 好像一直没有盈利，说白了，是国际风险投资给快递员交了社保。

淘 x 是盈利的，但是无数的淘 x 夫妻，基本是不交社保的，这些钱给快递员交了社保。

# 二、基建行业

基建行业是完全脱离国际定价的，能够轻松转嫁社保成本。事实上，基建行业的劳务工，交社保的，也极少。但是，要维持庞大的基建行业，需要多少 m2？你心里懂！
