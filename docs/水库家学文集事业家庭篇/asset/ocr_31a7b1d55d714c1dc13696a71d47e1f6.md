# 宏观角度认识民企结构性困难

民企给全社会80%的城辗就业人口发工资。大家拿了工资，却主要不在民企的产品领域消费，而是把钱投给了医疗教育住房。那么，民企成品卖给谁？除了一部分固定消费，例如你家总要买一些塑料盘，卫生纸，多余的产能，只能出口了。如果出口不畅，民企会怎么样，大家也懂的。
