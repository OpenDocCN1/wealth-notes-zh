# 公司被判决破产了，老板受影响吗？

答：1、老板肯定破产。中国没有什么公私财产隔离的，民企去银行贷款，股权质押+老板个人担保。公司破产了，肯定还不起贷款了，股权也是废纸了，那老板也完了。

+   2、上市公司老板一般没有很多人财产。上市公司要给老板分红或者发薪，必须是利润，可能涉及企业所得税25%和个税（约20-35%）。很多老板不愿意个人名义拿钱，往往就没有什么个人资产。你看别的财团，豪车，可能是公司资产。

+   3、上市公司，财务帐很短，卖掉角料的小金库，也不会很大。如果私吞，是犯罪了。
