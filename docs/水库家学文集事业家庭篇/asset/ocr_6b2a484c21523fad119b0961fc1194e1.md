# 亲戚之间，互相帮忙

  一起嘴的情况有吗？

  我活了大半辈子，只听说过一个家族，还是世家。子女们个个都是能人，职位极高，县里面无人能比，我遇到的真实情况是，绝大部分家庭，亲戚之间都是互相借钱，互相说坏话，互相鄙视，互相看不起，互相不服气。例如，几十年不联系的亲戚突然带了一些梅干菜来串门，然后说，自家男人得绝症了，躺在医院里，要借钱十五万，你真是恶心到家了。
