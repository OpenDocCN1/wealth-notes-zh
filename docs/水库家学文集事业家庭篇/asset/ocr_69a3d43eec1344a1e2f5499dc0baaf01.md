+   2. 股东不得在公司内长时间逗留，不能在票号过夜。

+   3. 股东不得监督大掌柜。

+   4. 股东不得干涉大掌柜的任何决策。

+   5. 大掌柜可以不断强迫股东给手下人加身股。到了民国初年，票号末期，有身股的职业经理人已经占 40%。而这些都是大掌柜拉帮结伙，笼络人心的办法。

+   6. 大掌柜决定一切人事权，从招聘到提拔，股东不得插话。

总而言之，股东对企业完全失控。理论上股东可以辞退大掌柜，实际上也是空话，如果是内斗后辞退总经理，业务立马就混乱，股东全毁就会破产。

当前，民生利润不高，风险极大，如果完全交给职业经理人，暂是不现实的。

# ## 为什么服务业更适合个人创业？

因为服务业的硬成本投入是最小的。

制造业的投入成本实实太高了。你买机器，租厂房，聘请工人，社保开户，银行开户，原材料备货，生产了一大堆，如果最后卖不掉，一亏亏一整套房子是很正常的。

服务业只需要一个办公室，大的小的，市中心还是郊区，看你的业务情况了。甚至你可以上门服务，或者找朋友办公室临时用一下，自己带块招牌过去挂在会议室。

服务业最大的成本，其实是你的过往资历的投入。你要想做服务业，必须在这个行业深耕十年以上，这个资历是非常值钱的，很多人不值好价值，就浪费掉了，非常可惜。

服务业不需要大批量的发货，不存在人工和仓库的问题。做个淘宝可忙了，就算卖袜子，几百个品种，必须一家五六个人，天天在库房里揽货，打单子发货。

关键是找到一个好的思路和好的项目，很多搞技术的人，其实没有商业概念，也不知道怎么去操作，需要一个指路人。我建议你是思考一下，哪些行业是你基本做得下来的，只是其中的 1 到 2 个环节干不请道。就按照这个方向去思考。

我没有鼓励你现在就辞职的意思，有备无患，当你在本单位已经无法发展的时候，还有另一条后路可以选择。

另，主要是因为懒！
