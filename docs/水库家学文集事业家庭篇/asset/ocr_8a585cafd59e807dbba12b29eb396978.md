# 为什么欧美日的百年老店多？

阶层固化。

我问过几次欧美年轻人，你们为什么创业？他们想了半天说，真没想过这个事情。他们的习惯思路是：名牌毕业后，在大城市，租个房子，搞几个女朋友，找个好工作，浪漫旅游，混到35岁生孩子，然后看情况要不要搬回老家，享受乡下列假@中低收入阶层的生活。混的好，就留在大城市了。

欧美人的特点是：家家户尸，吃光用光，还房贷，没有存款，几乎没有创业启动资金。

大概说欧美的产业结构：

+   1. 农业，基本是祖传的，葡萄园，牛场，小麦地。一般人不会想到去当农民的。

+   2. 工业，也不可能。工业，一般是老企业垄断了，新厂要几十个人以上了，欧美劳动力太昂贵了，请了个大爷，你必须帮企业破产。大多数小企业也是祖传的，有个特色产品或者加工技艺，例如风辣药酪，金属切割，首饰加工，一家子人，混派日子，自己开个汽车生产厂，至少几个亿投入，不可能的。

+   3. 小服务业。大型服务业，都是集团连锁，欧美人没有存款，搞不起来的，百货小超市被东移民包了，欧美本地人搞不起来，雪茄吧，小餐馆，咖啡酒店，小酒吧，停车厂，小诊所，设计室，歌舞团，小律所，旅游公司，涉及到文化和语言，本地人千的多，但这种玩意也是祖传的多，也有部分是家族性质。

风险投资，是年轻人创业的唯一途径了。

欧美人最喜欢投资了。他们在内心情深处是喜欢钱的，但大环境导致他们不能直接表现，现在很多上层以为欧美人是食草动物，不喜欢钱，开玩笑了！人家是大航海时代过来的，殖民地球地，内部打了儿百手，都是要钱不要命的性格。但是，欧美比较理性，没有什么股民之类的小动物。他们相借，专业素养。

欧美也有很多富人，表面上看不出来。他们往往是几代人都认识的，在乡村俱乐部打牌，找到共同的兴奋点，成立私募基金，整个lp（有限合伙人）替他们智收。
