# 新年被父母敲打要 20 万彩礼

菜菜投个稿：我是西北偏远地区的妹子 23 岁，颜值中等，从大四开始在上海实习工作，没花过家里一分钱，还清了自己的助学贷款。

毕业后的第一个新年，过午高高兴兴地回家。结果被父母敲打，找对象彩礼要 20 万，不给的话就是不孝，就是嫌心穷脚，可是我对象是上海的男孩子，很难过，我无脸瞒他说我父母是这样的人。菜菜，我现在好恨自己的父母！

答：你找个老乡吧。上海正常家庭绝对不能给彩礼的。就算勉强结婚了，如果婚后丈母娘乱伸手，大概率是离婚。
