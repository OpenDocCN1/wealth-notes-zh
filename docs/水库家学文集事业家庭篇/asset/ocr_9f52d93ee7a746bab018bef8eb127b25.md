又有合作。谈纠纷调的过程比较长，这就需要一正式代表，穿针引线。儿媳的地位很高，她天
然的正式代表。说话做事要有分量，对领导有要求很高。

与此同时，很多富裕家庭，人口不多，经常有突发任务，没人顶的上级总负责，儿媳就要上。
不行也要行。

第四，内部和谐。不仅仅是斗小三，更多的是七大姑八大姨，企业老臣子女，各种破事一大堆。
老板不能不管，但没时间管。儿媳就是最佳代表。有分量，有地位。

儿媳还要管家，主要是给保姆们安排任务，监督工作质量，保证一家老小生活正常。这都几个
亿的身份了，老板想吃点好的，也不过分。

结论：你只有搞明白土豪家庭对媳妇的要求，你才知道怎么培养女儿。即使以后不嫁豪门，这
个媳妇也会是中产家庭的一把手。

# 土豪选儿媳

我从来没有听说过，土豪选儿媳，把艺术气质列入条件的。相反，大多数土豪家庭认为，艺
术气质就是性格不靠谱，根本不适合做长房儿媳，做小三比较合适。土豪比较看重的条件：

+   1. 家庭背景上，父母的职务，财富，学历，口碑，父母是原厂配最好。
2. 女性自然条件上，身高，体型，学历，健康，外貌。
3. 性格很重要。热情大方情商高。富裕家庭，关系复杂，考验人啊。
4. 有较强的组织能力。中高端的人情往来，是富裕家庭的大事情，必须有张罗，小到食材
采购，大到邀请范围，要自然亲帖，丝丝入扣。
5. 见得多，顾大局。见惯大场面，就不会闹笑话。富裕家庭，经常发生一些狗血剧，要顾
大局，不能一点就炸。

具备以上条件，如果双方满意，基本就敲定了。
结论：一碗清汤激和的白开水，比一瓶花里胡哨的眼药汤，更适合嫁豪门媳妇。
