# 作为 40 岁的老汉，谈几点人生体会

女人是一个家庭幸福与否的关键。大多数男人是不调用的，工资就那么点，也升不上去了，还好吃懒做，喜欢躺摆。男人，除了上班给领导马屁屁，其他啥事也不想干。

一个家庭最大的事情是，买房子，照顾老人孩子，搞好吃穿用，男人什么都觉得烦；都是女人操心。

大多数男人觉得，带孩子，做家务，是小事。女人付出的再多，也根本不在放在心上。男人最大的得意是工资收入比女方略多一点，就整天在家里耀武扬威，爷王称稀。

女人超过 37 岁，基本也不可能怎么伺候了，大多数是忍气吞声，只要男的不在外面喝场头，基本也就算了，但心里憋气大。

我的想法是：

+   1，双方互相体谅。男人撒，可能不是真撒，而是身体原因。我一直是很勤奋的类型，但现在这个年龄，我觉得自己也懒了，我仔细想想，觉得可能是身体机能下降的问题。例如，不想带孩子出去玩，不想陪孩子做游戏讲故事，不想去看房子，不想折腾，我理智上觉得应该要去做，但就是没有那个耐心。

+   2，男人撒，那就嘴上加快一点。你讨厌打领导的那批话，留一部分给你家庭撒，效果好一百倍。单位里那些小领导，不会再给你什么大好处了，你也没个岁数了，想开点吧。女人是吃软不吃硬。你打她一顿，老了肯定会整死你。咱不犯那个蠢事。

+   3，女人也不要三天两刻翻脸骂。谁家买房子，谁家男人升官发财了，那用，别人家男人这么好，为啥不要你？你心里要没点谱数吗？对付男人，骂他不如鼓励他。大事不行，就鼓励他做点小事。胡乱的跟别人老公比来比去，除了夫妻打架，还有什么意思？你不如安安心心，教育子女。孩子争气，你就幸福了。一代比强了，那就比下一代。
