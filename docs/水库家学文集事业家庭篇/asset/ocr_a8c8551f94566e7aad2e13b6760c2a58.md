孩子偷钱的原因是，家长不愿给钱，还一直告诉孩子，你要长大后再本事自己去赚钱。

这孩子就老和我孩子说：“爸爸妈妈的钱，和你没关系”。我孩子莫名其妙：“怎么没关系？都是我的”。因为我们从小到大都是这么说的，一切都是你的。孩子一直生活在幸福之中。

给孩子幸福感，还是危机感？我也糊涂了。因为这个问题，我以前没遇到过。为了这个问题，我和柒妍研究了好几天。

孩子有危机感，就学会了生存技能，狡诈市侩，机豪拐骗，溜须拍马，但不幸福。

孩子有幸福感，就会250，没有危机意识。

我们的意见是，先给孩子幸福感。等孩子长大后，再说。

# 不要害怕改变

经常有中青年妇女私信告诉我：公婆或老公不愿意买房，就喜欢拖着一张存折，在脏乱差的老公房里硬扛，怎么办？这是普遍情况，而且可以想象的是，这种男方家庭一般是中下质量，至少12.15年内没有买过商品房。他们长期习惯了一种生活模式，上班存钱，吃点好的，在微薄上骂骂黑心开发商。他们根本不想改变。他们面对不确定性时，天生悲观，略带动感。他们担心的是几件事情：

+   一，生活质量下降

买房和装修后，基本是存款花光，负债累累，其他开支就要节约一点了。他们不习惯，不愿意，他们想继续现金觉的过日子，吃光用光，身体健康。现在孩子小，还能喘合流泪，把难题留给下一代。

+   二，心理压力加大

房贷一般是20-30年，很多工人家庭出来的公婆，一听就炸了。响，几十年啊？不行不行。我还能活几年啊！我要享受，不愿意把钱给你们。

+   三，会不会买亏了？

这种男人长期在相对稳定的工作生活环境中，只愿意卖力气，绝对保保险，绝对赚钱的事情，他们对任何不确定性，都厌恶痛绝。被矿的是，过去漫长的二十多年里，每天都有各种各样的好消息告诉他，“要死了，马上腰斩了，政策发福利了，黑心开发商吓尿了”。你想睡觉，别人道枕头。有些人已经到丧心病狂，失去理智的程度了。连“房子不如大葱”的话，居然都有很多人相信。我们的科学思维教育，任重道远啊！

四，女方是不是要占便宜？

男方婚前有个老破小，价值300万，女方陪嫁50万过来，齐心协力，一起贷款，买个700万房子，一家人稍微宽裕一点，但男方不这样想，你出50，我出300，凭什么女方占一半？这种鸡贼家庭，把婚姻做为利益计算，一把小算盘，打的是眼里瞄的响。一个女人的青春，也就是25-40岁，短短十五年，都给你们家了，还要生儿育女，肚子上拉一刀。难道一个大姑娘，还不值那几块骨头吗？

+   五，怎么办？

我从来不劝人买房。你家的事情，关我鸟事？我要对女方说几句。

1，婚姻是价值观的合并。能过就过，能过就离了。千万不要强迫男万方做什么不愿意的事情。

2，女方父母要为孩子长远考虑，为人父母不都是为了孩子吗？

3，当妈的，要勇敢，不要怕什么！就算输出去一半子全输光了，也要给孩子当好垫脚石。
