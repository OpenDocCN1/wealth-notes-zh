我研究了他们家很多年，今年又收编了几个他们家的老臣，基本搞清楚了他们垮掉的原因。这个过程大概有五年，我就不分时间的归纳一下。

# 《一支农民起义军极其而衰的过程》

# 一、创始人：

贫困县农民夫妻，九十年代在温州打工，后来回到工业园（地点隐去）开小作坊，一步一步熟到 2005 年，他家成为大土豪，其中有两个关键点：一是产品非常畅销，二是老厂房被拆了一次，一夜暴富。

他们家到 2005 年左右，确实发财了，这个我们都知道。当年，我们的机器开不了工，没有订单，他们到处抢工人，在各个路口举牌招阿，气的我们精神崩溃了。主要原因是，他们的产品确实畅销。

# 二、农民习气

他们企业的精神内涵是，农民意识，从上到下，99%是农民工。会计师，设计师和技术员，也是找了几个第二代大学生。

我没有贬义，当年去工业区的，也只有农民工志愿了。农民的特点是，肯吃苦，敢拼。他们的工人当年意思不睡觉的加班，老板现场发钱，销售员像是疯了一样到处抢客户。再加上，他们厂的产品确实好，短短数年，发大财了。

# 三、善于内讧：

发大财了，农民的第一反应是炫耀啊！

老板立即把自己从头到脚，置了个全豪华，买最好的别墅，居然还请了花匠和厨师，这在当年，是石破天惊的。

手下的骨干也发达了，买房买车买包包，一时间，成为了工业区里一道亮丽的风景线。更加气人的是，他们把车停在门口。我们两家是面对面，两年后开始出错了，主要是大市场环境不好。于是，他们家开始对老臣下手了。因为销售区长老臣跑了，所以，销售都被裁员九成，沦为小部门。设计师原来是提成改为固定工资。生产主任，原来可以招工吃回扣，现在被没收了等等。

几个大怨下来，骨干们分为两派：一是自立山头，抱团出逃。二是按照惯性继续搅。

# 四、高层内斗：

农民哦，吃饱了就想做女人。小老板和销冠代表搞个不私生子出来。原来还有搞大的一儿一女。一家人变成了四家，互相守攻。夺权的方式是，只认钱线，不以能力。听我的，摆大谱，不听我的，能打压，各个派系，都这样做，最终是最大程度控制企业的内部实权。实权就是钱啊。采购权，批发权，甚至是宿舍分配，都可以内部出。

这个企业就人心不稳了，内部人员都在看风向，四派人马，还主动出击，各自拉拢经销商，为最后分家做准备，不惜损害企业利益，胡乱的发好货，销赃赖赊账。

# 五、分兵割北：

小三是空降部队，在企业里没威信，被大药房子女，打的丢盔卸甲。但是，老板心疼呀，于是小三的团队出了一个叛胎，动员老板进军房地产业。老板看见原来的制造业也越来越难了，再加上内斗剧烈，于是决定企业一分为二，老板领制造业，老皮带小三进军房地产。

这个老板是农民出身，房地产业是高端项目，没有人际关系是玩不转的。考察了半年，最后在湖北的一个贫困县开发了。过程省略，最后没赚什么钱，也就是个利息。
