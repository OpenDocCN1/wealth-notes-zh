# 人生在世，不进则退

我住的小区，在十年前是属于上海非常好的。地下产权车位，漂亮花园，小高层一栋有个漂亮的大客厅（公共区域），一梯两户，墙是是漂亮墙砖。刚刚搬进来的时候，周围的小区居民超级羡慕这个所谓的豪宅小区，都想晚饭后在我们花园里遛弯。

十年过去了，再看这个小区，明显比不上新小区了。大理石的地砖不够，小区花园的面积不够大，人车分流没有，室内没有地暖，装修也老旧了，双开门冰箱冰箱的顶部，积了厚厚一层灰，吊顶也有点脏了，浴室的装修档次明显不如新小区。有些居民把助动车搬到楼道里，令人无语。

我实在是迫不得已，只能再买一套新小区了。这怪我吗？
