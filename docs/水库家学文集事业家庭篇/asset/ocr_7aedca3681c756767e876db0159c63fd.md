# 我们家是抗战前搬到上海

定居近一百年了。老人们回忆，只有 1999-2002 年这三年，是住房最轻松的窗口期。只要想买，就买得起。其他时间，住房难是常态。1998 年以前，大单位的正调，也就是分个市区小二楼或者浦东小三层。而且父母这一代有房子了，子女还是没有房子。1998 年房子很便宜，主要是两个原因，一是下岗人比较多，二是外地大学生罕见。但是，随着暂住证取消，2003 年后，房价就高开高走了。一转眼到现在了。
