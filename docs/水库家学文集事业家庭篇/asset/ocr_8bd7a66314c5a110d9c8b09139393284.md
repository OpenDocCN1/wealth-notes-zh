# 什么是人脉？

曾经的我，人很多。除了京沪户口和正式编制，我没办法，其他的事情，只要是合法的，真不是事情。最常见的是找末交区重点之类的。现在的我，狗不理。老朋友聚会，没人理我了，他们都在热切的讨论，某个位置出缺了，会轮到谁！他们对我的唯一感觉是，好像有几个钱的无用人员。为什么呢？

人脉，潜在词就是互相帮助。现在我帮你，以后你帮我，互相吹票。如果你没有帮助别人的能力，就是废柴。你再巴结也没用，人家就当你是个跑腿的，帮闲的。你不要以为和人喝过一次酒，吹捧过别人几句，人交会当你是个菜，实际上，第二天就忘了。

他人利用你是好事，不一定是你有什么头衔之类的，也可以是技术。某大头头特别喜欢魔术，找人拜师学艺，这就是人脉了，在合法的情况下，有些事情就可以办了。某某特别喜欢乒乓球，某某特别喜欢唱京剧，某某特别喜欢和医生交朋友，某某有两个关系极好的律师朋友。你啥也没有，有个球啊！

我见过最有趣的人脉，小区邻居，老王是个大头头。以前，周末是可以出去合法喝酒的（现在可能不行），再合法的吗唱歌，钓钓鱼，这就一天了。驾驶员周末不让休息，老王也不好意思开口。怎么办呢？小区里有个熟人小张，比老王小十几岁，他就时不时的让小张当驾驶员，这个熟人实际上也是有小身价的，嘴巴紧，过了几年，小张遇到一个事情，老王一个电话就解决解决了。

结论：苦练内功，做个有用的人。光有贱没用，你又不会把小别墅让给别人。人家懒得理你。

# 焦虑的本质，是嫉妒

这是人性中最常见的内容。

办公室里五个人，四个人买房凑了钱，剩下一个，父母底子差，没钱买，心里一万头草泥马，这是焦虑，还是嫉妒？大家心知肚明。

我们遇到了这么好的时代。大多数人充满幸福，可你家还是村里倒数，为什么呢？不是有狗就是傻，没什么好说的。

# 逆袭没有固定套路

人世间，没有一种套路，可以保证富家逆袭，最聪明的人，也就是考个消比，插个副高，评上副调，润到中产，这就算努力到顶了。

一场华丽的逆袭，往往是千万分之一的偶然。当绝大多数人并不看好某生意的时候，你处于某种不得已的原因，全部押上，拼死一搏。结果，99.9%的人当了炮灰，成功往往是偶为偶然因素，死里逃生，莫名其妙就成为王者。

九十年代初期，马奔爽，干什么都得有，马云最初是做翻译社。华为例家前实灭减肥茶，万科还做过度假，碧桂园做包工头，因为甲方拖欠工程款，老板原接低楼，谁也不知道为什么赚钱，大家都在试错。那时候我刚踏读大学，最大的梦想是去美国洗盘子。

我认识一个上海人，初中学历，八十年代后期，混在欧洲洗碗了，洗了七年盘后升后厨，成为中餐馆的配菜师傅，还攒了五十万人民币，成为整个客厅的富官，于是，衣锦还乡，回上海相亲，正好有个上海三甲医院的女医生也伸出圈，于是就结婚了，准备春市后一起出国。九十年代，这个选择是无数人羡慕不已的。
