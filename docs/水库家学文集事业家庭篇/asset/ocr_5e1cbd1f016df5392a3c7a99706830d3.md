# 爹妈不给力，那你努力

你不舍心疼大学学费，也不会想把大学宿舍买下来！

林语堂说，法国人和中国人最像。大巴黎（包括郊县），聚集了法国30%的人口，年轻人蜂拥而至，房租贵到离谱，年轻人从来不去考虑在市区买房，郊区勉强够的上，但也很难。原因很简单。法国年轻人把巴黎工作几年，视为第二次读大学。成就好的留校，读不好的回老家。

现在，京沪广深也是这样。大批外地人，其实是来一线城市吸点空气的。房租就是学费。他们当中的绝大部分是不可能留下来的，塞不到户口，买不起房子，如果运气不好，28岁就会走。上海大部分人，没事也不会去内环线。那里太拥挤了。外环，停车费是一小时三十元（可能记不准）。

上海人的房子是怎么来的啊？绝大部分是第一代人通过努力，先在京沪站了脚，然后搞了个十几平米，或者几代人造了个农民房，经历几十年旧居改造，最后通过拆迁、置换、落款，搞到了两三套房子。大家都不是很容易的，只不过，每个人发展阶段不同。我是第三代，房子户口都有。
