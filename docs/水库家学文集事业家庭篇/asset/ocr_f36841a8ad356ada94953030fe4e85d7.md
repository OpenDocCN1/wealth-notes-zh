# 父母亲戚只关心我赚了多少钱

菜菜，我已经回家了。这一年在大城市拼搏的艰辛和痛苦，我想在老家得到心灵的舒缓。

但是，我的父母亲戚只关心我赚了多少钱，拿多少钱出来给亲戚们送礼，还旁敲侧击的问我，弟弟结婚怎么办？家里房子要装修，出多少钱？他们丝毫不关心我一个女生背井离乡所受到的痛苦，以及对未来的迷茫。我彻底失望。

# 看了劣质父母系列，把回家机票取消了

菜菜，求退，刚刷看了你的劣质父母系列，我把 14 号回家的飞机票取消了。

在我小时候我爸有钱，后来吃吗赚赔散光，我 24 岁，弟弟比我小 9 岁。我高考毕业父母离婚，母亲改嫁再孕生一个儿子。

我大学毕业后继父母亲的电话都不接，爸爸的电话也不接（大学基本考自己兼职养活自己），现在月薪 1.5 万。

老家弟弟本来成绩很好，老爸不管孩子，弄的他初中缀学，我怕他以后一輩子就这样底层，我就出钱给他交学费，目的是希望在他成年之前，至少走的是正路，弟弟学费一学期 3600。

我告诉弟弟，我只帮他到高考毕业，并不是优抚他。以后我是不会再管，这样做对吗？该如何争取告诉弟弟让他好好抓住这个机会自己成才，辛苦啦～文字乱如麻。

# 我妈把我当猪养！

我是妹纸，今年 23，有个小十岁的弟弟，单亲家庭。我妈重男轻女的，她经常对我爸先洗脑，等我结婚了，向男方拿 50 万礼金回来分钱。我爸也被洗脑，觉得这是理所当然，还经常问我妈，什么时候把我卖掉分钱？

我本身是比较疼爱爸爸的，但也不想当扶弟魔，更不想当以后老的公，有没有什么办法可以改变我爸的认知？让他清楚男大平我不欠他？对于我妈我已经放弃了，只想以后结了婚能不墨会就不墨会！
