今年的双摄节快递员没有增加。我在家寒假，往年这个时候，小区里快递员很多，大楼门铃声此起彼伏，今年，静悄悄的。那个大恶爸爸说什么我都会相信的，反正不要钱的，敲开了搞宣传片。

# 我为什么不买新车？

+   一是已经过了赶时髦的年龄。以前买车有面子因素
二是用车环境不友好。马路上摄像头太多了，动不动就是罚单（我认罚），扣分十分就要考试，心存敬畏。
三是满潮行车合法化。我以前有个硬任务，父母嫁去机场必须接送，现在网上叫车挺方便的。我今年扣了三次超速（低速路段，没控制好速度，我认罚）和人行道转弯，不敢开了，平时有事儿打车，总比考得好。
四是大城市太堵车了，特别是虹桥机场那段，经常尾急。

# 我周围的朋友都不太喜欢开车

扣满十二分真是太容易了。不喜欢开车也就想不想再买车了。小城市，开什么牌子的车还是个面子，大城市都是地下车库，没人看你，没有什么面子这个说法，打黑车也方便，综合比较，其实也差不多。养车还有一大堆麻烦事情，买保险，走流程，修车，年检，换证，花费很多精力，如果是上班族，请假也麻烦。
