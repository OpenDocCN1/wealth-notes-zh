# 愿意工作就没有穷人

我家保姆，五十几岁的农村老太婆，基本不识字，住单间带浴室的漂亮房子，年入七万以上。

就是接送孩子，做点家务。全家她最凶，因为她管孩子。我们都让着她。就这样简单的高薪岗位，还不好找人，因为混到做保姆了，大部分人已经沒有工作态度了。

# 当你的人生停滞不前了，那就换个道
