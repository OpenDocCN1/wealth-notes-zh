# 家族发展是接力赛，每一代都有自己的阶段目标

有个美女女小姐姐，985 研，这十多年，加减加点拼命干，运气也好，陆续贷贷款买了两套普通价值的房子，经过不到八年的市场增值，已经身家不菲了。但是，姑娘始出事的她，心里总有一个豪宅光。既然换不到富二代男票，那就自己买！

上个星期，去某豪宅小区看上了一个 2500 万的房子。但她需要卖掉另外两套旧房，才能凑齐首付，就得销售处打听，能不能宽限一点时间。售楼员一听这话，也就不怎么搭理她了，时不时露出一点不耐烦的神色。

这时候，现场来了某父女两人，直接说：写女儿名字，全款。售楼员天双次喜地的围着他们打转，再也不理这个小助理了。小姐姐在售楼处的沙发上，痛苦的眼泪都要掉下来了。我那个爸爸只会花光用光，自私自利，还不给家用。为什么别人就唯有这么个好爸爸？

这个场景很真实，我也有过类似的情况。前两年，我去买了入门级的豪宅，没有两千五百万万，但也算费了。售楼小姐上来摸脸牌，你家怎么样考虑买这套啊？我说，给孩子准备的，我们不住。突然，我明显感受到了售楼小姐神情的变化。在看奢侈板的路上，她先是夸了你们真有钱，然后说，她是自己山区的农村姑娘，从小到大都是第一名成绩，长得也算白白净净，来沪读了本科，嫁了个市区老破小男人，我孩子和我孩子年龄差不多大，但经济差距太大了。

我当时愣住了，实在没想到会扯出这个话题。我不知道，这是不是销售技巧，防止跑单。最后，我就说，你名片给我，我要是买，算你你的业绩。

这种事情在靠沪楼市里，司空见惯。这并全不是什么阶层差距，只不过是发展阶段的不同。柴少女技术男，售楼小姐姐，我，三家人都在发展里。

售楼小姐就是白手起家，为自己和孩子拿到了沪户口，预备了老破小，就算起步了。

柴少女技术男，已经攒下了豪宅首付，属于小康阶段了。

我今年四十几岁了，几代人在上海攒下的砖房子，遇到拆迁和反贫估值，属于接近富裕层次了。

当然，京沪让我还好的富裕家庭，太太。

# 面子不能当饭吃

我家是郊区万人厂厂里的，八十年代改革开放了，可以做生意了。但是，厂里的正式编制工人，没有一个在做小生意的，因为他们认为自己有面子。这事像现在的二本啊，在格丁间里打 PPT, 感觉就比较吊顶，进快速的工人高黄了。
