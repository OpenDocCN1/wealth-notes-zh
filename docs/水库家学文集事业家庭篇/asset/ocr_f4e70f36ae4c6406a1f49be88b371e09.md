# 鼻炎治疗

二十年前我得过鼻炎，后来好了。
前不久感冒，鼻炎复发，很痛苦。
经推荐，在京东买了一小罐海水，喷鼻子，喷了两瓶，好了。
这不是药，就是纯的海水。
后来我查了一下资料，其实医院洗鼻器也是这个原理。（不是药，就是盐水洗鼻腔，有效果的。）
