# 婚姻大事，要不要听父母的？

答：你问要不要听父母的，那么你对男朋友并不是百分之百喜欢。可能是姑娘年龄大了，在几个备胎当中，选一个靠谱的，成家立業生孩子而已。新娘子的内心中可能还有一个其他的小鲜肉。只不过，人家没看上你。既然主要不是考虑感情因素，那么就是考虑匹配度。

父母能不能给出合理的意见？主要看父母的人生阅历。如果父母的学历较高，称于成大就类似于你男友，那么应该听一下父母意见。特别是有过管理经验的，当过总经理，厂长，处长，人事经理，这类人对年轻人的判断，准确性是比较高的。这不是百分之百的，人也是会老的，年轻的时候积极向上，可能到了中老年，脑子发病了，也可能。

如果父母一直处于底层，也没有接触过什么大写上的人群。父母的思想观念主要来自于同牌狗很亚亲戚朋友，他们的眼界是比较狭隘的，很难给出正确的意见。两代人行为方式，思维观点都不一样，甚至有点倚老卖老，看不上人家年轻人，最后就变成了看钱看房子。

结论：我们要自己做优质父母。

# 我认识的一个小县城未上港的女学霸

他父母是下岗工人，母亲是做保姆的，父亲是运输公司做搬运工。女孩长得中下颜线，但个子比较高。由于家庭经济实在太差了，所以女孩从小就大非常大自尊。凭把自我化作学习的动力，对自己极度的苛刻。最后，考上了 top2 大学。在大学里，非常刻苦，各类成绩都是优等，毕业后进入了一个超极好的公司，被派往美国。在美国当地结婚，常到了国籍，买了别墅。现在是美国的中产阶级。

这个故事的另一方面，是非常凄惨的。女学霸小学开始，因为必须考第一名，就落下了精神高度紧张的毛病，内分泌完全失调，月经过早来一次。人得像浮肿胖。表面上阳光开朗，但实际上内心几乎快得神经病了。她直到 26 岁才解除了贫穷，然后吃了大量的药，调整了六年才怀孕。这是她有一次和亲戚私下聊天的时候说起的童年往事

过去看，她的人生是个喜剧，但是过去的 20 年经历，实在是悲惨的不得了。很多学霸不同程度这条路上走过来的。虽然最后的结果还算不错，人前很风光，但这个拼得过程的痛苦，只有自己知道。不要以为学霸是可以轻易成功的，你表面上看到的，往往不是全部。

# 我们立志做优质父母

别人家的优质父母，高高兴兴的卖了唯一住房，给儿子凑首付。一群穷家属还住在那里喝啤酒发酸话，好像打地不平。

这是人家的私事，这是人家的权利，你没有这种父母，就不要嫉妒了。我们立志做优质父母。

# 一个人成熟了，是什么样子的？

只要不涉及到最低限度的尊严，不和人吵架，不说人坏话，不挖苦别人，被人嘲笑几句也就算了。排除各种干扰，一门心思做自己的事情，不麻烦，多帮人，留点小口碑。每天憨厚的一笑，尽可能再往上开一级，五十岁之前，成为光荣的副调。

# 和优秀的人在一起，共同进步

人生进阶的最大因素是，和优秀的人在一起，共同进步。
