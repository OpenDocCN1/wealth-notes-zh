# 贫穷的家庭，只会把子女拉入深渊

我是南京隔壁的三线城市市生，28 岁，2017 年复习考律证，我带了六万元自己的存款，在北京租房子参加补习班，彻底关闭手机，谁也找不到我，安安心心考完了，才开机。
