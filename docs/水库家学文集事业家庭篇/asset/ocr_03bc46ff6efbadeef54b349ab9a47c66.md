# 为什么大学生创业几乎赚不到钱？

我先举个例子。我读大学的时候，我们的辅导员是金融系毕业的研究生。他的志向不在学术，而是拼钱，就是小倒爷。那时候，北京的大学生里，读书是普遍被鄙视的事情，只有赚钱或者考托福，才有面子。

这位老师是县城凤凰男出身，经常排挤我，主要是我们这种上海学生不像农村兵痞那么听话。我看他就想要，丝毫没有崇拜的意思，不像有些农村大学生，觉得北京的大学老师简直是神了。他一直按部班就的糊逼。后来，终于来机会了。

学校后勤体制改革，成立了一个集团公词。他主动请战，当了副总。这种属于勤助处机制，正规老师是不屑一顾的。这个公司资产多的一比吊糟，生意也好。
一是学校房产出租。众所周知，北京的各个大学里，餐饮宾馆超市和私人小卖部，不计其数，这都是学校房产。
二是采购权。堂堂一个殿堂级大学，每年的吃用住，科研设备图书资料，都需要采购啊。
三是福利房等等。
四是三产，cpa，律师，考研辅导班，会计所，评估所，律师所，咨询公司，贸易公司，生产小厂，多的一塌糊涂。

你想啊，他是九十年代末期创业，资金稠啊。他搞到现在五十多岁了，还是个老孺丝，就算个中产吧，北京五套房，也就这么多了。我看他真是可伶了。
为什么他混不好呢？说白了就一条：牙疼切，帮谋不谏啊。

+   1. 大行帮来临之前，习惯性用学生思维进行质疑，越帮越陷，不敢下手。这么多年了，办企业，进出口，制造业，房地产，啥也没改口。这两个两届，被学院里的老人，事后评论的一钱不值。
2. 不放用人。这种清北凤凰男，最怕别人占他便宜，他就习惯性把这种思维带到了企业管理中，什么事啊都先考虑不能被占便宜，率先提防下闲黄汤，收回扣。什么事都需要他签字。最后，优秀的下属一溜，水至清则无鱼，全跑工，就剩下小阿姨生孩子，中年大妇混日子。
3. 好面子。他的很多决策看似稳妥，但失去了机会，生意总做的小而美。每个事情，单看都不错，但汇总后发现，总体落后了。人家是几倍几倍的发展，他总每年15%的发展，没过几年被后起之秀甩了云三街。自私自心极强，大家不敢对他提意见。你挑毛病也挑不出什么，如果耍否定他，就是把他做广。
4. 不敢下决心。最大的一个败笔是，没有在十多年前带领公业进人房地产。大学的勤助集团，信誉超级好，贷款绝不是问题，建筑系的老师是现成的，房产维修的技术工队是现成的，工程技术，信息资料，不操操心。但他就是怕啊。怕收租，怕风险，怕这馅那，就是不太失去机会。
搞了这么多年，这么好的条件，最后混成了一个半死不活的企业。可悲！
