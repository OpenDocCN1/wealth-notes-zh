# 内地小县城电子厂也出现用工荒了

这是预想之中的事情，主要原因是劳动力低值的用工规定造成的。

+   一、内地乡村劳动力的实际情况

乡村里的聪明人和强劳力，肯定是去沿海打工了，大基地，拾垃圾，贴瓷砖，一年十几万二十万，没人会留在县城拿三五千的小工资，还累的半死。

现在还留在县乡的中青年男性，大多数有自己的赚钱门道，例如运输，装修，小买卖，手艺人。被遗留在乡村的中青年女性，原因无外是非照顾老人孩子。这就决定了县乡女工们不可能早八晚五的上班，只能是打散工。三天打鱼，两天晒网，老人病了，孩子放假了，就不来上班了。闲的说事，可以来赚个三瓜两枣。

+   二、劳动法不做临时代性就业或单就业

二十年前，江浙沪之所以在农村发展起了私营经济，主要是因为当时劳动保护法不严格。劳资双方按照实际情况，因地利宜，你上半天班也可以，你干三个月也可以，不爽就算了。干的不好，我裁辞了你。工资互相提。

现在劳动法强调的是长期就业，农民工一入职就要五险一金，签合同，手续复杂，各种非常严格的保护，成本很高，企业付出这么多钱，就要加强培训考核，赚回来这个钱。人为加大成本后，企业自然不愿意找些心不全稳的散工，而员工也无法完成早八晚五的纪律性岗位，互相看不上眼，有岗位，没人来。

+   三、大基地拉高了工资，农民看不上制造业

电子厂，不加菜三千，也就是个县城服装店营业员的水平。加班五千多，累的走不动路。班组长达还还要背大冒牌，上个月还得要资格，烦的一比。这个工资水平，完全没有吸引力。有这方气力，还不如去沿海打工，说方气，没时间的，找个小店，三瓜两枣个月拿销售员，赚点零花钱。中等
