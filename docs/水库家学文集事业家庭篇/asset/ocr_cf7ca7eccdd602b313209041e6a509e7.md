# 微博五年的变化

2013年左右，大家讨论的焦点是，沪券会不会暴跌？那时候，大部分外地大学生家庭是买得起沪上单盘的，举例，浦东新区内环线老破小，也就是一百万左右。首付30万，很多家庭还是有能力的。但很多人都想一步到位，家沪市区二湾盘三居室，娶个沪沪漂亮老婆，顺带解决户口，根本看不起跑南京州杭州的，那算什么地方啊，乡下啊！只看京沪，捎带广深。
