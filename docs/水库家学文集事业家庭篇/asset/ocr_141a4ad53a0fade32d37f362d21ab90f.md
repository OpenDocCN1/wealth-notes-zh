# 上下班工伤

上下班途中，助动车被汽车摩擦一下，是工伤。

我前两天遇到一个小老板，他们公司员工比较多，经常出点小意外，主要是助动车上下班摔一下，这些年，小老板为这事搭行了很多工伤费，医保之外，企业还要支付小骨折几万元，重一点的十几万元。每年几十万是的。

小老板现在经苦心恼。小骨折还能够承受，万一来个大事悄，他可怎么办？其实，理想也简单，员工离开公司控制范围后，老板还要为他的上下班路损，这岂不是什么加级保险损推了。老板该算算信是交单的问题了。让小老板买单，是所有人最愿意看到的事情。小老板有老有小，有点小资产，也不球怎么样。那就他了。

# 清盘还是支撑？

就是，我是一个老板。现在月亏 8-10 万，主要是订单少，养销售团队的固定成本高。如果我现在就营业清盘，等于彻底输了，就剩下一套房子了。如果继续支撑，抵房子还能够支撑 12-16 个月。

问题是，根本看不到行业好转的可能性。如果把最后一套房子赔光了，我的妻儿就完了。我该怎么办？

# 民企老板与职业经理人

为什么，我们的民企老板不相信职业经理人？

+   1. 职业经理人水平良秀不齐。我们没有 - 个培养职业经理人的渠道，所以，就不可能批量的产生优秀的职业经理人。高水平的总经理，都是自学成才，机运使然，数量很少。老板就算相信一个 emba，也很难确保企业挣钱。

+   2. 职业经理人道德水平一般。吃里扒外，短期考虑，屡见不鲜。例如，在采购中，采购他的兄弟公司，关联公司，朋友公司。在销售中，把好货赐给熟人。在生产中，关系户的工价提高，非关系户工价乱压。乱报销，多报销，贪污，收款迟到，这些都不阳生吧。

+   3. 职业经理人往往是业绩考核，但业绩并不是 - 个人能决定的，外部大形势，内部各部门配合，只要有 - 块搞不定，企业就挣不挣钱。民企的各部分家族内斗，往往是非常剧烈的，所以绝大部分的职业经理人两三年就滚蛋了。万般无奈，职业经理人可能更多的就考虑自己的利益，对企业下黑手也是屡见不鲜的。

职业经理人怎么才能全心全意的服务民企？

在我国的商业历史长河中，职业经理人做得最好的应该是山西票号，一百多年，没有出现一起掌柜贪污潜逃的事情。但有一个大家都不知道原因。山西票号的掌柜和大伙计（职业经理人），不承担任何风险，居然可以拿到整个公司纯利润 60%，股东承担无限责任，只能拿到纯利润的 40%。

说白了，山西票号其实就是职业经理人完全控制。股东可怜巴巴的还可以拿 40%，是因为需要股东来说省锅侠，承担了无限责任，给他们一点甜头而已。万一出事了，官府倒纵股股东，和大海桩无关。
