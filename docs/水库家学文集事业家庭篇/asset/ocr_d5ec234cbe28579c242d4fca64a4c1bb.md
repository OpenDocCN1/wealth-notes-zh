# 为什么小企业亏损严重

老板倒贴钱，也关不掉？

+   1，小企业亏损的很多。但是关门的不多。因为不敢关门。

+   1，劳动法赔偿。现在普遍是 N 个月工资。农民工现在在大多数是 5-8 个月收入。十个三年工龄，就是 18 万～20 万。大部分小企业，30-40 个人是有的，一百人左右是普遍情况。

+   2，封口保密费。小企业要关闭了，这是高管们最后一次机会了，什么事情都会发生。最多的情况是，很多高管掌握了小企业不违规的地方，有钞票影的说告官，以此争取额外补偿，这笔钱就大了。

+   3，有关部门查账：一旦正常经营的企业关闭了，有关部门就来了。查账是司空见惯的。你懂的。

+   4，欠款。现在要关闭的企业，有很多欠款，包括银行贷款，供应商欠款。如果维持运转，不会立马出问题，一旦关闭，债主堵门，信贷员冲到办公室坐着，法院传票纷纷过来。

+   5，小企业最好的退出办法是，整体盘给別人。目前很难找到下家。

很多人不懂企业经营，他们的观念是，亏钱为什么还开着啊？你当我傻吗？
