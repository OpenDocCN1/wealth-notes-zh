# ## 很多人完美错过了 20 年的全部机会，现在彻底沦为了老屌丝

贫穷的主要原因是，不科学的独立思考。

过去二十多年，你只要胆大流，在大城市多买套房，或者多买 20 个平米，你全家就走上快车道了，娶媳妇家，你有面子。但是，很多聪明聪明的人，极度喜欢独立思考，完美错过了二十年的全部机会，现在彻底沦为了老屌丝了，还不解气。

看了两个微信朋友圈，你就天天瞎琢磨，那不是独立思考，是发症癌。

独立思考有前提的，充分掌握信息。99.99%的人是做不到这一条的。过去二十几年，经济信息，发展数据，内外形势变化，货币政策转换，发展目标的变换，政旗工具，时时刻刻都在做调，三五年大调，你有多少时间去研究这个？你所谓的独立，无非是看几个微信朋友圈。

独立思考，不能以个人好恶为出发点。买房不起房子，就独立思考出，房价马上腰斩，售楼小姐免费在厕所。我是男方，就独立思考出，要彩礼，加名字的女人，都是卖女儿。这种独立思考，只不过是为自己遮羞，祸祸了下一代。

独立思考，需要有执行力的支撑。很多人也知道，子女二十岁了，应该考虑婚房了。但是，他太喜欢独立思考了，总觉得我这么聪明，肯定能够便宜几千万，拖拖拉拉，犹犹豫豫。最后，房价翻倍了，从徐汇一路涨到了徐家汇。
