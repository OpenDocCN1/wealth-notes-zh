# 为什么中国没有形成投资人的氛围？

+   1，信任度不够。中国出现有钱人，大概是十几年的时间，富人之间的信任度基本为零。

+   2，骗子疯子太多。很多中专者归层新 985，走投无路，毫无底线，给他五十万，他什么文件敢签名，没注意好。

+   3，急功近利。中国人往往急躁，一年大发展，三年见效益，五年要上市。哪有这种好事情？

+   4，缺乏科技内涵。中国的创业，基本都是复制拷贝外国某个新生意，比得是偷抢钱多。让你替我找，还不如替换一个自己找。

+   5，实体经济赚钱太难了，成功机会太小。钢镚骗来几十亿伪投资，现在也是大裁员。

+   6，没有契约自由的法律基础。风险投资是对未来不确定的事情投资，合同条款肯定是稀奇古怪的，但这个在中国不行，任何事情都要有法律政策，否则天知道结果会怎么样？

+   7，最关键的一点，中国的风险投资，没有退出机制。几千万下去了，要么上市，要么打水漂，几乎没有中间状态。每年 lpo 指标就那么几个，各级审批，繁文缛节，你懂的。投资的成功率比双色球还低。

# 如何发展民企？

民企最大的问题，不是贷款难，而是成本高，心气高，劳动纠纷多，最后赚不赚钱了。

民企哪里需要什么几个亿的贷款啊！建一个大钢厂，大炼油厂，开发一个县城楼房，确实需要 3-10 个亿，但那是量力而行。你有钱，你去建，没能力就算了。民企最多也就是建个集体宿舍，建个 8 米层高车间，1-2 千万到顶了。总不能什么都靠贷款吧？你家有房子，也卖掉两室演凑。

民企的生产经营性贷款，一千万基本到顶了，建设性贷款，盖一栋楼体宿舍楼（农民工确实需要），两千万到不了。绝大部分中小微企业的融资需求，都是百万以内的。如果有房产抵押，银行就不要去他们了。特别是手续上，无事生非的要看各种资料发票，烦不胜烦。企业给员工开食堂，两百人的大钱厂，一年下米食堂也要 120 万支出了，上哪家开发票？

民企不缺贷款，缺的是利润。如果利润好，亲戚朋友几分钟凑够三百万给你，只要 8%的利息。问题是，企业赚不到钱，那那，只好找银行消费贷款了。企业为什么赚不到钱呢？好吧，99%因为小老板思想落后，不搞高科技研发，不搞精英大投入，做不成芯片。那我们就谈谈那 1%的事倍。

+   一，成本高。税务罚，社保公积金个税，最好奖励企业和员工多做贡献，交完税再捐多多捐款，社区要办个好人好事了，你小老板是不是也出一点？呵呵，真的一丝不苟的交了这些税，思想脑后再不做高收入，做企业是很难过下去。企业好不容易结条点钱，发工资了，企业支出 11000 元，员工只能到手 6300 元，你看真不爽？

+   二，心怯素。企业的罚款，1-20万，1-5倍，全凭一句话，懂不懂事？大家看都懂。

+   三，劳动纠纷多。现在的劳动合同法，使老实话，就是法官律师，我也们出不了都懂，那些微徒醒时稀糊的小老板更别提了。最主要的是，裁判人员自己和家人绝大多数也是上班族，企业处于什么状态，可想而知了。所以，上下班路上员工摔一跤，企业也要承担责任，孕妇生孩子，小老板也要掏钱。开心位？
