# 微博十年，最大的收获

是对人性有了更加清晰的认知。做人要努力，成功就是持之以恒。

我们这一代 top1，一直生活在良好的氛围里，每天像个骄傲的小公鸡，趾高气昂。我们和周丝，和农二代的接触不多，主要接触是快播、装修和保姆，所以对江湖险恶认识不够，以为别人也是 985 思维。

微博这么多年，我算是明白了，人心难测，形形色色。不要轻易相信任何人的甜言蜜语，实际上，绝大部分人是讨厌你有钱，反感你有地位，他们很羡慕你，但是他们长期习惯了好吃懒做和底层思维，使他们无法翻身。

不要在意图周的穷亲戚，甚至是近亲属，说了什么话，而是要向成功的人学习。每个人周围都有几个成功的人。你仔细观察他们一举一动，一望一笑，时间长了，就会有感悟。千万不要沉浸在底层思维，对于别人的成功，充满鄙视，或者自以为是地认为自己啥都懂，就是没机会打土豪分田地。

机会不是等人的，而是自己争取来的。我以前就没机会，都是自己一枪一枪爬出来的。我写微博的基本功（最分总结构）就是十几年如一练出来的，现在发一条广告至少几万块钱。你加油，你也可以发财，买别墅，换车漂。
