# 菜嫂从娘家骗来的钱，应该有我一半

我觉得，我还算精神状态正常。但菜嫂说我不正常：是她从娘家骗来的钱，又没花你的钱，但我觉得，既然骗到钱了，就该有我一半，这件大衣有我的2.6万元，大家觉得我是不是正常？我也糊涂了！
