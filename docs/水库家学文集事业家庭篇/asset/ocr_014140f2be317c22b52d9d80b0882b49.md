# 你把自己喝伤了，根本没人在乎

年前，我参加了不少年夜饭聚会。很多朋友公司都请我去捧捧场。

在酒席上，我看到了很多年轻人。小伙子，小姑娘，年轻漂亮，对生活充满激情，就像当年的我。

年轻人看到我们这些老混蛋，热徭洋溢，菜总啊，张总啊，李总啊，热情敬酒。一些老痞子哄着他们喝大杯，看他们杯的白酒一口闷，我差点被新生代吓傻了，这也太猛了，尼玛啊，53°的白酒啊！小姑娘，你不要命了？在现场，我也不好说什么，气氛还是要的。

现在，年过完了，和年轻人说几句，不管你会不会喝酒，尽可能说不会喝。说人因为为你会喝酒看你一眼，最多拿你当个250，特别是小姑娘，尽可能不要在坐种老混蛋圈里刷脸。没用的。你喝的再爽快，我也不会就因为你几杯面膜找你。相反，你把自己喝伤了，根本没人在乎。大多数时候，你是任务，那就泡一下。
