# 做一股生意

千万不要找外部合伙人。

按合伙人，绝大部分是撕破脸结束。公司做好了，固定资产几千岁了，互相争权夺利，采购经理让我妹去做，做了，怀疑大股东拿了钱，掏空公司，你要交代这笔钱！

“好好好，我害你了，二股本来嘛财务总总总行了吧？”还是不行。因为我决策买个大设备，我不同意，就算下来利润率太低。你给王小姐加工资，我也不同意，谁知道你们是不是有一腿？（还会〈万码一万字）。

愿意说，“开董事会啊！”你看啊！中小企业最大的优势就是，快快快。各种事情如果开会做决策，你以为是大单位啊？我在武汉要下个订单，你不同意，让我回蚌埠向董事会汇报工作？老子一脚踹死你。

为什么会产生这个问题？因为人的思路不一样，就算是两口子，装修完了说离婚，就算是模范夫妻了。有时候为了瓷砖铺什么颜色，夫妻两个可以在市场里互相打起来。到了公司，这个问题也是始终存在的。

谈合作的时候，大家互相吹捧，其乐融融。干开了，大老板有钱，想做大做强，二老板是小户，只想每年分红，每家每户，情况不一样，想法就不一样了。大老板确实常常欺负小股东。小股东也很可怜。马动志，全家勒紧裤腰带投进去八十万，原来指望三年翻倍的买房，现在搞成这个样子，钞票都变成机器了，我不服，我要闹！

大老板说，“闹你个锤子，老子说了算。”

小股东说，“你信不信，我现在就告去各个部门告你。”

这种纠纷，此起彼伏，多的一 b。所以，现代管理制度，没有一个亿，你别多想了。这事情和你没关系！
