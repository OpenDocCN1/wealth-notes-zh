# 安卓手机企业面临的经营风险

放眼世界，手机也就两个牌子，苹果手机和杂牌手机。

大致看，杂牌手机是苹果手机一半的价格。苹果手机依靠品牌优势和较好的用户体验，卖高价，就给其他手机留出来足够大的市场份额。其他手机厂，一个品牌也居然搞出所谓几百亿美元估值。

但是，苹果手机如果哪天不爽了，或者出于某种无法预测的目的，放弃几年盈利，直接降价一半，其他手机恐怕就活不成了。这不是开玩笑，因为其他手机都集中在一个地方生产。

# 最后一句是关键

民企老板的结局不太好，自身缺陷也是主因。

中国十几前的商业环境是不完善的，充满了无法预测风险和成没完没了的纠纷。敢创业的老板，绝大多数有极强的个性，难说好的就是，精神有点 xx。这类人好像多少有点迷信。实际上通过各种卑劣的推究挖究，克服商业风险造成的长期焦模和心理压力，运气好的一部分人就搅下了巨大家业。

长期的精神压力，往往会导至人的精神出问题，外人是不看到的。这些老板表面正常，但在私密场合容易暴虑，情绪失控，焦虑到了极点，有些人还长期服药，或者有一些奇奇怪怪的行为，动不动就会发狂。

这些老板现在大部分已经六十岁了。性格非常固执，眼睛老花了，学习能力基本丧失，但又以几个经验丰富，掌握人性，看几个微信，就认为通晓一切。他们不愿意交富，又没有能力继续管理复杂的企业事物。管实体企业是烦不胜烦，不管，各种各样的小经理就搞好吃，管，就是天天紧张，头痛脑胀。

老板们周围总有几个天天吹捧他们的人。这些人接近富人的目的，就是为了最后捞一把。但是，酒肉朋友们很少说话，专门惹恼老板们的想法去吹捧，老板们和他们在一起，感觉非常舒服，就像心理按摩一样舒适。这些人经常研究出各种说辞，把富人往各种陷阱里带，你有一百个警惕心，他有一百零一条的计谋，总有一款适合你。

这些有头脑的老人，一旦中招，就会几百，几千亿的烧钱，把全家带入深渊，家里谁要是劝阻他，他就发狂。前两天我去了一个老板家里，老板女儿已经哭遍了，六十多岁老板还是执迷不悟，认为这几千万可以让他开创的大事业，说什么都用。

我已经劝这个老板的手机号删了。这他妈的就是个骗子陷阱，但我无法说服他，因为那些吹捧他的人，已经连续说了快两年了，把所剩的几块薄饼都彻底烧了。你要对待老板的遗嘱，至少三年，还要拿出大量的数据统计研究。我吃饱了管这档事？

民企发展到今天，第一代老板大多都是 55-65 岁左右，还不至于退休。我至今没有见过一个正常交接给子女的民企，丰病猝滚的老板可能是最佳结局。我感受，能够正常退休下来的老板可能极少。因为她们很根本不想退，他们太喜欢小企业里一统局面，不停的吹捧他的感觉了。

我见过好几个老板子女，已经和老板彻底决裂了。这些老板大多致只有一个孩子，决裂之后，老板们已经放飞自我了，基本没有什么家庭感情色彩。

总结：屌丝逆袭，这也是条路子。按照富人，拉他去投资，你也就发财了。
