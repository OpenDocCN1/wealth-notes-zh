# 小姐身子丫鬟命！

老张原来是某国企中等规模厂总经理，业务技术出身。十多年前，有点经济问题被查了，关了几个月，判了个别缓刑，就出来了，从此，再也进人登门了。

他女儿那时候大概还是高中。家里出大事后，从人人见人爱的小小姐，一下子变成了 250。很多人还欺负她。她也长得一般，普妹。因为实在是不变了，就考到外地一个高职，不回老家了。

父母退休后，也跑过来了，不管怎么样，多少还有点底子，就在某地级市买了房子。那时候也就是一千多元，现在七千的样子。这个大小姐也奇怪了，照说法，都混成这样子了，应该变得俗一点了，偏不！她对对象，就一个要求，老实人。于是，找了个农村房后初中学历。帅是很帅，但是脑子不行，赚不到钱，也不会温，就在小工厂当工人。

家里没钱也不行啊。于是大小姐就开始自己做点小生意，卖欺诈首饰给小镇女青年，几十块钱一个项链，这几年也赚了一些钱，又按揭了一个三室两厅，总价八十万，首付三十万。小地方生意难做，磕磕碰碰的事情多。现在，这个大小姐已经经常到小店媳妇的程度了。

想当年，他老爸在好的时候，是有能力给她在京沪该提买套房。若真，现在可难人生就不一样了。可惜了。
