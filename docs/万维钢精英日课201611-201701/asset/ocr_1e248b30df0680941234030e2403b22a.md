# 日课091 | 把人变成工业品的思想(上)

日课091 | 把人变成工业品…

不知道咱們日課的讀者中，有沒有人有過“打工”的經歷——不是說腦力勞動或者“白領”的工作，我是說純體力勞動。我有個朋友，學生時代曾經在餐館打工，他的任務是洗碗。他跟我說起那段經歷的時候，既沒抱怨工作累也沒抱怨工資低，他最大的感慨，是那份工作根本不讓你“幹好”。

他自詡聰明，發明了一個新的洗碗方法，洗得又快又好——結果遭到了餐館老闆的懲罰。老闆並不認為洗碗這個工種有什麼可創新之處。你老老實實幹就是了，任何偏離標準動作的做法，都是偷奸耍滑。

這位老闆，深得現代企業管理之精髓。工業化大生產，要的不是什麼高人奇人，而是“平均人”。

“平均人”，這個思想現在聽起來簡直是悲哀，但是1百多年前它剛剛流行的時候，就如同現在的“互聯網思維”一樣先進，一樣牛氣，一樣讓人津津樂道。現在思想新潮的人肯定都不屬於去到哪個企業當“螺絲釘”了，可是歷史上曾經有過一個時期，做螺絲釘非常光榮。

這一切，起源於人類歷史上第一個“大數據”時代。

今天我們繼續說《平均的終結：我們怎樣在一個崇尚相同性的世界中成功》(The End of Average: How We Succeed in a World That Values Sameness) 這本書，作者是哈佛大學教育學教授托德·羅斯（Todd Rose）。

# 1.社会科学的牛顿

黃仁宇一直抱怨中國歷史上的王朝沒有實行“數目字管理”，導致國家經濟上不去。歐洲歷史上的確很早就對私人財產有“數目字管理”，但是要說政府對國家情況有一個清楚的判斷，也是近代的事情。19世紀中葉，歐洲各國政府開始大規模地統計人口數據，一時之間各種數據暴增，人們突然對國家情況有了一個全新的視角。

這就孕育出了一位了不起的思想家，阿道夫·凱特萊（Adolphe Quetelet）。有了充足的數據，凱特萊就開啟了用定量分析的方法研究社會問題的時代，他被視為是社會科學領域的牛頓！

“平均人”這個思想，就源自于凱特萊。

# 2.以高于平均为荣

1851年英國舉辦了一個萬國博覽會，地點就在水晶宮，這是載入歷史的大事。而在當時某些人看來，這個博覽會有點丟英國的面子，因為博覽會上最牛的展品，都是美國人制造的。一個英國人類學家，弗朗西斯·高爾頓（Francis Galton），就產生了一種恨鐵不成鋼的情緒。难道英國人不行了嗎？

高爾頓說，什麼“平均”，其實根本不值得追求——你應該追求高于平均！你的跑步速度比平均人快，你應該以此為榮啊。在高爾頓看來，偏離平均值，既不是誤差也不是錯誤，而是排名的參照物。高爾頓發展出了一系列人格測驗的方法，想通過考察個人相對平均水平的差異，來把人分為高中低檔。
