# 知微 21

想像一下，这样的生活真的很棒啊！如果可以只拿福利的话，我一定会最大程度地去尝试曾经那些不切实际的“梦想”，环球旅行，陪伴父母，拍摄电影，玩玩音乐……哈哈哈哈，感觉生活是如此地美妙！
当然，只是想想。其实这些事情现在也能做，只不过是被安排在了房子和车子之后而已。
其实，我觉得所谓没有工作的时代并不太靠谱，一方面是从对社会的稳定的角度考虑，就想万维钢老师和罗胖老师说的，我们需要工作来维系社会这个大共同体。其次，我觉得就算是随着人工智能的不断发展，一部分工作被取代了，但同时一定会有新的工作被创造出来啊！人类作为如此聪明的物种，怎么会让自己灭亡呢？也许真的到了那一天，会有更多的人转向服务业吧！现在，不是一种新的职业叫"网红"吗？(^_开个玩笑)。
总之，我觉得工作是人类生活的一种必需品，就算消失，也不过只会换一种方式存在而已。
