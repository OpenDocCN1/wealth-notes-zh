# 周末攻略 | 什么样的留言会被精选？

现在我们每天的文章都有好几百条留言，也有许多读者问我：为什么我的留言没有被选出来？怎么才能被选出来？

我想干脆写个攻略吧，剧透一下我选日课留言的…标准，给有这样疑虑的读者做个参考。

说&aacute;“标准”，不如说我们的专栏鼓励什么，或者期待什么。每位读者花了钱订阅，需要获得价值感，这个价值不仅来自于文章，也来自于各位精英读者的思想。所以我挑选了一些举例说明，但这只是举例，因为好留言实在太多了。

# 比如说，这样的留言被选的概率就会很高：

# 1.老司机的真知灼见

和其它知识、经验、场景的关联思考，把文章的观点提炼升华到一个高度，给大家（包括我）提供一个崭新的视角！

> 王煜全 290
对行为和心理的研究就仿佛是一场军备竞赛，政府和商家用“助推”思想来影响社会公众，个人用自我认知的提升来抵御诱惑，结果变成和谐魔的同步增长，简单粗暴的方法不奏效了（如传统广告），新的“助推”方法极大发展出来，而公众也在抵御新的行为影响中变得更加有智慧…对企业来说，掌握了先进的助推工具就是掌握了核武器，而对个人而言，了解行为设计就是更好地抵御善恶、更好地进化，其关键，就是战败对方便是在自己的跨界里出现类芬兰。

# 2.自己的经历和具体的人

从自己行业角度给话题做了漂亮的延伸，哪里是不相同甚至相反的观点。每篇文章的视角都有它的局限性，很多思想如果不被体验或践行，它大概就是冰冷的。是这样的留言让知识落地，又让思想长出了翅膀，让我们见识到陌生领域的精彩。期待不同行业高手的分享！
