# 来自日课：斯坦福商学院都招什么人

很多人认为美国及美国公司的成功，很大一部分来自于多样性，董事会也都要求多样性，那单一性有没有价值呢（像日本企业）？多样性有什么缺点吗？

万维钢

多样性的最大缺点可能就是一旦众人的价值观不一样，就麻烦了。最理想的多样性是各人的价值观相同而看问题的视角、解决问题的办法不同，这就叫 “君子和而不同”。反过来说，如果一帮人看问题的视角相同，会的本事也都一样，但是各人有各人的利益，想要的东西都不一样，那就是 “小人同而不和”。
