# 每天必写日课
28

我弟弟今年也十四岁，我二十一岁，在那个教育的问题上，我想我有一个想法可以分享。我爸爸就特别凶，每次我弟弟犯错误的话他就打他（以前也是这样对我），所以我比较能理解我弟弟，他现在也比较叛逆，偶尔逃学，整天和同学搞生日聚会，今天这个过生日，明天那个过生日，出去吃饭啥，唱歌，反正就是不学习。我爸爸为他伤透了脑筋，亲戚们也都说他完了，不会有出息，现在我爸爸和亲戚们都已经放弃了，因为他们的教育方式没有效果，他们也想不出有什么办法了。

但是在我看来，他们有时候是过度反应了，一些事本来不是大问题，但是当他们心里有一个对他的认为，认为他是不好好学习的人，所以当他做出一些事的时候，我爸爸对这些事的看法都是带着他对弟弟的认为的，会造成小题大做，这样我弟弟也会特别反感，长此以往，矛盾就会恶化，失控。我对我弟弟就没有带着他是坏孩子，不好好学习，以后没有出息的看法，我能理解他，我能宽容他，他跟我倾述的时候就不会有隐瞒，因为他不怕会被我责怪。我弟弟曾经说过一句让我特别感动的话，那时他跟家里人的矛盾最激烈，他跟他们说：“你们说的我都不听，我只听我哥的。” 而且我发现我弟弟也爱学习，今年暑假我给他补习的时候他主动说只有星期天下午的时候才出去玩，主动手机也暂时不用了。

从我弟弟的例子中，我了解到，有时候父母因为对子女的责任与爱，怕教育不好子女，所以在教育的过程中会过度用力，反而适得其反。而我没有责任，只有爱，而且他现在的经历我经历过，我能理解他，也能宽容他，所以他听我的。父母有时候对子女的教育，不是出于爱，而是出于私心，或是由于舆论的压力，怕教育不好子女被别人说，或是让子女去继承自己的梦想，其实子女是能感受到父母到底是出于爱，还是出于私心。如果你真的是因为爱，他能感受到。如果 你有一点私心，他也能感受到，他就会反抗，你得理解反抗这个词，有压迫才会有反抗，他感受到的压迫就是你强加给他的东西，是你的私心。而我对我弟弟没有任何私心，只是单纯的手足情，而且他能感受到我能理解他，不光是我能理解他，而是让他能感受到我的理解。

总的来说，就是让他感受到两样东西，一是你没有私心的爱，二是他能感受到你的理解。
