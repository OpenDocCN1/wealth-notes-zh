# 应丽芳 18

经常思考人类行为背后的意义。

一层一层的思考，一层一层的深入，最后无不只能发现:人类所引以为傲的自由意志，欲望，兴趣，爱情，全都是文化所致，历史所致。

我们所有人的所有特征，就像是设定好的程序，一步步演化，演化的方向可能不确定，但是演化的逻辑都可以倒推，有其必然性。

每个个体和每个个体，每个家庭和每个家庭，每个国家和每个国家，每个文化和每个文化，都是程序不同演化方向的不同结果。但是本质，却都一样。

我还曾为此沮丧过。但是，就像文中所说，那期盼的绝对的自由到来的时候，反而人们会无所适从。最快乐的自由，应该是有限制的自由。
