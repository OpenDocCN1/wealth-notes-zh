# (๑•̀ㅂ•́)و✧

专注 和 震动 的关系，很像我们计算机专业 的成长过程。

开始学习一门新课的时候，我们会有课本和lectures，我们对知识点反复学习，用各种练习题巩固。这是专注的过程。

但这是不够的。很多课都会设置一个project，需要用所学甚至一些额外的知识。这时候我们就面临着震动！搜索各种新的知识，对所学的课程知识作新的应用。做完后，我们会对课程知识有更深的理解。这是震动的过程。

只有 专注和震动 两手一起抓，计算机专业的知识才能学得扎实。只有专注，可能空有理论思想不懂实践。只有震动，效率低下且不易融会贯通。缺一不可。
