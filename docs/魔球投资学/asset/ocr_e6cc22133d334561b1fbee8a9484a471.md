# 18 萊特兄弟的故事

——為什麼創新勢不可擋

所有創新再現的都是與過去的某些斷裂——燈泡取代了煤氣燈、汽車取代了馬車、汽船取代了帆船。然而，所有的創新同樣也是以過去的斷片建築而成——愛迪生的發明所依循的核心原則來自煤氣工業、早期的汽車由馬車商製造、第一艘汽船其實是把蒸氣機裝在原本的帆船上。

——安德魯·哈格頓（Andrew Hargadon），
《突破從何而來》(*How Breakthroughs Happen*)

我們務必要確保我們的工業有能力每年生產高達50,000,000 噸的生鐵、60,000,000 噸的鋼鐵、500,000,000 噸的煤，以及 60,000,000 噸的石油。唯有成功達到這些目標，我們的祖國才能免於任何意外事故的危害。

——約瑟夫·史達林（Josef Stalin），1946 年演講

未來的帝國，是思想的帝國。

——溫斯頓·邱吉爾（Winston Churchill），
1943 年哈佛大學演講
