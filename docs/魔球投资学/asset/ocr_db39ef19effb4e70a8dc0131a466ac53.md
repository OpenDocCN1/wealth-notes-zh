# 你的心跳下承諾而你的身已無法填滿

1998 年，企業策略委員會（Corporate Strategy Board）發表了一篇有關「失速點」（stall points）的詳盡研究——他們稱之為失速點的，就是 S 曲線頂端的轉折處，${ }^{11}$ 也是圖表 20.1 裡 B 點到 C 點的轉移。委員會發現，有 83% 達到失速點的公司再後續十年的銷售成長大約為 5% 或更低。對投資者來說更重要的是，他們的研究顯示這些公司當中有大約 70% 會失去至少一半的市值。這個跡象證明了投資者總是把最近剛過去的股票的勢外推到可預見的未来，然後在銷售放緩的時候再降低他們的期望。

研究者也發現，一旦公司營業額達到大約 200 億元，二位數的（實質）營業額成長率就極度罕見了（不過這個成長天花板正在緩慢上升中）。今天，有些大型科技公司的股價仍然反映了二位數的強大成長率期望。${ }^{12}$

創造性破壞和失速點的相關研究有一項共同點值得關注——無法創新與創造成長的原因，主要來自於可控制的組織和策略性因素。佛斯特和凱普蘭詳盡闡述了企業的例行運作如何讓組織陷入衰老狀態；兩位作者也提供了一些有效的指南，讓企業得以持續革新。企業策略委員會的報告深入分析了失速點的成因，而且他們認為只有少於 20% 的因素落在企業的控制範圍之外。
