# ## 跟隨你前方的螞蟻

模仿是正向回饋的首要機制。例如，動能投資策略（momentum investing）假設正在上漲的股票會繼續上漲。如果足夠多的投資者依循動能投資策略，股價上漲也就成了自我應驗的預言。
