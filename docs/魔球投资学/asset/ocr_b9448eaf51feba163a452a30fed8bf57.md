班傑明·葛拉漢（Benjamin Graham）曾經說過：「在股票市場裡，價值標準不會決定價格，是價格決定價值標準。」$ ^ { 3 } $個人投資者並非以內在準則建構價值標準，而是受到他人行動的影響。股票價格反映他者的集體行動。但是每個人受影響的可能性並不均等。我們都有各自的所謂「採納臨界點」——即某個行動的採納者人數必須達到某個數值，我們才會加入。市場的極端事件將情緒推向高點，幾乎超越所有投資者的採納臨界點。這類極端事件也可能創造反向情緒。

而且，我們的互動比以往更頻繁。近年來，科學家對小世界效應，也就是俗稱的六度分隔理論有了突破性的理解。$ ^ {4} $小世界模型的核心概念之一就是叢聚（cluster）——即節點和節點之間有多大的連結性。舉例來說，叢聚的分析說明了你的朋友之間彼此認識的可能性有多高。

以模型再現這些網絡時，研究者發現，即使只在局部、叢聚的網絡加上少許的隨機連結，就能大大減少個體的分隔度。因為有了現代的低成本通訊網絡，各種想法在社會叢聚當中以前所未有的速度傳遞。大眾媒體更進一步加強我們之間的連結。

生物學的類比告訴我們所有投資者或早或晚，終將屈服於市場裡無論多方或空方的強烈情緒。而且，既然我們具備溝通的能力，因此交互作用必定發生。情緒攪動自古皆然，現代人無法免疫。
