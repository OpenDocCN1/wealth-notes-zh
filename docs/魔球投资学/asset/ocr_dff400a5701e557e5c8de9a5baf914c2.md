# 本能如此

大多數人知道人類的大腦分成左半球與右半球。右腦在處理圖像、空間相關的任務時表現優異，而左腦的專長則是語言、會話、解決問題等相關工作。右腦較發達的人很有創意，而左腦型的人則精於分析。

但是左腦系統的專長不限於計算，還會在背後持續運作，為所有遇到的事件尋找連結。被神經科學家麥可·葛詹尼加（Michael Gazzaniga）稱為「解譯器」（the interpreter）的左腦，試圖以融貫的故事把整個生命連繫在一起。1

胼胝體（corpus callosum）是一道神經組織的橋樑，連結著左腦和右腦。為了更全面理解大腦左右半球的不同功能，葛詹尼加和他的同事喬瑟夫·雷杜克斯（Joseph LeDoux）投入研究左腦無法連結的病人。科學家知道，如果某個大腦半球接收到獨有的資訊，另一半大腦是無法得知這個資訊的。

為了檢測大腦左右半球的互動，葛詹尼加和雷杜克斯設置了一個極為精巧的實驗。首先，透過圖像提示，他們祕密地指示右左腦執行某項行動。左腦觀察到行動發生，但無法理解狀況。接著，科學家請腦裂病患為他的行動做出解釋。值得注意的是，病人的解釋來自於左腦。例如，當科學家指示右腦大笑時，病人的左腦會解釋說：科學家很滑稽。雷杜克斯如此寫道：「病人解釋當下狀況的成因，就像他確實回顧了導致該行為的原因，而實際上他並沒有這麼做。」2 解譯器正在發揮作用。
