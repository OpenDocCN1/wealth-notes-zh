# 尋找熱手

人類天生就會尋覓模式（pattern）。其中一個眾所周知的例子即是籃球比賽中的「熱手」（hot hand）。連續幾次進球的球員會被認為是手感火熱的「熱手」，暗示著他下一次投籃將會有異常高的進球機率。研究顯示球迷和運動員本身都相信熱手現象。

問題只有一個：熱手根本不存在。科學家研究了費城 76 人隊（Philadelphia 76ers）一整季的進球統計，以及波士頓塞爾提克隊（Boston Celtics）的罰球記錄，結果沒有找到任何顯示熱手現象的證據。球員當然會連續進球，但球場上的連續得分完全符合機率。連勝或連敗始終受制於機率。¹

即使模式不存在，我們也能看到，因為我們的基因帶有這樣的傾向——以為符合機率作用的結果不僅出現在總體事件序列
