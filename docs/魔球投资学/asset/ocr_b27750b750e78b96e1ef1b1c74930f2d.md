+   1. 持續性的卓越經濟績效得以維繫的時間正在縮短。他們的分析證實了這項假說，顯示公司離開「卓越績效階層」的機率越來越高。

+   2. 超強競爭（Hypercompetition）不僅限於高科技產業，大部分產業都有可能發生。證據支持這項假說——非科技公司留在「卓越績效階層」的機率比科技公司來得高，但是離開該階層的機率也隨著時間而增加。

+   3. 企業逐漸傾向於把一系列短期競爭優勢串連起來，以此維繫其競爭優勢。這裡指的是，成功的公司把短暫存在的個別競爭優勢連結起來。同樣的，資料也支持這項假說。研究者發現，後期階段的資料顯示單一週期的卓越績效變得更常見。$^{7}$

+   4. 產業集中、高市場占有率，或兩者，跟某個產業失去持續性卓越績效的可能性呈現負相關。研究發現並不支持最後這一項假說。產業的集中程度，或者高市場占有率，跟可持續性的競爭優勢在經驗數據上皆不存在一致的相關性。

魏金斯和雷菲利的研究成果跟其他的研究發現相當一致，其中包括佛斯特和凱普蘭的創造性破壞，以及坎貝爾（Campbell）等人的發現——個別公司的波動率自1970年代中期以來持續升高。$^{8}$創新步調的加速導致個別公司更易於陷入失調狀態。

有兩大因素讓我相信脈動速度的上升趨勢即將到來。首先是資訊科技的進步，這將帶來持續性且明顯的微觀經濟效應。$^{9}$科
