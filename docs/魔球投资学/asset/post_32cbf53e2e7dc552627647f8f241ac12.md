
# 結論：迎向投資領域的知識大融通

自 1993 年以來，我在哥倫比亞大學商學院教授一門稱為「證券分析」的課。正如你所料的，這門課涵蓋投資基本議題如企業估值、財務報表分析，以及競爭策略架構。然而，每一個學期的第一堂課，我都會先提醒學生：這門課提出的問題，將遠遠超過它所解答的問題。

例如，我們無法真正知道市場如何聚合資訊，也無從得知這對股價效率產生什麼意義。我們的風險概念仍然不完善，儘管我們已經知道標準的風險測量方法是錯的。大多數競爭策略架構都不會告訴你，在各種不同的情境下哪些策略會成功，哪些又會失敗。而且，關於大腦如何運作，我們顯然還有太多需要學習。

一長串未解的問題，讓投資這件事變得即讓人興奮，又讓人沮喪。覺得興奮，因為我們知道自己在未來將會得到更多知識，洞察力也會提升。感到沮喪，則是因為我們理解的還是太少，而且，即使最精明的參與者也一再地在市場裡經歷挫敗。

我堅信，不同學科之間的融通是我們提升投資知識的關鍵要素。金融經濟學家總是對來自物理學家、心理學家和社會學家等等的投資相關作品抱以懷疑態度。欠缺經濟學的訓練無疑讓這些領域的科學家處於劣勢。但是，研究者從跨學科的協作所累積的知識，最終將為我們帶來最深刻的洞見，甚至答案，以解開企業和市場的運作機制。

### CONCLUSIONS

至於跨學科的取徑如果幫助我們提升投資的相關知識，以下是一些扼要論點：

- 決策與神經科學：貫穿全書，我引用丹尼爾·康納曼和阿摩司·特沃斯基的展望理論；這套理論說明人們如何系統性地做出偏離理想的決策。展望理論催生了行為財務學的領域，研究的是商業與投資環境裡的認知與決策偏誤。

雖然展望理論已跨前了一大步，但仍然無法揭示人們為何一再做出那樣的決定。如今，神經科學的進步讓科學家得以窺探受試者的大腦，瞥見人們做決策的瞬間所發生的巧妙機制。經濟學家柯林·坎麥爾（Colin Camerer）將神經科學開啟的視角比擬成1950年代整棟大樓第一戶擁有電視機的人家——畫面或許模糊，你可能還需要調整兔耳天線才能看到，但是，新得到的影像和見解讓人興奮莫名。隨時間推移，影像只會變得越來越好。

- 市場的統計特徵——從描述到預測？描述市場時，金融經濟學家在風險與報酬之間預設一種可清晰說明的平衡狀態。遺憾的是，經驗現象並不是簡單的風險－報酬關係能夠說明的。正如本華·曼德博所說的，無法解釋是因為無法敘述。

曼德博自1960年代初開始的金融學研究即有所預示，後來的統計研究確實證明了股價變化的分布並非依循鐘形曲線，而是呈現冪律分布。¹ 市場的從業者很早就意識到這一點，而且還修改了模型以符合現實境況——儘管這樣的調整是出於直覺。然而，即使我們能夠妥善對市場的統計特徵做出敘述與歸類，探尋因果關係仍頗不易。

- 以行動主體為本的模型 (Agent-based models)：大多數經濟學模型掩蓋個體差異，直接預設一個均值的個體。以行動主體為本的模型賦予行動個體有限但多樣的能力，然後任由他們在電腦模擬之中交互作用。這些模型顯示個體差異對市場結果有重要作用，也證實回饋機制非常活躍。例如，人們總是依照他人的決定而決定。嘗試了解市場行為時，這些簡單的模型可大大改善我們原有的直覺，並且最終推導出有用的預測。

- 網絡理論和資訊流：史丹利．米爾格倫在1960年代提出的六度分隔理論——世界上任何人与人之間只要透過五個中間人，即可彼此連結。問題是，米爾格倫進行的頂多只是個粗糙的研究。幾十年來，著名的六度分隔理論終究沒有被證實。

1990 年代末，處理這個問題的新一代科學家開始利用更精良的分析工具，包括電腦。他們透過嚴謹的方式證實了六度分隔理論的有效性，還描述了網絡結構的關鍵特徵。²

我們對網絡有了更完善的了解，這顯然是跨學科的努力所致的；在其中，「硬」科學如生物學跟社會科學彼此開放交流。網絡研究交錯於各個領域之中，包括流行病學、心理學、社會學、擴散理論，以及競爭策略。網絡理論或許能大大增進我們對產品和資本市場發展與改變進程的理解。

- 成長率與規模分布：在工業化國家裡，公司規模的分布高度傾斜——極少數的大型公司和大量的小型公司。科學家早在一個世紀前就觀察到這樣的分布模式；至於造成這種分布的機制，則無人能解釋。

動物體積和新陳代謝率的分布也是傾斜的，而且傾斜的方式跟公司規模分布很相似。科學家已經為動物體積和新陳代謝率分布的物理條件提出解釋。³ 將這些生物學和物理學原理的部分元素延伸到社會科學的領域，成效備受期待。

- 心智的飛行模擬器？我對於飛行員訓練過程中使用的飛行模擬器留下深刻印象。這部精細的機器模擬出無數狀況，為飛行員在真實卻安全的環境裡得到必要的駕駛經驗與回饋。

是否有可能為投資者打造一個目的相同的模擬器？投資的一大困難就在於回饋，長線投資尤其如此。研究顯示，在任何涉及機率操作的領域，清晰與一貫的回饋對該領域的專業工作者大有助益。儘管氣象預報員和賽馬評磅員都能即時得到準確的回饋，但長線投資者卻無法如此。或許有一天我們可以建造一種為投資者提供訓練的模擬器，以提升他們的決策能力。當然，屆時將產生一個更難被擊敗的市場。

每天有數萬億元的資金在全球市場上交易。即使投資者投入了大量資金，研究者也援用了相當可觀的資源來理解市場，然而，市場裡仍然有太多我們無法掌握的東西。這本書宣揚的是這樣一種理念：唯有讓思維跨越不同學科，才有可能把握以上那些問題的答案。
