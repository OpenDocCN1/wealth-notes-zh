# # 投資心理學

投資者需要付出極大心力去留意那些影響他們行為的因素。席爾迪尼列出的六大行為傾向，有其中三點對投資者特別重要：承諾與一致性、社會認同，以及稀有性。

心理學家發現，賭馬者一旦下注，就馬上變得比下注前更有信心，認為他們所押注的馬匹會勝出。 $ ^{10} $ 做出決策之後，我們就開始面對內在與外在的壓力，即使後來出現的證據動搖了原初決策的正確性，我們都必須盡可能維持一貫立場。

因此，當投資者對某支股票抱持特定看法，並且公開推薦或怂恿同事跟進，他就會覺得自己有必要始終維持一貫看法。這樣的傾向讓人跌入「確認陷阱」（confirmation trap）——做出決策之後，開放接受有利證據，同時否定或拒絕不利證據。要減輕對一致性的執著，其中一個有效的方法就是將世界視為各種有其相應機率的值域（ranges of values），而非絕對的單點。若能設想多樣的事態情境，就能為我們提供心理庇護，在必要時刻改變想法。
