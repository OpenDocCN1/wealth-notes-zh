希臘人把許多發音簡化成少數幾個字母，為今天大部分西方語言所使用的 26 字羅馬字母奠下基礎。我們可以組合這些文字來代表幾乎所有概念。這套字母幫助人類大幅提升識字率，進而改善了生活水平。

然而，就在二戰前夕，另一種語言開始崭露頭角——那是一套 1 和 0 的語言。二元或數位語言可以給任何資訊進行編碼——從文字、音樂，到人類的基因地圖都不例外（見圖表 18.7）。

因為數位語言很簡單，我們可以讓編碼、傳輸及解碼的程序變得更快速；同時維持理想的資訊保真度，而且易於保存。圖表 18.8 顯示資訊生產在 1999 年至 2002 年所經歷的變化；磁場與光學儲存媒介的大幅增加值得關注。

這一切對創新有什麼意義？因為數位語言的靈活性，我們擁有比過去任何時代更強大的能力去辨識與操作概念構件。加上概念構件儲量的成長，結果就是創新步調的急速前進。以醫療衛生為例，一旦科學家結合了數位化科技與生物學知識（基因地圖），加上日漸提升的電腦運算能力，這個領域很可能經歷全面性的變革。
