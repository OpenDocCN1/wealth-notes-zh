# 為什麼斑馬不會得胃潰瘍

斑馬的壓力清單裡的前幾項會是什麼呢？斑馬當然會擔心身體的危害。你剛剛才被一隻獅子攻擊，你逃脫了，但是獅子現在仍追著你，要把你當成牠的午餐。演化讓斑馬得以有效回應這一類危機；其他動物，包括人類也一樣。

現在，列出你的壓力清單——大概跟斑馬的清單不太一樣。在大部分情況下，我們擔憂的不是身體的事，而是心理方面的事，比如工作期限、投資組合中某支股票上星期的走勢、你的人際關係。人類主要面對的是心理與社會方面的壓力。
