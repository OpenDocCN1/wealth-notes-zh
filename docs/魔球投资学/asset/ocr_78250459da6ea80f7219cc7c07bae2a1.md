# # 29 從蜂巢到錢潮
### 集體的智慧與異想

蜂巢最發人深省的特徵在於成千上萬的蜜蜂能夠在沒有中央管控權力的情況下達成協作。

蜂巢的一致性取決於分散式控制的機制，進而引發天擇；這過程類似於創造大自然規律，也類似創造人類競爭性的市場經濟體制。

——湯瑪士·西利（Thomas Seeley），《蜂巢的智慧》
*（The Wisdom of the Hive）*

預測市場（Decision markets）將各個不同的個體所知的資訊匯合成共同資源；而且相較於規範的資訊聚合體制如新聞媒體、同儕審查、審訊與民意調查，預測市場擁有許多優勢。這個投機性市場是去中心化的，而且相對平等，對於我們所提出的問題可提供更直接、簡明、即時且精確的預測。

——羅賓·漢森（Robin D. Hanson），《預測市場》
*（Decision Markets）*
