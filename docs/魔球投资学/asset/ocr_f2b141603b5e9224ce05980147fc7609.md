# 14 小心行為財務學

# ——誤用行為財務學可得出荒謬結論

個體行動的優化往往是為了產生競爭均衡（competitive equilibria）；然而，真實的經濟體系要達致近乎均衡的狀態，個體優化是非必要的。人類無法在複雜任務中優化行為，我們不需要因此而推斷源自競爭模型的均衡概念不適用於此。我們證明了，在複雜經濟系統裡，即使對個體行為做出種種極其薄弱的假設，系統仍然可以達致這樣的均衡。

——安東尼．博希－多明尼克（Antoni Bosch-Domenech）
和希亞．姆桑德（Shyam Sunder），
〈追蹤隱形的手〉（Tracking the Invisible Hand）

經濟學怎麼可能無關行為呢？如果不是行為學，那會是什麼鬼東西？

——查理．蒙格，《誤判心理學》
（Psychology of Misjudgment）
