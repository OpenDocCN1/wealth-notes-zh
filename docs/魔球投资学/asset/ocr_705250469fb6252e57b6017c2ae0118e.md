# # 9  窺探高層內幕
——管理評估與投資過程

在我們的年度股東大會中，有人常會這樣問：
「如果你被卡車撞了，這裡怎麼辦？」他們還會這麼問，我很高興。不用太久，這問題就會變成：「如果你沒有被卡車撞，這裡怎麼辦？」
——華倫·巴菲特，1993 年致股東信函¹

第五級領導把自我需求從個人轉移到創建卓越公司的遠大目標。這並不是說第五級領導沒有自我或個人利益。實際上，他們的野心抱負異乎尋常——但是在他們的抱負之中擺在前面的是組織，而非自己。
——吉姆·柯林斯（Jim Collins），
《從 A 到 A+》（Good to Great）²
