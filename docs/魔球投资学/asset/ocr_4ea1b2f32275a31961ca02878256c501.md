# ## 前言

2003 年 8 月美國東岸大停電之後，我打了電話給我的朋友鄧肯·華茲（Duncan Watts），他當時是哥倫比亞大學的社會學教授。我向他拋出一連串有關大停電的問題：可能的成因為何、災難如何進展，以及我們可能以什麼方法防止未來再次出現此類災難。

你可能會問，為什麼我會打給一位社會學教授詢問有關大停電的事？華茲是理論與應用力學博士，是網絡理論的全球權威之一。他只是湊巧在一個社會科學的學系裡發揮所長，但是他確實擅長於跨越自然科學和社會科學兩大領域。在我們無所不聊的討論當中，他提出了大停電事件、哈利波特的成功、股市榮景，以及流感疫情等現象的共通之處。

在一般大學校園裡，「硬科學」（hard science）和社會科學的系所通常位於不同的大樓裡，但實際上這兩者之間的距離在於其哲學，而非物理位置。近年來，許多科學家如鄧肯·華茲為世人展現了跨學科思維的價值。理解金融市場時，我們也納入了物理學家、心理學家，以及複雜理論學家的見解。
