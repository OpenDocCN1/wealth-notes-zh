# 螞蟻的腦袋

2000 年秋天，我聚集了一小群領導業界的投資者，一起聆聽多位來自金融、策略以及商業領域的傑出人物發表他們的演說。所有演講者都極為精彩，但仍然稱不上是最令人振奮的演說——「最令人振奮的演說」這頂殊榮後來歸於洛斯阿拉莫斯國家實驗室（Los Alamos National Laboratory）的科學家諾曼·強森（Norman Johnson）。強森劈頭便以似乎預示著不祥的語氣說了這段話：「我被邀請在這裡談論專家到底出了什麼問題——而我可是這方面的專家；但今天的討論針對的是金融領域的專家，而這是幾乎我一無所知的領域。」$^{1}$
