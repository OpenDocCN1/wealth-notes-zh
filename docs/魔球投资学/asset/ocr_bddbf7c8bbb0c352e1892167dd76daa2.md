4. 大多數產業經歷可辨識的生命週期：產業在早期階段通常大幅成長，眾多公司進入市場；隨後，顯著數量的公司退場，生存者享有高經濟報酬；最後，成長逐漸減速。到了成熟階段，企業成長率和經濟報酬率已減弱至接近競爭均衡的狀態。大型公司通常也是成熟企業。

為那些處於成長停滯期的企業提供諮詢，這項服務本身即成了一個產業。基於種種原因，大公司確實不如小型公司那樣易於投入創新，我極力推薦克雷頓·克里斯汀生（Clayton Christensen）和邁可·雷諾（Michael Raynor）的著作《創新者的解答》（The Innovator's Solution）10，這本書為管理者提供有效的創新框架。然而，事實是：不是所有公司都能永遠迅速成長。

# 外推性預期
