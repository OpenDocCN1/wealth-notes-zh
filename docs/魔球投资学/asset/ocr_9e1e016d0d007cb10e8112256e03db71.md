# 非定態性與歷史本益比

非定態性（nonstationarity）是時間序列分析的關鍵概念，在氣候學和金融學等領域尤其重要；也就是說，母體的統計特徵必須維持相同或靜止不變，不同時期的平均值才能相互比較。如果母體的特徵隨著時間而改變，數據就不再處於定態；這時候把歷史平均值套用到當前的母體，可能會得到誤導性的結論。

本益比的理論性與經驗性分析都說明了這個數據並非定態。² 實際上，研究顯示在過去 125 年以來，每個年度開始時的本益比跟後續十二個月或二十四個月的報酬率都不存在顯著的統計相關。³ 說得更直接一些，若要衡量特定投資期的市場報酬率，本益比的歷史平均值對投資者而言幾乎沒有任何引導作用。

本益比很可能不是靜止恆固的，認知到這一點非常重要；然而，了解本益比為何不是靜止不變，則可以帶來更實際的洞見。本益比的非定態性源於三大驅力：稅賦與通貨膨脹、經濟體系的組成變化，以及股權風險溢酬的改變。

# 為什麼過去不一定是序章？⁴

金融學的基本原則是：投資者為標的定價，以便扣除稅金、通貨膨脹與交易成本等因素之後取得（感知風險調整後的）適當報酬。因此，稅法的改變以及通貨膨脹率會影響市場的公允價值，進而對本益比產生實質作用。
