粗造型適應度地景裡的公司需要混合傳統的現金流量分析工具和策略選擇方案。為尋求具有價值創造潛力的商業機會，策略選擇是有利的，但也並非必要。$^{12}$ 最後，處在混亂型地景的公司必定得更依賴策略選擇來評估當前與未來可能的適應度。而且，這類公司很適合應用「簡單規則策略」法。這種去中心化的方法涵蓋已商定的決策規則，但允許現場的決策者依據當前狀況制定決策。$^{13}$

| 適應度地景 | 財務工具 | 組織結構 |
| :--- | :--- | :--- |
| 平穩型 | 現金流貼現分析 | 集中化 |
| 粗糙型 | 現金流貼現分析加上策略選擇 | 寬鬆的集中化 |
| 混亂型 | 策略選擇 | 去中心化 |

老虎伍茲的故事告訴我們：改變有時候會帶來短期陣痛，但這對長期的適應度改善是必要的。適應度地景有助於評估某家企業是否採取能夠發揮潛能的正確策略，並且具備適當的組織形態。這樣的分析也指出評估各家企業所適用的財務工具。
