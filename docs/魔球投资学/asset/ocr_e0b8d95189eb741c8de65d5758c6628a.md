善幅度最大的公司，股價表現往往顯著優於利潤惡化幅度最大的公司。這些數據顯示利潤改變的完整幅度並非全然在市場的預期之中。$^{8}$

投資者必須謹慎評估市場期望，並且嘗試確定這些期望有多大的可能性會改變。許多投資過程並沒有妥當衡量與考慮市場期望。$^{9}$

+   3. **判斷超額報酬可能持續多久**：均值回歸是作用於公司層次報酬率的強大力量。競爭讓高利潤產業的獲利縮減，而資金通常將撤離低利潤產業，讓整體利潤得以回升。確定超額報酬因競爭而削減之前還能維持多久，這是必要的評估。$^{10}$

股票市場透過不同風險偏好的估值過程，讓股東報酬趨於均衡。高利潤企業有較高的淨值比，低利潤企業的比率則較低。基於這個理由，好公司不一定是優質股。

+   4. **策略很重要**：從公司的角度來說，策略是為了展開一系列行動以產生高於資本成本的報酬。成功的策略通常會將公司置於一個獨特的位置，或許是以產品差異化生存於產業，或是以低生產成本求存。策略關乎權衡——決定做什麼、決定不做什麼。
