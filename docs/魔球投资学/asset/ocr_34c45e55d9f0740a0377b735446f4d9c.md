Sull）稱之為「簡單規則策略」（*strategy as simple rules*）$^5$ 他們認為，企業不應該採取複雜的策略，反而應該採用且固守「少數幾項直接、嚴格的規則以指明但不限制行動方向」；這在變幻無窮的市場裡尤其適用。

艾森哈特和薩爾具體提出五種規則：

+   1. 指引規則（*How-to rules*）說明企業如何執行某項程序的關鍵事項。「我們的程序有何獨特之處？」——指引規則解答了這道問題。

+   2. 畫界規則（*Boundary rules*）界定管理人應該追逐哪一些機會，而哪一些則在追求的範圍之外。

+   3. 優先規則（*Priority rules*）幫助管理人為眼前的機會排列等級。

+   4. 時機規則（*Timing rules*）讓管理人的步調跟公司其他部門的機會同步。

+   5. 退場規則（*Exit rules*）幫助管理人決定何時退出已過去的機會。

艾森哈特和薩爾認為一家公司應該制訂的規則大約介於二至七條；他們也指出年輕公司通常規則太少，而較成熟的公司則規則太多。維持會計誠信的決策規則（即避免管理的焦點脫離業務而陷入每股盈餘的數字）或許也有助於減少不當的短視作為。
