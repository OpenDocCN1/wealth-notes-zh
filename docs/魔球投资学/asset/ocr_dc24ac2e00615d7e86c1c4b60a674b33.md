# 尋找你的利基

公司尋找利基，這並不是新穎的概念。一般的競爭策略研究，或者更具體的博弈理論，都有許多面向觸及企業尋找利基市場的方法，也闡述了企業為何有此需求。這裡要傳達的主要訊息是：技術發展、法規變化、產業新進者與退場者的更替，這種種因素改變了環境，因而改變了利基市場。

想想小型工廠和綜合性鋼鐵公司的對比，或者網路零售商跟實體門市對比。新的利基被開啟，然後新公司進場占據利基。企業對環境變遷的適應能力非常關鍵——只有少數公司具備這樣的能力。

因此，特定產業的理想公司規模並非僵固不變；比較不同經濟模型之下的企業估值，也是沒有意義的。
