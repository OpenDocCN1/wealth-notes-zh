# ## 情緒急轉彎
### ——探索市場的情緒擺盪

人們堅信這場派對要結束還早得很，這是科技股持續往更高點上揚的原因之一。艾倫先生說：「我不認為有什麼事能動搖我對市場的信心。」歐克菲先生再加上一句：「即使我們下跌個30%，也會馬上恢復的。」

「不久前顯得有些乏力，」他繼續說，「那些人打給我，問我：『怎麼辦？』我告訴他們：『繼續買進。』」

——〈閒聊科技股，鱈魚角在地人的生活增添色彩〉，《華爾街日報》，2000年3月13日

「他們甚至還說「買、買、買」，而股價已經從100元跌到破產。」這位粗壯的63歲理髮師這麼說。「現在，他們給我提示，但我都盡量離他們遠遠的。任何人都不再相信任何人。」

實際上，弗林先生不再投資股票；現在他每週一都會開車到附近康乃狄克州的賭場玩廿一點和撲克。「我在那裡賺得比股票還多。」弗林先生說。

——〈在鱈魚角的理髮店，股票熱潮驟減〉，《華爾街日報》，2002年7月8日
