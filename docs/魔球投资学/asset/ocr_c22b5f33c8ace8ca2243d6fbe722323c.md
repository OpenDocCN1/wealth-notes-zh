# 結論：迎向投資領域的知識大融通

自 1993 年以來，我在哥倫比亞大學商學院教授一門稱為「證券分析」的課。正如你所料的，這門課涵蓋投資基本議題如企業估值、財務報表分析，以及競爭策略架構。然而，每一個學期的第一堂課，我都會先提醒學生：這門課提出的問題，將遠遠超過它所解答的問題。

例如，我們無法真正知道市場如何聚合資訊，也無從得知這對股價效率產生什麼意義。我們的風險概念仍然不完善，儘管我們已經知道標準的風險測量方法是錯的。大多數競爭策略架構都不會告訴你，在各種不同的情境下哪些策略會成功，哪些又會失敗。而且，關於大腦如何運作，我們顯然還有太多需要學習。

一長串未解的問題，讓投資這件事變得即讓人興奮，又讓人沮喪。覺得興奮，因為我們知道自己在未來將會得到更多知識，洞察力也會提升。感到沮喪，則是因為我們理解的還是太少，而且，即使最精明的參與者也一再地在市場裡經歷挫敗。
