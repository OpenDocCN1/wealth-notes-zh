公告盈餘依據會計原則。結果不一定總是與潛在的企業經濟一致。然而，企業的管理績效通常以會計盈餘衡量，而不是潛在的經濟價值。因此，風險管理策略直接連結至會計績效，而非經濟績效。8

獎勵指的是能夠激勵工作的措施。長線持股人期待的應該是適當的獎勵制度；然而，這在現實中是極為稀少的。

# # 資金配置

企業管理的演化之路皆導向資金配置。我如此定義資金配置：對公司資源進行分配以產生超越資本成本的長期報酬。基金管理人都知道，資金配置才是這一切的本質。

該如何評估資金配置的能力呢？第一步是仔細研究過往的資金配置選擇。管理層如何運用公司資金進行投資？資金投入何處？投資項目是否取得充分報酬？取得正向報酬的原因為何？無法回收的原因又為何？過去的資金配置方式往往提供良好指標，說明該企業資金流動的胃納，而且也揭示了管理層的焦點與偏好。
