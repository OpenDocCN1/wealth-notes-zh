# CONCLUSIONS

領域的科學家處於劣勢。但是，研究者從跨學科的協作所累積的知識，最終將為我們帶來最深刻的洞見，甚至答案，以解開企業和市場的運作機制。

至於跨學科的取徑如果幫助我們提升投資的相關知識，以下是一些扼要論點：

+   - 決策與神經科學：貫穿全書，我引用丹尼爾·康納曼和阿摩司·特沃斯基的展望理論；這套理論說明人們如何系統性地做出偏離理想的決策。展望理論催生了行為財務學的領域，研究的是商業與投資環境裡的認知與決策偏誤。

雖然展望理論已跨前了一大步，但仍然無法揭示人們為何一再做出那樣的決定。如今，神經科學的進步讓科學家得以窺探受試者的大腦，瞥見人們做決策的瞬間所發生的巧妙機制。經濟學家柯林·坎麥爾（Colin Camerer）將神經科學開啟的視角比擬成1950年代整棟大樓第一戶擁有電視機的人家——畫面或許模糊，你可能還需要調整兔耳天線才能看到，但是，新得到的影像和見解讓人興奮莫名。隨時間推移，影像只會變得越來越好。
