投資就根本而言是一種機率操作。每一天，投資者都必須把投資機會轉譯成機率——實際上，這是投資的基本功。所以，我們必須仔細思考如何在各種不同的情境中估算機率，並且指認出可能的陷阱藏在何處。

# 從不確定性到機率

蓋格瑞澤在他的著作《計畫風險》（*Calculated Risks*）中說明了三種得出機率的方式。以下歸納出這三個方式，具體程度從最低至最高排序；這樣的闡述能幫助投資者為各種機率陳述做分類：

+   信念度：信念度是主觀機率，也是將不確定性轉譯成機率的最寬鬆方式。這裡要指出的是，即使是一次性事件，投資者也可將之轉譯成機率，前提是這些事件符合機率法則——即所有互斥及周延事件的機率總和為 1。再者，投資者得到新的相關資訊之後，這種以信念度為基礎的機率可時時被更新。

+   傾向性：以傾向性為基礎的機率反映的是某個事物或系統的特質。例如，如果骰子對稱且平均的，則得到任何一面的機率為六分之一。DASA 和 NASA 的風險評估也是基於傾向性的。這種機率評估的方式不一定會考慮所有可能形塑結果的因素（如火箭發射中的人為失誤）。
