# # 市場裡的從眾行為

在投資哲學中明確引證正向回饋作用的投資者當中，最突出的當屬喬治·索羅斯（George Soros）。索羅斯的反射（reflexivity）理論認為股價跟公司基本面之間存在正向回饋，而這樣的回饋可能導致股價暴漲或崩跌。索羅斯的策略在於趁著這類趨勢買進或放空而獲利。

金融學文獻也揭示了投資者之中有不少的從眾行為實例：

+   1. 共同基金：羅斯·溫默（Russ Wermers）證明了共同基金也存在從眾行為，尤其是小型股與成長型基金。他發現，群眾買進的股票在後續六個月的績效比群眾賣出的股票高出 4%。

+   2. 分析師：伊沃·韋爾奇（Ivo Welch）指出，賣方分析師所做的買進或賣出建議，會對後來執行評估的兩位分析師產生顯著的正面影響。分析師在提出建議之前總會先環顧左右。

+   3. 肥尾（Fat tails）：經濟物理學家（Econophysicist）利用簡單的從眾模型，複製了我們實際在市場上觀察到的肥尾分布。相較於那些把投資者行為預設為理性的模型，這類從眾模型所顯示的市場圖像更為可信。

在市場上，正向回饋與負向回饋之間的共生關係是普遍存在的。如果所有投機者都在勤動價格，平均而言他們將落入買高賣低的情境。市場會迅速剔除掉這些投機者。再者，套利者，也就是讓價格回復穩定的投機客，無疑在市場上扮演著重要角色。但
