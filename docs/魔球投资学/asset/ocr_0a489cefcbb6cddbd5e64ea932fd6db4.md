# 我也可以

《生活》(Life)雜誌曾經因為公開質疑傑克遜·波洛克（Jackson Pollock，1912-1956）為「美國在世最偉大的畫家」，在1940年代掀起一股騷動。波洛克不是那種拿著調色板做畫的典型畫家——他把顏料滴在大片畫布上，創作出獨特的抽象畫作。雖然他的一些作品叫價數百萬元，但某個質疑者說他的作品就像「那頭我忍不住要梳理的紊亂頭髮。」$^1$一些評論者則揶揄說他們只要隨便噴灑顏料，也能弄出跟波洛克作品一樣的畫作。$^2$

然而，波洛克的作品還是很吸引人。為了理解其中的美學魅力，物理學家理查·泰勒（Richard Taylor）轉向數學的世界。他發現波洛克的畫作看似任意，但其實呈現出讓人愉悅的碎形樣態。碎形是「一種可以分解成部分的幾何形狀，分解出來的部分也是整體的縮小版本」。$^3$儘管其他質疑者一昧地冷嘲熱諷，泰勒證明這些碎形不可能是隨便滴下顏料就能產生的。
