# 圖表 12.1 經驗系統與分析系統的比較

| 經驗系統 | 分析系統 |
| :--- | :--- |
| 1.全觀性 | 1.分析性 |
| 2.情感：以苦樂經驗為導向（何者感覺良好） | 2.邏輯：以理性為導向（何者合理） |
| 3.聯想式的連結 | 3.邏輯連結 |
| 4.行為因過去經驗的「氛圍」而調整 | 4.行為因自覺的事件評估而調整 |
| 5.將現實轉譯成具體圖像、隱喻與敘事 | 5.將現實轉譯成抽象符號、文字與數值 |
| 6.快速處理：導向即時行動 | 6.緩慢處理：導向延時行動 |
| 7.改變緩慢：因反覆或激烈的經驗而改變 | 7.改變迅速：一念之差即可改變 |
| 8.較粗略的分異化：粗略概化的梯度劃分；刻板思考模式 | 8.較精確的分異化 |
| 9.較粗糙的統合：分離狀況、受情感左右 | 9.較精密的統合：跨情境處理 |
| 10.被動且前意識（preconsciously）地經驗：受制於情感 | 10.主動且意識地經驗：掌控思維 |
| 11.不證自明：「經驗為實」 | 11.必須經由邏輯與證據來證實 |

來源：Epstein, “Cognitive-Experiential Self-Theory.”，經許可引用。
