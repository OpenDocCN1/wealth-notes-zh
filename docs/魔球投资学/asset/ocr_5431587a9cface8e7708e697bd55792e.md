# ## 望向下一個高峰

1997 年春天，老虎伍茲（Tiger Woods）不僅贏了威震天下的高爾夫名人賽——他甚至主導了這場賽事。賽場高手雲集，而老虎伍茲以 12 桿勝差脫穎而出。先釐清一下事件脈絡：當時伍茲參加巡迴賽還不到一年，而且只有二十一歲的稚齡。他已經參加過十五場 PGA 巡迴賽，在四場勝出。高爾夫球迷將他與傑克．尼克勞斯（Jack Nicklaus）相提並論，而尼克勞斯被譽為有史以來最優秀的高爾夫球選手。

伍茲如何看待自己的非凡成就呢？他並不認為自己的潛能已經發揮到極限。他從不鬆懈、放縱。相反的，他仔細研究他在名人賽中的錄影，最後得出驚人的結論：「我的揮桿動作有夠糟的。」¹
