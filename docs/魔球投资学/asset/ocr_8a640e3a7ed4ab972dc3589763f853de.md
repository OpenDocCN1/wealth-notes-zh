# 1. 坐上莊家的位置

——投資的過程與結果

欠缺思慮的決策可能會成功；經過縝密思考的決策卻可能因為早已確認的失敗機率實現了，所以失敗。但是，長遠來說，越縝密周全的決策將帶來越理想的整體成績；若要促進更多思考周密的決策，可以試著從決策過程的好壞來判斷決策，而不僅僅以結果論斷。

——羅伯特·魯賓（Robert Rubin），

2001 年哈佛大學畢業典禮演講

當你下了最好的賭注，也就是當勝算對你有利的時候，不管這個賭注最終是輸是贏，你都會有所得。同樣的道理，當你下了最糟的賭注，也就是當機率對你不利的時候，這樣的賭注無論最終輸贏，你都會有所失。

——大衛·斯柯蘭斯基（David Sklansky），

《撲克理論》（The Theory of Poker）
