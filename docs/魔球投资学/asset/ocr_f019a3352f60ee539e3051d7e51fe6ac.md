# 前言

雪茄不離嘴的普吉・皮爾森（Puggy Pearson）是賭界傳奇。他出身貧寒，只有八年級的學歷（他曾自嘲：「那大概相等於今天的三年級」），¹ 但創下的卻是驚人紀錄：他在 1973 年世界撲克大賽（World Series of Poker）中勝出；一度成為世界十大撞球手之一；曾經以 7000 美元的賭注擊敗一位職業高爾夫球手，而且當然是在球場上。

他是如何做到的？普吉解釋說：「賭博不就是那三件事：找到 60-40 的賭盤、把錢管理好，還有了解你自己。」他還附加了一句：「這是連笨蛋都懂的道理。」

皮爾森三件事的前兩點，關乎的是投資哲學，也是本書前一個部分的主題。然而，第三點「了解你自己」，正好落在心理學的範疇。

心理學大概是投資世界裡價值最被低估、最少被教導，也是投資者最疏於思考的面向。這是極為重要的面向，因為心理學有助於解釋你在各種情境下可能會犯的錯誤、洞察他人如何影響你的抉擇，並且幫助你開展視野，從中了解自己該如何行動。大多數傳統的商學院都無法在這些關鍵面向提供太多幫助。
