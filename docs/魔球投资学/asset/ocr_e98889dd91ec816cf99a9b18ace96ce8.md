# 34 驅逐拉普拉斯妖魔
——因果關係在市場裡的作用

我們的祖先必定會因為沒有能力控制或理解種種無原因之事而深感不安；實際上，今天我們仍然如此。因此，他們開始建構，而得出的是錯誤的知識。我認為人類進行判斷的首要目標並不是為了精準，而是為了逃離令人癱瘓的不確定性。

我們必須給自己敘述故事以建構生命的意義，這是根本的需求。我們對不確定性的厭惡，簡直到了難以忍受的程度。

——劉易斯·沃伯特（Lewis Wolpert），法拉第講座

我們的思維習慣於集中式控制、清晰的連環指令，以及直接了當的因果邏輯。然而，在大型且相互連結的系統裡，其中的參與個體終究會對其他每一個個體發揮影響力，於是我的標準思維方式潰散瓦解。簡易的圖像與言語論據顯得過於無力、過於短視。

——史蒂芬·斯托蓋茨（Steven Strogatz），
《同步》（Sync）
