# 真實世界又如何呢？

所以，集體力量已獲得證實，能夠巧妙地探求者和解答者配對起來，並且確定當前或未來狀態。那麼，這一切該如何應用到股票市場呢？

股票市場和我所描述的交易市場有所差異，因為那裡沒有答案——股票沒有確切的時限或價值。（當某家公司已同意被收購時，會出現例外狀況；這時候股票價格往往非常準確地反映企業的根本價值。）因此，股票投資者易受影響而採取模仿行為，因為他們總是可以把股票賣給另一個願意出更高價的投資者，由此賺取超額利潤。換言之，良好的資訊聚舍所必備的三大條件之一，即群體的異質性，在股票市場裡被破壞了。
