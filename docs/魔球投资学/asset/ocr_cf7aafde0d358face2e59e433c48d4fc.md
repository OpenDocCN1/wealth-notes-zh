# 神諭般的預測市場

社會性昆蟲的形態帶給我們一項啟示：整體往往大於部分的總和。然而，我們人類總是依賴各個領域的專家，包括醫學、政治、金融、公共政策等領域。專家能夠給予我們最好的答案嗎？或者，我們應該設法把許多個體的知識匯聚成集體知識？

近年來出現了許多預測市場，人們在其中為某項問題的預測下賭注，然後以預測是否成真來決定輸贏。事實證明這類預測市場異常準確，而且，就像社會性昆蟲的聚落，預測的準確性仰賴的是分散的個體智慧。

成立於 1985 年的愛荷華電子市場（Iowa Electronic Markets，IEM）是其中最著名的預測市場。5 IEM 允許人們針對選舉中個別候選人的得票率下注。這個市場的過往表現十分讓人稱羨：過去四屆美國總統選舉中，IEM 的市場價格有四分之三的時間比民意調查（近 600 項）更具有預測效力。IEM 也有其他市場供下注。6

預測市場擴散到政治領域之外。想要預測某部電影的首映週末票房收入？你可以查看好萊塢證券交易所，那裡的交易者眼光向來比電影產業的評論家更準確。這個交易所對奧斯卡金像獎的提名名單也有亮眼的預測表現，最近還讓交易者就電視選秀節目《美國偶像》(American Idol) 的明日之星下注。7
