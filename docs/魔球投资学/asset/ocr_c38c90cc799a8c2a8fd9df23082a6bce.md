# 砍掉決策樹

在近期的一篇文章裡，羅伯特．奧爾森（Robert Olsen）列出「自然任務」（naturalistic tasks）所顯示的五種特徵，並且指出這些狀態跟投資者的關係。6

+   1. **結構含混且複雜的問題**：在這類狀況下，並不存在一個最佳的問題解決程序。例如，確定證券的公允價值就是一個結構含混且複雜的問題。

+   2. **資訊不完備、不明確，且持續變動**：依賴未來財務績效的預期來選擇股票，意味著無法把所有的資訊納入考慮。

+   3. **不明確、變幻且複雜的目標**：雖然投資的長期目標非常清晰，但是其短期目標卻可能經歷顯著改變。例如，投資組合經理可能以防衛的態度保持績效，也可能採取更積極的姿態彌補虧損。

+   4. **因時間限制、高風險，或兩者同時作用下的壓力**：壓力顯然是投資的屬性之一。

+   5. **決策可能涉及多方參與者**：這意味著決策者可能必須跟不同的合作者共事，而這些參與者可能會約束決策過程。

採用自然決策的人實際上如何做決策？奧爾森確認了三種主要行為。首先，他們有能力依靠自己的心像（mental imagery）與情境思維，據以評估當下情境與可行的選項。7
