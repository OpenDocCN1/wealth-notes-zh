# **Hush Puppies 與道瓊指數的尾隨者**

1994 年，麂皮休閒鞋品牌 Hush Puppies 的銷售量在三萬雙左右。事實上，這家曾經風靡一时的製鞋公司當時正在考慮淡出市場。但是，神奇的事隨即發生：Hush Puppies 突然成為紐約曼哈頓的時髦穿著；經典鞋款銷售在 1995 年達到 43 萬雙，1996 年增至 170 萬雙。短短幾年之內，Hush Puppies 擺脫鞋類市場裡的蹩腳貨形象，躍升成為時尚行家的必買品項。¹

Hush Puppies 的故事跟股票市場有什麼關係？無論是股市或上述品牌故事，情緒（sentiment）都是市場走勢的重要決定因素。掀起 Hush Puppies 熱潮，或者讓投資者在極端樂觀和極端悲觀之間擺盪的，背後其實是完全相同的機制。

以上兩段引言來自《華爾街日報》兩篇描述一家小鎮理髮店的文章，刊登日期相隔不超過兩年半。在第一篇文章裡，理髮師對市場的信心無可撼動——他的投資組合價值七位數，到處給人出主意，而且思考著提早退休。第二篇文章裡，他對股市和投資專家的信心早已崩潰，寧願到賭場碰運氣，也不想再碰股票投資。我們對理髮師從狂熱到沮喪的轉變感同身受，因為這樣的情緒轉變也發生在許多投資專業人員身上——而我們還以為這群人會懂得多。
