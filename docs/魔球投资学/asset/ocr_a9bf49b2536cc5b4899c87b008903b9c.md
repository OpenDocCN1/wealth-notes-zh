# 體積越大，成長越緩慢（或停滯）

所有公司的規模，就像城市規模，傾向於呈現離散分布。$^{4}$科學家透過模型再現這種分布，並且從中發現平均成長率跟規模沒有關係，而成長率的變異數則隨著規模增加而下降。這即是所謂的生長錐（cone of growth）。

圖表 27.4 以圖像呈現這個概念。這裡採用的是 2600 家美國企業的十年複式年度銷售額成長率。橫軸使用對數尺度。圖表顯示大公司與小公司的平均成長率近乎相同，但是大公司出現劇烈成長或衰退的機率卻相當小。投資者往往稱這現象為大數定律，意指大公司無法像小公司般迅速成長；更精確而言，大公司的成長率不會大幅偏離平均成長率。$^{5}$
