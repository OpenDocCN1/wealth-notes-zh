# 六、见色，不趁淫生邪

爱美之心人皆有之，但乱性是对自己和他人的人格和尊严的践踏。珍惜自己的人格与尊严，基于生命。忠告：尽管风流莫下流。

# 七、待人，讲宽宏利他

水到清则无鱼，人至察则无徒。人非圣贤孰能无过，以包容的心态给别人一个机会，给他人一条路走，则可化敌为友；反其道而行之，则举目无故人。

# 八、营职，必鞠躬尽瘁

前进之时不贪名求利，不避谤抗上命的罪名。但球做事尽心尽力。在其位谋其事，尽其责。

在“红袖”第一期，顾继鹏一人讲了十天的课，每天几乎讲8个小时。讲到第7天的时候，嗓子已经不行了，加上压力大着急上火，声音越来越嘶哑，到后来几乎失声。这10天时间里，顾继鹏主要是讲企业文化，并让学员们更了解金王集团这个企业，学习阮东升董事长这种永不言败，愈挫愈奋的精神内涵。此外，还花了大量的时间给学员们讲成功学。

所谓成功学无外乎就是专门研究成功的规律，并应用于生活、工作实践的学问。

在字典中对“成功”有两种解释：1、成就功业、政绩或事业。2、获得预期的结果，达到目的。随着社会进步，经济发发展，人们的目标越来越大，创业者越来越多，生存压力也越来越大，于是成功学得以蓬勃发展，越来越多的人研究成功学，将成功学的理论与方法运用于生活、工作当中，并取得不凡的成就。

有人说“成功学”是一种状态，是总结全世界所有成功者共同的一种思维规律和行为规律；也有人说“成功学”是一门“铸造富豪”的学问，目的是帮助更多有追求的人成功致富。其实，自从拿破仑。希尔博士开创
