# 在上世纪90年代初期，阎东升所做的也并不全是养殖项目。

那时他曾看过日本著名企业家松下幸之助的一本书，书中倡导多元化经营。当时，中国的市场经济尚未成熟，几乎凡是生意都好做，市场竞争还是低层次的，并不激烈！，因此大部分商人、企业家都在多元化经营的大潮中兴奋地冲浪。阎东升自然也不例外。其实就在做“黄金屋读书社”那一年，他曾生产过一种能治疗痔疮的“神奇香烟”。当初阎东升发现这个项目，是看了《哈尔滨日报》上的一条新闻。
