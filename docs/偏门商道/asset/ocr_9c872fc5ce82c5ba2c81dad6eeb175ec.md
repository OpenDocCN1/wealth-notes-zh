# 远赴北京的“求道”之行

1809年，纯祖九年。

以礼曹判书金鲁敬为陈奏使的使臣一行，离开汉阳，前往北京。

所谓陈奏使，不同于每年定期派往中国的使节，而是一种因临时有事情要通告才加派的不定期使节。
