衣带渐宽终不悔，为伊消得人憔悴。众里寻他千百度，蓦然回首，那人却在灯火阑珊处”。

# 红埔七法

红埔人应当铭记：
只有团体的每个成员同心协力，互相配合，才能取得进步和发展。因此，当我们投身到连续不断改善团体的工作中去的时候，成员必须把这一最终目标牢牢记在心上。

# 一、客观现实

实力和利润不能成为生活中的唯一目标，首先必须为团体和社会的进步作出贡献，然后利润和发展才能成为所期待的奖赏。

# 二、公平合理

如果不执行公平合理的原则，那么任何人也不会得到自信及别人的尊重。仅凭智慧是永远也替代不了人与人之间的相互理解的，只有二者的统一才能给人以幸福和满足。

# 三、团结精神

个人的力量永远比不上团体的力量。相互依存是一种美德，相互依赖也不可或缺。只有这样，真正的和谐才能存在和发展。

# 四、事业成就

自力更生始终能培育出自尊自爱的性格，沾沾自喜从来就比不上创造的劳动，也无法替代创造的劳动。应该知道进步来自对成功的渴望和鼓身。

# 五、谦虚谨慎

每个人都应该永远记住自己卑下的起点，自高自大永远比不上谦虚谨慎
