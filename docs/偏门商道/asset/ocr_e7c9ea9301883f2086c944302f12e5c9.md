# 如

果说做“长城痔烟灵”的时候，阎东升还是多元化经营的想法使然，那么，他后来涉足的一种青少年鞋类产品的生产和营销，则完全可以说是开始了全新的实业尝试。

这一次尝试，离最后的成功几乎仅一步之遥。

上世纪90年代初，中国兴起了一股持续多年的保健品热，任何一种被赋予某种新概念的保健品一上市，就肯定能得到大家的热烈追捧，国人似乎对自己的身体和保健问题忽然间格外重视起来。

“505神功元气袋”是那个时期保健品最具代表性的“产业符号”。

那个时期几乎所有的保健品种类，阎东升都代理过，只不过相比做“放种、回收”的偏门行当而言，保健品代理挣到的那些小钱，实在无足挂齿。

直到后来阎东升自己发明并推出了一种叫做“步步高”鞋的、专门针对青少年身体增高而设计的鞋类产品。
