# 40岁前的阮东升，可以说是完全靠致富项目起家的。

致富项目是市场经济条件下出现的一种商业类别，不知道在国外是否存在，在经济正处于起飞阶段的中国，致富项目这种商业门类是随着国家的经济转型而发展起来的，不同的经济发展阶段呈现出不同的特点，直到今天仍然方兴未艾，一派繁荣，而且涵盖的范围越来越广。

与一般的商业形式所不同的是，致富项目“出售”的不仅仅是商品，而是一种致富的机会与可能。所以说致富项目的“购买者”并不是为了消费，而是生产和发展，也就是为了致富。作为发展中国家的中国，盼望发家、梦想致富的普通老百姓数以亿计，于是就不难理解致富项目为什么在中国如此有市场、如此有生命力。

在一般人眼里也许并不起眼、甚至被视为“小儿科”的致富项目，缘何在阮东升手里能变成角逐市场的利器、瞬间给他带来巨大的财富？他又缘何将自己这种的盈利模式归为“偏门”？

要回答这些问题，我们不妨对致富项目的不同操作方式作一番剖析，从而窥其中的“奥秘”。
