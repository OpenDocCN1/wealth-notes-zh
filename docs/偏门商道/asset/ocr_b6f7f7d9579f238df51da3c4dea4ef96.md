终成为这场“金钱游戏”的牺牲品。阎东升在这样一场高风险的“金钱游戏”中同样很难得以“全身而退”，如果按照合同，卖种崽获得的利润并非完全是自己的，因为这个游戏不可能一直无休止地玩下去。所以在获得这些卖种崽赚取的钱款后，就必须得赶紧再找项目去赢利，因为这些钱实际上是要返还给那些养殖户的，除非你获利后就卷款跑了或者搞“人间蒸发”，而这就构成诈骗，变成真正的经济犯罪行为，性质就不同了。而以阎东升的抱负，如此没有“技术含量”的低级获利方式从来就不曾进入过他的“法眼”，他有自己长远的事业理想，要建立的是阳光下的“商业帝国”，他需要的仅仅是快速的资本原始积累。

所以说阎东升“捅”的是“偏门”，原因就在于是。

他游走于法律的边缘地带，隐晦于灰色的商业领域，却从不让自己向下沉沦。

而操作这样的致富项目以期获取原始积累，其“命门”或说“软肋”就在于，必然受制于项目的周期，也就是说游戏不可能一直玩下去，如果到一定的环节没有新项目获利，不能很快地“钱生钱”，将部分利润返还客户（比如说按合同回收养殖户成功繁育出的动物幼崽），那么，整个游戏将会 Game over，资金链条断掉，建筑于沙滩之上的“财富大厦”就要顷刻间土崩瓦解。

这就表现为，当公司拒绝按合同回收养殖户的动物幼崽后，必然会出现经济纠纷等事端，严重的甚至会诱发群体事件，于是公司就进入了危机处置阶段，开始退赔，投入人力物力进行善后处理，而手头的一些商业实业项目就再也腾不出时间和精力去打理，到最后全盘皆败，溃不成军。

这样的过程，成了一个怪圈让阎东升几度大起大落，由此就 不难理解了。

要挣脱怪圈，超越自我，他一直为此而苦苦思索，直到有一天，他彻底想通了，“大彻大悟”后便有了这本书的写作之由来。
