# 后 记

回首偏门江湖的风风雨雨，2006年，阮东升作出了人生与事业的两大决定：一是另起炉灶，彻底转型；二是投身矿业，全力以赴。

一天，阮东升将频道调至中央二套，收看他以前常看的经济信息联播。看完这档新闻节目后，是一个经济类的专题栏目，反映的是央视记者在著名的“锰三角”所看到的矿业繁荣景象。这个“锰三角”就在湘、黔、桂交界地带，锰资源储量大，易于开采。2005年的時候，赶上钢铁行业势头正猛，冶炼所必须的锰矿价格暴涨，每吨锰矿从过去的百来块钱，上升到1500元钱，这就使得许多当地人“一夜间”暴富起来，矿主一天出几百吨矿，就有数十万的收入。矿业的繁荣，让那些偏僻的乡镇满大街跑宝马奔驰，120块一盒的中华烟卖得最好，连大白菜都卖5块钱一斤。

“锰三角”的电视报道，这回让阮东升看了心里微微一动。

可是，阮东升所买的那份《21世纪经济报道》上，赫然在整个版面刊登铁矿石行情上扬的专题报道。
