# 1 1987 年对阎东升来说是很有特殊意义的一年。

那一年，幸运之神向他展露了微笑。尝过了许多创业受挫的苦涩滋味后，阎东升终于抓住了 个机遇，敏捷地纵身一跃，稳稳地坐上了开往成功的财富列车。

在阎东升的记忆里，那一定是激情四溢、充满豪情的一年。一切都是那样的风生水起，周围的一切都在发生变化，有时连自己也想象不到。

不过，在获得成功之前，上苍仍不忘记给他足够的“考验”。

离开单位的收发室后，阎东升至少尝试了几十种致富项目，不但无一成功，还折进去所有的老本，那时候几乎是身无分文了。

这种情形下，他还是如常地到处寻找项目，不轻言放弃。一次，他看上了一个聚乙烯塑料发泡技术，也就是制作海绵的工艺。当时有一个原籍哈尔滨的澳大利亚华人回国投资创业，厂子就设在哈尔滨市郊。这位后来阎东升得知他的名字叫王克强的海绵老板，对外出售的就是设备和技术，每套设备三到五万元钱不等，买了设备就附送塑料发泡技术，制造海绵。
