# 六、适应变化

变化是不可避免的。抗拒变化是目光短浅的表现。如果没有自由或应变能力，必然会在前进的道路上举步维艰，那是非常令人尴尬的。

# 七、体贴照顾

一句简单而善意的诸语是一种最大的奖赏，体谅别人能使关系亲密；赏识别人能得到尊重。因为独裁永远也代替不了体贴照顾。

# 二、位显，不以权谋私

团队利益为主、个人利益为次。事上敬谨，待下宽仁。严于律己，宽以待人，才能保持长久的利益。

# 三、受荣，不得意忘形

志不可满。荣不可极，谦虚谨慎，戒骄戒躁，得意时须早回头。弓满则折，月满则亏，得意时恃弄权威，建独立王国，分庭抗礼，古今灭亡之道。水滴石穿、绳锯木断。宠辱不惊，方显英雄本色。

天将降大任于斯人也，必先苦其心智，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为，所以动心忍性，增益其所不能。挫折是事业成就的砺石。

# 五、临财，不见利忘义

在商不言利，虚假；在商尽言利，庸俗；在商常怀兼济之心，胸襟自然广阔；言利毎有共享之念，行动自然庄重。
