# 乐观：想想一件事最好的结果

心情不好+多虑=操蛋的一天

这是不幸的铁律。

多虑的人有一种自我预言的死循环——想糟糕一面，关注容易出错的事，如果真出事了——更加强化了自己的多虑。

这种行为极其耗费精力。

今天，尝试找到一件你脑子里多虑的事，然后问自己：

我期待这个事情最好的结果是怎样的呢？尽可能多地描述细节，描述当时你的、别人的感受和评论。让自己尝试一下乐观练习。

试试看嘛——乐观点又不会怀孕。
