# —— 回顾 ——

我们用了2周时间谈论“幸福”这个话题，我们一起来回顾下：

幸福是一种基因、环境和行为三者的结合，每个个人都有幸福基因（50%），环境因素并没有我们想得那么重要（10%），幸福更多是一种幸福的行为（40%）。每个人都可以通过学习幸福的行为活得更幸福。

幸福不是幸福的知识，幸福是幸福的行为。

# 什么是真正的幸福（happiness）？

有很多很多定义——亚里士多德似乎认为，幸福就是追求有意义的生活。而与他同时代的哲学家安提西尼则认为，幸福是享乐。
