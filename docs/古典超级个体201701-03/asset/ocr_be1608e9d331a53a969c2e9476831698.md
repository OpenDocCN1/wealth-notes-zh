# 古典

我们先回顾下优势的定义：“持续地近乎完美的表现，持续地产生积极成果的能力”，所以优势的三个要素：近乎完美的表现、持续的能力、积极的成果。

优势并不许诺你——要比别人强。

这里需要区分两个概念——“优势”和“竞争优势”。优势的定义如上，竞争优势则是：“在一个竞争中，相对于其他选手的明显优势”。

优势=才干×投入，所以即使在你最优势的领域，都一定有人比你投入更多，起步更早，所以有人比你强，是天经地义的事。

那为什么还要关注自己的优势呢？
