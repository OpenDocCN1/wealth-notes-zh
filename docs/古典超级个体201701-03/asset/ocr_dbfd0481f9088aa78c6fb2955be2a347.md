# 预告｜职场中什么最浪费你的时间？19-7

用了这么长时间，才能和你聊聊接下来的这个话题——职业定位。因为“定位”不是件容易的事，而且还是个技术活。你看，虽然特劳特的《定位》理论这么火，但是这么多年来通过清晰定位让你记住的品牌，一只手都能数得过来。

《超级个体》订阅专栏从“未来职业世界的趋势”，谈到“职业发展模型”这些底层逻辑，然后是“自我效能的提升”、“优势管理”、“价值观”……谈了这么多，做了这么多铺垫，“职业定位”的出场才显得顺理成章。

就像我们在专栏开篇讲到的“车日路模型”：理解和管好自己，才知“车”（自己）；有价值观、视野，才知“日”（目标）；然后才是思考如何到达的“路”（过程）。

你发现没有，许多人会特别认真地规划自己下班后2小时的学习时间，却对上班8小时熟视无睹——不清楚除了薪酬，为什么要做这份工作，以及这份工作有没有为自己的未来增值？

其实，最大的时间管理，是方向上的管理。与伟大同行，就抓住了⼀次重新设计人生的机会。而这些都与“职业定位”的话题有关。

下周我们将讨论3种帮自己定位的方法——从小到大，从初级赛道到高级赛道：

+   在⼀家公司里，如何确定自己合适的位 置？
在快速变化的行业里，怎样找到自己的定 位？
如果想转行，什么是切⼊一个行业的好时 机？
