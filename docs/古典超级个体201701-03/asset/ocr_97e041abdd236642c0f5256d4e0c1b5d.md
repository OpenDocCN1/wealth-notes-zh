周二的留言前所未有的充满羡慕嫉妒恨，留言里第一次充满各种醋味——我过得不好无所谓，关键是知道了你们还过得那么好，这就很不好了。

很多管理者问“我该如何提供好的福利”，也有很多人问“上哪儿能找到这么好的企业啊”。话分两头，各表一枝。我整理了一下留言，收集了5种企业能提供给员工的有趣福利，也提供了5个企业福利识别器。

# 弹性上班：

+   - 平时弹性上班时间
- 在节假日，如果没有很重要的事，可提前半天走
- 过节算好什么时候买车票，提前告知上下班时间

# 节日问候：

+   - 儿童节，送儿童摄影写真券
- 圣诞节，节日布置
- 三八节，全体女员工一起学习烘焙
- 生日時，送礼品
- 过节时，给老人红包

年底，公司给员工父母写一封信，加一个红包，请员工带回家或邮寄过去。谈谈这一年孩子在公司的成长，公司的背景以及孩子的表现——在外地的父母亲很希望知道我们的状况，而我们回家往往又不愿意说，这个设计非常暖心。别问我怎么知道的——我们新精英坚持8年了。

# 偶尔给员工创造点精心时刻：

公司在2016年组织的一场千人豪华游轮之旅，让我至今念念不忘，大海，冲浪，攀岩，表演，美食，新奇，刺激，快乐，疯狂……真是刘姥姥进了大观园，体验了一回狙的。

# 心想事成专案——满足绩效好的员工的个性化需求

年初抛}[出35年个性化愿望，包括员工发展类、即时满足类，还加进了一对一职业辅导、与高管聚餐等。员工发展类是让有潜力的员工尽早跳到管理层视线，可以提供助力加速成长；即时满足类，让员工更多注意家人亲情，稳固员工大后方。

# 阿里招聘文化：

2016年最大的感受是总裁室的老大人纷纷亲自招聘海报，玩各种花样做宣传，贴在公司所有人多地方，只为了让员工内推，内推的奖励还十分丰厚。同时各部门还经常出各种招聘的H5引导大家在朋友圈扩散。这跟老师讲的“招聘营销化”趋势是一致的。
