# 学关羽之前，先让自己“稀缺”

刘哲敏：在学习本周三内容（《想优雅地离职？学关羽 18-3》）之前，首先要搞清楚你有没有像关公那么“稀缺”。比如，一个普通保安想要辞职，需要什么时机、理由、对象吗？没必要。所以，先收收心，赶紧让自己成为“超级个体”，变成“稀缺型人才”，然后再潇洒地学关公辞职。

古典

> 点评：个人求职的4P 是产品（实力）、价格（工资）、渠道（求职路径）、推广（个人营销），其中还是实力最重要。

# 非常好的入行攻略

施辉波:无论你有多少能力和经验，到一个新公司，尤其是一个新的行业，都得从跟随者开始。一个业务成熟的公司，要在市场招人，有两种可能，一是业务发展需要增加基层员工，二是一定有一块难啃的骨头在等着你。所以公司通过你的简历找到你，要么不可能是要职，要么不可能容易拿高薪。

+   1. 你到了新公司，一般依然要接受一定的时间考验才会:`~`被委以重任。那么，有没有更好的策略？
2. 去创业公司。通常创业公司很缺乏有经验的人，可能待遇不会高——创业公司穷啊，但职位任你挑，一旦做起来，你就成功了。
3. 自带资源。与新公司协作，比如人脉圈、客户资源，这样你才有谈判的条件。
4. 熟人介绍。有熟人在中间搭线，就会增加新公司对你的信任。
5. 如果以上三个条件都不具备，没熟人没资源没有适合的创业公司，那么把新公司当作一个协作对象，而不是雇佣关系。你还可以通过这个平台开发几个协作对象，但最好几个协作对象可以不冲突（可以同一时间做一件事，获得几种结果）。

不管什么策略，在求职的过程中自我营销能力（能力的萃取）是核心。

古典

> 点评：一般公司都会做“注地空降”，外来人员会被空降到相对低的职位，让他自己靠实力爬到期望中的职位。所以要准备好打一场硬仗。
