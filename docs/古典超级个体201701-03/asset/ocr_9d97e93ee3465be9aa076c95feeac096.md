# 一定要看｜我想讲的，都在这个故事里 19-6

周六，我第一次尝试在这个时间发出一些特别好的文字。

不是我的原创，我也无力转述，也不是为了偷懒，仅仅仅是因为我非常非常期待你能读到这些文章，我相信这比再学个什么知识多多了。
