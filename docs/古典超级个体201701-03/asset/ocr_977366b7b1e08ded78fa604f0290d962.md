# 2.改变计时方式

改变计时方式会改变我们对于未来远近的认知。Lewis Jr.与Oyserman（2015）的研究发现，以“天”作为时间计算单位会比以“月”或“年”更让人感到时间上的紧迫，也更愿意尽早做出努力。这可能也是高考倒计时总是使用“100天”而不是“3个月”的原因。
