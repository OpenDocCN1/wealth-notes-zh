# 预告 | 知识怎么“管”，才更值钱？
21-7

![](bbox=[0.09, 0.44, 0.15, 0.49])

这周我们分享的主题是“学习”。简单来讲，我们一起解决了“学什么”和“怎么学”两个大问题。知识大爆炸的时代，知识快速迭代，“学海”更加“无涯”——我们必须学会更有目的性和更有效率。

成长就是解决一个接一个的问题，就像游戏里的打怪升级。这周我们讲的是对内“输入”的事情，但是，当“输入”积累到一定程度之后，你又将面临一个新问题——知识管理。

学了很多，但是脑袋里的知识，就像堆满文件夹的电脑桌面一样，混乱不堪、无从调取，怎么办？

怎样让学到的知识条理化、系统化？

有没有学了就不会忘的秘诀？

“知识变现”对于普通人来说，是不是都是“别人家的故事”，可望不可即？

这都是我们下周将要讨论的问题。

欢迎在留言区写下你对这个话题的理解：

+   1. 你平时是怎么管理自己的知识的？其中你最大的困扰是什么？
2. 你有没有把学到的知识经常跟朋友分享？分享的都是哪类知识？
3. 你身边有没有“知识变现”的朋友？他们是怎么做到的？

下周见。
