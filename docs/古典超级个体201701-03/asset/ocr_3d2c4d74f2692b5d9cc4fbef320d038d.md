# 关于独立思考的“思考”

听说有‘早老师’的且抢，听说古典老师的强大力量，才更加明白，为什么古典老师把卓老板请来做本周的嘉宾。古典老师为卓老板做嘉宾主持，也就不难理解了。

对独立思考的接触，得益于万维钢老师的《万万没想到：用理工科思维理解世界》一书。之后，顺藤摸瓜，看了不少关于批判性思维、理性思考方面的书。慢慢地，我走进了古典老师所说的误区，“怀疑一切”。直到有一天，爱人对我说，“不喜欢你这样。看到啥都是一番批判。”我才猛然醒悟，我已经陷得太深了，学习、思考是为了给工作生活提供帮助，而不能为了批判而批判，成了彰显自己‘特立独行’的表演舞台。于是，我开始区别对待。一些无关紧要的东西，错了就错了吧，还能图个乐呵。与朋友就热点问题交流时，适当的时机，给出自己的观点，如果不被接受，也就不再辩解和争执。但牵扯到个人的成长方面，不管别人怎么看、怎么说，我选择执拗地坚持做下去，行动是最有力的语言。
