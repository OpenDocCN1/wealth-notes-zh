# 我半路进入，怎么高效跟上？

这个提问理性多了——对于半路进入的小伙伴，有下面几个方法让你效率更高：

# 1. 搜索式

周一谈“认知效率”提到，最高认知效率是停留在“有困惑能实践，而且难度适中”的区间。所以建议你找到自己最大的痛点，然后在过去20周专栏中寻找到对应的主题去阅读。先解决这个问题，然后才是跟着大部队进度——先学最有用的，处理好自己的焦虑，否则讲了你也记不住。

# 2. 先跟后带式

如果没有明确的痛点，只是希望跟随大家一起升级。建议你先跟随现在这个进度。我和所有的专栏作者，在设计内容的时候都考虑到了一个“难度梯度”的问题。和培训产品不同，专栏主题间的关联性不高，难度也不是高低关系——《超级个体》专栏是一个你随时翻开某一页就能学到东西的书。你不妨先从最热闹的地方一起往前走，能跟上讨论、践行和答疑——这会让你认知效率更高。

如果确实时间不多，就这样跟到十月份，然后反过来看第一篇，也不会觉得突兀。

要记得，要和自己比，不是和其他订阅者比。

# 3. 往返跑式

如果你有充足的时间，不妨尝试往返跑的方式。专栏作者一般会把类似的主题放在一起。比如卓老师前段时间大开脑洞的大脑专题，吴军老师这段时间的金融投资专题，我们21周的学习专题……你可以先从当前主题开始，然后往返跑。

+   21周-19周
22周-18周
……

这样能很大程度涵盖一个主题。而且在第40周的时候，你发现自己也学完了前面的进度。你可以以周为单位，也可以以左边的大模块，以模块为单位往返跑。

切忌刚进来一顿猛看，看吐了又丢掉——最忌一曝十寒，不如慢慢往返。

# 怎样聪明的学习一个专栏？

再说一次——如果你是个懂得学习的人，你就能意会——《超级个体》专栏，是一个设计精巧的学习系统。我在本周三谈到了一个“学习金字塔”，里面谈到了学习方式与记忆效果之间的关系，如下。

![](bbox=[0.14, 0.005, 0.88, 0.007])

重要的知识就不是在书上，而在圈子里的人口口相传中。想获得更多隐性知识，不妨“费曼技巧”——教别人来学。

根据不同的认知效率，可以分成三个不同的难度的学习方式。

# 初级学习者：学习者（5%学习效率）

+   订了很少看
先打开音频，快速地听一遍
初级学习者追求的是“看完”。

# 中级学习者：践行者（30%学习效率）

+   回顾：重要的、没有完全理解的内容，打开文字图文再看一遍。
动脑子：每日回顾的时候，不仅仅在脑子里回答问题，而且写下来几个关键词。这么一写，发现自己其实不太懂。
留言：坚持留言。留言并不是为了上墙——而是一种记录和复习的方式。哪怕就是重点被抄写一遍，也会更加记忆深刻。
复习：把成长卡存为图片，收藏在手机某个文件夹，通过翻看重复记忆。
中级学习者关注的是“记住”。

# 高级学习者：传播者（80%学习效率）

+   讨论：刷下讨论区，看看其他人的思路和观点，并在“超级共同体”学习小组讨论勾搭高手
践行：实际践行文中的工具，并有自己的观点和思路。
分享：利用成长卡为工具。用费曼技巧给周围的人讲讲内容，用公众号、博客、简书等方式，传播文中的内容，并注明出处。
高级学习者关注的是“会用”。自己用能创造效益，教会别人能创造影响力。

同时，我也提供了不同的素材给初中高级选手：

# 初级：

听音频，我的声音还不错，但普通话极差，普通话甲等考生不要订阅。

# 中级：

+   看文字，听音频；（《超级个体》的文字、音频对应率是最好的，并不仅仅是笔记）
良好的文件名检索系统；（每篇文章都有标题号，方便检索，有整体知识地图）
每天都有成长卡，方便存在一个文档，然后翻出来复习。

# 高级：

+   精选的评论区；
每天的每日践行任务；
用成长卡来教人——多炫。

在希腊神话中，西西弗斯不断将巨石推向山顶，但是每一次巨石都会从山顶滚落，让他不得不从头推起……如此往复、永无止境。在诸神看来——重复而无效的努力是对一个人最大的惩罚。

嗯，有时候我看很多人学习也是这样。

所以方法论、方向感很重要，很重要，再多说也不为过。

学好一个专栏，就是这样。
