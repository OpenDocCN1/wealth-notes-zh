# 众筹 | 你做的每件事，都是你的名片 18-6

Hi，入市有风险，跳槽需谨慎，欢迎来到本周的《超级个体》跳槽专题！

周三，我在专栏发起了一个“故事众筹”活动，请大家分享自己知道的“跳槽故事”。这两天收到很多留言，有人回忆莽撞岁月，有人讲述华丽转身……其实，所有经历都是化了祝福的：当一个人开始总结并付诸行动时，就已经走在人生精进的路上了。

今天和你分享其中4个故事和它们背后的道理。

# 一、跳槽后，你吐槽前东家了吗？

不少人在跳槽之后，都会开启吐槽模式。这是特别值得警惕的一种倾向。就像下边这位——

六梭雪：曾经有一个同事，他在考上研究生之后离职，此后每天都更新一篇文章，用连续一周的时间各种吐槽学校：从人到事，从校领导到系领导，再到同事，所有和他共事过的人或者他稍微接触过的人都榜上有名……有的同事说，这人研究生的日子也不会好过，毕竟大家都还在一个圈子里。

这除了给智宣泄情绪之外，只会向别人说明：你不但当时决策错误，而且现在还不愿意为自己的错误负责——不能担责，是不成熟的表现。另外，还无形中得罪一大票人。

值得一提的是，故事中这位连吐槽都能“日更”？！这么勤奋干点别的什么不好吗？

都说“分手见人品”，还真是一——

纳修：我同事离职前就抢了属于组内其他同事的课题，接到高薪水的offer后，马上撂挑子辞职，连交接的资料都没好好整理，搞得接手的同事要重新开展工作。后来她还找人抱怨说大家针对她，害她辞职——现在没人愿意和她再联系。

如果让前同事们描述故事中的这位换工作的朋友，他们大概会用到“自私”、“不靠谱”这些吧。如果有机会，你会和她合作吗？

这也是为什么有的人路会越走越宽，而有些人则恰恰相反。其实，有一种跳槽，叫“好聚好散”。比如，下边ora的故事：坦诚沟通、理由充分、心怀感恩……都是她做得特别好的对方，值得我们学习、借鉴。

ora：跳槽前，趁公司领导来的时候，准备先要告诉他这件事，再写邮件给HR。我们两人坐 Glock 办公室里，他突然变得不像平时那么严肃，笑着问我：你不是被竞争对手拐走了吧？我当时恰好也是收到竞争对手的offer，心想，呀，这下坏了。很巧的是，竞争对手给了我homebase（在家工作）的位子，我当时正好也考上了MBA，于是坦诚告诉他：这份工作对我目前要上学的情况更适合。本来心有忐忑的我却得到他的赏识说当初没看错你，果然没让他失望……后来出于尊重和感激，我一直和这位领导保持联系。在我跳槽到目前的这家公司时，他还亲笔为我写了推荐信。在这件事中，我的心态变化挺大的，之前面对离职，心里总是很害怕。其实，面对面的沟通比写邮件强很多倍。另外，我和之前的同事们也保持着良好的合作关系。前公司也变成了我的客户呢。

# 二、其实，你还可以为自己“背书”

我曾说“80%的好工作都不在招聘网站上”，并提到被“信任的人背书”在换工作时起到的作用。其实，在这个“人人都是自媒体”的时代，不用等别人，你自己就可以为自己“背书”——你在网络上留下的每一条痕迹，拼凑在一起就是你的形象。

比如，下边这位，她发了条微博，就换了份工作。

Vikki(Φ e p υ з a)：六年前我MBA毕业，当时在一家公司工作。那个时候还没有微信，大家都在玩微博。五 Mø 期，我还在忙工作，于是就发微博说，劳动节就是在努力的劳动，为了接待几个英国人， 前期要学会那些专业术语……结果，就被一个人私信，问我做什么工作，问我是否知道XX公司，并告诉我说是这家龙头企业的National的部门经理，现在需要招聘一位BD，如果我有兴趣可以给他发简历看一下……后来，我顺利地进入这家公司并一直工作至今。在微博上跟我搭讪的人，就是我现在的领导。

我领导说，当时他关注微博的几个关键词：南开大学、天津大学、MBA，放假时间忙工作，还很乐观，所以他就想跟我聊聊。我觉得这就像是一种机缘，用“功不唐捐”来形容再合适不过了。

Vikki找到新工作，当然不只是因为发发微博那么简单，从文中我们也可以看出，她本身就很优秀而且懂得努力。新媒体的意义在于，它可以帮助你在更多人面前展示你的优秀。

读过这些故事，你有没有这种感觉？我们所做的每一件事，都是自己的名片。你曾经的公司、同事，包括你自己都可以为你的未来“背书”。所以，每一个环节值得你认真对待。
