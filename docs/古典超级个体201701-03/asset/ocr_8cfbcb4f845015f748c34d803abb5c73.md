# 特约成长导师：成甲

2017年开年，在个人成长学习圈里，一本新书《好好学习：个人知识管理精进指南》被争相传阅，上市20天销量突破4万册，豆瓣评分一直经8.5分以上，稳居各大图书网站畅销榜前列。

这本书的作者是我的朋友成甲，他也是“得到”App“每天听本书”栏目的说书人。成甲总是满怀热忱地分享他的观点：知识和知识是不一样的，少数知识拥有更大的威力。如果我们没有掌握正确的学习方法，就很可能陷入低水平的勤奋陷阱里。

“得到”CEO脱不花在给《好好学习》的推荐序中说：“成甲是一个掌握了高级学习方法的人。”在我看来，他更是一个把学习方法用到生活中改变自己命运的实践者。他依靠自己的学习方法，不仅每年阅读将近200本书，还在“得到”开设说书节目，转过身写的第一本书就立刻成为畅销书，此外他还维护着一个公众号，经营着一家为景区提供咨询服务、规划设计的公司——也是靠知识赚钱。

对于学习而言，成甲有着特别深入的体察和系统思考与实践。所以，我邀请他做本月的“特约成长导师”。如果你关于“学习”有任何问题，欢迎在留言区提出。成甲老师将选择最有代表性的一个在周末回答。
