# —— 讲在后面 ——

古典

一直以来，我都有个担心——超级个体作为一档个人成长专栏，是帮助个体更好地处理了焦虑，还是带来了更多新的焦虑？恰当的焦虑是我们开始思考一事情的动力，但是一旦过度，就会感觉自己四处着火，哪哪不行，学习的效果就恰得其反了。

所以我一直希望大家践行——小点的是留言评论、中间的是自己去做，更大点的是自己开个群去分享一遍。

一方面，行动已经被证明是降低焦虑最好的方法。另一方面，所有的策略都像一个梯子，如果光看不爬几步，永远不会有提升。你也永远够不着更高的梯子。

所以接下来一周，我会做一个尝试，让专栏的形式更加结构化、信息更精华和更便于学习和践行。

周一、周二、周三主要还是介绍一个专题，最后加一个提问式的回顾。

周四是互动讨论：我们会回答和讨论一些留言中的提问，澄清一些问题。比如本周就是“刻意练习和优势理论哪个更正确”。

周五是精华串讲。一周的知识点，我会重新串联起来讲一遍，加上音频，加深理解。

周六是扩展学习，也许是成长导师的“成长加餐”，也许是我精选出来的“扩展阅读”，比如书籍、文章、视频或者课程；也许是“知识众筹”或者学员自己投稿的“超级践行故事”（微博投稿 @古典 @得到，或者来邮箱投稿：cjgttg@163.com）。

周日是预告和发奖的环节，也会预告一下，下周讲什么。

《超级个体》是一个持续进化的专栏。希望可以更好地帮助你成长——也正是因为你，我们共同变得更好了。

说好了的，一起成长，长成为自己的样子！
