# 预告 | 如何练就独立思考的能力？ 22-7

我们用两周时间，分享了学习之道和知识管理的内容：搞清楚“学什么”，“怎么学”，以及“什么才是最有效知识管理方法”等底层逻辑和方法论，将帮你快速迭代知识系统，成为这个时代合格的学习者。

但是，只有这些还不够。必须加上“独立思考”，才能形成一个完整的认知链条。

现在，我们每时每刻都在接收大量的讯息，自觉不自觉地做出N种选择。——有的选择无关痛痒，有的却可能对你的生活产生深远影响。这背后的决定因素，是思考能力、认知水平的高低，而与知识的多寡不成正比。

围攻XX超市就是爱国吗？

日本福岛核泄漏会不会影响中国的食品安全？

“淘宝不死，中国经济不振”，有没有道理？

逃离北上广的“例假式”热点，每隔一段时间就会来一次，在老家与大城市之间，你会如何选择？

也许你发现各方观点都好有道理，“公说公有理婆说婆有理”。于是，对内，你茫然无措；对外，被各种“忽悠”拐跑。

那么，什么是独立思考？

常见的强盗逻辑和认知偏差有哪些？

为什么独立思考很难，但依然值得你去学习？
