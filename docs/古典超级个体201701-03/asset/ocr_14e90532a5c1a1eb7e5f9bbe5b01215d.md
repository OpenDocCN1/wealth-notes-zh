# 六、服务行业

园艺：花园中心是未来的方向

行业分析师：裴余明

所在行业：园艺师

总体态势：从2014年起，这个行业整体处于倒闭潮。

领先机构：以铁石斧斜为主列出名单：森山、康恩贝、寿仙谷。

行业热点：为政府服务的绿化苗木公司转型成个人服务的花园中心。这属于第二产业转娛乐业。在欧美地区，已经有成熟的花园中心模式。

未来机会：花园中心模式是一个经过发达国家检验的模式，以家庭园艺为生活方式的思想潮也会出现在主流媒体上。

# 七、房地产

房地产租赁：整体下行

行业分析师：阿杰

所在行业：房地产中介经纪人

总体态势：下行，2015年房地产行业非常火爆；2016年一到三季度，房价涨幅下降，行业趋于平稳；四季度，国家出台限购政策，整体态势处于下行。

领先机构：链家地产、中原地产、爱屋吉屋

未来机会：利用互联网、大数据，O2O模式经营。在国家政策引导下，房屋租赁将成为下一个增长点。

房地产行业和政策紧宻相关。

# 八、生产、加工、制造业

汽车行业：互联网带来巨大无比的挑战

行业分析师：你微笑时好美

所在行业：日系某车企

总体态势：整体稳定。生产级自动化、通用化、效率化是主要竞争手段。

行业热点：以混合动力为主的环保节能车是中长期热点。

未来机会：互联网走进我国制造业基层，如果成功将不亚于电商对于市场的作用。

工程机械制造业：AI带来巨大冲击

行业分析师：Sally

所在行业：工程机械制造业

总体态势：这个行业一直在下滑

行业热点：AI给这个行业带来的冲击非常明显。从小细节来讲，焊接机器人等早已渗透，大大减少了焊接人员；从大的方面看，行业老大三一公司早已实现通过大数据分析，远程诊断设备，根据客户实际开工的预测需求，进行研发、生产等各项管理活动。

# 九、政府、非盈利机构

政府部门：受人工智能冲击小

行业分析师：纯真

所在行业：监狱工作。监狱的主要任务是管理囚人。

总体态势：这个行业还很难受到人工智能的冲击，至少受冲击的程度应该是相对轻。

以上代表个人观点，并不一定是行业的真实大图像。

不过不同行业的发展虽然不同，但是有非常类似的曲线。

+   1. 曝光期：3D打印、VR等
热炒概念，大量资本、媒体曝光。
退潮触底，少数团队跑出，一般都是有积累和有技术的团队，如互联网金融。

+   2. 朝阳期：大数据、人工智能、互联网等
前期：战国时代结束，各种基础建设完成，开始稳定上升。大额度的资金进入，如内容创业。
中期：迅猛上升，如国外大数据行业。
后期：逐渐放缓，寻求新概念，如智能手机、AI+制造业、BIM+建筑业。

+   3. 平台期：高水准，但是发展放缓到停滞，如电力系统、银行系统。

+   4. 衰落期：开始逐渐下降衰落，如：邮政、平面媒体。

该进入什么领域？其实我觉得和养生差不多——让身体符合行业发展节气。曝光如春、朝阳如夏、平台似秋、衰落如冬。

刚毕业年轻人火力壮，建议进入朝阳前期的行业，与行业一起跑个5-8年，有巨大的能力和财富收益。

理想主义者是赤子之心，也许喜欢曝光期的无限可能。

中年人求稳，一般在朝阳后期和平台期待着。

当然，年龄不是重点，心态才是关键。
