### 3.1 集成测试常用工具

集成测试是在单元测试基础上，将各个模块按照设计要求组装起来进行的测试。其目的是检查模块间的接口、数据传递和协作是否正确。常用的工具包括：

- **JUnit**：主要用于Java平台的单元测试和集成测试，支持测试套件和参数化测试。
- **TestNG**：受JUnit启发，提供更灵活的测试配置，支持分组、依赖和并行测试。
- **Mockito**：用于模拟依赖对象，隔离外部资源，便于验证模块间交互。
- **Selenium**：用于Web应用集成测试，支持浏览器自动化，验证前后端集成。
- **Postman**：用于API集成测试，支持HTTP请求的构建、断言和自动化。

| 工具名称 | 适用领域 | 主要特点 |
|---|---|---|
| JUnit | Java | 断言、测试套件、与构建工具集成 |
| TestNG | Java | 并行执行、依赖测试 |
| Mockito | Java Mocking | 模拟对象、验证交互 |
| Selenium | Web | 浏览器自动化、多浏览器支持 |
| Postman | API | 请求脚本、环境变量、集合运行 |

> **提示**：在选择工具时，应结合项目语言、架构和测试需求，避免工具链过度复杂。

### 新阶段，在中国式现代化进程中全面推进乡村振兴

五年砥砺奋进，乡村振兴取得阶段性重大成就。党的二十大在擘画全面建成社会主义现代化强国宏伟蓝图时，提出中国式现代化的五大特征，与乡村振兴战略在内涵上紧密相连，在进程上高度匹配。

中国式现代化与乡村振兴战略具有内在统一性，主要表现在以下五个方面：

- 中国式现代化是人口规模巨大的现代化。目前我国仍有6亿人口在农村地区，即使基本实现城镇化，预计到2035年农村常住人口仍在4亿人左右。人口规模巨大的现代化主要工作就在农村。

- 中国式现代化是全体人民共同富裕的现代化。我国发展不平衡不充分问题仍然突出，城乡区域发展和收入分配差距较大。通过乡村振兴提升农业的发展效益，完善利益分配机制，确保农民实现稳定增收，是共同富裕的题中之义。

- 中国式现代化是物质文明和精神文明相协调的现代化。中国农业文明正是中华民族得以持续发展的最深厚的根基，实施乡村振兴战略，文化振兴是灵魂。

- 中国式现代化是人与自然和谐共生的现代化。习近平总书记在2022年海南考察中提出“乡村振兴要在产业生态化和生态产业化上下功夫”，即推进传统产业生态化改造、挖掘乡村生态产品价值，是人与自然和谐共生的现代化的集中体现。

- 中国式现代化是走和平发展道路的现代化。从应对全球危机角度来看，夯实粮食安全根基、维护社会稳定是和平发展的基础。

### 新主力，央地国资加快服务乡村振兴战略实施

**中央企业**

根据国家最新印发的指导性文件精神，中央企业将进一步强化组织力量、保持资金投入，在乡村产业振兴领域发挥重要引领作用。具体来说，中央企业参与乡村振兴工作主要涉及产业引领、消费帮扶和乡村建设三大领域。

从产业引领来看，中央企业将重点在粮食安全、种业振兴、农业关键核心技术和先进农机装备研发推广等领域持续精准发力，进一步发挥基金作用，促进农业农村现代化发展。从消费帮扶来看，中央企业强调充分利用市场化机制，打通脱贫地区农副产品销售渠道，增强重点帮扶地区涉农企业核心竞争力。从乡村建设来看，中央企业依托自身优势，聚焦农业产业园区开发建设帮扶工作。

**中央企业乡村振兴核心任务**

1. **产业引领**：做强农村产业帮扶，加大乡村产业投资，打造帮扶品牌，创新产业基金投资模式。

2. **消费帮扶**：参与脱贫地区农副产品流通渠道建设，提升涉农企业在品牌、营销、物流等方面的核心能力。

3. **乡村建设**：参与乡村基建投资，积极参与高标准农田、农业产业园区开发建设。

**地方国资**

工商数据显示，自2018年以来，我国新增国资背景乡村振兴或涉农政府平台企业600余家，覆盖省、市、县、乡、村五级政府。地方国资有望成为乡村振兴的“第二生力军”。

从组建方式来看，省、市两级新设平台公司主要以本级优质政府平台公司为基础，整合域内重要涉农资产重组而成；村级新设平台公司则以“县级国资+村集体”或村党组织独资、控股形式成立村投公司。

从平台定位来看，省、市级平台公司在资源整合和资本运作方面更具备优势，注重在省内综合涉农服务平台的搭建和重点领域、重大项目投资孵化两方面发力；县级及县级以下平台公司是乡村振兴项目建设实施和资产运营的主体。

从核心业务来看，平台公司主要围绕“土地、基建、产业”三大领域开展业务。

**乡村振兴/涉农政府平台企业核心业务**

1. **围绕农村土地**：参与农村土地整治项目、发展农村土地流转服务以及基于土地整治开展后续片区综合开发运作等。

2. **围绕乡村基建**：参与农村道路、农村供水、数字乡村等农村公共基础设施建设、人居环境整治以及生态治理工程等。

## 建设世界一流企业，打造核心“五力”

世界一流企业通常需具备产业引领力、品牌影响力、科技创新力、企业经营力和国际竞争力这五大核心能力。

### 世界一流企业的核心“五力”模型

1. **产业引领力**：主业具备核心竞争力，在某些行业具有较强大的经济规模与较强的盈利能力。
2. **品牌影响力**：拥有国际知名品牌，具有先进的企业文化和较强的社会责任。
3. **科技创新力**：自主创新能力较强，拥有自主知识产权的核心技术，信息化、数字化处于较高水平。
4. **企业经营力**：具有现代企业经营管理体系，集中有效的集团管控模式和强大的风险管控能力。
5. **国际竞争力**：跨国合作程度高，国际化管理与经营能力较强，内部激励、管理、改革等机制适应国际竞争要求。

与世界一流企业相比，中国企业虽然在资产、企业规模与发展速度等方面具有明显优势，但总体上，在创新能力、品牌影响力、国际化建设与现代化管理等方面仍存在一定提升空间，这就需要通过对标来发现差距、洞察原因、持续改进与提升。

## 对标世界一流企业，打造“三步走”

在对标世界一流企业的过程中，方法论是核心。通过“和谁对”“怎么对”“怎么用”三步走，实现精准对标，发现核心问题，分析洞察差距，提炼关键提升举措，并不断实施和优化，实现企业建设目标。

### 步骤一：“和谁对”

普华永道发现，往往企业在选择对标对象时无明确方向、期望大而全、缺少精准目标，尤其对于处于综合性和复杂行业的大型企业集团而言。这就需要通过制定科学的筛选标准与步骤，来实现精准对标。通过定行业、选企业、定维度三步走聚焦合适的对标企业。

### 制定筛选对标企业的三个标准

1. 具备相似的行业属性与环境。
2. 具备强大的可持续经营能力。
3. 具备可借鉴的关键领域。

筛选标准还包括：

- 选取全球范围相似行业内具有高度国际竞争力的企业。
- 挑选与自身企业有类似的外部竞争环境、目标市场、发展时间阶段。
- 规模较大或市场份额高，与自身企业具备可比性。
- 具有较好的盈利能力或者保持长期业绩稳定。
- 面对市场变化时具有较强的抗风险能力。
- 筛选在主要对标维度如战略定位、业务模式、品牌建设、技术创新、管理机制等核心竞争力上有可借鉴之处的企业。

**最终筛选出合适的对标企业**

### 步骤二：“怎么对”

建议也从三个方面入手：

第一，建立清晰易懂的对标维度和指标体系，遵循五大选取来源和五大选取原则。指标来源需确保满足客户发展要求并符合外部行业通用标准，符合权威性、全面性、适用性、独特性和指导性的五大原则。

#### 评价指标选取来源

1. 客户发展要求
2. 行业重点关注指标
3. 泛行业通用指标
4. 知名企业排名关注指标
5. 行业数据库

#### 评价指标选取五大原则

- **权威性**：选取指标来源时，充分考虑来源的权威性，运用更有说服力的来源作为指标输入。
- **全面性**：确保指标来源的全面性，以实现对企业的全方位能力评价。
- **适用性**：所选指标评价内容应当适用于所针对行业。
- **独特性**：在各指标来源中重复或者考核维度近似的考核指标之中，选取最优的指标进行保留，避免针对同一业务领域反复考察。
- **指导性**：所选指标数据能够反映企业运营情况，且跨企业指标对比对于提升企业运营具有充分指导意义。

第二，制定外部绩效与内部管理双重指标体系，从结果与过程双向出发，全面分析差距，深入洞察差距产生的原因，为总结关键提升举措进行精准铺垫。

#### 建立对标维度与指标体系

| 类别 | 对标维度 | 指标 |
|---|---|---|
| 外部绩效 | 经营业绩 | 管理规模、经营绩效、投资业绩 |
| 外部绩效 | 理念和形象 | 社会责任、企业文化、发展理念 |
| 内部管理 | 管控模式 | 组织架构、内部治理、集团管控 |
| 内部管理 | 业务管理 | 资源获取、成本管理、运营管理 |
| 内部管理 | 职能支持 | 技术创新、资源整合、人力发展、信息化 |

- 结果指标
- 过程指标

第三，通过运用量化评分与能力成熟度模型等多种工具，构建全面、合理、完善、易用的企业评估模型。

#### 运用评价指标工具

- **评价指标集**
  - 量化评价指标
  - 无量纲化的量化评分
  - 非量化评价指标
  - 能力成熟度模型评价
- **评估模型**
  - 多指标量化评价体系
  - 能力成熟度模型

能力成熟度模型将企业的某项综合能力水平分为多个发展阶段，各能力发展阶段覆盖企业能力从基础到卓越的完整区间，企业能力的显著提升对应发展阶段的提升。

对于非量化指标及其对应的综合能力，能力成熟度模型能实现评价标准的统一，并能够更为全面、直观地反映样本企业的能力水平及企业间的相对差距。

### 步骤三：“怎么用”

通过对标差距分析，得出对标结论，总结最佳实践，提出关键建议并持续改进。

**“怎么用”可分三步展开**

1. **总结世界一流企业实践经验**
   - 对标企业最佳实践案例
   - 总结归纳世界一流企业的优秀实践经验
2. **分析差距，总结原因**
   - 基于企业自身的战略目标，聚焦关键领域的核心问题
   - 识别对标企业与自身企业在定性与定量指标上的差距
   - 分析差距形成的原因
3. **提出关键建议，持续改进反馈**
   - 制定提升计划
   - 阶段复盘评估
   - 持续反馈改进

- 第九问，组织文化：如何融入集团文化、保持价值观一致，并建设有自身组织特色的文化？

当下，产业数字化机遇和挑战都是前所未有的，产业集团需要明确科创公司业务的定位和发展策略，加速数字产业化进程。通过整合内外部资源，加速产品化、市场化，在拓展业务增长空间的同时，带动产业链数字经济的高质量发展。

### 科创公司发展的六大破局点

普华永道认为，针对以上问题，科创公司的发展可以从六个方面破局：

1. **发扬核心能力优势**：综合集团与科创公司核心能力，加强数字技术自主研发，打造强竞争力的数字科技产品和服务，加速技术产品化；
2. **构建高效运营体系**：基于定位和目标，选择合适的业务组合，并构建与未来业务发展方向相匹配的治理架构、运营架构、系统架构、数据架构等；
3. **提升集团资源效益**：充分借力集团母品牌影响力、优势人才资源、成熟管理经验、渠道等，快速提升运营管理效率、降低服务成本；
4. **培育活跃生态系统**：在解决方案、供应链、营销、交付等方面和伙伴实现优势互补，快速弥补能力不足，提高市场响应速度，提高客户满意度；
5. **开展积极投资并购**：在集团的战略支持下，适当进行相应的投资并购，可补齐关键能力短板，拓展战略市场，进一步提升市场竞争力；
6. **严守风险合规底线**：建立战略性、专业性、全员性、系统性的风险管理体系，落实责任主体，强化底线思维，严格遵守国家和集团合规底线。

## 哪些常见瓶颈制约地方国企发展与功能发挥？

我国区域发展不均衡，地方国企通常承担着很重要的发展和建设任务，但常见在功能定位、业务布局、投融资空间、经营能力活力等方面面临一些挑战。

### 国企在发展中常见的瓶颈

**01 投融资压力较大**

负债空间有限，债务压力大，现金流平衡难度大；资本运作手段有限；投资拉动能力不足，重大任务支撑力弱。

**02 定位与布局不合理**

功能性与市场类业务混淆，经营不聚焦，考核不精准；业态传统，新兴产业布局不足，缺乏发展潜力。

**03 经营能力较弱**

经营性业务少，营收规模小，资产效能低；业务同质化竞争，资产集约化程度低。

**04 能动性与活力不足**

体制机制陈旧，经营授权不足，企业缺乏经营活力与积极性，工作推进缓慢。

## 地方国企在整合重组中常见哪些问题？

成功的整合重组固然可让地方国资国企迈上新台阶，但实践中不少案例由于对重组整合的根本逻辑理解不深，对业务及资产现状分析不足，对商业模式及关键脉络认识不够，重组整合徒具其形，常见的一些问题有：

1. **关联性协同性考虑不周**。重组整合缺乏产业关联性和业务协同性，简单按照功能、概念、逻辑抓堆进行整合，资产好像同类、业务看似相关，实则并无关联，没有整合协同效应。
2. **未充分考虑重组后企业发展**。整合后个别平台功能定位过窄，产业纵深不足，造血资源配套不够，缺乏腾挪空间，最终难以发展。
3. **未配套改革措施，机制未改变**。未配套授权经营机制、职业经理人机制、中长期激励机制、混合所有制改革、创新容错机制等，重组前后机制无甚变化，无法调动经营活力。
4. **设计深度不够，工作组织机制不周全，落地困难**。方案对重组路径、任务清单、重组后发展方向等设计深度不够，或缺乏推动重组落地的工作机制，重组方案未能有效承接落地。

## 如何体系化开展重组改革？

根据普华永道研究，成功案例坚持“从花钱到赚钱，从投资到经营”的理念，以“产管分离，功能分开，聚焦经营，推动上市”为原则，从产权侧、监管侧、经营侧同时发力部署整个国资国企重组改革：

1. **在产权侧突出功能平台作用，提升资信**。通过整合优质资源，开展市带区县、区带镇街等，做强资产和资信，提升评级，化解投融资能力饱和的问题。对于丧失投融资功能的平台，则稳定负债规模，防范债务风险，分流可经营业务。
2. **在管理侧调整业务布局，提升集约化经营**。对重点产业和重点业务进行布局谋划；将重点发展的核心公司提级管理以缩短层级；利用产管分离方式聚拢资产强化集约化运营，推进企业市场化转型发展。
3. **在企业经营侧系统性承接提升**。承接顶层设计，分业务分板块对标对表，从战略路径、组织架构、经营机制、中长期激励、合规内控、引进来投出去等全面策划和优化从而落实重组改革要求。

近年参股投资已成为国企投资的重要部分，如何有效管控参股投资十分重要。国务院国资委发布《国有企业参股管理暂行办法》（国资发改革规〔2023〕41号）（以下简称“《办法》”），标志着对国有企业参股投资的监管进一步强化，重点更加明确。

### 对《办法》的理解

**国有企业参股管理是国资监管不可或缺的一环**

本次《办法》的出台弥补了地方国企及子企业参股管理制度的空白。从长远来看，国有企业参股管理一直是国资监管体系的重要组成部分，未来政策会进一步升级和完善，在政策落地实施方面开展更多探索。

**与国有企业控股投资监管导向相衔接**

本次《办法》覆盖国有企业参股投资、经营、退出全过程，在投资方向、投资决策机制、投中股权结构、交易安排、投后公司治理、监督管理等多个关键环节与国有控股企业监管的导向吻合，体现了监管政策的一致性和国资监管“一盘棋”思路。

**在参股投资管理、退出方面进一步明确了要求**

本次《办法》结合了参股投资实践中的重难点问题，特别在参股投资管理、参股投资退出等方面新增以及强化多项具体举措，例如根据参股比例对参股企业实施差异化管理、选派人员到参股企业履行股东权责、加强对参股企业经营情况与财务情况的监控管控等，为政策落地实施提供支撑。

**与新一轮国企改革深化提升行动导向相统一**

本次《办法》要求国企在参股投资中聚焦主责主业、健全参股投资决策机制、完善国资监管体制，同时发挥国有资本投资、运营公司作用，盘活处置低效无效资产，体现了《办法》与新一轮国企改革深化提升行动导向相统一。

### 落实《办法》的思考

**实操层面留有进一步细化的空间**

本次政策提出了方向性、原则性的要求，为国企参股管理带来指引，但企业仍需充分学习、借鉴各地公共资本投资管理的优秀经验，积累优秀实践，细化为实施细则。

**国企参股痛难点需有针对性地探索解决**

在实践中普华永道关注到国企参股投资管理存在一些常见的痛点难点，例如股东借款、关联交易、公平市场竞争、同业竞争、合规经营等问题，需总结优秀实践经验，提升管理精准度。

**可探讨从顶层设计加强对国有资本的权益保障**

未来可以进一步完善国企参股投资权益的法律保障，从根本上保护国有资本权益。

### 对国企实操的建议

**精准监管**

建立参股企业业财信息收集与风险监控平台，对所参股投资企业的经营、财务风险进行集中分析和监控。加强对国企参股投资专项审计力度，约定对参股投资项目实施审计的形式与频率。

**构建体系**

建立参股投资绩效评价、参股投资项目重大决策事前评估机制等管理体系，完善参股经营投资台账，形成常态化、标准化管理机制。

**分类管控**

探索差异化管理，如对于重要参股企业可通过经济运行分析、管理报表、财务分析、重大风险监控等手段来提升经营监管能力。有条件的国资可建立参股企业数字监管平台，提升数字化监管能力。

**提升内控**

将参股投资项目纳入国企内控建设要求中，推动参股企业完善企业内部风控合规管理的制度体系建设，不断提升治理能力和管理水平。

### 政策要点梳理

《办法》从参股投资、经营管理、股权退出、国资监管要求等领域出发，为国有企业参股投资管理提要求、划底线以及明确监管职责，本文总结为3类要求+9条底线+4个明确。

**3类要求**

**参股投资要求**

1. 聚焦主责主业。
2. 开展尽职调查。
3. 参股达一定比例应享有提名董事权利。
4. 通过制度文件明确权责边界和重点事项权利义务。
5. 健全参股投资决策机制，强化投资决策统一管理。
6. 参股投资决策权向下授权作为重大经营管理事项经党委（党组）前置研究讨论，授权的企业管理层级不超过两级。
7. 达到一定额度的参股投资纳入“三重一大”范围，由集团公司决策。
8. 以非货币性资产作价出资的，应以公允合理的方式确定国有资产价值。
9. 其他股东未按约定缴纳出资，应采取有效措施防范风险。

**参股经营管理要求**

1. 建立参股经营投资台账。
2. 建立重要参股企业名单，实施差异化管理。
3. 选派股东代表、董事监事或者重要岗位人员。
4. 派出人员及时掌握并向派出企业报告重大事项，定期向派出企业述职。
5. 参与企业重要事项决策，充分表达国有股东意见。
6. 及时掌握参股企业经营情况，发现重大变化、重大风险或重大损失及时向同级国有资产监督管理机构报告。
7. 及时获取参股企业财务报告。
8. 根据章程督促参股企业及时分红。
9. 对投资额大、关联交易占比高、应收账款金额大或账龄长的参股企业加强风险排查。
10. 建立参股经营投资评估机制。
11. 及时办理参股股权的产权占有、变动、注销等手续。
12. 企业通过增资扩股引入其他投资者，国有股东应当在决策过程中就资产评估、进场交易等发表意见。
13. 产品注册商标确需授权给参股企业使用的，应当严格授权使用条件和决策审批程序，并采取市场公允价格。
14. 国有企业持股比例合计50%以上的参股企业，党建工作由持股比例最大的国有股东或国资监管机构领导和指导。

**股权退出要求**

1. 5年以上未分红、长期亏损、非持续经营的低效无效参股股权应当退出，战略性持有或培育期企业除外。
2. 与国企定位严重不符且不具备竞争优势、风险较大、经营情况难以掌握的参股投资应当退出，战略性持有或培育期企业除外。
3. 合理运用多种方式清理退出低效无效参股股权。
4. 通过国有资本投资、运营公司集中处置低效无效参股股权。
5. 退出参股股权应当严格执行有关规定，依法合规履行程序，及时办理工商变更登记。

**9条底线**

**涉及投资行为**

1. 不得通过参股等方式开展投资项目负面清单规定的禁止类业务。
2. 不得以股权代持、名股实债方式开展参股合作。
3. 共同出资新设的企业，不得对其他股东出资提供垫资，不得先于其他股东缴纳出资，另有规定的除外。

**涉及参股管理**

4. 不得选择与集团公司及各级子企业领导人员存在特定关系的合作方。
5. 严格控制对参股企业提供担保，确需提供的不得超股权比例提供担保。
6. 不得将字号、经营资质和特许经营权等提供给参股企业使用。
7. 国有企业失去标的企业实际控制权的，交易完成后标的企业不得继续使用原国有企业的字号、经营资质和特许经营权等无形资产，不得继续以原国有企业名义开展经营活动。
8. 国有企业及其各级子企业领导人员在参股企业不跨级兼职，不兼“挂名”职务。确需兼职的不得在兼职企业领取任何形式的报酬，不得获取股权和其他额外利益。
9. 参股投资主体及其各级控股股东领导人员亲属在参股企业关键岗位任职，参照企业领导人员任职回避有关规定执行。

**4个明确**

1. 将参股经营投资作为内部管控的重要内容，建立健全以风险管理为导向、合规管理监督为重点的内控体系。
2. 国有资产监督管理机构应当建立健全参股监督管理工作机制。
3. 具备条件的国有资产监督管理机构建立健全在线监管平台，对国有企业参股经营投资进行实时在线监管。
4. 对各级企业负责人开展任期经济责任审计时，将参股投资、与参股企业关联交易等有关事项列入重点审计内容。

中国人大网近期发布了《国务院关于2021年度国有资产管理情况的综合报告》，这是自2017年以来，国务院连续第五年向全国人大常委会报告国有资产管理情况。

### 国有资产整体情况

2021年企业国有资产（不含金融企业）、金融企业国有资产和行政事业性国有资产合计资产总额715.1万亿元、负债总额523.1万亿元、权益总额155.1万亿元，与2020年相比同比增长12.6%，11%和18.4%。

建立国务院向全国人大常委会报告国有资产管理情况制度是增加国有资产管理公开透明度、提升国有资产管理公信力的重要举措。过去五年披露的数据显示，国有资产整体呈现出稳步增长的态势。

2021年，在资产总额和负债总额指标上，金融企业占比均仍居于第一位，分别占总量的49.3%和60%，但与2020相比分别下降1.6和1.2个百分点，金融类国有企业资产和负债增速比企业国有资产（不含金融企业）低。

## 2022年国有企业IPO市场回顾

### 国企改革观象台2023年度

![](img/02c5bd393e4e45983149b8f3fbc15624_56_0.png)

2013年以来这十年，国企改革积极稳妥推进，大量国有企业通过上市和增发融资进一步优化了股权结构。国有企业以上市为契机和新的出发点，不断完善内部治理结构和市场化经营机制，在现代企业制度建设、发展混合所有制经济等重大改革议题中发挥了先锋模范作用。2022年是国企改革三年行动的收官之年，之后将进入高质量发展的改革新层次。

2022年，38家国有企业¹在A股上市，合计融资金额为1386.5亿元，分别占去年A股IPO数量和融资额的8.9%和23.6%。去年有7家国有企业在香港地区上市，合计融资额为312.4亿港元。

中国移动和中国海油是2022年A股市场的第一和第二大IPO，融资额分别为519.8亿元和322.9亿元。中国中免以183.9亿港元的融资，成为2022年港股最大的IPO。

自科创板开板和北京证券交易所开市以来，41家国有企业登陆科创板，融资额945.3亿元；15家国有企业在北交所上市，融资33.6亿元。A股境内分拆上市新规实施以来，已有超过10家国有企业通过分拆实现上市，另有超过15家国企公布了分拆计划。

> ¹ 国有企业指Wind中“公司属性”为“中央国有企业”或“地方国有企业”的上市公司。根据Wind，企业实控人为国资委、中央国有企业、中央国家机关时，企业所有制属性归类为中央国有企业。企业实控人为地方国资委、地方政府、地方国有企业时，企业所有制属性归类为地方国有企业。

## 2022年下半年中国国企改革回顾——央企的改革与发展

2022年，国企改革三年行动收官，取得预期目标。党的二十大为未来国资国企改革指明方向。国务院国资委优化央企经营指标体系，调整“两利四率”为“一利五率”，提出高质量发展、世界一流企业建设、新一轮国企改革深化提升行动等工作重点。

提高核心竞争力和增强核心功能是国资央企高质量发展的重要路径，也将成为新一轮国企改革的重点。未来，国资委将通过进一步优化国有经济布局结构、完善市场化机制、打造创新型企业，不断推动央企改革与发展。

全年有17家央企下属公司在A股上市，融资额合计1124.4亿元。37家央企25组专业化整合项目集中签约。央企积极布局数字产业，推动数字化转型，多家央企成立数字化专业子公司，多个央企间数字产业合作项目落地。绿色低碳发展成为多家央企2023年的工作重点。

### 国资国企改革新方向

党的二十大和中央经济工作会议对未来国资国企的改革提出新的要求，主要包括：

- 深化国资国企改革
- 加快国有经济布局优化和结构调整
- 提升企业核心竞争力
- 加快建设世界一流企业
- 处理好国企经济责任和社会责任关系
- 完善中国特色国有企业现代公司治理，真正按市场化机制运营等

国资委将上述改革目标具体化。在高质量发展方面，将推动央企经济运行实现质的有效提升和量的合理增长。在建设世界一流方面，将分类施策，全面对标，推进创建示范行动、管理提升行动、价值创造行动和品牌引领行动。在国有经济布局方面，将推动传统产业转型升级和新兴产业加快布局。

国资委表示，央企将突出高质量发展首要任务，通过提高核心竞争力和增强核心功能两大途径，实现做强做优做大国有资本和国有企业的目标。提高核心竞争力将以增强科技、提高效率、培养人才和打造品牌为抓手；增强核心功能将通过优化布局、调整结构来实现。

新一轮国企改革的重点包括三个方面，即加快优化国有经济布局结构，增强服务国家战略的功能作用；加快完善中国特色国有企业现代公司治理，真正按市场化机制运营；加快健全有利于国有企业科技创新的体制机制，加快打造创新型国有企业。

### 聚焦2022年中央企业负责人会议

- 优化调整央企经营指标体系：将“两利四率”调整为“一利五率”。净资产收益率替换净利润指标，营业现金比率替换营业收入利润率指标，继续保留资产负债率、研发经费投入强度、全员劳动生产率指标。
- 2023年央企“一利五率”目标：“一增一稳四提升”，即利润总额增速高于全国GDP增速；资产负债率总体保持稳定；净资产收益率、研发经费投入强度、全员劳动生产率、营业现金比率进一步提升。
- 2023年工作重点：高质量发展、世界一流企业建设、组织开展新一轮国企改革深化提升行动、国有资本布局优化和结构调整等。
- 国资委解读“一利五率”：建立“一利五率”高质量发展指标体系，突出了新阶段实现高质量发展、提升核心竞争力和建设世界一流企业的新要求，有助于统筹稳增长、抓改革、强创新、促发展、防风险等多重监管目标。通过引入净资产收益率和营业现金比率，从根本上引导企业增强自生能力、积累能力、可持续发展能力和价值创造能力。

2022年，央企合规政策进一步完善。国资委印发《中央企业合规管理办法》，成为国资委首个针对合规管理发布的部门规章；《中央企业法律纠纷案件管理办法》进入公开征求意见阶段，案件管理力度进一步加强。

国资委召开中央企业负责人会议，以及重组整合、合规管理和上市公司高质量发展多个工作推进会，部署未来改革工作。

### 2022年部分央企重组与整合案例

- 战略重组方面，中国南水北调集团列入国资委监管，中国中钢集团整体划入中国宝武钢铁集团，中国矿产资源集团组建成立。
- 国资委在7月和10月分别组织专业化整合项目集中签约活动，37家央企25组专业化整合项目集中签约。除了央企间的资源整合外，也包括央企和地方国企间的资源整合、产业类央企与国有资本投资、运营公司协同联动。中国稀土集团与广晟控股集团在稀土产业展开合作，中国电子与中国国新拟设立平台公司，盘活前者下属的非主业企业。
- 集中签约之外，中国储备粮管理集团和中粮集团合资组建的中企联合粮食储备公司和中企联合油脂公司完成组建；中国检验认证集团与中国通用技术集团所属检验检测企业实施专业化整合。中国三峡集团将所属中国水利电力对外有限公司划转中交集团。

### 混改、重组整合及“两类公司”¹的改革

2020年以来，央企引入各类社会资本超过9000亿元。下半年以来，中粮福临门公司混改项目签约，募集资金210亿元，引入社保基金会、中远海控、中国诚通国调基金等多家战略投资者。中国电子集团下属公司中国电子有限公司披露了招募增资方的计划，预计募资金额将超过150亿元。

2022年，17家央企下属公司在A股上市，融资额合计1124.4亿元，同比增长8.6%。其中，上海科创板IPO家数达8家，占比近一半，2家在北京证券交易所上市。

国资委要求加快央企间资源有效整合，推进内部深度整合融合，推动与外部资源有机结合，以提升核心竞争力。未来将从“进、退、整、合”四个方面推动重组整合，具体行动包括加大国有资本投资力度，研究组建服务国家战略目标新要求的新企业，深入开展企业之间同一或同质业务的整合。

¹“两类公司”指国有资本投资公司和国有资本运营公司。

加大创新能力体系建设和对战略性新兴行业的布局也成为国资委增强央企核心功能的重要举措。央企最近五年战略性新兴产业投资年均增速超过20%，2023年力争战略性新兴产业布局比重提高2个百分点以上。新一代信息技术、人工智能、生物技术、新能源、新材料、绿色环保等将成为央企布局重点领域。

据国务院国资委印发的《关于进一步深化国有资本运营公司改革有关事项的通知》，中国诚通、中国国新将由试点转入持续深化改革阶段，这是继五家国有资本投资公司完成试点后，“两类公司”改革的又一重大突破。

### 央企加快推进数字化

加快数字化转型是国资委推动央企科技创新的重要工程，国资委将推动央企突破一批关键核心数字技术，建成一批新型数字基础设施，打造一批典型应用场景，培育一批知名数字产业公司。

云体系建设是其中的重点。国资委表示，国资央企将积极投身云体系建设，成为国家基础公有云的运营者，构建数字基础设施。国资央企将致力于打造开放协同、绿色安全、自主可控、高效可用的国家级基础公有云平台。天翼云科技有限公司引入中国国新、中国电科、中国诚通、中国电子作为战略投资者，将积极推动央企云计算资源整合。

国务院国资委研究中心发布的《中央企业高质量发展报告（2022）》显示，央企加快推动数字化转型，建成了以航天云网、中电互联为代表的60多个工业互联网平台，此外还有三分之二的央企设立专业数字产业公司。

通过资产整合成立专业化数字子公司的行动依然在继续，中国联通临港数智科技（上海）揭牌。国机集团召开数字化转型推进大会，提出筹建数科公司。国内首家由央企设立的数据产业集团——中国电子数据产业集团在广东深圳揭牌成立。央企之间还形成了专业化的合作机制，由中国电建牵头组建的中央建筑企业数字化转型协同创新平台正式成立。

### 新一轮国企改革

2022年底召开的中央经济工作会议提到“谋划新一轮深化国有企业改革行动方案”的要求。2023年7月，全国国有企业改革深化提升行动动员部署会议召开，对改革行动进行了具体的部署，这意味着在国企改革三年行动（2020-2022年）收官之后，新一轮的国企改革拉开序幕。

改革将聚焦提高核心竞争力和增强核心功能。科技、效率、人才、品牌是提高核心竞争力的重要抓手。核心功能的主要体现是国有经济的主导作用和战略支撑作用，主要涵盖战略安全、产业引领、国计民生、公共服务等重点领域。

通过梳理部分央企召开的2023年年中工作会议发现，部署下一轮深化国资国企改革工作已经成为多家央企的工作重点。

### 改革重点及政策

通过对国务院国资委召开的工作推进会、专题会和研讨会等会议信息分析来看，2023年上半年国企改革工作的重点主要聚焦对标世界一流企业、提高上市公司质量、中央企业合规管理、发展战略新兴行业、数字化和央地合作等改革重点领域。

以对标世界一流企业为例，2023年3月，国务院国资委启动了“国有企业对标世界一流企业价值创造行动”，要求国有企业通过行动提升效率效益、战略性新兴产业布局、科技创新能力。此后，“创建世界一流示范企业”试点从此前的11家中央企业扩围至27家，新增10家中央企业和7家地方国有企业，另有200家中央和地方国有企业入围“创建世界一流专精特新示范企业”名单。

在新一轮国企改革中，国资委此前推出的改革专项工程将继续发挥着引领示范带动作用。2023年5月，国务院国资委将“双百企业”数量从449户扩充至580户，将“科改”企业从440户扩充至672户。

国资改革方面新发布的政策包括《中央企业法律纠纷案件管理办法》、《中央企业债券发行管理办法》和《关于上市公司独立董事制度改革的意见》。

### 数字化

数字化是上半年国资国企改革的重点关注领域。2023年4月，国务院国资委召开央企信息化工作推进会议，要求提高智能监管水平、推进央企云体系和大数据体系建设等重点工作。

5月，深入推进国有企业数字化转型专题会召开，会议披露了央企数字化转型取得的进展，主要包括89家央企明确数字化转型发展规划，组建数字科技类公司近500家等。对未来数字化转型方向，国务院国资委也提出了加强对标评估、推进试点示范及加强合作发展等多个要求。

组建数字化相关的专业化公司成为市场热点，上半年涌现出多个新的案例。国家能源集团原信息公司、国能信控、大渡河大数据公司重组整合为国家能源集团数智科技开发有限公司。中国电子信息产业集团组建中电数据产业有限公司。中国物流集团联合中国软件与技术服务股份有限公司、中国电子信息产业集团组建了中国物流数字科技有限公司。

多家中央企业的年度工作会议信息显示，“数字化”或“数智化”是2023年整体工作或科创工作的重点。中国石油天然气集团提出要加快建设“数智中国石油”。哈尔滨电气集团要求“数字化赋能新优势，加快生产数字化、装备智能化、管理信息化”。中国宝武集团提出要加速数智化转型，深化数智化体系建设，加快推进数字时代的管理变革，全面加强数据要素的治理与应用。
