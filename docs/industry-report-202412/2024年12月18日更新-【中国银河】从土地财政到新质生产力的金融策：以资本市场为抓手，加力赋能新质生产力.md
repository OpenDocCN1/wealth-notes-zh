# 2023年10月

**中央金融工作会议**

切实加强对重大战略、重点领域和薄弱环节的优质金融服务，引导更多金融资源流向科技创新、先进制造、绿色发展和中小微企业。

# 2023年11月

**中央金融委员会会议**

做好科技金融、绿色金融、普惠金融、养老金融、数字金融五篇大文章。

# 2023年11月

**中国人民银行、科技部、国家金融监管总局、中国证监会联合召开科技金融工作交流推进会**

聚焦科技创新的重点领域和金融服务的短板弱项，深化金融供给侧结构性改革，推动完善包括信贷、债券、股票、保险、创业投资、融资担保在内全方位、多层次的科技金融服务体系。

# 2024年4月

**《资本市场服务科技企业高水平发展的十六项措施》**

从上市融资、并购重组、债券发行、私募投资等维度提出了各项举措，促进科技企业的创新和发展，同时确保市场的稳定和健康发展。

# 2017年7月

**《新一代人工智能发展规划》（国发〔2017〕35号）**

充分利用已有资金、基地等存量资源，发挥财政引导和市场主导作用，形成财政、金融和社会资本多方支持新一代人工智能发展的格局。

# 2019年8月

**《关于新时期支持科技型中小企业加快创新发展的若干政策措施》（国科发区〔2019〕268号）**

加强金融资本市场对科技型中小企业的支持。

# 2023年2月

**《境内企业境外发行证券和上市管理试行办法》（中国证券监督管理委员会公告〔2023〕43号）**

一是坚持监管全覆盖。二是坚持落实“放管服”改革要求。三是坚持深化对外开放。

# 2024年6月

**《关于深化科创板改革 服务科技创新和新质生产力发展的八条措施》**

充分发挥金融资产投资公司在创业投资、股权投资、企业重组等方面的专业优势，加大对科技创新的支持力度。

# 2024年9月

**《关于深化上市公司并购重组市场改革的意见》**

支持上市公司向新质生产力方向转型升级、鼓励上市公司加强产业整合、进一步提高监管包容度、提升重组市场交易效率等。

# 2015年6月

**《关于大力推进大众创业万众创新若干政策措施的意见》（国发〔2015〕32号）**

支持符合条件的创业企业上市或发行票据融资，并鼓励创业企业通过债券市场筹集资金，支持符合条件的发行主体发行小微企业增信集合债等企业债券创新品种。

# 2016年4月

**《促进科技成果转移转化行动方案》（国办发〔2016〕28号）**

支持符合条件的创新创业企业通过发行债券、资产证券化等方式进行融资。

# 2017年7月

**《关于开展创新创业公司债券试点的指导意见》（2017年第35号公报）**
