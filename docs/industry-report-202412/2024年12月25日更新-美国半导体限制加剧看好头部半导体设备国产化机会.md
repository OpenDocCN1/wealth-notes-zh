# 美国半导体限制加剧，看好头部半导体设备国产化机会

- **2024年12月2日，美国进一步加大对中国半导体设备材料、存储芯片带宽和制造软件方面的限制。我们不排除日荷政府或于近期出台新一轮限制措施的可能性。**
- **10M24，中国从美国、荷兰进口的部分设备（化学气相沉积、分步光刻机、检测设备）金额下跌明显；相应地，中国将相关设备进口方向转移到日本和新加坡等国。**
- **看好中微公司（行业首选）和北方华创（买入）；短期观望芯源微。**

**针对中国半导体限制层面，美国逐步从设备材料向软件方向延伸。**美国针对中国在2022—2023年期间陆续出台了针对14nm逻辑芯片、18nm DRAM、128层以上NAND及AI芯片的诸多限制。美国近日又于2024年12月2日进一步收紧对中国地区的管制，涵盖实体清单、半导体设备、存储芯片密度、EDA工具等角度。

首先，实体清单方面，我们认为被添加Footnote 5的企业（华芯恩、福建晋华、中芯北京、中芯南方等）将更难拿到美国及其盟国的设备材料，或对近期国内先进制程扩产产生负面影响。

其次，存储方面，美国对输中的先进DRAM和HBM（高带宽存储）的存储带宽密度进行了限制（HBM裸片带宽密度不超过每平方毫米2GB）。由于当前高端在产HBM带宽密度大于等于2GB，我们认为此项规定限制了中国企业直接获取中高端HBM产品。

最后，美国也对中国获取半导体设计制造软件（如EDA）进行了限制。我们认为，以上事实表明，除关键工艺设备零部件外，美国或下一步加强对软件和半导体IP的限制。日本和荷兰也在2023年和2024年跟随美国脚步，陆续出台了针对中国的半导体设备和材料限制。我们认为，后续限制风险主要与EDA、设备维护和零部件供给相关。若美日荷政府进一步限制或禁止针对关键设备（光刻机、刻蚀和薄膜沉积）的零部件获取或维护工作，近期中国先进制程逻辑和存储芯片的扩充节奏或受一定影响。

## 2024年前10个月中国大陆半导体设备进口情况

我们发现在美国和盟国颁布限制措施后，中国从美国、荷兰、韩国进口的部分设备金额出现明显下跌，相应地，中国将相关设备的进口方向转向了日本和新加坡等国。

根据中国海关，10M24期间，中国从美国进口的薄膜沉积设备、化学气相沉积设备金额下跌明显（分别同比下跌84%和13%）；而同期从日本进口的这两款设备金额分别同比增长316%和44%。10M24期间，中国从荷兰进口的分步重复光刻机和检测光掩膜用的光学仪器金额下跌明显（分别同比下跌83%和61%），但从日本进口的分步重复光刻机金额则同比增长25%。

## 荐股理由

在美日荷出台进一步半导体限制措施之际，我们更加看好半导体设备国产化提升逻辑。在半导体设备赛道，行业首选是中微公司（买入），基于我们看好公司2025—2026年的盈利增长前景。对于北方华创（买入），我们认为公司作为平台型公司，是国产化趋势的长期受益者。针对芯源微，我们认为公司仍处于经营业绩调整阶段，建议投资者短期观望。

# 美国和盟国半导体制裁分析

## 美国出口管制法案分三年陆续发出

根据半导体行业观察，自2022年起，美国通过一系列出口管制新规，逐步收紧对中国先进半导体技术及设备的出口。管制范围涵盖高端逻辑制程、存储芯片以及高性能芯片技术，同时针对中国获取关键设备和技术的路径进行了多方位限制。2024年，这些措施进一步升级，覆盖从转口贸易到下一代半导体技术，旨在遏制中国在高性能芯片及半导体技术领域的突破，以削弱其军事和经济竞争力，并确保美国及其盟友的技术领先地位。

根据韩国《首尔经济》报道，早在2022年3月28日，美国政府提议与韩国、日本和中国台湾省组建“芯片四方联盟”（Chip4），同时美国与日本和荷兰组成三方联盟。我们认为，美国盟友中，尤其是日本和荷兰，分别在刻蚀设备与EUV光刻机领域占据核心地位，这两个国家的合作对管制政策的有效执行至关重要。

## 2022—2023年美国发出与半导体制造工艺和相关设备有关的制裁

2022年10月7日，美国商务部工业和安全局（BIS）宣布了一系列对向中国出口先进计算和半导体制造设备的限制性控制。具体来说，它限制了以下几类产品的出口：

1）非平面晶体管架构（即FinFET或GAAFET）16nm或14nm或以下的逻辑芯片的出口；  
2）18nm半节距及以下DRAM存储芯片；  
3）128层及以上NAND闪存芯片。

该规则还对某些半导体制造项目（如蚀刻和沉积）以及相关组件和部件施加了控制。我们认为其威胁体现在两个方面：

1）对28nm以下的设备实施统一限制，导致中国客户不能采买14nm及以下的关键刻蚀和薄膜沉积设备；  
2）但1980i光刻机因既可用于生产45nm制程，又能通过多重曝光技术实现7nm制程，在2022年10月的制裁措施中是一个模糊地带。

2023年10月17日，BIS对向中国出口的先进芯片实施了额外出口管制，禁止H100和H200芯片出口。随后美国进一步升级管制措施，直接禁止H20芯片对中国市场的销售，限制中国获取高性能和高带宽芯片，限制中国获取先进计算能力。

2024年9月5日，BIS对包括GAAFET、蚀刻和电子束流检查（EBI）在内的某些半导体制造技术实施了全球出口管制，与GAAFET技术有关的向世界所有国家的出口将需要BIS的许可证。针对此项规定，我们认为可能的影响有几方面：

1）设备层面：如果荷兰政府与美国采取相同的管制措施，禁止ASML通过第三方为中国光刻机提供维护服务，那么2000i以上型号的光刻机将无法获得必要的零部件和校准工具支持，中国大陆的2000i以上型号光刻机面临失去功能的风险。

2）GAA层面：GAA技术主要针对2nm及以下制程，虽然相关设备早已被列入美国禁运名单，但我们认为美国这一限制不利于中国利用GAA结构发展本土先进存储和逻辑技术。

2024年12月2日，美国进一步收紧管制，主要从实体清单、TSV刻蚀设备、离子注入设备、DRAM存储单元面积和密度、HBM裸片带宽密度以及提升半导体制造和设计良率的关键软件等角度做出限制。

实体清单角度，由于这次产品限制清单又对一些企业添加了Footnote 5（包括华芯恩、福建晋华；科研院所张江实验室、中科院微电子所等；中芯北京、南方等），我们认为被添加Footnote 5的企业或更难拿到从美国及其盟国进口的关键半导体设备。

半导体设备和材料方面，随着限制措施的加剧，我们认为零部件国产化进程会进一步加快。由于日本还未出台进一步的限制措施，我们认为来自日本的进口材料供应情况值得投资者持续关注。

半导体存储方面，美国2024年12月2日的管制还对中国输中的先进DRAM和HBM（高带宽存储）的存储带宽进行了限制，要求HBM裸片的带宽密度不得超过每平方毫米2GB。由于当前在产的HBM带宽密度均在2GB或者2GB以上，我们认为目前流通的HBM3和HBM3E已被直接限制。

软件方面，我们认为此轮对关键制造软件（如EDA工具）的限制表明了美国除对关键工艺、产品、设备、零部件限制外，对软件层面的限制也在加紧。由于许多中国大陆芯片设计公司仍然外采美国头部公司的EDA和IP产品，我们认为，若下一步对美国公司的IP产品进行限制，或对一部分依赖海外IP的中国芯片设计公司的经营产生较严重影响。

## 日本2023年7月份出口管制的设备主要包括成膜、EUV、清洗和刻蚀设备

2023年5月份，日本出台限制法案，其限制内容包括23项出口细节。日本出口管制法律体系由多部法律法规构成，其中，《外汇与外贸法》构建了日本出口管制法律体系的框架；《内阁令》《出口贸易管制令》和《外汇令》分别规定了管制货物与管制技术（包括软件）清单。此外，出口管制相关省令、通知、通告、指南等配套行政细则从实操层面提出出口管制的细化要求。

此次管制主要针对制造电路线宽在10至14纳米或以下的设备，同时还对部分涉及45纳米及以下的半导体制造设备（步进重复式光刻机设备）进行管制。

我们认为日本在2024年9月份实施的出口管制主要针对的是GAAFET结构的集成电路，对GAAFET相关的设备材料进行限制。相比于2023年7月发布的版本，2024年9月发布的政策新增了5项半导体相关的特定货物及技术纳入出口管制。我们认为日本对GAAFET相关结构的设备材料限制或是基于美国对中国进行GAAFET限制的跟随措施。

我们认为日本的出口管制可能对中日两国以及整个东亚乃至全球的半导体产业链和供应链带来冲击，并可能引发中国的反制措施。

# 荷兰出口管制的设备和对应公司

根据彭博社报道，2024年9月6日，荷兰政府宣布扩大对先进半导体制造设备出口管制措施。从2024年9月7日起，1970i与1980i等DUVi曝光设备出口必须申请授权。根据彭博社报道，在此之前荷兰政府只规定2000i以上型号禁止出口中国，这次把1970i以及1980i型号也纳入管辖范围。

2024年11月7日，美国国会众议院中国共产党问题特别委员会（SCCCP）向ASML首席执行官发出问询函，重点关注以下内容：

1）关键客户与制裁实体：要求列出ASML与中国主要客户及受制裁实体的业务往来情况；  
2）设备出口情况：涉及2021年以来出口至中国的光刻设备型号、相关出口许可及设备的技术节点能力；  
3）合规与管理：包括在中国负责出口合规工作的员工及第三方服务提供商的信息。

因此，我们认为美国针对荷兰的长臂管辖的影响将会持续。

根据ASML 2023年财报，公司净销售额达到276亿欧元，较2022年的212亿欧元增长约30.2%。其中，中国大陆市场贡献的营收占比为29%，较2022年的14%增加了15个百分点。

中国大陆市场2023年相较2022年贡献的营收大幅上升，我们认为主要原因包括：

1）成熟制程需求旺盛，特别是对DUV光刻机的需求；  
2）客户为应对出口管制加速备货；  
3）中芯国际等本土企业扩张带动设备采购；  
4）政策扶持加速半导体产业发展；  
5）ASML调整销售策略，聚焦中端DUV设备（如1970i和1980i），进一步推动了销售增长。

尽管受到出口管制限制，ASML近些年在中国的销售额仍在持续增长，反映出中国半导体制造业对高端制造设备的强劲需求，以及ASML设备在全球半导体产业中的关键地位。

根据半导体行业观察，2023年ASML向中国销售了450台光刻机，较2022年的出货量提升了50%，但中国海关总署数据显示2023年从荷兰进口光刻机数量为49台，差异源于多重因素：

1）二手市场设备和模块化出口未完全反映在海关数据中；  
2）ASML的销售数据包含已签约但未交付订单，与海关统计口径存在时间错配，进一步加剧差异。

我们认为，后续荷兰加紧限制带来的风险主要跟设备零部件供给和设备维护相关。若荷兰政府禁止ASML通过第三方途径支持中国光刻机的维护工作，那么我们不排除2000i型号以上的光刻机无法获得零部件和校正工具服务的可能性，高端光刻机可能面临失去功能的风险。

# 填补半导体设备需求缺口：国产蚀刻和薄膜沉积设备的最新发展

在美国及其盟友实施制裁后，中国在获取关键半导体技术和设备方面受到了限制，我们认为这可能对其制造先进计算芯片带来挑战。然而，我们也看到中国企业在努力降低对进口技术的依赖。以下是我们汇总的中国在半导体工艺和设备方面取得的一些进展：

- **先进制程：**根据半导体行业观察，中国现在可以在GAA结构下使用DUVi+MP生产5nm芯片。
- **DRAM/NAND：**根据行业半导体观察，中国的DRAM制造限于18nm或1α节点；NAND方面，中国的NAND工艺主要依靠国内蚀刻公司的技术突破和海外国家的进口。根据半导体行业观察，中微公司（AMEC）正在寻求生产与Lam Research（LRCX）Syndion和SABRE 3D产品类似的产品。Syndion蚀刻器用于创建更大、更高的长宽比特征，如TSV和沟槽；SABRE 3D专注于晶圆级封装（WLP）和TSV结构，产品提供了铜大马士革制造所需的精度。
- **半导体国产设备：**在刻蚀设备方面，代表性公司如中微公司正在开发具有90:1深宽比能力的刻蚀设备（根据中微公司2023年年报）。这个指标意味着刻蚀深度可以达到宽度的90倍，是实现更高密度和更复杂结构（如更高层数的3D NAND存储器和先进逻辑芯片）的关键技术。北方华创最早做ICP刻蚀，2024年ICP在整体刻蚀收入中占据90%。同时在CCP设备方面，北方华创在2024年初也实现了大批量出货。在薄膜沉积设备方面，根据北方华创2023年年报，公司2023年获得的PVD订单达40亿，相比2022年增长约4倍，一定程度上说明了国产公司在重点薄膜沉积方面的进展。

但同时，我们认为当前一部分7nm和14nm制程的国产设备紧缺进口零部件，国产设备的零部件国产化是近期的重要课题之一。

整体而言，面对美国、日本和荷兰的多重制裁，我们认为中国政府从产业链全局出发寻找解决方案，其中半导体设备被视为关键环节。为降低对外依赖，中国加大对本土企业的支持，推动诸如中微公司、北方华创等在刻蚀和薄膜沉积设备领域的突破。同时，通过政策引导和资源倾斜，加快关键设备国产化进程，逐步构建自主可控的半导体产业链。

根据芯谋研究，2023年国内半导体设备公司总体营收增长超17.6%，达到40亿美元，设备国产化率达到11.7%。该机构预计2024年中国大陆设备厂商营收将进一步增长至51亿美元，国产化率达到13.6%。我们认为在国产替代的大趋势下，国内设备厂商将有望从点式突破向纵、横两个维度加速拓展，设备产业将进入全面高速发展的新阶段。

从我们覆盖的半导体设备公司看，中微公司覆盖200层3D NAND和19nm DRAM制程的刻蚀产品。北方华创扎根ICP刻蚀基本盘，发力CCP、薄膜沉积和清洗设备。芯源微专注于涂胶显影、清洗设备及先进封装设备，重点突破高产能涂胶显影机、化学清洗和临时键合设备领域。这些进展显示国产设备逐步满足先进制程需求。

## 美国：薄膜沉积、化学气相沉积、其他刻蚀及剥离设备进口金额下跌明显

根据中国海关数据，中国从美国进口的半导体设备主要包括薄膜沉积、氧化扩散、其他制半导体器件或集成电路用的机器装置、化学气相沉积、物理气相沉积、刻蚀机、离子注入、晶圆检测、其他刻蚀及剥离设备等品类。以上品类汇总，10M23和10M24期间，中国从美国进口的设备总金额分别达到220亿元和280亿元。

**10M24期间进口金额下跌品类：**根据中国海关数据，10M24期间，中国从美国进口的薄膜沉积设备、化学气相沉积以及其他刻蚀及剥离设备的金额分别为1.8、21.6和1.9亿元，分别同比下跌84%、13%和27%。我们认为薄膜沉积设备进口金额同比下跌84%，主要由进口设备数量及均价同比下跌导致（分别同比下跌72%及超过40%）。化学气相沉积设备进口金额同比下跌13%，则是由于其设备进口数量的同比下跌所导致（设备数量同比下跌28%，均价同比上涨21%抵消部分跌幅）。其他制半导体器件或集成电路用机器装置方面，即使1H24期间的进口金额出现了大幅度同比增长，但从10M24期间看，该品类的进口金额同比下跌了34%。

**10M24期间进口金额上涨品类：**10M24期间，中国从美国进口的氧化扩散热处理设备、刻蚀机、离子注入设备、晶圆检测设备以及物理气相沉积设备金额分别为35.6、18.0、88.3、88.6和14.8亿元，分别同比上涨75%、3%、72%、32%和30%。我们认为氧化扩散热处理设备进口金额上涨主要由进口设备数量及均价同比上涨导致（数量和均价分别同比上涨37%及46%）。

# 风险提示

- **下游需求不及预期：** 下游需求与设备公司业绩紧密相关。若整体半导体市场增速放缓，半导体晶圆厂的投资进程则将延迟，直接影响对上游设备厂商的订单和需求。
- **美国对中国半导体行业进一步限制：** 2024年12月2日，根据美国工业和安全局（BIS）官网，北方华创已被BIS列入实体清单，这表明涉及该公司的任何先进计算和半导体制造项目的出口、再出口和转让都需要额外的许可证。若BIS进一步扩大限制清单并将中微公司列入实体清单，则中微的经营可能会被负面影响。
- **半导体设备竞争加剧：** 更多国内半导体设备厂家的产品开始量产和销售，国外厂家为了维持市场份额导致竞争加剧。

# 风险提示

- **下游市场需求放缓：**半导体市场的整体放缓可能会影响半导体晶圆厂的投资努力，直接影响对上 游设备厂商的订单和需求。
- **美国潜在的进一步限制：** 2024年12月2日，北方华创已被美国工业和安全局（BIS）列入实体清单，这表明涉及该公司的任何先进计算和半导体制造项目的出口、再出口和转让都需要额外的许可证。虽然我们认为，目前这一限制对北方华创当前的运营影响有限，但如果BIS扩大限制的范围，无论是直接对北方华创或其任何上游供应商的限制，都可能对其产能产生大于预期的影响，从而给其销售或利润率带来下行风险，因为它可能需要以更高的成本收购原材料。
- **半导体设备的竞争加剧：**随着更多的国内半导体设备厂家开始大规模生产和销售半导体设备，海外公司可能开始会更激烈地竞争以维持其市场份额。激烈的竞争可能会损害北方华创的利润率。

# 风险提示

影响股价的下行风险包括：

- **下游需求不及预期：** 下游需求与设备公司业绩紧密相关。若整体半导体市场增速放缓，半导体晶圆厂的投资进程则对延迟，直接影响对上游设备厂商的订单和需求。
- **美国对中国半导体行业进一步限制：** 一方面，根据美国BIS官网，美国直接将一部分半导体设备公司纳入实体清单，限制中国大陆设备公司获取海外零部件，不排除影响一些设备公司的正常经营和产品出货。另一方面，根据美国BIS官网，美国限制14nm及以下先进制程设备出口中国，或对中国部分存储和先进逻辑产能扩产造成一定程度影响。若先进产能的扩产节奏出现延迟，直接影响上游设备厂商短期的订单。
- **半导体设备竞争加剧：** 更多国内半导体设备厂家的产品开始量产和销售，国外厂家为了维持市场份额导致竞争加剧。

影响股价的上行风险包括：

- **下游需求超过预期：** 若整体半导体市场需求增长超过市场预期，有望直接拉动对上游设备厂商的订单和需求。
- **产能扩张超预期：** 如果国内晶圆厂扩产速度超过预期，芯源微收入有望充分受益于半导体设备持续增长需求。
- **半导体零部件国产化速度超预期：** 如果更多国内半导体设备厂家开始采用国产化零部件，有望直接拉动毛利率的增长。
