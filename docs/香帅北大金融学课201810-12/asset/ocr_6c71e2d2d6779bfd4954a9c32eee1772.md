# 第一天：创新、监管和危机：金融市场的新陈代谢

第一天的时候，我从整体上给你介绍的是这三者之间的关系。尽管，现在的金融市场变得越来越复杂，但是，其实你会发现，它的基本逻辑是没有变的。

![](bbox=[0.05, 0.32, 0.95, 0.36])

![](bbox=[0.05, 0.36, 0.95, 0.44])

金融监管和金融创新会交替上演，也就是说，你只要有融资需求，市场上一定会想办法创造出新的金融工具，而金融工具会受到市场的狂热追捧。当市场反应过热以后，又会遭遇监管的降温与监管，由此催生出新一代的创新产品。而危机则是监管和创新博弈的结果，也是新一轮博弈的起点。

# 第二天：金融创新的本质是思想革命

第二天，我讲的是这一周里边最重要的一课，我跟你讲的是金融创新的本质到底是什么。

很多人借用的是熊彼特的说法，金融创新是整个生产函数的改变。其实我告诉你，金融创新的本质是思想革命，因为金融市场本身就是一种创新，12世纪开始的是国债，17世纪开始流行的是股份和公司，像股票是金融市场两个最基本的工具，它是人类思想史上的两次飞跃，为什么呢？

第一次，在欧洲的中世纪，人类的时间是属于上帝的，而利息是时间的价值，所以，收取利息被认为是是对上帝的时间的偷窃。大规模地国债使得货币资本化和世俗化，告诉人们，人的时间并不是属于神，等于把人从神那里解放出来。

而股份制则是打破了不同社会阶层，资源聚集度，行动者的区分，使得普通每个人也能够召集强大的资金聚集和资金募集能力，让人们有了身份不重要，项目才重要的理念，把人从人那里解放出来。

![](bbox=[0.05, 0.88, 0.95, 0.91])

这次思想革命，是金融对人类文明贡献最大的两个贡献，大大地提高了人类征致自然的能力，也大大地提高了社会的流动性。

金融创新的本质和最关键的要害其实就是思想革命。

# 第三天：“金融创新”到底是好孩子还是坏孩子？

第三天的内容，我给你讲的是金融创新到底是靠么评价，因为在现实世界里，你会发现，人们普遍对金融创新抱着很感兴趣，但监管者对于金融创新则是一种非常比较负面的，或者说比较保守的态度。

![](bbox=[0.05, 0.11, 0.95, 0.15])

![](bbox=[0.05, 0.15, 0.95, 0.22])

这里，确实也跟金融创新给社会带来的影响是有关系的，很多金融创新工具，一方面能够使整个社会更加紧密联系在一起，使人们的资金使用更高效。但另一方面，因为金融的这种特性，它也常常会是生平，在监管没有覆盖到得边界地区进行突变，野蛮生长，甚至风险引发。这就是为什么我们对各国金融部门对于金融创新的态度都是矛盾的，监管、创新和监管之间，经常会呈现出一种相爱相杀的关系。

# 第四天：中国古代历史上的金融创新

第四天的时候，我给大家分析一下中国古代的金融创新，从中国古代金融创新的历史里面看看，能不能够沉淀出一些对我们未来生活有用的信息。

中国历史上，金融创新虽然不少，但是你会发现，跟我们这些现代意义的金融创新不太一样，中国古代的金融创新大多跟信用债有关，而不是围绕者信用债来做文章的，这也是第一周我跟你讲的，因为我们有一个庞大的帝制统治体系的存在，所以使得很多的金融创新都围绕着这个轴心来展开，但是，金融创新的依旧是信用交易，所以，在缺乏信用的社会中，这些创新最后很难获得极大的成功。

![](bbox=[0.05, 0.6, 0.95, 0.65])

那么，什么样的金融创新才能获都获得成功呢？我也给你讲了，有两点：

+   - 在我们中国这个社会现状下，第一是边缘性的创新，也就是不涉及到中央财政政策体系的创新，才有可能在边缘长大，甚至覆盖主流。
- 另外一点，就是一定要像股似债同样，比当时的生产力领先半步地创造，才有可能取得实质的成功。
