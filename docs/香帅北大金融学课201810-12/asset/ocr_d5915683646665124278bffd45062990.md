# 208 | “金融创新”到底是好孩子还是坏孩子？

你好，欢迎来到曾鹏的北大金融专业课。

今天我们要说的金融创新这个话题，一般来说讲，一听到金融创新的这个话，我想大部分人都会感觉挺好的。像支付宝、微信支付它们不是带来了这么多的生活的便利，对吧？还有的就原来那么那些外债的人，对他们说得到更、汇率的的冲对工具，让很多人企业有了更大的的风险能力。

但是，你要知道，这只是我们的感觉。你要问监管层的话，它一定会这么说看。

美国金融届有一个大牛，是曾经担任过美联储主席的沃尔克，他就怒说过金融创新：他说，这十几年，银行金融创新唯一做的的事情，就是发明了ATM机。

所以，我可能真的要问一下一个题目，就是金融创新到底是好还是坏呢？

要回答这个问题，我们就要从金融创新和监管中的博弈说。因为你会发现，在很大程度上的，创新和监管之间，其实是一个相互关系的关系。

# 一、监管和创新：相爱相杀

我们用例子来说，比如监管许可证化，对美元用这三十年的金融市场有有重大影响，有好的，又有的。所以对于对监管界来说，真的是一个“让我欢喜让我忧”的个新工具。

这个工具对于解决历史上金融工具，尤其是商业银行流动性不足和期限错配的问题，有很大的帮助。

这个话是什么意思呢？我们都知道，美国在30年代之后，实取了银行银业和投资业务分业监管的模式，两者中间泾渭河分别明。

为什么要强制分业呢？就是为了防止资本市场的活动，会波及到商业银行的资金安全。所以，分业监管，就像把资本市场和商业银行两个市场给分开。它的好处就是波动是不会相互传播的。

但是，后来随着时代发展，我们又发现，这个事的好处越来越明显了，其中最重要的一条就就“期限错配”。

什么叫期限错配呢？就是银行存款大都是几个月的短期存款，但是，贷款一般是不半年，甚至十年。存贷款之间的期限是不平衡的，这就叫期限错配。

这个问题很大的，因为长期的贷款贷出去了，但存款突然间到期了，银行资金总会缺口的，然后面临着资金头寸调不了的风险。另外一个问题就是，这些长期贷款就在整个，整个银行的流动性也很差，所以银行的发展会受到很大的限制。

既有限制，等于市场出现了需求，这个时候，聪明的银行家就开始想办法了。他们把这些就放在每个人的长期贷款，也把它打包。就就各个客户的利息都作为现金流，用这个现金做作为抵押发行债券，在资本市场上卖出去。这个过程就证券化。所以，这个市场就叫做资产证券化产品。

这个产品，一下就解决了流动性和期限错配的问题，因为一方面把这种长期资产的长期资产给活起来，而且可以在注不断循环再流动，等于流动性和期限错配问题都一块儿解决了。

这么一个产品，后来的兴起就把整个美国金融市场的深度和广度拓展了。你想，作为监管层，那肯定是很高兴的，对不对？

但是高兴之余，还有一个后果，就是原来银行和资本市场是分隔的，但是现在通过资产证券化这个产品，将金融市场和银行系统就连在一起了。因为它的好处比较多，而且利用也很大，所以随着市场份额越来越大，就出现了大量的监管真空。这个产品好像也不适用商业银行的监管上不大对，用监管层在监督也不对。在监管真空的情况下，围绕着资产证券化，各种证券化、再证券，还有复杂的衍生品加杠杆的创新就不断地出现了。

到2000年之后，证券化份额已占据到了整个美国金融市场30%的份额，所以就形成了一个庞大的缺乏监管的影子银行。

所以里面的产品，链条越来越往长，也越来来越复杂。这导致了，我们层的基础资产的质量越来越看不清楚。所以，也是我在前面课程里面讲过的，2008年的次贷危机，和资产证券化这些新产品的滥用，是有密切关系的。
