# 242 | 中国信用社会的弯道超车

你好，欢迎来到李帅的北大金融课。

上节课我给你说了一个词——颗粒社会。在数字化时代，我们每个人的形象都可以清晰地呈现出社会，整个社会变得高精调。这种高精调，使得精准金融、精准金融都有高可行性。

那么，在这么一个颗粒度极小的中国社会，还会发生一个变化，这就是今天我要跟你讲的个人信用社会。

那什么叫做个人信用社会呢？就是你的个人信用能更多地渗进社会，而这种个人信用和你的日常生活是密切相连的。

# 一、社会信用与个人信用

有的同学可能会疑惑，我们现在所处的不就是信用社会吗？对的，但你发现了吗，我们现在用的信用是以机构为主导的，国家信用、银行信用、大型公司信用。个人信用的构型上面是显得很单弱的，所以这里你需要理解，社会信用和个人信用是相互促进，不能简单划等号的，社会信用是包括机构信用和个人信用的。

我在第二周课程里讲过，中国的金融市场由中央到财政拨款系统的，你就很容易明白，我们现在处的信用社会就是信用社会。为什么呢？这就是昨天课程里讲的，社会颗粒度的问题。

个体信用和整体粒度之间存在极强的正相关性，个体很模糊，没有个体很细碎的社会，是不存人个体信用化的。

那说到个人的信用体系，美国在这方面是值得参考的。有两个原因，第一，他们的是用系统个人主义；第二，他们的信息技术的发展一直在点前行。这使得美国的金融粒度相对与我来说一直处于很小。

尤其是从上个世纪60年代的信息化革命以来，美国社会对于个人的数字化记录一直很强，每个的社保、医保、养老、医疗，甚至到警探使用比较完整的数字记录。通过对这些数字记录的整理和分析，你可以根据一定的算法，计算出一个人的信用分。

美国有好几家这样的个人信用分数计算机构，其中影响最大的是FICO分。在美国生活的同学你多知道，这个FICO分对于个人来说是一个很重要的信用指标，相当于你的信用画像。分数低了，可能申请贷款时会有麻烦；FICO分数高，贷款不仅容易，还可能便宜到有利率。

我工作的时也会碰到类似的情况，比如华尔街的金融机构就会看着你的FICO分，如果低于一定分数，你是没有办法拿到金融机构的offer的。

所以，在美国，个人信用的资产化一直做得比较好。这也是美国普通人比较信用制度的基础。因为他们知道，个人的行为会转成信用资产，和自己的生活息息相关。

所以，每次我听到别人说，美国人更讲信用，中国人缺乏信用意识的时候，我都特别想说一句，错，不是国民性问题，是制度和技术问题。

# 二、中国信用社会的弯道超车

没错，就是制度和技术问题。

制度问题我们前面讲比较多，三等、制度、国家、单位，干年以来的信用体系向来是以机构为主体的，个人是看不见。

你说一下，我们是很不崇尚集体主义，也可明白这一点。这也是昨天我到的，中国社会的颗粒度一直很低。
