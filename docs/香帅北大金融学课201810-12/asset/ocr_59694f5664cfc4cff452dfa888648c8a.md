# # 226 | 理解“蚂蚁金服”关键词之一：数据驱动

你好，欢迎来到唐帅的北大金融课。

上周我带你看了科技金融的全貌，了解了它的颠覆性影响，还有它的弊端。我相信你已经对科技金融有了一些整体性的认识。那么这周的课程，我们要换一个视角，从一个代表性的企业入手，来理解这个领域的特点和潜力。

今天要讲的是蚂蚁金服。我一直觉得，如果要正确理解科技金融，把蚂蚁金服搞清楚是个非常重要的突破口。

# ## 一、新物种：蚂蚁金服

我不知道有多少人知道蚂蚁金服，但是我猜一定没有人不知道支付宝。你要知道，支付宝不是阿里巴巴，而是蚂蚁金服旗下的产品。

蚂蚁金服是阿里巴巴的炼体企业，也是阿里系里面衍生出来的一头超级独角象企业。它的估值是多少呢？是Uber加滴滴的估值的总和。你熟悉的阿里系金融产品，支付宝、余额宝、蚂蚁花呗、相互宝、芝麻信用，全部都是在它旗下的。这个企业在科技金融领域具有标杆性的地位。

第一，它的业态之复杂，产品之丰富和演化之动态，特别地具有科技金融这个新物种的特征。

第二，它已经具有一个超级大国的规模。比如说在全球的科技金融企业排行榜上，连续三年排第一的位置，而且相当于后面几百家企业估值的总和。

第三个企业比较敏感，因为我从2015年开始研究它，跑了多次杭州，和很多高管、员工交谈，这几年积攒了儿十万的笔记和资料。最后发现它是一个特别有学习价值的对象，它跟一般的互联网企业不太一样，它是处于一个快速试错、自我进化的物种。

注意我这个词：“物种”。

也就是说，它的变化不是预设的，而是数据驱动的自主进化。所以，你也没法设定边界，更不可能给它一个结论性的定义了。

其实，这也是科技金融这个领域现在的难点之一。

那么我们应该怎样理解这个企业呢？我想了好几年以后，觉得可以在FinTech这个大概念下，用一个词来对它进行定位，把它叫做“数据驱动的金融平台生态”。

“金融”很好理解，对吧？那么“数据驱动”和“平台生态”这两个词，则是它和传统金融机构的分野之处。

接下来的两天里，我会从“数据驱动”和“平台生态”这两个关键词入手，给你讲清蚂蚁金服，也把科技金融的核心特征讲清楚。

# ## 二、数据驱动

今天，我先讲数据驱动。蚂蚁金服做的是数据驱动的金融服务，传统金融机构是使用数据进行分析、决策的金融机构。

请注意我的用词，一个是“数据驱动”，一个是“使用数据”。这两者看上去有点像，却大相径庭。

我在直播课曾经给你举过一个例子，当时浙江有一家很不错的地方小银行，泰顺银行，它和蚂蚁金服一样，一直看中的是小微企业金融。泰顺是浙江省里很小的一块区域，人口少，银行规模也小，但是风险控制得比较好，坏账率很低。要知道，这相对于高风险的小微贷款来说，是很低的。

那么泰顺的经验是什么呢？它就是实地收集关于这些企业的一些信息。

比如说呢，要决定是不是给一个小商铺贷款，它会把派一个有经验的信贷员去蹲点，不是一天、两天，而是相连的一到三周时间，观察和记录商店的客流量、交易金额、服务态度，还有货架上的品种丰富度，然后根据这些数据，作出是否贷款、贷多少额度的决定。然后在贷款之后，信贷员还会跟踪这个商店生意的活跃程度，然后及时进行风险预警。

所以，你看，这就是典型的“使用数据进行分析，支持决策”的案例。

好，那么蚂蚁金服是怎么做小微企业金融服务的呢？它旗下的蚂蚁小贷就是干这个事的，但它的服务模式是很简捷的，比如像泰顺银行是有贷款需求了，就去收集数据作为判断。但是，当时淘宝小店有些什么生意记录呢？是因为当地商家有贷款需求，然后淘宝店家找银行合作，最后发现没法做，为什么呢？因为这些小店现金流太小，融资需求低，还没有抵押品，根据银行的技术来说，信用质量真是不好。那么就不太符合信贷体系的门槛。淘宝就自己开始琢磨一茬给这些小微企业贷款的流程。

那它的最大的武器是什么呢？就是数据。

我们知道，淘宝做的是电子商务，所以这么多年下来，淘宝家平台花下留了上所有的交易记录，像泰顺银行花上收集的那样流水、活跃度数据，对淘宝平台来说都是现成的数据，而且数据要丰富得多。所以，它就可以按照自己对这些店铺的理解，给它们贷款。

好了，最有意思的地方就在这里了。经过一段时间下去，淘宝发现行动变得有了。

传统金融机构的风控体系就是像保龄球里击打小球至倒瓶。

当时它发现，影响违约率有一个重要指标，旺旺的活跃度，就是店家响应买家的速度。长期“聊”的买家，尤其是女顾客，我们估计是已经上不上头了。也就是说，就在最典型的情况下，它会决定你贷款的多与少，这取决于店家的响应速度。

而且这个循环在这里还没结束，使用蚂蚁小贷企业的这些店铺的还款记录，甚至是其他银行的还款，数据也都留存在淘宝平台上，又成为大数据资源的一部分，进入蚂蚁小贷的贷款模型。这些数据都是实时在线的数据，在模型中不断迭代，从而支持着后面的决策。

好了，现在我想你我已经发现了，这种模式和上面泰顺银行的那种信贷模型，看上去都使用了基础数据。但是，实质上很不一样，为什么？在这里，数据太主体，一贷款就是被确认下来，就像有了生命一般就是数据，不断自我喂养这个模型算法的生命体，然后让它越来越具有自主决策的能力，让数据说话，这才是数据驱动。

人在这个模型里的作用，主要是调试模型，优化算法。你既不参与数据的收集、整理，也不参与决策。

我再给你一个例子，比如保险。女生买东西的时候，经常会有退货率、退货险，这一点是明确的。有些“剁手”的，同学没有保险，则有一个东西不能够很容易退掉，就会极大地降低你的购买意愿，对不？那么蚂蚁金服做的小贷保险就是针对这个来说的。因为商品不是每个人都会退货，也不是所有的商品都会退货，退货的难度也不一样。那么，其实这是个概率问题，说通俗一点保险是用于风险，它的意思是，同性的退货率上形成了新的数据，然后变成了一个决策闭环。

什么产品退货率高，高多少，男性还是女性要买退货多，哪个店家的退货率更高，哪个店的退货率高，甚至要退到多少，这下下来以后，保险公司可以变得极为精准和个性化。那么对于蚂蚁金服来说，风险也变得更低。

一旦模型算法被确立以后，覆盖和服务新增用户的成本变得极低，新增用户的数据就沉淀下来，就变成这个数据驱动决策闭环中的一环。

我们日常使用的蚂蚁花呗、蚂蚁信用，背后的逻辑都是一样的，是数据驱动的金融服务。

# ## 三、对传统金融模式的降维打击

说到这里的时，我想你可以明白了，所谓数据驱动，并不是简单地收数据和用数据，在这个语境下数据是基础，但更重要的是流动和互动，也就是数据得活起来，而不是存在硬盘里的一串串数字。
