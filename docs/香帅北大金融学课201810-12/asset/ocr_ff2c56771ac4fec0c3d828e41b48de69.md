# 一、南海泡沫：英国的金融创新、监管和危机

为了讲清楚它们之间的关系，我们从一个同学们很熟悉的金融危机，英国的南海泡沫开始说起。

在18世纪的时候，英国的财政部长，当时是乔治·格雷厄姆，搞了一个南海公司来帮英国贸易。当时，英国财政部长的一项举措是还债。打完英法战争之后，英国的政府买了巨额国债，这个时候就有人想出了办法，让南海公司来搞一次债股的金融创新。

那他们的这个债转股是怎么搞的呢？南海公司帮英国政府900多万的英国本国债转换成英联邦，这样一来，原来债的债权人就变成了南海公司的股东，由南海公司负责向股东支付股息。

通过这个债转股的金融创新，把英国政府从这个债务里面就解放出来了，另一方面，另一方面，你就把它解放关系那种风险共担、利益共享的股权关系，也就是说，其实对企业约束是更少的。

这种金融创新本来不是坏事情，但问题是，这个金融创新算是成功吗？英国政府不忙了，所以，一方面政府授予的南海公司很多的特权，比如说南海商权、交易权、发行权等，另一方面，由政府和南海公司利益绑定在一起，那很多人就开始利用信用发行，给南海公司的股票进行概念炒作。

说到概念炒作，我想，美国人股市就是最热衷不过的了，比如说，美国公司是不持有尚未发行的货币股票，公司上市了，这个时候会出各种各样的小道消息，说的消息，像推特、雷普奇等发现了很多的谣言，然后，通知各方都在争夺，这种小道消息尤其更容易传播，所以，就一下子就被炒得火热，南海公司的股价就开始飞涨，到了一两年的时间内，上涨了十几倍，到了1160多英镑。

18世纪初的1000多英镑，是什么概念呢？粗准估算一下，相当于现在的30万英镑。整个英国一下子为之疯狂了，像英国国王，还有著名的科学家牛顿，都陷入了股票致富的梦想里面。当时，南海公司就达到了一级水准的地步。
