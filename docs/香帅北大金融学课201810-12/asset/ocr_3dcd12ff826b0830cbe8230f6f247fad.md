# 240 | 本周问答：支付宝推出的“相互保”，是区块链应用吗？

你好，欢迎来到香帅的北大金融课。

又到了我们一周的问答时间。这一周问题挺多的，所以，我给你们挑了几个我觉得比较有意思的问题来答。

+   - 第一个问题是，蚂蚁金服的“相互保”不是区块链保险吗？
- 第二个问题是，关于区块链的技术基础问题。
- 第三个问题是，在现在的大数据时代，哪一种数据含金量最高？

老师，想请教一个问题，为什么蚂蚁金服的相互保可以做叫做区块链保险，是因为一人理赔，大家分摊吗？

没有将来：
支付宝出了一个新产品，相互保。做的宣传是蚂蚁区块链。我知道这算是一种区块链技术的应用吗？

香帅：
这个问题挺有意思的。“相互保”是蚂蚁金服在2018年推出的一款大病互助计划。在我看来，它更像是一个互助合作基金，只不过这个基金针对的是某种特殊病理情况，包括恶性肿瘤在内的大病。还有就是一些病种的门槛比较高。

我们很多人都会这个经历，平时好像也不怎么缺钱，但是一遇到大事，就容易缺钱，特别是生大病，花起钱就跟流水似的。有时候确实是一笔钱就砸死英雄汉。

跟你举个例子，两毛钱都一个说法，有人说在有钱买药，专门花100元左右，那是低的额度，但你知不知道很多大病，住院的人，有时候真的就是那么一点点钱，实在是没有钱。

你知道这种贷款的利息是多少？180%。据说这还是良心价，高的时候能够到300%。

所以说，相互保就是针对这种大病缺钱的情况来的。

我看了一下，网上有很多帖子讨论这个事情。但是他们的把它讨论得挺复杂的。其实这个机制挺简单，我们用我们生活中的场景来举个例子。

现在支付宝来当群主，开设了一个微信群，叫“相互保”。它先被补了一下马化腾和马文杰的色...总之不容易。我们就让支付宝群主来开一个微信群。有支付宝APP的用户，每个用户都有一个芝麻信用分。你的分数在650以上，60岁以下，就可以申请加入这个相互保的群。加入这个群是不花钱的。

加入这个群以后，你就自动获得了一个权限，就可以说万一你生大病，这个大病有一张很长的单子，包括恶性肿瘤在内的100种，只要你查到这种病，你群里的人，就可以拿到一笔保障金。

那这个群每个人每个月都有可能生大病，那么大的钱，就把医院诊断的信息全部公开在群里，然后通知大家。

那支付宝作为群主，它的职责是什么呢？收集验证这些人的医院诊断信息，然后发放保障金给这些人。

这个群的人要付钱，保障金从哪来？就是这的群的人一块儿分摊。群主这么辛苦干这些活，又花精力，又花时间，还能得到10%的管理费。这就是相互保险的模式。

这个群也很剔的，比如这一期你分摊完了，你说这个模式不好玩，你退群就可以了。

你看，这不就是我们小时候听到的互助差不多嘛，一人有难，大家分掉，就这么简单。

可是现在问题来了，我们十几个人小群，大家都认识，有信任。支付宝这种群可可是上百万，甚至千万人，这里边有许骗得多，再说到多人的信息，我们哪里看得到来？我又怎么知道支付宝的付钱给谁的人？还有，你生病了，你还少会愿意把，也不愿意自己的信息给全公开吧？

好了，现在就可以引入区块链技术了，大家都上链，每次确诊的信息通过区块链公开给全群发布。

这些信息都是加密的，所以，链上的人只知道，有一个人，两个人，或者五个人确诊了，但是并不知道是谁，这样就保护了个人隐私。

每期分摊的金额，计算这些信息上，的过程，信息，在所有人的账本上记录下来，不再更改。这样省得大家担心支付宝作为中心的机构，是不是会贪污挪用，克扣我们的钱。

你看，这样就实现了保险上的去中心化，等于把保险这个杨桃黑盒子给打开了。所以，这确实是区块链技术的应用在健康医疗领域的应用。

我两天有个新闻，说的是一个几岁的女孩两，她父母间的相互保正好给她，她赔了个30万。可以，这一期加入相互保的每个人拿出3分钱。

我这个人还是喜欢个应用场景，的感觉挺sexy的，但是，我们也要看到，这笔账只是一个尝试性的应用，效果怎么样，其实也需要验证。

比如，网上就有帖子讨论说，里面逆向选择的问题难以完全解决。很多人知道自己出问题的概率大，才加入这个相互保组织的。这样，最后就得降低分摊的成本可能比较高，失去了公平分配的可能性。很多人可能会退出，使得这个模式不能持续。所以，这一点我们还存有观察。

另外一个问题，是效率问题。目前上链的成本是比较高，不一定比中心化的机构来做更有效率。

不过就像我在课程里说的，技术的落地应用需要一个非常漫长的过程建设，所以，我们要有一点耐心，也需要有更多的专业的大型机构，再投入人才、资本来布局未来。

Rebecca：
老师，你说区块链能让信息更透明，可透明度，意思就是降低信息不对称。那商品交易利用区块链，二手车市场、农产品交易领域会吗？还有，如果很大一部分人不知区块链，比如说贫困地区、贫困国家，那未来会不会变成发达国家和发展中国家的游戏呢？

香帅：
他的问题其实是两个问题。咱们先说第一个问题。

降低信息不对称，这是人类社会一直在努力争取的事情。做好市场机制设计，让市场更完美，都是为这件事而努力的。

供需的调节，利用供需，一定会倒逼供给者更优，让买家得到更好的，更有意思的产品。人类就是这样进步的。所以，不用担心这一点。

第二个，区块链技术会不会带来更不平等的？这倒真是有意思的问题。

我也想过类似的问题，但是，我觉得我们太担心，互联网出来的时候，我们也是担心互联网，是技术的使用会使世界变弱、越来越友好，让普通人也能使用。

你要知道，相机最早的时候就是标准的高科技，后来就变成了“傻瓜相机”，谁都能用，对吧？

80年代用计算机还要使用编程，现在的界面就是基本上识字就能用。

区块链，我想也不会例外。现在，还是少的人才能用，但是想到未来需要让更多人能用的。
