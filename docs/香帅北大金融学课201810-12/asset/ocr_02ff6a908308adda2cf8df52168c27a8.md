# 201 | 股权激励机制有用吗?

你好，欢迎来到眷待的北大金融课。上周我们讲的是治理问题，这一周讲几个解决治理问题的重要制度。

今天 要讲的是股权激励制度，这个制度和你们平时听到的CEO们的巨额财富是密切相关的。

比如说吧，2017年，美国CEO收入最高的10位，平均薪金大概是3000万美金，也就是2亿人民币一年的薪水。但你知道吗？这2亿人民币，其实不是那种到年终就进你口袋里的钱，大概是50%到90%不等，都来自长期的股权激励。

股权激励计划就是上一个世纪60年代开始兴起的，它主要是管理层持股，股票，或者股票期权。 这是是想让他们和股东的利益更加相同。这个制度安排被很多学者，尤其是我们商学院里面的一些认为是解决管理层和股东同床异梦代理问题的良药。

而且从全球范围来看，这也是一种通用的企业激励人才的办法。但是也不所有的人都对股权激励计划很好看，像巴菲特就看了当时说，股权激励计划只是富了高管的腰包，但没有真正地提高公司的业绩水平。

还有很多的企业家也对股权激励计划提出很激烈的批评。

那么这些针锋相对的观点，到底谁对谁错？今天的课程里我就来回答，股权激励计划的利弊到底在什么地方。

# 一、股权激励之弊端

好，在回答这个问题之前，我们先把股权激励计划的具体含义搞清楚，就像我刚才说的，它在一个人上个世纪60年代以后出的新兴的，70年代之后，美国股权分出的趋势越来越严重，所有权和控制权分离了。这个时候，职业经理人和股东之间就出现了很大的代理问题。

比如说有的管理层挥舞着公司利润，还有的管理层为了满 足自己的私利，浪费投资人的钱，进行很多低效的投资。

那为了控制这些问题，学界也好，业界也好，首先考虑的就是，怎么让管理层中和股东的利益一致，而且要事前的合同中来安排。方法主要有两种，第一种是在所有权上，去赋予管理层一定的股票，这就股票激励。或者说在一定的条件下，给管理层以某个价位，买入一定数量公司股票的权利，这就是股票期权。

你看这两种方式，目都都是扩大管理层的股权，希望他们的收入和企业长期成长之间挂钩，所以被称为股权激励计划。
