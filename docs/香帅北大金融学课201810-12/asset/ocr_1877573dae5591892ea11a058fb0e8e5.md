# 十年以来最具有前瞻性的
诺奖：用经济学科模型量化未来 | 2018诺贝尔经济学奖解读

2018年10月8日下午，诺贝尔奖委员会宣布了今年的诺贝尔经济学奖得主：

威廉·诺德豪斯（William Nordhaus），美国经济学家，77岁，耶鲁大学

保罗·罗默（Paul Romer），美国经济学家，63岁，纽约大学

一般人可能会认为这次奖项是颁发给“发展经济学”（Romer）和“环境经济学”（Nordous）的。这种理解不深入，但是远远低估了评奖委员会思想的深度。

我个人认为，今年的经济学诺奖是过去10年最具有前瞻性和思想性的（经济学）诺奖，也是两位这对时代未来发展面临的巨大转变所作出的一个回应。

极简地说，这两位的研究可以用3个词语来概括：经济增长，知识创新，气候变化。其中经济增长是目标函数，知识创新和气候变化是具有外部性的内生变量。

这句话怎么理解呢？

我们先看一下“经济学是研究什么的学科？”对于这个问题，可能有无数种解释，但是有两个命题是永恒的：一个是“增长”，一个是“分配”。没有增长就没有任何分配，而是提高分配的效率。人类最关心的是怎么样才能使得持续的增长？比如说，如何创造更多的财富？

其实在人类漫长的历史上，“增长”并不是常有的。

![](bbox=[0.08, 0.56, 0.92, 0.68])

从上图中我们会看到在过去的2000年中，人类经济增长几乎是一个缓慢的增长，在前面的1800年里，人类经济增长几乎是一条水平线，到18世纪末也就是工业革命之后，这条线就出现了“快速”增长，再到了20世纪50、60年代，也就是计算机和互联网为代表的信息革命革命之后，这条曲线再次跳跃，变成了一根几乎是垂直上升的直线，也就是说人类经济增长呈现出爆发式的几何级数的增长。

比如说，公元后的前1700年总共增长了3倍，从1700到1940年，这200多年增长了10倍，而从1950年开始到的70年，又增长了10多倍。

没错，人类摆脱极度贫困仅仅仅200、300的历史，衣食无忧也不过160、70年的历史，所以沉迷于游戏的学生可以断一下这句话，因为穿越到公元200，70年的衣食无忧是今天的人类根本无法想象的。

那么除了庆幸自己生活在当下以外，这些数据还告诉我们一些基本事实，并且得出一些关于我们未来的推论。
