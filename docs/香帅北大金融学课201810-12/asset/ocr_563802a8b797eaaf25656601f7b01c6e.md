# # 203｜独立董事到底是花瓶还是宝剑？



你好，欢迎来到香帅的北大金融课。

2018年，华尔街有几个大新闻都和一个概念有关——独立董事。

苹果的CEO库克变成花轿了，但是他还有几份工作要做，他要做微软公司的首席独立董事。Uber的独立董事席，是星巴克的灵魂人物霍华德·舒尔茨也决定要退出了，而将掌管这个伽利帝国的是星巴克原來的首席独立董事谢乐·乌尔曼。

这么看上去，独立董事其实在美国的资本市场是一个非常重要的存在。美国证监会（SEC）、交易所对还有各种相关的法案，都要对美国和上市公司的董事会中，独立董事的比例要点到制约多数。绝对多数就是11个人的董事会，独立董事的下限是6个。另外，董事事的新聘委员、审计委员、薪资委员会都是独立董事构成。在监管的里，独立董事的数量和质量被视为一个公司治理结构的重要因素。

第一，独立董事到底对公司治理有什么影响？ 好处局限到什么地步呢？第二，我们要怎么看待中国公司的独立董事？ 在今天课程里，我们要把这两个问题给弄清楚。

# ## 一、独立董事制度

“独立董事”这个名词，我想你肯定听说了。它其实就是指和公司没有利益关联的董事，例如利益关联就是担任公司职务，和公司有关联交易，甚至和公司管理有亲属关系等等，都叫关联。

这个制度是怎么来的呢？最早是30年代的时候，美国金融市场环境监管，要求对管理层或者控股股东损害中小股东的利益，所以要求公司的事董事会要有40%以上的外部人士，即和公司无关的人作为独立的外部监督。其实从这个时候开始，一个董事会就分两块：一块是内部的管理人员，另一块就是外部的独立董事。

我们说过，到70年代以后，美国公司的股权越来越分散了。这些管理层，也就是内部人的势力就越来越大，这样就越来越需要对公司控制人的权力加以制约。这个时候，独立董事的制度就成为一个解决方案，受到了市场的一度推崇。大家就开始逐渐地把独立董事制度作为一个特别重要的公司治理机制，希望这些外部的独立董事能够站在中小股东的立场上，替代他们监督管理层的动向，包括投资决策、财务报表等等。这个政策在美国推行得特别地快，而且推行得特别广。比如说到2000年的时候，美国大企业董事会，董事数的平均规模是11个人，独立董事数目的是多少呢？占到了80%以上。

那这个独立董事到底有没有起到监督管理层的效果呢？美国有很多研究，认为由于声誉机制的影响，它取得了不错的效果。

什么叫“声誉机制”呢？最开始搞的这些独立董事社会上有头有脸的人，而美国法律违法又更多处罚，他们一不小心就可能被诉讼，说你和受害人企业共谋伤害中小投资者，那些有头有脸的独董们爱惜“羽毛”，所以这个独董通常会在重大问题对管理层进行约束。最重要的就是两条：

+   1.  警示作用
    第一个是警示作用。一个独董如果对公司的问题公告了否决或者有保留的负面意见，甚至直接辞职，投资者就能够从这些信息中知道公司外部出了比较大的麻烦。
    很多研究发现，一个公司如果独立董事越多，公司治理的指标就越好，而且CEO的新酬也相会发放的比较低难。

你想这个也合理，比如说一个CEO要提点私利，那都必须把这件事提交董事会去决。一个两个独董说好，但是你要搞很多，比如说11个人里面你要搞定7、8、9个人，这个成功的概率就很小了。如果外人本来就比较多的情况下，内部控制人作弊的成本也比较高。

+   2.  监督作用
    另外，美国的很多独立董事都是很有发表意见的，他们经常会公司的决策提出质疑或者保留意见质疑监督。所以由一定程度上，对公司起到了监督作用。我们可以看到，这个制度在美国起到了一定的效果。

# ## 二、独立董事的局限

另外一方面，你也要看到，任何一个制度都有自己的很大的限制。实际上独董也难道说有一个很完美的解决方案，它也有自己的局限性。

像巴菲特就屡屡质疑独立董事的独立性，他说如果一个人为收入的20%、30%都靠50%，要么来源于你大量的报酬，要么这会影响到别人的独立性，尤其是当他们的总收入水平并不高的时候。

这里面有两层意思：

+       - 第一，独董是谁选出来的呢？是董事会。你去从商业的角度来说，董事会一般会去挑选那些自己熟悉的，或者说得上去的人，所以独立董事不独立的概率也是很高的。

+       - 第二，独董最开始是各大公司的CEO、名人的商科教授、律师等人。后来上市公司的目标越来越多，多到后来连律师都不够用了，就开始有一些人来兼好几家公司，有名称的人都不愿意兼小公司独董，所以公司的独董数量就下降。这又出现了其他的代理问题。

比如说一个人时间精力有限，你怎么可能说那么多时间在监督管理层上？再比如说，像霍华德·舒尔茨这个职位的人的収入有大概一大部分来自某个职位的时候，收入人的利益关系，人怎么独立起来？所以巴菲特说，必须是在独董拿不超过30%的人收入的时候，比说靠职业来独立起来，比如说要靠职业来赚钱的决的更多的要求，比如说要对职业上的决的更多的要求，比如要作出一定的承诺。

整体上从这两方面看来以后你会发现，美国全成对独董制度是很满意的。所以，作为一种对冲股权分权化的制衡安排，它有一定作用的。但是这些年随着独董数目的增多，利益冲突变大，这个制度有效性有多少也是值得商榷的问题。

# ## 三、中国独立董事的尴尬

好了，说了美国的情况，可能很多同学会更关心，中国的情况是不是这样？特有特殊性，我们不能强迫独董这个制度来判断公司治理的好坏，我中国大概的2000年以后才开始推行独董制度的，当时的目标也是希望加强公司治理，但是理想丰满，现实骨感。中国市场的特点导致公司治理很复杂。

市场上有个笑话，说中国的独立董事有两个诀窍：一是要“懂事”，就是识趣的意思；二是如果不独立，什么叫不独立？就是现实中独董从来没有发表过任何否意见，基本上沦为一个摆设的花瓶。这是什么呢？

第一，中国是一个股权高度集中的市场，所以控股股东股东的强势控制中，一般都倾向于找和自己声音一致的独董事。所以这种情况下，独董就沦为了花瓶的角色。

第二，咱们中国是个人社会，它缺乏声誉机制。你看，街上碰到男人打女人经常有人说，哎呀，人家的事，别管了。呵呵，独董是个公司的事，人从本质上来说监督企业的动力。再说了，因为没有公开的独董事的市场，所作使没有行使监督力，也不会对自己的名誉有什么损害。

第三，就是利益牵扯大。中国的独董中高校教授占上流，所以很多独董给自己人的薪水比较低有限的，而上市公司独董新酬要求是0.9万、9元，而大部分人都会把它当作副业。在市场上你会发现一个教授本身做独董，几事就太多了。当靠独董收益作为主要收入来源的时候，你很难期望什么专业，目前独董什么实质性的监督效果。我目前的环境来看独董制度来看公司治理的好坏，我觉得不是特别靠谱。

那独董制度是不是在中国市场就没有好处了？当然也不是，我觉得它的好处就是……
