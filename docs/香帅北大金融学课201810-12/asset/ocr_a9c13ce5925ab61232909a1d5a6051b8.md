# ## 今日概要：

+   1.金融创新在很多时候，其实是和监管的博弈中倒逼出来的。资产证券化、货币基金、垃圾债券、掉期利率等等，都是如此。

2.金融创新不能用简单的好和坏来形容，一方面金融创新使我们整个市场更加紧密地联系在一起，资金的使用也更加有效率。但另外一方面，金融创新总是在那些监管没有覆盖到的边缘地区巧妙突破，野蛮生长，也造成了很多让我们困惑的问题。

今天的课后想给你留一道更加思维更广的思考题：著名的经济学家熊彼特说，创新就是毁灭式创造。所以，破坏和创造，其实永远是一体两面的事情。你也会发现，这条规律在金融创新上是完完全全一致的。它给我们带来的好处，创造力，和它给我们带来的困惑，破坏力，都是一体两面的事情。

在我们生活中，其实也有很多这样的例子。所以我想请你结合今天和我们以前学到的课程，仔细想一下熊彼特的这句话，创新，就是毁灭式的创造。能不能在你自己的身边举出创新和监管进行博弈的例子，或者说创新就是毁灭式创造，这种破坏和创造一体两面的例子。我想你举出了这个例子以后，你就会对金融创新和监管的博弈更加理解，也对创新的本质有更深入的理解。
