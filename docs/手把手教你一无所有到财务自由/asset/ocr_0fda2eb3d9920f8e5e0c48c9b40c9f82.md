那是新团队刚组建不久，为了尽快打开市场，我把所有的业务人员分成了三个业务小组，每个小组大概 7 个人，我要求他们，在传统销售模式的基础上，每个小组必须要去尝试非传统的销售渠道，至于具体是什么渠道，自己琢磨试验、自己去找办法（当然，是在一定基本行为规范的前提下自由发挥了）。

3 个月的考核期，哪个小组在非传统渠道之外的渠道取得最好的成绩，哪个小组胜出，然后再在这个胜出小组的 7 个人中统计排名，第一名直接越级升为营销主管，第二名到第四名分别任这 3 个业务小组的组长，如果能在接下来的 3 个月排名也为该小组第一名，则升为销售经理。

至于我后期的晋升制度就与本话题无关了，不做详细介绍。

这是在干嘛？这是让每个人在团队合作中有竞争意识，最大程度地发挥每个人的主观能动性。

知道 3 个月考核期结束的情况如何吗？

结果让我始一大，给我带来了很大的震撼。

他们竟然意外地尝试了很很多不同的渠道，很多连我想都没想到，更不敢尝试的东西，最后效果最好的渠道也是我从没有想到过的，真是不可思议，就算再给我几个月时间让我去想破脑袋我估计也绝想不出来。

这个时候，是你说，会怎样继续开展公司的业务呢？
