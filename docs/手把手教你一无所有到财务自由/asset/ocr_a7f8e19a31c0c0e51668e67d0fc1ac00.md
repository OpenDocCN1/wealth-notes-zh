# 三怎样与供应商打交道？

+   1.  退换货相对容易。

+   2.  不会一段时间没拿货，把市场上的旧款拿回来了

+   3.  拖拖欠欠，以后好见面。加大营运资本。

+   4.  不要把钱都丢在路费上了。你不时可以要求供应商发较给你，宁可电话拿货。

+   1.  有实力。不要怕辛苦，见到缝纫机，才考虑长期合作。这是意大利商人的铁律。

+   2.  有道德的公司
