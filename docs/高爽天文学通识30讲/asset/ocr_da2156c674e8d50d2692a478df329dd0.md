# **16｜木星：为生命带来了可能性**

大家好，欢迎来到《天文宇宙30讲》，我是高爽。

在太阳系里还有一个行星是一定要看懂讲一下，那就是木星。

要说木星最直接的特点呢，就是大了。的确是啊，它真的是太阳系里最大的行星。拿我们地球和木星对比的话，木星是篮球，地球就是一颗豌豆。

不过如果它是大的话，只能算是特点吧。如果不放大到我们有什么意思吧。如果仅仅是这样的话，我是不会单独拿出来讲的。

在我心中，木星最重要的是，它为生命带来了更多的可能性。至少有三个方面，分别是离开太阳系的可能，研究太阳系早期的可能，以及最重要的，生命存在的可能。

为什么这么说呢？我们一个个地来介绍。

# **1**

2019年春节上映的电影《流浪地球》里有这样一句台词：太阳即将毁灭，人类在地球上的装备了发动机，推动地球离开太阳系去新的家园。但是在逃离的过程中遇到了木星的强大引力，差点就吸了进去。

不知道你有没有看这部《天空这么大？》过呢？甚至还会认为这是电影的bug，不合理。其实这个完全是没问题的，要想逃离太阳系的话，木星是一定要借助的引力。

因为借助引力弹弓的原理，不需要任何燃料的能量，可以获得的更快的速度。它想的木星里，在太阳系里的速度快到惊人，这个功能如果我们的飞船借到它就不得了。引力弹弓其实就是飞船在探测器里利用木星的动能，它们的速度会大大增加，就是因为被木星给弹走了。

当然了，并不是发射的，撞上就，而是出去。引力，撞击木星就是一撞就出去，这就相当于被弹出了。

你可不要小看木星的加速度。木星的公转速度可以秒到每公里13公里，3秒，以3秒可以一秒钟到13公里，只要3秒，就可以在北京到上海之间来回一次。

这是它的引力弹弓，帮助它的速度。经历了一次大引力弹弓，其实就是相当于进行了一场小型火箭的加速。

就比如说在人类最快的设备“旅行者1号”，它是1977年发射的，到达木星的边缘速度只有13公里/秒左右，但是木星的引力弹弓加速后，可以到达23公里/秒了。如果说离开引力弹弓，只要发射力达到同样的效果，别说80多年前了，就是我们现在的科技水平都很困难。

既然有这样一个免费的速递工具，不用也不用，这几乎要了我们的头去太阳系外发探探测器的效率，2006年发射的“新视野号”，也是借助了木星的引力弹弓效应，才能在2015年到达冥王星。

这也是我为什么说木星是我们离开太阳系提供了可能的原因。当然了，如果是探测器，也能帮助我们。除了你，如果不利用木星，也可以利用其它行星，甚至利用地球。

但是如果你像《流浪地球》里演的样子，要带走一整个地球，那就一定是非它莫属。要想地球，引力弹弓增加的速度不是全空的，它不是全空的。探测器增加的那些全用于行星的速度，太微不足了，所以它得忽略，但是如果能足够强大的，地球的话就是它，也只有木星这样的巨行星才能把地球推飞了。

所以你，因为木星的存在，为我们离开太阳系降低了门槛，如果我们有一天真的必须逃离太阳系，我们一定会感谢有木星存在的。

# **2**

这是木星带来的第二个可能性，就是第二个可能性。木星可以帮助我们的了解到太阳系诞生的早期都发生了什么。

为什么会这么说？需要我们先知道一件事，那就是越大的行星，需要的时间越早。其实这个也容易理解，在太阳系刚诞生的时候，各处的物质密度其实是差不多的。所以，先诞生的行星能有多多的吸积物质。木星是行星里最大的，这代表了，木星内部可能还保留着太阳系诞生之初的遗迹。

其实，太阳系里最大的天体是太阳，但是太阳系了，根本没有没办法着研究。那什么太阳太热了，在内部没有温度梯度，和大气运动就全熄灭了。所以，木星就是首选，没有其他。
