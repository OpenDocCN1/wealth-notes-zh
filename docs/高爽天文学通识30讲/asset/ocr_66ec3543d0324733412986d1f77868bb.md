# 21|超新星：星系间的灯塔

你好，欢迎来到《天文学通识》，我是高夔。

前面几讲我一直是把恒星当做一个统一的群体，从整体上去看它们的特点和规律。这一讲，我们特别来把恒星中的一类特殊段落拿出来讲一下，那就是超新星。超新星不论对天文学还是对我们人类生存都非常重要。

# 1

“为什么这么说呢？别急，我先介绍一下什么是超新星。其实它并不是某一类具体的恒星，而是恒星的一个特殊阶段，而且也不是所有恒星都会经历这个阶段。只有满足了特定条件的恒星才有可能经历这个阶段。”

超新星这个名字呢，其实是从超“新星”这个，字面上的意思就是超级亮度的意思。“新星”这个词啊，从古代就有了。当时的天文学家观测星空，会发现在某个地方忽然出现了一颗新的恒星，就像是新诞生了一颗恒星一样，所以叫做新星。

不过因为这种新诞生的新星不会一直有，一过几小时或几个月的时间就消失了，就像是夜空中的客人一样，所以也叫做客星。

我们现在都知道，这其实不是新星诞生，而是一颗恒星爆炸了。原本因为亮度不大，所以我们看不见，爆炸后忽然释放的光度，就像是新诞生了一颗恒星一样。

我国历史上就留下了一群新星出现的记录。最有名的就是公元1054年宋代记载的“客星”，其实我们现在的观测中，天文学家们能看到很多。它们与我们用望远镜看当前的肉眼可见的，这里还可以看到恒星爆炸的遗迹。

我在金文书中提供了一张非常明亮的蟹状星云的照片，非常不错，你可以打开文稿看一下。

后来现代天文学发展之后，天文学家发现，恒星是变量发生爆发的原因并不相同。其中有一种就是特别巨大，它一下释放的光度能超过一个太阳的几万倍。你想想象太阳要烧一万，大概100亿年才慢慢地释放能量，最后只能用到自己不到1%的质量，而这个爆炸会在几秒或几分钟的时间里面把整个太阳光度全部变成能量。这是一种情况，还有一种情况呢，虽然也是超新星爆发，但是释放的能量只有太阳质量的百分之几。

所以，天文学家就对超新星重新分类了，威力大的就叫做超新星，而威力小的就叫做新星。当然了，这里只是简单地拿来以大小的说明，其实本质上是说超新星和新星爆发的原理不同。其实，即便是超新星，也是分原发超新星的。不同。现在你只弄先了解到这么多，后面我还会再详细地介绍。

而这一讲要特别介绍一下超新星的原因，这也是因为它的威力巨大。因为威力巨大，所以我们能在很远的地方看到它们。

# 2

前面虽然也说了超新星能够在很短的时期内把一个银河系变得亮很多倍的亮度，有的时候可能更多，是好几倍的实际太阳光度。但是，你可能还是没有办法直接感受到这个威力有多大。如果星是从光度来谈的话，这个时候超新星就是可以亮到把整个星都照亮。

这一点就太重要了。不是比如说在银河系某一颗超新星会如何，而是在银河系外如果有一颗超新星爆发了，那对于天文学家来说就太重要了。这简直就是一艘联系星系的灯塔。

你要知道，我们能用望远镜观察到的恒星基本上都是银河系内的恒星。而其他星系的恒星，我们很难做到量出恒星的光度。银河系外的星星我们也叫做河外星系。

河外星系距离我们都非常远，就是最近的星系仙女星系，距离我们也有250万光年。仙女星系里差不多有1万亿颗恒星，但是它看起来也不过是一个斑点。在上确也放了一张伽利略望远镜拍的仙女星系的图片，不过你看到的，上面还有很多的恒星小亮点。这一切它们都属于银河系的，当在望远镜和仙女星系之间。

![](bbox=[0.35, 0.0017, 0.65, 0.00183])

所以，当银河系里面发生了一次超新星爆发，它的亮度会超过整个星系的亮度，这对我们研究银河系是非常难得的机会。

就好比，在2006年的时，天文学家在距离我们2亿3800万光年的星系里发现了一次超新星爆发。通过对这颗超新星的研究，可以确定，我们对超新星的模式至少在2亿3800万光年之外依然有效。如果我们不能新。这个文搞也提供了一个星系的照片，感兴趣的话可以去看一下。

# 3

不过它专门用—讲来讲超新星，并不只是因为它对我们人类证明了宇宙原理。它对天文的重要程度还要更大。

我们在第一章就讨论测量距离对天文学的重要程度。因为超新星是我们可以看到星是看见的。所以它也成了我们测量星系之间距离的重要手段。

还记得在介绍天文学中测量方法时，我讲一个标准烛光的方法吗？一个标准烛光就可以作为标准烛光，而且这个标准烛光可以跨越星系的。这个标准烛光呢，叫做IA型超新星，这里是罗马数字，也就是大写字母I。

超新星可以大致上分为两大类，一类是我们前面介绍过的，如果恒星的质量大于8个太阳下面就是快速爆炸，这样的快速明暗就会释放大量的能量，并且产生一系列的连结物，也就是新星产生的新星。

这是一类，还有一类，本来并不会发生超新星爆发，而是一颗白矮星。只不过这颗白矮星不是孤零零的，身边有一颗主序星伙伴，这颗主序星会一直从这颗白矮星处吸取物质。直到自己达到了它的钱德曼极限，也就是1.4倍太阳质量，电子简并力扛不住了，忽然崩塌，然后发生超新星爆发。

其实，IA型超新星爆发，就属于第二种。

其本，前期超新星爆发，是一颗白矮星从旁边的恒星吸取物质，但是它并不是过于了钱德曼卡梅极限，而是在白矮星表面发生了硅核素变反应。这个你了解了一下就好，不是这一讲的重点。

重点是，IA型超新星非常难缠。只要是IA型，那么其中的各种参数一样，好像是一个模子刻出来的一样，这样很难理解，因为白矮星的质量都慢慢增加的，而其中重要的就是它们的光度也一样。既然光度一样，那就成为已知的参考，如果知道了IA型超新星爆发，测量一下地球上看到它的亮度，就可以反推出来距离。

这样就能把星系的距离测量出来了。

2011年的诺贝尔物理学奖就发给3位天文学家，他们就是因为用IA型超新星对研究获得了这次诺贝尔奖。因为他们是通过对IA型超新星给出了宇宙“量”“标尺”，发现宇宙不只是在膨胀，而且还是在加速膨胀。

我们现在能够如此确信宇宙充满了暗能量，其实是因为他们的工作。因为没有存在暗能量才能解释为什么宇宙会加速膨胀，虽然在对宇宙能量量是什么我们还一无所知。

如果没有超新星，我们对宇宙的认识绝对不可能如此深刻。

# 4

天文学研究虽然超新星，但是我们并不希望超新星发生在离我们附近。根据计算，3000光年之内的超新星爆发，就可能影响到地球，给地球带来毁灭性的灾难。
