# 1

这个问题，我们平时是不会体会的。我们从来不会说某个天体是一颗巨石或者一座山。因为它们的质量和天体自己太相斥了。因为天体内部主要力是向外，天体是互相排斥的。

但是到了天体这种尺度，内部因为自身巨大的力产生巨大的压力，这个压力足以让恒星内部的各种元素被挤压在一起。但是恒星是一种极其稳定天体，原子核被压缩到一定密度后会发生核聚变，释放出巨大的能量。这个能量反过来会推动恒星内部向外运动。

所以一般恒星可以稳定地发光，是因为自身的引力和核聚变产生的辐射压达到一个动态平衡。

不过，我说的是一般情况，毕竟一颗恒星是不能靠核聚变提供能量的。一开始引力占优势，辐射压没有核聚变反应。所以说，这个恒星就不断坍缩，直到温度升高到核聚变的门槛，核聚变产生了，辐射压才起来。

那么一颗恒星的生命历程有哪些呢？先别急，我们首先介绍一下主序星的引力平衡。这里就是引力平衡点。这些恒星，我们天文学家取了一个专门的名字叫做主序星。为什么叫主序星呢？因为这些恒星是恒星的主序带，上节课程中已经介绍过了。它们可以被分为几类区域呢？

这看似是一个巧合，其实在背后是有道理的。

# 2

为什么这么说呢？前面提到引力平衡。

我们要把太阳拿来举例。引力与辐射压平衡的恒星就是主序星。引力让恒星塌缩，辐射压让恒星膨胀。当这两个力平衡的时候，恒星就稳定在主序带。如果燃料耗尽，引力占优势，恒星就会离开主序带。
