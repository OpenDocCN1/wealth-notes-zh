# 2：通过各种“测试”来解决，例如无理取闹等等。

这个也靠谱，但有副作用。

首先，每一次无理取闹，实际上都会增强对方“新鲜感”的衰减，*以至于你可能短期暂时获利，但中长期失利*。

由于你第一条很难完成，而对方的“新鲜感保持”除非能够远超常人，否则都是在一般区间波动，你无理取闹导致了新鲜感迅速降低，那么你常规时候获得的好处就只能减少。
