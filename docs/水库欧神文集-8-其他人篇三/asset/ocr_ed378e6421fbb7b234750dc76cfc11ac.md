# 四：外部干预有可能吗？

会有抗议，会有反对，但干预成功是几乎不可能的。

原因很简单，既然美国政府能够口无遮拦的说出门罗主义，那么意思就已经很明确了：现在的美洲计划是不可更改的，谁动用实质意义上的干预就是美国的直接敌人。现在美洲是美国的，插手这件事和侵略本土没有什么区别。

然后你觉得会有实质性的反对吗？不会的。不仅对委内瑞拉不会了，对古巴也要力度减小一—当然，不意味着这些国家吃亏了，事实上至少短期来看，美国打理后院的时候对远方的压力会减小。
