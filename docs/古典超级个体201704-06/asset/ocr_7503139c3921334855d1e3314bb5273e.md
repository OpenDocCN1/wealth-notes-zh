# 7步讲好一个故事

![](bbox=[0.13, 0.15, 0.87, 0.26])

在这个过程中，记得4点：

+   1. 一边问一边画，一边画一边解释。
2. 美不美不重要，太好看反而会妨碍对方拿起笔来参与。
3. 邀请对方也在你的画上画一笔，这幅画就变成“你们的”了，往往对方会开始站到你这边，开始维护这个结论。
4. 字要写得足够清晰、简洁——好像你真的在餐巾纸上写字一样，认认真真，简单几个字。大部分图表都是因为字迹模糊而被放弃的。
