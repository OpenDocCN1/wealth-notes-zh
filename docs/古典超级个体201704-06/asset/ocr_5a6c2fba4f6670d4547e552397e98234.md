# 成洁getit

回到上周预告留言的问题“有好多奇思妙想的小点子想写成小说，却从来没有写完”，我想自己找找原因，没掌握好套路，是写不好的一个障碍。这一点应该从增加输入开始。不要想着一下子写出哈利波特，从讲好一个故事开始。借鲍鱼缸的做法，第一步是要写出来，而不是让点子溜走。把我要写作为行动指南，不要总是用读者的眼光去看。

笔记：
写作要写出真情实感，从经历出发。
把小想法放到纸上，让它们自己玩耍一会会儿~会发生奇妙的事情。从自己的角度全心全意看待，不要持续评价。
要达到自我表达、升级思维和传播影响力，可以找到更适合自己的方式，写作是一个推荐选项但不是唯一选项，要从自己的需要出发。
