# 写作的思考

小时候，我们会专注于某个领域，如记叙散文，听到建立自己知识体系的好处，并开始践行；
再仔细想想，开始体会这句话的高明。鲜活证据是相对客观而稳定的，吸收提取而建立的体系，则结合了个 人具体的、一时一地的情境，自然是会随着时间崩塌的。这并不否定体系的意义，而是提醒我们要不拘泥于过去和成规，要终身学习、不断升级。

有人问：“如果让你写，关于自己的二十件小事情，你会写什么？”
我想了想：“和别人有趣的对话，思考，没了吧？”
我一直对生活中，那些让我发笑～、开脑洞～、扎心了～的那些对话、画面很敏感，坐车的时候我就要把让我发笑的拿出来想一想，然后对着车窗一个劲笑提不起劲了，就拿出别人夸我的话，使劲想自己怎么怎么棒
安慰人，就拿出曾经让我鼓舞的故事，讲给别人听
因为反复的想起，以至于，我非得写下来，才能感到安全，“嘿，总算不会忘记了”～
小卡片难道不是这样吗？这得是你充满感情的小卡片，也许你想起某张小卡片时，你还能感受到它的颜色，是黯思的紫，还是孩子气的柠檬黄，或者是在绝望中求永生的黑
有一次，那是一年之后，我把那张记录了很多小故事的小卡片给了故事里的主角一一我的朋友看，她后来跟我说“ 我看了不下十遍，一直在哭，也不知道哭什么 ”
也有人跟我说，“真的暖到我了”
也有人说，“我记得我看过，可是……再看一遍，感觉还是很好～”
这就是我理解的一张卡死代表的，印象、情绪、生命力

这让我想起了易中天老师写中华史采用的方法——填格子。灵感来源于侦探小说，因为某侦探把犯罪现场分成一些格子后，找线索的速度快了很多。
于是易中天老师用来找中华史的“线索”，是这个方法使他写作速度那么快。
后来，我自己把这种方法用来复习，填核心概念；用于三件事，把一张纸折成四部分，写三个可交付成果+小确幸。
最大的感悟是人好像天生就有把格子填满的冲动。
这个知识迁移的过程中，也让我感受到方法是相通的。
