# 写作的思考

# 时间之树

写作作为一种输出方式，能极大的提高学习效率。我自己的原则就是有输入就要有输出，输入可以是生活体验、工作经历、读过的书、看过的电影等，输出就是要形成自己的思考，以文字的形式讲给别人听。真正体验过的人都能感受到在此过程中的巨大收获。

对于写作，在工作中，我最多的写作机会是软件需求文档，生活中最多的写作机会是一些随笔。对于现在的写作热，我认为是国民整体进步的一种体现。随着信息的极大丰富，个人影响力传播的门槛降低，越来越多的人想要表达自己，使信息传播更加便捷和迅速，形成了一个良性循环。

# 黄睿涵

对于写作机会，我每天最多的写作机会应该就是读书写笔记。多数是以记录式的文字进行简单的 copy，paste。这也给我带来了极大的困扰。
即：看完一篇文章，继续向下思考，思考不下去，思考无法深入。

对于我的这一问题，我发现，只要不停的进行这一周文章的写作，一些你一开始想不到的点子便开始涌现。思考更加“深入”

对于写作热，我近期真的对这个话题进行了思考和提问。现在流行了知识创业，我们能够赶上吗？
同时，绝大多数人以吸粉，以赚钱为目的的创作，又有多少价值？

# 一拢如刃

“人并不是突然死去的，而是慢慢死去，因为我们活在自己的记忆中，而当这些记忆一点点消失，我们就在一点点死亡。”虽然我现在还很年轻，才27岁（害羞脸），但我其实在 我24岁的时候就想写自己的回忆录了，我的想法让朋友很是诧异，认为写回忆录是老人才能做的事儿。24岁的我去除年龄太小的那段不记事儿也已经有了20年的人生经历了，怎么就不能写呢。

人的记忆存储是有限的，也会更新迭代，一些发生在岁月中的幸福和痛苦都是那么宝贵，觉得都是美好，怎么能任其随风而逝呢。于是25岁的我开始写了，记录我与亲人之间发生的重要事儿，爱情的纠葛，阶段性的自白，现在回头看，我的回忆更加清晰，感觉自己也是个“很有故事的人”了。而 且这些回忆被我记录，被我再一次的加强记忆，我越来越觉得我的前段人生变得厚重，长度也被拉长了，非常棒的体验，我将继续写下去。

# SCO jessica娟

心里一直想着“写作对自己有这么多好处，赶紧行动吧”，但是 一直不起作用。为什么？直到看到老师说的父母记录孩子的幼年时期，才惊觉我从来没想过“记录女儿的成长”。每天都有趣事发生，每天女儿的成长都让我惊讶，而我竟然麻木了，任由这些记忆随着时间被遗忘……我可以从最简单的，为了记录而写作。

对于现在的写作热，说明有更多人认识到写作带来的好处并付诸实践，是好事。但如果 是抱着通过写作获得成功或者出名的目的来写作，比如公众号热，我认为时间会筛选出真正有料的作者。
