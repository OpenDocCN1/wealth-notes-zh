# 快乐学习每一天

开始写东西的时候，你最大的困扰是什么？看到这个问题，第一个出现在我脑海中的是：不知道怎么写。
虽然每天有看文章读书，但还是不清楚该从哪个角度来思考和输出，如果是很多人回答的问题，倒是可以看看大家讨论的共同点是什么，有没有被集体忽视的盲区。但更多的时候，还是自己独自写，而且也没有多少人看，缺乏交流和互动，也不知道自己的缺点在哪。
