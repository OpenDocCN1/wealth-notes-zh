昨天给大 家提了一个问题：
这半年，你个人学到的最重要 的事情是什么？

感谢罗胖、娘娘和专栏作者们第一时间给了大家他们的答案。评论区也收到不少精彩的回答，很大深度潜水用户被这个问题炸了出来，忍不住忆下了往昔，今天就把这些答案分享给大家：

# 罗振宇（罗辑思维创始人）

过去半年，我最大的收获，是找到了“第一性原理”和“概率权”这两个思考工具。

第一，找到了“第一性原理”，意味着我们做任何事情，有了一个基本的参照系，有了一个纾困工具。正如开车路上，眼睛要盯住前方某个目标，而不是手里的方向盘。过去半年，我团队的创业思路因此清晰了很多。

# 脱不花（罗辑思维联合创始人兼 CEO）

过去半年学到的最重要的是“终局思维”，研究其他人、其他行业甚至其他时代的经验教训，对终局做预判，然后反过来，今天最应该做什么。

# 刘润（《5分钟商学院》主理人）
