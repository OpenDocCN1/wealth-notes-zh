# 2. 糟糕的结尾

“嗯，时间到了，所以就此结束吧。”

这是糟糕结尾——首先显示出自己没控制好时间，也没提前设计，所以讲到哪算哪，其次还想暗示听众错过了后面要讲的精彩内容。

“最后，我想感谢我优秀的团队成员，他们是……还要感谢我所在的机构、主办方……”

先让自己的演讲变成值得骄傲的事吧！如果真要致敬，不如对观众表达。例如，“今天在场的都是非常棒的听众，希望你们能利用今天所学的方法，让自己的演讲更精彩！”

“未来充满挑战与机遇，在场的每一个人心534中心只要有未来，都能有所作为。让我们一起梦想，改变世界。”

假大空的升华一律不要。

“我要用这段视频来结束我的演讲，它可以概括我今天讲的内容。”

既然能概括，为啥不自己概括？再好的视频也是别人的。就好像你和谈恋爱的女孩表白一样，在最后关键时刻，你说我写了封信，让我同学来读给你听，他能表达我的爱。你觉得这个女孩会怎么想？

演讲结尾也有三板斧——“重复、升华、指示”：

# 重复

重复你在开头提出的值值点——说好要带我们看有趣的世界，实现了吗？好导游会做一个旅行回顾。

# 升华结尾

柴静的《穹顶之下》大家都看过，其实我印象最深反而是她在央视的一个主题为《认识的人，了解的事》活动上的5分钟演讲。演讲的最后一段，就是升华；

“一个国家是由一个个具体的人构成的，她由这些人创造，并且决定。只有一...（长引用）...我们才说我们有信心让明天更好。”

好的升华，就好像《阿甘正传》里面的羽毛，从一个人手里飘起来，升高，升高，看到整个世界和未来。

# 清晰地给指示

TED演讲《怎样用纸巾擦手》，只有5分钟，但给了一个清晰的指示，至今我还印象深刻——方法只有2个词：抖（shake）、折（fold），洗好手后先抖动十几下，然后拿起一张纸巾折叠，这样就可以无死角地把你的手擦干。

最后我也说个甜点吧——

准备这篇内容时，我正在帮某著名民间女权主义者修改演讲稿，我也跟她提到了这个峰终定律。结果她翻了一个白眼说——峰终定律果然很好啊——同样的道理，你们男性在那件事上，总认为时间越久越好，其实重点是峰值和终点。

所以，世界上的道理都是相通的。

听懂的，你是智慧的；听不懂的，你是纯洁的——能听到这里，都是好好学习的人。
