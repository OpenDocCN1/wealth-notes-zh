# 预告 | 清明节的 “生死课” 23-7

今天是清明假期 GNOME 第一天。这个假期你打算做什么？会不会去墓园为逝去的亲人扫墓？

清明节大概是少数几个不能祝你 “节日快乐” 的节日，但却是距离我们思考生死最近的一个节日。

所以，接下来，我将用一周的时间，专门和你聊聊 “生死” —— 这个特别值得思考的话题。

死亡就像一道刺眼的阳光，刺进我们的生命里。直视骄阳，不免带来痛苦，但是躲避也并不能让它消失。相反，即使不看，它也笼罩着我们的时时刻刻，甚至或明或暗地驱使着你的行为、选择。

死亡还像房间里的一头大象，可能在我们假装视而不见的时候，破坏我们的生活，直至后悔莫及。

所以，晚谈不如早谈。我们谈论死亡，正是为了以更丰富、更清醒的方式重返人生。

+   你想到过 “死” 吗？
你有没有死亡恐惧，或死亡焦虑？
该怎样面对亲友的重病？该不该告诉他们关于疾病的实情？
怎样有尊严地离开这个世界？
如何超越死亡，向死而生？

这都是我们在下周 “清明节特辑” 中，将要谈论的话题。
