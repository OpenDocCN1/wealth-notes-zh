# 写作的思考

Vikki(Феруза) 7

1、日常最多的写作机会是看书，定下的Islamic Reading Trip，每看完一本书就写一篇文章。书也分两种，一种是国家书（小说、记者记录、自传、历史等我都归类为某一国家的书籍），另一种是专业书，这种书里讲的都是建筑艺术与出土文物。看专业书耗费的精力特别大，因为里面不懂的、需要延展的，就会去查文献或者维基；但是坚持写作是一件趣事，让我内心感到平静与快乐。

2、对于“写作热”这件事，我把古典老师曾经在一二三四手知识里提到的一句话视为经典：真传一句 话，假传万卷书。所以我从来不看标题很吸引人的，非名人写的文章，绝大多数是四手知识，浪费时间。现在很多写作软件开通打赏功能，于是很多人标新立异，写文章、赚打赏，曾经在知乎上看过一篇有关如何提升点击率的文章，里面的招数和掠夺其实差不多。在我看来，写作本是做自己喜欢的一件事，为何要把他功利化呢？究竟是要哗众取宠，回家利用各种手段促成外在的这种虚荣心好呢？还是写一些东西让自己充实和踏实来的幸福好呢？

所以我一直在写文章，一直没有太多的点击率，我没有开通简书、知乎这样的平台。写的价值大的就投稿给一些知名和影响力的公众号、杂志，仅此而已。我喜欢的东西太小众，又不喜欢浮皮潦草的哗众取宠，所以没有太多的交换价值。但是在某一个专业领域里，难道写一两年就能有很大收获吗？我认为不会，坐冷板凳的时间还很长。也许将来有一天我的坚持不懈会让我在伊斯兰建筑艺术上有一席之地，但如果没有，我也并不遗憾，因为这些写作与学习，已经化为踏踏实实、沉甸甸的幸福融入到我生活的每一天了。

周泽 5

个人觉得三种文体对应三个阶段：
第一阶段-在青少年时期：喜欢写自我表达的文章，年轻，想表达自己；
第二阶段-刚参加工作：更多的是记录信息，整理信息、挖掘信息、提高认知；
第三阶段-有了 一定成就：逐渐从这些成就、失败与成功的经历中总结有影响力、有价值的文章。

那么问题来了，如果判断你的认知是成熟的？你要写的文章是有影响力、有价值的？
