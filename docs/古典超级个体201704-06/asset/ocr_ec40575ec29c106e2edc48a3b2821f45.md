# 奔跑吧！“施”代

2017.4.27

演讲开始的时候，紧张是非常很正常的事情一件事情。每个人都会有这样的经历。还记得高三语文老师每一节上课之前都有一个小练习，让我们每个同学在演讲讲台上讲一篇古文。然后不断地与同学互动。刚开始我上台演讲的时候也非常紧张。后来，我用了一种方法，就是我眼睛一直盯着教室后面的黑板上看。这样不会眼睛看着大家自然而然就轻松了很多，但是眼睛盯着后面看，同学也会觉得我在看他，还有另外一种方法就是把同学想象从一群小孩。所以当我们面对已经小孩的时候就不会那么紧张的感觉啦。我们把演讲对象想象成比我们弱小的群众，这样来演讲是非常轻松的。当同学提问的时候，就把他想成一些不懂事的小孩提一些奇怪的问题。当你在解答小朋友那些奇怪的问题的时候，就不会有那种紧张感了。

+   1目转转移，
2对象想象（一定想象比你弱小又好玩的人或事物）
3找自己喜欢的事，
4对自己喜欢的人讲，
5做习惯的事。
6主动要求反馈，
这都有助于我们读过紧张时刻。
