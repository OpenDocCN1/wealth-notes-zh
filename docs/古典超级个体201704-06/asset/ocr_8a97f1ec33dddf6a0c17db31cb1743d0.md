# 思维捕捉：做个情绪的拆弹专家 34-3

+   1. 我们常常以为是事件引发了情绪，其实是你内心的看法引发了情绪。情绪只是信念的外显。
2. 尝试找到胸海里这些一闪而过的，影响了你情绪与行为的想法。这个过程被称为“思维捕捉”。

不管你相不相信，每个人身上都隐藏着自己的“情绪按钮”，按钮背后连着一枚定时炸弹。平和和蔼可亲的一个人，一旦不小心碰到了这个按钮，就会爆发巨大的情绪。

有些人的按钮和人际关系有关，他们平时非常平和友善，对每个人都很好的人，一看到某类典型人就无名火，怎样都不舒服，恨不得弄死对方；有些人的按钮和环境有关，一秒前还很开心，结果回到家发现老公又把房间弄乱了，就开始生气；有些人的按钮和自己有关，每当自己的努力被误解，就会生气的回击——你的想法也不怎么样！结果通常是更被误解。

这种情绪按钮的导火索似乎会绕过理智，直通情感，完全不受控——所以大部分人最好的处理方式，就是藏着这个按钮，平时尽可能不让别人碰到。老同事、老朋友、相处很久的爱人，这些亲密的人难免触碰，那么就需要互相了解，知道对方底线。

# 非合理信念的3个特征

+   1. 绝对化：他没权这样做；我天生就是个没用的人；他从来都不信任我……
2. 扩大化：这个社会，付出了也沒回报；所有的牛人都会英语；大家都比我好……
3. 灾难化：全完了；彻底失败了；没有机会翻身了……
