# 金圣叹临刑前

第一个故事是清末才子金圣叹，点评《水浒传》的金圣叹。清朝政府文字狱，他带着儿子在孔庐前面哭，相当于今天的游行骂街、搞行为艺术。这种公知艺术家肯定要被关入大牢，择日问斩。

临刑前，金圣叹请狱卒带封信给大儿子。家人以为是遗言，啃啃索索打开一看，写着：“字付大儿看，盐菜与黄豆同吃，大有胡桃滋味。此法一传，吾无遗恨矣。”

行刑当天，押到菜市口。金圣叹又出么蛾子——他对刽子手说，我不想看着其他哥们儿先死，求先从我这里开刀——我也有好处给你，我身上有银票，你杀了我，就给你啦。

接下来这个情节都超越东野圭吾了。

刽子手手起刀落，第一个咔嚓了金圣叹。结果他脑袋落地，耳朵滚出两团字条，打开一看，不是银票，分别写着“好”“疝”。

这是第一个故事，好多人挣死如归，金圣叹做得最有趣。

# 鲁迅的遗言

鲁迅的遗言就不是金圣叹那个文风——透着一股“战斗劲儿”——他清醒得可怕：

+   1. 不能因为丧事受任何一文钱——但朋友的，不在此例。\n2. 赶快收殓、埋掉、拉倒。\n3. 不要做任何关于纪念的事。\n4. 忘掉我，管自己的生活——倘不，那真就是糟涂虫。\n5. 孩子长大，倘无才能，可寻点小事情过活，万不可去做空头文学家或美术家。（想起了老舍儿子舒乙）\n6. 别人应许给你的事物，不可当真。\n7. 掠着别人的牙眼，却反对报复，主张宽容的人，万勿和他接近。

# 佛陀圆寂

最后的故事讲佛陀。佛陀三十岁成道，传法49年，80岁那年某天，他感知到自己就要圆寂，提前一天告诉侍奉在身边的弟子。

弟子想，这是一个非常伟大的人，以后人们再也见不到他了，于是告诉师兄弟，师兄弟告诉了信徒们。这消息一传十，十传百，大家都想拜见佛陀最后一面。

第二天，佛陀仰卧的菩提树旁排起了长队，人们在佛陀脚下磕头，献上鲜花，然后离去。有个城里的屠夫，走在他面前，既不磕头，也不献花，站着对佛陀说——你不是一直在传法吗？我还没有学会冥想的法门，你为什么就离去呢？

佛陀不生气，也不推辞，敛身站了起来，坐下细细地教了那位男人打坐冥想的法门，然后回去坐下，仍然离去。

这是最后一个故事，佛陀展示出一个好老师的慈悲和坚定。
