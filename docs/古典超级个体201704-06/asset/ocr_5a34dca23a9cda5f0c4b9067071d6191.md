# 麦子

古典：五问写作构思法
观点（what）-价值（why）-发现（路线图）-行动（how）-总结（甜点）

+   1. 最近有什么特别想分享的事和观点吗？（提炼一句话题主题）

你之所以学习不得法，是因为没搞明白当前学习的内容是什么。（学习内容包括知识、技能、思维三个类别）

+   2. 这个观点有什么不同？对你有什么价值？
如果不先搞明白学习的内容属于什么类别，会用错误的方法来学习，可能会导致【学了很多却记不住】【听了很多却依然过不好这一生】这些结果。
不同的学习内容不能用同一套思路学习，否则会降低学习效率。

+   3. 知道了这个观点后有哪些概念是需要确认的？（3个左右子观点｜举例-旧体验接新概念；类比-旧概念联系新概念｜大脑只能用已知来认识未知）

学习新知识要用已知来学习未知，建立体系。（类比：Git和时光机，树和沙丘）
学习新技能要更快地开始刻意练习，而不是一直在看书。（举例：学编程）
学习新思维要找到现象背后的本质，且不能急于求成，建立在前面两个基础上。（举例：李笑来概念学习法-奥卡姆剃刀，成甲坤界知识学习法-四两拨千斤）

+   4. 接受了这个观点后具体该怎么做呢？（给出3个立刻可行的建议，非必要）
学知识：5个例子+3个应用
学技能：囫囵吞枣建体系-高频套路拧方法-刻意练习做强化
学思维：复盘-解决问题-优化迭代

+   5. 你的观点是什么？（最后总结亮明，一个观点或建议或应用呼吁）
当你学习时要先搞清楚学的是什么（明确敌人），再用合适的兵器来应对（制定战略）。

# 梁明晶

写作五问被古老大提炼成知识晶体以后，觉得写作思路清晰了好多。

最近也是在践行写作，比如最近写职场话题，按照写作五问来梳理就是这样的。一开始就是从一句的话观点开始（第一问），接下来阐述为何职场人要知道这个观点/能解决那个职场困惑（第二问），然后列具体职场场景丰富阐明观点（第三问），接下来给出如何做的套路（第四问），最后给出建议和注意点（第五问）。

有了五问的框架，以后文章就不会在抓瞎盲目了，而是清晰的主线和中心思想和完整骨骼的文章了，在加上三改，把“外表修饰好看一些，一篇自己的好文就有。
当然，开始行动是最基础的保证。加油自己，加油超级共同体们！

# Bruce

文章是用编写的方式完成写作的，而不是突发灵感，一气呵成。

一般来说，在我们的观念中，好的文章出现是这样一副场景。一名优秀的作家，在一个偶然的时机下受到启发，突发灵感，一瞬间，才思泉涌。他回到自己的书房，伴着灯光，洋洋洒洒数千甚至数万字的皇皇巨著一夜完成。但事实上，好的文章是先列出大纲和问题，然后寻资料，把所有的素材堆在一个文档里面，最后一个个问题和板块拼起起来，是用编的方式在写作，是通过一个一个步骤完成的。写作的价值不言而喻。文章并不是憨出来的，而是根据积累的内容编写出来的。不要想象写作是一件高大上的事，其实这就是对我们生活学习的点滴记录。不要认为好文章是灵感的产物，积累和套路才是。

因此，对待写作，不要认为我有灵感才开始写。而是要注重平时的积累。你积累的内容加上写作的套路共同促成好文章的生产。写作，要注意的是平时的积累。写作，不要想着灵感实现，一步登天，而要一步一步从眼下做起。

# 抵当心中

+   1. 我特别想分享一种写作的方法，问答。自己提出问题，自己回答问题。在回答的过程中，自然找到了感觉，把事情说清楚。

+   2. 坦白说，在看到古老师的文章之前，一直纠结一个问题。文章字数凑不够，问题又没有说清楚。看似字少的背后，其实是缺乏框架。

+   3. 问答，首先要澄清，不仅仅站在自我角度，同时要考虑读者的想法。只有与读者产生共鸣的文章，才是好文章。

+   4. 有了问答的思路，该怎么做，当然是写。看到古老师文章，说每个问题应该有一百字的答案。当然，凑还是能凑出来的。可是我这个人，不想将就，少一些就少一些。

+   5. 就我而言，写作不仅是一种抒发，更是一种交流。就像宋朝 siap 向皇上进谏，又怕话不投机。怎么办，献本书，把自己的想法写进去。哪怕有争论，也不至于撕破脸。这就是写作的魅力，避免了冲突与非理性。
