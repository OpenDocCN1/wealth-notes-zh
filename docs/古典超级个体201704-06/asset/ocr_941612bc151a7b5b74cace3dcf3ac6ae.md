# 周利军 1

峰终定律最典型的应该是歌手演出，无论演唱会还是小型现场。暖场歌手——哇，惊喜；歌手出场亮相交流——哈，拉近距离；歌手第一首歌预报——嗯，共鸣，就是这个味道。然后过程可能平淡，但在1/2或2/3处，总会安排几首压轴曲全场大合唱，嗨起来——峰值。最后一首歌也特讲究，既要意犹未尽，又要再掀一个新高潮。结束后的En core返场，无疑就是小甜点。
如古典老师所说，世间道理都是相通的，峰终定律应用的领域还很多哈！

# 季风 1

峰终定律:首先一定要有一个好的结果，然后要有一个足够高的顶点。

现实的影子:比如对团队或个人的绩效，首先看有没有恶性事件，是否达成了预期目标，这个是好的结果。然后看是否亮点，有让大家眼睛一亮的突出表现，也就是顶点。通常好结果加亮点，肯定绩效和影响力都有了。

认知提升判断力:很多人讲成功故事，只强调了一两个要素，比如成功就是坚持不懈的努力，讲述遇到了什么，什么困难，然后坚持坚持就成功了，听了很high，很鼓舞。任何结果也许有一两个关键因素，但是分析和复盘一定要看全，很多时候，结果是由很多因素导致的，听和看都要特别注意以偏概全的现象。
