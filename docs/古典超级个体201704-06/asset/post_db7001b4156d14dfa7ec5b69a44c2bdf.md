# 预告 | 演讲：越来越重要的自我营销手段 26-7

![](img/25e88d373f85ee6d39d9f51899b4f484_75_1.png)

我们用一周时间谈了写作，下周开始学习演讲。

对于这个专题，你可能会问：我既不想做演说家，平時也不需要在公众面前演讲，演讲跟我有什么关系？我有必要学吗？

我先说说我的看法，看完你自己决定：

首先，过去的时代传播效率低，语言只好压缩成文字传输，而今天互联网的带宽速度越来越快——不出几年VR就能模拟大部分外部世界。可以想见，到时候语言这门古老的手艺，一定会复兴，成为越来越最重要的网络影响手段。演讲则是其中最好的自我营销手段，以及最高效的沟通方式之一。

其次，我们每个人接触“演讲”的几率其实都很高：吃饭的时候大家让你“先讲几句”；公司提案，你得“介绍一下整体方案”；包括奇葩说式的“总结陈词”……这些都是小型的演讲机会。

最后，演讲还和写作一样，通过输出倒逼输入，逼迫你提炼自己的新观点。

所以，你可以不登台演讲，但你很有必要学一些演讲技巧。

下周，我们将学习演讲的几个重要知识点：

+   如何架构一个好的演讲？
如何把一个观点讲得有趣？
如何设计好的开头和结尾？

加拿大大学者马歇尔·麦克卢汉（Marshall McLuhan）曾讲过一句影响很深远的话——“媒介即信息”。如果写作是阅读的逆向工程，那么演讲则是听的逆向工程，是一种表达的艺术，是一种关于影响力的科学。

为什么要这么做？因为前一年百事可乐主打年轻市场，销售增长了百分之一点五，而可口可乐虽然加大广告力度、降低折扣，市场份额还是掉了百分之一。人一旦喝了百事，成了习惯，就不会再喝可口可乐，这样下去怎么得了？所以，可口可乐的高层一致决议，是该创新的时候了。

守旧一定稳死，但要创新从何入手呢？当时可口可乐的总经理名叫罗伯特·戈伊苏埃塔，他是化学工程师出身，这样的背景，也使他想要创新口味。而且他们新推出的健怡可乐市场反应极佳。

查，所以他们专心在比较口味，并没有把感情因素放进去。等到他们变成消费者，自己要掏钱买时，左右他最大的因素，搞不好就是感情。什么叫“妈妈的味道”？不是妈妈做的菜比较好，而是你习惯了。那是感情、爱的记忆。这就是范仲淹说：“常调宫好做，家常饭好吃。”习惯、情感，是没有理性可以计算的。

那好的东西就不能动了？一定不能创新吗？那倒未必，看你要动哪一块。

可口可乐近年做了一次新包装的改变。他们把罐装的可口可乐，在红底白字上，加了一条黄色的曲线彩带。当然上市前要做调查，结果百分之七十的人不喜欢新的包装。怎么办？是不是“从众”如流？不要动。不，他们看了调查以后，决定改包装。你说人就是不向历史学习，不要重复错误吗？为什么他们明知喜欢旧包装的人多，还坚持去改变呢？

因为年龄。喜欢旧包装的人虽然占大多数，但这是平均数，可是喜欢新包装的，全都是十四岁以下的青少年。哪一个是未来？而且包装设计并不是全换，基调不变，只是加上一条黄色彩带，让可口可乐更年轻一点儿，基本上没有伤害原来的情感。

后来市场的反应，也如预期，年轻消费者的购买量有提升。这是增加，不是取代。如同健怡可乐，是回潮潮流，增加一种选择，它并没有取代旧的，所以能让消费者接受。情感没有失落，旧的还在，只是增加新的。

所以，感情是计算不出来的。
