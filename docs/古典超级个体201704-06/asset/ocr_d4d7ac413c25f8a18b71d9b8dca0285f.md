# 预告 | 演讲：越来越重要的自我营销手段 26-7

![](bbox=[0.08, 0.39, 0.18, 0.45])

我们用一周时间谈了写作，下周开始学习演讲。

对于这个专题，你可能会问：我既不想做演说家，平時也不需要在公众面前演讲，演讲跟我有什么关系？我有必要学吗？

我先说说我的看法，看完你自己决定：

首先，过去的时代传播效率低，语言只好压缩成文字传输，而今天互联网的带宽速度越来越快——不出几年VR就能模拟大部分外部世界。可以想见，到时候语言这门古老的手艺，一定会复兴，成为越来越最重要的网络影响手段。演讲则是其中最好的自我营销手段，以及最高效的沟通方式之一。

其次，我们每个人接触“演讲”的几率其实都很高：吃饭的时候大家让你“先讲几句”；公司提案，你得“介绍一下整体方案”；包括奇葩说式的“总结陈词”……这些都是小型的演讲机会。

最后，演讲还和写作一样，通过输出倒逼输入，逼迫你提炼自己的新观点。

所以，你可以不登台演讲，但你很有必要学一些演讲技巧。

下周，我们将学习演讲的几个重要知识点：

+   如何架构一个好的演讲？
如何把一个观点讲得有趣？
如何设计好的开头和结尾？

加拿大大学者马歇尔·麦克卢汉（Marshall McLuhan）曾讲过一句影响很深远的话——“媒介即信息”。如果写作是阅读的逆向工程，那么演讲则是听的逆向工程，是一种表达的艺术，是一种关于影响力的科学。
