企业在招聘人才时，一般会用到2种测评工具：

+   一种是评估类，判断你行还是不行，它的理论基础是心理学，依据是你的过去，他要解决的是你是准，比如MBTI。
一种是评测类，认为你各种特质都有，但就是使用程度的不同。它的理论依据是组织行为学，面向的是你的未来，他要解决的问题是协助你成为准，比如今天要讲的DISC。

说到DISC，不得不提一下它的创始人——美国著名心理学家威廉·摩顿·马斯顿，他研究人类行为多年，出版《常人之所以绪》一书，创立了DISC理论。除此之外，最近电影院火的《神奇女侠》也是他的代表作，其中影片中的真言套索也是他发明的“测谎仪”的一个原型。

DISC具体是什么，古典老师在本周三时有讲，它根据“关注人”和“关注事”，“快”和“慢”两个维度，可以分成目标明确的D特质、受欢迎的I特质、善解人意的S特质和思维缜密的C特质，如下图。你属于哪种类型？

![](bbox=[0.08, 0.00218, 0.94, 0.0029])

你可能会选不出来，或者觉得不同情境下，四种特质都会出现。其实，DISC理论的前提假设有3个：

+   1. 每个人身上都有DISC，只是比例不同。
2. DISC四种特质，不是优点不是缺点，只是特质。
3. DISC是可以调整和改变的。而且，这四种特质还可以被训练和掌握，需要的时候都能拿出来。

# 一、心情不好时，你有四种解决方案

+   1. D特质：选择有挑战性的工作或者运动；
2. I特质：选择参加朋友聚会或者Shopping；
3. S特质：选择回归家庭给家人做顿饭；
4. C特质：选择静静看书或者玩数独。

# 二、拖延时，你有四种解决方案

+   1. I特质：调动想象能力和说服能力，激起自己做事的兴趣；
2. D特质：必须得拿到结果，自己才舒服，要立即行动；
3. C特质：分析究竟是哪个环节阻碍了行动，然后解决，程序开启；
4. S特质：找朋友聊聊，给自己赋糯能，然后开始做。
