# 写作的思考

话“听说读写”的具体使用过程中逐渐习得英语。在听写时，最好选择属于“知识源头”的那类英文，比如TED演讲的内容、优秀的心智类文章、BBC或VOA英语新闻、雅思托福听力考试以及《新概念英语》等教材都是比较好的听写内容。最重要的是，要记得循环往复、持之以恒地积累，切不可一曝十寒，用“PollPoll”慢慢来的方法每天刻意练习一段时间（可根据自己的可执行情况来调整时间长度），以上就是一种非常高效的英语学习方法。
