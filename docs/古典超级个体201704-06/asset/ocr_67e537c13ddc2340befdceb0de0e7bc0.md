33-2 该不该把爱好当职业？

我是做互联网产品运营的，做得还不错。在一个偶然的机会，我接触到了心理咨询行业，受益很多。我发现自己很喜欢这个职业，觉得能力也很匹配。但当我了解这个行业的收入和成长方式以后，我觉得很难以满足我的收入和成长需求。我该选择自己的爱好，还是选择自己现在的职业呢？

+   A. 转型尝试爱好的事。
B. 先做好现在擅长的事。

# 古典

几乎在每一本名人事记里，你都能看到名人发出："做你热爱的事！并且一直坚持下去！" 但你身边的人却告诉你，"千万不要把爱好当成工作，那样你连爱好都会失去！"

# 1. 爱好是为了自娱，职业是为了交换

# 2. 竞争水平的高低之分

# 3. 职业是主收益，兴趣是额外收益

# 爱好和职业重叠的最高境界

我的建议：选择 B
如果真的热爱心理学，不妨先从心理咨询师证或在职硕博士起。边学边用，一直有信心能达到专业水平，并且预期收入也足够养活自己时再进入该行业。
