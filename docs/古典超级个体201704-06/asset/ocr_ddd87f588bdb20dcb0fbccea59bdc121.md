# 预告 | 有一种落后，叫做不会讲故事 27-7

古典

从上周的“写作”到这周的“演讲”，从根本上来说，我们都在谈表达和输出。下周开始的“故事”主题也是如此。

关于故事，存在两个常见的误区：

+   1. 故事是小孩子的专属。

+   2. 讲故事是少数有天赋的人才能做的事。

事实上，故事是人类最古老的表达工具，也是今天最重要的影响工具之一。

美国前总统奥巴马说，美国总统的一个主要职责就是持续地给美国民众“讲故事”。

我们的大脑更喜欢听故事，而不是听道理。至今我们仍习惯用故事来思考。

所以，寻找和讲述让自己和听者都产生共鸣的故事显得特别重要。一旦掌握了这种技巧，你也就具备了说服、沟通、打动他人的基本技巧。

# 你发现了吗？

今天你记得的很多品牌，其实都在用讲故事的方式来传播。比如，万科集团的王石爬珠峰的故事；海尔的张瑞敏砸冰箱的故事；褚时健“褚橙”的故事；新东方俞敏洪“合伙人”的故事……

一个好的故事就像长了脚一样，是能“跑”的。如果/logs希望你的影响力更远一点，讲故事会给你加分。
