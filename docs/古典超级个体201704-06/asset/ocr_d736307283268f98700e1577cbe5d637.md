# 写作的思考

个人感悟：要在真正有料的前提下广泛传播，但从输出倒逼输入的角度看，是不是应该先大胆的写出来，从不确定不熟悉的领域快速获取相关知识，过程中，不断提炼、更新、修正观点，我觉得要比一味的记录和抒发要好很多，写作的内容也会丰富很多，从读者的角度也能收集很多反馈意见，促使自己不断的成长。最近在着手写一些乐评和影评，正好赶上了老师的写作课，实在是幸运啊：）

最后回顾一下，老师在文中提出的写作新手的进阶之路：尽快开始记录自己的生活，提高自我观察和表达能力；在工作中大量使用记录和文档型写作，提高自己的思维深度。

木头人

现在的岗位是公司的办公室，负责所有的会议组织和公司的内宣，使用最多写作方式就是记录式写作，用规范的文档格式忠实的记录会议内容。同时，内部邮件也是使用最多的一种 basically每天需要处理几十封的邮件。从现在的工作中看写作，写的很多，但是是没有长进，按照今天的文章的观点，应该是缺少复盘这个动作，很多时候是机械的去完成一个工作，很少会去思考写的这个过程和结果还有哪些可以改进的地方，对比做的好的人哪些是可以借鉴的，而且这样的复盘应该有即时的，也应该有阶段性的。这是以在工作成果输出上完善的地方。

对于目前的写作热，估计大多数人还是一时热情胜于写作本身。拿我自己做个案例吧，看过很多大牛都在鼓励写作，就有了心血来潮，开始鼓捣着写一点文字，刚开始的时候还觉得不错，自己也可以写出一些东西来。但一个月不到的时间，自己的文章没几个人读，公众号也没有所谓的爆红爆粉。然后开始发现说自己完全没有可以写的东西，感觉就是茶壶里煮饺子，有欲望却没有能力熬出来。这个过程跟风的概率更大些，另外就是其实自己完全没有想清楚写作的目的到底是什么，是表达自己，还是思维升级又或是增加影响力？一上来就没想明白的事情，持久的可能性就没有那么大。还有就是用错了文体，也是会对传播起到副作用的，现在所处的时代是作为一个写作的人既是知识创造者，又是知识传播者，两个角色是需要互相关联的。我们大多数人只考虑到了知识的产生，而很少关注知识的传播方式、渠道或者平台，所以出现种种障碍就在所难免了。幸好，订阅了古典老师的专栏，带着我们去认真思考写作。接下来的日子，要让自己认真跟上来。

风筝有风

古典老师的这篇文章可能是贴近我的最近发展区的吧。原来一直想为什么有些写作是好的。有些就是没有人围观传播。现在我明白了，很多时候我们是用错误的方式来做这件事情。比如说用写感悟的方式传播思想。这样大概就是没什么用的。我们之前讲到用写复盘和文档开始，今天我见识到为什么了。当然最打动我的是写作是一种自我存在感的确定。有些人很低调哈。比如说熊逸，罗胖说他是思想隐士，可是他却写了不少东西呢？他的思想被看见了，最后罗胖还请他出来开专栏，这不比那些炫富炫包包的人好太多了吗？还有，每天留言真的是要把自己的想法和思维写出来，这样很多时候我回头饭留言的时候，我就想，哎！原来我还写过这样的话。现在写留言就是一种习惯了。有一些不提不快的时候，也有闷不出一句话的时候，不过，每次总要说点什么。说着说着总会有话的。

看看

从12年底开始写日记，到现在差不多五年了，自己写日记的初衷是想记录自己的生活，同时，在这日常事件中总结和反思自己。在这些日子里，自己能够更好看清自己的同时，也让自己的表达有了提升。

毕业后，自己从事的是和文字有关的工作，平时接触到的大部分是记录性的文字，比如新闻事件的整理和传播，公司领导人的演讲稿，热点的包装等等。在工作中锻炼了自己的逻辑思维能力和归纳总结能力。

最近，自己也来了微信公众号，通过书写自己的人生经历，所思所想，成败事件，给读到的人能够有所启示，因为，我觉得他人的得失虽然不代表自己的所有，但是至少可以有所警示，这是我写自己公众号的原因。

但是，通过这段时间运作以来，效果不是太好。在读到古典老师文章后，才想到传播性文字中需要有深度的思想，有很强的阅读性才行，而这种阅读性更多的是，和读者的相关性，实用性，切身性。

了解三种不同的写作方式和功能后，对文字的力量有了更好的把握。

谢谢古典老师！
