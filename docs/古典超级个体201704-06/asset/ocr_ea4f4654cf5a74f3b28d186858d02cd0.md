# 1.为什么你应该马上开始写作

今天很多人都在谈论写作的重要性：有人说写作是未来必不可少的一个交流和思考的工具；有人说记录是一种态度；有人通过写作圈了不少粉丝、赚到了不少钱……于是大家一窝蜂跑去写作。

但是，成长、交流、赚钱的方式还有很多种，写作究竟有什么独特的好处？

# 2.回答这5个问题，会说就会写

写作不只是天才的事，教你一个简单易行的方法：你每听我说一个问题，就随口答几句，回答完这5个，文章也就出现了。

# 3.逆向工程：写得好一定学得好，反过来则未必

这里谈的是写作的底层逻辑。你需要知道一个概念：写作是表达的逆向工程。两周前，大家已经学习了人是如何学东西的，那么你只要能够倒过来想这个事情，就明白你该怎样写东西了。那么，到底什么叫做逆向工程？

开始写东西的时候，最大的困扰是什么？
不知如何下笔
想写一部科幻小说，脑子里非常多的点子，也把点子记下来了，可是它们变不成另一本三体，我也没有变成另一个刘慈欣。
想给父亲写一本回忆录，可是每当我翻开他的日记想要整理的时候，就整理不下去，也不知道以什么样的方式记录？故事串联还是时间线。
想记录自己生命的珍珠，那些触动与沧海遗珠，可是往往是一个个碎片化的小段子，无法形成一个完整的可以不断重复去讲的有趣的小故事。那些经历和故事，没有被打磨得更有趣。

你觉得写作能带来什么收益？
收益太多了，切身体会的是两点。
一，解决烦恼，平缓情绪。每当有烦心事的时候，写下来，烦恼和情绪也随之平稳，不论引起烦恼的是什么事。并且更容易找到解决办法，甚至有时候写着写着，办法就自动出现了。
二，更了解自己，忠于自己。剖析自己内心与自己对话的过程，人诉说经历了什么，感觉了什么，注意了什么，表达了什么，组成了你自己。写作会让人不停地与自己对话，更了解自己，忠实于自己。
其他的收益也有很多比如，对知识点更透彻的理解，公众号的写作会更好的宣传统自己，让更多的人更了解你，把时间重复的卖很多
