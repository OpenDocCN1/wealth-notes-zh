# 三原则：

# 1. 有结构

人的思考和行为受“框架”影响很大，框架本质上就是思考的套路，人脑的内存相当有限，需要把多线程任务拆成一个单线程小任务。

商务讨论：事实-解释-行动 三分法

心理咨询：情绪-事实-意图（Feeling - Fact - Fouc s）3F

![](bbox=[0.05, 0.85, 0.95, 1.0])

# 2. 以问题为中心

学生时期的笔记是“积累知识”，而工作之后的笔记是“解决问题”。工作要求你做的不 是收集信息，而是得出“一个结论”——工作中信息太多，从海量信息中抓重点，整理出框架后整理结论——关键是思考的能力。工作笔记是以问题为中心，为了“舍弃”而存在的。

所以，标题放到正中——然后持续比对你收到的信息——快速思考“是否和问题相关”。无关的都不要放。

![](bbox=[0.05, 0.0015, 0.95, 0.00185])

# 3. 好奇停车场

当然，好奇的灵感也很重要——所以我有一个“好奇停车区”——一旦遇到不懂的问题，我就翻到停车场，写下来这个灵感，然后马上回到问题框架。

通过改变笔记本改变思路，通过改变思路改变未来。

# 古典

特约成长导师：毛泡泡

这几年有一个非常有意思的职业越来越受年轻人欢迎，称为“视觉引导师”，通俗点说就是图像同声传译，把声音画出来。我的好朋友毛泡泡就是中国图像引导的先行者。全球从事这样小众职业的人不到300人，而她是目前全球能用3种语言图像同传，且出场费用最高的一位。

毛泡泡在职业初期并非从事这一行，她是决心从事服装设计，但在26岁那年被确诊患有阅读障碍症。心理医生对她说：“恭喜，上帝为你打开了另一扇窗。”于是她从这扇窗出发，向另一片天地走去。
