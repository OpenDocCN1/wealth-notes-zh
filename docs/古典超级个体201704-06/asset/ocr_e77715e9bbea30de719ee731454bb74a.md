# 峰终定律：设计好的高潮和结尾 27-3

27-3 峰终定律：设计好的高潮...

今天我们来谈谈，怎么给我们的演讲再加分——设计好开头结尾。

演讲是听的逆向工程，所以我们先来讲一个心理学的重要的概念“峰终定律”（Peak-end rule）。

# —— ◆ 峰终定律 ◆ ——

什么叫峰终定律？

当你去判断一次旅行好不 好玩、一个party是有趣、一部电影是不是精彩，你并不会把它所有的瞬间各自评分，然后求得均值，你只会把最嗨的点和最后的感觉提出来，基于这两个点来评价。顶点和终点对于一个事情的体验最重要，这就是峰终定律。这当然是人脑的一个不那么理性的判断，但的确为我们打动听众提供了火力点。

看电影
比如说电影就是按照这样的方式做的，可能电影的过程非常无聊，但是这部电影只要有一个特别好的高潮，比如3D的大战镜头。大部分人都可以捏着鼻子看下去。如果最后还有彩蛋，你就觉得太有良心啦！看完一部一个半小时的电影不难，但你要听完一场演讲，那实在是太难了。

吃大餐
同样的道理，吃法国西餐也是按照这个方法来设定的：
第一步，开胃小菜。就餐前会先端上来一盘开胃小菜，基本上是帮这个西餐定了个调子。
第二步，上主菜。其实主菜就是让你体会高潮的峰值体验。
第三步，上甜品。西餐最后会赠个小甜品，而且甜品往往非常好看。这其实就是让你对这顿饭留下一个好印象。

我请人吃饭时，就有一个习惯——在吃到接近尾声时去买单。因为把买单作为吃饭结束动作是有点小尴尬的。吃饭最好的体验就是大家吃到兴起，关键时刻戛然而止，正好峰值和终值停留在同一个点上。不然大家聊到冷场，反而败兴。

我后来发现有些聪明的商家也想明白了这个道理，所以一般他会在你买单后再送一个果盘，这个果盘其实就创造了一个终值效应。

产品发布
更加有趣的是在产品发布上，也是这样。你有没有听说过一本叫《重来》的书？这是一本一群作者写的书，这本书背后是一家叫37signals的公司，它们每发布一个新产品后的两周，都会再来一次重大产品更新，也就是说，它最初发布的那个产品并不是100%的版本，可能只是达到了80%-90%。

这是很聪明的！
他意识到一个产品推出来，只要满足一个关键点，获得峰值效应就可以。而在两周之后让用户免费获得一次非常棒的产品升级，就能获得终值效应。这样，用户对这个产品和公司的情感就会强烈很多。所以新产品的发布并不是一次达成的，对客户来说也不会觉得，我买完就 lee 我了。这样，他追加一个尾部体验，创造了两次特别好的高潮。

我觉得很多人都看明白了这个事儿，比如说 Linkedin 创始人雷德·霍夫曼（Reid Hoffman）说：“如果你不为你发布的东西感到一点点尴尬，那说明你太晚了。”

同样的道理，演讲也是这样。

演讲时你不需要系统，也不需要面面俱到，你只需要在十几分钟的认知资源中，让别人记得一个关键点就是一个峰值，然后在结尾时获得一点小甜品。

这个定律用得最聪明的就是乔布斯，他经常会在演讲最后面说“ One More Thing ”——“对了，还有一件事情”，然后从兜里掏出一个非常厉害的产品。

# —— ◆ 开头和结尾 ◆ ——

理解了这个概念，我们就理解了如何设计开头和结尾。

# 1.开头不要瞻谎虚

在开头最容易犯的错误是乱谦虚——比如有一次我参加一个年会，董事长一上来就说：“今天来的路上，我还在想和大家说什么呢？我没有太准备好，今天随便说几句。”这也就是他的主场，没有人敢嘘——如果是客场，听众就嗤之以鼻了：“为什么不准备？我可是准备好了认真听你说话呢！”

所以，你要用到好“开头三板斧”——最好能让人“哇一下、哈一下、嗯一下”。
“哇一下”就是有个惊喜；
“哈一下”是有个段子（一定要和主题相关，至少也和自己相关）；
“嗯一下”说一两句让听众内心很认同，有共鸣的话。

实在没有出彩的开头，至少可以开门见山——“今天我想说一件事，这件事对大伙的意义是……它分成下面三点……”。

# 2. 糖糕的结尾

“嗯，时间到了，所以就此结束吧。”
