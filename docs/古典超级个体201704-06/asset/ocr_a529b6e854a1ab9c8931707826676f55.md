# 预告 | 如果消除情绪内耗，你会比现在更优秀
33-7

下周的话题，是我们几乎天天遇见的“老朋友”——情绪。如果一个人连自己的情绪都管理不好，又怎么去照顾别人呢？更不用说打造高质量的人际关系了——你永远给不出你没有的东西。

单是“情绪内耗”就能让人心力交瘁：有些事想想就觉得“累”？有些人一见就心烦？担心、焦虑、烦躁……就像雇人在自己家里打了一架——负面情绪和对于负面情绪的克制，都消耗的你的“精力”，最终“家”也被砸个稀巴烂。

你知道吗？每个人身上都隐藏着一个情绪按钮：一碰到，就会爆发出巨大的情绪。这种情绪按钮导线似乎可以绕过理智，直通情感，完全不受控制……

所以，下周我们从消除自己的“情绪内耗”开始，学习如何理解情绪，降低内耗，防止情绪爆发。

就好像顶级的滑雪教练在教你滑雪之前，都是先教你怎么停下来；顶级的跳伞教练教你 jelasnya 你在空中左右移动之前，先教你如何稳定身体。所以，在你变成一个人见人爱、如沐春风的“妖精”之前，先学会把握好自己吧！本周目标，正如我们的联合策划人、咨询师董如峰老师所说——帮你“成为一个内通外顺的人”。
