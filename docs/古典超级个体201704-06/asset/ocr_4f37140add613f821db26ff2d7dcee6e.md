# 预告 | 为什么“玩”是一件被严重低估的事？
31-7

![](bbox=[0.07, 0.24, 0.12, 0.28])

今天是端午假期第一天，你是不是长呼一口气——终于放假了，相信你已经做好了假期的计划：回家看看父母、旅行放松自己……无论哪一种，此时此刻，我都希望你能有一种心态——玩儿。

“玩”这件事，其实小时候我们都是玩儿的专家——躲猫猫、丢沙包、谈玻璃球，甚至和自己的手指头都能玩一下午。但随着我们长大，玩变成了一件越来越奢侈、越来越有负担的事。“作业都没有做完，还玩呢！”但是人生的作业实在是太多了——所以越来越多的人“玩无能”，一方面可能是因为负罪感，另一方面是实在不知道玩什么。

但也有很多高手们不仅是人生赢家，同时也是人生玩家，“微信之父”张小龙是围棋、网球高手；小米的黎万强办过摄影作品展；特斯拉CEO马斯克特别喜欢玩《守望先锋》和《炉石传说》。据《科学》杂志2009年的报道，接受其调查的CEO、CFO及其他高管中，有61%的人每天都在工作休息时玩游戏。

玩，是一件被我们严重低估的事。

明天开始的一周里，我会变着花样教你认识玩、怎么玩，会和你一起探讨：

为什么玩是一件被严重低估的事情？

如何把重复枯燥的工作变得有趣？

玩和享乐有什么区别？

什么叫在热爱的领域努力的玩？

为什么游戏人生，是一个很健康、从容的高手心态呢？

看到这，有人可能还会有疑问：“事情都做不完，还有心思玩吗？工作都没做好，玩不是浪费时间吗？”这些我都替你考虑到了，就等着你来翻牌子。

古典

下周的特约成长导师，我请来了来自大洋彼岸的劳伦斯·科恩博士（美国）。

科恩是美国资深儿童心理学家，已在儿童游戏、游戏治疗和亲子关系领域研究30多年。四年前，他出版了一本书《游戏力》，后来被翻译成14种语言，在全球热销。

“游戏力”课程的中国引入者，是简栅教育创始人刘芳。她说，科恩不只是写出来，还全情投入地去实践，他自己就是一位活出“游戏力”的父亲、外公。

科恩先生说，“我想不出还有什么能比游戏更重要，无论是对于孩子，还是对于我们自己……（我）同意库尔特·冯尼格特的一句话‘我们来到地球，就是为了四处逍遥，说别的都是扯淡’。”

“对于孩子，游戏就是工作”，我们曾经“在玩中学知识”，“在玩中懂得理”，“在玩中建立自信”……可惜长大后，很多人都忘记了。

下周我们请科恩博士来讲讲，怎么玩好“工作”这场游戏。如果你有想问的问题，留言告诉我，我替你转问。
