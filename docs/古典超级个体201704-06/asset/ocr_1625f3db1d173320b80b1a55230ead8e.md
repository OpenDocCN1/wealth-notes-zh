# 预告 | 可视化思考：让杂乱的思维体系化 28-7

从古至今，人类偏爱两种信息形式：一是故事，二是图形。

远古时代的夜晚，人类常常围坐在火堆旁边，听老人讲述遥远的传说。而早在三万多年前，我们的祖先已经在洞穴里留下了关于野牛、马群的壁画……

这周我们已经知道，故事不仅仅是小孩子的偏好，而是一种有效的沟通工具和营销手段。

下周我们即将进入的“可视化思考”（图解的力量）专题，将与你分享一个好用的思考工具，并可能颠覆你的既有认知。

# 1. 90%以上的人不会正确地记笔记

开会的时候，你的笔记写了满满一页，唯恐漏掉一句，可会后还是搞不清当时讲了什么，抓不住要点——你知道吗？这种记笔记的形式正在阻碍你的成长。

# 2. 你的思考正在消磨你的想法和创意

你有没有遇到过想一个问题想到“头大”，却仍想不出结果的情况？

越想不清楚越焦虑，越焦虑越想不清楚，恶性循环……花费时间的长短和思考的质量，并不成正比。很多有价值的创意、想法，反而会在反复思考里消磨殆尽。

你看美剧里那些警察或者高智商的主角，他们常常会在白板上贴照片、写文字、画图形——这些超级聪明的人，都在借助图形或文字来帮助思考。我们也应该学习运用这种大脑喜欢的方式思考。

# 3. 很多公司正在拒绝使用PPT

在亚马逊的内部会议中，PPT的使用是被严令禁止的。因为PPT只呈现思考结果，而隐去了重要观点背后的思考过程，这会让其他参与者变得被动。

乔布斯在开会时，很喜欢用一张表格或者一块白板与大家交流。他用一种简洁的方式让他的思考过程一目了然，也让参与者拥有更多思考和表达的空间。

# 什么是可视化思考？

可视化思考，是一种思考方式，它能把你杂乱的想法用可以看见的形式，逐步规整、呈现出来，并让你的左右脑实现高效协作，让眼、耳、手、脑齐开动，使你的思考系统化、结构化，并最终清晰地表达出来。
