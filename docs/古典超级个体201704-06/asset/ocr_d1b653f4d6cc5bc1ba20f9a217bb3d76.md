# 你理解的人脉，也许都是错的 30-1

30-1 你理解的人脉，也许...

假如你遇到了一件能力范围以外的事，这个时候，你会自己想办法，还是拿起电话找人帮忙？如果找人的话，你会找谁？如果那个人能够帮你，他又凭什么帮助你呢？

我们每个人都需要很多朋友。一个穷不仅仅仅意味着缺钱，更意味着没有办法与那些能帮到他的人联系。你不可能一个人到达目的地，任何领域的成功都无法独行。

正是因为有这样的焦虑，很多天参活动、合影、递名片、加微信，认为这就是拓人脉；有的人则特自豪地跟我说，“我手机里面现在就有xx的电话”，其实真正尴尬的不是打电话找不到对方，而是对方接起你的电话，都不知道能和你聊什么。这种人只是社交花蝴蝶，未必是高质量的社交。因为你和他们只有链接，并无关系。

怎样聪明的经营人脉？首先要知道什么是真正重要的人脉。
