# 四人行

看到这个问题，让我想起了一篇文章《落花生》，这是小学时候学过的，可是我依然记得，每次吃花生的时候我就会想起，那里面的最精华的一句话：花生只把果子，埋在地里，等到成熟，才有人把它挖出来，你们偶然看见一棵花生瑟缩地长在地上，不能辨出它有没有果实，非得等到你接触它才能知道。这其实就是描述了作者-许地山的品格。也就是他这种品质把我深深的吸引了。他是个很有学问的人，可是却从来没红过，这是跟他的写作态度有关。在他那个年代，从不奉承别人，字字珠玑，低调再低调的做自己，做认为应该做的事，写自己应该写的文章。许地山是老舍的好友，是张爱玲的老师。他的去世，很多人感慨说，老年人失掉了快活的谈话伴侣，中年人失掉了热热炽的同志，少年人失掉了开心的先生，孩子们失掉了淘气的老伯。

# 鸣沙石

今年刚开年，罗胖就推荐了一本书叫未来简史。作者是以色列作家尤瓦尔赫拉利。环顾我周围的朋友，同事，读这本书的几乎没有。了解这个作者也不是很多，知道人类简史就是他写的那更加很少了。所以他复活了古典老师说的冷门特征。他最吸引我的地方在于他对宏观把控力是非常强大的。他书中引用的素材，其实我们很多人都能接触到，但是唯有他可以提炼出指导未来的观点。我想这一点就是他最吸引我的地方吧！从看他的书我也学到了：哲学不是无用之学。

# V言

开始写公众号的时候，总想把自己学到的东西“传授”给别人，后来写的很痛苦，分析了一下是站位的问题，总想着“传授”就会有种为人师的暗示，不把读者当学习者，而是把他们仅仅看做不同的人，只是恰好我的这个知识点TA还不知道，我的这个感悟视角不太一样，不是“传授”而是“分享”写作就舒服多了。因为如果把自己看成老师，你就要对自己的传播负责任，就不能出错，就容易不自觉的偏执和狭隘，自然就容易痛苦。分享者就不同啦，来，我有一个观点，大家聊聊互相启发嘛～

# 骑小晓

# 素衣月

我推荐赖声川老师！作为戏剧届的大拿，他的文笔实在太厉害了！他的《赖声川的创意学》写得非常好，把创意生产的知识晶体--应该可以称为知识金字塔了--完整地呈现出来，非常给人以启发。里面有一段回溯《如梦之梦》剧本的创作是由哪些经历激发出来、融汇碰撞后产生的，都有点《粽梦》的味道了，非常精彩！
