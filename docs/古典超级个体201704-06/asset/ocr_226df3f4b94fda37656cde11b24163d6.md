# 向着光亮那方 3

对于我来说，写作最大的目的是自我记录，所以我写的最多的日记。对于我来说是一种记录，是一种经历。每当我翻看我以前的日记的时候我都会很开心，因为我感觉自己的生活有厚度，我会看自己一个月有多厚，两个月有多厚，三个月又有多少。这种感觉很棒。

而现在写作掀起了一场热潮，很多人说写作应该怎样怎样，很多人开写作课，可是我就想，这个真的必要吗？很多时候我认为写作是写给自己看的。当然，我的这种想法是不对的。想真正扩大自己的影响力，无疑写作是最好的方法。而对于现在的写作热，我想我们应该理性看待吧。不管别人如何，先看自己到底需不需要，做好自己该做的。也是的，要看自己到底是为了什么而写作。 04-17 07:18:37
