# 理由② 一般散戶參與度仍低

一般而言，多頭行情會經歷4個階段，分別為：在絕望中誕生、在半信半疑中成長、在憧憬中成熟、在希望中破滅。

舉例來說，當我在2017年1月4日看到國內主流媒體公布民調，在1,034位有效受訪者中，對台股樂觀者僅為13%，如此沒信心的狀況，甚至逼近2008年金融海嘯時的12%，就可以感受到「行情在絕望中誕生」的跡象。

此外，時序進入2017年3月，代表散戶參與程度的融資餘額，仍舊維持在1,500億元以下的歷史低檔區，直到2017年8月24日融資餘額才突破1,500億元，因此縱使台股在農曆春節過後，上演了一波驚驚漲的走勢，但當時的台股，我認為也只是進入「在半信半疑中成長」的階段而已，離「成熟」與「破滅」的階段，還有一大段的安全距離。

畢竟追蹤台股過去20年的歷史經驗，1,500億元以下的融資餘額，一方面雖然反應散戶對台股「興趣缺缺」的心理因素，但另一方面由於只出現過3次，並且每次都巧合地出現在台股最低點時候，這項指標也提供了判斷整體行情的依據。

# 理由④ 全球景氣強烈復甦成長

前行政院長陳沖在2009年時提出判斷台灣景氣的3大指標，除了台股漲跌、外資買賣超之外，英國倫敦Liv-ex所編制的紅酒100指數（LVX 100 Fine Wine Index），由於指數編撰的成分股，蒐集了全球最貴的100支紅酒，不僅可用來洞悉當前有錢人的消費動態，更可視為景氣的領先指標。

整體而言，當景氣好時，紅酒指數會因為有錢人消費不手軟，而出現價格走揚的發展；反之，當景氣不好時，有錢人消費緊縮的結果，便會導致指數走跌。

此外，由於台灣本身對外貿依存度非常高（台灣2016年第3季為96%、日本為61%、中國大陸為31.6%），因此相較於亞洲其他國家，全球景氣的枯榮與紅酒指數的漲跌，更能直接反應在台灣經濟的起伏變化上。

追蹤2011年以來，台灣2次景氣對策燈號在掉入代表經濟蕭條的藍燈前，紅酒100指數都曾出現過一段跌幅約15%的走勢，2011年指數從360點下跌到300點，便準確預告台灣景氣即將陷入一連串的藍燈困境；2015年4月到2016年3月，當台灣總體經濟掉入連續藍燈的谷底時，紅酒指數不僅在先前因為受到中國打貪腐的政策影響，出現約15%的下跌走勢，更一路處在250點以下低檔徘徊，直到2016年4月重新回到250點以上，才讓台灣景氣同步告別藍燈，並且一路回升到代表景氣穩定的綠燈。

紅酒指數在2017年1月不僅已經連續13個月上升，更攀升到2011年11月以來的新高位置，來到301.08點，因此若無太大意外，這波全球頂級消費者所代表的景氣回升力道，將可持續挹注台灣經濟的提升。

# PMI指數組成的5大要件

整體而言，PMI指數是由5個面向所綜合組成的分數，包括：①新增訂單數量、②生產數量、③人力雇用數量、④現有原物料存貨水準、⑤供應商交貨時間。其中一個簡單的衡量標準，就是以50分為分水嶺，PMI指數低於50分，代表製造業呈現衰退的局面，高於50分則顯示目前製造業處於成長的擴張階段。

# 月K連6紅 台股必啟動多頭行情

從技術分析的觀點來看，紅K形成的要素是「收盤價＞開盤價」，因此能夠出現連續6個月以上的月K收紅，不僅代表市場完全不畏懼過去已「漲多」的格局，更顯示市場大戶不計成本，也要將底部越墊越高的做多心態。

整體而言，台股歷史上，能夠出現月K連6紅以上的機會並不多（扣除這一次，只出現過4次），但每一次出現，都代表未來將有「大行情」誕生。例如2012年11月～2013年5月期間（月K連7紅），當時台股一路從7,166點上漲到8,254點，雖然月成交量僅有1.86兆元，但絲毫不影響1年之後指數續攻到10,014點的萬點行情。

# 習慣萬點理論 建立在獲利走揚基礎

我在2017年3月大膽提出台股投資人要開始「習慣萬點」的理由，隨著台股持續改寫史上最長時間的萬點紀錄之後，雖然得到了市場最直接的驗證，但2018年初某天晚上外出運動時，遇到一位年紀約50歲的男子前來打招呼，一方面詢問本人是否就是電視上面的那位「孫慶龍」，另一方面在確認過後，劈頭就問：「台股已經這麼高了，還可以買嗎？」

相信這位男子的疑惑，也是目前市場上許多投資人的疑惑，畢竟台股不僅創下28年以來的最高點位，也讓一般投資人心生「高處不勝寒」的風險意識，然而我卻以為，大多數人在看待指數的高低時都有一個盲點，就是單純以「價格」來看，而忽略更內在的「獲利」表現。

舉例來說，市場在計算一檔股票合理價格時，常使用每股稅後淨利（EPS）乘上本益比的公式，若EPS為5元，本益比10倍，那合理的股價就是50元（5×10），然而，如果EPS上升到10元，在本益比維持10倍的情況下，合理的股價就可從50元上升到100元（10×10）。

# 計算股票合理價的公式

![](img/1fa1f4d4436b0fbf820926994a4b7975_48_0.png)

以台積電（2330）為例，2011年以前，市場總認為100元的台積電就已經來到了價格的天花板，即使再漲也有事，主要的考量有二，一是投資人的主觀印象，二則是以當年度EPS獲利5.18元計算，20倍的本益比，合理的股價大約就落在104元。

殊不知，只參考「價格」高低的主觀印象，往往會忽略內在「獲利」的變化，畢竟當台積電EPS一路從2011年的5.18元，上升到2012年的6.41元、2013年的7.26元、2014年的10.18元、2015年的11.82元、2016年的12.89元，以及2017年的13.23元，即使在本益比20倍不變的情況下，合理的股價也一路走揚到104元、128元、145元、204元、236元、258元以及265元，不僅遠遠突破一般投資人以為的100元主觀印象，更完全展現「大象也會跳舞」的多頭氣勢。

# 萬點台股 處處是黃金

![](img/1fa1f4d4436b0fbf820926994a4b7975_52_0.png)

總結而論，假設不是投資指數，也沒有投資上述這20檔權重較高的股票，那麼台股指數的高低，其實對一般投資人的意義真得不大，而我認為，只要堅守3個原則，不管今天台股是在7千點、還是1萬點，甚至2萬點，投資人依然能夠創造合理的績效報酬，而這3個原則就是：「用好的價格」買進「好的公司」，並搭配「大賺小賠」操作紀律。

談起台股指數高點的預測，近幾年最驚人的言論，莫過於被譽為「新興市場教父」的墨比爾斯（Mark Mobius），在2014年4月發表對台股後市的看法，他認為：台灣不僅服務業發達，科技業也具有世界競爭力，因此就長期而言，台股不僅可維持每年12%的正成長，2020年時更可上看到2萬點的指數位置。

姑且不論「台股上看2萬點」的推論是否有點一廂情願，單就台灣目前整體上市櫃公司的總獲利確實「好到沒話說」來看，這波萬點以上的台股，確實走得很扎實。

# 台股萬點榮景一般投資人為何吃不到？

根據統計，台股2017年底上市櫃公司總市值，已經從2016年底的30兆元，成長到35兆元，換言之，若以500萬個股民計算，平均每位投資人在過去1年期間，應該都可以為自己加薪100萬元。

這樣平均的獲利數字，我在2017年全台的巡迴演講中，意外發現台下大多數投資人，似乎都無法達到這樣的獲利水準，這中間到底出了什麼問題？或許可從3方面來探討。

# 原因① 投資方法錯了

這是一個簡單的邏輯驗證，假設市場的統計顯示，每位投資人平均可以賺到100萬元，但自己卻賺不到，這中間一定代表原來的投資方法是錯誤的，必須得更正。

# 原因② 誤信不正確的資訊

在資訊大爆炸的年代中，資訊的取得雖然容易，但市場往往也充斥著似是而非的觀點，影響投資人的判斷，舉例來說，川普2016年11月意外當選美國總統，不僅掀起全球金融市場的大波動，網路上更快速流傳一則訊息，並煞有其事地指出：其實早在1千多年前，唐朝詩人李白已看穿了一切，有藏頭詩為證：

> 「川原行稍穩，普天皆滅焰，入戶辭父兄，白鳥凌風迴，宮中淑氣遲。」

平心而論，我第一時間看到這則訊息時有種驚為天人的撼動，因為這首藏頭詩的每句字首，合起來看的意思，就是：川普入白宮。

然而，當我再度細細品味這首藏頭詩時，隱約之間有種感覺這不是李白的詩，因此便隨手上網查詢相關內容，赫然發現，原來這僅是網友「東拼西湊」的內容，因為上述的每一句詩文，沒有一句是出自李白，而是分別來自於張九齡的《出發道中贈司馬兼寄諸公》、沈佺期的《寒食》、元稹的《樂府古題序（丁酉）佑客樂》、羊士諤的《登樂遊原祭司封孟郎中盧補闕》，以及李隆基的《軒遊宮十五夜》。

科技的進步，讓現今的投資環境，與10幾、20年前出現了很大的差異，投資人要面對的課題，已經不再是如何取得資訊，而是在面對電視、網路、媒體等大量資訊「轟炸」的環境下，如何有效解讀資訊，分辨什麼是假資訊，才能讓資訊成為有用的賺錢依據。

似是而非的資訊，同樣也充斥在台股的投資，尤其這幾年國內有一些高收率的電視節目，從2010年至今，就一直在平日的晚上不斷轟炸空方言論，不僅嚇得一般投資人根本不敢進場買股票，更忽略了台灣電子產業不僅已成功搭上未來的科技趨勢，更讓台股的結構出現脫胎換骨的變化。

# 原因③ 與飆股有緣無份

我發現，大多數投資人即使買到飆股，跟飆股也是有緣無份，關鍵原因是，不了解飆股的基因，而輕易放棄可以讓投資人累積財富的好股票。在下一個章節中，將跟大家好好分享什麼叫做：飆股的勝利方程式。
