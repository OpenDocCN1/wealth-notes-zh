# ② 退休餘命可達30年

隨著醫療進步，加上現代人重視養生，台灣人平均壽命不僅已經來到80歲，未來活到90歲以上的人，相信也會越來越多。

若在60歲、趁還走得動的時候選擇退休，餘命至少還有30年的時間，相當於360個月，若以每月6萬元計算，光是維持基本的生活品質，至少就要花掉2,160萬元，只剩不到3成的錢，可以做其他「犒賞自己」的消費運用。
