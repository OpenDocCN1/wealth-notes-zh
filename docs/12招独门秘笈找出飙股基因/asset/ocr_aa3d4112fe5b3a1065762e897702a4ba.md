# 技術分析小學堂：均線

一般而言，「均線」就是平均成本的觀念，所謂年線，指的就是過去1年，買入這檔股票的平均成本，以此類推，季線指的就是過去1季，買入這檔股票的平均成本；月線指的是過去1個月的平均買入成本。

至於股價站上均線的解讀，以年線為例，指的就是過去1年買進這檔股票的投資人都賺錢；跌破年線，就代表過去1年買進這檔股票的投資人都賠錢，因此容易形成股價一上漲，就被市場賣下來的解套壓力。

此外，一條均線會開始上彎，代表市場買進這檔股票的成本越來越高，因此在底部越墊越高的情況下，容易形成股價上漲的助力；反之，當均線開始下彎時，由於市場買進這檔股票的成本越來越低，股價上漲的阻力便會自然形成。

# 均線的意義與解讀

年線、半年線：過去1年、半年的平均成本
季線、月線：過去1季、1個月的平均成本
