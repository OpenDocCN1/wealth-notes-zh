# 遇股災大跌 用定期定額向下攤平

當然，利用K值的起伏來抓元大台灣50短線股價高低的轉折點，同樣也經過大數據的客觀分析，整體而言，在2004～2018年2月2日期間，合計出現過52次轉折點，以此為據的投資策略，平均勝率可達到76.92%，雖然平均報酬率僅為1.47%，但由於平均持有天數僅為26.7天，若能善加利用具有2倍槓桿效果的元大台灣50正2，或適度地搭配融資操作，短線累積的報酬，也是一筆相當可觀的收益。
