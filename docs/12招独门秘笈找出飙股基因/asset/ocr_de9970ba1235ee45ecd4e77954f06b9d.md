# ⑫2017年9月

當時月KD在91附近死亡交叉，在1個月的空頭走勢中，最大跌點為407點，跌幅為3.82%。

值得留意的,例如，2017年11月台股指數在10,882點的位置，出現月KD在89附近死亡交叉的變化，直到2018年5月都還未扭轉死亡交叉的內容，若以這段期間台股最低點10,189點為計算基準，已出現693點的最大跌點，跌幅約在6.36%。
