會有上述台股月KD若出現在70以上死亡交叉，便可視為台股長線將「由多翻空」的訊號，主要是追蹤2000年以來，台股合計有12次出現月KD在70以上死亡交叉的變化，不僅台股後續表現都偏弱，由最高點與最低點所計算出來的平均跌幅，竟然高達22.07%，換言之，從統計數據來看，似乎也印證了上述的論點，這12次分別為：

# ①2000年4月

當時月KD在72附近死亡交叉，不但開啟長達19個月台股的空頭走勢，最大跌點更高達6,892點，跌幅為66.73%。

# ②2004年4月

當時月KD在81附近死亡交叉，不但開啟5個月的空頭走勢，最大跌點為1,661點，跌幅為24.02%。

# ③2006年6月

當時月KD在74附近死亡交叉，在2個月的空頭走勢中，最大跌點為735點，跌幅為10.55%。

# ④2007年8月

當時月KD在85附近死亡交叉，在1個月的空頭走勢中，最大跌點為1,278點，跌幅為13.79%。
