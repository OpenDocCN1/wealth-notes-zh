# 複製成功經驗
賺錢方法有跡可循

為了尋找台股中被人埋沒的隱形冠軍企業，幾年前我南下彰化和美，獨家專訪耀億（4430）董事長王昭仁，這是一家全球最大的線材供應商，在網球拍線市場的市佔率高達 80%。

在採訪過程中，有一段故事讓我相當感到興趣，因為追溯王昭仁的發跡過程，早期是以送瓦斯開始，最後竟蛻變成全球線材的專家，不僅在球拍線上擁有壟占的市場地位，產品還延伸到釣魚線、割草線等，甚至還打入全美最大女性內衣品牌「維多利亞的秘密」與全球最大車商Toyota的供應鏈中。
