# 大成長與大擴產的2大思維

思維1 — 今年要有大成長，1～2年前要先大擴產

思維2 — 大擴產定義：年度資本支出占股本80%以上

哪裡找？ — 現金流量表中的投資活動

資料來源：《投資家日報》

以工具機大廠上銀（2049）為例，2016年固定資產增加了25.9億元，預付工程及設備款也增加14.77億元，兩者合計40.67億元的金額，便可視為當年度的資本支出，此外，若以2016年上銀股本27.47億元來看，當年度超過股本148%規模的資本支出，一方面可看出董事長卓永財想要帶領公司「大成長」的企圖，另一方面若能搭上產業的成長趨勢，營運與股價的節節高升，自然就是預料中的事。

以上銀2018年1～4月繳出累積營收年增率達51.75%的成績單來看，這一波股價走高至530元的過程，不僅是建立在基本面強勁的基礎上，也呼應董事長卓永財先前在集團尾牙上喊出
