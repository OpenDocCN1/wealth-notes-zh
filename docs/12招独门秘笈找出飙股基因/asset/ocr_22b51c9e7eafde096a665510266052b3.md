# 多頭格局下的均線條件

+   條件①
股價站上所有均線之上
過去買股票的人都賺錢，沒有解套賣壓

+   條件②
均線上彎
底部越墊越高，形成股價上漲助力

+   條件③
均線呈現多頭排列
股價下跌會有支撐

![](bbox=[0.67, 0.38, 0.87, 0.48])

資料來源：《投資家日報》

總結而論，所謂危機入市3部曲的第1部曲，就是一定要經歷公司遇到麻煩、股價出現重挫的過程，此外，即使歷經股價重挫，後續出現一波反彈，我認為只要沒有經過「整理」階段，股價上漲都只能視為「反彈」，而非開啟另一波多頭行情。

而所謂整理階段，指得就是要經過2部曲所談的「均線糾結」，至於最後能否成功邁入「重返榮耀」的3部曲？一般而言，只要能進一步搭配到基本面的利多條件，通常股價自然容易出現驚驚漲的走勢，並讓投資人可以在最短的時間內，獲取到最大的利潤。
