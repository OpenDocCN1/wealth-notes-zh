# 2015～2018年漢唐（2404）股價走勢

資料來源：CMoney 資料整理：《投資家日報》

上述的概念，就好比加入健身房的會員一樣，對健身房的經營者而言，雖然預收了會員1年或數年的會費，必須認列在資產負債表中的「負債」上，但由於未來還債的方式是透過提供對等的「健身服務」，而非「金錢」，因此只要未來兩造雙方沒有毀約，這筆「負債」最終還是會反應在「營收」與「獲利」的數字上。

舉例來說，從2015年以來，我便持續追蹤至今的半導體設備股漢唐（2404），之所以能夠在股價還在33.55元時，就看到其未來的投資價值，並掌握到後續股價翻倍大漲到72.7元的過
