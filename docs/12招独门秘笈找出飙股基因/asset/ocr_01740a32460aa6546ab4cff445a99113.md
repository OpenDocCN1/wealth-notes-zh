# 股價站上20週均線 買進訊號才真正浮現

20週均線，是我平日會用來判斷一檔股票長期趨勢「由空翻多」或「由多翻空」的參考依據，其原則有二：進場要慢、出場要快。換言之，當週線的收盤價站上20週均線，才具有浮現「買進訊號」的條件，不過只要日收盤價跌破20週均線，就具備了「賣出訊號」浮出的條件。

整體而言，我針對「20週均線」進行了2個不同時期的大數據分析，只要台股中的任何一檔股票，股價站上20均週線就買進、跌破20週均線就賣出，在完全不管考慮任何產業分析與財報分析的影響，其結果如下。
