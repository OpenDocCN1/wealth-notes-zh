# 成為贏家的條件

![](bbox=[0.155, 0.308, 0.805, 0.425])

資料來源：《投資家日報》

股票投資對我而言，是當作一輩子的事業在認真經營，因此從2009年開始主筆《投資家日報》以來，將近10年時間，過程中累積了許多投資經驗，其中雖然有賺錢的股票，也有賠錢的股票，但我堅持每一筆投資決策都必須詳實記載，長期累積的分析內容，不僅提供我追求「精益求精」的重要依據，更促成了2016年以來，《投資家日報》對股票分析越來越「犀利」的關鍵。

平心而論，這2年之所以能夠在股票分析上越來越犀利，其實可歸功於2012年年底，我在組織內推動「複製成功經驗」的專案，因為從那時開始，我便不斷地試圖從過去諸多成功的投資經驗中，找出一些共同特色，並且將這些共同特色量化成實際數據，作為選股的條件，以及「買進」與「賣出」的依據。
