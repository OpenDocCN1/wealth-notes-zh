# 大江生醫 (8436) 危機入市3部曲的規劃

+   跌深
○ 股價從144元腰斬到72元
○ 麻煩事：中國頗布進口禁令

+   整頓
○ 短中長期均線逐漸完成糾偏
○ 解決麻煩：與日商結盟，擴大中國投資

+   動揚
○ 重回多頭格局
○ 利多：2015年第3季上海S8廠加入營運

本保健飲料大廠DyDo Drinco策略聯盟，強化未來布局中國市場的能量，另一方面則擴大上海廠的生產基地，落實在地化生產的營運方針。

# 最終曲：重返榮耀 股價重回多頭排列

大江規畫的上海廠，總產能較原本的主要生產基地屏東廠整整大上2倍，因此在2015年第3季開始量產加入營運之後，不僅支持營運重返榮耀，更讓大江股價的均線開始朝多頭排列發展，一路上漲至2018年4月時的最高點478.5元。
