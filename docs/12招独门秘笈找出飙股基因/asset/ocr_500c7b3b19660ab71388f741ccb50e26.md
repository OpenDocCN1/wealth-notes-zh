# ①黑膠唱片的「類比」音質，更勝於「數位」音質

根據許多樂迷的分析，黑膠唱片撥放出來的音質，相較於數位化音樂，更有立體感、更溫暖、更動態、更真實自然，因此得到許多樂迷的認同與愛好。

# ②黑膠唱片對唱片公司的利潤很大
