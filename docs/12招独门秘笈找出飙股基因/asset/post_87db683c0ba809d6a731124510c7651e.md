# 搭配均線糾結 投資更有效率

在了解大數據分析的客觀驗證之後，再來檢視老牌的家電廠大同（2371）。

大同的股價從2016年8月時的5.2元，一路狂飆到2017年2月的20.65元，波段漲幅達到驚人的297%，分析大同能夠出現如此剽悍的漲勢，一方面歸功於2017年的董監改選，另一方面股價長期「遠低於」每股清算價值，更是一大關鍵。

以大同2016年第3季的財報為例，總資產為2,402億元、總負債為1,511億元、應收帳款與票據為110億元、存貨為173億元、長期投資（大數據版）為69億元，因此可計算出清算價值為539億元（2,402億−1,511億−110億−173億−69億），以股本233.95億元計算，發行股數為23.395億（股本×0.1），換算下來，大同的每股清算價值為23.04元（539億元÷23.395億股）。

我有時也會參考市場行情，使用另一種更嚴格的計算版本，所有的項目基本上都是一樣，差別就在於「長期投資」的認定，以大同為例，大數據版僅為69億元，嚴格版則提升到211億元，主要是加計了「投資性不動產」的會計科目，其結果便是每股清算價值從23.04元下調到16.97元，當然調整的結果，也會導致目標價跟著向下修正。

# 獨門秘密 第10招

# 仿效彼得林區 十倍打

投資一家營運正在成長、股價又便宜的公司，是我認為能夠長期戰勝市場的重要關鍵，然而，上述的觀點，卻會牽涉到2個問題，一是如何定義「營運正在成長」？二是如何定義「股價便宜」？

「本益比」是目前市場中最常見、用來定義一檔股票股價高低的財務準則，但本益比最大的缺陷，就是本身並不會透露價格的合理性，換句話說，20倍本益比是「高」還是「低」？很難有一個明確的界定，因為用在3D感測概念股、電動車概念股或許是低，但如果用在食品股可能就高不可攀了。

當然，上述評價的過程中，還要考慮到整體市場的本益比、主要競爭者的本益比，或者公司歷史的本益比等資訊，才能理出具有參考價值的頭緒。

# 營運成長公司 有方法找出便宜價買進

「股價盈餘成長率」提供了一個解決的方案，美國投資大師彼得林區（Peter Lynch）在其著作《選股戰略》表示，如果一家公司的股價盈餘成長率僅有0.5（成長率是本益比的2倍），他會毫不考慮地進場逢低買股票，反之，如果一家公司的本益比是成長率的2倍，那麼他情願帶著家人去賭城拉斯維加斯度假，開心地花掉這筆錢，也不會傻到買進這家公司的股票。

# 用「股價盈餘成長率」判斷股價高低

股價盈餘成長率 = 預估本益比 / 預估未來5年每股盈餘成長率

若未來5年股價盈餘成長率為30%，則：

合理本益比 30倍

超跌本益比 15倍

超漲本益比 60倍

舉例來說，假設一家公司未來5年的盈餘成長率為30%，那麼合理的股票本益比就是30倍，當本益比掉到只剩下15倍時，不僅是絕佳的買點，更是投資人安心賺大錢的保證，因為買到了一家營運成長、股價又便宜的好標的，相對的，本益比若來到60倍，就可視為市場過度追捧，股價隨時有泡沫破滅的風險。

談到彼得林區，就不得不提到他最擅長的投資策略，就是從生活中找10倍飆股，不僅讓他在擔任麥哲倫基金經理人的13年期間，管理資產從2,000萬美元暴增到140億美元，更被華爾街譽為與巴菲特同為「神」級的投資大師，其代表作分別為：沃爾瑪賺了1,000倍、麥當勞賺了400倍、The Home Depot賺了260倍。

再回到彼得林區對「合理本益比」的看法，在實務經驗中，彼得林區分享的這套選股邏輯，會牽涉到一個現實問題：如何預估一家公司未來5年的盈餘成長率？

雖然在財報分析中有個公式，可以換算出一家公司的盈餘成長率：股東權益報酬×（1－股利支付率），但未發放股利的企業並不適用上述公式，其次，隨著目前全球產業趨勢的變化加快，要預估5年的盈餘成長率，除非加入「折現率」，否則將嚴重失準，然而「適當折現率」的給予，又會牽涉到非常複雜的計算內容，因此在主觀與客觀條件都不容易達到的情況下，投資人確實不容易使用「股價盈餘成長率」。

為了解決實務面的困難，我進行了一些改良，在不違背上述「精神」、考量能夠符合台灣財報公布原則，以及市場現況的條件之後，重新定義「營運成長」與「股價便宜」的內容。

就營運成長部分，以「過去3個月的營收」做為選股條件，只要一家公司連續3個月營收年增率都超過30%，就符合「營運成長」的定義。

股價便宜的依據，則以過去4季累積EPS做為計算基準，在近4季獲利皆無虧損的情況下，當一檔股票本益比落到10倍時買進，回升到15倍時賣出，作為此投資策略的大數據分析依據。

# 彼得林區「十倍打」的投資策略

- 條件1 過去3個月營收年增率皆超過30%
- 條件2 本益比在10倍以下買進
- 條件3 本益比15倍以上賣出
