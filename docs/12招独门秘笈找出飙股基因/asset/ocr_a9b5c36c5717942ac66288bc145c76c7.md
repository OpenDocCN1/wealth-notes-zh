# 理由①台股多頭「結構」非常健全

透過觀察呈現短中長期均線（月、季、半年、年）多頭排列家數的多寡，來判斷台股指數的虛與實，不僅是我獨家的分析觀點，更多次應用在「提早抓出」大盤重要轉折的成功經驗上。

回顧2015年台股攻萬點時的情景，當時呈現多頭排列的家數一路走跌，從前一年度的551家，下滑到345家，甚至攀上萬點時，家數更只有294家。換言之，以這樣的趨勢來看，縱使台股在2015年4月28日最高來到10,014點，但整體結構不僅是「虛」的，更埋下日後暴跌到7,203點的警訊。

反觀2017年台股攻萬點時的多頭排列家數，一路從2016年11月時的226家，上升到12月的309家，2018年1月的319家、2月的460家、3月初的533家，以及3月21日的604家，這不斷走揚的趨勢，充分顯示此次多頭格局，結構確實非常扎實。

上述的概念，就好比觀察一個人的體態，不能只以「體重」的高低，作為判斷的標準，還必須搭配「肌肉比」，舉例來說，NBA球星林書豪與前副總統連戰之子連勝文，兩人身高與體重幾乎完全一樣（連勝文多了1公斤），但外在的體態之所以會相差甚遠，關鍵就在於一個是「長肌肉」，一個是「長脂肪」。 

現階段的台股，從股價呈現多頭排列的家數一路走揚來看，指數位置雖然看似高，卻都是「長肌肉」的高。
