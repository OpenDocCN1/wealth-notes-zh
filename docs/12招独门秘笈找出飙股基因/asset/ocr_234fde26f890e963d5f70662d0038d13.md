# 2004～2017年邦特（4107）股價與月KD

![](bbox=[0.183, 0.229, 0.857, 0.471])

資料來源：CMoney 法人系統 資料整理：《投資家日報》

③2012年2月：當月KD在15附近完成黃金交叉之後，則是掀起了股價從27.1元飆漲到173元的序幕。

值得留意的是，2017年10月，邦特的月KD再度在13附近黃金交叉，而10月的收盤價為89.5元，後續股價的表現，確實有了值得期待的空間。

工具機大廠的上銀（2049）也出現類似狀況，2016年2月的月KD，在16附近出現黃金交叉的變化，開啟了這一波從134元飆漲到2018年4月530元的波動行情，股價累積漲幅不僅已超過300%，更成為2017～2018年台股的亮點飆股之一。
