# 策略①：自股價高點回檔超過20%

對於一檔正在走「大多頭」行情的股票而言，我的習慣，只要收盤價未跌破自高點回檔的20%，都會假設這檔股票的多頭走勢還在持續中，因此當前股價的任何起伏，都視為正常的短線波動，無須過度反應，持股續抱就是最佳策略。反之，若有一天收盤價跌破回檔的20%，就要開始認真考慮「停利點」，將獲利入袋為安。
