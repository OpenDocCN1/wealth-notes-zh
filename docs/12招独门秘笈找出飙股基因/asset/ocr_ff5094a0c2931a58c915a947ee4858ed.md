# 1994~2018年宜進（1457）月線走勢圖

![](bbox=[0.18, 0.246, 0.805, 0.505])

資料來源：CMoney 法人系統 資料整理：《投資家日報》

前3次宜進股價在15元附近時，成交量都不小（3次累積的成交量高達76.6萬張），因此2017年雖然受到本業轉好、業外又大進補的利多，股價呈現穩步走揚的趨勢，但累積長達17年等著解套的籌碼，都讓這一波宜進的上漲走勢，在15元附近的價格就遇到沉重賣壓。

不過話說回來，一旦宜進未來股價能夠成功化解並突破15元的天花板，不僅在技術分析上，將打岀一個結構非常扎實的底部，更容易引導後續的股價，出現一波上漲無壓力的走勢。
