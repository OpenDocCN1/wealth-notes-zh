# 從均線排列方式 觀察漲跌趨勢

一般而言，不同天期的均線，可依不同的高低順序，出現不同的排列組合，其中若是出現月線＞季線＞半年線＞年線的組合時，稱之為多頭排列，因為這代表長天期的成本最低，短天期的成本最高，不僅代表市場短線追價意願較高，此時若能搭配均線上彎的走勢，以及股價越過月線之上，更是「強勢多頭」的重要指標，因為股價上漲將看不到壓力。

反之，若是出現年線＞半年線＞季線＞月線的排列組合，則被稱為「空頭排列」，一方面是因為市場投資人短線上不計成本地往下（降價）賣股票的心態，容易形成股價越走越低的趨勢。另一方面，長線也會形成股價上漲的壓力，因為股價漲到季線，就會面臨季線的解套賣壓；漲到半年線，就會遭遇半年線的解套賣壓，即使突破層層關卡漲到了年線，累積1年的解套籌碼，也會讓股價想要再突破的難度非常高。

此外，由於一家公司若今天遇到了營運上的任何麻煩，絕不可能在明天一大早起床之後，就看到麻煩奇蹟式地被解決，因此在正常情況下，需要經歷長時間的努力，才有可能解決麻煩，通常少則半年，多則1～2年，甚至有些公司始終身陷泥沼中而無法回升。
