# ②2010～2014年（多加「連續4季獲利」條件）

為了進一步優化上述投資結果，我在選股條件多設了「持續獲利（過去4季皆獲利）」的條件，目的就是為了排除某些公司因為處分土地、處分轉投資，或其他因素造成的一次性認列收益，大幅美化EPS帳面數字的假象。關於上市櫃公司的CEO如何利用「處分利益」達到美化EPS的議題，有興趣的投資人，可以延伸閱讀《源源不絕賺好股》書中的內文。

整體而言，多加一個「持續獲利」的條件，反應在股票操作的過程上，確實可
