# 台股2大友善投資環境

![](bbox=[0.206, 0.24, 0.842, 0.414])

資料來源：《投資家日報》

不過對短線投資者而言，台股就不是一個友善的環境，因為交易成本之高，幾乎可以說是獨冠全球，以1,000萬元資金為例，假設每一次都不賺不賠（例如用108元買進鴻海，同樣用108元賣出），只要進出100次，1,000萬的本金將只剩下557萬元。

台股會有這麼高的交易成本，關鍵原因是現行賣出股票所課徵的千分之3證券交易稅，其實已經內含「證所稅」的概念，畢竟追蹤民國43年所制定的《證券交易課稅辦法》，當時稅率僅為千分之1，之後由於證所稅於民國79年停徵，才上調到千分之6，民國82年之後，再降至千分之3至今，換言之，多出來的千分之2證交稅，就是課不到「證所稅」後政府做的補償方式。
