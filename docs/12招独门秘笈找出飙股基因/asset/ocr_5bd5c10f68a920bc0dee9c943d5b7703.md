# 利用年初觀察 可窺知公司營運面貌

看到創意身處在「春節加班出飆股」的行列中，就不得不提起先前我獨家專訪創意總經理賴俊豪的一段小插曲。

當時我花了將近2個小時的時間，請益台灣IC設計服務產業的優勢與未來成長契機，並於採訪過後寫了一篇研究報告，標題為「創意所屬的IC設計服務產業，未來還有100倍的成長空間」，不過隨即接到公司派來電，提出能低調一點的要求，後來修正為「還有很大成長空間」的字眼，但絲毫不影響創意這幾年投資價值的大幅提升。
