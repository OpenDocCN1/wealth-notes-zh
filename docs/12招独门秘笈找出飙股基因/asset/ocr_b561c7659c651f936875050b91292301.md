# 解股基因 2-5

# 黑K之3 只有上影線的黑K

雖然一度有買盤試圖推升股價，但在賣壓沈重下後繼無力，收盤反而到最低點，若出現在跌勢時，代表未來股價恐將持續下跌。

![](bbox=[0.195, 0.178, 0.34, 0.247])

# 黑K之4 只有下影線的黑K

開盤雖然湧現賣壓，但盤中出現逢低承接的買盤力道，若出現在波段跌勢中，代表有機會出現短暫的反彈，甚至結束空頭走勢。

![](bbox=[0.195, 0.299, 0.336, 0.367])

# 特殊新影 十字型（白忙一場）

多空力道勢均力敵，通常有反轉或趨於盤整意味，上下影線的長短，代表多空激戰程度；上下影線越長，則多空交戰越激烈。

![](bbox=[0.188, 0.417, 0.322, 0.493])

# 特殊新影 T字型（白忙一場）

雖然開盤後賣壓沈重，但逢低承接的買盤也相當強勁，出現在跌勢中，隱含「強力反彈或反轉」的可能；下影線的長度越長，效果越明顯。

![](bbox=[0.188, 0.563, 0.32, 0.603])

# 特殊新影 逕雷針（釘錘線）

雖然代表有強烈的上漲意圖，但高檔卻遭遇強大的賣壓，若出現在波段上漲行情中，要注意可能隨時反轉向下。

![](bbox=[0.188, 0.678, 0.32, 0.735])

# 特殊新影 一字型

不是大好就是大壞，也就是漲停板或跌停板一價到底，這類型K線最常在成交量極小的股票中出現，通常代表上漲或下跌趨勢將持續。
