# 月KD黃金交叉 往往贏到大波段行情

以2012年到2013年期間，讓我大賺的生技股邦特（4107）為例，當初在做投資分析時，「月KD在20以下黃金交叉」的條件，確實提供了重要的參考指標。追蹤2006年以來邦特股價走勢，每次股價大漲前，都伴隨月KD在25以下黃金交叉的變化。

+   ① 2006年3月：月KD在16附近黃金交叉，開啟了股價後續從8.56元大漲到55.3元的波段行情。
② 2009年2月：月KD在22附近黃金交叉之後，再度上演股價從18元大漲到55.9元的驚喜。
