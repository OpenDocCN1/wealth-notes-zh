# **第七章：饭局上最好的躲避喝酒的托词和做法，很多人的托词都是错误的！**

2019-06-11 23:15:41

本文给大家讲一讲饭局上躲避喝酒的托词和正确做法。

当然，这一章不是求人办事的饭局了，大家看过我前面讲的那些，也知道我的观点。求人办事，你能喝也得喝，不能喝也得喝，你这个攒饭局的人都不喝，大家都端坐在饭桌周围，寒暄蹬蹬聊国家大事、本地趣闻，吃饱了，嘴一抹，走人。

这种饭局能办成啥事呢？

我今天讲的是普通饭局躲避喝酒的托词和正确做法。这可能比较普通，稍微懂点智慧的，估计都懂这些。

估计在看我专栏的，大部分都是年轻的职场人，年轻人在参加饭局时（有领导在有长者呢），一定要有年轻人的样子，什么年轻人该有的样子呢？端茶倒水你来吧，转餐盘碟你来做饭、领导筷子掉地了得你去拿吧、红酒醒一醒、分酒器分一分，这些都得你来吧等等。当然，有部分读者觉得这些事情包里都有专门的服务员，嘛他们来做就是了，毕竟给了服务的。是，本来他们做也可以，但你把这个活抢过来，顺带说一句：平时很少有机会会给导游服务，今天我得抓住机会；平时不是忙工作就是忙其他的，很少有时间教长辈靠您，今天我得抓住机会。

你觉得这样做、这样说，是不是更好一些呢？

年轻人想要操盘求人办事的饭局，我建议先从这种普通饭局入手，起码得会说一些场面话、应景话之类的吧，起码能及时发观饭局上他人的需求吧，起码能面面俱到，能主导饭局的走向、控制好大家的酒量既喝好又不至于喝多、喝出问题。

扯远了。

还是扯回主题：如何躲酒吧。

一般的饭局，无关痛痒的饭局，比如同学、同乡、朋友之间的聚会，你想喝就喝吧，实在不想喝，随便找个借口，就能搪塞过去，比如说今晚确实不能喝，在赶计划；今晚还要回去加班，要帮领导写一个讲话稿；我开车来的；胃炎这两天犯了，辣椒都不能吃，更别说喝酒了；刚吃了头孢等等吧。

当然，也有一些爱打酒官司的人会调侃你两句，甚至力劝你几句：今天多场合，怎么着也得喝一点，总量控制一下，你就喝二两，二两、二两等。

你千万别实诚得听信他，你只要让他倒了酒，就不是喝二两了，就是二两二两得喝了。

所以，态度一定要坚决，再强调一遍：今天是真不能喝，原来我喝酒干什么时候抱过大家后腿，今天特殊情况，大家记着，下次我补上。

下次？下次谁还记得这次的事。

别干这种蠢事：刚开始嚷嚷着不喝，别人劝两句，揣头草坪的说：好吧好吧，你倒吧。如果你一直是这种喝酒作风的活，别人会觉得自己不实在，喝酒都扭扭捏捏或者说没有自己主见。

今天不喝就是不喝，反正具体问题我已经摆出来了，如果他们怪罪，怪罪好了，又不是你的错，是他们莫名其妙而已。

如果有领导参加过的饭局，当然，这种饭局较之前少了很多，但不是没有。这种饭局，你如果能喝就尽量喝点，喝不多，可以少喝，但最好不要一点都不喝，尤其是领导都在端杯子喝的时候。

但如果确实不能喝，最好在饭局开始前，就给领导报告一下，不要到饭桌上，人家给你倒酒了，你才说出来，这个时候领导大概率会说：多少喝点。

这个时候，你不喝吧，领导多少会觉得没面子，你喝吧，又违背了你的初衷。所以，提前给领导说，这样，饭桌上别人给你倒酒时，你说不喝，即便别人打酒官司，领导也多半会站出帮帮你唱场：他不喝就算了，平时他确实也没喝调。今天又有特殊情况。

酒不喝，话要到位、接下来的行动也要到位。

话要到位：今天实在是抱歉，确实有特殊情况，只能以茶代酒，请领导不要怪罪，是我今天就负责做服务工作了，酒和茶放我这边了，我负责给各位领导倒茶斟酒。

接下里的行动要到位：大家频频举杯，你也得跟着端，等你觉得气氛差不过的时候，或者大家都互敬的时候，你也别干坐在座位了，站起来游走，看到谁的杯子没茶凉了，就去坐下一下需不需要倒茶？看到人家的茶杯一空了，就过去给人家倒满。看哪个热菜凉了，需要加热下，就喊服务员过来帮杯热一下。看哪个领导想去找洗手间，就帮忙在下路，或者帮忙打开一下包间里的洗手间门。看哪个领导旁边的酒瓶里堆的有点多，就帮忙收拾到一边。等等。

读者们，千万别忽视这些有眼力见的事了，你们让他们都把这些事干不了，怎么体现你有眼力见呢？怎么体现你服务到位呢？领导又是不带着服务员参加饭局，是带着你来的。

当然，你看别人敬来敬去，你也想表示下尊重，你也想敬别人。可以敬，但节奏晚一会，你一个喝茶的，那茶敬别人，本身就是不公的。所以最好等别人先来敬你，然后你一定要注意表示很歉疚的说几句抱歉的话，比如：我应该先来表达您的，领导，但我想着我喝得不多，实在有点不太好意思，感谢、感谢！您接一下就就可以了，我端正态度，我把茶喝完。

这节就写这么多，因为在写本章的时候，我刚喝完酒回来，一一回答全知识星球上读者的几十个疑惑，已经是凌晨两点多，酒意、困意来袭，迷迷糊糊的敲出了近两千字。

总之，在饭局上，无关紧要的饭局，是否喝酒，你随意，那是你的自由，别听劝酒人瞎叨叨就改变主意，这种主意你都没成个不了，轻易被别人改变，这种人你难成大事，估计小事都做不成了。

有领导在的饭局，也可以不喝，但得用话术和行动来补足不喝酒的欠账。毕竟，在座的都是领导，你以后得求人，就你的身体是身体，人家的身体不是身体？所以在他们面前你不喝酒是理性的，得用其他你来补。

本章完。各位晚安。
