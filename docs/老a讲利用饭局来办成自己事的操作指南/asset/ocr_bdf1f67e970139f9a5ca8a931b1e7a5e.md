# 第十章：求人办事的饭局，一定要在散席后抓住机会，抓什么？怎么抓？

2019-06-01 23:25:55

很多年轻人，请人吃饭，吃完了吧？各自回家，各找各妈？

那不行。

因为整个饭局最关键的，在我看来就是饭后的独处时机，因为前期铺垫了那么久，饭后的独处就是要把诉求提出来的时候了，很多人觉得饭局后大家都喝得差不多了，领导也想休息了，就让领导回去休息了，想到等第二天再去领导办公室去说。

你可想错了！打得亲热越热，明领导都灌醒了，在办公室正襟危坐，没有酒精的刺激，他一切又恢复往常，你求他的事说出来，他要么说研究研究，要么说考虑考虑，大概率不会痛快的说行还是不行。

所以，当饭散席后，一定要抓住时机。

比如，你最好在人九点半左右结束饭局，因为还要留足时间说正事呢。如果一不小心闹腾到十点、十二点，那还有什么说正事的时间。

散席后，你护着领导走出饭店，悄悄的给领导说：旁边有个小茶馆，想再领导喝茶，正好有一件事情想给领导汇报一下。

领导说，不去了，有什么事你直接说。

你要接话道：那好吧，那我们散散步吧，就当消化下吧。

这样做的目的是，把说正事的时间稍微争取取得长一些，虽然，在领导寻回去的路上也可以说，但路上顶多只有二十分钟不到的事，他如果一口回绝，或模棱两可，你都没有进一步做工作的时间了，并且你们都喝酒了，肯定打车或等驾驶员开始，稍微做点你的事领导不是故意再第三者面前表述任何不利于自己的事的，你懂的越早、越难，说明在规则下越难办到，就越需要他突破规帮你办，他就越不会在第三者面前求我。所以，最好是在争取稍长时间的前提下，摒弃任何第三者。

至于你怎么跟他推，因为涉及到具体的事情不同，言辞也不不同。如果你从来没办过这种事，不知道该如何措辞，可关注我的公众号：你体内内阅读，才公众号菜单栏下方有：咨询老A，点击后进入我的星球，在星球里可以匿名向我提问，我可以根据你的具体情况，看你具体想象。我在星球里可以回答你的各种具体难题近4000个，这些难题，你也没有可以围观，这个星球，几乎囊括了单位人遇到的所有难题，人事晋升、推混别、同事攻讦、流言等等，在这个星球里，你能看到xianxianwangbanwei的困惑，能看到fujuzhang的麻烦，能看到bawei同志的困境。

刚才算是打了一个小广告。星球在那，你爱进不进，我也只是告诉你有这么一个渠道而已，虽然这个渠道也是我搭建的。

我回来继续说。

我前面讲过的，你千万别指望一顿饭领就就点头答应你求的任何事，人家不想老那顿饭，来吃你这顿饭，也是看起你。吃你的饭，不答应你的事，你就像撇油似的，又是水、又是苦药、又是表忠心的，这样就有失水准了，估计也永远没有下一次了。

如果领导态度坚决的拒绝你，没事。大度的表示理解，你理解也没办法啊，决定权在人家里手。比如说，领导说：这事不行，这事法不允许。你可以说一句：如果方便，一定请你领导想想办法。如果他还是说没说是没有办法，那就不用再逼着他了，立即大度的说：那好吧，领导你肯定是自己的难点，我不能为私，为了自己的事让领导为难，然后再聊点其他的，就让领导回去休息了。

这事完了？没事领你，他虽然拒绝了你，但你知道他的底线在哪里了。下次有小事可以再求他，大事你办不，小事总有没问题嘛。毕竟前期都已经铺垫成这个样子了。如果他连小事都不帮你看办，并且明明确就是他一句话的事，那这种人，是否值得你再投入，你要打个问号。因为这个世界上能有一种人是吃喝要是玩，但丝毫无私心事的。

当然，还有一种情况，就是当你提出诉求，他没有任何一口回绝，但是也没有立即答应，而是说了一些模棱两可的话或者说一些办来可能会很大难度的话，那大概率说明你求的这个事是有戏的，之所以不现在表态，或许是他的稳重起见，又或者是要进一步的观察你。

这种情况，你也不能逼着人家立即表态，心急，是吃不到热豆腐的，再说了，想吃热豆腐的人多去了，能这么容易就让你吃吗？容易吃到嘴的，都不是热豆腐，都不是什么好东西。

比如你要求点小项目款，你和某位上司说交情交情，你请他吃饭后，饭后提到了你的诉求，他一口就答应了，这时候，你还应该多问，而是迫切地抓起起来，你应该怀疑这个项目是不是里面有很多隐形的困难？是不是有一些隐形契约？是不是有一些群贪的利益难以满足？是不是有一些隐形的工程量？如果不是，那他为什么答应得这么快呢？答应得痛快，大概率说明这是一个烫手的山芋，熟悉内情的人不愿意来做，恰恰，不熟悉内情的你来了！

基本上就是这些了。

另外，不管人家是否办成，我建议你都要备一些“礼尚往来”的小礼品。至于有多少，你自己看着办吧，我把话说说到这个分寸了，你也看完了到篇，我相信，聪明如你，一定会明白我说明什么。

如果不明白，也不要留言问，如果明白了，也不要留言说。
