# 第三章：饭局中要送的东西，提前备好，你知道我说的什么

饭局，饭局，可不仅仅是吃饭，必须得有酒水。

尤其是求人办事的饭局，我觉得宁可没有饭，也必须有酒，因为酒能助兴，因为酒是这个世界上最能快速将陌生人的面具摘除，将两个并不怎么熟知的人的距离拉近。

你看那些人，在进馆子之前，都是一副公事公办，不可侵犯的凛然样子，等饭局结束后，又成了勾肩搭背，欲说还休的架势，是饭菜的功劳？是酒精的功劳！

所以，很多求人办事，忽略了酒的作用，只在菜品上下功夫，顶多也只是让对方吃了一顿好饭菜。你不用酒把他的防备、戒心、庄重、架子都放下，你怎么好提出自己的诉求呢？所以，我写这个饭局的专栏，着重点，也是在酒上，而不讲什么狗屁礼仪、点菜、着装等等，这些大路边上的东西，既不是重点、也并不是难点，你们随便在网上搜一下，都能够知道。

这一小章，我是想说：领导答应赴宴后，你必须把东西准备好。尤其是酒。

如果你能打听到他喜欢喝哪种酒，那你备好就是了。

如果不知道，那你应该多少都备点。白酒，酱香型、清香型的都备点，备点啤酒，备点红酒。你可能觉得饭店里有啤酒啊，但，如果领导执意不喝酒时，你说喝点啤酒，他还是不喝，毕竟饭店里啤酒都是路边货，不是燕京就是纯生、青岛，你备的啤酒可不能是这样路边货，哪怕是价格不高的国外啤酒，你也可说是一个朋友在德国带回来的，这是德国最好的啤酒，只有一条流水线，是限量的，领导你尝一尝，不多喝。

不这样，你劝不下去酒的。甚至，连开始都开始了。

备点红酒，是以防他连啤酒都不喝，那只能说喝红酒了，毕竟红酒在大多数眼中，是具有养生功效的，起码能软化血管。（虽然我不觉得，都是酒，都伤肝，软化血管，只不过是噱头）。

备红酒的另外一个意思，是饭局中难免有女性，在较高档的饭局上，让女性饮白酒，是很不绅士的，除非她自己主动喝，你不能力劝。很多基层的领导却反其道而行之，有点小权力，逼着女性喝白酒，一直喝到人家丑态毕出，他才心满意足。这是一种恶习和陋习，也是闲的没事干吃饱了撑的。毕竟女性在这个社会上处于弱势群体，因为他压根就不会想到女性喝多了，回家是否安全？如果觉得无所谓，为什么不回家灌自己老婆喝呢？

扯远了，以上我说的是酒要备好。

并且，备足。只有备足了，遇到领导执意不喝时，或少喝时，你才能拿酒来开路，每种酒，都有让他品尝的一番说辞，你花这么大心思准备了，他不喝，会有却之不恭的感觉。

除了备酒，还要准备哪些东西呢？

求人办事，有些心意，是要提前表达的。所以，你懂得是什么。

这些东西，你也得提前准备好，即便饭局时，他态度比较强硬的表示无能无力，你也得提前准备好。

很多大事的办成，是一波三折的、是需要多次协商的、是需要反复攻坚的，所以那些心意，即便没办法让你一次就把事办成，也能成为你办成事的一块小基石。

既然话说到这了，我不得不给各位泼一盆冷水了，我估计你们看完我这个专栏，一定有机会让你们实践我讲的饭局里的这些，但，你们千万不能指望一次饭局就能帮你解决问题，即便你这个饭局安排的再完美。

为什么这么说呢？

因为有好事，有利益，大家都会去争取。你之所以安排饭局，是因为你们还不算熟，熟的关系根本不用饭局，一句话就搞定了。你安排饭局想促成好事，是想在半路截胡，你可能截胡成功，但大概率是不成功，因为，他对这个好事，可能另有安排，或者已经有确定的人选和目标。

但你也不灰心，因为他还会有其他好事，即便这次不成，下次不成，下次下次不成，总有成的那一次，毕竟，这么多年，你一直不断这条线，一直让你这么投入，而让你见不到收成，他自己都会于心不忍的。

不是有老话是吗？常与领导吃饭，提拔是迟早的事；常跟大款吃饭，发财是迟早的事。

是的，是迟早的事。
