# **第五章：饭桌上别提你的任何诉求，可以点一点，但是别说全，说了也白说，那什么时候说？**

2019-06-11 23:12:31

写这个标题的时候，我觉得写的有些武断了。其实你要求上司办的事，是可以在饭局上提的，我只是想说，提的时候不要大声说出来，悄悄附在他耳边悄情还是可以的。

上司，大多都很多疑且机警，如果你当着饭局上很多人的面，提出你的诉求，即他他喝调了，他也也有可能没有放松警惕心，如果涉及到原则性的诉求，他一般不会把内心真实的想法表露出来。我举例说明：

比如你想提正科，在饭局上，喝着喝着，你觉得气氛差不多了，直接就说出来了：领导，我在办公室也干了好多年了，您看看能不能提携一下，我想在进步一下，到更高一个平台上继续给领导服务。

你说这些话的时候，饭桌上的人都听到了。

你指望领导怎么说，或许，有些不拘小节的领导会拍着胸脯说好好好，小伙子早就该调窝了。这种爱拍胸脯打票领的导的话，我是不太相信的。但是更多的领导，是不会在这种情下给你表什么态的，他大概率会说：这种事情，人部门会统一协调，你安心工作，单位是不会亏待老实人的。我觉得在这种情况下说这种话的领才是成熟的领导，不然就是不成熟的。为什么呢？

当着这么多人面，你问这种提拔的问题，他如果打了包票，给人的感觉岂不是单位成了他的一言堂，民主呢？党组会呢？这些都不用考虑了吗？万一下子青，饭桌有一些别有用心的人把一些不合时宜的话录下来，弄成一个小风波事件，岂不是要死。

比如你请上司吃饭，想要上司把那小工程拿给你做，你童言无忌的说出来：领导，那个工程，您看交给我做可以吗？我做过很多这样的工程，有资质，有经验，您放心，绝对做得妥妥当当的。

上司心里肯定想：真是个二傻子。

这种事情能在这种场合下公开说吗？如果上司大嘴巴一长：好好好，就交给你做吧。

那其他人会怎么想这位上司呢？

有句古话说得非常好，君不密则失臣，臣不密则失身。大概的意思就是说要让自己嘴巴严一点。说什么话要分什么场合，秘密的事，就秘密的说，不要公开说。

求人办事也是一样的，很多事，都是违背原则的，怎么能当着一帮人说出来呢？尤其是当着一帮喝调的人，万一这些人酒后多言，回家就给老婆或者朋友吐出来，上司岂不是自己给自己找麻烦？如果你欠考虑的当着很多人面请求上司、上司也欠考虑的答应，那这种手泄露出去，日后传到上司耳朵里，你觉得他会反悔吗？当然会！一定会！

所以说这种事的时候，一定要悄情说。

但我更建议，饭局结束说。

比如，饭局结束后，你总不能上司自己回去吧、你要把他送回去吧。

在回去的路上，你可以向提出你的请求，或者你不说，聪明的上司也会主动问你：今天让你破费了，你一直没说话，但是我知道你有事，你说吧，能办的我就帮你办，不能帮你的，你也多理解。

这个时候你就可以说出你的诉求。

诉求说完了，可以听下他的回复。

你千万不要指望他立即就回复：好，这事我帮你办了。

这样回复的上司，多半也是过于耿直的生手。

他多半会说：这个事，我回去研究研究，后面再给你答复吧。或者说：这种事，我说了不算，我帮你留心一下吧。总之，他不会把话说得太死。

其实无论他是否把话说得太死，都无所谓。你只要确定他能帮你办这个事，就够了。

因为，这个饭局只能起到这种作用，牵线搭桥的作用。

剩下的，要继续跟踪，才能落实。

很多人不知道该怎么做跟踪。我在这里也没办法展开讲，毕竟，这个专栏，我只是讲饭局的。所以我只围绕饭局来展开讲。如何跟踪后者panfu，大家可以参照我曾经写的三个专栏，那三个专栏，可能会教会你其他的一些技巧。
