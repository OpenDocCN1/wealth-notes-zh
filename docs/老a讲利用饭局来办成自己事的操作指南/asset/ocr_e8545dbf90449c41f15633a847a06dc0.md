# 第九章：什么时候帮领导带酒、以及带酒的托词，这是饭局你能出彩的地方。

我年轻的时候，非常喜欢帮领导代酒。

不要以为这只是酒量的问题，没眼力见、没情商，这个活，干不了。

很多读者觉得：代酒？用得着吗？领导不喝吗，直接说不喝就是了，难道谁还强迫着他喝？

确实没人强迫。但是有人帮领导代酒，会在无形中抬高他的威严，也会让他有无时无刻有人跳出来提自己挡子弹的成就感或满足感。

关于代酒，我想到哪里就写到哪里，其他他没写到的，你们自己展开联想。

其实，不是所有场合都适合替领导代酒。比如单位年终聚餐餐（虽然现在这种聚餐极少），或者单位小范围聚餐，这种场合下，就不太适合帮领导代酒，为什么呢？因为大家都是领导的下属，就你跳出来帮领导代酒了，就你跳出来讨好领导了，其他同事都是傻子？这是明目张胆献殷勤的方式，会引起其他同事的背后非议，并且，大家很乐意在这个时候保持一致的贬低你，因为你是另类，他们做了他们没做虽然也想做的事，那你就是公敌，所以这个时候不太适合帮领导代酒，除非你是领导的秘书或者驾驶员，不然，最好不去出这个风头。

那，哪种饭局适合帮领导代酒呢？

我觉得是在参加饭局的人都不是特别熟悉的情况下。

比如你们出去去外地调研相关，当地肯定要尽地主之谊，一般来说，这种饭局，当地都是点到为止，但是难免碰到对方是爱喝酒的领导，那，这种饭局可能就不是点到为止了。那得喝高兴啊！

这种饭局，两边是不同的群体，相互不太熟悉，这种饭局你可代酒了。

但，不能乱代。

你在代酒之前，如果有比你稍微高点的领导，比如你的处长，想帮你们的tingzhang代酒，那你就不能再出头了，或者只要有比你高点的领导在场，你要去代酒，就必须事先请示下比你高的这个小领导的意思，不然，这个小领导大概率是不喜欢你这样做的，怎么，就能帮领导通风挡雨，我们就不能了？

你大可以先去请示这个小领导：领导，我看tingzhang喝不下去了，我酒量还可以，我想帮咱领导带几杯酒，您看需不需要？

他只同意了，你就可以去到大领导身边专门为他服务了。

怎么个服务呢？

端个分酒器，站在领导身边，如果有人来敬酒，你负责给领导倒酒，倒的时候稍微倒一点，边倒边说：领导，我少给您倒点吧，大家喝酒只是表示下敬意，您喝多喝少，都不会在乎的，您明天还有重要接待，您就少喝点吧。

如果领导点点头，那就是默许了你这样做，说明领导也确实不想喝了，只是盛意难却，不得不维持下去。

当然，你这样说，有些人会买账，但是有一些人不会买账，如果对方有不买账的，说：那不行啊，喝酒没有喝半杯的，一心一意，满上满上！。

这时候，就需要你跳出来代酒了。

你说：领导前些年喝酒是不要人劝的，但这两年身体原因，医生是不让喝酒的，今天确实盛意难却，领导不得不喝，但是今天确实已经超量了，再喝，估计晚上又要吃药了。这样吧，我倒满，我替领导干了这一杯。

不用等他在说什么，直接端起来干掉，干掉后，再补一句：我干了，您随意吧。

大部分人遇到这种情况，也不会说什么。

如果有傻子、或者已经进入醉酒状态的人，还不买账，还非要领导喝，你可以先让他把前一杯干掉。然后再附在他身边说：今天实在不好意思领，领导确实是身体原因不能再多喝了，多担待。

但，如来给领导敬酒的是对方的最高领导，你就不要代了。这种情况，领导也不会让你代，你最好也不主动提出来代。因为你们是一个档次的，这种酒你来代，好像人家那边没人代似的。除了对方最高领导来敬酒，你最好不帮领导代之外，其他的你可以在饭局中途，帮他代。

还有一种情况，最好不帮领导代。

比如，你的分管领导确实不能喝酒，但饭局上你的分管领导也在，这个时候你最好不要去帮分管领导代酒，毕竟一把在哪，你这样做，他心里肯定不舒服，你帮我的分管领导代，难道你眼里就没人了？所以这个时候代酒，是一件吃力不讨好的事。

当然，如来你帮领导代酒时，如果领导说不用，你去坐下吧，那你就乖乖坐下，不要非站在帮领导分担什么，这种情况，说明领导今天心情好，愿意多喝点，你不能拦着。

这个时候，你可以和其他人碰着交错了，但不要忘记领导，多注意观察他的水杯，如果水杯里没水了，就去给他倒满，倒的时候可以多说一句：领导，您多喝点水，解酒解得快。

或者，在倒水的时候，问一句：领导，要不要来一点西瓜汁，帮助解酒的。

总而言之，围绕帮领导代酒，将饭局上伤害领导身体的事情降到最低。

如果你眼光好，既八面玲珑又能遮风挡雨，他会很喜欢带着你参加他的饭局，在一起吃饭的时间多了，长了，那你就是他那个圈子的人。

或者说，是他的人。
