# **第一章：人都请不出来，你怎么办成事呢？该怎么样他才会出来？**

2019-06-11 23:06:20

很多人，想问题想的很简单：饭局有什么难的呢？不就请人吃饭吗？他想吃啥，咱请他吃啥，他不说，咱就请他吃最好的。

你口气真大，你心眼真直。求人办事请吃饭，如果都像你这样想，那饭局也不能称之为一门学问了。这年代，谁还差那口吃的？你认为饭局的意义真的在饭上吗？是在局上！

所以，饭局，饭局，你得安排这么一个局，有这么一个局，你才好在这个台上说出你的请求。

很多人因为心眼直，吃了无数次这种闷亏，还是不知道反思总结。比如请领导吃饭，领导闭着眼睛都知道你想调换岗位的事，可为你那个处室累死个人，很多人在你那个处室待不了一年就换岗位，你无缘无故请他吃饭，不是想提换岗位的事是什么吧？于是，友短信问领导有没有安排饭？想请领导吃饭。领导说周末有安排了。过一段时间，你又给领导打电话，问领导有时间吗？领导说这段时间比较忙。又过了一段时间，你学聪明，你打电话给领导说：领导，您下周末找个时间吧，我请您吃饭。领导说不必了，有什么事你直接来我办公室说吧。

你心中愤怒道：清高你大爷，请了这么多次，都请不出来，我还请不了呢！

怪领导？

怪你自己是个榆木疙瘩！

谁愿意牺牲自己的休息时间参加下属的饭局？和你很有话说？并且人家知道你这混门宴啊，请吃饭是要张求别人啊！

你这种干将，把人请出来是小概率事件，请不出来才是正常的啊！如果千请人都能请出来的人，这种人请出来他也办不成什么事。

所以，饭局，在开始讲的时候就要花心思、动脑筋，否则，人家是不会露面的。这点你必须要搞清楚。

怎么说，他才能出来呢？

你得让他知道，来参加饭局，是有甜头的。

每个人在这个社会上，都是有喜好的、都是有诉求的、都是有他自己想办的事却暂时没有办成的。

你就揪着这几点想办法。

比如你的领导非常喜欢收藏老酒，越是年份长的酒，他越想把它占为己有，不是为了喝，就是为了收藏。你可以打电话说：我爷爷年轻的时候藏了一箱子酒，藏了半辈子了，他最近想要把这些酒卖了，但是我听到这块不熟悉了，您是行家，您看下您什么时候有空，您帮我们看下，看看多少钱合适啊？

即便他知道你有求于他，他还是忍会忍不住，成年人对癖好的追求，是很执着的，他知道你有好东西，却没见到，他会寝食难安的。就像年轻人的床上躺着一个西施，你让他一晚上不动手动手，也是不可能的。

再比如说领导喜欢结交上层，只要是职级比他高的，有助于他更进一步的，他都想去结交，他都非常喜欢积累这些以后可能会用得着的人脉。你恰恰有一个亲戚在省里是个处长，你可以趁着你亲戚回家看望老人的时候，给你的领导打个电话，就说你亲戚来了，是省厅的一个处长，估计过不了两年就要升futing了，我想请他吃饭，但是我是我长辈，没什么可交流的，领导您如果有空能不能一起来下来和他交流交流。他掂量掂量，你计得来。即便他，你自己单独请着你亲戚吃饭也是应该的。

在比如你领导的子女想要留学，领导每天为这些事情忙得焦头烂额，选学校、走流程，啥事都不熟悉，心力憔悴。恰好你有刚留学回来的朋友，你可以借此引领导吃饭，就说领导您愿意吃个饭，本来想单独请您，但是恰好一个朋友刚从国外留学回来，非要见识下领导您的风采，领导您一定赏光啊。你去他谈话到嘴边了，不能不说吧？并且，他这样说，我也会觉得你是一个聪明人，聪明人说话、办事，都善于把明明是对方想要的说成那是自己的紧察。

很多读者会说，领导到底喜欢什么，咱也不知道啊，咱也不敢问啊。我在《老A讲职场人应掌握的手段》里曾经讲过，你连领导的喜好都不知道，你不是一个称职的下属，起码不是一个具备提拔潜质的下属。可能我说这句话，很多读者觉得绝对了一些，但大概率是对的，这个概率是百分之九十九，请相信我。

回过头来说接贵饭局的事，刚才我把重点都讲了，攒饭局的重点一定不能出现偏差，一定不能以自我为中心考虑这件事，不能老是想着我要在饭局上让领导帮我解决什么事，而是要以领导为中心，想着领导喜欢什么，然后有的放矢的抛出甜头，让他无法拒绝来参加你的饭局。
