# **第四章：饭局上必须得让对方端起酒杯，只要他端起来，就一切都好说了，怎么让他端起来？**

酒真是一个数一个好东西，你看东西方文明，虽然有很多不同，但是每种文明都是在进化的过程中发明了酒，并传承下来的。

它是人世间情感的催化剂，合理地利用它，能起到你意想不到的效果。

一般求人办事的饭局，事，能不能成，很多时候要取决于你能不能让上司端起酒杯、并且喝好。如果不能，那他吃饭前是正襟危坐的，吃饭后依然正襟危坐，犹如没有防护破绽的堡垒，你根本找不到一个入口走到他柔软的心里。

怎么才能让上司端起酒杯呢？

我建议这个功夫最好也是提前准备，准备什么呢？准备一些托词。准备什么托词呢？我在稍后，会提到。

我来帮大家模拟下你请上司的饭局。

佳肴都端上来了，你请示上司说喝点养生酒？无酒不成席的嘛。

上司如果说好那，少喝点，顶多二两。

那就好了。直接开整就是了。

如果上司说我身体有问题，喝不了白酒，那你别那么听话的就顺着上司的意思，你应该立即接话比如：那领导，要不您喝点啤酒？总量给您控制住，能一杯，啤酒应该是没问题的，那玩意是液体面包，补充能量的。

他一般不会拒绝你，如果他还是拒绝，你再劝：确实，啤酒也是酒啊，要不整点红酒吧，红酒是保护身体的，里面有抗氧化的因子，每天喝一点，确实对身体有好处。

如果他还是不喝，那你就别劝了，毕竟你是求人家办事，你不能像江湖兄弟那样，傻不拉几的说一些什么不喝不给面子、少多喝点等等之类的劝词。

能来就给你是面子了，来了还以上社会上那套俗不可耐的烂规矩来套住上司，我看纯粹是没事找事了。

他不会喝，一会还是有机会让他喝的，不急在这一会。

大多数上司，都会接招，喝点红酒。

很多人认为红酒不是酒，那玩意，喝起来能起什么作用。其实我觉得红酒比啤酒还要厉害一些，喝十瓶啤酒的人大有人在，但能喝十瓶红酒的人，找不出来几个。顶多六七瓶，就已经不行了。

所以，红酒，喝个两三瓶，一般人都已经进入醉熏的状态了。

如果你把陪酒的人找好，把提前准备的托词想好，喂他喝两三瓶红酒，简直是轻而易举的事。

比如：是校友敬一个是、老老乡敬一个、聚会认识得敬一个、您刚才说的话有启发得敬一个、在您的带领下局面一片大好得敬一个、都有高蛋白是朋友得敬一个、以后需要您栽培得敬一个、您女儿刚考上中国人得敬一个、您也在黄埔区啊我也，是邻居啊，得敬……

这种散敬的托词，找一百个都能找到，总而言之一句话，敬就对了，喝就是了。

我们再回到上面说的，如果他执意不喝，你在一开始不要劝。在饭局气氛稍微活跃点的时候，可以再去敬，敬之前，先倒少量红酒给上司端过去，说：领导，我酒量其实不行，所以今天有点醉，您不喝酒，我也不能劝您。但这杯洒，我还是得敬您，您女儿刚考上中国人，这对于咱们这些做家长的，是天大的好事，我提议咱们一起敬领导一杯，就当拜个师傅，让领导教教咱们到底该怎么培养才能把孩子送进中国最好的大学里啊！

他能不喝？

喝完这一杯，鼓鼓掌，让他讲，都有好为人师的德行，也不例外。

等他们完，你能没启发？有启发了能不感激？大家都有启发，一起再敬一杯。
