# 第六章：攒一个饭局，要请哪些人来促成好事的办成？千万别乱请！

2019-06-11 23:13:46

我这个专讲人的饭局的学问，主要讲的是求人办事的饭局。至于其他无关紧要的饭局，大家可以在我讲的这个求人办事的饭局的基础上自由发挥即可。

很多人求人办事，在攒饭局的时候，想到了要围绕核心领导，请一些相关人士。

但是对相关人士上考虑不周全，请了认为该请的，其实是不该请的人，这对于事情的办成，是起反作用的。

我在前面说过，要围绕领导的喜好、需求请他出来，如果他出来了，你只需要把那个他喜好的、需求的人请出来就可以了，多余的人就不需要了。

很多笨人，自作聪明或者妄自菲薄，觉得自己的分量不够，得找个平级的或者上级的领导陪着。你仔细回想下，是不是你身边经常有这样的笨人会做这种事。

为什么说蠢呢？

因为你是求人办事，这种事多半是没办法正规操作的事，这种事本来知道的人越少越好，你却叫来他的同级官僚或者上级领导，他当着同级官僚的面，不能答应你，因为这个同级官僚，日后可能是他的竞争对手，他不能露出破绽；当着他的上级领导，他更不能答应，除非领导力压，或请求。如果领导只是笑眯眯的坐个台，那他在也不会答应，不然领导会觉得自己没有原则，再说了，上级领导来都来了，本来吃个饭该答应的事，现在也不答应了，何不趁机让直接领导亲自讲出这个话，然后自己再卖他一个人情呢？

所以，在围绕领导请人的时候，不要乱请，无关紧要的人，一个都不请。确保的任何一个人，都能在促进事情办成上起到积极作用。

我请人吃饭办事，当然是指办大事，一般都会喊一个美女作陪，我觉得每个职场中人，也最好认识一位这样的女人，她聪明伶俐但游离在体制外，这种人喜欢蹭这样的饭局，结交所谓的领导阶层，但是只要你事前嘱咐好，她也不会主次不分，她会好好的把握分寸，既结交了领导，又促进了饭局的活跃、增加了领导的喜悦。

这就是为什么大家总能在一些饭局上看到这种角色存在的原因。

你们可别小瞧了这种女人的促进作用，我见过有一些老板请上司吃饭，老板半开口舌粗笨，说句利索的话都费劲，但他能找到会说利索话的可人，他不会敬酒，可人会，可人敬酒，领导端起来喝，他也陪着喝，既活跃了气氛，又让领导觉得他很实在，人家一杯杯的陪着喝，多实在！

小地方，有很多这样的女人，甚至有一些还在小地方很有名气，我觉得如果你有长远打算，可以和这种女人交朋友，是真交朋友，因为你早晚都会用得着她们。当然，或许你一般会觉得和人家交朋友，人家还不一定卖账，因为平时就穿梭于那些大上司之间，她们的眼界也很高了。

扯远了，但我觉得扯得很有必要。

一些年轻人，不善于把这运用好，结果即便是请人吃饭，也只是尴尬的吃请，自己没能力很好的主导饭局，领导不喝满自己也没能力让他端起来，结果呢，草草了事，只是尴尬的请吃了一顿饭。

老同志，就非常善于也非常喜欢用这一手，为什么呢？

因为他们屡屡从中得到好处，这个棋子用起来简直太顺手了。

所以，年轻人也不要顾及什么，人和人之间有时候就是隔层纱，虽然你在单位表现的老老实厚，但上司永远只觉得你是一个老老实厚的下属，进而，他也只会在你面前表现得像一个有风度的领导，其实呢？你未必忠厚，上司也未必是君子。

老话不是说过吗，什么关系最近？一起同窗、一起扛枪、一起……

很多情况下，你只有表现的稍微出格一点，领导才觉得自己也没必要端着了，大家都是人，都有同样的欲求，很多人在上司面前自污，你可能心里会想，真蠢，其实我觉得这种人不是蠢，是真聪明。

有时候，只有你稍微没下限了，没禁忌了，领导才好放下面具。

比如在ktv里，大家都在酒精的刺激下，搂搂抱抱，跳舞闹闹，只有你，只有你觉得那样做不好，只有你静得碍端坐在座位上，众人都瞅你独醒的那么坐着，那上司也不好放肆，虽然他很想知道。聪明的人这个时候会摸清楚上司在想什么，然后当活跃气氛的催化剂。

这样，你和上司，就能拉近一些关系了。

又扯远了，但同样，我觉得扯得很有必要。

扯回到饭局上也是一样的，不要规规矩矩的像个君子，你既然是君子，为什么还想走这种捷径请上司为自己开绿灯呢？

姿态放低一点，自尊去有一边去，你觉得在饭局上你该充当小丑的角色了，就去扮演小丑，你觉得气氛很浓烈了，可以适当的再往下限上探一探，那就勇敢的站出去探，我觉得，在人性正常的欲求下，你在饭局上下探的底线越深，对事情的促进越好。
