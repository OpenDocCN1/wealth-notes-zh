# 第八章：敬酒的基本话术有这几种，学会了受益终生。

很多读者在，在敬酒时，是真不会说话。走到领导跟前，说一句：领导我敬您一杯。

完了。

宽容大量的领导会觉得：这孩子，笨手，没什么多话。

心眼小的领导可能会觉得：你孩子傻不拉几的，连句祝酒词都说不出来。

就你这么短短的一句话，都说靠领袖拉近和上司的距离，机会创造出来了，但你得大胆表达啊，这么生硬的、没有感情的一句话话，能拉近距离才怪呢！

今天端午，全家人吃饭，我在这个不高不低的位置，说实话，亲戚们每到节目，都会来我家，说是来帮我办事，我父母，其实大家都知道，节日期间多走动，万一以后求我办事，也好张口。今天也不例外，我老婆的大侄子，读大三了，今天敬我酒时，手端着杯子，设没个站相，杯子举得比我的还高，然后有气无力的说了一句：姑父，我敬你啊！他抿了一口，就把杯子放下了。

我就本着教导晚辈的初心，教育他说：你好好看我是怎么敬你爷爷酒的。

我站起来，双手捧杯，杯子低过长辈的杯子，长辈坐着，我站着，说到：老爷子，我敬您一杯，祝老爷子身体健康，事事顺心。然后头稍微低点一下。老爷子一饮而尽后，我又给老爷子满上。

我又让他按照我刚才的套路，重新敬了我一杯，小伙子很伶俐，只是平时没人教，他敬我时，把敬酒改成了：祝姑父当更大的官。

各位读者，别以为只有大三的学生不懂酒桌上这些基本规矩，很多毕业的年轻人，也不熟悉基本的规矩。比如：

+   - 敬酒时，必须双手举杯。
- 杯子一定要低于长辈或领导的杯子。
- 领导杯子无酒，你顺势要满上。
- 喝完酒，要领导先坐下，你再坐。

+   - 你敬领导酒，必须站起来敬，如果距离远，可以走近一点。
- 领导要站起来，你必须说客套话：领导，您坐、您坐。
- 敬领导酒时，最好加一句：领导，您随意我一口。少喝酒。

+   - 转动餐桌时，一定要在别人没有夹菜的情况下。
- 看到有人夹菜，一定要停止转动餐桌，等他人来夹完再继续转动。
- 饭局上，大家都放下筷子，你也得放下筷子。

+   - 不要因为喜欢吃红烧肉，就挑几块放在自己盘里里。一口一口夹。
- 别人来敬你酒时，最好站起来，哪怕是你的下属。

+   - 饭局上如果你是最没地位的，最好别多说话，更不要喝点酒就冒然打断他人讲话。

+   - 在饭局上，没必要表现的过于殷勤或低三下四，容易让人翻眉头，饭桌上不卑不吭，私下里可以敬得过分一些。
- 饭局上的座位乱坐，如果你不知道该坐哪里，就站着，会有人根据情况安排你的座位。如果你请客，那自己好好研究下正规的商务座次，别搞乱了，有些地方、有些领导可能不在乎这些，但是在乎的人也不少！

+   - 暂时想到这些，这些基本都是的规矩，当然，还有很多基本规矩，我暂时不讲了，因为本篇是打算讲敬酒的固定话术。

敬酒的基本话术是什么呢？

我觉得最好用这三种。

一是领导，我敬您一杯，再加上祝福的话。

比如，领导，我敬您一杯，希望领导万事顺心，带领我们在创新辉煌;祝福领导身体健康、工作顺利用等等。说一句比不说好太多。

二是，领导，我敬您一杯，加称赞对方优点的话。

比如，领导，我敬您一杯，您刚才说的中国经济形势的高论，简直颠覆了我的三观，在大学里没学到的知识，今天晚上学到了；领导，我敬您一杯，刚才您说您冬泳坚持了五年，其实就是冬泳界的选兵，我坚持了一个星期就放弃了；敬您，领导，我敬您一杯，单位人都说您是油画高手，我的本科专业也是学美术的，但是我那三脚猫的功夫，和您一比，根本不入流，改天希望能私下里向领导请教。等等。

这个话术，我觉得大家一定得会，并且得学会用，因为，用这个话术，很容易给下次接近领导埋下伏笔，比如领导冬泳，你这么说，下次跟着他去游泳就是了；比如领导爱油画，你下次找他画，就可以找领导开画了；当然，这个话术，可以提前准备，提前提好，才能在饭局上下次的再接近找到正当的理由，找到合适的借口。

三是，领导，我敬您一杯，加感激的话。

比如，领导，我给您一杯，感谢您一直以来对我的关照；领导，我敬您一杯，非常感激您在我职场最迷茫的时候，给我指点，我一辈子不会忘；领导，我敬您一杯，说心里话我我常幸能在您手下干活，我学到了太多受用终生的本事。等等。

这个话术，我也建议大家多想、多用。

有句话说千穿万穿马屁不穿，只要你能说的恰到好处，能准确的切中领导的酥麻点，他一定会很舒服。很多读者觉得，哪里知道领导的酥麻点在哪里呢？傻瓜，你多敲几次，多拍几次就不行了吗？总会有一次拍对的。
