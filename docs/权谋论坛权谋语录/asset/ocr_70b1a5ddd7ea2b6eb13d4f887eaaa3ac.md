# 八：言辞篇

+   1.  说话的口吻。

+   2.  你又不是诗人，不必要直输胸臆。

+   3.  他如果一直看时间，则表明你们的谈话，他想结束了。

+   4.  话匣子就像一首歌。

+   5.  你说话的目的，有没有达到。

+   6.  进谏有工作方法。

+   7.  《真心话，大冒险》：真心话，冒险大掉了。

+   8.  不是你说什么，就是什么。

+   9.  体制不对。

+   10. 幽默就是蝎后语。

+   11. 说话大喘气。

+   12. 一就是一，二就似二。

+   13. 不要触犯他人的“雷区”。

+   14. 男人说话，不能没有内涵。

+   女人说话，不能没有内涵。

+   15. 说话要把自己加糕。

+   16. 对显而易见的事，不用去说。

+   17. 没有生造的。

+   18. 话中有话。（画中有画）

+   19. 你要表达什么意思，不能说病句。
