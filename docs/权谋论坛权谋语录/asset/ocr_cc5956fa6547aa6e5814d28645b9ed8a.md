# 三：斗争篇

+   1, 他做这个需要时间。

+   2，你有可能来掀桌子，我就不请你。

+   3，你有可能不在这吃饭，我就不告诉你。

+   4，你家办喜事之前，就需要和怡关系。

+   5，井敌一向。

+   6，就你需要高大上，他自己不需要高大上。

+   7，如果你将来，所以一场戏。

+   8，死人头上有浆子。

+   9，两面三刀：两面三刀的人，有时候还蛮可爱的。

+   10，眼神是心灵的窗户。

+   11，让大家憎恨。

+   12，哀莫大，莫过于心死。

+   13，他有多高，能够着什么东西。

+   14，硬倒酱缸，不倒酱架子。

+   15，上帝为你关上一扇门，绝不会为你打开一扇窗。即使打开了一扇窗，也不是好窗。

+   16，这边没有风景怎么办？

+   17，你如果一直有续后，就不会拆你台。

+   18，进攻要害。

+   19，今天咬别人的人，他也会咬你。
