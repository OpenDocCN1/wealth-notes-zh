# ## 二：智慧篇

+   1. 晴雨表反应了外部环境。

+   2. 不能做孔乙己。

+   3. 他有多少钱，能做多大的事情。

+   4. 打落牙齿和血吞。

+   5. 欲速则不达。

+   6. 老板他要不英明，他的企业也不可能做得这么大。

+   7. 除非有很紧急的事情，晚上十点钟以后，不打电话给别人。

+   8. 你在河中，大棍是怎么到你这边来的。你也可以分析，这个大棍是怎么从你身边走的。

+   9. 不会跟着人家的感觉走。

+   10. 赔了夫人又折兵。

+   11. 能想到后果，后果是酸的，是甜的。

+   12. 跟大风向走。

+   13. 战略目的。

+   14. 先顾眼前。

+   15. 品出话味。

+   16. 外来的媳妇难做人。

+   17. 孤军作战。（我先走，你殿后。）

+   18. 时机不对。

+   19. 女生叫你哥的，是把你当凯子了。
