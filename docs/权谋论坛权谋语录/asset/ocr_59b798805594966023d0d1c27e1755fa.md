# 九：爱情篇

+   1、对女的高待，可以防止人家挖墙角。

+   2、不要总会说对不起，也会让她感觉很理性。

+   3、每天结束，请收拾你的心情。

+   4、女孩会把男人打扮成自己喜欢的样子。

+   5、男人必须要有家庭责任感。

+   6、温柔是女人赢得男人的杀手铜。

+   7、信任是爱情的基础。

+   8、你的丈母娘，就是你的老婆20年后的样子。

+   9、能忽悠得住媳妇，你就能忽悠得住别人。

+   10、夫妻之间，千万不要揭老底，等到揭老底的时候，就离离婚不远了。

+   11、要满足女人的虚荣心。（女人的虚荣心得不到满足，就会分手。）

+   12、女人：在公开场合要给足男人面子。

+   13、花钱宜采取中庸之道。（年轻小伙子，应该脾啊漂的）

+   14、说话没有梦想的人，不值得投资。

+   15、他是可造之才。

+   16、错过了爱情，就错过了人生。

+   17、长期饭票。

+   18、钱靠自己挣，才有底气。
