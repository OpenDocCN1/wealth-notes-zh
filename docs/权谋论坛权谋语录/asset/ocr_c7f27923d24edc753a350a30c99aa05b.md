# 十一：生意经

+   1．商人言利，无可非厚。

+   2．京东上，不要买衣服鞋帽，上面的衣服鞋帽全部是农村农贸市场的质量。

+   3．弄虚作假，短斤少两。

+   4．大的工程，做一个模型。

+   5．买基金：就是拿你的钱去赌。

买股票：就是在参小丁股。

+   6．货卖当时。

+   7．政企合一：政府官员在企业有股份。

+   8．有关商业机密的事情：人家也有可能不告诉你。

+   9．盗尽先机：让别人的秘密，没有秘密。（但你不能奉献给别人）

+   10．君子爱财，取之有道。

+   11．创收。

+   12．物以稀为贵。

+   13．美女经济。

+   14．做生意不能置气。

+   15．公司和部门领导一 起卖。——《杰克·韦尔奇自传》

+   16．财富是知识的结晶。——《巴比伦富翁的秘密》

+   17．你不理财，财不理你。存起你每个月收入的百分之三十。

+   18．开支节省。
