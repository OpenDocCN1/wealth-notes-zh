# 十二：育儿经：

+   1.  推荐给小孩看的五本书：
    1 十万个为什么。
    2 上下五千年，
    3 安徒生童话选，
    4 脑筋急转弯，
    5 福尔摩斯探案集。

+   2.  初中毕业，每个人都是。形成不了竞争优势。
只有高中毕业，大学毕业，才能形成竞争优势。

+   3.  女大不中留。

+   4.  照顾小孩，像看小猪一样。时时刻看。

+   5.  当家才知柴米贵。

+   6.  社会科学的抽烟年龄是20岁。

+   7.  父爱一座山。

+   8.  做人最重要的是，不要让人把你当傻子。

+   9.  近墨者黑，近朱者赤。

+   10. 拉链子，一扣不让。

+   11. 发肤受之父母，岂能一嘴而毁之，是为不孝。

+   12. 年轻就是本钱，不努力，你就不值钱。

+   13. 年轻人犯错误，上帝也会原谅他的。
