# 七：职场篇

+   1，做下属的，最忌居功自傲。

+   2，你做什么动作，他做什么动作。则可能你是领导者，因为你在影响别人。

+   3，十年河东 十年河西。

+   4，学好你的专业，才是置身之本。

+   5，你工作的再认真，如果你不会拍马屁，不送礼。你就永远升不上去。

+   6，我准许你罚我的款，但不准你侮辱我的智商。

+   7，把敬业变成习惯。——从长期看是为了自己。

+   8，适度地抬高身价。——在就业市场中，人也是一种商品。

+   9，向领导说实话的人，不吃亏。——《智囊》

+   10，耐心解释：因为特是领导，需要向他耐心解释。

+   11，老板最喜欢不拒绝分外事的人。

+   12，投桃报李，人之常情。

+   13，别唱单调。

+   14，除非你不准备干了。不然不要说，现在这个单位不好。

+   15，在你的责任区，人家叫你做事，就没有错。（改进步奏）

+   16，什么叫会做人，我只会保护我自己。

+   17，做天下所有工作，都应该带手套，只有做车床，不需要带手套。
