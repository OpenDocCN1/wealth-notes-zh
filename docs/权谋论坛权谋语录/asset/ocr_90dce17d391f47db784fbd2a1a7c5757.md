# 六：成功学

+   1. 上天永远不会辜负努力，奋斗，勤奋的人。
2. 做事业，不能前怕狼，后怕虎。
3. 哪些事业有成就的人，秘诀之一，就是知道别人的需要。
4. 做事，去抢。这是最简单的成功学。
5. 让质量为你说话。
6. 掌握国家的政策新动向。
7. 成功学，做好仿造者。
8. 人人有脸，树树有皮。这句话是错误的。
9. 他有两个渠道。
10. 不愿意吃一点亏的男人，发不了财。
11. 人家成瘾的，就是商之路。
12. 火焰山不去。
13. 谦虚是高贵的品质。
14. 大事可成。
15. 海阔凭鱼跃天高任鸟飞。
16. 踩出一条血路出来。
17. 抱团取暖。
18. 方法对了，锲石可开。
方法不对，锲石不开。
19. 一群人不会追随一个人，只会追随一个伟大的梦想。
