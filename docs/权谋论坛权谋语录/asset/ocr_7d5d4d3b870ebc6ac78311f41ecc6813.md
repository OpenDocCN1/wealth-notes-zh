# 十四：玄学篇：

+   1，算命，其实也是概率学，有七七八八，也不是全部准。

+   2，国字脸，有官威。

+   3，女孩子，长脸命好。

+   4，鸟眉大眼，命里有富贵。

+   5，鹅蛋脸，福薄。

+   6，天庭饱满，地阁方圆，这种人容易发财。

+   7，小长脸的男人，克妻。

+   8，喊魂是一种科学技术。

+   9，你的命是怎么来的——今日的因，明日的果。

+   10，算命先生的原则是玉成，而不是去破坏人家婚姻。

+   11，命书，主要讲的是五行，相生相克。

+   12，命有五行，缺什么，补什么。——韦千里

+   13，风水住宅，目的使人不得疾病，从而有利于家庭的发展。

+   14，推动命盘。

+   15，道，就是仁德智慧。

+   16，“看行头”。

+   17，要能藏风向水。

+   18，泄露天机。

+   19，八卦的字，是为了说明它的性格。

+   20，心思纯良者，目不斜视。
