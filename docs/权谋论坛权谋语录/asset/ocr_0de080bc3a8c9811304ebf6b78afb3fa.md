# 十三：修身篇

+   1，这人没教养。——《活着》

+   2，如果不能增加见识，你就读书。

+   3，过犹不及：什么东西吃得多了，对人都不好。

+   4，你的形象，价值百万。

+   5，希望在迷途的兄弟们，戒赌，才是人生最大的赢家。

+   6，干体力活，防止腰痛的方法，掌握这四个字：“贴近简易”。

+   7，死者为大。

+   8，对方回报的心意，聚集在他的内心之中。平时他会慢慢找机会报答你的。

+   9，不待人待我，只看人待人。我以此知之。

+   10，如果不看书的话，他的思想会像轨道。

+   11，个人妹力。

+   12，劝君莫惜金缕衣，劝君惜取少年时。

+   13，心满天下；一副热心肠，外挂两行泪。

+   14，思想上的贫穷，胜过物质的贫穷。

+   15，人生来必有使命。

+   16，败军之将，不可言勇。

+   17，事业和爱情兼顾。

+   18，生命在于运动；多运动，对人有好处。

+   19，遇到敢于直言的朋友，应该贺喜。
