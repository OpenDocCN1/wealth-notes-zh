# 四：军争篇

+   1，谁的兵器优良。

+   2，号召当兵，蹦跃参军。

+   3，不管我用什么计谋，我胜了，你败了。我活着，你死了。你就是输了。

+   4，避免两线作战。

+   5，孤军深入。

+   6，挂彩。

+   7，后卫部队。

+   8，战略撤退。

+   9，包围侧翼。

+   10，打掩护。

+   11，抓大放小。

+   12，谁掌握了制空权，谁就掌握了胜利。

+   13，鲁莽出战。——《孙子大传》

+   14，战线拉长，则左右不能相顾。

+   15，战略意图。

+   16，《纪校新书》——车轮战。

+   17，双方对付阶段。

+   18，为何兵马未动。（因为条件不够）

+   19，战略伪装。
