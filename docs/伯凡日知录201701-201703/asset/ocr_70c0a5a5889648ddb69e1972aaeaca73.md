# —— 知识笔记 ——

前几天和几个朋友在谈关于小米公司，小米公司其实是一个很不错的，被寄予厚望的公司。但是现在的品牌形象越来越模糊，因为它的产品越来越多，你没办法说它是一个什么样​​的公司。

在去年夏天我用过一个小米的电扇，我觉得非常好，它很安静的，很谦卑的为你送凉风，但是你又不意识到它的存在。

小米399元的音箱，我觉得它可能在业内导致一场灾难，就是很多过去随意定价的，动不动卖到一两千块钱的那种音箱一下子就没有生存空间了。

在这一点上，我觉得小米很了不起，它是一个价格屠夫。这个行业里头有很​​多的所谓高端产品，不过是因为自己的成本控制能力不行而导致的高价，而不是本身这产品的价值而自然溢出的高价。我们如果有越来越多公司像这样能够去掉一切不为客户创造价值的环节，赤裸裸的把价值呈现给客户，客户以很低的成本能获得不错的价值，我觉得是一个很​​好的策略。

雷军同志最近在说：“伟大的公司总是能够把产品越做越便宜。”大概他现在是松下幸之助的信徒。松下幸之助说：“最伟大的公司就是自来水公司，人人都缺不了，但是价格又很低。”我们用自来水的时候常常忘记自来水的价格。但是假如一停水，停一个小时，你也会觉得很不舒服。

将来我如何能够识别它是小米公司生产的？

它的品牌形象会越来越模糊。如果仅仅是拼价格的话，那它就会把自己放在了一个很麻烦的市场里头。

据说聪明的公司都不是去拼价格的，它能够在一个让人眼花缭乱的市场里增加自己的市场能见度，让大家自动去忽略那些乌云般的，大量涌现，但是是没有什么特点的那​​些产品，第一眼就看到它的产品。或者在没有看到众多的品牌里，首先联想到​​的就是它的品牌名，首先就能够联想到的产品。

最高的境界是将你的品牌名称变成这个品类的名称。

吉普是一个品牌，但是我们已经习惯于说“这是一辆吉普车​​”。其他的同一品类的产品我们都把它叫做吉普车。

据说在越南把摩托车叫Honda，因为本田摩托在那个市场占的份额太大了，以至于他们以为那个东西就叫Honda，忘了那其实只是一个品牌名。

百度不叫搜索一下，叫百度一下，它就是希望把品牌名变成品类名。

我们引用一对生态学的概念，把世界上做产品的公司分成两类，一类​​的产品采取的是K策略，一类采取的是R策略。

# K策略

![](bbox=[0.15, 0.0026, 0.85, 0.0030499999999999998])

K代表king，代表王，王只需要一个，一山不容二虎。这个king就是说以一当十、当百、当千，它只需要用一个产品就能够一夫当关、万夫莫开。

# R策略

在英文当中老鼠这个词的开头叫R，rat。R策略就是老鼠策略。

民间有一句话叫：“龙生一子定乾坤，猪生一窝拱墙根。”就是一个是以质取胜，一个是以量取胜。

# 两种策略的比较

这两个策略之间没有优劣之分，K策略风险很大，如果这个独生子突然死了，种系无法继续繁衍。

对采取R策略的生物来说，即使死掉70%，也还剩30%，比如说蚊子，昆虫，它永远是前赴后继的，它是打不死，杀不绝的，凭借这种R策略它能够保证整个种系的持续的繁衍，这就是K策略跟它相比是它的劣势。

但是从另一方面看，K策略它比较高级，采取K策略的都处于食物链的高端，属于R策略的一般处于食物链的低端，当然这也不是绝对的。

# 人类的生殖策略也分K策略和R策略

# 1.6 和 6.1

非洲的出生率是6.1，中国的出生率是1.6。每一个非洲妇女她平均生6.1个孩子，中国的妇女生1.6个孩子。

大家可能听到这个数字就觉得有点奇怪呀，因为一对夫妇只生一个孩子，可是在农村里头他很多夫妇他不止生一个孩子。

这个1.6和6.1的差别就是K策略和R策略的差别。政府放开二胎以后，我们发现一个现象，很多可以生二胎的人也不生。其实在放开二胎之前，两个独生子女也可以生两个孩子的，但是很多人也是不生的。

原因是什么？原因是他们后代的哺育和教育成本非常高。采取K策略，怀孕、哺育、教育的时间会很长。比如说城市里头的孩子，你想在社会上获得较强的竞争优势，你必须要接受良好的教育。那良好的教育首先从娃娃抓起，家长会为上最好的学校去操心，每一个时间段都想着怎么去买学区房。最后你发现一个孩子要真正结束他的教育，走向社会，能挣钱来反哺父母的话，差不多快到三十岁了。从小学、中学、大学、研究生、博士，恨不得搞个博士后。当他接受完教育以后，他有价值的生命差不多过去了一半了。快三十岁的时候，你才开始工作，工作三十年，然后你就退休了。

我们看非洲的孩子的哺育和教育时间，越是处于落后的地方，孩子的哺育的时间和教育成本就越低，因为在那样一个环境里头，他用不着学很多很多的东西，他就可以谋生了。

有一个很著名的京剧唱段叫《穷人的孩子早当家》，这是《红灯记》里头面有一个唱段，“担水砍柴拾煤渣，里里外外全靠她，穷人的孩子早当家。”因为在那样一个环境，差不多5-6岁的时候，你的生存技能就已经够了，你会表达，你会各种各样的工作。我自己的记忆在农村里头，5-6岁的孩子就开始做饭了，这个在大家听起来现在觉得不可思议，我姐姐就是这样的，6岁的时候她还没有锅台高，就站在椅子上炒菜。

5-6岁的教育和哺育时间和这个30岁存在一个什么关系呢？大概是5、6倍的关系。这样我们就能理解为什么中国的出生率是1.6，非洲的出生率是6.1。
