# —— 知识笔记 ——

正常的细胞一切行动听指挥，它们按照一种内置的程序按部就班、有条不紊，绝不走样地生长发育、分裂。

细胞发生癌变就是细胞不再听话，细胞内部预置的程序被遗忘或者被删除，它完全不顾生命体本身的利益，而盲目地、疯狂地生活发育和分裂，从而最终对整个生命体产生致命的威胁。

正常的细胞里头的抑癌基因管得住原癌基因，也就是说保守基因管得住创新基因，即使有所创新，它都是在保守的框架下生长和发育。这就是说在正常的细胞和正常的生命体当中都有一种天然的防癌、抗癌的力量在。

对于企业来说这创新基因和保守基因都必不可少，而任何一种基因占绝对优势的时候都会对这个生命体产生巨大的威胁，当然我们最害怕的还是那种创新基因，那种过度创新、创新泛滥、创新失控的这种基因，一旦在一个企业里占上风的话，一个企业可能就离倒闭不远了。正因为如此，越是成熟的企业，他们对于这种异质化的东西、非流程化的东西，与企业既有的价值观、既有的资源、既有的流程相对立、相违背的那样一些理念、产品和流程都是非常警惕的，甚至是有一种自动删除的机制。

索尼MP3部门被删除

柯达的数码相机业务发育不起来

诺基亚顽固地维护塞班系统，像恐惧癌症一样的恐惧其他的操作系统

他们的抑癌基因过于发达，而使得企业的创新基因、原癌基因处于绝对的弱势，甚至完全消失。企业在防癌、抗癌，提防癌的过程当中不自觉地陷入到另外一种他自己不知道的癌症当中了。

![](bbox=[0.06, 0.0025499999999999997, 0.94, 0.0030800000000000003])

哈佛商业评论莱维特有一篇很著名的文章叫《警惕创新的洪流》，他的意思是说创新是好的，但前提是你的企业里头有很好的防洪工程，如果没有防洪工程和水利工程，你的创新会将你的企业的资源、企业的资产消耗、毁灭、殆尽。

那么问题就来了，到底企业是应该创新还是应该保守，这个问题好像容易回答，要在创新和保守之间保持某种平衡。这跟所有的真理一样，听起来总是对的，但是它一定是毫无用处的。

克里斯坦森用大量的案例证明，在一个成熟的占据行业领导地位的企业里头，总会时不时冒出对于新市场、新产品的尝试。但是既有的业务具有一种防卫本能，几乎能够在第一时间内将新的业务和新的产品围剿殆尽。这似乎是给大企业判了个死刑，就是你只能慢慢地衰老，只要你得势就一定会有失势的时候，你怎么上来的到时候就怎么下去。

大企业与新市场，与真正代表未来趋势的产品是有缘无分的，但是我们同时也看到一些案例，一些大企业居然能够在相当辉煌的时候还能够实现转型。

# 例子：IBM

IBM当年就是一个生产磅秤、奶酪切片机和打卡机的一个所谓国际商用机器公司，但它后来居然做起了电脑。有人总结说IBM之所以能够实现这一个不可思议的转型，是因为老沃森有一个败家子就是小沃森，这个人酗酒、爱赌博，他的行为可以用“От卖爷田心不疼”来形容。他把父亲留给他的这个产业不那么当回事，老沃森很不想把产业留给这个儿子，但是他只有一个儿子，不得不让他儿子来接班。看起来很不成器，一个兼酒鬼与赌徒于一身的小沃森最后居然能够让IBM成功的转型，原因就在于他不把他老爸的事业太当回事。但是很多企业的不幸或者说幸运的地方就在于他们没有这样的败家子作为接班人，他们很珍惜以前的成就、以前的路径。
