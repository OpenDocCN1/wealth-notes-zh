# ——◆ 知识笔记 ◆——

有一本已经绝版的书，因为我的推荐，这个书让淘宝上那个小书店发了点小财，我估计已经不低于600本了。我推荐完以后，很多朋友去读那本书，然后还加印。有一个朋友读了这本书以后，自己又购买了十几本去送给朋友。这本书叫《麻雀变凤凰》。它讲的内容听起来有点熟，就是一个小公司是如何变成大公司的，为什么有些公司就永远是小公司，永远是小老树，岁数不小，但是始终长不大。而有些公司，今天是麻雀，明天就变成一个体量大，规模大，而且很光鲜的凤凰，它是如何实现基因突变的。

今天不细讲这本书的内容，但是这本书里有一个很重要的观点，企业在由小变大的过程中当中，领导者是这个公司最终的障碍，他是有任期的，但是他自己没有意识到自己的任期，长期盘踞这个位子。而且他会隐隐约约的意识到自己已经成为这个公司的障碍了，这个时候他很自然就会做一件事，强化自己的权威，建立跟企业成长并没有关系的各种机制。

一套什么机制呢？一套阿谀机制。所有的信息传递，人事安排，公司的议事日程背后都有一个总的议题叫“阿谀奉承”。他创造了一种特殊的生态，在这种生态当中，最重要的能力就是阿谀奉承的能力。当然，阿谀有低级的，有高级的，最能够获得加薪升职的人一定是掌握了非常高超的阿谀能力，听起来都不像是阿谀奉承的那种阿谀奉承。

阿谀奉承，一本正经，拼命的维护老大权威的这种氛围下一种东西就会越来越少，这个东西就叫幽默。

# 幽默的定义

幽默有很多的定义，我自己觉得很靠谱的定义有2种：

幽默起源于不太认真的看待自己。

你不太把自己特别当回事情的时候，你才会有幽默。你越把自己当回事，你越没有幽默感。你能说幽默的话，或者别人对你说幽默的话都有一个前提，就是你的权威不是绝对的，你是有缺陷的，你是有漏洞的。

一个富有幽默感的人，他一定是具有某种坦然自嘲的气质，没有这个前提，你想要幽默，结果出来的只是滑稽，甚至滑稽都算不上。

所谓幽默是一种对生活的主动。

一个很被动的人他是没办法幽默的。在一个固定的场景下，一般的人都是顺向的思维，而幽默的人不是被动的受这种态势的操纵，他在思维上完成了某种逆袭，一种超级主动的方式来解构和重新定义眼前的场景。

例子：独木桥上的对话

+   1. 一个旗帜鲜明，针锋相对的立场。\n2. 一个表面上非常友好，非常有亲和力的，不捕破窗户纸的一种界面。

这两者合起来，才能算得上幽默。
