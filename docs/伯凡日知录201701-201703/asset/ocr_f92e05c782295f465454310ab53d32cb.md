# 本周问答 | 伟大的灵魂都是雌雄同体的

本周问答 | 伟大的灵魂都是...

本周大家就操作系统这个话题提了许多的问题。

有一个我认识的朋友给我发了微信说，他最近在给自己公司做年终总结的时候一直在想一个词，他想表达的是公司里头看不见摸不着，但是在悄悄的决定着，影响着，左右着公司の運行的那种神力量。他听到这周节目的时候，他觉得这个词他找到了，就是操作系统。他说我发现自己公司的问题就是操作系统严重老化，而应用软件越装越多，结果公司现在是处于一种几乎是到了系统崩溃的程度。所以现在他要做俩件事情，一个是要卸载大量的应用软件，第二是如何优化自己公司的操作系统。看来这个同学是深有感触。

Eleven：电脑中存在双系统，那现实中是否存在这种可以随时切换的系统呢？

# 吴伯凡

应该说在现实当中，让自己的公司，让自己的大脑同时具备 windows 和 Macintosh，这个系统不好用的时候切换到那个系统上，这是一件很值得向往，但是做起来是非常难的事情。我们的感官器官，我们的思维方式，包括我们遵循的制度文化本身都有一个特点，就是难以反映自身。眼睛能看见所有的东西，但是它看不见它自身。即使在镜子里头它看到的也是镜子。一个人的心智模式决定了我们做事的方式，思考问题的方式，但是我们又常常意识不到它的存在。

《第五项修炼》这本书其实它就是要提供一种路径，提供一种方法，让我们能够反映自己公司的运行的模式，让我们反映自己的思考问题的方式，让自己看到自己的后脑勺，抽身出来看自己。这本书写的那么厚，后续的著作那么多，问题是讲清楚了，但是我们要真正获得那样一种方法，非常非常的难。

美国有个作家叫菲茨杰拉德的有一部作品，我们可能都看过，叫《了不起的盖茨比》。他说一个伟大的头脑的标志就是在自己的头脑当中同时运行两套思考方式。经常是用一种思考方式来看自己的另外一种思考方式。当你具备这样一种能力的时候，你思考问题，做事情就不大可能钻到牛角尖里头去了。也就可以说我们不大可能陷入到一种愚昧的状态。什么叫“愚”，愚就是心陷到一个角落里头，没办法出来。愚上面是一个禺，下面是一个心，所以愚就是心陷到一个角落里头而无法抽身出来。如果我们自己在迷宫里头走，另外一个我能够站在迷宫外头给自己指点该怎么走的时候，我们其实是很轻松走出迷宫的。但问题是，我们常常没有这样一种抽身的能力。

这周关于操作系统的話題其实也是提醒大家和提醒自己，我们常常是身不由己的，我们常常是自己以为自己很主动，很积极，在左右着一切。实际上我们是在被左右，被操纵，被操作的一种状态。

蒋杰：企业的操作系统和企业的基因有什么样的关系？

# 吴伯凡

应该说这个关系非常的密切，在某种程度上说，这二者其实就是一体的。我看过一种关于公司DNA的理论，这种理论认为，公司的DNA取决于公司里头详细传递的方式，你是自下而上的还是自上而下的，是中央控制式的还是分布式的。

第二是你决策权在哪里，你的决策权的重心是偏下的还是偏上的，还是在中间的，决定了你的公司的DNA。

还有就是你的激励方式，你是在激励什么。任何一个公司的激励系统其实都是在悄悄地决定公司的走向，领导者的自己的一言一行在很多时候也是一种激励系统。领导者常常是在自己不自知的情况下发号施令。你觉得你没有表态，实际上别人其实已经清楚清楚地看到了你的态度了。

还有就是公司的组织结构，在信息传递方式，决策权和激励方式之外还有一种东西就叫做组织结构。这种组织结构比这前三种因素更能够决定公司的基因。

如果我们把决策权，信息传递方式，激励方式和组织结构这四个要素合到一起，大家马上就会意识到，这就是一个操作系统。所以在一个公司里头，你的操作系统决定了你现在的状况，更决定了你未来的命运。但企业的领导者常常是意识不到这一点的，常常觉得企业的命运，企业-Louis走势是取决于他怎么说的，他怎么想的，他怎么做的。而忘了操作系统是一个类似于黑箱的东西，你的每一个决策，你的每一次行为，你的每一句话都会输入到这个黑箱里头，最后的结果往往是你自己意识不到的。

何荣：现在的各种平台都具有女性特质，像淘宝、微信、微博等，特点是营造出一种生态。吴老师的日知录更偏重哪个特点呢？

# 吴伯凡

如果这样问的话，我首先要告诉我这个不太具有女性的特点。我希望是今后更多的具有女性的特点。

据说伟大的灵魂，伟大的组织，伟大的人都是雌雄同体的，既要有雌性的那种自强不息，积极主动，操之在我的那样一种特质，同时又要具有厚德载物，具有隐忍包容，能够自动地降低一个产品和一个公司的噪音和杂质的那样一种功能。

我们听说过一个词叫信噪比，我们发出一个信号，别人才是否能够接收到领悟到你的本意，那就取决于你的信号与噪音的比值。如果你信号很大，但你的噪音也很大的时候，别人往往是听不清楚的。如果你的信号不是那么强，但是你的噪音很低的时候，别人也可很好的接收到感受你所发出的信息。所以我们做通信，做沟通，最重要的工作就是如何增强自己的信号的清晰度，同时要具有一种降噪的能力。

在一个公司里头，太过于男性化的公司往往特别强调信号本身的强度，而不去做降噪的事情。一些具有明显的女性特质的领导者或者演讲者，他们常常只在乎如何说，而不在乎如何去降低自己说的时候可能随时在释放着各种的噪音。所以最好的状态是雌雄同体。
