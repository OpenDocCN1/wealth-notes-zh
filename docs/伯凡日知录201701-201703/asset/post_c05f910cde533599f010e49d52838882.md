# —— 知识笔记 ——

我们今天要解读的关键词是惰怠，这个词也可以说成急惰，急慢的怠，惰性的惰。
这是任正非在新年反思的时候提到的一個词，说华为要保持警醒，华为正有可能变得急惰。那是什么意思呢？华为的干劲很大，在一个大家都说生意不好做的时候，年增长率达到百分之三十四，这个结果一定是大家干出来的，他怎么会讲华为要提防急惰这种状态。

# Inertia

惯性，物理学名词，一个物体在运动的过程中当中具有一种惯性，即使火车要进站的时候，发动机关了，但是它还是能够到站，因为火车在运动的过程当中已经形成了一种惯性，那种惯性能够继续推着它往前走。

惰性，惰性在我们看来就是不动，不爱动，懒惰的人就是不爱动地方，哪儿舒服哪儿待着，好吃不如饺子，舒服不如躺着。

这两个词一个是跟动态有关，一个是跟静态有关。这两个词为什么在英文当中是一个词呢？其实仔细想来，惰性和惯性还真是有相通的地方。

英文词典里头对 inertia，对惰性有一个解释，很有意思。指的是不想改变生活和工作习惯的倾向。

你不想改变就是惰性。哪怕你还是在动，但是你不想改变，这意味着惰性已经悄悄地控制着你。当我我说一个公司在飞速发展的时候，我们首先想到的是它的惯性，它借助这种惯性还能够继续往前走。

# 惰性的两面性

比如说像索尼，在我们看来它的发动机可能都已经停了，但还是在继续往前走，可以说它的品牌是有惯性的，它拥有的资源赋予它某种惯性，能够在一个已经缺乏动力的情况下让企业继续往前走，这就是企业的惯性。在这个意义上说惯性应该是好的。

从另一面看，当一个企业被惯性所驱使的时候，它的状态就是没有动力了，没有自我改变的欲望和能力了，这个时候它就已经陷入到惰性当中了。

Inertia 这个词是一种很好的提醒，不管是人还是公司，当你高速发展的时候，就意味着你的惰性已经产生了，你感受到的是惯性，你没有感受到的就是惰性。

# 例子：蛇头的常识

蛇头，就是领着别人偷渡的人。因为偷渡的人是不能走直路的，他们要不停地绕着走，他走的永远是弯路，是蛇形的，也就说是偷渡的队伍是蛇形的，所以走在前面的那个人叫蛇头。

据说有经验的蛇头都有一个常识，当整个进程特别顺利的时候，他就会感到一种巨大的恐惧，他会想一想能不能再找一条路，为什么呢？因为过分的顺就可能意味着一个巨大的陷阱，只有那些菜鸟级的蛇头，他会乘胜前进，最后顺利地进入到警察已经设好的大口袋里头。

爱尔兰作家王尔德是一个挺会抖机灵的人，有一次他演讲的时候说了一段话，下面就响起了雷鸣般的掌声。他就反问一句：”我刚才到底说错了什么？为什么下面掌声雷动？“ 这个人真会抖机灵，他又赢得了一次掌声。

> 我们借用他这句话，赠送给企业家：”我到底干错了什么，为什么下面是一片欢呼声。”

一说到这个我们马上就想到一个词——居安思危，或者还想到一个概念叫舒适区。我们曾经讲过谷歌在把公司的名称改成阿尔法贝塔的时候，发布过一个公告，那个公告里有一个很难听的说法。他说我们之所以这样做，是因为我们近年来的业务发展得过于顺利，我们担心我们会陷入到一种叫做 Fxxking Comfort 当中，其实很多的 Comfort 都可以在前面加那么一个词。管理学的说法就是你的核心能力过于强大以后，会导致一种核心能力的硬化和核化，也就是说让你的能力失去弹性，你只能沿着这样一个路径往前走。最后的结果很可能是，一旦有变你完全没有更改的机会。

有经验的领导者都会把特别顺利的状态视为一种不祥之兆。

君子终日乾乾，夕惕若厉，无咎。

君子应该整天是小心翼翼的，心里头充满着忧患的，即使一天的事情千完了，到了晚上还要保持着一种警醒，仿佛遇到了厉鬼，特别又恶的鬼，只有在那样一种状态才会无咎。

咎上面是个处，下面是个口，那个口代表陷阱，处就是待在陷阱里。只有君子终日乾乾，夕惕若厉，你才可能不掉到那个陷阱里，换句话说当你很舒服的时候，你已经处于一种 Fxxking Comfort。

# 例子：柯达的黄昏

2001年，柯达公司迎来了他们公司业绩最好的一年，公司上下无不欢欣鼓舞。不仅仅是因为这个业绩达到了历史最高水平，而且这个好消息能够驱散他们心中的焦虑，“人人都说数码相机时代要来了，你们看看我们今年的业绩有多少”。

在柯达公司上下一片欢腾的时候，大家忘了问一个其实很简单的问题，为什么今年我们的业绩会那么好？真实的情况是，这个行业已经不行了，这个行业已经没落下去了，所以其他的公司就纷纷撤离了。退出去的这个公司就会把他们原有的市场份额自动地让出来，留下来的公司可以独占风光，这时候整个市场都属于你的，那业绩不好吗？夕阳无限好，只是近黄昏。

# 做企业的扒道工

管理哲学家查尔斯·汉迪有一个说法，就是每一个公司的领导者都应该在你公司的办公室画一道抛物线。你要天天想一想你的公司到底处于抛物线的哪个地方，是在抛物线的左边还是在抛物线的右边。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_79_0.png)

当你特别顺的时候，你应该提醒自己，我已经离右边半条线非常近了，这个时候你要干一件什么事儿？培育一条新的抛物线，要不然你就会行驶在一条没有扒道工的铁路上。

一个领导者应该学会做扒道工，在你所在的这个抛物线上，你要决定在哪个点上建立一个岔道，而且要敏锐地察受到你的公司可能正在接近岔口。安迪·格鲁夫把这个点叫 Turning point ，不是说你现在的公司突然要转型。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_79_1.png)

前两年我们听到了很多人讲企业转型、传统企业转型，我认为那都鬼话，至今为止我没有看到哪个传统企业转型成功的。

查尔斯·汉迪告诉我们，要建立岔道而不是所谓转型。企业的领导者要成为一个建立岔道的人，并且要守护那个岔道，做一个扒道工。

原有的业务它一定是往前走的，公司成功的路径你是很难改变的。也就是说在没有岔道、没有扒道工的情况下，所谓的转型其实就是出轨，就一定会车毁人亡。

这个时候你应该悄悄地培育一个新的成长曲线，当你的公司沿着旧的成长曲线划过了抛物线顶点的时候，你的那条新的抛物线已经悄悄地形成。

启动一个新业务，刚开始都会陷入到那种状态，钱花得非常多，效果非常得差，成本很高，收益很小。所以你那条新的抛物线很可能是一条倒置的抛物线，也就是说新的抛物线顶点可能正好处在旧的抛物线顶点的正下方，这是一件好事。为什么是一件好事呢？因为你的旧业务已经达到顶峰，足以支撑你新业务的谷底，让你的新业务划过谷底，然后开始上升。

这种成长方式不叫转型，而是叫转轨，但转轨之前你先要铺设这条轨道。

IBM从当年卖磅秤的公司变成计算机产业的领袖企业，并不是在磅秤上做文章，而是用卖磅秤、卖奶酪切片机和打卡机赚来的50亿美元来培育一个新业务，那就是计算机的业务。所以当商业环境发生变化的时候，它活过来了，它没有死去。

很多企业的领导人很容易被快感所裹挟，或者说是被惯性所裹挟，丝毫没有意识到惯性即惰性。我们个人也是这样，个人的成功往往也是这样，当你觉得特别顺的时候，应该意识到你已经陷入到一种惰性当中而不自知，这个时候的高歌猛进会让你耽误一件大事，那就是你忘了做自己的扒道工。

所以怠惰是一种很可怕的习惯，但最可怕的怠惰我们常常是没有意识到的，有时候我们的勤奋、我们的活跃本身就是一种怠惰。任正非在新年的時候讲华为要防止怠惰，目前在中国年销售额已经达到5200亿的这家公司，能够意识到这一点，值得我们每一个小公司、每一个创业公司，尤其是值得那些融到了B轮、C轮的公司深思一会儿。

先说一些题外话——

前几天我桌上不知道谁给我放了一本书，是房龙的《宽容》，Tolerance，这本书很有生命力，文字通俗，大家要练一练自己的文字水平的话，可以看看1985年三联书店出版的那一本，那个版本差不多能显现房龙文笔的精彩之处。

房龙的故事很励志，他年轻的时候立志想成为一个作家，天天买最廉价的话剧票到剧场里去听话剧。因为话剧的语言既精练同时又上口，他要做一个受人尊敬的通俗作家，天天去听话剧，那可以说是他的童子功，后来他就写了很多的书，包括这本《宽容》，还有《圣经故事》，还有《房龙地理》，还有《人类的故事》等等。

家长们要是想提高孩子们的作文水平，多让他们读一读房龙的书，让孩子多听话剧会有帮助。

我之所以提到这个书是最近我恰好在思考“宽容”这件事儿。宽容这个词听起来很有道德色彩，“你要做一个宽容的人”，“你要宽容一点”，“你要包容一点”，“你干嘛那么刻薄”等等，我们常常把它认为是一个道德概念。

我越来越意识到它不是一个道德概念，它是个能力概念。按现在流行的说法，这本书不应该翻成宽容，而应该翻译成宽容力，今天很多讲创新的书现在都不叫创新了，叫创新力。

在房龙看来不宽容的人，与其说他是邪恶的，不如说他是无能的，一个不能宽容人的人，是因为他没有宽容人的能力。

在房龙看来，不宽容的本质是恐惧。一个 人之所以刻薄是因为当别人再说你有点刻薄，当自己也觉得自己有点尖酸的时候，你要意识到你的内心可能有藏着很多的恐惧。你应该去跟好朋友或者找个靠谱的心理医生去聊一聊，找到你内心的那个恐惧，把它抖落出来，那么你就变得不那么尖酸、不那么刻薄了。如果你要是以尖酸刻薄谋生，做一个毒舌主持人，毒舌的脱口秀，那你就可以不妨把它当成是一种工作技能，在生活当中还是宽容一点好。

# 宽容的能力

不宽容是因为你缺乏宽容的能力。宽容是一种坚强而不是软弱，宽容所体现的退让是有目的、有计计的，主动权掌握在自己的手中，无奈和迫不得已不能算宽容。当一件事你被迫忍受的时候，那不叫宽容。宽容是一种居高临下的包容，宽容是建立在一种强大的自信的基础之上。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_81_1.png)

# 例子：盲人摸象

当七个盲人在摸象给出的答案千差万别，甚至是针锋相对，可以说他们之间是很不宽容的。

当一个人摸到象牙的时候，说原来大象就像一只棕熊；当一个人摸到大象的肚子的时候，大象是一堵墙；有人摸到象鼻子的时候，说大象是一根管子。我们可以想象当时在场的七个盲人，每一个人听到别人观点的时候一定是嗤之以鼻，甚至会大声地反驳。他们能彼此宽容吗？不能，因为他们连视野狭隘都算不上，他们看不见整个大象，所以他们就会针对大象是什么会争论不休，甚至视同水火。

假如旁边站着一个明眼人，他是能宽容每一个盲人的。首先他知道大象是什么样子，这一点他坚信不移，他没必要向别人证明自己的正确性。第二，他也知道为什么这个人说大象像棕熊，那个人说大象像柱子，因为他知道其中的原委，所以他能够保持宽容。

这个例子提醒我们，当我们陷入到一种不宽容的时候，我们应该意识到也许我们的视野很狭窘，甚至连视野狭窘都谈不上。有时候我们看见小孩子在我们面前耍鬼把戏的时候，我们会淡淡地一笑。
第一，你知道他在干什么；第二，你知道他的这种鬼把戏都是在你的可控之下的。你具有一种居高临下的包容能力，你心里头不恐惧、不慌张，你没有任何想证明自己正确性的愿望。

罗永浩的那句话用在这里还是挺恰当的，他说彷徨的人生无须解释，当你特别想解释什么东西，想证明什么东西的时候，只能就证明一点，你不彷徨。

# 惭愧性功能

我们读心理学书的时候常常会看到这样的概念，代偿性满足，代偿性功能。我们很多想要强烈表达的观点、立场、情绪，其实那里的认知含量很低。我们很多的论调，那个理论的成分其实很低，情绪的成分其实很高，我们不过是因为缺了某种东西，因为恐惧某种东西，因为对某种东西不自信而加大嗓门，喊出各种各样的论调。

> 威不足则多怒，信不足则多言，知不足则多虑。

一个人内心威严不足的时候，或者他的威信、威望不高的時候，他常常会多怒。内心的自信不足的时候你说话就会很多，有的人在你面前拼命地解释的时候，他往往是因为心虚，其实他心里头觉得这事儿做得都不怎么体面，所以他的话就会很多。我们很多时候思绪很多、想法很多，这并不表明我们多有思想，而恰恰表明我们没有思想。当我们的思想力不够的时候，心里头各种的顾虑、各种的考虑就会绵绵不尽地涌出来。

比如说前面有一道矮墙，如果你个子很高腿很长，一步就迈过去了，那这个墙对你来说就不是一个问题，这道墙不会让你愁肠百结。如果是一个矮个子，一个小孩儿、一个侏儒，他面对这个墙的时候，他一定会想方设法、不择手段，他奋斗、他挣扎，并不表明他的能力有多强，而恰恰表明他的能力很低。所以说思不足则多虑。

弘一法师的这句话很能说明什么叫代偿性功能和代偿性满足，也很能说明为什么会有那么多人不宽容，因为他们没有宽容别人的能力。

# 例子：陈咬金

以前我看过一个话剧叫《秦王李世民》，那里头让我印象最深的不是李世民，而是程咬金，我当时就很佩服他。他手下的人抓了一个对方的败将，那个败将一看见程咬金立即就跪下了，不停地磕头作揖。

程咬金冷冷地看着他在那磕头作揖，说了一句：“你起来吧，起来吧，我最怕软的，走吧，走吧。”我当时觉得程咬金好厉害，我长大了一定要做一个像程咬金这样的人。当时我不明白我为什么那么佩服他，现在我明白了，他有宽容人的能力。他太强大了，所以面对对方的败将，他能够有如此高的姿态，姿态不是摆出来的，因为他很彷徨。

昆德拉说他去巴黎的时候，最不能忍受的就是巴黎街头的狗屎，很多人去过巴黎都有这个感受。但是他自己回过头来想，其实也不算特别的难受，因为那毕竟是狗屎，他不会感到特别的恶心。如果换一种，那是人屎，那你就会极其恶心。他就在反省，为什么我看狗屎不那么恶心呢？因为我人，那是狗，我有一种居高临下的本钱，所以我就 Motor。

说到这里我们就大概明白了，为什么我们说宽容不是一个道德概念，它是一个与能力相关的概念。不宽容就意味着无能，反过来说一个人包容的程度与他能力的大小成正比。

# 《菜根谭》

我若为洪炉大冶，何患顽金钝铁之不可陶熔。我若为巨海长江，何患横流污溅不能容纳。

如果我是一个大熔炉，什么样顽金钝铁到我这儿来自然熔化，如果我是巨海长江，什么样不干净的东西我都不怕，我都能够包容。一个人的所以那么的不宽容，是因为他不是洪炉大冶，更谈不上是巨海长江。

这两个问题都很有深度。

国学大师牟钧锡有一个说法是，道家是佛家在中国的思想代理人，或者说为佛教打前战的，佛教之所以能够在中国生根，与中国本身就有的道家的思想有很大的关系。简单地说道家和佛家本身就有相通的东西。庄子的那句话，至人用心若镜，应而不藏，特别像佛教的东西。

在中国哲学史领域有一个大家基本认可的观点是，中庸跟道家是最具有相通性的，所以中国最后是儒释道一体，尤其到《宋明理学》，到《王阳明心学》的时候，都分不清楚他的思想有哪些到底是属于佛家的东西，哪些是属于道家的，哪些是属于儒家的，或者说王阳明的思想是以儒家思想作为正中、作为底色，但是他里面包含了大量的佛家和道家的思想。

中庸跟佛家的出离心是不是类似？的确的确就是类似的。

“允执厥中”就是要在动荡当中始终恪守一个不变的状态，这本身跟出离心是有关系的。用佛教的观点来说就是一种不粘附的心态，我们讲过荷叶、荷花，它就是具有那种不粘附的状态，出污泥而不染。水也没办法把荷叶打湿，就是因为它有一种不染、不粘附的特性。如果我们的心能够做到这样，你可以说那就是保持中庸，也可以说是保持了出离心。

# 吴伯凡

这个问题让我首先想到一个词叫做道德爵士乐。熟悉爵士乐的同学知道，爵士乐里头是包含大量即兴演奏成分的，在丹麦每年7月份都有一个国际爵士音乐节，我听了一次爵士音乐才知道什么叫即兴。也就是说他们三个，钢琴手、贝斯手和鼓手，他们之间有一种紧密的默契，某一个音符、某一个节奏一旦出现就到了即兴演奏的时刻了，听众听久了以后都知道这个时候就要开始即兴演奏了。这个即兴演奏尤其是那个鼓手，那种自由挥洒的状态，他可以在差不多5分钟内就在那即兴演奏，但是当他突然把某一个鼓一敲，那个声音一旦出现的时候，他们马上又进入到非即兴状态。所以有人就把在遵守原则的时候保持灵活性就叫做道德爵士乐。

要了解什么是道德爵士乐，我觉得最通俗的读物就是王跃文写的那个《大清相国》，那里头的陈廷敬就是一个典型的掌握了道德爵士乐的人。这个人在中国政治史上创造了一个官场奇迹，他是康熙的老师，大家知道在中国古代辅佐少主都没有什么好下场。吕不韦没有好下场，张居正没有好下场，但是陈廷敬作为康熙的老师，他从21岁进入政坛到72岁的时候老死相位，51年的时间没跌过什么跟头，而跟他同朝共事的明珠、索额图一大批纷纷阵亡，但是他始终是屹立不倒。有人说那他是不是个好臣？不是，其实做好臣也 малы не能够保证你屹立不倒，有些好臣死得也很惨。

陈廷敬是一个能够在原则性和灵活性上处理得非常有艺术的，可以说达到了炉火纯青的地步，他在原则的坚守和即兴发挥之间可以说是做到了完美无缺的程度。在个人的成就上他是著名的书法家，大家可以去在网上看一看他的书法，那真是一绝。有一个字典叫《康熙字典》，那个总编纂就是陈廷敬，同时他在康熙朝发起了一场金融改革，效果非常好，不像王安石那种变革最终是半途而废。

所以如果大家要了解灰度，要了解道德爵士乐，可以去读一读那本其实很好看的小说——《大清相国》。

# 吴伯凡

要区别和折腾和不急惰有一个标准，在管理学上叫MBO，目标管理，Management by objective。管理是由什么东西来管理？是由管理者来管理吗？不是的，是目标来管理。而管理者做的事情不过是面对一个目标，你要分清步骤，你要区别哪些事情是创造价值的，哪些事情是不创造价值的，或者说是跟目标无关的。如果你不始终是把目标作为管理的前提，那么管理者就会陷入到一种很自由散漫的状态，他会做很多事情，但是这些事情当中很多是跟目标没有关系的。

我对管理有一个特别简单的定义，就是去掉一切不创造价值的环节，尽可能地增加与目标相关的价值环节，这就叫管理。如果用这样一个标准来区别不急惰和折腾，这就很清楚了。
