# —— 知识笔记 ——

我们昨天谈到了图灵测试，谈到了什么叫二，谈到了傻子和疯子的区别，傻子是完全没有内容、没有答案的人，而疯子是有内容不知道场景的人。一个缺的是内容，一个缺的是场景和语境，一个人做到既不傻又不疯不是一件很困难的事情，但是你要在这个基础之上要具备真正的智能，那就是一件非常难的事情。

有人说围棋代表人类智力的尊严，这个没错，但是围棋它不能代表人类智能的尊严。能够代表人类智能的是另外一群人。今天，我们来谈谈和珅，谈谈普京，这样的他们到底具有什么样的智能？

![](bbox=[0.15, 0.97, 0.85, 0.00117])

和珅从小就有一個願望，為皇上服務，能够成为皇上身边的人。他想了一想，如果走寻常的路，就是十年寒窗读书，通过考试最后一步步升迁，从科长一直做到部长，然后渐渐就能见到皇上。但这个程序要走完的话，得好几十年的时间，甚至好几十年也走不完。他想了一个最直接的方法，能够不用走这些路马上就能见到皇上，到皇上身边工作，就是给皇上抬轿子，这个不需要考试，不需要漫长的升迁。

你想一个可以去考狀元的人，他去抬轿子，那他就是在抬轿子的人当中最聪明的人。所以他很快就成为一个杰出的轿夫。

有一次乾隆在给那些大臣训话，乾隆是满族人，他对汉文化有一种既崇拜又自卑的那样一种情结。所以按照阿德勒《自卑与超越》心理学的说法，越是自卑的人就越是尽可能抓住各种场合来凸显自己并不是很擅长的，但是他很希望拥有的那样一种特质。

乾隆发表讲话有个特点，喜欢引经据典，因为他意识到自己的文化不高。这次讲话的时候，他引到了《论语》当中的一句 话，结果上半句说完下半句想不起来了，这可是一个非常严重的问题，对于皇上来 说是一个极其严重的挑战。

# 普京

在人们的印象当中，普京就是彼得大帝，就是伊凡雷帝，那样一种以雷霆万钧之势 来推行各种政策方案的人。其实普京之所以是普京，普京能够成为总统，他以露雳 手段行菩萨心肠，就是凭他的那种超级的 智能或者说对于场景的超级感知能力和解 决能力，以及应对之策。
