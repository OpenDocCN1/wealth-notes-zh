周栎：吴老师如果看见这个留言，我希望你能回复下。我经常学习一些知识，听的看的好像都是只言片语似懂非懂的样子。但是我总觉得自己没有形成一个完整的认知体系，不知道要如何建立一个完整的认识体系？对现实生活中的问题没有自己决绝办法或判断依据。一定要建立一个自己的完整的认知体系吗？

# 吴伯凡

这个同学的问题我一下子就想到那句老话，我们不能学会了游泳再下水，我们对于世界的认知总是开始于碎片化的不全面的认知。不管你承认不承认，我们对于世界的认知都是一个不断的试错，不断的迭代，以比较小的代价，非致命的代价去犯错误，然后在这些错误当中获取真知。凭借这些你积累下来的很可能仍然是很片面的认知，你去跟人，跟事打交道，去验证或去证实和证伪你的认知，这样一个个的快速循环，你就可能形成一个相对完整，相对靠谱的认知。

可以说认知的形成很像是一个拼图游戏，我们不可能获得了一个完整的认知之后再去跟世界，跟人打交道。你可以回想一下你是怎么学会说话的，或者去观察你的孩子，你周围，你朋友的孩子，他们是怎么学会说话的。刚开始是一个字一个字的蹦，常常犯各种各样的错误。但是，这个时候他不会想到说我能不能先学习掌握汉语的语法之后再来说话呢？事实上，他可能说的每一句话都是有问题的，都是有语病的，但是在这样一个多次的看似反复、重复，实际上都是在悄悄迭代的认知当中，一个小孩子就学会了相对完整，相对准确的表达自己意思的技能。

所以，如果要我给出建议的话，现在你不要去想建立一个完整的认知体系，应该说从古到今的哲学家们，那是一些聪明透顶的人，他们试图去建立一个完整的认知体系，但是哲学史，思想史表明他们的这种努力不过是以不断的努力证明自己永远不会成功的一种努力。所以不妨听听王阳明的教导，在事情上面，在事上面，要知行合一，行到极处即是知，知到极处即是行，不可能脱离练习试错，碰壁以后小成功、小收获而凭空杜然之间获得某种所谓的完整的认知体系。
