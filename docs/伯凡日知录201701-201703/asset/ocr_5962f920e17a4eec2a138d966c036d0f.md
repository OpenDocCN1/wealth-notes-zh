# 福

福的右边的那个字“畐”也念fū，它本来意思是指人的腹部，也就是我们的肚子。

畐下面有一个田字，但是它不是指田，而是指肚子充满、充实的一种状态。口字里头那个十字就是代表充满，充实之意。

与福字同源的两个字：

富，富贵的富的下面与福字的右边是同一个字，指的就是充满充实的意思。

备，准备，它的意思同样也是指充足和充满的意思。

如果说幸福的幸是一种因为逃脱了灾难免于不幸之后的那样一种感受的话，那么福是指由于我们的愿望，由于我们的祈祷，上天把一种东西赏赐给我们，所以福的这个字，它本来意思就是指来自于上天，来自于神的赐予和赏赐。

与福相关的一个字是佑，它的意思是来自于上天的护卫，上天的保护，这就叫佑。

# 中国古代的左和右

# 左为卑

左将军和右将军，显然是右将军大。

左丞相和右丞相，显然是右丞相大。

辅佐，左的意思是辅助的意思。

旁门左道，思维左道就是不太重要的辅助性的路叫左道。

# 右为尊

座右铭，是古人为了勉励自己，把一句非常重要的活刻在他座位的右边，时时刻刻在提醒自己。

无出其右，就是说没有一个人比这个人更厉害，没有一件事比这件事情更重大，所以叫无出其右。

加了单立人以后的左和右，它们的意思也是有明显差别的。佐是辅佐，佑是护佑，是保佑，是自上而下的赏赐给你的一种东西。

今天人类已经进入到一个相对富足的时代，由于我们拥有了这种富足感，我们常常会对我们所拥有的东西视而不见，或者是比较忽视，比较轻视的状态。爱因斯坦在他的一封信里头说，“我所吃的食物，我所使用的物品没有哪一件是我自己做的，我甚至都不知道它们是怎么来的，每想到这一点，我的心里就有一中强烈的收缩的不安，我只能通过辛勤的劳动来驱散我心中的这样一种不安。”拥有这种心态的人，他每得到一点点东西，他自己心里头都会有一种类似于曾国藩所说的“每遇幸事，常念天之过厚于我”。

![](bbox=[0.07, 0.00156, 0.93, 0.00172])

在鸡年来临之际，我真诚地祝愿大家拥有越来越多的幸福感，而要得到幸福，要拥有幸福感，首先我们要学会减少自己的拥有感和占有感。当你意料的东西越少，你所获得的意外之喜也会随之增加。与此同时我们要意识到福是我们真诚的期待和劳动的结果。

《左传》里有一句话叫“小信未孚，神弗福也”。当人不能够一点一滴践行自己的信用，恪守诚信的时候，上天是不会将富有和完备降临到你身上的。我们要学会珍惜那些看似免费的东西，很多所谓的免费的东西不过是我们幸运的免除了成本和代价的东西。其实它们很可能是相当珍贵的。

我们一直以为空气是免费的，但我们今天已经意识到空气，新鲜的好的空气并不是免费的，只有到我们今天天天吸雾霾的时候才意识到空气并非免费的。

我们的身体是免费的，我们在出生的时候我们拥有了身体，但我们并没有花钱。身体最好的状态就是让我们意识不到它存在的状态，当我们意识到某个器官的存在就意味着某个器官出问题了。

每一个器官都是免费的，但它并不真是免费的。什么时候我们知道它是不免费的，知道它是有价格了的呢？这就是在它出问题的时候。人只有到医院以后才知道器官是不免费的。

所以我们要珍视所有那些看似不免费的，但实则非常珍贵的东西，比如说空气，比如说我们的身体，比如说亲情，比如说来自父母的，来自长辈的关爱。

真诚地祝愿大家在鸡年里幸福安康！
