克里斯坦森说一个占据行业领导地位的企业，它有三样东西是最宝贵的，

+   它的价值观，
它丰富的资源，
它成熟的流程。

有意思的是这三样东西又是 最可怕的，过于固化和明确的价值观，过于丰富，丰富到你根本没有勇气去抛弃的那些资源，以及成熟到你可以不假思索地按照它去执行各种任务的流程，这三样东西就是企业的惯性或者说是惰性。

这三样东西还有个专门的说法就叫“遗产的重负”，很多的在位企业就是被这个遗产的重负压得喘不过气来，但自己又自得其乐。换句话说这三样东西，VRP（价值观、资源和流程）是一种很好的防癌机制，这三样东西表面上是一种抑癌基因，能够保证企业的战略执行不走样，能够让一个企业越来越像一个领导性企业，但是它是另外一种原癌基因。当它小心地提防、抵御各种癌变的可能性，一旦出现某种异动，企业要不快刀斩乱麻似的切除掉这个疑似的癌块，要不就是有一种强大的机制让这种所谓的癌变悄然终止。当企业这样做的时候却没有意识到你可以切除已经发现的癌块，已经出现的癌变，但是你没有意识到的是整个企业正在被一个悄悄成长起来的市场悄悄地切除。

处于领导级地位的企业要找到出路就在于你有没有一种强烈的动机或执行力。在你原有的价值观资源和流程与新的产品、新市场、新业务部门之间形成一道防火墙，新的业务和旧的业务是在同一个锅里头吃饭的时候，新的业务一定会饿死，那你就必须再搭个灶台、再做一口锅，让新的业务和旧的业务彼此隔离，互不相扰，与其相濡以沫，不如相望于江湖。

# 例子：苹果

如果说在苹果公司iPod之所以能够做起来，是因为iPod跟它原有的业务之间是没有竞争关系的，他们之间的动机也是不对称的，他们所针对的市场是不一样的。

但后来的苹果也出现了问题，比如说当他们推出iPad的时候，他们突然发现iPhone和iPad之间其实是有一种潜在的竞争关系。当手机大屏化的趋势越来越明显的时候，苹果为了让手机不 chánh对Pad形成威胁，他们坚持不做大屏手机，因为他的手机的屏大一点就意味着Pad的销量就会小一点。

今天的苹果也仍然不能解决这个问题，但是二者之间的矛盾并不是那么大，而且他们今天已经意识到了，如果Pad，尤其是Mini Pad非放弃不可的话那就放弃。他们最近推出了那种超大屏幕的Pad，让大屏的手机跟那个超大屏的Pad之间不形成正面的冲突。

# 例子：腾讯

当移动互联网来临的时候腾讯面临着两种选择，一个选择就是推出手机版的QQ，让QQ在移动互联网时代延续它的辉煌，还有一种选择就是推出一个真正面对移动互联网时代的产品，那就是微信，但是如果在一个公司里头同时有两个产品，也就说让QQ和微信在一个锅里吃饭的话，那么微信可能会因为抢不到食而饿死，那怎么办？腾讯做了一个很好的决策，那就是在新的产品、新 的业务与旧产品和旧业务之间设置一道屏障，互不相扰，如果两个产品放在一起，在企业内部新的产品就很可能被认为是癌变，是一个癌块，是一个威胁到企业的原有产品，甚至威胁到企业的整体生命的一个产品。所以很可能会被掐死在摇篮里，腾讯的领导层就做出了一个非常明智的选择，让微信作为一个相对独立的实体在体外发育生长，甚至把微信的研发团队不是放在深圳，而是放在广州，让两个产品在某种程度上实现了相望于江湖。

现在我们就明白了谷歌为什么要在2015年8月把自己的公司改名叫阿尔法贝塔公司，也就是字母表公司，让新的业务保持独立性，让新旧业务之间彼此互不相扰。新业务和旧业务不过是一个字母表里头不同的字母，离则两全，合则两伤，避免了新业务会被旧业务当着癌块切除掉。同时也避免了企业因为成熟的业务而越来越舒服，从而形成一种对新业务无形的绞杀机制。

可以说腾讯的案例和谷歌的案例为我们如何处理好创新与保守，在追求创新的过程当中如何防止癌变，在防止癌变的过程当中如何避免因过度保守而反过来让企业陷入到整体的癌变当中，提供了富有启发性的答案。
