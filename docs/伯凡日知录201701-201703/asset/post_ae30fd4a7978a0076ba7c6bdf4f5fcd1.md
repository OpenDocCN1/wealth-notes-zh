
# 为什么说是永恒之女性引领我们上升？

歌德所说的这个女性其实就是一种跟男性的思维和行为相对立的那样一种思维和行为模式。

男性的思维和行为模式：积极、主动、有作为，是一种贪多求全的思维和行为方式

女性的思维方式：往往看起来是不主动，不作为，是一种以简驭繁，以不变应万变的那样一种思维和行为模式。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_14_0.png)

# 两种模型

管理学家把前一种模式称为狐狸型，把后一种模式称为刺猬型。这个分类来源于《伊索寓言》。狐狸有千伎百俩而有限，刺猬无一技之长而无限。

狐狸，狡猾，能够想出各种办法来对付一件事情。面对老虎的时候，狐狸有各种各样的方法，它一般是跑不过，它会狐假虎威，它会用各种各样的很巧妙的方法来应对。

刺猬，看上去什么都不会，它遇到事情的时候就是收缩它的身体，任什么百兽之王都奈它不何。

# 看不见的操作系统

我们现在每个人，每天都在与这两种力量在打交道。我们在使用电脑，使用手机的时候，其实是面对是两种类型的力量。

一种是我们用的各种的app，各种的应用软件，而我们往往会觉得我们用手机就是在用这些应用软件。

一种东西我们一直在使用，但是我们并没有意识到它的存在，它真的达到了那种百姓日用而不知状态，那就是操作系统。

你在用手机的时候，首先用的，而一直在用的，而你常常没有意识到你正在用的就是那个操作系统，或者是安卓，或者是iOS，或者是windows。它是默默的在后头在分配、协调、支撑着整个系统的运行。没有它，一切应用软件都无从用起。

应用软件坏了，不灵了，我们可以重新下载，重新安装。但是操作系统一旦是出问题，你的应用软件再好都无法使用。环境也好，自然界里的生态系统就是一种操作系统，它和我们电脑，和手机的操作系统一样，它非常重要，非常强大，同时又非常的隐秘，不动声色。这就是它一直在引领我们，但是我们没有意识到它的存在。

# 故事1：《渔夫与金鱼》

有一天一个渔夫在海上打渔的时候，打到了一条小金鱼。那个渔夫发现那个金鱼突然会说话了，它告诉他：“我是大海的女王，如果你把我放了，你有什么愿望，你都能实现。”

渔夫抱着半信半疑的态度就把这条金鱼放回了大海，垂头丧气地回到家，因为他一条鱼都没有打到。当然就遭到了他老婆的义正严辞的批评了：“既然它女王，你为什么不求它帮你做点事情呢？你看，我们家这个木盆这么破了，多少年都没有换，你赶紧回去跟它说，我们要换一个好的，换一个漂亮的一个新的木盆。”

渔夫抱着试试看的心情来到了大海边，他发现金鱼已经在那儿等着他了。他陈述了他的要求，金鱼说：“没关系，你回去就有了。”等他一回来的时候，发现家里头真的有了一个崭新的很漂亮的木盆。他以为他的老婆会大大的表扬他一通，没想到他的老婆又是对手劈头盖脸的大骂一顿，既然它能变出木盆来，它一定能变出很多的东西来。这样子一趟又一趟的，就去海边，他们家的东西都换了个遍。直到最后说，我要有一座像宫殿一样的房子，你赶紧跟它说。小金鱼听到这个请求的时候有一点为难，但是还是答应了，说你回去吧，会有的。

一回去，果然发现在他们那间小破屋的那个地盘上已经有了一座像宫殿一样的楼盘。这个时候，渔夫没想到的是，他又一次遭到了老婆的叱骂。“它都能变出一座宫殿来，那能不能干脆就让我成为大海的女王。我有什么需求，就不用再那么麻烦的求它变了，我自己想变什么就变什么。”

渔夫没办法，只好回头再去求小金鱼。当小金鱼听到他的这个请求的时候，没有说话，摆了摆它的尾巴，然后就向大海深处游去。当老头走回来的时候，发现那座宫殿已经消失，展现在他前面的是他们家过去的那一个小破屋，还有一个悲伤的老太太对着一个破旧的木盆。

那条小金鱼，也就是大海的女王，它其实是一个操作系统，而它能够变出的所有的东西都不过是一个个的应用软件。

当你不再满足于拥有这些应用软件，而直接想成为操作系统的時候，你已经失去对操作系统的敬畏，你也想来一个像现在的这些创业家们做的事情，来一个彻底的颠覆，那就不行，一切都回到原处。我突然明白了，普希金要告诉我们的道理只有一个，我们要保持对操作系统的敬畏。当然，这个操作系统碰巧还是女的，它是女王，是女神。

# 气候和风景

有一个英国作家他说一个比较完美的婚姻里头，丈夫是风景，妻子是气候。

特定的气候导致了特定的风景，但是气候我们常常是感受不到的，我们能看到就是那些无限风光的风景。事实上，当我们看到一片风景的时候，我们应该想到，每一片风景的背后都有一个气候，都看不见的操作系统。

这个英国作家是想同时提醒男性和女性，提醒男性，当你很风光的时候，别忘了导致你的风光的那个你逐渐忽略的背后的那个气候；提醒女性，女性的恰当的位置是做气候。虽然它不那么显眼，但是它要比风景重要得多。

# 王和后

现今为王，内容为王。我听到这句话的时候，都会止不住地问，那什么是后呢？

所谓后字面的意思就是处在后台的看不见的隐性的那样一种力量。我们普通人常常不会去关注那些隐性的看不见的力量，因为关注了也没用，反正看不见。

哲学家们特别爱关注背后的那个看不见的东西，甚至哲学家的标签就是关注那些据说是看不见，但是非常强大的那种力量。这种习气一直传到经济学里头来了，我们刚刚接触西方经济学的时候就听到有一个词，叫看不见的手。经济现象背后有那么一个无形而巨大的力量，你可以在很多地方大有作为，但是你千万不要跟那个看不见的手去扳腕子。

# 《道德经》和《失控》

天下万物的根本是那个看不见的东西，这个无既无形也无名，无名天地之始，有名万物之母。

天地肯定比万物大，有了天地才有万物。天地之始，始就是开始的始，但是我们常常忘记它的本义了，始就是胎的意思，十月怀胎的那个胎儿就是始。我们现在不写成始了，写成胎。孕育天地的那个母胎就是无。那当然是最根本的最原始的力量。这个它作为天地的本原，人从娘胎里头一出来，不会受制于娘胎。

在《道德经》里头，无不仅仅是天地的本原，而且是整个天地运行的根本法则。《道德经》很晦涩，有很多朋友要读《道德经》的时候，我让他们读一本相对比较通俗，但是像砖头一样厚的书，叫《失控》。我曾经请教过KK，我说你整本书的哲学基础是什么？他告诉我是《道德经》。

所谓失控就是一种表面上没有控制，实际上一种无形的方式在控制这个世界的力量。面对万事万物，我们常常会有控制的冲动，而这种控制的冲动和行为常常是无效的，整本书翻来倒去告诉你，我们要学会尊重那个无形而巨大的力量。这一个无形而巨大的力量用我前面的话说，其实就是操作系统。也可以说是气候，也可以说是女王和女神。

# 水

在《道德经》里，老子常常用另外一种意象来指称无，因为无是很难以琢磨的一种状态。老子常常用一种我们非常熟悉的物质来象征这样一种无形而巨大的力量。这种物质就是水。

上善若水，因为水利万物而不争，万物生长都离不开水，但是我们看万物的时候，常常常想不起来水，看不到水。

水利万物而不争。水还有一个重要的特点，就是水往低处流，对水来说没有最低，只有更低。它的归属就是别人看不到的，别人不喜欢的，别人不乐意去的那样的地方。人往高处走，水往低处流。

水除了往低处流这样一个特点之外，还有一个特点就是，它没有固定的形状，随形而化，容器是什么形状，它就是什么形状。这个特点能用一个字概括，就是柔，柔到极处。

天下万物柔莫于水，在老子看来，这种最柔的东西又恰恰是最坚硬，最强大的东西。天下万物柔莫于水，而攻坚者莫之能胜，这种至柔又至刚存在，也就是我们说的那个无形而巨大的力量。

# 阿里巴巴为什么成功？

近期阿里巴巴有一个人引起了很多人关注，因为他套现6亿美元，差不多40亿人民币。阿里巴巴能有今天，我们不能不说到这个人，这个人名字叫蔡崇信。

有人把蔡崇信称为马云背后神秘的男人，还有人说，如果阿里巴巴是一部电影的话，马云是导演，甚至是一号男主角，而蔡崇信是这部电影的制片人。

# 蔡崇信的经历

当年他以一个风险投资者的身份来跟马云谈合作，想投马云。结果他的公司决定不投马云的时候，他自己突然对马云说：“那边我不干了，我要加入阿里巴巴。”当时马云非常吃惊：“你到我这儿来，我养得起你吗？我这儿每个月就500元人民币的工资，你还是再考虑考虑吧。”蔡崇信当时的年薪是70万美元，按当时的汇率差不多是500万元人民币。他放弃500万的年薪到阿里巴巴一个月拿500块钱的工资。从这件事情上我们能够感受到，能够在那样情况下做出那样的决断，他的的确确是一个狠角色。

从他身上我们也可以明白一个道理，真正的狠角色往往是很谦和和低调的。足够的谦和，足够的低调才有可能足够的狠。这个狠其实就是落到实处的去做事情。

可以说，马云是非常幸运的，那么一个张扬，那么一个高调的人，在他公司刚刚成立的时候就找到了一個能够默默的为他的公司写底层代码，为他构建操作系统的 人。

公司的战略、商业模式说到底都不过是应用软件，而比商业模式，比战略更重要的是他的操作系统。这是我们创业的时候常常忽略的。很多创业者以为自己找到了一个好的商业模式，找到一个好的战略，或者是在一段时间内非常管用的盈利模式的时候，就以为自己的公司大功告成，长治久安了。这其实是很成问题的。

# 阿里前员工眼中的马云

# 女人的 “无我主义”

著名的国学大师辜鸿铭认为，在中国的传统的家族里头，决定一个家族命运的往往不是那个在家族里头代表着至高无上权力的那个男人，而是一个女人。

这个女人的最重要的品质，辜鸿铭把它称为 “无我主义”。就是不强调，不凸显自己的身份的重要性，而是以一种很和蔼，很弱势，弱势到你常常在她身上感受不到任何权力感权力欲的那样一种女人。有这样的女人在，这个家族才会兴旺。如果一个家族缺乏这样的女性，或者是由一个非常强势的女性来掌权，那么这个家族就离衰落不远了。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_18_0.png)

《红楼梦》里真正的权力的源头其实是贾母，但是贾母是一个非常和善，非常明理通达的一个女性，而贾府的悲剧，或者说贾府的衰亡就在于，这个家族已经没有能够接替贾母角色的女性。

王熙凤显然是无我主义的对立面，她是极端有我的一个领导者，她能力非常的强，做事情非常的勇猛精进，但是她却是一个不祥之兆。后来，包括贾母在内的贾府所有的人都在操心一件事情，谁将会成为贾府的那个具有无我主义特点的真正的女主人。

林黛玉是另外一种极端的有我主义者。与林黛玉相反，薛宝钗才是一个真正的无我主义者，用贾母的话说：“耐得住贫贱，守得住繁华的女人。”而贾府的悲剧就在于，家族的命运被王熙凤这样一个极端的有我主义者不知不觉的引向了毁灭的深渊，而真正能够担当贾府的隐性领导力或隐英雄的薛宝钗还没来得及成为贾府的操作系统，这个家族就坍塌了。

无论是对于一个公司还是对于一个家庭来说，如何才能够拥有“不知有之”的领导者是最重要的事情，同时也是最容易被忽略的事情。

现代的家庭如果夫妻双方都争着做应用软件，而没有人愿意或者有意识的去担任操作系统的角色，那么这个家庭很可能会陷入到崩溃的局面。

如果你是一个自强不息，勇猛精进的人，你除了关心你现在正在做的事情之外，你要考虑的是如何像马云那样找到或者遇到一个像蔡崇信那样的人。在你的任务清单里要增加一个你可能忽略了的重要内容，是如何像任正非那样去为自己的公司写下底层代码，为自己的公司写操作系统，或者找到一个或几个能为你的公司写底层代码，悄悄地构筑操作系统的人。

成为风景当然重要，但是，为自己的公司营造一种气候更重要，毕竟没有气候，风景无从谈起。

本周大家就操作系统这个话题提了许多的问题。

有一个我认识的朋友给我发了微信说，他最近在给自己公司做年终总结的时候一直在想一个词，他想表达的是公司里头看不见摸不着，但是在悄悄的决定着，影响着，左右着公司运行的那种神力量。他听到这周节目的时候，他觉得这个词他找到了，就是操作系统。他说我发现自己公司的问题就是操作系统严重老化，而应用软件越装越多，结果公司现在是处于一种几乎是到了系统崩溃的程度。所以现在他要做俩件事情，一个是要卸载大量的应用软件，第二是如何优化自己公司的操作系统。看来这个同学是深有感触。

Eleven：电脑中存在双系统，那现实中是否存在这种可以随时切换的系统呢？

# 吴伯凡

应该说在现实当中，让自己的公司，让自己的大脑同时具备 windows 和 Macintosh，这个系统不好用的时候切换到那个系统上，这是一件很值得向往，但是做起来是非常难的事情。我们的感官器官，我们的思维方式，包括我们遵循的制度文化本身都有一个特点，就是难以反映自身。眼睛能看见所有的东西，但是它看不见它自身。即使在镜子里头它看到的也是镜子。一个人的心智模式决定了我们做事的方式，思考问题的方式，但是我们又常常意识不到它的存在。

《第五项修炼》这本书其实它就是要提供一种路径，提供一种方法，让我们能够反映自己公司的运行的模式，让我们反映自己的思考问题的方式，让自己看到自己的后脑勺，抽身出来看自己。这本书写的那么厚，后续的著作那么多，问题是讲清楚了，但是我们要真正获得那样一种方法，非常非常的难。

美国有个作家叫菲茨杰拉德的有一部作品，我们可能都看过，叫《了不起的盖茨比》。他说一个伟大的头脑的标志就是在自己的头脑当中同时运行两套思考方式。经常是用一种思考方式来看自己的另外一种思考方式。当你具备这样一种能力的时候，你思考问题，做事情就不大可能钻到牛角尖里头去了。也就可以说我们不大可能陷入到一种愚昧的状态。什么叫“愚”，愚就是心陷到一个角落里头，没办法出来。愚上面是一个禺，下面是一个心，所以愚就是心陷到一个角落里头而无法抽身出来。如果我们自己在迷宫里头走，另外一个我能够站在迷宫外头给自己指点该怎么走的时候，我们其实是很轻松走出迷宫的。但问题是，我们常常没有这样一种抽身的能力。

这周关于操作系统的話題其实也是提醒大家和提醒自己，我们常常是身不由己的，我们常常是自己以为自己很主动，很积极，在左右着一切。实际上我们是在被左右，被操纵，被操作的一种状态。

蒋杰：企业的操作系统和企业的基因有什么样的关系？

# 吴伯凡

应该说这个关系非常的密切，在某种程度上说，这二者其实就是一体的。我看过一种关于公司DNA的理论，这种理论认为，公司的DNA取决于公司里头详细传递的方式，你是自下而上的还是自上而下的，是中央控制式的还是分布式的。

第二是你决策权在哪里，你的决策权的重心是偏下的还是偏上的，还是在中间的，决定了你的公司的DNA。

还有就是你的激励方式，你是在激励什么。任何一个公司的激励系统其实都是在悄悄地决定公司的走向，领导者的自己的一言一行在很多时候也是一种激励系统。领导者常常是在自己不自知的情况下发号施令。你觉得你没有表态，实际上别人其实已经清楚清楚地看到了你的态度了。

还有就是公司的组织结构，在信息传递方式，决策权和激励方式之外还有一种东西就叫做组织结构。这种组织结构比这前三种因素更能够决定公司的基因。

如果我们把决策权，信息传递方式，激励方式和组织结构这四个要素合到一起，大家马上就会意识到，这就是一个操作系统。所以在一个公司里头，你的操作系统决定了你现在的状况，更决定了你未来的命运。但企业的领导者常常是意识不到这一点的，常常觉得企业的命运，企业走势是取决于他怎么说的，他怎么想的，他怎么做的。而忘了操作系统是一个类似于黑箱的东西，你的每一个决策，你的每一次行为，你的每一句话都会输入到这个黑箱里头，最后的结果往往是你自己意识不到的。

何荣：现在的各种平台都具有女性特质，像淘宝、微信、微博等，特点是营造出一种生态。吴老师的日知录更偏重哪个特点呢？

# 吴伯凡

如果这样问的话，我首先要告诉我这个不太具有女性的特点。我希望是今后更多的具有女性的特点。

据说伟大的灵魂，伟大的组织，伟大的人都是雌雄同体的，既要有雌性的那种自强不息，积极主动，操之在我的那样一种特质，同时又要具有厚德载物，具有隐忍包容，能够自动地降低一个产品和一个公司的噪音和杂质的那样一种功能。

我们听说过一个词叫信噪比，我们发出一个信号，别人才是否能够接收到领悟到你的本意，那就取决于你的信号与噪音的比值。如果你信号很大，但你的噪音也很大的时候，别人往往是听不清楚的。如果你的信号不是那么强，但是你的噪音很低的时候，别人也可很好的接收到感受你所发出的信息。所以我们做通信，做沟通，最重要的工作就是如何增强自己的信号的清晰度，同时要具有一种降噪的能力。

在一个公司里头，太过于男性化的公司往往特别强调信号本身的强度，而不去做降噪的事情。一些具有明显的女性特质的领导者或者演讲者，他们常常只在乎如何说，而不在乎如何去降低自己说的时候可能随时在释放着各种的噪音。所以最好的状态是雌雄同体。
