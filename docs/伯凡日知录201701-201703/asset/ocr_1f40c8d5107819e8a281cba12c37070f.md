# 本周问答｜人工智能会玩弄权术吗？

本周问答｜人工智能会玩弄权术… ↓

苏魁漫：有个疑问，吴老师，您觉得将来的 인공지능会玩弄权术吗？

吴伯凡

这个问题提得很好，也许是因为我前面讲到了和珅、讲到了普京，可能同学就自然而然地找到了权术，那么我们就来说说什么叫权术？这个权术跟智能有什么样的关系？

中国古代有一个很著名的故事叫二桃杀三士，说的是齐国的国相晏婴如何用两个桃子杀了三个大力士，但听起来有点荒唐。有一天鲁国的老大鲁昭公来访问齐国，他带了一个随从叫ss孙姪，而齐景公接待他，国相晏婴作陪，旁边坐着三个人。这三个人号称齐国三杰，其实是三个著名的将军，他们共同的特点就是力气大，非常的勇猛，但是智商不高，情商更低。
