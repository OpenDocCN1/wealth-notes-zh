# 本周预告｜聊一聊“柔性的专断”

![](bbox=[0.07, 0.17, 0.12, 0.2])

本週的《伯凡·日知录》将围绕“柔性的专断”来展开。

领导者本来就是与其他人不一般见识的人，但他又必须与其他人达成共识。领导者之所以是领导者，就在于他比常人站得高，看得远，同时，他能走在别人的前头。但领导者常常遭遇这样的困境：即使你真切地洞见到先机，但你也很难让别人相信你的洞见，因为远见在很多时候常常与常识相悖，甚至在常人眼里显得极其荒谬，这个时候，作为要带领众人向前走的领导者，你就很难与众人达成共识，众人的行为与你的布置常常是貌合神离，你也就很难成为一个卓有成效的领导者。领导者的职责是做正确的事，是发动变革，管理者的职责是正确地做事，即按部就班、循规蹈矩地做事，但发动变革谈何容易。在你和别人没有达成共识的时候，你不仅不能改变别人，而且很可能触发强烈的反弹和骚乱。在古代印度有一个王子得了妄想症，突然有一天坚定认为自己是一只鸡，国王遍寻名医也没能把他治好，后来出现一位大夫，出奇制胜地治好了王子的病。他是怎么做到的呢？

孔子说：“民可使由之，不可使知之”。难道民众、员工、下属就只能被迫服从吗？当他们不能像你一样拥有远见卓识的情况下如何让他们不知不觉认同你的决策，甚至让他们觉得那是那是他们做出而你勉强认可的决策？什么叫“丐词魔术”？为什么我们常常被这样的魔术所欺骗而不自知？

本周的伯凡日知录详细解读了北魏孝文帝迁都的故事中。什么叫“自由选择的错觉”？什么叫温和的专制主义？什么叫柔性的强硬？如何以周密、隐秘地方式让反对者不自觉地成为你的同谋？在这个故事里我们能生动地感悟到这一切。

欢迎收听本周的伯凡日知录。

另外，本周五，也就是除夕夜了，按照我们日常的更新，这一天要跟大家互动问答。但我想这一天大家都跟家人团聚，我也应该说一些跟年节氛围应景一些的东西。所以，除夕这一天，将作为《伯凡·日知录》春节的特辑的开头，给大家从一个“除”字讲起，聊聊中国文化。

周六，也就是大年初一，《伯凡·日知录》将请来一名神秘嘉宾，具体是谁？会说什么内容？

请大家收听本周的《伯凡·日知录》
