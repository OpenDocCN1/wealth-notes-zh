# 孝文帝迁都

中国历史上还有一个伟大的变革者，北魏孝文帝，今天看来这个人做了一件事情，或者细分起来是两件事情。

第一，结束了五胡乱华，当时中国的大地上有一大半的土地都是被那些胡人在那折腾，烽火连天，老百姓民不聊生，他结束了这样一个战乱的局面，统一了中国的北方。

第二，他不仅不让这些胡人折腾，而且要让胡人归化汉文化，他自己是一个胡人，他却用汉文化来同化所有的胡人。

孝文帝改革有很多重大的举措，比如说鼓励鲜卑人和汉族人通婚，在政治上、经济上推出了一些重大的举措，其中一个非常关键的步骤就是迁都。

# 背景

北魏原来的首都唉平城（今天的大同），那个地方是胡人聚居的地方，这些人一直生活在这个地方，也有汉人居住，但是匈奴、鲜卑、羯、氐、羌，这些人是主流的，而洛阳是汉人聚居的地方，他觉得要真正地推行汉化，一定要把首都从平成迁到洛阳这个地方。

搬家对古人来说很难，因为古人大量的资产都是在土地上，搬家必定会让很多既得利益者非常的不满。最主要是在这些胡人看来，这是一种文化上的投降。这是明显地把主场作战变成了客场作战，很多人非常的抵触，可以说迁都是一件非常冒险的，弄不好有可能自己的皇位都要丢掉的这样一个大举动。

# 迁都的准备

+   1. 与这些反对派的带头大哥诚挚的交谈。
他对带头大哥说了一句我们听起来有点肉麻的话，本来这个人是反对你的，你先要道歉，然后说其实我们的立场本质上是一样的。“你之所以反对我就是为了这个国家好，你的忠心耿耿、你的足智多谋，你就是我的张子房，就是张良，我有了你就如同荆邦有了张良一样。”这种精神按摩是很有效力的。

+   2. 发动了一场事先大力声张，其实是一个表演性的战争，也就是对南朝的南征。
他调动30万大军，而且要御驾亲征。

+   3. 在发动南征之前，他在洛阳早就派人修好了宫殿、官舍、营房。

# 迁都的过程

南征是精心策划的，因为往南走就一定要走到洛阳。

他选的那个时间特别好，阴雨连绵，当30万大军在泥泞的路上苦不堪言，行走了多日，终于接近洛阳的时候，他好像做梦初醒似的，这就有点像那个情场高手们经常用的那种偶遇，好像怎么又一下子现在到了洛阳呢？那要不我们就休息一下吧，这些人当然心里三呼万岁，“太好了、太好了，实在是不能再走了。”

这些人一到洛阳就好像住进宾馆似的，至少是如家那一级的，大家觉得很舒服。这种对比非常的强烈，各方面的服务也很好，当官有自己专门住的地方，当兵的也觉得自己住的酒店其实是早就修建好的营房，很舒服。休息了几天，他说：“不能贻误战机，我们必须马上出发，要往南走。”这些人不管是当官的、当兵的，都还沉溺在洛阳的这种良好的服务体验当中的时候，你竟然要他们又要踏上泥泞的道路往南去，很多人就站出来反对在这。

> “不行陛下，作战最怕的是士气低落，最怕的是对方以逸待劳，我们这么老远走过去必败无疑，我们不能够走。”

孝文帝的反应是非常坚决的，“必须得走，不能够停留。”

这就越来越多的人苦劝，“不能走了，我们就坐在这个地方待一段时间。”

> 孝文帝：“要待好吧，你们不走这仗就别打了，你们就在这儿待着吧，这个地方不是挺好的吗？你们不是挺喜欢这个地方的吗？”

> 士兵：“好好好，只要不南征怎么都行。”

> 孝文帝：“那就好，既然要住下来，既然你们觉得这个地方好，你们就在这里住下来。房子都安排好了，从此以后我们也别再回平城了，这个地方就是我们新的首都。”

这就让我想到那个词，富有弹性的坚定，富有柔性的强硬，他让他的反对者做出一个决策，而这个决策是他事先早就想好的。有一句话叫“两害相害取其轻”，他要把两种害处摆在他们面前，让他们自由地选择，选择他为他们事先准备好的那个方案。

我们分析孝文帝迁都的特点：

+   1. 目标非常明确；

+   2. 隐藏自己的目标；

+   3. 要制造各种各样的情景，让你的反对者不知不觉地进入到你选择的这个流程当中。同时把两种方案、两种选择摆在他们面前，让他们不自知地选择为他们做好的那个选择，而且当他们做出这个选择的时候，你还要旗鲜明地反对他们的决断，直到他们苦苦哀求，心甘情愿地做出这样一个选择。

这让我想到林肯，林肯当年在跟南军打仗的时候，他手下的人都觉得他过于宽厚、过于仁慈，有时候甚至分不清敌友。林肯说了一句话，你们有你们消灭敌人的方式，我也有我消灭敌人的方式。孝文帝智慧的地方就在于他也知道怎么去消灭他的敌人，他不是以暴力的方式去消灭自己的对手和持不同意见的人，而是精心设计，营造一个场景，制定一个流程，让一个他本来已经成竹在胸的决定最后成为大家的共识。

我们刚开始讲到说领导者做事情，他不是make things，他不是做事情，而是make things happen，让事情发生，如果是发动变革的话，那就是make new things。

说到变革我们很容易把变革定义为make new thing，制造出一个新的事情。事实上一个真正有战略眼光，同时有战役手段的人是make new things happen，让新的事情生长出来。
