# 1 秘密

大家可能读过或者至少听说过有一本书叫《从0到1》，这本书里头有一个核心的论点，真正能够实现从0到1的创业的成功取决于你是否能够找到一个秘密。

所谓秘密就是在常识和幻想之间的一机会点。很多 natural 是依据常识创业的，这样的创业往往会无疾而终；还有一些人是受到幻想的蛊惑而去创业。但真正成功的创业它既不是基于常识，也不是基于幻想，而是基于在常识和幻想之间的一机会点，这个机会点就叫秘密。在那些依据常识来创业的人的眼里，秘密很像是一个不靠谱的异想天开的想法，而这恰恰是成功的创业的机会之所在。

在每周的第一天，我跟大家讲了几个故事，其中一个是在西方哲学史上最早的一个哲学家叫泰勒斯，他是如何抓住一个秘密，最后赚到大钱的。一般来说，抓住一个大家都没有看到的秘密，投下高的赌注，最后获得高的收益。我们通常把这种行为叫做投机。其实所谓投机就是找到秘密，同时在这个秘密上头投下高的赌注。

我还和大家讲到了著名的投资家索罗斯的投资理念，他的点“错”成金，他的反身性理论其实也是一种发现秘密，投下高赌注的投资方法。

索罗斯是如何发现这样一种投资理论的呢？

跟他的个人经历，甚至跟他的父亲的经历有什么关系呢？

# 2.外部性

我以前和大家讲过一个经济学的概念，外部性。所谓外部性就是一个经济主体，一个行为主体的行为对他人产生了影响。或者说是别人从中得到了好处，但没必要向这个行为主体支付成本。说的通俗一点就是一个人为社会，为他人做出了贡献，但是他人和社会没必要向他支付成本。我就以罗马这座旅游城市和《罗马假日》这部电影之间的关系，我就以罗马这座旅游城市和《罗马假日》这部电影为例子，分析一下什么叫外部性，为什么说外部性是一个暂时的概念。

# 3.善

本周我也讲到了一个听上去跟经济，跟商业很不相关的概念，那就是我们通常所说的善，从经济学上看，它到底意味着什么呢？

事实上善也可以理解为一种外部性。善就是一种对公众和他人有利的行为，但是行善者付出的成本并不尽如交易清单，也就是说它不是一个市场行为。善不过就是暂时没有转化为市场和交易行为的外部性。但是随着场景的变化，善随时有可能转换为内部性，或者说它能够为行善者超乎预期的回报。
