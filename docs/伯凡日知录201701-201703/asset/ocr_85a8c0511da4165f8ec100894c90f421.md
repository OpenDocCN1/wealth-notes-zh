在很多时候品牌的的确确是减少了我们的选择困难，减缓了甚至消除了我们的选择焦虑症，它让你不选择或者在不知道在选择当中已经做出了选择。

# 实验：可口可乐和百事可乐哪个更好喝？

有一个很著名的实验，就是把一组人召集在一起，让他们喝可乐，喝两种可乐，具体哪一种是百事，哪一种是可口可乐不告诉他们。在大家都不知道是什么可乐的情况下，有50%的消费者认为百事可乐的口感更好。

如果事先告诉他们现在我们先喝可口可乐，再喝百事可乐，或者先喝百事后喝可口可乐，告诉他们以后有超过75%的消费者会认为可口可乐口感更好。

为什么会出现这么不可思议的现象呢？

原因就在于我们的感知能力里头已经被植入了某种快捷方式。当你一旦听到说这是可口可乐的时候，你的感觉会借助於一个无障碍通道自动的在进入到大脑当中的一个快乐区和舒适区。如果别人告诉你这是百事可乐，你的感受也照样会借助於另外一个快速通道进入到一种你不喜欢、你贬斥，你觉得陌生的那样一个区域里头。也就是说把它打入了另册。同样的感知可以借助不同的快捷方式或者说无障碍通道，进入到不同的区域里头，在认知的抽屉当中各就各位，各自进入自己所事先规定好的那个抽屉。

这种快捷方式对我们人来说有个什么好处呢？很简单，我们在感知的时候不归费劲地去感知，我们在感知的时候、我们在认知的时候会非常的省力，这个省力好处的代价就是我们的感知、我们的认知被歪曲，被一种先入之见所绑架。

所以在这个意义上说做品牌就是让消费者做出伪选择，好像是选择，其实不是选择，甚至是做出不利于他们自己，而只利于厂商的选择。如果是这样的话厂商是最愿意的了，那也是极好的。

# 例子：大众汽车广告

大众公司有个广告，结尾他总是要说一句 Das Auto，这不是大家开玩笑说的他要打死奥拓，Das Auto是德语，是一句德语。

电视广告结尾那句话是很重要的，他为什么要uchen一句大家都不大听得懂的德语来结尾呢？其实很简单，他就告诉你，我们是德国的汽车。只要你一听到这句德语的时候，你的感知会借助於一个我们头脑当中已经事先有的快捷方式或者说叫无障碍通道，进入到一个区域里头，进入到一个认知的格子里头、一个框架里头、一个抽屉里头，这个抽屉的内涵就是高品质值得信任。只要有这样一个认知就好办了，也就是说它已经在某种程度上完成了帮你做选择的大部分的事情，你会去选择，实际上你的选择是在它的那<|start|>软性强制下做出的选择。

我买第一辆车的时候就被一种观念所绑架，德国的车就是高品质的，就是值得信赖的，结果买了一辆大众的车小毛病不断，我问周围的同事、朋友，他们说确实有这样的问题。事实上这种感觉是一个事先被植入到我们头脑当中的一个观念病毒，我们被这个病毒所绑架了。但是我为什么就做了这样一个，为什么我做了这样一个选择呢？因为做这样一个选择最容易，我觉得最省事儿，这就是为什么我说我们很多时候做的选择是一个伪选择。

那么一个问题就自然出现了，我们都不傻，我们很多的消费者都不傻，为什么常常做出的所谓选择是伪选择呢？我们在自作聪明做选择的时候最后为什么常常是聪明反被聪明误呢？这的确是一个值得探究的问题，我们明天就来探讨这样一个问题。
