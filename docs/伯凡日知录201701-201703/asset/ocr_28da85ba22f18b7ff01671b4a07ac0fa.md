# —— 知识笔记 ——

上次提到了哈雷摩托，有90后的朋友就告诉我说，你这个例子还不是太恰当，真正说明问题的一种自行车，这自行车的名字叫死飞，英文名字叫Fixed Gear，是指那个档位给固定死了，这自行车在我们俗人看来，那就是一个次品，那就是一个典型的不合格产品，不能变速，不能刹车，你蹬了它就走，你不蹬它就不走，各种的不省心，不省力，简单的说，那就是一个不省油的灯。与其说那是交通工具，不如说是一种自虐的手段。

我们可以想象一下，一辆没有刹车的自行车下坡的时候，想想都害怕。但是这样的车拥有一批忠实的用户，真正的粉丝，发烧友。他们玩的就是心跳，要的就是酷，要的就是花，玩各种的花。他们骑车主要的目的就是要展现自己的各种花活，让人惊叹，让人发出各种的尖叫。

我们自然就要问了，这么一个看上去都不合格的产品，有设计缺陷的产品，怎么会有那么多的粉丝呢？听过我们周节目的人就明白了，世界上三类产品，分别对应人的心理状态的三个区域。大多数产品是冲着舒适区去的，让使用者感到舒适。还有一些产品，也就是那些不合格的，活该上315榜单的那样一些产品，它主要的功能就是让人来焦虑的。但是还有一种产品，它是要让人来学习的，它对应于我们的学习区。使用这类产品的人他们都会有一种油然而生的精英意识，他们看普通的用户就像《哈利波特》里头那些会玩巫术的人看着那些叫麻瓜的人们。据说吃瓜群众是来自于麻瓜，我不知道对不对，就是在这些年爱酸、爱花的用户眼里头，你你就是一群吃瓜群众，就是一群麻瓜。套用木心的名言就是，他们使用这个产品的时候，他们会对那些使用很舒服，舒服到平庸的那些产品的人有一种这样的心态，“我悲哀的看着你们这群不知道悲哀的人们。”你说它的性价比不高，其实它的性价比很高，这类产品有一个很重要的性能，就是能够让用户产生强烈的优越感、精英感和使命感。套用宗教上的一个词，就叫他们会觉得他们是 chosen people，被挑选的人们。

说到这类产品，我就想到《小王子》里头有一个词叫“驯化”，我仔细地琢磨了一下这个词，其实应该翻译成“被驯化”。小王子一直心神不宁，就是因为他始终牵挂着他的那颗袖珍小行星上头的一朵玫瑰花。

那朵玫瑰花有点让人想起了林黛玉，她老爱发脾气，老爱挑剔，永远泪流满面，永远在挑剔。她给小王子提出一个无理要求，说你有屏风吗？他说你要屏风干嘛？现在起风了，一会儿你要没有屏风的话，我就会感冒。说着说着还咳嗽了几声。弄得小王子非常的烦躁，最后负气出走，遨访了各个小星球，最后来到了地球上。但是当他来到地球上的时候，他一直是心神不宁的，他牵挂着那朵伶心玫瑰，他始终在想会不会起风了，小行星上会不会有一只羊把这朵伶心玫瑰给吃了，他甚至是想象那朵玫瑰应该是一只小老虎，它的刺是老虎的爪子，如果有羊来吃它的时候，它用它的爪子来对付羊。总而言之吧，就是它的核心竞争力，那朵玫瑰的核心竞争力就是让你欢喜让你忧，让你牵挂，让你又气又恨，在你的心中牢牢的占据了一个小窝家的位。

我们听起来这越说越不像话，这不就是受虐狂吗？你为什么偏偏对那么一个老是在跟你发脾气，老是在挑剔你的人有一种择之不去的牵挂和依恋，这其实是人性的一个特点，你也可以说它是一个弱点。

我们经常会对人性发各种各样的议论，其实我们对人性知之甚少，人性有很多很多的面。比如我们经常说，人好逸恶劳，就是人性。懒惰是创新的动力，没有懒惰就没有层出不穷的发明和创新，许多许多的发明就是为了迎合人的懒惰，迎合人的好逸恶劳。

我们说好逸恶劳是人性，但是不能反过来说人性就是好逸恶劳。好劳恶逸是一种隐秘的，常常被我们忽略的人性。

我们时时能够在生活当中看到，否则你怎么能理解那些攀岩的人呢？经常我们去健身中心，总有一些人在搞所谓的锤子的舞蹈，在那儿做那种荒诞的运动，又没人给他钱，但是他们付出的劳动一点不亚于民工兄弟们，但是民工兄弟们还能挣钱，他是挣不了钱的。为什么他们还要花大价钱去购买这种吃苦受累的权利。我们喜欢游戏，其实也是我们的好劳恶逸的一个表现。

那么好劳恶逸到底是一种什么样的人性呢？其实很简单，还是要回到那三个区域，人类除了喜欢待在舒适区以外，还偶尔，有的人甚至是经常的要让自己处于学习区，特别爱学习的人常常是人性的好劳恶逸的那一面特别发达的人。

我请教学日语的朋友，说这个学习在日语里怎么说？答案让我很吃惊，但是我想又特别有道理。日语里头的学习是两个汉字，就是勉强，学习就是勉强，勉就是尽力而为，无保留的使用你的力量叫勉，所谓勤勉就是这个意思。强就是强迫，《简·爱》里，简·爱的老师跟小简·爱解释什么叫责任，就是你不愿意干，但是你必须要干的事情就叫责任，一个人没有责任，他就不是一个真正的人。我们也可以说，一个不习惯于勉强的人，他就是一个不合格的人。当然，用汉语说就很通顺了，一个不学习的人就是一个不合格的人，学习就是勉强，就是尽力而为，强迫自己去做感情上，感受上不接受，但是你觉得应该去做的那样的事情。人其实就是在勉强当中成长的。

日语还有一个词很有意思，我们汉语叫努力，日语叫一生悬命。一生悬命我就立即想到一个成语，叫命悬一线。你之所以要努力是因为命悬一线，当你从悬崖上掉落，被绷带挂在一棵树上的时候，这个时候你就要努力呀，因为一生悬命。
