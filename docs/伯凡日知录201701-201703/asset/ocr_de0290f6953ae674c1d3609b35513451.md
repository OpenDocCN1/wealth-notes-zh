# —— 知识笔记 ——

在三四十年前，在缅甸有个地方，有一片珍惜的树林，这树种是一种濒于灭绝的树种，非常的珍贵。生态学家们很吃惊地发现一个事实，就是这片树林正在老化，也就是说在这片树子里已经找不到新的树了。生长在这里的都是老树，如果任凭这一个趋势发展下去的话，有朝一日这片树就会全部枯死，也就意味着这个树种可能灭绝。

后来生态学家们找到了原因：这种树长的果子有一种种子特别爱吃，这种猴子长得很灵巧，外表很漂亮，在缅甸那个地方有人喜欢把这种猴子作为宠物来养。当地的人觉得有利可图，就抓这些猴子到市场上去卖。时间久了，这片树林里头猴子越来越少，直到最后都消失。猴子在吃下这些果子的时候，果子里头的种子是会随着猴子的粪便排到地上，这些种子有个特点，它必须借助 IB 于猴子的粪便才能够发芽，生长。当猴子没有的时候，这些果子只能掉到地上，掉到地上的果子是不能够自己发芽的。

原因找到之后，办法就很简单了，就是购买一些猴子，让这些猴子在这个树林里头生长发育。

从这个例子我们就看出，物种之间的关联很紧密，但是我们常常容易忽略它们之间的密切的关联。当一个环节消失的时候整个生态链条都有可能崩断。

一个生态系统其实是有多个玩家参与其中，其中有些玩家的角色非常的隐秘。但是，他们也是其中不可或缺的角色，不可或缺的因素。一旦没有他们，整个的游戏就可能结束。

# 平衡记分卡

平衡记分卡既是一种管理工具，也是一种管理的思维。

平衡记分卡里有一个重要的观念，就是当我们在管理企业的时候，如果仅仅是根据账面上的结果来对企业的资源进行分配，对企业的部门、员工进行激励和惩罚的时候，我们常常可能会意识不到，我们奖励一个东西的时候，其实有可能是 bromine 在奖励我们不该奖励的人和部门；我们在惩罚一个部门和一些员工的时候，我们可能是在惩罚本来我们应该去表扬，我们去奖励的人。

由于我们只是根据一些显而易见的指标和数字在采取行动，我们在管理企业的时候不自觉地在破坏自己的企业，而且不自知。经营管理健康的企业应该去平衡地看待各种的因素，从而平衡地全面地看着各种与经营和管理相关的因素。意识到它们之间的复杂性，去制定一个与这种复杂的隐秘的因果关系相适应的激励体系和管理体系。
