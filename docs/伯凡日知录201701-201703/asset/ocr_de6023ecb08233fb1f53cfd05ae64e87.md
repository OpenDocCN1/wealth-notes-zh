# 本周预告｜你有没有陷入时间管理的误区？

本周预告｜你有没有陷入时...

《伯凡·日知录》的朋友们，本周的伯凡日知录将会讲到四个关键词，能量管理、龙卷风暴、诺曼底、谎言。

# 1.能量管理

说到个人管理，我们常常会马上想到时间管理、效率管理，但是我们在想方设法抓紧时间提高效率的时候，有没有陷入到一种误区呢？真正值得管理的也许不是时间，不是效率，而是我们自己的能量。我们在一味地追求效率的同时，可能忽略了一个比效率更重要的东西，那就是效果。最没效率的事情就是以最高效率做一件没有效果或效果很差的事情。

# 2.龙卷风暴

我们谈龙卷风暴，可不是在谈论天气的问题，而是在谈一个产业的生态，一个产品，一家创业公司的命运的问题。所有的创业公司都可能面临着一种叫做龙卷风暴的产业洗牌的过程。有的企业会在一场龙卷风暴当中青云直上，而更多的企业会因为一场龙卷风暴而销声匿迹。

# 3.诺曼底

我们讲的不是地理，也不是军事史，而讲的是一个新产品如何才能够在正确的时间、正确的切入口进入市场。如果一个企业，一个产品找不到自己的诺曼底，它的命运就不是出众，而是出局。

# 4.谎言

我们通过案例的分析向大家展示一个弥天大谎是如何让人坚信不疑的，一个谎言是如何做到天衣无缝、浑然天成的。我们之所以关注谎言不是为了让大家学会撒谎，而是用一种新的视角让我们重新认识人工智能。

以上就是本周的《伯凡·日知录》的内容，欢迎大家收听。
