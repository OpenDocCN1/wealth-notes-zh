# —— 知识笔记 ——

我们昨天给大家留了两个问题——

+   1. 既然今天的计算机机器人已经如此强大，为什么它的智力只相当于一个4岁半的儿童，甚至根本比不上？
2. 为什么教育孩子是超级复杂的事情？

要回答这个问题，就要回到我们以前讲的一个话题——维度。

真正的竞争不是在某一个特定维度上的比拼，而是维度的多少。

真正的高人是具有高维度的人，而那些在某个方面具有明显特长的人，很可能是一个低维的人。那么二者之间的竞争是一种不对称的竞争，最后竞争的结果是不言而喻的。

# 例子：《三国演义》中马谡和诸葛亮的维度

马谡在某些方面他确实是一个高手，他熟读兵书，但是他对战争的认知是一个单维的或者说是一个低维的认知。当他面对真正的高手的时候，他就一败涂地，所以诸葛亮含着泪也要把他杀了。而诸葛亮在与司马懿的竞争当中，能够在他处于最弱小的状态下，还能胜算，原因就是他处于一个高维度，至少他不比司马懿的维度低。

我们前面讲到的那个来自山西的心算天才，我们应该客观地说他是一个低维度的天才。除了在心算方面他有绝招之外，在其他方面他几乎没有能力，甚至连自理的能力都没有。

# “白痴天才”

心理学上以前有一个说法叫做白痴天才，就是说某些天才他在某一个单一的方面，具有常人无法比拟的能力，但是他的所有的能力都集中在这个维度上，在其他的维度上，他的能力很低，甚至没有那个维度。

他在与正常人的竞争当中，他一定是处于劣势的。

# 人与机器的维度

人与机器的差别恰恰就在于低维和高维的差别。

我曾经跟一个研究人工智能的朋友交流，他说他们现在研制的机器人智力是4岁到4.5岁，我提了一个很外行，但是他难以回答的问题。

我说：“可不可以这样理解，明年这个时候它的智力就是5.5岁，再过十年以后它就是14.5岁？”

他说：“不能这样说，他说他完全不能保证机器人智力增长的速度跟人的智力的增长速度是同步的。”

我说：“不是有一个摩尔定律吗？摩尔定律说的是每隔18个月计算机的性能提高一倍，它的成本降低一半，如果按照这样一个速度增长的话，机器人的智力不就很快的超过人的智力了吗？人的智力不管是个体智力还是人类整体的智力，其增长的速度其实是很慢的。”

比如说我们现在的人跟唐朝的人相比，你很难说我们的智力比他们的智力高出多少，尽管已经过去了一千多年。

机器人的智力的增长速度是远超于人的。

2016年3月份，阿尔法狗把李世石打败，但是毕竟还给李世石留了一点颜面，李世石毕竟赢了一盘。

十个月以后，Master出场的时候，能够将人类所有的围棋高手格杀勿论。这十个月时间就发生了这么大的变化，如果按照这样一个增长速度的话，要不了几年机器人的智力就会远高于人之上。

当然这是明知故问，其实我知道，我们说的机器人的“智力”只是一个单维度的智力。

以前我们对智力的理解很片面，所以都用一个统一的标准来测量人的智力，我们把一个人的智商通过特定的检测方式来确定这个人的智商。

后来人类马上意识到，人类的智力是远远不能通过通常的智商测试方式来衡量。后来有人提出了情商的概念，再后来又提出了社交商的概念，甚至有人提出叫领导商，领导力的商素。各种各样的、五花八门的商，各种各样商的概念，表明人类意识到智商是一个多维度的问题，而不是单一维度的问题。

今天的计算机在某种意义上说它也掌握了一种语言。有一次我在一个会议上作演讲，我亲眼目睹了今天语音识别的技术，我在演讲的时候发现我的每一句话、每一个字，瞬间就变成了字幕，其错误率的确是很少。这就是说计算机已经听得懂人的语言了，甚至它已经听得懂我这种普通话很不标准人的语言，这说明它的智商的确不低，但是语言绝不仅仅是语音。你在语音识别上，我说了一句话你知道我说是哪几个字，这并不表明你就听懂了我的话。一个4岁的男孩儿，他不只是掌握了一门语言。
