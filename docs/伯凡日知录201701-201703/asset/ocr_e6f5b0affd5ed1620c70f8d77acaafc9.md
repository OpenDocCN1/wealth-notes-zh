# 2.28 | 有钱人也会 “舍不得”

# —— 知识笔记 ——

前几天一个朋友他问我一件事，他陪一个朋友去香港旅游，他这个朋友很有意思，他到那里去专门采购各种奢侈品，买的表都是十几万的，但是他们在买东西的时候口渴了，到处都有卖水的，水十多块钱一瓶，这个时候他说：“我们回到宾馆，宾馆有免费的水。”他就强忍着，同时要身边的这个朋友也忍着，陪他一起，让他在对水的极度的渴望当中买完了所有的东西，购物体验非常不好。

他就问我：“这个人出手十几万的表他不觉得贵，十几块钱的水他觉得贵，这到底是什么原因呢？”

他这么一问，当然我觉得我自己和我身边的人都有这个毛病。

有一次我一个朋友特别得意地给我展示他新买的直升机——“海军一号”，总统远途飞行坐的是“空军一号”，短途的都坐十几个人这种大型直升机，很安全，体验也很好，这种直升机叫“海军一号”。而且他买的这个版本是一个改良版，后面的螺旋桨不是横着在转，而是竖着在转，而且在螺旋桨的周围有一道边框保护。

他就讲这个螺旋桨如何好，如何能够保证直升机在突然上升的时候避免螺旋桨碰到别的东西，而导致整个螺旋桨的损坏，以致于机毁人亡。他赞美了一通自己的这个直升机以后，随口一句：“不过稍微有点贵，比别的版本贵4000多万。”

我当时就倒抽一口凉气，不是值4000多万，是贵4000多万。我就想起，我们是特别好的朋友，我发现他在日常生活里头是一个非常节俭的人。他还津津乐道地跟我讲，他在停车场有一次愉快的经历，就是又一次他眼看着那个时间快到了，他一个箭步冲上自己的车启动，然后赶到那个收费口，恰好差一分钟，少交了10块钱，他觉得特别爽。买飞机出4000万不嫌贵的一个人，他在停车场里头为了这10块钱他付出那么大的努力，我就觉得有点不可思议。

后来回想起来我自己也常常是这样，在国外的时候我也遇到过口特别渴的时候，想买瓶饮料一看都是5欧元，我觉得贵得没有道理，也是跟那个朋友一样，强忍着去喝宾馆里头免费的水，甚至喝那个自来水，因为他们的自来水也是可以喝的。但我在国内买一些我熟悉的商品的时候，比如说买烟，烟也很贵的，但我就 bu 嫌贵。

我之所以不愿意出这个钱，表现得像个吝啬鬼，不是因为我口袋里没钱，我那个钱包鼓鼓的，但是我不愿意掏那个钱。用古人的话说这叫“富贵而贫贱心”，我虽然不富贵，但是口袋里有那么多钱，搞得像一个瘪三一样，我觉得自己也挺没出息的。

# 例子：浪费粮食 vs 减肥健身

我们都是从饥饿年代过来的，所以一直到现在对浪费粮食这件事情是有一种强烈的恐惧感的。

我觉得我们这一代人的肥胖有各种各样的原因，懒惰、不爱运动、生活不规律、常年出差，这都是原因。其中还有一个原因，就是那个年代加在我们内心的匮乏感、稀缺感和恐惧感，使得我们不愿意去浪费粮食。吃饭的时候最后发现锅里头还剩那么一点，绝对没有勇气把这个饭扔掉。马上再把它盛到碗里头，一看放在锅里不显眼，放到碗里就是整整一大碗了。
