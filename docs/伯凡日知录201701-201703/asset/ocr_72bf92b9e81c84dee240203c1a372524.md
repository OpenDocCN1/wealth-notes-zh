# 两种策略在产品上的运用

K策略和R策略是生态学上的概念，也是社会生态学上的概念，也是一个产品策略的概念。

例子：索尼

索尼有2200多个产品，我用过索尼的磁带、电池、耳机。你能够几乎能想象的跟消费电子有关的所有的这些产品索尼都会生产。但现在的索尼，你也不知道它到底是哪一款产品有特色，可以说是除了极少数还能让你觉得这是代表索尼曾经的那样一个品牌的形象以外，大量的是非常的模糊。中国有很多这样的公司，也是产品超过2000多种的大公司，但是每一样子产品都没有特点。

例子：苹果

苹果公司整个的产品SKU很少，说白了其实就一个，到现在为止，说多了那也没几个，四五个。

iPad，就是把它那屏幕弄大一点的一个iPhone。

什么叫itouch，不过就是把通信模块抽掉的一个iPhone。就变来变去，它本质上是一个东西，所以它的产品策略是典型的K策略。

Cosmo磊
k策略和r策略，这样让我联想到了个人生存。我们每个人想要成为一名优秀的人才，最起码做到在一领域中做足够优秀。而现在讲究的综合素质培养，我个人认为其实是相对广义的理解。在狭义的范围内去理解综合素质这一说法，应该是首先实现单点突破，然后再去逐步多维度竞争，才比较合理的。如果作为一个人，你样样通，却样样松，那么无非从广义的理解你就是一个普通人，一瓶不滿，半瓶子晃荡罢了，最终你的发展空间也不会太大。而如果是从单点突破，然后再去多维发展，那么你最强优势可以弥补你的很多的不足，再通过多维度完善，最终的结果就是强者恒强。不是一句话这么说的嘛：“不怕富二代有钱，就怕富二代既有钱，有才，还有志。”所以我个人认为，从个人发展方面看：单点突破是很有必要的，单点突破，是建立自信的良药，而自信可是你在社会生存中更成为坚毅，而坚毅之后的行动得到的反馈就更为丰富。
