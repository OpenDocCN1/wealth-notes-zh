# 1.K策略和R策略

有一句听起来政治上有点不太正确的俗话，“龙生一子定乾坤，猪生一窝共墙根”。说的是好的东西不需要太多，差的东西太多了也没用。这一句可能我们已经很熟悉的俗话里头包含着生态学上的一对概念，那就是K策略和R策略。

K策略：王者策略，像狮子这样的动物产子不多，但是个体很强大。

R策略：比如说昆虫和某些哺乳类动物，它们不强调优生优育，它们不是以质取胜，而是以量取胜。比如说蚊子，比如说蟑螂，它们生存的环境其实是很险恶的，人手一拍就可能拍死几个蚊子，但是无关紧要，因为即使它们死掉了80%，还有20%存在，这20%是一个很大的量。

通俗的说，就是K策略是头部策略，而R策略是长尾策略。我们在产品世界里头也能看到这两策略，苹果公司是典型的K策略的公司，像索尼公司采取的是R策略。今天的小米到底是K策略呢，是R策略？好像逐渐的从K策略转向了R策略。这两者之间到底谁优谁劣，我们在创业的过程当中到底要采取什么样的产品策略，听完这一期大家可能会有所领悟。

# 2.归因

有一句话叫“雄鸡一唱天下白”，这里头就是包含着一个典型的逻辑上的错误。大公鸡一叫，接下来天就亮了，所以大公鸡常常会认为天是它叫亮的。这是一种典型的归因偏差，或者叫归因谬误。但是大家不要以为只有大公鸡会犯这种错误，我们人可能天天在犯这样的错误。

我们无论是总结成功还是总结失败的时候，常常会把一个由大量的显性的、隐性的原因所导致的一个结果归结为某一个原因，这个原因就是从一个大的原因包里头随便拣出来一个原因，得出一个简单的因果推理。其结果不仅仅是认知的谬误，而且在行动上会导致巨大的风险。

# 3.不确定性

我们身处在一个充满着不确定性的时代，很多看上去板上钉钉的事突然之间就变得不那么靠谱了。我们很多人都不喜欢不确定性，我们希望是说好的事情就要兑现，我们就是处在这么一个一切说好的，最终常常是不靠谱的这么一个时代。

但是，不确定性就真的是那么负面吗？面对不确定性，我们该采取一种什么样的态度呢？如果我们换一个角度来看不确定性，我们会发现不确定性恰好也是一种资源，如果一切都是确定的，我们人生当中最重要的问题值不值得活下去也成了一个问题。

在很多时候，正是因为有了不确定性，我们才会全力以赴的去从事一件事情。所以正确的态度很可能是拥抱不确定性，亲近不确定性，在不确定性当中获益。

# 4.产品和服务

讲到体验，每个企业都在强调用户体验，其实用户体验包含着两种很不相同的体验。一种是服务体验，一种是产品体验。

产品和服务的本质区别到底何在呢？简单的说法是，生产过程和消费过程同时发生的叫服务，生产过程和消费过程分离的叫产品。

我们在提升用户体验的时候，如何针对产品和服务的不同来最大限度的提高用户体验呢？这期节目就和大家探讨这个问题。
