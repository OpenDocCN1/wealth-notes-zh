# —— 知识笔记 ——

昨天我们说了，我们在好多时候自以为是做出的选择其实是伪选择。无论是在选购商品还是在选购一只股票的时候，我们都是按照商家和大玩家们预设的套路程序做出他们早已经预料和安排好的选择，而我们常常会认为这是自己的选择。

我们还以为我们的选择是凭着我们自己的头脑，凭着我们的自由意志做出来的选择。这种自以为是，这种自由意志让人想起一句老话，就是被人卖了还帮着别人数钱。

我们为什么这么容易中招，而且中招以后还那么的浑然不觉呢？原因可以用一句话来概括——我们早已经不知不觉地被驯化了。

![](bbox=[0.28, 0.88, 0.72, 1.0])

在我们的生活世界里头，有很多以各种各样的面目出现的驯兽师在不断地驯化我们。

我们看马戏的时候就知道，那些驯兽师多么可害，他能够把老虎、狮子、大象这些令人生畏的动物驯化的那么乖。大象用一条腿就能支撑起它那么沉重的身体，我们看马戏的时候都能感觉到大象好像有一种洋洋自得的那种状态。但是我们心里头很清楚，大象其实是极可怜的。在漫长的被驯化的过程当中，驯兽师按照特定的套路、特定的程序，一点一点地把大象驯化为一个特殊的演员。无论是大象还是老虎，它们在完成一个动作以后都会得到一个奖赏，它们在得到这种奖赏的时候，它一定会觉得它是在为自己劳动、为自己工作，它们凭借它们的劳作、凭借它们的工作，它就得到了它应该得到的奖赏。

![](bbox=[0.3, 0.00152, 0.7, 0.0016799999999999999])

驯兽、驯兽师这样的字眼听起来的确有点难听，我们会说哪有啊？我们的社会里头哪有什么驯兽师啊？我们是人又不是兽，有谁来驯化我们呢？

我想起一个词不是那么难听，甚至听起来有点高大上，这个词就是牧师。

牧师，就是像牧者、像牧羊人一样的老师，我们普通的人就是那一群听话的羊，随大流的羊，他在指挥我们，他在饲养我们。面对牧师我们只能是高山仰止，恭敬都来不及。

大学的时候我读列宁的《国家与革命》，那里头有一句话，我印象很深。他说国家是阶级压迫的工具，国家只有两个功能，一个是劊子手的功能——暴力，另一个是牧师的功能。两者都很重要，一个国家如果缺了牧师，这个国家就是没办法运行的。中国的秦朝、隋朝之所以那么短命，一个很重要的原因，他们是只有劊子手，没有牧师。所以很快的就被既有劊子手又有牧师的汉朝和唐朝所替代了。

牧师这种角色当然已经是明日黄花了，在现代社会宗教早已经衰落，但是像牧师、社会驯化师这样的角色，他们改头换面化整为零，这个阶层好像不不存在了，实际上他们已经遍布在各个领域里头。

传统的那种布道行为，那种显而易见的仪式，已经悄悄地渗透在我们的生活当中。当你在看电视、你在上网，甚至你在听音乐的时候，你都是在接受某种布道。很多的观念就是随风潜入夜，润物细无声，已经悄悄地植入在我们的头脑当中。

久而久之，我们的头脑当中就潜伏了大量的隐秘的说服者、隐秘的控制者。我们不假思索作出的选择的背后，是我们过去的生活经历，我们在有意识和无意识状态下接受的种种的观念，在一瞬间爆发，在一瞬间连接起来，就形成一个冲动、形成一个意向，我们的大脑快速地扫描我们过去的记忆、我们过去的情感情绪，把它压缩成一个快捷方式。

这个快捷方式在几秒，甚至零点几秒的时间内就变成了一个决策，变成了一个冲动。这种冲动就会让我们把某件商品放进了我们的购物袋和购物车里头。

# 例子：科罗娜啤酒上的柠檬

比如说你上酒吧或者上一个酒店的大堂里头去喝一杯科罗娜的啤酒，你会发现瓶口插着一个卷曲的柠檬片。你倒这杯啤酒的时候，你会觉得喝这个啤酒跟你平时喝的啤酒是不一样的，那个小小的柠檬片可以说是点睛之笔，能够让你的这个体验一下子上升到一个层次，让你觉得这一瓶啤酒真值。你在喝这一杯从柠檬片上缓缓地流淌出来的啤酒的时候，你可能真的觉得这啤酒里头隐隐约约有一种柠檬的味道，这种味道渗和在啤酒里头味道好极了。

今天我们喝科罗娜啤酒的时候，好像这成了一个必不可少的一部分，已经成了一个习惯。这个习惯是由一个调酒师想到一个主意，他觉得用这种方式会让喝啤酒的人有一种巨大的体验附加值。就是凭一片小小的柠檬片一下子就把科罗娜和所有其他的啤酒区别开来了。你在喝科罗娜啤酒的时候，你甚至还会感受到这一杯包含着一点点柠檬汁的啤酒跟别的啤酒不一样，其实完全不是那么回事。它给你营造的是这样一种场景，这样一种类似于仪式化的东西，让你感觉到很不一样，事实上上并没有什么不一样。

# 例子：健力士啤酒

我们被告知道在喝健力士啤酒的时候，当你在倒酒的时候，你要等着啤酒泡沫慢慢的消失，只有等这些泡沫安静地破灭以后，这个健力士的啤酒真正的味道才能够出来，这实际上是一个骗局。

厂家在做健力士啤酒的时候，为了追求一种味道，它的酗制过程跟普通的啤酒不太一样，但是这样一种酗制工艺有一个意想不到的副作用，那就是这个啤酒的泡沫很多，而且消失的比较慢。
