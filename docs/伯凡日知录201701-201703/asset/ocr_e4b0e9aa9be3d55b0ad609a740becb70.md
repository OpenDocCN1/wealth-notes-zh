# 3.9 | 一个晴天过海的谎言

# —— ◇ 知识笔记 ◇ ——

我们在讲智能的时候说，“智能”和“情报”在英文里是同一个词。

智能技术和信息技术有一个非常明显的差别是，智能是在众多的显性信息当中发现、挖掘、提炼出隐性的关键的信息，这个隐性、关键能够作为决策依据的信息就叫做情报。

所以我们一般说情报人员就是刺探隐秘信息的人，但这只是情报人员的其中一个功能，间谍还有一个重要的工作，不是发现隐秘的真相，而是制造弥天大谎。不管是刺探情报还是制造假象，其实都是一个功能，消除你跟对手的认知落差。

刺探情报是因为他知道的东西我不知道，我们首先要消除这种信息不对称，制造假象是反过来制造认知的落差，那就是说你不仅要知道对方不知道的东西，你还要让对方不知道你知道。最重要也是最难的，是不仅要制造对方不知道的东西，而且尽可能地让对方的认知偏离这个真相。

图灵作为计算机之父、人工智能之父，他的真实身份是一个情报人员。他整天要做的事情就是要破译德军的密码。当时图灵最痛苦的事情是当他知道了德军的情报之后，他发现这些来之不易的情报最后并没有发挥作用。因为英国人明明知道了德军要怎么干。比如说德国人要去炸毁某个地方，但是英军根本不做任何防范，不做任何反击。为什么要这样呢？是因为他就是要让德军不知道英军已经知道了他们的情报。当然，英国人在跟德军交战的过程中还要做一件事情，就是制造假象、制造谎言，而制造谎言、制造假象的代价，有时候要远比获知真相的代价要大。

# 故事概况

在英国间谍史上有个双重间谍，至今还是一个谜，从一般的材料来看这个人就是一个叛徒，他被纳粹抓了以后就招了，然后就为德军服务，他向德军提供了很多英国的情报，而且害死了很多英国的谍报人员。他在投靠德军之后不断地向英国军方发出请求，要求派情报人员过来，派过来以后这些情报人员就被德军抓获，前前后后他一共叫来了英国的17个情报人员，最后都惨死在德军之手。

德国人为什么要抓那么多的英国间谍呢？因为他们要获取一个非常重要的情报——盟军会在什么地点登陆？

如果盟军进攻欧洲大陆，有两个最可能的登陆点，一个在加莱，一个在诺曼底。如果比登陆的条件，加莱是更好的登陆点。一方面加莱离英国本土的距离比较短，第二，从军事学的角度看，加莱更容易被攻下。而相比之下诺曼底是易守难攻。尤其是诺曼底的海滩很宽，这个对于登陆是很不好的，因为那是一个开阔地带，盟军登陆以后要穿过这片海滩的时候是极易受到攻击的，所以登陆加莱的可能性更大。但是双方都知道，打仗就是要出奇制胜，很多的军事决策之所以有效，是因为它是反常识的。

德军收集到了很多关于盟军要在加莱登陆的情报，但是他们不敢确定，所以他们要尽可能地抓还更多的英国情报人员，撬开他们的嘴。这17个英国间谍来一个抓一个，有男性也有女性。他们都会遭受严刑拷打，最后到生命的垂危之际终于投降，告诉他们真实的情报。每一个人最后在经历了严刑拷打之后都说登陆地点是加莱，说完以后这些人都死了。由于这17个人说的都是在加莱登陆，所以德军最后确信盟军要在加莱登陆，但最后的结果我们都知道，盟军是在诺曼底登陆的。所以后来有人分析，这个投靠德军的间谍很可能是假叛变，而这17个惨死在德国人手里头的情报人员也是奉命惨死在德军手里，他们做的无非就是一件事，将一个假情报以德国人相信是真的方式给到德国人。
