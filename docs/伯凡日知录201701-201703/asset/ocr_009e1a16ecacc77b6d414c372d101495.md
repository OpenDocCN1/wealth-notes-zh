# 索罗斯

其实，在哲学史上能赚到钱的哲学家也并不是太多，泰勒斯作为西方哲学史上的第一个哲学家，他不仅获得了很高的认知成就，同时也赚到了钱。我仔细想了想，我们当代有没有这样的哲学家也像泰勒斯一样既仰望星空又脚踏实地，而且还赚了大把的银子呢？想来想去我发现有一个人大概是这样的，这个人的名字说出来大家一定知道，他叫索罗斯。

在我们商务印书馆里头出过一套书《索罗斯文集》，很多财富青年们要是看到这套书的时候一定会觉得奇怪，这个索罗斯是那个索罗斯吗？我要告诉大家的就是就是那个索罗斯，就是那个赚了很多钱的，一个人发动了一场对全世界的战争，在1997年掀动了亚洲金融风暴。如果大家粗略的翻一翻那套《索罗斯文集》的话就会发现，这个人怎么都写了一堆哲学书啊？其实他本身就是学哲学的，而且一辈子矢志不渝的想当一个哲学家。可是正经的哲学界又不太承认他那套理论，觉得那个东西不太入流。人常常是这样，对自己擅长的事情往往不在乎，对自己不擅长的事情他往往耿耿于怀。

乔丹同志打完篮球之后，他觉得会打篮球太简单了，太不酷了，他要去打棒球。

托尔斯泰一直想写特别好的短篇小说，本来他是擅长写长篇小说，他说写长篇小说太简单了，真是短篇小说不好写。

契河夫是只会写短篇小说，不会写长篇小说，一直想写一部长篇小说。

这就叫矛盾嗜好欲，就是一个人总是对自己擅长的事情不在意，对自己不擅长的东西特别在意，索罗斯就是这么一个人。每隔一段时间他就会搞一个发布会，他不是搞产品发布会，他是主要是像罗胖一样搞知识发布会，要搞思想发布会。他发布的其实就是他自己认为很得意的思想，他的这个思想概括起来就叫反身性理论。关于反身性理论我就不细说，以后我们讲思想史跟大家详谈。

我这里头只是跟大家交代一下他为什么会提出这样的理论，以及他为什么倔着这个正统哲学界根本不认可的思想武器就能赚到很多的钱呢？

索罗斯有个基本的判断，就是一个任何完备的系统里头，一定有一个大家不知道的漏洞。如果大家有兴趣，可以看一部索尼公司拍的电影，叫《没有一个系统是完备的》，这听起来特别不像电影，但这个电影我看评级还很高。在互联网时代，这其实是一个很重要的思想，没有一个系统是完备的，看似完备的系统里头都有一个只有极少数人能发现的漏洞。如果你一旦发现这个漏洞，抓住这个漏洞，就可能搞事情，搞大事。

为什么索罗斯会产生这样的一个看法呢？其实每一个人的思想都跟他自身的经历和他周围的人的经历有关。

索罗斯的父亲参加过一战，由于他在匈牙利当时是处在，是跟俄国是对着来的。他在打仗的时候被俘虏了，我们知道俄国人都有个习惯，喜欢把俘虏的人都关到一个叫西伯利亚的地方，让他们在那里自力更生、艰苦奋斗，然后自生自灭。可是索罗斯的父亲是一个不安分的人，他在那个地方他搞各种事情，搞小事情，搞大事情。比如说他在监狱里头出黑板报，要搞自媒体，搞黑板报。总而言之就是那种天生有领导力的人，喜欢当带头大哥的人。有天他突然意识到如果在这儿长期待下去的话，都可能死掉，这就是陈胜吴广的逻辑，等死和找死之间我选择找死，找死有可能活下来。所以他就带领一帮兄弟们秘密的扎了一个木排，他们就凭着这个木排沿着一条河流就逃到外面的世界。他们很顺利的就沿着这条河流往下漂，也不想想为什么会那么顺利，为什么那些监狱的人在河流上为什么不设岗。他们也没想过，反正觉得自己是个幸运儿。

![](bbox=[0.25, 0.0026, 0.85, 0.00312])

漂着漂着，后来他们突然发现怎么越来越冷啊，而且渐渐河上都有冰了。索罗斯的父亲突然意识到，原来西伯利亚的河流不是往东流的，都是往北流的，都是要流到北冰洋的，那是一个死亡地带，这才搞明白对河流的管理为什么那么松懈。这时候只有一个选择，砍掉木排走回来，回到原点，打回原形。幸运的是，当他们回到那个地方的时候，一战已经结束了，原来留在这个地方的那些俘虏兵早就回国了，他们折腾了那么久，还是留在这个荒凉的地方。那后来经过各种的跋踬辗转，也回到了国内。

这件事情对索罗斯影响很大，就是说一个人如果不知道他所处的环境和所处的系统，你任何努力不仅可能是白费的，而且可能是适得其反的。那么反过来，任何一个系统看似很完备的，但是如果你找到了一个真正的漏洞，那么你就可能别开生面，别有洞天，发现自己的桃花源。这可以说是索罗斯思想的一个起源。

我们刚才讲到了泰勒斯和索罗斯，他们有一些共同点。

+   1. 他们都是仰望星空又脚踏实地，既要赚认知，又要赚银子。

+   2. 他们都能够发现别人不能发现的一个漏洞，或者说是一个秘密。倚着对这个秘密的发现，他们可能以很小的努力获得很大的收获。

这种方法经济学家，搞金融的人们他喜欢用一个词叫杠杆，杠杆不就是找到一个支点以后，以很小的力能撬动一个很大的物体嘛。那就是说，你要找到一个支点，这个支点其实就是一个错误，或者说是一个系统漏洞，这是一个错误，这是一个宝贵的错误，是一个只有你发现了的错误，然后你就把点“错”成金，获得巨大的收益，这就是索罗斯和泰勒斯的他们思想和行为的共同点。

今天就跟大家说了两斯，这两斯大家听完以后还是不是觉得哲学可能还真有点用处。我不做那种承诺，听了我的节目你就能踏上财务自由之路，偶尔真正让你获得大收益的往往是“闲篇”。我们以后就会和大家一起扯闲篇，赚大钱。
