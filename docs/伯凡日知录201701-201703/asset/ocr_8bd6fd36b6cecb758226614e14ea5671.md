# 本周预告 | 聊一聊 “操作系统”

![](bbox=[0.05, 0.16, 0.12, 0.18])

本周预告 | 聊一聊 “操作系统…”

在本周的《伯凡·日知录》里头，大家会听到不少的故事。

我讲到了渔夫和金鱼的故事，讲到了一个老修道院长的故事，讲到了凡尔纳的神秘岛的故事，也讲到了阿里巴巴和华为的故事。显然我不是为了给大家讲故事，而是想讲这些故事里头都包含的一个共同的主题。这个主题听起来有点突兀，我把它称为操作系统。

操作系统本来是一个技术的名词，它指的是我们在用一部手机，用一台电脑的时候，我们用的都是应用软件。但是我们没有意识到的是，我们还在使用另外一种东西，那就是操作系统。

操作系统是如此之重要，它是在后台调用、协调、处理各种的计算资源，没有操作系统，应用软件无法运行，但是它又是我们常常忽略的。我真正想说的是，对于一个公司，对于一个家庭，对于所有的组织来说，操作系统非常重要，但同时又是非常容易忽略的一个要素。如果说应用软件是风景的话，那么操作系统就是营造这种风景，维持这种风景的气候。

初创的企业，往往会特别关注自己的商业模式，盈利模式，战略路径。但常常忽略了比这些更重要的是一个在公司的底层悄悄运行的那个操作系统。

作为一个领导者，你除了制定战略，确立商业模式，监控公司的运营流程之外，一定要悄悄地为自己的公司写好底层代码。换句话说，你除了去寻找那些能够在市场上敢打敢拼，勇往直前的那些经营者和管 理者之外，你还要找到能够为你的公司写底层代码，构筑操作系统，并且不断地优化你的操作系统的那样的贵人。就像马云，马云的幸运就在于，他在公司成立之初就遇到了能够帮助他为阿里巴巴构造操作系统的蔡崇信，甚至可以说的绝对和武断一点，如果一个公司没有构建起一套稳定而高效的操作系统的话，再好的应用软件也没办法有效地运行，甚至会直接导致公司系统的崩溃。

本周的《伯凡·日知录》结合《道德经》中的某些观点，对建立公司的操作系统的重要性，以及如何建立公司的操作系统做了一些探讨。
