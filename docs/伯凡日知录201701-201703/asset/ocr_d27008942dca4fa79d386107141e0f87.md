# —— 知识笔记 ——

我们今天要解读的关键词是惰怠，这个词也可以说成急惰，急慢的怠，惰性的惰。
这是任正非在新年反思的时候提到的一個词，说华为要保持警醒，华为正有可能变得急惰。那是什么意思呢？华为的干劲很大，在一个大家都说生意不好做的时候，年增长率达到百分之三十四，这个结果一定是大家干出来的，他怎么会讲华为要提防急惰这种状态。

# Inertia

惯性，物理学名词，一个物体在运动的过程中当中具有一种惯性，即使火车要进站的时候，发动机关了，但是它还是能够到站，因为火车在运动的过程当中已经形成了一种惯性，那种惯性能够继续推着它往前走。

惰性，惰性在我们看来就是不动，不爱动，懒惰的人就是不爱动地方，哪儿舒服哪儿待着，好吃不如饺子，舒服不如躺着。

这两个词一个是跟动态有关，一个是跟静态有关。这两个词为什么在英文当中是一个词呢？其实仔细想来，惰性和惯性还真是有相通的地方。

英文词典里头对 inertia，对惰性有一个解释，很有意思。指的是不想改变生活和工作习惯的倾向。

你不想改变就是惰性。哪怕你还是在动，但是你不想改变，这意味着惰性已经悄悄地控制着你。当我我说一个公司在飞速发展的时候，我们首先想到的是它的惯性，它借助这种惯性还能够继续往前走。

# 惰性的两面性

比如说像索尼，在我们看来它的发动机可能都已经停了，但还是在继续往前走，可以说它的品牌是有惯性的，它拥有的资源赋予它某种惯性，能够在一个已经缺乏动力的情况下让企业继续往前走，这就是企业的惯性。在这个意义上说惯性应该是好的。

从另一面看，当一个企业被惯性所驱使的时候，它的状态就是没有动力了，没有自我改变的欲望和能力了，这个时候它就已经陷入到惰性当中了。

Inertia 这个词是一种很好的提醒，不管是人还是公司，当你高速发展的时候，就意味着你的惰性已经产生了，你感受到的是惯性，你没有感受到的就是惰性。

# 例子：蛇头的常识

蛇头，就是领着别人偷渡的人。因为偷渡的人是不能走直路的，他们要不停地绕着走，他走的永远是弯路，是蛇形的，也就说是偷渡的队伍是蛇形的，所以走在前面的那个人叫蛇头。

据说有经验的蛇头都有一个常识，当整个进程特别顺利的时候，他就会感到一种巨大的恐惧，他会想一想能不能再找一条路，为什么呢？因为过分的顺就可能意味着一个巨大的陷阱，只有那些菜鸟级的蛇头，他会乘胜前进，最后顺利地进入到警察已经设好的大口袋里头。

爱尔兰作家王尔德是一个挺会抖机灵的人，有一次他演讲的时候说了一段话，下面就响起了雷鸣般的掌声。他就反问一句：”我刚才到底说错了什么？为什么下面掌声雷动？“ 这个人真会抖机灵，他又赢得了一次掌声。

> 我们借用他这句话，赠送给企业家：”我到底干错了什么，为什么下面是一片欢呼声。”

一说到这个我们马上就想到一个词——居安思危，或者还想到一个概念叫舒适区。我们曾经讲过谷歌在把公司的名称改成阿尔法贝塔的时候，发布过一个公告，那个公告里有一个很难听的说法。他说我们之所以这样做，是因为我们近年来的业务发展得过于顺利，我们担心我们会陷入到一种叫做 Fxxking Comfort 当中，其实很多的 Comfort 都可以在前面加那么一个词。管理学的说法就是你的核心能力过于强大以后，会导致一种核心能力的硬化和核化，也就是说让你的能力失去弹性，你只能沿着这样一个路径往前走。最后的结果很可能是，一旦有变你完全没有更改的机会。

有经验的领导者都会把特别顺利的状态视为一种不祥之兆。

君子终日乾乾，夕惕若厉，无咎。

君子应该整天是小心翼翼的，心里头充满着忧患的，即使一天的事情千完了，到了晚上还要保持着一种警醒，仿佛遇到了厉鬼，特别又恶的鬼，只有在那样一种状态才会无咎。

咎上面是个处，下面是个口，那个口代表陷阱，处就是待在陷阱里。只有君子终日乾乾，夕惕若厉，你才可能不掉到那个陷阱里，换句话说当你很舒服的时候，你已经处于一种 Fxxking Comfort。

# 例子：柯达的黄昏

2001年，柯达公司迎来了他们公司业绩最好的一年，公司上下无不欢欣鼓舞。不仅仅是因为这个业绩达到了历史最高水平，而且这个好消息能够驱散他们心中的焦虑，“人人都说数码相机时代要来了，你们看看我们今年的业绩有多少”。

在柯达公司上下一片欢腾的时候，大家忘了问一个其实很简单的问题，为什么今年我们的业绩会那么好？真实的情况是，这个行业已经不行了，这个行业已经没落下去了，所以其他的公司就纷纷撤离了。退出去的这个公司就会把他们原有的市场份额自动地让出来，留下来的公司可以独占风光，这时候整个市场都属于你的，那业绩不好吗？夕阳无限好，只是近黄昏。

# 做企业的扒道工

管理哲学家查尔斯·汉迪有一个说法，就是每一个公司的领导者都应该在你公司的办公室画一道抛物线。你要天天想一想你的公司到底处于抛物线的哪个地方，是在抛物线的左边还是在抛物线的右边。

![](bbox=[0.15, 0.0067800000000000004, 0.85, 0.008230000000000001])

当你特别顺的时候，你应该提醒自己，我已经离右边半条线非常近了，这个时候你要干一件什么事儿？培育一条新的抛物线，要不然你就会行驶在一条没有扒道工的铁路上。

一个领导者应该学会做扒道工，在你所在的这个抛物线上，你要决定在哪个点上建立一个岔道，而且要敏锐地察受到你的公司可能正在接近岔口。安迪·格鲁夫把这个点叫 Turning point ，不是说你现在的公司突然要转型。

![](bbox=[0.15, 0.009130000000000001, 0.85, 0.01028])

前两年我们听到了很多人ెల讲企业转型、传统企业转型，我认为那都�鬼话，至今为止我没有看到哪个传统企业转型成功的。

查尔斯·汉迪告诉我们，要建立岔道而不是所谓转型。企业的领导者要成为一个建立岔道的人，并且要守护那个岔道，做一个扒道工。
