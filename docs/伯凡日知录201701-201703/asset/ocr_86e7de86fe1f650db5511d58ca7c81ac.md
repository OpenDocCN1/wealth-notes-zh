在从北京到法兰克福的飞机上，9个多小时，我跟隔壁薛兆丰老师聊了很多，不知道怎么我们就谈到了经济学上的内部性和外部性的概念。记性好的朋友一定记得我以前谈到过内部性和外部性。

# 内部性和外部性

薛老师是这个领域的专家，那是最权威的，所以我就请教他到底什么叫外部性和内部性，这是经济学里头充满争议的一对概念。

薛老师的观点是，不存在着什么真正的外部性，所有的外部性不过是因为收费的成本已经高于得来的收益。就好像说一个十万人的税收队伍去收5万人的税，这是得不偿失的，或者根本就没有可能。

# 例子：机场的美女

他举了一个例子，这个例子是很有场景性的，一般大男人在一块儿等行李，如果行李不来时，你知道我们主要看什么呢？那肯定是看等行李的人当中有没有美女。恰好有一个美女就站在我们的对面，薛老师说，这就是一个外部性。这个美女长得很漂亮，实际上我们在场的人都是有收益的，但是这个收益是不进入一个收费清单的，她没办法跟我们收钱。你看我一眼，10块钱，看我两眼，打个折15块钱。她已经被我们无数的人看了无数眼，但是她一分钱没有收到。这无非就是因为她没有这个收费的途径。

![](bbox=[0.08, 0.42, 0.92, 0.55])

# 例子：地铁口的设立

在经济生活当中有很多的外部性的例子，比如说一条地铁修成了，地铁在哪个地方开口，那个地方就会大获收益。但是以前修地铁的时候，没有考虑过这个外部性，现在就是修地铁的机构会把这样一个权利卖给周围的厂商，这样他们就获得了额外的收益。

实际上修地铁的机构是不会付出额外的成本的，因为你总要修地铁，你总要修地铁口。但是由于他知道了这个自身行为带来的外部性，他找到了收费的途径，他就变成了内部性。

# 养蜂人和果农谁该收钱？

经济学上有一个著名的争论，果农该向养蜂人收费？还是养蜂人该向果农收费？

果农说：我不让你在 chỗ地方放蜜蜂，你的蜜蜂就采不到蜜，所以你应该给我钱。

养蜂人说：假如我的蜜蜂不在你这些花上采蜜，那么你的花就没办法授粉，那你开出来的花就是空花，就叫华而不实。最后春天的时候，桃花灿烂，秋天的时候，颗粒无收，那你应该给我钱。

这里头果农和养蜂人他们的行为当中都存在着外部性。当这两个外部性有对接的时候，或者他能够形成专属通道，就像高速公路上有收费口的时候，他就能够收费了。

因为在很多的合作当中，你很难说是哪一方的贡献更大，比如说生一个孩子，你构成一个家庭，你生孩子，这到底是男人的贡献大还是女人的贡献大，好像又陷入到养蜂人和果农之间的那个争论了。薛教授说，其实你发现没有，还是有礼金的，都是男方给女方的。家庭是共同的，既是你家，又是我的家，但是为什么男方要给女方礼金呢？也就是说明女方的成本进入了这个交易清单。

# 例子：不一样的罗马

正好那天我们在罗马，我就一下子觉得，我以前到过罗马，但这次看到的罗马，因为跟薛教授在一起，我看到的完全是另一个罗马，我发现那个街上有很多很多的女游客。这不是因为我好色，我发现了，我想的是一个外部性的问题。

罗马对于男性，而且是中老年男性它是有吸引力的，因为那个地方历史悠久，叫永恒之城。这个城市里头有很多2000多年前的历史遗迹，我们站在古罗马斗兽场那个地方的时候，前不见古人，后不见来者，念天地之悠悠等等等等，你可以得到这样一种体验。

但是罗马怎么有那么多的女游客？而且是那么年轻光鲜，她们到这里来干什么呢？我仔细地想，也想不明白。后来突然有人提醒我，明白了，中老年男人看到的罗马和年轻女性看到的罗马其实是两个罗马。我们看到的是古罗马，她们看到的是一个特殊的罗马，她们的罗马是因为一部电影，《罗马假日》，那个永恒的爱情经典，那个永恒的女神赫本和永恒的男神格利高里·派克。
