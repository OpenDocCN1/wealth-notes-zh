最近我碰到了好多想在人工智能方面有所作为的创业者，有做伴随小孩机器人的，有做扫地机器人的，各种各样的机器人，以我的接触频率来看，人工智能创业的确是已经形成了一个所谓的风口。

风口这个名称不是太好听，其实风口这个说法，我自己老觉得是我最先说的，可是因为我微微言轻，大家都不知道，我说了好多年，原话：“台风来了，猪都在天上飞。”可是普遍的规律一直是名人才能说名言。有一个姓雷的名 人重复了这句话，这就成了一句名言，大家都却在谈关于猪、风之类的问题。

风口、台风、龙卷风等等，其实是跟一个概念有关，提出这个概念的人叫杰弗里·摩尔，他是真正的硅谷教父。KK（凯文·凯利）在硅谷是毫无影响的，我们一直说KK是硅谷的教父，所以美国人很奇怪，说我们一个并不知名的人到中国为什么那么火。

杰弗里·摩尔他提出了一系列关于高科技产业的理论，其中最重要一个概念就是龙卷风暴。

# 什么叫龙卷风暴？

这跟一个故事有关，一些同学可能读过一本美国的童话书叫《绿野仙踪》，也有人把它译成叫《OZ国历险记》。好莱坞曾经把这个故事拍成电影。

![](bbox=[0.25, 0.00175, 0.75, 0.00225])

一个小女儿住在一个屋子里头，突然有一天龙卷风暴来了，她住的屋子是一个木头的屋子，龙卷风暴来势汹汹，地面上好多东西都给卷走了，美国人其实非常怕龙卷风暴。

前些年布什当政的时候卡特里娜飓风造成了很大的灾难，导致很大范围民众的抗议。龙卷风暴的特点就是能够扫荡地面上的所有东西，但是它还有一个附带的效果，就是如果这个东西是处于龙卷风的中心，它获得了一个纯天然的空气发动机。

飞机之所以能飞起来就是借助于空气动力学的原理，沉重的机身能够被顶到天上去了，而这个小姑娘住的木房子正好处于龙卷风暴的中心，所以她免费地坐了一次豪华的飞机。当龙卷风暴消失的时候，她软着陆，来到了一个童话世界。

# 龙卷风暴跟行业的关系

一个新兴行业起来的时候一定会有很多企业投身其中，导致一个早期的大繁荣，这其实是一个非常幼稚、非常脆弱，注定会结束的，造成很大浪费的一个大繁荣。紧接着这种繁荣之后就会出现一场龙卷风暴，把现有的绝大多数的创业企业全部摧毁，但是有某一两个小企业会借助龙卷风暴给抬到天上去，然后被安全地输送到一个童话仙境的世界，一个想什么有什么的世界。

# 例子：微软的崛起

微软从一个蚂蚁公司变成大象公司，用的时间其实是很短的，原因其实很大程度上不在于比尔·盖茨有多努力，而在于他很幸运地处于龙卷风暴的中心。

当时有很多的企业在开发各种操作系统，而比尔·盖茨，他其实自己也不会开发操作系统，但是他有一个别人没有的关系，这个关系他一直不讲。他的妈妈是IBM的董事，所以我们看微软成功故事的时候略去了这一段，我们觉得微软好了不起，很励志，那么小的公司一下子变大了。但是大家不知道这样一个细节，当时IBM在开发一款操作系统，花去了几亿美金，但是运行起来非常糟糕，很“重”，跑不来。因为当时计算机的硬件水平不那么高，所以这样一个庞大的操作系统一旦放在电脑里头的时候，它就会消耗大量的计算资源，使得计算机的运行效率很低。一个好的操作系统应该能够完全的运行，同时它消耗的计算资源 Jep 可能的少。当时比尔·盖茨成立了一个软件公司，听说IBM正在为自己开发的操作系统在头疼，准备引进新的操作系统，比尔·盖茨知道这个消息以后就花5万美金买了一个叫DOS的操作系统，然后把这个DOS操作系统做了一些改造，在前面还加了两个字母叫MS，就是微软的操作系统。然后他把这个MSDOS卖给IBM，IBM是当时电脑业的巨头，也就是说他一下子就搭载了IBM这艘大船，这个操作系统一下子就变成了几乎所有人都在用的一个操作系统。

这个其实就是一场龙卷风暴，对于许多做操作系统和应用软件的小创业公司来说无疑是一场大灾难，而微软处于龙卷风暴的中心，它一下子从一个蚂蚁公司变成了大象公司。

其实在任何一个行业，甚至在政治、经济领域，我们都能见到龙卷风暴的现象。

# 例子：诸子百家

我们经常说诸子百家，百家是哪百家？我们现在最有文化的人，先秦时代的那些大IP，能说出几个来呢？无非是管、老、孔、庄、墨、孟、苟，管子、老子、孔子、庄子、墨子、孟子和苟子。

再有文化一点，你可能会说出十二家来，法家、道家、墨家、儒家、阴阳家、名家、杂家、纵横家、兵家、医家等等，再往多大家可能不知道了，原因是那些“家”们太小了。

特别有文化的人可能说出189家，再有的那些纯粹的老学究可能罗列出来1000家。

所以我们说的百家其实只知道七家。为什么会是这样呢？那就是在先秦时代周朝的官学作为一种权威的理论开始分崩离析，民间那些搞内容创业的人一下子就涌现出来了，涌出了1000多家，但是在这个过程当中逐渐会合并同类项，最后形成了七家，我们甚至是只记得三家，儒家、道家，还有一个法家。
