下面我来简单介绍一下欣赏这首曲子的几个基本概念：

第一，节奏，整曲《波莱罗》都是3/4拍子，从头到尾连速度都没有变化，小鼓敲击的波莱罗节奏型也一直不停：X XXX X XXX X X| X XXX X XXX XXX XXX|X XXX X XXX X X| X XXX X XXX XXX XXX|；

第二，主题与应答的旋律从开始到结束都没有发展，也没有变奏，尽管这首曲子的主题前后反复了九次，在音乐织体上一直在变化，乍一听起来以为是一首变奏曲，其实不是，因为主题没有发生变化；

第三，全曲一直保持顺耳的C大调，直到最后两个小节才突然转成E大调；

第四，在曲子的前半部分一直没有陪衬主旋律的旋律性和声，乐器从独奏到齐奏，其他的陪衬乐器只是在刻画节奏的重音。直到曲子的后半段，偶尔会出现若有若无的平行和弦，虽然很容易被忽略，却是越品越有滋味；

第五，音乐的力度也是从头到尾基本没有变化，只是到了中间木管与长号的主题与应答的时候，出现了一处“...
” ，但如果不仔细去辨认也不太容易察觉。

总而言之，拉威尔在这首曲子当中尽显他的“管弦乐魔法师”的功力，据说，拉威尔在总谱中其实暗藏了更多的玄机，研究这首曲子可以在谱子中发现更多妙处，所以法裔美籍指挥大师洛林·马泽尔一直认为轻易不做指挥的拉威尔之所以只乐意指挥这首曲子，是因为他的作曲方法就像儿童在做游戏。

毫无疑问，这是一首富于魔力的音乐，如果你对这首曲子陌生，但又肯注意集中地聆听，你就会被这首曲子的节奏所控制。如果你比较熟悉这首曲子，那么通过这一次我们带着“迭代”的预期来欣赏，你可能会突然发现音乐当中实在是妙趣横生，色彩变化极其丰富，从而对这个看似单调实则如原子裂变一般的乐思大加赞赏，从此便深深地爱上这首曲子，进而爱上拉威尔。拉威尔在那么短的时间里创作出这么天才的作品，特别像是和听众开了一个玩笑，首演现场，一位女士受了刺激，高喊：“疯子！这个音乐的作曲家一定是疯子！”结束后，拉威尔激动地说：“只有这位女士才真正理解了我的音乐，只有她一个人啊！”下面我们就来欣赏由刚才提到的指挥大师洛林·马泽尔指挥法国国家乐团演奏的《波莱罗》。

# 给大家的新年礼物

欣赏完《波莱罗》之后，我想再送给《伯凡·日知录》的读者一个新年礼物，同样是拉威尔的作品，它原本是钢琴曲集《镜子》中的一首，拉威尔单独把它改编成了管弦乐队版。这首曲子叫《小丑的晨歌》。

“晨歌”一词就来自西班牙中世纪游吟骑士吟唱的一种诗体，里面有对话和歌唱。为什么叫晨歌呢？因为骑士会经常深夜去幽会情人，一般他们都会带一位挚友替他在外面守候抵风，这位挚友通过唱歌提醒与情人难舍难分的骑士，天已经亮了，危险在逼近，要他抓紧离开，而骑士当然不愿意离去，所以才有了清晨两位男人的对唱。好奇怪，不是男女对唱，而是两个男人大清早在对歌。这是中世纪骑士文学和骑士歌曲一个很显著的特征。这种诗歌体，全称叫“阿尔博拉达”，简称“阿尔巴”。

那么“小丑”呢？就是我们通常理解的那种为宫廷和达官贵人插科打诨、提供开心果的“丑角”，文雅一点的称谓是“弄臣”，不过这要在有一定规模的宫廷里才可以这么翻译。当然欧洲的公共文化里，“小丑”也是必不可少的，大街上卖艺的小丑形象最多，遇到狂欢节或其他节日，小丑遍地。在马戏文化里，小丑的分量也是相当重的。

拉威尔的音乐以自由的节奏音型奠定全曲的基调，一开始是弦乐器的随意拨奏，竖琴的一连串音符引出由双簧管、英国管、单簧管等木管奏出的旋律动机，然后突然响起乐队齐奏，而且伴有西班牙舞蹈特有的响板声，犹如小丑摇摇晃晃、步履蹒跚、醉态可掬的形象。接下来是对称性的中段，音乐突然安静下来，独奏大管吹出忧伤的曲调，这个既可以理解为对着镜子化妆的小丑感叹自己的强颜欢笑人生，抒发内在的悲哀，也可以联想到“晨歌”的本来意境，那位在寒风中为朋友守望的挚友想象着自己的爱情徒劳无获。逐渐加入的乐队伴奏声音越来越新奇，一定要注意听这些细节，它们会带给你更丰富的联想，也会使你惊讶作曲家对管弦乐器的娴熟驾驭和音响调色板上的高超技法，可以说这个中段部分是全曲最具魅力地方。随着弦乐弹拨和打击乐的加入，木管和加弱音器的大小号以及独奏小提琴将音乐连接到第三段，并迅速掀起音响洪流，以变幻莫测的情绪将音乐结束，请注意在结束之前仍不忘小丑很滑稽地做了一个鬼脸或者一个嘲弄的动作，由长号的一声滑奏体现出来。

好，感谢你们的节日陪伴，再次祝各位新春快乐！下面请我们一起来欣赏非常醒神，非常欢腾，也非常有趣的《小丑的晨歌》，在音乐中感受节日的气氛。
