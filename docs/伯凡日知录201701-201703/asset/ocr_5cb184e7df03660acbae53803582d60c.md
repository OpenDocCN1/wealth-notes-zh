姜志龙：伯凡老师，保持中庸，时刻观察自身，和佛教所说的保持出离心是不是类似，区别在哪里？

佛日吃肉：吴先生说儒家的中庸，好像道家也有这方面的描述。道是独立而不改，周行而不殆。中庸就是德吗？

# 吴伯凡

这两个问题都很有深度。

国学大师牟钧锡有一个说法是，道家是佛家在中国的思想代理人，或者说为佛教打前战的，佛教之所以能够在中国生根，与中国本身就有的道家的思想有很大的关系。简单地说道家和佛家本身就有相通的东西。庄子的那句话，至人用心若镜，应而不藏，特别像佛教的东西。

在中国哲学史领域有一个大家基本认可的观点是，中庸跟道家是最具有相通性的，所以中国最后是儒释道一体，尤其到《宋明理学》，到《王阳明心学》的时候，都分不清楚他的思想有哪些到底是属于佛家的东西，哪些是属于道家的，哪些是属于儒家的，或者说王阳明的思想是以儒家思想作为正中、作为底色，但是他里面包含了大量的佛家和道家的思想。

中庸跟佛家的出离心是不是类似？的确的确就是类似的。

“允执厥中”就是要在动荡当中始终恪守一个不变的状态，这本身跟出离心是有关系的。用佛教的观点来说就是一种不粘附的心态，我们讲过荷叶、荷花，它就是具有那种不粘附的状态，出污泥而不染。水也没办法把荷叶打湿，就是因为它有一种不染、不粘附的特性。如果我们的心能够做到这样，你可以说那就是保持中庸，也可以说是保持了出离心。

亚一：如何能把控好灰度、中庸、妥协？怎样才是既讲道德又讲灰度的高度艺术？怎样才能有意识的锻炼对中间地带的运用？

# 吴伯凡

这个问题让我首先想到一个词叫做道德爵士乐。熟悉爵士乐的同学知道，爵士乐里头是包含大量即兴演奏成分的，在丹麦每年7月份都有一个国际爵士音乐节，我听了一次爵士音乐才知道什么叫即兴。也就是说他们三个，钢琴手、贝斯手和鼓手，他们之间有一种紧密的默契，某一个音符、某一个节奏一旦出现就到了即兴演奏的时刻了，听众听久了以后都知道这个时候就要开始即兴演奏了。这个即兴演奏尤其是那个鼓手，那种自由挥洒的状态，他可以在差不多5分钟内就在那即兴演奏，但是当他突然把某一个鼓一敲，那个声音一旦出现的时候，他们马上又进入到非即兴状态。所以有人就把在遵守原则的时候保持灵活性就叫做道德爵士乐。

要了解什么是道德爵士乐，我觉得最通俗的读物就是王跃文写的那个《大清相国》，那里头的陈廷敬就是一个典型的掌握了道德爵士乐的人。这个人在中国政治史上创造了一个官场奇迹，他是康熙的老师，大家知道在中国古代辅佐少主都没有什么好下场。吕不韦没有好下场，张居正没有好下场，但是陈廷敬作为康熙的老师，他从21岁进入政坛到72岁的时候老死相位，51年的时间没跌过什么跟头，而跟他同朝共事的明珠、索额图一大批纷纷阵亡，但是他始终是屹立不倒。有人说那他是不是个好臣？不是，其实做好臣也 малы не能够保证你屹立不倒，有些好臣死得也很惨。

陈廷敬是一个能够在原则性和灵活性上处理得非常有艺术的，可以说达到了炉火纯青的地步，他在原则的坚守和即兴发挥之间可以说是做到了完美无缺的程度。在个人的成就上他是著名的书法家，大家可以去在网上看一看他的书法，那真是一绝。有一个字典叫《康熙字典》，那个总编纂就是陈廷敬，同时他在康熙朝发起了一场金融改革，效果非常好，不像王安石那种变革最终是半途而废。

所以如果大家要了解灰度，要了解道德爵士乐，可以去读一读那本其实很好看的小说——《大清相国》。

# 吴伯凡

要区别和折腾和不急惰有一个标准，在管理学上叫MBO，目标管理，Management by objective。管理是由什么东西来管理？是由管理者来管理吗？不是的，是目标来管理。而管理者做的事情不过是面对一个目标，你要分清步骤，你要区别哪些事情是创造价值的，哪些事情是不创造价值的，或者说是跟目标无关的。如果你不始终是把目标作为管理的前提，那么管理者就会陷入到一种很自由散漫的状态，他会做很多事情，但是这些事情当中很多是跟目标没有关系的。

我对管理有一个特别简单的定义，就是去掉一切不创造价值的环节，尽可能地增加与目标相关的价值环节，这就叫管理。如果用这样一个标准来区别不急惰和折腾，这就很清楚了。
