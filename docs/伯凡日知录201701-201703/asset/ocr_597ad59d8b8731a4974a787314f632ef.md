# 本周预告｜幽默的本质到底是什么？

本周预告｜幽默的本质到底是...

本周的《伯凡·日知录》是围绕四个关键词来展开。

+   1.驯化

读过《小王子》的同学们一定会对这个概念有印象，爱闹小脾气的、爱挑剔、爱抱怨的那朵伤心玫瑰，是因为在养那朵花的时候，悄悄地被那朵花所驯化了，它其实就是一种让我们从舒适区进入学习区的一种状态。

人有好逸恶劳的天性，但人心当中还隐藏着另外一种天性，就是好劳恶逸，我们为什么喜欢玩哈雷摩托，玩死飞自行车？是因为我们在使用这些产品的时候，它们在悄悄地驯化我们、提升我们，让我们在不断地勉强当中，受苦受累当中，获得一种在舒适区里永远得不到的快感。

+   2.知识产品

朋友可以分成四种类型，高雅而有趣、高雅而无趣、庸俗而无趣、庸俗而有趣，其实我们今天接触的知识产品也差不多可以分成这四种类型。我们要真正地让自己进入学习状态，而不是表面上像在学习，其实是在娱乐的那种状态，那么就要认清眼前的这个知识产品，到底是属于哪一种类型。爱因斯坦说，游手好闲地学习并不比学习游手好闲好，那么如何选择真正对我们有益，真正能给我们提供营养的知识产品呢？

+   3.恢宏大度

本周还讲到了《道德经》里头一句话，叫“圣人执左契而不责”，也就是说一个受人尊敬的，具有感召力的领导者，他应该常常制造一种利益的落差，也就是说他的给予、贡献、付出，常常多于他的获取，让众人感受到某种歉意，然后在这种歉意当中去追随这样的人。这样的人亚里士多德叫做恢宏大度的人，他也是一种贵族精神。那么什么叫恢宏大度的人？如何才能够成为一种有感召力、有魅力，让大家一路追随的人呢？

+   4.幽默

幽默的本质到底是什么？一个组织如果缺少了幽默的氛围，将会出现什么样的麻烦甚至灾难？大家都知道扑克牌里头最大的牌，不是国王，不是王后，而是小丑，也就是弄臣，这里头包含着什么样的管理学和政治学的道理呢？
