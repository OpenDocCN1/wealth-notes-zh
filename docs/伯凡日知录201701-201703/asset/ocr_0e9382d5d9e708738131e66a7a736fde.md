# —— 知识笔记 ——

前几天看了一篇文章，说如果你每天的睡觉时间超过4小时，你的成功几率就减少了一半。看到这样的文章的时候特别自卑，自己从来也没养成每天只睡4小时的习惯。虽然现在是越来越少，但一算下来还是很罪恶的一睡5、6个小时。仔细地看了这篇文章，我觉得这里头的观点是有问题的，而且很有代表性。我们现在在提到个人管理的时候，常常是把个人管理等同于时间管理和效率管理，但时间管理并不等于是个个人管理。

那么个人管理真正要管的是什么呢？很早以前《哈佛商业评论》就有一篇文章，叫《管理能量，而不是管理时间》。比如说睡觉这个事情，你是要给自己规定多长时间的睡眠时间呢？你还是你要让自己的能量、精力、状态达到一种什么样的状态？

有的人会被那各种各样效率手册、手账所绑架，每天把自己的日程安排得满满的，但他很可能就忘了管理的目的是什么。管理的目的就只有一个，完成你的目标，完成你的任务，而且要尽可能优质的完成你的任务。但时间管理项可能能够让你避免时间的浪费，但是并不能够保证你的能量处于最好的状态。

# 动物的能量管理

![](bbox=[0.1, 0.0014, 0.95, 0.00185])

# 熊

熊的所有的生存行为不过就是一个能量管理，它首先是杂食，吃各种各样的食物，以充分地保证能量的供给。与此同时，它要尽可能的节省能量，所以它有冬眠的习惯。

![](bbox=[0.1, 0.00235, 0.95, 0.0027])

# 鲨鱼

鲨鱼这种动物应该说是一个奇迹，它的体量是非常大的，而同时它又是处于食物链的顶端，它是食肉的，它不会去吃海草。那么大的体量，同时又有那么大的能量消耗，它的历史已经超过了4亿年，它是地球上最古老的动物之一。

鲨鱼的行为里头有一个很重要的原则，就是尽可能的节省能量。

比如说它在攻击大体量的动物的时候，它一般不会Bind打，它往往是采取袭击的方式，咬掉猎物的某一块肉，导致大量的流血，然后让这个猎物在流血当中慢慢的死去。而且猎物流血还有一个好处，就是能够保证鲨鱼不费力地跟踪这个猎物，因为鲨鱼是通过水里的血来辨别猎物的方向的，它会以一个很慢的速度慢慢的跟着你，或者它就待在一个地方，让你在海里头流血，最后当那个猎物刚烈死的时候，它就饱餐一顿。

![](bbox=[0.35, 0.00405, 0.65, 0.00435])

# 鹰

老鹰在抓小鸡这样没有什么反抗能力的猎物的时候，它就是一招致命。

有时候它会抓一些体量比较大，而且有反抗能力的这样的动物。比如说它抓羊或者抓那种甚至是小鹿这样的动物的时候，它是在高空慢慢地盘旋，这个盘旋是一种滑翔状态，是不消耗任何能量的。它借助于热蒸汽的循环在上头慢慢的在搜寻、扫描底下的猎物，然后当它发现猎物的时候，几乎是以自由落体的速度下来，这样一方面能够保证速度越来越快，另一方面它不消耗任何能量。一直要在地面差不了多5米的时候，再展开翅膀，然后抓住猎物。它抓像羊、鹿这样的动物的时候，它把利爪扎到猎物的身体里头，然后飞起来差不多50米的时候松开它的爪子，然后这个猎物就摔下来，马上摔死，这样它再把这个猎物抓走。

为什么要这么干呢？这是因为这个猎物总会反抗，总会折腾，这个时候就会消耗鹰的能量，所以它用这种方式保证了它的能量的最低消耗。

以前我们在讲“知几”这个概念的时候，引用于《易经》里头一句话，“君子见几而作，不俟终日”，君子真正看到了苗头、趋势，看到了那个最佳的时间点以后才会行动，他不会去整天忙叨叨。

讲到这个概念的时候，我们还讲到了《菜根谭》里一句活，“虎行似病，鹰立如睡”。为什么老虎走起路来要懒洋洋的，为什么鹰它趴着的时候它是闭着眼睛的，目的无非就是一个，最大限度的节省能量。这两个自然界里头最猛的禽，最猛的兽，它们不是整天忙叨叨的，它只是在正确的时间做正确的事。

# 效率和效果

我们在做个人管理的时候，常常是在时间上做文章，而不是在能量上做文章，在这一点上我们甚至不如动物。或者说在这个意义上说，动物是很懂得个体管理的。管理首先是去掉一切不创造价值的环节。有时候我们在追求效率的时候，常常忘记另外一个比效率更重要的概念，就是效果。

德鲁克第一次区别了效率和效果这两个概念。因为很多的管理都是以效率为导向，而不是以效果为导向。Efficiency和effective这两个概念是很不一样的，德鲁克有一句话说的非常简单明了，他说世界上最没有效率的事情就是以最高效率做没有效果的事情。我们在做个人管理的时候，一定要以效果作为目标，与此同时要管理能量，而不是时间。

# 例子：与未婚妻三次擦肩而过

德鲁克为什么看到了效率和效果的区别是因为一个很小的个人经历，是他在电梯里头遇见了分别四年的未婚妻，他们在一个扶手电梯里头，扶手电梯是非常效率的工具，一个在往上，一个在往下，他们因为他俩相遇非常激动，所以他一下电梯就赶紧上了向上的电梯来追他的未婚妻，而他的未婚妻也一上那个电梯马上就换了那个向下的电梯，也来追德鲁克，结果他们又一次的擦肩而过。但是由于沉浸在那种相逢的欢乐里头，他们又一次的重复了前面的动作，结果他们在电梯上三次擦肩而过，还没有拥抱在一起。后来德鲁克终于明白了，要拥抱在一起，他必须下了电梯以后停下来，这就是效率和效果的差别。

我们好多时候做时间管理的时候能不能问一下自己，我现在 Circulating是不是在让自己尽可能在扶手电梯里头多走几圈，在一个高效率的实际上低效果或无效的状态里头呢？
