# 2.真理之口

大家一定会记得那样一个场景，格利高里·派克把手伸到一个看上去像一个大磨盘的东西上，它有一个奇怪的面孔，张着嘴，把这手伸进去，据说是你要撒谎了，它一口就把你的谎骸给咬掉，那样一个情节给太多的女士留下了印象。

我当时在观改变那个队伍里头排队，那个地方不收费，那个队伍排的跟蚯蚓一样的，大家就轮流在那儿想等着把手伸进去。我看着看旁边的罗马人经过的时候，有一种既漠然又有点不解的看着这帮远方来的无聊客人，怎么会对这么一个地方感兴趣？可以说那个地方对他们来说是没有什么价值的，据说那个像磨盘的东西在古罗马是干什么的呢？是一个下水道的井盖。

很多人，尤其是年轻的女士们之所以来到罗马，就是为了那个西班牙台阶和这个真理之口，这两个不收费的地方。

罗马本来是一个名胜古迹非常多的地方，却因一部电影而让它的游客至少增加了一倍。我们可以说《罗马假日》这部电影它创造了一个外部性。后面产生的效果是拍电影的人没有想到的，这部电影本身已经很赚钱了，但是它创造的后续效果产生的那个价值并没有因为它后续的效果再来收费，事实上用蔡教授的观点来说，它是没办法收费的。

有个朋友春节期间到新西兰去旅游，给我发了一堆那种照片，那照片一看就很熟悉，它马上让我想起《霍比特人》、《指环王》，可以说是因一部电影使得那个地方人山人海。拍《指环王》和《霍比特人》电影的人也已经不像拍《罗马假日》的人那么傻了，他们意识到这部电影可能产生的外部性。他们在这个取景的时候，他们回到了一个场景，就是养蜂人和果农的对话。农场主说你在 admir 这个儿拍电影，你拍电影去赚钱，你在这儿取景，你应该给我钱。那拍电影的人说，我拍了这部电影，你这地方可以招来大量的游客，你应该给我钱。当然这种最后的结果就是双方达成一个协议，最后就成就了一门大生意，一门可持续的，可以赚大钱的生意。所以外部性其实是一个假象，或者只是一个暂时的现象。

# 例子：手机预装App

内部性、外部性这听起来还是很抽象，大家不妨想想这样一个例子，刚开始手机厂商卖它的产品的时候，甚至会去找一些互联网公司，问他们能不能把他们的App装在手机上，这样我的用户就免得费劲去下载，买到手机马上就可以用那些最基本的最常用的App。

对于App的厂商和手机厂商来说，双方都没有付出额外的成本，这个交易其实是不包含资金的一个交易。

由于人的注意力总是稀缺的，我们正常人每天经常打开的App只能是5到7个，所以手机厂商突然意识到，它为那些App厂商，它的价格，它没有体现在交易清单的那个价值，也就是外部性没有得到体现。

而现在它可以跟App厂商说，我给你预装一个App，你给我多少钱，据说刚开始的时候是2块钱，5块钱，10块钱。我听说有的，最贵的已经到30块钱。大家可以想想一部手机的利润是多少，凭空一下子就增加了30块钱。关键是它还不只是装一个App，大家算下来，一部手机里头预装几个App，说不定它挣的这个钱已经比它手机本身挣的钱还要多。

外部性、内部性的问题跟一个商业模式非常相关，那就是所谓的免费模式。所谓的免费不过是交叉补偿和转移支付，通俗的说法是羊毛出在猪身上，狗买单，这就是一个典型的外部性转化为内部性的例子。

如果事先有好的制度设计，能够找到可操作的盈利模式的话，外部性就不存在了。我不同意这种观点，说经济学是来解释经济现象的，管理学是来解决经济问题的。其实很多经济学的概念它本身包含着一种企图来进行制度设计，解决一些看似不能解决的问题。

# 合成谬误的起源

合成谬误这个概念是起源于一个剧场的难题，在前面的人会挡住后面的人，前面的 人坐在地上，越往后面的人他只有站起来才能看得到演出。再后面的人他必须要站在板凳上才能看到演出。最后的结果是，所有人的成本都在增加，但是收益并没有增加，大家基本上都在受累，这是合成谬误本来 的意思。但是，这里头就包含着一种解决的方案，事实上后来的体育场就是要解决这样一个合成谬误。就修大型剧场和体育场的人终于意识到，这个体育场和这个剧场必须<|message|> 修成一个碗型的剧场，这个时候通过事先的制度设计就解决了合成谬误的问题。

所以我同意蔡教授的观点，外部性是一个暂时性的概念，它只不过是没有找到好的收费方式的时候，它才呈现为外部性。我们在设计商业模式的时候，必须回答三个问题：

+   1. 你卖的到底是什么；
2. 凭什么是你卖，而不是别人卖；
3. 最重要的问题是，你如何收费，你如何赚钱。

前面的都很好，前面你能创造客户价值，但是你收不了费，你修了一条高速公路，你修不了收费口，那你这个商业模式不成立。所谓 的商业模式涉及一个很重要的节点就是防止外部性，或者把外部性转化为内部性。
