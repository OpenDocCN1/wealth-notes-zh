# 本周预告 | 成见就是认知中的 “快捷方式”

本周预告 | 成见就是认知中…

本周的《伯凡·日知录》从几个德国科学家曾经做的一个实验说起。

科学家们铺出两块人造花田，也就在两块相邻的田里分别插上黄色和蓝色的塑料花，前者涂有花蜜，后者没有。随后，他们就在两块田旁边放飞蜜蜂。

刚开始的时候，蜜蜂在两块田上均匀分布，但很快，蓝色花田里的蜜蜂就意识到蓝花上没有花蜜，纷纷飞离这些蓝花。同样 的过程重复几天以后，就再也没有蜜蜂飞到蓝花上了。随后，科学家在蓝色塑料花涂上花蜜，而黄色塑料花上没有。结果是，蜜蜂仍然飞向黄色花田，而将蓝色花田弃置不顾。接连几天下 来，蜜蜂痴心不改，一直飞到黄色花田上，直到大量的蜜蜂饿死在黄花田里，虽然旁边的蓝色塑料花涂满了花蜜。蜜蜂以它们的生命，为它们的成见买了单。

成见并不一定就是坏事，拥有成见可以说是一种生存技能。如果我们面对新事物、新场景时，不能用已经获得的认知来判断和决策，那生命将因为缺少起码的效率和品质而举步维艰，甚至寸步难行。

所谓成见，用一个我们熟悉的计算机术语来说，就是我们在认知中建立“快捷方式”，或者说是一种认知上的“无障碍通道”。我们的阅历越多，这种“快捷方式”就越多，正是凭借一个个不假思索的快捷方式，我们活得越来越有效率，有一些时候，也活得越来越有品质。

但这种快捷方式也是暗含着危险的，就像我们在蜜蜂的实验中看到的那样。如果人的心智模式中充斥着各种各样的快捷方式，人的心智和感觉就会在不知不觉中被控制，被程序化。在生活中，在商业实践中，这种快捷方式几乎无处不在。

比如说，所谓品牌，就是商家、媒体通过精心设计的程序在我们的头脑中建立他们所期望的快捷方式。在传统宗教的势力越来越式微的今天，各种产品和品牌拜物教此起彼伏，它们的目 的只有一个，让人们的头脑中植入各种无障碍通道，尽可能屏蔽同类选择，让你在别无选择中做出选择，并且让你自鸣得意地感受到这是你自己做出的选择。
