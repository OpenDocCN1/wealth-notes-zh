# —— 知识笔记 ——

听完昨天的节目，已经有一个同学在问我：“你说的这些跟我的印象完全相反。有些做的非常成功的企业，他的领导者他并不是你所说的那种是地低为海，人低为王的，他们一直是在高处。比如说马云，他一直是非常的高调，不仅在他公司里头振振有辞，扮演一个教主的角色；而且在机场，在微信上，我们都能看到马云指点江山那样一种好像要做所有人的导师，所有人的教主的那样一种气派。你能说阿里巴巴不成功吗？”

# 阿里巴巴为什么成功？

近期阿里巴巴有一个人引起了很多人关注，因为他套现6亿美元，差不多40亿人民币。阿里巴巴能有今天，我们不能不说到这个人，这个人名字叫蔡崇信。

有一篇文章说，如果你在创业，你如何才能找到你的蔡崇信。这篇文章的意思非常的明确——如果你想当马云，你必须先要找到蔡崇信。

有人把蔡崇信称为马云背后神秘的男人，还有人说，如果阿里巴巴是一部电影的话，马云是导演，甚至是一号男主角，而蔡崇信是这部电影的制片人。

![](bbox=[0.15, 0.00148, 0.97, 0.00174])

# 阿里巴巴的参谋长曾鸣先生评价蔡崇信：

观察阿里巴巴的发展道路，尽管马云和孙正义一直是媒体和舆论关注的中心，但是实际上还有另外一个人，蔡崇信对阿里巴巴的成功至关重要。蔡崇信是阿里巴巴的隐性的英雄。

# 阿里巴巴的副总裁王帅介绍蔡崇信：

双十一的数据说明，马云背后有很多热爱购物的女人，但是马云背后还有个低调的男人，这个男人对我们公司从创办到我们今天走向资本市场发挥着重要的作用，但是他很少，这也应该是第一次跟我们国内的媒体来见面，属于“大家闺秀”。

# 蔡崇信的经历

当年他以一个风险投资者的身份来跟马云谈合作，想投马云。结果他的公司决定不投马云的时候，他自己突然对马云说：“那边我不干了，我要加入阿里巴巴。”当时马云非常吃惊：“你到我这儿来，我养得起你吗？我这儿每个月就500元人民币的工资，你还是再考虑考虑吧。”蔡崇信当时的年薪是70万美元，按当时的汇率差不多是500万元人民币。他放弃500万的年薪到阿里巴巴一个月拿500块钱的工资。从这件事情上我们能够感受到，能够在那样情况下做出那样的决断，他的的确确是一个狠角色。

从他身上我们也可以明白一个道理，真正的狠角色往往是很谦和和低调的。足够的谦和，足够的低调才有可能足够的狠。这个狠其实就是落到实处的去做事情。

可以说，马云是非常幸运的，那么一个张扬，那么一个高调的人，在他公司刚刚成立的时候就找到了一個能够默默的为他的公司写底层代码，为他构建操作系统的 人。

公司的战略、商业模式说到底都不过是应用软件，而比商业模式，比战略更重要的是他的操作系统。这是我们创业的时候常常忽略的。很多创业者以为自己找到了一个好的商业模式，找到一个好的战略，或者是在一段时间内非常管用的盈利模式的时候，就以为自己的公司大功告成，长治久安了。这其实是很成问题的。

# 阿里前员工眼中的马云

前两天，我跟一个阿里巴巴的前员工在聊阿里巴巴，聊马云的时候，他说，很多人看到的马云都是一个很活跃，很躁动的形象。其实他的感觉是，马云在关键的时候，尤其是在听一些重大的汇报的时候，他是一个非常不愿意多说话的人，他只是在那儿静静地听，然后他偶尔会提一些看似很小，但是是非常关键的问题。当他提出关键问题的时候，汇报的人往往就立即停止滔滔不绝，因为他发现自己面对着一个其实很少想到一个重大的问题。当然，阿里巴巴能够有今天的成就，尽管马云看上去年是一个很高调的人，但他是一个很懂得沉默和低调的价值之所在的人。

也许正是因为他懂得沉默、低调，他才能真正意识到对一个公司真正重要的是那些不足为外人道也的那样一种系统性的力量，或者我们就可以把它叫做一个公司的操作系统。

# 是什么在决定命运？

我们在评价和自我评价一个公司的时候，往往容易忽略公司是iOS还是安卓，还是塞班，还是Windows。也许在公司的初创时期，如何确立自己的商业模式，如何获取战略性资源是头等大事。我们要意识到这里可能隐含着一个陷阱，就是当我们在做那些你的员工，你的投资方，你的合作伙伴看得见、摸得着的事情的时候，你是否忘记了做一些他们不容易看到，或者他们不太关注的那样一些事情。
