# —— 知识笔记 ——

美国有一个州叫阿拉斯加，在我们今天一说到阿拉斯加就会想到这是美国的领土，实际上这块领土是属于俄罗斯的。沙皇俄罗斯是世界上唯一的横跨三大洲、濒临三大洋的一个国家，东边是太平洋，西边是大西洋，北边是北冰洋，它的领土横跨欧洲、亚洲和北美洲。但是也许是由于他们的领土太多了，西伯利亚已经够远了，他们在西伯利亚之外，在白令海峡的那一边还有这么一大块冰天雪地的领土，他们觉得没有太大的用处，所以在国家困难的时候他们想着怎么把这块领土干脆就卖了。

北美洲总共才三个国家，能出得起钱的只有美国。据说当时美国是以每亩地2美分的象征性地价，总共这块地方卖了700万美元，这其实也就相当于今天一个豪宅的价格。但是当时很多人是表示反对的，因为当时的700万美元也还真是一笔大钱。最要命的是那块地方在当时的绝大多数美国人看来是没有任何用处的，中间还隔一个加拿大，那个地方主要特产是冰和雪，所以很多人都反对买那么一个地方，你把纳税人的钱去买这么一块无用的地方。但是当时美国的领导人力排众议，最后还是买了那块地方。

当然抱怨、斥骂的声音从来就没有平息，到了20世纪的时候，大家的观点一下子改变了，因为首先那个地方发现了金矿。到了20世纪后半期的时候，所有的美国人都觉得后怕，假如当时不买这块地方的话，苏联人就会把导弹基地设在阿拉斯加，中间就隔一个加拿大，他们用不着远程导弹就直接可以打到美国的本土，美国人当时就觉得那个时候的领导真是有远见卓识，为我们造福了。

# 精英主义和草根主义

很多主张精英主义的政治学家们常常用这个例子来说明决策一定不能是草根主义的，你要是被草根主义甚至被民粹主义所摆布的话，你做出的一定是个糟糕的决策，或者说你做出这样的决策就证明你不配成为一个领导。

精英主义的政治学家们还用很多的例子说明精英主义是必不可少的，比如说他们常常爱举这样一个例子，小男孩儿话都不会说的时候他老爱用各种各样的东西去插插座，你不能够跟他讲道理，你只要告诉他就是不能插，只要你插我就会打你，这样小孩就老实了。他那个时候也许会恨你，但是他长大以后他会感谢你，幸亏当时我爸不让我插电，要不然我活不到今天。

这样的理论又让我们想到昨天讲到的孔子的那句话：“民可使由之，不可使知之。”你之所以是领导就是因为你的见识、你的见解、你的判断跟普通人不一样，否则你就是不称职。但是我们昨天讲到了领导者的悖论，你作为一个领导者一方面你要跟大家不一样，另一方面你要跟大家很一样，你一方面要站在大家的前头，站在大家的上头，同时你的精神、你的思想要高于普通人。但是形体上的你应该是跟大家站在一起的，是跟群众打成一片的。

# 川普希拉里之争

前两天川普正式登上了总统的宝座，川普和希拉里之争也告诉我们，即使你本身就是一个大土豪、一个大富豪，你的衣食住行是普通的老百姓做梦都想不到的，但是你要让他们感到你跟他们是一伙的。老实说希拉里一家其实是平民，没多少钱，不仅没钱还欠了一大堆债，克林顿时不时到中国到五粮液来走穴，原因是由于他欠了很多钱，这两个穷人和富人之间的争论特别有意思，一个是代表着穷人的超级富豪，一个是代表着富人的一个穷人，最后的结果普通的老百姓毅然决然地选择了那个跟他们本来根本不是一路人的那么一个大富豪，这其实是一个很有意思的现象。

# 国王与先知

在管理学上经常会提到一个命题叫“国王与先知”，一个好的国王必须要由自己的先知。我们中国把那些人叫帝王师，姜子牙、张子房、刘伯温等等，他们是先知，但先知仅仅是先知，真正的领导者是国王，国王跟先知最大的不一样是他不仅要站得高看得远（当然他站不高看不远的时候他还有先知），同时他要让普通的人觉得他是普通人的国王，普通的人不管再普通都是他的子民。

以前我提到过唐朝有一个隐帝叫唐明皇，他在视察蝗灾的时候，他抓起一个蝗虫就往嘴里塞，然后咔吧咔吧，咬完了恶狠狠地把它吞下去，然后恶狠狠地说一句话：“你吃我子民的粮食，我就吃你。”这就是国王跟先知不一样的地方，他是一个领导者。

《道德经》里说的那句话：“欲上民者，必以言下之”，你就你站公众的高处，你就必须要用语言让自己处于低处。“欲先民者，必以身后之”，你想站在民众的前头，你必须把你的身体放在最后。原因就在于领导者是一种很特殊的人。
