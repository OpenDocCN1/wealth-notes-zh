# 拉威尔

音乐史上通常会把拉威尔划到“印象乐派”，但是我听拉威尔的音乐越多，便越是不可能同意这种划分。

![](bbox=[0.13, 0.0023799999999999997, 0.88, 0.0028])

《波莱罗》(Bolero)是拉威尔最为人熟知的作品，几乎可以成为他的标签。这是拉威尔最后的管弦乐作品，也是他的五部舞蹈或者舞剧音乐的最后一部。就创作过程而言，它算得上是一个“急就章”，可以说是仓促完成，却又是那么的完美无缺。1928年初，在巴黎非常受敬仰的俄罗斯舞蹈家伊达·鲁宾斯坦夫人请拉威尔为她写一首西班牙风格的舞剧音乐，她的请求是无法令人拒绝的，因为当时的许多作曲家都在为她的舞蹈写音乐，拉威尔起初打算直接从西班牙作曲家阿尔贝尼斯的钢琴组曲《伊伯利亚》里面选一首改编成管弦乐，可是当他已经酝酿准备得差不多开始谱曲的时候，意外得知《伊伯利亚》的改编权已经被另一位西班牙作曲家指挥家恩里克·阿尔纳奎斯买断了，这令拉威尔非常不爽。眼看时间已经非常紧迫，拉威尔只好在夏天把自己封闭在家乡的一处住宅中，在很短的时间里完成了这首《波莱罗》。
