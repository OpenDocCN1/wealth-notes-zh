# 2.13 | 人与计算机如何竞赛？

# —— 知识笔记 ——

有一个节目叫《最强大脑》，我相信很多朋友们都看过，这个节目把隐藏在民间的诸多的高手搜罗起来，让这些高手们展示在智力上令人 cardiovas 强项。

我记得我对这个节目印象最深的就是那个从山西找来的一个朋友，他由于小时候得了？一场地病，很不幸他的智力上出现了一些问题，也即是在常人看来，他已经从一个正常的儿童变成了一个弱智儿童。但是周围的人发现他有一项独特的能力，那就是心算的能力，在这个节目里头我们看到他的心算能力，的确是让我们望而生畏，与他相比我们简直是弱爆了。

![](bbox=[0.15, 0.0013, 0.95, 0.0017800000000000001])

刚开始主持人给他出了一道题，随机叫了一个电话号码，有一个嘉宾叫梁冬，也即是我的《冬吴相对论》的搭档，他在后面又加了三位数字。我们知道手机号码是11位数，加上3位数就是14位数，一个14位数连续开七次平方以后的得数是多少？这道题对于绝大多数人来说那只能是望而却步，当时请了一个南京大学数学系的教授，他尝试想用口算和心算把它计算出来，可是刚尝试了一下就放弃了。

这个被认为<|message|>弱智的嘉宾，他经过两分钟的心算，在纸上写了一些数字。后来用计算器验证的结果是，他给出的答案非常接近正确答案，应该我记得好像是2.06点几，6后面的数字跟正确答案有一点误差。所以在场的人、所有的观众都感到非常吃惊，甚至有人感动的流下了眼泪，这个平时免不了受到别人歧视的这个孩子，在这一个时刻展现了他的智力上傲人的那一面。
