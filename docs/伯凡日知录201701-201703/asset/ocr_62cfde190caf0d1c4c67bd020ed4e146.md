# 春的命令

中国人对春意的敏感，对春意的推崇，可能跟我们这个民族一直是农业民族相关。在农业社会最重要的工作就是把握天时。在传统的中国人看来天时其实就是天给我们下达的命令，所以叫时令，时令什么时候，时间给我们下命令。作为一个合格的农民，他就是能够听见并且服从天的命令，也就是时令的人。正因为我们关注时令，所以我们也就关注春意，而不是关注春形。当大自然透露出春的信息的时候，我们就要开始劳作，我们就要开始工作了。等到了春暖花开的时候你才开始工作，就意味着已经错过了春天。

一年之计在于春，也就是说一年的关键就是春，而这个春指的是春意，也就是春的信息，当这个信息一旦发布的时候你就要跟时间、跟气候同步的工作，如果你错过了这个信息、错过了这个时令，这一年也就告吹了。

人类早已经从农业时代经过了工业时代，现在都已经进入信息时代，甚至是智能时代了。春对于我们的意义已经不同于传统社会当中春对于农民的意义了。

但是有一点是共通的，真正的好消息、真正重要的信息往往是以一种不太明朗的方式发布的，如果等这个信息已经很明朗的时候，这个信息往往价值已经不大了。我们今天在创业的时候，应该让自己像传统社会的农民那样，当春天的信息刚刚透露出来的时候，我们就应该深切地感受它，然后去顺应它，与大自然同步工作，你在秋天才会有丰厚的收获。如果一个机会是大白于天下的时候它都不是机会了，我们都可能有一个共同的感受，春节虽然以春命名，但是我们好像感受不到春天，这个时候天气还是那么寒冷，大地还是那么萧瑟，但春节这个节日它是在提醒我们，春天其实已经来临了，尽管我们往往感受不到它，我们应该具有梅花那样的敏感性，在春天还没有成为一个公开秘密的时候，我们提前获知这个秘密，并且现在就开始进入一个播种和生长的季节。
