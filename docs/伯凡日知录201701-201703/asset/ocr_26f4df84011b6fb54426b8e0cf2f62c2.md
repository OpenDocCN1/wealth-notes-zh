# 春字

有一个字谜叫“三人同日去看花”，这个字谜的谜底就是春。我们很少看到春这个字有别的写法，其实在古代春不是这样写的，在古代春还有别的写法。有一個写法是，一个草字头下面是一个屯，就是北方话里头村子的那个屯。

屯是一个象形字，它描绘的其实是草破土而出，下面是草根，上面就是一个小尖，就是草的嫩芽刚刚钻出来的那样一个情景。春本来的意思就是指草开始发芽了。

> “屯”这个字在古代跟“春”这个字的发音是非常相近的，屯的意思是不明显、不鲜明、不锐利。

# 春意

在中国人的感受当中，春恰恰也就是这样一种状态，一方面它意味着冬天的结束，但是在这个时刻你还能感受到冬天的那种气息，冬天意味着停止、终结甚至是死亡，而春天意味着开始、意味着生长，同时它也不是那种显而易见的生长。

风雨送春归，飞雪迎春到。
已是悬壶百丈冰，犹有花枝俏。
俏也不争春，只把春来报。
待到山花烂漫时，她在从中笑。

这首诗写的是梅花，梅就是典型代表着春的“意”，而不是春的“形”的那样一种植物。在这首词里头我们看到好几句都写着好像是冬天的情景：“风雨送春归，飞雪迎春到”，风雨、飞雪、百丈冰，这写的都是冬天的情景。而梅花的可贵之处或者说它值得赞叹的地方就在于，它在寒冷的时候在发布关于春天的消息。
