# 本周问答｜如果你追求伟大，那就别害羞

本周问答｜如果你追求伟大...

大家好，又到了周末和大家互动的时间了。本周讲到一个话题“冒充者综合征”，没想到这个话题引发了许多同学的讨论，可见这的确是一种看似有点怪异、有点特殊，但实际上是相当普遍的一种心理现象，所以引起了大家的共鸣。我首先回答与这个话题相关的两个问题。

沈思（文迈）：为什么是“冒充者综合征”而不是“冒充者综合症”？

吴伯凡

这个问题大家只要在百度百科里头查一查综合征这个词条就能得到答案，但我还是简单地说一下。综合征的英文叫Syndrome，综合征我们可能会在一些书上、报纸、杂志上看到综合征常常被写成综合症。综合症其实现在是一个错误的说法，可以说综合征不是一种可以被特别明晰界定的病症，而是一种症候群，它有一系列的症状，它不是一种独立的疾病。有时候出现几种疾病或者由几种不同的原因所引起的疾病，比如说冒充者综合征，它可能会跟拖延症有关，作为一种习惯性的自我挫败的心理特征，它具有多种的特征和症状，而不是一个单一的症状。具有一系列特征和具有一系列症状的那样一种疾病群或者叫症候群，我们就把它称之为综合征。

粤创（麦生）：伯凡，您好。我认为儿时是否染上“冒充者综合症”与人们性格的强弱有关，性格柔弱的不知道不觉中被父母和老师种下心锚，糊里糊涂的被催眠了。我是70后，我们那时候家里、学校和社会的道德文化是比较统一的，没有现在的个性化，然而还是造就了许多许多不同的人，我们被输入的大体一样，但结果却大不相同，看来性格大多是基因遗传的，难道三岁真能定八十？

吴伯凡

他的观点表述并不太清晰，他说冒充者综合征是与人的性格强弱有关，但是什么性格的强，什么性格的弱也是比较难定义的。可能在他看来只有那些性格比较弱的人才容易染上冒充者综合征，应该说这有一定的道理，但是哪怕是一些性格看起来很强硬、很自强自立的人，也可能染上冒充者综合征的习惯。他们认真地做事，但是当那些难得的机会、难得的收获出现在他们眼前的时候，他们常常会怀疑自己是否配得上这样的机会、这样的地位、这样的成绩。也就可以说这种习惯性的自我挫败，也会发现在性格看起来很强的那 些人身上。

那天讲到冒充者综合征的时候，有一个相关的话题，我今天在这里补充一下。很久以前我读过一本书叫做《天路历程》，是英国作家约翰·班扬写的一本想象性描述一个想获得信仰，完成自己使命的人在实现自己使命的过程当中的种种经历，这本书是一本世界名著。早年我读这本书的时候，书中有一个观念让我很困惑，在作者看来对于一个要获得信仰，完成使命的人来说，害羞是一种恶习，甚至是一种罪恶，必须要抛弃。我当时百思不得其解，因为传统的基督教伦理是强调谦卑、强调羞涩，反对狂妄自大的，但为什么他说害羞是一种恶习、是一种罪呢？我当时觉得非常矛盾。

我顺便说一个观点，我们年轻的时候、读书的时候特别乐于发现别人观点所谓矛盾的地方。当我们发现某种矛盾的时候，我们常常会暗喜，我们会因为自觉不自觉地抓住别人的某个漏洞、某个把柄，而在挟上获得某种快感，这在学习、读书的过程当中是一种不太好的习惯，应该尽量地避免。有些人看书、听讲座、学习的时候，特别乐于发现别人的漏洞和矛盾之处，这其实是一种偷懒。面对一个人的观点，我们感受到某种谬误、感受到某种矛盾，并不意味着作者的思想和见解当中真的存在着这样一种谬误，而是因为我们没有细致地、全面地了解作者的观点，我们不愿意去慎思明辨，自觉不自觉地想通过一种抖机杼的方式让自己显得很聪明，显得很机智，从而让自己逃避认真的思考。话说回来，后来我逐渐意识到为什么班扬认为害羞是一种恶习、是一种罪恶，因为如果对一个要获得信仰的人、要完成使命的人来说，他应该有一种当仁不让、舍我其谁的心态，不要在追求自己信仰、完成自己使命的过程当中，习惯性地否定、习惯性地怀疑自己所做的事是否真的有价值。如果一旦这种怀疑的习惯渗透到你的内心的时候，你有可能就知不觉地放弃了自己的信仰、放弃了自己的使命。所以在班扬看来，你要真正地去走完天路历程必须要抛弃那种习惯性的害羞，习惯性的以别人的眼光来苛求、来嘲讽自己的那样一种习惯，其实班扬所说的这种害羞的心态也是冒充者综合征当中的某一种症状。

我们经常说要战胜自己，那怎么才算战胜自己呢？我们应该意识到最可能和我们暗中作对的人很可能不是别人，而是自己。我们在想问题、做事情的时候，另外一个自己，在随时在侧，在我们自己没有意识到的情况下单独我 们、挫败我们。故战胜自己有很多方面，其中一个很重要的方面就是要战胜那个悄悄给我 们自己挖台，给我们自己挖坑的那个自己。只有当我们战胜了那个以各种噪音来干扰我们，让我们心神不安的那个自我以后，我们才可能既专注又轻松地去做事、去想问题，才可能进入到一种叫做沉浸感的状态当中。说到沉浸感，我就想到洛克菲勒的一句话，他说：“我和穷光蛋最大的不同，不在于我 是世界首富，他身无分文，我始终觉得我和他们真正的区别就在于，我无论在什么地方，无论环境多么恶劣，无论别人以一种不友好的方式来看待我，我都能够在5分钟之内沉浸在自己的工作里。而有些人他们在一生的时间当中都无法拥有我这样的状态，他们用一辈子的时候在追寻，同时也在自我怀疑，那种三心二意的态 伴随着他们的一生，所以他们碌碌无为，最终一无所有。”

关于冒充者综合征我就说到这里。

吴伯凡
