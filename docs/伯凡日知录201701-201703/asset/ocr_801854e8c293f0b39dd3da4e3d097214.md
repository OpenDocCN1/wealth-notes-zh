# 人工智能的现状

除了传说中的AlphaGo，还有传说中的Master之外，真正能够让我们感受到人工智能的威力、魅力的产品或者案例很少很少。

利用了人工智能的技术来提供服务的产品都让我们比较失望。

# 例子：智能推送

这一年多来出现的那种以智能的推送为特点的内容服务，给大家的体验都不是那么好。有 一个朋友说，他只是很偶然的原因点了一个明星八卦，但是即使你不是一个八卦的人，没有一颗低俗的心，但偶尔你会不小心有所涉猎，有时甚至是极偶然的原因，你就触及了某一 个领域。但是在网络那边的那个据说很智能的那个推送者，他就会不断的向你推送与这个内容相关的种种的话题。那时候，正好是奥运会，可是给他推送的内容里头大量的根本不是奥运会，而是关于王宝强的內容。

有一个统计，说如果按数据的流量来算的话，对王宝强的八卦关注的程度在那段时 间已经远远超过了对奥运会的关注。

我觉得现在的所谓的智能推送就好像说我到了一个餐厅，餐厅里头桌子上摆着几碟凉菜、咸菜。我在等菜上来的時候，我偶尔吃了一点海带丝，吃了几粒花生米。这个据说很智能的餐厅就认定我是喜欢这些东西的，最终的结果是我的桌子上堆满了各种各样的花生米，各种各样的海带丝。这就是我们今天感受到的所谓智能技术的威力或者说一个关于智能技术的神话，在我们看起来就好像是一个笑话。

所以大家最后好像得出了一个一致的结论，就是人工智能不靠谱。只是一些资本 玩家和创业玩家们在那里说说而已，是他们做的一个局。

# 例子：立春

立春的意思就是春天已经立起来了，已经立住了。但是我们看到的景色没有一点点春天的迹象，哪怕室外的温度非常的寒冷，但我们要意识到春天真的已经立起来了，它不是一个传说，尽管现实让我们感觉到它非常的遥远，遥远的很不靠谱。

天街小雨润如酥，草色遥看近却无，这是我们在早春时节常有的一种体验。现在看 来对我们来说人工智能遥远的就像是一个谣言，但是正如我们以前一次又一次的体会到的很多的谣言不过就是遥遥领先的预言。我们千万不要因为它眼前的不可靠而对它弃之不顾。

我偶尔低俗，你就认定我是一个低俗的人，你就飘泼桶倒的把那些低俗的内容推 向我。

这里头可能还会有 一个循环，由于你推送的内容越来越多，我被迫去接触这样的东西，被迫去消费这样的信息，结果就形成了一个正反馈，我们更加不打自招的告诉他，我们就是一个低俗的人，所以他用他的巨大的流量和所谓的先进的技术使我们更加的低俗。这是目前在内容产业应用人工智能造成的一个令人尴尬的局面。

# 实验一：蜜蜂采蜜行为研究实验

几个德国科学家为了研究蜜蜂的采蜜行为，他们就找到了两块地。在两块地上他 们都插上了塑料花，一块地插上的是黄色的塑料花，一块地插上的是蓝色的塑料花。

他们给黄色的塑料花注入了花蜜，而蓝色的塑料花上没有。接下来他们就在这两块田旁边放飞刚刚出生的蜜蜂，开始的时候蜜蜂是在这两块田之间是均匀分布，它们凭着本能看到有花就去采蜜。但是这些蜜蜂也很有聪明，当那些飞到蓝色塑料花上的蜜蜂发现这些所谓的 花上没有花蜜的时候，他们都纷纷选择离开，飞到黄色塑料花的 那一边。由于黄色的塑料花上涂满了花蜜，所以飞到上面的蜜蜂越来越多。到最后，蓝色的塑料花上再也没有蜜蜂了。

第二天，他们又做了同样的实验。这些蜜蜂很聪明，几乎就没有蜜蜂飞到蓝色塑料花的 那一边，都不约而同的扑向黄色的塑料花。当这些科学家发现蜜蜂已经形成了这样的习惯的时候，他们就改变了实验。

他们把上头没有涂过花蜜的黄色塑料花插在那块田里，然后在蓝色的塑料花上涂上花蜜，然后把这些蜜蜂放出来。这些已经形成了记忆，形成了习惯的蜜蜂又是LIN。不约而同的扑向黄色的塑料花。尽管上头已经没有花蜜，但是它们还是坚定不移的，矢志不渝的叮在这些黄色塑料花上。结果是不言而喻的，这些蜜蜂忙活半天，一点收获都没有。

第二天，他们接着又在这个地方放飞这些蜜蜂，结果那些蜜蜂还是跟头一天一样又扑向这些根本没有花蜜的黄色塑料花。几天下来，这些蜜蜂因为饥饿大片的死去，尽管旁边的蓝色塑料花上涂满了花蜜，它们置之不理。

# 实验二：蜜蜂趋光行为实验

把一只蜜蜂放在一个空瓶子里，这个空瓶子的底部有着窗户，由于它的趋光性，它不停地朝着有光的地方飞，尽管它是永远飞不出去的。至于最后它累死在这个空瓶子里头。而如果是把苍蝇放在这个空瓶子里头，苍蝇在那里胡打乱撞，一会儿它就飞走了。所以蜜蜂由于它的执着把它的命都丢了。这个实验也再一次证明，蜜蜂由于它的认死理，由于它的执着，而用它们的生命为自己的执着买单。
