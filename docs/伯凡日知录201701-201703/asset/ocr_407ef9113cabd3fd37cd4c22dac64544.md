# 喜

关于喜这个字有几种解释，比较权威的解释，喜上头的这个字是敲锣打鼓的鼓的本字，而这个鼓字就意味着欢乐，我们前面已经讲到中国古代的乐（le）跟乐（yue）是同一个字，而最早的乐是鼓乐，或者说中国最早的乐器是作为打击乐器的鼓。所以这个鼓就代表着吉庆、代表着欢乐，而当心理产生了欢乐之情的时候，人就会把这种情绪表达出来，喜的最初的意思就是欢乐之情脱口而出，所以它下面是一个口字。简单地说喜就是内在情绪的外在表达，有一个成语叫喜形于色，还有一个成语叫喜出望外，当一种欢喜、欢乐的情绪超乎了我们的期望的时候，我们就会大声地叫出来，这叫喜出望外。当然也有人解释说，喜跟吉有关，因为喜字的上半部分是一个吉字，但不管是哪一种解释，喜都跟我们前面讲到的幸福、欢乐、吉祥有关，尤其是跟欢和乐密切相关，所以汉语里头也有欢喜、欢乐、喜乐这样的词。

我们在昨天讲到吉祥的时候提到了《菜根谭》里头的一句话，福不可邀，为养喜神以为招福之本，祸不可避，为去杀机以为远祸之方。什么叫喜神呢？在中国文化当中神这个字既指外在的某种力量，同时也指内在的某种能量。人的内在的能量分为三个层次，精、气、神，相对于说精是比较接近于物质状态的。在精字上是气，繁体的气字下面有一个米字，它是指我们获取的这个外在的，像我们吃的东西里头进入到我们的身体以后转化成的一种能量，比如说我们的身体气血不足，我们有什么食品是补气的，这个气其实就是能量。所以我们中国古代的经典译成英文的时候，学者们常常把气这个词译成能量，叫energy。当然西方也有一些学者认为气这个词不可翻译，直接用气的汉语拼音来指代气这个概念。精、气，最高的状态是神，这个人的眼睛很有神，就是指这个人的眼睛里头有一种至精至纯的能量，如何达到神这种状态呢？最重要的方法就是壹，这个壹就是繁体字的壹，用志不分，乃凝于神，当你的意图、当你的精神的指向凝聚成一点的时候，你就能达到神的状态。那么所谓喜神就是那种正向的、欢乐的、吉祥的心态，就是我们的心志长期地聚焦在欢乐、吉祥上，我们就能达到一种叫做喜神的状态，它是一种比我们通常所说的喜气更高的一种状态。

# 聚精会神

我们有一个成语叫聚精会神，你只有把你的内在的能量聚集起来，最终你才能跟神，跟你的那个最纯净的能量相会，那种东西叫做神。我们说一个画家，他画一个东西的时候非常传神，也就是将一种内在的能量、内在的力量能够传达出来，如此说来喜神是一种非常珍贵，因而也是很难达到的一种状态和境界。喜跟我们通常所说的欢乐的状态、高兴的状态还不太一样，我们高兴常常是因为为什么东西而高兴，我们欢乐常常是因为为什么东西而欢乐，而这个喜神可以说是一种无特定对象的一种正向的心理状态。可以说它首先是一种习惯，是长期的正向状态形成的一种习惯，一种自内而外的无特定对象的或者说是针对所有对象的那样一种喜悦的状态。

有一个心理学家在研究了，在做了大量的样本研究以后得出一个结论，我们通常说的好运气、坏运气，常常是带有一点点迷信的色彩。这个人很顺利是因为他的运气好，那个人不顺利是因为他的运气差，他的结论是那些常常遭遇坏运气的人，并不是有一种固定的处境笼罩着他，而是因为他的心理状态和行为模式是处于一种消极的负面的状态，面对问题他不是习惯于正面的期待，而总是习惯于用一种负面的方式看待和对待眼前的的人和事。而这种微妙的心理状态他具有一种感染力，会影响到他周围的人和事，这些周围的人和事会作为一种环境又反射回来，又会加剧他的行为和心态的负面程度。如此他的这种负面心态和行为形成一种正反馈，所谓正反馈就是一种状态会引发另外一种状态，而另外一种状态会反过来加剧这种状态，不断地循环，使得抱有这种心态的人越来越相信自己的判断，持有这种行为状态的人，他的行为模式就越来越缺乏建设性，越来越禁锢他自身能量的发挥。所以这个研究表明坏运气并非是一种神秘的东西，而是由人自身的状态引发的一种正反馈。我们常常听到这样的说法，Dependency...

新的一年已经到来，在中国人的信念当中鸡跟吉同音，我们都期待鸡年对于我们来说是吉祥的一年。在过去的2016年，我们目睹了许多黑天鹅事件，也许2017年又是一个充满着挑战、充满着不确定性的一年。面对这样一种客观的环境，我们应该做的和能做的也许就是和气以致祥，让我们内心多一份和气，也许我们的内心多一份和气，我们所处的环境也会悄悄的有所改变。还是那句话，养喜神去杀机，静由心生，我们自身的状态也许就是我们所处环境的最根本的原因。
