# 2.15 | 什么是智能？

# —— 知识笔记 ——

我们昨天说到, 所谓智能就是能够捕捉场景性的信息, 在特定的场景下作出适当的反应。而机器和人最大的差别就在于机器的智力, 它常常是非常隐形的。一个最先进的机器人和一个4岁半的小孩子之间的最大的差别, 就在于二者对于场景的感受力。

“二”

在日常生活中, 我们常常对那些不太具有智能的人用一个不太好听的词来形容就是 “二”。我请教过好几个人说这个 “二” 是怎么来的。二是北方人才这么说, 北方人形容一个人智力不那么灵光, 做事不那么地道的时候, 用 “二”。

北方还有几个相应的方言, 二傻子, 二愣子, 所谓二, 是指程度上稍稍缺就一点, 比如过去把伪军叫二鬼子。就是程度稍低的, 成色不足的。

# 图灵测试

这个笑话跟有一个听起来很高大上的一個问题有关, 叫图灵测试。

![](bbox=[0.3, 0.002, 0.68, 0.00235])

图灵不仅被认为是计算机之父, 而且被誉为人工智能之父。他早在1951年就提出了一个著名的图灵测试, 他设想有一台机器, 我们后来把它称为图灵机, 就这不是一台具体的机器, 而是一台图灵想象当中的具有智能的机器。

![](bbox=[0.35, 0.0033, 0.75, 0.00385])

如果再把这个场景变换一下, 把在第二个房间里放置一台图灵机, 这台机器能够自如地回答裁判员提出的问题, 以至于让裁判员并分辨不清楚哪个房间里是人, 哪个房间里头是机器, 如果有30%的人都没办法分别出他是机器还是人的话, 那么它就通过了图灵测试, 那它就具有了智能, 这就是著名的图灵测试。

![](bbox=[0.15, 0.00435, 0.95, 0.00475])

我们在很多书上看到, 有一个想象出来的场景, 让我们更容易感受到什么叫图灵测试。
