3.2 | 如果你能穿越回过去

# —— 知识笔记 ——

现在穿越剧越来越流行，让我们这些老同志觉得越来越不适应，我自己反省一下，我发现我在年轻的时候其实也看过穿越剧，那是一个叫《时间机器》的电视剧。写的是两个历史老师借助时间机器穿越到过去，然后再目睹一个个的历史场景。

我还记得当时有这么一个场景，这两个人站在一个桥头，发现桥那边走来一个矮个子。其中一个老师马上就明白是怎么回事了——“年轻人，请等等，你去干什么？”“我现在要到巴黎去上炮兵学校。”那个历史老师说：“我听你的口音怎么有科西嘉口音？”“对，我就是科西嘉人。”然后他拍了拍这个矮个子的肩膀说，“波拉巴你将来一定会大有成就的。”因为这个穿越剧里头有一个固定的规则，是不能干预历史，所以这个历史老师就没再说多的话。

我一直忘不了这样一个虚拟的场景，可能因为这样的场景对于我来说太有诱惑力了，如果有这么一台时间机器，我不仅能够亲历历史，而且可以指点江山，可以对一个个的历史人物给出决定正确的忠告。那真是一件好诱惑人的事情，当然这也只是我年轻的时候众多的白日梦之一，我知道这是做不到的。

前几天我看了一篇文章叫《中国互联网20年》，里头最有意思的是把中国互联网上20年前的一些人物、事件一一罗列出来，我看了以后真的是有一种恍若隔世的感觉。这些事情对于别人也许是历史，对于我来说在某些点上不仅仅是历史，而且还是个人的经历。当时的那些人、那些事历历在目，我记得王峻涛结结巴巴地在跟人讲“8848”的商业模式，因为他这个人，媒体说他结巴好说话，他有点口吃，但是发现很多口吃的人都很执着。他在那讲“8848”未来的前景。记得当时有个人跟我说，这个网站做不起来，我说为什么？他自己觉得8848是世界最高峰，你想八八四八珠穆朗玛峰上头，那是一个无比寒冷，没有生命的地方，那个寸草不生的一地方他取这么一个名字。这个人我不知道后来他会不会自己觉得自己有先见之明。

有一个哲学家说，先知们即使说对了也是在撒谎，因为他也不知道他自己怎么对，他们就像是那种坏了的手表，一天总有两个时刻是特别准的，但是那种准是没有价值的。

这篇文章罗列了很多的事实——

百度最早是给门户做搜索技术服务商，没打算自己做流量入口，这个是真的。

当年李彦宏从硅谷回来创业，他边创业还边搞文学创作，用章回体的方式写了一本叫做《硅谷商战》的书，那个文字水平相当的高，从标题到行文都是章回体的。这本书的责任编辑叫张朝阳，但不是我们知道的那个张朝阳。

我记得他有一次怯生生地去一个专门报道互联网业态的杂志，去拜访那的编辑，胳膊底下夹着一本书拿出来说，“这是我写的一点东西，你们先看看”，那就是当时的李彦宏。他想把自己的技术嵌入到门户网站里头。比如说你在用新浪的时候，可以在新浪上做搜索，但是这个搜索引擎是百度提供的，他根本没想过自己独立地来做一个网站。

腾讯最早是想给电信做网络寻呼系统，BP机，没打算自己做用户，当时想发展点用户，只不过是想做样本的测试系统。但是很可惜或者说很幸运的是，电信根本没理他，让他滚，结果电信不鸟他，幸亏电信不鸟他。

阿里刚开始做的业务是叫企业黄页，我们今天说阿里巴巴是在1999年创业的，实际上马云同志是在1992年就创业了，做过各种各样的事情。马云做过一个不可思议的职业就是做财会的培训师，办培训公司发现英语课不如财务课招的人多，所以他自学财会，去教别人如何做财务。差不多前前后后折腾了七年，最后才创立的阿里巴巴。

盛大最开始做社区，做了一半天没有什么结果，最后还剩下一有点钱，说怎么办呢？这点钱做网站是不够烧的，干脆去代理个游戏，就代理了一款叫做传奇的游戏。当时大家都觉得中国的游戏没有市场，所以代理金很低。盛大就凭借传奇这款游戏发达起来。

京东最开始是在中关村电子一条街在卖东西，这点大家都知道。当时那条街还有一个名字叫“骗子一条街”，刘强东他没有骗别人，但是他是从这条街上起家的。

看到这样一些事实的时候，大家会觉得很吃惊，怎么这些创业者刚开始干的都不是他们后来要做的事情，甚至差十万八千里，但是他们都做起来了。这其实说明了一个创业当中普遍存在的现象，一个 start up，一个初创公司所从事的业务跟它后来足以奠定它基业的那个业务之间可能差得很远，但是每一个公司必须要有个起点。
