在《人类简史》里头赫拉利说，如果单个人和单个的黑猩猩来叫板的话，那么输家一定是人类，甚至是十个人和十个黑猩猩在一个孤岛上，人类胜算的机会也不大，那800磅的大猩猩可以把人类像撕布娃娃一样的撕掉，但是人类并没有因为比大猩猩弱小而被大猩猩奴役。

让人类没有灭绝，而且成为万物主宰的是一种超过个体能力之上的一个东西，当然不同的人会给出不同的答案。我们人类在某一个单一的能力，比如说在计算能力上跟计算机来竞赛的话，那么人类是极其渺小的。但是我们并不能因此断定随着计算机的技术越来越发达，人类将会被淘汰。最重要的是人类跟计算机之间并不只是竞争的关系，同时它还有合作的关系。即使单从竞争方面讲，人类跟计算机的竞争必须是整体能力上的竞争，而不能是在单一功能、单一能力上的竞争。

控制论的创始人维纳写过一本书，叫《人有人用之处》，我们今天仍然可以把这个标题作为我们思考人跟机器之间关系的一个重要的启示。

机器的用处越来越大，但是人类并不因此而变得百无一用，这里头的关键就是我们对智能的定义。

可以这样说，我们在最强大脑里头看到的那些最强大脑，在与机器的竞争中差不多都会失败。比如说有一个选手，他面对48个可以变脸的川剧演员，这48个人轮番地上场变脸，在最后他还是能够按照主持人的要求，从这48个人里头找到其中的三位。这样的能力当然非常的了不起，但是如果用计算机来做的话那简直是轻而易举。

# 柳传志面对竞争的心法

柳传志在谈到竞争的时候，他说过这样的话，面对强大的竞争对手，你要想在竞争中取胜，你必须学会两者：

+   1. 改变游戏规则，你不能按竞争对手划定的游戏规则来与对手竞争，那样去竞争几乎是没有胜算的可能。

+   2. 是要选择竞争的环境。除了改变游戏规则，你还可以做一件事情，那就是改变竞争环境。

![](bbox=[0.18, 0.00166, 0.85, 0.0019])

他举了龟兔赛跑的例子，乌龟和兔子赛跑，最后乌龟竟然胜过了兔子，原因是兔子睡觉了。假如兔子不睡觉的话，乌龟还有没有胜算的可能性呢？柳传志说也有，比如乌龟可以选择在沼泽地里与兔子赛跑，

显然如果选择在沼泽地里头赛跑的话，兔子几乎没有胜算的可能。

柳传志的话对我们很有启发，人跟计算机如何去竞争呢？

首先是不要用计算机的规则，而要按人的规则来竞争。

第二，计算机之所以能够取胜，是因为它的环境是单一的，而人跟计算机最大的不同，是人能够面对极其复杂的环境，随机应变，审时度势。

有人说计算机已经强大到把人类顶尖的围棋高手打败的程度。围棋跟其他的棋类，比如说跟象棋相比，它要求棋手能够随机应变，而围棋跟象棋最大的不一样是围棋棋手在下棋的时候要面对的变数比下象棋要多的多得多。机器连围棋都能下，还有什么不能干的呢？

很多人都认为围棋代表人类智力的尊严，而人在面对AlphaGo和Master的时候败下阵来，就证明人类在处理复杂问题上已经比不上机器了。

这种说法其实是误解了复杂性，人提出来的场景的复杂性，是与人在下围棋的时候面对的复杂性完全不在同一个层面之上。

在这里我只说一个事实，专家们公认尽管机器下围棋已经胜过了人，但是目前为止最先进的机器人的智力只相当于4岁到4岁半儿童的智力，这听起来是不是很矛盾？当我们明白了人在生活当中所面对的场景的复杂性到底是什么的时候，我们就不会觉得矛盾了。

有一本书叫《清单革命》，它把世界上的事情分成了三种：第一种叫简单的事情，第二种叫复杂的事情，第三种叫超级复杂的事情。

+   1. 简单的事情，造汽车，是因为汽车尽管有那么多的零部件，但是这些零部件的数量，每个零部件的功能都是确定的，也就是说因为它是确定的，所以它是简单的。

+   2. 复杂的事情，造火箭，因为火箭零部件的数量，它所各个系统之间的协调、配合，以及它所要求的精确性，是与造汽车不可同日而语的，所以它是复杂的事情。

+   3. 超级复杂的事情，教育小孩。

为什么教育小孩儿是超级复杂的事情？为什么最聪明的机器人其智力也只相当于4岁半的小孩儿，甚至不如一个4岁半的小孩儿呢？这两个问题又跟人与计算机、与机器人的竞争又有什么关系呢？我们明天接着讨论。我们明天来详细讨论。
