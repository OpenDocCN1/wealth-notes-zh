# 什么叫幸？

按照《说文解字》的说法所谓幸就是吉而免凶也。本来可能会遇到的麻烦是不好的事情，你逃脱了，那才叫幸。凡应死而生曰幸，凡应生而死曰不幸。现代汉语当中仍然保留这个意思，比如说侥幸、幸存、幸免于难，这些都是说本来可能要遇到不好的事而你逃脱了，或者说本来不属于你的好事你得到了，这才叫幸。所以幸这个字里头本来隐含着一个意思，就是亏欠，或者说不配。你欠了债，但把你的这个债免除了；你不配，但是你得到了，这才叫幸。

有一个成语叫幸灾乐祸，它本来的意思指那种心态不健康的人，当别人遭遇不到不好的事情的时候，他自己感受到侥幸逃脱了，心里头有一种暗自庆幸的感觉。

# 幸与皇帝的关系

皇帝是高高在上的，他不到哪个地方是必然，到哪个地方是偶然，他偶然到哪个地方就叫做幸。

“巡幸”这个词就是指皇帝到了哪个地方，那是非常难得的，本来他不会到这个地方，他到了这个地方。

皇帝与某个女子同房，那也是一种偶然，所以把皇帝的这种行为叫做“临幸”或者“宠幸”。

幸福其实可以分成两类：

+   消极幸福
积极幸福

消极幸福，free from，免予什么……

人的很多的幸福感是来自于对灾难，对不好的事情的逃脱之后的感受，或者说是本不该得到，但出乎意料的得到了那样一种感受就叫做幸。

我们要获得幸福感就需要我们缩小自己的权力和资源的边界意识，觉得本该得到的东西你得到了，你是不会有幸福感的。所以曾国藩说，“每遇幸事，常念天之过厚于我”。他的意思是说，每当遇到好的事情的时候，他总是这样一种心态，这些东西本来不属于我，但是我得到了。

一个人的权力范围的意识越大，他的占有感越强，他的幸福感就会相应的减少，这就是说至少有一半的幸福是来自于我们的某种亏欠感，不配感，以及意外之喜。人的痛苦的根源之一是习惯性的将自己得到的东西认为是理所当然。其实我们只要有一点反省能力，我们就会意识到我们所拥有的这些基本上是不属于我们的。

北宋的哲学家张载有一句话叫“民吾同胞，物吾与也。”就是说老百姓，所有的人表面上跟我没有血缘关系的人，我都觉得他们是兄弟。所有我所得到的东西都是上天赏赐而来的。一个君子应该有这样一种心态。如果我们认为我们拥有的所有东西都是我们该得到，或者是由于我们已经拥有了它，我们就逐渐开始漠视它，轻视它，随着这样一种意识越来越明显，我们幸的感觉就会越来越少。
