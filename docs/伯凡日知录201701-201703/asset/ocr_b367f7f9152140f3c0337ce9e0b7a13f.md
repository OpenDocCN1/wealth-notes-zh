# 本周问答 | 人是生态中极其特殊的变量

本周问答 | 人是生态中极其...

Mr. Du: 想请问老师，为何狼作为个体能力和合作能力都很强大的物种，为何最终无法赢得生态竞争的胜利？是因为人类这个物种太强大了？还是有其他的原因？

吴伯凡

首先应该说是因为人太强大了，人是在整个生态里头，是一个极其特殊的变量。

随着技术的发展，人类对周围环境的干预能力越来越强的时候，人类的生存空间越来越大。这也 hồng即是生态作为一种无形的自然的自我调节的一种力量，跟人类相比，显得很弱了。这个时候，整个自然界就逐渐失去了平衡。如果没有人类出现的话，狼在这个地球上它一定是一个非常强大的物种。但是即使它很强大，它还是有一种力量在抑制它，这就是它所处的食物链的位置，它是纯粹的食肉动物。

我们很早以前就听说过有一个比例，就是十比一的比例，就是食肉获得的这个热量，你吃的这个肉要耗掉的植物是你这个热量的10倍，就是它有一个百分之90%的损耗率。所以越处于食物链高端的动物，它的生存的风险就会越大，所有的动物甚至植物都有捕食能力，羊也有捕食能力，它捕食的是草。狼它是能捕食羊的，相来来说你的捕食能力越强的，你就越处于食物链的高端，越处于食物链的高端，也就意味着你的食物来源的风险就会很大。

比如说像大象这样的体型庞大的动物，它如果选择高端的食物链的话，它的生存风险就会非常大。所以它只能选择食物链低端的，它选择去吃植物。狼的凶猛不仅仅是作为个体的凶猛，而且是作为一个团体的凶猛，使得它获得了高超的捕食能力。但是，这个捕食能力也会无形当中把它绑架到一个很危险的位置上。碰巧的是，早期的类跟它又处于同样的生态位。尤其是冬天的时候，人是杂食动物，但是在冬天的时候，他找不到什么植物来吃的时候，他只能选择去捕食动物。本来冬天基本上所有的植物都冬眠了，大部分的动物也冬眠了，这样这两个物种一下子处于一个强烈的对持状态，在这种对持状态下，因为人类有一个除了自然进化之后，他有一个叫文化进化的能力，比如说当一种武器发明的时候，人作为一个物种的捕杀能力就一下子产生了一个飞跃，而狼它没有办法在捕食能力上实现一个飞跃，它的能力一直被固化在这个状态，这个时候它在与人的竞争当中狼就会节节败退。人对生态的破坏，有时候连人自己都没有意识到。

很多年前，我听一个朋友从东北做调查研究回来告诉我，他在调查鄂温克族人的生存状况。鄂温克族人以养鹿为生，当鄂温克族人处于一个封闭的状态里头，他们跟他们的环境之间有一个很和谐的，一个相对稳定的状态。后来，汉族人去了那个地方，就告诉他们，鹿的刚刚长出的那个角叫鹿茸，是可以卖钱的。这个变量一旦进来，就引发了一个非常大的变化，那就是每年春天，当鹿长出鹿茸来的时候，他们就把那个鹿茸锯掉，它作为一种名贵的中药材拿到市场上卖很多钱。这些雄鹿们就不再有角了，没有角的结果是什么呢？每年春天的这个鹿王大赛就没办法举行，因为所有的雄鹿由于没有角的话，它没办法展开实质性的竞争，它们不能用角来打仗的时候，只能用身子这样撞来撞去，这样是很决出一个胜负出来的。

原米通过一次一次的淘汰赛就会选出一个鹿王来，它就拥有了与整个鹿群里的母鹿的交配权。这就意味着这个鹿群的基因一定是最优的。如果来年春天，再进行比赛的时候，这个鹿王打不过，被新的雄鹿给打下去，它就永远地丧失了交配权，这个鹿群里头又获得了新的最优化的基因。铁打的营盘，流水的鹿王，它就能够保证这个鹿群的基因总是处于最好的。当雄鹿们没有角，没法进行实质性的竞争的时候，一场灾难就悄悄地出现了。一个很自然的结果就是，几乎每一头雄鹿都有交配权了，再怯的雄鹿也能够跟人类社会一样，拥有那种类似于一夫一妻的生活。这个在自然竞争当中是不允许的。几年下来，鄂温克族人的的确确通过卖鹿茸赚到了很多钱，一个他们意想不到的结果是，他们的鹿群的质量越来越差，越来越爱生病，有时候甚至是一场瘟疫，整个鹿群都死掉。

当然，他们只是后来才意识到，正是因为人类爱钱，而采取了一种极端化的指向性极其明显的措施，而导致了整个生态系统当中因为指向的模糊而自然产生的那样一种平衡，被人类给打破了。

从狼这个强大的种群濒临灭绝，以及从鹿群的质量的退化，都能看出来，只要人的因素加进来，整个生态就一定会出现失衡。

我们说狼的生态竞争力很强大，是排除了人的这个因素的。反过来，你把人的这个因素加进来之后，所有的生物是很难安宁的平和的生存和繁衍的。人类的技术的进步的节奏越来越快，那些其他的物种的生存能力是在漫长的进化过程当中由基因决定的那样一种能力，是没办法跟人不断升级的能力相抗衡的。这让我想起当年马云跟王健林对话的时候说的一句话：“传统零售和电子商务之间的差别不是南拳和北腿的差别，不是少林和武当的差别，是武术和机关枪的差别。”

由于人类的进化除了基因进化之外，还有一个文化进化，这样一个因素，使得整个自然的生态就不再是平衡的了。

还有一个反面的例子，就是切尔诺贝利核电站的例子，在1986年，前苏联的切尔诺贝利核电站爆炸，导致当地的居民不得不迅速地撤离那个地方。在大约过了26年以后，人类再进去看的时候，发现那个地方的生态非常的好。狼群们在城市的街道上到处游达，窜到这个屋子又窜到那家屋子。有的鱼长到一百多斤重，这些鱼并不是因为受到了核辐射而长这么大的，是因为长期没有人去捕鱼，导致一些鱼没有天敌，他们用26年的时间长身体，所以能长到一百多斤。最后有人惊叹，这么一个因为人类的失误而导致的巨大污染的地方，仅仅是因为人有二三十年没到那个地方，它就成了一个伊甸园式的地方了。当然那个时候还是有很多的辐射的。

这个例子说明什么呢？就是人类的力量的干预最终的结果是在所谓的无所不能当中悄悄地把一个管理者给罢黜了。这个看不见的管理者被罢黜掉以后，这个世界实际上是处于一个失控的世界。表面上是人类能够控制的，实际上它已经没有一只巨大的看不见的手在打理这个世界。最终的结果是，人出局。但是，从更长远的角度来看，这也是生态的一种力量，就人出局也是生态反应的一个部分。当人被清理出去以后，这个世界又很快地回复到一个自然的平衡当中。
