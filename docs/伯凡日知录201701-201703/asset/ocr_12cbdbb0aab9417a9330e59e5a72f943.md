# 现在的节

我们过去过节是团圆，是往家走，现在过节是往外走，我看所有的人现在开始一旦要过节就是问你到哪里去玩儿，古人觉得这是不可思议的事情。因为古人有很强烈的共同体意识所谓团圆就是聚合在一起，深化、强化我们的共同体意识，让我们意识到我们不是一个人，我们是一家人、一族人、一国人，是这样的一种状况。而今天我们是节日越来越个体化、越来越自由化、越来越娱乐化，还有越来越消费化。以前曾经讲到过现代节日的消费化或者说消费主义化，最典型的是情人节，当然在我们中国更典型的是光棍节，所有的节日说白了在今天都有一个共同的名字叫“购物节”。

# 情人节的由来

情人节是西方人发明的，准确地说就是美国的一个卡片商发明的，因为他们在圣诞的时候多印了很多的圣诞贺卡，没想到那一年大家买圣诞贺卡的热情不太高，我们知道这种节日贺卡其实是一个最典型的无效存货，一旦时间过去它就根本不值钱了，你不可能把今年的圣诞贺卡存放到第二年，它一旦变旧是没有任何意义的。所以美国的这家贺卡商要求他底下的员工，你们必须要在一个半月之内把这些贺卡给卖出去。

大家想想贺卡可不是柴米油盐，它是在特定时间消费的，圣诞过后我怎么跟别人去推销圣诞贺卡，老板说那你们想办法，我不管。这些下面的还真能想办法，他们决定有节日要过，没有节日创造节日也要过，老板下令一个半月，大家知道2月份只有28天，也就是说在2月14号以前如果我们不把这些贺卡全部卖出去的话，那就意味着我们全部要被炒鱿鱼，所以他们就是急中生智，就翻历史书，就找了一个据说叫圣瓦伦丁的人，我要如何跟一个少女有火热的恋情，在中世纪那种禁欲主义氛围下如何追求爱情等等，他们就拼命地在报纸上炒作，这些年轻人过完圣诞以后觉得自己还可以过一个属于自己的节日，一个私房的节日，所以他们就相信那一天2月14号，那个其实是一个销售的截止日期Deadline，说那一天就是情人节，大家就开始买。结果后来一下子卖掉了很多贺卡，还有一些搭便车的商家卖玫瑰花、卖巧克力的也搭上这个便车，也卖了不少东西，这样他们形成了一个共识，说我们第二年再来，我们一定要强化这样一个节日，这有利于提高我们的销售额。所以也就渐渐渐渐的有了一个节日，后来也传到我们中国，我们的青年男女也开始痴热闹，去买各种各样的东西。

![](bbox=[0.12, 0.0015, 0.88, 0.00175])

现在的三八妇女节也基本上变成一个叫母婴用品、妇女用品促销节，然后是每个儿童节，所谓的儿童节就是儿童用品的一个促销节。后来在国庆10月到元旦之间中间是有 一个巨大的空档，因为这里头找不到节日，三个月一季度没有促销日，那是一件很恐怖的事情，对于商家来说。在差不多十年以前，中国的那些零售商们不约而同地编一个故事，说他们的商场都是在某年的11月份开业的，因为在10月和12月之间因为他们找不到一个促销日，只好说多小孩周年店庆。

我曾经也很搞不明白为什么那些商场都选在11月份开业，其实它只是一个故事，但这个故事说实话比较低级。后来就出现了一个特别会讲故事的人，那就是马云。他利用了本来是一个很搞笑的说法，就是这些IT男有几个特点，第一个整天上网，他们是互联网上的主力军，虽然在总人口当中的比例并不大，但是在网民当中他们的比例是很大的，最重要的是他们爱在那发言，他们有的是时间，因为是光棍，所以话很多，所以在网上聚到一起说各种各样的事情，为此他们就逐渐地形成了一种叫做想象的共同体，就是光棍们是一种想象的共同体。只要有想象的共同体，他们一定会有节日的，正好11月11号全是看四个光棍合在一起，1111四个光棍合在一起，这一天应该是最能够体现光棍的，据说还有小光棍节，1月1号、1月11号是小光棍节，大光棍节就是11月11号，本来这是一个半开玩笑的说法。但是阿里巴巴找到了这个故事里头的商机，他们就把这么一个光棍节作为网民主体的光棍们的一个节日，变成了一个购物节。

现在的节日基本上就是一个购物节，老百姓的口袋里都钱再多一点的时候，当然他们不仅仅是购物，他们要购买另外一种东西，就是风景，其实是购买各种照片。到了过节的时候最重要的是花很多钱换很多照片，在朋友圈里头晒，今天的节日跟古代的节日已经很不一样了，当然节日从回家的日子逐渐地变成了离家出走的日子，顶多是集体离家出走的日子，这是我们今天早已经不再是农业社会的社会里头一个正常的演变。

# 节的提醒

过一个真正的节，回顾一下节日它的本来意思：

首先，节日是一种命令，它告诉我们到了哪一个时间节点，在这个节点上我们该干什么样的事情。

第二，节日意味着共同体，也意味着团聚，不仅仅是空间上的团聚，而且意味着时间上的团聚，不仅仅是人与人的团聚，而且是人与天、人与地、人与神、人与自己的列祖列宗，所有这些东西的团聚或者说在团聚当中对这种共同体的深刻感知。

第三，腾下少一些购物的时间，少一些汇入到旅游洪流当中的时间，给自己、给家人多留一点时间，不要让节日成为平常日子一个简单的延续，而是要让自己在这样一个时间节点上，在平常的日子体会不到的一种独特体验，那才叫过节。
