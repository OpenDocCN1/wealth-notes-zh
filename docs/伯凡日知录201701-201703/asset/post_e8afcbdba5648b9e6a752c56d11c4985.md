
# 福

福的右边的那个字“畐”也念fū，它本来意思是指人的腹部，也就是我们的肚子。

畐下面有一个田字，但是它不是指田，而是指肚子充满、充实的一种状态。口字里头那个十字就是代表充满，充实之意。

与福字同源的两个字：

富，富贵的富的下面与福字的右边是同一个字，指的就是充满充实的意思。

备，准备，它的意思同样也是指充足和充满的意思。

如果说幸福的幸是一种因为逃脱了灾难免于不幸之后的那样一种感受的话，那么福是指由于我们的愿望，由于我们的祈祷，上天把一种东西赏赐给我们，所以福的这个字，它本来意思就是指来自于上天，来自于神的赐予和赏赐。

与福相关的一个字是佑，它的意思是来自于上天的护卫，上天的保护，这就叫佑。

# 右为尊

座右铭，是古人为了勉励自己，把一句非常重要的活刻在他座位的右边，时时刻刻在提醒自己。

无出其右，就是说没有一个人比这个人更厉害，没有一件事比这件事情更重大，所以叫无出其右。

加了单立人以后的左和右，它们的意思也是有明显差别的。佐是辅佐，佑是护佑，是保佑，是自上而下的赏赐给你的一种东西。

今天人类已经进入到一个相对富足的时代，由于我们拥有了这种富足感，我们常常会对我们所拥有的东西视而不见，或者是比较忽视，比较轻视的状态。爱因斯坦在他的一封信里头说，“我所吃的食物，我所使用的物品没有哪一件是我自己做的，我甚至都不知道它们是怎么来的，每想到这一点，我的心里就有一中强烈的收缩的不安，我只能通过辛勤的劳动来驱散我心中的这样一种不安。”拥有这种心态的人，他每得到一点点东西，他自己心里头都会有一种类似于曾国藩所说的“每遇幸事，常念天之过厚于我”。

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_45_0.png)

在鸡年来临之际，我真诚地祝愿大家拥有越来越多的幸福感，而要得到幸福，要拥有幸福感，首先我们要学会减少自己的拥有感和占有感。当你意料的东西越少，你所获得的意外之喜也会随之增加。与此同时我们要意识到福是我们真诚的期待和劳动的结果。

《左传》里有一句话叫“小信未孚，神弗福也”。当人不能够一点一滴践行自己的信用，恪守诚信的时候，上天是不会将富有和完备降临到你身上的。我们要学会珍惜那些看似免费的东西，很多所谓的免费的东西不过是我们幸运的免除了成本和代价的东西。其实它们很可能是相当珍贵的。

我们一直以为空气是免费的，但我们今天已经意识到空气，新鲜的好的空气并不是免费的，只有到我们今天天天吸雾霾的时候才意识到空气并非免费的。

我们的身体是免费的，我们在出生的时候我们拥有了身体，但我们并没有花钱。身体最好的状态就是让我们意识不到它存在的状态，当我们意识到某个器官的存在就意味着某个器官出问题了。

每一个器官都是免费的，但它并不真是免费的。什么时候我们知道它是不免费的，知道它是有价格了的呢？这就是在它出问题的时候。人只有到医院以后才知道器官是不免费的。

所以我们要珍视所有那些看似不免费的，但实则非常珍贵的东西，比如说空气，比如说我们的身体，比如说亲情，比如说来自父母的，来自长辈的关爱。

真诚地祝愿大家在鸡年里幸福安康！

伯凡日知录的同学们，大家春节幸福、欢乐。

今天仍然是伯凡日知录春节特别课程当中的一课。我们今天要讲的关键词是欢和乐。

欢

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_46_0.png)

我们今天看到的欢这个字是个简体字。繁体字里头，欢左边是一个蕖，右边是一个欠。

蕖，坍坍罐罐的罐和灌溉的灌的右边这个字，它本来的意思是装满了东西，将它倒出来，将它注入就叫做蕖。比如说灌溉、灌注。蕖的本义是很充分，很丰富的东西，将很丰富，很充分的东西浇灌在，灌注在另外一种东西上头。

欠跟蕖是对应的，一边是很丰富的，一个是很欠缺的。当很丰富的东西跟很欠缺的东西相遇的时候这就叫欢。欢的本义，本来是指男女交合之时，男女交合之为欢。就是充满的东西和欠缺的東西的相遇。所以在古代女子把自己所钟情的男子称为欢。“闻欢下扬州，相送楚山头。”这里头的欢就是这个意思。

乐

![](img/f47a5fb2d99d8b2557309e5ada0c8e7e_46_1.png)

繁体字的乐下面是一个木头，它代表着木头架子。古代在举行各种宗教祭祀活动的时候，用大大小小的鼓。大鼓叫鼓，小鼓叫皮。这些鼓和皮放在木头架子上，把这些大大小小的鼓放在木头架子上，发出响声，那叫乐（le）。所以中国最早的乐其实是打击乐，钟鼓鸣之是打击乐。这个乐就是指木头架子上放着大大小小的鼓，简单地说是一种乐器。所以在汉语里头乐（le）和乐（yue）是同一个字。换句话说，中国的古人是从乐（yue）的意义上来定义乐（le）的。

那么乐（yue）是什么呢？所谓乐（yue）就是天地之和，阳的和阴的，天和地，乾和坤之间的那种和，和谐就叫做乐（le），也是乐（yue）。而表达这种状态的声音就是乐（yue）。所以无论是欢还是乐，这两个字里头都各自包含着两个要素，一个是阳的因素，一个是阴的因素。一个是施的因素，一个是受的因素。一个是阳，一个是阴。一个是施，一个是受。在中国古人的心目当中，欢乐就是两种因素的结合和和谐。

不欢或者不乐，也就意味着两种因素，一阴一阳两种因素之间的不结合或者不和谐。

有很多的认为我们中国人是缺少音乐细胞的，高晓松认为中国的音乐只存在在中国 的疆域的边沿，那些少数民族那里。汉族人的乐感，在音乐上的天赋很低，这种说法其实是有点可疑的。中国古代文化与其他文化相比，有一个很独特的现象，就是将音乐提高到宗教的程度。当然，音乐也的确确实是脱胎于宗教。

我们中国传统文化当中提到的六经，就是指诗书礼易乐春秋。六经当中关于音乐的乐经是其中的经典之一。

儒家讲兴于诗、立于礼、成于乐（yue）。乐是最高的状态。儒家教育的过程首先是读诗，然后是要教你各种各样的礼，最后的状态是乐。这个乐是什么？乐就是旋律、节奏，一种隐秘的和谐和次序。所以孔子把乐（le）的状态，也就是乐（yue）的状态作为他心目当中理想的人生状态。

有一次他对他的几个学生说，你跟我们讲将你们的志向。这个学生讲他将来如何领军打仗，如何治理国家。最后有一个学生说，“我跟他们都不一样，我的志向就是在暮春时节，穿上春天那种轻便的衣服，约上五六个成年人，六七个小孩，在沂水河里头洗澡，在舞雩台上吹吹风，最后一路唱歌回到家”。“我同意曾点的观点”。

孔子对他人生成长阶段有一著名的概述，“吾十又五有志于学，三十而立，四十而不惑，五十知天命，六十而耳顺，七十从心所欲不逾矩。”从心所欲不逾矩是他人生的最高的状态。要随心所欲，同时又不逾越规矩。这就是音乐的状态。音乐一方面是对人内在情感的尽情的抒发。它又是符合规矩的，是符合乐理的。音乐是欲望与规则天衣无缝的结合。只有达到那种欲望与规矩密切结合，而且很和谐的那种状态，你才成为一个真正的儒者，也就是成于乐。

回过头来我们再来看欢和乐。我们经常说两个人相见交谈甚欢。交谈甚欢其实是指两个人的思想、语言、气场的极度的契合。在这种契合里头你能感受到一种欢的状态，也是一种乐的状态。二者之间既有差别，又能够和谐相处，相映成趣，这才叫欢乐的状态。

伯凡日知录的同学们，新年快乐。祝愿大家在新的一年里幸福、欢乐，内心充满喜悦。

# 吉

吉这个词上面是兵器，下面是盛放兵器的器具。

兵器盛放在器具当中就意味着战争的止息，没有危难。一个国家要想立足是离不开兵器的，但是最好的状态是有兵器而不用，把它盛放在那个地方。

在《道德经》里头老子是这样说的，兵者不祥之器。还有一句话叫国之利器不可示于人。他说的意思就是，兵器是万不得已才使用的东西，而它本身是不祥的。

祥，是你有这个东西，你不靠这个东西，不滥用这个东西。一个国家老是把武器拿出来展示，那是不祥之兆。就国之利器不可示于人，这当然符合老子一贯的观点，圣人有而不示，拥有一个东西，不靠那个东西。功臣而不居，有功劳但是不居功，只有这样的状态才叫吉。

没有兵器的状态也不叫吉，吉不是没有兵器，没有兵器你就会受到摧残，遭到毁灭。兵器最重要的，最完美的功能就是放在那儿，这种状态就叫吉。所以在中国古代文化中，吉的反面是凶，凶这个字是指一个陷阖塌陷，人掉在了一个陷阱里头。和凶相关的字叫咎，咎由自取的咎，上面是个处，下面是一个口，也是指一个人被迫处在一个塌陷的陷阱里头，那 siis叫咎由自取。

简单地说，吉就是有武器不用，放在一个装武器的容器里头。而凶就是人掉到了一个和器具有点像的陷阱里头，这就叫凶恶。在汉语里头有一个字与吉密切相关，那就是祥，吉祥。

# 祥

祥的本质就是羊，在中国文化的初期就 有一种对羊的崇拜。我们中国文化当中最好的一些字都跟羊有关，比如说真善美，这三个字里头，善和美都是跟羊有关的，上头都是一个羊。可见在中国文化当中，正面的东西，文化是美还是善，它都是跟羊有关。

根据专家考证，在我们的上古时期，我们的祖先是把羊作为图腾的，在十二生肖当中，羊跟其他动物最不一样的东西就是它的温顺。而一个氏族，一个部落，一个民族以某种动物为图腾，就意味着一种认同感。当我们的祖先以羊为图腾的时候，也就意味着我们的祖先对羊这种动物有一种深切的认同。

羊这种动物最重要的特点就是它缺乏攻击性，它总是造福于人的。这可能意味着我们的祖先饲养羊的历史非常悠久。在汉语当中还有一个跟羊有关的字，那就是祥。我们从吉祥的祥，安祥的祥，美和善里头都能找到某种共通的东西。我们这种共通的东西可以用善来概括。

在美、善、祥这三个跟羊有关的字里头都有一个共同的含义。我们能隐隐约约感受到这样一种东西，它跟美好有关，跟善良有关。在吉这个字里头，我们也能感受到这样一种含义。

前面已经讲到，所谓吉就是将兵器盛放起来，不用。兵器是一种必不可少的在万不得已的时候需要使用的一种东西，但在更多的时候，我们是要把它盛放起来。《孙子兵法》里头有一个核心的思想，和平是战争的最好的状态，不战而屈人之兵，善之善者也。不崇尚暴力，拒绝残忍，在绝大多数的时候将那种代表着暴力和残忍的兵器藏而不用，这是吉这个字最重要的含义。

# 亚马逊的管理智慧

当我们在品味吉和祥这两个字的时候，我就想到亚马逊的创始人贝索斯的那句名言，善良比聪明更重要。聪明不能告诉你最好最好的答案，但善良可以告诉你，当你面对客户的时候，你使用各种聪明，你都不可能找到最好的解决之道。但是当你抱着善待客户这样一个不变的宗旨的时候，你总能找到最好的解决之道。所以贝索斯开董事会的时候，他总要把董事长坐的那个座位，他应该坐的那个座位空出来。那儿摆着一把空椅子。贝索斯说，我们永远要记住这张椅子上坐着的是我们的客户。当我们在指定一个战略，设计一个商业模式的时候，只要你始终把客户放在首位，你总能找到最佳的解决之道。但是如果我们仅仅是用自己的聪明，甚至是用自己的聪明去对付客户、去制服客户的时候，我们已经离最佳的解决之道很远很远了。我们在处理客户关系，处理人际关系，处理各种各样的社会关系的时候，我们最好是采取一种以不变应万变的方法，方法 Controllers 核心就是善良。

《道德经》里说的，上善若水，水利万物而不争。善就是利万物而不去争，利万物而不与万物去争利，最终你会创造最大的利益，最大的价值。

《菜根谭》里有一句话叫“福不可邀，养喜神以为招福之本。祸不可避，唯去杀机以为远祸之方。”去杀机就是，吉，我们已经看到吉这个字就是去杀机。而祥这个字就是养喜神。如果一个人的心中暗藏杀机的话，他一定会有飞来横祸；而当你内心充满喜气的时候，祸事会绕道而走，而福会不期而至。

在新的一年里头，我真诚地期望大家在新的一年里吉祥平安。而要做到吉祥平安，就是不要忘记善良比聪明更重要，就要学会养喜神去杀机。

在此祝大家新春愉快。

# 喜

关于喜这个字有几种解释，比较权威的解释，喜上头的这个字是敲锣打鼓的鼓的本字，而这个鼓字就意味着欢乐，我们前面已经讲到中国古代的乐（le）跟乐（yue）是同一个字，而最早的乐是鼓乐，或者说中国最早的乐器是作为打击乐器的鼓。所以这个鼓就代表着吉庆、代表着欢乐，而当心理产生了欢乐之情的时候，人就会把这种情绪表达出来，喜的最初的意思就是欢乐之情脱口而出，所以它下面是一个口字。简单地说喜就是内在情绪的外在表达，有一个成语叫喜形于色，还有一个成语叫喜出望外，当一种欢喜、欢乐的情绪超乎了我们的期望的时候，我们就会大声地叫出来，这叫喜出望外。当然也有人解释说，喜跟吉有关，因为喜字的上半部分是一个吉字，但不管是哪一种解释，喜都跟我们前面讲到的幸福、欢乐、吉祥有关，尤其是跟欢和乐密切相关，所以汉语里头也有欢喜、欢乐、喜乐这样的词。

我们在昨天讲到吉祥的时候提到了《菜根谭》里头的一句话，福不可邀，为养喜神以为招福之本，祸不可避，为去杀机以为远祸之方。什么叫喜神呢？在中国文化当中神这个字既指外在的某种力量，同时也指内在的某种能量。人的内在的能量分为三个层次，精、气、神，相对于说精是比较接近于物质状态的。在精字上是气，繁体的气字下面有一个米字，它是指我们获取的这个外在的，像我们吃的东西里头进入到我们的身体以后转化成的一种能量，比如说我们的身体气血不足，我们有什么食品是补气的，这个气其实就是能量。所以我们中国古代的经典译成英文的时候，学者们常常把气这个词译成能量，叫energy。当然西方也有一些学者认为气这个词不可翻译，直接用气的汉语拼音来指代气这个概念。精、气，最高的状态是神，这个人的眼睛很有神，就是指这个人的眼睛里头有一种至精至纯的能量，如何达到神这种状态呢？最重要的方法就是壹，这个壹就是繁体字的壹，用志不分，乃凝于神，当你的意图、当你的精神的指向凝聚成一点的时候，你就能达到神的状态。那么所谓喜神就是那种正向的、欢乐的、吉祥的心态，就是我们的心志长期地聚焦在欢乐、吉祥上，我们就能达到一种叫做喜神的状态，它是一种比我们通常所说的喜气更高的一种状态。

# 聚精会神

我们有一个成语叫聚精会神，你只有把你的内在的能量聚集起来，最终你才能跟神，跟你的那个最纯净的能量相会，那种东西叫做神。我们说一个画家，他画一个东西的时候非常传神，也就是将一种内在的能量、内在的力量能够传达出来，如此说来喜神是一种非常珍贵，因而也是很难达到的一种状态和境界。喜跟我们通常所说的欢乐的状态、高兴的状态还不太一样，我们高兴常常是因为为什么东西而高兴，我们欢乐常常是因为为什么东西而欢乐，而这个喜神可以说是一种无特定对象的一种正向的心理状态。可以说它首先是一种习惯，是长期的正向状态形成的一种习惯，一种自内而外的无特定对象的或者说是针对所有对象的那样一种喜悦的状态。

有一个心理学家在研究了，在做了大量的样本研究以后得出一个结论，我们通常说的好运气、坏运气，常常是带有一点点迷信的色彩。这个人很顺利是因为他的运气好，那个人不顺利是因为他的运气差，他的结论是那些常常遭遇坏运气的人，并不是有一种固定的处境笼罩着他，而是因为他的心理状态和行为模式是处于一种消极的负面的状态，面对问题他不是习惯于正面的期待，而总是习惯于用一种负面的方式看待和对待眼前的的人和事。而这种微妙的心理状态他具有一种感染力，会影响到他周围的人和事，这些周围的人和事会作为一种环境又反射回来，又会加剧他的行为和心态的负面程度。如此他的这种负面心态和行为形成一种正反馈，所谓正反馈就是一种状态会引发另外一种状态，而另外一种状态会反过来加剧这种状态，不断地循环，使得抱有这种心态的人越来越相信自己的判断，持有这种行为状态的人，他的行为模式就越来越缺乏建设性，越来越禁锢他自身能量的发挥。所以这个研究表明坏运气并非是一种神秘的东西，而是由人自身的状态引发的一种正反馈。我们常常听到这样的说法，Dependency...

新的一年已经到来，在中国人的信念当中鸡跟吉同音，我们都期待鸡年对于我们来说是吉祥的一年。在过去的2016年，我们目睹了许多黑天鹅事件，也许2017年又是一个充满着挑战、充满着不确定性的一年。面对这样一种客观的环境，我们应该做的和能做的也许就是和气以致祥，让我们内心多一份和气，也许我们的内心多一份和气，我们所处的环境也会悄悄的有所改变。还是那句话，养喜神去杀机，静由心生，我们自身的状态也许就是我们所处环境的最根本的原因。

# 本周预告 | 成见就是认知中的 “快捷方式”

本周预告 | 成见就是认知中…

本周的《伯凡·日知录》从几个德国科学家曾经做的一个实验说起。

科学家们铺出两块人造花田，也就在两块相邻的田里分别插上黄色和蓝色的塑料花，前者涂有花蜜，后者没有。随后，他们就在两块田旁边放飞蜜蜂。

刚开始的时候，蜜蜂在两块田上均匀分布，但很快，蓝色花田里的蜜蜂就意识到蓝花上没有花蜜，纷纷飞离这些蓝花。同样 的过程重复几天以后，就再也没有蜜蜂飞到蓝花上了。随后，科学家在蓝色塑料花涂上花蜜，而黄色塑料花上没有。结果是，蜜蜂仍然飞向黄色花田，而将蓝色花田弃置不顾。接连几天下 来，蜜蜂痴心不改，一直飞到黄色花田上，直到大量的蜜蜂饿死在黄花田里，虽然旁边的蓝色塑料花涂满了花蜜。蜜蜂以它们的生命，为它们的成见买了单。

成见并不一定就是坏事，拥有成见可以说是一种生存技能。如果我们面对新事物、新场景时，不能用已经获得的认知来判断和决策，那生命将因为缺少起码的效率和品质而举步维艰，甚至寸步难行。

所谓成见，用一个我们熟悉的计算机术语来说，就是我们在认知中建立“快捷方式”，或者说是一种认知上的“无障碍通道”。我们的阅历越多，这种“快捷方式”就越多，正是凭借一个个不假思索的快捷方式，我们活得越来越有效率，有一些时候，也活得越来越有品质。

但这种快捷方式也是暗含着危险的，就像我们在蜜蜂的实验中看到的那样。如果人的心智模式中充斥着各种各样的快捷方式，人的心智和感觉就会在不知不觉中被控制，被程序化。在生活中，在商业实践中，这种快捷方式几乎无处不在。

比如说，所谓品牌，就是商家、媒体通过精心设计的程序在我们的头脑中建立他们所期望的快捷方式。在传统宗教的势力越来越式微的今天，各种产品和品牌拜物教此起彼伏，它们的目 的只有一个，让人们的头脑中植入各种无障碍通道，尽可能屏蔽同类选择，让你在别无选择中做出选择，并且让你自鸣得意地感受到这是你自己做出的选择。
