# 参考答案

已知：**Y** = 800，**V** 不变，  
　　　**M** = $2000，**P** = $5，2008年  
2009年，美联储货币供给增加5%，增加到2100美元

+   **a.** 计算2009年的名义GDP和P，并计算从2008年到2009年的通货膨胀率

名义 GDP = **P** × **Y** = **M** × **V**（数量方程式）  
　　　　　　　= $2100 × 2 = **$4200**

**P** = \frac{**P** × **Y**}{**Y**} = \frac{$4200}{800} = **$5.25**

通货膨胀率 = \frac{$5.25 - 5.00}{5.00} = **5%**（与货币供给增加的比例相同！）
