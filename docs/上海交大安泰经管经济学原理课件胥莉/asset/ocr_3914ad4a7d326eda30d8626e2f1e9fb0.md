（2）对于厂商A，低价格是占优策略。因为：

+   - 当B选择低价格时，A选择低价格的利润（30）比选择高价格的利润（20）高；
+   - 当B选择高价格时，A选择低价格的利润（70）比选择高价格的利润（60）高；

因此，无论B选择什么策略，A选择低价格总是最优选择。

对于厂商B，低价格也是占优策略。因为：

+   - 当A选择低价格时，A选择低价格的利润（20）比选择高价格的利润（10）高；
+   - 当A选择高价格时，A选择低价格的利润（50）比选择高价格的利润（40）高；

因此，无论A选择什么策略，B选择低价格总是最优选择。
