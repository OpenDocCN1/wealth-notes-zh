

## 沉没成本的无关性

- **沉没成本：** 已经发生而且无法收回的成本
- 沉没成本应该与决策无关：无论你做怎样的决策，你都必须支付它们
- 固定成本是一种沉没成本：无论企业决定生产或停止营业，都必须支付固定成本
- 因此，固定成本的大小不影响做是否停止营业的决策

## 完全竞争市场的短期均衡

- 完全竞争企业短期均衡时的盈利状况
  - P>AC： Π>0盈利
  - P=AC： Π=0利润为零
  - P<AC： Π<0亏损
    - AVC<P<AC： 亏损但会继续生产，因可收回全部VC及部分FC
    - P<AVC： 亏损并停产，因连VC都无法得到全部补偿
      - P=AVC： 短期停产点

## 企业的短期停止营业决策

- 如果生产能得到的收益小于生产的可变成本，企业就停止营业。
  - 如果 TR < VC，停止营业。
  - 如果 TR/Q < VC/Q，停止营业。
  - 如果 P < AVC，停止营业。

## 完全竞争市场中企业短期供给曲线

- 供给曲线是每一个价格水平上企业愿意而且能够提供的产品的数量的轨迹。
- 它表示短期内企业最有利可图（或者亏损最小）的产量水平与产品价格之间的关系。
- 供给曲线上每一点均为对应市场价格的利润最大或亏损最小的产量点，即均衡产量点。
- 在完全竞争市场中，随着价格的变动，企业实现利润最大化要满足MC=MR=P，即均衡的产量点总是在边际成本曲线上变动。
- 企业的短期供给曲线是位于AVC曲线最低点以上部分的MC曲线（P>AVC）。
- 注意：竞争性企业的供给曲线和短期边际成本SMC曲线并不完全相同。

## 完全竞争市场中行业的短期供给曲线

- 一个行业（市场）的供给曲线由该行业内所有企业的短期供给曲线的水平加总而得到。
- 行业的短期供给曲线是向右上方倾斜的，表示市场的产品价格和市场的短期供给量成同方向变动。
- 行业的短期供给曲线上与每一个价格水平相对应的供给量可以使全体企业在该价格水平获得最大利润或最小亏损的最优产量。

## 企业进入或退出一个市场的长期决策

在长期中，如果从生产中得到的收益小于生产的总成本,企业就退出。

- 如果 TR < TC，就退出。
- 如果 TR/Q < TC/Q，就退出。
- 如果 P < ATC，就退出。

如果一种行动将有利可图，企业就将进入一个市场。

- 如果 TR > TC，就进入。
- 如果 TR/Q > TC/Q，就进入。
- 如果 P > ATC，就进入。

## 带有细胞类型检测和定位的整体切片图像分析

本项目专注于开发用于整体切片图像（WSI）分析的深度学习解决方案。该系统在大型病理图像中检测并定位不同类型的细胞，为病理学家在诊断和研究中提供有价值的帮助。利用最先进的目标检测模型，该解决方案处理高分辨率的整体切片图像并识别各种细胞类别，包括炎症细胞、上皮细胞和其他生物结构。

### 数据集描述

数据集由来自多个医疗中心的 50 张组织样本整体切片图像（WSIs）组成。每个 WSI 都标注了不同细胞类型的边界框。切片以 40 倍放大倍数扫描，生成的图像约为 100,000 x 100,000 像素。为了提高训练效率，切片被分割成 512x512 像素的小块。

### 细胞类型及分布

| Cell Type | Number of Annotations | Percentage |
|-----------|----------------------|------------|
| Inflammatory cells | 45,230 | 62.5% |
| Epithelial cells | 18,450 | 25.5% |
| Stromal cells | 6,820 | 9.4% |
| Other cells | 1,880 | 2.6% |

### 方法

- 1. **Patch Extraction**: 每个 WSI 被分割成 512x512 的块，重叠率为 25%，以确保细胞覆盖完整。
- 2. **Model Architecture**: 我们采用基于 ResNet-50 主干的 Faster R-CNN，并在 ImageNet 上预训练。
- 3. **Data Augmentation**: 应用随机翻转、旋转（90°、180°、270°）和颜色抖动以提高鲁棒性。
- 4. **Training Strategy**: 模型使用动量为 0.9 的 SGD 优化器进行训练，初始学习率为 0.001，并采用余弦退火调度器。
- 5. **Post-processing**: 应用非极大值抑制（NMS），IoU 阈值为 0.5，以去除重叠块之间的重复检测。
