## 名义GDP和实际GDP

通货膨胀会扭曲像GDP这样的经济变量，因此我们有两种类型的GDP：

一种是经过通货膨胀校正，另一种则没有校正

- ▪ 名义GDP——按**现期**价格计算的物品与劳务产出的价值。
- ▪ 实际GDP——按不变的**基年**价格计算的物品与劳务产出的价值。
- ▪ 名义GDP按报告期的实际价格乘上实际产出（P₁Q₁）计算。
- ▪ 实际GDP则按基期的价格乘上报告期的产量（P₀Q₁）计算。反映产量的变动，而不反映价格的变动。

## 例：

| 2019 | $11 | 500 | $2.50 | 1100 |
| 2020 | $12 | 600 | $3.00 | 1200 |

## 例：

| 年份 | 名义 GDP | 真实 GDP |
|---|---|---|
| 2018 | $6000 | $6000 |
| 2019 | $8250 | $7200 |
| 2020 | $10,800 | $8400 |

- - 名义GDP是用当期价格来衡量
- - 真实GDP是用不变的基年价格来衡量（本例中以2018年作为基年）

## 例：

| 年份 | 名义 GDP |  | 真实 GDP |  |
|---|---|---|---|---|
| 2018 | $6000 | 37.5% | $6000 | 20.0% |
| 2019 | $8250 | 30.9% | $7200 | 16.7% |
| 2020 | $10,800 |  | $8400 |  |

- - 名义GDP的变化反映了价格与产量的变化
- - 真实GDP的变化是价格不变时（就是零通货膨胀条件），GDP数量的变化

因此，真实 GDP经过通货膨胀校正

## GDP平减指数

- - GDP平减指数衡量相对于基年价格的现期物价水平。
- - GDP平减指数说明**在名义GDP增长中，有多少归因于价格的上升而不是产量的增加**。
- - GDP平减指数：**反映价格的变动**，而不反映产量的变动。

![](img/518b44ff56ad05e168220626515b534d_1182_0.png)

## 例：

| 年份 | 名义 GDP | 真实 GDP | GDP 平减指数 |
|---|---|---|---|
| 2018 | $6000 | $6000 | 100.0 |
| 2019 | $8250 | $7200 | 114.6 |
| 2020 | $10,800 | $8400 | 128.6 |

14.6%
12.2%

# 计算每年的GDP 平减指数：

2018: 100 x (6000/6000) = 100.0
2019: 100 x (8250/7200) = 114.6
2020: 100 x (10,800/8400) = 128.6

| 物品 A | $30 | 900 | $31 | 1,000 | $36 | 1050 |
| 物品 B | $100 | 192 | $102 | 200 | $100 | 205 |

A. 计算2017年的名义GDP

$30 x 900 + $100 x 192 = $46,200

B. 计算2018年的真实GDP

$30 x 1000 + $100 x 200 = $50,000

## 讨论
参考答案

|  | 2017（基年） |  | 2018 |  | 2019 |  |
|---|---:|---:|---:|---:|---:|---:|
|  | *P* | *Q* | *P* | *Q* | *P* | *Q* |
| Good A | **$30** | 900 | $31 | 1,000 | $36 | 1050 |
| Good B | **$100** | 192 | $102 | 200 | $100 | 205 |

**C.** 计算2019年GDP平减指数

名义GDP = $36 x 1050 + $100 x 205 = **$58,300**

真实GDP = **$30 x 1050 + $100** x 205 = **$52,000**

GDP平减指数 = 100 x (名义 GDP)/(真实 GDP)
= 100 x ($58,300)/($52,000) = **112.1**
