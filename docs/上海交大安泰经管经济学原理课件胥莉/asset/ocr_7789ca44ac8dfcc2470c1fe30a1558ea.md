# 通货膨胀率的计算

+   - 消费价格指数（CPI）
+   - 某年CPI=某年消费品价格水平/基年消费品价格水平
+   - 例如：已知消费品价格水平：1998 8.07；1999 10.82；2000 12.37，以1998年为基期，计算1999和2000年的CPI
+   - 1999年CPI=10.82÷8.07=134%
+   - 2000年CPI=12.37÷8.07=153%
+   - 通货膨胀率=（本年CPI一上年CPI）/上年CPI
+   - 1999年通胀率=（134%一100%）/100%=34%
+   - 2000年通胀率=（153%一134%）/134%=14%
