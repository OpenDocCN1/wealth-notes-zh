# 中国的反垄断法案例

+   - 相关市场界定
+     - 奇虎360诉腾讯QQ
+   - 2010年10月14日，腾讯起诉360“隐私保护器”不正当竞争。
+   - 2010年10月29日，360推出“扣扣保镖”，声称要对腾讯实施系列“净身”动作。
+   - 2010年11月3日，腾讯要求用户二选一。
+   - 2010年11月4日，工信部介入调停，QQ和360软件完全兼容。
+   - 2011年4月，北京朝阳法院一审判决，360“隐私保护器”构成不正当竞争。
+   - 2011年9月18日，腾讯向广东高院起诉360“扣扣保镖”不正当竞争。
+   - 2011年11月15日，360向广东高院提起腾讯滥用市场支配地位垄断案诉讼。
+   - 2013年3月28日，广东高院一审判定，360诉腾讯垄断案，腾讯不具有市场支配地位，驳回360的全部诉讼请求。360上诉。
+   - 2014年10月16日，最高人民法院终审判决，360诉腾讯垄断案，判决驳回360上诉，维持原判。
