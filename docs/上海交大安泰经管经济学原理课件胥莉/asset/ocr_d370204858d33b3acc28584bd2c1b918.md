# 总收益、边际收益、价格与需求弹性的关系

$$MR=\frac{dTR}{dQ}=\frac{d(P\cdot Q)}{dQ}=P+Q\cdot\frac{dP}{dQ}=P\left(1+\frac{dP}{dQ}\cdot\frac{Q}{P}\right)=P\left(1-\frac{1}{|e_d|}\right)$$

$$\frac{dTR}{dP}=\frac{d(P\cdot Q)}{dP}=Q+P\cdot\frac{dQ}{dP}=Q\left(1+\frac{dQ}{dP}\cdot\frac{P}{Q}\right)=Q\left(1-\frac{1}{|e_d|}\right)$$
