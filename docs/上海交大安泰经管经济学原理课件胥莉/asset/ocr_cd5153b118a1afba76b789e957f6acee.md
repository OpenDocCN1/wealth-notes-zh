# “最终……”

+   - 例：一辆新的奔驰汽车是在2019年生产的，但是到了2020年才第一次出售，那么应该计入2020年的GDP，因为当它第一次出售时才作为一种最终物品。错
+   - 这个是根据GDP的定义和核算原则：在哪一期生产就计入哪一期的GDP。
+   - （1）这个最终物品不是销售的，是当期生产出来的。简言之，就是当年生产的产品数量，不是卖出去的产品数量
+   - （2）在某t期交易过去生产的东西而形成的交易额是不能计入第t期GDP的，因为它是过去生产的；
+   - （3）第t期生产出来的东西如果要到t+1期甚至以后才能卖出去，它依然以存货的名义计入该期（t期）的GDP，而不是t+1期的GDP，因为它是第t期生产的。
