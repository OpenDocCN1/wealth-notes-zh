

## 为什么边际成本重要

- 农民杰克是理性的，并打算最大化他的利润。为了增加利润，他应该生产更多还是更少的小麦？
- 为回答这个问题，农民杰克需要“考虑边际条件”。
- 如果多生产小麦的成本（MC）小于出售它的收益，那增加产量，杰克的利润也会增加。

## 固定成本与可变成本

- **固定成本（FC）**：不随着产量变动而变动的成本。主要有厂房设备和管理人员的工资。**总固定成本（TFC）**
  - 对杰克而言，FC = $1000 是他的土地的价格
  - 其他例子：设备成本、偿还贷款、租金支付
- **可变成本（VC）**：是指随着产量的变动而变动的成本，主要指原材料、能源和工人的工资等。**总可变成本（TVC）**
  - 对杰克而言，VC = 他支付给工人的工资
  - 其他例子：原材料的成本
- **总成本（TC）**：TC = TFC + TVC
- **平均成本**是指单位产品上分摊的成本；可以进一步划分成平均固定成本（AFC）和平均变动成本（AVC）。
- **平均总成本**：ATC = AFC + AVC

## 成本的各种衡量

- 边际成本是指生产最后一个单位产品所发生的成本。边际成本的变动影响所有成本的变动。
- 短期成本是指至少有一个要素不变时期的成本；
- 长期成本是指在所有投入要素都发生变化时期中发生的成本。长期中没有固定成本。
