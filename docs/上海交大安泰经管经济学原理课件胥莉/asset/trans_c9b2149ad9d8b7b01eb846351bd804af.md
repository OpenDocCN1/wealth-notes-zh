

## 垄断的福利代价

竞争均衡：
- 产量 = Qc
- P = MC
- 总剩余最大

垄断均衡：
- 产量 = Q_M
- P > MC
- 无谓损失

## 垄断企业的行为

- 完全垄断企业不同于其他企业之处：
  - 垄断企业总在需求弹性大于1处生产
  - 垄断企业控制市场和价格，有能力并会让 P>AC，从而获得超额利润
  - 垄断企业具有垄断势力
    - 垄断势力（Monopoly Power）：P—MC
  - 市场的需求弹性越小，垄断企业的垄断势力越大

```
P − MC = P − MR = P − P·(1 − 1/|E|) = P/|E|
```

## 无谓损失

- 由于垄断者通过收取高于边际成本的价格发挥其市场势力，它就在消费者的支付意愿和生产者的成本之间打入一个楔子。
  - 这个楔子使销量低于社会最优产量。
- 垄断引起的无谓损失类似于税收引起的无谓损失。
- 税收和垄断之间的差别是政府得到税收的收入，而私人企业得到了垄断利润。

## 垄断企业的行为

### 价格歧视

- 价格歧视是以不同价格向不同消费者出售同一种物品的做法。
  - 两个消费者消费的产品生产成本是相同的。
  - 对不同成本的产品向不同的购买者收取相同的价格。
- 当一种物品在竞争市场上销售时，价格歧视是不可能的，这是因为有很多以市场价格销售同一种物品的企业。为了做到价格歧视，企业必须具有一些市场势力。

## 价格歧视的条件

- 厂商具有一定的市场力量。
- 消费者具有不同的偏好，且能够被区分（需求弹性不同）。
- 消费者群体或销售市场相互隔离。无法转卖或转卖的成本太高从而不值得转卖。

## 价格歧视的例子

- 电影票
  - 对老年人，学生以及可以在工作日下午看电影的人们实行折扣，因为他们的支付意愿要低于那些在周末晚上买全价电影票看电影的人们
- 飞机票价
  - 对愿意在周六晚上过夜的乘客实行折扣，可以帮助航空公司把商务旅行者（通常有更高的支付意愿）从高价格弹性的旅游乘客中区分出来
- 折扣券
  - 有时间收集折扣券的人们通常收入和支付意愿都较低

## 常见的定价方法

- 分段定价法
  - 依据数量定价
  - 累进与累退
- 高峰负荷定价法
  - 依据时间定价（以减少需求的波动）
    - 上海电力分时间段定价
    - 新加坡出租车高峰时间加收附加费
  - 产品储存成本对定价的影响

## 创造价格歧视的条件

- 加强市场分析，了解消费者意愿和消费者差异；
- 增加套利的难度，减少套利的价值（服务、担保、区分、交易费用、协议、纵向一体化等）

## 价格歧视的分类

- 一级价格歧视（完全价格歧视）
  - 是指垄断者完全了解每个消费者的支付意愿，并对每位消费者收取不同价格的情况。
  - 一级价格歧视要求垄断企业能够区分不同消费者对产品价值的预期或保留价格，从而向产品价值预期高的消费者卖高价，低的卖低价。
- 二级价格歧视（如，两部定价）
  - 对给定的消费者，依据其购买量的多少来确定价格。
- 三级价格歧视（市场分割）
  - 进行市场分割，对不同团体的顾客收取不同的价格。

这里，垄断者生产竞争市场的产量，但收取的价格是他或她的支付意愿

## 一级价格歧视

- 实施中的困难，因为：
  - 消费者人数太多，难以估计不同消费者的保留价格或最高愿付价格
    - 没有企业知道所有买者的支付意愿
    - 买者也不会把它告诉卖者
  - 因此，企业根据一些它们所观察到的特征把消费者分为若干群体，与支付意愿有关的特征，比如年龄

## 常见的两部制定价案例

- 电话费， 出租车费， 俱乐部会费
- 耐用消费品（照相机、空调等）可看作二阶段收费，尤其是易耗品对耐用品有针对性的
- 特殊设备厂商（如电梯、锅炉、计算机系统等）把产品与售后服务、升级等作为整个产品出售，从而考虑二阶段收费

## 垄断企业的行为

- 三级价格歧视
  - 实现市场分割的条件
    - 垄断者能够把不同市场或市场的各个部分有效分割
    - 各子市场或消费团体具有不同的需求弹性
  - 如何进行价格歧视
    - 均衡条件：MC（Q）=MR1（Q1）=MR2（Q2）
  - 需求弹性大的市场定价较低，需求弹性小的市场定价较高

```
P_i = MC / (1 - 1/|E|), i = 1, 2
```
