### 一个故事

你的工作是为本地企业制作网站，制作一个网站收费200美元。目前你每个月能卖出12个网站。

你的成本在不断上升（包括你的时间的机会成本），因此你考虑把价格提高到250美元。

需求定理告诉我们：如果提高价格，你将不能卖出原来这么多的网站。你将少卖出多少网站？你的收益将会减少还是增加？减少或增加多少？

### 弹性的概念

- 在经济上是指一个变量对另一个变量变动的反应程度，或者一个变量变动影响另一个变量的程度。它通常是两个变量变动的百分比，分母是自变量，而分子是因变量。
- 弹性的种类很多，有价格弹性、收入弹性、交叉弹性、供给弹性、产出弹性，等等。
- 衡量买者和卖者对市场条件变动的反应大小的指标。
- 弹性衡量需求量或供给量对其某种决定因素的反应程度的指标。
- 使我们可以更精确地分析供给与需求。

![](img/518b44ff56ad05e168220626515b534d_248_0.png)

### 需求价格弹性

- 需求价格弹性——价格变化1%引起的需求量的变化百分比值。
- 它是一种物品的需求量对其价格变动的反应程度的衡量。
- 简单地说，它衡量买者需求的价格敏感程度。
- 弹性系数可以是正的或负的，大多数情况下是负的，为方便起见，一般都取绝对值。
- 同一条需求曲线上，不同点的弹性值不同。

需求价格弹性 = \frac{需求量变动百分比}{价格变动百分比}

例如：

需求价格弹性等于 \frac{15\%}{10\%} = 1.5

**P** 上升 10%，**Q** 下降 15%。

![](img/518b44ff56ad05e168220626515b534d_250_0.png)

### 计算变动百分比

计算百分比（%）变化的标准方法：

$$\frac{终值 - 初始值}{初始值} \times 100\%$$

从A到B价格变化百分比等于：

$$(\$250 - \$200)/\$200 = 25\%$$

### 中点法

需求价格弹性 = \frac{(Q₂ - Q₁)/[(Q₂ + Q₁)/2]}{(P₂ - P₁)/[(P₂ + P₁)/2]}

例子：如果猪肉的价格从2元上升到2.2元，你的购买量从10斤下降到8斤，利用中点法你的需求价格弹性计算如下：

$$E_p = \frac{(8 - 10)/((10 + 8)/2)}{(2.20 - 2.00)/((2.00 + 2.20)/2)} = (-22\% / 9.5\%) = -2.32$$

采用中点法，价格的变动百分比等于：

$$\frac{\$250 - \$200}{\$225} \times 100\% = 22.2\%$$

数量的变动百分比等于：

$$\frac{12 - 8}{10} \times 100\% = 40.0\%$$

需求的价格弹性等于：

$$40/22.2 = 1.8$$

### 需求价格弹性：点弹性与弧弹性

$$e_d = \frac{\frac{\Delta Q}{(Q_1+Q_2)/2}}{\frac{\Delta P}{(P_1+P_2)/2}} = \frac{\Delta Q}{\Delta P}\cdot\frac{P_1+P_2}{Q_1+Q_2}$$

$$e_d = \lim_{\Delta P \to 0}\frac{\Delta Q}{\Delta P}\cdot\frac{P}{Q} = \frac{dQ}{dP}\cdot\frac{P}{Q}$$

这一点的一阶导数。

### 讨论：计算弹性

利用下述数据计算宾馆房间的需求价格弹性：

如果 **P** = \$70，**Qᵈ** = 5000；如果 **P** = \$90，**Qᵈ** = 3000。

采用中点法计算需求数量的变动百分比：

$$(5000 - 3000)/4000 = 50\%$$

价格的变动百分比：

$$(\$90 - \$70)/\$80 = 25\%$$

需求的价格弹性等于：

$$50\% / 25\% = 2.0$$

### 需求弹性的分类

**缺乏弹性的需求**

- 需求量不随着价格变化而强烈变化。
- 需求价格弹性小于1。

**完全无弹性**

- 需求量不随价格变化而变化。弹性值为零，即价格无论怎样变化，需求量不变，需求曲线是条垂线，如急救药。

### 需求弹性分类

**富有弹性的需求**

- 需求量随着价格变化而强烈变化。
- 需求价格弹性大于1。

**完全弹性**

- 价格极小变化引起需求量极大变动。弹性值无穷大，即价格不变，需求量无穷大，需求曲线平行于横轴，如黄金。

**单位弹性**

- 需求量与价格同比例变动。需求曲线是一条正双曲线。

### 需求弹性分类

**小弹性（1 > Ed > 0）**

- 需求量变动的比例小于价格变动的比例，需求曲线比较陡峭，生活必需品大多小弹性。

**大弹性（Ed > 1）**

- 需求量变动的比例大于价格变动的比例，需求曲线比较平坦，奢侈品大多大弹性。
