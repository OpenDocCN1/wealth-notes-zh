# 总收益与需求价格弹性的关系

证明：\(\frac{dTR}{dP} = \frac{d(P \cdot Q)}{dP} = Q + P \cdot \frac{dQ}{dP} = Q\left(1 + \frac{dQ}{dP} \cdot \frac{P}{Q}\right) = Q(1 + e_d)\)

若1+e_d>0，即e_d>-1或|e_d|<1，则 \(\frac{dTR}{dP} > 0\)

若1+e_d<0，即e_d<-1或|e_d|>1，则 \(\frac{dTR}{dP} < 0\)

若1+e_d=0，即e_d=-1或|e_d|=1，则 \(\frac{dTR}{dP} = 0\)
