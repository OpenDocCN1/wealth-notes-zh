# 柯布一道格拉斯生产函数

（C—D生产函数），由美国数学家柯布和经济学家道格拉斯于1982年根据历史统计资料提出的。

$Q=AL^\alpha K^\beta$

$Q=AL^\alpha K^{1-\alpha}$

+   - A为规模参数，A>0
+   - a表示劳动贡献在总产中所占份额
+   - $0<a<1$
+   - 1-a表示资本贡献在总产中所占份额

美国20世纪初期的经验数值

$Q=L^{3/4}K^{1/4}=1.014L^{3/4}K$

+   - 资本不变，劳动单独增加1%，产量将增加1%的3/4，即0.75%；
+   - 劳动不变，资本增加1%，产量将增加1%的1/4，即0.25%；
+   - 劳动和资本对总量的贡献比例为3:1。
