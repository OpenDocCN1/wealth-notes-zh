+   - 生产一台电脑需要100个小时的劳动
+   - 生产一吨小麦需要10个小时的劳动

|  | 雇佣的劳动小时 |  | 生产 |  |
|---|---:|---:|---:|---:|
|  | 电脑 | 小麦 | 电脑 | 小麦 |
| A | 50,000 | 0 | 500 | 0 |
| B | 40,000 | 10,000 | 400 | 1,000 |
| C | 25,000 | 25,000 | 250 | 2,500 |
| D | 10,000 | 40,000 | 100 | 4,000 |
| E | 0 | 50,000 | 0 | 5,000 |
