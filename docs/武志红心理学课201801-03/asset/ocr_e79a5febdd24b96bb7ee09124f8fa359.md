# 觉知03｜个人历史的潜意识

我这周的主题是“觉知，是最大的容器”，今天是第三讲「个人层面的潜意识」。

了解潜意识概念的知识和通道于冰山的比喻，这个比喻说，意识如同潜藏在冰山，就像是一座冰山，浮出水面的是意识部分，藏在水下的是潜意识部分。

按照弗洛伊德的比喻，冰山藏于水下的部分，约占十之九，而露出水面的，则约占十之一。用这个比例来形容弗洛伊德的潜意识观，是比较合适的。

我将潜意识分为三个层级，最表层的是个人历史的潜意识，弗洛伊德说的主要是这个层级的，再深一些，是集体历史的潜意识，这是荣格讨论的部分。更深一些，则是佛学说的阿赖耶识，其中蕴藏着一切。

个人历史的潜意识用山水来比喻是比较恰当的，但一旦涉及到集体历史的潜意识和阿赖耶识，就会进入到复杂甚至在其中非常有局限的部分。人类的认识能力当然是越来强大，但意识层面的东西仍无限，深入潜意识也是一个无限的过程，并且其乐无穷。

同时，我认为，觉知这个容器也是无限的，我们可以不断扩大自己的觉知范围，而破除对潜意识的有限理解。

在我之前的文章中讲到，潜意识的这三个层级，今天我来跟大家探讨如何觉知个人历史层面的潜意识的深渊。我来给你讲一个故事。

有一个故事，她诸初中女儿，不接受自己的女性身份，决心想要去做变性手术。这个女孩是非常中立的，她的各种行为表达了反性别的，例如她剪自己的长头发，穿得非常中性，想办法跟男生混在一起，拒绝和女孩玩。

父母非常担心她，带她去找了多位心理咨询师，还特意去医医院的心理科，还咨询了精神科，也有咨询师说她这叫“异性恋”。

到我这儿时，女孩已经拒绝再接受任何心理帮助，并因此让这阶段母亲和我咨询。在和她妈妈交谈的过程中，我发现她不是这么简单，例如女孩非常爱父亲，而她母亲的样子和气质很像女孩的父亲。

因此，我约女孩的父母和我谈了谈。这位父亲很和善，但说女儿有很多念头缠着她，也很敏感，例如说女孩小时候总喜欢盯着他，就像看情人一样，还有其他一些表达方式。这些父亲因为比较木讷，没有发现这些多么问题，但我判断这是因爱恋父亲。

然而，比恋父更严重的是，恋恋看。女孩父亲的家表示，重男轻女，这个女孩就是她的表现，例如生了几儿子，就是为了生儿子，而女孩和父亲亲近的时候，实在太少。

这个家庭适合做精神分析式的治疗，所以我给他们提了这些建议：

+   1. 建议女孩的父亲，单独带女孩去附近旅游，有时也单独带孩子去爬山，如果其他孩子参加的话，也请女孩放在一边。
2. 建议女孩的奶奶、妈妈多和女孩亲近，多制造一家人在一起的时光，并且有意识地鼓励女孩和父亲亲近。
3. 女孩的父母，也多些单独出去浪漫的时光。

基本上就是这些建议，目的是为了增强女孩和父亲以及与母亲的连接。

那个时候，我还没有明确形成一、二、三元关系，所以我的建议是符合二元关系的。不要把女孩恋父的性恋看得太重，甚至要认为根本不是恋父，而是女孩和父亲的情感连接太弱，而增强情感的一部分；同时也增强女孩与母亲，以及父母之间的的情感连接，这样可以让女孩进入一元关系中和女孩，进入三元关系的世界。
