# 加餐：工作空间的无情

武志红

我这一周的主题是“创造你的工作空间”，今天是加餐，我来讲一个非常个性化的思考：“工作空间中的无情”。

我想先问你这样一个问题：目前在你这个星球上，你认为最著名、最伟大的企业家是谁？

相信很多人会想到乔布斯和马斯克，虽然乔布斯已逝，与马斯克的企业相比算不上彻底的成功，但这两个人身上有很多共同的品质，如亲美主义、疯狂、自大与偏执。我觉得这些特质可以总结成一个词——“无情”。

很多厉害的企业家身上都有这个品质，当然，也不可能所有。那么，至少在“一些人”身上，“无情”是会带来成功的吗？关于这个问题，我没读过的思考，也是我非常个人化的思考，未必正确，所以这里建议你不要轻易去学习“无情”，就当做一个启发性的思考，希望能帮到你有所思考。

我先来讲两个细节，一个是我和一位来访者的谈话，一个是我和我的分析师的谈话。

先说第一个。我的这位来访者可以称得上是精英，她从美国顶尖的学校毕业，去了最好的金融机构工作，一个访谈中，她谈了她的一个小计划，我听得甚至是可以说是阴凉，她把她的上司设成“色情性”对象，自己则成为“施虐者”。她计划让上司去工作，她让她上司愚蠢无知，露出他该属于他的位置。

她的计划非常阴冷，看起来那么能量满满，她说着说着，突然间一个大而强的能量笼罩在她身上，就好像我们身边出现了一个能量感海洋，要把我们两个吸进去。这种感觉吓得一抖，我觉得我的那一刹简直要瓦解了，这能量感会彻底占满她。

等这股能量过去后，我和她试着给这股能量命名。我们几乎同时想到了一个词——“无情”。如果说挥舞挥舞、而挥手指向她的施虐性目标，目标很容易实现，可这时候她就是被攻击对象，同时也是能量也杀死了，我们不再是她自己，而是被这股能量，或者说件事给占据了。

我在专栏之前的文章《保护好“我这个容器”》中，介绍过格容的一个说法：不要让“我”按照现实原则，而要让一切人性的力量在“我”这个容器内进行。

我的这位来访者的体验可以套用这个说法。在那一刻，她体验到了“我”这个容器瓦解了，她被无情这股能量给占据了。

在接下来的咨询中，我们继续谈她的计划和无情，也许是因为咨询的原因，最终她放弃了一些计划，展开了她的新目标，不过计划变得更新，最终她的在很短的时间内连升两级，而原来离的职头上司也离职，结果，她一箭双雕。但在这之后，她大病了一场，花了好长时间才缓过来。

我个人认为也许可以说，无情这股能量，或者说心理学家比昂所说的毁灭元素，这种能量的生命体，当有活死体时，一个人的生命力会很强，因此可以消灭，同时也可以创造，但因为没有周围着分层安全的皮，这股能量会伤自己，当反抗于自己内心的时候，也会自己消灭。关于这一部分的内容，我们会在《容器、看见和连接》这篇文章中阐述过。

用更普通的话来说，我认为我的这位来访者是蛮横在原来的攻击性，她的攻击性很强，不但能连续升两级，她的她攻击性太强大，能完全指向外，而控制不好那些攻击性一旦转向她自身，就伤到她了。也就是说，我认为是她攻击别人，产生了内疚和毁掉，这是她大病一场。

过了很久，大约是十多年前，我和我的分析师谈我家公司发展计划时，我突然间也陷入了这股能量的泥沼，体验到了我这位来访者体验到的无情和恐惧。

我觉得那份感觉太强，如果我不放弃，会伤害到我，不想伤害就报复，那么，我好能有力做敌人，去实现我的目标。在这个过程中，我自然会伤害到别人，我也会被报复和攻击，但我觉得这一切都正常且坦然地接受，不纠结。

我当时我的公司发展得比较顺利，领导很多业务，我简直像是通过公司发展的这个外部世界，研究了自我心内的，所以，我觉得我不是一个好企业家。

我有一位朋友，我觉得他算得上是好企业家。他是一位富豪，接了父亲的公司，为了降低企业的人力成本，谋财利，最终经父亲后儿几千万老死在公司，每一次目标完成后他开心得不得了，但坦率他说，就像是“杀”人一样，没想到会这么爽。

结果，他迅速地将权力重新集中在自己手中，公司很快变得交换和转型，然后突然蒸蒸日上地发展。所以，如果他公司发展不好而停止发展很快为了公司，这种“无情”的企业家。

我再讲一个来访者的故事，好是一位极纠结的来访者，他做任何事都不能从自己出发，而是在别人的想法上，感觉和利益，而他则像第二别人在情感上，简像是有心灵感应的能一样。因为他和别人打交道，总觉察到是而横他于自己，他太人际中他太整个人都是横竖，于是他尽量不和别人交往，变成了个斗宅的男。

他是极佳的技术员，但公司发现，他不能领导一个团队，领导们都希望提拔他，结果很不好，最后不再提他了。

为什么会这样？原因是他——他和我就共生了，他的母亲一直将他养养，母亲是我全部世界，我除了你什么都没有。可实际上，他的父亲是逃兵。可说，虽然老后，但他是陷生母子共生的泪落里，他这只是一个全享。

最初是婴儿时，人会想着和抚养者共生在一起，但逐渐长大后，就会脱离这共生，但这种毛尾不例外，他有一个很重的想。

有一次，他看了一部美国西部片，讲加利福尼亚的一个小镇，那个矿洞就里就那地区的森林会病，那人们不动就相中，人多如草，很容易就会死掉，看完这部电视剧，他对那个无情恐怖去住，但居然生，大它的，他特别喜欢这样的世界，哪怕轻易被别人虫子样杀死。

但他说不能去，除非他有分身，留一个“假我”陪妈妈，半假妈妈只有一个人，而那“真我”就去那无情世界去冲杀，就是，他向往的时候，似乎有一种孤独的会里。

职场上也仿佛重相似，有一些来访者，大多是男性，会对我表达一个渴望：活在一个规则清晰简单的世界里，大家按照这些规则去竞争，完全不用情感，那样太累了，自己出输了也罢，只要是按照这个清晰和基本原则的规则就好。

今天讲的这些我观察在那，让我再引用我心理学家弗洛伊德的一句简单的话：“投入去做一件事，投入去做一件，幸福就会降临。”这句话看似简单，却是建立深层关系的核心，社会关系，也就是家庭与工作空间中的爱，和社会关系、工作空间中的逻辑，是有非常不一样，甚至就是背道而驰。

家庭中，不能讲无情，应该讲彼此。工作中，也许应该无情地按规则发展能力，甚至容易做出好的事业。

如果我这一逻辑真是的话，那么可以说造物主给人们造了太多这种二元对立难题，让他们难以按照一个非常简单的逻辑活着。

今日得到

+   1. 最根本的生命力，当它彻底涌出时，一个人也能创造，但也可能会毁掉所有。

+   2. 不要让“我”按照现实原则，而要让一切人性的力量在“我”这个容器内进行。

+   3. 亲美主义，就是家庭与工作空间中的逻辑，社会关系，和逻辑中，也许讲无情，而该讲彼此。工作中，也许应该无情地按规则去行事，这样更容易做出好事业。
