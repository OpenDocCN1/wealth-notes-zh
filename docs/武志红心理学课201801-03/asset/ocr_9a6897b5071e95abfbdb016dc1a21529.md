# 【春节特辑】觉知10 | 创造属于你的春节

我们这一周的主题是“回家过年的怕与爱”，今天是第四讲“创造属于你的春节”。

前面三篇春节特辑的内容，我们都倾向于“回家过年”这几年。如今春节可以知道和对应，那即是只过年了，但我们可以在春节期间真正体验到回家的感觉呢？

了解前面的因素是很重要的，否则，我们很容易是被春节“过”了，而不是主动地“过”春节。

如果想增加春节中的积极因素，关键也在于“回家过年”这几年，如果我们可以通过和应对，那即是只过年了，但我们可以在春节期间真正体验到回家的感觉呢？

我一再提到，幸福感和主要来源是在关系，可以答案很重要，如果在过中期间，改善彼此重要的人际关系，就能帮助我们体验回家的感觉。那么，如果我们好好去认知知识这些事件，你会想到一些什么方法呢？我讲讲我能想到的方法。

# 了解自己

我们整个专栏的最主要目的，就是帮你了解自己，你次是很了解自已。并且有过各种重要，例如你记忆中最早的是什么，你生命中记忆最深刻的三个事件或细节是什么。

这些事情，按照你的经验，多数和父母关系很密切，并且你年轻时太小，因此对时间、空间和等细节记忆未必准确，所以可以找父母等相关他人确认一下。

还有，这些细节和事件有关，请他们给你的详细描述这些事件，那会对你很有帮助。不仅如此，你还可以问问父母，他们对你深刻的记忆都是哪些。多数情形下，父母对你的记忆都是连续的。让他们按照你的年龄讲述各种记忆，可以帮助你的记忆也变变得更连续。

# 了解父母

春节期间，很多父母和长辈之间容易疏远，因为缺乏有效沟通。如果有一些有效的沟通，减少无意义的唠叨和烦人的控制就会减少。

有效沟通，无非是心理学家张说的那三点：表达、表达和表达。那么，利用这个时间，问问他们对你过去的哪些看法，例如你父母的认识，他们生命中最深刻的三个细节，特别是他们童年的记忆。

你可以问过家人或意识和社会意识，你还上过可好问，他们关于家族的认识，他们对自己经历的那些时代的认识。

我喜欢干这件事，我可以肯定地说，这样的事情会很有价值。并且如果你的认识会非常有意义。去问问你的经验和感受，会大大增进你们之间的链接。
