# 【春节特辑】觉知09 | 集体性自我带来的焦虑

“【春节特辑】觉知09”

我们这期的主题是“回家过年的喜与‘哀’，今天是第三讲‘集体性自我带来的焦虑’。

我先来讲一个现象。我上过很多外国老师的课程，而且其中的很多人都是会写到，当你跟学生说真，学生其实不太好了，学习变得认真。老师对特别喜欢。

一开始我觉得这是个好消息，可听多了之后，又开始有些担心，学生老师都过于依赖，老师都是权威，学生老师都过于依赖，老师都是权威，学生会很顺从权威，而失去了自己的独立思考呢？

同时，我也自己常讲课，一年也会带一两场几十人的工作坊，一般会持续三天三夜，不同身份我也是老版，也是商人，这种多重身份，让我有了一个感受，做人心理学的生意实在太好了，不仅听到了钱，而且还获得了即时的爱，当课程结束时，从学员那里获得的都是满满的感恩和赞誉。如果我是普通的商人和老板，肯定不会获得这样的满足感。

并且，无论是在我课程中还是我学课程，都会看到一个学习当中会产生一个强大的动力，就是学员和导师之间都特别想在一个团队上，其中也有领导，但团体本身是一个团体，普通成员在争夺团体领导者的关注，这是团体中的竞争。

有些课中，会有从欧美来的学员，我会问他们，你们在国外感受到的这种团体氛围，和在中国团里感受到的团体是一样的吗？他们多数人会说是，团体中的竞争很相似，但确定的西方学员，对于老师们会获得某种特殊的尊敬，全世界对老师表现出更多的服从，要更多得多。

我认为其中的差异在于，东方是集体主义文化，个人的自我依是他们的集体自我，而西方是个人主义文化，他们的自我是个体化自我。

每一种文化都有它的优劣，所以要强调一下，我这样并不是说集体主义文化和集体性自我就不如个人主义文化和个性化自我。

我再举一个例子。我去过南极北极，坐的是法国游轮，游船上中国船长、探队长、服务员全都是中国，中国游客探索队居多，而欧美的游客偏少年多了一些。此中差别，但一样要追溯集体主义和个人主义的差别。

我们不说优势，只是来说它的特色。以前，精神分析就有一个说法，说精神分析很难在中国发展出来，因为中国人是集体性自我，精神分析只能是分析个性化自我的人。为什么这么说呢？因为个性化自我的人，他能超开分析，而群体性自我，个体的、与生俱来的、却没有一个独立自我，所以不好分析。

但事实恰恰相反，中国人对精神分析的热烈程度超出想象，我打个角色，精神分析在中国心理咨询家都特别多，也许占到百分之几以上，这是在其他国家都难以见到的比例。

说了这么多，有点绕了，再回到今天的主题：集体性自我中的竞争，理解了一点之后，可以帮助我们理解，在春节期间，你为什么觉得各种与无处不在，例如你家孩子结婚了吗？结婚对象如何？孩子有了孩子了？成绩是多少分？挣多少钱？你收了多少红包、收了多少红包？

春节中的这些竞争，和它们带来的巨大焦虑，都是你的集体性自我。集体性自我，至少有两大块组成。一个是“大家长”，一个是“所有人”。“大家长”可以理解为，就是你，集体性自我指自己可以贯穿现实个人的，“所有人”是我指自己简单使用的一个词，很通俗，不学术，但很形象。

“所有人”是我怎么理解，它为什么构成春节焦虑的重要组成部分。对此我讲两个发现。

很多年前，我回家时还很爱和邻居们各种聊天，但有一天我发现，大家约的无非就两件小事：一是，我家谁谁谁如何如何；二是，谁谁谁对另一个竟然对我好。这个发现让我立刻失去了听邻居人唠叨的兴趣。

另一个发现是2017年刚刚发生的。我是一个处女座，而且自诩对细节有强迫症，以前的理解是这里面有恐惧，但2017年，几次和别人讨论冲突和指责，我却触发了朋友圈或微博，隐隐地透露了这些冲突和指责，然后再咨询界并不时，我们发现了自己：第一，你看，我就是一个没有好花轿子的，所以完全可以反驳，我如此清心；第二，你看，她人有问题，我竟然这样对她，辜负了我的好的我。

真善评价别人容易，理解自己太难，而我和我的家邻居们完全是一样的，但我要花这么长时间，才在自己身上认识到这一点。

可是，我的表达对象是谁？我在微博我说？基于社交媒体和朋友圈，所以我可以说我的知识就是“所有人”。我说的那些朋友也是一样，他们并不只是在说我对他讲，也会在别人那里再说，所以他在诉说所有人。

所谓“所有人”，可以理解为是集体性自我的整个集体。当你觉得你的自我家族绑在一起，你会忍不住对那个家族：当你自我和整个村子绑在一起，你会忍不住说，你也会说，整个国家绑在一起，你会对全国家说。

相反，在欧美个人主义社会，他们会宗教师诉说，或更直接对着心中上帝诉说，上帝就成为了整个集体的一种超越性的浓缩。

这样还可以推论，在集体性自我中，我们既会觉得自己的一举一动都在大家长和所有人看着，那他们也会主张他们自己这个集体中的人的某些，主要地，自己这个自我，让我们评判对错，主持公平。
