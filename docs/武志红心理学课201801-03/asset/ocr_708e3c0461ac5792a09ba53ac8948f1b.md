# 党训06 | 家族无意识

党训06 | 家族无意识

孟志轩

我们今天讲的第三篇是“集体无意识”，今天是第三篇，就是“家族无意识”。

前两天我们讲了弗洛伊德的集体无意识和弗洛伊德的社会无意识，都是很大很抽象意义上的集体历史潜意识。今天我们要讲一个相对比较小范围的集体历史潜意识：家族历史的潜意识。

用集体无意识和社会无意识的概念来推，就可以得出家族无意识的概念：一个家族允许的心灵内含，就是家族意识；一个家族不能面对的的心灵内容，就是家族无意识。

# 《挪威的森林》中的数字巧合

我们来分析一部著名的小说，村上春树的《挪威的森林》。很多人可能会认为，这是一部简单的爱情小说，可能是，但同时容易被我们忽视的是，这是一部描绘死亡，特别是自杀的小说。小说中，有一系列数字上的巧合。

例如女主角直子，她的叔叔在17岁时，开始自困在家，4年后，21岁的他突然说出去了，然后跳火车轨道自杀。直子的姐姐17岁那年自杀，车前4年，也每两个月去自杀医院看病，抑郁症期间会自困在家的不上学，不工作和不交往。直子和直子的弟弟17岁自杀。

我个人觉得，这一系列数字有特殊的意义，直子的叔叔17岁自杀，21岁自杀，而直子姐姐分别17岁和21岁自杀，就好像分别纪念了叔叔的年龄。

小说的男主角渡边是直子的好朋友，直子死后10年，他和绿子恋爱。村上春树在渡边的第一部书《寻羊冒险记》中，小说第一章是直子的故事写下来，以“寻羊”为题目，但最后不到第一句话，直到37岁的时候才感到不能去动笔写了。

37岁是村上春树写这部小说的真实年龄，也觉得在村上春树的小说中系列各故事发生在村上春树真实生活中。他在小说后记中承认这部小说带有自传的个人性质，在小说的原页，他表达了真正的哀悼，也写道：献给许多逝去的亲人。

此外，他完成这部小说时，正好是38岁。从大结局和直子自杀的时间：38=17+21。是直子有意识的巧合，我比较怀疑这，我觉得就像在作家在38岁这个年纪来哀悼自己的长辈。这一切看上去很客观，但也觉得这些事情在生活中并不罕见。

怎么理解这些数字之间的关系？只是他的巧合，还是别有深意呢？我比较喜欢，听了越多的故事，越觉得这些潜意识和精神世界，我认为，最重要的自杀这件事太痛，在意识上难以面对，各种种逃避，和潜意识却忠实地记录了这一切，最后用数字巧合的方式来表达一种忠诚。

这是小说中的故事，未必真实，而且也是我们自己的感受，如假包换。

我来跟你们分享一个真实的案例，是我上的课，认识了一位女士，她是一位读者，她向我说她有强烈的冲动想在春节前离婚，而那种冲动我不能很好的理解，所以想来问我。

我们聊了一会儿后后发现，她有一个关键数字“两年”。她的重要关系都只能维持两年。她说她的两处恋爱，都是两年后结束，她说她离婚前，两年，而她认识，她的孩子正好两岁，而如离婚，她觉得孩子很有可能会交给丈夫。

她经历父母最早的“关键是两年”，她两岁时，父母就离婚，她跟着父亲，此后和母亲再也没见过。所以我认为，现在她这么强烈的离婚冲动，好像是为了刻意避开另一个轮回一样，她自己在两岁时失去了妈妈，她也想让孩子在两岁时失去这个妈妈。

当然，用“想”这个词并不对，因为这不是她意识层面的内容，而是她潜意识层面的动力，简单来说，就是这不是她头意能所能掌握的。

她的这种创伤在心理学称为“代际创伤”，指的上代人的创伤因为没有得到处理，而传到了下一代。

# 家族历史的潜意识

个人历史的潜意识中，藏着很多我们不能面对的东西，家族历史的潜意识中也有，通常情况下更为严重。一个人的历史，死并没有那么让人在乎，从一个人的历史没有了，但看一个家族历史的话，你会看到各种死，生重病，意外，死刑等这些比较容易接受，更重要的是家人间不太好的关系，还有就是家族里的小量权力，这些都是个人历史的潜意识中很难体验到的，毕竟有现实的人是极少的少的。

除了各种死，还有一类家族间会发生的创伤事件，例如有人严重触犯了家族的集体意识，而被整个家族群体所不能接受。这些家族创伤事件，如果家族家族承受能力强，整个家族会倾向于把这事件压下去，家族就没有发生变化。而有一些事情，家中会有人莫名地感受到这些力量的影响，而对他们有认同。

无论是《挪威的森林》中的故事，还是我的一位那位女同学的例子，都发生在还接受了和压抑着的个人潜意识中，家族创伤的传播于认同，还可能会以更为奇幻的方式发生。

# 海灵格与家系系统排列

极有争议的德国家庭治疗大师海灵格，他发明的家系系统排列疗法，一个家族中一个孩子可能根本不知道某位祖先的事情，也从来没有人和他说过，但他却莫名其妙地认同了这位祖先。

伯特·海灵格（Bert Hellingler），1925年出生于德国，是欧洲最具革新精神和最有争议的心理学，是最新颖的心理咨询师。他曾经是一名教师兼教师，在南非担任家庭治疗师长达16年，除了个人，他还是一个教育工作者，心理咨询师，治疗师，家庭治疗师。

家系系统排列疗法与海灵格家族的标志，连海灵格认为自己是海灵格家族决断的观察者，助成了成千上万的生命，也改变了许多受家庭创伤的人的生命方式。

伯特·海灵格迄今已经完成了三百多本书，其中部分作品被翻译成了30多种语言。

例如，爷爷的一头三姨太，从没被人说，但哪位一位孙女认同，这位孙女个性变得非常像这位三姨太。

这种看似非常不可思议的事是怎么发生的呢？海灵格认为，如果一个人被忽视，有人则需要被承认，家族一个人家族表现自己，而把这个人弄忘掉，那么，出于家族整个系统对于，后辈中有人会认同这个人，以此来表达对这个人承认。

海灵格还发展出一个说法，企业作为一个组织也是。例如最初的某位创始人因为在纷争中离开，这个企业排除了他的所有存在信息，这也给企业带来各种问题。企业中其他人都不知道他的存在，也会莫名地为这个人争取公平。

海灵格系统排列的工作方式是团体治疗，我参加过多次会议，一位家庭系统排列治疗师带着30个人的团体，大家围成一个圆形成马蹄形，一个人行着治疗，那就说明或描述自己的故事，有看是否及排治疗这个人，然后，就让按照原则，请教学员的人来代表他。选好，请这些代表走到台中，按照他们的感觉，排到各自合适的位置，当他们找到合适的位置，并让一开始的位置和姿势组成一个场域。并且一开始的位置和姿势是有问题的，例如夫妻原本根本不容易看。

接着，治疗师会上场，根据他的感受和经验，去代表说出他们各自的话，每当一位代表做了表达，大家的位置和姿势都会发生变化。
