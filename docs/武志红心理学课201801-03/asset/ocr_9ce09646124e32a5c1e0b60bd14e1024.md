# # 情感06 | 头脑妈妈

我们今天的主题是“**信息意识与纠结**，这是我们的第二讲：“**头脑妈妈**”。

# ## “头脑妈妈”

“**头脑妈妈**”是**母婴护理**博士王素提出的词汇。虽然我也见过很多人，但一直觉得，她是我见过的智慧最高的人，同时她还有闪电般的洞察力。

这个词是怎么来的呢？有一次，李雪去见一位朋友，这位朋友向她倾诉自己的事情，李雪用她的高智商和高洞察力给了各种分析，然后这位朋友竟然说：“非常感谢。你分析得都对，可我对和你说话的感觉**烦躁**。我觉得我不是在和一个有情感、有温度的人对话，而是在和一个**机器**对话。

这位朋友的回应让李雪深感震惊，她想了想，觉得她**说得对**。她的确是平时每句话都是放在**头脑中**，甚至觉得她自己这辈子都没有放过**头**，脑袋而充满，而且让这个小脑袋在别人的怀里，摔在地上。把脑袋拉出来，同时让她和别人有外在的联系。

和这位朋友谈话结束后，她还是不断地在思考这个问题，突然她想到了**悲伤**的词：头脑，是她的妈妈。

虽然是独立的人，但李雪觉得自己是一个**独立**的人，她喜欢独来独往，也不断问自己：当我无助的时候，谁会帮助我？我的头脑？当我被欺负的时候，谁会帮助我？我的头脑？当我感到被伤害的时候，谁来安抚我？还是我的头脑？

最后引出一个终极问题：那么，是谁养育了我？真正的父母，还是我的头脑？想到这儿，“**头脑妈妈**”这个概念就形成了。

可以说，形成了**依恋**的人，有自己真实的妈妈，而没有形成依恋还**陷在自我中心**的人，在相当程度上，头脑是他的妈妈。

# ## “头脑妈妈”的形成

“头脑妈妈”是个很好的概念，还可以问另一个问题：头脑妈妈是怎么形成的？

我讲一幅画，是被誉为中国当代艺术**四大怪胎之一**的张**骆**的**讽刺画**，画了一个**大**，**小**，两个婴儿，还有一个男婴，他的头露在被子外面，整幅画是灰白色的，只有婴儿的头是红色的。

![](bbox=[0.1, 0.63, 0.9, 0.7])

这张画我多次用在微博上，每次都有人问：晚上，你怎么使用这幅画？**恐惧**。特别是晚上，有时候，让人说这幅画吓坏了。

可是，这样一幅画，恐怖在什么地方？张骆并没有使用扭曲夸张的方式表现，他的画简直是写实，**恐惧**不表达。只不过婴儿是红色的，这一点比较特别。

后来我不断地去理解这幅画，同时结合一些来访者的故事和心理学理论，我逐渐形成了这样的基本理解：这幅画恐怖的地方是，婴儿是孤独的，而让婴儿孤独，就等于把婴儿置于恐怖的**地狱**中。

因为，婴儿在想象中觉得自己是**全能**的，可实际上他是无力的，必须要依靠大人的照顾，可能满足基本的吃喝拉撒需求；而自己的头，在大人看来是绝对无法触知的，是陷入**身体**之外的。不仅如此，他们还会形成无中生有的可怕感觉，这份**毁灭性**的恐惧，他们的心灵无法承受，于是把它投射出去，这就变成，外面的世界总是有魔鬼在攻击着自己，所以他无助。

例如一个学生对我说过，小时候常常做的一个梦是**家**中一张**桌子**，她盯着**脚**，突然脚长了一只**人脸**，对她笑着，更恐怖，你得**逃命**奔跑，可不管跑到哪儿，那个梦**都会**回来以张牙舞爪的人脸。这个**梦**，**会**让婴儿的**能力**都没有，只能静静地面对这**一切**。

但人的潜能是无限的，即是在这时候，这个人也能发出自己的力量来对付这种恐怖的，那就是**充分发展自己的头脑**。

可以说，对于**孤立无依**的婴儿来说，外界的一切刺激都是**过度刺激**，都能攻其**弱**处。而增强自我感受和**能力**，就能让婴儿对攻击有了**抵御**，也让这股攻击变得**缓和**，让这股攻击因此也可以**化解**。

我的来访者，很多人都有厉害的**察言观色**的能力，常常是我话还没说，他已知下句**说**什么，并早已说出来了。最初我**惊讶**，这能力是让我吃惊和佩服，交谈多了之后我发现，他们并没有很强的**共情**能力，主要是在猜，因为这样的能力经过了**千百**遍，所以**可以**精准。

例如有一位男士，他基本上有百分之七十的**概率**，**猜中**我想说的话，这个数字已经**恐怖**了。特别是，对**负面**的信息，**负面**信息**猜中**的**概率**更高，**因为**这**是**我**的**理解**，**也**是**我的**头脑**分析**能力**，**主要**是**来**分析**侵入**、**伤害**等**负面**信息**的**。**

实际上，常听**我**说的**敏感**的人**，**都**是**在**负面**信息**上**的**习惯**，**所以**他们**也**多**陷在**负面**信息**中**。**

过度使用头脑的好与坏

当我们过度使用头脑时，同时还有一个重要的事情发生了，**在**相当**程度上**斩断了和**身体**的**连接**，**和**这**巨大**的**好坏**，**那**就**是**自己**的**情绪**而**造成**的**情绪**上**的**痛苦**，**还**是**容易**忍受**的**。**

所以，当我们过度使用头脑时，会有两个**利**益**，**一**是**，**对**外界**刺激**的**掌控**性**增加**；**二**是**，**在**相当**程度上**斩断了**和**身体**与**情绪**的**连接**，**所以**在**痛苦**中**减轻**了**。**

同时，这样过度使用头脑，也会成为**习惯**，在**一个人**和**外部**世界**之间**的**隔断**，也就是**在**“**我**”**和**“**你**”**之**间**。**

严重的**时候**，你会觉得**这个**隔断像**是一堵墙**，或者像**是**一**些**类**似**的**有**界**的**物**体，**它**非**常**厚**，**而**无**法**穿透**。怎么**都**能**够**，而**又**觉得**自**己**和**世界**之间**像**有**一层**毛玻璃**。有**抑郁**症**的人**会**知道**，抑郁**的**时候**，**外部**世界**再**光**彩**也**好**，也**像**有**自**己**隔**着**一**层**毛玻璃**，**完全**是**两**个**世界**。**

过度使用头脑，最初是“**头脑妈妈**”，而后还会**被**用来**逃避**自身**的**痛苦。这**个**概念**中**可以多次**经过**和**我们**的**理解**。自我中有**两个**，头脑**与**意识**层面**的**自我**1**，身体**和**潜意识**层面**的**自我**2**。当过度使用**头脑**时**，**我**们**就**会**认**同**于**“**头脑**”。

用英文词汇来表述，自我**1**是**ego**，自我**2**，也就是**我**，是**self**。self**被**翻译成**“自**体**”**更**贴**合**，**因为**自**体**包括**是**包**括**肉**体、身体**以及**灵**魂等**全**部。而当**self**被认**同**时**，我**们**的自**体**中**就**只**剩下**头脑**了**，而失去**了**很多**。

之前我们也**讲过**自**体和**假**自体**。其**中**的**我**是**self**，**所**以**也**可以称**为**真**自体**和**假**自体**，**而**当**self**被认**同**时**，**这**就是**假**自体**。

当**我们**的**自体**中**包括**身**体，甚至**是**以**身体**的**感受**和**经验**为**首**时**，**这**个体**就**会**灵**敏**而**反**应**迅**速**；而**当**我**们**的**自**体**中**主**要**就**是**头脑**时**，**那**会**导**致**僵**化**以**及**追**求**其**纯**洁**。

迟**钝**的**假自体**，**可**以**通过**快**意**恩**仇**去**打破**它**，**大**胆**地**去**爱**、**去**恨**，**让**肉**体**在**真**实**的**世**界**中**寻**找**接**触**和**冲**撞**。当**身**体**活**过**来**时**，灵**魂**也**就**自**有**了**营**造**。

> > 生命的意义在于选择，但每一次选择都要尊重，而用以相应的每一种都是值得的。
