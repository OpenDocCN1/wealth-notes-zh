# 自我防御机制的定义

关于自我防御机制，布莱克曼的简单定义是：

防御，就是把大脑接受排除在意识之外的一个途径。

复杂一些的定义是：

一般来，防御是把不愉快情感的某个或某些组成部分，如想法、感觉和情绪一起，移到意识之外的一种心理操作。

讲到这儿，我们需要做一些解释。布莱克曼认为，情感有两个内容：感觉和想法。至于不愉快情感，他认为有三种：焦虑、抑郁和愤怒。

+   焦虑，是由不愉快的感受，和对可怕事件将要发生的情结组成；
抑郁，是由不愉快的感受，和可怕事件已经发生的情结组成；
愤怒，是由不愉快的感受，和想要灭灭某个人某事件的想法组成。

这种分类方法和你说的分类法不同，更多简单的是如果说，不愉快的情感是两种，抑郁和焦虑。

有时候你会发现，自我防御机制防御的并不全是情感，也包括愉快的情感，但仔细分析就会看到，防御针对的还是不愉快情感。

关于自我防御机制的种类，布莱克曼总结了101种，但他的这是不可能穷所有的。而且系统性的对自我防御机制做了分类的，安斯认为人类的所有情事都是防御。

这些说法我们可以通过佛学的一个心法来理解。佛学认为，人生由苦，有等说人开悟之后，才会变成正常人，没有了苦，苦之前，必须使用自我防御机制来防御。

自我防御机制是非常有用的，越是了解，你就会发现，你的行为简直是没有常识。你例如，我的行为真是没有常识将自心的公司变得大，有一家公司咨询，我的一个朋友，那朋友就让我在他的区域成立一个梦，那我可以给他他咨询的心的湖咨询，他感受极不，说会益太大。

然而，下一次咨询他的事，再安排上次事情，他就说，他说他已经提前安排了事情，他出差，咨询的时间点正好在飞机上。他下次咨询，咨询让他感受极差，不过，咨询后也有咨询，他想改变改变航位，好让咨询继续进行，但这次出差不想取消，取消的话会弄的不少事，结果在重要的取选中，他既没来，也没告诉我这次咨询取消了。
