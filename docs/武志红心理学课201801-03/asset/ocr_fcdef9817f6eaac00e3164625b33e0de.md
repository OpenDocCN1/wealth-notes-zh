# 情感||自体的虚弱与坚韧

情感| 11 自体的虚弱与坚韧

武志红

我这一周的主题是“最难面对的对立之物”，今天是第一讲“自体的虚弱与坚韧”。

我先讲一个故事吧。我的一位来访者，是一位女士，她在孩子三岁的时候出轨了。我觉得简直可以说是急不可耐地出轨了。为什么呢？通常情况下，人们很容易怀疑这个女人水性杨花，或者说寂寞。但她这个寂寞的理由并不成立，小孩子整天家人都围绕在她身边。

在我给她做咨询时，发现关键信息是她出轨的那个对象，像是逃避一些什么东西似的。那到底是逃避什么呢？我和她深入探讨后，发现了真正的原因：可孕期期间，丈夫按照她的要求，可以说是不眠不休，你肯定也绝对不能理解，这怎么能构成出轨的理由呢？

我个人的观点，因为这种照顾，加上坐月子的各种身体反应和3岁，让我这位来访者觉得自己已经进行成一个无助的宝宝，必须依赖别人。

这位来访者发现自己控制不住地想失控一些什么事，她甚至从来不是一个想控制一切的女强人，突然就放弃控制，变成一个无助的人，转而去找依仗了，这超出了她很多的恐惧，于是我们认为她的出轨行为，最初并不是为了追求浪漫，而是为了逃避无助和依赖。

讲“情感主题”的第一周内容中，我们了解过自体这本书。我认为，我这位来访者的丈夫把她照顾得这么好，就像是一个好妈妈一样，这位来访者所长的依赖，其实包含着依恋的成分。我个人的从依，如果是放在这个时刻是咨询转变的爱，也就会放弃控制，变成从依恋变为安全依恋的绝佳时机。但是，这时她反而充满了恐惧。

但其实我认为这份恐惧很复杂。首先，没有建立过安全依恋的人，一发现可以构建依恋，会非常担心，万一有一天失去这个关系呢？

其次，我们前面讲到，这位来访者对于失控的恐惧，是担心自己在不能控制的边界之外，是一个危险的“它”在那里的着自己。

同时，她也担心，自己当放下控制，展现出自己的真面目，丈夫这个“好妈妈”看到她丑陋的、或者充满污点、不真实的真实自我，会讨厌或抛弃。

以上都是深层原因，这位来访者最直接的受无助带来的虚弱感，实在是太糟糕了，以至于想要用“我有力量我很难弱的”的感觉。

自身的虚弱，是一种通俗说法，而专业点的术语，就是自体的虚弱。自体虚弱时，容易导出几个问题：

+   1. 胆小、缺乏安全感，脆弱的自己拒不止，甚至会破坏；
2. 自己这么虚弱，这会引发严重的羞耻感；
3. 因为有严重的羞耻和恐惧，结果导致一个人不直面自己；
4. 不能和强大的力量合作，因为这会唤起自体的脆弱；
5. 容易否定母亲，很容易给别人好处，以此显示自己是强大的；

这些问题，从头遇上不难理解，而真要试着去理解它们，常常是非常不容易的。差不多经过某些来访者的咨询过程中，我和另一名咨询人员认为他很强大的女性顾客，聊着聊着，我觉得自己强大了，简直是晕倒。把这种感觉反馈给她，她说她也有这种感觉。

等这份感受一般确认，我接下来的感觉是聚焦了，她感觉和我一致。我们深入聊了下去之后的发现，那一段时间她的事业遭到了很多质疑，但她顽强着，并得到超级工作狂一样应对这一切，而且已经经不起自己的身体承受能力，可她甚至是想继续硬撑着下去。

通过我的感知，她感知到了自己身体即将崩溃的信号后，她决定，立即停下来，缓一缓，休息一下。再聊下去我发现，在此之前她在大病一场，就是因为这种硬撑着的得导学致的。

我们得学习尊重自己的虚弱，毕竟谁都有承受极限。但可惜这种虚体的虚弱和处境中的虚弱，会让们看到“我”也就最自体的虚弱，这个时候自的虚弱感会带来恐惧和羞耻，我们不愿意承认与面对，于是选择了硬撑着，直到身体和外在现实崩溃。

人是容易接受身体的虚弱，而难以接受心灵的虚弱。因为我们把身体视为了一个生理体，好像是“我”之外的东西；而心灵更像“我”，所以心灵的虚弱会让我们觉得，“我”是脆弱的、老迈的，因而会看轻自感。

很多人抗拒找心理咨询师，就是因为这种虚弱感，觉得找心理咨询师，就证明了自己的虚弱，就像是一个心灵虚弱的人，在心灵强大之间的去依靠。然而我认为，这也是从走向自体的开始。

有一次，我和一个合作伙伴聊天。聊天时我发现，他有一个问题是不能和能量很强的人合作，比如说他找专家去讲课，都是一种无法反驳的，按照他的本意，他会选择一个没什么影响力的老师去讲课。虽然讲的话，效果好，但绝不会在。

我和他深谈下来，看到了非常有趣的真相：看上去非常谦虚低调的他，一样是深度自恋的。当他和他认为的强人们一起时，就舒活了他的自恋，会让他非常不舒服，这个不舒服最常见表现为：不在于和他认为的与自身水平相当的人在一起，就认为没有自恋的虚荣，他就不必面对这种让他难受的感觉了。

和自体的虚弱相对应的，并非是自体的强大，而是自体的坚韧。就像我们今天讲的几件事，当我们追求强大时，常常就是为了让自体的虚弱感，目的坚韧就是虚弱与坚强。而自我，不坚强的感觉和坚韧的感觉也完全可以，自己都有一个基本的感受，那就是“我能行，我能基本掌控自己的人生，即使当我最后不能掌控自己的人生时，我仍然知道这值得不是非我，并非空洞，而是有一个值得信赖的位置，或者是自己的，或者是自己之外的。
