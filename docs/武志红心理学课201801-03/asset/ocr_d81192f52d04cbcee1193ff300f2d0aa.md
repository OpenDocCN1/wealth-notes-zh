# 依恋的类型

所谓依恋，是一个人的情感，能够向依恋对象打开。依恋的类型，可以分为安全型、回避型、矛盾型和混乱型。一般人都属于前三种中的一种，表现比较稳定，但人在这三种中不断变换，这就叫做混乱型。

要搞清楚安全型、回避型和矛盾型，可以设想这样一个情景：幼儿园的家长们，家长们特别是妈妈到了幼儿园把家门口去看孩子，这时候会发现，孩子们大致会有三种表现方式：

安全型：看到妈妈在门口，笑道翻开，放下手里的东西，妈妈扒过去，然后紧紧抱住妈妈。

回避型：看到妈妈在门口，没做反应，仍然玩手里的东西。

矛盾型：看到妈妈在门口，显得有些矛盾，看看妈妈，想过去，但又有犹豫。

关于依恋类型的论述和查找资料，感兴趣的用户可以自己再搜索查找资料，这是一个比较好理解的概念。我来举一点特别的，依恋是怎么发生的。

最高本的原解是：你们都在寻找客体，“我”永远是在寻找你。小孩、猫、狗、鹦鹉等动物，都是天然地在寻找情感对象的。如果说，我对你的渴望，得到了你的积极回应，这份情感就会在我和你之间建立了一份连接，我会去表达这份你的依恋。

安全型比较，是因为我对你的渴望，得到的类似一致的积极反应，并最终我确信你这份表达基本是欢迎的。

回避型依恋，是因为我对你的渴望，得到的是一般冷漠的回应，并最终我阻挡住我对你的渴望。

矛盾型依恋，是我不能从你那获得稳定风格的回应，你忽冷忽热，于是我的情感表达矛盾了起来。

# 自恋是依恋的对立面

依恋意味着我能够向对你表达出我的动力，弗洛伊德把初把力量的自我 libido 不再能指向客体，而只能指向自身。比多是由弗洛伊德自创的一个词，大致可以理解为动力。

在弗洛伊德看来，自恋就等于是你的动力，也就是能量暂时在自己体内，对外部世界失去了兴趣。

后来的精神分析学家们，不断发展自恋这个概念。到了美国心理学家科胡特那里，自恋和全面依恋联系在一起，他集中讨论了全面依恋的问题。这一点在我们自己也专门讨论过，章思是小婴儿们一生觉得自己无所不能的神，他一动态，世界就应该按照他的欲念给会回应。

如童世界观是不给出口，整个社会就会生出自恋型情绪。恨不得摧毁了整个世界，因为他有全能感，所以这个时候他是真的觉得，他一定要自我暴露，世界就会给他提供。他不接受自己在这个世界，这时他就把这份额入天尘的坏，投射到外部世界。这就表示他得坏世界所有都要打散一个词境里做，和这个魔界隔开，这样这个魔界就可以不攻击他了。

但这个词境铁壁打造出来，也意味着他这个人困在了里面，他的生命力也被禁在了里面。

例如我一位来访者，他是典型的回避型人格，最开始咨询的时候，可以让他说儿几乎没有一个朋友，他常常有这样的观点，凡事小事退逸到寻找，就会合巨大的挫败感，同时他会觉得，好像整个外部世界为铁板一样，在对他发出严历而残忍的拒绝。这时候他隐隐觉着，好像世界背后有一个狰狞的魔鬼在操纵着。

所以说，彻底的孤独，会带来彻底的黑暗。

# 科胡特：自体客体

该怎样解决这问题呢？科胡特认为，咨询对象这样的来访者：妈妈对于最初的咨儿，都需要扮演一个角色，叫做自体客体。

所谓自体客体，简单理解就是你的确是主体，在我这个主体之关下，你可以觉得，好像是我自身的一部分，我可以像控制自己的手脚一样控制你。
