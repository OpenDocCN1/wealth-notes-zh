# “点亮时刻”精选

我在一边学习，一边观察生活。和我的朋友相处，我感到他能懂、理解他，那是因为朋友了解了一切都会因为时间和空间改变，所以明白了朋友有不安和不安的，而是会随着时间和空间而改变。记得那段时间，男女友在我耳旁抱怨，说心里很苦，他们只是暂时的。后来我在身边安慰他，不觉得惊慌。后来他告诉我，谢谢我的理解，很感激我的陪伴。

朋友的家庭有点特殊，哥哥智力不高，脑子不太灵光，最近家里给他娶了一个媳妇，媳妇对一直不照顾的哥家人最近哥哥和嫂子在闹别扭。一家人因心情不好，所以他倾诉了一番，我对此很清楚，知道虽然他问了问题，但是根本的问题在于他的哥哥。我疏导他后出谋划策，想办法去感化哥哥的想法，没想到，要去感化哥哥的想法，多沟通多交流，知道他的思维逻辑后再慢慢转变他的思想。

我遗传性，家庭是一个人的根，不可能脱离，所以你必须要改变家庭关系，让这个家变得更好，但是很难做到。与之完全相反，好的是心情好多了，也知道以后该如何去做了。我印象深刻的感受是在学过的理论体现心理学科法，也深刻地感受到家庭关系的重要性。

很多时候家会因为一点小事搞得不可开交，究其原因不过是在外受到气到家里，把对别人的愤怒投射到最亲密的身上了。这时候最好能给他发泄的机会，然后再和他一起冷静下来。举个例子，我下班比老公早，可以基本回到家可以直接吃饭，有一天在洗碗时，他百般挑剔，我的脾气上来，两个人差点动手。既然他想起到刚上学时的愤怒，迅速回到洗碗桌上发生的一切，我并没有做什么，平常不会也会这么说嘛！毕竟他外面受了气才这么说，白天是不被敬畏了，告诉我来到的不一样的客户。然后我就耐，甚至比他还激动，不一会儿，两个人都冷静了，就看了一下周围说，边吃边喝。他心情好，不但把碗洗了，还附带送我个小礼物。

+   1. 背景：大概是我女儿两岁8个多月的时候，女儿天天踢的话，晚上睡觉会发脾气，晚上不小心吃了一整餐的蛋就蛋。
2. 运用的心理学知识和亮点过程：去毒化和被看见的需求就是生能原我女儿。女儿：“宝贝”，如果不是因为妈妈只有很少就说了个女儿点头，还是生气哭。
3. 我从中获得的体会：我真心觉得每个做父母的都应该去上心理学课，不然我们总觉得非常幸运能够认识我学，订这个专刊。

我自己很焦虑，所以希望儿子成为一个快乐的人。可是事与愿违，他总是不断烦躁地发火，这让我很头疼，甚至指责我让他伤心难过。在学“爱是容”去明白连的，我萌动了父亲该被看到的。孩子不是要一个焦虑给孩子，当他，孩子不是要一个焦虑孩子，我感觉到他只是想感受发牢发牢心里的焦虑和思绪，所以我开始静静地陪着他一个多小时，最后他轻轻地吐了一口气，那一刻我看到他的样子，母亲身份做出了正确的亲子关系，孩子也终于可以做孩子了。

+   1. 背景：上班场景，我是护士。有一天，一个有透析的病人独自一个人来门诊就诊。他虽然说自己身体不适，但是显得特别别扭，情绪也很不稳定。
2. 当这位病人给他解释要挂号的时候，我很焦虑。我立刻去安慰他，我知道他缺少关心和社会支持，所以身体的不舒服加重，心情转糟糕下来。
3. 我的感受：每个人都需要被看见，愿我们每一个人都能被人看见、被关心、支持。

今天我用了武老师所说的“过渡性客体”：上午妈妈在看电视，我在打游戏，妈妈突然说家里还有鸡蛋，以为她只是说说，没想到过了一会儿真的拿了一支洗脚香皂，我就没理她，但热打灯，不想被打扰，就去正到。竟然抱着香皂来要我服我，说我玩游戏呢。它一半回来些，反正一下子融化不了。她本来有些不好的情绪立刻缓和下来，等我洗完，接了还剩下半的香皂，妈妈很开心，除了以前过年回家吃饭，都是硬地拒绝人哭，道苦，弄得我很难受，总像是为了惩罚我，用我老道的心理学知识，缓和家里的尴尬气氛，太棒了。

背景：2017年单位建立了“职工心灵驿站”，我担任这个岗位工作，使我的部分教和心理咨询师，有专业心理师资格证书，上个月同武老师共专，它就像“加油站”在。为们的工加，无业，或去会啊！心理室安排心理咨询师，使大家放松，通过体验者交流和沟通，90%通过的方式受益匪浅，今后可以尝试通过多种方式点亮更多的职工。

收获：通过武老师心理学知识，我不仅对自己的工作和学习帮助都很大。我学会了理解别人的感受，知道怎样去激发别人，懂得关心和身边的人相处，更加关注孩子的身心健康和情绪，获得了一部去包容和善待人心意。

我的父母在我家是易因一件小事就引发巨大的矛盾，争吵的内容无非是谁对谁错，应该听谁的，互相各执一词，各有各的理由，我在一旁静看着看着着，都吵累了，我开始从书着书上学到的“大脑”。第一规则就是应该接纳情绪和感觉，第二情绪在转化，第三觉察感受的地方，可以去爱在彼此上方，去包容和理解，一包容和理解。一切都是为了获得正性，也避免我们不打倒在这边，而是流动，最要父母的争吵的时候就少了，虽然是，但是总觉慢慢来，彼此包容和理解也多了。
