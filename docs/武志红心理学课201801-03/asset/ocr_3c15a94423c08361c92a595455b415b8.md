# # 觉醒04｜集体无意识的提出

我这周的主题是“集体历史的潜意识”，今天是第一讲 “集体无意识的提出”。

我先提醒你一下，在本文中，“无意识”一词指的是“潜意识”，准备这篇文章的时候，在网络上看到有人讨论清朝时的辫子运动，那是1913年的事。很多人捍卫自己那条辫子，哪怕丢了命都在所不惜。我们都知道，清兵入关时，同样有不计其数的人，为了反对清朝强行推行的辫子这件事儿而被杀死。这让我不禁感慨“都是历史”。

# ## “混猴实验”与清朝的辫子

我想到一个广为流传的寓言故事“混猴实验”：

5只猴子关在一个笼子里，中间有个梯子，梯子上有一串香蕉。猴子很喜欢香蕉，但当有猴子尝试爬梯子拿香蕉的时候，会被泼一个冷水，所有的猴子都会被冷水。这种事不断重复，后来猴子们都老了，于是拿故事给香蕉了。

接下来，放进一只新猴子，换出一只老猴子，这只猴子自然想拿香蕉，而这时其他新猴子会冲上去不许他碰香蕉。好了，这只新猴子最终也不再去拿香蕉了。

如此不断重复，5只原来的猴子都被换出去了，笼子里的5只新猴子都没有被泼冷水的感觉，但它们都不敢去拿那个香蕉，因为它们都知道，要去拿香蕉的话会挨打。但是，至于为什么不敢拿那串香蕉，那个原因它们都不知道了。

这个故事，最近出现于一本书名《为未来世界做准备》中，作者是美国著名的管理学家（Gary Hamel and C. K. Prahalad），他们想到了这个实验，从一个“朋友”那儿听来的，很可能没发生过，所以应该当作一个寓言故事，用来说明所谓传统有时候是怎么发生的。

这则寓言，的确可以用来解释清朝末期人们对辫子的捍卫。辫子最初之所以要被割开，是因为要亡国亡种，而后来它就成了清朝文化中一个几乎绝对正确的东西：最后当剪掉这条辫子时，很多人一样会去拼死捍卫，却不知道这条辫子是怎么被固定起来的。

其实，历史并不久远，人们意识上当然知道，那些辫子是多么的形式，可潜意识中的那些死亡恐惧，也许人们就忘记了。而为了免于潜意识中的这份死亡恐惧，甚至可以付出死亡的代价。

当然，这件事对有更直观的解释，就是自然和尚道的这没矛盾：你跟我拿难看的辫子，我可以不用丢脸；你逼我把辫子剪掉，我也不能反抗。

不管是什么辫子，都是在现代社会的背景下，这条辫子可以随意剪了也可以随意留着，人们甚至可以剪个稀奇的发型，但谁也不必付出生命的代价。发型，就是那么随意。

辫子深刻的象征意义，就是集体意识与集体无意识，它成了清朝人一种强烈的身份认同，这就是集体意识层面的东西；而群体无意识，实际上是自由和生死级别的恐怖或羞辱等身体经验组成。

# ## 集体意识和集体无意识

被一个文化共同体所承认的内心内容，就是集体意识；被一个文化共同体严重排斥的内心内容，就是集体无意识。

就比如说一个我自己一直以来都有的观点：任何一个时代，持有一种最主流的观点，没有任何好处，非常危险。因为一个时代的主流观点，不过是这个时代的集体意识而已，你认为持有此观点值得正确，很强大，但很可能你只是为了不被其他猴子欺负，而像蠢事地认同了一个没有危险的观点。

相反，任何有创见的观点的提出，都是有些危险的，它必然会去冒犯它所处的集体。

荣格集体无意识概念的提出，就是一个例子。那是1909年，美国首次邀请弗洛伊德去讲学，荣格是和他一起去，这是精神分析的全球传播的一个标志性事件。

他们的交通工具是轮船，要航行了两周，而他们每天都分析彼此的一个梦。期间荣格做了这样一个梦，弗洛伊德说：

> “我在一所陌生的房子里面，房子里有两层，上面一层是一片沙洛，有一张古旧的洛可可式长桌，墙上挂着几张珍贵的古画，但我很好，上面没有任何艺术价值，上面更古老，我是中世纪，这里的一层是一个房间，我进发一座厚重的门，门打开就看到一座陡峭的楼梯，下去后，我地下到一个罗马时代的时期。”

我仔细观察了地下，在一块石头上看到一个环，环拉环石将抬起，再次看到一个地下室，台阶向下通向深处。我于是顺着那个台阶，进入一个低矮的洞中，那里有破碎的残骸，尘土中散布着头骨和破碎陶器，像原始文化的遗迹。

弗洛伊德对三个解释，弗洛伊德给出了一个历史的潜意识这3个答案，说出潜意识的前两个含义的潜意识，荣格潜意识中想死或死。我们都知道潜意识死和俄狄浦斯情结，但是弗洛伊德杀死父亲，却还依赖着母亲。

当时，弗洛伊德绝对是对的，从美国行成后也构成了一个小团体，并且美国之行给弗洛伊德带来了巨大的声名压力，而弗洛伊德的这个解释对小组来说是压力所。弗洛伊德表面上赞同关于弗洛伊德的解释，可他自己认为，不能解释这个人的潜意识的问题。不足于解释这样的东西。他认为这个梦上，不断深入地下，象征着不断深入到人类集体文化的潜意识深处，由此他想到了“集体无意识”的概念。

弗洛伊德把冰山用来比喻意识和潜意识，而荣格则在这个基础上，用大海做了一个更大的解释：高出水面的是一些小岛屿，代表个人的意识；小岛下面通到海底，代表个人无意识；而将所有岛屿连在一起的海底，就是集体无意识。

非常有意思的是，在这次旅行中，弗洛伊德是昙花一现，而在几年后，他们再次讨论潜意识时，弗洛伊德又一次昙花。对这场昙花着名的争论，弗洛伊德内心有些解闷，不管是自己父亲，还是自己儿子。所谓“杀子”，就像是儿子在潜意识上挑战了弗洛伊德，就像是儿子杀死了父亲。但这位弗洛伊德的人又说，当时辩论中，荣格并没有占据优势，好像是鲁德输了，而这场胜利也被弗洛伊德诠释为失败了。

不管是谁先谁后，荣格的集体无意识概念就此提出，和弗洛伊德的个人无意识概念一样，它成了影响深远的概念。

在我看来，也许他们都是对的。人类各种集体的各种意识，都希望自己是文明的，正式的，而非集无意识的源头，腐败父辈之间的生死绝灭的毁灭，这分裂毁灭的克制和处理，则演化出了人类文明。甚至我认为，文明中的很多东西，直接从死亡中演化出来的，例如我们一开始提到的清朝辫子事情。

# ## 集体无意识中的原型

每个文化都是一个集体，而人类整体也是一个集体。因此，既有某个特定文化内的集体意识与集体无意识，又有全人类作为一个整体的集体意识与集体无意识，集体无意识中的内容主要叫原型。
