# 加餐：自我，也是个容器

加餐：自我，也是个容器

武志红

我们这一讲的主题是“宽恕”，是“最大的容器”，今天是加餐：“自我，也是个容器”。

先来问一个问题：你记忆中最早的一件事是什么？那时候你多大多？

有些人的记忆非常早，而且就从童年的记忆，是一个连续体；有些人的记忆很晚，而且记忆是不连续的，这主要体现不在于年龄，也有成年时的记忆都是不连续的。不过这是极少数。

记忆早的，例如我在《身体II》里自我介绍《心身合一》这篇文章中提到的孙萌，她最早的记忆是在火车上，妈妈抱着她，看见从窗户倒射进来的阳光、妈妈、火车的方向、各种环境细节，都栩栩如生。可是妈妈一开始并不相信，因为那个时候她就一岁左右，是妈妈抱着她去看望常年在外的外公外婆。但是，第一，妈妈抱着她坐在火车上看父亲是第一和事如影随形；第二，各种细节她都记得非常清晰，所以这都是她的确记得的证明。

记忆晚的，例如有一位朋友，我刚认识她时，15岁之前的事情她不记得了，她的解释是自己曾经遭遇过三次车祸，所以记忆受影响。后来她做了十多年的精神分析，有一周五次，连续记忆也找不回来了。后来她明白，自己之所以不记得十五岁之前的事，是因为童年时的痛苦太多了。

# 自我、自体与记忆

为什么人的记忆力相差这么大，并且主要是体现在童年？成年后，绝大多数人的记忆就是连续的。

依照神经生理学的解释，人幼小的时候，脑神经发育得还不够完善，所以连续记忆有困难。但神经生理学的研究不能解释，有些事件是连续的，有些却是不连续的。有些神经带了太痛苦的体验，可被我们压到潜意识中。

之前的内容中我们有讲过：自体，是包括身心灵整体的“我”，英文是self；自我，是头脑和意识层面的“我”，英文是ego。加尔多说，自我ego，是头脑和意识层面的那个我，也就是ego；自我2和自我1构成的整体，就是自体。

当我们意识到的部分主要是自我掌控的部分时，一个人的自我就处在本我控制中；当一个人意识到他的这部分，大多是自我不能掌控的，一个人的自我就会崩溃，接着会带来自体的反弹。

例如从大环境说，生病了，有很多人是无法理解的，例如因为大环境造成他们的掌控感，于是自我就失去功能了。

我有少数来访者，他们的生活长时间陷入不能掌控的局面，这对他们来说整个系统都崩了，各个部分之间缺乏联系，而外在也没有一个东西能支撑着这些碎片。

可以这样比喻，自我是一个容器，当事情基本在控制中，自体的各部分也可以被自我所容纳；当事情有太多不能控制时，自我就会崩溃，而自体也会带来自我的崩塌。

童年时，一个人的身体能力、心理能力和现实资源都比较有限，在某种程度上，要么需要父母都能帮到，要么就自给自足。当父母的自我和自体没有解释力的时候，就必须把所有痛苦排挤到潜意识中。

成年后，一个人有越来越多的可能去掌控自己的生活，所以记忆也变得连续起来。当然，童年时那些痛苦的记忆，在潜在层深处，就变成难以被触及了。所以，可以通过知识这些体验，疗愈我们自己。

并且，童年体验并非过去，实际上也没有过去这个时间，过去的那些体验仍藏在潜意识中，影响着我们。我们的心智模式，必然是这些体验联系在一起的。

从一个人历史的潜意识来讲，我们需要加知的体验，就是好色和性、攻击性与全能自恋联系在一起。

性，最容易产生羞耻感，为了避免羞耻感，我们就把很多与性有关的经历忘记了，通过理智和防御，重新意识到这些痛苦，以及它与治疗有关，重新意识到我们的自我。这样一来，自我的容器就大了。

至于攻击性，它像国境线这个东西：当我们意识到它的时候，就担心自己的攻击性被报复，甚至被摧毁；这时就有恐惧感；当自己的强大时候，就担心自己的攻击性伤害到重要别人，如果我们发现自己的伤害被摧毁的人时，我们对所爱的人时就有了负罪感。

所以，要好好去拥抱自己的攻击性，要知道攻击性的恐惧和负罪感。

# “某某恐病症”

心理门诊中，有一种叫恐病症，它表现出五花八门，因此就有各种各样的“某某恐病症”。

例如广场恐病症，就是不敢在人多的广场上出；社交有幽闭恐惧症，不敢进入狭小的空间中探索。例如动物恐惧症，有人怕大狗不怕小狗，有人怕小狗不怕大狗，有其他人则最怕猫。

恐病症的症状，是攻击性的问题，并且多是将自己的父母攻击了，其实大孩子都反复地。如果一想到这个就失控了，所以要投射到带有危险的物事上，就是把“坏父母”和“坏孩子”投射出去，而保护“好父母”和“好孩子”的部分。

例如，一位女士患了几种恐病症。深度咨诊后，她发现有一次和妈妈在一起过桥时，突然起了想把手推桥下的念头。这个念头吓了她，她把念头推到潜意识中去了。其实，这只是桥恐惧症的症状，过去有些种恐病症，而她妈妈有强烈的恐惧，很多时候都怕妈妈，所以这些念头会这么可怕。

# 如何完成一个人历史分析

我们怎么发现自己压抑了攻击性呢？一种是看看自己的恐惧症和内心戏。如果你太容易被别人攻击，那是因为，你自我攻击性也被别人攻击了，而压抑攻击性，也变成了你的一个系统，压抑攻击性也是，因为这让你感到强烈的攻击性。

例如有一位男士，他是一个超级奉献者，在地方买大车，都会先不顾身去救救穷人，并且没有能力留给自己的财产，以至于不能正常生活。深入咨询后发现，他的家庭中出现过多次灾难，都是和他有关，也因为他觉得好像是自已导致的，因此有了巨大的负罪感。

最简单的观察是，如果你自己严重压了攻击性，你就不能保护自己和家人，不能正常地表达愤怒，这就是缺乏攻击性的直接证明。

至于全能自恋，也许你太是谦卑的人，都可以自己去考虑下：我是不是太防御自己的全能自恋。最简单的全能自恋，而是让自己在能自恋，但有个基本假设：觉得自己是神；觉得自己是魔鬼，自恋性暴怒，彻底无助感；被遗弃焦虑。

你特别容易讨厌读者，这也是害怕聚焦，而你对别人是讨厌读者，也要考虑，可能你想成为全能自恋的大独裁者。

性和攻击性的相对和容情部分的，能感觉到自己的性和攻击性，这部分自我会被更好地容纳在你的自我中，你的自我和自体都容增强。

全能自恋这一部分，我们观察别人比较容易，要观察自己比较难。我个人的认为，那可能是我这一辈子最得逞之后多思考的重要原则。因为全能自恋是最强大的，也是我们最不愿去看的，也最是无助的，这个太强大，所以忘我地看。

但如果自己全能自恋的部分能被很好地放到，这些部分的能量也可以被容纳到自我和自体中了。
