# 觉知01 觉知的力量

![](bbox=[0.0, 0.04, 1.0, 0.1])

武志红

我们这一周的主题是“觉知”，是最大的容
第一讲——“觉知的力量”

我们先来思考一个问题：人，可以按一
些简单的原则生活，而让自己的心灵处于
完美吗？或者说，就是让健康幸福地
活着这个目标，可以通过遵守一些正确的
原则而实现吗？

我会不时想到这个问题，特别是写斯多
葛主义者爱比克泰德的故事的时候，我对这位
哲学家的完善和生活方式的向往，于是
这个问题再次浮现出来。

![](bbox=[0.0, 0.28, 1.0, 0.34])

简单的问题，一旦被认为是“正确的”，就会
变成二元对立，产生出一个“错误的”东西，
这会导致负面的、消极的后果，最终妨碍对人
性、自我和人际关系的发展。

可以说，人是理性的，认为人性至
善，一切都可以被观察和觉知。我还相信，
人对一切善和恶，都能观察到对人
性的一切信息，在二元对立中，我们能看到
的“东西”是“我”和“非我”。

这是非常严重的问题，可以被称之为“嫉妒”。

妄想是严重的问题，是人之初、人之性本
善的体现。

例如这位女士，她是硕士毕业，有很好
的智商和学历，有稳定的工作和好的伴侣。

他说：“是啊，不就是证据吗？要判定一个人
杀了另一个人，你总要找到他犯罪的证据。”
他笑了笑，说：“那如果找不到证据呢？”

这个反问，让我愣住了，但我也想不出
更好的反驳。

他这样，我给他讲了一个故事。

此路不通，就换一条。我问他，你以前有
没有想过想杀你？我也问过，他有什么
想杀的人？

他一开始，然后发现他最亲密的共同人之一，
是让他很失望的母亲。

为什么要杀妈妈？因为他觉得妈妈的
爱是有条件的。

想杀死妈妈，这是他内心的真实想法；而在
外的表现，是妈妈的控制。
