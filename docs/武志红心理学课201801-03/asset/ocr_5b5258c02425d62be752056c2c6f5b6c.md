# 复盘：关于“情感”主题的回顾

现在，我们专栏已经讲了七章：命运、自我、关系、动力、思维、身体和情感。今天我们来对“情感”这个主题进行一个复盘。

以前我们说过，我们专栏的章节设计，有一个内在的逻辑“道生一，一生二，二生三，三生万物”，这里面临“道”是命运，“一”是自我，“二”是关系和动力，“三”是思维、身体和情感，前面七章的结构非常清晰。而再接下来，我们就要开始“万物”了。

思维、身体和情感这三者构成了一个整体，也就是我们常说的身心系统。专业一点的说法就是，人的心理过程。用思维过程，身体过程和情感过程来描述，把这三者放到一起来看，可以更好地理解。

这三章，乃至第七章，其实讲的就是同一个东西：展开你的生命，在关系当中。情感这一章，则把这个点讲得更为精细一些，并且这时我们会看到，自体的坚韧或脆弱，和关系中的爱恨是紧密联系在一起。

自体都在寻找客体，“我永远都在寻找”。在这个寻找的过程中，一切人性呈现于其中，自体的坚韧与脆弱，关系中的爱与恨，只是其中两个比较根本性的命题而已。

# — 自恋与恋恋 —

> 如果你可以哪怕一次
抛开你自己，
秘密中的秘密
就会向你敞开：
隐藏在宇宙背后的
未知的容颜，
就会在知觉之镜中显现。

在本周的预告中，我用鲁米立的这首诗，表达了恋恋的深刻含义。自恋并不是自大而简单，依恋也并非是我们一般理解的情感形成这么简单。或者说，情感这件事的意义，也远远超出我们一般的理解。

世界很复杂，人性很复杂，但其实也简单，无非就是“我”和“你”。“我”就是单个人的内心，是“你”是整个人在世界，而你“就是”“我”之外的整个世界。

所以，自恋就是我们待在“我”的世界里；而依恋，就是“我”和“你”之间建立了信任关系，有能量流动在“我”和“你”之间。

在《依恋的形成》这篇文章中，我谈到依恋有一个范畴，就是婴儿。但抬头是不能强行完成的，而是婴儿最初剧烈使用了妈妈，把妈妈当做自体客体。自体客体是科胡特的一个美妙概念，温尼科特相对应的概念是“客体使用”。温尼科特最核心地无情地使得婴儿，可以婴儿，可以说最初使用关系的对象来。所以母亲关系，就是婴儿和整个世界的关系的基础。

在《两种妈妈，两种孩子》，这篇文章中，我用了一个经典区分，讲了“好妈妈”和“好妈妈”“坏妈妈”和“坏孩子”。孩子会去依恋“好妈妈”，而在“坏妈妈”这里，孩子就会滞留在自恋中。

这个逻辑延伸推，有了《依恋》“你”，排序“它”这篇文章，中有有我非常喜欢的一段话：

> “我”并不希望控制一切，那太孤独了。而是希望，在“我”不能控制的边界之外，有一个“善良的”“你”存在；在边界更好的是，在“我”不能控制的边界之外，有一个“善良的”“它”在那里。

依恋的完成，是确信了外部世界是善良的“你”，而滞留在自恋中，就是外部世界感如恶意的“它”。同时，依恋意味着，“我”和“它”建立了连接。自恋意味着，“我”和“它”要切断了联系。就引出了一个命题：连接是善，切割是恶。

如果我们觉得世界是善如耶和华的世界，那就是“它”；如果我们觉得世界是如伊甸园的世界，那就是“你”。当然这是首先是一种隐喻，但这样我们可以看到，“我”和“你”，“我”和“它”，依恋与自恋，连接与切割，竟然是有着如此丰富复杂的联系。

真正深刻的命题，必然和生活是息息相关的，否则就会是脱离生活的一串命题，或者只能是，比如延伸到车事，牵动与爱牵这一组命题上，于是有了《牵车的隐喻》这篇文章。很多同学读了这篇文章后，这篇文章的方法，改善生活治疗了自己的车事。所以牵车这件事，并不仅仅是车事里面的牵车都有没有点出的，我认为它有牵有真的自恋心理原因，甚至说有善与恶这么深刻的大命题。

# — 快意恩仇与纠结 —

我们介绍了精神分析学家比昂的概念“负爱、负恨与负知识”。比昂认为，人与人之间的连接有三种：我爱你，我恨你，我想了解你。用英文字母表述，分别是L、H、K，它们的对面分别是L-、H-和K-，可称为负爱、负恨、负知识。

国内有心理学人在讲比昂时，把L、H与K，说成了“快樂關係”，可以立刻聯結“糾結”，我覺得非常有表達力，於拿來做了本週的標題。

其实，《负爱、负恨与负知识》这篇文章更多的美地回答了第一周的问题：我可以不依恋任何人吗？可以，而这就是负爱、负恨与负知识。

负爱则负恨，就是不喜爱，不去恨，而负知识则负广义了一些，首先是我不去了解，拒绝我在讲解时，忽略了这个最容易讲的部分，而集中讲解了负知识的那一层含义“了解进入心灵深处，它只是为了彰显自恋；了解了他，只是为了控制他。”

在《头脑妈妈》这篇文章中，我使用了李雪发现的概念，他概括地精确地表达了一个东西：在形成依恋态度的孩子中，妈妈真实地养育了他们；而在没有形成安全依恋的孩子中，除了真实妈妈在养育外，他们的头脑中，还有一个“头脑妈妈”养育了他们。

对于太孤独的孩子而言，头脑就像母亲，有“后头脑”来认同他们的头脑，构成“后天头脑”，来体会应该是头脑的身体和情感的共同体，但在头脑主导的自体中，主要被剥夺的，就是孤零零的头脑，身体和情感是剥落的。因为身体和情感中，有很多痛苦，多很多泪。

如果你发现自己有严重的假自体，就可以通过爱情拥抱去撕破它。生命是一场赌注，用以拥抱的自体是我们血肉的内，而在大爱的爱憎憎仇中，一个赌输的人会醒来，一个赌赢的人生活会更丰盛。

所以，有了《去爱、去恨、去了解》这篇文章，其主题想要（去行动，去创造），但没有说完全，以后还会写。为什么是去行动、去创造，因为基于创造性的去恪守生命的行动，背后是对于世界的不信心的，是爱。所以《去爱》，是一种什么味儿，在相同意义上解释了含蓄的中国人是什么，实际上就是负爱与负恨。虽然我解释了一下含蓄，但我说，我还是很喜欢中国式的含蓄。

快意恩仇这个表达，让很多用户有了担心，可是，畅快要恨的人，至于有了看见可能释放的机会，如果待在负爱负恨中，那么什么都不会有。
