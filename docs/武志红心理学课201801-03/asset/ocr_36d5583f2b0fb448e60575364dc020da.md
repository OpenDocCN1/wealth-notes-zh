# 苏格拉底的死刑

古希腊有“三圣”：苏格拉底、柏拉图和亚里士多德，他们三人一脉相承，是西方哲学的奠基人。

苏格拉底一开始就提出了“认识你自己”，他还说“未经考察的人生是不值得过”。然而，在苏格拉底身上发生了一件大悲恸：他被雅典法庭判了死刑，罪名是对雅典不敬的神不敬、公众精神和败坏青年。

事情发生在公元前399年，那个时代雅典已经实现了民主制。雅典的法庭没有法官，只有完全由负责陪审和维持秩序，判决完全来自于陪审员，而陪审员是根据一定的程序选出来的。我认为可以说，雅典当时已经实现了陪审制和程序正义。

苏格拉底案，是一位检察官、一位辩护人和一位陪审法官联合发起的。陪审员有500人。陪审员在这时还不算是大案，大家的陪审可以说大约2000人。雅典法庭可以充分公开辩论，而陪审团中，苏格拉底毫无疑问地赢了，但在陪审员中还是犯了罪无法成立，并被判处死刑。

在雅典，“不敬神”是一个严重的罪名，很多人被指控过这个罪名。如哲学家阿那克萨戈拉，因为他说太阳是一块红热的岩石，月亮是一块土，这是亵神，这是人类历史上第一位“异端”，还给15岁发生的第一个实现社会制度的雅典。

又如哲学家普罗泰戈拉，他在《论神》一书说“我不能断言神是否存在，认识神障碍众多，第一是不对，第二是寿命太短暂”，也被指控“不敬神”，著作也被烧掉。

这样的人还多得很，包括雅典最著名的政治家伯里克利。伯里克利，是当时最有权势的人，但当老婆被抓了个强奸他人，他是百密无一疏的老让娶新妇。至于其他人，罪名一旦成立，他们共同的选择是逃，离开雅典。

伯里克利（Pericles，约公元前495-公元前429），古希腊思想家、政治家，在古历史上占据非常重要的地位。

伯里克利一生致力于经营改造民主政治，扩展雅典的势力。他促成了雅典在军事、经济、政治、军事和文化上的繁荣，在历史上占有比较重要的地位。

苏格拉底的自辩也可以说明。实际上，那些判处苏格拉底的陪审员中，有更多人并不真想判他处死，但伯里克利拒绝了上诉，也拒绝他伯里克利一样的态度，他坚持自己的观点，同时也认为自己的工作为雅典公民，这遵守雅典的法律，最后饮下毒酒而死。

我们都知道，古希腊有一个神法体系，所谓不敬神，就是不信神，对这些宗教的神，确定，一个人，人的科学家的宗教，我相信这些神，那么，苏格拉底的信徒神是什么？

通常的说法是，苏格拉底信仰的是宇宙理性神，他认为宇宙理性神，是人类德性和智慧的源头。苏格拉底曾自己说，他有一个内在的“神”，在陪审中自己说，他行动的时候，总是听从心中一个声音，这个声音会告诉他，什么事该做或是不该做。例如参加政事，很多是声音的是“不”，而不是在参加这场公法的维护时，这个声音完全不反对。

我在这之前写到概念中，人类到了弗洛伊德这儿，潜意识概念深入到人心，这个说法很易让人误解，好像是弗洛伊德提出了潜意识。当然，不能说潜意识，弗洛伊德只是已经提出，不能打开心灵的声音，而听见自己内在的灵性的声音，这个在神学里，就是西方最有形的神学，最清晰的潜意识的概念。
