# —— 爱与恨 ——

这一周我做了个艰难的探讨，谈了谈什么是非常，什么是恨。爱恨这样的东西，看起来很非常简单，但随着我进一步的思考后我多，却发现爱恨越来越难以定义。

我主要还是使用了比昂的一个理论，来阐释什么是爱。比昂有一个著名的网格图，有纵轴和纵轴，我只是研究了纵轴这一轴。这个轴中，最顶端的东西是贝塔元素。在我的理解中，贝塔元素是毁灭欲或死本能这些可怕的东西，它们不能被直接感知，而经由别人的容器，变成了阿拉元素。

容纳，意味着有容器和被容纳物。贝塔元素是最原始的被容器，经由初步的容纳变成了可以忍受的阿尔法元素。阿尔法元素仍然不能被直接感知，它再被容纳，变成了梦与梦境思维；再被容纳，变成了预想；再被容纳，变成了前概念；再被容纳，变成了概念；再被容纳，变成了科学演绎系统；再被容纳，变成了代数公式。这个过程，就是爱的过程。经由这个过程，人类的认识能力在不断增加。

反过来的过程，就是不断去破坏对人性认可的过过程，就是恨的过程。例如对人认认的禁区越来越多，这就是一个恨的过程。

在《爱是容纳、看见与连接》中，我讲了比昂一个很有意思的关系：关系的本质是看谁投掷焦虑，谁承受焦虑。按说应该是父母承接孩子的焦虑，但中国家庭容易是一个相反的过程，父母让孩子承载自己的焦虑。这个时候，如果你把这当成是对孩子的爱，可就是占了便宜还卖乖。

这周主要讲的是恨，我们对恨的恐惧，来自于恨意中有毁灭欲，而我们在婴儿时期觉得自己是全能的，所以有了全能毁灭欲这个东西后，我们会惧怕，恨意真会带来自伤、客体破坏关系的毁灭。例如，婴儿会很嫌弃他们的尿袋和口水，都可能推搡摧毁乳房这一原始的容器。这就引出了“加餐：给毁灭欲披上一层‘胶囊’”，这是我非常喜欢的文章，觉得是对比昂的容器理论的一个很直观的理解。如果你没有读，建议你读一下，不过别在吃饭时候读了。

当我们了解了“恨”是这个东西之后，也许就不怕“恨”了，然后，就可以以《做一个“不好惹”的人》。

# —— 最难面对的平实之物 ——

最难面对的自我的虚弱，和关系中的恨；最难活出的，就是自我的坚韧，与关系中的爱。

说起来，道理都是这么简单。然而，要把它这个道理活出来，却很不很，甚至说到这个虚弱和恨意，都很难不算弱。我们看到这些“东西”为“毒”，视为坏东西，恨不得从自己身上切除掉，而这么做时，我们会变得更虚弱。

所以，在《一念之转：你就是我》这篇文章中，我做了一下自我暴露，讲了我这个滥好人得转变过程中，首先就是面对了我的狠意，面对了这个意识中充满破坏力的自我。这个过程很痛苦和容纳破坏，让我变得更有力量，然后我才能去面对更难的东西——自我的虚弱。

关系中的爱恨，和自我的坚韧与虚弱，有着无比密切的关系。我们在饱满的悦情关系中，才能形成真正坚韧的自持；而在充满恨意和关系中，坚韧的自体很难形成。因为在本质上，“我”就是“你”，“你”就是“我”，“你”就是整个世界。

所以在本周的回答中，我简单表达了 这个概念：任何一个关系，任何一个“你”，我们都以视为就是整个世界。所以任由一个“你”的视角来看，充分地深入去爱去恨去了解，都是一种恨本性的事情。

真的爱上一个人，就是爱上整个世界。一如我此前所说的：对爱情的信心，就是对整个世界的信心。
