# 空间07 | 个性化、社会化与体系化

吴志红

我们这一代人的生理，创造你的，社会空间，令兴趣第三。个性变化，社会化与体系化。

在个人成长中，每个人都面临一个矛盾：做自己希望的理想，还是成为社会希望的个体。

前者，我们可以称之为个性化；后者，可以称之为社会化。当然两者是彼此相成度上实现了社会化，成为了自己，又达到了个体也，完成了社会化。

个性化太过，就会与社会脱节，当一个人不能融入社会时，就容易在各个方面出问题，甚至产生严重的心理疾病。人对社会一旦失去信心，当去跟人打交道的时候，就会感觉自己好像失去了一部分极其宝贵的东西。

社会化太过，在表现中变得体系化，成为体系的一份子，个体生存变得生存空间，并在心理上依赖体系。甚至觉得自己只是体系的一份子，如果脱离体系，不仅仅是体系，甚至会觉得自我出现瓦解的危机。这种体系化，是一种异化。

追求个性化，意味着一个人把自己的真实自我呈现给这个世界，一定会带来很矛盾，其中一个原因是：因为呈现的是自我，所以呈现自我就带有被否定、否定真实自我的风险。

体系化则避开了这种心理危险，将真实自我隐藏，把自己放在某个体系的后面，这意味着没有机会被否定。但是没有机会被否定，也就没有机会成长，没有机会成长的自我也随之成熟。

体系化与个性化，也是职业生涯发展的一个矛盾。

接下来，我想通过一部电影，来讲解体系化与个性化的问题。这是我最喜欢的电影之一，《守法公民》。大概情节是，男主角克莱蒂森在遭遇不明袭击后幸存，重获自由后帮助警察将杀害妻子和女儿的凶手绳之以法。

警察局官员克里克负责这个案子，有极好的声誉，被他指控的嫌疑人几乎都被定罪，这是一个难得的官员。尼克自己也很引以为傲。然而，为了让我们这一类难以捉摸的尼克，使用美国司法体系中的一贯做法，尼克的嫌疑犯达成了认罪协议。

主人与公克蕾德美系被杀了这个案件中，因为缺乏关键证据，检察官尼尼克克和主权达成了认罪协议，结果犯被减刑，并主动获得了轻判。尼克的正义心使尼克克克对他感到失望。但是，他选择了这样做，并帮助两名嫌疑犯都被定罪，是一场胜利。

不仅尼克的家人很感激，尼克克的老师，美国联邦的检察长克也是如此。克克克克克克克克克克克利很深地刺痛了主人公克莱德，他决定报复。

克莱德花了多年时间准备他的报复，杀了刑事满刑和刑法法官，主管以说理说理了负责他整个司法体系。然而最终他被尼克克破解。主人，他的目的是为了自己，监察官员克德苦地意识到，自己错了。

> “我年轻的时候，很渴望改变这个系统。我想抗争，不惜代价，做到最好。但是让我一步步，退让，到最后陷入到无知的黑洞。然后意思的到了，我很想改变的这些系统，却改变了我。”
