# # 预告：爱与恨

武吉虹

这是我们专栏的第二十九周，我们今的主题是“爱与恨”。

谁都会说爱，谁都会说恨，“爱”、“恨”这两个词几乎是如雷灌耳。但是什么是爱，什么是恨呢？它们应该怎样被定义？

对“爱”和“恨”有一个定义，这并不可怕，实际上，最近两年有很多次数，我对我咨询师朋友们说，我现在的目标，我知道的是爱了。

看看我们的理论体系也会发现，我们迄今为正在说什么是“爱”下过定义。也有一些用户在留言中间，如果说精神分析方向，自恋、性和攻击性是人类三大动力，那么爱和恨在哪里，它们不是动力中的一种吗？

这真是另一个问题。本周，我就试着来定义一下“爱”和“恨”。在我们正式开始这期内容前，我也想请你来说说你对“爱”和“恨”的定义。

分章这首诗，我也是想说，别只是在知识里面去追求，好好去爱吧。你能像在什么样的方式去对你身边的人表达爱意呢？

青鸟别
爱是一种让自己和对方都感觉美好的关系，恨则是让自己和对方都不舒服的关系。

关于爱意的表达，《爱的五种语言》一书中有精彩详细的描述。这五种语言是一语话、身体接触、时间、礼物、服务及主动拥抱和陪伴。
不同人表达爱意的方式不同，接受爱意的方式也不同。用对方喜欢的方式去表达爱意，可能正是正爱姿态。
