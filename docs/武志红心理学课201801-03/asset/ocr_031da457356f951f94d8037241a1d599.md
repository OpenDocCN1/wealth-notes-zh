# 问答：梦可以整理心灵碎片

一些知识类，然后再回答一些问题。

武志红

今天我们要讲的问答是梦。我们先来读一些知识类，然后再回答一些。

关于梦，弗洛伊德有一个说法，他认为梦是愿望的实现。意思是梦会倾向于圆我们白天的一些梦想。弗洛伊德有一个说法：梦有整理心灵碎片的功能，这个说法我非常赞同。我们白天遭遇各种各样的事，我们要活在社会中，关系到我们，很多心灵材料就没有被整合到我们的自我中，梦会帮助我们整理这些心灵碎片到自我中。

梦的这个功能还可以引出一个说法：梦会思考，而梦中的思考，常常是胜过我们在清醒时的思考。据说门捷列夫的元素周期表的发现，就是借助了一个他常常做的梦，就是他在梦中做了一个元素周期表，简直是无与伦比。

讲一个我自己的亲历梦想，也是非常常见的考试梦。考试梦，常得担心自己的某一科或某一些科目没有考好，这种考试梦经常发生，我给大家讲。一个是你担心自己过不了这一关，比如考公务员，做了一个考试梦，就是担心过不了关。第二种可能是道德考验，比如你白天对一位异性产生了欲望，晚上了做了考试，这位考可能是超过你应不应该，你太本急了；三是安慰性？我们梦中的考试科目，通常是新不长尾花了很长时间，所以梦会拉长我们的意识，一种是考试，就是焦虑，所以不漫长到一刹那觉得，嗯，这一科虽然差，但我还是考过了。

我做过很多的考试梦，通常是高中文数学。因为我最整梦经常花了一年半的时时间，才把我当初的梦分析了一模半的考试梦，我做了很多的考试梦。

我有过一次例外，有一次是梦见考试，考的是难也，我能在梦中勇敢地考，大考过这张试卷，考的是地理题的题，这需要一些技巧，现在没有地理的题，梦是有一些题。

我在2013年梦醒了，当时，我对于家庭和社会的一些形势形成了基本状态，虽然梦醒，但回答是我大时自己出的考题，人回到我是怎么回事？当时做了一个考试梦，醒来后，我觉得，这是我最后一次做考试梦了，竟然也是。

我特别喜欢我在梦中的思考，我觉得他简直是绝顶聪明的，例如，我一直在学认识梦，我们说一个概念，梦是永远不能理解，然后有一天梦中，梦中像是有一力量在对我解说梦境认性，讲解精纯，现实中没有任何人能做到这一点。

很多用户问我怎么知道我想梦是对的，我的梦是理性的，我有个认人觉这梦只能到的是你感觉到的。也就是你的感觉和直觉，知道你的梦醒是否准确。

人是万物的尺度，而你的感觉是你心灵的尺度。这件事很难形成量化的科学指标，当然，人会很想去验证这些感觉是否准确。

有过晚上做梦，但白天梦醒的情况，难道是自我防御机制在起作用了吗？这会有一些严重的后果吗？

武志红

很多用户在问这个问题，也许我们要加一个前提，在创伤情景下，同一，我们也看是否，特别是梦中的关键。

梦，作为潜意识通向意识的通道，总是会做某种修饰，不一定都是直观的表达。也可能是梦想在整理白天的一些碎片，并且晚上的梦，显然是取得在白天中的素材，但梦醒关键点做了修饰。

在某段不顺利的时期，我常常会做梦，而且目标很明确，但生活中，没有太多目标，甚至不知道了发生中可能出现的事物。在我解梦时，我如何知道哪些是重要的，哪些是不重要的？

武志红

我个人认为，这些中的标准只是你的感觉，那些最给你强烈感觉的细节，或是记忆非常生动的细节，可能是重要的细节。

“角色扮演”可以理解为“进入他人的印象”吗？如果可以，如何进入梦中的“陌生的”事物，例如，在梦中梦到某个人，但是不知道他/她是谁，这种情况应该如何处理？

“角色扮演”可以理解为“进入他人的印象”吗？如果可以，那对于梦中某些具体的细节，例如，梦到一些事情，但是不确定，该如何理解？

例如，梦见到一个蛇，但不知道是什么蛇，梦到蛇是常见的梦，我梦到蛇，梦到蛇是一种什么样的心理状态？

武志红

我认为，当有这种可能，就是你的感觉，而不是妈妈的感觉，而是梦者的自己的感受。

对于长期活在一元世界中的人，这种的练习也常常无效，因为他们难以共情他人，共情他人的能力在他们那里，通过角色代入体验别人的感受，这并不是很难发生。

调问梦中梦怎么理解呢？以前有这样的梦，梦到什么时，当时我是清醒的。

武志红

人的心灵状态，会有各种各样的表达方式，人的心灵通道，通道是一个通道，梦中的梦，就是这个通道中的一个存在方式。

我认为全然的梦境，就是一个人的自我已经不能发挥作用了，彻底被潜意识的潜意识支配，这是一种无意识的状态。
