# 平行志愿投档是什么？

平行志愿投档原则是“位次优先，遵循志愿，一轮投档”，也就是说同一颗雷某批线上按考生投档分从高分到低分排序，确认位次，然后按照位次逐个检索考生所填的志愿院校。经检索到符合投档条件的院校，即投档到该院校，平行的后续志愿将终止检索，一轮投档就结束了。
