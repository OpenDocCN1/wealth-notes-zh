# 成语补写，

C-题体解题逻辑：

1.  分析语境：
    - ① 根据题目信息，判断成语在句子中的感情色彩（褒义、贬义、中性）。
    - ② 根据成语的适用对象（人、事、物）选择合适的成语。
    - ③ 注意成语的语法功能（动词、形容词、副词等）。

2.  排除干扰项：
    - ① 检查成语的字面意思是否与语境相符。
    - ② 注意成语是否有固定的搭配对象。

3.  确定答案：
    - 综合上述分析，选择最恰当的成语填入空白处。
