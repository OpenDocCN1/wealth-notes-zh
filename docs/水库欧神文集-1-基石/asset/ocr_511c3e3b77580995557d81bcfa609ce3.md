# 五）统一市场

中国在 1949 年之前，一直都是传统的中古“农业社会”。

农田的本质特性，是地理上的分散性。

因此中国大地上，星罗密布地分散了几十万个村庄。“牛家村，李家庄”，种植业土地的分散性，决定了人口的分散性。
