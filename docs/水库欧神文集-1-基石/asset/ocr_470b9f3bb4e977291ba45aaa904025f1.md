# 四）结语

千门八将：正、提、反、脱、风、火、除、谣
正：摆在台前的人物，类似于武僧“一龙”[2]
谣：搞乱舆论的水军。
火：以武力处理问题
除：事后的谈判抹平

三大宗教可以混得这么大，纯粹是靠“吹”。
是把千门八将的套路发挥到了极致。

这不是武术的凋零。而是骗术的凋零呀。
