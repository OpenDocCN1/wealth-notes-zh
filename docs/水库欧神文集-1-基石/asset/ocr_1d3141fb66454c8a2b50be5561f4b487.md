# 三）通货紧缩

我少年读书，满腹疑窦。好几个问题，一直思索了十几年，苦苦探寻答案。

其中一个问题，就是老师介绍的，“可怕的1929年美国大萧条”。

这一次大萧条，被誉为“通货紧缩”的典范。

在政治课老师的描述上，资本主义的邪恶真是没边了。

+   价格不停下跌
工人没有工资
没工资没购买力
价格进一步下跌

当年政治课读到这段时，哥哥无论如何不能理解。绝对反直觉的。

“循环排位中，怎么可能每个人都是输家呢”。
