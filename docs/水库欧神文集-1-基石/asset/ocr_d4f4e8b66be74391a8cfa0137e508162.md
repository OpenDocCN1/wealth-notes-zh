# 二）下九流

炒股的看不起炒楼的，这几乎已是目前社会的公论。

炒股的看不起炒楼的，认为炒楼是下九流。认为那是土豪和温州大妈们干的事。平均文凭不会超过初中。

而炒股是高大大的活，要牵涉到利率，汇率，宏观经济走向，货币政策，财政政策，美国QE，日本大选，印尼局势，中东地缘政治与原油供应……

炒股的认为自己从事的是一项高大上的事业。是知识与学历的完美集合，是技术分析与哲学勇气的揉和。每当屠丝观测K线图时，激动得浑身发抖。似乎明天他就可以成为巴菲特索罗斯
