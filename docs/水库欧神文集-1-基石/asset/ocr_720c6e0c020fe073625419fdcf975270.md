# 七）王族之骄傲

政府的权力，应该被极大削减。

例如《电信法》《邮政法》《保险法》《商业银行法》，所有的法律，都是恶法。

如同我们在《经济学第二定律》中说的，如果是 AB 都有利的事情，则不需要政府立法。

AB 自己会找到协同协作的方法。

只有对 A 有利，对 B 不利，而且 B>A，效率净损失的情况下。你才需要《立法》，才需要强制以法律的行为，规定哪些可以做，哪些不可以做。

所以《商法》的一切法律，全部都应该废除。市场可以创造一切。

对于“君王”，君王只需要管《刑法》。

君王不需要营造造铺路，抚育孤老之类毫无意义的事情。
