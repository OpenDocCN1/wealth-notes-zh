# 一）伐木

前两天，有人在“水库”知识星球，问了我一个问题。

刚果、非洲等国家，是不是再也没有机会，造起来百万吨级的钢铁厂。因为所有的制造业，都已在中国完成。

他们会一直贫穷。

答：不造钢铁厂，他们会更富裕。

长期以来，我们生活在谎言之中。

如森林迷雾，无所不在。

生于斯，长于斯。“缸中之鱼”，更难认识真实的世界，真实的物理，真实的底层道理。

无限拔高“工业化”，尤其是“19世纪的工业化”。是一个显著的教育败笔。

我们先举一个例子，17世纪时，一个“工业化”国家最闪亮的产业是什么。是“伐木业”。

因为几乎一切的设施，都需要木材。

造房子需要木材，造军舰需要木材，造成器需要木材。
