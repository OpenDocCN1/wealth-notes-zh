# 房价下跌天下毒 #1940

+   一） 媒体

1993 年的时候，中国还是一个相对贫穷落后的国家。

当时浦东开发，上海《新民晚报》社，派遣了一支小队到沙特去，参加国际会议，向外国友人取经。

沙特一家媒体的主编问，“贵刊发行量多少”。

新民晚报谦虚地说“不多，不多”。

沙特媒体骄傲地，写下了数字：“3 000”

《新民晚报》拿过便笺纸，写了“1 000 000”份。

沙特小编昏了过去。
