# 五）经济学第三定律

铅笔社谭叔之流，属于脑子僵化，我甚至都怀疑他如此自傲，以致于再也听不进新的知识。当见识了“经济学第二定律”之后，他肯定又会回答：“暴力也可以市场化，镇政府可以自由选择警察公司”之类妄语。

拜托，我们谈论的是**军队**。不是警察好么。

**最终暴力**无法被替换，也不可能被包含到“市场”概念中去。

这是经济学第三定律的内容。有空再讲。
