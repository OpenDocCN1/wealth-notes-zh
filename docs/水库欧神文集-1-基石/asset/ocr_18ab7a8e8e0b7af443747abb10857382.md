# 白爽三年，有什么不好。

同样道理，“荷兰病”并不是病。荷兰在 1959 年之前，和 1982 年之后，其实在欧盟内部，过得都差不多的日子。享受差不多的地位。

但 1959~1982，当中有 23 年的时间；

这 23 年，荷兰人爽了啊。挥金如土，和中东土豪无异。这又有什么不好呢。

让我们也多几个油田吧。

真正难受的，是 1982 年之后的“调整”。

由奢入俭难。收缩带来的痛苦，远远大于放纵学坏的速度。

而且在民主社会，特别忌惮“让老百姓勒紧裤腰”。很容易导致内阁垮台。
