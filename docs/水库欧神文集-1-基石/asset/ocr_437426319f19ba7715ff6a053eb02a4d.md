“交易” 产生的财富，也远远超过了 “生产”。

大概是 “交易” 75%, “生产” 25%

商业创造的财富，是工业的三倍。

+   - T 代表 Trade，贸易。

+   - dT 是微积分符号，代表 T 的微小改变。

+   - dT > 0，就是任何一个微观的角落，Trade 轻微增加，都是好事。

譬如说，经济学中有著名的 “帕累托最优”。指的是一个经济体，在现有的科技之下，所能

达到的最大生产力。

传统教科书上，帕累托最优是三重最优。

+   1) 生产者最优，生产量最大化。

+   2) 消费者最优，消费者的口味最佳化

+   3) 生产/消费比例最优。

但是在 dT > 0 的公式下，整个帕累托最优可以简化成一行字。

+   - dT=0
