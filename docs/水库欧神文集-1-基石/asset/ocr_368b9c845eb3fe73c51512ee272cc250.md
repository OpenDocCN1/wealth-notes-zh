# # 单一市场

网络有多大，生意就有多大。不超过市场大。

中国人，从分散居住，组织度松散的农业社会。

倚靠现代通讯，现代物流，在庞大的国土之上，逐渐凝聚成了“统一市场”。

从此以后，你不再是三十万个分散的村庄。

你是 3 亿人口大市场。
