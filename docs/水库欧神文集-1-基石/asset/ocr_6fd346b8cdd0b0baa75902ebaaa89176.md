# 四） 经济学的王冠

在《论儒·法·禅宗·基督自治和道教的复兴》#10 一文中，我们说道了“大学”的概念。

“大学之道，在明明德”。

这里的“大学”，并不是后世 University 的意思。

这里的“大学”，其对应的名词是“小学”。

儒家学者们认为，“儒道”才是大学。才是国家运转和维持的根本大道。

其他数学物理化学，纺织炼钢石化，统统都是“小道”。
