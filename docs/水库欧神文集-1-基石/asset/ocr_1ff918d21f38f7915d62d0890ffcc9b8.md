# 二）理性基础

两个人坐在一起讨论学问，一定要有一个“共识基础”。

要有一块共识的地基，然后才可以向上讨论问题。

譬如说，二个粤菜师傅坐在一起。则双方对于“浓汁高汤”，基本是没有什幺分歧的。

剩下的，仅仅是料理的手法和辅料的添加。可以直接从很专业的层面聊起。

但是，如果一个是粤菜师傅，和一个英国厨师坐在一起。

双方的“共识”就很少了。

英国师傅，会觉得白汤高汤破坏蛋白质。

粤菜师傅，会觉得英国主食都是猪食。

双方剩下的“共同点”，或许仅仅是“色，香，味”摆盘的考究了。

更进一步，如果是一个厨师，和一个音乐家坐在一起。
