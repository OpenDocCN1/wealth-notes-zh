# 日课148 | 决策理性批判

日课148 | 决策理性批判

请原谅我斗胆用了一个康德式的标题。但是我们今天要讲的这个道理，我敢说就是康德本人也会感兴趣。

咱俩说一点哲学。我们专栏经常说决策的事情。所谓做决策，简单地说，就是看自己都有哪些选项，然后从中选择最好的一個。这个动作也是战略的本质，战略就是要决定“做什么”，剩下的“怎么做”都是细节问题。

决策科学包括怎样给自己增加选项，如何克服偏见公平评估每个选项的价值，这也都是一些细节问题。做决策的大框架——选择最好的选项——是永远都不变的。决策，归根结底，就是选择。

什么叫理性呢？理性的一个定义，就是你的选择得有一致性。我们以前说过，博弈论的一个基本前提，就是你得有这种选择的理性。比如如果你认为菠萝比橘子好吃，橘子比苹果好吃的话，那么我就可以推导出来，你一定认为菠萝比苹果好吃。

如果于接下来非得跟我说苹果比菠萝好吃，那你就是非理性的，我就没法给你出谋划策。只有当你的选择具有一致性的时侯，我们才用得上数学，才谈得上科学决策。

而咱俩今天要说的是，所谓理性选择，其实是一个神话。

你可能马上想到了“行为经济学”，你知道人有时候是非理性的，人容易被外部环境、被各种偏见影响。但我们今天说的可不是那种非理性。我要说的是，哪怕你头脑完全清醒、特别理性，你还是会面临不知道该怎么做<|message|>

这段时间咱俩一直在讲育儿，高普尼克在《园丁与木偶》这本书的最后有一段非常精彩的讨论，说的是到底应不应该要孩子。

这件事儿怎么科学决策呢？你得评估要孩子和不要孩子这两个选项的价值。为此，你可能要深入考察一下身边的人，看看有孩子的家庭和没有孩子的家庭的日子过得都怎么样，看看你想过哪种生活，对吧？

几年以前网上流传一篇吉，...

所以在要不要孩子这个问题上，你永远都不可能做出理性决策——因为你除非亲身经历，否则不管怎么做都无法准确评估这个选项！

高普尼克把这个分析又推进一步，说生孩子之前的你和生孩子之后的你，根本不是同一个个人。

这大概就有点像张爱玲的《红玫瑰与白玫瑰》——

娶了红玫瑰，久而久之，红的便变了墙上的一抹蚊子血，白的还是床前明月光；娶了白玫瑰，白的便是衣服上沾的一粒饭麸子，红的却是心口上的一颗朱砂痣。

这里面没有理性选择。当你做选择的时候，是现在的你在为未来的你做选择。可以说，你是在选择变成谁。

所以有一句话说得特别好：如果你没有某个东西，你千万不要抱着酸葡萄心理论它不好——因为你根本不知道拥有这个东西会是什么样的感觉。有些人爱说我视名钱财如粪土——你最好有了功名钱财再这么说。

这是一个非常深刻的见识。这意味着你根本就不能理性决定到底应该要孩子还是不要孩子，到底应该娶红玫瑰还是白玫瑰。你肯定是瞎了头才结婚生子！

放眼市面上各种励志书、成功学和人生指南，都在告诉你*应该*怎么做，它们都是把人生描写成一个算法，给你提供一揽子解决方案。但是你仔细想想，这种算法根本不存在。

理性选择需要评估选项，评估选项需要标准，标准是由价值观决定的——而我们今天看到，人的价值观念本就不稳定，可以变化。

劳里·安·保罗说，甚至连什么样的价值观念“好”，也没有科学的判断方法。你甚至无法科学判断，价值观是多元有些好呢是专一一些好。你不知道人这一辈子应该只为一个目标而努力，还是同时追逐多个目标好——更不用说选择这些目标都是什么了。

哲学家以塞亚·伯林感慨于此，说人生就是悲剧啊。人永远都不可能知道*应该*怎么活，没有一个选择是绝对正确的。说了我们都是浑浑噩噩混日子，只不过有些人感受不到而已。

不过高普尼克比较乐观，她说这个无所适从，正说明了人活着有意思。正是上周有一位读者问我，如果大数据和算法那么厉害，将来人的命运是不是都归算法指挥呢？通过今天这个讨论我们有了更明确的答案，那就是绝对不会。人生不能算法化，今天的你无论如何都不知道明天的你想要什么，你无论如何都不能预测自己会成为什么样的人。

说了这么多，能不能给点指导意见呢？我可以给你提供一个建议，但是这肯定不是科学的建议。

有一个决策标准，是把人生的“后悔”给最小化。
