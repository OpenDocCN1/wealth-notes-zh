# 日课168 | 《为什么》7: 为什么必须回答为什么

今天咱们继续讲讲诺亚·穆尔的《为什么：因果关系的新科学》。小学老师经常说一句话，你不光要“知道是什么”，还要“知其所以然”——你光会做作业不行，你得知道这件作业为什么还要做才行。这就是“为什么”。

这么简单的道理，可是竟然有众多统计学家居然认为没有必要去探究为什么，有相关性经验就足够了。读完这本书我觉得讲完了，今天咱们就讲讲为什么探究是不行，为什么你需要理解因果关系，为什么要回答为什么。

# 3.一次数学改革
