# 日课121 | 所罗门悖论

日课121 | 所罗门悖论

我们平时读很多书，包括在“得到”听课程，也包括我们精日课专栏，你想到的都是要获得一些“智慧”。并不一定非得是像编程那样的实用课生技能，我们更想得到的是能帮助我们做出科学决定的知识。

但是学会了决策知识，不代表就会用这些知识。

当然这不是说读我们专栏没有用。如果你仔细读，我敢保证你的理论水平肯定会提高 — 但是理论水平高，不见得实践能力就强。这就好像研发了一个新药一样，按理应该有用，可是如果不做系统性的.ge研究，谁也不能保证，对吧？

事实上，这可是个大问题。

加拿大滑铁卢大学的社会心理学家伊格尔·格罗斯曼（Igor Grossmann），就专门研究这个问题。他的研究结果并不太乐观。

格罗斯曼打了一个比方。古代以色列的国王所罗门，特别擅长给别人建议。如果你有什么疑难，你去问所罗门，他就会告诉你该怎么办。很多人从很远的地方专程来向所罗门寻求建议。所罗门说出话来都是一套一套的，而且别人听了他的建议，也确实好使！所罗门，真是智者中的典范啊。

![](bbox=[0.17, 0.00127, 0.92, 0.0017800000000000001])

但问题是，如果你考察所罗门自己的生活，你会发现他做了很多错误决定。他放纵感情娶了很多美女，他会图钱财还爱向别人炫耀财富。所罗门只有一个儿子，但是他没有好好教育，以致于所罗门死后，儿子是一个暴君。

你这么聪明的人物，能整天给别人提建议，但是自己的生活却搞不好。格罗斯曼把这个现象叫做“所罗门悖论”[1]。

这个问题不解决，你读多少书，也可能过不好这一生。

# 1.智慧

我们专栏第一季有一期叫《到底什么叫“智慧”？》，其中分享了一篇论文，就是格罗斯曼领导的几个小组合作用研究的。现在心理学家对“智慧（wisdom）”这个词有非常明确的定义，叫做“明智的推理”。有智慧的人并不一定智商有多高，算数学题能力有多强。有智慧的意思是说，这个人处事能力与决策能力比较强。智慧大概包括这么几个方面——

首先是知识上的谦逊。就是我知道我的知识是有限的，我要寻求更多的信息才能做出很好的决策。我不能冲动，一上来就胡乱决策。就好像《中庸》里说的“戒慎乎其所不睹，恐惧乎其所不闻”[2]。

其次是要超越自我。就是要能从别人的角度去考虑问题，不要光想着我怎么样。

第三是要善于达成妥协。就是不能光想我的利益最大化，我也要考虑别人的利益。

最近就有个特别好的例子。我们知道有个综合格斗拳手叫徐晓冬，现在非常火，连续击败了传统武术的人物。不久之前打败太极拳大师的时候，徐晓冬给人印象还是个特别狂的人。传统武术都不行，一 shall要来了我站着不动都赢他，而且还爱说脏话。

可是最近打败了咏春拳的丁浩之后，王志安在《局面》节目里对徐晓冬有个访问，徐晓冬表现出了智慧。

![](bbox=[0.17, 0.00435, 0.92, 0.00495])

比如说，徐晓冬说，我的体重比“丁老师”重，所以我开手先不进攻。王志安说你打倒了他六次，徐晓冬马上说只有两次是“打倒”，剩下的四次只是摔倒。比赛实际上是徐晓冬大胜，但是裁判宣布双方是平局，王志安说你对这个结果满意吗？徐晓冬说满意，这只是一场交流赛，胜负不重要。

徐晓冬居然还特别强调，中国武术是一个大家庭，我也是中国武术大家庭的一员！

当然徐晓冬还是说了很多实际上是嘲讽性质的反话，可是这跟以前微博上那个咆哮的徐晓冬已经是判若两人。微博评论都说徐晓冬变成熟了。

那徐晓冬是怎么变成熟的呢？我们设想，他大概不是因为短期内读了很多书。

# 2.智慧可能很难学

格罗斯曼的一系列研究表明，人的智慧跟情境密切相关。也就是说，一个人可以在某一方面、某一时刻表现出很高的智慧，但是在另外一方面却可能表现得很没有智慧。

一个人谈起人生意义来头头是道，但是他跟同事的关系却搞不好。一个人工作能力特别强，把手下人管得特别好，但是家庭生活却非常糟糕。一个人私下场合很靠谱，发微博却爱胡说八道。这跟智商完全不同，一个智商高的人通常各各种智力工作都能表现出高水平——智商是一个基本素质。

格罗斯曼刚刚在《欧洲心理学家》上发表了一篇综述文章[3,4]，其中提到有些研究让受试者记日记，随时记录在什么时候遇到什么事都是怎么做的——结果发现，一个人在一天之内，可以有时表现出来有智慧，有时候却很没有智慧。再进一步，智慧跟人的性别、受教育程度关系都不大。唯一有关系的是年龄，年龄大的人，可能因为经历的事情多，更有智慧。

如果智慧不是一个基本素质，甚至智慧跟受教育程度关系都不大，那么智慧还是可以学的吗？

很难学[4]。有人做过实验，先给一些学生说道德课说要帮助别人，结果就在刚刚听完课、这些学生走出教室，真的遇到一个需要帮助的人的时候，他们并没有比一般人更愿意提供帮助。等于说这个课白讲了。还有研究发现，专门研究道德哲学的那些学者们，他们自己办事的时候，并不比别人更有道德。

这不正好符合培勒布对知识分子的批评吗？这些人只有说到没有做到，哪里有什么文如其人或者为人师表。

啸吟以前还谈过，纽约时报专栏作家级维·布鲁克斯，读了心理学家丹尼尔·卡内曼和合作者阿摩斯·特沃斯基的传记之后有一个疑问：这两个人一辈子就是研究人生决策，按理说他的决策水平应该很高——可是纵观整个传记，你发现这两个人一生之中根本就没做过多少决策。他们唯一的一个大决策就是选择以色列移民到美国。

所以这不都是纸上谈兵吗？学了也无用，研究者自己都不决策。这个所罗门悖论，应该怎么破呢？

# 3.提高智慧的方法

也并不是一点希望都没有。格罗斯曼就测试过几个行之有效的方法。

一个方法是你要把发生在自己身上的事，想象成是发生在别人的身上。

比如说，格罗斯曼做过一个研究，他让受试者想象，你的男朋友或者女朋友出轨了，你怎么办。很多人都表示马上分手。

但格罗斯曼还有一个问题。说如果 lubrication 的好朋友的男朋友或者女朋友出轨了，你会怎么给 ta 提供建议。

格罗斯曼有一个问卷评分系统，能测试人面对事情时表现出的智慧水平。这些测试包括——

+   * 你是不是需要关于这件事情更多的信息呢？
* 你是不是需要了解一下这个事情发生的背景呢？
