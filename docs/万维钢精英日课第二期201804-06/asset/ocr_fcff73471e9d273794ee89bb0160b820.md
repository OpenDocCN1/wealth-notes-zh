# 日课166｜三种“谦卑”

日课166｜三种“谦卑”

珂尔的《为什么》这本书越讲越难，今天咱们调整一下节奏，说个简单的话题。我想说说什么叫“谦卑”。

谦卑的英文是 humble，原本的意思是强调“卑”，是自觉得低人一等，表现出来是卑躬屈膝的样子，本来不是好话。中文加上一个“谦虚”的“谦”字，这个词立即就变得高级起来，感觉上是主动去放低姿态。从不得已卑到主动谦卑，性质完全不同。

其实在人人平等的现代社会，不论是英文世界还是中文世界、主流语境中凡是提到 humble 或者“谦卑”，都是高大上的好话。如果你说我是个谦卑的人，我当然是赞美。

谦卑，是一种美德。而且还不是一般的美德。以我的阅读经验来看，“谦卑”在英文世界被越来越高，已经到了精英人士最值得拥有的美德中排名第一的位置。

这种谦卑，是地位的计较。

第二种谦卑最大的好处，就是能确保你永远都不会自卑。

第三种谦卑，则是高人的专用词。它的意思是承认自己的认识和能力是有限的，承认自己会犯错误，所以保持开放的头脑，能听得进去别人的意见，能随时调整方向。
