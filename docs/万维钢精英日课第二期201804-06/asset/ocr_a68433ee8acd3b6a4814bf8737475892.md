# 日课162 | 正确的学习方法只有一种风格

日课162 | 正确的学习方...

老一辈的人谈起学习来总爱说什么时候“书山有路勤为径，学海无涯苦作舟”。现在认同这句话的人好像已经很少了，没人以吃苦而为荣。新一代更愿意追求“科学的”学习方法，人严禁认为学习这件事情应该是快乐的，最好能寓教于乐，让每个人都能够轻松愉快地获得知识。

我听说美国国院有个说法，叫病人有“不疼的权利”——既然病人来到了医院了，那就甭管用什么方法，先把疼痛给人止住再说别的的，动刀之前得先打麻药。这是一个充满现代感的权利。那学习这件事儿，学生是不是也有不疼的权利呢？

比如现在有个思想，说既然每个人的性格和喜好不同，那就应该根据每个人的喜好，给他量身定制一套学习方法。用自己最喜欢的方法学习，就好像选择发型、时装和卡拉OK歌曲的风格一样，这当不是很好吗？

现在有一个流行的学习风格分类模型叫VARK，你可以到它的官方网站 [1] 测试一下自己喜欢的学习风格。VARK 把学习风格一共分成四种：视觉、听觉、读写与动手实践。如果你是视觉型的，你可能会喜欢用看图片的方式学习；听觉型的可能更愿意听老师讲；读写型的人爱用读书和笔记的方法；动手实践型的人最爱做实验和演示。测试结果是学生们的确有不同的类型，还有的学生是混合型。

我们可以想象这四种风格就好像四个门派一样，不同类型的学生分属不同的门派。世界是多元的，每个人都有自己的选择，这多好啊。

好是好。现在我们要问的关键问题是，用自己喜欢的风格学习，是不是就能取得更好的学习效果呢？
