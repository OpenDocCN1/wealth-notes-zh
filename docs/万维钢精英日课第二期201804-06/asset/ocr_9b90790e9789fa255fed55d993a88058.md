# 日课139 | 《超越曲线球杆的战略》5:到底什么叫“集中力量办大事”

今天咱们《超越曲线球杆的战略》这本书讲完。我想重点说说战略的心理问题。

我们专栏叫“精英日课”，但我其实很不好意思说“精英”这个词。在当今世界“精英”略带贬义，让人想到那些脱离群体、可能还比较自私的人。但群体之所以一直是群体，可能也是有原因的。比如说，考虑战略的时候，你得克服两个群众式的心理障碍。

一个障碍是人们总觉得做大动作是比较危险的，安全的做法是不做动作。另一个障碍是集中在一个方向做事是比较冒险的，最好在各个方向上和稀泥。

合在一起，就是普通人做事，总想在时间和空间上都更平稳、更周全一些。

但是至少从麦肯锡这份研究报告来说，好战略应该走极端。

# 1.多“大”才叫“大”动作

我们前面说了，战略模型公司能做的事，一共是五个动作：循序渐进的并购、动态的资源分配、资本花费、提高生产率、产品创新，这五个动作加起来对成败的影响达到45%。

# 2.大动作比不动作安全

数据分析显示，做大动作不但没有增加公司的风险，反而还降低了风险。

# 3.大动作的回报

下面这张图是麦肯锡数据库中的公司做大动作的情况 ——

真正做了大动作的公司并不多，尤其是处于利润分布曲线中部的公司很不愿意做。有39%的中部公司一个大动作都没做，38%的公司只做了一个大动作。

# 4.找到你的曲线球杆

这本书的书名说要“超越曲线球杆”，我们也一直在说大多数部门给你承诺的曲线球杆enni项目的都不好使，但是归根结底，公司成长靠的恰恰是曲线球杆项目。

所以问题不是没有曲线球杆，而在于你能不能识别真正的曲线球杆，然后能不能给足资源。

到这里这本书就算讲完了。总结一句话，什么叫战略呢？

所谓战略，就是选择方向，集中力量，做几件能让你在利益分配曲线上有一个更好的位置的，大事。

“集中力量办大事”，是我们中国人特别爱说的一句话，但是我看一般人都不理解错了。
