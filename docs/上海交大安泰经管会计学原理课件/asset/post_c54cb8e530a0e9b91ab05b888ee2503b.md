## 等额支付的长期应付票据会计处理

On January 1, 2009, Foghog borrows $60,000 from a bank to purchase equipment. It signs an 8% installment note requiring 6 annual payments of principal plus interest.

|  |  | DR | CR |
|---|---|---:|---:|
| Jan 1 | 现金 | 60,000 |  |
|  | 应付票据 |  | 60,000 |

*Borrowed $60,000 by signing an 8% note*

Compute the periodic payment by dividing the face amount of the note by the present value factor.

| Computation | Table | Table Value | Present Value | Payment |
|---|---|---:|---:|---:|
| Principal divided by PV factor | Annuity of $1 (B.3) | 4.6229 | 60,000 | 12,979 |

## 普通股筹资的优缺点

- **普通股筹资的优点**
  - 普通股筹资没有固定的股利负担
  - 普通股股本没有规定的到期日，无需偿还
  - 利用普通股筹资的风险小
  - 发行普通股筹集股权资本能增强公司的信誉
- **普通股筹资的缺点**
  - 资本成本较高
  - 可能会分散公司的控制权
  - 可能引起股票价格的波动
