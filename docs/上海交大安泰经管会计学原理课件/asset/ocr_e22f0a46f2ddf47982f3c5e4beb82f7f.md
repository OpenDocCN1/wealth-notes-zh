# Bond Retirement

# Before Maturity

+   - Carrying Value > Retirement Price = Gain
+   - Carrying Value < Retirement Price = Loss

Let’s retire the Adidas bonds on June 30, 2009, after the first interest payment. The bond carrying value is $102,659, and the unamortized bond premium is $2,659. Because the bonds are retired early, a call premium of $3,000 must be paid to the bondholders.
