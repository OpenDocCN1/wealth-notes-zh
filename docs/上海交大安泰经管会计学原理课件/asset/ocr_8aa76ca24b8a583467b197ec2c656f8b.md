# 假设销货1000元，付款条件为2/10,N/30，不考虑增值税

+   - 总价法：
+   - 销售时：
+   - 借：应收账款 1000
+   - 贷：营业收入 1000
+   - 若在10天之内收回款项：
+   - 借：现金 980
+   - 财务费用 20
+   - 贷：应收账款 1000
+   - 若在10天以后收回款项：
+   - 借：现金 1000
+   - 贷：应收账款 1000

+   净价法
+   - 销售时：
+   - 借：应收账款 980
+   - 贷：营业收入 980
+   - 若在10天之内收回款项：
+   - 借：现金 980
+   - 贷：应收账款 980
+   - 若在10天以后收回款项：
+   - 借：现金 1000
+   - 贷：应收账款 980
+     财务费用 20
