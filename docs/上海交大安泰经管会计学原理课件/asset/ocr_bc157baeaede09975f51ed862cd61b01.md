# 预收帐款（预收收入或者递延收入）

On May 1, 2009, A-1 Catering received $3,000 in advance for catering a wedding party to take place on July 12, 2009.

|  | DR | CR |
|---|---|---|
| May 1 现金 | 3,000 | |
| 预收帐款 | | 3,000 |
| *To record advance payment.* | | |

|  | DR | CR |
|---|---|---|
| Jul 12 预收帐款 | 3,000 | |
| 收入 | | 3,000 |
| *To recognize revenue earned.* | | |
