讓我們考慮一個例子。一家新企業承諾提供10 % 的盈餘成長率，並在各種不同的資本利得稅率下，發行股票募集資本。請你根據表4.1所列的投資方案，評估這家新企業投資的可行性，假定你是一位擁有1萬美元資金的「一般」投資人。

表面上看，一般投資人可能會選擇高成長股票。實際上不然。許多投資人瞭解，只要一季的盈餘報告不理想，本益比高達40倍的股票很容易下跌25 % 或以上。就目前的經濟環境與高達33 % 的資本利得稅考慮，我猜想絕大多數投資人都會選擇中度成長的股票與債券基金的組合。

新企業承諾的報酬率只較債券基金高2.17 % ，債券基金幾乎毫無風險，這種情況下，誰願意投資新企業呢？新企業的風險遠較爲高——投資人可能損失所有資金！如果資本利得稅率爲15 % ，新企業投資的報酬較債券基金高4.69 % ，這或許可以吸引部份投資人。如果稅率爲0，其報酬率將幾乎是債券基金的兩倍，這當然可以吸引風險取向較高的投資人。

爲了說明資本利得稅對於邊際投資造成的嚴重影響，讓我們考慮下列簡單案例。史密斯擁有一家非常成功的州際卡車運輸公司，而且他有一個夢想。他希望成爲高速公路卡車休息站的麥當勞，提供廉價而高品質的食物給卡車司機與其他旅客。他的基本構想是在車潮較多的地區購買土地設置休息站。經過詳細的研究，他認爲最初可以建立100個單位。然後，經過10年或15年，規模可以逐步擴大爲1,000單位。
