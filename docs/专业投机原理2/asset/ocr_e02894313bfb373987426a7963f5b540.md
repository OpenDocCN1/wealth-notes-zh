在《專業投理原理Ⅰ》一書中，我曾經將相關的交易守則編爲一章「至少有五十種方法讓你發生虧損」。其中某些法則僅適用於場內交易員。因為我訓練許多場內交易員，為了讓他們瞭解這些法則的重要性，我將它們印製在卡片上。（深入的解釋，請參考《專業投理原理Ⅰ》。）以下是另一套稍有不同的交易守則，我交易的時候，一定把這些守則擺在身邊：

# 交易員守則

+   1. 不可過度交易。
2. 不可把虧損帶回家。
3. 不理想的交易部位不可加碼。
4. 不可讓獲利演變爲虧損。
5. 交易前，務必先決定你的停損位置。
6. 不可以成爲單方向的交易員。務必保持彈性。
