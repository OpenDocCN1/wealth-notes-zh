# 交易機會與市場波動

研究的過程中，第一個問題是：一年之內何謂「正常的」交易機會？根據我當時的交易策略來說，我認為在一個月內，如果市場出現2％的價格走勢，便稱得上是交易機會。於是，我回溯至1897年的資料，並計算每年某個月內出現2％價格走勢的月份數，結果列於表7-1中。我發現，每年交易次數的中位數是7次，平均數則為8.7次。換言之，由中位數考慮歷史資料，交易機會大約每1½月出現一次。
