
# CPI 消費者物價指數

CPI（Consumer Price Index）是一種透過時間變動，所產生的物價變動，也是衡量通貨膨脹的重要指標之一。若CPI指數過大就代表這個國家的經濟前景較為不明朗。

台灣地區透過家庭的收支來衡量其指數，透過調查反映民眾的消費狀況，可用來作為市場經濟活動，或是政府貨幣政策的參考標準，例如當CPI超過3%即為通貨膨脹，而CPI也是計算「核心物價變動率」的主要依據，當核心物價變動率低於3%時、代表經濟處在一個較為令人擔憂的時刻。當CPI上升2%、代表我們的生活成本要比一年前增加2%，由於金錢的價值不會隨著CPI升高也一併升高，導致你口袋裡的鈔票會因為CPI的提升而愈變愈薄。由於CPI涵蓋了食、衣、住、行、育樂、醫療保健、其他等七大類支出，所以CPI也能反映出居民消費型態的變化。

# 窮人把錢當糧餉，富人把錢當子彈

「只要把錢存起來，就可以變成口袋飽飽的有錢人。」

相信這句話大家一定耳熟能詳，尤其是口袋空空的窮人更是將之奉為理財準則；但背後的真相，其實是三流理財專家為了誤導你永遠當窮人的一流催眠術。

人類以前過著原始的採集漁獵生活，每天為了三餐而忙碌，後來進化到農耕畜牧的生活型態，開始學會儲存多餘糧食，為了避免未來發生糧食短缺的危機，於是人類想出將鮮肉風乾的方法，做成能夠保存比較久的肉乾。

但是再怎麼儲存，糧食只會一天比一天少，而且經常食用營養早已流失的肉乾，還會導致身體出現不健康的警訊，這種情形同樣也反映出現今窮人的金錢觀念。

窮人總是依照經營之神所說的：「你賺的一塊錢不是一塊錢，你存的一塊錢才是一塊錢」這句話，把錢一點一滴的存下來，就像糧食一樣，有多部就囤起來仔細保存。

只是他們忽略了一件事：把錢當作糧食，數量只會愈來愈少，還會隨著保存時間過長而日漸腐敗，最終變成沒有價值的廚餘。

愈存就愈少的錢，讓你的口袋陷入被掏空的危機

我有一位朋友，擁有典型的窮觀念，認為錢一定要留在身邊才安心，積沙成塔就是他的信仰，投資對他來說就像是黑洞，稍微靠近就會招來自我滅亡的危機。

他始終相信唯有銀行帳戶才是最安全的地方，因此他把每個月的薪水都存入戶頭，等到要用錢的時候再領出來，因此戶頭的錢就像糧食一樣日漸減少，等到發薪日才又恢復原來的水平。

看似每個月都在存錢，實際上錢根本就沒有增加，只是挖一角補一角，雖然不至於坐吃山空，只是每個月賺得就是這麼多，必要支出也就是那些，根本不可能有多餘的錢可以存起來。

如果收入與支出差不多，表示你的錢只是左手進右手出，帳戶只是中途的轉運站，而不是最後終點。但是窮觀念卻蒙蔽了你的雙眼，讓你在「有存就有錢」的認知迷宮裡永遠找不到出口，只能盲目地繼續走下去。

直到現在，我這位朋友還是持續這種每個月都會存到錢的「假性理財」，獨自對著維持不變的存摺數字沾沾自喜，完全沒發現自己的「聚寶盆」早就破了一個大洞。

我最近認識的另一位窮朋友，也是把死儲蓄奉為圭臬的窮觀念實踐者，不僅如此，他還完全不管支出，只要皮夾沒錢的時候就去領錢，沒有設定每月的上限，有時候領出來的金額比每個月存進去的還多。

我問他難道不會擔心財務出狀況嗎？他只是淡淡地回答：反正每個月都會領薪水，存進去時就會有錢了。

因為通貨膨脹與政府萬萬「稅」，會讓錢愈存愈沒有價值，雖然帳面上一樣是五百元，實際上卻只能買到一百元的東西，加上稅收東扣西扣，最後荷包就會開始營養不良，難逃又瘦又乾的命運。

遇到這種情形，窮人從來不會審視自己的行為究竟哪裡出了問題，只會怪大環境的景氣差，或是抱怨政府壓榨人民的血汗錢；要不然就是怨嘆自己命運乖舛，天生就沒有富爸爸，反正怪天怪地就是不會怪自己。

同樣是累積財富，富人的想法卻跟窮人截然不同。

子彈不一定百發百中，但只要擊中目標，就能到達夢寐以求的「金銀島」

所有的窮人心中都有一道待解的謎題：富人的錢究竟是怎麼賺到的？窮人把錢當作糧食，可以填飽肚子免于飢餓，富人卻是把錢當作賺取更多錢的「武器」，像是投資企業或是自己創業當老闆，建構一套完整的商業模式，讓錢能夠持續不斷地流進自己的帳戶裡。

我曾聽說有位企業家本業做得有聲有色，每年營業額也是上看幾十億，但是也會要求市場部注意各個產業的動態，最重要的是找出當中最具潛力的「新秀」，進而轉投資或是把整間公司買下來。

剛開始底下的人都非常不能理解，老闆為何不專注在已經賺錢的產業上就好，多的錢就當作營運準備金或是私人存款，竟然要花大錢在其他地方，而且又不能保證未來一定會賺錢。

那位企業家聽了只是笑著說，我也知道把錢放在安全的地方最好，只是誰能保證不會有突如其來的經濟大風暴？況且子彈放著不用就只是等著生鏽，倒不如讓它發揮最大的效益，積極地擊中其他可能賺錢的目標；公司賺愈多，大家的口袋就愈飽，企業也有更好的生存條件。

窮人與富人的差別就在於腦袋裡裝的觀念不同，窮人只會傻傻地守成，認為今天存一塊，明天也存一塊，只要每天都存一塊，一年過後就會有三六五元，但富人卻知道守成就是「等死」，於是他選擇將錢投入市場，以獲得大於三六五元的收益。

根深蒂固的窮觀念，讓窮人只能眼巴巴望著對面的高級餐廳，嘴巴裡卻啃著白饅頭，而富觀念卻能讓窮人不只中餐能吃高級餐廳，連下午茶、晚餐甚至宵夜都能饕餐享用山珍海味。

有句話說「腦袋決定你的口袋」，窮人就是因為腦袋裡只有窮觀念，才會造就窮口袋，你今天所擁有的一切，都是長久以來的僵化思惟所導致，跟上輩子沒燒好香或是做太多壞事一點關係都沒有。

過去的窮已經是不可改變的事實，但沒有人規定你必須窮一輩子都不能翻身，你現在能做的是藉由摒除以往的習性，脫離現在與未來的窮困。

把腦袋中的窮觀念換成富觀念不必花任何一毛錢，這種交易怎麼算都物超所值，要是這種無本生意你還不做，就算是再厲害的理財專家或是幫人改運的風水師都救不了你窮酸的人生。

# 愛錢賺錢和用錢滾錢，是很道德的

對多數人而言，「愛錢」是貶抑詞，「銅臭味」則是勢利者的標籤。

人們會用「渾身散發銅臭」來諷刺那些唯利是圖、庸俗的有錢人，暗指他們的行徑「像銅錢一樣臭不可聞」。

但是現在你可能要改觀了，美國微軟公司的一位副總裁麥卡錫，自費研發了一款「銅臭香水」，將這款香水命名為「錢（Money）」，並號稱擦了之後讓你聞起來就像有錢人，而且更有自信。

既然錢能讓我們變得有自信，為什麼我們要厭惡它？甚至似乎那麼做就是罪惡的，會受到千夫所指。

事實上，人打從出生起就無法離開錢，一舉一動都和錢息息相關，是我們物質面上不可或缺伴侶。

# 大方投機，勝過矯情抗拒

過去錢滾錢被視為卑劣的「金錢遊戲」，其行為和賭徒差不多；事實上，我們得承認「用錢滾錢」的做法確實帶有投機的成分。

對《一個投機者的告白》作者安德列・科斯托蘭尼（Andre Kostolany）而言，貨幣經濟就像空氣一樣重要，「我是投機人士，始終如一！」科斯托蘭尼毫不諱言地承認，並以身為優雅的投機客而自豪。

佛洛伊德（Sigmund Freud）曾站在心理學的角度說：「知識分子看待金錢問題的方式，會跟他們對待性的議題一樣表裡不一、过度拘謹和虛偽。」

舉個例子，假設桌上有兩塊蛋糕，一大一小，你會選大的還是小的？相信不用經過思考，你也會選擇大的；要是回答選小的，那就有點矯情了。因為選擇大的是符合人類真實的天性，誰都希望自己過得更好不是？

是人都會有過好日子的欲望，更甚者會想讓身邊的人也過上好日子——這 點並沒有錯。

這種欲望同時帶有破壞性和建設性，很難直觀地評斷是好是壞；但物欲會讓人變得積極、激發創造力，推動文明的進步，這點無庸置疑。

我們該做的，是正視物欲帶來的破壞性和建設性。倘若人類沒有物質欲望，就不會出現以物易物的交易形式，進而發展出完整的經濟體系，很可能到了今天還在過茹毛飲血的原始生活。

錢的本質是單純的「交易媒介」，是我們擅自賦予它的意義，擴大了對金錢的闡釋，使得它像放大鏡一樣擴大和暴露了人性。

說愛錢不道德的「衛道人士」，他們的動機多半出於嫉妒，而不是其中的「道德」。

我以前有個同學，他家境優渥，向來出手闊綽，身邊總是不乏酒肉朋友。

對於他處處撒錢「搏感情」的行爲，這些所謂的「朋友」常在背後議論他，認為他能力一般、言語無味，人緣好只是因為淨會拿錢「收買」人心，還私下給他起了個「闊少」的綽號。

說是這麼說，但這些人禮物照拿、東西照用，吃喝玩樂都不會忘記帶上他，因為這樣一來就不愁沒人付賬了。

然而，他們的行爲符合道德標準嗎？任誰都看得出來，虛偽和忌妒的成分太多了。

會有這樣想法的人應該拜讀猶太人的致富經典《塔木德》，當中有句話說得很對：「並不一定貧窮的人什麼都對，而富有的人什麼都不對。」

對許多人而言，「金錢」是一個符號、一個圖騰，象徵著地位和權利。他們追逐金錢，認爲錢可以帶來朋友、建立威信和自尊，具有無上的力量；但是當他們漸漸變得爲金錢所挾持時，就開始將自身的脫序行爲怪罪給金錢了，完全忽略自己就是罪魁禍首這件事。

前陣子友人在父親資助下買了新房，邀請大家前往參觀。在這房價高居不下的時間點，能買房是了不得的事，哪怕是位在靠近郊區的房子。

然而大家你一言我一語，說的都是該友人「含金湯匙出生」、「靠爸族」之類的言論；也有人说房子地段不好、價錢買貴了，語氣中充斥滿滿的酸葡萄味道。

這不禁讓我想起，小時候同學裡如果有人穿了新鞋，大家要輪流踩新鞋子三下的習價。當時不解這麼做的意義，現在檢視起來，這多半是為了防止「酸葡萄心理」作祟而打的預防針。

事實上這位朋友除了買了棟遮風避雨的房子，讓自己和家人過得更好之外，什麼壞事也沒做，卻平白遭到非議。

這種既對金錢充滿渴望，卻又予以譴責的做法，彷彿金錢有讓人中毒的魔力一般，引誘我們變得自私和犯錯。但其實說穿了，一切是我們自己主導的，金錢只是中立的道具罷了。

# 錢帶來的祝福，與道德無關

「錢不是罪惡，也不是詛咒，它是給予人們的一種祝福。——《塔木德》。

世界上最會賺錢的猶太人認為，「賺錢」是種高貴的美德，能為自己和家人帶來幸福。不僅如此，對賺錢的渴望會激發個人的創造性和冒險精神，帶來正面的能量；宏觀來看，金錢帶來的是安定、富足的正向力量。

貨幣經濟是市場經濟的一個重要元素，最終會成為一種秩序，包含了高級生命的自由。「前德國央行總裁卡爾．奧托．弗爾（Karl Otto Pohl），在一篇文章中寫道。

而素有「股神」之稱的巴菲特相信：「錢可以讓我校務獨立，然後我就可以做任何我想做的事。」

巴菲特給人慈善家的形象，然而他毫不掩飾自己對金錢的熱愛，他甚至請太太用鈔票圖案的壁紙裝飾自己的辦公室。

你不會想用道德去檢視巴菲特的行為，就像你我都買過樂透彩，但是罪惡感並不會找上我們，為什麼？就因為我們買的是「公益」彩券？

那是何錢滾錢、用財務工具賺錢，就是不勞而獲、不道德的行為？

窮人總被錯誤的信仰限制住，給賺錢的行為扣上道德的高帽子，指責商人淨賺「不義之財」。

但是回歸商業的本質，法律允許商人在合理範圍內賺取最大的利益；企業追求利潤理所當然，畢竟沒有「利」，何來「義」？不賺錢的商人才不道德，除非他做的是慈善事業。

阿里巴巴集團董事主席馬雲曾經說過：「企業不賺錢是不道德的，賺錢沒有錯，不應該有羞恥感，做企業不賺錢才應該有羞恥感。」

不賺錢，企業對不起員工和股東；沒有收入，一家之主養不起妻子和孩子。所以，企業怎麼能不賺錢？

# 你要有意賺銭的渴求，才知要去哪裡找錢

美國作家華盛頓·歐文曾說：「偉大的人設定目標，平凡的人就只有願望。」

你對財富的欲堙有多大？每個人都做過發財夢，幻想電視新聞上中樂透的那個人是自己，但是隨著一期的樂透開獎，這些人沒有一夕致富，反而還被現實扼殺了他們的美夢。

其實，窮人之所以窮，就是因為他們對財富的渴求並不大。如果你愛錢愛到了一個瘋狂的地步，你不會盼望它從天而降，而是會在這股深切渴望之下，整天在錢的後面緊緊追著錢跑。

# 知足的人，永遠別想賺大錢

有人說不知足的人，永遠覺得自己貧窮，但也正是因為這份不知足，讓他們對賺錢有所渴求；而其實知足，才是促使自己永遠貧窮的關鍵原因。

務實是窮人的本性，粗茶淡飯沒關係，肚子填得飽就好；房子小沒關係，能遮風避雨就好。但是你要知道，你過的生活，多半來自於你想要過怎樣的生活。不把自已對財富的欲望養大的知足心態，只會讓你跟財富絕緣。

富人对錢的渴求是與生俱來的，但是骨子裡窮的人，不被逼到絕境，很難會有破釜沉舟的決心。

我有個朋友，原本是個單純的家庭主婦，老公在台南開麵店，雖然不算富有，但也算是衣食無虞。但是好景不常，他老公迷上賭博，後來又投資股票失利，前後一共欠下將近千萬的債務，巨額債務壓得一家人喘不過氣來，讓她跟她老公的婚姻亮起紅燈。最後，她決定一肩扛起沉重債務，還有三個小孩的監護權。

此時的她面對三個小孩的教養問題，還有龐大債務，她知道，普通上班族的薪水根本負荷不了，在這樣岌是懸崖，後是陡壁的壓力之下，她心生創業的念頭，而在沒有資金，銀行又不肯借她錢的狀態之下，她硬著頭皮向地下錢莊借錢。

她知道，向地下錢莊借錢是一條不歸路，她非得成功，否則就只有死路一條。回想這段處境，她表示，在她一生之中，從未有這麼渴望賺錢的想法過。

雖然她在創業期初期歷經重重關卡，決定要開麵店的她，每天都在研發食材，幾乎沒有時間睡覺，除此之外，還要面對前夫家眼地下錢莊的刁難。

而看著三個孩子，堅定了她賺錢的意念，成了支撐她的支柱，也成了最後她得以致富的關鍵。

最後，靠著這樣的信念，她一步朝自己的目標邁進，不但還清了前夫的債務，還在競爭激烈的台南府城，闖出自己的一片天，創造出年營收入三千多萬的驚人成績。

沒有人能想像，原本一個弱不禁風的家庭主婦，可以從負債百萬到年收入千萬，但是這樣實際的案例其實就發生在你我周遭，他們不是含著金湯匙出生，而是原本過著和我們一樣，可能生活無虞，卻一輩子要過著被房貸、車貸追著跑的辛苦生活。

安於現況，是窮人跨不出致富第一步的原因；學會不知足，學會對錢產生渴望，才有可能逃脫貧窮枷鎖。

# 致富機會，不是從天而降的禮物

富人之所以會成功，在於富人不但敢擁有夢想，而且攤開他們對未來的藍圖，看到的是有條理的時間計畫表；而窮人之所以一輩子無法翻身，是因為別說要有計畫表了，他們甚至連夢想都不敢擁有。

# SMART 原則

![](img/78ad5f64390102052ae3fb2c0940e6bc_50_0.png)

「SMART原則」是由管理學大師——彼得·杜拉克在一九五四 年提出的理論，是「目標管理」的一種方法，在企業界被廣泛運 用。

- 實行目標管理，可以用來提高員工的工作效率，也能制定科 學化且有規範性的目標，作為未來公開考核的依據。
- 之所以會提出這項原則，是因為彼得·杜拉克認為，管理者 不可以只顧著埋首苦幹，而忘記企業的終極目標；而在執行時也 不能只有高階人員參與，而是要制訂一個具有規畫性，而且能讓 所有人員都可以投身其中，作為共同目標的系統。

- SMART，分別代表 Specific Measurable Attainable Relevant Time-based.
- 第一，具體的目標。因為如果目標模糊兩可，會使員工不知該往哪個方向前進。
- 第二，可衡量的目標。無法明確衡量的目標，會造成認知上的分歧。例如，想要降低客訴率，可以訂定「將客訴率從3%降到1%」的明確目標。
- 第三，可達成的目標。好高騖遠的目標，會使執行者沒有動力執行。
- 第四，和其他目標有關聯性的目標。如果你達成這項目標，也對其他目標有利，執行的動力相對也會增強。
- 第五，有明確截止期限的目標。沒有期限的目標，很容易讓執行者在日後一日日失去動力。

# 負債不可憐，可憐的是你不懂負債的威力

《富爸爸，窮爸爸》的作者羅伯特·清崎曾經說過一句話：「富人買入資產；窮人只有支出，中產階級買入他們以為是資產的負債。」

更確地說，在富人眼中，即使借錢創業，都算是一種投資。在他們的字典裡，沒有負債這兩個字。

窮人之所以會一直逃脫不了貧窮的日子，就是因為他們不願意轉念一想，將負債轉為機會、將當下的逆境當作未來致富的跳板，他們安於領著 22K 度日，不願意破壞眼前的安逸、不願意放手一搏。
