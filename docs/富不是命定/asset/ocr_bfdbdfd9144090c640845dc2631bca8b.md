# 每天沉浸在貧窮的氛圍裡，你只會逐漸習慣貧窮

片中克里斯·賈納的老婆，和他也形成了強烈的對比，顯現出一個人之所以會成功，限為什麼會持續流浪連貧窮，無法脫身的關鍵原因。

遇見法拉利後的克里斯·賈納，想起他從小就精於數字，於是動了想到證券公司上班的念頭，但是他也知道，他老婆絕對第一個舉手反對。

果不其然，當他表明自己想要去證券行看看有沒有機會當股票經紀人的時候，他老婆以輕蔑的語氣說：「只是想當股票經紀人而已嗎？我還以為你更想當機長呢！」

在這句調侃話的背後，她想表達的是一個務實的想法：「沒錢，就是好好勤奮工作就對了，不要做一些好高騖遠的夢想，先把手一餐的飯錢籌出來再說。」
