# 儲蓄不是美德，是窮人根深蒂固的習性作祟

老一輩的人常說：「儲蓄是種美德。」這句話僅僅在提醒你不要把手上的錢拿去吃喝嫖賭亂花掉而已，卻不是讓你從無到有致富的明燈，所謂的「美德」，不過是窮人應守的美德，卻不是富人之所以變有錢的習性。

如果你一天只花一百元的話，你的定存本金要準備二四六萬，你的財富才有可能每年慢慢增加，但現在有哪個在外地打拚的上班族平均一天只花一百元的？隨著消費者物價指數不斷增加，手中的一百元也變得愈來愈薄，當你連泡麵都快吃不起的時候，有錢人的世界對你而言，就像是希臘神話一樣遙不可及。
