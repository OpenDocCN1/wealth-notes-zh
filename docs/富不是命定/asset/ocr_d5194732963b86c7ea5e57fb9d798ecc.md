# 八字不好，讓你贏在起點

被問到讓他脫離貧窮的最大原因，高雄今喜旅行社董事長江其興是這樣回答的：『是貧窮帶來的無限鬥志，以及那個容易激發人們向上的貧苦年代。』

如果你現在正處於貧窮，恭喜你，因為你正處在一個脫貧致富的最佳環境。
