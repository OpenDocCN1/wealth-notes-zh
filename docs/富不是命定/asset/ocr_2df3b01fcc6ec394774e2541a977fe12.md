# 6 街頭舉牌員的機會成本

我曾經在十字路口等紅綠燈的時候，看到一位房地產的舉牌員，會特別讓我注意到的原因，是因爲他穿得西裝筆挺，而且年紀很輕，目測大概才接近三十歲，一般從事這類工作的人，多半是中年以上，甚至是接近銀髮族的族羣，於是我決定上前跟他交談。

這一問，讓我大吃一驚，原來他是剛從國內知名大學畢業的博士生，念完博士原本想要擠進大學教職的宅門，但因爲職缺早已飽和，轉向業界投了幾十封履歷也同樣石沉大海，最後因爲學貸壓力與生活開銷，於是就來當舉牌員。

這讓我想到之前的「博士雞排事件」，其實不管是誰賣雞排，反正不偷不搶，普通人根本不在乎，只是因為郭董一句：「浪費國家資源」，整件事情才鬧得沸沸揚揚。
