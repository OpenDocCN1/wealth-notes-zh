# 機會成本

機會成本（Opportunity Cost）是做決策時，沒有被選上並且價值最高的選項。

機會成本又包含兩個部分：一个是顯性成本、另一個是隱性成本。顯性成本也稱為會計成本，代表自身要付出的貨幣代價，而隱性成本是捨棄選項中能得到最大回報的代價。

舉例：李教授想參加歐洲七天六夜的旅行團，但出國的一星期就無法授課，也沒辦法舉辦講座，假設出國旅行的費用為二十萬元，授課收入為五萬元，舉辦講座收入是兩萬元。如果李教授決定出國，那他的機會成本就是二十萬＋五萬＋二＋十五萬元。若他留下來授課、金錢上就沒有損失，只是得不到出國旅行的滿足感而已。
