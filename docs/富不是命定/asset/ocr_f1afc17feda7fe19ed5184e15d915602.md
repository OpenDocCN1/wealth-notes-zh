# 窮人的心跳會隨著戶頭數字變化，
富人的心跳不管何時都始終平穩

窮人與富人最明顯的差別，並非是金錢的多寡，關鍵在於腦袋裡有沒有富貴觀念。

如果窮人擁有五塊錢，他想破腦袋只是为了如何让这些钱可以用得更久，
相反地，富人則是會思考如何让这些钱「倍增」。

+   「即使你們把我身上的衣服剝得精光，一個子兒也不剩，然後把我扔在撒哈拉沙漠的中心地帶，但只要有两个条件，給我一點时间，並且讓一支商隊從我身邊路過，那要不了多久，我會成為一個新的億萬富翁。一 美國石油大王洛克菲勒這樣說道。

窮人得到很多錢，就會克制不住內心的喜悦和欲望，忍不住心跳加快，如果戶頭只剩下五塊錢，心中就會極度不安，只想著如何勒緊褲帶度日，不同的
