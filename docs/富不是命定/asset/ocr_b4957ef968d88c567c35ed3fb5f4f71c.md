# 電影「當幸福來敲門」裡的法拉利

電影《當幸福來敲門》，是由真實故事改編，內容描述美國買納理財公司執行長——克里斯．賈納白手起家的故事。

想要白手起家，需要怎樣的條件？片中的克里斯．賈納，憑藉的是堅定的目標、鍥而不捨的拚勁、務實的執行力，還有一輛法拉利。

影片的一開始，他只是一個因為交不出的房租、稅金、小孩學費的父親，他每天為了賺錢絞盡腦汁，卻始終無能為力，而一切轉折都從他在路上看到的一輛法拉利開始。

在一天為了賺錢而奔波的早晨，他看見眼前迎面而來一輛紅色法拉利，他走向前，向法拉利的主人說：「先生，很抱歉，但我只想問你兩個問題，就是你是做什麼的？還有，你是怎麼做的？」
