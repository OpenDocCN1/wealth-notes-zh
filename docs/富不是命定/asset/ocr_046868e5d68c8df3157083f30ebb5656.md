# 9
富人犯錯的投報率

戴爾電腦創辦人麥克·戴爾曾經提到：「別花太多時間試圖去挑選完美的機會，致使你錯失對的機會。認清以後將會有失敗，並承認以後將會有阻礙，但你將會從你的錯誤及別人的錯誤中學習，因為成功裡能學的很少。」

但是窮人遠遠看見失敗就嚇得像驚弓之鳥，只想用最快速度逃離現場，因為無法承受失敗帶來的挫折感，致使他們沒辦法面對自己犯錯的事實，只能藉由逃避讓自己心裡覺得好過一些，久而久之，他們心中就築起一道「多做多錯，少做少錯」的貧窮之牆。

相反地，富人會將失敗當作檢視自己一舉一動明鏡，他們認為犯錯並不可恥，只是一種讓潛在問題更快浮出檯面的方式，若能藉此累積經驗值，便是「順利誠可貴，犯錯價更高」的最好證明。

要在別人貪婪的時候恐懼，而在別人恐懼的時候貪婪。
