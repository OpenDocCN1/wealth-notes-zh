# 愚勤的做事方法，是導致命運坎坷的最大推手

我曾經聽過一個案例，有位剛踏入職場的新鮮人，經過無數次投履歷與面試的過程後，終於進到一家新成立的活動企畫公司上班。

他的工作態度非常好，只要有活動，無論是不是自己的專案，也都會主動留下來幫忙，平常上班也是最晚走的一個，他始終相信上司會看見他的辛苦，進而照顧到自己的「薪」情，於是上司提出的每一項要求，他都努力地使命必達。

就這樣做牛做馬過了一年，他覺得自己的辛苦應該要有實實的回報，就主動跟上司商量加薪，沒想到對方卻說：「要加薪就要有實實的績效，像是業務量增加，或是成本有效降低，雖然你很努力，但是做了比別人更多事情，並不表示你的個人價值就會增加。」

任勞任怨並不會獲得賞識，只會讓自己成為逆來順受的可憐阿信。
