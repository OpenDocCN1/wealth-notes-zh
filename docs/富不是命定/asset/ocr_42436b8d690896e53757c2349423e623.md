# 紙資產和硬資產

一般我們熟知的投資項目如股票、債券、基金等，都屬於「紙資產（Paper Asset）」。這是基於金融體系的穩固下，將資產化為契約的虛擬交易。

「硬資產（Hard Asset）」則泛指具有實體的財貨，諸如黃金、珠寶、郵票、古董、藝品、名錶、甚至紅酒和鮑魚等貴重物品，都是能夠作為投資目標的硬資產。

紙資產與硬資產之間，有一種跟隨景氣循環相互消長的趨勢。景氣大好時，大家對於市場與貨幣的信賴感較高，紙資產的交易相對受歡迎；當景氣低迷時，紙資產無法保障其自身價值，硬資產就會抬頭。
