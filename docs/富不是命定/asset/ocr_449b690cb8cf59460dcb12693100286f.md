# 執著現在的擁有，讓你未來一無所有

成為富人的漫漫長路，必須從現在就開始，如果你始終不敢跨出第一步，和致富目標的距離就永遠不會縮短。

窮人可以想出一百個原因，作為不願將夢想付諸行動的理由。當他們有本錢時，他們畏懼於用這筆小財富投資，因為他們害怕萬一失敗了，大半輩子的心血就會付之一炬；更別說當他們沒有本錢時，就更不願以借貸來放手一搏了，因為窮人始終認為「借貸」是一條無法回頭的不歸路。

但其實借貸的好與壞是一種結果論，其中的區別，則是要看你如何使用這筆借來的錢，如果你獲取的利益高於成本，現在的借貸，將是成就你未來成功的關鍵。

每個人都有成為富人的本領，只是窮人不斷地遙想著在未來的某一天，他可能會因為某些契機而致富，可是其實這些機會每天都在發生，只是被你窮人如果用同樣的想法、同樣的做法，卻妄想得到完全不一樣的結果，那是不可能的。
