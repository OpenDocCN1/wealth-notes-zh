# 成本與效益，是成為富人的必備觀念

富人不會花時間去蒐集折價券或是排隊買便宜，因為他們了解時間成本的重要性，既然每天二十四小時是無法變動的 成本，在成本不能調整的情況下，想要有高收益，就要選擇能產生高收益的方法。

而排隊搶便宜對富人來說除了「浪費時間」之外，不就是「毫無意義」。他們在喝一杯水的時間就能幫自己賺進大把鈔票，怎麼會把時間花在排兩個小時的隊，只是為了前一百名的消費者可以享受半價的芒果冰。

就像大家都熟知的有關比爾·蓋茲的故事，他有一天在路上看見一百元美金，卻沒有彎下腰來撿，因為在彎腰的一秒鐘，他的口袋就會流進幾十萬美金。

同樣是一分鐘，窮人如果能賺到錢就心滿意足，富人則是絞盡腦汁，能賺一萬元就絕對不賺一百元。
