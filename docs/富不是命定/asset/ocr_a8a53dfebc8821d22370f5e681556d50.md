# 8 博士賣雞排的沉沒成本

前陣子「政大博士生賣雞排」的新聞，引起廣大爭議。一開始「雞排博士」宋耿郎頂著博士光環，成功打響知名度，新聞媒體也爭相報導，「行行出狀元」、「雞排博士勇敢走出自己的人生」……將這件事塑造成一種追求生命價值的勵志故事。

到後來又因為被鄂台銘批評而一夕爆紅，連帶使他的雞排生意一併翻紅，業績跟著水漲船高，但是這樣貌似成功的創業故事、看來很有商業頭腦的背後，卻是一個富人們怎麼樣都不可能去做的虧本生意。

辛辛苦苦、耗費龐大資源地念到博士班，這些年來的勞心費神先不說，光是他所繳的學費就是筆相當龐大開銷，難道最後這些付出的代價，就只是想換來一個「博士生幫你炸雞排」的噱頭嗎？

找錢人勝過你找錢，要懂得錢為你工作，而不是你為錢工作。
