# 窮人才會相信「富貴險中求」

常聽人家說：富貴險中求。其實這是有心機的商人為了誤導笨蛋和掏出窮人口袋的錢，所發明的口號或咒語罷了。

當然了，這句似是而非的謊言，也只有窮人和笨蛋才會相信。

事實上，富人當然也追求富貴，但他們是很清醒地看清一個事實：富貴無法強求，富貴是在你掌握風險之後，自己送上門來的羽毛。

因此，富人絕不相信那些專騙窮人和笨蛋的理財廣告詞和名師祕笈，他們只相信自己的理性判斷力和專業能力。

然而，不幸的是，我在很多窮人身上，看見這句咒語早已根深蒂固地植入了他們那個，仍在使用舊版本作業系統腦袋裡。
