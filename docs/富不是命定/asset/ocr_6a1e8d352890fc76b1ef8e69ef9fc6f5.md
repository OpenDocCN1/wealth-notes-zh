# 舒適圈

![](bbox=[0.75, 0.15, 0.9, 0.2])

心理學上的一種精神狀態，指人對所處環境和習慣產生依賴，並且久處在這種安適的狀態，因而喪失危機意識。舒適圈（Comfort Zone）會帶來非理性的安全感，並產生惰性，造成他將傾向於待在目前的舒適圈內，不想再離開。

舉凡因轉學而適應不良的孩童、不願改變工作模式的老職員，或者出國還堅持要吃台菜的遊客，都可能是因为脫離舒適圈而產生排斥，急於尋求安全感的案例。

而像尼特族（NEET，指非受教、非受僱者）就是舒適圈極小的例子，有甚者會把生活範圍框架在一個房間之內，形成以自我為中心的舒適圈。

如果一個人走出自己的舒適圈，就表示他必須在新的環境中發展出不同以往的行動方式，也面臨新的挑戰。
