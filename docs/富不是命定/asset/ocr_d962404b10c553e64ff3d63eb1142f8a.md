# 狹隘的眼界，讓你無法決定自己的方向

有一句話說：「窮人追漲跌，富人看趨勢」，說的就是窮人的盲目跟從。

電影《奪命金》中，在銀行投資部裡充斥著各行各業的顧客，他們來到這裡的目的，就是設法為自己的未來買一個保障：或是以錢滾錢，賺取更多獲利。

在片中對一切投資感到茫然的娟姊，只會盲目地聽從投資顧問的意見，而當時她的投資顧問因為業績欠佳，便慫恿一直以來都只願做定存的她買下高風險基金，最後碰上股災，導致娟姊賠上存了一輩子的積蓄。

我們會發現，在這樣的場合裡，市井小民受專業的投資顧問擺布，人云亦云地砸下積蓄，導致最後血本無歸。
