# 讓富人能乘風破浪的五千萬，卻會讓窮人陷入翻船危機

我聽過有位白領上班族，一直夢想著自己能夠中樂透，瞬間發一筆橫財，因此他每期至少會買十張碰碰運氣，這個習價持續了好幾年，有次對獎的時候他驚覺自己竟然就是那位頭獎的幸運得主，於是他當天立刻向老闆提出辭呈，跟家人一起想像成為有錢人的樣子。

只是好景不常，因為他從來沒有得到這麼多錢，根本無法抵抗迎面而來的盧槳感，開始大手筆的買房買車，連吃的、穿的、用的都非要最頂級不可，在毫無節制的花費下，獎金竟然不到兩年就被揮霍殆盡，更慘的是，他已經過慣奢侈的日子，最後還欠下一屁股卡債。

習慣坐五塊錢小船的窮人，躲不過五千萬海浪的波濤洶湧，最終只有翻船滅頂的下場。
