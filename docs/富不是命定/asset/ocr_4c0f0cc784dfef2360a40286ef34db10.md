# 5 現在，是上帝給我們最好的恩典

世界銀行副行長林毅夫曾經說過一句話：「窮人把錢存入銀行，實際是在補貼富人。」而這樣的現象，正是導致富人愈來愈富；窮人愈來愈窮的關鍵原因。

很多人的理財觀念，都是源自於從小父母教我們要懂得儲蓄。儲蓄，乍聽之下是美德，但是父母沒教我們的是，很多富人其實是樂於貸款買房或是做投資的，他們寧願負債一時，把握現階段的時機，而不是守著大筆財富，或是望著空空的存款，然後在未來不斷地悔恨當初沒有勇敢做出決策，然後不斷地活在懊悔裡；或是只會把眼光放在對未來的盲目期盼上。而始終搞不清楚，其實「現在」，才是決定你貧窮或富有的關鍵時間點。
