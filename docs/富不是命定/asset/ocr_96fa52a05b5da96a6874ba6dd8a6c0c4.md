# 限量是殘酷的——「硬資產」締造另類商機

在紙資產幾乎變成壁紙的同時，「硬資產（Hard Asset）」卻在投資人間興起一股烘炒熱潮。

這股「硬資產」熱潮從國外延燒到台灣，它的疆域面積遠比想像中更為寬廣，指的是有具體商品的「實體資產」，其精神是「萬物皆可投資」，除了傳統認定的黃金、鑽石和古董，蒐集品如郵票跟模型玩具，食物如紅酒、鮑魚等，一樣有人投資，潛藏的商機無限。

硬資產都是些看得到、摸得到、可以保存的東西，相較於「虛擬財富」的紙資產更有安全感，而且品項多元，不但能藉此增加財富，所選擇的投資項目還可以建立在興趣上，更有成就及認同感。
