
根據行政院主計處最新調查，以目前法定工時來說，每周平均為四十二小時，但有四五、八%的比例，相當於三八九萬勞工，處於工作超時的情形。

窮人總是陷入愚勤的迷思，殊不知工作時數與薪資根本是兩碼子事，就算你二四四小時都在工作，也無法成為夢想中穿金戴銀的有錢人。

不同的是，富人通常比窮人懶惰，他們懶得浪費時間、懶得長時間工作，因此他們更懂得如何將事情做得又快又好，和愚勤相比之下，智懶反而更能成一翻事業。

# 5 現在，是上帝給我們最好的恩典

# 執著現在的擁有，讓你未來一無所有

在你們羨慕這些成功創業者的同時，你們沒有想到的是成功的背後總有個起點，窮人只會幻想未來，但又因為過度的未雨綢繆，不敢把眼光放在當下，沒有開始，雖然不會讓你失敗，但也代表你永遠跟成功絕緣。

# 錢的未來價值，取決於「現在」

金錢的價值，會隨著時間變化而有所變動。我們第一直覺會想到的是，鈔票會因為通貨膨脹，導致其價值會隨著時間流逝。

# 6 街頭舉牌員的機會成本

# 選出最適合的機會成本，就能獲得變成富人的機會

機會成本（Opportunity Cost）也稱為「替代性成本」，是指在面對許多選項要做決策的時候，被放棄同時又擁有最高價值的方案。

只要是兩個以上的選項以及擁有選擇權，不管你選了什麼，不管吃虧或是佔便宜，都會產生機會成本，也就是「有得必有失」的概念。

以一開始舉牌員的例子來說，一天的工資為八百元，若是在業界工作，以博士學歷來說，平均一個月薪資約五萬元，日薪約為一六〇〇元，選擇舉牌員的機會成本是一六〇〇元，若是選擇進入業界，機會成本則是八百元。

有些人可能會說，這種簡單的數字比大小誰都會，要是能選擇的話，誰都不會選高機會成本的選項，但事實就是你最終還是屈服於現實，選擇了讓你愈來愈窮的方案。

窮人總是將選擇權交給命運，富人則是將它緊握在自己手中。

如果已故的蘋果創辦人賈伯斯，當初是跟著父親的腳步去銷售車輛，而不是賣電子商品，現在就不會有一蘋果帝國了，而且以現在的發展來說，每個人一定都覺得賈伯斯去賣車子的機會成本太高了。

機會成本愈低，表示損失愈少，選擇也愈明智，不過機會成本的高低有時候不一定能正確的衡量，像是假日要去爬山還是去海邊，不管選哪一個都無法將機會成本量化，只能由內心的滿足度來評估。

# 無論機會成本如何變動，最重要的是你選擇了什麼

我曾經聽過一則案例，有位從事行政工作的上班族，相對於同事在下班後去兼差賺第二份薪水，他則是選擇在下班後參加一些管理與創業的講座及課程。

很多有兼職的同事跟他說，現在每個月薪水三萬就還不錯，要是你下班再去兼另一份工作，說不定一個月就有四萬元，不只可以存到一些錢，又可以出去玩玩吃美食，何必花那些錢去上課，讓自己的生活過得這麼刻苦。

但他了解，每個月一萬的兼職薪水乍看之下還不錯，但誰知道以後的整個大環境會變成什麼樣子？如果去參加課程的機會成本是一萬元，那下班兼職的機會成本就可能是以後創業的十萬元收入。

每一次的選擇，都會造就不同的人生，窮人因為短視近利，只會貪圖眼前的安逸假象，通常是用「我立刻能得到什麼」這個方向去思考，而不像富人一樣將時間軸拉長，把重點放在「如果我選了這個，會對未來有怎樣的影響」，因此，同樣是在機會成本中做選擇，但結果完全是天壤地別。

投資人必須提防很多東西，尤其是自己。

每個人機會成本不一樣，富人是魚與熊掌不能兼得，但窮人無論再怎麼挑，不是剩菜就是剩飯。

另外，「不可逆」是機會成本的特性，經由每一次選擇造就的不同結果，都無法再回到尚未選擇的時候，因此，在企業內部做重要決策時，機會成本也是絕對會被列入考量的條件之一。

# 機會成本

機會成本（Opportunity Cost）是做決策時，沒有被選上並且價值最高的選項。

機會成本又包含兩個部分：一个是顯性成本、另一個是隱性成本。顯性成本也稱為會計成本，代表自身要付出的貨幣代價，而隱性成本是捨棄選項中能得到最大回報的代價。

舉例：李教授想參加歐洲七天六夜的旅行團，但出國的一星期就無法授課，也沒辦法舉辦講座，假設出國旅行的費用為二十萬元，授課收入為五萬元，舉辦講座收入是兩萬元。如果李教授決定出國，那他的機會成本就是二十萬＋五萬＋二＝二十七萬元。若他留下來授課、金錢上就沒有損失，只是得不到出國旅行的滿足感而已。

有一隻剛離群的年輕雄獅，在有機會獨自闖蕩前，就被人類抓進籠子、送到馬戲團裡。獅子從此不再狩獵，不必再為飲食的來源擔憂，改學習跳火圈之類的雜耍本事。

過了幾年，馬戲班解散了，獅子被放回了原本的草原。獅子正當壯年，卻完全不懂得如何在草原生活；他發現在馬戲團裡學的技能完全無法用於野外，而且那些和自己同時離群的雄獅，早已各自組成了獅群，當起草原之王了。

### 為何年輕人該太早進入大企業？

“到了一個程度，人要挑戰的不再是外面的世界，而是自己的舒適圈”
（Comfort Zone）。] ——褚士瑩《給自己10樣人生禮物》。

如果你還年輕，在經歷社會經驗前就進入穩定的大企業工作，那你就是上面的故事中的獅子。你似努力賺取每一分回報，然而你所擁有的一切，其實都是別人給予的；只要有一天這個「給予者」抽身離開，或是你被剝奪了「受僱者」的身分，你就等於失去了一切。

或許在馬戲團營收好、顧客多的時候，獅子曾有過風光的日子，而更大的誘惑是，獅子得到了那些草原上同伴沒有的條件：飲食無缺也不必餐風露宿，這樣的環境下，原本再尖銳的爪和牙都會漸漸變鈍，並且忘記狩獵的本能；只有跳火圈的技巧愈來愈洗練，但就算身懷這樣的技能，只要離開馬戲團，就變得一點用也沒有。

馬戲團就是獅子的「舒適圈」。對於身處大公司的你來說，或許認為現在的情況稱不上舒適，畢竟公司常逼著你加班或「跳火圈」；然而真相是，你已處在比出外謀生的人更高的穩定中，免卻生存本應面對的風險。

穩定的環境帶給我們「此生完滿」的錯覺，錯以為世界以公司為中心運轉，凡事以公司的利益為優先，期待有朝一日能被提拔到僅次於老闆的高位。

然而當你安於當一名受雇者，就等於接受自己只是顆小齒輪，完全得照定義好的軌跡運轉。你看不清機房的全貌，只能固守自己運行的方寸之地，撇開成就感不談，你已經失去了客觀競爭的能力。

對於長久待在舒適圈裡的人而言，面對不熟悉的事物或挑戰很容易感到不適，就算後來有心離開，這樣的不適感還是會再度驅使你回到舒適圈中，就像被圈禁久了的獅子不想再離開囚籠。

最近，一名友人脫離高壓的科技業，進入一家貿易公司擔任 IT（資訊科技人員）的工作。

起初，由於新工作較原本工程師的職務輕鬆，朝九晚五的日子讓朋友如魚得水；但這種日子過久了之後，朋友認為生活缺乏挑戰和前景，於是再度來求職網站搜尋職缺，可是不同於上一次的順利，這一次他驚呼：「怎麼每個工作都這麼困難！」

我建議他趕緊換個工作，這是典型在舒適圈裡待久了，競爭力下降的警訊。這樣的環境若繼續待下去，不僅無法發展個人的長才，更讓工作變得枯燥乏味；沒有風險，卻也再不會進步了。

# 甘於只做「手藝人」，就要有隨時被取代的準備

所以說富人學管理，窮人才學手藝。

技術再好，始終只是為人作嫁的「手藝人」，一旦出現更年輕、更厲害的技術者，就只能面臨被替換的命運。

不是說專業不重要，而是在追求技術的精進時，必須轉換想法，引用褚士瑩在《給自己10樣人生禮物》中的看法就是：「只要讓自己成爲一個有專業的人，『生存』就覺得很簡單了，錢不夠的話總是再賺就有，工作沒了的話總是再找就有。」

要能像離群的雄獅在遼闊草原上行走，具有帶著你的『手藝』遠行的勇氣，才能在瞬息萬變的環境中生存。

一般獅子群在離群後，會隻身在草原闖蕩，也許一開始四處漂泊流浪、過著有一餐沒一餐的日子，但是在這樣的過程中，打獵的技巧會日漸成熟，並結識同樣流浪的母獅、繁衍幼獅，開始以家族為單位的狩獵行動，久而久之，會形成一支強大的群體。

經過此番磨練的獅子，會成為名符其實的「王者」。這樣的獅子擁有實戰淬煉出的尖齒與利牙，甚至在統領群獅後，不至因為安逸而失去鬥志，懂得為可能發生的危機儲備體力。

年輕人需要向中小企業學習的，就是這樣的能力和見識。比起在大企業待到退休才能看盡職場百態，小型企業就像一台微縮廠房，能從較全觀的角度看待事情的運作，更容易發現問題的癥結。

對於不甘只當一顆小螺絲釘，積極想致富的人來說，小公司的高機會、高風險相當適合你。

中小企業容易受大環境的影響，而景氣就好比草原上的氣候，氣候不佳時，待在馬戲團的獅子能不受影響；而面對惡劣氣候的衝擊，草原上的獅子勢必面臨食物減少的生存壓力。但是當氣候再度好轉時，渡過飢餓危機的草原獅子，將有機會成為主宰獅群的新一代王者。

# 舒適圈

![](img/78ad5f64390102052ae3fb2c0940e6bc_149_0.png)

心理學上的一種精神狀態，指人對所處環境和習慣產生依賴，並且久處在這種安適的狀態，因而喪失危機意識。舒適圈（Comfort Zone）會帶來非理性的安全感，並產生惰性，造成他將傾向於待在目前的舒適圈內，不想再離開。

舉凡因轉學而適應不良的孩童、不願改變工作模式的老職員，或者出國還堅持要吃台菜的遊客，都可能是因为脫離舒適圈而產生排斥，急於尋求安全感的案例。

而像尼特族（NEET，指非受教、非受僱者）就是舒適圈極小的例子，有甚者會把生活範圍框架在一個房間之內，形成以自我為中心的舒適圈。

如果一個人走出自己的舒適圈，就表示他必須在新的環境中發展出不同以往的行動方式，也面臨新的挑戰。
