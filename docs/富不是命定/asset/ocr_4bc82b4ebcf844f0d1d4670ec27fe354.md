# 拒絕負債，讓你把致富機會擋在門外

很多人拒絕負債，認為負債等於負面的表現、是種不負責任的金錢態度，但是這樣的想法，讓你永遠都只能看著雜誌裡面別人創業成功的案例，然後自怨自艾地怨著自己沒有成為富人的福氣。

你們以為借錢投資，不但不切實際，也等於把自己逼進死巷。但其實看似再幸運的致富故事，裡面都帶有孤注一擲的成分。

廣為人知的「2派克雞排」，可謂現在台灣雞排界的龍頭，但是在風光背後，也是靠著老闆負債百萬的危機所換來的成果。

派克雞排的老闆李存祥，在二十歲之前，是個只會揮霍家產的闊少爺，他玩古董車，光算被他撞爛的古董車，就讓他負債百萬。

這樣荒誕不羈的人生，讓他父親在嚥下最後一口氣的前一刻，還在為他擔憂不已。父親帶給他的衝擊，讓他痛下決心要靠自己的力量闖出一番成績。
