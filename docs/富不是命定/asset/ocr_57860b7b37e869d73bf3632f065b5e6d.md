# 百萬。

我有個朋友，原本是月薪數十萬的保險員，但是在一次和公司的合約糾紛中，不但失去現有的工作，還欠下七百多萬的債務。

在窮苦潦倒之際，全靠他老婆做家庭代工，每個月領取一萬多元微薄的薪水度日，有時候還要靠著吃野菜、撿寶特瓶換取零錢過活。

後來為了小孩的教育部費，不得已向朋友借錢的過程中，他受盡羞辱，因而讓他下定決心自己創業，因為只有發了財，才不用再看人家臉色。

他拿著身上僅剩的七百元，買了滷味用的調味料，用來熬煮一些滷味，再開著家裡的破舊小貨車到市場叫賣，靠著這樣暴利的小生意，從第一天賺三百元、第二天賺五百元的進展，到日收入三、五千。

接著他開始研發特別食材，並且廣設分店，最後再的年營收入破千萬，這樣成功創業背後的本金，竟然只有七百元！

七百元的價值有多大？在這裡我們沒有辦法下定論，因為是使用者造就金錢
