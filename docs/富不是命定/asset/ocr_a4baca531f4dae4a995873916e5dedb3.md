# 把錢花在刀口上，不會讓你翻身致富

有個趨勢大師說過：「這個世界是平的。」

目前臺灣的經濟環境正處於停滯發展階段，很多產業把生產線外移至人力低廉的國家，以致愈來愈多的正職工作轉換成派遣、外包、約聘或是時薪制，就算是身處在科技業的電子新貴，也可能因為景氣的衝擊而被迫放無薪假，甚至是裁員。

前陣子媒體二十四小時輪番報導高科技業裁員的後果，就是大家不敢花錢，曾經有個夜市老闆娘跟我說：「新聞現在每天都在報景氣有多差，大家都不敢消費，我們生意也一年不如一年，現在的業績只能做到二十年前的『一半！』

因為收入減少不花錢，所以儲蓄率愈來愈高，也許你會問，大環境不好，未來的飯碗不知在哪裡，把錢存起來未雨綢繆有錯嗎？
