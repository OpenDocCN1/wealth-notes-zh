# # 我国取得疫情防控重大决定性胜利

### ——贯彻落实中共中央政治局常委会会议精神

**解读**

3月1日上午，中共中央政治局常委会会议分析了当前经济
形势，强调要更好统筹疫情防控和经济社会发展，因时因
势优化疫情防控措施，进一步做好医疗资源储备、医疗保
障等，确保平稳转段、平稳过渡，最大限度保护人民生命
安全和身体健康，促进经济平稳健康运行。

+   **解读要点：**

- 我国取得疫情防控重大决定性胜利

- 坚持中西医结合、中西药并用

- 坚持“乙类乙管”的防控措施

- 对新冠病毒感染实施“乙类乙管”

+   **主要任务**

- 实施“乙类乙管”的防控措施

- 保持新冠病毒定期检测

- 加强重点场所和重点人群检测

- 做好重点人群健康防护

- 强化医疗资源储备

- 加强药品、抗原试剂供应

- 强化医疗救治

- 加强重点机构管理

+   **工作要点**

- 平稳转段

- 医疗资源储备

- 医疗救治

- 药品供应

- 核酸检测

- 疫苗接种

- 基层防控

- 应急处置

# ## 国办印发《中医药振兴发展重大工程实施方案》

新华社北京3月1日电（记者 彭韵瑶）为
深入贯彻党中央、国务院关于促进中医药继承
创新的决策部署，促进中医药传承创新发展，
国办近日印发《中医药振兴发展重大工程实
施方案》（以下简称《实施方案》），部署开
展中医药服务、中医药健康促进、中医药人
才培养、中医药科研创新、中医药文化发展
等5个工程。

# ## 中共中央政治局召开民主生活会

**解读**

2月24日下午，中共中央政治局召开
会议，决定2023年3月召开中共二十大届
中央委员会二次全体会议。

+   **主要任务**

- 建设国家临床医学研究中心

- 建设国家医学中心

- 建设国家中医临床研究基地

- 建设国家中医医学中心

+   **工作目标**

- 2025年建成30家中医临床
服务能力显著提升的中医特色优
势明显的国家中医医学中心

- 2025年建成30家国家中医
临床研究基地

- 2030年建成国家中医药服务
能力和水平显著提升的现代化
中医药服务体系
