# 银发人群线上消费能力分布变化

在国内，**50 岁以上人群**已经可以视为占比高达 **1/3** 的主力人群之一，他们在互联网上的渗透率也在不断提升，线上正在成为他们生活场景中的重要组成部分。未来，银发人群的各种需求很大概率将会通过线上满足。然而，目前针对银发人群的线上内容、产品和服务供给还相对稀缺，未来潜力巨大。
