# 中国人口老龄化趋势带来的影响和机遇

# 一、影响

# 1. 一老一小消费市场广阔

根据联合国对中国 2020-2030 年间人口变化的预测，未来 10 年间 35-44 岁、55-64 岁、65 岁及以上几个年龄段人口数量增长最快（图16）。人口结构的变化也将带来消费结构的改变，婴幼儿消费、银发经济这一老一小市场空间广阔，同时，家庭规模缩小也带动了单身经济、宠物经济等消费的发展。
