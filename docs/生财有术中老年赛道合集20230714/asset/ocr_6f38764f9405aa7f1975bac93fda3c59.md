# ② 昵称

昵称一年只能修改 5 次，建议慎重修改，通常是根据自己要做的账号定位进行包装，常用的方法是采用关键词组合的方式，例如 xx 聊职场、xx 女装、xx 国学、xx 妈妈育儿好物等等

我是直接参考对标账号：xx故事会，昵称重复就换xx部分的文字，或者加后缀加数字
