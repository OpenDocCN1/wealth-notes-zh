# 科技史纲 60 讲

芝加哥大学的古埃及及学家马克·莱纳将主要的研究成果编成了一本很厚的书，叫做《金字塔大全》，里面详细 ground 解了建造金字塔的各种秘密。我在《文明之光》中概括了这本书中的很多内容，今天我将你再提炼和总结一下。

首先，我们要承认金字塔的大。位于吉萨的三个大金字塔中，最大的 termo夫金字塔，在 1311 年，高 147 米的英格兰林肯大教堂建成之前，它是世界上最高的建筑，这个纪录保持了 3800 多年，非常的不起，在它建成后再过 1000 年，中国的商朝才建立，同期古希腊的迈锡尼文明才刚开始。

对于这么大的建筑，科学家们首先要搞清楚建筑材料，也就是那些巨石到底是从哪里来的，这些巨石每块平均重 2.5 吨，最大的巨石重达 80 吨左右，而且有大约 230 万块之多。最关键的是，金字塔所在地本地本身没有这些石灰岩巨石。考古学家们发现它们来自于尼罗河对岸，但是接下来大家就又有一个问题，那就是这些巨石是如何开采、切割和运输的呢？

古埃及当时已进入了青铜时代，有青铜的锯子，但是青铜锯子硬度不够高，因此当地人把石英砂粉末在钢绳的表面，这就可以锯开石灰岩了。古埃及留下的一些壁画描绘了当时工人 们开采切割巨石的情况。

至于运输，由于古埃及当时还没有发明轮子，因此他们搬运这些石头确实费了些功夫，不过古埃及人远比我们想象的要聪明，他们制作了类似雪橇的运输工具来搬运石头。这件事情是有证据的，在第十二王朝的法老杰胡提霍特普的墓中，有一幅壁画，就描绘了 172 个人拉着一个雪橇似的木筏运巨石的场景。
