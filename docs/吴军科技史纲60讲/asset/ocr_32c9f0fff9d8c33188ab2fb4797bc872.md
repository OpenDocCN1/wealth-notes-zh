事实上，弗莱明的想法来自于德国着名的医生科赫，科赫被称为“细菌之父”，他认定感染的病源是细菌，要治疗感染引起的疾病，就要寻找能够从根本上将细菌杀死的药物。

因此，如果我们认定完成从 0 到 1 发现的人是弗莱明，科赫要是还活着的话，他可以去争辩说，弗莱明是受了我的理论的启发。

当然，有人会争辩，科赫没有发现青霉可以杀死细菌这件事，因此不算数。那我告诉你的 是，其实弗莱明也不是第一个发现青霉可以杀菌这个现象的人。早在中国唐朝的时候，裁缝 们就知道如果划破了手，把长了绿毛的糙米涂在伤口上，能够帮助伤口愈合。

这其实就是绿毛上青霉素起了杀菌的作用。只不过，唐Τ的裁缝们不懂科赫一大堆的理论，他们解释不了其中的原因，因此这种士方法也沒有得到推广。更关键的是，光靠绿毛上 那点青霉素其实也治不了大的伤病，因为按照我们上讲对药品的定义，那种能杀菌的天然物 根本算不上药。

因此，我在很多文章中都讲，寻找第一个发明人常常没有意义，因为根本找不清，永远能 够往前追溯。在人类的技术发展历史上，有无数次的从 0 到 1 的发明，但是绝大部分走不完到 N 的过程，因此都沒有产生什么效果，最后就被大家遗忘了。

不仅唐朝裁缝没有发明青霉素这种药，实际上弗莱明也没有。那第二个问题就是，为什么 弗莱明没有完成从 0 到 N 的全过程呢？利用我们前面介绍的“发明的预先要求”这个工具， 就很容易分析出其中的原因了。

首先，弗莱明的知识结构不完整，他是一个着名的医生，但是他不懂化学，也不懂制药学， 因此他无法搞清青霉素的有效成分，也无法从带有青霉菌的果汁中提取出药物。

此外，还有两个客观原因。

第一，当时药物纯净水平很差。弗莱明培养的青霉菌，每一升培养液只能产生两个单位的青 霉素，按照今天门诊肌肉注射青霉素一天 60 万~80 万单位的用量估算，这需要将一个 25 米 的短道游泳池的水都灌到人体中。此外，因为浓度太低，用青霉素做实验时时灵时不灵，这是 今天科学研究的 lease。
