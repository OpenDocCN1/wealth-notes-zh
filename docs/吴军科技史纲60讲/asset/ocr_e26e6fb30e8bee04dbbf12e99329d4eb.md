# 60 | 结束语：

# 信息从哪里来，它和能量怎样互换？

这是我们这门课的最后一讲，我先从回答几个读者具有代表性的问题开始，讲述一些关于信息和能量本源的问题。接下来则 อย่างไรก็ตาม 概括一下我们下一门课的内容。

我在第 51 讲后留了一道思考题：

如果 10000 年后，我们发现債務在距離地球 1000 光年的地方有另一個和地球一樣宜居的星球，人类移居到那个星球最便捷的方式是什么？

对于这个问题，同学们都各自开了脑洞，給出了精彩的回答。下面我给出我的思考，它可能和不少读者的想法或者部分想法有一致之处。

经过我们课程的学习，大家可能都明确了这五种概念：

+   1. 能量的量级，包括总量的量级。
2. 科技到了近代之后，能量和信息各自发展的速度，后者比前者要快很多。
3. 能量和信息的关系：它们在某些场合可以互换。
4. 相对论中的质能方程，即 E=mc²。
5. 生命的本质是基因的传承。

有了这些准备，我们就来思考上述问题。

首先，让地球漂移到太阳系之外的其它恒星系，从能量的角度讲是很难办到的，更不要说到 1000 光年之外了。因此可行的方法是降低旅行者的质量，按照旅行者自身质量的高低次序往下排序，可以是个人、人類胚胎、人類基因、人類基因信息 等等。

首先明确一点，人如果进行近光速旅行，几乎不会变老。但遗憾的是，人是不可能进行近光速飞行的，要想加速到那个速度，能量的消耗会近乎无穷大。

如果人按照 1/10 的光速运动，这或许可行，但是飞到 1000 光年之外的地方需要 1 万年。这就不会将人类胚胎送去更现实。

人首先活不了 1 万岁，因此即使你今天开始登上宇宙飞船出发，到那里的也是自己不知多少代的子孙。既然到 1000 光年以外地区都是自己的子孙，不如直接送胚胎过去，而 1 万年后，科技早就能发展到机器人可以培育和照顾人类的胚胎长大成人了。

比送胚胎更便捷的方式，就是直接将基因送过去。那时候的人类早就可以通过基因中的 DNA 自主复制出 RNA，再通过 RNA 制造出蛋白质，然后启动新陈代谢。
