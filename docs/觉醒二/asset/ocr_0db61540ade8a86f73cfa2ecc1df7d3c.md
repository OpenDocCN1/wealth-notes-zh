# 3.当股东

我们知道投资股票就相当于买入一个公司的股份，而一支普通的股票型基金包含了几十上百支股票，投资者仅/仅用了少量的资金就可以做多 个上市公司的股东，基金投资还有以下几个优势

（1）投资门槛低：

最近这几年最热门的公司大概就是贵州茅台了吧，前段时间正式成为A股市值最高的上市公司，大家如果想当茅台的股东，按照中国股市的规定，最少要买 100 股。

以今天的收盘价 1766 元来看，大家最少要准备接近 18 万的资金，不少投资者手中现金不足或者不想只买一支股票就会错过这个机会，但是如果 我们选择投资基金，只需要 100 元就能持有茅台的股票。

（2）多元化：

之前讨论的易方达消费行业为例，买入这支基金就相当于持有 了中国顶尖的消费类公司，一方面降低了风险，一方面让我们的投资更加多元化。
