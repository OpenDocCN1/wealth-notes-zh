# 二、大力出奇迹

多发多发多发!

我说的多发不是因为像中彩票一样，买的多中奖的机会就大。而是你只有多发内容，才能让平台的算法快速的认识你，了解你是干啥的。就好像人和人互相了解，都需要发生一些故事。

你内容都没有，平台怎么知道该给你什么样的流量？

没有内容，就没有标签，没有标签，平台就不认识你。

举一个把这点流量密码用到极致的账号，在抖音上叫牛丸丸安口。2年发了15万个视频，意味着每天300多条视频，就是忍着急牛丸丸拍，煮了去吃，非常简单的短视频。但人家把这个流量密码用到了极致，而且人家还是24小时日不落直播间，很多个主播轮流卖货。

钱不给他赚给谁赚？

人家也是经历了很长一段时间无人问津的时间，但人家挺过来了，做自媒体就最怕急于求成的人，想暴富的人。

所以我谈能把自媒体最好的人，身上是会有很多优秀品质的。

还有，我们本来就刚入场，百万级博主都发的比你多，你凭凭什么发能呢？所以真的要多发。

# 三、反差感

反差感为什么是流量密码，因为反差才有新鲜感，才有起伏。

我们大多数在某些领域的专业程度可能只有60分，毕竟不是每个人都是专家对吧？那我们要就降低用户的预期。

你不要本来讲的内容就只有60分，然后装个专家在那讲。用户点进来看到你整那么专业，就会提高预期，以为你会很牛逼。导致你本讲得是60分的知识点，用户听完觉得你只值30分。
