# 三、小红书的赚钱方式

对于普通人来说，常见的变现方式有这 4 种。

![](bbox=[0.48, 0.11, 0.88, 0.42])

+   **第一个：接广告**

接广告是小红书上最流行的变现方式。

因为小红书本身就是一个种草平台。大多数刷小红书的人群都是带着钱来的，她们来小红书的目的是挖掘好物。

比如化妆好物，家居好物，各种好看的衣服，好用的产品等等。一旦被种草，她们就会直接去消费，去线下实体店或者在网上的购物平台直接下单。

所以，大多数的品牌方会把品牌的广告预算放到小红书。让博主或者素人去推。

小红书接广告跟其他平台接广告，有一个很大的区别。
在小红书上，素人也可以接广告。素人，就是只那些粉丝只有几十几百的人。
