我自己有自媒体 IP 课，但是一直都没在公众号正经说过，其实 IP 这玩意并不是人人都能做的，所以我卖课都很挑系。

很多学员都会怀疑自己，觉得自己没有什么擅长的，什么也不会，但是看完这个案例你会发现，大部分人身上都是有价值的，只是没有找到自己的定位，没有找准人群而已。

我之前说，其实每个人身上都是有闪光点的，只是有些人没有找到而已，说白了就是瞧不起自己会的东西，觉得那些东西根本赚不到钱。其实有时候只是我们看不懂需求，低估了自己的价值而已。

由这个案例我想到，下沉市场其实还有很多需求未被满足。

比如，我是 94 年的，我爸妈今年差不多是 50 多岁，但是他们根本不知道怎么用淘宝京东或者拼多多购物，但是买东西这个需求又真实存在。你说这不是很强的需求。

假如你通过短视频找到这群人，然后搞一套课程出来，教他们怎么网购，其实和上面这个案例是一样的，既能帮助别人，还能赚钱，这不是一举两得的事情吗？

我搜了一下发现，现在好像还没有人做这一类的知识付费，有想法你们可以去搞一下。

为什么我觉得这个可以搞。

因为有个普遍的现象是，咱们父母那一辈的人，首先是有意愿会去尝试新时代的一些生活方式的，但是咱们作为子女的，大多数都会嫌弃自己的父母笨，这么教也不会，那么教还是不会。

大多数人都是很不耐烦的。

然后这时候你打个口号，让我成为你网上的孩子。

你说行不行得通。

（虽然说起来有点挺无奈的，父母都老了，咱们作为子女的还没一点耐心。）反正我觉得干这种事情，既简单，又实在，能帮助别人，还能赚钱，挺好的。

总之这篇文章的核心就是告诉大家，不要低估自己身上会的那点东西，每个人的经验都是值钱的。
