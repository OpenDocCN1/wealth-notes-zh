# **觉醒二**

给大家讲清楚，不会这些内容创作你一样可以出卖卖货。

区别于抖音的商品橱窗功能，抖音小店是面向字节全系平台的，可以上传自己的商品。而商品橱窗功能是指的抖音账号的商品分享功能，具体就是通过视频和直播分享，商品分享出现在你的抖音首页我们称之为商品橱窗，出现在视频里就叫小黄车，出现在直播里就叫小黄袋。

开通商品橱窗以后，你就可以添加自己开通的抖音小店的商品或者精选联盟（一个类似淘宝联盟的平台，就是各个抖音小店卖家把自己的产品设置佣金，让各位抖音达人来带货销售）。

说白了，商品橱窗是分享功能，如果没有开通抖音小店，你就只能给别人带货。而抖音小店可以上传自己的商品，还可以让其他抖音达人帮忙带货。

开通商品橱窗的路径就是在抖音个人主页，点击右上角的个人中心，然后选择创作者服务中心，选择变现能力的商品橱窗，然后按要求开通就可以。开通商品橱窗需要完成实名认证，然后个人主页视频数大于等于 10，以及粉丝数量大于等于 1000。
