# 普通人为什么赚不到钱

2021 年我和很久不见的大学同学聚会，觥筹交错之间被问到一个问题，他们说什么大家都是同一个起跑线毕业的，5 年之后你能混得风生水起，而我们却还处在一个月薪都不过万的水平，说完之后他干掉了杯中的酒，并缓缓地点燃了手中的烟。

赚钱这件事究竟有什么秘密？没钱的根源到底是什么？普通人如何才能有机会成功逆袭？人和人之间到底差在哪里？什么样的状态才能让人赚到钱。

其实对于这些问题，我刚毕业的时候也非常困惑，但经过这么多年的行业沉淀之后，我仿佛找到了些许可以给大多数人的答案。这些答案里面有认知、选择、信息输入、能力积累、努力执行、所处的城市、人脉圈子、胆量等等。他们并不是一个个单独的个体，影响一个人过得好与不好是需要由这些关键词串联起来，才有可能有那么一点逆袭的机会的。

这一节我们来聊一聊普通人为什么赚不到钱的问题。因为我觉得只有先搞清楚这些问题的底层原因，我们才有可能改变现状，尽可能的让自己成长起来。

对于这个问题，我的答案是，这个世界上充满了太多的陷阱，我们普通人相对于富人来说，其实一直都在各种陷阱里负重前行。比如我们从小就被教育、环境所影响，最终这些因素会导致一个人的认知水平截然不同，而认知又会影响一个人的选择，思考问题的方式，进而影响赚钱。
