# 2. 基金的风险和收益分析

基金经理会把大家的钱集合起来投资不同的股票或者债券，相对来说投资会更加分散，就算其中个股股票暴雷对于整体的影响也不会太大，因此基金的风险要显著的小于股票。

同样收益也会小于股票，但对于普通投资者来说挑选到优质的股票并持有到获利是相当难的。

# 三：基金投资的本质

# 1. 投国运

资本市场的走势反应了国家经济的走势，一个经济发展迅速的国家，资本市场必定会一路上扬，我们以世界上最强大的国家——美国的资本市场来分析。

在 1918 年用 1 万美元投资道琼斯指数，到 2018 年你的 1 万美元在股市中将变成 288 万美元，100 年是翻了 288 倍。

但是如果你在 2000 年投资相同的金额在欧洲股市（欧洲斯托克 50 指数），到 2020 年不仅赚不到钱，还要亏损 50%。
