# 第四章：捞金实操

其次费用便宜，现在互联网渠道手续费基本都是打1折，0.15%，比银行的销售费用便宜10倍，谁和钱过不去呢？

并且手机APP购买非常方便，所以这几年互联网渠道急剧抢占市场，我也推荐大家用互联网渠道购买基金。

| 平台类型 | 平台名称 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| 银行平台 | 四大行，和股份银行 | 1、安全信赖<br>2、试用于中老年客户，不会操作APP | 1、费用贵<br>2、一般只有少数几家基金公司 | 
| 基金公司 | 各大基金公司 | 1、品牌直销 | 1、产品局限性大，只买本公司产品<br>2、费用贵 | 
| 互联网平台 | 支付宝<br>天天基金<br>微信财付通<br>其他平台 | 1、费用低，2、大品牌、3、方便<br>1、费用低，2、数据最全<br>1、费用低，2、微信购买，方便 | 对于年龄大的用户，不会操作。 |

听我讲完了基金基础知识，很多小伙伴是否心动准备开始做投资了呢？

先不要着急，希望 在投资前做好充分的准备，这样才能在资本市场里稳赚不赔。
