+   2、利用蝉妈妈、飞瓜、抖老板、抖查查等抖音数据工具选品。

+   3、利用精选联盟选品，精选联盟有啥热门产品，你也上架啥产品。

+   4、利用同行来选品，观察同类目 top 榜商家所售产品

至于抖音小店的流量来源有三大类，分别是自营流量，猜你喜 欢和精选联盟，我们主要做的就是猜你喜欢和精选联盟。

# 1：自营流量

这个很好理解，就是将你的抖音小店和你在字节跳动旗下 APP 绑 定，然后把你商品放进你的直播间、短视频、文章、问答里去。当 然，这个是需要自己有一定的内容创作能力的，对于一般的小白来 讲，门槛也比较高，所以不建议大家去做。

# 2：猜你喜欢

这个是我们做无货源抖音小店最大的流量来源，根据字 面意思应该很好了解。就是抖音官方根据系统推荐，把你的产品推 荐给用户。大家都知道，抖音是不缺流量的，日活 6 个亿不是说着 玩的，而且在抖音小店处于刚刚起步阶段，平台卖家还不多，所以流 量扶持非常大。用店铺思维去做抖音小店简直不要太爽。

而且一旦抖音推出自己的电商 APP 以后，猜你喜欢推荐的流 量入口将会更大，届时搜索流量也会做起来。往平台电商靠拢。抖 音今年提出了兴趣电商概念，他的目的就是要用自己旗下的所有平 台，通过内容形式，以短视频、直播、文章、问答等多种形式嵌入电 商，为自己独立的电商平台导流。所以，在未来，抖音小店的流量 将更加恐怖。

# 3：精选联盟

这个也是我们在做无货 源电商抖音小店的一大流量入口来源。首先给大家解释一下什么是 精选联盟，精选联盟是一个类似淘宝联盟的 CPS 双边平台，一边链 接商家，一边链接字节旗下所有 APP 的内容创作者。

商家给商品设置推广佣金，内容创作者领取商品推广链接， 将推广链接嵌入自己的内容里带货，用户通过内容创作者的分销链接 下单购买确认收货以后，平台自动将佣金达到创作者账户，然后进行 提现。
