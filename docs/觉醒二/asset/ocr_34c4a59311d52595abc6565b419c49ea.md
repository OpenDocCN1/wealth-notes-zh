# 他，淘宝蓝海运营最高月入7万——不辍

黑油们大家好我是不辍，拽哥的“黑粉”一枚，目前在体制内上班，兼职做淘宝蓝海项目。

从1月份接触淘宝蓝海项目至今运营了3家店，平均月利润2万左右，最高月利润是7万。

这个成绩实在是放不上台面，所以这次的分享主要并不是分享实操的细节和技巧，更多的只是一个淘宝小白从0到1的心路历程。

# 从0到1，迈出第一步

关注拽哥的公众号其实很久了，昨天星球提示到期续费，算下来加入星球也快一年了。

我平时的工作也算规律，但是守着那万把块钱的工资过着一眼望到头的生活，内心着实有点不甘。

在拽哥这里一边学着奇奇怪怪的知识，一边也想找个项目丰富一下业余的生活。

看到向总的文章后，再结合自身实际，那一瞬间怦然心动。

随后我又顺藤摸瓜，把向总的知乎、公众号的文章全部仔细翻看了一遍，衡量了一下手头的预算和自身的时间精力后，觉得这个项目能落地，于是便直接进了向总的内训社开始我的淘宝小白从0到1之路。

# 大力出奇迹，精力换概率

1月份我花了一个月时间前后听了五遍课程，因为是小白，感觉每一遍听完都有新收获，每一遍都有新笔记（当时做笔记的笔记本落单了没拍照），就这样初步建立了淘宝运营的大概知识体系。
