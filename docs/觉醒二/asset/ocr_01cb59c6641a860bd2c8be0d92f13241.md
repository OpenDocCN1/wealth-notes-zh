# 觉醒二

原生家庭对一个人的影响，有好的一面，自然也会有不好的一面。我们都知道，一个人的行为是受大脑中的想法控制的，但是这个想法又是怎么来的呢？这个想法其实最开始并不是你的，而是从你生下来的那一刻，你身边的人给你种植的。

谁是你身边最近的人，答案是父母。

举个例子，有些人的爸妈天生就是那种尖酸刻薄，贪小便宜的人，你觉得这个小孩长大后会是一个大方得体，有格局的人吗？我觉得大概率不会。

再举个例子，有些人的爸妈如果都是七八十年代的老师，儒雅随和，家庭氛围幸福又和谐，我想这个小孩以后应该懂得如何去爱一个人，如何去处理亲密关系。

讲点真实的现象，小时候我会发现村里的一些家长，对于自己孩子的教育很随意，他们都信奉读书无用论，在他们的认知里，他们会觉得反正早晚都是要出来打工的，还不如早点从学校出来赚钱，还能多份收入。

同样，很多家长抱着他们那个年代的思想告诉自己小孩，一定要早点结婚。很多人20出头，都还没有弄明白什么是爱情，什么是婚姻，就匆匆忙忙领了证办了婚礼。结果导致的是，大多数人没过一两年觉得不适合就离了婚。

所以这说明了一个什么问题，这说明一种人只能被种植同一种人的思想。如果我们被种植的思想是穷质的、老旧的、不健康的，那么假如我们还没意识到这个问题，并且不进行自我批判和认知突围的话，那我们这辈子大概率也只能靠这种老旧的思想活着了，最终导致的可能就是生活一团糟、事业不顺心。

即便我们后天远离父母，我们脑子里依然会残留着一些父母思考问题的方式，然后慢慢在不同的环境中，我们又会被人所影响，长期下来就会形成一套自己的认知思维体系。

换句话说，你的一些想法，一切行为，都和你所在的环境有关，人是环境的产物这句话，我想没有人会陌生。
