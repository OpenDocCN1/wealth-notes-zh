# 第三：坚持做复购，积累信任

他的视频为什么拍那么简单随便也有人买？因为他的账号已经逃离了抖音的“算法魔掌”，已经是自由身了。

什么意思呢？在抖音发作品，不管你粉丝多少，都要经过抖音的算法考试，什么完播率用户停留时间等等，流量焦虑这个词不是白来的。

但当你通过长时间的信任积累，维系和用户之间的关系，你的用户就会每天主动上门来找你买东西。

这是抖音的算法管不了的。
