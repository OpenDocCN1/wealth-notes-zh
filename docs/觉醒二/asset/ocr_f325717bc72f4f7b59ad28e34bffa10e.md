# 一些**小感悟**

结合自己职场和自媒体的经验，给大家分享一点点小的感悟。

+   1、做一个技术人，喜欢研究源码技术当然很酷，但培养解决问题的能力更重要。不论是平常或者项目在特殊时期，一定让自己成为一个解决问题的推动者。

当公司出现重大问题的时候，能够主动站出来并且解决问题的人，将会有很大的概率让领导对你加深印象，后期得到提拔的概率将大大加大。

在公司想成为一个什么职位级别的人，就先得让自己的能力匹配上那个职位，当你真的已经拥有职位对等的能力时，提拔也就不是远不了。

+   2、集中力量成为一个小领域内的 TOP 人物，在职场或者自媒体领域同样适用。

比如在小组内成为能力突出者；在某个细分技术领域内成为技术专家；先侧专注于某一个博客平台成为博客专家。

因为在相对靠前的位置，才会有相对靠前的机会和曝光量；头部所拥有的曝光量几乎是中底部的 N 多倍，当然机会也会同样如此。

在某一个小领域内做到头部之后，很容易在其他领域去复制这个经验，从而更加快捷的提升曝、光量，增加成功概率。

+   3、这世界唯一不变的就是变化，要喜欢和拥抱变化。

对于像大多数像我一样的朋友，没有资源没有背景，我们最应该喜欢和拥抱的就是变化，正是因为有变，才有机遇，才有机会。

以我为例，正是因为很多主动的和被动的变化才把我带到今天。

主动的变化包括选择成为程序员，选择北漂、选择做自媒体、选择成为自由职业。
