+   （1）商家群：我们只需要找到楼下的超市或者母婴店，我们买一瓶水，咨询一下商家有没有福利群，我们进一下，正常情况下，商家都愿意让自己进去群。之后我们再把人才网小号拉到群里，考察群的活跃度，然后我们用人才网小号加群主，给群主发个 1 块钱红包，告诉他之后泰安市有好的岗位我们发布到群里，只要不是砍价广告，其他的什么广告，有价值有用的，群主都会同意的；

+   （2）社区团购群：社区团购群目前是比较好新型型的群，随便申请一个某个平台的 bd（就是帮助平台拓展团长的人员），大平台已经帮你把优质团长的位置包括手机号都搜集出来了，我们打电话让他们拉自己进群就可以了，考察群活跃度，再用上述商家群的方式，进行小号岗位发布；

+   （3）村群：村群目前是最大的本地流量池，没有之一，村群的建立者都是当地比较有威望的人，我们可以把自己包装成一个信息发布的角色，进行一个村一个村的拓展，直接进村委会，给村官直接聊，正常一个城市的村大概是 2000-4000 个；第二个方式就是在一个镇上的快递驿站摸爬；

+   （4）业主群：业主群是城市最大的流量池，进群之后你只要在群里创造有价值的信息，就不会剔除你，对于一线城市来讲，业主群可能没这么好进，但是对于三四线城市而言，业主群还是相对来讲好进的，业主群可以发动身边的熟人，发红包进群，因为一个城市的楼盘是有限的，可以拉出楼盘名字，发动身边的朋友发红包邀请进群，50 块红包拉进群还是没问题的；
