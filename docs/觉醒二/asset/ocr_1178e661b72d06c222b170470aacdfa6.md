# 三、什么是短视频带货

短视频带货说白了，就相当于你在抖音、快手、视频号、小红书等平台开的一个网上小超市。

但是这个小超市你并不需要付租金，不需要花钱装修，不需要花钱囤货，不需要你日夜守着。

这间小超市还能在你睡觉的时候“继续自动售卖”，如果方法用对，来你“小超市”购物的人可能一天就有十几万甚至上百万人。

一部手机、零基础就能做、适合打工人、宝妈、在校大学生、个体创业者、以及想要找副业的各种人。

说白了就是，你只需要把商品的视频拍好，在视频的购物车里挂上平台里的商品，只要有人看到并下单，你就可以赚到佣金。

比如抖音上有精选联盟、视频号有选品中心，里面的商品都是平台选过的产品，你只要选一些你想带的货，拍好视频就能赚到钱。

这是时代给予普通人低成本创业最好的机会。传统创业你需要租门店、要搞点供应链、要投入很多资金，风险大、回本周时长。

但现在短视频时代都不需要了，你只需要有一部手机，搞清楚短视频带货怎么玩，你就能带货赚佣金。

因为你帮商家做了推广，你赚的是商家给你的产品分佣，几乎不需要投入成本，没有任何的风险。

2、不需要自己囤货、发货
3、不需要在意别人的脸色
4、不需要做售后服务
