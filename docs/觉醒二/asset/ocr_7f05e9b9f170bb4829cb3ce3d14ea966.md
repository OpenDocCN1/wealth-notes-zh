# 再次迷茫

这一年年底，我彻底迷茫了，我不知道以后的路该怎么走了，闲的无事时，我在想我十年的技术，到现在还剩几何？

2017 年裸辞时，想着跨行业赚点钱，继续我的软件生涯，经过两次探索发现失败的非常彻底，才有点明白，没有任何一个行业，是简简单单就能把钱挣了的。

都是需要付出大量的时间、坚持行业的低谷才能挣到自己该挣的钱。那么我能不能一个人继续我的软件生涯呢？

有一天，已经快过年了，想如何将继续我的软件事业，在网络上看 dubbo 对比 springcloud，dubbo 在那个时还没有重新开始维护。

让我心 有 于悸，而 springcloud，spring 嘛，大家都懂的，好多人都说微服务好难，我不相信，决定全力一博 springcloud。

我资料的过程中找到微笑哥的博苦，根据微笑哥的 springcloud 教程，在过年前后我边学边录制了一个初级的 springcloud 的 git 开源项目，在视频的最后我预告了要出一个 spring-cloud 脚手架项目。
