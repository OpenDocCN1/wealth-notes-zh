# 三：平台审核

填写完各种资料以后，我们就要提交审核了，平台将在 1-3 个工作日内进行审核。审核情况会以短信的形式发提到手机。

当然，如果没有审核通过，系统也会告诉你具体原因，你再按要求调整就是了。

# 四：账户验证

审核通过后，会直接进入账户验证界面，支持两种验证方式：实名认证、打款验证。

+   1：实名认证

第一步：填写经营者/法人个人名下的银行卡号

第二步：输入银行预留手机号，填写验证码

第三步：完成验证

+   2：打款验证

第一步：填写企业对公银行卡号

第二步：选择开户银行

第三步：选择开户支行所在地

第四步：选择开户支行

第五步：等待打款验证

第六步：平台已打款，待回填金额

第七步：完成验证

当然，这里也再次建议大家直接用实名认证，因为现在企业对公账户管控很严，很多企业开对公账户，银行都是需要实地上门检查的，所以建议大家用实名认证会比较好。
