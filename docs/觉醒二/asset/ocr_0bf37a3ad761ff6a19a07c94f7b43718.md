# 为什么基金现在这么火？ 小白怎么才能参与？——强少

最近越来越多的朋友私信我说：“强少强少，你买的基金赚了多少钱？有没有比较推荐的，我也想 在基金里赚点小钱。”

其实想要玩好基金，多多少少还是需要学习一些相关知识的。

我知道的很多小白，看着别人玩基金赚了不少钱，于是就眼红跟着去买，结果完全不知道自己是买在了最高点。

等连续跌几天后，心态直接崩塌，然后在低点卖出。

这是典型的高点买入，低点卖出，很愚蠢的一种投资行为。

我入行十年，每天仍在不断学习，才不至于在投资市场当个韭菜。

我准备写一个《玩转基金》的系列文章，实战基金投资经验分享，全是我十多年 来在基金投资方面的干货。

希望你看完这些内容，能对自己的投资思维有一定的影响。

最起码，能做到不再当韭菜。

基金这两年确实非常火，不论是对普通小白领，还是中产、富豪，基金都成为了他们不可获取的投资工具。

并且很快会超越股票，成为最受老百姓喜爱的投资工具。

但是我发现，绝大部分人对基金并没有全面的认识。

大部分人是一知半解，一顿胡乱操作，瞎买！

还有些人是想学习基金投资，但是没找到全面的攻略。

所以呢，我准备从今天开始，做一个针对小白的、从 0 开始的基金投资系列文章—《玩转基金》。
