决定一定要去一家互联网公司，当时西安几乎没有互联网公司，于是决定北漂。

# 北漂启航

北漂是人生最对的决定之一，北漂后不论是技术水平，还是人生视野的提升都是最快的。

来到北京后，去了一家第三方支付公司，那时候公司刚搭建第三代平台，新的平台有很多问题，一边解决问题一边开发各种新项目。默默积累着。

同时，一位朋友在海淀创业街的号召下，想创业做一款心理咨询方面的APP，拉我入伙，我们两个人除过工作，就整天泡在创业街的咖啡馆。

2个纯粹的技术人，妄想做一个APP就拉到投资走向创业，失败得几乎没有悬念，6个月后朋友继续去上班了，而我真正的遇到了一个互联网风口。

2013年余额宝横空出世，激发了人人线上理财的热情，也激活了半死不活的互联网金融。2013年，被称为互联网金融元年。

# 互联网风口

2013年年底的时候，公司的技术总监说，明年找你做一个秘密项目，我问什么秘密项目呀？总监故作神秘，到时候你就知道了！

2014年春节刚过，领导就召集了公司最精锐的同事，全部拉到一个5星级酒店，要求一个月内封闭开发出一个对标“陆金所”的项目。

项目主要以从百度过来的副总牵头，我们来做配合，当时我只是这个项目中的一个主力开发，当然机会就这样突然来了。

封闭奋战一个月后，项目倒是开发出来了，但是这位副总却要出去创业了，并且带走了绝大部分参与的研发人员（仅留下3个）。

可能是我喜欢在群里帮大家解决问题，加上一直印象还不错，引起了领导的注意，我的2位领导想说让我尝试负责这个项目，领导承诺要给人，要钱给钱。

那我就试试。
