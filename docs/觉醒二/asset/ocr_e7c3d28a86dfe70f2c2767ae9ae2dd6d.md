# ##### 1、团购的逻辑

团购，电商领域的超级黑天鹅，团购这个领域长出了美团，长出了拼多多，长出了聚划算，长出了直播电商，甚至把双十一变的热度不在，稀松平常，让整个阿里在近几年绝对焦虑；

我们就以黄峥的思考来讲述，传统电商其实就是把义务小商品搬到网上，流通侧信息高度透明化，线上商贩卖竞争越来越激烈，线下生产的计划脱节和对比就越厉害，其实对线下传统制造业改变并不多；
