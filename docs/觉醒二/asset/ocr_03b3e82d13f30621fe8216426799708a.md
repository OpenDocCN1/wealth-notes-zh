# 序言

大家好，今天这篇文章，将会是一本黑公众号自诞生以来的最后一篇文章。近段时间，一本黑这个账号将会和我的另一个号郭拽拽合二为一。接下来，讲一讲我和一本黑的故事，以及停更原因。2017年，我大学毕业，彼时我还是一个“三无人员”，没资源、没人脉、没背景。年轻人想要逆袭，想要白手起家，想要从底层爬起来，真的非常困难。多年之后的今天，我明白一个残酷的真相，很多人之所以混得不好，大部分情况来说，并不是说这个人能力不行，也不能说努力不够。而是在各种机缘巧合下，选没选对，或者有没有机会选的问题。我个人这些年的发展，完全是选对了行业，遇到了贵人，抓住了公众号的内容红利。是这个世界所谓的时代红利，放大和造就了我自己，给了我积累资源、人脉和资金的机会。有时候想想，努力在选择之下，可以说一值一提。这是我作为一个清醒的年轻人，该有的自知之明。我当时遇到了L，他年长我七岁，年少成名拿过上千万的投资。当时一本黑这个账号的灵感就来自L，而我作为主理人的身份，开始了在一本黑公众号的内容创作。
