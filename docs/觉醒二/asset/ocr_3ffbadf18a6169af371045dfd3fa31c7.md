# 【如何找到你的客户】

常用社交媒体引流，寻找电商运营的 qq 交流群，贴吧，豆瓣，电商论坛，知识星球，在里面加人混脸熟，慢慢增加客户，这个方法在对于新手入行没客户，你只能通过这个来引流。

这里主要推贴吧，豆瓣很多人以为加人就是找到群加进去那么简单，我操盘时的思路是，贴吧豆瓣很多楼主要留下钩子，让人留微信，他负责拉人，但他不能留自己的微信，于是这给了我们漏漏可寻。我用爬虫把这些人的微信号整理出来，铺设几个微信号（我一般是选择 2 年以上带圆形支付记录），每个号一天主动加 10 个人，加他们抛下钩子，通过后续跟他们说你好我是贴吧

（豆瓣）来的，我留言了那个楼主拉你进群了吗，他一直没回我，你可以拉我进群吗？这些人由于也是做电商的不会他们不会在下面留言，于是我问他能不能拉我进群，麻烦他多拉几个群，因为我刚做电商。

这个方法我现在都在用，效果很好朋，可以借鉴到其它行业。

新手需要做的就是，大量加微信群，如果你这样子后面还赚不到钱，你可以找我，我把你加的所有微信群回收。

把几个微信号的群互通拉进群，切记需要分不同时段拉进群，以免被同时踢群。接下来就是开始发广告，这行你主动加别人的效果是不好的，只有主动找你的客户成交率才会非常高。

购买电商公众号软广，整合资源微信群广告

在网上找几个做公众号排名的网站，例如新邦，整理一份电商行业公众号 top100，里面有微信公众号负责人员的微信，添加微信，跟他们谈好发推文，或者付费购买其名下微信群广告 x 条，具体看你财力。

我就是买了几个专门做电商领域整合的微信群广告，包一次广告几千块钱，效果很不错。但是这两年随着很多人抢这块，引流效果逐渐降低。
