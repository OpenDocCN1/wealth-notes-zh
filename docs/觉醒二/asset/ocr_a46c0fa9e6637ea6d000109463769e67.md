# 三、怎么卖？怎么挂购物车变现赚钱？

+   1、直接挂购物车

虽然这是最快的下单路径，但上面也说过了，有门槛，所以暂时玩不了。

+   2、挂有商品信息的公众号链接

也就是在公众号文章里面放一个购买商品的小程序，发布视频的时候，挂上这篇带有购物链接的公众号文章，用户要先点进这篇文章，再点去购买。

![](bbox=[0.55, 0.46, 0.88, 0.64])

和已经开通创作者变现功能的账号相比，我们新号的这种挂链方式，用户要多一个步骤，也就是多点一次才能买到这个产品。

但对比上面那种要引导用户进主页才能购买下单的方式，已经好很多了。
