# 序言

说白了就是在自己的领域和圈子里待得太久了，觉得月薪过万都是一种奢侈，你怎么让他去相信做自媒体能这么赚钱。

很多人之所以赚不到钱，原因有很多，要么是在自己的行业里混得不夠久，要么就是没做好混，或者说赛道没选对。各方面眼界不够，看的东西也不多，知道得也太少。

人以类聚，物以群分，先想想自己现在呆在在一个什么样的圈子里。

你身边最常接触的5个人，他们收入总和的平均，差不多就是你的收入水平。

环境对人的影响是巨大的，它影响你的眼界、格局、赚钱能力，甚至是未来的很多可能性。

赚不到钱，大多数情况下可以说你没有看到，没有看到那些活生生的赚钱案例，你知道得太少了。

人和人最大的竞争力，有时候其实就是信息量输入的多少。

要想提升自己的赚钱能力，有两个很重要的点，第一，选对适合自己的赛道，深耕下去。

第二，换优秀的圈子，去提升自己的眼界和格局，多看，多思考，更新现有认知。

只有通过大量的观察，你才能知道那些赚钱高手是怎么赚钱的，他们的模式是什么，这样你才能一步步的获取到有效的信息和玩法。

而我创建的这个社群，就是给大家提供这么一个圈子和环境。给大家一个打破成长瓶颈的机会，给大家一个接触牛人的人的机会。

俗话说近朱者赤近墨者黑，讲的就是这个道理，你得靠近牛逼的人，看别人是怎么做事和思考的，看别人成功或者失败的经验，看得多了，很多东西自然就明白了。

这个社群，在过去几年时间分享了很多赚钱案例、副业思路、个人成长、投资、创业心得等等。

总之它是一个提升你认知，让你找到同频人的这么一个社群。
