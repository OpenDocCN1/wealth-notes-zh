# 序言

大家好，今天这篇文章，将会是一本黑公众号自诞生以来的最后一篇文章。近段时间，一本黑这个账号将会和我的另一个号郭拽拽合二为一。接下来，讲一讲我和一本黑的故事，以及停更原因。2017年，我大学毕业，彼时我还是一个“三无人员”，没资源、没人脉、没背景。年轻人想要逆袭，想要白手起家，想要从底层爬起来，真的非常困难。多年之后的今天，我明白一个残酷的真相，很多人之所以混得不好，大部分情况来说，并不是说这个人能力不行，也不能说努力不够。而是在各种机缘巧合下，选没选对，或者有没有机会选的问题。我个人这些年的发展，完全是选对了行业，遇到了贵人，抓住了公众号的内容红利。是这个世界所谓的时代红利，放大和造就了我自己，给了我积累资源、人脉和资金的机会。有时候想想，努力在选择之下，可以说一败涂地。这是我作为一个清醒的年轻人，该有的自知之明。

我当时遇到了L，他年长我七岁，年少成名拿过上千万的投资。当时一本黑这个账号的灵感就来自L，而我作为主理人的身份，开始了在一本黑公众号的内容创作。

2017 年，其实已经算得上是公众号红利的尾声，但就是凭借着猎奇、且硬核的互联网揭秘内容，一本黑这个账号得以成功出圈。

我记得那时候，我仿佛一个自由调查记者，拿到一个线索就去深挖，往往一篇文章从调查到成稿，差不需要一周左右的时间。

当时的内容大都是互联网擦边产业链的揭秘，比如色情、博彩、非法集资、诈骗等。写这类文章费时费力，需要用到一些黑客技术协助我做调查。

于是，我开始塑造出老师傅这个形象，每当老师傅点上一根烟，利用计算机基础知识、还没等烟熄灭的功夫，所有的产业链就已经逐渐浮出水面，这些句子像皮去灰级读者依然历历在目。

而老师傅究竟是谁，一直以来都是一个需要保持神秘的事情。

我只能说他是以某个黑客朋友为原型，通过我的文字描绘出来的一类人。

那时候我作为一个初出茅庐的内容创作者，在和老师傅的互相配合中，做了很多有趣好玩的调查，并写成了故事进行事件还原。

比如调查过某色情偷拍狂经常出入一家洗浴中心；

调查过某虚拟货币市值数十亿，并且这个虚拟货币还能在线下实体店消费；

我还采访过很多在金融圈从事骗贷行业的人，他们为了赚钱不惜偷渡异国他乡，靠坑蒙拐骗为生；

我们还拦截过某境外诈骗团伙和家人的通话录音，发现一哥们用诈骗赚到的钱，医治着老家瘫痪在床的老父亲。

这些都是非常有趣的故事素材，它存在于大众看不到的互联网阴暗面，甚至能穿越周期让人揣摩人性的无奈。

后来因为一些个人原因，2019 年初，我带着一本黑账号离开了 L，独立负责一本黑的内容创作和商业变现。

这个过程中其实还发生了很多事情，慢慢开始影响我创作一本黑内容的走向。

前段时间我们在一起喝酒，聊到以前做过的一些事情，发现那时候做公众号真的就是为了好玩。

从没想怎么能通过公众号赚到什么钱，完全是靠做一件事情来获得精神满足。

只是后来的发展都慢慢趋向于向现实的各种原因妥协，我的重心也不再放到一本黑的经营管理上，而是独自扩展了更多的衍生业务。

除了不可控因素，在对于经营理念和商业变现上，我们也总找不到一个可以平衡的点。

我们无法说服彼此。

后来我们觉得，一本黑这个名字的出现，就是为了记录中国互联网的阴暗面故事的，既然现在不得不面临转型，那就让一本黑回到最开始的状态吧。

一直以来，我都觉得能选择一个自己热爱的事业，是运气带给我的馈赠。

但也许曾经那些成就我们的东西，可能最终又会反过来束缚和打败我们。

这个感觉其实对我来说尤为强烈，有段时间我一直陷入一种路径依赖，错把过去的小成功当做是自己的能力。

但其实不是的，大部分情况下来说，一个人的成功是时代红利和机会造就的。

所以我一直告诉自己，不要陷入路径依赖的牢笼，不要过多看着过去的经验不放，要多试错，多犯错，要把以前积累的能力、认知和资源复用到另一个赛道上。

懂行的人都知道，从自媒体变现与 IP 价值这个点来说，一本黑不管是名字还是内容，对于变现的价值来说都是很局限的。

总的来说，停止的原因很多，内容方向、商业模式、业务转型……但最主要的，其实还是我们自己对于初心的情感还在。

既然回不到过去，那就让它留在过去。

很多人会说注销了很可惜，账号迁移合并也会流失很多读者，为什么不直接改个名。

什么样的安排能对我利益最大化，这我比谁都清楚。

但我觉得，在利益和情感面前，我愿意选择后者。

惭愧地讲，我们有时候都是矫情的人。

回看早期的文章，确实是硬核，里面写了很多大众闻所未闻的操作和思路，展现了互联网的千奇百态。

如果你想要这些内容，可以扫码添加我微信，在我朋友圈领取。

对了，我曾经创建了一个付费的圈子，叫【一本黑的朋友们】。

为此，我为一本黑的会员们留下了两本书，分别是《觉醒一》和《觉醒二》。

当时创建的原因有两个点。

第一，解决我和读者、读者和读者之间链接的鸿沟。

大家关注我这么久，我想把大家聚在一起，交个朋友的同时，搞一些好玩的，能提升赚钱意识和能力的事儿。

第二，通过提供服务，售卖经验的方式赚点小钱，可以理解为大部分人口的【割韭菜】。

一定程度上来说，我并不认为【割韭菜】是个贬义词。

最起码在我这里不是。

我始终觉得，大部分人之所以平庸，赚不到钱，就是因为看得不够多，没有看到更多的可能性。

大部分普通人是不混自己领域外的圈子的，相对来说他们的思维会比较固定。

比如一个月薪 6K 的人，就算不吃不喝，把工资全部存下来，一年也才七万出头。

如果我告诉你，我做自媒体，一个月纯利润能做到三十万，你觉得他会怎么想。

可能大部分人会说我吹牛逼，为啥，因为他没有看见，所以不相信。

说白了就是在自己的领域和圈子里待得太久了，觉得月薪过万都是一种奢侈，你怎么让他去相信做自媒体能这么赚钱。

很多人之所以赚不到钱，原因有很多，要么是在自己的行业里混得不够久，要么就是没做好混，或者说赛道没选对。各方面眼界不够，看的东西也不多，知道得也太少。

人以类聚，物以群分，先想想自己现在呆在一个什么样的圈子里。

你身边最常接触的5个人，他们收入总和的平均，差不多就是你的收入水平。

环境对人的影响是巨大的，它影响你的眼界、格局、赚钱能力，甚至是未来的很多可能性。

赚不到钱，大多数情况下可以说你没有看到，没有看到那些活生生的赚钱案例，你知道得太少了。

人和人最大的竞争力，有时候其实就是信息量输入的多少。

要想提升自己的赚钱能力，有两个很重要的点，第一，选对适合自己的赛道，深耕下去。

第二，换优秀的圈子，去提升自己的眼界和格局，多看，多思考，更新现有认知。

只有通过大量的观察，你才能知道那些赚钱高手是怎么赚钱的，他们的模式是什么，这样你才能一步步的获取到有效的信息和玩法。

而我创建的这个社群，就是给大家提供这么一个圈子和环境。给大家一个打破成长瓶颈的机会，给大家一个接触牛人的人的机会。

俗话说近朱者赤近墨者黑，讲的就是这个道理，你得靠近牛逼的人，看别人是怎么做事和思考的，看别人成功或者失败的经验，看得多了，很多东西自然就明白了。

这个社群，在过去几年时间分享了很多赚钱案例、副业思路、个人成长、投资、创业心得等等。

总之它是一个提升你认知，让你找到同频人的这么一个社群。

我一直秉承的一个观点是，一定要花钱买别人的经验，这是最好的学习方式之一。

# 第一章 认知升级

# 先赢下第一局

深圳是一座快节奏的城市。

有人在这里草根翻身年入7位数，从此改变命运；有人折腾七八年依然入不敷出，除掉必要支出所剩无几，最终只能卷铺盖回老家。

前几天看到一个老同事发朋友圈，说自己今年35岁了，在深圳这座城市待了十年，实在是撑不下去了，工作、恋爱两不顺，只能和自己握手言和，卷铺盖回老家。

我当时看着挺感慨的，但现实就是这么残酷，这就是大多数深漂、北漂、沪漂人的真实写照和宿命。

他们来的时候一声不响，走的时候也黯然无光。

有一天傍晚下班我走出公司大楼，看到了一些值得思考的场景。

外卖员奔走于城市的街道和楼栋，大楼门口的保安按照惯例检查人群的核酸码，路边报停的小店支付宝悄悄入账15元。

比起大楼里各种高科技公司的核心人才，他们算得上是低收入人群。

此时我想到的是，或许他们的智力和能力并不比刚走出大楼的律师差，仅仅只是因为行业站位的不同，才导致了他们拥有不一样的人生。

无奈的是，就算他们把各自的工作做到极致，可能也无济于事，依然不太比得上那些高价值行业里的平庸人士。

这里提到一个词叫做高价值行业，相对应的自然就是低价值行业。

在我看来，高价值与低价值的区别在于行业的门槛和壁垒。

比如外卖员、快递员、保洁阿姨这种行业就是典型的低价值行业，因为门槛足够低、替代性足够强，几乎人人都可以做。

反之律师、程序员等行业就算得上是高价值行业，很多专业知识需要付出时间学习和积累，门槛高、壁垒强。

但是，学得越多就能赚到更多吗？

如今各种野生网红靠着哗众取宠的方式博得大量关注，扭扭屁股就能赚得盆满钵满，比起某些埋头苦读的老实书生来说，他们好像就是天选之子。

显然这个逻辑并不成立。

但是有一个事实是，不同的选择造就不同的人生，选对一个行业是普通人逆袭的关键。

不管是千万粉丝的网红、还是500强企业的核心高层、亦或是家电维修工人，他们在行动力或者执行层面，并没有太大的区别。

前者花2小时做的直播大纲或PPT，可能会撬动巨大的价值，而后者花2小时修好的冰箱，显然只能赚个百来块钱。

真正决定了他们社会价值的等级，不管是杰出还是平庸，其最根本原因，在于谁在最开始的决策层面投入了更多的认知。

选择对于我们普通人来说就像是一面高墙，跨过去了就是另一番风景，跨不过去就是一生的障碍。

前段时间我拍过一个视频，说一个草根想要翻身赚到100万，那么他就要去做能年入百万的事情。

这句话乍看一下子就废话，但请各位仔细想一想，你听说过送外卖、跑滴滴的有年入百万的吗？

另外这里多说一句，那些成功赚到钱的人往往也会陷入一个误区，觉得自己现在所谓的成功完全是因为自己的能力强、够努力。

当然，我们不能否定别人战术上的勤奋和技术上的能力，他们在各方面都远超越常人，但绝大多数情况下，很多人会高估自己的才华，忽略了时代给自己带来的机会。

我曾经就因为赚了一点小钱高估过自己一阵，后来发现有这种想法其实挺傻逼的。

其实很多人之所以能赚到钱，首先是选对了个行业，抓住了时代红利和机会。

是这个所谓的红利和机会，推动着他们去补自己的能力和认知。

于是他们靠着一个机会积累了自己的第一桶金、积累了行业认知、人脉和资源，这才慢慢形成自己的壁垒。

比如 2015 年前后，你靠着一张嘴一个概念，就能把投资人忽悠得团团转，百万千万的投资人家也愿意天使轮一把。

但你再看现在，投资人都变聪明了，要是项目不能扎扎实实的赚到钱，你的概念包装得再牛逼，人家可能也不会多看一眼。

互联网上经常说一句话，没有所谓的马云时代，只有时代中的马云。所谓的成功，往往都是时势造英雄。

我当前这点微不足道的小成绩，也是因为一开始选对了一个适合自己的行业和赛道，才在未来的发展中嗅探出了更多的可能性。

我 2016 年开始接触公众号写作，写了一年才 300 个粉丝，但好在确定了自己未来 5 年的职业方向；

后来抓住公众号红利积累了几十万粉丝，做出成绩后，又复制了几个不同类型的账号；

再到短视频领域，我们也能干出几个百万粉丝的账号。

在电影《1942》里，张国立饰演的地主，在逃荒的路上和他家里的长工说：

“等到了陕西，立住脚就好了，我知道怎么从一个穷人变财主，给我十年，你大爷我还是东家。”

这句话里面我看到的是，一个人只要赢过一次，那就能用过去积累的经验、认知、和资源去赢下一次。

所以对于普通草根来说，最关键的地方在于如何选对，且尽早的赢下第一局。

# 你不知道的赚钱真相

我大学毕业之前，去深圳找了一份月薪六千，敲代码的工作。

当时心里就想着，要是我毕业之后能拿到八千一个月就挺爽的，职场上再努力，每年涨薪两三千，25 岁左右收入怎么也能上万了。

事实上我在毕业之后的两年里，工作状态都还挺不错，第一年月薪六千，由于工作出了些成绩，第二年直接就涨到了月薪一万五。这个薪资涨幅我相信大部分人是做不到的。

但是在这个过程中我慢慢意识到，即使我每个月能稳定收入两万块，并且还是税前，一年不吃不喝全部存下来也才二十万出头。可实际情况是，还得除去各种花销，所以根本存不下什么钱。

直到我开始在自己的自媒体业务上发力，我才意识到，打工只是让自己进行能力和资源的积累，是一种短暂的过渡，只有自己创业才有可能实现财务自由。

一般情况下，大学毕业两三年内，基本上看不出每个人的差距有多大，这时候的同学彼此都还会经常联系，顶多是谁升职加薪，谁马上研究生毕业，又或者谁出国留学。大家的经济收入不会有特别大的差距。
