# 淘客们是怎么获取流量的？——弥策

因为微信个人号承载力无法承载太多的泛粉，团队运营力的消耗还有最终的转化力问题，淘客最需要的就是精准的电商流量，淘宝站内用户是淘客的一大批流量来源。

# 评价粉：基于淘宝评论区流量，评价粉曾火遍一时

![](bbox=[0.21, 0.46, 0.86, 0.67])

评价粉就是买一个商品，在评论区写评论，做个图，然后告诉用户加哪个微信或者是关注哪个公众号，可以比正常买便宜，

对于评价粉来坑优势是：

+   1. 流量大，当某个淘系商家烧钱做推广的话，你所留的钩子（加微信、加公众号）会不断有曝光，换种说法商家的一部分广告费是为你做的，也算是截流的一种；

+   2. 有针对性，你需要美妆粉你可以去美妆商家下面做评价，你需要零食粉，你可以去零食商家下面去做评价，所有可以根据自己需求，找到对应的粉丝。
