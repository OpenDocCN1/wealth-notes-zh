# 二： 基金投资的基础介绍

俗话说“工欲善其事必先利其器”，对于想要在基金投资中赚到钱的小伙伴们，我们首先要搞清楚基金到底是个什么东东。

基金从募集形式上来看可以分为公募基金管理，私募基金门槛高，风险高，主要大佬们玩的东西，普通投资者参与的机会较少。

这篇文章主要讨论的是公募基金，大家在支付宝里看到的基金基本都属于公募基金。

# 1. 基金的起源

第一次工业革命后，英国工商业发展迅速，老百姓兜里有钱了就开始对股票进行大规模的投资，尤其是海外市场。

但是由于对国际投资知识，海外投资环境缺乏了解，再加上地域和语言不通，导致大量的投资者亏损被骗，因此大家就萌发了集合众多投资者的资金，委托专业人士管理的想法。

1688 年，英国成立海外及殖民地政府信托基金，主要投资海外实业和债券，这被视为历史上第一支基金。

大家可以看出来基金投资本质上就是委托理财，把我们的钱交给专业人士投资，他们在专业上远远超过我们，我们赚钱的机会更大，亏钱的机会更小，这类人就被叫做基金经理。
