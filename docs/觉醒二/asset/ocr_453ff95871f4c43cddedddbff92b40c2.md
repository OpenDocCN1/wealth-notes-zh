# ## 高手都在用复利赚钱

上面说到两种赚钱模式，一种是出卖单位时间，一种是把单位时间卖多次，而这里要讲的第三种，是通过复利赚钱。

复利是啥意思，简单点说就是，你做事情A，会导致结果B，而结果B又会加强A，不断循环。

说白了，复利就是一种滚雪球的生意。

打个比方，我不断写文章，拍视频，用内容去吸引越来越多的人关注，让自己的影响力越来越大，最后导致的结果一定是我赚的钱越来越多。

当我能赚到越来越多的钱，我就可以花钱招人来解决我的问题，也就是创业当老板，然后一直循环下去，这本质就是一直复利思维。也就是通过购买别人的时间，来为自己创造收益。

你看那些玩投资的，不管是个人还是机构，人家不差钱看准一个项目就使劲砸钱，只要有一个项目能做起来，前期砸进去的钱全都能回来。

其实不管是批量贩卖自己的单位时间，还是做有复利效应的事情，本质上就是让自己的时间产出更多的价值。说白了就是，别人在睡觉的时候，收入也就停止了，但是你在睡觉的时候，依然可以源源不断获得收入。

当你有一天不再依赖任何一个公司和老板，不再依靠简单的体力和技能赚钱，而是用资源赚钱，比如流量换钱、社会关系换钱，那么你就能够托上班族这个层级了。

而且利用这种商业模式赚钱的人，他们是有机会接触到各个行业的顶级圈层和资源整合者的。比如我自己做自媒体这么多年，身边围绕着很多粉丝群体，这些粉丝资源，也就相当于一个信息中枢，我就能获得和了解到很多信息差，有了信息差也就有了赚钱的机会。
