号码注册，不要直接用你的抖音号注册，因为一但你的抖音号注册以后，抖音小店将绑定你的抖音号，你就无法更改了。所以建议大家先用手机号注册，后期视情况需要，选择要绑定的抖音号。

# 二：提交资料

注册号账号以后，就开始填写资料了。这里给大家重点说一些注意事项

+   1：开通抖音小店的主题必须是个体工商户和企业，不支持个人开通。

所以如果你想要开通抖音小店的话，需要办理执照。

当然，这里友情提醒

![](bbox=[0.38, 0.4, 0.88, 0.7])

一下大家，建议大家办理个体工商户。个体工商户和企业没有什么权重之分，然而企业是需要每月代理记账的，有个代理记账的费用，而且个体工商户相对而言注册注销都简单一点，开通抖音小店的保证金也低一些，所以建议注册个体工商户。

同时提醒大家，主体类型一旦选择，认证后无法修改，请务必根据营业执照选择符号要求的主体类型。

+   2：抖音小店分普通店，专营店，专卖店，旗舰店。

关于各类型店铺的区别都在下面这张图里，我自己做的是无货源的店铺，建议各位小白也可以无货源采集模式为主，所以都建议大家开普通店铺。同时提醒大家，个体工商户只能开通普通店，开通专营店、专卖店、旗舰店必须要企业主体才可以。
