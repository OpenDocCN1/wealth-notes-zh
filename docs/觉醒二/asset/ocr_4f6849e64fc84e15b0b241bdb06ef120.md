# 三、从 0.5 到 1－提升效率

打造人才网个人号成为本地的内推专家

社群是我们的人才池，很多有价值的服务还需要一个 ip 来呈现，我们还是围绕着帮求职者找到优质的岗位来创造价值，打造区域性的内推专家。所以我们就需要做以下动作

+   1. 提供简历修改服务

本地求职者的简历是一个很大的问题，版面差没有内容，对于 hr 极其不友好，所以说我们可以提供简历修改服务，通过简历的修改一是给用户建立很好的链接，二是帮助求职者更有机会得到需要的岗位；

+   2. 提供内推服务

我们可以把一些求职者，进行分层例如：会计，女，专科，23，已婚，工作薪水，在特定岗位做过什么有价值的事情，通过进行求职者的归档，我们可以把一批人定点推荐给某个企业，这样做的好处有几点：

+   （1）企业可以在短时间获得更多的简历，方便企业找到岗位；

+   （2）求职者可以直接拿到面试机会，方便求职者更有机会拿到入职 offer

+   （3）我们也可可以给一些求职者享受一下猎头待遇，直接打电话咨询求职者这边有好的岗位，要不要过来。

+   3. 提供企业摸底服务

如果有求职者对于有些企业不了解，我们可以提供一些企业的摸底服务，这样帮助求职者更清晰的认识到自己的企业靠不靠谱，虽说给求职者创造价值这个比较重，但是可以做时间的的朋友
