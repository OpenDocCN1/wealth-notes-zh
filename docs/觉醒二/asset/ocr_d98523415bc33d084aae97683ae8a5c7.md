# **第四章：捞金实操**

同时，平台为了提高商家与达人的合作的效率，平台推出了普通计划、定向计划、专属计划、招募计划、鹊桥计划等联盟工具供商家使用。我们一般使用普通计划即可。

当我们的产品进入精选联盟以后，我们就有机会被大V推广我们的产品，然后售出产品。当然，除此之外，我们自己也可以主动去联系一些达人给我们带货。不过这个效率比较低，而且除非有优质的供应链，否则很难取得什么效果。当然，大家也可以尝试和一些小主播沟通，取得合作。

精选联盟的入驻条件：

+   1. 商家账户可正常登录使用且店铺营业状态为正常营业；
2. 商家体验分大于等于 4 分，新商家（入驻成功 60 天内的商家）无体验分时，暂不做考核；
    3. 商家店铺近 365 天内不存在违反小店《发布规避信息处理规则》、《商家违规行为管理规则》等规则而被处罚的记录；
4. 商家店铺账户实际控制人的其他小店账户，未被小店处以特定严重违规行为的处罚，未发生过严重危及交易安全的情形；
5. 商家店铺需要根据不同店铺类型上传品牌资质，并保障品牌资质真实性、合规性，链路完整性，参考《店铺类型及命名规则》

精选联盟的入驻流程：
点击商家后台 - 营销中心 - 精选联盟 - 点击立即开通。
