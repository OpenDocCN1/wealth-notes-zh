# 今天讲一个三线城市可以过千万的机会，城市招聘人才网——孙策

# 一、从 0 到 0.5 – 基础起盘：

打造人才网成为企业的招聘顾问
人才网核心三个点为平台，企业，用户，通过简历这三个纽带进行三者串联，我们需要找一个靠谱的第三方平台，通过复制本地其他招聘平台企业岗位数据，完成第一波企业岗位数据积累；

+   1. 本地打败巨头的关键：岗位数的质量与数量高于竞争对手美团一直讲究供不应求与供大于求，美团之前举了一个案例，二手车是一个供不应求的产品，只要你的二手车价廉物美，就不缺乏买家，就可以吸引来流量，只要你的车足够多，足够优质，就可以源源不断获得新流量；迁移一下，优质的岗位可以带来流量，只要自己的岗位质量与数量高于竞争对手，就可以源源不断带来流量，自己的壁垒就越来越高，巨头也没法在当地打败你。

+   2. 复搜集本地各种有效获取企业信息的渠道，并把企业信息提交到产品刚开始没有这么多数据，我们可以通过各种渠道提取企业信息，岗位信息。这里讲一个效率比较高的方式，数据爬取可以找当地大学生兼职来解决，3~4 个大学生可以用 3 天时间把全市所有企业的信息复制下来，然后再打电话邀请企业入驻，完成管理平台交接，整个过程半个月就可以完成。
