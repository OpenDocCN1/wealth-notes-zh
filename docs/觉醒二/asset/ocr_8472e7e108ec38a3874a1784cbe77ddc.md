# 第二章：牛人分享

有时候有成长的失败，比没成长的成功更有用。

与节点共成长，成为一张网

做淘宝让我结识了很多很多的圈内大佬，每一次的交流与我而言都是一次提高，这是我跟着向总做淘宝的原因，也是我当时征军阀的原因。

这期间也了解过很多淘宝之外的其它项目，但是了解项目和实操项目是两回事。

多听、多看、多学、多想，不因自己能说个大概一二的二就告诉自己也就这么回事儿，不局限自身的认知，保持好奇和专注。

有个大佬和我说过一句话：有什么问题直接问，当初我也是这样过来的。他们对我来说是淘宝路上的一个个粗壮的节点，有幸路口相逢，虽目前实力有限，无太多干货反哺，但一直心怀感恩，努力扎根，力争成为这张网中的节点之一。

所得有限，仍含满取半

这点感悟是自己因工作原因时间精力有限，开始打造团队的时候得出的。

目前手头的店铺，有的已经稳定盈利，有的仍在投入运营，每个月其实所得不多。

只取其中的一小部分，剩下的都给团队成员。我要的不是眼前的 2 万利润，我要的是以后的 20 万、200 万。

坚信眼下事业的底层逻辑，提高战略忍耐力，把它当做长期主义的事业，把成员当伙伴（当然是需要明确的规则制度），打心里希望他们能够成长进步，能够有所收获，当一个人单打独斗遇到瓶颈，需要团队协助以进一步成长的时候，先学会分钱。

写在最后

个人能力和实力实在有限，对于淘宝本身还是属于拾他人慧学为己用的阶段。

很喜欢小黑说的那句话：日盈精进，想办法让自己一直站在有多个可以选择的十字路口，我只要明天比今天的自己更好一些就可以。共勉！
