# # 一、心态篇

这个为什么要放到最前面讲呢？

因为我觉得做任何项目，首先就是要摆正自己的心态。大佬们的收益图让 人看了固然兴奋，可也不是每个人都是这样，大多数人一般也就是每月几千块 的样子。

所以，我们首先可以降低自己的期望值，给自己设定一个相对合理的目标。 在我佣金只有几百的时候，我给自己的目标是上一千；上了一千的时候，我又 把目标定在了三千，甚至是五千！

这样一步步来，会让自己有种看得见摸得着的感觉，感觉目标并不会离自 己挺远，比较有动力些。

除了佣金方面，其他一些事也会及其影响你，但是请记住，慢就是快！

为什么这么说呢？

因为知乎好物是一个长期的项目，需要你长期的积累，任何事情都不是一 蹴而就的。

中间你默默耕耘的这段时间，你可能会经历好不容易升到三级，却收到知 乎好物官方发的申请资格要达到四级的通知

你还可能会经历辛苦耕耘了好久的帐号，因违规而被永久禁言

又或是被同行针对，回答排名一落千丈而导致阅读量急剧下降等等等等

这些都是会极大的影响你的心情，处理不好的话你可能还会从此退出这个 舞台，但是请记住，慢就是快！既然阻挡不了历史的洪流，那就随着洪流前进就 是了。遇到困难时可以丧，但是不要丧太久，收拾好心情，路肯定是对的，只 是看你愿不愿意走下去罢了！

说了这么多，其实也就是摆正自己的心态。这在我看来是最重要的，没有 之一！
