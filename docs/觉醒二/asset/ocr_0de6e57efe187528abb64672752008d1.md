# 你不知道的赚钱真相

我大学毕业之前，去深圳找了一份月薪六千，敲代码的工作。

当时心里就想着，要是我毕业之后能拿到八千一个月就挺爽的，职场上再努力，每年涨薪两三千，25 岁左右收入怎么也能上万了。

事实上我在毕业之后的两年里，工作状态都还挺不错，第一年月薪六千，由于工作出了些成绩，第二年直接就涨到了月薪一万五。这个薪资涨幅我相信大部分人是做不到的。

但是在这个过程中我慢慢意识到，即使我每个月能稳定收入两万块，并且还是税前，一年不吃不喝全部存下来也才二十万出头。可实际情况是，还得除去各种花销，所以根本存不下什么钱。

直到我开始在自己的自媒体业务上发力，我才意识到，打工只是让自己进行能力和资源的积累，是一种短暂的过渡，只有自己创业才有可能实现财务自由。

一般情况下，大学毕业两三年内，基本上看不出每个人的差距有多大，这时候的同学彼此都还会经常联系，顶多是谁升职加薪，谁马上研究生毕业，又或者谁出国留学。大家的经济收入不会有特别大的差距。
