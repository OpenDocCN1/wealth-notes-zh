# 案例六：46 个点赞，净赚 980 元

再看看这个刚过 1000 粉的账号，46 个点赞净赚 980 元佣金。

这条 6 秒的带货短视频，头像一看就是网图，不露脸不讲话，光线也很一般，手指还黑乎乎的，是男是女都不确定。

46 个点赞，带出了 3000 多的销售额，佣金比例是 30%，也就是赚了 980 元。

不是个例，抖音上刚过 1000 粉就能带货的数不胜数。
