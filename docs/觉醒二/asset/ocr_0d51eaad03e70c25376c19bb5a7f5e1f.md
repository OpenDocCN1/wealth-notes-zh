# 教人识字赚了 30 万!

今天刷到一个抖音账号, 居然在教成年人识字。

？？？

我翻了一下他的视频, 做得非常的简单, 就是拿一支笔带着观众读汉字, 读拼音。

而且这个博主做了一门成人识字课, 卖 99 元, 目前已经 3688 人购买。

![](bbox=[0.23, 0.55, 0.76, 0.64])

可能会说, 卧槽, 这他妈也行。

不光是你们, 我刚看到的时候也是一脸的懵逼, 没看到她卖这么多课, 你都不知道中国现在还有这么多的文盲。

关键是她自己普通话都说不明白你知道吗, 但是那又怎样, 并不妨碍人家能赚到钱。

现在各行各业的培训都卷得不行, 知识付费的需求千奇百怪, 这种完全打下沉市场人群的培训简直是绝了。

知识付费这个市场, 有太多需求是我们想不到的。

但是你想不到并不证明这玩意儿它不存在啊, 就好比我今天不写这篇文章, 你也不知道啊。
