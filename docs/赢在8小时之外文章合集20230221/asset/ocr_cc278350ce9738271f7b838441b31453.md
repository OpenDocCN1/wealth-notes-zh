# 为什么穷人，都喜欢参加饭局？

原创   赢在 8 小时之外   2020-01-19 22:18:41

大学刚毕业那两年，我参加的饭局比较多，一方面是国企的同事领导聚会，另一方面是老同学聚会，还有就是回家过年时亲戚的聚会。

当时我还是个一无所有的打工狗，也热衷于结交人脉，所以特别喜欢参加各种饭局，还到处去学习饭桌上的礼仪、社交技巧等等，对于酒桌上能说出一套套祝酒词的同学更是佩服的五体投地。

在饭局上，我见过位高权重的局长，在那里噼着吐沫星子侃侃而谈，叙说自己的光辉岁月，给我们新来的员工指导发展方向；

见过同学信誓旦旦撇着大嘴的承诺，“有事你就说话，咱俩哥们肯定当亲兄弟处”；

也见过德高望重的亲戚，甩开腮帮子边吃肘子边给我谆谆教诲，教我各种“做人”的道理……

总之，每个饭局都特别有人情味。

可是呢，我依然很穷。

而且碰到困难时，我稍微透露一点，这些人都躲得很远很远。

后来我终于脱离了这些有人情味的环境，一个人来到了北京打拼。

后来有了自己的团队，事业总算是有了方向，至少不至于挨饿受穷。

有一次在班级群里，有好事的同学在讨论，我们大学毕业 5 年后谁的收入最高，然后他们就把我排到了第二名……

本来到北京这几年，没有几个同学联系过我，自从“排名”事件之后，有过好几个同学说要请我吃饭，还有两个来北京找过我“叙旧”。

还有个在微信上直接向我借钱，说想把车贷还清，就是当年祝酒词说的特别溜的那个同学……

后来我就想，在中国式人际关系里，穷才是最 大的罪恶。

想要好的人际关系，自己变富就行了，不用学习各种乱七八糟的技巧和礼仪，屁用没有。

只要你穷，在任何场合你都不会收到好的脸色，不用说同事和同学，就算是亲戚、父母、子女、配偶，也不会给你好脸色。
