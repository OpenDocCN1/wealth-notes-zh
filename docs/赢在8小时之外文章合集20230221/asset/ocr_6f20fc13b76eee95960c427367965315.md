# ③ 写作能提升专注力。

经常写东西的朋友应该清楚，我们在写作时，有一点声音或者琐事的干扰都不行，必须精力全身心集中，否则什么都写不出来。

专注力这个东西，是可以慢慢培养的，而且专注力也是至关重要的。

无论你是写作、研发还是创作，只要你想做非常有价值的事情，一定需要极强的专注力。而专注力正是现代人所缺失的。

因为手机的诱惑太大了，有斗音、有游戏、有各种社交软件，很多人离开手机 30 分钟就受不了了。

# ④ 写作可以扩大个人的影响力。

其实不光是写作，录制音频、录制短视频、直播都可以。

只要你一直在输出内容，一直在分享经验，一直在传播价值，那么你的影响力会越来越大。

比如，你可以跟大家分享：你是怎么样过上更好生活的，怎么管理自己情绪的，怎么教育自己孩子的，怎么经营自己婚姻的，怎么开创自己事业的。

当然，你也可以分享自己对世界的见解、对社会的见解、对人性的见解。

只要你坚持输出，那么你就能吸引很多认可你的、跟你同频的人，不出家门就能链接社会上的各种资源，让你有更多新的可能性。
