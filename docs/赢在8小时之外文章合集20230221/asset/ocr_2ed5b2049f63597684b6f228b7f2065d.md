# 创业者一定要有匪气

原创   赢在 8 小时之外   2022-02-04 12:00:00

之前群里有人问了我一个问题，说他要上台演讲了，怎么样才能克服紧张情绪呢？

我说，你的能量场如果比台下的人高，你就不会紧张，你的能量场如果比台下的人低，你就会胆怯，这个是客观存在的，不是你学一些技巧就能克服的。

那么怎样衡量能量场高低呢？用收入来衡量就行了。

如果你月收入是 8 万，而台下大部分人的月收入是 8 千，那么你的能量场一定是比他们强的。

如果细究的话，高收入背后隐藏的是你的先进的行业经验，丰富的人生阅历，这些足以让你在台上熠熠生辉，强烈地感染到台下的观众。

这时候，你说什么都是对的，你想怎么收钱，他们就怎么交钱。

反之，如果你只是个实习生，拿两三千的工资，是个行业小白，那么你在台上肯定会心虚。

即使你学了很多心理学知识和演讲技巧，在台上能侃侃其谈，但这本身是没有意义的。你的气场无法感染到台下的观众，当然你也无法从他们身上吸取能量（钱）。

最后你会发现，气场这个东西，不是营造出来的，而是客观存在的。

收入高的人气场就强，开口发言时，其他人都会安安静静地听，而且让他们掏钱的时候，他们就会乖乖掏钱，无法抵抗。

而且，能成事的人，本就带着骄气和匪气，他们不喜欢跟别人平等对话，而喜欢在气场上影响别人，碾压别人。

要知道，在一个项目的发展初期和中期，创业者会面对各式各样的人，各种眼花缭乱的事。

而且越是离钱近的地方就越肮脏，如果你身上没有那股匪气，没有霹雳手段，那么你对内无法服众，对外根本无法去应对那些尔虞我诈。

有些老板就很蠢，他相信情商，相信人人平等，相信换位思考。

你要知道，大部分人是没法平等沟通的（因为智商、见识、收入差距太大），你需要做的就是引领他们，影响他们。

比如，我就不喜欢平等对话，我在微信群里就要当群主，而且一定是收费的。我不敢保证我说的每一句话都是对的，但是我也不会平等地跟你沟通和辩论对错。
