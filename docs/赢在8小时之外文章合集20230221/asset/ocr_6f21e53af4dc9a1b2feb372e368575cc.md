# 浅尝辄止的艺术

原创 赢在 8 小时之外 2023-01-30 12:33:27

之前我在

我在 B 站一个月赚了 1500 元

这篇文章里讲了关于 B 站的一些赚钱思路，我并不是说大家都可以靠 B 站养活自己，而是说可以多一个选择，多一条收入途径。

其实类似与 B 站的小众平台有很多，知乎、小红书都属于这种类型的。

你去大街上随机采访路人，估计有 50% 的人手机里根本没有安装这些 APP。

但呢，如果去这些平台里深挖，你会发现确实有很大大 V 在上面制作内容、引流、变现。

如果你也是做自媒体的，我建议各个平台都要玩玩，至少知道它们大概的运行逻辑，哪怕是浅尝辄止也行。

就拿 B 站举例子，如果你想玩好 B 站的话，你得学会视频剪辑吧？入门的剪辑软件是剪映，进阶的剪辑软件是 Pr 和 Ae。

无论是哪个软件，都会让你对“视频剪辑”这个技能有个最基础的认识。

有了这些基础的认识之后，有什么用呢？

下次你再看到一些视频内容时，你就多了一个视角：除了以消费者的角度看视频之外，你还能从制作者的角度去看这个视频。

视角多了之后，你的思维自然就会更丰富，那么创造力也会更强，赚钱也会更容易。

另外，很多逻辑都是相通的。

假设你搞了一个月的 B 站，虽然没赚到多少钱，但是你对“视频剪辑”这件事有了最基本的认知。而且你对于视频平台的审核逻辑、上热门<|start|>则、粉丝增长趋势、变现途径这些都有一定的认知。

而新媒体平台的这些逻辑和规则都是相通的，你把这套逻辑应用到小红书、抖音、知乎上，你会发现也都是换汤不换药，是通用的。
