# 打工人的分水岭

原创 赢在 8 小时之外 2022-06-08 12:00:18

我平时很少聊打工人的话题，但是最近咨询这类问题的人挺多，于是我打算专门写一篇文章，聊一下这个话题。

对于打工者来说，工资是高是低，是否有社保，在大城市能否买车买房，这些都不是最核心的问题。

最核心的问题，还是角色的转变。

大部分打工者都是棋子的角色，任人挑选，任人摆布。公司制定什么文化和制度，你必须得遵守。

公司给你开多少钱，你就得接受。

哪怕你是 50 万年薪的总监，也是一个随时可以替换的工具人。

只要你是“工具人”的角色，那么无论你工资多高，是否有车有房，你的人生始终是一种“被动接受”状态，非常不爽。

到了中年之后，还有被裁员的危机。

当然，疫情的出现，把很多打工人的裁员危机给提前了，才 35 岁，就没有大公司给你 offer 了，而愿意要你的那些公司，都是工资较低的垃圾岗位。

所以，如果你想逆转这个局面，只有一个办法：变被动为主动。

主动的打工者，已经不是简单的“棋子”角色了，他们已经有了议价权，有了主动权，成为了一名“棋手”。

具体途径主要有两条：

# ① 吃着锅里的，看着碗里的。

尤其是大公司，上市公司，这种现象非常常见。

聪明人都知道，自己是来大公司赚钱的，或者是来镀金的。干一段时间之后，自己早晚是要跳走的。

凡是认同公司文化的，把公司当成家的，都是大傻狗。

因为上市公司一切都要看业绩，看市场，看投资人，而不是讲感情。
