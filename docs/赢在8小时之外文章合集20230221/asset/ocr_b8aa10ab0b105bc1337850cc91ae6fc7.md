# 征服与被征服，才是人际关系的本质

原创  赢在 8 小时之外  2020-06-16 14:09:44

我在公众号里面写的东西，会招来两种人。

一种是，觉得我写的東西太對了，一針見血，說出了他們的心聲。

另一種是，覺得我這個人三觀太歪了，而且冷血無情。

他們經常反駁我的理由就是，人與人之間是平等的，不存在貴賤之分，也不存在階級的劃分，這都什麼年代了。

男女是平等的，老板與員工是平等的，窮人與富人是平等的，我們都一樣！

但是呢，我還真不認為“平等的關係”能夠長久。只有征服與被征服的關係，才是人際關係的真相。

比如男女之間，開始可能是像愛情一樣的衝動，但是呢，時間長了，肯定不是靠這些虛無縹緲的東西。

長久的關係能維持，說明他們之間就是征服與被征服的關係。可能是靠財力征服，也可能是靠才華征服。

總之呢，當你理解了這個，你就懂了。世界上的大部分人都是賤人，強的一方必須讓弱的一方崇拜，臣服。

如果強的一方，傻乎乎地總想平等相處，不N役另一方，對方大概率會忘乎所以，下一步就是，雙方的關係會破裂，然後就是分道揚鑣。

大型公司的老板與員工的關係也是如此。老板必須要征服員工，在“勢”上一直壓制住員工。

如果你不相信，對於弱者或者窮鬼，你一旦想要跟他們談平等，他們會迅速騎在你脖子上拉屎，把一切都搞砸。

等到你受不了了，把他們趕跑之後，他們就會尋找下一個能N役自己的強者，然後這種關係才能持久，才能平衡。

我在 VIP 群里，也經常跟大家讲，在互聯網上如何对待粉丝、好友、客户以及潜在合作者。

核心就是一种强者的姿态。举一个小例子，你如果碰到一个新客户，充当客服的角色，在聊天、报价的过程中，你一旦想的是“平等交流”，而不是“征服对方”，那么你就等着失去这个客户吧。
