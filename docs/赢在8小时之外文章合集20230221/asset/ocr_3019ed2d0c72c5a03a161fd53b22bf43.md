# 什么是迷信？什么是心理学？

人的精神世界是很难说清楚的。

所以碰到阴婚或者其他所谓的迷信行为，只要不触犯法律，我都是特别理解的。

一方面，我们没有经历过当事人的痛苦，另一方面，老一代人跟我们这一代人接受的教育存在着巨大的鸿沟。

我以前经常报团出国旅行，碰到东南亚的团，经常有老人在吃自助餐的时候抢大虾，而且是一窝蜂的抢，有时候互相还能够打起来。

其实，自助餐的大虾是无限量供应的，没必要抢，但是你跟他们说也没用，他们还是要抢的。

大家应该也看到过这类新闻，确实是客观存在的。

原因是什么？他们在年轻时都饿怕了，穷怕了。饿到什么程度？穷到什么程度？我们根本想象不到。

电影《1942》讲的是河南大饥荒，全家人逃难，连喝一口米汤都是奢侈品，每个人都饿的皮包骨，走路都打晃。但是女儿星星还是把心爱的小猫带在身边，还给它喂饭吃。

挺着大肚子的嫂子看到了，就嘲讽了一句：现在连人都吃不上饭，你还喂猫？

星星回答：大不了我饿着，把我那份粮食给猫吃了。

可见她爱猫心切。

有一天她发现猫不见了，老父亲伤心地对她说：妮儿，爹对不起你啊，我把你心爱的猫给炖了，因为你嫂子生产需要补充营养，否则连她带孩子都活不了。

星星听了之后说道：爹，我也要喝猫汤。因为此时她也饿慌了，饥饿战胜了其他一切所谓的道德和理智。

直到今天，我们仍然没有实现蛋白质自由，比如很多农村地区还保证不了牛肉、大虾、牛奶的供应，因为大部分人吃不起，偶尔改善一下生活的时候才舍得买一点吃。

仓廪实而知礼节，衣食足而知荣辱。等到经济水平到了一定程度，文明自然就跟上来了，所有的陋习都会逐渐消失的。
