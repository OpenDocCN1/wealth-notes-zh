# ② 多听富人的建议

富人，就是收入高、手里现金多的人。

他们推荐东西、他们提的建议，一般都比较靠谱，比较良心。

“穷生奸计富长良心”，这句话绝对是真理。

我虽然不是富人，但是我在朋友圈也经常推荐东西，很多人从我的推荐下都去购买了。

他们之所以信任我，一方面是我的见识还算广，吃过见过玩过，满世界也跑过。

另一方面，我从来不挂链接，也不推荐具体的卖家，我都是推荐大家去实体店或者官网去购买。

（我不拿提成、没有任何私心）

总之，我今天想表达的就是两点：

+   ① 穷鬼朋友推荐的东西，不要随意听信。信任是没法转嫁的，尤其是穷人的信任。

+   ② 多接触不坑人的产品和服务（贵的才不坑人），多听有成果的人说的话。
