# 金钱是对冒险者的最高奖赏

原创  赢在 8 小时之外  2022-01-28 12:00:00

之前我在

能成事的人，做什么都能成

这篇文章里提到过一个观点：一个人只有先做成过一件事之后，才能找到感觉，找到信心，才能引出后面的一系列成功。小成功是大成功之母。

不过话又说回来，想要独立做成一件事，真的很不容易。

好在呢，你可以先参与进来。

什么都不参与的人，就是不愿意冒任何风险的人，这样的话你就无法获得一手的体验，那么你以后做的任何决定都是不客观的，甚至是危险的。

举个例子，你没有买过车，没有几万公里的驾龄，你对于汽车根本没有基本的认识，即使你看再多的自媒体讲解也是白搭。

如果有条件，多驾驶不同品牌、不同排量、不同动力来源（油、电、混动）的汽车就更好了，体验得越多，你就越能找到属于自己的交通工具。

有的人连驾照都没有，整天嚷奔驰 1.5T 的排量，喷奥迪就是换了壳子的大众，但是等他真的开上车之后，他会发现，在大城市市区开车，任何高配置都是没有意义的，好看和品牌才是最重要的。

当然，如果他生活在路况好的城市，或者经常跑长途、自驾，他可能又会得出另外一个观点：什么豪华品牌、一线品牌，都是虚的。动力强、提速快才是真的香。

再比如炒股、买基金这件事，如果你从来没有买过，那么你就不要到处去学习、到处跟别人讨论，因为你所有关于理财的认知都只是停留在纸面上而已。

你去跟老玩家讨论，人家也不会搭理你。

为什么会这样？因为你看到的所有教程、教材，里面都没有提到过“一天亏损几万元”会对方的心态造成多大的打击，甚至在生理上对你的健康都会造成伤害。

具体会造成什么样的打击和伤害？你只有经历过之后，才会知道。但如果你不参与进来，你永远也不会知道那是一种什么感觉。
