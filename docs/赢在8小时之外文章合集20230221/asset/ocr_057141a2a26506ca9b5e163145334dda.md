# 我不会再过，以前的生活了

晚上写东西时，手欠，打开电视看了一眼春 wan，结果不出所料，又在那里煽情，ge 顶 xx，xxx 和 xxx x。

我抓紧扇了自己一巴掌，他妈的，你自己当初深爱 xxx 那套文化时，自己混的是什么 B 样忘了吗？

我最近一直在思考，也在观察，我以前是个傻屌丝时，我因为什么而感动，因为什么而快乐；现在我对自己的生命有掌控感了，我又因为什么而感动，因为什么而快乐。

以前，所有的感动，都是来自新闻媒体和出版物，是它们在引导着我该对什么感动、什么时候感动。

比如电视剧，电影，小说，X 闻 L 播。

这些东西，都在教我该如何热爱工作，如何孝敬父母，如何珍惜爱情，如何热爱 wei 大的 xx 和 xxx。

但是现在想想，这些都是毒害我的毒瘤，我如果没有及时清醒过来，我这辈子就会一直生活在一种 1 ao 笼里，我会一直停留在弱 B 傻屌丝阶段，一切美好的东西都得向别人乞求，到死都是一个满嘴负能量的老屌丝。

从 2016 年我彻底辞掉打工者角色之后，我才开始慢慢接受强势文化的洗礼，简单来说就是，在任何环境里，或者人际关系中，要有绝对的实力，绝对的主导权，要有势差。

尤其是男性老板们，如果一个圈子，或者一段人际关系，你不能主导，那么就不要沾。否则，你的自我会被一点点吞噬掉，就成了一个没有灵魂的人，你的事业也会一落千丈，一切美好的东西都会离你远去。

永远要想着提高自己的实力，而不是想着如何取悦别人，如何感动别人，如何学一些手段去骗别人。

我认识很多老板，他们在春节这几天都是工作的，不休息。

我自己也是如此。从 2017 年实现了时间自由之后，我就再也不过春节了，因为都时间自由了，想什么时候跟家人团聚都可以，这时候还上高速公路跟打工者去挤路，那不是吃饱了撑的吗。

至于春 wan、过年气氛这些，早就不在意了，早就不靠节日给我带来什么幸福感了，我现在的幸福感都是自己创造的。
