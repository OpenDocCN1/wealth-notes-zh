# 金钱能买到真爱吗？

原创 赢在 8 小时之外 2021-06-11 13:00:00

无论在现实生活中，还是在网络上，我经常能看到一些穷人在教育富人，大概有这么几种言论：

①别看你的老婆又年轻又漂亮，现在对你百依百顺，等你破产了试试？看她还跟不跟你！

②兄弟，要低调，你现在属于德不配位，小心你的钱财！

③兄弟，做人要厚道，不要有了点钱就忘了本了，往上数三代，谁不是穷人？

这些言论，我给翻译成通俗的语言，是这样的：

①漂亮女人只有跟着我们穷人才是真爱，她们选择跟着你们这种有钱人，是瞎了眼了。另外，她们都是奔着你们钱财去的，你还以为是真爱，幼稚！

我的老婆虽然丑得让人难以下口，还经常打我，骂我是窝囊废，但我们绝对是真爱！这种真爱你是 Hospitality 一辈子也体会不到了，悲哀！

②人的财富一旦多于某个值（比如 100 万），那么他的钱财就都是非法获得的，这个世界上没有任何合法的生意能赚到一百萬！

只要你的赚钱模式超过了我理解的范围，你就危险了，你必须每天修炼自己的道德，才能镇住这些钱财。

比如我看 L 嘉诚、M 云、L 彦宏这些企业家，虽然有千亿身价，但是他们德行不过关，我抬指一算，用不了 50 年，这些人的财富就会烟消云散！他们也会身陷囹圄！

我自己虽然月薪 5000 元，但是我德行高尚，我从来不坑害消费者，也不坑害未成年人！我骄傲！

③咱们向数三代，都是农民出身，所以咱们的财富也应该平分！凭什么你的身价是我的百倍？这不公平！

祖上穷、世代穷，祖上富、世代富，这样才公平！

……

其实，我想说的是，富人有两个点，被穷鬼严重低估了。

这两个点就是“看人的眼光”和“看钱的眼光”。
