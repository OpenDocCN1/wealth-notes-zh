# 2021-VIP (176)

这是我最近两年喜欢的葫芦

我跟大家说说原因。因为以前我也不是理解玩葫芦、玩手串的人。觉得这些人是吃饱了撑的，浪费大钱。

后来我发现，文玩、机械表、珠峰、阿拉善这些问题，连接的都是企业家。

包场飙士滑雪之类的运动

跟他们交流越多，可以聊的东西就越多。越往上的人是越稀少的，越有钱的人越孤独。

而且，你要清楚一个道理：越有钱的人越聪明。他们玩的东西，一定是特别有意思的，甚至是世俗人永远也体验不到的。

比如，总有愿意加价买稀奇古怪的的人。但是你有没有想过，为什么人家能配到100万买辆面包车，你却吃着一块干冰、营养丰富的面包...？

# 2021-VIP (176)

手串、葫芦这些东西，盘的越久，从你手上流过去的时间就越多，它就会越亮，也可以说你在不经意间给它赋予能量，看着它一天天、一年年的变化好。

这种感受，没玩过的人肯定不会懂

人活一生子不就是体验各种各样的感受吗

去高海拔地区住一段时间，也是一种感受，而且是前所未有的感受

我说的这些东西，不是扯淡的。它们跟赚钱、跟幸福，有很大相关性。

见识越多、体验感受越多的人，包容性越强，偏见就越少，而能俯视众人。收个钱，收个人不是易如反掌吗？
