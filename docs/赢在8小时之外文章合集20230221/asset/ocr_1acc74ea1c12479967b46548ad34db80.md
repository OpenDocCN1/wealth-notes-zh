# 治疗懒惰的最好方法

原创 赢在 8 小时之外 2022-05-25 12:00:52

有人咨询我：U君，我发现自己什么都想做，但最终什么都没做成。越清闲反而越想拖延，有没有什么好的方法？

我说：99%的人都是这种状态，否则世界上就不会有这么多普通人了。

那么该如何解决这个问题呢？

见仁见智，没有标准答案，因为这个问题太大了。

但是呢，今天我跟大家分享一个思路，一个我受益匪浅的习惯。

如果你认可的话，可以去实践一下，看看能不能让自己变得不普通，变得更优秀。

在我看来，治疗懒惰的最好方法，主要有两种。

第一种是运用科学的奖惩机制，克服我们人性中的惰性。

“时间管理”是伪命题

这篇文章里已经写得很清楚了。

第二种就是适度的贪婪，这一点很多人意识不到。

很多得过且过之人之所以做事情毫无动力，能拖延就拖延，是因为他们赚到的钱根本没有多少是花在自己身上的，也没有“我要体验更好人生”的欲望。

大多数人过的是这样的一种生活：

一个月赚 8 千元，其中有 5 千元是用来还房贷和车贷的，剩下的 3 千元，还要参加穷鬼同学的婚礼，还要参加穷鬼同事的聚会……

好不容易存下了一万块钱，苹果公司又出最新款的 iPhone 了，于是你又去跟风购买，然后又回归到捉襟见肘的生活。

我知道，有人肯定会说：我能力有限，只能赚这么多，但是我不能不买房不买车吧，同学婚礼我也不能不参加吧。
