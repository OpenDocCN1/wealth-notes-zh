# 如何避免成为工具人

原创　赢在 8 小时之外　2020-12-26 16:10:05

当年我在国企工作的第一家单位，有个关系比较不错的同事，跟我差不多，农村出身，没车没房。

但是我的收入比他高很多，当时我在网上赚的钱已经是本职工作的好几倍了。

因为我在很早的时候就认识到了：普通出身的男人，必须得多赚钱，其他的比如长得好、铁饭碗、能力强、技术好、文笔好、素质高、处事圆滑、会献殷勤，这些都是锦上添花的。

你没钱的时候，这些技能屁用都没有。

但是我跟同龄人说这些他们都是不屑一顾的。

所以，很多事情我也比他看的透彻，他算是一个技术直男吧。

他在单位跟一个女同事关系比较不错，女的家里是本地市区的，长相 4 分吧。他自己长得还可以，7 分左右。

他们平时的关系很微妙，比普通朋友近一点，稍微有一点暧昧，但没有确定关系。

在大概三年的时间里，他帮女方干了很多活，事业上也帮了很多忙（我同事技术比较厉害），几乎是鞍前马下，随叫随到。

三年之后的某一天，女方发朋友圈说订婚了，而且还发出了两家人一起吃饭的合影，未婚夫父母和女方的父母都是单位的双职工。

我同学听了之后，觉得五雷轰顶，立刻就跑去了女方家里，这时候女方一家和未婚夫一家都在。

他就质问那个女人，为什么这三年一直利用自己，到头来却跟别人迅速订婚了？

女人的父亲知道了这件事的来龙去脉，也说了自己女儿，想拒绝别人就早点说，你看人家大老远的跑来多不容易。

然后就安慰我的同事几句，大概意思就是，你们也没有确定关系，我女儿也不算是脚踏两只船吧。我看你很优秀，以后肯定会有个好归宿的。

然后这个事就过去了。

我同事这个心结一直打不开。

有一次他来北京找我，跟我说了这件事的详细经过。我就跟他说，就当是教训吧，以后不要再给别人当工具人就是了。
