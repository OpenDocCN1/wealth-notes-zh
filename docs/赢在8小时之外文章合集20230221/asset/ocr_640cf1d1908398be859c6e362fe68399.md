结果就是，这个男人和这个女人，都在互相抱怨对方，都觉得亏了。《天道》里的丁元英就说过类似的话：接受孝道文化的家庭，只要有矛盾发生，父母就会觉得孩子不孝，而孩子会被耻辱压的抬不起头，双方心里都很苦。

其实底层社会的男人和女人也是如此，糟糕的家庭环境，再加上自己没有独立思考能力，也没有规划自己成长的能力，没有足够的实力来摆脱家长的控制，结局就是，自己的婚姻也很幸幸福。

那么怎么样才能建立以上的这些能力呢？

我从女人和男人的角度分别跟大家聊一下。

# ①被捧杀的女人。

在底层社会，很多女孩子都在经历着捧杀。

几乎所有的网络信息都在告诉你，让你委屈的男生都是因为不成熟，男人靠不住等等。

可这些把男人低等化的信息，目的只有一个，那就是获取更多的传播和浏览量，然后多接一些广告。

一旦你傻乎乎地接受了这种设定，马上变得自傲而不自知。

如果你身边没有人给你忠告，而是一味地捧着你，捧到你得意忘形的时候，你就会丧失了独立思考能力，很容易在重大事情上做出错误的判断和选择。

我们每个人都喜欢听好话，都喜欢优越感。但是下次你再听到别人的追捧时，一定要问问自己配不配。

# ②被嫌弃的男人。

在 Z 国，大概有 90%的财富和权力掌握在男人手里。

但是呢，这些男人都是领导、老板或者投资人，肯定不是打工者阶层。

打工者男性，比同等级的女性要更加没有地位，无论从动物属性还是社会属性上来说都是如此。

我之前说过很多次，男人，千万别相信男女平等，也千万别总听“男人比女人多几千万”这种言论。

有一个真相就是：100%的女性的目光都在前 20%的男性上。

也就是说，80%的男性是被嫌弃的，很难会被同等级的女性青睐。
