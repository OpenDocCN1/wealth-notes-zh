# 资源敏感型人格

原创 赢在 8 小时之外 2021-12-09 12:48:40

我总结了一下粉丝私信我的各种问题，这些问题的核心，总结起来无非就是三种：钱少、事多、不自由。

“钱少”这个很好理解，自己出身平平，家里提供不了实质性的帮助，而自己又走上了传统的打工者路线，一直处于社会底层。

“事多”的本质也是因为钱少，无论在职场上，情场上，碰到的全是烂人烂事，随便一个阿猫阿狗都不把你放在眼里，因为都知道你根本没有退路。

“不自由”不仅仅是指时间不自由和财务不自由，更重要的是自己选择很少。这份工作虽然干的不开心，还经常受气，但是我一旦辞了之后还真的不好找家了。

更要命的是，你的情绪也会变得不自由，就是你得不断矮化自己的人格，为他人提供情绪价值。

公司聚餐时，得给领导敬酒吧，得看他的脸色行事吧。好不容易找了个对象，还得供着点吧，要不然你本来就是穷鬼/丑鬼，再不会提供情绪价值，那对象早跑了。

长期下来，你的气场将会受到严重的压抑，你所有的潜能、所有的灵光都无法显现。

选择将会越来越少，身边的处境将会越来越糟糕。

但是，生活总是需要娱乐，需要调剂，于是你就去参加聚会、玩游戏、看电影、刷斗音，获取短暂的快乐。

回到现实之后还得继续面对糍粑的生活。

如果你想改变这种现状，想要觉醒，我给你的建议就是：可以培养一下自己的“资源敏感”能力。

举个例子，你再去参加聚会，不是简单地喝酒聊天搂人，而是把眼睛盯在那些能给你带去资源的人身上，多跟他们交流，多加他们的微信。

如果你恰好也做一些兼职，想想哪些人可能会在你这里买单，你就多加这类好友。

再比如，你玩游戏时，或者看游戏直播时，看看人家是怎样组织代练群的，他们是怎么倒卖装备的，怎么通过直播获利的。

再比如，你去看电影，别傻乎乎地又哭又笑，你要想怎么样才能写一篇影评，来吸引粉丝，来变现。如果我花 50 块钱看一场电影，如果不能收回 500 元的回报，我会觉得亏大了，因为我还浪费了两个小时的时间。
