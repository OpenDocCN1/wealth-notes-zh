# 商业世界，是刀刀见血的

原创　　躺在 8 小时之外　　2021-02-13 15:05:31

昨天在写作群，有个朋友说了这么一种情况，就是他也仿照我写的东西，去写公众号，然后分享到朋友圈。

结果就是，他的朋友们都说他三观不正，还要友尽。

我就跟大家说，没事不要跟别人分享自己的三观，这样容易没有朋友。跟亲爹亲妈、跟自己枕边的人都不要分享。

比如有些男老板，如果你的老婆是个上班族，你还非要跟她讲道理，讲三观，那么恭喜你，你练姓生活都没有了。

只有打工者、中产这些矫情鬼整天在那里讲三观，讲心灵沟通。

我们老板只想做个没有灵魂的赚钱机器而已。

什么是灵魂伴侣呢？我的理解，能一起赚钱的合作伙伴就是灵魂伴侣。

其他的，比如父母、伴侣、子女，大概率都是不能分享三观、不能灵魂沟通的。

当你是个打工者的时候，你很容易找到三观契合的人，因为你们都是在传统教育和媒体舆论的裹挟下，形成的三观，当然一致了。

如果你一路披荆斩棘，成了孤家寡人的老板，哪怕是个自由职业者，你也会发现，想找个能深度沟通的人，是多么困难。

我之所以做 VIP 交流群，一方面是想帮助更多人成长，摆脱打工者思维和弱势文化的影响，另一方面我也需要跟聊得来的人沟通，现实生活中这样的人太难找了。

为什么老板跟打工者很难做朋友呢？因为老板都是一路拼杀过来的，最困难的低谷也都是自己一个人熬过来的。见过人性的卑劣，也见识过社会的现实。

他们都知道，低谷的时候，没有人会给你雪中送炭；等到事业有成了，所有的人都来给你锦上添花。

这时候你又跟我扯三观一致、灵魂契合，你他吗忽悠鬼呢？

如果一个人自己熬过了人生的低谷，那么他起来之后，一定会六亲不认。
