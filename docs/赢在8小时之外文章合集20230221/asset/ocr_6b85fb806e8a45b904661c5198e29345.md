# 有钱有闲，就真的幸福吗？

原创　赢在 8 小时之外　2021-05-18 11:30:35

今天刷朋友圈，我看到一个微信好友发了一些关于 iPhone13 的预测。

2020 年春节前几天，疫情刚刚爆发，我当时在韩国过的新年，北京飞济州的飞机上认识的他，因为头等舱登机早，闲着没事做，我看邻座的他在刷知乎，就跟他打招呼，说我自己也玩知乎。

聊天过程中我得知，他是 93 年的，做手机测评类的自媒体，后来我发现他不仅在知乎上粉丝很多，在 B 站和 YouTube 上也有十几万粉丝，阅读量都很不错。

公众号和抖音这些平台只是机械地同步过去，阅读量不高。
