# 《美国丽人》

原创    赢在 8 小时之外    2021-11-17 15:27:04

有些电影我隔几年就要看一遍，而且时看时新。

因为随着年龄和阅历的增长，以及心绪的变化，总是从电影中读出不一样的东西。

《美国丽人》这部电影我看过四五遍了，最近又看一遍，还是觉得特别精彩，它在 2000 年斩获了很多奥斯卡奖项。

电影的主线是一对中年夫妻，他们彼此互相嫌弃，妻子 Carolyn 跟一个行业大佬好上了，丈夫 Lester 又被正在上高中的女儿的同学 Angela 迷住，而且这个女同学又是个不折不扣的绿茶婊，特别风骚，主动勾引他。

Angela 不仅勾引同学的爸爸，还经常跟同学到处吹嘘自己的风流韵事，以及自己如何开放、如何有魅力、床上功夫如何好。

另一个家庭组合也是个奇葩，妻子精神有问题，儿子是一个变态，最喜欢偷拍别人，兼职卖大麻。

丈夫是一名退役上校，性格强硬正派，而且是直男癌。这个直男癌不是今天大家理解的直男癌，而是真的直男癌，就是看不惯那些同性恋。

而且只要看到有同性伴侣在大街上秀恩爱，他就会一脸鄙视地对儿子说：你看这帮死基佬，真他妈恶心，他们难道一点羞耻心都没有吗？

但是这一切都是表象。

实际上，风骚的 Angela 其实还是个处女，她到处吹嘘自己的魅力和风流韵事，可能就是生怕别人觉得自己没有魅力（当然也可能是其他的原因，这个剧中没有说明）。

而那个恐同的上校，其实本身就是个同性恋，而且自己压抑了多年。他到处辱骂、贬低那些同性恋，可能就是怕别人识破他的同性恋身份。

至于他那个“变态”的儿子，其实是个文艺青年，他偷拍的东西完全不是外人理解的那种为了私欲，而是为了诗人、哲学家般的思考人生。

这些都是中产家庭，都住着自己的大 house，
开着气派的小汽车，表面上看富裕而又温馨，但真实情况呢，家家有本难念的经。

每个人又都有自己的恐惧和压抑。恐惧着外界的评判，压抑着自己的真实需求。
