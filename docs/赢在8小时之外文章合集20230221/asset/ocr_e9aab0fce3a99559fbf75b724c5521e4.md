# 第7天，快结束了

原创  嬴在8小时之外  2022-12-25 11:47:21

今天是周日，从昨天开始，我的身体状态和精神状态就好了很多。

我是周一晚上开始发烧的，现在回顺一下，整个过程大概也就持续了5天的时间。

先说一下我的情况：一针疫苗都没有打过，身体素质还算可以，每年感冒1次左右，也不用吃药，两三天时间就好了。

我没去做核酸和抗原检测，不过几乎可以断定我是阳了，一方面是因为我身边接触过的人都阳了，另一方面是因为这次发烧跟以前的发烧不是一个感觉。

以前的发烧基本上都是因为感冒引起的，先出现感冒症状再发烧，而这次是先发烧，后出现感冒症状。

周一到周三，这3天是发烧期，37-39℃反反复复，吃布洛芬缓释胶囊就能把温度降下去，很管用。

期间浑身酸痛，有时候喉咙疼，有时候头疼，但是都不严重，能正常吃饭、睡觉。

周四我的头开始“跳痛”，就是头部左右两方一跳一跳疼，钻心疼，那种疼痛感受仅次于牙疼。

吃布洛芬一点都没母有（布洛芬的主要功效之一就是止痛）。

我上网查了一下，很多朋友也都有这种症状。

我每天都是早上四五点钟被疼痛醒，然后到中午自然就好了。

后来我上网查各种资料、各种专家的视频，众说纷纭。

其中有一个叫“钮博士聊疼痛”的人，是某医院的疼痛科主任，他说了一个办法：找到跳痛的部位，那里应该有硬结，有个包（可能不明显），然后用手指轻轻按压即可止痛。

我试了一下，超級管用，按得时候能听见那个包里面有咔哧咔哧的声音（按压其他部位就没有这个响声），头当时就不疼了，按五分钟之后，症状就减轻了很多。

到了今天，我只剩下轻度感冒的症状了，轻微鼻塞，吃东西没有太多味道（但是我的味觉并没有消失）。

另外，我自始至终都没有出现过喉咙痛的症状，也没有什么咳嗽。
