# 如何在 35 岁之前退休？

原创   赢在 8 小时之外   2022-02-21 12:00:00

疫情之前，每年春节前后我都会在国外待十几天，东南亚比较多，有时候也去欧洲或者日韩。

我碰到过形形色色的国人，有青年假旅行的，有带着父母出来玩的，有跟爱人度蜜月的，这些都是很常见的类型。

还有一类人，他们属于半退休人员，因为年龄都不大，都是 80 后、90 后的年轻人，他们在小小年纪就实现了时间自由。

而且，这类“退休人群”跟大家想的不一样，没有人给他们发养老金，也不是有几套房收租那种情况。

但是呢，他们已经完全实现了时间自由，而且每天只需要工作很短的时间，赚到的钱就能完全覆盖掉自己的支出，甚至还有丰厚的盈余。

不仅如此，他们的收入途径也比较多，而且是稳中有升的。

这样就使得，他们可以在全球任何一个城市都能过上非常体面的生活。

所以，黄金时间段也就是中间这二三十年。

如果你在这二三十年内，一直朝九晚五上班。那么无论你的能力有多强，薪水有多高，你的时间总归是非常有限的，一不注意就用完了。

况且，你真的愿意把宝贵时光花在日复一日无休止的工作上吗？所以，但凡你的智商不算太低，脑子还算灵活，我建议你一定要制定一个目标，比如 35-40 岁之间退休。
