# 那些去菲律宾留学的人

原创   赢在 8 小时之外   2022-07-12 13:23:44

今天我在知乎上刷到一篇文章：菲律宾一年制硕士。

不是那种投放的广告，而是一个中介发了一篇正规的文章，介绍菲律宾一年制硕士的各种好处，然后引导那些有需求的人私信他。

他宣传得非常好，说什么这个大学硕士是 QS 排名认证的，回国之后享受全日制一本硕士同等待遇，而且只需要几万块钱……

我不知道这些是真是假，我也没有验证，而且我也没有这个留学需求。

我就想看看评论区，我知道一定很精彩。

果然，大部分网友都是嘲讽他的。

有人说，去英国读一年野鸡大学也比去菲律宾这种国家强。

还有人说，好的单位对国际学校排名是有要求的，你去菲律宾这种国家读研，回来发现根本没有单位认可。

有的人直接说，去菲律宾这种垃圾地方读研，笑死了！

当然，也有人说，这种一年制的研究生，都是给“特定人士”镀金用的，镀金回来直接能升一级，至于是不是菲律宾大学还是棱辅黎大学，无关紧要。
