# 第7天，快乐来了

食欲不好的时候，我就吃鸡蛋、酸奶和水果，因为鸡蛋几乎是营养密度最高、最好消化的食物了，一分钟就能拍掉两只，即使没有食欲也无所谓了。

不过无论如何，大家也要注意补充蛋白质，因为抗体、免疫球蛋白的主要成分都是蛋白质，这玩意跟免疫力是直接挂钩的。

大家应该都知道，连续喝几瓶啤酒不会出现问题，连续喝几杯茶也不会出现问题，但是连续喝几瓶白水肯定会出现问题。

因为水里几乎没有什么电解质，这时候就需要喝味道的水，比如兑点果汁、蔬菜汁，或者泡柠檬片之类的，都可以。

我自己在不吃药的情况下会喝淡淡茶水，提神醒脑，还能帮助消化，感觉很好。
