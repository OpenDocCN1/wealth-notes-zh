# 为什么要去大城市创业

原创 飨在 8 小时之外  2022-11-15 13:06:03

我的公众号简介是“打工者不要关注我，这里没有你想要看的东西”。

有人看了之后就觉得很奇怪：打工者得罪你了吗？

我想说，打工者没有得罪我，我写这些话时也没有带任何情绪。

我只是想提前做好预防针，先小人后君子。

如果我写的东西冒犯了你，你千万不要呛我，因为我已经说得很清楚了，我写的东西根本就不是面向大众的。

我写的这些文章跟普通大众的价值观背道而驰，甚至可以说是“三观不正”。

有一个扎心的现实，很多 人是拎不清的：人人与人之间的观念差异非常大，“

道不同不相为谋

”是最好的解决方案。

举个例子，如果我跟普通上班族或者穷人群体说“轻松日入一千是幸福的最低门槛”这种话，那我就要倒霉了。

他们会认为：U 君这个人的脑子有问题，估计是被什么传销组织洗脑了，现在又来给我们洗脑。总之吧，他们无论如何也不相信，这个世界上存在轻松轻松月入 3 万元的年轻人，绝对不可能。
