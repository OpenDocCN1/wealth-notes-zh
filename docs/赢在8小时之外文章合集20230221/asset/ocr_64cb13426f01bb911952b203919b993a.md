# 把自己活成奖品

原创 赢在 8 小时之外 2022-10-08 12:00:20

经常有人咨询我：把时间花在什么样的的际关系上才最明智？把精力放到什么样的事业上才不算浪费？面对各种选择时，走到人生岔路口时，该如何选择？

这类宽泛的问题，其实没有什么是标准答案，如果你去百度上搜索，应该会有一大堆冠冕堂皇的回答，都非常有道理。

今天我跟大家说两个比较玄的原则，以后再做选择时你可以尝试一下，看看我说的有没有道理。

# ① 永远不要选择低成本的人或事物

也就是说，无论买东西、结交人，还是做人生规划，一定要让你的选择有一定的成本，否则你的选择会很廉价。

廉价的选择太多，本质上就是一个需要解决的大问题。

比如，有的人会说：我现在单身是因为太优秀了，如果想结婚的话，有一大堆舔狗可以选择。

那么问题来了，你的这些备胎都是什么货色？有没有一个可以拿上台面的？有没有一个可以托付终身的？

再比如，有的人会说：我现在之所以没辞职，就是看老板人还可以，如果我想跳槽的话，一大堆公司任我选择。

那么问题来了，你的那些备选选项，薪资待遇都怎么样？有没有一个真正比得上现有的这份工作？如果真的跳槽之后，你需要额外牺牲什么？

西方有一个谚语，特别有意思，大家可以猜一下：

有这样一样东西，当有 3 个的时候，它就是 3 个；当有 2 个的时候，它就是 2 个；当有 1 的时候，它就是 0 个。

你知道这样东西是什么吗？

……

……

答案是：选择。
