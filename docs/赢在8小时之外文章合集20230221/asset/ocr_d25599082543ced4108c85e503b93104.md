# “傻子”的钱最好赚

原创 赢在 8 小时之外 2021-12-21 09:16:09

我喜欢观察各种赚钱的商业模式，而且我发现每个赚钱的项目都是魅力无穷的。

我最喜欢玩的游戏是穿越火线，所以我也研究过利用穿越火线赚钱的各种项目和各种大神。

有的游戏高手，在斗音上直播玩游戏，打的是多人生化模式，他一个人把 20 多个僵尸溜的团团转，最后还能把这些僵尸全给杀了，画面看着特别爽，围观的人也非常多。

那他怎么盈利呢？

我能看到的主要有两个途径：

+   ① 他可以代玩你的账号，帮你打分，一个小时收五六十块钱，保证能打到第一名，上 1000 分（同房间里 90%的人连 500 分都打不到）。

注意，他的这种代玩不是大家理解的“代练”，能帮你的账号升级、刷装备之类的。

他只是“代玩”而已，就是他玩你的账号过程中，让你观战，好像你身临其境一样，看着非常爽。

一小时过后，你的账号等级、装备之类的没有发生任何变化，只是让你“意淫”一下，仿佛自己的也变得厉害起来。

+   ② 他会引导围观的看客们加 QQ 群，然后说进群就可以领取低价 xx 武器。

如果你进群之后，发现得添加群主微信才能领取。添加之后发现确实能领取，而且价钱都不贵，你一刷这个人的朋友圈，发现他卖各种各样的角色和武器，比官价价格低很多，还有账号出租等各种各样的业务（都是合法合规的）。

后来我就去淘宝搜了一下，我发现淘宝上做这类业务的也特别多，价格也都非常便宜，只不过销量都不高。

原因就是，现在没事就刷淘宝的人不多了，但是没事就刷斗音、看直播的人却很多，而且他们会相信直播的大 V，反而不会太相信销量只有几十个的淘宝店主，担心他们收了钱之后就不发货了。

我观察了一个比较厉害的团队，主要业务人员也就三四个人，但是一个月的利润至少有七八万，而且他们都是在玩的过程中就把钱给赚了。

有一次游戏主播在直播时咬嚼，想要“上号”的抓紧下单，现在前面已经排了两个人了，今天接 4 单就下播了。
