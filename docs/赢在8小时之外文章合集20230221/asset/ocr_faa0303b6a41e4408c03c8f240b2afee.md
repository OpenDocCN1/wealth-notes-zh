# 世界会狠狠奖励，那些“不守规则”的人

如果你认真观察，你就会发现，那些富人低头特别快，动不动就承认是自己错了。

但是呢，低头越快的人，翻脸也越快，因为这种人基本没什么底线。对于底线越低的人，世界给他的回报也就越丰厚。

而穷鬼呢？脖子永远是硬的，永远在跟别人讲道理，讲对错，凡事都要坚守自己的底线和原则。结果就是本应该属于你的资源也会被别人拿走。

经常关注我公众号的朋友应该清楚，我除了喜欢讨论金钱之外，还特别喜欢讨论情绪，因为这两个东西才是世界上最宝贵的。

越富有的人，越不容易动怒，原因就是他手里的王牌比较多。相反，如果一个人动不动就发脾气，说明他已经没什么王牌了，也就只剩下发脾气这一点能耐了。

所有的负面情绪，都是因为没办法之后的无奈之举。

当然，除了爱讲道理的穷鬼之外，在中国还有这样一种穷鬼，他们特别“会做人”，见了谁都称兄道弟的，能说会道，“情商”很高。

他们之所以会有这些症状，就是因为没钱、没势、没才华、没长相，但凡有一丁点本事，也就不用这样了。
