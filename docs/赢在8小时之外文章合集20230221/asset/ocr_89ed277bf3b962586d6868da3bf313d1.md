# 穷人在过节，富人在赚钱

原创　赢在 8 小时之外　2021-05-01 14:35:12

今天刷微博，看到一个我认识的老板发了这样一条微博：穷人在过节，富人在赚钱。

底下的人大部分都是在喷他。

有的说，照你这么说，富人真可怜，我还是当穷人吧。

有人说，你现实生活中应该没见过富人。

还有人说，人都是要休息的，不要钻到钱眼里，该放松就放松。

……

我知道，这些负面评论的大部分都是打工者，都是比较穷的人。

至少我认识的年收入 100w 以上的老板，大多都是不过法定假日的，因为智商正常的人都应该很清楚，法定假日出门就是他妈的活受罪。

无论你选择飞机、火车还是自驾，都是一种折磨，肉体上是折磨，精神上也是煎熬。

五一或者十一假期的时候，总有人发泰山或者长城上拥挤的人群照片，其实太多的人限制在一个空间里不是很安全，无论从踩踏风险、疾病传播等角度来看，都是非常不明智的。而且，在高速上一堵就是几个小时，机票酒店价格都是平时的好几倍，亏不亏？

但是呢，大多数的打工者没得选，平时没有假期，只能这时候蜂拥而出，也是没有办法，我也是从这个阶段过来的。

但是呢，只要你不是打工者阶层，你是自由职业者、老板或者投资人，你就已经能安排自己的时间了，你可以选择一个清净的、天气好、交通通畅的日子，带着家人去坐淡季价格的头等舱，住淡季价格的五星级酒店，享受一片无人打扰的风景，多好。

后来我就在想，幸福感这个东西是分等级的。

在我们还是穷鬼打工者的时候，只能在周末、法定假期出去旅游旅游、发发朋友圈，就觉得已经很开心了。
