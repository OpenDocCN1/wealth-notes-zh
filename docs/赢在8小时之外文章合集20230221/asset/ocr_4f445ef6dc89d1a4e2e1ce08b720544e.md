# 不要指望大环境会发生改变

原创 赢在 8 小时之外 2022-09-29 12:00:06

有位家长高鸿我，是让孩子读高中还是读职高呢？然后介绍了大堆孩子的情况。

我的建议很简单，你去看有钱人家、有知识人家的孩子都去读什么，你就让孩子读什么即可。

也就是说，在财力、智商允许的情况下，能走高中路线，尽量走高中路线。

将来能留学就留学，留不下学就上本科（咱就三本），上不了本科就上专科。

那些读职高的孩子，可能是自己底层根不是读书的料，或者家里条件太差，想让孩子早点学技术、早点赚钱养家，实在没得选才去读职高。

有人说，现在“上面”已经讲得很清楚了，职高、蓝领一样有前途，一样高收入，一样受尊重。

我想说，大环境那样容易改变。

职业技术学校里的氛围很差，将来从事车床、电焊、厨师、理发等行业的人，一般都处在社会的底层（即使月薪 8000 元、10000 元）。

我去过很多发达国家，他们的职业学校里的技术和设备都非常先进，学习氛围也非常好，毕业之后的技术工人、体力工作者、蓝领的收入非常高，一个人每天工作 8 小时，就能养活 5、6 口子人，而且活得非常滋润。

当然，社会文化方面，也是非常尊重和认可这些蓝领工人的，地位相当高。

而这里就不要想了，大部分技校的氛围，以及学生素质，在当地的名声可能都不太好。

打架、斗殴、纹身、酗酒、喧哗、包养、流产……这些都是社会给他们贴上的标签。

技校毕业之后呢？能吃苦、认真学习的少数人，可能去从事电工、焊工、厨师等收入较高的行业，其余的人要么去做服务生、要么去送外卖了。

注意，我并不是歧视技校学生和服务生，我有很多亲戚都是技校毕业的，也有做服务生的。

我只是想说几句实话，大的趋势、大的环境不要指望在几十年内会有所改变。

我再举一个例子。

我听到不少一个跟我抱怨，说商场里卖奢侈品的店员、4S 店的工作人员对自己爱答不理的，瞧不起人。
