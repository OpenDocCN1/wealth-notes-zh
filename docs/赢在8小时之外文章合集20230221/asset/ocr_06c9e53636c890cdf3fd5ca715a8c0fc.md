# 不会撒娇的女人，六亲不认的男人

原创　赢在 8 小时之外　2021-05-07 12:04:00

小 A 长得很漂亮，但是她的老公经常抱怨她，说你怎么不会撒娇啊，我唯一的愿望就是你能更有女人味一些。

后来小 A 跟他坦白道，我也知道会撒娇的女人更吸引人，但是我做不到。

因为在我还是很小的时候，已经尝试过撒娇这条路了，行不通。

我们家的财政大权掌握在爸爸手里，我在很小的时候，有一次就跟爸爸说想要买漂亮的发卡，然后他非常冷漠的说，你自己去卖头发吧，我没钱。（她们家里确实很穷，村里到 21 世纪才通上电，四川某山区）

后来她就养成了独立的习惯，从来不依靠任何人，自然也就不会撒娇了。

人的习惯，都是从小养成的，而且都是条件反射式的。

如果一个人，在小时候通过撒娇能获得一些甜头，那么她就会养成撒娇的习惯。如果她第一次撒娇就被泼了冷水，后面的几次也都吃闭门羹，那么她可能这辈子都不想撒娇了，也学不会了。

后来她生了一个女儿，又生了一个儿子。有一天在大街上，5 岁的小儿子抱着她的大腿，撒娇道：妈妈，我要买那个奥特曼！

她说，宝贝，家里玩具已经有很多了，这次先别买了。

儿子就开启了撒娇打滚模式，先央求，然后再威胁说不买就躺在地上不回家了。

没办法，她就给买了。

回到家，她跟老公说，儿子这么小都比我会撒娇，我一辈子都学不会了。

小 C 是个钢铁直男，而且是六亲不认那种。

女朋友问他，你到底是经历了什么，对待亲戚这么冷漠。

他说，从我出生到 28 岁这么多年，我们家里经历过两次重大困难。90%的亲戚听说这个消息之后，都是选择主动疏远。

其中一个重大困难是，我考上了一所 211 大学。因为我家里比较穷，我的亲舅舅听说这个消息之后，当即就跟我们家一刀两断了。
