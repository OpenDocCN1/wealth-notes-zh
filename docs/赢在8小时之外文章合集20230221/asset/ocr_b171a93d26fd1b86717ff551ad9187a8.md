# 老板的情绪，也都带有目的性。

其实聪明的老板都明白：高手，是没有情绪的。

负面情绪几乎永远也不会出现，有的只有淡淡的愉悦感和暗爽。

如果高手发火了，绝不是像穷鬼那样的发泄情绪。

高手发火是一种策略，他们发火背后的逻辑，一定是为了提高整个团队的工作效率。

比如，高手发火一般是对身边举足轻重的人，目的是让对方和整个团队明白自己的底线。

所以呢，关注我公众号的各位老板朋友们，一定要时刻刻留意，自己的时间、金钱和情绪，一定
要投资在能带来超值回报的事情上。

如果这三样东西你控制不住，肆意挥霍，那么人生的种种美好，便再也与你无缘了。
