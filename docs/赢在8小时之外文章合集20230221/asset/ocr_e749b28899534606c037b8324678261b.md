# 自己不能做主的事，不要参与

原创　　赢在 8 小时之外　　2021-04-07 23:09:35

今天我看到朋友圈有一个人在那里声讨，说有人欠自己两万块钱，迟迟不还，要了几次账，对方都是一拖再拖。

而今年他自己的生意也不好，上有老下有小的，日子很艰难，所以他决定撕破脸，给对方下达了最后通牒，说再不还钱就法庭见。

结果对方把自己拉黑了。

然后他就发朋友圈抱怨，说人无信不立，这种欠钱不还的人会遭报应的，还诅咒了很多难听的话。

我猜当初他把钱借给对方时，对方肯定说的比唱的还好听，把胸脯拍的山响，哥们义气那一套背的滚瓜烂熟，结果你就被对方的誓言冲昏了头脑，把自己辛辛苦苦赚的钱拱手相让了。

你知道什么人最容易上当受骗吗？就是那些把“先做人后做事”“人无信不立”等鬼话奉为至理名言的人。

我早就说过，所有美好的道德和品质，都是用来要求自己的，永远不要期待别人拥有这些美好的品质，连一丁点的期待都不要有。
