# 豆腐下水救人遇难留下一妻五子还有一瘫痪老人

为什么会这样？因为会游泳跟会救人，需要的技术相差十万八千里。

刚刚落水的人，会陷入巨大的恐慌，然后就会乱扑腾，而且这时候他爆发出来的力量非常强大，如果谁跳下去救他，就会被他死死抓住，动弹不得，最终只能双双沉入水中。

所以，要么递给对方一个长杆子，要么把有浮力的东西扔到水里让落水者抓住，要么悄悄绕到他的后背，然后再通过专业的操作方法进行施救（具体可以百度）。

总之呢，一定不要在对方力气特别强、乱抓乱扑腾的时候，出现在对方的正面，否则他一定会把你拉下水。

落魄的人也是同理，他在向下坠落的过程中，力量是非常强大的，你如果没有菩萨般的能量，没有金刚不坏之身，就不要随便去施救，否则他也会把你也拉入深渊。
