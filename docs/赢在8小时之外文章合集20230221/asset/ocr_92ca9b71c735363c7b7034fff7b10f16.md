# 学习战争最好的方式，就是上战场

原创    赢在 8 小时之外    2021-06-13 13:22:39

以前我处于打工者阶段，还是个穷鬼时，有道德洁癖。

就是什么都看不上，别人赚再多的钱，我如果觉得他做得不是高尚、可持续的项目，我就认为他的事业肯定不长久，哼瑟不了几天。

比如那些搞直播的，做微商的，招加盟的，做培训的。

但是后来我逐渐意识到，金钱是没有色调的，是中性的。

他是搞微商赚到的 100w，你是辛辛苦苦种地赚下来的 100w，等你去买房或者买车时，人家不会问你这些钱的来源，一视同仁。

如果你说，我这钱是辛辛苦苦凭良心赚来的，问心无愧，我的 100w 应该抵得上做微商那些人赚的 1000w……别人肯定会说你是神经病。

昨天我在 VIP 群里也说过这个事，无论赚快钱还是赚慢钱，只要是合法的生意，我们就要积极拥抱。
