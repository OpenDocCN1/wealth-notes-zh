# 不要指望大环境会发生改变

连 Nike、Adidas 这样的店员都很傲慢。

无论是北上广深，还是小县城，这种现象都非常常见。

我想问的是，你当时穿的什么衣服？戴的什么表？

要知道，人靠衣装马靠鞍，先敬罗衣后敬人。

这是我们几千年文化的沉淀，为什么你总是心存幻想、不尊重我们老祖宗的文化呢？

有的人会说，这些店员真该验，他自己月薪才能够 5000 元，以为卖奢侈品，自己也就变得高贵了，狗眼看人低。

我想说，问题并没有出在他们身上，而是出在了你身上。

你总想别人一视同仁，简直是天方夜谭，白日做梦。

在这里，根本没有一视同仁、人人平等这个概念好吗，你开着好车，穿着奢侈品，就是能一路畅通，所有人都会谦卑、面带微笑地为你服务。

你穿着普通，气质婆娑，那么服务人员自然会冷眼相待，而且这种现象应该几十年内不会改变。

这个道理其实很简单，连小学生都懂，只不过很多人不信邪，每次吃完闭餐之后都要经历到人，怪大环境，然后回家生闷气。

要知道，人生是短暂的，你能感受到各种生命体验、感受到外界对你反馈的时间段，可能就三五十年。

你是想在这三五十年里被人尊重，还是被人冷落？

另外，不光是在个人服务维度，即使在个人成长、事业规划维度，“营销包装”的力量也非常强大，这也是 U 君在公众号和社群里重点讲解的。

之前我在聊奢侈品、聊豪车时说过，凡是那些喜欢讲配置、讲性价比的人，都是拎不清的韭菜，而聪明人首先看重的是品牌。

现在是物质极度充裕时代，很多商品的社交属性远远大于实用属性。

换句话说，那些愿意为超高溢价买单的人，才是高人。
