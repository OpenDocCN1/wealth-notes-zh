# 穷屌丝的一切宏图伟志，都是瞎扯淡

原创 赢在 8 小时之外 2021-06-28 18:32:39

每天私信我的人比较多，有咨询问题的，也有咨询合作的。

我比较关心的只有两点：你的学历和你目前的收入。

我这个人是充满偏见的，看人、看事也特别武断。我从来不追求小概率事件。

一个人学历高，大概率说明他的智商还比较不错，而智商这个指标，几乎跟金钱一样，能衡量一个人是否值得合作、值得相处。

在寻找合作伙伴时，我几乎不关心他的情商，以及他的为人处世能力。因为只要智商还不错的话，一切都是可以学习的，一切都是可以改良的。

但如果反过来，一个人学历很低，很早就辍学了，但是在社会上历练了很多年，为人处世特别圆滑，是老油条，那么我会离他远远的。

稍微有点实力的人找对象，稍微有点实力的公司招聘员工，都会非常看重“学历”这个指标，不是没有道理的。

这就好比，你高中毕业，非要去苹果公司应聘，他们把你的简历筛选掉，你还要反问人家 HR：你们凭什么瞧不起低学历的人？我要求你们，告你们歧视！

所有人都会把你当成神经病。

一个本科毕业的人，跟一个初中毕业的人，几乎没法沟通，只能互相妥协，彼此看对方都像神经病。

当然有例外情况，50 岁的煤老板即使小学都没毕业，但是他有亿万身价，也可以娶一个年轻漂亮的女硕士。

因为金钱是能让人变聪明的，有钱人看新闻，听别人聊天，看书里的内容，基本上听一句就能知道整篇文章的意图，知道对方葫芦里卖的什么药。

而且财富值越高的人，说话越能说到点子上，因为他在积累财富的过程中，对于行业知识、社会规则、人性的弱点，早已经了如指掌，所以他说的每句话都特别好听。

因为赚钱这件事，是最考验人的智力和智慧的。

另外，永远也不要担心有钱人会坑你。
