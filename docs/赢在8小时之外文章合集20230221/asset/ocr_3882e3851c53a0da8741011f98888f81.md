# 最顶级的能力

赢在 8 小时之外  2023-01-23 12:00:49

+   1. 最顶级的能力是屏蔽力，任何消耗你的人和事，多看一眼都是你的不对。
2. 不要告诉别人你的计划，让他们看结果。真正要做的事情，对神明都不要讲。
3. 无论何种关系，只要别人没有考虑过你的感受和利益，你就应该及时止损了。
4. 只要利害不发生冲突，别人讲话一般不需要反驳。
5. 你要怀疑的是自己的眼光和见识，而不怀疑自己的真诚和善良。
6. 在不公平的时候，大多数人都会选择优先照顾老实人。
7. 只有天才和雄才才能享受孤独，普通人只是寂寞罢了。
8. 真正看不起你的人是不会批评你的，他只会看着你在错误 Threat上越走越远。
9. 所谓的事事不顺心，主要原因就是手头紧。
10. 一个人善于独处的时候，自然也会与别人相处。
11. “懂事”在我眼里是贬义词。什么是懂事？你能吃下委屈，吃下苦，吃下这些年长辈对你的不公平，那就你懂事。
12. 没有人会真正的关注你，除非你长得漂亮或者即将消失。人的注意力总是会被好看或可怜的东西所吸 引。
13. 作为苦逼成年人来说，越早意识到自己可以选择跟别人不一样，就可以活得越轻松。
14. 大部分人往往在思考，怎么做一件足够惊艳的事情让人生质量得到改善，殊不知，只要坚持不做傻事，就足够 impressive 同行了。
15. 成年人升职其实很危险，这意味着你拥有了更稀缺的 思想，也意味着你即将开始和周围的人产生重分歧。之前以为为常的事，也再难以入你的眼。
16. 人得到任何一件东西，不管是豪车美宅还是俊男靓女，大概能激动兴奋 3 个月，3 个月后基本就会归于平淡、熟视无睹了。

后续的关系，全靠“实用价值”支撑，否则就是进冷宫吃灰。
