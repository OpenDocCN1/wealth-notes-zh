# 穷鬼就不要再低调了

原创   赢在 8 小时之外   2022-07-07 13:12:38

我在公众号上经常“高谈阔论”，在朋友圈也会经常发一些高调的内容。

不过，总会有“好心人”劝我：这个时期，很多人吃饭都成了问题，你一定要低调点。

确实，每年都会有人因为高调而被打倒。

比如，体制内的某位官员，拍照时竟然让手腕上的百达翡翠入镜了，结果被查了；

比如，一位百万粉丝的网红，每天都在直播间里炫富，最后终于被封号了，还被罚了很多税收；

比如，一位富二代经常在朋友圈晒他的豪车豪宅，结果被歹徒盯上了，家人被绑架了……

这些人确实需要低调，因为他们的影响力太大了，能量场太强了，稍微不注意，可能就会踩雷，最后功亏一篑，前功尽弃。

而我们跟这些人相比，就是穷鬼级别的角色，压根就没有低调的资本。

还没起来的时候，要尽可能地高调。

杜汶泽和梁洛施当年演的电影《伊莎贝拉》里有一句非常经典的台词：在道上混，手上必须要戴一块金劳（黄金劳力士）。没有金劳，别人不是看不起你，而是根本看不见你。

其实在互联网上也是如此。

现在是个信息大爆炸的时代，每天都会有数亿条信息流在网上冒出来，你如果发那些平平淡淡的内容，很快就会石沉大海，根本不会有人关注到你。

反之，如果你非常高调，喜欢晒，喜欢炫，喜欢表达自己的真实感受，说话语不惊人死不休，这样大家才会愿意关注你。

我这个人，最讨厌那些不痛不痒的文章了，所以我自己也不会去写那些冠冕堂皇的鬼话。

另外，我之前说过一个观点：能让你起来的人，很可能是陌生人，而不是亲戚朋友。

在互联网上赚钱，更是如此。

你如果有粉丝，有铁杆用户，那么你就不用愁赚不到钱，不用担心未来。

你最需要做的，是跟他们说真心话，不要藏着掖着。
