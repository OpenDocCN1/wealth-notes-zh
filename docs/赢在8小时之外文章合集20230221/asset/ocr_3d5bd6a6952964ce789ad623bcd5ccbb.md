# 父母沟通不顺畅，把他们舍弃掉就行了。

我早就把亲戚、父母、亲情这些在我人生里舍弃掉了。

不要误会，我说的“舍弃”，并不是不跟父母来往了，而是不会再跟他们平等沟通了，也不会聊任何深入的话题了。

我之前发过一条朋友圈，是这样说的：

和父母相处，永恒的真理就是：认真你就输了。只有不认真、不较真，不当回事，说一套做一套，从不试图在口头上得到认同，从不在道理上争输赢，才能让家庭关系和谐。

说得再明白一些，就是能躲就躲，绝对不能跟他们说任何实话，更不能交心。

当然，这句话的前提是，我们的三观已经跟父母产生严重的分歧，在大多数事情上已经无法达成共识了。（劳人出身的孩子一定会走到这一步）

这时候，其实没有任何深入交流的必要了。

敷衍、躲、少沟通、少见面都是不错的选择。

我每个月会给他们微信上转账，他们有事需要帮助的时候我也会帮忙，但是我再也不会跟他们闲聊天了。
