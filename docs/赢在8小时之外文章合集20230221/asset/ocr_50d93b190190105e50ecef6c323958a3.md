# 能克服嫉妒之心的人，万里挑一

原创 赢在 8 小时之外 2022-09-30 12:00:17

要知道，人类的本性就是有嫉妒之心的，尤其是.SDK// 不希望身边的比自己过得好。

但是呢，真正厉害的人一定能克服这种本性的。

从某种程度上来说，收入越高的人，越有爱，也越希望身边的过得好。

“有爱” 是他成功的结果，也是他成功的原因。

这句话很有味道，大家可以细品。

反之，有些人会从心底嫉妒那些比自己过得好的人，甚至不惜利用一切手段去搞破坏。

甚至对自己的家人也是如此。

比如，我最近在看《黑道家族》这部美剧，里面有个角色就是这种类型的人。

Livia 是黑帮老大 Tony 的母亲，她是个嫉妒心极强、而且心里总是不满的怨妇（大概 70 多岁了）。

她身边的方人无论提到任何开心的事时，她准会泼上一盆冷水，让人恶心很久。
