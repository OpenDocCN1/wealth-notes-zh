# 人的价值，就是靠奋斗才能体现出来

藏在 8 小时之外　　2022-10-05 12:00:54

+   1. 经验越少时，学到的经验越宝贵。
2. 真正的忠诚，都是悄无声息发生的。
3. 不跟别人争论，是一种自爱的表现。
4. 获得别人信任的唯一方法就是保持真实。
5. 你不会因为选择忍受更多而成为一个好人。
6. 无需询问，别人的行为就是你想要的最好答案。
7. 始终让自己的圈子保持小而真，这一点很重要。
8. 最终所有人都会离开的，学会独处是生存的基本功。
9. 请控制好你的情绪，尝试着少做回应，甚至不做回应。
10. 非凡的人生需要非凡的牺牲，所有东西都是有价格的。
11. 一定要和那些能把你最好的一面引导出来的人保持联系。
12. 被人忽视比被人讨厌更糟糕，被人尊重比被人喜欢更重要。
13. 相信自己的直觉，在某种程度上，它们比你自己还了解你。
14. 在你能真正解决问题之前，没人 ใน乎你是哪个大学毕业的。
15. 保持隐私和神秘感，是个人成长的最大利器，甚至是力量的源泉。
16. 永远不要因为做了对自己有利的事或者让自己开心的事而感到愧疚。
17. 不要想着报复谁，也不要想着跟谁争论，安安静静地拉黑他们即可。
18. 当别人展示伤疤时一定不要嘲笑对方，因为撕下盔甲比穿上盔甲要难多了。
19. 被攻击，说明你很厉害，所以才会成为众矢之的。你应该珍惜这种被关注的感觉，以及证明自己的机会。
