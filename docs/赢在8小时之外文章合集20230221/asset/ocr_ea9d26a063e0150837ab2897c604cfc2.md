# 我不需要真心

原创 嬴在8小时之外 2023-02-01 15:06:43

之前在

冲破枷锁，神魔寂灭

这篇文章里，提到“地域枷锁”时，我说日韩的管理人员、服务人员态度都很好。

然后就有大聪明跟我说：他们都是职业假笑而已，认真你就输了。

我呢，其实并不在意他们的微笑是出自职业习惯还是出自真心，只要他们对我笑脸相迎就行了。

我不需要任何人的真心、甚至包括身边的亲人朋友。

为什么会这样？

因为真心是没法评判、没法量化的。

一个人对你很好，很真诚，你怎么知道对方的真诚里包含几成真心、几成功利？

没办法知道，干脆不去分析，直接看结果就够了。

如果别人对你的真诚是伪装出来的，那说明你有让别人伪装的理由。

只要这个理由由始终存在，那这份真诚就会一直维持下去。

这比为单纯地真诚，你将拥有更多主动权。

换句话说，真诚这个东西就像金钱一样，你不用太关心它的来源。

有人会说，如果生活中没有了真诚和真心，一切都围绕着转钱，那将是一件多么悲哀的事啊。

我想说的是，你以为你不提钱，净跟别人讲感情、讲真诚，你就能收敛获别人的真心？

幼稚。

2023年春节已经过去了，各地的离婚率都在飙升。
