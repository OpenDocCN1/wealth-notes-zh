# 35岁的单身女人，还会获得幸福吗？

原创　　赢在 8 小时之外　　2021-02-08 14:02:02

昨天有个粉丝私信我：35岁的单身女人，还能获得幸福吗？

我听了之后觉得很搞笑，我就说，80岁单身女人也可以获得幸福，但前提是你有能力，有自己的事业，有各种富足的保障。

年龄，性别，婚姻状况，这些跟是否幸福没有必然联系。

真正厉害的人，他的人生里不会只有爱情，还包括友情、亲情、事业、兴趣、爱好等等。

即便是爱情出了状况，其他的部分还很正常。只要这些大框架还在，他的人生就不会因为某一部分缺失而停止运转。

另外，所有的这些因素里面，最重要的是事业，至少得占90%以上，其他的都是锦上添花的东西。

30岁之后，重心应该放在事业上了，其他虚的东西，根本靠不住。（我说的是老板，不是打工者。打工者收入单一，如果盲目努力加班，可能会导致猝死）

有砖家说过，女性外貌的巅峰是27岁，之后就走下坡路了，很快就呈现衰老的痕迹。

其实男人形势更紧迫，如果你过了30岁，事业还一塌糊涂，那么爱情、友情、亲情统统会离你而去。

我这不是危言耸听，很多30多岁的男人，如果一事无成，过年连家都不敢回。因为所有家人、亲戚朋友，看待你的眼光都不是善意的，甚至是嘲讽的。

连狗看你的眼神都是鄙视的。

大部分普通人，是没法轻松赚钱的，要么拼爹，要么拼命。

只有这两个选择。

我经常在公众号里说，如果你获得幸福的瓶颈是钱（大部分人都这样），那么你就应该把灵魂献给事业，献给金钱，献给权力。

很多傻狗事业做的一塌糊涂，还总想平衡事业和生活，还总想着去维系亲情、友情、爱情，或者去发展兴趣爱好，我觉得纯粹是神经病。

即使你用尽各种手段去维系这些人际关系，如果你没有事业作为根基，这些美好的东西会统统离你而去。
