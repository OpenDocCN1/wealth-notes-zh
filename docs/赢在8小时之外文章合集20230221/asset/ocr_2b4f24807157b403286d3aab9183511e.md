# 小黑屋

这篇文章写得稀松，“花钱享受”这件事，至少在东南亚地区，比在国内大部分旅游城市性价比都要高很多。

住酒店、吃海鲜、吃水果、看风景、做 spa……各个方面，都可以用更少的钱享受更好的服务。

从“打工人”这个赛道切换到“自由职业者/创业者”赛道也是同理。

只要你不受雇于人、受制于人，那么你的时间利用率、金钱利用率、生命体验都会直接大幅度提高。

只要你体验过不同的工作方式，你就会发现：世界上最苦、最累的就是打工者阶级，他们不仅要跟数以亿计的同龄人竞争、内卷，他们的孩子将来也要走上一条内卷之路。

想要向上升级的话，不是你需要额外付出多少努力（否则又走上了另一条内卷之路），而是说，你要做出很多决断，之前想都不敢想的决断。

我跟大家举一个简单的例子。

大概在 27 岁的时候，我就做出了一个决断：从今天起，我的收入来源，我的幸福来源，我的好情绪，都要靠自己获得，不能求任何人、依靠任何人。

其实无论在事业维度，还是幸福维度，道理想是相通的。

赚钱这件事，只有一种情况可以靠别人：你是清华北大、常春藤大学毕业的，毕业之后你去了欧美大厂打工，你还是有很大概率可以过得轻松幸福。
