# 人是从决定再也不占便宜那一刻，开始变富有的

原创 赢在 8 小时之外 2020-01-17 12:35:31

经常有人在微信上私信我，该怎么选行业，选工作；

还有人问我该怎么样不再为别人打工，想拥有更多的自由时间和金钱；

还有人问我微博该怎么样引流，怎么卖产品，怎么样写东西最走心。

我会扫一下 ta 的头像、昵称、简介、朋友圈，如果感觉是正能量的人，积极的人，我会把 VIP 群的报名链接给到 ta，我说在群上我都会讲这些，你也可以提问。

有的人，会有这样的回复：问个问题还要交钱啊？

我就把 ta 拉黑了。

跟大家说一个惨痛的事实：

但凡在网上直接私信别人请教问题的人，都是穷人，而且也永远不会富有的。

因为你的开口，会消耗人家一分精力，一份时间，其实跟抢劫没有区别。

我这个人特别喜欢贴标签，凡是一个陌生人直接过来开口问问题的，我都把他贴上一个“强盗”的标签，因为他想在 0 付出的前提下，获取点什么。

互联网时代，你觉得一个人拥有你想要的答案，他能解决你的问题，那么大概率，他的身边会有一万个类似于你这样的求助者，他是没有精力为所有人服务的。

所以，他只能拒绝所有人。

所以，我们才会见到，有能量的人都只会为付费的人服务。

并不是他精明，或者贪财，而是说，不这样做的话，他每天只在醒着的时间，都在解答穷鬼的低级问题。

如果你不想付费，哪怕发个红包，也算是一点诚意，你穷的时候，哪怕发一块钱、十块钱的红包，人家不会收，但是至少能感受到你是愿意为价值买单的，不是强盗。

受垃圾文化洗脑的人，最喜欢谈感情：大佬请多多指教，感激不尽，我是一个视金钱如粪土的人，你看我朋友圈转的内容，每天都是感恩、仁义道德、正义爱国的言辞。

我再跟大家说一个惨痛的事实：谈钱的人更知道感恩，避开谈钱的人更容易要流氓，大概率会忘恩负义。
