# 男人，一定要把自己活成奖品

本文章只有男性读者可见。

今天我看到一个非常有意思的新闻，教育部强调要注重男性“阳刚之气”的培养，也就是要打压一下，部分男星女性化的“不正之风”。

什么才是阳刚之气呢？我觉得跟外表或者言行举止关系不大，而是一种内在的心态。

并不是说你练就一身肌肉，留着胡子，穿着笔挺的西装就代表有阳刚之气，因为太多这样的男人，每天跪舔女人，还愿意做父母的奴隶。

只要你有一丝跪舔心态，不论是对女人，对父母，对孩子，那么你就跟阳刚之气不沾边了。

上次我提过一嘴“脱单”这个话题，评论区没人回复，但是私信我的却有好几个，他们都说自己有这方面需求。

我这个公众号是讲创业的，讲个人成长的，但是我知道很多男性同胞，连马斯洛需求金字塔的最底层都还没满足（性），我觉得非常可惜：

其实找女人，跟创业做生意，没有本质区别，这件事跟你的外貌、出身、财富值、学历都有关係，但最核心的绝对不是这些，而是你的心态，别人跟你接触时你散发出来的能量场。

我经常拿动物世界举例子，其实不光是动物界，人类的几千年来都是如此，雄性负责外出打猎，然后讨好雌性，或是献上猎物，或是展示自己的肌肉和华丽的羽毛，然后雌性就会在这些优质基因里选择一个最优的，跟自己繁殖后代。在潜意识里，几乎所有的女人，都是把自己当成奖品来看待的。
