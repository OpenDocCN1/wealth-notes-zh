# 2023 VIP

能交1500进一个微信群，我相信大家都是敢闯敢干的人，做事情不要总是犹豫豫豫

如果自己属于那种思维活跃、动手能力强、整天喜欢搞事情的人，就要主动迎接更多挑战。

对于这样的人来说，刚毕业的前几份工作收入如何，是否有保障，都不重要。因为自己以后不断搞事情，肯定能搞出一些名堂。到时候一天的收入可能是现在一个月收入。

我属于割韭菜很一般的人，都能在业余时间轻轻松松赚几十万。群里很多00后，只要把格局打开，将来肯定更厉害。

我属于不搞事情活着没意思的人。大家如果是这种人，就不要追求稳定。

大学毕业之后，你可以去考研，可以去考公务员，可以直接就业，也可以创业……做什么都可以，但是我希望你走的这条路不是别人规划出来的。

很多弱者最喜欢追求稳定和确定，他们会去找家长、老师或者前辈去做职业规划：

路径一：读完本科之后读研究生，读完3年研究生之后要出国学习，然后就可以回国找一份外企工作，从此就走上了人生巅峰。

路径二：毕业之后尽量去大厂，去不了大厂就去小厂，然后从基层做起，埋头苦干两年，第3年做到团队副主管，第5年做到团队主管，第8年……
