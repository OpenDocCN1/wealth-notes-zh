# 没事不要随便在时间线上游走

原创    赢在 8 小时之外    2021-08-06 12:09:09

很多人都认为，世界是四维的。除了三维立体空间之外，第四个维度是时间。

但是还有很多人不认可这种说法，包括很多科学家，都认为“时间”这个维度是不存在的，是人为创造出来的。

虽然咬一口苹果，它就再也回不到原来的完整状态了；虽然人变老了之后，就再也无法回到年轻状态了。但是，构成物质的基本粒子，没有发生本质的变化。

我是比较认同第二种说法的，就是说，你不要没事就在时间线上游走，过去和未来只存在于你的脑海里，在现实中是根本不存在的，不要沉迷于过去，不要担心未来，要活在当下。

有些“怨妇”，特别喜欢回忆过去。一回忆起过去美好的时光，就发现现状很惨，很悲伤。一回忆起过去不好的经历，伤心的往事又会重演一遍，人会更加的恍郁。

还有些人，总喜欢为未来焦虑；我们这里也发大水了怎么办？我要是感染新冠病毒怎么办？我的公司今年倒闭了怎么办？我老珠黄之后，男人跑了怎么办？我破产之后，女人跑了怎么办？

只要你总喜欢在时间线上游走，那么恍郁和焦虑将会常伴你左右。

其实呢，过去和将来，都是不存在的，都是你的妄念，徒增烦恼罢了。

你要多关注当下的事物和心境，感受每个粒子的振动，感受每份能量的传递。

很多物理学家认为，物质是由能量构成的，因为任何物质都是由分子、原子构成的，而每个粒子都有各自的振动频率、轨道，发射着各自的能量。

霍金斯认为，情绪也是由能量构成的，你的能量层级高了，就会表现出正向、积极的情绪；你的能量层级低了，就会表现出负面、消极的能量。
