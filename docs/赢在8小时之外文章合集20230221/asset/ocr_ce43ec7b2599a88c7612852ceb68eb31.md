# 抱歉，你的真心并不值钱

我的一位高中同学，在山东一家韩企工作，是韩国某汽车品牌的供应商。

我记得在 2017 年的时候，我跟当时的女朋友路过济南，在那边玩两天，他知道之后也开车过来了，说要一起吃个饭。

我跟他的关系非常铁，几乎是无话不谈，就是没有任何隐私那种。

他直接跟我说，你看我现在单身一个人，要不让你媳妇给我介绍一个靠谱的人呗。

我说，介绍倒是可以。

但是呢，对于咱们这种出身很差、长相平平的人来说，最需要做的就是把收入提上来，在此之前，其他虚的都没有用，太刻意了不好。

他就跟我发牢骚，说自己也追过几个，对她们都特别好，可以说是无微不至那种，但是没有一个成的。

自己有车有房，虽然有房贷，但是年轻人现在都是这样啊。

我就跟他说，你不要总想着做好人了，穷人嘴里所谓的“好人”，其实是最不值钱的。

另外，不要听别人怎么说，要冷静想别人是怎么做的。

比如，一个漂亮的女人，择偶时声称自己喜欢对她好的，体贴的，幽默的，专一的，什么都想着她的，时刻把她放到第一位的。

但是后来呢，她嫁给了一项都做不到的男人。

这就很有意思了。

原因就是，这个男人有令她仰视的闪光点和魅力，在很多维度都能胜她一筹（当然性格和教养也绝对不差）。

你光对女人好，是没有任何吸引力的。不是有那么一句话吗：世界上最不值钱的就是男人一事无成的温柔。

这年头一个 3 分的女人，化化妆再开一下美颜，在社交软件上都会有几百个男的来舔她。
