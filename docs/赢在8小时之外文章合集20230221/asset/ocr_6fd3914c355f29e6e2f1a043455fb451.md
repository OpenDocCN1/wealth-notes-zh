# 守规矩的人，都穷的很稳定

原创　赢在 8 小时之外　2020-11-10 16:26:28

最近我们也在做抖音，我跟团队伙伴是这样说的：抖音就像是快餐店，快餐店老板生产出速食品，卖给大众，自己赚的盆满钵满，然后带着全家人去吃慢餐。

所以，大家的定位一定要清晰，市面上流行什么就输出什么，因为抖音的用户群体就是这样的，千万别给自己加戏，搞什么深刻的、文艺的东西。

至于快餐是不是健康？这可就难说了，这是信仰级别的话题，就像“中医好不好”一样，不能讨论，一讨论准得挨架。

我们作品的播放量大概分布是这样的：2w、14w、100w、200w。规律性非常强，很少有播放量偏离这几个节点的。

我们抽样分析过给我们点赞的人群主页，以及视频结尾的引流，初步判断是，整个 D 音上至少有 90% 的粉丝是假粉丝，跟 X 浪 W 博是差不多的。

所以说，如果你在 W 博上投放推广，你花的 90%的钱是打水漂的，全部都推广给假粉丝了。Dou+是同理。

除了抽样检查，还有一个方法可以判断某个平台的假粉比例：去看明星大 V 的粉丝数以及阅读量、点赞量。

比如很多明星粉丝都是几千万了，某个作品点赞量动辄就上千万，即使是弱智也知道这根本是不可能的。即使是按照 10%的点赞率来算（其实都达不到），那也有一个多亿的人看过他的视频了。

连我们伟大的 xxx 都没有这个推送能力。

不过话又说回来，短视频时代，不通过短视频获取一些流量，也是一种浪费。即使人家只有 10%甚至 1%的真粉丝，那也不少了，够大家去瓜分流量蛋糕了。

我们几个号做的还都不错，我也在 VIP 群分享了一些操作要点和思路。

有个朋友知道了，非要跟我学习。我说，你先复制别人的，或者搬运别人的，做伪原创。

如果你是自己拍摄，就抄别人的剧本和段子，别人怎么演你就怎么演。

他问，这样不会有侵权风险吗？

我说，我就知道你会这样问。当初做公众号的时候，我就说，第一批原始粉丝的积累，大家都是靠各种各样的手段搞来的，比如送资源等等。
