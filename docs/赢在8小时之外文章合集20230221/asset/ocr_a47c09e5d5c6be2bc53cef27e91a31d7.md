# ⑤ 不要参与任何形式的债务。

不要借钱给别人，也不要向别人借钱。

如果有人向你开口借钱，你首先要清楚一点：深陷债务的人，嘴里已经没有真话了。负债的人说的每一句话，你都要当成假话来对待。

如果交情不够的话，直接拒绝就行了。

如果你们的交情还值点钱，就可以把钱借给对方，但是你在心里一定要清楚，这个钱是送给对方的，不指望归还。

这份赠予就算把友谊划上一个句号。

什么？发生债务关系，以后还想做朋友，还想维持原有的亲情关系？你他吗白日做梦。变成仇人的概率倒是很大。

# ⑥ 不深交任何人。

俗话说，君子之交淡如水。

跟任何人相处，都没有必要深交，没有必要互相把对方的家底都了解个底朝天。跟任何人走得太近，都是R一场灾难。

对所有人——伴侣、朋友、老板、同事，要保持 30%的神秘感。这部分神秘感是魅力的源头。逐步释放神秘感，同时提升自己。渐提升的部分，也是神秘感的增量。
