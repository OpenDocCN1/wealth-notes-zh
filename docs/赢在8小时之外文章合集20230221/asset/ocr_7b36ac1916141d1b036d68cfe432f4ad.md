# 边界感一定要大于共情能力

原创 赢在 8 小时之外 2022-10-03 12:00:05

我之前说过一个概念：很多垃圾词汇已经从我大脑词典里删除了，比如道德、面子、情商等等。

因为正是这些词在影响我赚钱、阻止我变得幸福。

我还说过一个概念：一个人的词汇量越丰富，那么他的财富值就会越大，人生就会越幸福。

能完美服务她心的人，万里挑一

这篇文章里提到的“分寸感”，还有今天我要提到的“边界感”和“共情能力”。我一直在公众号里强调，如果你没有金刚手段，尽量不要随便展示你的菩萨心肠。

什么意思呢？

没事不要随便帮助别人、拯救别人。

据我观察，凡是因为帮助别人而闹得不愉快、甚至结仇的（比如把钱借给别人最后成了仇人），原因都是：你已经越界了。

你的边界感太模糊了，而且你的狗脑子被虚无的“共情能力”占了上风。

当你如遣有些人正在闹中深渊，如果你没有金刚不坏之身，就不要随便出手阻拦。

否则你属于越界，属于滥发善心，从某种程度上来说，你是在害人害己。

一方面，你正在剥夺对方“吃一堑长一智”的机会，另一方面，你自己也会被对方拉进深渊的。

比如，你的闺蜜被家暴了，或者婚姻出现问题了，你不要随便参与进去，人家再怎么打也是两口子，而你是个局外人。

我还说过，这个社会上有些精神问题、有暴力倾向的人比例不低，你没事跑过去和弄不好会挨一刀的，而人家可能是特证抓人。

我并非是危言耸听，你去看那些法制节目，很多被害人都是“劝架者”的身份。

一直在撕的“刘鑫案”本质就是如此，面对变心疯狂的闺蜜男友，江歌非要阻拦，非要说服对方。
