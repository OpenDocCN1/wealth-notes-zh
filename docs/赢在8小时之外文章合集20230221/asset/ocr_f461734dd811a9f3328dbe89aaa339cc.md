# 让女人死心塌地的，一定是真金白银

本文只有男性粉丝可见。

让女人死心塌地的，一定是金钱和物质，而不是什么人品，责任，担当，诚实，细节。

这不是鸡汤，这是现实。

当然，女人嘴上肯定会说，钱不是最重要的，人品和担当这些才是排在第一位的。

这么说的人，要么还不成熟，要么就是在撒谎。

雌性基因决定了，她们在寻找配偶时，一定会优先选择那些能给自己幼崽带来安全保障的雄性。

而雄性基因决定了，男人必须出去打拼，必须肩负起养家糊口的担子。

虽然时代不同了，独立女性也很多了，女人可以忘了自己的基因需求，但是男人绝对不可以忘记自己的使命，一旦你的收入不如女方了，那么一段感情也就快接近尾声了。

而在婚姻里，如果男人不是挣钱主力，那么婚姻可能也已经名存实亡了，因为女人感受不到你存在的意义，也不会有崇拜感。

上次我就提到过势差这个东西，任何一段人际关系，一定是势差才能产生吸引力。势差没有了，关系也就破裂了。

所以说，如果有女人私信你，问你现在在做什么，或者说最近在忙什么，你永远都要告诉她，你在认真工作，你在筹划项目。

不论她嘴上怎么说，女人最看中的一定是男人开拓领地、守护家园、养育幼崽的能力。

所以我很少讲技巧，我觉得那些不是男人应该学的。

不管你学了多少技巧，最终一定是实力取胜（哪怕是包装出来的）。

如果你对她特别好，什么都为她着想，天天送早餐，她虽然找不到借口，但是会告诉你，我们只适合做普通朋友。

真正厉害的人，是不谈恋爱这个事情的，他一直在掂量自己的筹码能不能买得起对方。
