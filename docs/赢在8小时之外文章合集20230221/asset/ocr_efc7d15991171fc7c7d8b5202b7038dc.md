# 边际效用（Marginal Utility）

这篇文章里提到了如何提高自己的时间利用率，说白了，就是能同时服务多个人，就不要同时服务一个人。

其实我写的这些东西，很多人 Мель脑子里是有模糊概念的，但是他们不愿意去这样去计算自己的时间值多少钱，因为他们会认为这样太功利，太没人情味。

我想说，如果你是普通上班族，生活在温暖有爱的大家庭里，那你可以不计算，人与人之间都是平等相处。

但是，一旦你脱离了上班族群体，你必须要计算。尤其是当你的收入越来越高时，自然会思考“如何分配时间才能实现利益最大化”这个问题。

无论是煤矿的小老板，还是世界五百强企业的 CEO，他们都会非常清楚自己的一小时值多少钱。

比如比尔盖茨，一小时大概能赚 1 万美元，那么他肯定不会亲自去做廉价的事情，也不会跟收入比他低很多的人一起玩。

除非，他能从这件事里面获得金钱买不到的东西，比如快乐，比如名声。
