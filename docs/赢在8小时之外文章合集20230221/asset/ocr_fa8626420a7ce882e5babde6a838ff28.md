# ① 不生孩子的年轻人要适当惩罚

单身、不生孩子的人，享受的福利会少，甚至会有惩罚性措施，这个并不是天方夜谭，在日本、欧洲等国家已经开始实施了。

比如，匈牙利（发达国家）就有单身税，欧洲其他各国也在积极采取措施。开始是给生孩子的家庭

很多福利，到最后一定是惩罚无孩或者单身的人群。

而发达国家的现状就是我们的未来。

这种现象好不好？

很难说。但是呢，该来的 一定会来。

# ② 提高油价，可以大幅缓解交通压力

最近十几年，我们的私家车保有量处于井喷式增长，一方面能解决底层很多就业问题（加工制造业），另一方面还能带动很多上下游产业，上面还能收很多税，绝对是好事。

但是呢，临界点一定会到来的。

比如今天的新加坡，私家车持有成本极高，但是公共交通比较发达，那么减少私家车的目的自然就达到了。

日本大城市的停车费、车位费也极贵，公共交通也非常发达，所以大城市的白领出行都坐电车和地铁。

我估计，我们国家有 50%的人买车是因为确实有通勤需求，或者需要接送孩子，剩下 50%的车主可能纯粹是为了面子而购买的。

U 君是农村出来的，我非常了解农村人买车（甚至买房）的真实想法。

为了面子，为了攀比，为了结婚需要。

现在在农村，男孩子想要结婚，必须在县城有房，必须得有车。

至于县城的房子一年住几次，汽车一年开几次，这些都不重要，也没人在意。

如果提高私家车持有成本之后，至少这部分虚荣型消费会遭到打压。
