# 不甘心的时候，就是在进步

赢在 8 小时之外    2022-02-18 12:00:00

+   1. 不甘心的时候就是在进步，痛苦的时候就是在成长。
2. 天下人人都说这人不好，但是他对你好，你就得记得人家的好。
3. 我们飞得越高，我们在那些不能飞翔的人眼中，形象越是渺小。
4. 不要把知识和智慧混为一谈；知识教你谋生，智慧令你不枉此生。
5. 等岁数大了，你就会发现，人能用钱买到的快乐，会越随着年龄的增加而越来越少。
6. 再高明的博弈手段，只有建立在你不害怕失去对方的基础上，才能发挥得淋漓尽致。
7. 是骄傲、虚荣、嫉妒和报复，支撑你走到今天。你的成长依赖的是这些负能量，而非天生的善良。
8. 穷人为什么把亲戚关系看得很重？因为在潜意识里，他认为这些亲戚将来可以帮助自己。
9. 原单位离职后，尽量不要回去看望老同事。你说过得好，人家认为你炫耀；你说过得不好，人家当面同情你，背后笑话你。
10. 赚钱就是最大的正能量，赚钱也是最大的厚道。任何人赚钱的姿势都很难看，但努力养家糊口的样子，值得每个人去欣赏。
11. 莽撞地开始， Кры... 抽劣地完成，也好过因为心怀完美主义而迟迟不动手去做。
12. 人和人之间想要保持长久舒适的关系，靠的是共性和吸引。而不是压迫、奉承、一味的付出以及道德绑架式的自我感动。
13. 只有在你工作堆积如山时，你才可能享受闲暇。当你无事可做时，空闲就变得一点也不有趣，因为这时候空闲就是你的工作，而且是世界上最耗人的工作。
14. 承诺这个东西，就是一个骗子哄一个傻子。听的人记住了， 说的人早忘了。所以，永远不要听一个人跟你说了什么，而要看他为你做了什么。毕竟， 说话不需要成本。
