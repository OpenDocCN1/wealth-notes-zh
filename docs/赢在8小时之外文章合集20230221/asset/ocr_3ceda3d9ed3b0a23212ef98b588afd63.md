# 一万小时定律，只是标配而已

原创   赢在 8 小时之外   2022-02-14 12:00:00

上次在群里有人聊奥运会的事情，我也表达了我的观点，我很少关注跟体育相关的任何新闻。

![](bbox=[0.26, 0.178, 0.74, 0.61])

我自己喜欢打乒乓球和游泳，但是对于职业运动员，我真的不想看他们比赛，一眼都不想看。

因为我接触过一些运动员，他们都是从小开始刻苦训练的，即使非常有天赋，再加上后天投入大量的时间进行训练，最终能参加奥运会比赛的也不到万分之一。

中年之后，如果能“混然众人”也还算好的，最怕的是没有得过什么大奖，还落下一身职业病。

当然，如果体育生能做好规划，家里人给做好铺垫，将来去学校里当体育老师，也是一个非常不错的选择。

或者，去各种民间闲散机构做教练，也还算有个好的归宿。
