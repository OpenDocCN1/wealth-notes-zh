# 所谓的自由，就是被别人讨厌

赢在 8 小时之外    2022-03-14 12:00:00

+   1. 人生的一切烦恼都来自于别人的眼光，所谓的自由，就是被别人讨厌。

+   2. 对自己建立信心，对他人和世界放下所有期待。

+   3. 他们诋毁你的力度说明了两件事：你的强大和他们的不安。

+   4. 若是一个人能做到对自己坦诚，就可以无坚不摧。

+   5. 没有什么拼命隐藏的东西了，人自然就放松了，自然也就灵光了。

+   6. 有人不喜欢你，太好了，说明你开始做自己了。而不是一个谁也不得罪、却谁也无法欣赏的庸人。

+   7. 分享一个避免负面情绪的方法：当很多人和事情来临，只是经过你，并不选择让它们留下。

+   8. 喜欢做一件事，和做一件事能让你暂时逃避焦虑和烦恼，是两个不同的东西。

+   9. 由于绝大部分人极其平庸，所以默认忽略他们的想法和建议，才是最正确的选择。

+   10. 如果你朋友的真正实力，能有他在酒桌上所说的一半强大，这个世界就再也没有烦恼了。

+   11. 狗的嗅觉实在太好，能闻出太多的信息。幸好它们还是哑巴，不然它们知道太多，肯定做不了人类的宠物。

+   12. 男人的专一，就是一辈子都爱 25 岁以下的女孩子。不像女人那么善变，年轻时喜欢老的，老了又喜欢小的。

+   13. 如果一件事一个人，让你觉得眼花缭乱，那么大概率是错的、假的、低劣的。最了不起的人和事，都简洁而优雅，朴素到一剑封喉。

+   14. 当你随意张口询问一个人的建议，而并没有思考过他是否有资格回答这个问题的时候，你已经在不知不觉中提高了自己决策失败的概率。

+   15. 自卑是：我这么对你，是因为我想你也这么对我，否则我会觉得很受伤。自爱是：我这么对你，是因为我想这么对你，以及你也值得被这么对待。
