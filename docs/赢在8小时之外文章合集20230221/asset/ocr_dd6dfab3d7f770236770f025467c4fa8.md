# 没有主见的人，会一直迷茫下去

原创       赢在 8 小时之外      2021-08-12 11:53:17

上次我写“借钱”这个话题之后，有个朋友就私信我，说从小到大，他的姐姐对自己恩情很大，现在各自都有家庭了，姐姐家想买门市房，向自己借十几万。

一方面他自己也正在筹划买车，没有额外闲钱；另一方面姐姐是有恩于自己的人，又不好拒绝。

所以就很纠结。

姐姐也很谅解他，但是，姐夫知道没借成这个结果后，已经没有好脸色给他了。

力，至于她怎么想，我控制不了

我把自己的日子过好，至少我爸真要是用钱，我得有钱往外拿。

少给我姐我爸添麻烦，做好自己的工作。

我们的手不能伸太长了
