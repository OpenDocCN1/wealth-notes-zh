# 拥有自信的关键

原创 赢在 8 小时之外 2022-10-27 13:46:58

“潜力”“自信”这些词都很虚，甚至可以归纳为玄学范畴。

一个人到底有多少潜力？自信和自大之间的界限在哪里？

很难量化。

有科学家发表过这样的言论：普通人的大脑还有90%的潜力没被开发。

也就是说，只要多开发10%的潜力，我们的富足程度就会翻一番；再多开发20%，富足程度就会再翻一番……

对于这个理论，我是比较认可的，这样量化我们的潜力，可以把虚无的概念转化成实在的概念，有助于我们按图索骥、一步步向上提升。

或者换一种参考，用金钱来衡量也可以。

普通智商的人，他的潜力本可以实现月入5万元，但是他目前才月入5千元。

这时候，他的提升空间非常大，只要刻意去开发自己的潜能，那么收入翻一番、翻两番还是不难的。

那么问题来了，到底该怎么开发自己的潜能呢？

限制大多数人的瓶颈，还是信心不足，大多数人不相信自己的潜能还有90%未开发。

那么该如何树立信心呢？

我的建议是，你先做成一些赚钱的小事（打工不算），失败不是成功之母，小成功才是大成功之母。

那么如何才能实现“小成功”呢？

我的建议是，赚点小钱（比如日入300元、日入500元），不需要任何信心，你在网上东搞西搞就赚到了，送送糟糕的钱就到了，你还没弄清是怎么回事。

只要你找到了我说的这个感觉，那么你已经实现了“小成功”。

一旦你走到了这一步，你会对“潜力”“自信”这些词网有一个更加客观的认识。

我给大家举个真实的例子。
