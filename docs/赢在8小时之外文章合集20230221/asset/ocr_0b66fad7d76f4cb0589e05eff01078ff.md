# 痛痛快快收钱

原创 赢在 8 小时之外 2022-09-11 15:46:13

昨天有个 VIP 群友跟我说，他的公众号阅读量还不错，就是变现很困难。上周开通了知识星球，但是被粉丝给骂了，说他变了，开始割韭菜了。

我就跟他说：帮人帮到底，送佛送到西。

你如果喜欢做好事，喜欢做好人，那就做到家，不要随便改变风格。如果你想赚钱，就早点把脸拉下来，大大方方收钱，一点都不丢人。

最怕的就是纠结。

比如我，在几年前我就说了，我这个人就喜欢割韭菜，收钱，是一个见利忘义的小人，从来不讲武德。

结果就是，我每年都会搞几个收费项目。比如我会写很多付费阅读文章，还会组织付费社群，付费的知识星球。

另外，在我的带领下，群里很多小伙伴也都开始收钱了，而且一个比一个猛。

那么，有人骂我吗？

非常少，因为我早就把自己定义成唯利是图的商人了，你再来攻击我，说我割韭菜，那就没意思了。

所以，我的评论区是非常清爽的。

那些鄙视我的，会在第一时间取关我，也不会跟我废话。

而那些喜欢我的，会用金钱来支持我。

我觉得这种状态就很好，我基本不会陷入什么纠结的情绪当中。

有些人就很蠢，他们当了表子还要立牌坊。

整天在评论区跟粉丝辩论，想证明自己多么有文化、多么开明、多么道德高尚。研究收钱项目已经够心累的了，结果你还要维持一个“好人”的形象，不累吗？
