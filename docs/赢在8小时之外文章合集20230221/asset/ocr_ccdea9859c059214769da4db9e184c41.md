# 为什么越有钱的人，越抠门？

昨天我在公众号写了

人心是永远也喂不饱的

这篇文章之后，写作群有个朋友问我，说他现在已接触了「不做免费服务」的思想，但大学期间有个人来寻求帮忙，自己要不要做无偿帮助别人的事情？

![](bbox=[0.249, 0.278, 0.751, 0.668])

我就跟他说，你如果觉得融入集体感觉很温暖，很幸福，那你就得跟随大家的价值观，互相帮助，团结友爱。

顺着这个思路走下去，将来你就去找一个公司去上班，然后在公司你要继续学习集体文化，与同事和睦相处，与上级搞好人际关系，当然也可能会遭遇办公室政治，得学会站队。

不过呢，在zg做一个平凡的普通人，是非常不爽的。
