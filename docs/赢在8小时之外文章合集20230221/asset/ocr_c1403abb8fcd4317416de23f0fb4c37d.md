# ① 我几乎不吃路边摊

中国的每个省份我都去过，也在不同的城市生活过，TS 是我停留时间最长的。

所以，出现 TS 烧烤店事件，我一点都不觉得奇怪。

我上高中的时候（2006 年前后），我们那里有两个特色：

一是经常有黑帮火拼，一群光着膀子的纹身男，手持砍刀或者棍子在大街上跑，互相追打。

二是大白天有很多街道的角落，你一路过，就会有女人向你招手，并且大声说：进来玩会吧。

一点都不避讳。

至于路边摊，啤酒+烤串这些亲民的小吃，我去过的次数屈指可数，25 岁之后我就从来没去吃过了。

有社会学家调查过，说人这一辈子，平均会与 36 名杀人犯擦肩而过。

这种数据准不准我不知道，但是在我的脑子里，数据大概是这样的：有 10% 的人有精神类疾病，有 10% 是刑满释放人员、罪犯或者有犯罪倾向。

而网吧、KTV、酒吧、啤酒烧烤摊这些场所，罪犯的比例会比正规餐厅、博物馆、图书馆这些场所要高很多倍。

小城市尤其。

因为在北上广这种大城市，罪犯根本生活不下去，因为成本太高啊。

但是小城市就不一样了，即使自己没有工作，每天睡晌悠也饿不死，所以闲散人员、有犯罪倾向的人员密度就高一些。

所以，如果你在小城市生活，一定要注意周围环境。

公务员小区，教师职工小区，国企职工小区，相对来说治安就好很多，素质也高很多。

至于路边摊（尤其是 melden 酒销售）这种地方，没事尽量少去。

女人晚上不要单独出门，不要穿得太暴露。
