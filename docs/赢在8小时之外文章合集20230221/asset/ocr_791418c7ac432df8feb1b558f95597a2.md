# 跟别人倾诉苦难，就是在鲨鱼面前流血

原则　　赢在 8 小时之外　　2021-05-12 20:12:27

在所有私信我的消息里面，很大一部分都是在抱怨，在倾诉，要么就是自己现状太惨，要么就是遇人不淑。

我对于这类消息，都是扫一眼就删除了，因为我可不想被你的负能量侵袭。

我的生活本来是很愉快的，但是你们总向我投掷精神垃圾，我肯定得躲开，我才不愿意做树洞角色。

没有人愿意做树洞，甚至包括最亲近的父母。

昨天城都中学坠亡事件刷屏了，今天是 512 地震 13 周年，有很多灾难重现的讲述和纪念。

这些我都是扫了一眼立刻就关闭了，你可以说我冷血，但是我真的没有消化负面新闻的能力和时间，我玩不起了，我都 31 岁了，你让我今天怜悯这个，明天为那个伸冤，那我不用干别的了。

其实，我的父母都经历过 76 年的唐山大地震，他们也给我讲过当时的经历。我小时候也经历过各种校园暴力和老师的暴力，那又能怎么样呢？我每天就自怨自艾，每天到处诉苦、去寻求安慰吗？

最近 VIP 群里，大家也交流了很多化解负面情绪的见解，我觉得收获还是很大的。

其实呢，喜欢抱怨，喜欢倾诉负面情绪的人，是没有福报的，能量场也会越来越弱。

这不是迷信，而是有依据的。

但凡是幸福的人，或者是富有的人，都是特别在意自己的能量场的，他们不会轻易让负面情绪入侵。

如果你散发出来的都是负能量，他们绝对会躲得远远的。而你吸引到的，也都是失败者，然后你们一起大吐苦水，一起顾影自怜。
