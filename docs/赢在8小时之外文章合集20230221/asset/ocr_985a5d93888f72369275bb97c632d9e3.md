# 牛人的世界，没那么多意外和惊喜

又到了一年一度的十一长假，等到假期过后，我预计会出现两件事：

+   ① xx 会继续在各地爆发
② 旅游欺诈事件依然会遍地开花

几乎每年都会出现导游欺诈甚至勒索游客事件，而视频在网上曝光之后，网友也都是一窝蜂地谴责导游，说他们太可恶。

而我却不这么认为，我虽然不支持导游的这种做法，但是我认为大部分“被欺诈”的游客也都不是什么好鸟。

报团旅游这件事，其实是有两个极端的。

有的人报团，会提前问导游，有没有购物环节啊？要是有购物环节的话就不报了。

反之，有的人报团会专门选择有购物环节的路线。

有一年我去法国旅游，由于在巴黎的行程发生变化，不得不取消某些景点，于是导游决定取消“老佛爷百货商店”半日游。

于是大家就开始提出反对意见了，说景点可以少去一个，但是购物环节一定不能少。

导游也很好说话，既然大家的意见都一致，那就继续去老佛爷，其他景点压缩一下就行了。

为什么会这样？

因为很多人出国旅游，是有购物任务的：自己需要买衣服、鞋子、包包、手表、化妆品，有的还会给家人朋友带。

国内 3 万元的包包，那边可能就卖 1 万 8，国内 8 万元的手表，那边可能就卖 5 万，而且还没有“搭售”等各种恶心的套路。

如果恰好有需求，那么去国外购物确是一件非常划算的事。至于那些反对购物的团，一般是国内或者东南亚的低价团。

比如那些曝出来导游威胁游客的视频，我猜肯定都是低价团，甚至是零元团。
