# 赚钱最怕“着相”

原创 赢在 8 小时之外 2022-08-27 14:08:51

我在朋友圈经常发各种购物体验，买了一件 T 恤，买了一个包，买了一块表，买了一双跑鞋，甚至买了一个保温杯，只要我觉得对大家有帮助的，我都会晒出来，供大家参考。

上周我发了一条朋友圈，我说在所有的运动鞋里面（包括奢侈品），阿迪 boost 系列和彪马 RS 系列的鞋底是最舒服的。

U君
在我穿过的所有运动鞋里面，阿迪ultra boost系列和彪马RS系列的鞋底最有“踩屎感”，超级软，跟其他运动鞋的鞋底是有本质区别的。

喜欢穿软底鞋的人如果不知道怎么选运动鞋，可以直接去专卖店里试穿这两个系列，款式有很多种。

阿迪boost的鞋面比较紧，包裹感比较强，彪马rs的颜色选择比较丰富。
