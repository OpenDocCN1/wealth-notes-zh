# 不要享受占便宜的感觉

原创  赢在 8 小时之外  2022-09-18 12:00:39

从小到大，我老爸最喜欢计算商品的成本和利润了。

比如，一盒包装很精致的月饼，售价 50 元，他会说，里面的月饼成本也就 5 元钱，其余的都是包装、运输等成本，太不值了，还是吃散装的月饼实在。

但是呢，散装的便宜月饼，很可能有食品安全问题，没准会吃到一支苍蝇腿……

我很早就发现他的这套逻辑有问题，只是不知道问题出在了哪里。

进入社会之后，我特别喜欢观察其他老板的行事风格，我自己也会反思很多事情。

比如，我买东西就不喜欢讲价，如果我觉得这件商品确实很好（我有甄别能力），而且正好能满足我的需求，那么我一般不会讲价的。

服务也是如此，比如我去西藏这些地方，都会包车，找当地的向导，氧气瓶等装备我都是从他们那里买，而且各种费用我都不会跟他们讨价还价的。

我知道，如果我把每样服务都跟他们压价的话，整体能省下来两三百元，可那又能怎么样呢？

让他们多赚几百块钱，他们心里高兴，自然也会用心为我服务。

一次愉快的体验，一次美好的记忆，比几百元钱重要多了。

而且，如果服务非常好，事后我还会主动给向导发个 66 元或者 88 元的红包。

其实现在很多服务都是可以发红包的，只是大家意识不到而已。

比如用软件打车，服务完成后可以发红包；用软件预约安装空调，服务完成后也可以发红包。

只要服务到位，我一般都会发个红包，算是给师傅的辛苦费。

而大多数人是怎么做的？

他们在买东西的时候会说：

> “我知道你的成本是多少钱，我必须压价，不能让你赚太多。”
