# 如何处理办公室政治？

原创 赢在 8 小时之外 2021-08-04 14:19:56

昨天有个私人信我，说了一堆他办公室的故事。

大概意思就是，这里都是人精，每天都是互相争来争去，尔虞我诈，心累。

自己本来是个实在人，平常有啥说啥，结果来办公室工作一年多，感觉每天都是在上演宫斗戏，必须得戴着面具生活。

从小到大被教导的那些美好品质，在这里都发挥不出来，而且还会被同事嘲笑自己是傻子，太幼稚。

比如，答应别人的事，自己一定要履行承诺，但是在同事们看来，诚信不是最重要，而要时时刻刻权衡利弊。

这个事对你有利，你就去做。这件事对你无利可图，那你就别去做，即使答应好了，该变卦也要变卦，形势比人强，这才是生存之道。

然后他就问我，难道现实社会就是这样吗，所谓的美好品德都是骗人的？

我就跟他说，如果你处在一个恶劣的竞争环境中，那么所有的体面、善良、优良的品德、遵守契约、服从原则都将成为你的竞争劣势。

只有在优质的环境中，你的道德品质、契约精神，才可以为你树立名声，积累信誉，长久坚持下，它们可以构成你的核心竞争力。

在很多办公室环境里，打工者想要生存下去，需要见机行事、结党营私、处处钻营、对上迎合、对下打压等等这些手段。

否则，你根本活不过三集，甚至一出场就被秒杀了。

我也打过几份工，也深入观察过办公室政治。我发现很多混得好的打工者（尤其是体制内），他们就像是《编辑部的故事》里的老刘和牛大姐，事后诸葛亮，要小聪明，贪小便宜，倒打一耙，时刻把自己放在道德制高点。

他们总会有办法让一个道德品质高尚的人背下所有的黑锅，小人永远是得志的。

所以说，如果你想要体面的生活和工作环境，你必须想尽办法争取进入更好的环境中去。

俗话说，有人的地方就有江湖。
