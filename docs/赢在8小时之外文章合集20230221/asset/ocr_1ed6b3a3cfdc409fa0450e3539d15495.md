# 富贵险中求？

原創  赢在 8 小时之外  2022-07-28 12:00:38

经常有人咨询我，说知乎上 xx 类的内容最受欢迎，抖音上 xx 类的内容容易上热门……

但是呢，自己又不是很擅长那个领域的内容。

这时候，该不该去学习那些内容，主动去迎合平台，然后获得流量扶持呢？

这个问题其实非常典型。

我自己的宗旨是：尽量不要把“迎合平台、迎合趋势”放到第一位。

不要总想着什么样的内容发出来能火，因为那些“能火”的内容，可能距离你的价值本身和变线路经差了十万八千里。

比如，在 B 站、抖音上做影视搬运和剪辑，在知乎上写鸡汤或者扎心文案，可能是容易上热门，然后涨粉丝。

那又能怎么样呢？

你可能会获得平台的一些扶持，涨了一些粉丝，赚到一些广告费，仅此而已。

长期来看，这些事对你自身价值的提升、对你个人影响力的加持，没有太多帮助。

弄不好过一段时间严打，直接就给你封号了。

我为什么不做抖音？原因之一就是，我不想把自己的命运交到平台手上。

让平台定夺下一条内容的热度，这种感觉很不爽。

反之，如果你深耕某个领域（在尊重客观市场规律的前提下），不去在意那些所谓的“趋势”，你的个人影响力、变现能力一定会越来越强的。

当然，如果不谈价值、不谈成长，仅仅是赚钱的话，迎合趋势也不是不可以。

但是这种钱必须要快，要多。

因为这是以牺牲个人成长、牺牲个人影响力为代价的。

其实普通人跳槽也是同样的道理。
