# 你读了那么多书，为什么依然很穷？

原创    赢在 8 小时之外    2021-07-27 15:02:47

昨天 VIP 群里，有个群友私信我，说她经常帮别人解决专业问题，但是不好意思开口收钱，怎么办？自己付出了很多精力，但是没有任何回报，觉得太亏了。

自己专业水平还不错，也读过很多书，但是感觉读过的书并没有解决人生中的实际问题，只能让自己有份还算不错的薪水。

我说，既然你加入我的群了，我就要跟你讲赚钱的思维，而不是扯感情、道德、文化这些东西。

我自己现在读书，都是为了卖书。

很多人声称自己喜欢读书，学历也很高，但是我知道，这帮傻鬼读的书毫无意义。

什么才是有意义的呢？卖书。

也就是你把书中的概念、专业知识卖出去。

让别人为你输出的价值买单。

养成一个“看”的习惯，其实是一种消费的习惯。大部分人所谓的“读书”，本质是消费了你的时间，消费了你的精力，最后你自然就穷了。

聪明人是不消费的，或者说，外人看起来他在消费，其实他是在投资。更多的时间里，他都是在卖。

# 你一旦养成“卖”的习惯，别人就会被你培养成“买”的习惯，于是你就开始盈利了。

这句话非常有杀伤力，大家可以细品。

所谓的有钱人，其实就是天天卖的人。每句话、每个字，都是为了卖，而且每天思考和研究的，也都是卖。

很多人之所以陷入了人生困境，就是因为他脑子里塞得垃圾信息太多了，甚至连合理的诉求他都不敢提。

结果就是，自己越活越贱，越活越不值钱。你把宝贵的时间和精力都散出去了，也没人说你好。

我之前说过一个观点：你想让别人从你这里获取点什么，你必须让他拿出点什么来交换。
