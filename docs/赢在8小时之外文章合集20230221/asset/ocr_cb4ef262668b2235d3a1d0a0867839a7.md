# 杰克马又翻车了？

偶然间看到杰克马的一个新闻，下面评论竟然都是喷他的。

我很少关注这些人的新闻，我也不知道为什么他又落下神坛了。

但是我能确定的一点是，今天踩他的人，跟当年叫他爸爸的人，是同一批人。

在 xx，底层的人最擅长做的事就是捧神和杀神。

因为他们没有自己的思想，无时不刻都是在被别人当枪使。

所以呢，在 xx，任何一个现在被夸上天的人，到了明天都有可能被踩在脚下。

当然，只有一个人不会出现这种情况，那就是俱乐德。

其他任何一个人都有可能会遭遇这种翻车的情况。

其实呢，人都是两面性的。一直在公众面前呈现出高大上的形象，也很累的，下来了解他的心里没准也很轻松呢。

你看另一个小马哥，和 S 王莹这种商人，基本不在公众面前露面，被别人骂他们是用游戏残害青少年的罪人，人家也不反驳。

我本来就没打算做你们穷鬼眼中的“好人”，你们爱怎么说就怎么说好了。

谁才是更有智慧的人呢？

说到做坏人，我还想再聊聊在国企或者某些职场上，做“坏人”的好处。

在某些特定的公司或者单位，晋升的都是有背景的人，当然人家工作能力和努力程度这方面也不差。

其他没有背景的人，无论你努不努力，是 100% 不可能晋升到好的岗位的。

这时候，不如就做一个“坏人”。什么活都不积极，没事就搞副业，自己赚钱。（当然得给领导分一部分，这点永远不能忘）

这种人活的是最洒脱的，而且其实也不会遭人嫉妒。
