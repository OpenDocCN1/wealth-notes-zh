# 底层的道德，跟富人一点关系都没有

原创　赢在 8 小时之外　2020-10-04 11:25:47

道德规范，一般来说都是给穷人定的。

比如，坐车是否让座，排队购物是否谦让，遇到跌倒的老人是否要扶起来，遇见歹徒是否见义勇为，娶媳妇要给多少彩礼。

这些最底层的道德，跟富人一点关系都没有。

另外，穷人和富人的价值观排序不同：穷人首先考虑的永远是感情和面子；而富人首先考虑的永远是利益。

穷人最喜欢让自己的孩子学习技术，然后将来找个好工作，为富人打工；而富人教给孩子的，是赚钱的手段和思维，以及如何操纵别人的时间和剩余价值。

穷人为什么穷？就是因为他们把所谓的“道德”当真了，殊不知，这些所谓的“道德”都是为底层的穷人设计的，就是为了让你落入这个框架里，永远没法翻身。

穷人把道德奉为人生宗旨，时不时就自我感动一下。而富人把道德当帽子，结果善良的人变成了穷人，不择手段的人变成了富人。

如果你仔细想想，一切框架和限制，其实都是对老实的穷人不利，而为精明的富人减少了竞争对手。

就连神圣的 F 律，基本上也是限制穷人的。因为富人会想尽一切办法钻 F 律的空子，确保一切的不择手段，都是在合 F 的前提下进行。

当然，我说这些，并不是想让大家都成为坏人，去做坏事，去变得不善良。

之前有个傻屌朋友，每次喝完酒就跟我滔滔横流，说他不赚钱就是因为太善良了，找不到女人也是因为太老实了。

我说，就你那狗脑子，如果搞阴谋诡计的话，你就直接进去了。人啊，如果没有自知之明，真的很恐怖。

如果你很穷，首先要做的，就是放弃对任何人（包括自己）抱有道德上的洁癖。这个世界上，每个灵魂都半人半鬼，凑近了谁都没法看。

道德，在有的人手里，就是束缚自己的枷锁；而在另一部分人手里，就是收割韭菜的镰刀。
