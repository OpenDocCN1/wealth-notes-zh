# 人生，是隔离的艺术

不要听他们说话，不要给他们机会接触你，否则你的命运会受到他们的影响，身体会变差、思维会变得更加混乱、情绪会更加负面、收入会直线下降。

据我观察，一个人经历的大多数灾难，都是愚昧的人带来的。

人生是隔离的艺术，也是靠近的艺术。

如果真想跟别人社交，想交朋友，一定要靠近幸福的人。

幸福的人也会给我们带来幸福，这是世界上最简单的经济学。

别看我平时写东西很冷血，我对幸福的捕捉还是非常敏感的，有些人吐出一个字，发一个朋友圈，我就能嗅到这个人是不是幸福。

尤其是女人，没事千万别跟那些家庭不幸福的人在一起玩。否则的话，慢慢你会发现，她们家里的那些不幸，你们家都有。

很多女人都是怎么离的婚？你的好闺蜜离婚了，而且变成了怨妇，每天都抱怨前夫有哪些坏毛病，有哪些不够专情的地方，所有男人都靠不住。

你听多了，回家之后也会观察自己的老公，然后发现他也有这些毛病，然后时间长了，你也离婚了。

因为你的闺蜜很可能是个嫉妒心极强的人，自己掉坑里也要把身边的人拉下水：凭什么你过得比我幸福？
