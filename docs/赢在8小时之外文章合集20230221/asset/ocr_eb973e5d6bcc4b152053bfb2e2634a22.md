# 穷人永远熬不过“冷水期”

原创 赢在 8小时之外 2022-12-18 20:12:27

最近我发现一个问题，很多人之所以穷，就是因为他从来不做“正事”，永远上不了“正轨”。

一旦累了正事、正轨站边了，他们一定会找借口，最终把自己继续搞到副路上、沉浸到烂人、烂事、烂情绪里不能自拔。

不信你去观察，凡是那些没有家庭、月薪不到一万的人，他们整天在谈论什么。

他们谈论剧情，谈论世界杯，谈论汽车配置，谈论保险，背后议论别人，上班偷懒，到网上抬杠，跟家人偶尔子扇，计算小钱……所有这些不值钱的套路，他们都是无师自通的。

总之呢，一个值钱的正事都谈做过。

即使你拿着棍子抽他们，让他们去做正事、让他们去收钱，他们仍然像脑瘫一样不动弹，反而不注意就闹到了烂人烂事里。

为什么会出现这种情况？

我总结，有一个重要的原因是：

穷人永远不会去做正事，即使做了正事，也熬不过“冷水期”。

“冷水期”这个概念是我提出来的，之前也写过很多次，今天再重讲一下。

大家可以想象一下这几个场景：场景一：

下定决心要挣钱，必须去大城市闯荡一番。可到了大城市就会发现，自己一无是处，连份像样的工 作都费劲。

这时仿佛一盆冷水浇在了自己头上，心魄时凉了一大截…… 场景二：

不知道咋赚钱开咖啡店/水果店赚线，于是投了几十万，租店铺、搞装修、雇员工……

好不容易开业了，发生生意非常惨淡，一个月过去了，才成交几十单，这时依然自己又被浇了一大盆冷水……
