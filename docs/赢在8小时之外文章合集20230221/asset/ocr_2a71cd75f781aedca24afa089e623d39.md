# 所有的人际关系，都会结束

原创   赢在 8 小时之外   2020-06-25 22:08:09

昨天有个老同学联系我，说他买房了，而且收入比之前已经高很多了，特别感激我：

![](bbox=[0.28, 0.18, 0.72, 0.73])

我想，我是不是太坏了？之前鼓动过很多人跳槽（大部分都是我的老同学），好在，大多数人收入都有了明显的提升，也算是一点功德吧，就是有点对不起他们的前老板了。

不过，帮别人提高收入，我已经没有太大成就感了。能帮人向上一 个阶层跃迁才是最有意思的，就是成为自由职业者或者创业者。但是呢，这是一把双刃剑，只要不老老实实上班，风险就全都担在自己身上了，能不能驾驭，就得看自己的修为了。
