# 动底层人的观念，如同挖他的祖坟

原创　赢在 8 小时之外　2021-05-27 12:25:28

原来我在国企的一个同事，在微信上私信我，跟我讲了一大堆公司最近发生的事情，大概意思就是，自己任劳任怨这么多年，才熬到一个技术员，当年跟自己一起进来的同学，很多都有一官半职了。

我跟他说，当年我在公司上班的时候，只要不是特别抢手的职务，都是明码标价啊，你只要找对中间人，然后把钱准备好就行了。

然后他跟我说，他舅舅认识人事处处长的秘书，一直让他帮忙上心，但是一直没有结果。

我就说，如果你的亲爹是人事处处长，这点面子还好使。

除了这种直系亲属的面子，其他的都不好使。该砸钱的时候就得砸钱，毕竟在 zg 有一万种合法送礼的方法，传承了几千年的 power-money 交易文化，你一点都不尊重。

其实，不论是在国企，还是体制内，还是市场化的社会上，求人办事的时候，千万不要指望谁的面子。

这年头，谁的面子都不好使，你要是真想把事办成，就把它当个生意来做。你计划多少钱买到这个结果。

只要你这样去想，哪怕谁都不认识你，你都可以把事办的很漂亮。

反过来想，你就会清楚，根本没有必要维持那么多无用的关系，把精力放在多赚钱上就行了。

当然，对于我的这种回答，他是不满意的，他总想绕开真金白银，去用虚的东西换取别人的宝贵资源。

他永远也不会理解，资源分配者，之所以能坐到那个位子，付出了多少真金白银，甚至几代人的心血和苦熬。

你所谓的“面子”才值几个钱？

后来我就反思了，我不应该跟他说这些。如果他能听进去，也不至于混这么惨。

我经常说，一个全日制本科毕业的男人，在没有家底的情况下，如果到三十岁，还拿几千块、万把块钱的工资，一定是哪里出了问题。
