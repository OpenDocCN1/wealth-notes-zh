# 经济基础决定了你的阅读能力

原创 赢在 8 小时之外 2021-08-07 13:46:41

前天，VIP 群里的一个朋友问了我一个问题：你的这些思考和想法都是从哪里来的？

![](bbox=[0.236, 0.182, 0.762, 0.652])

我读书、我的大脑摄入信息，都是功利性的。

也就是说，我只学习那些能帮助我赚更多钱的知识，只跟能让我赚更多钱的人交流。

所以，我不推荐穷屌丝每天利用业余时间去读书，去学外语，去学吉他，去旅行等等。

你要知道，限制你突破人生瓶颈的因素，不是读书不够多，而是你的经济基础限制了你的阅读能力和理解能力。

在你的阅读能力很低的情况下，你拆腾再多，也没有任何意义。比如，你让一个普通的打工人，下班就去图书馆，让他每天必须读一本书，你看看他的收入会不会提升。
