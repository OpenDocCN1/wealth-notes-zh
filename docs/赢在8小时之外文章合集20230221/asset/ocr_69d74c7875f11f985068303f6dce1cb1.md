# ① 恐惧导向和希望导向。

其实人类的所有活动，要么是被恐惧支配的，要么就是被希望引导的。

比如，有的人结婚，纯粹是因为恐惧和压力。身边的人都结婚成家了，自己的父母又总是催促，那么自己就稀里糊涂地结婚了。

但是，有的人结婚是因为他看到了希望，他知道两个人一起生活，能共同创造美好的生活，两个人过比一个人过好多了。

那么这两类群体，将来的幸福指数，肯定是天壤之别。
