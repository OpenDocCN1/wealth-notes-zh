# 成年人学东西，快速入门很重要

原创 赢在 8 小时之外 2022-07-16 12:00:13

大概在 4 年前，我跟一位画家朋友学过十几个小时的油画，当时就是想培养一个爱好。

我觉得那位老师教的很好，至少经过这十几个小时的学习和实操，我能独立作画了，主要画抽象一点的画（因为不需要素描基础）：

![](bbox=[0.23, 0.235, 0.76, 0.52])

这些画，唬一唬外行还是没问题的。

我把这些画挂在家里，朋友来了都会问：你这幅画从哪里买的？

我说是花 1000 块钱从一个画家手里买的。

没有人会怀疑，毕竟大家都是外行，根本看不出什么名堂。

最近我又开始画画了，我的计划是，每个月画两三幅，每画一幅需要 1-2 小时。

另外，以后有机会我还会继续跟着画家朋友学习的。

而且，关于画画，我还有 3 个感悟，跟大家分享：

+   ① 画画是个体力活。

坐在椅子上两个小时，全神贯注拿着笔在画布上涂抹，其实并不轻松。
