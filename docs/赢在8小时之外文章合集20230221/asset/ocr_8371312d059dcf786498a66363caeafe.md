# 警惕那些劝你吃苦的人

原创   赢在 8 小时之外   2022-05-04 12:00:00

网上有一部分很奇怪的群体，他们喜欢说这样的话：

现在的价值观真是扭曲了，明星和网红们赚的盆满钵满，大肆地挣钱，但是那些默默无闻的科学家呢？可能还过着非常普通、甚至非常拮据的生活。

应该颠倒过来，给科学家开高薪，限制戏子们的收入。

发表这种言论的人，要么蠢，要么坏。

要知道，现在是市场经济，一切都是优胜劣汰，适者生存，谁的能耐大，谁的知名度高，谁能惠及的人多，谁的收入就越高。

一个明星，或者网红，他们能给上忆人带去欢乐，这个还不值钱吗？

太值钱了。

在物质充裕的时代，精神食粮比物质粮食更稀缺。

虽然我很少看娱乐或者综艺的东西，我也不看网红直播，不看各种类型的体育赛事，但是我知道他们都是非常有价值的。

至于科学家，你以为给他们开高薪，他们就能研制出来有竞争力的芯片？就能研制出来有竞争力的医疗设备？就能开发出来有竞争力的药物？

太天真了，你把所有科研人员的收入提高一万倍，他们也研究不出来。

反而这些钱可能会落入管理内行的外行人腰包里，你懂的。

还有些大人物，最喜欢宣扬“吃苦耐劳”文化。
