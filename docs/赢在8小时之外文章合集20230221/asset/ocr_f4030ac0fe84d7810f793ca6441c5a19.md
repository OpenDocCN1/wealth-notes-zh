# 智商很高，但是收入很低怎么办？

原创   赢在 8 小时之外   2022-07-31 12:00:42

智商很高，但是收入很低怎么办？

我之前说过一个观点：如果你是全日制本科毕业的大学生，到了 28 岁、30 岁还拿几千块钱的薪水，那真的是愧对你的智商了。

不论你的本职工作收入是多少，至少在互联网时代，社交媒体时代，你必须得在网上多搞几份收入来源。

否则你看那些初中毕业的大 V 网红们在网上敛财，你真的不眼红吗？

不过话又说回来，智商和学历的重要性，往往是被高估的。

我就拿写作这件事来举例子。

我每天拿出一个小时的时间来运营公众号，写写文章，发发知乎，至少也有 1000 元的收益（老粉丝都知道我所言非虚）。

那么，这件事跟智商、跟学历、跟文笔有关系吗？

关系很小。

我经常收到过类似这样的私信：U 君老师，我是北大中文系毕业的，在 xx 期刊发表过很多篇文章。现在做 xx 类型的自媒体，但是阅读量很低怎么办？

我觉得这种类型的问题很常见，这些人有学历、有智商、有文笔，但是缺乏网感、引流能力、吸引眼球能力、分析市场需求能力和变现能力。

比如，大家在我公众号里看到的是，每篇文章有两三千的阅读量，每篇付费文章有百八十人付费阅读，这些都是表象而已。

大家看不到的是：我每周都会在知乎里写出一篇爆款回答，阅读量几十万，而且我还会在里面加上软文，向这个公众号引流。
