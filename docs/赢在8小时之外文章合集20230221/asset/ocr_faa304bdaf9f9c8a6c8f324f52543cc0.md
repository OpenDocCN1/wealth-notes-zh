# 屑丝心中的 3 座祖坟

原创 赢在 8 小时之外  2022-10-30 14:35:29

长期关注我的朋友应该清楚，添加我的微信好友是要付费的。

一方面，我的精力确确实有限，如果免费开放，每天都会有几十条私信，如果一一答疑的话，几个小时就没了。

如果怠慢了某个人，还会被骂：你装什么装？看把你牛的，给你发一条信息几个小时都不回复。

另一方面，我已经好几年不跟免费用户打交道了，我决不允许免费用户的文字、声音、面面进入我的大脑，一点都不行，否则我会恶心很久。

我也よ可能给他们任何建议，否则就是在培养懒人。

多么痴的领悟。

我也是农民娃，是樱居丝出身，我非常理解这个层次的人的发展瓶颈是什么。

我总结，穷人有 3 座“祖坟”，既是自己的精神支柱，也是限制自己发展的瓶颈。

# ① 长期的仇恨意识

对于有任何仇恨意识的人，我都是远离的。

他们恨日本鬼子，恨韩国棒子，恨菲律宾猴子，恨美国佬，每天就喜欢看这些国家的笑话。

日本发生地震了？恭喜！

韩国发生踩踏了？真好。

……

当然，他们也仇视一切富人，认为他们的钱都不是好来的，都是剥削穷人得来的。

马云被收拾了？大快人心。

刘强东被起訴了？活该。

这些人只有每天生活在仇恨当中，睡觉才会安稳，甚至做梦都会笑醒。

对于这类人，我们千万不要有一丝一毫的可怜，更不要试图提醒他们、拯救他们，否则他们会觉得你在拧他祖坟，他们会跟你拼命的。
