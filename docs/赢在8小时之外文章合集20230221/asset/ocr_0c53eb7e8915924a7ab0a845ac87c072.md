# 如何在 30 岁之前，找到自己的天命？

昨天有个人私信我，说了一大堆他的故事，总结一下就是，自己喜欢 A 行业，但是呢，由于父母的干扰，或者说是迫于财务的压力，只能选择了 B 行业。

自己马上就要奔三了，他仍然觉得不应该做这个 A 行业，不喜欢的工作，工资高一些又有什么意思呢

？

而且，他一直坚信，如果从事自己喜欢的行业，后面爆发力肯定会越来越大，幸福感和成就感也不可同日而语。

另外他还说了很多对自己生活的不满，简单来说就是，本来每个决定都应该倾听自己内心的声音，结果他每次都妥协了。他觉得是父母太强势的结果。

我说，人不要把自己活得像个落难者一样，到处去诉苦。你的经历，在别人那里，也只是个故事而已。你要相信自己有改变的力量。

成长，本来就是一个孤立无援的过程，千万不要指望外界的扶持和帮助。真正的人生瓶颈，只能靠自己去突破，连父母都帮不上忙，更不用说别人了。

所以说，人必须自己强大起来，沉着冷静地找到自己的定位，找到自己的“天命”。

大多数人，因为害怕未知，还有就是向大众妥协，导致终生没有找到自己的天命。

其实呢，如果人能找到属于自己的使命和定位，那么一辈子工作起来都不会觉得累，不会觉得烦。

同样是打工的话，如果一个人喜欢做这份工作，那么就像找到喜欢的伴侣一样，无论怎么折腾都会觉得很开心，不会觉得累，还会感觉很幸福。

如果找不到喜欢的工作，每天上班第一件事，就是盼着早点下班，苦熬。

如果是那种工资跟绩效挂钩的工作，那就要了命了，你会为了多赚点钱，拼命干活，不舍得下班，最终把身体健康给搭上了。

所以说，你想做什么，一定要尽早去尝试，千万不要想着等赚够多少钱再去做，因为那时候可能你的好奇心、积极性已经被消耗殆尽了。

另外，如果你妄想在收入上获得安全感，那么你永远也不会有安全感。
