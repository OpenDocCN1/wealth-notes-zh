# 为什么我从来不相信人品

如果细究起来，所有的这些美好的东西，在金钱和权力面前是不堪一击的。

所以呢，这就引出了第二个原因，为什么两类人没有交集。

下面我要说的东西，比较冷血，比较扎心，适合男人看，不适合女性阅读。

在这个世界上，只有一种人，他永远也不会被骗，永远也不会经历绝望和失落，那就是在人品和人性的选择上，永远选择人性，而不是人品。

如果你看不透这句话，那么人性的贪婪、自私、无情，会让你防不胜防，被伤的千疮百孔，然后还要抱怨命运的不公。

我有时候看别人的签名，或者发的朋友圈，如果他在说：对待父母要孝顺，对待朋友要知恩图报，选择爱人要三观一致，看人首先看人品……之类的话，我就知道这个人混的肯定是很悲惨。

因为本质上，人品、道德，是完全不存在的东西。

一个人在顺风顺水的时候，他可以声称自己有各种各样美好的品质。但是一旦他陷入被动的境地，或者他的贪欲、嫉妒心等人性被唤起，那么他会变成一个满嘴谎言的恶人。

久病床前无孝子，久贫家中无贤妻，人穷闹市无人问，富在深山有远亲。

你如果喜欢通过“人品”“道德”来观人，那么我想告诉你，所有的这些都是面具而已。

所有的标榜和表演，都是为了更好地满足自己的生存需求和繁殖需求。

如果你是女人，你碰到一个男人，口口声声说他自己人品好，每个观点都跟你三观一致，那么原因只有一个：他想得到你的身体。当然也可能是骗钱的，如果你收入钱多的话。

如果一个老板，招聘员工时喜欢说“先看人品再看能力”，公司文化就是“先做人后做事”，那么只有两种情况：要么这个老板非常坏，他会想尽办法压榨员工；要么这个老板非常傻，他的公司很快就会黄了。

如果一个 xx 每天都宣传自己高大上的形象，那么你要小心了，他已经把镰刀磨好了。如果你足够智慧，冷眼旁观的话，你就会发现，数以亿计绿油油的韭菜们，心甘情愿地把脖子伸了出来，等待 xxx 的收割。
