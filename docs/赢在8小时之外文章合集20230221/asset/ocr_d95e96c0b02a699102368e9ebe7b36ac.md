# 你付出很多，却一无所获？

原创　　赢在 8 小时之外　　2020-10-20 12:41:31

一个女人抱怨，自己的几年青春时光都给了那个男人，最后他却跟别人结婚了。

一个男人抱怨，自己把女朋友照顾的无微不至，投入了全部的感情，最后她还是嫁给了一个比自己富有很多的男人。

一个员工抱怨，自己为公司尽心尽力，而且从来不敢得罪任何同事，他们有事的时候自己都是第一个帮忙的，但是到自己落魄时，他们都离自己远远的……

这三个人聚在一起，开了一个伤心派对，然后就互吐苦水：为什么我们付出了这么多，却一无所获？

原因是什么？

因为这些蠢货把所谓的“感情”看得比物质更重要。

因为你的愚蠢，人家就用一些虚无缥缈的东西，兑换了你的真金白银，你的青春，你的生命。

时间就是生命，这个大家都懂。

但是很多人不明白，金钱也是生命。

我之前就说过，我们赚的每一分钱，都是用生命时光换来的，都是熬出来的，非常宝贵。

所以呢，我们的生命（时间和金钱），千万不能浪费在无意义的人和事上。

如果我们花费了自己的一段生命，那么我们必须索取同等或者超值的回报，绝对不可以单方面付出。

两个人相处，如果一个人长期单方面付出，结局只有两种可能：要么你想他死，要么他想你死。

有些蠢货，总以为单方面付出能感动对方，或者期待对方到最后一定会感激自己的。
