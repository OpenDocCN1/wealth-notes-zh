# ① 开放度

我们都知道，在各大自媒体平台里面，微信公众号是开放度最高的。你去聊党、国家、美国、选举、犯罪、营销都可以，也不用敏感词来代替，平台的包容度还是很高的。

只要你不宣传违法乱纪或者造谣的言论，平台基本不会管你。

另外，你想怎么做营销都可以，直接卖产品、卖服务、做收费社群、收代理，怎么收钱都可以，基本没有禁忌。

那么微信视频号也会继承这个特点，就是开放度非常高，在法律的范围内，想讨论什么都可以，想怎么做营销都可以。

但是 D 音、J 日头条或者 K 手这类平台，包容度跟腾讯系产品是有天壤之别的，在那些平台上面，稍微敏感一点的词汇都得用字母代替，比如：

钱→Q，国家→GJ，营销→YX，股票→GP，诈骗→ZP，我见过最夸张的一个博主，连“女人”这两个字都不敢写出来，得用 NR 来表示……

这也不能怪他，因为他被罚怕了。稍微违规一次就会被降权，小黄车商品动辄就会被下架，有时候不知道哪里犯错了就会被封了，所以只能选择噤若寒蝉。

微信是开放的顶端，D 音是开放的底端。

而微博、知乎、喜马拉雅这些自媒体平台，就介于二者之间了。

这也就是为什么其他平台的流量，大家都想引到微信公众号或者个人微信了，因为这里才是自由的地方。
