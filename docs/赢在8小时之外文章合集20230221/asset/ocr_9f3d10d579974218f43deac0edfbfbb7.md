# 碰到提意见的人，我一律拉黑

原创  嬴在 8 小时之外  2021-12-17 16:41:36

在网上各种各样的人我都会碰到，一般我会提防着两类人：给我提意见的人，没有任何缘由就夸赞我的人。

你可以反思一下，最近有没有免费给别人提过意见。

也就是说，对方一没给你钱，二没有诚心地请教你，而你却因为某种冲动，或者好为人师，去给人家叽叽地提意见。

如果有，那你的段位一定还非常低，收入也在平均线上挣扎。

但凡聪明一点、富有一点的人都懂得一个道理：不请自来的、免费的意见，只能招致别人的讨厌。即便是

有血缘关系的亲人，提意见时也要非常谨慎，注意技巧和手段，否则弄不好就反目成仇了。

中国有句老话：法不轻传，道不贱卖。这句话绝对是有道理的。

意见或者建议，一般只能从高能量层级向低能量层级流动 之所以上面愿意向下传递，一般是由于下面付出了什么东西，让上面受益了，他才会吐露一点。

而喜欢给出免费意见的就是两种：要么是傻屌丝，要么是/jquery 的人。

前者的时间不值钱，而且他还懂得很多没法换成钱的大道理，又特别好为人师。

而后者刚刚翻身，就急着到处免费指点江山，不注意保护自己的能量场，结果很快就被打回原形了。

如果你相信我所说的，那么下次无论在任何场合、任何平台，只要对方没有给你付钱，或者没有诚心地请教你，你就不要给对方传授任何经验。

当然我的做法更绝，如果对方没有给我付过费，我根本不给对方跟我交流的机会。不是因为我是什么大腕，而是说我的原则就是如此。

我一直坚信，“钱”是普通人能给出的最大诚意了，说其他的都很虚。我对言语上的奉承和夸赞是有免疫力的。

当然，段位更高的人，你给他钱，或者求他，他也不会吐露半个字。
