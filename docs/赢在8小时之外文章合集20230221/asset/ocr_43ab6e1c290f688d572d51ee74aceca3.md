# 请戒掉这两个危险的习惯

原创 赢在 8 小时之外 2022-06-10 12:00:57

# ① 把注意力全部奉献给别人

要知道，人的精力是极其有限的。

所有厉害的人，都会把注意力聚焦在自己的项目上，我没见过哪个大佬天天打探别人的信息，以及别人的项目进展。

如果你真的这样做了，很可能的结果就是：你被别人的障眼法给耍了，不仅仅丢失了自己的精力和注意力，最后还被别人收割了。

你也不想想，别人为什么会把宝贵的经验和数据免费分享给你？

你是他爹吗？你交钱了吗？

有人肯定会说，我也不能一直闭门造车，得跟别人学习啊。

我想说，学习可以，但一定不是这种方式。

要么你暗中观察、暗中学习、暗中模仿；要么你就交钱跟人家学习。

除了这两种方式之外，其他任何一种打探和请教，都会把你引向深渊。

# ② 乱发善心，乱帮人。

所有的免费建议都会导致恶劣的后果，没有例外的。

一方而，我没见过哪个厉害的大佬整天免费给别人提建议和意见。你不交钱，他一个字都不会跟你说的，甚至他都不会通过你的好友申请。

反过来也成立，如果你喜欢免费帮助别人，只能说明一点：你的时间和经验都非常不值钱，你就是个不值钱的人。

另一方面，真正厉害的人，做事情都有自己节奏和感觉，不会因为别人的免费建议而随意改变。

当然，这并不是说他们会忽视客观的市场规律，一意孤行。

而是说，他们更相信自己的经验和直觉。如果真的想要请教前辈的意见，他们也一定会花钱去咨询。

总之呢，那些提免费建议的人，人见人厌，费力不讨好。
