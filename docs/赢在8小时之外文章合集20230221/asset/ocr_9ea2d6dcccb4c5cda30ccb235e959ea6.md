# 跟高手打交道，总是很紧张怎么办？

原  创  赢在 8 小时之外  2021-08-18 13:03:55

之前我写过很多跟高手、贵人相关的话题，然后反馈最多的，有两种声音：

第一，人家高手凭什么会理你，人是没法融入高于自己的圈层的。

第二，跟高手打交道，总是很紧张，怎么办？

关于第一个问题，我想说的是，我们一定要想尽办法跟高手发生交集，他们随便点拨两句，就够我们吃几年的的，一定要相信这个事实。

另外，所有高手，都需要小弟。

而且你要知道，即使再有钱、再有地位的人，他也需要情绪价值，也需要成就感，也需要被崇拜、被追随、被恭维的感觉。

认准一个大佬，你知道从他那里可以获得非常宝贵的经验，你就放下身段，多去跟他接近。

比如请客吃饭，朋友圈点赞，戴点高帽，经常发红包请教问题，都可以。

要知道，人心都是肉长的，当大佬知道你对他很信任、很崇拜，而且经常向他请教，他很可能就愿意帮助你成长。

因为帮助一个人成长，是非常有成就感的一件事，跟钱无关。能量是需要传递的，而且这种正向传递的感觉非常舒服。

另外，从功利的角度来说，他培养过很多人，而且都做出成果了，那么对于他后续的营销、宣传，也是非常有帮助的。

当然，大佬最反感的就是白眼狼，没人愿意帮助白眼狼。

所以，你千万不能有索取心态，而是要养成“先付出”的习惯。

身价越高的人，他的嗅觉就越灵敏。

你的一句话，一个表情，一个动作，就把你内心的动机暴露无遗了。

一个人的身价只要比你高，那么一起吃饭时，你一定要负责买单。

另外，也不要刻意过度消费，你的收入低，请大佬吃碗面条、喝杯咖啡也可以，没人会瞧不起你。
