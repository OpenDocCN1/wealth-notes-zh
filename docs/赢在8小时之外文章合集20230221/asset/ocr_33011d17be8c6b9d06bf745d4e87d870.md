# 喜欢表白的人，都是蠢货

赢在 8 小时之外　　2021-05-19 19:54:17

本文只有男性粉丝可见。

520 快到了，私信我情感问题的人也很多，一部分男人私信的问题是：表白被拒绝了怎么办，该怎么补救挽回，或者重新争取到对方的认可。

我的回答是，如果你已经不是学生了，还做表白这种事，那说明你比猪还蠢。

现实社会里，一个男人如果比较忐忑地向女人表白，50%的几率，女人会这样回复：我还没有想好，我再考虑考虑（其实是婉拒）。还有 40%的几率会被直接拒绝。

之所以成功率很低，原因有几个方面：

+   ①你如果表白，问对方能不能接受自己的追求，相当于把决定权交给了对方（这是致命的错误），很多女人是不喜欢做决定的，她就只能逃避。

+   ②有心机的女人，可能会借此吊着你。不答应，也不拒绝，拉长追求期，让你多付出时间、金钱、感情等等。

+   ③很多女人潜意识里是享受暧昧的感觉，你一表白，就剥夺了她享受不确定性的快感。你把她的快感剥夺了，她肯定不会满意。

+   ④这是最重要的一个原因，我也会重点讲一下这里面的逻辑。

成交女人，跟成交客户是同样的道理。

凡是比较贵的品牌，比如苹果手机专卖店，LV 专卖店，销售员一般不会向你推销：您看中我们的商品了吗？我特别想把它卖给你，你能接受我们的商品吗？接受的话就快点交钱吧，给我一个明确的答复，别吊着我好吗？

只有那种特别廉价的商品推销员，才会搞这种策略，而且即使他们的姿态再低，稍微有点品位的顾客也会产生鄙夷的感觉，甚至想立刻转身走人。

你向女人推销自己时，也是一个道理，你一表白，就证明你是个廉价货。

所以呢，千万不要姿态很低的去表白对方，把选择权交给对方。
