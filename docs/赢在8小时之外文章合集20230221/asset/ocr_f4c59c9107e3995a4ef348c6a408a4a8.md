# ③ 餐饮

清迈古城里面有很多现代化的、小清新的、非常有格调的餐厅和咖啡馆，泰国菜、中餐、日料、西餐都能吃到。而且绝对是优质价廉，服务态度超级好。

比如下面这种地中海风格的沙拉（鸡肉、萝卜、西红柿、青椒、牛油果、生菜），20元一大盘，边上的香蕉奶昔大概10元一大杯（本文我标注的价格都是人民币，不是泰铢）、货真价实、绝对新鲜

![](bbox=[0.21, 0.335, 0.77, 0.62])

餐厅的装修很干净、氛围很好、服务也非常到位。

国内同样的服务和餐饮，我估计至少要100元吧。

芒果糯米饭也大概20元（芒果是熟透了的，超级甜），菠萝饭大概是20-40元一份，而且量超大、超级好吃。

椰子大概是6-10元一个，都是超大、超新鲜、超甜的。
