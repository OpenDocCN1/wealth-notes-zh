# 高筑墙

，就是说你要想办法建立“行业壁垒”，也就是提高“行业门槛”。

京东当年之所以能够虎口夺食，在淘宝在占领“电商领域”半壁江山的情况下，从马云嘴中撕下来一块肥肉，就是因为刘强东通过“自建物流系统”提高了“行业门槛”，建立了一条无法轻易逾越的“护城河”。

对于打工者来说，提高行业壁垒的方向有两个：要么把某项技术钻研到顶尖水平，让技术成为你的“铁饭碗”，永远不用担心失业。

要么就多面开花，让你的收入变得多元化。

我的观点是，在这个瞬息万变的时代，一个人如果没有两个以上的收入途径，那他就已经很危险了。一旦有某个收入途径断掉，那么自己就会陷入非常被动的局面。

如果一个行业的“势”已经没有了，那么不要恋战，要迅速开辟新的战场。至少在互联网上，开辟一个新的收入途径并不是太难。

# 缓称王，

就是说你不要太急于变现。

比如“微信营销”这件事，如果你加上对方好友，就直接在朋友圈卖货，频繁营销对方，那么对方很快就把你删了，或者屏蔽了。

真正的大佬是很少在朋友圈直接卖货、招代理的，他们都是分享自己高逼格的生活方式，分享自己对某些事件精辟的见解，分享对这个世界独一无二的认知。

一旦他们掏出镰刀，就一定收割把大的。
