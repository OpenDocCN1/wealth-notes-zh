# 2021-VIP (202)

我看世界地图，发现每一个有名字的国家，都是狼角色。要么对外狼，要么对自己人狼。

人也一样，你看那些立起来的人，无论外表看起来多么温文尔雅，内心绝对也都是狼角色。

不要被所谓的规则和文化束缚住，你要朝着对自己有利的方向走去，不要考虑太多

工作不累、回报还很高的工作，一般都是非常有挑战性的，你如果自己不怕挑战，就去尝试。咨询周围的人没什么用，因为他们不了解你。

今天我在 VIP 群还在聊这个话题，我说，每一个有名字的国家，都是狼角色。要么对外狼，要么对自己人狼。

朝鲜以前一直被其他大国挑衅，最后他搞出了核五器，所有不好听的声音都静下来了。

人也一样，你看那些能够立起来的人，无论外表看起来多么温文尔雅，内心绝对也都是狼角色。

另外，打破牢笼的思想也非常重要，凡事不破不立。所有新朝玮的建立，都是靠打破上一个朝玮来实现的。

打破牢笼的那个人，他没有任何道德、文化的束缚，把所有的“君君臣臣父父子子”之流的狗屁文化都抛在了脑后。

就一个字：干。

很多成功的老板也是这样干的，他的人生突破性时刻，就是摆脱原来的公司、自己拉帮结伙的那一刻。

最后你会发现，成功不是靠聪明、靠算计出来的。可能就是靠的一股冲劲，一种强势的力量。这个世界上有太多的人喜欢走小道，不喜欢走大道，整天在那里绕来绕去。
