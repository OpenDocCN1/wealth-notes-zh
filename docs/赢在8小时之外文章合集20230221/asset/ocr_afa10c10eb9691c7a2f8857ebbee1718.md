因为不是一个收入阶层的人，是没有任何话题交集的，坐到一起聊任何话题都会产生本质的分歧，人家只能假装附和你。

除非，你的特长是世界冠军级别的，是诺贝尔奖级别的，那么这时候你也可以跟世界首富平起平坐，但这时候你的财务也比较自由了。

所以说，活在当下，做离赚钱最近的事，才是我们普通人最需要的。

未来肯定是要规划的，但不应该以停止收钱作为代价。你必须每天收钱，收着收着，美好的未来就光临了。

那么，除了收钱这个动作，今天我们做什么会对构建美好的未来有帮助？

# 对自己的思维方式进行升级。

我们现在处境，其实就是我们过去的想法、过去的思维方式的真实反映。

所以说，你想改变未来，最需要做的就是升级现在的思维方式。

未来是没法预料的，要么你在互联网上走出去，跟有成果的人产生交集；要么在现实中走出去，去跟现实中有成果的人产生交集。

只要你能走出去，你的很多思维方式、看问题的视角都会发生变化，这些都是没法预料的。

我之前就说过一个观点，只要你不是打工阶层，你是自己搞事情、搞事业的人，你第一次出国之后，收入肯定会有明显增长。

因为只有到了外面，你才会对 zg 的人、事、物有一个更加真实的认识，而且是完全不同的视角。

认知一旦发生改变，那么现实必然会跟着改变。

你对这个社会、对人性认识的越深刻，那么你赚钱就越容易。

到了外面，你一定要观察当地的商业模式，当地人的思考方式，有哪些是值得借鉴的，有哪些是需要抛弃的。如果能跟有成果的人发生交集，那就再好不过了。

而单纯的旅行、单纯的看风景，其实没有任何意义，对于提自己的生命成长没有什么实质性帮助。

普通人的生命高度，就是由经济基础决定的。
