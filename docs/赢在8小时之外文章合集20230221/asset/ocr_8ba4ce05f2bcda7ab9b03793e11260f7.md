# 付费合集功能灰度测试通知

昨天 18:46

微信公众平台灰度测试付费合集功能，支持将多个文章收录在同一付费合集下，用户购买此合集后即可阅读全部内容，点击此处了解详情。

我大概看了一下，这个东西类似于喜马拉雅 FM 的“付费专辑”，比如我建一个合集，叫“写作教程 3 0 讲”，定价是 3000 微信豆，而且会承诺更新 30 期。

那么购买此专辑的人，会免费收到推送和更新。

这个功能我可能会使用，也可能不会使用，总之呢，我是能感受到微信公众平台的工作人员，平时一定在绞尽脑汁想让创作者能获得更加丰厚、更加多样化的收入，同时也给读者提供一个更加便利的环境。

其实最近这 5 年，公众平台做了很多开创性的动作，让创作者的收入越来越多样化。

比如下面这几个收入渠道，都是被很多人（包括我）验证过可行的，而且一直在受益：

# ① 流量主服务

也就是公众号底部的广告，读者点击一次，创作者就会有 0.5-1 元的收入。

从我这个号的统计来看，只要有读者点击一次，我都能有 0.9 元的收入。这个是非常实在的。

# ② 付费阅读功能

相信关注我的读者应该都清楚这个功能，我每次写付费阅读文章，都会定价 6-10 元，平均每篇文章都能收上来七八百元。

已经很够意思了吧？

# ③ 打赏服务

我这个号的打赏收入不多，每天几十元。但是有很多公众号是可以靠打赏活着的。
