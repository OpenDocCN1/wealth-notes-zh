# 赚穷人的钱，等于诈骗

原创 赢在 8 小时之外 2022-01-24 12:00:00

昨天一个小伙伴私信我，说他自从创业以来，身边没有一个人支持他，连她女朋友也经常跟他吵架。

我说，你每个月的现金流是不是很少，甚至连基本的生活开销都捉襟见肘？

他回答：确实是这样，但是我也刚刚起步啊。她一点都不理解我，我不也是为了我们的未来在奋斗吗。如果有人能理解我、包容我、关心我、支持我就好了。

后来我就想，这是所有底层普通人都会有的幻想，但这也是一个彻头彻尾的白日梦。

现实中贫贱的伴侣，只会像电视里演的那样作、闹、争吵、给你拖后腿。

如果你生活没法安定，且有比较大的目标，那么还是先保持单身比较好。

有的人就不信邪，他会一直陷入一个思维怪圈里：难道没钱就不能拥有幸福的婚姻吗？不是所有的感情都能用钱来衡量的！

其实，很多道理都是相通的，“贫贱夫妻百事哀”适用于任何领域。

比如，运营社群这件事。

有的人就很蠢，他建了一个免费群或者低价群，然后他一直在群里呼吁：大家一定要文明发言，让我们一起努力把这个社群给营造好，一起成长。

结果呢？一定是一地鸡毛。

今天有人发广告，明天有人吵起来了，后天就有人开始对骂了。

记住，金钱是最好的筛选门槛，如果你否认这个最基本的原则，那么你做任何事情都会遭遇极大的阻力。

再比如，选择客户这件事，能赚富人的钱，老板的钱，尽量不要赚穷人的钱，打工者的钱。

富人在你这里购买高价服务，他一定是看到了你的价值，他买完之后就非常安静地去执行了，而且他一定会收到超值的回报，他还会感谢你，鼓励你，甚至给你介绍更多的客户。

而如果你的客户是穷人，那你就麻烦了，你会陷入无穷无尽的纠缠里。
