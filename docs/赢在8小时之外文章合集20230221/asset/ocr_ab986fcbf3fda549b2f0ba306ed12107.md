# 所有的失败，都源于恐惧

原创 赢在 8 小时之外 2020-06-14 17:30:16

昨天我拉黑了一个开口向我借钱的老同事。

我之前说过，落魄了，千万别向朋友开口，要自救。非要开口的话，朋友肯定做不成了。

当然了，我的这些做法，很多人看了会受不了的，会觉得，你也太绝情了，等你需要帮助的时候，也没人来帮助你了。

我的回答是，你是穷鬼，你自然讲感情了，你自然喜欢从道德层面去讲人际关系了。

但是呢，我不能这样。因为我曾经也是个重感情的穷鬼。重感情，并不是什么缺点，但是呢，如果因此就把“理性”给抛弃了，那么就无可救药了。

人年轻的时候，没钱很正常。但是呢，如果过了 30 岁，或者说到了中年，仍然需要借钱，那么这个人本质上是个不负责任的垃圾人。

要么就是他的智商太低，要么就是家庭环境束缚太大，要么就是太懒，要么就是有赌性，要么就是太懦弱，等等。

基本上全是无解的死亡题，你一旦跟这种人产生交集，他也会把你拉进深渊里的。弄不好，连命都得丢了。

我不是危言耸听，这年头，穿着西装革履，但是身上背着几十万债务的人，多如牛毛。为了还债，他们可以无所不为。

看了那么多法制节目，我的经验就是，要跟穷鬼物理隔绝，就是永世不会见面，不会有交集，自然就安全很多了。

我的这个老同事，是当年跟我一起在国企上班的，我辞职一年之后（2015 年），他也辞职了。

在 2017 年的时候，我的收入已经是他的十几倍了，当时他父母给他凑钱在省会买了房，每个月需要还五千多的房贷。

然后，他说我对象太难了，买房了还是不行，人家根本不跟我谈。

我心想，你是个大负翁，每个月赚一万块钱，还完房贷再加上正常开销，剩不下什么钱了，你拿什么养女人。

千万别听网上一些傻屌在那里聊男女平等之类的鬼话，大部分普通男人，不高不帅，没有才华。如果再没有钱的话，还找什么女人，不是神经病嘛。稍微有点姿色的女人，得买化妆品吧，得买包吧，每个月得两三万的开销吧，你是个大负翁，定位千万别偏了，眼光放低的话还可以考虑。
