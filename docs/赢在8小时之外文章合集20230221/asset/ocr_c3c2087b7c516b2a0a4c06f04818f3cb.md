我说，最快的方法就是去英国、去美国待一段时间。如果你觉得签证难办，费用太高，你去菲律宾也行，菲律宾是我去过的所有英语国家里面，成本最低的（当然马尼拉的消费比上广深还是要高的）。

你想去便利店买东西，去超市购物，去必胜客点餐，你会发现，所有的商品包装和菜单都是英文的（而不是菲律宾本地语言）。

芒果、榴莲、火龙果、薯片、酸奶、燕麦片、瑜伽垫、拖鞋……等等这些日常用品用英语怎么说？基本上你去超市逛 3 次，你这两子就再也忘不掉了。

因为单词跟实物是相关联的，而且你是在完全陌生的语境里，记单词的速度飞快。

你跟当地的人交流，也只能用英文。

不论是去酒店、去医院、去景点，在特定的场景，就会使用特定的词汇，即使你忘了该用什么单词，对方也会给你提示，让你很快掌握那个场景的知识点。

再比如，你如果想学视频处理软件 Pr，你并不需要系统地学习整个 Pr 教程，否则你在学习“界面”的那一节，就会枯燥死。

你最需要做的，是找一个会熟练使用 Pr 的人，想办法让对方教你（需要付出成本），而且只教你几个最实用的场景即可。

比如，如何剪切画面大小，如何去水印，如何加字幕，如何处理转场，如何调整画面的亮度和对比度，如何把音频和视频分离，如何给视频配音频……

如果你制作视频的目的，是运营抖音或者 B 站，那么这些知识点不会超过 20 个，基本上就够用了。每个知识点，只需要 1 分钟的讲解，再加上几分钟的实操就行了。

我自己也经常使用 Pr，我如果想教会一个人使用 Pr 的基础功能，基本上都在 1 个小时之内。

但是，如果你喜欢学习理论，喜欢学习教程，你去买一本书，或者买一个系统的课程，你会发现，你学了一个月的理论，真的让你独立压制一段视频，你会发现自己几乎什么都不会。

当然，最值得我们学习的案例，一定是跟赚钱相关的案例。

还有就是，我刚才分享的写作群这个收钱案例，你是不是也感兴趣？是不是很想知道他的账号名称是什么？
