# 做视频搬运，有前途吗？

原创  赢在 8 小时之外  2022-07-08 12:00:05

最近收到了一条咨询消息，我觉得很典型，就打算写一篇文章聊聊这个话题。这位付费读者问我，

看到抖音和 B 站有很多做视频搬运的博主，粉丝也不少。

自己会一些剪辑技术，知道该怎样从国外网站下载视频，所以也打算做一个视频搬运博主，不知道可不可行？

另外，有没有必要深入去学习 Ps、Pr 这些软件？

在我看来，这是两个问题，我分别聊一下我的看法。

# ① 视频搬运这种事情，对于能力和 IP 打造，没有太多成长性和积累性。

做这类博主，跟那些做房产、做教育、做旅游的博主，是有本质区别的。

说白了，你的粉丝太分散，不值钱。

另外，这类账号的风险也很大，阶段性的严打很可能会落到你头上。

BBC、YouTube（油管）、Twitter（推特）这些词，没准哪天全部都会成为敏感词，然后一大批搬运账号都会死掉。

过来人都知道，这种可能性并不小。

所以，如果打算做个人 IP，打算积累粉丝，尽量去做那些有成长性、有积累性、有正向反馈的事情，而不是冒着一定风险去做这种不是很值钱的事情。

不过话说回来，搬运海外视频发到国内社交网站上这件事，我之前也做过。大概是在 2014 年前后，

我做了一个微博（@U 君笔记，现在有 60w 粉丝了）。

但是当初可不叫这个名字，当时微博昵称里面就有“YouTube”字样。

因为那时候微博刚刚兴起，微信还没有大规模的影响力，抖音等社交平台还没有诞生。

总之呢，互联网上的内容并不是特别丰富，优质内容也比较少，所以好的内容很容易吸引粉丝。

所以，那时候我就开始搬运视频，而且学会了视频剪辑、压制字幕，还成立了一个字幕组。
