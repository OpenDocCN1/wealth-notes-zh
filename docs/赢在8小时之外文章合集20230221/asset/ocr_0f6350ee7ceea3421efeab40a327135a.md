# 人性中最大的恶，就是见不得别人比自己好

原创　赢在 8 小时之外　2020-09-30 12:15:33

最近我在西藏玩，缺氧的感觉特别难受，适应了 3 天仍旧很不爽。

布达拉宫上到一半我就不想继续往前走了，头晕脑胀。而且在工作日的工作时间，排队买票的人都很多。（网上预约只能进大门，最终大家都要排队买实体票）

十一假期的火爆程度就更难以想象了。正因为太多的人对西藏趋之若鹜，所以机票很少打折。从北京飞拉萨 3000 元，飞回来还是 3000 元，你爱坐不坐。

很多人从西宁坐火车到拉萨，目的是逐渐适应高海拔。但是青海海拔 2000–4000 的地方我都去过了，我觉得拉萨的 3650 米海拔还不是小意思？但是我还是误判了。

拉萨大昭寺、青海塔尔寺这些佛教圣地我也都去过了，没有任何感觉。我就觉得里面的一部分“信徒”很贪婪，给佛祖扔几毛钱、几块钱，然后就许很多愿望：保佑我学业有成，婚姻幸福，事业腾飞。

你的脸怎么那么大？

昨天晚上收到一条微信，一个老同学问我能不能帮他买一个天珠，并且还要开过光的（一个天珠价格从几百元到几百万元不等）。

我心想，我也没发朋友圈啊（其实我把他屏蔽了），你怎么知道我在西藏？

他说看到我一个朋友发圈了，就猜我也在西藏。

我就跟他说，我已经回北京了，他说，哦。

其实呢，我自己有一个习惯，凡是生活中让我觉得很开心的事情，我发朋友圈时，一定把老同事、老同学、亲戚朋友全都屏蔽了。

相反，凡是不如意的事情，发朋友圈时，只让他们可见，而让我的客户、粉丝不可见。

我知道这种做法让很多人觉得不可理喻，但是这确实是我多年的习惯，不可能会改。

2017 年我开第一家公司时候，手欠发了一条朋友圈，所有人都可见。后来找我安排工作的、借钱的亲戚朋友同事陆续都来了。

我自己才刚刚起步，哪有能力帮助你们呢。但是呢，拒绝就把人得罪了，还有的人就开始说风凉话了（你懂得）。
