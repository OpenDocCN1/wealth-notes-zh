# 放空自己，好运就会成为常态

原创   赢在 8 小时之外    2021-06-19 19:10:58

今天在 VIP 群，大家聊得热火朝天。然后有位群友问我，是怎样安排自己时间和精力的。

![](bbox=[0.28, 0.178, 0.72, 0.729])

我的回答是，我每天必须睡够 7-8 小时，而且下午会锻炼半小时，然后每天至少也会写作 1 小时。

当然，想要输出 1000 字的文章，还需要摄入 10000 字的消息。

其余的时间，要么在搞流量，要么在收钱，要么就是在组织合作伙伴写作、搞流量和收钱。至于看新闻、看综艺、刷朋友圈、跟朋友团聚会、社交之类的事情，我早就不过参与了，因为实在是提不起兴趣。
