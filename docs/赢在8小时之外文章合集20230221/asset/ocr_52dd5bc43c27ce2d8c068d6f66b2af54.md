# 只有多花钱，才能理解钱的属性

原创 赢在 8 小时之外 2021-06-06 13:44:05

前段时间出了一个新闻，大概意思是 x 团外卖开始按照里程收费了。底下很多人都在喷 x 团公司，说它终于露出了资本家贪婪的真面目。

我倒是觉得这种收费机制很合理，因为我早就希望送外卖的按照里程和时间收费。

他们的收入提高一些之后，他们骑电动车就不会胡乱逆行、胡乱闯红灯，安全事故也会更少，跟客户沟通时也会更礼貌，客户体验会更好。

我开车时，最烦的就是不遵守交通规则、到处乱窜的外卖员，我开门拿外卖时，最讨厌的就是急匆匆把外卖扔到我手里，然后就冲进电梯送下一单的外卖员。

如果真的按里程收费之后，这一切都会好转。

其实资本化、市场化，都是好事。

大部分有钱人都愿意多花一点钱，享受更好的服务。

麦当劳、必胜客、吉野家这些餐饮公司早就已经实现了。

比如麦当劳，每单外卖都是 9 元的配送费，外卖员很气定神闲地配送，也很高效，整个过程也很有礼貌、很舒服。

另外，你看那些跟送外卖相关的交通事故、犯罪事件，肯定与麦当劳这类送餐员无关。

涉事的都是那些来去匆匆、把工资看得比命都重要的低学历、低收入送餐员。

最后你会发现：收入越高的人，越有尊严，人生越不慌乱。

如果你从来没有点过麦当劳这类需要交配送费的外卖，我推荐你点一次试试，感受一下花钱服务跟不花钱服务的区别。你也可以观察一下这些外卖员跟保安、门卫的交流方式，跟那些免费外卖员有什么区别。

其实呢，我以前在公众号里面写过，多花钱的人，才能多赚钱。

当然，我不是让你盲目去消费，而是要感受花钱跟不花钱的区别。

比如，花钱能享受更好的服务；花钱能节约更多的时间；花钱能购买别人的时间；花钱能让别人帮我们跑腿。
