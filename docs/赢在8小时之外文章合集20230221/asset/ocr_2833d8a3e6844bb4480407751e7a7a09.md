# 朋友借钱不还怎么办？

一个人之所以敢践踏你的人格（比如借钱不还，或者敢说一些让你不舒服的话），就是他在内心里已经把你摸透了。

他觉得你这个人，就是个没有底线的怂包。所以他才敢在你面前肆无忌惮、无所顾忌。

一个人之所以有胆量在你面前做那些让你不舒服的事，或者说让你不舒服的话，这些都不是一天形成的。而是两个人相处的过程中，长期心理博弈的结果。

或者说，他对你的这些态度，并不是他的性格，他在别人面前，可能像哈巴狗一样，唯独对你他敢肆无忌惮。

但是这不怪他，而要怪你自己。因为别人对你的态度，都是你一手培养出来的。

你可以想象一下，两个陌生人第一次见面时，都是非常客气的，因为都不知道对方的底线在哪里，只能慢慢试探。

如果在这个过程中，对方尝试着侵犯你一点权利，你没有反抗，那么对方会逐渐加大筹码，直到把你吃透。

接下来就可以肆无忌惮了。

所以，即使再好的朋友，甚至是亲人，开玩笑触犯到你的底线了，你必须用同样的力度反击回去。

千万不要想着以德报怨、忍一时风平浪静这种鬼话。

注意，我上面说的这些都是对待熟人和朋友，而不是陌生人。陌生人踩了我们一脚，或者是开车时骂了我们一句，我们完全可以忽略，因为这些都是无关紧要的。

但是，如果你在生活或者职场上，培养了一个肆意践踏你的人，那后果会是非常可怕的。

而且势差一旦形成，想要改变局面就比较难了。

当然，也不是没有办法。

那就是，在对方触碰自己利益或者底线的时候，第一时间警告对方，并拒绝任何形式的妥协。

因为，妥协一步，就要终生妥协。
