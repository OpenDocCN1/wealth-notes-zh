# 如何提高自己的修为？

原创 赢在 8 小时之外 2021-10-07 12:00:20

昨天有个读者私信我，问怎么样才能提高自己的修为？

我想，这个问题太宏大了，很难说。

但是呢，从财富和健康两个角度来看，就很清晰了。

财富这个不用多说，一个人的收入越高，基本上就可以判定，他的修为就越高，对社会和人性的认识就越深刻。

健康，也是一个指标。

越是富有的人，越重视健康，包括身体健康和心理健康。

# 一个成年人，如果不是亚健康状态，就已经意味着他的觉知、取舍、行动力，已经达到很高的修为了。

比如，我之前经常拿“牙齿健康”来举例子。

一个人如果有一口洁白的牙齿，而且你跟他近距离聊天，他的嘴里没有任何难闻的气味，基本上就可以证明这个人的修为已经相当高了（超越了 95%的人）。

因为他有清洁牙齿的意识。

大多数穷人是没有这个意识的。

如果你去看他的后槽牙，一颗都不缺，也没有蛀牙，那基本上可以判断，他的家庭非常富裕，因为他的父母在他很小的时候，就知道督促他养成保护牙齿的习惯了。

他的父母为什么有这个意识？因为他的爷爷奶奶、外公外婆，在他父母小时候，也是这样培养的。

优秀的习惯一定是一代代传递的。

不用说农村的人，就算是县城的人，90%的人都有口臭，都不在意保护牙齿，或者说不懂怎么保护牙齿。

再说心理健康，大概率来说，越富有的人，实现心理健康就越容易。

因为你有实力和底气，去选择身处一个什么样的环境，去选择跟什么样的人交往。

人之所以会抑郁，跟所处的环境和接触的人有直接关系。
