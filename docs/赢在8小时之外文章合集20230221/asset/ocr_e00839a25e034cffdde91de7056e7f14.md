# 底层人的婚姻，只能将就？

我是屌丝，难道我就不能拥有美好的爱情和婚姻吗？

答案是，很难。

因为没有跨越金字塔的底下两层，就想直接拥有第三层的东西，这不太现实。

![](bbox=[0.269, 0.278, 0.731, 0.539])

现在网上，很多 zg 女性抱怨男人，抱怨婚姻，说不婚保平安，不能给男人做免费保姆。

这些都是底层的屌丝，出身比较差，导致了自己在生活中碰到的男人质量也很差，导致了她们会发出这样的言论。

她们其实也渴望爱情，也渴望男人（生理异常的女人除外），但是呢，现实是很残酷的。

如果你不是天赋异禀、拥有逆天绝技的女人，那么你的父母混得怎么样，基本上就决定了你会遇到什么样的男人。

因为在 zg，学校、父母和 xx 洗脑的历程非常彻底，大部分普通人一直到 30 岁了还是接受同样垃圾文化的洗脑。

醒不了。

所以说，你如果身处底层，那么你遇到的男人，大部分都是底层的屌丝。

这部分男人，其实是没有什么选择的，他们找女人没得挑：只要你能生育，彩礼我给得起，那就可以了。
