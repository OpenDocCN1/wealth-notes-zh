# 教培从业者的出路

原创 赢在 8 小时之外 2021-12-13 12:00:00

最近有个做教培的粉丝私信我，讲了他最近几个月的遭遇，只能用“狼狈”两个字来形容。

他和老婆都从事的教培行业，正好在这次整顿的行列之中，于是双双都没了工作，有房贷要还，还有一个孩子要养。

两人失业后也做过一些其他尝试，但是均没有达到他们的预期，工资只能勉强糊口。

30 多岁想找到一份收入不错的工作已经很难了，因为教育行业的岗位骤减，其他行业自己又不擅长。

但是呢，毕竟是大学生，又不愿放下身段去送外卖、开滴滴，所以非常迷茫，不知道何去何从。

我说，其实不光是教培行业，其他的比如地产、旅游、餐饮等行业受到的打击也非常大，所有被裁掉的人都会面临着同样的问题：我该如何寻下一份工作？如何学习新的技能？收入大幅度下降时，我该如何适应？

对于这些迷茫的朋友，我的建议就是：广积粮，高筑墙，缓称王。

这也是当年朱升给朱元璋提的战略方针。

民以食为天，你的粮食充足了，百姓富裕了，那么无论怎么打仗你都不用担心粮草。

把每个城墙都垒的非常坚固、非常高，那么就再也不怕外敌的入侵了。

更不要着急称王，否则你会背上“不义”的骂名，会四面树敌。

这些理论其实很朴素，但是也非常有效，跟《孙子兵法》不谋而合。

孙子兵法的精髓就是五个字：道、天、地、将、法。

# 道，

就是“得道多助失道寡助”“君子爱财取之有道”里的道，你得师出有名，还得得人心，这是重中之重。你如果得道了，就连天下的鸡鸣狗盗之徒都愿意为你卖命。
