# “恩情”把握不好，会变成伤人的利器

原创　　赢在 8 小时之外　　2020-09-28 20:37:43

昨天在 VIP 群里，我跟大家聊了一些关于“恩情”的话题。今天在公众号里面再免费分享给大家一小部分。

分享令我受益匪浅的思维，是要收费的，在公众号这个平台偶尔分享一小部分，目的也是为了收费，进入 VIP 群之后才能看到完整版的，也能和群里各位老板进行交流。

我之前说过一个很扎心的观点：免费帮助别人，经常处于付出状态，是一种犯罪。说的再通俗一点，不要平白无故对别人好，否则以后不是你想他死，就是他想你死。

平等交易是每个老板都应该严格遵守的准则。

我自己还有一个非常严格的做事准则：我给谁提供过帮助，在 ta 面前，永远也不会提及此事。

给谁送过礼物，在 ta 面前也永远不会提及，甚至眼睛就永远也不会看这件礼物了。比如我送给别人一块表，那么我跟 ta 见面时，从来不会看一眼那块表，更不会聊跟手表相关的话题。

因为我自己也有感触，谁帮过我，我心里其实一直都记着。但是，如果对方有意无意提及这件事，我会非常反感。

换位思考一下，我就知道该怎么做了。

很多皇帝，之所以要杀掉当年帮自己打下江山的功臣，其中一条原因就是，这个功臣，有意或者无意会提到他的功劳。但是，他的功劳实在太大（功高盖主），皇帝也无以为报了。

官给已经封到最大了，赐给他的金银财物，够他全家儿子锦衣玉食了。

接下来还要怎么办呢？只能杀了他。

因为，只要留他活命，那么皇帝每次看到他，都会心生愧疚。

“愧疚”是一种很不爽的负面情绪，你敢给皇上带来负面情绪，不是作死吗？所以，高明的功臣，都懂得功成身退的道理。

中国人最喜欢讲恩情，总觉得这样的人，才有人味。
