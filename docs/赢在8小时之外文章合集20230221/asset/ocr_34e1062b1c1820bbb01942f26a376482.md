# 现金流不稳定的人，随时可能破产

原創 赢在 8 小时之外 2022-09-07 14:44:29

最近两年很多人私信我，说他在疫情期间丢了工作，还有人说他开店投入的几十万全部打水漂了，现在负债累累，想知道该如何翻身。

还能怎么做？

线下就开滴滴、送外卖、卖早点、做装修工人，如果努力干，一个月也能赚万八千块钱。

线上就搞搞自媒体、搞搞闲鱼等其他副业。

最重要的，是要提前预判，要警觉。

我之前经常玩罗伯特清崎发明的《富爸爸现金流游戏》，有时候玩电脑版的，有时候在线下跟几个朋友一起玩。

他的这个现金流游戏，包括他写的富爸爸系列书籍，其实很多内容都是过时的，或者说是不严谨的，但是里面有一些逻辑是通用的。

比如，对于大多数普通人来说，“现金流”才是最重要的东西。

光有资产可不行，因为有个词叫“资不抵债”。

只要你的“资产”不是全款购买的，那么将来都有可能出现“资不抵债”的情况，比如垃圾城市的房产，比如保值率很低的豪车，比如业绩很差但是高杠杆运营的公司。

如果现金流不稳定，那么你永远都不是富人，随时可能破产。

那么“工资”算不算是现金流呢？

大概率不算。

你以为你一个月拿 1 万元，每个月还房贷车贷 6000 元，剩下 4000 元供家庭开销和储蓄，就算是现金流稳定吗？

远远不够。

一场意外，一次风城，一次裁员，直接把你打回解放前。

有人说，那我买医疗保险、买失业险不就行了吗。
