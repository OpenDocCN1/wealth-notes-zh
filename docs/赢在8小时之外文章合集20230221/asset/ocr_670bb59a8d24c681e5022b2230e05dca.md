# 令人恐惧的边界感

我的助理跟我说过，平均每个月至少有一个咨询的，说我现在很落魄，没那么多钱，能不能先把我拉进去，赚到钱之后再交报名费？

或者说，我现在是个大学生，能不能给我打个折扣？我坐火车还半价呢。

我就跟助理说，碰到这种人直接拉黑就行了，不用多废话。

一方面，我们不确定对方是不是在说真话；另一方面，我也不是做慈善的。

最重要的，我非常讨厌没有原则、没有边界感的人。我当然也不会做一个这样的人。

如果我的原则今天变一下，明天又变一下，那么所有人都不会尊重我，觉得我就是个谁都可以捏的软柿子，是个草包。

也经常有 VIP 群的朋友咨询我，请教该如何培养自己的气场。

我觉得大部分人气场弱，都是因为有两个瓶颈没有突破：没有边界感，习惯以弱者身份自居。

今天主要聊聊“边界感”这个东西。

比如，当别人向你借一次钱不还，你直接把他拉黑就行了，不要再给他第二次机会，因为他明显是把你当韭菜来收割的，你还像个傻屌似的把他当朋友。

再比如，你如果嗅到了某个人一直在向你索取，你一直在单方面付出，那么你也要抓紧与他划清界限，哪怕这个人是你的亲人。

还有，在很多亲密关系中，如果对方从来不就事论事，而是习惯性人身攻击，你就不能一直迁就，更不能一直自我反省，而是应该直接了当地告诉对方，我不接受这样。

设定边界，是让屌丝极其恐惧的一件事，因为你害怕一旦这样做了，就会失去对方，害怕自己会失去别人的喜欢。

但是呢，你必须要这样做，否则你会失去所有人的尊重，你一辈子都会是一个彻彻底底的屌丝，都会被别人牵着鼻子走。
