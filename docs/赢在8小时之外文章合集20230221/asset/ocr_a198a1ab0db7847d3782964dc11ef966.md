# 经济再不好，也要一直收钱

原创 赢在 8小时之外 2022-11-23 12:00:46

虽然YQ持续了3年，但是对于传统生意来说，今年才是最难的一年。

因为过去两年的余波，到今年才彻底显现出来。

很多实体店铺都关门了，还有一些人还不上房贷车贷了，还有一些跳楼的。

在前两年，线上生意受到的影响还不大，但是到了今年，线上的很多行业也都受到了影响，因为大家都把钱袋子捂紧了，不敢乱花钱了。

或者说，都没钱了。

但是呢，全球的富豪、企业家们，资产都翻了几番。

为什么会这样？

年初我组建VIP群时，其实是想提价的，因为我觉得两千元是一个最低的筛选门槛，不能再低了。

这样大家的执行力、悟性应该都不会差。

不过我还是比较谨慎的，因为我知道大家手头都比较紧。

我的最低预期是，大家在一年之内赚回群费。

我的进阶预期是，群里有100个人能实现日入千元以上。

通过最近的聊天内容来看，很多人已经实现了。
