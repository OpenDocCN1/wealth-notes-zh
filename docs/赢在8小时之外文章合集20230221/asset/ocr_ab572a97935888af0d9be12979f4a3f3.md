# 只要你想上进，被排挤就是必然的

原创 赢在 8 小时之外 2021-10-31 13:11:17

很多人咨询我的案例，都有一个特点，每当他们想要成长、想要上进的时候，都遇到了很大的阻力。

比如，想要考名校的研究生，想要应聘一个薪水更高的职位，想要让自己的社会角色向上跨越一个等级，想让人生自由度更高一些……

这时候，很多身边的同事、家人，甚至自己的内心，都会提出反对的声音。最后你会发现，想要成长一步，比登天还难。

其实呢，只要你想上进，被排挤就是必然的，岁月静好的生活，只有死人才配享受。

你以为你拒绝斗争，别人就会放过你吗？并不会，这些只会让敌人变本加厉。

这个敌人，可能是竞争对手，可能是残酷的现实，可能是你驾驭不了的身边人。只要你没有进化成为一个更高级的角色，它们会分分钟教你做人，压制你一辈子。

比如，很多人跟我抱怨过，说自己办公室有几个同事特别坏，整天就是惦着害人，有没有办法对付他们？

我的建议是，不要琢磨怎么对付他们，要想办法尽快离开那个环境。

一般来说，收入越低、学历越低的群体，越容易出现互相排挤、互相打压的局面，这是无解的，唯一的出路就是离开那里，跳到更高层级。

要知道，不同层级的人，看到和接触到的信息都是不一样的，这也正是区分高手和低手的关键所在。
