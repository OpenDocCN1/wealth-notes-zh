# ③ 成就感巨大。

到目前为止，令我最有成就感的事情，就是事业和赚钱了。

我一直在寻找第二有成就感的事情。

比如玩游戏在 30 人场里面排第一，写的文章能有一万人阅读，每年帮助几十个人实现收入大幅度提升，这些都是非常有成就感的事情。

画一幅能让自己满意、让自己看着舒服的画，也是非常有成就感的，应该也能排到第二位。

况且，绘画、音乐这类事情，是能令很多人产生共鸣的，或者可以这样理解：不同的人看同样一幅画或者听同样一段演奏，反响是不一样的。

自己在画画过程中、以后慢慢欣赏时也会有不同的感悟。

这种感觉很美妙。

我在朋友圈也经常展示我画的画，看到大家的反馈，也非常有意思。现在想想，其实学画画、学游泳、学篮球、学写作、学赚钱，其实都是相通的。
