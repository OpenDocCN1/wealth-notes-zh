# 农村的春节，不一定很美好

原创  赢在 8 小时之外  2022-02-03 12:00:00

春节是个阖家团圆的日子，家家户户笼罩着喜庆的气氛。

但是，春节期间也会发生很多让人痛心疾首的事情。

我有个朋友在县城的急诊室工作，她跟我说，过年期间，农村来的这几类病人开始激增：出车祸的男人，突发心脑血管疾病的老ন্ন，鞭炮炸伤的小孩，喝农药自杀的女人。

男人出车祸，是因为很多人都是常年在外打工，但是车一直放在家里，自己过年回家才开几天串亲戚，手生，而且农村也没有交警查酒驾。

另外，春节期间，雨雪雾天气也比较多，还有人自驾回老家，一天跑七八个小时，更容易发生交通事故。

老人突发心脑血管疾病，跟天气冷有关，还有就是大吃大喝、熬夜打麻将的人也变多了。

鞭炮炸伤这个也很好理解，光是我们那个小村庄，以前每年都有被炸伤的，要么手指炸掉了，要么眼睛炸伤了，而且以小孩居多。

至于喝农药的女人，这个很多人不理解，为什么这些人非要选择过年期间喝农药？

因为只有这个节日全家才能团聚啊，夫妻矛盾、婆媳矛盾、家族矛盾才会集中爆发。

有些事情很难说清楚谁对谁错，两个人可能就是气场不合，三观不一，你非要把他们挤到一起，而且硬生生地让他们互相包容，互相理解，怎么可能？

之前有个叫 papi 酱的大网红接受采访，说她结婚五年根本没有见过丈夫的父母，丈夫也没有见过自己的父母，过年都是各自回家。
