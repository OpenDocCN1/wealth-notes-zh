# ③ 我们的物理状态就是生命状态。

以前我一直认为，意识决定物质的比例更多一些。但是我现在认为，物质决定意识的情况更多一些。

比如，如果我们没有坐过豪车里，没有睡在大房间里，我们根本想象不到那会是一种怎么样的心境。
。

现实世界是很残酷的，人的想法是可以千变万化的，一秒钟内都会有几十个念头闪过，但是呢，想要改变物理世界却是很难的。

住小房子的人，可能一住就是几十年，甚至一辈子；开小排量汽车的人，可能一辈子都不知道开大排量汽车是什么感觉。

好在呢，有些“场”是很容易改变的。

比如，人有自由迁徙的权利，让你觉得不爽的地方，你可以抬脚就走（99%的人都意识不到自己有这个权利，或者总是用其他借口说服自己）。

社交方面，多跟积极向上的人、幸福的人待在一块，你自然也会受到正面的影响。

另外，运动也能让人心情变好。
