# 最高级的他力

17. 社交平台遵循了林塞的经济规律：好内容的创造是需要极高成本的。你刷手机时，刷到非娱乐类优质内容的概率非常小。

所以，别担心不刷手机就会错过些什么，要把时间用在个人成长上。这样做收益是最大的。

18. 当两个人的圈子交集在缩小的时候，两个人已经在走自己的路了，偶尔寒暄想维持一下感情，也会力不从心。

特别是在中年以后，朋友只会越来越少，存量友情也会渐行渐远，这就是人生常态。

19. 普通人最大的问题，是能力不行，这是最根源的问题。其他什么性格问题、情绪问题、道德问题、社交问题等多种问题，都是其次的。

能力是一切的基础，能力出了问题，其他所有问题都会倍数地放大。

20. 当你越来越专注自身的时候，不断地精进，你就会变得越来越清晰。

在长达一两年的时间里，你会攀援到一个新台阶，会和很多人告别，会看透很多事情、想通很多道理。
