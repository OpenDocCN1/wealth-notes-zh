# 打造属于自己的护城河

原创  赢在 8 小时之外  2021-11-27 09:43:26

前几天在 VIP 群里，有个朋友说想调整自己的内容，除了文字输出之外还想要加上视频输出，原因是有朋友反馈说看文字太麻烦：

![](bbox=[0.28, 0.23, 0.78, 0.45])

我自己的一贯做法是，我会有我自己的节奏，很少听别人的意见和建议。

否则我这个公众号从第一天开始，一直到今天，都有很多批判的声音，我能怎么办？谁给我提意见，我就积极采纳，然后进行调整？

如果真的那样做了，那么今天公说公有理，明天婆说婆有理，我听谁的？一天变一个风格？

最终结果一定是大家觉得我写的越来越平庸了，越来越垃圾了，没法看。

当然，我并不是否定“视频”这种形式，利用视频赚钱的人大有人在，只不过你一定要找到自己擅长的战场，找到自己的节奏和风格。

你可以多方位去进行探索，去试错，你也可以关注读者的反馈，但是你不能把别人的意见看得太重，否则会陷入手忙脚乱、手足无措的境地。

毕竟你们是两个不同世界的人，思维方式、对未来的规划几乎没什么交集。这就好比，同样是年入

50 万的高级打工者和小老板，思考方式完全不一样。

小老板思考的问题是，如何把系统搭建起来，而且让它稳定、长期的运转，还要规避各种风险，还要尝试更多的收入渠道。
