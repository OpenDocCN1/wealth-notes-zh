# “你这么本份，活该是在最底层”

原创　　赢在 8 小时之外　　2020-10-08 14:27:52

昨天，有个老朋友（打工者）私信我，说了一大堆牢骚，总结起来就是一句话：我是个实在人，总吃亏咋办？

我说，你不敢直视自己的欲望，已经不实在了。

其实对于这种人，我的唯一的诊断就是：上了“感情”和“道德”的当，当了婊子还想立牌坊。

收入很低的打工阶层，想要的就是金钱和女人，只要这些有了，大部分的烦恼都没有了。

但是呢，这些穷鬼总想扯到其他的方面上，什么道德理想，什么个人价值，什么坚持原则，这些虚无缥缈的狗屁。

马斯洛需求金字塔是分层级的，你连最底层的需求都没有满足，还想一步登天到最顶层？
