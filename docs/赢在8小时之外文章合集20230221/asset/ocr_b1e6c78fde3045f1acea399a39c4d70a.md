# 大多数你感受到的冷漠，都是真实存在的

原创　　赢在 8 小时之外　　2021-04-04 11:18:01

有个 VIP 朋友私信我，说最近感觉女朋友越来越不重视自己了，自己心很慌，就怕哪天对方提分手，或者背叛自己。

我说，人对于重要的东西，都不会随便对待。大多数你感受到的冷漠，和不在意，都不是错觉，都是真实存在的。

如果势差（吸引力）没有了，要么创造势差，要么放手。学习再多的手段和套路都没有用，这些只会通往更加痛苦的地方。

另外，我经常强调，离开校园后，处理任何人际关系，都不要沉浸在感情里，否则你的心会碎成一片一片的。

不论在感情场，还是生意场，你永远不要去猜测，对方会不会背叛你。你只需要知道，如果对方真这样做了，你完全能承受。

因为你知道，你有随时转身离开的底气，你的选择还有很多。

尤其是男人，一段人际关系如果你不能主导，尽量在开始的时候就别碰，否则你的能量场会越来越虚弱。最后不仅仅是你的感情会破裂，连你的精气神都会锐减。

下面我再聊点扎心的。

如果一个男人，不被身边的人尊重和重视，大概率是因为这个人没有创造价值、创造财富的能力。

女人也是如此，当你什么都不是的时候，就别期待会有人把你当回事，就算你有几分姿色，如果没有实力的支撑，那顶多也只是个玩物。社会是食物链的本质，永远不会改变。

弱肉强食的戏码不停上演，欺软怕硬的剧情永不停息。

实力差的人一定会向实力强的人臣服。

另外，如果你身处底层，就不要太在意人际关系，这些都没有用。

当你经历多了就会发现，身边的人都是靠不住的。

特别是当你生活在社会底层的时候，你会发现，底层的人更不可靠。
