# 喜怒形于色，是需要资本的

# 《阴婚》

原创作  赢在 8 小时之外  2021-11-25 12:15:00

最近有一条新闻比较火，有个主播自杀了，但是她的骨灰被人配了阴婚。

底下的人全部都在谴责，说这种陋习滋生了很多违法犯罪、令人不齿的事件，早该严查了！

阴婚这件事，我还真的目睹过一次。

在农村长大的朋友应该清楚，农村因为交通事故而死亡的人特别多，一个小村庄里面每年都会撞死两三个人。

原因有两个：第一，不尊重规则，很多人的驾照是买来的（我们村以前专门有人做这个生意），不系安全带、超速、转向不打灯、酒驾等情况特别常见。

第二，农村进城或者去市区都要走国道，而国道上大货车特别多（它们遇到紧急情况也不刹车），没有红绿灯，没有中间的隔离带。

我有个堂弟，他的驾照就是买来的，在一个大雾天在国道上发生了车祸（车里只他自己一个个人），车和人都撞的面目全非。

当时他和未婚妻已经订婚了，而且女方已经怀上孩子了。

然后他的父母就给他配了个阴婚，就是在附近村庄找到一个也是刚刚去世的未婚女性，然后把他们合葬在一起，还举行了正规的阴婚仪式。

我不知道他的父母是花钱办的这个事，还是女方父母也正好有这个需求、然后一拍即合。

后来我才知道，原来阴婚是针对特定时期去世的人准备的，一个人在订婚但是未完婚的阶段去世，老人们就会认为，如果不替他们完婚，他们的鬼魂就会作怪，使家宅不安。

如果双方都是这种情况，而且父母们又商量好了，也是可以理解的，毕竟也能抚慰一下受伤的心灵。

但是新闻里那个事件有人触犯了法律，这就是另外一个性质了。

我们隔壁村还有一个年轻人，在船上工作，在一次事故中落海了，最终也没打捞上来（据说是因为风浪太大）。
