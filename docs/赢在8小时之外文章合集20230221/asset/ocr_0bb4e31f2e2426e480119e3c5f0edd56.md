# 《玄学》

原创  赢在 8 小时之外  2021-12-03 13:28:46

什么是玄学？

老子的回答是：玄之又玄，众妙之门。

我总结，喜欢玄学的有两类人。

第一类是金字塔塔尖的人，比如乔布斯、马云之类的人，他们追求到一切可以触摸的成就之后，很有可能会转向玄学，也就是专注于精神领域的突破。

他们可能会去某个寺庙修行，可能会找某个大师论道。

第二类就是金字塔底的穷人。

他们也追逐玄学，并且深陷其中不能自拔。

比如，一个连初中都没毕业的人，他整天去研究身体的“阴虚和阳虚”，研究“气血”，研究“风邪湿毒”，并以此来作为养生的准则。

你问他这些理论有什么科学依据，有没有成功案例，他一定会给你鼓吹一通“玄之又玄”的鬼理论。结果就是，自己的健康状况其实已经堪忧了。
