# 为什么我很少有负面情绪？

原创 赢在8小时之外 2022-09-28 14:31:30

今天在我的

知讯星球

里面，有个星友问我该如何处理“压力、拖延”等负面情绪，我是这样回答的：

![](bbox=[0.26, 0.26, 0.78, 0.48])

有个很奇怪的现象，我的词典里好像没出现过“压力”“逃避”“面对”这些词汇。

如果认真评估的话，我生命里肯定也有各种各样的压力需要面对和处理，但是我真的没有具体想过我目前有哪些压力，我有哪些拖延的地方需要改进。

我只是把手头需要做的事做好，然后去开辟新的收入途径。

所以，与其总是去想这些高大上的“词汇”，不如先把手头的事情做好，然后规划下一步行动。

关注我时间比较长的读者应该清楚，我把很多词汇都从我的大脑词典里删除了。

比如：道德、责任、压力、抑郁、心理健康等等。我工作和生活时，根本不会考虑这些词汇。

是我反常吗？
