# 改变家族命运的人

原 创   赢在 8 小时之外   2022-02-15 12:00:00

从我进入大学校园的第一天起，就实现了独立，包括经济独立，以及在重大事情上的决策。

说好听点，是父母对我 100%放权，从小就给予我充足的自由，放学之后就跑出去疯玩，饿了才知道回家吃晚饭。

说不好听点，父母除了能给予我青少年时期基本生活保障，以及最基础的培养和教育，就没有其他可以传承了，比如资产，以及优质的观念。

这些都是非常宝贵的东西，他们没有什么可传给我，我也不怪他们，因为他们的父母也没有传给过他们。

继续沿着家谱向上推导，很可能会发现我们这个家族一直都没有“传承”这个动作，只是本能的基因传递而已。

当然，也可能有一些优秀的传承，在 WHDGM 以及数次的“斗地主”过程中被打断了。

以前我经常去日本，我就发现他们有很多百年老店，朋友跟我说日本超过 200 多年的企业就有三千多家。

可能就是一家做拉面的小餐馆，或者是一家做陶瓷的小作坊，也可能是像丰田这样的大企业。

它们之所以能传承数百年，一方面是因为大环境的保障，另一方面是因为优秀的家学、家风一直能向下传递。

后来我就想，在我们家族的这个传承链条上，从我这一代一定要做出改变，给后面的人留下可以传承的资产以及优质的观念。

我总结，社会角色可以分成 3 个层次：穷人、中产和富人。

# ① 穷人阶层。

他们基本没有什么财富可以传承，甚至都不会有后代。没有孩子的穷人，年老之后没人照顾，自己又没钱，生活会非常被动。

即使生了孩子，自己也无法为他们提供比较充裕的生活保障，以及良好的教育。所以，等你老了之后你也不要指望他们会对你有多好。
