# 想要赚钱，先清空大脑里的垃圾

原创　赢在 8 小时之外　2021-05-31 16:14:20

昨天 VIP 群里一个成员，私信我，说他在一个二线城市的国企工作，每个月都要去随礼，多的时候一个月能随出去两三千块钱。

自己虽然也在做兼职，但是真的心疼钱啊，而且自己结婚也不知道猴年马月呢，自己现在连女朋友去都没有。

若干年后，即使自己结婚了，那时候早就不在这个公司待着了，怎么算都是血亏。

问我该怎么办。

我好像讲过我之前的经历。

我在国企混了一年半，这期间，除了领导的父亲去世，其余的各种同事的红白事，我一概不参加，因为我知道我早晚得走，我神经病啊给你去随礼。

我当时的工资是用来备考雅思、出国旅行、进大佬社群学习的，还有就是花在让自己觉得享受、觉得爽的事情上，不是给一群跟我没有关系的人随礼用的。

如果一个人想要成长，想要专注做事情，要把垃圾清掉，包括大脑里的垃圾思维，包括身边的垃圾人际关系。

微信上凡是让你觉得不爽的人，统统都要删掉。

现实生活中，大部分人都是过客而已，面子上过得去就行了，你把半数工资都贡献给别人了，你还怎么发展自己？

最终结果就是，由于你手里没有余粮，想要做点什么事，都会畏手畏脚，这会严重影响自己成长的。你连“试错”的机会都被剥夺了。

穷鬼是要给自己留下试错资金的，因为我们输不起。人家富二代，即使试错到了 60 岁，也不必担心，因为有父母在兜底。

穷二代就不一样了，刚刚大学毕业，父母就已经开始向你伸手了。

你整天讲做事留一线，他日好相见。你他吗都穷成这样了，还在这里讲文化、讲道德、讲做人，给你洗脑的人多损呐。
