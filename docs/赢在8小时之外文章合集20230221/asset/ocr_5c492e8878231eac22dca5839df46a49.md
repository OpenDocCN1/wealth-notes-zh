# 《送礼的艺术》

赢在 8 小时之外    2021-11-12 09:48:13

我从小就喜欢听相声，包括传统相声和“非主流”相声。

因为家里的收音机能收到北京和天津的电台，而这两个地方又是相声人才的聚集地，所以我有幸听过所有相声名家的相声，而且 99% 的内容我都耳熟能详，一点都不夸张。

小学和中学时听马三立、刘宝瑞、姜昆、杨少华这类传统艺人的相声，上大学时就已经是郭德纲的天下了。

爱屋及乌，相声演员拍的一些电视剧、电影我也爱看，上中学的时候天津电视台热播的《杨光的快乐生活》非常火爆，当时觉得特别有意思。

现在再看，这部剧其实是很无聊的，但是有一些小桥段拍的特别好，特别传神。而且小时候看不懂的情节，现在都能看懂了，甚至能感同身受。

比如“送礼”这件事，因为我在国企的时候也学会了送礼，所以再看这类送礼的剧情，就特别有代入感。
