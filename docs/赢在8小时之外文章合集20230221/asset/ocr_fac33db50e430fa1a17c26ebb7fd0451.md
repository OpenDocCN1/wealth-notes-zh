# 农村的可怕，不在农村的人根本没办法理解。

1.村里一对兄弟结婚后分家了，大哥先建了房子，建房过程中的顶梁的那些柱子就摆在了房子边上。后来弟弟要建房，找大哥借顶梁的柱子，然后大哥就借给了他。本来事情很简单，用完还了就可以。但是大哥老婆知道了这个事情，瞬间爆发，说不许把家里的顶梁柱借出去，会丢财运。大哥鸟都没鸟她，她觉得没有得到足够的重视，重申并说，不拿回来就喝农药死掉，大哥直接就出去喝酒去了，然后回来的时候，那女的在他进门ories时候喝农药，后来抢救无效死.

没有在农村生活过的朋友可能不清楚，分家、兄弟、婆媳、邻居这些都是敏感词，一点屁事就闹翻，兵刀相见、喝农药自杀这些事也并不罕见。

我之前有一个同事，是四川农村的，他们村里到2002年左右才通上电，他的妈妈和舅妈都是喝农药自杀的。

我问过他，到底是什么原因让她们都选择喝药自杀？

他说，其实根本没什么大事，就是婆媳、兄弟之间的吵架导致的，矛盾一步步升级，最后想不开了就喝农药自杀了。

我小的时候，村里或者隔壁村喝农药自杀的事件也时有发生，有的因为婆媳关系，有的因为被捉奸颜面无存，还有的是妒情。现在农村喝农药自杀的少多了，我觉得跟离婚率上升有直接关系。
