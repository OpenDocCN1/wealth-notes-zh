# 写作 36 计：敏感信息

先说上面的第一个问题：学校给小学生放感恩视频，引导学生哭得稀里哗啦。在我看来这些都是属于滑稽表演，学生不会因为 Task 你放感恩视频就会变得懂事、孝顺。

学校之所以这样做，应该不是为了学生着想，而是为了赚钱。大师最终还是要卖课、卖书，学校能拿到分成。

学校这样做虽然不妥，但也无需太过担忧，小孩子的恢复能力是很强的。

虽然当时被洗脑哭得稀里哗啦，但是你不用担心，第二天他就能吃吃、该玩玩了，早晚把昨天的事情抛到九霄云外了。

当然，如果你特别在意孩子的教育，想给他提供一个宽松、有爱、优质的环境，而且比较有实力，那肯定是发国养老>国际学校>私立学校>公立学校。

不过现在大环境就是如此，仇恨教育、愚孝教育、悲忠教育是避免不了的，没必要因为这件小事就给孩子转校。

# 下面聊聊第二个问题：舍友的素质太差，严重影响自己。

我在知乎上给他建议是：

+   ① 舍导说明送礼，让他帮自己换个宿舍，说自己的舍友人太多影响睡眠。
② 自己赚钱或者向父母要钱，去外面租房。

其实上学时碰到垃圾舍友，进入社会后碰到垃圾邻居，都没有太好的办法，只能换一个环境。

哪怕你花了 500 万买的房子，碰到垃圾的邻居/上下楼，也得换。

我早就看透了，只要你想当好人，那么就一定会碰到很多垃圾人，尤其是当自己很穷的时候。

这时候除了换个环境之外，没有更好的办法。

还有一个办法，就是变成比他们更坏的人，比如我就见过有人受不了楼上的噪音，拿着刀上去谩骂，但是这种极端的方式我们不可能效仿。

不过话又说回来，很多大的趋势和大的概率都是可以预见的。

比如，在生源来源方面，一定是本科生>专科生>技校生。
