# 能花钱解决的问题，绝对不花时间。

这句话如果你领悟透了，你就很容易从打工者/自由职业者跃迁到老板这个阶层。说的通俗一点，老板必须把能交出去的工作全部都交出去，然后把钱分好就行了。

阶层越高的人，越了解钱的工具属性，钱能驱动傻去推磨，更能驱动芸芸众生了。如果你喜欢把钱捏在手里，那么你这辈子注定是劳累命，一生为别人所驱动。

另外，在现实生活中如果遇到问题需要帮忙（比如搬家），能花钱雇佣陌生人尽量花钱，千万不要想着让朋友帮忙，朋友就是用来喝酒聊天的，而且人情债才是世界上最贵的东西。

到最后你就会发现，那些从来不想花钱解决问题的人，他的问题一定会越来越多，永远生活在社会的底层。
