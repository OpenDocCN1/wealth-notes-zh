# 穿人永远不敢正视自己的欲望

原创　　赢在 8 小时之外　　2021-04-21 14:30:34

我记得有个大佬说过这样一句话：买你现阶段认为比较贵的产品或者服务，是最超值的。

对于大部分普通人或者一般的小老板来说，永远有些东西或者服务是你觉得很贵的，但恰恰是这些东西能给你带来非常大的改变或者提升，尤其是思维层次的提升。

我大概是在 2017 年左右的时候，开始接触五星级酒店或者头等舱这些，而且我还会发朋友圈，还会说自己的感受等等，因为给人的冲击力确实很大。

那时候偶尔去日本，我就从北京开车到天津，然后从天津飞关西，头等舱，因为这样比从北京飞能省两三千块钱。

毕竟从办公室到北京机场也有时间成本，还不如直接开车到天津机场，附近的酒店还可以免费停车。

我带着我的团队合作伙伴时，也会请他们住日本的五星级酒店，我记得东京湾洲际酒店一晚上是 200
0 元人民币左右（含早餐）。

对于各种新奇和开眼界的体验，我都会发朋友圈，有新鲜感的原因，也有穷人乍富炫耀的成分。

我非常清楚，有的人看了会觉得我很牛逼，会被吸引；而有的人看了会觉得我很 low，炫耀什么就说明缺什么。

对于这些，我是都能接受的，而且我绝对不会在意身份比我高很多的人的评价，因为那会严重影响我的发展。

很多创业者之所以没有立起来，就是死在了别人的评判标准里，这也不敢说，那也不敢发，就怕那些“高雅”的人批判自己。

客观的讲，组建团队的初期，一定要有能吸引别人的点，如果你的生活让大家觉得高高在上，是仰望的，是羡慕的，这时候你的能量场是要高于他们的，你才有可能把他们吸引过来，然后大家劲往一处使，一起搞钱。

白手起家的人，都是大俗人，哪儿有那么多高尚的想法，而且也高雅不起来。
