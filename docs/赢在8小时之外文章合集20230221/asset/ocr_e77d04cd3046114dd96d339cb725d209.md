# 2023 VIP

厉害的人，上进的人，最终都会达到一种状态：你不付费的话，我压根不会跟你有任何交集。不是因为我势利，或者是缺这份钱。而是因为，跟免费人群聊天，天天秾粹是浪费时间，而且价值差距巨大。而跟付费人群聊天，大家聊的都是实在的、温暖的、充满希望的。

我的这些思想，如果跟免费人群分享，会被嘲的。他们全是负能量。

大部分人做事情，是被恐惧支配的。早起是怕上班迟到，不敢辞职是怕自己找不到更好的工作，跟同事附和是怕被孤立......厉害的人是被希望支配的，做事情的源泉，是因为前方能看到一个美好的未来。这两种思考方式区别非常大。
