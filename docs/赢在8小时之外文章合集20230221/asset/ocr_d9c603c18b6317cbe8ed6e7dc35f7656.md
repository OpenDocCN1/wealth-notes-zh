# 如果你不认为别人伤害了你，你就不会被伤害

原创　赢在 8 小时之外　2020-11-25 12:45:49

这几天我来澳门办点事，因为澳门的防疫政策跟内地普通省份一样了，凭着核酸阴性证明即可出入，回内地之后也不用隔离了。

谈完事情，我就在酒店里刷 YouTube，

我看到一段查理芒格的采访，我觉得特别有意思，至少能引起我的共鸣。

之前我说过类似的话，想要从名人身上学到点什么，不要看他们的演讲，更不要读他们写的书。因为这些面向大众的东西，是不能说真话的，否则会万劫不复。

只能说一些打工者爱听的话，或者灌点鸡汤。

当然，你如果想说真话，比如自己的真实发家史，出版社也不让你出版，因为不符合社会正能量。

比如，你说底层男人想发家，最快的方法就是找一个有钱老妇人；而底层女人想逆袭，最快的方法就是找一个有钱老公。

出版社肯定会把你撵出去。

而访谈就不一样了，很多回答都是临时性的，没法提前编好台词，更多的是即兴发挥，会听到只言片语的真心话。

所以我特别喜欢看国外名人访谈。

Charlie Munger 是巴菲特的黄金搭档，今年 96 岁，身价十几亿美元，身体很健康。

记者问他，这一辈子经历过哪些背叛，怎样看待背叛？

他说，我不会因为人性而感到意外，所以我不允许自己花过多时间去感受背叛，所以你问错人了。

如果这种想法在我脑子里闪过，我立刻就会把它给消灭了。我不喜欢把自己当成受害者，永远都不会。

我就想，还真是这样。现实生活中，大部分人的思维方式都是：抢着去当受害者。动不动就觉得别人伤害自己了，自己很受伤，很憋屈。

有一个判断标准，听到别人充满偏见的言论或者攻击性言论（比如我公众号写的这些东西），立刻觉得就是在针对自己，自己就要对号入座，就要跟他理论、攻击，这就是受害者心态。
