# 为穷人说话，帮富人办事

原创 赢在 8 小时之外 2021-12-06 15:17:49

最近老白火了，一是因为他经典的“不会吧”言论，二是因为他为 LX 集团鸣不平，导致网友都怒了。

后来我就观察，同比是王朔笔下的“肉喇叭”，他跟其他的肉喇叭还真不是一个套路，其他的喇叭都是表面上为穷人说话，背地里帮富人办事。

而这个老白竟然为富人说话，言语上却不放过穷人。他到底想干什么？

这个我也不清楚，因为我没怎么看过他的访谈和书籍，自从进入社会之后，我对一脸正气的面孔天然反感，总觉得他们憋着要坏事。

小时候看国产的影视剧，里面的坏人基本一出场就能看出来，面相就透着一股子邪气，说话阴阳怪调。而男主角永远是一脸正气，说话大义凛然。

结局永远是正义战胜了邪恶。

进入社会之后，我发现真实的情况根本不是这么回事，一个人的好坏并不会在外表和言语里透露出来。

不过话又说回来，为穷人说话，帮富人办事，这是聪明人心照不宣的潜规则，也是能在这个大环境下生存下去的基本法则。

你喜欢听好听的，他们就说给你听，但问题是，光给穷人说好话也不能发财啊，所以他们的落脚点还是要帮富人办事。

所以，从这个角度来看，当一个名人说穷人不爱听的话时，还真的需要认真听一听。

毕竟，大多数人的天性就是喜欢听好话，喜欢听别人夸自己。

之前有位美国社会学家做过一项调查：谁是世界上最善良的人，最应该上天堂？

结果排第三的是乔丹，60%的人把票投给了他，认为他的篮球打得太好了，举世无双，应该上天堂。

排第二的是特蕾莎修女，80%的人把票投给了她，认为她帮助过很多穷人，为维护世界和平做出了巨大的贡献，应该上天堂。

排第一的是投票人自己，98%的人都认为自己是世界上最善良的人，死后应该上天堂。要知道，这些受访者里面也包含杀人犯和小偷，他们都认为自己是无辜的，是善良的。
