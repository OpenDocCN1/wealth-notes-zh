还是举我当年搬运视频的例子。

如果我不做这件事，那我就不会主动去学习英语、字幕压制技术、微博运营技巧。

做了这件事之后，我的英语听力至少突飞猛进了，雅思听力满分，平时看 YouTube 视频根本不需要字幕，能听懂 99%。

我去任何英语国家都不需要带翻译，都能自由交流。

最重要的是，我对社交媒体、粉丝经济、个人 IP 有了很深刻的认识。

今天我写一篇文章就能收到千八百元，进我 VIP 群要收 1500 元，连加我好友还要收 300 元，这些都跟上段提到的这 3 个点相关。

所以，可以这样说，现在我虽然不做视频压制工作了，但是当初的那段经历，对于我的启发意义非常重大。

其实很多成功人士也是如此，你去调查一下，他们赚第一桶金的经历，好像都不怎么光彩，但如果没有当初的那第一桶金，就没有他们今天的成就。

另外，我在公众号里也经常提到一个点：只要你不是靠出卖时间、出卖技术赚钱，那么你的收入只要提升了，就很难降下去了，因为你找到赚钱的感觉了。

这种感觉就像骑自行车，只要你学会了骑自行车，那么一辈子都不会忘了。

对于“粉丝经济”的理解也是如此，由于在 8 年前我就有几万粉丝了，我对于粉丝的运营、维护、营销，还是有两把刷子的。

所以，从这个角度来看，你如果靠视频搬运能积累粉丝，还能探索出几条变现的路径，那也是一件好事。

但是你一定要清楚，这玩意不是长久之计，转型只是早晚的事。

其他任何行业也都是如此，如果打算纯靠技术吃饭，那么你赚钱可能会很辛苦。

但是呢，如果通过做技术这件事，让你的思维认知提升了一个层次，你开始考虑“团队”“营销”“粉丝经济”这些事情了，那么这项技术可能就是把你通向成功的一块敲门砖。
