# 能花钱解决的问题，绝对不花时间

（本文发了好几次都没通过审核，敏感词太多，所以我都用同音字或者形似字代替了）

通过花钱解决问题，能帮我们节省很多的时间和情绪。而时间、情绪、好心情，都是比金钱还要宝贵很多的东西。

穷人花钱，只会买看得见的商品（比如食物、电器），以及最基层的服务（比如火车二等座）。

富有的人，愿意花钱买时间，比如雇佣别人当司机，雇佣别人打扫卫生，直接买头等舱不用等待……
……因为他们非常清楚，自己的时间非常值钱，很多不值钱的事情交给别人来做更划算。

最高级的人，愿意花钱买特权，这个才是最有意思的。

比如说，我去交×局，或者**所等地方去办业务，虽然上面横幅写得清清楚楚：皇牛能解决的问题我们也能解决，我们解决不了的问题皇牛也解决不了。

他说的是真的吗？

这个我不知道，反正我知道我一定优先去找

皇牛

，能节省我大量的时间，和跑腿的精力。

后来我就养成了一个习惯，能用钱解决的问题，尽量花钱解决。

他说，这都什么年代了，老师的签名就是谢绝
