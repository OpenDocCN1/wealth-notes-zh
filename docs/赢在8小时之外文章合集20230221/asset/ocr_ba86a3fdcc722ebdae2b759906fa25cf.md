# 向上进阶，是唯一的出路

原创 赢在 8 小时之外 2022-07-20 12:00:22

YQ 期间，发生了很多驳人听闻或者令人哭笑不得的烂事，很多牛鬼蛇神也都跳出来开始作恶。

小地方尤甚。

我们之所以听到的不多，是因为小地方的人很少使用微博这种社交软件，他们可能只会用微信和抖音，但是你在抖音上稍微抱怨一句就会给你限流了。

所以，声音很难传达出来。

我也听到过很多人抱怨，甚至骂当地的工作人员和 ZC 制定者。

以后这种事情还会不会上演？大概率会反复上演的。

所以，我们能做的是，尽量去发达、文明的地方生活，如果我们这一代做不到，就尽量为下一代做铺垫。

地域迁徙，是改变命运的最佳方式。

文明和开放，一定是一线城市优于二线城市，二线城市优于小县城，小县城优于乡镇农村。

所以才会出现农村人进城、城里人进市、市里人进一线城市、一线城市移民发达国家的现象。

漂亮而又有文化的女人，嫁人也是这个趋势，一定是往上走的。

那么，大城市一定比小县城更文明吗？

至少在我们这片土地上是这样的。

我之前去英国的时候，专门去了牛津小镇，大名鼎鼎的牛津大学就坐落在这个小镇上。

英国向来是以绅士和淑女著称的，我的感受是，小镇上的人比伦敦这样的大城市还要文明。

因为大城市有很多外来人口，成分比较杂。

尤其是服务人员，很多都是印度人，以及其它发展中国家或者落后国家的人。

牛津小镇上有世界顶级学校，医院，实验室，图书馆，还有劳力士、LV 的专卖店，还有特别唯美的咖啡馆和大大小小的精致餐厅。
