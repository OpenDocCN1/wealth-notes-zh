# 一定要远离打击你的人

我就见过两个笨鬼因为争论特朗普到底好不好而骂起来的，我猜他们骂完后挤地铁回出租屋吃泡面去了，当然，手机里依然刷着国际形势，内心依然激情澎湃。

一般追星或者崇拜某个偶像，然后极力维护偶像形象的，大部分都是神经病。如果是学生还可以理解，但是三四十岁的人了，还相信这些虚无缥缈的东西，那真是令人绝望。

当然，这些喜欢跟别人杠的人，也就是不会做人而已，没什么大的伤害。但是呢，有一种人一定要远离，就是喜欢打击你的人。

仔细观察一下身边的人，包括亲人，如果他张口闭口都是在跟你说负能量的话，都是在否定你，打击你，阻碍你的进步，那么一定要早点离开他。即使是父母，也要尽早搬离出去。

最可怕的谋杀就是谋杀一个人的精神。

如果是朋友经常否定你，打击你，那么大多是因为，他特别害怕你会比他过得好。如果你混的风生水起，那么他的心里很可能会生发出一股难以压抑的恨意。

对外界的所有恨意，其实根源上都是恨自己的无能。

就像东野圭吾在《恶意》里写的那段话一样：

> > 我就是恨你，明明你那么善良。我恨你抢先实现了我的理想，我恨你优越的生活，我恨当初如此不屑的你如今有了光明的前途，我也恨我自己的懦弱，我恨我自己的运气不够才能不够。我把对我自己的恨一并给你，全部用来恨你。
