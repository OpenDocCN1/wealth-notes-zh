# 喜欢谈技术的人，永远跟赚钱无缘

原創    赢在 8 小时之外    2020-06-08 15:51:31

最近这几天在大西北转悠，一共走了宁夏、青海、甘肃、新疆这几个省份。给我印象最深刻的省份，就是青海了，雪山、沙漠、草原、湖水，该有的都有了。

我觉得青海完全可以跟瑞士媲美了。

去年我去了一次瑞士，爬了铁力士峰，坐了金色列车。回国之后，我觉得对所有美景都免疫了，原来瑞士就是美景的“上限”啊。

但是呢，青海的景色更加壮阔，更加厚重。从西宁开车到青海湖要 3 个小时，从青海湖到茶卡盐湖又要 4 个小时。沿途的风景，无论是湖水、草原还是雪山，都可以用“一望无际”来形容。

这次行程一共有三个人，另外两个都是比我牛逼的朋友。

一个朋友戴手表是卡地亚蓝气球，我觉得比劳力士漂亮太多了，劳力士大部分水鬼、日志系列，我觉得都没有什么美感可言，土不堪言。

尤其是众人追捧的绿水鬼，在机场的国际出发那里，随便一个乘客都是戴绿水鬼的，看见我就觉得恶心。因为戴的人实在太多太多了，咱也知道真假的，逛淘宝所的都戴绿水鬼。

当然，卡地亚的机芯肯定跟劳力士比不了，保值率、稳定性这些，劳力士肯定吊打卡地亚，这是公认的事实。

但是蓝气球漂亮啊。

我就跟他说，咱们俩换着戴吧，我把劳力士给你戴一段时间，你把蓝气球给我把玩把玩。

因为他也有很多块表，也无所谓的，我们就换着戴了。

后来我就发了一条说说：刚到大西北，就收了一块蓝气球，运气真好。

底下评论就有不止一个“聪明人”开始说了：这个表就是悠悠傻子的，不懂表的人才买卡地亚，然后又 BB 了一大堆。

我就把这些傻鬼一一拉黑了。

因为我知道，这些人都是又穷又傻又屌的“聪明人”，他们平时最喜欢研究的是配置、技术、性价比、保值率。
