# 没事不要随便下水救人

原创  赢在 8 小时之外    2021-08-11 13:28:00

最近有一条新闻很火，一个 17 岁少年救了 3 位女孩，自己却牺牲了。而那 3 位女孩中有一位还翻脸不认人，冷嘲热讽。

报道是不是属实，这个不好说，但是因为下水救人而自己牺牲的事件，却是经常有报道。

我学游泳时，教练跟我说的第一句话就是，除了正规游泳池之外，不要去任何野外池塘、湖水、海水里面去游泳。

第二句话就是，不要随便下水救人，救人者更容易溺水死亡。

![](bbox=[0.25, 0.337, 0.875, 0.56])

一方面，水底的情况我们看不到，可能有很深的淤泥，可能有缠绕的水草，这些都很致命。

另一方面，你去救人的话，对方可能死命地拉着你，缠着你，让你丧失游泳能力，最后只能同归于尽。

君子不立危墙之下。

我是在 27 岁的时候才开始学习游泳，后来我也教会过几个朋友如何游泳，我觉得单从“会游泳”这个角度来看，我教的比教练还要快，因为教练更侧重的是每个动作都要标准、要专业。

而大部分人最需要的技能是：掉在水里淹不死，而且能游几分钟到岸边的能力。

我总结，游泳最难突破的有 3 点：第一是学会心平气和地放松，让自己漂起来；第二是换气；第三是从浅水区到深水区过渡。
