# 没钱就不要特立独行

原创 赢在8小时之外 2022-05-19 12:00:34

昨天有人私信我，问我是怎样看待纹身的。

我说，如果你已经纹了，那就不要再去想这件事了。

如果还没有纹，还在犹豫，我觉得你可以看看你父母的收入如何。

如果你的父母很有钱，在大城市有几套房，那么你可以去追求自由，可以去做很多特立独行的事。

如果父母很穷，那就别搞这些么蛾子了。我之前在公众号上说过一个扎心的观点：

# 一个人如果在30岁之前，事业不顺，或者婚姻不顺，原因只有一个：你的父母太穷了，太差劲了。

没有第二个原因。

无论你身上有什么恶劣的品质，差劲的能力，如果一直往上推导，最终的根源一定是父母贫穷导致的。

而那些出生在有钱家庭的孩子，他们在上学、就业、婚配等任何一个维度，都是有很多选择的。

相当于上一辈人的奋斗，给孩子的人生打开了很多扇门，开辟了很多条路。

当孩子面临重大人生选择时，会发现前面可以走的路太多了，而且都非常宽敞，走哪条都可以。

另外，有Road上停着跑车，有Road上已经架起了铁轨。

这时候他们想纹身就可以纹身，想追求艺术就可以追求艺术，想环游世界就可以环游世界，想开一家公司就可以开一家公司。

而穷鬼家庭出身的孩子，无论在任何一个人生节点，选择都是极少的，面前可能只有一两条羊肠小道，而且充满泥泞，还有很多牛鬼蛇神在路边等着袭击你。

这时候你的选择本来就少，就别再把本就不宽敞的道路给堵死了。

要知道，有纹身的不能做军人，不能考公务员，不能做空乘人员，不能做很多高端行业的服务人员。
