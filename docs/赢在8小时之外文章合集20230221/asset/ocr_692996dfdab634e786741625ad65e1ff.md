# 远离自带毁灭倾向的人

原创 赢在8小时之外 2022-11-10 13:39:32

西芳有一则特别有趣的寓言，大概内容是这样的：

一只� Chrys 要过河，它向善良的青蛙求助。

青蛙说：“你的尾巴上有虱子，万一你蛰我怎么办？”

蝉子说：“不会的，如果我把你蛰死了，我也会沉入水底的。”

青蛙听了之后，觉得很有道理，于是就背起蝉子过河。

游到河中央的时候，青蛙感觉背上一阵刺痛，回头一看，果然是蝉子蛰了自己。

快要没入水面的那一刻，青蛙质问蝉子：“为什么明知道会沉入水底，你还要蛰我？”

蝉子说道：“对不起，这是我的本能，我也不想，但是真的忍不住。”

于是双双殒命。

这则寓言的浅层寓意是：要警惕别人的坏习惯成为你背上的“蝉子”。

如果明显对方有某种恶习，那千万不要轻易相信他关于改变习惯的承诺，更不要试图改变对方，否则，你也很有可能会被拖下水。
