# 如何获得贵人的帮助？

原创 赢在8小时之外 2022-08-20 12:00:24

昨天有付费好友私信我，想知道如何才能获得贵人的提携。

我在文章里其实提到过很多次“贵人”这个概念（大家可以在我公众号里搜一下），但是没有系统归纳过，今天正好借着这个问题总结一下。

都是我亲身的经历，绝对原创。

贵人，其实可以是一个很大的概念。

在我看来，那些愿意给我们指明方向的、愿意拿出真金白银给我们投资的，或者仅仅是给我们精神支持、语言鼓励、衷心祝福的，其实都可以算是贵人。

简单来说，凡是能赋予我们能量的，都属于贵人。

那么怎么才能让身边的贵人越来越多呢？

我总结了以下几个原则：

# ① 当有很多人希望我们成功时，我们自然就更容易成功。

这一点也是我在公众号文章里经常提到的。那么，怎么做才能获得别人的衷心祝福呢？

其实很简单，如果你的成功和崛起，也能让很多人分到一杯羹，那么这些人自然会从心底祝福你，由衷地希望你越来越好，甚至在行动上也会有所表示。

这篇文章里我提到了一点：有很多 人抄袭我或者仿写我，从而获利，我从来都不会追究的，更不会到处去维权、投诉。

因为我非常清楚，这些人能靠这些钱养家糊口，也算是一份生计。

真金白银是世界上最高级的供养，所以他们每天一定从心底为我祝福，希望我的公众号不要倒下，希望我健健康康的，不断创作出更好的作品，为他们提供更多的创作灵感。

他们的这种祝福，甚至比烧香拜佛还要虔诚，没有一丝一毫虚假的成分。
