# 为什么我从来不相信人品

# 如果一段关系你不能主导，请及早放弃

原创　　藏在 8 小时之外　　2021-03-26 23:55:57

最近在收拾家里的破烂，我把可用可不用的东西都处理掉了，或者是扔了，或者是送人了，稍微值钱一点的我就挂闲鱼上给卖了。很多旧书都在 VIP 群里送给大家了。

因为我发现很多东西，比如我从国外带回来的各种马克杯，各种模型，各种小玩意，以及我收藏的各种旧书，它们不仅占据屋子里的空间，还占据我的心里空间。

以前我购置这些东西时，想的是我以后每次把玩它们的时候，都能回想起这个东西是在哪个国家购买的，什么时间，跟谁，多有意义。

而现在我很清楚，这些小回忆很难让我感动了，我已经到了需要做减法的人生阶段了。每当我处理完一件东西时，我觉得非常痛快，还会有继续处理的冲动。

原来断舍离是会上瘾的。

后来我就发现，凡是家里堆满了很多东西的人，都比较穷；而富有的家庭不会轻易买东西，家里特别宽敞、整洁。

如果什么东西你都觉得有价值，都不舍得扔，那说明你还很穷。

不光是东西，项目也是如此。一个人如果过了 30 岁，应该能确定自己最擅长的点了，也该清楚团队最赚钱的项目是什么了。

这时候应该聚焦到一个点上，重点发力，去把它做大做强，而不是今天谁说 A 平台是风口你就去做 A，明天谁说 B 平台是风口你就去做 B，否则的话你始终飘忽不定，没有根基，立起来的概率就很小了。

最后再来聊聊我心的人际关系。

想要解决大部分的人际关系，最有效的方法就是放弃。

如果一个人说话办事都非常温文尔雅，可就是身边没有几个朋友，和同一个圈子里的人也融不到一起，那你一定要搞清楚，并不是因为这个人很孤僻，而是他非常清楚自己想要的是什么。

而且在心智上，他早就超过了同龄人。

大多数人是不知道自己到底想要什么的，每天浑浑噩噩，从来不敢得罪人，还非常怕错过潜在的贵人。

比如，有朋友叫你参加饭局你就去了，妄想着去蹭点人脉。
