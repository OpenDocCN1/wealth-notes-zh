# 凡是有本事的人，都不好控制

原创 赢在 8 小时之外 2021-08-14 13:15:50

很多人咨询我感情问题，这个话题其实挺无聊的，因为男女之间不就那么回事嘛。

男人找女人，本质就是见色起意，用钱钟书的话来说，就是“生殖冲动”。在这个基础上再去谈其他 的，比 如性格、家教等等。

女人找男人，最喜欢的是有本事、有实力、有上进心的人，这个是符合进化规律的。无论是一万年 前，还是今天的 xx，群居动物里面，只有少数的首领们，才有丰富多样的交配权。（参考官员、富 商和明星）

大家可以细品。

但是呢，现在还有很多女人既慕强，又喜欢聊“三观一致”，我觉得这些人比猪还蠢。

无论男女，只要是特别上进的，而且白手起家赚到第一桶金的，那三观肯定跟普通人不一样。

对于你来说，他是没有什么感情的，他更在乎的是利益得失。

因为从底层向上攀爬的过程，是伴随着血与泪的，他们的奋斗史，就是不断丢掉自己幻想的过程。

所以说，只要你面对一个白手起家的人，你会清晰地察觉到，这个人几乎是没有什么情绪波动的。

一个人经历越多，他丧失的感情就会越多，剩下那一丁点的感情他也会小心翼翼地藏好。因为他们 非常清楚，很多宝贵的东西都是靠争抢的，但是感情这个东西反而是越淡越好。

当然，这些人并不是不渴望感情，而是非常清楚，感情已经变成了奢望。往往这种冷血无情，都是 底层奋斗人共同拥有的特征。

如果你非要说，我既想白手起家，又想情感丰富，不行吗？

我的回答是，真不行。如果你这样做了，最终一定会被坑的体无完肤。

原因很简单，只要你身处底层，你遇到的大部分都是贪婪的垃圾人，这个是由环境决定的，由不得 你。

你对他们动感情，他们除了会坑你、控制你之外，就没别的了。

另外，如果你身处底层，也永远不要轻易去取悦别人、感动别人、把别人的感受凌驾于自己的感受 之上。
