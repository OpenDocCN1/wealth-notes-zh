# 我每写 1 个字，可以赚 0.76 元

原创　赢在 8 小时之外　2021-04-09

11:19:38

最近几天我都在安徽宏村，虽然不是晴天，但是空气质量很好，也很湿润，特别适合我居住。我是专门等到清明假期结束后才过来的，因为我真的受不了一堆人挤来挤去的，体验非常差。

在北京或者河北老家的时候，如果是春季、秋季、冬季这 3 个干燥的季节，每天早上洗脸的时候我都格外小心，碰到鼻子的时候，力气稍微大一点就会流鼻血，我觉得每年我流鼻血的量比女人大姨妈出血还要多。

一点都不夸张。所以每次有朋友跟我提“献血有益健康”这种理论时，我都会说，要献你去献吧，我的血液每个月都会更新。

在家里或者办公室流鼻血也就算了，最要命的是，有时候在高速上开车时，根本没碰它就开始流了，非常尴尬。

但是我一到江浙沪或者广东的时候，所有的症状都消失了。

安徽不知道算不算南方，但是我一到安徽，鼻子也好了，一次都没有流过。而且鼻头上的白条和黑头都可以直接用洗面奶洗掉了，特别顺滑，难道湿润的气候还能去黑头？

我平时很少看电视，在酒店里无聊就打开看了一下，CCTV 有个纪录片频道，是拍摄的作家迟子建，她是《额尔古纳河右岸》的作者。我虽然没有读过这本书，但是她的各种短文、书摘我从小就读过很多，特别喜欢看。而且纪录片里的黑龙江场景，我也都有共鸣，因为我在那里生活过几年。
