# 屌丝逆袭之后，迎接他的只有孤独

昨天跟朋友吃饭，聊到“老同学”这个话题，我就说，我的老同学、老朋友，保持联系的基本没有了，有也不超过 3 个。他们联系我我基本不回复，或者拉黑处理了。

他就说，朋友还是老的好。

我说，你可以有老朋友，但是我可没有你那样的资格。

他问，维持老朋友还需要资格？

我说，当然需要了。你从小家境比较好，你朋友父母的阶层，跟你父母的阶层也差不多，都很优秀。你们进入社会之后，发展也都差不多，都很稳定，当然可以一起玩了。

但是像我这样的屌丝可不一样。

有一个残酷的真相：出身平凡但是很聪明的人，他一定是很孤独的。

因为原来的朋友，不可能跟上你发展的脚步，你只能不断地淘汰圈层。

刚跟一群人玩熟了，过了两年你会发现，他们又跟不上你的脚步了，因为他们的收入止步不前。你就得去结识新的朋友。

成长速度越快，孤独感就越强。但是你身上肯定会带着原有出身的烙印，融不进更高的圈子，却也回不去原来的圈子。

所以，一定会很孤独，这就是高速成长的代价。

另外，我在公众号写过一个观点：富有就是对贫穷的背叛。背叛，是一个撕裂性的词汇，意味着跟过去的一切说再见。

你发展的飞快之后，你会发现，之前的那些穷朋友、甚至是父母的一些价值观，已经跟自己的价值观发生背离了，你想要发展，只能背叛他们。

我之前就说过，古代造反成功的皇帝，上台之后都极力反对儒家思想，甚至屠杀儒生。

原因很简单，老子就是靠造反起家的，你们这帮傻逼竟然敢跟我说“君君臣臣父父子子”？

当然，父母比较特殊，在我辞掉铁饭碗出来创业的时候，也发生过一些矛盾。但是呢，看我发展好了之后，他们也是非常支持我的。
