# 互相利用，才是人际关系的本质

原则　　赢在 8 小时之外　　2021-03-08 01:25:54

VIP 群有个人私信我，跟我讲了一堆他跟朋友之间的矛盾，到现在也不知道该怎么处理合适，总之就是这段人际关系很拖累自己。

两个人是发小，但是职业发展已经不在一个轨道上了，很多话题都聊不到一起去，互相谁都说服不了谁。

我说，任何一段人际关系，如果你非要掺杂感情进去，那么大概率你会受伤的。

你总想着，是朋友就应该互相理解，互相支持，要把友谊放到第一位，把感情放到第一位。

但是呢，进入社会之后，你就会发现，这样是根本行不通的。

等你碰壁次数多了之后，你就会认识到，朋友就是用来互相利用的而已。

如果一个朋友不思进取，让你觉得是拖累，你就直接抛弃他即可，不用有感情负担，因为他已经没有利用价值了。

过两年之后，当你发现他起来了，有利用价值了，就可以一起搞钱，这时候大家就又是朋友了。

哪有那么多感情因素，哪有那么多的义气千秋。

也不存在记仇不记仇，谁会跟钱过不去，大家都是成年人。

反过来也是一样的道理，如果你的某个好朋友起来了，就不搭理你了，千万别怨恨对方，说明你们的成长速度差太多了，你需要奋起直追了。

另外，我想给关注我公众号的创业者们一句忠告：事业维度的任何问题，都不要去咨询你身边的朋友。

你所谓的那些朋友，如果真的比你高几个维度的话，他们就不会在你身边了，你压根就搭不上话。

愿意跟你聊天的人，都是跟你水平差不多的傻屌丝，解决不了实质性问题。
