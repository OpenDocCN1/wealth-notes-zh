# 28 岁，终于活成了父母眼中的笑话

原创 赢在 8 小时之外 2022-06-20 12:40:09

昨天是父亲节，有个粉丝私信我，说她最近都不心思跟父母联系了，因为她觉得自己成了亲戚眼中的笑话。

她自己按照父母的意愿选了专业，也考了研究生，还拿了很多奖项。

但是只有她自己知道，自己根本不喜欢做学术研究，读研期间，每天活得都很痛苦和压抑（老师把她当打杂工使用）。

研究生毕业之后，一心都扑在工作上，却成了大龄剩女。

由于疫情的影响，上一家公司裁员了，自己工作也丢了。

虽然找份工作不是难事，但是想要找到心仪的工作，比登天还难。

自己长得很一般，也不太会说话，找个理想的对象也不是件容易的事。

父母虽然没说什么，但是她明显感觉到，父母是希望她早点嫁人的。

她说，这么多年来自己一直是乖乖女，现在事业和爱情却双双失败，终于成了家人和亲戚眼中的笑话。

我觉得她这种现象还是很普遍的，无论男生还是女生，活在父母的期待中都是一种煎熬。

我的建议就是，成为“笑话”要趁早，最好在 18 岁的时候就要戳破父母的美梦，尤其是那些不负责任的垃圾父母。

稍微负责任一点的父母，在孩子成年那一天起，就该着手给孩子准备房子了。在孩子毕业的前两年就该给孩子着手安排工作了，或者准备留学的资金、创业的资本。

如果家庭条件不好，什么都没有给孩子准备，那也可以理解，毕竟对于很多父母来说，能把孩子养大就已经用尽全力了。

但是，这时候父母就不要对孩子的发展路径指点点了，也不要对他有什么期待，更不要有任何约束。

你们本身就是世代穷鬼出身，还指望孩子能一飞冲天？

有点异想天开了。
