# 文字是人类逻辑的最后根据地

原创 赢在8小时之外 2022-12-15 12:01:50

昨天在星球里，有人私信我，想知道：进入社会之后该如何提升学习效率？有没有哪些原则或者策略可以采用？

我说：提升学习效率的目的是提升工作效率，提升工作效率的目的是提升赚钱效率，所以我们不如直接聊“提升赚钱效率”这个话题。

因为这个话题几乎是所有人都会碰到一个瓶颈。

但是呢，这个世界上几乎不存在这样一种清晰的法则，能让我们在一个月内学习效率、工作效率提升20%，从而自己的收入也提升20%。

否则大家也用不着挨个的事情了，每天都去学习这些法则就够行了。

但是呢，这个世界上确实存在一部分人，他们在年轻时成长飞快，才两三年不见，他的收入已经翻了好几番了。

世界和生命玄妙的地方也在于此。

我自己其实对于“效率”这个词是没有任何概念的，我根本没有想过这件事。我认为这个词是个低级词汇，是学生和打工阶级最喜欢研究的。

我更喜欢“熟悉”、“手感”、“炉火纯青”这些没法量化的词汇。

之前我提过很多次“1万小时理论”，大概意思是：1万小时的修炼，是任何人从平凡变成世界级大师的必要条件。

大概过程是这样的：先经历几千小时的训练，才会逐渐熟悉一件事；再经过几千小时的训练，才会找到手感；再经历几千小时的训练，才能达到炉火纯青的境界。

换句话说，在这个过程中，人是一次次突破、一层层蜕变的，没法用“效率”这种词汇来形容。

或者也可以这样说：在你找到手感之前，先不要考虑“效率”这件事，你必须要<|start|>有压倒性的投入。
