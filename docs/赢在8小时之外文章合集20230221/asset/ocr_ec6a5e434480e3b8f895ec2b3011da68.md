# 承受不了孤独，就不要创业

原创　赢在 8 小时之外　2021-05-25 11:27:19

以前我没钱的时候，我特别羡慕有钱人，觉得他们才是人生赢家，只有有钱了，才能心情舒畅，才能自由自在地享受生活。

等我也有了一些钱之后，我才发现，有钱人真的不值得羡慕。

大部分有钱人的钱，都是他劳动得来的。脑力劳动，体力劳动，总归有一个在劳动。

靠脑力劳动的人，每天都在算计，都在规划，都在筹划，他的大脑一刻都不能停歇，否则整个公司的人都得跟着自己喝西北风。

靠体力劳动的人，得到处去跑业务，还要陪客户喝酒，伤胃伤肝这些代价也无所谓了。只要能把单子拿下来，也就觉得值了。

另外，大家也不要羡慕那些开豪车的美女，她们的钱，除了是靠脑力和体力赚来的之外，也可能是父母或者老公赚来的，要么就是自己交易过来的。

不要鄙视别人，也不要羡慕别人。

能赚到钱的人都是很辛苦的，都是要付出代价的。

我从来不歧视任何人，包括当小三的，做鸡做鸭的，他们都是在做交易而已。只不过他们拿出来做交易的筹码，大部分人不愿意拿出来而已。

富二代们赚钱，相比创一代而言，要容易一些，但是他们想要获得尊严和尊重，就难了很多，他们永远都会活在父辈的阴影下，这种痛苦不是多赚多少钱就能够弥补上的。

再有钱、再富有的人，也需要遵循马斯洛需求金字塔，一一级一级往上爬。
