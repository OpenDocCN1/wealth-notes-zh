# 喜欢囤积资料，是一种穷病

比如，真正美好的东西，都得用真金白银或者宝贵的青春，去兑换，去争取，去经营。真正厉害的人，一定是不断积累筹码，让自己兑换资源的能力越来越强。

金钱、美色和武力，都是可以兑换资源的筹码。理论上，如果你的金钱足够多，马云都可以为你端茶倒水；如果你的美色倾国倾城，国王都愿意为你发动战争，甚至不惜亡国；如果你的武力足够强大，你拿枪指着任何人，他都会对你言听计从。

但是对于大部分人来说，这三样都没有，他就很容易去寻找捷径，而且捷径的背后一定隐藏着杀机。

那些很容易就得到的东西，大概率不会让我们成长，也不会让我们获得幸福，甚至会把我们带入深渊。

比如，碰到免费的资料，便宜的产品，廉价的服务，收入低的人，你就像碰到鬼一样，绕道走，你的前途肯定是一片光明。
