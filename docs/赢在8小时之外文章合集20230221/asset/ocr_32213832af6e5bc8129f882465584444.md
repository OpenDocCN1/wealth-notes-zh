# 30岁之后的赚钱方式

原创 赢在8小时之外 2023-01-01 19:28:51

昨天是2022年的最后一天，我按照之前的约定，把那个付费社群都解散了。

心里还是挺不舍的，但是没办法，天下没有不散的筵席，内心知道早晚有一天会分离，这样在相聚的日子里才会更加珍惜。

我现在写东西这个公众号也是如此，我天天口无遮拦乱说话，没准哪天也就消失不见了，大家且行且珍惜吧。

熟悉的人都知道，我是从来不过元旦、春节这些法定假期的，因为我赚钱、成长是连续不断的，没办法按照“年”来进行划分，更不会制定什么新年计划。

但是呢，我知道 ak 有很多人喜欢制定新年计划，比如学习、赚钱、健身等方面的计划。

从我自己的经验来看，按照时间节点来制定计划，一般都不会有什么效果。

反而是人生中许多“顿悟”时刻，才是促使我们进入下一个人生阶段的关键。

举个例子，我在27岁左右的时候就意识到了一个非常严重的问题：如果我继续研究技术、继续打工、继续做具体的事务，那么我这样子可能就会废了。

我将一无所成，跟着一群穷鬼每天挤地铁、上下班、还房贷、处理家庭的一堆琐事。

在职场上，奔三或者超过30岁的人，其实就不过适合继续打工了。

因为这个年龄段的人已经有自己独立的思想了，自尊心也开始觉醒，也会开始思考自己存在的意义，思考人生的意义。
