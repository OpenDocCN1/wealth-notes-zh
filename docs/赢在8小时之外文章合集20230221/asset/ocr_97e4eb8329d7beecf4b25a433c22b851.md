# 林芝之行

原创 赢在 8 小时之外 2021-06-25 21:42:31

最近这几天在西藏林芝待着，由于海拔较高（3000 米），含氧量是平原地区的 70% 左右，不能剧烈运动，走路稍微快一点就得喘，而且经常是头昏脑涨的。

同行的朋友状况好很多，几乎没有任何高原反应，但是也不能剧烈活动。

去年的時候，由于没法出国，我就走了很多西部省份，包括甘肃、宁夏、新疆、青海和西藏，能乘飞机就不坐火车。

西藏直接去的拉萨，海拔 3700 米，我当天就出现高反症状，头发胀，呼吸比较费劲。

所以每天我都要去酒店前台吸氧（免费的），然后去布达拉宫门口溜达溜达。

我们本打算去里面参观的，但是走到半山腰的时候（布达拉宫是依山而建的），所有人都觉得缺氧了，特别难受，就全都退回来了。

不仅仅是觉得爬山累，更重要的是，我们对于各种“人文景点”已经免疫了，提不起来一点兴趣。

我自己是一听到 5A 景区、4A 景区就头疼，因为大部分这些景区就是把人圈起来收钱而已，人工雕琢的痕迹太明显。

最重要的是，无论任何时期去国内任何景区，都会有一堆人在那里挤，很不爽。

我在拉萨待了 4 天，高反症状依然没有缓解，但是也没有加重，我就飞回家了，他们去了纳木错这种海拔更高的地方（4700 米以上）。

这次我学乖了，先来海拔比较低的林芝过渡一下。到林芝第一天有头胀的现象，第二天就好了。

西藏对于很多人来说还是很神秘的，很多人都把去西藏定成了旅行的终极目标。

其实你如果真去一次就知道了，去西藏的交通其实很方便，国内很多城市都可以直接飞拉萨，哪怕不能直飞，也就是转一次机的事。

如果不怕折腾，从西宁坐火车过去也行，还能逐渐适应高海拔。

拉萨这个城市，除了海拔高之外，跟其他城市没有本质区别。

这里有各种各样的商场（比如万达广场），各种各样的酒店和餐馆，你所在的城市能买到的商品或者服务，这里也都能买到。拉萨不仅仅是个旅游城市，也是西藏的省会，拉萨几十万市民日常生活需要的商品和服务，拉萨都能提供。
