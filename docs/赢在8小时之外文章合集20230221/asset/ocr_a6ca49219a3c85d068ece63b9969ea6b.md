# 一事无成的老扇丝

原创 赢在 8 小时之外 2023-01-03 18:38:33

最近一个月，风向变了。

XX 重新给 VQ 下定义，说这个病毒其实并没有那么可怕，大家不用太过担心。

然后，几乎是一夜之间，至少有几亿人，从惧怕它，到接受它。

大家没觉得哪里出现了严重的问题吗？

我觉得问题很严重。

外部的客观世界几乎没有发生任何变化，但是几亿人的主观世界已经发生了翻天覆地的变化。

换句话说，这些人的恐惧与希望，都是由外部引导的，异常可悲，也非常可怕。

即使躲过了这一劫，以后也会有更大、更快的镰刀在等着他们。

除非？

除非他们重新换一个脑子，从此对自己的喜怒哀乐、恐惧、希望负起 100% 的责任。

大家知道为什么 XX 没信心吗？

原因很简单：信来信去，最后发现都是自己吃亏，都会被狠狠地收割。

这时候又会有人跳出来告诉你：吃亏是福；吃得苦中苦，为人上人。于是你又开始信仰“吃苦耐劳”的文化，然后继续被收割……

那么问题来了，怎么才能让自己的智商重新占领高地呢？如何区分信息的真假呢？

很简单，我跟大家分享两个原则。

# 原则一：认清对方传达信息的目的。

我之前说过很多次了，世界上不可能有真实的新闻报道，所有新闻部门都是为了赚钱办事的，然后把老爷爷送到 M 国去。

所以，无论是电视里、手机上出现的任何新闻报道，你都当成笑话来看即可。
