# 为什么总有人喜欢践踏你？

原创　赢在 8 小时之外　2020-07-31 20:35:20

我们曾如此期待他人的认同，到最后才知道，世界是自己的，与他人毫无关系。—— 杨绛

我在公众号写的这些东西，其实是给特定人群看的，主要是老板朋友，不适合大众人群阅读。

但是呢，我如果知道有哪个朋友，自从看了我写的东西，收入更高了，人际关系更加清爽了，自己的生命感更强了，我还是非常有成就感的。

昨天有一个 VIP 群友私信我，说这么多年了，自己的感情和时间都让垃圾的原生家庭给践踏了，她一直被当作免费劳动力来培养的，付出再多家里也不会满意。

我觉得在被 R 家文化毒害的 G 家，出现这种情况很普遍。人们普遍没有自我，一味为别人着想，病态地学习 LF。

付出太多之后自己又觉得太亏了，如此往复，心里的能量一直不会平衡，直到死的那天，内心里也会在惦记着这辈子亏欠了谁，谁又对不起自己。

我在 VIP 群里经常跟大家说的一个思维就是，永远也不要做下贱的事，永远也不要去做低价值的事。

比如，我有时候开车回老家，如果有亲戚来串门，临走时如果父母想让我开车送送，我会立刻找借口拒绝掉。

因为这件事价值很低，司机的工资也就一个月几千块钱。如果我抽出一小时去送这些低价值亲戚的话，我损失的不仅仅是这一小时生命，而且还要被他们猪脑子里的那些鬼理论污染掉。

而且，你如果免费服务了比你身份低很多的人，那么他们会非常瞧不起你，认为你很贱，你的时间不值钱，可以随意支使。

但是呢，在你服务完他们之后，他们绝对不会念你的好，反而会一味索取，一旦你拒绝一次，他们就会恨你：说好的免费劳动力呢？说好的任劳任怨呢？中华传统美德不懂吗？你父母怎么教育你的？

有一个扎心的真相就是：如果你不在乎自己的时间，那么就会有很多人来践踏你的时间。

这些人可能是你的父母，可能是你的孩子或者另一半，可能是你的同事。

当然，本质上是因为你很贱，不珍惜自己的时间，才会招致一些苍蝇来践踏你。
