# 脑部运动，才是真正的贵族运动

原创　　赢在 8 小时之外　　2021-01-06 15:03:03

今天早上在老板 VIP 群里，有人在讨论新冠疫苗是不是应该打的问题。

我就给大家泼了一下冷水：咱们群里尽量别讨论跟医学相关的事情吧，因为“医学”是个人信仰级别的话题。

哪怕只有两个人，讨论这些也会产生分歧：先是各自举出自己的论据，摆事实讲道理，最终的结果一般都是互相诋毁。

更不用说一百多人的群了。

其实呢，医学进展，科技进展，宇宙知识，细胞知识，转基因知识……这些理论知识，可能隔几年、几十年就会被砖家推翻一次，我们何必去较真呢？

好好赚钱就行了。

我自己每天都运动，而且尽量做能让心率上升很快的运动，比如俯身登山、开合跳等等。

让心率维持在 120–130 之间，砖家说这样燃脂效率最高。

间歇的时候也会做俯卧撑、引体向上和卷腹，等心率下来时继续做高心率运动。

歇歇停停，半小时大概能消耗 200 大卡的热量（Apple Watch 监测），每天我都完成燃烧 550 大卡的目标。

我在饮食没有任何节制的情况下，体重已经好几年没有变化了。

其实我的目的并不是减肥，而是想增强心肺功能和免疫力，让颈椎、腰椎都得到活动，就可以了。

至于说健美、练腹肌之类的，我想都没想过。

昨天我在 YouTube 看到一个科普视频，他说人类脑部的重量只占体重的 2%左右，但思考时消耗的能量占整体消耗量的 20%。

我就觉得挺有意思的，我每天思考的时间比健身时间长多了，难怪怎么吃体重都不会增长，可能就跟这个相关。

他这种大脑消耗能量的理论准不准确我不知道，但是我知道，让一个人思考问题的话，比让他去健身还难受。
