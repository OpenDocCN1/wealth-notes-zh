# 边界感太弱，是大部分痛苦的根源

原创 赢在 8 小时之外 2022-10-11 12:00:55

我在公众号后台或者知识星球上，经常会收到那种关于家庭关系的提问，一发就是一大堆文字。

我只要看到里面出现父母、哥哥姐姐、弟弟妹妹、公公婆婆等字样，我就知道这种烂事是无解的。

亲人之间，有血缘和恩情的羁绊，但是这两种东西既可能是快乐的源泉，也可能是痛苦的根源。

恩情这个东西，其实已经属于玄学范畴了，因为它是很难界定的。

比如，养父母当初因为家里贫寒，把孩子送到亲戚那里寄养（或者直接扔掉、卖掉），那么等孩子长大后，养父母对自己的恩情该如何界定？

他们虽然没有养育你，但是他们毕竟把你带到了这个世界上，这份恩情是说不清楚的。

再比如，哥哥姐姐在弟弟妹妹的成长过程中，帮了一点儿忙，比如小时候帮忙带、长大了可能会打工帮着交学费（本应该是父母的职责）。这时候，哥哥姐姐的恩情该如何回报？

未成年的时候还好说，彼时他的心里还没有起“异心”。

但是，等到大家都成年了，甚至成家了，这时候还让亲人之间的恩情捆束太多，那么情况可能就不妙了。

很多离婚案件的源头就在此。

一种原因是，女方回娘家太多。都出了嫁了，还总向老家“输血”，适当照顾父母是可以理解的，但是弟弟妹妹也都全权负责，这就很可能会引发男方的不满。

“扶养魔”的称号就是这样来的。

另一种原因是，男方的父母或者家人掺和进了他们的婚姻，而且干预太多，这时候必然会引发各种各样的矛盾。

“妈宝男”的称号就是这样来的。

其实吧，自己有能力之后，适当回馈父母，帮衬一下弟弟妹妹，是非常合情合理的。

但凡事都要有个“度”，或者说是要有一个清晰的“边界感”。
