# 被泼冷水的次数越多，成长越快

原创  赢在 8 小时之外  2022-06-24 12:00:26

最近我收到好几条消息，有想缀学创业的，有想裸辞创业的。

他们说了一大堆自己的情况，想知道这种状态下适不适合打破传统路径，跳出来创业。

我的回答是，像缀学、裸辞、裸婚这种“离经叛道”的行为，不是计算出来的，也没有一套评判标准。

而是说，内心的渴望和积聚的势能达到一定程度时，这些事情是水到渠成的。

比如，你在业余时间搞的事情，已经有了非常显著的效果（赚到了第一桶金），而且你自己非常清楚，如果全身心投入到这个事业上去，将会爆发更大的能量。

机不可失，时不再来。

这时候缀学、辞职是势在必行的。

我至少认识 3 个年入几百万的人，都是当初从大学缀学创业的。

因为他们非常清楚，如果缀学创业的话，一年就有可能赚到普通上班族一辈子的收入（或者说已经赚到了很多钱），为什么还要走传统的“学习→求职→打工”这条路线呢？

所以说，如果你仍然在到处发问，你仍然在犹豫不决，那么说明时机根本不成熟，你还是老老实实上学、上班吧。

这是大多数人的归宿，包括我自己当初也是如此，我没有遇到缀学创业的机会，如果有的话我也不一定有这个魄力。

而那些真正厉害的人，都能倾听自己内心的召唤，而且能非常敏锐、客观地判断目前形势，也能准确地预测未来的发展方向。

但是，人毕竟不是神，任何人都会出现误判现象。

比如，一个人辞职创业之后，发现局面跟自己当初想象的完全不一样，自己陷入了一个非常局促和尴尬的境地。

比如，一个人力排众议跟另一个人结婚之后，发现婚后生活跟自己当初的想象完全不一样，心中叫苦不迭。
