# # 永远不要活在别人的标准里

原创　　赢在 8 小时之外　　2021-02-17 22:42:49

当年刚毕业时，我去的国企，我们公司领导给我们讲话，说一个好的职工，要把工作做好，要处理好人际关系，要把家庭安顿好，要爱岗敬业，要务实，等等。

总之，他把一个好员工的所有标准都跟我们讲了。当然，我知道这些都是工具人需要遵循的标准，我不想做工具人，我就没有遵循他的那套标准。

我没事就去做兼职，去搞副业，然后给领导合法送 money，他就给我一路开绿灯。

我不喜欢国企的生活，但是在那里面对着确实很稳定，三四千的月薪，再加上我一万多的副业，在四五线小城市也算不错了。

但是呢，我可不满足于此，于是我还是跳出来了。

到北京之后，第一家公司老板也经常强调，他眼中好员工的标准：要踏踏实实的，把公司当成自己的家，把同事当成自己的家人，没事多感恩别人给了自己什么，别总是要求别人为你做什么。

这些话在我听了，就像放屁一样，我也不知道这是注谁定的“好员工”标准，反正在这一年里，我就跳了好几次槽。

我有个做 HR 的朋友，劝我，说这样跳来跳去，再去新的公司，人家会认为你做什么事都不长久，哪儿还敢录用你啊。

我也没跟他解释，因为我知道我们不是一路人，你嘴里的招聘标准并不适合我，我很多的工作都是跟老板直接谈的，比如我最后一家打工生涯的工作，是新媒体运营，我直接用自己的微博私信的他们 CEO，他看我粉丝比较多，就直接约我过去谈薪资了……

后来我开始弄自己的公司，进入了创业的圈子，我发现这些老板，都是不遵守大众标准的人，他们有的在大三就辍学出来创业了；有的是从上一家捣走几个客户，然后自己单干了；有的也是在国企，但是挂职出来赚钱的，因为本职工作收入太低……

总之呢，随便拎出来一个老板，让普通老百姓用大众的标准去衡量，都不是什么守规矩的人，甚至是道德有瑕疵的人。

去年的时候，我萌生了一个念头，就是想总结一下，到底有哪些瓶颈，限制了穷人变富。我能想到的，至少有 100 个瓶颈了。

我在 VIP 群里，已经分享过很多个了（今后也会继续分享），今天我就想在公众号里，免费再给大家分享一个，那就是：永远不要活在别人的标准里。
