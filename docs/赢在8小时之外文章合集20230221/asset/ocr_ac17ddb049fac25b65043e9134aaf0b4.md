# 找到属于自己的“平流层”

原创 赢在 8 小时之外 2022-05-12 12:00:40

我在公众号里经常提到一个观点：你就尽管增加自己的收入途径即可，千万不要怕累。

因为有一个神奇的现象：你的收入增加了 10%，而你的精力消耗可能只增加了 1%。

举个例子，我的知识星球开通一个月了，现在里面有 55 个人，平均每天都会有几个人提问，我的每条回答也都在 500-1000 字左右。

那我会不会觉得这份工作是负担？

完全不会，不仅不是负担，甚至会让我精力更加充沛。

下面我说说为什么会出现这种现象。

昨天，有一个星友提问：怎么才能提高自己的词汇量？

![](bbox=[0.25, 0.43, 0.75, 0.5])

我记得一位大佬说过：一个人的词汇量跟他的收入是成正比的，所以增加词汇量确实挺重要的。

当然，他说的词汇量，是指探索新的领域，而不是华丽的文学词藻。

想增加词汇量，我建议多读一些词汇量丰富的书籍和文章，比如描写历史故事的。

我喜欢用喜马拉雅APP听朝历史、宋朝历史这些，即使主持人故意用现代

然后我意识到，我还从来没有思考过这个问题，但是他一发问，我才意识到，这个问题其实非常好，词汇量确实是区分收入关键因素之一。

于是我就根据自己的经验和思考，总结了几条提高词汇量的方法。

我用了五六分钟，写了几百字回答了他的这个问题。

那么在回答问题这个过程中，我的知识体系又拓宽了，而且这条回答也成了我知识库里面的一部分，我可以把这条回答拓展成一篇文章，搬到公众号上，设置成付费阅读文章，收一波钱。

另外，我也可以去知乎上搜索“写作技巧、词汇量”相关的问题，进行解答，然后赚一波流量。
