# 穷人该如何保护自己的能量场？

原创 赢在8小时之外 2021-07-25 12:06:32

上次在 VIP 群，有个朋友说，他被公司的老同事询问家里情况，以及个人情况，财产情况，他就一一回答了。

然后他就觉得，自己的能量遭受了巨大的损失，说不上为什么，就是感觉某一部分被掏空了，暴露在别人面前。

我是非常理解这种情况的，所以我说，对于大部分询问你个人情况的同事、亲戚来说，你就把他们当成畜生来看待就行了。

其实也很好理解，因为他们成长的年代，是 xxx 的年代，盛行的是流氓文化。他们是没有“文明”这个概念的，只有野蛮。

今天我想再跟大家说一下，不仅仅是对于这类半熟不熟的人，我们不要敞开心扉，即使对于朋友，甚至父母和孩子，也不要完全坦诚相待，该戴上面具就戴上面具。

我之前总说，我是没有朋友的，我也不打算交朋友。

但其实，我的人生里是有两三个人，可以把真面目给他们看的。

在我看来，一辈子可以交心的人，不应该超过 3 个，这 3 个就是那种一起 x 过 x，一起扛过枪的那种，可以无话不谈。其余的人就给他们看面具即可。
