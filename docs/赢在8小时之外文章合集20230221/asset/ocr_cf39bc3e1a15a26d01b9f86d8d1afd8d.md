# 不要把“吃苦”当成自己的舒适区

原创 蒸发在8小时之外 2022-12-12 12:00:08

最近风向要变，所以我把照片翻出来，清理一下封面，因为上面有很多贴纸。

然后我就梳理了一下我去过的地方，第一次出境是去的韩国。

当年我出国的第一站之所以选择韩国，原因之一就是，我所在化工厂使用的全套设备都是韩国八十年代海运下来的，直到40年后的今天它依然运行良好，而且是全自动化的。

那时我在班上，8小时内一般只需要工作半个小时，其余时间做什麼都行，睡觉、玩游戏、跟同事打牌、下象棋……

当时我就意识到，我这么多年接受的仇恨教育，可能是错的。

我们挤着些“弹丸小国”取了很多外号；小日本、韩国樱子……

真正进入社会、进入生产领域、科研领域才发现，大部分先进设备、专利技术都在那些发达国家手里。

于是我的第一站就选择了韩国（毕竟签证门槛也比较低）。

那次出国对我的冲击我就不赘述了，我之前写过。

总之呢，接触外国的先进设备、去发达国家旅行，对我观念的改变非常大，也让我重新审视我之前被灌输的世界观。

现在，我们全家使用的手机也都是三星和苹果，已经彻底不用国产手机了。

其实我选择这两个品牌的理由很简单；三星有谷歌框架，而且没有任何内置流氓软件和 jian 听嫌疑。

另外三岖的屏幕是 number 1, 这个是没有任何疑问的，我爸妈都用的三星手机，就是因为屏幕看着比较舒服。

有一种说法是：三星把最好的屏幕留给自己，第二梯队的留给 iPhone，第三梯队的留给……

不要以为老年人不懂科技设备，他们对于好与坏非常朴素而且实在的认知，哪个屏幕看着舒服，他们非常清楚。iPhone 系统比较流畅，而且能做到多年不会有弹窗、广告、系统提示、内置流氓软件等等，这一点是我比较喜欢的。
