# 只有等到有钱之后，才能做自己吗？

今天在 VIP 群里面，大家聊了很多关于汽车的话题，以及因为汽车而起的一些矛盾和纷争：

![](bbox=[0.242, 0.186, 0.758, 0.508])

我开车时就很容易发怒，典型的路怒症。

比如，有时候等红灯，还有一秒钟变绿灯，后面的车就开始鸣笛，我特别想冲下来去打他一顿，但是理智告诉我不能这么做。

再比如，有一次后车一直鸣笛、开远光，我就先加速，然后突然刹车……

过后我还是挺后悔的，因为我知道这样做特别危险，还有就是，可能是我开得太慢了，而后面的人有急事，或者有其他原因。

而当我开一部好车时，这些乱七八糟的事也有，但是会少很多。

但是呢，只要开车时，我就特别容易发怒，很难控制住，就是血往上涌的感觉，我知道这一点之后，我就很少开车了。

后来我就思考原因，这些不好的脾气都是遗传来的。
