# ③ 自我怀疑

对于没有给我交钱的人，向我咨询问题，让我介绍赚钱路径时，我都是闭口不言的。

包括我的亲戚朋友，我也是不提任何建议的。

我知道他们要跳火坑、要吃狗屎，我也静静地看着，不会熄耀的。

是我坏吗？

真不是，而是我不想被 awaits 咬到。

因为我有过不少一次这样的经历了：有免费用户或者亲戚朋友来看我请教网赚之道，我明明知道至少有 10 条康庄大道可以供他们选择和试错。

但是呢，我刚刚说出一条，他们就先把我否定了，然后就是否定自己：你说的这些都不行通，我根本不是那块料！

对于喜欢自我否定、自我怀疑的人，都是绝世劳觉，没救。

总之吧，这 3 个障碍，既是穷人心中守护的“祖坟”，又是压在他们心头的大山。

所以，局势逆袭之道是什么？

答案很简单：你要勇敢地打破这 3 座心中的祖坟。仇恨、恐惧、怀疑，统统都要打破，不破不立。

注意，我绝对不是建议大家不生孩子、不买养老保险，而是说，你都活成这个鬼样子了，还有担心自己的老年生活吗？

你把重点搞错了。

你的首要任务，是要找到自己内心的力量，生而为人的力量。

每当你犹豫时，心里默念“活在当下”，“为自己而活”，那么你内心的恐惧和怀疑都会烟消云散的。

等你内心有力量之后，再去打拼，再去赚钱，那时候一定会事半功倍， המעשה无往不利。
