# 在外面混，姿态永远不要单做

有个老同学，他听说我们可以为其他公司、名人提供官微、抖音的代运营，于是他跟我说，他最近有个饭局，里面都是有能量的人，有律师、有医生，还有一些企业家、银行行长。

他邀请我也过去，这些人都有在互联网上做营销、积累粉丝的需求。

我一听就知道怎么回事了，这年头，银行的普通职员都会被介绍成银行行长，其他的同理。

我说，你把我公司的宣传 H5 发给他们看一下就行了，饭局我就不参加了。

他说，你不想认识更多有能量、有用的人吗？

我说，我早就过了当傻逼的年龄了。他们有需求就来找我即可，我从来不去求别人给我机会。

另外，不要把人脉当真，交情没法抵钱。

真正到你需要帮助的时候，直接花钱去咨询专业的医生、律师即可。而饭局上认识的所谓的“朋友”，他们只会做一件事：比市场价多坑你点钱，多一些手续和流程来吓唬你。

毕竟“朋友”不就是用来出卖的吗？

你认识的这个行长、那个局长，屁用都没有。你对于他们的用途只有一个：需要的时候拿出来当枪使。

另外，我想跟各位老板读者说的是：在外面混，姿态永远都别太卑微。

有个性的人，更能赢得别人的尊重。有些人遇到大佬，说话都发抖。你又没做过对不起他的事，你怕什么？

你越卑微，别人就会觉得你越弱，不如挺直腰杆，勇于表达自我，更容易赢得尊重。

在互联网上，更是如此。不论你是在输出文字、音频还是视频，如果你的目标是营销高能量场、高收入的人群（比如我自己的这个公众号），那就永远不要听大家的建议，直接独裁就行了。
