# ③ 富裕阶层。

富人的资产和观念是可以代代传承的，无论社会如何变迁，真正的富人阶层一定能让家族的财富一代代传递下去。

只要没有大的动乱，那么富人阶层的财产都可以向下传承：房产可以传承，公司可以传承，信托可以传承，就连著作权都可以传承……

当然，比这些财产更重要的东西，就是家学家风，这个东西传递下去，威力是非常巨大的。

我国就有很多“名门望族”，比如钱氏家族。

从宋朝开始，光是载入史册的钱门名家就超过千人。

远的就不用说了，因为不好考证，就说近代的，著名国学大师钱穆，文学大师钱钟书，科学泰斗钱三强、钱学森、钱伟长，他们都是一个家族的……

另外，钱学森是金庸的表姐夫，徐志摩是金庸的表哥，琼瑶是金庸的外甥女……
