# 强势规划自己的人生

原创 赢在 8 小时之外 2022-11-08 12:00:29

大多数人，都是活在别人制定的标准和框架里。

这样做的好处是：你能受到大多数人的认可，会获得一种虚无的“归属感”。

但问题是，大多数人是财务不自由、精神不自由、灵魂不自由的。

所以，你想让自己的生命变得自由、富足，你必须有自己的标准，有自己的框架。

这个逻辑简单吗？

但是很多人一辈子也搞不清楚，或者不愿意相信。

结果就是，一直活在别人的评价体系里，一直被别人挑来捡去，人生如浮萍。

我之前建过一个包群，只允许男人加入（现在已经停止收入了）。

我在里面就说过，你可以包装，可以虚张声势，可以强势，但是就不能活在女人的标准里。

很多女人嘲里“好女人”的标准是：性格好，对自己好，会说话。

但是只要你这样做了，你就很快会被“养之如嗤屑”，被当成破鞋扔掉了。
