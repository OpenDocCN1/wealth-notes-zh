# 加入我的知识星球（最后 3 天优惠）

赢在 8 小时之外      2022-05-06 16:36:55

之前有很多朋友跟我说，让我开通知识星球，说这个平台很不错，答疑解惑也方便。

我一直觉得太麻烦，就迟迟没有开通。

最近呢，我的想法变了，主要有两个原因：

+   ① 我要尽可能开辟多种收入渠道，然后把整个流程展示给大家，也让大家多一些变现的途径。

到目前为止，我开发了微信付费阅读、流量主广告收入、付费社群等收入途径，很多人模仿得也很成功，都收了不少钱。

+   ② 因为有的粉丝有问题，但是不想进微信群（或者是怕消息打扰，或者是嫌贵），我又不看公众号私信，但是我还得给这部分群体一个沟通的机会。

加入我知识星球的门槛费是 365元/年（从加入那天开始计算），能享受到的权益就是：每个月能免费向我提問 10 个问题+我每个月至少会分享 3 次写作技巧。

当然，每一个问题都会被其他星友围观。你加入我的星球之后，也能看到其他所有人的提问和我的解答。所以说，知识星球从某种程度上来说就是一个“问答库”。

那么我擅长什么领域呢？无非就是写作、知乎、公众号、引流、付费社群、时间管理、学习方法、认知提升、个人成长、赚钱项目等方面（不负责解答情感问题）。

知识星球也有“专栏”功能，如果有人提的问题非常典型，几段话说不清楚，我也可能偶尔会写一篇文字进行拓展讲解，发到知识星球专栏上。

我分享的写作技巧也会整理到专栏里。

另外，我认为比较有收获的书籍、影视作品、纪录片、学习工具、赚钱工具、认知思维……我也会在知识星球的动态圈分享。
