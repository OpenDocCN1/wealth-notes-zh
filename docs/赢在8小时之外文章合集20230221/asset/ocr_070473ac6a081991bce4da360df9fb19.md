# 赚穷人的钱，等于是诈骗

穷人花100块钱，是要收到1000块回报的，而且你必须手把手教他，随叫随到。否则他一不满意就会举报你，为难你，让你退钱，各种扯皮。

你要做的，就是要第一时间甄别出这类人，然后设置金钱门槛把他们筛选掉，不要跟他们发生任何金钱链接。

女人找男人也是如此，你如果有资本、有能力，可以找到有钱男人，那就最好了。

如果没资本、没能力，只能找个穷男人，那你就别指望让对方给你花钱。

你想要几百块的口红，他咬咬牙帮你买了。你想要几千块的衣服，他也咬咬牙买了。最后你还想要几万块的包包，他要是不答应还好，万一他攒了几个月的工资给你买了，那你就惨了。

他为了你几乎是倾尽了所有，这时候你必须要完全听从于他。否则的话，你可能会有性命危险。

穷人掏出来的每一分钱，他都当成命一样，要是收不回成本，他一定会歇斯底里的。
