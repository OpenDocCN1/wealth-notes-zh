# 好的人际关系，不需要经营

原创  赢在 8 小时之外  2021-08-09 15:43:01

昨天在 VIP 群里，有个群友说，他的一个老大哥向他借钱，还差点弄出很多误会。

我就说，你要反思，为什么会有人向你借钱。

如果有人向我们借钱，一般来说只有一个原因：我们所处的圈子太差劲，太 low。

如果想要做朋友，就不要发生金钱的往来。如果有人向你借钱，大概率他就没有把你当成朋友，而是在收割你，甚至把这件事作为拿捏你的筹码，或者是在检测你臣服程度。

这年头，想借钱，平台有很多。

开口借钱的人，直接拉黑就行了，要是觉得不好意思，就口头上拒绝，在心里把他拉黑。

我跟大家说两个社交层级，很扎心，但是你如果是老板，早晚会经历这两个层级。

第一层级：交朋友先验资。

资产没有几百万，手里没有几十万现金，也没有稳定现金流的人，我们不交往，负债的一律拉黑，包括房贷（专业炒房的除外）。

不是人变的势利了，而是说，只要到了 memudahkan 一定高度，验资是最基础的门槛。

你想去订车，想要看房，只要单价比较高的，都是要先验资的，要不然谁搭理你。

交朋友也是如此。

资产这一块合格之后，他大概率就不会坑你，大概率就不会作恶。

不要跟我说小概率事件，那样很幼稚。

成年人，只跟有成果的人有来往。第二个层级：人是不需要朋友的。

只要你已经是老板了，已经赚到了几百万、几千万，你就没有朋友了，你也不需要朋友。

你的身边只有家人和一起赚钱的合作伙伴。

至于其他所谓的朋友，都是因为利益而聚到了一起，最终也会因为利益而走散。说得再深入一点，只要你身价到了某个点之后，你跟身边的人也不是简单的感情关系了，而是利益、合作的关系，是主导与被主导的关系。
