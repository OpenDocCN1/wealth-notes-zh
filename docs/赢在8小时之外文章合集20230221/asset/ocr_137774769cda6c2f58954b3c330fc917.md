# 普通人最难突破的 3 个瓶颈

原创    赢在 8 小时之外    2021-08-21 19:37:28

30 岁左右，是人生中很重要的一个节点，大学毕业六七年了，同学之间的差距可以用 “天壤之别” 来形容。

有的仍然在稳定的单位上班，一个月拿几千块钱工资；

有的已经成了家庭主妇/夫，每天不修边幅地带娃，体重已经过了 180。

有的已经建立起自己的事业，实现了时间自由和财务自由……

当个普通人，其实没什么不好，平平淡淡也是一种幸福。

但是呢，每个人都有追求不普通的权利，也都有变不普通的可能性。

我总结，想要变得不普通，想要对自己的人生充满掌控感，下面这 3 个瓶颈最难突破：瓶颈一：

# 空闲时间不会利用，全部都浪费掉了。

上学时，老师给我们出题，我们只需要解答即可，只要把教科书、试题集研究透彻，我们就可以取得一个好成绩。

所以，每天根本不会迷茫，英语不好就补英语，数学不好就补数学，非常充实。

但是，一旦进入社会，情况就完全不同了。

在公司里，上级虽然会给你制定工作任务，但是大多数打工者其实都是磨洋工而已，或者就是机械性地执行，主观能动性其实发挥的很少。

另外，下班时间、周末时间，大多都用来通勤、聚餐、郊游、睡觉、玩游戏、追剧、刷抖音了。

大部分打工者，其实是没有精力和意识去做职业规划和人生规划的，因为他们的积极性已经在工作中耗尽了，还天真的以为，只要努力工作，人生就会变得越来越轻松，越来越惬意。

最后发现，根本不是那么回事，或者情况完全相反，自己越来越疲惫，对人生越来越没有掌控感。

很多人根本不知道 “打工者→自由职业者→老板→投资者” 这 4 个层级的存在，他们认为这辈子只能一直打工，没有第二条出路。

还有一些打工者，其实是有提高和成长的意识的，只不过，这个世界的诱惑太多，一不注意就去刷短视频、玩游戏了，或者朋友一叫就去吃饭了。
