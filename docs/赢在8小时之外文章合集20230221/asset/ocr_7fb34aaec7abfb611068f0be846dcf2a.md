# 想要逃离底层，这几样一定要割舍掉

原创　　赢在 8 小时之外　　2021-02-14 17:41:21

今天一个 VIP 群友私信我，说进群之后收获很大，收入已经提高一大截了，因为有了自己的副业了，但是呢，距离理想的被动收入还差一大截，而且人际关系偶尔也会影响到自己。

他觉得，现在虽然比之前强多了，但是仍然没有逃离底层，这次春节回老家就被打回原形了，自己在家人和亲戚面前啥都不是，而且没人给自己鼓励，大家都是在那里攀比，炫耀，或者奚落，长辈们见到自己依然在教自己如何做人。

他问我，怎么样可以快速逃离底层呢？

今天，我就来聊聊这个话题。

上个月我写过一篇文章，就是讲的“隔离”对人的提升：

人生，是隔离的艺术

今天我再讲 4 个需要隔离、需要进行割舍的点。

# ①不要忽视物理隔绝。

如果你想生活在治安好、纠纷少、人人都比较礼貌的环境里，就有一个方法，找到你们城市里最贵的几个小区，绝对能满足你的这些要求。

包括教育孩子，你把孔孟之道讲出来，也不如选择几个好的邻居，过来人都懂我说的是什么意义。

同样的，我们这些出身比较低微的穷屌丝，如果想往高处走，尽量也要与便宜的环境、便宜的人隔离开来。

这件事是很难做到的，因为很多穷人对“贫穷”是有感情的，是难以割舍的。

如果可能的话，尽量离农村远一点，能把父母接到城市生活尽量接过来。就算现在农村都通了互联网，信息依然非常闭塞。

还有就是，很多小地方的那些亲戚朋友，嫌你穷，怕你富，学历虽然不高，但是心眼不少。没啥能耐，但是算计你一下、坑你一把，你会叫苦不迭的。
