# 不要让垃圾认识您，他们会弄脏您的人生

原创 赢在 8 小时之外 2020-06-20 13:27:29

我一直在公众号里面强调，各位老板朋友一定要注意保护“金钱”和“情结”这两样东西，因为它们是人世间最宝贵的两种财富。

因为，一旦你有钱了，而且情结舒畅了，那么身体自然健康，跟周围的人际关系自然也会相处的很好。

金钱这个不用我多说，我们每一个人都在追求，只不过有一些受 R 家毒瘤文化洗脑的人总想在嘴上反驳，背地里却会因为很可怜的一点钱跟周围的人闹翻，甚至做出背信弃义的卑鄙勾当。

不用说远了，就说我们父母那代人，只要有兄弟姐妹几个的，至少有一半的情况，会因为分家产而闹翻。无论任何人际关系和社会关系，只要你接受的是 R 家文化教育，最终一定是一地鸡毛。

今天跟大家聊聊“情结”这个东西。我觉得人活一世，最重要的就是情结，是好心情，是愉悦的感觉。

所以说，谁如果整天陷入勾心斗角、抱怨、悲哀、焦虑等负面情绪，我就觉得 ta 是一个畜生，因为他在浪费生命。

其实是畜生都不如的东西，因为小动物一般是不会有负面情绪的。

但是呢，回忆一下我来北京的这几年，负面情绪最多的时候，就是在我还是个打工者、还是个穷鬼的时候。

上下级关系，同事关系，客户关系，男女感情关系，每天总是有一大堆不值钱的破事让我头疼。

但是呢，自从创业之后，而且赚到第一桶金之后，我发现，身边的<|message|> 大部分都是正能量的老板了，互相之间，给予最多的就是鼓励，其次就是互相介绍客户。

所以呢，每当有满腹牢骚的人，向我咨询该如何处理不值钱的烂事时，我的回答都是，你这个问题无解，你需要做的是，尽早离开那个鬼圈子，或者那个阶层，越快越好。

你如果身处垃圾堆，你的情商再高，为人处世玩的再溜，这些垃圾还会把你污染掉。

另外我要声明一下，对于一部分人来说，他的家庭就是一个垃圾堆，他的父母就是垃圾中的战斗机，这种人最需要做的是跟父母切断联系，越快越好，否则他一辈子就废了，一无是处的废物，窝囊废。
