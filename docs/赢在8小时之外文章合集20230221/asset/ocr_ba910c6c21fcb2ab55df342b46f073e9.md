# 普通人的一生，意义何在？

原创　赢在 8 小时之外　2020-12-14 14:53:02

我的个人微信号，把大部分人都屏蔽了。

尤其是那些经常在朋友圈宣泄负面情绪的。

我觉得情绪是能感染人的，负能量是会传染的，我躲着它们就像躲瘟疫。

前两天我就看到一个老同学发了一条这样的朋友圈：

一个月几千块，根本存不到钱，其实大部分人都在做着非常廉价的事，直至青春耗尽，然后被社会淘汰，普通人的人生，意义何在……

然后我翻了一下他之前的朋友圈，有的在转发 M 国疫情的，有的在转发抨击杰克马的，当然还附有他义愤填膺的评论。

我就直接把他也屏蔽了。

这种穷鬼，过了 30 岁，也只剩下对社会的抱怨，以及对自己处境的哀鸣了。

远古时期的人类，主要以采集食物为生。现代社会的人类，主要以采集信息为生。

远古时期，最怕的就是采集到有毒的食物。

而信息时代，最怕的就是吸收了有毒的信息，这个看似是没什么大碍，但实际上很致命。

本来人就像一张白纸，吸收了负面信息，白纸就会变得暗淡一些；吸收了正面信息，白纸就会更加鲜亮一些。

有的人就是很贱，就像我之前说的受害者心态一样，特别喜欢收集负能量的东西，然后躲在角落暗自神伤。

你如果是写诗歌的文艺青年，也可以理解，毕竟需要无病呻吟，有点轻度抑郁就更好了。

但是我们普通人，千万别走入这种信息里，一点也不要去沾。

比如，男人抱怨女人，抱怨社会，甚至连 M 国的 election 他也要喷几句；女人抱怨婚姻，抱怨男人，抱怨心机婊同事。这些就像毒品一样，你一旦沾上了，那么你每天就不用干别的了，潜意识里就会去搜罗这方面的新闻，然后找到几个失败者朋友一起抱团抱怨。

当然，人世间确实有很多令人绝望的事，比如一眼望到头的人生，每天重复着日复一日相同的生活
