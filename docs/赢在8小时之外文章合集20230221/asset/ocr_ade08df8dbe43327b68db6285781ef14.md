# 朋友借钱不还怎么办？

原创　　藏在 8 小时之外　　2020-11-26 12:00:11

之前在老板群里，有个人说明友欠他十几万，几年了都没还。每次去要，对方就说没钱，或者就是先还上几千块。

然后很多老板都附和，说自己也有类似的经历。

然后我就说，不借钱的话，还能做朋友。只要钱一借出去，不论你打算要，还是不打算要，朋友都做不成了。

你不要的话，自己觉得亏。只要你张口要，就得罪了对方。钱是我凭本事借的，凭什么还给你？

下面我要说一段残酷的话，聪明老板都应该懂：

凡是开口找你借钱的人，90%的情况是因为对方看你老实、本分、好欺负。如果你真借给他，当你找他还钱的时候，他一定不会给你好脸色。

所以，当有人找你借钱时，你就回复对方两个字即可：没有。

当然，有人总喜欢反驳，谁还没有落难的时候呢？朋友之间不就是互相帮忙的吗？

我想说，这就是为什么我上面用的数据是 90%而不是 100%，因为剩下的那 10%是穷鬼。穷鬼之间是可以互相信的，因为这些人经常过着吃了上顿没下顿的生活。

等你的收入稍微提高了一些，你就知道，人活着不是靠朋友的，也不是靠亲戚的，而是靠自己，以及给自己投资的各种保障、保险。

说的再直白一些，只要有人向你借钱，他的潜台词就是：你这个傻 B，让我收割一下好吗？因为我觉得你的智商很低，活该被我收割。

所以，只要有人开口向我借钱，我就会觉得，自己受到了侮辱。然后我就会反思，到底是我最近做错了什么，让对方觉得我是个大傻 B 呢？我得改。

从借钱，我再给大家延伸一下，讲一讲人与人之间的势差和博弈。

在 VIP 群里，经常有人说，自己在日常生活或者职场上，经常出现自己不被重视或者受欺负的情况，感觉很憋屈。

我就说，别人之所以敢欺负你，是因为你做人没有原则，或者说你有原则、但是没有胆量去维护你的原则。
