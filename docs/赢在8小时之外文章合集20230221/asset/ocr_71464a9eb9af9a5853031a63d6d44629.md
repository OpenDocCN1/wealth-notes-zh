# 离开地狱的路

藏在 8 小时之外 2023-02-08 17:08:49

+   1. 离开地狱的路就位于地狱的中心处。

+   2. 只有冒险和进步，才能摆脱昨日经验的限制。

+   3. 每个成功的人，都有一个克服自身瓶颈的长期故事。

+   4. 做人不需要太多朋友，因为朋友有时候也会做着和敌人同样的事。

+   5. 与那些欣赏你独特品质的人在一起，而不是那些试图贬低你的人。

+   6. 做某些事情不会让你变得富有，只有按照某种方式做事才能完胜。

+   7. 高级的感情，最终形成精神和能量；低级的感情，只会沦为脾气和情绪。

+   8. 饥饿的肚子、空空的钱包和破碎的心，会教会我们人生中最宝贵的经验。

+   9. 敏感地感觉到他人的情绪，然后完全无视它们，这是所有厉害角色的共同特点。

+   10. 任何时候，你请求另一个人让你自由，你就永远无法得到自由。自由是你必须为自己做的事情。

+   11. 所有人只要还活着，就有改变自己、甚至是彻底改头换面的可能性。并非只有孩童才具有可塑性。

+   12. 所有让你感到压抑、感到负能量的人和事，你都应该远离。成功的土壤，一定是积极向上的。

+   13. 自甘堕落的路上一波又一波、出人头地的途中万阻阻挡。一旦倒下，推枯拉朽，唯有向上的力量需要自已争取。

+   14. 永远记住对方互<|start|>的一面，不要因为几个好话就放心，否则你所遭遇的一切都是活该。好的一面可能是装的，而坏的一面都是真的。

+   15. 人只有足够复杂，才能更好地简单。没有经历过复杂的简单，在今天是很很难保全自己的那份简单的。吞没复杂是能力，选择简单是境界。
