# ③要尽快找到的兴奋点，找到成功的感觉，小成功是大成功之母。

我在群里讲知乎、微博和公众号的玩法时，我建议大家要尽早找到“火”的感觉。

就是说，不论你的初衷是什么，你的目的什么，你要想尽一切办法先火一次。

你去抄袭也行，你去模仿也行，你去蹭热点事件也行，总之你必须得感受一次“火起来”的感觉，大家都在下面热烈评论你的感觉。

找到这种感觉之后，你就算开始上道了。

很多沙雕特别务实，闷声做了好几年，一直没有起色，也就放弃了。

其实这些人就需要有人指导他们，搞火一把，把他们内心的激情给点燃，他们的能量才能爆发出来。

顺着这个话题，我最后再跟大家说点虚的东西，你能理解就听一下，你觉得很扯淡就跳过。

人在由穷变富的过程中，最好也要早点找到“有钱人”的感觉。

比如，你一直都是踏踏实实地攒钱，从来没有奢侈过，从来没有体验过有钱人的生活，那我建议你尽早把能体验的奢侈消费都体验一把。

比如坐头等舱，住五星级酒店，去发达国家旅行等等。

也就是说，在消费方面，先装作有钱人，找找感觉。

另外，对被坑的钱、亏掉的钱别太计较，大度一点，慢慢的你的气场就出来了。这一点，对于创业者非常重要。

尤其是那些带团队的创业者，除了不计较小钱之外，还要舍得分钱。你的一举一动，团队伙伴们都看在眼里。

Fake it till you make it.

你要相信，只要是心智正常、思维正常的人，不会因此就堕落了或者开始飘了。

而是自己内心的一些东西会被激发出来，让你能量爆棚，从此就可能走上了开挂的人生。
