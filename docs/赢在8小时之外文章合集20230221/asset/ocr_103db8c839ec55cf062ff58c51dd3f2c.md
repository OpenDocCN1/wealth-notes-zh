# 大明星真的缺女人吗？

原创 赢在 8 小时之外 2021-10-22 21:54:49

前两天我刚刚写完一篇涉及到漂亮的文章：

我从哪里获取优质信息？

然后昨天就爆出一则消息：L 云迪漂亮被抓。

本来这些八卦我不想讲，很无聊。

但是有个读者是学钢琴的，她说，看到 L 云迪漂亮被抓的新闻，很难过。

她问我：L 云迪，包括之前的 L 丹，这些男明星粉丝无数，愿意为他现身的漂亮女粉丝，没有十万，一万肯定有的。那么他们为什么非要漂亮？哪怕你包养一个也不至于违法吧？

我跟她讲，有一定高度的男人，确实不缺姓资源。

一个地区的小领导，或者百万粉丝的小网红，他们都是不缺女人的，十几个、几十个都不罕见。每天还会源源不断地往身上贴。

但是真正高级别的人，他们更加会追求精神上的共鸣。

例如 L 云迪、L 丹这类人，在他们各自领域都是王者级别的，他们一定有精神上的挚友，但可能年龄很大了，也不方便谈这些。

所以，在某些问题上，他们反而会变得简单。

不光大明星，很多企业家（至少有 50%）也是都漂亮的，X 蚁子这类浮出水面的，仅仅是冰山一角而已。

因为他们非常清楚，谈恋爱是高危行为，一方面是因为谈恋爱会消耗大量的情绪、心力。

另一方面，每一个跟他谈恋爱的女人，到最后都可能变成一颗定时炸弹，把自己的事业和前程全部炸毁。

不信你去细数那些翻车的大佬，一般就两个原因：非法集资结果崩盘了；睡女粉丝被录像录音，或者闹到大房那里去了，或者把他公司很多内幕都揭露出来了。

所以，很多名人反而会选择最简单的方式来解决需求。

绝非大家理解的，他们缺乏姓资源。
