# ② 纪录片

![](bbox=[0.25, 0.108, 0.755, 0.513])

我比较喜欢看各种各样的纪录片，比如上面的 DW Documentary 和 Unreported World。

他们会记录世界上各种不为人知的故事。

比如，有个纪录片是讲在西班牙最北部有个小镇，里面开的全是济院，因为在那里漂姆是合法的。目标群体就是法国南部的漂客们。

法国漂姆是非法的，但是开车去西班牙漂姆，对他们来说就是一个很可行的方案。

记者分别采访了几位济女和漂客，他们的对话特别有意思。

有个济女被采访时根本不打马赛克，也不避讳，说这是 zheng 府定的合法生意，我们也正常纳税，我也需要养家糊口，没什么可忌讳的。她们的安全措施也非常到位，也定期体检。还有一个五十多岁的中间漂客也很有意思，他每次都是带儿子来，一人找一个。他自己是因为中年丧妻，但是再次寻找新的配偶太麻烦，如果短期约的话，成本也太高。无论时间成本、情绪成本、金钱成本，都是非常昂贵的。
