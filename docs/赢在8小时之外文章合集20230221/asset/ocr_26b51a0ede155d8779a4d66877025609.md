# 为什么我要写作？

为什么我要写作？很多人问过我这个问题了，我也写过一些原因，比如从小的兴趣等等。

除了这个原因，还有其他 3 个更深层次的原因，跟大家分享。

# ①看别人写的东西，太没劲了。

我们每天总归是要往大脑里输入信息的，我最喜欢听的东西，就是跟白手起家的暴发户朋友面对面坐下来，一起吃饭，听他吹牛逼，听他讲故事，听他扯淡。

因为这种人嘴里说出来的话，听上去特别有意思，特别真实，而且会给人很多启发。

是真的启发，就是听完之后，应用到自己的行业上，收入和客户都会明显上升那种。所以说，他们嘴里说出来的东西，就跟财富密码差不多。

就像是偷自行车那小子说的一样：里面的人说话都很好听。

这些人之所以说话好听，是因为他们只讲真话，一句谎都不扯。而你到社会上，是没人跟你讲真话的。因为聪明人都知道，这年头，在 XX 混，讲真话是要倒血霉的，全家跟着一起倒霉那种。

除了这种信息之外，我最喜欢看的就是我自己写的东西。

因为别人写的东西，包括公众号、知乎、抖音、微博、各种新闻媒体，他们的目的只有一个：抓住我的眼球，然后他们赚取广告费，或者他们要卖给我其他的产品和服务。

所以说，一旦我知道了这一点，我就再也看不下去别人的东西了，太没劲，还是看我自己写的有意思。

那天老板群有人看我发的朋友圈里面有 kindle，问我平时用 kindle 都看什么书，我也没有回答太多，因为我看的东西，除了我自己公众号导出的文档，就是贾平凹、刘心武、林清玄这些人写的散文、随笔。

至于什么畅销书、什么名著，我真的是提不起兴趣。

# ②写作是能带来很多快乐的，还会有很爽的感觉。

人过了三十岁，对于性、美食、美景、豪车、奢侈品、健身、旅行之类的事情，虽然也喜欢，也能带来好的感觉。
