# 骗子从不吝惜誓言

赢在8小时之外 2021-12-08 12:09:15

+   1. 骗子从不吝惜誓言。
2. 所有的真相都是有对立面的。
3. 不存在什么外在能量可以长久帮助你。
4. 如果你不觉得一年前的自己是个蠢货，那说明你这一年没学到什么东西。
5. 千万别和餐馆讨价还价，因为你永远不知道他会对你的菜做些什么。
6. 当一个人没有优点可以炫耀的时候，他就会炫耀自己有多倒霉。这也是我不喜欢负能量的原因。
7. 一个看似可怜的人，你不要轻易去靠近，这是原有原因的。多半是他自作自受。
8. 好东西和伟大东西的区别是，好东西看起来工整完美，而伟大的东西缺点鲜明。
9. 好朋友不是通过努力争取来的，而是在各自的道路上奔跑时遇见的。
10. 谁禁止你优秀，谁就是坏人，远离他们，他们没有品尝过美好人生的滋味，也决不让你品尝。
11. 成年人不必谁说服谁，各存己见、各说各话就好。我的地盘我做主，你的地盘你做主。
12. 越穷的人，往往越喜欢购买面子，原本就所剩不多的资本，花在了面子以上后，就没有多余的资本翻身了。
13. 学会给别人自由和尊重，不要试图控制或者阻拦，让他们去成为他们想要的样子。
14. 有人向肉里注水，你义愤填膺，恨不得杀了他。有人往你脑子里注水，你却于恩万谢、感恩戴德。
15. 把你的知识变为金钱，把金钱变为财产，然后把财产转化为自由。
16. 规则很难困住顶尖的优秀者，因为任何规则，都存在漏洞。任何的习惯和规范，都有可能在智慧人的面前被重新定义。
17. 为什么战争每隔几十年就要爆发一次，因为和平久了，人们会浪漫化战争。实际上，乱世一来，99%的人都是填沟壑的。
18. 谣言多是根据人性弱点量身定制，针对人的希望、恐惧、好奇进行精准投放。相比之下，辟谣就像给人兴头上浇冷水，没劲，讨厌。
