# 不要干预别人的命运走向

原创   赢在 8 小时之外   2022-04-29 12:00:00

最近半年，有好几个朋友跟我借钱。

我虽然发朋友圈经常哭穷，而且只允许认识的人可见，但是这几个人非常了解我的情况。

我先给大家描述一下，这些借钱的人是怎样操作的。

他们会给我打电话，先聊家常里短：你那里疫情怎么样？工作受不受影响？办公室租金下调了吗？客户有没有流失？……

等到铺垫得差不多了，他们就该转入正题了：我的信用卡逾期半年了，银行一直催我，我也在申请新的信用卡，下个月就能批下来，但是这个月我已经吃不上饭了，你能不能先借给我 2000 元，等到下个月信用卡下来，我立刻还给你。

我知道，任何一个负债的人，嘴里都不会有实话的。

我觉得交情还不错的，比如当年“一起扛过枪，一起……”的人，我就会把钱转给他，但是我心里已经把这段交情划上句号了，我也不期盼对方会还钱。

如果对方是跟我没有什么交情的人，在对方开始打探的时候，我就会开始哭穷：老兄，我最近快活不下去了，每个月两万多的房贷要还，办公室一个月还有一万多的租金，虽然行情很差，但是员工跟了我这么多年，我也不好意思辞退，都给他们发着工资……我现在是拆东墙补西墙度日啊。

对方听完这些话，一般都会安慰我几句，然后就结束通话了。

我之前说过一句很扎心的话：一个人如果落魄了，不要求救，最好的方法就是自救。你一旦开始求救，所有的朋友都跑了。

有人肯定会这样说：这不是废话嘛，如果能自救的话，谁还会求救啊？一定是没法自救了，才开始求救的。

我想说，不是这样的。

所有的友谊、交情，只能禁得住一次试探。不是到了生死关头，你不要随便动用交情。

我本来以为我们的交情值几十万，结果你上来跟我借两千块钱，太出戏了。你为了这两千块钱，谎话连篇，把我们的交情都葬送了。

救急不救穷，你家里如果真的发生重大意外了，我肯定会出一份力。但是你仅仅是因为自己的愚蠢
