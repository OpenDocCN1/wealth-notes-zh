# 如何阻止坏事发生在自己身上？

经常关注 U 君的朋友应该清楚，我是坚定的“环境论者”，改变环境才能改变心境，屁股决定脑袋。

如果你在风景优美的地方，心情自然就会变得舒畅。

如果你所处的圈子都是幸福、乐观的人，那么你也会受到他们的感染，很难会变得悲观。

与“如何阻止坏事发生”相对应的问题是：如何吸引好事发生？

我的回答是：要对发生的好事、帮助自己的好人做出即时反馈。

比如，别人邀请你去家里吃饭，你一定要带一份小礼物，不需要多贵，但至少能表明自己的心意，而且还要当面感谢对方的邀请，以及丰盛的美馔。

比如，有人帮了你一个忙，一定要进行感谢，买点水果、请一杯咖啡、发个红包都可以。

总之呢，能量必须要irl 来有回。

不要觉得“礼尚往来”这件事很简单，90%的人都做不到上面我说的这两条。

老祖宗有 3 句心法还是很有智慧的：看人长处，帮人难处，记人好处。

而未经雕琢的人性是：在别人身上挑毛病，别人落难了抓紧远离，别人发达了才去锦上添花，别人给的好处自己拿的理所当然。

这样的人不受伤穷才怪。

关于能量，有两个法则很有意思，一个是能量守恒定律，一个是马太效应。

能量守恒定律就是，能量交换是 1:1 进行的。

别人给予你 1，你至少也要回馈人家 1，那么愿意帮助你的人才会越来越多。

同理，对于比较厉害的人，你如果先付出 1，别人不可能无动于衷，让你付出的能量湮灭。反之，他们一定会回馈你更多。

马太效应就是，强者愈强、弱者愈弱。

愿意帮你的人越多，那么你的势能就会越强，那么就会有更多的好人、好事被吸引过来。
