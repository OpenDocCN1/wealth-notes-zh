# 人生中最重要的两件事

原创   赢在 8小时之外   2022-11-01 12:00:13

昨天我收到一条私信，大概意思是这样说的：我这辈子没想过要活太久，把父母送走，把孩子养大就可以了。人生太苦，没多大意思，下辈子不来了。

然后他就问我：人最终都是要死的，没人能逃得掉，那我们来世上走一遭究竟是为了什么？

我本来是指绝谈这些大问题的，太无聊，没什么意思。

不过如果非要总结的话，我觉得有两件事是最有意思的：明道和体验。

# ① 明道

有句老话是这样说的：朝闻道夕死可矣。

大概意思是：早上想通了一个道理，那么晚上就去死也无怨无悔了。

我特别认可这句话。

我自己，是不怕死亡的，但是我怕不明不白地死。

我还有很多问题还没想通呢，还有很多事情没有体验过呢。

把问题一一想通的过程，就是人生中最大的幸事，也能带来最大的愉悦感。

比如，前两天大家在群里聊“熟人关系、弱关系”这个话题时，我就表达了两个观点：我赚到的钱都是来源于陌生人；我喜欢把事情做绝。
