# 抱歉，人与人之间是没法沟通的

我弄了一个包装群，只有男性可以加入，因为我在里面可以无话不谈，说脏话都可以，我觉得这样才痛快。

VIP 群里的一个女性老板知道之后，私信我，说你能不能建一个女性包装群啊，也给我们讲讲怎样找优质男性。

我问，你想找什么样的啊？

她说，我就想找三观一致的，我不需要对方多有钱，我不差钱。

我说，你还不如要求有钱呢。你要求别人跟你三观一致，大概率会遇到骗子。

因为人与人之间的三观是不可能一致的，那些看起来一致的，大概率是伪装出来的。

因为人与人之间的性别、年龄、阅历、受教育程度、家教、视野、格局、财富值、独立思考的程度，不可能都一致，所以三观也不会一致。

比如，我列举一些话题：美国，苹果手机，华为手机，特朗普，中医，风水，星座，国产汽车，日本汽车，婚姻的意义……

那些自称是三观一致的两个人，围绕上述话题一交流，准得打起来。

所以说，高明的人，是不会给自己贴标签的，也不会随便谈自己的坚定立场。

你看那些朋友圈动不动就支持 x 国，或者反对 x 国，支持 xx 手机，或者反对 xx 手机，这些不断表面自己立场的人，都是比较穷、比较蠢的人。

一方面，他们接收到的所有信息，都是有偏向性的，都属于垃圾信息。

另一方面，我们活着的目的，是让自己越来越富足、越来越愉快，而不是看不惯谁，跟谁争论，辩论个你死我活。

善者不辩，辩者不善。

另外，世界上只有一条真理是永恒的：人性是贪婪的。

如果你是心智健全的成年人，别人吸引你，一定是因为你知道对方能满足自己的某种需求，比如生理需求，物质需求，精神需求，面子需求等等。
