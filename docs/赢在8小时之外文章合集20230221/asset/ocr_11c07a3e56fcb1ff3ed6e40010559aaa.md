# 大明星为什么要嫖娼？

原创 赢在 8 小时之外 2022-09-12 11:55:44

我在公众号里曾经说过一个观点：今天被众人追捧的偶像，在未来的某一天一定会被众人踩在脚下。

而踩他和捧他的那批人，是同一批人。

你去看今天风光无限的名人和明星，未来基本都逃不过这个命运。

当然，我说的是这片土地上的明星。

而 US、HK、JP 这些地方的明星就可能好一些，不会有这么大的反差。

为什么？

一方面，F 制健全、高度文明的地方，PC 一定是合法化的。

另一方面，他们这些地方的人，对性、婚姻看得很透，比如名人娶老婆、找小三时，一定会签订非常严密的协议。

你不想签，经纪人也一定会逼你签。

比如，每个月给多少零花钱，一定是清清楚楚写在合同里的。

但是我们这里不一样，我们是道德高尚的地方，怎么可能签这些影响感情的协议呢？

结果就是，一地鸡毛。

那么问题来了，这些帅气的大明星为什么要去嫖娼？你找正常的女朋友，或者睡粉丝，至少会有上万的人排着队。

你为什么非要去嫖娼呢？

其实原因也很简单，明星找女朋友，或者找粉丝，是一件风险极大的活动。

每一个跟他交往过的女人，在未来都可能会成为一颗巨大的定时炸弹，随时白把自己的前途炸毁。

为什么会出现这种情况？

因为财富值、能量值严重不对等。
