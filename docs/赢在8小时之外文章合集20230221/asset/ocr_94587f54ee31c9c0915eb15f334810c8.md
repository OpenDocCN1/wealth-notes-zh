# 马斯克分享的 50 个 “认知偏差”

赢在 8 小时之外      2022-04-02 16:00:00

最近我在翻看马斯克的推特，发现他在去年的时候分享过一张图片，内容是 50 个认知偏差，配文是 “年轻人越早知道这些偏差越好”：

> Elon Musk @elonmusk · 2021年12月20日
Should be taught to all at a young age

![](bbox=[0.315, 0.246, 0.745, 0.475])

什么是认知偏差呢？

就是说，我们在思考事情时，如果按照往往的思维惯性，很容易落入一个陷阱里面，从而会做出错误的判断。

如果意识到这些认知偏差的存在，我们在思考问题、做决定的时候，就会更加理性，更容易做出正确的判断。
