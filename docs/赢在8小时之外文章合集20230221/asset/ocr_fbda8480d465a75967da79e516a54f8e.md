# 我最喜欢跟 00 后打交道

原创 赢在8小时之外 2022-12-05 12:00:22

上次在知识星球里面，一位 00 后向我提问，想知道经历不够丰富，能不能在网上写文章？

![](bbox=[0.22, 0.22, 0.79, 0.62])

我的回答是：在互联网上赚钱，跟阅历这些关系不是很大。30岁、40岁阅历丰富的穷层级还有好几亿呢。

他们的阅历一毛钱都不值。

世界上只有年龄是不需要任何努力就可以得到的，我从来不会一个人因为年龄大就尊重他，我更喜欢“老而不死是为贼”这句话。

另外，我觉得互联网赚钱这个领域，希望还是在 00 后身上，我们社群里就有许多日入过千的 00 后大学生。

想在互联网上赚钱，最重要的是接受新鲜事物得快，脑子灵活，收钱要狠，这些都是年轻人的特征，而不是老年人的特征。
