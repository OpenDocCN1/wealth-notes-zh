
# 为什么我从来不追逐风口

原创　赢在 8 小时之外　2021-01-23 12:24:13

微信视频号一天一个动作，比如这周推出了直播功能，下周推出了打赏功能，下下周推出了展示到个人名片功能……

昨天微信更新后，据说是好友数量能容纳 1 万人了，而且还都可以查看朋友圈，不知道是不是真的……
……

然后有个 VIP 群友就私信我，问我微信视频号的风口是不是来了。

我说，微信视频号我们也在做，但是呢，我还真没有想过“风口”这个词语，我做自媒体 7 年了，从来都没有追风口的意识。

新出来的东西，我如果有时间，就上手玩玩。如果没有时间，就不予理会。

若是这个东西推出一年、两年后，火遍了大江南北，而且很多人都在上面赚到钱了，那么我们也会进入这个平台，去认真做引流，认真做内容。

有的人非常精明，什么事都喜欢抢先，抢在风口浪尖上，他们坚信，“抢占先机”是最最重要的事，错过了就没你的份了。

我就不这样认为，我觉得人潮拥挤的地方，也可能是要围的人在围钱。

我一直喜欢举的例子是，2016 年我们才开始做微信公众号，那时候就有人跟我语重心长地说，现在已经没多少人看微信公众号了……

但是我觉得当时很多钱都流向了公众号，我们做了半年之后，几个号盈利也非常可观，就投入很大精力去搞公众号。

直到 2021 年的今天，这些账号仍然是我们收入的一大块。

另外，我们做的几个喜马拉雅账号，也持续盈利 3 年多了，非常稳定、可观，但是好像从来没有人提过音频平台的风口是什么。

B站、知乎同理。

还有一个特别有意思的事，直到今天，仍然有人说“现在没人看公众号了”“公众号风口早就过去了”这种言论。

我就觉得非常奇怪，明明我们这里的数据增长是非常可观的啊。回到一年前的今天，疫情刚刚爆发，我在韩国过的春节，那时候韩国和日本还没有病例，而国内形势日趋严重，我还打算跑到北海道去躲一段时间来着（我有日本多年签），因为当时我还傻乎乎地以为，这个病毒怕冷……

当时很多人都只能宅在家里刷手机，工人放假了，学生也放假了，导致刷手机的人群、时长暴增，我们的收入在过年前后那两个月，比之前至少翻了一番。

结果大年初二我就飞回了北京，开始忙碌。

今天早上助理还跟我说，现在又出现去年时候的迹象了，出奇地相似，就是增长数据出奇的好。

也就是说，你如果是做公众号的，或者打算开始做，那么过年前后，大家都宅在家里刷手机的这段时间，正是绝佳时机。

千万不要相信什么风口论，从目前各个文字类平台的受众、盈利能力来看，公众号仍然是 number 1。

而且，你一旦积累了自己的粉丝之后，就可以卖自己的服务或者产品了，只要是合法合规的，平台没有任何限制。

这一点，公众号跟头条这种毒瘤平台是有本质区别的。

张一鸣的所有产品，包括抖音，他的宗旨都是不让运营者、内容制作者赚到钱。你贡献内容可以，一做营销就给你降权，一卖东西就给你封号。除非公司化运作，而且是专业表演团队，还有一丝机会，但是个人运营者大概率会被他绞杀的。

虽然我们也做头条、知乎、百度贴吧这些，但是我们的目的绝对不是长久运营，去积累粉丝，去在这些平台上直接变现。

在不靠谱的平台上，我们的所有的动作都是为了引流，用尽各种手段把流量引到微信上。因为如果不引流的话，最终结局仍然是被降权、封号，还不如从第一天开始就进行引流。封号就封号，我继续注册，继续蹭热点，继续用尽手段去引流。

有些傻货特别拎不清，竟敢去头条或者抖音这种毒瘤平台上用心做内容，深耕了一年、两年，一直循规蹈矩，粉丝也起来了，你一做营销，就给你封号了。

如果你想做短视频内容，我觉得可以尝试做微信视频号（哪怕是快手也行），至少微信的产品，他的粉丝和阅读量一般都是真实的，如果你不做特别过分的事情，他不会给你降权或者封号，微信系的产品给我的感觉就是：十年如一日，特别靠谱。

当然，腾讯的视频号，最终也有可能变成“腾讯微博”，不了了之。

总之呢，我不推荐大家去追所谓的风口，因为那个东西都是事后诸葛亮总结出来的。找到一个适合自己、靠谱的、很多朋友都在上面赚到钱的平台，就去深耕，这样是最客观的做法。最后，如果你不知道该写什么、怎么写，可以点击“此处”加入我的写作社群（入群费 400 元）。

# 赚钱就是上战场

昨天在写作群里，有一位老板，已经按照我说的思维开始写作了，并且开始收到钱了：

![](img/e1f3d1b26c6e137a1e76a069830cb76f_253_0.png)

![](img/e1f3d1b26c6e137a1e76a069830cb76f_254_0.png)

简单聊几句我就知道，这类老板执行力非常强，今天我说的东西，明天他就能实践了。

而且，就像我在群里说的那样，只要你在网上开始独立收钱，那一刻就相当于上了战场，是真刀真枪的实干。

因为只有这一刻，你才能直面大众的质疑、攻击、无理取闹，当然还有信任、价值交换、温暖的感觉。

大多数人，一辈子都不会在网上花 1 块钱，你让他充个视频会员，或者玩游戏买个皮肤，比要他的命还要难受。

你如果迟迟不走出收钱这一步，那么你一直是在彩排，根本上不了战场，一个突发事件就会吓得你屁滚尿流。

一直跟你互动的，也是那帮从来不会为价值买单的穷鬼。你自己可以想想，你如果沉浸到这样一种穷鬼氛围里，还想赚钱，简直是做梦。

我之前就说过，一个人进入社会之后，无论在商场、情场、朋友场还是亲情场，你唯一能靠得住的，就是手里的钱，其他任何一个人都靠不住，包括亲爹亲妈、亲老公、亲儿子。

而一个士兵，进入战场之后，唯一能靠得住的就是自己手里的枪，其他的上级、下级、战友，统统靠不住。因为性命攸关的时候，所有人都会先想到自保。电视剧里那些舍己救人的桥段，都是演绎而已，认真你就输了。

其实呢，赚钱这件事，跟上战场没什么区别。

当然，打工者赚钱跟战场没什么关系，他们一辈子都不用上战场，也不敢上战场。只要你已经脱离了打工者阶层，你要非常清晰地意识到，你已经上战场了，没有退路了。

你如果不抓紧开始收钱，就相当于你的枪膛里没有一发子弹，生活中随便一个小挫折都相当于一个劲敌，直接把你干趴下。

收钱越多，你的子弹就越充足；收钱越狠，你的刺刀就越锋利。

你如果不想赚钱，就说明你根本不想活命，最终结果就是基因湮灭。

下面，我再跟大家分享一个扎心的真相。

你如果还身处泥潭，身处臭狗窝，那么你必须集中精力去赚钱，而且要把赚钱培养成自己生命中最喜欢的事，生命中最重要的事。

你的灵魂必须献给金钱。

只要你不这样做，那么任何人都拯救不了你，你还是老老实实去 996 吧。

经常关注我公众号的人，应该了解我，我特别喜欢给别人进行分类，当然不只是“穷人”和“富人”这么简单。

我把人分成两类，第一类人把赚钱当成生命中最重要的事，也是自己快乐的源泉。赚到钱之后，当然能享受人生，但是这不是终极目标，终极目标一定是赚更多的钱，让自己的影响力更大，队伍更大，击败更多竞争对手，甚至建立起自己领域的小小商业帝国。

另一种人，他们并没有把赚钱当成生命中最重要的事，他们总会说：我赚到钱之后要怎么样。比如，很多打工者最喜欢说的就是：等下个月发工资我就要换一个新的 iPhone；等年底发奖金之后，我就要去旅游；等我攒够一百万之后，我就要买车买房，娶个媳妇成个家……

总之呢，这类人，并不把“赚钱”“事业”当成生命里最重要的事，他的心思都在赚钱以外的事情上。

你不重视金钱，那么结局一定是，金钱也会离你远远的。

有两点，大部分穷鬼一辈子都想不透。

第一，如果你仍然困在泥潭里，即使你拥有了最新的 iPhone，你也会用它来抢红包，抢拼多多，刷个抖音，玩个游戏，看看小电影撸一发，然后你就空虚地睡着了，你的梦里都会充满焦虑和不安。

因为你仍然是一个不敢上战场的懦弱垃圾，世界不会奖励你真正美好的感受。

如果预算不足，那么即使让你去世界上最漂亮的国度去旅行，你也是穷游，非常不爽。之前我去瑞士时，就碰到过这类人，他们很少买水喝，也很少上厕所。因为一瓶矿泉水要十几块钱人民币，上一​​次公厕也要十几块钱人民币。为了省钱，有的人就会少喝水、少上厕所。这时候漂亮的瑞士在你眼中根本不是人间天堂，而是人间炼狱。

再说婚姻，其实经常有大学同学来咨询我脱单建议，碰到男的我就跟他说，你如果没车没房，或者有车有房有贷款，或者有车有房无贷款但是工资不高，你要么单身，要么娶个丑老婆，因为稍微有一点姿色的女人，保养费都很高的，你有个破房子有个破车有什么用，又不能当钱花。

当然，你非要想找漂亮的也行，那就是去包装，去骗，除此之外别无他法，但是你要承担不可估量的后果。（我要是想开个男性脱单群，有没有人想加入？想的话评论区回复个“1”，肯定是收费的，而且只针对月入一万以上、外形不是极差的人。）

第二点，很多人看不透的是，你所追求的最新数码产品、环球旅行、漂亮女人，假设我统统给你满足了，用不了半年，你就会觉得非常无聊，真他吗没意思。

即使你去玩高尔夫球，玩马术，玩茶道，你也会发现，你碰到的人都是事业心极强的人。

到最后你会发现，只有事业，只有赚钱，才能带给你实实在在的快感和满足感。

而且这种满足感是每天更新、历久弥新的。

所以说，大部分人如果真想逆袭，真想体验人世间最美好的东西，首先得聚焦在赚钱上，有了稳定的现金流之后，你就可以买一切能给你带来良好感受的体验；体验过后，你会意识到，最有意思的事情还是自己的事业，是收钱。

子弹上满膛之后，到战场上，你想怎么射都可以。

# 热爱学习的人，命都不太好

原创　赢在 8 小时之外　2021-01-25 16:38:01

最近听到一个段子，说现在三千块钱招不来一个农民工，三千块钱只能雇一个大学生。

这种说法肯定是夸张了，因为学历越高，平均工资就越高，你到哪里查数据都会是这样的。

但是呢，高学历低工资的现象确实存在着，而且很多。

不光工资低，很多大学毕业的白领，连幸福感都不如农民工高。

农民工干的虽然是体力活，但是晚上就能老婆孩子热炕头，睡个安安稳稳的觉。

而很多办公室白领，每天都要挤公交上下班，职场上还要勾心斗角，996 的生活让自己连对象都不好找，晚上也可能是怀着焦虑入睡的。

当然，如果收入高的话，这些也都可以忍了。关键是，很多大学生进入职场，即使工作几年之后，月薪也很难过万。

我之前就发出过这样的感叹：如果一个人能考上本科，那么他的智商差不多能占到全国人民的前 10% 了，那么他的收入也应该占据在前 10%，否则不科学。

我在公众号也经常写，钱是最客观的东西，它是每个人用生命精华换取的。

今天我想再说一句：钱也是一个人智慧的结晶，一个人赚的越多，说明他的智慧越大。

高学历的穷鬼整天以为自己很聪明，那些有钱人都是笨蛋，都是土老帽。但是你想过没有，如果你的想法是对的，那么你的口袋里为什么没有你想要的东西？

这就很有意思了。

我之前写过一篇文章：

# 为什么我不再读书了

，当然，我说我不读书了，并不是你想象的那种，我成了反智之人。而是说，我已经非常清楚地意识到了，大部分书籍，我们读了之后，除了会浪费时间之外，还会给我们大脑灌输非常糟粕的思想和文化。

我也出过书，之前也组织过读书会，也参加过读书会。你们知道里面都是什么人吗？都是喜欢批判有钱人的无产阶级。

热爱学习的人，命都不太好

比如，我们都没有房，但是我们可以聚在一起，批判一下那些有房产的人，取笑一下他们的决定多么愚蠢，我们多么英明。

我只是举个例子而已，大部分读书会都是这种本质。也就是说，喜欢读书的大部分都是穷人。

为什么我说，热爱学习的人，命都不太好呢？

因为做事情，跟学习是对立的，你如果真的抽出时间去读书、去学习，那么大概率你就没有精力和积极性去做事情了。

然而，真理都是在做的过程中总结出来的。

我虽然组织了写作群，但是我经常喜欢说的一句话就是，写作这玩意，学习技巧只占非常小的一部分，最重要的是不断去写，写的过程中才能思考，才能进步，才能收钱。

下面我再跟大家说一个扎心的真相：学习的门槛是最低的，干的门槛是最高的。

很多人，报了这个学习班，那个学习群，整天记笔记，参加群组讨论，但是呢，他就是不去实践。

这样的人至少占了90%，也就是说，大部分人都是热爱学习的穷鬼。

有人经常给我留言，说让我多写点正面的东西，积极向上的东西。我心说，你都学了二十年正能量了，每天都是好好学习天天向上，现在你混成什么 B 样，心里没点 B 数吗？

为什么就是不肯承认自己学错了东西，自己一直坚守的文化是糟粕呢？

如果你一直都是学习高大上、正能量的东西，但是现在混得狗屁不是，我建议你还是早点把那些放弃，学习点“坏”的东西。

当然，我不是让你去做坏事，去害谁，而是说，你不要总活在童话里，要直面现实，要多做，多输出，多做收钱的动作。

永远都别再做一个热爱学习的穷屌丝了。

# 喜欢做准备的人，最终将一事无成

上次我讲了做短视频的事情，然后一个 VIP 群友就私信我，说他打算做 xxx 行业的短视频，问我有什么好的建议没有。

我说，你现在就掏出手机，注册短视频平台的账号，然后今天必须发一段内容上去。

他说，我还不知道怎么拍摄呢，也不会剪辑，运营原理也不清楚，我是不是需要先学习一段时间，做好准备再开始发？

我就跟他说，进入社会之后，我们做本职工作以外的事业或者探索，必须在你产生想法之后的当天，或者 3 天内做出行动。

如果 3 天内你没有做出行动，那么这辈子你都不会真正行动起来。

准备工作虽然重要，但是开始的第一步才是最关键的，这一步必须是行动，必须是直接上战场，而不是到处去学习，去准备。

比如，你在职场上想多考一个外语证书，比如雅思考试。这个考试呢，没人逼你去考，考完之后也没有承诺性的回报，这件事的投资回报率很难预估，仅仅是你意识到自己一定要考个证书，提升一下自己，提高一下职场竞争力。

这时候你最需要做的不是去背单词，去做阅读理解，去找外教练口语。你最需要做的，就是今天去官网报名报了。

因为一旦你有这个想法了，你知道这件事能提升自己，这时候必须要立刻行动，对于很多普通人来说，报名这个动作，几乎就占你整个流程的 99% 了。

你如果不立即报名，那么你可能会把这件可有可无的事拖到猴年马月。

当然，报名也是要客观的，如果自己六级刚通过两年，英语水平还不错，那么你可以报考两个月后的雅思考试；如果你大学四级是勉强通过的，而且已经工作多年了，那么你可以报半年甚至一年以后的名。

当然，雅思最新政策我也没有了解，现在可以提前多久报名我不清楚，我只是举个例子而已，就是说大家一定要根据自己实际情况去行动，但是这个行动必须要在 3 天内完成。

我之所以举雅思这个例子，因为它是我的亲身经历。我大概是在 2014 年考的雅思，也算是人生中的转折点吧，因为外企工资一般是比国内的企业工资高的，一般要高 2-5 倍，而且福利待遇、工作理念等方面也是天壤之别。
