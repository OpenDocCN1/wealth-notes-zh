# “我投错胎了，还有救吗？”

原创　　赢在 8 小时之外　　2020-11-30 16:06:19

我有个老乡，学历不高，后来去当兵了。

有一次回老家碰到他，他跟我说了一段话，让我印象特别深刻。

他说，退伍后才发现，有钱人家的孩子，回来父母都把路铺好了，不像咱穷人家的孩子，稀里糊涂去当兵，回来又稀里糊涂的在社会上摸索谋生。

后来我就想，有钱人家的父母，不是说在孩子退伍或者毕业之后把路铺好了，而是在孩子出生的时候就已经把路给铺好了。

人家几代人、几十代人，每个人都有这种意识和思维。

而穷人家的父母，最喜欢说的话就是“儿孙自有儿孙福”，时不时就把“孝道”这顶帽子压在你头上，让你动弹不得。

有一次，我在网上看到一个 95 后的山村姑娘，她说了类似这样的一番言论：如果自己能选择的话，希望父母当初不要生她。

少年时对世界充满好奇的，活的很快乐。

自从成年之后，就没有感觉生活有多美好了。因为家庭的负担让她不能像同龄人那样享受这享受那，而是要承担这承担那。

而且仿佛看不到尽头在哪里。

我就想，投胎还真是个技术活，还有很多运气的成分在里面。

好在呢，发展中 G 家，一切都是混沌的，敢闯敢干的屌丝们，还是有逆袭的机会的，但是要把眼睛放亮，脑子要活。

昨天我去一个小超市买水，店主是一个中年女人，她儿子就在那里刷手机，正在看的是《最美逆行者》，我在机场等地方看到过这类片子的片段，大概就是有灾次时，那些英勇的消防战士会第一个冲上去，有疫情时，那些无畏的医护人员会冲上去……

妈妈发现了他在看这个节目，就把手机拿过来了，问，谁让你看这个节目的？

小孩子说，老师让看的。

他妈妈说，以后不许看这个节目了，老师要求的也不行，听到了吗？
