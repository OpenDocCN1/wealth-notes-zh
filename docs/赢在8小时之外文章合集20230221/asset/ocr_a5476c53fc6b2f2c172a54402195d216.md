# 为什么我鼓励大家搞原创

原创 赢在 8 小时之外 2022-03-01 12:00:00

最近每个月我都会收到几条这种需要处理的投诉：

![](bbox=[0.285, 0.184, 0.71, 0.6])

意思就是，A 抄袭我的文章，被 B 发现了，于是 B 就举报了 A 的这篇文章，然后系统就询问我，是否对 A 发起投诉。

我一看这篇文章，跟我以前发过的文章重合度在 80%以上，已经属于抄袭了。

如果我点“同意”，那么 A 写的这篇文章就会被判定抄袭，而且他的公众号也会被记一次“大过”。有几次大过，你的号就废了。

我没有点“同意”，因为我知道可能是群里的朋友仿写的，而且这样的人还不止一个。

这一切都怪我之前没说清楚，我以前一直说，欢迎大家仿写我的文章，但是我没有说清楚仿写比例。

今天我要声明一下：内容重合度如果超过 50%，那就不是仿写了，那是抄袭，我反对抄袭。
