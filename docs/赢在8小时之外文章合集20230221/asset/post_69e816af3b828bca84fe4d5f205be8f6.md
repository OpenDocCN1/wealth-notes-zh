
# 富人的道德只为利益服务

原创 赢在 8 小时之外 2022-10-31 12:00:20

最近我看了一部关于英国的纪录片，18 世纪的时候，由于大规模的工业化和城市化，导致很多农村穷人涌入到城市，他们没有工作，也没有食物，所以犯罪率激增。

当时英国的监狱已经超过最大负荷了，没办法，只能把一部分罪行较轻的罪犯（比如盗窃罪）运送到澳大利亚，顺便让他们开垦那个荒芜人烟的殖民地。

有数据表明，当时至少运送过去 16 万人，今天每个 5 个澳大利亚人里面就有 1 个是罪犯的后代。

早些年的时候，这些“罪犯的后代”为自己的身世而感到耻辱，但是到了今天，很多人都以这种身世而感到豪。为什么会这样？

因为他们非常清楚，当初自己的祖先犯的是轻微盗窃罪，而不是强奸罪或者杀人罪（这些罪犯在英国都被处决了）。

祖先们之所以会偷盗，不是因为他们坏，而是当时的环境决定的，工业化让他们陷入了贫困和绝望，如果不偷面包就会被活活饿死。

有一句名言是这样说的：如果一个人为钱犯罪，是这个人有罪；如果一个人为面包犯罪，是这个社会有罪。

在最初的时候，从英国到澳大利亚的运输船上条件很差，船长按照出发时的人头收取报酬。

所以犯人上了船之后，船长根本不在意这些犯人的死活，吃得很差，生病了也任其自生自灭。死了就直接扔进海里，还能省去后面的伙食。

结果就是，这些犯人的死亡率很高，抵达澳大利亚的时候，往往是半船人死了。

上级发现了这个问题之后，决定想出一个对策来改变现状。

一方面他们要挽救生命（因为承受不了舆论的压力），另一方面他们也希望有更多的犯人活着抵达澳大利亚，好参与殖民地建设。

所以他们制定了一个新规则，给船长支付报酬按照健康抵达澳大利亚的人数来计算。

这下好了，船长给犯人的伙食变得好多了，还给每艘船上配备了一名医生，还让犯人参加各种娱乐活动……

看到了吗？

船长之所以觉得保护生命、道德高尚，并不是因为他突然良心发现了，而是因为他只有这样做才能实现利益最大化。

也就是说，道德是为利益服务的。

“有钱能使鬼推磨”也是这个道理。

比如，有的男人整天抱怨自己的老婆不贤惠，父母和孩子也总是让自己头疼，但是他从来不说自己能赚多少钱。

再比如，有的父亲整天抱怨自己的孩子不孝顺，但是他们从来不反思一下，从小到大给孩子提供过什么资源，造成过什么伤害。

提到“孝顺”，有一个经典的问题很有意思，争议也特别大。

老婆和老妈同时掉进水里，你先救谁？

其实有标准答案的，但是很残酷：谁的价值高救谁。

我特别认可这句话。

我还有很多问题还没想通呢，还有很多事情没有体验过呢。

## 改变物理世界的重要性（玄学）

这篇文章里我强调了物理环境的重要性，很多人是意识不到的。

比如有别的国家或者城市，为什么人们那么热情开朗，而且创造力特别强？

你去看看就会发现，首先就是人家的环境好。

空气无污染，食物无污染，到处都是绿油油的草坪和干净的湖水，人均居住面积超级大，孩子的成长环境和大人的工作环境也超级宽松自由。

我如果说“干净的自然环境能带来干净的灵魂，狭窄的生活空间会带来狭窄的灵魂”大家会不会觉得太夸？

但这就是我真实的感触。

稻盛和夫也说过类似的话：奋斗一生的目的，就是为了走的时候比来的时侯灵魂更干净一些。

## ② 体验

要知道，我们无法真正拥有任何物品或者人。

注意，我说的无法拥有，不是有些人嘴里说的那种“人死的时候什么都带不走”，而是说，你买满屋子的宝贝，也无法真正拥有，因为你的注意力永远在下一件宝贝身上。

你的心不在现有的宝贝身上，那么他们就没有灵魂。

不知道大家有没有发现一个有趣的现象：有些比较贵的衣服我们买回来没穿几次就挂在衣柜里面吃灰了，而日穿常的衣服虽然不华丽，但是特别舒服。

一年后你再对比一下两件衣服，自己现在穿的这件日常衣服越看越亲切，而衣柜里那件吃灰的衣服，已经感觉很旧了。为什么会这样？因为衣服就是用来穿的，你总也不穿它，它的灵魂慢慢就枯萎了，外表也会失去光泽。

长期没人居住的房子，没有“人气”，也是同样的道理。

# “体面”的最低门槛

原创 赢在 8 小时之外 2022-11-05 12:00:46

我在年少前就已经下了一个决定：这辈子离穷人越远越好。

并不是我势利，因为我发现这些人所患的穷病是无药可治的。

很多穷人的智商也是非常高的，甚至还有很高的学历，但是他们把那点小聪明都用错地方了。

如果你在底层待过就会发现，满大街都是才华横溢的穷鬼，而且一个比一个聪明的。

但是呢，如果你细扒开他们这些“聪明”，也仅仅是懂得察言观色，擅长扮酷扮有地夸耀自己、贬低别人。

为了有点小利益就要算计很久，甚至要破口大骂、大打出手。

他们看起来好像精通世故，能说会道，但是他们的认知只是停留在非常浅的一个层次而已。

不足为道。

举个例子，一个中年男人，在单位里是个个人精，同事和上级的关系处理得都非常好，对国际形势、历史人物、足球……分析得头头是道，所有人都被他的口才和人格魅力所折服。

可就是回到家里，老婆还是嫌他太废物，孩子对他也没有太多尊重之意，非常不听话。

亲戚之间的故事也是一箩筐，自己也经常有闷心的感觉。

为什么会这样？

因为他没有解决根本问题，那就是把自己的聪明变现，换成钱。也就是说，为自己争取到实际的利益或者职位。

我昨天在群里也表达过一个观点：如果你的月入不到 3 万元（在不加班的情况下），那你就不要说自己聪明，也不要期待有尊严、有爱的生活。

当然，如果你没达到这个标准，也恰好过上了无忧无虑的生活，那就是运气，不是常态。
