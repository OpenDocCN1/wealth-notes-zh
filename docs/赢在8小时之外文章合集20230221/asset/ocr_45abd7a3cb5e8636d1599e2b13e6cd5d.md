# 你读了那么多书，为什么依然赚不到钱？

原创 赢在 8 小时之外 2022-04-18 12:00:00

上周我在知乎回答了这样一个问题：每天坚持看书两小时，能否真的提升自己？

我说，进入社会之后，如果你读完一本书，能把书中的信息换成钱，你就是在提升自己。

如果读完一本书之后，里面的信息无法换成钱，那么就相当于白白浪费了两个小时，还浪费了几十块钱。

至于提高格局、开拓眼界、陶冶情操之类的，都是糊弄鬼的说辞而已。真正想要获得这些方面的提升，你需要的是人民币，不是你所谓的“读万卷书”。

我看完一本书之后，我就会写一篇读后感，设置成付费阅读文章，然后就会收到 1000 元钱。

如果你真这么想，那你就太幼稚了。

今天我就以最通俗易懂的形式，把“吸引力法则”给大家讲透彻，以及该如何运用这个法则，帮助我们突破一个个人生瓶颈。
