# 如何提高自己的修为？

有人总会反驳，说哪儿那么容易换一个环境。

真相是，你如果没钱，那确实不得不忍受命运扔给你的任何烂环境。

如果你有钱，你可以选择更换家庭，更换城市，甚至更换国家，都是可以操作成功的。

还有砖家会说，心态是最重要的，要学会调整心态。无论命运如何捉弄你，只要你保持一颗积极的心态，总能逢凶化吉，遇难成祥。

我一直很反感这种言论，我觉得这些砖家都是在扯几把蛋。

你如果出生在一个烂环境里，你的健康、思维方式都会被底层思维所污染，污染了20年，已经根深蒂固了，然后你试图学习国学、学习佛学来熏陶自己，让自己调整心态？

做梦呢吧。

你最需要做的，是用尽一切办法，改善自己的处境，改变每天接触的人。

心态是会随着环境而调整的。

否则，再多的自我激励、自我安慰都是徒劳，都是自欺欺人，最终你的心会被现实击的粉碎。

现实，对穷人很残酷。

无论你如何逃避现实，现实最终一定会对穷人下手，打得你满地找牙。
