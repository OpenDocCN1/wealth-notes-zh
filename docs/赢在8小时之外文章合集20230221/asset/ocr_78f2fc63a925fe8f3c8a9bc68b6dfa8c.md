# 为什么我从来不相信人品

我很少跟别人一起吃饭，尤其是不跟打工者一起吃饭。

并不是我瞧不起打工者，因为有的打工者收入很高，非常光鲜亮丽；而有的老板可能是负债累累，但是我也会选择老板，不会选打工者。

当然，自由职业者也行，投资人也可以，只要你不是打工者就行。

为什么会这样呢？

原因有两个。

第一个，如果你是打工者，你深入了解我之后，你会发现我非常无聊。

你喜欢聊的上下班通勤、买车买房、友情、爱情、相亲、婚姻、看电影、购物、旅游、道德、文化、团建、同事关系、上下级关系、爱国、美国，我压根都不关心，或者我只能假装着附和。

但是呢，几乎所有的电视剧、电影、短视频和书籍，跟大众展示的都是上面这些内容。

老板都知道，这些东西都是很无聊的，是非常要命的。

但是呢，14亿人里面至少有13.9亿人每天就关注这些东西，而且他们之间每天还要互相讨论、交流、互相发表观点。

如果你不参与讨论，不发表观点，他们会说：你这个人神经有问题吧？是出家人？

当然，只要不是刚刚暴发的老板，都懂得离这些打工者远远的，因为我们非常清楚，我们之间是没法沟通的，根本不是一个物种。

谁也不必说服谁，谁也不必讽刺谁。

那么，创业者、老板们到底关注什么呢？

如何获取更多客户，如何更好地服务客户，如何卖出更多的产品或者服务，最终收获的就是钱和权力，以及不平等的势差和别人的臣服。

而且我们的成就感、存在感、人生意义，都来自于此。

但是打工者不一样，他们的成就感可能来源于道德高尚，文化修养，爱国情操，美好的爱情，忠实的友情，良好的人际关系。
