# ② 跨过“技术”，让自己在更高维度思考问题。

有很多学历不是很高的年轻人，总喜欢咨询我：学个什么技术好找工作？什么专业最有前途？

我的回答是：世界上不存在最好的技术、最有前途的专业、最舒服的职业。

如果你QQ的思考方式仅仅停留在“学技术、找工作、赚钱”这个维度，那么任何技术都拯救不了你。

比如，你去学习 PS，出路很可能是，去复印店打杂，或者去照相馆打杂，或者偶尔从猪八戒网站上接个私活，而且甲方个个都很难伺候。

再比如，你去学习外语，毕业之后你会发现外语人才多如牛毛，想要做翻译的话，还要继续苦熬多年，而且笔译是按字数计费的，口译是按照时间或者项目计费的，除非天赋异禀，否则都是赚个辛苦钱。

疫情之前，还有专业做代购的，不需要任何学历，平常飞飞日韩和香港就行了，一个月飞几次就可以纯赚万八千块钱。

只不过呢，这个属于赚差价，也是辛苦钱，而且还存在被海关查到的风险。

那么，学技术到底能不能让自己赚钱更轻松呢？答案是，有这种可能性，前提是你不仅仅通过时间和技术来换钱。
