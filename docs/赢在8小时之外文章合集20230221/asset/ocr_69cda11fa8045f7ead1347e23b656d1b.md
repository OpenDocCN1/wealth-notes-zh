# 男人永远要说值钱的话，做值钱的事

原创 赢在 8 小时之外 2021-07-21 18:37:08

（本文只有男性粉丝可见）

前两天，在包装群有个朋友私信我，说他最近间倌一个心仪的女生，但是都得不到回应，以前聊得一直很好。

我看了他的聊天记录，发现他不是问候人家早上好，就是问人家吃了吗，要么就是多喝水，注意避暑。

我就跟他说，你能不能说一句值钱的话？要是没有值钱的话，你就不要聊天。

但凡是一个长得还过得去的女人，在她二十几年的成长路上，她已经听过太多太多的关心语和问候语了，所以你的问候就显得非常廉价了。

这些话一分钱都不值，而且让人听了会很恶心。

要么你就聊点值钱的话，要么就闭嘴。

另外，不要总找存在感，怕别人挑剔你的不理睬。

人际关系的本质，不是陪伴，是仰望和依赖。

廉价的陪伴一文不值。

不光男女关系如此，连父母和子女的关系也是如此。

其实很多家长私信过我这个问题，就是自己的事业，与陪伴子女发生了冲突了。

自己到了事业关键阶段，需要投入大量精力。

但是呢，孩子正好也到了成长的关键时期，最需要自己的陪伴，所以特别不好取舍。

我一般不给建议，但是我今天就统一聊一下这个话题。

每天的陪伴，不是最重要的。而你作为家长所树立的榜样，才是最重要的。

你可以想象一下，如果你是 M 国总统，或者是刘德华，或者是董明珠，那么即使一个月见一次孩子，他在想到你的时候，也是特别敬佩、特别崇拜的。

他跟同学聊起你，也是一脸骄傲和自豪，而且是发自内心的。
