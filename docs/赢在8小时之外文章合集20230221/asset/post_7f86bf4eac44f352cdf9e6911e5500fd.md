+ 2. 不要害怕重新开始。因为这一次，你不是从头开始，而是从经验开始。
+ 3. 人只有做真实的自己时，才会有独特的个人魅力，伪装出来的人设，崩塌只是时间问题。
+ 4. 金钱对于人生的意义，并不仅仅是买买卖。更重要的是，金钱意味着你拥有选择权和拒绝权。
+ 5. 在这漫长而美好的一生里，如果你真找到了想做的事，那么无论何时决定再次开始，都不算晚。
+ 6. 今天不改变，就不存在明天会更好。今天什么也不做，却相信明天会更好，你是在浪费时间。
+ 7. 人生苦难重重。不要去刻意追求幸福，因为它终究只是一种主观情绪。人生最好的状态就是平静，不悲不喜。
+ 8. 人生不是烧火煮饭，要等柴米油盐都准备好了再下锅。很多事情是突然来临的，仓皇之际你就要硬着头皮上，等你什么都准备好时，已经散席了。
+ 9. 忘掉虚无缥缈的梦想，远离那些高谈阔论的人，制定切实可行的目标，执行中关注每一个细节。反复训练，反复尝试，最终就会达成你想要的结果。
+ 10. 有些朋友对社会还是缺乏认识。你要知道，人与人之间最大的区别是阶层，而不是城市。
你觉得自己在一线大都市，但你是底层，大都市的资源你根本享受不到，说不定你就是资源本身。
+ 11. 现代社会，打工者最容易产生两个认识误区：
从小地方到了大城市，以为阶层提高了；开上了汽车，以为阶层提高了。
实际上这是生产力发展的结果，你还是原来的阶层。年薪 30 万的普通码农，真正的名字叫信息产业工人；写字楼行政秘书，真正的名字叫账房丫头。
+ 12. 任何一个你不喜欢又离不开的地方，任何一种你不喜欢又摆脱不了的生活，就是监狱。
如果你感到痛苦和不自由，希望你心里永远有一团不会熄灭的火焰，不要麻木，不要被同化。

13. 等你活到一定年龄，足够了解自己之后，就知道这世界上很多人你相处不来，很多应酬的场合没太大意义，很多倾诉你没必要去当垃圾桶。很多琐事你没有义务去解决，很多废话都不必说，很多执意走开的人本来就不该挽留。只有你自己的时光最宝贵，比什么都值得珍惜。

14. 一段雇佣或合作关系，一开始一定是等价交换。经过一段时间的相处之后，才会互相信任、欣赏。这时候，人际体验会越来越重要，甚至超越利益关系。

这个过程不能倒过来。那种索味平生一上来就只谈交情、不谈利益的大忽悠，尽量回避为好。

15. 演员、歌手、网红、运动员、作家这些职业是典型的赢者通吃，没有中等收入者，只有 1%超级明星和 99%跑龙套的。

医生、会计师、工程师、大学老师这类职业，个体收入呈橄榄型分布——普通人居多，只要勤勤恳恳脚踏实地，就可以获得越来越好的收入，不过也几乎没有一夜暴富的可能性。

16. 人的大脑每天会产生几万个想法，大部分毫无任何价值，甚至只有负面价值。情绪其实是大脑思想的排泄物。如果你每天都认真对待、仔细分析自己的想法，很容易沉溺其中。

那些喜欢找树洞倾诉的人，往往并不会变好，只会情绪持续性的低迷，永远阴暗抑郁。这样的人难以取得任何成就。

17. 脑力劳动者和体力劳动者工作时，有一个明显的区别：脑力劳动者工作并不完全是有效的。

脑力工作者的产出只是信息，并不能直接的变成产品；体力劳动者工作产出是具体有效的，可以直接变成产品。

对于脑力工作者来说，忙碌本身没意义；你工作中有效性产出的占比，才是决定你工作价值的所在。

18. 刷手机太多会影响人的深度思考能力、认知能力、损害记忆力、增加压力与紧张感、引发负面情绪、容易抑郁、造成失眠……

人的大脑不擅长多任务同时进行，更多的还是单线程。刷手机本身是个多任务快速切换的过程。

你从一个话题迅速转换到另一个话题，上FE秒因为新闻而愤怒，下一秒刷到段子又笑起来。长期进行这样的高频多线程，会给大脑带来很大的混乱与压力。

19. 一般情况下，没有人会挖空心思，处心积虑地骗你。更不会有人用非常多的时间和精力，动用大量人力物力财力，去给你挖坑设套。
