# 没事不要乱动脑子

原创 赢在 8 小时之外 2021-08-24 11:46:18

我有个老同事，最近也打算自己开公司，单干。

原因就是，他已经筹划好几年了，他认为现在时机很成熟，客户也比较多了。

然后他来问我：现在应该是所有的创业条件都具备了吧？你帮我看一下还缺什么？有哪些注意事项？有哪些需要避免？你跟我说说可以吗？

我就跟他说，你觉得合适了，就去做，别想东想西的。

问题没办法提前预测，只有先去干，才能碰到各种各样的问题，才会寻找解决办法。

很多人一犹豫就是几年、几十年，从来不敢开始，就是因为他总想“准备好”再开始，或者他想找到一个万能的公式，把这个公式学会了再去做。

我们的大脑局限性非常大，自认为想的很多，准备很充分，其实连事实的 1% 都达不到。

这时候，必须直接去做，才能遇到 99% 的问题，大脑再慢慢调整、进化。

比如创业这个事，很多打工者其实已经具备了单干的实力，手里也有充足的客户了，他就是总想着先学习，先积累经验。

但你不知道的是，打工者跟老板有实质性的区别，你让身体处在打工者层面，光让大脑沉浸在所谓的创业经验和创业法则里，你学的再多，也是 0。

屁股决定脑袋，就是这个道理。也可以说是身体决定精神，身体决定思维。

真正厉害的人，都是“直觉”告诉他，该上战场了。

到了战场上，才发现之前所学的东西都用不上，只能慌忙的随机应变，寻找新的策略。

这时候才是真正开始成长。

等到站稳脚跟，自己不慌了，能冷静思考了，这时候发现，之前学的东西还是有一些能派上用场的。

很多人最需要突破的瓶颈就是，先上战场，别想太多。

就这一步，很多人一辈子都迈不出去。

创业、健身和结婚都是如此，身体远比大脑聪明。
