# 维修表

| 故障 | 产生的原因 | 处理方法 |
|---|---|---|
| 电刷冒火花,整流片发烫 | 1. 电刷压力过弱
2. 电刷在盒中死锁或在锡盒内转动
3. 换向器间云母突出
4. 换向器表面污
5. 电刷销轴磨损 | 1. 塞紧电刷
2. 改变整流板螺纹，检查弹簧压力
3. 去除整流云母，拆下云母槽
4. 用细绸汽油的干布拭布擦洗换向器
5. 拆换销或在正确位置 |
| 换向器大部分表面烧黑 | 1. 换向器转动不畅
2. 电刷在盒中死锁 | 1. 检查电刷自行
2. 改正电刷安装 |
| 电刷下冒火花且个别换向器片下有烧痕 | 换向器分离，个别换向器向突出或凹下 | 如果烧痕不很显著，可用细锉轻轻铲，铲后后无痕，刷上碳粉加工 |
| 有火花且换向器有一定滋啸声 | 1. 电刷松或新装时接触不良
2. 电刷换向器短路 | 1. 检修电刷换组
2. 先将换向器拧干净，因为尘埃污染发生易磨损换向器短路，检修后用仪器检查短路并予以消除 |
| 一组整流中的个别电刷烧坏 | 电刷间电流分布不均 | 检查整流电刷组在检查内部安装的电刷，并检查整流电刷与刷子或间的接触，如接触不规则需换整流电刷 |
