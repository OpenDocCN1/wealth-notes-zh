要求头发在指缘中散布均匀，手指齐排紧、不让头发在指缘中移动，同时手指须要微微弯曲，以便于右手落剪，剪路也要略带一些弯曲，不致把发根剪成直线。

2、托剪。用左手食指托住颈身，绕绕她引导剪刀向左边小开小合地剪。这种动作一般都在最后修饰时才用，女式理发修饰剪喉也用得到（见图14）。

# 卷发圈动作的训练

女式理发的卷发圈动作，完全靠手指活动灵活。练习时可将两手平伸，掌心向下，食指垂直不动，拇指与中指分别在食指周围来回摆动（见图15）。在初步练熟时，往将拇指与中指一齐动，食指须无法律垂直，而每一个动作都应以食指为中轴旋转来的，如果食指一动，就要影响卷圈质量，因此必须认真练习。
