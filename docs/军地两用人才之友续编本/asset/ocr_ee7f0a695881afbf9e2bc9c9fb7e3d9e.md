# 直筒裤

近年来直筒裤比较流行，特别是很受青年姑娘的喜爱。直筒裤裤管口较大(与中档同大)，裤管更直，所以有笔齐、稳重之感。在裁剪直筒裤时，腰围可以略紧，中档应略为上提，这样更能反映裤管的宽松挺直的特点。
