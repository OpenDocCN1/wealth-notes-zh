萎后进行加工，尚未出土的体重期的箭藤和白头藤，可保留其顶芽进行加工。加工方法有两种。

+   1. 一般加工法：采收后先用清水洗净除去在表面的泥沙，然后用竹片轻轻刮去外皮，勿伤皮及内<|start|> 并泡入清水内，如刮皮以后不能及时泡入水中，染紫发黑则变废弃物，加工后需晾晒阴凉处。
2. 采用凉水浸泡。水温必须加入少量明矾（10后面天麻每公斤另2两明矾），再把刮去外皮的天麻浸入沸水中煮蒸，水煮的时间要看天麻块大大小，150克（3两）以上，煮10—15分钟，50—150克（1—3两）煮8—10分钟，50克（1两）以下，煮5—7分钟，破损残次类煮5分钟。水煮时，水深须浸过天麻，煮得合适时，天麻块茎切开以后呈白色小孔，通常质地润密心实。如水煮时间过长，块茎内水溶性物质流失得多，降低成份率。

煮后捞出，平摊在竹席或筛筒上，放在通风的地方晾干水汽，再上坑用文火烘焙，烘至可一股药材加工板，火力宜保持在80℃左右。开始时火力较小，以免温升过高，但不可高于90℃。当天麻烘至七、八成干时，取出用木板压扁、整形。若有膨胀膨胀的，用竹签穿刺，以排出内部的水分，防止胀破，再摊开继续烘干。烘干时火力应降到60℃，不宜用急火，防止焦枯，否则常会连续3—4天才全干。第二次上坑时，可在木炭火上加一些硫酸钾碳或（70—80％泥温加上20—30％碳粉，加工时炭即可混块），进行烘焙。这样的天麻色泽洁白，并可防虫蛀，以上所述的成品为明天麻，如不加硫不用硫酸浸，不用硫磺漂白的称皮天麻。

+   2. 改良加工法：为减少切片和水煮加工业造成的水被成分的损失，采用改良法。天麻采收后洗净，按大小分级，放在蒸笼内蒸透，再用文火烘焙。烘焙温度不得超过100℃。烘焙一天以后，取出晾开，回潮，使内部所含水分逐渐至表层。贮至七、八成干时，最好取出晒干，这种产品坚实，少空穴。如遇阴雨天气，烘焙的温度也应下降至60℃左右。
