# 糍米饼

原料
糯米粉1斤，白糖2两、豆沙馅7两、水5两、小苏打5分。

做法
1. 把五两水和小苏打倒进糯米面里和匀。
2. 把馅烧熟，用勺把面团摊平擀成二寸直径圆形饼坯，
烧成黄色，然后把豆沙馅放在米饼上，折成半圆形，撒上白糖即成。

成品
半圆形，中包豆沙馅，黄色，甜香馅。
