# 川筍

加工川筍要晒干和堆均可。以及时干燥为好。一般要用火烘干，烘时火力要适度大，以免焦黑。每天翻烘一次。待一半英雄出烘，用筐笼堆一层。续烘时，下层取新鲜丢弃，上层放半干的。到上层者部分全干后，再分上下层各堆一次，除尽泥土和须根，逐出全部的即为成品。未干的放在上层继续烘，如此每天翻烘，直到全部干燥为止。通常100千克鲜竹笋可供川筍约30—35斤。

# 玉竹

加工方法分三种：

+   1. 将鲜笋上层竖放在阴晒晒，晒到剖裂时（去掉部分水分后，表面有微波漂出，两个筏就软），用白塑光滑的塑料一包，以去其毛。土。将大身个分开，继续晒至表白或淡黄或紫色，晒到后即分小堆（4—5斤一堆），用手或木板挨揍，连续后晒，如此反复晒晒至根茎柔弱光亮无黑。大约七、八成干时，拿到1斤。加工前须用盐腌一遍，产品约为4—5斤鲜笋做出成品1斤。加工过程中应注意：（1）挖出后不可立即晒晒，因易破皮、折断；（2）加工前勿堆放，要勤换晾，以免霉变；（3）初晒时先轻后加压，避免如过甚成品早呈现红色。太阳晒色变黄，外皮粘稠；（4）遇雨要在室内风暖处用低温烘焙。

+   2. 将鲜笋先放在沸水内稍煮，或微蒸后上大气约10分钟，时间太少不妥。干后中间现白心。然后摊晒上晒干。也可边晒边送，这样成品较软，晒干后柔韧。

+   3. 将鲜玉竹直接晒干，但品质次。约7—8斤鲜货出成品1斤。

# 半夏

出土后，先放入清水浸透土，去皮。去皮方法：将半夏放入盛内，不可装满，浸入其中或水池中，用水泡浸，以能翻动为度，用木棒捣根稻草或玉米芯，插入盛内，上下搅动揉搓，用力不可过猛，并随冲进水深—将掉的外皮去掉，直至除尽外皮，显洁白如半夏为止。也
