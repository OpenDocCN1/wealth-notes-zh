# 1. 公制圆锥

# 2. 英氏锥度

英氏锥度在机械制造工业中应用较广，如车床主轴、尾座套筒锥度等。特别在电气工业中，英氏锥度应用的更多见，如钻头锥柄、铣刀锥柄等。常用其莫氏圆锥有 0、1、2、3、4、5 和 6 号 7 种。
英氏锥度的主要缺点是，不同的锥号锥角不同，给用工带来麻烦。英氏锥度数字越大圆锥直径也大。
