2. 把蒸糕用的木方板放在屉内，铺好悦布，先将蒸糕刚入一半，用旺火蒸熟，取出

3. 把糕块切成细长条。把枣泥搓成细长条，以适当的距离，缚在蒸好的黄糕上，再另取一半蒸糕倒在上面堆平，把芒红丝、瓜子仁撒在上面，放在蒸糕取出，拿下木板，揭去铺布，凉透切成象眼块即可。

庚皇秽冲
起发黍糕，面光滑平，餡酸适口。

# 乌梅糕

# 原料

绿豆粉5两、大米面5两、荠花籽仁葡萄干、青梅、乌梅、元肉、金橘各4钱、青红丝2钱、桂花2钱、白糖2两。

# 做法

+   1. 先把绿豆粉、大米面拌和一起上屉蒸熟，出屉后筛过罗。\n2. 把其它原料（青红丝、白糖除外），都切碎，拌入糕粉里。\n3. 把各种型的馅放在糕子上，先敷上青红丝、白糖，再把糕粉装入摸内，压实，经轻轻拍出来。置在盘内即可。

庚皇秽冲
色泽鲜艳，松软适口。

# 糯米兰花糕

# 原料

绿豆粉5两、大米面5两、豆沙馅3两、白糖2两、金橘、青梅、红菱子2钱、熟面粉2两、黎子叶4片。

# 做法

+   1. 把绿豆面、大米面用水平和好，做成小窝头式的生坯，上屉蒸熟，出屉后。\n2. 把刚透的窝头放在盆里，离凉开水撇成蒸透适宜的面团。\n3. 粘糕面上贴面粉，把面团搓成长条，辗成长方形片，把豆沙馅也搓成两根细条，放在两边，然后对卷起来。盖点水把缝捆住。
