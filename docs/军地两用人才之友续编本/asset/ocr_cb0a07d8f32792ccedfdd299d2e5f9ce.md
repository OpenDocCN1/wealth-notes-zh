# 图10 两圆弧内切

五等分：如图11d所示。作两互相垂直的直径A、B、C、D。在B点以R为半径作弧，交圆周于K、L，连接K、L，交AB于E。以E为圆心，以CE为半径作弧，交AB于F。再以C为圆心，以CF为半径作弧，交圆周于G，则CG即为五等分弧长，以CG弧长依次在圆周上截取H,J,I, K,C,G,I,J,H就是圆周上的五个等分点。
