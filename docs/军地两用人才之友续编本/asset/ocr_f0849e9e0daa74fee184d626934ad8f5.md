# 腌白菜

酱渍时，取小白菜菜（大白菜的一种种），先切去白菜菜唇，在根部割一个口，切口深度为5—6厘米，然后入缸。每100斤白菜下盐10斤，拌披黄18度或减3斤，放一层白菜撒一层盐，拌披废少许。倒缸时略轻放一些，以免挤伤菜根，使根基盐化。腌制半个月后取出进行行晾晒加工，把白菜的根部剪去4—6厘米，切口深度为5—6厘米，将白菜叶切下，留作冬菜或作腌料，留下后半部20厘米长的一段，封缸贮存，即为成品。成品色白，嫩脆。

# 腌黄瓜

黄瓜分为秋黄瓜和伏黄瓜两种，以秋秋黄瓜为好。秋黄瓜和伏黄瓜的腌制方法相同。

方法一：以每100斤黄瓜下盐15斤，拌披黄18度或减3斤，分层入缸，每天倒缸2次，开始倒缸要用手抬起缸，避免挤断，务必使盐充分溶解。分层时略加热，挖出盐水。盐糖48小时后取出进行机器加工，分为三类，分别色绿、完好的留作罐装黄瓜丝，中等质量比较直挺的留作黄瓜条或粉；残存较差的留作制盐菜用。挑选分类后分层入缸，依次一层黄瓜一层盐，每100斤黄瓜下盐20斤，不用加糖，直接封缸盖顶。

方法二：先将三类挑选，然后分别入缸，每100斤下盐37.5斤，拌披黄18度的或减3斤，放一层黄瓜撒一层盐，拌披废少许。每天倒缸2次，倒缸时要轻轻地放，使黄瓜盐溶解。腌制6天后改为每天倒缸一次，腌制一个月即可封缸贮存。成品脆嫩，嫩脆。

腌制黄瓜时要避免日晒，否则会由绿变黄，影响质量。
