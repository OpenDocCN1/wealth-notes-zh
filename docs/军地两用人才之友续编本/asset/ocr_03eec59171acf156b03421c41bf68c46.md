# （二）木制滚浆式水轮机

小型水电站采用木制水轮机有诸多优点，可以就地取材，节约钢材，节约资金；木制水轮机结构简单，群众很容易掌握，施工进度快，维护能力强。

# 1. 木制水轮机的转轮

转轮必需采用坚硬、变小、不易腐烂、没有扭曲的木料。东北地区一般采用柞木、桦木等。

转轮一般都是四轮叶的，它是由很多单叶片拼成的。制作时，先将两片单叶片拼成十字形叶片，见图16，然后将这些十字形叶片（一极是3～6个）错开一定角度再叠起来，它的中心部分就是轮毅，其周围的四个轮叶都有平滑的扭曲面，见图17。在轮叶的边缘上可钉上铁板条，以增加轮叶的强度。

在所有十字形叶片的中心都钻有圆孔，直径比水轮机主轴的直径大2毫米。在其周围还均匀分布有四个穿螺丝用的圆孔。在轮毅的上、下两端用圆板和根部假板夹起来，穿入相应的螺丝将它们紧固在一条轴上。装上表面水撞和轮毅上部的木盖板，做成了它的一个转轮。如果整个转轮外部再上防水层，这样在冬季冰块和冰凌的撞击下，也能延长转轮的寿命。
