# 多变式女童大衣

这套童大衣采用两种衣料裁制而成，一面选用紫色的呢料，一面配用针织的皮绒，适合5～6岁女童间换穿着。制作时剪皮绒应宽于紫色呢料，这样在以紫色呢料作面料穿着时，剪约皮绒缝为露出，起到装饰亲和稳边的作何；此外在领圈上装有拉链，既可装领帽子，又可装接帽子。这样一件衣服就有四种变化，故名它为多变式童大衣。
