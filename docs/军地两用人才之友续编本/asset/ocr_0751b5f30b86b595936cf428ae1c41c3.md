# 利用太阳能的设备

设计制造各种太阳能设备，是有效地利用太阳能的一种好方法。目前，国内外制造的太阳能设备种类繁多，如果我们掌握了太阳能的分布情况、它的转换原理和特点，我们就可以因地制宜、因陋就简，研制出适合于其它情情况的，科学实用而经济的太阳能设备。

# 1. 太阳灶

太阳能的基本原理是通过光—热转换装置累积得热，来加热食物或烘干，因此，结合型式主要看有没有太阳灶、聚光式太阳灶和太阳能蒸汽三锅。

箱式太阳灶就是前冴所说的热箱，不过在箱内安装了玻璃窗而已。灶体（即热箱箱体）可用木板或成，也可用钢条、竹篾、箱等制成。灶盖一般采用两层或三层单低的玻璃板制做，两层玻璃板之间有2厘米，灶的四壁和底部用棉花或木屑、麦秆、稻草等良好隔热，壁的内表面涂黑，并做微内不透气。必要时，可在箱盖上平<|start|>面反射镜，以加强收集太阳热的作用。
