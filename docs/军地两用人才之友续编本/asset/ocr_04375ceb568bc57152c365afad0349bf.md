# 2. 润滑液的选择

铰孔时，铰刀的后面与孔壁的摩擦很大，必须加润滑液，这样不但能减少摩擦，提高光洁度，而且可以散热，并防止因刀具磨损而使孔扩大。铰孔润滑液的选择见表 3。

# 表 3 铰孔润滑液的选择

| 工作件材料 | 适用的润滑液 |
| --- | --- |
| 雾染钢、工具钢、合金钢、钟钢 黄铜、铸铁、青铜 | 机油、菜籽油 |
|  | 不加润滑液用 |
| 紫铜 | 肥皂水 |
| 铝及铝合金 | 煤油、柴油、菜籽油 |
| 黄金及合金 | 鱼油、猪油、亚麻油 |
