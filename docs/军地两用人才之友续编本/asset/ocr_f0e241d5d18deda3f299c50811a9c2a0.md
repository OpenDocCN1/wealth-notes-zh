# 样冲

其主要用途是在工件表面已划出的线上传记号，习惯叫做“打样冲眼”。打样冲眼的目的，是为了避免以后好线的工件在以后的加工中界线模糊不清。

样冲用工具钢制成,尖端和棱角缝经淬火硬化,形状如图 2 所示。在打样冲时,样冲应斜着放上去,锤击前应直,这样打出的样冲眼才清晰(图 3)。
