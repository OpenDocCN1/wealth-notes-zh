# 全蝎

捕捉后，先将蝎子浸入淡清水或含少量盐分的水中，使其将肠内泥土吐出，淹死。然后取出，再放入盐锅内（每斤活蝎子放2—3两盐），煮沸后将瓶盖扣下如瓦盏形，即可捞出。再用清水洗通拍，摊在席上晒干（不可日晒，否则返盖霜发白），阴雨天可用微火烘干。加工时锅水需保持宽馀有余，慌忙要轻，不可揺拌翻动过多，以保持其完整无损。

# 刺猬皮

捕得刺猬后，将内脏取出（有些地区用刀以腹部割开，将肉制掉）。将皮用竹片撑开或用两手在木板上，剥起肌层，蘸酱取一层皮夹或石头，以防虫蛀。然后晒于通风处风干勿晒（不可晒），以免皮内脂肪烊化，发放走油，影響质重）。干后拍净即可。有地区方法不用竹片撑开，多侵入淡水中吸湿，故干后皮边向内曲成团块状。

# 蝎什蝎油
