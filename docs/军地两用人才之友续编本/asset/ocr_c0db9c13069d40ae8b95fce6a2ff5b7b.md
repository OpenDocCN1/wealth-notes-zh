# 刮削平面

刮削前必须显示刮削正准确的加工位置，否则从无下手。方法是待工作件表面清理干净，把涂布的显示剂薄而均匀地涂于标准平板上，然后进行对磨，取下观察，工作表面沾上色点的地方是突出部分，需要刮去。

如果刮削工作件较小，可夹在 entendido上，注意不要使其变形。中型、大型工作，可鑽在螺钉固定的木架上或放在地面上就地刮削。

刮削平面一般采用直线运动，刮刀推去时的较慢是切削，返回是空行程。在一般情况下，刮刀的 philosoph 角度为25～30°。新刮削的刀刃口较钝，角度可稍小，刮过相当间后，刀口变钝，角度可稍稍大，刮硬金属时角度大些。刮刀握法如图64。左手放在靠近刀头处，引起刮刀的方向随身形，右手握住刀柄，用力推刮刀时左手，左手由前向后移动，上身向前俯着，向前推时，上身要轻微旋转，以减轻臂力。如果使用长柄刮刀，可将刀柄端在腹部或大腿靠部。
