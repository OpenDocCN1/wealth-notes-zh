法叫研磨。研磨是最精密的加工方法之一。工件通过研磨之后，表面光洁度可达▽10以上；粗糙公差可控制在0.005～0.001毫米以内，可以获得比较规则的几何形状。
研磨在工作上、量具的生产和精密机器制造中应用很广。销轴在机器设备中的装配与修配中常常制造到的工具、量具的修配、内燃机的气阀及各种气、汽、液的阀门、汽封、轴封等，都需要研磨。

# 研磨原理

研磨过程是由微量微粒的机械切割作用和化学现象相结合完成的。研磨时，加工研具上装有研磨剂，发生在工件和研具之间。部分研磨剂被挤入工件里，本身形成一种没有规则的单个颗粒，产生切割作用。由于压力低，所产生的纹路极浅，并且研磨无一定方向，纹路又互相交义，磨料在工件表面上就变成一层很薄的金属。另一层由于研磨剂的作用，研磨剂在工件与金属表面之间化学反应——起一层氧化膜。研磨时就这薄膜被去掉，于是又重新起氧化作用，又经一层新的氧化膜，又被研掉。由于切割作用和氧化作用不断反复地进行，使工件逐渐达到要求。

# 研具、研磨剂及润滑液

研具是一种研磨时决定工件表面几何形状的标准工具。一般常用的有平合、圆盘等，但大部分都是根据需要特制的研磨器具，如尺寸不同的圆柱体、圆球体、环等。

研具的材料比工件材料软。常用的研具材料有灰铸铁、低碳钢、铜及铅等。

+   1. 灰铸铁：是最优良的研具材料，因为它含有石墨，耐磨性和润滑性好，研磨效率也高，适于研磨。

+   2. 低碳钢：在研磨细缝或小孔（一般为 8 毫米以下）时，因灰铸铁磨损不尽，杂质亦造成孔，所以用低碳钢做研具。

+   3. 铜：在研磨要求大时，为了加快研磨速度，提高效率，应该用铜（紫铜或黄铜）研具大。但用铜做研具得不到很好的光洁度，所以用它研后，还应用钟铁类具精研。
