# 影响电弧接地稳定的因素

电弧在工作时是否稳定是影响焊接质量的因素之一.造成电弧不 稳定的原因有几类, 现量是关系；一般酸性焊条的熔敷性能比碱性低 氢型焊条好,酸性焊条可用交流电源或直流电源,而碱性焊条因熔渣 药皮内含有多种氧化物,故用交流电源时,电弧不易稳,必须要用直流 电源. 另外一种是弧长的变化时就会影响温度而弧长变化,电弧也不稳定. 与电焊的型式有关,交流电因电压的大小和电流的方向都在 不断变化,所以对电弧的稳定性不利,而直流电的方向和大小总能 保持不变的,所以电弧比较稳定.

磁吹的影响, 当采用直流电弧焊接时,有时会出现一定方向 性的电弧偏斜,称为磁吹.产生磁吹的原因很多,如气体的壅动 或稀释等.但最常见的原因是电弧受附近强磁场的作用而造成的. 偏移方向与焊接电流在工件上运动的方向有关.由于一般电焊线 与工具只有一点相连,而电流沿着路径经由焊接工件 经过电弧从工件上焊接处经过焊丝反向回电流.由于受到附近铁工作 上的电流产生的磁场的用.电弧就总是与电流流向相反的方向偏斜 (如图2.).了解这一情况,我们就可以采取一定措施来克服这种
