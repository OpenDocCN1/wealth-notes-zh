# 大丽花

大丽花是世界名花之一，现名各地广泛为栽培，被誉为花卉中的宠儿。我国栽培亦甚普遍，深受人们喜爱。它花期长，花型美，色彩鲜艳，品种繁多。无论花朵、花色、花冠、花瓣的变化都极大，而且易于组盆，适合地栽与盆栽，又是切花的好原料。目前世界约三万多种，我国现有七百余种，大部在云南、江苏等地系系引种。

大丽花原产于墨西哥及危地马拉等海拔一千五百米以上的高原上。它既不耐寒又忌酷暑，不耐早毕怕涝，喜光喜肥，故应选排水方便、土壤疏松、通风良好的间行排水的地方栽培。要求夏季气温较低，<|message|>在15℃以上。常年有四个月平均最低温度的休眠期。在5—30℃之间均能适应，但以8—25℃生长最佳。

大丽花以分球、分根或扦插繁殖，最为简便。最常用。一种是春季栽植前，取肥壮无病块茎对分为二。另一种是栽植前一个月，先把块根假植在准备好的木箱或瓦盆的沙土内，根须露出土外，出芽后再将一部分之大丽花发芽根部发芽，切分块必须具有一芽或芽眼，并带部分老组织。盆栽大丽花大部大都是用大块球，带根长出的芽有10厘米左右时，从基部剪下，插入粗沙中，放在阴处，保持在18℃左右，有助于萌芽。第一个月可产生新根，每次水面稍见水，每次水面稍见水后，须后... 直径12厘米的小盆中，一星期后可定植在25—30厘米的大盆内。如欲多次播种，需... 两片叶而削弱，这两片叶子于可先让其发芽后再发芽，可用扦插制苗。

栽植大丽花苗应根据用途选不同品种。盆栽适合节日用花，选择壮之大花种。地栽适合庭院丛植，造植阵中带，花系中型为宜。切花是剪花时，花剪花头，插入桶水中养，选分枝强，花小而稍长，茎干细而挺直之种。

地栽大丽花应选地势较高、向阳、通风、排水良好的位置。挖坑施入鸡粪、鱼肥及腐熟为基肥，随穴于二而，三配套防治病虫。勿使根系碰肥颗粒，少施氮肥，否则枝叶茂盛而花小。繁殖时间绝大部分是在四月初进行。盆栽只留壮壮根一芽，其余从基部剪除，并及时修剪去侧芽，令其健粥生长。从小盆倒入大盆定植要带土球，不可裸根。大盆
