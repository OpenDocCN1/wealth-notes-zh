# 双片袖直裙

这种裙型式款式465, 庄严朴实, 特别适宜中年以上妇女穿着。前裙片正面有一条双面折褶（俗称明褶），左右两边的两只只是中间折迭的单褶（欲称补褶）。折褶是 从上到下直条形的，下摆比肩部宽2分，上半部腰部缝8分处封存，下半部松散。裙子收有折褶, 不但使款式美观, 兼有变化, 特点是使跨步时松散行走方便, 停步时成流线型直挂。直裙裁剪简便, 宜用较为厚实的衣料制作, 如麻呢、中长羊绒等。
