# 7. 安全

沼气在生产和使用上必须注意以下几点。

+   ①防止爆炸。大量沼气与一定量的空气混合后，遇火就会爆炸。新投料的沼气池，因为原来密室有空气，产生沼气后，此种混合气体是极易爆炸气体，所以千万不能用火上检查管道口气，最好放空一段时期，排净气体，用肥皂水把池子离地面几米以外方可点火。
②防止烧伤。开炉时要先点火后开气。如果先开气，沼气很快充满炉膛和炉子附近的空气，这时一点火，火焰就会猛然窜起，很容易
