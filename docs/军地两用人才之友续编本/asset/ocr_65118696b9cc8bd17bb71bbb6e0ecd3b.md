# 刮 削

工件经过机械加工后，总会有一些凸出的痕迹，还不到理想的光洁度要求。尤其是把平面结合处经常移动、转动以及经常与测量面要  求气密的地方，如果不消除这些凸凹部分就会大大地增加滑动或转动 的阻力，加快磨损，降低寿命。为消除这些缺陷，就要使用刮工具刮刀在工作表面上刮掉一层极薄的金属，使工件表面达到技术要求，这 就叫做刮削。

通过刮削还可以来调整轴承的中心线；通过刮削机件摩擦表面， 采取调整制造的间隙等等。因此刮削是钳工工作中常见的一项且又 却很重要的工作，应该熟练掌握。
