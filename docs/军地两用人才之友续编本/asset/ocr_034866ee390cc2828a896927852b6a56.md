# 3. 污泥浓度

经过发酵，消化污泥沉渣分离出来。污泥的浓度是这样确定的，以3000升/分的离心机转5分钟，离心分离后的沉淀物与原物体之比（％）即为污泥浓度。消化污泥中主要是腐殖，其能均可发酵物质，则这些污泥的浓度越高，就越能促进发酵的发酵，因此，沼气发酵适于处理浓度高的废水。但若无良好的搅拌，污泥浓度不宜过高，因为污泥沉淀在底部，反而数能发酵的有效的
