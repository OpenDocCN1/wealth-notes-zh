# ①幼龄茶树的定型修剪；目的是促进分枝，培养骨架，为盛产期初次定型打下基础。

第一次定型修剪宜在2足龄时进行（南茶茶区茶树生长量大的可视具体情况提前进行），即苗圃出土后的第2年至第3年春进行，修剪高度以离地15～20厘米为适当。第二次定型修剪在第一次定型修剪后一年早春进行，定剪高度为离地1～1.2米。第三次定型修剪在第二次后后一年早春进行，修剪高度为离地1.4～1.5米。

# ②丰产树时期的轻修剪和深修剪。目的是于保持结实的树势，增密生产枝，刺激新芽萌发。轻修剪每年或隔年进行一次。轻修剪采用离剪，每次修剪在原芽上提高1～1.5寸，掌握"茶梢红杠提一节，秋梢黄叶一扫光"的原则，当轻修剪进行4～5年后，树型趋于密结增高，茶树萌发力下降，生长势减弱，此时就采用有薄剪（单边、双边）进行一次深修剪，修剪深度以剪去老叶为原则，一般在树冠上剪去3～5寸，以后每隔3至5年系统修剪一次，这样轻修剪和深修剪交替进行，可保持壮年茶树的旺盛生产力，获得高产。

轻修剪和深修剪的时间可在早春或茶树谢花后进行，南部茶区也可秋茶采摘后进行。
