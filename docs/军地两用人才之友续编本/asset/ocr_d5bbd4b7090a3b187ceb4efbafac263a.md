# 男童折袖短袖套装

此套装适合 5 ~ 6 岁男孩在夏季穿着。式样是：上衣是米黄色小翻领两用衫，胸前作斜直形分割，并缝有五道线的折袖和斜制的路肩条，领边和袖口边选用彩线缝制"蝴蝶花"针绣饰，下配白色细绸条布短裤，腰间用松紧带。整套服装。上、下面色和裤裙一体简单。说明：左右两边前衣片各有五只折袖，每只折袖大 0.5寸，连同裤底共需发出 3 寸。
