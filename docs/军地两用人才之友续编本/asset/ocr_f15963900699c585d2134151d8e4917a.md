# 运条

使焊条沿焊缝按不同方法移动，以形成焊道和清除渣滓叫做运条；焊条由电弧气孔在焊件上形成一个熔化金属的凹陷即熔池。运条动作的正确与否，对于焊道形成的好坏有密切的关系。运条的方向有搭接运条向进条和横向运条两种。就向运条是焊条沿焊缝直线向前移动或后退移动。一般焊条作业应用此运条方法焊接。在焊接较厚的焊件，为ield使焊缝具有一定的宽度，采用横向运条，就是把焊条沿焊缝宽度方向来回摆动向前移动，其摆动方法见图9。
