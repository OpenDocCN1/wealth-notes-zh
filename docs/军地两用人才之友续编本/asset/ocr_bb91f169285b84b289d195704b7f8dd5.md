生物供给鱼类：养蚕（得蚕）; 捉蚯蚓、蝸蚘等，直接喂鱼。

# 三是截。野草藻、清水藻、狐藻等。

# 四是引。引入城镇生活污水、食品厂、淀粉厂、酒厂、豆制品厂、屠宰厂的废水。

# 五是制。一种是将青饲料打碎，或用粗饲料粉碎，经微生物分解发酵，制成微生物饲料喂鱼；另一种是将青饲料、粗饲料、精饲料、药物饲料比较适合配合，制成颗粒饲料。人工制饲料中，还可加入药物，防治鱼病。

# （3）饲料的加工

颗粒饲料的制造：颗粒饲料的原料，粗饲料（有秸秆、黄豆秆、麦草秆、油菜秆、芝麻秆、高粱秆、玉米秆、花生成、甘薯藤、淡黄、牛粪、各种菜叶、树叶等）；精饲料（有豆饼、棉饼、米糠、麸皮、鱼粉、麦麸、酒糟、下脚面、麦类、大麦、稻谷、玉米等）；加上鱼粉、蛋壳粉、鲜鱼粉和食盐、土霉素，先将各种粗料混合粉碎成粉，加以碱化，经微生物发酵发酵，然后按一定比例，配上精料和添加物，混合拌匀，用颗粒饲料机（碾衣机改制肉机也可）制成颗粒，干燥后喂鱼。

# 2. 肥料

养鱼池所用的肥料有两大类，有机肥和无机肥。

有机肥主要以人和牲畜的粪尿、绿肥。

无机肥包括

氮肥类—硫酸铵、硝酸铵、氯化铵、硝酸铵钙、硫酸铵镁、硫酸镁等，这些肥料不可与石灰、草木灰等碱性肥料混合用，否则铵、氨脱氨要损失。
