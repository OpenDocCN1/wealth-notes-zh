# 1. 饲料

解决鱼饲料问题是提高鱼产量的重要途径。养鱼有“粗养”、“精养”之分。粗养，是主要依靠水中天然饵料和养鱼，鱼产量低，而且极易不稳定。精养，是经常配合投饵，能歉取较高的产量。现在养殖技术提高后，许多工厂化立体养鱼呈密养、轮养、轮养，即多种鱼混养在同一水体中，轮捕轮放，供养鱼的密度大大提高。这样就要求增加饲料，否则会出现许多大头、小身、肉薄的“大头鱼”，鱼产量的提高仍然很低。

# (1) 饲料的种类

鱼的饲料有天然饲料、人人工饲料两类。

天然饲料有，浮游植物、浮游动物、底栖动物、水生植物、生物尸体的碎屑及其上面的细菌。

人工饲料，按其性质分，有植物性饲料、动物性饲料、矿物性饲料。其加工分，有颗粒料、粗粉料、精饲料、精化饲料、颗粒饲料。

# 植物性饲料。

一是农产品及其副品，如黄豆做成的豆饼、二是食盐工厂的副产品及糖类制品，如米糠、麦麸、茶籽粕、菜籽粕、棉籽粕、豆渣、酒糟、米糠、麸皮、薯渣等。三是水生和陆生植物，水生植物有苦草、小浮萍、紫背浮萍、水浮莲、凤眼莲、水金莲、马来眼子菜、黄丝草、轮叶黑藻等。陆生植物有青菜、狗尾草、紫花、紫菀、紫苜蓿、早熟禾种子、豆类植物的茎、叶、海藻类植物的剪青苔、蒲公英、各种菠菜叶和瓜叶、瓜蔓，还有松树叶、杨树叶、柳树叶、榆树叶、杨树叶等，加工后也可喂。

动物性饲料，包括鱼、虾、蚯、蝇蛆、蝇蛹、蚯蚓、枝角类动物（如红虫）、蚕蛹、鱼粉等。
