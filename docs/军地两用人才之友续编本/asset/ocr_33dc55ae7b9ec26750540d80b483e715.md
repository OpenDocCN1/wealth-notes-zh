# 三色糕

原 料
熟面粉7两、鸡蛋1斤、白糖1斤、豆沙馅5两、青梅丝2钱、
葡萄干2钱、瓜子仁1钱、食用色素适量。

# 做法

+   1. 将鸡蛋黄液、黄分另打在两个盆内油成糊。之后，合在一起，加入白糖、熟面粉搅匀。
2. 把豆沙馅入蒸笼内水柜内一薄蒸熟取出。
3. 把豆沙馅切成与蒸糕同样大的片，放在蒸糕上面。
4. 把另一半蒸糕加点色素，调成玫瑰色，倒入豆沙馅上面，再撒上青梅丝、葡萄干、瓜子仁，放在锅上蒸熟取出。晾凉后切成方块。

原香味柔
焦黄红三色分明，整齐不碎，甜脆香甜。
