# 女足发式的变化

女发的梳理变化相当сами, 产生的发式也很多。它的变化主要体现在额面、轮廓线、卷曲花纹等方面。

# 顶部头样的变化

处理顶部头发，对应脸型很关键；即从顶部带前面额发际线的部分，提起一块呈长方的部位头发，按额高额，修剪成各种式样。煞后根据式样要求单盘丝的部位而定型，分别形成刘海、单花、双花、莲花等几种不同变化。

# （一）刘海。顶部前面头发披放在额前，可修剪成平直形或弧形，长短可根据额角高低、宽窄来决定。刘海可稀可密，也可以剪成或成花瓣形（见图27）。
