# 铆钉尺寸计算

为保证铆接质量，铆钉尺寸要经过计算来确定。

+   1. 铆钉直径的确定。铆钉多受剪切力作用，因此必须根据承受剪切应力所需要的强度来决定直径。一般图纸上都有标注，应按照执行。如没有标注时，可按板厚的1.8倍计算。然后对照国家铆钉标准进行选用。

+   2. 铆钉长度的确定。见图74，铆钉过长或过短都会造成铆接废品。半圆头铆钉L = 1.12s + 1.4d。对设计上有特殊要求的，应通过试铆来确定。
