# 中式装袖对襟旗袍

旗袍是我国的传统服装，富有民族特色，造型优美，能充分显露女性
的形体曲线，且用料较省，深受广大妇女的喜爱。传统的旗袍都系紧袖式
的，这种旗袍的设计系中西结合，取二者之长点，即有肩缝，前后腰部收
省，这样，穿着时更能贴体合身，富有立体感、线条化美。这种旗袍款式较长，领具式钮扣，并设有盘领相，可作为礼服之用，衣服可选用质朴不
规则的花纹或素色材料加适当的绣花。
