# 女童圆领短裙衫

这种裙装适合6～7岁女童穿着式样。是圆弧形的领口靠后开擖，裙袖，前衣片作圆弧形分前，下面配三接式皿胸裙，裙围逐渐放宽，上口收有省胸，下口形成波浪，穿在身上宽敞蓬松，显得分外轻快活泼。宜用柔色或印花的轻薄柔软衣料裁制，如涤棉布、尼龙绢、纯化纤织物等等等。
