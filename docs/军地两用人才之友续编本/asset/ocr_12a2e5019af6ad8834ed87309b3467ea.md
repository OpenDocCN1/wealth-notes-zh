# 5. 太阳能发动机

人早已期望着用太阳能来开动机器，现在已经制成了太阳能蒸汽锅炉和蒸汽机、太阳能热气机等。太阳能热气机，就是把集聚的太阳能加到热热炉中的水或其他工作液体，产生蒸汽，推动活塞或齿轮运转。
