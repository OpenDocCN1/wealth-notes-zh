# 黄麻栽培

黄麻是重要的经济作物。它的纤维是麻纺工业的主要原料，是对医药用和科研试验证实要用药。黄麻种子含油14%，可作工业、医药用油。麻可作造纸原料、板纸和板纸之用等。
种子处理 播种前半个月左右将已选好的种子晒1~2天，以提高种子的发芽率和发芽率。为了避免种子种菜，用药剂拌种（100万种子用3~5两力生或药剂力敌）。拌药后的种子需在种室内，使药性渗透到种子里，杀死病菌，以减少病害。
整地 黄麻栽培技术，大根入土壤，吸取或吸水力强，一般以土层深厚、肥沃、排水良好的沙质为好，过砂或瘠薄的土质不宜栽黄麻。种黄麻的地势常要近水源，这样便于灌溉。由于黄麻种子小，幼苗须土力强，因此必须施底肥以肥料，要求作到深耕、土细、平整，肥料“施”“高、中高”。中高形成，两边低，不要求成“高畦法”，以免雨后积水影响出苗。同时做到草根尽，底肥足，三沟通，排水通畅。如果整地不符合要求，底肥施放出苗不齐、生长不良。深耕不仅增加保水肥力，而且能促进根系深扎，一般要求深耕5~6寸。如用冬闲田施肥，要在冬季进行一次深耕，使土壤在冬季风化，增加土壤肥效。到播种前，耙耕1次，把地整好。晒匾以种黄麻进行明确，一一般6~7尺为宜，沟宽5尺左右，沟深5~6寸，但地势低洼的要略深些，海渠深些，以利排水。在整地前最好撒8%六六六粉2~3斤，拌细土撒匀，然后后立即耙作畦，将药土翻入土中，以杀灭地下害虫。
