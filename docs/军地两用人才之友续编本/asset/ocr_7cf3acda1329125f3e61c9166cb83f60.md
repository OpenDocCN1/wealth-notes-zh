# 水电站的机组部分

# （一）水轮机的类型及系列

水轮机是水电站的主要机械设备。现在，我国已自己设计、制造了各种类型的电站水轮机，并逐步完善了中小型水轮机产品系列。

# 1. 水轮机的类型

水轮机按其利用水能的特点来分，可分为反击式水轮机和冲击式水轮机两大类。

反击式水轮机主要利用水流的压力能（即转轮前后压力差所形成的压力差）推动转轮。压力水经喷嘴导叶后，将压力传递给叶片，推动了转轮，与此同时，水流的压力降低，由尾水管流出。前而装有的轴流定浆式和轴流混流式水轮机都属于这种类型。

冲击式水轮机主要利用水流的动能。水流经喷嘴中喷出时，具有冲击的能力。冲击转轮转动。轴流定浆式（旋浆式）水轮机，其特点是水流沿轴向通过水轮机的转轮，叶叶固定在转轮的轮毂上，转轮的构造比较简单，如图11所示。

混流式转轮的特点是水流流经转轮时，先轴向流入，随即旋转成斜向，最后以平行于主轴的方向流出，故称混流式。转轮由上环、下环和压盖片组成。转轮的结构见图12。

贯流式是一种特殊的低水头水轮机。它实际上也是轴流式的一种。
