# 儿童的发式

儿童比较流行的，适合儿童特点的发式，有以下几种。

# 男童发式

（一）超发型。基本操作方法是：四周用手推光，顶部留发较长，中间略高，逐渐向四周低下，两侧及后脑轮廓均呈弧形，额际部分头发中间较长，向额角两边及顶部逐渐低下。由于眉短，发干基本竖起而略向前倾，显得活泼、自然。

在梳理时，如果儿童比较安静、讲话，对额际部分头发，可用剪刀修剪。

年岁较大的少年儿童，一面造型梳成顶部凸起，亦可将顶部两侧及后脑边缘部分的头发略微留长一些，使其前后部丰盈，后脑部放宽，形成扁平头，不应该有偏角。这类发型能使头部显得开阔一些。

（二）长发式。有两种，一种实际上相当于成人的短发，但是额际线较高，顶部<|message|> 发较长，向额角前时要求略微垂下一点。头发的线条柔和，被剪的长度不短于眉毛，像一枚圆形的小花瓣覆盖在顶部，颌部正是花瓣的尖端，罩上也很好看。这些发式适合四岁以上到童年时期。另一式相对少见些，适合较大的儿童梳理。留发长度也相当与成人的短发式，但又比前一种发式略短一些。特点是头发蓬松，不贴着头皮，发干梳直而竖立，并略带前倾。操作时，先推剪，两个高处与耳相连，然后后脑上缘线条向上整体忽高，轮廓线向两侧在面上以上，后脑部在枕后凸起以上，置于顶部前发束竖起来，自四周至顶部都保持弧形。推剪完毕，不必经过梳理，发梳即可自然形成。

（三）推光式。与成人推光式操作一样，但不一定强调齐发根全部推剪光净，可以稍微留一些极短发丝。儿童在夏天，为了头部凉爽，便于梳理头发和保持 hygiene，可以推成这种式样。

# 女童发式

一般只有直发、东发（不包括蓬发）两类。直发类可分童花式、狐狸式、平垂式等几种。童花式是基本上保持自然生长的状态，头发发向前额两侧圈下，额前两角之间眉毛部位以下整齐地剪齐。眉
