# 3. 焊接电流的调节

在BX1型焊机中，焊接电流的调节可以通过两种方式： ① 将活动铁芯从口字形铁芯中拉出或推入来调节焊接电流。 ② 通过改变二次线圈与电抗线圈的圈数来调节焊接电流的调节。

# BX3（BK）型交流弧焊机（BK为旧型号）的简要介绍

BX3型交流弧焊机属动圈式，常见的有BX3-300和BX3-500，BX3-300适用于中厚钢结构的焊接，使用焊条直径为2～7毫米，BX3-500适用于厚钢板的焊接，使用焊条直径为4～8毫米。
