# 服装裁剪制图符号

| 符 号 | 名 称 | 说 明 |
|---|---|---|
| — | 辅助线 | 裁剪制图时首先划出的基本组织线 |
| — | 轮廓线 | 是衣片的实际轮廓线，在正式裁剪衣片时，必须另外放缝线 |
| ~~~ | 等分线 | 将一区段分成相等的若干小段 |
| —— —— | 连折线 | 表示衣片对折的线，系衣料上下层相连却不可裁开的线条，如后衣片的背中线等 |
| — — — — | 翻驳线 | 表示衣片的翻折，如前衣片的连挂驳取头、翻驳线等 |
| 7---7 | 注目线 | 用以表示这一部位的尺寸 |
| — — — — — | 影示线 | 裁剪时，常以先裁好的衣片与待裁的衣片互相重迭，作为参考，对重迭的部分用影示线表示 |
| /////
/// | 折 衩 | 根据体型需要作折衩部分，如裤子前片两只折衩，身材村后衣片的两只折衩等 |
