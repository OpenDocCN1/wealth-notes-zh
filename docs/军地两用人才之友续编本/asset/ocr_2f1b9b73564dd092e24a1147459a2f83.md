# AXI-500型振荡发电机

这种振荡发电机属于三相制复复式激磁，它与AX-320型有所不同。它有四个主磁极为主性五极交替安排，磁极铁芯截面处有缺口，磁极极掌中央部朝向有四槽，以减少辅助电刷的火花。电刷不能移动。为了改变换向顺序，设有四个换向组。四个公换磁组分布在四个主磁极上，两个串联绕组（与电阻串联）。另分别在两个主磁极上，其中一个串联绕组中中间抽头，串联绕组产生的磁通与主磁极相反，其内部接线如图8所示。
