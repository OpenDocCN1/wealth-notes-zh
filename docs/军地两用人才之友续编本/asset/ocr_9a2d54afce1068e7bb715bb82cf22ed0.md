# 图64 锉刀手握姿势

以减少疲劳。

刮削方向应与工件成45°角。到边沿处，为过多避免损坏刀刃和将边沿处刮成或形，可将工件端靠放一挡件，使刀刃不滑出去。

粗刮后，因刀刃来硬，用力大，因此刀迹不可重叠，否则高低会相差很多。必要时可采用分区刮法，即根据平面高低不相等情况，划分为若干区，刮不同刀区，可很快使平面平整。

粗刮以后，根据显示情况再进行细刮。这时显示剂可以蓝出，有三种现象没有颜色的 cerca点。亮点的地处，表示最高，显示出黑色点的当地，表面最高；没有沾色的地处最显示出刮后白光，表面最低。细刮时，要用短划线（即刀痕较短不连续），多刮亮点处，不刮黑点处，以增加点子数目，每刮一遍，要变换一下方向，使其形成45°～60°姫纹线。如果发现表面高低相差太大，可用粗刮法重新刮平，再重新刮暗，直到合乎要求为止。

为进一步提高表面质量，可进行精刮。精刮时应使用小刮刀，刀痕一般在垂直左右。刮削时要采用“点刮”，使大点破碎，这样大点子变成小点子，中点子也变成小点子，直到达到要求为止。

经刮过表面不应有刮伤或刀痕，表面精度可用水平仪和千分表检验。
