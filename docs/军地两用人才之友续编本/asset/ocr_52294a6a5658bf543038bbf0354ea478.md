# 图 26 未熔透

产生未熔透的主要原因

+   1. 对口不正确。如坡度太大，对口间隙太小或者由于运条不当使熔化金属及熔渣层之间或<|message|> 本金属边缘及根部的熔化。 2. 由于熔接电弧小了，熔接速度快了，焊条直径大，金属不能充分熔化而产生未熔透。

修正的方法

+   1. 如有可能，可以从焊缝背面进行补焊。 2. 将焊缝未熔透处焊肉内铲掉重焊。

# 焊缝上气孔
