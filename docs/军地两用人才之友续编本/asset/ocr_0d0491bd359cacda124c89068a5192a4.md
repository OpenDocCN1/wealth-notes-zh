# 2. 乙炔发生器（通常称电石桶）

乙炔发生器的种类很多，按所得到的压力力不同可分为：低压电石桶（其容积为小于 0.07 公斤/立方厘米以下的，中压电石桶（其压力为 0.07～1.05公斤/平方厘米）一种最常用的电石桶是 Q 3 — 1 型的 1 立方米/小时排水式的中压电石桶，这种电石桶结构如图29所示。这种电石桶各部件均用钢板焊接而成，由外壳、罐盖、储气筒及回火防止器等四个主要部件组成。还有手推式小车，移动方便。
