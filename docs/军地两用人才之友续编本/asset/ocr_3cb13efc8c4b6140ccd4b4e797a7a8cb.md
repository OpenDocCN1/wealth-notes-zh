# 图4 尾轮式对风装置

对风装置。常用的对风装置有两种，一种是尾轮式，一种是尾车式。

尾轮式对风装置如图4所示，由尾轮和尾轮组件组成。尾轮是一根钢管，用圆形或椭圆形设立，其转移架用花兰丝连接。尾轮是一块形状椭板，装在支架的后面。梯形钢板应这样装配，其长边应装在垂直于尾桁的方向上，这样所得到的机轮反转力较大。尾轮对风向起到的风向转动的8~10%，当风向和风向转轮正面吹来的时候，尾轮为平平风向位置，受风面积最小，当风向改变，从某个角度吹来时，尾轮的受风面积增大，作用其上的风力增大，推动整个发电机组中立轴转动，
