# 主要花卉的栽培技术

# 君子兰

君子兰又名侧叶石蒜、胖叶石蒜、达标兰。
多年生常绿草本花卉。株高40~50厘米。根肉质。叶革质簇生成帚状基，叶由基部抽生，两侧对称，革质、全绿，为狭长的剑形叶，叶尖圆砲，深绿色而有光泽。花茎从中抽生，直立，花梗粗壮，肥厚而多汁，长约30~40厘米，半球形花序，每序着生小花15~30朵，可多达40朵以上，萼一花外有覆瓦状花片，两性花，花冠具短喙漏斗形，雄蕊6枚，雌蕊长于雄蕊，柱头3裂，子房下位，球形，果实为浆果，成熟时宽紫色。
