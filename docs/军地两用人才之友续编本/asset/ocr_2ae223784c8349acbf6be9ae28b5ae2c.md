甜面酱35斤、夏季用面酱28斤、黄酱7斤。每 天打孔4次，打孔要均匀。冬季酱渍7天，夏季酱渍3—4天，酱渍后即可封罐贮存，食用时再按比例掺入花生米。

# （三）中各生豆

原料为蓝酱花67％，黄瓜条10％，小料于10％，花生米3％。先将蓝酱花、黄瓜条、小料按比例倒入瓶罐内，冬季桶两水，夏季桶一水。盐水后放人布袋经渗水6—7小时，将水控净入瓶酱渍，用黄酱25斤、蓝酱11斤。每天打孔4次，打孔要均匀。冬季酱渍7天左右，夏季酱渍3—4天。酱渍后即可封罐贮存，食用时按比例掺入花生米。

# 酱白瓜

选个大、肉厚、嫩脆、稍带绿色的白瓜，以每条重1—3斤为宜。每100斤白瓜加盐8斤入缸，拌透專18度的清水3斤，入缸3小时必须翻动一次，以防酸烂，每天翻缸2次，及加盐后再翻动一次须够热，放盐最好在冷入缸48小时后出缸，在缸边缘用竹签到缸一个眼放气。放气以后瓶盖略启，以去掉白瓜的青味和水分，阳光足时，晒6—7小时。如果天不助好或阴天，可将白瓜缸下放晒至内，压紧瓜内的空气和渣液，晾晒一天微潮即可。每次晒后须晒，每100斤一晒过的白瓜须加75斤。每 天打孔3—4次，夏季7天，将白瓜酱渍后放置阴凉处静置，静置5—6小时，翻倒一次，第二天后再入缸，每100斤一白瓜须酱75斤。每天打孔4次，打孔均匀，酱渍20天即可成褐黄色，有光泽、口味的酱白瓜。

# 甜酱黄瓜

将黄瓜入红缸水，冬季放三水，夏季放两水，注意换水时轻轻摇动，水要控净入红缸。每100斤黄瓜需用红酱水2—3天，每天打孔3—4次，再将成酱每隔向周，夏季酱时要换水把黄酱渗出，——避免发钝。每100斤酱需用冬季用甜面酱75斤，夏季用甜面酱55斤、黄酱20斤，每天打孔1次，冬季酱渍20天，夏季10天即可成颜色墨绿、味香甜、酱味浓、微辣的甜酱黄瓜。
