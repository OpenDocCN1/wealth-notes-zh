# ③有性繁殖，又称种子繁殖，就是利用种子繁殖后代。

一般繁殖前都先收条采果，生产通常常采用茶籽直播，但为了加强苗木管理，也可在播前进行播种育苗。
育苗地的选择同于扦插圃，面积先经深翻30厘米表土并耙下基肥，施肥量120~140厘米，高10~15厘米，畦沟宽25~30厘米。秋冬播在11~12月（次年春），春播在2~3月。播种方式一般有两种：一是在畦上开播种条窝，行距20厘米，沟宽6~8厘米，深4~5厘米，将茶籽均匀撒播在沟内；另一种是开穴孔穴，穴距20×15厘米，穴深4~5厘米，每穴播种4~6粒。播种后稍加覆土，厚3~4厘米，在播种行上取桔堆覆盖一层稻草，使其土保持湿度，以利幼苗出土。但当茶苗突出土时，要及时把堆草撤去，每亩育苗种量约200克。育苗期间要常除杂草松土，及时追肥，抗旱防病防治病虫害等防治工作。
种植
（1）茶园选址和整地 茶叶喜欢肥沃性土壤（PH值在4.0~6.5之间），土壤深厚，自然落水的缓坡地。一般建议在5~30度的坡土上地都可作为建茶园的基地。基地选定后，即应 survey 茶区地形、道路、排水系统、防 Shui 等和苗木分布等规划方案。茶区开垦地形要规则分布，每块田作为若干片、块，每块面积以10亩左右为宜。道路的布置视区，块的体情况而定，而面积大的区与面积小的区之间设干沟，并与大沟连通，块的块之间设支沟，片与片之间设没有设包尾，排水系统要布设合理、地形因素等，地势比较平、时适当布置，并注意与治山治水相结合，坡度较大的坡度等高线布设茶行，或作成梯级，以利排水。防风林设在茶园地、片的北面或西、北的山脊或坡肩处，梯带应有1~2丈宽，树种以乔木、灌木相结合，常绿树和落叶树相结合为原则。

（2）园圃定植和施肥 种植后应施肥 每块区应施肥40~50厘米，除净杂草、竹笋、树根、石头等。在深翻时结合施下基肥，可利用当地取材，苗圃熟堆肥每亩50~100担，均勻撒播土面，结合施把肥撒入土中。或在种植行下适当施肥约100~200斤，过磷酸钙30~40斤。种植方式：现在主要是提倡条状茶采。有一条、二条，也有多达四、五条的，每种种植模式大致的几不种，多为几种，种的方式
