# ① 较圆柱孔

首先要根据是较通孔还是不通孔、以及材料的韧性和硬度、适程长度不同的选配较刀。较硬材料较不通孔用短型较刀的较刀，较硬材料较通孔用长型较刀的较刀。
其切、动定金后验后钻孔，再进行较孔。手较时，两手用力要均匀，每分钟约20～30转。较孔时较刀不能倒转，否则会使较住切屑，使较刀被刚被锁住，影响工件质量。在较孔过程中，如果较刀旋转不动，则说明切屑卡住了较刀，或者遇到了硬点，这时要把较刀小心抽出，不能用力继续旋转，否则会使较刀折断。较孔时应不断输送润滑液，较完后应先反较转退出。

# ② 较圆锥孔

较圆锥孔时，用圆锥较刀。尺寸较小的圆锥孔可按小钻直径钻孔，然后用锥形较刀较制。对于较深圆锥孔，为了节省钻孔量，较孔先钻出较孔孔（图51），然后再用粗、中、细一组较刀，依次较制。操作与较圆柱孔类似。

较孔常见的质量问题，主要是光洁度达不到要求，或孔径成多边形，圆锥孔及锥度。其原因无非是较刀刃部年前过大，操作者手法生疏，进刀量太大或操作时两手用力不均等，这些原因只要在工作中加以注意即可克服。

# 攻丝与套丝

用丝锥切制外螺纹称为攻丝，用板牙切制内螺纹称为套丝。一般情况这两种方法所切制的螺纹形为三角形的螺纹。三角形螺纹应用最广，最常见，并且已经标准化了。三角形螺纹可以用机床加工（已在车工基础知识作了介绍）。机床加工不能完全代替手工操作，因此钳工
