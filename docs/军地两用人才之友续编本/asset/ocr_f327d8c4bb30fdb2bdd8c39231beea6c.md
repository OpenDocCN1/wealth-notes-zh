# 制图说明

女式两用衫前、后衣片和袖片的制图步骤都是分三步进行：第一步确定各部位长度；第二步确定各部位宽度；第三步在直楞盖袖结构线工作上精确线，方法是点作弧。

【奇片 领窝门襟处（连面）2.1（也可加贴边）作一直线为止口线。】

# 第一步 先定衣长（见图1）

+   ①下平线 颈前点起0.8
②衣长线 ①～②是衣长19.5
③肩斜线 ②～③是胸围的 1/20 = 1.5
④前开领深 ②～④是领围的 1/5 = 2.2
⑤袖窿深 ⑤～⑤是胸围的 1/5 + 1.4 = 5.9（胸围线）
⑥前腰节线 ②～⑥按腰节长11.8，肩过0.3
⑦底边起翘 ①～⑦ 0.4

# 第二步 后衣宽度（见图1）

+   ⑧进门线 止口线～⑧一般0.7
⑨横开领大 ⑧～⑨是领围的 1/5 - 0.3 = 1.9
