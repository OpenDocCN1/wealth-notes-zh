# 烫油油酥糕

# 原 料

面粉1斤、酱油3两、白糖5两、芝麻1两、桂花酱5 *@*、青丝红丝各1钱、豆油3两。

# 做 法

+   1. 将芝麻洗净、炒熟、捣碎，加入白糖（三两）、桂花酱、青红丝拌匀成馅。

+   2. 面粉用开水烫好，揉成硬面团，醒凉。将馅油全部搓进麦，使面松软后擀条，下二个小孔后按扁，包入馅粘成烧饼圆形做成生坯。3. 锅内放入豆油，烧八成热时，将包好的生坯下锅，炸成金黄色。捞出油面拧出，撒上白糖（二两）上桌即可。

品尝杂论 形似烧饼，色泽金黄，外皮不破，不漏馅馅，馅香软酥。

# 撇面糕

# 原 料

精粉1斤、豆沙馅5两、白糖2两、豆油2两、食用红柔素少许。

# 做 法

+   1. 把勺制净放入清水一六六两烧开后，将勺离离火位放入精粉一斤，一把把铲，一面用热水拌搅。

+   2. 把搅拌的面团揪成块，下成四十个馒头，馒头包入豆沙馅。用手按成直径一寸大的圆饼，在中间用筷子点一个红点。3. 锅内放豆油，烧熟后放入圆饼炸成黄色捞出沥油，凉透装盘叠上白糖。

品尝杂论  色泽金黄，圆形整齐，皮酥甜脆。
