选充成分爽、果大、肉厚、离核，且水分稍少品质良好的香梨，用水洗净用锋利刀对半切开，然后切成薄片向上排列在果盘上。以每百斤用 3 两硫酸的比例进行熏制。熏 2.5～3 小时后果切透明（此时香梨处出现绿豆大的水珠），随即取出晾晒，成品含水量以 20～24% 为宜，如果果肉手抓一把捏于掌股成一团，随即松手，含子可以自动散开还原即为适度。

# 香梨果干

广东、福建、江苏等地习惯生产的一种类似果干而又有特种美味的果实加工品，如话梅、五香梅、各种糕糖制等。此类产品广东称如胶果，福建称方梨制，统称香梨果干。
如梨原料较好，可每年 100 斤加 18～25 公斤进行腌渍，制成半成品后保藏，可随时加工。这种半成品称为梨坯（在盐水中保藏称水坛；腌后干燥保藏的称干坯）。
制成品时取坯，先将梨坯用清水浸泡，排出过多盐分，然后用甘草、白糖、糖精及各种药食物香（荳香、桂皮、丁香、陈皮等）配成糖液，反复浸渍，使梨坯充分吸收，取出晒干，即为成品。

# 红枣

由熟枣即成。取成熟度较高的鲜枣，用沸水浸泡 5～10 分种，然后摊摊在阳光下曝晒，爱致湿潮时动，以利干燥。待表面裂纹时将枣翻起，用原皮盖，堆积期间要揭盖翻动数次，以免内部温度过高发生霉烂，以后再可堆开晒 1～2 日重复堆起，如此反复进行，直至用手捏时带弹性为止，枣外皮显深红色，肉为淡黄色即为成品，一般需要晒 15～20 天。

# 黑枣

又称黑枣，系人工熏制而成。选成熟无病虫蜂穿，放在沸水中加热，蒸至熟肉稍软为度，取出晾干，以备熏制。熏炉需备：在地下掘深约 18 里米、宽 165～20 厘米、长度适宜的坑，在坑口向下 50 厘米处用粗杆平铺，将晾干的枣堆放在上。厚约
