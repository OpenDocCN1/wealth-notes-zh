# 弯曲

将板材、棒料、条料、钢丝、管子等弯成一定的曲线形状或一定的角度，这种操作叫弯曲。

下面介绍几种常用的手工弯曲方法。

+   - 直角形工作件的弯曲

先划好线，然后夹紧虎钳，使锯条和锯口平齐，两边要与带口相垂直。如需稍的弯度比工件厚度不深时，可用角铁做夹持工具，图85。

![](bbox=[0.55, 0.7, 0.88, 0.86])

图85 用角铁夹持工件

如果弯曲的工作件在外的上部较长，应用左手压在工件上，锤击靠近弯曲部位，而不应锤击板料的上部。
