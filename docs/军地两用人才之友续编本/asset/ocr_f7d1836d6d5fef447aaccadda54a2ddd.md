发酵。为使发酵得好，出箱后需配少许肥糟、曲药4斤，待品温降至30℃进箱发酵，第三天升温到33℃，第二天后逐渐降温，到第七天上午时，品温降到27—28℃。

蒸馏、空酿缸气后，开始上酿，要空气一层上一层，以免霉气。

# 酒酿

用上等的好白米，洗干净，水浸一夜、浸后手指一捻、立成粉，然后倒入蒸锅里，加热水用米蒸熟，蒸熟的米饭，要粒清楚爽，松而不粘。取熟蒸锅架在缸上，用开净冷水淋酒，使其降温并去粘性。淋得米粒不粘，温度在35—40℃即可停。把米饭上洒放一层干于净的红丝，用手把米饭摊匀、使蛋有块就搅散，批酒药（酒药一掺酵、糯成粉末，用量为糯米的6％，另取上等白糖，用量为米的3％，拌匀后，混合好的物放在盆或盘上，边放边翻，最后用手轻轻压平。当中一端，用湿布把面皮盖好，再置—些温水（酒药、发酵封好。热天1天即软，冷天4—5天。若保留温度在30℃左右一天就能取食。发酵开始，就要慢有洒露水在当中增湿了。洒露到饭的高度的1／3时，就已成熟。

# 发芽马铃薯脱毒

马铃薯如果保藏不好，时间一长，就会生芽。马铃薯芽里面，有一种龙葵精的毒素，人吃会恶心、呕吐、头晕、腹痛，中毒严重的会造成心脏和呼吸器官的麻痹而死亡。发现马铃薯长了芽，要把芽削去，并且把芽附近的皮屑用刀削去，然后用水泡一些时间，在晒毒杀的时间要适当的长一些，方可食用。
