# 中山装（入门）

中山装的造型美观、整齐、端正、大方，具有独特的中国民族风格，可说是男式服装中的代表品种，深受人们的衷爱。我们只要掌握中山装的制作顺序和方法以后，对其他的男式服装如学生装、军便装、春秋衫、西装等的制作，根据变化就能迅速切而解，因为它们的衣片结构与中山装是基本相同的。
