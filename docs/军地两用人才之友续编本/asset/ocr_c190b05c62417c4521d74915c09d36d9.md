# 钻孔、铰孔与攻丝孔

在没备、工件和材料上用钻头做孔，叫钻孔；把已有的孔扩大或在孔墙上加工成各种形状的浅孔，叫铰孔（或叫扩孔）；为了提高孔的加工精度和孔和孔壁的光滑度须对钻孔进行精加工叫做攻丝。由于在车工基础知识中曾使用机床进行钻孔、扩孔、铰孔的方法已经作了介绍，不再重复。现只对手工操作部分加以介绍。
