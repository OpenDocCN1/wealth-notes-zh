# 麦冬

挖出根后，洗净泥沙，在烈日下曝晒。须根晒干后，用手搡揉、碰破、修剪等法去掉须根，净筛表皮，再晒数遍。
有的地方外采条状根，于地下部含的夹皮、放在筐箩内，浸于清 水中漂洗，不可用力，以免破皮或折断。洗净泥沙，用竹席架起，或 摊开晒 3～4 天晒后，再筛去残余杂质，继续再晒风干，约需 3 天，然后再 把晒干物反覆揉搓 2～3 次（修润时，两端可略剪除，每次长度，以利于 晒干）。","暂后晒干。若仍再掉噢，拍坯，反复 2～3 次，直至七、八成干时，将须 根剪去，并按大个分开，晒至干燥，装麻袋中，撞击摩擦，撞净外皮和须余须梗，过筛即可。有的地区最后还常用石粉匀抖，使其外形 光亮，并有防潮、防油、防虫的作用。

# 远志

挖出根后，去掉残茎、须根及泥土，晒至二、三成干。然后将平 板上来回搓压皮与木心分离，抽出木心，晒干。也可采用放量 1-2 天后，将水分稍干皮后，抽去木心，晒干。此为“远志筒”。如不 能抽骨者，可将皮肉摇开，去掉木心，此为“远志肉”。过于细小，不能 去木心者称为“远志根”。
