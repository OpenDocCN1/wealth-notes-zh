质量标准
色泽金黄，形似荔蕉，光亮整齐，不被皮不漏馅，香甜适口。

# 混合糖酥

# 原料

精粉3斤、猪油1斤、鸡蛋1斤、白糖1斤、芝麻2两、葡萄干2两、桂花酱1两、香精适量。

# 做法

+   1. 把鸡蛋洗净炒熟待用。将鸡蛋盛在盆内，留出两个鸡蛋待用。把白糖、猪油、葡萄干、桂花酱、香精加入鸡蛋内搅匀，倒入精粉内和匀，揸成面团。\n2. 把面团分成条，下三个十刻子，揸成圆形饼状。或用各种花样模具，揸出形状。\n3. 把两个鸡蛋打在碗内搅匀，用刷子逐个把饼刷上一层蛋液，再撒上一层芝麻。\n4. 扣在烧烤器盘内，放入烤炉烤十分钟左右，成熟取出即可。

质量标准
色泽金黄，形似荔蕉，不破边不裂馅，香软酥甜，口味多样。
