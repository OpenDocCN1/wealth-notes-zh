# 3. 切断车刀

切断车刀供切断工件之用。主刀刃宽度一般为2～6毫米。切断车刀头部伸出长度根据能全部切断工件毛坯直径而选择。切断车刀按刀头与刀身的相对位置可分为对称式和不对称式。不对称式又分为左侧式和右侧无对称形式，如图10所示。按切断处在右或左需物来选用。
