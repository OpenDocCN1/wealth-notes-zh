# 3. 圆雏体的计算

+   ① 大端直径的计算。
D = d + 2 L tga
式中
D——圆雏体大端直径（毫米）；
d——圆雏体小端直径（毫米）；
L——雏体长度（毫米）；
a——圆雏体斜角（度）。

+   ② 小端直径的计算。
d = D - 2 L tga
式中
d——圆雏体小端直径（毫米）；
D——圆雏体大端直径（毫米）；
L——圆雏体长度（毫米）；
a——圆雏体斜角（度）。

③ 圆雏角（或斜角）的计算。雏体的圆雏角和斜角之间是 2 倍关系，只要求出其中的一个，另一个也就计算出来了。
tga = (D - d) / 2L
