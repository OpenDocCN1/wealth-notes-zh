# 检验工具

为了知道工件表面高低不平的情况和检验刮削面的准确性，可用标准工具加上显示剂与工件平面对磨，使工件表面的高低部分显示出来。

标准工具
常用的标准工具有：标准平板、标准平尺、三棱检验尺（图63）、检验轴（图70）等。标准平板适用于检验较宽的工件表面，它的大小不等，可根据工件大小选用。标准平尺适用于检验刮削长而窄的工件表面，三棱检验尺适用于检验成角度的<|message|> 面，检验轴适用于刮削圆孔和轴类内表面，一般视用现场配制。

显示剂
显示剂应具有颜色鲜明、无腐蚀，对表画不上腐蚀作用的特点。常用的显示剂是红丹粉。它有两种，一种是铁丹（氧化铁），另一种是铅丹（氧化铅）。使用时用机油、橄榄油、柴油“调和”，但调和不要过重。它主要在铲削和研磨上，具有不反光和清点清晰的特点。在做高精度的研磨时，需用调和或苯节油来做显示剂
