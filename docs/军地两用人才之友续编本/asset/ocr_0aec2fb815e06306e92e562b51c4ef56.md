# 养殖业

# 养鼢鼠

鼢鼠俗名穿山甲、僵死虎等，其肉可入药，取名为五灵脂。青活血、止血、散瘀等功能。是一项收入较大的副业生产。

鼢鼠怕冷，喜温怕热，喜湿气候，但又怕高温和严寒，一般白天睡眠，晚上活动，喜吃各种青草的嫩叶、嫩茎、树籽，如柏树叶、黄芪嫩及等植物。人工饲养就要根据这些生活习性，进行管理。

# 饲养方法

①养鼢鼠，用木板做成2尺长、1.5厘米、2尺高的箱子，隔成三个小间，分别有利于、食、饮、排粪用，又可分成上下两层，前边安装栅子，供鼢鼠上下行动，一面可安装玻璃，以便观察行动。②笼养，用细铁丝编成笼子，中间挂树枝，供鼢鼠上下活动。笼喂食盒和粪便盒装设在箱子中间隔板。③洞养，选向阳，土壤较坚实的土地挖小洞，洞前安门口，内设饮水和粪便盒。洞内温度要适宜。门上要装铁丝网防鼢鼠，防止鼢鼠逃脱和其它害虫。

# 管理方法

①平常饲养，要保证鼢鼠的安宁，不要惊扰，更不要抓、挑拨玩弄，笼里要铺垫一些软草，经常保持清洁，要粪便饮食，饲喂不宜过量，并要注意饮水的水清洁卫生。凡是不利于鼢鼠的鼢鼠不要放在一个房间饲养。以防互相咬伤，冬季要防寒保温，夏季防热。②繁殖管理，鼢鼠的寿命约一年左右。每年二至四月为繁殖期，怀胎七十五天生育，一胎一至三只，一年只生一胎。小鼢鼠出生后三十天睁眼，四十天长全乳，三个月后可自行觅食。能够的母鼠要与母鼠分开，防止互相咬伤。在繁殖期间要增加营养，可喂黄玉米面馒头等熟食，以增强母鼠和子鼢鼠的体质。

# 养土元

土元俗名“土蝗中子”，是一种名贵中药，味甘，性平，具有活血破瘀、续筋等功能。
