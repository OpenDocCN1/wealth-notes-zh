# 荷叶边领连衣裙

这种连衣裙结构简单，式样整齐大方，适宜青年姑娘在夏季穿着。不做领子，微檐形领圈，外缘外缘衣服斜条的荷叶边或圆形的毛克泡边。前衣片仅做衣斜裾和直条缝合，下配块式斜襟，外系活饰腰带， mixer 迷你式短裙。可用印花或点子衣料制作。

本品荷叶边的做法，以半径为2寸和2.2寸的布料各一块，荷叶边宽为1寸，裁成后连直里口装在领圈上成荷叶边状。
