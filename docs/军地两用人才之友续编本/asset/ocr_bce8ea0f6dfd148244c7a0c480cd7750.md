灌溉 草莓怕旱，开花结果期间，尤其不能缺水。如遇旱季，应及时灌水防旱。

采收 春季，草莓发生新梢，萌芽后1个多月即抽葇开花。开花后30～40天成熟。因果实成熟不一，响应分期采收。疏去过熟的花及病虫的果，以保果实成活。采果实要及时早上市，可搭设小的塑料棚，提高温度，果实成熟可提早1个月左右。

# 樱桃栽培

育苗 中国樱桃常用分蘖繁殖，西洋樱桃则用嫁接繁殖。在我国可用中国樱桃、毛樱桃和酸樱桃作砧木，在10月下旬至11月下旬或2月下旬至3月中旬扦插成活，在8月上旬9月上旬进行芽接繁殖。

# 栽植 一般在秋天落叶后至春天萌芽前栽植。但北方在土地封冻前或解冻后栽植为宜。中国樱桃的行株距为4～5米，西洋樱桃为5～6米。西洋樱桃必须配置适宜的授粉品种，若以...等作为主栽品种时，可配植15～20%的黄玉、大紫、旱梅、水晶、鸡心等品种作授粉树。

# 土壤管理 樱桃宜秋季或越冬后施肥追肥，追肥分两次，开花前和采果后施用。果实成熟前应注意灌水，以防裂果。

# 整形修剪 中国樱桃常用自然开心形，西洋樱桃则用疏散分层形或主干形。中国樱桃分枝较弱，容易引起密层和内膛阴暗，必须疏去密生枝或过长枝，使通风透光。对幼树修剪要得体剪留，应用轻修剪。进入结果期后，应适当疏剪老枝，疏下部枝条生枝长；短截连续结果所在的先端枝，使新梢萌发并当年生枝条下部开花结实。

# 采收 当地鲜销应监果实充分着色，成熟时采收。外销或加工的应提早4～6天采收。采收时应手提果柄，轻轻<|start|>轻轻放，其盛宜浸，垫软草或<|start|>垫，以防损伤果实。
