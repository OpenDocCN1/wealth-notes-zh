直线运动，极易溃疡。在冷却过程中用小锤轻击焊缝，消除应力， 施焊部位保持在水位之下。

焊接零部件用107电焊条。焊接焊箱用焊227或237电焊条，焊接锡青铜用227电焊条，焊接铬青铜用焊237电焊条。

# 铝和铝合金的焊接

铝具有良好的塑性和较高的导电性、导热性，同时还有抗腐蚀的能力。铝的比重小(2.6~2.7)，比较轻三分之二，热膨系数较大(为0.000024)，收缩性也很小，铝合金的强度较好；重量轻，加工性能好，适宜压制、焊接、锻造等多种加工。

铝及铝合金焊接性能差。 由于铝和铝合金具有它们独特的性能和特点，因而，它给焊接造成了困难，以致成为一种较难焊接的金属。下面介绍铝在焊接操作时常常遇到的问题：

+   1. 铝从加热到开始熔化的整个过程中，颜色没有明显的变化，不易正确掌握补焊量，给焊接造成困难。 2. 铝的氧化性很强。铝在空气中氧化，形成氧化物熔点很高，用气焊烧熔铝时易形成，而氧气很稀的比重大，熔接时易将氧被夹渣到焊接的铝合金焊缝中去，形成夹渣。焊接时为了减少氧气氧化影响，需要使用焊枪使，为了披盖熔化的氧化膜，要采用一定的运条手法来防止焊渣，使用操作技术更加复杂一些。 3. 由铝的强度低，随温度而变化的高，强度更低；铝熔在375℃(融化时)，强度不超过1公分/毫米²。常常不能支持住铝本身的重量，有时当你还以为表层氧化物还没熔化时，熔渣一下子就被熔掉了。一大。 4. 从铝和铝合金的焊接性能来看，在铝的焊接过程中，常常出现气孔。裂缝和缩松。 5. 铝在高温下强度低，容易形成裂纹。 6. 铝具有较大的膨胀系数和热膨系数大，使焊件产生较大的变形和应力，容易引起裂纹。
