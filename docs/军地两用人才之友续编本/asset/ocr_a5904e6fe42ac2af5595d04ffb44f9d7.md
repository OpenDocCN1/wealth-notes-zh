# 一 螺距（毫米）。

从式中看出螺距一定的螺纹，加工头数不同时，可得到不同的导程。

多头螺纹能在不降低螺纹工件强度的情况下，当 nở杆转动一转时，就能得到较大的移动量。 由于多头螺纹的螺旋数目大于1，所以车完第一条旋槽时，必须把工件旋转一定角度，或把车刀移动一个螺距的距离，再车第二条螺旋槽，这个过程叫分头。分头的次数取决于螺纹头数。双头螺纹分一次头，三头螺纹放两次头，以此类推。只有分头正确才能车出合格的多头螺纹，因此加工多头螺纹，必须解决好分头的方

2. 多头螺纹的分头方法

# 螺纹的分头方法有多种，我们在加工多头螺纹时，应根据工件的加工要求、机床设备的情况、加工批量的大小等条件，来选择适当的分头方法。常用的螺纹分头方法有三种，利用挂板和数板进行分头；利用小板根据刻度盘进行分头；利用三爪卡盘和四爪卡盘进行。

# 1. 提高梯形螺纹精度的 方法

车削丝杠实际就是车削梯形螺纹。提高梯形螺纹精度的方法：
①提高机床精度，应保证进给丝杠松、小，精度较高的车床进行加工。加工时选择精密的尾座和丝杠进行加工，并经常调整车床各处间隙，特别是主轴轴向窜动、趋向旋转及丝杠轴向等间隙要经常应注意。
②提高工件安装精度。由于丝杠是超长工件，应采用跟刀架进行车削。在车外圆时，应特别注意避免装偏或圆度误差，车前时要注意调整跟刀架支承爪的松紧程度，防止车削时产生振动，并随时注意观察爪磨损情况。
