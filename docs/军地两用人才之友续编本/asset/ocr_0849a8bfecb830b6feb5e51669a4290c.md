+   1. 粗车后应经正火或正火后等车，应考虑热处理变形对工件的影响，留出1.5~2.5毫米的余量。
2. 需精制加工零件，不可不必精车。
3. 车外圆开始前，先放粗车面一刀，以便加工时决定长度方向上的尺寸。
4. 车保证轴颈时，先加工较大直径的外圆，后加工程小直径的外圆，以保证工件在精加工中的刚度。
5. 车轴细长轴时，应稳定中心架或跟刀架。
