水轮机的产品型号由三段文字来表示。第一段的字称和数字表示水轮机的型式及模型试验序号。第二段的字称表示水轮机的布置方式和引水方式。第三段的数字，为水轮机的名义直径（对混流式水轮机，取转轮室最大直径。对于混流式，取转轮叶片进口的最大直径。）

# 3. 小型水轮机的选择步骤

+   (1) 根据第一部分的介绍方法，首先确定本电站的设计流量、设计水头和预期功率。

+   (2) 根据电站的出力，负荷的情况，是否并网及制造厂供应机组的可修性等原因，初步选定机组的台数。

+   (3) 根据已知的设计水头和单机出力，在表2中初步选定水轮机系列（不必拐双击和斜击式）

+   (4) 根据初步选定的水轮机系列，再从几种小型水轮机系列的使用范围中一步选出水轮机的直径、转速、出力及机组布置方式。
