| 原料 | C占原料重 % | N占原料重 % | C : N |
|---|---|---|---|
| 干稻草 | 42 | 0.63 | 67 : 1 |
| 干麦秆 | 46 | 0.53* | 87 : 1 |
| 野草 | 14 | 0.54 | 27 : 1 |
| 耕牛粪 | 7.3 | 0.29 | 25 : 1 |
| 耕猪粪 | 7.8 | 0.60 | 13 : 1 |
| 人粪 | 0.4 | 0.03 | 0.42 : 1 |
| 人粪 | — | — | 6 ~ 10 : 1 |

两钟原料总的含C量为：
C总 = ax + my
两种原料的总含N量为：
N总 = bx + ny
∵ C总 : N总 = K ∴ C总 = K · N总
即, ax + my = K · (bx + ny)
(a - K·b) x = (K·m - n) y
故甲原料与乙原料的重量比为：
x : y = (K·n - m) : (a - K b)
例如，用干稻草（作甲原料）与人尿（作乙原料）搭配。在表2查得：
a = 0.42 b = 0.0063 m = 0.004 n = 0.0093
选取 C : N = 16
则 x : y = (16 × 0.093 - 0.004) : (0.42 - 16 × 0.0063) = 1 : 2.2
即需用 1 千干稻草与 2.2 份人尿相搭配（重量比）。
