# 短袖两用衫

这是一种男式的夏季兼本服装，式样大方，穿着凉爽，很实用。它可选用府绸、麻纱和涤棉布裁制，对青年同志来说，也可选用比较流行的条格料或花纹物裁制。式样的变化主要在口袋，领子和袖口翻边等处，贴袋的лих方有方、圆角和六角形等等，领子的领角有平角和尖角之分，袖口翻边近年来流行外翻形式；后衣片有帽，穿着者可根据自己的爱好选定。
