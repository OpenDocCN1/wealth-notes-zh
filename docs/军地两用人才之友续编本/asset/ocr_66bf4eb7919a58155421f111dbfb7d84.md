# 刮刀的刃磨

平均刮刀，应首先在砂轮上进行粗磨，磨出适合于工件要求的形状。粗磨时刃先磨头部两侧面，再把虎齿磨成与刀身相垂直。中部刀和细刮刀，要磨出适当圆弧和尖前角。粗磨要经常冷却，防止炎热退火。在砂轮上进行磨削的刮刀必须有较细的砂痕和毛刺，此时须在小轮上进行抛光，以使刃部更锋利。细磨时，在油石上抛光机，刀身垂直于油石表面，一手握刀柄，一手握刀头，来回滑动。磨平刀刻时，两手应对同一方向。磨圆头的中心，细刮刀时，握柄的方向可动或按纵向反方向变动。两侧面的前角和顶端应交迭进行，推进方向应与长度长边成一角度。图62是磨法示意图。粗磨三角刮刀，应在砂轮上照黑刀
