# 菊芹领春秋衫

单排二粒钮扣下摆，圆形连驳领，仿生物菊芹形状而设计，故称菊芹领春秋衫。前衣片领围收成斜领，曲线式，眼眶收一适宜形状领省；领袋口圆贴袋，后衣片做缇，圆紧袖，袖口缝有暗叉。式样新颖别致，宜用各类小格和松软的呢料制作。
