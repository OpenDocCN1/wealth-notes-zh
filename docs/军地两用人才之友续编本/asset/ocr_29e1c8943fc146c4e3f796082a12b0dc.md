# 矫正与弯曲

# 矫正

原材料的条料、槽料、板料以及某些零件由于加工、热处理等原因往往产生弯曲、翘曲等缺陷，清除这些缺陷的操作叫矫正。这主要讲述用手锤等工具在平板、铁砧或矫板等设备上进行的手工矫正。变形材料的矫正操作能依靠矫正力取得材料本身的性质：对性质好的材料（如铜、锡、铅等）通常予以矫正；而脆性大、硬度高的材料（如铸铁、淬硬钢）不宜矫正。经过矫正后的材料，性质要发生明显的变化，一种是表面硬度增加，这现象称为冷作硬化，一种是使材料变脆。这两种变化给矫正和其他冷加工带来不少困难，在实践中，人們采用退火处理的办法，使材料恢复原来的机械性能。
