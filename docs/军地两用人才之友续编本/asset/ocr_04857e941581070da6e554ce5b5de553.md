# 焊接基础知识

焊接技术，大体可分为电弧焊接、电弧熔接及特种焊接。人們平常所说的电弧焊接系指弧焊统称。这种焊接方法的特点是，以焊接电弧产生的热量来局部地加热，使焊件和焊条熔化、互相融合、冷却凝固后形成牢固的焊接，成为永久性不可拆开的联接。这种工艺过程利用手工操作就能完成而且机械操作或就自动焊也能完成。

焊接技术广泛应用在国防、冶金、石油、化工、造船、电力、铁路、交通、建筑、机械等各部门。人們所熟知的人类、轮船、汽车、飞机等，它们的内外各躯架都以焊接来组成一类模型焊和一般焊接来完成。此外，压力容器、锅炉结构、高炉炉体、化工设备、矿山机械、铁路桥梁等都是典型的焊接结构。焊接技术与铸锻、锻压、切割、其它有着各金属材料、减轻结构重量、简化加工与装配工序、接头的致密性、强度高、经济效益好、能改善动态条件等一系列优点。

# 手工电弧焊

于工电弧焊（简称手弧焊）是利用电弧放电时产生的电弧热量熔化焊件边缘和焊条，熔合形成焊缝，最终而成焊接。

手工电弧焊，在焊接中是最常见而且也是应用较多的单一焊接方法。它的优点是，使用灵活、操作方便、设备简单、适用于焊接短小或曲折焊接，可焊不同头形式及空间各种不同位置的焊接。在电焊生产中占有重要地位。
