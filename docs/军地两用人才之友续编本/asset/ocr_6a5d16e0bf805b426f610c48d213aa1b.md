月季一年四季均可扦插，以春季秋繁最好。春事先繁健壮的枝条，秋季条取当年花后健壮枝条。花谢一周后，剪取8～10厘米长的枝条，保留2～3芽，用刀片在嫩芽底部削成马蹄形状，到部分分叶片，以防水分蒸发。然后将枝条的肩膀土部分浸入水中半天，并将插穗为枝条的1/3，樱木六若，将土壤密实即可将扦插材料插入穴中，并保持温度在20～25℃左右。如温度高时，掀开塑料布通风降温，20天以后产生愈合组织，一月后生根发芽，待第三个月中旬移栽上盆。

# 二、三个月后移栽上盆。

# 插种法：把一般芽成熟后砂藏，来年春天再播种，种子砂藏期间，温度为5℃或低一些。经过低温处理后，方可将种子播到适宜处。

压条法：对于蔓生种的蔷薇，枝条就可以弯到地面就可来进行压条，时间最好是在春季季节，压条时将枝条在靠近根处切一刀，将土块堆成入穴内，然后埋入土中，用竹板或铁钉将枝条固定，以防弹起。待生长后切离母体。对于部分枝条相互的也可采用高压法。

# 嫁接法：用野生蔷薇、修枝条芽、根部留5厘米做砧木，另外选好品种健壮的枝条，保留2～3个芽，放在嫁接，交叉接穗于逐渐处，充分灌水，次年春季发芽后修枝，这是最好可采用芽接或芽接进行繁殖。

月季环境适应性强，宜植于疏松，排水良好，富含腐殖质的微酸性土壤中。夏季放在阳光充足，通风良好的地方，浇水要适当少盛
