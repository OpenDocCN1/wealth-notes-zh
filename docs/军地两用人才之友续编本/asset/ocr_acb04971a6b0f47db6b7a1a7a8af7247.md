# 开花。

华南及福建一带可在露地种植，其他地区均做盆栽。五月下旬出房，放阳在光充足的温室为好。茉莉花适宜在25℃的气温下生长，生长旺盛更需要水分和湿润的空气，相对湿度为80～90%左右为最 好。每日浇水1～2次，在气温最高7～8月份，叶面蒸腾作用加劲，每 天浇水增增到2～3次，但要避免过湿。北方地区为加湿湿度，每 天在叶面喷水2～3次。在多雨季节应注意防倒，以免积水，引 起烂根。
由于浇水不当，盆土长期潮湿，土壤偏碱以及长期不换盆土，缺乏肥 料，特别是叶?子会变黄出现一现象要检查原因，带病浇水或适当 浇淡液肥的黑腐水。般北方地区为防止土壤盐化等，每10天左右浇一次 0.3%的黑腐水，九月下旬向室内停止施肥，温度最低保持10～12℃， 不能低于5℃。春季至室内进行换盆，并结合整形修剪，有利于茉莉 花的生长。

在闷热、通风不好的情况下易引起介壳虫。
