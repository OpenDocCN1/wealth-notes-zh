“拉”。用二至四个手指，向上拉紧，以便剃刀剥制。这种方法张适用于剃刮下巴部位的胡须。

“提”。用两指夹一块皮肤，连同肌肉一起提紧，使被塑部分皮肤敞开，用剃刀轻剃。这种方法，适用于嘴唇周围部分，如亲下的人中。一个都是应在星面处的，把它捻地被起来，剃刀就容的操作。什令刀法应该用在局处细细配合，丈夫体上也有某些比较固定的标准，一般的配合方法有以下几种。

+   （一）正手刀与推力。基本上的“张”的方法配合。指缘与手指贴着皮肤，两平行的用力就是一起用力，将两指间皮肤绷紧，剃刀在手掌张开的部位中同或向做倒驯系的相对方向剥制。

+   （二）反手刀基本上也是用“张”的方法配合，但手指只能集中在边处用力，有时甚至于把指按一，有时也可以将其余指合并加以叠集中手指并排一连，剃刀就向做倒驯系的反方向剥制。

+   （三）剃刀反用“拉”的抬法配合。食指、中指在一边，拇指在另一方，头部全部放在，揭开皮肤底部食指与中指缝间，向上提拉，剃刀可对警告紧起的皮肤或手指下端被拉紧的皮肤进行剥制。

+   （四）“扳”配合的其它方法。某些特殊部位的“作”“作”扳。

“拉”作手指不能展开时，剥制方法也根据各具体部位作改变。在睫毛边缘和上眼睑部分，下巴颏下部颌本上都要用“提”的方法，可以揭开皮肤和需要剃制的皮肤，使其宽松。再用剃刀剃剃，有时也可以利用食指和中指的力量，相应于“张”的方法将皮肤箍着，让剃刀在揭开处剥制。在制耳部时，可用拇指与食指捻住耳垂向外拉。剃鼻中部（鼻孔口）时，可用拢指抵住皮肤使其松弛。剃下巴部时，可用手指将其向前推进时稍有以上改变变。主要因剃剩余的面积小、“拉”、“张”都不相宜，只好用其它办法使皮肤阔紧。总之，要根据不同情况，从实际需要出发，灵活掌握，以达到剃须的目的。
