含剂为好。焊膏最好将焊缝温度冷却至200℃时，用小锤轻轻的锤击焊缝，再用火焰加热到600℃左右，放到水中迅速冷却，使焊缝金属组织细密，增加焊缝的韧性和塑性。

# 黄铜的焊接

黄铜和合金含黄铜。焊接黄铜最容易出现的问题是：当黄铜加热到925℃时锌就蒸发，使得焊缝金属产生气孔或在焊接表面产生辉点。黄铜在高温下产生氧化物，且容易吸收氢气，所以在焊接黄铜时，产生氢气孔现象比氧化、青铜严重。为了克服这一现象，应采用经验较多的氧化焰焊接，使熔池表面形成一层氧化锌薄膜，相反的bt等一些非常容易挥发，焊剂保持焊接温度600℃以上。适用的焊条，要求基本上和母材一样，最常用的是加入了少量锡和硅的铜。焊料为211号锌焊料。锡焊最好够防止熔池很少熔池中锌的蒸发和挥发，防止熔缝中产生气孔。为使很好地清除熔池产生的氧化物，可用30％硝酸冲洗焊缝。焊后用小锤轻轻敲击焊缝，再用火焰均匀的加热，用火，温度约600℃左右即可，各个焊接过程迅速越好，以减少辉点的产生。焊接时应尽量减少焊接次数。

# 铜合金的焊接

铜合金中除了铜和锌之外，其它合金经常青铜。焊接青铜值得注意的问题是：减少锡的烧蚀。另外青铜在高温下很容易，应注意将焊件固定好，防止受热后局部弯曲。焊接将焊件预热至450℃，常用中性焰焊接。焊接黄铜金属散热快7～10倍的速度高，焊接过程中要利用焊条覆盖焊接金属面，保护熔池和供给充足的金属，以保证焊条和熔处的熔化金属互相融合。其它焊粉成分与黄铜焊时基本一样。

总的来说，焊接铜及青铜应采用严格的中性焰焊接，而焊接黄铜时为了减少锌的蒸发，经常采用氧化焰。焊接要缓慢进行，借以缓慢冷却金属焊缝处所同时间，减少金属在高温下的氧化和锌的蒸发。施焊时应配以锡焊条类同样。用力，可为铝和优惠的焊接缺陷。

电气上用作导电线，一般是紫铜的，在焊接前，将导线的头部打出坡口，并除净氧化物。焊接前先进行定位焊，然后从点焊的焊。
