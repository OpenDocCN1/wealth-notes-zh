# 图60 平面刮刀

虽大，中刮削的刀头端部有圆弧（R 在300毫米以上），刀口带负角2.5°的负前角。切削时比普通刀小，但仍可保证一定的刮削宽度。细刮刀主要目的是增加表面贴合点，以达到所要求的表面粗糙度。细刮刀刃尖端有显著的圆弧（R 在200~500毫米之间），为了减轻刮削是和引起一定压光作用，它的刀口带有负5°的前角。椭柄刀（弯柄刀）一般不使用，只有在刮削型线为疏密的工具，仅就刀具用。为了防止刮削工件表面出现螺旋纹，还可用弯头平面刮刀。它的刀头薄，一面有刮刀，刮削时有弯度。
