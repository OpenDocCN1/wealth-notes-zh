# 5. 酸度（pH值）与控制

一般来说，沼气发酵最适的pH范围是6.8~7.2，即在中性范围内合适，pH值在6.5~7.6之间对抗发酵会显著的抑制，pH值在6.4以下，会抑制发酵，如果pH高于7.6，就会有显著的制动进行。

正常发酵时，酸度产生后发酵液的pH值，但酸的进一步氧化和蛋白质等物质分解产生氢气又提高了pH值，所以发酵池自然地维持平衡。

对pH影响最大的是挥发酸度，正常发酵的挥发酸浓度（以乙酸计）应在2,000毫克/升以下。要控制pH值，就要控制投料量，控制发酵温度，从新取出发酵液或喷雾发酵。首要先使发酵池清水，投入沼液发酵的产品，这些从池边动或从发酵池或旧发酵池中排出的消化污泥中获得），然后，少量缓慢不断添加发酵料。发酵料的pH值须在7以上，在添加过程中，经测定pH值，如pH值降低过多，减少或停止投料，使pH值回复至7后，再适<|start|>增加，直到投料达到通常的处理水平。有很多对收集一次集中大量投料，随后不再添加新鲜，这是极其错误的做法，造成较长的冷和前提不充分的二氧化碳气体不能热能，更严重的是大量有机物不能于下消化不了，产生二氧化气泡将物质托起，形成很厚的难以消化的浮渣层，使物料不能充分利用。还有每天均投料的有效控制。
