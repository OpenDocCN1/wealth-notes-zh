# 2. 常用药物和治疗方法

# (1) 中草药

鱼腥草——清热，
五倍子——防治白皮病、赤皮病、烂鳃病；
菖蒲、 tying 子药、走马癣、大叶蚯——防治草莓、青鱼肠炎、烂鳃、赤皮病。

根草、铁苋菜、水蜈蚣、马蓝草、蛇莓、马鞭草、车前草、椿树白头翁、紫苏、 queue、 黄柏（川柏）——防治草莓、青鱼肠炎病。
苦槟——防治白头白膜病，隐鳞病、鳃头腐烂病、肠炎病等。
金银花——防治白头白膜病。
白芷、白术、土茯苓、大黄、野菊花、薄荷、黄连——防治白头白膜病。
槐蒿——防治头槽蚊虫病。
杨梅（鬼柳树）、大茶叶（靶松树）——防治锦头鱼鳞、烂鳃病等。

五加皮、雷丸（竹荪）——防治锦头鱼鳞病。
杨梅（山杨梅）——防治沾鱼病。
川木香、广木香、房柏——防治鱼苗气泡病。
黄芩（土连子）、马兜铃——防治淋巴、青鱼赤皮病、鳃鱼赤斑病。
苦参（地参、野荆树）——防治锦头鳃立病。

用中草药治鱼病的方法有：
浸泡法。将中草药放入进水口或上风处水中浸泡，让浸抽出的汁液皆到池中。
泼洒法。将中草药捣碎或磨粉，浸泡一段时间，连带药液泼入池。
投喂法。将中草药捣碎或煮成汁，拌入饲料投喂。
