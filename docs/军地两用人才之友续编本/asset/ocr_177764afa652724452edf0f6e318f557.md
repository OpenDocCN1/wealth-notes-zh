4. 铅, 研磨铱钢及其它非金属, 一定要用铅锉研具, 否则因研具过硬而损坏工作表面。

+   - 研磨剂

研磨剂有研磨粉和研磨剂两种。研磨物有多种, 它们的硬度、使用
途各不相同, 使用时可参照表7。在研磨粉中添加粘结剂、润滑剂,
便可制成研磨膏通用。常用的添加剂有硬脂酸、石蜡、动物脂肪等。
加入添加剂可以使研磨物质分布均匀, 提高研磨效率, 而且使用方便。
因此, 在工厂中多用研磨膏。
研磨颗粒有粗有细, 多种型号, 不能混合使用。细粒是用来研磨
表面的, 粒度有二种分类方法：第一种是筛孔表示, 有12、14、16、
20、24、30、36、46、60、70、80、100、120、150、180、
240、28 0 共17个号, 号数越大越细；第二种是微粉分析法, 有W40、
W28、W20、W14、W10、W7、W5、W3.5、W2.5、W1.5、W1、
W0.5共12种, 号数越小越细。

润滑液
研磨时不能干研, 因为这样容易使表面产生划伤和粗糙毛刺, 易
发热, 影响精度。加润滑液可以消除这些毛病, 并可以使研磨剂分
布均匀。
常用的润滑液有机油、煤油、猪油、水等。使用不同种类的研磨
剂和不同材质的研具, 所加的润滑液见表8。使用研磨膏时, 加少量
机油做润滑剂即可。
