# 中式宽腰棉袄

中式宽袄是我国的传统服装样式，在民间流行普遍。它是由娃娃衣料裁成，逢袖式，不做肩缝。用它来作为冬季的棉袄最为适宜。保暖性能好，穿着舒适，双手举动方便。开襟的形式有两种，一种是盘襟式，配用中式的盘花钮扣；另一种与西式服装的开襟方法一样，有选门，开洞装。如果制做棉衣，应该比棉袄放宽0.2寸。
