# （1）变速联接的小风力发电机

在制造和使用的风力发电机中，大都具有变速机构的。有的采用齿轮传动，有的采用皮带轮传动。输入轴是风轮轴（即风力发电机主轴），输出是发电电动机轴。所以要采用变速机构，其原因是风力发动机的转速是很低的，特别是高道性不甚好的风轮叶片，其转数每分钟最高也不超过百转，而发电动机转数很高，如一般汽车发电机、空载转数为1000转／分，工作转数3000转／分。因此，为了把风轮轴转速提高到发电机的转速，必须采用中间变速机构。其低速轴就是风轮轴；高速轴为发电机转轴。图8是一种具有代表性的小风力发电机。它采用皮带轮皮带联轴，速比为1：7.5。风轮直径为1.1米，装3片4“厚型”叶片，在风速低于60风的风力，通过变速器向用户供电。这种风力发电机的调速采用离心增阻，把风轮转速稳定在160
