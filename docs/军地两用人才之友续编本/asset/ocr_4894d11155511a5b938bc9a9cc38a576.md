均风速为10米/秒，它可以由瞬时速度14.5米/秒5.5米/秒得到，也可以由瞬时速度8.0米/秒和12.0米/秒得到。后者变化幅度小，就说明它的变化小，对风能利用的意义反而大。

风速的另一个特性是垂直高度而变化较大。这是由于空气流经树木、山丘和建筑物等障碍时，会形成不规则的涡流，降低其原有速度。一般说来，离地面愈远，风速愈大。若已知在高h1上的风速为u1，对于任意一个高h上的风速，可按下式计算：

```
v = v1 (h / h1)^{1/5}, 米/秒
```

风速的这个特性，对风力机安装场地的选择和安装高度的选择是很重要的。

风，除了速度的变化外，还有方向的变化。风的这种不稳定性也是风力设计中必须考虑的。

# 4. 风能的计算

任意运动着的物体都具有动能，风既是空气的流动，也就具有动能。这种动能称为风能，可用式表示：

```
A = ρ v² F / 2 公斤·米/秒
```

式中，ρ ——空气密度，公斤·秒²/米⁴ F ——风轮叶片的回转面积，米² 从这里可以引出两个结论：

+   (1) 风能同风速的三次方成正比，因此，风愈大，它所拥有的能量也愈多。

+   (2) 风能与风转叶片的回转面积成正比，因此，风轮直径愈大，所产生的风能也愈大。在风能利用中，常用这个关系来确定风轮直径。

风力发电机是利用风轮上的叶片来获得空气动能的，但是所得到的好动能，只有—部分转变为机械能为人们所利用。目 前，设计良好的风力发动机，大多数只能把45％左右的空气动能转变为机械能，也就是说，还有55.5％的动能没有得到利用。因此，增加风能转变为机械能的百分比，是完全风力发电机设计的一项十分重要的工作。
