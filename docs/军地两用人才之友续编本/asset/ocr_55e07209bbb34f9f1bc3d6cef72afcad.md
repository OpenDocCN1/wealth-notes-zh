# 裂纹

在焊接过程中或焊接后，在焊缝和焊接接头区域内所出现的破裂现象，称为裂纹。裂纹出现不但降低了焊头的强度，还会引起裂纹的继续扩展，导致整个工件破坏而报废。焊件有了裂纹，一般认为是混合合格产品（图28）。

# 产生裂纹的原因

1. 选用材料、化学成分不适宜。一般情况下，含碳量会合金元素越多，产生裂纹的倾向越大。金属成分中含有容易形成低熔共晶体的杂质，则容易产生热裂纹。
