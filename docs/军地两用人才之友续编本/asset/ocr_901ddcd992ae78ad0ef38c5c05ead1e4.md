# 车 螺 纹

螺纹的用途很广，既可以用于紧接、紧固及调节，又可用來传递动力或改变运动方向。加工螺纹的方法可以用车削、滚压、搓丝等，但车螺纹应用最广，因为一台普通车床就可以加工出各种螺纹。
