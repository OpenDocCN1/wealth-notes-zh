# 建筑蘑菇窖和蘑菇生产

蘑菇是冬春季生产的主要品种之一。生产要求条件不苛，虽粒立缘、温室内可全年生产。为保证产量高、生长快、质<|message|>量好，可利用蘑菇窖生产。窖宽窄、大小根据地形、村材而定。为向最好朝南，半地下式。挖地深下1.2米，挖出土厚培，前墙高35厘米，宽35厘米，后墙高70厘米、下宽45厘米。山墙厚度与后墙一样。前墙用双层薄膜（6厘米方木上各钉一层）。中间立两根支柱，用木架、棚楞起后坡，上铺蘑菇秸杆玉米秸，上拱10厘米厚泥。
