# 白皮豆沙酥

原 料
精粉1斤、豆沙馅4两、猪油3两。

做 法

+   1. 用四两精粉加猪油（二两）揉成油酥面。用六两精粉加猪油（一两）、温水和成水油面。

+   2. 用水油面包进油酥面，再用面杖擀成长方形片，切齐边沿，往里卷起梢长，下二十个剂子，将剂子按扁，每个包入豆沙馅（二钱）。按一下，罗成直径一寸五分的圆。

+   3. 将饼放进烤盘内，入炉烤至见饼鼓起，皮背硬时，将烤盘上层面盖上铁盘，再用慢火焖熟即可。

原芝麻烙
形圆，个头匀，层次分明，色白酥甜。
