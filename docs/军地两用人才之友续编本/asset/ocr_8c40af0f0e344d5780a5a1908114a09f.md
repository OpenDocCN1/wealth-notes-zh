端面虽然简单，也应当引起注意。

端面车削时可以采用两用车刀方向，但是，在车端面开始之前，必须根据选好的端面车刀及切削情况，确定其中的一个车刀方向为当今选定用45°左右车刀车端面时，应当采用由工件外圆向工件中心的前进方式。选择车刀主切削刃进<|message|>工件，工件表面先过渡较高。若选用左偏刀时，也要采用由工件外圆向工件中心的进刀方式。

# 3. 偏切削用量

+   ① 切削深度 ap 的确定 一般情况下：
粗车时 ap = 2 ~ 5 毫米；
精车时 ap = 0.1 ~ 1 毫米。

+   ② 走刀量 f (即进给量的确定) 走刀量 f 的确定原基和切削深度 ap 的确定相关，一般情况下，
粗车时 f = 0.3 ~ 0.7 毫米/转；
精车时 f = 0.1 ~ 0.2 毫米/转。

+   ③ 切削速度的确定 车端面时的切削速度是随着工件直径的减小而逐渐减小，所以计算切削速度时，要按最大外圆直径计算。计算方法和车外圆时相同。

端面车削的特点是
端面车削的特点是，要求端面必须保持平整、光洁、平面度好。

车削端面时的特点是：强春车刀由工件外圆表面向工件中心走刀，工件直径逐渐减小。

```
v = π D n / 1000 米/分。
```

式中 D — 工件直径（毫米）；
n — 主轴转速（转/分）；
v — 切削速度（米/分）。
当主轴转速确定后，切削速度随着工件直径减小而减小。因此越接近工件中心部分，切削工件越比较困难。车端面时须特别注意这点。
