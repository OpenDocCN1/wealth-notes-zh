# 焊接工具

手工电弧焊常用的工具有：电焊钳、电焊软线、面罩及焊接工具等。电焊钳其作用是夹持焊条和传导电流。电焊钳应有良好的导电性、长时间使用不会发热，能与各方面上安装各种型号的电焊条，以安全、轻便、耐用为宜。一般有30安、50安两种规格。

电焊软线是用来联结机与开关（或）、焊机与焊钳（手把线）的，电焊软线一般是用紫铜外包橡胶皮做成，要有良好的导电性和绝缘性，并需要有足够的长度和适当的截面积。对于导线（电焊软线）与电弧的连接应能所了除，以便于正确地选用适当规格的导线，使其得到足够多的接触电压。

+   1. 导线越长，电阻越大。
