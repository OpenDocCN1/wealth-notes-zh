# 利用太阳能的途径

太阳能是一种巨大的、清洁的能源。为了高效地利用太阳能，首先需要把它转换成为其它方便利用的能量，例如高温热的热能、电能、化学能，再加以利用。这些转换方式被分别叫做光—热转换、光—电转换、光—化学转换。
