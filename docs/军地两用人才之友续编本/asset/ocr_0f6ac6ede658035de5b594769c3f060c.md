# 丝锥前部孔直径及减度和

攻丝前，钻孔直径应较螺纹内径稍大一些，因为在攻丝过程中，丝锥对金属有扩张作用，使金属扩张。如果丝孔与螺纹内径一致，丝锥会由于金属的扩张而被嵌住，以致折断。
一般工厂都备有制造螺纹前钻孔直径选择表，常时间制造螺纹和管端纹攻前钻孔直径从表里选择。另力，攻丝前钻孔用的钻头直径还可以用经验公式计算：

式中： t —螺距（毫米）；
d0 —螺纹外径（毫米）
