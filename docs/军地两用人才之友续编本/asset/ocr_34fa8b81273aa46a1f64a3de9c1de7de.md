# （1）水压式沼气池

水压箱（也称反压箱）建成在发酵间外称，为倒反应式，如建在池侧则为正反应式，如图1。池顶覆盖混凝土， 般可保温，也可抗衡池 气室内向上方的气压体积力。设置活动盖板便于修检和请渣时工作人员 上下活动和通风排气；就进料管道便于进料，并且可以从进料管中 随时提取发酵液，发酵间内大量产气后，把发酵液压至水压箱，压力 上升，一般控制在1.5米水柱压力以下。使用沼气时，池内压力降低， 水压箱的发酵液流回发酵间。

这类池的优点是容易建造，可因地制宜地用三合土、灰、砂、砖、石、水泥（少量）等建造，所以深受广大民众欢迎。其缺点是压力较小，防漏的要求严格，如管理不善，易引起沼气池的破裂；此外，发酵液面至水压箱，减少了发酵间内的有效发酵液的量，影响产气，同时发酵液中的氨氮气会在水压箱中挥释，对保护肥不起。
