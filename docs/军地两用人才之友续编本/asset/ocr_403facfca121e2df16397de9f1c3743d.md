# 千 层 饼

# 原 料

精粉1斤（包括馅面2两）、豆油5钱、花椒面1分精盐1分、食碱适量。

# 做法

+   1. 将八两精粉与二两醇面粉用温水加食碱搅和成面团，醒一会儿。\n2. 将醒好的面团揉匀，擀成条，下同样大的五个饺子，再拧成一头尖一头宽的椭形片。

3. 把椭形的片子用刷油，撒上花椒盐面，由窄的一头卷起来，用宽的一头将两面包好，再拧成椭圆形片，用刀在饼上交叉压上菱形花纹。上屉蒸熟取出，由中间切开为两片即成。
原英称净
色泽<|start|>白，形似牛舌，层多嫩软，味美可口。

# 香 蕉 酥

# 原 料

精粉1斤、香蕉2个、白糖3两、豆油2两、枣泥馅3两、香精1分。

# 做法

+   1. 将精粉倒在案板上，加入豆油、白糖、香精拌匀，用温水和好揉成粉团，揶成块，搓成二个小剂子再擀开。\n2. 将面团包一个走龙馒头，搓成两头细中间粗的香蕉酥生坯。\n3. 将做好的香蕉酥生坯放烤盘内，再把蛋黄用筷子搅匀，用刷子往香蕉酥上面刷一层蛋黄，放烤炉内七八分钟烤熟取出即可。
