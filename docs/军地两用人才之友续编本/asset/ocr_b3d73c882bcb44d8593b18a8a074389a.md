# 仰焊方法

仰焊比较难，立焊都要困难些，因仰焊时熔化金属的熔池处于底部上，铁水由于重力作用有向下滴落的趋势，熔池不容易过渡到焊缝中去，焊接过程中易发生熔渣被前，焊道形成较窄等。

仰焊由于它的特殊位置，造成了焊接过程的不易控制，操作感到不顺手。<|start|>焊大电流、粗直径焊条易造成熔池大，出现焊肉较大熔池。熔池体积太大，铁水下滴的可能性越大，因而不易控制熔池的形状。运条动作不好掌握。如果采用过大的电流也不行，小电流虽能控制不易熔穿，并容易产生夹渣和气孔。为了克服以上问题，在焊接时对焊件平台方面可采用一些措施：仰焊时对口要紧与平齐。立焊不同，仰焊缝的坡口角度比较大，一般为60°～80°。坡口角度大，运条活动范围大，焊条可以按其坡口内自由地摆动和变换位置，对口间隙一般为2.5毫米。坡口宽度应小些，一端来加强焊，这样容易焊接。

施焊时，都需焊接始终应注意在熔透的情况下，尽可能的缩小熔池面积，避免熔化铁水下落。应该要求在操作时，尽可能不作横向覆盖焊，焊条尽量轻微抖动，在保证熔透的情况下，焊渣尽可可能的快，防止根部烧穿。焊接电流的选择为：比平焊时小10%左右比较快，可比焊时大10%左右。焊时要保持短弧顶弧焊法。开始引弧时，用长弧预热起
