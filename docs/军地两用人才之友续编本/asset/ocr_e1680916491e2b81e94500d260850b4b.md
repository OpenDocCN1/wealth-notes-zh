# 炸山药卷

# 原 料

山药1斤、豆沙馅4两、熟面粉2两、白糖2两、豆油3两。

# 做 法

+   1. 将山药洗净，上笼蒸烂，取出晾凉。 2. 把山药剥去外皮，捣成细泥，加入熟面粉拌匀，撑成长条，下成二十个小条松条。递一个包上豆沙馅（二钱），再擀成一寸二分的长形，即成山药卷生坯。 3. 勺内放入豆油，烧热时把山药卷生坯放入勺内，炸成金黄色时取出撒上白糖即司。

质尝棕浅
卷粗细均匀，色泽金黄，软酥适口。

# 炸春卷

# 原 料

精粉1斤（包括面馅5钱）、猪肉丝4两、绿豆芽1斤、菠菜2两、韭菜2两、水发兰片1两、酱油8钱、味精1分、精盐2分、芝麻油3钱、豆油3.5两。

# 做 法

+   1. 将精粉倒入盆内，用七两水加入一分为精盐倒入盆内，用面杖擀，至面不粘手为止。 2. 勺内放入肥油，把肉丝放入勺内烧炒，加 Betriebs 酱油，炒熟取出。 3. 把绿豆芽去根，菠菜洗净切成段。韭菜洗净切成三段分。兰
