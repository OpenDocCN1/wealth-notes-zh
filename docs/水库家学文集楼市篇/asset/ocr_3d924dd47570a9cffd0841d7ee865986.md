那时候，年轻人的想法都是天天加班，写论文，很职称。只有一些中老年屌丝，大单位里坐了十几年老正班，百无聊赖的才研究房子。研究房子有个麻烦，就是要到处看。那时候绝大部分家庭都没有车，一般人没时间到处跑。而这些人板凳可以在上班时间溜出去，开着单位车，办完单位事，中午去工地看看。

房子这个东西，看多了就会产生贪欲。我印象中，单位里的很多老板就是在那个时期入市了。中环线外，一万多的别墅也敢买。从此尝到了甜头，一发不可收拾。而那些年轻人辛辛苦苦十年，终于熬到了副高副调，回头看房价，内心只有种白忙了一场的愤懑。

# ## 有置业需求的人注意观察（2019.03）

上海楼市将在四月底五月初开始逐渐趋向中好了。按传统习惯，四月上旬是不买房的。325政策已经过去三年了，当初被卡的购房需求陆续出关了，逐月增加，到2020年底为止。2021年后进入正常期，今后一年半，要把近三年积压的限购人群购房买力，全部释放出来。这个力量是比较大的。

# ## 没有产权的单位福利房

万谨慎，不要太当回事。

近来，有几位网友私信我，一线城市某些特定单位入职后，工资很低仅几千元，但有一个一户福利房，无产权，不解职可以一直住。这个事情，要谨慎看待，我是不感兴趣的。说白了，就是单位给你付了房租，从你的工资是扣了，毫无意义。你不能享受城市发展红利，还会产生温水煮青蛙的心态。过渡期可以将就一下，但不要当真了。

# ## 穷人投资

不能只看便宜又漂亮。（房住不炒）

业内很多习以为常的思维概念，在很多时候切入市的人心里，好像是砸破石蛋。新手比较多的观点是，浙江江苏靠近上海的这个地方（不点名了），房子又大又漂亮，靠海宜居，交通发达，单价也便宜，九千多，买下来，过几年翻一倍出手，多么唛。

我真呵呵，你以为求家开银行的，随便抢钱啊？这种靠对野外地而起漂亮小区，给谁住？没年轻人住，都是老头老太养老的。因为附近没有高薪就业。这种地方，都是旅游区，以前倒不埋的，土地多的事，要是房子卖的好，要多少有多少。你去抢钱？呵呵，你是被人抢了！

# ## 不谋全局，不足以谋一地

（房住不炒，依法依祺）

现在的各省市县的楼市，眼花瞭乱，精彩纷呈，各地都有绝招，一般人基本理不清头绪。你的任务是，看透底层代码，不管表面是什么花样！

中国楼市就像是一层层的梯田。京沪广深是最高点，中西部小县城是最低点。如果你是农民，你会怎么办？肯定是层层分水。

一线灌饱了截封住，继续往二线灌水，灌满一层封一层，确保所有的地块都有点水，这是全局。
