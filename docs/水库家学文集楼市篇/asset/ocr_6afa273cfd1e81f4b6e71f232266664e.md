# 为什么首套房要求全国无贷？

一是规避金融风险。如果改为本市无贷，那么，不少人就会有办法在各大城市贷款4-10套，首付三成。银行资金就会大量集中到楼市，相当于银行为房价背书了。如果房价垮了，银行倒霉，个人最多是上了黑名单。无所谓，用几子的微信钱包，也可以生活。

二是兼顾公平。有条件多买房，多贷款的人，往往是富人。富人就占据了更大的金融资源，加剧贫富差距。正常的社会管理，是要减缓贫富差距的。

三是遏制购房需求，减缓房价上扬速度。如果富人通过户籍迁移，社保缴纳，夫妻离婚，人才引进等各种手段，在杭州，苏州，北京，上海到处购房，到处贷款，市场需求就会井喷，供不应求，房价就拦不住了。

所以，我们要采取处女贷的政策，每人只能享受一次，兼顾公平。

# 你接受加装电梯吗？

蓝鲸财经记者工作平台：国务院今日就老旧小区的改造举行吹风吹风会。住房和城乡建设部副部长黄艳在会上表示，老旧小区的加装电梯正全面推进，去年已加装万余部，目前进展顺利。各地实践中经验就是必须因地制宜，一个楼门一个方案，一栋一个方案，群众工作要做细致。假如你是老旧小区一楼住户，你接受加装电梯吗？

菜菜：加装电梯后，一楼住户是最大的吃亏者，噪音无休无止，采光受影响，应该给与补偿。例如允许拓宽近电梯的空间，搭建一间房。

# 城市发展和衰弱的原因(房价)

一个城市之所以建在这里，是有原因的。主要有几类：一是边关防御（嘉峪关关）。二是河运商贸聚集（柳州）。三是海运物流中心（广州）。四是特产资源（普洱市，大庆市）。五是省会。六是文化科技中心（例如现在的松江大学城）。七是旅游休闲城市。

一个城市的价值，完全是以其专业的容量决定的。当这些城市的主业不复存在了，这个城市就会迅速衰弱。

保定原来是省会，现在不是了，立即就不如石家庄了。
