# 大国经济

一方面经济遇冷，一方面需求得不到供应，当中被卡住了。现在，各地普遍人最大的需求是：房子，教育，医疗，养老，偏偏是都不够。经济遇冷，我们为什么不启动内需，扩大供给呢？这事情就该说说了。

+   一，住房（省略，保号要紧）

+   二，教育，包括幼中小。

如果扩大供给，就涉及到各省之间，教育经费和教育用地指标的转移。这事得要决心啊。

+   三，医疗

我对绝大多数医生充满敬意。至少，我们每个人都是医生接生出来的。当然，我对乱塞给我中成药的医生，充满鄙视，气s鸟的。

医疗成本很高，但为了维持表面低价，把博士教授的挂号费卡到了两片大白菜的价格，这是不合理的。（公众号：财宝宝讲经济|医院怎样降低服务质量，大排长队，三分钟一个患者，五花八门搞创收，患者都慌，不揭穿而已。为什么不搞按质量计价？呵呵，不敢谈。

+   四，养老院

这个涉及到法律环境。养老院肯定是经常死人的，纠纷多。我们现在是谁闹得凶，谁厉害。一旦遇到事情了，有关部门就希望养老院腾出钱，花钱买太平，这个最省事的。但是，民营机构是成本核算的，扛不起啊！

# 我内心深处的经济学

每当我看到，地铁里年轻人挤在车厢疲惫不堪的下班，回到又破又乱的小出租屋，忍受低质量的生活，我都会想起我年轻时候的苦。我经常会有一种冲动，打土豪，均贫富。为什么富人可以在大house里，而对人只能老婆小里挤？太不公平了。

但是，我内心的这种冲动和血性，很快会冷静下来。因为我知道彻底的均富是什么样子。我从住在大企业的家属区，非常漂亮，干净整洁，窗明几净，物质丰富。那时候，真的是均富，虽然一堵之隔的农民很穷，但关我什么事嘛，只要是有编制职工，工人福利就是二室一厅，企业中层和副高职称三室一厅，其他都平。

这种彻底的均富，实行了几十年，效果并不好。我的部分中学同学，顶替进厂，我亲眼看到他们，上班磨洋工，偷小东西，干活偷懒，辱骂领导，这些都司空见惯。企业不能开除职工，只要8个小时待在车间，工资奖金一分钱不能少。干多干少没区别，会打会吵会撒泼，领导倒过来怕你。这种企业有多少竞争力，大家心知肚明。内部的浪费和低效，早已经见怪不怪了。

当时，我们之所以能够维持高质量的生活，完全是行业垄断的结果。工业刀刃，工业品价格奇高，农产品价格奇低。这种剪刀差，抵消了工人的低效，结果是，一堵之隔的农民穷爆了。他们的生活状态只能用贫穷来形容，当我家乡十代开始用洗衣机的时侯，他们还在不怎么干净的小河里挑水喝，只是用锅简单的清洗一下。

不是每个人都喜欢辛苦劳的活。我们逼当的容忍贫富差距，是提高效率的无奈之举，如果你不努力工作，也可以在地级市分套房子，那么，社会上的懒汉就会越来越多。
