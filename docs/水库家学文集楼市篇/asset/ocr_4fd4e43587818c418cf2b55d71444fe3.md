# 微观经济学的笑话

这是我所在工厂里亲身经验的事情。

总经理设计了一套表格，要管理企业的每个流程，要求相关的员工每天或者每三天填一次表格。

很多部门对新增加的工作量非常反感。统计数据是一个事常耐心细致的工作，需要花大量的时间。于是，部门经理层层下转，最后落到了一个刚入职的实习生那里，他就每天胡编乱造，写几个数据交上去。

因为各个部门交上来的数据，互相矛盾，乱七八糟，然后部门间就开始互相吵架。总经理觉得不行，应该再聘请一批人去，监督这些数据是不是真实？

总经理花了很多钱发现，有些数据确实是不真实的，胡编乱造的，然后就去捉原来的部门，相关生产部门喊冤枉，说新来的那些人为了邀功请赏，吹毛求疵，抓住一些工作失误，故意打投诉举报，不服，要求重新调查。

干活的人和审核的人发生了矛盾，老板觉得应该再抽调一批人去，判断他们到底谁说的是对的。他们抽调的是公司管理层的人员，这些人平白无故多了一个很复杂的工作，只能是加浓点干涉，一肚子怨气。错是原来的老同事错了，但是我和老同事关系很好，新来的人为了邀功请赏，骂着不肯他们，最后的结论就变成，各打50大板。给问题也没解决。

本来无中生有的事情，结果越搞越复杂。用工成本越来越高，部门之间互相不服，互相制造矛盾，造成了企业效益下降，成本上升，互相变成了打口水官司的事情。最后总经理怒发，算了算了，不搞了。

# 微观经济学，根本没月

微观经济学的本质是管理人，通过员工的为员工工作，提高企业效率。这个事情说起来很美好，但微观经济学的前提是，有一套规范的制度。商人在这套制度下研究如何提高效率？

实际上，目前的企业环境根本不存在这种制度。民营企业遇到的问题是非常非常的复杂，任何环节都可以卡你一把。你想按规则走，你可能就走不通。你绕开走，就会产生非常复杂的后果，搞不好就把自已搭进去了。最后，就变成了一团乱麻。

你制定了一个很好的工资考核办法，但是这个方法触及了很多工头的利益，他们就会联合一些人给你捣蛋。你接了一个大的订单，他们跟你说，你拿他们一点油头都没有。或许你可以开除他们几个，但是，你的订单可能就无法完成，造成了更大的损失。

你设计了一个非常好的规范采购流程。但是，具体操作的人为了吃回扣，故意给你找麻烦，这个办法也不行，那个条件也达不到。你不可能再雇佣很多人去调查他是不是吃回扣，事实上你也调查不到。
