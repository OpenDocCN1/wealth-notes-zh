北京父母如果有点头经济头脑，可能是贷款买了个大面积房子，现在四百万了。这就是两个世界了。如果北京父母没有买房，就是干存钱，也没什么，因为自住几十年的老破小可以卖钱，四百万，加上存款一百万，一个五环首付就来了。

农村父母的贫穷，并不是他不勤劳，而是制度设计+选择错误。也有一些安徽人在上海买了商品房，十万元一鉴，送上滩户口。比在北京开门的小老板好一百倍了。

外地城市大学生也买不起，您怎么说？那是你家贫卖。如果你家把原来的房子全部卖掉，全家在北京挤一挤，首付还是够得到的，只不过挤了一点。

# 我说的是个别

外地大学生可能比京沪居民更加贪婪。

外地人想的是，老家什么都不动，农民别墅，县城130平米或者省城二居室，给父母，自己想办法在北京搞个90平米，美滋滋，买不起就买，天天骂。不管什么事故，全部算北京房价贵。

京沪居民不是这么想的。存款和老房子，全部给儿子拼个中环首付。老夫牺牲自己，和子女挤一挤，顺便帮忙做家务。

# 房价变化的基础性原因没有变化

各种措施只是增加了一些交易障碍，延缓了变化的速度。货币，就业，财政，民企，人口流动，消费心理，根本没什么是大变化。我实在想不出，房价凭什么独善其身？你是专家，你先吹！

# 对房东征个税，暂时会有利于京沪房东，不利于三四线房东

理论研究者痛宏观理论的问题，都懂一个道理。说能卖不能转嫁，谁承担强谁，谁承担弱。水电气，房租油艰厉害，无论如何去加，给总用户就行了。你随意。

京沪住房稀缺是有目共睹的，不要说什么有个房子几个月没租出去了，那是叫价高了，或者是季节性因素。开春后，新大学生就来了。

房东征收个税后，第一反应可能是把负担转嫁出去，涨价10%（我强烈谴责京沪）。那么，房客会不会接受？大概率是会的。京沪过这么多年来，一直都在涨房租，大家不也接受了吗？我在2003年，租西城区一室一厅带厨卫，五层楼的三楼，1500元。不知道现在多少钱了。

三四线城市。例如平顶山，牡丹江，市场上有非常多的房子租不出去，因为没有什么外来需求，再降价就不划算了，因为装修有损耗。房东也不会得了，只能空买。如果房东涨价，租客会得换一家问问。市场上很多空置房，换房很简单。谁涨价，谁空置。

三四线城市，区域面积小，换来换去，不会对租客上下班产生太大的麻烦。京沪广阔，区域粘性太强，换个地方，上下班多出30-40分钟是完全可能的。

个税是全国立法，地方不能轻易挑战，例如沪环保护区县，增值税和个税开拆，那沪京公司马上就会蜂拥而入，前段时问，影视圈的人跑到号称优惠的小地方注册个人工作室，最后呵呵一场。

大城市的租赁房是利润。对于刚储，税收调节的效果是微不足道的事。你对92平米，面积大来，加税50%，也不会有什么太大的作用。

建议：京沪进一步扩大住房供应，大力建设低价房，以成本价租给外来务工人员，例如北京上海市中心，月租1500元一套，让大学生，农民工，住的起，住得好，体现大城市的人文情怀。到那个美好时好，房租就涨不上去了。回头再对房东征税，就不会伤及租客利益了。
