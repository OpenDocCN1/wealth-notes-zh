# 1-10 亿富豪的居丝亿豪

为什么富人的日子，和我們差不多？

我和几百亿的富人不熟悉，我超级熟悉 1-10 亿身价的居丝亿豪，他们的房子车子比白领好很多，但是日常生活真的是差不多。孩子兴趣班，和你差不多。吃的用的，也是大超市和菜市场。他们说起来好像挺有钱的，实际上，也是很抠的。有个土豪家装修别墅，和装修公司分屋必争，建材家具家电也要求性价比，微波炉就用中低价位的。

居丝亿豪的资产全都是在企业里，这个大楼，那个机器，吃饱也不能吃，住也不能住，还要背上很多贷款。有些白领家庭年收入五十八十万，很多亿豪家庭，生活费还达不到这个程度。有个亿豪，去海南过春节，就是租个一室一厅，还要房东打个 98 折，送一罐液化气。冬天在海南，日常吃饭也是老夫要自己买，自己做饭，平时也挺节约的。

社会上有很多人，以为土老板都是野奢级别，挥金如土，实际上基本不可能。绝大部分土老板都有银行贷款，现在 6% 利率算低的，以前都是 12%。你在 KTV 消费 2 万，还要搭上传 12% 的利息，想想都不划算。

当然，对居丝级亿豪的消费状况没有建立起来，所以基本漏洞在普遍白领里面。

# 男人不赚钱，女人养男人

四五线城市逐渐出现“男人不赚钱，女人养男人”的家庭现象。

最近，陆续听到好几起这样的事情，偶然中也有必然。例如，张大姐老公原来是小厂的人事兼行政，现在失业好几年了，全靠张大姐在武汉做保姆养活全家，为什么呢？

一，县城 4050 男，就业不容乐观

很多县城男是城乡户口，一直在本地的体制外工作，例如做个小生意，在某民企当个小干部，或者靠某事业单位做个十年期的合同工。由于各种眼因，这些男性在四十岁之后，还真就失业了。例如羊肉汤锅开不下去了，小老板就失业了。某民企倒了，或者和老板发生矛盾，一气之下辞职了。本来在是一县中医院或城里，当个合同制人员的，过五十岁了，人家不要了。

县城男，年过四十，没有专业技能，再就业，只能去建筑工地搬砖了。一般企业是不喜欢些人的。干活不行，搞事情，讲道理，一查一查的，很难管理。他们以前干了二十年的体面岗位，自己内心也无法接受体力活。实际上，中年男的身体技能下降，应付一下老婆还要求可能还行，突然去干体力活，真不行了！

于是，很多中年男就自己骗自己，不急，再等等，说不定有哪个公司招聘行政经理，人事主管，我就合适了。一等两三年，彻底家里蹲了。不过也好，可以照顾一下家里的孩子老人，买菜买，做饭，打扫家务。

二，四十几岁的妇女，就业容易

社会上有大量的基础岗位，例如保洁，保安，家政，餐馆打杂，服装店营业员，小超市理货员，有点文化的，还可以去企业打卡。越是素人，工资越高。营业员两三千，扫大街捡废品三十五，会计四干，保姆六千，月嫂八干。

三，经济安排

这种城乡户口的男人，可以前收入还行，存款加拆迁，或者靠定点父母寄养，往往是在县候买了漂亮大户型，精装修，住的很舒服。男人就产生错觉了，以为自己是中产阶级了，不可能再去工地住板房，下力气了。家里还有十万八万的存款，可以杠几年。
