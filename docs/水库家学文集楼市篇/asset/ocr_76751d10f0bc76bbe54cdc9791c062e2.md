站，也没有多少土地可以卖了。那么土地在哪？在郊区，特别是远郊区。例如距离成都武汉80公里的地方。

这些地方，原来就是一片农地，缺乏就业和配套。你盖满了房子，卖给谁？一般居民是很难长期住的，杭州的临安有多少高新就业？去市区上班又太远。那么谁会来买这些远郊区的房子？对了，长期投资者。

但是，长期投资者是有要求的，那就是有效益，总不能亏亏去买个郊区房子。短期行情不好，可以接受，市场经济，总有起伏。但如果长期不好，别说临安了，就是京沪郊也，照样没人要了。你住在延庆，能够找个多少钱的岗位啊？

# 出口，到了关键时刻

外销厂，订单不是我们说了算。例如苹果手机，它下单多少，我们还真没法管。

民企的低端，大路货，大批量产品，我们已经没什么优势了。例如鞋厂，服装厂，低端陶瓷，中档档电子产品等，已经跑了不少大厂子去越南了。现在说减工资，拼出口，是不是太现实了，工人也不能答应了。吃惯舒服饭了，你让我不吃，怎么可能呢？

高铁，华为，大飞机，是我们的目标，但总有个发展过程。

现在，最顺手的出口是，民企中高端产品，冷门产品，非标原件，优势非常明显。

一，我们有丰富的加工经验。虽然农民工到处流动，但是企业老板和车间骨干的技术功底还在，产品质量靠谱。

二，我们有非常先进的设备积累。加工，大部分是靠设备。

三，我们有供应链产业集群。冷门，备件，很快可以组织原材料。

四，我们的电力水资源，交通设施非常好，可以快速出货。

现在欧洲的皇马甲，基本是在义乌卖多。这个属于冷门物件。交通专业服装，需求固定，不会出现大规模突发需求的。这次意外情况，越南的出货优势就特别明显了。越南可能不一定有完整的原材料供应链。

我们可也要看到，暂时的优势只是因为别人没有准备好的，并不是比越南性价比高。皇马甲再复杂，也不会比越南的耐克运动鞋，摩托半设备，一旦人家准备好了，单子就跑了。这种情况在一点一点发生，滴水穿石。

我们怎么办？留住中高端单子。华为，高铁肯定是好，但这种项目是长期利好，打入欧美市场，过程有一定的不确定性，也不完全是我们说了算。我们能够做的是，现成的生意不能丢了。

我们的中高端订单，质量速度都好，就是成本高。怎么办？千方百计的压成本，除了工资不减，其他方面，决不打乱筋的减，事物是会变化，越南的劳动力成本也会上升的。此消彼长，尽可能争取战略时间，等到华为高铁，在国际舞台一统江湖了，再对民企小老板那个，也不晚啊。

# 委内瑞拉是怎么回事？

很多屌丝最喜欢说，委内瑞拉了。我就给你大概讲一讲。

委内瑞拉国内基本没有什么制造业，他们的经济模式是，出口石油，换回美元，美元进口各种日用品，然后在国内以本币交易。石油价格暴跌，石油收入还不够石油的生产成本，这就彻底绝望了。没有美元了，市场上也就没有东西了。原来还剩下的一点商品品，价格暴涨。

有关部门就给老百姓发钱，补贴涨价，差距越来越大，物价越来越高，还是买不到东西。后来，委内瑞拉就把货币印到了十亿一张，当做饭烧给总部销售，效果还可以。
