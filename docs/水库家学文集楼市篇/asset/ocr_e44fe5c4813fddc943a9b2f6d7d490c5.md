# 我们能学新加坡的住房制度吗？

超级人口大国学新加坡的住房制度，会遇到哪些问题？

新加坡人口六百万，和浦东差不多，陆地面积大致相当于 2/3 个浦东。新加坡是一个相对均衡社会。我们不是谈绝对的平均化，但至少到最后 10% 的人的托底，那是完全没有问题的。新加坡区域狭小，经济发展没有明显的区域性差别，也没有城乡差别，各个社区的经济发展水平基本是接近的，不会存在东面的人集中涌向西南，或者南面的人集中涌向北面。所以，中国楼市遇到的问题，新加坡基本遇不到。

新加坡主要采取的方策是，富裕人口买商品房，中低收入人口排队，等国家发一套超低价的房子，这个房子只能住，不能用来牟利。

如果中国也实行这个方案，那么会出现全国各地的大学生集中涌向京师，等待分房子。全国各地的贫困人口也会集中涌向京师。京师是没有能力承担全国 13 亿人住房保障的，可能的办法是：

+   - 一是按照户口分类，不是京沪户口就不能享受。
- 二是不按照户口分，但是设置复杂繁杂的条件，表面上每个人都有资格，实际上一个安徽到北京打工的人，可能几十年都等不到这套房子。

目前前面看，我们好像是在往第二条路上走，北京大概有近 840 万外来人口，实际需要的住房差不多是 250-300 万套。假设解决了这 250 万套，估计第二年需求是 600 万套，1000 万套，因为全国各地的人都来了，怎么办？

所以，大国住房制度，不可能去学习小国的，国情不同啊！

# 德国房地产为什么这么稳定？

德国房地产市场好像是全世界唯一一个长期稳定的楼市。（首都柏林，均价大概是不到人民币四万）

近几年，有很多专家纷纷研究德国楼市稳定的原因，写出了五花八门的文章，包括德国采取的各种措施。其实这些专家都是 250。稳定楼市是非常简单的。问题是，稳定楼市之后，财政收入大幅度下降怎么办？

德国一向注意姓利国，德国的财政收入大部分是建立在制造业国际贸易税收的基础上。中国搞制造业的人，只要听说是德国的机构，都是脱不行的。所以，德国不靠房地产税的成功，也能够实现经济的稳步增长。

我们内地有多少城市能够拿出全世界都亟需的口气，高科技产品？很少县城在房地产税费之前，基本就没有科技类工厂，最多就是个化肥厂，啤酒厂，制糖厂。靠这些少，根本无法支撑有关们日益增长的办公经费请求和教师加工资的要求。城市面貌日新月异 的资金来源，也无米下炊。

上海在 90 年代没有发展房地产之前，每年的城市建设费用低的可怜，城市面貌几十年没什么大变化。南京，合肥，这样的华东省会，有多少很棒的高科技工企业，能够拿出全世界皆需的东西，你或许可以说出一两个企业，但是就这些企业能够支撑全省的经费迅速发放吗？

下决心把房价控制住，是完全可以做到的。房地产市场全面冷却，房地产上下浮 200 多个门类的关联企业可能就陷入困境，部分地方政府收入越来越困难。你说怎么办？

建议：经济类学者，加强理论研究。而不要像个专家那样，什么热闹什么，看上去好像满嘴高论，实际上自己也在买卖套套。要静下心来，综合考虑房价，财政，企业，农民收入等问题内在联系，为国民经济的健康发展，积极贡献自己的智慧。
