# 楼市和股市

楼市不会出现股市那种暴涨狂抛！

因为市场上没有机动筹码。上海家庭，限购两套，外地已婚，限购一套。这是基本居住需求，没有机动筹码。一家老小去住宾馆，把房子卖来买去，赚差价，这是不可能的。那么多家具怎么办？孩子读书怎么办？一家老小搬个家，是多大的动静？买进卖出，税费损失呢？

说完理论，再说实际。我周围的家庭，好中差都有。中和差的家庭，就删除了，他们没有什么多余的房子，儿子结婚还没差呢？不可能抛售房产，恨不得再搞一套。

富人阶层呢？更不可能了。只要不是卖出倒闭，谁会卖房子亏银行啊？

既然没有抛盘，要让房价下来，只有一个办法，有关部门一年增加四十万套，把市场塞满。问题是，

+   - 一是不可能有这样的用地指标。

+   - 二是开发商不接招。如果这样供地，价格下行，谁愿意开发？买了就贱，你当我是傻？

+   - 三是亏本生意的资金来源在哪里？民企亏不起，不敢干，国企票据保证国有资产增值保值，谁去干？

# 楼市，说白了就是有奖征税

正常情况下，没人愿意多缴税。但是，财政收入是要交支，不够使用麻烦的，怎么办呢？必须采取一个方法，鼓励你主动排队来缴税。

历史上，有很多老办法，主要给级别，给品级待遇，出一个万两，给你个三品候补，算是光荣耀祖了。或者给你一个专管戳，这一块地方的烟草归你经营了。

老办法不能搞了，现在的办法是，卖房子给你，然后把各种税费打包进去，用丈母娘监督你。不买？呵呵。没有女人给你约了。买不买？

# 深度老龄化社会和楼市的关系

有专家预测，2022年，新增就业人口就少于退休人口了。2025年，全国进入深度老龄化。不管这些数据是不是完全准确，但是，老龄化问题已经在敲门了。

老龄化是什么样子的？你去看看东北地和中西部乡镇就知道了，满大街的老弱妇妪，本地年轻人不多，还主要是体制内的。新增年轻人少，考上大学就跑路，挥挥手，不带走一片云彩。我小时候生活过的那个大厂宿舍区，惨不忍睹，到处都是撒洋样的老年人在散步。

为什么会是这样的？因为老年人的需求不多，吃饭吃药广场舞，唱胡头郭不花钱，其他需求几乎没有，各行各业没生意了，自然就就住不起来了。这就造成了恶性循环，越是老龄化，越没有年轻人，因为年轻人在体制外，接不到单子啊。

那么，年轻人去哪了？大城市，日本是老龄化，很多小地方直接送房子了，不要钱。但是，东京的房价还在涨，很多年轻人买不起房子，晚上在网吧睡觉。大城市人口多，年轻人多，生意就好
