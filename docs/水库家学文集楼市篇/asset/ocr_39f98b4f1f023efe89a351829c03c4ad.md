# 房价下跌有两种情况：

+   一是基础性原因，经济较差，人才流失，例如东北一些地级市。

+   特点是，量价齐跌，长期阴跌，幅度不大，但趋势明确，一年不如一年。

+   这种地方是没办法了，自住即可，不要想发财了。

+   二是行政措施原因。例如突然性的限贷限购。

+   特点是，成交量突然暴跌，价格止涨。一夜之间，排队的人没了。

+   但是，这个城市的经济基本面没有改变，只是通过行政措施，暂时剥夺了一批人的购买资格或者贷款成败，这种是假跌。

+   过几年，大家满足资格了，购买需求又会卷土重来，而且还聚挟了这几年多攒出来的存款，势头更加凶猛，而且是集中爆发性涌来。

# 郊区涨辐为啥这么猛

外环外唐镇周浦江桥卖 5 万多/平，而内环源漂亮楼盘才 10 万。

原因是，现在是购房者慌慌张张，抢上车阶级，大部分人手里的钱只够外环外摘个二居室，于是外环外就遭遇疯抢了。

而内环内新盘，千万起步，大部分是 1200 万以上，属于奢侈品了，买得起的人极少，涨得就慢了。

内环被低估了。

# 我对农村生活是有切身体会

我身上还有几个疤痕，是当年在农村睡觉，被床上跳蚤咬的。后来抓破了，留下了眉头大小的疤痕。

农村生活是非常艰苦的。割水稻，第二天，腿是直不起来的。打谷子，必须非常小心，否则手会被机器切断，每年都有。夏天害虫多，大田里打农药，简直是不说了，能够不晕倒回家吃饭那是高 technics 了，更不要说什么挖稻草了。这么好吃，农村还会有困难户吗？
