# 学术观点

美国为什么老是说中国破坏了国际秩序？

没有争议，我没有评论过什么，只是学术解释。

现行国际贸易秩序是美国在二战后主导的，各种贸易规则和纠纷解决制度，包括你看不见的底层代码，都是美国按照自己对世界贸易的理解进行设计的。美国对世界贸易的理解是，美国主导，分工协作，比较优势，大家要得再了。

+   1. 美国，一枝独秀，承包所有高科技，金融，维护世界秩序
2. 欧美日韩加拿，是美国的好朋友；负责高科技衍生品，高端商品等。
3. 中国等负责生产初级品，人多，勤劳，少拉拢，商业多，环保要求低
4. 俄罗斯，中东，南美，非洲等主打资源供应。

除了线的国家适合搞子，劳动密集低值产品，至少他们有钱，不需要生产新的麻烦。

这是美国自始至终追求。从1980年开始，大致上就是按照这4个模式进行的。中国是90年代初期才开始，2002年加入世界，全面进入了国际贸易体系。中国的世界贸易体系中分为几个发展阶段：

第一阶段是1978-2008年，讨好换飞机，生产资料加速，带动消费商品为主。通过近三十年的艰苦奋斗，中国的外汇储备达到了天文数字，国内一般群众的生活得到了极大的改善。人们的工资水平大大的提升，初级加工业已经能满足普通人日益增长的物质文化需求了。

第二阶段是2009-2018年，产业集团，抢购出口。这个阶段，中国形成了非常完备的产业链，不管是工资和恶劣的生产环境都赚了，而是高效配套产业链。一个打火机需要12个配件，方圆五公里之内就能把这12个配件凑齐，这样的反应速度，对于千万的市场需求，是非常有力的。例如，甚至突然来了个大型装箱的订单，基本上就可以搞定生产。初步形成产业集群的行业包括，纺织，冶金，化工，中低端机电产品，机械产品，还有大型组织加工业，例如富全球。生产效率得到了极大的改善，人们的物质生活水平还是可以提高继续的提升。

第三阶段是今后二十年，产业集群每年来的劳动力成本提升速度有巨大影响。对我们而言竞争的负面，北美自由贸易区，被迫非非，也勉强维持了生产线体系，所以我们的人口增长从原来的百分之十几，现在缓慢的回落到1.6%了。

经济走到这一步，中国必须要选择新发展了，2035科技进步大跨，概括起来就是六个字，海陆空，软电路。

2. 高铁
