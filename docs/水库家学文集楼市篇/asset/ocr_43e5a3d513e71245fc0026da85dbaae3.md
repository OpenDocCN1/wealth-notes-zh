# 我觉得，不会放弃车祸的

目前，劳动力市场，质次价高的情况，时有发生，都是不可言说的原因的。举例，很多建筑工地发生对冲之类的。但是，这事仅仅是黑心老板？肯定不是农民工制造漏洞：偷工减料，敷衍了事，工作安员而被扣钱？很多事情，我们无法深究了。

这些不可言说的原因，导致了农民进逃的赚钱了。但是，我们各行各业的质量怎么样？有目共睹。这个便宜，不会便宜了车祸的。

# 牛奶倒沟里的故事

大家有误解。

一种是滞销时间太长了，变质了，只能倒掉。另外一种是因为经济学原因。就跟前两年大田里的大白菜卖不掉，随便拿是一样的。

大白菜收到整筐运输到菜市场，成本很高。如果零售价和这个成本差不多，那收割就没有任何意义了，还要仓储费，索性送人了。如果没人来，只能是烂掉。

我们这里也有。广州花市，卖不掉的花，直接打烊，也不会送人的。人性都这样。
