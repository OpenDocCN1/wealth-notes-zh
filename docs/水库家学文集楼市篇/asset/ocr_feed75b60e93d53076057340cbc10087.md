# 互联网思维进入租房市场

长租公司可能颠覆淘宝。

互联网思维就是抢夺流量，赚不赚钱，可以先不考虑。公司直接把流量控制住，市场份额保生，再通过其他增值项目赚钱，就可以吃独食了。例如淘宝 qq 微信对一般用户是免费的，庞大的维护成本，靠其他项目抵消，包括广告，直通车，游戏，支付，微商，到处都是挣钱的项目。

长租公司可以通过大数据和 app，直接控制住消费群：身份证，银行账号，电话手机，地址单位，婚否，子女同住情况，一应俱全，还有 app 时刻联系你，形成牢不可破的消费依赖。

长租公司把租客和房源信息控制后，增值服务就多了。搬家，装修公司，婚纱，酒店，生活用品配送，生鲜食品配送，保姆清洁服务，育儿，幼儿园，补习班，买房置换，一大套的消费，完全可以精准营销和终身服务了，这个是海量空间。

长租公司控制的信息量，远远超过京东商城。京东淘宝只是掌握了地址和商品，名字也可以是虚的，性别也搞不清楚，推测客户需求是不太准确的。长租公司是直接控制了精确信息，房子住几个人，什么关系，身份证，年龄，什么时候结婚，老公什么消费档次，信用卡是金卡还是普卡，长租公司对客户换房间的原因和住户变迁信息变化，都可以精确掌握。

如果长租公司握住一百万套的市场份额，那些家电的家具冰箱洗衣机厨房三件套等等，完全可以控制相关的制造业了。这不是开玩笑的，任何一个制造业公司要达到这么大度的采购订单，直接跳楼了，股权给你一半也可以。

传统房产中介简直是个土老帽了，除了一个手机号啥，啥也没有。至于房租赚不赚钱，完全是个鸡毛小事了。

这盘棋实在是太大了。

# 北京房租价格的影响因素

在人口总数没有明显下降的情况下，租房供应遇到了变化：

+   - 城中村分流，大量租房被拆。

+   - 商住分流，被直接打断。

+   - 郊熟分流，严格限购。

+   - 北京旧房，卖给了外地人自住，不可能再出租了。

+   - 外地在京富人，被限购拦住了。

各种政策肯定是对的，我没有冒犯罪的意思。

但各种因素，在短期内，重复叠加，结果是吧新增和原有的外来人口，全部赶入了正规的租房市场，可北京租房供应量没上来啊！

建议：北京尽可能扩大可租的低价房屋。在不影响大政策的情况下，做一些变通嘛。
