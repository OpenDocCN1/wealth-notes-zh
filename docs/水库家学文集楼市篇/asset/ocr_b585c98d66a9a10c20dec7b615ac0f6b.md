# 防城港的房价贵吗？

上海正常工资是七千多，出租车司机大概一万多，市区内环线房价十万出头，松江区是五万。防城港工资三千应该有的，出租车司机六千左右差不多，我专门问过的。房价才一万，你说贵吗？肯定不贵。我看还挺便宜了。

房价低和幸福指数，没有直接关系。房价低，更不代表经济好。要是你在鹤岗，拆迁房单价，还不如一只烤鸭呢。
