2. 票号是潮业经营，相当于银行也大在味啤酒油锅。票号吸纳社会存款，大部分用于自家经营，放贷不多。主要经营界地汇兑业务。

3. 现代银行是董事会结构，无限吸纳社会股本。董事长总总经理本没有控股经，经常换人。山西人视票号为私产，是无法接受东家换人的可能性。非常反感银行制度。大鸿昀台后，山西票号的很多中层干部要求改为你行，被东家视为有异心，谋取私利，直接开除。

4. 票号是北方的称呼，栈庄是江浙的称呼，业务大致类似。

# 货币政策基本失效（理论探讨）

1. 继续增发货币，会导致高收入者更富，低收入者更穷。

上中收入人群非常聪明，已经完成了战略大转移，大部分中上阶层通过买房从银行贷了大量的债务，几百万贷得司空见惯，手里没现金了，只有债务。他们最希望的就是货币大增发，债务稀释。例如原来工资1.5万，慢慢涨到2-3万，债务就明显得缩小了，一百了。

大量增发货币会导致房价的继续上涨，而中低收入人群现在还在攒首付，手里有较多现金，债务很小，在大城市没房子或房子小。如果房价继续上涨，无房子是最大的吃亏者。房价涨一下，他们十年白干了。

2. 收缩货币增速，失业增加。低收入者受到的伤害更大

目前，实体经济不是特别好。大量的经济活动实际是围绕着基础建设开展的，就是修建铁路修电网之类的。如果货币收缩，基建相关行业可能会失业增加。中高收入人群，知识文化水平较高，即使在非本行业失业了，他们降低工资要求，再就业相对容易。

中低收入人群技能单一，大量的人其实没有什么特别技能，主要就是在基建工地摆摊，以及上下游行业从事体力劳动。一旦失业，很难依靠工作技能快速再就业。很多人可能会去当黄牛，开黑车，摆地摊，放高利贷，反而增加各种冲突和纠纷。

3. 货币政策维持现状是很难的

正因为现状不如人意，才需要调整。这么多年的货币中高速增长，已经积累了相当多的问题，特别是楼市暴利导致实体经济失业，亟待改变。

无法解决的汇率问题。留给我们的战略时间不多了，战略空间已经接近警戒线了（省略一万字）。

在货币政策中寻找对策。已经没有什么上中备选选项了，我们应该进一步发挥财政政策和经济的调节作用，通过积极财政政策，缓释货币政策造成的就业头痛问题，充分鼓励实体经济和科技创新，保持经济良好运行和提升经济质量。

1）进一步对实体经济减负减税。目前看，实体经济最大的问题是成本上升过快。国内市场是销售价格上不去，成本高，盈利低。国外市场是因汇率较低，出口价格上，越南和墨西哥的价竞争竞争力相对上升了。

国内工资是难以下降的，那么最快的办法是，在财税方面为企业进行一定的减免，至少让中小企业活下去，满足一定的出口创汇和国内一般需求。制造业减产过快，会导致物价上涨。

2）继续减免个税，提升居民购买力。

3）暂对非急迫进行行业的财政补贴，输血动力，保持工资短期内平稳。过去十年，企业工资大涨上涨，超过了很多中小企业的实际承受力，靠透支，透支了资金线的效应，小老板转向高利润的集资和投资，脱实就虚，坚持正税。

4）楼市严厉限购和高度重视，其实是双刃剑。一方面阻止了楼市继续暴涨，但另一方面导致无房青年买房更难。这个问题，各种看法都有，我不说了。以各地有关方部门看法为准。
