# 再说个悲剧变喜剧的逆袭故事

2002年，某单位的四十几岁的小干部，和女方属鸡耕头。当时没房子，就开了单位的车，晚上在郊外野战。不幸的故事发生了，被联防队当嫖客抓到了警察局。这事嘛，可大可小，降级处分，熬到退休也是可以的。

但是，这个单位是个小单位，没多少人，低头不见抬头见，这事瞒不住了，大家觉得相处起来太尴尬，小干部哭了一晚上，离婚，辞职，几天办完。人走了，也就没人管了。女方就私下裡說宣告，别人是造谣。

小干部出去之后，岁数大了，完全没技术，生活的不好。那时候，律师考试改革了，据说原来是考外语的，2003年后就不考外语了。他原来是中文系的，背书在行。于是，考了个律师。现在顺风顺水，成为很富裕的小小老板。据说，心里目前又会给娶了个小黄白。

而和他差不多年龄的老同事，别看当年幸灾乐祸，级别比他高，现在除了退休工资，就剩个抱怨了。

# 人生真的是充满奇迹

大家有没有见过2003年前，上班开汽车的？我见过。

那时候，一辆别克霍歌加牌照大概是8万，内环钱老破小是15万。我至今还记得我们单位这个老兄，他老婆是汽车公上税，可以优惠，他呢，数科书般的倒霉蛋，狗的一塌糊涂，学问也好，就是升不上去，老正科到了五十岁，万念俱灰，那时候是副处配杀档纳，正处帕萨特，可以开回家，他的同龄人都升上了，就他没有，心里那个难过呀！

于是，他一咬牙，买了夏款，当时大家都嘲笑他，吃饱了撑的。他家距离单位几百米，买个车子吗？车子主要是给他老婆开的，汽车厂在郊区，上班远，有了车，就开始骚包了，周末自驾游是必须的，还准备了各种烧烤架在后备箱。

玩了半年，出现奇迹了。那时候，房地产市场出现了，但新盘都是比较远，培平路现在是内环线了，当年可是遥远的地方，普通人没办法上班啊！所以，我们那时候还是喜欢市中心老破小，最好是西藏路，上班近。

他看中了，思路不同了，买了很大的别墅，在中环，我记得是3700元/平米，位置随便挑，这种别墅，当年没人要，因为农民买不起，上海人卖不起，周末别墅，平时在老破中，过上了幸福生活。

再后来，他拿到别头了，又买了几套，二成首付。现在他退休了，大概是十套满亮房子，而他的同龄人，一辈子把心思用在单位里，一门心思提升级，最后，两套养老院，悲剧的一比。

人生真的是充满奇迹。
