# 一辈子不想赚大钱，就留在小地方

亲案：我们从广州，回四线小城过年，很多本地人觉得在这里生活很好，空气清新，生活休闲，但我还是喜欢大城市，让人有奋斗的动力，在小城生活感觉就是静等耆衰老。

我劝本地的朋友，让他们自己即将毕业的女方留在大城市，根本说不通，他们认为大城市房价高太拥挤，有时候我也会迷茫是不是非得要大城市呢，你怎么看？

答：有关节门是希望你们回老家县城。你自己想的。

小地方是低价值重复，赚的多数价低。大城市是高价值重复，赚的多数价高。纽约的生活水平不比南昌好。

但是，如果你一辈子不想赚大钱了，那在小地方也很好。

# 货币学

过去二十年，凡是掏空父母买大城市房子的家庭，都是幸福的。

那些扣扣搜搜在银行存款的家庭，无一例外的悲剧了。

这就是货币学，十年前外地线100平米，现在也就是装修款了。找谁理论？

# 一线城市死奋斗赚钱的地方

一线城市，二线省会，三线地市，十八线小县城，区别不在于房价，而是赚钱的难易程度。

一线城市赚钱又多又快，举例，做中介抽样是2%或2.7%的中介费，在京师做成一笔，比在家做强5-10倍。其他同理，炸油条，开黑车，修马桶，小公司上班等。

一线城市是奋斗赚钱的地方，小地方房价便宜，但只是消费。

# 一线在物质享受上，没有特别优势了

梁得答地产下：一线城市在物质享受上，已经没什么特别优势了。吃喝玩乐，二三线不但不差，性价比甚至更高。

唯一不同的就是，同样是靠实力，一线的天花板比较高，你可以靠自己一个人走得更远，再往上都一样，实力关系都不能少，另外，京沪的医疗和教育资源更好，目前仍然有很大优势。

亲案：二线城市赚钱难，花钱是一样的！
