# 保姆比东家富裕

已经蔚然成风了。

王女士今年三十几岁，省会小公司，人事专员，工资五六千，偶尔加班。去年年底生子，月子中心花了三万，回家后，还请了个月嫂，8500 元/月。全家日子紧巴巴的，还要给保姆做好吃的，塞红包，生怕保姆辞职或者不尽心。

我家小区的垃圾工，表面看，工资四五千，实际上非常有钱，小区的回收垃圾，他可以卖钱的，具体收入不知道，反正听上海人门卫说，月入估计近两万。就这眼前的钱，没有一个上海人愿意去捡。他们习惯于在门卫室里，干干净净坐一宿，看着手机，月入 3200 元。其实，他们也不是什么拆迁户，就是 1-2 套老旧公房的遗次（包括继承所得），但现金很少。

上海年轻大学生，能够去银行做柜员的，就是人中龙凤了。大多数就是某个正规单位，基层员工，年入 8-10 万，岗位干净，打订单子，接接电话，穿擦亮衬衫上班。实际上，他们真不如那些电线杆，钻下水道的工人收入。我经常溜达出去吃点海鲜疙瘩，各种小餐馆里，上海小菜皮和外地包头工，成双成对，嘎夜啤酒，已经不计其数了。看的心酸了。

结论：虚头巴脑的研究生文凭，只能让你搞个基层办公室，想赚钱，还是学点真本事。

# 思路决定出路

我认识一个九十年代的省考状元，文科，现在某地城市的基层部门，四十多岁，当个小头头，聊了几句，我看他是的不得志。主要原因是，年入十万左右，职务也升不去了。想当初，他是全省第一名的殊荣，现在搞成这个样子，家里人对他失望至极，老家的十里八乡，把他当成书呆子的典型。

我问他的，你有没有想过转型？他很茫然。他说，咱们那个地方，经济不算太好，下海做生意，也不知道做什么。上也有，下有一没赚钱，今后的日子怎么办？我当时没说什么。

其实，这种人就是没思路。先借他省考状元的头名，去京沪的家教培训中心，或者网课辅导 APP 公司，挂个业务总监的名号，年薪五十万起步是肯定的。如果再有点业绩，年薪百万不是梦。毕竟，省考状元可不是一般人搞得出的。可惜，他根本不懂市场经济，一天到晚想着再往上爬一级。

# 京沪的收入

有个 90 平米的漂亮小区，生活水平就完全达到巴黎伦敦的白领水平了。不足是，食品卫生可能还差一点。优点是，你在欧美赚钱难，发展难，语言差，在京沪就没有这些问题。现在的焦点是，中下收入白领和退休工人，生活质量还算不算好。希望大家有机会在京沪生活定居。
