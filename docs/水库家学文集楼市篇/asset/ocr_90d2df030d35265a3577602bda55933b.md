# 当年，蒋经国在上海进行币制改革

为了稳定金圆券币值和汇率，采取强力措施，维护物价，打击炒作，各行各业都限价，最后还是彻底失败了。为什么？我家是亲身经历。

一，这么多年来，各路理论专家的那帮解释。

蒋经国抓到杜月笙的儿子，国际赌商，直接逮捕。杜月笙一怒之下，举报了礼耕熙的儿子（扬子公司），惊动了宋美龄。宋美龄痛失爱女，去找杜月风，蒋介石这个特大坏人，为了自己私利，博得美人一笑，两边和稀泥，蒋经国彻底失败，灰溜溜的滚了。

这个故事，我看的都笑昏古七了。这些专家，不知道是不是含赃红？

二，接近真实的情况。

当时的旧上海进行了严格的限价，蒋经国亲自上任，确实把物价降下来了。但是，蒋经国的经济管理水平实在是太差了，他不知道，商业活动应该给商人留点小利润。蒋家福口，他的做法，表面看讨好了低收入人群，实际上导致商人大面积亏损。商人没法干了，就混日子。三个月后，上海供应短缺，什么也买不到了。

这时候，只有两个办法。

一是放开物价，宣布币制改革失败。

二是老蒋拿真金白银来补贴物价，让商业活动起来。当时，老蒋在军事上失败了，也缺钱，拿不出补贴，反而被迫继续印刷金圆券养活几百万吃皇室的人。货币飞速增加，各行各业的成本超过了蒋的限价，商业彻底崩溃，老百姓连德饼和面粉都买不到了。

迫不得已，小蒋承认失败，退出上海滩。物价重新暴涨，金圆券因此彻底失去信誉，变成废纸。
