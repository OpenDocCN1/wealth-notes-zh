+   4. 真正的看点是，外汇贷款，但目前这个项目，国内是严格审批制，不是想做就可以做的。如果这个项目做起来，那就有意思了。

# 如何辨别老夫人是不是有钱?

某菜，我女朋友的父母，经营一个大企业，但我丝毫不知道：她到底是是有钱没钱？也可能是正牌白富美，也可能是负债累累。怎么办？五百元红包已付，求指导。

# 如何创造财富?

专业人士，也不开公司，如何创造财富？

专业人士最喜欢在熟悉的环境中，赚熟悉的钱。但这个套路，大家都知道，你赚不了大钱，无非是变相的加班加点。大家要想想办法，把有限的资源，更大限度，批量变现。我说几个例子。

画图纸的小王，他丈母娘家里开桩社，原来也是画图纸的，时间长了，找不到门，因为有图纸啥格略高一点，具体高多少我不知道，假设多两三万，他就花了一两天补了一套图纸，再接烂团，就交差。也不知道怎么搞的，反正，他请假半小月，回来发了个好年。

律师小王，生意一直不好，一天到晚，愁眉苦脸。2008 年，劳动合同法台了，正常情况下，员工起步企业的官司，索赔两三万元左右，律师费两千。老律师没兴趣。小王实在是没生意，就找点企业培训。小板多帮门啊，一张牌最多收费五百元。小板帮一番也不贵，场面糊糊；但是小板还还是觉得心疼这五百元。非要他去讲席费搞点警察。后来，小板领陆续续都遇到了起诉，正好有他的名片，就请他当年去法律顾问，一年一万，电话答疑，打官司另算。

他一口气接下了 200 家企业，当天晚上就去买了个内环边漂亮房子！当然，他不可能服务好两百家企业，第二年人家也不请他了。没关系啊，他那个房子现在价值一千万左右，就干了三个月。

我再说个专业人士怎么做大钱的？
