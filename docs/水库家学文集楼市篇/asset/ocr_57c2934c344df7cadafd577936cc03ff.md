# 我们这一代人，为什么可以逆袭？

九十年代初期，南巡讲话前，上海各区基本没有招聘外地大学生的做法。我熟悉的这个局，全部是本地人，少许是转业人员。

本地人大多数是中学毕业或者中专，工作后自学个杂牌夜大专。
本专业的全日制本科生只有一个。
转业进单位，其他专业的本科生大概 2-3 个，例如汽车工程师，药剂师等。他们不做业务，就是打杂。

与此同时，区级的小学教师只要求中专学历，高中老师大专就够了。
区级三甲医院，中常年骨干都是大专生为主，本科生也有一些。研究生几乎没有。
1994 年，浦东开发，开始招聘大学生，上海市区的孩子基本不愿意去，大多数是崇明金山青浦这样县里的农村孩子来，但也不多。人数不够，就开了新口子，外地中级职称，外地生源本科生对口，都可以招聘，给户口，分房子。
1996 年，这个单位的本科生人数，达到 20% 高。这个比例刺激了其它区县，于是也开始慢慢招聘外地本科生了。
北京也是这个情况。1999 年，我去北京市顺义区出差，区里那叫一个穷啊。区级单位的办公楼都是农民小院的感受。秦始皇已经是宝贝了。我去的时候，他们单位一把手接待我们，用塑料大盆盆，端上来一盆新鲜大枣。我从来没见过大枣，不知道那是什么水果，午饭是高规格招待，去一个露天大棚，吃红鲳鱼。
当年就是这么个情况。
