# 楼市没有什么技巧

楼市的主要问题是：

+   1. 买卖时机。就是大势判断：冷冷，热热，高潮，低潮。我给你说一下不就好了？

+   2. 二手房注意事项。这些网上也有，你多看几篇就行了。

+   3. 税费筹划。不同情况，不同税费。你要是理工科的，度百度搜索，一天就会了。

+   4. 地区选择。同事同学讨论一下，我也可可以。

+   5. 投资目的。战略投资还是五年投资？不同情况，不同思路。

楼市是生活经验类问题，不要简单问题复杂化。主要是多看大方向。太精密的技巧只是个别职业选手的打法。我算十年买一套，犯得上都错吗？大不了，找个人间洞就行了。
