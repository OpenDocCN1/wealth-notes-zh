# 为什么京沪高价房的涨幅很低？

豪宅楼盘太少了。超过一千万的房子，十年后涨到两千万，基本已经没人接盘了，在整个中国，买得起两千万房子的家庭，奢侈品局，且基本都已经被限购了。与此同时，低价房的楼盘多，多的一比，特别是老公房的一室户，价格就像是瞌天顺，十年涨 5-8 倍是很正常的。

高价房和低价房的功能是不同的。高价房是保值和自住为主，低价房是投资筹码和暂时居住。高价房业主很少卖房子，除非是特殊原因，例如大笔投资，移民和破产。低价房业主，天天想卖小换大，交易特别活跃。

客户买大房子 的目的是：自住，保值，炫耀和传家宝，不是炒作，没必要限购，且有可能在这个领域慢慢放开。
