# 郊区别墅的增值和流动性

十年内，肯定不如马路对面的单元房，不是理想的短期炒作工具。

原因是，总价高，地段远。别墅的实用性和舒适性好，面积大。买别墅不是为了迅速增值，是为了家族的长远发展，适当的享受，更好的生活。

当然，如果把眼光放远到二百年后，别墅肯定是绝好选择。举例，世纪公园附近的叠屋和联排，在 2000 年的时候被人嘲的无地自容，现在简直是人间接壤。

上海会不断发展的，现在，浦南的漂亮小区已经有人接受了。当然，这是有钱人的游戏，你就不必考虑了。
