# 在岸人民币和离岸人民币

为什么汇率不同？

+   1、在岸是指国内交易，离岸是指境外交易，主要是香港新加坡，和内地经贸往来较大的地方，
他们有人民币兑换需求。例如回内地，先兑换好一些人民币，免得打车都找兑了。
2、在岸人民币汇率，央行说了算，6.8 左右，你同意不同意都没关系，你认了就是了。
3、离岸人民币汇率，波动非常大，经常和国内人民币汇率不同。
