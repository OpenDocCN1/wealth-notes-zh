# 当年 325 政策突如其来

早上十点钟发布的，没有任何预告。有一批人非常倒霉。他们当时已经满两年社保，有购房资格，一家老小正在看楼盘，甚至已经交了定金，只是没有网签。政策一来，顿时被拒之门外，被暴出的目瞪口呆，天旋地转。这些人继续熬了两到三年，今年才重新获得购房资格，喜极而泣。

# 关于防止商品房涨价的建议

+   不一定都对，大家批评。

1. 减少购买人群，外地人社保延长到十年，本地人必须工作满五年。
2. 彻底取消房贷，必须是现购房。
3. 不得开展房抵贷。
4. 一对夫妻，十五年内只能买一套。离婚也不行。
5. 开展房产大普查，人均超过六十平米的二套房家庭，有关部门直接征收一套房产，原价补偿。
6. 购房资格要严格审查，必须优先满足住房困难，例如单位领导集体讨论同意，获得过年度考核优秀等。

# 京沪有房的幸福感为什么高？

这个问题不是房子原因，而是工资，在京沪，公司发给你的收入，是暗含了三千元的房租的，同样的工作，京沪的工资比淮海高三千元是常态。

在小县城，营业员工资 2500 元是很正常的，因为她家就在附近，晚上骑车年 20 分钟就到了。在上海，商场营业员没有 5500 块，她基本是过一波下一波，说走就走的。

这个三千块钱，就是房租加成。如果你有房子了，这三千元就是你的纯利润。

对于抢夺的人才，更加厉害了。公司为了尽可能留住你安心工作，给你发工资，要考虑你的买房支出，月工资可能会多个五千八千元，举例，同等岗位，京沪工资比杭州高 30%是正常情况。
