# **中国经济，稳中向好**

是绝不允许出现失业增加的。

现在不比 1998 年大下岗了。上一次下岗，只不过小夫妻要兑钱了。女工身体好的去餐馆打工，端端菜，洗洗碗。男的去私企做做保安，司机，厨师，搞点副业，例如会计兼职，技术指导，装修，婚礼拍摄，再不行还可以做做中介。

现在不同了。大中城市稍微像点样的中产家庭，大多有房贷，一个月 6000-20000 元是普遍情况。这种资产负债表结构，是绝对不能出现失业的，甚至收入下降 10%都不行。我问过几个京沪码农，普遍是月供两万以上，三万也很正常。现在，码农大多数是 50-80 万收入，收支平衡，暂时安全。

但是，今后二十年，如果发生失业，那是绝对不行的，至少老婆要翻脸离婚了。夫妻本是同林鸟，老婆不能顾顾洞。

一，减税减费，帮助企业渡过难关。不管是不是高科技企业，只要不危害公共卫生，就要让他活下去。但你觉得可能吗？省哪一万字。
