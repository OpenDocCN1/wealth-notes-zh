# 有哪个自媒体敢预警？

答：因为冷静的旁观者不敢预警。我的微博，这么多年，从来不赞成p2p，各种私募，各种烂币，但我也不敢预警，只能泛泛而谈，甚至不想多说。原因：

+   1. 这些公司，表面上有合法手续。我要是说他们有危险，可能爆雷，我会迅速被这些公司告上法院。这涉及到这些犯罪嫌疑人的核心利益了，非得你拼命了。

+   2. 监管部门，都不愿意说某某类型公司，例如那几个高息平台，风险巨大。我有老有小，为什么要去惹官司，搞的自己精疲力尽。

+   3. 经济领域，也有舆论监督的问题，但这事情没法多说了。因为没有标准，哪些话可以说，哪些话不能说，我也不知道啊。要是惹事了，至少已经2人会陷入无穷无尽的打官司状态，官司输了可能会巨额赔偿，我何苦呢？

+   4. 相关利益者，会无休止诬告我。很多人已经入局的，不希望看到平台在自己入局期间爆雷，会自觉的站到犯罪嫌疑人那一头去，对你无休无止的攻击举报，我也没能力去管他们。

+   5. 出于无奈，我在公开场合也只能说：有钱还是给女儿买个小房子吧，至少踏实不会骗人的。其实在私人场合反复反复叮嘱亲友，千万不要去套的。

# 拼多多上市

拼多多的业务模式本质是地级网络化。多花时间少花钱，降低消费快乐，节约小钱。这种模式确实可以吸引大批的低收入人群，他们喜欢最便宜的。但也有问题：

+   1. 如果再出现更便宜的网站，这些贪便宜的消费者立马就走了。这是完全可能的，淘宝要是恶搞一把，拼多多不一定扛得住。这就导致了盈利压力太大。我从来不去淘宝，因为淘宝送货太慢，我只买京东，送货快。

+   2. 无限度追求低价，会导致差”帅“博的层出不穷，理论上合法，但实际成为笑话。我经商多年，我坚决排斥低价低质量，东西不好，即使卖出去了，回头客也很多。长途看，很难收回建厂成本。

+   3. 最后祝贺拼多多上市成功。这是一群聪明人，抓住了时代机遇，对个人而言是巨大成功。

# 去杠杆为什么这么难？

压缩贷款很简单，有关部门画个指标就行了。难的是，压缩谁？

目前，贷款结构大致是：

+   1. 房贷。基本上压不下去了，房子都造出来，不给贷款，那就卖不掉烂尾了。地方形象太难看了。

+   2. 开发商，大开发商可以境外借钱，发股发债，压缩的结果只不过是增加了建筑成本。小开发商就是三家凑钱，自有资金，银行贷款，民间集资，把地压死了，民间集资一下子就要暴起来了。民间集资的背后，往往是p2p。你看头疼不啊？

+   3. 国企事业单位，那是亲儿子，承担了铁公鸡的大任务，关系到GDP和城市新面貌。
