# 战略转型的关键期

> 为什么我们强调 2018-2019 年是战略转型的关键期？

今后两年，本来就是处于经济周期下行阶段的前夜（下行是为了更好的上行，是正常情况），居然又碰上了中美贸易纠纷，可谓是双重挑战。

然后，中美贸易达成新的贸易谈判约定，中国将进口美国大盘的商品，原来说增加进口 2000 亿美元，现在没有说具体的数字，但是应该不会是相差太远。中国老百姓除了住房以外，其他的消费应该是没有太剧烈的增加。如果中国市场上增加 2000 亿美元的进口美国商品，会出现什么情况呢？首先我们要研究这两千亿美元商品组成。

+   1. 能源。中国在过去几年并没有在能源领域出现明显急短缺，而且能源不具备长期储存的条件，所以增加的金额应该是减少其他国家的配额。那么其他国家和中国的贸易关系，会出现略微的挑战。这对中国其他领域的出口，多少是有一点影响的。当然我们相信，有关部门有能力有信心解决好这个问题。

+   2. 金融领域开放，特别是放开对美国保险业的准入。这一块主要是，对其他保险公司高管收入产生压力。对员工就业的影响可能并不大。张家不做李家做，保险也是劳动密集型行业，美国 人进来了，也是要聘请其他公司的员工的。

+   3. 农业。这里面包括，小麦，大豆油，土豆，肉类，禽类，水果等。这对中国农业的影响应该是比较大的。小麦和大豆油，中国本身确实需要进口，但是肉类禽类水果的进口将极大的压缩中国农产品的销售市场。中国消费者每年吃掉多少水果，金额和数量，相对是稳定的，不可能变成吃很多很多的水果，你吃了一斤昂贵的美国车厘子，大樱桃，梨果，可能就少买两斤中国的苹果桔子了。那么一部分农民的就业和收入，应该是会受到一些影响的，就需要靠其他领域，增加就业机会来弥补。

+   4. 制成品开放。这个主要集中在在民用科技，电子，机械等领域，例如汽车领域。中国的汽车产业工人数量是比较庞大的，进口汽车，又便宜又好，国债比还难，含贸易顺，美道，咱们得静静看。不能说没有影响。这就使得这些企业可能会有一点点的裁员，或降 低工资。

+   5. 强调专利保护。这个说白了就是增加科技类企业的成本。美国赔着款钱，这些专利费的支付将变成企业的成本。这些成本并不一定能够在市场上让消费者买单，更多的是企业自己减少利润或者内部消化。
