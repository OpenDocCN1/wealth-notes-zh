# 纯理论研究，不是投资建议

上海青浦大虹桥板块，有国家级重点区域的巨大可能性。

中国城镇化发展到今天，暴露出一些具体的问题，有点两难状态。如果人口继续往三大都市圈聚集，经济效率是最高的，但是会带来大城市病，主要是人满为患，交通堵塞，房价上涨，一房难求。

如果平均的西面筋，依托省会城市建立10-20个中心城市，那么会出现不均衡情况，有的省会城市，例如杭州南京，辐射带动能力比较强，合肥西安或太原，对周围省份的带动能力不强，经济发展慢一点。

这些年，我们创新了发展思路。在大都市圈的附近造一个副城，既满足了依托大城市，加快经济发展的传统手法，又把一部分非核心功能迁出来，以此满足宜居大城市的国际要求。中国经济有三个大都市圈：

北京，雄安新区。

广深港澳，大湾区。

上海，下一轮的重点区域和制度安排，谜底尚未揭晓，但已经有端倪：江浙沪一体化。最近几天，嘉定青浦和浙江江苏的省领导头，已经开始纷纷开始安排打通告了，这是一个非常不得了的信号。

江浙沪一体化，不是书面理论，必然有一个具体的制度安排，重点区域发展，我个人的看法是，大虹桥所辐射的青浦嘉定松江。看中之重，可能是青浦区，它处于三省市的空汇点。

松江区是市区内，和浙江江苏均无联系，并且距离大虹桥有点远。

如果以嘉定区为中心点，主要面向太仓，昆山，和浙江没有一丝毛关系。

只有青浦区，符合江浙沪一体化的中心点的地理位置，同时对接江南，容易获得江浙沪的认同。

如果江浙沪一体化发展，必然在上海要有一个协作发展示范区，我推荐青浦区。
