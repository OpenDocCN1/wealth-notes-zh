# 我稍微解释几句

我看到，大部分股民对“股权质押和公司回购”完全搞不清楚。我稍微解释几句。

+   1. 股权质押，是个人行为，和公司资金无关。股东，把自己的股份抵押给银行，贷款取出来。

+   2. 公司回购，是公司行为。用公司资金（包括贷款，债券，融资，各种资金），把公司的流通股买回来。

+   3. 股东有没有钱，和公司有没有钱，完全两回事。很多时候，公司账上有很多钱，但不能发给股东，因为没有经过企业所得税和个人所得税，也没有分红决议，大股东只能眼睁睁的看钱散。
