# 区域性楼市的价值

完全取决于本市高薪岗位的密度。

北京是个住住不太舒服的地方，吃的也不好，空气也不好，交通堵的不像话，地铁挤的沙丁鱼，房子贵的高潮，但北京楼市是最有价值的地方。因为中国最好的高薪岗位都在北京。
与此同时，你去看看北戴河，承德山庄，生活好是好，但附近没什么机会，房价自然不高。你要是回到靠山屯，两百米大房子，常年空关。村里没收入啊！

# 京沪广深房价

和平均工资没关系。

京沪每年的新房销售 20-30 万套，二手房大概是 40 万套。大部分是旧换新。中老青年朋友以置换+贷款，买大面积。年轻朋友是靠父母卖掉老房子，首付个外环线小二层，市区老破小。京沪广深，没有人靠平均工资买房，实际上也买不起。

# 平均工资和贷款的关系

100 万贷款，月供 5500 元（不精确），400 万贷款至少是 2.1 万月供，就算你在流水上搞点花样，家庭月入 3 万是必须的，否则，物业水电气都麻烦了，更不用说教育医疗和生活成本。

贷款 400 万，首付4装修+税费一般是 250 万，合计 650 万。在京沪，大概就是一线城市的老公房的二层，近郊漂亮小区的小三居，例如松江区五万多单价。

家庭税后市月入三万多，在京沪已经算是不错的了。夫妻两个体制内的，估计是勉强达到。体制外的，税后能够合计达到月入四万，估计是不多的。吹牛的不要拍扛。

结论，大城市高潮人群决定了房价，和平均工资没有什么关系。
