# 房子买在哪儿很重要

某同学，大学毕业后回老家了，这几年一直在微信上炫耀他家300平米大别墅，鄙视我的市区老破小。

前不久他要换房，和我聊了几句，才知道，他的这套二手房真正能到手的价格，远远不如我的富扬二村38平米的老破小。

这么多年，他算是白干了。

2000年后，努力没有一毛钱的用处，关键看你房子买在哪儿！

# 没有房子，你的幸福放在哪里？

有人认为，妥妥的宇典里只有房子，忘记了人生的幸福。

没有房子，你的幸福放在哪里？

你老婆在别人家里坐月子，你就幸福了？

如果一个男人连老婆孩子的吃穿住都无法解决，你和幸福有一毛钱的关系啊？
