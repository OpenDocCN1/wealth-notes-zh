# 楼市见底的标准

住宅土地卖不出去了，陷入僵局。

大中型开发商一般都会养几个人，专门研究地价。即按照现在的行情，什么价格拿地是有商业利润的。他们就算的非常准。如果某市土地多次流拍，说明房价偏低，地价偏高，开发商没办法做了。怎么办呢？

+   一，财政割肉，大幅度降低地价，满足团贷户的合理买房需求。

+   二，房价上扬，给开发商留出成本和利润空间。

+   三，不卖地了，没有新房供应，爱咋地吧。

+   四，大量建设廉租房，共享房，财政出钱补贴，今后再倒贴物业费。廉租房的素质，苍天可鉴，哈哈就不说了。

# 投稿：我为什么去买了一个商住楼？

商住楼缺点：不增值，税费高，水电贵，卖不掉，缺点一大堆。

商住楼优点：收益率是住房的 2-2.5 倍。商住楼只有住房 40-50% 的价格，租金还给到同面积住房（因为可以注册公司）

我的情况是：彻底跟购房了。养老金是企业水平，不高的，存钱又怕毛了，理财也没这个水平。

于是，我买了个商住，没有指望卖掉赚差价，我也开发票给企业抵扣，就图个租金。

内环线 100 平米商住楼，七楼有电梯，租给一个头条小公司，现在大概是税后 8000-1 万元月租。我的想法是，就当领个平均工资吧。
