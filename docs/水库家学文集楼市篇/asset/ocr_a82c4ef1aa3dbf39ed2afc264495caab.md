# 屌丝要娶人了

两万元的貂，一天一万的五星级酒店，贵不贵？

经济学上有个经验，如果这个东西，你喜欢，又低于 2% 的零花钱（总额），心里感觉就不贵。所以，很多看上去很贵的东西，总有人买，也有人卖，例如三千元一斤的茶叶，一两千的酒，几百元的烟。

你去看看京沪有几个大商场，9 逛商场，几千元到一万的商品，特别畅销，例如三四千的头发送风枕，一两万的四面吸尘器。至于家具城，更有意思了，一个桌子一两万是普遍行情。

所以，贵不贵，完全看你的心情和公婆有没有实力
