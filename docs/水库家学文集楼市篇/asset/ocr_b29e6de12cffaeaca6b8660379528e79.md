# 重庆房价为什么永远是涨幅最低？ （2017.12）

很多人只是在表面上研究，例如供应量大，工资低之类的。其实，重庆市的工资至少是南京的七成，但是房价差了四倍。为什么？我说个严谨版本。

重庆模式，不可复制。重庆市是直辖市，但是地域面积8.2万平方公里，接近江苏（10万平方公里）那么大了，上海是6千平方公里，直辖市和平常省的区别，是有三大优势的。

直辖市的土地是全市调配，换句话说，如果南京市中心要加大建设，可以用苏北潜迁的指标，那么，南京市的房子就可以源源不断的造出来，要多少，有多少，根本不会涨了。

省级体制下，各市的土地指标是不能互相挪用的。实际上，南京市不能使用镇江市的指标。这就导致了稀缺性，如果南京市土地紧张，也没办法了，只能眼睁睁看它涨到5万一平米。而扬州可能也就是1-2万，宿迁也就是5千。

有些大V，拉人头去重庆买房，我一开始就在看笑话。京津沪，面积很小，各区发展水平差距不大，挪来挪去的可能性，基本没有。

# 不要去重庆炒房 （2017.12）

重庆的老市中心可能将是一个逐渐被废弃的地方，重庆经济的未来是在坪口的北面。重庆，老市区的经济地位，是地理和历史特殊原因造成的，而这两个原因，现在已经在不存在了。

重庆经济起源是航运。古代，货物通过水运进出川东的门户。李白出川，就是走重庆。历史上，这条路就不好走，需要在湖北通过纤夫拉船。但当时，重庆和成都对外不通公路铁路，只能走水运。所以，重庆的老市区核心，就是朝天门码头和碚南门码头。

到了清末，大轮船只能在宜昌到头，通过小船转运入川。

解放后，长江大桥越来越多，重庆的水运，基本作废了。

而因为水运形成市中心，也变成了政府；放弃市区吧，有点可惜，继续用吧，太难受了。

历史上，重庆也就是个转运站，没什么工业基础。但是，重庆运气是真好。

抗日时期，国府内迁；形成了大渡口，九龙坡的工业基础，这给重庆带来了第一次的工业繁荣。抗日结束后，重庆又变成西部中等城市了，没啥花头。

六十年代，重庆又一次撞大运。备战建设大三线，重庆市又迎来了一次工业繁荣，什么钢铁，汽车，军工，航天，电子，通通来了。但是，好景不长，改革开放后，这种三线m工业，基本陷入大屠杀。而成都市为首府，越来越好。重庆长成在成都下，混的是王小二过年，一年不如一年。

九十年代，重庆又一次撞大运。三峡建设，这次把重庆拉出来成为直辖市，地位一下子高于四川省了。

但是，重庆的缺点是也独一无二，交通实在是拥堵不堪，无法忍受了。重庆就是几座大的山链接而成，人们在山里找个稍微平一点的地方，就搭了房子。这种规划，在以前叫交通的古代，勉强可以接受，重庆带修，是全国独一无二的职业。我到了重庆参观，才知道什么叫地元三万尺。

重庆的老市区，就是朝天门。我感觉，朝天门的货运功能已经作废了，大概也就是几个旅游照了。朝天门四周都是高峰不平的山坡。离开朝天门，道路极其难走。以前，人们坐摩托或者走路，还勉强忍受。现在，汽车社会化了，道路的关键词，拥堵不堪。令人绝望，一个小时走二三公里，算正常情况。而且是，时时刻刻堵车，没有高峰低峰。

与此同时，重庆市的北面，江北区长者路以北，比较平准。观桥桥像个进城关隘，千军万马进城则，五十年代后变成一座道，你撑不了别人的车，就算是优秀司机了。
