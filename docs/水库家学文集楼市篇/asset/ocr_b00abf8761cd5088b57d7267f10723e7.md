# 银行贷款是怎么审批的？

很多人说我有明明有钱，可以正常还贷的，为什么银行要为难我？其实你应该换一个角度思考。银行的钱不是审批人员个人的，他同意还是不同意贷款，完全是按照银行的规则来操作的。所以你要提供各种材料，让他能够在舒服安全的情况下，写出一个同意。他个人不承担责任。如果你这个材料也缺了，那个材料也缺了，你让银行工作人员很难。你跟他非亲非故的，为什么要替你承担风险呢？

# 为什么环沪富裕，环京穷？

为什么环京比较穷，环沪很富裕？

真正在80年代，上海周围的农村，昆局、平湖、威尔、吴江、常州等郊区也是很穷的。因为这是最乱之2号，吃地还是差一点，也有一些农副产品，包括一些水产品。

真正改变环沪的贫困区，80年代乡镇企业蓬勃兴起之后，环沪地区迅速富了起来。环京还是没有什么发展。原因：

+   1. 人员交流密集。上海的主体人群主要是来自苏南和东南地区，所以，这两个地区在日常生活和和上海的关系是非常紧密的。这为今后的经济交流打下了人材基础。北京的主要人群，特别是各行各业的工厂长，车间主任等，极少直接来自于北京周围几个县。

+   2. 京工业迁移成功。苏南和浙江主要是承接了上海的原来的低端产业，轻工业，比如纺织品、行业、小电行业、钟表行业，简单的机械加工，包括自行车之类的。北部的传统工业向周边转移的则很少了，因为北京本身也没有什么特别优势的传统工业产品，可以往外走的。京沪产业区的区别很大。

中国真正的经济腾飞是在02年以后加入了世贸。主要的出口项目就是传统工业产品，包括纺织品行业，珠三角边际主要是贵格港活动，轻低纺织为主，上海周边主要是以轻工工业日用品为主。

+   3. 从历史上看，北京周边几个县并没有承接到北京的轻工业产业，所以，也做错过了市场是清朝时十余年的贸易空间。

+   4. 北京的优势并非在传统工业出口，无力带动周边地区。

改革开放，在经济领域主要就是轻工业的国际贸易，但北京本身并不定一个轻工业出口为主的城市，也并没有什么明显的外贸优势，更别说不上带周边几个县了。而重工业高科技产品，在改革开放初期，整个中国都很难拿出有竞争力的产品，所以北京也就不可能带动它的地区。

+   4. 技术特殊，复制子交通，北京北靠山西和北京，有群山阻隔。主要障碍的就是地理性。北京的市中心地高居地，远离沿海港口，这给以上海经济所限，还在客观上也不利于北京东西的工程经济向周边农村去输出技术的发展。

当时，上海工程师到浙江和苏州来技术领导是非常常见的，叫农民星期天工程。是每两个工之之后直接坐火车出发，晚上8点钟到农村，第二天一大早，晚上坐火车回上海。他下个星期天，把上周末遇到的技术问题解决掉。他们利用在在上业的工作时间，运用一些技术状况实验，然后把结果带到乡下去。他们当时会一次乡多下工厂的工当相当于在上海市一个月的工资，相对性非常合，客观也可以实现。
