+   2，那些不务正业，资本运作做赔情的，不要管了，照赔就赔。

+   3，转移资产，全家移民的，不要管了，那些人也自有办法。

# 民企的流动资金在哪？

中小规模的制造业民企，三五百万流动资金基本就够了。因为企业是循环生产，这里进货，那里卖货，左手进，右手出，几百万流动资金，几乎婉房租押一下就有了。如果这个企业不错，亲戚朋友，五家人凑个三百万，吃10%利息，司见双嬴。

民企缺的是利润。

民企现在的成本综合起来，已经高的离谱了。前两天，遇到一个生产 企业老板，在办公室里说，若说着就哭了。他已经快七十岁了，背了两百个职工，根本没有希望脱身了。熬到最后就是“老板中风，企业清算”的下场。

他干了三十年，攒下了近两百个中年工人，一万平米的标准化工厂房（附近房价两万元），各种大型生产设备，自己家里一套四居室，数量不详的企业贷款。看起来好像价值过亿，实际上，老屋丝一个，没有现金，吃饭都不敢点菜的。

+   1，无法裁员。都是老职工，干了十几年了。劳动法令让裁。天天养人，人浮于事。

+   2，无法变现。机器厂房都是卖不掉的。硬卖，税费奇高，只能抵押付利息。

+   3，每月发工资，就像是鬼门关。两百人，就是一百万现金。还有各种费用，不堪重负。

+   4，银行贷款，还利息可以，本金很难还清，因为变成机器厂房了。是个长期过程。

+   5，企业账面上还有点利润，但是变成了利息和税费，自己基本不剩到什么了，就是混个维持。

那个老人哭，是有原因的。他的下场是肯定的。老板身体一垮，企业没人管了，就是法院清算。他的子女根本接不了班，因为民企内部外部的矛盾太复杂了，都是见招拆招，空降部队根本本事搞定。

我说这些，不是什么喝衰，而是提供一些素材给大家思考。

中国经济稳中向好，我们欢欣鼓舞。
