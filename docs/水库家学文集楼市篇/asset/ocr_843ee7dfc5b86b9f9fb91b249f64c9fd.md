# 站在货币学高度

适时把握股市的发展趋势。

我不懂股票，但我懂经济学啊。现在，经济领域最大的麻烦是什么？实体经济缺资金，但银行贷款发不下去，双方互相干瞪眼。

为什么会出现僵局呢？大公司没有抵押物。A股上市的公司，基本都是实体经济的精华企业。这些企业贷款，无非是股权质押。目前的麻烦是，不但贷款发不下去，还要收回贷款，因为股票跌了，质押权极度伤害。

实体经济要发展，就业要稳定，GDP 有发展目标，但是银行也有工作纪律，现在卡在在抵质押坏可节了。怎么办呢？最好股票涨起来，什么都解决了。银行可以顺利发贷款了，实体经济拿到钱了，GDP 也上去了。

# 我们的经济发展

是否存在极力挑剔的。这就等于提前暴露了。

省级财政资金，实力超级雄厚，远远强于各地市。省级财政，名义上是为全省经济发展布局谋划，不分远近。但是，关键点布局在哪里，区别就大了。举例，全省新设立一个力量最强的妇产科医院，服务全省群众，你说放在哪里？全省试点优质中小学，你说在测试点？基本都在省会。

这就导致一个老农民都明白的道理，说起来是服务全省，但你高得近啊，肯定是你划算。重大项目是全省资金投入，但是产生的边际效应全都在省城了。高新岗位人群聚集在省会，产生了大量的消费力，经济发展越来越好。
