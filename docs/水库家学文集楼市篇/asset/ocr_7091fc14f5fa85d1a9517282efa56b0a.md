# 住屌丝小区楼王里,啥感觉？

单价七八万的京沪屌丝小区，都会配置几套单价十多万的楼王，或有总价是人家家两套的土豪户型，以此拉升档次。前几年，我虚荣心膨胀，干过这样的事情。我买了套单价是别人1.5倍的楼王。

# 一，受不了别人的目光

我从来不承认这件事。但是，每当我去物业、保安办公室办事，总会遇到一些其他业主。人家投诉的时候，顺带问我，你是不是也遇到xx问题？我说，我回去看看。结果，保安大嘴巴说：人家买的是楼王，没有这个问题。顿时，好儿双羡慕嫉妒恨的目光，像是匕首一样刺来，我落荒而逃。

# 二，阳台大的不像话

我那个阳台，比人家两个客厅加起来还大，还是四四方方的。我想申请违章搭建，所有业委会成员都反对。他们封闭阳台，我是同意的啊！

# 三，装修公司拿我当猴大头

这个小区，貌似你最有钱。不宰你，岂不是天理不容？

# 四，在外面经常被鄙视

我去申请宽带，人家一查地址，就来一句，你们小区最近插号优惠啊！

# 五，非常孤立

我遇到的问题，人家不存在。很难处理。呼呼了，也没人听。

# 六，性价比确实高

同样的产品，户型，位置，面积，气派，赠送面积。如果搁在豪宅小区，估计还要加价20-30%。

# 京沪置换，遇到插奖难题

现在，京沪买房都要‘验签十插号’。假如，我把老房卖了，凑出五百多万首付，最后没摸到号，两头落空。这可怎么办？

答：目前是插号售楼，这是普遍存在的问题。但分几种情况。

# 一，插号不难的郊区楼盘

+   1，宝裔育枪多金，郊区盘。2，和周围楼盘比，也不便宜。这两种情况，你放心大胆的插，区别只是选房先后，肯定买的到。插号首选，售罄六成就不错了。

# 二，明显发泡利得楼盘，插号中签困难

地处市区，至少中外环地县。（例如闵行环外紫线附近），单价比附近二手房便宜。这种楼盘是房产商无奈之下，利润降价。它会吸引全城屌丝插号，有便宜占，像干啊？就像是北京车牌，最后中签率很低。说白了，你就要当这个是个正常事，就当是春节联欢会的摸奖。

这种楼盘的特点是：没有明显的售楼处，售楼小姐就是雪大门的。一问三不知，最好你赶紧走，别耽误我玩手机。这种亏丁卖的房子，早有公司内部大量人员打听听了，对于慕名而来的散客，开发商没有一毛线。连杯茶都没有。
