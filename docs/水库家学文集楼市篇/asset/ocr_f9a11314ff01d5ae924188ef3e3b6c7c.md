# 我家这些年，乱七八糟买了很多房子

我家这些年，乱七八糟买了很多房子。喜欢了就刷卡，住了几次就不去了。现在想收拢一下资产才发现，很多房子根本是无法变现的，只能眼睁睁的交物业费，把钱交成了砖头。

+   1. 风景区房子，幻想自己归隐山林，鸟语花香。住了几天才发现，吃的不好，除了猪肉，啥也没有，百无聊赖。

+   2. 避暑山庄。都是山区，交通困难，上去了，就下不来了。

+   3. 冬季度假村，就是三亚附近，物价很贵，没车，景的不行。

+   4. 沪郊别墅，面积太大，价格太高，没有换盘侠。

+   5. 写字楼，增值太少，纯粹是自忙一场。

+   6. 商铺，经常性空关，没人租啊。

+   7. 工厂车间房，租客经常性拖欠房租，很烦人。

+   8. 最好的是，上海市区的中小户型，秒拍。

# 房子太多了，很烦心的

真的，我经常接到电话，你家要交物业费，停车费。我一般都反问一句，你是哪个小区？

一套房子，涉及到的日常缴费项目大概是8-10项，包括水电气之类的。除了物业费可以一年一交，其他的真是乱七八糟。如果你有10-20套，分散在全国各地的房子，你基本是别想好好过日子了。如果你还痴心妄想，要出租赚钱，那是在经营一个全国性连锁店了，烦得不得了。
