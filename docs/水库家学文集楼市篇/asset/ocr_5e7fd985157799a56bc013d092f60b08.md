# 北京房租暴涨，和燕郊限购

多多少少有点联系。

超过 3500 元月租，年轻白领为多。婚后两个选择，一是继续北京租房，二是退北京租房市场，在燕郊买房。公交车每天来回三个小时，混的好可以开公司的车，来回不到两小时，所以每年还是有几万人会退出租房。

燕郊限购后，把北京租房市场每年自然减少的几万人，彻底关在租房市场内。租房市场，只进不出，遇到今年的毕业季，又是十几万人进入，房租市场的压力，可想而知。

# 为什么 2003 年以前，京沪房价低？

因为那时候，外地大学生人数很少。扩招的第一批大学生是 2002 年毕业，当时这些大学生大多数来自小地方，根本没有房地产意识，大家还没反应过来。等 2003 年以后，大家发现，没有户口，有社保也可以定居，2007 年后，小学生借读也可以了，外地大学生醒过味了。
