# 四，贫富差距

现在，西欧的富人已经低调到你看不出来的程度了。北欧的个税，最高超过 90% 了，已经达到了市场经济极限了，再搞就是全面国企化了。

贫富差距的问题在哪？穷人不能逆袭。为什么不能逆袭？因为欧洲的劳动法已经苛刻到，一般人连开个公司的欲望都没有。

# 为什么西欧不可能产生淘宝？

# 一，知识产权

淘宝怎么起步的，大家都知道。反正全世界最便宜的名牌运动鞋运动鞋服都在淘宝。这要在欧洲，活不过前三集。省略一百字。

# 二，小作坊体系

现在的淘宝，背后是大规模的小作坊体系。小作坊基本上不怎么交税的，在沿海企业学会技术的打工，回到村里，几间房子，几台机器，几个亲戚，开工了。很多小工具，塑料桶，小家具，神奇面膜，都是这么来的。

这个欧洲是不可能的。环保，税费，选址，劳动法，每一件事情都会让你无法承担。

# 三，网络支付

欧洲不喜欢网络支付。因为他们的银行卡支付，支票，已经非常成熟，大家觉得没什么不方便的，没有彻底盈来的想法，也不想花钱搞建设。

# 四，送货体系

欧洲最贵的就是人力，劳动者工资不高，但是雇主的成本很高。大规模的送货体系，根本玩不起来。他们国家的邮政包裹系统，属于公务员序列。

# 增值税，在制造业，实际上是工资税

举例，你给我一捆竹仔，2000 元。我拿一些小工具，千方百计做成工艺品或日用品，价值 22000 元，增值了 20000 元，实际上就是我的劳动收入。增值税是 20000 元×16%=3200 元。剩下 16800 元，我要交个税社保。七七八八下来，到手一万多一点，就不错了。

# 经济学大 V，不是那么容易冒充的

经济学有很多基础性质，这些逻辑是非常拗口的。例如财政收入的组成。你可以百度复制粘贴，但是，你有没有能力改写成口语？这就麻烦。如果你不深刻理解掌握这个术语的内涵，你是不敢改成口语的，因为很容易就写错了，成为笑话。

前段时间，说我国债是财政收入，引来一大群黑丝的嘲笑，认为抓到了我的错误了。按照黑丝们淳朴憨厚的打口辟思路，借来的钱怎么可能是收入呢？但如果你是真写过经济学论文，你就笑不出来了。因为国债真是财政收入。

再比如，央行的会计账和企业的会计账，借贷关系是相反的，一般是人是无法理解的。

真正的经济学大 V，不是简单讲讲俏皮话，预测涨跌，写一写学区房政策，而是把经济学底层逻辑，按照口讲讲出来，你一听就懂，而且永远不会忘记。
