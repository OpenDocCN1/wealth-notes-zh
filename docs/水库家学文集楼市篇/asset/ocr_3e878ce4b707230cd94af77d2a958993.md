这么大的厂，内部管理人员十几个，每个人都知道具体情况，特别是采购部门，生产部门，销售部门，财务部门。这些人在离职前，和企业多多少少有着磨，说翻脸就翻脸的。一翻脸就会去告状，什么都告一遍。

你在账面上少缴税了，就会被这些内部员工讹诈，甚至是敲诈勒索，买来一大堆麻烦，很多老板做大了，想来想去也就算了。如果真的那么好搞税，会计早就失业了。

3，几十个人的企业，看情况了。如果全都是亲戚的，可能最搞点手脚。如果是外人为主的，基本也就不搞事情了。

# 为什么在市场经济条件下是不可能彻底打击富人？

市场经济是一个个企业家，披荆斩棘，赴险踏智做出来的。生意失败了，全家住桥洞，富了，全家住别墅。这是市场经济对风险的代价。

如果对准富人进行无情打击，就打破了风险补偿的平衡机制。大家都不动脑筋了，你说怎么办就怎么办，安全第一，就像98年大下岗前的那种搞法。

如果再走回头路，聪明人还是活得下去，我可以做医生，做护士，做老师，通过自己的劳动特长，己结各实力方人物，到关系户家里里吃个鸡腿，卖几块红烧肉。

但很多不那么聪明的人，可能就只能拿36块钱的死工资了，连个自行车也买不起了。

# 税收，对财富的影响忽略不计

财富的本质，不是绝对值，例如几个亿，几百万，而是你在经济社会的排名。如果有一套什么听上去很厉害的税收方案，可以让居民们放弃逆袭，彻底死心了，这就是富人们最喜欢的方案。99%的所得税，等于把阶层固化了，这多好啊！大家就按照原本来做事。

只要你爬不上来，我就永远压你一头。

大家都没钱了，物价也会降低，日子照样好过。

# 富人大多数是聪明人

富人大多数是聪明人，就是有好商，市场经济的小偷，至少智商没问题。你不要鄙视人家是靠请客送礼的，你爹这么穷，也要找找自己的原因。如果把掌握企业经营技术的富人，敢于创新，不断进取的企业家强调掉了，经济就不会是这个样子了。

最富的是银行，但是他们不愿意搞支付宝，微信支付，因为嫌麻烦。银行的人即使做成了，也不见得立即加两级工资，做不成受罚倒霉了。只有企业家愿意碰码前行，无惧风雨，发明出微信支付，qq聊天。

如果讲到计划经济，国企想的是，通过审批，让别人做不成生意，我就一家独大了。至于产品质量，反正你也没得选，凑合凑合吧，至少不会死人。这也是咱们转到市场经济的最基本原因。
