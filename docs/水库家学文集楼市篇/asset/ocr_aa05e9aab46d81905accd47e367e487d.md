# 宅基地制度的利弊

该办法保证了农村大学生今后返回农村种地的时候，至少有个住处，但也有麻烦的一面，农民房的市场基本为零。如果农村大学生进入城市，就是两手空空了。

制度的初衷，据说 是防止农村二流子把宅基地卖了换酒喝，最后变成了流民。但搞笑的是，有关部门从来不担心城市二流子卖了房子变成流民。我也不知道为什么，农村人傻吗？也不能这样说。

农村宅基地制度建立的时候，城里还是计划经济，单位分配住房，所以，农民大学生进城后也很满意，咱当当的铁杆无房户，理直气壮享受福利房。现在，单位不发房子了，自己买了 太，农村大学生彻底傻眼了。宅基地制度和城市商品房制度，无法衔接，卡在当中的 985 凤凰男，既外不是人。大城市有宅基地，大城市买不起商品房。

大城市子弟，不管怎么样，大大小小总有个商品房。再贫的家庭，过去二十年也基本轮到拆迁改善了，京沪一套房子 300-700 万，老居民基本是白得的，这就对农村大学生产生了巨大的碾压。农村大学生能不高兴了。你觉得为什么吗？

# 停止房贷，会便宜了谁？

房价会下降一点点，但 还是价高者得。农村凤凰男有 120 万，富裕家庭直接拿出 160 万，你还是买不起，绕了一圈，富裕家庭占了更大的便宜而已。所以，房贷不是问题的原因。

很多人要问，怎么确保凤凰男占便宜？你是大学生，你先说。
