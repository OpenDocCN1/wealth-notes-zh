# 今后的中国出口，工人在哪里？

中国制造大概分类：

一是外卖，类似于富士康，这种企业根本不是制造业，实际是服务业，工人主要就是拧螺丝，擦玻璃片，就和饭店洗碗工差不多。苹果手机的核心部件，你掌握几个？说白了，就是借你一块地方，借你几万工人。芯片传感器，一个也不会告诉你的。

二是高太上的企业，这类企业出口不多，脾气很大，他们最幸福，卯足了劲赚小老板的钱。小饭店拉一根燃气管，就要十几万元，小工厂拉一根几米长的高压线，要几十万。香烟茶水不说了，小老板还要懂事。他们通过专家编了一套说辞，解释天价合理性，我只能拼命点头赞同，有什么办法呢？

三是义乌之类的出口小企业，看上去灰头土脸的，但真得是中国出口的中流砥柱。今天，我就说说这类企业。

前段时间，我去了好几个这类企业，发现一个现象（如果说得不准确，请见谅）。车间技术工人年龄偏大，35岁都是年轻人，绝大部分是40--55岁。这些人已经习惯了自身岗位，不喜欢改变，比较安心。但是，这批工人也就是再抗十年了。技术工，不是给钱就有的，一般需要3年的培训锻炼，难题是：现在的城乡年轻人，统统不愿意做技术工了，企业没有技术工后备梯队了。原因是：

一，工资不高。现在的二三四五线的小工人，旺季半年，月入一万还是可以够的，但很辛苦，淡季只有最低工资。全年收入也就是6--8万。为什么小老板不给他们大幅度加工资呢？呵呵，小老板有的叮当响，劳动局，社保局，各种税费罚，厂租，哪个不要钱？不倒闭就算好的了。

二，年轻人去嗨了？主要是服务业。

高太上的985就不说了。小镇青年，现在最热门的是去做中介，快递，滴滴，淘宝，保安，维修，售后台，推销，p2p，炒币，高太上的外企拧螺丝，在生态区开个小店，在小公司里打打字，混社会，当骗子，放高利贷的也少。现在很多人农村家庭拆迁了，儿子房子等着婚，混个饭碗就行了，再也不愿干辛苦活了
