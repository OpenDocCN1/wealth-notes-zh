# 325 政策

是改变楼市二十年趋势的大转折点。主要内容是两年社保改为五年社保。这个消息是最严格保护的，绝对没有提前公布，是 325 当天的上午 9:40 左右才公开，而且据追溯，从当日凌晨 0 点就开始生效。

严格讲，政策不应该倒着算。这个事情导致了一个荒唐的尴尬：就是 325 当日 9:40 之前网签合同的，在完全不知道的情况下被列入到了限购，合同立即作废，当场哭的稀里哗啦，而且还引发了 xx。后来作为一个案解决了。

我是那次大转折的亲历者。2016 年之前，写楼市的人很少，那时候我的私信多到爆！所以，根本没有 324 抢房源。这个小猫完全是胡说八道。
