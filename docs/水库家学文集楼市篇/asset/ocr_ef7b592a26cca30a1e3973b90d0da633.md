# 互联网即将杀死菜场

中国的cpi，本质上是食品价格，不管房价租金飞到天上云，cpi一直在1.5-2%左右，好像全世

界的变化和cpi没关系。一直以来，中国主流的菜系渠道还是菜市场，还有极少数超市。现在网购来了，这次简直是排山倒海的浪潮。

我是菜场资深VIP，买菜十年以上，而且是买好东西的顾客，例如鲍鱼、青节虾、石班鱼，牛拌，活鸡。我原来不相信海鲜还可以送货上门，现在，活鲜真的可以活的送上门，我不知道是不是放了点化学物品的，但肯足是活的。这就打开了魔盒了。

菜市场一般服务周围两公里的人群，所以品种不多，劣质货，便宜货是当家花儿。要买点好食品，必须提前去预定，但你中午提前去，晚上吃死血流虾的，也不开心。网购不一样了，什么品种都有，按时送货，就是贵一点。

网购肯足是推高物价的。很多人相信马云的说法，什么网购便宜是不需要房租，我还！举例说明。

内环级菜场，活鱼摊位，月租3000元，如果你换到乡下仓库，至少800元，节约了2200元，每月节约了75元，相当于10单送货劳务费。

事实上，一个活鱼摊，月成交额是150单以上。如果网配送货，基本是每日1500元成本，一个月的费用是4.5万元，远远超过3000元租金。这些增加的成本，肯足是消费者承担。所以，网购物价肯定是高的。

富人玩送货，穷人买菜场，行吗？不行。菜场必须品种丰富，否则没人去，赚大钱的花班鱼青节虾，被网约抢了生意，但小摊贩的生活成本是不能降低的，便宜货的价格就必须上涨，例如鲍鱼12元就可能涨到20元。否则，小贩千不下去了。鲍鱼涨价了，蓝类弹也涨落。

菜场继续繁荣，主要是靠富人消费，继续品种丰富。如果富人消费被网购拉走了，便宜货马上就会涨价，最后大家都网购。菜场就像是老的百货公司了。只有大爷大妈来挑点便宜货。

我已经很痛菜市场了。门口不能停车，买菜实在足是背不动。大热天的，累的直喘气。来来回回，耽误时间。
