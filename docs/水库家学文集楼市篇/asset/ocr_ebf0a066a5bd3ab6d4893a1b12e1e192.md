# 搜狐今天发了一篇文章

把东北经济困局归因于：资源枯竭，历史包袱重，地基位置差，改制不及时，天气冷等各种原因。一句话，主要是以前不好，以前事情没办好，现在不能怪我。如果这样反总问题，我看就别反思了。

文章说的这些问题，其他地区也是普遍存在的，并不是东北一家。相反，东北有大量的科研机构，大量的高素质国企技术工人，这笔宝贵的财富用好了吗？我们就算全都认同东北的种种困难，但归根结底，这些困难还只是在国内内部。民企和外企，并没有这些历史包袱。他们发展起来了吗？也不乐观。

+   一，民企

先说个别情况。亚布力那个滑雪场，民企老板在网上和有关部门掰扯威胁说：宝宝心里苦啊。这是其他地方非常罕见的。将说雪乡等等，这个和东北历史包袱没关系吗？

再看一般情况。在东北，注册和注销一个公司，有多麻烦？居民去办事，满大街找关系，是不是很多？

+   二，外资

我很少听说东北大学毕业生后，积极进入东北的外资就业的。想来想去，好像外资也真不多。为什么啊？好吧，又是历史包袱重。

+   三，大学生就业

现在的东北居民，就业观念只认体制内。为啥？不是东北人思想僵化，而是现实反映。因为其他所有制企业，短命啊。为啥短命？好吧，历史包袱重。

+   四，购房

东北人在海南北海，购房之热情，我想大家都知道。为什么这么多资金大量逃离东北？好吧，历史包袱重。

东北附近海域的扇贝最能代表靠山山风格了！一查帐了，它就自己跑了，不查了，它又自己回来了。神奇吧？更神奇的是，东北人听了都会呵呵一笑。就这样了，你咋办呢？
