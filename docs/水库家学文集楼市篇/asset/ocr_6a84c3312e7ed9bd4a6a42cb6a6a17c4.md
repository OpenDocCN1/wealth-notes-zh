小老板的亲戚们都看不起他了。

小老板在外面催不到钱，亲戚里借不到钱，马上要发工资了，只能来银行碰碰运气。在银行办公室里面，遇到了和他儿子差不多大大的小杨经理，小杨咧嘴，坐立不安，抖抖索索掏出一幕假报表。银行经理小羊挑着签签字，大概瞄了一眼，“老王啊，远程也要专业一点，近三个月的电费水费下降了30%，你好意思把产值翻了2倍？销售看上去是涨跌了，但半天就转走了。你还是回去吧！”老王刚回到厂里，镇里的经济科打电话来了，“请您明天下午参加一个中小企业发展座谈会。”到了会场，老王是一肚子火大，但一看，七头八所的股长大都来了，好几个还是来厂里检查过的，怎么好意思当面说企业家担太重要呢？更何况，是困难，也不是镇里可以解决的。想来想去正发愁。老王一看银行行长没来，嗯，那就喷银行了。

当然，中小企业也在特别情况下，也需要贷款，例如建造宿舍，设备升级等中长期贷款，但是，银行对中小企业不提供这个服务，只有一年期的经营贷款。“不要赶死我，把门帘一下。”

# 把民间热线引到实体经济中

而不是楼市！

毋庸讳言，民间热线是大量存在的，而且是热度很高，跃跃欲试，怒也怒不住的感觉。这些年，那么多非法集资平台被点了高炮，但是还是有那么多人继续冲进去。

一，热线是怎么形成的？

主要是居民家庭长期存款，经商收入，拆迁款。也有一些野钱，因为理财平台的存款，法院执行或者是查不到的（有待确认）。

二，热线的目标是楼市

这些钱的目标，可能是给孩子在大城市买个婚房，由于大城市限购，这钱钱一半年会无法使用，只能是存起来。

三，过渡期内，追求保值

在过渡期内，各种物价，轮番在涨，番茄五元一斤，很多居民就希望追求高收益。一时贪心，就被各种理财平台拉进去了。

四，热线为什么不去实体经济？

十多年前，大家最开心的事情是，把十几万存款放在做大生意的亲戚家里收利息，一年多收入一万元，幸福不得了。现在很少了，亲戚开的厂子黄了，不敢了。存银行太亏了，买房子限购了，自己创业也没能力，怎么办呢？只能是去理财平台碰碰运气。一旦亏了，全家喝稀饭。

五，思考

+   1，民间热线是不可能消头的，钱是会自动追逐高回报的。我们必须开辟一个大池子，把它调起来。以前是大城市楼市，现在楼市也不要它了。热线的最佳去处是，实体经济。

+   2，引导热线去实体经济，必须要让热线有回报。那实体经济应该大部分是赚钱的，一天到晚亏损谁敢去啊？

+   3，千方百计让更多的民企有能力产生良好效益！
