# 市场经济是信用经济

中国信用的基础是房产证。什么创新发展，高科技，新领域，那是远大目标。你给银行讲创新，讲专利，银行小姐都要睡着了啊，就一句话：房子有钱？没房子啊，拼房，我没办法了，环跃终身制，你懂伐？你不要叫领导来打招呼，你直接让领导帮你批贷款吧，不要装我了。

福利分房，如果仅在公务单位，那么肯定会被套五子以上的。如果推广到全部人群，那么大家就开始比对了，越穷越好（是不是很熟悉的话？）。你辛苦一辈子的，也不过是买套房，不如穷下去吧，还能吃低保，分房子，孩子读书免费，连年过节还要给我送来送油。我就是在小区里扎金花了。

我不相信有关部门愿意看到这种情况。因为如果大家开始比穷了，有关部们的脸日子也到头了。我在吃低保，你好意思坐奥迪，好意思把儿子送到美国读书？总要做点表面功夫吧？这下子，你看明白了？

# 发大财不是你可以设计的

我想告诉同学们，发大财不是你可以设计的。

发大财永远是运气，而不是智慧。智慧的人，拼到底，也就是好一点的土产，例如教授博导之类的。我从来不认为我可以凭借努力和智慧发财。

我建议的道路是，按照你的实际情况，专注一个行业，保证做成专家大工。有机会开个小作坊的！

# 京沪持续繁荣的秘密

无论整体经济如何，京沪从来就不会出现大的降温，略微起伏是有的。京沪有其他任何城市不具备的资金来源，财政拨款之类的，我们不讨论，就说经济本身。

京沪是中国绝大部分富豪的生活居住地，是各地中产家庭向往定居的繁华之地。这些人就像是抽水机一样，把全国各地，每个商业角落，点点滴滴的利润收集起来，形成一股强劲的激流，汇入京沪。京沪依托这个资金来源，发展出越来越先进的服务业，例如高端医疗，杜克大学分校之类的高消费玩意，又进一步吸引富豪买房资金。

你出钱，我服务，互相做账，互为因果，京沪基本垄断中国最高端的消费。这些最高端消费也是最好利润的生意，又养成了很多中等收入员工，消费不断延伸下去，依次降低消费层次，繁荣了京沪的各行各业和每个角落。就算是卖大白菜，京沪生意也比在南京好做，因为客户富裕啊！

这种资金收集叠加模式，其他地方是无法比拟的。温岭曾经有点这个意思，温岭大学小老板在全国各地赚钱，把利润汇回温岭，温岭消费全越类起。本来无法消化，曾经期内引发了温岭抄房团这类奇葩。但这种民间自发的形式，没有长期性和机制性的保障，也就是昙花一现。
