# 可恶的专家

我想在中部某大市买套一百平米，看报纸说跌，全家犹豫不决。我经常看到这种问题，心里悲伤。

专家明明知道房价跌不下来，却拼命暗示跌，但从来不明说跌。屌丝家庭没有任何经济知识，不知所措，很多鸡贼家庭（至少 30%）以为等一年后有便宜可占，结果彻底失去翻身机会。专家信誉就是这样额面扫地的。
