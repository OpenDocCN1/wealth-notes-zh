# # 京沪房价跌了吗？

来自楼市一线的小故事。

小王要买市里茶小区的老破小，上班近，学区房，这个老小区的一室户都是 30 平米，统一户型，所以，卖房子的都是喊总价。这个老破小在最巅峰一般是喊 300 万总价。

众所周知，在市场狂热期，只要出来一套，立马被买走，根本不存在什么比价。这种户型实在是太小了，一般是买的不住，住的不买。购买者一般也不考虑什么朝向和阳光，现在，限购限贷厉害，交易冷清了，购房客主要是自住。

小王这几年在该小区居然看到了两套老破小在卖，房东都是喊 280 万。

+   * 房源甲，位置好，环境好，楼层好。
* 房源乙，靠马路，噪音大，顶楼。
* 小王看了后，想买甲房，结果房东说在出差，要过几天来谈。后来得知，看上的人太多了，房
  东内心膨胀，又涨到 300 万了。
* 房源乙，没人想买，房东降价到 250 万，还是没人买。

# # 只存面积，不存钱

我姆那一代人，天生节约，在番茄只有两毛钱的时候就开始存钱。千方百计的从嘴巴里省钱，五毛一毛的节约，买把青菜，还要多顺两根葱，各种抠门的事情干了很多，好不容易存了十几万，现在番茄五块钱一斤了。她这辈子白违章了，真是可怜的一生。

我这代人，已经不储蓄，不存钱了，我只存面积，到老了，卖掉一套老破小，比什么社保养老金都管用、顶用。
