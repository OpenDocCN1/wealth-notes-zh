# 我们是如何保持食品价格基本稳定的？

现在，一只鸡大概是 100 元，一个番茄 2-3 元，一个苹果 4-6 元。总体而言，比五年前贵了不少，但和房价比，基本稳定。主要原因是，食品不能囤积，需求是可以提前测算的。

现在的基本手法是，大宗物货例如小麦，米，油，肉，糖，海鲜等易运输的食品，大规模进口。把以播种粮油的土地和人力腾出来，生产不容易运输的副食品，例如蔬菜，瓜果，活鱼，猪肉，鸡蛋等。这样，主食和副食的供应非常充足，没有短缺，也就不太涨价了。有时候，国内的鸡猪猪肉还生产多了，导致降价。食品价格就基本控制住了。

这里面的逻辑是，外汇必须充足，能够满足进口粮油的需要。而我们的创汇大户是外企和民企。你不要说什么造船和军 xx 工之类的大国企，这些东西七十年代就有，也没看到有多少外汇。

外汇的管理很复杂。外汇多了，冲击本币币值。少了，冲击物价稳定。有些时间，我们外汇超过了需求，积极鼓励大家换汇，汇出境外也无所谓，代购代购一些奢侈品，也不管了。现在，外汇管理超严格。你去美国买一块百丽手表，国内机场就要你上税了。

将来的食品价格如何？很简单，只要创汇的机制还在运转，基本不会有问题的。欧美的物价比较稳定，我们的进口价也很稳定，即国内食品价格将稳定。你敢涨价，我就大规模进口。

但这就把种粮油的农民搞的不赚钱了。房子和其他工业品涨价多，粮油涨不上去，一般神地就没收入了。

但这也没关系。我们还有补贴机制：

+   1，郊区拆迁。

2，减少农产品税费，适当补贴之类的。

3，鼓励进城打工，增加劳务收入。

4，低保农保托底。
