# 发财的时间点，一般会在什么时候出现？

现在的大学牲，一般都是毕业后就到单位去上班，然后浑浑噩噩的升职加薪，半死不活，一直没有什么赚大钱的可能性。35岁了，突然发现一大群小孩进了单位，然后管自己叫师傅，叫小领导，这时候意识到，自己的人生已经失败，今后几乎没有上升渠道了。

当年的我也是这个样子，当时紧张到了极点。我从小到大都是优秀的学生，我那么努力就是挣不到钱，为什么？我不甘心啊。于是我走进了体制。

一开始出来的时候，你会觉得很恐惧！虽然没有人管你了，但是也没有人给你发钱了，你赚的每一分钱，都需要自己想办法从别人的口袋里掏出来，这个很难的。这个时候，我机缘巧合的去做了塑料桶。

其实像我们这种科班出身的人，竞争力其实是很强的，只不过我们原来一直在体制内不敢出来，越来越胆小，最后丧失了机会。我当年出来的时候，塑料桶行业正处于兴起的箭拔。我上山下乡跑农村，和农民工打交道，把一支队伍拉了起来，最后把塑料桶卖到了大江南北。

在中国，如果你没有马爸爸的投资，你就不要去做什么高科技的行业，因为你不具备那个实力。一台仪器几十上百万，你根本很难赚到。如果要创业，就做老百姓需求最大的行业，你把这个行业做精做透，你本来就比别人聪明，你的思维，你的逻辑，完胜那些从农村出来的半文盲，中学生。你不要怕，你只是暂时的落后，三五年之后你就会赶上他们。市场经济的变化是很快的，一个企业兴衰荣辱，也不过就是几年的时间。

我的看法是，当你32岁到35岁的时候，积极的寻找一个项目，35岁之后，如果没有当县长可能性，坚决的走人。不要怕，你的基本功和综合素质可以全面碾压超过现在市场上已经成功的那些中等商人。

# 要往大城市走

在中国，城市发展前途，并不完全取决于经济因素，而取决于资源分配的份额。

资源分配不是按照市场经济的规律，主要是按照行政决定。例举办某大型会议展览运动会，一下子就投入300亿。在哪里举办？其实不是一个市场经济行为，而是一个行政决定。所以，我们要往大城市走，不能往小城市贪图安逸。

即使偶尔你抓到了一一个小红书，在小城市过了几年安心的日子，也是短暂的。房产投资，家族发展，子孙幸福，那是几十年上百年的大格局，不能看短短的两三年，你是占了点小便宜，吃了几次低价乡村基。
