# 三世积福，生在周浦！

大学某谭姓上海土著男同学，说话结巴，不修边幅，身高 170 体重 170，新生自我介绍父亲开出租，母亲全职家庭主妇。

大一在食堂吃早餐，看到同寝室的同学点了六七块的早餐，结结巴巴地感叹道，“你看你多有钱，我我我点早餐都不敢超过两块…” （这是真事）

就这样，在大家的关心与同情下，大家愉快地度过了四年。

大学快毕业的时候，大家都为各自的的事情忙得焦头烂额的，我工作的找工作，考研的考研，考公务员的考公，出国的出国，而这个胖子还在寝室里哼哼唧唧。

聚会酒过三巡的时候，他们寝室老大很铁不成钢地说，“谭胖，好歹本科毕业，工作还是要找的，不要自暴自弃。”

胖子傻呵呵地挠了挠头，说，“自己自己也没啥本事，就就不找工作了，帮自家收收租…租金，过得开心就就就好。”

才知道，他么的家里在七宅房子。那顿饭，好多同学吃得很隐没…
