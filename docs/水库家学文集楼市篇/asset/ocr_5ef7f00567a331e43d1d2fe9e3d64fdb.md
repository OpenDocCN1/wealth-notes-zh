+   1. 增值税不抵扣。工资6000元，肯定是算增值部分，17%增值税。
2. 社保是工资48%，一分钱不能少。这也是增值部分，交了48%，还要再交17%增值税。
3. 个税，3500块以上就要交税了。
4. 企业所得税，25%。
5. 各种附加。
6. 税费罚若千。

这还是毛估估的，实际上只多不少。

既然企业也嗟，工人也不太满意，那就一拍两散吧。

# 如何建设好一个新区或者特区？

如何建设好一个新区或者特区？让普通人赚到钱。

中国的新区特区非常多，好像每个省都有几个。普遍认可的大概只有深圳特区和浦东新区了。很多新区估计大家早就忘记了。现在好像已经没人再关心汕头是特区了。

深圳，建设之初，普通人工资高的惊艳。在服务厂赚钱佣机的农村打打工，工资五百元左右。超过京都一个国企科长，匪夷所思。浦东是让人得实惠，正规就业的本利生给上海户口，非正规就业的十万元买房送进口户，直接享受了上海积累了几十年才形成的优质医疗教育，吸引了大量江浙沪皖的大学生和中级职称，包括一些知青子女。2003年以后，深圳和浦东的房价直线上升，导致来的人全部享受到了城市发展的暴利，良性循环。

再看着其他一些不知名的新区，定位的时候，就先天不足。基本流程是，选一块地，成立一个管委会，邀请几个大企业设个分公司，再把一些GDP算到这个区块里。有关部门就开始创作作报告，该发展宏图了。仔细看看，这个地方既发不出高工资，也没有什么实惠，人还是那些人，工资还是那么工资，医疗教育也没什么变化。除了争取到了一点优惠政策，普通人说走就走了。

深圳和浦东的成功，其实有大原因，赶上了全球代工分工，内地成为全球加工业基地，深圳和浦东，是珠三角长三角的深港港口，物流信息流资金流的集散地，辐射广阔内地。在此基础上，又发展了金融，航运，先进制造业，大出口。

厦门就一个孤零零的小岛，当年连火车运力都缺给巴。珠海靠近热门，澳门人口只有一个杨浦区那么多，又是旅游城市靠赌场过日子，没有力量拉动周边发展。

所以，一个新区能不能成功，其实在初期基本可以看到结局。
