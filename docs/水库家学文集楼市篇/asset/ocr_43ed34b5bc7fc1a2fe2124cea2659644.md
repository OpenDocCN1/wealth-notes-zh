# ## 世界上有一门课叫做经济哲学

但没人研究。这玩意没有实用性，既不能考证，也不能做笼，大家不感兴趣。实际上，这种知识是真正的屠龙术，是大国决策的价值取向。有些话，有些事，是永远不会出现在公众场合的。要理解一个重大长期政策，不是那些垃圾员给你扯扯热闹，而是要看懂贯穿决策的内心依据。

# ## 我谈的经济学

都只说一些浅的内容。真正深层次的东西，我是不敢说的。举例，西方经济学中，“资源诅咒”是一个大家都听说过的名词，也知道大概意思，就是卖资源国家，经不起外贸波动。

但实际上，外国人当初发明这个概念的本意是：任何一个经济体，必须防止底层人太有钱了，必须千方百计把底层人的钱拿走。资源诅咒，只是这个思想的一个例子而已。当然，这是万恶的资本主义思想，和我们无关。
