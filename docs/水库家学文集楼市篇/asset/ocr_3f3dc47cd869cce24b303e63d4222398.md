# 逆周期调节（2019.03）

易纲回应货币政策删除“中性”二字：中国实施货币政策的内涵没有变，并要体现逆周期调节。

专家：从参会表述看…

点评：不同于去年两会货币政策目标的多重表述来看，今年仅存促进就业、保持物价稳定、维护币值稳定以及防范化解金融风险。

不同于去年两会上对宏观经济市场的诸多目标表述，在多年的年初的政府工作报告，对房地产的表述不少“杠杆不变”“长夜孤战”的表述也未提及。

政府工作报告中，在2019年经济运行工作部署中，针对解决民众住有所问题，强调城市主体责任，改策完善住房市场体系和租赁体系，促进“房住不租”市场下健康发展，继续促进保障性住房建设和农业棚户区改造，保障困难群众基本居住条件。

中国经济社会城市发展与环境建设研究副会长吴晓晖（《华夏时报》记者，从中长期宏观上判断，更多的是关注经济内部问题，如民生问题，房地产的调控更多关注经济系统性风险。继续降低风险促进发展的问题，政府也有自己的思考，能不能调控。中国正处于一个由大变强国阶段，人们的观念也随国家在变化，这些是需要解决的，所以要继续坚持民生和经济资产建设。

今年与元旦提及的“货币不变”“长夜孤战”“稳定房、租购并举、金融稳定”方面尚未提及。

对此，牛凤霞透露，这往往非常难得的政策共识形成共识的，经据官方有文字提报，已经有共识的应该没有使用货币工具的杠杆变化使用提报，比如“房住不租”这些已经写了多少年了，包括租赁等提报。

中国金融研究院院长朱晓对（华夏时报）记者分析时表示，今年的政策，对于房地产产品应比变化，各地段起来社会就有弹性。地方政府需要管好自己的调控。要行市场发挥作用，发挥市场长效作用。

记者表示，是2018年房地产市场2019的又一次特点。内地房地产市场从统计指数来看，2018年中国地产“调控历史上调控政策最总最紧的年份。全年房价下跌的城市有640个，同比2017年上涨75%，已经到新的历史高点，但在2018年末，三个双月跌幅依然较明显。今年经济面临包惠政、结构调整以及国际化的多重挑战，防范化解防范经济金融风险的压力较难放松，也制约信贷投资需求，这些都可能升起了地方政府对调控的小小意愿。

那么今年房地产市场的主基调是什么吧？牛凤霞表示，目前的政策还是房住不租的，‘进’并不等于不‘退’，我们能看到他解释的宏观大的变化，但房地产调控政策不会动摇，这才能有效房地产调控比起到定心丸的作用。
