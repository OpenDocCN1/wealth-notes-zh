# 深圳市盐田外国语实验学校关于学位申请
补充事实的告示

近年来沙头角生源持续增加，学位学位已经紧张。为了优先保障学校区域内家庭的适龄儿童和少年入学的权利，也让您的孩子能享受就近入学位，人为造成不公平学位申请局面。保证教育教学的正规开展，现明确凡本地、市、区做法，按金湖镇大房房。从2019年开始，申请我校学位的住户补充事实如下：

+   (1) 在房屋面积小于等于30m²的，需实际及实际居住满一年以上，且在深圳市有房没有大房居住或类房屋。
(2) 住房面积大于30m² 且小于或等于50m²的，需实际及实际居住满一年以上，且无大房居住。
(3) 在房屋面积大于50m²的，需实际及实际居住满一年以上，且无大房居住。
(4) 以上所起的房屋年限，均以此当年3月30日为起的时间计算。

学校将通过社区房屋档案的查看或走访等形式核查是否存在申请学位后实际居住进行核实。
