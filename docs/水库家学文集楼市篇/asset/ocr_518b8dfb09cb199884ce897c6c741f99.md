# 地段决定命运

绝大多数人一辈子就攒了一套房子。而且一般是生活在哪里，房子就在那里，买的，单位发的，拆迁的，来源丰富。

黄浦区的老王家，大儿子去了成都某电子厂，二儿子去了贵州某铁厂，小儿子留在了上海。他们老一代在国管局，工资差不多。外地工资可能还多几块钱。等子女长大后陆续回城，小儿子的子女因为拆迁买了两套房。外地子女的异地房子不值钱，就闹大霉了！没有上海房产成为了他们人生悲剧的所有原因。

熬在京沪是最有价值的人生努力和拼搏。
