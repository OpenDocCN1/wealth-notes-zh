# 三，港币的利率能不能和美元同步？

理论上可以，但同步的后遗症实在是太大了。利率是调整经济周期的手段。经济不好了，降低利率，刺激投资。反之同理。谁能够保证，美国和香港的经济周期完全一致？

美国经济今年火炬燃的一场糊涂，利率上调的可能性就极大。

与此同时，假设香港经济一般般，港币要是跟，也抬高利息。本地经济就×××了。如果不跟，汇率要麻烦了。

# 给在沪的老年轻网友说个思路

现在，越来越多的外地211朋友，在上海混不下去了。房租高，工资不高，买房无力，小孩读书难，拼挣了这么多年，心里想走，但又不甘心。我给你出个招：熬满五年社保，你大概是28岁左右。婚后拼尽全力在金山区，买个别得及的老破小，等待时机。然后踏踏实实回老家娶妻生子。

金山区有个超级大型化工区，导致房价一直是上海最低，大家还嫌便宜。崇明岛虽遥远，但心里舒服啊，长寿岛。金山区住在化工厂旁边，那里真不是个滋味。

我按照经济学原理预测，

+   1. 化工区迟早会搬迁。金山这个大个区，地价一直上来，实在是太大了。

+   2. 搬迁时间，我无法预测。但我相信，10年内搬迁的可能性很大，因为设备折旧基本完成了，损失较小。化工区搬迁后，除了原厂不能用，其他地方就存在工业废气废水了。极大好。

+   3. 北面的宝钢，已经开先例了。释放了巨大的土地利好。

+   4. 金山区一旦调整产业结构，就是浙江沪的桥头堡，地理位置兼顾两边，非常优越，利好极大。

+   5. 或许还有其他利益。上海今后的人口政策趋势，我猜测是以房管人。若有一天，中高考考放票，第一批受益者应该是有房子的定居者。
