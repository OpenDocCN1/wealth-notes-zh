# 楼市十年后的大格局

本地房价的实质性涨跌（不是随大流），主要看：本市优质高中生生的回归率。

+   1，本科生回归率达到80%，房价大涨。例中东部省会城市。本地学生基本不回来，其他地方学生拼命想扎根，住房需求非常大。房价会自我循环，自我突破。

+   2，本科生回归率低于60%，当地房价，波澜不惊。优秀学生走了，必然卖掉多余房产，凑个首付款，去大城市安家。若干年后，父母老了，彻底卖房！同时，也有一些附近农村的、省内异地的买人，供差距不多，但是离开的人质量高，进来的人质量低，总体向下走。

+   3，本科生回归率低于40%，这种楼市基本玩完了！像样的本科生一溜烟的跑了，留下来的都是家里有关系，可以考上本市大单位的，他们基本也不需再买房了。

跑了的本科生，会把家里多余的1-2套房子卖了，去三亚杭州做首付。而接盘侠往往是本市附近农村的，支付能力很差，价格抬不起来。实际的客泉想过买房的家庭，再加上新星出台，这种城市基本没戏了。无论如何怎么忽悠，你不相信倍会有惊喜。

京沪永远涨！

# 京沪已经固化了

京沪整套自己买房扎根的年轻人，已经是凤毛麟角，百分之一都不到了。

算算账：

+   1，前三年的起步期。小夫妻，一个研究生毕业24-25岁，一个博士毕业28-29岁。读书期间基本零存款，毕业后3年是事业起步期，收入不多，小夫妻每年收入40万，存25万最多了，绝大部分存不到这个水平。

+   2，之后，小夫妻每年收入60万，老人孩子夫妻的日常生话费20万，存款40万。京沪最优秀的小夫妻，大概要8年，存够200万的首付。勉强可以买一个外环线（五环外）90平米。此时，男方已经38岁了，还要面临每年25万的还款，持续20-30年。

+   3，十年后，男方大概是45-50岁，基本还清了90平米贷款。这算是非常优秀的小夫妻，不能遇到任何的意外情况。90%的一般屌丝，彻底完希望了。
