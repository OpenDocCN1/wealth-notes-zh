# 简单讲一下当前经济的大格局

> **【新华社评：把减轻税费这件大事办成办好】** ，切实让市场主体特别是小微企业有明显减税降费感受。

我认为，这个措施高建远颂，非常正确，抓到了关键点。我简单讲一下当前经济的大格局，敬请指导。

经济工作的第一要务是就业，保就业，无非是内需和内需。外需不是我们说了算，那就聚焦内需。内需分为公共支出和居民支出。公共支出，已经绷到极限了。很多地方财政能够把大基建的利息还上，就算很不错了。

内需不撑，主要原因是商品价格涨幅，超过居民加工资的速度了。

+   1. 小额支出，主要是日用品。我经常买某普通牌子的豆腐，半年前是1.8 元/盒，现在是2.2 元/盒。蔬菜价格也上涨，西红柿 4.5/斤。菜市场胥 95-100 元/斤，鲫鱼也涨了。我家附近的菜场，近一年，至少 15-20% 的涨幅。洗车20-30 元。

+   2. 中等支出，几千元左右的，包括新款手机，儿童兴趣班，学生补习班，也在涨价。

+   3. 大额支出，例如房价，除了强力限购的一线城市基本不涨，其他地方，涨的还是很贵，为什么涨价呢？其实很简单，企业成本每年在涨。

+   1. 最直接的社保基数，每年在涨，就算停缴也不让，社保这一块每年都直线调了上去，

+   2. 原材料涨价，去年环保风暴，很多原材料直接涨价。

+   3. 税费征缴力度，省略一百字。

+   4. 工资上涨，每年正月十五，都会来一次用工资的大宣传，无非是配合涨工资，实际情况看，不涨还不行，因为大基建开的工资高，制造业不涨工资，人就跑了。

+   5. 房价，我不说了。避免红杠。
