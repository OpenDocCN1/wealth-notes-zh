# 买房要不要写孩子名字？

答：没有特殊情况，不要写孩子名字。原因：

+   1. 占了孩子将来的房票。

+   2. 卖房时多一个麻烦手续，卖房款需要保证孩子居住利益。

+   3. 离婚时，需要保障孩子的居住权。

+   4. 有的银行也不喜欢把孩子名字写进去，断供后，没收房子麻烦。

# 父母不努力，老大徒伤悲

我们这一代人是算幸福的，至少很多 985211 毕业后，有条件去大城市和省会买房子。巴黎伦敦纽约，香港台北，东京首尔，很多国际大城市的年轻人已经彻底没机会了。

1949～1999 年，整整五十年，我家没有能力买房子。我们的祖辈父辈，就是靠解放前留下来的房子，苦苦挣扎，熬到了 21 世纪。多少悲欢离合，多少爱恨情愁，绝大部分和房子有关。在我的理念中，房子不仅仅是资产，更是子孙幸福的根基。

我是只管价格的，只要够得到，直接来一套，管他什么划算不划算。二十年后，都是划算的。

# 上海是五年限购

2019 年第二季度，将迎来首批解禁者。这批人是 2016 限购的倒霉蛋。当时，他们已经满足两年资格，或者即将满足，正在慢慢挑选或者和房东洽谈，没想到一晚上政策变了，限购变五年了。他们只能是彻底离场，气的直跳。三年后，这批人再次获得购房资格，而且增加了三年存款。你自己想想，他们会如何？

这个问题，可能会涉及到杭州南京苏州的二手房供应量。

# 最近要求个人填表

其中一条是要求申报者填写房产的地址，身份验证码，租金价格，大概可以减免一点个税（我估计几十元到一百多）。我建议，你在填写之前和房东微信核对一下信息，不要填错了，同时也尽可能让房东客观理性，正确面对，今后不要吧增加的费用转嫁给租客。

市区出租房，大多数是老龄人，很多房屋是七老八十的退休人，本来不交税的，被你一报，他要么增加了很多米跑去填表的麻烦，这对老人是个巨大麻烦。有的房东可能不理性，破口大骂，租客要对他做好情绪疏导，心理劝解工作；让他认清现实，正确面对，积极去交钱。
