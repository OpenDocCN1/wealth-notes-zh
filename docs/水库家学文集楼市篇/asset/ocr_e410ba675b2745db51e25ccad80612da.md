# 贵阳楼市（2018.03）

贵阳房价涨得小，表面看是超级大盘多的铺天盖地。但这不是主要原因。本质是，贵阳能够提供的高薪蓝领就业岗位不足。房子再便宜，我吃饭要花钱的，现在全国各地家教的价格是一样的，雷琴可乐的价格是一样的，住在贵阳也要花钱的。怎么赚钱呢？

高薪蓝领位，直接决定了能够安安心心住下来的中产数量。如果高薪酬位多了，房价立刻起飞。举例，浦东春潮，原来是浦东最穷的小镇，各种人才嫌弃的建筑物流站设在那里。现在一举突破六万了。为啥？因为附近的张江软件园，国际机场，信用卡园等企业，提供了大量的高薪岗位。

# 海南买房买哪里？

海南分为东西南北。

+   - 1. 南面，三亚，陵水。特点是热。春节期间是全国最冷的天气，三亚好似人间仙境，温暖的海身舒服。但是，过了正月十五，你就热的难受了，地面都是烫的。如果你只住春节前后的十五天，三亚是首选。但是，若你想住三个月，那就捉摸间吧，夏天比冬天更难受。
- 2. 北面，海口为主，左右各有一排小城市。特点是和三亚相反，春节期间还有点冷，穿一件毛衣+一件外套，或者带羽绒服。我是二月初到达海口机场，看到游客们穿厚衣服，心里彻底失望了。而且是令人恼怒的湿冷，衣服洗了，水远干不了。被子湿漉漉的，地板上的水，不会蒸发。
