# 法国黄背心在搞什么？

我估计绝大部分人不清楚，法国黄背心在搞什么？汽油涨价已经取消了，为什么他们还在搞事？甚至蔓延到周边国家了。从新闻看，他们没有什么是明确的主张，一部分人让马克龙走人，一部分人支持马克龙留下。闹的，很多人都是互相矛盾的，实际上，他们有很多话说没，但说不出来，实在是憋屈，于是采取了一个很奇怪的幺法：闹，但不提要求。因为大家心知肚明。

我对欧洲太了解了。我告诉你一个秘密：他们为什么不高兴。因为他们的生活状态三十年没有提高了，而新兴国家发展太快了。他们明显感觉到不高兴了。举例，现在巴黎最有钱的人，不是巴黎本地人，而是我们的旅游团大姐。我们买五号香水，就像是买卫生纸，一箱一箱买。我们买包，就像是买土豆，十个八个的买。

意大利法国德国北欧，一般家庭根本舍不得买奢侈品。他的月收入可以买两个lv基本款。他们基本没有什么存款，很多女性带孩子不上班，男性的月收入大概是2800-3200欧，低的只有2000欧，一家人，只够还贷款，过日子。最惨的是，几十年不变，看不到希望。

西欧白人屌丝最喜欢的福利是大锅饭机械人。人的区别就是在祖上传下来的房子大小。其他方面看不出明显的差距。穿貂的不一定富家，穿毛衣的不一定是穷人。开大宝马的，都是滴滴司机，开小排量汽车的，可能是精英人群。这就是屌丝们最喜欢的公平，那么他们还有什么不满意的？

欧洲的问题是，太喜欢平均化了。他们把底层劳动者保护的太好了，失去了动力。精英阶层和底层不同，他们不在乎劳动法的保护，他们要的是发展，工作超级努力。底层人口，例如接近一般大学的屌丝家庭，他们没有发展的能力，也放弃幻想了，他们把注意力集中在保护自己。

由于劳动关系僵化，经济失去活力了。近三十年，全世界所有的重大变化发展，和欧洲没有一毛钱关系，主要是美国和东亚。欧洲内部，死气沉沉，都在维持。高门槛导致没人想创业，所以老企业可以简单维持，但没有发展，工资提不上去。要走不留，你随意。

这两年，又增加了两个刺激。一是新兴国家的人来炫富，深深地刺激欧洲人。二是移民问题。这话没法说了，一说就可能不正确了。

最后，就形成了现在的局面，普通人不高兴，但也不说具体那件事情，其实大家心里都知道，但这话没法说出来。

# 黄背心背后的几大问题，均无解

+   一、提高经济效率

+   主要是两个办法，一是大规模的科技创新，这个在西欧基本没什么头了。欧洲不可能产生快速和淘宝的。二是扩大贫富差距，激发劳动效率。这也不行。因为西欧历来是大锅饭思想最严重的地区。

+   二、国民自尊心

+   西欧，特别是法国，因为历史发达，一向是鼻子翘到天上去的。你去看看全世界的法师界遗址，就标榜了。现在，其他地区的人富裕了，他的自尊心受不了了。但这个问题也无解。你不让人来，关起门来当岛鸟？不可能吧。

+   三、中东非移民

+   这个问题，我有一大箩筐话要说，但也不敢说。反正，这事情，只能意会，不能言传。至少无法快速解决。
