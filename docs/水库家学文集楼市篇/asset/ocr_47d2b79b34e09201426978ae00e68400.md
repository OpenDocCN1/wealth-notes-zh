# 中美贸易，确实很难协调

关键是结构性矛盾。

+   1，中国希望进口的主要是高科技，最好是航天飞机和高级芯片，美国不卖。中国卖的，美国基本都喜欢，中低级工业品，日用品等。

+   2，美国同意卖的，中国基本可以自产自销，质量差一点，但也可以分。例如手机，机械，电子产品。

+   3，中美贸易局面是，中国想买的，美国不卖。我不但买的，你硬塞。

+   4，如果这样下去，那么中美贸易基本是一边倒了。为了维持表面顾尽尽可能小一点，中国不得已大量向美国进口农产品，波音，能源，留学学生去花钱等。

+   5，美国的经济优势是，金融外汇，工业品牌，知识产权等。美国希望，你要开门，自由贸易。这个确实抓到了关键。中国的日用品牌，确实不如美国。例如汽车。

中国的比亚迪奇瑞，确实比不上美国纯进口汽车品牌。从战略角度讲，汽车是重要的工业门类，中国必须维持发展。怎么维持呢？

一是大陆全包下来，亏损。

二是不让美国汽车进来，让国内消费者买国产车，逐步发展。我们实际上是对纯进口汽车高额关税，简单直接的打压，倒退让老百姓买国产的汽车。这就导致了美国汽车工人泄泄了。

其他行业基本差不多。国产工业品，质量低价缺点类，通过关税，让美国货卖不掉，例如掌握核心科技的格力空调，大金空调要是平着待来实验室中央空调，董奶奶就这么开心的。

以前就这么玩了很多年，原因是 WTO 的过渡期十五年，到了 2017 年到期了。现在，美国人来要求兑现了。你谈好开放金融，教育，影视，电信，汽车，的，现在你看着力了。

如果撕脸脸，中国的出口肯定是受阻，且拿不出什么很结棍的办法。你不卖美国小麦，你的小麦产量根本不够吃，那你去哪买？就算有人卖，价格立马就涨了。

而美国相对好一些。你的东西是价格伪劣，例如塑料盆，棉质内衣，但是现在墨西哥，东南亚，北非也可以做了，不卖你的，我还是不会短缺的。

，不要以为美国傻，他们都是算好了的。不吃亏才敢与君绝。我们怎么办？不说了，肯定是被割的。
