# 从我们这代人做起，

加快推进遗产税。

我在京沪市区有十套房子（假设），每年房租收入 50-80 万，而且是水涨船高，一年比一年高。只要子孙不糟蹋财富，那就是世世代代享福了，至少两三代是可能的，除非京沪的高薪岗位全都搬走了，市中心房子没人租了，可能性不大。

但这样太不公平了。人家孩子辛辛苦苦读出来 985，工作收入的一半，是给我孩子交房租，简直是岂有此理？这样做，并不利于经济发展，也不公平。

建议：遗产税直接征收 80%。而且不允许通过赠与或买卖的形式避开。

我们这代人有远大志向的，我们有勇气直接让出自己的利益，而不是让别人吃亏。
