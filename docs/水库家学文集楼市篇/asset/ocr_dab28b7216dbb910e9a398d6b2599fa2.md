# 外汇是怎么来的？

富士康应该是中国最大的出口企业了。但是富士康的工人嘴里懂什么高科技，无非是拧螺丝，擦玻璃。

举例，100 美元进口元器件，组装后，120 美元出口，产生了 20 美元的增值。这 20 美元外汇归国家，国家拿出 130 元人民币给企业，企业给工人发工资。也就是说，我们把国内的劳动力，水电气，土地资源变成了外汇。

外商也会研究，这个加工费划算吗？以前肯定是划算的

# 经济降温的最大承担者是：

+   1. 农二代里的二本专科到。

农护户口的年轻人，混的再差，家里也有个卖身立命的小二居，大不了工资打六折，一万变五千。但是农二代面临的尴尬就复杂了。

+   一，985 的日子不会太难

农二代里的 985，一般单位较好，不操心经济变化。大公司白领，以前的经济积累和工作资历也不错，大不了降降打击，回省城地级市。

+   二，体力打工族也不会差

贴瓷砖，送快递，拎次桶，是经济必须的，一旦降温，这些行业会立即火爆，可能还会收益。例如四万亿。大家也不要担心。

+   三，最借火的可能是小公司里的托尼和文妹

经济形势的冷热变化，受影响最大的是城市里的小中公司。而这些公司又是农二代进城坐办公室的最大收容站。经济形势好的时候，托尼也可以搞个八千一万，但是生意不好了，分分钟歇业或者赶人。一旦被赶出来了，文妹那个二本职务学历，马上又要生孩子了，也没有什么项强技能，真就难了。托尼，罗伯特，一过 35 岁，就成为最年轻的熔老头子了。

而这个年龄正是小夫妻最要钱的时候。买房还贷，孩子学费，人情往来，父母住院，一件一件事情令像泰山压顶一般袭来。

# 建议：

+   充分发挥民企业主渠道的作用。工资低总没工资好。有关部门一定要千方百计帮助各类民企业度过难关，不说全部有利润，至少 90%的民企业有利润。企业有利润，就业就稳定了，良好的社会治安就有经济基础了。

+   2，尽可能减少罚款，除了危害公共安全，食品卫生，其他违章事情，教育为主，罚款为辅，不要再吹毛求疵了。消防通道放了几个纸板就罚款，虽然合法，但是能不能缓一缓了，再犯再罚也不迟啊。企业这么大，个别工人不懂事，也要给个改正的机会。

+   3，方老总时，要把自己也放过去。不能老是盯着小老板，他们那个小身板，扛不起全部，方方面面也要拿出真金白银，说起来十条二十条，方起来，这个表格，那个申请，最后也不过是一点点钱。几十个人的小微企业，多个三万元补贴，也就是个精神鼓励，顶个啥呀？

+   4，五险一金，能不能三免五减半？这是企业目前最大的成本压力。说多了，也说不下去了。看看办吧！

+   5，劳动法能不能修改？凡是不符合提高质量管理，技术进步，鼓励吃企业的内容，直接删了。动作要快。
