# 现在有个经济学观点

中小微企业乱糟糟的，通过各种手段淘汰一批，最后每个行业剩下几十家大块头，不就好了吗？顺便发个通知，不经营的眼跟好点吗？

这种经济学观点在部分场合非常有市场，但这是有关xx们在办公里胡思乱想的，完全不符合实际经济情况。大头头企业，是喝酒吃肉的话，不会去做小生意的。中小微企业是拾遗补缺，填补市场空隙。例如，这个街道需要多少个水果摊，稳定需求，不是国企或者超级大企业可以规划的。是市场决定的，待大型企业的决策程序，很难做到刚刚好。要么多了，国家亏损，要么少了，居民难受。

制造业同理，中国需要多少个塑料桶，不是待大型企业可以预测的。那么招收多少工人，配置多少机器，需要多少厂房，都是未知数。生产少了，大家难受，招工多了，国企难受。市场经济就可以解决这个问题。

倘若火爆，厂里周急，拉上亲戚朋友找钱，再开一家小企业，以此类推，直到充分满足市场。如果市场不好了，企业老板分分钟稳定减产，原材料去卖其他产品。小老板不睡觉，也要把这些事情情况，但国企领导不可能分分钟决定改变。要开会研究，层层审批，为什么不完成计划，为什么变更，我没有吃肉回扣，也没有xx，等你走完这一套流程，其实已经不需要减产了，因为生产部分做完了。

中小微企业是最有活力的，最高效的。中小微企业也有缺点，就是穷。穷就抠门了，职工福利不如国企，解决办法也很简单，国企多招人就行了。为什么国企不招人，把就业任务交给民企？这话就拔根就发了。
