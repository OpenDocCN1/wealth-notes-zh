圾。要想稳赚利，必须是炒作价格。这个风险太大了。我哪有时间天天去看盘？就算有时间，我也看不懂啊。

其实有个搞笑的逻辑，你一个这么大的上市公司，每年分红（利润率）达不到 8%，你好意思吗？你是什么黄色，我 就 是 什 么 颜 色！

我建议，前 20 大股东把个人财产全部公示（地址可以详细到那条街）抵押，担保公司每年分红达到 6%，达不到，个人财产全部拍卖，用以分红。以后公司好了，再补给你。我保证，一晚上股票就火了。

# 如何让你悄无声息的赚钱？

现实生活中，有很多不符合经济学常识的事情。举例，淘×有很多炒手游，盗取了实体店成本和劳务，把实体店打的七零八落。这是不合理的，但没人管，有关部门貌似没看见。很多普通人甚至是幸灾乐祸的认为：小老板挂了，关我屁事，我只要便宜 80 元。淘×就是好。大部分想到这里，就美滋滋的去玩手机了。

但是，我比你聪明，我会再往深了想一层。实体店垮了，网络火了，会导致什么变化，有没有提前打桩的机会？果然，我发现了新萌头：快递站和实体店，对房子的需求不同。

实体店需要的是人流量大的街口路边摊。但快递站不是。快递站需要的是，人流量越小越好，门口宽敞一点，能停卡车卸货，一楼。这就激活了很多市区小角落的旺铺。这些店铺，往往是在一般人走不到的角落里，原本做不起生意，就是当仓库的。

六年前，我抄底两个这种烂货，马路尽头，靠个早已停产的老厂房，能够停卡车，平时没有人流量。办过户手续的时候，房东觉得，总算把这些路线货卖给这个250了，脸上洋溢着迷人的满足感。今年，我加价350万出手了，卖给了快递站小老板。

我说出这个私密事，是因为在京沪广深，这个机会已经不存在了。这么多快递站，已经把大街小巷挖掘干净了。但是，你要研究一下我的思路。不符合经济学常识和价值观的事情，往往会造其 他 方 面 的 巨 大 变 化 。 这 就 是 你 提 前 打 桩 的 前 置 区 。
