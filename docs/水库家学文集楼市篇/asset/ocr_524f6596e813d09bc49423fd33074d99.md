+   2，代持人一般比较穷。有钱人不会替人代持房子的，自己房屋还不够呢！

+   3，代持人往往会错觉的以为，你发财，都是我的功劳。

所有的问题，就出在这几个因素混合了。假设，这房子多年后涨了三百万，代持人心里扭曲了。

+   1，代持人开始认为，你赚钱了，是我帮忙，自己是有大功劳的，你是不是多意思一下？你也不好意思，只能是在他嫁女儿的时候，一两万两红包。

+   2，等涨了两百万了，代持人音调就大了。”我的名额给你用了，我就不能用了，这样吧，赚了200万，你给我70万“你肯定不接受，双方关系冷淡了。

+   3，代持人家里不宽裕，这么多年总会遇到各种麻烦，缺钱了，他就越想越气，你这么富，还抠门。他遇到一个什么大事情，例如大闹住院，心力憔悴，就发作了，直接问你要钱，双方新裂破裂。

+   4，等你要求过户的时候，代持人不理你了。让你先出个态度，一牵诺作五，大家还是兄弟。否则，摊你摊！就不配合。

# 房产空置率为什么那么高

某总行行长说是超过21%。这个数据实在是耸人听闻。我来说说说原因。

计算空置率，一般是按照水点米算的。例如一个月低于10元点费，基本就算是空置了。主要有：

+   一，超级豪宅空置率高

你去看看汤臣一品，也没几个人住。这些房子，大多数境内外大土豪买的，人家全世界有房子，当然入住率不高了。

+   二，旅游地产空置率高

我在很多地方有旅游地产，海南一到3月15日，整个小区彻底没人了，物业保安比居民还多。避暑度规房，一年只住一个月。

+   三，地县乡镇空置率高

这些房来，主要是在外地打工的，春节住一下。平时空置。

+   四，未装修房空置率高

每个小区，前几乎都是10-20%的房子没装修，自然就空置了。

+   五，人口下降区空置率高，例如东北

鸹锅的那么多动迁房，批量空置。

+   六，捂盘惜售的新房。

这些房子早就五证齐全，可以销售了，但是因为各种原因，没卖。京泸的数据很大。

+   七，待交易的二手房。

很多房子，在交易过程中会空置3个月。

+   八，正常空置

例如出国工作，精装修房子，舍不得出租。

+   九，上市公司囤积房子

略。

有些专家，不食人间烟火，看几个数据就大嘴巴了。我所在的小区，99%的房子是有人长期居住的。
