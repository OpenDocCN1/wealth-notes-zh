# 中美毛衣站

如果真来，弊大于利，但也不是完全弊端，例如对内资私企也有一点好处。

本轮贸易磋商的核心就是中国要大些进口美国商品，几千亿美元，反正我也数不清多少个零了。除了能源，高科技和农产品，还要进口很多日用品的。而日用品这一块，例如玩具、服装、眼镜、鞋帽等等，主要是私企生产的。如果大量美国商品进来，可能是结束墨西哥制造的，那么这些私企下场是可想而知了。其中一部分私企可能是毛都不剩一根了。但也有部分私企，可以安全的降旁，剩下一点点钱去买套房子。

私企在 2008 年是个转折点。之前出现过大量的隐形冠军，某一单一领域做到了世界前几名。例如玩具、吸管、塑料拖鞋等。4 万亿之后，劳动法出台，集资破产，一系列的变化导致了现在的私企已经很困难了（主要是私企自己不好）。当然还有很多好的，bat、华为、京东商城，但这些优秀企业数量也不是很多，他本身吸纳的员工有限。私企还是承担了 70%以上的就业。

最好不要发生贸易纠纷，如果一定要搞起来，那么，我们也有足够的信心应对。

# 西方经济学，本质上只有两派：

+   1，多印钞票派，财政有钱，啥都管了

+   2，少印钞票派，财政没钱，少管闲事

# 一句话讲清楚，西方经济学的几大流派

+   凯恩斯主义：大政府，小市场，印钞票。

+   奥派（哈耶克）：小政府，大市场，政府尽量少管，商人比公务员反应快。

+   新制度经济学派：降低交易的制度成本，繁荣交易。

+   货币主义派（芝加哥学派）：钞票印多了，要出问题。为人失业，别管他，他自然会去找工作。

+   供给侧学派：减税，少印钞，政府少管事。

+   理性预期派：上有政策下有对策，老百姓比公务员聪明。

+   啥也不管派：政府最好什么都不管，反正他管也不好。

+   我们肯定是选凯恩斯的！你放心。
