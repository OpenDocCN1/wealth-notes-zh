# 新增货币真实的流入实体经济

这已经是当前各种经济问题的最大焦点。其实，大家都懂，只是在装糊涂。让实体经济赚钱，资金自然就过去了！不用你引导，拦都拦不住。问题是，我们现在的实体经济不挣钱啊！为什么不赚钱？因为成本太高了。

我们的员工，有老有小，又要买房子，付房租，结婚生子，工资低了真不行。但是，社保和个税卡在那里。你给工人 1.5 万，工人大概拿到 8-9 千。你说怎么办？如果算上对工资保证的增值税，算了，还是别算了。

价格高了，自然就不动了。我们大部分的商品价格，和欧美大超市里差不多，质量就不说了，工资比人家低多了。你说怎么办？

我们的一件不知名的县城生产的男士羊毛大衣，商场里一万元是普遍情况，八千元就好像大减价了。你去欧洲看看，大牌也就这个价格！这种价格，销路还真是自找的。H&M, Zara, 这种低价服装都在进口了。我们是世界第一人口的发展中国家啊，宝贵的外汇在进口低价服装，真是无语了。

为什么我们的商品不能便宜下来？你问我，我也不敢说明！要不，你去开个厂？试试看？

# 有人说旅游可以花钱

+   一、国外游

我是国外留学回来的。（不像有些爱国人士，一家老小全部在国外买房子读书）。我对国外实是在不感兴趣。

+   二、境内游

我是怕了。倒不是钱的问题，而是纠纷多。如果当地没有房子，我不太喜欢去。团队游，导游虎视眈眈，逼你买中药材叶玉石，不买就翻脸。自由行，吃住行自己安排，很累心。特别是交通，很容易出现纠纷，一天的好心情也没了。

+   三、时间不匹配

有老有小的家庭，只能是黄金周去旅游。黄金周旅游，实在是太恼人，坐个索道排队三四个小时，孩子实在受不了。我们不是去看风景了，而是去看人了。吃饭抢座位，质量一塌糊涂。

+   四、思考

扩大消费，本质上应该是高中低分开消费。但是，由于屌丝们的斗争意识太强，任何富裕消费都会上升到某种高度。我花不起这钱，我也不让你花钱。举例：

住房。京沪 99% 的人买不起几千万上亿豪宅的。无论高端豪宅是不是限购，反正和普通人没有毛钱关系，那就放开啊，让买得起的人买啊。呵呵，不行，我们屌丝买不起，我也不让你富人买。

教育。99.99% 的人是考不上清华的，那我出 500 万读一个行吗？不行。我考不上，也不让你花钱读上。反正把你拉下来，我就开心了。

车牌。摇号摇不到，我出 80 万买一个行不行？不行！屌丝心里不舒服。

出国买房。也不行。除了最受搞的手机老板，其他人出国买房，真是没办法。

反正，不让富人把钱花出去，我就开心了。这种环境下，扩大消费，只能是低质量的重犯了。我买的手刷，两年就卡了。他们还不让我投诉，非要我去买新的。买你妈的。
