# 资产荒来袭

现在，资金不发愁，银行的子弹充足。但是，我们就眼望去，就是没什么好投的项目。为什么呢？目前实体经济的大麻烦，不是资金问题，而是企业无利润。

正常的实体经济，除了技改和修建农民宿舍，一般不需要多少资金。自有资金，供应商账期，卖点库存，最多再外借100-200万，已经足够了。如果企业是经营良好的企业，亲戚们立马把钱给你送来了。

我有个表叔，非要把6万万元放在我这里，按照9%的利息，一年给他5400元零花钱。我几次要还债，她眼泪汪汪的求我不要还，想继续吃利息。一二百万，也就是个老破小的首付款，老板老表叔因五家亲戚，凑一凑，真是分分钟到账。根本不需要去受银行的气。

现在，很多实体经济的老板，不停的夫喊大叫，缺贷款。这些人不是什么好人，都是玩资本运作的。房地产搞了一半，资金链断了，急需了。因为他们的社会地位高，说起来一套一套的。其实，他们是资本大鳄，不是千千万万的中小企。

现在的中小企业，最缺的是利润。同样做皮鞋，十几年前，刚踩缝纫机搞起来的时候，那是真有利润。否则也不会扩展了。现在倒闭了，同样是皮鞋厂，质量更好了，款式更新了，设备更贵了，居然没利润了。那么，利润到哪里去了？

有关部门以非常漂亮的理由，让小老板交这个，交那个，基本就这样了。

当然，我们肯定会充满激情的赞美有关部门的正确决定。

中国经济稳中向好，我们欢欣鼓舞。
