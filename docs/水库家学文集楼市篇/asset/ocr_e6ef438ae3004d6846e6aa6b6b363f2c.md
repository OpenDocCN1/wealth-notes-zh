# 海南买房，我是中立态度

云贵川鄂，东三省，京津疆，河南山东山西，是海南的主力客源。因为这件事，父子成母女，家里打成一锅粥，拍桌子顺茅盾，鸡飞跳跳的情况，非常多。主要原因是，老人看了海边的鸟语花香，蓝天白云，坚决要买。子女用不了几天，不想出钱。

我只有一个建议，老人先住一个春节试试看，成本1.5万~2万。

+   1. 海南租房，高中低都有，民宿是捡×网。去宾馆，上携程，海南各县的碧桂园X星级宾馆（很多），订一个月，可以争取一个优惠价。

2. 海南买房，总价120-250万为主，都是一次性付款，没有贷款。两年后，你在本地交个税，满两年了，可以办证。

3. 海南的旅游地产，你要想今后卖掉，只能在老家的朋友圈里。海南大城市和县城中心地段，本地人的房产，还有些中介买卖。旅游地产没有中介的，房产商是严防死守，绝不能让你的散户挖地脚的。

4. 海南旅游地产，交通困难。海南两个机场内就有“x吨租车”，订个年，每月6千元左右的成本。支付宝既行了，超级方便。取车时，对车拍照，证明有些瑕疵是原有的。我订过几次。没有什么纠纷，返程时，要提前几个小时还车。

5. 家里的老头老太，要盯紧着看牢。老人很容易冲动消费，先在海南付了五万八万定金，再回来和子女商量。如果子女不同意，老人心疼那几万块，要死要活的闹翻天。如果是老姐妹，老同事，结伴而行去海南，子女一定要事先说清楚。
