# 美元真的能跑掉吗？

很多人以为，我们外汇管理超级严格，外汇跑不掉的。其实不是跑掉，而是少来。

中国的创汇，45%是民企创造的，部分是卖给了外国大超市，例如沃尔玛，赚口袋很清。但也有一部分出口是卖给了在外国的老板孩子表弟，例如世界各地的唐人街，批发市场，都是华人小老板在卖货。这部外汇流，回不回来，回来多少，完全是看汇率。如果不划算了，就可能少回来一点。一个滑板鞋的出口价格，是10美元还是20美元，有时候真不好判断了。

还有一部分是香港内地的零星贸易，省略一百字。
外汇政策很复杂，我就不建议了。

# 人民币面对美元加息，有点为难

目前人民币贷款余额约 130万亿，外汇贷款余额 6万亿（人民币口径），如果半个点，相当于要从实体经济中抽走 6500 亿。对比中央财政一年也就是 12万亿的规模，类似于全社会税费整体增加 2-3%。以此类推。

+   1，目前，人民币不适合加息，要想留住美元，汇率破 7 的问题，再度摆上桌面。

+   2，如果人民币贬值，物价就要上升，实体经济更加困难。

+   3，2019 年的日子不好过。各行各业的人员调整，摆在脸上了。

+   4，建议适度的减税减费，可以对冲成本上涨。

# 美元加息，钱更贵了

美元加息，短期内对世界经济是一个打击，钱更贵了。具体到亚洲新兴市场，风险投资机会减少，互联网行业的寒冬开始了，房地产行业的美元债更贵了，外汇流出速度加快。美元升值，油价可能略微看涨。
