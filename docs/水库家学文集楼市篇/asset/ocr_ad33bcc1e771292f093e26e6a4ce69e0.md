# 第三机场确定

利好青浦和昆山居住区。

最近几年，青浦区和昆山市交界处的居民区，因为考虑到机场的巨大噪音，总是让人有点发愁。现在，这个问题彻底解决，大利好。

建议：虹桥机场晚八点就关闭算了。跑道两头的居民，饱受噪音污染。

# 大型机场对当地经济的拉动

是个缓慢过程。

浦东机场开通后，专门设立了一个机场镇政府，还搞了临空产业园等。整体看，利好兑现有个过程。

一，短期意义

+   1. 货运客运加速发展。
2. 新建几个宾馆。
3. 航空食品加工等。
4. 航空维修服务
5. 本地就业大发展。机场是用工大产。
6. 适合空运营的高科技企业（芯片笔记本 iPad）大发展。

二，长期意义

浦东机场在发展了二十多年后，终于迎来了迪士尼，拆迁了附近农村。

三，也有一些不利因素

+   1. 噪音污染区（一般认为十公里外无影响），不适合住房。
2. 距离上海太远，主要是辐射苏中和崇明浦东。苏州，浙江居民，不一定愿意去。
