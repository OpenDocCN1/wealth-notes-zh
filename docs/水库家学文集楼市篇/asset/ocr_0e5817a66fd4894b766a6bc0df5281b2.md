# 客观看待中国经济

1978年，中国还有很多地方，饭都吃不饱，姑娘姨婆婆裤子都没有。仅四十年，中国每个家庭都买得起美国别克轿车了（不一定是真的去买）。城市建设超过欧美。居民家庭每年也有2-3万美元的收入。这是非常非常巨大的成就。
