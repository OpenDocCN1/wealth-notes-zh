# 机场对于上海的作用

上海第三机场，将对上海经济发展格局产生重大深远的影响。

首先，机场对于上海的作用，是重中之重。上海已经不是那种傻大粗黑的制造业基地了。上海经济发展的讲究的，精巧快速的信息物流和人员往来。例如，芯片一个就是几百块钱，几千块钱，一手摸烫的芯片可能就几十万，这种物流快产品对机场的要求就非常高。另外，包括人员往来的快速便利。上午在新加坡吃早饭，中午下午在上午谈生意，晚上去日本休息。所以，机场对于一个大的城市发展是非常非常关键的。

第二，上海目前有两个民用机场，浦东机场在东面，虹桥机场在中间，如果昆山机场将落在西面，上海整个经济发展的重心，明显向西搬的趋势已经发展。浦东机场在海边，对老百姓生活的干扰确实是最小的。但是，成本非常巨大，因为浦东机场辐射的整个江浙沪。如果从浙江嘉兴、苏锡常，往浦东机场和往昆山机场，单程打车费用要节约200块钱，来回一次就是节约400块钱。这个费用，在企业层面和居民家庭，其实非常高的。另外，上海南面的居民，其实更加愿意走虹桥机场或者昆山机场。

第三，昆山机场如果建立后，适合空运的高档次项目，会迅速在昆山和青浦那里落户。特别是，与飞机相关的，飞机保养维护，人员培训，餐饮住宿等一系列高附加值产业，将明显的加速发展，与之配套的地面交通物流产业，人员物资进出，也将迅速发展，成为辐射浙北和苏南的重要集散地。就业增加：高薪资位数量的增加，对嘉兴，昆山，青浦，松江四个区域的房地产价值，将产生巨大的拉动作用。

第四，上海大虹桥经济格局，正式拉开序幕。

昆山机场考虑，将改变上海新一轮经济发展的格局，上海近20年是以浦东为经济发展的龙头，上海的经济向来是浦东最大。但是，现在浦东新区房价地价非常之高，已经很难满足大型工业的土地要求。盈利水平并非很高的物流企业/企业，在浦东新区的高房价高造价面前，也是颇为尴尬。从新的时代要求看，需要有一块更新的成本更低的文区来，实现上海今后20年的发展空间的求，大虹桥生些时其。

第五，江浙沪经济一体化，是中国经济发展新模式的重要探索方向。

区域经济一体化，城市集群发展，必然是要有一个抓手，这个抓手现在看起来，和讨论中的昆山第三机场是有重大联系的。青浦松江昆山嘉善交汇处，工商业土地价格，现在还处于全上海较低水平，昆山机场进入正式运营，这四大区域会成为新的经济增长点。

这个规模和时间长度，可能不亚于浦东新区的开发开放。
