# 如果他们家京沪有一套漂亮房子

楼下附近小店，是一个老界首甜户区里面的破房子，没有厕所。小店老板娘是外地乡下来的，两口子带一个孩子在上海读小学，老板娘每天下午去接。据说老家还有两个小姐姐，小夫妻就不管了，留给老人照顾。

那个上海借读的小孩读书成绩一般，在公立小学，据说是普通班第 15 名左右，五年级。孩子天天在看各种各样的课外书，因为上海公共图书馆非常多发达，一次可以借五本。我看了一下书名，没有一本是讲考试的，全部是大自然的秘密，宇宙的秘密，海洋的秘密。

我看了之后觉得挺不是滋味儿。这样的孩子其实在上海很难有什么前途，书也念得不好，长的又矮又瘦，家里也没有条件，其实他应该研究考试，分数，而不是看这些杂七杂八的东西。

当然，如果他们家京沪有一套漂亮房子，嗯，城市让生活更美好，京沪欢迎您。

# 学区房的作用并没有完全消失

原来一校一片区，入学或功率是 99%，现在是多校联合保位。根据国家义务教育法“就近入学”的原则，只不过是把成功率从 99% 降低到 30%。

好的学区依然会成为家长购房的一个重点考虑因素，但权重比以前降低了很多。单纯的学区房概念即将历史性的结束。

# 老百姓抱怨房价很正常

现在，极个别的老百姓抱怨房价问题，也不是完全没有道理。

按照国家统计局的数据，大部分人的工资是在 8000~12000，这已经很不错了，夫妻两个人一个月收入 2 万元，很正常。贷款月供只能是 Half，1 万块钱，最多只能贷 200 万。

如果是套套房，他最多只能买 300 万的房子。现在京沪广州哪里有 300 万的房子可以使老百姓正常的上班上学的，这个明摆着就是让你买不起了。

到底是什么力量造成了焦虑？大家难道看不懂吗？

# 领工资的怎么买得起房？
