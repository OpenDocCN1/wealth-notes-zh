# 我给你十块钱 (2018.11)

你能不能让我笑一下？

移动互联网的下半场，普通人能够赚钱么？我们来先思考一个普通问题：类似于支付宝（荣荣）这样的全定制网红，有没有存在的价值？很多人认为没价值，就是一个卖皮子的，最好退昌平沙子。再问：这么多年来说房价价值的经济学家有价值吗？相声演员和歌手有价值吗？这个答案，我放到最后讲。

我们都非常熟悉移动互联网。移动端的上半场主角是，卖家。现在换到了，省路一百字。马化腾说。下半场是产业互联网，方兴未艾。那什么是产业互联网？按照一般人的理解，就是把移动互联网和工厂企业联系起来，做大数据，分析销售。皮鞋厂最好在每个女人的 bra 里放上芯片，自动连线手机，看售我的货品最后卖给谁了。

这可能是产业互联网的一个细分领域，但只是很小的方面。我理解的核心是，移动互联网有无界限的的优势，满足人们一个极微小，的需求，创造财富。
