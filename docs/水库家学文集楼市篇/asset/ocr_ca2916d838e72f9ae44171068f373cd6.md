# ## 房价是由就业岗位决定的

特别是高薪岗位。

就业越好的地方，房价就越好。你住在内环线，在家门口找个简单岗位，还是很快的。实在不行，你去贴物业要求在小区里当保安，出门就算上班了。

我有一次去市中心三甲医院，在附近小区停车等人，就和保安大叔聊聊天。保安大叔五十八岁，他说，他这一辈子就在这个小区里。六十年代出生，长大，结婚，生娃，中年失业离婚，在小区里当保安，一个月工资三千。实际收入六千多。我顿时来劲了，为啥？

他说，你们白天来停车，有的人也不要发票，这就算我的了。要不是物业安装了探头，我一个月八千都有。他还说，小区门口我有小块空地，如果停车，我进出很难，但一个小时十块我成了，难就难，我也不在乎。这是我的小金库。

我差点哭出眼泪了。
