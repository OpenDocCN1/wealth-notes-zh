# 最好明确一下，不能补缴社保

这是重中之重！

不过西安实行外地人社保五年，考虑到落户太容易了，实际意义有限。落户后满一年买房，有点作用，至少租房市场会适当上扬。但是，一年限购的力度是极其微弱的，房价最多只会更加稳一点，尽可能避免集中购房。

![](bbox=[0.13, 0.46, 0.64, 0.49])

【落户西安需1年才能购房，临潼区纳入限购范围】西安市房管局刚刚发布消息称，为深入贯彻落实中央“房子是用来住的，不是用来炒的”定位精神，逐步适应投资投机性购房需求，稳定住房市场发展，建立促进房地产市场平稳健康发展跨部门领导小组审议，现对进一步加强对本市住房经营管理有关事项通知如下：

+   一、自本通知下发之日起，从市外迁入户籍的居民家庭（赠送 property、家庭成员落户的除外）在本市住房限购区或限购范围内交易具备住房满二年住房的，自落户满1年，或在本市连续缴纳12个月的社会保险（或个人所得税）。

+   二、非本市户籍居民家庭在本市住房限购区或限购范围内无住房且能够提供5年以上（含5年）个人所得税或社会保险证明的，可购买第1套商品住房或二手住房。

+   三、将临河区纳入住房限购范围。严格执行我市住房限购政策。
