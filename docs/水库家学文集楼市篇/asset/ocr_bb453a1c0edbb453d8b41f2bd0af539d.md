# 家和万事兴

近十年，楼市极大的奖励了“家庭和和睦”。小王姑娘是省城某大院长大，父母皆有地位，自己也是一帆风顺的在美国留学，结婚，生子，2011年，小两口双双拿了上海集体户口并且定居上海。在买房问题上，小王倾向于一步到位，静安区大平层，当时大概 1 千万，全款解决。这时候出现了意外情况。

+   1.  老人外面有了情况，闹离婚，不舍得拿出这笔巨款（2012年的巨款）。丈母娘一天到晚哭哭啼啼，没心思管女儿买房。

+   2.  公婆虽然有拿出一半的经济条件，但是那年代在外地生活，没什么见识，对比省城两三百万的豪华别墅，从来没想过世界上还会有一千万的单元房，总觉得价格虚高，要暴跌，舍不得出钱，想把钱拿去理财吃利息。

+   3.  老公，面对父母不舍得出钱的尴尬局面，不说实话，采用哄骗的办法，诱导小王说，房价要暴跌，租了一个豪宅居住。

+   4.  小王姑娘自己也设有主见，就拖了下来。

后来，公婆买股票被奉套，本金损失大半。父亲退休后，闹离婚成功，在母亲的逼迫之下，小王父母在省城三套房子（现在合计估价 800 万）写了小王姑娘的名字。但房子里都有人居住，无法变现。现在，小五夫妻在上海，啥也没有，连儿子读书都没办法落共享区。

小李姑娘，是北方县城的中产家庭，父亲在小地市民企当总总监二把手，母亲是家庭妇女。小李自己比较争气，考入了上海某业编制，拿到了户口。2011年，母亲给了她42万作为嫁妆，她自己存款除了10万，找男朋友要了8.8万彩礼，在外环城首付了一个漂亮小区，现在价值700万。老公是比她高两届的北方小户人家，上海也曾首买了房子，目前合计房产价值1500万（贷款不多）。

小王和小李的父母，应该是天差地别的阶层，一个是天上，一个是地上。但是，仅沪一个游戏，就把这几十年形成的巨大差距，抹的干干净净了。

感谢 m2，感谢京沪，感谢伟大时代！中国经济稳中向好，我们欢欣鼓舞。
