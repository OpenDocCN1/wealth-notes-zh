只要你触及到了员工的利益，那么员工就千方百计给你制造障碍。最后很多民营企业就变成了稀里糊涂的过，只要大体上还有点钱挣，大家就不断破裂。

如果触及到了利益，就变成了举报，打官司，雇洋汇，出卖技术信息，出卖客户名单，各种乱七八糟的事情一大堆。而这些问题所引发的法律争议，成本是非常高的，很多小老板也没有精力去搞这个。

或许你可以举出几个超级大企业，他们管的非常好，他们是干得非常好，我们并不清楚。一个企业在高速发展的时候，利润大，发钱爽，那么乱七八糟的事情就少，老板有钱赚，员工奖金多，大家就很和谐。

但是，天天赚大钱，年年大发展的企业，是非常少的，大部分企业，还是一个相对稳定的利润，那么这个时候，老板和员工之间的关系就是你多我少的关系，这种关系是很紧张和微妙的。

微观经济学在处理复杂利益纠纷的过程中，基本是没有作用的。

# 西方宏观经济学

本质上是臆腾九的规则。

宏观经济学不会让你发规财。大部分经济学教授不是富人。少数有钱的经济学学者是急走穴演讲之类的，他们本身并没有什么成功的办企业，做投资基金。

学习宏观经济学的唯一目的是，学习打牌的规则。

某投资领领域，发生了剧烈的变化。有关部们要干预。有关部们怎么出手，怎么干预，他采取措施的内心理顺来源于哪里？这就是宏观经济学的秘密。有关部们干预的思路和措施，往往来自于主流的或者是热门的宏观经济学理论。

通过学习宏观经济学，可以高效准确的判断有关部们的思维方式，将来可能怎么出招？聪明的人就可以提前打铁

# 新加坡的战略地位有多大？

马六甲海峡喉咙处是 37 公里，大船不可能通过航行，一般是走中间的。新加坡只要花三十万美元，摆上几个二战时期的老炮盖子，就可以隔断中柬产区进入太平洋的航道。

+   1. 绕行马六甲，要多 15-25% 的距离，邮轮还必须多带生活物资和燃料，少装油，结果是东亚各国的石油成本大幅度上升，经济效率滑坡，基本无力参与世界贸易竞争。

+   2. 绕行马六甲，就必须通过其他国家的海峡，别人也不是什么善男信女。

+   3. 由于马六甲是各国关注的重点，不可能被一国独霸，新加坡在漩涡中心反而最安全。

# 新加坡的经济之本是什么？

马六甲海峡。

全世界四分之一的油船经过马六甲海峡，中国 85% 的运输油船经过马六甲海峡。国际贸易的集货货物集散地。有些原材料到了马六甲，直接上岸加工后，再分销到世界各地。
