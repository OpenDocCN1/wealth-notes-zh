# 省会慢慢胜出，是必然的

莱莱，我是你的粉丝，柳州原为广西经济第一，现已被南宁远远超过，包括GDP、税收、城建。南宁有地铁，柳州轻轨在盖。

答：中国是竞沪。与此同时，沿海省份，一省双雄是普遍情况。今后慢慢的，省会会胜出。这是必然的。因为我们现在的经济模式是有部门主导的，各种优质资源会向省府倾斜。

原来，苏州是远远超过南京的，现在，南京快速上升，和苏州基本差不多了。宁波原来是优于杭州的，现在宁波远远逊色于杭州。柳州大连也是。

一省双雄是历史形成的。经济大市往往是沿海大港口，自然属性优越。省会往往是腹地，现在是资源倾斜堆起来的人造景观。研究这个问题的目的是，预测未来。现在，青岛，厦门还领先于省会，但这个趋势也快了。济南，福州必定会越来越好。

北京已经全面领先于上海了。金融，互联网，科研，文化，教育，卫生，北京超过上海半个身位是毫无疑问的。上海因为靠近大海，在部分制造业略有优势，例如海工，飞机等。但北京拥有两院院士，重大项目的唯一主导，科研力量是远远超过上海的。

# 如何研究经济学？

很多250喜欢套数据，画个饼图之类的，那只能是搞骗傻B。我从来不看数据，因为我知道数据是怎么来的。我相信做过统计填表的人可能会笑了。某些时候，也就是按照上面的要求，略微加一点点多，不能多加，也不能少。

我使用的是田野调查，深入基层，去一线，去工地，去车间，去批发市场，去拆迁现场，和部分行业的小老板保持十年以上的联系，定期沟通，遇到问题，一起研究。

那些厚厚一大本，艰深难辨，永远平稳的统计数据里，看不出市场和人心，看不出金融机构对小老板插干杀手的狠劲，看不到劳动带来各种影响，看不到小老板的眼泪和喜悦，看不到楼市的风云变幻。
