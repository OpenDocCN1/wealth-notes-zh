# ### 屌丝专家总是说房价到顶了

我买的第一套内环的房子是1999年，3600元。几年后涨到了一万元。有个复旦大学的屌丝专家谢某说，到顶了，到顶了，三借利润，远离出货。我尼玛的，现在已经是10万单价了，幸好没理他。

# ### 房价大格局，进一平二

房价，三年一个周期。一年暴涨，货出清。然后，卖方也没货了，买方也没钱了。专家们一看，火柴差不多，就跳出来说好人了，严厉谴责高房价，限制投资开咔咔。

实际上是封山育林，休养生息。两年后，新一批韭菜有资格了，开发商的新货也备好了。找个理由又起跳。

# ### 房子票子的合法途径是资源互换

在这个世界上，不论男女，要想获得房子票子，合法途径是资源互换。男的，要有技能。女的，要有资源。偷抢拉毕竟不是长久之计，而且到处犯法象，日子也不好过。你什么也不拿出来，就在家里幻想，有个非常爱你的白马王子带着内环几大平层来娶你，或者有个家产比金灿土给你买单，那你大概是吃饱了。

# ### 一千多万的房子，是较富裕家庭的极限

上海有一套一千多万房子，是较富裕家庭的极限了。标志是：2008年后建成，带地下车库，内环线，100平米左右的漂亮新房子+地下车库。中环线，大三层，漂亮小区。例如新江海域，徐汇，张江。外环线，漂亮欧式小群排或带复式。

外环外，花园精排的边套类独栋，上下五层大花园。看上去档次很高的那种。参考佘山别墅区。若有两个以上房产，就是小豪了。三个就是中豪了。上海因为法律原因，基本没有完全的独栋别墅。买个双拼，凑成一个独栋的，极罕见。

# ### 买二套房，要看十年大趋势

年入百万的普通家庭，买二套房，要看十年大趋势。上海限购二套。如果你不是什么大土豪，基本就是2-3套的圈圈里打转了。例如万一你结婚后多买一套之类的。买房有个硬门槛，资金。绝大部分家庭，前面有贷款，后十年不断积累，再存个第二套首付款，基本是极限了。我一直不说哪个楼盘便宜一点，哪个楼盘会多涨个5%，这是股神给糖子的短腿做法，不适合楼市，买套一套上海房子，投资几十万，没事最好不要轻易动，这就是房产不炒的基本含义。
