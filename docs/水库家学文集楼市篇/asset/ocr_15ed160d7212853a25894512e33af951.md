# 答复某个 250

为什么说楼市是蓄水池？

蓄水池的意思是，增发的货币不要冲击物价，从而引发大的通货膨胀。只要不冲击物价，钱在谁的手里，并不重要，反正就是一张存折，写几个数字。

很多家庭有 100-500 万存款，按照经济实力选择相应的房产，再贷款 30-70%。通过几块砖头，一下子把你家三代人的积蓄拿走，还把你家今后二十年的消费给卡死了。接下来的漫长岁月，各家各户要节衣缩食，减少消费。收了钱的开发商，自己又花不了多少钱的。这样，物价就稳定了。
