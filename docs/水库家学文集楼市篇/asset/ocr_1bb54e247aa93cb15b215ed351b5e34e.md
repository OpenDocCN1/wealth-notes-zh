# 专家对楼市的三层分类法，值得学习

+   一，自住和租的出去的房子，放心买，那是一笔不亏的收入。
二，哪里房子租的出去？京沪广深为主，十个八个的强省会豪合。
三，租不出去的房子，结局是很悲感的。

1，现在的乡镇房产，基本租不出去。县域 80 年代的老房子，空置率也高。
2，一般地级市也有大量已装修的楼房，长期空置。因为 80 后的小夫妻凑房，长期在大城市打工。只有春节半个月才热闹。
3，海南，北海防城港的过冬房产，各地的旅游地产，出租很难。供应实在是太大了，也卖不掉。开发商防止小业主抢生意，一般在自己的区域内，严格禁止中介存在。
四，严格限购的地方，一般没有投机购房了。

+   1，上海单身外地人都不能买房，老了回乡下。上海户籍的单身，只能买一套，住到老算了。
2，外地夫妻只能买一套，子长 4 长大后给孩子，自己早点回乡下。
2，上海夫妻可以买两套。现在市区新房最少 7-800 万，首付七成，买得起二套房的人很少。孩子嫌房都很困难。

五，不限购的地级市或者县域，还可能存在炒作投机，这批投机客的下场比较惨。因为小地方的新房供应量是无穷无尽的。你要多少，我就造多少。

六，建议
走，我们去大城市！

# 关于代持

答疑。房产代持的风险。最怕对方发生意外，例如对方夫妻离婚婚破裂，失去行为能力，公司破产，法院查封，重大灾害，变成遗产，重大负伤之类的。

1，代持一般是长期的，代持一两年，要多少道几十万完成上百万的过户费，就划不来了，很多人还不如晚两年买。所以，代持最少是五年以上。
