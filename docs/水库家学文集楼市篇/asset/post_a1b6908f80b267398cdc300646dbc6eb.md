# 高度警惕房地产市场的过剩情况

总体而言，中国住房是严重的结构性过剩。我今年40岁，从我懂事开始，农民就不停的造房子。等我读大学的时候，中国的大城市相继进入了高速的拆迁期。拆到现在20年了。今天的大城市和20年前相比，等于基本拆干净重新造了一遍。几十年来，我们把绝大部分收入都投入到造房子上去了，中国的住房过剩的苗头已经显现。

但是，还是有越来越多的人进入大城市的大学生，天天抱怨买不起房子，甚至是租不起房子，这是什么原因呢？这叫结构性过剩。十年前，全国各地平均的造房子，京沪省会，县局乡村，全面开花，处处造房。但中国城市化的进程是，人口快速的向大城市和特大城市聚集。这导致了两个非常明显的后果：

- 一是以京沪广深为代表的特大城市，住房短缺，房价暴蹿，原来的居民只要早两年买房，涨价收益超过了十代人的积蓄。这是非常荒谬的，也是不应该的。
- 二是乡村大量的房产被废弃，中小城市也就是春节热闹几天，平时没什么人流。

住房供求关系，两极分化，非常明显。大城市造房子和小城市造房子，在成本上本上实际是一样的，但是收益却截然不同。这就是经济学的问题了。

宏观问题，普通人也无能为力解决，你只要大概知道就行了。微观问题，涉及到每家每户对未来生活的规划，必须高度警惕。

- 1. 人口向特大城市，省会和发达级地市聚集，是大势所趋，浩浩荡荡，不可逆转。特大城市和热点地区的住房，在今后5到10年内还将处于供不应求的状态。如果你们准备在大城市定居生活，要及早安排。
- 2. 小城市房产只适合自住，绝对不要投资。小地方，人口外流，优质高收入人口纷纷走了，即使今后有农村人进城接盘，他们的支付能力也是微弱的，你很难指望什么收益。

地级市分化趋势，即将开始。

- 3. 中上档次地级市，省府前三名城市是可以指望的，长期持有，能够跟得上通货膨胀和M2的增速。
- 4. 中下档次的地级市和非热点县级市，只能买自住房。有钱的，高学历的年轻人走了，进来接盘的，主要是省内乡的农民和普通家庭，支付能力较弱，货币负循环。这类地区不适合任何的战略投资，你就把房屋看作是消耗品，小地方的，而不应该于任何的金融属性。

结论：特大城市和大型城市是多数年轻人将来的工作地和居住地。下一代长期定居的地方，所以尽早的解决住房。老家也就是父母养老，或者今后自己退休生活的地方，2室一厅足够了。

# 房地产市场对经济发展的作用

限制预售是房价稳定发展的基础性制度，是楼市健康发展的重要基石。

按照正常的规律，房价一旦开始上涨，就会进入自我加速。所有的人都押钱了，越来越多的人加入，每一个加入的人都可能会让房价迅速的往上攀升。新建楼盘要三个月，但是买房决策只要几秒钟，短期内供不应求，房价暴涨。

房价上涨的顶部，子弹打光了，社会上再也没有资金去大量购入了。这里有一个重要的前提，货币总量固定。我们现在不存在这个前提。所以，没有任何人，或者任何权威部门，敢说房价什么而破裂。

社会上没有多余的钱去换盘了，房价基本停涨了。但是，这么多房屋，估计总会有1~2%，家里出问题的人，企业破产了，夫妻离婚了，急于移民跑路，需要把房子卖掉，但社会上已经没有钱去接住他的房子，只能是就被降价卖。

此时，市场上扛得住的人都不会卖房子。卖房的，都是急于要钱的人，都是急降价，这就形成了价。

- 直接打三折，是香港市场的经验，直接打五折，是东京市场的经验，直接打七折，是美国市场的经验。

房地产市场无论如何火爆，在阶段性总是有一个顶部的。解决的办法是，当楼市接近预期90%或者95%时，出台一个限制楼市交易的政策，在市场上留一部分机动购买力，随时吃掉那些低价而破盘，跑路盘，避免出现降价风潮。

# 全国不动产联网

现实的微观影响是：法院执行，房产税，限购依据。

宏观层面的影响是：经济决策的依据。

- 一，法院执行，廉政建设，略
- 二，房产税，明确是地方税。各地只能对区域征收，异地联网的实际作用，暂不明显。
- 三，对限购的影响，京沪广深对异地第二套的认定。现在是处女贷，今后可能是异地首套房。
- 四，禁止全国购买第三套房子的可能性为零。

假设你在老家或者京沪隔壁区域，因购买继承，已有两三套，如果禁止在京沪购买第三套，那直接反应就是，卖掉小地方房子，腾房票。这个情景蔓延开了，对二三四线城市的财政和楼市的打击，实在是太惨烈了。

京沪家庭在环京，海南，重庆，嘉兴等不限购地区，买第二第三套房的情况很多。例如老夫妻在京沪只有一套六十平米老公房，住住是卖掉老房得款 400-500 万，大部分留给儿子在京沪首付一套新房，老夫妻在环京环沪的便宜地方买个房子养老。这是化解社会贫富差距，缓解大城市住房紧张的好办法。

若干年后，儿子媳妇有能力在京沪买第二套，如果禁止全国第三套，那么肯定是卖掉二三四线房子，聚焦京沪，因为孙子结婚也要提前准备了。卖外地，买京沪的情况一旦蔓延，小地方楼市就关门吃面了。这就涉及到，理论界怎么看待楼市作用的问题？

目前看，京沪人口拥挤，交通堵塞，房价暴涨，确实需要严格限制楼市，减少人口。但对于很多二三四线城市群，楼市是当地数一数二的支柱产业，卖一个楼盘就是几十亿，小地方要创办一个年销售几十亿且赚大钱的大企业多困难啊！小地方财政收入的大部分和楼市相关，拉动了装修和家具家电销售，对就业影响巨大。如果因为京沪限购，导致小地方抛售房产，小地方的有关部门是绝对不愿意看到的，这就等于为地方倒贴盘地方。

除非在全国层面彻底放弃楼市的经济拉动力，彻底否定财政对二三四线城市依赖，否则全国禁止三套房的政策只会是小地方吃亏，京沪其实也没啥影响。
