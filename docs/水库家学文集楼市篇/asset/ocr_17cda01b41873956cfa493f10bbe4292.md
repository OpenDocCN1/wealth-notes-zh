# 京沪楼市呈现出了黎明前的祥和

2008 年前，商业富人大集中在珠三角和长三角。我家的内地生意伙伴，那时候穷啊，50 万都拿不出来，现在动辄几百万，不够猎头。

四万亿，横空出世，内地资源型产业，蓬勃发展，富裕人群结构彻底改变。

2010 年后，各县市集中出现了一批富人群体，红黑白，各种情况都有，矿老板，工厂主，企业家，富豪的，甚至是村干部。

这群人因为各种原因，一下子富起来了，但是他们的投资意识并没有形成。各种五花八门的投资，层出不穷。我见过西北的富人在 2010 年砸进去几百万，买北海的垃圾别墅，还有的在县长城地级市乱买。最好笑的是，还有买字画，核桃，文玩的。

2012-2015 年，是楼市调控期，各地媒体楼市都不太好。这拨刚刚发财的人也没看明白，哪里的金条，哪里是稻草。

2016 年，绝对是载入楼市历史的一年。京沪楼市，摧枯拉朽，气象长虹。资金流，一路向西，横扫各地楼市，造成了全面普涨局面。当然，涨幅表现不一，有的涨 50%, 30%, 20%。

到 2017 年 3 月左右，全国楼市已经是收敛的态势了。曾经牛气冲天的燕郊和环京各县楼市，一个接一个的悲地割下，连挣扎一下都没有就挂掉了。内地大部分城市的二手房市场，有价无市，中介一条街，一夜降温。

这一轮的楼市大震荡，用真金白银，实打实的教育了所有散户。京沪楼市是金砖堆起来的，其他地方是融资起舞。这个常识已经在各地富裕人群中完全形成了，这个心理阻力，是非常强大的。各地富裕人口，随着子女大学毕业务向各大城市，陆续卖掉老家资产，资金迅速向京沪集结。买不起豪泸的，也往大城市涌动。

目前看，京沪楼市表现平静，但这种平静是强力限购压下来的，内地普通家庭对京沪的价值没有一丝一毫的怀疑。限购总要有到期日，討老總总要有个房子吧？留在张了，这事情，你说怎么办？你是大学生，你先说！

# 拍死房价是很简单的

但是，方方面面的代价太大了，承受的起吗？

说个简单例子，很多县级市中的小业，在 2003 年工资都发不出来。有的县里，还拿贷款给公务员发工资。公安局的车加不起汽油，派出所，电话欠费被断线了。这些都是十几年前的真实情况。自从走上了楼市经济，一切都好了。

现在四川达县的教师工资达到了上海市区的八成，而当地房价只有上海的一成，爽不爽？
