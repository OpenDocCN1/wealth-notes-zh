# 当年分房子的套路

上海是1998-2000年停止福利分房的。当时各单位手里多多少少有些房子，有个处理过程，所以拖延了一段时间。我就有幸参与观摩了一次末班车的抽奖。

当时，我们单位里有一套内环线擦亮房子，是原来的大头头退出来的。大家把所有的注意力都集中到这套房子了。房子最后分给谁，是靠打分的。。

因为是最后一次，表面上，单位说，全部人员都有资格参与排队。当时，我和一个会计，都有可能。

那个会计是中学生。众所周知，大单位会计是掌握核心秘密的人，各部门要报销，如果会计不配合，你是很痛苦的。所以，虽然是中学生；但是路子广，面子足。我是本科，业务好，但没什么地位。

单位就故作样的公布了打分标准，工龄的分值，远远高于学历的分值。会计是中专，工龄长，顺利的拿到了房子（现在大概是九百万的价值）。我出局了。
