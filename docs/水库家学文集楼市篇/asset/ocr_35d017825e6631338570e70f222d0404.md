# 股东大会和董事会的区别

+   1. 股东大会一般一年一次，四月份为多。

+   2. 临时股东大会，程序复杂的令人窒息，一般开不起来。

老政策是：回购股票必须是股东大会通过。但是，股东各方利益不同，有的要压价收购，有的要抵押估价，有的就是基金投资人，吵吵闹闹，烦不胜烦。股东大会要想通过回购股票的决议，在股票暴跌的时候，不是那么简单的。闹场的人也可能很多。

+   3. 董事会就简单了，发个微信的功夫就可以开了。理论上讲，一夜八次都可以。反正只要 2/3 的董事会出席就行了（这话不严谨，意思差不多）

新政策是：董事会决议，就可以买卖自家股票，那是打开魔瓶了！

不作为投资意见，纯粹是胡思乱想的。

我有个预感，股市可能要和国际接轨，彻底对外大开放了。

若现在这样，外资进来就直接捡便宜货了，那些穿得裤子都当了股民实在是太亏了。

最佳的办法是，外资基金会场前，先拉起来，防止吃闷亏。

# 恭喜了，股民！（2018.10）

这次公司法修改是对股市的超级特大利好。

公司法以前对上市公司回购股票做了极其苛刻的规定，导致上市公司基本无法回购股票，或者程序很复杂很复杂。现在，股价跌成狗了，上市公司也是干着急，能动企业资金买进。

这次公司法修改，彻底解决了这个问题，虽然表面上还是有很多限制，但实际上，基本没限制了。因为有个体底的表述，为了维护公司价值和股东权益的需要，这个解释就是橡皮筋了。

这次修改，理论上是不符合经济学原理，我看了这点皆占古了，但是现在股市这个样子了，也没人反对了。

这个修改，在理论上有害大不足的。公司回购股份是违背股份制存在意义的，另外也很容易引发作弊。所以，今后会有相关的解释和修改出台。

在没有新限制规定出台前，我猜测很多企业会抢跑道，迅速购入本公司股票，稳定股价。（本分析是理论研究！不是投资建议）

恭喜了，股民！
