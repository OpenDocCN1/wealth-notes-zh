# 普通人很难接受婚后长期租房

事实上，法律环境也无法推行租房时代。

法院对无房户基本零手无策。

# 京沪房租是火箭式上涨

上海东方路的一室户，2002 年租金是 500 元，现在是 4000 元以上。
