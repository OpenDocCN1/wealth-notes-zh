# ### 什么叫金融创新？

反正你看不懂的，都是瞎头。不用看了，我直接说答案。

银行的业务就是借钱，自古有之，哪里有什么创新啊？说白了就是绕开窗口指导。现在婆婆妈妈的规定太多，理论上风险不大的贷款，窗口指导就是不让放。你说怎么办？好办，找个背锅侠，表外业务什么的，就都可以了。

表外业务的意思是，银行做个通道，供需对接，银行收个手续费。其实，这些钱应该是存银行的，但是银行直接把你导游到需求方手里，不在银行这里记账，也就不用上表了。这就叫表外业务，俗称为拉手，拉皮条。

# ### 回老家，怎么样？

来自小国的粉丝投稿。回老家，怎么样？

我是苏北县城走出来。小地方现在新大楼新道路，非常漂亮，但精神匮乏，物质可以网上买买买，但是斗志萎靡。回小地方两年之后，你就会被老家的那些风气带偏了，重视关系人脉和所谓的圈子，由于娱乐业的匮乏，有钱的开始擦妍头，没钱的嗑烟吃肉骂骂咧咧，死气沉沉。

# ### 大城市必然是今后经济发展重点方向

我们处于一个大迁徙，大变化，大发展的时代。

非常多的外地年轻人在大城市没有住房。原住民住房，要么不够住，要么过时了，不适应现在的需要。当大家有能力改善自己的住房条件时，大家的消费一下就放焦了。

中国有近 14 亿人口。注意力全部集中在一个消费品上时，生产速度永远赶不上需求的速度。
