# 高科技，金融业，那是燕燕鲍，不能当饭吃

美国经济学家们算是活明白了，高科技，金融业，那是燕燕鲍，不能当饭吃。

2009 年前后，欧美发达国家的经济学家们，集体吃错药了。他们认为，全球产业应该重新分工。 德美做码，欧荚做两头，亚非拉去傲慢走粗的话。当时，入市谈判的纠缠点就是，一般贸易普遍商品，由中国完成，但是中国要开放电信，金融，高端服务业。谈的结果是，原则同意，但要给中国十五年的过渡期。

于是，中国的出口疯狂增长，爆发性扩容，生意好的鸡飞狗跳，天天加货。与此同时，欧美普遍陷入停滞。大家都发现，一般制造业虽然没什么经济好处，但是解决了就业问题。高精尖的玩意，不需要人，少量的从业人员，还必须是人精。欧美那么多成绩很差的屌丝，根本没有就业机会了。吃低保是可以，但那么多兴业背壮年闲的无事，麻烦大了。

川普哥哥上台后，第一件事就是制造业回归，就业岗位回归。富士康，送快递，这些老板去美国开公司，川普也会见。这说明，制造业是社会稳定发展的基石。哪有那么多人去做高精尖？大部分都是普通人，还是吃穷用。

但是，我们这里瞧在普通鄙视中小型企业，听到最多的是：你交了几个税呀？你占了这么大一块地方，还不赚钱，你为什么不倒闭呀？从来没人关心这个企业解决了多少就业。
