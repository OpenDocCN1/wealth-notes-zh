# 楼市限购，要一城一策

没必要扩大化，绝对化。

京沪确实可以限购，我主张京沪社保满十五年才能购房，但是，其他地方，限购意义不大。人家要买买买，你拦着不让买，这算什么事情？又不是买违法的东西，这是给子孙买传家宝，有必要拦吗？

楼市调控，说是怕价格高了，群众吃亏。那有关部门多供应一点，不就平衡价格了吗？你一边卡着三甲医院少招医生，卡着中小学少招老师，一边是买房难，求医难，入学难，双输，市场经济，靠的是消费。

现在，群众最大的消费是四大件：买房买车，医疗教育，有关部门全部都是卡人的，有必要吗？扫除消费障碍，促进物资流通，增加群众消费热情，是市场经济长盛不衰的唯一办法。
