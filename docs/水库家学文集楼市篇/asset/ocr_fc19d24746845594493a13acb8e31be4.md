# 楼市的巨额涨幅

把每个小家庭都转型成了风险巨大的小公司，在波涛汹涌的大海里，随风飘摇。

不说京沪广深几百万的涨幅，就说说成都重庆西安，年涨百万，比比皆是，有多少小家庭能承受的起？接下来的天津可能又面临这种事情，想想都是夜不能寐。你有什么办法？去找活路吧，你爱咋咋地吧。我认命了。

# 千万级别的买房

确实很多人第一选择是买新房。原因：

+   1. 1、二手房的法律环境非常恶劣。买房完全没有法律保障。购房者付款 60%后，京沪房产被偏远省的县法院查封了，购房者急的当场昏厥。这种事情，时有发生，无法预防，处理起来，难的不得了，耗上几年也没办法的。
2. 高仿真一房是生意人买的，白领很少买，买了也不会卖掉。
3. 高仿真一房是生意人卖的，白领现在哪里置换得起三千万四千万的房子啊？
4. 生意人卖京沪高仿真的原因主要是接近破产了，偏瘫房产的抵押，查封，霸占，家庭矛盾多的一比吊糟。
5. 很多人现在不敢买生意人的高仿真二手。
6. 2、有一定的迷信因素。
7. 3，设施逐渐陈旧。市区老房子，交付十年后，小毛病很多，下水道堵塞，漏水，地板开裂，门窗损坏，难掉合不得，小修小补很操心。
8. 4，邻居素质真不是第一位的。很多高仿真，邻居之间基本无往来。小区里保姆快递员很多，素质参差不齐，餐巾纸顺头望科垫，直接跑到一楼司空见惯。我的隔壁邻居我都没见过几次。他就算是超级大牛，关我球事。
9. 5，新住宅小区的设计理念完全不同。以前有个地下车库就算牛了，但是地面无车不行的。现在的新建筑计材，门厅非常豪华，绿化极极高，小桥流水欧美范，人车分流，电梯入户，每楼楼的一楼大堂有专人值班。
