二，房价使劲会继续发病。股市衰退后，资金转移到楼市，京沪广深房价超级大涨，所有的人都受益巨大，赚在家里。房子就莫名其妙的增值了几百万。

调整阶段是2017-2018年。

京沪广深出台了超级严格的限购限贷措施，房价全面冻结。但是，由于2015年一線城市的楼市繁荣，直接刺激了三四五线楼市的巨大开工量。这些楼市基建资金，主要来源于银行贷款和民间借贷。这两块是高度敏感点，如果实行全面的紧缩政策，必将会造成较大的后遗症。

于是提出了分域施策的楼市调控政策。一线压住，二线放开，二线压住，三线放开，三线压住，四线放开，把楼市热钱逐层往下传递，逐渐线头下地方接盘，解决巨大库存会导致的金融风险。现在连惠州这样的18线城市，都已经是1万3到1万8的房价。我们有理由相信，在2018年年底，地級市和县城的楼市库存将达到合理的平衡点，为全面的经济调控做好准备。

接下来，2019-2020年，我们将会遇到的局面主要是：

+   1. 大城市房价稳中略降。住建部昨天重申了调控的决心，大城市楼市库存已经在合理范围内，5%左右的房价下滑是完全可以接受的。

+   2. 中小企业生产面临进一步的挑战。中美贸易谈判的结果是我们将较大的增加美国的产品进口，这里面势必包括一部分生活用品，而這些是原来内資中小企业的传统市场。

+   3. 金融工具的进一步泛滥。目前出现的纷繁复杂的金融工具，主要是为了炒钱，货币空转的需要而形成的，这些金融工具的繁荣，对实体经济并没有什么好的作用，相反导致了实体经济的融资难。

+   4. 进一步强化稳健的货币政策。货币政策已经从“稳健”改成了“稳健中性”，增加了两个字，说明m2要继续往后撤一点。

+   5. 地很紧张。这次调控提出了，防止地价上涨推动房价上涨的要求，推出了共有产权等住房改革新措施。纯商品房房地产根緊是势在必行。

+   6. 财政支出约钱范化。特别是ppp项目的融资，财政部已经做了非常细致的规范。

经济周期的调整，目的是为一轮经济周期的新增长，做好足够的物质准备和政策准备。所以，我们不应该消极等待，而应该积极看待。我们的理由相信本轮的下行调整期，应该控制在两年左右。
