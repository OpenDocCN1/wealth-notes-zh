子们只能在家里玩，出不去。一共要关几个月，实在是心疼。带孩子去少年宫，儿童玩具园，是全封闭的空调环境，交叉感染多，感冒咳嗽，司空见惯。而且，大人带孩子出去半天，也是很累的。

很多孩子在东北，一到冬天就很容易生病。到了海南，阳光好，暖和，孩子们玩的开心，基本不生病。所以，他们退之后，每年冬天都带孩子在海南生活几个月。但是，孩子马上要读小学了，就不能来了。因为小学寒假就要补课了。

大多数东北人买房，基本是一百多万的总价，一室一厅一卫一阳台。电梯房。质量不错，大多数是中国前几名的大开发商建起的房子，小区非常漂亮，不亚于京沪的顶级小区。就是吃饭麻烦一点。

我行细观察发现，中小学生在海南的，确实太少之又少，基本都在老家补课，海南到处都是奶娃子，没有度假的青年。

# 北海，海口附近的郊县，三亚

每个城市的气温，大概差 2°。三亚最热。

一般春节白天都是 20° 以上，鸟语花香，风和日丽，面朝大海，春暖花开。

空气情况，北海有点雾霾，看远处不太清晰。

北海是城市，配套较好，餐饮价格不便宜。

# 海南气候

我海南住过六个地方，三亚大东海，陵水碧桂园，琼海市中心某老小区，海口市内，临高县城，迁迈福山镇，相当于海南岛的右半圈各县，我都住过。

除了三亚，其他地方都是很潮湿；三亚略做好一点，但也好不到哪里去。遇到潮湿天气，衣服三天也晒不干。

如果开除除湿机，市内可以控制到 50%湿度，相当于上海正常情况。上海一般是 50-60%湿度。去年，海南大雾，非常潮湿，今年好多了，室外一般是 80%湿度。除湿机基本上六个小时就满了。睡觉前一定要把水倒干净，否则，半夜水满了，机器会叫。不要买靠海的房子，不要买高层，风大，湿度大。

# 中国冰雪产业前景不大

一是中国人的体质，不是特别耐寒，绝大多数人也不喜欢寒冷。特别是四五十岁的富人，很少有人喜欢去冰天雪地里吃苦的。

二是冰雪项目都在黑龙江日山区，本地没有什么消费力。瑞士周围都是富裕地区。外地人千里迢迢去学习滑雪，成本太高，可能性不大。

三是滑雪是技术活，有一定危险性，又没有什么经济回报，中国家长是不感兴趣的。
