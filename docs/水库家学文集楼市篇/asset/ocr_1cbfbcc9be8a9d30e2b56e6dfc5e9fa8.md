大圈，又回到起点了。

# 五，最大的内需就是热点城市住房

我们的住房，总体过剩，局部短缺。农村大片大片的空房屋，爷爷奶奶带着孙儿去县城读书了。中小城市的出地产，哪家不是几套房？问题是，现在年轻人大学毕业后，集中涌向大城市，导致大城市住房非常短缺，短缺造成了暴涨，暴涨造成了财富效应，恶性循环。

# 六，严格限购限不能拉动内需日常消费

不可能的。京沪广阔，五年限购。很多家庭手里有1-2百万，但不愿意消费，还是节衣缩食，很多家庭跟门的连下两天气都不打车。无房产，拼命攒钱，等待购房资格。有房的，拼命攒钱，买二套房或者置换大户型。现在出口不确定，大家都这么拼命省着钱，民企的商品卖给谁？

结论：要坚决防止内需和外需，一起熄火。

# 七，建议

+   1，降低普通房价，鼓励中小户型的住房消费。热点城市，按照实际人口，千方百计增加土地供应，千方百计鼓励住房消费，千方百计降低普通房价。

+   2，豪宅彻底放开。土老板愿意花一个亿买房装修，你就让他钱包，至少这个亿花在国内，农民工赚走了，多好吗，总比一个亿去买外国酒店好。

+   3，适当放开合格外资进入医疗行业，享受医疗用地待遇，为群众提供优质医疗服务。欧美日的大医院，引进几个又怎么样呢？医生还是中国医生啊！莆田医院都开了，还怕欧美日的大医院吗？

+   5，适当放开民资进入中小学教育领域，教师取得教师资格就行了，何必管他在哪个办公室里上课呢？那么多家长盯着老师，你还怕教师不好好上课？现在民企进不去，说白了就是拿不到教育用地。

# 京沪为什么好？

前段时间，给我家送快递的，是一位熊瘦瘦的农村大姐，四十几岁，还用丝巾扎了个防晒口罩，类似于海扁福建的农村妇女打扮，说话多省量，听起来费劲，应该是没学历的。

这样的妇女，如果在农村，根本没有赚钱的可能性，到县城打小工，估计两千块差不多了。但是，她在上海送快递就不一样了，月入6-8千是肯定的，如果是夫妻搭配，收入更高。上海送快递，一般是包住宿的，可以存下不少钱。
