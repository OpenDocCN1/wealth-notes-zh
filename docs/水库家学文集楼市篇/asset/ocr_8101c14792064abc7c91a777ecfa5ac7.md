# 一步错，步步错

我有个亲戚，在五年前往是挺有钱的。但是，一步错，步步错，现在几乎是中下阶层了。

五年前，他是做牵线搭桥的生意，合法赚了200多万，在省城可以买一套中等水平边郊别墅，当时就是1万块钱一平米。他那时候已经快60岁了，省城的房价也不怎么涨，所以他就不太关心买房，我们一直劝他，他也不听，他拿200万放出去吃利息，一年大概有二十多万的利息。他很开心。

吃利息吃多了之后，他觉得小额贷款这个生意还是可以做一下，然后他儿子就参与了一个小额贷款的股权投资，他投了100万。众所周知，现在小额贷款公司经营状况非常恶劣，这100万打水漂了，虽然大家还是认可这个债券或者股权，但是要不同来钱。

去年夏天，他还剩下一百多万。他开始想买房子，这两年房价涨得非常离，从1万块钱涨到了2万多块钱，他实在咽不下这口气，左看右看，就是没买。

今年春节，他跑到海南去买房，交了20万块钱定金，他以为这钱终于花出去了，结果昨天接到电话。海南限购，售楼处让他提供账号，把钱退给他。

现在他手里的一百多万，购买力已经大大下降，而且实在花不出去，非常痛苦。
