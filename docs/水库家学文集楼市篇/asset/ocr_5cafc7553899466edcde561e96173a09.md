# 另一半农村女人去哪了？

若再任由农村女人随意嫁到城市，农村光棍就越来越多了。

按照人口统计学，农村男女比例差 5%最多，婚姻情况不应该这么紧张。但你实际看到的情况是，农村未婚男女比例相差 50%以上。那么，另一半农村女人去哪里了？城里。

+   一、升学

众所周知，二本以下的高考成绩，比得是记忆力和自律性，女生的优势明显。所以，农村女生考上个破大学就走出农村了，再也不回来了。

+   二、打工

很多农村未婚妇女，在沿海发达地区打工时，遇到别人介绍相亲，就嫁到当地了。不再回老家相亲了。

+   三、混社会

农村妇女中，也有一些好吃懒做，富丽虚荣的，这些人根本不可能再回农村嫁个老实人了。

农村女性嫁入城市是比较容易的。因为女性不需要买房买车，只要是身体健康，五官端正就行了。而农村男性没钱，无力承担城市房贷，在城市里找老婆很难，一般只能回老家相亲。

这么多农村妇女，争取到了相当一大部分城市男性，从而导致了一个恶劣后果，城市妇女严重过剩，贫困地区男性光棍成群。城市妇女也不可能跑到山区贫困村，此路无解。

很多国家，女多男少，某些服务行业管理松，这个问题不突出。但是，我们出现这么多光棍，又没有合法的解决渠道，必然会出现一些难以描述的问题。
