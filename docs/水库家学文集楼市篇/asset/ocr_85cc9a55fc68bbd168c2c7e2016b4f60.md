5）政府财政支出要适当缩减了，在经济形势不是特别好的情况下，增加居民企业的蛋糕，那么政府蛋糕要暂时缩小一点了。这个省着略一万字。

6）对企业家要有睿智的态度。—张嘴里是几十万亿几百亿的大老板毕竟是个性，他们再苦，也就是少数高管跟着苦了。千千万万的小企业，才是国民经济稳定就业的根本。有关部门的基层人员，对小老板要宽容一点，遇到各种事情，只要是涉及健康和安全，尽可能是教育为主，罚款为辅，能前婚后，治病救人。一棍子打下去，罚的他们一年白干，也不一定是最佳方案。

# 所谓的四大发明

高铁，支付宝，共享单车，网购。

既然科技日报总编敢批判，我就继续说几句。这些东西，和发明没有一毛钱关系，都是外国原创技术，我们加以改进利用。中国地广人多，用的人多了，看起来很热闹。

+   1，高铁，我先说几句正确的废话，高铁是我们伟大的经济发展成就，是改革开放的重大成功，是中国几代工程师的智慧实践，但这和科学发明不是一回事。高铁核心部件基本上是外国原装，我们是根据中国地形气候特点，改造利用，不惜工本地建起来了。日本和德国，国土面积小，老一代高铁已经好了，没必要全部拆掉重建。

+   2，支付宝，这是民企开展金融的牌照审批问题。任何一家银联的技术也完全可以做到。

+   3，共享单车，那是占用公共道路，如果自建停车场，直接可以破产了。我准备做共享单车，行不行啊？

+   4，网购，笑点特了。亚马逊开创的技术，我们因为人口密集，人工便宜，助动车乱窜乱停，所以发展起来了。欧美人工资，俄罗斯地广人稀，成本太高，所以搞不起来。

这几个东西，只是商业应用的成功，是先进商业模式在中国伟大的经济发展中产生的绚丽花朵，不是什么科学发明，科学发明和技术运用，是两回事。如果外国芯片封锁了，这几个都要趴窝。

# 农二代怎么才能赚到大钱？站在风口

老王是标准的农二代，是做建材生意的，说他做生意还是高看他了，实际上是送建材的。我在2000年装修他买过建材，当时他是小老板，开了一个小门脸，自己已经两厢房到六月，非常辛苦，我对他有点印象。最近又碰到他了，他已经有变化了。当时，上海刚刚流行装修，很多家庭还是长期住毛坯房，装修需多大。他就开始卖马桶，有很多人不愿意卖马桶，给他脸十多个。

一开始他是卖唐山的马桶，赚了钱之后，他就代理了一个国际著名马桶，经过多年，彻底发财了。因为他是做建材的，所以跟房地产是连在了一起。拿到了一两套房抵材款的房子，自己又买房。他买那些房子都是一整做仓库的，所以一直没有卖掉。这下就发财了。
