# 身边两个姑娘的不同人生

近20年来，人世间所有的悲欢离合，阶层流动，咸鱼翻身，土豪没落，好牌打成烂牌，公主落入凡间。背后99%的因素是房子。（房价不炒，最好暴跌）

# 一、温州姑娘的逆袭

二十年前，她家非常穷，父亲是渔民，在她童年时候，随母亲卖光家财跑路了，母亲独自孩子，流落上海街头，以前靠倒卖火车票为生。所有的温州亲戚都看不起她家人。女儿历经坎坷，在外地货级大学毕业后回沪做外贸业务员，逐步熬到了年薪14万，因为没有娘家的资产，嫁了个年龄相仿的上海无房男，婚后有了儿子，一直群老自在公司附近。男方碌碌无为。

2011年，上海男继承了祖辈遗产，一套房的35%，折合60万现金，姑娘坚决要求买房，上海婆家担心女方不名堂，不同意买房，只想存银行。姑娘提出自己不记名字+还贷，上海婆家遂同意买了个郊区一百平米。姑娘负责还贷。

2015年暴涨前夕，卖掉郊房，贷款七成，买了个杨浦区小三居，这次婆家同意加名字了。买入后，上海房价翻倍，现在价值近千万，成为全家功臣。

与此同，温州亲戚因为福州暴跌爆雷，几乎全军覆没。她逆成为家族里最优秀的年轻一代，为父母赚了面子。老父亲在外面的欠债，也还掉了，老父亲也回归家庭。现在一家人幸福的生活在内涵线。

# 二、公主坠落凡间

女生非常漂亮，性格温和，父母是高级住家庭，她从小到大，都是医生上门服务，连医院挂号都不会的那种人。女生留学美国毕业后，找了个知根知底的帅哥，婚后他们去上海发展，于是两个人凭借漂亮的外形，漂亮的外来，漂亮的家庭背景，进了最好的外企，女方拿到上海户口了，但工资不高，月薪两万。婚后女方辞职去美国生了儿子，拿了绿卡。

2013年准备买房的时候，男方家里投资了一个准备上市的公司，暂时没大钱，两家凑钱只能全款买百万的漂亮小区，但买不起豪宅。他们看中的是当时九百万（现在两千万以上）的豪宅区。那年，楼市一片唱衰，他们也本息，就砸下来了。

老太人退休后，居然打官司离异，母亲离婚后，三百万私房钱给了女儿，老太人退休后找个开贸易公司的小姑姑娘结，没钱管女儿买房了，只是给了几十万零花钱。再后来，婆婆投资失败，洗了市。婚后，他们住在一套租赁豪宅，女方带娃，男方上班，每年开净挣额提20万。由于房价暴涨了一倍多，差了1200万，小夫妻实在是无法接受住老破旧，继续租赁宅，但前路暗淡了。现在，他们已经是京沪非常普通的小家庭了。

# 说个身边事

某大叔是中原大省的省城市区人，专门在贫困山区帮助农民搞养植技术，顺带推销农资，长年在县恶劣条件下工作。到了2014年初退休，他领了220万存款，感觉自己是人生大赢家，即将开置美丽幸福的退休生活。

大叔性格好强，吃苦耐劳，但是这种人往往思维固执，落后于时代变化。当时，我们劝他220万足够会近郊，买个豪宅或者别墅，传的女儿。他却所谓了报纸上的什么鬼样报道，不愿意买房。这两年，大叔连续遭了暴亏，无缘无故的，家里掏了。
