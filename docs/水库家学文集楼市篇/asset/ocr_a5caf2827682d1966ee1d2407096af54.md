# 美国减税终审落定，我是期盼加税的

毕生 2010：美国减税终审落定。我上月中经济学年度论坛上说过，美国若减税成行，中国应认真应对其降低税率。有人说美国税收与我们关系不大，其实不然。美国企业没有增值税，现又将所得税降到了 21%，而我们仅所得税率即为了 25%，加上负担更重的增值税，企业实际所得税负担超过 50%，故中国税收变乃势在必行。

案梁：我盼望加税，做不下去的企业都是烂企业，关门算了，剩下的钱，外环外的周墙买套房子，养老去吧！

# 还是咱们内地好，缴税光荣

美国办企业，只有 21%的企业所得税。内地办企业，企业所得税 25%，17%增值税，49%的职工社保，各种教育附加，罚款等，还有各种助款验资审计。

我觉得，还是咱们内地好，缴税光荣。在美国办企业，没劲，不刺激。你说呢？

# 认为私人可能会偷税漏税是误解

很多人，包括城墙内的人，普遍认为，私人可能会偷税漏税的。其实，这是个很大的误解。

+   1. 十人以下的小作坊，真的会偷税，例如什么小皮鞋厂，小餐馆。

+   2. 百人以上的厂，老板基本不愿意偷税漏税。道理很简单。
