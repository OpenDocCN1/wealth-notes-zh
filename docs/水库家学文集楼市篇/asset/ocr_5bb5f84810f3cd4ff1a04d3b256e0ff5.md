# 货币政策没有太大余地了（2018.07）

要坚定不移的扩大内需！

经济发展，说白了就是内需和外需。面对严峻的经济形势，我们首先要绝对避免内弱外需，同时熄火。

外需，风雨飘摇，非常不确定。贸易纠纷远远没结束，而欧日等央行之已经谈成了。与此同时，中兴公司这种精搞点火，也不一定是终点，会不会有其他公司继续中枪，完全是人家说了算。美国老兄谈好的事情都可以立马反悔，外需已经不能太指望了。有单子做，那是最好，没有也在预期内。外需不确定，只能靠自己了。

内需分为两大部分：公共支出，居民消费。

# 一， 居民消费

我日，普遍居民，除了医疗，教育，住房，其他事情统统不想花钱了，恨不得一条内裤穿五年，一件西装穿十年。你去看看幼儿园的大型庙会，小幼娟们一个个灰头土脸的，穿的都是搞两年的淘宝爆款。为什么？拼命攒钱，交够三处大山啊。

个别土豪二代，舍得花钱，但也是炫耀消费，都买进进口货，和内需没有一毛钱关系。一个包包三万，一个豪车百万，一套lamer八千，一套23区万，反正不买乡镇企业的，环球航海旅行，阿尔卑斯山滑雪，他就是不去张家界，你说气人吧？

大家都这么省钱，国内小厂真是苦逼了。
