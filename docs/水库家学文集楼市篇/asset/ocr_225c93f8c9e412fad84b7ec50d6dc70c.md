# 京沪楼市的长期区别

北京楼市是社会属性形成的。因为北京是审批中心，总部所在地，也是目前当之无愧的top1城市。但是，北京楼市可能有变数：

一是首都区域的确定。延庆门头沟那些山沟沟的村子，也是首都，这话怎么说呢？

二是央企总部搬迁。大部分央企，并没有非在北京办公的必要。他们在北京盖房子，无非是土地不要钱而已。两桶油是进口为主，可以搬到港口城市，靠前指挥。

三是部委审批的区域化。最高法院设立了巡回法庭，减少了大量的进京打官司。其实各部委也可以设立几个区域审批中心，例如环保部，在全国设立分中心，行使总部权力。

当然，这些问题不简单，但也不是不可能。

上海楼市是自然属性形成的。上海外挨的是日韩北美，内接江浙沪的长江水道，承上启下。只要外贸还在，上海的经济地位是牢靠的。

# 为什么北京大学生买得起房子

而外地农村大学生买不起？

北京的双职工收入，并不比外地来京的来源于高。这里面是制度设计问题。

北京的大学生，父母年龄是五十岁左右，家庭积蓄大多数在一百万以下。农村打工夫妻，工作30年，如果结余的钱，全部存起来，60~100万也是有的。

但是，十多年前，出现了一次经济分叉，导致天差地别了。农村父母回老家盖房子了，这就要命了。因为农村房子市场价为零，投下去的钱，全部打水漂，根本卖不掉，只能是等拆迁。
