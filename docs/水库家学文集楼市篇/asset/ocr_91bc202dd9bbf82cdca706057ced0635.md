# 鹤岗的房子刷屏了

几万元一套，还不够装修费的，基本和白送差不多了。说起来也是工业化市地区市了。为什么？赚不到钱，气候也不好，医疗教育也不行，去干嘛？

大家不爱吃盐，其实还有个地方更加严重，中西部农村。很多的房子，几乎没人住，村里最年轻的小伙子是 52 岁。为什么啊？年轻人出去打工了。时间长了，也不想回来了。

人口流动是有经济规律在起作用的。大城市，大码头，人多需求大，人越多，需求越大，形成了自我循环，越来越膨胀。小地方，收入低，大家扣扣搜搜，没人花钱，更加赚不到钱，年轻人就跑跑了。

人往高处走。只要是市场经济，人口必然集中。中心城市，前途远大。以我的经验看，四百公里是京津沪深辐射的极限了，上海到肥西堡。省会城市辐射范围大概是两百公里。开车五六个小时，是正常人的生理极限。超过这个距离，没什么人会经常回去了。如果把老人接出来了，那地方就永远拜拜了。一年不住的房子，回去要打扫好几天，还要维修各种设备，谁感恩啊？

# 小地方的年轻人要吸取教训

鹤岗市的小学生入学人数，从 2012 年的 7319 下降到 2017 年的 3995 人。这 3995 人，可能很多还是因为父母在外地工作，子女无法全部入学，被迫回来的。

这些父母年龄应该是 80 后婴儿潮一代，是本地区最佳劳动力，几乎一半或者一半以上走光了。剩下的中青年人群，可能主要是集中 在体制内或者依附于体制的。看到这里，我们也知道这个地区情况了。

我在全国各大城市，甚至是港口动物园，都看到了部分辽吉黑的新牌，很多的东北口普长期居住在华南西南，这也就解释的通了。

鹤岗是哈尔滨还得往北，几乎是最北的地级市了，冬天冷成啥样子，可以想象了。同时，它又属于资源枯竭城市，青壮年人口流失，年轻人经济规律，没什么好说的。

我要说的是，很多小地方的年轻人，要从这个鲜活的案例中取得经验，进一步指导自己的发展规划。
