# 楼市 325 限购

社保延长到五年，现在回顾，任何措施也是有利有弊的。

当时确实是有效果的，原来社保两年可以买房，一下子提高到五年，把有支付能力的外地人基本排除了市场。这就导致了接下来的三年，楼市的持续低迷。除了几个倒挂盘，其他都是冷冷清清的，时不时的还会冒出几个二手房降价新闻，成为外地刚需小脑们眉开眼笑的论据。

任何事可能都是十全十美的。实际情况是，这些外地人没富沪籍、住房需求还在、延长社保只是把这些外地人购买力积蓄起来，让他们再攒三年首付，就会平推房价了？这个问题是值得研究和重视的。

我建议，继续提高门槛，社保 8 年，甚至是 15 年。

# 财富的滋味

人生最幸福的事情，穷人买了第一套房子。这种幸福是刻骨铭心的，一辈子不会忘记的。但当你真的富了，其实幸福感很低。你有五个亿还是十个亿，已经不重要了。

你再有钱，也不可能带五个金液指出门。

你再有钱，也找不到什么好的保姆。外卖质量也很差。

你再有金，也不会经常换房子。我们这个年龄，住习惯的房子，不愿意搬来搬去了。我不是迷信，而是习惯，任何一个新房子，你都需要再次扭曲自己去适应新环境。

你再有金，也不可能要到年轻时候的女神了。现在的舔去女神只是好吃懒做，把你当饭票了。就你这么个老傻瓜，老娘看上的就该，还不如门口道的保安哥哥吧！

那么，财富还有意义吗？有的，你的下一代可以幸福一点了。

# 十年后
