# 1. 美元疯狂进入日本

1985年广场协定，说来没我转一个意思，日元要升值。正常人都知道，如果某项资产将定 会涨价，例如股票房产外汇，你会怎么办呢？我先驱，恭喜你，答对了。

广场协定签订后，全世界的美元都疯狂的进入了日本，把美元兑换成日元，什么都不用干，日 元升值，每年将有16%左右的贬值收益。先锋一些资本家运作成本，5%左右的利息是有约。 对于跨国公司来说，4%的利润率就比较行容易更好的多，但是资本家永远贪婪的，他们希 望得到更好的回报。这些人拿着几千万几万亿的美元，在日本市场上转来转去，希望找到更好的 投资项目。他们对项目的要求也很苛刻的。

首先，流动性要非常好，开发一个矿山，这10年20年是退不出来的。广场协定的有效期，虽 然没有十分的明确，但是国际金融学并不认为它是一个可以管20年的长期协定。可能会很快 产生新的经济变化，所以，资本家寻求一个能够快速退出的项目，事实上，广场协议也就看了 五年。

第二，这个市场足够大，大到能够吞纳几千亿美元。你要是做塑料地板，这个市场容纳不了 这么多的美元。

第三，这个市场是非常朝阳。当时日本的商店已经满街非常了，大家都看好的盘。

第四，这个市场的监管非常年轻。股票是电子化交易，监管是非常容易的。房地产是对人 的，一对一的交易，监管麻烦，从入手开始到最后全部需要调调清楚，再采取措拖，可能要3到4年 以上的时间。

于是，外国资本无光都打上了日本房地产。
