# 假设房价整体下跌 20%

银行就受不了了。

很多周丝没有金融概念。他们是这么理解问题的。首套房首付 30%，二套房首付 70%，哪怕跌 30-40%，银行都不会有风险。对钱？你就是 250。

实际上，银行不是这么算账的。银行的主要贷款，都是以房产作为抵押的。假设这套房子价值 两百万，打七折，贷款给你 140 万。如果这套房子降价 20%，只剩下 160 万了，银行只能贷款 112 万给你。这时候，银行就会要求贷款人立即归还 28 万，否则，银行就处于高风险状态了。

如果经济差到个这个度，贷款企业一般是还不出钱的，很多企业个人就拖着不还了。你走立法 律程序拍卖，我的损失也不大。爱咋咋地吧。

银行拿回这么多房子，卖给谁？张涨不买房，房产跌成这个样子了，市场上都在观望，银行肯 定很尴尬。司法拍卖房子的纠纷非常多，老赖也不是那么容易赶走的，实际上银行把 160 万的房子拿 回来，130 万也卖不掉。

这时候，银行傻眼了，资金被国住了，所有业务都下滑了，手里一堆房子，还要一个一个去赶 走老赖。单个的可行，大批量是不可行的。怎么办？银行就会把房价拉回去，以便处理掉这些库存。 搞了半天，就回到原点了。

金融系统根本不愿意看到房价大跌。除非我们能够找到另外一个东西，代替房产，成为银行可 靠的抵押物。事实上，美国也是拿房产作为抵押物的。

最好的制度安排是，房价平稳，确保信用体制的安全。随着 m2 上扬，房价缓慢向好，确保贷 款人还有利可图，不发生弃贷的愿意。
