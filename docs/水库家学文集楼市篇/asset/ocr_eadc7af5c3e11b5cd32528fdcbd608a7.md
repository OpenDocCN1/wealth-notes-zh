# 京沪市中心房价

一平米约等于一年半均收入。京沪大概是几万多。

2000年左右，大单位年轻人是两千多工资，一年 2.5万，内环线边缘房价大概是 4000元，郊县是 1200-2000元，正式编制的公务员，六七年，在内环线搞一套全款小三是没问题的。如果要川沙周康，那就像是不花钱了。

京沪房价是怎么起来的？说白了，都是外地人炒起来的。上海本地人的住房需求，每年是基本固定的。2000年左右，总价十万进口户，零首付，不落户。也没人要。

2003年以后，取消了暂住证，各大单位招聘不紧户口了；买房也不要户口了，这下子，全国各地中级职称，应届大学生，中学生，外地小生意人，境外人士，拖家带口就来了。找到工作就买房了。住房需求井喷。

那时候，住房就像是塑料桶，随行就市，还可以砍价。越买越热，越热越买，所有人都发了，吸引了更多的人来。

2006年，外地儿童可以随便借读，来的人更多了。住房需求再次井喷。

所以，外地人买不起房子，更多的原因是需求的井喷。本地家庭大多数是置换，个人面积没有增加多少。

# 山清水秀，房价七千

为什么不回去？

成年人不会问这个问题，一般都是居丝二条狗。我在这种地方住过的，夏天度假两个月。山清水秀和穷，实际上是一个意思。这种小地方找不到钱。啥也没有。一条商业街，一大半是卖廉价地摊货的。还有几个苍蝇馆子小超市。

+   一，商业，赚不到钱。县城里的年轻人都跑了，就剩下体制内的消费者。数量不多的。网购基本抽光了所有的小商店。除了烟酒饮料五金件。

+   二，餐饮。本地人的总消费有限。没有什么新鲜外来消费力，工资增加也不多。只不过是你抢了我的客户而已，整体没有什么增长，商户严重摊薄。

+   三，小厂。也没什么优势，客户觉得麻烦，交通不方便，你也不是什么大工厂，我就不来了。而企业在招工，管理等方面，面临村民，环保，有关部门的种种，无法言说。

+   四，旅游。旅游都是季节性的。开价高了，生意差！开价低了，其他半年得收入，也好不到哪里去！我举个例子，我有个朋友，上个星期去西部某市旅游，他和我说。风景区漂亮，但没什么游客，日涌大街都是上海游客。原因很简单，富裕游客的来源，主要是沿海地区，去西北的成本和去日本差不多。宁夏要想超过日本，还是有点挑战性的。

+   五，医疗教育就不比了。

+   六，发展机会，也就是正科，其他不要想多了。

# 要掏空老底在北京买房吗？

财老师，举手问题。小本，外地女，在单位拿了京户，这几年靠自己加上家里支援初步可以买一个五六环近地铁的小两居，首付一百万差不多。但是家里是农村的，爸妈觉得房子也不会涨价，就为了在北京暂时站住脚把老底掏空。不划算。我就也很犹豫，因为毕竟他们也出钱，咋吩咐啊。

答：不顶，嫁个有北京房子的，加名字。
