# 彩礼的经济学本质

彩礼是把男方拥有的钱财，转移给儿媳。这笔钱是男方的老婆本。男人失去了这笔钱，基本没有财力再婚了，对女方婚姻有个保络。农村地区，离异女是不可能分到房子的。城市男性的房产如果是婚前 的，女方离婚也得不到房子。

彩礼制度是中国古代文明，有保护女性的一面，也有破坏婚姻的一面。它极大抬高了娶妻门槛。男方要准备婚房，酒席，三金，服饰，一大笔彩礼，一桩家庭如果两个儿子，真是负担不起，怎么办？聘老婆。

通过负债的形式，把老婆先骗过来，然后逼迫女方把彩礼拿出去还债。如果女方不同意还债，那就一起吃咸菜。婚后，女方逃跑或执迷离婚，一般是索退钱的。男方婚后立即要求生孩子，绑定风险。有了孩子，你一般就逃不掉了
