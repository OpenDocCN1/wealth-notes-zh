# 中国经济面临关键性选择：

一是参考日元经验，二是暂时缓缓，等待创新成果。

以往三十年，中国经济的主要模式是：增发货币搞大基建，催热地段，卖地收入，房地产火爆，带动三百个行业，加速城镇化进程。举例，在大城市的外围，例如以前上海人来不去的周浦江桥，北京的顺义昌平，砸下重金建地铁，建高速，这点附近的地铁就热翻了，卖地盖楼，楼市火了，大量的人口聚集，拉动消费。连卖空调的都飞上了。

现在的情况是，最后一环，楼市被卡住了。楼市，是为前面所有环节买单的惊险一跃。现在不动了，那么前面的账单谁来买？你问我，我也不知道啊。理论上讲，可以通过税收。现在，民民的税负已经很高了，从上到下都在讲减税减负，指望民生税收是不现实的。指望国企呢？你看看办吧！

科技创新是最好的办法，只有找到十个八个类似于苹果特斯拉的那种级别的创新，带动几亿就业，通过全球领先的科技创新，形成新的新经济，支持大基建模式和有关环节门开支，包括教师工资。什么大基建停不下来？一方面，我们国家确实有需要，例如接下来的环保建设，农田水利建设，江河湖海治理等等，都是万亿级的大手笔。另一方面，大基建是吸纳农民就业高工资的最佳办法。电子厂，裤子厂，话说是的一群穷逼，给不起收购，农民工怎么办呢？还是上工地，捡灰插哈！

科技创新，有一定偶然性。我们坚信有关部门一定能够搞出世界一流，全球第一的大项目。但是，我们也要给他们一点缓冲时间，三五年吧。那么，这三五年过渡期怎么办？我算是还没票子吧。这个阵痛最小。要不然，这么多农民没钱花了，那事多了。省略一百字。

# 让农民富起来

这句话蕴含了两个重要问题，一是农民怎么富？二是怎么致富？

改革开放四十年了，国家政策好，目前还是最穷的农民，可能是更多的是自己原因了，即使是偏辟山区，只要身体可以，去大城市进煤矿去或快递公司干几年，肯定是不穷的。目前还是贫困的，大多数是身体有痂，或者个人素质不堪。不要说什么岁数大了，你年轻时候在干什么？

+   一，怎么富？

大多数农民没有什么高精尖技能，主要是操作工，例如倒瓦泥，水泥工，钢筋工，电工，木工，杂工。绝大部分农民是不具备经营管理能力的。要让农民普遍富起来，必须找一个肯定赚钱的行业给他们干，过去是大基建。这个行业真是包赚不赔。今后呢？

+   二，怎么致富？

现在，给大多数农民家里有小洋楼了，很多人城里有房，从县城到资产，儿子努力一下也可以读大学了，给大多数农民月净到手是 7.4 万元/月，医疗保险养老金，打开全世界，这也是高收入了。但是，他们满意吗？为什么？因为他们只是和过去比，而是直接对标京沪平均收入。而京沪已经是世界 top10 城市了，如果广大的农二代，都以京沪中产为标准，这事复杂了。

+   三，农民必须是包赚不赔的
