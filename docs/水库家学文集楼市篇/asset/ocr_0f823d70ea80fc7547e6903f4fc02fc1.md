# 互联网繁荣和房地产

中国的工厂基本集中在沿海，南京以西以北的内地区县基本都是农业县，做什么像样的工业，既来县城解决就业的第几个啤酒厂，肥皂厂，拖拉机维修厂也没了。二本子铁在北土厂就是这个原因。没有工业，就没有财政收入，也没有什么就业。

后来，县城发展第三产业，膨胀一条街。KTV 一条街，现在被电商和扣 x 取代了，县城大商场，大商场，营业员比顾客多，基本上都是空荡荡，亏本的小老板在干瞪眼。餐饮业是现金交易，不开发票的。

那么县城财政怎么办？1998 年后，各地的楼市蓬勃发展啊，楼市的巨额税费远远 > 商业一条街，所以整体也没什么影响。

如果房地产税费没了，商业一条街废了，工业又不行，我实在是不知道县城怎么过日子？
