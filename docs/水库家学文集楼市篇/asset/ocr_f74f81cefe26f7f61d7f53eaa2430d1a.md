# 大土豆已经不食人间烟火了

北京大土豆：我觉得网上很多对在北京年收入 100w 好像有一些误解，这个收入，不客气地说，在北京就是一个刚刚脱贫的水平，再跟我念一遍，刚刚脱贫。我看很多人把收入 100w 看的很高大上，动不动就国际学校，豪华洋房，醒醒好啊。

这点钱，扣完税拿到手是 76w（含公积金），扣除房贷，养车费用，孩子的教育费用，吃喝拉撒，一年 1-2 次的平民全家旅游，所剩无几，要么不吭声，换房都换不起。要是生俩娃，基本就是月光的节奏。

年收入 100w 的这类人群，是很焦虑的，稍有不满，100w 的工作要是飞了，这一家老小，高额的日常支出咋办？孩子的学区房咋办？以后自己老了，是不是该存一笔养老钱？老人要生病，不能天天请假陪护，医疗费可能是个无底洞，怎么可能安心？自己的健康是不是也得关注一下？

这群人，看着光鲜，其实每一天都如履薄冰，这就是一线城市 100w 年收入家庭的真实写照，顶多网上跟人吹吹牛逼，但实际也就是刚脱贫的水平。

菜菜：对，北京人都瞧两百万！

大土豆已经不食人间烟火了。年收入百万才脱贫。这他妈的是逼宁了。我这种不赚钱的货，是不是该销号走人了？

# 我们的工厂是没工人的，全部自动化

现在，各地制造业老板最牛的一句话是：我们的工厂是没工人的，全部自动化。现在，越来越多的大厂往这个方向走。

劳动法把农民工培养成了“动不动就想打官司”的法律人，小老板被迫变成了佛系禅师心理医生，花钱买太平的冤大头。很多标准件行业，小厂会被大型无工厂兼并，形成一个个的行业寡头。

现在，就业足，工资高，根本原因是铁公鸡吸了无穷无尽的劳动力。而铁公鸡是不讲究成本的。建设这条骆驼花了多少钱，没人会质疑，只要有贷款，给农民工开出高工资是不心疼的。长此以往，把制造业的工资也拉高了。但是制造业是全球定价，一分一厘都要讲究的，你说怎么办？

# 三十年中美关系简史
