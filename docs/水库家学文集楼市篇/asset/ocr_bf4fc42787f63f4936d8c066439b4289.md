# 利率和降准的关系

现在已经看的很清楚她了：利息不动，直接灌水。
美元加息，勾引热钱回去。本币左右为难。
1，加息，楼市崩溃，企业困难。
2，降息，热钱更发狂了，会加速走人。现在物价实际是上，上海的番茄菠菜都是8元/斤，统计局心里是知道的，只是不愿意面对而已。再降息，没有空间了。
3，想来想去，还是放水为好。工地的小彩旗飘起来，小灰猫捡起来，一了百了，皆大欢喜。

# 当前宏观调控工具

为什么由货币政策转为财政政策了？
1，宏观调控主要是，就业。外汇，经济结构等等，也重要。但我们只说重点。
2，货币政策是：央行发钞票，贷款给企业。你们抓紧去买原材料干活。
3，财政政策是：财政部门安排项目，修桥修路，治理河道。钱由项目公司找银行借。怎么还？还没想好。
货币政策是发贷款，前提是，有人来借钱。这可难办了。现在，产能过剩，不倒闭就算好企业，你给我钱，我也不会去生产了，那么谁来借钱呢？嗯，楼市。这个体量够大。
有了购房者这个最大的市场，百业兴旺。空调厂长都扬眉吐气，觉得自己是世界领导者品牌了。其他建材类，施工类，设计类，家具类，开足马力，上啊！
财政政策也有不足，买房的人太多了，超过建房速度，房价发飙了，其他部门不高兴了。
那就改一改，让买房的先缓缓。但是，楼市缓了，就业税收怎么办？不急，修桥修路。
公共设施，老百姓不可能出钱的，那就财政政策出钱。
好了，你也是宏观调控学副高了。

# 央行不要去救赌徒！

民企不缺贷款，不缺资金。我也不知道为什么，有部门好像一直认为民企缺资金，千方百计忽悠放水印钞票。
我想向央行说一句，聚焦主业的生产民企，根本不缺资金。除了引进个大设备，其他时间完全不需要贷款。
那些急吼吼要大资金的大民企在干什么，你们央行不知道吗？他们在搞资本运作，拆股权并股，搞房地产，搞商业地产，捞快钱。他们不是在生产，是在赌行情。你去救赌徒干什么？
我建议，银行的行长，认真分析一下各种缺钱的大民企。
1，聚焦主业，引进大设备的，纺织工厂粮食之类，必须救。这是中国制造业的火种。你救它，群众没意见，职工很高兴。
