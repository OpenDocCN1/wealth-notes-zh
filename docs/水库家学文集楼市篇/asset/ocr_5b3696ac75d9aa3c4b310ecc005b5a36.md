# 京沪很富裕

来京沪做保姆的人，绝对不愿意回老家，因为老家找不到钱。为什么京沪这么富裕？因为京沪集中了天底下最好的单位。一个三甲有多少人才了？还有各种总异员工。都是现金牛。

富裕人口多的城市，民间消费力极强，各种生意好做。举例，绝大部分行业，杭州的工资是上海的七成。有一次，我熟人发生企业合同纠纷，去杭州找了个律师，来上海打官司，便宜了八千块律师费，挺高兴的。杭州特点工 25~30 元一小时，上海是 40-45 元。

上海工资高的原因是房租高。没有大几千工资，员工留不住，不利于企业发展，工资暗含了房租成分，好处是生意多，在京沪，只要不怕苦也不靠，赚钱是可以的。我前段时间住院，一个护士，一年十几万收入，明的是京沪，他还还提供各种服务，例如为病人擦身，洗脸，夜间照看，扶你下地上厕所，出租各种你用得到的东西，例如轮椅，还有办法插队，或替你去排队，还有几个打官司黄牛专门拉车搞生意，这些都是有偿服务，一年下来好几万。护工最大的支出是房租，儿子上学要住。

护工最大的感慨是，如果我上海有个老破小，就好了。
