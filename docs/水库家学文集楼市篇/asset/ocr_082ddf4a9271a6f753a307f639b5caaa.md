3. 东西两侧，介于当中。传统上讲，东面比西面好。西面的中间位置有个核电厂，直接面对高科技。

4. 买市区，还是靠郊野外？市区贵，小区也不漂亮，但配套好，吃穿用，什么都方便。略微干燥一点，但还是很湿。远郊区，落差大些，赏心悦目，看海，拍照片一流，但是潮湿，完全无配套，一个小超市就是生活的全部。要想吃肉，必须驾车开到十五公里外的市区，或者在小巴上折腾小半天。

5. 买高层还是低层？高层，很潮湿，雾气往上走，但比较安静，蚊子少，风景好。低层相反。

6. 买朝南的，还是朝北的？春节短期住的，一定要买朝南的，有大阳。但是，长期住的，不一定，因为朝南更热，你不一定受得了。在海南，除了春节前后十五天，其他时间，以凉快为最佳方案。

# 厦门怎么样？

答：厦门，我住在思明区。冬天不冷，就是潮湿，风大。生活服配服务配套成熟。冬天阳光好像也不多。需要穿薄薄的羽绒服，至少毛衣外套要的。

# 北海咋样？

答：去年冬天，我在北海住了半个月别墅，看海。去年，北海天气特别好，阳光明媚，北海天气给我留下了很好的印象。今年什么天气，我不知到了。说说你需要知道的事情。

+   1. 没车，日子难过。北海虽然小，但是，商品房小区一般都靠海，菜场配套不行的，小超市比较多。你要是去买菜，一般三公里。

+   2. 北海的海鲜餐馆，一般装修，个体经营的那种，价格奇高，超过上海。

+   3. 北海的经济落后，楼盘漂亮，价格大概是 6-8 千元（去年）。

+   4. 北海老城区，市容市貌偏下，垃圾遍地。

+   5. 春节打年车，都要加钱。

+   6. 北海房价，八年不涨。本地年轻人都跑广州找工作了。

+   7. 东北人很多。机场门口出租车，一半是东北驾驶员
