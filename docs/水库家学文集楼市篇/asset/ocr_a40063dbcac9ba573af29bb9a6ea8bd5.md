# 为什么丈母娘要房子？

这是一种筛选，男方家长是不是烂货？基本可以筛选出来。古人云，勤俭持家。你家生儿子，二十多年还不准备婚房，说明父母没有自律性，属于“吃光用光，身体健康”的垃圾族。

丈母娘必须要房子。因为准备婚房的家庭，门风好，愿意为子女考虑。不论你自己高低贵贱，至少你家父母全心全意努力了。

不给子女留后路的父母，是极其自私的。谁家女儿嫁过去，很难过的舒心。因为他们夫妻那丝一辈子，没什么追求，也没什么愿景，就是吃光用光，骗个女人生孩子。

在攒婚房的过程中，非常考验公婆的智慧。如何妻顾平衡？如何精打细算过日子？如何自律克己？

给子女准备婚房的家庭，一般没有坏毛病。因为吃喝玩乐抽是非常浪费钱的，有任何一个毛病，子女都不可能有婚房。

很多家庭是靠父母在单位发房子，才多了一妻。单位发房子是很难唯的，这说明父母很努力，有事业心。这种家庭的孩子，大概单品行比较好。
