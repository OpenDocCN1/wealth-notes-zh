# 货币是很聪明的

现在的经济局面，错综复杂，两难向地，相互纠葛。

央行为了刺激经济，稳定就业率，发出了大量的m2。2002年至今，增加了十倍的多的货币供应量。这些货币通过层层转手，大部分还是到了居民手里。居民也知道，货币对应房价，是在急剧贬值，拿到货币统够了首付，立马就把货币抛出去，换成了实物房产。

这时候央行统常篇尴尬了。央行的本事是通过货币刺激各行各业。但是实际上被刺激的只有房地产，皮鞋打火机眼镜，卖小吃的，开餐馆的，都没有被刺激起来，这时候央行陷入为难状态。

如果紧缩货币，房地产确实管住了，但各行各业，雪上加霜。整体企业萎缩，财政收入，gdp增长，都会遇到巨大的挑战。

如果扩张货币，房地产会继续疯狂涨。大票赚钱了，各行各业也会被带动起来，经济数据确实红火，但是人民币的市值稳定就越来越危险了。市值涉及到汇率，如果汇率出现波动，那么进口的大宗粮食石油价格就会变化，干扰国民经济的基础价格形成。

于是，货币当局就提出了中性货币政策，不扩张不收缩，先稳定下来，以后慢慢说。但是货币是很聪明的，他们会采取集中优势力量，分割包围的方式，继续囤积房地产吃红利。于是央行就提出了各种补丁的办法，限制货币流入房地产市场。
