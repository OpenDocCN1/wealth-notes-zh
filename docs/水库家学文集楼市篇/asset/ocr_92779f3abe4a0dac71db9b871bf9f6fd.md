# 你了解各个经济现象吗？

刚才和朋友乱侃发现，我们习以为常的很多经济类概念和认识，在经济学小白那里，都是很模糊的。特别是一些理工类大学生，工作了十年后，终于有钱了，要考虑家庭资产配置了，才意识到自己对各种经济现象，经济大趋势的认识，完全是空白。

# 如何赚正常的钱?

努力成为有知识的人，然后卖时间。考cpa，律师，医生，有点麻烦，干的人也多了，不一定要往人多的地方挤。知识，不仅仅是大学里的那几个专业。只要是合法的，群众有需求的，都可以是知识，都有价值。

你要是把京沪广深三甲医院专家的专项和论文方向搞清楚了，就是知识。以后谁问你个找医生问题，收费三百，保证没问题。

你把一线城市各知名中小学入学手续和排队办法搞清楚，也是本事，保证有需求。

你把各城市历年来的房价数据和当年本地实行的各种政策和举措，分门别类整理好，提供给有置业需求的人，也是好项目。

你至少读过高中吧。你专门研究中高考选题，你研究透了，写几篇文章，或者微博，也是本事。保证有人请你去演讲，一场八百元。

这个社会不缺乏机会，缺乏的耐心和毅力。我坐了七八年的冷板凳，一直在努力奔跑，我也有所抱怨。有些屌丝，毕业没两年，就一天到晚抱怨，这个不高兴，那个不开心。你应该想想，我是不是改变一下自己的赚钱方式。除了小公司的格子间，还有没有其他渠道？

大城市里，遍地是黄金，这个夸张了。但是，你要做个中等略偏上的劳动报酬，办法和机会都很多。关键是，你要静心学习，坚持不懈。
