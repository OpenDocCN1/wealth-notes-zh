转行也很难遭。打杂就废掉了，专业技术也不知道干什么好。

+   2. 老公也过来了，也面临相同的收入问题。她们是四川人，生活习惯。但是配偶不是四川人，离乡背井，事业不顺，环境陌生，已经开始埋怨了。

+   3. 心里压力巨大。没房子的时候，觉得房子重要。回来后，发现事业没了，又总压力山大。

# 上海记忆

每一个老上海家庭都经历过人生的选择。

1959年左右，上海开始户籍登记。我们家也经历了。当时有个政策，如果你自愿离开上海回老家（主要是江浙皖农村），可以在老家参加分田分地。我们家族中的很多亲戚，贪图短暂安逸，就在第一瞬间，离开了上海，从此天涯陌路。之后几十年各种不忍回忆的历史，你也知道了。

我家没走，原因是，我家在沪有几间大瓦房，如果走了，这点东西就没了。于是，就咬牙留守。三年后遇到公私合营，只保留了一间大瓦房，其他都没了，待遇是每月给十几元养活几个孩子（具体细节我不清楚）。

我家第二代在上海过的不好，但比回到江浙农村的亲戚第二代强多了，至少没有挨饿。我在八十年代家初期，只见故乡乡下亲戚，看样子真的和闰土差不多，穷的只剩下一件破衣服了。

进入九十年代，上海开始拆迁。我家是市中心，第一批就遇到拆迁了。第二代只要有户口，都分到了内环块边绿的小二层（九十年代的内环块边绿还是农村地段）。九十年代已经不许家庭成分，个人出身了。

在沪的第三代普遍考上了名牌大学，于是，小日子就起来了。而八十年代来的江苏，出了名的高等地就熟模式；他们高智商，还要搞一次预选，才能取得报名资格。回到老家乡下的第三代，基本没有考上本科的。大专有几个。那时候不允许户口流动。考上大专的县城镇正式编制了，考不上大专的要去上海打工。

到了2000年，上海搞进口户，外地人可以买房了。来上海打工的亲戚，有两家买了。当时的十万日元，可以在农村搭个小洋楼，在上海至少买外环块的小二层，或者内环块的一室户。这个分水岭，再次拉开人生距离。

第四代目前还在念书。但是，上海户口很难搞。

# 为什么大城市相对公平？

小地方人情关系特别严重。这是有历史原因的。大单位自己盖房子，居住集中。以前都是单位盖宿舍小区，一个局的同事，大部分挤在一起，几代人，从小到大一起长大，互相都认识。不是一个局的火头，通过婚姻关系，旁系关系，也牵扯起来了。经过几代人之后，形成了非常稳定的人脉关系。现在，不盖房子了，但县城就那么几条街，一到晚上，吃个烤串，喝个啤酒，互相介绍一下，也都认识了。

大城市不一样。解放前，市区就盖满了房子。干部职工发房子，都是见缝插针，完全是分开居住。长此以往，形成了惯例，同事之间不会生活在一起。大城市交通堵塞，聚会很不方便。一般情况下，同事之间在单位以外是不见面；日常交往也很少见。因为交不到，形成姻亲关系，做乎其微。大城市的单位，外来干部职工的特别多，例如调动转业等，无形中也没散了抱团取暖的情况。大城市里，路路通的本地家族，很少很少。十年前，一些郊区曾经有这种势头，后来通过大规模的跨区调动，外地大学生入职，独生子女政策，现在基本没有了。人情网消失了，大家互相就都没有信任度，谁也没事喜替你冒险？
