# 宏观经济学的大格局

很多人不懂宏观经济学是什么？99%的人以为，买一本萨缪尔森经济学上册，读了两本夹纸小册子，就觉得自己看过了。按照我的理解，宏观经济学分为大部分：一是思路，二是工具。

+   1. 思路

奥派，凯恩斯等，都是思路。这些思路往往是互相对着干。你说东，我说西，反正我就是杠精。思路没有对错，谁都可以说几句，所以，人人都是经济学家，人人都是足球教练。

+   2. 工具

这个就严选了。工具主要是两类，财政和货币。

财政主要是研究，税收，赤字和投资方向。

货币主要是m2，各种调整总量和速度的工具。

+   3. 微积分模型

用数学手段，预测和描述工具的变量，效果和影响力。不太准确，类似于跳大神。

# 微积分在经济学中的作用

好像是用拉丁文写药名。

在经济学领域，微积分本身毫无意义。我这么多年，从来没有见过一个模型是精确的，模型实际的目的，是让你看不懂。那我就是专家了，掌握了话语权。

这个现象在各行业中都存在。最明显的是，医生写字是鬼画符。这个事情的起因是，解放前，西医都是老外教的，没有统一的中文翻译，为了避免歧义，索性就写拉丁文，德国，英国，美国的医生药师，都可以看懂。这个陋习一直流传到十年前。现在基本没了。

学习经济学，一般是两个目的。当做投资人，实际投资。

如果要当教授，必须学好微积分，因为微积分的存在，会让你看上去高深莫测，别人怕你。

如果是实际投资，那就别学了，微积分是骗人的。

# 九十年代，发财难不难？

现在做生意的难点是，供大于求，货卖不出去。当年做生意的难点是，不知道怎么做事情。

1. 九十年代，老王想开个长途客运汽车，例如上海到北京。正常卖票载客，车的行李箱可以少拉货，膏求极大，理想很丰满，现实很骨感。

他遇到的是，当头一棍子，不知道上哪申请。折腾了好几年，没办成，拉倒了。他家镇上的某一户人家办成了，具体情况，我也不知始，反正开始盖了，手续齐全，拉到了第一桶金，接下来就吃鸡了。开汽修厂，成为某品牌的定点维修站，大发一笔。后来又陆续投资，现在，也是一方土豪了。而我的亲戚王某，事没办成，又没技能，最后混成了低保户。现在回想起来，那个老板应该是走了挂靠程序。问题是，当年谁想得到这个啊！想到了，也没门路办成啊！

2. 老张当年想在要阳路倒卖bp机，研究了好长一段时间，也没搞清楚货源在哪里，黄了。

3. 老李想在市区开个饭店，但是选址很困难，因为上海市区人口稠密，想找个体门好，面积大的地方非常困难，黄了。

4. 老赵是大企业的工程师，想去农村办厂，但是，很多农村都是集体小厂，土地资产管理流程麻烦，邻里关系复杂，农村人也不讲道理，动不动就把闹起来闹赔偿，最后什么事情都办不成。
