# # 农二代为什么买不起省会的房子？

你的父母把钱拿去盖了农民房，现在农民房的市场价值为零，所以，你啥也没有了。

2000-2011 年，京沪大城市不限购，想买就可以买。这个时期也是中国农村建房的高潮。在农村建一个普通小楼，相当于在北京五环买个小户型 50 平米（或许徽盖贷款），

这一步是所有中国家庭的经分水岭。如果你往京沪走一步，就是人生巅峰。往老家退一步，就是跌入谷底，害苦了三代人。但当时，谁也不知道这个后果如此之严重。绝大多数农民选择了回老家盖楼，人生毁了。

近十年，进行教育向县城集中，孩子在县里读高中，老人要去县里看病，青壮年要到沿海打工，乡村农民房连居住价值都没了，整村整组，房屋空置的情况，屡见不鲜。三五年不去，院子里的杂草，比人还高，完全荒废了。这就是你父母一生的积蓄，打水漂了。

造成这个结果的原因是很复杂的。一是城市资本不能下乡投资。没人接盘。二是拆迁也拆不到，国家也不收购。

这个问题，目前看是无解的。今后，除了特大城市的附近郊区，地级市县级别的拆迁都不会得大规模发生了。因为小地方的房地产基本饱和了，没有拆迁的意义了。
