# 讲一个比吊糟的金融历史故事

上海隐媒某地的民菅理财平台，一直是高息收钱，1 分-3.5 分不止。本来还可以勉强应付得去，因为利息高。拆东墙补西墙，十个锅，五个盖，早块就行。大不了，年底底息低估一个盖来玩。

不料，理财平台意外的被一个楼市大扫荡打击了。某市一口气推出了 n 个低价盘，引发众人排队摇号。开发商把燕离卖了大罗卜价，实在是憋了一肚子火，索性搞了一个硬条款，要求中签者 1-3 天内首付八成。这一下子，起了化学反应。

理财圆里，有经验的老鸟都知道，理财平台取现金，往往不一定很快，几天都有可能。而开发商要求 1-3 天，那么参加摇号的成千上万人，不管是不是摇到号，必须各自先提现几百万预备。摇中了就行钱。例如中签率是 5%，但参加摇号的人必须是 100%预备资金，否则就可能逾期付款导致选的了。好不容易摇到的签，谁也不敢大意。

而这些购房资金往往是暂时存在高利息的理财平台上。于是，一场莫名其妙的大挤兑来了。瞬间，搞垮了某钞票平台。其他人也慌了，立即去掉京沪外地没有海岸的理财平台。一下子，海域鸡毛了。

回头着，如果开发商把付款时间放宽到一个星期，那么也只有摇中的 5%的人才会去理财平台提现，这场莫名其妙的大挤兑根本不会发生。
