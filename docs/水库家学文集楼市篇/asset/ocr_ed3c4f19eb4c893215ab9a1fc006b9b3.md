贫困县的新区和京沪漂亮小区没什么区别，都是全国大牌开发商建设的，富丽堂皇，漂漂亮亮。

# 海南经济，还是非常有前途的

虽然现在不怎么样。

+   一，海南民风较好

大家可能以为海南是个没文化的地方，其实恰恰相反，海南是文化之乡。海瑞就是海南出的进士，宋庆龄祖籍海南，你想不到吧？历史上，海南作为一个州县，出过96个进士，767个举人，这是非常高的比例，可能比北方一些省还要有文化。

我在海南好几个小县城的街头闲逛了几圈，没有看到内地常见的湘潭，就是蹲在街头，叼个烟，斜眼看人，一脸戾气的那种。大多数人，看上去还是很客气。南方人得有的那种热情。

+   二，本地人诚信度还不错

我去吃了几次路边海鲜店，本地人开的，明码标价，不搞手脚。发狠点的可能性是有的，但至少是愿买愿卖。路边买水果，基本也是正常情况。

+   三，独特的气候

海南气候确实有养生之效。我家孩子来海南的时候，冬季咳嗽，流鼻，来了之后，气候暖和，基本就好了。我来了之后，没有咳嗽过。

海南非常潮湿，但是，现在抽湿机普及了，一个房间一个，适度控制在50%的舒适区，也没什么了。被褥衣粮都是干燥的。

+   四，海南妇女，吃苦耐劳

我在青岛的五星级酒店看到，很多打扫卫生者都是中年男性了。海南的旅游宾馆业，从事一般劳动的，清一色是附近农村中的青年女性，而且看上去也比较乐观。北方妇女如果是从事打扫卫生，都是板个脸，觉得没面子。

+   五，觉得经济发展的路子，还要再想想

现在是说海南将来要搞国际贸易，我从学术的观点看，并不认为是最佳路径。海南，孤悬海外，和内地交通不便，本地市场也没什么消费力，也没有生产力，搞什么外贸啊？搞外贸最好的地点，改革开放四十年的经济实践，已经测出来了，就是长三角，珠三角，勉強发展一个大连烟台也就到底了。

+   六，思考：海南应该大力发展旅游休闲产业，顺带拉动楼市经济

发展经济，说白了就是比较优势，各做各的强项，强强联合。海南和内地相比，唯一的强项就是气候好，土地多，空气好，水好。你和珠三角比货贸出口，有必要吗？

海南这种条件，应该是该在国际旅游休闲养老者的方向发展，以候鸟为抓手，吸引广大内地中产家庭，来旅游。买不买房子没关系，至少你来消费了一个星期，这就够了。最佳模式是，中产家庭买个小公寓楼，老人住三个月，成年子女，春节玩一个星期，小孩子玩二十天，渡过寒冷的冬天。

现在是限购，可能这些思考不符合实际，但也算是一些建言，没有其他意思。

+   七，具体措施

按照国家“一城一策”的战略定位，实事求是，做好经济发展工作。楼市容积率是必要的，但是急刹车后，也要把脚拍一下，才能保证整体平稳。

说白了，国家级省级贫困县，你去限制干什么？他有本事发展，只要不污染环境，我们高兴还来不及呢！
