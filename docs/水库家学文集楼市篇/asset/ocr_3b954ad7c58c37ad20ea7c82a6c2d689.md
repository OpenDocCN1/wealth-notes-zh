够，没什么大产业，也不是市中心，距离西濒湿地公园，还有好长一段路，没有十年靠过不来。

无锡是近十多年经济发展最曲折的一个城市了，2007年太湖一场蓝藻爆发，举国震惊，把无锡小工厂拆的八九不离十了，民企一做产业集群就此停滞后。2013年，高调辞职，民企高科技成了当地笑柄。这些年没缓过来，但也有些外惊喜，在十年前低成本的情况下小作坊拆蛋不多了，现在土地价值重新发现了，开心了。

苏州楼市一直是无锡的风向标，只要苏州热，就没无锡什么事了，等着吧，等苏州吃饱了，无锡才轮到上场，抓紧扎几口，然后就没一刃的挖到了，翻翻过去老报纸，基本如此。所以，无锡一直是有心无力，挑不高。

不过，这次新的机会来了。苏州这几年地价太高了，外企跑了不少，大家心里有数，就不要说了。新进里的大民企，基本是二三级子公司，占个地盘，设个窗口，前途远大，但也总有小过程。所以，苏州的经济发展速度慢了。一不留神，无锡大阿福飞起来了。今年第一季度，无锡GDP增速7.5%（后劲足），全省第一。而且，无锡的经济质量非常高，基本没有太多脏乱差的小工厂，十年前全干掉了。

无锡最牛的是仍然是，先进制造业。这个优势一旦确定，基本就是躺着通吃了。目前看，无锡华虹等，还是很的前进的，做起来了肯定不比华为差。无锡还提出了具体目标：物联网、集成电路、高端纺织服装、高端软件、节能环保、汽车及零部件（含新能源汽车等）等6个超千亿元产业集群、高端装备、特钢、高分子材料、电子元器件、新能源等5个超500亿元产业集群。

规划是一回事，能不能做到，是另外一回事，但规划也不是凭空产生的，至少有一定基础坚定决心。

我对无锡的观点是，两年内赶上青岛。希望无锡发展的越来越好。

# # 苏州限售出台（2019.05）

苏州部分重点区域新房限售3年，二手房限售5年。

苏州市政府出台《关于进一步促进全市房地产市场持续稳定健康发展的补充意见》。补充通知如下：一、调整土地出让报批规则，将土地出让报批条件认定调整为区间设置。二、对苏州工业园区全体、苏州高新区部分重点区域（东起青杭铁路，西至渡江路，南至竹园路，北至邓尉路）新建商品房实施房屋限制转让措施。自本意见发布之日起，限制转让区域内新取得预（销）售许可的商品住房项目（含已经取得预售许可尚未开始网签的项目），购房人自取得不动产权证之日起，满三年后方可转让。三、对苏州工业园区全体二手房实施限制转让措施。自本意见发布之日起，购房人通过二手房交易市场交易新取得不动产权证满五年后方可转让。
