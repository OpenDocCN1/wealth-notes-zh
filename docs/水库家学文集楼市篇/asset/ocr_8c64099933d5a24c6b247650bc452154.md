# 房价代表高斯岗位和福利，巴黎不能和北京类比。

1，高薪岗位。巴黎和北京类似，越是市中心，好单位越多。

2，福利。法国的福利是全国统一价，不存在高者分高不同，医保不同，车牌摇号，买房限购，所以外地人对于是否挤到巴黎去，完全是上班远近因素，没有什么其他利益。

3，学区房。巴黎的名牌小学，是财力大比拼，家长学历单位，住房情况，孩子面试成绩，高昂学费。北京学区房的概念是不存在的。

4，外地孩子读书，都是就近读书，普通学校，没什么麻烦。

观点：巴黎房价不存在额外利益，供求关系基本平衡。北京房价捆绑了社会福利，孩子读书，供不应求，价格上扬，引发了投资需求。

# 法德的房价为什么平稳？

因为他们经过了几百年的自由迁徙，早就完成了人口大流动。现在，法国各城市的人口，基本比较平稳，有进有出。例如巴黎，外省年轻人去追求梦想，中年外地旅客日离婚，基本保持了一个平稳，不会出现二十万一平方米的事情。德国完全是一些小城市，柏林并不是大家都想去的城市。

京沪的无户无定居，是在 2005 年以后爆发的，才短短十几年，还远没有达到进进出出平衡，如果不加以遏制，实际人口肯定是远大于出。市区的土地和容积率是不可能再增加了，人口越来越多，住房要求越来越高，有关部门在楼市里获得了巨大利益。土地财政，应运而生。
