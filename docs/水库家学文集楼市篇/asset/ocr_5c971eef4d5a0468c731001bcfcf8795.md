真正的难题是银行，有些人断供了，炒房，失业和破产，都可能。按照常规思考，卖房归还，互不相欠。但是，这些地方买的是期房，只写两年限购期，前后写后可是四年了，这就傻眼了，取消预售，可以卖了，银行安全性就高了。

# 内地农村年轻人走光了

基本不适宜居住了。

不要以为农村房子大就好，在农村生活，需要各种配套服务，包括购物，维修。现在的情况是，屋顶漏水，下水逢堵塞，在农村可能找不到人修。年轻人都去大城市赚钱了，农村没有什么机会，零零星星的小活，农村也出不起钱。这样的恶性循环，导致地段偏一点的农村，根本*有服务系统。网络坏了，只能等好几天，哪天修好，不知道。

# 县城楼市最多还可以撑十年，然后就没有新增需求了。

我们要看准小地方楼市，就必须研究农村和农业人口。现在的县城楼市，谁在买？

+   1，拆迁户，货币安置，必须把钱花掉。

+   2，本县农村小年轻，结婚需要。

+   3，本县农村偏远地段，轮不到拆迁的7080后，他们被大城市限购了。经济实力一般，只能在县城买个养老的房子。

+   4，县城居民和体制内家庭，基本有拆迁机会，往往是小换大的置换，不能算外来新增需求。

一，农村70后的购买力释放完毕

70后都四十岁多了，如果现在没买县城，基本不会买了，或买不起了。

二，农村80后是前几年的县城购房主力军

本来，这些人也不愿意买在老家，平时用不上，只是春节里显几天，所以，前儿年县城出现了大量的楼市库存。但2016年，楼市去库存，大城市纷纷限购十暴涨，小地方是棚改发钞票，县城也涨了。很多80后没办法，只能在老家挤一套房子。

县城最大的问题是，没有什么高薪岗位。我家保姆的女儿侄女等，在四川县城当小店营业员，每月收入二干多。这些年轻妇女主要是为了孩子读书，居住环境好一点，老公在外面打工，收入8000~15000元（高薪的主要是建筑工地），女生长期没人用，经济不宽裕，出轨越来越少。现在很多家庭选择，孩子到老公打工地读小学，除了一线城市，其他地方读书还算方便。

三，部分90后目前还在县城购房

他们的父母是68年到75年的多，家长读书时候赶上了恢复高考，是最早一批中学毕业的农村打工者。有的家长在城里混好了，在工作和买房，不回来了。

有的家长混得好，孩子一直在农村长大，这部分农村孩子，实际上五谷不分，绅士情怀，还读了个三本高同，完全不能吃苦，一部分人就留在县城结婚了。县城买婚房，总价60~80万，贷款一半，也说什么。

四，外出的90后普遍不愿意再回县城了

一部分孩子，从小到大离开老家，对老家完全没有了感情了。即使初二回来考学，也是临时思想，根本不想在家哪混。

一部分留在本地长大，属于第一代留守儿童，也不愿意再走老路了。大概率是把孩子带在身边，外出工作。
