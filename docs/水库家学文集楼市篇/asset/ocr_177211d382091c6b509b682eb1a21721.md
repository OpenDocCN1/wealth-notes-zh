# 为什么很多美国上市公司回归 A 股

为什么很多美国上市公司（内地企业）纷纷要求回到 A 股？

答：因为内地的股价明显偏高，高 50-100%以上。这两个好处：

+   1.  套现后，股东身价大涨。
2.  不套现，股权质押给银行，贷款总额大幅度上升，缓解资金压力。
3.  太阳底下没有新鲜事。

# 郁金香泡沫，已经永远消失了

所谓价格泡沫，必须有个前提，货币总量基本稳定。如果某个商品价格暴涨，会导致社会上没钱维持这么高的价格，最后价格崩溃。郁金香时代是金市，香港是浮动联系汇率，日元有广场协议，货币总量是强约束，泡沫是必须破裂的。

但是，如果某个经济体的货币是不受约束的，那么就根本没有泡沫，只不过是水涨船高而已。
