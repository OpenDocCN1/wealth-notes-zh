# 微观经济学，根本没月

微观经济学的本质是管理人，通过员工的为员工工作，提高企业效率。这个事情说起来很美好，但微观经济学的前提是，有一套规范的制度。商人在这套制度下研究如何提高效率？

实际上，目前的企业环境根本不存在这种制度。民营企业遇到的问题是非常非常的复杂，任何环节都可以卡你一把。你想按规则走，你可能就走不通。你绕开走，就会产生非常复杂的后果，搞不好就把自已搭进去了。最后，就变成了一团乱麻。

你制定了一个很好的工资考核办法，但是这个方法触及了很多工头的利益，他们就会联合一些人给你捣蛋。你接了一个大的订单，他们跟你说，你拿他们一点油头都没有。或许你可以开除他们几个，但是，你的订单可能就无法完成，造成了更大的损失。

你设计了一个非常好的规范采购流程。但是，具体操作的人为了吃回扣，故意给你找麻烦，这个办法也不行，那个条件也达不到。你不可能再雇佣很多人去调查他是不是吃回扣，事实上你也调查不到。

只要你触及到了员工的利益，那么员工就千方百计给你制造障碍。最后很多民营企业就变成了稀里糊涂的过，只要大体上还有点钱挣，大家就不断破裂。

如果触及到了利益，就变成了举报，打官司，雇洋汇，出卖技术信息，出卖客户名单，各种乱七八糟的事情一大堆。而这些问题所引发的法律争议，成本是非常高的，很多小老板也没有精力去搞这个。

或许你可以举出几个超级大企业，他们管的非常好，他们是干得非常好，我们并不清楚。一个企业在高速发展的时候，利润大，发钱爽，那么乱七八糟的事情就少，老板有钱赚，员工奖金多，大家就很和谐。

但是，天天赚大钱，年年大发展的企业，是非常少的，大部分企业，还是一个相对稳定的利润，那么这个时候，老板和员工之间的关系就是你多我少的关系，这种关系是很紧张和微妙的。

微观经济学在处理复杂利益纠纷的过程中，基本是没有作用的。

# 新科技产业很难在老科技城市诞生

为什么新的科技产业很难在一个老科技城市上诞生？

席梅修，曾经是工业时代最辉煌的城市，为什么硅谷没有在这个地方出现呢？上海沈阳，曾经是计划经济时代工业科技最发达的城市，为什么腾讯、华为，阿里并没有在这些城市诞生呢？

原因很简单。柯达胶卷永远不可能发明数码相机，新的科技诞生，要彻底颠覆老的产业格局，而老格局的利益相关方，长期以未形成的各种利益盘根错节，势力非常强大，一个以重工业或轻工业为主的城市，并不具备立即转型到高科技互联网企业的能力，一旦颠覆了老格局，会产生大量的经济问题，至少就业人口的转移是一个巨大的麻烦。

举例，上海是全国的商贸中心，淮海路南京路，外滩陆家汇，寸寸千金，如果互联网销售成为主流，那么上海的商场将全面的失去价值。无论我们表面上怎样解释这个问题，但是内心的价值判断应该是一样的。

华为最早的程控机，并不是在大城市得到广泛认可使用，而是在一些经济落后的县城，甚至一些偏远的工矿企业，原来的大城市都是进口程控机，这个流派有非常多老的利益相关方，至少有个出国考察的好处吧。

一个颠覆性的科技，往往产生于老格局最薄弱弱的边远地区，然后慢慢的推广，最后得到大家的认同。这就是农村包围城市的概念。同样，当造地下铁路的时候，也是非常非共识的。

原来大型综合城市面对新情况新问题，如知转变思路，就成为这个城市今后发展情况的决定性因素。同样面临新的转型，计划经济时代最耀眼的三个城市，上海，天津和沈阳，走的道路完全不同。

上海是以轻工业为主的，纺织机呢，统一下来了，老一代人家的生活用品，衣，帽，鞋，缝纫机，电视机，录音机，都是上海生产的，但上海迅速转型了，百万纺织工全部下岗，钢铁厂，电子厂，自行车厂，基本关停。90 年代的上海不如广州，上海很多漂亮的姑娘背井离乡，到南海广州去唱 KTV，甚至更加不块。

上海的综合实力较强，人才储备丰富，各种业态都有一些基本的储备，所以迅速追了上来，现在金融业，航运业，先进制造业等一大批代表国家综合实力的项目，成为了新的发展动力。

天津，算是历尽艰辛，咿罢背非的保住了北方第二的地位，但这更多的是因为直辖市地位和靠近北京的辐射作用。

东北老工业基地则陷入了悲凉，东北一直是一种重工业为主，你标长体重的，在 90 年代不愿意放弃老的利益格局，没有转型的勇气，试图继续计划经济那种国家订单承销的模式，现在，经济发发展的情况越来越困难。
