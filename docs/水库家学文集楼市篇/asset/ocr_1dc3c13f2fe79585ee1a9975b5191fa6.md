我打麻将，赢多输少，出牌很快。高考，数学前几名，外语差点，所以去了二本。我上班后，自学劳动技，各种问题，滚瓜烂熟。我考职称，比同龄人早两年通过。各种人情世故，小领导的心思，看一眼就看穿。可我为什就赚不到钱？

答：1、发财都是借势，占据优势地位，少部分人份的配合，赚大部分人份的钱。

2，你学的都是利己工具，别人内心都排斥，你没有机会出头，自然就够了。

3，要学会团结人，让别人喜欢你，你才有机会领导组织别人，干大生意。单打独斗，赚不到大钱的。

# 用“债转股”完成“去杠杆”

是中国经济的伟大实践，是对西方经济学的重锤。

1，杠杆的意思是，负债率太高，例如净资产1亿，负债3亿，三倍杠杆。

2，债转股就赚哭了。本大爷的公司，负债3亿还不出，马上变老赖了，没关系，把2亿债务甩给银行，算银行入股的本条金，就不用还钱了。第二天，本公司就是净资产3亿，负债1亿，非常优质，基本无杠杆。

3，去杠杆，就是拿笔画一下就行了。我是服气的。

# 理论探讨（2018.06）

今天下午深准的货币学含义：3万亿如期而至！

目前，货币余额约175万亿，定向降准直接释放0.7万亿。按照5倍的货币乘数，扣除法定准备金，年底，市面上又要多出3万亿m2。

货币乘数就是法定准备金金的倒数，现在法定是20%，货币乘数就是5。

货币乘数的意思是，央行释放一元钱，经过反复借贷存取，最终在市场上会多出多少钱？一般认为一元变五元。
