# 为什么小地方不限购？

小地方的财政压力太了，这么多吃公家饭的人，靠谱的企业没几个，不卖地就没钱，只能等上面拨款了。上面也难啊！

小地方的购销两旺，本质上是债务转移，把公共债务转到私人部门。一线城市，财源广泛，积蓄雄厚，收入一块，也能花几年。

现在最大的问题是，如果楼市不能收回 m2，不能稳定缴纳高薪水民工，后面的事情就不好办了。我们必须抓住宝贵的机遇期，创造一个替代楼市的行业集群。现在，美国那边也是扑朔迷离，你说怎么办？

中国经济稳中向好，我们欢乐鼓舞。

# 各地楼市现在啥情况？我用一句话讲清楚

有价值的，都在跌跌。没价值的，都在微涨。

最近一年，我们一二线大城市普遍打 92-95 折，四五线城市大部分是涨的。原因很简单：限购+摇号。

大城市限购后，多数人了不能买了，基本面撑住了。但还有一部分人具备购房资格。怎么办呢？摇号。大城市拿出少量低价房，吸引大家去抽低签，顺带压低了二手房市场价格。购房看一看，啊，这么多人讨好我啊，那还要再等等，期盼更大的便宜。这个办法，在前两年肯定是有效的。
