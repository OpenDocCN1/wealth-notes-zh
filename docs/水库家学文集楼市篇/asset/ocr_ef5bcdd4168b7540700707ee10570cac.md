# 房产证就是大额存折

买房不是消费。这是国家政策明确的。统计调 cpi 指数，消费品物价指数，是不包括房价的。买房类似于存银行，房产证就是大额存单。

没有人会认为，存银行是掏空了我们家的财富。事实上，买房的家庭，个个是欢天喜地，放鞭炮。楼市实现了财富的平稳运行，有恒产者有恒心，社会也更加和谐美好了。

房价事实上没有涨，只是表面数字有点小心的变化。与此同时，其他商品也贵了。我十年前买房的时候，番茄 1.2 元，现在番茄 5-8 元了。农民把我口袋掏空了吗？不是的。我们和农民一起进步了！

我喜欢大额存折！
