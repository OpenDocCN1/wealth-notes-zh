# 偶尔一次年入两百万

没房子的外地户，和上海正常家庭比，真不算什么。

上班族，年入两百万是很罕见的，上市公司总经理也不过如此。这种情况往往很难持久的，除非是大厂高管，技术大牛。更多的情况是，偶然一次，例如项目成功，拉到大单子，单位上市后一次性收入。

与此同时，外环外的周遭，新房也卖5万多，六百万一套小三居，还是毛坯房。首付有了，接下来每月两万多月供怎么办？你还是继续挤公交？

如果你五年持续年入两百万，五年后的一千万相当于现在什么房子？你心里没点数吗？所以，做人还是要谦虚，年入两百万，在房子面前，也就是个卫生间。不要太激动了。
