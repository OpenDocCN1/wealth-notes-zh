# ## 假如京沪按 1%征收房产税

房产税。美国最低是 1%每年，也有 2-3%的，但不多。假设京沪 1%来征收：

一是单套免税。那就会抢购豪宅了。富裕家庭把手里的多套普通房子抛售，拼成一套。但是，京沪的实际情况是内环缘源公寓并不多，也就是 3 万套左右，到时候内环线的房价就疯了。我是欢迎的。

二是每套征收。现在浦浦一套五百万是起步价，一年要交税五万。实际上很多家庭是无能力承受的，例如老人，丧偶，疾病，残疾，还贷中。不交税的，判刑还是上黑名单？

三是税率降低，例如 0.3%，一千万房子，每年交 3 万，这对房价有多少遏制作用？

四是税负转嫁，如果高税率，房租肯定是飙升的，除非京沪的房子租不出去。

五是有条件申请减免。这利益实在太大了，到时候黄牛可以重新就业了！

# ## 房产税的宏观考虑

作为财政学专家，我最担心的是，房产税的宏观调控，要避免京沪抽干了全国的水。

房产税必须是一年一收，才能起到作用。
