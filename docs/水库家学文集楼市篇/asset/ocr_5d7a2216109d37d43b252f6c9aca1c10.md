周浦虹桥预计，2005年前在市区人眼里是遥远的地方，一辈子都不会去的。现在，城市化已经慢慢接近了，道路修好了，现在医疗和教育还有点欠缺。我估计，周浦这个地方，5-8年后可以参照市区看待了。

同理，九亭佘山马陆等郊环线，8-15年后，也会成为市区。如果你有条件，可以买一套漂亮别墅，空置十年，给儿子娶媳妇准备。因为十年后，一切条件好了，你也买不起了。

房子总是要有的，有些杂乱无章的话，你不要听。你们打心自问，你希望女儿嫁进漂亮独立别墅，还是在曹杨二村租个小破小？

# ### 京沪中产家长怎么解决下一代的住房？

有几套房子的，请绕道。

靠孩子自己努力，考上985，工作三年，婚前买房，是天天被诅咒了。不买房，公婆嫁给小美女洗漱是不可能的。小美女现在都聪明了，父母嫁也是严格把关。不见房子不点头，没钱也娶不房子。

问题总要解决，聪明的中产家长应该打个小时后动手。你先去看看，十年后可城市化的郊区，提前打个地基，按照自己的实际收入，尽可能贷款买上一套100平米的。现在的房子质量好，十年内绝对和新房一样，甚至比新的还好。新房小区，绿化还是小树苗，十年后是参天大树了，小区绿化档次更上一层。

上海买新房，千万不要买外观是浅白色和乳白色的小区，上海梅雨季容易导致房屋外墙有霉斑，十年后很难看，小区外观档次：

二等级，夹石料。

三等品，1-3楼是石材，以上是涂饰。

拆迁房，套装刷漆。

谁都喜欢外环郊漂亮公寓，但我们也实事求，绝大部分人还是住在外环外的。我去伦敦巴黎考察过，他们大部分人住在外城郊区，去市区叫做去巴黎，巴黎伦敦基本完城市化，郊区和市区是完美整合。上海的郊区和市中心，没有实质连接，当中还存在农田阻隔，这就是机会。

# ### 房价下跌的两种情况

+   一是基础原因，经济较差，人才流失，例如东北一些级城市。特点是，量价齐跌，长期阴跌，幅度不大，但趋势明确，一年不如一年，这种地方是没办法，自住可以，不要发财了。

二是行政原因，例如突然的供受限，特点是，成交量突然萎缩，价格止跌，一夜之间，排队的人没了。但是，这个城市的经济基本没有改变，只是通过行政措施，暂时剥夺了一批人的购买资格或者贷款资格，这种假跌。过几年，大家满足资格了，购买需求又会卷土重来，而且还套换了近几年多攒出来的存款，势头更加凶猛，而且集中爆发性强。
