# 长期稳定的扶贫

应该是走市场化道路，提倡劳动致富。

扶贫工作，非常重要。当年我留学的时候，有很多人为贫穷失业而愤青，在国外的工 厂里，尖 进，小偷小摸，听到那种情况，我实在难以觉得我们多厉害，感觉不到什么"厉害了，我的人"。 消灭贫困，是一个大国的伟大责任，义不容辞。

短期内，给贫困户送钱送物，是工作需要，立竿见影。机关小干部领来洛也方便。但是，彻底 解决问题，应该是让有劳动能力的人通过劳动脱贫。我们给那些长期脱毒的农村酒架子的大小微烂， 送再多的钱，也没用。这个月得钱了，下个月呢？

在中国，四大之家，只要有一个壮劳力打工，就脱贫了。问题是，不少家庭就有一个壮劳力， 只有一些老弱病号，4050 人员。这些人群是脱贫的重点之区。正常总想应该是，大活做不了，那就 做点小活。红包不行，那就看大门，多少是个收入。可事情被劳动法搅乱了。

劳动法对员工进行了无微不至的关怀，导致用人单位慎之又慎。这些老弱病号，4050，一旦录 用，就很难辞退。如果他们干不好（要是长期干得好，也不至于贫困了），用人单位很难辞退， 等于是要背长期包袱了，必须包括他们退休。有几个中小企业养得起这么大人力包袱的话啊，也就不 敢接单了。

与此同时，国企也不喜欢这些人帮。贫困县的河流二池子大多数是贫困人口，那个电力局要， 你站出来？你看，民企要不动，国企不想要，农村设施干不了，你说怎么办？继续送钱送物？这也 不是办法啊！建议：

+   一、修改劳动法，给这些急需脱贫的贫困户以灵活就业的待遇，双向选择，双方自愿。不能 一点是。劳动脱贫。

+   二、充分发挥中小企业业主渠道的作用，拿出政策干货，积极鼓励民企吸纳贫困人口就业。 再也不要像什么暴心态，不要让这种小气。各行各业都有些问题，国企也不是十全十美， 就看盯着说什么了。民企也是建设主力军。

+   三、一视同仁降低企业税费，鼓励中小企业做大做强。民企生意好了，用人自然也就多了。

+   四、扶贫工作是长期任务，单靠送钱是不行的。这个月送了，下个月你还送不送？
