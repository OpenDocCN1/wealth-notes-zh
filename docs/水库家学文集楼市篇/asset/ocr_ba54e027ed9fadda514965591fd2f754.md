# 投稿：精装修房子，确实郁闷

+   1. 承诺是某名牌产品，但不说型号。实际上安装的是所谓的知名品牌“工程款”，质量差，尺寸很小，类似于纸制门，迷你马桶，以及各种滞销产品。

+   2. 安装工艺极差极差。安装的时候，没有业主监督收督，大概一半的东西，都不能用。例如门是坏的，玻璃裂开，水龙头没有装上，渗水严重，大门不严密，线路不通，都需要报修。实际上，拖拖拉拉，一两个月都没没人来。

+   3. 改装踢脚条。开发商一般会赠送一点毛坯面积，给你今后改装。但是，精装修的房子，死透水泥黄沙，拉电线水嘴，墙面基本全毁了，毛坯毁了一半。

+   4. 不满意的设计，或者使用不便，也无法修改了。你想拆除一点地方，但无法收口，实际上就要拆一大片，或者不改了。

结论：目前建筑施工的责任心较差，没有业主监督验收的所谓精装修，实际上比重新装修还麻烦，多花一趟钱。
