二，不要把房子作为筹码来思考问题，房子确实有金融属性，但这是次要内容。你有余钱的情况下，可以轻捻一下，但不会捻猛了。

三，任何孤注一掷的企划，我都反对。货币形势的变化，有时候不是完全按照我们的一厢情愿的预测来演的。忽如其来的黑天鹅，我们经历好几次了。近十余来，杠杆大神层出不穷，熬到现在的，也不多了。做人做事，要留点余地。打仗还有预备队呢。

四，我举个比例，自有资金最低要有三成，话期贷款必须保留六个月以上的月供。在这个情况下，适当往上赌一下是可以的。

# 京沪广深

对二三线城市的降低强压。

站在五年的周期性高度，楼市的规律是十分明显的。京沪广深第一波热起来，然后出政策抑制一下。热钱蹦踉立马窜入二线。因为江浙沪皖家庭，往往是互通的，儿子在上海，老爸在合肥之类的，两线都有房票。二线城市有了一线榜样，只要资金一到，不用动员就热了。

这就出现了一个明显的时间差漏洞。一线城市先热起来，二线未热。如果置换，二线城市明显吃亏了。

+   1，儿于在京沪。二线城市卖的时候，价格还在平稳期，拿钱去京沪换货，遇到的是已经热起来的价格。

+   2、相反，一线卖的时候是好价格，去二线扫货的时候，还是平稳价。

结论：人往高处走。

# 楼市里，谁跌跌，谁看好？

我有个亲戚，五十多岁大叔，中高级职称。前几年，经常看到他义愤填唐，口水横飞的投诉房价高，经常在微信群里转发一些房价不如大意的文章。

再后来，他儿子要结婚了，他毫不犹豫的把一辈子的存款投进去了，和女方家一起出资，首付了一个小二居，在杭州，从此之后，他立马成为钢铁般意志的看多派。

后来我问他：你以前不是看跌吗？

他咬着牙齿，一脸得意的教育我说：已经涨了一百多万。年轻人啊，任何事情不要一根筋。要与时俱进，天天进步。

我服气了。
