# 以前是怎么让一个地区的房子迅速涨起来的?

+   1. 先找个借口或者卖点, 舆论一下。当然, 这是虚的。例如 x 万亿, xx 博览会, xx 运动会, 高铁, 安库容, 反正就是个由头。

+   2. 抢卖地, 货币化拆迁。一家给几百万, 几千万 (例如商铺, 小厂), 动员他们自己买房。于是, 楼市里突然出现一群野蛮人, 用小孩子背着现金入市了。

+   3. 中介, 开发商, 售楼小姐, 各路专家, 哄的一下来到此处, 火爆了, 火爆了。

+   4. 银行放水, 拆迁户的竞价还是开发商的, 楼市要吸引的是场外资金。这就需要银行积极支持了。贷款哗哗的放。

+   5. 报纸说要严厉遏制本市本区本县房价。这下子把没想到买房的人, 也吓傻了。大家都买了, 谁也别硬扛了。老爷, 明天去看房。

+   6. 然后, 房价就按照自己的逻辑演绎了。

+   7. 等本地房子销售差不多了, 当的一下, 严厉限购, 封山育林了, 积蓄下一波正能量了。
