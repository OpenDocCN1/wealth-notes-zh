狠复清单一下子就拿出来，就觉冠大了。但是，如果不适当反击一下，被牵着鼻子走，也太窝囊了。有点左右为难，先搞个不痛不痒的反击，目前看是稳妥的。

4. 最钻的是，举艳不拖，就怎么耗着。这就可以了。因为市场经济的核心理念是预期。如果欧美形成了总要打一次贸易战的经济预期，那就不会投资了，反而是加快跑了。内贸也头大了，到底还能不能继续生产了？研发搞不翻了？招工料怎么办？

# 两头在外是改革开放初期经济起飞的巨大法宝 (2018.03)

中国外贸的“两头在外”策略，导致巨大的外贸顺差，这实在是难以解决。

两头在外是改革开放初期经济起飞的巨大法宝。大致意思是，来料加工，全部出口。我们廉价打工的人力钱。当时，中国的土地基本不要钱，水电气便宜，工资低的基本不要钱似的。税费大优惠。全世界就好像发现了经济新大陆一样，纷纷来办厂。这些厂生产的东西，是供应欧美市场的，比较贵。当时一般中国人工资只有几百元，根本买不起的，也只能是全部出口。

两头在外，肯定是贸易顺差。我们就是在当中赚个人钱，你还怎么样？但是，老美就找这个麻烦，说什么贸易赤字。在入世之前，老美派了一个对华的狠崽崽来侦，现在的年轻人已经不知道了。最狠间谍，年年要申报一次，等于美年年要来找一个麻烦，我们实在是觉得太累了，就希望加入WTO，一次性解决。

这么多年过去了，“两头在外”这种临时性的措施还是外贸主流（增加了一点内销而已），最著名的例子是，苹果手机系列。苹果手机除了富土康食堂的框架是国产的，我实在想不出哪个零件是国产的。这就是典型的两头在外。现成为了贸易顺差的巨大来源。这事情，基本无解了。

美国，对大多数国家都是逆进口，多出口，这不来顺差常常。美元是他的印，随便欠。但是美国就拿着这个事情来敲打别人，怎么办呢？我们就也没办法，只能提出了一个词“韬光养晦”，就是忍了。

# 2009年以前的经济模式，还是有借鉴意义的

那时候，国企100%掌握上游资源。民企买来资源后，加工成五花八门的产品，卖给全世界。国企通过原材料的涨价，例如油，电，水，气，铁，钢，煤等，自行决定对私企抽多少提成。

这种模式创造了一个利益分享机制，国企拿大头，民企有贴头。

私企老板可以不睡觉的干活，辛苦全世界的需求大，哪里要加大的修他衫，哪里要换黑色的加标牌，哪里要大号的圣诞节球，他们想尽一切办法满足市场需求。

国企是不可能做到这么高的效率，董事长甚至不愿意主动决策，因为决策是有风险的。位子来之不易，万一决策错了，位子就保不住了。主动请示，事事报告，等待上级批复。这样最安全。但是，市场经济不等人啊。

现在，很多格局都变了。民企已经不再是从前的民企了，因为越来越不赚钱了。为什么不赚钱，我也不敢多说。反正近十年，很少听说谁干发财的，倒闭的厂倒是一茬一茬的。

现在最时髦的是，买房。很多大小老板混在一起，不太生意，就谈买房，北上广买房，海南买房，差不多度假房。谈的眉飞色舞，相当开心。有时候还谈谈股票。

与此同时，各种神仙，普遍歧视民企。例如银行，其他部门；我不敢谈了。那些羞辱人的话，张嘴就来：低端产业，工资太低，黑心老板，你为什么不发明苹果手机啊？你们啊，自生自灭吧？
