# 现在的限购政策

导致京沪女方非常被动和吃亏。男方婚前房产，占用了夫妻共同购房指标和贷款指标，女方损失惨最。

+   1，男方婚前有一套房子，婚后再买房，就是二套房，首付七成。大部分家庭基本买不起了。

+   京沪平均房价是五百万，需要首付350万，再加20万左右的税费，这么多现金，小夫妻是拿不出来的。结果是，女方倒霉。

+   2，婚前男方有两套房，彻底限购了。女方一輩子无房。

+   3，能不能婚后换房？富裕家庭的公婆基本不会同意卖掉婚前房产，腾出一个购房指标的，因为倒腾一次，税费百万了。

+   4，最公平的办法是，男女在婚前各自买一套，然后签个购房协议，各归各。那还结什么婚啊？

+   5，最合理的办法是，别名字。
