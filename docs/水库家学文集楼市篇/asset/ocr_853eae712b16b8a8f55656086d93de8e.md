# 每个旅游城市，都有一条街

欧美也差不多这样。

无非是咖啡店，西餐，麦当劳，还有明信片，景观都很尴尬。

主要是看着建筑群。

在中国，几乎每个旅游城市，都有一条街，人山人海，全是游客，以卖特色零食，以文艺饰品，千篇一律的东西从义乌批发市场加工出品。有卖豆腐脑的也有卖热奶茶的。这条街在北京叫王府井，在上海叫田子坊，在杭州叫河坊街，在黄山叫屯溪老街，在南京叫夫子庙，在成都叫宽窄巷子，在厦门叫中山路，在重庆叫磁器口，在西安叫回民街，在厦门叫鼓浪屿，在桂林象鼻山西街，在新加坡圣淘沙，在天津叫古文化街，在长沙叫火宫殿，在拉萨叫八角街，在丽江叫丽江古城中，在乌镇叫茅东。
