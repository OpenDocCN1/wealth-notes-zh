# 房价问题并不是什么很复杂的问题

完全可以解决的，只不过解决这个问题是需要付出代价的，我们有没有壮士断腕的决心，这个才是问题的关键。

# 解决房价上涨的问题，最核心的几条

+   1. 在源头上控制货币的发行量，整个社会没那么多钱了，那么房价自然就能控制住。
2. 热点特大城市，暂时不要再无休止的接纳新的外来人口，人来了必然是有租房需求的，需求增大了，那么自然会合对价格产生影响。
3. 进一步加快住房供应。不要为了把地价卖高了，故意人为控制卖地节奏，我们可以设定一个在建工程量，比如说，特大城市必须有 30 万套在建工程量；低于 30 万套，立刻批地，哪怕把价格降下来，我们也要把供应量搞上去。
4. 切断地方政府对房价的依赖。我们可以把卖地收入和房产税形成的各种税收，作为中央财政收入，而不是地方财政收入，那么地方就没有这个积极性托高房价了。
5. 对于个人拥有的平方数，做一个上限，例如 60 平米。
6. 全社会搞一次房产普查，到底哪些人拥有最多的房产，公示出来。只有搞清楚哪些人的房子多，那么我们才可以对症下药的解决现在面临的楼市复杂情况。

# 为什么买两套房的家庭是不敢炒房的？

京沪限购两套房，一套是自住房，一套是子女婚房。上海人结婚，男性一般在 30 岁之前，女性在 28 岁之前，外地农村的可能性更早一点。小夫妻工作也就是 5 到 8 年，靠自己的能力，是不可能买得起房子的，必须是父母给他提前准备好的。

夹房价，每隔五年观察，都是大幅度上涨的，所以有子女的家庭，在有能力的情况下，必然是预先购房，所以，限购两套房都是自用，一般不可能套子女婚房去炒的。

# 上海的房子是谁在买？

邱剑锋：上海人口是负增长，那到底是谁在买房？

答：上海实有人口 2400 万，每年新房销售 10-15 万套，二手房 40 万套，五年限购政策之后，新房和二手房的销量更是大幅度下降，很多人买第二套或者以旧换新，所以，涉及的家庭最多是 40-45 万。也就是说每年上海 5%的家庭和房价有关，和人口基数没什么关系。
