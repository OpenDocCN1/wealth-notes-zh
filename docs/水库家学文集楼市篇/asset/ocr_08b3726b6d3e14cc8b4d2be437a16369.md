# 京沪房价的极限是多少？

（理论探讨）

+   1. 如果 m2 不变

    1. 中产家庭，首套房卖掉，扣除剩余贷款，实际得款 500-600 万。

    2. 夫妻收入合计 4 万，这个算偏高了些。如果留出生活费，子女教育医疗费，最多拿出 2.5 万还债，也就是贷款 500 万。

    3. 结论：京沪极限总价在 1000 万。

2. 如果 m2 每年增速是 8-12%

    新增货币不是平均分配的，高收入人群的收入增长一般高于 m2 增速，大致在 10-15%，那么房价每年增加 10%，也就是每年 100 万，应该是顶天了。

3. 研究极限总价的意义

    很多人会说，这是大部分中产的极限，少部分富人完全可以买两三千万的房子。虽然这个道理，但是富人炒的再高，没有接盘侠了，这个价格就是无本之木。

    外地客人来京沪购房，现在越来越困难了，五年社保等限制条件越来越多，很难出现群体买盘。

    四，在大城市大单位上班的父母已经全面超越小老板的经济地位

    省城家庭的子女到京沪定居，小老板往往拿不出 300-500 万现金支持孩子，而省城以前在体制内分过房的，倒是轻轻松松了，卖掉一套就有了。

5. 房价停涨吗？

    停涨是一种办法。还有一种办法是，做高单价的小户型，例如香港 90 平米，就是豪宅了。

6. m2 这样下去，普通人会如何？

    普通家庭会越来越富裕。人民币多了，汇率基本不变，中西部地区的一般家庭超过美国普通家庭，指日可待，厉害了我的国！

    齐心协力，万众一心，为中国经济加油！
