# 结婚谈经济

·女，31 岁，硕，年入 40 万，外地户口，老家金黄农村，上海无房，省城有房（贷款）。阳光活泼。
·男，28 岁，本，年入 7-8 万，沪，郊区二居室。性格内向，宅和闷。

女方希望：
1，不要彩礼，上海房子加女方名字。女方房子不加男方名字。
2，婚礼费用一人一半。
3，婚后，女方管钱，女方给自己父母养老。女方没有兄弟。
4，婚后去外地定居，上海房子出租，租金由女方支配。
大家觉得行不行？

男方的境遇。
1，女方实际控制股，男方彻底缴械，女方收入再多，男方也砸不到钱啊！
2，婚后，男方实际得到的就是合伙过日子。
3，女方属于高收入，估计没时间伺候人。
4，若离婚，女方把钱转移了，男方啥也没了。
5，时间长了，女方要是给男方经济压力，男的估计是悲惨世界了。
