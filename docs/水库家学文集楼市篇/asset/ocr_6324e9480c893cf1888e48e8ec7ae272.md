# ## 上海小两千万的房子

> > （1100-1500万），是什么样的？

1，和你老家县城的三室两厅差不多，可能还不及” 源 gui-yuan”的这两年的新装修房，内部装修也一般。卖点是地段好一段，上班方便，挤地铁容易，小区花园精致一点，大楼的入门处，漂亮一点。

2， 新交付的郊区别墅类产品，边套十八花园。但郊区的问题很多，近郊主要是两个机场的噪音麻烦，各种垃圾填埋场，垃圾截烧厂。因为这些恶心人烟的设施当年都建在两区交界处的近郊。远郊的麻烦是，去江浙比去上海还方便，油门一踩，就地到外地吃大排档了。去一次南京西路，像是乡下人进城，车额进入外环线后，潘四堵车严重，GPS上，一天到晚都是红色标记。浦东除了东方明珠附近，其他地方不怎么堵车。

3，上海没有独栋别墅。我印象中，2006年就将彻底禁止了。现在有些房子看上去像独栋，主要是两个概念，一是双拼，买两吞染个独栋，近五年也罕见了。二是小区里的老栋栋，新装修，这种产品，差异极大。有的是真豪，有的基本已经是拆迁小区水平了。

4，不要把工业厂房当成别墅。现在，有些所谓的企业总楼被产品，看上去是法式大宅，欧式别墅，实际上是工业厂房性质，噪音污染控制标准都是工业园区级别的，居住不舒适。这种房子，不限购，你要认真辨别。
