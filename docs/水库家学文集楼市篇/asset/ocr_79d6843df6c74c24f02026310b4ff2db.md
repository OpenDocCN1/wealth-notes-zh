会不会某天就满了。

70后农民工技是怎么学技术？传帮带。这些人都是在正规技校读过。但工作技能非常强。这些人学手艺，大部分是亲戚朋友老乡，手把手教的。例如我认识某做模具的大技工，在三四线城市，年入二十万是很正常的。他当年是在广东大厂，挨同村的拜师学艺，自己也喜欢钻研。那时候私企效益好，徒弟们热情极高。企业一般会要求大技工带好几个徒弟，企业出钱养人，大技工一般是揭携自己家发中的年轻人。

现在的私企，劳动法严格，利润都不厚，小老板没那个心思养闲人了，直接加班提钱。技工少了，私企夹得行转的也多，需求大，技工少，弱平衡。这批技工已经不会去找徒弟了。自己孩子读了个国际贸易专业，不愿意学这种科级技术了，企业也不愿意花钱养闲人。企业临时配给他的助手，也是时期想辞职考专业编的心态。大家都在打自己的小算盘。很多工厂里多快好省的实战技术，慢慢也失传了。

技校职校的课，和工厂实践，脱高的太远了，完全没有意义，学生最多学习六个月，有个理论框架就行了。最关键的是，学生要在企业里对照实践学习。但是，现在，学生不喜欢，企业不欢迎。（有的企业非常喜欢实习生，适当简单劳动力使用的）学生万一在我企业这里转一转，小企业还讲不活路了。

+   1. 劳动法保护职工是好事，但企业和员工利益平衡，才是共赢。挖偏架对长远发展是不利的。
2. 税收是好事。但农民种地也要留点明年的种子钱，给中小企业留一点活路钱。也是可以考虑的。不要卡的正好好，企业发展也要有点积累才行。
3. 培育高大上企业是好事，但中小企业更重要。大企业不能解决广大中低学历的普通劳动者就业。送快递的商品，也是中小企业生产的。
4. 给中小企业留点活路钱，保住技工队伍的延续性，是经济长远发展的基础性工程。

# 港币的制度性痛点在哪里？

（菜场版）

这几天，土耳其里拉发滞后，新兴市场价格，也战战兢兢的。这边的港币，又碰到7.85的高潮点了。

+   一，港币最大的特色是“浮动联系汇率”
港币兑美元，必须在 1：7.80 附近晃悠，一旦超过警戒线，例如7.85 点位，就必须强力干预，把汇率拉回去。
这个制度的优点是，港币信誉好，不怕大起大落。缺点是，维系成本太高了。
二，港币为什么会跌？
任何公司机构的力量再大，一般也顶不过香港全力以赴的保卫港币。所以，联系汇率存在了很多年。但有一个例外，美元。
假如，美元利率是3%，港币利率也是3%，港币和美元汇率基本不变，大家相安无事。你若安好，便是晴天。
假如，美元利率上调到了5%，港币利率还是3%，那等于香港给人发奖金了。把低利息的港币，换成高利息的美元，存银行就赚钱了。如果配上衍生工具，放大10倍30倍，那就是去夜总会和豪赌谈人生的节奏了。
