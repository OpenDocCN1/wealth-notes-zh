在最贵的，最有面的北京，还要抱怨价格高，这就不合适了。

京沪房价高，为什么还有这么多群众买得起？其实是有合理原因的。

一，计划经济下的福利房，相当于国家送你半套豪宅

北京是计划经济的样板城市。市区无数干部职工群体都分到过房子（当然不是百分之百），这些房子大概分为两种：

1，拆迁了，五环几套房是有的。

2，没拆，现在价值4-5百万是常见情况。置换一下，相当于国家给了半套豪宅。

实在困难的群众，还有廉租房，共产权房，政策房，总有一款适合你。

二，京沪农民是绝对是城市拆迁发展的受益者。

就算差985博士，也比不上拆迁户。省略一千字。

三，十年前进入北京的外地人

他们在高考最难的年月里，千军万马过独木桥，杀出了重围，在北京就业安家了。因为高考很难，所以买房的时候，竞争对手少，就遇上了低价房时代，基本解决了住房。

四，抱怨是扩招的结果

北京就这么点地方，大家都想来，先来的价格宜了，后来的没地了，火气就大了。其实不让后来，就没这事悟了。以前计划经济，外地人暗算北京人房子小的时候，还历历在目，你咋不说那时候外地人剥夺北京人的面积啊？

没人让你拿三代人六个脑袋买房，你们可以买便宜的房子，你不过就是扩招后考了个一本尾巴的学历，就想要非，非要买最好的地段，最好的城市，那你谁啊？你不好好想着建设美国家乡，跑到北京来抱怨房价高，何苦呢？

# 如何提前保护金融诈骗的受害者？

去年，我妈代表全县，干净利落的被骗了十几万退休金。我们这里，娶老婆彩礼也不过是八万八啊！等于亏掉了娶娶两次老婆的钱，我姨，我姑之类的亲戚，也被骗了很大一笔钱，但我内心不同情她们。

因为她们根本不听劝。这群老太太，自以为是，非常固执，总认为这次不祥。"你说的话都懂，但小王经理肯定不会骗我的"，最后全部钱光了，在家痛哭流泪，她们被骗的原因：

+   1，喜欢占便宜。利息高一点，这群老太婆就很高兴，从来不考虑风险。谁要是提醒风险，好像在骂她们贱钱，非常敌视你，鸟鸡哑之类。

+   2，思维陈旧。他们认为，有工商局执照，有著名教授合影，报纸电视台广告，在大街上有正规店面，持续经营好几年了，就是合法正规的，要不是国家你为什么不抓他们？这是标准的计划经济思维，你和他没法说了。

+   3，拒绝风险提示。你和她说，这种公司是骗子，追早要跑路的事。她还要反问，"那你去报案啊！看看国家会不会抓他们？"我当场扇嘴古了七。

+   4，骗子们推销厉害，一般是熟人营销，一嘴骗一层，逐步扩大，受害者在案发前还抱团维护骗子公司信度，一张嘴就是，"我利息都拿到了，是真的"。老年妇女也喜欢相信熟人，你和他没法讲的。
