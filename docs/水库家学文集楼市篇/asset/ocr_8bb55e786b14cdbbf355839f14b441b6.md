# 限房租，总路是好的

但也要重视如何落地？

按照三甲医院的操作，可以把一个阑尾炎手术拆分成几百个收费项目，最后收你多少钱，都是合法的。

限房租后，房东可能另外加收费项目：

1. 交房前的擦玻璃费，1000 元；
2. 厕所地板清洁费，3000 元；
3. 擦油烟机费，600 元；
4. 擦马桶费，800 元；

以此类推，事情就复杂了。

建议：1. 有关部门既然规定房租限价了，还要把其他可能的收费项目，一并列明，通通限价；否则，个别素质不高的房东可能会把一个房租拆分成几百个收费项目。

2. 能不能把三甲医院的大收费，也管管？谢谢。

# 农民小别墅为什么那么便宜？

能不能把农房房的营理理念，嫁接到城市房产？

农民房是最严厉的限购，只能是本乡镇的农民户口之间，才能交易，这就彻底杀死了任何需求。房价=砖头+人工。还根本卖不掉。

如果城市房产也这么搞，那就来劲了。购买本街道辖区内的房产，必须是本区交社保满十年，或者有本街道户口。我保证，京沪房价一夜降到 30%。因为需求没有了。

要想降低房价，有无数的手段，甚至可以规定，房子只能有企业买卖，然后分配给职工。对伐？问题是，这么做的结果是什么？经济失去活力了。

需求减少，生产也就减少了。生产下降，就业就森筷实公鸡了。

这一头，铁公鸡上马，是要大量房子。
