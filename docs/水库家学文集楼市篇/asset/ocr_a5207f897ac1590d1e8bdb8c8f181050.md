# 京沪生活的痛苦，钱花不出去

前两天看电视剧，正阳门，里面有个场景，小酒馆，就是家门口附近，喝点小酒，听听八卦。这种消费场所，一天花费不大；天天去，开支就大了。

京沪也有一些贵的地方，人均一两千块钱，我从来不想去，因为太远了。为了吃个饭，在晚高峰的马路上开一个半小时，头晕脑胀，心情不好。

家门口附近，也没什么消费场所，就是几个肉骨头炖汤，灰灰黄山菜饭，灰尘满天飞，看了就饱了。

我不知道大家有没有日常消费花不出去钱的痛苦？

# 我年轻时，最励志的一句话

说出来，你可能会哭死过去。

“年入十万不是梦”。这就是我们当年拼命激励自己的一句话。前两天，我的法律顾问告诉我，八十年代，打个离婚官司，律师忙几个月，也就是收费40元。估计现在很贵了。wokao, 什么都要趁早啊！

# 和保姆闲聊他们家的经济实力

+   1，儿子，初一学历，送快递，就是送饭的那种，一年9.8万。  
2，儿媳，初中毕业，育月嫂，一年15万以上。  
3，保姆，认字几百个，自己三个钟点工，外加接送小学生下课，一年8万。  
4，老公，可以看管微信，工地扎钢筋，一年10万。

合计一年收入40万，生意超级火爆，比一家人开厂当老板还好的多。

他们觉得京沪房价不高。你家啥情况？

# 我家保姆觉得

大城市家庭，例如你家，大部分是年入百万，低于五十万的，还不如他们村里来南京的垃圾分类老乡，他们都看不起的。我家保姆有个侄女，今年二十三岁了，考出了老年护理执照，前途远大，想找个北京对象，年入百万，三室两厅，可以考虑，再低就连门接受了。你家儿子啥情况？

# 京沪赚钱为什么这么容易？

我老家在儿，中学没读了，辍学来上海了。我对他冷酷热讽，希望他回去好好读高中，不要荒废青春。争取读过二本野鸡大学，以后考个事业编制，当个老师，一个月六千工资。

结果，发生了意外，他去某送餐公司上班了，就他那个只能看懂地名的文化程度，第一个月收入8103元，看得我目瞪口呆，比我在大单位收入还高。为什么？

# 30岁100万够花吗？

首先，你没有100万，我30岁的时候，只有十几万，作为top1和大单位的小跑腿，工资也不高，花钱不少，谈朋友，吃饭店，买衣服，送礼物，房租，存钱很难。
