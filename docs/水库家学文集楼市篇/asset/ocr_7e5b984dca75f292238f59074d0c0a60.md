# 用大格局

看待城市的未来价值。

如果城市新来人口的体力智力，明显好于本地平均数，大利好。例如京沪广深，杭州南京苏州青岛济南南昌门等优质城市。

如果本市优质人口走了，附近农村人进城了，例如瑞昌，是长期利空；平均值越来越低，这种城市没什么花头了。短期的集中购房或者货币因素，表面也会提价一点，但将来房子旧了，也不会有什么大收益。

如果本市优质青年绝大部分回来家族就业属于中上水平，例如重庆成都宁波绍兴无锡等。

我就说个大概思路，各位自己判断。

# 济南优质吗？

答：表面看，济南比青岛差了不少，看上去灰灰的。但是，济南是省会，嫡长子。在山东这种地方，省会是什么地位，将来会如何？不言而喻的。还有南宁，福州。

我对财政有几十年的思考研究，历史上形成的一省双雄局面，经济天平会慢慢倾斜向省会，突破口是在医疗教育。济南超过青岛，不会太久了，我估计5~8年就差不多。苏州因为靠近上海，还能抗一抗。厦门早就被甩远了，也就是个旅游城市了。

# 内地省会城市的未来

肯定是绚丽多彩的。

在很多人眼里，四川只有成都，安徽只有合肥，湖北只有武汉，其他第二第三名，根本无人知晓，也不关心。省内二三流城市基本就是打酱油的，唯一的作用就是抽水机。把本地的学霸，美女，资金，源源不断的输送到省会去，得到的无非是劳动密集型和有污染的制造业而已。

现在，还有些什么傻乎乎的农民工返乡置业，小地方楼市看上去还可以。今后户籍政策，力度越来越多，00后观念进步，没人再会回去了。

大家注意把握，不要被人云亦云带偏了。
