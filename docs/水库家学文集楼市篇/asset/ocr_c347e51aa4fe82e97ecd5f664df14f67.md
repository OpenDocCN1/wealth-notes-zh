调理，医疗教育，货农资源，物资流通，信息传播，只要人口多，居住密的地方，交易就旺盛。你在内环摆个早点摊，辐射的人群大，生意好做。你在山东章县的村口摆一个，基本没生意。

当然，人口稠密也会带来弊端。交通拥堵，水电气资源不够，垃圾太多，房价太贵，公共资源短缺。怎么办呢？不是回老家，而是往外扩散，建立大城市为主的经济圈。

人口密集也分为两种。一种是综合业态丰富，什么都有。无论哪一个行业暂时困难了，也不会影响整体。二是单一的产业结构。虽然短期内集聚了大量人口，但是主业不行了，立马下滑了。

想当年，瑞典的几个资源型城市，何等的兴旺发达！但是，这种城市的产业结构单一，一旦资源没了，直接躺床上干傻了。

这个理念就对我们起到了指导作用。业态丰富，人口密集的大城市，肯定好，放心去。主城区不行，就去郊区看看。郊区也没有资格，考虑就近原则，隔壁省的交界处也看看。或者中东部省会，人口稠密，产业结构丰富的发达地级市。

环沪京区，因为政策原因，规划原因，人为的造成不方便。从全国一盘棋的角度看，迟早会改善的。但我也不推荐你去京沪的周围。因为迟早是早早，谁也说不清，历史一瞬间，人生一辈子。前人栽树，后人乘凉，老了有人管。

倾尽全力往上走！我们再出发！

# # 改革攻坚战

（六百字看清中国经济）

目前最难的几个领域:

+   1. 医疗。看病还是看病贵，是怎么来的。大家心知肚明。办法有的是，关键是下决心，把医药公司的销售成本拿出来核查，一日了然。当然，利益链太粗了。

+   2. 教育。一是中小学异跨省报名，主要是京沪沪深的外地人，孩子读书难。二是高考改革。要保护青少年健康，让所有的孩子都有机会公平的享受高等教育。

+   3. 就业。最关键的是，扶持中小民企。民企容纳了80%的城镇就业。民企稳，就业稳。

+   4. 国企改革。

+   5. 金融改革。涉及很多细节，银行是否歧视中小企业，IPO审批制，保险误导问题，非法理财。

+   6. 三农改革。涉及到土地流转，还有个过程，但是，宅基地集中，已经是如火如荼开展了。

另外几个热点:

+   1. 户口改革已经到位。京沪以外，其他城市，例如深圳杭州，几乎零门槛。

+   2. 住房保障体系基本建立。目前并不鼓励大家集中去京沪买房。更希望的是，大学生分散到中心城市，安居乐业。深圳广州的社保限制，完全可以透过户口解决。

+   3. 农保体系基本全覆盖。今后是继续提高水平的问题。

# # 促内需

住房，教育，医疗。每个家庭90%的存款，都花在这上面了。要想快速拉动内需，必须在这三个领域，加快改革步伐，满足市场需求，更好的服务群众。

住房，第一套平价，第二套限价。富人花钱，就让他花。

教育，除了985，其他大学，一律注册制。鼓励进大学。
