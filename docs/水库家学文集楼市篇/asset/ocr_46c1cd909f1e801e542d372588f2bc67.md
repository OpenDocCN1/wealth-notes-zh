# # 我们投资的目标，不是成为巨富

我们只想成为长大的中产阶层，二十年后，把一份还算沉甸甸的资产交给下一代。我们投资研究的方向，更加全面研究风险和趋势，我们坚决反对超做杠杆。我们不主张赌短期政策。我主张看五年趋势，预估中长期政策。

中国经济总量非常大，超级邮轮不可能瞬间掉头。任何大的经济转向都是有时间的提前量的，包括财政货币政策，货币政策，住房政策，区域规划，产业结构。我们认真追踪分析，是可以发现其中的微妙变化和中长期趋势，举例，大湾区已经箭在弦上了，该区域的限购也会加紧，五年后的经济会更好。我们就是综合各种因素，提出研究观点。

我们不敢说多优秀，但我们在努力！

# # 房产投资规划，分为两大内容

+   1.  一是正常的各个流程环节。
2.  二是意想不到的细节和突发情况。

我们可以对第一部分按部就班的查资料，学习掌握，但是，最难的是第二部分，许多意想不到的事情，实在是防不胜防，无法提前掌握，这就需要有过脑的时候，有购房经验的买房者，（现在不能再叫炒房客了），有贷款经验（例如银行同仁），有合格资质（例如公证员，税务师或律师等）的同事参与讨论，互相启发思路，把矛盾和麻烦消灭在萌芽之中。

换句话说，类似于模拟一年的 EMBA 的讨论课。有没有用说不上，听听到人怎么想问题的，也算是打开思路吧。

我们不研究激发疯狂的投资手法，我们讲温和的跟踏潮流趋势，顺势而为，赶上 M2 即可，不抄底最后一块钱，逢可而上。

# # 为什么GDP下滑？

手机支付是主要原因。

现在，很多小企业和批发市场的小妹，发工资都是支付宝，微信转帐，她们拿了工资就去吃吃喝喝买买买。货币兑了一大圈，全都是在两个马爸爸的虚拟账户里打圈圈，根本没有到银行入表，GDP 也统计不到。这个资金量是惊人的。

# # M1 和 M2

+   - M1 变化主要是指企业活期存款变化，大部分中小民企老板的存款，公私不分，所以基本失真。
- M2 增速下滑实际原因：支付宝和微信支付这类手机支付创新导致的，传统 M2，包括所有现金，实际是我们现在基本不用现金了，这几年，M2 下滑速度和手机支付的发展程度完全一致。现
