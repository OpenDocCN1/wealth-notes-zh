# 今后一段时期的经济形势

会面临扑朔迷离，错综复杂的局面。我是准备谨言慎行。大家一起共同欢欣鼓舞。

经济学分为宏观经济学和微观经济学。我以前偏重多谈的主要是宏观面，例如货币，财政，经济原动力，机制运行，但宏观领域容易惹出不开心的事情，骂我傻逼的二本狗跑来知多了。傻逼就傻逼，who 怕 who？所以，我近段时间改为微观经济学，就是张老板栗汁王类粪。

结合现实需要的的宏观经济论文，选题靠谱的应该是任泽平。以学术标准看，他的理论水平和经济敏感度至少中上了。我不知道他在内部是怎么工作的，但我看他的文章，总觉得故意泼了一口水，最后总是少写了一句两句，因为他没把写这篇论文的原因说出来，他的文章，看上去都是四平八稳的，好像就是一般学术类。

众所周知，他本质上是商业公司的高级员工，在智商言。经济学课题，面大量广，浩若繁星。他为什么选这个题，为什么在这个时间点发言，其实是服务于经济战线现实发展需要的。但是，他做了巧妙的安排，

+   一、是把该简化的搞复杂了，他在面向小白的商业文章中，不需要详细的论证过程，故意写的很复杂，十八般武艺全部使上去了，又是表格，又是引用，看上去是高深莫测。其实，大家知道这部分，应该读几个人看的。

+   二是该点题的话没点出来。直接抹掉了文章的真实性，这就导致一般人看不懂他在说什么了。

最近，我看了他写的传导机制理论的文章，论文主要内容，我们可以如果大致研究过，有基本印象的。他的论文把内容细化了，条理清楚，论证完整，堪称中上水平。但是，你仔细看到最后发现，他为什么写这篇文章，原因没有点题。一般人可能也不会想这么多。看完就算了，大部分人可能根本看不完，确实太长了。

内行看门道。这篇文章其实是有巨大现实意义的。大家可能只关心报纸上的几个名词，例如货币阀门等。你仔细想想，总词只是管了意见，传导机制相当于一管水，如果水顺直涌过去，开闸之后，水会不会浸到其他地方？这事情意意义大。文章详细论述了欧美人日三次开闸的起因，机制，效果，层层推进，表述完整。

算了，反正你们看不懂，我休息了。
