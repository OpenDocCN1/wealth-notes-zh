现在，小城市还能卖卖的炒，若干年后，可能更难了。我对中国城市化发展的判断是，京沪广深+20个中心城市，其他小城市，年轻人很难有什么高起岗位，可能会越来越难做。

# 楼市五年之变化

五年前，微博讨论的是京沪太贵，我劝大家回省城占坑。现在，我们讨论的是省城太贵，我劝大家去省城郊区占坑（例如增城，渝北区）。再过五年，可能无锡宁波这种中等市，也会抢的头破血流了。最后的结局也很明确了，回到我们九十年代的起点：大学生，哪来的回哪去。

人往高处走，你现在的思维，不要老是考虑自己压力大不大，而是要考虑，牺牲自己，给孩子们一个不那么残酷的起点。这就是为人父母的初心，往上走的路总是艰难的，往下走的路总是舒服的。你应该庆幸，你现在还有路可以选。我们在八九十年代，出门都要暂住证的事情，还历历在目。无路可选，那才是伤心。

你不要想当然的以为，一切总会是越来越好。前进的道路，艰难曲折，出现反复也很正常。历史的一个转身，对个人就是一辈子。中国经济稳中向好，我们就欢鼓舞。

# 京沪房价涨了二十年

翻了多少倍，我也数不清了。绝大多数年轻人就是在房价不断上涨的气氛中，从小走到了现在结婚生子。要降低房价，必须来一场彻彻底底的调整，北京五环内回到两万。建议，京沪继续强化社保限购：先调整为8年社保。以后陆续调整到15年社保，彻底打压盛的兴趣。

# 五年前劝你去二三线占坑（2019.02）

菜菜：我耸，有潜力的年轻人抓住现在二三线城市人才竞争不强的时间窗口，跑步去占坑。坚持十年，抱个土愿望，蒸个好彩头，然后再来京沪碰运气。否则，你在北京再抠五年后，终于发现彻底失掉了。这时候超过35岁了，真的晚了，你去小地方也没人要了。

# 大方向，大趋势，大政策

大部分楼市微博，是广告性质的，喜欢研究买哪个楼盘划算一点点。其实，哪有什么划算，开发商比你聪明一百倍。无非是放弃一些品质，得到一些折扣，仅此而已。我的微博是研究三五年后的事情，抓住大方向，大趋势，大政策，这才是最佳姿势。

我从来不愿意细腻具体楼盘，避免利益冲突。人都有趋利性，说着说着，就开始吹自己买的盘了。这就不客观了。异地置业投资，也不是适合所有人，人生地不熟，节假日匆匆忙忙去看一眼，容易被套重套，今后管售也麻烦。

我的建议是，以实际生活地位为圈心，就近考虑省城，京沪广深。接下来的好几年，自住，出租，管理，抛售，都合适和方便。只有没有房源的情况下，才不得不考虑异地。
