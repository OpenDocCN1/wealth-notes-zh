# 房贷的利率变化

![](bbox=[0.15, 0.25, 0.35, 0.29])

*房贷的利率变化会不会影响到已经还住房贷的人？*

1、 房贷的利息是每年的1月1号，通点重定，重新核定。一年调一次，所以，你的每月的还款额，这一年和上一年可能是不一样的。

2、 贷款利率的调整分为两种。

第一种是优惠幅度的调整，这种不影响你的房贷。

第二种是基于基准利率调整，人民银行公布，那么你的房贷就是受到影响的了。

3、 目前看，今年的基准利率没有变化。所以你的房贷没有影响。

4、 如果你是85折利率优惠，那么基准利率变化后，你还是85折优惠。

# 吃亏的事情大家都不愿意干了

真正要平抑房价，让大家不多买房，尽量少买房，就必须让买房成为一件吃亏的事情。吃亏的事情大家都不愿意干了。这个是可以做到的。增加持有成本，或者是转卖之后的利润全部清零。这在历史上是经常发生的。

真正的难点在于，其实是通过房地产，为地方财政征收收入。一线城市中心，10万块一平米的房子，建造成本绝对不会超过5000块。那么95000块去哪里了？

把房地产搞冷却了，大家都不去买房子了。土地卖给谁？各种各样的建筑税收去哪儿收？农民工增收怎么办？GDP怎么算？这些问题不解决，很多事情，我们就很难再进一步的深入探讨了。

# 全国不动产联网

现实的微观影响是：法院执行，房产税，限购依据。

宏观层面的影响是：经济决策的依据。

+   一，法院执行，廉政建设，略

+   二，房产税，明确是地方税。各地只能对区域征收，异地联网的实际作用，暂不明显。

+   三，对限购的影响，京沪广深对异地第二套的认定。现在是处女贷，今后可能是异地首套房。

+   四，禁止全国购买第三套房子的可能性为零。
