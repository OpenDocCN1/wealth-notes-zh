一代的安徽人，难道就因为觉得亏了，摔也不买房了？天天在家哭吗？不是的，该干嘛干嘛，他们赚我们的钱，我们赚他们的钱，只要手里有筹码，大家都赚钱。买房，永远不要想炒炒底最后一块钱，或者在最高点卖出。

每个家庭的买房时间都是不相同的，价格有一定的差距是很正常的。随着时间的推移，当年的这点房价差距，今后将是微不足道的。我记得很清楚，2000年浦东新区潍坊新村的房子，一室户10万元。一年后涨到12万，两年后就涨到了16万。我是10万块钱买的。我一个朋友是15万块钱买的。他先买了1米，心里非常痛苦。

2000年以前，工资很低。5万元存款，是上海普通家庭一辈子的积蓄，相当于中环线一套小户型房子了。因为买房晚了1年多，就损失了5万块的存款，对一个家庭来说简直是晴天霹雳，灾难性的后果。为此，他们全家痛哭，我那个朋友沉默了好几年。

20年过去了，大家再说到潍坊新村的时候，5万元已经忽略不计了。现在那套房子大概是380万左右。

# 这就是大国的难处

人口随意流动和用地指标固化，造成了土地供应量的错配。假设安徽人到上海买房。

上海每年的用地指标并没有因为外地人来多了而相应的增加，上海甚至要确保基本农田。安徽也没有人口外流而相应的减少用地指标。这就造成热点地区土地供应量不足，房价狂涨。而人口大量外流的地区，房子变成了库存，求爹爹告奶奶的兜售，还要国家操地去库存。

如果外地人到北京，把他的用地指标也交给北京，那就彻底解除了用地指标的限制。但是，现阶段不能这么做。因为，这会把经济欠发达地区的资金人才用地指标，分分钟抽取到一线城市，富的越富，穷的越穷。

这就是大国的难处。

# 降低房价的最好办法

+   1，减少商品房供应，加剧供不应求。

+   2，给那些原本不买商品房的人，低价供应房子，并不能减少潜在购房者。

+   3，供应减少，需求没有减少，房价太贵了。

+   4，优质房子的价格是参考市场价的50%，如果市场价暴涨，优惠就会大幅度缩水。

+   6，降低房价的最好办法是，无限量供应，把五年的供应量大一年推向市场，彻底打碎涨价预期。房子建设周期长没关系，直接卖图纸，有关部门借着，我们都相信。
