# 海南的买房考察经历

海南岛中北部的同学：今年海南的冬天是不是太冷太湿了？

前两年，我首选三亚，去过东海岸，高大上的豪宅，但是在那里租了一个冬天，发现阳光明媚，但吃饭不方便。我喜欢吃海鲜，自己买，自己做，但是三亚那里非常不方便，菜市场距离住宅区有8-10公里，连个停车位都没有，我又去了陵水，发现碧桂园，珊瑚小区，大的无边无际，商业配套也不足。

我今年去了海南北部地区的几个小区，活成狗了。买菜方便，门口2公里就是渔民自行销售，价格不高，大螃蟹50元/斤，各种海鱼清算，吃的满嘴流油。

但是，海南北部，今年整个春节，几乎没有什公太阳天，潮湿的实在忍受不了了，早上起来阳台栏杆上全部是水珠，天天是雾气，被子霉了，衣服永远不干。体感湿漉漉的，贼难受。我想问一下，这是正常情况，还是今年特别冷？
