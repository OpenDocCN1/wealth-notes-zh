# 沪郊区小别墅和堡垒的销路

远不如市区大盘。原因很简单，上研读，没有中小学校，商业配套差，医院远。但是，情况在改变之中。

![](img/fe0763d1c3cef9e2b76dd74a0e5520f1_158_0.png)

1. 上班远倒不是事情。买得起别墅的有钱人，大多是生意人，自由职业者，港台明星，外地富人，不一定天天上班，至少家人不上班的很多。
2. 商业配套由团购解决了。中青年身体好，医院也不急。
3. 真正麻烦的是，孩子读书难。郊区别墅区，是玉米地里建起来的，周围没有中小学，最近的农村小学也在 5-8 公里以外。买得起别墅的家长，怎么舍得孩子读农村小学？所以，郊区别墅进入恶性循环。不想买新房，二手房也卖不掉。

这种情况已经在慢慢改变。成熟的别墅区，本地政府已经开始引入高质量的民办优质学校。教育问题慢慢得到突破，10 年后，郊区别墅群是重大机遇。

我去过外地很多别墅区，只要符合“走路上学”的别墅区，都是非常抢手的。如果没有学校，基本是丑丑鸟。

# 县城楼市无未来

这两年县城楼市火爆期。大批量中年人群到县城买房，原因很简单，县城教育质量好，县城医比乡村卫生室靠谱。

与此同时，新一代未婚年轻人，却在迅速逃离县城。除了紧贴大城市的少数县城，中西部地区县城，会越来越少。

菜嫂经常做颈部按摩，遇到了很多县乡出来的勤劳善良和稍打精妆的姑娘。这两年，小姑娘嫁人的要求是，坚决不回县城，必须是中城市有房。

女人在哪，男人就在哪儿。越来越的年轻，也到 1-2 万房价的大城市边缘买房，筑巢引凤，安居乐业，考上一本的，基本都是直扑省城。

县城为什么留不住人？产业结构单一，几个大国企，一堆小私企，一条商业街，不需要几个高技术人才。在长谷，铺盖身的关系网，中低工资的服性岗位，文化生活异单调，连肯德基都是高端时尚。小镇年轻人往往是一种无力感，再努力，也难啊。

大中城市提供了完无多的岗位，选工多，工业足，白领，部门经理，小老板，副教授，领导，什层次的劳力都可以尽情发挥，每个人都有想象的空间。这对崇岗的做梦想人，是具有无限吸引力的，而且可以立即看到实实在在的经济收入。

现在的入口政策就县小镇，加大通入大城市，公务除外。可以想，现在的中年人把工送到本科职毕业后，工们再一定不会再回家了。县城也将慢慢无去。

人往高处走。乡，县城，地级市，省城，京沪。现在的乡镇村，基本看不到几个年轻人了，县城也快没了。今后的大趋势是，京沪加上十个中心城市，基本就完就业。其他地方，地大人稀，养老里，还有什么楼市的前景啊！
