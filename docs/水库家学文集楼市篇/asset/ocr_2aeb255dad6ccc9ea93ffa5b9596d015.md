# 稳定结构，是大趋势

我们的经济规模已经达到世界第二了，我们有十四亿人口已经达到发达国家生活水平了。十年后，我们大概率的全直接进人稳定型社会结构，基础设施基本完成，大学教育普及化，各行各业出现牢不可破的龙头企业。

十年后，可能不会再出现类似九十年代后期那种混乱且刺激的大规模造浪，大规模幸运，大规模的农民进城，超高速经济发展。今后，大家各司其职，安居乐业，务力建设，美好生活。

稳定时期，个人的赚钱能力越来越小了。年轻人拼的是存量，拼的是三代人的积累，我们不要过于纠结我们现在眼前的小利益，小得失，要看长远，看未来。在大城市，第一生活资料就是住房，这是无法改变的，够得到，坚决上。居住不炒，目光长远。

人生就是一代传一代。为了孩子们不再重复我们年轻时的痛苦，我们别无选择，只能勇往直前！

# 京沪广深是个抽水机

和我长期联系的某银行宿舍分理处的小行长，去年底，给在北京的儿子买房子了，九百多万，瞬间掏空了全部家底，他在省城已经退休，就剩下一个老破小的福利房了。这个小行长，一辈子狡诈算计，利用各种条件，买进卖出，在省会几十年攒下了这点家业，被京沪的一纸户口就吸引过去了。

他怎么赚钱的，我不知道。但每年年底年初的贷款过桥资金，都是他帮联系的，态度超级好。这种资金单向流动的情况，绝不是个别的，每年那么多外地年轻人，进迁京沪豪宅，漂亮小区，不是没有道理的。
