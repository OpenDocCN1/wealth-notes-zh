# 京沪接纳外地人的阶段性窗口正在徐徐落幕

京沪已经相继发布了人口容量上限，上海实际人口 2420 万，上限是 2500 万。今后很长一段时期，总的还有 3-4%左右的增量指标，分摊到每年，其实也就 0.5-1%。京沪人口承载极限，是根据污染总量，水资源，绿化率，人口密度，道路交通，医疗教育容量等方面限制的因素汇总形成的，难以很快增加。

一个城市的运行，需要高中低各种劳动人口的搭配，不能全部是高富。京沪可以减少几所大学，但不能减少快递员，物业保安。京沪现在的人口结构中，大概三分之一是非户籍人口。这部分人多数从事一些基层工作，是城市急需的优质劳动力，不可能把装修工劝退，全部引进二本文员。

京沪是计划生育最严格的城市，导致以前出现了人口下降问题。现在，二胎化政策已经逐步开展，新京沪人的生育观念转变，人口增长由负转正，是看得见的带情了。

总体看，外地人要成为京沪新市民的机㑈，已经是难上加难。但京沪是进出自由的经济中心城市，买张火车票就来了。义务制教育普及及自己，社保难倒，都在源源不断的吸引流动人口进入京沪。所以，必须通过其他手段，防止流动人口沉淀积累，确保人口总量。实践中最有效的办法还是：以房管人，以房控人。

流动人口和定居人口，最大的区别是住房。一个家庭，有老有小，要是没有产权房，等你年龄增加，收入下降，自然就会走。因为你的收入无力承担租房费用了。与此相反，住房如果太便宜了，根本不可能控制人口。我住在大兴区庞各庄镇的自己家里，你还可以劝我回老家吗？

现在，京沪的新房供应量，主要是以动迁拆补为主，而不像是惠州惠州那样，批一块空地建新房。旧改的意思是，老居民改善居住，置换地方，而不是引进新人口。目前看，京沪的外地 985 还有少量老破小上车机会，但这些老破小也越来越贵了。

结论：京沪房价是人口原因。其他地方房价，更多的是货币原因。
