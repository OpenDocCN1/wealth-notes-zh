异地养老，涉及到房租和交通费。一旦成为热点地区，房租不低，物价不低，老年人很难负担。京沪老年人，绝大多数人也没有独立房产。就算有，你也很难把京沪房产房租出去几个月，抵消在广西的冬季房租。夏天，广西有点热，想待不住。

四：当地人也不感兴趣

老年人消费不大的，很难拉动多数就业。想维护工保姆的本地人，县城省城镇有的是机会。与此同时，大多数老年人，不太讲究卫生习愤。当地人一出门，就看到一大群白发苍苍，衣销有点旧的老年人满大街溜达，我并不觉得是件多么开心的事情。相反，各种特殊车辆满大街跑，心情也不高明。

海南，目前接待的主要是，比较富裕低龄有活力的老年人和一些带娃妇女。七八十岁的老年人，街上看不见几个。

# 农村适合养老吗？不

好多人说什么，农村空气清新，绿色蔬果，这完全是擦谎。你去看看，农村的老头老太，有几个身体比城市老人好的？一天到晚打化疗，打农药，那些残留都在空气里，泥土里，水里。

大道理不讲 了，老年人最大的需求，不是什么不打农药的蔬菜，而是医院近。你要是 在农村，县医院的抢救水平完全是砸运气了，如果那天医生不在，你儿子就爽大了，一下子节约了几十万。

# 深圳，有非常好的前景

但也不是万事无忧。

深圳经济发展，经历了两次偷跑一路的发展阶段。

第一阶段是80年代到2008年以前，这三十年，不可否认是，有东方之珠的红利。资金，销路，管理，科技，都是隔壁邻居带来的。到了2008年美国次贷级债危机时，这个红利基本差不多 了。这个话题没法多说，打住了。

第二阶段是2009到现在，科技红利。深圳市市场化科技发展水平最高的城市，民营科技巨头云集。

以上两次机遇，多多少少有历史性机遇的原因，而不仅仅是单方面努力。但深圳的经济发展也有继续思考的方面：

一是高房价制约了年轻大学生的进入。这不是建一批  宿舍，或者多给一千元房租就可以解决的。房产是有金融属性的，科技企业和金融属往赛跑，长期看跑不赢的。深圳，有金融属性保镖的房产，不仅仅是居住。如果不能持续吸引高水平大学生进入深圳置业安家，本市发展就会受限 了。企业创业也无所谓，东戴成都武汉开个新基地就行了。

二是科技新机遇的转移。深圳的优势是科技企业。科技企业最怕的不是同行竞争，而是跨行业维段。就像智能手机彻底摧毁了电子字典和—般照相机行业。替代微信支付和手机的新科技，例如生物科技，若干年后应该会金产生，到 时候，掌握新科技的企业是不是还在深圳，真不一定了。

三是和隔壁邻居会不会形成竞争关系？假设隔壁邻居想通了，985研究生直接跨市，深圳直接变宽州了。当然，目前看不现实，但再过三十年，人六十岁的时候，可能出现新的思考。

四是和广州的定位关系。目前看，广州在科技水平发展上，不如深圳火力旺，高薪酬位方面 不可。但是，广州也有优势，医疗教育行政资源，远迈好 于深圳。如果深圳不能长期保持民企高薪资的压倒性优势，广州会很快超过深圳。

目前，深圳的优势是明显的，也看不到被立刻取代的可能性。但是，深圳的优势相对单一 了。
