# 美国的软肋是不敢豁出去

因为美国形成的基础是共同的经济利益，而不是共同的价值观。美国对小国家大出手，必须满足三个条件：1，代价小，2，利益大，3，保证赢。这才能在美国内部通过。中国不是这个情况。

美国对付苏联的办法，对我们无效。苏联的经济结构是，石油出口，买回轻工业产品。美国把石油价格，压低到苏联亏本。这就导致了苏联没钱支援小弟，搞垮了他的盟友。同时，苏联完全没有轻工业，居民生活物资短缺，越来越不开心，最后发生变㤵。

中国的经济结构是轻工业开路，先满足老百姓需求。即使美国对我们经济上搞大动作，但老百姓至少十年内不会受到根本性影响。

+   1. 老百姓的第一需求是住房。这个美国管不到。
2. 老百姓的生活需求，例如家电，汽车，我们基本能够自产自销。
3. 医疗教育养老，本来就是内部事务，美国也管不了。
4. 石油依赖下降。现在电动车也可以顶一顶了。
5. 中低端芯片也可以生产了，至少手机没问题。
6. 粮食，或许要想点办法。
7. 能源。煤炭资源管够。
8. 铁矿石。我们有的是铁矿石，只不过含铁量低一点，但不存在短缺问题。
9. 工业门类齐全。虽然质量不一定是最好的，至少可以顶上好几年。
10. 战略武器扩散问题不讲了。

老百姓的基本生活没问题了，那就是漫长的持久战了。我估计，美国人还没有下决心和我们玩大的。目前看，还是贸易层面。
