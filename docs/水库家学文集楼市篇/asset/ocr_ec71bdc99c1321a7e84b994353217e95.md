# 莱莱，资产 n 亿是啥感觉？

没啥感觉。人生最幸福的时间光是：买第一套小房子和第二套改购置大户型的时候。资产过亿，往往口袋里没什么钱了。因为银行贷款也多，找你房贷的多，找麻烦的也多，要想打你黑棍子的也多，烦的一比。

# 如何花小钱，解决大问题？

上海房产专业律师：在京沪，大部分涉及房产诉讼的律师费是 3-8 万，风险代理是 10%-25%，打官司成本高。现实中，很多诉讼的当事人是没有经济能力请律师的。

+   1. 诉讼金额太小，例如房租中介费纠纷。
2. 收入低，月入几千，无力承担高昂的律师费。
3. 地处偏远乡镇，没有懂这方面的专业律师，例如涉及到几十年前的产权纠纷和历史问题。也没有能力去省城找高水平的律师。
4. 中低收入家庭的诉讼，主要是分割房子，婚姻，继承，借贷，舍不得花几万元请律师。
5. 事情尚未发生，只是预防。

如果你有本科以上学历，能够正确表达和书写文件，我的建议是：花点小钱，咨询专业律师后，自己操作：

+   1. 本次纠纷的关键争议点。
2. 取证的途径和方法。
3. 大致的判决结果（谈判调解的底线）。
4. 诉讼流程。
5. 需要注意的方面。
6. 法律文书的模板在哪里找。
7. 如果你愿意再花几千元，可以请律师给你草拟一份非常详细的代理词或者答辩稿。

经过这种一对一的有针对性的培训和法笔记，至少你对于这场诉讼是心中有数，不慌不忙了。当然，这肯定不如直接请专业律师方便和高效，但绝对比让你一无所知强得多。
