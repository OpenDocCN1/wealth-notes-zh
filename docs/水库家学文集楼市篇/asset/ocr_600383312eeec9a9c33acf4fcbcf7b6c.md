# 回顾上海 325 政策

努力确保大城市房价平稳。

2016 年，325 政策把原来的购房资格，从社保两年加码到五年。对三批人产生了重大影响。

+   一是当时就不满两年的人，例如 2014 届之届毕业生。这批人，会在 2019 年 8 月份后，陆续出关。

+   二是当时已经社保满两年，但不满五年的人。这批人一夜之间，失去了购房资格，当时市场影响是很大的。这批人在 2019 年初就出关了，基本有购房资格了。
