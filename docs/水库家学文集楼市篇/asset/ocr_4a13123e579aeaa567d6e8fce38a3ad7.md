# 上海改革开放的进动，是区域拉动

回顾上海改革开放的进程，我发现上海的经济发展模式，不是产业导向，而是区域拉动。

1993 年至今，浦东开发是上海经济腾飞的最大动力，老浦东 560 平方公里，新浦东 1200 多平方公里，体最超级大，各行各业，都在发展，最后带动土地增值，皆大欢喜。

但是，你说浦东有什么明星的支柱产业，我是要看答不出来。

+   1. 金融，期货中心和证券中心，和浦东也没啥关系，只不过修了个大楼办公而已，浦东本地围绕这两个中心单位，也没发展出什么全国知名的企业，大智慧软件呵呵。

+   2. 航运，确实比较明显，但这是解放前就有的地理优势，本质上不是浦东开发创造的，造船业已经搬到长兴岛了。

+   3. 文化，没看出来。

+   4. 制造业，通用汽车和大飞机是代表，客护在浦东，但其他区也有大龙头企业，很正常。

+   5. 高科技，展讯芯片，张江软件，华为分公司，中芯，算不错，但华为要搬到青浦区了，展讯的发展也一般了，张江软件别以前有个盛大，现在也就那样了，中小软件企业倒是很积极，但比起 bat，那是忽略不计了。

+   6. 医疗教育，中等水平吧。

结论：如果我们认可区域拉动这个思路，那么下一阶段区域发展的重点，就是我们关注的热土了，我强烈看好大虹桥。
