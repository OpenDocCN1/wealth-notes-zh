# 同样五万美元年薪，

相当于月入 2 万多 RMB（税后）。外面好，还是京沪好？

肯定是京沪好。我在外面生活过很长时间。除了房子漂亮，其他生活方面的，你什么都难受。天一冷，你就很痛苦了。只能是看看中文网站，骂骂这个大 V，吼吼那个网红，然后气急败坏的去睡觉了。年复一年，没有任何改变。

现在，也有一些中餐馆了，但是很远，不方便，一般是开去车。你最多也就是周末去一下，贵的很。我们那时候没有中餐馆，全部越南菜，凑合一下了，反正看上去像个青椒土豆丝就行了。

你对社区的一切事物，公共事务，完全不感兴趣。本市民员候选人，单位竟跑来演讲，我着都不看，和我没有一毛线关系。我只关心麦德龙什么时候打折，老板会不会开除我？这里的一切，和我无关。我就是来打工的。

外面的空气是真的好。但也有代价，生活不便利。商业设施都在几公里以外，居民区连个小超市也没有。一般情况下，你要在家自建一个小仓库，买足一个月的啤酒和半年的卫生纸等。

一开始，认识几个新朋友，互相串串门，好像很幸福。但这只不过互相好；半年后，就剩下你一个人了。

事业发展，基本不可能的。人家招聘你，是有特殊岗位需求的，不是让你来参加升职的。你这个岗位能够熬到退休，就是中大奖了，别想太多了。

劈劈喝矫头的事情，几乎没有。因为你的生活太简单了，中国人圈子太小了。稍有异动，马上我就找到人了。
