# 怎么在沪逆袭？

我认识的一对白克夫妻，是如何在沪逆袭的？

他们现在还住在内环线的老居民区的工具房里。冬天很冷的那种临时房。他是小区的物业维修员，没啥文化，泥瓦匠，水管，电工，都可以搭漏。他的主要收入是老破小的新装修。因为小区里都是熟人，生意火爆。现在的老破小一手手都要装修，他就找了几个老乡，专门干这个。我就找他的。

老破小的装修，一般分为自住和出租用途。出租用途的装修，一般是包工包料，表面新就可以 了。他在小区上班，经常捡到人家装修扔掉的破木头和废旧材料；堆在工具房。今后他给人家装修，这些材料都是可以搭候的。例如，自己业余时间拼出个木门，刷个清漆就是一扇门几百元，很来钱的。 而且，客户还喜欢这种木头；没有甲醛，装修好了，立即出租。

他们老夫妻，要轻了一辈子，在内环线的小区摆下来三套老破小，一装修，内部就很漂亮。一 套给儿子住，两套出租。儿子娶媳妇真的是随便挑了。最后，他儿子娶了一个外地回沪的小姑娘， 长相还可以，但娘家穷，有上海户口。现在，这对白克的孙子，已经是上海户口三套套房的小太阳 了。

你说他干了什么？也就是吃苦换钱。现在，他回到老家，已经是十里八乡的名人了，内环线三 套房于，呵呵。
