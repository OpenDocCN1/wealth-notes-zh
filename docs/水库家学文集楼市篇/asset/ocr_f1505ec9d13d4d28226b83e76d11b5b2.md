# 关于财政部减税经费措施的建议

坚决不要搞“符合什么条件，享受什么减免”的审批性减免。审批性减免，往往导致一些企业会计把握不准，理解偏差，操作错误，中小微企业过段时间又成为有关部门多次罚款的对象，吃闷亏。

请求：直接降低税率，或者某些小项目税减免 1~2 年，简单易行。

# 上面的好政策到了最底下

为什么有时感受不明显？

好政策分两种。一刀切的，例如取消农业税，普天同庆。但更多的是：符合什么条件，享受什么好处，这就我的天了嘛！你符合不符合？可不是你说了的算的，科长说了算。为了证明自己符合，可能成本就大的离谱了，还要投入巨大时间精力。
