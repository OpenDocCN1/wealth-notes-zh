# 我对物价的担忧

我所在小区有很多保姆。我今天突发奇想做了一个统计，保姆子女的学历和工作情况。因为保姆之间都是认识多年，相根知底，这个统计超级精确。结论：

一、学历

普遍情况是，女的是大专为主，中专为辅，男的是二本三本为主，大专高职为辅。没有985211，也基本没有初中辍学。保姆见过世面，坚决鼓励孩子读书。

二、工作

+   1. 没人愿意做建筑施工和工厂车间，虽然他们的大专本科专业就是工民建和工科，但在就业时全部放弃了辛苦岗位。

+   2. 收入少的，主要是在办公室，销售助理，行政打杂，小厂会计。

+   3. 收入可能多的，主要是出租车，民宿，导游，淘宝成功者，开小店。

+   4. 少数进入体制内，农村教师。大多教在体制外，混省粮了。

三、原因

保姆阶层是打工族里的最高收入，干净卫生，吃睡都好。他们的子女大多数读到了大学。但由于无父母陪伴，成绩特别好的没有。省城县城的房子手子，全部都买了，而且是漂亮小区。她们买的早，全部赚了一百万以上，管不起体力活了。

四、今后物价可能会面临上涨压力

很多农民工子女不愿意做体力活了，倒不是钱少的原因。现在体力活钱多的，主要是吃不起苦。一是住房条件不愿意降低。出去打工，一般是工厂宿舍。现在很多农民工二代，从小娇生惯养，住的是省城或县城的漂亮小区带电梯，绝不可能去吃苦了，就算将来降低也去不去。最喜欢吹饭生意。

二是农村年轻女性，普遍好吃懒做，互相攀比。现在的农村小姑娘就业，大多数愿意美容店，房产中介，服装店，小公司，看上去干净漂亮的地方，连保姆都不愿意去了。更不要说什么电子厂流水线了。

三是婚介都很钱，很报媒国。快逸男，月入一万，不如在公司随意混月入四千的大专生。大多数农村妹，要求农村房，有身高，有学历，有房子，特别是将来有发展。她们普遍认为，在公司上班比送快递优秀，至少还有个梦。

结论，愿意去建筑公司和工厂车间的人，已经越来越少。只要这个地方拆迁了，很多年轻人都彻底废了。拆迁就买个比亚迪，就是新新人笑了。今后的城市物价，面临压力。
