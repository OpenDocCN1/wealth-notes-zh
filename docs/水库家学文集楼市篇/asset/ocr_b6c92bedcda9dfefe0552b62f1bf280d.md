# 商业地产越来越差了？

是因为互联网。

商业地产分为两大类，商铺和办公楼。

商铺已经是大街了，互联网一键搞定。除了人对人的服务业，理发餐饮小超市，其他不是交付消费的交易，都可以通过快递解决。所以，商铺的意义基本消失了，以后改为快递站就行了。
