# 我最担心的问题

作为财政学家，我最担心的是，房产税的宏观考虑，要避免京沪抽干了全国的水。

一是按面积征税，南京以西的各个省会别墅和大平层还不如京沪的一个老破小。如果跨区套利，各地多余的资金会集中涌入京沪。

二是按价值收税，事实上很多家庭交不起。挤门证吗？呵呵！

# 假如京沪 1%来征收房产税

房产税，美国最低是 1%每年，也有 2-3%的，但不多。假设京沪 1%来征收，

一是单套免税。那就会抢购豪宅了。富裕家庭把手里的多套普通房子抛售，拼成一套。但是，京沪的实际情况是内环线漂亮公寓不多，也就是 3 万套左右，到时候内环线的房价就疯了。我是欢迎的。

二是每套征收。现在闸滩一套五百万是起步价，一年要交税五万。实际上很多家庭是无能力承受的，例如老人，老病，肾病，残疾，还债中。不交税的，判刑还是上黑名单？

三是税率降低，例如 0.3%，一千万房子，每年交 3 万，这对房价有多少遏制作用？

四是税负转嫁，如果高税率，房租肯定是飙升的，除非京沪的房子租不出去。

五是有条件申请减免，这利益实在太大了，到时候黄牛可以重新就业了！

# 征收 1.5%的房产税，可能吗？

上海一套房，正常的大概是六百万，一年交九万房产税，我估计很多人交不起。如果退休老同志有三套房子，一年要交几十万的房产税，那你还不如直接没收算了。

# 【房产税的征管模式】

如果是每年都交，那不交的人，你怎么办？反正就这一套房，我交不起，你看着办了。

如果是平时不管，到卖房的时候，一起交，那绝对是转嫁给下家了。这样的房产税，起不到抑制作用，只不过是增加财政收入而已。外来户倒春，想买房，嘿嘿，先把老业主的欠税付了。

一听说加税了，屌丝直接高潮了！
