# 福利分房最常见的两种

既然大家对福利分房这么感兴趣，我就来扯几句老黄历。

福利分房实际上有很多种类，常见的有两种：

+   一是市区单位，人数较少，级别较高的单位，分房子。  
二是郊区万人大型企业分房子。

市区尊贵小单位分房子，由于历史原因，房源是散的，东西南北都有，好的差的，乱七八糟。这个排名就非常重要了。因为第三名和第四名的房子，按照现在的价值，差两百万都是保守的。这里面的事情，真的是无可谓精的巧妙了。大家都懂。

现在说说郊区万人厂的分房子，一般是按照级别分区的。

+   一居室（结婚十年以内的），二居室（科级＋长工龄的普工），  
三居室（部门领导），四居室（总部正副职）。

这种分配办法在规划的时候刻意形成了，主要是尽可能隔开普工和领导在晚饭后进寝的时候经常性遇到。这就人为的形成区了；苦逼区，小康区，高级区，牛逼闪闪区。可想而知，配套服务有什么区别了。这个大家都懂。

这种隔商居住的模式，带来了一个深远的影响，就是下一代孩子之间的身份差别。大企孩子，都是读子弟校。老师只要一看地址，就知道孩子的背景。小学到高中，十二年，绝大部分的管工子弟是很压抑的。因为他们是屈低身份。而牛逼闪闪区的孩子们，虽然迫不得已和你们同班，但是，基本是碾压你的状态。

现在，虽然也有这种事情，但是毕竟还可以巧妙掩饰一下，对孩子的心里打击少一点。

# 福利分房其实不是准确概念

正确说法是，解决职工住房困难。这意味着，你首先要困难，才能分房子。困难的标准大致是（回忆中），市区人均 15 平米，郊区 20 平米以下。

你若是单身女，高井女，直接去四人间的集体宿舍。年纪大的往下铺，年纪小的啊上铺。如果是离异女方带孩子，一般女方留给女方。但是，你肯定是无法改善，因为一个小房子，你人均都超过 15 平米了。除非你妈升到了比较高级的职位，人均面积改善了，大致能够分个 56 平米，也就到头了。

这就倒霉女性必须早早结婚，否则，你就在集体宿舍混到老。

福利分房的结果是，谁买房子，谁就不困难了，就不能分房子了。所以，商品房是没有生存空间了。于是，你就想辞职来上海打工，也办说法，因为上海没有什么房子卖给你，偶尔有些外销房，你也买不起。大家住房都紧张，也没有房子出租。

男女离婚，在福利分房时期，简直是酷刑。福利分房是，每个家庭只能合计为一套，离婚后，房子归谁？往往是有两个可能性。

+   一是市区情况。本来就是男方房产，女方净身出户。这就倒霉女方在离婚前，必须噶好头，否则就要回娘家喝妹妹打翻了。
