# 说个外行话

现在有那么多企业去美国上市，除了几个独角兽，我真的无法想象，美国会有谁愿意买这些遥远地方的陌生股票。

你要说服美国人买这种股票，首先你要保证，你派发的分红要比一般投资品高，否则人家不了解你，怎么敢买？

但是，从你的角度看，如果每年真的派这么高的利息，相当于贷款还息了，那么上市融资的意义就不存在了。

于是，很多人愿意回来了。

# 稀土和石油的区别

石油是有没有的问题。如果石油不够，一个地区的物流交通就算瘫痪了。另外石油工业品，包括衣服面料和塑料制品等，可能都会有点麻烦。电动车可以解决一部分运旅客运，必须使用柴油车的货运就难办了。石油很难储备，因为没有这么大的容器，现在一般是找个大山灌满一部分，也就是几个月的储备。页岩油技术还不成熟，能够缓解痛点，但不能解决问题。

稀土是贵不贵的问题。稀土在全世界都有分布，只不过开采成本和环境成本太高，不如去其他地方买。要是买不到，自己干，也就是贵而已。稀土储备很容易，这玩意不占地，成品无污染，各地储备也是比较多的。就算断供了，一时半会，作用是有限的。

石油是工业血液，稀土是工业味精。真发生特别严重情况，大的经济体，还是可以承受稀土成本的。当然，无论如何吵架，石油肯定不会断供。因为这个等于是绑架不了了。被断供的地区只有两个出路，要么退回中世纪，要么拼命一搏。没有哪个富人希望隔壁村的老王天天怒和他拼命干一架的。
