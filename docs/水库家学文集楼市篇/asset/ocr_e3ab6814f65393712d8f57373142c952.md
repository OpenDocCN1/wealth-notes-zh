# 如果房贷彻底取消

全款买房，会出现什么情况？

一，二手房市场

京沪绝大部分家庭最多是两套奢。拆迁户大部分也就是 3-4 套小户型，父母和子女各两套。

市场没有贷款支持，二手房肯定滞销。购房族没钱了，房东就会降价出售吗？基本不可能。房子可以留给子女，按照现在的京沪平均寿命，80% 的人是可以看到孙子结婚的。所以，一个家庭两三套房子是必须的。

一方钱不够，一方不想卖，交易就基本停止了。只有生意破产，法院拍卖的房子，可能会低价出售，但这个数量是很小的，远远不可能满足市场的正常需求。二手房市场基本停滞。

二，新房

开发商的利润在 10~15% 左右。开发商作为商业企业，承担了较大的风险，付出了劳动，投资必须要有回报的。

银行贷款利率 7-8%；按照两年的开发周期，至少是 15%，如果涉及民间借贷，那就更高了。

土地款大概是 30%。

硬成本，材料，人工，公用设施设备费，大致是 30%。

税费约毛估 10%。

哪一块成本是可以降下来的？

如果购房族没有足够的资金，企业成本又降不下来，第一批的开发商因为各种原因被迫亏本销售，但就是后来的新房了。

如果楼市熄火，财政，就业，上下游企业，都会遇到麻烦，至少空调厂的董事长就当场哭丧亡了。
