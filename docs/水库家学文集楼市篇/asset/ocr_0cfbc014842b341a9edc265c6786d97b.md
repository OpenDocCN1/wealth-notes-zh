# **我们每个人都应该感谢房地产行业**

你们二十年前住的是什么地方啊？老鼠蟑螂蚂蚁，家里有没有？不要假清高啊，说的就是你。

就说上海内环线，北京车公庄，一出门，到处是灰尘，一起风，灰尘漫天，一下雨，到处是污泥杂草。每家每户的厨房都是又黑又臭。中关村的批发市场，像是河南县城的老式百货商店。

短短二十年，翻天覆地。我们现在去欧美日漫游旅游，发自内心的自豪啊！为什么？中国太漂亮了！这是房地产行业的建设者们为国家为群众创造的。他们有理由受到尊敬。

有的人说，应该感谢建筑师。我不是很感谢他们。建筑师也是拿工钱的，建筑队也是拿工钱的，包工头也是赚钱的。这些技术并不是什么高精尖；美国在五十年代就完成了基本建设。南京长江大桥在五十年代也建的那漂亮。真正值得研究的，是房地产行业解决了资金来源问题。有了建设资金，才有柏油马路，漂亮的高级公园。

# **香港为什么房价会暴跌？**

而 xx 等城市，绝对不会出现类似情况，甚至不会降。（我没说错，别找茬）

二，香港是联系汇率制度。m2 不是自主的，市场上有多少港币，是大致固定的。如果楼市的资金需求超过货币供应量，直接到了。我们是自主汇率，m2 是自己说了算的货币。你懂？

三，投资渠道单一。市场经济，总有一些富官富商。你家贩爷今年生意好，多赚了三百万，你不能拿出去，只能在境内投资。香港人可以去欧美买房开公司，资金随便进出。

四，香港土地制度。香港拆迁少，不可能人为创造需求，我们稍改一下，农村发行发行支持一下，啥都好说了。
