# 房价是什么？

+   1，房价和成本，没有一毛钱关系。就算是单位免费给你的房子，你也会卖五百万，少一分钱都不行！

+   2，房价和供求关系也没关系。就算是不让买了，大家还是不肯走，眼巴巴的守着，像个贞洁烈妇。

+   3，房价和货币也没关系。m2还在扩张，环京已经绝掉了，动都不动一下。

+   4，房价和人口也没关系。房价的波动幅度远远大于人口的进出。

+   5，房价和供给也没关系。京沪无论供地多少，反正你买不起。

+   6，房价和调控也没关系。调控了这么多年，已经成为连续剧了。

房价实际上是一种对未来的预期。

# 福利分房的苦楚

我是那个年代过来的，福利分房有多内幕，真是不堪回首。

+   一，单位有多少房子，普通人根本不知道。不要以为分房子都是公开的，很多事情，只不过你不知道而已。

+   二，一套房价值五百万，少说点也要两百万。很多人卡卡在了可上可下的档口，还能怎么办呢？大家都懵。

+   三，房子福利分配，完全是按级别排队。那么，你的一切就掌握在领导手里了，你真的喜欢一辈子围绕单位副总，使劲巴结的那种生活？

+   四，同级别的，看工龄或获奖等因素。这里面大有奥妙。分房子之前，都会排出一个表格。同样是副科级，A 老是五年工龄，B 女是三年工龄+论文二等奖。领导想给 A 看，就把工龄分值拉高。领导想给 B 女，就说鼓励科研，把论文分值拉高。你没地方哭的。

+   五，普通工程师分房子，排队三十年也不一定保证。
