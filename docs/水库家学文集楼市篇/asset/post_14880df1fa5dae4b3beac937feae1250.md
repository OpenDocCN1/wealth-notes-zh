
# 身边两个姑娘的不同人生

近20年来，人世间所有的悲欢离合，阶层流动，咸鱼翻身，土豪没落，好牌打成烂牌，公主落入凡间。背后99%的因素是房子。（房价不炒，最好暴跌）

## 一、温州姑娘的逆袭

二十年前，她家非常穷，父亲是渔民，在她童年时候，随母亲卖光家财跑路了，母亲独自抚养孩子，流落上海街头，以前靠倒卖火车票为生。所有的温州亲戚都看不起她家人。女儿历经坎坷，在外地货殖大学毕业后回沪做外贸业务员，逐步熬到了年薪14万。因为没有娘家的资产，嫁了个年龄相仿的上海无房男，婚后有了儿子，一直租房自在公司附近。男方碌碌无为。

2011年，上海男继承了祖辈遗产，一套房的35%，折合60万现金。姑娘坚决要求买房，上海婆家担心女方不懂行，不同意买房，只想存银行。姑娘提出自己不记名字+还贷，上海婆家遂同意买了个郊区一百平米。姑娘负责还贷。

2015年暴涨前夕，卖掉郊房，贷款七成，买了个杨浦区小三居。这次婆家同意加名字了。买入后，上海房价翻倍，现在价值近千万，成为全家功臣。

与此同时，温州亲戚因为福州暴跌爆雷，几乎全军覆没。她逆袭成为家族里最优秀的年轻一代，为父母赚了面子。老父亲在外面的欠债，也还掉了，老父亲也回归家庭。现在一家人幸福地生活在内环线上。

## 二、公主坠落凡间

女生非常漂亮，性格温和，父母是高级知识分子家庭，她从小到大，都是医生上门服务，连医院挂号都不会的那种人。女生留学美国毕业后，找了个知根知底的帅哥，婚后他们去上海发展。于是两个人凭借漂亮的外形、漂亮的外貌、漂亮的家庭背景，进了最好的外企。女方拿到上海户口了，但工资不高，月薪两万。婚后女方辞职去美国生了儿子，拿了绿卡。

2013年准备买房的时候，男方家里投资了一个准备上市的公司，暂时没大钱。两家凑钱只能全款买百万的漂亮小区，但买不起豪宅。他们看中的是当时九百万（现在两千万以上）的豪宅区。那年，楼市一片唱衰，他们也不信，就砸下来了。

老太爷退休后，居然打官司离婚。母亲离婚后，三百万私房钱给了女儿。老太爷退休后找个开贸易公司的小姑姑娘结合，没钱管女儿买房了，只是给了几十万零花钱。再后来，婆婆投资失败，血本无归。婚后，他们住在一套租赁豪宅里，女方带娃，男方上班，每年净赚额提20万。由于房价暴涨了一倍多，差了1200万，小夫妻实在是无法接受住老破小，继续租赁豪宅，但前路暗淡了。现在，他们已经是京沪非常普通的小家庭了。

## 说个身边事

某大叔是中原大省的省城市区人，专门在贫困山区帮助农民搞养殖技术，顺带推销农资，长年在县乡恶劣条件下工作。到了2014年初退休，他领了220万存款，感觉自己是人生大赢家，即将开启美丽幸福的退休生活。

大叔性格好强，吃苦耐劳，但是这种人往往思维固执，落后于时代变化。当时，我们劝他220万足够在近郊买个豪宅或者别墅，传给女儿。他却听信了报纸上的什么鬼样报道，不愿意买房。这两年，大叔连续遭了暴击，无缘无故的，家里掏空了。

- 1. 错过房价。大叔一辈子干技术，不相信房价会涨，最后被楼市硬生生成了逆流。有人会补偿他吗？不可能的。
- 2. 误信互金。大叔有个独生女儿，从小到大是掌上明珠，非常疼爱。前两年女儿女婿劝他投资了120万本钱，参与p2p股权融资，结果他和女婿被人骗了，血本无归。这些存款来的太难赚了，一下子损失了，大叔气急败坏，经常性抱怨女儿女婿，而且说话难听，搞得父女基本不来往了。

大叔觉得人生悲催，还剩下100万。年前在海阳买了个漂亮小户型，准备养老，刚交了定金没网签，没几天，售楼处通知，全员隔离，退钱。大叔拿着钱到处看房子，本市暴涨的凶呀，买不起了，急得在家直打转。女儿女婿又来找他借钱80万翻本，大叔正在火头上，直接拒绝，女儿在家气得哇哇大哭。父女彻底翻脸。

最后100万，分为两份：15万买了某贫困山区的豆腐渣小户产权房，25万买了北海滩乡络台部落的高层小户型（只能说一张床那么大），两个儿子娶媳妇各10多万，剩余不到50万，作为一年四季来来回回的机票车钱，基本不会剩下什么遗产了。当年错过的省会房产，现在至少550万。一副好牌打成这样，女儿和他也不得来往了。他现在已经没钱了，大家都彻底伤心了。

当今社会，是个变化剧烈的经济大时代。建议：

- 1. 做人，不仅要能够吃苦耐劳，拼命换钱，更要善于认识风险，稳健投资。
- 2. 做事，无论你做什么行业，学一点基本的经济学知识是需要的。
- 3. 思维，不要太固执了。时代变化太快了，兼听则明，绝爱为主。

# 楼市见底的标准

住宅土地卖不出去了，陷入僵局。

大中型开发商一般都会养几个人，专门研究地价。即按照现在的行情，什么价格拿地是有商业利润的。他们算得非常准。如果某市土地多次流拍，说明房价偏低，地价偏高，开发商没办法做了。怎么办呢？

- 一，财政割肉，大幅度降低地价，满足团贷户的合理买房需求。
- 二，房价上扬，给开发商留出成本和利润空间。
- 三，不卖地了，没有新房供应，爱咋地吧。
- 四，大量建设廉租房、共享房，财政出钱补贴，今后再倒贴物业费。廉租房的素质，苍天可鉴，哈哈就不说了。

# 如果房贷彻底取消

全款买房，会出现什么情况？

一，二手房市场

京沪绝大部分家庭最多是两套宅。拆迁户大部分也就是3-4套小户型，父母和子女各两套。

市场没有贷款支持，二手房肯定滞销。购房族没钱了，房东就会降价出售吗？基本不可能。房子可以留给子女，按照现在的京沪平均寿命，80%的人是可以看到孙子结婚的。所以，一个家庭两三套房子是必须的。

一方钱不够，一方不想卖，交易就基本停止了。只有生意破产，法院拍卖的房子，可能会低价出售，但这个数量是很小的，远远不可能满足市场的正常需求。二手房市场基本停滞。

二，新房

开发商的利润在10~15%左右。开发商作为商业企业，承担了较大的风险，付出了劳动，投资必须要有回报的。

银行贷款利率7-8%；按照两年的开发周期，至少是15%，如果涉及民间借贷，那就更高了。

土地款大概是30%。

硬成本，材料，人工，公用设施设备费，大致是30%。

税费约毛估10%。

哪一块成本是可以降下来的？

如果购房族没有足够的资金，企业成本又降不下来，第一批的开发商因为各种原因被迫亏本销售，但就是后来的新房了。

如果楼市熄火，财政，就业，上下游企业，都会遇到麻烦，至少空调厂的董事长就当场哭丧亡了。

# 京沪房价是谁炒起来的？(理论探讨)

1998年到2002年，京沪房价基本稳定，价格足够低。

炒房出现的时间应该是入世之后的2003年。上海炒房的第一波人群，就是温州炒房团。2003年入世了，温州出口飞速发展，这群人拿着开工厂、出口小商品赚来的大把钞票，在上海楼市横扫一切。

我们那时候可伶俐，工资也就二三千元，温州人一出手就是几十万的，完全不能比啊！各大售楼处门口大糯红色标语，欢迎温州炒房团。然后一群温州老娘是从长途车下来，大糯大糯进去，售楼员根本不理我们这种本地散户，我们眼巴巴的看着他们看完了，才敢敢上去问咨询售楼员，结果一脸晦气：都卖掉了，就剩这几套鸡头鸡脚了，要不要？

我记得最清楚的是证大家园，第一期开售2700元，我们当时很乎零的，认为那个盘太远了，最多也就是1500元。结果温州人冲上去，一条街全的买。当时是一栋房子，一楼到六楼，全部买下21套，叫做买一条线；如果01和02室，全部买下来，叫做买一个门洞，12套。

温州人大把大把的炒房，上海人也没办法，因为融资渠道不同，温州人喜欢民间集资，上海人哪玩敢这个啊？没钱当然不可能买房。

2009年出现两个大事请，新生儿落户放开，随父随母都可以，盲流收容取消了。于是，大批的外地人进沪就业。两个外地人，只要一个通过人才引进办了上海户口，子女就是上海人，于是大批量的外地人子女取得了上海户口，他们就定居了。

2005年，温州人玩了一通后，外地大学生又来玩一通。那时候，扩招的不良反应已经出现了，各地小县城根本不需要这么多大学生，于是大城市放开就业。上海各大单位开始招聘外地人，上海各种专门国企也大批招聘外地人进来，大部分不给户口，也不算正式编制，工资差别不大，各种民企也开始大规模招聘外人。这些大学生的数量是十万二十万这个模摸来的，几年下来，上海集聚了几十万外地大学生，他们成家立业，拼命买房。现在在沪外地人是八百万。

2006年以前，大城市房子不贵的原因是，土地随便卖，各个乡镇都可以招商引资，自己卖地盘楼。2007年后，土地市场招拍卖，导致了房价上升。外地大学生一下子加了几十万套需求，拆迁户也越来越多，于是住房需求大爆炸了，房价呼呼的往上跑，温州人和外地大学生生意赚满锅响。

2007年以前，上海本地人没有买房意识，一般是子女结婚了，双方单位固定了，找个中间地区，双方都方便上班的小区买房。上海一般是进婚是职员，人很老实的，真没什么炒房意识，一般不会提前买房。但是，外地人毫无无意的把房价哄起来之后，本地人怕了，也开始提前买房了。

2008年，金融危机，房价下滑。

2009年，四万亿，后面省略。

# 说说 2003 年以前的房价为什么那么低？

大学扩招是1998年后大规模开始的，当时为了拉动内需，对准了住房医疗教育下手。2002年以前的大学住校，基本都是干军马号独种转过来的。考上985的，一般是重点前5-10名的水平。那时候复旦全国招生800名，清华也差不多。

本科毕业后，一般进单位，月入两千左右，我第一个月转正工资是750元左右。外地人不能在本地找正式工作，临时工是可以的，例如材材市场送货。但是，你要办暂住证，如果无证，直接送进去挖沙子（参考北京当年做法）。

当时富沪的985本科生，极少考研，都是回原籍人事局报到，然后层层分配下基层。我的一个同学，被分到了周雄镇里的某个所，他们毕业后，工资大概五百元左右，大部分时候上班也没什么事情。他们只有五个人，没有食堂，每天派一个人出去买菜，中午烧烧当年，自此做饭。冬天实在太冷了，中午来一瓶五块钱的白面，几个人吃的二两三两的。这就是富沪985的真正情况。

富沪当时买房，主要是本地人，外地人也可以买，但实际上，因为外地人没有正规工作，也买不起的。盖印户口吸引了很多上海知青回嘉，给予买过户籍迁话，2003年，北京办公庄那里开了一个新盘，我当时在北京某部委工作，我记得很清楚，6700元。靠近海淀区农村的城乡结合部，类的太贵了。我们一致悉尼。

当年，外地人和京沪居民，基本不离婚的，不存在外地人结婚必须买房的问题：因为当时的政策是，子女户籍随母亲。外国人在京沪没有正规就业，京沪姑娘也不可能嫁给们。京沪男性也不敢娶外地美女，否则，孩子就要去外地读书了，当年交通不便，这个是很可怕的事情。

总结：当年的京沪，没有外地人，工资极低，人口不能流动，不能异地正规就业。没有外地人抢房子，大家都在单位附近买房，也没有投资需求，所以房价基本稳定，在合理范围内。大学生买房完全无压力。

# 为什么房价的稳定性远远好于股价？

人的内心有两个负面因素：贪婪，懒惰。当获利超过50%的时候，绝大多数人就开始脑子活泛了，想套现了。

但是，卖房子可累了。大城市房子，不是自住就是出租，里面有人。卖房前，要赶人，或者和租客反复协调，斗智斗勇。或者自己来收房，买新房卖装修，事情多的一比。很多人想了两天，索性上来，又开始贪婪：喝，说不定还会上扬一点，先缓缓。这就避免了抛盘的集体踩踏。

卖股票简单简单。坐在地铁里，手机点一下，三秒钟就卖掉了，很多人实在是忍不住啊！

# 中国最大的内需就是房子

买了房子，才会买空调，地板，木门，厨卫洁具，否则你空调挂墙上啊？没有这么多发展的楼市大发展，哪有登明珠啊？楼市最大的问题是：房价涨的过快，导致贫富差距拉大。有房的人，贪婪起来，不买房的人，更多亏损。

解决房子的根本办法。

- 一，扩大供应量。现实中，各地因为用地指标不够，导致供应短缺。我建议，土地互换。安置人来上海定居，那就把安徽的用地指标带过来。现在，很多安徽人，老家有宅基地，二上二十八楼闲置，县城有房子，老头老太住，自己在松江闸浦有房子，这么多土地浪费，合理吗？
- 二，关系货币的龙头股。基础货币发行量，应该纳入预警体系，就像是财政预算报告。
- 三，缩小各地民生待遇差异。经济发展的差距，受制于自然条件，一时三时搞不定。但是医疗教育可以尽快解决的。河南东北安徽，大学升学率和京沪平齐，就不会有那么多人往京沪挤了。
- 四，绝不与民争利，切实减轻群众负担。豪宅可以多收税，普通住房是生活必需品，应该轻税薄赋，首套免税。
- 五，房价的变化因素，不在楼市本身，而是社会综合因素。就算税费翻倍，我也只能接受，难道去睡马蓉吗？

# 京沪房价的极限是多少？

（理论探讨）

- 1. 如果 M2 不变
    - 中产家庭，首套房卖掉，扣除剩余贷款，实际得款 500-600 万。
    - 夫妻收入合计 4 万，这个算偏高了些。如果留出生活费，子女教育医疗费，最多拿出 2.5 万还债，也就是贷款 500 万。
    - 结论：京沪极限总价在 1000 万。
- 2. 如果 M2 每年增速是 8-12%
    - 新增货币不是平均分配的，高收入人群的收入增长一般高于 M2 增速，大致在 10-15%，那么房价每年增加 10%，也就是每年 100 万，应该是顶天了。
- 3. 研究极限总价的意义
    - 很多人会说，这是大部分中产的极限，少部分富人完全可以买两三千万的房子。虽然这个道理，但是富人炒的再高，没有接盘侠了，这个价格就是无本之木。
    - 外地客人来京沪购房，现在越来越困难了，五年社保等限制条件越来越多，很难出现群体买盘。
- 4. 在大城市大单位上班的父母已经全面超越小老板的经济地位
    - 省城家庭的子女到京沪定居，小老板往往拿不出 300-500 万现金支持孩子，而省城以前在体制内分过房的，倒是轻轻松松了，卖掉一套就有了。
- 5. 房价停涨吗？
    - 停涨是一种办法。还有一种办法是，做高单价的小户型，例如香港 90 平米，就是豪宅了。
- 6. M2 这样下去，普通人会如何？
    - 普通家庭会越来越富裕。人民币多了，汇率基本不变，中西部地区的一般家庭超过美国普通家庭，指日可待，厉害了我的国！
    - 齐心协力，万众一心，为中国经济加油！

# 房价稳定是金融稳定的重要基石

- 金融的主要表现形式还是借贷，其他各类花里胡哨的投资品种，毕竟是小众产品。既然是借贷，那肯定要涉及到风险。如果债务人还不钱怎么办？理论上说有几个办法：
    1. 抵押。
    2. 夫妻全签字担保。
    3. 违约会造成的其他成本。例如，个人破产上交一切财产，上了法院黑名单，名下不再有任何的资产，社会面誉度下降，个人不能考公务员等。

结合中国的实际来看，我们没有破产制度，老赖上了黑名单也不在乎，已经还不出现了，也不可能再去做生意了。个人破产虽然没了，但是房子还可以住，法院也不能把你赶到马路上去。如果有成年子女，那把隐匿的债转移到子女的账户上，以后刷他的卡，用他的微信支付，生活不存在任何问题。

银行对于放贷风险，其实心里是很害怕的，所以银行必须抓住一样非常牢靠的东西，充足抵押。其他都可能是骗人的，只有这个东西实实在在的，那么我们研究一下抵押物品的种类。理论上，东西都可以抵押，实际上，银行接受的抵押品种极为有限，我们逐一分析。

1. 房产土地抵押，最好。
2. A股股权。这个和普通人没什么关系，主要是一些上市公司老板长老。普通人手里有A股，直接卖掉就行了，不需要绕一圈套去抵押。上市公司老板一方面为了控制这个企业，一方面又要募集资金，所以他把股份作为一个质押，工商局备案。
3. 金银珠宝玉器字画。银行一般不具备保管能力，鉴定能力，不会接收你的，除非特别情况。
4. 汽车，一般10年报废，二手车不挣钱，不具备什么抵押价值，可能你借个5万块钱，银行看一眼你的实力而已。
5. 飞机轮船，一般人也不会有这个东西。
6. 知识产权，包括商标专利，除了茅台五粮液，其他基本和废纸差不多，就算这个商标专利现在很有名气，等企业已经要到了欠债不还，基本破产的时候，你那个商标也毫无意义了。
7. 其他

说了一大堆，我们就发觉，在整个金融系统里，只有房子土地是最好的抵押品。事实上，我们的绝大无数贷款，就是围绕土地住房开发开展的，这是金融的基石。

假如房价暴跌一半会出现什么情况？

1. 银行，就必须立刻收回一半以上的贷款。否则，银行就处于巨大的风险之中了。因为债务人已经没有兴趣还债了，暴跌一半的房子你拿走，大不了我上黑名单，但是我几千万个亿贷款，直接踩了一半，我还在乎黑名单吗？
2. 企业，面对银行逼债，也不可能还债的，因为企业贷款说明确给钱，你突然抽回一半的贷款，那直接就停产了，企业实际上根本没有能力给你筹集一半的钱，立刻归还银行。
3. 个人，房贷也没有兴趣还了。假如我500万买的房子，首付150万，贷款了350万，25年利息合计180万，现在房子值280万，除了顶级品质非常非常高的人以外，其他入一般就不会还贷款，大不了把房子拿走。剩下的钱，以子女的名义再去另外买一套房，直接赚了很多钱。

也就是说，如果房价出现快速暴跌，抵押品的价值打了五折，整个金融系统就会出现无完无尽的违约了。这就是所谓系统性金融风险。

一旦走到这一步，各行各业就难以正常的进行生产了，因为大量的企业违约，银行起诉，法院查封，我不敢和你签合同，因为我不知道他明天会不会被法院查封了，那就没有人敢经营了。

4. 央行，这时候就要出手了，他必须大量的推出货币，然后借给给各行各业，维持正常的经。产，市场一下子就丢出很多很多的钱，生产经营的恢复没那么快，但是房价倒是立刻飙升上去。

千辛万苦，千方百计，把房价打下来，除了增加一大堆社会麻烦，造成巨大的金融风险，最后还是要再房价呵呵，这有什么大的意义呢？
