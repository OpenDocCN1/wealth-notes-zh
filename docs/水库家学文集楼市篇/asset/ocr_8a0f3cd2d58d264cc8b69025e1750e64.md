# 中部发展，关键是人

特别是增加中高薪岗位。

中部六省，一直是劳动力输出大省。河南山西，多去北京。安徽去长三角。江西去杭州广东，湖南去珠三角，武汉处于中间，去北京和广东都有。高端优秀人才和初级劳动力，大多数外出打工，留在本地的中高级人才，大多数是正式编制。在较长一段时间内，中部地区的经济发展，并不炫目，更像是随大流。

自从三年前的楼市 325 政策后，北上广大批资金返乡，刺激政策加油助力，中部主要城市加速繁荣，特别是楼市率先开摆。武汉的高端房价，从一两万变成了五六万。合肥房价直接是三级跳。楼市兴旺，带来了装修和家具行业的超级繁荣。与此同时，地方财政大增，基础教育，如火如荼，锦上添花，到处是一片欣欣向荣。

在充分肯定发展成果的同时，我们也要冷静分析，自我加压。中部地区这几年的繁荣，目首看，主要还是资金投入的结果。实体经济发展，并没有达到珠三角长三角的基本规模。这几年，个别明星企业来办个基地，拆个分公司，但规模有限，尚未形成珠三角长三角那样罗布布的特色产业集群。

中部发展，关键是留住人。高中低档次的劳动力不要再走了。感情留人，事业留人，特别是大力发展产业，创造中高薪岗位。目前看，已经具备了外部条件。北上广，生活成本越来越高，买房非常困难，有钱也不行。外地孩子入学难题愈发：未婚男女没有婚房，找不到象。各种压力之下，很多有生活质量要求的大学生，越来越倾向于到中部地区工作，安居乐业。

目前的主要问题是，中部地区的自身建设发展，能不能承接住这些人才的回流？

前段时间网上有个小文章，一位深圳的 IT 技术人员为孩子读书，想回武汉就业，但找了一大圈，没有合适的岗位，又去了北京。高科技公司，还是少数，更多的一般劳动力。这些人在北上广小厂打工，一个月五六千还是有的，中部地区现在也就是一三千多，差距很大。

中部发展，高中低端要同步进行。中小企业是容纳就业的主渠道，一定要给与大力扶持。只有形成了广泛的产业集群，才会稳定就业基础，吸引越来越多的中高技术人员回流。

中小企业是留自己人。就像是当年给外来的待遇，一次性给全了给中小企业，三兔五减半，一把裁掉了。不要再搞什么“你来搞个，我们 上研究一下了”了猪媒程序了。也不要再搞一个点一个点的给了，反正内在锅里。就算是便宜了自己人，担心什么呢？

抓住机会，拿出勇气，时不待我。
