# 经济学并不是发个通知那么简单

昙是这个局，那个局，对民企大力减税，依法追缴十年，确实很简单，发个通知就行了。但是，民企的存在价值是：就业和创业。如果把民企搞的很卑微，民企也不会说什么，实际上他也没地方法。现实中，民企会悄悄地收缩。债务多的民企，就维持最低开工量，防止债主堵门，职工投诉。债务少的，小老板提前退休，房子租给档次快递的。结果是，就业和创业，慢慢废掉了。

就业，乡镇街道搞点什么绿化员，保洁员，村长助理，居委会助理，还能应付一下。

外汇，那是真正的国际市场，完全凭实力。如果民企很难赚钱，或者赚了钱也是被各个局依法追缴走了，这怎么说呢？我不说了。

中国经济稳中向好，我们欢欣鼓舞。

# 明年，建筑公司成本要大幅度上升了

农民工端奖杯码农的好日子也要斟酌了。

建筑行业是劳动密集型，但这个行业对工资个税社保，似乎根本不关心。这里面有奥妙的。

+   1.  证书虚似提意。技术职称，一个证，几千或几万，建筑要＋社保。实际上，工资几乎不存在。

+   2.  员工也是虚似的。建筑公司理论上应该有很多农民工，建个大楼可不容易。在办证的时候，也确实有很多人交社保。但实际上，建筑公司拿到各种证件后，一线员工就成被裁辞退消失了。最后劳务外包给包工头。

+   3.  个税也无所谓。现在的套两万年收入的农民工，根本无所谓个税，好像都是码农的事情。建筑公司劳务外包，包工头是本村本队的，只发钱，不交个税。所以，农民工觉得，个税和自己没关系。

明年元旦开始，社保就税管了。建筑成本是肯定大胀的，横向纵向一比较，你根本无处可藏。除非故意放你一马，否则，这个大楼建筑成本三个亿，肯定可以落实到具体人。

# 中国经济，稳中向好

我和国企打过交道。国企考虑问题做生产决策，思路的民企不太一样。

第一条，领导是否满意。至于领导是否满意，不仅仅是赚钱，还有很多其他因素，甚至是人事因素。

第二条，内部是否能够协调。国企内部各部门之间都有自己的工作节奏。销售部不一定能够协调其他部门，例如生产部，财务部，人事部。如果你的工作给其他部门增加了额外负担，你做好思想准备。

第三条，思路稳重，别人挑不出毛病，尽可能不给自己上下级手指责你的机会。

第四条，严格走审批程序，程序走完了，个人就没有责任了。擅自做主是大忌。但是，各级领导工作繁忙，何时走完程序？看情况吧。
