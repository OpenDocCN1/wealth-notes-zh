# 楼市就这样默默无闻下去？

不可能的。

绝大多数地级市和一大半的省会，如果没有楼市收入，根本没有财力支撑现在的建设规模和城市发展速度。我看到一些几百万人的城市都在建设地铁和机场，简直是吃错药了。他们哪里负担得起这个成本啊？

现实是，还真就建了，怎么着吧？呵呵。钱那来的？银行借的。要不要还钱？看情况吧。有钱就还，没钱我也没办法，反正推进自己口袋。你说怎么办，就怎么办。我凭本事借的钱，你还说就不还啊？

接下来无非是两个办法。

+   一是核销，就是不还了。但这个办法后遗症太大。以后就别住车了。因为大家都会嫌你欠钱，就会拼命借钱，最后一风吹了，老实人吃亏。
二是还钱。怎么还钱呢？现在的企业，再去税费罚，估计直接黄给你看了。一般居民家庭，还在房贷，承受能力有限。影视里的明星有钱，但已经错过一耙了。农民有钱，摆个早餐摊子，一年几十万，但很难收上来。怎么办呢？也只有楼市经济了。

现在的情况是，限购，买家人数太少，接盘少。限价，开发商利润不高，积极性不大。土地款不好收。

如果做持下去，GDP就下滑了。就业就要受到影响，现在，出口已经遭到挑战了。楼市是最大的内销，再搞挂，那岂不是自己捆住了自己的手脚？

结论：楼市经济是中国总经济稳中向好的重要力量。楼市的健康发展，关系群众利益，只能做好，越来越好！
