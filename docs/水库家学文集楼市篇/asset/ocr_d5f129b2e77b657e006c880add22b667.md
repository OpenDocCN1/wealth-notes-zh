# 互联网的起步，在北京是肯定的

北京是互联网的发源地，这个是没有任何疑问的。原因也简单。

互联网的起步是新闻网站，例如 sina，搜狐，网易。内容之后是辩论，这大致是属于宣传口。地方政府没必要去做这个敏感东西。万一点了炮，也没什么好处。所以，互联网的起步，在北京是肯定的。

在中国，一切内容，都是需要审批的。而审批内容，特别是可 能涉及到敏感内容，地方政府是不愿意去碰的。阿里巴巴是卖货的，微信 QQ 是私聊，不涉及内容发布，后面发展了另说，但起步肯定是纯商业事物。

上海后来也想突破互联网，但失败了。上海是全国互联网金融的发射地。你看，绝大部分闪瞎跑路的 p2p，都和上海有关，大多数是注册在浦东。据说那个南京钱宝，总注册地好像也在上海，更不要说什么中首合伙人之类的，纯粹是本土骗子。
