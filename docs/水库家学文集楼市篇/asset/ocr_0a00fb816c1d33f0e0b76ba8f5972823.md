# ## 地方财政与房地产

@胡锦涛赞美了一个不知名的小城，城市面貌，日新月异。但是，胡锦涛不能经济，这种小地方，要工业，没什么大工业，要商业，没什么大商业，地方财政凭什么建设这么多漂亮的建筑？无非是房地产。

背后的逻辑非常清楚，当地人去发达地区打工，攒了首付，加上房贷，买了本地房子。地方财政获得了巨大的土地收益，城市面貌大发展，家电，装修，家具，得到了空前发展。这就是我们这些年来的宝贵经验。

房地产是财政收入的半壁江山，也是很多地方的支柱产业。楼市的健康发展，是地方财政的重要保障。（房住不炒）

# ## 京沪能不能像种稻子一样

密密麻麻的种满房子，这不增加供给应，降低房价了吗？

肯定不行的，每增加多少人口，就必须增加多少道路，医院，学校，水电气基站，公务员，事业编来管你。否则，城市的垃圾就没人大运了，路也走不动了。

房价不仅仅是砖头本事，而是一个综合城市运行成本。京沪一套房，八百万，每一块钱都有具体的人事走，你让谁不拿钱给你白干？你愿意在单位白干吗？不可能的。

房价不存在高低。房价只是你的存款金额在สังคม中的排名。无论房价涨跌，排名靠前的人总是买得起，你的排名靠后，再跌一半也不买不起。五年前房价是现在的一半，你家买得起？
