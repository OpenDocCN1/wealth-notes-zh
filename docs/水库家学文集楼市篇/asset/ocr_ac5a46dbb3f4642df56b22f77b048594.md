# 西欧的家庭积累

西欧现在已经进入无增长模式了。但是低保搞得好，也不担心饥饿。大批外地二二代在西欧大城市里游手好闲，可以在路边坐一天，就喝一杯极小的咖啡，喜欢监窃游客。现在那里是愿意惹干涉谁得罪，因为干活的中老年人要交各种福利费去养活这些啥也不想干的年轻人。

房住细细观察了他们的家庭经济情况，基本买不起房子。上一辈有房子，我们就过得好，没有房子就倒霉了。大单位工资基本就是月供一个小公寓，绝大多数人是租房子，买不起房子啊。很多年轻人和父母挤在一起等遗产。

我已经给孩子留好了足够的资产。孩子们以后靠自己一般是买不起婚房的。我们做家长的，能帮一点是一点。

# 生活在小县城，幸福吗？

这看怎么说了。

我在海南住过一段时间，隔壁邻居是成渝地区贫困山区的公办教师。你不要误会了，虽然是贫困山区，但公办教师的工资不比京沪低多少。上海公办教师，35岁左右，我估计年收入12万左右；贫困山区的年工资是7-8万，抓小摊贩的收入，看情况了。

他们两口子都是正式编制，表面上的年收入就有15-16万。当地是城中村地段房价八千九，买房不是什么难事儿。他们在城中村地段买了两套豪华小区房子。第一套是父母资助了一部分，第二套是他们自己买的。

买车，十几万的国产车。

旅游，他们是教师，暑假直升四川山区的避暑山庄。冬天去海南（偶尔）

网络购物，县城和京沪一样方便。

餐饮，当地餐饮的房租低，价格便宜多了。三百元，五六个人吃的满满溢油。

父母帮忙带孩子。因为房子大，父母来住，根本不是问题。

他的感受是，作为一个二本档次的师范本科生，农村出来的，感觉幸福。他问我一年收入多少钱？我说，京沪家庭，两个外企小白领，合计30-40万比较多。但房价太贵了，生活压力极大，幸福度不高。你说那些好事，我们都没有。他很高兴。
