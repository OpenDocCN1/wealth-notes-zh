有的地方规定，外地父母改嫁到本市，拖油瓶孩子（外地户口）可以在本市读书。于是，有的人就装了个假结婚，把孩子入学问题解决了。

老的征信有不严谨的地方，现在改了就不说了。

限购政策后，双方假离婚，把房产归于方，另外一方名下无房，可以再买一套。

外地人没有购房资格，找个上海户口结婚，用了对方房源，然后再离婚。

建议：有关部门及时拿出办法，遏制不良风气，维护婚姻制度的严肃性。特别是今后，在出台新规定之前，就把假离婚离婚因素考虑进去，防范于未然。

# # 没有卑微，哪有荣耀？

买房的过程，真是卑微。自己有了几百万首付，感觉是爷了，等你走上购房路，才知道多憋屈啊。

去找房东谈，人家心不在焉。开盘现场，被人群挤得东西倒西歪，一圈靠抢。去找银行谈，人家把你当个散户。在办证大厅里，抱着一大堆资料，站着等号，滴的连口水也没有。窗口交材料，直接把资料退出来：缺这个，缺那个，下次补齐了。

这是每个购房者都经历过的心酸。但是，不走过这一遭，哪有后来的辉煌？

# # 为什么我们不敢往前多走一步？

大多数人在买房决策时，迟迟下不了决心。他一直在心里想，我要是买亏了什么办？是的，价格风险，无处不在，逢涨杀跌，此起彼伏，谁保证肯定赢啊？一旦你进入这个思维模式了，你肯定输了。

你从头到尾只考虑自己的利益。“要是缺了二十万，我就三年白干了，不行不行，不能上当，菜菜肯定是个坏蛋。我这么聪明，骗不了我的”。你从来没有想过，为了孩子，牺牲自己。你一直想怎么占便宜。你是哪根葱啊？你怎么就一定可以占便宜呢？
