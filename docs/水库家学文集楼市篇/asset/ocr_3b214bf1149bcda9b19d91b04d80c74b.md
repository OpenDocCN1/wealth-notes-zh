# ## 地价红利是最大的经济学漏洞

农民盖房子，没有地价。这就导致了一个极其无解的问题，配套太差。卫生，垃圾，道路，绿化，电力，网络，水源，通通不能解决，必须是等有关部门出钱，才能逐步解决。但是，啥时候解决，不知道。

城市买房，要出地价，目的是完成配套。这里面有个经济学漏洞，越早买房子的人，越划算。因为今后的配套越来越好，但你不需再花钱了。举例，我买房房子的时候，附近一千米没有地铁。五年后，地铁开通了，房屋被市场热捧，立即升腾了。但是，我没有花钱，而是新房购买者把钱把我托起来了。

我住在内环线，配套成熟了，还能享受地价红利吗？当然可以，松江区卖五万，是因为购房者出钱做好了配套。于是，产生了比价效应，我的新静安弄睡区，自然就腾到十万了。你啥也没干，就赚到了上百万美元，是不是比巴菲特还厉害？

一层一层往外套，套乎现在大概是1.5万左石，今后卖到两三万是完全可能的，松江区那不得七八万那？你的赤腰区直接十五万了。

结论，老客户赚了新客户的钱。你不搬可以去租屋。没人拦着你。（房住不好，依法依级）

# ## 贫富差距，是自然现象

贫富差距是竞争的结果。大家拼尽全力，为社会做贡献，总有奥运冠军，省队在缩，和第一轮就淘汰的。各行各业都是这样的。做生意也是。你卖黄鱼面，我卖塑料桶，生意好的发家致富了，生意不好，对顾客甩脸子的，被淘汰了。那么多成功者，主流是好的，个别作弊的，你可以去举报，但不要在这里杠精了。

失败者肯定是不甘心啊，千方百计划理由，说明不是自己的问题。我是对顾客甩脸子了，那是顾客要求太多，他先一张破嘴。我家饭菜质量差，那是厨师不尽力，我可没少他工资。反正我总有理。

体制内很划离的，分身千工，工资高，肯定是对他。但是，体制外的成功者，钱多房子大，是不是就不错呢？这话没法说了。

我们更充满爱的去帮助确实有困难的弱势群体，但帮助的前提是，你自己先要有能力。如果你啥也不出，带个嘴去跟啊喂喂，那就合适了。至少捐个三五万，对吧！

对于好吃懒做，四十多岁不上班，三天两头打麻将的贫困，我们应该严厉整顿，治劣去先顺。
