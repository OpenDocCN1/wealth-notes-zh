# 就业是经济工作的红线

国际贸易形势，错综复杂，风云诡谲。在各种困难面前，最重要的问题是民生，是就业。应对就业问题，无非是两个办法：

+   一是增加招聘，鼓励用工。千方百计地化解招聘障碍，降低招聘成本，让各类企业安心招聘，大胆用工。这个潜力是巨大的。

+   二是货币投放，基建先行。这是创造岗位。建个高速，100亿就下去了。100亿分配到各个环节，人为15万，就可以给付几万人发一年的工资。所有的建材，大部分是建材厂人工成本。农田水利，环保治污，搞个几万亿，不是问题。这个可能性也是有的。

# 中共中央办公厅印发《关于鼓励引导人才向艰苦边远地区和基层一线流动的意见》

新华社北京8月19日电 2018年8月23日，中共中央总书记、国家主席、中央军委主席习近平主持召开中央全面深化改革委员会第六次会议，审议通过了《关于鼓励引导人才向艰苦边远地区和基层一线流动的意见》（以下简称《意见》）。近日，中共中央办公厅印发了《意见》，并发出通知，要求各地区各部门结合实际认真贯彻落实。

《意见》指出，支持艰苦边远地区和基层加快发展，人才是关键。党的十八大以来，以习近平同志为核心的党中央对艰苦边远地区和基层一线人才工作高度重视，推出一系列部署举措，积极促进各类人才到艰苦边远地区和基层一线干事创业，取得明显成效。当前，艰苦边远地区和基层一线人才匮乏问题仍然较突出，难以适应促进区域协调发展、打赢脱贫攻坚战、决胜全面建成小康社会、基本实现社会主义现代化的目标要求。面对新形势新任务，要以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，坚持完善人才强国，进一步完善人才培养吸引流动和激励保障机制，鼓励引导各类优秀人才到艰苦边远地区和基层一线贡献才智、建功立业。

《意见》指出，要发挥产业和科技项目聚 tal 效应，搭建人才到艰苦边远地区和基层一线干事创业平台。鼓励艰苦边远地区和基层一线结合实际开展自主人才区域、特色优势产业和有关科研项目，积极引进专业平台，为各类人才干事创业提供岗位。创造就业机会、发展空间。要强化人才管理政策，畅通人才向艰苦边远地区和基层一线流动渠道，坚持从艰苦边远地区和基层一线实际和出发，因地制宜、分类施策，完善编制管理、职称职务、人才选拔和奖惩性流动政策，为人才引得进、留得住、用得好提供制度保障。要发挥人才项目示范引领作用，加强艰苦边远地区和基层一线人才帮扶协作。实施好艰苦边远地区和基层一线人才帮智项目，健全人才帮扶结对机制。

重点围绕产业优势和民生项目加大人才支持力度，进一步吸引和引导各类人才向艰苦边远基层聚集人才。要善用好用本土人才，培育善经营边远地区基层一线干部内生动力。激发艰苦边远地区和基层一线积极性主动性，创造条件满足人才的发展
