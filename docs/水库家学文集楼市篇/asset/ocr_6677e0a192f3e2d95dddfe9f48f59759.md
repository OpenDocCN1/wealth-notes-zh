# 一证一套，让房价插上隐形的翅膀

现在的拆迁趋势是货币化。一证一套，或者全货币。

一证一套的意思是，拆你一套老房子，只给一套拆迁房，另外给你现金若干。

如果你选择全货币，另外再奖励现金（很大一个数字）

一，万人抢购。有便宜占，那也不是天上掉馅饼。南京河西区的那个几公里排队，影响实在太大了。本来大家懵懵懂懂的以为，楼市貌似降温了，结果搞出来一个万人大排队，直接敲醒了很多梦中人。
