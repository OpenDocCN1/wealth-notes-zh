# 买房3年， 法院判合同无效！

中国证券报： 【北京买房住了近3年， 法院却判合同无效！ 】 日前，北京市房山区发生了这么一桩子事，交了钱，过了户，买来的房子都住了两年多，却被告合同无效，房子要被收回。事情的原委是这样的： 2016年9月，李先生通过中介公司购买了77岁的老人李老太太名下的一室住房。去年6月，已过户并入住的李先生被李老太太的儿子陈先告告了。陈先称自己母亲患精神疾病多年，卖房时是限制民事行为能人，卖房这事，自己作为监护人并不知情，也没有得到自己的追认，陈先申请求法院确认房屋买卖合同无效。 （北京晚报）

菜菜： 这个判例，直接封杀了老年人自主卖房的可能性了，购房者不敢买了，极大的损害了其他老年人的权利。

+   1.  35个三线城市新房环比上涨0.7%，涨幅比上月回落0.1个百分点；二手房上涨0.7%，涨幅比上月扩大0.1个百分点。
