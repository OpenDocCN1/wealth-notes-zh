# 京沪房价会如何？

京沪房价会如何？我不直接说。

但我说个最近的拆迁大方向，鼓励全货币化拆迁和一证一套，精确含义自己百度。我说个老百姓听得懂的大概意思。拆迁全部拿现金另外奖励几十几万，或只给一套拆迁房（特殊情况除外）和若干现金，拆迁户再也不要几套拆迁房。

于是，很多拆迁户同一个时间点，拿到了几百万甚至更多的现金，用麻辣香锅冲向了商品房楼市。现在，很多楼盘要求全现金付款，就这么苛刻的条件，还是非常多的人抱关系才能买到房，还不能挑三拣四。

你说，靠小工资的家庭怎么办？报纸上说调控了，你是大学生，你先说。
