# 戒烟戒酒，健康生活

茅台酒，中华烟，是国之上品，但也不必神话了。

这两个神奇宝贝，都是新牌子。起源也很简单，解放后的计划经济，票证供应。这两个商品供应对象是高级别，其他省的一般群众看不到，自然就好稀了。当年，大军路过茅台酒镇，很多土兵用茅台镇泡脚。说明茅台酒在当时是畅销的好酒，但也不是什么特别珍贵的东西。大军里面的知识分子非常多，不要说什么不识货之类的话。

中华烟，出自上海杨浦区长阳路，没什么特别的。3 字头是生产班组编号，不代表什么高品质。我现在不吸烟了。茅台酒，我家也多，原来是用来打交道的，都是八位伴装的正品，每瓶都有发票。前几年因为塑料桶生态太差了，不需要打交了，天天一个人，半夜喝茅台，借酒消愁，确实好喝。

娱乐喝啤酒，闷闷喝白酒。啤酒，我一口气敬喝半瓶，冰凉的，非常爽。北方的二锅头，南方的高梁酒，我真的喝不下去，尼玛的，纯粹是疯房打纤的味道。一闻到二锅头那个味道，我就想起去医院，心惊邪务。茅台酒，比较香，没有酒精味道，入口不辣，慢慢喝，三瓶啤酒的人，喝四两茅台，当场不会有事。茅台酒不上头是真的。白酒喝头痛了，纯粹是劣质酒的杂酚杂液混入血液造成的。

我说话的意思是，其他高品质的烟酒，也是非常好的，自己享受一把，没必要玩虚的。

# 富人都是一群一群出来的

小霸王学习机的段永平带了几个徒弟，在各自领域都上市了。农夫山泉特别有名，你知道创始人是向谁学习饮料的操作手法？新东方 的前员工，在其他领域出了很多富豪。农村创业领域，更是传奇多的天下。为什么富人会集中出现在某个地段呢？原因很简单。

他们商业思维上的师傅，在商业实践中形成了一套有效的打法，符合现阶段的人性。但大师傅自己精格力有限，不可能什么行业都去摇一脚。学到这些方法的聪明人，就带着这些经验，在相关细分领域创业，成功的就多了。
