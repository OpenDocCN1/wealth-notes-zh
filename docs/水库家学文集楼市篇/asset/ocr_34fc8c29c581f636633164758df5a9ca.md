# 发财，绝对不是聪明人设计出来的

现在的大江南北，发财意识，空前强烈，我也想！。

无论什么机会，都有乌云压低的一大片人在捧场。普通人能摸到的风口，微博共振。前面那个250小子，可能是看了几本鸡汤学，就觉得自己聪明大了，估计什么资本运作，国际兼并也就想了。

我劝他也跟那个妈，好好学个手艺吧。别说发财了，你这水平考个北航失败帮困难难吧？他妈不爱好，还把我骂了一顿。骂就骂吧，也不缺一个骂我的。

发财，绝对不是聪明人设计出来的。某老师清华物理学毕业，一等一聪明人了，还不就在中学里教书吗？你儿子想什么呢？真正的发财，是脱离了每月1-2万工资的恶性循环，把全家房子抵押给银行，赌一把风口浪尖。你敢吗？老子用脚指头想，你都不放！还发财呢？能有个朴素味老婆就不错了！

# 不加快发展，怎么得了？

现在的上海80后，好像听上去也比较年轻

# 夜夜闭门读禁书

夜深人静，我给你们讲个匪夷所思的国际学观点。是我留学时候，一个欧美教授给我讲的。欧美矛盾，比中美矛盾还大，胡锡贵肯定不知道这个。

这个事情的起源是，二战末期搞摊子。二战初期，法国迅速投降，美国慌的一比，请美国支援。美国口头同意帮忙。但事实上，美国仅仅是经济支持，通过了租借法案（这个我在后面详述）。美国当时的任务主要是揍日本。

美国打日本，也不是什么二战同盟的意思，而是报复。日本干了两件事情，一是在菲律宾俘虏几万美军，处死了一半。二是偷袭珍珠港。

法国投降后，欧洲发生了奇迹。德国突然不打英国，转头去打苏联。德国苏联，两败俱伤，这个局面的结果是我苏德联军不战而胜了。

整个二战的主线是：美日互殴，苏德对决。英国当时是世界老大，实际上没有什么损失，只是吓坏了。

当德军在美国科涉外失败的消息传来，丘吉尔超级郁闷。请神容易送神难。美国在欧洲战场，基本没有什么力气。租借法案的意思是，延迟付款，不是无偿支援。
