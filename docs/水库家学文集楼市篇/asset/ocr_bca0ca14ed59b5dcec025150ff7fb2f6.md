# 房地产税立法思考

上海居民早就习惯了房产税。今天要研究的是，房地产税是不是全国联网核查？这涉及到今后城市的大格局。

京沪广深最有活力有激情的人，大概是外地精英。这些外地精英，多多少少在外地可能有房产，最平价也有遗产房。这些年轻人在京沪广深工作，如果工作能力很强，一般一会再买 1-2 套之类的。

选择 1，全国面积累计。一家三口，老家人均母遗产 1-2 套，上海 112 平米，那么这个外地精英就要缴纳房产税了。如果把老家房产卖掉，在上海买个小户型，人均低于 60 平米，就不用交房产税了。

选择 2，各地房产不累计面积。现在上海是人均 60 平米免税。一家三口，在京沪广深大城市，买得起 180 平米房产的人，几乎其微，实际上也选择不到多少房产税。

如果全国面积累计征税，那么富裕家庭一般会选择抛售小城市房产，购买大城市房产，这对大城市的打工族有利吗？

如果各地面积不累计，在大城市买得起 180 平米以上的，微乎其微，房产税的调节作用有限。

美国的方案是，每套征税。按照房产价值，每年征收 1-2%。例如加萨一套 800 万，一年征 8-16 万。大家觉得怎么样？

# 税负转嫁理论

一线城市，住房紧张是长期现象。如果本地居民没有什么多余的房产出租，那么外地人进入京沪广深租房，必然会加剧供应短缺，租金高企。我相信，很多人会想出各种办法，争取多买一套。房价怎么办？

小地方缺乏大量外来流动人口，租房需求不高，房子空交还要交房产税，且金额不低，你会怎么办？无非是卖掉小地方房产，尽可能往大城市挤，小地方的财政就难了。财政背后是养老金，教师工资，公共服务。
