他儿子，长得超帅，学历大专，工资一般，找了个非常漂亮的研究生长辈，现在，婆婆带孩子，老公公出去赚外快。丈母娘倒贴钱。小夫妻日子过得非常好。儿媳生孩子，三年不上班。现在孩子入幼儿园了，又去外企了，月入1.5万。

说来说去，就是一套房子改变命运。

# ## 就是卡在房子上

县城女生，去南京或北京，真的没有区别，就是卡在房子上了，县城普通家庭，拿不出多少钱的，南京北京都一样，买不起房子。县城一般家庭，如果父母近五年换过房子的，基本没什么钱了。如果父母一直住在老公房里的，那就更没钱了。能够拿出50万现金陪嫁的县城父母，大多数是体制内的，比例不高的。

# ## 和城市一起成长

我的大学同学，毕业分配基本都在地省城某局某行，工资差距不大。经过二十年，现在最大的差距是住房增值部分。上海停止福利分房比较早，外地来了一些变送，很多人以前没有买房意识，就靠着单位集资房。北京的同学在2001年还有政策房，举例。

我在2000年买的内环线三千多元，现在二手机单价大概是8万多。

西安同学在2005年才考虑买房，也是三千多，现在二手机单价2万多。

就这一个，差距五六百万了。如果要是换来换去，加杠杆，那是没法比了。

# （房住不炒）

这两年，我在市场上看到了很多类似于孤注一掷的购房企划。新生代的疯狂，比我们这些老鸟还凶悍，我甚至在想，是不是该退出江湖了。我是温和派，这种刀口舔血的事情，我是下不了手的。我想和朋友们说几句：
