# 关于炒房的问题

一些不限购的小城市有可能会出现。但在京沪，我实在搞不懂怎么炒。

能够在京沪买得起两套房子，是经济条件较好的家庭，一套自住房。一笨留给房子结婚，这是刚需，不可能卖的。对于有多套房的家庭，你卖掉了也不能再买了。只卖不买，这个不叫炒房间。

2011 年之后。我在京沪基本上是没见过炒房的人。或许你见过。

京沪房子本身就是最优质的资产，就怕买不到，怎么可能卖呢？你卖房，手里拿几百万上千万干什么呢？存银行的利息远远低于房产增值，炒房客都是聪明人，没有这么干的，我只见过置换好户型，但真没见过，把房子卖掉，把钱存在银行的。

# 二套房停止房贷，会降低房价吗？

答：no。理由如下：

二套房停止房贷，意味着卖不出去了。众所周知，热点城市和大城市，二套房的交易数量一般是新房的 2 倍到 3 倍。如果市场上，供应盘突然减少了 60%，大家集中购买新房，这会造成极大的供不应求，促使新房价格猛涨。
