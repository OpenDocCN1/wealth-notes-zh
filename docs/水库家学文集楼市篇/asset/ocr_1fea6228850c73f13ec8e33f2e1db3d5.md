# 普通人决策家庭重大投资底线

+   一，不要以为自己很聪明。说白了，你就是普通人。我是职业选手，都不敢说自己有多厉害，那些业余看秀了几个月微博朋友圈的旁友，就不要觉得自己什么都懂了。
二，保守心态活的长。你的主业不是投资，只是暂时不够首付，先存一下。千万不要以为自己是对冲基金的职业操盘手。
三，任何投资好机会都不要碰。隔壁王阿姨家真热闹，每个星期有外地年轻人上门慰问，陪你聊天，迷迷送油送利息，你就心里发慌了。哎，他们只是在做人户调查。
四，凑够了首付就上。不要在乎短期的划不划算，五年后都是人生大赢家。因为我们和城市一起进步，共同发展。
