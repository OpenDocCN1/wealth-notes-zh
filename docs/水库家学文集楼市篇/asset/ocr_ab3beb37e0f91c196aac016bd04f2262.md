# 为什么房价的稳定性远远好于股价？

人的内心有两个负面因素：贪婪，懒惰。当获利超过 50% 的时候，绝大多数人就开始脑子活泛了，想套现了。

但是，卖房子可累了。大城市房子，不是自住就是出租，里面有人。卖房前，要赶人，或者和租客反复协调，斗智斗勇。或者自己来收房，买新房卖装修，事情多的一比。很多人想了两天，索性上来，又开始贪婪：喝，说不定还会上扬一点，先缓缓。这就避免了抛盘的集体踩踏。

卖股票简单简单。坐在地铁里，手机点一下，三秒钟就卖掉了，很多人实在是忍不住啊！

# 中国最大的内需就是房子

买了房子，才会买空调，地板，木门，厨卫洁具，否则你空调挂墙上啊？没有这么多发展的楼市大发展，哪有登明珠啊？楼市最大的问题是：房价涨的过快，导致贫富差距拉大。有房的人，贪婪起来，不买房的人，更多亏损。

解决房子的根本办法。

+   一，扩大供应量。现实中，各地因为用地指标不够，导致供应短缺。我建议，土地互换。安置人来上海定居，那就把安徽的用地指标带过来。现在，很多安徽人，老家有宅基地，二上二十八楼闲置，县城有房子，老头老太住，自己在松江闸浦有房子，这么多土地浪费，合理吗？

+   二，关系货币的龙头股。基础货币发行量，应该纳入预警体系，就像是财政预算报告。

+   三，缩小各地民生待遇差异。经济发展的差距，受制于自然条件，一时三时搞不定。但是医疗教育可以尽快解决的。河南东北安徽，大学升学率和京沪平齐，就不会有那么多人往京沪挤了。

+   四，绝不与民争利，切实减轻群众负担。豪宅可以多收税，普通住房是生活必需品，应该轻税薄赋，首套免税。
