# 东北怎么了？

留几乎说东北没落的原因是，东北人以前好日子过惯了，不愿意去工厂卖力气，所以越混越差。这是胡说八道。

要说好日子，京沪更好。自然灾害，上海也不存在饿肚子。要说大厂子，上海更多更好，而且是民用产品，红灯录音机，上海牌彩电，大白兔奶糖，飞机牌皮鞋，凤凰牌自行车，什么都有。但是，计划经济结束后，上海还是金光闪闪，东北却不行了。

要说外资企业设厂，日韩对东北也是感兴趣的，

要说上级部门关心，那是捧在手宝一样的宝贝。

要说技术人才，东北那么多大学，杠杠的厉害。

为什么东北还是不行呢？思想观念落后。东北人最喜欢说的是，历史上做了多少贡献，这话有意思吗？四川在自然灾害的时候，还往外省调拨粮食，他说什么了？

我和东北小商人打过交道几次，毫不说夸张，我念孙子也不再想看见他们了。说话像放 P，合同当废纸，喝酒时候，什么都行，干活时候，什么都不行。一有矛盾，不讲道理，而是直接威胁恐吓。信不信，老子现在就撕死你？或许我遇到的是个别极品，但我在其他地方，极少遇到。

为什么东北会有这种风气？其实，南方也是崇山峻岭，解放前到处土匪军帮，好勇斗狠，也是稀松平常的事情。解放前，闽浙就是海匪重灾区。为了争夺水命，南方农民打起来也是非常厉害的。但改革开放后，好勇斗狠，基本没了，最多是出了点电信骗子。

东北很多人不相信规则，更愿意通过打架和找关系解决问题，这不仅他们是他们自己的原因，而是有深刻原因的。省略一百字。

# 一线和三线的中产阶级生活区别

答：我不知道你说的三线是什么地方。一线京沪，二线苏杭宁，三线就拿济南成都青岛作为三线中国信。

+   一， 日常生活差不多

三线城市房价低，除了个别桥头楼盘，大部分买房子是 2-3 万左右，总价 200-300 万，首付三成，双方各出 50 万，一个溜娃生僻的小家庭就可以拍抖省，还包吃，晒美食了。其他物价也差不多，日用品基本是京东淘宝，大概面还便宜几块钱。

+   二， 成为中产的渠道不同。

三线城市最大的问题是，高薪岗位少，产业结构不完整。三线城市大多数中产就是机关事业大国企，经营良好的小老板。外企白领微乎其微，新产业带来高薪岗位不多，不存在复制一个华强北和农付的可能性，这就极大的提高了屡尽尽难度现象。

好单位相对固定，各种势利，早就划定地盘了。人际关系，盘根错节，人情往来，烦不烂。
