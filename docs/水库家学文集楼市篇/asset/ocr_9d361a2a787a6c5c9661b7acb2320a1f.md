# 房子不代表幸福？

我周围的亲戚中，有自己房子的老人，晚年 100%幸福，儿孙孝顺，媳妇嘴甜，生怕老头头摔外出，被小保姆骗了。京沪也有很多名下无房的老人，拆迁的时候，房子直接写了儿子媳妇名字，晚年相当悲惨，儿媳妇一脸嫌弃，儿子也没耐心，随便请个钟点工应付一下就拉倒了。

# 如果没房子

张子姐：房子再多，你也只能住一套。人民币再多，你一生也不可能花一亿。人这一生，知足常乐，身体健康，才是根本。其他的都是虚的。到医院里，走一走，看一看，人也就清醒了。

紫溪：如果没有房子，儿媳妇是不会到医院给你擦汗送饭请保姆的。

# 女人对房产非常疯狂

昨天和多年未见的某女亲戚聚餐，她 35 岁，说起她前两年买的一套房子赚了一百多万，眉飞色舞。

她已隐和老公办了离婚手续，准备用首付再买一套。她老公开始不同意，她就摔锅砸碗，最后老公同意了。她说起离婚毫无羞涩，觉得就像办了一个暂住证，她老公倒是有点尴尬的表情。（房住不炒，最好暴跌）

# 有人说，

买房后，普通人没钱消费了。这简直是胡扯。

吃小龙虾是消费，买烧烤、洗衣机，空调，那不是消费啊？现在京沪一百平米，硬装修大概是 25 万左右，其中 15 万大概是给贴砖开槽厕所的农民工赚走了。多好的事情啊！

# 房住不炒，最好暴跌

现在，又到了一片唱空的时候了。房东忍了，房价跌了。嘿嘿，这次不一样了。你自己看着办了。

# 解决高房价的治本方法

+   1、打掉投资需求。让开工的小老板有钱赚，比买房好。  
2、打掉居住需求。没有户口的，暂时过几年苦日子，一律回老家。  
3、打掉货币增发。没钱了，我看你怎么买？  
4、打掉财政利益。土地款一律转给医保证金，社保金，专款专用。

# 时代的变化，往往让人忘本了

很多人觉得我写的那个公主故事，不可思议。

其实，在 2014 年之前，内地省城根本没有什么房产意识，当时的报纸都是一片暴跌的声音。郑州的新区现在大概五万了，当年一万多也没人买，直接叫做鬼城。除了京沪，你想想你家在 2014 年前，有没有多买一套的概念？根本没有。时代的变化，往往让人忘本了。
