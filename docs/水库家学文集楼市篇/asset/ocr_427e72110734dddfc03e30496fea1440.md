# 菜菜说金融

你先查看同总说的这段话：“过度的须业造成一系列金融乱象，同业、通道、嵌套、资金池、庞氏融资管的万能险、P2P、非标、现金贷等层出不穷、相互叠加。”

你看完的结果是：都是中国字，但一个也看不懂。这些词是什么意思？其实就是各种监管工具。所有你看不懂的金融新业务，都基于以下原因：

+   1. 根据银监要求，企业之间是不能互相放贷的，但实际上，很多企业就是做资金掮客的。很多企业也确实需要资金，但在银行贷不到款。
2. 根据央行要求，合法贷款利息是有上限的，例如 8%之类的。
3. 贷款发放范围，是严格管控的。

实际上，有很多企业抵押物充足，但由于风险高或者不符合产业政策（例如土地贷），银行不能按照 8%的利率放贷。但是，银行又要收，到手的肥肉不吃可惜了，于是双方一拍即合，你出两分利，我借钱给你，但要换个合法外衣。

如何打造这个合法外衣，就需要律师和 CPA 去设计了。于是，律师们就设计出各种千奇百怪的套路，然后再起个你根本听不懂的名字。你不需要学习这些乱七八糟的名词，只要记住一条：名义上是股权，实质上是债权。

# 两千万是什么概念？

+   1. 京沪一套大房子，住 5-6 个人最多 了。
2. 三线城市的一个大工厂，员工几千人（学徒），年产值低，是完全正常的。

目前，货币政策已经失效了。无论你怎么印票子，已经很难刺激生产了。多出来的票子，在铁公鸡工地上晃一圈后，如滔滔江水般直接流向售楼处，不带一丝犹豫。财政赤字和货币超发，说白了是临时性工具，不是常规工具。但是，有些专家沉迷于这种临时性工具带来的快乐和迷幻，忘记了吃亏嘴苦，蹑蹑实实，以至于把一切希望都寄托在货币上。

今后会如何？不要指望那些舒服惯了的专家，会自觉反思的转型发展思路，自觉自愿的去吃苦耐劳，这是不可能的。我们应该反思的是，如何真正的创造活力？而不是简单的靠儿个吃香锅和地球，然后自我表扬。这种工程项目，一报国家筹金，技术上没有周意，只不过他们不愿意出骡骡子而已。

大力培养有竞争力的中小企业，通过生产，制造，创新，富民养民，而不是发几个通知，强迫企业把钱找投资机构去给员工加工资。
