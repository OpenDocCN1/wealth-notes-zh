# 如何判断城市估值潜力？

人口越多越稠密的城市，经济活力越大。这是经济学底层原理决定的。

经济学是怎么来的？资源不够。那么，最快捷的解决办法就是，共享资源。举例，在一望无际的大草原上，你建个学校，经济学术上，不现实的。就算勉强猜几个，也难以长期维系。但是，在人口稠密的大城市，建一个小学立即爆炸。
