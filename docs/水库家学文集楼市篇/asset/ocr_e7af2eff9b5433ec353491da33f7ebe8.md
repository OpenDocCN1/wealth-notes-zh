会计认为，这笔开支就是研发费用。两个月后，稽查局来看了，认为不算。呵呵，这个企业傻到了。算了，你这是违法了。补缴税款+罚款。那么罚款多少呢？1~5倍都可以，还必须先交钱，再罚款。钱都交了，一般企业也就服了，以后还见到面了，不必吵到最后了，也线认了！

建议：税减就不要附加件。附加件减税，只不过是增加审批环节而已。

# ## 金融改革的方向（2018.07）

当前的贷款结构大致是三层：

+   1. 贷款利率12%（一分利）以下的，基本是银行在做。

+   2. 贷款利率12-24%（二分利）的，基本是亲戚朋友互动。大量的小企业就是靠这个混的，高利贷团队不会做这个业务。因为高利贷要养活一个催债的金钱仔，成本极高。

+   3. 实际三分利以上的，基本就是高利贷了。表面上，往往是合法的两分利，但是有很多隐藏条件和潜规则，三分利、五分利，司空见惯。

国企和信贷，利息最低，条件最优，往往是基础利息上浮一点点。因为得行利益不大，所以审核超级严格，生拍坏帐，要你提供各种各样的资料。信用卡负责往往是利率12%左右了。信用卡办卡最方便，你要咋啃吧地，但是信用卡金额不大，也很迷表现，中小企业不能完全指望。

在这种环境下，中小企业就愁催了，他们一般拿不到什么正常贷款。经营贷款就是房产贷，小老板拿家里住房抵押。但很多地方，例如前两年的成都重庆长沙贵阴西安，省会房子也不值钱，打六折，一百平米也就贷款六十万，而且是一年期 的。如果小老板要技术升级买设备，再加上原材料进贷之类的，六十万根本不够用。

举例，做最低端 的塑料拖鞋，厂房租金、水电、会计财务部房屋造工人，七七八八加起来一共15个人，再买设备，进原材料，一年开支五百万以上，因为有淡季，资金转3-5国基本是极限了，至少要100-200万流动资会。稍微高大一点的生意，做个儿童手表之类的，没有五百万现金，你不开要开工。

做生意有场有场，平时找亲戚朋友指点，房子抵押搞贷款，可能也换合了，一旦出起场，例如一笔货款收不到，中小企业马上发烫发行，银行货款到期了，那这个小企业基本落入高利贷之手，生不如死了。其实，中小企业是愿意要银行按20%利息的，但是银行不愿意啊，没有抵押，经营不稳定，反正一大堆理由啊！

这就导致了一个结果，中小企业要正常贷款，必须有房子，最好是京沪房产。怎么办呢？卖了钱就买房。那么多老板去买房，时间长了，很多小老板发现，辛辛苦苦干个十年，还不如房价变化一年的收益。你说怎么办？
