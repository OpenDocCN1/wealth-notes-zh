# 经济思维的转折年（2018.08）

是2009 年的四万亿。

我们这一代经济学老，都是金融系的老古董教出来的傻博士，工资低的可怜，混不得把中午食堂的大排多买一份晚上吃，晒是见过分什么货币大棒炸啊？那些老学究，老古董，就更好笑了，火柴两分钱一包，四十年没改过，他们更不懂货币了。当年最离经叛道的经济学观点，也不过是赤字财政。银行呢，就是个记账的，算个球啊！我们那时候，银行行长没有地位的，就像个国企厂长，财政局长才硬气，开会坐第一排的。

2003 年以前，房价=成本+工业利润

2004-2009 年，房价=成本+工业利润+供需关系溢价（热销就涨价，滞销就降价）

2009 年以后，房价和成本没有一毛钱关系了，我们当时的测算模型是：参考拿地时周围的房价，一年后开盘，直接涨 50%，不考虑成本。

2009 年是经济学人集体反思的一年，那一年，经济很困难，农民工都回乡了，博士的工资不过是五千块。照理说，经济困难了，应该逮人为出来，勤俭持家。没想到，上面突然大手笔，来了个四万亿。我当天晚上就在想，这钱哪来啊？后来，大家都看明白了，无中生有啊。央行在电脑里输入几个零，四万亿就出来了。我靠，这么简单啊！

货币只要出笼子了，都是有主人的，不可能凭空消失。货币在建筑工地晃了一圈，就纷纷落入各种人的口袋了。这钱接下来还能去哪儿呢？当时的情况是，欧债危机，美国次贷债，世界经场一塌糊涂，外贸半休息状态。出口不好了，投资扩厂肯定不可能，社会零售品也不会增加多少，开店也是死找，想来想去，最可能是买房。外地大学生来京沪这么多，总要住房啊。买下来租给他们，也是个收入。

2010~2011 年，京沪房价，一飞冲天。调控了，限购两套房就是那个时候出来的。不过，刚刚出来的时候，大家都看房票，所以没效果。

2012 年，大家房贷供完了，这下子市场真的冷却了。

2014 年，CCTV 经济半小时去宁波采访几个开发商，七千元卖不出去，开发商哭的像个傻逼。银行也是手脚冰凉，不知道怎么办了。鬼魂到处都是。

2015 年，楼市去库存开始了。上海休息五年，直接迟退了。杭州南京厦门楼市，一跃成为领头羊。

2016 年，房价翻番，空头哭成了 259。

嗯，这次不一样了。你先别买炒，让丈母娘耐心点，以后一起捡便宜货。
