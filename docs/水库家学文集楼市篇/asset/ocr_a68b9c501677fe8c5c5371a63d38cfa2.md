# 年轻人不要在京沪广深买房

但他爸应该买。

年轻人，大学毕业就 22 岁了，工作五年就该结婚了。小两口这几年的存款，能选彩礼，置嫁妆，办酒席，就算是优质青年了，买房这种事情，起步就是几百万，和年轻人有一毛钱关系吗？我说不买，是因为不现实。

人往高处走。年轻人就应该去大码头，大城市，经历风雨，砥砺前行，用勤劳和智慧，创造美好生活。为人父母应该及早打算，为子女修路架桥，打通站。邪种“儿孙自有儿孙福”的中年矮鸡，你好意思吗？活了大半辈子，没存下多少首付，反而攒下了一肚子怨，天天在家里负能量，你对得起孩子吗？
