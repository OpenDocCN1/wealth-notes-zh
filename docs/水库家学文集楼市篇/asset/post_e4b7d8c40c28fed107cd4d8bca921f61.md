## 近二十年来各种倒霉蛋经济体

例如委内瑞拉，阿根廷等，他们有个共同特征：

日用品大量依赖进口，本国制造业薄弱，靠1-2个经济强项过日子。

这种经济结构非常脆弱，一旦出口强项出现了价格暴跌，那么外汇就很快枯竭，日用品立马短缺。这时候，超市里一壶加洗的货架，会对普通人产生巨大的恐慌，加速崩溃。

中国经济结构不会发生这种情况。中国的日用品完全可以自给自足，粮油供应，短期内绝无问题。大不了，进口鳕鱼和苹果手机少一点了。我们和东盟的经济互补极强，粮食短期内不是问题。

但长期看，如果不能和世界高科技接轨，内生力量会受到拖累。离开了高科技的进口芯片，多少年才能追的上，这日期很难确定。

在民用领域，老百姓不用苹果手机，也活得下去，开机慢30秒钟，也无所谓，做信也 不错。

在其他领域，只能各略一百字了。

## 在迫不得已的情况下

建议暂时放弃市值

当前的经济工作，面临三大任务：保就业，促实体，稳市值。

### 一，就业和GDP其实是一回事

正常的经济体，人均劳动产出基本稳定，每年有点点进步，但不可能无缘无故的突交（除非科技大变革）。GDP就是劳动产出的总和。

当前，看不到有改变大趋势的科技发展惊人进步。保就业，说白了就是继续投资。铁公鸡是当家花旦，绝对主角。

钱，从哪来？

### 二，促实体就是保住外汇储备

中国经济结构是有很多挑战的，最大的困难是，大宗商品和高科技必须依赖进口。

我们小时候，遍地是稻田，到处是农民。大家还是吃不饱，缺甚至吃不完，现在，40岁以下的农民，五谷不分是普遍情况，但我们吃的越来越好了。阿拉斯加的海鳗，加拿大的鳕鱼，大西洋的三文鱼，随便吃，食用油一桶一桶的买。

这就是外汇的魅力。我们出口大量的商品换取美元后，进口食物，丰富了菜篮子。铁公鸡是不能出口的。国人最大的利润是赚中小企业的钱，出口多少，大家心知肚明，不说了。

外汇的主要来源

一是劳动力换汇。外资企业在华生产，本质上是看上了我们的便宜劳动力。低价土地不是优势，全世界低价土地多了。水电气过路费，比美国贵。还有一些劳务出口。

二是中小民企的日用品出口。例如袜子，裤子，塑料桶，还有一些低端机电产品，便宜实惠。

保住实体，就是保住出口，保住外汇。

### 三，稳定市值对应的是日用品价格和资产价格

现在，番茄7元多，一只鸡100多元，短节虾80元，物价水平非常高，接近欧美了。房价就不说了，驻马店和法国德雷的中等城市差不多了。

稳定市值就要发发钱，但是，缺钱了，铁公鸡和实体发展怎么办？科技进步也不是一天就完成了。

在经济上升期，还能强可以维持面子做到，但是，如果遇到较大的外部冲击，我们就不得不突出重点，那么，经济发展重点是什么呢？

第一，治安稳定，就业足。

第二，吃嗝不愁，靠外汇。

市值稳定，是第二层面的目标，不能超过治安和吃饭的重要性。万一房价短期内略微上扬了一些，你不买就行了，也没人逼你买房。但是，社会治安和吃饭问题，那是一天也不能松手的。

经济发展不可能一帆风顺。暂时的困难，终究可以克服。放弃面子做到，突出工作重点，是理性客观的选择。

老家还有宅基地，没事的。

## 当前的经济形势，确实遇到各种挑战

- 1. 本币的基石是外贸出口。
出口换回了美元，美元支撑了本币汇率。几万亿外汇储备在手里，胜过用商进步。但是，中国外贸的结构是有不足的。
进口都是物资，粮食、石油、高科技。这些都是一必须美元交易的。
出口都是可替代的，我们的优势又快又便宜。问题是，
第一，如果某些国家为了其他利益，放弃便宜，那我们就不尴尬了。
第二，一般商品今后还能不能继续便宜，不一定了。劳动力成本已经接近中等发达国家了，水电气，房租，过路费比美国高，税费负担出口可以减免，但现在又加了个环保成本。这种情况下，怎么能做出比东南亚，北非，墨西哥便宜的商品，真是需要耐人了。

- 2. 楼市取决于财政的需求。
楼市的本质是，解决财政收入。在任何一个把房地产搞垮的小锅小县，财政收入都可以迅速发达到，例如海南，西双版纳，贵州。如果房价骤冷，各地出现烂尾楼是完全可能的，房产商的资金来源，有相当一部分是拖欠工程款，拖欠原材料，或者民间借贷。这些借款是有期限的，一到年底或者借贷到期，必然出现上门要债。

开发商原来根本打算给现金，一般是房子抵债。如果房子限购，抵押也没人要啊，包工头拿什么支付工资，民间借贷都是十万八万的，房子给谁啊？

财政的半壁江山是房地产相关，如果真冷了，财政工资怎么办？地方债怎么办？这需要综合考虑。

- 3. 中小微企业没利润
求生欲望强，不敢说多了。但形势严峻，真的严峻。小企业最大的困难是，没有利润，干耗干熬，甚至没有资金遣散员工。现在银行的意思是，锁定向商建，给你点贷款，先活着，但这不解决问题啊。贷款要还的，小老板要拿几房子做去银行抵押的。拖得越久，债务越大，小老板就榨的一点不剩了。

- 4. 利率两难
目前看，实体经济领域走弱，需要减息。但是虚拟货币领域资金泛滛，需要加息。热钱滚在一起，到处乱窜，走到哪里都是祸害。必须找个笼子把钱锁起来。以前是楼市，现在楼市限购，还有哪个领域吃得下这么一大盆水？

- 5. 高科技，包含芯片的自主研发
科技技难题人为设定成功的最后期限。飞机发动机搞了几十年了，做了多少规划，现在如何？大家都懂。

在没有取得突破之前，我们的就业和经济，主要靠什么？靠内需啊！

- 6. 国企改革的目标
国企的目标不是关门来爆小民企的钱，而是要在世界经济的大舞台上，创造中国品牌，国企标杆，就按照这个目标考核。

建议：紧紧围绕群众的需求，寻求经济再发展

- 1. 大规模建设住房，要建精品，而不是低质量低成本的廉租房。通过扩大供应，解决价格问题，平衡市场周期。
- 2. 中小学入学难，尽快突破。在大城市中，迅速建立一批低价便民的学校，可以几个学校合用一个操场或者公共体育馆，尽快满足广大本地和外地群众的需求。对于经济条件好的家庭，优质中小学扩招，欢迎消费，拉动内需。
- 3. 引进一些优质外资医疗，形成市场竞争，促进群众身体健康。
- 4. 能不能减税三年？直接打五折，不要什么审批了，跑来跑去大家都累，力气都花在研究材料上了！
- 5. 吃皇粮的，能不能减少0.1%？也算是为财政减负。
- 6. 青壮年就业不难，难的是，很多人要钱要薪少，不想去艰苦岗位。这种人，管他干什么？

## 在岸人民币和离岸人民币

为什么汇率不同？

- 1、在岸是指国内交易，离岸是指境外交易，主要是香港新加坡，和内地经贸往来较大的地方，他们有人民币兑换需求。例如回内地，先兑换好一些人民币，免得打车都找兑了。
- 2、在岸人民币汇率，央行说了算，6.8左右，你同意不同意都没关系，你认了就是了。
- 3、离岸人民币汇率，波动非常大，经常和国内人民币汇率不同。

小额的可以，超过五千美元，你就要填写很多表格了，然后告诉你，你的表格是不是填对了？如果不对，那就没办法了。以此类推，反正有一大堆手续和窗口把关，保证让你爽到嗨。

离岸人民币知道自己回去不一定能够换成外汇，就在境外直接抛售了，这就出现了汇率背离情况。

## 中国绝对不会有金融危机

真正麻烦的是中小民企的技工队伍。

- 1. 外国的金融危机，是市场因素造成的。我们对市场的管理非常有力的，绝不可能出现金融危机。涨了，就调下来，跌了，就给他拉上去。如果市场不买房，那就审批，设立各种前置条件。控制下交易，价格就不会上蹿下跳了。天下太平，放心吧。
- 2. 落后国家，金融危机外在表现主要是日用品短缺。我们的强项就是日用品，绝对不可能短缺的。卫生纸，食用油，敞开供应。
- 3. 发达国家，例如美国欧洲的金融危机，主要表现在，币汇贬值，四大市场同时暴跌。这在中国绝对不会发生。人民币是自己家地里种的，若遇到比较严重的时候，国家可以随时可以解决问题。
- 4. 汇率是管制的，没有什么好担心的，最多是出现汇出，麻痹一点。

我担心的是，实体企业能不能保留住一批技术工人？这个问题现在表面看不出来，十年后有点头大了。

实体企业和金融市场不同。金融市场只要有货币顶进去，15分钟拉个涨停板，直接阳光灿烂了。但是，实体经济不是那么简单的。举例，做个最简单的儿童滑板车，也需要模具，喷漆，锻造等等很多工序，不是工资加倍就可以了，而是需要大量的技术工人。一般2-3年工广经验，才勉强算上手。

现在的情况很微妙。技工，工资高，人手少。

一般民企，如做家具机械城市拖鞋，技术工人工资待遇还算不错，但年龄越来越老化了，都是四十多岁的人了，年轻人没有技术，工作环境恶劣，工资不高，都不愿意干。因为没有年轻人竞争，中老年技工收入不错，但十年后，他们都会老花眼了，怎么办？

为什么小老板不给年轻人开高工资，让他们安心心学手艺？因为小老板也朝不保夕，天知道。
