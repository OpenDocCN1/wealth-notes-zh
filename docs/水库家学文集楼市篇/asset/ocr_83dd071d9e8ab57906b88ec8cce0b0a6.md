子的故乡。

目前：各种手段，强力控制京沪房价表面上不再快速涨价，其实大家都知道是怎么回事，反正报纸上說降价了，但只要一开盘就是人人山抢的抢购。为什么？因为这个城市越来越好，越来越富裕，大家都想来，而不是要离开。一个人人都想得到而又得不到的东西，你说他会降价吗？

要想让房价下降只有一个办法，减少常住人口，导致该地区房子的流动性越来越差，卖不掉，租不掉，挂牌三个月没人看，那就真的降价了。

减少 m2，首先摧毁的三四线城市房价，京沪根本无所谓。就像是发生春荒了，地主家也不会领了。

目前的人口情况是，京沪的人口可能会越来越多，而不是越来越少。人口为什么会聚集在京沪？因为其他地方，例如东北，类似于东北的地方，商业环境不发达，人情关系太复杂，走投无路的屌丝只好来京沪博一下。这话说远点了，不是经济问题了。

# # 京沪楼市最理想的状态是

房价微跌的跌一下点，持续 6-12 个月，然后停止，不跌不涨。

+   1、房价持续下跌等于好坏或下跌。房价是财政收入的成比例镜像，如果房价正式下跌通道，开发商就不会拿地了，拿地到预售，至少 3-4 年，如果持续下跌，开发商必亏，楼市就停止了。不排除个别无所亏损的企业，带着任务去拿。正经的经济核算，开发商是不能在进入下跌趋势后，继续介入的。

+   2、京沪房价必须微弱跌一点，目的是杜绝社会闲余资金，无休止的流入楼市，造成不科学不理性的狂购，否则各行各业谁也不想干了，就等着买房发财了。这在宏观经济层面，是无法承受的。

+   3、京沪房价也只能是微弱跌一点，因为必须保证银行抵押的安全性。中国经济目前的信誉环境，一旦变成负资产，那是可以想象怕情况了。

+   4、不涨不跌，是理想状态，但很难在大城市做到。

+   1）中国太大，资金太多，其他地方资金就微溢过来一点，京沪就水漫金山了。

+   2）人口流动是单向的，集中涌入大城市。而大城市的资金无法进入乡村，大家聚在一起，最佳的存放地点就是楼市，简单安全。

+   3）世界上，从来没有长期横盘的夜食品。不涨了，买莱就不急了，互相观望，等于开跌了一点，一旦下跌，那就是败市了。

# ## 为什么出嫁多年的女儿回来抢遗产

出嫁女儿抢房子，一般是父母全走了，才会来抢，这种事情主要是五十岁以上妇女，带着自己的儿子媳妇，和阿哥阿姑的儿子媳妇对换。

上海家庭绝大多数经历过拆迁，在拆迁过程中，儿子女媳已经把老人的份额吃掉了，所以出嫁女儿抢遗产主要是发生在棚户区。一拆迁全拆迁，每条弄堂里都有几家这种故事。

无论法律怎么规定，上海家庭是非常鄙视这种妇女的。这是有原因的。到了父母双亡的时候，阿哥阿弟已经接近六十岁了，子孙三代。习惯上已经默认这房子（棚户区为主）就是我的了，这么多年也为了修缮，付出了巨大心血。

女儿出嫁几十年了，也就是偶然回来看看。不要说什么女儿照顾老人，上海交通不便，工作节奏快，半个月来一次己经算是好的了。真正遇到半夜上医院，主要是儿子媳妇出力。
