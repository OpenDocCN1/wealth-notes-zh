# 同样是军阀混战和八年抗战

为什么票号倒了，银行完全没事？

答：1，银行柜台里没有金条，敌军抢不到什么。

2，银行董事长不是东家，日军抓他也拿不到钱。

3，银行柜台里，只有少量纸币，抢了也没用。

4，日军抓到了银行大股东，他也就是几张股权证，拿走就拿走吧，以后补办即可。

5，银行的核心是账本，复制十分就完全了。日军攻占前肯定有征兆，行长带上账本躲起来就好了。票号不可能带上几吨白银跑路。

6，银行不做实体生意，道路断了就断吧，无所谓。

7，银行也不怕老蒋和日本人的更替，存货相似，也不亏多少，关门就关门，大不了，这个地方的今年利息没了，但员工遣散费也不用付了，损失有限。

# 乔家大院为什么完了？

1935 年币制改革：

1，严禁金银流通。票号的起源就是金银携带不方便，这下彻底完球了。

2，强制使用纸币，取代了银票。票号无所事事了。

3，汇兑官办。把票号的最大业务拿走了。

次要因素：

4，各地混战，道路阻隔，丝茶贸易也做不下去了。

5，冯玉祥勒索军饷，拿光库银。

6，阎锡山在中原大战失败，晋钞变废纸，乔家守信用，按新币发放存户，损失惨重。

7，日军占领祁县，乔家人全跑了。生意彻底烂倒了。

8，士政后，房子也没了。

# 山西票号、江浙钱庄和现代银行的区别？

答：表面看，票号和银行，业务基本类似。但股权结构，风险管理，业务重点，完全不同。

1，山西票号相当于沙县小吃，一铺养三代，东家说了算，不招募社会股本。副总，领取身股（无投票权，只有分红权，离职就没收）。乔家最鼎盛的时候，只有 40 个号，下设地区小号 160 个。抗风险能力小。大部分票号都是昙花一现。
