房贷一次就是一家门250了。所以在大城市漂某小区的店铺根本没生意。

# 今后做生意要盯住农民工

他们有巨大现金流。同样九十平米，沪深比县城贵几百万，农民工支出少多了。农民工主要是辛苦岗位，装修保俶，鸡嘴爪收废品。收入比城里人多尚了嘿，下一波消费看城市农民工了。城市白领都是硬消费，没有花头了，除了在孩子方面动动脑筋。幼儿园一个培训班收几万。

# 九十年代初期

中西部农村大学生批量承包揽京沪大单位岗位的情况，可能不会再现了。

那时候，城里人也不管子女教育，城里高中孩子考上大学的也就是15%。我们毕业时候，又遇到单位学历大比较，每个单位都以本科率高不高，作为单位重视人才和提高人员综合素质的标志，最简单的办法是，全部照招本科生，二本也要，研究生直接副科。单位每年要公布本科率（含夜大学，我是top1函授化学系）这于下，我们这些250一捣而入，占搭了很多很多好位置。经过二十年疯长，成才率很高。那时候是位置多，本科生少。

九十年代单位发房子，外地农村人都是上海无房子！排在前面，一套房子现在四五百方。当年给中环线三居室，我还不嫌嫁远呢了。

现在，大家都聪明了，这种事情不会再有了。

# 90年代银行都是中专生职校生

那时候存折是手写的。银行桂圆和菜场卖类雕的大姐是一个档次，工人编制，还不如菜场营业员实惠。菜场要是晚上盘点有一些猪脚剩下来，就是福利了，银行不可能有人民币多出来，那时候1毛钱也是很宝贵的。经常会出现在盘点少了钱，有可能是多给了客户一张票子？？。营业员要赔钱，否则就摘大了，层层领导都要来问原因，年终奖也改了。

你仔细看管，现在五十岁以上的银行大姐，基本上都是大嗓门，跨女人，腰围紧不下制腰裤子，都延特大码的，都是那时呼喽架练出来的。我们那时候有六个规定，不许攻打顾客，存取自由。
