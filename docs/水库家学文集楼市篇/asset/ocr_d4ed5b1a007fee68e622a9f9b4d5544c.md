# ## 雄安的未来非常美（2018.04）

我把北京人口分为两个类型，一个是原动力人群，二是衍生就业人群。

举例，企业总部在北京有几千个员工，可以自行选择办公地点，具有单独存在的能力，不依附于其他行业。

这些人出现，衍生了无数就业机会。例如，医疗教育，衣食住行，保洁保姆，公共服务，门口卖煎饼果子的。他们撤走了，衍生服务人员也就走了，煎饼果子没人买了。

+   1. 在校本科生，中专职校学生，老师，后勤人员，大概是 100 万。

+   2. 大医院的外地患者，很多。

+   3. 集团总部人员，例如银行，大央企。

+   4. 区域性批发市场。

+   5. 外地来的短期培训人员

我估计这几类人群合计至少 150~200 万以上，这些人带动的其他岗位至少也有 100 万。这就 300 万了。如果把这些 人撤离，北京一下子就可以减少 15%人口。就市中心而言，可能是减少了 30% 的人口，因为这些主要是在五环以内。这就大大缓解了各种压力。

这么大的人群搬迁，需要一个稳妥的承接地方。

+   1. 水源充足，交通便利。

+   2. 不能太近，否则和北京联系不便利。

+   3. 不能太近，否则一下班，就往大红门赶。

雄安各方面都是最合适的。我感觉，今后，雄安全部形成一个 200-300 万人稳定居住的新城市，人口数量取决于北京把多少资源搬过来。

雄安有了这个基地入口，能不能进一步发展，取决于将来有什么产业集群。河北水资源不是特别好，一般不会发展工业。
