# 年轻人

当然我知道，中美向何处去，还取决于中国如何应对。当年的冷战也不是一下子就形成的，而是美苏激烈互动的结果。中国如果全面向美让步，接受美国的各种苛刻条件，签一个不平等条约，中美就可能避免最糟糕的情况。代价将是，第一步中国的经济体制将按照美国的意愿进行改造，中国放开国家推动高科技发展的权利。在让了第一步之后，美国一定信心爆棚，接下来要求中国在台海、南海等问题上听美国的。再接下来，它会要求中国限制军费，削减弹头数量和核武器的规模。美国已经发出要让中国参与美俄限制战略武器谈判的信号。但是大家希望那样吗？

我个人认为，以中国对美做战略大遏退来化解双方冲突的途径几率低。这是中国的民族自尊、美方的贪婪、中国社会不太可能放弃继续发展的权利等诸多现实条件所决定的。中国不断反制，中美进入旷日持久的对抗，这样的可能性正在一天天增加。

中国官方星期四首次释放了可能动用稀土武器对美进行反击的强烈信号。我相信随着美方步步紧逼，中方动用这一武器已是定局。中美会进一步相互出招，以打击对方为目标。双方冲突会有很多概率越来越往耐撕，打击对方置于保护自我利益之上，两国冲突的性质会逐渐失控，不以很多人“通可止”的善良愿望为转移。

今天的年轻人在经历一场大变革，这场变局在重新定义中美关系，重塑21世纪国际关系的性质，无论它的结局如何，它肯定会被载入史册，直到千百年后人们仍会谈论它。

大家知道，老胡很不希望中美 的冲突愈演愈烈，我把这些写出来是想告诉大家，中国的确走到了国家复兴的一道关键屏障前。我们别无选择，只有所有中国人团结起来，迎接这场改革开放 以来前所未有的考验。焦虑无关人，我们惟有坦然承受历史分配给这一代中国人的时代曲折和担当。

冷静沉着，进退有据，中必赢！

现在有 种观点，老川誉的芯片公司如果不把产品卖给某大厂，芯片就卖不掉 了，就会亏损了，滴若不已，急得直跳。这种思维并不理性，某大厂也就是这十平多年多买了一点，人家原来也不靠你。真正需要芯片的，不是某个厂，而是消费者。
