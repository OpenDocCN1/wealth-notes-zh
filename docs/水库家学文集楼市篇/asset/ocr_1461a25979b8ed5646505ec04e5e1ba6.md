# 一文钱逼垮英雄。

如果你将来买房，首付加贷款，到顶也就是 500 万预算，那么你很难买得起 550 万的房子。一个家庭要想多凑出 50 万，几乎不可能。多揍 20 万都不可能。现在都是小家庭，大环境下整体储蓄也不好，谁会借钱给你？

现在的银行体系，要求月供是收入一半，这在十年前是合理的。现在，你家月入六万，归还四万月供是正常的，但银行不认，你无法多贷款。综合计算，贷款 400 万是正常人的上限了，打工族很难做出更高的收入流水了，除非银行故意配合你，目前较难。

贷款 400 万。首付能够拿出 300 万，已经阔过 95%的上海家庭了，除非是老人卖老房，和你挤二居室。你愿意？凑了 700 万，相当于中环线 95 平米。这就是 985 佼佼者被优势前途了。事实上，90%的 985 毕业生是达不到这个水平。更多的是，住在马陆九亭周浦，内环线上班，每天上下班接近三个小时。
