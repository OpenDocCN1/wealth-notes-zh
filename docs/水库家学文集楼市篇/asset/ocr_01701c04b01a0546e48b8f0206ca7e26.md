# 西欧发达国家的老百姓生活状况

> （美国的复杂一点，以后再说）

说好的平等自由富裕，市井语言是呢吃穷吃。发达国家的人也不是神仙，他于的活不一定比我们强多少。人口低于一亿的发达国家，有个显著特点，通过高税收建立起一个高福利的国家，就像是以前的天国全。

英法德等国，年轻男女谈朋友，不太强调金钱。不是他们不爱钱，他们都爱钱，实际是没钱，大家差不多的，富二代不是特别明显。外国人家庭普遍是子家庭。你家住别墅，我家是公寓，但这个区别，经过遗产税和多子女的冲淡，最后差距就不大了。

以-一个英法公务员为例，类似于我们的正科级吧，收入大致是3000-4000欧，老婆在公司里当个职员，2500-3000欧左右，可以维持一个体面的家庭。-一个大众欧雪诺低价小车，养两个子女，买套郊区小别墅或者小城市的市区小三层，每年两次出国旅游，相对于上海到安徽吧。

他们没有什大目标，发大财是不可能的，高税收，导致所有人只想上班，不想做生意。他们把主要精力放在个人兴趣，职务升迁。例如园艺，钓鱼，做糕点，装修，跑步，在单位升个官，升个职称之类的。浑浑噩噩一辈子，退休后，喝咖啡，喂鸟，瞎聊天，唠唠叨。

父母与子女关系。西欧小城市和中国人也差不多。奶奶带孙子，是普遍情况。但是，英国和巴黎放这种大码头，个人的迁徙剧烈，相对少一点。西欧国家很小，亲情是一点。

饮食，这一点真是太惨了。富豪宅区，都是吃牛排，喝鱼汤，只不过你的牛排可能是英国的，我的牛排是罗马尼亚的，我是吃不到区别。

穷人和富人最大的区别是，服装。西欧的穷班上班，大多数是做公交车地铁，所以，他们不可能穿豪华的服装，大多数上班总是买普通的普通西装，女的穿羽绒服带丝的到处都是。富人不需要上班，出门就有车，男的穿豪华西装，女的半妆小西，风度翩翩。

交通，伦敦巴黎这种一线城市，上班族家里都有车，但是上班不开车，因为停车太费钱了。小城市上班族，开车多，停车相对方便。富人家里都有豪车。

周末，穷人家孩子，穿个像模子长袖体恤，街头闲逛。富人家孩子参加各种兴趣班，带好各种装备，穿上种特服装，网球，篮球，橄榄球之类的。看上去，很幸福的样子，其实也无聊。
