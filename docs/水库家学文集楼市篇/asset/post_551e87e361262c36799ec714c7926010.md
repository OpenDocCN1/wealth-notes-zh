# 羊毛推出了新高度

解密大城市房产中介爆炒租房源的隐秘原因：羊毛推出了新高度。

房产中介领域，传统上是以买卖为第一业务，出租房是给新手练练口才，熟悉环境的，中介老鸟一般都懒得带租客看房了。但目前，京沪二手房买卖基本是冷冷清清，严厉限购限贷后，还有房票的人不多了，就这么点潜在购房者，注意力全部在新房市场，盼望买限价房，捡便宜货。持币等着每月开大奖，对二手房不感兴趣了。

中介是直接饿慌了：没买卖业务了，怎么办？持币等待的转租租房需求越来越大了，多少也是个进项，别的也不干啊，那就搞出租吧。以前看不上出租业务，现在没办法了。

世界上最怕的就是认真二字。中介公司是搞大数据的，聪明人一大堆，分析一下就懂了，京沪可出租房源是越来越少了。这等于发现新大陆了。

房产买卖中介，虽然利润高，但很难做，中介投入的时间精力非常大，经常打电话到半夜，还要协调夫妻矛盾，家庭矛盾，邻里纠纷。购房者倒是慢慢悠悠，不看几个月和三十套，绝不会下单的，下单之后，也有一大堆难事，麻烦的很。租房就简单了，只看一次就成行了，半个月能搞定。给钱，拿钥匙，滚吧。

京沪一套 600 万的房子，买卖中介收费 12-15 万（还要还价折），租金行情是 6000~7000 元，一般是中介收费 5000 元左右。表面看，出租 20 套，差不多等于买卖 1 套，以前确实没什么积极性。但是，中介公司在大数据的支持下，这次玩出了前无古人的新高度，利润率直接提高了十倍，堪称巅峰之作。

长签五年。第一年扣除三个月租金，以后每年扣一个月。五年扣了七个月，去掉清洁和简易装修 20 天左右，中介实际上手得到了 6*6.5 个月的租金。

1. 按照 7000 元的月租，中介收入就是 4*5 万了。
2. 大部分租客可能提前走，拖后退，走一走可以罚款 1 个月，没收已付租金几个月。违约金原来是房东的。

新玩法开创了新思路。中介公司可以在一套房子里反复搞羊毛，收到 7-9 个月的租金。那么，出租 2 套，接近买卖 1 套。这个新发明，已经足以颠覆中介行业的思维了。京沪的出租市场一直是很火的，不愁房客，基本不会有空转期，而且也很省力。十倍利润模式了，这就是租房市场突然大爆发的隐秘原因。

建议：有关部门严格管制租房价格，严厉打击不法炒作，要让外地人开开心心在京沪生产生活。（凌驾上司前，是我一生的痛点）

# （一）一套福利房和一套商品房

京沪老居民家庭拥有两套套房的情况，我是非常熟悉的。这些家庭主要是一套福利房（置换成为商品房），另外买了一套商品房。这里有个非常隐晦的背景。

2. 福利房分两个前提：已婚，工作至少三年，大多数是五年以上。

结论 1：省福利房的二套房家庭，子女接近婚龄了。京沪近五年的房价，正常家庭绝对买不起全款的，大多数是卖掉福利房，再贷款买婚房。

福利房的特点是：老破小（55 平米的二居室），噪音大，没有隐私，没有绿化，小区脏乱差，楼道黑乎乎，但地段好，学区房。京沪年轻人从小到大住这种房子，已经是忍无可忍了，一般情况下，京沪年轻人婚房一般不会买这种老破旧，太丢面子。但这类房子现在超级抢手，为什么呢？卖给外地精英了。你去看，上海陆家嘴，北京牛车记的老破小，单价十万，超过纽约了。

外地精英喜欢什么？上班近，学区房。外地精英基本是读书出来的，超级看重学区。外地精英工作难度大，天天累得像条狗，很看重上班近。京沪老房子，大多数卖给了这些外地 985。

结论 2：外地家庭限购一套，所以不可能出租的。京沪居民卖掉一套老房子，出租市场就少一套房源。

# 巴黎房价为什么平稳？

我用北京的概念来解释。

巴黎分为两个圈：

小巴黎，就是核心区，你能够想到的巴黎浪漫，都在三环内。城市圈心，大致是巴黎圣母院和法国老皇宫。在三环外；巴黎人进城也叫“去巴黎”，类似于现在北京郊区的说法。

大巴黎，那就海了去也。我估计相当于北京七环（我没到过），至少包括燕郊和大厂广汉。据我目测，六环外基本没有高层，小别墅和四层楼居多，绿化非常好。

大巴黎的人进城上班，基本不开车，地铁轻轨公交车。中午吃个披萨，3–4 欧。类似于北京炸酱面或者马兰拉面。外乡人，日子幸福，汽车别墅，空气新鲜，工作压力不大，钱也不多，就是时局感差一点，外乡有点土里土气的。

# 房价代表高薪岗位和福利，巴黎不能和北京类比。

1，高薪岗位。巴黎和北京类似，越是市中心，好单位越多。

2，福利。法国的福利是全国统一价，不存在高考分不同，医保不同，车牌摇号，买房限购，所以外地人对于是否挤到巴黎去，完全是上班远近因素，没有什么其他利益。

3，学区房。巴黎的名牌小学，是财力大比拼，家长学历单位，住房情况，孩子面试成绩，高昂学费。北京学区房的概念是不存在的。

4，外地孩子读书，都是就近读书，普通学校，没什么麻烦。

观点：巴黎房价不存在额外利益，供求关系基本平衡。北京房价捆绑了社会福利，孩子读书，供不应求，价格上扬，引发了投资需求。

对策：我说了也不管，就不说了。

# 法德的房价为什么平稳？

因为他们经过了几百年的自由迁徙，早就完成了人口大流动。现在，法国各城市的人口，基本比较平稳，有进有出。例如巴黎，外省年轻人去追求梦想，中年外地旅客离婚，基本保持了一个平稳，不会出现二十万一平方米的事情。德国完全是一些小城市，柏林并不是大家都想去的城市。

京沪的无户无定居，是在 2005 年以后爆发的，才短短十几年，还远没有达到进进出出平衡，如果不加以遏制，实际人口肯定是远大于出。市区的土地和容积率是不可能再增加了，人口越来越多，住房要求越来越高，有关部门在楼市里获得了巨大利益。土地财政，应运而生。

房住不炒，降低房价！

# 解决高房价的治本方法

1、打掉投资需求。让开工的小老板有钱赚，比买房好。
2、打掉居住需求。没有户口的，暂时过几年苦日子，一律回老家。
3、打掉货币增发。没钱了，我看你怎么买？
4、打掉财政利益。土地款一律转给医保金，社保金，专款专用。
