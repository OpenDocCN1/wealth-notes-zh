# 葡萄到了市场经济，居然变甜了？

我小时候吃的葡萄，都是父母厂子里发的福利，先是计划指标，买是公款指标，最后发到我家。

但我从小就不吃葡萄，因为实在是太酸了。

我一直认为葡萄是酸的，只有孕妇才吃。

市场经济后，我也坚持不吃葡萄，后来有人劝，我勉强吃了一个马陆葡萄，居然是甜的。

怎么可能呢？葡萄到了市场经济，居然变甜了？

# 人民币的意义

我表弟的老婆的嫡亲，四川某县的退休老太，工人编制，一辈子省吃俭用攒了十几万。

这钱攒的不容易啊，以前工资低，都是买最便宜的肉，最打蔫的菜，一天几毛钱，几块钱攒出来的。

五年前，这钱可以买套本地二居室了，现在也就是旅游几次，吃几顿好的了。

她说，这辈子最后悔的就是存钱了。

他孩子小时候基本没吃过什么好东西。老太婆说起来是满含泪水
