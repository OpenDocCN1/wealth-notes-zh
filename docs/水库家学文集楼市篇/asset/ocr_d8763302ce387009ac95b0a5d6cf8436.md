# 很多财经小编有极度愚蠢的想法

很多财经小编一直认为：京沪房价那么高，就算工资三十万一 年，要存多少年。这批人买了，以后房子卖给谁？这是极度愚蠢的想法。

我再说一遍：京沪房产证不是消费，就是个存折。

存钱没有先后。存的早，利息余额多，存的晚，利息余额少。

现在买房的，除了置换，还有产业资金和其他你懂的资金。例如收了那么多的医疗回扣，除了买房，还能怎么办？

# 房产税的经济学意义

房产税征多少是个关键。如果是象征性的几千块，没什么争议。我们主要讨论，京沪如果开征 1% 左右，也就是每家 6-10 万元，会出现什么情况？

+   1，高婚端是不可避免的。除了等十年办北京户口 的，其他家庭的结婚费每年需要支付 6-10 万年检，那是不可能承受的。
2，中国制造，创新的事情先放一放，直接搞最便宜的商品。中高端内需，主要是中产阶级在购买，而这些中产阶级又 是房产税的承担者，如果这些钱全部拿去缴税了，国产中高端日用品和生活支出基本枯竭了。制造业失业，指日可待。
3，制造业失去的岗位，要靠 m2 买单。中国是不能有大失业的。央行可以立即开工几条地铁，高速，桥隧，分分钟就解决失业了。
但是，m2 就越来越大 了。怎么办？京沪首套房房价飙升是完全是可能的。
4，房产税会带来加 剧管制，售楼小 姐站在地上求你买一套？不可能的，房产税每年 1%， 十年不过是 10%，比起京沪十年加 个零的涨幅，算个球呀！
