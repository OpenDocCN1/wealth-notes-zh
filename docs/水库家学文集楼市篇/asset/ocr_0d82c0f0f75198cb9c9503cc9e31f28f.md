# 房价，是其他问题的反应

要跳出楼市看楼市，其他问题不解决，房价问题只是暂时一下，尚未在机制层面彻底解决。

没有人喜欢高房价。就算是富人，也不喜欢高房价。现在是五百万买个二居室，如果可以再赚  个别墅，我肯定更高兴。房价涉及几个问题：

+   一、财政。如果财政可以不依靠楼市，那么，我们有很多办法可以解决遇到的各种问题。但是， 开辟如此规模的新财源，谈何容易？财政支出是刚性的。你说减哪一块？

+   二，人口。主要问题是单向流动。郊区去市区，外地去京沪，县城去省城。这种流动是单向的， 只进不出。京沪的人口，基本不出去。外地人口，源源不断进来。为什么京沪人不出去，因为 不能交互。

+   三，货币。人民币货币总量 m2 已经超过美元了。人民币国际化还在起步阶段，人民币对应的 资产，主要在国内容。那么，有什么东西可以替代房产，成为人民币的依托？如果降低 m2 幅度， 农民增收怎么筹划？

我才疏学浅，思考了几个问题，希望各路专家群策群力，一起为经济建设加油助威。

# 观察楼市大行情

不能只看自家门口。

楼市关乎国计民生，政策性强很强，是经济领域的重要内容。与此同时，楼市又有自己的特点， 各种回暖和控制政策是各地发布，这就产生了一二三线城市的政策时差差，创造了预先观察的窗口。 专业人员可以通过各地区政策走向的汇总，认真学习，积极领会有关部门的大意向。
