# 如何抢银行的大羊毛？

很多银行小行长看到了，肯定哈哈大笑：你个臭屌丝，还有本事指使我们？大姐姐，你先别笑。我这么多年就是抢银行。当然，我不是抢银行的现金，而是抢银行各路专家的智慈成果。

银行是社会上最聪明厉害的公司。倒不是银行那七个屌丝专家多厉害，而是银行掌握中国经济所有的秘密数据；我们不知道的，或者不说的，他们都知道。这就带来一个结论，银行最清楚中国经济的走向。

宏观走向，在天上飞，对我们普通人没什么实际意义，真正落地的是抵押物标准。这个标准的制定，是银行各路专家几十年经验智慧的极大成果。我们通过研究抵押物的门槛、门类和折率，基本就找到了各种商品的价格趋势。

举例，现在银行一般不愿意接受个人所有的商业办学学校抵押了。我们马上就知道，这玩意废了，赶紧扔掉啊！银行最喜欢的是个人住房，京沪深广，省城中心。这就对了，你银行喜欢什么，我就跟什么。

我就自觉自愿的和银行捆绑了。你银行别不怕，我怕什么？
