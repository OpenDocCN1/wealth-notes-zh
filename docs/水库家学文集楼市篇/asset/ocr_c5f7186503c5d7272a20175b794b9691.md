# 买不起房子的京沪屌丝是如何助推房价的？

一是租房需求火爆，租金源源不断涌进楼市。有钱人买房出租给屌丝。屌丝1/3收入，交了京沪进场费，房东一边收租还贷，一边等房价上涨，两全其美。
二是买房带来的阶层提升感，导致信用无限大。有了房子，丈母娘高看你一眼，小美自瞄自欢喜。学校招生，单位招商，都是加分因素。居委会也会对你高看一眼，尽可能不找你麻烦。就算是外国旅游签证，有房的，优先通过。因为无房屌丝默默承担了各种痛苦，导致人们对无房的忧愁，京沪住房的需求越来越大。
三是2-3%的优质屌丝，通过节衣缩食，买下了京沪房子，成为老家村里的骄傲，父母脸上增光，左邻右舍羡慕，进一步刺激了潜在需求。
