# 莱莱：感慨

张里骏：像这种地方的东北县城，没什么加工生产制造业，确实像柴总说的一样，人才都被吸走啦。以后人口肯定越来越少。和公交公司的负责人沟通，以前一台车能拉七八百的乘客，现在就三四百。一方面是私家车地多了，坐公交的少了，另外一方面也是因为人口在不断缩减。晚上吃饭的时候，对面的桌上，正好坐了一对父母和一个穿着校服的高中生。闲聊显示，高中生是这里一中的学生，真是感慨万千，等到 5 年之后，他大学毕业，大概率的可能他也不会再回到当初送走它的这个小县城来安家置业了吧。这就是无法解答的东北县城发展困局。

# 大城市 vs 小城市

Saüternes-si 在张接住了两个月，彻底爱上了四线旅游小城市的生活。住在全市最贵的小区里（房价 6000 一平），靠近国家湿地公园，天空不时有候鸟飞过，房子前后大湖，小区绿树成荫湖泊成片，每早打开窗就是湛蓝的天空，傍晚是绚烂的晚霞。周末准门就带孩子到大自然里散步，每天逛一个公园一周都不够用。回到天津后各种不适应，天气热、楼屋高、天暴得旱、蚊虫又多……宝宝成天被困在家里，出门也是车来车住、雾霾漫天……都说大城市容不下肉体、小城市放不开灵魂……我突然有点想做没有灵魂的人……
