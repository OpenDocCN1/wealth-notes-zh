# 为什么京沪广深买房

会成为大学生的沉重负担？

这个问题貌似很搞笑，但背后是深刻的经济制度原因。

+   1．城乡剪刀差，京沪孩子考不上 985，父母正常，买房不是特别吃力，因为老房子卖掉就是首付，配上 30 年按揭，挑一套明光亮敞的小三居，够得到。

农村 985 就闹大了幕了，父母的农村房子，价值为零。差一个首付，就差一辈人的奋斗，这怎么赶得上啊？

+   2．地区差距大。我老家是成都或杭州的老居民，虽然穷了点，拆迁政策好，那套房子也有两三百万元，如果卖掉成都房子来过来到京沪，也可以凑合过过。

你家是湘西，湘聚或三明的，那就郁闷大了，就算卖掉老房子，也没多少钱。进退两难。

+   3．配偶差距大。人家深圳拆迁款，虽然丑了点，黑了点，瘦巴巴的，但是陪嫁多啊，自带光环。你对对象是县城二本妹，还互相嫌弃。你说气人吧？

# 京沪广深大城市的房子，

将来一夜变大煞？

上海，自清末开埠，历经了封建王朝，殖民，北洋，军阀混战：民国，汪伪，日据；工商业改造，什么制度都走过来了，但从来都是住房紧张的。

八九十年代，大城市住房紧张矛盾达到了难以忍受的地步。合法夫妻要偷偷的到小公园草地上，才能挤打一枪，还可能被联防队抓起来，手电筒跟踪，带所里盘词。为什么？没房子啊！

98 房改时，内环地边缘的新房，单价才五千元。现在什么价？你心里不知道吗？大城市早就没有炒房了。限购两套，父母一套，子女一套。今后二胎了，住房紧张的矛盾，就在眼前了。

与此同时，货币怎么样了呢？我妈是大陆企正式编制，辛辛苦苦一辈子，到 2000 年才存了十万。要不是她买了房，现在肯定哭瘫在地上了。

我一直反对炒房，非常反对。我是希望你懂点市场经济规律。

时代的洪流，浩浩荡荡，历史的车轮，滚滚向前。任何意气用事，都是可笑的、随大流，往前走！
