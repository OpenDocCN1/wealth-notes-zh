# 一线城市和三四线城市的区别

如果从房屋外观，城市面貌，消费水平等方面看，北京上海和西安差距的差距，几乎没有。一线城市和三四线城市最大的区别是你看不见的离端岗位。上海北京聚集了中国最优质的企业，他们提供了非常多的高薪岗位。

小地方大部分普通单位也就是 3~5000 块钱，上海低于 8000 块钱工资的男丁，都是骑驴找马，先在这里综合凑合，上班时间也在 51job 上找工作，一且有会机，立刻在单位请假去面试。一般 1 万块钱以上，才可以勉强的接受。15 万以上，才基本踏实。

我去过很多二三四线城市，例如杭州西安驻马店，我的感觉是吃喝玩乐，买车买房区别都不大，最主要的就是新岗位缺失。例如，杭州和上海，同样一个注册会计师，杭州的工资大概是上海的 75%，西安可能就 60%，驻马店能达到 40%就不错了。再往下，这个职业就找不到工作。

很多人说，我在小县城很舒服，一百块钱请一桌烤串，夜啤酒泡起，上班十分钟走路，为什么去大城市？奥秘就在于你的现金收入。

# 为什么天津会这么热？

因为北方的大城市就两个，北京天津，其他都一样，青岛勉强第三。如果北京是 100 分，天津 65 分，青岛 60 分，其他的你随意，反正就那样了，西安济南石家庄，太原洛阳平顶山，你要咋算咋算，没什么意外惊喜的。

这次天津作为北方 top2，把户口门槛拦到了地板价，其他城市基本没有什么吸引力了。山东河北河南这种高考参考型的户口，我是真没什么大兴趣。
