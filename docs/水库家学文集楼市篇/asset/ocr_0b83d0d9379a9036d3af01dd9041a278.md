适合赚钱，小城市只能是度假，连养老都不行。

# 一，基础建设，完全一样。

小县城和大城市，几乎一样。Wifi，高速公路，网购，漂亮的小区，应有尽有。

# 二，商业环境，天差地别。

小城市的人口基数不大。内地县城最多也就五万人顶天了（不包括农村），只有大路费才能生存，因为大费货的价格低，销量大。这些地方，我没有找到一家像样的蛋饭店，可以达到上海的一般水平。

这就导致了一个明显的结果，任何高精尖的东西都活不成。因为没有需求。在京城，人均三百元的馆子，遍地都是。在小县城，一般人均 50~80 元的饭店就算体面了，贵贵的，全城也就 1-2 家了。（旺季专门招待游客的不算）。在这种消费基数下，无法产生多少高薪岗位，主要就是一条街里的几十个老板娘而已。

# 三，医疗教育，差距较大

医疗，主要是大城市医生不愿意来，设备不全。中小学教育，更多的是，优质教师流失。养老都不能生病。

# 四，体制内外，差距较大

在县城，如果熬到一个体制内的好岗位，例如医院中层，县一中的教师骨干，大单位里带个长，确实是体面，福利待遇好。房价便宜，买车用车方便，上班近，熟人多，时间多，只要不出大麻烦，生活是舒适的。

体制外的，大概是 50-100 个成功的老板，例如建筑队老板，专卖店老板，火爆餐馆的老板，各行各业的孤儿么吧。

各行各业的普通人，例如晚上八九点下班的营业员，工资 3000 元算好的了。大多数人干这种工资，家里很难有多少存款。你家千万别遇到什么花大钱的事情，给孩子去省城买房？想都别想了，真傻缺。

# 五，县城创业，问鼎艰难

县城的日常需求，以大路费为主，总量固定，利润不高。

县城里，商用级别的需求，总量不多，甲方就这几家耳熟能详的大单位，少数大商户。县城是人情社会，长期老关系。在没有新增大需求的情况下，你要想挤进去，必然要把其他人赶出来。举例，我是建筑队的，做了几十个工程了，新公司很强势市场，包括后期借款。

县城里最有效的创新，可能是饭店。你要是菜品好，倒是真有客户了。

# 经济结构的扭曲

在一个经济体里，房地产应该是建设水平的行业。图纸是复制的，施工是半文盲，质量乱七八糟，经常出人命工伤，但是这个行业却因为光彩夺目，富家辈出的行业。

制造业本来是最伟大的行业之一，你在一块石头里提炼出了金银铜铁，变成各种产品，满足了各行各业的需求，创造了外汇储备，世界第一，经济增速，世界第一，一系列的伟大成绩。但是，制造业老板现在是什么情况？

一群背负原罪的人，理由都是现成的：税务工高，安监质检，环保清所，劳动纠纷，我不得已你这个工厂，干了几十年，找不出一个下岗子来？叫上记者，一锅领照，黑心老板一大堆，也是分分钟的事情。一大群原丝悬着劲在这等这个时刻呢。
