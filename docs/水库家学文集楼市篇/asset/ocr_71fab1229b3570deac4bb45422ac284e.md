# 2019 长三角楼市的趋势思考

+   一，上海回暖在即（没说谎，不要揍我）

我们即将迎来 825 限购政策三周年。当年被挡在门外的那股长三角力量，陆续进场了。再加上本地需求，还有一直等着捡便宜的社保旁友。三股力量，实现合流。

+   二，南京杭州苏州合肥，平稳为主，可能出现二手房难卖

上海楼市的中低端产品，现在 400 万左右的房子，购买人群主要是长三角的优质青年。这批人在当年 325 政策后，被迫转到长三角的四大城市，也就是老家省城。2016 年，这四大城市，不限购，房价是热的说法没了。现在要买房了。出来混迟早还。

+   三，时间节点

我估计五一前后，上海楼市的回暖态势，将可以得到确认。长三角四大城市的抛售会明显增加。

+   四，不确定的因素

长三角四大城市的新增需求和拆迁力度，能不能接下当年 325 的那批置换盘？

小建议，杭州南京苏州合肥，五六月份可能会出现少许急售二手房。因为上海的行情不等人，你若是不急，多看多看，说不定能抢到一条活鱼。

# 去上海挤个老破小？

问，有人会卖掉杭州南京苏州合肥的四百方的豪宅房子，去上海挤个老破小？

答：你误解了。2016 那一波四城狂欢，只不过是钱钱移动而已，当年叫做上海楼市外溢效应。这些钱本来是没沪工作的长三角青年人准备在沪买房的钱，只不过被 325 踢出去了，两年社保聚五年，一夜之间便聚了。

因为考虑到保值增值等各种因素，不得已到四大城市买房，很多人为了保住首套资格；可能是用老家父母名义买的。三年后，这些人基本还在上海，在陆续获得购房资格后，就会把四城市的房产置换出来，到上海买自住房。这个时间点是今年五月份开始。

那些杭州本地居民，不会卖了房子来上海的。
