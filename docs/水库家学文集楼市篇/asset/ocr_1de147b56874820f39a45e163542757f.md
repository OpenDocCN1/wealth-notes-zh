# 现在的经济两难局面

京沪广深，经济条件最好，就业率最高，工资最高。类似长春，驻马店，遂宁这种地方，经济结构单一，就业弹性不足，没关系的年轻人很难找到月入八千或一万的岗位。怎么办？

一是让小镇年轻人自由流动到高收入地区，实现收入翻翻，但会刺激京沪房价飞起来。

二是采取明目的堵的办法，不鼓励年轻人去京沪广深，降低京沪住房需求，压住京沪房价。但年轻人在小地方趴窝，收入上不去，也难啊。

三是加快建设区域性中心城市，例如武汉，成渝，太原，沈阳。但这是慢功夫，至少二十年的周期，年轻人等不下了。举个例子，上海的一南一北分别是宝钢和金山石化，超级特大企业啊，但搞了三十年了，至多是市区的六七成水平，这说明人为的形成区域中心，是非常慢的。

今后，经济格局会怎么走向？你自己下注了。
