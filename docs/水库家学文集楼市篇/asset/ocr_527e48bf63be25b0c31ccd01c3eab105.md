# 杭州-第五城市地位

杭州落户细则出台，毫无争议的内地第五城市地位，即将确立。

杭州是省会，省内独一无二的地位。

苏州是省内第二名，地级市。南京的民营经济，互联网，商贸中心地位，比不上杭州。苏州截胡了一大半的东北资源，苏锡常资源也是往苏州靠拢。南京能够争取到江苏的一半资源聚会，就不错了。当然，南京是安徽副省会，也还有点优势。

深圳广州杭州，快速落户后，合法买房是很容易的。内地最难进入的，只剩下两个堡垒了，京沪面临尴尬。

+   1. 如果户口不大放量放松，杭州房价三年后接近京沪的可能性是极高的。

+   2. 如果松口子，瞬间挤爆。实际在沪的外地人已经有 800 万，北京大概是 700 万，再加上配偶，子女，源源不断进来的应届毕业生，简直是天文数字了。

未来的五三年，地县市的产户以上家庭，会随着子女大学毕业去外地，卖掉本地剩余房产，大批量进入广州深圳杭州苏州南京，与此同时，普通地级市因为高考的抽水机效应，人才，资金，美女被源源不断的抽走，这场面真是难以直视了。

【杭州大专落户新政官方细则出炉：35周岁以下、缴纳一个月社保即可落户】5月29日，杭州市人才服务中心发布《杭州大专落户新政官方细则》，明确给出非杭州大中专毕业生落户办理指南，大专学历人才引进落户需要满足两个条件：35周岁以下、在杭州工作并缴纳一个月社保。

【民生研究所】近日，浙江官方公布发布了大专落户杭州办理指南，文件显示，只要是35周岁以下并在杭州工作并缴纳一个月社保，即可办理杭州户口，落户后可享受杭州人才、教育等政策。
