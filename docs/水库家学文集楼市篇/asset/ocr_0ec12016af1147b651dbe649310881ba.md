+   3，拆迁户很少。因为还有一部分自贵购房的指标，假设你们家安置面积是140平米，但是没有那么多，正好好几套房子凑起来是140平米，可能是163平米，那么国家就给你一个自贵购房的指标，140免费，自贵23平米，拼成三套，父母，子女，孙学辈，都至少有一套房子。

# 二，费市安置

实物安置好处很多，但有两个缺点

+   1，拆迁房地权偏僻。如果我在市中心好单位上班，搬到偏僻的地方去，就没法上班了。举例，我们夫妻两个在黄浦区某机关上班，拆迁房在嘉定或者松江。我就没法上班了。于是，拆迁部门给你发一张支票，只能在本市使用，你可以自己在全市买房子，离单位近一点的。

+   2，拆迁房没有杠杆。拆迁安置三套房，价值是600万，如果我给600万现金，我再去贷款，我就能买1000万的房子。按照近几年的增值速度，1000万的增值肯定是高于600万的，富裕家庭就愿意选择费市安置，追求高收益。

# 四，商品房库存遇到了拆迁安置，产生了奇妙变化

这些年，各地商品房建得非常多，在大城市的像远处或者是地级市，县级市，商品房卖得不好，导致土地也卖不出去，恶性循环，经济发展就慢下了。于是有关部门就采取了新办法，把原来建设动迁房的资金直接发钱给拆迁户，让他们去把市场上的库存商品房买走，这也是楼市去库存的一个办法。

实际情况走样了。拆迁是集中发钱，这个地区一共拆了600户，每户大概可能买两套房子，那市场上就会出现1200套房子的购买需求，如果加上贷款，可能会出现1800套的需求。拆迁户往往有个特点，就是喜欢在老地方聚集买房。

当一个区域集中跑来上千家万户买房的需求，而且全部是现金，那么开发商就要躺着坐了，涨价就开始了。城市房价有比价效应，当一个地区的房价开始涨，其他地区也会跟着上涨，而拆迁大部分也是四面开花。这就导致了一边拆迁，一边涨价。拆迁户倒是没什么，涨了更好，增值了，但是，靠工资收入买房的人就倒了霉了。杭州是比较典型的一个地方。

所以，现在调整了。

# 年轻人怎么赚钱？

+   1，做小生意，是非常挣钱的。做大生意，往往不太赚钱。因为大生意环节多，你层层授权，手下层层捞好处，你很难管。

+   2，不要做那种你一看就懂的，例如坐在柜台里卖首饰，卖衣服之类的。这种生意烂大街了，赚钱难。

+   3，稳赚钱的小生意，是10%的技术（动脑部），20%的风险，加70%的体力，需要到处跑的那种生意。

+   4，实在没办法了，开滴滴，月入万元是有的。有个驾驶员住在浙江嘉善，每天的第一单生意就选去浦东机场的，否则不出门。到了浦东机场之后，专门接同一单互联网的生意。当中可能有几个小时空档期，他就在上海跑几个小单，有就干，没有就放弃，月均1.2万。

+   5，小生意一般是年销售额200-400万，需要一点点技术经历的，至少对几个月内模仿不了。

+   6，小生意的渠道，都是小圈子里的。例如你做运某个小老板的小助手，小打工的。然后单干。

+   7，我不可能教你具体生意的，因为人就算做你自己都不干，但这个思路是对的。

结论：寻找一个适合自己的小生意：技术风险为辅，体力活为主，期望利润可以定在30-60万。
