# 经济学上有个概念，预期

网购模式扩大了东西部县域财政的差距，楼市及时的填满了差距。

一个县城的财政收入，主要是工商业。工业是老大难，很多县城除了几个糖厂化肥厂塑料制品厂，基本没什么知名品牌。商业一直是老花旦，现在情况变了。

网购主要销售快消品和生产，销售已经巨头化了，主要集中在北京和杭州。生产主要集中在长三角和珠三角，这也是老牌的大用品生产基地，这种格局，对中西部县城的财政影响是比较大的。

一是大商业凋零，大城市居民对县城不了解。其实每个县城都有2-3家大型百货公司，多是省城或大型百货公司的分支机构。原来是大商业的绝对霸主。现在是每况愈下，工作日里，门可罗雀，营业员比顾客多。

二是商业街凋零。县城都有小商业街。各种专卖店琳琅满目，也是基层七姑八婶的最爱。但是，现在商业街也越来越差了。除了及时消费吃喝，百元东西都网购了。

三是就业趋紧。县域商贸，是就业最集中的领域，但受到网购的巨大冲击，除了运输业火爆，其他岗位也越来越差了。营业员工资两千多是普遍情况。

四是商铺贬值厉害。除了一些餐饮业，其他商铺难于难。

与此同时，县城现在的财政实际上是越来越好了，县城教师工资也较高，每年8-10万是普遍情况，再有副业的小收入，在县城还是很舒服的。那么，钱是哪来的？楼市+基建。

很多县城没有知名品牌企业，区域批发中心，火爆的本地百货大厦，高新技术企业，最大的财政收入是基建和楼市带来的，一个住宅小区，几个亿到几十个亿的产值，足够开发票，远远比什么商业街一条街道多了。

2015年的楼市去库存，主要原因是县城有大量积压的房地产，导致银行压力山大。棚改政策很成功，县城库存基本卖完了，县城财政很紧张。但是，接下来，我们会发现一个怪事，本来因为卖不掉才搞了一个棚改，现在库存卖完了，接下来怎么办？据目测，很多县城还在继续建楼盘。两年后，这些房子卖给谁，怎么卖？

答案是不言而喻的，经济学上有个概念，预期，如果预期好了，什么都卖的掉。那么县城的预期来自哪里？肯定是上一级城市也火了。层层传递。
