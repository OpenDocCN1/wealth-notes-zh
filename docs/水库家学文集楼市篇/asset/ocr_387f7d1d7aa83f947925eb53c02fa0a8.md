# 你一年赚多少钱？

大部分人经常会被熟人问到这个话题，最多是问法不一样。我一般答复是30-35万。我是经过反复推敲的。

一，说少了，人家看不起你。我的朋友大多数是在单位里，一年18-25万。我出来了，总要多一点。

二，说多了，人家恨你。你凭什么赚很多钱？不玩了。羡慕嫉妒恨。

三，防止别人找你借钱。一个月三万不到，扣除房贷车贷，孩子补课费，也没钱借了！

四，贴近基层。我周围大部分人的收入是在90万以下，但也差的不多。你比人家稍多一点，人家也喜欢认你个朋友。人总是喜欢和比自己略强一丁点的人玩。

五，遇到土豪，没人问我这个话题。
