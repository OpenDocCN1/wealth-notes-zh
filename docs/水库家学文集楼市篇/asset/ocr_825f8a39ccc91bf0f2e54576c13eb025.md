# 楼市的小秘密

新房满二，实际上相当于二手房满五。因为实际起算日不同。

满二年五年，是产权证日期（交易税期）为起点。这就造成了新房和二手房巨大的差别。

+   1，二手房，2017年1月首付后马上可以过户，2月份就拿到房产证了。2019年2月，就满二年了。

+   2，新房，往往是交了首付数后，要等两年甚至三年，才能办理产权证。然后再起算日期。举例：2017年1月首付，往往是2019年8月才开始办证，到了2021年8月，才满二年。实际上接近五年了。

这对于今后有改善置换需求的上辈而言，成本巨大。

结论：二手房时间成本低，相同时间内改善置换，税费可能显低很多了。
