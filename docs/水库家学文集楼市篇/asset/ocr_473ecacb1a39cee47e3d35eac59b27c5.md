而我是这样想的。我就是个普通人，我的目标就是给孩子铺路。现在这个价格，我够得到，我就坚决上。就算今后几年吃吃苦，我也认了。我苦亏了，孩子没吃苦，将来白得了一套中环线的漂亮房子，多好啊。说白了，就这 m2 的架势：十年后，大家都是大赢家。你考虑那么多干什么？

# 325，往事并不如花似玉

当年，我接到一个咨询，我和他都直接弃疗了。他是外地人，325 之前卖掉了一套房子，准备置换婚房。他社保断断续续的，只有两年连续记录，本来是符合政策的。但是 325 一来，他卖掉了房子，却不能买了，直接傻眼，嗷嗷大哭。

我当时没有回复他，那种情况下，任何安慰都是虚情假意。但我内心是翻江倒海的，这个朋友不知道现在怎么样了！老婆是不是跑了！

历史一瞬间，人生一辈子。买房不能拖。

# 在买房决策上

随大流，最安全。

房价是所有人共同决策的结果。我们是十几亿人的大市场，占据了人类四分之一的人口。具体到某个城市，大家都想买，就上去了，大家都不买了，就下来了。你个人因素的作用，犹如大海里的一滴水，微不足道。

和中国经济结构一样，楼市也存在一二三线的梯度结构。每一个层次，决策汇总的结果是不同的。这一点，需要仔细分析。

但是，个别人哗众取宠，故意反着说，是拿你的痛苦开玩笑呢。有些专家超高，无视普通人的切身利益，为了出风头，语不惊人死不休。她或他已经有了好几套房了，却嬉皮笑脸的安慰你：不要买房子，经济不好了，以后可以捡便宜之类的。这种人内心并不善良。

# 住房是正常家庭最大的需求

不考虑什么短期利益，这是一家老小的生活必须。

京沪外地家庭，连续工作五年才能买一套，房票金贵，来之不易。与此同时，持续严格的监管之下，京沪炒房情况基本杜绝了，这一点，有关部门功不可没，值得赞扬。

任何家庭，有条件就买，实在没条件，也可以考虑做攒租，男女平等，从我做起。长期租房，并不是什么好办法。人心都是一样的，个别人就不要逆着良心的乱吹了。你见过哪个牛逼的家庭，子女在北京租房的？

建议在大城市的年轻人，留出每月的基本生活费，再留几万元应急费用，全家老小紧搭房子，必须上，坚决上，毫无保留地上。任何谁气的话，不听，任何你需苦逼过问的人，拉黑。一心一意谋发展，聚精会神搞装修。

大风起兮云飞扬。时代的洪流，浩浩荡荡，历史的车轮，滚滚向前。随大流，跟上去！
