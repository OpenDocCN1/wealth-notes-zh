# 全国楼市看武汉！（2017.12）

倒不是武汉有多重要，而是武汉无锡宁波这城市，正好卡在调控分韵线上！

举例上一个周期：

+   1，上涨期：一年多。接近翻倍时，炒房客正兴高采烈，突然来了一记大耳光。这是注定的。
2，平稳期：一夜入冬。两年左右。由于前期的惯性，正负和中，产生动态平稳，看涨看跌的，擦肩而过，互写一声，SB！
3，下跌期：下跌期是非平均的，京津基本是-0.x%，省城是-5或8%，地级市是-20%，县城新区彻底变鬼城了。但这种下跌，居民挤不到便宜，必然是伴随严厉的限购限贷，看得到，摸不到。

进入下跌期后，最急的是小地方的财政收入。中位线城市，如果连跌两年，调控必然出花样。例如什么办户口赠房票，大专人才送房票，农民进城送房票，拆迁户不算房票，新开发区送房票，夫妻恩送房票，优秀农民工送房票，跨区不累计房票，反正不管什么花样，就是松了，因为地方上实在是有困难了。

如果中位线城市连涨了两年，必然进一步严格楼市。

这里面 的逻辑是很清楚的。地方财政，支付刚性，收入波动。你说哪个部门，哪个人群，可以少发钱？收入来源中，楼市占了相当大的比例（具体多少），大家都懂。你看省黄冈下面的农业县，有多少增值税？除了违章罚款，其他收入也就这样了！

要解决房价，必须解决财政预算的纪律性，叠入为出，彻底放弃对楼市财政的依赖性。

但是，这事情，谁说起来都不容易啊？
