# 为什么内地的小农经济

暂时不赚钱？（东北也一般）

对于小家庭，农业要发财，必须规模化，品牌化，科学化。但是每家三五亩地，凭什么都不行，成本太高了。你总不能说，为了三亩地去搞科学实验，土壤改良，水利建设，机械化，信息化？算了吧，种点猪虱田，留个口粮。

对于宏观面，能不能提高粮油蔬菜价格？也不行。因为下一步就是集约化大流转，如果种地大户赚了，小农就跟红了。流转肯定推不下去了，必须让小众经济干不下去，几十亩地的流转收益正常，才能流转，甚至产业化起来。

再过二十年，没有几个青壮年会种地了，大多数地域荒废了，就水到渠成了。那时候，大学生农民进场了，科学种地，大规模，标准化，品牌化的农产品，就起来了。
