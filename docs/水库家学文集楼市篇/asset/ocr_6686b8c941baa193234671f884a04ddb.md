上海市中心的概念，现在衍生到外围了，也基本没地了。新一轮大发展，必须要有个大一点地方。东南西北，我们要找个方向。

+   一，东面

唐镇二手房已经六万多，川沙是人口密集区，没有发展余地了，再往东，就接近机场噪音区和大海了。就此打住。

+   二，北面

东北一向经济不景气的，又是隔江隔海，过路费太高，道路堵塞。修个桥也要报国家高层面审批，先放一放。

+   三，上海南面以河流为界限，分为两个部分，

+   1. 浦东的南面是大海，跨海大桥只是连接了洋山港，没有经济腹地。

+   2. 金山区，地理位置很好，但糟心的是，沪津边界有个特大化工区，金山区的房价，历来是上海最低。我曾经去金山区一个叫什么马什么郡的联排别墅楼盘踩盘，非常漂亮，价格非常便宜。但是，走在小区漂亮的花园里，突然一股子工业酒精味迷随风景区味，呛得我呼吸困难，大煞风景。

+   四，最有可能的大热点是西南。上海向来说以西为贵：徐汇，西郊御宾馆，现在是大虹桥概念。西南主要街区：青浦区、嘉定区。

松江区，是内陆区，和江浙不接壤，谈不上长三角协调发展的含义。

嘉定区，是上海最北面，和浙江无关。花桥的高速，对接上海青浦区白鹤镇和嘉定区安亭镇，上海轻轨连接安亭和花桥。如果是对接苏州，嘉定区比青浦区好。

青浦区，上海唯一和江浙接壤的区。应对苏州和嘉兴。青浦区是上海水源地，环保背刺，居住环境好，但是工业一般。以前看，这是GDP的制约，现在看，那是宝地了。你想想，上海水源地的环境，好多好明。

青浦区被三个点围绕，浙江嘉兴，江苏苏州市，上海大虹桥。未来的上海第三机场，最大可能是在昆山，距离青浦区十公里左右，是最佳位置，既近，又没有噪音。

如果上海再要选一个大热点，我倾向于青浦区，或者以青浦区为主体大虹桥区域。华为已经去占坑了，估计明年一季度就要入驻了。

# 当前的经济形势，确实遇到各种挑战

+   1. 本币的基石是外贸出口。

出口换回了美元，美元支撑了本币汇率。几万亿外汇储备在手里，胜过用商进步。但是，中国外贸的结构是有不足的。

进口都是物资，粮食、石油、高科技。这些都是一必须美元交易的。

出口都是可替代的，我们的优势又快又便宜。问题是，

第一，如果某些国家为了其他利益，放弃便宜，那我们就不尴尬了。

第二，一般商品今后还能不能继续便宜，不一定了。劳动力成本已经接近中等发达国家了，水电气，房租，过路费比美国高，税费负担出口可以减免，但现在又加了个环保成本。这种情况下，怎么能做出比东南亚，北非，墨西哥便宜的商品，真是需要耐人了。
