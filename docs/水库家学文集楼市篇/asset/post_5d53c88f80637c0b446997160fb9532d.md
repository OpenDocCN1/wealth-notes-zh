# 我内心深处的经济学

每当我看到，地铁里年轻人挤在车厢疲惫不堪的下班，回到又破又乱的小出租屋，忍受低质量的生活，我都会想起我年轻时候的苦。我经常会有一种冲动，打土豪，均贫富。为什么富人可以在大house里，而穷人只能蜗居小屋里挤？太不公平了。

但是，我内心的这种冲动和血性，很快会冷静下来。因为我知道彻底的均富是什么样子。我从住在大企业的家属区，非常漂亮，干净整洁，窗明几净，物质丰富。那时候，真的是均富，虽然一堵之隔的农民很穷，但关我什么事嘛，只要是有编制职工，工人福利就是二室一厅，企业中层和副高职称三室一厅，其他都平。

这种彻底的均富，实行了几十年，效果并不好。我的部分中学同学，顶替进厂，我亲眼看到他们，上班磨洋工，偷小东西，干活偷懒，辱骂领导，这些都司空见惯。企业不能开除职工，只要8个小时待在车间，工资奖金一分钱不能少。干多干少没区别，会打会吵会撒泼，领导倒过来怕你。这种企业有多少竞争力，大家心知肚明。内部的浪费和低效，早已经见怪不怪了。

当时，我们之所以能够维持高质量的生活，完全是行业垄断的结果。工业刀刃，工业品价格奇高，农产品价格奇低。这种剪刀差，抵消了工人的低效，结果是，一堵之隔的农民穷爆了。他们的生活状态只能用贫穷来形容，当我家乡十代开始用洗衣机的时侯，他们还在不怎么干净的小河里挑水喝，只是用锅简单的清洗一下。

不是每个人都喜欢辛苦劳的活。我们被逼无奈容忍贫富差距，是提高效率的无奈之举，如果你不努力工作，也可以在地级市分套房子，那么，社会上的懒汉就会越来越多。

# 凯恩斯主义又跑起来了

（我说的是外国，不要杠精）

凯恩斯的内涵很简单。失业加剧时，多印钞票搞基建，大家都有工资了，商品就有人买了，市场再次繁荣，失业减少。麻烦是，家家户户的钞票不会一次性花完，必然有一部分结余，人们就想保值，不动产价格不断上涨。外地大学生就住开心了。

我们都知道凯恩斯主义的缺点，问题是，有比凯恩斯更好的办法吗？裁员的原因很多，例如微信来了，传真机厂就垮了。手机视频来了，彩电厂就垮了。这种零零碎碎的倒闭，没什么坏处，彩电厂的员工可以去手机厂，反正都是搞螺丝。真正可怕的是，企业普遍不景气，商品卖不动，街道裁员。

理论上说，销售少了，税费也会相应的减少。实际上不是，反而更多了。

首先，社保基数年年增加，倒逼你交钱。

第二，税费是下指标的，正常的税不够，那就鼓励举报，深挖历史。中国几千两小公司个体户，小老板和兼职会计不可能比执法部门还精通政策，要想让你交钱，有的是办法。

第三，金融部门，趁火打劫。企业的大环境不好，贷款风险欲上升了，银行直接加利息。明面上不让加，那就搞暗的，让客户给银行做回报。一般有两个办法：

- 1. 贷款利息算一年，实际上只能给你用10个月。你必须提前两个月放回账上。
- 2. 贷款总额算100万，实际上只给你70万，另外30万只是放在账上看着的。

如果你敢得罪银行，你就倒霉了。

走到这个地步，中小企业基本上就是砧板上的鱼肉了。

结论：共克时艰，减税减费，给中小企业喘口气，是利大于弊的。

# 风停了，猪死了

一是汽车销售饱和。现在第一代农民工家庭，子女也二十几岁了，大部分买车了。我家两个保姆，在老家省会或者县城买了房，大多数是90平米左右，儿子都有车。现在车价十几万，首付一半就行了。有了车，相亲方便。汽车是耐用消费品，十年也不换了。

二是住房消费严重下滑。包括装修家电家具。现在限购太厉害，大城市置换和新居民买房基本窒息了，环沪省会的二手房，已经是裸房冷价中，没有买卖，就没有消费。很多老破旧房子，也没新业主去装修买家具了。现在的家具城和建材城，跟个鬼城似的，保安比客户还多。

三是拆迁放缓了。

四是涨价因素遏制日常消费。冬季生意看服装。据浙江的部分化纤和皮毛行业反馈，今年冬装生意出现了断崖式的崩溃。很多服装厂提前两个月停产。往年是做到春节前二十天，现在是二月初就关门了。

贵卖不出去，原因是价格上涨，但工资不涨。

1，企业增加的成本主要是：融资成本，社保，环保，安监等环节。税费严格了，省额无数字，一把辛酸泪啊。这就造成了基础原材料涨价，然后传递到下游的日用品制造业，最终商品也只能是涨价了。但工资没涨，相反，因为生意不好，加班费和奖金还少了。

2，必需消费，越来越贵。孩子仅仅是十二年补课费30~50万，一个老人医疗自费30万是最低的。四个老人的负担，可想而知。这就把小夫妻还房贷后的存款全部吃光了。

3，白领失业风险上升。现在年薪40-150万的中高级白领，面临的失业风险，已经不是开玩笑的了。这些高薪岗位主要集中在京沪深广核杭苏，风险投资带来了短暂繁荣。风停了，猪死了。

4，高薪行业收入滑坡了。原来银行小妹，走路都带风范的，一个信贷经理简直是成功人士了。现在回归理性了，银行也就是小八千十收入吧，很多非银行金融机构，例如私募，券商，基本成猪头男了。

商品涨价，收入不涨，必然开支越来越小，失业降薪风险就在眼前，导致普通家庭的非必要消费欲望，彻底下滑，经济陷入相对低迷期。

建议：继续深化供给侧结构性改革，理性看待房地产。

1，房地产不是毒药，住房是群众的生活必需品，也是群众愿意花钱的地方。

2，房地产是职业发动机，拉动了三百多个行业。经济之大器。

3，医疗教育行业，必须回归理性，不要挤压居民消费。

4，降低企业运营成本到底怎么样了，大家心里不懂吗？

中小企业最盼望的不是贷款，而是降低成本。只有那些资本运作的大佬才需要几百几千亿贷款，实体经济哪里需要多少贷款啊！只要生意好，亲戚朋友立马把钱送来了，不就是李嘉奇的逻辑嘛！现在，企业没钱，是因为没有利润，银行贷款给没有利润的中小企业，只能是短期为。治标不治本。

二是没有进步的动力。发展进步，多累人啊！累死累力，我就这点工资，你能不能给我省点力气？我也不想多干。绝大部分人没有无偿额外劳动的想法。即使有个人非常想干，但是，他叫不动人啊。自己一个人也干不了多少！算了吧。

三是内耗麻烦，司空见惯。计划经济，一切分配看级别。你上我就上不去了，位子有限啊！那有人就搞事情。

你昨天晚上和张群花亲吻了，我看见了。
你这样做是出风头。
你这样做是对领导不忠。

呵呵，这种事情绪越来越多，大家慢慢的把注意力转移到了互相提防。至于创新发展，重要是重要，但那是单位的重要。我的第一个任务是别被人家黑了。

个人怎么办呀？搞好关系。王小二年年间抽佣，我要装没看见。李大铁偷东西，我赶紧回避。朱厂长找我客户捞了一只大火腿，管我鸟事。这群人，罪都不起啊。

当然，也有一些人非常好，但是架不住大多数人思想觉悟没到啊。计划经济下的京沪第一皮鞋厂干不下去了，最后还不如浙江农村的小作坊。

# 高科技和低科技

都是经济学的重要组成部分。

中国13.83亿人啊。欧美日韩人口加起来也没我们多。我们要是都转型去做高科技了，其他发达国家也在做高科技，这么多高科技给谁用？

亚非拉印巴孟加拉，人口是多，但外汇少啊。印度13.39亿，巴基斯坦近2亿，孟加拉近1.7亿，看上去很多，但有多少人放弃欧美日韩的高科技，专门买我们的国产高科技？

高科技和低科技，要齐头并进。我们不能只重视高科技，鄙视低科技。14亿人口的就业，不能指望高科技，还是要实事求是，高科技和低科技并重。印度人口多，工资低，低价衬衫和塑料拖鞋好爽，为什么我们就看不起塑料拖鞋厂呢？

扩大就业，提高工资，必须同等对待。以很多企业走下去为代价的提高员工待遇，并不是最好的办法。

# 过了松花江，东北就是你的了

很多县域首富吹自己是五十亿的身价。靠谱吗？

主板股市，pe一般是30-50倍。税后利润的30-50倍，就是企业估值，老板身价。很多250就按照这个来了。今年要是赚了一千万毛利润，就敢自已是三个亿身价，往北过了长江，可以吹四个亿，过了淮河就变成五个亿了，过了黄河就是七个亿了，到了亮马桥，就变十个亿了。过了松花江，东北就是你的了。

# 老王有几十亿！这句话靠谱吗？

我在穷逼时期，对这句话是非常崇拜的。当时我要是有一个亿就好了，别说张翠花看不上我了，老子要是有一个亿，可以把她四个表妹也一起收了，这都不用几十亿。

人长大了才知道，几十亿几百亿都是小瘪在意滚。中国没有哪个人有几十亿的钱，只能说有这个身价！为什么？假设你存款有10个亿现金，你大概要交8亿的个人所得税，你的企业要交2-3个亿的企业所得税，至于其他增值税之类的，就不说了。

没有一个富豪会这么干的。富人们的所谓几十亿，是指他所拥有的股票价值。这是虚的，又不能吃撑排。你卖个试试看，保证暴跌八成。一般情况下是抵押给银行，企业贷款需要抵押物，少部分是抵押买个房子。如果企业做不好了，连公司都带你全家，一起玩完。

富人们的生活条件比较好，可以用股票支出，例如买个飞机算企业资产。两情相悦，搞个女人，不用给现钱。加工资也行，或者对她的个人企业投资两百万，就算扯皮了。

一切前提是：企业必须做好，否则，你的富豪生活就算结束了，根本不可能划到什么钱。例如以前的太子汤，那是福布斯前几名品水平，一旦垮了，老板也彻底结束了，据说现住在个桶面老家的小破小（听说的）。

真有什么百年不倒的企业吗？我着难。这几个超级爸爸，超级老公，十年二十年后，还能剩下半截不错了。
