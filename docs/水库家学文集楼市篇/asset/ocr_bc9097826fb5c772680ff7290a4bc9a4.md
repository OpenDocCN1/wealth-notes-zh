# 很多农村老人过得比较惨

为什么呢？

京沪或地级市的城市老人，一般比较幸福。因为手里有房子，子女娶了不孝顺，他损失就大了。有些中老年亲杀，就算单位里面想腐败，也要回去伺候老人。单位里方几千元，那算个球啊！老头老太的房子再小，也是上百万，万一被老婆婊骗走了，岂不是当场振到？

农村老人穷，手里没有干股，农村人一辈子打工，拉扯子女，最后攒点钱建了房子。过程和城市老人一样辛苦的，但是，农村老人辛苦一辈子攒下的房子价值为零，儿媳妇自然无所谓了。在农村，儿媳妇欺负老人的事情，比往常是。

解决农村养老问题，不需要花钱，只需要发个通知，农村房子自由买卖了，儿媳妇第二天就会骑着给你老太婆洗脚，伺候。

# 妈妈的价值观

房子比儿子好一百倍。

我妈在 2000 年左右，买了一个内环线老破小，当时我去办手续的，10 万总价。现在每月租金 3500-4000 元。她把这个钱看的比我还重要。她周围没看到任何一家的儿子，每个月给父母三四千元零花钱，她有了这笔小钱，心里非常满意。

当时，是我怂恿她买的。原因也很简单。她为人善良，周围的亲戚朋友全同事，时不时找她借钱，三万两万。也不是不还钱，就是不知道什么时候还钱，她也不好意思去催债。所以，她的那点存款，大部分时间不在家里待着，而是周游列国。

我劝了也没用。于是，我就怂恿她去买房子，当时的说法是这样的。总价十万，月租金 200 元，年利率 2.4%，比存银行也不差了，说起来还多一套房子了。

现在，她把功劳都算在自己头上了。存款也比较大了，反正一个月多出四千元零花钱，一年就是近五万，出手给老娘阔绰了。上次老娘找去丽江旅游，加了六个来，合计 580 元，都是她买单。这么大手笔，小妹妹夸了她三次。幸福感激哪。

她的价值观就是，房子比儿子好。儿子没良心，跟老婆跑了，还是房子实在。
