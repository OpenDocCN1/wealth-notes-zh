# 严格限购下，远郊盘是彻底凉了

刚才看到，京沪几个远郊盘开业了。在自住为主的严格限购背景下，这些远郊盘是悲催了。远郊区没有什么就业，纯粹是农业地区，比我们苏北老家的县城好不了多少。但是，京沪的房价又比较高，买得起远郊盘的中小产蛋，不可能在那种村一样的地方上班。这就造成了远郊盘的尴尬处境。

平心而论，远郊盘附近没有什么就业，学校医院不全，交通不便，根本就没有卖给居住者的，完全是短略投资的需要。我看好这个地方十五年后的发展，几乎现在七折，我砸个金盘，就放那里，但现在不行了。外地户籍只能买一套，那只能是在市区买了，说什么也不走。因为走不了啊。小夫妻的单位，孩子的学校，都在市区，我叫我去远郊区，怎么可能！

这些远郊盘，因为没有就业，今后彻底凉掉的可能性极大。我干一辈子，才得了那么宝贵的一张房票，绝不可能投到远郊区的。目前的市场情况，也基本反应了这个情况。在普通行情中，鸡毛飞上天。远郊区也是赚的笑不动了。但是，现在的好日子，也快结束了。
