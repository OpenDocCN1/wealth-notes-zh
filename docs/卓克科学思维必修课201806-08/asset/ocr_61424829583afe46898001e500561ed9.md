# ——►上节思考题解答◄——

上节课最后，我留了一个问题：
有些经济或者社会现象，我们很难甚至都没有条件做实验来确定它的因果关系，我们最多只能做到收集多个因素的数据。那么我们还能不能分析出因果关系呢？或者一定程度上排除一些非因果关系的因素呢？
这个答案是，可以的。
那就是利用一种数学算法，叫做格兰杰因果检验。
这是克莱夫·格兰杰在1970年代提出的一个判断因果关系的数学方法，他本人也是因为在方面的研究于2003年获得了诺贝尔经济学奖。
我在资料里把检验方法的数学定义给大家列出来了，当然你不必弄懂这些数学含义，听我大概说说，知道有这么一种方法存在就够了。

这个数学工具的含义就是：
如果一个变量 X，对预测另一个变量 Y 没有任何影响，那么 X 就不是 Y 的原因。
相反，如果 X 是 Y 的原因，它必须满足另外两个条件。
第一，知道 X 的值，应该有助于预测 Y 的值，X 知道越多，Y 值预测得越准。
第二，就是 Y 不应该对预测 X 有任何帮助。原因是，如果 X 有助于预测 Y，同时 Y 也有助于预测 X 的话，那很可能就存在第三个或者更多的其它的变量，这些变量才是既引起 X 变化，也引起 Y 变化的原因。

# ——►无力的主观判断◄——

真真正正能把一套研究过程的流程走完整，然后依据最终找到的因果关系下结论，医学是一个很好的领域。
因为美国食品药品管理局，就是 FDA，在 2010 年之前，就要求所有上市的药物，除了必须要有提供足够棒的三期临床实验的疗效之外，还需要药企把药物的起效原理说清楚。
也也就是说，不但要求药跟现实中的疗效有高度的统计相关性，还要求提供因果关系的阐述。
不过，后来因为这个门槛实在太高了，还是放宽了标准，就是把提供药物作用原理这一条列为可选了。

# ——►随机双盲实验◄——

在医学上，确定药效，这个方法论就是随机双盲的分组跟设置对照组。
随机双盲分组指的是没有哪个患者知道自己被分到哪个组了，医生也不知道。只有第三方的统计者，默认记录着这些。
设置对照组是什么意思呢？
就是至少有一组人，他们是使用安慰剂治疗的，或者使用的是上一一年代的主流治疗方案，他们不采用新研发出来的药物做疗法。
咱们举一个实例来说说。
在1960年代，美国对肝硬化病人有一种流行的疗法，就是做肝内门静脉分流术，大致做法就是把肝门静脉跟胰子的静脉建立即连接，因为肝硬化的病人肝门静脉的压力总是非常高，这对肝是不好的。
