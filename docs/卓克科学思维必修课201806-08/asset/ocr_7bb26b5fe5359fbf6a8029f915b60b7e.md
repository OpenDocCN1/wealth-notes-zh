# ——►概念28：批判性思维◄——

批判性思维，指的是在人格平等的状态下，对自己和他人观点做谨慎多角度地思考。它讲究逻辑和理性，是一种高效地积累知识的方法。很多人以为它是一种专门抬杠、反对的技巧，这是对“critical thinking”这个词中文断地翻译造成的误解，实际上，它体现的是“带着高级技巧去审视”的含义。

# ——►语言中的圈套◄——

上节课，我们提到过亚里士多德曾经详细解读过，用修辞学来说服人的技巧。这些技巧的微妙之处在于，所陈述的句子没有事实上的错误，可实际却可以起到误导人的作用。

我们作为受众，接受信息的时候如果不希 望被带偏，那就需要一种能力，能够敏锐地识别出 语言中这种修辞方法，然后才不会被精心设 计的圈套。

比如说这句话：

这次股市暴跌，股民平均损失只有8.5%。

与此相对的一句话就是：

这次股市暴跌，股民平均损失高达8.5%。

这两句话说的是一个事实，而且都是事实，没有造假。但起到的心理暗示效果，一个倾向于让人认为，8.5%并不很大的损失，一个倾向于让人认为，8.5%已经是非常严重的损失了。

# ——►有预谋的引导◄——

但下面我要说的一些方法，就已经非常微妙了。整句的陈述中，没有一个字带有倾向性的表达，但却仍然可以有预谋地把人的判断引向他们希望的那个方向。

比如说：

依照这项计划，年收入20万欧元以上的纳税人，将平均纳税9.8万欧元。
