# 概念：荣耀

诺贝尔奖很伟大，但也有错误。这个世界有太多未知的东西，哪怕是诺贝尔奖得主的观点，也未必正确。

037 | 荣耀：诺贝尔奖在各种奖项中地位是最高吗？

诺贝尔终生未婚没有后代，晚年想要洗清人们脑中他与炸药的联系，他非常清楚科学是最值得投资的，所以为了心中的那份荣耀感，把毕生的巨资全部给了全世界的科学家。而接手的机构也充满了使命感，认真负责地把诺贝尔奖做成了瑞典的国家事业。

038 | 荣耀：那些颁错了的诺贝尔奖

即便是伟大如诺贝尔奖，也曾发生严重的错误，造成了很大的遗憾。因为在科学的探索过程中，再努力再真诚，错误也远比正确要多，付出的心血值得敬佩，可一旦落到事情的“是与否”上，就要屏蔽感情，客观判断，只有这样，才能更接近事情的真相。

# 概念19：源头

大学是在社会需求的土壤上生长出来的，它是现代文明的源头。而一个国家强大的标志，是拥有一个世界闻名的科学院。我们需要从文化的角度，带着演化的思维去解读它们的价值。

193 | 源头：第一所大学是怎么诞生的？

拉丁翻译运动中，负责翻译工作的法学院零散分布在欧洲各地，其中在意大利中北部最为著名的一个法学院受到国王的庇护和支持，这就是世界上的第一所大学-博洛尼亚大学诞生的背景。

# 概念20：遗憾

中国在明清两朝始终期和西方科学保持接触，关系有时候亲密、有时疏远。有人认为当时的中国没有发展出现代科学很“遗憾”，而实际上，只是必然，没有什么遗憾。
