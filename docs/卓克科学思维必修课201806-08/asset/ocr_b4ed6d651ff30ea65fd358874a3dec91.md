# ——►概念27：袁老◄——

袁老，是每个人都会经历的，但它并不是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解衰老，是科学地树立世界观必须的环节，它可以让我们更坦然地面对生命的最后阶段。

这节课，我们要说说线粒体上的基因。

这里有两个问题要注意：

+   一个是线粒体上为什么还有基因？这个问题是比较难回答的。

+   而另外一个比较好回答的问题，就是线粒体上的基因为什么变异速度那么快？

# ——►氧化与突变◄——

我们先说这好回答的。

之前我们课里说过，细胞内的 DNA 分两地保存，一部分保存在核内，占到绝大多数。而另一部分在线粒体上保存，而且我们后来可以通过线粒体 DNA 的测定来判断很多人人类考古的问题，或者说母系传承关系。

在测定中，我们也发现，线粒体上的基因突变速度，是核内基因突变速度的20倍。

那高了这么多的原因，就是因为线粒体是细胞的能源工厂，里面发生了剧烈的氧化还原反应，所以就连歉的 DNA 也免不了受到氧气的影响，变异的速度快得多。

也幸好它快很多，所以才能够在短时间内，比如说几千年就展现出足够大的差异，让人类学家精确地分析出我们走出非洲、走入亚洲，或者到达澳大利亚的时间。

而细胞核内的 DNA 是不会接触到这么活跃的化学物质的，突变少，所以相对要稳定很多。

# ——►线粒体中的基因◄——

而要回答第二个问题就复杂多了，线粒体里为什么还有基因？

它需要一些背景知识，就是不同的物种线粒体含有多少基因，含有哪些基因，这是不一样的。

比如含基因最少的就是我们哺乳类动物，它们线粒体内只有 16.5KB 的基因数据。但是在细胞核内的基因数据，那可是高达 3GB，两者就相差了18万倍。

而线粒体是细胞中众多细胞器其中的一种，你可以把它当作是一种设备。细胞中的设备可远不止线粒体这一个，还有像内质网、核糖体、高尔基体、中心体、溶酶体等等等等。

除了线粒体之外，其它的设备都不含一点遗传物质。

那细胞在正常工作的时候，核内的 DNA 根据各种信号来调控生产各种设备需要的东西。

线粒体既也是一种由各种蛋白质组成的设备，那么为什么不能把图纸也交给核内，让它全权负责生产线粒体需要的蛋白质呢？

其实线粒体在漫长的地球生命史上，确实是一直不停地把自己的遗传物质转移到细胞核内的。

因为科学家们测定了不同物种的线粒体 DNA，就发现：

有些还没有来得及转移到细胞核内的序列在果蝇身上就有，但是这段基因在人类的线粒体已经转移到核内了。所以看来，从果蝇到哺乳类动物的进化路上，这段基因是从线粒体向核内转移的。

科学家在酵母菌的细胞核内也发现了一些仍然停留在果蝇线粒体中的 DNA，所以也可以说，从酵母菌到果蝇的演化过程中，也有一部分遗传物质是从线粒体转移到核内了。

而植物的线粒体 DNA 片段，很多都是酵母菌都已经转移到核内的部分。

所以很明显地可以看出，随着生命的演化不断地进行，线粒体这个曾经的小细菌，自从寄生在一个古细菌体内形成了真核细胞之后，确实是不断地把自身的遗传物质往细胞核内转移。

这个转移过程是随机的，但要最终转移成功，却需要同时满足特别多的条件：

+   比如说需要整段的基因完整地跨过细胞核的核膜；

+   然后还要融合到更大体量的核内 DNA 中；

+   合并之后还有表达的功能，而不是沉默的；

+   到这里还不算完，因为这样一段有效的基因就算工作正常了，可以产生出线粒体需要的蛋白质了，也还是需要有正确的蛋白质工人，把生产出来的蛋白质送回给核外的线粒体才行。如果没送达，那也不行。

到此为止，才能算是一段基因成功地从线粒体转移到核内了。这中间任何一步卡住了，都会导致线粒体报废。

尽管如此复杂，现在科学家可以证实的是，人类的线粒体 DNA 曾至少把350多个基因完整地从线粒体上转移到细胞核内的基因组中了。到现在为止，人体的线粒体 DNA 只能生产13种蛋白质了，也就是对应13个基因。

# ——►呼吸链◄——

于是我们就要问，这最后13种基因，会不会在几百万年，或者几亿年之后也转移到细胞核内呢？在那之后，所有的基因都归于一处了呢？

现在的研究结果是，不会。

线粒体中会始终保留最少量的基因，这些基因图纸可生产出的那13种蛋白质都跟呼吸作用密切相关。

所以到这里就说到呼吸链了。

什么是呼吸链呢？

你可以把它理解成一条流水线，中学的知识只告诉你这流水线的第一道就是加葡萄糖跟氧气，最后一道出口就是 ATP。

其实这条流水线中间还有很多过程呢，只不过因为涉及到太多细节，中学教科书就省略了，中间的过程对我们来说好像是一个黑箱。

但就在这个黑箱中，就隐藏着线粒体基因为什么那么少，却一定要保留着一点的答案，也同时隐藏着真核生物衰老的解释。

这条流水线上，大致是这么工作的，就是：

+   葡萄糖上的电子跟质子被复合体1、2、3、4 剥下来；

+   接着电子顺着呼吸链一级一级往下流动，同时质子在电平衡的作用下被等量地一个一个泵入到线粒体的膜内侧，形成了一个能量蓄水池。

这些质子会在能量需求出现之后，撞击 ATP 合酶的蛋白马达，让它转动，每转一圈，就把3个 ADP 套上3个磷酸基团，组装成3个 ATP，这个就是能量货币产生出来了。

这条呼吸链上每个零件的运转速度都要互相匹配，任何一个点出现了停顿，整条链的工作就要停止了。这个道理跟流水线停工是一样的。

那么零件的运转速度由什么决定呢？

其实就是细胞对能量的需求。

如果你跑步的话，呼吸的频率跟深度都会自然而然地加大，这部分不是由人的意愿控制的，而是由大脑在你的一生里头完全自动地接管。

当大量的氧气出现，葡萄糖的供给加大，呼吸链上就有更多的电子流过，相应地就将有更多的质子被泵入到线粒体膜的内侧。蓄水池到了一个程度，质子就开始推动 ATP 合酶的马达转动了，然后就制造出 ATP 供肌肉使用。

但当我们停下跑步的时候，身体不再发出需求能量的信号给大脑了，合成 ATP 的工作会延迟一点才会停下来，在延迟的这段时间内，电子会把质子继续泵入线粒体内。

当蓄水池满了，细胞把手头还富裕的 ADP 全都转换成 ATP 之后，到现在手头已经没有任何原材料可用的时候，这整个过程就停下来了。这个就是正常停机的样子。

有正常停机，就有非常常停机。

比如说在呼吸链这条流水线上，有的设计因为老化出了故障，比如说那些电子流动，是由电子的载体蛋白承担的，本来应该搭载一个电子往下游走，但明显错了，它不知道从哪儿已经获得了一个额外的电子，所以当电子从葡萄糖上拆下来之后，就没法装载在这个载体上。

如果这样不正常的载体多了，比如说占比超过40%，那么就相当于参与传导电子的效率低了40%。其实本来是有多少载体，就对应着呼吸链工作的时候，能在线粒体膜内出现多少质子。

可是现在，因为有40%的载体出了故障，所以质子也会相应地减少，蓄水的速度变慢了，之后推动这ATP 合酶马达的质子也会变少。
