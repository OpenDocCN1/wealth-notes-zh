# ——► 概念27：袁老 ◄——

袁老，是每个人都会经历的，但它并不是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解袁老，是科学地树立世界观必要的环节，它可以让我们更理智地面对生命的最后阶段。

这节课，我们要讲真核生物和细菌的对比，从中我们要反思的是，什么是简洁，什么是美？

因为简洁的美，这样的表述经常出现。尤其是人们表达对一事物价值判断上。

但，起码我们细致观察生物界，就会发现，“简洁的美”这样的词汇，在科学体系里已经找不到没容身之地了。

# ——► 真核细胞与细菌 ◄——

之前的课里我们说过，主流科学界对细胞中普遍存在线粒体的猜测，那就是有一个不会利用氧气的某个大块头的细菌吞噬了一种会利用氧气的小块头的细菌。而且小细菌还有幸没有被消化掉，这样，它们达成了共生的细胞之后，也就是现在的真核细胞。
