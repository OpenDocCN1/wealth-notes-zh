# 分娩到底有多疼？

是剖宫产还是自然分娩，或者能不能采取无痛分娩，孕妇和家属可以提建议给医生参考，最后作决定时，最好听取医生意见。

# 乙肝的方方面面

乙肝只有在正规医院接受“抗病毒”治疗着一种有效的方式。任何中成药、中药、保健品、护肝药，或者奇奇怪怪的疗法，都是无效的。

# 感冒的方方面面

真正的感冒只有两种：一种是普通感冒，一种是流行性感冒。都是由病毒在鼻黏膜上繁殖引起的，两.oauth感冒根据病毒不同而区分。预防感冒就是到剥摸眼睛和鼻子、勤洗手、戴口罩。对于流感，除了流感疫苗，世上不存在其他药可以预防流感。

# 肾虚和补肾的方方面面

肾虚与补肾都是被滥用的伪概念，源于古人粗糙的观察；

+   - 保护肾的方式:少喝酒、戒烟、少吃盐、适量饮水、合理饮食；
- 肾不用补，不要乱吃保健品和各种药物；
- 维持健康只有三条：均衡饮食、规律作息、坚持锻炼。

# 近视怎么治疗？带状疱疹怎么处理？

+   - 飞秒激光手术是治疗近视最稳妥的手术；
- OK镜角膜塑形可以短时间改善视力，但不能治疗近视；
- 带状疱疹病毒每个人身上都有，免疫力低时就可能爆发；
- 带状疱疹是自限性疾病，只能靠自身的免疫扛过去，医疗手段只能缓解和缩短病期。

# 朊病毒会不会爆发？

+   - 科学界对朊粒的致病原理、感染途径、不同物种体内朊粒的情况了解非常有限，没有治疗手段；
- 朊粒非常难灭活，不容易分解，次氯酸可以对其进行杀灭；
- 人体一旦感染，发病后的死亡率是100%；
- 也许当神经性退行疾病有了全面的治疗方法，朊粒的感染也能一并解决。

# 从换头术了解“科学共同体”

科学共同体，代表了一大群科学家的意见，公开发表的任何观点，都是这群科学家的共识，对“换头术”，世界神经外科联合会严肃声明，头颅移植技术有一点可能，但它不仅伦理上不可接受，也缺少科学价值。因为头颅移植还缺少基础理论，技术上也达不到。

# 基因检测值得做吗？

现阶段廉价的基因检测都是不靠谱的，几乎没有参考价值，而数万元的全基因组序列的检测现在做还为时尚早，因为我们还没有有效解读的能力，而且随着技术发展，未来几年的检测费用会大幅下降。

# 你为什么会晕车？

人会晕车，是因为人耳内部负责平衡的器官“前庭”采集的移动信号与眼睛采集的视觉信号不匹配造成的。一般来说，人体的不舒服很可能是吃了有毒的食物，所以坐车觉得“晕”的时候，植物性神经会启动保护机制，赶紧把食物吐出去。

# 痛风很可能是一件大好事？

高尿酸在几百万年前，是让人类活下来的一种救命的能力。在当前的医学发展程度下，痛风是不可治愈的，一切宣传可以根治痛风的人都是骗子。

# 新的人体器官被发现了？

间质广泛存在于皮肤下、器官之间的结缔组织里，呈网格状状态，百年以来一直是科学界的共识，“新发现”只不过把这部分组织起了一个新名称。

# 偏头痛治疗史

偏头痛有着漫长的历史，在现代医学出现之前，几乎都是类似“驱魔式”的胡乱治疗。而实际上，偏头痛发作，是让人降低活动强度的信号，目前我们能切断疼痛信号，但还不了解疼痛真正的根源。

# 100%鲜榨果汁营养价值有多高？

+   - 果汁中含有大量的游离糖；
- 在人类的饮食中，并不需要添加任何的游离糖；
- 喝果汁长胖是次要的，它最大的危害，是扰乱胰岛素对血糖中的糖含量的调控，增加疾病风险；
- 喝果汁不如吃新鲜水果，鲜榨果汁同样没什么益处。

# 胃炎和幽门螺杆菌

幽门螺杆菌虽然致癌，但如果没有任何症状，是不用治疗的，如果在儿童时期杀灭，可能会加重胃酸反流的情况，长期看危害更大；对于浅表性胃炎，只要你没有出现症状，就可以理解为你拥有一个正常的胃。

# 我们应该怎么科学养胃？

胃是一个很坚韧的器官，传统文化中的绝大部分养胃的观点都是没有科学依据的，比如喝粥、吃山药等。真正的“养胃”就是少吃盐、少吃脆刺食物、不要喝酒、如果有幽门螺杆菌引起的明显症状，就去杀灭。

# 零热量饮料反而增肥？

摄入代糖是否有增肥现象，需要寻找足够的证据，证据从弱到强分为三个等级：流行病学、动物实验、人体实验。如果一个药物或者一个成分在这三方面都给出一致性结果，那么这个结论就是人类可以回答的最好的水平。动物实验中，代糖造成了肥胖，而对人体的研究，没有让人变胖。

# 关于睡眠：

+   - 只要能够保证足够时长 的正常质量睡眠，晚睡晚起并不比早睡早起有什么坏处；
- 人类本身是需要整块睡眠时间的，达芬奇睡眠法、盲想睡眠法都不靠谱；
- 咖啡对人体健康有好处没有坏处，控制在400毫克以内可以放心喝。

# 蛋白粉该不该吃？黑眼圈怎么办？

+   - 以增肌为目的的训练，吃蛋白粉是最好的补充方式；
- 以减轻体重为目的的体育锻炼，无需吃蛋白粉；
- 不同蛋白粉之间的差别不大，不用追求高价格；
- 黑眼圈本质上就是血管被看见了，静脉血的颜色是偏深的，所以会让皮肤映着发黑发暗。
