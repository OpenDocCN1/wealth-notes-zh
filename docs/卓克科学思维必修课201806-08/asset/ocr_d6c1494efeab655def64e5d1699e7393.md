# 305 | 问答：人类13万年前就到达美洲了？

最近有同学说，他看到了一篇报道，说：

最早到達美洲的人類是13萬年前到的，他就說是不是知識更新了呢？

因為咱們之前的課裡講，人類是1.8萬年前到達的北美洲。

那我正好借這個問題，來說說科學發現是怎麼一步步成為科學共識的。

首先，這個發現是去年刊登在《自然》雜誌上的，內容說的是在加州的南部聖迭戈發掘的乳齒象化石，在這些化石上發現了乳齒象受傷的痕跡，而且還發現了人類使用石錘、石針的痕跡。

其實這個發掘工作，從上世紀90年代就開始了，不斷地挖掘出像大地震、猛獁象、乳齒象、恐狼這些古老的的大型的哺乳類動物。這些動物的尸骨上貌似是有人類武器敲打過的痕跡，這個一直也作為一個疑點。

不過在90年代，那會兒用碳14測年法的時候就發現，已經超過了這種方法的測量上限，也就是5萬年這個上限。當時就估計這些化石至少也有6萬年的歷史。

但如果這些就是人類造成的，那跟主流的觀點就不符合，所以並沒有引起學術圈的轟動。

那這次的研究是重新取用了一種測年法，叫鉈系不平衡法做soa的測年。結果是這些動物是死於13萬年前。

而一些動物死于13万年前，这没什么稀奇的，还有死于130万年前的呢。

關鍵是要證明這些動物是被人類杀死的。

從前的證據就是那些骨頭上的痕跡，而這次多了一組模擬的證據。

這些科學家怎麼做呢？

就是按照當年石器時代工具的樣式設計了不少武器，又找來牛、袋鼠、大象的骨骼，就用這些模擬的武器敲來敲去，模擬了當年古代人把骨頭敲碎吃裡面骨髓的過程。

敲去完，仔細地對比模擬實驗中在骨骼上留下的痕跡，跟發掘出的那些化石骨骼上的痕跡，對比結果，它們的形態是高度一致的，所以得到結論，13萬年前，就有人類祖先到達了北美洲。

剛剛是這個研究的簡介，但這能不能說明就是這樣呢？就是13萬年前人類已經居住在北美洲了呢？

這還不能。

# 劃重點

+   1. 要从'科学发现'发展到'科学共识'，就必须从多方面都发现强有力的证据，并得到高度一致的结论，结论还要能经受更多次的验证。 2. 新的科学共识的形成，是反方面的优质结论不断地积累的过程。当更多多数的研究者站到新的这一边的时候，新的共识就形成了，老的共识才被推翻。
