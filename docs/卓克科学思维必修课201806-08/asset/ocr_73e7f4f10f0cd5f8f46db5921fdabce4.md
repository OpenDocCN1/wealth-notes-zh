# 256 | 味道：抵抗不住的食欲

# ——► 概念25: 味道 ◄——

味道和现代生活里很多文化元素结合在一起，比如美食、烹调、厨艺等等。但实际上，它是真核生物最早演化出的一批感知世界的信号。所以味道既可以用文化视角理解，又可以从演化视角理解。它的改变曾经强烈影响着物种的存亡。

# ——► 上节思考题解答 ◄——

上节课最后我留了一个问题，就是：

怎么看待大胃王的视频跟他们背后的辛酸？

视频呢，指的是就是他们面对镜头的时候大吃大喝，辛酸指的是他们在镜头之外给自己催吐，把吃过量的食物强制吐出来。
