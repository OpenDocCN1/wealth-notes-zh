
# 267 | 心理：心理学实验的结论可靠吗？

# ——► 概念26：心理 ◄——

心理学学科科学化的时间还非常短，从经验到知识，从看起来包罗万象到满足可验证可复现的理论，观察这种转变，不仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

这节课，我们并应该如何对待心理学实验的结论，这些结论真的可靠吗？

其中要讨论到的心理学实验，都是那些正经科学化过的，而不是成功学里头编出来的那些心理学的段子。

# 如何看待心理学实验的结论？

+   在小了说，有助于你在面对其他心理学结论的时候保持正态度；
往大了说，你可以知道一个科学理论是怎么成立的。

# ——► 暴力镜头对儿童影响 ◄——

我们用“影视节目中的暴力镜头会不会增加儿童的攻击性行为”这个研究来举例。

先说这个结果，对于这个问题，全世界心理学界已经研究了40多年，达成了共识，就是：

+   影视节目中的暴力镜头会增加儿童的攻击性行为。而ingt不只是儿童，成年也会受影响，增加攻击性行为。

# 那这个结论是怎么形成的呢？

它的实验大致是这样的：

让随机分组的两组儿童，一组观看暴力视频，一组不看，看完之后，分别给两组设置一些任务，比如说填写一些专门为了衡量攻击性高低的量表，最后统计这两组的攻击性的高低。

这样的实验，在细节上的差异也非常多：

+   有的是把暴力视频组的暴力程度给它细分；
有的是衡量一天中不同的时间看暴力视频有没有影响，比如早、中、晚；
有的是控制两组人在看视频之前，他们的情绪、出发点是什么样的。比如说是在已经愤怒的情况下看的，还是在平静的时候看的。

那不看暴力视频的那一组，也会有不同的状态，比如说：

+   什么都不看，这是一种；
有些可能是看一些风光片，或者看一些音乐剧。

# ——► 可靠性的判断标准 ◄——

那之前的课里，我们并不晓得这个问题是不是人类导致问题的，讲到判断一个研究是否可靠，那它依据什么呢？

就是，结论的一致性高不高。

# ——► 心理学主流理论 ◄——

现在，针对暴力电影是否导致儿童更高的攻击性行为，已经满足了结论的高度一致性。其实作为一个研究的结论，已经有了荣登主流科学结论的宝座了。

在非自然状态下找到的规律，不能用来说明孩子的攻击行为会增加，顶多只能说在实验室监控的条件下，攻击性会增加。

心理学研究的主流结论，是针对人这个属性，这个属性在各个年龄阶段都有体现，在各种生活模式下也都有体现。 用实验测的不是自然生活条件下的表现为理由，是无法驳倒心理学主流理论的。

# ——◆ 课程小结 ◆——

那这节课我们能收获什么科学思维呢？

那就是，对心理学的主流理论的看待方法。

通过前几节课，我们先是知道了什么样的研究才是符合科学标准的。

今天这节课，我们就应该了解这样的结论是在精心设计的实验过程中得到的，它跟现实生活当然不是严丝合缝地吻合，它必须得把干扰因素排除在外，才能找到几个重要的影响因素。

这是任何学科作研究的时候，都要搞定的规范化的过程。

而真实情况呢？

真的是只有爱因斯坦这一本，历史上除此之外再没有任何一次突破如此的坚实，如此的惊世骇俗，而且快速地被接纳。

270 | 问答：安慰剂效应有生理基础。

在之前心理学科学化的课程里，我专门讲到了安慰剂效应是种只是心理感受好，但疾病并没有器质性好转的情况，这个其实是一种对安慰剂的传统理解。

# ——► 快乐疗法 ◄——

最早出现的著名案例，是1964年的“快乐疗法”。

当时有一名杂技编辑叫诺曼·卡辛斯，患了强直性脊柱炎，这是一种免疫类疾病，免疫系统会攻击身体关节部位和椎间盘的纤维环，就造成这些关节部位的纤维化和骨化，最后的结果，就是没法正常弯曲了，是非常痛苦的一种病。而且还不知道它的发病原因，所以非常难解决。

这个编辑确诊之后，完全就没参考医生对病情的预判，他就坚信，快乐的生活会让他康复起来，所以之后定期去看喜剧演出，后来竟然奇迹般恢复了。

好了以后整个人的职业生涯就变了，他把让病人快乐当做后半生的事业，建立了卡辛斯中心。

# ——► 压力与疾病 ◄——

在上世纪60年代的时候，医学界是完全不认为心理状态会影响身体的，负面和正面的影响都没有。

但是到了80年代，开始观察到一些个案，就是大脑和免疫系统有直接联系，因为神经系统的某些部分跟胸腺跟骨髓都有联系，这个联系就体现在，胸腺跟骨髓有神经递质的受体。

那么，大脑在承受压力，或者享受快乐的时候，分泌出的神经递质就有可能影响到胸腺跟骨髓，而这两处是免疫系统非常重要的部分。

从这一点出发，科学家们首次测量到，医学院的学生在考试前夕，他们血液中抗击病毒的免疫细胞活性降低了，而且潜在在人体内大部分时不时发作的第四型疱疹病毒的抗体也更多了，这些现象都表明，考试前夕巨大的压力，让学生们更容易患疱疹。

之后的流行病学统计中，也找到了长期压力和患病几率的正相关。

比如有一个对3000名英国公务员长达20多年的跟踪调查，结果就是，长期工作压力会增加冠心病、二型糖尿病的患病风险。压力大的时候，HIV 病毒的潜伏期甚至都会更短，艾滋病的发病进程都会更快。

当 DNA 测序设备变得很高敞的时候，测序成本降到很低的时候，2007年加州大学洛杉矶分校的心理神经免疫学教授科尔，对长期独居且感受到强烈孤独感的人，对他们白细胞里的 DNA 作了全面的测序，对比了这里2.2万个基因，这些基因甚至都占到了人体基因总数的70%以上。

跟正常人对比，这些孤独的人有209个基因有显著的不同，这些基因要不就是蛋白质表达量很低，或者是很高。再仔细看表达量特别高的那些蛋白质，大多是参与炎症反应的，那些表达量非常低的蛋白质，大多是具有抗病毒功能 的。

也也就是说，那些不快乐的孤独者更容易患病，身体更容易出现各种红肿、疼痛、过敏。

如果要问为什么，其实也可以从演化的角度理解：

因为，从人类祖先算起，如果一个个体经常有强烈的意愿参与各种社交活动，那么他被感染的风险也就很高，如果社交过程中的一些生理信号可以传达给免疫系统，多生产一些抗病毒、消炎的蛋白质，那这个个体就能抵御感染，所以长年累月下来，拥有这种基因的个体就筛选出来了。

这些基因表达的强弱，信号就来自于社交活动给人脑带来的变化，这些变化也许从主观上理解，就是类似于孤独感或者热闹感之类的感受。

这些是负面情绪上的研究。

# ——► 幸福感与身体健康 ◄——

那么，是不是快乐的情绪，也能产生对身体有利的基因表达或者有利于免疫系统工作呢？

也确实有。

快乐对免疫系统跟基因的影响，这个实验和负面压力那个实验有点类似，它是通过负面压力减少的效果来衡量 的。

因为最初，如何衡量快乐感这一步很难。

那么就从一些可控、可测量的角度入手，找那些从事高度类似的工作，而且工作极其繁重的医务工作人员，相信在长期工作压力下，他们在快乐不快乐这个指标上，大致还是类似的。

然后让他们统一地参加一个冥想课程，一个阶段的课程结束之后，对比他们没上课和上过课之后血液中炎症因子和抗病毒基因的表达强弱，确实就发现，上过课后，炎症因子少了，抗病毒基因表达更强了。

还有的实验是找处于同一发病阶段的乳腺癌患者，给她们提供压力管理课程，来调整患者的心态，然后比较上课前后肿瘤转移相关的基因表达水平，发现也降低了。

在进一步的测量中，他们还发现，幸福感对身体健康的影响是可以分类的：

+   幸福感，有一种是纯享乐主义的，比如说吃了美食，或者获得了美女帅哥的青睐，或者是挣了一大笔钱。总之是层次比较基础的快乐感。\n还有一种，是因为从事具有伟大意义的活动才获得的幸福感，比如说从事艺术创作，或者呼吁社会公平，这些是一种高阶的幸福感。

真正可以明显降低炎症因子，增加抗病毒基因表达的，这个幸福感是第二种。

那种基础物质需求得到满足的幸福感，很可能因为持续时间不长，比如就像吃饱了，或者约会结束，这种感觉就消散了，甚至当这些物质条件不再能维持的时候，人还会马上陷入痛苦中，所以长期下来，第一种幸福感，总的效果并不明显。

那么，通过这些研究我们也可以猜测，安慰剂效应，让患者以为吃了有效的药，或者让患者认为医生技术高超，自己的病马上就会好，虽然不一定能产生什么幸福感，但起码疾病带来的心理压力更可能减轻或者减少。

这对免疫系统是好事，也就一定程度上改善了病情。

所以，安慰剂效应随着研究深入，背后的那些微弱的生理机制会被越来越地挖掘出来。

但是，它即使对器质性的疾病有一定的效果，也是非常微弱的，完全比不上那些已经通过 FDA 认证有效的药物，所以不能因为安慰剂效应有生理基础，而拒绝吃药。

对于幸福感的分类，我也要补充两句：

享受生活并不是什么罪恶，只要我们同时关注一些除了个人福祉以外的事情，就会减少对现实生活中压力的关注，这样高阶的幸福感才会更加持久。

好了，关于安慰剂效应的补充答疑就是这样。

# 划重点

+   1.安慰剂效应背后有生理学基础，不快乐的孤独者更容易患病，更容易出现各种红肿、疼痛、过敏。\n2.幸福感能降低炎症因子，增加抗病毒基因的表达。\n3.对身体的有益影响，通过参与具有伟大意义活动带来的幸福感，强于物质满足带来的幸福感。\n4.安慰剂效应，对器质性的疾病有一定的效果，但非常微弱，还达不到通过 FDA 认证的有效药物的水平，不能因为安慰剂效应有生理基础而拒绝吃药。
