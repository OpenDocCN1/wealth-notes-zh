# 269 | 问答：病毒引发阿尔茨海默症？全球变暖停止？

这次答疑回答两个问题：

+   第一个是，阿尔茨海默症是不是由病毒引起的？
第二个是，气候变暖是不是停滞了？

# ——► 阿尔茨海默症 ◄——

第一个问题，是最近科学圈里刚聊比较多的，就是阿尔茨海默症被发现是由病毒引起的，很多人问，这是不是谣言？

简单地回答：

这不是谣言，这是发表在《神经元》这个顶级期刊上的一篇论文。但大多数学新闻类的文章的题目都把论文的意义夸大了。
