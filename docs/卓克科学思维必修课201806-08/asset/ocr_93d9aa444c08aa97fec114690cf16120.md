# 176 | 成瘾：毒品疫苗真的能够帮助戒毒吗？

毒品疫苗的原理，是用某种能被免疫系统识别出来的物质吸收血液中的毒品，然后等免疫系统来清理排出体外。

# 178 | 成瘾：大脑中植入电极治疗精神病靠谱吗？

如果在大脑里植入电极能够让患者获得的收益多于害处，那么这种治疗手段应该被采用，从2002年起，植入电极已经被 FDA 批准用于帕金森氏病和特发性震颤的治疗。

# 概念17：谬误

有些结论因为科学进步不再准确，有些观点在宣传中被一再夸大，抓住其中可以量化的部分进行查证，或者寻找归纳的一致性，就能识别出其中的谬误。

# 181 | 谬误：全球变暖为什么不是谣言？

科学结论是不是正确，是不能靠人多势众的，科研不是搞选举、搞投票，不是谁的数量多就听谁的，也不存在“真理永远掌握在少数人手 中”这种哲理。它最需要看的，是理论背后的验证过程，是不是有众多的、独立的、多角度的研究，并且得到了高度一致性的结论。

# 182 | 谬误：真的存在催眠和催眠术吗？

催眠得以科学化，是因为跟它有关的学科都已经科学化了，有了现成的研究规范可以遵循，现在，任何一个现象都可以采用科学方法进行研究。

# 183 | 谬误：雷雨天打手机会被雷劈吗？

那些太普遍的，太经常发生的事情是不可能致命的，流传了几十年的生活小贴士，大多是因为技术进步，社会发展，失去了原来的提醒作用。

# 184 | 谬误：空调真能“每晚只耗1度电”吗？

面对广告宣传，只要它在表述中涉及到定量化的描述，我们就能通过基础的数学和物理知识进行验证，识别出其中是否存在夸大成分。

# 概念18：严谨

科学是从定量的概念发展出来的，衡量一个目标多少、大小，最关键的动作就是测量。测量的边界就是存在的边界，测量的准确就是对“存在”最严谨的定义。

# 187 | 严谨：1米到底有多长？

1米有多长，在科学发展过程中第一次得到可靠的结论，就是赤道到北极距离的1/1000万那么长。

# 188 | 严谨：1千克到底是多少？

国际单位制中的7大基本单位，米、千克、秒、安培、开尔文、摩尔、坎德拉，目前只有千克是以实体物质来定义的可是，只有那些永恒不变的逻辑、概念、物理常数，才能够保证我们看到的世界是稳定的。

# 189 | 严谨：角度是测量的基础

米是第一个被国际计量局标准化的单位，它背后还有一个更为基础的单位“角度”。

# 190 | 严谨：测量里产生世界观

单位的标准化，之所以要将单位进行抽象化、概念化，是因为实体参照物总会存在精度上的误差，而只有那些永恒不变的逻辑、概念、物理常数，才能保证永恒，让我们看到的世界是稳定的。
