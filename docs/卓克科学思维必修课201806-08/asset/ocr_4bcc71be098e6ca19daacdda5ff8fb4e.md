# 250 | 反省：那些真性情的论文

# ——► 概念24：反省 ◄——

科学是有力的，但内部也有各种问题，这些问题往往还是科学家们自我反省时公之于众的，甚至有科学家会把这些问题当做课题来研究。这让科学看上去没有那么完美，但正是科学不断自我否定与完善的过程。

上节课最后我留了一个问题，如果论文里出现了一这么一段话：

我们以其中3个样本为例，进行了深入的研究，对得到的数据进行了仔细的分析，在一定程度上验证了阿凡达理论，我们仍然需要进行大量的工作，才能完全了解该现象背后的形成机制。最后鸣谢沙隆巴斯先生对本实验的协助，以及孙小美女士富有见解的讨论。

那这段话背后是什么意思呢？

其实，如果我们只按字面意思理解，大致也是对的。但因为论文发表体制存在弊端，这段话解读到最不堪的情况，也能到下面这个地步。

# 第一句：

我们以其中3个样本为例进行了深入的研究。
