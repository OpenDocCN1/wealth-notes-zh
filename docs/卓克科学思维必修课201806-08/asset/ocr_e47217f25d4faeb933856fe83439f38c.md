# 253 | 味道：苦味儿与生存

# ——概念25: 味道——

味道和现代生活里很多文化元素结合在一起，比如美食、烹调、厨艺等等。但实际上，它是真核生物最早演化出来的一批感知世界的信号。所以味道既可以用文化视角理解，又可以从演化视角理解。它的改变曾经强烈影响着物种的存歿。

这个系列我们围绕味道来説一説。

我经常见到有人问：

为什么现代的饮料里，可巧力、咖啡、茶都是苦味儿的，却有那么多人喜欢吃呢？

苦味儿它不是象征着有毒吗？而我们偏偏那么喜欢，那人类这些做岂不是风险太高了吗？

其实我们如果深入其中的原因，说说里面的道理，你会发现，很多口口相传的厨师经验，背后都有生物学基础，甚至还可以从中感受到生命的规律。

# ——巧克力、咖啡和茶——

我们先来说说三种典型的苦味儿饮料：巧克力、茶和咖啡。

当巧克力粉，也就是可可粉溶于水的时候，苦味成分会大量地溶解在水里，而香成分大都没有溶解在水里。而当我们把可可粉溶解在油脂里的时候，苦味儿成分基本上没有溶解在油里，反而是一些带着香味的挥发物就会首先溶在油脂中，再挥发出来。

所以，巧克力在17世纪之前，用水冲着喝，味道其实不太好，特别苦，是需要加糖加奶的。直到1920年之后，固体的巧克力问世之后，口味才大大的提升。

那你据这个原理，你就会知道，固体的巧克力味道总比那些带着水分的巧克力酱会更好一些。

对茶来说，苦味儿的茶碱也会溶于水，水温越高，泡的时间越久，茶碱就越多次地溶解到水中。

所以，有些茶道讲究用80度以下的水泡，而且时间不要太久，主要原因就是为了避免苦味儿太重。

咖啡也有这个规律，最开始大家都用热水，所以就难免苦。如果采用低温高压的方式，其实也是能做咖啡的，而且这个时候，咖啡的香味跟咖啡因还是可以萃取出来的，而苦味儿的成分因为温度低，溶解在水中就会相对少很多，这个时候的咖啡就格外的香。不过用低温高压的方式萃取的咖啡时间要比用热水长了10几倍，所以价格也会比较高。

# ——苦味儿——

人的舌头可以分辨出5种味道，它可不是传统中的酸、甜、苦、辣、咸，而是酸、甜、苦、鲜、咸，辣只是一种跟痛的感觉，并不是味觉，而鲜味儿才是味道中的一种。

当然，现在最新的研究中，也有观点认为，对淀粉的感知也是一种味觉，但是它还有争议。

所以，对于舌头可以分辨出多少种味道，答案还是5种，酸、甜、苦、鲜、咸。

# ——苦味儿的保护作用——

我们对苦味儿这么敏感，其实还有另外的保护作用。

那就是在现代食品工业中，不至于死于各种添加剂摄入过量。

# ——苦味儿中的演化史——

统计舌头上的苦味儿受体就会发现很不一样。

我们先说说什么叫受体，那就是像一把锁，俗话说一把钥匙开一把锁，凡是可以插入受体的化学物质，都要求有县定的形状，只要形状合适，插进了受体，一般神经就刺激马上就会顺着舌头传到大脑，然后我们就感觉到了苦味儿。
