# —— 下周课程预告 ——

下周的课程，将是《科学思维课》这一季，最后一个小块内容，那就是考古。

虽然我们之前在讲人类走出非洲后，如何分布到世界各地的内容时，也涉及了大量考古研究的结论，甚至是研究方法。

但那些都更偏向于技术细节，而这一系列考古的内容，是带你利用考古学研究的终极目标，看研究成果，看历史，甚至看今日和看未来。

这个终极目标就是：梳理出遗存的古物在时间和空间上的分布，从而理解历史。

当你第一次听到这句话时，是很难领悟他的含义的。

但我在第一节课中就会用一个冰人奥茨的考古学发现，告诉你，那只是考古学极其特殊的例外。如果把做出这样级别的发现，作为从事考古的目的，那世界上几乎所有考古学家都将是彻彻底底的失败者。

# 概念28：批判性思维

批判性思维，指的是在人格平等的状态下，对自己和他人观点做谨慎多角度地思考。它讲究逻辑和理性，是一种高效地积累知识的方法。很多人以为它是一种专门抬杠、反对的技巧，这是对 “critical thinking” 这个词武断地翻译造成的误解，实际上，它体现的是 “带着高级技巧去审视” 的含义。

301 | 批判性思维：如何说服他人？

+   1. 掌握对信息进行逻辑论证的思考习惯，除了可以敏锐地判断出语句表达里的前提跟结论，更关键的，在于确保自己的信息入口的可靠性，积累更稳固的知识。 2. 通过逻辑论证来说服他人，在现实生活中效果往往很差，可以使用一些广告式的、口号式的，情感共鸣的方法，自己知道道理上靠得住就可以了。

302 | 批判性思维：不说谎，也能误导人

+   1. 用修辞学说服人的技巧，可以在陈述的句子没有事实上的错误的情况下，起到误导人的作用。 2. 修辞这种技巧是把双刃剑，你可以巧用它说服别人，或者欺骗别人，也可以在熟练掌握之后，增加对恶意使用修辞方法的防御力。

303 | 批判性思维：心理技巧上的误导

+   1. 利用简单概念反复重复来灌输观点的办法，已经在主流的心理学研究中被证实是有效的。 2. 只要愤怒情绪出现了，理智真的就不在了。不论我们是在说服别人，还是被说服，愤怒都是有害的，需要尽量地避免。 3. 批判性思维更大的作用，是在一點一滴的信息流中，构建稳固的思维世界，最大限度避免思维被劫持。

304 | 批判性思维：人为什么会信神？

+   1. 信神的生物演化视角，指的是 一种行为在客观上会增加生存几率，这种行为的后代就会更多的出现。 2. 宗教，是灵长类动物智力发达之后的副产品，它的形态会随着智力成果的进步而提升，但信什么样的神，是分三六九等的，尤其体现在对神的抽象上。 3. 不论是人类文明的发展，还是一个人从孩童到成人的发展，思维能力的进步，都是高度一致地体现在抽象能力上的。

# 答疑时间

305 | 问答：人类13万年前就到达美洲了？

+   1. 要从 “科学发现” 发展到 “科学共识”，就必须从方方面面都发现强有力的证据，并得到高度一致的结论，结论还要能经受更多次的验证。 2. 新的科学共识的形成，是反方面的优质结论不断地积累的过程。当更大多数的研究者站队到新的一边的时候，新的共识就形成了，老的共识才被推翻。

306 | 问答：代孕是否可行？

+   1. 代孕，是指夫妻双方的精子跟卵子经过试管婴儿的技术培养成胚胎之后，再移植到代孕女子的体内，孩子跟代孕母亲没有任何的血缘关系。 2. 商业代孕需要考虑的环节非常多，需要找合法的地区，专业正规的服务公司，才能提供足够的保证。 3. 整个社会对商业代孕服务的评价，跟历史上任何一个新技术的出现，公众对它们的态度都是类似的，一旦因为技术发展，某一项服务价格降到足够低，这项技术势必会成为主流选择。
