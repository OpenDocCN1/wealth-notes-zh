# 直播内容：

关于科学的4大关键问题：

+   1. 科学思想， 一直是一种主流思想吗？

科学文出现2000年，可直到500年前，科学思想才告别“苟且偷生”的状态，从非主流走向主流。

+   2. 大学是科学的土壤，但象牙塔里只是做学问吗？

大学自诞生起，就是“矛盾与斗争”的中心，科学思想与教会、皇权、民众不断发生利益纠缠与斗争，但正是这个过程，演化出了科学院。

+   3. 古代中国为何没有科学？

16世纪，科学就踏入了中国，但因为与中国社会格格不入，连续遭遇了无数次惨败，长达300年。

+   4. 科学最终是如何来到中国人身边的？

胡适、钱学森、邓稼先、梁思成、季羡林、钱钟书、杨振宁、李政道等等，这些大学者、大科学家奠定了科学思想在中国的位置，而他们都来自清末年间的“留美幼童计划”和“庚子赔款奖学金计划”。
