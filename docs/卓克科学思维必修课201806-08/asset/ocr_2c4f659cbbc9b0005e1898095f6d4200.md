# 292 | 袁老：自由基是怎么伤害细胞的？

# ——► 概念27：袁老 ◄——

袁老，是每个人都会经历的，但它并不是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解袁老，是科学地树立世界观必须的环节，它可以让我们更坚定地面对生命的最后阶段。

# ——► 自由基与抗氧化 ◄——

从线粒体的角度看袁老，最早的理论，就是现在都耳熟能详的“自由基跟抗氧化剂保护健康”的这套说辞。

它是在1972年被提出来的，大致的意思是说：

细胞中的自由基会伤害 DNA、蛋白质、各种膜和糖类，而线粒体上的自由基的泄露是自由基最主要来源于。
