# ——► 概念27：袁老 ◄——

袁老，是每个人都会经历的，但它并不是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解衰老，是科学地树立世界观必要的环节，它可以让我们更坦然地面对生命的最后阶段。

上节课最后我们讲到：

细菌的身体规模不能很大，尤其是细菌的遗传物质，不但承担不了解现多种生存技能的任务，更没有能力容纳垃圾基因。

因为遗传物质只要多一…, 就会耽误它复制自身，这会导致它在繁殖中落败。

看起来好像细菌只能往短小精干的方向拼搏了。

但其实并不一定，因为只要给细菌复制遗传物质的工人，也就是那些 DNA 跟 RNA 的合成酶足够多的话，复制速度也会提高的。

但是细菌没有能力给这些酶提供能量。

# ——► 课程小结 ◄——

细菌的一生跟真核生物的一生，甚至都能让人联想到人生。
