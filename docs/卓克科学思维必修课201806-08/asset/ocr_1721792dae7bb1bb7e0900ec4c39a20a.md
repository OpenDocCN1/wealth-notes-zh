# —— 泡沫与谣言 ——

人可以训练出蒙眼视物的能力？

人是一种动物，不存在什么超能力。儿童接受蒙眼视物等能力的训练，不仅无用，还可能为了被称赞而说谎。

成年人还能增高吗？去高原要吃红景天吗？

成年人的身高不会再增长，因为骨骼线已经闭合；

人体在承受压力、受到外伤、感冒后的疲惫和肌肉酸痛时，脑部会分泌内啡肽带来愉悦感，甚至让人上瘾；

高原反应的根源是每个人对氧气的利用率不同，这只由基因控制，与年龄、身体素质等无关，因此吃药无用。

食物寒热是什么？发炎是什么？

食物分寒、热、温、凉的概念，是古人粗糙的观察经验的总结，科技水平越高，它们就越难以存身；

红茶并没有真的“发酵”，而普洱茶很可能是被微生物污染了；

消炎药分两种，一种是抗生素，是杀灭细菌，另一种是抑制身体反应，让人舒服，但治标不治本。

眼保健操能预防近视？50年窖藏酒能喝吗？

眼保健操不能预防近视，但增加了眼部感染风险；

酒不容易被黄曲霉污染，但原浆酒是噱头；
食物的“发物”概念是古代人落后的观察，不存在寒性食物；
抗体数量决定了能不能打败病毒，注射狂犬疫苗，是让整个免疫系统都能认识病毒，在病毒形成大规模前消灭。

# —— 疾病与医药 ——

一次花费300万的治疗癌症新方法是真的吗？

CAR-T疗法很可能是一个彻底解决一部分癌症的方法。在技术成熟后会迅速降价，而且不只针对白血病，还肯定会逐渐地用在肿瘤、骨癌、皮肤癌，其他器官的癌症治疗上。

普洱茶致癌？

在普洱茶中发现的黄曲霉素是顶级致癌物，它会导致“抑癌基因P53”的变异，大幅增加细胞癌变的可能性，超过半数的肿瘤组织中都发现了P53基因变异。因此，无需谈论剂量，原则上也要尽量避食食用。

HIV病毒疫苗制作成了？

绝大部分假新闻和泡沫消息都可以通过找3-4个版本原创内容，分别读一遍鉴别出来，不需要你有什么丰富的专业知识，而是需要你先抑制住自己冲发的冲动，再花费10-15分钟的阅读和鉴别。
