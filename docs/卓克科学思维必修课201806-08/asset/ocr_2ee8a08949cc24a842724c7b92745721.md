# ——◈ 概念27: 袁老 ◈——

袁老，是每个人都会经历的，但它并不是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解衰老，是科学地树立世界观必要的环节，它可以让我们更坦然地面对生命的最后阶段。

# ——◈ 为何杀死宿主？ ◈——

上节课，我们说到了那些让细胞凋亡的蛋白质，很可能就是来自20亿年前，细菌入侵古细菌，形成共生模式之后，由细菌带进来的。

那为什么寄生菌要杀死它的宿主呢？

我们可以试想一下：

假如我就是一个寄生菌，如果我发现这个赖以生存的<|start|>山，不能满足我的日常营养需求了，那我势必要换另一个宿主来寄生，当前这个宿主就不再适合继续待下去了。

可是我随便走吗？

不能的，因为它的细胞膜已经把我困住了，那我作为寄生菌也只能想办法把困住我的膜给溶解掉，这样我才能出去找下一个家。

真实的生物体内发生的大致也就是这样的剧情，而且科学家们还找到了证据。

那是1997年的时候，德国马普研究所的医生用近似的方法重构了这个猜测的考古事实。

# ——◈ ATP与热量 ◈——

如果观察如今已经很成熟的真核生物，线粒体跟细胞已经配合得非常好了，它们各自完成必须的任务。对线粒体来说，它负责的工作主要是3个，执行死刑，产生ATP和产生热。

执行死刑我们之前说过，我们来说说产生ATP和产生热对身体的影响。

另外一种就是在浓度差的作用下，不冲击蛋白马达而流出。
