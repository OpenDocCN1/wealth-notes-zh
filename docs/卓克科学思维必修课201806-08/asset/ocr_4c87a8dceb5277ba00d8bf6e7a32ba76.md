# 259 | 心理：被低估的心理学

# ——► 概念26：心理 ◄——

心理学学科化学的时间还非常短，从经验到知识，从看上去包罗万象到满足可验证可复现的理论，观察这种转变，不仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

接下来一个系列，我跟你讲科学跟不科学的心理学。

# ——► 年轻的学科 ◄——

专门挑心理学，是因为这是一门年轻的学科，我们正好可以借助它的年轻来体验人们对一个领域的了解，从经验到知识的变化，这中间发生的变化，就是科学化的过程。知道了科学化的过程发生了什么事情，就知道科学思维是什么样的了。

科学化过程曾经发生在各个领域，但绝大部分在我们出生之前几百年，这个过程就已经完成，了以至于我们现在谈起物理、生物、化学，总觉得它原本就是现在这么科学的样子。而我们没有机会感受当年发生的那些惊心动魄的科学化的变革。

说心理学年轻，是因为它刚刚完成了科学化的过程不久。

之前的课里我们讲过，不同学科的科学化深浅是不一样的，最深的是物理学，现代科学最初的那些分支里，后来有一些模样大变了，你甚至可以理解成它被后来出现的学科分支取代了。比如像博物学就逐渐地被生物学取代了。

物理学没有被取代，而是自己发展得越来越壮硕。

那心理学什么时候才完成了科学化的过程呢？

如果用比较松的标准，那就是1892年，美国心理学会，简称APA，从它成立开始算。因为那时候，才可以说心理学这个学科分支出现了。后来在这个大分支下，逐渐出现了56个子分支，这些分支也就是当前心理学内部的分类。这是宽松的标准下的。

如果用非常严格的标准，甚至可以说是在二战之后心理学才完成了科学化的过程。那这个标志就是曾经的美国心理学会发生了分裂，其中有一部分成员，因为对学会当时内部主导的方向不满意，认为它偏离了心理学的基性研究，所以另立门户，成立了美国临床心理学家协会，后来这个协会改名，发展成现在的美国心理科学协会，简称APS。

APA跟APS，从字面上看很好解释，因为分裂出来的APS，最后一个字母S就代表了Sicence，科学的意思。

那让我们记住这两个简称：

+   - APA是参与的心理学家最多的那个组织；
- APS是所有心理学组织中科学化程度最深的那个组织。

可以说，APS的理念跟它的核心成员是推动心理学逐渐科学化最重要的力量。

这么一算，数一数年头，物理学科科学化已经500多年，而心理学科科学化才70多年，按最宽松的标准也是126年。所以心理学还是一个很年轻的学科。

# ——► 现代心理学 ◄——

心理学很年轻表现在，很多普通人都觉得自己可以对心理学研究的对象说上个1、2、3。但是他们说的内容基本没有按照心理学的科学化标准来阐述，也往往带着巨大的偏见。

这里首当其冲的就是弗洛伊德理论。

如果让你现在说出两个著名的心理学家的名字，我相信大多数人就算想了几分钟的时间，也仍然只能说出弗洛伊德这一个名字。这个例子就已经非常鲜明地说明，普通人作为科学的心理学是多么地缺乏了解。

因为如果对APA的成员作调查的话，那里面的人认同弗洛伊德的理论的比例不会超过10%的。如果再对APS，就是这个后面带着S后缀的这个组织作调查的话，那里的人认同弗洛伊德理论的更不会超过5%。

那我们应该知道的，在现代科学体系下的心理学家是谁呢？

比如：

+   - 大卫·胡贝尔，他是在1988年获得过APA最高科学成就奖的人，也曾经在1981年因为对脑部视觉系统的信息处理方面的研究获得了诺贝尔生理学或医学奖。
- 丹尼尔·卡纳曼，他是希伯来大学心理学的教授，在2002年获得过诺贝尔经济学奖。

这些人在心理学上的成就要远比弗洛伊德大，但普通人很少有人听说过他们。

所以，我们首先要明确一个最浅显的道理，现代心理学，不是弗洛伊德理论里描述的那个样子。

那弗洛伊德的理论是什么样子呢？

有这么几个特点：

+   - 首先，他有一套详细复杂的理论，用来描述他看到的各种案例；
- 其次，这些理论没有建立在可靠的，可重复的因果关系上；
- 最后，这套理论没法像其它科学理论那样预测未来。

那现代的心理学的理论是什么样呢？

要回答这个问题，并不容易。

因为APA的分支机构如果按名称算，一共有56个，每一个都可以算作是一个子学科，而每一种子学科中，又包含了N种心理学理论，每一个理论只能解释一个子学科中的一小部分问题。

而现实中的心理学理论，它的样子只比这56个领域更加零散，在每一个领域中都有N个主流的理论可用，它们都是用来描述、概括已经发生过的此类事件，也一样用来预测将要发生的此类事件。

可能当你听说这个结果会大失所望，觉得这还不如弗洛伊德的理论呢？

因为那个理论好像可以描述非常宽广的范围。

但是事实就是如此，如果我们不要求可验证性这一点的話，任何一个通过思辨方式产生的理论，都可以描述万事万物。

就像我们传统的阴阳五行理论那样，也像古埃及及的四中心八神系理论描述的整个宇宙那样。只不过这些理论都不是科学。

那么我们今后有没有可能把这56个领域，几百个理论整合成为一个理论呢？

答案是短期内基本不可能。

因为短期来看，理论的数量仍然在增加。

那长期呢？

也许会减少，但是它需要生物学、神经学、物理学，或者新的数学工具的引入，来发现新的规律，以整合旧的理论。

其实我要指出的是，一个领域能不能用一个统一的大框架理论来解释，这样的念头本身就是发达的物理学把我们给惯坏了。

要知道，科学的其它分支极少像物理学那样高度的准确，高度的提纲挈领。但即使如此，物理学到现在也仍然在找统一理论，因为力和其他类型的相互作用融合在一起。

物理学在1800年之前，也是明确地分为力学、热、光、电、声、磁这些门类的，它们之间也一样不能用一个理论来解释。

化学也是这样，它分为无机化学、有机化学、物理化学、生物化学等学科分支。

这些学科分支之间不能用一个统一的理论来描述，本质上跟心理学现在56个领域，好几百个理论不能统一是一样的。

所以什么是科学的心理学，我们第二个要明白的是，它是N多领域里，N多碎块的理论组合在一起的样子。之所以总看起不那么美好，原因是，这里每一个理论它都钉得住脚，可以验证，而且它都是经过其他心理学家反复
