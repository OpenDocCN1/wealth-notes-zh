# 262 | 心理：被安慰剂效应左右着的思维

# ——►概念26: 心理◄——

心理学学科化的时间还非常短，从经验到知识，从看起来包罗万象到满足可验证可复现的理论，观察这一转换变化，不仅仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

这节课我们讲安慰剂效应，这是现代医学出现之后才被定义的一种现象，它就是：

没有做有效治疗，但病人自己却主观感觉病症缓解了。

安慰剂效应，是在现代药物研发的进程中才被总结出来的。

具体来说，就是在研发的末期，对已经开发出的新药做真实的对照实验的时候，需要测量的一种效应。

# ——►安慰剂效应的测量◄——

那我们先来说说安慰剂效应的测量。

+   第一组，吃处方药，叫舒马曲坦；
第二组，吃同样外观的，但是里面是淀粉的药片；
第三组，什么都不吃。

医生不知道病人吃没吃药，也不知道那些吃了药的到底吃的是什么药。而吃了药的病人也不知道自己吃的是淀粉片，还是真药。

+   第一组，有70%的人反映有明显好转；
第二组，有30%的人反映有明显好转；
第三组，只有10%的人反映有明显好转。

# ——►安慰剂的普遍性◄——

我们刚刚举的例子中，那些百分比的数字虽然是举例，但那些百分比也都跟实际情况相距不远，尤其是，针对由主观口述病情轻重，没办法用设备测量病情轻重的情况下，安慰剂效应占的比会更大一些。

+   它包括：
所有疼痛类的问题；
所有心情沉痛压抑的问题；
还有由情绪波动引起的肠易激综合征，等等等等。

# ——►从个案到结论◄——

那当我们知道了安慰剂这么普遍存在的情况，就会发现，有好几个普遍藏于大众思维惯性中的不足。

第一个，就是很多人愿意从个案入手，却又从个案得到了结论。
