# —— 概念29：考古学 ——

考古学的终极目的是：梳理出遗存的古物在时间 and 空间上的分布，从而理解历史。通过它，不仅能看历史，甚至可以看今日和看未来。

考古活动，都是对过去几千年、几万年的历史证物作研究的，所以当下没法作考古研究。
