那是因为，这层磷脂被氧化了，线粒体的内膜没法固定它了，而外膜又出现了个大洞，于是本不该够过去的大分子现在都可以漂走了。

如果把这个过程改成人工控制，我们提取了细胞色素 c，再注射到那些健康细胞里头，有一样会引发凋亡。

所以，让细胞维持呼吸、维持生存，和导致细胞逐步凋亡，竟然都是同一个东西，就是细胞色素 c，区别只在它是在膜内还是已经游离出去了。

你看，生死只相隔那个膜，5纳米的宽度。

# ——▶ 课程小结 ◀——

我们再回想凋亡的过程，再结合之前几节课描述的线粒体的历史，很容易就想到一个悖论，那就是：

> 细胞凋亡可能不是细胞自杀，它也可以理解成是一种他杀。

因为如今所有的真核生物的线粒体，都来自曾经那个被吞进体内的寄生菌。是这个寄生菌为了自身的利益，在某些条件出现之后杀死了它的宿主。

那这样理解对吗？

现在已经找到了一些证据，因为细胞色素 c 这种蛋白质，是线粒体从外面带来的，而且如果研究其它的真核生物，它们的细胞凋亡的关键物质，还不止细胞色素 c，还有其它 N 种的蛋白质，也能起到开启凋亡的作用。

比如像 diablo 蛋白，核内切酶 G 等等等等。
