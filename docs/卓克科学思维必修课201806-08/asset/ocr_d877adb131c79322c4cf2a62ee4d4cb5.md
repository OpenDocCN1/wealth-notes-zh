# 概念25：味道

味道和现代生活里很多文化元素结合在一起，比如美食、烹调、厨艺等等。但实际上，它是真核生物最早演化出的一批感知世界的信号。所以味道既可以用文化视角理解，又可以从演化视角理解。它的改变曾经强烈影响着物种的存灭。

# 253 | 味道：苦味儿与生存

人类食谱外的苦味儿大都含有毒素，食谱内的带苦味儿的食物都是无害或者毒素含量极低的。激烈的生存斗争在自然界是普遍存在的，演化出毒素的植物得以生存，演化出识别毒素能力的动物得以繁衍。

# 254 | 味道：滋味的好坏没有客观标准

味道好与坏的评价，很难与文化影响分开，这类主观评价体系，都是很不稳定的。

# 255 | 味道：口味改变命运

对食物味道的识别能力，决定着一个物种的生存和灭亡，在美食这种文化里，实际上蕴含着和生死紧密相关的内容。

# 256 | 味道：抵抗不住的食欲

人类对于好味道的追求，并不是一种高级的文化产物，而是几亿年来生物演化出的生存本能，对于食物的渴望，在身体和心理上同样强烈，这是我们很难抗拒美食的根源。

# 概念26：心理

心理学科学化时间还非常短，从经验到知识，从枉上去包罗万象到满足可验证可复现的理论，观察这种转变，不仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

# 259 | 心理：被低估的心理学

心理学年轻的表现，是很多普通人却觉得自己对心理学研究能有一定的见解，但实际上，普通人基本上没有能力按照心理学的标准分析和陈述问题。

# 260 | 心理：心理学科学化的第一步

人们对心理学这个学科的偏见，就是普遍低估了心理学作为一门学科分支的专业度跟复杂度。

# 概念27：衰老

衰老，是每个人都会经历的，但它并非是每个生物都会经历的，有些动物就没有明显的老化，甚至越老越强。了解衰老，是科学地树立世界观必要的环节，它可以让我们更坦然地面对生命的最后阶段。

# 272 | 衰老：人老了以后会怎样？

人体是极其复杂的系统，各自组成部分都有一定的“冗余”，即使是一些部分出现损伤，系统也能维持运转，衰老的过程，就是损伤持续积累的过程，当“冗余”耗尽，人的寿命也就走到尽头。
