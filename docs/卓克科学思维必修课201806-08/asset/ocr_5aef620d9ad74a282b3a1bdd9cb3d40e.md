# 划重点

+   1. 社会群体形成的知识库，就是不同个体间一块一块维系在一起的，而且我们的大脑，一直在尽量把专业的信息分摊给专业的对象处理。
2. 互联网真实改变了人们的记忆习惯，人们总是倾向于不再花成本记住那些可以存储到网络上的信息。哪怕是被强制要求记住，记忆效果也比没有互联网存在的时候更差。
3. 有了互联网和搜索引擎之后，人们需要记住的知识不一定变少了，只是思考资源进行了重新分配。
