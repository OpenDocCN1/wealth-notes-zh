# 268｜心理：科学结论成为学界共识有多难？

# ——► 概念26：心理 ◄——

心理学学科科学化的时间还非常短，从经验知道识，从看上去好像万象到满足可检验可复制的理论，观察这种转变，不仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

这节课，我给你讲一个科学结论是怎么成为学界共识、成为主流认同的。

知道了这些，你就能理解，为什么今天的现代科学看上去好像发展得举步维艰，很久都没有出现过跨时代的重大理论了。

# ——► 科学成果总被夸大 ◄——

我们在一些新闻媒体上如果看到了跟科学有关的标题，虽然它们不是每条都跟下面这样，但大概率说，看类似下面风格的标题你是不会意外的。

比如说：

+   - 科幻成真，章鱼有可能起源于其他星球；
- 可以对抗超级细菌，科学家发现了全新的抗体；
- 可以永生，癌症免疫疗法治愈率超过99%；
- 50倍电量，3分钟充满，新式锂电池诞生。

这里每一个听上去都像是一个历史性的突破。这是因媒体总是或多或少地追求销量或者流量，大媒体在这方面可能收敛一些，小媒体就放肆多了。

总之，这是媒体报道科学新闻的一种风格。

这种风格流行久了，就会导致读者产生错觉。什么错觉呢？

就是对一个科学结论，一个科学成果，是以怎样的方式出现的产生了错觉。

# ——► 科学发展的真实模样 ◄——

而真实情况呢？

真的是只有爱因斯坦这一本，历史上除此之外再没有任何一次突破如此的坚实，如此的惊世骇俗，而且快速地被接纳。

那么除了这个以外，其他大多数理论都是怎么进阶的呢？

它大概是这样的，就是：

+   - 先从个案找到灵感，提出一个假设；
- 然后做实验一试，这种实验当然可以是真实的实验，也可以是思维实验；
- 如果实验结果初步满足了假设，那么就要面对一个更大的挑战。这一步的挑战，会把绝大部分的理论候选者拒死在摇篮里。那就是要看这个新假设可以解释的范围，能不能覆盖它上一代的理论已经可以完美解释的领域。而且，还能在原有的范围之外多解释一点什么。
