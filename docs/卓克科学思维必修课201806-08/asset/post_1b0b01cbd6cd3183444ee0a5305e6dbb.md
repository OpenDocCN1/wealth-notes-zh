# 127 | 旁证：寻找衣服的历史

通过DNA技术研究猿子的进化史，人类衣服出现的时间被锁定在了17万年前，科学技术在历史研究中的应用，让历史更加坚实。用旁证来进行证实，虽然是一种无奈，但是使用科学的逻辑和方法，就能够得出相对最为接近真实的答案。

# 128 | 旁证：黑猩猩还有机会变成人吗？

现存的任何一种猿猴都没有机会再进化为人类，因为早在几百万年前，它们与人类的祖先在演化路径上已经分道扬镳。

# 129 | 旁证：日本人是中国人的后代吗？

通过基因测序分析，日本人、朝鲜人、中国北方人拥有共同的祖先，我们都是3万多年前亚洲祖先的共同后代。

# 130 | 旁证：家猫是什么时候出现的？

全世界所有的家猫都源于非洲野猫。家猫跟非洲野猫的DNA从遗传学上几乎无法区分，突变量的积累还太少，少到无法测量。因此，确认家猫的驯化史，反而是考古遗迹这种更粗犷的证据更有效。

# 133 | 旁证：猫为什么那么孤冷？

家猫的祖先非洲野猫是独居动物，与人类共同生活时也依赖于自己捕食，始终没有形成对人类的忠诚或依赖，这可以理解为猫总是那么孤冷的根源。

# 135 | 旁证：乌龟为什么长寿？

# 136 | 旁证：人类是怎么分布到全球的？

大气环境和海面的大幅度变化，是一种天然的物种大过滤，元谋人、蓝田人、北京猿人都是这样走向灭绝的。通过DNA分析技术，科学家们确认了人类起源于非洲。

# 139 | 旁证：最早的语言听上去什么样？

一种民族的出现，一种语言的出现，都是在各种自然条件限制的夹缝下，自然而然展现出来的可能性，这些可能性几乎无法提前预知，它在大跨度的历史时间中，基本上是由大的背景参数筛选得到的。

# 140 | 旁证：人类祖先是怎么逃过大灾难的？

人类祖先面临极为严苛的生存条件，除了我们都灭绝了。通过发掘古人的语言和艺术品，是大规模协同让人类存续至今。古代文明几乎都有大洪水的记载和神话，由此推断，人类在5万年前就有了语言。

# 141 | 旁证：文字诞生前的Strah...人类文明

科学是一个容观理性的工具，它可以纠正历史记录中的偏差，客观上拉近了世界民族之间的距离，降低了民族主义中来源于的优越感。

# 142 | 旁证：酵母菌也能致命吗？

格特隐球酵母菌是一种高危真菌，随着全球变暖，它的繁殖开始扩散，与人类的生存空间产生了更多重叠，在形成新的平衡前免不了带来疾病与死亡。

# 概念13：边界

人类观察世界的边界，是由所能使用到的最好的工具决定的，面对任何问题，只有尽可能多找一些可验证的细节，不过度地理解，不过度地解读，才可能了解真相。

# 145 | 边界：钢铁侠会成真吗？

科技路上每一个推进，都是跟经济利益挂钩的需求推动的，科技选择往哪个方向突破，背后是成本的考量。

# 146 | 边界：电影为什么每秒只有24帧画面？

一个事物所表现出的现状，源于方方面面的积累，看似不合理，存在提升空间，但只要没有遇到危机或者强大的需求，就是很难改变。

# 147 | 边界：恐怖记忆也能遗传吗？

小鼠实验中，“恐惧”能够遗传，是负责苯乙酮受体的基因的甲基化变弱了，让小鼠对苯乙酮变得更为敏感，过度的反应，被人理解为恐惧记忆遗传了。

# 148 | 边界：为什么镜子里的像不是上下颠倒的？

镜子里的像既没有上下颠倒，也没有左右颠倒，而是前后颠倒了。我们感受、看到了什么，并不是最初眼睛收集到的那些粗糙的原始信息，所以的我们看到的东西，已经是大脑深加工后的内容了。

# 151 | 边界：为什么没有绿色的恒星？

恒星在发光的时候，尤其是那些发白光、发蓝光的恒星，一样也在发射着绿光，只不过绿色光被淹没在各种其它颜色的光里了。

# 152 | 边界：人会疼痛吗？

疼痛属于情感体验，它并不一定是客观的神经刺激，即使没有发生实际损伤也可能产生疼痛，这也就预示着它很难准确测量。

# 153 | 边界：从科学角度理解情感

从科学角度理解情感，不是唯科学主义，而是在文化的基础上传加一个维度，寻找更多实物证据，得到更准确的解答，更理解情感。

# 181 | 谬误：全球变暖为什么不是谣言？

# 183 | 谬误：雷雨天打手机会被雷劈吗？

那些太普遍的，太经常发生的事情是不可能致命的，流传了几十年的生活小贴士，大多是因为技术进步，社会发展，失去了原来的提醒作用。

# 184 | 谬误：空调真能“每晚只耗1度电”吗？

# 213 | 遗憾：西方科学是怎么诞生的？

科学思想诞生于脱离实际的，用数和几何解释世界的逻辑，除了古希腊文明，其他文明都没有出现。李约瑟提出的“中国科学是在文艺复兴后被西方反超”的观点，在学术界已经普遍不再被认可，我们要避免被情绪因素左右。

# 概念21：追赶

1847年，三名中国学生赴美留学，迈出了中国追赶现代科学文明的第一步，他们之后促成了“留美幼童计划”。留美的幼童人到中年后又促成了“庚子赔款奖学金计划”。这些奖学金培养的人才几乎就造就了中国现代科学所有学科分支的创立者，确立了现代科学在中国地位。

# 217 | 追赶：科学思想扎根中国

观察历史大事件的时代背景，是把握历史真实影响的重要观察方法，再伟大的事件，也超不过时代的限制。

# 218 | 追赶：中国科学发展的紧张时刻：天津教案

天津教案能妥善迅速解决，一是曾国藩处理得当，二是普法战争让法国无暇顾及。这才让曾国藩有时间听取咨询的留美幼童计划，并与李鸿章一起奏uming朝廷。

# 219 | 追赶：120个留美幼童

现代科学，现代社会制度，始终没能在中国古代，不是几个原因决定的，而是几乎所有的社会活动的每一个环节，都藏着让人想都想不到的巨大的阻力。

# 220 | 追赶：改写中国科学史：庚子赔款

留美幼童的成材率极高，关键因素在于他们得到了获取差异化信息机会，与同时期的本土人才相比，他们掌握了巨大的信息优势，因此才大有所为。

# 223 | 追赶：科学在中国生根发芽

科学思想在中国生根发芽，是各种因素的影响互相叠加带来的。如果把社会形态里民众可以选择的人生道路的多样性作为标志，更丰富等于更文明的话，只有更文明的社会，科学才能更发达。

# 概念22：平凡

在现代科学方面，中国用了150年的时间追上西方500年的进展。所以当代的中国人难免对科技发展的速度有所高估，把科学当作无此伟大正确的事物。而实际上这是一种偏见，科学没有大家想象的那样完美。客观公正的评价科学，也是一种科学精神。

# 224 | 平凡：大家都站在巨人的肩膀上

不论什么时代的科学家，他们的成就都是在他们生活的那个时代已有的知识基础上作出的突破得到的，每一位科学家，都站在巨人的肩膀上。

# 225 | 平凡：把伟大科学家拉下神坛

带着批判性思维审视科学，了解伟大科学家平凡的一面，而不是仰视与崇拜，这也是一种科学精神。

# 226 | 平凡：如何科学看待四大发明？

“四大发明”一词，来源于英国科学家李约瑟在1940年代对中国文化的研究，其中的火药和造纸术是真实的，但活字印刷在古中国几乎没人用，只能算半个，而指南针是无法指南的。

# 229 | 平凡：天文历法是为农耕服务的吗？

历法的功能，不管是在中国还是在欧洲，其实都是给人算命用的。对科学怀着宗教情感的人，总会尽力无法把科学的往事和那些现在看起来已经沟沟的东西清界限，但这种情绪本身就是不科学的。

# 230 | 平凡：被利益左右的科学体系

相对于热核聚变动辄几十亿美元的投入，冷核聚变每次都是几百万美金的投入，而一旦成功就是超级暴富的机会，所以一直不投资者。在面对巨大利益时，科学的自我纠偏能力也会大大降低。

# 231 | 平凡：科学圈内部的自我审查

对科学问题来说，就是实验证据和从证据到结论的逻辑演化。证据是不随主观情绪改变的事实，逻辑推演更是不随主观情绪改变的。

# 概念23：宏观

用宏观历史的角度了解人类史，不再纠结于某个事件或化石证据。而更多考虑气候、地理、人口总量、物种多样性等大背景条件，就可以更接近众多元文明之所以诞生或消亡的最初原因。科学作为一种文化，也可以从这个视角重新审视。

# 232 | 宏观：人类为什么进入农业生活？

人类在狩猎采集时代的生活比早期的农业生活更为优越，但随着大型动物被捕杀殆尽，加上新仙女木事件导致大型动物加速减少，之后的升温又让农业制造食物的可能性增加，在诸多因素推动下，人类祖先进入了农业生活。

# 235 | 宏观：农业文明的地理决定论

人类农业文明的出现，很大程度上是由地理条件和资源状况决定的，因为只有那些环境略微艰苦的环境，才存在适合作为农作物的植物。

# 236 | 宏观：族群的命运由技术裁决

人类文明早期，一个区域内的人类族群能持续繁衍生息，掌握的技术越先进，基因被保留的概率就越大。

# 237 | 宏观：科学诞生前的技术大同小异

16世纪之前，就算是经验再丰富，总结出来的东西听着更神奇，那些从实际用途跟利益出发，总结归纳出来的东西都不是科学。

# 概念24：反思

科学是有力的，但内部也有各种问题，这些问题往往还是科学家们自我反思时公之于众的，甚至有科学家会把这些问题当做课题来研究。这让科学看起来并没有那么完美，但这正是科学不断自我否定与完善的过程。

# 238 | 反省：关于青少年叛逆子的研究

科研工作，往往让外行人觉得和自己没关系，但实际上，科学的研究方法与思考方式，是人类目前能掌握的最有效的认识世界与指导生活的方法论。

# 241 | 反省：搞笑诺贝尔奖

科学圈内部有些潜规则也是让科学家们不吐不快的，搞笑诺贝尔奖，就是以一种公开自嘲的方式，反省科学家的的工作，把发人深省的道理通过搞笑的方式显现出来。

# 242 | 反省：面包抹了黄油那一面更容易着地？

一个好的研究，不但理论要成熟，而且要能全面地描述研究对象，得出的结论要有实验支撑。

# 243 | 反省：什么时候需要假设上帝的存在？

现代科学的发展，会随着观测水平的提升，新的证据的发现，不断地核实与订正。旧的理论会不断被细化与完善，甚至被新的理论取代。

# 244 | 反省：一个物理学家为何挑衅一群人文学者？

文史哲的学科历史远比科学要久远，这些学科非常重要，只要剔除其中的糟粕，对认真做学问的学者才是公平的。

# 247 | 反省：圣经里的密码

现代科学、工程学跟文史哲学科的最大不同，在于它们建立在实验的基础上，需要掌握设计实验、动手操作、处理数据、分析结果等能力，这一套是无法通过自学达到研究者程度的。

# 248 | 反省：科学是怎么预测未来的？

准确预测未来的能力，是科学带给人类最强大的力量，这种准确度，让我们得以超越其它生物。

# 249 | 反省：科学江湖里的潜规则

科学界已经形成了足够大规模的利益集团，与其它行业一样，利益关联让它得以出现并稳定存在，而它也会自然吸收更多资源和利益的方向演化。

# 250 | 反省：那些真性情的论文

科学论文的范式如果不被滥用，将会出现很多有个性的论文表达方式，它们散发的是智慧，也会有更多务实的内容，让科学的表达更具有多样性。

# 概念25：味道

味道和现代生活里很多文化元素结合在一起，比如美食、烹饪、厨艺等等。但实际上，它是真核生物最早演化出的一批感知世界的信号。
