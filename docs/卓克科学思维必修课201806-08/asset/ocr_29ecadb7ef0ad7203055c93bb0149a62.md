# 问答

很多同学在后台留言，想问问抑郁症相关的问题，他们都是因为身边的亲人朋友有患病的。

如果查一下也就能知道，中国的抑郁症患者比例超过2%，也就是说有3000万人，这个病尤其是城市人发病率更高。而且据统计，其中只有9%的人去医疗机构接受了治疗。

那是不是抑郁症，也要测量了之后才能算数。有些人比较矜情，他就愿意夸大自己的负面感受，把一时心理的低落也算进去。

如果你感兴趣，可以按照这里的规则自己评估一下，我自己也试了一下，得了35分，看来是好得很。

# —— 皮质醇 ——

因为，抑郁症不是一种仅仅停留在主观感受，比如说心情不好，或者没有兴趣这样的一种病，而是有具体的生理指标的改变。

主要就是肾上腺分泌的皮质醇过量，它就产生了脑部的生理变化，而且皮质醇过量也会影响到全身。

# —— 抗抑郁药 ——

而抗抑郁药，却不是直接从减少皮质醇来入手的。
