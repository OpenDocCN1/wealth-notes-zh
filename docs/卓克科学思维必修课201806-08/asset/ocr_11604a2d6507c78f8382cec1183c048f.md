# —— 下周课程预告 ——

# 关键词：衰老和死亡

我是谁？我从哪儿来？我要到哪儿去？

第三个问题，其实可以理解成“衰老和死亡”。

科学进展，让人类的平均寿命得到大幅提高，主要贡献来自于新生儿死亡率下降和解决了微生物感染的问题，但实际上，人类寿命的上限，始终没有变化。

过了70岁之后，每个人都会明显地表现出衰老、皮肤的褶皱、肌肉的无力，甚至器官的衰竭，都是衰老的表现。而衰老并不是存在于每种生物中，有些鱼类和鸟类在一生中始终看不出衰老的迹象。

下周的课，我们先来说说衰老后是什么感觉，再领大家回顾细胞的生命史。

这些预备知识学会了，再下周我们就要介绍一个关于衰老常常有启发的观点：线粒体质量下降导致衰老。

# —— 本周课程复习 ——

# 关键词：心理

心理学科学化的时间还非常短，从经验到知识，从看上去包罗万象到满足可验证可复现的理论，观察这种转变，不仅能知道科学思维是什么，更能在研究人的情绪、行为、心理状态时，获得更稳固的答案。

265｜心理：再高的相关性也不是因果性

+   1. 只要如实地收集数据，并对数据作初步的整理，就一定会找出几对高相关的事件，但是，再高的相关性，也不能确立因果关系。\n2. 在日常生活中，人们非常容易对高相关性的事件产生共鸣，草率地把“不确定”当作“事实”去对待，强加因果关系，这不仅不利于了解真相，很多时候还会造成恶劣后果。

266｜心理：最有力思维武器-双盲实验

+   1. 任何现象，即便统计数据再多，对扎实地确认因果关系也都是无力的。\n2. 人的思考存在认识惯性，即便是训练有素的专业人员，也无法避免凭借经验进行主观判断，目前来说，只有随机双盲实验和对照组，才能把人性中那种偏袒和私心全部抹去，获得可靠的结论。

267｜心理：心理学实验的结论可靠吗？

+   1. 持相反结论的两个理论，哪个结论的一致性更高，就越可靠。\n2. 任何学科研究规范化的过程，都是尽可能在精心设计的实验下排除掉干扰因素，只有变量的数量尽量地控制得少一些，才能更好地找到高的相关因素，甚至找到因果关系。\n3. 用实验测得的心理学主流理论，是不会被“不是在自然生活条件下的表现”驳倒的。

268｜心理：科学结论成为学界共识有多难？

+   1. 人们普遍误以为科学进步都是“历史性突破”的样子，而现实情况是新理论的建立举步维艰，根源在于，很多人们把物理学曾经辉煌的过去套用在其他学科上。\n2. 科学研究的模式，是新理论建立在已有的理论之上，它不仅要能解释旧理论解释的内容，还要能比旧理论解释或者预测更多。\n3. 任何成熟学科的体系里，成立的理论不计其数，一个新的理论想要在体系内成为共识，只会越来越难。

# 答疑时间

269｜问答：病毒引发阿尔茨海默症？全球变暖停止？

+   1. 阿尔茨海默症的发病原理依然没有定论，在患者脑中发现疱疹病毒只是增加了“阿尔茨海默症微生物感染”这个假设的一个比较可靠的证据。\n2. 全球变暖没有停止，只是减速，温度还在持续升高，原因是人类排放的二氧化碳阻挡了太阳电磁波反射回宇宙的总量，这部分能量被融化的冰层和深海吸收。\n3. 全球变暖的真正危害，在于升温速度太快，是地球历史上温度平均变化速度的数万倍，没有给予生物足够的适应时间。

270｜问答：安慰剂效应有生理基础吗？

+   1. 安慰剂效应背后有生理学基础，不快乐的孤独者更容易患病，更容易出现各种红肿、疼痛、过敏。\n2. 幸福感能降低炎症因子，增加抗病毒基因的表达。\n3. 对身体的有益影响，通过参与具有伟大意义活动带来的幸福感，强于物质满足带来的幸福感。\n4. 安慰剂效应，对器质性的疾病有一定的效果，但非常微弱，远达不到通过 FDA 认证的有效药物的水平，不能因为安慰剂效应有生理基础而拒绝吃药。
