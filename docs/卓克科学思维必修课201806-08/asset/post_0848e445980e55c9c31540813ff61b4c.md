# 概念24：反思

科学是有力的，但内部也有各种问题，这些问题往往还是科学家们自我反思时公之于众的，甚至有科学家会把这些问题当做课题来研究。这让科学看起来没有那么完美，但这正是科学不断自我否定与完善的过程。

247 | 反省：圣经里的密码

+   1.现代科学、工程学跟文史哲学科的最大不同，在于它们建立在实验的基础上，需要掌握设计实验、动手操作、处理数据、分析结果等能力，这一类是无法通过自学达到研究者的程度的。2.圣经中的密码，是科学工具被胡乱使用后得出的没有价值的结果。3.科学结论的得出，具有鲜明的特征，就是可以在它的基础上积累，甚至可以用它来预测未来。

248 | 反省：科学是怎么预测未来的？

+   1.科学可以预测未来，因为预测的准确率极高，远超过自然语境下“预测球赛”“预测股票涨跌”的“预测”，它更类似于“用魔法预测未来”语境中的表达。但科学只能在极少领域做到“预测”，这个强大的能力容易被人忽视。2.准确预测未来的能力，是科学带给人类最大的力量，这种准确度，在我们衡量预测结果时，是用标准差来表示的。3.了解一些统计学常识，能让我们对“科学可以预测未来”这个结论有更深的了解。

249 | 反省：科学江湖里的潜规则

+   1.科学演化到今天，成熟的体制除了展现出公平、高效等特征，也发展出了背离科研初衷的套路与潜规则。2.科学界已经形成了足够大规模的利益集团，与其它行业一样，利益关联让它得以出现并稳固存在，而它也会自然向吸收更多资源和利益的方向演化。3.了解科学，离不开历史、商业、政治这些大背景，直面科学的不完美，也是全面理解科学的重要的一部分。

250 | 反省：那些真性情的论文

+   1.科学论文的范式如果不被滥用，将会出现很多有个性的论文表达方式，它们散发的是智慧，也会有更多务实的内容，让科学的表达更具有多样性。2.尽管科学论文规范和“江湖规矩”一定程度上阻碍了科学进展，但它仍是目前最高效的筛选优质论文的方法。
