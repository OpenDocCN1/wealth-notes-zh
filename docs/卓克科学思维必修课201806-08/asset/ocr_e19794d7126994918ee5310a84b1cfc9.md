# ——◆ 课后思考题 ◆——

你认为一个对神有信仰的人，会比一个无神论者更幸福吗？

如果你有什么思考，就留在评论中。

划重点

+   1. 信神的生物演化视角，指的是 一种行为在客观上会增加生存几率，这种行为的后代就会更多的出现。 2. 宗教，是灵长类动物智力发达之后的副产品，它的形态会随着智力成果的进步而提升，但信什么样的神，是分三六九等的，尤其体现在对神的抽象上。 3. 不论是人类文明的发展，还是一个人从孩童到成人的发展，思维能力的进步，都是高度一致地体现在抽象能力上的。

信神的人不会比无神论者更幸福，因为他们往往将希望寄托于深的庇佑，然而对于随机的事件，甚至是大概率会失败的事件，一旦产生事与愿违的结果就会严重的破坏神的神圣性，因此他们内心就会产生怀疑纠结的情绪，究竟是自己做错了，还是他们信仰的神根本就不存在，当他们产生这种负面情绪时幸福感就会陡然下降

我认为幸福是一个主观概念。有的人习惯了活在舒适区，对确定的事物有强烈需求，而这个事物是否正确不重要。宗教刚好能满足这种需求。而有的人对任何事物都有强烈的好奇心，总想弄明白背后的道道。对这种人宗教反而会带来不安全感。现代社会的知识体系早就了越来越多后者，相信有越来越多的人会在宗教之外获得幸福和安全感。顺便说句，这个话题应该到了期节目的高潮，越来越期待卓老板后面的节目了！

伯鞅
这个问题如果理解成，随机找一个信神和不信神的，信神者是不是总比不信神者更幸福？我的答案是不。
如果要用科学方法来研究这个问题，那就要先把幸福感量化，还要限制研究对象的条件，这实在太难做到了。
但是我相信许多无神论者都是和我一样有经历过从有神论者变成无神论者的过程，如果问我愿意回到有神论者的状态吗？我会说不。
当然也可能存在从无神论者变成有神论者的人。

小白杨
不如换个词来回答问题，一个对“想象共同体”坚定者会比“想象共同体”幻灭者大脑中有更强的愉悦感嘛，我的答案是肯定的，智人是群居物种，大脑中抱持共同体信念是一种扣团取暖的安全感，回音室里的暖流也会更强烈的反馈与你。
但正如赫胥黎《美丽新世界》所呈现的新世界，我不知道在新世界里的人是否更幸福，但能感受到“野蛮人”约翰的悲哀。对于自由意志的人而言，是沉迷欢快其中更幸福还是逃离到独立空间才算的上幸福呢

想不出来啊
无神论者的世界图景建立在事实证据和观测结果的坚实基础之上，即使碰到暂时无法解释和事物也并不求助于超自然的存在——因为无路可退。只能依靠新的证据改进已有的解释，哪怕忍受长久的困惑。信仰神的人无论遇到任何困难，都可以随时退守到神的脚下，给自己一个台阶，得到心理上的安宁。从这个方面看，由于信神的人有心理上非常稳固的彼岸（只要愿意就能随时靠港停泊），而无神论者没有，我感觉信仰神会比较幸福。
但另一方面，在神的庇护下停止脚步就意味着放弃对某些问题的思考或者闭目塞听；无神论者因为不肯放弃思考和追问又能获得多种角度欣赏风景的快乐，这种通过思考得到的幸福又是前者无法体会到的。
最后，我感觉在不触及深层次终极问题和追问终极意义的情况下，无神论者和信仰神的人完全可以没啥差别。日常生活大家游走在两者之间（大多数人可能都处在这种模糊状态）对幸福感并没有啥大影响。
