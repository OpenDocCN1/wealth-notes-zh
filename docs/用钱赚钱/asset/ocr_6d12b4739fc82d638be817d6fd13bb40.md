# 做好收藏投資的規劃

俗話有「盛世藏古董」之說。收藏除了可以用來欣賞之外，還是一種保值、增值的有效投資方式。有理財專家統計，當前金融證券業的平均投資回報率是15%左右，房地產業是21%，而藝術品收藏投資卻在30%以上。無疑地，藝術品收藏的高回報率已經成為时下最為賺錢的行當。

收藏品帶來的名利成為了眾人追逐的對象，很多人為收藏的魅力所吸引。當然，收藏品投資並不是只賺不賠的買賣，收藏品投資也像其他的投資一樣，風險無處不在，需要進行一個合理的規劃。

# 收藏要有超前意識

搞收藏應具備前瞻性眼光。作為一名收藏投資者，洞察市場潛在熱點的前瞻性眼光最為重要，也就是對未來市場趨勢的把握。在20世紀70年代至80年代，一些地方的古玩交易就已經十分活躍，當時古玩市場上的藏品不僅價品少、而且價格低，還有很多精品、珍品。當時一些有前瞻性眼光的收藏家認為，隨著中國經濟的發展，人民生活水準的提高，藝術品收藏必將成為一個新的投資熱點。當時潘天壽、齊白石、徐悲鴻的書畫每幅才100多元，而到現在這些書畫早已经高達幾十萬甚至幾百萬元了。
