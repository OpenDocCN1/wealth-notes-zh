# 面積要適宜

隨著小户型熱潮的興起，預售房的套內面積稍稍降了一些，但是許多購房者仍然認為住房面積愈大愈好，似乎小於100平方米的住宅就只能是何級消費的臨時過渡產品。甚至一些經濟適用房也名不副實，大戶型、複式戶型層了不大少，致使消費者也被誤導，覺得大面積、超豪華的住宅才好。其實尺度過大的住宅，人在裡面並不一定感覺舒服。從經濟上考慮，不僅購房支出大，而且今後在物業、取暖等方面的支出也會增加。

住宅橫文的高低其實不在於面積的大小，三口之家面積有70平方米至30平方米基本就能夠滿足日常生活需要，關鍵的問題在於住宅是否經過了精心設計，是否合理地配置了起居室、臥室、餐廳等功能，是否把有限的空間充分利用了起來。

# 公攤面積要合理

購房者買房時，一定要注意公攤面積是否合理，一般多層住宅的公攤面積較少，高層住宅由於公共交通面積大，公攤面積較多。同樣使用面積的住宅，公攤面積小，說明設計經濟合理，購房者能得到較大的私有空間。但值得注意的是，公攤面積也並不是愈小愈好，比如變過過狹窄，肯定會減少居住者的舒適度。

# 物業收費合理，服務到位

買房時購房者一定要問問，物業公司是是否進入了項目，何時進入項目。一般來說，物業公司介入項目愈早，買房者受益愈大。
