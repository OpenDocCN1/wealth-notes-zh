# 要想玩轉股票，K線圖一定要看懂

投資股票是最常用的理財方式，股票即是「股份證書」的簡稱，是股份公司為籌集資金而發行給股東作為持股憑證，並藉以取得股息和紅利的一種有價證券。每股股票都代表股東對企業擁有一個基本單位的所有權。通俗地說，股票就是一張資本的憑票。民眾可以根據自己的意願將手中的貨幣投向某一家或幾家企業，以博取股票價格波動之差異或是預期企業的未來收益。由此不難看出，股票即指股份公司發給股東作為已投入股的證券與索取股息的憑證。股票的魅力就在於高收益和高風險。

在進入股市前，最好對股市有些初步的瞭解。可以先閱讀一些關於股票的書籍，掌握一些基本用語，逐漸做到能夠看懂股票類的報紙和聽懂股票廣播。這其中，能看懂K線圖是證券投資的基本功。所謂K線圖，就是將各種股票、每日、每週、每月的開盤價*、收盤價*、最高價、最低價等漲跌變化狀況，用圖形的方式表現出來。

K線圖有直觀、立體感強、攜帶信息量大的特點，蘊涵著豐富的東方哲學思想，能充分顯示股價趨勢的強弱、買賣雙方力量平衡的變化，預測後市走向較準確，是各類傳播媒介、電腦即時分析系統應用較多的技術分析手段。

K線最上方的一條細線稱為上影線，中間的一條粗線為實體，下面的一條細線為下影線。當收盤價高於開盤價，也就是股價走勢呈上升趨勢時，我們稱這種情況下的K線為陽線，中部的實體以空白或紅色表示。這時，上影線的長度表示最高價和收盤價之間的價差，實體的長短代表收盤價與開盤價之間的價差，下影線的長度則代表開盤價和最低價之間的差距。當收盤價低於開盤價，也就是股價走勢呈下降趨勢時，我們稱這種情況下的K線為陰線，中部的實體以黑色或綠色表示，上影線和下影線分別代表收盤價與最高價、開盤價與最低價之間的價差。
