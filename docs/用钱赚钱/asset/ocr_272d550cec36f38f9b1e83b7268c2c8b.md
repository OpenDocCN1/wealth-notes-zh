長，表示賣方實力愈強。上影線實體小的形態，常出現在階段性的頭部或震盤*洗盤中。

# 帶下影線的陰線

這是先跌後漲型，反映股價在低位獲得買方支持，賣方受挫，常出現在市場底部或市場調整完畢。

# 帶下影線的陰線

這是下跌抵抗型，表示空方力量強大，但在下跌途中一定程度上受到了買方的抵抗，常出現在下跌途中、市場頂部或震盪行情中。

# 帶上下影線的陽線

表示下有支撐，上有壓力，總體買方占優，常出現在市場的底部、上升途中。上影線長，說明上方壓力大；下影線長，說明下檔支撐強，實體愈長，說明多方實力強。

# 帶上下影線的陰線

表示上有壓力，下有支撐，總體空方占優，陰線實體愈長，表明空方做空的數量愈大。常出現在市場頂部或下跌途中。

+   * 震盤、又稱洗盤、洗盤，股市術語，是大型投資者向散戶收集優質股票的常見手法。
* 做空：指賣出您當前並未擁有的資產，寄望於低價買回這些資產並獲利，當交易結束交易從而獲利。行為亦稱為賣空。
