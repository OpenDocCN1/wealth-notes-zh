# 訂金

在二手屋交易中，因為訂金的問題經常發生買賣雙方衝突。訂金是對買方的約束，如果賣方收取了訂金而違約，就要雙倍返還訂金。

收訂金後，如果買方沒有按時履行約定，賣方將房轉賣他人應該手握對方退房申請，最好讓買方寫書面申請退房，否則將要雙倍返回訂金。

購房合約對雙方當事人都具有法律約束力，任何一方不得擅自變更或解除合約。如果買房人違約在先，買房人可不退訂金。買房人沒有以書面方式明確表態不履行，則房主在未解除合約也不退訂金的情形下將房子賣給他人的行為就違反了合約。

對於房主而言，若買房人提出退房或解除合約，應要求買房人提出書面解約的申請或證明，以保全對方違約在先的證據，然後才可以將房子賣給協方贖商。

# 付款方式

房款如何支付，必須在合約中詳細寫清楚。買買房子屬於大宗交易，所以交易如何付款，如何收款一定要詳細說明，而最好找到合適銀行託管，以防止生變。

雙方簽訂買賣合約時，應對付款流程、方式和時間做出明確、具體的約定。買房人如果將購房款交給中介公司再轉交賣方，應先審查中介公司的資質狀況。特別是能不能將購房款交給中介公司的個別職員，防止他們卷款潛逃。
