# 選擇投資專案5原則

找到一個好的投資項目等於投資成功了一半，起步對了，後面的路就不會走得冤枉。那麼在實際選擇投資項目的過程中，怎樣選擇才算是選對了呢？以下原則能在我們選擇投資項目時起到指引的作用。

# 高回報

這要求所選擇的企業應是高速成長型，至少年成長速度在10%以上的發展領域。

# 產品和服務具有獨特性

你所選擇投資的企業有獨一無二的優勢嗎？這些優勢體現現在技術、品牌、成本等方面，而這些優勢能保持多長時間，也是你投資取敗的重要原因之一。

# 要有風險意識

無論你選擇哪一個投資專案，都會有風險。如何規避風險應放在選擇投資專案的首位。因此，在選擇投資項目時不要光想著如何賺錢。應該時刻想著如何不賠錢，不賠錢就是賺錢。
