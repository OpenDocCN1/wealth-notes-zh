# 貨幣市場基金

貨幣市場基金是用貨幣市場工具為投資對象的基金，主要投資對象有：短期國債、中央銀行票據、商業匯票、銀行承兌匯票、銀行定存和大額轉帳的存單。像國華貨幣 A（160606）、博時現金收益（050003）、景順長城貨幣（260102）、上投摩根貨幣市場 B（370011）、招商現金增值（217004）、易方達貨幣基金 A（110006）、華夏現金增利（003003），這些屬於貨幣市場基金。

貨幣市場基金是怎麼運作的呢？貨幣市場基金面值永遠是 1 元。面值永遠是 1 元，怎麼計算盈利呢？主要體現的是分紅和收溢率。貨幣市場基金，只要存一天錢，貨幣基金會給你一天的利息，所以它既是每天計息，每月都會分紅，當然有的是按天分紅，還有的是更長一點時間的分紅，主要是看每個貨幣基金的特點。

貨幣市場基金免除利息稅。如果我們到銀行存款，獲得利息要交納 5%的利息稅，而貨幣市場基金免除 5%的利息稅。

貨幣市場基金免收申購贖回費用。貨幣市場基金在申購和贖回的時候，是免收這些費用的。它只是收一些託管費、管理費和銷售費用。在千分之三到千分之五以下，這個費用很低。它的收益高於銀行儲蓄，也比較安全適合替代儲蓄。特別是在股市出現大熊市的時候，貨幣基金就可以替代偏股型和股票型基金，近以於保本。因為還有一些不確定的因素，例如通貨膨脹加大，如果貨幣基金收益 5%，現在通貨膨脹為 6%，這樣看似保本，實際也有一定的損失，所以它叫做近似於保本。

讀者可能會說：誰買它呀？貨幣市場基金漲得那麼慢，股票型基金多好啊，獲利比貨幣型基金多幾倍。但是如果是在熊市中間買入股票型基金，虧損風險很大，更不好說獲利了，如果在熊市買了貨幣市場基金，不僅有收益，收益還要高於銀行的存款。
