# 小人書的收藏

「小人書」學名叫連環畫，是中國獨有且歷史悠久的出版物，源於白描畫本、繡像本等傳統藝術形式，20 世紀 20 年代在上海興起。由於其特有的藝術形式、獨特的反映故事手段、歷久彌革中產生了特殊作用等特點，「小人書」近年來伴隨收藏投資市場的日益活躍而身價上浮。業內公認它是繼瓷器、書畫、錢幣、郵票之後的「第五大收藏」。

以運作「小人書」而取得良好收益的投資收藏者不少見。曾說有一位收藏愛好者，一天在地攤上發現 10 餘本品質、外觀絕佳的 20 世紀 60、70 年代出版的連環畫後，狠下心掏出 200 元買下了，沒走出幾步，就被一位收藏家瞧見，硬是塞給他 2200 元後拿走。可見小人書收藏的潛力是很大的。

如果您真的喜歡小人書，並準備投資收藏的話，就需要對它有更深層次的瞭解。因為不是所有的小人書都具有收藏價值和升值潛力。

# 名家名品、獲獎佳作，應是首選

因為小人書不僅是一種大眾通俗美術讀物，也是一種繪畫藝術品。許多優秀作品都是當代的繪畫大師創作的。如：劉繼卣的《武松打虎》、王叔輝的《西遊記》、《生死牌》、《楊門女將》、陳緣督的全套《水滸》、獲獎作品《蔡文姬》、《楓》、《鑑真》等。這些作品內容豐富、嚴肅，具有很高的收藏價值。劉繼卣的《雞毛信》、《東郭先生》，王叔暉的《西遊記》、《孔雀東南飛》，程十發的《膽劍篇》、《孔乙己》、《阿Q 108 圖》，劉旦宅的《屈原》等也很有收藏價值。
