# 光頭光腳小陰線

此形態表示開盤價就是最高價，收盤價就是最低價，價格波動幅度有限，表示買方力量有所增加，買賣雙方空方力量暫時略占優勢。此形態常在下跌初期、橫盤整理或反彈結束時出現。

# 光頭光腳長陰線

沒有上下影線，表示多方走勢強勁，買方占絕對優勢，空方毫無抵抗。經常出現在脫離底部的初期、回檔結束後的再支上漲，及高位的拉升階段，有時也在嚴重超跌後的大力度反彈中出現。

# 光頭光腳長陰線

沒有上下影線，表示空方走勢強勁，賣方占絕對優勢，多方毫無抵抗。經常出現在頭部開始下跌的初期、反彈結束後或最後的打壓過程中。

# 帶上影線的陽線

這是上升抵抗型，表示多方在上升途中遇到了阻力，此形態常出現在上漲途中、上漲末期或股價從低位啟動到密集成交區，上影線和實體的比例可以反映多方遭阻的程度。上影線愈長，表示壓力愈大，陽實體的長度愈長，表示多方的力量愈強。
