# 在用家庭資產投資火爆的資本市場取得較高投資回報時，為什麼依然要堅定分紅保險的購買

事實上，分紅保險不是唯一的家庭投資理財產品，購買分紅保險也不是收益最高的投資理財手段，但分紅保險既有保障、又能取得長期而穩定的收益，從而從根本意義上解決家庭投資理財活動中最需解決的一生意務規劃：現有資產在通貨膨脹的過程中依然保值增值的問題。分紅保險的這些功能作用是其他金融理財工具所不具備的，因此也必然成為最適合普通家庭的金融產品，在家庭投資理財工具組合中成為重要的一個組成部分，也必將發揮愈來愈重要的作用。所以，當我們借力火爆的資本市場透過投資活動取得較好的投資回報時，理應在增量資產的再配置過程中加強家庭理財金字塔的塔基部分，更多地採用不同的分紅保險品種，為自己和家人的一生幸福美滿生活打下更扎實的保障基礎。
