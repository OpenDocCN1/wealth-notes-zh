# 期貨交易的特點及基本程式

期貨交易是 21 世紀世界上最偉大的投資之一，特別是隨著現代經濟與資訊技術的發展，投資者透過期貨投資參與全球金融市場，其收益是顯而易見的。

期貨交易是在現貨交易的基礎上發展起來的，是指交易雙方在期貨交易所買賣期貨合約的交易行爲。期貨交易的物件並不是標的物的實體，而是標的物的標準化合約。期貨交易的目的是爲了轉移價格風險或獲取風險利潤。

# 期貨交易的特點

# 以小博大

槓桿原理是期貨投資的魅力所在。期貨市場裡交易無須支付全部資金，由於保證金的運用，原本行情被以十餘倍放大。假設某日金價格漲停（期貨型漲停僅爲上個交易日的 3%），如果我們操作正確，資金的利潤率達到 60%（3% ÷ 5%）。當然，如果操作錯誤，損失也被放大，所以期貨交易風險高。

# 交易便利

由於期貨合約中的主要因素（如商品品質、交貨地點等）都已標準化，合約的互換性和流通性較高。另外，期貨是「T＋0」的交易，你可以隨時交易，隨時平倉，使資金的應用達到極致。
