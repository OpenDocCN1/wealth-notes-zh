# # 奇石

它與工藝石的最大區別：一方面它是經過大自然磨礪而形成的，形態、材質、色泽、紋理等元素獨特而自然，且缺一不可，又無人為雕琢或打磨的痕跡；另一方面，它還具有較高的觀賞價值或收藏價值，其價值重點體現五大要素上：形、色、質、紋、韻，天然形成，更重要的是「韻味」無窮，文化內涵豐富。

# # 觀賞石

顧名思義，它是指具有一定觀賞價值的石頭，既包含了奇石，又包含了工藝石。在日常賞石活動中出現的經拋光、開片、去底等方式改變石頭形態後的石頭藏品，是為了突出石頭的「紋」、增強石頭的「韻味」、拓展石頭的文化內涵、提高石頭的觀賞價值。如：雨花石、草花石、大理石等。它的價值主要體現在石頭的質、色、形、紋及其所包含的文化氛圍。

# # 工藝石

它是透過人工和物理的方法將原始自然的石頭和岩石打磨成某一狀態的物品，或在石頭上人工雕刻、拼繪成某一圖案，或黏接組合成某一主題的作品等，形成可觀賞或收藏的石頭商品。這種透過人工或物理作用，將石頭變成一種具觀賞性和收藏性為一體的石頭，稱之為工藝石。如：石雕、石刻、石畫等。工藝石的價值主要體現在石質自身和雕刻、繪畫工藝上或作品的巧妙構思上。
