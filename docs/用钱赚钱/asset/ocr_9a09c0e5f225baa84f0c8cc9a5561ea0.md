# 處於熊市時的操作技巧

# 積極求和法

當收藏者預期某種收藏品的市場行情會上漲時，可以買入這種收藏品。但是，如果市場行情創出人意料地反向跌了，收藏者該如何做出一決無呢？如果收藏者預期市場行情依舊會反彈，那麼，為了挽回大勢，他就應該下定決心，在市場行情一跌再跌時，不斷買入這種收藏品，以壓不斷分擔自己的總投資成本。在收藏者處於不利的情況下，如果採取消極的方式買草收兵，將會造成或多或少損失。但是，如果將積極求和法運用得當的話，那麼，收藏者不但可以部分甚至全部地挽回損失，有時候甚至還可以獲利不少。

如收藏者預期某種收藏品的價格會上漲，因此，買入了這種收藏品，但沒料到的是，收藏者的預期並不正確，這種收藏品的價格不漲反跌了。那麼，他實際上還可以在這種收藏品的價格不斷下跌的過程中，分別以更低的價格繼續買入這種收藏品，從而降低平均買入成本。等到這種收藏品的價格開始反彈後，再尋找有利時機，例如：等價格上漲後再將這這收藏品一次性脫手，或者分批賣出。對於收藏者而言，積極求和法的關鍵在於資金占用的時間通常會比較長。因此，收藏者必須考慮到資金占用的機會成本。此外，收藏者還應該選擇恰當的出手時機，以免错失良機而被再度「套牢」。

# 捨小求大

如果收藏者預期行情將上漲，買入了某種收藏品，但是，市場行情卻反向跌了，而且，似乎還有一跌再跌的趨勢。此時，收藏者就應該在損失還不是太大時先行將收藏品賣出。在這種收藏品繼續下跌的過程中，再伺機買入，從而挽回過去的損失。這就是捨小求大法。

從某種角度來看，捨小求大法與積極求和法，似乎有幾分相似之處。
