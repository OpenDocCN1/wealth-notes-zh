# 工作再忙也要記得理財

「有時間賺錢、沒時間打理」，已經成為現代很多年輕人的通病。「忙人」們為數衆多，他們因為「忙」而帶來的財富損失，尤其是機會成本也是不可小覷的。儘管「你不理財，財不理你」的理念早已深入人心，可在現實生活中，有錢無間的理財「忙人」依然為數衆多。

黃先生是一家房地產公司的業務員，不僅工作忙碌，又是公司的業務主管，每天工作都很忙。於是工資便往由會計打進銀行卡裡，最多買東西時刷刷卡，多餘的錢就在卡裡放著。當理財專家對他提出理財建議時，黃先生卻抱怨說：「我哪有時間打理錢財呀？朝九晚五地上班，加註是家常便飯，難得有個空間的時間，也只能躺在床上看看電視或者是睡個懶覺，逢上週末，還需要進行自我充電，生活中邊培養自己愛好情趣的時間都沒有，更別說每天看看股市行情，或者研究市場上新出什麼理財產品了。」

這或許就是大多數上班族的真實際現吧，這一類人多因為工作的原因而沒有時間對投資市場做更多的研究，因此他們並不適合一些技術性很強的投資品項，如匯市、期市等。對於這一類人而言，來自銀行的理財產品或許更為適合他們，因為無需大量資金的頻繁轉移，譬如基金等相對於較普及的投資品項就非常適合他們，因為他們可以適當承擔一些風險，也期待更高一點的收益。
