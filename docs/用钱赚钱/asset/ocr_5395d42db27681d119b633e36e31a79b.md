部傾向於買盡善盡美、世間少有的收藏品。品質與外觀好的收藏品可以賣出好價錢；品質與外觀差的收藏品價格就會較低。因此，一定要注意收藏品的品質與外觀好壞，以規避其風險。從收藏投資的角度來看，對於供給彈性較大的收藏品而言，一定要非常注意其品質與外觀問題。因為當投資者著想轉讓收藏品的时候，買方的選擇餘地是很大的。但是對於供給彈性小的收藏品來說，品質與外觀問題就顯得相對次要一些，不過，如果投資者收藏者在購買的時候，以此作為計價還價的籌碼，花適當的價格購人的話，可以在很大程度上規避因為收藏品品質與外觀問題而帶來的風險。

# 規避贗品風險

防範贗品風險是投資收藏品最重要的一條。無論是拍賣市場還是收藏市場，贗品的陷阱比比皆是。當你踏入市場後，稍有不慎就有可能跌入陷阱，難以自拔。因此，對於初涉者，進入收藏品市場要謹慎操作。對於自己熟悉的、把捉大的收藏品，應該冷靜分析，明察秋毫。對自己拿不准的、把捉小的收藏品，愈是珍稀品項，愈要格外小心，最好是請信得過的專家幫助鑑別。如果需要當機立斷做出購買決定，沒有轉圜的餘地，也應以儘可能低的價格購買真僞尚不明瞭的收藏品。
