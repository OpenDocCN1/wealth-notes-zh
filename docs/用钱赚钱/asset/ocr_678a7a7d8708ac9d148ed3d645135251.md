# 不該迷的理財課

曾經有這樣一種概念：「理財是有錢人應該考慮的事情，有錢人才需要理財。」在很多人的腦海中，一說到理財就會聯想到銀行理財顧問為有錢人彙報每年的資產收益。就像和年輕人聊起理財的話題，最常聽到的說法就是「我無財可理」。乍聽之下，讓人覺得年輕人剛剛從學校畢業，工資不高而開銷不低，很容易成為「月光族」，甚至出現了透支好幾張信用卡的事，理財似乎離他們很遙遠，但真的是這樣嗎？

小王，大學畢業，剛工作半年，每个月的工資是2600元；小劉，專科畢業，也是一畢業就工作，每個月工資是1500元。他們在生活支出上基本差不多，都是單身，除了一些基本生活開銷，其他只有偶爾和朋友一起聚會的消費支出。

如果單純按照收入來比較的活，小王每個月的收入比小劉多，他應該比小劉更具備理財的條件。可事實並非如此：他們兩人的工資均是每個月初領取，結果半年後，小劉存了3300元，小王卻存不到600元。

這是個很奇怪的現象吧？既然生活開支基本上類似，而收入較高的小王半年之後卻只存下了600元。這並不是因為小劉有其他的收入，而是小劉更懂得規劃自己的收入和支出。讓我們來分析一下他們各自的具體財務情況：
