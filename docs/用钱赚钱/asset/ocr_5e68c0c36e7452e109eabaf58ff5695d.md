# **債券價格**

債券價格包括發行價格和交易價格兩種。

債券的發行價格是指債券發行時確定的價格，可能不同於債券的票面金額。當債券的發行價格高於票面金額時，稱為溢價發行；當債券的價格低於票面金額時，稱為折價發行；當兩者相等時，稱爲平價發行。選擇何種方式取決於二級市場的價格以及市場的利率水準等。

債券的交易價格是指債券離開發行市場進入交易市場時採用的價格，由利率以及二級市場上的供求關係來決定，通常與票面價值是不同的。

# **償還方式**

償還方式分爲期滿後償還和期中償還兩種。主要方式有：選擇性購回，即有效期限內，按約定價將債券回售給发行人。定期償還，即債券發行一段時間後，每隔半年或者 1 年，定期償還一定金額，期滿時還清剩餘部分。

# **信用評級**

信用評級即測定因債券发行人不履行而造成債券本息不能償還的可能性。其目的是把債券的可靠程度公諸投資者，以保護投資者的利益。

+   * 臺灣的債券期限：短期債券爲 3 年內；中期債券爲 3 年～ 10 年；長期債券爲 10 年以上。

+   * 臺灣的付息方式：分爲單利債券、複利債券、貼現債券、累進利率債券四種形式。
