# 個人炒匯如何開戶

目前民眾的外幣資產絕大部分存在銀行裡，經過多次外幣存款利率的下調，現在透過儲蓄來實現外匯資產的保值和增值愈來愈困難了。於是很多投資者都把目光投向了炒匯。那麼，我們應該如何開戶？

目前各大中城市的中行（「中國銀行」簡稱）、工行、交行（「交通銀行」簡稱）、建行均已開辦此項業務，凡持有有效身份證件，擁有完全民事行為能力的境內居民，均可進行個人實盤外匯交易。

個人可以持本人身份證和現金去銀行開戶，也可以將已有的現匯賬戶存款轉至開辦個人外匯買賣業務的銀行。

如果採用櫃檯交易，只需將個人身份證件以及外匯現金、存摺或存單交給櫃面服務人員辦理即可。中國銀行、交通銀行沒有開戶起點金額的限制，工商銀行、建設銀行開戶起點金額為50美元。如進行現鈔交易不開戶也可以。

如果採用電話交易，需帶上本人身份證件，到銀行網點辦理電話交易或自主交易的開戶手續。交通銀行的開戶起點金額為300美元等值外幣，工商銀行的開戶起點金額為100美元等值外幣。
