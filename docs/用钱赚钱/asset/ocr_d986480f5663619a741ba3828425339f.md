# 市場不明朗決不介入

缺乏經驗的投資者，在開設買入或賣出某種貨幣之後，一見有贏利，就立刻想到平倉收錢。獲利平倉做起來似乎很容易，但是捕捉獲利的時機卻是一門學問。有經驗的投資者，會根據自己對匯率走勢的判斷，決定平盤的時間。如果認為市場走勢會進一步朝著對他有利的方向發展，他會放棄性子，明知有利而不賺，任由匯率盡量向著自己更有利的方向發展，從而獲利闊延續。一見小利就平盤不等於見好即收，到頭來，搞不好會贏少輸多。

在外匯市場上，沒有必要每天都入市炒作，特別是市況不明朗的時候，一定要學會等待。初入市者往往熱衷於入市買賣，但成功的投資者則會等機會，當他們入市後感到疑惑時亦會先行離市。他們在外匯交易的時後，一般都秉持「謹慎」的策略。外匯交易切忌賭博的心態，如果用賭博的心態，十之八九都要輸。孤注一擲的交易方式往往會伴隨著虧損，做外匯交易，也需要穩紮穩打，只有看準機會，才可以在大筆投入。而且，外匯保證金的交易方式，具有槓桿放大的效果，贏利當然可以放大，但是虧損也同樣會被放大。如果投資者盲目入市，遭遇巨大虧損的可能性非常大。

# 止損是炒匯賺錢的第一招

波動性和不可預測性是市場最根本的特徵，這是市場存在的基礎，也是交易中風險產生的原因，這是一個市場本身固有的特徵。交易中永遠沒有確定性，所有的分析預測僅僅是一種可能性，根據這種可能性而進行的交易自然是不確定的，不確定的行爲必須得有措施來控制其風險的擴大，而止損就是最得力的措施。
