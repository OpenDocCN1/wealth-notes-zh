# 分紅保險銷售過程中亟待解決的若干問題

+   分紅保險能夠真正有效抵禦通貨膨脹的關鍵因素是什麼
• 險種設計本身確保資金本金安全，最大限度滿足了家庭投資理財的第一需求點，也就是保證現有資金的安全。 • 借助機構專家的投資活動，並透過分紅的形式，取得個人無法企及的高收益，真正做到了“機構理財，借力為取”。 • 複利的運用，借助時間長度的累積，使現有的財富在未來幾十年後呈幾何級數增長，因此即便面對市場利率的頻繁變動，依然能有效地抵禦通貨膨脹。確保現有資產的貨幣購買力在幾十年後依然同等擁有甚至更高，真正做到現有資產在未來的保值增值，從而達成家庭投資理財的根本目的。

# 為什麼最初若干年分紅水準比較低

其實世界各國只要銷售分紅保險，都會呈現出在購買分紅保險最初的 6 到 8 年的時間裡，分紅水準相對比較低的狀況，而隨著時間的推移，分紅水準會一路高漲，維持在一個相對良好的收益水準上的基本分紅走勢。而在最初若干年分紅水準相對較低，究其原因主要有以下幾點：

+   • 開辦新的壽險公司、推出新的壽險險種，一般來說壽險公司都需要付出高額成本。最初若干年所收到的保費能夠真正投入資本市場運作的資金數量有限，因此難以取得較高的分紅收益。
