發展方向，當建倉方向與價格波動方向一致時，用備用資金加碼建倉；當建倉方向與價格波動方向相反時，又可回避由於重倉介入而導致較重的交易虧損。當投資者持倉處於虧損之際，除了投資者需準備充足資金進行逆勢操作之外，一般來說，投資者不宜加碼，以免導致虧損加重、風險增加的不利局面發生。

# 賺錢不宜輕易平倉，要讓贏利積累

將賺錢的合約賣出，獲小利而回吐，將可能是導致商品投資失敗的原因之一。假如你不能讓利潤繼續增長，則你的損失將會超過利潤並把你煙烤。成功的交易者說，不可只為了有利潤而平倉。當市場大勢與投資者建倉方向一致之際，投資者不宜輕易平倉，在獲利回吐之前要找到平倉的充分理由。

# 學著喜愛損失，隨時準備接受失敗

「學著喜愛損失，因為那是商業的一部分。如果你能心平氣和地接受損失，而且不傷及你的元氣，那你就是走在通往商品投資的成功路上。」期貨投資作為一種高風險、高贏利的投資方式，投資失敗在整個投資中是不可避免的，也是投資者吸取教訓、積累經驗的重要途径。投資者面對投資失敗，只要仔細總結，就能逐漸提高投資能力、回避風險、力求贏利。
