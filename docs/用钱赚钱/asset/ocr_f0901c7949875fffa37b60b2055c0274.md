# 實業投資要避開的 5 大誤區

在實業投資過程中，做決定之前，一定要從方法、思維、技術等方面入手，細致分析，迴避投資的誤區，減少投資的風險。

# 投資項目過於單一

由於資源和資金的集中，單一投資在專案選擇正確的情況下，常常會給企業帶來好的收益。但單一投資的風險也是顯而易見的，放大了的風險只要發生一次，就可能使投資者多年積累起來的財富毀於一旦。

投資過於單一，就像把所有雞蛋放在同一個籃子裡，一旦籃子打翻，雞蛋也就全部摔破了。而由多專案構成的組合性投資，可以大大減少單一投資所帶來的投資風險。特別作為一名缺乏經驗的創業投資者，在進行投資決策時，一定要盡可能拓展投資思路，培養多元化投資思維方式，在保持投資專案的多元化同時，也應注意在項目與資金之間達成平衡。
