# 聽信小道消息

股價投資10忌

著名投資經理，《投資者商業日報》的創辦人威廉·歐奈爾這樣說過：「我不管你是個職業投資家，還是一個投資新手，我知道你一定會犯錯誤。對此你應該怎麼辦呢？是否想另買一條路徑並且設想錯誤會走開？如果有這樣想法的話，那就不要進入市場。」

可見，股民初入股市，由於經驗不足等因素，犯錯是必然的，任何股民入市都要「交學費」。既然犯錯是不可避免的，關鍵就是要想方設法少犯錯誤，減少損失。從這個意義上說，少犯錯就等於多賺錢。以下講的是新股民容易犯的致命的錯誤，希望剛入市的朋友能夠盡量避免。

股市是一個變化莫測的地方，各種消息、預測往往滿天飛。一般投資者尤其是新股民由於對股市行情沒有太大把握，自然對各種消息特別敏感，一有風吹草動就會買然行事，因此往往吃虧。投資大師巴菲特曾說過：「我從來沒有見過能夠預測市場走勢的人。」證券分析之父葛拉漢也曾說過這樣的話：「如果說我在華爾街60多年的經驗中發現過什麼的話，那就是沒有人能夠成功地預測股市變化。」由此可見，在股市中唯一可以確定的是「不確定」，根據一些不知是真是假的消息來買賣股票絕對是一種不明智的行為。
