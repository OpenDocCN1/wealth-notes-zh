# 如何規避外匯投資的風險

投資者決定投資外匯市場，應該仔細考慮投資目標、經驗水準和承擔風險的能力。在外匯市場上遭受一部分或全部初始投資的損失的可能性是存在的，因此不應該以不能全部損失的資金來投資，並且還應該留意所有與外匯投資相關的風險。否則，不控制風險，隨意操作，要想從外匯市場上賺錢簡直就是天方夜譚。要控制風險就要做好投資計畫，設好止損點，堅持操作紀律，順勢而為，巧妙解套。

# 制定投資計畫

這是投資者最重要、最經常性的工作之一。在外匯投資過程中，沒有投資計畫，盲目行動，最終的結果只有一個字——「虧」。

投資大師巴菲特曾說過，他可以将大谈他的投资哲学，有时候也会谈他的投资策略，但他绝不会谈他的投资计划。因为，那是重要的商业秘辛，是核心竞争力集中体现。每个投资者水准如何，业绩差异多大，最终要落脚在投资计划上。由此可见投资计划的重要性了。

# 順勢交易是外匯市場制勝的祕訣

人們在買賣外匯時，常常片面地著眼於價格的浮動而忽視匯價的上跌下趨勢。當匯率上升時，價格越來愈貴，愈買愈不敢買；在匯率下跌時，價格愈來愈低，愈低愈覺得便宜。因此實際交易時往往忘記了「順勢而為」的格言，成為「逆市而為」的錯誤交易者。
