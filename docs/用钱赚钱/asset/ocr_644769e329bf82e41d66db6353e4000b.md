# 銀行信託理財產品

隨著滬、深股市的盤整震盪，以及開放式基金淨值的變化起伏，人們把目光又轉向了風險相對較低的銀行理財產品。有關資料顯示，股市從6000多點回落以來，購買銀行理財產品的人數明顯增多。但面對琳瑯滿目的銀行理財產品，很多投資者感到非常困惑：銀行理財產品到底是怎樣運作的？個人投資者又該如何正確選擇銀行類理財產品呢？

可考慮用信託項目類理財產品代替股票。信託專家類型產品是指投資者將資金委託給銀行，並指定銀行作為代理人，代其與中國信託公司簽署《資金信託合同》，從而進行資金信託理財。信託產品的投向一般為國家或者市政府的重點工程，投資者可根據信託計畫投資物件的信用狀況獲得理財收益。

它的門檻比直接購買信託產品低。普通信託計畫的投資起點較高，當個人直接購買信託產品的起點多數在數十萬元以上，而銀行發行的信託專家類型產品的起點只有5萬元。有的銀行規定，只要在该行購買信託產品的總額超過5萬元，也可以1萬元作為起點，購買信託類理財產品。
