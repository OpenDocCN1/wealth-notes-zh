# 確定你的最大風險承受底線

如果你現在投資資本是20萬，其中的10萬是借來的，你的風險承受底線最大就是10萬，甚至要考慮設在5萬至6萬的範圍，因為你一旦失敗還要吃飯和生存。

# 資本小的時候只能跟風

投資者一般的感覺是缺少資金，當資本少的時候選擇專案的方法只能是跟風，就是別人做什麼你就跟著做什麼。每個業內市場都有賣白菜的，你也是賣白，一般不會賠。

# 資本大的時候創造市場

如果是二次投資，或者可以一次性籌到比較多的投資資本，可以不必跟風，這就要自己來創造市場，把潛在的市場由投資者自己開發出來，以此獲得超常的利潤回報。

# 高科技是多數人失敗、少數人成功的投資項目

高科技專家雖好，但是高科技專案的成功率遠低於在市場上賣白來。如果投資者掌握著高科技技術，並且有別人給你投資，一旦成功，身價百倍；一旦失敗，也只是搭上了些精力和時間。如果是自己在第一次創業時就籌資開發高科技專案，並且自己不懂技術，這種事情成功概率較低。看不見、摸不著的東西比看得見、摸得著的東西賺錢快，賠錢更快。
