# 瓷器的收藏

瓷器一直是收藏品市場上的熱點，也是眾多收藏品類中增值較快的一種。近年來，瓷器收藏市場逐年看好。

相對於書畫等其他收藏品來說，瓷器的選擇性較寬。從明清官窯作品到民窯精品，從價格較高的古瓷到工藝精美的現代作品，都能從中挑選出值得投資的精品。而且，不同瓷器的投資額也相差很大，無論是財大氣粗的大收藏家，還是資金有限的中小投資者，都可以進入。

在市場上海得瓷器，價格最高的都不超過千元，其中很多都在三百、五百元上下。但只要是看準了「下手」，即便是兩三百元買進的貨品，也有不小的利潤空間。一般的民窯瓷器在市場上往往百餘元就能買到，門檻並不高，投資風險相對較低，而且目前正處於上升期，非常適合廣大中小投資者進入。

# 應看作品的造型

造型往往被陶瓷藝人和收藏家忽視。因為人們最易被色彩打動，而輕視造型本身。作為一種三維空間的藝術形式，造型的本身就能體現出一種精神：或圓潤、或挺拔、或纖秀、或雄強、或文懦、或豪放。造型雖是由簡單的線條組成，但提供給人們的想像力卻是無窮無盡的。
