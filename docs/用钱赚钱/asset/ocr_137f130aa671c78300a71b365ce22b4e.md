# 進行交易時，選擇相關商品中價格偏差較大的商品，

選擇較為熟悉的商品

當某一商品價格與其他相關商品價格偏離較多，則該商品價格相對於其他相關商品價格升水較大，即是拋售時機；而該商品價格相對於其他商品價格貼水較大，即是吸納時機。投資者對各商品的熟悉程度各有差異，不可能對多種商品都很熟悉，而多種商品同時出現投資機會的可能性也較小，且投資者同時交易多種商品將分散注意力，難以在多種商品交易中同時獲利，因此投資者應選擇較為熟悉的商品進行投資。

# 交易過程中不要隨意改變交易計量

當投資者對市場已確立一個初步的概念，確定操作策略後，投資者切不可因期貨價格劇烈波動而隨意改變操作策略。交易計量輕易改變將使投資者對大勢方向的判斷動搖不定，錯過獲取較大贏利時機，導致不必要的虧損，另外還要承受頻繁交易的交易手續費。

# 作壁上觀、適當休息

每天交易不僅增加投資錯誤概率，而且可能由於距離市場過近、交易過於頻繁，導致交易成本增加，每天交易還會使投資者疲憊，判斷力銳化。學會觀望、適當休息，將使投資者能更加冷靜地分析判斷市場大勢發展方向。同時，還會讓投資者以另一個心境來看自己以及下一個目標。

在投資者對市場走勢判斷缺乏足夠信心之際，也應該學會觀望，稍作休息，懂得忍耐和自制，以期重新入市的時機。
