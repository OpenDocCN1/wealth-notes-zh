# 3 招把債券炒「活」

隨著股市風險不斷積聚，債券投資在投資者眼裡的位置顯得重要起來。面對一個新債券品項，當初選股經驗已派不上用場，那麼投資者要考慮哪些方面呢？

# 提高流通性

很多債券投資者認為，債券投資就是在債券發行的時候買進債券，然後持有到期拿回本金和利息。這樣就忽略了債券的流通性，而僅僅考慮了債券的收益性和安全性。

債券的流通性就是能否方便地變現，即提前拿回本金和一些利息，這是債券非常重要的一個特性。很多的債券由於沒有良好的流通管道，所以其流通性極差。債券的流通性與安全性和收益性是緊密相關的。良好的流通性能夠使得投資者有機會提前變現，回避可能的風險，也可以使投資者能夠把投資收益提前落袋為安。良好的流通性可以使得投資者能夠承擔太高的機會成本，可以中途變更更理想的債券品項以獲得更高的收益，如果能夠成功地實現短期組合成長期的策略，中途能夠拿回利息再購買債券，就要變相達到了複利效應。所以，債券的流通性是與安全性和收益性一樣值得考慮的特性。
