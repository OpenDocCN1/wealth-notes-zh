# 個人信託的運用範圍

投資理財：使財產保值、增值；個人或家庭的財富管理、移轉及節稅

規劃：子女生活、教養及創業資金的準備及管理；身心障碳子女或其他家屬的照護；退休安養生活的照料；夫妻財產保障；家族股權的控制；遺族的照顧等。

# 使用信託達到人生目標

從人生的發展過程中，我們發現在不同的生命階段中，會有不同的人生目標，而信託可以幫助我們在各個階段中達成不同的人生目標，其情形可區分如下：

+   20 歲以前（求學期）

此階段主要的生活資金供給來源為父母親，自己的經濟能力較差，故可考慮以金錢信託、信託存款等方式累積資金。

+   21 ～ 30 歲（創業期）

此階段主要為開始成家立業階段、雖具有自己的經濟能力，但因剛在起步階段，收入較低，此時仍宜以金錢信託或信託存款等方式累積資金。

+   31 ～ 40 歲（安家期）

此階段，經濟能力逐漸增強，但隨著子女的誕生，使得生活的負擔增加，此時除以金錢信託或信託存款等方式累積資金外，亦可考慮辦理個人壽保險信託以防萬一。
