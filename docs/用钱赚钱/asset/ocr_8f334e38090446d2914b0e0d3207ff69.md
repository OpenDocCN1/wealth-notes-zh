# 房地產投資的 6 種方式

住房投資是不少人目前正在採用的一種理財方式，除了採取直接購房方式外，人們還可以選擇以下 6 種形式。

# 合建分成

合建分成就是拆舊建新、共售分成。這種操作手法要求投資者對房地產整企業務相當精通才好操作。

# 以舊翻新

把舊樓買來或租來，投入一筆裝修費，以提高該樓的附加值，然後將裝修一新的樓宇出售或轉租，从中賺取利潤。

# 以租養租

即長期租賃低價樓宇，然後以不斷提升租金標準的方式轉租，從中賺取租金差價。如果投資者剛開始做房地產生意，資金嚴重不足，這種投資方式比較合適。
