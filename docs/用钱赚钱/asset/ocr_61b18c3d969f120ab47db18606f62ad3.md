# 網上理財，網住你的財富

隨着科技不斷進步和人們金融理財意識的逐步增強，如今，網上銀行、網上投保、網上炒股等「時尚」理財法也開始融入百姓的日常生活。不過，儘管網上理財方式繁多，但要真正做到足不出戶、輕點滑鼠就能理財好錢，亦得動動腦筋。

公司派小張到上海參加一個為期一個月的業務培訓班。財務科給小張開出了2萬元的學費、差旅費等費用。對於如何攜帶這筆不太小的錢，筆者讓他煩惱了，直接帶現金肯定不安全，這時太太給他出主意，讓他把錢存到銀行卡上。小張說，這個辦法地球人都知道——但異地取款就要收1%的手續費，陸續取2萬元要花掉200元，這筆費用總是感覺很浪費了。

後來，他想起前段時間開的某銀行網上銀行。當時幾銀行工作人員介紹，其網上銀行正處於推廣期，網上自助匯款免費。於是小張突發一個省錢的靈氣：何不到上海後開個活動儲存，然後自己透過網上銀行把錢匯到這個存檔裡，豈不是既安全又省錢？

於是，他便將2萬元全部存到了自己在網上銀行的存檔裡，然後就兩手空空地上路了。到上海後他找到了一家和他網上銀行屬同系統的儲蓄所。從填寫憑條，到他拿到存檔和配套的借記卡，只用了3分鐘的時間。然後，他又一頭栽進培訓機構附近的一家網吧，看四下沒人，便悄悄地登錄網上銀行，點擊匯款業務，輸入他在單位辦理的存檔帳號和收款人，點擊確認，電腦提示「匯款已成功」。他趕緊退出了網上銀行，並將一些上網記錄全部清除。
