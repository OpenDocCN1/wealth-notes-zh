# 強行平倉和爆倉風險

交易所在期貨經紀公司要在每個交易日進行結算，當投資者保證金不足低於規定的比例時，期貨公司就會強行平倉。有時候如果行情比較極端甚至會出現爆倉，即虧光帳戶所有資金，甚至還需要期貨公司墊付虧損超過帳戶保證金的部分。

# 交割風險

普通投資者做多大豆不是為了幾個月後買大豆，做空銅也不是為了幾個月後把銅賣出去，如果合約一直持有到交割日，投資者就需要湊足夠的資金或者實物貨進行交割（貨款是保證金的10倍左右）。

# 經紀公司和居間人風險

選擇的期貨公司或居間人的不正規操作也可能帶來損失。

# 委託代理風險
