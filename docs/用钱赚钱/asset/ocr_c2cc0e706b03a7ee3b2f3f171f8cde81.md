# ## 石油價格

在國際大宗商品市場上，原油是重中之重。原油對於黃金的意義在於，油價的上漲將推生成貨幣膨脹，黃金本身作為通脹之下的保值品，與通貨膨脹形影不離，石油價格上漲意味著金價也會隨之上漲。一般來說，原油價格的小幅波動對黃金市場的影響不大，當石油價格波動幅度較大時，會極大地影響到黃金生產企業和各國的通貨膨脹，因而影響黃金市場的價格趨勢。同時，石油和黃金各有各自的供求關係，如果在通脹高漲的情況下，石油跌不定黃金也跌，因為僅僅石油跌對通脹的影響畢竟有限。所以投資者要全面分析，避免陷入被動。

# ## 世界金融危機

世界金融危機出現時，人們為了保留住自己的金錢紛紛去銀行撈兌，銀行出現大量的撈兌後導致破產或倒閉。大金融危機爆發後，所有品項全部暴跌，唯有黃金還在高位震盪。在經濟蕭條的經濟形勢下，黃金作為一種重要的儲備保值工具，人們開始儲備黃金，金價即會有一定程度上揚。

# ## 國際政局動盪、戰爭等

戰爭和政局震盪時期，經濟的發展會受到很大的限制。國際上重大的政治、戰爭事件都將會影響金價。政府為戰爭或為維持國內經濟的平穩而支付費用，大量投資者轉向黃金保值投資。這時，黃金的重要性能淋漓盡致地發揮出來了。
