# 創業型：拿 80 萬做生意

天津的張先生是一家公司的金動部經理。今年已經 31 歲了，他平時工作忙碌，每個月工資為 4000 元左右。每個月固定支出主要有 1500 多，用於償還房貸。

# 享受型：有 100 萬，當「包租婆」

北京的劉小姐，今年才 24 歲，剛從學校畢業並開始工作一年的時間。她在一家知廣告公司做編輯工作，年收入約 8 萬元左右。她每個月固定的支出主要用於房貸，每個月 2000 元左右；另外，她每個月還有一筆固定的投資，2000 元用於基金定時定額。除此之外，由於工作的關係，她平時開銷很小。

她的百萬計畫如下：100 萬的投資方式比較簡單，她希望能在商圈買一個店面。店面的房租將會是一筆穩定而不低的收入。而她可以悠閒地生活，店面房租成為她選擇的主要方式。她認為股票和基金都有較大風險，所以不列入考慮。

理財專家認為劉小姐的百萬計畫反映出在很多年輕人共有性格：嚮往自由、安逸和休閒。對於年輕人來說，養成基金定時定額的習慣是非常好的。而投資房產的理財方式在長期來看也是不錯的理財方式，但需要提示劉小姐的是一定要選擇足夠好的位置，同時應該防範租賃活動中的各種風險，如法律風險、房市變化風險等。

是不錯的選擇。而王小姐是否有較全面的金融知識和足夠的時間，直接決定她投資股票和基金的比例。如果金融知識和時間不足，專家建議王小姐購買基金而不是直接購買股票。
