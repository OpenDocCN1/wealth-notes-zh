# 資金信託理財

資金信託業務是指委託人基於對信託投資公司的信任，將自己合法擁有的資金委託給信託投資公司，由信託投資公司按委託人的意願以自己的名義，為受益人的利益或者特定目的的管理、運用處分的行為。

# 資金信託業務

資金信託業務的形成有以下幾個原因：委託人對自己的資金在運用上不滿某個專門技術知識，為避免資金損失而採取資金信託方式；委託人對自己的資金無暇目為運作生利，而委託信託投資機構處理；委託人不願自己出頭露面而委託信託投資機構代為處理其資金。

中國現行的資金信託包括：信託存款（又分為單位信託存款、公益基金信託存款、勞保基金信託存款、個人約好信託存款），信託貸款（又分為技術改造信託貸款、橫向聯合信託貸款、聯營投資信託貸款、補償貿易信託貸款、耐用消費品信託貸款、專項信託貸款、房地產開發信託貸款），委託貸款（包括一般委託貸款和專項委託貸款），委託投資，信託投資。

# 資金信託操作流程

信託公司（受託人）制定信託計畫，並向廣大投資者（委託人）發售，募集信託資金，投資者為信託財產的受益人；信託公司作為受託人將信託資金投入到信託計畫描述的專案中，信託財產從現金形態轉化為股權
