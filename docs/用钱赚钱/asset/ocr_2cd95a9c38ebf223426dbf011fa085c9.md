# 保險是理財，不是消費

「我現在要攢錢買房，等我買了房、車以後再買保險。」這是很多上班族對保險代理人常說的一句話，類似的說法還有「我現在沒有閒錢買保險」，在他們看來，保險是一種奢侈的消費品，現在並不緊急，或者說保險是有錢人消費的。這都是一些人對保險的錯誤理解。

其實，保險的本質就是理財。理財可以分為消費理財、工作理財、保障理財和投資理財。而保險的本質，就是保障理財。要建立保險社會文化，就是保保險生活化，而保險的生活化，就是保險的理財化，就是要復原保險與理財的血肉聯繫。理財是人們的生活方式，而保險就是理財中占有重要位置的保障理財。

因此，很多上班族理財的時候，由於對保險的不瞭解，以爲買保險都是消費掉了，因而覺得不合適，虧了。其實如果你買過保險，就會知道這個認識是很片面的。保險是生活的必需品，並不是要等到你的生活達到小康甚至更好以後才需要的。保險是轉移風險的一種很好的手段，而風險並不是在你生活好了以後才出現，它是隨時會出現的。

生活中，每個人都不希望意外發生在自己身上，但「不怕一萬，就怕萬一」，事先作好保障才不至於意外發生時措手不及。其實人人都需要一份保險，爲什麼總是當你需要它的時候才想到它呢？
