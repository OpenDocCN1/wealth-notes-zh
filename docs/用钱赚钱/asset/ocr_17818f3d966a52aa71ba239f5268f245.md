# 郵票的收藏

郵票投資具有資金多少皆宜、市場操作簡單及投資獲利相對穩定等多優點。郵票作為收藏投資，在收藏的同時，還能開闊你的眼界，使你從中學到很多東西，而且隨著郵票市場的便捷，其投資前景無疑非常樂觀。

集郵的範圍是很廣泛的，除郵票之外，與「郵」字有關的封、簡、片、戳、卡及集郵文獻、郵政用品等，都可列為集藏的範圍，特別是各種實客封要注意蒐集，它是組織郵集不可缺少的到品。

郵票市場和其他市場一樣，同樣具有很大的風險性。而且郵票市場上存在著很多大戶，大戶吃小戶的現象可謂非常普通。如果你作為一個小戶、剛剛涉入郵票市場或正在萌市中倒騰，並藉此希望從中獲取高額利潤，那麼觀察市場動向，並掌握郵票投資的策略和技巧，是至關重要的。那麼，投資者究竟應該如何投資郵票呢？

# 要樹立正確的投資理念

投資邮票不同於投資其他的项目，郵票是具有貨幣功能的特殊商品，郵票價值的高低受題材、發行時間、發行量、存世量、群票喜愛程度等諸多因素的影響，同時也受市場投機炒作的影響。因此，郵票價格的浮動受各種因素的制約，某一時間的價格並不代表其實質價值，對郵票本身價值的認定必須得到社會的認可，這之間要扣除炒作的泡沫成分。
