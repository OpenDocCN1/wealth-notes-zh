# 太貪心不懂放棄

如果你有100個女子可以娶，而她們也都可以嫁你，你其實說準、選擇一個最好的就行了。
像這綠纜是執著於追漲殺跌，全無目的，纜像足別人的「老婆」好，看著別人的股票漲了，於是集中全部身家接到那個漲了的股票中去，没有想到剛殺入那個本來漲得很好的股票忽然在那裡打起了秋千，忽悠得你頭暈目眩。這個時候回頭去看，那個剛剛被你放棄的股票卻黑馬奮蹄，絕塵而去。於是折騰，於是歎息，於是恨自己，然後再劃，然後再追，最終錢還是沒有賺到。

# 唯專家意見是從

股票投資的關鍵在於選股，許多人會選擇聽取所謂「專家」的意見。其實，「專家」的意見是不是可以聽，關鍵還是你自己要有主見。切記不要把腦袋長在別人的脖子上，當然這也並非是說「專家」分析得不好，而是不能偏聽偏信，聽風就是雨，要養成自己分析的能力，學會積極思考。

# 大猶豫誤大事

有些人，本來在家裡研究得好好的，對一個股票很有信心，可是到了要買了，心裡又開始嘀咕，腦漲了半天還是決定買。要不低點報價吧，誰知道就因為1毛錢股票沒有買到，結果第二天股票就上了漲停板，腸子都悔青了，見人就講。我本來研究好了的，誰知道就少報了1毛錢，1毛呀，我要多報1毛多好，成了祥林嫂*。那位也好下了哪裡去，明明看著

* 祥林嫂：魯迅短篇小說《祝福》中的角色：是中國農村勞動婦女的典型。
