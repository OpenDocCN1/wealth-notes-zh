# 找到適合自己的黃金投資方式

時下，黃金價格節節攀升，許多投資者對此心動不已，且隨著各家銀行相繼推出各類的黃金業務，愈來愈多的市民也開始對「炒金」投資躍躍欲試。但一接觸黃金市場，不禁會產生這樣的疑問：現在市場上究竟有多少黃金產品可以購買？要不要緊？買什麼樣的產品呢？投資者又怎樣在令人眼花繚亂的市場中看得清楚、想得明白、自己做主呢？

目前，市場上的黃金交易品項中，紙黃金投資風險較低，適合普通投資者；黃金期貨和黃金期權屬於高風險品項，適合專業人士；實物黃金適合集藏，需要堅持長期投資策略。

# 實物黃金

實物黃金買賣包括黃金、金幣和金飾等交易，以持有黃金作為投資，只可以在金價上升之時才可以獲利。

從權威性來看，人民銀行發行的金銀幣最權威（幣類標有「元」），是國家法定貨幣。市民目前對金條比較熱衷，仍未完全注意到金銀幣的升值潛力。熱門金銀幣主要有奧運題材的金銀幣和紀念幣、生肖金銀幣、熊貓金銀幣，以及《紅樓夢》系列、京劇藝術系列和《西遊記》系列金銀幣。
