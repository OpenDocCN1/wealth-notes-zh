# 債券按償還方式不同，分爲

# 一次到期債券和分期到期債券

一次到期債券是發行公司於債券到期日一次償還全部債券本金的債券，分期到期債券是指在債券發行的當時就規定有不同到期日的債券，即分批償還本金的債券。

分期到期債券可以減輕發行公司集中還本的財務負擔。

# 債券按是否可流通，分爲可流通債券和不可流通債券，或者上市債券或非上市債券等

發行結束後可在深、滬證券交易所*，即二級市場上上市流通轉讓的債券為上市債券，包括上市國債、上市企業債券和上市可轉讓債券等。上市債券的流通性好，變現容易，適於需隨時變現的閒置資金的投資需要。

# 債券按發行主體不同，分爲國債、金融債和企業債等

國債也叫國券，是中央政府根據信用原則，以承擔還本付息責任為前提而籌借資金的債務憑證。金融債是由銀行和非銀行金融機構發行的債券，金融債券現在大多是由政策性銀行發行與承銷，如國家開發銀行，通常不是為個人投資的。企業債就是企業債券，是公司依照法定程式發行、約定在一定期限還本付息的有價證券，通常泛指企業發行的債券。

+   * 息票率：印製在債券票面上的固定利率。
* 深、滬證券交易所：同臺灣證券交易所 (TWSE)。
