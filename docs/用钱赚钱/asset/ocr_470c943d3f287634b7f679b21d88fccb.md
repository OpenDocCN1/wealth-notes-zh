# 行使委託人的權利

根據中國《信託法》第 20 條的規定：委託人（投資者）有權購解其信託財產的管理運用、處分及收支情況，並有權要求委託人做出說明。委託人有權查閱、抄錄或者複製與其信託財產有關的信託帳目，以及處理信託事務的其他檔。

同時，第 22 條還規定：受託人違反信託目的的處分信託財產或者因違背管理職責、處理信託事務不當致使信託財產受到損失的，委託人有權申請人民法院撤銷該處分行為，並有權要求委託人恢復信託財產的原狀或者予以賠償；該信託財產的受讓人明知是違反信託目的而接受該財產的，應當予以返還或者予以賠償。

另外，第 23 條規定：受託人違反信託目的處分信託財產或者管理運用、處分信託財產有重大過失的，委託人有權依照信託文件的規定解除受託人，或者申請人民法院解任受託人。因此，充分利用法律賦予委託人的這些權利可以更加主動地控制信託投資的風險。

# 關注是否繳稅

目前，由於信託的相關配套政策還未到位，資金信託產品的稅收還是空白，因此，投資者在投資資金信託產品時，要關注是否繳稅。在國外，信託稅制多奉行信託管理原則和稅負不增加原則。根據信託等管理原則，信託是向受益人分配信託利益的管途，信託當事人之間相互轉移財產的行不具有實質經濟意義，因而在稅收上也就不能對普通交易行為那樣課稅。
