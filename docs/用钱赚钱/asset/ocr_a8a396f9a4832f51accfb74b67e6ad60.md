# 小額開始，循序漸進

對於初涉市場的投資者而言，必須從小額規模的交易起步，選擇價格波動較為平穩的品項入手，逐漸掌握交易規律並積累經驗，才能增加交易規模，選擇價格波動劇烈的品項。

# 建倉數量不超過資金的三分之一

投資者一般動用資金的 1/3 開倉，必要時還需要減少持倉量來控制交易風險；避免資金由於開倉量過大、持倉部位與價格波動方向相反等因素的影響而蒙受較重的資金損失。最好的方法，就是交易資金常保持三倍於持有合約所需的保證金。這個規則可幫助你避免用所有的交易資金來決定買賣，有時會被迫提早平倉，但你會因而避免大賠。

# 交易判斷不應帶主觀希望

投資者在交易中不要太過希望立刻有所進展，否則你會根據希望進行買賣，違反基本的買賣規則。成功的投資者通常將自身情緒與交易活動嚴格分開，以免市場大勢與個人意願相反而承受較重風險。

# 選擇買賣市場上交投活躍的合約或合約月分進行投資

投資者交易時一般選擇成交量、持倉量規模較大的、較為活躍的合約進行交易，以確保資金流動的暢通無阻，即方便開倉和平倉。而在活躍交易月分中做買賣，可使交易進行更為容易。
