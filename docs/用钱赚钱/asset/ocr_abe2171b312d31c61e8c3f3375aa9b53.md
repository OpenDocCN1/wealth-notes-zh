# 石頭的收藏

奇石乃天地間最古老的藝術品（天爲藝術品或稱類藝術品），其生成年代以百萬年、千萬年甚至億年計數，加上其造型、結構、色彩、圖案、線條等，有時美得讓人眩目和驚嘆。於是從古到今，愛石者甚多。

如果你沒有加入石頭收藏的行列，你就很難想像到一塊石頭能賣上幾十萬甚至上百萬元。對一些上班族收藏愛好者來說，可多關注奇石收藏。奇石作爲一種大眾藏品，起步並不高，有的甚至低至幾十元，很容易被普通人所接受。

但是，一般投資者在市場上購買石頭時，要冷靜對待自己已見到的觀賞石，一開始玩石先不要購置價格很貴的奇石，不要爲其高價值迷惑，並非高價就是好石。什麼石頭值得收藏？首先看石品，有最常見、最受歡迎的中國四大名石——太湖石、英石、靈璧石、昆石，還有戈壁石、陽春孔雀石、潮州蠟石、廣西大化石等；其次看色泽，石頭是否對光的反應強，是否有自然威、威重感、本色感或奇異感，石頭經過千萬年的沉澱通常呈現古樸穩定的色泽，很有質感；再看石頭的觸感，是否滑潤、是否有手感，如廣東的黃蠟石，不是蠟卻有蠟的光澤，滑潤可愛；然後才講究石頭之勢，是秀美還是峻立，是富貴還是文雅。

當然，一些具有特殊意義的，石頭，如名人收藏過的石頭、來源特殊的石頭，如隕石、恐龍蛋化石等，也常常被石頭愛好者作爲收藏對象。

另外，石頭這個水準如今愈來愈高，尤其是造型的造俱買家很可能透過機器打磨等方法，把原本平淡無奇的石塊鑿造成似人、似物的獨特形狀，一定要仔細辨別。
