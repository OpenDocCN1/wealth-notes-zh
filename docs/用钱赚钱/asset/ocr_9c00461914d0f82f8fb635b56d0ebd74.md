例大，投資股票的比例小的基金。像銀河銀泰理財分紅（150103）、國投瑞銀融譽債券（121001）、南方避險增值（202201）、南方實元債券（20101）、招商安泰債券A（217003），這些屬於債券型基金。

債券基金的投資主要有三類，第一個是國債，第二個是一些政府企業建設債券，第三個投資是一些企業的債券。投資債券主要看的是信用風險，國債信用最高，由國家的信用來擔保，政府大型項目債券次之。但是收益比起股票來可能不是太多，當然風險收益都是成正比的。

如果投資企業債券，這個風險就很大。這個企業突然倒閉了，或者經營不善，就會有投資風險。但是很多債券基金，尤其是偏債的基金，漲勢有的甚至超過偏股型和股票型基金，這是因為很多企業既發行股票，又發行債券。看到股市很好，透過證監會批准把債券變成股票，發行可轉股的債券。債轉股之後，債券基金持有了很多債券，一下變成股票，結果上市交易收益相當好。很多債券基金，尤其是偏債型基金，反而收益要高於偏股型基金。

債券型基金投資的對象就是債券，到期還本，風險低於股票。影響債券基金業績的因素有：

# 利率風險

如果央行持續加息，而債券基金因為利率固定不變，收益可能比存款利率要低。這個就是它的利率風險。例如約定1年以後，企業的債券是5%的利息，結果一年中，央行的利率從3%漲到6%了，我們買這個債券基金就有利率風險。

# 信用風險

這個企業信用不好，結果虧損了，信用等级下降，則投資債券基金就有風險。
