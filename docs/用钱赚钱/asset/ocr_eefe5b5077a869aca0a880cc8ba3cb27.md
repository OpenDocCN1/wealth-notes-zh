# ## 理賠基本要素

# ### 理賠種類

理賠分為兩種，賠償和給付。賠償與財產保險相對應，而由於人壽保險是以人的生命或身體作為保險標的的，生命和身體是無法用金錢衡量的，故在出險時，保險公司只能在保單約定的額度內對受益人或被保險人給付保險金。

# ### 理賠程式

立案檢險——審查單證、審核責任——核損覈算——損失處理——保險公司支付賠款——保險公司行使代位求償權利。

# ### 理賠時效

保險索賠必須在索賠時效內提出，超過時效，被保險人或受益人不向保險公司提出索賠，不提供必要單證和不領取保險金，視為放棄權利。保險不同，時效也不同，人壽保險的索賠時效一般為 5 年，其他保險的索賠時效一般為 2 年。索賠時效應從被保險人或受益人知道事故發生之日起，事故發生後，投保人、被保險人、受益人應當先止險報案，然後提出索賠請求。

# ### 理賠原則

重合約，守信用；堅持實事求是：主動、迅速、準確、合理。

# ### 理賠申請

索賠時應提供的單證主要包括：保險單或保險憑證的正本、已繳納保險費的憑證、有關能證明保險標的或當事人身分的原始文本、索賠清單、出險檢驗證明、其他根據保險合約規定應當提供的文件。
