# 影響黃金價格的因素

黃金具有作爲貨幣的悠久歷史，其本身具有雙重屬性，一個是其本身作爲貴重金屬的商品屬性，二是有著世界貨幣功能的貨幣屬性。在市場上，黃金價格的波動，絕大多數原因是受到黃金本身供求關係的影響。除此之外，由於黃金的特殊屬性，以及宏觀經濟、國際政治、投機活動和國際遊資等因素，黃金價格變化變得更为複雜，更加難以預料。影響黃金價格變化的基本因素主要包括以下幾個方面：

# 供求關係

眾所周知，商品價格的波動主要受市場供需等基本因素的影響。黃金交易是市場經濟的產物。地球上的黃金存量，年供應量，新的金礦開採成本等都會對供給方面產生影響。黃金的需求與黃金的用途有著直接的關係。

# 美元走勢

美元雖然沒有黃金那樣的穩定，但是它比黃金的流動性要好得多。因此，美元被認爲是第一類的錢，黃金是第二類。一般在黃金市場上有美元漲則金價跌，美元降則金價揚的規律。通常投資人土在儲蓄保本時，取黃金就會捨美元，取美元就會捨黃金。黃金雖然本身不是法定貨幣，但始終有其價值，不會貶值成廢鐵。若美元走勢強勁，投資美元升值機會大，人們自然會追逐美元。相反，當美元在外匯市場上走勢弱時，黃金價格就會走強。
