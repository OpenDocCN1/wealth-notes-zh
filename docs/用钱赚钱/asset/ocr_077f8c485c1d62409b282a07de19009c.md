# 第 4 招

刷卡消費要活用信用卡與信用卡。借記卡和信用卡配合使用，透過參加刷卡消費等優惠活動，獲得抽獎、積分。

# 第 5 招

巧用銀行免費管道進行銀行卡餘額查詢。

# 第 6 招

境外刷卡注意選擇銀聯網路，少花 2%的貨幣轉換費。出境旅遊者在國外及港澳地區消費，國際卡組織在換匯業務中都要收取部分的貨幣轉換費，即服務費。而目前，卡號為「62」開頭的「銀聯標準卡」持卡人在境外消費時，銀聯方面只按規定匯率進行貨幣轉換，少花 2%的貨幣轉換費。

# 第 7 招

積極換領「62」字頭銀聯標準卡，享受國際標準服務。採用中國銀聯「62」開頭國際標準BIN號，不僅可以境內使用，還可以境外消費結算。

# 第 8 招

注意農村信用社銀聯標誌，邊遠地區也可跨行用卡。透過中國銀聯切換式網路，在具有銀聯標誌的全國縣及縣以下農村信用社櫃檯可以進行銀行卡取款和查詢，充分利用遍布農村鄉鎮的農村信用社網點資源，為農民工提供方億、快捷、優質的銀行卡服務。
