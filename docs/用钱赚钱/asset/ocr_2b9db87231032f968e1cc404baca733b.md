# 跳出保險理財的常見誤區

很多人都會把保險當成收益性金融產品，在購買保險之前，都喜歡算算是否划算。如果自己沒有出現意外，沒得到理賠，就認為自己賠了，買保險就不划算了。

事實上，從保險生效那一刻開始到保險責任終止，這期間，作為被保險人一直在使用著保險，只是因為保險是一種無形商品，被保險人沒有感受到。

產生這樣的誤區的根本原因，是人們還沒有真正樹立正確的風險觀念，或者說對風險的認識還不夠。有些錯誤還是非常普遍的、有代表性的。對於這些典型的認識誤區，我們要學會甄別並盡量避免。
