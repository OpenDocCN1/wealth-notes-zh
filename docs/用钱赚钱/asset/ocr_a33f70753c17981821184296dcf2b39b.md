# 認識基金大家族

基金是一種兼顧風險和收益的理財方式。舉例來說，假設你有一筆錢想投資債券、股票這類證券進行增值，但自已又一無時的二無體力三無能力的情况下，就想到與其他一些人合夥出資，並雇傭一個投資高手來操作大家合格的財產進行投資增值。如果將這種合夥投資的模式放大一千倍、一萬倍，這就是基金了。如果這種合夥投資的活動經過中國證券監督管理委員會審批，允許這種活動的牽頭操作人向社會公開籌集吸收投資者的合夥出資，這就是發行公募基金，也就是大家現在常見到的基金。

# 封閉式基金

做明白的基金投資者，一定要知道基金分哪幾類，都有什麼樣的基金供我們投資，以便在衆多的基金中選擇適合自己收益風險偏好的基金。

封閉式基金是不可贖回的基金，事先確定發行總額，在封閉期内基金份額總數不變，發行結束後可以上市交易，投資者可透過證券商買賣基金份額。例如：基金開元，發行20億，那整體就是20億份，即便宜的人多，也不會再增发。封閉期就是15年，或者是固定一個時期，封閉期結束之後，可以轉開放的，或是贖的。

封閉式基金不可贖回，那投資者買後如何賺錢呢？第一，它可以分红；第二，它可以在證券市場進行買賣，就跟股票一樣。比如说，2塊錢買的基金，漲到2.1塊了，那可以在股票市場上把它賣掉。這樣的話，封閉式基金交易類似於股票，在第一次買到封閉式基金的時候，投資者跟基金公司接觸，從基金公司申購。基金公司封閉期結束了，最後一次，投資者
