# 優化基金投資組合

在基金的投資過程中，有很多投資者雖然付出了很多時間和精力，但是收益情況卻並不是非常理想，其中一個非常重要的原因就是沒有建立合理的基金組合，從而使自己徒勞無功。俗話說得好，不要把所有的雞蛋放在同一個籃子裡。在投資基金上，就是要求要做好基金的有效組合工作，尤其是在股市動盪的今天，科學合理的基金組合顯得尤為重要。

那麼，投資者應該如何選擇資金組合呢？

# 多種形態需要不同的投資組合

我們投資基金，就是為了避免風險，作一個基金投資組合可以有效地避免非系統性風險。

但是投資基金如果盲目組合也不行，不同的時期需要不同基金組合，不同時期的基金組合可以使我们避免風險、賺取利潤。
