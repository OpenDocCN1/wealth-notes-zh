# 投資基金不可忽視風險

現在，投資者選取基金的比重愈來愈多，但有些投資者對基金產品的風險和收益沒有一個正確的認識，認為投資基金會穩賺不賠。對此，理財專家提醒投資者不可對基金抱有不切實際的期望，更不可把基金當作無風險投資。投資者應當清楚，只賺不賠那只是人們期望中的神話而已，現實的存在則絕對是有賠有賺。基金作為投資的一種方式，必然也是存在風險的。

歷史告訴我們，沒有只漲不跌的股票市場，也沒有只賺不賠的金融產品。認識到基金的風險，投資者就要採取必要的措施以減少風險。因此，投資者應根據基金的風險大小以及投資者自身的風險承受能力不同，把基金的業績和風險與投資者的風險收益偏好特徵相匹配。賺取了基金投資的風險，就要想方設法防範這種風險，避免給自己造成投資的損失。

對於投資者來說，可以運用下面的幾種方法來規避基金投資的風險。

# 進行試探性投資

「投石問路」是投資者降低投資風險的好辦法。新上市的投資者在基金投資中，常常把握不住最適當的買進時機。如果在沒有太大的獲利把握時將全部資金都投入基市，就有可能遭受嚴重損失。如果投資者先將少量資金作為購買基金的投資試探，以此作為是否大量購買的依據，可以減少基金買進中的盲目性和失誤率，從而減少投資者買進基金後被套牢的風險。
