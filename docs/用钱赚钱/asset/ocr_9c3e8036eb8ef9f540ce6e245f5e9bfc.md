# 要有投資風險的意識

對於收益和風險並存這一點，多數人首先是從一種負面的角度來考慮風險，甚至認為有風險就會發生虧損。正是由於風險具有消極的、負面的不確定因素，使得許多人不敢正視，無法客觀地看待和面對投資市場，所以裹足不前。

投資者在交易中要知道自己願意承擔多少風險，能夠承擔多少風險，以及每筆交易應有的回撤。

投資者參與黃金市場的過程，就是正確認識風險，學會承擔風險，然後對風險進行規避的過程。在投資市場如果沒有規避風險的意識，就會使資金出現危機，失去贏利的機會。那麼，怎樣做才能真正地降低黃金投資的風險？以下幾種方式非常值得借鑑。

# 多元化投資

從市場的角度來看，任何資產或者投資的風險都由兩部分組成，一是系統性風險，指宏觀的、外部的、不可控制的風險，如利率、現行匯率、通貨膨脹、戰爭衝突等，這些是投資者無法回避的因素，是所有投資者共同面臨的風險，這是單獨主體無法透過分散化投資消除的。另外一個是非系統風險，是投資者自身產生的風險，有個別差異。多元化投資可以在一定程度上降低非系統化風險，從而降低組合的整體風險水準。新手炒股由於缺乏經驗，剛開始時投入資金不宜全倉進入，因為市場是雙刃劍的，這樣做風險往往很大，即使有再準確的判斷力也容易出錯。炒「紙黃金」的話，投資專家建議採取短期小額交易的方式分批介入，每次買進10克，只要有一點利差就出手，這種方法雖然有些保守，卻很適合新手操作。
