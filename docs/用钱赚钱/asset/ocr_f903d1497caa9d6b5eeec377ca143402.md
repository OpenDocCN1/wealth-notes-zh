無資金可以周轉，導致滿盤皆輸的局面。

# 急於獲取回報

創業者在初涉投資時，易受眼前利益驅動，而忽視長遠利益，採取急功近利的短視行爲，這樣做雖然能夠使企業一時獲利，卻喪失了長遠發展的後勁。投資是一項系統工程，創業者要克服急功近利的思想，更不可蝸鰲取卵、竭澤而漁。

# 不願尋求投資合作夥伴

投資者在投資活動中，既要講獨立，也要講合作。適當的合作（包括合資）可以彌補雙方的缺陷，使弱小企業在市場中迅速站穩腳跟。假如創業者不顧實際情況，一門心思單打獨鬥，就很有可能延誤企業的發展。畢竟，分享利潤總比誰也沒有利潤好。

# 過度相信他人，不親自進行市場調查

一般情況下，創業者對他人（尤其是親密朋友）的意見都容易過度信任，認爲親友的話即代表了市場的真相，自己無須再對市場進行調查，從而導致投資失敗。在做投資決策時，不要輕易相信任何人的意見與建議，哪怕這個人是赫赫有名的專家、你的親兄弟、你的父母。畢竟：要想知道梨子的滋味，就要親自嘗一嘗。這是萬古不渝的真理，投資者更應該牢記。
