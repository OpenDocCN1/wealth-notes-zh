# 收入不同，理財重點各異

很多人都在努力工作，為生存而忙碌，一心一意地賺錢和謀求事業的發展，不太重理財。但是，身處這一階段的你必須要清楚地知道你的工資只能使你安穩地生活，而如果你想變真正成為富翁，你就必須要把資金投入到夢幻莫測的市場中去，讓錢為你賺錢。所以，你必須學會妥善打理個人財產，讓錢為你賺錢。

雖然說：理財不是有錢人的專利，每個人都有「財」可理，但由於擁有的財富不同，每個人的理財方法、理財重點也各有不同。那麼，不同收入的階層將如何理財呢？

# 藍領：絕對穩健的理財方法

對普通的上班族來說，一般理財觀念傳統。因為他們收入較低，承受風險能力也較差，理財要求絕對穩健。建議每月做好支出計畫，除正常開支外，再將剩餘部分分成若干份，進行必要的投資理財，可優先考慮投資保險、基金和國債等項目。

如，國債利息略高於銀行同期儲蓄利息，因此可以將家裡短期之內用不到的資金購買國債；如果對外匯感興趣的話，建議購買銀行和證券公司推出的 MMF*等；在保險投資方面，對於剛就職的年輕人而言適當購買人壽保險，既可獲一些基本保障，也可強迫儲蓄，且盡早購買，費率較
