# 什麼時候該賣出股票

買股票雖然不容易，但賣股票同樣也是一門大學問，許多股民都很會買股票，但卻不懂得如何賣股票。事實上，一個真正成功的股民在懂得買股票的基礎上，也要懂得在最適當的時機賣出股票。

一般，投資者的目的如果是既定的利潤率，在市場給它的利潤率達到一定的程度，而這個利潤率在短期內進一步上升的可能性較小時，就是投資者賣出股票的時候。「只有傻瓜才會等著股價到達最高位」，一定要學會見好就收。

在股市上，專業散戶的標準有很多：會看、會聽、會買、會跟、會思考、會賣、會逃、會分析、會判斷……總而言之，會賺錢。但最基礎的一點就是要會出逃，會賣掉自己手中的股票。

2006年夏，夏雨抱著對股市的良好願望，提著自己的全部積蓄5萬元開了戶。並且由於夏雨是舉財經出身，具備一定的證券市場知識，同時也從事證券資訊編輯工作，接觸股市的機會也較多，因此自信滿滿。剛開始嘗試著買幾檔股票，借著當時牛市東風，其股票也是水漲船高，股票漲幅有時也變成可預期的事情。這讓夏雨開始沾沾自喜。

然而，之後在購買一檔股票的經歷讓夏雨懂得了及時獲利了結是多是麼的重要。夏雨在周圍朋友的大力推薦下於2007年5月15日以19元的價格買入大唐發電（601991)*，之後大唐發電一路走高，最高2007年6

* 大唐發電（601991)：大唐國際發電股份有限公司，是中國獨立發電及供電企業，也是中國五大国有電力集團之一。(601991)為其證券代碼。
