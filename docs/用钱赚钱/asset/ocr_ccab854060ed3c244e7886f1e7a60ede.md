# 密碼要真正體現保密

設置網上銀行的登錄密碼和交易密碼應採用數字加字母或符號的方式，盡量不用完全是數字密碼。登錄密碼和支付密碼也不能相同，這樣萬一登錄密碼被竊，因為不知道支付密碼，登錄人只能辦理帳戶查詢等一般業務，無法劃轉帳戶資金。另外還要注意定期修改密碼，一般情况下，每月更改一次密碼會增加網上交易的安全係數；網上銀行使用完畢後，一定要注意點擊「退出交易」選項，從而清除電腦中暫存的會話密碼，保障帳戶資金的安全。

# 養成定期对帳的習慣

有些人對自己的帳戶疏於管理，有時帳戶上少了錢，幾個月以後才發現，有的甚至始終察覺不到。所以使用網上銀行要養成定期对帳的習慣，對於轉帳和支付業務要隨時做好記錄，定期查看各種交易明細。另外，現在許多銀行開通了「短信銀行」業務，客戶申請此項服務後，銀行會按照客戶要求，定期將網上銀行的帳戶資金情況，透過手機短信告知客戶，以便及時發現各種賬務問題。同時，每次登錄網上銀行後，都要留意「上一文登錄時間」的提示，查看最近的登錄時間，從而確認網上銀行帳戶是否被非法登錄過。如果發現帳戶被非法登錄或資金被盜用，要及時透過銀行服務電話對註冊卡及註冊卡下所掛帳戶進行臨時掛失，並盡快到營業網點辦理書面掛失手續或報案，以最大限度挽回經濟損失。
