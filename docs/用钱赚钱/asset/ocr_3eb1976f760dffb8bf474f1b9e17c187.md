# 買保險不為保障為投資

王女士最近剛剛買了一份保險，她向理財專家說：「這份保險我感覺很划算了，交20年，一年交7080元，每三年就返款8200元……」王女士說，她以前也沒買過什麼保險，但現在條件好了，手裡有餘錢了，就也想買點保險，就當投資了。

暫且不論這個保險產品的好壞，王女士的這種觀念是不對的。雖然，目前很多保險產品具有儲蓄和保障雙重功能，但更重要的、最獨特的是保障功能。百姓投保也應更重視保障方面的作用。如果只注重保險的投資功能，必然偏重於儲蓄投資類險種，而忽略人身意外險、健康險等的投入，這是保險市場不成熟的表現。

但很多人都像王女士一樣，不願意投保消費型的純保障類保險，更願意投保一些返還型的產品。其實消費型保險一般保費都不高，但保障作用卻很強，當然由於保險事故只是可能發生而不是肯定發生，因此讓許多人認為是白搭，不願意投保。但要知道，保險對防的就是意外，一旦發生意外事故，保險才真正發揮保障、救急和彌補損失的作用。在安排家庭保險時，一定要先安排基礎保障類保險，然後考慮投資理財型的保險。
