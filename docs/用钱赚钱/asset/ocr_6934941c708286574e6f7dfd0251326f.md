# 分紅保險的概念及作用

# 什麼是分紅保險？

。分紅保險是指保險公司將其實際經營所產生的盈餘，按一定比例向保單持有人進行分配的人寿保險。

。分紅保險的主要特徵是投保人除了可以得到保單規定的保證利益外，還可享受保險公司的經營成果。

。分紅保險的分紅實質上是保險公司的盈餘，盈餘就是保單賣份額高於未來負債的那部分價值。

分紅的產生是由很多因素決定的，但最為主要的因素是利差益、死差益。對於以死亡率作為保單責任的壽險，死差益是由於實際死亡率小於預定死亡率而產生的利益；當保險公司實際投資收益率高於預定利差時，則產生利差益。

。分紅領取方法。現金分紅：以現金形式定期向客戶發放；累積生息：自動利派發日起，將應計分紅轉入累計生息賬戶儲存生息，並於合約終止或投保人申請時給付。

不同壽險產品的保險責任、繳費方式、適用的人群等都不同，因此分紅利分配水準也都不一。不同公司有同的分紅理念和原則，不同公司的險種責任不統一，所以不存在可比性。
