# 世界主要黃金市場簡介

世界各地約有 40 多個黃金市場。黃金市場的供應主要包括：世界各產金國的礦產黃金、一些國家官方儲備，如央行黃金儲備或國際貨幣基金組織以及私人拋售的黃金、回收的再生黃金。目前歐洲的黃金市場所在地是倫敦、蘇黎世等，美洲的主要集中在紐約，亞洲的在香港。國際黃金市場的主要參與者，可分為國際金商、銀行、對沖基金等金融機構、各個法人機構、私人投資者以及在黃金期貨交易中有很大的經紀公司。

目前，倫敦是世界上最大的黃金市場。倫敦黃金市場交易所的會員由具有權威性的五大金商及一些公司有資格向五大金商購買黃金的公司或商店所組成，然後再由各個加工製造商、商店和公司等連鎖組成。交易時由金商根據各自的買盤和賣盤，報出買價和賣價。倫敦沒有實際的交易場所，靈活性非常強，採用黃金現貨延期交割的交易模式，黃金的重量、純度都可以選擇等，吸引大量的機構和個人投資者參與進來，造就了全球最為活躍的黃金市場。

蘇黎世黃金市場是在第二次世界大戰後發展起來的國際黃金市場，沒有正式的組織結構，只是由瑞士三大銀行：瑞士銀行、瑞士信貸銀行和瑞士聯合銀行負責清算結帳。蘇黎世黃金市場的金價和倫敦市場的金價一樣受到國際市場的重視，在國際黃金市場上的地位僅次於倫敦。

紐約商品交易所（COMEX）和芝加哥商品交易所（IMM）即是美國黃金期貨交易的中心，也是世界最大的黃金期貨交易中心。兩大交易所對黃金現貨市場的金價影響很大。紐約商品交易所僅為交易者提供一個場所和設施，其本身並不參加期貨的買賣，但是它制定了一些法規，保證交易雙方在公平和合理的前提下交易。
