# 選擇保險理財的 10 大原則

保險多，保障也多，但是保險也不是愈多愈好。投保是需要成本的，
投保的根本原則是盡可能小的代價獲得較全面的保險。所以在買保險的
時候，還要遵循一定的基本原則：

# 「三三制」原則

現代家庭理財應進行「三三制」原則，即三分之一－的流動資金用於應
急；三分之一透過投資，獲取較高收益；三分之一用於保險，獲得家庭人
身財產保障。而在投資類型上，股票、期貸解決收益性，屬於理財金字塔
頂端；基金、儲蓄解決流動性，屬於金字塔中間；各類保險解決安全性，
在家庭理財規劃中是必不可少的培養。

# 按需選擇

按需選擇原則就是根據目前所面臨的風險種類選擇相應險種。市面上
針對家庭和個人的商業險種非常多，並不是每個都適應自己。必須識別目
前所面臨的風險，根據風險種類和發生的可能性來選擇險種。
