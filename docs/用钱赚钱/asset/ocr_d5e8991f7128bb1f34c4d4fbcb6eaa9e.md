# 投資分散

有一種理論說：不要將雞蛋放到一個籃子裡面。其意思是分散風險，這本本沒有錯，可是我們看到許多散戶沒有正確地理解這個意思。投資過於分散有很大的弊病：第一，持有股票多肯定要付出上漲，因為買 100 股肯定要比買 1000 股付出的平均手續費要貴。第二，你不可能有精力對這麼多的股票進行跟蹤。第三，最糟糕的是這樣買股票你就算買到了黑馬也不可能賺到錢，說不定還要賠，因為一匹黑馬再大的力氣也拉不動裝着 10 頭驢驢的車，這是很自然的事情！

# 持股結構不合理

有些股民在選股時也是很科學的，其所持股股票甚至都是同一個屬性的，要麼就都是大盤股、要麼就都屬於同一行業，要麼就都是科技股。可以看出，這個仁兄的持股結構是扁平的而不是立體，他不懂持股要講究立體性，投資和投機結合，短線和中長線結合等。我實在看不出他這把雞蛋放進同一個籃子有什麼區別，更糟糕的是，很可能這些個籃子的底還是漏的。

# 沒有耐心

不會空倉，嚴格地說是不願意空倉，每天在市場裡不是買就是賣，反正是不能閒著，好像不買就會錯過了黑馬，5 萬的資金一年做不出 500 萬的交易額，這個行為券商最歡迎，因為你這樣的做法無疑只是在頻繁的轉賬中平添了許多的交易手續費罷了，對你的投資增值沒有半點益處。

> ＊特倉：表示您已做出且仍然能夠產生利潤或損失的交易。
