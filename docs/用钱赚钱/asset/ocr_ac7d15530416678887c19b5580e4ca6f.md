# 投資郵票要量力而行

對廣大中小投資者而言，投資收藏郵票的基本要素有兩條：一是要判斷郵票保值、增值的條件要素是否具備；二是在決定投資前一定要根據自己的經濟條件量力而行，在沒有絕對把握獲利的情況下，切忌負債或超負債投資郵票。雖然郵政改制後的政策面對市場有利，但也要有預防突發性事件發生的心理準備。

# 把握建倉時機至關重要

中國各省郵政改制掛牌在2007年9月初正式拉開序幕，設立省級郵政監管機構，標誌著郵改政企分離邁出了關鍵一步。此後開始，郵市做出了積極的配合，市場成交活躍，成交量有效放大，熱點逐漸擴散，社會主力大資金已經進場。趁市場行情還沒有達到一定熱點前，择機建倉不失為明智之舉。

# 還要認真選擇投資品項

在決定投資郵票後，挑選好郵票品項也是一門學問。一般來講，1991年之前的老紀特郵票存世量少、消耗量大，基本上都沉藏在社會。因此，老紀特郵票的價格都較高，保值、增值比較穩定，受市場波動的影響較小，是長期收藏投資群的首選。

# 郵票的收藏與保管是十分重要的

一張郵票有纖細的齒孔，有怕受潮的背膠，如不注意保管，就會發生變形、撕裂、破齒、粘齒及出現黴點，從而影響郵票的品質與外觀。
