# 不要期望在最好價位建倉或平倉

在頂部拋售和在底部買入都是小概率的事件，逆勢摸頂和摸底的遊戲都是非常高險的，當投資者確認市場大勢後，應隨即進入市場進行交易。投資者追求的合理的投資目標是獲取波段盈利。

# 重大消息出臺後或有暴利時應迅速行動

買在預期，賣在現實。當市場有重大利多或者利空消息，應分別建倉抑或賣空，而當上述消息公布於眾，則市場極可能反向運行，因此投資者應隨即回吐多單或收回補空單。當投資者持倉在較短時間內獲取暴利，應首先考慮獲利平倉再去研究市場劇烈波動的原因，因為期貨市場瞬息萬變，猶豫不決往往將導致盈利縮小，或者導致虧損增加。

# 要學會做空

對於初入市的投資者來說，逢低做多較多，逢高做空較少，而在商品市場呈買方市場的背景下，價格下跌往往比價格上漲更容易，因此投資者應把握逢高做空的機會。
