# 妥善控制股市風險

「股市有風險，入市須慎重。」對於股票投資者來講，風險控制永遠比獲取利潤更為重要。而對於某些投資者來講，卻沒有任何風險控制的意識，他們永遠關心的只是「該股能漲多少」，卻從來不關心「該股會跌多少」。可見，這種沒有任何風險控制的投資，往往最終使得自己損失慘重。

這種不再矚目什麼市場風險（又稱系統風險）、非市場風險（又稱非系統風險）之類的話。只是簡單說一句「收益有多高，風險就有多大」，絕對是投資中的至理名言。希望能夠引起大家重視，在真正投資之前，認清風險，正视風險，樹立風險意識，做好規避股票交易風險的準備工作。

2007年5月30日，狂跌的股市給那些充滿著期待的股民們上了一堂精彩的風險課。由於政策的變動，證券交易印花稅稅率由0.1%上調至0.3%，這使得過深股指一瀉千里。在這種背景下，那些心中毫無風險意識的股民在還沒有來得及分享牛市的成長，就慘遭了狠狠的一記閃棍，只能欒欒地流著淚自己承受。
