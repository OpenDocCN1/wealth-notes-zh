# 利率

利率調整是政府緊縮或擴張經濟的宏觀調控手段。利率對金融衍生品的交易影響較大，而對商品期貨的影響較小。投資黃金不會獲得利息，黃金投資的獲利全憑價格上升。對於投機性黃金交易者而言，保證金利息是其交易過程中的主要成本。在利率偏低時，黃金投資交易成本降低，投資黃金會有一定的益處；但是利率升高時，黃金投資的成本上升，投資若風險增大，相對而言，收取利息會更加吸引人，無利息黃金的投資價值因此下降。特別是美國的利息升高時，美元會被大量的吸納，金價勢必受挫。

# 經濟景氣狀況

世界經濟是否景氣直接影響投資者對黃金的需求。通常，經濟欣欣向榮，人们生活寬綽，自然會增強人們投資的欲望，黃金需求上升，金價也會得到一定的支持。相反之下，民不聊生，經濟蕭條時期，人們連基本的物質基礎保障都得不到滿足時，黃金投資自然不提，金價必然會下跌。因此，預測金價（特別是短期金價），要關注各國政府或機構公布的各項經濟資料，如 GDP、失業率等。

# 通貨膨脹對黃金價格的影響

從長期來看，每年的通貨膨脹若是在正常範圍內變化，物價相對穩定時，其貨幣的購買能力就愈穩定。那麼其對金價的波動影響並不大，只有在短期內，物價大幅上升，引起人們的恐慌，貨幣的單位購買能力下降，持有現金根本沒有保障，收取利息也赶不上物價的暴升，金價才會明顯上升。總而言之，黃金不夫為對付通貨膨脹的重要手段之一。
