# 收益型基金

很多投資者希望今天買這個基金，明天就漲 2 分，後天漲 5 分，再漲 8 分，一下子三個 10%。也有這種類型的基金，叫收益型基金。收益型基金在一定時段裡，強調的是這段時間的收益，風險也高於成長型基金。收益型基金追求高的收益，那就肯定有風險。收益型基金會拿出很大比例資金買股票，在行情大漲的時候，投資比例可能就傾向於風險大的。它的收益和風險相對成長型基金都要大。像寶盈瀉利收益（203001）、中銀收益（163804）、海富收益（519003）、普天收益（160603），這些屬於收益型基金。

# 股票型基金

股票型基金是 60% 以上的基金資產投資於股票的基金。這樣的基金風險比較高，收益也高，收益隨著股票市場的波動而波動。還有一些偏股型的基金，即用大部分資金投資股票，而用少量的資金投資債券。像華夏大盤精選（491304）、易方達積極成長（491704）、中郵創業核心優選（496401）、華寶興業先達成長（493107）、嘉實理財增長（492302），這些屬於股票型基金。
