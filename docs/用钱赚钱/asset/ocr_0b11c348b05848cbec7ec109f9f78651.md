# 巧用銀行卡之 10 招祕訣

如今持卡族愈來愈多，如果僅僅把銀行卡當作是存取款的工具，那簡直是太「冤枉」它們了。其實從普通的借記卡到可以「先消費、後還款」的信用卡，都各具特色，若使用得當，不僅可以享受到多多便捷，還可以幫持卡人省錢，實現個人理財的目的，充分享受現代「卡式」生活。

# 第 1 招

跨行交易認準銀聯標誌（包括境內外）。不同銀行發行的銀行卡能夠在帶有銀聯標誌的 ATM 機和 POS 終端上統一存取款或消費。客戶取款或刷卡，不用再像以前那樣，在各種銀行卡標誌中尋找自己所持有的那一種卡，而只要認準標誌即可。

# 第 2 招

牢記發卡銀行客服電話。在用卡過程中一旦出現無法解決的問題，及時撥打發卡銀行客服電話，以減少不必要的損失。

# 第 3 招

經常登錄銀聯和發卡行網站獲取最新優惠資訊。

中國銀聯和發卡行不定期的都有一些對於持卡人的優惠活動，如積分換獎、刷卡消費、累計換獎等活動，及時透過網站獲取相關資訊，為自身刷卡消費帶來实惠。
