# 在匯市最活躍時參與交易

匯價在交易清淡的時刻，行情波動會很小。這個在匯市中叫做「橫盤」。從交易的角度來看，在趨勢明朗後追擊入市，風險最小。

在匯價橫盤時買入，趨勢不明朝，上升和下跌的概率各 50%，那麼你可能會遭受損失。買賣之後匯價不升不跌，必然會增加心理負擔。如果是短線投機，則失敗的機會更大。

如果交易活躍，那時市場買賣雙方的力量不是勢均力敵，而是有一方支持不住，匯價發生大幅波動。如果你買入的點位不好，一定會被深度套牢。

匯市中分析師經常會談到上檔阻力位、下方支撐位，可見這 2 個點位元對交易的重要。匯價上探到了阻力位，肯定受壓制。如果這回升的力量很強，突破了這個阻力位，後市肯定是繼續往上走。如果不能突破阻力位，後市肯定是見底回落。找出阻力位和支撐位，後市的操作方法就有了。

前期未能突破的高點或低點：前期沒有突破的高點肯定是阻力，前期沒有突破的低點肯定是支撐。這樣我們可以在沒有突破的高點做空，在低點受到支撐做多。

# 學會從各種消息中發現良機

炒外匯就要即時關注定期公布的經濟資料及影響消息。能否在第一時間獲得經濟資料的資訊和掌握第一手重大事件的內容，對外匯投資者來說非常關鍵。特別是對短線的外匯投資者來說尤其重要。一旦有新聞消息傳入市場，原有的平衡狀態就會立即被打破。一位有經驗的外匯投資者會分析消息對經濟金融方面的影響，果斷買入或者賣出某種貨幣，從而獲得比較豐厚的收益。
