呢？我們沒有辦法知道。結果杜輝買後只微微上漲了3天，然後就停止步伐，隨後開始大幅下跌，後來他在26號出局，使買入資金虧損了30%。過後，白糖真的漲起來了，他又後悔不已。

很多投資者都會犯這樣的錯誤，因為知道得不全面，理解得不透徹，這樣的交易往往是以失敗告終，而且很容易陷入深深的困境之中。如何成為那25%的成功者中的一員，是許多期貨交易者的夢想，我們來看看以下期貨交易高手的期貨交易心得。

# 閒錢投機，贏錢投資

用來投資的，必須是你可以賠得起的閒錢。不要動用其他資金或財產，如果是以家計中的資金來從事期貨投資，那就註定要失敗的，因為你不能從容運用，可能由於較多的牽掛而無法做出正確的判斷，最終導致投機失敗。「買賣的決定，必須不受賠掉家用錢的恐懼感所左右。」若贏錢，拿出贏利的50%。投資不動產。心智上的自由做出穩健的買賣決定，是期貨商品買賣的成功要素之一。

# 認識自我，控制情緒

投資者需要有冷靜客觀的氣質、心平氣和、具備控制情緒的能力、對市場上突如其來的變化，能做到「臨危不驚」。雖然這種功夫需要日積月累才能夠鍛煉出來，但成功的商品買賣者似乎向來就能在交易進行當中泰然處之。「在期貨商品市場中，每天都有許多令人興奮的事情發生，所以你必須要有決斷的心態，有能力應對市場短期的狀況，不然你會在短短幾分鐘之內，數度改變你的心態和合約方向。」
