# 財產信託理財

隨著社會經濟的不斷發展和財富形式的增多，為適應社會多種理財需求，信託公司適時推出新的財產品項，更有效地發揮「受人之托，代人理財」職能。

# 財產品品收益

財產品品的收益來源於信託財產本身。投資者購買財產品品時，由於信託財產可見，所以信託財產產生的信託收益也買賣可見，從而避免賴以產生信託收益的財產形成過程中的風險。

財產品品中一般設置優先信託收益和剩餘（或次級）信託權益，並作為控制風險的一種方式，投資者所持有的是，從已存在的大額資產中優先受益的權利。而且財產品品沒有份額的限制，投資起點較低，一般為5萬元，符合各類投資者的購買能力。

財產品品和資金信託產品，二者的收益率大致相當，財產品品不僅投資門檻較低，收益水準有一定保障，能有效地將投資風險控制在一定水準，實現投資者保值、增值的目的，更為重要的是，財產品品能夠幫助投資者合理節省一定稅額。
