# 對中介全面審查

根據統計資料顯示，中國二手房交易中，經過中介成交的已經占到80%。然而如果在交易過程中，遇到資質差或者根本沒有資質的中介公司，則後果不堪設想。所以下面先教教大家如何辨別中介公司的等級和真偽。

+   一看中介公司是否有明確的公司名稱、長期經營的地址。這可以透過看中介公司的招牌、詢問周圍人該公司成立情況及經營情況來確定，以防皮包公司詐騙。

+   二看中介公司營業執照以確定該公司的營業資質。看是否可以進行二手房中介業務，辦理經營二手房仲介的中介公司的營業執照需要衆多的條件，包括相關的有仲介資質從業人員等條件。

+   三看中介公司營業執照確定它的註冊資金，中介公司註冊資金不能低於買賣一間房子的價格。客戶透過中介來交易房屋最主要的原因就是不希望直接交房屋款，希望在整個交易過程中有一個協力廠商來維護雙方的利益，所以一定要找到一家公司的風險承受能力，即該公司的註冊資金能大於該房屋的廠價或該中介公司為品牌公司，擁有良好的信譽，一旦發生糾
