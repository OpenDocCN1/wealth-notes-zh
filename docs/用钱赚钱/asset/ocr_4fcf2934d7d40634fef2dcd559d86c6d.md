# 與社會保險。

+   強制保險與自願保險
*   **強制保險**：是國家透過立法規定強制實行的保險。強制保險的範疇大於法定保險。法定保險是強制保險的主要形式。
*   **自願保險**：是投保人根據自身需要自主決定是否投保、投保什麼以及保險保障範圍。

+   商業保險與社會保險
*   **商業保險**：又稱金融保險，是指按商業原則所進行的保險，以盈利為目的。具體而言，是指投保人根據合同约定，向保險人支付保險費，保險人對於合同约定的因可能發生的事故而造成的財產損失承擔賠償保險金責任，或者當被保險人死亡、傷殘、疾病或者達到合同约定的年齡、期限時承擔給付保險金責任的保險行為。

+   社會保險：是指國家透過立法強制實行的，由個人、單位、國家三方共同籌資，建立保險基金，對個人因年老、工傷、疾病、生育、殘廢、失業、死亡等原因喪失勞動能力或暫時失去工作時，給予本人或其供養直系親屬物費幫助的一種社會保障制度。社會保險具有法制性、強制性、固定性等特點，每個在職職工都必須實行，所以，社會保險又稱為（社會）基本保險，或者簡稱為社保。
