

# “凡事发生皆有利于我”吗？

今天是问答时间。我们昨天聊了一个危险的观点：内耗有可能转化成一种资源。这个观点很有力量，疗效很强大，但副作用也很厉害。这是一体两面。我们今天就来讲讲它为什么危险。结合不同的视角，你会对内耗有更清晰、更立体的理解。不过我们不再讲那句话了，讲讲另一句最近非常流行的话，“凡事发生，皆有利于我”。

好事发生有利于我，显而易见的，不用说。它想说的是，坏事发生，其实对我也有利。这句话背后有些自我中心倾向。好像世界上的好事坏事都是专门为我安排、为我设计的。为什么很多人喜欢这句话？

它会显著地降低一个人对外界威胁的感知。有个成语叫杞人忧天。说有个杞国人担心天塌下来，愁得饭也吃不下，觉也睡不好。我小时候老觉得这个成语是编的，怎么可能有这种人？但是现在，我不确定了。因为发现世界上真的有很多奇怪的人，脑回路跟一般人不一样。你从来不担心的事，不见得别人就不担心。有些人的杏仁核，也就是情绪报警器过于敏感了。有个风吹草动他就担心。过度担忧的人，怎样缓解焦虑呢？接受一些信念会好很多。信念可以带来确定性。

“凡事发生皆有利于我”，不管对不对，这种旗帜鲜明的观点可以给人确定性，降低焦虑。前提是你得信。在不同宗教里，有各种信念。比如相信天国的存在、极乐世界的存在，相信这些可以大大降低焦虑。它跟理性没有太大关系，跟情感有非常大的关系。有些很理性的人也会坚信无法证实的内容。很多时候，人不是因为理性才相信，而是因为敏感的体质、容易焦虑的性格。信念可以帮助他抚平焦虑，带来安稳。信仰需求其实在很大程度上是天生的。我们最好把它看成是像容易高血压之类的体质。这样可以去道德化。

我们的大脑始终都在预测。“预测误差”就体现在多巴胺上。好事发生有利于我就不用说了，坏事发生为什么也有利于我呢？坏事带来的预测误差更大。这也就意味着，留给你学习的空间更大。我们有机会从成功里学到的东西，往往不如从失败里学到的更多。因为失败里面包含的未知信息量更大。

但这一切，有个前提：你得去捕捉那些信息量，用它来校准对世界的理解。这里面就有个悖论：经常是，当一个人坚定地相信“凡事发生皆有利于我”的时候，他就不校准了。你问他：门口挖掘机的噪音吵得你没法工作、没法休息，怎么就有利于你呢？他可能说：锻炼我的忍受能力。这就有点拧巴了。因为他过于看重解释，而忽略了身体的感受。他是先有了结论，再为结论找理由。

很有必要区分坏事的有利和校准的有利。我们上一讲说，内耗可能是一种资源，就像矿石。矿石如果你不去开采、不去冶炼的话，它没有用。有些矿石还有辐射。之所以说坏事有积极意义，是因为你把它转化了，拿来校准对世界的理解了。这个利是校准的利，而坏事只是校准的条件之一。有点悖论的是，校准的有利，恰恰来自你敢于面对不确定性，冲进一个陌生的、甚至有点恐怖的世界里，开始一点点熟悉它。但如果反过来，先认定一种信念，比如“凡事发生皆有利于我”，很多人反而不去校准了。因为他用确定性把他理解的自我和真实自我之间的裂缝，给严严实实地遮住了。

我想用梅洛庞蒂的理论来聊聊这件事。梅洛庞蒂在讲啥呢？简单来说，不要把意识看得高于身体，身体不是意识的工具。你要重视身体的感受。从梅洛庞蒂的视角看，“凡事发生皆有利于我”，这句话危险，因为它过于重视大脑的解释，而过于忽视身体的感受。

一场突如其来的疾病，一次撕心裂肺的背叛，首先是身体性的，是一种体验。这种体验发生在反思之前。你生病的时候，身体非常诚实地告诉你：我不舒服，我难受。而“有利”是什么？是事后的反思。一只猫不会在难受的时候去想这对我有什么利，难受就是难受。当你拿事后的反思来覆盖身体的难受，其实是一种异化，是你企图在用意识来驯服作为真实的我存在的身体。那么，相信这句话，就不是在诠释现实，恰恰是在逃避现实。最现实的首先是你的身体，你的感受。而不是对感受的复杂解读和联想。那种解读和联想，是在帮助你逃避最真实的存在。

身体的基本语言是“我能”。健康的时候，我能跑能跳；腿骨折了，我不能了。这是一个真实的我。而“有利于我”的“我”，是个什么我呢？是个“叙事自我”。那是一个虚假的、不受身体影响的，活在故事里的我。安徒生笔下卖火柴的小女孩，最后是冻死的，故事里说，她在火柴划出的光亮里看见了烤鸭，看见了奶奶，看见了一切美好的东西。那就是叙事的自我。而作为身体的自我仍然要忍饥挨饿。理解这些，也许有助于你理解宗教和世俗的关系。真实的我，到底是在一片废墟中，还是在美好的幻想里？

所以，从梅洛庞蒂的视角看，“凡事发生皆有利于我”，“皆”和“有利”，把真实世界的丰富性和模糊性抹杀了。

真实世界充满了模糊和含混，有些事情的发生不利于我，哪怕大脑可以把它解释得有利于我，但身体感受到的不是那样。要敢于承认这一点。

不过，我还不想让讨论停在这儿。梅洛庞蒂视角的批评，恰恰能帮助我们认出这句话最有价值的地方。那就是，不应该把它当成一种信念，而应该把它当成一种工具，或者叫，一个技能。什么意思呢？你还记得我们讲的过度夸奖一节吗？小孩在三四岁的时候，会经常摔倒。摔倒对他来说是不是有利的？如果不严重，可能确实是有的，因为他在学习走路。他会摔得越来越少。这个有利是事实层面上的，不是信念。因为在摔倒的同时，你就感知到了世界。不是通过摔倒后的反思去理解世界的。

也就是说，我们应该把信念变成身体技能。当观念仅仅停留在口头上或者思想里，它就是虚假的；一旦融入身体，就真实了。怎样融入身体呢？凡事发生，都为我打开一扇陌生世界的门。那个世界充满了寒气，阴森恐怖，而这正是我想走进去的原因。我们在游戏里是会进入那种场景的。但是在真实世界是否愿意呢？佛学有个词叫“园林游戏门”，以及“游戏三昧”。如果你愿意走进一个陌生而充满未知的世界，坏事的发生，也许真的对你有利。那时候，“凡事发生皆有利于我”这句话早已多余了。因为你根本不会意识到它。如果你意识到它，说明它还只停留在意识层面，停留在脑子里，是一种经过反思的观念；只有在你完全意识不到它的时候，它才从脑子里走出来，进入身体。

想想这个问题：什么东西对我很重要？

有人会想：自我价值、信念、爱、生命。你有没有发现，这些东西有个共同点？——抽象。它们都是看不见摸不着的东西，不是身体当下感受的。一个人说，爱对我很重要；另一个人说，拥抱对我很重要。你更喜欢哪个说法？会觉得哪个更真实？也许是拥抱。因为它具体，触手可及。爱未免有点虚，有点大，有点冠冕堂皇。它说得不错，但总是像隔了一层。当我们想拿掉隔的一层，再来回答“什么对我很重要”，答案也许是：呼吸。呼吸的重要不是通过反思知道的，它存在于反思之前。

很多人以为，内耗是因为想得太多，解决方案是少想。其实，内耗不是想得太多，而是感受得太少；是在用想来替代感受。当他反复琢磨“我是不是不够好”“这件事到底值不值”的时候，他不是在思考问题，而是在用认知活动来占据注意力，好把原始的身体感受压下去。

所以，“凡事发生皆有利于我”，这句话，我们可以把它作为一种技术，但是最好不要把它升级成一种信念。当它成为信念的时候，可能会阻碍你更新对世界的理解，也会让你过于看重大脑的解释，而忽视身体的感受。今天的回答就到这里，我们下一讲再见。

- 1. 信念可以带来确定性，“凡事发生皆有利于我”，不管对不对，这种旗帜鲜明的观点可以给人确定性，降低焦虑。
- 2. 这句话一个潜在的危险，是可能让人过于重视大脑的解释，而过于忽视身体的感受。
- 3. 可以把它作为一种技术，但是最好不要把它升级成一种信念。
