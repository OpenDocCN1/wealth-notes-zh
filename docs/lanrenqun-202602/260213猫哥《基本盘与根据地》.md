

# 基本盘与根据地

260213 猫哥

看后台留言最大的感受就是很多人都很焦虑，焦虑大环境，焦虑单位没前途，焦虑年龄大了没技能等等，那么怎么解决这些人生的焦虑呢？

我给大家提一个基本盘与根据地的概念。

我们常说读史如同观镜，那么为什么历史上农民起义一般都是失败？为什么我党在 412 之后，面对地狱级别的开局，为什么能取得最后的成功？

原因可以有无数条，但是核心只有一条。

古代农民起义都是流寇，从来不建立自己的根据地，而我党在 412 之后，在秋收起义失败之后，一直把建立根据地作为中心任务来抓。

有根据地就有根，就有基本盘，然后慢慢才寻求发展，星星之火可以燎原。

好了对比当下，所有焦虑的朋友其实本质上就与古代的农民起义军差不多，到处流窜，饱一顿饿一顿，没有基本盘，没有根据地，也就是没有根。自然就对未来与前途感到迷茫。所以，解决焦虑最好的办法就是回答几个问题：

- 我的基本盘在哪里？
- 我的根据地在哪里？
- 我的根在哪里？

其实对于个体而言，如果仅仅是保证生存与未来，这个基本盘与根据地要求是不高的。

比如，你现在所在的企业（或者行业），可能看起来没有多大的前途（全国大部分行业都是这样），但是只要还没垮掉，还能按时发出工资，都是可以作为基本盘与根据地来建设的。我们唯一要做的仅仅是不被裁员而已。

要做到这一点其实也不难。

如果自己在技能与业务水平上乏善可陈，那么就在人事上在关系上下功夫。

比如，想尽办法与领导建立良好的私人关系。

领导也是人，再大的领导也会有一大堆烦心事——比如接送小孩，比如小孩培训辅导，比如家里老人看病照顾等等，任何人只要做到脸皮够厚，腿脚够勤，嘴巴够紧，这些领导的麻烦事都是可以揽过来做的，当你能帮助领导解决他生活的烦心事的时候，与领导的私人关系就建立起来了，这就是你的基本盘，这就是你能在企业生存的根基。

还有另一种情况，就是企业看起来很没有前途，自己就是企业的小领导也感到迷茫怎么办？

去年一个银行的朋友就是这种情况。朋友是银行一个网点负责人，但是各种考核 KPI 压力让他喘不过气来，同时也感觉现在做的事看不到前途，这种情况下怎么找到自己的基本盘？怎么找到自己的根？

其实逻辑也很简单，银行靠啥生存？归根结底不就是靠客户吗？左手存款进，右手贷款出，中间掐点油水而已。

所以，我就给这个朋友出了一个主意，用个人微信加高净值客户。对公这是帮助银行揽客户维护客户，对私只要运作得好，这批高净值客户就是你的基本盘，你的根！

过程就不详述了，朋友在我的开导下将焦虑转化为动力——他甚至给自己定了阶段性的 KPI，每个月要加多少人，然后每天每人私信一篇小作文，分享自己对金融形势的观点与看法，不知不觉一年过去了，他就加了上千人，大部分人还有一些互动，看着微信通讯录这批高净值客户，朋友突然就不焦虑了。因为他已经有自己的基本盘，有了自己的根。

所以呢，今天给大家分享不是简单的方法论，而是几千年历史的宝贵经验总结，如果仅仅是农民起义造反，声势再大，如果没有根据地最后也是覆亡，相反，即便是地狱级开局，如果坚持把建立基本盘，建设根据地作为中心目标，也能逆袭天下。

所以解决大家生存焦虑就是把几个简单的问题整明白了就行了：

- 我的基本盘在哪里？怎么稳固我的基本盘？
- 我的根据地在哪里？怎么更好建设我的根据地？
- 我的根在哪里？怎么让我的根扎得更深？

相信我，即便你只是一个普通人，把这几个问题整明白了，你的人生绝不会失败。
