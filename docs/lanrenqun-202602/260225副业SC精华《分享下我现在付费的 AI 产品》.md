分享下我现在付费的 AI 产品：

- 1. ChatGPT Pro, 200 刀/月，使用场景：主力聊天工具 (沉淀我最多记忆，随时聊，Pro 模型深度探讨)，现阶段主力编程工具 (Codex)。
- 2. Gemini Pro, 20 刀/月，使用场景：NotebookLM 辅助阅读学习，Antigravity 编程智能体在本地处理临时需求，Chrome 下的 Gemini 问答 (和网页对话)。下个月开始，会开 Ultra 会员，大概 250 刀一个月。
- 3. Manus Pro, 40 刀/月，使用场景：通用行动智能体，类 OpenClaw，但更智能，完成任务更会自己找各种工具解决，但消耗积分也贵。OpenClaw 完不成的任务有时我会找 Manus 来执行。我会从 Manus 的一些能力里面去寻找提高我的 OpenClaw 能力思路。
- 4. Grok, 50 刀/月，使用场景：Grok 可以调取 X 平台的数据，我把 X 平台当成我的最大号赚钱和 AI 实践的知识库，搜索调研各种真人的经验分享。
- 5. Vultr VPS，大概 50 刀/月，使用场景：我把 OpenClaw 配置到了海外服务器上，这样可以方便的配合我各种海外信息获取工作流。
- 6. 飞书体系，包含在公司的飞书付费套餐内，使用场景：飞书问答，飞书录音豆，公司知识库对话，公司每日工作总结。
- 7. Claude，之前 250 刀/月，使用场景：之前是 Claude Code 主力编程，自从这个月我的 Claude Code 被封了号后，我彻底放弃 Claude，不去折腾，也劝大家不要把主力聊天放在 Claude 上，有被封号风险。君子不立于危墙之下。
- 8. RapidAPI 里面的各种社交平台的数据获取 API，大概加起来 50 刀一个月。
- 9. 沉浸式翻译会员，年费不到 1000 元，配合浏览器插件获取海外资讯。
- 10. Typeless 语音输入法，12 刀/月，使用场景：Mac 端输入法。

还有日常 token 费用，就不算在内了。

全部加起来，也不到 1000 美金一个月，比生财工资最低的员工工资还要低一些，对我来讲，也太划算了。这些花在 AI 工具上的钱，是投资而不是消费，而且我已经非常确定，一定是近几年 ROI 最高的投资，能开最高额度的，我会开最高额度。

每个月 20 刀，加起来 1680 块钱，如果你每年只有这么多钱为未来投资的预算，那我强烈建议你去开一个 Gemini 会员或者 ChatGPT 会员。

接下来预计半年，我用 AI 的三个目标，其实都是围绕着 Agent 来：

第一个，是把我的整个信息获取的工作流全部 Agent 化。这个可以完整支持整个生财有术赚钱机会的前沿性，包含超级标，一条超级标能够支撑起一个赚钱的小生态。

第二个，全力的把生财有术的各项工作都 Agent 化，包含增长、内容、运营、服务、产研等，这背后要求整个生财团队对 AI 编程以及 Agent 的理解和落地，一方面我会积极的推动整个团队对 AI 的学习和使用，另外一方面，我打算直接带 5 个人以内的 AI 小分队，从公司内部选拔出来，靠这几个人来深度的把公司各项业务都 Agent 化。

第三个，探索用 Agent 更好的赋能圈友赚钱，举个例子，如果我们发现 YouTube 的赚钱机会，从选题到视频制作全部靠 Agent 根据每个人的需求和特点定制好，圈友只实现最终的发布就可以了。再比如，垂直小号的机会，我们依靠 Agent 直接帮每个人制定好定位、内容，每天把合适的内容推送给圈友，圈友只需要拿着内容去发布，就可以实现日更和获取流量的目标。当然，这背后就涉及到大量和各个垂直领域有优质工作流的圈友深度合作了。

也许，不久的将来，我们真的可以实现让每个圈友躺着赚钱的目标。

这是个最好的时代，我看到有雄心壮志的人都是完全沉浸其中，不想睡觉的状态，积极的用 AI 创造价值改造业务，我也希望生财有术圈友都能加油跟上。AI 的出现，让一切都重新开始计数，大家都在同一起跑线，甚至因为没有老业务的拖累，新人反而更能快速用好 AI，应了那句老话，乾坤未定，你我皆是黑马。
