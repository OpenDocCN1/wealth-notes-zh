# 第一站，賺取第一桶金 認清資本的力量

但如果阁下像大多数人一样，没有富裕的家底，请在此第一站「起跑线」就位，由累积第一桶金开始。同时，笔者亦会恭喜你，因为你获得的会比富二代更多，由零走向财务自由的路，沿途风景很漂亮，值得你细心欣赏。懂得欣赏，你的人生将会变得不一样。

每一个人的起步点都不一样，没必要去想太多，人生起跑线不是自己决定，但中途站及终点在哪里，则由自己计划、自己编写。你抱怨社会也没用，只会浪费 时间，而年轻人最宝贵的资产当然就是时间，大家要将其好好珍惜及利用。

# 做专业人士 Vs 搞 Startup

如何赚取第一桶金？笔者认为从来都没有捷径，既不应该跟着传统思路走，也不应该随潮流去创业！

过去数十年来，社会普遍认为是读好书，入名校，读大学修专业学科，毕业出来做专业人士，就可成为社会的天之骄子。随着时代转变，传统行业到了樽颈，大学生数目大幅增加，专业人士供应量多了，自然没上一代吃香，起薪点也下降了。而随着香港作为世界金融中心的地位冒升，投资银行从业员的起薪点较其他行业及专业人士高，市场又开始追捧投行职位，不少高考状元和海归名牌大学毕业生全成了投资银行家（iBanker），大学的经济金融学系都变得炙手可热。
