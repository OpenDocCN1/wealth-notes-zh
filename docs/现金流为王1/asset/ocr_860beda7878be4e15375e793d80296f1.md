# ## 富中產或窮中產 關鍵在可持續現金流

香港有不少中產人士，收入高，表面上財務狀況非常健康。然而收入來源很單一，主要靠每月工資，是靠勞力和時間換取的主動收入，因此從結構上看，長遠並非如表面般健康。假如經濟不穩，原來穩定的工作突然變得不穩定，或十多年後開始計劃退休，而小朋友十多年後仍在中學階段，同時計劃海外升學，開支只會有增無減，屆時現金流狀況便會由健康變為不健康。當收入無明顯增幅而開支增加，人的壓力自然增加，甚至需要延遲退休計劃。

同為中產，即使淨資產及每月收入相若，有部分可如期50歲退休環遊世界，有部分卻到50歲時財務狀況不但沒有進步，反而倒退，最後需要延遲退休。原因為何？
