# 做好資金管理 防流動性危機

在我的理財投資哲學中，在合理風險下尋求高回報之餘，資產流動性亦是我最重視的一環。不少基金、投行在金融海嘯中資金鏈斷裂，導致上萬億的資產崩潰，都是出於流動性的問題，作為專業投資者應從中汲取寶貴教訓。投資，若要立於不敗之地，謹守戒律才是至關重要。

無論你是做生意或是打工人士，都需要定期做好個人資金管理計劃。沒有良好而有條理的資金管理，就莫說有良好的投資表現。投資往往是因為沒有做好資金管理計劃而導致失預算。

以筆者為例，作為生意經營者，同時又是投資者，我每個月都會做好資金管理，對生意上所投資的項目及經營性的現金流作出預測。用汽車來比喻，生意是「前輪」，前輪所產生的現金流入，相當一部分會流入「後輪」，而後輪就是投資，投資會帶來更穩定的現金流入，扣除開支後的現金流會用於後輪的再投資，不斷滾存。時間一長，個人財富組合風險會再分散，進一步優化整個組合，真正做到進攻退可守，而當中關鍵就是現金流。
