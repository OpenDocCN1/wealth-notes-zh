# 第三站：多元投資＋創業 主動出擊

香港問題是專業人士太多，創業者少。這是歷史遺留下來的問題，亦是每個已發展國家總會面對的問題。一方方面，香港教育著墨死記硬背，所謂的精英教育、「知識改變命運」觀念根深柢固，中產家長們都著墨「贏在起跑線」；當知識沒能改變命運，同時社會貧富差距拉開，市場遊戲規則改變，香港人就開始貶疑，加上政業及相關利益團體、傳媒的影響，年青人價值觀開始改變，部分更變得仇富、反智。當不少人都認為「一帶一路」是笑話（當然689政府都有相當的責任），筆者看到的卻是極大的市場機會，並已經研究發展馬來西亞市場。香港的步伐，在海嘯後幾年已毫無疑問比其他競爭對手走慢了很多，再不急起直追的話，十年後可能真的如上文所說，機會窗口完全關閉。

香港在傳統產業優勢漸失的大環境下，只有大集團和大品牌才能岀立不倒，小市民創業去搞零售、開酒樓必然輸錢收場。在內地二三線、經濟發展中的城市，即使傳統產業也仍有機會，可見在不同的環境下做同樣的事，會有不同的結果。香港人要明白自己的優勢在哪，大環境轉變了，再按傳統的方法定，失敗是必然的，不應怪香港機會不多，只能怪自己不會審時度世，創造新產業，為市場創造價值。要知道香港的國際人才資源、稅制和成熟的法制有多大優勢，怎樣利用這種優勢走一條該走的路（如創意產業、科技產業）才是關鍵。

以上不一定是事實，但值得大家反思。
