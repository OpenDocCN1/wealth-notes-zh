# 4.6
窮中產的
非理性消費模式

![](bbox=[0.05, 0.05, 0.3, 0.27])

金融海嘯後，全球經濟出現巨變，市場遊戲規則改變，大家不知不覺間已經過渡到另一個世界。不少人會覺得，為何我爸媽年代大家生活都不覺吃力？現在社會進步了，感覺反而生活得比以前更吃力？

第一個原因當然是社會富餘殊差距拉闊。幾十年前，左鄰右里的生活水準普遍很接近，我住的居屋可能十多萬，你住的私樓可能二十萬，不覺得貧富有多大分別，也沒有特別大的要求或需求；消費市場沒有太多選擇，大家的消費模式也沒有多大差異，生活得很和諧，不存在強烈的比較。數十年後的今天，隨著科技進步，社會普遍生活質素大幅提升，日常生活所需的選擇多了，即使是同類型的日用品或家庭用品，不同選擇的價格差異可以是數十倍。同樣是吸塵機，Dyson 與普通家品店的型號價格差異何只十倍，但 Dyson 已不是有錢人專利，身邊不少一般市民都可能擁有。這反映了甚麼？不是 Dyson 價錢親民，而是大家消費模式改變了，筆者稱為「消費力錯覺」（Purchasing power illusion）。
