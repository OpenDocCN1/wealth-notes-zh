# 3.11 平價農地 價值升級成農莊

香港百物騰貴，相對平價的磚頭資產除了工廈外，還有農地。農地價格便宜，原因與工廈差不多。農業在香港已經式微，大部分的農產品均從外地或內地進口。對於一般人的認知而言，農地只能用於農耕，商業價值十分低，農地價格也就極為便宜。

有了投資工廈的成功經驗，筆者在想，既然農地這般便宜，如果能夠在極低市場價值的農地上加入一點點商業元素，為農地提升商業價值，這將會是另一種主動增值的價值投資。
