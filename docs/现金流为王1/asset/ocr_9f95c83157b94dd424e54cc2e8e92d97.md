# 後記

筆者自小貪玩，小時憑著小聰明，小學階段不用讀書也名列前茅，中學階段繼續貪玩，因覺得讀書太沒趣，整天打波不讀書，成績低落，第一次會考只得7分。放榜當天看到母親失望的表情決心發憤讀書，到處找學校，最後從屯門跑到灣仔重讀。有些事情失去過才懂得珍惜，短短一年的重讀生涯體驗了許多，得到啟蒙老師龍Sir的啟發，明白到人生需要計劃，有心不怕遲。從此每走一步都很用心地去計劃，走自己認為正確的路，目標是希望自己和身邊的人都能擁有富足人生。

理財和人生同樣需要計劃，分別只在於人生投資的是時間，理財投資的是金錢，時間和金錢同樣重要，有時間沒金錢抑或有心靈錢沒時間都沒有意思。因此，努力工作的同時亦要懂得投資，只有投資才能獲得「被動收入」，才有條件贖回自己的人生和時間。投資愈早開始，效果愈顯著，這是複息的力量，因此愈早懂得珍惜時間去投資，便能愈早獲得真正的「財務自由」，擁有更多時間去做有意義的事情。
