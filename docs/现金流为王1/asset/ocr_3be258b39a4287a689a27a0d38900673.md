# ## 2.4
真正的高息股：
房託 (REITs)

投資REITs及高息股，都可產生持續的現金流，大家應多加研究。筆者在第一站曾提及，REITs盡得房地產升值之好處，而且化解了投資住宅的辣招及回報率低之短處，同時具有高倉值的特點，是穩健投資之選。那究竟REITs是甚麼？

# 低負債 高派息

REITs (Real Estate Investment Trust) 中文全名為房地產投資信託基金，簡稱「房託基金」。沒錯，REITs 如其名是一隻基金，性質是上市的封閉式基金 (closed-end fund)，所以其基金單位就像股票，按現行市價買賣，而市價很大程度由市場供求決定。理論上，基金單位的價格與本身的資產淨值沒直接關係，即其二手價格可能較基金本身的資產淨值出現溢價或折讓。
