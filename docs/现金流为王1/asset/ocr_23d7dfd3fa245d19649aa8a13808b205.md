# 被動收入 不低於家庭開支1.5倍

這種理財哲學對我很重要。如前文所說，我是一個有家庭的人，上有高堂下有妻兒，一家大細都等我開飯。相信不少中產讀者近年都會體會到，隨著通脹，銀紙愈來愈不值錢，一個中產家庭的基本開支，每月7-8萬對於一個有小孩的家庭來說已是必需。因此，投資要立於不敗之地，必須要謹守原則，避免受其他客觀因素影響。即使給我遇到再好的投資項目，以上的資金分配永遠不會改變。
