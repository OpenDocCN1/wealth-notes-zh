# 專注「有數得計」投資 致富不是夢

當你明白複利的力量，就會明白時間的重要，亦會明白5%年回報已足以令你致富。你會再浪費時間去投機炒股，還是專注「有數得計」的投資，讓時間將你的雪球滾大？

對於一般非「投資專家」的普通人，不應對投機回報和資本增值有過分的預期，因大部分普通人認為會令資產資本增值的因素一般已經在價格反映（Price-in factors）。因此作為普通打工仔，有正職，又不是專業投資者，時間不多，更不應對這類筆者稱之為非常回報（Abnormal return）有過分臆想，而應對「有數得計」的投資下功夫。
