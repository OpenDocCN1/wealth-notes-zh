# 第一站：賺取第一桶金 認清資本的力量

所謂「有數得計」，即是會定期產生現金流的資產，這類資產值得累積，使自己的收入來源更廣。以勞力收入作爲前鋒，再將勞力收入的儲蓄投資往有定期現金流的資產，累積一段時間，直至非勞力收入（被動收入）比勞力收入（主動收入）更多，財務自由就指日可待。

會持續產生現金流的資產包括：

+   1. 穩定派息的股票（高息股如一些公用股、內銀股等）；

+   2. 以一籃子租金收入為主、同時會定期將不少於90%盈利分派予股東的房地產信託基金（REITs）。例子有領展（0823）、越秀房託（0405）和置富產業信託（0778）等；

+   3. 固定收益資產（Fixed-income asset）如定息企業債券（例子有內房債世茂房地產、路勁基建等等）；

+   4. 買入「實磚」（實物磚頭）物業收租（包括住宅、工廈、商厦和鋪位等等）。

上述都是能持續產生現金流收益的資產，然而它們的特性和收益率（Yield）都不同。在資金不多的情況下，投資一開始不必強求太分散，可選擇一些具穩定增長的高息股，好處是回報率「有數得計」，基本上每半年派息一次，到時再用收回來的股息分散投資其他具增長潛力又會穩定派息的股份。要注意的是企業派息背後是否有盈利支持，切勿只看周息率或一味貪高息。由零開始到第一桶金，一點也不困難，關鍵在於你是否on the right track，以及能否堅持，謹守紀律。
