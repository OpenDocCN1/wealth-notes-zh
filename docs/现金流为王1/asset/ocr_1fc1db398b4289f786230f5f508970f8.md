# 第一站：滾動你的投資雪球

其實與賣股套現無異，這與「債基」（債券基金）如何每月保證派息的道理一樣。（「債基」保證派息的來龍去脈，筆者稍後解釋。）

重申一次，長線投資收息股應關注該股每年的**股息增長及可持續性**，前提是**盈利和派息**能同步。股價增長，或是每年股息派發的增長，都可體現該企業價值，一種是股價（帳面）體現，另一種是現金流的體現。其實，上市的股票已證券化，要套現可以直接賣出股票，不一定「期待」收息去體現現金流，因此長線持有收息股的焦點不是現金流，而是其每年的派息（盈利）增長及其可持續性。以何種方式體現（股價、股息或紅股）則視不同投資者本身策略的需要。

我相信價值投資，投資股票等同投資公司，公司的表現離不開盈利或將來的**盈利**。股息、股價只是體現上市公司價值的一種方式，背後如果沒盈利支持都是沒有意義的。

試想想，投資一隻股票，如每年盈利及股息持續雙位數增長，而股價卻不斷下跌，假設沒其他因素，你應該感到高興還是失落？筆者肯定感到高興，因為發現了一隻市場錯價的股票，也難得地找到市場有極好的再投資機會，而股息在持續盈利支持下，長遠而言，價值總會回歸，這就是真正的價值投資。
