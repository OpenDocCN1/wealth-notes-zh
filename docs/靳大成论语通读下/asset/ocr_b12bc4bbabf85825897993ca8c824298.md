# 14 | 你愿意跟狂狷之士交朋友吗

13.19

樊迟问仁。子曰：“居处恭，执事敬，与人忠。虽之夷狄，不可弃也。”

13.20

子贡问曰：“何如斯可谓之士矣？”子曰：“行己有耻，使于四方，不辱君命，可谓士矣。”

13.21

你好，我是新大欢，欢迎来到我的《论语通读》，我们今天一启，读懂经典。

13.19 樊迟问仁。

樊迟问怎样做才是仁。

你还记得上一篇《颜渊》里，樊迟曾提出过同样的问题。

这里孔子是对“仁”的解释。是以“恭”“敬”“忠”三个德目为基本内涵。与说泛泛的宽要求相比，对内在的修为和外 在表现上，境界明显上了一个台阶。

孔子怕樊迟理解得不透，最后还是意犹未尽，一口气他拍着胸脯说：

这是强调恭、敬、忠三德目是一种普世通行的道德标准。

13.20 子贡问曰：“何斯可谓之士矣？”

子贡问道：“怎样才能叫做士？”

“士在古代家族中算是最底层，此后慢慢变为古代社会知识分子的通称。

子贡问的是君子，不是鲁人，不是仁人，而是士。

子贡非常善于思考。

于是孔子就从日常生活的修身说起。

子贡再问，如果比这个标准再降一等，是什么情况？

这个问题多少有点难答。

但子贡非问不可，到最后两个问题有点敏感，孔子对子贡的态度有点失望了。

“斗”是古代最普通的量器，箕是饭量。用斗箕来容纳人，指的是有些人眼里见识狭小。

你大概也学过《曹论战》，曹刿对当政者有个评价，叫“肉食者鄙”。

不过，随着经典流传，“言必信，行必果”在今天倒成了一句赞美的人的信。

13.21 子曰：“不得中行而与之，必也狂狷（juàn）乎！狂者进取，狷者有所不为也。”

孔子说：“碰不到奉行中庸之道的人和他交往，我一定交朋友。

狂狷二字，流传今日。

你可能觉得奇怪，孔子教育弟子一向是主张行礼。

有一次，孟子的学生万章问他，关于孔子在陈，‘饥乎来，民党在小怀羁，进款，不忘甚国’。

孟子解释说，孔子大概因为找不到中行之士吧。

孟子给他举例。

而狷介之士呢？

唐代大诗人李白，就从这个词里立意，选用了楚狂接舆的例子。

“孔子说的中行，就是不偏于狂，也不偏于狷。
