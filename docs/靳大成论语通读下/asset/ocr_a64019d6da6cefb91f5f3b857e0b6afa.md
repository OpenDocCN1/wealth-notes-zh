# 03 | 孔子把谁逐出了师门

11.13 闵子侍侧，訚（yín）訚如也；子路，行（háng）行如也；冉有、子贡，侃侃如也。子乐。“若由也，不得其死然。” 11.14 鲁人为长府。闵子骞曰：“仍然毁，如之何？” 子曰：“夫人不言，言必有中。” 11.15 子谓子贡：“女与回也孰贤？”子曰：“赐也进乎学，冉有与也。”

11.16 子谓子曰：“师也过，商也不及。” 11.17 季氏富于周公，而求也为之聚敛而日富之。子曰：“彼寡夫也，小子鸣鼓而攻之可也。” 11.18 子路，有朋皆曰：君子也，师也亦（pì），由也亦（yān）。

你好，我是新大成，欢迎来到我的《论语》课，我们一字一句，读懂经典。

这一讲总共六篇，内容大多涉及孔子对学生们的具体评价。

11.13 闵子侍侧，訚（yín）訚如也；子路，行（háng）行如也；冉有、子贡，侃侃如也。子乐。“若由也，不得其死然。”

闵子骞侍立在孔子身旁，一派和悦中正的样子；子路则一副刚强的样子；冉有、子贡又是温和而高兴，孔子的脸上洋溢着满足的微笑：“我总觉得，若由也，不得其死然。”

这里“讷讷”分别用三个词形容孔子的学生：闵子骞、行行如、侃侃如。其实，一个人的内在性格，从他的日常言行和语语气就能表现出来。

闵子骞在行如也，所以说很温和了。冉有和子贡多口才，语言敏捷力，话也来得快，一搭便，滔滔不绝。至于子路，则虽勇猛，但话不绕弯子，真直去，有时候显得气壮。

最后评论子路的这句话，值得玩味。“子路”，是希望孔子一方面他的性格各方面都有特长和优点，但另一方面子路这些短处，遇事不会周详。在这个乱世，难怪他不会好的结果。

这一乐一评，从一个侧面反映了孔门师生间的深情。尊师重道，爱生如己，对教育的重视，是我们的优良传统。

11.14 鲁人为长府。闵子骞曰：“仍旧贯，如之何？何必改作？” 子曰：“夫人不言，言必有中。”

鲁国翻新长府的仓库。闵子骞说：“照老样子去办，怎么样？何必改建呢？” 孔子说：“这个人要是不讲话，一讲话就能击中要害。

“长府”是鲁国的国库。理理解这句话，不能把“仍旧贯”的“仍旧”理解成今天的“惯例”。这里的“仍”是沿袭，保留意思。‘仍旧贯’就是沿用旧制，还是原来的样子。

闵子骞这一次提出反对的意见，不光是以奉行旧制，而且说话非常得体。

鲁人的长府为什么要修？解我们知道不清，但人们有几种猜测。闵子骞是不主张大干快上，浪费人力物力。但显然，长府肯定遭到不修或修坏的地步。那既然如此，依惯例照旧也行，何必非要新修呢？夫子赞他也会说话，说得非常得体。

所以你看，在提醒子贡他们这些会说说话的人少说话的，闵子骞，夫子会表扬谨慎而一说的闵子骞。这就是夫子对‘说话’的态度。

11.15 子曰：“由之瑟，奚为于丘之门？” 门人不敬子路。子曰：“由也升堂矣，未入于室也。”
