# 1.1 “名正言顺”为什么重要

1.3.1 子路问政。子曰：“先之劳之。”请益。曰：“无倦。” 1.3.2 仲弓为季氏宰，问政。子曰：“省力俭用，慎罚而慈惠。”子曰：“先有司，赦小过，举贤才。”子曰：“吾何暇哉？举尔所知。”子曰：“尔所不隐，吾得舍乎？” 1.3.3 子曰：“君子居其位，必须名正，则不惑不患，无患则事不成；不成，则礼不兴；礼不兴，则刑罚不中；刑罚不中，则民无所措手足，故君子之于言也，无有苟而已矣，君子之于行也，无有苟而已矣。君子不以其言与人而已。” 1.3.4 樊迟请学稼。子曰：“吾不如老农。”请学为圃。曰：“吾不如老圃。”樊迟出，子曰：“小人哉，樊须也！上好礼，则民无所避，好义，则民无所惮，好信，则民无所欺，四方之民襁负其子而至，岂用稼乎？”

1.3.1 子路问政。子曰：“先之劳之。”请益。曰：“无倦。”

子路问为政之道。孔子说：“要做表率并亲自劳作，然后才能使人顺从。”子路请求再多讲一点，孔子说：“不要懈怠。”

你看，和前面几章子张、樊迟、司马牛、冉雍等弟子问政的回答不同，孔子对子路、言氏这个最无礼的、最欠琢磨的脾气，就什么也“先”“先”。这该做到的道理，但他追问时，子为子为他在往深远里说，而只回答一句“无倦”呢？

子路简直有余，细绳缺精的样子，性子刚、刚直有余，不圆滑。这样的个性，往容易缺少耐心和细心。一句话，是提醒他要有小心从事、如临深渊，如履薄冰，要有耐心，有始终，不可松懈。

1.3.2 仲弓为季氏宰，问政。子曰：“先有司，赦小过，举贤才。”曰：“焉知贤才而举之？”曰：“举尔所知，尔所不知，人其舍诸？”

仲弓做了季氏的家臣，问为政之道。孔子说：“给手下负责事务的官员派表率，赦免他们的小过错误，选拔有良贤才。”仲弓又问：“怎样来辨别有良贤良人才举而不也，选拔出来呢？”孔子说：“选拔你所知道的人，至于你不知道的贤才，别人难道还会舍弃他们吗？”

有司，是古代负责具体事务的官差。

这一段话可说是手把手地教学生，如果担任了大夫的总管，具体应该怎么做。

举尔所知”这句话很有意思，我举个例子帮你理解。

孔子之后一百多年，燕国发生内乱，差点被齐国灭了燕国君主出走他国，想有燕国开国，就派忠臣处死。齐国一位官员想为燕国招贤，就派大臣招纳贤人，希望国富兵强，报仇雪恨吧？

郭隗告谕燕昭王，看你怎么对待人，能吸引贤才前来。燕昭王对他说：“我该如何招揽贤良人才呢？”郭隗就给燕昭王讲了个“千金买骨”的故事。

古时有个君王想得到千里马，出重金去买，结果三年找不到。于是有臣子建议，先花千金买一千里马的尸骨，表示诚意，天下人就相信君王爱马，千里马就会陆续来了。不久，千里马果然到了。

大臣意思是想给招贤良，就从敬纳郭隗开始，这像请个能臣，贤才智士就会追随而来。郭隗果然被燕昭王厚待，郭隗的贤名传开，于是乐毅、邹衍、剧辛等人纷纷来投奔。

郭隗的例子，真是“举尔所知”最好的注释。

1.3.3 子路曰：“卫君待子而为政，子欲先之何？”子曰：“必也正名乎！”子路曰：“有是哉，子之迂也！奚其正？”子曰：“野哉，由也！君子于其所不知，盖阙如也。名不正，则言不顺；言不顺，则事不成；事不成，则礼不兴；礼不兴，则刑罚不中；刑罚不中，则民无所措手足。故君子名之必可言也，言之必可行也。君子于其言，无所苟而已矣。”

1.3.4 樊迟请学稼。子曰：“吾不如老农。”请学为圃。曰：“吾不如老圃。”樊迟出，子曰：“小人哉，樊须也！上好礼，则民易服，好义，则民易使，好信，则民易信。夫如是，则四方之民襁负其子而至，焉用稼？”
