# 重點整理

+   1. 投資買賣時最重要的是，並非如何巧妙地掌握買賣時間點，而是不要破產。若想避免投資導致破產，首要之務是確實落實資金管理。\n2. 資金管理的要訣在於掌握承擔風險的幅度，避免破產，並在此範圍內追求最大獲利。\n3. 在海龜投資法則中，某標的一次的合宜交易量，稱為「頭寸單位」(Unit)。\n4. 真實波動幅度均值（ATR）是把幾日的數值平均後，算出的一日最大價格波動，運用ATR可計算出一次買賣時適當的頭寸單位金額。\n5. 人難以靠自己的意志力執行停損，所以必須事先決定好「到何種程度時要停損」，一旦到了設定的條件，就執行機械性停損。\n6. 正確的停損線，應該設在足以判斷未來走勢持續或轉換的位置上。
