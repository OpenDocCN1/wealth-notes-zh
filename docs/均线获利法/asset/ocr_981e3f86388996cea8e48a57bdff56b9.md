# 加入柱狀圖，讓你更快看出 MACD 的方向性

![](bbox=[0.065, 0.107, 0.359, 0.305])

事實上，MACD一般還會加入另一項重要要素「柱狀圖」。求出柱狀圖的公式如下：

# 柱狀圖 = MACD － 信號

正如此公式所示，柱狀圖表示的是 MACD 和信號線的間隔。

MACD是用來看12日EMA和26日EMA間隔的曲線，找出兩條EMA的黃金交叉、死亡交叉，可作為早一步找出買賣時機的工具。

信號線是讓我們更容易了解MACD目前走勢，是上漲還是下跌的工具。

柱狀圖則是用來看MACD和信號間隔的工具，有助於我們更進一步提早讀出MACD的方向性。

一般柱狀圖會以長條表示，這裡的柱狀圖也是以0為中心，往上的長條表示正值，往下的長條表示負值（圖表5-6）。
