# 重點整理

+   1. 移動平均線大循環分析有「買賣信號出現太慢」的缺點。除了可用試水溫和提早布局兩種方法因應，也可結合 MACD 技術指標，形成「大循環 MACD」。 2. MACD = 12 日 EMA − 26 日 EMA，若找出 MACD 觸頂反轉的點，便可事先預測出黃金交叉或死亡交叉。 3. EMA 和 SMA 相比，前者對於價格波動的追隨性更佳，除了觸頂、打底的信號更早出現外，線條也更為平滑。 4. 要讓 MACD 的方向和觸頂反轉的時間點明確浮現，可以加入一條 MACD 的移動平均線，觀察兩條線交織出的黃金交叉或死亡交叉。 5. 使用 MACD 的目的，是為了解讀市場上的價格波動（走勢現狀）。要讓波動更為明確，必須使用加入信號線和柱狀圖的完整 MACD 工具。
