# SECTION 1-1

# 為何大家都喜歡，用技術線型來分析買賣點呢？

為什麼要投資呢？這是一個單純的問題，答案也很簡單：「為了增加資產。」這是唯一的答案，也是所有投資人的共同想法。

為了聰明投資以增加資產，於是衍生出基本面分析和技術分析兩種方法。不過，一般投資人要靠基本面分析和投資專家決勝負，確有難度，所以才要研究技術分析。技術分析的指標之一，就是本書要說明的移動平均線。

技術分析指標除移動平均線外，還有相對強弱指數（RSI）、指數平滑異同移動平均線（MACD）、一目均衡表、隨機震盪指標等，並沒有絕對正確或錯誤的指標。每種指標都有其原理。

此外，不論使用哪種手法，共通點是「用技術線圖分析行情現狀」。所謂技術線圖分析，分析現狀的重要性遠大於預測未來，這一點請讀者務必牢記在心。

分析現狀時，找出「有優勢的狀態」，就是技術線圖分析的基本原則。
