# SECTION 3-2

# 如何看出市場或個股的趨勢正在上漲、下跌還是盤整？

三條移動平均線的排列方式只有六種，三條線（短期均線、中期均線、長期均線）的排序，有下列這些排列組合。

+   - 第一階段：短期均線、中期均線、長期均線。\n- 第二階段：中期均線、短期均線、長期均線。\n- 第三階段：中期均線、長期均線、短期均線。\n- 第四階段：長期均線、中期均線、短期均線。\n- 第五階段：長期均線、短期均線、中期均線。\n- 第六階段：短期均線、長期均線、中期均線。

市場行情會由第一階段依序發展到第六階段，這也是移動平均線大循環分析的基本概念（圖表3-2）。此六階段都隱藏著代表行情現狀的訊息，訊息如下。

+   - 第一階段：穩定上漲。\n- 第二階段：牛市終結。\n- 第三階段：熊市入口。
