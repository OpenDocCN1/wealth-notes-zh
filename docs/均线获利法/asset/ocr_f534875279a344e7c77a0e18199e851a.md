# SECTION 7-2

# 如何練習才有用？
你得……

練習時必須使用過去的線圖。請從券商等單位提供的看盤系統中，找出可回溯過去線圖的系統。如果只能回溯過去一年的線圖，無法進行深度的練習。如果用可以回溯五年、十年，甚至更久的系統來練習最為理想。

第二個條件是要有K線。回溯過去的線圖時，從過去某個時間點開始，線圖系統都有K線。幾乎所有券商提供的看盤軟體都有相同架構，你也可以向往來的券商詢問。

以網路看盤系統來說，我建議大家可以使用以我的移動平均線大循環分析，以及大循環MACD為指標的「Trading View」（https://tw.tradingview.com/，內建中文系統）。此外「Monex」（https://www.monex.co.jp/，僅日文）的交易站看盤系統，也使用我的移動平均線大循環分析，做為標準內建指標。

實踐練習時請特別注意以下事項：

+   - 要回溯自己不知道的過去線圖。

+   - 只靠線圖最右側來判斷。
