# 我練習超過 1000 次，你呢？

![](bbox=[0.05, 0.11, 0.34, 0.31])

究竟要練習幾次，才能分辨盤整行情和大行情，並找出大行情開始、結束的標記呢？

參考值是看 1000 次一年度的線圖，我稱這種做法為「1000 擊」，練習一年度的線圖就是一次出擊。操作一年度的線圖，尋找哪裡出現大行情，應該在哪裡買進或賣出，出擊 1000 次，就等於進行 1000 年度 的練習。

聽到 1000 年度，常有人說：「我又活不了那麼久」，但實際操作起來，一年度的練習不過花費 20 分鐘左右。只要有心，一天就可以練習五年甚至十年份。雖說要練習 1000 年度，如此計算的話，其實花不了多長時間。快則一年，慢則二、三年便能達成。

當然不是一定要練習這麼多次，才能成為勝利組投資人。但若能練習到這個程度，任何人都可以以直覺掌握看盤的技巧。如此便可在有賺有賠的投資世界中，成為最終勝出的投資人。
