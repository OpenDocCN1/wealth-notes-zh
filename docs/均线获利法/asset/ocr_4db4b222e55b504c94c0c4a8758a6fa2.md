# 優勢在賣方的狀態

① 移動平均線的排列由下而上為短期均線、中期均線、長期均線。

# 兩者各有兩個條件，只要符合條件即可判斷優勢在買方還是賣方。

當然優勢在買方時就要布局買進，優勢在賣方時則要布局賣出。更重要的是，除此之外的時機都一律按兵不動。原則雖然簡單，不過這就是買賣的勝利方程式。國外也因此稱這種手法為「完美操作（Perfect Order）」，表示在買賣中最完美的條件，也是最完美的機會。
