# 移動平均線的優勢

第二章將詳細說明移動平均線。這條線之所以會成為買賣時的優勢，最主要的原因是「行情走勢會持續」的經驗法則。因此，建立符合走勢方向的部位，是獲勝的關鍵，而最容易了解行情走勢的技術指標，就是移動平均線。

移動平均線有許多活用方法，也有許多當成優勢活用的方法，如第二章將說明的黃金交叉和死亡交叉等。本書介紹的「移動平均線大循環分析」，則是綜合判斷移動平均線中各種能當作優勢活用的方法。詳細內容將於第三章起依序說明。
