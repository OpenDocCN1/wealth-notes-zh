# 重點整理

+   1. 移動平均線大循環分析的優點，在於可清晰看出優勢所在。這種方法既可套用在觀察日線、週線的長期投資，也可運用在使用分時走勢圖的短線投資上。 
2. 買方優勢的位置，是移動平均線的排列順序，由上而下依序為短期均線、中期均線、長期均線，且三條都呈左下右上的走勢。 
3. 賣方優勢的位置，是移動平均線的排列順序，由上而下依序為長期均線、中期均線、短期均線，且三條都呈左上右下的走勢。 
4. 移動平均線大循環分析的基本概念：市場行情一般由第一階段依序發展到第六階段，但有時也會反向發展，稱為「逆向」。 
5. 階段逆向是大盤進入反轉點、反彈點或盤整局面，且不會持續太久。因此進入逆向時，要及早為回到順向時好好布局。
