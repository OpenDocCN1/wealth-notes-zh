# Column 關於海龜計劃

當我進入投資世界時，業界正在改變，由投機轉向投資，當時「海龜計劃」正是眾所矚目的焦點。

海龜計劃始於在黃豆市場累積巨富的華爾街傳奇交易員理查·丹尼斯（Richard Dennis），和他的盟友威廉·艾克哈特（William Eckhardt）的一個賭注。

賭注的內容是：「交易員是與生俱來的天賦？還是可以被培育的？」丹尼斯認為交易的技巧是可以傳授的，而艾克哈特認為是與生俱來的天賦。

為了找出答案，兩人在報紙上刊登求人廣告，挑選出 32 位年輕人。
