# 重點整理

+   1. 移動平均線可以平均價格波動，讓波動較為平滑，更容易看清走勢。

2. 運用分析指標時，最重要的是理解指標的計算根據，切記不用自己不理解的指標。

3. 移動平均線的畫法是，每日計算某段固定期間內數字的平均後，將每日算出的數字連成一條線。

4. 要使用什麼期間的移動平均線，端視自己的買賣期間，或者想買賣的期間而定。應配合自己的買賣風格，參考合適的移動平均線。

5. 移動平均線最簡單的運用方法，是比較過去某段期間的平均買價（或平均賣價）和現在的價格。

6. 掌握平均買價（或平均賣價），和現價比較，分析目前市場上投資人的損益狀況，就可以推測接下來容易出現哪種行情走勢。
