# 漲多後，如何看出行情趨勢是否會持續？

在移動平均線大循環分析中，最重要的是第一階段和第四階段，因為這兩個階段是行情走勢出現的時期，大部份的買賣獲利也來自這兩個階段。

只要看移動平均線的排列順序，就能清楚辨識出：現在是否處於第一階段或第四階段。但更重要的其實是判斷走勢是否會長期持續，才是在這兩個階段買賣是否能獲利的關鍵所在。

要判斷走勢是否會長期持續，就要注意移動平均線的間隔。

當維持穩定上漲的走勢時，三條移動平均線幾乎平行（圖表3-15）。同理可證，持續穩定下跌的走勢時，三條移動平均線也幾乎平行（圖表3-16）。
