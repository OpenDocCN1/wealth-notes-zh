# 如何追求最大資金運用效率？事先掌握承擔風險的幅度最重要

前面幾章已經說明，利用移動平均線大循環分析和大循環 MACD 投資買賣時的優勢，也是掌握買賣時間點的方法。

不過，投資買賣時最重要的，並非如何巧妙地掌握買賣時間點，而是不要破產。只要不破產都還可以繼續挑戰，也總有獲利的機會。

投資買賣中，所謂的「破產」指的是什麼？破產的原意是指蒙受大額損失，導致失去財產，不得不宣告破產的狀態。不過，在投資買賣中，破產指的是失去大半投資資金，無法再重回市場的狀態。

要避免落入如此窘境，最重要的是要建立買賣原則。本書介紹移動平均線大循環分析和大循環 MACD，做為投資者布局和平倉的原則。然而，所謂的買賣原則並不只是布局和平倉的方法。

買賣原則中最重要的是資金管理，若想避免因投資導致破產，首要之務是確實落實資金管理。
