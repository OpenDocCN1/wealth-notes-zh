# 進行練習時，你必須留意 3 個重點！

接下來要說的也是理所當然的事。練習並不是閉著眼睛猛做就好，大家都知道「有目的、掌握要點的練習」一定比較有效。

進行練習時請牢記以下幾點：

+   - 看出盤整行情和真正的大行情。
- 找出行情開始的標記。
- 找出行情結束的標記。

投資時最重要的事，是看穿盤整行情和真正的大行情，所以練習時要把重點放在這裡。

盤整行情是大盤走勢持平的狀態，表示買方和賣方勢均力敵。有時買方可能稍微占上風，不過賣方很快又會出頭，反覆拉扯造就出盤整行情。一旦平衡被破壞，當買方占上風就會起漲，賣方占上風則會下跌。
