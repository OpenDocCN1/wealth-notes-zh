# SECTION 3-13

# 如何看出突破盤整期的關鍵點

持續長時間的波段行情中，進行的買賣操作最簡單，也能獲得極大的利益。

然而，走勢不明顯的狀態（盤整行情）下，獲利就不是一件容易的事。話雖如此，我完全不建議大家這種時候就放棄看盤，因為不論後續是起漲還是大跌，突破盤整期的動向經常是後續趨勢的起點，對投資人來說是大好的機會。

利用移動平均線大循環分析，也可找出突破盤整局面的時間點。

當行情進入盤整，大循環分析的三條移動平均線就會持平，而且互相接近。特別是中期均線和長期均線之間接近，正是判斷盤整期的關鍵。

只有進入第一階段或進入第四階段時，才可能出現突破盤整的局面。

在第一階段，三條移動平均線的間隔逐步放大並開始上升時，就是突破僵局起漲的信號；在第四階段，三條移動平均線的間隔逐步放大並開始下滑時，就是突破僵局下跌的信號。
