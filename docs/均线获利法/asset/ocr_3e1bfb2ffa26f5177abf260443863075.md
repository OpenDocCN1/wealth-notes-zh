# ②加速上漲、加速下跌

上漲或下跌的走勢開始加速後，三條移動平均線的間隔會越拉越開（圖表3-17、圖表3-18），是走勢開始增加動能的狀況。後續發展則會因為現狀是走勢初期還是結尾而不同。

如果走勢初期出現擴散（間隔拉開），表示是蓄勢待發的狀態，可以想像之後可能會朝著同方向出現大行情。

另一方面，如果擴散出現在走勢的結尾，就要注意後續
