# 前言 只要掌握投資技巧，就能提早 10 年賺到千萬退休金！

人的對手就是小次郎。（譯註：取自日本戰國時代的劍術家佐佐木小次郎和宮本武藏在巖流島決鬥的知名故事。）

投資絕非易事，不經學習便難以如願獲利。然而，只要擁有正確的知識，就可以提高獲利的機率，而且要學會正確的知識其實並不困難。

本書適合投資初學者參考（第五章的大循環 MACD 對於中高階投資人也有幫助）。雖然我將這些投資技巧冠上「移動平均線大循環分析」等名稱，乍聽之下好像很難，但說穿了只是運用三條移動平均線來分析而已。

移動平均線簡稱均線，在股市極為出名，甚至有「技術線圖分析始於移動平均線，也終於移動平均線」的說法。只要運用三條移動平均線，就能輕鬆地找出「優勢」所在。

什麼是優勢？這裡指的是獲利機率較高的局面。市場上沒有所謂的絕對，但我相信：只要持續在獲利機率較高的局面投資，最終一定可以獲利。

有鑒於此，我寫了這本書，希望大家開始投資前，能先閱讀本書。書中內容雖然簡單，卻具有實踐性，是成為投資勝利組的捷徑。希望本書能幫更多投資人了解投資的魅力，真正學會如何投資。

執筆時我盡量深入淺出，不過對於完全沒有投資經驗的人來說，或許還是有難以理解的部分。請務必詳讀三次，我保證你的人生一定可以改變。

讓我們一起認真學習正確的投資知識吧！
