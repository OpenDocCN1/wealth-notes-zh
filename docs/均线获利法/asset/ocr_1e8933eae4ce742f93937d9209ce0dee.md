# SECTION 3-9

# 第四階段：穩定下跌期

只要價格持續下跌，反應快的短期均線會率先下降，不久後中期均線跟進，最後連反應最緩慢的長期均線也開始下降。移動平均線的排列，由上而下依序會變成：長期均線、中期均線、短期均線。

這就是穩定下跌期，此時買賣雙方的力量對比，和第一階段完全相反。

在這個階段中，只要三條移動平均線都是左上右下，就表示優勢在賣方的狀態，圖表3-9正是顯而易見的下跌走勢。

因此，在第四階段只要確認三條移動平均線全都朝下，就進場建立空頭部位（如果不是三條移動平均線全都朝下，即使是在第四階段，也可能一下子就結束而進入盤整期，必須注意）。

特別是當三條移動平均線的間隔越離越遠時，就 可以更大膽地進攻。

第四階段持續一段時間後，就一定會進入第五階段（如果要回到第三階段，在第四階段的初期就會退回）。
