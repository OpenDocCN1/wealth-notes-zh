# 推薦序一

# 與其埋頭研讀理論，不如起身練習打擊

作家、全職交易人 梁展嘉

多年的投資生涯當中，終日與數字糾纏，多少使我感到身心疲憊，因此閱讀各類書籍一直是我調劑人生，以及增廣見聞的重要法寶。我雖然看各種書，卻不太看投資相關的書籍。這是因為在十幾年前，我已經把台灣大部分的投資書籍看完了，目前只專注於實踐理論、微調自己的投資方法。不過，有時仍有一些優秀的投資新書吸引我的目光，例如本書《趨勢預測—哥教你均線獲利法》。

本書作者手塚宏二先生介紹的投資方法，以移動平均線為基礎，剛好與我在《一個全職交易人的投資告白》書中所述主張不謀而合。本書中提到的「移動平均線大循環分析」有兩大優點：其一是可以確實掌握住大行情，其二是方法一目瞭然，任何人都可以上手。這兩點正好符合大多數投資人的需要，假如有大走勢可以簡單獲利，誰還要在小走勢裡辛苦來回穿梭呢？
