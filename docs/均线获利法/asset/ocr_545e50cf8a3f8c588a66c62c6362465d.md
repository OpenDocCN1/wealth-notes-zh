# 高深的技術，建立在紮實的基本功上

最有自知之明的操盤手 王力群

本書《趨勢預測—哥教你均線獲利法》是一本踏實的股市教科書，十分難得。

現在很多操作者一進入股票市場，往往抱持兩種不當的想法。第一種是「套公式」：幻想股市中有像統計指標一樣的數學方法，只要每天不停地循環照抄運作，就可以讓鈔票滾滾而來。

另外一種是：高喊「技術優先、技術第一、技術萬歲」，但是連最基本的技術都不會，更遑論心理素質與自我認知。
