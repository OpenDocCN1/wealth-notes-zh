# 用 ATR 來精準計算價格波動，幫你判斷是否該停損！

為了判斷行情會持續或結束，必須確實掌握走勢和雜訊的關係。

走勢明確顯示出價格漲跌的方向性，但實際看盤就知道，即使價格基本上根據行情移動，也會經常上下波動，並不單純（圖表6-3）。

即使價格仍處於上漲行情時，也有投資人打算賣在此時，相對地，就算價格持續上揚，仍會有投資人想買在更高價格。

因為投資人各有盤算，所以價格永遠在上下波動。這些不同的盤算導致寫下行情的過程出現價格偏離，這種偏離就是雜訊。

關鍵在於雜訊的價格波動幅度。如果只是在行情持續中的雜訊，價格波動不會超出一定幅度。在這個範圍內，即使價格朝自己持有部位的反向波動，也必須忍耐。因為行情應該還會持續，只要繼續持有，價格波動很有可能會回到行情的方向。
