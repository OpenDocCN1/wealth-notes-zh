
# Column 關於技術指標的「騙線」

以技術指標做為買賣信號時，明明出現買進信號卻不漲，或出現賣出信號但不跌的狀態，我們稱之為「騙線」。儘管預估價格會漲而建立多頭部位，或是預估價格會跌而建立空頭部位，結果事與願違，就像是被信號騙一樣，因此稱為騙線。

其實所謂的技術指標，不過是根據過去的價格資料，統計出「出現這種走勢時，將來大多會變這樣」的可能性，原本就是自己任性的期待，要說被騙好像也有點言過其實。

技術指標有助於了解現狀，但並不能保證一定可以準確預測未來。當然，本書介紹的移動平均線，也潛藏騙線的可能。

重要的是，讀者要先瞭解技術指標的意義，再根據每種技術指標的由來和架構，掌握什麼狀況下容易出現騙線。

## 葛蘭碧法則的 4 種買入訊號

### 關於買進信號①

這是最典型的黃金交叉。第一，移動平均線呈下降趨勢；第二，這條線隨後出現止跌跡象。在這兩大前提同時成立的情況下，當位於移動平均線下方的價位線，穿破移動平均線向上升時，就是買進的最佳機會（圖表2-5）。

很多人印象中的黃金交叉，是「短期均線由下向上穿破長期均線時」。不過，就如同本章至今的說明一樣，移動平均線和價位線的關係很有意義，考慮到這層關係，請正確理解上述黃金交叉的三大條件。

### 關於買進信號②

乍看之下容易以為是死亡交叉，其實不然。真正的死亡交叉，前提是移動平均線必須處於水平盤整，或是呈現下跌跡象（參閱後面說明的賣出信號①）。再加上價位線必須從上方跌破移動平均線往下降。

在這個例子中，移動平均線依然呈現上升的走勢，而價位線卻往下跌破移動平均線。這是上升走勢持續下的反轉點，不但不是賣出時機，反倒應該是買進時機（圖表2-6）。

但在這種情況中，也常看到移動平均線和價位線交叉好幾次，最後則趨於疲軟反轉向下。到底是逢低買進的時機，還是走勢轉捩點，其實不過毫釐之差，並不算是值得強勢出擊的局面。

### 關於買進信號③

價格穩定上漲時，價位線和移動平均線會平行上升，此時價位線原則上會在移動平均線之上。因為移動平均線是過去數日的平均值，所以在上升趨勢下，平均值當然低於現價，這個現象稱為「移動平均線的落後特性」。

價位線隨時在變，有上有下，而移動平均線的上下會落後於價位線。因此只要看看價位線和移動平均線的位置關係，就能瞭解現狀是處於上升趨勢還是下降趨勢。如果處於下降趨勢，價位線就會在移動平均線下方。

位於上升趨勢時，價格一旦喪失上漲力道，價位線就會慢慢接近移動平均線。相反地，當價格漲勢強勁時，價位線和移動平均線的間隔就會越來越遠。

也就是說位於上升趨勢時，價位線和移動平均線的位置關係不會改變，只是兩條線有時會接近有時會分開，因此買進信號③的例子表示漲勢一度疲軟的行情再次開始上漲，可說是買進的機會（圖表2-7）。

### 關於買進信號④

有人將這個信號視為另外一種技術指標，名為「移動平均乖離率」。

移動平均乖離率是一種技術指標，以數值（%）表示價位線和移動平均線距離多遠，做為買賣時的參考。移動平均如其字面的意思，是一種「平均値」，所以價格背離平均値後，也會有朝移動平均線靠近（回歸平均）的特性。這個指標便是利用這種特性，當成是買賣的信號。

如果價位線以一定的角度下降，移動平均線也和價位線以相同的角度平行下降，表示價位線和移動平均線正維持一定的乖離程度。

如果下降中的價位線價格突然急跌，價位線就會遠離移動平均線，但這種狀態一般不會持續太久。急跌總有一天會反彈，因此價位線又會朝移動平均線接近（圖表2-8）。

話雖如此，移動平均乖離率並不是一種容易運用的指標，因為沒人知道「離多遠後才會開始接近」。一般用來當成買賣信號時，多以10 %以上作為參考。也就是說當價位線在移動平均線下方，且偏離10 %以上時，就表示被超賣

## SECTION 2-8

## 葛蘭碧法則的 4 大賣出信號

### 關於賣出信號①

這個狀況與上一節買進信號①相反，是最典型的死亡交叉。移動平均線先呈上升趨勢，然後出現漲勢不再的跡象，在這兩大前提同時成立的情況下，位於移動平均線上方的價位線穿破移動平均線下跌時，就是賣出的最佳時機（圖表 2-9）。

葛蘭碧法則中，最重要的是上一節買進信號①的黃金交叉和這裡的死亡交叉，所以請務必牢記這兩點。

### 關於賣出信號②

這是上一節買進信號②的相反狀況。乍看之下容易以為是黃金交叉，其實不然。真正的黃金交叉，前提是移動平均線必須處於水平盤整，或是呈現上升跡象（參閱前面說明的買進信號①），再加上價位線必須從下方突破移動平均線往上升。

但在這個例子中，移動平均線依然呈現下降的走勢，而價位線卻向上突破移動平均線。這是下降走勢持續下的反彈點，不但不是買進時機，反而是賣出時機（圖表2-10）。

不過這和買進信號②說明的狀況一樣，在這種例子中，常常看到移動平均線和價位線交叉好幾次，最後趨於強勢，價格反彈向上。究竟是反彈賣出的時機，還是走勢轉捩點，其實不過毫釐之差，並不算是值得強勢出擊的局面。

### 關於賣出信號③

這是上一節買進信號③的相反狀況。

位於下跌趨勢時，價格一旦喪失下跌力道，價位線就會慢慢接近移動平均線。相反地，當價格跌勢強勁時，價位線和移動平均線的間隔就會越來越遠。

在下跌趨勢中，價位線和移動平均線的位置關係不會改變，只是兩條線的距離有時接近，有時拉遠，因此這個例子表示跌勢一度疲軟的行情再次開始下跌，可說是賣出的機會（圖表2-11）。

### 關於賣出信號④

這是上一節買進信號④的相反狀況。如果上升中的價位線價格突然急漲，價位線就會遠離移動平均線，但這種狀態一般不會持續太久，急漲總有一天會反轉，價位線因此又會朝移動平均線接近。

這和買進信號④一樣，是利用價格偏離移動平均線一定程度後，會朝移動平均線靠近（回歸平均）的特性，當成是買賣的信號。

這通常是相對於急漲的暫時回檔，所以並非大幅獲利的機會。話雖如此，如果在走勢的最終局面出現大幅偏離的現象，可能會形成天花板，後續則進入下跌走勢（圖表 2-12）。

## 為何短期均線加上中期均線，就能減少騙線的損失？

為了回歸葛蘭碧法則的基礎，上一節的說明是以現在的價位線和移動平均線的交叉為例，接下來要說明兩條移動平均線交叉的狀況。

首先，為什麼要用兩條移動平均線，而不是價位線和移動平均線呢？這是為了降低出現騙線的機率。

前面也提到過，移動平均線的功能之一，是讓價格波動平緩。換句話說，如果看的是價位線和20日均線，就會因為每天的價格變動而頻繁出現交叉（圖表2-13）。可是，如果用價格波動較為平緩的5日均線和20日均線，就能減少頻繁出現的交叉（騙線）（圖表2-14），也是使用兩條移動平均線的目的。

最近，如果提到黃金交叉和死亡交叉，大都是使用短期均線（例如5日均線）和中期均線（例如20日均線）來判斷，可見這麼做能減少騙線出現的效果，已經廣為人知。

就算以5日均線取代價位線，也不會改變黃金交叉和死亡交叉的概念和定義，仍然適用前面說明的葛蘭碧八大法則。

## 重點整理

+ 1. 移動平均線可以平均價格波動，讓波動較為平滑，更容易看清走勢。
+ 2. 運用分析指標時，最重要的是理解指標的計算根據，切記不用自己不理解的指標。
+ 3. 移動平均線的畫法是，每日計算某段固定期間內數字的平均後，將每日算出的數字連成一條線。
+ 4. 要使用什麼期間的移動平均線，端視自己的買賣期間，或者想買賣的期間而定。應配合自己的買賣風格，參考合適的移動平均線。
+ 5. 移動平均線最簡單的運用方法，是比較過去某段期間的平均買價（或平均賣價）和現在的價格。
+ 6. 掌握平均買價（或平均賣價），和現價比較，分析目前市場上投資人的損益狀況，就可以推測接下來容易出現哪種行情走勢。
+ 7. 現價和移動平均線（或是兩條移動平均線）的交會點，稱為「交叉點」。
+ 8. 交叉有兩種，一種是現價由下而上突破移動平均線，一種是現價由上而下穿過移動平均線。前者稱為「黃金交叉」，後者則稱為「死亡交叉」。
+ 9. 黃金交叉是投資人轉趨強勢的分岐點，而死亡交叉則是轉趨弱勢的分岐點。
+ 10. 只要觀察某日移動平均線的位置關係，就能看出過去至當日為止的走勢，以及當日的狀況。

## SECTION 3-1

## 如何使用移動平均線大循環分析，抓到買賣點？

第一章曾經提到，投資買賣要獲勝，最重要的不是預測未來，而是掌握現在的行情狀況，再朝有優勢的方向布局。

可判斷優勢的局面有很多，我最注重的是移動平均線大循環分析，利用三條移動平均線，明確定義出市場局面，分析漲跌強弱關係。

順帶一提，這種利用三條移動平均線分析市場行情的方法，過去就已經有許多人研究，並不是我的原創。我只是把這個方法整理成多數投資人容易理解的內容。

移動平均線大循環分析的優點，在於可以清晰看出優勢所在，而且找出優勢的方法也很簡單。此外，這種方法既可以套用在觀察日線、週線的長期投資，也可以運用在使用分時走勢圖的短線投資上。

有買方優勢的位置，是移動平均線的排列順序，由上而下依序為短期均線、中期均線、長期均線，且三條都呈左下右上的走勢。相反地，有賣方優勢的位置，則是移動平均線的排列順序，由下而上依序為短期均線、中期均線、長期均線，且三條都呈左上右下的走勢。當然，出現買方優勢時就要建立多頭部位，出現賣方優勢時則要建立空頭部位。

若實際以線圖來看，應該可以清楚看出行情的優勢（圖表3-1）。

## SECTION 3-2

## 如何看出市場或個股的趨勢正在上漲、下跌還是盤整？

三條移動平均線的排列方式只有六種，三條線（短期均線、中期均線、長期均線）的排序，有下列這些排列組合。

+ - 第一階段：短期均線、中期均線、長期均線。
+ - 第二階段：中期均線、短期均線、長期均線。
+ - 第三階段：中期均線、長期均線、短期均線。
+ - 第四階段：長期均線、中期均線、短期均線。
+ - 第五階段：長期均線、短期均線、中期均線。
+ - 第六階段：短期均線、長期均線、中期均線。

市場行情會由第一階段依序發展到第六階段，這也是移動平均線大循環分析的基本概念（圖表3-2）。此六階段都隱藏著代表行情現狀的訊息，訊息如下。

+ - 第一階段：穩定上漲。
+ - 第二階段：牛市終結。
+ - 第三階段：熊市入口。

第四階段：穩定下跌。

第五階段：熊市終結。

第六階段：牛市入口。

依時間順序來看，一般的移動順序是由第一階段開始，最後進入第六階段，稱為「順向」。

既然是「一般來說」，就表示有例外。例如，有時會從第一階段朝第六階段移動，稱為「逆向」。

不過逆向並不是常見現象。大致上來說，整體行情的發展有七成是順向，只有三成是逆向（圖表3-3）。

階段逆向表示大盤進入反轉點、反彈點或盤整局面，而且逆向不會持續太久。通常移動一到兩個階段後，就會再回到順向，例如：由第六階段進入第五階段、第四階段。因此進入逆向時，要想著「總有一天會回到順向」，並好好布局。

第二個重點是，不管是順向還是逆向，階段不會跳著來，一定是一個接著一個。以順向的狀況為例，第一階段後會是第二階段，逆向時第六階段後則是第五階段。從移動平均線的過程來看，線圖不會跳空移動，所以階段也不會突然亂序。

這也表示，只要知道現在處於哪個階段、是順向或是逆向，就能明確地看出下一個階段。
