# SECTION 2-3

# 大家如何用移動平均線，
推測未來走勢？

上一節曾經提到，移動平均線的第一個功能是讓價格波動變得平緩。至於把過去的數字平均後連成的線，到底有什麼意義？接下來就以20日均線為例來深入說明。

所謂的20日均線，是將包含當日在內的過去20日平均值標繪在當日位置上，將每日平均值連成一條線，可看出包含當日在內過去20日的平均值變化。

移動平均線最簡單的運用方法，是比較過去20日的平均值和今日價格。這麼做可以比較過去某段期間的平均買價（或平均賣價）和現在的價格。

假設某日價格高於20日均線時，代表過去20日買進的投資人有獲利（換句話說，放空的投資人應該有損失）。如果當日價格低於移動平均線，意思則相反。

假設今日的20日均值為1美元=110.50日圓，而今日的收盤價為1美元=111日圓，就表示過去20日買進美元的人平均獲利5角日圓，而賣出美元的人平均損失5角日圓。

此外，描繪移動平均線有助於看出趨勢變化，可以知道隨著時間經過的損益增減狀況。
