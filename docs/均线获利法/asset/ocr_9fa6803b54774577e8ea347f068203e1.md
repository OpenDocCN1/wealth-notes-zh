# 想避免越投資越窮，你得精準控制一次交易可承受的風險！

海龜投資法則列出一次買賣可承受的風險量，原則是「一次買賣可容許的最大損失，是可投資資金的1%」。舉例來說，可投資的資金為1000萬日圓，則一次買賣可容許的最大損失便是1000萬日圓的1%，也就是10萬日圓。

以此反推，針對自己買賣的標的，算出「一次買賣最大損失金額為10萬日圓，總部位應投入的資金」。總部位即是頭寸單位的概念。

計算頭寸單位時必須用到兩個數字：自己可用於投資的資金金額，以及ATR。
