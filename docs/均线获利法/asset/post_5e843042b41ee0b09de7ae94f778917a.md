# 推薦序一

# 與其埋頭研讀理論，不如起身練習打擊

作家、全職交易人 梁展嘉

多年的投資生涯當中，終日與數字糾纏，多少使我感到身心疲憊，因此閱讀各類書籍一直是我調劑人生，以及增廣見聞的重要法寶。我雖然看各種書，卻不太看投資相關的書籍。這是因為在十幾年前，我已經把台灣大部分的投資書籍看完了，目前只專注於實踐理論、微調自己的投資方法。不過，有時仍有一些優秀的投資新書吸引我的目光，例如本書《趨勢預測—哥教你均線獲利法》。

本書作者手塚宏二先生介紹的投資方法，以移動平均線為基礎，剛好與我在《一個全職交易人的投資告白》書中所述主張不謀而合。本書中提到的「移動平均線大循環分析」有兩大優點：其一是可以確實掌握住大行情，其二是方法一目瞭然，任何人都可以上手。這兩點正好符合大多數投資人的需要，假如有大走勢可以簡單獲利，誰還要在小走勢裡辛苦來回穿梭呢？

本書介紹的分析手法，是使用從短期到長期的三條移動平均線，來掌握市場趨勢，作者鼓勵大家盡量在趨勢最明顯的穩定上漲期與穩定下跌期中進行操作，正是適合投資入門者的穩健方法。對於尋求進階操作方式的讀者，作者則將既有的操作方式結合MACD的技術指標，輔助讀者找出提前進場和出場的時機，在穩健的基礎上設法再提高獲利率。這種做法我也曾在拙作中推薦讀者使用，不過本書的解說更加詳細與全面。

然而，如果缺乏嚴格的停損規則，再穩健的投資方法仍然可能以失敗收場，這一點請讀者務必留意。本書在資金管理方面也有所著墨，作者介紹的是一九八〇年代，知名的美國海龜投資團隊採用的部位控制方法。在此指導原則之下，投資人面臨的投資風險應能得到有效的控制。

綜觀本書內容，我在此毫無保留地向大家推薦，這確實是一本相當適合投資人入門的好書。不過作者在本書末尾也提醒大家，為了確實提高投資績效，「1000擊」的訓練是不可或缺的。所謂的1000擊，即是依作者的方法，並運用過去資料的線圖，實際練習一千次。讀完本書後，請各位讀者在正式投資前，起身開始練習打擊吧！

# 推薦序二

# 高深的技術，建立在紮實的基本功上

最有自知之明的操盤手 王力群

本書《趨勢預測—哥教你均線獲利法》是一本踏實的股市教科書，十分難得。

現在很多操作者一進入股票市場，往往抱持兩種不當的想法。第一種是「套公式」：幻想股市中有像統計指標一樣的數學方法，只要每天不停地循環照抄運作，就可以讓鈔票滾滾而來。

另外一種是：高喊「技術優先、技術第一、技術萬歲」，但是連最基本的技術都不會，更遑論心理素質與自我認知。

這本書有以下幾項優點：

第一個特色，也是讓我眼睛為之一亮的地方，是一開始便強調基本功，例如均線的「交叉」與「匯集」等。這些基本的东西必須反覆練習，才能有更深刻的體會；有了更深刻體會，才能够賺大錢。如此簡單的道理卻不受人重視，太多的人都幻想能找到一夜致富、快速暴賺的方法，或是以為不必花費太多精神與時間，就能學會「安全」的賺錢方法。

第二，內容由淺入深，從基本的線型交會技巧，再深入講到部位的建立。

第三，現在台灣的媒體為了賣書，常常使用誇大的詞彙誤導讀者，我覺得這股歪風太過強烈，但是這本書沒有這個缺點。本書有傳統日本人謹慎務實的作風，逐步帶領讀者進入平均線的認知領域，非常難得。

第四，圖表繪製十分清晰，並把重要的地方都清楚標示出來，文字部分的講解也相當詳細。

我想提醒各位讀者：技術分析在複雜的時候，應該要不怕繁瑣，不要好高騖遠只想馬上看到結論；而在應該巨觀的時候，不要小心眼、見樹不見林。一般讀者、甚至很多自以為是的高手，最難做到的就是這一點。

我的意思很簡單：當我們展開分析工作時，很可能面對的是一片迷霧，要小心謹慎地面對每一個細節，用科學的精神去深入分析。一個細微的疏忽，都可能造成整個交易的失敗。另一方面，一般人在分析過程即將結束，應該用大觀點來做總結時，卻把自己困在繁瑣的細節中難以跳脫。講究細節的精神在此時反而成為累贅，等於作繭自縛、變成小鼻子小眼睛，忽略了大格局。一般人難以拿捏這兩種態度的平衡，因此常常在股票市場裡感到左支右紐、矛盾叢生。

若是深入研究這種現象，會發現這是因為當初在學習時，沒有依照科學的精神一步一腳印踏實學習。關於移動平均線，坊間有太多我認為是「奇技淫巧」的魅惑之術，但是本書作者已經把重要的觀念與基本的精華，都先替你勾勒出來，如此一來，便能避免少走許多冤枉路。

學習技術分析，並不是只學習它的外表，最重要的是「不怕繁瑣，又不執著於細節的精神」。把握住精神，才有真實的成功。如果只注重外表的浮華絢麗，等於徒具形式，離失敗就不遠了。

我覺得現在社會處在一個虛偽的時代，太注重表面功夫，而忽略基本功。所以我樂於推薦這本書，希望大家從最基本的部分開始熟悉。千萬要記住：高深的技術建立在紮實的基本功夫上。

至於本書的缺點，在於有些市場（例如部分商品期貨）並不適合一般散戶進入操作，因為趨勢一旦反轉容易死得快，但作者忽略「一般散戶並非高手」的現實，各位讀者在這方面最好留心。

# 前言

# 只要掌握投資技巧，就能提早 10 年賺到千萬退休金！

大家好，我是投資教育講師手塚宏二。上課時學生都稱我為小次郎講師。

投資的重要性與日俱增，目前已經成為社會人士不可或缺的技能之一，政府也大力鼓吹國民「由儲蓄轉向投資」。

上一代人生活的年代很幸福，當時企業奉行終身雇用制，薪水會隨年資調漲，而且一定領得到退休金，退休後可以靠年金安穩度過餘生。在那樣的年代，當然沒必要冒險投資。然而，時代不一樣了。

上述條件在現代已經不復存在，而且平均壽命越來越長。活得久在過去是可喜可賀的事，但曾幾何時卻出現「長壽風險」的說法。對現代人而言，長壽反而是一種風險。很多人都有這樣的困擾：「我雖然有足夠的經濟能力可以活到△△歲，但是如果活得更久，就不知道該怎麼辦。」甚至還延伸出「老後破產」的說法，實在是可怕的時代。

要解決這個夢魘，只能仰賴投資的力量。在這個時代，不管你喜不喜歡，所有人都必須要懂得投資，利用投資來守護資產、增加財富，不學會這項技能，便無法安心度日。

話雖如此，在日本卻很少有正確的投資教育場所，投資人像是迷途羔羊。就算想投資，也不約如此，在日本卻很少有正確的投資教育場所，投資人像是迷途羔羊。就算想投資，也不 知該如何是好，想學習也不知要在哪學、學些什麼。日本是投資教育的落後國家，這是令人遺憾的事實。投資應該要列入國民義務教育當中，因此目前我正致力於改變現狀，為改善日本的投資環境略盡綿薄之力。

很多人問我小次郎講師這個別名是怎麼來的。

我長年浸淫在投資的世界中，親身體會到其好處與魅力，然而也看過許多投資人因為缺乏學習，貿然投入市場而失敗。

失敗並不是一件壞事。投資有賺有賠，即使是老手也會投資失敗。但最讓我感到遺憾的是，很多人落入的陷阱，其實只要經過學習就能避免，這樣的情況事實上占了絕大多數。

看著這種現狀，我一直認為：就像開車需要駕照，其實投資也需要執照，投資人要先考過執照再開始操作。假如真能有這樣的資格考，我希望能擔任這種考試衝刺班的老師。所以我取別名時，首先決定要加上「講師」兩字。

至於小次郎（Kojiro）的由來，一是它和我的本名「宏二（Kouji）」的發音類似，二則是來自「佐佐木小次郎」。

我把未經學習，就飛蛾撲火般投入投資世界的投資人，稱為「Muchashi（意指亂來，音近武藏Musashi）」，而這些人的對手就是小次郎。（譯註：取自日本戰國時代的劍術家佐佐木小次郎和宮本武藏在巖流島決鬥的知名故事。）

投資絕非易事，不經學習便難以如願獲利。然而，只要擁有正確的知識，就可以提高獲利的機率，而且要學會正確的知識其實並不困難。

本書適合投資初學者參考（第五章的大循環 MACD 對於中高階投資人也有幫助）。雖然我將這些投資技巧冠上「移動平均線大循環分析」等名稱，乍聽之下好像很難，但說穿了只是運用三條移動平均線來分析而已。

移動平均線簡稱均線，在股市極為出名，甚至有「技術線圖分析始於移動平均線，也終於移動平均線」的說法。只要運用三條移動平均線，就能輕鬆地找出「優勢」所在。

什麼是優勢？這裡指的是獲利機率較高的局面。市場上沒有所謂的絕對，但我相信：只要持續在獲利機率較高的局面投資，最終一定可以獲利。

有鑒於此，我寫了這本書，希望大家開始投資前，能先閱讀本書。書中內容雖然簡單，卻具有實踐性，是成為投資勝利組的捷徑。希望本書能幫更多投資人了解投資的魅力，真正學會如何投資。

執筆時我盡量深入淺出，不過對於完全沒有投資經驗的人來說，或許還是有難以理解的部分。請務必詳讀三次，我保證你的人生一定可以改變。

# SECTION 1-1

# 為何大家都喜歡，用技術線型來分析買賣點呢？

為什麼要投資呢？這是一個單純的問題，答案也很簡單：「為了增加資產。」這是唯一的答案，也是所有投資人的共同想法。

為了聰明投資以增加資產，於是衍生出基本面分析和技術分析兩種方法。不過，一般投資人要靠基本面分析和投資專家決勝負，確有難度，所以才要研究技術分析。技術分析的指標之一，就是本書要說明的移動平均線。

技術分析指標除移動平均線外，還有相對強弱指數（RSI）、指數平滑異同移動平均線（MACD）、一目均衡表、隨機震盪指標等，並沒有絕對正確或錯誤的指標。每種指標都有其原理。

此外，不論使用哪種手法，共通點是「用技術線圖分析行情現狀」。所謂技術線圖分析，分析現狀的重要性遠大於預測未來，這一點請讀者務必牢記在心。

分析現狀時，找出「有優勢的狀態」，就是技術線圖分析的基本原則。

在有優勢的時間點買賣，是交易的鐵則。說得再精確一點，在有效控制風險的前提下，只要遵守此鐵則，不論參考哪種指標買賣股票，獲勝機率都大於失敗機率。

到底什麼是優勢呢？買賣時的優勢指的是在持續波動的行情中，「買方明顯有利」或「賣方明顯有利」的局面。

行情不是漲就是跌，機率是五五波，而現價取決於買賣雙方的勢力平衡點。說得更簡單一點，因為現在看漲和看跌的人各占 50 %，所以價格才會維持在這個價格。因此「不論價格多高或多低，現階段價格上漲和下跌的機率各占五成」。

舉例來說，假設專業基金經理人分析某檔股票有 1300 日圓的價值。如果是真的，現在這檔個股應該會湧入買盤，將股價推升到接近 1300 點。所以不論誰怎麼說，現階段的價格就是該檔個股的股價，而接下來會漲還是會跌，機率都是五五波。

然而，另一方面也存在著現狀明顯對買方或賣方有利的局面。

前面提到買方與賣方的均衡決定了目前的價格，而價格變動就是買賣雙方拔河的結果。大家可以想成是人數和體格都五五波的兩隊人馬在拔河，A 隊用力一扯，B 隊又拉回去，於是中間點不停地一進一退。

可是一直這樣下去，總會有一隊在某個時間點失去平衡，於是被對手拉著跑。不過，失去平衡的這一隊也會找到重整旗鼓的時機，原本是勢均力敵的兩隊，有時候某一隊會獲勝，有時會輸；有時會連贏，有時也會連敗，或是很快又恢復勢均力敵的狀態。這就是市場中的價格變動。

買方有優勢，指的就是行情處於對買方有利的狀態，而賣方有優勢，指的就是行情處於對賣方有利的狀態，也可說是「略微失去平衡的狀態」。

不過請讀者注意，本書所謂的買方有利狀態或賣方有利狀態，不過是代表獲勝機率較高的狀態。就算是買方有優勢，

也就是說，優勢代表從原本五五波的狀態，變成六四波或七三波的狀態。即使投資者認為有優勢而出手布局，也有幾成的機率會朝反方向發展。

此外，從機率的角度來看，只要反覆在優勢時買賣數百次、數千次，最後整體約有六成、七成的機率會獲勝，即符合大數法則。

大數法則是機率論的用語，也就是母數越多越能反映出正確機率的想法。舉例來說，丟一顆骰子，出現1點的機率是六分之一，但並不表示丟六次骰子一定會出現一次1點，有時丟了十次、甚至是二十次都沒出現1點。如果丟一千次的話，結果會如何呢？出現1點的次數應該會接近一千次的六分之一。這就是大數法則。

因此，即使在優勢時買賣，次數少也不一定會獲勝。總而言之，必須在優勢買賣的意思是：反覆在優勢時買賣，最終獲勝的可能性較高。

# 移動平均線的優勢

第二章將詳細說明移動平均線。這條線之所以會成為買賣時的優勢，最主要的原因是「行情走勢會持續」的經驗法則。因此，建立符合走勢方向的部位，是獲勝的關鍵，而最容易了解行情走勢的技術指標，就是移動平均線。

移動平均線有許多活用方法，也有許多當成優勢活用的方法，如第二章將說明的黃金交叉和死亡交叉等。本書介紹的「移動平均線大循環分析」，則是綜合判斷移動平均線中各種能當作優勢活用的方法。詳細內容將於第三章起依序說明。
