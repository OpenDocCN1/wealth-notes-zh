# EMA 與 SMA 大比拚

# （三）

比較一下5日EMA和5日SMA的計算公式，我想更能了解EMA和SMA的差異。

5日SMA =（到昨日為止的4日平均×4＋今日價格） ÷ 5

5日EMA =（昨日的EMA×（5−1）＋今日價格×2） ÷（5＋1）

SMA是簡單算術平均，是將包含今日價格在內的5日價格合計，然後除以5日。

EMA則是把今日價格乘以2，加重今日價格的比例（圖表5-3），除以「5+1」是因為今日價格變成2倍。此外，首日的計算和SMA相同，第2日起就使用以上公式。

如此一來，價格占移動平均值的比重即如圖表5-4所示，越近的價格占比越高。因此EMA和SMA相比，前者對於價格波動的追隨性更佳，除了觸頂、打底的信號更早出現外，同時線條也更為平滑。
