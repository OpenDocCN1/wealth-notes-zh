# SECTION 2-4

# 什麼是黃金交叉與死亡交叉？

如同上一節說明，現價在移動平均線上還是線下，對於判斷行情走勢有很大的意義。一般把現價和移動平均線之間交會（位置關係產生變化）的點，稱為「交叉點」。 順帶一提，很多入門書籍上寫的交叉點是指短期均線和長期均線交會的位置，不過在葛蘭碧法則問世時，交叉點指的是現價和移動平均線的交會點。本書回歸基礎，從現價和移動平均線的交叉點開始說明。

交叉有兩種。一種是現價由下而上突破移動平均線，一種是由上而下穿過。前者稱為「黃金交叉」，後者則稱為「死亡交叉」。（圖表2-3）。

黃金交叉是之前平均虧損的買方損益翻紅的分歧點，死亡交叉則相反，是之前平均獲利的買方損益翻黑的分歧點。

換個立場來說，黃金交叉是之前平均獲利的賣方損益翻黑的分歧點，死亡交叉則相反，是之前平均虧損的賣方損益翻紅的分歧點。
