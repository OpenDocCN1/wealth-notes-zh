# 用信號線與 MACD 的走勢與相對關係，來看出行情的現狀

如本章開宗明義所示，MACD是表示12日EMA和26日EMA位置關係的曲線。

為了讓MACD的波動更容易了解，一般會追加一條信號線。所謂的信號線，指的是「MACD的9日EMA」。

為什麼這條表示兩條EMA線差距的MACD，還得再用EMA去分析呢？

用12日EMA減去26日EMA求出的MACD線，特徴是走勢會領先實際價位線（及其移動平均線）。因此，只要知道MACD本身的走勢是上漲還是下跌，便能明確掌握實際價格的走勢。

既然如此，應該怎麼做才好呢？要讓MACD本身的方向和觸頂反轉的時間點明確浮現，可以加入一條MACD的移動平均線，再看兩條線交織出的黃金交叉或死亡交叉即可。經過試誤的結果，發現最合適的是MACD的9日移動平均線（EMA），因此用這條線做為信號線（圖表5-5）。
