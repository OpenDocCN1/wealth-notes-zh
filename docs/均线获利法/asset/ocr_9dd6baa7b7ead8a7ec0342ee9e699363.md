# 重點整理

+   1. 不論使用哪種技術分析手法，共通點都是用技術線圖分析行情現狀。
2. 運用技術線圖時，分析現狀的重要性大於預測未來。
3. 在有優勢的時間點買賣，是交易的鐵則。優勢指的是在持續波動的行情中，「買方明顯有利」或「賣方明顯有利」的局面。
4. 優勢代表從原本五五波的狀態，變成六四波或七三波的狀態。即使投資者認為有優勢而出手布局，也有幾成的機率會朝反方向發展。
5. 反覆在優勢時買賣，最終獲勝的可能性較高。
6. 行情是多數決的結果，所以如果 Cic 只有自己知道的秘密優勢，沒有其他投資人追隨，通常無法在行情中發揮優勢的作用。
7. 建立符合走勢方向的部位，是買賣獲勝的關鍵，移動平均線是最容易了解行情走勢的技術指標。
