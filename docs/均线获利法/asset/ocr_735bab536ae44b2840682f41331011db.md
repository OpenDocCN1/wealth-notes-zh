# 用大循環 MACD 判斷賣出時間點，需符合哪些條件？

接著來看看賣出。正式布局、提早布局、試水溫的時間點，如圖表5-11所示。

鎖定移動平均線大循環分析第四階段下跌行情時，正式布局的條件如下：

+   ① 第三階段
② 三條 MACD 為左上右下

第三階段指的是短期 EMA 穿過狹長帶的狀態。如果此時三條 MACD 都是左上右下，幾乎就可確定接下來一定會進入第四階段。此外，從三條 MACD 都在下跌的情況，也可以判斷之後的下跌行情會持續一陣子。

接著是提早布局。在正式布局的階段前提早布局，可追求最大獲利。不過必須注意，因為布局時間早，也有遇到騙線的風險。
