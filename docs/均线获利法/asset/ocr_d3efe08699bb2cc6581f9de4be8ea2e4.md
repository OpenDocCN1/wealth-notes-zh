# 只要掌握投資技巧，就能提早 10 年賺到千萬退休金！

大家好，我是投資教育講師手塚宏二。上課時學生都稱我為小次郎講師。

投資的重要性與日俱增，目前已經成為社會人士不可或缺的技能之一，政府也大力鼓吹國民「由儲蓄轉向投資」。

上一代人生活的年代很幸福，當時企業奉行終身雇用制，薪水會隨年資調漲，而且一定領得到退休金，退休後可以靠年金安穩度過餘生。在那樣的年代，當然沒必要冒險投資。然而，時代不一樣了。

上述條件在現代已經不復存在，而且平均壽命越來越長。活得久在過去是可喜可賀的事，但曾幾何時卻出現「長壽風險」的說法。對現代人而言，長壽反而是一種風險。很多人都有這樣的困擾：「我雖然有足夠的經濟能力可以活到△△歲，但是如果活得更久，就不知道該怎麼辦。」甚至還延伸出「老後破產」的說法，實在是可怕的時代。

要解決這個夢魘，只能仰賴投資的力量。在這個時代，不管你喜不喜歡，所有人都必須要懂得投資，利用投資來守
