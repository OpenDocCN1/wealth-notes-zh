# 用大循環 MACD 判斷買進時間點，需符合哪些條件？

接下來，更進一步說明用大循環MACD掌握買賣時機的方法。正式布局、提早布局、試水溫的時間點，如圖表5-10所示。

鎖定移動平均線大循環分析中第一階段的上漲行情時，正式布局的條件如下：

+   ①第六階段
②三條MACD為左下右上

第六階段指的是短期EMA穿過狹長帶的狀態。若此時三條MACD都是左下右上，幾乎就可確定接下來一定會進入第一階段。此外，從三條MACD都上升的情況，也可以判斷之後的上漲行情會持續一陣子。
