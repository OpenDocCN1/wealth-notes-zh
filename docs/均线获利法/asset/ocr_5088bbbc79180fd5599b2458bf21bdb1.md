# 第三階段：熊市入口期

第二階段的狀態若再持續往下跌，短期均線會跌破長期均線，移動平均線由上而下的排列順序，會變成中期均線、長期均線、短期均線（圖表3-8），這就是熊市入口。

第一階段進場佈局的多頭部位，到這個階段就要全數出清，此外也要考慮提早佈局建立空頭部位的可能性。提早佈局和試水溫不同，是運用真正佈局時的部位數量，早一步進場佈局。雖然必須承受被騙的風險，但只要成功，就能享受到提早佈局的甜美果實。

不過，實際上要提早進場佈局，必須符合以下的條件：

+   第一階段持續一定期間。

+   階段變遷依序為第一、第二、第三階段。

+   短期均線和中期均線的走勢為左上右下，而長期均線的走勢趨近持平。
