# SECTION 5-8

# 如何用大循環 MACD，
提早看出市場即將進入下一階段的時機？

為了讓大家更容易了解，在此我們只用不含信號線和柱狀圖的單純MACD，再次說明大循環MACD和移動平均線大循環分析的關係。

請利用圖表5-9，來看大循環MACD和移動平均線大循環分析的關係。

圖中由上而下依序是5日EMA（短期均線）、20日EMA（中期均線）、40日EMA（長期均線），由第一階段開始。

首先是短期均線和中期均線出現死亡交叉，進入第二階段。此時可以看到MACD（上）由上而下穿過0的基準線。只要觀察MACD（上）的波動，就可以提早解讀進入第二階段的時機。

接著短期均線和長期均線出現死亡交叉，進入第三階段。此時可以看到MACD（中）由上而下穿過0的基準線。觀察MACD（中）的波動，便可以提早解讀進入第三階段的時機。

接下來中期均線和長期均線出現死亡交叉，進入第四階段。此時可以看到MACD（下）由上而下穿過0的基準線。
