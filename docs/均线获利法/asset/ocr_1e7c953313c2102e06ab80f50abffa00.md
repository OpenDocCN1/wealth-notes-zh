# SECTION 7-1

# 反覆實施5步驟，讓你成為股市達人！

說到練習投資，一般常見的作法是虛擬操盤，觀察目前的市場行情，假裝自己已投入資金，模擬「這裡要買進」、「這裡要賣出」、「賺了多少」、「賠了多少」等過程與結果。不過虛擬操盤有個很大的缺點，若不等到時間過去，不等到今天結束、明天、後天，就無法知道結果。

相對於此，我建議各位不妨使用過去的線圖做練習。由於是以過去的價格為基礎，所以可以在一天內練習操作一年或兩年的盤。

不論是投資或運動，都必須練習才會熟練、精進。正在閱讀本書的你，要如何才能成為穩定的勝利組投資人呢？我把所需步驟彙整在圖表7-1。

首先必須學習紮實的理論知識。本書目的是向讀者傳授必要知識，但不是學會本書所有內容，隔天就能成為勝利組投資人。

學習後的練習很重要。網球也好，高爾夫也好，知道理論上要這麼做，和實際上真的能這麼做，是兩碼子事。透過練習，才能將理論與實際串連起來。
