# 介 绍

距离意大利佛罗伦萨一小时车程的东部海岸上，坐落着比萨城，斐波那契就出生在这里，他是13世纪的数学家，主要为意大利皇室服务。他最著名的著作是《算数之书》（Libre Abaci）。当年他因为这部著作而获得的奖励等同于现在的诺贝尔奖。他为把罗马数字作为算术数使用作出很大贡献。在斐波那契之前，数字30被写作XXX，而在他的《算数之书》传播后，它被写成了“30”。

传说中把他去埃及的旅行描述成最伟大的发现之一——他去埃及学习蕴涵在金字塔中的数学关系。
