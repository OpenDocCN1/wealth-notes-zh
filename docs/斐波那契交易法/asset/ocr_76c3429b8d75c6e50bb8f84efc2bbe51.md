# 一些周期的实用技巧

第二个周期理论是关于名义性。周期通常以相同增量重复。例如，有一个 9 时段的周期 = 18 个时段*。有时它会持续 5 次以上的周期（5 个波段），但此后它就会变化。交易者可以从这个现象学到两个珍贵的经验教训。首先，一旦周期改变了，投资者应该开始寻找新的名义周期。其次，一旦发现一个名义周期，持续使用它直到它不再有效。这应该听起来非常简单。

对于周期的学习可以通过利用合理比例的原理来提高。如果你把任意一张股票或期货的价格图表看作一张路线图，那你需要做的仅仅是把所有的点连起来到达终点。下面这个图表就是我努力要表达的意思的简单化模型。
