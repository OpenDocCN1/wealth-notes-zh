# 正方形的对角线

( $ \sqrt{2} = 1.4142 $ )

正方形由四条互成直角的等长线段组成。

利用毕达哥拉斯定理我们可以计算出对角线的长度。这个斜边的长度始终保持着对任一正方形边长的比例（1.4142 : 1）。

边长为 1 的正方形的斜边是：$\sqrt{1^2+1^2}$ 或者 $\sqrt{2}$，即 1.414。

斜边和正方形任意一边的关系都是 1.4142 : 1。

![](bbox=[0.25, 0.43, 0.7, 0.71])
