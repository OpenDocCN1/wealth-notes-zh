# 浇音数和震荡数字

我在这本书的开篇引人有关浇音数和震荡数字的章节，目的是让读者开始思考价格的重复和波动。

拒绝和别人分享自己最宝贵的交易秘诀的心思，或许深藏在所有交易者心中。我也不例外。这一章你将学到的内容，是我所认为的技术分析最珍贵的秘藏之一。我所介绍的这些浇音数或者震荡数字，对于预测收益和止损特别有用。每一种商品期货、股票或者是投机工具都有自己独特的震荡数字。这很自然，就像每一个元素在周期表里都有自己的字母一样。专注于某一种投机工具的交易者一 直在使用这些数字。他们并不知道为什么，除了注意到这些数字一 天天在市场中重复之外。接下来的几页和一些图表将描述这些数字 并图解它们的用法。关于这一章必须指出的是：它可能是你作为交 易者所能运用的最有效的工具之一。
