# 2号模型

![](bbox=[0.13, 0.17, 0.88, 0.49])

+   1. A 到 B 的价差在 60% 的情况下与 CD 相等。剩下 40% 的情况下 CD 是 AB 的 1.27 或 1.618 倍。

+   2. BC 的价差将是 AB 的 0.618 或者 0.786 倍。在市场趋势非常强的情况下，BC 的价格波动只能到达 0.382 的撤回位。

+   3. 如果 AB 的价格波动非常强烈，它将对预测 BC 的走势给出很好的线索。

+   4. 从 A 到 B 的时间跨度在 60% 的情况下应该与 CD 的时间跨度相等。剩下 40% 的情况下这些时间跨度会扩展到 1.27 或者 1.618 倍的 AB 时间跨度。

+   5. 如果 CD 的价格走势有一个跳空价差或出现一根长线，交易者应该把这看作为市场动力极强的信号并且期望价格扩展到 1.27 或 1.618 倍。
