# 一，亚马逊OA是什么？和其他模式有什么不同？

这个内容我们手册里已经有更详细的解释了，一句话说就是去其他网购平台采购低价的产品，发货到第三方物流商检查，打包贴标后发到亚马逊仓库，然后上架跟卖平台上的现有有销量的同款品牌产品的链接（国内卖家链接除外，切记）。这里要补充的是，采购的平台非常多，不要限定于手册举例的Walmart，Target几个大平台。如果你试过一些选品工具，就知道上面有几百上千的网站供你去淘宝。
