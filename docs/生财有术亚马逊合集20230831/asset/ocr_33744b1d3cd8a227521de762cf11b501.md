+   分析和预判热卖图案，并二次创作图片（这个是重点，是出单的关键）；

+   使用分销平台合成产品详情图，写产品文案，批量上架产品；

+   出单后，订单导入分销平台，他们负责生产和发货，只需要去亚马逊后台填写物流单号即可。
