-细分人群的特定需求

-隐藏在各个角落，不出彩而不容易为发现

-大公司看不上，大公司要么做GMV，要么做流量，要么两者兼具。例如我前公司，原创飞机机模等做大GMV

# 二，实操细则

# （1）拆解条件：

-选有机会的品类，低成本，可塑性强且不容易被轻易模仿

-找细分人群的刚需

-低竞争，小产品，成本要低利润要高

# （2）可落地的实操步骤

定类目→熟悉材质→刷数据，找产品→挖掘细分需求→锁定单后细致调研→找本土人查询专利→原创设计→找供应链打板→确认样品后做大货→运到当地仓库→上架运营
