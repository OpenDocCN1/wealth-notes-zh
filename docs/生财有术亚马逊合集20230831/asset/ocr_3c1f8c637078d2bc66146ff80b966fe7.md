# 7.小包分拣配送

小包配送分拣及仓库打包的解决方案：可以找一些大学生兼职，你只要培训好其中一个能力比较强的，然后让那个人你带着其他几个大学生来做就可以，每个产品最好都要弄一个编码之类的，按照编码来弄可以防止打包打错的问题，毕竟自发货如果发错货还是很麻烦的，买家要退货基本就很亏了。
