+   1. 加速器项目优先招募现有账号的实

+   2. 卖家项目佣金7%（除平台佣金费，FBA仓储费/配送费，另外收取）【此费用暂未收取，未来的收取比例若有调整也会官方通知卖家】

+   9. 必须100%使用FBA。

+   10. 品牌店铺具有增长潜力的GMS表现，差异化的产品设计和优质的顾客评分。
