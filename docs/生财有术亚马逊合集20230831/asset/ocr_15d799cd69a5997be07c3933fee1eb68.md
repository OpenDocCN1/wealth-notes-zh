# 3-联系工厂开搞

4月，让合作方联系温州的工厂（之前合作过上百万个沙拉碗），算开模价格，塑料件温州工厂表示可以很轻松搞定。

重点在于里面的刀片，看起来简单，但涉及到的工艺有点复杂，全国只有广东阳江一个地方能做，他们有渠道能解决，评估出来开模费用5~7w左右。

工厂收到样品后也很看好这个产品，于是开模费用一人一半，产品量产后我们有前期的产能买断，和最低价拿货权（我们4元/套，其他人12元以上）。
