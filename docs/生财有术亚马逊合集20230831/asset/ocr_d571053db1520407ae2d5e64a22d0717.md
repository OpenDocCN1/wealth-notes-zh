我无意标榜刷单的正确性，这玩意的是确是不太好的，但是在对于推新来说，在你没有什么推广渠道、没什么运营手段的情况下，这不失为一个辅助工具。

说一下刷单用来干嘛：

+   1.刷销量（用于提升节点排名）；
2.刷关键词转化（用于提升关键词自然排名）
3.刷review和QA的数量（用于优化listing，增加关键词权重，以及客户信任感）
4.刷点赞review和QA（优化listing界面）

根据刷单的目的不同，所做需要测评人做的操作也不同。当然你也可以让你的测评人把这些事儿全给做了，毕竟你是金主爸爸。

注意，新品的review一定要好看，最好是文字+图片+视频的形式，增加信任感。
尽快增加review的数量到12个以上，QA的数量为20个以上。（注意留评率控制在50%以下，怕有风险就控制在30%以下）

有了4个评论的时候，就可以开自动广告，让广告多跑一点关键词，拓展一下流量领域。
有了12个评论的时候，就把手动广告开上。
每日优化。

新品的广告预算可以给到亚马逊推荐预算的120%-150%左右。（我一般会给的比较高，看个人）
