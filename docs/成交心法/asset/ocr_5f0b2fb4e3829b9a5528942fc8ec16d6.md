# 第五个步骤：

“那我们什么时候可以跟你的股东见下面？”

为什么这样问呢？

因为假如客户还有问题的话，跟股东见面也没用，他自己都不想买，他没问题的话就差要问股东了。

所以你己经排除所有的问题，就差股东的确认了，他很认可你的产品，所以你们的工作就是一起去见他的股东。

然后你再对他的股东做一次介绍跟说明，你不要期待他会回去帮你推销产品。

很多人搞不懂说。好吧，你回去问你的股东吧，你回去问你的家人吧，问完之后你再来买跟我买哦。
