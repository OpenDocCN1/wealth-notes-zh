# 一、销售要学内功

一个人在购买一件产品或选择跟你合作，这个过程就是内

心下决定的过程。

内心做了决定才会做出购买的行为，而为什么有的客户会

做决定购买，有的却决定不买？

这两种决定的不同其根本原因就是头脑的想法不同，客户

在做决定的时候会在内心思考，所以如果我们有方法能够预测

到客户的内心世界，了解客户头脑的想法，你觉得成交率是不

是会增加呢？

那要如何才能了解到客户的心理？

这个问题就是《成交心法》的精髓部分，客户做决定的十

大心理学步骤，当你学会这十大心理之后，你会了解到客户做

决定的奥秘，了解客户心理之后，再去对应在后面我会讲到的

成交的十大步骤具体去化解。十大心理和十大成交步骤是相辅

相成的。
