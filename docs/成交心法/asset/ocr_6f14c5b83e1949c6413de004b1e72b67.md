# “改变世界英雄会” —— 九鼎老师：医技有志者成大业

看他发的信息，和客户的对话，完全是敷衍了事，好像是做给九鼎老师看一样。

而那些业绩高的人写的文案，一看就是用心做的，图片跟文字配的非常好，整个文案行云流水，条理清晰，符合逻辑性，看见内容有画面感，故事讲的生动，有很强的购买欲望，九鼎老师看他和客户的对话，很明显能感觉到是在关心客户，为客户着想。
