销售的最高境界是忘记了自己是销售，别人也不认为你是销售，你可以是朋友，是老师，是顾问，是专家，是任何身份，而不是销售。

所以学过九鼎老师《万能成交》的人都知道，在课程上面九鼎老师有讲到什么“无痕成交大法”，也就是你的成交能让人感觉到没有痕迹，客户主动交钱给你。

通常学过九鼎老师《万能成交》现场课程十遍以上的人，就可以达到这种出神入化的境界。

其实世界上是没有销售这个职业的。

+   企业家是销售，他要推销企业的形象；

+   领导者是销售，他要让属下意见统一；

+   谈恋爱是销售，商品就是你自己；

+   父母是销售，要卖给孩子正确的生活方式；

+   老师是销售，要卖给孩子知识和世界观。
