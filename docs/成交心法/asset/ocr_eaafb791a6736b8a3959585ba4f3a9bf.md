# 4、完美型

# **客户特点:**

追求完美，注重细节，爱挑毛病。

# **客户表现:**

完美型的客户最大的需求就是精确，有条理、做事情要有 个圆满的结果。重视专业的循规蹈矩。

非常注重细节，喜欢追求完美。喜欢在产品或服务的细节 方面发现毛病和缺点，重视体验，并对销售人员采取苛刻、强 硬的态度，期待客服人员来解决这些问题。

这种类型的客户遇到一点不满就牢骚满腹，抱怨不已，非 常固执。此类客户，常常会为他能够当着销售人员的面或购物 现场发泄心中的牢骚抱怨而满足，其目的就是让推销者当场解 决他心中的结。

# **应对技巧:**

+   1、 作为销售人员：对待他们要认真细心，不可马虎，凡
