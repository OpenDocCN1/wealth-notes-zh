# “改变世界英雄会”——九鼎老师：医扶有志者成大业

但是九鼎老师说：“我的课程可以无限次复训，也就是说你不用担心一次学完学不会，以后你可以终身过来学习直到学会为止，并且你每次回来学都不用付学费，你可以无限次降低成本并且结交平台上长久的人脉，毕竟价格对你很重要是吗？”

“是。”
