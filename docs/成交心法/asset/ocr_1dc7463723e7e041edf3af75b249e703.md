# **销售就像追女孩耍，先利她**

一个陌生的女孩，她不认识你，你见到她之后，很渴望与她在一起。

如果你一开始就上去说：“嗨！美女，我太喜欢你了，我们结婚吧！”你得到的肯定会是一巴掌。

有经验的朋友都知道，第一次上去搭讪，都是简单的聊聊天，然后索取电话号码，方便下次约人出来聚餐或者方便你请她去喝杯咖啡。然后慢慢的大家熟悉之后，会约一些朋友出去游玩。不断地给予她关心和呵护，顺利的话会成为男女朋友，最后结婚。
