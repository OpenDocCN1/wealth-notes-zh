# 抗拒之八：我不感兴趣/我不需要

客户说不感兴趣，不需要，那是因为价值没有塑造到位，或者信任不够。

所以客户说不感兴趣是骗你的，或者你没有把产品介绍清楚，客户没听懂他就会说我不感兴趣，我不需要。

所以我们要找到客户有什么原因，有哪些还没听懂的。

+   1、"听到你说不感兴趣我很惊讶，因为我们的产品有这么多优点，而且这个产品是能帮助到你的，而你却不感兴趣。不过我敢肯定你不感兴趣一定是有道理的，你能给我说一下是为什么吗？"或者"你能给我说下你哪里还没懂得的吗？"这样问的目的是要找出客户真正的原因。

+   2、"你是说不需要是吗？在以前也有几个客户，他们刚开始也说不需要，但是后来使用我们的产品之后，他们非常的震惊，因为他们没有想到看似普通的产品功能却这么强大。自从他们购买这个产品使用之后，他们公司的业绩就提升
