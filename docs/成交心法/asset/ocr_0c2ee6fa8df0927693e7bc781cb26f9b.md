# 第三、客户对你还不够信任

比如有一天你要买一台相机，你去到一家店里面，营业员问你要买什么相机，于是你告诉他你要的相机，是什么品牌多少价位什么配置。

这时候营业员拿出一台相机，你看见这台相机非常符合你的需求，你对相机很满意，但是在跟营业员聊的时候，你问他一些问题，你觉得这个营业员态度实在是太差了，营业员问你，你要不要买，你说我再看看，你有遇到这种情况吗？

为什么你不想买呢？不是你对产品不满意，而是你对这个人不满意，问他两三句话他就感觉不耐烦，所以你不想跟他买了。

客户拒绝你说明你跟客户的信任程度不够，他不相信你这个人，你问他，他也不会直接告诉你我不相信你。

所以这个时候你就要表现的非常真诚去赢得客户的信任，或者你也可以直接问客户：“可见你对我还不够信任，你能告诉我，我要怎么做你才会相信我呢。”记住一定要真诚。
