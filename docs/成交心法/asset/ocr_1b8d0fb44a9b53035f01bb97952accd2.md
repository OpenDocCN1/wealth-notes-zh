# 3、免费法

我：“什么，2000 你都觉得贵？如果有一个免费产品你想不想要？

客：“想”

我：“要不这样，你先交 2000，这套产品你先拿回去用，如果你用完之后，要是感觉没效果对你真的是没有帮助，我自己私人掏腰包我把 2000 退给你，如果你要把我当朋友你就相信我一次，这套产品绝对会令你震撼的，你觉得这样好不好？”

这套方法针对熟客或者朋友，语气要坚定，让客户相信你。
