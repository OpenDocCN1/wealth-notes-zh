# ## 化解抗拒要学习

在过去九鼎老师培训过很多人，九鼎老师发现很可悲的是，大部分的人明明知道化解客户抗拒很重要，但是真正用心去研究如何去化解客户抗拒的人很少很少。

大部分的人每天几乎是被客户同样的问题给难倒，这一次不会解答，下一次遇到同样的问题还是不会。

所以这就是无数人变普通的原因。
