# 第一阶段：自我满足

# 一、客户真的没有问题

什么叫自我满足？

在我们面对客户的时候，你有没有发现有的一些客户，他们的心理认为他们的生活都很好，各方面都不错，他们没有任何的问题，你从客户的身上看不出他有任何的需要。

比如一个人跑到沙漠里面想要卖游艇，不管这个人怎么说他的游艇有多好有棒，但是没有用，因为那里的人根本不需要，也没有理由需要，因为他们真的没有问题，他们对游艇就是处在自我满足阶段。
