# “改变世界英雄会”——九鼎老师：医扶有志者成大业

创始人不在了，企业依然能成为世界500第一名？

因为沃尔玛的创始人山姆沃尔顿当时看到很多老板姓买菜不方便，买日用品不方便，要跑到很远的地方买，还要跑几家，于是他想能不能把所有的商品全部都集合在一起，让老百姓用最优惠的价格最方便的方式买到东西。
