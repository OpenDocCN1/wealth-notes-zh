# 3、为结果做准备

很多人都没有目标感，没有结果思维，在过去我给企业训
练销售团队，讲到激发潜能课程的时候，第一课就是要让员工
学会结果思维。

很多销售人员看起来天天出去拜访客户很辛苦，可是一到
结算薪水的时候却不能为企业带来业绩，他以为自己很努力，
大量的行动，公司就应该发工资给他。

实际上是，公司能发薪水给他是因为他创造的业绩里面
提成出来的，如果一个销售人员没有销售业绩，每个月还拿着
公司的底薪，这种员工就是公司的负债。

所以你就知道培训有重要了，一个企业最大的成本就是没
有接受正确训练的人，天天拿着你的薪水在得罪你的客户，损
失业绩，赶跑客户，本来会买的不买，因为没有系统的接受正
确训练，没有方法，也不知道该怎么做。

所以训练员工有一个非常重要的观念就是结果思维，要为
企业创造结果，在《21天改变命运》音频课程里面会讲的更详
更勾魂、更完整的成交绝学，尽在《万能成交》课程
