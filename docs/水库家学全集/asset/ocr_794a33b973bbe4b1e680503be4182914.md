# 05

暑假怎么过？给非毕业班的家长。

暑假马上来了。优等生和差生的区别，基本就是寒暑假拉开的。差学生的寒暑假就是看电视，玩手机。好学生的寒暑假是黄金90天。

一是课前准备。现在的老师上课，就是稀里糊涂走一遍。他说完了，就默认你学会了。不管是什么档次的学校，都是这样的。事实上，娃没学会。如果你娃是没有准备的去听课，能够理解一半已经很好了。

二是课后总结。你要把课堂上的内容，一点一点过一遍，确保没有遗漏。

娃平时这么忙，哪有时间折腾？这就看寒暑假的功夫了。你在寒暑假里，要把下个学期的课程，基本捞一遍，有个感性认识。上课的时候，你就听的比较清晰了。这叫带着问题去听课。事半功倍。如果还有不懂的，下课自己立刻去问一下，老师也会很高兴，简单给你讲一下。

寒暑假的作用，不是看电视，而是踏踏实实，提前准备下一学期的课程。如果是初二高二，那就开始把以前的高考中考题拿出来看看，这个比较有用。

高考中考的真题，虽然不可能再考原题了，但是，题目里内在的知识点非常有用，题目整体质量奇高，非常值得研究。

当然，娃肯定不愿意。我采取的办法是威逼利诱。

一是威逼。不听话，就要挨揍了。

二是利诱。“娃啊，想不想去游戏厅？想不想吃个好吃的？想不想买个好东西？你只要完成任务了，咱就去买！”
