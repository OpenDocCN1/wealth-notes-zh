# # 找老婆不能只看脸。

财上海微博 2020-09-29

01

## 一步到位。

莱莱，我是来自美丽的 山脚下，今年21岁了。在内环线餐饮店打工。以前是传菜员，现在是收银员，这是我们店里最好的岗位了。我也知道，你们这些本地人有点瞧不起我们。但是我们也是辛辛苦苦的劳动吃饭。

最近，有个大娘给我介绍了他儿子，36岁未婚，差距15岁。他们家原来住大桥附近，也没有多余的婚房，所以儿子年轻时将就就耽误了，但是据说马上拆了，有两套，他们选择松江南。

我的意思是，郊区找工作不方便，希望婚后再置换到虹口。你觉德如何？

答：你是聪明人，说几点一般人不注意的点。

+   1，置换相当于，婚前个人财产变婚后共同财产，避免了加名字的尴尬。千万不要提前暴露火力。老太婆敏感的很。

+   2，安置房有三年禁售期。也就是说，你真要这么做是四五年后的事情了。

+   3，和本地人结婚落户，需要同时满足，婚十年，满35。你还可以多看看。最晚到25岁左右下决心。

+   4，将军开拔，不逐小兔。你已经有明确的目标了，就要沉住气，平时装的云淡风轻，千万不要提什么彩礼。本地人不接受这个。反正以后你是一锅端，怕个球。

祝你生活愉快。
