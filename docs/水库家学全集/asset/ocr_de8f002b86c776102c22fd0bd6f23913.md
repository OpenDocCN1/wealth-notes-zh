# 01

答：这是老家父母没钱的意思，不要问了

# 02

女方要房子，实际上是一种社会筛选。

+   - 你家生儿子，二十八年了，从来没有考虑给儿子买房。这家人啥样子，大家心里明白。大概是几个原因，
- 一是真没钱。有很多人确实没钱。父母都是农民工，一辈子就攒了个村口大别墅。
- 二是鸡贼。房子要爹。
- 三是投资失败。炒股炒成了股东。
- 四是身体有病。确实没有劳动能力，可以理解。
- 五是懒。五十岁就退休打麻将了。一天一包烟，一瓶酒，开心色特了。
- 六是推给女方。我家儿子是大学生金凤凰，找你家女儿是吃亏了。丈母娘赶紧的去买房。
