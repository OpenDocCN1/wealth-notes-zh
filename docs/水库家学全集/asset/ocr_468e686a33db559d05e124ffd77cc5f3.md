# 爱到深处就倒贴！

做生意的感觉。

大家带入体验一下。

某年，我看好一个滑板车，投了五百万，毛利润是35%，如果有一辆卖不掉（成本100），相当于有三个白卖了（毛利润35）。

过程实在是太刺激了。我就每天等着发财，最后只卖掉55%，亏得一塌糊涂，在家里呜呜呜的哭。

事后，我研究了原因，我误以为，自己的喜好就是别人的喜好。实际上，我喜欢的，别人不一定喜欢。

我花了几百万得到一个结论：很多人自以为聪明。实际上，如果别人都按照自己的想法做事，我可能是聪明的，但实际上，绝大部分人和自己的想法是不一样的。我就成为SB了。
