# 03

能不能在法律上停止二手房买卖？

很多人在二手房获取了巨大利益。如果停止买卖，一了百了，就彻底铲除了二手房涨价的可能性。

这个不是异想天开。现实中，农村就这样。村里的二手房是不能买卖的，同一个乡镇农民之间可以，实际上微乎其微。大家都有宅基地，没人会买别人的二手房。

二手房不能买卖，就会波及新房。绝大多数人买新房是置换，卖掉二手房获得首付。如果二手房不能买卖，新房市场也就不存在了，农民工辛辛苦苦造好了房子，卖给谁？

如果新房不能增加，城市就不可能再增加外地人了，否则住在哪？

如果城市不能腾出房屋，对外出租，外地人怎么办？回老家也可以。

# 04

京沪广深楼市快速发展对农村大学生意义重大。

我们老上海都知道，小时候，有温州人来鸡毛换糖。但是，你知道那些挑担子的温州人晚上住哪里？没地方住，就是随便找个屋檐下睡一觉，不被野狗咬了，就算运气好。

现在的农村大学生来到京沪广深住哪里？出租房。大城市的出租房哪来的？就是老居民买了新房子，腾出来的。有的是卖掉，投资客买下来出租几十年，有的是没卖掉，出租几十年还贷款。

换个思路，如果老居民没有能力搬家，就没有老房子租给外地大学生了。所以，要确保大学生进城，必须有足够的出租房。大城市外来人口大概是四百万左右，居住需求大的一逼。

大城市楼市欣欣向荣，农村大学生才有机会进入大城市。否则，谁租给你？二本子不服了，“为什么单位不能给我发房子？”

这个问题，我以前也遇到过。我们找工作那时候，确实是单位发房子的，陆家嘴三室两厅，金鱼缸同小平房两间，白送，不要钱。但是，那时候外地人要想进一个发房子的单位，比登天还难。
