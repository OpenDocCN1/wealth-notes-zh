# 03

关于私人电梯。

有的房子可以安装，有的不行。因为电梯井是大项目，自己搞，会遇到各种管子，不太现实。我有一套房子，是毛坯还房，有电梯井，我安装了一个私人电梯，电梯这玩意不贵，十万出头，都是国产的。区别是原厂派人安装，还是本地发包安装。电梯不价钱，就是占地方。

私人电梯，我考虑了很久，最怕一个事情，如果孩子被关在里面，没有手机信号怎么办？

电梯最花钱的部分，你可能想不到，就是那个电梯门。这个门是国产的，上海郊区就有工厂，现在各大商场都用他们的。门出来，还有个电梯门框，一般是大理石加工的，比较费钱。如果是五层楼，电梯门和门框的成本比电梯本身还贵。

现在安装私人电梯已经很成熟了，只要有电梯井，就像是买个中央空调那么简单。

# 04

装修小知识。

装修材料现在不贵了，贵的是人工。举例，起一个小的隔断墙，砖头水泥不价钱，但是人工奇贵。人工包括，砖头水泥和废料的搬运。

再举例，花园材料不贵，贵的是挖土和背上。挖土挖掉五十万，是很正常的。很多小区的花园挖土是天价。算了，这一块普及意义不大。
