# 什么是浪漫？

女人都喜欢浪漫。但是上下五千年，没有一个人告诉你，什么是浪漫？以我多年的经验，简单解释一下，

不同的女人对浪漫的认识是不一样的。举例，你给一个屌丝女送一束688元的玫瑰花，人家不会觉得是浪漫，而是浪费。但是，如果你给一个喜欢花的白富美送一束花，怎么哒。

归纳起来就是一句话，缺啥补啥。如果女人缺钱，送个miniCooper，送个小房子，就是最好的浪漫。如果缺玫瑰，你就送个花。如果缺劳力，你就去做饭洗碗。想当年，我是那个惨，怎么做都不行，最后发现，菜婆居然好面子。我就告诉她，我以后会飞黄腾达的，就一把拿下了。从此，菜菜幸福的在城堡里躺平了。
