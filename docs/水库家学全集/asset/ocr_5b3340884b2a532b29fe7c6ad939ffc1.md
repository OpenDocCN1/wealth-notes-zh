# 01

（纯属虚构。如有雷同，概不负责）豪门恩怨。

最近，我周围出了一个狗血剧，是我听来的，不做数。有个男生，仗着老子有钱，婚前泡了个妞。那个小女人确实漂亮，而且是江湖儿女，对于弱鸡一样的富二代，简直是魔力十足。这小子和小姐姐一来二去，对上眼了。小伙子到了25岁，家里给他订了个亲，是个门当户对的白富美，小伙子立马同意了。但是，这个小姐姐，好巧不巧，这时候怀上了。

双方谈条件。女方老家来人的意思是，两千万育儿费，不给钱就闹婚礼。老爷子大怒，你要咋咋地。小姐姐也不是吃素的。真就开播了。第一阶段是在男方门口耍赖。因为怀孕了，也不好怎么样。小伙子婚礼就缓一缓了。然后，小姐姐就生了个儿子。这下子热闹啦。

男方定亲的女方家也是很有面子的土豪。男方不舍的黄了，就同意了育儿费。但是提出了两个条件，

一是女方必须回老家，双方彻底断干净，女方回去买套房装修好，避免大孙子遭罪。

二是二千万拿不出，签合同，分期付。第一年给3百万，必须用于买房首付。女方抓紧嫁人。

这两个条件看上去很平常，实际上暗藏杀机。主要是把女方赶回老家，别折腾。

这个傻女人可能还在期盼后面的千万。实际上没有了。因为老爷子就想把婚礼办了，你别来闹，婚后再闹，也没什
么了，大不了上法院。
