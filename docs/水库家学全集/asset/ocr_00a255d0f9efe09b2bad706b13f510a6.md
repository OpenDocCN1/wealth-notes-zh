# 寒门出贵子

寒门原来的意思是普通人家，现在是说/屌丝，我见过几个这样的。整体说，逆袭不过是神话故事，比例极小。

老王是我小时候的同学。这厮读书极好，可能实际水平比我还好。他们家很穷，他屋子里基本没有什么新的东西，就是一个很小的旧木床，一条很破很破的老棉被，灰突突的。他住在靠北窗的一个小屋，一天到晚在写作业，眼镜腿还用白色医用胶带卷了好几圈。他父母都是工资不高的普通双职工。

我影响最深的一个细节，我经常去敲他们家的玻璃窗。因为他永远在玻璃窗后面写作业。我遇到实在是不会的题，就会去问问他，他也不太喜欢搭理我。但我还是孜孜不倦的去求人。

高考那一年，他考上了福建东南大学建筑系，好像也是985。后来就没见过，偶尔听说了一些他的情况。他工作后，被派往某发达国家进修两年，读了个博士，趾高气昂的。再后来，找了个黑胖花。屌丝家里，一天到晚打架，他们家也这样。再后来，他当了一个很大的公司总经理，飞起一脚把黑胖花踢到垃圾桶了。今天你对我爱答不理，明天我让你高攀不起。

还有几个，基本差不多。我发现，屌丝逆袭对他老婆不是什么好事情。
