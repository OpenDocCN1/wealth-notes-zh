年入百万的外地男过什么日子？

前两年，我在海南度假，遇到过一对小夫妻，他们家的情况就是这样的。总结起来就是四个字，一笔屌逼。

男主是985毕业，好像是上海top2的理工男，在漕河泾上班，码农小头头，年入百万。女主比较漂亮，是外环线的穷村花。

+   1，女主不上班。男主每天加班，因为太疲劳，不敢开车，回来打车（可报销）。男主累成了狗，什么也做不了。女主孕后无法上班，长期操持家务。

+   2，买不起漂亮小区。现在漂亮小区基本是千万。首付要300以上，装修办证又是几十万，月供4万左右，他们家开支较大，拿不出400。实际情况是租在一个漂亮小区，每月一万多。为了求得心理平衡，在海南某个小县城买了个外地盘子盘。

+   3，根本不考虑孩子的发展。男主自信心爆棚，他的计划是，儿子18岁去美加澳新留学，以后在那边买房。他们退休后也搬过去。于是，他们带儿子苦练英语。说白了，就是把自己的压力转移到儿子身上了。

+   4，双方老人，水火不容。公婆认为，这儿子是我们培养的，女方是占便宜，吃闲饭的。女方的意思是，你这个乡下人，娶到大城市老婆应该很开心了，居然不买房，亏待我们家闺女了。双方老人互相不满意，基本不见面。
