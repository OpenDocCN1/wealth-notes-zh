# 如何快速找到富人扎堆的地方？

这和抓小龙虾是一个道理。你要仔细研究富人的爪爪印，思考他们一般会在哪里扎堆？比较多的是豪宅业主微信群，私立家长微信群，奢侈品交流会，私人银行讲座，豪车车友会等等。当然，还有一些扎堆的地方，但你不愿意去，例如野鸡MBA。

我曾经见过一个私人博物馆，这老兄喜欢收藏紫砂壶和购买优质茶叶，他一天到晚邀请各种土豪去免费参观。他的藏品在一个太湖别墅里，大门都是厚铁板，你要仔细看那些泥罐子，估计大半天。我也不太懂，就是走马观花。据他说，这些东西价值一个亿。我是不相信的。

看完了紫砂壶，品茶。大家一听说是一件元一斤的茶叶，都比比较好。内线走过来一百公里，来也来了，就坐下喝一次！又不要钱，一个下午就过去了。天黑就喝酒，菜品也不贵，太湖三白，太湖大闸蟹，管够。各种酒，应有尽有。那些一起来的年轻妇女，总有几个多才多艺，唱个歌，讲个笑话，手拿把稳的。

小孩子就在别墅区里玩一天，年轻妇女们就互相八卦，比比谁是正房，谁是野路子，谁是小鲜肉的是，谁是曹操故里的。还有雪茄吧，电影吧，水果吧，也不值钱，你随便玩。愉快的一天就这么过去了。

这些地方都是花钱的私立小聚会。但是，进入门槛比较高。那个紫砂壶老兄，是专门做IPO的。很多业务就在那里，提前几年打桩了。

因为要回城内线，一般女人不喝酒，回去的时候要当司机。如果你一个人来，一般会带个司机，司机们另外吃一桌，除了不喝酒，其他待遇都一样，司机也愿意来看着。我一般是鼓励司机带个娃过来。司机很高兴，认为我是帮他孩子开眼界。实际上，我是想，你的娃在车上，你开高速就会很谨慎，我也安全第一。
