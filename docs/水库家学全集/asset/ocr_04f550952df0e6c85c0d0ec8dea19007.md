# 半商半骗，防不胜防

我也被骗过很多钱。

我自认为很聪明，而且特别喜欢看骗子的伎俩，非常注意提高警惕。但这几年，我也被骗过好几次。人市间的骗术，无穷无尽，总有一款适合你。我就说一下我被骗的套路，熟人下黑手。

世界上的骗子，绝大多数是自学成才，走到那一步了。我有个熟人老王，原来是非常好的人，突然辞职，突然发大财了，激发了我的好奇心和攀附想法。于是我就被骗了。

老王把一个高风险的生意吹成很简单的事情。正常情况下我是不相信的。但是，老王这么多年的人格魅力四射，还有这么多有头有脸的朋友吹捧他，我觉得自己一个人可能被骗了，不可能这么多人也同时被骗了。导致我绝对相信他。他也是正儿八经的生产，销售，一天到晚接待客户，请了一大堆人发工资，我把可能的因素都琢磨了，实在是看不出来他哪里有什么情况像是骗子。完全是一个看上去非常正规生意。

实际上，这就是一个天天在赔钱的生意。但是老王锦衣玉食，宝马香车，有别墅有资产，完全看不出是亏损的企业。有个别时候老王有点小气，例如打个滴滴几千元，是我抢着付钱，老王也不还给我车费。我觉得是一个大老板勤俭持家的表现，很正常。我就想能不能也沾点光，就进套了。

老王的套路就是这个，谁想发财谁倒霉。有很多熟人自愿借钱给他。他就是靠别人主动送来的借钱维持场面，再
