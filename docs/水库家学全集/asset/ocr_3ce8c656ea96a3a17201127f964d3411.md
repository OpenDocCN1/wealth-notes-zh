# 男人为什么那么懒？

我是个中年大叔，现在发现自己懒得一塌糊涂，每天就想平躺，看看我最喜欢的抗日剧，特别是手撕特务的那种。菜婆一天到晚骂我，我也奇怪，我怎么能变成这个样子了？

我30岁之前，特别勤快。菜婆说想吃吃什么，我立马窜到南京路稻香村给她买。现在的我，连鸡饼头都不想去，就想平躺。前两天，菜婆说出去做个饭，我没搭理她。这两天，菜婆天天在家闹，跳的八丈高，像个好斗的母老虎，对我拳打脚踢。我很不得把她色色波波打一顿，一想到自己的地位，忍了。菜婆是我们家的一霸，什么事情都是她说了算，我就像个大型家具，负责蹲着。

实际上，不仅仅我这个样子，很多男的婚后十年，都是这样懒。我家隔壁那个女的，休息天带娃出去，她老公连开车都不愿意，觉得累。那个女的一天到晚和菜婆一起叽叽咕咕骂男人，看得我火冒三丈。

我以前也不是这样的，为什么现在这样了？我深刻反思了，觉得不是我的问题，而是自然规律，大叔老了。
