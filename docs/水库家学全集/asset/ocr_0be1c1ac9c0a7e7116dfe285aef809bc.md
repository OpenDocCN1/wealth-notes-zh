# 看了很多小资躺平的故事。

有一个点是不可回避的，生活怎么办？实际上，大部分躺平的小资，生活费是几个来源，

一是卖掉大城市房子回乡建房，产生了巨大的差价。一般有四五百万，爽死了。

二是以大城市房产租金过日子。很多城里人想回农村赚钱，无一例外的不可行。

三是大城市的存款。以前在大公司当码农，工资高，年入几十万，现在相当于提前退休了。

你只不过是花掉了以前在大城市攒下的子孙钱。以我的认知，农村人并不傻，也不懒，你能够想到的事情，他们都晓得。只不过不可行。你想不到，做不到的事情，他们也想到了，做到了。他们不赚钱，更多的原因是，真的没办法。村里还剩下几十个老头老太，基本不花钱，你说怎么赚钱？

装修是城里人的发明，但是，有几个城里人去做了？极罕见。最多就是去拉单子，交给农村人去做。我有个农村亲戚，脚有点残疾，六十年代的农村高中生，人非常聪明，但就是赚不到钱。后来，他没办法，买了个二手摩托车，在汽车站搭客。因为汽车站到农村家里，一般有好几里地，有客运需求。他应该赚了一点钱钱，但是这钱来的不容易。汽车站鱼龙混杂，纠纷不断，他个子小，力气小，经常吃亏，被人欺负，可怜人。

再举个例子，我那美丽的山脚下老家是以著名茶叶出名的，现在一斤茶叶大概是2-30元。但是，乡下的邻居们靠这个富裕了吗？几乎没有。有几个原因，

一是技术。任何农业都存在巨大的技术要求，并不是发个锄头去刨土那么简单。

二是人力。现在农村做点事情是很难的，最大的困难是，农村的事情往往需要临时劳动力，但是农村要想找几个劳动力已经很难很难了。举例，茶叶最大的麻烦是采摘，你上哪找几十个人采摘？万一摔一跤，你怎么赔？

三是规模。一家一户的小农经济，吃饱是可以的，但是你想赚钱是很难的。鱼米之乡是人均一亩半。干旱地区，偏远地区，人口少，人均十亩也有。但是，这个规模，很难有规模效益。机械化，规模太小。纯人力，我又太累。

四是销售。农产品有自己的特点。高价钱不好卖，30元一斤的有机大米，土豪是不会买的。因为没有信任感。1.2元一斤的稻谷，你个人很难销售，只能给粮站。

五是储存。现在，储存的费用是很贵的。

想来想去，还是大城市好，在小区里跑个快递也有七八千。

小结，没有几百万差价，躺平是不可能的。黑胖花会抡起黑拳，揍得你鸡飞狗跳。
