# 06

房贷压力有多久？四年。

很多人感觉房贷压力比较大。特别是新人。这是很正常的。我自己的体会，加上问了一些身边的人，绝大多数的体会是，到了第四年就后悔贷少了。买两房一厅的后悔没有买三房。买了联排的后悔没有买边套。各种各样的后悔，层出不穷。

为什么是第四年？这是大部分人的体验。

一是收入上去了，四年前，你家收入多少？只要是正经人家，现在应该有所增加了。

二是房价变化了。痛苦感小多了。

一正一反，你就不慌了。当年贷款八十万就是天大的事情了，现在八百万也没什么。
