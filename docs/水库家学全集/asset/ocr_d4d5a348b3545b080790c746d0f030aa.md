# 人生在世，无非是贪婪和恐惧。

财上海微博 2020-01-21

# 01

我们这一代985对孩子要求不高。

因为我们这一代人读书吃的苦太多了，很多人把身体读差了，大部分是近视眼，豆芽菜，小胖墩，月经不调的胖姑娘，我们熬出来了，什么都有了，不希望孩子们再走老路了，也要给二本子留点机会。

人生三大苦，撑船读书磨豆腐。我们在和平年代也算吃过苦了，现在也过得不错了，不能太贪心了。我们的下一代可以干点自己想干的事情了。我小时候最大的理想是天玩，做飞机轮船的模型，可惜没有实现。现在，我的孩子可以实现的了，心里感觉很高兴。年轻时，我看上了隔壁村的翠红，人家不要我。后来，我比她男人钱多，我心态也平衡了。

我现在最大的心愿是写一本家学。我的成长，离不开家里祖传的一些技能（例如倒插门），但是时代变化了，有些内容要修订，写好后留给几十年后的孙儿看看。

成功是一种付出，有少许运气的成分，但大部分是等价交换。亘古不变的是人心。我看着一百年前，老祖宗用毛笔字写的人心独白，和现在一模一样。如果你懂的人心，混社会就容易了。

人生在世，无非是贪婪和恐惧。

# 02

现在有个奇特的现象。好单位工资低，实际收入高的地方，大家都不去。例如贴资助，送快递远远比办公室老板竟收入高，但是大家不想去。

作为家长，怎么平衡这个关系？男方家里有房，或者女儿争取加名字，那么你家孩子可以去一个窗明几净的好单位，例如去大学当个老师，找个有编制的好窗口。
