# 如何创业成功？

我简单提示一下，抛砖引玉。提前三年做准备。

+   1. 提前进入。你要想清楚，你准备在什么行业创业，就深入到这个行业，成为行家。

+   2. 搭建团队。你可以有意识的结交一些能人，这些人是你的人才基础。

+   3. 资金来源。胆小的是合伙，胆大的是押房子。

+   4. 综合管理。例如会计，财务，人事，食堂，住宿，激励，目标。你要有个清晰的规划。

+   5. 吃进进销存。采购最好是老婆管。销售自己干。库房交给老丈人。

你要对公司大事小事，特别上心。因为这些事情，你以后也会遇到的。你就提前想怎么处理。
