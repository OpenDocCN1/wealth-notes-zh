苹果产品优缺点。优点，

+   1. 基本不坏。按照概率，肯定有坏的，但我十年没有遇到过，比空调质量好。

+   2. 没有恶意程序。台式机最恶心人的是，各种各样恶意软件，甚至一些知名企业的软件，无法删除。活生生把你逼成了格式化高手。苹果产品完全不存在这个顾虑。

+   3. 一般不会被恶意APP偷去个人资料。举例，现在很多APP是可以读取你的通讯录照片，打开摄像头话筒等，特别是安卓，苹果就很少了，因为苹果的APP是需要苹果公司审核的，不会让那些250胡来。

+   4. 花钱少。安卓基本上是一年一机，如果不买新的，基本不能用了。苹果是两年一机，三年一机。以年费的角度看，苹果比安卓便宜多了。

苹果的缺点：不防水。喇叭声音小。外设零件少。充电线容易坏。我买过很多次苹果线，特别是两米线，一般只能用一个月就坏了。
