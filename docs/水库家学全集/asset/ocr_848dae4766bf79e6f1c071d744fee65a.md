# 05

大生意往往就是几句话。

曾经有个老厂长，前些年创业几次都失败了，亏了不少钱，被老婆儿子媳妇骂成了猪头。四年前，我需要扩产，但又不想招人，于是我就和他说，你开厂吧，我给你单子。他就开干了，搞出来一个规模很大的厂。凭借给他的单子抵消了所有成本，他还接一些零零碎碎的小订单，那就是纯利润了，现在日子过得极爽。

后来我问他，你就不担心我说到没做到？他说，有钱人做事都是想了又想的，不会乱说的。我心里一惊，此人真是奇才，对人心的把握如此精确。

他现在的工厂规模是一两百个人，净利润大概有两百万一年。他主要负责质量控制，毕竟是老村长，质量合格率奇高，也该他发财。
