# **04**  
该不该找公婆要房子？

我以前也觉得，硬要不太好。最近，我听到了几家人的新故事，我的看法是，有就要，能要就要。

老年人手里有几百万现金，不是什么好事。十有八九出问题。老头子要享受人生，老太婆要折腾，还有去理财的。

前不久听到一个土豪家的八卦。儿媳想进门，没要求买房，将就现在的别墅过了。没想到，老太婆作妖，七八十岁了，买了几十万的包包和丝巾，在老年大学搞孔雀开屏。然后被理财专家盯上了，一口气搞掉320万。

好多人觉得320万也不多，实际上很多了，绝大部分家庭根本不可能有这么多钱。你总不能跨桥洞吧？

儿媳天天在家哭，意思是，原来以为，这些东西，以后都是自己的，没必要急于一时拿下，还可以留个好名声。没想到，公婆作怪，给她搞得干干净净。

儿媳说，除了是一些股权，家里现金也就几百万，被老太婆糟蹋完了，早知道如此，还不如当初名正言顺要房子。现在，有苦说不出。

还有陆陆续续的几家小八卦，大同小异。与此同时，儿媳黑着脸要财的家庭，基本没出大的破事。因为钱没了，老头老太也搞不出花样了。
