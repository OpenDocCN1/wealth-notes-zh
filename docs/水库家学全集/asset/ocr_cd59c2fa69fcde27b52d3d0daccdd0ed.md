我最后悔的买房经历。旅游地产。

海南县城，当时一个小套，总价100，现在新盘大概120-150。我已经三年没去了。前几年有一次去，我没住家里，而是住酒店的。因为不想打扫。

你可能不知道，海边的房子，如果三个月没人住，不要说三年了，房子里面是啥情况？基本就是一霉的一塌糊涂了。厨房霉了，厕所黑了，卧室门框裂了，阳台长草了。被单床垫，臭的一塌糊涂。到处是一块一块绿色霉斑。

我和菜娘一开始准备自己收拾一下，最后发现，有些修修补补不是我自己能做的。居家过日子，只要有一个电器坏了，你就很难过。逢年过节，根本找不到人。就放弃了。

+   1. 我后来找了个偏僻的酒店，一天五百元，花了1.2万，一个月不到。主要是陪孩子。

+   2. 实际上，酒店里不能做饭，周围也没有菜市场，我就天天吃饭店，三个人，一荤一素加个菜，一顿两三百左右。因为一天两顿，午餐和晚餐，一天大概是五六百。又去了1万多。饭菜质量较低，就是摆盘非常漂亮，像是艺术品。

+   3. 酒店附近没有交通工具，租了个车，我印象中好像是Polo，1万左右。看海不要钱，我基本没有买门票。

+   4. 还有买一些零食玩具，大概3-4千。

+   5. 改善生活的聚餐，一顿一千多。你自己看着办。我花了五千多。

+   6. 朋友聚会。我花了八千多。

+   7. 来回机票打车费，近1万。

那个春节大概是7万。虽然在承受范围内，也是个不小的数字。当然，你也可以精打细算，少花钱。

+   1. 天天挤公交车去买菜。我那里的公交车大概是半个小时一班。你就等吧。公交车不是直达目的地，再加上去半个小时走路。
