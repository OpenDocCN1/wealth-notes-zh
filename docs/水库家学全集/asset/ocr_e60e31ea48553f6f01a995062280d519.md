# 漂亮女人在想什么？

这两年，无意中接触了几个漂亮少妇，内环线的江湖儿女，一般是本科毕业，三十岁出头，千娇百媚，不化妆不出门，说话又好听。和她们的交谈中，感觉到了女人的很多无奈，给各位白衣骑士参考。

女人要漂亮，肯定需要大笔的钱。

一是买个房子，至少800万。首付三成，杂七杂八，要三百万。就算是租，一个月一两万吧。

二是买个车，80万打底，开个小破车，实在丢不起那个人。就算是贷款，一半首付。一个月也要一万多。

三是全套出门装备。30万要的。包包，鞋子，箱子，首饰，稍微牛逼一点，50万出头了。

四是日常开支。一个月两三万是丐帮了，美容美发，香薰按摩，衣食住行。

五是环球旅行，节约点，五十万吧，也可以玩现。

她们在呼唤B轮爸爸，但她们也没有什么职业技能。一看到微软积分就冒充七了，一说金融就打瞌睡，一唱K，就精神焕发，不要说什么搞个副高，她们就一个本事，漂漂亮亮混江湖。
