# 学区房会越来越好吗？我不看好。

学区房会越来越好吗？我不看好。

作为学生家长，我现在越来越感觉，孩子的考试成绩和学区房没有多少关系。什么样的家长看重学区房？无非是两种，

一是中产家长最来劲。原因以前分析过了，现在的中产是90年代和00年代初，高考的受益者。他们坚信一点，考上985，就有好单位，以后什么都可以解决。

二是土豪的新老婆要上升。很多人没有意识到这个复杂因素。略。

家长看重学区房，原因很简单。他们认为学区房可以提高娃娃的成绩。但我认为不可能。我自己是千军万马独木桥过来的，现在也有娃娃，我简单说一下学区房的事，

一是老师并不来劲。所谓的学区房都是社区学校，工资待遇是固定的。一个班级是40-45个娃。你让老师怎么办？

二是老师的法宝是压着家长持续大投入。我家是被压的很苦。压的方式，各种各样，有的刺激批评家长和娃，有的是心理折磨，有的是利用各种各样小奖励，引诱娃。家长们也有功利性，看到自己娃混得不好，就有点急了。

三是筛选。学区房的家长分为两种，城市老居民，新大学生。说白了，老居民没有花头，这么多年了，你家还在老破小里蹲着，可想而知了。新大学生有潜力。略。

说来说去一句话，学校名气大，并不能让娃成绩有多好，只不过是靠压家长而已。我身边已经有好几个重点学校的娃，出现成绩不好的事情了。他们是在一个名气很大的学区房，属于班级倒数8名，可能考不上50-60%录取率的高中。家长们对所谓的重点也绝望了，另辟蹊径，找了个高价值辅导班级，15-20万，冲刺一学期的那种。现在家长对所谓的学区房非常膈应。

成绩来源和学区房无关，更多的是家长和小朋友的时间投入。我相信，越来越多的家长会慢慢认识到这个问题。学区房的光环可能就就没有那么来劲了。很多人没有考过985，他们相信，学校名气大，娃娃成绩好。这是不可能的。

总得来说，没有学区房也没什么，你自己在家多鸡娃，效果也不错。高中就没有学区房了，你早点适应也好。
