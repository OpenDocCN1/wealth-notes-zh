# 幼儿园的学科兴趣班有用吗？

指语数外教育。

基本无用。上课的时候，老师也就是照本宣科讲一遍，部分课程就是外包给实习生，孩子们傻乎乎的听一次，老师认为我讲过了，你就应该会了，孩子们根本学不会。下一次测验，孩子们就傻眼了，老师就去找家长告状，用不了三个月，你家孩子就是脑子不好的典型。家长慌得一b。

怎么办呢？继续交钱呗。

实际上，问题不在孩子，而是家庭教育。我家孩子每次幼儿园语数外测验都是满分。因为我在家里已经提前教育了。幼儿园已经学会两年级的题目了，随你搞。老师就把我家孩子作为典型，你看财上海家的小宝宝，一学就会，你家孩子怎么学不会？不是我的不好，是你家孩子脑子不好。
