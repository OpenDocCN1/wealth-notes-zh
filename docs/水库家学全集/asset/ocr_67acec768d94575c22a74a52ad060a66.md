# 04

道听途说。

前两天，我在小区里溜达，发现一个老太婆在吹牛，我仔细听了一下，她说的事情是，大城市户口分为好几种，吧啦吧啦。周围有几个也是带娃的老头老太，如痴如醉，佩服的不要不要的，甚至还多次提问。老太婆也不客气，直接给他拍了板，你这个情况，可以办。

我听的目瞪口呆，但是我又想了一下，这些内容，老太婆好像也编不出来。我就研究哪里出错了。最后的研究结果是，老太婆把居住证误认为户口了。这下子就全部对上了。

结论：道听途说的事情，不一定是对的。如果你有这方面的需求，最好找正规途径问明白。
