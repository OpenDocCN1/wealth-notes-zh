# 现在的女人越来越难了。

什么招聘越来越难了？

做过企业的人，你会发现一个有趣的现象，招聘越来越难了，最踏实的是四十岁以上的人，年轻人基本不鸟你，特别是农村的年轻人。为什么？我也不知道为什么。我就说说我们家保姆的情况。

我家这么多年，前前后后招聘过n多的保姆，对她们子女的情况多多少少有一点了解，懒二代基本不想干辛苦班。主要原因，

一是不缺钱。现在年轻人，特别是农村年轻人，父母大概是45-50岁，是农民工收入最好的年纪。我家保姆和老伴，年入30，春节可以带回去25以上。在农业小县城绝对是人上人的档次了。

二是不缺房子。小县城，特别是中西部，前些年，房价大多数是五六千以下，150平米，也就80万，装修家电全套，前两年90万解决战斗了。首付一半，很多给得起。

三是大学生有面子。可能是扩招原因，这几年请的保姆，绝大多数家里儿子都是大学生。大学生就要讲究一下了。什么送外卖，贴瓷砖，敲钉子的活，我会去吗？不可能的。

四是日子舒服。我家以前有个保姆，儿子是大学生，二本子，住在小县城里，老婆（女票）是服装柜台营业员。两口有房有车有女人，车子是八万多的，房子是四室两厅大豪宅。你让他去工地拎灰桶？西开，不可能的。

五是考编制。你一个大男人，天天不上班，靠老头老太养活，也不符合乡里乡亲的想法。缺什么来什么！现在，有个阳光大道，叫做考编制。这个事情，简直是小县城的超级大红包。儿子牛b费奏抬出这个借口，老头老太没话讲了，出钱呗。实际上，老头老太也暗自叫好。6070后的打工仔，多少多少在大城市是受过气的。如果儿子拿下下一个正式编制，岂不是扬眉吐气？暗暗窃喜。

小结，懒二代没希望了。
