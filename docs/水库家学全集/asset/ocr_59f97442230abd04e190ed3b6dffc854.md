# 01
读书的目的不是为了读书

而是学以致用。我以前有个销售员，估计小学文化，只能看懂故事会。她原来是车间里的杂工，因为她老公是我的人事副经理（也是中学生）。经过他老公多次请求，我调她去做销售文员。说是文员，其实就是坐办公室，不用忙里忙外了，说白了就是给他老公帮个忙。

这个女人文化不高，实在是做不了什么事情。正好，有个活没人愿意干，就是数据整理。我就安排这个女人干。但是，需要用到Excel工具。大家可能会笑了，这破玩意谁不会啊？她就不会。于是，我安排会计小姑娘教了她几天。这个女人拼了命的练啊！一个星期后，加减乘除可以了。

因为她干活认真，做的表格大家都喜欢，表格没有什难度，就是需要认真。然后得到了大家的赞扬。因为工作认真，董事会特许，几年后，她已经成为了一个大区域的销售副总监，专门防止吃里扒外。

这个故事很有意义。人世间，绝大多数工作都是面对普通人的，技术不难，钱也多，但是，你为什么不赚钱？就一个原因，你不想认认真真干。时间长了，落后就大了。贴瓷砖，不需要抛头露面，就是累一点。你要是踏踏实实干上几年，你也发达了。

小结，我一个业绩考核的工作，认认真真干几年，别人离不开你了，你也会发达的。

# 02
如何突破天天的平庸？

你或许对现在的碌碌无为很不高兴，但是，你又没有办法。先说说，你可能想到的办法，

一是升职。这是最保险的，也是最搞笑的。你在退休前和那一群大专二本不会有什么大的区别，最多是有几个表扬，而且奖金只不过是五六百的小钱。你会感到，在单位里很有面子。但这只不过让同事们看你更加不爽。

二是副业。开面馆，开超市，投资一个朋友的公司！呵呵，你有啥本事，人家要分钱给你？

三是投资。你会什么，炒股？你拉倒吧。

那么，有没有什么办法，突破平庸。我也不知道有没有，说点体会。
