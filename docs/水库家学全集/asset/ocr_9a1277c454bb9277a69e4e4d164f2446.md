# （宝妈爸爸福利）中学数学二级结论。

（宝妈爸爸福利）中学数学二级结论。

中学数学考卷上各类型题，包括填空，选择题，小大题，大题，前几个题是简单题，基本是一级结论的覆盖范围，最后几个题是有难度的，基本都是二级结论的覆盖范围。只要熟练掌握二级结论，初中高中数学无忧了。

二级结论实际上是一种经验结论。中学数学书本上只会现出一级结论，这是成千上百的数学大师自文艺复兴以来的智慧结晶。但是，一级结论太直白了，班级中下游的二狗子也能掌握，那么，大考选拔人才的目的就很难达到了。

于是，有关部门要求命题组在大考卷里要出一些难题。但是，数学老师也很无奈，我们也不是科学家，就是当年的二本，自己也没多厉害，你让我怎么办？因为出难题怪题很容易考虑不周，形成错题或者无解题。到时候里外不是人。但你也不可能说，老子水平有限，没办法了。于是二级结论就粉墨登场了。二级结论是亘古不变的，久经考验的经验解法，绝对不可能出现无解错题。

高考大闸们就把二级结论乔装打扮一下，变出各种各样的花头，一举两得。一是出了难题，二是答案肯定对。可惜，这个办法害惨了学生。绝大部分学生是很难自己研究出二级结论的，于是，中学数学分数就很差了。宝妈气哭了，老娘寒窑苦守十八年，就换来你这个个不开窍的蠢货。宝爸垂头丧气的赔房子出去。实际上，只不过方法没掌握，损失巨大。
