# 为什么做生意发对比上班赚钱快？

不是每个人都有能力发财的。但做生意是发财的快速途径。做生意也是一天十个小时，上班也是一天十个小时。为什么区别这么大呢？

因为做生意是金融行为，有杠杆作用。举例，你做葱油饼很好吃，一小时也就是做几十个。一个赚一块钱，一小时赚30元最多了。如果你做生意，请二十个人给你干，分工配合，一小时可以做五百个葱油饼，你一个赚一块钱，一小时赚五百，杠杆就是几十倍。

当然，杠杆意味着风险。你的葱油饼要是卖不出去，劳动法就要逼你卖房子发工资了。

普通人能够接触到的唯一杠杆是房贷。贷款两三百万是普遍现象。一般的小老板做生意根本贷不到两三百万。你就偷着乐吧！
