# 如何看待行情？

有些大牛市，可以持续五十年，例如棒子国。人家从七十年代就飞了。册那，到现在还没有停一下的意思。

很多人看问题，是以农村妇女的角度看问题的，今年大葱这么贵了，明年是不是会降一点？已经贵了二十年了，能不能腰斩一次，让我捡个漏？这种分析方法，和农村妇女猜下雨，没什么区别。已经二十天没下雨了，说不定明天就下雨了，挖井多痛苦啊！赌一把，明天下雨。“小小心，开！”这就是一种简单的形而上学的思考方法。

某价格会不会有所发展变化？你先要分析问题的由来。造成这个问题的几大基础性因素，有没有变化？如果原因没有变化，你就不要指望结果会变化了。这就叫提前一步。

哲学的基本方法是，透过现象看本质！不要七想八想。

# 经济能不能预测？

我的观点是，细微方面不能预测，系统性方面是可以预测的。

# 一，小的

举例，明年猪肉价格是多少？这事情不容易猜。因为，这涉及到很多随机性的小事情。你家今天吃不吃饭香肉丝面，我很难提前一年预测，吃的人多了，价格就高了。经济学家天天在书房里写论文，真的无法猜测你的随机性决定。

猪肉的存栏量很容易猜测。现在养猪都是饲料喂养，只要在几个饲料大厂严格计算几年的出货量，基本可以搞清楚生猪存栏量升降比例。你经常可以看到生猪存栏量，这个数据，不是你去养殖场一头一头去数的，是用饲料量算的。现在，农村用剩菜剩饭和打猪草来喂猪的，已经非常罕见了。
