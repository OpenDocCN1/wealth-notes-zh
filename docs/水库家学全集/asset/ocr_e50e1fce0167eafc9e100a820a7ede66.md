# 02

什么样的生活比较惬意？四套一部。

钱多并不开心。我过了很多年的钱多日子，但很痛苦。举个例子，给你一个**一万块，让你站在悬崖边。一开始，你无所谓，这么多钱，我愿意。但时间长了，你就有点郁闷了，已经有这么多钱了，我万一摔下去怎么办？即使你不是自己往下跳，但是架不住风吹雨打的意外状况，你每分钟都会高度紧张。这时候，你就非常非常痛苦了。

有房有车，还有个不算恶心想人的工作，旱涝保收，就比较开心了。假设，张大户有一大三小，四套房，基本差不多了。大套自己住，楼上楼下，电灯电话，朝九晚五，牛肉土豆，很开心。三个小套就是工资。一般情况，房租是月入的三分之一左右。市中心有个小套就是月入五千。

但是，这里面又有矛盾。安稳上班的人是不可能搞成“四套一部”的，怎么办？那就是靠父母了。你加油。
