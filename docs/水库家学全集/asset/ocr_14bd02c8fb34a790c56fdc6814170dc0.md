# 为什么高职比二本好用？

企业需要人，但是找不到可用的人。现在的大学生基本没有实际工作能力。会计专业的学生不会用本票，电子系毕业生连个门铃都不会修。我也招聘过大学生，当时我没把他们当做大学生看待，而是把他们当做一个今后渐渐培养的普通人看待，只不过他们比较年轻而已，比老油条好管一点。

我在工作中发现，如果是一般工作，高职大专反而比本科生靠谱。因为本科生不安心具体工作，他们老想升职加薪，上班就拿著一本靠编制的参考书，等于找了一个吃饭拿零花钱的地方，还要背后嘲笑小老板。高职好像不能考编制，所以反而静下心来慢慢学点东西，做点工作。

今年，很多企业没什么钱了，估计招聘要收缩了。我建议大学生学一点真正的实用技术，减少小老板的成本压力。贴瓷砖吗？
