# 09

叠墅。

我没买过，但我有个朋友买过。大概说说交流参观体会。叠墅就是，1-2楼一家，3-4楼一家。

一是赠送面积。底墅有地下室，顶墅有阁楼。这两个是赠送面积，不上权证。

现在的地下室，采光通风越来越好了。可以做个书房，或者影音室。阁楼不算面积，是因为高度不够，大多数不满1.8米，而且是斜坡，利用率极低。需要防潮。

二是居住体验。叠墅确实不如联排或独栋。底户的，晚上睡觉，楼上有脚步声。顶户的感觉是没有花园，和别墅没有一毛线的联系。

三是地段不行。叠墅一般是在外环外，低密度小区。不太适合市中心上班的家庭。

也有优点，

一是漂亮。叠墅基本都是按照别墅区设计的，很漂亮。
