# 01

好事要办好。

刚才，菜嫂整了一大桌，给我安排早点。我心有感谢。过了一会儿，菜嫂说，没稀饭，你喝牛奶吧，我说，我想喝稀饭。菜嫂说，稀饭只有一点点点了，还要加热，你就喝牛奶吧。我坚持要喝稀饭。一下子把菜嫂惹怒了。然后，菜嫂劈头盖脸给我一顿骂。我也火大了，对骂回去。

你看看，老婆给老公准备了一大桌，原本是个好事情。因为一碗稀饭，最后撕破脸，互殴一场，我还吃亏了。所以嘛，女人要知道一个经验，

好事要办好。不仅仅是干活，还要让人高兴。现在有很多蠢女人，干活很辛苦，老公还不喜欢她，自找的。特别是像菜嫂这种250!
