# 08

不管不问，孩子有可能考上985吗？

很多家长以自己身边的例子说，自己或隔壁村的狗剩，父母也是不管的，怎么就考上985了？这种情况在以前是比较多的。我也是自己折腾出来的。但是，这里有个很麻烦的前提。以前，所有的家长都不管。孩子们自己长成什么样子就什么样子，听天由命。

现在完全不是这样了，现在好一点学校的家长，大概有一半是读过大专以上的，对考试有一定经验，也愿意抓。我读大学的时候，学生出身是那是五花八门。我有几个同级校友是湖北黄冈的农家子弟，那时候我们孤陋寡闻，不知道黄冈有多厉害，只是知道他们很认真。有个同学一家几个孩子，三女一儿，都是985。当然，现在也存在这种情况，谁家的娃娃，没人管，也考上清北了。

我司的技术员老王，三年前，儿子考上985了。大家都去祝贺。我就问了一下其他同事情况。同事们都说，老王三天两头加班。两口子也是中学文化的农村人，这孩子厉害，一直没人管，就自己争气。

然后，我又去找老王，问起此事。老王也无所谓了，就竹筒倒豆子。他们两口子确实也管不了孩子功课。但是，这不代表真的不管了。

一是孩子发愤图强。男孩子初二有一个爆发期，主要是数理化上来后，挤压了其他学科时间，如果没搞好，有可能各个科目一下子全部拉下了。老王儿子就是抓住了初二的爆发期，逆袭成功。

二是家庭支持力度大。为了孩子，他们把自己的房子租出去，租在学校门口，就是为了孩子，吃好睡好。

三是舍得花钱。只要是考试需要，不计代价。请家教，买习题册，上网课，只要想的出来就花钱。

这一切的前提是，内外因素结合，孩子爆发，家长给力，可遇不可求。

我的意思是，与其碰运气，等孩子爆发，不如打阵地战，家长也努力，一分一毫的争取。

一是从小培养良好的读书状态。家长天天陪着，练好基础。

二是提前卡位。我们现在都知道了，小三，初二，高一，是三个节点，你家就因势利导，提前准备。

三是做好保障。吃穿用满足。晚上写作业不要影响孩子，特别是不要两口子打架闹离婚。看电视刷手机，一律静音。

四是请教一些成功家长，套套经验。
