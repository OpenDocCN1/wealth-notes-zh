# 01

怎样拒绝借钱？

来借钱的人，一般都是精心准备了说辞，你的各种问题，全部在他的预料之中。

找你借钱的套路是这样的，他先编一个桥段，说一个优美凄惨的场景，如果你不借钱，等于断送了我一生的幸福。例如买房娶媳妇就差这个二十万了。工程收尾了，利润四百万，就差三十万工资款就可以一了百了。很多人在第一阶段，心理防线就崩溃了。

如果你借给，还有下文，我（我家）曾经对你（我家）有多好多好，你都不记得了。小时候，你家遇到了那个事情，我爸妈是怎么对你家的？

解决方案：没问题，我回家和老婆说一下，我给你打电话，脱身就走。然后把他的电话微信拉黑。

# 02

春节回老家系列。

Black&Castle：菜菜，数教亲戚或者亲戚家小孩传来上海找工作，希望要常住，如何拒绝？连睡客厅都可以。

答：直接拒绝，否则后患无穷。另外，今后回老家过年不要再吹牛逼了。你的每一次吹牛逼都是亲戚们吃大户的心理依据。你吹什么吹？
