# 06

中小企业的困难主要在哪里？

成本太高了，销售难，赚不到钱。

成本高，主要是人力资源部分，不仅仅是工资，而且赔偿也厉害。前不久遇到一个小老板，一年利润大概二十几万，有个员工上下班路上骑助动车摔了，就全部赔光了。

销售难，现在的消费者，捂紧口袋办大事，房贷养车医疗教育养老，基本就掏干净了口袋，民企能够做的也就是小商品，不是刚需，日子就难过了。销售难啊。

最头大的，这两个问题，小老板也无能为力，只能是听天由命了。
