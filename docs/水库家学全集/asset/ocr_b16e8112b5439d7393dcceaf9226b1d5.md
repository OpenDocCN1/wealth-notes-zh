# 京沪一般家庭对就业

已经有新要求了。

不仅仅是实现就业，而必须是“体面就业”。什么是体面就业？原来上海有大批的人是做工的，种地的，现在已经完全放下锄头和榔头，必须是电脑桌，键盘，联网，上班可以炒股，驾驶员也必须配电脑可以上网（美日其名开车查路线），否则就不舒服了。

京沪二本最喜欢带编制打卡岗位，五大行，垄断单位的营业厅。三校生，职高，也必须是大众民办公室，大单位办公室里的合同工，公司前台之类的。这么多年，我就没有见过一个上海人在物业公司做电工的。上海一般老破小家庭喜欢的工作是事业单位，公司财务，物业经理，接电话前台，跑腿的文秘，或者在事业单位混个办公桌，也不讲究编制了。最低要求也是干干净净的超市营业员，否则不来了。就是必须体面。
