# 学区房新思路

近年来，上海出现了两个神一般的学校，张江中学，七宝中学。碰巧的是，我对这两个学校都有点印象。张江中学和七宝中学，在20年前就是城乡结合部的一般中学，质量怎么样？我们心里都明白（不许笑）。为什么异军突起，如此多娇？原因很简单。

张江最著名的是张江软件园，码农集中区，七宝当年是浦西低价房集中地（有一号线地铁），大批的985家长在这两个地方买房，安家落户，形成了考二代聚集区。

这两个地方集中了大批的优质家长。他们的特点是，白领很多，且绝大多数是外地考官，才能够在上海就业安家买房。他们的成长经验就是考试，考考考。他们带来了全国各地最优秀的中高考经验，把这套行之有效的实战打法传授给了下一代，就捧出了两个耀眼的名校。

与此同时，传统名校光环太甚，已经被有钱有地位的家长和其他方方面影响，反而失去了“静下心来研究考试”的心态。学校很牛逼，这么多人来考入，私教高价，开心的不得了。生源也慢慢受影响了。不如以前那么牛逼了。

如果你不能进一个优质传统好学区，那也不要太担心了，你去白领家长爆棚的新房集中区域，那里的家长会再捧出一个名校。
