# 我这些年做了一件蠢事，给大家笑话一下。

财上海微博 2020-01-20

# 01

我已经接到第一个辞职报告了。

有个创工，年入二十万，想发财想疯了，要去创业。他以为，自己轻轻松松做点货卖一下，一年几十万纯利润肯定有，给老板被剥剥了，实在是不甘心，自己干比拿工资强多了。他老婆一劲的鼓掌叫好，希望单干。他们已经准备好了，去某个贫困地区租个场地，找几个250员工就可以了。

他这辈子完了。因为这两年可是销售十分差的年份，他要想在我这里轻轻松松生产，要投入大概150万设备，他这些钱基本就是打水漂了。

他已经想好了，等发了财，就把厂里的兄弟一起带去发财。这些小老板我见多了，就没有一个熬的过低迷期的。

# 02

创业最难的两件事情。一是拉单子，二是要账。

你在街上走一圈，任何一个生意都是对半毛利润，但每年都有大批的店铺倒闭，就是这个原因。价廉物美是不存在的，举个例子，现在配钥匙，一个八元，实际上毛坯件只要几分钱一毛钱。你少付钱，开心了，农民工就没钱赚了。你以为别人能高兴嘛？

由小及大，你开个厂子，如果物美价廉，你可能有点生意！但是做不长，因为现在保姆日薪几百元了，你看农民工会不会愿意做低价单子。

还有一种生意，很好做，就是垫资生意，例如去修个村口大路，垫资120万，三个月后你要去账就哭了，会计会告诉你，没钱，走吧！
