# 01

失败不是成功他妈。

做一个事业。要是失败了，有一万个可能性，任何一个小小的失误都可能导致全军覆没。失败者就算再反思，也只能想到那一个小小的失误。

要做成一个事业，必须是所有的选择题都做对了，这就难了。

结论，失败者没有什么值得骄傲的经验，他的失败，往往是源于一个万分之一的**小小失误**。我们要向成功者学习，观察他的一言一行，最好能够模拟他的思维过程。为什么这么多选择题，他都做对了，不能简单的用运气好来解释。

# 02

我为什么愿意聘请高价保姆？

我始终认为，今后经济的发展，大商品价格走势，取决于新人群，就是高收入农民工的集体判断。我对土豪太熟悉了，他们的思维已经定型了，都快走入了，没有什么新的变化了。而目前正在发生日新月异变化的是，底层新贵，就是高收入农民工。我就要近距离观察他们，研究他们。

我的前一个保姆，她老公是滴滴答疑司机，两口子月入2.5万。有个保姆，她兼职好几个，月入一万，她老公是废品回收的，月入1.6万，他儿子是送外卖，月入0.9万，儿媳是外地来的，中专，内环线民营医院护士，月入0.6-0.9万。

他们一家的特点完全符合我的研究方向，立即聘用了。农民工中的高收入人群，是农民工中的精英，他们在老乡中是头羊，他们的一举一动就是后面追随者的方向。他们买个大件，其他人会一窝蜂的冲上去买，砸锅卖铁也买，否则没面子。

通过他们的喜怒哀乐，他的占便宜吃亏，我学到了好多东西，特别是对今后的商业领域，有了比较明确的看法。你知道吗？一个农民工居然愿意给儿子聘请26万的亲京律师（儿子和几个老乡偷东西了），我是目瞪口呆。他们愿意给孙子买县城学区房。但是，他们不愿意进饭店，他们就喜欢在家做喜酒。
