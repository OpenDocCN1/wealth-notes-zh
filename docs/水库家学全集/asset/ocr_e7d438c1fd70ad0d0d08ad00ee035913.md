# 03

农民工家庭的儿子，应不应该留学？

我年轻时候，有个留学同学狗剩，他家是种包谷的，一笔吊粗。出去前，他妈给了他五百个美元，然后告诉他：“娃啊，家里没条件了，以后，你是死是活，就靠自己了。”这娃是全奖，接下来就是生活费的问题了。

山沟沟里的孩子，刚到国外读大学，哪有什么机会打工啊？他赚钱的对象就是他的同学。因为他已经放下面子了，很多女同学（包括亲戚）也可怜他，愿意让他赚钱。他很聪明，

+   1，代办业务。刚刚入学，需要办理各种各样的手续，包括借书卡，食堂，上网等等。这娃不辞辛劳，把各种各样的事情都提前搞清楚，然后一个一个通知其他同学，问要不代办？有很多土豪家的姑娘也不在乎小钱，就请他代办了。他第一步就赚了三个月生活费。

+   2，中转站。每个大学都有高年级的老乡。老乡有各种服务。我们那时候主要是，二手车（自行车），二手电器和书籍笔记，旅游和电话卡。他就做转手生意，把高年级的卡倒给新生。

+   3，打工。因为他和高年级的老乡熟悉，甚至是新生的首席话事人，所以，他经常接到各种高年级转过来的信息。他挑个好的活，就开始赚钱了。我印象中，他第一个工作是去烤鸡翅当小工，每天吃饭钱都省下来了。

这时候，他已经解决生活问题了。接下来就是要发展了。

+   4，找女友。时间很快到了第二年，下一批新生来了。他是忙前忙后的张罗，很快获得了女学生们的感激，一致赞美。有个中产姑娘，对他超级感兴趣，对他的努力过程充满佩服，于是，他就免费用上了。毕业前，和平分手，估计也用腻歪了。

+   5，结尾。因为打工挣钱，他留级好几次，2008年，他拖了几年的博士，终于毕业了，因为没有什么成果，成绩一般，实在是在找不到什么好工作，他就回老家地级市，找了个附近的大专教师岗。然后，在学校里找了个家里挺有钱的黑胖花，凑合过日子了。

客观讲，他实现了人生逆袭，从一个农村丝变成了海龟大学老师，还有老婆和陪嫁房子。他儿子起点就很高了。
