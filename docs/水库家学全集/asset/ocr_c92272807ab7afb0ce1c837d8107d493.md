做什么赚钱？

这是我天天被私信的经典话题。我简单答复一下，无论你做什么，都有赚钱和亏钱的，关键是你要先做起来，积极进入。贴瓷砖肯定赚钱吗？如果你是包工程，拿到钱，有可能老婆房子都输光了。所以，做什么不重要。重要的是几条，

+   一，做一个有希望的事

男怕入错行，女怕嫁错郎。实在没想法，就去内环线转转。

+   二，不断总结得失

你在做的过程中，肯定会有很多感悟。包括：判断，人事，财务，合作，友情，爱情。你也把这些东西用文字保留下来，以后尽可能不要再错误了。

+   三，做精品思维

举例，考会计证，一般两个月肯足够了。考cpa是3-5年。很多人想玩简单的。这是不对的。因为门槛太低，竞争者太多，赚不到钱。

+   四，善待配偶

每个人都会遇到彻底无助的时候，要有一个你绝对信任的人。配偶是最合适的人。

+   五，一边赶路，一边完善

很多人的思维是，我复习好了再参加考试。这是99%的人的状态。你不要这样，没有任何一件发财事情会让你完全准备好了，再发生的。

+   六，保持乐观

你一定会赢的！二本子愤怒了，你还是没设做什么！答：我已经说了十年了。这就是你我的差距。
