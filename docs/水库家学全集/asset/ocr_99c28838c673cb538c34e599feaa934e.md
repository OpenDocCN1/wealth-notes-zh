# 我为什么没有成为马爸爸？

我是1996年就接触到了互联网。当时，我思维跟不上，我把互联网看成电子报。那时候，一台电脑五六千，再加一个28.8k的猫，就可以上网了，相当于几平米的房子，看个报纸，简直是有毛病。网上啥也没有。打开一个网页要半个小时。我还去借了一本网址大全，就是一个电话号码本那么厚的大书，可惜没有鸟用。

电脑还可以打游戏，但是没有游戏机方便。我当时的观点是，电脑没用，我也就放弃了。后来，电脑可以中文了，我们实际上是吧电脑当做打字机看待的，我用过最早的wps，foxbase，excel，就是蓝色屏幕的那种。当时是作为一个技术炫耀的。

再后来，电脑有了搜索功能，我就搜索一些资料，帮助自己工作，基本上就是剪报合集的功能。你要查一个什么知识点，你就去搜索一下。

再后来，出现了网络购物，我们觉得不方便，甚至是骗人的。买个东西要等几个星期，作为大城市人，实在是不接受。所以，你会发现一个有趣的事情，互联网购物是在小地方发展起来的。大城市的人不感兴趣，也没有体会。我们当时最喜欢的是南京路，六百，啥都有，方便。

再后来，人家上市了，我去买婚房了。就此，天涯陌路。

小结，要用发展的眼光看待世界，不能就事论事。

# 02

你有没有想过一个问题，你给娃留点什么？

很多人不考虑这个问题。我在十年前就开始考虑了。我是屌丝出身，一路走来，泪眼朦胧。想来想去就一个原因，手里没有东西。

能够靠读书混到的东西，我都混到了。当时，一进入单位，我就痛苦了。我家是郊区的，在市中心没有一平米。单位里那些大专二本子，趾高气昂，混的风生水起。而我特别可怜，连个洗衣机都没有地方摆。当年我特别遭罪。

一是吃饭。没有厨房，我只能到处打游击。食堂混一顿，朋友那里混一顿，我也不是买不起小鲫鱼，就是没地方。同事们聚餐，都喜欢同情我，把吃剩下的鸡鸭鱼肉给我打包，我还要厚着脸皮说谢谢。我是top1啊。怎么就这么了？太惨
