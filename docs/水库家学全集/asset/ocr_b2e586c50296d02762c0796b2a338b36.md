# 09

男方婚前财产，女方加名字，有用吗？分为很多情况。

婚前加名字结婚，视为对女方的彩礼，有用。

加名字后不结婚，不存在对价，也拿不出巨额财产赠与的合法理由，大老婆（父母）可以索回。

婚后加名字，视为夫妻财产约定，有用。

结婚时间短，加名字后，外地女，穷女匆匆忙忙提离婚，一般只能得到极小利益。因为法官会认为一方骗房子，正义感油然而生。

当然，好多杠精会提出不同意见，不要理他，你说没用，那你就给我加一个，我看的高兴。

婚后，儿媳找婆婆要钱买房。婆婆的对策是写借条，儿子女儿一起签名。

当然，婚前没房子的家庭就不要研究了，有女人来谈就不错了。

# 10

我印象很深的一对情侣旧租客。

很多年前的租客，好客沙东，男的又高又帅，女的成漂亮。两个人都是银行上班的研究生，据说工资高。租了我的一个小房子，一个月四百元。没过几个月，我再去收房租发现，女的跑了，男的把爸妈接过来一起住，他们自己买了个小冰箱，退租的时候，一定要打七折卖给我。说他们回老家了，带不走了。

现在想想，如果他们当年咬牙坚持一下，二成首付，不限购不限贷，扛下一套，现在应该是成功人士了。

因为签合同是女的。我就打电话问对方，今后怎么处理？听了半天，大致意思是，双方是同学，没结婚，男方没钱买房子，已经散伙了。到期后不租了。

真是悲伤。这家人对一个几百元的小冰箱算的那么精，对儿子的婚事基本不考虑，啥人啊！

备注，二十年前，买房也是很困难的，基本上也是倾家荡产了。我父母存款一辈子也就十万块钱。不少钱是工资36元的时候存下来的。这些钱现在毛都不值了。
