# 01

你是人才吗？才你个头！

绝大多数二本有个蜜汁自恋，总觉得自己是人才。你以为人才是那么简单的？就你那货色，一副上下五千年都欠我的嘴脸，和人才有一毛钱关系吗？当然，你肯定不服了。那就说一下。

你家估计有十万块，你能不能在一年之内赚回来五十万？打工也行。只要一提钱，人才就憋屈了，怒了。因为你这个人才根本赚不到钱。臭屌丝急眼了。马勒戈壁，你算什么东西？好了，那就不谈钱了。说说考试。

你可能也是大学生，那我问问你，为什么没有考上985？二本急眼了，我曰你，哪壶不开提哪壶，你能不能说道点好话？好吧。你高考发挥失误，可以理解，那你这几年有几个正经论文？我估计没有。

论文和文凭都不行，那就说说你的颜值，有没有比傻根好一点？我估计差不多。人家傻根也好歹娶个好看的老婆，你怎么样？没有。

智商不行，情商不行，那么财商怎么样？也不行。屌丝的三大爱：“房子腰斩，股票翻倍，丈母娘不要彩礼”。就这水平，晚上喝水都找不到尿壶。

这时候，屌丝已经气爆了。

# 02

孩子要什么？

小时候，孩子最希望家长在考试方面给予最厉害的帮助。分数就是孩子的天。分数好的孩子，在学校里，走路都开心。

找工作了，孩子最希望家长有路子，你看小王，成绩还不如我，居然进了这么好的单位，凭什么啊？我不服！

工作了，孩子最希望家长有钱。找对象要钱，买房子要钱，请客玩耍也要钱，没钱的日子实在是难过。我当年没钱，只能倒插门，一想起来，就是老泪纵横。

我们当家长的怎么办？只能努力向前冲。
