# 饭菜票。

读过大专二本以上的同学，都见过饭菜票。大家去食堂买饭，为什么要用饭菜票？

一是融资。饭菜票的规则是先付钱买菜票，然后慢慢花钱。于是食堂就拿到现金去集贸市场采购了。

二是增发。饭菜票有没有上限？没有。只要你给钱，就可以换给你。我们以前读大学，国家给大学生有个伙食津贴，每个月几十元，我们从来没有看到现金，都是给一叠饭菜票就完了。那现金被谁拿走了？不知道。

饭菜票是个神奇的金融工具，相当于食堂可以印钞了。而且，饭菜票在大学附近可以当钱用，你去小杂货店买包烟，饭菜票也可以。

饭菜票在同学当中可以当钱用。你欠我几十块钱，就用饭菜票抵。

承包食堂的人，可能亏钱吗？后来，食堂大师博觉得饭菜票，还要印刷防伪损耗，很麻烦，索性就采取了电子饭菜

# 怎么占便宜？

我有个同学，2000年买房，没钱。当时一套房子是天价，要十万元。我们心里都认为房子是单位的责任，个人不应该花钱，要十万太不合理了，当时我们的工资也就一千元左右。凭什么啊！

这个同学各方面条件不好，找了个没有房子的外地老婆，迫不得已，必须买房子，自己出了两万，那是到处流眼泪，亲友那里乞讨借来的，贷款八万，一个月还贷637元左右（当时房贷利息很高）。苦不堪言。

后来，m2一把撸的爽大了，这套房子现在租出去是4200元每月。他收房租的卡就是还贷的卡，等于白捡了四五十万，人生走上巅峰。他和我说，内环线一套老破小，抵得上老家一套别墅，退休以后去九华山脚下追求诗和远方。
