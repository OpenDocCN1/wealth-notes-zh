# 08

我对自己的定位。

年轻时候，我也觉得我要做个什么大目标，后来发现，这事情不是你怎么样就怎么样的。现在，我也想明白了，就做一件事，给送打基础。房谈专家。

一，攒面积。基本上，一套好房子需要一家人花三十年的投入。你不想干，我也不想干，最后父子俩个在老破小里大眼瞪小眼。与其那样，我就放弃自己了，做铺路石。

二，攒分数。一个孩子要想在社会上确保混个中上水平，985是必不可少的。但是，985也不是那么容易的。初中以下，大概是四个班考上一个，高中是两个班考上一个。要从小抓紧。我就和那个中年妇女拼一下了。

三，攒经验。人生有很多挫折，如何处理好方方面面的事，谁也不会和你交底。只能是家长趟雷。

四是攒口碑。一个孩子，父母口碑是很重要的。我就自我约束，力争给娃一个交代。

五是攒身体。一个孩子，身体很重要。我和那个中年妇女，一天到晚就围着娃研究，多运动，多锻炼，吃的好，睡得好，住得好，就会长得好。

家族发展，总要有下一代人吃苦受罪，那就是我了。也没什么。
