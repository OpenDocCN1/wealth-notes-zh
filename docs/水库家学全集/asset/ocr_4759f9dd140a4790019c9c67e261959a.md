# 05

再谈学区房。我的观点是小学毫无意义，初中可以考虑。

小学教育看的是家长，和老师没啥关系。我家娃娃所在的小学，硬件一流，实际上没什么意义。一个老师面对四十个孩子，一人说一分钟就要40分钟了，你就别指望了。

大多数家长的心态是，交给学区房，我就轻松了。事实上，绝不可能。一个孩子成绩好不好，完全是家长的作用。菜嫂每天辅导孩子，长年累月，效果很好。有点家长因为工作忙不管孩子，基本就没希望了。

初中涉及到早恋，打架等一系列问题，学校好，相对破事少，也不完全。初中有个好一点的学校风气，作用是孩子不要学坏。至于初中的成绩，不要多想了，还是看家长。一道题讲三分钟，你家孩子不一定学会，全班四十个人，就是两个小时，我觉得你就不要想太多了。老师也好累。

如果你家老婆不是单位的明日之星，就算了，别折腾了，好好的把孩子管起来。孩子考上985，人生豁然开朗，比多多赚二十万有意义。

建议，把孩子推给学区房是懒惰的表现，效果不一定好。
