# 03

很多人不清楚请保姆意味着什么。

钟点工不算保姆，他们来一次，基本是150-200元。按小时算钱，节假日期翻倍。你不能说我请半个小时，反正至少要达到起订量。因为钟点工来来回回路上也不少时间了。

保姆是住家的，收入大概是相当于一个快递员，内环线8000比较多，如果是长期客户，6000也有。主要工作是做饭打扫卫生。老人小孩一般不管。但是，保姆现在也挑客户。

一是看活好不好。如果家里有半身不遂的病人，保姆不愿意来。

二是看生活条件。一般是独立房间，最好是独立卫生间。老公房是没人愿意去的。

三是吃的好。你家要是吃的扣扣搜搜，那就没人来了。海鲜大餐，涮羊肉小火锅，一个月总要安排一顿吧？

四是玩的好，一年五星级旅游总要有两次吧？

五是奖金。年底总要有点头意吧？

六是东家脾气好。保姆老公喜欢抽烟喝酒，顺你一点，你也不要想不开。

七是帮忙。如果你有路子，保姆也会针对性地托你帮忙。

八是休息。一般是做六休一。

九是保险。按照劳动法，保姆是不管社保的。一般家庭也没有渠道给他们管。你可以买商业保险，人身伤害那种，也不贵。

如果你家条件不好，保姆也不会当面说，她们会找个借口，例如老公起诉离婚了，父母住院了，老家拆迁了，辞职走人。实际上就是换一家。

总体而言，保姆的实际开支是工资再加2-3千的生活费。凡是有保姆的家庭，都是比较富裕的。
