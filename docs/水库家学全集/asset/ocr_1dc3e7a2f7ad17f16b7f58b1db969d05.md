# 小学一年级的数学

# 04

题目：有五个小朋友捉迷藏。已经捉到2个，还要捉几个？作为平时张牙舞爪的top1，这题我也做错了。

解题的关键是，你要抓除捉的那个人。五个人玩，1个捉，4个躲，已经抓到2个人。5-2-1=2。你往往反应不过来，要扣除那个捉的人。

这种题目是小学一年级的级别，实际上很恶心人。为什么要这样设计题目？因为，现在小学的学业压力越来越大了，不出一点难题，分不出上下左右。但是，这种题目会把小学生的意志力给击溃了，人为造成一个又一个的差生。这就是我们现在的尴尬。

考试的目的是筛选，是竞争，是很残酷的人生淘汰赛，你不要想简单了。考上985，丈母娘送三居，丈母娘如果没有三居室，你家女儿只能找二本子了。祝福大家！我草。

# 05

# 幸福的烦恼。

菜菜，我很痛苦。我是新杭州人，二本男，公司中层，虽然公司不大，今年32岁，初婚，不是倒插门，只不过随女方过而已。老婆35岁，大专妹，农村的，二婚无娃。女大三，抢金砖，我也不计较了。现在遇到一个棘手的问题，房子。婚前已经说好的，女方出房子，男家出酒席（六桌）。

我老婆有房子，楼上楼下，市区，欧式联排别墅，精装修，420平米，9个房间，7个厕所，4个厅。和老丈人丈母娘同住。这房子客观上讲，确实很好，大理石，带地暖，全套欧式沙发，水晶吊灯，丈母娘付钱的保姆三个。这房子是丈母娘买给老婆的婚前嫁妆，她上一次结婚就住这房子，因为这个破事，我越看越不高兴。

我家是临安隔壁市的，因为女方的原因，我们也没有大操大办，结婚在杭州办酒只有六桌，我已经好委屈了，现在又弄成这样。我是越想越气。凭什么啊？我还是头婚啊，我是受了多大委屈啊！

我的意思是，我们另外买一个房子。但是，今年生意不好，丈母娘拿不出大钱，只能赞助三百万。你也知道，在杭州这样的地方，三百万买不到什么好房子。

问，我该怎么办？

答：把你老婆微信给我，我去骂她，这个死女人真的耽误你了。另外，我的意思是，你也想开点，就当不知道算了。
