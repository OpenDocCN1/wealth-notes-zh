# 小地方到底好不好？

刚才，有个二本私信信我，说是回我们老家了，进了编制，小日子快乐得飞起来，上班几分钟路，中午可以回家睡一觉。大概意思是菜菜是250，只知道京沪广深。

我在小地方生活过，我对小地方太熟悉悉了。小地方如果进了编制，肯定是很开心的。这辈子不发愁了。逢年过节还要发一些鸡鸭鱼肉，夏天还发风油精和卫生巾，两百块钱的火锅吃的满嘴流油。早上还可以沿着主干道跑跑步。老婆要求也不高，首付三十万，小美白随便挑。

这里有个你无法说出来的苦衷，我替你说了。小县城的快乐是建立在你有大单位的基础上的。如果你不能保证下几代也有大单位正式编制，你的日子可能就不那么好过了。

我家附近有个卖卤菜的小伙子，原来是四川某大城市的。因为厂子不景气，自谋出路，做了一手非常好的盐帮菜，号称张飞牛肉。他们老家房子便宜，一平米三千左右，二手房更低，但是，他不得不出来，离乡背井。因为当地很难赚钱，同样是摆摊，当地生意不好。

与此同时，在一线城市，就业是很容易的。且不说三甲，老师，就是初二学历送快递，每月也有七八千。

结论：小地方有固定收入肯定舒服，但是你要保证下几代也有固定收入。小地方可没有那么多快递送的好岗位。

# 富人买房容易吗？也不容易。

所谓的富人，不是大佬，也就几个亿的老老板。简单说，一个土老板的流动资金是不多的。如果你有五个亿，有几百千万周转已经是上等条件了。

流动资金不是零花钱，是有严格用途的，包括购买原材料，发工资等，根本不可能移位他用。绝大部分土老板，也就是几个亿身价的老土帽，很难一下子拿出几百万现金。

与此同时，富人买房，一般会买中等偏上，简单说，大概600-900万居多，千万就很吃力了。
