# 03

富人圈里也互相说小话。

大部分富人和普通人也一样，互相喜欢看人笑话。最近，王二娘家不太平了，倒也不是男人劈腿，而是女儿闹翻天了。

王二娘是远近闻名的老富豪，看上去虽然抵扣搜搜，但小几个亿是有的。前两年，买了个房子，装修交给了女儿和上门女婿。前前后后花了700w，最后效果还不好。加上房子本身，2000w没了。她们家的主要分歧是，王二娘需要法式豪华版，女儿喜欢小清新，女婿喜欢面积大。但是，她们没有时间去折腾，就交给了女婿。女婿是孵蛋毕业的金凤凰，一下子拿到了700的预算，激动的。于是他便发挥了学霸的传统美德，和装修小队长斗智斗勇，每一样东西都反复比较价格。本来也是好事情，但是，金凤凰忘记了一个大的要点。装修要想省钱，不是在材料上便宜两百块，而是不能胡乱动结构。

王女婿，一直是住宿舍楼的，对面积有一种原始的渴望。他把所有套房里的罗密欧小阳台全部砸了，换成名牌塑钢门窗，扩大了室内面积，这就花了20万。又挖了个毫无意义的地下室，还要做防水。这一下就多出来两百万。然后，又买了很多花里胡哨五颜六色的大理石地板和名牌家具。前前后后花掉了700。

老丈人和丈母娘一看效果，气的破口大骂，让上门女婿滚。但是木已成舟，也没办法了。女儿一看男人受气了，跳起来骂回去，现在吵成一锅粥了。

于是，这个劲爆信息迅速在老板朋友圈流传开了。几个闲的无事的富太太们一天到晚吃瓜，到处八卦，追剧情。老扎劲额！作为同道中人，我是深深地同情王女婿。

小结，富人也有很多方面是无知的。最好做的生意就是赚富人的钱。
