# 心态炸了，闺蜜找了个比她大十几岁的老男人。

![](bbox=[0.48, 0.12, 0.52, 0.15])

老年人再婚。

五六十岁结婚，我见过几对。我说两个典型例子。

一是双方均有子女。这种婚姻比较麻烦，有利益冲突。双方都考虑亲生子女的利益。某体面女，年轻时喂老公没不了，含辛茹苦带娃，养大成人，一个女人非常不容易。退休后，也找了个大单位的普通退休男结婚。婚后直接AA。双方有点像喝妍头的感觉。偶尔住一起，大部分时间都各过各的。主要原因是房子。双方都是一套三居室，和子女共同居住。哪一方出新房，哪一方吃亏。

于是，双方各自带孙，周末去房开，这哪里像夫妻？因为没有共同生活，经济帐分开。有一次，老太婆住院，老头垫付了8500元。出院后，老头一直撒看老太婆要钱。老太婆气的直接和他打起来。后来双方觉得麻烦太多，又名义上离婚了，但是实际还是来往。

二是男方老光棍。这种情况比较清爽。举例，女方是金融行业优质单位的小头头，收入比较高。年轻时丧偶，一个人带娃。女方看上去还算年轻，就像是五十出头，也小有资产，价值一两千万元，全部给了儿子在内环线买房。一个女人能够积累这些东西也很不容易了，主要是几套老破小，买的时候价格也不贵，一套几十万吧。儿子还没有结婚，老太婆寂寞孤独，就找了个没钱的老光棍。老光棍是好单位的。结婚后，就搬过来和女方一起住了。

老光棍是大单位的，比较拎得清，就像伺候主任一样伺候那个女人，女人感到很幸福。现在，女方出房子，男方上交工资卡，干家务。女方挺满意。女方打算，等有了孙，老头也退休了，就一起到内环线带孙。老头无牵无挂，也同意。

没见过老姑娘结婚的。有钱男也不会找老太婆。王大叔49岁，离异，有两套房产（一套是父母遗产），价值1000万，工资一两万。当时有两个选择，一是隔壁单位的副高老姑娘45岁，一是31岁的离异村花。王大叔毫不犹豫的选择了村花。
