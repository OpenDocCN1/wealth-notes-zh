# 我不幸福，怎么办？

我就要让老婆孩子幸福。我这辈子的高光时刻大概是读大学的时候。那时候，我特别喜欢的事情就是，别个校徽在大街上溜达，而且就喜欢人多的商店车站，现在应该没有人这样了。大街上所有的人都会看我一眼，我是这条街最亮的崽子。

毕业后，按照本科待遇，进了一个单位，好日子就没了。那时候，大学不分档次，就只有本科或大专的区别。我和那些杭州西湖边上的大学生挤在一起评职称，心里可不高兴了，凭什么啊？老子高考比你多一大截了。最可气的是那些单位拆二代，简直把我们鄙视到了尘土里，给我们贴了个标签“那些没房子的大学生”。单位有什么活动，都不叫我们。理由是晚上没有食堂，耽误你们吃饭。

因为没有房子，穿的也不好，住的也不好，时不时感冒咳嗽。冬天洗衣服太冷，一偷懒，衣服就有味道，同事们，特别是老妈们把我们鄙视到了骨子里，三天两头敲打我们，要注意多洗衣服，都有味道了。

就这么悲催的混了几年，到了谈对象的年代，什么歪瓜裂枣女胖子都塞给我们，好像我们是打折的处理品。我看上一个姑娘，人家很不麻烦我。因为人家也没房子，两个无房户哪有什么好日子。没钱没房子没盼头，一天到晚在低矮潮湿的农民房里唉声叹气，实在是太痛苦了。

后来，菜妮把我从烂泥坑里捞出来了，洗洗干净发现，菜菜还不错，大眼睛，白皮肤，高瘦瘦瘦的，还不错。但这个中年妇女也很气人，三天两头对我顶指气使，好像我就没有地位一样，现在想想，还真的没地位。

虽然，我很痛苦，但我一定要让老婆孩子幸福。挨打不还手，挨骂不还嘴，小娃娃都欺负我。我忍了，谁叫我当年没房子呢？
