# 09

管理最大的难题：员工忽悠你。

+   1，销售不好了，销售经理和你说，要跑市场。实际上他是想出去玩一圈。

+   2，原材料涨价了，库房经理和你说，应该换一家供应商。实际上，他小舅子想接单。

+   3，生产进度太慢，是生产经理三天两头请假，但他告诉你，是设备不行，员工不愿意加班。能不能重新买设备，或者给员工发奖金。

这种事情特别多。一个老板不可能什么都懂，于是有人就忽悠你，实际上是花冤枉钱。忽悠你的人也不会难过，他们认为，老板一天到晚看看电脑就发财了，心里不高兴。为什么会出现这种情况？

因为员工和老板的利益不同。老板想的是快快快，多赚钱。员工想的是，你不给我加钱，我何必那么来劲？于是互相甩锅，最后不了了之。老板不管提出什么想法，员工都不感兴趣。这时候，某大屌丝跳起来了，“我有办法，搞股改，给管理层分股票。”这是典型的250。

一是股票不能兑现金，绝大多数人不感兴趣。

二是增加管理难度。如果有一个公司有十个八个小股东，这个公司的主营业务就是吵架。

三是不解决问题。就算给股票，也是空的。没什么人会为了这个毫无意义的口头好处，改变睡午觉的爱好，或者拿供应商好处的想法。

小老板的感受

很多小老板误以为，你一个月给人开八九千工资，这个人就要全身心的为公司服务，这简直是太二了。我跟你说个实际感受，年入30方管一年。年入50方管两年，年入80方管三年。就是说，他年入80万，可以保持3年的全身心的状态。

为什么呢？因为绝大多数人会在一年后认为，这些钱都是自已该得的。要不你继续加钱，要不我就舒服舒服。
