# 年轻人过的好坏不好

基本看父母。

年轻人主要是三件事情，考试，就业，结婚。最关键的是考试。读个什么大学，基本决定了后面两个事情。

有好多家长根本不知道怎么读书考试。所以，孩子也被教成了250。我娃在幼儿园有个熟悉的小朋友，父母是做小生意的，根本不懂读书。那个孩子非常聪明，结果被练废了。

父母也无所适从，毫无办法，眼睁睁看着孩子彻底沦为废材，从一个性格开朗活泼的好孩子，变成了一个唯唯诺诺，啥也不敢做的差生。

我家孩子，从小就是按照985的套路搞的，考试成绩遥遥领先，从一个普通孩子，一跃成为了幼儿园大班的年级学霸，自信心爆棚。

我曾经反复多次说过，孩子学习就两个事情，提前学习，反复刷题。

但是，大部分家长偷懒，坐不住，习惯性地把孩子送到一些乱七八糟的辅导班，那些班级里，孩子几十个，老师哪里管的过来？时间长了，也就废了。

考试不好，就业也麻烦。
