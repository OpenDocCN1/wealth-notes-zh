# 所有的朋友，最终都会离开。

财上海微博  2020-11-21

+   01

怎么走好生活每一步？抄作业。

绝大多数人在做出重要选择的时候，并不一定具备选择的能力和阅历。只有极少数有家学支持的精英才能混好。包括，

+   一是婚恋。你应该找一个什么样的人，实际上你自己不是很清楚。绝大多数人是随波逐流，年龄到了，遇到谁就谁。

+   二是定居。你啥没有，看了几个电视剧就想去大城市白手起家。基本不现实。你想到的，别人也想到，凭什么便宜你？

+   三是买房。好不容易三代人攒了个首付，怎么选？都没有经验。

+   四是教育。一个人再成功，子女不行，就是不成功。一个人再窝囊，子女考上985就翻身了。跳广场舞，老太婆都会多看你一眼，因为你有子女将来送钱。

这些选择题，简述题，一般是在你30岁左右就要拍板了。但是，你还没活明白，不知道怎么选。最优化的办法是，抄作业。你盯牢一个你基本认可的有本事的人，和他渐渐熟悉，看他怎么操作，你依样画葫芦，大差不差。

老王是我见过的最聪明的土老板。我和他认识二十年了。当年在批发市场一起创业的老熟人，现在就剩下他了。

+   一是买地。二十年前，买地很容易，因为看不到什么现成的利益，还要投入大资金。很多人不买。我买了几十亩，老王拿不准，就来说我的作业。现在，他买在我北面五亩，发的不要不要的。

+   二是买房。以前的土老板是不买房的。因为绝大多数人住厂里的贵宾房，有食堂老太婆打扫，送饭，很舒服。投入几十万买房装修，没必要。老王又来抄作业，现在几千万了。

+   三是剪免配，当时最疯狂的时候是20%以上，老王鸡冻的不行了，就来和我说话，我没理他。几年后，老王说，“幸亏你没理我，否则，我就完了。”当时他已经准备了两千万现金（一半是贷款）。

+   四是抓教育。我和他说，儿媳一定要找个有文化的。最后他儿子娶了一个985中文系的翠花，彩礼给了六万六，人娘家不要钱。相当于白捡了一个大闺女，现在老王的孙儿是小学四年级的全年级第一。一说到这个事情，老王就激动了，他们家八百年就没出过学霸，这下子捞到一个文曲星，兴奋大了。
