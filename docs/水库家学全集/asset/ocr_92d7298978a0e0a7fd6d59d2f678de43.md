# 01

未来的婆婆要怎么做？

如果美若天仙的你，是在城市里生了儿子的，你要看明白一件事情，如果你儿子不到985，你和你男人，就算多赚五百万，也不解决问题。我和菜嫂已经想好了，接下来，就是一心一意鸡娃。

我和菜嫂经常互殴。因为教育理念不同，经常发生家庭械斗。她拿拖鞋飞过来，我拿床垫接住。最后互抡王八拳结束，经常打的我鼻青脸肿。菜嫂下手太狠了，我以后不和她好了。

一个小伙子，考下985的实惠，要远远大于一套房。985，意味着可以进大单位。这是工资高，有面子的好事。接下来，就是找媳妇了。包邮区的丈母娘，看到你儿子有985大单位的光环，只要姑娘同意，基本就是送房子的节奏了。备注：低于130平的先不要，丢不起这个人，就这么硬气！

话又说回来，你家多一套普通婚房，单价也不怎么样，儿子就是个二本子，婆娘儿子就立马难过了。二本子意味着找工作可能有点难办。你家儿子的画像是，学历差，单位差，长得一般，也就比送外卖好一点。这就郁闷了，找老婆就要扣分了。

前不久，菜嫂的一个闺蜜准备辞职回家鸡娃。她闺蜜两口子都是有编制的，单位很有面子，一人一年二十七万，还有饭卡，三块钱吃饱，五块钱吃好的那种。但是，儿子一年级，数学考了七十几分，当妈的急眼了，这样下去可怎么办？当然，你可以说，男孩初中会逆袭，但是，你想过如果没有逆袭怎么办吗？这事情可不开玩笑。他们两口子都是单位人，没有什么可以继承的，既没有大房子，也没有大矿车，一切都要靠娃自己了。如果就混个招后的二本子，将来就难办的不要不要了。

我听后就，基本是赞同辞职的。菜嫂有点难以接受。前不久，一起吃了顿饭，有点悲壮的气氛，风萧萧兮易水寒，女壮士一去兮不复还的味道。其实这个现象不仅仅是我们，欧美也是的，如果是藤校毕业，进了大公司，基本是前途无量。如果进了州立二本，基本就是亚洲超市的收银员了。

小结，腰缠万贯下杭州，不如考上985。
