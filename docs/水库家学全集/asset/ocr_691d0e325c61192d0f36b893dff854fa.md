# 我遇到人生十字路口了。

财上海微博 2021-02-25

# 01

菜菜，我遇到人生十字路口了。

我是沿海985男生，毕业了。女票是大学同学，大长腿，不是很白，用了两年不到。女方家里是洛克农村的，他们家村口开小卖部的，你脑补一下《乡村爱情》，基本就那样。这样的家庭也就是吃饭而已，谈不上什么对我们的帮助。

我毕业后，进入一个好单位，女方对我巴结的很，不要彩礼。最近，家里给我介绍了一个对象，这个女方是职教，虽然是柯基小短腿，也不算多漂亮。但是，柯基家在浙江有两个大工厂。介绍人说，不要婚房，不要彩礼，陪嫁一千万。

我现在想的是，怎么和大学女友拗断？女方已经在幻想，婚后我给她家怎么帮忙了，她父亲居然暗示我买个车给他家。我担心的是，那边女方会不会派小舅子过来揍我一顿？

答：放心，你只要不乱说，人家不会揍你的。

# 02

菜菜，我是985，在杭州上班，月入1.2w。你说我怎么才能买房结婚？

答：我看分几步走。

一是好好上班。你平时节约一点，一年存10万左右，存十年，也有100来。

二是谈恋爱不要多花钱。肯德基，拉面，三五十块钱也可以混一天。

三是巴结丈母娘。丈母娘是绝大多数人第一个天使投资人。你要好好把握。

四是找个不要彩礼的女人。能省一点是一点。

五是找爹妈谈谈，让他们出个 200。

六是尽可能找个大单位的女人，其他不用多考虑了，就看能不能凑个30-50的。
