# 装修要做好记账

一个装修，往往是3-6个月，我现在有个工地干了两年了，还在装修。这里面会涉及到一个问题，就是最后怎么算总价，装修公司往往是给你一个表格，比预算多出很多钱。有的是你临时加活，有的是按实结算，有的是修改方案，有的是胡乱多算的，例如隐蔽工程。

你和装修公司吵架是不可能的。因为，你家在这里，他们四处游荡，你家有老有小，玩不过他们的。

经过这么长时间的装修和各种破事，你和装修队长很多事情就记不清楚了，最后就是按照装修公司的表格计算了。我教你一个办法，三天两头写个工作记录，在手机里，以后对账，你心里有数。很多人把微信记录作为对账依据，是不行的。因为微信记录，时间长了，你可能无意中就删除了。我发过这个号，损失惨重。
