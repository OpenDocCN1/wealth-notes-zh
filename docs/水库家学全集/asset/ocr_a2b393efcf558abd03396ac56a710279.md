# 为什么聪明人混不好单位？

大家有没有发现，单位里的老油条，实际上有很多是聪明人，脑子转的极快。吃完午饭打摸蛋，他们水平很高。背后议论单位点头，也是一个接一个的俏皮话，逗得一群大叔大婶们，像老鸭子一样，嘎嘎嘎的笑，2个小时的午休时间，很快就过去了。实际上，这批人长期混的不好，自己心情郁闷。为什么聪明人混不好单位呢？我就自己写个几段，给大家一个教训。

# 一，我的基本情况

油腻大叔，青年时候的24k穷比，工龄近20年，985，看上去贼妈8聪明，说笑话的口才超一流，我能把中年妇女都哄开心了，但在大单位，长期混不好。

# 二，检讨原因

+   1，喜欢天天吹牛逼。但凡能力太牛的人，那是从小到大，不自觉养成的。学校里的竞赛规则是看分数。我从小到大在清北班鄙视，什么大场面没混过，还怕你们这几个歪瓜裂枣。我经常和别人吹牛逼，“你看我，又是第一名，服不服？”这种货色，招人恨啊！我要是你同事，恨不得一脚踹飞你。

+   2，能力太强吃独食。我一个人能够顶三个人，不需要你帮帮忙，瞎掺和。这就得罪人了。很多人没有能力，就想和牛逼的你混一把，顺带帮点好处。你一个人吃独食，实在是过分了！你不想分好处，我也让你吃不成，到处说你坏话。我呸，你算个啥东西，瓜总呢！

+   3，好出风头不安分。你出风头了，显得我们好像很蠢，我不要面子啊？不行，老子就要恶心恶心你。“菜菜这家伙坏的很，前两天说老王坏话了，我都听见了，我給你学一哈！”

+   4，和小头头关系太差。像我这种尾巴巴到天上去的250，往来无白丁，至少是个副高才能和我说几句话吧？在单位里，一般看不上小头头，这些货算个鸟水水平啊？想当年，老子在985的时候，你在农村挖野菜。这下子就直接坏了。小头头会把压成肉饼子，直接塞进韭菜地里。

+   5，家里穷比还不服。穷比孩子，自卑心理作崇，还往往有种不服气的感觉，事事要争一下。但是，单位里的每一个好处都是有分配顺序的，岂能让你乱跳？你就尝倒霉了。

# 三，对策

在靠互相评价的单位里，太聪明的人是混不好的。咱也可以考虑一下出来，陆家嘴是好地方，广阔天地，大有作为。你不是牛逼吗？来！给老子拉个五亿的单子。穷比，你行不行啊？
