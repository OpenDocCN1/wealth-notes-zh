# 10

奥数和高考有关系吗？

我们那时候，一般不搞奥数，主要是省市数学竞赛之类的东西。也不知道为什么现在奥数这么流行。如果说奥数完全和高考无关，家长不至于那么来劲。家长里面藏龙卧虎，不要小看。

我的结论是，奥数和考清北有关系，和考985关系不大。高考数学，有个你不知道的隐秘规律。就是一些次级定理。什么意思呢？这些定理公式，书本上没有，但是，一般也是大家公认有效的定理。这些定理可以通过书本上的内容，间接推算出来。

这些次级定理，用处很大，经常作为难题的拦路虎出现。你要是不知道这些个破烂玩意，你根本不可能在短时间想到。如果你掌握了，猜题解题极快，特别是选择题。

这些东西在哪里？就在奥数班上。例如将军追兔，蝴蝶定律，对称公式。

如果考985，这些东西意义不大，反正你也不需要考数学满分或接近满分。

我们如何解决这个平衡问题？我的观点是，你去买一本奥数的书，不是题库，里面有很多定理，都是你闻所未闻的东西，你就把他背下来，然后试做几个小题就够了，千万不要沉迷进去。

奥数难度的题目，在高考数学中比例极低，如果你的目标是985，基本可以放弃。
