# 07

餐饮业的秘密

开饭店，什么最重要？你可能想当然认为味道，价格。实际上不是的。餐饮业分为两种，

一是社交餐饮。例如外单位来你这里取经交流，商务宴请，同学聚会。这种饭店往往看装修。装修好，气氛好，贵一点也没什么。

二是家庭餐饮。这讲究安全性。

我不喜欢洋快餐，但是，我每年为了洋快餐花了不少钱，包括各种农村产的杂牌汉堡，温州披萨，低档牛排，意大利

通心粉。为什么？没办法啊。

家庭出去吃饭，往往是节假日带孩子玩一圈，吃点东西。孩子吃什么，家长也顺带吃一点。孩子吃东西，不能辣，尽

可能没有添加剂，不能有各种这个那个。想来想去，最后就是吃洋快餐，心理上感觉安全一点。一家三口带个保姆，几百

元就吃一顿洋快餐，心情沮丧，但也没办法。

上海有一家台资牛排，比较贵，三个人就是一千多，我居然半年吃成了金牌顾客。实在是匪夷所思。

结论：开饭店的同学注意了，你的饭店生意，一定要考虑儿童生意。这是非常重要的客户群。
