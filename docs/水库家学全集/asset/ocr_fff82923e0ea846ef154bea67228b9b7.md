# 逆袭和什么有关?

我考察了三代人，4050后，6070后，8090后。

1，如果是混中产，学历是第一因素。凡是学历相对好的，找工作就比较好。4050后，只要是大专以上，基本都是人中龙凤。退休工资很高。6070后，需要本科，8090后，要211，985了。没有学历就要苦干了，贴瓷砖也出了很多人才。

2，如果硬说发达了，可能还是和经济有关。80年代的热门是钢材水泥，90年代是开厂，然后就是众所周知了。

3，逆袭和工作的关联性是相对的，肯定不是直接的。我家有个亲戚，工作上非常厉害，一天到晚找办公室里加班，其他什么都不考虑，最后被市场经济甩了。第二代比较难混了。因为父母只能包你到入门，入门之后，父母的因素下降很多了。特别是不在一个系统里。过了35，父母的作用基本为零了。

4，我们这些40几岁的老东西在一起，讨论最多的是婚房。这个事情，你懂的。省略千言万语。
