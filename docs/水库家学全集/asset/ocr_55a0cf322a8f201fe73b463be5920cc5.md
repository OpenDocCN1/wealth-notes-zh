# 01

读书要适可而止。

很多人读书读上瘾了。例如我，这一大把年纪了，还跟个屌丝似的，对各种知识，非常好奇。

人生最重要的不是读书，而是**学以致用**。举例，你就算把贴瓷砖的技术研究出花来，你也赚不了几个钱。你踏踏实实练三个月出师了，去赚钱，**才是对老婆孩子负责**。

不仅仅是贴砖，还有各行各业。你不要想什么都研究透了。爱情的关键是先用起来。

# 02

准备。

很多人对待生活的态度是，等我彻底准备好了，再去做。这是我们从小学到大读书，形成的惯性思维。每次考试前，我们都要准备充分，反复看三遍。

但大千世界不仅仅只有一个道理。生活中很多事情，你必须一边准备，一边抓紧上车。如果你彻底准备好了，车也开走了。

有很多人买房，非要买个非常满意的房子。特别是中西部大城市来的。她们老家的房子便宜，自己又是城里人，形成惯性了，非要什么都好。这种一步到位的想法，往往会错失良机。农村的，相对务实一点。例子很多，就不说了。

此时彼一时。你在大城市不能什么都准备好了再行动。这个世界变化太快了。你要抓住一切机会，先进去再再说。就像是娶老婆，你管她好看不好看，先来一个再说。我们小时候坐火车的经验是，先买个站牌，上车后，补个票。如果你不满意，再往卧铺挪，找乘务员，再补差价，进一个卧铺票。

你的一生基本不会只做一个公司，只买一次房子，不要太关注开始的辉煌，更重要的是，结果的美好。
