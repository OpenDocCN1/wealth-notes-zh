# 02

作为一个普通人，我简单说一下小娃娃读书的事情。

在大城市，流动人口的孩子，一般初二要走人，回老家读书。小学，理论上可以在父母工作地读，但是需要很多很多资料，还有一些不利因素，主要是不一定就近入学。初二回老家的原因是，建立高中学籍，学籍和高考挂钩，高考名额各地不一样，防止投机取巧。

这个问题不是新事情，而是一个存在很久的事情，留守儿童就是这么来的。这么做的原因有很多，但是结果是很明确的，就是部分大城市的流动人口必须回老家了，特别是北上广深。

有些人说，有没有变通的办法，实事求是讲，基本没有。国际高中不是一般人可以读的。如果不参加高考，能不能读外国高中？（我好像听说过，但没有研究过）

双外家庭分为，

一是高学历家庭。这种家庭普遍重视子女教育，有可能就是长期的两地分居。

二是低学历家庭。这种家庭主要是在大城市承担体力工作，例如菜场杀鱼，贴瓷砖，送快递。如果回老家，基本找不到类似的收入。

如果非要留下来，好像不能读高中（具体不熟悉）。
