# 大考前两个月，重要的是调整。

财上海微博 2021-04-16

01

有没有什么企业给你月薪十万？

+   1. 如果是超级数据化大牛，可以解决牛顿也搞不懂的编程问题，
2. 如果是销售提成，业绩特别好的，
3. 假如您是路路通，你说多少钱都可以。

但是，如果仅仅是轻飘飘的说几句：我是大学生！那基本不可能。

刚才一个屌丝说，自己20岁，想月入十万，基本就是吃错药了。你不是很牛吗？给你一个销售区域，做到区内空调第一名就可以。“看见对面那个办公大楼吗？拿下空调订单。”你行吗？不行。那就撤油娜那了。

刚才那个大学生，正常收入应该是8千。啥也不干，还不如一个清洁工呢！

小结，这个社会最重要的是，你能给别人什么，而不是你想要什么。我还想要新垣结衣呢！

02

小孩子单挑。

我家娃已经一年级了，小孩打打闹闹是经常发生的。我以前就给娃报了一个拳头兴趣班，其实就是运动运动。没想到，值回票价了。这种兴趣班一般会教两个事情，一是遇到坏人立即逃跑，二是遇到熟人可以躲闪。这次，我家娃用上了躲闪。

娃班级上有个小霸王，经常欺负班那里的小娃娃。前两天，我娃提出单挑，小霸王应战。在单挑的过程中，我娃充分使用了躲闪技术。正常人遇到对方冲撞，本能反应是后退几步，正确的打法是横闪。

对方那个娃估计没练过，几次冲撞无果，被我娃家拌了腿，摔了。然后就和平了。

我有个建议，如果要参加兴趣班，可以报一下这种强身健体的班，至少不慌。
