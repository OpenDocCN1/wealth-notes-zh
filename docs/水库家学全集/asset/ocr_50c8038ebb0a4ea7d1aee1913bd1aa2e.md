# 03

大城市的困难户。

由于在大单位，这方面工作接触过不少。很多农村孩子印象中的困难户，应该是吃饭都困难的感觉。实际上不是的。

我接触过的困难户，一般是这样的。

+   1，有一套房子，也不大，内环线60平米以下。

+   2，有本地户口。

如果没有以上两个条件，基本就是流动人员了，社区也管不到。

+   3，困难原因很多，主要是因病，因伤，孤寡，丧偶后另一方无工作。

+   4，困难表现，缺乏现金流。这是最主要的表现。

综上所述，大城市的困难户，主要是缺钱，而不是没有房子。我接触过一家困难户。房子是内环线50-60平米（来源可能是，单位分房或拆迁，继承），孩子读大学。老公因病不上班，只能在家做做饭，老婆在大超市上班，那时候是月入两千左右，放在现在应该三千多。

如果说资产，他们家的房子大概是五六百万，不算少了。如果说收入，确实困难，一家三口，只有这点钱，老公还有医药费支出。

那时候，我们逢年过节就去送点东西，他们配合我们拍拍照片。

# 04

在大城市，困难户主要是身体不好。如果身体好，随便做点工作，吃饭没有问题。例如现在保安，一个月三千多，勤快一点的人，还可以有点纸板箱，停车费。要想穷，还真不容易。我们小区的垃圾桶是承包的，没点路子，你还真塞不上去。

在大城市，身体健康，愿意干点活，就是财富。我家对面，有个老破小区，里面有不少外来农村媳妇，多年前嫁到内环线的，现在一般已经五十岁了。她们也基本实现了家门口就业。主要是在家门口一些小商店当营业员。上班近，一抬腿就到了岗了，没有交通费。我家门口一个小烟酒店，蛋糕店，食品店，麻辣鸭头店，里面的老阿姨营业员就是对小区的，有的已经做了十年了。
