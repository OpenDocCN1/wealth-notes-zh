# 凤凰男都有一个悲催的老姨

绝大多数的京沪凤凰男，婚后都会出现一个苦命的老姨：老家，丧偶，离异，把自己打扮成天底下最可怜的人。

凤凰男结婚后，面临最大的困难是，孩子没人带。凤凰男一般不会同意老婆辞职带孩子。而且，凤凰男找对象一般会选择工资高的老婆，一起奋斗还贷款（大家警惕）。

这时候出现了完美衔接，老姨来我家做全日制保姆，工资五千。大家是亲戚，互相信任，一拍即合，就等那个城里死女人同意了。丈母娘高度欢迎，终于可以去旅游了。你还能说什么？同意呗。

我有好几个熟人上套了。一开始双方互相客气，还算正常。用不了多久，老姨家里肯定出事了，找凤凰男借钱，一般是小步快跑，三万也不多，给了吧，就当是年终奖。我有个熟人借给老姨，历年合计24万了。

老姨儿子来城市开黑车了，租房后，缺这缺那的，先从你家顺一点。你是本家大表哥，讨一个手机呗，旧的也行。你好意思吗？

然后，老姨家里大事小事不断了，老姨一天到晚开始和老公，和家里人网络聊天了，吵的你也受不了了。

第二年，老姨认为自己工资低了，另外在小区找了个兼职，老姨的生意越来越好，你也不好意思阻拦，从此之后，你家就变成老姨在大城市打工的宿舍和网吧了。如果老姨在京沪谈恋爱，你家就算毁了。

我也曾经遇到过类似情况，但我怕人情太多，没让老姨来。
