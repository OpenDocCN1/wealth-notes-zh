# 如何在小县城做优质父母？

莱菜，我和老皮都在小地方，房子两套，有房有车有关系，都在大单位，日子很舒服，也不想去京沪省城了，我也愿意孩子过上我们这种快乐生活。怎么做优质父母？

大部分人都是生活在小地方，部分家庭日子还很不错，150块钱，可以在小餐馆吃的满嘴流油，卡拉OK一晚上也不过是五百块。节假日自驾车旅游，开心的不得了。欧美，京沪都去玩过。遇到事情，一个电话，四面八方都有关系，实在是想不出来打拼了。

小地方最大的困难是赚钱难。离开体制就活不成了，但是小地方也有好处，山清水秀，房子便宜，网购四通八达，什么都有。以后在大单位搞个小位子，带个长，混小地方其实也很实惠。小地方也有痛苦，就业不充分，子女怎么办？

其实也有办法。小地方最看重教育和文凭。你只要把孩子培养好，以后就好过了。必须搞个985。

一是努力培养孩子读书。小地方家教便宜，你要舍得花钱，把孩子成绩搞好。

二是孩子必须进入大单位或者正式编制。有了文凭，一般情况下，进入小地方的正式编制是可能的。

三是没有正式编制去做家教。小地方特别重视文凭，三教九流，上上下下，都希望孩子读书好，家教需求特别大，永远不会失业。那就OK了。搞个家教班，抓小猪仔很赚钱。有了源源不断的收入，又有房子，你就开心了。

你只要把孩子文凭培养出来，那就衣食无忧了，儿子找老婆也容易。因为有很多二本妹，受不了京沪的激烈竞争，就想回小地方躲藏，你家儿子捡个漏，完全可以。

如果你儿子不是读书的材料，那就要搞个技能了。例如贴瓷砖，做大厨，以后去大城市赚钱。不要太难过了。谁让他
