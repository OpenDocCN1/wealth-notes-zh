# 04

房子要爹？好像已经说了几十年了。

从牛b刀开始，每隔几年，都有一批新韭菜不服，非要等多几年，被人割了三代人的韭菜，才嚎啕大哭。时间长了，我也在研究，房子怎么才能爹。我感觉有几点

一，有无穷无尽的便宜房子等你。我印象中2000年前后就是这样的，外地人买房还送户口。那时候，四五万就是一个中环一居室，售楼大妈还来你买，那时候没有什么售楼小姐。我有个老乡同学，在中外环上班，为了父母来照顾他生活，就花了几万元在单位附近买了个一居室，现在两百多了。

二，出现了无风险的高利润项目。你把房子卖了，手里这笔钱干什么？总不能存银行吧？如果回到九十年代，那时候没人买房，大家都在凑钱做生意。我们工业区的老王，九十年代是技术员，辛辛苦苦在私企打工，攒了五万块钱，一直舍不得花，准备回老家盖房子娶老婆。老王厂里的老板因为岁数大了，想把厂子卖了（没有土地，只是一些设备），于是老王盘下来了全部的机器设备和部分不值钱的原材料，实际上也没什么大东西，老王一共花了9万多，这个数字很大了，相当于内环线一套老破中了。后来WTO了，老王发达了，现在也是亿豪写了。

三，大学生流动暂缓。房子的需求有几个大因素，

一是本地人改善，你去看看市中心的几个区，居住条件确实很难，他们也想改善。

二是外地人进入大城市。包括农民和大学生。不要小看农村人，人家承包一个快递站，开个土方车，炸油条，贴瓷砖，比大学生收入要高了。这些人的居住需求也是客观存在的。前两个月，内环线有个葱油饼大叔，做了二十年葱油饼，攒下两套房。比985厉害多了。
