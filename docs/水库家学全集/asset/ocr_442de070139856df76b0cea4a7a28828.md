# 09

逃离北上广。

我这几年看了不少省会和大城市，整体感觉是，千城一面，特别是一些新小区。我曾经在东北某地级市看到一个小区，连外立面瓷砖颜色都和浦东东邦一模一样。结论是，各地的生活水平实际上和北上广差不多了。区别是就业。

曾经有个东北的女粉丝告诉我，她是怎么赚钱的。她是苏某重点高中的老师。每周五下午就坐火车去大城市的辅导班上课，虽然超级累，但是虽然累增，副业甚至比主业还高。她的聪明才智实现了小城市的财务自由，一年收入25～35万以上。可以在房价八九千的小城市买房买车，毫无压力。

由此，我想到了—些建议，你能不能练一个可以异地办公的技术。例如咨询设计制作，甚至是考试辅导。据说，专门写大城市生活的著名影视刷作家阿乃，居然不是生活在京沪，而是浙江。我在欧洲的同学告诉我，班加罗儿有个奇葩的职业，当地工资很低，他们那里的大学生发明了一个赚钱新办法，通过互联网络给其他英语国家的弟子辅导作业，收入很高。

目前看，这个技术的可能性是存在的。例如以前环线 的书报亭经常看到一个小广告，免费装修设计，现在没了，估计全部跑到网上了。还有著名的学生辅导网，雪而私，某某著名的考试网，还有一些程序员，设计师，现在都实现了网络办公。今后，他们的主力员工可以陆陆续续搬到小地方而不影响收入。
