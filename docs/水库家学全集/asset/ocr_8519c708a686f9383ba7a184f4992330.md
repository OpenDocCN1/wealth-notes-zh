# 努力，能不能逆袭？

我认为：可以，但不在一代人。

我出身985，又是早期留学生。我从小到大认识的人，大多数是清北的，都很努力。现在四十多岁了，改命的不多，到了城市中专就止步了。大概情况是，

在本地有一套三居室，有一个二三十万的车，老婆也有一个不错的工作，自己也混成了一个小头目，管了几个打印机。偶尔几百元的餐饮费，可以在公司报销，时不时有几个外地出差，纯粹是玩一圈。吹起来谁都认识，实际上没鸟用，真找他个事，就推三阻四了，都是场面上的点头之交。

他们算不算改命了？你自己判断。我也没有逆袭，只不过在老婆那里吃了个合饭，合法软饭。真正的逆袭可能性是发生在下一代。我有几个同学，已经具备了潜质，

一是大城市三居室已经有了。

二是子女有了大城市户口。

三是看孩子运气了，如果考上985，也可以再上一个台阶。如果考不上，也就混个平平常.

很多丝丝认为的逆袭，可能是几个亿之类的。那不是靠努力了。努力是有极限的，你的老板不可能无限制的给你好处。更多的是画大饼。古今中外，发大财的，都是承担了巨大不确定性，被市场毒打了。

你的上限，一般是行业平均收入的5-8倍。如果你家公司的会计是月入六千，你的上限就3-5万，再多不可能了。当然，也有个别大牛，就像是省内高中数学竞赛一等奖。那毕竟是少数，不要太执迷了，和你没关系。

你结婚房子买好了伐？
