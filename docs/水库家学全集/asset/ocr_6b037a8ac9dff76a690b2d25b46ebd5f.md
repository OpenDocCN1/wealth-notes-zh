# 07

你能不能开厂当老板？

你装修的时候, 能不能握住装修队的小队长和泥瓦匠, 在不加价的情况下, 让他们按照你的意思修改修改。若可, 你就有当老板的气质。

上班族对人的理解是肤浅的。同事之间, 没有直接的利害冲突, 极少搞到互相瞪眼, 剑拔弩张。但是, 开公司就不一样了。人家就靠这个吃饭的, 少一块钱也不行。举例,

某技术员, 负责一个项目的CAD。他三天两头请假外出, 表面意思是家里有事, 实际上是出去应酬。他找到了一个新工作, 在某年8月12日回来, 立即要求结算工资奖金, 还要提前发年终奖。一天也等不了, 因为他明天就要去上班。我不同意, 他就不移交资料。我急得满头大汗。最后怎么办?

我认怂了。他要多少钱, 就按照他的计算公式付钱。可能有二本子激动了, 和他打官司啊! 呵呵, 幼稚。若为了这点小钱, 误了交货期, 我全副身家都没了。
