# 小产权和没产权，是不是一回事？

小产权是完全办不了个人小产证的房子。看上去像一个正经小区，实际上是个不正经的小区，小产权和没产权还不一样。

有一部分没产权的房子，本身是合法房子，只不过是开发商拖欠各种费用，有关部门不发证而已。

小产权就是另外一个概念了，小产权从头到尾是绝对不可能发证的，因为这房子起头就不是正经房子，因为立项的时候，它是按照工业房，商品房，农村房，申请的，搞着搞着变成了不正经的个人住房样子，底子不干净，从头开始就是错的，最明显的特点是绝对没有小区绿化之类的，也不考虑容积率，摇号楼就是这么来的。

为什么不推倒呢？因为人太多，麻烦，你一个上班的，遇到事情了，也没多少精力去搞，尽可能不要碰这些麻烦。
