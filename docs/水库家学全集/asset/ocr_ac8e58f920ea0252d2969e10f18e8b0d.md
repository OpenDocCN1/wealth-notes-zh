# 01

你老婆会做菜吗？

菜娘是做菜做点心的高手，一个人可以搞出一大桌菜，大家还非常喜欢。我问她为什么会做菜？她说，读英国大学的时候，太穷了，吃不起饭店。同学们就一起周末聚餐，最后，大家公认菜娘做菜最好，其他同学自觉洗碗洗菜，她掌勺。时间长了，她也感兴趣，就练出来一手绝活。现在，这个女人厉害了，每次出去吃大餐，就在研究人家厨师是怎么做这个菜的，有时候，还专门打包一份（炒菜）拿回去研究。

# 02

你赶紧给老婆买个貂。

菜菜，我是某大厂的已婚妇女，一个儿子，15岁，我这一辈子倒霉太了，我那死鬼男人一天到晚打游戏，家里只有一个老破小。我年轻时候看走眼了，只图男人长相好看，为了琼瑶剧的爱情，可怜巴巴的，到现在也没买过貂，有一次在张胖花那里穿了一次，那叫一个舒服啊，拍了十几张照片。

万万没想到，我这个老女人四十岁的时候，桃花运来了。最近，两个年纪差不多的秃驴来示好。要不要给他们一个机会？

A狗，死老婆了，内环线三室两厅，年入四十万，过去就是正牌大房，争再一个生一个。

B狗，老婆还没死，但他年薪百万，公司配车奥迪a4，暗示工资归我管，就是身份委屈一点。

你怎么看？

答：人生一场，也不容易，开心就好。你都这把年纪了，不要闹笑话就行了。
