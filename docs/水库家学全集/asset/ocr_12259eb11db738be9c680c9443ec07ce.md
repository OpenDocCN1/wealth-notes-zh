# 富二代要谨慎

这几年，我周围出现了好几起老年人脑子发热的的事情。一辈子积蓄打水漂了，令人失望。我分析了一下，主要是几个原因，

一是长生不老。各种各样的高科技床垫，深海鱼油，各种各样奇怪的草药，配合微信号的忽悠，多少钱都会往里面砸。

二是贪婪之心。很多老年人一辈子没有成功过，他实在是不甘心，老了老了赌一把，“凭我这么多年的经验，还玩不过你们这些年轻人？”

三是精神享受，很多老板发财了，一辈子被员工捧在手心里，一天到晚吹他，他也忘乎所以了。他已经不考虑理性了，最喜欢一群人围着他说好话，他就心甘情愿发钱。我有个亲戚最喜欢的请，就是员工吵架找他当裁判。他非常享受这种过程。老了老了，还要做一个大生意，给一群人发钱。

四是把亲人当做绊脚石。亲人规劝，根本不听。“我是看你长大的，我还不如你聪明？”

他们脑子发热了，就把一辈子积蓄打水漂了。最后，一地鸡毛，子女倒霉，下场极差，我看了这些事情，很感慨。

一是老年人的钱真好赚。越是自以为是的老年人，越容易栽坑里。

二是指望你可以规劝老年人。他们已经完全不听。

三是不要给老头老太担保，不连累家里人。

四是富二代要有点意识，老头老太不一定会把钱给你。他们更喜欢自己糟蹋完了。
