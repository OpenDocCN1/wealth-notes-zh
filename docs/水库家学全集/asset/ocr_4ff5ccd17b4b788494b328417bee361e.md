# 为什么上门女婿越来越多，遍地都是？

财上海微博 2021-03-11

01

世纪公园。

这个地方我去看过。我听说有个打乒乓球的老辈冠军就住那里。我印象比较深的一次是，我有个熟人，在2008年的时候，花了三四百万买了那里一套158平米的房子。当时，大家都看不好。因为，当时单价几万元已经突破了大家的想象力。

我们这一代人，看房子的眼光是用“千”来计算的，超过八千，已经无法同意了，不像现在的年轻人，早已经适应了“万”。按照现在的行情，十年毛利过千万，尼玛的，揣摩心里都不能接受，这么个屌丝，就因为一次漂亮的选择题，就逆袭了？我从小到大，寒窗苦读十几年，做了那么多奥数选择题，凭什么啊！

我不服！
