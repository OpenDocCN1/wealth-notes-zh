# 01

什么是单位里的能人？

能人，不是你天天加班。很多单位的考核是可以通过拼命加班达到的，你或许很努力，也得到了超乎常人的考核成绩，但这不是能人，只是努力。

能人，不是吃独食，而是帮助别人。你不要自己赚了点钱，就洋洋得意。这是蠢货吃独食的表现。能人要做的，是自己成功的方法总结出来，让大家也得益。

能人的意思，是你能干成事。头头交给你一个有点困难的任务，大家也不知道该怎么办？你办成了，而且没有后遗症，这就是能人。

能人的意思是，不推卸责任。事情出了麻烦，丝丝的反应是推卸责任，这和我没关系，是张二蛋的责任。但是，你想想头头要的是这个说法吗？头头要的是你能不能去摆平问题。

能人的意思是，你能够领先一步，看清楚问题。你要是几年前就看清楚了房子，你就是能人。

# 02

人世间最大的美德是，尽可能帮助别人，同时不损害自己。

人是有感激心理的，这是DNA决定的。若某人帮助过我了，虽然我一时没有能力回馈，也是记在心里的。在有能力的时候，我也是愿意付出的。

帮助别人的时候，尽可能不要伤害自己。若会产生伤害，那就无法长期维持了。

如果你资源有限，那就选择性帮助。你把周围的人看一遍，以天使投资人的角度看问题。当然，你不要觉得，人家混好了，你就可以躺赢了，还没那么简单。
