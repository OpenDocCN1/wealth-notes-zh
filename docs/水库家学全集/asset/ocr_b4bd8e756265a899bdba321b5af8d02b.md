# 01

孩子的规划。

孩子就像是一张白纸。你画出什么样子就是什么样子。我的思路是，

小学到高中，主抓成绩。如果够不到班级前三名，那就认认真真捣作业。清北是两个学校出一个，985是两个班级出一个，211是一个班级出两个。

大学，女生学一点歌舞表演，男生学一点拳击篮球。

琴棋书画是好东西，但这是附加值。如果姓娃不能达到一个好的平台，琴棋书画就是瞎搞了。你在中专校里，文艺再好，也混不上去，无非是那个破事了。小娃娃的最重要目标是成绩，有了成绩，可以达到更高的平台，你的歌舞体育才能更值钱。

我读书的时候，年级里有个女生非常漂亮，还会表演手风琴。我们那时候没有钢琴之类的。这个女生因为想出风头，用力过猛，一天到晚练手风琴，最后没考上大学，去了车间。实在是干不下来，就辞职了，先去一个婚纱摄影公司拉单子，后来去售楼处卖楼，现在一个破公司当出纳。她嫁的男人也一般，是个婚纱店的摄影师，现在已经离婚了。她因为层次太低，混成这样，实在是太可惜了。

与此同时，年级里还有个女生考上了本科，毕业后到某大学找了个工作，是属于后勤部门的，嫁了个屌丝硕，现在也是副教授，两口子混的风生水起。

实际上，当年在中学里，漂亮的婚纱妹属于万人迷，一般的大学妹基本是无人问津的小草，没想到，二十年后，结局居然如此颠倒。

小结：培养孩子，成绩是最重要的。考上好大学就可以进入更好的圈子。千万不要为了一时的出风头，而本末倒置。
