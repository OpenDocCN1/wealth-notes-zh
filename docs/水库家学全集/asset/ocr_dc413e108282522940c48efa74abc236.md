# 04

我家乡姨是怎么发发财的？

三姨是八十年代化工厂的技术员。那时候，大企业里，无所事事，一天到晚打毛衣。有一次遇到一个浙江老板。他想做洗发水，但不会做。洗发水和沐浴露是就比较简单的化学合成。我三姨会啊。于是，我三姨就在实验室里捣鼓各种配方，小缸试验成功了，就做大缸批量。

三姨迅速发家致富了。那时候一个月工资一百多元，她一个周末五百元，还有土鸡土鹅吃，爽的不得了。这个生意越来越好。她也想用自己生产洗发水，但这玩意，城市里做不了。因为场地设备比较麻烦。后来有个乡下小厂找人承包。她就去了。然后一发不可收拾。

再后来，就不挣钱了。因为大品牌铺天盖地，小品牌没人买了。但是，她前前后后十年，也赚了几个老破小。现在也是小土豪了。

# 热门评论:

+   1. 回水君：幸亏她赚了钱买房，投入再生产的话就黄了，只能去刮腻子。

+   2. 睡觉梦里有个：以前缺人才缺产能，现在两者都是过剩。当然有些人才还是缺，比如新冠疫苗，但普通人也想不着那个本事。大家别老想着发财了，先想想怎么挣多点小钱吧

+   3. 短尾鳄：有技术完成原始积累，然后再搭上时代的顺风车就发了。两者缺一不可，否则拿积累去乱搞一样是白搭

+   4. 恋语随风1086：最终房本好啊

+   5. 似是故人来97：关键是地敢于周末出去搞外快，关键在于她找到了承包小厂还敢于跳出去，关键还在于她赚了买砖头还是投入再生产。人生的选择千变万化，有时候捏着鼻子或者被形式迫使，一切都变成最好的安排~
