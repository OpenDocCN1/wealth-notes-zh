# 购房决策时间。

一般情况下，想买房，肯定是想了好几年了。等你具备首付，实际去看房，遇到了合适的目标，例如合适的价位和地段面积，你一般会在多久做出决策。我的经验大概是一分钟拍板。

倒也不是我很厉害，而是售楼员倒逼你，一般的说辞是，已经有人看上了，正在谈价格之类的话，搞得你心里发慌，再说自己也可以接受，那就拍板了。这个一分钟把你家三代人的心血砸进去了，是很揪心的。签合同之后，也没什么想去了，就是走标准化流程，一般一两个月左右。

如果给你思考一个星期，有意义吗？没意义。如果你有研究，你肯定会千方百计研究这个房子的缺点，甚至把缺点扩大化，最后不买了。如果你真的这么做，我可以保证，你十年也不会遇到百分之百满意的。最后白白失去了时代机遇。

建议，你去看房前，写个纸条，哪几点必须满足或规避。其他不考虑，一旦遇到买得起的，立即拍板，稳准狠。
