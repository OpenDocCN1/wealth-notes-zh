# 企业销售好做吗？好做

销售是被大学生厌恶的岗位。因为大学生喜欢旱涝保收的位子。现在愿意做销售的，绝大部分是混混老油条，好吃懒做，脑子笨，凭你的本事，秒了他们也不难。

销售不是平白无故发生的。人家有产品需求，你有产品提供。关键是接单。

销售不是大海捞针，你站在马路上，哪里知道谁要你的产品？销售往往是有针对性的客户群，你不要担心，老板已经给你圈好范围了，你去碰运气就行了。

# 在海南东北人是如何谋生的？
