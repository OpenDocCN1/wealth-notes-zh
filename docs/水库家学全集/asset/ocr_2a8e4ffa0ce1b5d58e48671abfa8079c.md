# 你想过35岁之后的事情吗？

如果你现在是35之前，你会觉得一切都是那么美好。22岁之前，一直在上学，每年升学一次。一眨眼，中学生变大学生了。年轻人找工作机会也多。工作后，年轻人都是年年加薪。大概率还可以当个小队长，得个小奖状，管了几个250。单位里的老妈姨时不时还要夸你几句。

父母给你出钱，买房买车。人家丈母娘养了二十几年的黄花大闺女，洗的干干净净，送上门来给你用，只要你去办个证。你也不要考试了，一天到晚刷手机，父母给你做饭，管孩子，女票陪你聊天，你家里那个老婆，勉强还算可以，你想想怎么用就怎么用。开心色特了。

但是，这个好日子到35岁之前必然结束了。接下来，你就进入平凡的世界了。父母老了，三天两头进医院。老婆一天到晚骂你不买房。孩子读书了，班主任的微信把你折磨的死去活来。单位里也不加薪了，再想升职，几乎不可能了。新来的大学生，发了疯加班加点干活，你也比不上了。更漂亮的大学生来了，看都不看你一眼，你会越来越痛苦。

这时候，你就迷茫了，今后怎么办？我以来过人的经验，提几个建议，

一是建立职业护城河。最好是考个职称。有了职称，可以虐一下那些小sb。

二是建立财富安全带。就是买个房子，和城市一起成长。
