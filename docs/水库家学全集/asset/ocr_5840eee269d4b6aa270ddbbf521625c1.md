娃最近参加了一个文艺兴趣班。那个老师可能是公办出来的，在培训机构混点加班费，对家长的口气就像是班主任。既要收钱，又要指挥家长。最后没人理她了。前不久，为了鼓励娃续费，邀请家长聚餐，凑不满一桌，直接取消了。我听的哈哈大笑。在学校里，班主任说话，谁敢不去？

# 02

要不要提前培训小学生？

我家娃是一年级，在班级里，遥遥领先。说白了，也没有什么花头，就是在幼儿园的时候，提前学了一年多。把拼音和数学背的滚瓜烂熟。幼童的记忆力特别好，多背几次就记熟了。

今天要说的是娃班级里的其他同学。有个娃，看上去特别聪明，但是现在基本废了。这个娃属于白纸入学的，进来之前，啥也没学过，拼音也不认识。一年级名义上不考试，实际上还是有一些小小的测验，就是班主任突然发一个作业在课堂上写，写完就交。我家娃基本是满分系列，那个娃一般是85-89分左右。现在，这个娃已经是全班出了名的差生。

因为幼童放学，家长都要在校门口接孩子。我们也有机会看到了这个孩子的家长。孩子爸爸一看就是读书人，感觉是大单位气质。妈妈属于比较漂亮的小花瓶，没什么文化的感觉。每次看到这两口子，都是急急忙忙的感觉，我就不作往 了，你每次都是慌慌张张的，是不是回去有事？娃的爸爸说，每天晚上六点，娃有网课。一节课一两百，舍不得浪费了。

我看的心里很难过。现在的学校，就是一个卖场。你家娃读书好不好，数学学不会，和班主任没关系，学校就负责筛选。反正一半的娃不能上高中，无所谓，老师都习惯了。他们家的娃，在班级里属于极度自卑的类型，上课不敢举手回答，下课就急急忙忙往家里跑。这个家长今后可怎么办？我提几个建议，给各位参考

+   - 一是上学不要指望老师。一个班主任面对四十个孩子，不可能有什么明显效果的。老师上课就是按照讲义讲一遍，然后默认你学会了，实际会不会就是家长的事情了。
- 二是幼儿园还是要学会一些基本知识。尽可能不要白纸一张。
- 三是课余补习要参加高质量（贵的）的，那种纯粹是浪费时间的辣鸡课意思不大。
