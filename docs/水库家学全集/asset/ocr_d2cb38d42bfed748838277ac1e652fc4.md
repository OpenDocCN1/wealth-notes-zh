# 01
70后为什么逆袭那么多？

我们读中学的时候，家长都不管，孩子们纯粹是拼天赋。努力一把就逆袭。

我们读大学的时候，大学生很值钱，只要是本科，北上广深欢迎你。

我们找工作的时候，到处是优质单位缺人，本科进三甲，司空见惯。

我们找对象的时候，拆迁妹泛滥成灾。

我们买房子的时候，内环线四五千。

我们要升职的时候，大批的空缺等人。

我们想赚钱了，WTO居然就这么来了。
