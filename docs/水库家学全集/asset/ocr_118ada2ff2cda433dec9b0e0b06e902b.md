# 06

什么样的男人算混好了？

我们印象中，升职发财段位高就是混好了。我统计了一下我认识的人，发现一个有趣的事，在单位混的好的人，退休之后，幺蛾子百出。而在单位里默默无闻的人，退休后，实际很不错。这简直是颠覆了认知。

混好的人，往往有一个特点，周围的人长期在哄他开心。他明明是个250，一群人围着他吹歌载舞，拼命的说好。与此同时，他基本丧失了生活能力，无论他做什么事情，只要找个下属说几句，人家拼了命要给他弄好，哪怕是买不到火车票，人家也会买黄牛票给他，还不收钱。周围所有人，都在挖空心思讨好他，让他觉得，自己做什么都可以成功。

这就害死他了。一旦退休，老小子就成为沙b了。我认识一个老小子，退休了，还真以为自己魅力十足，找了个42岁的新老婆，没几年，就被揍得哇哇哭。还有被骗的，被弯的，被打的，实在是太多太多了。就算躲过了这些，他们为人非常傲娇，基本零朋友，日子过得很不舒服。

这些250特别不会打理家事，也没有技术，不会赚钱。下一代也就是找个单位，多套房子，其他什么也没有了。

与此同时，少部分被压抑到精神崩溃的聪明老屌丝，退休后活的不错。这些老屌丝可怜啊，几十年都没人哄着他们玩，什么事情都是劼力亲为，几十下来，锻炼出了一身本事。例如菜菜这种屌丝。
