# 大考前两个月，重要的是调整。

距离中考和高考，也没多久了。很多家长距离时间自由也快了。我相信，家长和孩子都比较紧张。我以过来人的经验，谈谈体会。

紧张是肯定的，也是正常的。你最最重要的事情是如何过好这两个月。我就老生常谈的说几句常事宜。

一，不要生病。这事情要是摊上了，影响比较大。最重要的是不要熬夜了，熬夜容易神轻衰弱，失眠，白天没精神。其次是不是要在外面吃东西，特别是小饭店，小吃店。比较容易出问题的是早餐。辣油馄饨就不要吃了，家长辛苦一点，去大城市买些面包，每天烤箱烤一下。

二，不要再刷新题了。你就把以前的老卷子看一遍，不会做的，也不要试图去理解了，背下来就行了。

三，合理分配时间，不要偏科。大考是看总分的。数学一分和语文一分，没什么区别。

四，提分最快的是英语。高中英语，比较简单，没有什么复杂的逻辑，会就会，不会就不会。提分最慢的是物理和数学。我建议不要再额外加班加点了。

五，高考前最好提前预定好宾馆。有的考场太远了，为了防止误事，可以住在步行可到的宾馆。高考前，宾馆很难预定，可以提前预定。考试期间，不要用宾馆毛巾。

六，二本也是人。家长莫慌。高考最重要的是考上本科。现在，各行各业越来越要求本科，是不是985？并不重要。你在报志愿的时候，找个最低分的二本学校保底。

七，专业选择有讲究。

1，家里有办法的。尽可能符合你将来要去的单位专业。很多行业有定点的院校，不一定有名气，但实惠。

2，家里没办法的。成绩好的，报医生，码农，成绩中下的报师范，以后当老师也很好，正式单位。

3，孩子不要任性。好多孩子恨不得报个电子游戏专业或环球旅游专业，这是不对的。多听听家长的意见。
