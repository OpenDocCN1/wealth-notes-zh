# 屌丝是怎么想问题的？

我写微博这么多年，一小半时间浪费在了二本子的身上，他们会无休无止的扑上来，告诉你，他多么与众不同。其实都一样，一滩烂泥。屌丝就一个想法：我买不起房子（必须是省会以上），你们什么时候给我发房子？

屌丝拒绝一切劳动致富的想法。不管你说什么，他们就一个理由：老子怕累。绝大多数屌丝目前在30岁以下，处于收入上升期，这也是他们人生的唯一一次高光时刻。离开了小地方，来到了大城市，二十块钱就有人送外卖到出租房。一边吃炒面，一边打游戏，还可以在游戏里意淫一把自己是高富帅，开心的不得了，比村里好玩。他们傻乎乎的以为，所有的事情，都会越来越好的，工资会越来越高。也快了，没几年开心了。一过三十矇不理。

他们认为，所有结婚要房子的女人都是坏人。明明知道是我买不起，你说求啊？我告诉你，房价多贵，知道吗？再烦我，老子一巴掌给你呼过来。用了好几年了，也不怕你翻天。

他们认为，自己在村里也是聪明人，在二本里曾经听过某教授的课，什么事情都懂。实际上也就是250。这群货色今后怎么办？

我一直建议他们认认真真学个技术，不贴瓷砖，也可以学码农。苦熬十年，成为专家。但是，这群蠢货，和公园里下象棋的老头没什么区别。他们上知天文下知地理，海阔局势，侃侃而谈，自以为有本事能找到一个漏洞，两年买房，小美白扑上来，直接走上人生巅峰。mmp。
