# 01

网贷害的是丝丝。

现在，网贷很简单，有身份证就可以一步步手机操作搞定了。那么多放贷款的app，一家搞个几千，积少成多，十几万应该可以。最后当然没钱还你了，再违约一两年，几十万的总额就来了。

富人家的娃，最多被爹妈揍一顿就结束了。而丝丝就没办法了。各种诉讼记录，黑名单，一套一套的。若干年后你买了房，债主还可以来执行。最后，这娃的人生就毁了。

现在，各种app不是不知道你是丝丝，而是他们有办法若干年后再来找你。你就等着吧！

# 02

最近有个视频，留学计算机本科，回来只能做外贸员，月薪四千多，老板还要修理你。

作为老一代的留学生夫妻，我也深深地感受过这种酸楚。先说结论，留学毫无收获，我还算幸运的，呲了个不要彩礼的老婆，相当于去了一次杭州南。绝大多数人根本没有任何收益。原因也很简单。

一是没有什么专业技能。专业技能，特别是卖文凭的文科经济类的。例如MBA，会计学，回来基本没什么用。如果是学法律，估计有极其实见但内应用，但你在国内想要遇到一个外国法律专家的情况，是很罕见的。

二是语言技能也不行。出去了，也是在留学生圈子里k嗦，追剧，打游戏，用小美，睡懒觉。很少有人踏踏实实练语言的。

三是理工类。一般本科硕士内容，还是国内好，至少大家差不多。你在xx学个鸟计算机，真的是叫天天不应，叫地地不灵。

四是自身素质。绝大多数人并不是全奖出去的，本质上还是旅游。我见过留学混出来的也就一两个，他们是苦出身，发了疯一样的干。很快适应了当地情况，运气也好，找到了机会。这个比例微乎其微。

如果不是真材实料的博士回来，留学基本等于零，甚至不如二本。我们以前混博士，还可以在三四线大学混个讲师，现在也不行了。
