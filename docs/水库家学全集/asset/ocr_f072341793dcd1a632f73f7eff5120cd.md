# 卖掉大城市去乡下养老？

逗查上有个小逼说了一大段思路，大概意思是，你把大城市的房子卖600，去小城市买个价值200的，相同面积，套出来的400存定期，爽的不要不要的。

我看了一下，这货居然是某券商的马仔。可想而知，现在炒股票的人，智商有多低了。这种很简单的加减法，不需要多高的智商，小学生也知道。我也不需要多宽的信息量，小城市去大城市谋生路的人多了，谁家没有几个外地亲戚？

这个局的破绽在哪里？不理解老年人的实际需求。说白了，就好比没钱吃饭了，还要去KTV嗨一曲《明明白白我的心》。众所周知，老年人分为两个阶段，一是健康生活，二是头昏眼花。当你刚刚退休的时候，你可以天南海北去玩，只要你有钱。当你买菜做饭都困难的时候，你要的就不是旅游了，而是保姆。当保姆也不想看到你的时候，你要的是子女了。

十年后，当初卖掉的600，不知道有多少了。这时候你傻眼了，房子糟干净了，两手空空，现在住往地上一蹦，“我是你老子，快来服侍我！”好意思吗？儿媳妇看到你是心情？你手里那小几百，按照你那边超级自私的想法，估计也是交给三甲了。你也就牵牵挂了。

如果你非要这么玩，我教你一个好办法。你把房子租出去，三年。大城市二层，七八千一个月，合计25-30万，再加上退休金6-10万，你去小城市当两年闲佬，看看行不行？我觉得你会感谢我的。
