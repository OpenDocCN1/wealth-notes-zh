# 13

读书为了什么？

以我家祖传五百年的倒插门手艺，我对教育有深刻的认识。教育绝对不是学知识。你去看奥数与知识有一毛钱关系吗？

首先读书是为了培养良好的人格。青少年时期，你快乐不快乐就看分数。老是拖后腿，你就完了，自卑一辈子。读书好就会自信，情怀在手，班花归我。

二是娶媳妇。家里没有房子，读书好也可以。在姑娘们傻乎乎的时候，985文凭，可以抵得上一个六环房产证。

三是为了攀高枝。在成年人的世界里，你和土豪是没有交集的，但是，如果你家儿子读书好，土豪家的三姨太也会来和你搭讪几句。

四是为了快乐。青少年最大的快乐是，碾压同班同学。你要是初中班级期末考试一次数学98分，立马就快乐了。那些傻屌，一个暑假都不高兴。
