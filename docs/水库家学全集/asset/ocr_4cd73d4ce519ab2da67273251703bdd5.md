# 01

上叠好还是下叠好？

叠拼已经越来越多了，原因是容积率要求。现在住房用地，低于1.0的容积率已经基本不行了，前两年的老地块还可以，新的不行。

价格上，下叠比上叠贵一百w。这是通常情况下。先说各自特点。

一，送面积
下叠，地下室一般是两层，负一负二，带花园两个，一前一后，花园面积各异，一般不大，也就二三十平米。
上叠，送阁楼（隔热层）。三代人居住足够了。
上下楼，有室外物业电梯。

二，不足
下叠的地下室闹心。主要是返潮和渗水。实得面积大，装修费用高，阳光花园就是无底洞。
上叠的阁楼，太矮了，利用率不高，夏天热，冬天冷。

三，如何选择？
如果是中老年朋友，建议下叠，面积大，还可以种点花花草草，带娃方便。
如果是小夫妻，建议上叠，清净，干净，干燥。你也没时间晒太阳，修渗水。

四，提醒
这种房子一般是在郊区，以后卖掉比较慢，等半年是常态。
