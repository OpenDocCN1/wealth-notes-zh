# 本地人和外地人找工作。

很多士老板有这种印象，

一是本地人不努力。好像绝大部分本地人有房有车，不喜欢努力，上班就是混个保险，平时喜欢骂骂咧咧。

二是外地人太看钱。他们面临较大的生存压力，房租生活费，样样都要钱，就喜欢占小便宜。

有的公司只招本地人，有的公司只要外地人。我做了很多年的士老板，对于这个问題有比较多的认识，也给大家说，士老板和求职者都可以参考。

一是本地人适合的岗位。财务，行政，不太辛苦的技术岗，需要耐心的岗位。本地人最大的优点是人品端正，有家有业跑不掉，一般情况下，人在家门口不太愿意干坏事。采购可以交给他。

二是外地人适合的岗位，出差多，加班多的。他们一般没人做饭，也懒得买汰烧，如果公司提供晚餐，还是会愿意加班的。外地人最大的优点是，有逆袭的强烈要求，只要奖金多，愿意拼一拼。异地销售，半夜爬起来的技术维护，很烦人的售后，可以交给他们。

其实外地人和本地人各有特点，用好了都是宝贝，不要带有色眼镜。我曾经招聘了一个本地985，小姑娘，家里条件一般，工作很认真，但是心不在焉，她们希望进大单位。我还招聘过一个女屌丝，业务能力较强，加班加点不计较，但是只要有公司多出五百块她就不犹豫跳槽。

小结，本地人适合稳稳妥的岗位，外地人适合钱钱钱的岗位。

# 无用的新知识，本地人有沒有拼劲？

很多人误以为本地人没有拼劲，其实不是的。如果看奥数，本地人也很有厉害。我高中的时候就获得过市级数学竞赛鼓励奖🏅，几个小球甩来甩去，我也会做。本地人看上去懒散一些，实际上只是看不上那点小钱，如果年终奖是一百万，我管你是哪里人！
