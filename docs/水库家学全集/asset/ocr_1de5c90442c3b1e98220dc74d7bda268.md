问题是妈妈不会教。不要以为小学课本，你就会教了，没那么简单。现在的小学四年级五年级，好多题目是思辨性质，不是简单的加减乘除。一般家长，哪怕是高中毕业，也搞不定。

有一次，我亲眼见到他们是怎么教孩子题目的女。就是爸妈拿笔用一个大人会的办法演算了一遍，孩子看不懂，妈妈就打孩子。最后一起来，妈妈是心酸，孩子是愤怒。我知道，孩子到这个地步，已经没办法了。因为孩子接受的一个点一个点的知识，无法连接起来，考试换个题型就懵活了。累了一晚上，啥也没学会。

孩子的基本功很重要，建议，先刷一波基本知识，熟能生巧，再刷各种题目，不追求难题怪题，先考个一般高中再说。

+   1. 把各学科每个章节快速学一遍，一般有20%是孩子没学会的。

+   2. 先刷基础题，不要刷难题。

+   3. 整理错题集，经常看看。一个月通读一遍。

+   4. 半年后，把学校卷子撸一遍。

千万不要以为学校卷子没意思。这是老师们集精竭虑几十年题库积累出来的，含义丰富。一题一题仔细看，实在不懂的，找老师或者家教。必须搞明白。

这样搞，考个高中或者二本，没问题了。
