不要指望朋友。

绝大多数所谓的朋友，只不过因为你还有点小小的利用价值，亲威来往也类似。如果你没混好，人到中年，想找朋友帮忙，我告诉你，不要自取其辱了。除非你卖惨，人家同情你一把，到此为止了。真正的朋友有两种，

一是有共同的兴趣爱好。例如很多运动员能够保留一辈子的友谊，因为他们有共同的话题，都是共同感兴趣。

二是价值对等，部门经理和部门经理交朋友。小老板和小老板交朋友。大佬和大佬交朋友。可以是不同领域的，但必须有用价值，否则，很快就散了。

其他的，只能说是业务关系，认识他，知道这个人。酒桌上敬一杯的，效果就是等于零，百分百。

年轻人不要沉迷于攀扯关系，例如，他是我们村出去的，已经做到××位子了。你硬攀是没用的。还不如给人家还在村里的父母姐弟多办点事情，等价交换。

当年，我的朋友遍天下。原因有几个，一是我处于一个好位子，二是大方（老婆有钱），三是地处交通枢纽。几乎所有人，只要有小位子，无论你是深山老林，还是亚非拉，都会路过京沪，我就在这里。朋友来了，我是忙前忙后，买单安排，吃喝玩乐，接机送机一条龙。有个什么事情，我是出车出人的安排，特别是买房看商读大学。

后来，我从单位滚蛋了，也没很多资源了，很快就没朋友了。大家也不找我。我找他们，人家也不微。现在我成SB了。

如果换位思考，也的确如此。按照我接待朋友的路子，成本很高。

+   1，接机送机，两个半天。

+   2，买单安排，两千起步，大多数是三千一桌，饭店的酒水特别贵，他们特别能喝。

+   3，出车出车，价值一千。

+   4，办个事，成本精力，价值几百几千吧。

如果你已经没价值了，谁会理你？

这么多年，我在两个机场接待了无数朋友，又如何？没用。

至于本地朋友，更加搞笑了。我辞职后，99%的人都不联系我了。平时那个热情啊。后来，我找了个理由，大家聚一聚，我自以为最好的朋友都不想来。他们以为我将要去求他们什么事情，避嫌。

后来，我也想通了。朋友就是对等交往。没价值了，就不要往前凑了，人还轻松点。
