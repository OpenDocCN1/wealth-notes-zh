# 11

成功的难点。

白手起家，从无到有。要经历三个阶段的考验。

第一阶段是胆大。白手起家，啥也不会，你敢投入身家性命，职业前途去某个生意赌一把？一般人不敢。99%的人会去找一个旱涝保收的小工资，刻苦钻研劳动法，生怕吃亏了。

第二阶段是智慧。小公司起步了，经过两三年，居然没有垮，还慢慢起来了，各种各样的破事烂人也见过了。接下来如何做大做强，就考验智慧了。

第三阶段是胆小。你已经几个亿身价了，如何稳住盘面，谨慎推进，就必须放弃一切杂念，平安降落。
