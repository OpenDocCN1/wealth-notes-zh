# 大平层

一般有四个房间，三个厕所，一个比较大的客厅饭厅。就这么点小地方，人一多就转不开。但是，大平层也有优点，

一是容易和家人互动。住别墅，我就是吃饭的时候，能看见娃，平时看不见。

二是购物方便。在乡下，吃不到油条豆浆。买菜都是手机叫上门。大平层比较方便，买个东西，下楼就不远了。

三是上班上学近。市中心人口密集，单位学校多。

现在的很多郊区，类似于00年代的浦东张江，光秃秃的，看不到什么人，道路挺宽，就是没什么东西，土方车来回呼啸，绿化率特别高。一到夏天，知了叫个不停。邻居大叔还在小河里钓鲫鱼，一天也能钓几条咪咪小的鱼儿，晚上油炸一下，炖个鲫鱼豆腐汤，撒一把自家种的葱花，味道鲜美。附近一公里才有个大卖场，老子懒得去。

大平层里，大家各自关闸门过日子。乡下房子比较好玩。小娃娃互相窜来窜去，其乐融融。大人们互相攀比，张家伙种了月季花，李家妈妈种了康乃馨，隔壁小媳妇种了玫瑰花，互相都知道，女人们互相说自家庭隐私。我家隔壁的老两口，原来是静安区的退休工人，因为女儿女婿有钱，全家卖掉两套老房子搬到这里来了。住在阁楼，老两口感觉很幸福。这辈子终于住上了电视剧里的大别墅。隔壁老太婆把菜嫂家祖上三代都研究了一遍，结论是菜菜福气好，找了个有钱女人。我日他全家。

上山容易下山难。

住了半年别墅，再回来住大平层，已经不习惯了。主要是两个原因，

一是保姆做早饭的声音。早上九点多，保姆开始忙了，叮叮当当的。

二是娃要上学了。叽叽哇哇的。

三是楼上邻居电视机声音哇哇啦啦的。

大平层互相干扰多一点。别墅相对比较好。我住一层，保姆一层，互不干扰。早上小娃娃下楼后，就清净了。

感谢菜嫂这个250女人，非要买个乡下房子，现在住住也习惯了。如果不是天天上班，可以考虑买个乡下房子。
