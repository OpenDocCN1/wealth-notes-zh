# 怎么学会说话

> 你说话的目的是让别人产生相应的反应，也有少量的发泄情绪，炫耀一把。我在这个方面吃了大亏，说话不太考虑听者的心态。教别人赚钱发财工作升官发财，一定要注意说话的方式。穷人的心态是，“我宁愿穷八代，也不想听你这么说话。你以为有几个臭钱就摆老资格了？老子就是不喜欢听，滚吧！”

我以前因为这个细节得罪了很多分公司经理，现在他们都锦衣玉食，宝马别墅了，但是心里真的很恨啊，当年在我这里学手艺真没面子。“现在混好了，那是自己有本事，不欠我一毛钱人情。”不仅仅是下属，就是亲人也是这个样子。

教人本事，都是很难受的，如果你看一个人特别顺眼，对方肯定是在扭曲自己，讨好你。一个正常人的言行，都是以自己为中心的，不可能会让别人特别舒服的，人家讨好你，无非是要搞你点钱，也正常。
