# 08

对高科技城市要理性看待

因为我和莱嫂都是高科技城区长大的孩子。七八十年代的高科技和现在不一样。那时候的高科技是：万人大厂＋医院＋研究所＋子弟学校＋一切生活设施，大型综合体，什么都是最好最新的。

大企业钱多，福利非常好，楼上楼下，电灯电话，是周围农民嫉妒羡慕的单位。在大家还把电视机电冰箱当做稀罕物的时候，我们那里已经普及到了99%。我现在四十出头了，幼儿园就用上了管道燃气。我初中英语是一个985副教授补习的。当年，他住外地，听说这里条件好，千方百计调过来，起初两年无所事事，就给我补补课。你说先进不先进？

但是，高科技有个特点，周期性明显。在初期十几年，那是金子做的厂，但是，这么暴利的生意，各地都想做，随着科学技术的普及，大学生越来越多，慢慢的也就平淡了。

我家那个地方，辉煌了三十年，莱嫂家那个地方差不多。现在那里已经没什么感觉了。周围的农民富裕了。厂子已经老旧了，当年的大学生已经退休了，厂子效益越来越差。

高科技扛不住三十年。想当年，一个黑白电视机就是全家的骄傲，甚至是一栋楼孩子的骄傲。谁家有个体白电视机，谁家孩子就是豪二代，因为他不让你去看电视，你就傻逼了。现在，一个液晶大彩电都是不值钱的小东西。

当年，我们厂子里，清北复交也不少，现在也就是路边小公园几个下象棋的老头。我第一看《少林寺》就是在厂里，不要钱，爽吧？附近的农民，若能有一套我们厂子的工作服，会高兴的跳起来。

三十年河东三十年河西。现在的老职工子弟，飞一样的跑了，再也不想回去了。因为那里找不到钱。与此同时，当年引以为傲的小区，现在年久失修，房型差，距离中心城区远，不方便，已经无人问津了，根本卖不掉，出租也就是每月一两百元给一些菜场鱼贩子，菜贩子。

三十年是一代人，买房要考虑下一代。
