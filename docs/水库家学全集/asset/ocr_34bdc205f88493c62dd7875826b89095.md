# 孩子如何成才？

我知道看我微博的有一些土豪，也有一些上班族。很多人苦恼子女读书不好，急得直跳。各种各样的网课辅导班，报了一大堆，基本无效。我先说一个我们家老人告诉我的老故事。

上海有个纨绔子弟，一大堆家产等他长大后续。这小子不学好，怎么揍也没用。他有个业余爱好，在家里偷老爸的小金条。很多人没见过小金条，我和你打个比方，长方形，比麻将牌小一点，一跟31克。

他老爸发现之后，以为是老婆偷的，就藏在小箱子里锁了。这小子居然找了个师傅，专门学开锁，越学越有兴趣。后来他老爸生意失败了。这小子居然自己开了一家锁厂，又混成小老板了。

把兴趣发展成为事业，是以前很多土豪家庭育儿的一个办法。例如，书画，集邮，古玩，甚至跳舞，听音乐。人有个特点，只要是他喜欢的东西，就会钻进去研究。如果你给他填一把火，大概率就成功了。

我读初中的时候，班级里有个差生，从小喜欢做飞机轮船的模型。这玩意特别花时间，寒暑假玩一下就完了，但是他玩上瘾了，功课就顾不上去了。前不久听说，这周丝也发财了。你想不到他做什么，他居然专门给售楼处的沙盘，美轮美奂。

小结，如果读书实在是读不下去了，就发展一个爱好，哪怕是拍照。
