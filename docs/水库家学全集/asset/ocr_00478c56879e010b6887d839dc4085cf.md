# 为什么企业不怕打官司？

一般企业都有法律顾问，法律顾问往往赠送打一个官司。打官司是法律顾问的工作，反正企业的钱也花了，让他去打官司吧。老板也不操心，打十年官司，老板也无所谓，企业是原告，就算输了也没什么损失，但是要是赢了，就是意外惊喜了。

法律顾问喜欢打官司。因为法律顾问还要做明年的单子，一旦给你打赢了官司，就是一个巨大的广告，我厉害吧，明年记得来找我。

很多hr，推事，图省事。遇到一些疑难杂症，hr不是想办法解决，而是说，“你的事情太复杂（我也搞不懂）你去打官司，赢了说明你有道理，企业就赔钱给你。老板那里，我也好交代。”
