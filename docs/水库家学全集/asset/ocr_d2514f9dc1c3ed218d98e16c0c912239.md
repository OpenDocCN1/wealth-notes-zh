# 再说一个破事。

我们小伙伴里有个叫“草狗”的负二代。看上了一个售楼小姐。人家不理他，意思是她有35套指标没完成。这下子我们

也为难了，总不能为了你泡妞，我们去买房子吧？

后来，我们也想了个办法，在各自老爸的公司财务科门口贴了个广告，本公司员工买xx小区房的找xx工号，优惠五万

（实际上就是售楼员的权限），一个星期就卖完了。草狗和新女票，激动的设置三天，喝完狗爸爸的小拉菲去唱歌，答谢

我们这群贵宾。我也不知道售楼员能够拿多少奖金。反正看上去很激动。

# 命运往往是一瞬间改变的。

我买房，一般只考虑十分钟。因为售楼小姐有绝招，“就剩这一套了，买不买你考虑一下”。她是为了防止你看花眼

了，犹豫不决。但是，这个决定关系到你几十年。有时候没办法，就是跟着感觉走。上一次，被售楼小姐忽悠买了一个楼

王也不是我希望的，但是住了也不错。
