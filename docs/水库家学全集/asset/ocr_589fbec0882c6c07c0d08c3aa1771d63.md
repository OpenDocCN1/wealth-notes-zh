# 03

我年轻时候，从来不参加聚餐。

也不是没钱，主要是几个原因，

一是没有公交车。我当年租的地方，没有公交车，有点偏，因为房租便宜啊。天一黑，就只能打车了。打车是25分钟，如果倒车，就是在风里折腾一两个小时。打车是14.4元起步价。我们当时工资也就一两千，实在是舍不得。

二是剩菜打包。同事们很鄙视我的困难条件。聚餐喜欢给我打包，就是把剩菜剩饭一股脑儿倒给我。我没有冰箱，实际上拿回去也没用。但是，架不住大家热情劝啊。有一次，我打包了一个酱肉，回来放在水泥地上，我房间没有桌子板凳，也没有冰箱，第二天，餐盒上爬满了蚂蚁小虫，我伤心极了。怎么混成这样了？

三是没衣服。大家聚会一下，总要穿的干干净净，光鲜亮丽一点。但我没有洗衣机，出去一次，回来就要手洗衣服，特别是冬天，冷水手洗衣服，冻得直跳，实在太累了，受不了。

那些年，我无数次的想回郊区，那里什么都有，还有中学女同学暗恋我的，生活好多多了。可当年，我实在是舍不得离开内环线。这么多年读书，考上top1，就是为了跑出来，现在回去算什么？痛苦啊，纠结啊！一切的转变是遇到了莱嫂。你不知道，倒插门有多开心！

小结，人生没有一成不变的困难，放下面子，放下心结，豁然开朗。
