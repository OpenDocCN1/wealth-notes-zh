# 06

为什么我们的就业率这么丰富？现在农村没有什么青壮年了。

很多人不知道，九十年代的时候，内地好多地方，要想找个平均工资的工作，那个难度不亚于你去参加奥数选拔赛。我有个江西同学告诉我八九十年代，他们那里农民找工作的行情，听的我后背冒汗。这才短短十几年，就业环境已经天壤之别，贴瓷砖收入超过大学副教授了，我对副高的怨念是经久不息的。

主要原因是m2。飞流直下三千尺，疑是银河落九天。有了钱，就搞工地！到处都是小旗飘飘，小队长吹着哨子指挥挖掘机。工地是劳动密集型，有多少人就敢要多少人。于是，其他行业，特别是小老板那里，招工越来越难了。工资飞起来了。

工地花的是新钱，滚烫滚烫的。小老板花的是老钱，臭烘烘的馊气味还在上面。老钱是有限的，比不过新钱。新钱波涛汹涌，横冲直撞，人仰马翻，形成了新的商业格局。这个格局是以现在的货币速度为基础的，各行各业，欣欣向荣。开心啊。
