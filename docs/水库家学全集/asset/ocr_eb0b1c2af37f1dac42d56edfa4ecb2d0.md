# 二手房能不能停止代款的理论研讨。我尽量用委婉的方式来研究。

01

楼市需求还有多少年？

任何需求都是有饱和的一天。你曾祖父有没有给你留下一套三居室，就是关键了。

现在的年轻人结婚，一般需要婚房，男丝丝愿意将自行车接新娘到出租房，用手机拍婚纱照，在门口小餐馆摆喜酒。但是，女丝丝一般不愿意。

现在人结婚时候，父母还没退休，也就是说，指望继承婚房是不现实的，一般是曾祖父这一代能留给你一个婚房，基本差不多饱和了。

以我的观察，35-65岁这几代人，基本上解决了住房。但是，还不至于富裕到有房子留给第3代。也就是说，需求还没有饱和。

我对继承房子有过观察，完整拿到一套房子的，目前罕见。因为1980年以前的人，绝大多数是多子女家庭，一般做法是卖房分钱，或者老头留给后面那个新老婆。如果老太熬到最后，大概率是卖房去养老院了。现在家庭，很少有子女会留在家里服侍老头老太的。

我仔细梳理了历来我家长保姆的情况。大家不要笑。保姆属于高收入的农村群体，基本可以代表农村富裕家庭。他们一般在二三线城市或者老家小县城，给儿子置办了一套。但是，没有能力给孙子置办了。

很快的，再过20年，孙子的需求就来了。这时候，孙子不会回村里了。回去也没用，他们连稻谷和高粱也分不清了。这时候，孙子对婚房的需求，你看怎么办？

02

小县城的房子。

可以比较肯定的是，附近农村人去小县城买房结婚的浪潮，基本结束了。我问过很多保姆，他们村里，有能力在小县城买房的家庭，基本都买了，基本在70-100w左右，一般是三成首付，月供3-4000，还可以承受。没有买的人，近期一般也没什么能力了。

今后，小县城的购房主力是两波人，一是大城市的卢慧，二是新生代农民工。
