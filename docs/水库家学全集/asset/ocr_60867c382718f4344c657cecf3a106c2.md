# 09

亲戚找你，总没好事。

如果亲戚升官发财了，不会联系你的。一是有地位了，怕人来求他办事，烦人。二是发财了，怕人来借钱，烦人。大家索性不联系，最简单。等到穷亲戚打电话来了，十有八九是要你出钱，要你出力，这是我几十年的经验。

大部分屌丝把亲戚朋友当做自己最后的底牌和资源，想着万一今后有什么困难，还有这么多亲戚帮忙。实际上别人也不傻，没人对一穷二白的你感兴趣。我读大学的时候，大学生还很少，亲戚认为我今后会飞黄腾达，对我很热情。最后让他们失望了，我还没毕业，就扩招了，文凭和废纸差不多。后来所有的亲戚朋友家都有大学生了，对你也不感兴趣了。

工作很多年后，亲戚们希望你帮助他们办事，特别是给他们子女找个正式编工作。实际上我没有这个能力，渐渐的，我就剩下随礼和逢年过节赶礼的功能了。为了这些破事，我投入了大量的时间精力金钱。以前交通不便，我也穷，骑个自行车给亲戚送金鲳鱼大原油。有一次，我还摔了一跤，当场就哭伤心了。单位里发了什么东西或者联华ok卡，我就盘算送给哪个亲戚。实际上人家也没把你当个事情，就是吃席多双筷子。

后来，我有个破事，想去借三万（那时候内环线单价1万），最好的亲戚只借2千。我是悲愤交加，一怒之下，倒插门了。后来，我苦心经营塑料桶，终于发达了。亲戚们认为，你发达了，又不会送钱给我，有什么用？我再次绝望。

亲戚也是马路上的普通人，年轻人不要对他们有太大的希望，相反，他们还希望你飞黄腾达给他们发福利。最好找个银行的正式编。你最要紧的是，多加班，多攒钱，早点买房。
