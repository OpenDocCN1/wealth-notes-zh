# 为什么珠宝首饰不流行了？

前两天看琉璃厂的一个老片子，一个破烂古玩要一万大洋，与此同时，一个小伙计的月工资也只有8个大洋。也就是说，在以前，最值钱的东西，一是房产土地，二是金银珠宝。斗转星移，很多人问，为什么现在珠宝首饰不那么流行了？其实这个问题很简单。

一是没有市场，没人买的东西不值钱。珠宝最大的难题是，难以辨别真伪。现在的技术已经可以人工合成钻石了，怎么鉴别真假。从来没有听说哪个电影明星去买一个几百万的珠宝的。或许有，但很少。买房的倒是比比皆是，随便问一个都买了。

二是现在金融制度必须剔除金银。金本位早被扫入历史的垃圾堆了。现在货币的理论基础就是不能和金银挂钩，否则，没办法处理了。

三是招人恨。金银珠宝没有实用性，只是炫耀的工具。这怎么可以？二本子岂不是跳起来骂了。好好好，那就不玩了，你开心了吧？古玩字画虽然不行了，但毕竟是文化人的玩意，还算流行过几年。

金银珠宝，特别是金银，在全世界已经不流行了，只剩下做电子元器件的功能了。不要想入非非了。依房子买好了伐？
