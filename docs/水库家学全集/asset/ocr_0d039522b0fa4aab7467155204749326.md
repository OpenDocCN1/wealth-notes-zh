# 货币政策如何影响小微企业？

一般情况下，几条枪的小微企业是不可能银行贷款的。原因很简单，没有抵押物，各种资料也不全。小微企业能不能把资料做到美轮美奂吗？不可能的。因为要做出这些优美的资料，至少要招聘两个会计专业大学生，规范成本几十万，你卖个下水管也要记账。一个装修队的包工头哪有这个能力？

那么货币政策对小微企业有没有意义？有，意义很大。小微企业的生存，不靠贷款，而是靠客户。客户有钱消费了，小微企业就活了。装修工养活了门口的建材店和大碗面，货币政策首先收益的是大单位。大公司的员工买房了，就要大巴花钱。木地板，水泥，瓷砖，家具，电冰箱，还要买件新衣服请亲戚喝酒，连小杂货店也可以挣点烟酒钱，各行各业就火的一塌糊涂了。农民工可以回县城买三室两厅了，又是大把花钱。
