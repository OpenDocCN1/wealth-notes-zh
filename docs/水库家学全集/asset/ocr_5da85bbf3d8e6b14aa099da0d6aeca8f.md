# 培养孩子什么？能在将来的竞争对手中脱颖而出？

财上海微博 2020-01-10

01

高考作文。

上海春季高考作文出来了。和我以前分析的一模一样，出一个大的无边无际的作文题目，类似于时光情怀，某个哲理。

设计这种题目的目的在于，确保课外辅导班不可能事先押题，也让学可以写几句，拿个基本分。但是，对于我们要考985的同学就不太容易拿高分了。因为你可能一上来就蒙了，千言万语在心里，就是不知道怎么写。

这种题目怎么写，我以前教过多次了，弄几句古文开头+从题目中拉出一个句子，接线头+联系一个大观点。

当前什么观点最热门？大家心里明白。总分总，再收个尾。妥妥的没毛病
