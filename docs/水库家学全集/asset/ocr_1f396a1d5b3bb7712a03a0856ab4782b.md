# 12

村花的苦恼。

菜菜，我是村里的漂亮姑娘，21岁，从小没干过农活，白白净净。高中没读完，现在老家县城当营业员，月入3000-3500元。

今年过年，我们村有个以前考出去的985，因为离异（无娃）想回村里找个对象。他经济条件很好，月入两万，在二环线有个三居室，据说价值600个，还有个挺好的车。他就是岁数太大，32岁的老头子了。我是有点贪人家的条件。他这个条件，我周围根本没有。

我周围都是农村娃。高职大专，在一个小公司月入三四千，在家咱老的比较多。你看能不能给我说说？

答：不要找这种三十多的老头子。找个差不多的农村屌丝，不香吗？有情饮水饱，不要为了钱而放弃人生。农村娃怎么了？不就是喜欢打老婆吗？现在也不是经常打了。忍忍就好了。

# 13

穷比的痛苦。

我以前是24k赤果果的穷比。我非常知道穷比男是什么样子。莱嫂一直说，我以前虐待她，我不是很理解，后来慢慢懂了。穷比男的特点，

+   一是抠，对自己抠，对身边的人也抠。我和莱嫂出去吃饭，就喜欢硬拉老婆往小饭馆钻，因为便宜。

+   二是要面子。不管什么事项，我超级要面子。为了面子，我不能容忍任何人说我不好。慢慢的就封闭自己了。谁要是说我不行，我就暴跳如雷。敢说你不好的，实际上都是亲密的人，我就把亲人们都得罪了。

+   三是酸。我看得出别人超过我，心里嫉妒心那个大啊！因为嫉妒，我已经不能宽容的看待世界了。

+   四是算计。这是穷比男的通病。没钱就要节约，一分一厘，来之不易，不舍得点花吗？于是，我成了一元店的超级VIP，浑身上下弥漫着廉价商品的独特气质。

+   五是脏。因为条件差，我们洗衣做饭，个人清洁，打扫屋子就好累，什么都不方便。时间长了，就不想搞了，人变得很懒，浑身脏兮兮的。莱嫂说我脏的就像是垃圾堆里拎出来的！
