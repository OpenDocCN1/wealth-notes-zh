# 07

站在别人的肩膀上。

我很佩服隔壁老王的思维。我是top1，隔壁老王是个土老板，电脑开机都不会，手机到现在还是用老人机。一天到晚就喜欢看前台妇女扭来扭去，悄悄流口水。为这个事情，他老婆经常在公司里和他打架。但是，这么多年下来，风风雨雨，和我一起做功成身退的就只有他了。

我们是二十几年前一起在行业协会吃牛认识的，那时候，我和他都是烂屌丝，他没事总来找我聊啊。后来几次个人腾飞的大动作，主要是买房买地，他也跟上了，现在富得流油。我们关系不错，有一次，他老婆非要开除他相好的前台，他就把那个前台送到我公司上班了几个月。我当时恨不得也去用一下。

他告诉我一个秘诀。他不研究事情，就研究人。他说：你是大学生，念书多，我也没文化，你让我看经济学，我也看不懂。但是，我有个绝招，你菜总干什么，我也干什么，等于我也是top1了。"娘希匹。

买房买地，我买了，他立马就跟着买在我隔壁。我坚决不参与劈兔匹，他也不参与。不搞多元化经营，他也不敢做。这么多年下来，发财的好事他都赶上了，毁人的坑，一个也没参与。他的子子孙孙，小三小四，对他崇拜的五体投地。等于我给他免费打工二十年了。他经常说，如果你也看错了，我自己判断也不会比你好到哪里。这货真是个人精。

结论：当你拿不定主意的时候，就看看牛人在干什么，抄答案就是了。
