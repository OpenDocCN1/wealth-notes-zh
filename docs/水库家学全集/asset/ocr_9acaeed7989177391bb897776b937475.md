# 01

妹纸崩溃了。

菜菜，我是妹纸，从小到大一直都是三观正。大学毕业，再苦再累我也自己扛。最近精神崩溃了。我女同事，小美，臭不要脸的东西，一直找前男友要礼物，被人甩了无数次，就是个破鞋。最后，名声臭了，只能在行业外嫁了个二婚大叔。

实在是没想到，这个傻帽大叔居然很有钱，住的是内环钱大平层，价值2600w，我在网上查了，他还给小美买了个小benz。其他各种小东西，不计其数。估计，仅仅是打扮，里里外外不下80万。现在，小美一身的珠光宝气。

本来，小美卖比搞钱，我也不羡慕。没想到，由于她这一打扮，销售业绩突飞猛进，提了部门副总，成为我的顶头上司了。我们实在无法接受了。我那个男票，除了油嘴滑舌，啥也没有，我们都25岁了，还在出租房死撑。想买个车，没地方停车就算了。我们老实人就该这么惨咯？你说我今后该怎么办？

答：不要羡慕人家发财，修身养性，淡然处之。

# 02

妹纸问怎么办？

菜菜，我是外来妹纸，也是贞洁烈妇，没有什么破事。我们公司安排了一个三居室给我们外地员工。我是销售部副经理，住了一个大单间还有单间厕所。

我男票半年前来看我，见我过得不错，也想来内环线发展。两个月前，他就回老家辞职，直接来了。我看他来了之后，非常高兴，激动的哭了。我是公司的主力骨干，经过公司同意，他就搬进来和我一起住一个房间。

没想到，他住上瘾了。我所在的小区，是高级小区，家里还有两个保姆，一个是做饭，老板和我们一起吃饭。一个是保洁钟点工。因为我们白天上班，我男票就一个人住在这个小区。晚上，我们几个同事一起看看电视剧，打打游戏，还有女人，也挺快乐的！他在这里住得好，吃的好，用的爽，还不干活，不愁钱。相当于过上了大少爷生活。

我一开始的想法是让他过度一下，赶紧找工作。没想到，他对找工作不感兴趣了，就想在这个小区里住着，吃喝玩乐。由于他整天无所事事，就在小区里闲逛，还认识了几个少妇。有的老太婆以为他是未婚小伙子，年纪轻轻就住这么好
