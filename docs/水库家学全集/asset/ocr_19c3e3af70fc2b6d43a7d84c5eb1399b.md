# 我以前不理解什么是功高震主？

当老板了这么多年，终于理解了。一个人在公司里太优秀了，业绩太好了，老板就不喜欢了。因为一旦你要是 有异心了，公司损失就大了。要是不断的给你加加好处，公司也受不了。

我以前有个员工，有一年业绩特别好，开始翘尾巴了，什么事情都要争一下，我恼火了，索性不理他了。他就开始挖墙脚了。拉拢员工准备出去单干。

我基本看透了他的想法，就把其他内容捂得紧紧的，不让他知道。后来他真的出去了，客户是挖墙脚，员工也是挖墙脚，但是他漏了一个项目，原材料渠道，结果被供应商骗得七荤八素，一年就把窟填赔光了。

功高震主的意思就是，你太厉害了，就会想法多，要自立门户了。老板就开始提防你了。
