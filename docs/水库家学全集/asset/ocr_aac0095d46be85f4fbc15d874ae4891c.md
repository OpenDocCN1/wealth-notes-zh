# 10

五星级。

前两天，王老板和我商量个事情，一起去外地盖个五星级，预算16亿，我出3个亿就够了。我兴高采烈的就去他家商量事情了。我最喜欢去他们家，因为他小姨子实在是漂亮。

王老板年近60，还老当益壮，天天个帆布鸭舌帽，冒充50岁。前不久收了一房新的。那个小红没房子，就住进老王的大房子了。小红和表妹在大城市相依为命好几年，关系特别好，所以表妹也死皮赖脸的住进来了，小红给她分配了一层，和保姆一层。小红的意思是，女大不中留，留着也是个祸害，最好把她推销出去了，也找个大户，以后还能走动走动。

她表妹有个绝活，唱歌特别好听。我就愿意去听人家唱歌。只不过，不好意思经常去。老王给我这么个台阶，我也有借口乐呵呵的去了。

包郊区有个小商品基地，以前是个小镇子，随着客商多了，镇子上最好的一个四星级也不够用了，好几个老板就研究搞个五星级。老王听到风声了，希望拉我一起上。我就装模作样的和老王研究。小表妹经常给我们端茶倒水的。

老王意思是，大家一起签个合同，正式搞起来。说心里话，我最喜欢的倒不是签合同，而是和老王开车去考察。一路上听听小妹的歌声，又有采暖的考察经费，我实在是开心。
