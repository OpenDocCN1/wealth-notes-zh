# 省会

省会分为很多档次，有一类是低价房省会。优点和缺点一样突出。

优点是，房子便宜，安居乐业，鸟语花香。我曾经去过长沙，株洲（省内第二批次），房价那个低啊，优点很明显，而且环境很好，居住舒服。早上起来遛个弯，绿树成荫，吃个花生牛肉米粉，好惬意。省会的医疗教育也是很不错的。

但是，这类地方有个明显的缺点，找工作不容易。低房价地区，普遍工资低。杭州相同的岗位，一般只有上海的七折工资，但是，日常物价差不多。

现在的日常生活用品，都是全国性大品牌，例如牙膏牙刷洗发水，啤酒可乐矿泉水，都是大品牌，全国各地的价格差不多。如果到手现金少，生活品质就差。康师傅就出现了。

我去山西旅游，当地导游愤愤不平，同样是打折的名牌，京沪的打折卖场，尺寸全，品种多，太原就差了，都是京沪卖不出去的，再拖到太原，看的就生气。为什么？很简单。因为价格。

同样打折，京沪顾客手里有钱，一口气买三件，一拿就是好几件了。拉到外地，顾客没钱，千挑万选买一件。商家自然愿意在京沪卖了。

总结：房价的决定性原因是，当地的工资。有的地方阶段性跳一下，逃不脱规律。
