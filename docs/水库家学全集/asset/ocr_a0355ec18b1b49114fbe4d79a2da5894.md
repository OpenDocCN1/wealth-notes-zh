# 楼市的本质是配套。

现在的社会，不缺盖房子的地，云贵川犄角旮旯都是山地，随便找个不停，三通一平就可以批量生产避暑山庄。他们就像卖冰箱彩电洗衣机一样的卖房子。但是，绝大多数房子，就是房子，不要想其他的，就和我们老家村里一样。村口一个小卖部，天黑回家看电视。

人买房的目的是生活，不是一堆砖头就行了。生活就要配套。吃喝拉撒玩，交通通讯购物，一样不能少。更高的要求是医疗教育，保值增值，就业发展。

如果按照这些要求看，楼市的范围就小多了。再要考虑个人发展，就剩下几个大城市了。

楼市不是砖头＋水泥，楼市要的是配套，最好单位就在附近。如果你财务自由了，我不建议去澳加薪，你就回老家也不错。小别墅＋x6＋KTV＋女经理谈谈人生，没事的时候看看电视剧，去医院也会说人话，关键是吃的顺口。肥西到肥东，买只老母鸡。

# 我是如何在外环线过冬的？

京沪不错，就是冬天冷。但是，办法总比困难多。最新办法就是地暖，绝大部分地暖需要提前一两天开。今年初的冬天，我就在外环线扒窝。地暖打开，气温度计显示室内26°，白天一套毛衣，晚上薄被即可。

虽然比不上内环线方便，但多一千元快递费肯定够了。一切都网购，从买菜到买肥皂。家附近也有大超市，一个月去一次，因为停车麻烦。温饱解决了，接下来就是开心过日子。
