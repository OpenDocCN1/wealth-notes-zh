# 用好暑假，进入班级前五名

我小时候是当之无愧的学霸，校长爸爸的宠儿，我们那时候叫做“尖子生”。我的考试成绩一直是遥遥领先，而且是班级里的答疑小能手。一天课下下来，别的孩子还没搞懂课本，我已经可以给大家上课了。很多人以为我是神童，一听就会，实际上不是的。我有个小妙招，用好寒暑假。

暑假就要来了，你家娃，做好这几步，包你下学期，笑到霍是你妈！

+   1，找全下学期 的语数外物化课本。
2，认认真真学一遍。不仅仅是看，而是学，程度是把课后小题自的飞起来。
3，把英语课本单词背一遍。
4，暑假作业不要做。

九月份，当你的同学还在为新课程发愁的时候，你已经可以攻坚克难了。如果你家娃精力旺盛，那就多搞几遍，我包你满意。

老师会不会看暑假作业？不会。

这个问题，我一直好奇了很多年。现在，我的娃也上学了。基本解开迷题了。

老师肯定不会看，最多是大概翻一翻，娃有没有写？而且也不会全部翻，可能是选择性的抽几本。原因，

一是没有时问。老师刚刚开学，也挺忙的，哪有时间来看这个？

二是这么多年，我从来没有听说过哪个娃因为暑假作业做错了而被批评的。

三是暑假作业一般是送到办公室，堆在一个小角落，如果正儿八经批，不可能是那样的。

唯一要防备的是，有的老师会抽几本看看，有没有全部空白？我相信，你娃有办法，提前一天解决这个问题。呵呵。
