# 05

逼孩子。

我现在已经是小学生家长了，感觉自己很厉害的样子。每次送完娃回去，在家里噔门也大了。前不久，在学校门口的马路上，遇到两个娃的同学家长。这几个家长有远大的目标。他们自己住在老破小里，省吃俭用给娃报了五个补习班，语数外，国际象棋，音乐。我差点唇古七，她们想干嘛？

五个补习班，四个都是高强度脑力运动，一个是极其枯燥的《玛丽有个小羊羔》。孩子已经被折磨的面无血色。她们洋洋得意的告诉我：补习班老师说了，每一个兴趣班都有非常重要的意义，可以改变命运。你日十八次！你自己干什么了？房子买好了钱？

很多家长孤注一掷，把买房子的希望寄托在孩子身上，这是很可怜的幻想。这些孩子今后又能怎么样？还不是和我当年一样，被家长扔到内环线就不管了，我当年租在阴暗潮湿的棚户区，遭受了巨大的心理创伤。最后也什么没办法改变。我从来不逼孩子，我告诉孩子，你爸已经彻底拼掉自己了，就为了给你一个起点，你已经站在终点线了。做事情，不要急，慢慢来。以后找个对象，好好过日子就行了。

成年人不要逼孩子。你能不能逼一下自己？你敢不。因为你好吃懒做。
