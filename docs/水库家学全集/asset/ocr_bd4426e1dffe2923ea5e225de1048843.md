# 躺平和教育。

财上海微博 2021-05-29

01

一个博士副教授的收入，可能比不上一个卤鸡爪的小贩。

很多人可能愤愤不平了，老子容易吗？一路考研，博士读到 32岁。歌德，苏格拉底，无所不知，凭什么是这样？亚里士多德听到这个消息，都要气的都要从地中海浮上岸了。

实际上，这是很正常的，天天发生的。因为供求关系。你知道歌德并不能给别人带来真正的意义，大家自然喜欢鸭脖子了，“老板，重辣。”

绝大多数人的有效时间很短，一般是26-35岁。过了35岁，基本是靠经验和管理混饭了。所以，你要在35岁以前，找一个自己看好的领域，疯狂投入时间，练就一个熟练工，以后好混饭。

这就有个冲突点了。练技术和找老婆，怎么平衡？很简单！让你爸把房子买好，你去相亲，也不要太挑了，好用就行。

热门评论：

> 周大强夫斯基：副教授一周八节课去学校两趟就行了，然后天天在家睡觉吃卤鸡爪，五险一金有万把块退休金，小贩天天风吹日晒雨淋没有任何保障，岂能相提并论？

> 不能乱用：各有各的不同，卤鸡蛋的小贩不出工就没收入，鸡蛋卖不完就得自己吃完，教授下雨天在家睡觉也有工资，但也会为写不出论文半夜抓头发。小贩辛苦一点可以提前把后面20年的钱挣了，教授退休后人生才刚刚起步。让人迷的话多数还是会选教授吧

> 番茄鸡蛋小丸子：不要这么嘲讽副教授，社会地位比卤鸡爪小贩高多了？收入也不会低多少的

> 马已限了99t：单纯比收入是不讲武德！况且卤鸡爪与副教授收入持平甚至更高，但生活质量可是一个天一个地，还有社会地位，隐性福利，社交福利，家人陪伴。打个比方同在深圳你做码农收入30个w，需要996但深圳的公务员收入30个w只要朝9晚5带各种法定节假日。

02

燕窝外卖。

你听吓一下，可能觉得是个神奇的操作。对面是个富人小区，一共近万人，如果这个小区的人，一年买我两次尝尝，我就发达了。我有个熟人，小区里的樱花妹妹，前凸后翘，找了个马莎拉蒂男人，这女人不服气，非要创业，就开了一家燕窝外卖店，单价是108元/份。可惜，一年就垮了，现在一天到晚被男人骂的像个小媳妇。

燕窝生意的第一个要素是信任感。由于假货问题，为了获得信任感，她砸钱在小区附近开了个实体店，里面堆满了各种燕窝，各种品种，可以堂吃。她开实体店的原因是，希望每天面对面向小区邻居介绍生意。

燕窝的第二个特点是高贵。你总不能在卖啤酒矿泉水的破环境里卖高级货吧？于是樱花妹妹又砸了几十万装修款，富丽堂皇。
