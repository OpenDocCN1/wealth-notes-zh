# 【财上海：屌丝出身】

![](bbox=[0.48, 0.07, 0.52, 0.09])

刚才我又愤怒了。

保姆请假回去了，那个母老虎让我去研究一个德国洗碗机。我看了半天，实在是无法理解。居然没有start按钮。于是，我翻箱倒柜找说明书，一身汗，我已经火大到要砸机器的程度了。最后发现，start按钮和另外一个按钮合并了，所以找不到。

德国电器的设计思路是，用最少的按钮，实现最多的功能。这就导致了人工操作的复杂性。这个洗碗机有八种洗涤模式，还可以调节洗碗机里面的灯这种无聊的功能。看上去好洋气，但是对于我们这种中老年朋友和农村保姆就是灾难片了。

我以前用过国产洗碗机，特别简单。
