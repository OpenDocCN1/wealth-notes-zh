# 04

每一代都有逆袭的大通道。

+   * 70后是媚房。
* 80后是考编
* 90后是码农。

这些东西在当时都不稀奇的，只要下决心，二本子都可以搞定。但是，在当时的环境下，你就没这个意愿。为什么？因为你看不透新路子，最后就只能找个最保险的门道走下去。我再讲一遍，经济学的老祖宗是财政和就业。一切问题最后都是围绕这两个搞的。

接下来，你就开动机的小脑瓜想想，有什么办法拉上去？你的思维无外乎课本里那几个办法，人家搞出这个办法，屹立几百年不倒，不是你能够轻易改的。
