# 04

985学历值多少钱？大概可以减免18万彩礼，直接坑了丈母娘。

为什么学历的作用在职场不明显？将心比心，你去超市买东西，你在乎营业员是本科生还是三校生吗？不在乎，你只在在乎火腿肠是不是打折？你去各种窗口办事，你会不会在乎盖章的人是985研究生还是中专？你不在乎，你只在乎是不是给你盖章了。

以前我觉得自己太厉害了，为什么不让我当副总？各级头头没眼光。我现在发现，是我产生了错觉。其实，绝大部分单位不需要985，不需要研究生。因为985和技校毕业，实际区别不大。举个例子，你去三甲看病，对面这个医生是博士，还是张家口来的短期进修人员，你也分辨不了。

既然学历没什么实际意义，那我们为什么如此激动？因为惯性。我们从小到大都是在班级排名的噩梦中度过的。考上985有面子啊。娶老婆，985是加分项目，没房子就一票否决。

做生意赚钱，真正的意义是给别人带来利益，你去下一碗面条，老板娘是文盲还是985，不重要。

做人做事是一样的，你必须给别人带来利益，才能获得自己的发展。
