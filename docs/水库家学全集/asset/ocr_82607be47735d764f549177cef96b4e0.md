# 和差生谈谈，高考数学怎么才能拿高分？

我当年没有满分，我有个同学是满分，我曾经和他聊了几句。因为当年我也是心高气傲，所以没有当回事。今天突然想到此事，就公开一下，数理化有一些隐蔽的次级定理，叫做潜在公式（现在也有人称为二次结论）。你不要去问一般老师，正常老师不懂这个。因为老师范学校当老师的，当年都是中档学生，99%的人不可能理解到这个程度。

这玩意是什么意思？说起来有点复杂。数理化有很多书本上印好的公式，但还有很多没有印刷出来的小公式，这玩意，往往是实际应用范围很小的公式，不登大雅之堂，在生产生活中基本没用，但考试特别有用，是数理化选择题的利器。

你只要看到某些特征，就可以知道这些题是要考什么，什么是正确答案，不用算，闭着眼瞎勾，肯定对。这些潜在公式是大部分难题的原始版本。很多难题就是 在这些潜在公式的基础上兜兜转转，加一点作料，衍生出来的。你提前知道了答案，做起了就不慌不忙了。

这个事情，实际上是一些投机取巧的办法，但是很管用。这些方法是怎么来的？我也讲不清楚，但我所知道的是，绝大部分都是哥哥姐姐交给弟弟妹妹的，或者父母是老师，偷偷教给子女的。我高中时候只看到过一个劣质讲义，专门讲这个事情，讲义是某个老师手写油印的，我们当年没有复印机和电脑，内容只有开头和结论，没有推理细节，实际上这些细节也没有实际意义。这玩意，纯粹是为了考试窃答案用的。所以当年也没有细究。
