# 孩子上学怎么办？父母养老怎么办？留下的巨额房贷由谁还？

家庭的幸福指数，会迅速下滑，下滑速度远远超过当年的攀升速度。从小康到贫穷，也许就是一次无法承受的意外。

> 步入社会，走进职场，我们不仅要努力抵消年龄劣势，还要肩负起沉甸甸的家庭责任。

很多人只知道拼命赚钱，却不知道给家庭做一个最基本的安全兜底。殊不知在这个经济波动，生活不易的时代，我们要更守往自己的钱袋子。

这个世界有太多我们无法改变的事情，唯一能做的就是风险管理，这是每一个有责任心的成年人都应该做的事。若因侥幸而忽视来自健康的潜在风险，很可能就是一辈子的自责与遗憾。

所以今天再次很认真给所有人提个醒：要加强家庭（自己、子女、父母）的保障意识，避免现金流转为负数，做好托底的终身保障。

其实保险往简单了说，就是分摊意外事故损失的一种财务安排。我们没有办法避免意外的发生，但保险理赔的钱，却能够让自自己和家人获得较高的经济补偿，能够保障有充足的医疗费，无需担心父母的养老和孩子的教育。

千言万语，保险所保护的，是你的钱。你现在拥有的资产和你的生活状态。只需占用一点点现金流，就能极大程度上降低极端情况下的资金风险，是最低成本的风险转移工具。

但保险不能跟风瞎买，它涉及金融、医学、法律三方面知识交叉，是一个需要专业知识与实操经验的领域，必须结合个人需求、理赔规则、风险评估、家庭成员收入等做到量身定制才行。

举个简单的例子，你家年收入50万有房贷，他家年收入30万无房贷，两个家庭的保障需求就不可能一样。

另一方面，很多人真诚服自己去买保险时，却处处都是陷阱，业务员为赚钱盲目推荐，捆绑销售，更不懂理赔。我在最初打算买保险时，也是一度十分迷茫，了解的产品越多，越觉得无所适从。
