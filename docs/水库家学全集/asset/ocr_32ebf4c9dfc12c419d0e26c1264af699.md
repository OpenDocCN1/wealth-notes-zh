什么是度假？

绝大多数人把度假理解为到外地景点拍拍照，转一圈。这是二十年前的行为模式。我们以前在单位的时候经常搞这个，所以，各地风景区我都去过，从西双版纳到长白山天池，实际上这样玩是非常疲劳的，搞不好还感冒了。有一次去昆明，下了飞机就爬山，那天爬的我两腿发抖，至今二十年了，记忆深刻。真正的度假是两眼放空，找个山清水秀，风景宜人的地方，躺一个星期，吃好吃的。

我印象最好的一次度假是在杭州。你也可以找个附近景点。我是提前一天，自己开车过去的，住在酒店，吃饱喝足，但是没睡好。因为有点兴奋。

我进城的时候，道路特别拥堵，第二天，我早上四点半就出发了，开到西湖边，找了个停车场，就在岳王庙对面的肯德基附近，然后，我步行了杨公堤，上香古道。走了四个小时，一直走到飞来峰，大概是早上九点多。这个时候，西湖游客已经非常多。我就回去了，找了个饭店，大吃一顿。

那一次步行旅游已经很多年了，至今记忆深刻。

+   1，避开高峰。有很多著名景点，你白天去，人挤人，毫无意义。我建议你们早晚去。西湖不要门票，我是早上去的。要门票的，你下午三点去，里面没人了，感觉不错。

+   2，吃住挑好的。出来了，就不要小气了，穷家富路，也给当地增加一点收入。建议，去本地最好的宾馆，三千一宿的那种。很多宾馆本身就是一个景点，附近逛逛，吃的东西。特别是广州，美食遍地，你住个市中心，就在附近居民区门口吃吃，很好的。记住，吃潮汕菜。

+   3，不用买任何纪念品，除非是捐助性质。这些东西，网上都有，你找个角落，网上下单，你到家，东西也到家了。
