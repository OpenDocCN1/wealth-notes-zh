# 在京沪广深如何算得上财务自由？

财上海微博 2020-05-07

# 01

男人结婚，必须要买房吗？

老一代结婚不买房，例如现在的5060年人口，市区单位不管结婚房子，都是靠祖宅。没房子的上海男就可倒大霉了。大部分家庭是在原有基础上，用布帘子隔出一个五平米的没有窗户的房子，就像是现在的豪宅。

当时一些城乡结合部大单位给一个临时宿舍，我看过一些几十年前的照片，搞清楚是临时宿舍是什么样子的。

现在也有，你去看看附近的建筑工地，工人宿舍就是那样的。找一块空地，一般是以前的农村，推平，然后直接搭一些轻型建筑材料，几天就盖好了。我已经没有印象了，据说，大概是8-10平米，无水，无厕，无厨，不隔音，只有电灯煤球炉。就这个房子，还超级抢手。

如果在市区五平米的面积都没有，怎么办？很简单，去农村倒插门。那时候，一个三甲中级职称倒到附近的农村倒插门是常见情况。现在不可想象了。
