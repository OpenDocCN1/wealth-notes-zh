# 县城生活的出路在哪里?

情商。

很多人都知道这个名词。但是，基本上没人讲的清楚，什么是情商？我用一句话讲清楚。

有的人一接触就招人喜欢，有的人一接触就招人讨厌。这就是情商。你我周围就有很多这样的人。如何提高情商？这玩意很难提高，但是我可以教你一个好办法，尽可能不说话。

因为不说话，就不会引起别人反感。但是沉默寡言也会失去很多机会。具体怎么做，你可以买套房，在家里好好研究一下。

# 大城市和小县城

前两天去接娃，在小学门口听到某老头和别人的对话。

老厚丝说：我退休了，还要管孙子上学接送，这辈子完了。大城市一点也不好，我在老家，下午打麻将，晚上广场舞，开心的不得了，又不花钱。在大城市，一个熟人也沒有，玩也没地方玩，住的房子小，蔬菜也不新鲜，物价也贵，出门就要花钱。我一直劝儿子回老家，老家什么都好，为什么要来大城市？我儿子特别要面子，死活不肯走，把我拖累了。大城市一套小房子的钱，在我们老家“美丽的黄山脚下”可以住别墅了，为什么现在的年轻人怎么虚荣。

我听的差的眼泪出来。这是老年人普遍的看发，小县城是老年人的幸福源泉。物价便宜，房子大，熟人多，玩的开心。因为老年人有退休金，他们只考虑花钱便宜，过日子方便。但是，那么多年轻人为什么背井离乡到大城市艰难催生？不是爱面子，而是没办法。就一个原因，就业。

绝大部分县城工作，实际上不需要什么高学历。老子是物理系的，在小县城能修录像机。老子是化学系的，在小县城能做卤鸡爪，老子是工民建搞，赶紧去贴瓷砖吧。这些工作也重要，但是，谈不上年轻人的梦想。大城市什么都难，就一个好，找对口工作容易。大城市需要的技术五花八门，京沪广深，什么专业都有市场，而且收入是小县城的一倍还多。

如果你能够保证，几代人都有编制工作，可以回小县城，找个二本科花结婚，每个月在大单位财务科领工资，上班网购，下班吃席，中午睡一觉，开心啊。否则，你在小县城打拼，日子不那么好过，还不如在大城市送快递。至少，大城市保证了你一个月八千。迟早要出来的，还不如自我牺牲一代，走出去算了。
