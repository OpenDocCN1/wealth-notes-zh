# 考试方法

我们这种学霸都是有一些江湖方法的。大概归纳一下是“三段论”，50%提前学会，50%课堂理解，20%刷题补短板。很多人笑出了猪叫声，尼玛的，整出120%！是的，很多知识点，你表面上会，但实际上不会用。很多物理题，拆了讲，你都能懂，但你在考场上就是不会做。985变成二本子，小美白跑了，老丈人的三房两厅也没了。

+   1，提前学一下很重要。因为课堂上，老师的讲课是平均速度，你对知识点的理解不一定是平均速度，还经常走神，没听见。提前学一学，有巨大的好处。

+   2，课堂相当于重新温一遍。反正你都有印象了，听听老师的讲法，温故而知新。

+   3，课后适量做个题，作用是检测一下能不能灵活运用。

这三段论，是我在初中高中中长期获得小美白青睐的小绝窍。

+   4，每次考试后，把错题归的一下（最好汇集到一个小本子上，方便以后查阅），分析出当时不会做的原因。积累几年，你家娃娃肯定是985211，没问题了。

这个打法是超级有效的，但是是费时费力，建议家长们也参与一下。公司里那个破工作无所谓了，孩子多考几分，啥都回来了。
