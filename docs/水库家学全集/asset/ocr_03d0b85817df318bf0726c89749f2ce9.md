# 中产阶级有个无法言说的痛楚，利益难以传承。

财上海微博 2020-01-15

# 01

中产阶级有点苦逼。

中产阶级有个无法言说的痛楚，利益难以传承。我之前一个保姆是在某三甲副高家里做了十年，月薪大概七千八，活很轻松，还可以给十里八乡的亲戚免费挂号，在村里是数一数二的牛逼人物。后来副高退休了，直接就是烂货了，没有能力再长期付钱了，就散了。保姆把他们家的破事，给我说的底朝天。他们家最大的遗憾是儿女不争气，考不上一本医学院，也没办法继续来混这碗饭了。

其实这个现象不仅仅是他们家，还包括各行各业的中年，手艺人（律师教师工程师），他们都是依附于一个副高职称。但是风水轮流转，如果下一代够不到副高，这事情就结束了。怎么办？

利益的传承要靠资产。职称是不能继承的，红本本是可以继承的。在有限的职业高潮期，一定要居安思危。前不久去看了原来的大单位退休的中层头头，他过得很好，以前单位发房子，低房价时代，他有几个小套和一个自住的漂亮大平层（买的），现在几个小套租出去很容易很舒服，资产增值也厉害，成为大家羡慕的对象。

与此同时，他退休后，发挥余热，发挥特长，还给一些开公司的熟人朋友提供一些合法的业务咨询，打打合法电话，也是一块明显的收入。以前单位配车，好坏不能挑，现在他自己买了个黑色大奥迪，请了个退休司机，牛逼大了，不知道最后便宜了哪个保姆？

# 02

富人最蠢。

前两天有个老板不想干了，准备关闭企业。我问他为什么？成本太高，无利可图，每个月全厂发工资就像是过鬼门关。

与此同时，农二代小王，开了几年土方车，攒了点钱准备创业，我问，将来发不出工资了怎么办？我是农民，老家也就几件大瓦房，谁能拿我怎么样？我一听觉得，妙！穷人有智慧，富人最蠢。
