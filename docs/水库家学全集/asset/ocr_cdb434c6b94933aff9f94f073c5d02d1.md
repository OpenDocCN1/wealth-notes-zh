# 富人是什么样子的？

绝大多数富人，可能只是懂一个点。碰巧，又有机会去干。运气也好，成了。这是我见过的绝大多数富人的发展轨迹。

我认识一个我老家来大城市的装修队长。他基本上除了装修，任何事情不感兴趣。他一天到晚就在研究装修中遇到的各种各样问题，例如渗水，价格，员工不高兴了，客户不满意了。反正就是各种各样的小破事。你说这样的人腿不聪明？他基本不懂天下风云，海湾局势。有一次还被石头砸断了脚指头。

就这么个人，干了十年，自己成立装修公司了。然后人生开挂。我们老家人有个特点，喜欢抱大腿。装修队还能抱谁的大腿？无非是物业经理。物业经理看他孝顺的厉害，也就给他指了个道。在物业公司的同一个楼层，开了个装修公司接待窗口。

他就一下子发迹了。居民进户都要去物业公司办事，他居然提供免费验房服务，实际上就是拿着个尺子，装模作样表演一番，以此低成本的办法，基本拿到了九成的住户微信。然后吃下了五六十户装修，我那个地方算是高价小区，一家五六十万是打底的，一般是80-100万左右的装修预算，多的是三四百万。

他一年就发迹了。他手下四十岁以下的员工，全部辞职了，自己当老板。你说这种小老板，是聪明人吗？也不见得，但是人家就是发了。比起我家保姆的儿子，一天到晚在窝里想发财门路，确实强多了。
