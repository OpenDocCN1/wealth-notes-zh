# 06

回到九十年代，你家就能分房子？

以我们家为例，想来想去只有一个远房亲戚，真的分到市区小房子了，其他人没有。远郊区房子不算。我家亲戚当中，五花八门，各种岗位的都有，一般都是国企。以我最熟悉的几个亲戚看，完全没有分到房子。原因，当年分房子有各种各样的打分，老是分数不够。

例1，我家有几个三甲副高，现在退休了。他们八十年代结婚，我还有印象。结婚时候是住院医师，相当于初级职称，因为家里还有一个小房间，不算最困难的，根本没有分房。医院最大的福利是两个，

一是单位免费洗澡。我也曾经和他们一起去单位澡堂子洗澡，淋浴水龙头。

二是食堂吃饭便宜。一般有一块大排。你可能不知道，我们小时候，大排就是好饭菜了。

例2，我有个亲戚是国企工人，好像是五级工。没有分房子，后来下岗了。

最后，亲戚们解决住房的途径完全一样，拆拆拆。就是那种六层楼的老公房，现在已经看上去很破旧的那种。

当年什么人能够分到房子？我工作后，仔细观察了一下。

一是大厂五十多岁的工人。当年大厂工资很低，几十块钱左右，干到退休前，能够分个几平米的棚户区。

二是窗明几净的大单位。当然，最好带个长。我认识一个中级职称老油条，就那么小工资，百般不愿意，干到儿子高中，才分到一个极度肮脏油腻的内环线小房子，公用厨房的那种。我至今记得，他极度兴奋，上班时间溜出去，带我去看看他的资产。那个脏啊！我至今无法忘记。

分房子比较容易的是远郊区大厂。土地是国家给的，不要钱。建筑施工单位本来就有厂房维修所。建筑材料也容易搞。当年人力也不值钱。
