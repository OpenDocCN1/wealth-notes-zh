语文没有一定的格式，你说范仲淹和杜甫，哪个厉害？没法说了。但是，语文考试是有严格程序规范的。

我专门研究过语文的中考和高考（在家闲的，又不能出去玩）。我发现，语文考试，答题基本有套路的。一般是问，这句话表达了什么意境之类的。

这句话表达了什么不重要，估计原著作者也没想明白，但这没关系，不影响老师出题。我曾经研究过北京x中某语文老师讲的一堂课，她把语文答卷的模式，归纳出大概35种情况。

你要是不分清，你就多写几种，变着花儿的写，只要一不小心戳到题点，你就得分了。语文得分和数理化不一样。数理化不能有废话，语文是不管你写了多少废话，我就挑一挑有没有戳到标准答案的话。只要戳到了，就给分。

标准答案的写法就那么几种，你背熟了，就可以秒干语文教研组。

# 05

中小学考试，没有什么鸡贼办法。

绝大多数孩子智力水平，补课的意志力，是接近的。确实有偶尔个别的奇葩，你去清北好了，我不和你争了。我的目标是985，华师和二医就够了。

中小学最难的一件事，滴水穿石。你每天努力一点点，该做完的做完，基本可以保庶六安师设。

我推荐给朋友们的错题本，是非常有效的办法。你不要看不起土办法，鲁班发明的锯子墨斗，人类用了几千年了。你只要踏踏实实干了，二本不难，985也可以冲一冲。家长最不应该的是，平时不上劲，现在临门一脚了，你TMD天天王八念经，孩子们好烦啊。

这样吧，你也不要揪心了。考的上，我们去做医生码农，让丈母娘出房子。考不上，我们去做瓷砖烧油条，找个外来妹。
