# 网上有没有行业秘籍？有。

绝大多数人没有赚钱，并不是因为行业知识的问题，而是他压根不想辛苦的事。我曾经说过很多个案例，都是行业小秘密，但你看不上。我曾经无数次说过卤鸡爪，贴瓷砖，炸油条。你以前应该不知道他们有多赚钱，但你会去干吗？你不会去。因为你要的是下一期的双色球号码，躺赢，这个真没有。

我明明知道你不会去干辛苦的工作，我为什么还要和你说？这就是哲学。如果一个二本屌丝整天混日子，再没有点运气，到了35岁，就是一滩烂泥了。这时候，你有两个选择，

一是儿孙自有儿孙福。

二是放下面子，做点力所能及的事，为家人拼搏一次。这时候，你就明白了，我说的那些卑微的行业，会成为你重新起步的方向。

一个人只有在非常困难的情况下，才会去做一些看上去不那么光鲜亮丽的工作。这时候，你没钱没技术，走投无路，怎么办？

从零开始，做一些保证赚钱，但是非常辛苦的工作，例如炸油条。你只要踏踏实实做下去，炸油条 + 豆腐脑，是非常赚钱的工作，绝对超过一个陆家嘴背电脑包的985。

当然，你有路子，你可以随意。侬房子买好了伐？多少面积？

# 古代考进士也是拼爹

你去看看看状元名单就知道了。大部分状元进士，名字起的非常讲究，大多数取自诗经古风，这就是书香门第。父母大字不识一个的老农民，只会叫个朱重八，绝对起不出翁同龢这种名字的。

网上有进士考卷，你去看那些字体，我的天啊，如果没有名师指导，哪里能练成这么好？

明清考进士的题目，一般是国家大事为切入点。以前没有互联网，农民孩子除了知道村口有条狗，哪里写的出政论对策，经济管理，官吏改革，兴修水利之类的重大课题？
