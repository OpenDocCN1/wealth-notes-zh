# 02

单位发房子是什么感觉？

我小时候是经历过发房子年代的。婚后，等1-3年，年轻人可以分配一个很脏的小房子，爬老鼠的那种。大概男性45岁左右，可以分到一个两室一厅的大郊区，例如三十年前浦东陆家嘴，桂林公园那种地段，或者市中心区16-20平米的棚户区子。这些房子都是老员工拿到新房子后腾出来的。

我工作后，去看过一个单位分到房子的老师傅。我的天啊，那房子，厨房脏的无法看，几十年积聚的油垢都黑了，现在的年轻人可能都不愿意走进去。就这条件，还要在单位里打的不亦乐乎，撕逼激烈。

现在的年轻人赶上了好机会，漂漂亮亮的新小区，可以贷款。也不要户口就可以买，当然，也有一些人买不起，但以前也有大批的人分不到京沪房子，没什么大不了，你可以去问问你爹妈为什么年轻时候没赚到钱？

现在的年轻人买得起房子，无非是父母有条件。
