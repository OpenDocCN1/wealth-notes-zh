# 怎么创业？

你就想想想你的日常生活中有没有什么痛点问题，你可以解决。或者你可以做的更好。不要做什么蓝海项目。

蓝海项目就是别人不敢做的项目。这种项目有个致命的缺点，需求较小，推销成本高的离谱。举例，玉石生意是暴利中的暴利，纯粹是游客套餐，加个零的利润，但是你要卖掉一个三万元的玉镯，销售成本高的难以想象，千难万难。不信？你把家里的那几个结婚戒指拿出来卖卖看！我保证，如果按照市场零售价，你一年也卖不掉。

做什么好呢？最合适的小生意，就是大家都在做的项目，比较辛苦的项目。例如早餐店，烂大街了。但是利润大啊，煎饼果子是五倍利润。也可以做家教，要有点真本事，你行吗？

我最无感的是健身房项目，这种项目表面看，营业收入就是净利润。但是，投资大，设备多，客户少，客服多，遇到一个猝死客户，你就完啦。

我建议，你就用上班时间想想看，除了穷，你还有什么不满的商业服务，我能不能做的更好一点？若有，恭喜你，你很快就会发财了。
