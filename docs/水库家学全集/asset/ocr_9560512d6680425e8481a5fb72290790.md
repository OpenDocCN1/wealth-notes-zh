# 01

春节消费是县城商业一年的黄金时刻。

今年的情况，对县城经济打击太大了。京沪广深也有损失，但这个期间，本来就是淡季。春节高架上都没车了，地铁里，一人一片座位。

与此同时，不计其数的农民工带着大额现金回到老家了。买买买，吃吃吃，玩玩玩，是一年心里最开心的时候，也是县城经济一年等一会的发疯时刻，就算平时不来县城的附近农民，春节期间也要带孩子去县城玩一次，买件新衣服，吃个大碗面。今年，没了。连炸金花都没了。

我有个熟人，前两年回老家开了个KTV，春节期间，卡拉OK小生意，大浴场，商业一条街，都是人满为患，数钱数的手发软。今年一切都是静悄悄的，够环保。
