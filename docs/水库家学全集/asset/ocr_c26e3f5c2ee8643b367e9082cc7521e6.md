# 06

二本，只是批量制造杠精的地方。

杠精的术语叫“批判x思维”。什么意思呢？就是不管别人说什么，他就会立马说：“不是这样的，我给你说几句啊”。时间长了，杠的越来越溜了。我们古代到几十年前，一直都是师徒制，杠精极少。

现实生活中，杠精满地走，所有的单位里，都有大批杠精，但是这些人混不出来的。因为没有人喜欢你一天到晚反驳小头头。我曾经遇到一个超级牛逼的女销售。她是初三毕业的文艺女青年。她有个天才本事，奉承。而且，拍的恰到好处。我曾经见过几次，佩服的五体投地。

有一次遇到一个做牙刷的小老板，要请客。他给我介绍说，这是浙江做牙刷的超级大户。把那个小老板乐的眉开眼笑，晚饭加了几个大龙虾，以此彰显大户的感觉。你要是买个新衣服，做个头发，你会愿意第一时间去她那里坐坐，接受她的心里按摩。

当然，这也不是白吹你的，她有一次趁我高兴，卖给我几个宝马x6。后来才知道，销售女有个习惯，一天到晚研究怎么捧别人，必须是恰到好处的，略带夸张，别人舒服到了极点，她就赢了。

我有一次看祖传家学，也有这一篇这样的，简直是一模一样，真是人心不变啊。

# 07

空乘。

我有个发小，娶了个空乘。我当时没见识。以为他发大财，走上人生巅峰了。后来才知道，压根没有，就是介绍相亲认识的。他在一个大单位里当个没有什么花头的闲人。据他说，空姐其实现在也不怎么厉害了。
