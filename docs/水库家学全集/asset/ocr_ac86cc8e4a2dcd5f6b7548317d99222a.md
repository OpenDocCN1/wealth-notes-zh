我对这个问题有切身体会。我有两个大房子做了比较，一个做了地暖，一个没有，感觉天差地别。一般大房子，浴室面积比较大，我浴缸是两米长，浴室估计12平米左右。

有地暖的浴室，非常舒服。没有地暖的浴室，冷。当然，面积不大的浴室，装不装关系不大，暖风机也够 了。

+   2, 要不要安装双台盆？不要。

双台盆就是两个洗脸池并列。当年，菜嫂的意思是一人一个，互不干扰。实际上，意思不大。因为，双台盆使用的机会很少，比较多的就是洗个手。与此同时，由于是双台盆，放东西的位置就少了很多。零零碎碎的小玩意多，非常不方便。

+   3, 要不要衣帽间？

我每套房子都安排了专门的衣帽间，如果你不是电影明星，实际上意思不大。我们这里，一般的中年妇女，不需要打扮的花里胡哨，每天换各种各样的衣服配饰，特别是带娃的妇女，有件干干净净的外套就行了。

衣帽间往往不在你最方便的地方，每次带娃出门，你要楼上楼下乱窜的换衣服，一般不是这样的。

+   4, 不要安装特别大的吊灯。刚开始挺好看，但是以后维护很麻烦。

+   5, 洗衣机最好带烘干功能。方便。

+   6, 冰箱最好是双开门。大，方便。

+   7, 锅子最好是铜锅。不会粘底。
