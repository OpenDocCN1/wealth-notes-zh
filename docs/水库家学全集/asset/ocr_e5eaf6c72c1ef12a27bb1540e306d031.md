# 01

美女老了会如何？

前两天，我见到一个老太太，65岁了，看上去年轻时候特别漂亮的那种，我相信她年轻时候绝不亚于AB的那种。我就好奇的问了问身边认识她的老头老太。

这个老太婆年轻时候因为出身不好，嫁了个普通人，现在日子过得一笔吊糟。房子是老破小，男人是普通的退休老汉，收入微薄（单位差）。现在打零工，给亲戚公司做出纳，增加一点收入。她儿子继承了她的基因，长得极帅，就是那种奶里奶气的小哥哥，娶了一个爆有钱的老婆。儿媳妇不知道哪根筋搭错了，给她儿子买了各种各样的名牌，外加一个保时捷。他儿子到处收割黑木耳，最后一地鸡毛，媳妇扔下两个离婚了。

现在，这个老太婆苦难的一塌糊涂，家里穷，儿子没老婆，两个娃肚兮兮的。我发现，女人不管漂亮不漂亮，一定要有家底，否则，日子很难过。因为她比较穷，亲朋好友一起聚餐，其他人不会让她掏钱，她超级没面子。

小结，爱情是美好的，适当也要看看经济条件。实在太差的，还是慎重。
