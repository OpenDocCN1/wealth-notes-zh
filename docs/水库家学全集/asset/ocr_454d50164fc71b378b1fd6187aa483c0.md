# 04

社会是如何把我驯服成可爱小乖乖的？🐱

想当年，老子是天不怕地不怕，上想天，下想地，中间想头发。现在的90后说什么躺平，那没用的丝丝。我们那时候叫做“生死看淡，不服就干。”二十年过去了，我已经蜕变成一个没有勇气的软饭了。回想起来，一路坎坷。

作为老一批985，我们当时进单位，面对的师傅都是大专生，当时的本科生比大熊猫还少，三校生一大堆。有一个结算部总经理（中层），居然是银行技校毕业的🤔，他和他老婆在一个单位上班。我印象中，我们单位好像是过了2000年，才达到本科率50%。像981大那种二本也算进去的。我们那时候，年少轻狂，经常把老东西说的一文不值，身份证500块卖，英文版，要不要我给你讲讲？那些老家伙直接萎了。行长也是一脸懵逼，这是我最快乐的时光。在食堂吃晚饭的时候，开心的手舞足蹈，觉得自己很牛逼。那么，社会是怎么教育我们的？很简单，不理你就完了。

你牛逼，是吧？晾你五年。五年后，那些很听话的小乖乖，已经提拔当经理了。过了十年，那些认受的姓也提拔了，最后就剩你你们几个脑子瓦特了的250了。

与此同时，我们在成长的过程中，也遇到了各种各样的麻烦事，买房买车，亲戚矛盾，各种求人。你没有点地位，走到哪里都不行。最后，我认怂了。你不要笑话我，你要是不服，将来也是这种货色。我至少还有个老婆管事，你怎么办？
