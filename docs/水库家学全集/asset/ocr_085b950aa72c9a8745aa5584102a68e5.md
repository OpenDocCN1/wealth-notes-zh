# 11

大平层和别墅的使用区别。

市中心大平层面积小，最多也就是两百多平米。一家人挤在一起不舒服，最主要的是互相干扰大。孩子一天到晚放那个“宝马小莉”动画片，烦也烦死了。

别墅有个好处，互相干扰小。孩子在一楼闹翻天，你在二楼关门睡觉影响不大。

当然，别墅也有很多麻烦，主要是打扫清洁太贵，距离市区远。我的意思是，上班族就不要买郊区了。因为别墅在郊区，没有公交车。请保姆不必担心，好多保姆也在郊区找活。
