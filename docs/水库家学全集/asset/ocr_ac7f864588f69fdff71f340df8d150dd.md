# 06

五年定律。

如果你拼尽全力，不出去玩，也不做家务，一门心思搞一个事情，五年后你肯定会成为大伽。

屌丝啥也没有，就是时间多。而且时间无处打发，没有女友，没有房子，除了在宿舍里打游戏，啥也做不出。不要说什么旅游，买包包，屌丝没钱，苦逼的一塌糊涂。怎么改变？撩一个技术。

具体做什么？你结合两个因素，

一是兴趣。兴趣是最好的老师。有兴趣，你可以坚持的更久一点。

二是结合已有的资源。例如自己的工作，父母的强项，老家的人文历史地理环境厨艺等。

屌丝一听就火大了。“老子什么不懂，还用你说？如果有这个劲，我早就清北了。我就一个问题，啥也不想干，也没兴趣，如何吃好玩好住好大平层？”

简单，倒插门呗。老了老了，再去撩一个张阿姨，齐活了。
