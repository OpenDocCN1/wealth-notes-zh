# 02

工资思维。

我见过太多的人是工资思维，只进不出。有个粉丝在n年前咨询我，看上某个房子，双方因为两万人的中介费推出，争执不休。甲方问我买不买？我说买。最后他没买，错失了一次重新投胎的机会，三代人呜呼了。很多人要说了，以前的事情说个棒槌啊，我问你，下一期双色球是什么号码？mmp，这我哪知道？

我说的意思是，投资和工资，是两回事，两种思维。赚工资是一分一厘的计较，加班熬少了十块钱都不行，大腿一拍，找小老板吵，揍他丫的。投资不是这个思维，只要方向对，根本不考虑小钱。很多人认为，多出两万元，就是我半年的存款了，实在是接受不了。

经济发展，大浪淘沙，不进则退。现在跑得慢都不行，晚几年没赶上，就让你一辈子工资白存了。很多人又要骂了，你说现在干什么？我已经告诉你十年了，你这辈子就拉倒吧。别问了。回镇子上带孩子算了。
