为什么赚大钱很难了？因为利润模式改变了。

传统的赚钱套路。我搞个小生意，例如滑板车，每个生意赚80块钱。一年下来赚六百万。

这就给赚钱设置了一个极高极高的门槛，你没有一个是上市公司，你就很难赚钱。那么，一般人怎么办呢？那就要进入一个资本大鳄说了不算的行业。例如，

# 02

深圳某中学花大钱招了一大批清北学生去当老师。有用吗？没大用！

一个孩子成绩好不好，和老师关系不大。同一个老师教出来的班级，有第一名，也有最后一名。前三名上985，后三名去送快递。你家孩子是第几名？不好讲。如果老师学历有用，你就把大学直接翻译成中学，老师个个都是博士，岂不是很开心？我可以很明确的说，就算把清北数学系教授给你家请去当孩子的数学老师，你家孩子也不一定能考上985。

那么，怎么才能考上985？每个成功的人有各自的办法，我简单说一个小办法，错题本。你从现在开始，把你家娃做错的题，重新整理积攒成一个小本子，每个星期看一遍。就算考不上985，混个211，应该可以。

这个办法特别适合尖子生。普通孩子很容易在同一个地方摔倒两次。试试看，这个办法真的超级有用！
