# 01

家学：懂得示弱。

人的天性是示强。生活中，比较常见的场景是，先发一圈香烟，然后开始对着村东头的队长儿子吹牛逼，“老子今年赚了五十万！怎么样，老子厉害吧？”但这效果好吗？不好。你喜欢示强，别人也不喜欢示弱，人家也要面子，也喜欢示强。两强相遇，头破血流，这有什么好的？

与此同时，换个效果，还是先发一圈香烟，开始吹牛逼，“各位老哥哥，这是我特意准备的新茶，各位品鉴！”如果这么说话，十有八九，人家是很开心的，有什么好事，哥哥愿意带你一个。这是示弱，以弱治强。

但是，绝大多数年轻人不懂这个心理，把学校里那套带到社会上，人家就不高兴了。很多小头头家庭出来的娃，非常懂这个，烂熟于胸。为什么屌丝家的娃，处处吃亏？不仅仅是爹妈没有路子，更重要的是，你的言语，可能让单位里的冷板凳感觉很没面子，你把周围所有人都得罪完了。我也不让你开心。

社会是个筛选器，第一步就是把性格不好的人给踢出群，例如菜菜这个大SB。

# 02

求人帮忙，要明说要求。

最近发生了一个惨剧。二婚姑娘小美，找菜嫂帮忙介绍对象。也没有明说要求，就一句话，人品好。菜嫂理解错了，以为是要找个顾家好男人，就四处打听，介绍了两个理工男，老实人，人家小美也没看上。菜嫂彻底气馁了，也就不参与了。

小美以为菜嫂看不起她，也不高兴了。后来，因为一个偶然机会，菜嫂才明白，小美是想找一个有钱人，还要舍得给她花钱。这就好办了，立马介绍了一个，成功了，不过，小美为此耽误了三年，28变31岁了。菜嫂说，3年前，她可以找个几亿家的儿子，现在也就找个千万家的了。谁让她不说清楚的？活该！人生就是这么冷酷无情。

小结：你都在求人了，就别不好意思了，要把话说清楚，不要让别人猜。否则，耽误是自己。如果要求多，就写清楚。
