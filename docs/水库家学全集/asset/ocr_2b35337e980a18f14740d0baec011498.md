# 顶替读大学的解决办法

刚才看了两个山东农家女被顶替读大学的事情，很气愤。但这件事，怎么处理合适？

一个是1997年高考，一个是2004年高考，现在一个是41岁了，一个是34岁了。四年大学读完，45岁和38岁了，还有孩子要抚养。

重新读大学在技术上不是问题，甚至可以安排单独宿舍，现在老奶奶老爷爷读大学也有了。关键是她们读完四年后找工作，这个年龄现实吗？我看会遇到很多困难。我以前看过一个报道，某保安四十几岁，自学成才，读完本科，读完研究生，找不到工作，又回去当保安了。

我建议，读大学和经济补偿都要考虑。

# 穷娃翻身靠读书?

如果你真的读进去了，确实可以翻身。例如，教师，会计师，码农，工程师。问题是，你读进去了吗？我看未必。

现在的很多所谓的二本，也就是成年人托儿所。这些懒娃，逃大课，打游戏，叫外卖，谈朋友，一天到晚做大梦，以后要做霸道总裁，百亿大佬，这简直是蛇精病。

你去看看那些大佬，基本都是本专业的佼佼者。杭州码虽然不是理工科的，但是人家的英语水平，已经可以当大学老师和做翻译了。你看看现在的二本子，文不能写作，理不能编程，最喜欢一天到晚研究劳动法，斗老板，就是一个上知天文下知地理的微信百科。
