（给副教授上个理论课）通货膨胀是怎么来的？

二本子吧几下一嘴，裂开厚厚的嘴唇笑了，嗯，老师讲过的，钱多了，自然就涨了。事实是那么简单的。我在生产行业观察了好几年，给经济大学里的250专家说一下过程。实际上，钱多了，一般的卖菜大妈也不知道，那他们怎么会不约而同的涨价了？大概流程是这样的。

+   1，钱多了，肯定不是躺在银行里发霉，肯定要做事，先立个项目。

+   2，有项目了，肯定要招工。员工拿到钱就要去买东西。于是，商品就热销了。这个非常好理解。你到春节看，县城里的大小超市，卡拉OK，大浴场，生意极好。

+   3，招工多了，社会上的打工人的就不够用了，于是老板把工资提高了。

+   4，其他公司也要加工资，否则人就跑了。

+   5，各行各业加工资，产品就贵了。

+   6，卖菜大妈的进货价就高了。

这个过程大概要一年，也就是你们一天到晚说的滞滞时间约为一年。你再仔细想想各种细节，你就找到财富密码了。

# 生活的乐趣。

菜嫂每天早上要去花园里剪花。拿回来后，在每个房间摆上插花。所以，我家到处都是鲜花插的小花瓶。我每天刷牙的洗脸盆上都有好几个花瓶，还挺香的，就是不能吃。实际上，我更喜欢摆上几个油条小笼包。

我家的餐厅特别大，有个三米的桌子，我每一天一个人吃早饭。菜嫂怕我一个人孤独，就摆了很多插花。“你一个——个看，全部花瓶看完了，早饭就吃完了。”我一直希望招聘几个漂亮的小助理，菜嫂就是不同意。她的意思是，你看我就行了。我能不能不同意啊？何必呢？

菜嫂不上班，每天的任务就是花钱，接住。菜嫂最喜欢购物。他认为，购物是一种说不二的权柄。每次买完东西，还要强迫我去赞美。我经常要赞美十分种才能罢休，否则明天就没有奶油蛋糕了。
