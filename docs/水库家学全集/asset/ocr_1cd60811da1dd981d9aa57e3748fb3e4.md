# 01

小镇做题家的未来在哪里？

马上就是新年了，毕业找工作大决战即将开始了。那那，想想就烦人。去年八十万，今年只多不少。我们如何应对呢？大家最喜欢的肯定是京沪广深，工资高，生活好，就业多，发展广，但是住房难，找老婆难，一入京沪深似海，从此买房困难户。我提个小小的建议，大家按照不同的情况，各自参考。

一是有实力的，去京沪广深。实力是指两个因素，一是自然属性，成绩好，学历好，广阔天地，大有可为。二是社会属性。家里有钱的，父母有路子的，起步价是有两百万存款的，以后凑合一个外地黑胖花，在京沪广深蹲个老破小，还是比较容易的。京沪广深有很多自带三套房的资深剩男剩女。你只要有一样拿得出手的，一鸭两吃，既解决了老婆，又解决了房子。

二是长得好看，瞄准强二线城市。例如杭州、南京、苏锡常、宁波、成都、武汉。这类地区现在买房还够得着，丈母娘还喜欢看学历、看长相。特别是江苏省苏北区的同学，身高1.75-1.8m，在南方地区，简直就是爆款，那我们就不塞给她。萧山我最爱，房子加名字！

三是实在难办看重庆。有同学说，老子除了一个二本子，啥也没有，身高171，家里是农村，长得像个小鸡头。没关系，可以看看重庆长沙。重庆有几个特点，一是房子便宜，二是工资不高，三是几乎不要彩礼。重庆的房价大概是成都的六成左右，年轻人买房子，压力不大，特别是本地人，几乎都有房子，不比北上广深，丈母娘逼得你走投无路。二本子基本不用彩礼，郊区一般是几万，象征性的转一圈拿回来。重庆号称美食美景美女，大差不差，但也有黑胖花。

四是躺前回小县城。包邮区以外的小县城，除了没有发展潜力，其他都好。一百万就可以买空中别墅，三块块吃的满嘴流油，二本子娶老婆，简直是手到擒来。因为二本子有个潜在优势，可以考编制，小地方丈母娘特别看重这个编制。二本子回小县城，属于降维打麻将。商业一条街，售楼处的妹纸，你直接去要微信，保证没事。

去大城市，你这一代是很痛苦的。我见过很多人，走的欲哭无泪。有一个装修公司的屌丝老板，自称年入五十万左右，买了房，娶了老婆，生了娃，最后因为娃娃必须要回家读书，活生生的夫妻分居，现在天天在KTV包房谈心，谈的生死无可恋。当然，下一代就比较顺了。目前看，大城市放开户籍已经是水到渠成了，你在大城市熬住三十年，肯定是为下一代打底了。

去小县城，你这代肯定是舒服的。小县城除了赚不到钱，其他很开心，喝好头也只是是讲感情（闲的），没有什么钱不钱的俗气。

小结，家里没钱，就好好培养娃考试。二本子的春天也快来了。
