# 05

上海姑娘有没有外嫁啊？

肯定是有的。我见过两次。

第一次是八十年代，嫁到香江。那时候，对面随便一个货车司机都可以娶一个漂亮妹子。当时，我们的生活状态是不太好的，大家都住在没有厕所的棚户区，每天早上第一件事情就是倒马桶。那时候都是女人倒马桶，如果哪个男人去倒马桶，基本就完犊子了。早上第二件事情是烧煤球炉。这是个技术活，男男女女都可以。

因为实在是太穷了，能嫁到东方之珠，简直是非常非常高兴的事了。后来因为各种原因，就不热了。

第二次是九十年代初期，嫁到广东那一代的农村。因为当时深圳广州东莞已经发展起来了，上海的收入还不是特别高，很多姑娘就去抓住机会去了。那时候，在市区开饭店，不敢招聘漂亮姑娘，因为漂亮姑娘干不了多久，就会被各种老板看上。

我刚刚工作的时候，住在棚户区。有个非常漂亮的小姐姐是从广东回来的。当时她想嫁过去，人家还要不要。你说惨不惨？

2002年后，因为包邮区制造业飞速发展，日子就好了。

很多人说上海女人不勤劳，那是不懂。我小时候见过外贸手工毛衣。日本市场要手工毛衣，我们接单后，发给想干活的女人，我印象中一件毛衣手工费是5块钱，一个女人如果勤劳，基本上一个星期就可以赚5块，一个月20。所以，你现在看到的很多老电视剧，妇女们没事就打毛衣。很多是为了赚钱！呵呵，不懂了吧？我家有个亲戚就是打毛衣小能手。
