# 06

顶替上大学可能吗？可能。

我们以前没有互联网。高考发布分数，是在一个什么机构，学生不可能自己去看。我们那年是老师带个圆珠笔过去，抄分数，然后，坐车回校。学生们等着老师回来发布分数。

分数知道了，上哪个学校不知道。再等一个月，可以去高中问问。那时候，也没有电话。如果你等不来消息，很多人也就算了。我那年出了个意外，老师抄分数的时候，只抄过线的，不巧把我漏掉了，我当年的高分，遥遥领先，但我还以为没考上。

我们那时候也没有什么标准答案可以估分，实际上并不知道自己考的如何。

我在家哭了一天。后来，老师觉得不对劲，又打电话找人核对了一下，这才发现是搞错了。

# 07

电话是什么时候普及到家庭的？

我印象中应该是九十年代中期了。那时候，家里有个电话是很牛逼的。我家装电话的时候，还用一个非常漂亮的毛巾盖着，把它当做家里的大件，仅次于电视机的大件。

每一个超级土豪都有一张照片，就是拿电话在办公桌上假装的电话的老照片。那时候，电话是世界上最神奇的东西。我工作的时候，流行大哥大，就是那种大板砖一样的黑塑料，那个东西很重，又很娇贵，不能摔，也不能进水。我专门拍了一张照片，就是借用的手机，站在一个红色桑塔纳旁边。此照片成为我今后很多年，相亲的御用照片。

社会上，一般的土豪会雇一个小蜜，一天到晚替他抱着那个砖头大哥大。我当年发誓要买一个大哥大。后来大哥大就没了。大哥大信号很差，通话质量也很差，需要扯起嗓子，大喊大叫。不过，这也是一种炫耀。我在村里东头喊，恨不得全村人都听见。那个有面子。

我的第一个手机是小灵通，花了几百元。小灵通的作用是接电话不要钱。以前大哥大接电话，打电话，都收费的。小灵通一出来，上海人就像疯了一样的去买。我也托人买了一个。我印象中是在一个下雨天，跑了很远的地方，在浦东东方路营业厅买的。那时候觉得自己很牛逼了，有手机了。
