# 09

为什么大企业遇到销售困难更容易垮掉？在二本子的想法里，你身价几百亿，就算躺死狗，也不至于几个月就不行了，事实上，大企业确实容易垮。原因：

一，摊子大。大企业之所以大，就摊子大，大片大片的厂房机器，都是前几年的利润和银行贷款堆起来的。亚历山大。

二，负担大。大企业首先是人多，一个月工资，人均一万，就是几百万到几个亿现金，这等钱就足以嫩死你。大企业为了满足生产，都有巨大的原材料库存，这等钱是超级巨大的。举例，你家是大饭店，生意好，肯定会多买些鸡鸭鱼肉，龙虾鲍鱼备料。一旦没客人了，就完了。

大企业肯定不会把几个亿存银行的，都是极力做大企业规模，往往还要贷款买流水线。这就导致了，大企业日常现金不多。他们平时也很简单。现做现吃。每个月销售回款，扣除原材料，就发工资，再有剩下，就是毛利润。如果没有回款，分分钟挂了。

三，能不能找股东追加投资？一般不现实。股东有钱也花出去了，股东儿子刚刚结婚，你总不能让人儿媳妇卖房救你吧？

四，节约成本的事情，一件也不行。没有销售，就剩下发工资了。总不能说不发工资了吧？
