# 为什么游戏会上瘾？能不能把打游戏上瘾的原理复制用到儿子学习上？

财上海微博 2020-05-10

# 01

大批的聪明孩子废了。

我在小区看到好几个小学生，男生为多，小时候特别聪明活泼，上树摘果子，搭个竹匾套麻雀，自制钓鱼竿，拉帮结伙在小区里玩飞车（娃娃骑得自行车，七八个人浩浩荡荡出游，大片既视感）。

但是，读小学后，家长们就蔫蔫的了。原因是，孩子考试成绩不行，上课不认真，被老师一天到晚批评。家长们心急火燎也没用，时间长了就开始鄙视这个孩子没出息。孩子也很郁闷，性格越来越内向，再也不敢玩了，孩子废了。

其实，这些孩子潜力是很大的，唯一的问题是考试成绩。上课不认真那是倒过来说的。孩子上课都不认真。怎么解决呢？最好的办法是有个985的妈或者私募，一天到晚盯着。

我建议，父母读过大学的，如果家庭收入可以，腾出一个人不上班了，专门陪读，盯孩子学习。你上班多赚的那点钱，比不上孩子读书差的未来损失。现在的丈母娘要求可多了。

# 02

为什么没人教我发财？

这个问题困扰了我很多年。就像小时候，没人教你如何考985一样。长大后，我发现很多大老板其实也不见得多厉害，只不过他机缘巧合做上了老板，然后发大了。我来说说发财的秘密。发财要具备两个因素。胆大心细。

一是胆大。万事开头难。一般人，一个月六七千收入，不敢砸几百万创业的。

二是心细。一个敢闯敢干的人，不可能什么事情都会做。开一个公司是非常复杂的事情。设备，厂房，宿舍，工艺，市场，财务，人员管理，质量控制，安全生产，千头万绪，一个项目没做好就完了。我认识一个老板，什么都好，也发财了，就是出了一个重大工伤，二十年废了。

胆大不难，也就是痛苦几个月下决心。难的是，创业后，千头万绪的细节。举例，宿舍厕所的化粪池渗漏了，整个厂区，恶臭难闻。一查原因是当年工程质量没有监督到位。老板不解决，就没人管。工人大不了换了厂。老板怎么办？自己去挖土呗。
