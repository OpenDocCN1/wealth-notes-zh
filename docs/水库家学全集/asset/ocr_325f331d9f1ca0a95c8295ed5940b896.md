我谈一下数学的准备工作。

+   1. 彻底放弃最后两个大题，你不是那块料，就不要瞎折腾了。高考最后两个数学大题，都能对的概率很低，一般全省不超过28个人，相当于省级数学竞赛三等奖的水平。中考的情况，我不太清楚，反正也恶心人。你要是运气好，能扒下1-2分就是人才了。

+   2. 抓基础。你把以前的卷子拿出来，错题撸一遍。也不要做笔记了，撸就行。

+   3. 好题抄一遍。有很多好题，实际上就是母题。可能会变成各种各样的三分题，一分题，五分题，熟能生巧。

+   4. 早睡早起，调整生物钟，晚上11点一定要熄灯了。

+   5. 高考考纲那本书，简单看一下就算了，因为出题一般是在考纲下发之前就开始了。
