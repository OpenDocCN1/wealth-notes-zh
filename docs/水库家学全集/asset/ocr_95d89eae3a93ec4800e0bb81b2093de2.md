# 城里小学数学题为什么那么难？

我娃的作业都是xx小状元卷子，买来的印刷本，一天撕一页，一天做一张，每个课程都一样。实际上，这些卷子是很绕口的，大人也不一定会写。为什么小学要搞这些？我想了好久，基本领会了。

这些卷子是在筛选家长。小孩子肯定做不好的，那老师就看家长是不是在辅导？如果不辅导，这娃基本就毁了。如果这娃基本都会做，那就成为老师的宝贝了。因为家长给力，以后就是老师争分数的种子选手。
