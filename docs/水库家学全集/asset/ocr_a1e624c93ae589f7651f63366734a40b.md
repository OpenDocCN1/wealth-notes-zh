# 不知道为什么我总是买到楼王？

我已经好几次买到楼王了。买的时候不知道，售楼处女告告诉我，就剩下这一套了，要不要赔你？我是老婆迷，菜嫂是房子迷。最后的结果，往往是买了。事后查了一下房地球，发现是楼王。大城市的房价是公开透明，网络备案的，不存在看人下菜碟的价格。所以，楼王也有好处，看上去有面子。

我家小娃娃特别喜欢楼王。小娃娃的江湖非常残酷，谁家有面子，吃啥就喝啥，就去谁家玩，东道主也有好处，制定游戏规则。例如捉迷藏，数到20还是15，一般是东道主说了算。我家小娃娃特别喜欢发号施令，到我家，就是我制定规则，这叫主场。家长就惨了，负责给小娃娃准备水果和汽水。

水果还好说，反正就那几个。汽水就不一样了。汽水的品种实在是太多了。为了吸引小朋友到我家主场，我家小娃娃要求必须是买最高级的汽水。没办法，菜嫂一天到晚就在大超市收集各种各样的汽水，放在冰箱里。

为了有面子，我还买了很多巧克力品种，反正，大部分人没见过就可以了。为了这个面子，我和菜嫂花费了巨大的精力和时间。一瓶进口汽水，十几元才一点点，小娃娃要喝三瓶，否则你就是小气。

我靠，老子怎么可以小气，买买买。
