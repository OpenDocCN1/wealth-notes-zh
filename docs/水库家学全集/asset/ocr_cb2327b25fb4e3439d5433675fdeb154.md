# 太阳底下笑，坐宝马里哭？

你两个都试试看，就知道哪个更开心了。我有一次回老家，美丽的山脚下，半夜冻的真哆嗦，这时候回想起荣嫂的好了。地暖，夜宵，车库子，什么都是现成的。吃完了不用管，保姆会收拾。在老家，烤火一不小心，把我的外套烤焦了。晚上就一个小太阳，屋顶五米高，冷的老子直跳。大冬天的还要支个蚊帐，一怕屋顶落灰，二怕半夜老鼠乱跑。

宝马还是不错的。很多人看不起宝马。你不要说这个话，等你有了720i，你再说也不迟。一般人，能够在京沪广深搞个180平米，开干小宝马，已经是人生巅峰了。不要小看那些土鳖，你不一定比他们强！
