# 03

留学时候。

我第一次震撼就是旅游。你读书的时候，无数次幻想的地方，就在眼前，而且价格也不高。一般是有个海报，贴在学校附近，不仅仅有目的地，甚至还有很多令人惊叹的项目，滑雪，跳伞，非洲大草原。哪怕你想去南极都可以。你会觉得非常激动，那些都是电视里里才有的东西啊！

第二次震撼是逛超市。现在你们肯定不震撼了，当年我还是很震撼的。你可以买到全世界的食品，什么大西洋的鱼，北美大龙虾，澳大鲍鱼。我有个同学花了一百元人民币，买了一个螃蟹，真空包装的急冻螃蟹。买回来之后，我和他在宿舍里研究，这玩意怎么吃？还有很多很多亚洲方便面，就像是看到了亲人。

第三次震撼是去餐馆。一大堆金发碧眼的小姐姐，给你端菜倒茶。她们可是外教啊！

第四次震撼是认识了五大洲的朋友。你在电视机里听到的各种奇怪地名，你都真真切切的见到了活人。像我这样的土鳖，实在是意外。

第五次震撼是在中餐馆。我遇到过各种各样的福清小妹，偶尔还听到过她们一路上的惊险故事，简直是目瞪口呆。

第六次震撼。我在大街上遇到过很多我们这里去各种团。基本都是啤酒肚大叔，在老家他们应该是趾高气昂的，在那里就是春游的小学生，一个一个排队走，连包包的款式都是一模一样的。
