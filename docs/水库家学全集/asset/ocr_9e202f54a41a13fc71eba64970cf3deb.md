# 09

通胀对农民是有利的。

八十年代，农民没什么钱，也赚不到钱。货币多了会贬值，但农民没有损失。他没什么钱，贬就贬吧，管我鸟事！

货币多了，经济活动就频繁了。建大楼，修马路，需要大量的人，农民工就找到工作了，而且是高薪。这下子爽了。现在，中西部农民家庭买小轿车的比比皆是，穷乡僻壤都堵车了，以前一个县也就三五个小汽车。

货币贬值，谁吃亏呢？像我妈这种，一辈子老实人，在工资36元的时候开始，精打细算，牙缝里节约的几毛几块钱，一辈子攒下来十万，原来可以买个学区房小房子，现在也就买一套家具了，还要打折时候。

我们对纸币的认识是很浅薄的。

# 10

货币加水，和农民关系不大。

农民工大多数是临时工，收入是随行就市的。现在的农民工，主要收入是临时打工，每年加工资加社保已经是基本要求了，否则就换个厂。反正现在想当老板的人多了。农村聪明人做的是做装修，菜贩，鱼贩，我家保姆一个月收入大概是万儿八千，比研究生也不差了。他们的办法很简单，你涨我也涨，大家不吃亏。现在贴瓷砖一天收入千儿八百还算老实人。

比较吃亏的是固定工资的长期工。他们的收入，往往是固定的，和物价没关系。他们很多是在大单位，没有和单位领导讨价还价的能力。要么干，要么滚。与此同时，他们还有很多事情，有求于单位，例如升职职称，提一级，不敢谈钱，也没法谈。大单位不可能因为你的想法，搞一次加工资。一旦房价上去了，他们就是直接吃亏了。

有人吃亏，就有人占便宜。手里有面积的人占便宜了。因为多出来的货币，会涓涓细流汇成首付，跑到售楼处。水涨船高，你的面积也值钱。

结论，可以考虑改善住房，就当是存钱了。
