# 买一千万的房子，啥感觉？

财上海微博 2020-01-11

# 01

买一千万的房子，啥感觉？

答：我没感觉。在京沪，一千万现金的房子，也不是什么好房子，要么是远郊联排边户(京沪没有新建独栋，禁止了)，要么是市中心漂亮小区的九十九米，没什么花头。

真正的感觉是在别人。一是打车的时候，司机特别感兴趣，总是问这问那的，最后还要吹捧你几句。

二是相亲。如果一方住这种漂亮房子，相亲的时候肯定是加分项目。特别是外地来的穷美白，基本就疯了。只要男方不是烂货！成功率99%。因为其他家庭拿不出这种房子。丈母娘眉开眼笑，今后小舅子二本毕业来上海开黑车，可以住客厅。

三是亲戚。一旦你买了这种房子，你在亲戚的眼里就是一种借钱的资源了，平时回村喝酒就是坐主桌，小姨子对你笑脸相迎。如果不借，为富不仁的帽子就给你带上了。

四是保姆。保姆喜欢这种小区，在这种小区干活，心情好。如果是个孤老头，很快就被拿下了。

五是朋友。有一次，我去旅游，把房子借给一个小伙子，他爸是我的vip朋友。小孩子很喜欢，说是豪宅。我听的莫名其妙。

一千万的豪宅怎么来的？其实也不难。在十年前买了一个漂亮小区，也就一点点钱，十年后置换一下加点贷款就有了。
