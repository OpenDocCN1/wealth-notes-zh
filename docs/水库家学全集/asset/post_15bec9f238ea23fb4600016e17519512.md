我有个熟人，很有地位，以前办公室里人满为患，都是来求帮忙的，前两年他悄悄地做过了六十大寿，然后，就很寂寞了。没人再来找他汇报工作了。他也好郁闷，就出去溜达，去找当年点头哈腰的老板喝茶，人家视而不见，去售楼处走走，喜欢的都买不起。

他自保是可以的，没人找他麻烦，但要想一个电话搞定事情就不行了。前不久，大家终于知道他是250了，他参加了一个投资，每月利息好几万，骗局里里外外都是他以前认识的人，他被骗了一个大额，可能一两百万，一辈子的工资。更惨的是，他还在初期乐滋滋的介绍了好多朋友去参加，全部被一锅端了。因为属于借钱性质，毫无法法。

好朋友在背后一致怀疑，他和主谋是不是有瓜葛？其实没有瓜葛，这么多年，他看到的都是笑脸，已经忘记了江湖险恶。

接着他的位子的人，在办公室笑的前仰后仰，这个250。

# 大单位内百无聊赖怎么办？

我也是曾经在某个超有面子大楼里的一个小办公点桌熬了很多年，这里面的酸甜苦辣都明白。

先说好的，有面子啊。虽然你也没本事替人办事，但大家觉得你年纪小，以后有机会飞黄腾达，那些外面的老混混亲戚也会敬你一杯。

亲戚朋友觉得你文凭好，单位好，今后用得得到，也会给足你面子。逢年过节，以前读书的时候轮不到坐主桌，上班后就可以进主桌了，开心伐？

找对象容易啊。丈母娘都是势利眼，虽然你没房没车，但是你可能有前途，女方也高兴啊，至少买个希望。

你成为亲戚们的主心骨。很多亲戚遇到生活上的疑难杂症，都会来问问你，这是巨大的面子。

在大单位也有苦恼的方面，升不上去了，绝大多数人在28岁就知道自己在单位里排列顺序了，人际关系非常复杂啊，各种勾心斗角，互相说坏话，此起彼伏，树欲静而风不止，没办法。每天上班像是去挨刀。

升不上去，呵呵，接下来问题就多了，首当其冲是穷。我也不知道，为什么大单位里穷人那么多，一个个买房买车，斗富斗房，你穷，靠边站。自己好难受。这时候，出现一个机会，跳槽，月工资两万，去不去？很多人不敢去，因为已经熟悉了原来的好处，一到单位就上网络购物，说说别人的闲话，担心出去后自己混不下去，也怕丢面子。一下子就到中年了，完了。

我的意思是，跳槽也是打工，没有金刚钻别揽瓷器活。没有替老板赚一百万的本事，就拿不到五十万。不要以为你现在认识那么多各种大头头和小杆子，一旦离职了，你啥也不是啦。如果你有替老板赚钱的本事，干脆自己干，现在，干什么呢？

服务业！

我告诉你一个秘诀，小本生意，一定要做竞争激烈的苦活。因为竞争激烈说明是刚需，生意多，你有机会站稳脚跟。千万不要去做冷门生意，以为有个冷门技术，包打天下。

冷门生意都是几倍利润，但是需求小，成交很难。卖玉石是十倍利润，但是没人买，搞个语数外辅导班生意就好了，家家户户需要。
