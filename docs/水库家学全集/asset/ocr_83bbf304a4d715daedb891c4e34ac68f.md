# 05

为什么人才房不太受市场热捧？

一是限制流转。几百万买个不流通的法人股，不能享受城市发展红利，意愿不大。

二是也节约不了多少。大部分福利房，都在穷乡僻壤，租房也没几个钱。很不自在。相比房价的起浮，九牛一毛。

三是质量一般。这种房子，出发点是过渡，不可能搞得有多好。

四是面子。很多小区搭配了一个福利房。各方面都比较差。在单位里，小区里，都没有面子。人才，最讲面子。

五是交通不便。人才房一般在外环线外，上下班是个麻烦。或许有班车，但是如果遇到加班或者单位晚餐聚会，就头大了。

# 06

待人接物，讲的是细节。

机场附近的高速路边上，总有一些打双跳灯的车。这些人是干嘛的？司机准备接机场出来的客人。"你说好在哪号门，我开过来，你直接上车"。为什么要这样？节约十元钱的停车库车费。驾驶员还可以不走路了。

问题是，司机方便了，麻烦留给客人了。有一次，我提着急大包小包在机场楼上楼下地跑，去找驾驶员说的某个地方。但我不熟悉机场，而且机场实在太太大了。我拉着大包小包累到受不了。虽然我脸上装着没事，但心里已经火大到要骂人的程度了。

客人千里迢迢坐飞机来，你去接站，说明你们关系很好，甚至是亲友。你为了节约十元钱，彻底得罪人，何苦呢？我接站，都是老老实实停在车库，然后出站口站好等人，让别人方便和高兴。我来来回回也要两三个小时，汽油费也几十元了，何必为了节约十元钱彻底得罪人了。

待人接物，讲的是细节。这样做，客人是高兴了，但你就非常辛苦了。经常这样，你就受不了了，怎么办？看人下菜碟，不熟悉的就糊弄一下，找个借口"呵呵，不巧，正好出差了"。其实，别人说出差的，基本都是逗你玩的。以后别联系了。

有一次，我真的在出差，来了个熟人，当年对我很有帮助的老朋友。于是，我立马打电话给副经理，让他安排接站吃饭送客一条龙。第二天中午，副经理代表我还正式宴请他一回。
