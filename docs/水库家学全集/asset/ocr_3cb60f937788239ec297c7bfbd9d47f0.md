# ## 说我认识十多年的外地媳妇。

财上海微博  2021-07-08

# 01

从高到低是很痛苦的。

我家小区里，有对双外夫妻，她是一年级。小区非常漂亮，娃过得也很开心。但是，这家人实际上并没有能力负担这套房子。这两年生意不好了，男主主要卖房子，打包回老家。目前这套房子增值了大概老家一套三房两厅，男主兴高采烈的吹嘘自己眼光好。女主郁郁寡欢。

小区里的女人群，也互相八卦。大致情况是，男主是山区局经，因为一个偶然机会赚了几百万。女主是我们老家的村花，肤白貌美大长腿。男主和女主吹牛，自己一定让她住别墅，开豪车，当上小公主。男主一咬牙一跺脚，贷款了很多，房子车子都有了。女主一高兴就嫁了。然后火速生了娃，这下子套牢了。

如果不出意外，这个局还能维持几年。天不遂人愿，2020年大家生意不好，男主的业务不行了，房贷亚历山大，没想到2021年一季度，房子来了一波小阳春，男主得到了意外之财，可以卖房解套。但是，女主很痛苦。她已经完全适应了别墅区小公主的生活。

他们家娃和小区的其他娃玩的特别好。现在，娃要回老家了，当妈的很难接受。从大城市的豪宅跳回到小县城的三室两厅，这个落差是很大的。大人可以承受，小娃可能不行。这两天，女主带着娃和小伙伴们一一道别。娃娃娃的稀里哗啦。我家娃给孩子送了一大盒巧克力豆。

小结，女人结婚要看清楚了。

# 02

80后，对当年4050人员再就业还是有印象的。

一转眼，80后自己也来到40岁了。如果真的遇到这件事，80后该怎么办？我建议，如果不是技术人才，你也别去找工作了，干脆在附近做个小生意吧。

做小生意不难，难的是，起步抹不开面子。我家附近有个菜市场，里面有一家人是卖面条的。生意好的飞起来。据说做了20年，带了两个徒弟，儿子还娶了媳妇。她媳妇是老家的。结婚没多久就生娃了。一家人和和美美。具体做什么小生意，要看你性格。

一是熬夜打游戏型。首推小超市。一般干到午夜12点。
