# 为什么cpa赚不到钱了？

cpa的雇主主要是新起来的大企业，老企业一般坑位都满了。这几年，出现新的大企业数量少，cpa每年以几千个的新增庞大数量，疯狂倾倒在市场上，接盘力量太小了。

其实，律师行业也有这个问题，但是，律师行业新业务多，例如现在每个家庭的房产就是几百万上下，离个婚比企业倒闭还搁闷。现在离婚率这么高，生意就好了。
