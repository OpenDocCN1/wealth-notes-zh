# 农民是怎么做外贸的？

当年，我在读大学国贸课的时候，被很多术语搞得一脸懵逼，实在是佩服很多农民也会做外贸。实际上，农民哪里看得懂外贸流程。后来，我去外贸厂看了才知道。

做外贸和做农村生意是一样的，不需要懂外语。

一是订单生意，出口日本一百双拖鞋。外贸厂是怎么做的？世界上有个神奇的宝贝，叫做外贸业务员，一天到晚在网上拉单子，万一碰巧拉到单子，他就找个他信任过的小厂开干。农民只需要完成做做拖鞋这个环节，收钱发货。其他不用管，业务员去解决。至于这个业务员把拖鞋卖到农村，还是卖到日本，随他了。
