# 06

什么是边际？第二杯半价。

边际函数是所有中文学生最头痛的概念。因为我们的传统文化中没有这个意思。我简单解释一下，

第一杯咖啡成本是15元，包括场地租金，人员工资，广告费，装修，拉客费用。但是第二杯成本是多少？几乎为零。因为第二杯咖啡不存在这些成本了。这就是边际函数的意思。
