# 11

我买过避暑山庄类的小别墅，后悔了。

人总有一个贪婪的欲望。看到好东西就想占为己有。我曾经在一个风景美如画的破地方山区看到卖房子的，也不贵，顺手就买了一套大户型，回家和菜嫂说了一下。菜嫂说，你自己去装修。我顿时觉得天昏地暗，发放了几个月，交房后发现，事情也很简单。当地人推出了套餐服务。就是ABC三个装修，明码实价，你选一个就行了，半年后来收房子。

半年后，房子装修好了，基本差不多。我也挺高兴，但是每年各种缴费很麻烦，而且小修小补也找不到人，上门服务价格高的不像是旅游区。

前两年，心情好，还去了几次。现在压根不想去。什么都好就是无聊。一天到晚就是做饭买菜。我是带保姆过去的，也不完全解决问题。因为买菜都是路边摊，还是要自己去。否则，保姆买的总是不合心意，质次价高。

这种旅游房子，最大的问题是无聊，没什么商业设施。一般就是寒暑假假有人来，这种情况，养不活商业设施的。没有理发，没有购物，没有一切，就只有一个超市。天一亮，就只能看黑乎乎的农村了。

我基本上不出门就是在房间里看看手机新闻，WiFi有的。隔壁很多家庭，一天到晚打麻将，吵死了。

你要是喜欢这种山间别墅，你可以去雁荡山找几个农家乐住一段时间，不要规划回家时间，住到腻味，也就是一两万。而且生活方便，玩的时间多。
