# 03

穷会遗传吗？不一定，很可能。

一个孩子，从一张白纸变成一个社会人，经历了二十几年。这其中99%的内容是父母教给他的。行为模式，思维方式，待人接物，风险判断，吃苦耐劳，精益求精。如果你的父母，不能在这些方面做出好的表率，孩子们也可能耳濡目染的重走老路。

举个例子，父母抽烟喝酒打麻将的，子女基本都会粘上一个。因为他在内心觉得，这不是什么大不了的事情。而父母不是这样的，孩子们就会很警惕，我爸妈没有这样，我谈不该做呢？我要好好想一想。这就可能阻止了很多不良嗜好。

我在生活中观察到一个有趣的现象，如果父母不买房的，儿子基本也不想买房，因为他们父母就是这么做来的。他们父母往往是福利房时代的人，不买房，或许可以理解。但是，子女们只看到了结果。

我家就两件事情，房赓传家。我和采嫂以身作则，有钱就花在房子身上，有时间就花在孩子身上。我一直告诉孩子，我是怎么对待你的，你将来就怎么对待你的小娃娃。

我从来不借钱。我拒绝一切网络小贷。朋友之间也不借钱，如果因为借钱闹翻了，那也无所谓。
