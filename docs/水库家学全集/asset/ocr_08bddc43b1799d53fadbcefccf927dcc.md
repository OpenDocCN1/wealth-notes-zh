# 04

菜菜，我给你说一个现象。部分女生歧视我们低学历的男生。

我是三校生，没学历，也不喜欢读书。我现在生活还不错，上班拿工资，下班打游戏，爸妈做饭。我在某大型工业企业做仪表班长，就是检测各个仪表盘的数据，如果遇到异常，我可以第一时间拉闸，相当于IT公司的大数据分析。当然，工资比不上他们。我的工作挺重要的，我现在月入七千多，还是大公司。

我最大的苦恼是，找对象麻烦。现在的女孩，眼睛长到天上去了，看不起我们这样的三校生。这些小女人不就是漂亮一点，学历高一点嘛？有什么了不起的。她们很气人，见面不到半个小时，就拐弯抹角问你有没有房子车子，家里啥条件？我很气愤，为什么不谈谈感情，非要比来比去谈房子？

我现在住在父母单位分的小房子，你也知道，就是那种上世纪七十年代修的，又土又旧又小，采光也不好，到处乱搭建的老公房小区，还没有产权，只能住，不能卖。当然，我家也不可能卖，毕竟是我爸妈的房子。

前不久，我们车间来了几个女的合同工，是你们老家农村的。我是一个个不愿意，一万个不同意，但是，没办法，形势逼人啊，我就试着讨好一下这几个村花。没想到，她们直接问我有没有房子？气的气当场发飙了。要脸吗？

车间里不行了，我就托亲友在浙江给我找个对象，没想到，人家还是问房子。我已经出离愤怒了。菜菜，想我们这种老实人，没有学历就不配结婚吗？
