# 01

当读大学比贴瓷砖还容易的时候

考大学的录取率达到80%，这个数字已经令人目瞪口呆了，特别是我们这种高考独木桥杀过来的人。物以稀为贵，现在后20%值钱 了。

考上大学，就可以在免费宿舍里打游戏，吹大牛，睡懒觉，没人管了。父母还要拼死拼活给你寄生活费，希望你以后出人头地，给爸妈买车出国游，衣锦还乡。只可惜，你一个破二本，每月三四千块钱，偶尔用一次小旅馆都舍不得。

与此同时，后20%的倒霉蛋，没有免费宿舍，只能在父母的一片埋怨中去大城市打工。高中生毕竟有点脑 子，知道什么赚钱。大场面，贴瓷砖，铺地板，扎钢筋，慢慢就会了。等你大学毕业，像个臭苍蝇一样嗡嗡嗡嗡乱找工作的时候，人家 已经是工地上的小队长了，年近二十万。

再过几年，高中生在烧烤摊把酒瓶一摔，也拉起了一个小队伍，自己接单了，流水几百万，年入大几十万，二手宝 马，京沪老破小都有了。而你呢？还在空调房里，为了几十元加班费和HR闹闷不乐。人生啊，就是这么公平。不要和我说 什么考上大单位之类的话，你就是一滩烂泥，只会打游戏。我呸。

# 02

功夫在校外

学校里，老师给你的东西是千篇一律的，而且老师重点关心的是第20-30名学生，因为70分拉到75分很容 易，92分拉到97分，基本不可能；老师关心的是平均分。但是，真正分配利益，985名额，靠的是分数，怎么才能拿到高分，成为 霸道总裁，小美白扑上来？这就看校外功夫了。

+   1. 一是拼家长。小学是家长砸时间，到了中学就是砸钱。
2. 二是拼体力。一个晚上七八个课程要复习，你干到十一点，我干到凌晨两点，看谁厉害？
3. 三是拼老师，你自学成才，也要花时间。我有优秀家教点拨一下，比你节约一个小时。
4. 四是拼经济，我每天上学是专车，你走路，我就可以多睡半个小。
