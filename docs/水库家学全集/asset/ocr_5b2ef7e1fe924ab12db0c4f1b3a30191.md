# 亿豪丈母娘如何挑女婿？

实际上，菜嫂也不是250，她有她的想法。菜嫂是村里的著名学渣，数学课只能听懂前十分钟。缺啥补啥，她发誓要逆袭，嫁个top1的。

这是歪打正着。挑女婿一定要挑一个读书好的。成绩没用，毛用没有。但是，读书好的孩子，自律性特别强，不会轻易败家。

你看我，没有任何不良嗜好，就是因为自律性强。多年前不限购时期，我用一百多万私房钱买了一个房子合法赚了五百万，全部交给丈母娘了，后来就不上交了。丈母娘心满意足，到处炫耀女婿会赚钱！搞的各个老板家的女婿烦死我了。他们千方百计腐蚀我，派各种小美拉我下水，我偏不。因为我口袋里没钱。

常在河边走，就是不湿身！后来，他们就不带我玩了，再后来KTV大涨价了，我现在后悔大了，没有在低价时代玩够了，现在亏了。
