# 我对农村生活是有切身体会

我身上还有几个疤痕，是当年在农村睡觉，被床上跳蚤咬的。后来抓破了，留下了烟头大小的疤痕。

农村生活是非常艰苦的。割水稻，第二天，腰是直不起来的。打谷子，必须非常小心，否则手会被机器切断，每年都有。夏天害虫多，大田里打农药，简直是不说了，能够不晕倒回家吃饭都是高技术了，更不要说什么挖松茸了。这么好挖，农村还会有困难户吗？

农村女人过日子从来不穿白色纱纱裙子。因为干活脏，白色不耐脏。另外，蚊子太凶了，一口一个大包。农村大姑娘是不爬树摘柿子的，我也不知道为什么，就是没见过。
