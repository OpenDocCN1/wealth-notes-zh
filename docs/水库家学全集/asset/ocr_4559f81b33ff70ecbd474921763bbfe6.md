# 穷就是懒

给我送家电的90后农二代。我的门是60厘米，家电是宽58厘米。因为门后面有个挂篮，实际上只能打开到55厘米，家电进不来了。我问小哥，你帮我拆一下挂篮，“可以，小费一百元”。因为那个挂篮是开发商送的，内六角螺丝固定。我没有工具，拆不下来。我心里一万个草泥马奔腾，但是总比以前自己折腾好，认输了，给钱。

送货小哥立马喜滋滋干了一分钟。他说：你不要觉得亏了，家家户户都有各种意外情况，一天赚五六百是基本小目标。有一次装洗衣机，房东龙头不对，我更换龙头赚了178元，成本几块钱。我们就靠这个过日子，否则一个月五六千的死工资怎么活啊？现在的人不愿意干活。我介绍表弟来干，他是大学生，不愿意。

在如此美好的年代，几十年了，你家还是穷，怨谁啊？
