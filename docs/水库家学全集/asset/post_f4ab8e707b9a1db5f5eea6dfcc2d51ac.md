# 为什么小县城容不下高质量的就业？

![](img/8b9dd9f40aac6260941086d97563c304_1091_0.png)
![](img/8b9dd9f40aac6260941086d97563c304_1091_1.png)

很多行业的聚集需要大量的人口基数。举例，小县城卖苹果手机，肯定是不行的。因为没有那么多消费力。小县城卖高级家具，一套二十万，肯定也不行。因为这种需求一个月也不会有一个顾客。小县城肯定不需要设计院，只需要棋牌室。

高端消费需要大量的人口基数，然后万里挑一。前两天，菜嫂给小娃找报了一个骑马班。第一阶段，三万。这个消费需求，在小县城肯定是微乎其微的，估计场地费也找不回来。但是，大城市就有这个需求，张家不来王家来，就算万里挑一，也有几千个潜在客户。

高端就业需要高端消费。补个牙一万元，县城的消费有多少人愿意，就不好讲了，但是大城市肯定有巨大潜力。如果没有稳定的高端消费，就没有稳定的工作岗位。有一次菜嫂在北海想买一个高价蛋糕送人，预算300-400元左右，最后在网上只找到一个店。

京沪广深会有会展业务，是一个大行业，但是除了这几个地方，其他地方根本不可能搞，连南京杭州都不行。

我家门口有个做塑钢门窗的小店，开了十年八年了，生意爆好，因为附近的老公房卖来卖去，换阳台门窗的特别多。你在村口搞个饭店，分分钟倒闭。谁来啊？现在的农村，就两个生意，烟酒小卖部，麻将桌。人口基数越大，人口越密集，就业机会就越多，生意就越好，工资越高。

结论：大学生发展一定要去大城市，那里有机会，各种稀奇古怪的行业，就是你的机会。

# 什么是企业管理？

小时候以为企业管理大概和数学差不多，设计好流程，尽可能高效。长大了才明白，实际上企业管理是世界上复杂的学问。举例，

小王一天到晚打游戏，没钱结婚。老王想发财，创业失败了，不得已出来找个工外。贵公司正好缺人手，就把他们两个招进来了。小王想偷钱，老王想发财，你希望他们认认真真干活，他们不愿意。你怎么办？换人也一样。

老板要把千奇百怪的人转换成想法一致、干活卖力的员工，是非常困难的，而且十有八九是失败的。举例，公司有内鬼，把公司的小秘密，例如进货渠道，设计思路，客户名单悄悄卖了，你怎么抓现行？库房有五十万件货，库房三天两头偷东西，你怎么管？技术主管没几个月就要加工资，你怎么办？
