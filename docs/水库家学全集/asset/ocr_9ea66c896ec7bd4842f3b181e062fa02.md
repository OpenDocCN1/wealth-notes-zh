# 读书重要吗？不一定。

财上海微博  2020-08-27

![](bbox=[0.48, 0.118, 0.52, 0.14])

如果你早生三十年能不能分房子？我肯定可以分到。

那时候分房子也是很累的。一要编制，二看职称。如果是副高可以确保。

分房子又有两种大情况。一是京沪广深大城市，二是穷乡僻壤的工矿企业。

大城市分房子是很难很难的。简单说，如果你在一个令人羡慕的好单位，又有职称，30岁有个筒子楼一室户（无厕所），40岁可能是二层居老房，50岁分个大一点的二居室。再好的房子就要看你的层次了。如果是有编制的普工，到40-50岁，可能有个十平米的棚户区。

山沟沟里，分房子比较容易。因为土地不值钱。大企业一般有一些卡车设备，买一些水泥砖头，附近找一些农民工，就可以盖房子了。这些房子现在估计还在，就是很破很破的筒子楼。小普工是一居室无厕所，中级职称和老普工是二居室带厕所，副高以上是三居室。地段是当年的偏乡僻壤，进城需要一个小时公交车。

当年分房子是建立在低工资基础上的。我们那时候吃一块雪糕都很高兴。你自己对照一下。
