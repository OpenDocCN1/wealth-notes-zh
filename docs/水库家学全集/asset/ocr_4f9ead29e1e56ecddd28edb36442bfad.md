# 高考考题是怎么来的？

找了一些老师，关起门来出题，然后选择了一部分题目发下去考。

老师面临很大的尴尬，他们凭什么空出题？而且要保证万无一失，接受全国学生老师和专家检验，没有漏洞。这个要求很高。一般人搞不出来的。

出题老师接了这个烫手山芋怎么办？肯定是把以前的题目改一改，看上去改的面目全非，但是内在的解题思维不能改，否则就会出漏洞，被人嘲笑。

学生怎么办？海量刷题，把各种各样的题目背出来。在考场上遇到不会的题目（改的太厉害了），也不要慌，你不会，别人也不会。我不是像财上海那样考top1，我只想考个低端985，例农林山大那个档次就行了。

你只要把市场上可以买到的书刷一遍，保证没问题。
