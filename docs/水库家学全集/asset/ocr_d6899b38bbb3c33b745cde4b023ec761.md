# 过上富人生活需要多少钱？

富人不一定对豪车感兴趣。因为在大城市，没人看你的车，车都停在地下车库。我有个熟人，买了个豪车，我这这么多年就没有机会见过车，只见过他故意拍桌子上的的车钥匙。他花了一百多万没人赞美，好像也挺失落的。

富人一般需要有个漂亮房子，在京沪广深，漂亮房子1-2千万肯定够了，你非要抬杠几千万，我就不陪你了。而且现在价值1-2千万的乡下别墅，当年买，可能也就几百万而已，不是特别贵。

有了房子和一个正常的车，再有30-50万，就可以过好日子了，你千万不要以为土豪都是挥金如土的。如果你没有什么特别花钱的项目，例如喝歌麻将喝哄头，一般30-40万纯花费就非常好了一家人过正常日子，菜嫂挎个篮子买菜，再买点零食，我家一天最多也就花费三五块钱。

我也没有刻意节约，菜嫂喜欢买插花，网上买，或者去花市买，一把几十元，可以用一个星期。我一天吃巧克力，也就30元。如果你在家里抽烟喝酒，一个月五千肯定够了。当然，也有一些贵的项目，例如空调地暖，一年五六万。孩子兴趣班几万。也就这些了，平时吃吃喝喝，养几个车，旅游一下也没多少钱。

富人最大的开支是喝哄头，那是无底洞。为了爱情，砸几个亿都不见一个水花。
