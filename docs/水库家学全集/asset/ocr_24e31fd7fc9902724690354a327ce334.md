# 01

为什么网上一天到晚在烘托团队的重要性？

因为团队重要，所以，你要培训团队。怎么培训？请大师培训。大师的生意就来了。那么，培训重要吗？不重要。

人干多少活，完全看钱。我以前培训过一段时间的员工。他们说，你把请大师的钱给我们吃一顿，效果更好。大师培训什么内容？就是老板喜欢听的那些。例如加班加点是提升自己之类的话。老板听得很高兴。实际上没用。员工要的是加钱，不是提升。老子快四十岁了，也不想提升了，能不能加点工资？

绝大多数人去小老板那里干活，就一个原因，挣点钱花销。你请个大师来培训，也不错，老子眯一会儿，不用干活了。

结论：培训没用。奖励有用。敢扣钱？老子就去告你个龟儿子！

# 02

闷声发财是王道。买了大房子要不要请穷亲戚（朋友）来玩一次？

你请客的目的不一定是炫耀，而是要体现一下热情。但是，别人不是这样想的。一个一个请客，你也觉得很麻烦，最好是打批发，一下子全部请来，一大桌全部打发了。

你买了一个一两千万的大豪宅，别人也不能空手来，总要带个红包。这下子你得罪人了。

首先，别人很痛苦。你这房子也太好了。我一辈子也不敢想。曹尼玛的，凭什么你这么有钱？

第二，别人还要恭维你。毕竟你摆了一大桌，别人也不好意思说不好。

第三，当亲戚回到自己的老破小里，实在气愤，你过得那么好，为什么不借（送）点钱给我？

于是，穷亲戚全部认为，你就是在炫耀，气我们。你就是个坏人。

以为这么多年的观察，这种情况大概占2/3。你花时间又花钱，最好只不过一次性得罪了所有人。
