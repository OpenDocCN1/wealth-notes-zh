# 01

屌丝的好日子从结婚开始算到头了。

结婚前，屌丝家里大概是三个人上班，父母 + 儿。如果没有意外情况，绝大多数家庭，每个月能够存 1-2万，现在农民工只要肯下力气，收入很高的。我家保姆，包吃包住，自己一个月八千，老公是电焊工，包吃包住，一个月一万多。儿子开滴滴，一个月七千八。很多家庭如果上班5-8年，存款50-80万，县城首付就出来了。但是，只要儿子结婚买房买车，小县城一口价是一百万，小车十万，然后就一贫如洗了。

一年后，孙出生了。婆婆带娃基本就不上班了。公公的年龄也大了，工资高的岗位也慢慢做不动了。儿媳妇，在县城的三室两厅里面住习惯了，还有婆婆带娃煮饭，十有八九不愿意上班了。这时候，爷俩上班，养活五个人，而且还要支付小县城的物业费，收入就紧张了。再过几年，娃要上幼儿园，媳妇要买化妆品，父母开始跑医院，屌丝就崩溃了。

怎么办呢？

一是媳妇最好产后上班。

二是公婆也去上班，补贴丈母娘来带娃。

三是屌丝争取考个正式编，或者贴砖。
