# 訂正15万円

告别这位富婆后，小哥可能还要前往下一家继续“工作”，有时难免需要过夜。

![](img/8b9dd9f40aac6260941086d97563c304_1212_0.png)

就是这样看起来轻轻松松的“工作”，生驹卓也每个月可以收入数百万日元，甚至有单个富豪一个月就会给100万日元（约合人民币6.6万元）。

面对着镜头，小哥轻松写意地留下这样一句话——

> “能够和我一起欢度时光，付钱是理所当然的。”

![](img/8b9dd9f40aac6260941086d97563c304_1212_1.png)

受到新冠疫情的影响，很多行业都陷入经营困难的危机之中。由于各行业不景气以及要求自觉居家隔离，生驹卓也的“软饭男”事业也受到很大的影响。最近再次接受电视节目采访时，他表示自己确实跌入人生低谷。如今保养他的富婆们，从之前的15人减少至7人，这也导致现在的收入大不如前，一个月“只有”近40万日元（约合人民币2.6万元）。

![](img/8b9dd9f40aac6260941086d97563c304_1213_0.png)

40万日元的月薪，对一般日本人来说也算不错了，更何况每个月就上几天班而已，但是对“软饭男”生驹卓也来说，的确可以算是收入遭到腰斩的地步。对于疫情的影响，生驹卓也这样描述道：

> “这段时间无法和女生见面，也就无法像往常一样获取收入。”

> “有天一觉醒来，看到手机上的信息，有位女生说要求出门”，也就是说不再继续包养了。

> “这位女生平时给钱最多，我月收入的一半左右，都是她给的。”

![](img/8b9dd9f40aac6260941086d97563c304_1214_0.png)

如今收入大幅下滑，生驹卓也的住处也从夜景无敌的高层豪宅，搬到了十来平方米的普通单身公寓。和之前的生活相比，小哥也多了一项“新工作”——就是在家里给有交往的富婆打电话聊天，然后请求对方打钱过来。

![](img/8b9dd9f40aac6260941086d97563c304_1214_1.png)

![](img/8b9dd9f40aac6260941086d97563c304_1215_0.png)

![](img/8b9dd9f40aac6260941086d97563c304_1215_1.png)

### 06

毕业找工作。

有的人贪图安逸，有的人希望升职发财，有的人追逐廉价满足。实际上这些人在十多年后，都会后悔。因为没挣到大钱。青春时代念念不忘的大平层，小美白，一样也没捞到，气的睡不着。

全国各地的小王，毕业后进入一个大单位，四平八稳，月入八千，食堂有晚餐。找对象也容易，单位是金字招牌，平时不需要花钱，几套大超市买的西装就能够上班了。但是，这些人到了四十岁会突然发现，很多初比不上自己的人一飞而起，赚了大钱。为什么？

因为进入大单位后，你只是一个螺丝钉，在单位这个大机器上，螺丝钉作用巨大，大家给你面子。但是大单位收入不高，一万多到顶了。离开单位，一个路边螺丝钉，价值等于零，你啥也不是。

我倾向于有志气的二本子进一个小公司，学学人家小老板是怎么赚钱的。小公司业务不复杂，逻辑简单。你在大厂当码农，你永远不可能开一个大厂。你在小厂跑销售，倒是也可能当小老板。当老板一年几十万，不用打卡，比当个螺丝钉工好多了。

很多人想当老板，但是不知道从哪入手。很简单，你就去一个小公司混两年，把小老板那套东西搞明白，再注意留心几个技术工人选，连哄带蒙，你很快就可以当老板了。千万不要去大公司，你无法复制。

# 地摊教程

地摊不存在品牌，针对的又是过路客，一次生意，永不再见，也不存在信誉度。所以，地摊的关键是两点：

- 一是地段。地段好理解，大家都懂，你在大商场门口摆摊，人流大，生意肯定好。问题是，门口就这几个位子，商场保安凭什么给你赚钱？这就要想办法了。省略一百字
- 二是货源。不同的地方卖不同的东西，海滨浴场沙滩上最好卖的不是海鲜炒面，也不是冰镇啤酒，而是游泳裤和挖沙玩具。我有一次被坑了。一袋子塑料玩具，包括铲子，塑料桶之类的儿童玩具，要一百元。我毛估估，生产成本也就五毛钱。但是，几个小娃娃非要玩沙子，我带着几个孩子，生怕出什么意外，没办法认怂了，我花了一百元买了几个儿童塑料桶，气的发疯。
