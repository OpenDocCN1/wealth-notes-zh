# 02

体面就业。

二十年前，我和一个大妈聊天，她和我说话，附近几个小区里，不上班的小年轻挺多的。也不是找不到工作，而是要求体面就业。体面的门槛是，有个办公桌，有个靠背椅，最好是带滑轮的，有个电脑，必须得上网。电子厂，送快递，你不要和我说，那是乡下人做的活，和我没关系。

我听的目瞪口呆，仔细一想，还真这样。某亲戚，女儿大专毕业，不想去小公司，想找个体面的工作。后来，不知道经过多少过程，进入了一个类似村委会的地方，一天到晚坐在电脑前盖章，她很满意。

我发现周围的本地年轻人，最低要求大概是物业公司了。五险一金，办公桌，办公室，只接电话，不干活。干活让农民工去，你只要嘟嘟嘴就行了。

我家保姆最近和儿媳吵架了。起因是换车。儿子这些年一直在考编制，多年的落第秀才，已经连续输了三Years，儿媳在老家小县城当超市营业员，婚房是老夫妻买的三室两厅的小县城大房子（156.68平米，精装修），还有一辆国产11.8万的车。儿媳妇觉得这个车没面子，要换个有牌子的，开出去拉风，看了一圈，发现二手宝马比较好，又大又气派。价格是16.12万。于是要求老头老太出15万。旧车出手大概1-2万。

保姆老公是在附近工地敲钉子的，两口子一个月凑一次，很辛苦，但也赚钱，一年可以带回去15-20万。儿媳妇觉得，你们钱多，就该你们出。保姆和我这事情，我也没办法。

今后人工会越来越贵，你家空置的装修早点办了，用结实 的材料，保证五十年不换。我安装楼梯的时候，有两个选择，五千块是木质的全包，我选了三万的水泥大理石。避免以后还要换，多麻烦。

小结，缺什么早点买吧。就我家保姆儿子那德行，以后有钱也难找人了。
