# 怎么赚钱？

人到中年，有了新的体会。赚钱不是高精尖，不是人无我有，不是我比你牛逼，不是985高级翻译。赚钱很简单，只要你愿意干活。

我家门口有个特别讨厌的农民老汉。他在人行道给人理发，搞得路面脏兮兮的。五块钱一个人，估计几分钟ok，一小时五六十块钱纯利润。这么说吧，我这么多年从来没见过他坐着，生意响到爆。顾客基本上是附近的老头，农民工，也不要求多好看，要的是方便便宜。附近的保洁员天天骂他。据说他十年下来给儿子在老家攒了一套大平层。难以想象。

我家门口有个刷丝黄牛，一天到晚坐着马路，背个破破烂烂的小黑包，收各种券，从月饼票到ok卡，一个月近万收入。尼玛币。

还有个朋友更逗了，他一开始是修电器的！后来居然是给人修手机电脑，有一次，我亲眼见他赚了二十元，有个老头手机没声音了（静音模式），他捣鼓了一下，打开了静音模式。老头千恩万谢，支付二十元。这还是小生意，后来，他开始做装修的网络布线给设备，和几个小队长合作！一天就是七八百。

小结，赚小钱不难，只要你想干就行。

在欧美生活过的人都知道，世界上最难办的事情就是找工作。我的很多同学为了找工作，可是苦逼大了。我有个博士同学，学的是会计学，考出了当地最难的cpa证书，然后去找工作，可就是不行。最后在一个修车厂找到了工作，那一天，他激动的热泪盈眶。
