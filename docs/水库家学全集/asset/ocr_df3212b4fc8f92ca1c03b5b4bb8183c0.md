# 01

菜菜，我前女友今天嫁人了。我有些惆怅，心里不是滋味。

答：有些事情要一辈子烂在肚子里，不能到处乱说。

# 02

菜菜，我是一个经济独立的女性，可结了婚后，我发现我沦为家庭的保姆，不仅要赚钱养家，更要带孩子、做家务。而他，工资少的可怜、更是懒癌附身，试过软硬兼施让他改正，效果微乎其微。想着孩子还小不能离婚，可总是按耐不住想一脚踹了他的心，感觉这样长此以往我会憋出内伤，如何是好？

答：不要劈腿。

# 热门评论：

+   论文在写了：不要劈腿，建议直接离婚

+   轻功女侠客：养娃可以，绝不养男人。

+   房产信贷哥：劈腿后财产就分不了太多了，菜总应该是这个意思

+   古丽梅朵N：及时止损

+   瑾玥夜：还不如保姆，保姆不操心。

# 03

前男友发财了。

菜菜，我和前男友分手才几个月，他就发大财了。我现在后悔大了，怎么办？

答：你喜欢的是钱，不是他，建议找个更有钱的，例如菜菜这种大叔。小别墅，大平层，内环线加名字，零花钱一年几百万。
