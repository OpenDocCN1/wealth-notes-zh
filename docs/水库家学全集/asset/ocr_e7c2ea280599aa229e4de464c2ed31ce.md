# 05

不要把孩子的未来拿去赌

  有很多人说，我也没有补课，孩子在初二自动逆袭了之类的话。但你想过没有，如果你孩子没有如期逆袭，你怎么办？你孩子就毁了。

  绝大多数家长不给孩子补课，唯一的原因是懒，还不是穷。绝大多数家长自己补课小学生课本还是可以的，基本不需要花钱。我家那个中年妇女，脾气大的令人讨厌，但她能够在家里吆五喝六，拿拖鞋飞我，就一个原因，她管娃很认真。

  我家人的时间表是铁打的。放学先玩一会儿。到家后，写作业一直写到九点半，然后扔给保姆洗洗涮涮。娃写作业，菜嫂从头到尾陪看着，不懂就解释，还要学各种小状元卷子。基本上，菜嫂没有在家休息的时间。

  管完娃之后，菜嫂就要来修理我，一般的套路是，上来先翻老账，历数我的各种历史问题，从她当年坐月子开始，一直讲到昨天我吃苹果，把一小孩苹果皮扔在地上。再要检查一下我的v信，看看有没有小美白给我发什么。我实在是忍无可忍，还是要忍。我已经想好了，等娃考上大学，我就要去广场舞唱幺头了。

  人生不如意十有八九。找对象不要看钱，还是要找个温柔体贴的。很凶很凶的女人没意思，一天到晚骂男人，唯一的区别是，你在老破小里被骂，我在大平层里被骂。
