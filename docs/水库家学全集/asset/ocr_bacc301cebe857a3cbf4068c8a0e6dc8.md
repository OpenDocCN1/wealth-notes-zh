# 为什么经济不好了，人们就会感觉市场上就没钱子了？

财上海微博    2020-05-11

# 01

大单位的人有几个敢辞职的？微乎其微。

我原来在十一个大单位，二十年就三个子辞职。前两个都是因为工作出现大的失误，被人指指点点，一蹶不振，不开
心走的。我是第三个，倒面丁了，欢天喜地走的。

一般人没有胆量敢辞职，特别是混的好的人，在大单位有个小小的位子，管了好几个人。你不管走到哪里，人家都会很
客气的接待你，以前，对方还要摆上几桌鸡鸭鱼肉。每次旅游后回到自个工作区域，就像是回到自己地盘了一样的感觉。

你不管家里有什么事情，直接去找相关部门的副头头，人家都是客客气气来接待你，在规则范围内想尽一切办法帮你
解决。实在不行，你厚着脸皮求来人，人家也不会太为难你，尽可能给你一个出路。

长期在这种环境中生活，你就会不太熟悉新情况了，对市场大期产生恐慌，甚至给你钱，你都花不出去。我曾经遇到
过一个头头。他以前的生活轨迹很简单，不管什么事情，都有人替他安排好了，包括早餐吃什么他都不用担心，到了小餐
厅，食堂经理会给他安排，他只要同意或不同意。有一次，他孩子摔跤住院后需要请一个保姆，价格不是问题，但是他就
是不会请，甚至去哪里找人都不知道。后来随便找了一个保姆，不满意。但是也没办法解决。我就把我冢保姆派过去了，
对方非常满意。

现在很多小中专毕业的人当了大老板。不是他们多牛逼，而是没人和他们竞争。最优秀的985就在单位里互相掐架，
给这些小老板钻了空子。气人吧？
