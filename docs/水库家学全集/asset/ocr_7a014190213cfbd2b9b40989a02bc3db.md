# 03

**林强大邦：**那厦门动不动上千万的房子谁买的起?

答: 你买不起不等于别人买不起。

+   一是置换。单位发的老房子卖掉五百万，这二十年存了一两百万，贷款就买了。

+   二是域外流量。厦门是福建省的顶级地段。大学生也多。大学生就业后，把父母老家的资金拉过来了。

+   三是新贵。这么多年，总有一些新发财的老板，买套房怎么了？

+   四是供应。厦门是个岛，青岛不是岛。岛内的面积就这么多了。供应量有上限。

# 04

为什么会出现那么多千万级别的房子？

我工资十万一年，不吃不喝，干一百年才行。这种理解是乡喔宁的尿溺。

真正的秘密是置换。新房一千万，老房子就是五百万，六百万，七百万了，这些房子是原来单位分的，不要钱。近二十年，家里也存了一两百万，再加上银行贷款，也就够了。

这里有个差价效应。开发商开出了天价，你手里的筹码也赚大了。原来旧换新，差价是两百万，现在工资大幅上涨，差价变成了四百万，存款加工资，也可以抵得上。

我二十年前去大单位上班的时候，转正后一个月1600元（大概）。现在的985，转正后1-1.5万是比较多的。

实在没想到，这么多年坚持说实话的，居然是牛皮癣中介。
