# 穷孩子的高考志愿

财上海微博 2020-07-25

# 01

知识重要吗？分数最重要。

我是top1，过了这么多年，解析几何和古文基本还给那几个白发苍苍的高中老师了。想当年，为了这点破分数，把自己折磨成什么样子了。

但是，也不能说无用。至少，这些古文让你进了一个优质大学。然后，我就哭着喊着冲进了大平层，赖着不走了，高高兴兴倒插门了。要是没有这些解析几何，估计我现在还在老破小里蹲着，以二本子的条件，估计也只有二手村花娶我了。

分数是竞争的排名。这个超级重要。资源永远不够的，这就产生了分配的问题。有大平层，有别墅，有老破小，有半地下室。谁拿什么？就看你在社会中的排名。理论上，应该按照贡献，但是贡献很难精确认化，副高就肯定不如正高，也不一 定。最简单的办法就是一刀切，看排名。

怎么提高分数？自己努力+好的家教。学区房没用。我是优质中学毕业的，班级里也有倒数的孩子，就像是大观园里的烧火丫头，被折磨的七窍冒烟，还不如小户人家的大婆，学校还关心一点。无论什么学校，老师都是打铃就走。你会不会和我没关系。

好多家长迷信学区房，实际上是偷懒的表现。他们想，老子花钱了，对得起你了，以后混不好，别埋怨我。这简直是不负责任。孩子能不能读好，基本看家长。特别是从小开始，养成良好的考试方法，而不是火上房了，再去砸几万报个班。

# 02

硬搞个重点中学有用吗？没用。

莱媛有个闺蜜，曾经自费就读于市重点高中的。他们年级一共六个班级，一半是全市掐尖招来的，一半是 高价的（以前有这个情况）。为了照顾消费体验，学校把掐尖生和自费生混班，同学们不用问就知道谁是谁。

市重点有个特点，考试特别难，每次考试，前二十名都是尖子生，后三十名都是自费生。当中有一个巨大的分水岭。据说，三年高中，自费生从来没有考过二十名。因为，前二十名实在是太牛了。她班级第一名拿了两个奥赛全国一等奖，一个是数学，一个是物理，top1点招了。

而后后三十名，一般只能在本二分数线附近苦苦挣扎。后来大部分进了劣质二本，就是名字很奇怪 的大学，我们这种老大学生闻所未闻的新学校，个别没读大学了。
