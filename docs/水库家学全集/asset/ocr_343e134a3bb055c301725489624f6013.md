# 你回得去老家吗？不可能了。

# 01

听人劝，吃饱饭。这句话是什么意思？

我年轻时候是不听劝的。原因很简单，

一是没面子。你劝我，说明我某件事情做错了，这实在是太伤害我了，我是那么要面子的屌丝啊！老子虽然没有钱，但是面子比天大，你居然敢说我不好？老子首先在心理上就不高兴了。

二是不服了。老子是985，你是啥东西？你居然敢教训我。要不要我说说你这个老东西？四五十岁的人了，不就混了个冷板凳吗？你有什么资格说我？不行，王八念经，老子不听。

三是太难受。人家说你不好，这事情肯定是你的长期动作，偶尔一次，人家也不会来说你的。但是，一个人的长期行为，是他生活经历和思维逻辑形成的，基本不可能改。我要是听你的，我就太痛苦了。

举例，我以前喜欢说小头头的笑话，把一群人逗得嘎嘎嘎的笑。我也得到了巨大的心理满足。这种愉快，你是无法想象的。你现在劝我，不要再小头头的坏话了！那我的快乐怎么办？我受不了啊！太难受了。算了，反正小头头现在也没有拿我怎么样，我还是快乐一天是一天。

四是做不到。我也知道三室两厅舒服，可我没钱啊！你劝我，又不借钱给我，你安的什么心？你是笑话老子吗？霍佬尼玛！老子不高兴了，你赶紧走，别让我再看到你。于是，我在四十岁的时候，也华丽丽混成了老屌丝。

小结，劝别人是没用的，你就让他一条道走到黑，他老了自然就懂了。

# 02

户口到底有什么用？孩子读书。

以我这么多年的观察，户口实际上就一个不可替代的用处，孩子读书。

买房买车，医疗养老，主要是看钱。但是，如果你孩子想参加中考高考，那就要看户口了，且不可替代。当然，如果你是亿豪，当我没说。

一，借读。理论上可能的，实际上，你去试试看就知道了。小地方或许还可以，大地方，你就要有点心理准备了。没你想的那么完美。
