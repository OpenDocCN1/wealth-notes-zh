# 05

刚才看了一个纪录片，就是“小村花遇到高富帅”的传统戏码。

绝大多数小村花都渴望改变命运，认识富二代，一步踏上人生巅峰。想什么来什么。高富帅登场了。

高富帅来自于非常贫穷的农村，父母都是多死嫁嫁人，动不动就棍棒教育的那种。高富帅初三没读完，就去街边捧打打工了。碰巧，他去了一个汽修厂。在汽修厂看到了一些富人的样子。

于是，他租了个豪车，冒充富二代，以谈恋爱不名，骗了十个八个垃圾大学的在读小村花。基本套路是，有个大生意，需要手续。让小村花帮个忙（实际上是网络贷款）。小村花，稀里糊涂就签字画押了，被人骗了五方八万。十个八个小村花加起来，这孙子爽死了。
