# 04

为什么老有人在我家门口照相？

今天我一楼客房里看手机打瞌睡，又有一群人围着我院子门自拍。我那个院子门，大概是1.5米，花了三千块，还算漂亮，按照英国农村风格买的，黑杆金顶。这事情天天有，特别是下午，一波接一波的游客，我以前一直以为我家院子漂亮，邻居们喜欢。今天看出门道了，我以后要收费了，一人5块钱。

我们小区大概有三百二百个房子，真正装修好，漂漂亮亮的英伦风，实际上不多，就那么几家。还有两家是新中式风格，就是门口有两个石狮子，院里迎客松的骆驼。近来，我们那一块中介生意不错。每次中介带人看完毛坯房，就会顺路带过来看看装修好是什么感受？让客户幻想一下大宅生活。我家是中介的必经之地，于是，中介顺手就把我家当做院子的样板房推荐出去了，反正也不花钱。客户看院子，中介就在不远处闲聊。

其实院子漂亮只是小case，真正好的是内部。院子漂亮，实际上很简单，你去花鸟市场，花几百元，买一大堆便宜的花，直接移植在土里，前三天非常漂亮，十天后，基本上有10%的成活率，多换几次就行了。真正花大钱的地方是内部。一个楼梯就是五万八万的。

每天都有好几拨人，一家老小围着我的门评头论足，莱嫂还洋洋得意。实际上，他们不知道，要装修成这样，打底三四个，也挺贵的。

# 05

倒插门的快乐，你想象不到。

我年轻时候特别重视性价比。举例，出去旅游，住宿是越便宜越好。最好是168。自从倒插门，和莱嫂在一起过了，就不一样了。莱嫂的要求是，必须在本地找最好的宾馆。一开始我觉得她有毛病，试了几次觉得超级有道理。

一是人舒服。

二是玩的好。你去旅游，大概有一半时间是宾馆里，特别是晚上，景点也不开门，你不就是行宾馆里吗？五星级宾馆和小旅馆不一样，里面有趣的东西多。如果这地方出茶叶，宾馆里肯定有本地茶供应，免费的，例如杭州龙井茶。来都来了，不试试吗？五星级酒店我少，没有遇到。确实贵了不少，但我也节约了研究的时间。

有一次在哪个宾馆，我记不清了，我带着婆婆去宾馆酒吧里玩。酒吧里，有一个很骚的女歌手在唱歌，一杯鸡尾酒是158，我和菜嫂一人一杯，听听歌。因为没有其他顾客，女歌手就专门让我点歌，一个多小时，偶尔享受了一把大老爷唱堂会的感觉。

三是吃的好。五星级酒店，一般是自助餐早饭，吃的特别好。晚饭是158的自费，一般也是自助餐，也非常好。我出去玩也不怎么吃午饭了，实在不行，就悄悄整个面包带着。宾馆自助餐干净，一般不会得病。而且这种地方能够吃到本地
