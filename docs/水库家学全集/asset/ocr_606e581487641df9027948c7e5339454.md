# 我这辈子见过的，最可惜的人才。

某丝，高考大省的理科状元。父母是农民，尽给他指指导。

那时候是先填志愿，后高考。最后，他考了个一般985的王牌专业。

大学毕业后，父母又指导了一下，他就回老家小地方，进了大单位，县电力公司。

结婚前，县里头面人物的女儿，托人来提亲。他父母觉得这姑娘长得不行，也不能吃苦，怕儿子受气，拒绝了。后来找了个二本师范学院的小美白。

高考，就业，结婚，全办砸了。一个天纵奇才，现在混成40多岁的老丝了，老婆已经变成了小媳妇女的样子，完全没有了小白美的感觉。前段时间，我回乡下，他遇到我，愁眉苦脸的。他想换房子，缺30万。我没搭理他。

这种人才，就算现在出去当老师，凭借20年前的声望，也是一个年入百万的香饽饽。可惜，他已经胆子小的像蚂蚁了，死活不敢。人的发展，是受到环境影响的。太可惜了。

遇到机会，不要怕。大家都是人，不比你能多少。丝丝们最怕的是风险。我以前也这样，总希望，能不能凭借聪明才智和吃苦耐劳，赚个无风险的大金元宝。这么多年过去了，我已经完全不担心风险了，甚至喜欢风险了。因为我理解了什么是风险。

这个世界，肯定有人赚钱。你不赚钱，是因为别人比你厉害或更有远见，挣掉了你的份额。你如果是人才，你就不要怕，可以自己给自己创造空间。我从来不怕竞争，因为我确信，我在自己擅长的领域，一定可以赢的。
