# 12

妇女也上工地了。

前段时间，我家装修，看到几个农村妇女，一个是种花挖土的，就和以前种田差不多。一个是贴瓷砖的，她老公也是贴瓷砖的，看久了也会了。妇女都是和老公一起过来的，开着一个suv，很漂亮的国产车。新的装修小区一般车位不紧张，到晚上五点半就开车走了，像是上班，只不過没有总经理。她们的月收入不高，比男工低不少，也就是一万多，太惨了。
