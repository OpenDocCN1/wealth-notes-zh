# 06

我也做过家教。

我教的学生是初二，英语。他们主要是考选择题。

我发现中小学教育，大班模式（40人），效果有待研究。老师板着一张死鱼脸，按部就班念一遍教案，就默认你会做题了，然后就测验，期中考试。实际上大部分学生就课堂上的听的那点东西，根本不可能去考试。

那个家长没读过大学，也不清楚什么原因，孩子考试成绩差。家长是大土豪，信奉快乐教育，快乐到初二，要留级了，家长急眼了，给我许下高额奖金，考到80分多少钱，90分多少钱。

对于我来说，这小钱一碟，简直是在送钱给我。我采取了一个简单办法。

+   一是把初中英语从头到尾快速过一遍。

+   二是刷题，错的我解释一次，然后孩子抄写到一个本子上。

+   三是坚持了一个学期，大概半年

孩子分数从65分，窜到了92分左右（满分一百），我也拿到了几千元奖金。那时候内环线大概是三四千一平米。

结论：家教的作用在于答疑，不是陪你做作业。
