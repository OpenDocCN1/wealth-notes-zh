# 12

富人的孩子早当家。

我是开公司的，经常招聘。我以前有个过时的想法，穷人的孩子，吃苦耐劳。所以，我特别看重这些孩子。实际效果非常差。

穷是相对的。现在的农民工孩子，你说富，也谈不上，你说穷，肯定不穷。耐克鞋，苹果机，高级餐厅，迪士尼，欧洲七日游，哪个没吃过用过。

他们的父母大多数在外打工，两口子一年能够打回家15万左右。但是对孩子比较愧疚，补偿方式就是花钱。这些孩子是在物资丰富，缺乏管束，沉迷于游戏机的环境中长大的。有个最简单的例子，你问问三十岁以下的农二代，有没有打谷子的经验，几乎没有。

这些孩子习惯了好吃好喝，不习惯非常艰苦的工作。有一次我让一个女工从浦东到长宁区拿个样品，她和我说要公司派专车，她不认识路。我尼玛啊，你不会坐地铁啊？

我有个保姆，女儿也来内环钱了，找不到办公室工作，就找我，意思是，工资没要求，先做起来。于是工资定为三千，也没有具体工作，就是打打电脑之类的。后来，这个女生一天到晚骂公司，打电脑太辛苦，工资亏待她了。

富人家的孩子反而非常努力（也有部分懒货）。富人家的子女从小到大，家长会有意识的培养一些劳动意识，也没有多报销占便宜的习惯，基本靠谱。富二代最大的缺点是看不起人。这就导致了他们没有什么朋友（狐朋狗友除外），没有朋友也就不知道人情冷暖，世态炎凉。
