# 读书的目的在于服务别人，而不是自己开心。

财上海微博 2021-02-08

# 01

原地过年好。

菜菜，我是30岁男，985本硕毕业，工作五年，存款有27.8万。我村里的初中同学，十六岁后打工至今，据说明年开一个建材小站，就在我们隔壁的郊区建材市场，菜人力三轮车给人送瓷砖的那种，我虽然看不起他，但人家也是凭力气吃饭，我从来没说看过不起他。

刚才，我爸爸电话，说这小子在外环线买房了，还是漂亮的新房，现在村里炫耀，他还臭不要脸的找小红家提亲了。我爸妈问我什么时候买房，我的眼泪哗啦一下就出来了。小红是我们村里最漂亮的姑娘，当年我也挺喜欢的，只不过，我现在是研究生了，不可能再回村里找她了。说到房子，菜菜，我根本看不起啊。我二十年寒窗苦读，985硕士，居然比不上一个踩三轮的，你说我怎么想？
