- 一是乘势而上。经济转型中，老的竞争对手消失了，新的还没起来，你正好有这个能力，迅速填补市场空白点。例如，以前的包工头变成了开发商，发的满嘴流油。
- 二是发明了新产品，又遇到了识货的人。
- 三是骗子们最喜欢的名词“资源整合”。你啥也不是，就是忽悠其他人为你的目标出钱出力，你拿走利润。如果你有真本事也行。这个行业以前叫做“拼缝”。老北京都懂这个词。
- 四是最普遍的做法，也是我家的法宝。在一个行业做精做细，掌握诀窍，然后找机会单干。我家以前就是在废旧市场，买报废机器，回来修好，再卖出去。

后来，在长期的工作中，发现有些企业很奇怪，愿意出高价维修某种特定机器，甚至开出的维修费高于新机器，百思不得其解，后来发现，原来有个季节性产品供不应求，时间就是钱。买新机器耽误时间，不如修。

### 如何办企业？我是3+1

说起来很复杂，实际上不复杂。三个角色是关键。

- 一是生产技术。任何企业都有一个对外销售的东西，你怎么把东西做好，让消费者买单。东西不仅仅是有形的，例如炸油条，也包括无形的，例如KTV，贴瓷砖。
- 二是销售，东西有了，还要卖出去。总有个人忙前忙后张罗。消费者的事情特别多。
- 三是行政。一个企业办起来后，杂七杂八的事，实在是太多了，任何一个事情都可以让你SB，要有个人处理这些破事。

老板干什么？老板主要是几个事情，

- 一是去借钱。资金永远不够的。
- 二是拍板。举例，滑板车千千万万，KTV千姿百态，你说做哪个？
- 三是下决心。有些事情，看上去可能做不成了，你能不下决心止损。损失多少，你要去找钱借来。

小微企业往往是3+1，老板和老板娘把所有的角色都包了。有利有弊。利是方便快捷省钱。两口子睡觉前说个十分钟，就把事情定了。弊是分散精力。很多事情，决定一分钟，做起来几个星期搞不完。举例，附近村民说你家生产影响了他养鸡，现在老母鸡都不下蛋了，要你赔钱。又如，老村长找你说，村口那条路，你用的最多，现在被你家的大车压坏了，你出十万修一下。车间主任和厂妹劈腿，王的老婆在门口又哭又跳。很多事情是非常难办的，需要一定的时间去折腾。如果老板和老板娘一天到晚就是这些事情，企业的主业就会耽误。

### 哪里的海鲜好吃?

我品尝很多地方，感觉越是北方越好。我侧重观察了几个地方，大连，青岛，舟山，厦门，北海，海南乡下。

海鲜类，都是软壳的，口感差不多。

贝壳类，蟹类，北方的明显好。冷水环境中，壳硬，肉质紧凑。南方的海鲜，肉质酥松，没有嚼劲。

西南西北华北的人，不爱吃海鲜，他们喜欢牛羊肉。我去四川，他们把冰冻小鳎鱼当做最好吃的海鲜，我差点笑昏六七。四川人喜欢吃兔子。北方人喜欢羊肉。上海人喜欢河鲜。浙江人喜欢醉虾臭冬瓜之类的，东北人居然喜欢吃蘑菇，各种各样的黑木耳。大名鼎鼎的小鸡炖蘑菇，实际上是吧鸡块剁碎了，和蘑菇，黑乎乎的一锅乱炖，看上去不怎么好吃。云南人喜欢山菌子炖鸡汤。贵阳喜欢酸辣粉，有个菜是小香菇炖研碎的鳐刺鱼汤。重庆人喜欢内杂碎火锅。山西人喜欢面食，刀削面，大馒头。安徽人喜欢红烧肉加白酒。
