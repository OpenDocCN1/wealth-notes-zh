# 03

你是学霸，关我鸟事？

曾经年少的我，在一次全国性比赛中获得了第二名。我激动坏了，立马告诉所有同学，但是，绝大多数人都只不过是淡淡的一笑，客气几句。

我容易吗？为了这个比赛，我拼的有多苦？你们为什么不激动呢？长大后，我终于明白，你的成功，只不过更加映衬了我的无能，我恨你还来不及，凭什么还要吹捧你？你要给我钱吗？

几十年后，同学们对我印象最深的是，我获奖后，就是一副小人得志的丑恶嘴脸。我？特码的心态崩了。

# 04

你原来一个办公室的小领导辞职创业了，找你帮忙（有点麻烦），你会不会帮忙？

你肯定不愿意。因为只有麻烦，没有利益。这也是你辞职后会遇到的情况。你在单位里朋友遍天下，那是人家看中了你的单位和你手里的一些资源。当你走人了，你就是一个毛用，没人对你感兴趣。

一过三十岁，你要侧重发展自己真正的能力，而不是沉迷于平台给你的虚荣。你在这个平台上可以走多远，基本是固定的。不要胡思乱想了。

任何一个平台都是金字塔模式。普通人一辈子大概可以得到三次晋开，前两次是骗你干活，每次相隔七八年，最后一次是接近退休的临终关怀，怕你想不开，干傻事。

这种很平稳的地方，有个必然的特点，日常收入是不高的，基本就是温饱，买日用品自由，不可能买房的。但是，这些平台会给你一种幻觉，买房不重要，我有这么多朋友关系，我很开心。
