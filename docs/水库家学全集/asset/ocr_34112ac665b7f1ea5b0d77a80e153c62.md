# 屌丝的快乐。

财上海微博 2020-12-26

![](bbox=[0.48, 0.12, 0.52, 0.14])

屌丝的快乐。

我家新来一个保姆，五十岁左右，她老公是泥瓦匠，年入20左右。她儿子今年26岁，二本毕业，在老家小县城，很快乐。

一是房子漂亮。她家是五年前买的房，单价5千多，是顶楼复式，142平米，实际上大概是200多平米。一楼140，二层超过1.9米层高的面积是70平米，俗称“楼中楼，空中别墅”。我看过保姆给我炫耀的照片，非常漂亮，家用电器，一个不少，还有壁暖。

二是有车，国产车，八万多。还有一个助动车，小县城内用。有地下车库，开发商送的。

三是有女人。他儿子结婚不久，老婆是小县城百货商场的营业员，学历中专，是超市杂物柜台的小队长，月入四千多。女方看上他们家的条件不错，儿子是大学生，立马就同意。

四是不上班。保姆儿子现在啥也不干，一用心思考编制。已经考了三年了。

五是有钱。她儿子靠父母和老婆养活。父母加起来，年入30-40，老婆也有5-6。房贷车贷水电气，根本不用他操心。父母寄钱，老婆做饭。他活出了最美好状态。

六是心情好。他们家在小县城，附近有山有水，风景宜人。他经常开车去风景区附近游玩，钓鱼（说是去看书）。晚上回家，豆腐炖鲫鱼。县城物价不高，一碟卤牛肉+卤鸡爪，加一瓶啤酒，也就三十块钱，美滋滋。

保姆问我，儿子已经习惯了县城的美好时光，说什么也不愿意出去打工。今后怎么办？我也知道。说实话，我也挺羡慕这个农村屌丝，啥也不操心。
