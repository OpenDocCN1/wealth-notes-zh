# 永远不缺代工厂的屠毛老板

我以前以为，生意不好了，开厂的新老板会少一些了，实际上没有减少，不怕死的多了。

绝大多数员工根本不知道市场行情，看到土老板开宾利，上女助理（虽然是又黑又胖），但很多屌丝还是嫉妒的怒火攻心。屌毛也想发财。怎么发财呢？屌丝最熟悉的就是他上班那点事。于是，屌丝和他150斤的老婆在冬天的被窝里开始盘算了，买机器，租场地，也不过几十万，我都打T好了。你看我聪明吗？工人都是我兄弟，一叫就来了，财务人理事老婆干，后勤卫生丈母娘干，采购销售交给小舅子，跑手续交给老丈人，几十万不过是县城一个首付而已。人人都可以开厂。人生难得几回搏！马上可以开宝马攒小美啦！

我见过太多的屌丝开厂创业，成功率为零，有个共同规律：三年亏完一套房子，老婆离婚占一半。前些年，屌丝老家的房价是上升趋势，所以，卖房创业，实际亏损更加厉害。

小美用上了没有？我估计绝大部分是用上了。前两天，又黑又胖的小美，老家来了个不知道真假的老公，堵在土老板厂门口要赔偿，还把土老板揍了一顿，土老板赔了十几万，最后的一点点贷数了。当老板不就这么点福利吗？

绝大部分屌丝有一个超级强烈的发财心，而且以自己特别厉害，老板是个蠢毛。屌毛们认为，如果自己当老板，肯定比现在的老板管得好。

实际上，小厂的秘密不是管理，而是单子非常平匀的源源不断进来，十年如一日，就像是厨师炒菜。这个事情是管理学中的甲级难题，很难解决。很多土老板喜欢赶场子拼命喝酒，还要抢着买单。为什么？就是去巴结人，争取大公司的生产经理给个两千台手机单子做。

> “这也不行，那也不行，我怎么可能发财？”

> “你就是个屌丝，发财和你有一毛钱关系吗？赶紧走人！”
