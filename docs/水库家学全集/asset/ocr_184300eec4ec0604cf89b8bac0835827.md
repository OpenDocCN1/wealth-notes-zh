# **03**

四十岁的大城市985，有没有手瑟？也有。

理论上说，在大城市，你只要按部就班随大流，一般也有一两千万的资产了。问题是有些屌丝自作聪明。

一是相信腰斩。我们当年工作的时候，内环线几千元。售楼小姐还要求你下单。我们老家旗子上那时候大概是几百元一平米，就怒了，差不多的钢筋水泥，凭什么加十倍给我？坚决不上当。然后，一年加一百万的速度飞跑，直接就死翘翘了。他越恨越愤怒：我家三代人的积蓄，一年就没了。我不接受，这些钱来的不容易啊，是我爸在工地上要死要活攒下来的。嚎啕大哭一番。

二是夫妻分手。一人一半，资产分解。各自拿钱租房。然后就没有然后了，现在已经在准备广场舞了。我有个女熟人，当年也算厂里一枝花，老公劈腿后散了，后来改嫁不顺，单身到现在，也就没有买房，现在成为快五十的灰层丝了，还一天到晚发一些旅游景点照片。她前夫倒也不敢误，七八千的时候买了苹花，现在和小村拾过得可好了。

三是股民，币人。这一批人比较多。

很多事情是这样的，原始股3块钱，现在40元了，你跟不跟？如果行情好，你十有八九会跟。各赚各的。但是，到了房子上，很多人就不爽了，凭什么，你六千买的，转给我就要四万？一怒之下真就不干了。你不要以为是笑话。

2010年，我公司有个员工，小镇女青年。当时在虹口区看了一个破房子，已经谈好价格了，我印象是100万，然后办手续的时候，她老公发现房东是总价1万左右买的福利房。心态崩了。最后没买，回老家买了个小县城市中心的大平层，单价5000，精装修。这个房子给他撩足了面子。女方是农村的，男方父母是县城有编制的。那一年过春节，热闹非凡。老家的农村人哪里见过这个稀奇？（现在不稀奇了）小夫妻季节决定回老家发展。但是。他们在老家大房子待了一年发现，小地方收入太低。又出来打工了。现在他们老家那套房子空关多年。两口子在内环线租了个棚户区，阴潮潮湿，日子苦巴巴的，若当年拿下那个福利房，现在400了，早就财富自由了。他老公现在已经变成钢筋了，谁也不能在他面前提房子，一提就翻脸。

人生不能回顾，往前看吧。我的意思是，下一代重来，还有机会。
