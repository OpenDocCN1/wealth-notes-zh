# 三十出头了，怎么办？

家庭矛盾。

某老板有两个女儿，大女外嫁，小女儿找了个上门女婿。去年，老板买了个大别墅，没时间装修，小女婿住不进去，急了，自告奋勇去装修。女婿是清水衙门的小上班族。老丈人给的预算足200万以内，女婿一激动，简直哭了，这辈子也没花过两百万啊。

我认识那个小女婿。人是好人，就是有点拎不清。小女婿是大单位的人，这事情一报一柜。装修队长和他耍心眼，被他一眼识破，于是漫长的拉锯战开始了。女婿以为装修队长要黑他，他就不惜工本的到处研究。

最后，女婿花了150万，自己倒贴了12万，终于完成了装修。为了节约这点钱，小女婿是遭了大罪了。每天泡在工地上喂蚊子。但是，最后一家人吵翻了。因为装修队长乱开价，小女婿还价，一来二去，所有的风格都变了。老板要的是豪华版，女婿装出来是小清新。老丈人大怒。

现在，一家人都在骂女婿不识货。我是装修过n次的人，深知装修的艰难。建议，儿媳妇女婿不要轻易给家里父母装修拍板，否则，很容易引起矛盾。菜嫂家装修，我给了8888元的红包，菜嫂家还觉得我好。

倒衙门要学会做人。
