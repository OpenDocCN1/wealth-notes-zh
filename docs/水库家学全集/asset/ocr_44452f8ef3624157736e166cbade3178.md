# 08

为什么非法私募会盯上老年人？因为老年人有钱。

很多人奇怪，老年人哪有什么钱？老年人有房子，通过房子抵押，可以在很多地方借到几百万现金。

大多数老年人的聪明劲全部用在对付亲人方面，防子女，防女婿，防儿媳，最后一套房子死死咬住，绝不松口。

这种看上去很聪明的老年人往往因为太精明了，一辈子没什么大钱。但是，这些人总觉得自己这么聪明，不应该没钱，肯定是运气还没来。一到傍晚等大发财的机会。看到这里，骗子们一拍大腿：我擦，就是他了。

非法私募有两个符合老年人的特点，

+   * 一是上不对顶，有多少钱都可以投进去。买的多的多，走过路过不要错过。

+   * 二是不需要现金，只要房产证抵押就行了。这个形式，极大的减少了老年人的负罪感。大部分老年人背一麻袋现金出去和签个字，心里状态是不一样的。

现在看来，几万块钱的玉石枕头，高科技床垫已经不能满足骗子们的需求了。希望大家提高警惕，回去教育一下老头老太：不要胡思乱想发大财。

# 09

为什么我使用京东商城？

其实，我一开始是不信任何电商的。京东商城当时打动了我，就一个原因，我要马上买一个大家电。众所周知，我房子多，相应的，我会经常买各种各样的大家电。

以前在上海，买大家电就几个选择，苏宁国美，还有一个上海本土品牌，陈晓做的，我记不清了。二十年前还是老式的谈判制度。开价1500，可以谈个优惠。但是，消费者最怕的就是谈价。无论怎么说，消费者肯定是冤大头，因为信息不对称。

这时候出现了一个京东商城，不议价，而且明码标价，不怕比价格。我当时还试验了一下，拿京东商城和某实体店的比价，结果比不出来。因为具体型号不同。于是，我不死心啊，就比相同品牌的相同功能。
