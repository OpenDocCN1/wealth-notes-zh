# 09

为什么要买个房子？

小王在内环线的一个好单位，混吃等死。她有很多梦想，但是不敢去做，因为她没有买房，没有归属感。她害怕失去贷款额度，银行是商业公司，非常看重事先审查，如果你在一个收入稳定的大单位，有面子的单位，贷款是很容易的。相反，如果你干个看上去很屌丝的，不稳定的工作，即使有钱赚，银行也不喜欢。

小王一直偷偷摸摸的在做辅导班，收入很不错，在家长的眼里是个优质服务。但是，受限于很多单位的原因，她不敢放开手脚，也就是熟人圈子里玩个票，挣点外快。

前不久，小王买了个房子，一切手续办好了，就立马辞了职。在一个辅导班混的风生水起，成为老板的明星员工，创收大户，好不惬意。小王已经想好了，再干几年，以后自己当老板。祝福这个勤务的妹纸。

结论：如果你在一个好单位，没买房之前，千万不要动，就在那混着。
