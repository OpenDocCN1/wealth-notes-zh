# 民企是啥样子？

我周围都是民企老板，实在是太熟悉了。

一是基本都是家族企业。企业内部盘根错节，都是亲戚。民企一开始没钱，也没有管理办法，只能靠亲戚，而且大多数是劣质亲戚，找不到工作，虚荣心强的。有个好单位的大学生亲戚是不可能去你的小企业的。

二是老员工欺负人。民企的部门经理，一般是老员工。这些人没有什么文化水平，基本都是大老粗。欺负人是一套一套的。但是，老板也没办法，人家以前有功劳的。总不能就翻脸了。

三是老员工欺负新员工。欺负的方式，就是甩锅，背锅。老员工很精，什么事情很累，什么事情容易出问题，是明白的。他们遇到坑，自己不去干，就把新员工派出去背锅。新员工辛辛苦苦干。干好了没有功劳，干砸了就背锅。新员工肯定不高兴。

四是没有晋升通道。民企一般也就5-200人，内部杂乱七八糟，有花头的岗位也没几个，而且基本不会变。也就是说，新员工很难出头。所以，流动性大。我那个会计部主任，干了二十年了，从小姑娘进来，现在都快退休了。这个女人因为熟悉业务，资历深，公司上上下下谁也拿她没办法，她五大三粗一米七，体重两百斤，凶的很，谁都敢骂。我看到她，就躲着走。

说了这么多，民企有没有好处？也有。

+   1，培养老板。民企是给聪明人准备的。民企业人少事多。如果你是有心人，三年之内可以全盘掌握办企业的方方面面，包括99%的细节，配方是老板自己在自家车库里配的。我那个会计主任，经常去跑各个窗口，成功率高，如果换个会计，估计在哪里停车交材料也搞不清楚。

+   2，高薪也容易。民企高薪是没有天花板的。只要赚钱，你年入百万都可以。我有个熟人，改进了一个辣条的配方，现在比老板还厉害，经常警告老板，“挖我的人多了。我在这里是给你面子”。你听听，就这种话。
