# 有人请客还不来？

刚才有个同学说，别人请客，你居然不去吃饭？是的，这是成年人的忙碌，生瓜蛋子不懂的。

绝大多数，有点面子的人，不是你一叫我就去的。去，是给你面子。你是不是值得我折腾几个小时，还真不一定。

内环线饭点一般是晚上6点半，开车是晚高峰，很麻烦。到了地方，还要停车去地下车库，来来回回折腾找电梯。

吃饭一般要2个小时。

回去方便一点，半个小时左右。

到家洗洗涮涮，基本十点了，相当于一个晚上没了。如果你是闲人，巴不得天天有人请客小青龙，大鲍鱼。但是，对于我们这种有事情要忙的人，还真不感兴趣。

去之前，一般也要想着给你带点小礼物，这又是头痛的事情。我一般简单化，带一瓶百元酒或者一盒龙井茶。

去之前，还要想想，待会儿说什么好？

还要考虑，其他人是不是熟悉，如果不熟悉，或者不对付，何必去凑热闹？

每个区吃饭的场子就那几个，吃来吃去也就是这些菜，吃了十几年了，有什么好吃的？所以，绝大部分饭局，我是不感兴趣的。

# **热门评论：**

+   1. 菁·贝贝：像我们要辅导孩子作业的更是一秒钟都不想被别人占用
2. 用户住宿费：就是这样，能去都是给面子或重要的人，阿狗阿猫的一般都嘴艳
3. jsonlorer：同感，如果不是交情特别深或者有益往来的，还真不想去，谁也不缺这顿吃的，大老远的，还费时间费力
4. 狗尾巴草皇后：无效社交很无聊
5. 小仙仔嘭：不去很正常啊，大家下班都很累了
