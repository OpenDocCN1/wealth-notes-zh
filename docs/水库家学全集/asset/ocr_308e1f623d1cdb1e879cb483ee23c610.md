# 02

为什么城里姑娘不敢要彩礼？

因为竞争激烈。现在的情况是，村花一窝蜂的涌入京沪广深，和城里姑娘一起硬怼，竞争激烈，城里的未婚男没有增加。除了20%的优质男，剩下的男人，其实对于老婆是哪里人，一个月赚多少钱，要求并不高，反正也没好的。这时候，区别就出现了。

一是心情。城里姑娘，一脸傲娇，看的老子就不高兴了。村花可温柔了，老子一个月赚八千，村花就觉得自己是天底下最厉害的男人，比我们老家的村长还厉害。男人的自尊心瞬间膨胀一万倍。

二是年轻。二本狗已经30岁了，人家村花才22岁，照样高高兴兴来相亲。要是城里姑娘，估计在翻白眼了。

三是不要求买房子。村花一般不要求京沪老公买房，也不要求加名字。有的住就行了。城里丈母娘烦人的多。村花实际上有一个隐形补偿，就是户口，京沪户口还是比较麻烦的，考上985都不行。城里姑娘不需要户口，一张嘴就是房子车子。你有毛病啊？

四是选择多。不管你是二本子，还是五十岁的老西瓜，还是七十岁的老大爷，总有一款适合你。洗衣做饭，样样都有，只要有房子就行，老破小也可以。

村花好处多，态度好，简直是捡到宝了！城里姑娘面对如此残酷的竞争环境，哪里还敢要彩礼？
