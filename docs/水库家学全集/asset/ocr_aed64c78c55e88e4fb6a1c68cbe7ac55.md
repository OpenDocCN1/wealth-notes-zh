# 幸亏找了个大学生老婆

刚刚陪小娃娃读了一会儿英语。我有点发懵。现在的儿童英语有不少貌似偏僻的生活单词，例如大部分人不知道沙发靠垫，拖把怎么说，但是，现在儿童英语越来越多的出现了这些单词。有些常用单词，要求你非常准确的辨析各种用。还有，英语发音是很关键的，如果跑偏了，以后麻烦很大。老婆不是大学生，你还真的玩不转的。

建议上知天文下知地理的二本子们，还是多考虑一下，找个大学生老婆，虽然丑了点，但是以后用起来方便。你一个人，又要创业，又要考职称，还时不时要给前台小美帮帮忙，一个人忙不过来的。你可能觉得，老婆丑，用的不开心。也没什么，以后条件好了再想办法。

办法总比困难多，侏房子买好了伐？

# 励志故事

老王是我们村为数不多的高中生，在那个80年代，农村高中生会数理化，相当于咱们村的博导了，因为金凤凰考上大学就不会再回来了。老王在90年代出门打工了，也没什么技术，就去工地搬砖。过了几年开水泥搅拌机，又过了几年，水电工进了，他就临时代替水电工，反正缺什么顶什么，谁让他是文化人啊！

兜兜转转到了2008年，一个建领队的小老板要退休了，于是老王接手了这个建领队。干完活，没拿到钱，老王就变卖家产，把工友们的钱垫上，他也不干活了，一直盯着甲方要账，最后拿了一些房子抵债。然后！因为大家都知道的原因发达到。

发达之后，老王干起了装修公司，又是年入百万的活。他信誉好，在工地上人头熟，叫得到人，生意越做越大。

现在，老王已经是土豪了。感谢市场经济给了老王这样的农村人一个出人头地的机会，前不久遇到老王，他已经卸甲归田了。在外环线买了个别墅，给儿子结婚。他自己回老家，建了个小儿尔寨官，还包了一个山头做茶叶，在山上搭了个非常漂亮的凉亭，没事的时候可以喝喝茶休息一下。天夭炖老母鸡，泡很腿，抽金南京，喝金种子。
