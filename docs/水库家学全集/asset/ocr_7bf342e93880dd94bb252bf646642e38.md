# 06

我实现了一个儿时的幻想。

我小时候有个幻想，要是能够和自己要好的小伙伴一起过暑假，一起看动画片，一起吃零食，一起玩游戏，一起在花园里疯跑，该有多开心啊！我们小时候，家里房子小，完全是不可能的。我们一般是在人家窗口令喊一声，“狗蛋，出来玩啊！”

现在有条件了。我替娃实现了这个幻想。两个娃不是同一个小区，但也不远，是幼儿园同学，现在又是一个学校一年级，部分老师也是相同的，孩子们在一起有说不完的话，菜嫂和娃的妈也是熟人，一直有来往。最近，她和老公要出差几天。于是，在菜嫂的邀请下，那个娃和保姆来我家小住几天。小娃娃高兴的上蹦下跳，激动的不行了。

我们家是地上三层，每层都是两个卫生间，两个套房。我家住二楼，那个小娃娃带保姆住一楼。娃娃们玩的废寝忘食，幸福快乐，上午写作业，下午玩游戏，在花园里疯跑。我也由着他们，人生的快乐也不多，多高兴几天也好。

菜嫂一天到晚忙着给娃娃们买各种各样好吃的。我家保姆和他家保姆负责干活，厨房卫生间，擦的干干净净。每顿饭都是按照米其林标准制作小牛排。娃娃们吃的兴高采烈。还有各种五颜六色的洋汽水，糖果，蛋糕。一个丰富多彩的暑假啊。
