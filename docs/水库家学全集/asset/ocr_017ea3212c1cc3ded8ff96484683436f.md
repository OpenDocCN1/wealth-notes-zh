# 疲于应酬。

过年期间，你估计是忙的比上班还累。为什么？走亲戚，跑朋友家。你的想法是，现在互相走动走动，以后有事情好开口。实际上有用吗？没用。大部分人的应酬都是没有任何意义的，只不过把你自已累的够呛。你今天请别人吃一顿，最多也就是下一次人家请客，叫上你，加一副筷子。仅此而已。金钱，时间，浪费在扯闲篇和路上了。

应酬是为了什么？利益交换。大部分利益交换不成功，是因为互相不了解，生怕被陌生人坑了。应酬就是我们先混个脸熟，以后有机会互相谈谈。

这就有个扎心的现实了。你有什么东西可以和别人交换？没有。那么，你所有的应酬都是零意义。

# 老同学的逆袭。

我有个初中同学，小王，当年蠢得像个250，解析几何被我们形成语道。初中升学考成为了可怜的分母。因为成绩实在是太差了，连技校都不要他。我们几个考上高中的，暑假里都开开心心，可怜的小王，像一坨废纸，被所有人忽视了。等我们九月份开学了，小王还在台球厅闲逛，真的是惨的滋滋叫。

当年有一个福利，凡大厂子弟，父母单位总要帮忙一点。因为这娃娃技校都不收，实在是没办法了，单位后勤科招了一个厨师帮训班，他就被去切肉丝了。那个可怜啊。他们切肉丝的地方距离我们高中不远，臭烘烘的。我还在他们培训班附近见过他。厨师的最大标志是一身白大褂，头上一个奇形怪状的帽子。那一天是下午，我见到他了，他也看见我了。他可能是自卑，没有和我打招呼。

一晃二十年多了。我前不久又听到他的消息了。这小子发达了。他在九十年代，进入了一个超级豪华的五星级餐饮部当后厨帮手，2000年后，成为副主厨。买了两套房。后来，他又谈了一个非常非常漂亮的老婆。是五星级酒家餐饮部的女服务员。大家可能不知道，九十年代，五星级服务员也是百里挑一的好工作，上海姑娘非常喜欢去，当年不乏于空姐的录取标准。

后来，这小子承包了黄河路附近的一个饭店，现在不得了了。他自己吹牛过亿了，我好嫉妒。人家是自己打拼出来的，而我呢？因为一次高考好成绩，迷失了方向。
