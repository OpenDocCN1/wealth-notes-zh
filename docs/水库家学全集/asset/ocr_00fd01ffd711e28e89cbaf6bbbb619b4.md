# 交朋友

敢于在大单位辞职的人，都是人才。没有金刚钻，不揽瓷器活。你在大单位坚持混下去，没脸没皮，天下无敌。没人会赶你走，每个月工资，一分钱不少。

生活中，有一些特别有能力，或者有秘密资源的人，就敢于离职。天高任鸟飞，海阔凭鱼跃。一个人敢于放弃原来的平静生活，直面惨淡的人生，是需要多大的勇气啊？

我认识一些师兄，他们2000年左右分别辞职，去了陆家嘴金融城，现在一个个都是人模狗样的，百分之百成功了。这些人如果在大单位，今天也就是条又臭又硬的老板凳。去年，我遇到一个投资总监。我说你也会投资？想当年，我买了条裤子不满意，回去退，被人家老阿姨骂了一顿滚出来了。我们哈哈一笑。他说，他现在管了几百亿。我超，马勒戈壁。

他说，“山中无老虎，猴子称霸王。你们都在大单位混吃等死，我们就发了。当年，有点脸面的人，看不起土老板。出乎意外，我们熬出来了，你看看，这是我最近招的女助理，是不是比李嘉嘉还漂亮？一个月才要八千，划算吗？哦，对了，当年那个老校花现在怎么样了？”

我说，老校花还在大单位瞎混，前两年离婚了，还有一个儿子，没再婚了。现在可能不怎幺好了。

结论：从大单位离职的人都是人才，可以结识一下。他们除了穷，其他都不错。

# 富3代是什么样的？

富二代往往是五花八门，因为他们父母开公司的时候，他们小小年纪，就自我放鸭子了，没人管，什么样的都有。有的当教授学霸，有的不学好，吃喝嫖赌。

富3代一般是出生在良好的环境中。他们背负了继承家业，发扬光大的巨大责任，全家老小都很重视。

+   一是学习成绩。基本上有一个985员工陪着学习，985也是公司招的，五险一金。
二是兴趣班。武术，游泳，健美，唱歌，跳舞，画画，基本上都是名师。
三是身体。基本有联系密切的儿科医生。
