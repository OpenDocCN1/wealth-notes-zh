# 05

把握人性，获得商机。

这是一个装修小队长告诉我的神奇办法。他是年入几千万的低调小老板，承包了我们小区98家装修，一户人家营业额打底200万。他把施工进度写在公司门口一个黑板上，以防忘记，大家都知道他的承包总数。他就是利用人性的高手。

人的第一个特点是，都喜欢"物美价廉服务好"。但凡一个小交房后，就会有无数的野鸡装修队的小队长在小区门口发小卡片，例如“优质服务，全套18万，包爽”。你会相信吗？99.99%不会。那怎么办？

人的第二个特点是，怕麻烦。你把小区门口的野鸡队否了，那接下来怎么办？内环线确实有几家装修队，你真有时间去研究吗？没有。看一家样版房，再聊几句，就要一个半天。你有多少时间？于是，这小队长出了绝招。他在物业公司门口设了个办公室。看上去和物业公司很熟悉的样子。这给他带来了滚滚财源。因为大家都要去物业公司手续，顺道看看他的公司，也不是麻烦事。

人的第三个特点是，喜欢比较。很多人拿着这个小队长的报价，再去市里面比较。发现这里还略微便宜。于是不少人就想找他了。因为你看上去和物业熟悉，以后各种事情方便一些。

人的第四个特点是，喜欢眼见为实。小队长急于开工，打开局面。于是给前十家优惠3万，我估计是让步分利润。于是工程队迅速开进来了。其他犹犹豫豫的客户就看到了实物。下单速度加快。

人的第五个特点是，喜欢扎堆。小队长告诉我，实际上到了第40个单子以后，都是客户找他，而不是他找客户了。订单像雪片一样飞过来。把他乐死。家装没有拖欠的，他发的满嘴流油。据说纯利润几千万。我看了他的年会微信视频。春节邀请员工和友商吃团园饭，都是五星级+大浴城，过年前他还换了个宝马x5，装修结束后，他儿子也来公司上班了。我估计他肯定是发财了。

# 06

女人最后都会变泼妇的。

女人在20岁的时候，又苗条又害羞，还心疼男人。结婚十年后，基本都是，胖了十几斤，膀大腰圆的凶悍泼妇。为什么？我研究了一段时间，我发现一个有趣的特点，

男人没混好，一般是骂自己。女人没混好，一般是骂男人。因为我们家的特殊情况，就是两口子不上班，娘嫂经常要去娘家哄点钱回来，维持日常开支。当然，偶尔也有失手，这就麻烦了。她回来后会一般就会拿出我，先把我骂一顿："要不是你赚不到钱，我还需要要回家娘受气吗？你，赶紧带娃儿！"那那，这件事关我什么事？你是学艺不精，被丈母娘嫌弃了，怎么怪我了？
