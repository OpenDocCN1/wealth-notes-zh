# **微博十年，最大的收获**

是对人性有了更加清晰的认识。做人要努力，成功就是持之以恒。

我们这一代top1，一直生活在良好的氛围里，每天像个骄傲的小公鸡，趾高气昂。我们和屌丝，和农二代的接触不多，主要接触是快递，装修和保姆，所以对江湖邪恶认识不够，以为别人也是985思维。

微博这么多年，我算是明白了，人心难测，形形各色。不要轻易相信任何人的甜蜜蜜语。实际上，绝大部分人是讨厌你有钱，反感你有地位，他们很羡慕你，但是他们长期习惯了好吃懒做和底层思维，使他们无法翻身。

不要在意周围的穷亲戚，甚至是近亲属，说了什么话，而是要向成功的人学习，每个人周围都有几个成功的人，你仔细观察他们一举一动，一颦一笑，时间长了，就会有感悟。千万不要沉浸在底层思维，对于别人的成功，充满鄙视，或者自以为是的认为自己啥都懂，就是没机会打土豪分田地。
