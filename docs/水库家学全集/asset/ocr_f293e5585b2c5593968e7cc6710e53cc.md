# 05

木地板好吗？很糟糕。

我们小时候都是住老破小，无装修的房子，每个人心里都有一个木地板的童话。但是，木地板是个非常糟糕的产品，不太适合现在了。

有很多吃木地板这碗饭的人不愿意我说，但是老子无所谓，说就说了。木地板的安装需要非常高超的技术和精材。我年轻时候，前后有四套房安装过厚木地板，无一例外出现了巨大的噪音，就是踩上去咯吱咯吱摩擦的声音，特别是晚上，十分痛苦。

这是由于安装工人技术不好造成的。现在，安装木地板的都是些打工的，今天还在理发店打工，明天就来安装木地板了，也不需要考核，只要拉到单子就行。木地板安装看上去很简单，一学就会，两天出师。所以，安装工程制造渣的，比比皆是。

你发现问题也没用。不管你找谁，没人给你解决售后。因为解决成本太高了，要拆掉重新搞，这个成本没人愿意承担，不管你怎么哀求，他们就互相踢皮球，糊弄你。他们是不在乎回头客生意的，因为你下一次再买木地板至少十年八年了无所谓。如果你逼得太紧，他们实在没办法了，就找个250上门看看，给你滴几滴润滑油，或者骗你几句，别担心，住几年就好了。实际上，不可能的。
