# 08

读书能不能致富？

我就问你一个问题，张三是清北毕业，寒窗苦读18年，你愿不愿意给他几百块？你肯定不愿意。因为张三对你没有一分钱的意义。李四是小学毕业的厨子，给你做了一大桌菜，找你要五百，你肯定会给。因为李四给你干活了。

这就是赚钱的基本思路。你要对别人有意义，你才会赚钱。你自己一个人嗨，那是没用的。读书可以让你快乐，高教除外。但是，你快乐和我有什么关系？这就是人性。

要想赚钱就一个办法，你让别人高兴，你替我编个程序，给我进讲一个题，就赚钱了。

读书的目的是服务别人，而不是自己开心。绝大多数人把读书当做了自己快乐，还叽叽歪歪，老子是大学生，没有钱。你做什么了？不就是小镇上刷了几个题，凭什么有钱？又不是倒插门。

# 09

生孩子的潜力在城市。

我走过不少小地方，年轻妇女的生育积极性比较高，二胎很多。生孩子积极性不高的主要是城市。现在，青壮年大多数在城市，有本地人，也有流动人口。不生孩子的原因主要是现实问题。

+   * 一是房子。已婚家庭，给娃弄一个上下铺，问题不大。大家更加担心的是，孩子长大后悔房怎么办？
* 二是入学。现在，孩子在学校里日子不好过。学校用干奇古怪的办法折腾家长。甚至让家长去学校打扫卫生。
* 三是考试。现在孩子考试分数已经到了竞争白热化程度，各种各样的网课赚的满嘴流油，这些都是家长的血汗钱。
* 四是就业。孩子长大后，就业也是事情。现在有些事情，也没办法讲了
