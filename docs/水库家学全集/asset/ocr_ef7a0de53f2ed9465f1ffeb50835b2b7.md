# 06

如何攒私房钱？都是和员工学的。

一是报账瞎。最精彩的一次，是和莱嫂去吃大餐。去之前，我和莱嫂说，你把现金给我，饭后我去付钱。莱嫂给了我2200。实际花了1388。我还给了莱嫂100元，直接昧了712，太爽了。激动的心，颤抖的手，我给莱嫂敬杯酒。

二是少买多记。有一次，莱嫂让我去超市买点东西，我实际买了436元，报账是648元，反正这婆娘也不会检查。

三是昧了小娃娃的汽水钱。有一次，莱嫂让我带娃娃出去玩一天，给了我600。我带娃坐公交车去了长风景园，再吃了一顿小笼包。回来就算清账了。这次有点负罪感，我怎么能昧了娃娃的钱呢？后来一想，我和娃娃是一家人，就不要分的那么清楚了。再一想，不对啊，我气愤了，必须的。

三代还宗！

# 07

财经烧和屌丝群体喜欢说腰斩。

我一开始还认真真听他们说些什么理由，后来我不听了。他们的背后，实际上是同一拨人，老中青三代卢慈＋村状元，说白了就是小镇做题家，三无产品。

但是，状元不服啊！凭什么啊！我也是本科！慌伐？本科，放在二十年前吓死你：我是村状元啊，我也想把村东头的小红接到城里，让小红他娘也享享清福。为什么我就不能在京沪广深搁个大三居？不行！你们这些坐地户必须要。他们的出发点实际上都是一样的。老子是文化人，我父母辛辛苦苦一辈子，在小县城搞了一套，所以小县城还要跳起来。老子在大城市没结婚，怎么也要来一套大三居，126平起步。你必须腰斩。腰腰腰。要彩礼就是卖女儿，加名字就是物质女，破烂玩意。

还有一些二十年前的小编，现在混成老屌丝了，在小县城的拆迁房里，扶着一条腿的老花眼镜，心里那个不服啊：想当年，我也是老中专，慌伐？老中专，一个县才十几人的。比现在的985还厉害！册那，我就不信了，你还敢不腰斩。你去看，一线的小编，或三四年级的老屌丝，做的自媒体都是一股味：老家小镇好又好，北上广深呆上爹。

小结，人要理智一点，不能失心疯了。
