# 为什么有人会去买二手房？

从宏观经济的角度，二手房不如一房源的带动效应。一房源解决了上下几百个产业链的就业和一系列的财政内容。二房源解决什么了？中介，换套家具，也就这么点了。

很多人预测，二房源将来会越来极不受待见。实际上，居民不是这么考虑问题的。二房源有非常大非常大的需求。因为二房源存在一个神奇的无法复制的特点，地段。你买房定居是为了更好的服务社会，方便生活。怎么方便？上班近，上学近。

现在的新房，漂亮是漂亮，可都在郊区，地铁挤得早坂都不敢吃了。来来回回三个小时，很多人下车就吐了，就受不了了。这每天三个小时如果用在学习工作上，能够为社会创造多少财富啊！说不定儿子考试成绩也提高大截了。一个码农，一个高管，年入几十万，天天累的死，再去挤地铁三个小时，实在是不想去。

结论：二房源比一房源，唯一的优点就是地段。二房源一般已经存在十年以上了，周围的配套慢慢饱起来了，就业就谋都方便。这就是二房源的优势。世界各地都这样。

# 二房源

最划算的肯定是买邻居，两套房连在一起，方便。如果是一梯两户，等于搞了一层楼，电梯打千都是你家的。一般情况下，公共面积也有5-10个平米了，做个瑜伽室，小茶室肯定没问题。

其次是同一个小区（还不错的小区），子女和父母，儿媳和公婆，住太远不方便，挤在一起要斗，如果是一个小区，那就美妙了。孩子穿来穿去，你不用陪者过马路了。

三是单位附近。如果一个人上班很近，就有更多的时间精力照顾家庭，相当于多了一个保姆。

四是学校附近。子女上学近，睡眠时间多，上下课安全一些。
