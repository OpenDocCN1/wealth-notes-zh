# ## 01

这些年，我避开的雷。

在过去二十年，很多土老板都垮了，我意外的避开了所有的雷。

一是开发商铺。很多老板喜欢买商铺，特别是各种小商品批发城。我没参与。

二是写字楼。很多老板喜欢做大公司，经常是一层一层买办公室，我没有。

三是高利息。我也没搞。

四是买矿。有一段时间，非常流行买矿，也不贵，小矿几个亿就够了。我周围很多人都倒霉了。我没买。因为矿山附近的娘们特别虎，菜嫂要求我天天回家。

五是各种加盟。我当时觉得加盟一个KTV不错，因为菜嫂反对，我也没办法

六是当小开发商。当时，有很多人拉我去，有MBA老师全程指导。我也没去。因为开发商要应付的人太多了，太累。

这么多雷，你只要粘了一个，基本就玩完了。我居然意外的躲过了一起，现在回想起来，心有余悸。我为什么啥也没参与？总结起来就一条。我是过日子的人，不是那种天天想发财的人。我觉得有点东西就够了，没必要再折腾了。

现在，我和一些老朋友聚会，都是我买单，他们已经彻底废了！伤心的故事。

# ## 02

相亲途径。

有很多人参加一些n对n的集体相亲，多是单位组织的。这种活动，成功率极低，参加的人也不是特别认真，特别是男生，有的穿个夹克就来了。比较靠谱的相亲是，熟人介绍，一对一的那种。

相亲地点选择最好不要是灯红酒绿的热闹地方，最好是安安静静的，可以互相多说几句。
