# 15

为什么我拿不到年薪百万？

绝大多数单位，都是层次管理，你就是个螺丝钉，就值个螺丝钉的钱。你再本事，可能连大头头的面都见不到。民企不一样，它们一天到晚处于高风险之中，一看-不慎就直接倒了。所以，中小企业民企特别重视人才，员工找老板谈淡是很简单的事情。

如果你有本事，又在民企，赚年薪百万是司空见惯的。大部分人赚不到钱是因为能力差，你不能给企业赚钱，也就没有机会赚大钱。假如你有本事打开个销路翻倍的-市场，搞出个利润五百万的新爆款，立马就会得到老板的重视。

一是能力，二是机会。能力是磨练出来的，机会要看环境。你在小公司，能够为企业拉到一个小区六成的装修单子，你就是二老板，公司里除了老板娘，其他都是你的，前台胖花就归你用了。如果你在大公司就算给单位赚了十个亿，也就那样了，年底给你发个小奖金，大-头头装模作样的跟你说几句，"小伙子，好好干，再接再厉！明年指标再翻一倍。"
