# 考985的三个点。

小学三年级，初二，高一。我今后一个一个慢慢讲。今天说一个大家经常忽视的小学三年级。

小学三年级是个巨大的坑。一二年级是认知教育，一朵花，两片云，比较形象，而且家长都有能力辅导一下。到了三年级以上，难度陡增，开始引入一些乱七八糟的逻辑思维了。举例，几只鸡，几条狗关在一起，数脚丫子。其实，这是为了淘汰一些逻辑能力差的。

作为家长，你要高度重视小学三年级，否则，一不留神就会让小娃娃掉到坑里，很难爬起来。

一是你先读一遍课本。做到心中有数。

二是化解问题。你要把孩子看不懂的问题，让他看懂，这考验你的知识结构和表达能力。

三是多写作业。熟能生巧。

你可能要问，老师干什么？老师负责把差生揪出来，通知家长。你家娃是不是差生，我就没办法了。
