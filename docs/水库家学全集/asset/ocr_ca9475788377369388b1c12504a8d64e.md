# 路径依赖和主动觅食

很多人习惯了某个工作某个生活状态，就再也不想要改变，哪怕是对其深恶痛绝。我有个熟人做小企业HR的，和他聊天发现两个事情，一是他有很实践验，知道如何管好一个小企业的人力资源，选签退，门清。二是非常痛苦，HR属于边缘位子，他月入八千，根本买不起一个市区老破小，他老婆已经把他一脚踢飞，带着娃回老家，随时准备改嫁。他郁闷，自己没什么本事，发不了财，谁都看不起他。

我和他说，你完全可以发财，你就把自己的工作经验，一个一个总结出来，然后做一百个短视频，立马就火了，响当当一个大V，以后做广告，做培训，月入五六万，不是问题。但是，他完全起兴趣。他的意思是，折腾这么多事情，太累了，万被老板知道后辞退，今后怎么活？他就希望我教他一个办法，如何找老板加千块钱工资。

我非常理解这样的打工仔。他们在小公司的格子里待久了，已经完全丧失了觅食的能力，他们唯一的想法是，主人能不能多喂一口？我给你跳个舞都行。这就是典型的路径依赖。如果回到大学里，他们可能也是响当当的一个精神小伙，现在变成这样了，可惜。
