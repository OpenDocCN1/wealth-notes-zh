# 07

尖子生的功夫在寒假。

期末考试基本结束了。考的怎么样也定型了，给各位家长说一说寒假的密秘。寒假可以给孩子们休息放松玩一下，当然，寒假对于考试也很重要。

+   1. 非毕业班。也不要做什么乱七八糟的寒假作业了。你就把下一学期的新课，先撸一遍。好处大大滴。最好是人力数教，实在没条件，可以上网课。

+   2. 毕业班。那也没什么好说的。你把这个学斯的卷子全部拿出来，错题抄写一遍，整理一个错题本。再有时间，就把错题重新做几遍。记住，是几遍，不是一遍。做错题集的办法不是把答案写对，而是想明白一个事情，做个题的难点在哪？当初错的原因是什么？一定要刷到滚瓜烂熟。

+   3. 再有时间，去花园里跑跑步。
