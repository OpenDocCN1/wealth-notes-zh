# 08

如何残忍的玩弄屌丝之心？你就不断的赞同他。

他说赚钱难。你就跳起来骂马爸爸。

他说房子贵。你就跳起来说，马上腰斩。

他说彩礼高。你就跳起来骂丈母娘卖女儿！

你这么玩他几年，他就废了。

小结，好话难听啊！尽可能不要让屌丝明白太多了。否则他不会努力，反而愤怒你。

# 09

为什么总是要说腰斩？

因为我也是要面子的人。

1，当你找我借钱的时候，我怎么办？我总不能说，实在是太抠了，不愿意借。你肯定应该说，我不借是为你好，马上腰斩了。

2，当你找我炫耀大三居，我怎么办？我总不能回去和老婆说，我错了，当年鬼迷心窍了。你肯定要说，这货就是秋后的蚂蚱，蹦哒不了几天了。安慰一下宝宝受伤的心！

3，当你女票要婚房的时候，你总不能说，我爸妈是穷比，没钱。你肯定要提说，马上爆多了，相信你爹。

4，当你老婆要婚房的时候，你总不能跟，我不想改变现在的啤酒小烧烤生活，我不想努力了。你肯定要提，腰斩腰斩。

5，当你儿子要买你婚房的时候，你总不能跟，我和你妈都是老抠，舍不得拿出来。你只好说，儿啊，这家姑娘不行，一家人都不实在，咱不能要了。明天爸给你再谈一门好亲事，又白又嫩又漂亮。
