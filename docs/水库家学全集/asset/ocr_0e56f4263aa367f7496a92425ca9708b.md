# 04

# 世界上最难当的“长”是家长。

你当个其他的，就算干砸了，倒霉的是别人，但你家长干砸了，倒霉的是自己和娃。这个结果太沉重了。

我年轻时候就是倒霉蛋。当年，我孤身一人来到内环线，除了一个985文凭，身无分文，光溜溜的。那时候血气方刚，什么都想要。最缺的是女票。可姑娘们看不上我啊。册那，急得嘴角起泡了。为什么人家姑娘，看不上你？因为没房子。

我是70后。很多人以为，00后的姑娘势利眼。实际上，她们70后的妈，当年也是势利眼。被她们折磨的极惨。我们那时候是分房子，一个月一两千收入，房子是十万二十万，一般人买不起房子。当年的丝丝，压力比现在的丝丝还大。至少，现在还有逆袭这一说，我们当年根本没有逆袭。那么，其他人是怎么办的？靠父母。

一是拆拆拆。家里有老房子的，基本遇到拆拆拆了。一般是一个户口本有一个小二层。有一次，我站在内环线的大街上，大雨滂沱，泪流满面。万家灯火，怎么就没有我的一间房？我的相亲装备，唯一的羊毛裤子，也湿透了，心里那个愤怒啊！

二是单位分。如果父母混的好一点，基本有个大二层，挤一挤，勉强结婚够了。那时候的女人，也没现在挑剔。

我为什么这么惨？归根结底就一个原因，想当年，老头老太为了自己压力小，跑到郊区去了。80年代的郊区大厂，就像是现在的小县城，特别舒服。什么都有，日子过得贼溜。我家在80年代就铺地毯，看电视机，有冰箱了。

然后我回城后，那就一无所有了。穷比小伙子是真的很惨。我以前讲过很多次。我还算幸运的，没有学坏。很多人在这种情况下，被坏人拉下水了，一辈子完了。后来，我得到了一个经验。要做好个家长。房族传家，再也不能让姑娘们遭罪了。我家的中年妇女基本赞同我的观点。

一心一意攒面积，聚精会神抓考试。
