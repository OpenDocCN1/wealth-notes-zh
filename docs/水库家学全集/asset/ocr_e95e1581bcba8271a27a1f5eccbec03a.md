# 高考报志愿。

我原来以为这个没什么学问，大概差不多就行了。实际上，报志愿的学问大去了。我进入单位后发现，很多高考垃圾和我是一个待遇，我不禁愤愤不平了。我简单说一下思路，你自己再发挥一下。

一是以单位为导。很多好单位表面上招聘985，实际上有30-40%的名额是招聘某个特定二本学校。这个二本，是该单位系统内的亲生儿子，招惯了。另外，二本子进单位，也有优点，脾气臭的，极少，比较踏实。985，个个有毛病，动不动就要辞职，发脾气。

家长要有用心，你就找一个你喜欢的单位，例如某金光闪闪的大行，托人问问他们除了央财，上财，还会招哪个学校？一般都有这样的二本子。不仅仅是大行，还包括一些大金。

二是以萧山为导。生儿子，家里穷，没房子，还想去混大码头。那么，找老婆就很重要了。学历是第一门面。例如西湖边上的那个工科实验班。

找对象，一般会问，哪个大学毕业的啊？不会细问专业。因为一般人也搞不清楚。你就乐了。女生同理。

三是以城市为导。有很多人，因为各种原因，例如爸妈在那个城市打工，哥哥姐姐已经在那里了，婚房已经搞定了，就想考那个城市的学校，专业不太要求。

你去看，那个城市考编制最凶的是哪个学校，一般考虑带“师范”两个字的，法律专业。这种学校，这个专业，分数比较低。以后考编制也方便。

为了避免被骂，我不说具体的了。你自己也动动脑筋。
