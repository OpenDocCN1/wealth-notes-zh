
# 11. 给没毕业的大学生几个建议

  1. 戒烟戒酒。很多人可能对喝酒不以为然。你坚决不要喝酒。我以前喜欢喝酒，喝到四肢麻木的程度。我以前不上班，又无聊，是早上起来就喝，喝到凌晨，一杯又一杯。一开始喝啤酒，太贵了，就变成了喝二锅头。后来戒酒了。戒酒特别痛苦，一般人根本戒不掉。

  2. 适当锻炼。年龄大了，容易发胖，发胖对身体伤害很大。

  3. 在大学里学好基础知识。你工作的前十年，一般是醉心于考职称，无所谓基础理论。到了中年，你会发现，很多事情又兜回到理论了。一般不要在大学里去想赚钱的事。读书就是读书。好好读书。

  4. 保持良好的人品。不要出现负面新闻。你在大学里的口碑，可能会伴随你一辈子。

  5. 尽快挖金矿。大学里，拆迁妹特别多，而且好上手，尽快捞一个。毕业就没机会了。你要想想，你家爹妈在地里刨食，在工地敲钉子，都不容易，还是幸父母姐比较划算。

  6. 工作后不要乱花钱。尽可能买个小房子，两手准备。丈母娘现在也不好糊弄了，舔精。

# 要不要考编制？

  有钱的人，最大的诉求儿孙不要败家。考编制是比较稳妥的。在好单位里，一般不会学坏。
