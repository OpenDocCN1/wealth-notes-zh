# 08

生活是需要经营的。

孩子的幸福是很简单的。几块奥特曼卡就可以笑一下下午，抓几个小玩具布娃娃就可以炫耀一个星期。看着小娃娃娃开心的笑容，我心里暗暗的想，苦日子还在后面。

在今后的日子里，孩子要想得到想什么，都是非常痛苦的。中小学12年，每一年都是艰辛的。然后，考985，找工作，找对象，买房买车，事业发展，带娃。任何一个你想得到的东西，都不会那么轻松，甚至是要花费你一辈子的心血。怎么办呢？

仔细观察你会发现，成年人想得到的东西，都是千难万难的。你得到了，意味着别人得不到，大家都有的不稀奇。最后的结果是，别人不希望你得得到，甚至会设置各种各样的难题，让你过不去。你必须像魔盾打怪一样，一级一级杀出来。但是，人的精力是有限的，怎么办？借力。

父母拼了。好东西往往是几代人攒一个，例如大平层，小别墅。我们没办法，只能做富一代，我这一代就自我消耗掉算了，留下两个东西，一是大城市首付，二是各种各样的经验。老子硬是用自己的血泪趟出一条路，娃走起来就舒服了，没有富了。

一是当爹的不劈腿。再好看的小姐姐，咱也不去招惹。村花就不要给我发果照了。要不然，我就发出来了

二是当妈的一心一意陪读。我负责不停的赞美老婆。

三是攒钱。所有的钱都攒起来给老婆买房。

四是和学校搞好关系，尽可能让娃少受欺负。

这些年，已经有好几家人要和我们家攀亲，菜谱说，他们是看上了我们家的大平层，哼，等你家娃考上985，再来谈。想要我的东西，没这么简单！
