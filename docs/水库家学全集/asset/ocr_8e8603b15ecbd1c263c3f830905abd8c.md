# 08

什么叫风险投资？

清末闹街的混混胡雪岩挪用店铺的资金融给落魄举子王有龄，居然成功了，匪夷所思。然后几百倍的回报就来了。

风险投资在现在也是比比皆是。例如商铺经营。你在初期就要判断这个企业能活几年，否则收不到钱，还要打官司，他还不搬走，你也很难处理那么多昂贵的机器设备，很麻烦。

我最喜欢的行业是两个，一是汽车业，二是银行门店。只要是这两个行业，房租直接打八折。因为这两个行业收入好，顾客认门，不舍得轻易搬家。

还有一些大项目施工队。他们不拿到工程款不会搬家的，而且他有技术力量，可以把你的房子翻修一遍，临走时，还会给你留下一大堆建筑材料，例如接线板，办公桌，麻将桌，洗浴城VIP金卡。

哲学姐: 最后是啊？洗浴城金卡？？

明长点心吧: 我老妈有个小铺子，银行效益不好，不租了。只能降价租给开小超市的。交租金的时候，各种催，过期一个月才收到。
明七菜: 汽车19年开始下滑得厉害。不过确实，租房给他们是比较稳定的——起码不会轻易搬家。

我办公室的电脑，桌案，都是租客留下，我200元一个收的。有个豪华麻将桌，四把特大号红木椅子，新的一万多，我收就是150元。否则你找人拖走。有一次遇到一个土豪，全套豪华办公家具，电冰箱，洗衣机，没办法拖回老家了，我给了一千元。然后，我分开卖给部分租客，特别是新创办的小老板，转手就是几万利润。最多的是电热水壶，已经有几十个了，都是租客搬走不要的。我卖给新租客，50元一个，畅销款。至于什么充电器，圆珠笔，印泥，随便拿，不要钱。最搞笑是某老板留下了一条充电器生产线，搬走需要几十万，卖又卖不掉，就送给我卖废铁了。我凑合一一下，自己开了一个小厂，财务科，工程师，搬运工，操作员，就用我老厂的人，效益不错，比单纯房租利润高。
