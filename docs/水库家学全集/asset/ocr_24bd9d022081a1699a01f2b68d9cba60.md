# 什么是人才？

很多人自认为是人才，只不过没混好。这么多年了，我对人才的看法是，你在力所能及的范围里做成功了，就是人才。举例，

你在县一中，考入年级前三名。

你出去打工，赚到钱了。二十年后也当老板了。

你在家门口开了一个赚钱的店。

你在单位里当主任了。

苦干二十年，你已经有房有车了。

这些都是你可能做到的事情，如果你到了45岁，还是一事无成，你就不是人才，只是个不服气的待退休辣鸡。
