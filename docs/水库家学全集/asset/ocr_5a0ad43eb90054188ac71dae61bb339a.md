# 精品娃娃

以我的观察，99.99%的娃娃智力水平是差不多的，能不能上985，主要是后天环境影响。我文文娘家小区里，有几个小娃娃，我是看他们从幼儿园到初中的，以我的观察，有几个非常聪明活泼的孩子，他们最后居然没有成为尖子生，实在是太可惜了，我问了一下他们的家庭情况，基本都是小老板家庭，父母也不会读书。有几个天赋一般的娃娃，父母看的紧，据说考区重点没问题。我也是很心酸，这么聪明的几个娃娃就要去切肉丝，炒盖浇饭了。

培养一个精品娃娃需要投入巨大的人力物力，绝大部分家长是很难承受的。他们一般有 几个想法，

一是甩给学校。老师怎么可能管四五个小娃娃连成才？他们不在校内受伤，已经是万幸了，你考不上区重点，管我鸟事。又不是人人都上区重点！

二是报几个廉价网络班。现在的网络班几百元一个，老娘给你报了四个，对得起你了。长大后会去工地打工，不要抱怨家长。你仔细看迓过一些网络课程，我认为很难达到效果。绝大多数网络课就是重新讲一遍。要是娃娃学的进去，也不需要再听一次了。

三是骂娃娃不争气。这是最普遍的。我们小时候八十年代也是这样的。最经典的台词是，‘你看王小狗家里，条件还不如我们呢！王小狗也没人管，学习成绩那么好，你就是自己不努力，滚！别给我丢人现眼。’我小时候经常成为别人家父母嘴里的王小狗。

抱怨之后，接下来怎么办？很多家长就放弃治疗了。你去看，针对十岁以下儿童的商业兴趣班特别多，超过十岁的兴趣班就没几个了。因为小时候家长是以划桨的心态看孩子的，超过十岁，就放弃了。那个孩子就像是垃圾桶里没中奖的彩票，随风飘散，惨的一笔。如何培养一个精品娃娃？

基本上要投入一个大人的全部力气。你去看看历史人物，虽然老是走错路，也谈不上多聪明，但是从小到大，接受了优质教育，单纯的文化水平还是可以的，现在去博物馆当个技术员，学校里考个副高，基本没问题。
