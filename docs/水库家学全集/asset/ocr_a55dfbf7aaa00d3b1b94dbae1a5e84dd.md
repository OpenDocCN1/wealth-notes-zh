# 考不上大学，狗剩怎么办？

有部分农村孩子，不会考试，确实不可能人人上大学。你不要难过，大千世界，处处有机会。现在，高中生比大学生好过。再不济，大城市送外卖，也有八千，不比在老家种红苕强吗？

+   1，最好的岗位是销售，哪怕是卖皮鞋都有机会。我有个老乡，是卖酒的销售员，破二本企业管理专业（就跟sb一样的专业），家里是山脚下的，好山好水啊。他每年都要到成都，开糖酒会，还有业务经理。有一年，花言巧语，又吹又蒙，搭了一个做礼仪的女大学生（附近地级市的小女子），白白嫩嫩，苗条漂亮，这女人估计也没什么见识，被他一把拿下，搬得死死的。然后，这货就发扬了我们村里的祖传秘方，直接就当无赖了，结婚可以，就是没钱。最后，丈母娘送车送房送女儿。他现已经在成都开开心心当大爷了。人家还很有面子，“霍德尼玛，老子是发达地区来的大学生”。

销售的下步是自己当老板。这个比比皆是。你混熟了，自己也可以挑大梁。

+   2，保底是送外卖。月入八千不求人，这个工作时间多。你就在美食一条街附近蹲着抽个红双喜，一边打游戏，一边等单子。你放心，小餐馆都有WiFi，不花钱。美食一条街是金矿，里面的服务员多，搞到一个不贪财礼的老婆就发了。还有很多二婚妇女，实在不行就认了，总比光棍强。

+   3，最有前途的工作是装修。这话是先苦后甜。一开始学手艺，没啥好日子。等满师了，用不了几年，就是一个年入四五十的小老板，开个大金杯，五把冲击钻。

+   4，搞个小手艺。修手机，开挖掘机，做电工，卤鸡爪，小工厂头，大街小巷都是机会。你最好在老家找个同村的表哥，带你一挦。
