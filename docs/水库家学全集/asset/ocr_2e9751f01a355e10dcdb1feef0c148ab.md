# 01

不要研究如何节约小钱。

现在有很多所谓的节约小钱的办法，例如通过几个券节约一块钱之类的。很多人痴迷。这一行的最高级别就是南京路的打折嫫子（优惠券黄牛），绝对不可能靠优惠券改变人生。与此同时，优惠券会造成几个问题。

一是浪费大量时间。优惠券分为好几种，每一个都有复杂计算过程，这会浪费你的宝贵时间。

二是心态不好了。你今后不管干什么，都会想有没有优惠折扣，这会让你的人生很不爽。

三是过于关注蝇头小利，迷失了。在家庭大决策的时候，往往是采取拖延回避，无所适从。有时候，购房者可能会为一万元折扣，居然不买了。这种人很多的。
