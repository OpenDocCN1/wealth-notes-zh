# 05

经济新格局带来的新机会。

目前看，大城市聚集青年男女女和子女的趋势越来越明显了。道理也很简单，就业容易。在小县城站柜台，一个月2800元，还要自己带饭。在大城市捡垃圾，做钟点工，一个月一两万是最低收入。新一代农民工为了增加收入，出来打工是必然趋势。我家保姆，春节期间一天七百元，连续一个月就是两万，还偷奸耍滑，磨洋工，我也不敢说为什么，因为找不到人。她收入远远高于老家的兄弟姐妹。

第一代，第二代农民工，通过微信群，已经牢牢的垄断了大部分业务，完全不用担心业务。举例，请保姆的流程一般是这样的。老王家请了个保姆，老李也想请，就会问问老王家的保姆，大概是什么情况。这些保姆贼精，立即收集了信息，发送给老乡微信群，简单一点击手机垄断了新业务。装修等其他业务也是这样的。聪明一点的工人就会慢慢成立公司。保姆不太喜欢在网上搜索，也没时间折腾。

我不是建议你去当保姆，而是你要发动脑筋想一想，除了保姆，还有没有周围的需求，包括住房，家教，助动车服务等。我家保姆最大的梦想是在上海买房。她儿子在环线送快递送外卖，一个月八千多收入，完全不是问题，回去老家镇子上也是杰出青年了，县城买房找老婆，轻轻松松。

这说明，这些人会聚集几代人的财力，包括卖掉县城房子，争取在大城市买房。因为有了房子，就不要交房租了。这股需求是很大的，很粗暴的。

# 06

保姆最羡慕一个的亲戚

我家保姆最羡慕的一个表姐，嫁给了上海老光棍，有个继承的市区二居室老公房（靠近内环线，49平米）。她表姐也是月入一两万的主。主要是做钟点工和保姆介绍费。表姐把老家十几个亲戚带出来了，在她家临时吃住，安排介绍保姆工作。表姐现在在老家非常有面子，吃席都是主桌，每年都有人送毛峰茶叶。

她把茶叶送给我，让我尝尝，意思是觉得好，可以买几斤。她准备进军茶叶批发市场了。我买了几斤，表示祝贺。

一开始，她的困难户老公觉得，毛峰茶成经常来家里打地铺也不开心，后来发现，他老婆财源滚滚，土鸡土鸭吃不完，也就闭嘴了。

表姐儿子是上海户口，考了一个师范大学，今后肯定是内环线中环线某中学的数学老师，再搞点家教，抓几筐小猪仔，日子马上就火了。
