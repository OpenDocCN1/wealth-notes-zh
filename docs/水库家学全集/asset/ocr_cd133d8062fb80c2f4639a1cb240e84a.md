# 你的掏心掏肺，不值钱

很多人难得掏心掏肺一次，以为会感动别人，实际上没什么效果，自己好伤心。

我以前也这样。对小领导都是掏心掏肺，非常真诚的拍马屁，但是没用。因为小领导不缺掏心掏肺的货色。你在三甲医院有路子吗？我家侄儿想进银行，有路子吗？你上面有关系吗？

啥，都没有？那你会什么？傻不拉几的加班？去去去，一边待着，工资给你了，你不要想东想西了。年底晋升，是领导考虑的事情，你就不要自己多想了。不能伸手要啊！

想通了，我也彻底绝望了。此处不留爷，自有留爷处，我去倒衙门了。这么多年掏心掏肺，还不如倒衙门。
