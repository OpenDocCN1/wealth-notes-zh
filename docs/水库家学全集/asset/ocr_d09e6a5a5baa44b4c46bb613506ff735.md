# 02

给土豪家的傻姑娘说几句。

最近，我周围发生了一个闺蜜抢男人的故事。某自卑女（91年生的），找了个圈外的985男，还是二甲内科的。不知道什么原因，傻姑娘时不时把男票带到别墅群里聚会，顺带显摆：呵呵，老娘脱单了。把一票姑娘嫉妒的醋意大发。该男也是非常温柔，时不时的送温暖，小事情跑前跑后，获得了一众姑娘的好评。只要这个男人来，姑娘们都会积极参加聚会。有一次，土豪妹为了去哪里旅游，和男票吵翻了。女的要走省省钱，男的建议去杭州。一言不合，大打出手。第二天朋友圈官宣分手。

没想到，男票第3天找了个熟人圈的老姑娘（94年的），比前女友还有钱，就是文凭太差，英国研究生。现女友为了锤实此事，还在朋友圈发了一个给男票送衬衫的视频，前女友气疯了。原是想吓唬吓唬男人，没想到被截胡了。

小结，一不要显摆男票，防止截胡。

二是不要吓唬男票。

三是屌丝不要低估自己的价值。
