# 10

老板娘也上流水线。

我认识一个小老板，白手起家的。小老板一开始是打工族。慢慢做了个车间小拉长，专门负责做一些小的配件。老板娘是村里的黑胖花，满脸横肉的那种，特别吃苦耐劳。

我去他们公司好几次，就是去下单前的打样品。每次，老板娘都在。老板娘是流水线上的一把好手，还负责工艺。有一次我说，零件外直径不圆滑，老板娘二话不说，直接开机器，几分钟就给我磨平了。我非常佩服。

这个小企业做了十年，小老板也发达了，居然和一群人玩年起酒去了，还发生过一些纠纷，被人家闹上门来。老板娘有经验，她说，要钱没有，但可以成全你们。小女人吓得一溜烟跑了。后来我在路上见过一次那个老板娘，非常憔悴。现在，这个小厂已经关了。主要是两个原因，

一是车间不达标。他是图便宜，在穷乡僻壤找了个农家小院开工。现在，方方面要求高了，混不下去了。

二是员工福利这一块，上涨太快，最后小老板无利可图，纯粹是白打工。一开始，他们还想着赚几年，给儿子留给成熟的企业，后来儿子大学毕业，坚决不干。他们也就给儿子留了几套郊区房就算了。现在，男的已经不上了，老板娘去了一个其他公司当小头头，一年收入二十万不到。

现实中，绝大多数老板娘是免费劳动力。我曾经去过濮院考察项目。那个地方是全国羊毛衫集散地。每个店铺里都是一个老板娘加两个小美，基本看不到男人。

结论：富二代就是拼摊的。你不拼谁拼？
