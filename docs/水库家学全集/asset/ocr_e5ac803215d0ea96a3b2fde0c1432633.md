# 为什么教育那么看重分数？

分数的第一目的，绝对不是为了什么公平。分数的目的在于从小到大给你灌输一个道理：拼命刷题，绝不能出错，否则就要惩罚你。

教育的目的是培养各行各业谨小慎微的技师，兢兢业业，加班加点，不能出错。如果你高考600分，说明你很努力，够谨慎，以后可以成为一个好技师。

夫妻两个都是成绩极好的大学生，儿子是学渣，什么原因？

这种情况很多。主要原因是父母忙于工作，没有花大量的时间培养孩子。孩子的发展都是父母艰辛教育的结果。如果父母管不了，由老年人带大，孩子确实没有读书的想法。

大部分家长没有心情陪孩子读书。反正，你花多少时间，就有多少收货。如果你真的想管孩子，我给你一个绝招，你陪孩子重新读一遍中学。你作为孩子的家教。当然，整个过程，非常惨烈。家长痛苦，孩子也痛苦。

我刚刚工作的时候，遇到一个家长，也就是我的同事，上班时间在看高中数学，回家给孩子补课。我当时被震惊了。后来他儿子考到了上海同济大学一个低分专业。

或者，你听天由命。孩子读成什么样就什么样。你也不要难过了，你们也尽力了。早点买套房子，现在考二本也容易，尽可能给儿子一个交代。

提醒一下其他家长，对孩子的功课要提前抓，积极筹划，从小培养。就一个办法：刷题，刷到地老天荒，孩子看上去呆头呆脑的就差不多了。
