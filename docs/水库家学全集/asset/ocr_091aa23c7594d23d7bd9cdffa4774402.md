# 挖断穷根.

很多人仔细想想会发现，自己的社会排名和父母基本差不多。儿子成绩一般，将来估计也好不到哪里去。这是很多人的困惑。这里面涉及到很多原因，我就说几个思路，

一是得过且过。很多劣质父母对子女的言传身教是混日子，不要太辛苦了，钱够吃饭就行了。然后，教了你一大堆鸡贼方法。例如我就喜欢到大超市吃点免费 的瓜子花生，实在是改不了，那玩意不值一毛钱，可我就是想占便宜。一听到，促销闺女的小喇叭"免费品尝"，我就像个兔子一样追过去，一般没多要一些，带回来给娃尝尝。我就这个德行，没办法。

这种精打细算的穷日子过久了，你就会花一晚上研究优惠券的使用规则，舒舒服服便宜了三块钱。斑马市的，人家小王老师，一晚上抓小猪崽，收入是两千块，我特妈的全力以赴，忙一天，才三块钱，丢不丢人？

二是攀比心态。隔壁二狗家建了二上二下，在村里可洋气了。咱家也要建。"儿啊，你不要在城里买房了，把钱寄回来。"。

三是愤怒心态。小王几年前去买房，一室户，谈好170万，在签合同的时候，小王发现对方是房改房，原价才万多。小王愤怒到极点。这170万来的不容易啊。全家省吃俭用几十年，还卖掉一套房子，才攒出来的。人家一转身就把他们家三代人的血汗钱拿走了，实在是不甘心。

小王在家哭了两天，最后决定不买了，实在是过不了心里那个坎。小王媳妇崩溃了，又打又骂，也无济于事。后来，小王回老家县城，买了个186平米的大户型，赚足了面子。五年过去了，老家房子成为了二手房，根本没人要。当年放弃的房子，已经575万了。小主夫妻需要用一辈子来赎了。

四是亲戚大如天。一天到晚把时间浪费在跑亲戚。很多年轻人找了个不错的单位，父母拿他们去炫耀，三天两头去吃席随礼。大把大把的时间金钱，浪费在毫无意义的礼尚往来。考职称不行，还要面对亲戚们无休无止的来借钱，心力憔悴。

五是跟风，没有主见。这是最常見的败家方式。很多老头老太有一颗狂躁的要发财的心，实际也不太懂，一听说谁赚钱了，就风急火燎的去打听。十有八九是坑子，一辈子的积蓄，被人一锅端。

六是借钱。现在网络上各种乱七八糟的贷款坑非常多，对于收入不高，渴望赚钱的哇，吸引力极大，你去餐厅方便，厕所面板上也有贷款电话，只要你补上了，基本就完了。肥猪进去，鸡架出来。
