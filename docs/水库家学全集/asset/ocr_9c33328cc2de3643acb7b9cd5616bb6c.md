# 什么是谈恋爱？

很多女人把谈恋爱视为，看电影，开房间，男人出钱我花钱。很多男人认为，谈恋爱是小钱占大便宜，以后怀上了，少出点彩礼。这是不对的。谈恋爱是结婚前最重要的了解期。这个猪队友是不是符合自己的人生观点？你要考察什么呢？

一是金钱观。这个队友对于金钱看法。这个很重要。

二是房子观。很多人觉得出租房里的VIP，也不错。这就麻烦了。

三是异性观。猪队友将来是不是要劈腿？多看看。

如果你不太满意，又贪图人家条件，有钱又好看，怎么办？这个比较难办。三六九，拉现钞。先用起来。

如果你条件太差，只有这一个选项，怎么办？先对付吃两口，以后再想办法。
