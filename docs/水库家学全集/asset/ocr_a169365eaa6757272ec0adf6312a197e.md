# 09

纸币最大的学术意义是什么？这是我研究了很多年的一个方向。

举例，康熙要打葛尔丹，但是边远地区运粮困难，没粮食打不下去。你自己运，也不知道要多少成本，再加上押运官也不一定尽心尽力，这就没法没际了，康熙爷也没钱玩了。

有了纸币就好办了。假如，戈壁滩一斤大米是10元。我提高到20元收购，如果大家蜂拥而至，说明奏效了，如果没人来，我提高到50元，你肯定就来了。

为什么康熙爷没有用这个办法？因为当年没有纸币，都是真金白银。现在有纸币就好办了。
