# 认知以外的世界。

原来，我不相信这句话，“你赚不到认知以外的钱”。现在岁数大了，我确实信了，我就说说我的心路历程。

我是top1，我觉得我可以搞懂各种事情，但是，经过二十年的努力，我成功的把自己搞废了。这段时间，我一直在复盘，20年来的财经大佬风云人物的每一个阶段。我在百度看他们发展的过程时，我就在想，当年我在干什么？

各种马爸爸，我就不说了，我现在回忆起了那几个如日中天的快递公司。快递公司在初期是没有技术含量的，就是接电话跑腿，在地铁走廊里分练打包。这个事情我是有印象的。想当年，他们起步的时候，是在内环线的电线杆子上贴牛皮癣，那时候的他们是非常非常卑微的，我印象深刻。我至今还记得当年的某本地大报评价他们是“黑心快递”，干了很多很多坏事，让读者远离他们。

那时候的我，在一个光鲜亮丽的大单位，窗明几净，悠哉悠哉。同事们互相麻痹，觉得自己是大学生，将来的社会大牛，以后单位的天下都是我们的。呵呵，可笑吧？是的，就这么可笑。我那时候完全看不起这些老板，觉得他们就是一坨垃圾，找不到好工作的无业游民。

二十年过去了，他们才是大牛，而我只不过是默默无闻的小垃圾，如果我没有出来，大单位里只不过是多了一根老油条而已。

我当年为什么会那样？因为这件事情超出了我的认知。当年，大强子在电脑城摆摊的那种场面，我是见过过的，内环线也有好几个这种电脑城。我从来没有想过，我也可以做生意，也可以赚钱。我当时只知道，我一个月两千多，想做生意是没本钱的。后来才知道，那时候已经有天使融资了。崩那。

生活欺骗了我，但我还要继续生活。
