# 孩子的未来就在父母的一念之间

小时候，我们经常听到一句话，“隔壁二狗父母，条件还不如我们呢！怎么也考上大学了。是你自己不努力！”这是非常典型的劣质父母，把一切责任推给孩子。孩子来到你家的时候，就是一张白纸，你画成什么样，将来就是什么样。绝大部分家长没有能力把这个图，画好。我见过很多家长不想努力，是这样混日子的，

一是报辅导班。家长出个小钱，在网上报几个班。幼升小衔接，拼音辅导，小学数学之类的，然后逼迫孩子在手机前，干坐三四个小时。这是极其恶劣的做法。你咋不报个副高考班呢？也升一个副高？因为你也就做不到。家长其实心里也知道，只不过，花了钱，就有个心理优势了。我給你报过班了，是你不努力，以后别怪我了。

二是乱七八糟的兴趣班。家长实际上是自己喜欢，或者想在其他家长前面出风头，假装给孩子报几个，弥补自己的遗憾。这个更加恶劣。因为占用了孩子大量的时间精力，最后一无所获，还耽误了孩子学习时间。一个孩子是不是幸福，就一个指标，考试成绩在班上前三名。

三是艺考路线。很多家长把翻身希望寄托在孩子身上，指望女儿以后当个大明星，给自己买房买车。于是，就不顾一切的逼迫孩子。艺考是老天爷赏饭，就像体育冠军，不是花钱就可以砸出来的。我看过几个孩子表演，完全是成人化的装腔作势，看的我汗毛倒立。

给家长几个方案，

一是精品路子。陪同孩子重新读一遍9年制。

二是尽力路子，认认真真陪伴孩子读完12年，每天晚上陪孩子，手机调为静音。

三是出钱路子。这是大落货模型。你和孩子多研究，需要在哪里请家教强化弱项。和好成绩学生家长请教，有没有什么好办法，好的参考书，你也给孩子搞一套。

四是甩锅办法。你把报班的收据贴在个本子上，以后告诉孩子，“你闹的差，就是你你努力，别怪家长。”
