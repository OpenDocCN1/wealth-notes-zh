# 01

老王家是十年前拆的。

有两个选择，一是拿钱，二是拿房。老王是企业老板，厂里有地方住，卫浴齐全，还有食堂做饭。当时是利率最高的时候，老王最苦恼的是缺乏流动资金，拆迁几百万等于天上掉馅饼，立即要求拿钱，发工资，还贷，风光了两年。

与此同时，老王的儿子不高兴了。儿媳妇儿坚决要求拿房子。因为这就是他们名字的房子了。父子两个翻脸了。大吵三六九，小吵天天有。

老王拿着拆迁款发工资，千辛万苦维持着那个小厂子，后面几年基本就是混个温饱，没有什么赚钱。儿媳妇儿被耽误了。以前儿媳妇儿在厂里当家做主，发号施令，还没有感觉。

后来厂子不做了，两口子去市区打工，一下子傻眼了。现在，两口子已经成为出租房屋里的钉子户了，啥啥也买不起了。估计这辈子就这样了。

每一个时代都有落伍者。没关系，大不了，从头再来！

# 03

一句话讲金融。表外业务。

很多人无法理解表外业务是什么意思。我用最简单的解释。

金融机构的表格都是填写金额的，如果这个业务不需要出钱，那就无法填写表格了，这就是表外业务。你替老王办个事，不花钱，但是半年后可能有收益，也可能有损失。例如，你拿公章替老王担保十个亿，这个业务牛逼大了。但是，这个业务不花钱，不可能体现在金融机构的任何表格里，这就是表外业务。
