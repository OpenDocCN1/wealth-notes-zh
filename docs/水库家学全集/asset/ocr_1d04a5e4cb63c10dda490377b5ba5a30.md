# 04

底下并不好混。

很多误以为，上面难混，底层好混。实际上恰恰相反，底下最难搞，上面反倒是彬彬有礼，相对好混一点。底下的人，做事情直来直去，就像是你去菜场买菜，一言不合就搧通，你在五星级宾馆，不会有人和你骂街的。你在公司里，厂长一般不会为了几千块钱和你斯通扯头发，但你要是遇到一个小拉长，为了二十块钱扣班费，就会骂骂咧咧，搞不好就推搡摸摸了。

在下面混，得益很小，而每天的破事越来越多，最后精疲力尽，也熬不出来。最好的办法是早一点离开破地方，进入管理层。上上下下，前后左右，各个地方都有管理层，进去了才好办。相同的精力时间，在上面获得的利益是在底下的几十倍。一样的996，你被总经理点赞了，那就发达了，你被拉长看到了，也就是客气两句，啥也没有。

怎么能进去？最简单的办法，可能是文凭了，很多大单位有门槛。这篇太难写了，不写了。

# 05

两千万的房子，只给一分钟考虑。

一开始我看到这个新闻的时候，非常震撼。两千万是什么概念？一年存十万，也要两百年，从乾隆开始存钱了。我小时候，第一次看到亿的时候，是这样的一条横幅“热烈祝贺我司年利润过亿”。那是几万人 的大厂啊！现在，买个职工宿舍就这样了？实在是不能接受。

问题是，市场上为什么会有这么多钱？我们小时候，油嘴子四分钱一个，排队买。一毛二，吃三个，用黄皮纸包的，很烫。那是吃的满嘴流油，开心的跳起来。我回家后，还要换一顿矮（我是拿了家里抽屉里的硬币和粮票），当时，我觉得一毛二换一顿矮，我也愿意。

实际上，我自己又何尝不是呢？想当年，我和中年妇女去买房，一千万的房子，只给五分钟考虑，而且没有一毛折优惠。售楼部说，“要不要随你！”我和菜嫂都没看到房子，就在沙盘上比划了一下。当时，我很紧张，菜嫂也很紧张。我们两个人走到售楼处门口，你看我，我看你，互相默默不说话。至今，我还记得，那是一个冬天的下午，外面的风很大很冷，我哆哆嗦嗦站在风口里，像极了一头猪。我和老婆知道，这一把要是砸了，三代人就完了。

最后，我非常悲壮的告语菜嫂：如果出问题，就离婚，我一个人背下所有的责任。事后知道，这是胡思乱想了，银行不会放过菜嫂的。然后，我和菜嫂悲壮的又进去了，风萧萧兮易水寒，壮士一去兮，我和菜嫂就像是手拉手冲向鬼子炮楼的感觉。那一刻，我思绪万千，老婆还年轻，娃还小，万一出问题，我只有跳河了。

这些年过去了，我活下来了，每天还有奶油蛋糕。
