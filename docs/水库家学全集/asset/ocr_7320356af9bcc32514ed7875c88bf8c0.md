# 社会周期逆袭

财上微博 2020-03-25

![](bbox=[0.48, 0.12, 0.52, 0.15])

通过社会周期逆袭。

我发现一个奇怪的规律，只要你在一个地方待够五十年，你就什么都有了。无论是阜阳阜新还是京沪广深。这里面的原因，是社会周期。

我家在抗日时期逃难到内环线。当年啥也没有。和我家一起来的人，比我家还要苦，基本都是两手空空。但是，几十年后，他们什么都有了。这里面的机缘巧合，无法细数。但是，这个规律是存在的。

有人在内环线卖葱油饼也搞出几套房子了，这实在是难以置信。所以，你不要因为暂时的困难而灰心，找一个好地方，熬下去就是胜利。当然，农村房子大，你也可以回去。
