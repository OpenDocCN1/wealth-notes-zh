# 04

穷男一般不离婚。例如我。

我最怕离婚了。我现在的好日子，是占了老婆便宜，这个我心里知道。我家这个中年妇女厉害的了不得，

一是回娘家搞钱。就一个女儿，多多少少给一点啦？富人的一点点，就是穷人的一大盆。老子可以吃的满嘴流油。

二是天天带娃。这个中年妇女对带娃有蜜汁爱好。一天到晚忙娃的事情。举例，我们家娃是班级里的颜值担当，穿的最好，长得也好。

三是天天骂男人。男人需要经常骂，否则就要作妖了。我家婆姨这个事情最来劲，也最厉害，三天两头敲打我。我已经烦透了，

“我知道吃你们家米了，以后我让娃还，行不行？你就不要天天说了。再说下去，老子跳脚了！”

小结，小美白，如果实在是没办法了，也可以看看丝丝。我们当中也有好人。

# 05

穷学理工，富考社科，一般不搞纯文科。

理工科的就业环境相对比较艰苦，工厂，工地是比较多的，就算是码农，也是天天加班。高薪理工岗位，技术发展很快，你要不停的钻研。人比较辛苦，富家子弟过不了多久，就退出了。

富裕家庭，可以考虑经济，法律的各种学科专业，混个文凭，进个窗明几净的单位。以后找对象好一点。

纯文科现在有点郁闷，例如文史哲，这些专业当然也是很有意义的，但是就业难度大，如果不是当老师，有多少企业要啊？

关于外语专业。我已经不建议了。因为，绝大多数情况下，各行各业已经不需要翻译了，实在不行谷歌翻译就行了。当然，现在一些高端场合，例如全球××经济研讨会，还是需要高翻的。但要求极高，市场很小，而且基本就是几个大牛把持了，你很难进去。

现在去亚非拉的业务比较多，你自己看情况。

如果你家没资源，就不要和有资源的人家硬钢，你要学会绕路，做人家不做的生意。我认识一个装修工，他儿子是××理工大学毕业的。毕业后，儿子很争气，去了西南山区修工程。他是和一个本县的，认识的工程老板一起去的。荒郊野外，也没有消费，一年可以存30万下来。当然，条件艰苦，住彩钢板房子，冬天冷的直跳，夏天喂蚊子。干了5年，现在回到老家
