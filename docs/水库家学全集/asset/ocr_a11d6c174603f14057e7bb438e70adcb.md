# 我为什么一直没有被骗过？

二十年前，我是没钱，谁也没办法骗我。近二十年，我有点钱了，可偏偏没想法了，黄赌毒一样也不感兴趣。我现在迷上了，抗日剧，微积分和置换化学公式。

五年前，劈兔兔掐猴的时候，有人给我介绍了12%的。当时，我已经不缺钱了，屌丝给我看一大堆表格数字，我也完全不感兴趣。

写微博的时候，历年来，很多抱脚大汉给我发来小美白的照片。老子担心被妻嫂看到，看完就删，现在也没人发了，郁闷。

前段时间，有人邀请我去擦妹，我激动坏了，一数零花钱，顿时不想去了。

男人没钱，岁月静好。男人不能有钱，否则，破事就多了。我现在不知道，广场舞上，大妈还看不看钱？我还有不到20年就要报名了，急死了。

# 为什么，越来越多的小镇做题家败下来？

作为一个曾经的，失败的，老丝丝兼做题家，我对过去的很多事情，历历在目，痛彻心扉。我花了很多年思考，今天分享一些心得，留给娃娃和后生们体会。总的一句话：人的发展分为三个阶段，不同阶段，需要不同的能力。

一是智商，从小学到大学。在读书阶段，99%的幸福来自于分数。老子考上区重点了，考上985了，拿到奖学金了，你眼不服？因为这个阶段太长了，经历了童年，少年，青年，三个阶段，把很多人搞得以为世界就这样了。这就把小镇做题家推到茅坑里了。很多小镇做题家进入单位之后，不懂人情世故，还是以分数作为考量，那就人见人烦，直接出局了。

二是情商，这是工作后到35岁之间，最重要的事情。你在大单位就会发现，论文数最多的人，干活最惨的人，基本上性格都很软，一般轮不到升职得好处。实际上是，特别会来事的人，他们情商超级高，最后吃到了最大的好处。我们以前还有分房子的事情，现在没了。

三是财商，这是35岁以后的人，必须面临的问题。娃娃大了，父母老了，买房买车，老婆没工作了，各种财务压力，犹如排山倒海一般压过来。你觉得你能扛多久？
