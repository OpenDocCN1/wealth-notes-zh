# 莫欺少年穷！先忍了，条件好了再换。

原创 集结小编 财上海微博 2020-02-05

![](bbox=[0.06, 0.12, 0.94, 0.28])

1.五年前大学毕业，在家乡的所谓最高学府任教，有稳定收入，有社会地位。家里经济条件也还凑合，第二年买了房，马上又买了车。父母觉得儿子的大事已办，不用操心了。而在外人看来，有房有车有好工作，算半个人生赢家，就等着赢取白富美了，走上巅峰的节奏。可谁想到，五年后的我，放弃了编制的工作，车子留给爸爸开，昨天还卖掉了房子，一切归零，重新开始了，在这座三线城市，除了家人和朋友，已无身外之物。

2.中国经济已进入赌场时刻。买房晚一年，等于判三年；买房晚五年，一生杨白劳。选择比努力更加重要。20年前，最优秀的中国人出国留学了，现在看，他们就是倒霉蛋。这是荒唐的，但却又是每天发生在我们身边的真人真事。我爱这个国家，我希望这块伟大的土地，能够演绎出精彩的历史。可能，大家要失望了。

3.刚才在地铁上看到的暴击！一对说普通话的外地情侣在站台里吵架，男的说不跨年，出去走人家里太闷。女的说没心情，男的不开心了说你闹什么闹啊，后来女的就怒了，大喊，说你在上海连套房子都没有，一年365天都是难过的，还有什么心情去跨年啊！然后就这么在座位上哭，男的背着书包傻站在那...

4.莫欺少年穷！先忍了，条件好了再换。

5.我给2016外地二本狗出个建议，去上海金山区碰碰运气。金山房价极低，约1.5万，又是大国企驻地，环境优美，经济条件好，人富房价低。金山区也有缺点，一是距离上海太远了。二是化工厂聚集地，你懂的。其他郊区，例如青浦嘉定南汇崇明房价低，空气好，但是传统农业区，没啥工作机会。

6.我是不会去金山的，但我建议二本狗去金山碰碰运气，理由：房价低，1万多，男女两人家凑钱没问题。买房后，赌今后户籍改革的可能：以房管人。例如有房产证，可以解决读中小学，高考，甚至是户籍。我坚信，以房管人是是方向。任何事情都要在政策没有出台前布局，牌摊开了，哪里轮得到你占便宜啊。对伐？

7.苏州杭州南京的印象。南京就是北京的翻版，大机关遍地都是，迷信关系。杭州是上海的翻版，崇拜商业。苏州类似上海，但地位低，时时刻刻要看着南京和上海脸色，例如虹桥机场某货运站航班改降落浦东机场，苏州就郁闷了。如果你去不了京沪，也不习惯深圳的热，那么最好在苏州杭州南京三选一，我偏向杭州。

8.马化腾马云的学历不算差。扩招前考入大专，就是人上人，跃龙门了。你看叶鹏的本科也很差。马化远是人大，好大学里的垃圾专业，那时候高分学生不可能选带农字的专业。刘强东是牛人，专业好，难得的是他是从江苏考出来的。我是上海考区，上个好大学没啥炫酷的。现在的二本狗，也就是以前的技校水平。

9.前年，初夏早上五点，我迎着第一缕阳光，步行于西湖的上香古道。车停在岳王庙门口的肯德基，然后走杨公堤，无意中还走进了一个高级养老院。整个行程，就我一个游客，有几个晨练老人，看不到任何游客，安静祥和，阳光明媚。接近十点多，走到了飞来峰，那是人多了。打了个车，回到岳王庙，开车回沪。
