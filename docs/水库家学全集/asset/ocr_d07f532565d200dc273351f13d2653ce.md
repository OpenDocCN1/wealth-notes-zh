# 02

刚才，看了半天的小学数学。我彻底僵逼了。但是，这也暴露出了一个中小学考试的漏洞，考高分的漏洞。

现在的中小学难题，都不是你在考场上五分钟内可以从无到有，完美思考出答案的。你进入考场（从小测验，到中考高考），你会遇到两个可能性：一是不会做。二是会做的题。你的分数就是那些会做的题，做对了多少。

那么怎么使你会做的题，尽可能范围大？天天刷题。刷的越多，覆盖的范围越大，考试分数越高。如果你每天夜里刷到凌晨一点，考个211基本可以了。
