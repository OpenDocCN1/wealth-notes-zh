# 07

二手房能不能停止代款的理论研讨。我尽量用委婉的方式来研究。

有人建议，停止二手房代款，让房东砸手里，我就开心了，说不定还可以捡漏。这个方法，很多年前就有人提议了，至少在牛刀横行的年代，我就听说过。如果这样做，还不如直接取消二用房。

1，银行安全。银行抵押贷款，绝大多数是二用房，相当于抵押物砸银行手里了。你说银行经理怎么办？

2，新房销售。现在大城市的价格实是太高了，常见是远郊区的600-市区的1500个，正常家庭根本拿不出这么大的数字，我觉得丝丝拿不出来。本地人一般是采取以旧换新，如果旧的出不了，新的也进不来。相当于大家都不玩了，这也不是希望看到的结果。

3，单单停大城市，还是各地全部停？如果单单停一个大城市，那就是欺负中小城市了。大城市客户没钱了，中小城市的二用房还可以卖，那么，很多外地人一看有便宜不占是傻子了，直接回老家把老家推了，资金给儿子在大城市置业付首付，这相当于大城市在对中小城市大力度抽水，会把中小城市的人才和资金，抽的七七八八，那么中小城市面对这么大的抛盘压力，又该怎么办？如果全部停，那参考本文前面的1。

4，新人上车怎么办？绝大多数毕业生定居大城市，首套婚房是市中心的老破小，兼顾上班和生活，他们很难去远郊区。如果停了，大学生家里也拿不出全部的钱，一般是350-500，就没办法上车了。这也不是我们希望的。

5，可能捡漏吗？现在你家婚房正常卖600个，你愿不愿意只卖200个，一般是不太愿意的。至少二十年内不愿意。大不了，一起僵在那里。我手里有贷，心里不慌。你呢？毕竟，破产卖房的业主是个别的，真有个好办事，不一定就轮到你了。

当然，出于额度考虑，下半年两个季度的额度紧张是可以理解的。

建议各方，以“稳地价，稳房价，稳预期”的角度，慎重思考，全面兼顾。
