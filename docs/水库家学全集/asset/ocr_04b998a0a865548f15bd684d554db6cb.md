# 创业的往事

有个装修队长，老王。原来是内环线大国营单位的技工。九十年代下岗了。恰巧遇到内环线装修热，他就拉杆子，带队伍，干装修了。由于是本地人，关系多，信任感强，一路过关斩将，生意红红火火。随着生意越做越大，也遇到难题了，住宿。

内环线需要装修的房子，大部分是婚房，面积普遍很小，堆放了好多装修材料，房东也不愿意装修工住，装修工更要晚上住在工地也有很多具体问题，例如烧火做饭之类，必须要有个宿舍。一开始，老王是租房子，但是，农民工集体宿舍，有很多麻烦，一是房东不愿意，二是邻里纠纷多。老王的大老婆负责这个事情，一天到晚头痛。
