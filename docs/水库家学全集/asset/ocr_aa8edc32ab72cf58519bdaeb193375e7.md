# 05

有一种甜。（中考作文题目）

二本子一看到就晕菜了。实际上不难。我給你分析一下

+   1，审题。这个和常见的题目“幸福”差不多，属于常规题目。

+   2，定调。现在最热的素材，肯定是最美逆行之类的，考试作文肯定要往这个上拉。

+   3，接头。甜和时代背景要自然过度。

+   4，格式。最好是总分总。一个开头，三个自然段，收个尾。八百字差不多了。

+   5，额外加分项。主要是文采。例如古诗词，名人名言。
