丝二代如何起步?

我说的起步，不是要成为亿豪，而是在大城市当上中产。正常情况下，这些人没有路子，没有资金，唯一的资本就是自己这个人。

# 一，学什么很重要

你不要去学富二代也可能学的，什么金融，经济，管理之类的250专业，你最好学一点比较苦的专业，例如码农，工民建之类的，以后没人和你抢工作。

# 二，就业最好选择一些比较苦的行业

不要想什么考编制之类的轻巧活。一是难考，二是你进去之后也很难迅速突进。你最好选择比较艰苦的工作。我认识一个农村娃，高职毕业，跟着一个土老板，在某山区修路，没地方花钱，三年攒了60万，一把逆袭，秒杀了所有的同班同学。当然，人也比较苦，夏天晒的都能皮了，冬天冷的直哆嗦。

# 三，找对象要务实

小美是漂亮，肤白条顺，用起来带劲，但是你不要自己找没辙。小美不是给富二代准备的。你最好找和黑胖花，皮实耐造好保养，先用起来再说。另外，黑胖花最好有个工作，月入四五千为宜，带资入场，一起攒首付。你一个人养家，也太沉重。

你只要踏踏实实做好以上几条，四十岁左右，基本就是大城市中产了。屌丝不服了。你把把我所有的幻想都浇灭了，我受不了。
