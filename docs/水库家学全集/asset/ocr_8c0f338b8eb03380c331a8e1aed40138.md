# 我最怀念的高中老师

是东北师大的那个英语老师，简直改变了我的命运。上海人学英语，最强调的就是口语，发音正确，听力满分。随身听，复读机用坏几个，那是最牛逼的，小迷妹一大堆。

我的那位东北老师（人才引进），他不会说英语，也不会说普通话，而且瞧不起会说英语的老师，外教来上课，他一概不去听，还和我们说，没用的。他的绝活是把英语变成数学公式。对付考试，简直是利器。

我以前英语高中考试就是不能满分，选择题，阅读理解总是错几个。我原来的英语老师是某外毕业的，一直想去澳洲洗盘子，所以那几年一天到晚研究打工，上课也不太尽心。我是找了一个家教，隔壁邻居，我妈替他们家做饭。他是湘潭大学的副教授来教高中，所以我的水平勉强可以混混考试。

我的那位东北老师来了之后，画风突变。英语课不讲英语，也不读课文，就是做数学公式。他是个大老爷们，上英语课就是讲靠山屯笑话。他把英语考点全部整理出来了，真是奇才。到现在，我的英语选择题和阅读理解，可以吊打高中英语教研室。
