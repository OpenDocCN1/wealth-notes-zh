# 02

有很多二本子觉得小老板很蠢。

“你看我，工作马马虎虎，整天拿着本考公的书，在公司的空调房间里复习功课，一日三餐吃你的，你还不是每个月要给我五六千块钱？一分钱不能少，傻逼小老板。”

你要是这么想问题，你就蠢了。你见过三十几岁的老油条在办公室这么混的吗？没有。年轻时乱混日子的二本子，是在拿自己的青春肆意挥霍，等熬过三十岁，你就啥也不是了。你不要以为占了小老板的便宜，你是在牺牲自己的青春年华。

正确的打法是，好好学本事，大学没学到东西，不怪你，出社会了，你自己不学，没人管你的。你应该尽心尽力，掌握客户，掌握技术，以后自己也做老板，或者把小老板的公司盘下来。如果你就这么混日子，也就是七八年时间，人生提前结束了。下半辈子就在出租房糟皮了。
