# # 小地方的房子可怎么办?

财上海微博 2020-10-06

![](bbox=[0.48, 0.12, 0.53, 0.15])

为什么学校从来不教怎么多赚钱?

凡是赚大钱的人，都不是学校救出来的。学校只教一个事情，让你成为技师，例如码农，三甲，师范，工程师，律师，会计，经济师。世界上最难的学问就是赚钱。问题是没人教。

发财是个概率问题。不一定百分之百成功的。但是，学校教育必须教百分之百没问题的东西，这就是学校不教的原因。

那么，赚钱的办法能不能教呢？大概率还是可能的。但是，发财是个天时地利人和的事情，很难说什么事情几十年都发财。举例，我们小时候最喜欢读大学，大专也算大学。因为读大学意味着商品粮，好单位，正式编。这才短短二十年，一下子就不是了。

我年轻时侯认识一个屌丝，他是我們单位三产公司的一个小头头，管了七八个民工。现在的年轻人应该不知道什么是三产了。那时候，各行各业都搞三产，想办法挣点钱，补贴一下单位职工生活。逢年过节我们发的水果就是三产搞来的。有的公司房子多，就出租门面。有的公司技术强，就接一些加工设计的活。我们单位开了个修理厂，首先是自己单位修车不花钱了，还可以对外营业。

后来，修生意不好了，就去修房子。九十年代，修房子的业务挺多的。我认识的那个屌丝，专门干别人不想干的活，跑手续，跑了好几年，各方面都熟悉。后来，来了个新大学生，他不想再跑手续了，就把全套资料交给他，手把手教会他怎么办手续，让年轻人继续跑手续。没想到，出新情况了。

很快就住房商品化。新大学生和包工头老乡一合计，就出去自己干房地产了，一切都是熟门熟路的，一下子呵呵大了。我至今还记得他当年赚了钱的兴奋劲。我第一次吃小青龙和斑节虾，就是他请客的。那时候，我才知道，世界上还有芥末这个东西，第一次吃，当场就哭了，眼泪鼻涕一大把。

结论：赚钱是先学会了，等风来。如果风来了，你就发了。
