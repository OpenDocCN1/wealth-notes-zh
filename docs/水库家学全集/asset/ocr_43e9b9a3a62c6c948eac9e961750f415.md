# 炫耀是恶。

财上上海微博 2021-02-11

01

炫耀是恶。

炫耀是每个人最喜欢的的事情。“你看我买的房子，你肯定买不起。我儿子考上了985，你服不服？”如果有过这种炫耀的人，基本上就算和别人结梁子了。年轻的时候，我干过不少这样的蠢事。现在还有大把的人在干这种蠢事，特别是中老年朋友。

千辛万苦，勒紧裤腰带二十年，终于买了漂亮房子，大宴宾客，一番炫耀。你会提前一天就开始准备一大桌菜，等客人们吃完了，你就静待别人的吹捧。别人吃了你一大桌，也只能言不由衷的吹你几句。但是，这有意思吗？不但没有意义，而且还会激发别人心底的恶意。

人心最底层的事实是，看不得别人比自己过的好。比尔盖茨发财我不管。老同学，老同事发财了，我就很痛苦。一旦有了恨意，这就不是朋友了。最漂亮的炫耀是，让别人自己发现，这就不得罪人了。

我十年前就不在生活中炫耀了。当我实在忍不住了，就在微博上说几句。当然，大家不认识我，也不会有更多的想法。就当又遇到了个250。

02

亲戚给你打电话，往往不是表面意思。

年轻时候，我有个亲戚给我打电话，问你能不能买到出厂价的某香烟。我就说，香烟要办证，他又问我怎么办？我虽然也不知道，但我发挥了理工直男的特点，又是查资料，又是打电话，找了好多朋友问细节，终于搞清楚了。然后，我兴高采烈发给亲戚了。

亲戚再也不回我信息了。

我以为，他忙，也不在意。

后来听说，他没有去办。

再后来，我岁数大了才明白，当年他们的意思是，你能不能帮我办了。
