# 每一个时代都有落伍者。没关系，大不了，从头再来！

原创 财上海 财上海微博 2020-05-24

# 01

老王家在八十年代就开厂了

那时候，叫做乡镇企业。工人都是附近农村的十八九岁未婚小妹妹，来赚钱办嫁妆的，一天两块钱工资。那时候，没有996，一个月休息一天，爱来不来，几十人一间的大宿舍，吃的比较差，做运动裤的，就是你们以前看到的蓝色运动裤那种东西。就这条件，进厂还要求人。老王家天天有人送鸡蛋。

那时候，做生意很难。难得是卖不掉。如果销售不好，发工资就麻烦了。人家员工千辛万苦在这里干活，就为了拿点工资。老王想了很多办法。

一是拉到集市上卖。
二是委托供销社代卖。
三是发动亲戚朋友团购。

但是，无论怎么努力，就是卖不掉。原因很简单。因为厂子附近的小市场很容易饱和，秋裤也穿不坏，买一件可以穿好几年。

二本子肯定哈哈大笑了：“你蠢啊，为什么不卖到外地去？”老们也想卖到外地去，但是，货款收不回来。裤子曾经卖到东北四川的小地方，很畅销，就是拿不到钱。那时候，做生意的人都不是什么老实人。

也试验前款现货，根本不可能。因为进货少，利润还不够运费。进货多，对方没有钱给你。

我们也试验过自卖。但是，单卖一个运动裤，你在全国各地租房装修，也不可能。必须依托原来的商业渠道

就这么不死不活的，

熬到了九十年代，生意开始好转了。因为市里面的外贸公司开始做出口单了。他们拿大头，老王喝点汤。

熬到了1999年，遇到了乡镇企业改制，老王见有利可图，就把家里房子抵押给银行贷款，把企业买下来了，条件是把老员工养到退休。

熬到2003年入世，老王就开足马力了。

熬到2006年，各地商业批发市场普遍起来了。老王发财了。外贸内贸一起干。

熬到2008年，劳动法来了，老王厂里的工人不服气了。

前两年，老王就退休了。

总结：老王忙忙碌碌了一辈子，就是忘记买房了。厉害了。
