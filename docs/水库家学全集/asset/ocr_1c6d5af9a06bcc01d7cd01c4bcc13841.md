# 04

不要小看农民。

绝大多数农民的知识结构，特别是精明程度，维权意识，超过城里人。因为他们的一分一厘米来之不易，非常珍惜。

现在，高考入学率是80%，绝大多数农民家庭，有一个大学生孩子在读。这就决定了，大多数和农民有关的事情，会第一时间传达到千家万户。

但是，农民也有薄弱点。他们对于明面上的事情特别精明，但是对于无法判断的人生选择题，往往没有见识。老王是一个装修公司老板，几年前，他发现了一个秘诀，他去银行贷款，利率是6%左右，一转手就是8%-10%，他非常兴奋的跃跃欲试。他算过一笔账，他可以贷出六百万，吃差价就是2-4%，一年下来可以白得近20万。

我及时阻止了他。他还不服气。后来，参与的人都血本无归，就他一个侥幸逃生。
