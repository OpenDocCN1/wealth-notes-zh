# 01

西瓜满天星：亲戚听说我儿子成绩好，要把孩子放我家寄养，让我教！可怕她让她滚，断绝来往！

答：孩子成绩好是有套路的！就是家长费心，这是十几年的苦活累活，给我一百万我也不愿意干了。要是我有这个力气，宁可再去装修几套房子，和农民工干几架。

你想省事，把孩子简单交给家教是没用的。因为家教都是屌丝，只关心一件事情，你给我多少钱。至于你考的好不好，和我没关系，我也不感兴趣。就像你去看病，没人包疗效的。以前九十年代，小老板流行把孩子送到班主任家里，包吃包住。后来，不搞了，因为效果等于零。班主任哪有力气管你八门功课？最多是你给你考试前透点题，骗骗家长。

读书成绩好，就一个办法，刷题，比老师刷的还多。没时间怎么办？不睡觉了。然后身体眼睛就不行了。我读高中的时候，享受了VIP待遇，因为我是校长的希望，能不能突破本校历史上top1光头局面，就看我了。

我那时候，有什么题不会做，直接找任课老师。老师回家做出来，第二天教我一遍。到了高三，老师也受不了了，我的题他们也不会做了，几个老师在办公室研究标准答案，然后逆向解题。他们看到我就烦。

我曾把一本辅导练习册重新修订了一遍，每一个印刷错误都找出来了。

中考高考是怎么出题的？

我研究过几年的高考卷子，以数学为例。

先把一帮优质老师拉到疗养院休息，然后，三个人出一套卷子，其他人负责改题，最后改的面目全非，确保原创，你不可能押题。

但是你想想，这里面有没有漏洞？有的。
