# 01

赞美别人。

是痛苦的。有的人宁愿加班五个小时，也不愿意赞美别人五分钟。为什么呢？

赞美别人，好像是自己失败了。很多人心里已经知道自己失败了，但是不愿意面对现实，老想给自己一个希望。别看他现在跳的欢，哼，说不定明年就腰斩了。这样想想，我心里就舒服了，再来杯牛二，我就是这条街，这条街，最靓的仔。

赞美别人，实在是说不出口。我以前就这样的人。我更喜欢通过考试，让你服软。可惜，工作后，基本没有什么考试可以让别人服你的了。

赞美别人，就是在自己伤口撒盐。十年前，老子也有机会的，可惜，我那村口的爹非要告诉我，“马上腰斩了”。现在完了，我还要来赞美你，老子不服啊！

那么，怎么克服心理阴影呢？我以前也不喜欢吹捧家里那个中年妇女。可形势比人强，我也没办法。这个女人，三天两头就不带娃了，你让我怎么办？没办法啊！

小结：对命运认怂，咱不丢人。现在条件不好，以后有条件了，再换。为了小红，明豁出去了。

# 02

快递小哥。

刚才看了一个故事。快递小哥，今年26岁，中部省的农村人，光棍，现在大城市送快递，月入七八千。自认为不可能有什么发展了，也就这样了。

观点一：现在老家的经济发展越来越快了，小哥应该快点回老家，抢占有利位置。趁现在彩礼便宜，早日娶上媳妇，依托本乡本土的优势，搞点什么项目，争取更好的发展。在大城市里，你再混十年，就干不动了。那时候，你回老家，上下的靠，啥也没有了。

观点二：老家乡镇上，实际上更加难过，到处都是人情往来，互相攀比，心力憔悴，烦不胜烦。在老家，三四千的工作都很难找，更不用说七八千了。还是应该在大城市多挣钱。有了钱，争取在小县城买个三居室，让老婆孩子过上城里人的日子。
