我简介一个入门级的办法。你先找到在本小区里有做保姆的。很容易找到，你在小区里转转圈，开电动车的基本都是保姆，保安也知道。然后和她们聊几句。如果合适，请她介绍一个。保姆是互通的，一个保姆背后有几十个保姆。

一是试用期几天。合适就留下。

二是工资随行就市，保姆一般不会乱开价。小区里问问就知道了

三是去小区物业那里做好流动人口登记，复印身份证。这是个威慑作用。

四是讲究的人家，给她买个意外险。

备注，

+   1，愿意做保姆的，而且动作麻利的，一般不是坏人。坏人不愿意做保姆的，试用期也熬不过去。家务活，动作麻利，是装不出来的。

+   2，保姆和劳动法没关系，不涉及三险一金。

+   3，现在这年头，做保姆的，都是家里挺难的妇女，不要为难人家。

# 请保姆要具备什么条件？

一是房子大。至少给保姆一个独立房间，若是有卫生间更好。我家保姆住一楼，一层楼就她一个人。

二是工资。略。

三是不能太累。你不能把保姆当做丫头。例如晚上九点，你让人家去炒个菜，这事情就不要了。也不能起的太早，一般是六点半左右正常上班时间。

四是休息天，一般是每月四天，互相商量。

五是春节怎么办，事先说好。以前还有麦收春假假期，现在没了。
