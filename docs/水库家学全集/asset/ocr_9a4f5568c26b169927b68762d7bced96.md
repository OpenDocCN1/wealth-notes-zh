# 女人怎么为自己打算？

菜娘有个本科闺蜜，小美白＋985研＋沪籍，但是一手牌打的稀烂。小美白学的是经济学，毕业的时候是2010年左右，有两个可能性，一是去中专执校当老师，二是大展宏图自己创业，小美白发了疯，以为自己能力很强，就搞了个小网店，做起了货小二。

这个死女人一天到晚在批发市场和家里来回窜，也不打扮，也不交际，娘家就是普通人家，也没什么资源，她是一心一意要发财，但也只是混到了月入六千的样子，没有五险一金。她没发财也就算了，找对象还麻烦，殷实家庭，一听这个女人是做生意的，立马拒绝。熬到31岁，小美白按照商用车惯例打折，最后嫁了个屌丝。

她婚后继续干货小二，收入不稳定，婆婆暴怒，她只能灰溜溜的去找工作了，因为没什么技能，在一个破公司当了个行政主管，一个月1.5万。前不久，被公司当做优秀人才输送到社会上去了。现在她岁数也大了，孩子又小，实在是找不到1.5万的工作。她老公月入1万，全部付了房贷车贷，生活费是公婆支持，公婆一天到晚挖苦她，让她干家务，她气的发疯，但也无能力为。婆婆不喜欢她，觉得她没本事，没资源，还好吃懒做。让她出去买条鱼，她居然在网上买，又贵又不新鲜。婆媳矛盾激烈，三天两头吵架。

结论1，女人的第一份工作很重要，不求钱财，一定要体面。

结论2，千万不要嫁屌丝。婆婆太凶了。

结论3，女人一定要有私房钱。
