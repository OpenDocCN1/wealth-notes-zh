# 09

生活总是艰难的。只不过难点不一样。

80年代，户口是最大的难点。90年代，考大学，找工作是难点。

从头到尾，婚房一直是难点。这个世界，没有什么轻轻松松可以得到的好东西。社会资源对应的是你的社会排名而已。

你满足了这个，马上又会出现一个新的东西。慈禧安装一个灯泡，花了8千两白银，现在灯泡不值钱了，你就开心了？好像也不是。
