# （无聊的话题）高考数学如何得满分？

这个很有挑战，中下游成绩的瓜娃子就不要搞了。想冲一下清北的同学，我简单说一下。其实也很简单，叫做降维打击。

你是不是发现了一个规律，你中学学会的各种公式定理，是怎么来的？你压根不知道。你可以去图书馆找几本数学发展论看看，你就知道了各种公式定理的来源，以及怎么解决问题，这就获得了超级视野，因为你已经知道了各种定理的真正意义。

高考压轴大题，包括一些省内数学比赛，实际上是分析一个巧妙的应用场景。你怎么运用，就可以结合当年这些定理发现的过程，你想象一下，牛顿怎么看问题的，脑子转几下就知道了。省内数学二等奖不成问题。

我不知道现在高考数学满分还有没有意义。我们当年是有意义的，如果你考清北差三分以内，数学满分是可能获取录取的。当然，一般专业也不好，就是去物理楼报到那种。物理系都是黑胖花。
