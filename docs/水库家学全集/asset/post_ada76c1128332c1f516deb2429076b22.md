# 我这辈子见过的，最可惜的人才。
某丝，高考大省的理科状元。父母是农民，尽给他指指导。

那时候是先填志愿，后高考。最后，他考了个一般985的王牌专业。

这种人才，就算现在出去当老师，凭借20年前的声望，也是一个年入百万的香饽饽。可惜，他已经胆子小的像蚂蚁了，死活不敢。人的发展，是受到环境影响的。太可惜了。

遇到机会，不要怕。大家都是人，不比你能多少。丝丝们最怕的是风险。我以前也这样，总希望，能不能凭借聪明才智和吃苦耐劳，赚个无风险的大金元宝。这么多年过去了，我已经完全不担心风险了，甚至喜欢风险了。因为我理解了什么是风险。

这个世界，肯定有人赚钱。你不赚钱，是因为别人比你厉害或更有远见，挣掉了你的份额。你如果是人才，你就不要怕，可以自己给自己创造空间。我从来不怕竞争，因为我确信，我在自己擅长的领域，一定可以赢的。

小结，找一个自己擅长的领域，你也是王者。加油。艾母娘会倒闭房子的。

# 一线城市城市的特点是门类齐全，东方不亮西方亮。
财上海微博 2021-06-16

### 01
深镇是新晋明星城市，而不一定是完整的一线城市。

一线城市城市的特点是门类齐全，东方不亮西方亮。深的经济有点单一化，突出特点是，科技，而不是综合功能。

任何科技行业都有周期，一旦处于上升期，要风得风，要雨得雨。一旦转入下半场，那就大眼瞪小眼了。超级大城市要经历百年，几乎没有任何一类科技型公司，可以好过百年。因为在社会发展的各个阶段，消费者需求不同。近四十年，各时期的王牌行业分别是钢铁，石化，商贸，建筑，高铁，通讯。圳是赶上了一个特别好的机遇，一好好好。我不知道，下一个十年，王牌是什么。可能是医疗养老文教。

为什么行业周期会变？因为消费者喜新厌旧。一旦满足了这个需求，立马会去追求新的需求。大家可能不知道，石化产业在80年代有多么厉害？以前的人都是穿棉布衣服。棉布衣服很舒服，但最大问题是不挺刮，皱巴巴的，没精神，不符合审美。后来石化产业起来后，解决了这个老大难问题，非常畅销，风靡一时。谁要是买到一件化纤西装，回头率95%。

还有钢铁行业。现在钢铁行业不太过好。但是，在70年代，钢铁行业是绝对的王牌。老的五元钞票就是一个钢铁工人。

我们以前缺钢铁到什么程度，你去看70年代的画报，一般农村妇女都是扎辫子的，极少齐耳短发发型。为什么？因为没有发卡，那么小的一个东西，就是没有。因为缺钢铁。

发展多业态是很重要的。靠几个明星企业扛起了城市名片，并不可靠，很多方面是有所欠缺的，特别是医疗教育商贸服务文化等各个领域，还有短板。如果明星企业走过了行业巅峰期，若干年后不那么赚钱了，其他行业能不能顶的住千万人口的就业？

杭州南京成都都是综合性城市。完全有可能成为新一线。大家可能觉得天方夜谭。我举个例子。如果成都来了四五个明星企业，工资提到80万，清北复交的孩子，打破头要来，用不了三年，就是妥妥的超一线。

我对郑州是比较看好的，具备了起飞条件。

- 一是交通枢纽。所有的大城市，都是这个原因。
- 二是人口多。这是工业化的最基础原因。
- 三是能吃苦。现在包邮区的年轻人已经把当老板看成刚需了，这简直是有毛病。河南人还算可以，胡思乱想的人少。

### 04
逆袭的方法和感悟。

这么多年，我见过，也亲历过很多的逆袭历程，我把感悟写下来，给下一代人看看。

- 乡镇企业蓬勃发展，成就了一批人。我有个远房亲戚，是农民。18岁中学毕业后进入乡镇企业。那时候，进入乡镇企业就像是在进入互联网一样，是很多人梦寐以求的事情。那时候月入90元。
- 到了90年代，厂子不行了，没人要，就搞了改制，他倾家荡产，把这个厂买下来了。后来成为一个附近三个村的首富。
- 外贸火热。我有几个亲戚在浙江做小作坊，就是做一些塑料小零件，现在也发达了。
- 内贸爆发。举例，一个厂子生产辣椒，你承包一个地区，例如一个县，完成多少销售，就提成多少。其他产品同理。
- 股票害人。这个是近30年的事情了。我周围这么多亲戚，没有一个因为股票赚钱的。套牢很多年的，比比皆是。当然，有人肯定会说，我亲戚赚钱了。
- 电商带货。确实有一批人赚了钱，但不多。我知道有一个，原来是营业员，瞒着小老板，就把店里的羊毛衫在网上卖，吃差价发了一笔，也就两年时间，后来就纯粹白忙了。杠精不服了，我朋友怎么样怎么样的，“西开！”
- 结婚买房，略。很多农民工进城打工，买了个小户型，发了。

我发现一个规律，大规模逆袭往往是有深刻社会进步原因的。普通人在时代面前，是渺小的。丝丝不要一天到晚想改变，你应该顺势而为，站上风口。

时代的洪流，浩浩荡荡。

历史的车轮，滚滚向前。
