# 04

人怎么混社会？

必须要有一个见人见人爱的技能。医生律师贴瓷砖，都是好技能。别人需要你，才有下一步。我有个熟人，小区水电工。嘴甜人热情。长期在小区里干活，换个灯泡只收几块钱，换个水龙头只要八元；邻居们都喜欢他。有一次我家下水道堵塞，急得发愁，他解决了，我很感谢他。

小区的富人门这些年开始陆续买二手房，给外来地落户的老头老太太，或者出租收取一些租金，他就接到了很多二手房简易装修的单子，现在已经是某装修公司老总，年入几十万了。
