# 08

生活和逆袭。

人的一生，分为两个部分，一是生活，二是逆袭。生活占了你99.99%的时间。逆袭往往只是你的几个抉择而已。那么，生活和逆袭是什么关系呢？

生活就是为了逆袭选择做好各种准备。一是判断，二是攒钱。绝大多数人职业起步都是拿工资，但是，拿工资绝对不可能逆袭。因为工资水平是有社会竞争的。就算你是世界冠军，也不会拿到太多的工资。公司可以多请两个人就解决了。真正解决问题的是判断。

一是攒钱。当你面对一个机会的时候，你没钱启动，也是白想。

二是判断。当你有了一点点本钱，你就要让这个钱飞速发展。很多人聪明啊，一天到晚研究肯德基打折优惠券的规则，一个月可以节约四五十元。但是，这事情没有意义。你爸妈把你养这么大，不是为了让你去节约几十块钱的。你要做点大事情。

很多人的想法是，我要无风险逆袭，这是不可能的。话说二十年前，你现在知道了，那是内环白菜价的搞笑年代。但是，你家发财了吗？没有。为什么？因为当年也不容易。我记得我有个同学，他在长宁区内环线来福士那里买婚房，当时是六千多，很漂亮的港式大楼。他觉得很，这么贵，天都要塌了。后来，他老爸和他说，做人的目标是，跳一跳，够得着，你还年轻，冲一冲。然后过了二十年，他现在最喜欢吹他当年的眼光有多好。好个叼蛋，当年你吓得像条狗。那时候，我就在你身边看着你的。

你在生活中，要多思考，多观察，总有一条缝被你发现的。

依买了啥地方，多少面积?

# 09

屌丝逆袭的经典故事。

小王是我的一个初中同学。24纯屌丝，屌的都没了丝了。他一天到晚想的就是娶老婆，可惜没有丈母娘愿意看得上他。小王是某郊区的一个文员，月入微薄，每天无精打采的。他小时候读书成绩也不行，高考是进了一个降分录取的外地本科法律系，这专业实在是太破了。家里也穷，无房产。就这么一副烂牌，硬给他打出了杠上开花。

话说某年花开月圆时，就是2007年，有关部门出了新规定，就是劳动合同法。这个事情，对很多小老板影响非常大。小王所在的单位就搞了很多培训，小王是公司里的法爷，实际上是打酱油的。因为大家对培训不感兴趣，就把这事情塞给小王了。小王闲的无事，认认真真研究了一下，讲的不错，经过层层推荐，然后到其他小老板那里做培训。
