上海今后的新房基本都在远郊区了。

你坐飞机，可能就有体会了。从飞机上俯瞰，市中心基本没有空地和棚户区了。远郊区的定义是，开车去苏州一医，比去南京路更方便。新房的居住体验，小区绿化，肯定比三十年前的市中心老破中好多的多。但是，新房有个难点，上班不方便。例如宝嘉青松是现在的热门地区，但是你在市中心上班，简直是天天跑长途的感觉。

# 05

如何成为牛人？

我年轻时候就一直好奇，如何在本行业成为一个牛人？经过二十年的观察和自我体会，我发现了一条路。

一是工作要专业对口。不管什么专业，就业不要脱离本专业，因为你的本硕博经历也可以算作资历，周围的人会认为你专业

二是十年冷板凳。你在工作的前十年，不要太多的考虑怎么赚钱，而是要一心一意搞专业。等你完成了这十年的基本功，别人一辈子也追不上你了。

三是走市场经济的路子。不要沉迷于靠上面提携的地方。那种地方，很压抑。
