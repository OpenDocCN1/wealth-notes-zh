# **05**

不要嘲笑你看不懂的事情。

现在，所有的快递公司大老板，都是超级富豪了，财富论坛的超级嘉宾了，小红最喜欢围着他们又唱又跳了。我当年就知道他们，他们被各种报纸称之为“黑快递”。当时，我在富明几净的大单位里，一张报纸一杯茶的研究新闻。我们单位，报纸特别多。看一个下午不带重复的。

我很早就知道了各种快递公司，电线杆上到处都是，当时他们是作为坏蛋被批评的。而且，还有各种各样耸人听闻的案例。我那时候，年幼无知，以为他们都是坏蛋。而且，那时候的快递员都很low，看上去就像是捡破烂的，到了一个单位的门卫，眼珠子滴溜溜的转，说话一口乡音。所以，我对他们嗤之以鼻。然后，眼睁睁的看着他们飞黄腾达了。

再说说电商。我实际上是互联网的第一批用户。那时候没有搜索。我们要去买一本超级厚的书，类似于辞海那么厚，上面密密麻麻印满了全世界的位置。你输入网址，十分钟后，可以看到半页。那时候是用28k的猫上网，那个慢啊！打开一个网页的时间，可以睡一觉了。那时候最厉害的网址是新浪搜狐。

我对电商的记忆很早。我印象中第一个电商应该是e什么f的，创始人是一个上海小伙子。当时，最厉害的是国唤电器，我们对电商嗤之以鼻，觉得就是几个乡下小商贩在群魔乱舞，哪有我们金光闪闪的大单位牛逼？过去几十年，我见证了无数的超级富豪的崛起，可我一个也没捞到。

再后来，进入电脑数据库时代。每个单位都要搞一个电脑管理，就是用数据库把单位里的客户资料编号。我们单位请的是某软件园的几个屌丝。他们很有意思，名片上印的是，xx高级工程师，xx总工程师。我当时吓得一哆嗦。你看上去也就20多岁，总工程师了？他们笑嘻嘻的说，私人公司，随便印的。于是，我对码农彻底鄙视了。后来得知，他们现在每个人都是几千万身价了。

我们那时候，最牛逼的是，在单位里当个柜台经理或科室小头头，那就是天底下最亮的崽了。如果遇到大方的，谁晚上请我们去小餐馆吃顿饭，上一盘盐节虾，再打个保龄球，可以幸福一个星期。我以前只在饭店里吃过盐节虾。那时候，芥末+海鲜，是土豪请客的符号。

年轻的时候，我就是这么蠢，完美的错过了几十个成为首富的机会。
