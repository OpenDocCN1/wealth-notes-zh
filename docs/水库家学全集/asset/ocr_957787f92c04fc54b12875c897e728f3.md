大城市户口有没有用？

如果你不结婚，不生孩子，没什么用。如果你有孩子，那就不一样了。

先说自己。买房买车，霸总裁，和你哪里户口，没有影响。例如我，就算是靠山电二村六组，也可以成为公司霸道总裁。但是，等你有孩子，你就头大了。主要是读书。

+   1，义务教育是统筹的，你不可能自己想办法。理论上没有户口也可以申请，但是，你去问问一般人，他们的经历会告诉你，事情不是那么容易的。

+   2，高考是按照户口的。这要求你娃在初三就回老家，建立报名资格。

+   3，夫妻分居。如果你家孩子在初中回去了，独自准备高考。那你放心吗？你估计不太放心。你就会辞职一个人回老家伴读，一般是4-5年。在大城市分居4-5年，还有爱情，那你的爱情质量还是比较好的。如果这期间，那个总货男人发财了，你怎么办？

以我的研究，基本就这些区别。另外还有个小小的区别是买房。本地人买房，不需要等五年社保，没有户口就要等2-5年社保，你要保证价格在2-5年不变，否则就头大了。

小结，孩子教育，婚姻质量，买房时间，和户口有一定关系。

建议各位大学生，提前考虑。另外，大城市现在也不好混了，老家省城也可以想想。
