# 装修是夫妻感情的第一次严峻考验

不同的人生长于不同的环境，对于美和家的装修认识是不一样的。但是，一套房子只能装一个样子。

买家具吧。我的想法是实用。结实。价格便宜。菜嫂的想法是，高端大气上档次。于是，立马打了一架。

硬装修。菜嫂觉得，护墙板是最爱，我觉得刷大白就可以了。两口子又是砸锅砸碗。

地下室装修，菜嫂搞得好多复杂，特别是要买一个超豪华大落地吊灯。我说，地下室有潮气，简单点就行了。差点打起来。

再说院子，我说总共就一亩地，搞什么搞？防腐木围一圈就行了，便宜啊！菜嫂说，我看了唐顿庄园，就要那个风格，于是又是一天到晚吵架。

最后，菜菜彻底输了，丢脸又丢人。幸好，老婆保住了。

# 出去旅游一次，就最能够看清楚对方是什么人？

菜嫂就是通过旅游把我看上的。那次旅游，我相当于一个机器人。负责看地图，买门票，安排餐饮，安排时间，路线，处理突发情况。选择题一个又一个，最后考了个高分，其实也很简单。

一是选贵的。吃住行，只选贵的，不考虑其他。因为在旅游景点，很容易引发纠纷。选大牌机构，纠纷少。

二是有眼力见。菜嫂瞄了一眼什么，我立马去买。

三是吃最好的。旅游很累。必须吃最好的，旅游区都有五星级宾馆。

四是做导游。女人没有方向感，我就负责看地图。
