# 02

做个均衡的人。

现实中，你会见到两种人，

一是业务极强，性格极差的人。

二是不学无术，人人喜欢的人。

这两种人都是走偏了的人，还自以为是，洋洋得意。有的人把所有的 时间用在了钻研业务上，就像是当年的菜菜，一谈起业务，犹如黄河之水天上来，那是滔滔不绝啊，一说起托人办个事，年底提一级，顿时像泄了气的皮球，蔫了。有的人，天生不喜欢研究学问，一天到晚琢磨怎么玩，一说业务，皱眉鼠眼，眼珠子乱转，一说关系，那是眉飞色舞，拦都拦不住，我是路路通。

这两种人都混不好。我见过的，混好了的人，大部分是比较均衡的人。

一是业务能力中上。太差也不行。毕竟业务部门总不能找个250。

二是人际关系特别好。上上下下都喜欢他。

给小伙伴一个建议，一定要注意人际关系，很多矛盾的时候，适当让一步。大家开心，你才能混下去。吃独食，活不成。
