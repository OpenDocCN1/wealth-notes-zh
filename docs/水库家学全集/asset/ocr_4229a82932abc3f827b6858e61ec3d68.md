# 为什么杠精这么多? 自卑。

大多数人有一颗强烈炫耀的心, 做个头发也要问问别人“好不好看?”, 但现实条件不允许大多数人有机会炫耀, 例如级别, 财富, 名气, 达不到要求, 心里憋屈。

于是, 很多人想通过自己知识丰富来炫耀。但别人没时间听你胡说八道。于是, 别人说什么呢, 他就抓住机会, 凑上去反驳, 痛痛快快怼几句, 以此满足一下虚荣心。真的是惨不忍睹。

我建议, 还没有发财的人, 不要自己培养杠精思维, 贻害无穷。因为你的老杠精思维大概率会传给予女, 得不偿失。有这个力气, 还是抓紧换时间买房子, 不要有二逼老太那里交房租了。
