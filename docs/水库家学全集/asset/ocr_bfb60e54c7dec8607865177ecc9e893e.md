# 08

二本子如何逆袭？性格好的考编制，能力强的进私企。

现在的私企已经进入下半场了，经过几十年大浪淘沙，活下来的私企都是金刚钻，铁布衫。很多人一直认为，私企工资低，待遇差。这不是绝对的。私企的一般人确实工资不高。但是，私企内部的几个大支柱人才，收入高的令人发指。

一般私企熬过十年，基本都是功成名就了，但是老板也身体熬垮了，子女还小，不能接手，急需一个强悍的二把手，无论男女，学历，年龄。只要你有能力，一般都可以拿到几十万，几百万。

当然，这个二把手不好当。

内部有威信，你讲话有人听。至少需要干五年。

外部有业绩。一个企业关键是销售或者技术，你要在这个方面有突破。

建议：二本子如果有志气，去私企混混。私企天天在风口浪尖，提心吊胆，如果你是人才，能够帮助小老板赚钱或者省力气，小老板把你当爹。
