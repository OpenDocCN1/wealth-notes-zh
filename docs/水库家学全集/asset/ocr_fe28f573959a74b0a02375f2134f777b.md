# 我们的骟平。

年轻时候，我也有过短暂的骟平想法。因为实在是没办法了。当时，我们一个月一千多收入，房子只能等单位分，没有任何办法。事实上，我在单位里五年八年内是分不到的。想当年，有个兄弟分到一个60平米的房子，我嫉妒的已经龇牙咧嘴，眼前发黑了。又穷又没房子，一个小伙子还能怎么办？你可想而知了，实在太痛苦了。

当时，我已经绝望了。单位里偶尔聚餐，老居丝们把吃剩下的鸡鸭鱼肉给我打包，我也只能接着。黑夜里，眼泪呼啦啦的流。女人更是不要想了。和我们差不多的女生，超级鄙视我们这些无房户屌丝。当年，那些最早认怂的哥们基本都找了附近的拆迁妹，后来成为了巨大的悲剧。

当年，我更惨，我就算想认怂，也没地认怂。因为附近的农村拆迁妹看不上我。你们可能不知道，拆迁妹也是按照地段分好中差的。下手早的兄弟，混上了单位附近5公里（还在内环线）的拆迁妹，到了我想明白的时候，已经到了20公里外（接近外环线）的闵行区了。以前因为没有交通工具，大家都是坐公交车小巴，远了就不行。

那时候，我已经眼睛发直，人都呆了，完全没有任何改变的可能性，彻底死心了。这事情不是我一个，而是一批中年油腻男的记忆。后来，我们这拨人大多数发达了，绝大多数人把老婆蹬了。这群拆迁妹招谁惹谁了，可惜啊。但是，他们也真的不敬规。就这么说吧，相当于一个清北毕业的基金经理，老婆是老锅公司的中年妇女，一天到晚叽叽嘎嘎，还几十如一日的嘲笑打击那个985倒插门，女方所有的亲戚都在鄙视这个sb，你说惨不惨？

小结，当一个困难来临的时候，只要不是你个人的问题，总会解决的，不用担心。

我们都在用力的活着。酸甜苦辣里，醒过也醉过。

# 05

作为一个家长，我对小额贷款就是深恶痛绝的。

以前，很少听说有大学生被社会人追债的。现在多了，因为网贷太方便的，有的娃躺在宿舍里就把钱借了，一个控制不住，就直坠深渊了。

有个娃想买一个苹果，算了算，一个月只要还几百元就OK了。时间长了，收不住了。最后各种小贷，多的一笔吊糟，把娃逼到了绝境。

很多人可能会说，十八岁了是成年人了。事实上，现在十八岁的娃，心智程度并不高。以前，十八岁是上班年纪了，现在基本都是大一百一高三，哪里玩过的社会人啊？
