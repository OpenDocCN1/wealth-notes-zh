# 03

为什么大部分不敢做生意？因为风险太大。

我以自己周围几个亿的小土豪做过一个研究，创业要多少钱？如果你是破釜沉舟，在此一搏，基本需要当时一套婚房的钱。菜嫂家是投入了五套婚房的钱。钱从哪里来？基本都是借的，或者几个人合伙（大多数悲剧收场）。有的人缘好，可以借到钱，有的是连哄带骗，有的是卖祖产。

做生意需要万事俱备吗？不可能的。一开始做生意，只有一个模糊的概念，基本啥也不懂，经常被骗，只有一颗想发财的心。被骗不是那种卷款潜逃的诈骗，而是把差的当做好的卖给你，你也傻乎乎的乐。你把婚房亏完了，你也入门了。然后就开始大甩图了。

有一种做生意的途径比较简单，就是员工起步，他做了三五年，基本看清透了，拉几个同事撑起脚。这种情况，非常多。起步成本相对节约一点。但是，也有困难。你和老东家竞争，没有什么优势，客户对你知根知底，也看不起你的实力，不太好吹牛，对你防备心很强。你本来就没多少钱，还很难融资。

做生意没有简单的办法。基本上都是要苦熬很多年，遇到一个商业大契机，发了。然后去和小美白吹牛，哥哥很厉害的！
