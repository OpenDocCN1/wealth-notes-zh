# 04

# 为什么农村二上二下的大房子不住，非要来大城市挤出租房？因为收入。

我们1大黄山农村什么都好，就是没有现金收入。一个村两百户人家，除了种玉米，根本没有就业。地里有新鲜蔬菜芋头，拖到城里也很麻烦，可能根本不赚钱。但是，要花钱的地方太多了，儿子买房，县城三室一厅是标配，娃娃读书，公婆看病，冰箱彩民洗衣机，都要花钱。

没钱怎么办？只能去赚钱。村里赚不到钱，经济养殖也要很大的本钱，一般人也搞不起来。最好的办法是出去打工。打工的难处是住宿。广东浙江电子厂一般是包吃住，但是工资不高。在京沪打工，不包吃住，送快递八千是很普通的。

结论：靠近大城市赚钱机会多。农村看不到现金，难办啊！
