# 03

文凭改变命运。

我读大学的时候，食堂里有几个和我差不多年龄的小伙子。这实在是太惨了。大家是同龄人。我在读大学，有美好的未来，他却在食堂切肉丝，洗大白菜，一天到饿晚可怜的给我们打饭。我曾经在心里可怜过他几百回，好可怜啊。

斗转星移二十年，前不久我的一个同学告诉我，当年在食堂打饭的小伙子一直在北京，主要是承包单位食堂，没有回老家温州。这些年他买了三套房，而我的同学只买了一套房。现在看，我同学已经远远落后。

实在没想到，生活居然是这个结局。
