# 02

维持币值的跳跷板。币值要想坚如磐石，一般是两个方面。

一是汇率。汇率涉及到食品，石油，矿藏。现在的牛羊肉供应充足，有两个主要原因，成品肉进口，饲料进口。目前外汇是比较顺畅的。

二是购买力。那么多钱，要能花出去啊。那怎么花？

1，日用品。由于世界工厂，商品还是比较齐全的。与此同时，农产品也不错。当然，日用品有个特点，买不了太多。你家一般不会买六个冰箱。那是250了。短期内看不到通货膨胀，因为生产能力充足，特别是日用品。没什么技术难度。卫生纸，拖鞋，羊毛裤子，要多少有多少。
