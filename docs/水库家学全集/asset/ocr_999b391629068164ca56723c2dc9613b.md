# 单元房和别墅，哪个合适？

对于一般家庭，单元房肯定好。因为别墅的使用成本实在是太高了。

一是空调。冬天别墅很冷，采暖费用必不可少。我简单算一下，一个冬天，集中供暖三五千，如果是自己地暖，一万元算中等。夏天，一个月电费两千打底，一般要五个月。

二是维修。别墅的管线复杂，乱七八糟的小事情特别多。现在维修成本高，费时费力。

三是保洁。大户型的保洁和家务，一般要占一个人工。你家老婆不上班也可以。如果遇到老鼠之类的，就是大闹天宫了。

四是装修费。单元房装修一般是10-30万。别墅加个零。！！我还没见过一百万就可以搞定别墅装修的。

五是购房款。一般情况下，别墅的总价是单元房的5倍。

天底下没有白花的钱。别墅的居住体验好于大平层，也有一定面子。

别墅成本太高，不要轻易买。买两套大户型打通是比较划算的方案。
