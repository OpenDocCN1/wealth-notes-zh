# 怎么培养孩子成才？

各家各户情况不一样。我用最简单的话说清楚。

一，无欲无求的土豪家庭

很简单，按照孩子的兴趣，他喜欢什么就干什么。反正也不指望他赚钱。

二，希望孩子有出息的家庭

说白了，棍棒出孝子。没有孩子喜欢读书考试的。你和他讲道理，一个小时就没了，他还不听。咱也不要说那么多了，最简单的办法就是一顿揍。没有孩子不怕揍的。

一个孩子要想有出息，必须做到两个要素：自律，细心。考试，完美的体现了这两个元素。我们的文化传统也不是吃干饭的。几千年无数人研究出来的东西，不是你不认就可以的。

自律就是每天认真上课写作业，雷打不动二个小时。细心就是会做的不要做错了，检查一遍。

在这个条件下，有些孩子还会搞一些花头，自学成才。我家娃有一次考了99分，错了一个，答案是9，结果写成了7。孩子有点坏，他把7改成了9，然后去找老师问，哪里错了？老师一看，就给他满分了。娃洋洋得意的回来了。我没揍他。

有时候作弊这也是生活的一部分。你在单位里和部门经理拉关系，你给孩子请家教，你找三甲副高，你是前几年买婚房了，何尝不是一种生活的作弊？
