# 为什么买别墅？

我是研究房子的。我非常清楚，别墅没有什么增值性，也没有流通性。买别墅的唯一可能就是传家宝。但我还是买了。为什么？

一是居住体验。别墅的特点是独门独院，没有楼上的干扰。

二是漂亮。

三是有花园。菜嫂喜欢养花，农民本色不改。

四是给娃留一个童年的回忆。这一点是我最看中的。我的童年是在马路上玩大的。那时候没什么汽车。别墅里的小娃娃特别喜欢串门，家长一般也热情接待。别墅串门很简单，在院子门口大喊一声，然后就看到一群小娃娃骑着儿童自行车一长串进来了。进来也不客气，看到什么吃什么。吃完就走了，去下一家吃。我和菜嫂经常买几箱零食水果招待他们。

热门评论:

+   - **程均邦**: 照你这种情况说的，跟我们村里差不多……
- **田边菜菜**: 说的就是我妈的乡村大别墅嘛。。串门就方便
- **喵喵侬悦**: 这个别墅听起来是高级版本乡村日记?
- **种种东西**: 主要还是3_5层，有尺度感、一定的缓冲，少了偶尔低头不见抬头见的顶心顶肺，利于和谐。
- **也许真的或许假的**: “喜欢养花，农民本色不改”这句话一点没错！我婆婆爱农村人，超级爱养花! [图片]

# 内环线有很多人没住过好房子。

最近搬到一个小区。我和娃天天在滑滑梯旁边守着，等待给小娃娃找几个同龄的好朋友。在等待的过程中，也遇到几个附近小区的老头老太带娃，实际上是蹭我们的小区花园，于是听他们闲聊。其中有个老头得意洋洋的说，自家房贷，每月一万，老房子是漂亮小区大二居，租出去也有一万，无债一身轻。

旁边一群老头老太羡慕不已，纷纷述说，自己的小破房只能租出去三四千，一辈子没有住过好房子。他们还算幸运儿，女儿女婿或者儿子媳妇收入高，才买了现在的房子。还有很多人家一辈子住在五六七八十年代的老小区。

我非常吃惊的发现，真的有好多好多的人居住条件不太好。有一家人，原来一共50平米，小二局，岳父岳母女儿加上女婿（外地大学生），挤了四年，现在外孙有了，实在是无法住了，就置换了一套，贷款七百万，亚历山大。幸好女婿是复大学毕业的码农，月入五万多，否则不可想象。

在内环线月入五万多，那是凤毛麟角了。其他人可没这个运气了。我只能感谢菜嫂了。
