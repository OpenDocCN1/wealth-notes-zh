# 女人怎么看男人的？

这就像你去买个车，买之前和买了两年后，关注点完全不同。

结婚前，女人的想法可多了，

首先看地位。经济地位，社会地位。你开个保时捷去相亲，成功率比较高。你放心，别墅大平层是现货，比清华复交那种虚头巴脑的期货好使多了。

二是看潜力。有些姑娘自身条件达不到一线要求，就退而求其次，例如看单位，看学历。

三是看颜值。有些姑娘，找不到有钱有地位的男票，就看颜值了，总要捞一个。

四是看舔狗。不要舔狗没用，实际上对某些特别类型的女生是杀手级作用。我认识一个女生，很漂亮的英国硕士，也是小土豪家庭，前男友是佼佼者，清北毕业，父母土豪，自己也白白净净的。女生拼了命要嫁。可惜，男生不接招，受伤多年后，遇到一个舔狗，三下五除二就被撩住了。女生的意思是，找到了一个懂我的人。懂个锤子。舔狗见谁都是那些话。

婚后两年，女人就一个要求，“都听我的，不服就打他”。
