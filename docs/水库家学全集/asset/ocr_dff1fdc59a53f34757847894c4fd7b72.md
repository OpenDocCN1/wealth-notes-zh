# 婚姻和读书考试有没有关系？

答：关系很大。任何婚姻都有矛盾，粘合剂是娃。如果娃的成绩非常好，很多时候就忍了。我娃成绩很好，娃一天到晚想参加考试，这可以赚钱啊。别人家的娃一提到考试，就心情不好。我们家的娃，一听说要考试了，激动的不行了，主动要求加班加点。把他老母亲累的不行。莱嫂经常说，还好是一个娃，如果多几个，只能放弃了。

莱嫂是我们家一家，经常殴打辱骂配偶，我也忍气吞声。为了娃今后结婚有大平层，我也心甘情愿愿当牛做马了。如果两口子经常互殴，娃成绩也不好，这个家庭就很让人心碎了。那么，怎么才能让我娃成绩好？

我觉得最重要的是，家长要会考试，一般考二代是很厉害的。也就是说，至少一个家长要非常熟悉考试规律，一个家长有耐心。我们家是我制定计划，莱嫂落地。时间长了，莱嫂以为都是她的功劳，谁要是来抢功，直接翻脸不认人。
