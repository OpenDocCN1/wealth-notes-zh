# 09

一般人没必要买奢侈品。因为奢侈品不会给你带来任何附加值。

莱嫬有一对非常漂亮的耳环，还有一对惊世骇俗的绿色手镯，玉质的，号称祖母绿。如果是真货，应该是近百万了。实际上是仿品，莱嫬花了一万多买的，买的时候就知道。有一年，内环线搞了一个国际玉石珠宝展览会，莱嫬一个人去看了看。那天是最后一天，参展的某外商可能嫌弃带回去麻烦，就低价卖了。

莱嫬喜欢绿色的玉石，就花了一点小钱买下来了。买的时候就知道是仿品。然后，莱嫬在大house里，经常带着这些珠光宝气接待客人，获得了高度赞美。奢侈品的价值不在于你花了钱，而是看用什么去配。如果你在地铁里背个爱马仕，没有一毛钱意义。
