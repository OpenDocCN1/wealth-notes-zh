# **大城市，只要有房有地，小日子还是不错的。**

财上海微博 2020-02-13

# **01**

买房子不要太关注赠送面积。

绝大多数赠送面积是没有实用性的。例如阁楼，地下室，大露台等等，加起来一百平米，不要钱，你高兴的跳起来。与此同时，赠送面积多，可能会有一些缺点，例如采光，临街，配电房噪音，户型不整齐，南北通透风，等等。开发商比你精明多了。他们加量不加价肯定是不可告人的原因，你不要被表面的小便宜迷惑了双眼，放弃了主要利益。

你去看房，一定要想清楚，你主要诉求是什么？不要考虑那些鸡头鸡脚的小便宜。如果大露台可以封闭，售楼小姐肯定会反复告诉你的，如果她不太提及此事，那就不要多想了。你买了后，物业公司换一批人过来，凶神恶煞的。
