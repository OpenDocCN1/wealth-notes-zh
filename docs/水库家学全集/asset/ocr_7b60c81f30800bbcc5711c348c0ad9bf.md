# 富人在海南怎么过日子？

其实也很普通。带1-2个保姆，（买或租）一个有三五个卧室的大宅。买一个小车，逛街买菜旅游。然后就是过日子。小区里一般有饭厅，游泳池和购物中心，不出门也没什么。阳台超级好，可以看大海，鸟语花香，渔火点点，晚上看大海，有种世外桃源的感觉。厦门也差不多。但是，厦门冬天要冷一点。

海南水果海鲜丰富。我们内地人平时很少吃的热带水果，海南很多，吃不完。海南的海鲜比不大上差，因为海南的水产品，壳薄，肉不动道。

住海南最大的问题就是寂寞。因为脱离了熟悉环境，没什么人聊天。建议，要去住最好扎堆。

海南物价还算一般，不低也不高。和内环线差不多。一般到三月份就走了。
