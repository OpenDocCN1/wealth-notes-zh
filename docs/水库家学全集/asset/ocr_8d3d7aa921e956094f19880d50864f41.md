# ## 什么叫经验？

绝大多数二本子对于经验是不屑一顾的，老子什么不懂？还要毛的经验？我举个例子，农民工是怎么秒杀大学生的？

装修最多的是贴瓷砖，但要先拌水泥。二本子笑了，拌水泥有标准比例，我什么不懂？但是你见过农民工带个秤上班的吗？

二本子不服了，一包水泥七包沙，你不会数啊？好，老子只要一小桶水泥补一下缝隙。你怎么办？二本子傻眼了，总不能用烧杯一点一点加吧？老师没讲过啊！你他娘的，你是不是故意为难人？

实际上，工地工人拌水泥是不看比例的，他们看颜色，水泥黄沙的不同比例混合后，会呈现不同的颜色，你一看就知道够不够用了。

结论：一个事情干多了，我眼睛一瞄就知道m2是什么情况。等你反应过来就晚了。去！把瓷砖镶下来吧，否则会说脱落砸人了。
