# 06

被动倒插门

内环线有很多这个情况，我估计30%以上。男方是凤凰，女方是坐地户。婚后，丈母娘帮忙带娃，老丈人帮忙接娃，男方买不起房子，先在女方家凑合两年，慢慢的，男方随女方一家门生活了。男方在思想主观意识上不是倒插门，但实际上过成了倒插门。

我认识好几对这样的。前不久，我们小区发生了一个破事，女婿和售楼小姐，买房一年后喝趴头了。那个房子大概是1200万，首付七成，再加上杂七杂八的装修家具办证，九百万打包。小夫妻一下子拿出来了。把售楼妹看的心花怒放。实际上，是老丈人卖掉原来房子六百万，再加上一家人多年积蓄和东拼西凑三百万。因为要房贷，女婿把一切资料给了售楼妹。我靠，码衣，月入七万，真香。估计是女婿先撩人家。最后一曲《广岛之恋》，搬下去了。

男人最喜欢面子。女人不要太凶了，要学女人家的优点。你别说，那温柔，真不是盖的。比母老虎温柔多了。很多女人在家吃苦受累，本来男人也很感谢，但是，被你一顿骂，老子就很高兴了。
