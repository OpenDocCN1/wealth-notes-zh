# 什么是浪漫？

你在女生宿舍楼下点十五块钱的网购小蜡烛，那不是浪漫，而是恶心人，谁缺你这十五块？真正的浪漫是一句话，“带上身份证，我们去售楼处”。

前两天，莱嫂遇到一个中年妇女，她儿子已经初中了。她对莱嫂说，当年，她是私企小职员，老公是饭点小老板。有一次，她老公在售楼处直接给她一个惊喜，买了个小房子送她。于是，他们结婚了。这个故事也没什么惊天动地，我唯一好奇的是，这个女人居然近20年念念不忘。每次说这件事的时候，好像一脸陶醉。

莱嫂回家后，我就倒霉了。莱嫂抄起拖鞋，满屋子追着要我打，“啊，你看看人家，你给我买什么了？”老子郁闷了。

我的意思是，男人也挺辛苦的。丈母娘是不是也自觉一点？早点把房子买好。最好不要低于160平米，你们老夫妻今后来带孙也得有个地方住，不能委屈你们了。我们985，也是很注重生活品质的。至于姓什么，我无所谓。

# 现在夫妻分手越来越多了

我认识的人中，有不少离了。大概有几种情况，

一是男方发达了。小美白发了疯的往上扑。女方一怒之下暴打男人的。

二是经济因素。有个男人，胡乱投资，损失了一百多万。女方30岁，受不了了，改嫁了。

三是男方太穷了。三天两头吵架，女方有正经工作经济条件还可以，散了。

四是因为某种原因，名义离婚。

双方没感情，各管各，纯粹是拜把子兄弟关系的，更多。

主要看，大概都是和经济有关。没有是夫妻打架离婚的。太穷或者太富了，矛盾就多了。矛盾多，很容易吵架。吵架就伤感情了，就过不下去了。

一个家里，女人管钱的，基本不离婚。我有个同学，春风得意马蹄疾，但是，在家里没地位，老婆天天骂他，也老老实实掏家里。
