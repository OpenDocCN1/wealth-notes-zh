# 01

江景大豪宅舒服吗？

给我我都不 要。就像我们农村出来的，不喜欢独栋别墅是一个道理。江边居住多麻烦，一是早上噪音，船的气笛声响到什么程度，大概类似于火车头乱叫。二是潮湿，上海人最不喜欢潮湿了。三是风大。冬天江面开阔，风大，又湿又冷，活受罪。我小时候手背上都有冻疮，太可怜了。

# 03

傅爵闪：你说这个Moncler有多贵呢？

上上个月港城打折，我去逛Moncler，进去之前问领导，这个牌子到底有多贵？领导说跟鹅差不多吧，我想买的就进去了。

然后试了一件，领导说不好看，但是我觉得非常好看。后来一看价钱折后4万多，我扭捏几下，脱下来推给销售，义正词严：“我还是要尊重领到意见的！”

财上海：菜嫂买了件豪口，穿上去像个女民工。结果我又瞄进去个貂。
