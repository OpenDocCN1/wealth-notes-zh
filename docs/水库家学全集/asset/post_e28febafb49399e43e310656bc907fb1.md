# 楼市关乎农民工增收

我们的农民工不是什么高科技人才，优点是，吃苦耐劳。这个和需要创造力的高科技八竿子打不着。但是，吃苦耐劳不仅仅是我们的优点，很多其他地方的人也可以。如果自废武功，结果显而易见。我不相信，几亿的农民工现在就能够转行做高科技。

能够大規模实实在在给几亿农民工增加收入的无非是拎灰桶，装修队。我这两年买房子搞装修给农民工搞走不少钱。我是985，贴瓷砖的收入比我高，还欺负我，三天两头用脸子，我实在是没办法。现在贴瓷砖的农民工都是开着小车来的，牛气的厉害。白开水不喝，都是矿泉水。

楼市链接的上下游，建材，甚至是保洁，都是赚赚钱，装修后大清洁，一天就是一千块，还找不到人，保安物业三天两头对装修业主搞事情，装修垃圾按重量收钱，说白了就那点心思。我们都懂，没办法。楼市再冷下去，量就不行了。涉及到农民工收入问题了。

作为一个冷静的经济学工作者，我们心里很清楚。这么多农民工是很难转换到其他行业继续保持高收入的，还可以对业主甩脸色。后面有什么变化，水到渠成了。业主怕什么，至少还有面积在手里，你怎么办？高科技的特点是资金密集型，不是劳动力密集型，这一点我们都看明白了。
