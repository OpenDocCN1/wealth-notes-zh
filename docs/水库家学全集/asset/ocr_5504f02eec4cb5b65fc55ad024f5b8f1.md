# 填志愿，很重要。

1，城市。好多人不理解城市的意义。这主要是求职原因。任何一个大学，在本地深耕多年，有发达的就业渠道。杭州到处都是浙大的。如果你家条件好，京沪欢迎你，如果家庭一般，我有两个建议，

一是浙师大萧山。如果考的上，这个校区应该是世界上最好的大学了。

二是重庆长沙。这两个地方，房价低，以后成家立业容易。当然，这两个地方，工资一般在四五千左右。

2，大学。大学的讲究比较多。同一班级，分数可能差距五十分。我推荐几个性价比高的，一是吉林大学车辆工程专业。吉大在985里面分数靠后，但是这个汽车专业，市场上堪比清北复交。二是西政法律专业（普通本科）。重庆西政基本等同于北大法律系的99.9%。西安建科的土木工程，基本就是我清建院系的待遇。

3，专业。家里有钱的，建议文科和经管类，好混，期末突击一个星期就解决了，平时想干嘛就干嘛。家里困难的，建议选比较累的专业。例如挖矿，铺路，修桥，码农之类的，这些工作一般是荒郊野岭，钱多但磨心。家里有路子，就选父母的能力范围。考编制，选经济类和法律类。

4，本科超级重要。如果你家成绩不好，建议报个小地方的破本科，就是听上去丢瞎瞎的地方。你要记住，最好的大专，不如最差的本科。

5，名校情节。如果你本科上不了清北，可以考个师范类本科，进去之后，一门心思考研，争取搞个清北研究生。山东河南的本科学校一般都是考研的积极分子，氛围比较好。

6，赚钱。飞行员，码农，农业就赚钱，比较热门。机械电子专业，需要时间磨练，珠三角的私人电子厂和机器厂的大师傅收入也很高，和你的能力有关，如果厉害，年入百万也很多。我举个例子，有个屌丝是食品专业的，你可能都无法理解这个专业是干什么的。结果人家年入百万。为什么呢？他改成了一款辣条，生意好到爆。

7，娶老婆专业。你就往西南来。辣妹子，辣妹子，辣辣辣！

8，最重要的还是城市，你想去哪个城市，就考哪个学校。举例，京沪本地的二本，比特苟自觉的985好的多。
