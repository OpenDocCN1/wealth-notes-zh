# 人懂事的年纪是四十岁，不管男女。

道理也很简单，绝大多数人到四十岁了，你一辈子能取得什么样的成就，基本就清楚了。如果有个别现在势头还很猛，你的人生答卷总分配加个10-20%，也就如此了。或许有个别的50岁才开挂的牛马，因为极其罕见，就不在研究样本范围内了。

40岁之前，你有好多幻想，你在单位里也愿意让步，人际关系上也愿意吃亏亏，希望以后能够有所回报。等你到了40岁你就发现，尼玛的，被骗了。这时候，你会复盘，老子混成这个破样子，究竟是哪一步走错了。你已经看到了答案，这时候你再回忆以前的每一个决定，你就非常清楚自己哪一步走错了。越来越多的事情，豁然开朗，哦，原来当年他们是这样玩我的！你也就成熟了。册那，悲催啊！

我考试成绩极高，但人生成就就不高，算机缘巧合，还挣了点东西。我年轻时候，因为没房子，导致了太多了遗憾。后来有条件了，我就尽可能给娃攒一点攒一点。日积月累，滴水穿石，就有了一点点积累。

希望大家能够发展的顺顺利利。最好把自己的人生感悟传承下去。
