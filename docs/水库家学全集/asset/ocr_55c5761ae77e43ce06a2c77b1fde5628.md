# 普通家庭不要囤积现金。

财上海微博 2020-01-16

# 01

为什么大家都在推荐网店？因为现在大家都在看手机。

我给网店做过配套，自己也开过网店（销售经理发神经了），我知道网店的生存状态，也就是二八效应。80%是赔读的高价自费生，白忙一场，很可怜。

2012年，我遇到一个中年危机的白领创业，码农失业了，无所事事，就开网店，一个季度做了三十几万营业额。一分钱没赚，还把老婆赔了。因为网店生意大部分在网上，经常忙到三更半夜，老婆受不了了，劈腿了。

不赚钱的原因是，人工工资太高。他要招聘几个人，小妹，搬运打包的，贴单子统计的，还要弄个房子（就在自己家里）。这些人白天无所事事，还一天到晚要加工资，搞得乌烟瘴气。上班就是上网，还说是了解市场，出差就是旅游，说是考察市场。那个白领苦逼，白天睡觉，晚上加班，辛苦的不得了。小公司三五个人，每个人的岗位不一样，没办法搞考核，进货都是小老板自己去拿，生怕采购员吃回扣，因为采购量小，有时候还要换换货，讨钱，只能自己去，太累了。

最大的麻烦是库存。有一次，小老板觉得某手套卖的好，就想自己下单，没有中间商赚差价，委托加工。这下子变成开厂的了，一系列破事，比装修还痛苦，还要付款提贷。最后剩了一大堆库存，欲哭无泪。

老婆看他三个月零收入，气得发疯，也不做饭了，大吵大闹几个星期离婚了，手把手练了几年的马子最后让给别人用了。。

结论：做网店，要女方提出来，就不会离婚了。

# 02

普通家庭不要囤积现金。

我经常装修房子，买不起精装修，实在是丢人。我也每年请保姆，我发现一个有趣的现象，十年后，可能农二代就不愿意干活了。

+   1，装修队的儿子，普遍不再干装修了，因为吃住不好。

+   2，保姆的儿子不愿意干活了。绝大多数保姆，受到大城市的影响，这些年都在省会城市或县城低价买房子，子侄们都是从生活在漂亮房子里，吃肯德基刷小火锅长大的，但是他们的教育环境考不上985。读二本子，待业是普遍情况。
