# 赚小孩子的钱，可能是发财的最快办法。

大多数女人现在比较实际了，自从背上房贷，买貂也心疼了，乱花钱的情况大大减少。但是，小孩子花钱那是很厉害的。我这么多年喜欢看免费电视剧，我家小娃娃喜欢看动画片。现在的人，真是坏啊。在我家小娃娃看的最开心的时候，中断了，要交钱，49.99元。哪有这么干的？损不损啊？我这么多年，就算是90秒的广告，我也忍了，就不想交钱，结果他们把目光盯住小娃娃了。

小娃娃在家满地打滚，要求交钱看《小马宝莉》，我也没办法，交了，心里一万头草泥马呼啸而过。你现在别看笑话，你静下心来想想看，你能不能搞点什么去赚小孩子的钱？
