# 亲人的贪婪不会因为你的大方而改变

很多人有这样的感觉，你的亲人和别人不一样。马路上的陌生人，好像是贪婪，冷漠，自私的，而我的亲人不是的。实际上，你的亲人，也就是别人眼里的陌生人，大差不差。

很多人因为小时候接受过亲人一些小小的帮助或者恩惠，感恩戴德，觉得这个亲戚是好人，实际上不一定。我小时候，有个远房亲戚过年给我五块钱，那时候，一个油墩子是几分钱，当时，我幸福的直跳，这么多年也不敢忘记。最近听说，这个亲戚借了其他亲戚几百万跑了。亲戚临走前，还给我设了一个局，编造了一个包赚钱的生意，打算让我卖一套房去投资。因为当时小美一天到晚和我闹，我也没细想这事情，后来忘记了。于是，这个亲戚没办法就跑。

小结，感谢小美。
