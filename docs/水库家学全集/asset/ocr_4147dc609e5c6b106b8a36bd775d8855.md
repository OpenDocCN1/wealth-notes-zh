# （家学）以前是怎么拜师的？

![](bbox=[0.48, 0.39, 0.51, 0.41])

以前，拜师就是学技术。有了这个的神神道道的小技术，就可以在十里八乡混饭吃了，衣食无忧了。例如，木匠，厨子，看病，裁缝等高精尖的活。还有一些做生意的行业，例如茶叶古董，牛羊买卖，当铺米布，这些生意基本不需要什么文化，还都是非常好的活路。很体面，容易娶媳妇，是大家很羡慕的营生。

但是，你有没有发现，以前很多人根本没有机会去学这个手艺，只能一辈子苦哈哈的种玉米。为什么？因为，绝大多数师傅不愿意教你，除非你给很多学费。但是，这些生意，都是不入流的行业，有钱人不想学，没钱人学不起。一般人付不起学费，能够拜师学艺的人很少。最后就出现了一个折中的办法。

徒弟给师傅白干三年，打杂，打下手，甚至包括洗衣做饭擦地板，同时承诺给师傅养老送终，相当于干儿子。所以，有了天地君亲师的说话。在以前，师傅吃席是坐主桌的。出师之后，不得与师傅抢生意，绝大多数是继续给师傅干活。比较常见的例子是，以前大户人家的小姐太太做衣服，都是师傅带个徒弟进去测量。实际上就是师傅接单子，徒弟实际干活。

能够拜师的学徒还是比较幸运的，一旦师傅退休了，徒弟就是独当一面的老把式了，立马过了中产日子。甚至有了个门面，可以当老板了。

现在，拜师学艺的事情几乎不存在了。为什么？因为徒弟会和师傅抢生意。你教会了徒弟，一转身就挤死老师傅。所以，现在有很多活路已经失传了。例如涮羊肉怎么做最好吃？

我认识一个农村老人，他家是世传五代的土郎中，也没有什么文凭，就会一掐正骨，治疗某个疾病，效果非常好。其实也没什么花头，就是对准一个部位压一下。如果正经救，三分钟就会。一招鲜吃遍天。他老父亲在在三十年代攒下了很多土地，后来倒霉了。

小钻，你在夜深人静的时候想一想，你能不能给灶留点什么秘方？我已经准备好了套很大的暗房，你呢？
