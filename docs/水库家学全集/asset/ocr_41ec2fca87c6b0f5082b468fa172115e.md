# 山西票号为什么经营不下去了？

历史上有很多解释，例如被现代银行击垮了。我以自己的工作经验谈几句。主要是大股东和职业经理人闹翻了。

票号的规矩是，部门经理（掌柜）比大股东（东家）厉害。东家出本钱只有人事权，没有经营权。职业经理人（掌柜）出力，只有经营权，没有人事权。

这个设计，有点像现在的股份制企业。但是，这里面忽视了一个人性问题：企业分红权。

在职业经理人的操作下，掌柜的收入，远远超过股东。而且，职业经理人为了拿钱，干一些短期行为，高风险的事，最后双方闹翻了，把企业活生生搞死了。好多人说，票号是因为日本鬼子打戏，实际上不是的，而是自身出问题了。票号垮了之后，再也没有恢复了

# 古代镖局是怎么赚钱的？

刚才翻了翻家里破纸，说几句。

镖局的特点是，营业收入极高，利润极低。大部分镖局说白了就是白手套。以前山贼多，衙门顾不过来。商业活动需要运输，怎么办呢？镖局起到了一个白手套作用。从商户收钱，发给盗贼。

甲地到乙地，一共八百里！每一段都有一个大王，一共七个，每人给1%，就是7%，自己留一点开销。就这么简单。

镖师的作用是对付一下零零碎碎的小毛贼，不是对付大股土匪的，实际上，一镖镖，也不可能去几百个人。成本受不了。如果丢了镖，只要有一个活着回来，就知道在哪个山头出事了。立马可以找到当地负责人

如果山贼乱来，镖局就协调附近一起去搞事情。山贼也受不了。
