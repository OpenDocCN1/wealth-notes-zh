# 01

男人一定要宠爱老婆。

我老婆就是家里的头号母老虎，一天到晚骂我。我就像是余则成，深入虎穴六十八载，长期忍辱负重。原因也很简单。这个泼妇，管娃很尽心。如果哪天女人生气了，不管娃了，我就害怕了。如何让女人尽心尽力管好娃呢？

一是男人要认怂。我是家里的唯一怂包。那个母老虎一骂人，我就灰溜溜的认怂。男人必须有这样的心态，女人才有动力去认认真真管娃。我家娃，各方面还是比较好的。但是，我在娃的心目中，基本没有任何价值。

二是女人花钱，万万不能说。菜嫂喜欢乱花钱，她居然可以去买个六千块的花瓶，放在客厅里观赏。她可以买两万块钱的窗帘，就因为花纹漂亮（我不觉得漂亮）。这些都是共同财产啊！我是丝丝出身，实在是接受不了。但是，不管能不能接受，必须认了。按照我年轻时候的脾气，肯定是跳起来了，但是，形势比人强，我直接秒趴。

三是女人犯错，不能当面指出。菜嫂也有犯糊涂的时候。有一次她要去投资理财，我也不敢吭气，就是拖。拖半个月就拖倒了。当母老虎兴冲冲的告诉你，她发现了财富密码，你要是敢泼冷水，你就完球了。对待女人干蠢事的唯一办法，是拖，而不是吵。女人在兴头上是不理智的，吵架没用的。

她当年嫁给你，不是因为她有多理智，而是蠢。

# 02

考上985，真的可以逆袭吗？

看你想要逆袭什么了。985毕业，一般是去一个窗明几净，光鲜亮丽的好单位，月入1点几个达不满，其他不要想了，不可能的。如果你是一个村里的金凤凰，以后想成为一个大城市体面的中产，985是最好的路子。财富地位和985，没什么直接关系。那985有什么用？

以我多年的观察，985在找对象方面，优势明显。985可以抵消一个你的缺点，例如没有房子，长得丑之类的。但也只能抵消一个，不能全部解决。现在的很多丈母娘还有文艺迷思。她们当年考不上名校，特别遗憾。如果你有个985文凭，可以让丈母娘把女儿洗的白白嫩嫩给你送过来，还不要房子。

我年轻时候认识一个女熟人，她是985。原来在外企当白领，现在公司待遇也不行了。她长得一般，160cm。路人甲的水平，黑区区的，脸上有几颗痘，关键是没陪嫁。她爸爸是该溜子，妈妈是家庭妇女，女生一直想改变命运，股癣了大半年，但是人家实在是的娶她。后来拖到31岁，嫁了个老破小的211。婚后一年，老破小男人就对丝丝毫不感兴趣了。当然，老破小也没有能力出轨。他们就在互相骂骂咧咧中，苟活了十几年。
