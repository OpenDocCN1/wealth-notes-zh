# 亿豪是怎么来的？

我认识的几十亿豪，都是后市算出来的，和他们不熟悉。我最熟悉的是身价才几亿的老老板。他们的发财路径，我实在太熟悉了，每一步我都走过。二十年前，老王开了个小厂发财了，然后遇上买地，几万元一亩，买下来盖楼，大宾馆，大厂房啊，盖房子成本不高，大写字楼，再遇到几个大客户包下来租了。

那些大租户，为什么这么有钱？人的想象力就是自己周围的那些事情，你永远想象不到大租户是干什么的。我对这些行业太熟悉了。举个例子，银行每年发放贷款，需要你提供很多很多资料，这些堆成山的资料要保存几十年，最后放在哪里？呵呵，银行经理也不知道。我知道，就是租个郊区大楼放着。

还有很多暴利行业，身价几百亿的纳斯达克企业，他们需要庞大的配套和工作人, 宿舍，仓库，车库，加工车间，停机坪，这都是发财的节奏。举个例子，4s店，需要多少场地你就搞不清楚了。不要以为就是你看到的那个展示厅，远远不止。
