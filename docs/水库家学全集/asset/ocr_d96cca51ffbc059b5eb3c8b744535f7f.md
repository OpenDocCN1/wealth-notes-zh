# 为什么大学生最鄙视销售岗位？

一是销售岗位不需要任何门槛，只要正常人就行了，大学生觉得郁闷。我辛辛苦苦搞了个二本子和村头小卖部家的狗剩一个待遇，不高兴了。

二是销售岗位一般是求人。我们的习惯是，万事不求人。我低三下四和你推销产品，心情不愉快。

三是收入不稳定。很多销售员是提成。没有业绩就没有收入。波动比较大，不喜欢。

实际上一个企业里，收入最高的岗位，地位最牛的员工，就是销售部。会干活的人多了，会卖货的人不多。

如果你今后想当个老板，盖摩天大楼，做五百强创始人，最好去干几年销售。你当老板，总要害卖货啊。不要指望员工，他干得好，会无穷无尽要求加钱，干的不好，你就挂了。
