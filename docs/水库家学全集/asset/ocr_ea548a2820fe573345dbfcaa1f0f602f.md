# **04**

高中物理。

这个课程是最难的。以我top1的经验看，物理本身不难，难的是，物理老师喜欢炫耀，出题角度太多，同样花多的时间，物理性价比不高，化学比较好。为什么要让两个小球转来转去的，这不有病吗？解决物理的办法是两个，

一是学好物理。没有什么简单办法，就是拼命学。

二是放弃物理。高考是3+n，你不选物理，可以选择化学，生物，历史之类的。同样是理科，化学卷子相对容易一点。

我当年问过很多教授，为什么物理卷子那么难？他们支支吾吾的，后来我终于搞明白了，闹的。

物理和化学不一样。两个小球撞来撞去，基本是天体物理专业，他们这个专业就像谈恋爱一样，很少做实验，基本就是在宿舍里拍自己油光油亮的秃瓢，苦思冥想，想多了各种怪题就来了。化学专业，经常要做实验，没那么多时间拍脑壳。所以简单一点。
