# 26岁在上海拥有的第一套房子！感恩爸妈！

也是没想到趁着2020年的末尾，26周岁，在上海拥有了人生中第一套房子。

融创徐汇滨江壹号，180平。全款付清。

其实在选房现场的时候我整个人都是懵逼的。

这个楼盘一共1200多组人认筹，一共两百多套房子。我170多号。选号结果刚出来的时候，大家都祝贺我说一定能选上房子了。

但是当我进入会场之后，看着前面还有十组人只剩下三个顶层，一组一组拿完。我的心都往下沉了。

轮到我选的时候我就记得我两眼一抹黑，所有高层都没有
