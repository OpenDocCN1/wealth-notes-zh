# 05

给不精通英语的家长说几句提高成绩。

英语考试就是，选择题十小作文。我教你几个小办法。

一是背单词。高中2800个单词，肯定够了，你去买本单词表，或者把课本背后的单词背下来。这是第一步。看不懂单词，就没法聊了。

二是做卷子。不求多。每一题都要搞懂就行了。就把学校里的卷子搞一遍。或者找老师推荐一本书。

三是背十个左右的小作文，不管什么题目，你直接套用，改一改关键单词就够了。

辛苦一个暑假，我保证你进入班级前十名。
