# 我当年毕业的时候，大致分为两拨人，和现在差不多。

财上淘微博 2021-05-15

# 01

大学毕业后。

我当年毕业的时候，大致分为两拨人，和现在差不多。

+   1. 坐地户。这批人，文凭不高，欲望不强，但家里条件不错。我们当年的工作，压力不大，这些人过得超级开心，每天喝小酒。特别是泡妞，爽死了，他们基本都有房子，有拆的，有买的，也有父母单位分的，经济条件好，找女人特别容易。

只有一个局线被老女人骗了，其他小伙子都混到一个漂亮老婆了，绝大多数是小单位的正式编，例如莲花乡经济开发总公司（这属于正式单位，当时很不错的）。我不知道为什么，我们年轻时候的姑娘，不如现在的白皙，可能是化妆原因。小姑娘普遍都是，嘴吧嘣嘿黝曲的。

坐地户们醉生梦死，过得无比开心。当年小酒馆多，吃饭喝酒便宜，他们一天到晚就泡在酒缸里，喝完了，就去洗桑拿，洗完澡，打麻将，周五吃过午饭就看不到他们了，全跑了。我当时羡慕嫉妒恨。

不过，他们的好日子到30岁就结束了。结婚生子后，天天带娃，老婆管得紧，事业卡壳了，生活完了。

+   2. 外来户。这批人一开始很惨。没钱没房，文凭也没用，单位里也普遍被人看不起。我大致算这一波的，因为我是郊区的，在外滩附近也没房子，一天到晚和外来户们厮混。他们的优点是985，长得好。当年，招聘我们的HR，中年妇女犯花痴，她对我们外来户的标准就是985长得帅，拉出去就是个模特队。

这群外来户在30岁左右，因为房价便宜，经济上追平了坐地户。但是到了40岁，也基本停滞不前了。因为任何行业，都是金字塔，不可能无限上升。

说白了，不努力，30岁就歇了，因为没本事。很努力，40岁，也歇了，因为没空间了。

+   3. 意外情况。我们那些人现在都四五十出头了，绝大部分泯然众人矣，也有几个意外情况。

一是命好有路子。省略一百字。你也学不来。

二是辞职务工作的，当年机会太多，现在一个个都是金融大咖了。

三是倒插门的。省略一个故事。

四是做生意的。我记得有个技术骨干，因为一次意外事故，试剂爆裂，单位要处分他，他一怒之下，自己辞职走了，据说去干装修了。邢那，服气了。以他的很劲和聪明，2001年到现在，应该过亿了。

五是买婚房的。这批人很多，大多数是老油条类型的。因为买婚房，不需要投入大量时间，老油条特别多，一起聚在食堂抽烟，互相交流信息。当年真的是便宜，遍地是金子。当年，就这群油腻腻有钱。
