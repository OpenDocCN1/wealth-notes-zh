# 08

人的一生实际上就是在做选择题，不选也是零分。

我从小到大非常努力，功课非常好，但又怎么样呢？在单位里，因为我不会混关系，被霸凌的很爽，努力了五年，还不如人家去找头说说好话。人生大概有几个选择题。

一是找工作。你的前五年工作，决定了你一生的性格脾气。你在前五年，会形成对职业，人际关系，社会，财富的概念性认识，以后，你的性格脾气，思维方式基本就那样了。

二是找对象。这个事情决定了你的人生。老婆漂不漂亮，在婚后已经不重要了，重要的是心灵伴侣。如果这个人不爱你，你就算倒霉了。赶紧踢了。

三是找房子。这个事情决定了很多很多。特别是你不再年轻，赚钱能力下降后。

努力可以让你有更多的选择，但是，如果选错了，你就没有回头路了。下一代再来吧。

有很多人说，我故意不选，拖下去。这是不可能的。你的年龄，你的家人会让你拖不下去的。你不要听人说这个好那个好，你就听从内心的呼唤，找准目标，主动出击。没有人会关心你的生活。你的父母，实际上也没能力关心你。

苏格拉底说：归根结底，人生是孤独的。希望你走出最漂亮的上升曲线。
