# 09

对大四的屌丝说几句，如何选择城市？

你们快工作了，也该懂事了。这么说吧，如果不是年入80万以上的码农工作，你可能难以通过上班实现财务逆袭。那么怎么办呢？估计是要靠首付了。我十几年前买的婚房，已经可以让我成为附近六个村的首富了。

我读书的时候，班上也有很多小地方来的同学，我印象中有甘肃县城，河南县城，成都的。他们现在的财富水平远远落后于在大城市 的同学。其实当年买的时候，差距不大，区别是后面二十年的城市发展。你选择了哪个城市，就要和它一起成长。那怎么选择城市呢？有个简单的办法。

如果这个地方送外卖基本有六千以上的月入，那就不要犹豫了。这种地方，非常有活力，一定是明日之星。

# 11

苏州好不好？

苏州的优点非常明确：工资不错，资产成长性极佳，苏州老婆也不错，不要彩礼，气候温润，生活舒适。这个小城市，风景特别好，以前不堵车的时候，还可以雨中散散步，现在不行了。

但是，江苏的城市都有一个非常大的麻烦，高考特别痛苦。如果你是学霸，可以考虑。
