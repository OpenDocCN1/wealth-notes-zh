# 04

好小区的外地娃。

每一个好小区，都有一些外地娃。我们小区就有几个。和他们家长聊聊天发现，他们也挺麻烦的，主要是读书没人管。

有一小娃佳读一年级。他爸妈是一个贸易公司的土老板，挺有钱，三天两头出差。于是，这个小娃佳苦逼了，只有一个保姆照看。这么大的房子，黑灯瞎火的，小娃佳下雨天就害怕。一年级的小娃佳不仅仅是吃饭，还要玩耍，读书。于是他爸妈没办法，就在小区里找了几个说得来的家长，意思是，如果可能，保姆带着周末来你家玩。

我是没意见的。多几个小朋友来热闹，也没什么。再说了，人家有保姆带着，摔一跤也说不到我头上。但是，仔细观察这个娃，我发现好像不太幸福。听他们家保姆说，这娃太孤独了，没什么好朋友。他一来我们家，赶都赶不走，一直要玩到晚上九点才要休。否则就是大哭大闹。

这家人也挺不容易的。他的贸易公司在市中心，三天两头出差，是夫妻俩的公司，回老家也不可能。老家父母也是土豪，根本不想来。两口子也没办法搞户口，最多读到初中就要滚蛋，心里很难过。
