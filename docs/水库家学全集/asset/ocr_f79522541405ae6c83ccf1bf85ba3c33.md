# 可怜天下父母心

一年前，曾经有个粉丝问我一件事情。他是农民工，在大城市瞎混，他儿子是农村留守儿童，爷爷奶奶管饭，成绩也不好。他希望儿子能够考上985，以后读博士，去京沪广深考上优秀编制，名利双收，过上好日子，丈母娘出房子。他能做的是可以给孩子提供二十年生活费。

问我有什公秘诀能够保证儿子考上？我当时没有答复他。但是，这个赤果果的问题对我造成了巨大的心里创伤。

实事求是的讲，这种孩子怎么可能？这个家长是属于异想天开了，自己不行，希望在床上开心几分钟，生个蛋，让那个蛋去天空翱翔。想得美！可这个答案，我怎么能够说出来？

面对他们家这样的困难，比较现实的做法是，让孩子去健身房多练练肌肉，特别是三角肌，以后找个爆有钱的资深淑女，一步到位，大家开心。现在，很多井盖村老乡已经在走这条络了。祝福他了。

这个问题对我的心理创伤实在是太大了。当网红有时候也是很痛苦的。

# 小镇做题家的下场

我是小镇做题家出身。我当时的心情是，我要用考分干翻暴发户。后来，我清醒了。一般过程是这样的。从小到大，家里日子不好过，父母都是资深钢筋，一般比较穷，还扣扣搜搜的。小镇做题家的唯一信息量是来自几个发了财的老家亲戚，实际上亲戚们也看不起他们家。
