# 12

穷人的孩子早当家，是什么意思？

以前，我一直以为早当家的意思是“柴米油盐”。现在发现不是这个意思。一般经济条件比较差的家庭，父母也是烂泥扶不上墙，什么事情都不会办。如果孩子要想出人头地，就必须自己学会各种各样的生活技巧，也就是自己当家拍板。

有的孩子，啥也不用操心，父母都安排的好好的。有的孩子，父母两手一摊，家里啥支持也没有，攒钱，办证，买票，找工作，找对象，找房子，都要自己安排，一次失误就是永远错过。在各种各样的复杂环境中，孩子学会了和各种各样人打交道的技巧。这些孩子长大以后，就特别厉害了。
