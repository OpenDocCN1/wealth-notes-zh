# 京沪广深找老婆容易吗?

京沪广深，各地漂亮姑娘都愿意来碰碰运气，男的就因为各种经济限制回去了。在大学里特别明显。女多男少，找老婆就容易吗?

我认识一个小伙子，家里是外地省会的，读了个英格兰二本子，机缘巧合，在北京找到了一个带编制的工作，前几年还解决了户口。他家里卖了三套房或门面，凑出六百万，给他买房首付。这下子抢手了。

+   三是积累。任何生意，起步阶段都要一些资金，否则看到机会也没有能力。

+   四是买婚房。你也不想做大事业，那就拼掉一辈子，踏踏实实给儿子买套婚房。以后儿子会感谢你的。
