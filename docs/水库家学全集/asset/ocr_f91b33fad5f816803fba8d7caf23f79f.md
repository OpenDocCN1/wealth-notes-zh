# 01

富人心软。

其实不是富人真的有多好。现在的富人，小时候也是穷棒子，性格早就定型了，和你读二本的班上同学差不多。

富人因为公司事情太多，麻烦太多，心理压力太大，对于一些不太重要的事情，没有时间精力去搞，所以有种错觉，富人心善。例如你要是骗了一个百亿元豪家里几十万零花钱，百亿元豪不会找你拼命的。因为他的时间更加值钱。

但是，你不要去惹屌丝，他们的时间不值钱，为了一点点彩礼打折，可以和你闹上三个月，到处说你家卖女儿，想想就烦了。

结论，还是嫁富人靠谱一点。
