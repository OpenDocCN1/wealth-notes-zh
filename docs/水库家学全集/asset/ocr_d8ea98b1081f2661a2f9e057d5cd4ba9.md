# 亲家矛盾。

有钱之后的快乐，你无法想象。

我在出租房里的时候，幻想有钱人的生活，应该是买四个油饼，吃两个，扔两个，再买一大堆好东西，请三个保姆，每天吃鲍鱼龙虾。实际上有钱的生活不是这样的。我简单说一下。

有钱人的基本生活还是比较好的，想吃什么吃什么，想买什么买什么。保姆也有，你不用洗碗擦地板。但是，这不是主要的，更加刺激的是其他事情，即别人对你的态度。

土豪最大的福利是，女人超喜欢你，特别是老红。我在大豪宅里，接待过很多人，有认识的，也有不认识。无一例外的是，各家老红对你表现出了极大的热情。有个老红，他们家男人也买了别墅，但是好几年没钱装修。看了我的房子，很喜欢，就问装修多少钱，我说硬装三百，家具家电要一百，还要监工两年，精疲力尽。在阁楼拐角处，老红一下子眼圈红了，好像在说自己嫁错男人了。

以前有人说，土豪只要摇摇钱袋子，就有老红要和你过。我原来不相信的，现在真TMD相信了。简单来说，当你在出租房里，绞尽脑汁的想怎么讨好小红的时候，小红却在想怎么讨好菜婆。

愿屌丝们都过上土豪的幸福生活，照顾好老红。
