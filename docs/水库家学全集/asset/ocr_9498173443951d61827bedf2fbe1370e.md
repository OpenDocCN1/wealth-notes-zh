# 外地985如何在大城市安家立业？

我是郊区来市区的，相当于外地人，没底子，一路走来，心酸自知。

一是找工作。我们那时候找工作比较容易，就是钱少。现在找工作，需要考虑的因素就多了。建议，尽可能往中外环考虑。房租低，找对象容易，生活开支也少一点。郊区有很多安置房，长期空置，你今后三五年住着，很安心。

二是找老婆。城乡结合部有很多拆迁妹，她们对985有加分。你选择余地大。

三是买房子。目前，郊区的漂亮小区，大部分在五万以下，90平米就是450万。首付150-120万区间。郊区一般都是独生子女，丈母娘疼女儿，你不要太担心。

大家不要以老眼光看郊区了。我最近考察了一段时间。给我的感觉是20年前的浦东。现在的郊区，规划特别好。新马路又宽又大，三甲分院陆续陆续过去了。还有各种商业综合体，也慢慢过去了。郊区也分为两种，一是老城厢，人口密集，环境嘈杂。二是新小区，鸟语花香，和伦敦差不多。

如果你留在内环线，一开始工资比较高一两千。但是，也有很多现实问题。

一不要攀比。内环线的年轻人，很多家庭条件比较好，也有点爱面子。你会时刻感受到碾压。

二是开支大。内环线的餐饮交通成本，明显比中外环多一点点。地铁溜一圈回来，大概就是十元八元
