# 01

菜菜，我爸在省会要买两个双拼别墅，合起来就是一个大独栋，周围一圈草坪，大概有一亩地，特别漂亮。我爸说，今后，我和我哥哥兄弟两个人一人一套，他和我妈住一楼小单间，给我们带孩子。菜菜，遇到这么好的父母，如何报答他们？

答：不用报答。你就告诉你父母，保证将房子传到第三代就行了。

# 02

大城市里，人生绝大部分烦恼都是房子不够带来的。有钱没钱，等于劣质。有房没钱，还是优秀。这是我家在内环线蹲了一百年的感受。

# 03

回县城干什么？

很多人不满意京沪广深的活，活的累，吃的差，上班远，买不起房子，找不到老婆，背井离乡受气啊。在窗口经常听说一句，“除了身份证，还要你的乡下户口本”。那那，阿拉也是省会城市下面的县城好伐？没人care你！我好想回老家，吃妈妈做的饭，在小县城当个体面人。半夜十点还可以去喝夜啤酒，周末去附近爬爬山，天天住大房子。但是，回去干什么？如果没有收入，小县城婆姨的嘴，会撕了你！

我最近发现了一些小小的线索，你参考一下。小县城和大城市的各种业态越来越接近了。前不久，我的法律顾问告诉我，他高中同学在老家，一开始是体制内的，现在辞职做法务顾问，专门研究离婚官司和股权公司，一年收入二三十万，现在已经开宝马了。我差点一口咖啡喷在地板上，“什么，小县城还有股权纠纷，这是大城市的事情啊！”

“这你就不懂了。现在小县城的土豪家庭越来越多了，各种事情和大城市都一样。离婚也是打房子。做生意也炒股。继承官司不稀奇了。”

这里面透露出一个惊人的信息，小地方越来越大都市化了。他们想要的服务，和京沪广深越来越接近了，例如县城的奥数兴趣班，芭蕾舞兴趣班，也风靡一时。
