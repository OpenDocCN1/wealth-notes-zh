# 上山容易下山难。

我研究了几十年了，没搞清楚，为什么上山容易？现在终于理解了，这就是在说我们的人生。人生大概分为上半场和下半场。上半场很精彩，下半场很难受。

人的上半场，就是中年以前，你会发现，你每年都在变得更好。小学中学大学，恋爱结婚买房，找工作领工资，升职加薪，不到35已经是小头头了，还有人专门给你拍马屁，看上去蒸蒸日上。人的下半场很可怜。身体不好了，枸杞喝起来了，年轻的小伙伴一批一批的冲上来，不要命的加班加点了，你真的受不了了。孩子还小，到处都要花钱，父母老了，杂七杂八的事情特别多，三天两头跑医院。再也听不到什么好事了，耳朵里都是坏消息。

上山容易啊。你的上半场很容易。你的发展，只要随大流就行了。单位里的老头老太要退休了，空出来的副高正高就是你的。老妈们的儿儿长大了，总要洗的干干净净，敲锣打鼓送过来给你用，还要倒贴嫁妆。什么好事都是你的。

下山难啊。你的下半场，没钱没力气，加班加点也不行了，用不了十几年就退休了，更是两眼发呆，提不起兴致。年轻人也看不上你们了，你的技术，思维也跟不上了。就算有小白愿意给你用，你也拿不出多少资源和我说钱了。最后，通通把你扔到养老院，也不要祸害子女了。

上半场和下半场的转折点，大概是40-45岁。这是客观规律，大自然法则。谁也没办法。怎么让自己的下半场过得稍微好一点？上半场攒点东西，下半场拿出来补贴。弱弱的问一句，依房子买好了伐？

# 因为爱情

人到中年，我终于明白为什么结婚要找有感情的伴侣，而不仅仅是漂亮有钱。在你的人生中，你会遇到各种各样的困难痛苦，夫妻之间也会大吵大闹，剑拔弩张。如果没有感情，两口子很快就散了。当然有感情也不完全解决问题，毕竟生活是靠物质支持的，没有地暖的房子他妈的好冷啊！
