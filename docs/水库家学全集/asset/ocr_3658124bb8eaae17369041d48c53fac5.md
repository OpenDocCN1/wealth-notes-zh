# 04

（人生处处有商机）说个赚钱的小故事。

前两天，菜姨有个小公司，要去某窗申请个事情。以前办的一个会计离职了，于是菜姨自己去办。因为没办过，菜姨看到一大堆表格，有点晕头转向。这时候，在大门口遇到一个小姑娘，可能是二本，愿意指填报表格。菜姨高高兴兴的答应了。

看的出来，这个小姑娘就是吃这碗饭的。菜姨也挺高兴。一点点钱节约了很多时间。这个小姑娘能够发现商机，又是合法操作，确实动了脑筋。

现在的人越来越累，也越来越懒了，你要是能够解决一些实际问题，真的有钱赚。希望大家不要懒，多想想办法。

很多事情，本身并不复杂，也不烦人，只不过你不懂，也没心思研究，心里打鼓。你要是能给他人带一下，就是一个好路子。举个例子，有一次验车，保险单过期一天了，我知道这件事情肯定可以解决，就是不知道有多麻烦。我算中偏上的经济条件，可以花点小钱，不喜欢麻烦。于是，我在网上找了个懂的人，咨询了一下，一共说了12分钟，我给他发了个100红包，表个心意。

小结，只要愿意动脑筋，大家都可以在家里躺着赚点钱，当然不是想发大财。
