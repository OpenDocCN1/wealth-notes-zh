# 07

工作技能和工作经验。

你们单位的副总裁，技术上比你厉害？不是的。他可能根本不懂你的专业，可是他是你的头头，你一点办法也没有。为什么他会成为头头，而你不行？就一个原因。你没有社会经验，人见人烦。

那什么是社会经验？社会经验就是，你的想法，不一定是别人的想法。你觉得这样做，这样说，大家会喜欢你。事实上，人家恨不得揍你一顿。你觉得，我指出你的缺点，那是为你好。人家恨不得一脚踢死你。你觉得马上腿软了，人家觉得你就是卢瑟。你觉得大家都喜欢你，实际上，你就是个垃圾。

# **热门评论**：
