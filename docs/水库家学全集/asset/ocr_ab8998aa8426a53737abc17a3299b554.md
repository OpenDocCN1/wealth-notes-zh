# 02

韩国的租房端。韩国为了降低购房需求，想方法想的方便租房者，搞了个办法，禁止房东中断租房，提前收回房子。租房者高兴了，拖欠租金也不怕了。没想到，这办法砸了自己的脚。房东为了避免损失，提高了租房者的门槛，提高了租金，部分房客觉得，租房很麻烦，不划算，改为买房。然后，房子一飞冲天。
