# 01

未来的商业会如何？基本就是金融公司说了算。

假设你工作三年，月入一万，没钱又想装备齐全，怎么办？分期付钱。

+   1，房贷五千，搞个老破小。

+   2，车贷二千。

+   3，苹果三件套，每月一千。

+   4，名牌西装（包包）。每月一千。

+   5，装修贷，每月一千。

你的工资不用过手了，就全部归金融公司了。生活费就靠老婆了。这种情况，现在发达国家已经很普遍了。按照00后的尿性，基本也跑不掉。

结论，老婆工资很重要。不能只看脸，也要看看学历。黑胖花也有好处的。

# 02

年入千万是什么感觉？我没体验过，但是见过不少。

一个人年入千万，往往会产生错觉，看什么都觉得便宜。你去超市买个饮料，会不由自主的想把收银员也买回去。

+   一，  人际交往

这个层次了，交往的人都贼牛逼了。省略一百字。直接说屌丝最感兴趣的话题，小美白看到你，两眼直接冒金光，就像看到一大坨金子。这是真的。所以，你不要以为自己不够优秀，你只是不够富裕。等你富裕了，你就是包邮区最亮的崽。
