# 09

为什么走不出贫寒的怪圈？心理素质。

绝大多数父母只满足吃吃饭穿衣报个班，你在学校，在社会上怎么立足，是没人教的，包括怎么考试，怎么赚钱，怎么升职？等你穷忙几十年终于大概明白了，你也没机会了。偶尔有几个人跳出了原来的圈圈，可能仅仅是碰巧蒙对了，还没有把经验保留下来。自己吃光用光，身体健康。老了再唱一场轰轰烈烈的葬头，完犊子了。

人的一生最多会遇到一两个有机会赢的机遇，而你是浑浑噩噩的，根本不知道什么是机会？

一是考试。考试成绩好，能够让你过上中下水平的生活。如果不折腾，不啃娟头，到了五十岁，能够过上副高的美好生活。但是，绝大多数家长根本不知道如何训练一个抓分小能手，眼睁睁的看着娃走向中中专。

二是结婚。一个人是不是幸福？和婚姻有一百万个联系。不要说什么，一个人也挺好，好不了。结婚是动物属性，很难扭过来。找对象有一万个思路，关键一句话，缺啥补啥。缺钱就尽可能找狗大户。缺爱，就找舔狗。缺社会关系，就找有地位。缺颜值，就找好看的。你也不要太贪，能够扭住一个就不错了。

三是买房。这是家族大事。以前搞个房子，还要看黄道吉日。

四是升职。这是很有门道的事情。我当了几年老板才知道，什么样的员工有前途。

五是积累。如果你这辈子没花头了，也不要难过，告诉儿子，坚持下去，一代一代自我奉献，熬几十年肯定有机会。一般都是分母，你争取成为分子。
