# 什么是小聪明？

我们经常听人说，这家伙是小聪明，没什么意思。我以前好奇，小聪明也是聪明啊！长大后，我理解了。

你去麻将室看看就知道了。打麻将的都是聪明人，太笨的，打不好麻将的。妙股同理。我的六婶三太公去一趟超市，能够研究出优惠券的n种组合，利益最大化。但是，这些人往往发不了大财，这就是小聪明。

小聪明就是，在条件确定的情况下，快速计算出利益最优的公式。例如二本子就精通肯德基的优惠券。那么，什么是大聪明？

大聪明是指，在条件不确定的情况下，你可以做出正确的判断。例如要不要买婚房？万一腰折了呢？我的观点是，

在我最大能力的情况下，给娃买好。我不管是不是盈亏的不确定性，我先保证娃有婚房这个确定性。如果出问题，我一个人去挡子弹，老婆可以改嫁，孩子好好过日子。
