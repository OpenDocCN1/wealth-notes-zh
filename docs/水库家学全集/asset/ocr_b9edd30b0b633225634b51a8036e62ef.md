# 悄悄告诉你，什么是"读书开窍了"？

财上海微博 2020-11-29

# 01

如此聪明的我就是赚不到钱。

我是985，从小到大都是尖子生，年级前五。

我研究生毕业进了金光闪闪的大单位，那是过关斩将，很不容易，20:1的录取比例。我熬到了上岸。

每一件事情，我是谨小慎微，察言观色。我每天兢兢业业干好手里的事情，有一时间我就琢磨各个小头头，琢磨同事，熬了十年，也带了个长。

但是，我就是赚不到多少钱。你也知道，大单位工资也就一万多，无论我怎么努力，也不可能五环以内买房了。我今后怎么办？

答：赚钱靠的不是多聪明。我认识的土老板，好多都是初二文化水平，读过高三就是知识分子了。像你这样的人，在各种大单位里，数以万计，没什么大不了的。我说几个赚钱体会。

一是勇于承担风险。你在大单位里，毫无风险，旱涝保收，每个月五号发钱，一分钱不少。上班也很闲，中午可以在躺椅上睡一觉。每个月饭卡还有五百元，可以买几瓶金种子和几条金南京，开心啊。但是，没有风险的生活，就没有多少受益。

二是不要太看重面子。你在大单位，很有面子。回老家，吃席都上主桌。你要是自己出来赚钱，就是无业游民了，走在马路上，看到保安都发怵。

三是心里不要怕。你找个结合你专业的方向，自己出来干，应该有收获。

四是准备好两年的生活费，大概10万元，肯定够了。一开始可能不赚钱。

五是赚钱不要怕辛苦。半夜货车来了，你自己去院子里卸货。没人帮你，所有的熟人都不想搭理你一个小老板了。
