# 8090年代的生意有多好做？

我们家曾经一晚上蹲在电视机前，等着看一个广告。以前买东西是很困难的，特别是一些不常用的工厂产品，例如机器配件。大家可能不知道以前修车是怎么修的？我给你大概说一下。

修车的第一步是判断哪里坏了。找到问题后，买不到配件。怎么办？很简单，自己做。那时候人力不值钱。自己做，有两个办法。

一是旧件重新打磨塑形。

二是用优质钢，自己上机床，模仿做一个出来。我有个亲戚，他自己做了一个剃须刀的手柄架子，和买来的分毫不差。

我家（女方）当时需要一些常用配件，买不到。此时，正好电视台有个广告，某门市部批发xx零件。我们是听别人说的，就一晚上守在电视机前等那个广告，等了三天，终于等到了，激动的热泪盈眶。但是，广告速度太快，电话号码抄错了。

于是连夜写信去问，有没有xx零件。一个星期后回信了：有。我们激动的收拾行李，坐火车去买零件。大家可能无法理解，我们工资几百元的，为什么一个大哥大要一万多。那时候一个手机可以买半套房了。那时候手机是生产工具，不是消费品。

那时候，根本买不到什么好东西。我们小时候最高级的零食是“奶油球”，一种硬糖。这是谁家结婚才能吃到的。一般一包喜糖里，只有一颗，装里面子的。如果一包喜糖过来，几个孩子，只有一颗奶油球，那就要打架了。
