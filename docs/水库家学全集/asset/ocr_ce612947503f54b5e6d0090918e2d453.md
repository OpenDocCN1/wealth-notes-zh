# 03

我热爱考试。

我这么大了年龄了，对考试特别感兴趣，总是在孜孜不倦的研究如何考高分。

去年，我的一个熟人，他儿子初中考出了惊为天人成续，很多高中要他，还有一些学校给出了高额奖学金（我理解为转会费）。我就去找他父母。

他父母是普通农民出身，学历初中，打麻将是他们最大的爱好，有两个孩子，大号练废了，又注册了一个小号，这次练成了。我就问他们，这个孩子平时往家里怎么学习的？

干言万语一句话，刷题。刷多了就成续好了。但是后果很严重，年纪这么小，身体好差，近视眼，驼背，干瘦，严重鼻炎，天天咳嗽，睡眠不足六个小时，而且心态不好，看不得别人超过他。
