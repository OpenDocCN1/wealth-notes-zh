## 如何提高中学成绩？整体战。

市场上，有很多教单科的数学大神，语文大神，物理大神，化学大神等等。我仔细研究过他们的东西，觉得不合适。原因是，

如果按照他们的办法，肯定可以提高单科成绩，但是，占用你的时间太多，相应的其他科目时间就不够了，其他成绩就要下降。累死累活一年，算总分，等于白干了。那怎么办呢？我推荐一个好办法。整体战。

大家有一个事情肯定是忽略的。每章节课本最后的那些小题。这些题能够入选教科书，你就想想，有多重要了。教科书上，每一个字都是千锤百炼的精华。你不要小看了。

1. 把教科书最后的每个小题，仔仔细细练一遍，烂熟于胸。
2. 自己问问自己，为什么要出这个题？题眼在哪里？
3. 买一本历年高考试题分类汇编，你把高考相关的题也攒一遍。
4. 所有科目，一视同仁，时间均分。

你做完以上步骤，如果还有力气，就再撸一遍。我当年把所有高考题，撸了十几遍。每次写，我就能在想，命题组为什么要这么出题？灵感来源在哪里？后来我想通了，灵感基本就是各章节教材最后几个题。
