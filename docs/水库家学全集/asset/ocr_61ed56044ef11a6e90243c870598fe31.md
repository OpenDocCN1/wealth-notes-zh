# 01

培养孩子的独立性。

很多劣质父母把这个事情当做人生甩锅的最佳借口，对孩子的成长不闻不问。一切靠自己，是这些劣质父母最喜欢的口头禅。

很多屌丝，进入社会的时候，两手空空，啥也没有。然后杯具＋餐具了。工作上，一点也没有教育，为人处世，一塌糊涂。经济上，根本不帮忙，没钱没房，两手一摊，活脱脱一个无赖。就这样把孩子扔到了大城市。生死有命，富贵在天，你自己看着办吧！你让一个孩子孤零零的活在物质世界，他能怎么办？这种环境出来的屌丝，就像是食草动物，懦弱无能，性格十分差劲，今后也很难发展。

为人父母，不能这么自私！至少，你要做好两条，

一是考试。你要想尽办法让娃娃考试特别好，至少混个211。985比较难，就算了。top1是文曲星下凡，和你没关系。

二是房子。乌龟还有个祖传的壳。你家好意思把儿子女儿就這樣，光溜溜扔到马路上？

小结，孩子也是肉长得，要爱他。不是嘴巴上忽悠几句，而是掏干货。不要多了，准备200个当做首付。
