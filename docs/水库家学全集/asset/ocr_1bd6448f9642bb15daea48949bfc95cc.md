# 工作重要吗？

如果这个工作不可能让你财务自由，那就不重要。因为你的人生要求，不是一辈子打工，二十年往老破小，你有远大的目标，你要挤入大平层，挤入独栋。

女人的第一份工作很重要。这是你的脸面。以后找对象，人家第一反应就是看你的工作。

男人的最后一份工作很重要。前面的工作，都是刷经验，最后一个工作是真正的去搞钱。老子辛辛苦苦熬到了42岁了，不能再当废柴了，我也要当老板，招聘五个前台，每天给我泡咖啡。

绝大多数工作是不可能让你挤入独栋的。你也不要忧伤，你要做的是刷经验。一个人要想做大事，情商是很重要的。你要在逆境里学会情商。

你工作的目的不是做机器人，每天早上七点开机，晚上十一点关机。
