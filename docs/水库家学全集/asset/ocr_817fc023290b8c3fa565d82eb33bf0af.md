# 03

心碎的感觉。

小王是985，内环线好单位，资深的房空，十年陈。这些年看他的朋友圈，你就会整理出天底下所有的房空基础知识库。

这些年，小王结婚生子，按部就班，今年娃要上岁了。这时候，小王没办法了。因为没房子，上学很麻烦。小王面临两个选择，一是把娃送回湖南老家，二是认怂。这时候，年初的一轮xx，让小王老婆精神崩溃了。因为小王这些年喋喋不休的告诉她，房子快爹了，房子就在眼前了，多一个房间不香吗？事实上，前几年确实变化不大。小王老婆满心欢喜，准备抄个世纪大底。没想到2021年1月份的变化，让她措手不及。

十年前，小王家有600个，现在经过10年理财，扣除房租，已经达到了650，小王觉得自己简直是个金融界的灭霸，在内环线白住十年，还凭空出现了50个w。十年前，小王可以在内环线挑一个江景房子，现在只能去外环线草鸡小区了。

小王那个不甘心啊！最近，小王老婆又来说了，要不要再等几年？看样子，这次要真的爹了。我看了一眼小王全家那要死要活的样子，心碎了。
