# 09

为什么我们没有私人乡村俱乐部？

实际上以前也有，苏州园林就是。西欧的富人不上班，又有一些保姆，需要的房子大，安静，空气好。于是大家就慢慢的搬到乡下了。

乡下最大的问题是无聊。那大家就在一齐打打牌。在哪里打？谁家的房子大就去谁家。慢慢的，牌友需求又多了，能不能抽雪茄，能不能喝咖啡，能不能上厕所？最后，富人家也受不了了。掰那，我又不是你家保姆，还要给你们打扫卫生。

这时候，有个聪明人就说，这样吧，我单独撂个地方，大家随意玩，我收点小钱。一次一收太麻烦，就交个会费吧！一年两千块钱。大家也不差钱。

打打牌，还想玩一会，那就去酒吧蹦迪，肉丝在舞厅就等你喝一杯。就这样，慢慢的，俱乐部，酒吧就出现了。最后成为产业链。

以前，内环线遍布大街小巷的茶馆也是这个意思。后来就没没了。

今后，一线城市的私人小业主聚会是有希望的一个产业。
