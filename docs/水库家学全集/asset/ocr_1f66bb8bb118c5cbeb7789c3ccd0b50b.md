# 为什么有人愿意相信各种千奇百怪的骗局？

财上海微博   2020-03-20

# 01

骗子是怎么活的？

我有个女亲戚，211研究生，经济专业，也被骗了几十万，最后两口子离婚。诈骗过程也很简单。一万变两万，高利息之类的。奇怪的是，经济学研究生也会上当。我和她聊了几句。

这个世界有一批人，自以为本事很大，什么都懂，只不过没有机遇发财。任何荒唐可笑的骗局，抵不过逆袭的诱惑。你仔细想就知道，天底下哪有那么简单的发财办法。

但是，就是有人愿意相信各种千奇百怪的骗局。这不是科普的问题，而是心理学。如果我对任何事情都采取怀疑理性的态度，

“我还没逆袭？马无夜草不肥，只有冒险，才能成功。你说这不能做，那又不能做，那你告诉我，怎么快速发财？你说得不出来了吧？闪开，不要耽误老婆发财！”

这个女亲戚借了公婆四十万，加上自己和老公的三十万，还拉拢了一批熟人，凑起来两百万，又找骗子加了一个点的利息，最后，被骗子一锅端，这个女亲戚众叛亲离，一地鸡毛，天天在家里打架。

她回忆说不后悔，因为我要逆袭。（超级励志）
