# 争取做个幸福的女人。

一是不上班。莱媞虽然也去公司看看，但没有什么打卡，想来就来，想走就走。

二是有陪嫁。莱媞传承了我们包邮区的好传统，陪嫁给够。理论上说，莱媞属于自雇人员，可以不上班，开心过到退休。

三是老公当甜狗。我在家里基本就是个大型活动家具。不敢拍桌子瞪眼睛。

四是娃娃成绩好。

不过，我也有很不满意的方面，莱媞属于暴躁脾气，一言不合就要打架的虎娘们，看在陪嫁的面子上，我暂时不提了。等我把娃的名字改过来，以后有机会再收拾她。

我一直在研究，为什么有人幸福，有人不幸福。说白了，就一个原因，积累。几代人的积累，远远比一个人天赋异禀靠谱。兄弟弟，也是堂堂正正的985，那又怎么样？还不是“无房户”。手机前的中年妇女，你想想看，当年，你们是多鄙视那些没房子的外地大学生？莱媞三代人积攒了不少平方，现在开心了。每一代人都有自己的任务。

曾经有个鸡贼男问我，买房要是跌了怎么办？我给他说了一下我我家的情况。我家在四十年代中期曾经买过一次房子。当时是12根小金条，没过几年，跌了一半。你肯定会说，看着倒霉了吧？事实上，如果你再拉长一点看，就不一样了。有了这个房子，全家人都有户口了，等于在艰苦年代稳稳吃饱穿暖了。再后来，九十年代拆拆了，当时几个子女一人一套小二层。孩子们都上了大学，有个不错的工作。如果你当年留着那12根小金条，到现在有什么意义？

人生不可能每件事都分毫不差，关键是你得看住方向。有人劝我，现在你的那些房子值钱了，为什么不变现享受一把？我就不。我要留给娃，以后他也可以堂堂正正的过日子。我不希望娃娃再重复一遍我的日子。

每一代人都都会遇到诱惑。没事儿去KTV包厢坐坐，大大把把的给小费，里面的人都是人尖，说话又好听，还专门为你打扮打扮，确实很开心，实际上也没多少钱。但是，有急用吗？建议，现在有点钱的家庭，不要想着吃吃喝喝，劲脑袋给娃留点底子。在大城市，一个娃只要走正道，有房子，基本可以娶个漂亮小花，太太平太平一辈子。万一考个功名就发达了。
