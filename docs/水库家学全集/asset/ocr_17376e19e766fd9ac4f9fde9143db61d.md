# **05**

乡间小路上的豪宅。

现在有一种产品，大山深处的豪宅。离开大城市，开车半个小时，到达穷乡僻壤。穷乡僻壤的标志是路边有卖土特产的，例如草莓，芒果，甚至是草药。开着开着，突然出现一个大别墅小区，非常漂亮，不亚于你见过的任何豪宅。价格也很爽，5百万。很多老屌丝就激动了。

市中心的老板小卖了四百五，再找女婿凑一点就拿下了。老红肯定很高兴。老子当了半辈子保安，这辈子也没享过福。以后，我就和老红在这里，安享晚年，再传给孙子孙孙，开心色特了。

这种房子表面看，五证齐全，实际上和村口大别墅基本差不多，没人要的，根本不算资产，就是一堆砖头而已。你仔细想想，有谁会到这种地方居住，你也不过是度假来玩玩。年轻人根本不可能来接手。

屌丝不爱听了，那么有没有其他老头老太接盘？也不会。因为，这种穷乡僻壤的小区实在是太多了。只要有人要，分分钟给你搞出一大堆来。你的旧屋比得过人家新房？

屌丝不开心了，那那，我自住，行不行？还是不行。这种大户型，鸟语花香，你要想住进去，大概是2年装修，投300w。你至少要在工地上住一年。因为来回不方便，你总要监工吧。

屌丝愤怒了。我不住，留给孙子行了吧？孙子说，你让我怎么上班啊？
