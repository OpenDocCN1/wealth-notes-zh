# 给职业经理人发股权行吗？

不行。

绝大多数职业经理人不喜欢那种根本不可能上市的股票，他们更喜欢现金，更喜欢抓一点企业采购的小好处。

我们正常人办公司是不可能上市的。职业经理人也懂。我遇到一个250给企业几个经理分了2%-5%不等的股权，最后，这些家经理天天要查账，天天吵架，把小老板管的头痛欲裂。小企业经营，哪有什么正规啊。

结论，员工只看现金，不要搞什么虚头巴脑的破事。
