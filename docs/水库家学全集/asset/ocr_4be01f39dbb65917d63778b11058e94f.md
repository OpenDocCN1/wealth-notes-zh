# 企业管理是商业最难的事情。

屌丝不知道什么是企业管理，总觉得企业管理是很简单的，实际上不是。举个例子，你做一个饭店，很成功，年入百万，但是你能不能开50个店，年入五千万。不可能的。为什么呢？

企业最大的敌人不是竞争对手，而是你的好兄弟，好伙伴，中层干部。每一个部门经理都是为了钱来你公司打工的。不要扯什么上市之类的破事，咱不感兴趣，年底能不能给我三十万奖金？

中层干部为了自己的蝇头小利，关键时刻，可以彻底牺牲老板和企业。老王和我了一个事情。他们的生产部是按照产量给员工们发钱的，员工们欺上瞒下，联合了所有环节的老乡，把一批有严重质量问题的产品入库了，他们很简单的拿到了人均一万的工资，但是，企业因为这批次品，几乎倒闭，亏损三四百万。老王气的直接昏倒在车间。

聪明的阿凡提肯定会说，我当老板不可能发生找个事去。OK，你去当个老板试试看！
