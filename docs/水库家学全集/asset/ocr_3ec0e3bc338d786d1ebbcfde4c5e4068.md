# 运气总是垂青努力的人

我们老家，近十年逆袭的人不少。大体有两种，

一是985大单位，中规中矩，买房结婚，二十年里不断小换大，加面积，忽如一夜春风来，发了。

二是真的努力拼，从拎灰桶开始。老王是中学毕业。一开始出来也没什么技术，就去工地做杂工。后来一点一学，成为了一个技术比较全面的小队长，现在已经是营业额一两千万的装修公司老板了。

当然，绝大多数没有混出来，躲着小角落里，嗷嗷不倦的酸这些成功者。混出来的有个共同特点，去了大城市。很多人都说，他们都是运气好。如果不是楼市，他们什么也不是。这是酸葡萄心理。这些人是高能分子，不管冲到哪里，都会闯出一片天。

超过40岁的老韭菜，我就不评论了，你的路子也就这样了，老老实实蹲好，不要被新韭菜取缔了。新韭菜一定要努力拼一拼，如果有机会，去更高的平台。不要怕，你也不是什么大富大贵，有什么啊！你再差，有上一条那个毛峰姑娘差？

你最大的问题就是太把自己当回事了。你算哪根葱啊？西开！
