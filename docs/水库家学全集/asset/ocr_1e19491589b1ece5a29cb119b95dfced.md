# 08

重祝民科。

有很多半罐子博士喜欢嘲笑民科，实际上，民科的作用是巨大的，而且非常实用，所有的近代科学，都是靠民科起步的。举个例子，古代炼铁，需要2200°的高温，问题是，你怎么判断温度达到了2200°？傻博士一般会说，你找个温度计测一下不就行了？可古代没有测量2200°的温度计！

那么古人是怎么判断温度的？很简单，看颜色。炉火纯青，就是2200°。怎么样？这个民科厉害吧！这个情况现在普遍都是，很多经济学家吹起来一套一套的。世界格局，尽在掌握。可他自为的一笔吊糟。这就是典型的半罐子。

我曾经问过小个经济学博导。你们不是说，股市是经济的晴雨表吗？那你们炒股吗？几乎没有人炒股。原因是怕亏钱。他们这种货色，就是南郭先生。我曾经遇到过一个包工头，买房神准。我看他也没读过书，也不知道萨缪尔森，我以为他是运气好。后来，我和他吹牛逼问起此事，顿时惊呆了。

他告诉我，他一到晚看招标公告，哪里要修什么，他—清二楚，等于比别人早了两年知道趋势。他不发财就没道理了。

# 09

8090后，有没有机会超过父母？

我们老单位的一些老油条，年龄已经在退休线前后了，子女大部分从事了类似性质的工作。一方面，有一定的人脉基础，另一方面，他们的认知就只有这个，而且从小就这样培养的。例如，要会做人，要察言观色，要和班主任搞好关系，要积极参加单位合唱队，基本如此。

他们的父母，基本上完成了两代人的目标，自己一套，儿子一套。老头老太自己的房，大部分在内环线，2000年～2002年漂亮小区，单价三五千入手的，现在基本是15-20倍了，在单位附近比较方便。儿子那一套，一般是2010年左右，用老房子置换的，五花八门，哪里都有，有大郊区别墅，也有地铁口。毛估估一算，大概在1500-2000个左右，贷款不多，基本低于月供5千。因为买得早，绝大部分已经房贷清零了。
