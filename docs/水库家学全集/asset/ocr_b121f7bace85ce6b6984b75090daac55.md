# 09

30而立。

以前以为，三十岁就是自己过，自己照顾自己。现在，菜菜岁数大了，有了新感觉。人生分为上半场和下半场，分界线是30岁。

30岁之前，各位的生活，大同小异。读书，考学，上班，结婚。条件好一点的买房买车，条件差一点的，就这出租房里干瞪眼，上网骂骂菜菜。真正的区别在下半场。

你仔细想想，你为什么上半场过得不如意？房子小，工资低，老婆也是一言难尽，要不是家里这情况，我能要她？想来想去，其实就一个原因。你家爸妈没给你留条路。

一个人花钱最划算的时期是年轻时候，娶个好女人旺三代，但是我最穷的时期也是年轻时候。这真的是急人啊。你看那个倒插门菜菜，人到中年，再有钱又怎样？那个中年妇女严防死守，又打又骂，这日子没法过了。我们，能不能把中老年人的钱拿到年轻时候花？

你自己不行，这要靠爸妈配合。你爸妈把中老年收入的积攒起来给你，提前给你打个桩，你日子就好了过。这是所有比你过得好的人的人生密码。你已经没希望再换个肤白貌美大长腿，或者嫁个法拉利的高富帅了，能不能从你开始，给娃留条路。认认真真给他攒个小首付。我自己买一套，哪怕是小地方。日积月累，强制储蓄。等娃长大后，亲手就给他。让你的娃过几年好日子！

这就是经营人生。

小老板如何不被技术大工拿走？

很多企业，老板不管技术，只负责对外打拼赚钱。这种企业结构最常见，小老板很容易被大工拿走，欲哭难填，无休无止的索要。好多二本子说，这题我会。再找个大工，做备份。

事实上不是这样的。你要是再找一个大工，一年20-40万，你也不要开公司，利润就归这两个大工了。

二本子又出主意了。找个新手，工资低，慢慢培养。妈卖批，等你培养出来了，他又要加钱了，培养不出来，钱白花。
