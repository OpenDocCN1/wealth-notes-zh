# 发财靠什么？劳动。

先说一个黑色幽默励志故事。某农村保安，三十几岁了，在大学里当小保安，老婆是女民工。小保安发愤图强，老婆省吃俭用帮助他。终于小保安在集体宿舍里自学完成了大学本科，考上了研究生。这个故事到这里还是励志故事。小保安顺利毕业了，

这期间，他老婆一个人养家，养孩子，还要供一个大老爷们读研究生，实在是遭了大罪。但是，女人凭着一股倔强强韧下来了，苦守寒窗十八年，守得云开见月明。小保安，通过这几年的疯狂读书，以优秀成绩拿到了研究生文凭，还得到了各位教授的好评。可惜，小保安毕业后怎么也找不到工作。因为那时候，他已经四十岁了。

折腾了几年，山穷水尽，小保安又回去当保安了。他老婆在集体宿舍里撕的撕心裂肺，她这一辈子白干了。为什么会这样？再看看隔壁村，十六岁就出来贴砖的二狗子，四十岁的时候，已经买房买车当老板了。

人生需要的是踏踏实实劳动，而不是好高骛远。
