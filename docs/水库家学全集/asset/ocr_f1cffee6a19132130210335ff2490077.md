# 02

刚才，有同学问，老公的公司里发了期权股票（绑定工作x年），现在还没有兑现。如果离婚，能不能分一半？

作为例插门，我对这个问题颇为激动，找出很多教授专家，有深入研究，结论是不能分。夫妻共同财产是明确的财产权益，期权股票是不确定利益，甚至能不能能行权也不一定，这就不是共同财产了。

假设你能分一半，这就很荒唐了。你们都离婚了，他还要给你的新配偶继续赚线，确实憋屈，可能这个死男人就会故意辞职了，相当于放弃行权了。总的来说，不利于社会生产生活。

老子现在很憋屈，这个女人居然经常叫我滚。我容易吗？要不是为了今后搭救老红，我肯定跳起来对骂了。who怕who?
