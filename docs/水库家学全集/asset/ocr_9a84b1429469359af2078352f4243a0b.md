# 02

张爱玲的时候，大平层比别墅好。

那时候，内环线都是大瓦房，就像现在的大农村，类似于现在的棚户区劣质别墅。所以，大家对别墅不感兴趣，大家最喜欢的是大平层。四十年代的大土豪，电影明星都喜欢住公寓。

为什么公寓好？很简单，公寓，装修漂亮，设施超级好。有热水，水马桶，自来水，空调，木地板，可以洗澡，有冷气，夏天舒服，有暖气，冬天舒服。门口有各种各样的小吃的，生活方便。

别墅就不同了。一般别墅都是静安寺那种荒郊野外。三四十年代，静安寺附近相当于现在的安灰农村。这是张爱玲张姐的书里说的。静安寺周围啥也没有，去一次外滩像是过节了。别墅的设备太差，往往只有冷水龙头，马桶也不方便。一到冬天，冷的不要不要的，四面八方，到处漏风，别墅太潮湿，冬天受不了。

当然，也有极少数现代化别墅，但微乎其微。以我家的说法，自建一个西欧别墅，大概要七八个大洋，那时候，一个保姆也就每月三个大洋的工资，为什么以前建别墅那么贵？

老人告诉我，老上海是没有水泥厂的，水泥都是进口的，更不要说什么漂亮玻璃了，但凡好一点的东西，都是进口的，以前上海的大户人家流行护墙板，就是因为没有立邦漆，护墙板是浙江产的，便宜啊。现在倒过来了。
