# 03

百年感慨。

我家是37年抗日前几天来的内环线，怪不得我如此热爱抗日剧。算下来，也有八十几年了。我家对比原来的族人，有个小小的体会，在大城市，只要有个住的地方，就不会穷。

我家叔父辈，有四五个子女，一般到了年龄，都有街道分配工作。到了九十年代，陆陆续续下岗了一半，但是，他们也饿不到。

一是民生招工上来了。我有个亲戚就是在浙江人开的小超市里打零工，我靠，居然小店就在小区对面，方便极了，干了几年，他居然热爱上了这个家近事少的工作。与此同时，那个浙江人就比较惨了，一天到晚在小超市里，连个洗澡的地方都没有，他要跑到自行车棚里，找老乡借个洗澡。

二是拆了。老一代人，不管怎么样，都有户口，户口挂在某个房子里，这房子一动，就是一个二居室。以前拆的早，安置房都在内环线以内。时过境迁，下一代拿着五六百万首付，日子也不错。

三是子女上大学了。虽然是个破大学（一工大），但是毕业后，找工作还是很不错的。

说起困难时期，很多地方吃饭都困难，而在大城市，吃饭是不发愁的。我们小时候，八十年代初期就有进口咖啡了，还有果珍，那个大口杯子，老一半的人拿他当茶杯。在胡同口摆卖，一看就是老土地的派头。

最难的是70年代。我还有极其微弱的印象。好像是崇明或者苏浙农民拿着老母鸡，土布，来大城市换一些票，类似于粮票，烟票，糖票之类的。反正那些年，我没饿到过。逢年过节还有一点点糖果。

再后来，浙江麻将风靡一时，大街小巷都是卖麻将牌的。

再后来就是打金戒指。那时候，基本上每个小弄堂里都有一个金匠。

再后来，大家出现了学英语的热潮，外企工资高的令人眼红。

与此同时，老家那些小地主，经过了那些年的那个，基本上已经呵呵了。

当然，大城市也有不好的地方，就是房子困难。如果房子解决了，真是好地方。所以，我家的观念是房读传家。先立命，再发展。好歹有个容身之处。
