# 08

给大家一个建议，装修早点搞完。

现在最年轻的装修工也是80初了。你去新小区，一眼看过去，基本都是四五十岁的老太爷在干装修。现在，工地找不到人了，妇女也上了，一般是给老公打下手，直接包活。例如这一转贴瓷砖多少钱。我叫上媳妇，自己全干了。

上工地的妇女一般是40-50岁左右。干点轻活，外加煮饭。我前不久安装门窗，来了一对北方农村夫妻。老公是主力，女方打下手，拿个东西，递个扳手，两个小时干完，两口子的收入是五百。他们是开了一个丰田的SUV来的。工具就放在车里。他们说，一天干三家，一半的时间在路上开车。

我也找保姆了解了一下，90后，基本没有当农民工的。也就是说，今后，装修的价格会越来越贵了。那么90后在干什么呢？

一是读大学。现在农村读大学已经越来越普遍了。我家保姆中，只要孩子想读的，基本都读了。当然，也不是什么好学校，二本大专为主。

二是考状元。现在这个非常流行。很多孩子就在小县城的三室两厅里蹲着，靠父母供养，他们装模作样考编制。其实就是糊弄糊弄，经常考三五年的，周末就去附近水库钓鱼。

三是去上班。干活是不去的。上班还是可以的。我们小区交房的时候，小区里有几十个小姑娘小伙子，在推销装修。还有些年轻人在办公室，用cad画装修图，挺搞笑的，就是骗骗业主。哪有按照CAD装修的？

这种情况，你身边也差不多。我问过很多装修工，他们的孩子肯定不干装修了。我的意思是，那种需要劳动力的活，早点做完。以后会越来越贵。

我已经把家里全部装修好了。我装修的要求是，材料用好的，能用混凝土的坚决用混凝土。能用地砖的，坚决用地砖。确保30年没问题。以后娃娃就舒服了。

有一次，我做楼梯，有两个方案，一是混凝土大理石，五万，二是木楼梯，一万多。我犹豫了一下，坚决用混凝土，不留麻烦。因为木椅子也就是二十年，然后就嘎吱嘎吱响了。
