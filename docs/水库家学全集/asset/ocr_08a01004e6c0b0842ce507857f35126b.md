我们一共有2.44万所高中，清北每年大概招0.5万个，也就是说，5个高中出一个，考虑到有些重点高中盛产学霸，大概也就是10个高中出一个清北。有时候，一个县也出不了一个清北。所以，很多人一辈子也不认识一个清北毕业的。这基本符合我们的生活经验。

# 一，日常要求按照清北来

一个普通高中，年级前5名基本是985的料子。但是，究竟哪个去清北，哪个去浙大，一般是看运气。日常要求尽可能争取孩子的在年级前几名。

# 二，考场上不要太纠结最后一个大题

很多同学，包括我当年的同学，都有清北的潜力，因为太想考好了，所以千方百计要砸开最后一题。我的建议是，适可而止，只花10分钟。如果你在十分钟内，思如泉涌。你就做下去。如果想了一十分钟，还是一片空白，你就放弃，稳稳当当搞个985算了。有些985还是可以的。
