# 生女儿的父母

一定要舍得下点本钱。

我有个穷亲戚。女儿长相学历条件不错，但是非常穷。他们对自己和对女儿非常抠门。女儿从小到大有什么享受过。

女儿读大学了，去一个展销会打工，大四认识一个屌丝。屌丝是保健品销售业务员，可以报销三万元业务费。屌丝就把钱全部花在这个女孩身上了，吃大餐，买衣服，豪华酒店，飞机头等舱。

女生有一次和亲戚说，她最想买 的是一套水晶项链，一直没钱，心里很难受。男生知道后立即购买 了一套最贵的，六千多。女孩当场激动的眼泪都下来了，晚上就被办了。女孩心甘情愿。她说，这辈子对她最好的就是这个业务员。

女孩觉得臭男人就该这样，最后嫁给了屌丝，现在大别山的泥巴房生孩子，父母气的发疯了。这个女孩的前男友现在是大城市某大单位的小头头了，有房有车，过得很好。他就是因为小气，当年被女生一脚踹了。女生现在也不后悔。女生的意思是，男人有一块钱全给我了，另外一个男人有一百元，只给我一毛钱，你说选谁？

后来，女生家里遇到困难，找前男友借钱三万元，被男方做心拉黑了，一毛钱不借。

我现在遇到生女儿的熟人，都劝他们要舍得给女儿下本钱。一万一天 的五星旅馆几天，买个小宝马，苹果全套，飞机头等舱，两千元的自助餐吃三天。这样的女儿就不会被屌丝送几个海鲜大餐就感动了？
