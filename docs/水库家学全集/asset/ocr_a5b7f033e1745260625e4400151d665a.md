# 学区房到底有没有意义？

财上海微博 2020-05-02

# 01

恢复经济高速发展，就两个因素：外需和内需。工厂生产，总要有人买单啊。订单在哪里？

外需主要就是那几个富裕地方，穷地方没钱。但是，那几个富裕地方现在街上没什么顾客了。

内需的重点主要就是几个领域，医疗教育住房。日常的看电影旅游，不是大头。医疗教育的特点是平稳，不可能大起大落。家庭教育的费一般是相对正常的，不可能翻倍，家长一口气报六个班，孩子也受不了啊。医疗同理，没事也不会去住院。

那么，有些事情就可以研究了。

一是促进大学教育消费。孩子想读大学就让他读，也别挑三拣四了，二本一律改为自考大学，宽进严出，为国抡才。

二是千方百计改善住房。大城市很多人，住房条件不好，帮他一把，让他先住进去。有条件的城市，就送她一套房。条件不够的，就想办法让他有资格买一套，让群众满意。

说的不好，大家多批评。

一是千方百计造楼，供大于求，自然就降价了。大城市一年二十万套就够了。

二是痛下决心压缩货币。没钱了，我看你怎么买？房贷一律暂停，必须全款。

二本子不是不喜欢房子，而是买不起，心里生气啊。怎么办？简单。千方百计造房子啊。外环线敞开了造，卖的掉就卖，卖不掉就送。让二本满意。
