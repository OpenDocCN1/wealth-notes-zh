# 平时不念书，考试第一名。

财上微博   2021-01-10

我要当老板。

这是很多人的愿望，但是落地难。晚上想恨千条路，早上起来走老路。为了节约几块钱的车费，宁愿在车站多等二十分钟。为什么？俺是穷逼一个，时间不值钱，等就等吧。但是，这样下去，你的人生就完揍了，什么时候可以用上小美，什么时候可以用钱砸的家里那个中年妇女闭嘴？没机会了，就这么浑浑噩噩的瞎几把过。

那么怎么才能走出这个怪圈？就是自己做个什么事情，赚他一大把钱。很多人想做事，但是不知道怎么做，做什么？我说下说一个。

一是找到自己的兴趣点。做生意，一开始很赚钱。如果有兴趣，可以撑过这个困难的时期。

二是抄作业。你去看看有相同兴趣的大玩家是怎么做这个生意的。

三是找到新思路。你仔细想想，这个生意，还有没有可以差异化的地方。拷贝不走样是很难赚钱的。你既没有优惠多少，也没有改进多少，绝大多数人不会选择你。

四是自我定位。你找到了痛点。你能不能改进？若可以，all in 梭哈。

有人说，老子最大的爱好是去KTV谈心。我日，兄弟，你有创意。好好干，莫丢铲蛋头。我有个同学，小时候喜欢做飞机轮船模型。因为这事请，成绩不好，经常被他们爸打的哭爹喊娘。后来，他成为我们当中第一个万元户。他居然去开了一个楼盘模型公司，一天到晚给售楼处处，赚的满嘴流油。

其实，这种事情特别多，还有集邮的，玩磁片的，给人画画，拍照的。后来一个一个发达了。我有个同学，上小学的时候，倒卖粘纸，就是花仙子那种。十块钱进一碟，分散卖出去，变成20元。后来，这屌丝居然去当中介了，现在装的人五人六了，比在单位里当床头还开心。
