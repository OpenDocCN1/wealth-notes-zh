# 11
豪宅里的租户。

我原来是大叔辈的老派思想。我总认为，租豪宅是个罕见的事情，现在发现还真不是，挺多的。我们现在已经有经验了，十有八九能够猜出哪家是租房的。

一是窗帘劣质。二是家具马虎。这些东西也挺贵的，如果出租，有点心疼。

三是院落普通。房东出租房子，一般不可能花几十万去装修院子。基本就是防碍木围一圈，意思意思。

四是改装少。例如换个主灯。现在千万级的房子，基本都是装修交付，自己住，多多少少会有点改。出租房基本不改装，本色出租。

五是老外家庭，百分之百是租客。因为，老外不会买房或者买不起这个价位。

我一直好奇，他们为什么要租房？后来发现了几个原因，主要是装潢需要。

你不要看不起外地人，部分外地人也是小土资，过惯了好日子，如果你让他去老破小，简直是痛不欲生了。

我有个附近的邻居，基本就是二傻子，说话没逻辑，喜欢拍胸脯，号称路路通。他在和一个女人谈婚论嫁，就租了个漂亮房子。
