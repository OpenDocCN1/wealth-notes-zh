# 06

实在没想到，我家保姆也在看房了。

保姆收入0.8-1.2是比较普遍的。他老公农耕回家，平时在大城市工地，月入比保姆略高一点点。下一代差些，儿子送外卖，0.8，儿媳妇是老乡镇上来打工的护工，0.8-1。一家四口，月入四万左右，如果再做个几个钟点工，例如接送娃娃上下课，一年50，基本可以。

他们生活费不大，四个人都有地方吃饭。他们一家还是很传统的想法，对租房深恶痛绝，总觉得房租给别人了，就是吃亏了，很不高兴。本来，他们想买一个车，晚上可以跑一跑搞个小钱，现在全家打算给儿子买一个老破小，已经看好了，大概是中环附近220-280左右，月供大概是0.8～1左右，可以承担。

他们打算首付80，已经有了，贷款用儿媳名义，她单位稳定，全家一起还贷款。原来的房子还可以，不装修，也不买家具了，就用旧的，没甲醛，有利于生孩子。十年后，保姆打算回老家，衣锦还乡，房子给儿子。我仔细想了想，觉得差不多。
