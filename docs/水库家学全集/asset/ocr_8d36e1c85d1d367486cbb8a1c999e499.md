这是上海的一句老话。意思是，平时不搭理人，有事了，百般讨好别人是没用的。很多人觉得，你不要这样做，你应该，平时多讨好人，有事情就会有人帮忙了。我相信，你家估计也这么说的。经过几十年的观察，我发现这句话是不对的。说这种话的一般都是老屌丝。希望你把他也当个宝。事实上，

一是你没时间去讨好这么多人。

二是你也不知道怎么去讨好别人。

讨好别人是非常困难的。不信？你去讨好一下老婆试试看。估计一脚踢在钢板上。正确的打打法是，

一要自己强大。为什么我要去讨好别人，因为你不够强大。你没有资源和人交换。总想着我巴结你，你给我一点点好处。你想多了。

二是赌重点。你考试前发现，都复习也没力气了，那怎么办？押题啊！

# 如何搞定富婆（老婆）？

这是俺的心法秘籍，平时舍不得搬出来秀。根据多数二本子的迫切心情，就简单说一下。富婆也是人，关键是要让富婆高兴。

+   一是赞美富婆。赞美的方向大概是聪明能干又漂亮（有气质）。

+   二是天天赞美。不要忽略时间的力量。一开始富婆没感觉，你忽悠她六个月，她就习惯了，一天也离不开了。

+   三是变着花样赞美。不要老一套。要千方百计，就像厨师开饭店，你总不能只出三个菜，天天一样。

+   四是背后也要赞美。当面试是主攻，背后说是伴攻。两手都要抓。

+   五是工资卡不论多少，全部上交。表表心意。当然，如果你年入百万，就不要真的傻乎乎上交了，自己花不香吗？
