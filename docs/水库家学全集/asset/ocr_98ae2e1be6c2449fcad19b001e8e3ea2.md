# 成功男人的特点

+   1，怕老婆。不出去惹事，是一个成功男人最安全的保障。如果三天两头惹事，迟早出问题。

+   2，睡觉睡到自然醒。有钱了，就不那么忙了。

+   3，银行卡上交。没钱了，就不会花大钱，保住了财富。

+   4，生活规律。戒烟戒酒戒嘌呤。

+   5，饮食合理。不要暴饮暴食。

+   6，住得好。家人之间互相打扰是很痛苦的。我家那个娃娃每天早上起床起不来，要大喊大叫才能赖起来。推荐多层别墅。图个清净。

+   7，尽可能和家人一起吃完饭。吃完饭洗洗澡就不好意思出去了。

+   8，赞美老婆。那个女胖子如果不好看了，会很伤心的。你多安慰安慰人。

+   9，对孩子有耐心。不要大喊大叫。

+   10，适当锻炼。我们小区有个屌丝，每天晚上跑十公里，有毛病啊？不建议这种狂犬类行为。

+   11，不买豪车。豪车的唯一作用是约炮免泡，害人害己。何必呢？大城市都是地下车库，没人看你的车，总不能没事去高架兜风吧？

+   13，做任何事要想着让老婆孩子得益。
