# 如果有地摊，你最想买什么？

财上微博博 2020-06-04

01

地摊

若干年前，内环线也有地摊。我常买的是VCD，地摊文学。我的经验是，如你可以分辨质量，地摊确实便宜，光盘五块钱一个，什么软件都有。书本按重量算钱，10元，20元一本。我经常消费几十元，近百元。

地摊经济也是复杂系统，要有喜闻乐见的货源，不是简单的把小店东西搬到街上卖。

热门评论：

头脑中的假象：5年前，大众创业，万众创新。今天，地摊经济学，你神经错乱，与我何干。

精品五花肉司：那时候曹安高架下面好多背小孩的妇女卖碟

雅婷月溪：还有女生的那些化妆品，好用的，随手试买试买回去，后来若干年竟然成为一个较知名的小牌子，哎，也有我的那一份子

即便是围观：消费降级了。

高校那些事：适合卖那种买了也用得上，没几个钱的。例如儿童玩具，袜子毛巾，拖鞋，几块十几块家用小东西

02

地摊经济一直有的，也不稀奇。

平时比较多的，

一是菜市场门口的菜贩子。一个五菱宏光，后备箱一打开就是各种蔬菜水果。

二是晚上出来的三无料理，例如葱油拌面，蛋炒饭，烤串，卤鸡爪。

三是各种黄牛。例如高价回收月饼票，ok卡，购物券，垮个小包包，扯起嗓门，讨价还价。

地摊经济打击的不是大商户，而是其他小商铺。举例，我在小吃店门口，地铁门口，经常看到卖煎饼果子，生意超级好。谁倒霉？不是大公司，而是其他小吃店。你不会因为地摊便宜就多咬两个鸡蛋饼。

大公司根本无所谓地摊经济。我家门口有个蛋糕房，一碗面包十几元，生日蛋糕一百多张，它每天六点下班。门口就被地摊烤串占领了。相安无事很多年。

我有一次去青岛旅游，海边，晚上，一路上都是卖闪烁灯头饰。孩子买了一个，我直接扔了。我担心闪烁灯对孩子眼睛不好。他们不是地摊，而是流动摊贩。围着电线杆子转圈圈。

建议，进一步鼓励合法散户多招聘员工，因地制宜，多种就业形势并存，增加就业。
