# 06

全年经济看夏天。

我们是制造业为主。无论内外贸，重头戏都是年底。外贸是圣诞行情，内贸是春节行情。制造业为了准备这两个重头戏，一般在夏天就要采购原材料，开足马力干了。你去市场上看看原材料行情，招工行情，就明白了。夏天好，冬天就好，一年都好。

由于去年春节消费不太理想，大家都不出门了，导致制造业的库存是客观存在的。去年的特殊点是，生产的时候是按照正常年份估计的，销售的时候，遇到了各种想不到的事情。于是，制造业，销售业，都不会办。小老板看着仓库里的库存，那是一脑门子汗。

当然，也有一些积极的信号，主要是企业借钱方便了。但是，借钱是要还钱的。如果成本利润局解决不了，光借钱方便，不解决实质。有的老板抵押儿子婚房，借钱发工资，是有限的。

我对今年冬季制造业行情的估计是价格战。主要是消化去年的库存，能卖出去多少已经考虑不了那么多了，多卖一块算一块，总比再压一年好。这些库存占用了企业流动资金，小老板还是亚历山大。

建议1：上班族今年尽可能不要考虑辞职。先观望一下。特别是不要裸辞。

建议2，二本创业家们，多关注服务业。轻资产，输得起。一片泥板贴瓷砖，一辆电驴送快递。背个包包做家政。
