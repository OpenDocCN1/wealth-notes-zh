# （针对二本子）新人如何度过大单位的职场前三年？

一个人在大单位要干几十年，但你的职业生涯基本在前三年就决定了。你的前三年的打分，会影响你后十年。每一个大单位都有人专门盯着这些新人，你不要以为自己没人关注。十几年下来，如果没有突发意外，你是啥货色基本就定型了。怎么安全度过前三年？我给你几个办法。

第一年不要评论。年轻人最容易得罪人的是那张破嘴。偶尔业务疏忽了，大家能理解，新来的，下次注意。但是人际关系没有下一次。大学毕业进了单位，看一切都新鲜，几个好朋友聚在一起，叽叽喳喳，喜欢评论一下。你千万不要参与。很多人会把你说的话传出去的。特别是传到当事人耳朵里，你就算结梁子了。人家是老人，背后有什么弯弯绕绕，你是不知道的，别人要整你，那是轻轻松松给你挖个坑。

第二年不要炫耀。单位里有很多老员工，业务知识已经陈旧了，比不上你了，或者你在同龄人中，有几个比较强的指标，这时候，绝大多数人都想显摆一下，炫耀一下，期望得到副总的注意，抓紧上台阶。你千万不要干蠢事。你的每一次炫耀，都是和同事过不去，显得他们很愚蠢。你总有不到位的方面，人家会对你下狠手。

第三年不要伸手。干了两三年了，单位里开始发些小好处理。每个人都想得分，特别是一些难得一见的好处理，例如去总公司锻炼，去哈佛混两年，评个优之类的。有些人觉得自己干得辛苦，该有份，上面不给，我就想伸手要，这是不行的。因为一个单位里，好事情就那么一点点（以前还有分房），给谁不给谁，副总心里早就想好了，你更没用，最多安慰你几句，但是，你一要，大家就尴尬了。你这么多年来辛苦，就算泡汤了，“哦，这家伙就是想得好处！人品不行。”

小结，混大单位来日方长，先做事，少整事，等有一定基础了，再发展，不要张牙舞爪，没用。

# 结婚买房是怎么流行开的？

以我的经验，结婚买房已经遍布大江南北，从遥远的边陲到美丽的山脚下，一样一样的。以我的认识体验回顾一下这个历史进城。

我们读书的时候，不流行买房，而是比谁的单位发房子。一般情况，越是好单位，发房子越多。教科文卫系统因为人太多，普通人基本不分房。大厂效益好，一般职工基本是熬到五十岁，才可能分个几平米的亭子间。

外地人不知道什么是亭子间。内环线以前有很多老洋房，一户建，后来变成72家房客。一楼二楼转角的的地方有个空间，原来是放点杂物或者保姆住的，后来装个门就是一个房间了。这个地方，由于靠近通道，隔音也不好，楼板下面是厨房，油烟味大，居住体验较差。

后来，流行商品房。一开始商品房很便宜，又有贷款支持，那几年，很多人理论上买得起房子。但是，那时候人的想法比较保守，一是新建房比较远，上下班不方便，二是借这么大的钱（相当于五年工资总和），一般家庭不敢借。

这时候，金光闪闪的文母娘华丽登场了。丈母娘疼女儿，生怕女儿吃苦，拍桌子瞪眼睛，倒逼公婆出钱买房。也有一些知识分子丈母娘，喜欢“有情人水饱”，不好意思颠倒道，现在这些女儿通通倒霉了。当年被丈母娘逼得走投无路的男方，现在一个喜笑颜开了，要感谢满脸横肉的丈母娘。那时候不流行加名字。后来，形成了一个习惯，新人结婚前，新娘子一般要带同事去着看新房。至此，这个习惯保留下来了。

# 当老板有多少风险？

我曾经和一个土老板聊聊天。我问他，30年前，和你一起做生意的人，现在还有几个在做？答案是，除了他，为零。

那个土老板和我家曾经是一个行业的。我对二十年前这个行业有多繁荣，印象深刻。那是一条五百米左右的小街，靠近长途汽车站，主街和小胡同上有无数个小门面，每个门面里有个小老板，每个小老板背后有个小工厂。这就是典型的“前店后厂”模式。一般情况下，每条街只做一种生意。五金一条街，装修一条街，电机一条街，灯具一条街，美食一条街，服装一条街。每天热热闹闹，车水马龙。那时候，蹬三轮车也有钱赚。

优胜劣汰，经过三十年的大浪淘沙，绝大多数土老板已经消失在茫茫人海中了。我有时候回想起二十年前遇到过的一些印象特别深刻的土老板，现在也不知所踪了。有的盆盆洗手，有的是老了退休，更多的是不赚钱散伙了。与此同时，剩下的土老板做大做强，又聚到一个新的地方了。老朋友走了，新朋友来了。但愿你属于幸运儿。

# 意外中奖。

我堂弟，经过我推荐，去年在远郊区买了个精装修的婚房，大户型，四室三卫二厅，600万左右。打算自住，后来因为上班远，就搬了。原来的市场价租金应该是5千左右。没想到，今年意外中奖。原来，附近有个著名的民办校，今年营业了，很多外地家长为了方便孩子读书，就近租房子。业主亲戚里有些刚退休的老头老太就开了辅导班，晚托班，作业班，接送服务。还有一些员工，急吼吼在买附近的二手房。租金飙升到1.2万，还是三年以上的长期合同。

堂弟原来还发愁月供压力大，没想到金元宝掉地上了。我说这个的意思是，如果考虑租金，著名学校附近（偏大户型），批发市场附近（一楼为主），三甲附近（偏小户型），是不错的。总而言之一句话，人流秘集的地方，包括著名软件园附近，都是不错的。
