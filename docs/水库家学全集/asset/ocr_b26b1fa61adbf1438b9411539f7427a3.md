# 考985的三个点。

财上海微博 2020-09-23

# 01

儿子应该回老家吗？

菜菜，我们是双外家庭，两口子都是外地户口，儿子也是你老乡。现在遇到一个现实问题。儿子读小学二年级了，要不要现在回老家？

我们老家是在南京隔壁的小县城，距离浦口很近，双方家庭就是最普通的双职工。我老公985，我是二本。现在中环线买房了，650万，漂亮小区，全家倍有面。现在，我们两口子年入38万到手。小娃娃从出租房搬到这么漂亮的小区，激动的不行，一天到晚饭很幸福，希望多住几年。我也喜欢这里。

因为两地的课程不完全一样，理论上早回去更好。如果小娃娃现在回去，至少我就要辞职回老家。小孩子这么多年没有父母盯着，学习成绩就难办了。但我现在年入9万，基本包下了全家生活费。如果没有我的收入，房贷就扛不住了。

老公的意思是，房子卖掉，有毛利一百万，一起回老家，找不到工作就开个小超市，一家人和和美美。这样做，我这么多年辛苦就白费了。如果不回去，就要拖六年，等孩子初二回。另外，我老公收入接近30万，我怕分居四年（初三+高中），有人要挖我墙脚，现在已经有苗头了，是一个本地女，原来也是郊区农村的，没我漂亮，就是年轻一些。到时候，那就彻底完了。怎么办？

答：你还有六年时间回旋。我的建议是，继续留下，多攒六年钱。理由，

+   一是，六年后房贷余额减少了很多。

+   二是，六年后总价估计增加不少。你心里有底了。就卖卖房也更划算。

+   三是，六年后出租的租金收入也会提高，直接减轻了你的压力。

+   四是，孩子在这里开心，就多得几年，给孩子一个美好的回忆。

你的主要诉求是保住房子。

一来不要出现离婚卖房的情况。二是给孩子留个家底。至于娃娃考什么大学，今后不一定重要了。有房子还担心没有儿媳妇吗？怕个锤子！
