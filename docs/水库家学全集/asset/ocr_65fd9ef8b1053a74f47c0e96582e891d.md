# 怎么学好中学英语？

英语有两个拍法，一是实战型，二是考试型。实战型比较简单，英语九百句，滚瓜烂熟，基本差不多够环游世界了。难的是考试型。考试专门挑你容易犯糊涂的地方。upfilon，怎么选择题？你可能觉得自己能够理解，但又有点含含糊糊。

实际上英语考140分是最容易达到的，英语满分要加个小作文，也不是很难。中学英语如何快速提分？很简单。

你把老师发的卷子，装订成册，错题背一遍，工工整整记在一个错题本上（家长不要代劳），每次考试前就错题本做两遍，你肯定140分。现在售楼处排队要58分。
