# 03

不要去劝人。

前年有个女工程师要辞职，劝她不要去，因为这两年行情不好。那个女的理解是，你的厂子离不开我，你说行情不好是吓唬我，是希望我留下给你干，那你就加工资吧，加50%，我简直是目瞪口呆，只好同意辞职。今年听说，那个女人把老公送的30万彩礼，一套婚房，娘家50万（她弟弟的婚房首付），全部变成了仓库里的机器和原材料，还有一群设备供应商追债要揍她，十几个农民拿不到年终奖和工资，要打她。

希望她振奋精神，及早还清债务，努力建设好小家。

# 04

我这些年做了一件蠢事，给大家笑话一下。

我把员工保护的太好了，结果员工长期在非常平稳的环境中上班，他们这么多年下来，以为做生意办企业是很简单的事情，一个个跃跃欲试，几个会计个个都想开企业当老板。

实际上，我这些年遇到的糟心事！实在太多了，而且根本解决不了。举例，你发出去一百万原材料委托加工，对方老板过两天欠高利贷跑路了，我的一百万原材料被对方厂里的农民工扣住了要工资，否则不还你。找谁都没用。结果，我等于再次把原材料买回来，气的心里忄流（liu）血。

明明签好合同的，农民不把合同当回事，就是一个劲的耍惨，我能怎么办？

招工多了，发不起工资，招工少了，做不出货。现在招工等于是请大仙，请神容易送神难。他攀高枝了，立马辞职，还要立马走人，你给他结清工资。否则，在厂里大吵大闹，其他人围着看热闹。他不管你是不是受得了。

我有个员工辞职前卡着手里的资料不还给我，非要我一个小时内结清工资，他下午要去新公司上班。我是和客户签了合同的，拖不起，一点办法也没有，认怂了。

我的好心好意，这些大大小小的破事，我一个人扛，眼泪止不住的流，但是，我从来不和员工说，怕他们操心。他们以为我一天到晚无所事事，创业很简单，就是胆子大，看好了就干。

若生活重来一次，我肯定不当老板。
