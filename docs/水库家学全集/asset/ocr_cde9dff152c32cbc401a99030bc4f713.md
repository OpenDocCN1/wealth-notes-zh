# 普通人如何抓个小风口？

你不用去看那种几百亿美金的大风口，这和你没关系。你拿不出几个亿去砸投入。现在，你要想研发出一个旷世芯片，基本不现实了，哪怕你有一个绝妙的互联网生意，你也付不起几个亿的流量设备费。

我建议大家去看清一两百万的小风口，就是新应用。我觉得李家奇是一个值得研究的好项目。李家奇没有名气，也不是电影明星，就靠一个卖货的新应用，就扬名立万了。成功有很多的经验。

一是后台扶持你。任何一个新应用推广初期，后台都会大力扶持你，尽快形成一两个典型，吸引大家跟风。

二是抓住新机遇。如果这个新东西是大多数消费者想要的，你就可以认真考虑一下了。

三是自己动脑筋。新的东西出来，不仅仅是你一个人看到了机会，与此同时，至少有几百个人看到了。你如何在几百人中脱颖而出，就看你是不是人才了？放心，二本都是人才，说话又好听。

四是不怕丢面子。你都混成泡面味了，面子不值钱，还有什么丢不丢的问题。我记得有个著名的女腿模，实际上是个瘦男人，一天到晚展现他美丽的小腿。人家做好了，就是为社会做贡献了。

五是保留一颗少女心。大千世界，每天都在变化，所有的新风口都是在变化中产生的。你不要以老冬瓜的心态看待新事物，不要以为自己什么都懂了，要时时刻刻保持好奇心，你就会发现一两百万的小风口。

人的职业生涯有四十年，只要揪住一个小风口就够了。

# 土豪的标准是什么？360万现金。

这个现金是可以自由支配的，不是你刚刚卖掉房子的钱。卖房款是有专门用途的，不能随便花。绝大多数老板，包括一些所谓的大中型老板，不一定有360万存款。

一年有60万存款的家庭已经是凤毛麟角了。现在，场面上混的宝马路虎，可能口袋里拿不出十万零花钱。去个KTV都舍不得和女经理谈淡心。这是绝大多数老板的真实情况。

我有一个开路虎的旁友，一天到晚吹几十亿的风口生意。前不久搞笑话了。漂亮的女经理找他赞助一百万买房，他死活不给，女经理逼急了，要和他结婚，结果是他立马回去和大离离婚，房子归儿子，光溜溜的来了，女经理一看他这副样子，吓得落荒而逃，惹不起惹不起。
