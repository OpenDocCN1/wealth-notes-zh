# **国家发改委：中国经济将在二季度恢复正常**

原标题：国家发改委：中国经济将在二季度恢复正常

一些行业企业特别是新业态、新模式和新产品出现了逆势成长。

新京报讯（记者 姜慧梓）3月17日，国家发改委举行例行新闻发布会。国家发改委综合司副司长李慧回应疫情对中国经济增长的影响时表示，我国经济运行必将回归常态，中国经济将在二季度恢复正常。

李慧表示，从目前情况来看，疫情确实对我国经济运行带来了明显影响，供需两端均受到了较大冲击，一些行业企业特别是中小微企业生产经营面临很多困难，前两个月主要经济数据都出现了明显回落。

> “但同时我们也应该看到，疫情的冲击是暂时性的、阶段性的，随着疫情防控的成效日渐显现，一系列已经出台的阶段性应急政策措施逐步落地，特别是后续我们还将适时推动出台一系列对冲政策，企业活力和市场潜力将进一步激发，我国经济运行必将回归常态。”李慧说。

具体来看，民生方面，近两个月来，全国人民生活必需品、医疗物资、电气水热等基本供应都得到有效力的保障，食品、药品、基础工业品、基本公共服务等关系国计民生的重点行业有序运转，经济社会大局保持稳定。这表明我们在保障民生上经受住了一次大考。
