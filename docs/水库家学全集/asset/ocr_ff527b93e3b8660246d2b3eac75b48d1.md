# 01

说一个老baby大叔的故事。

几年前的一个晚上，大概七八点，我陪客户去东方明珠玩。出来后，找不到出租车，又到正大广场转转。在商场门口，遇到两个五十岁左右的大叔，貌似和两个妹纸相亲。他们一直走在我的边上，等红绿灯的时候，我也就留意了一下。

甲叔明显是金主爸爸，个子不高，浑身名牌，穿了一双潮鞋，这个我印象特别深刻。因为这种花里胡哨的鞋子，我一直以为只有中学娃娃才会买，标志性的是藏了一个帆布短吉黑帽子。乙叔应该是陪衬的，神态表情明显是跟班的。

两个妹纸是北方农村姑娘，大概25-22岁左右，高个健硕，皮肤有点黑，脸上还有几个青春痘，和漂亮没有一分钱关系，但也不算丑，比较明显的村花气质。听口音感觉，甲女估计是在本地待过几年的，看上去像是带乙女出来见见世面。

我观察的比较严重，是因为他们发生了几句争执。乙女是新来的，以为有金主爸爸买单，就乱要礼物，可能是要一个苹果手机。当时五千多吧。金主爸爸没有买，乙女有点不高兴，路上板个脸。金主爸爸一看冷场了，也有点不高兴，于是两个人就争了几句。金主爸爸的大概意思是，哪有看到什么要什么的？乙女的意思是，也不是多大的事情，你怎么就这小气？

乙叔和甲女，就两边劝劝。后来我和他们走散了。我对这件事情印象深刻。两个妹纸看上去不像是富裕家庭，更像是农村比较差的家庭，虽然也涂脂抹粉了，但是气质还是看的出来。她们和我在菜市场买菜遇到的小妹，感觉差不多。理性的分析，她刚刚从北方农村来到大城市，普通话也说不好（明显的靠山屯口音），一无技术二无学历，还能怎么办？

一是去餐饮店打工，二是找个有实力的男票。显然，他们选择了后者。但是，这条路也不是那么好走的。人家金主爸爸是图个高兴，你以为出来认识一下，就可以随便买最贵的手机了？这也太靠谱了。以我的感觉，金主可能有点生气，这次相亲失败了。

小结，找男票，是要看条件，但也不能吃相太难看，要循序渐进。
