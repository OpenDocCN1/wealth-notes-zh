# 11

给没毕业的大学生几个建议。

+   1，戒烟戒酒戒烟。很多人可能对喝酒不以为然。你坚决不要喝酒。我以前喜欢喝酒，喝到四肢麻木的程度。我以前不上班，又无聊，是早上起来就喝，喝到凌晨，一杯又一杯。一开始喝啤酒，太贵了，就变成了喝二锅头。

后来戒酒了。戒酒特别痛苦，一般人根本戒不掉。

+   2，适当锻炼。年龄大了，容易发胖，发胖对身体伤害很大。

+   3，在大学里学好基础知识。你工作的前十年，一般是醉心于考职称，无所谓基础理论。到了中年，你会发现，很多事情又兜回到理论了。一般不要在大学里去想赚钱的事。读书就是读书。好好读书。

+   4，保持良好的人品。不要出现负面新闻。你在大学里的口碑，可能会伴隨你一辈子。

+   5，尽快挖金矿。大学里，拆迁妹特别多，而且好上手，尽快捞一个。毕业就没机会了。你要想想，你家爹妈在地里刨食，在工地敲钉子，都不容易，还是幸父母姐比较划算。

+   6，工作后不要乱花钱。尽可能买个小房子，两手准备。丈母娘现在也不好糊弄了，舔精。

# 12

学好基础知识的意义。

举例，你是五道口技术学校毕业的。如果你去银行当一个信贷经理，基础理论体系，完全没有意义，你把业务手册背熟就行了，多拉单子，多和客户聊聊天。但是，如果你要想成为银行家，基础知识就非常重要了。基础理论体系的主要作用是，预测和应对。

当发生各种情况的时候，现在的办法不行了，就要用新的办法。那么，你就会想新的办法会是什么呢，大家无非是从基础知识里找点灵感。你往往是两个可能性，一是自己摸刀，如果你有这个机会。二是你在家里预测，那几个老同学会出什么办法。

如果你熟练掌握和理解了基础知识体系，你就很容易猜到，大家是人都聪明不到哪里去。人生不需要太多的运气，一次加零，就够了。
