# 女人，第一份工作，一定要认认真真找个靠谱的。

财上海微博 2020-04-20

# 01

有个女同学，十几年前985毕业，有两个工作机会。

一是按部就班当翻译。二是做电商。

她的学历是应该做翻译，或者大专二本的在职老师。结果，她梦想一夜暴富，又遇到了一个不靠谱的狐朋狗友，结果去做了电商。这一步走错了，导致了两个恶果。

首先是找对象难。她做小生意，一天到晚不出门，遇不到合适的对象。托人介绍，一听说是做电商的女人，正经男生接受不了。最后嫁了个屌丝。一辈子倒霉。

其次是收入不稳定，又带来了两个麻烦，一是不敢买房，二是无法贷款。这个女同学，一开始年轻气盛，觉得房子不重要，最后，输得一塌糊涂。

电商干了一年，一直混不好，又去找工作，这时候已经三十几岁了，找了个小公司混混，现在失业了。

工作失败，带来了巨大恶果。婆婆很不开心。婆婆对这个媳妇严防死守，生怕她祸害了儿子的财产。这么多年就是资助儿子媳妇买房，现在完了。

总结：女人的第一工作是给别人看的，特别是给男方家长看的。所以，要认真认真找个靠谱的工作。最好是旱涝保收，有编制的单位。

备注：这个女同学，由于长期的焦虑，年轻时候还可以的容貌已经不存在了。现在倍受男方歧视。老公的工资卡也不给她看。
