# 股票退市的影响。

世界各地，股票退市的事情，经常发生。这个情况的影响有哪些？

一是大股东的钱没了。举例，你在电脑里买了一些股票，你可以随时变成钱，如果不巧退市了，这些股票，就真的变成股票了。

二是借钱能力。流通股股票可以抵押，你要借一百亿，抵押150亿的股票就行了。如果这些股票一文不值了，你有两个选择，要么立马还钱，要么重新找个靠谱的抵押物。事实上，一个也做不到，那就麻烦了。
