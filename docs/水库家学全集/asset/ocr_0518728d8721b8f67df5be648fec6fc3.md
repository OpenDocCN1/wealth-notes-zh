# 高考大小年是什么意思？

大小年是一种经验认识。按照每一科考卷，不同情况，区分判断。小年的意思是，这一年难题多，普遍考分低。大年 是，难题少，大家平均分高。这个事情是有实际意义的，所以这么多人在研究。意义在于：答题策略。

如果上一年普遍分数高，这一年就是难题年，那么，最后一题你就不要看了。如果上一年考分低，这一年估计是难题 少，建议最后一题看一下，争取扒个2分下来。全扒下来是不可能的，捞一把就走吧！就当是摸奖，万一哪个不长眼的阅卷 员丝给你几分，岂不是哈哈了？你不要当我命题组是吃素的？

另外，阅卷老师也不是大家想象中的高级教师，有时候就是大学里的研究生。
