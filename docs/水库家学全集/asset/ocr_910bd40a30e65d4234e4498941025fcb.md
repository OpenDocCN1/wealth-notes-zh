# 贫穷会不会遗传？

以我对周围同学邻居和亲戚朋友二十年的观察，大概率会的，除非遇到八九十年代那种经济大转型。我们那一代人靠读大学（985以上）去京沪当个老师，办户口，攒工资，买婚房，改变命运的很多，主要原因是那时候京沪房价低，你家又拿的出首付。现在985遇到京沪老破小，也是一脸茫然。

贫穷的代际流传，主要是思维问题，太鸡贼了，往往错失机会。我说个真实的故事。

某大单位原址，当时分配房子，给他中环线三房两厅（后勤科没有小面积了），他不要，理由是上班不方便，当时确实上班不方便，真实原因是不划算。当时发房子只看面积，不看地段。他希望下次有内环线的，最好是黄浦区。后来，分子房子停了，他越想越气，直到2016年在外环线买了一套中户型，人生完美失败，儿子倒霉。

我就是个相反的情况。当时，倒蛮门是个被人嘲笑的事情，但是我不动声色，坚持爱情。据某媛说，如果早知道房子这么值钱，就不该嫁我，你说她是不是要翻天了？

何以解忧，唯有打老婆。
