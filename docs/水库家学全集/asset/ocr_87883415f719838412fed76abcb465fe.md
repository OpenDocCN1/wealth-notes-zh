# 02

京沪的户口，房子和工作。

大致看了一下刚才的同学提问，基本最关心的是这几个。

一是户口。没什么办法，一般是两个途径，人才积分或结婚。

二是房子。买房是五年社保。雷打不动。

三是工作。京沪找工作相对容易，但是留下来不容易。主要是房子贵，小孩读书麻烦。

四是上学。如果没有户口，初二就要回了。

五是不要相信歪门邪道，所有的歪门邪道都是针对你的一个痛点，然后告诉你，只要出多少钱就行了。事实上，在大的方面，这是不可能的。这方面，大城市有比较严格的核对程序，不要鸡飞蛋打。

我提供一个新思路，职称路线。你在老家踏踏实实操把副高正高摘出来，然后通过人才引进的渠道，合理合法解决问题。这种渠道，也不一定是天天有，你多注意看报纸新闻，每隔几年总有一些机会。当然，在小地方搞出副高正高，年纪已经四五十岁了，生活状态已经很舒服了，基本上没人会背井离乡出来。

2014年，我有个同学，三十多岁拿了个洋博士，回小地方搞了个副高。上海有个郊区单位要他，工作，职称，户口，人才房都解决。后来，他考虑很久放弃了。

一是自已。他在小地方已经很舒服了，不想再来一遍创业了。而且，他在小地方已经是有点面子的头头了，十里八乡都认识。过来的话，就是从零开始，心态也难以调整。

二是老婆，当年，他老婆工作很好，如果过来，相当于老婆放弃事业了。
