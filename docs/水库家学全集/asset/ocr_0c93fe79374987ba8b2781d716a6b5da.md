# 05

# 二十年的筹码。

1999到现在已经22年了，那是飞奔狂飙的二十年。但是，有几个人拿住了二十年？不多。很多人仅仅是没地方往，被迫持有。但凡有一点选择的，很少很少熬得住。我碰巧拿足二十年。

1999年是个魔幻的一年。我至今印象深刻。年前的一天，我们单位搞了个小超市。把我们一群小屌丝叫过去开会。单位把珍藏多年的福利房一次性全部拿出来了，用一根塑料绳拉起来，就像是元宵节猜灯谜一样，让我们自己挑一个。看上了哪个房子，就把帖子撕下来，交给后勤科。这房子就归你了。我们一个个排队去挑。那一刻，我感受到了分田地快乐。现在回想起来，那不是薄薄的一张纸啊，就是一麻袋现金啊！

我事先看上了一个内环线的三层，那是原来单位副总的，可惜被排在我前面的一个女生选走了。我气的咬牙切齿，没办法。那时候我急的惊慌失措，眼泪也逼不住的流下来了。他娘的，老子这辈子恨上你了。没有选到合适的，单位也很人性化的给了三万现金补助。

有了这些小小的补助，我就自己去买房了，当时买了两套，一大一小连户。那时候房子面积小，也不贵，我印象中内环线是三四千左右，只要是正常单位人，都有条件。然后，我就开始了新的人生。

2004年是个关键的年份。因为那一年，市场上所有的人都谁说，已经10个涨停板了，肯定到顶了，赶紧跑。很多专家也这么说，特别是我熟悉的一个好朋友，是管这事情的。他也慌了，10个涨停板不走，你有病啊？我也慌了。但是因为刚刚刷装修的，舍不得卖，就自己留着了。

斗转星移，二十年过去了。我曾经问过那些好朋友，你们拿住了吗？没有一个拿住的，一般在三倍左右就走了，可惜。当年看上去傻乎乎的接盘侠，现在肯定发大了。
