# 成功男人的特点

财上哈微博 2020-10-24

# 01

和大城市丈母娘谈人生

今后，大城市女儿找对象越来越难了，这是肯定的。大城市集中了绝大多数高校和资源。各地年轻人通过读大学纷纷汇聚到大城市。毕业后，大部分男生走了，没房子，赶紧回家找村花。女生愿意留下来碰运气。这时候，大城市女生越来越多了。

男生能够留在一线城市的（屌丝不算公的了），一般都是高学历，家底有房子的。女生在找对象的时候就会遇到一个比较明显的问题。人家985，三甲男，凭什么要你家女儿？如果当时没房子没底子的，娶个县城小美白不爽吗？

我在大单位遇到过很多金凤凰，直接找了当地小肥圆，一拆五六套的那种，丈母娘还要带娃，苦的不要不要的。如果你家女儿不是才貌双全，怎么办？

一是靠丈母娘出钱。大城市三居室，七八十万，老丈人贡献个五百万差不多了，剩下的，男方出个五十万。

二是降低要求。也不要找什么985了，凑合一个职校开唇师也不错，以后请客有人干活了。

三是丈母娘要厉行节约，剩饭剩菜不要倒了，明天热一热继续吃。什么乱七八糟的包包，一律不能买，留着给女婿买房。

丈母娘要对自己严格要求，如果老丈人不幸加班到了，把财产都留好，别出去跳什么舞，坚决不能便宜老龙王了。

# 02

疯狂压价系列

菜菜，我女儿是二本大四，22岁，漂亮，校舞蹈队的主力，陪嫁内环线一个老破小（大概320万），以后可以卖掉凑首付。最近，亲家给介绍了一个二甲的外地男生（和你老乡），初级职称，刚刚工作两年。你说合适不合适？

答：人家男生明显吃亏了。在我们老家，这种男生就是咱们乡里百年不遇的金凤凰，你们这种小门小户怎么配得上？你家女儿没钱没学历，以后做家务也不行，辅导孩子也不行，现在漂亮，没几年就成老菜皮了。我的意思是，你再加点，例如把你的三居室给女儿陪嫁，你去住老破小。另外，你们两口子也要努力一把，不要以为嫁出去就好了，以后还要带娃，做家务。你会不会拼音和牛津英语？抓紧学一点，以后带娃用的上。
