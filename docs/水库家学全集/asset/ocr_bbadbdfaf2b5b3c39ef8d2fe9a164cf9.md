# 马云的高考之路。

马考了三次，82-84年。最后考上了本科，二本子。毕业后留校当了大学老师。现在的人不知道84年考上大学本科是什么概念，如果按比例看，基本相当于考上了中科大博士的水平。你现在去当个杭州的大学老师试试看？没有博士，你都想都不用想。

很多人觉得，二本没什么了不起的，你去问问你爸妈，他们当年为什么没有在大城市当大学老师就知道了。更加神奇的是，马的英语成绩特别好。当年英语好，是个非常非常了不起的事情，大致相当于现在的超级码农，就那么吃香。以前没有便携式录音机。学英语都是一大早起来在厕所水房门口里背书，要把一本书背的滚瓜烂熟。我当年考六级，没有什么复习资料，只能是听英语广播。

在如此艰难的情况下，马居然当上了翻译，实在是匪夷所思。说这个事情的原因是告诉二本子，不要小看富人，人家也是一步一步走过来的。你现在啥情况？能不能当翻译？我呸。

小结，成功，先要把手上的事情做好。侬房子买好了伐？
