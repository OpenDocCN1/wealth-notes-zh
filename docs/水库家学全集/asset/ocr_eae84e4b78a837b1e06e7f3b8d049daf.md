# 世界上有爱情吗？

年轻时候，我自认为获得了爱情。菜嫂属于白富美，高端大气上档次，低调奢华有内涵。时间久了，爱情渐渐消失了，只剩下柴米油盐。昨天我又和菜嫂打了一架，因为菜嫂忘记给我买奶油蛋糕了。现在，这个中年妇女只认钱。为什么爱情消失了？

# 一，爱情是奢侈品

出租房里没有爱情。我是住过出租房的。那个痛苦，至今胆战心惊，厕所浴室永远是臭烘烘，脏兮兮的。前两天天吃剩下的菜，在冰箱里可以放一个星期。mmp，我当年还合租过，惨的一笔吊糟。在出租房里，所有的爱情都缺乏安全感。你正在谈情说爱，室友说，“房东今天来了。”

# 二，美好的回忆是钱堆出来的

两个人一起去看油画展，是挤地铁还是开宾利去？你说吧？有一次，我和打车去的，在看油画的时候，我一直在心疼打车费，120元（市区堵车），一想到回去还要这么多钱，我就焦虑不安。有一次，我遇到一个年轻妇女，我好不容易鼓起勇气靠上去看看，一眼就看到了人家的爱马士，顿时天旋地转，惹不起，惹不起。

# 三，屏丝都是玻璃心

有一次，菜嫂说，那阴阴的别墅不错，要不要去看看。我觉得她在打我脸，明知道我买不起，你几个意思？是不是又看我笑话？莫欺少年穷，老了还是穷！

每次吵架，我都是卢瑟，菜嫂的名言是‘房子孩子归我，你可以走了’。艿那，我这把年纪了，还能去哪啊？我也迷茫了。

依房子买好了伐？
