# 01

居然还有人租别墅过日子。

按照正常思维，不可能有人去租赁别墅，即使租，也是过度一下。但是，我真的在小区里发现了两家租赁户。最新研究发现，他们不傻，都是来找客户，拉单子的。

别墅区有个特点，邻居们互相不太警惕。大家住一块，经济实力，社会地位相似，大差不差，不至于出现很low的事情。而且，富人对其他富人也充满好奇，愿意打交道，顺带参观一下你家的豪华装修，新式装备。

我们小区有个特点，黄昏时候，很多小娃娃都要在中心花园滑滑梯下面集合，互相大闹一番。宝妈们就成群结队坐在附近的凳子上聊天。不出一个月，大家就熟悉了，互相留微信，串门子。

有几户是明星家长，孩子特别厉害，能歌善舞，成绩很好，外语出色，大家都愿意去请教怎么带娃。其中有几户非常喜欢邀请大家去家里喝茶。有一个宝妈是卖玉石的，就在家里营销，还有一个宝妈是卖家具的，还有几家是家家教的，搞代购的，做微商 的。目前还没有打麻将。邻居之间信任感比较强，据说生意很好。原来聚会，这些太太们是喝速溶咖啡，现在改为手磨咖啡了。

还有一个宝妈，前凸后翘，身材火爆，是卖高 端 消 耗 型 酒 的，顾客是大老爷们，所以宝妈们集体冷落她。我日，女人间的战斗也是超级激烈。

那些商户，有几户就是租房子的。你看看，现在的营销，真是无孔不入了。

# 02

二八效应

20%的顾客，80%的利润。关键是找到优质客户。优质客户在哪里？一般在豪宅里。你愿不愿意打入敌人内部？这就是租赁别墅的商业意义。

一个老板，租店铺，租宿舍房子，至少也要一万多了，现在京沪郊区别墅也就这个价！住的超级舒服，还不用上下班，还没人来烦你。一出门，身边都是有钱的太太和有钱的大叔。

如果你家是做高单价生意的，例如玉石，高级吸尘器，高收费家教，豪华旅游，可以考虑在别墅区（高级小区）租个房子，发展邻居当客户。市中心大平层面积还不够开轰趴，市中心邻居们大部分要上班，影响不方便。郊区别墅其实很方便
