# 为什么你在大街上看不出哪个是土豪？

答：无论多少亿，他不可能自己开个服装厂做全家的衣服，也不可能自己开个汽车厂生产自己的汽车，他的消费都是市场上买的。他能买，你也可以买，所以大家看上去差不多。最多他的西装漂亮一点，也没什么大惊小怪，陆豪嘴地铁站附近都是漂亮西装和开出租的豪车。

如何找到亿豪？亿豪出现的地方，往往是一般人进不去的地方，例如银行贵宾室，路演第一排观众，豪宅签浴室，网上极少，即使有，也是广告部写的，不会和你多说什么。

不要迷信亿豪，他们大多数都是土包子，不比你聪明多少。这些人主要是运气好，胆子大。我认识一个90年代的房产商，现在的房产巨头他都熟悉，他后来退出房产了，所以现在没什么大钱，也就是几个亿，找了个三儿，还挺漂亮的，那个女人现在也快四十岁了，一天到晚要转正，烦死了。

如果经济进一步转型，只要你运气好，多尝试，你也可能成为亿豪。成为亿豪不能强求，不是你努力就可以成为亿豪，有各种偶然因素。如果你没有成功也不要伤心，其实亿豪的老婆大多数也不漂亮，狡妇居多。对比一下，你还是幸福的。

为什么现在还有人创业成功？因为老板之间矛盾也很大。

一个企业运作，需要很多很多供应商，例如做塑料桶，机器设备原材料，还要食堂宿舍空调电力服务，就算你把这个小破厂的通风设备包了，也是一大笔收入。这么多供应商和东家，经常发生巨大矛盾。你压价，我就偷工减料，满口胡话。甲方就不开心了，时间长了，还有可能大吵一架，一拍两散。
