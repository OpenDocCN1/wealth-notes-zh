# 01

补彩礼。

菜菜，你是大叔了，问你一个老家的风俗，能不能补要彩礼？我姐前年嫁人，当年，我们女方被男方哄骗了，只收了彩礼6.8万，现在我们这里起步就是12.8万。差价是6万。我想首付一个车，跑运输，缺4万，想找我姐夫家要一点，就当是补彩礼。

我爸因为少给了彩礼，气的好几年都在骂男方是骗子。这次遇到我创业，缺点钱，就想起这个茬了。爸的意思是，不给钱，就让我姐离婚，现在二婚也很俏，再收一次彩礼。我和我妈的意思是，能要就要，实在不行就算了，也不能让我姐离婚。

你说以什么理由开口，乡里乡亲的不会嚼舌头？

答：小伙子，你有创意。今后适合去杭州当战略副总裁。

# 02

炫耀是很糟糕的事情。

生活中，有太多的人喜欢互相炫耀，生怕别人看不起自己。你炫耀单位，我炫耀收入，你炫耀房子，我炫耀车子，你儿子做老板，我儿子有编制。就这么无穷无尽的炫耀下去，家里人被折磨的死去活来。

我家老人也喜欢炫耀，但凡有点什么好东西，就想法设法的炫耀。实际上，炫耀不仅仅会伤害别人，更会伤害自己。人性深处，最不高兴的事情就是，熟人混好了。如果你混好了，给我扔个骨头，我就跳你得尾巴，如果不给，那就是结仇了。你算老几？想当年，你爸还上门求过我爷老呢！

我家老人，这么多年炫耀，真的是舒服大了，一群人心底里恨死他了，什么事情都共火。有一次，老人住院，几个老头老太共火，“你家这么有钱，应该住单间”，一句话，出去了六万。林木总总，不计其数。

有个建议，屌丝将来发达了，不要到处炫耀，招人恨。
