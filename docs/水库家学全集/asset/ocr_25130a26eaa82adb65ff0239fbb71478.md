# 人生的第一个工作重要吗？

很多小伙伴即将踏上工作的历程了，首先恭喜你，你是个成年人了。当然，成年人也有成年人痛苦，我谈一点点体会，希望能够帮助你。你找到工作了，分为两种情况，

一是大单位，可能是要一辈子在这里混的。这种情况不多，现在看起来超级好的工作，二三十年之后也不一定就是最好的。或者你的水平已经超越了平台，自己不想干了。混大单位，经验有很多。我知道一个娃，他工作后，每天都要和父母谈一个小时，把工作中遇到的人和事，原原本本说一遍。父母也是大单位的，一招一式教。效果超级好，现在，他已经是人中龙凤了。

当然，99%的人没有这个条件，也不要担心。你就记住一个办法：不要评论周围的人和事，多观察，假客气。这个办法百试百灵。

二是小公司。这种公司，你一般干不了多久，两三年最多了。如果你想发财，我就教你一个小办法。你花五年时间，把公司里每个岗位仔仔细细研究一下，然后自己出来当老板。这种公司的起步费一般是婚房首付。如果你觉得这公司还可以赚钱，就找个竞争不太激烈的市场区域，照猫画虎，也搞一个。
