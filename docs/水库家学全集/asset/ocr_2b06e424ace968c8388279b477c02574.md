# 16

男方拿到财务章，能不能去银行转账？不能。

柜台转账要有两个条件，一是支票密码，二是印章。支票都是有号码的，你不能用别人家的支票+自己的印章，去转账，没有密码肯定不行。

这个事情现在闹得沸沸扬扬，公司肯定也通知了相关银行。男方拿不到钱。

支票密码是什么？

我相信绝大部分会计专业二本子也不知道支票密码。我简单说几句，也给你将来开公司说点基础知识。

现在开公司，支票，财务章都是在财务人员手里，一般放在办公室，不会带回家的。假如有内部人，例如二股东，大老婆，在财务室同时拿到了支票，财务章，法人章，不就可以去银行拿钱了吗？以前还真是这样的。现实中，绝大部分老板一天到晚在外面谈生意，财务要用支票怎么办？所以，谨慎的老板很惨，就让老婆在家里待着，随时盖章。

后来，发明了两个东西，一是公司网银，小老板可以随身携带，自己转账。当然，大银行的东西，都不好用，很复杂，还时不时要更新证书，小老板看的就烦。

二是支票密码。这个比较简单。密码设备是银行公开卖给财务的，类似于一包香烟大小，你把金额时间等输入，会产生一个密码，微信发给财务就行了。

结论：就算你捡到了贵司所有的财务章和支票，也没用。
