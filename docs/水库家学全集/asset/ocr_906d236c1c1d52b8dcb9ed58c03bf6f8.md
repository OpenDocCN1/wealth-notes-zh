精装修不是你想象中的那么美好。（本文具有较强的实用价值）

现在，很多同学看新房子，都会遇到精装修的概念。那么，精装修到底是什么情况？我来介绍一下。

+   1，精装修不等于拎包入住。精装修的表面价格，一般是每平米3-8千。很多人误以为，老子花了这么多钱，肯定是和样板间一样，美美哒，打扫一下，拎包入住。实际上不是的。精装修，类似于一个非常粗糙的毛坯砖，到处都是问题，完全不能用。没有大面积漏水，已经算你运气好了。

+   2，精装修的小瑕疵极多。绝大部分精装修，是拼命压价的结果。甲方对乙方的压价，你是难以想象的强势和凶狠。乙方没办法，只能减少配置，粗制滥造了。举例，最常见的纱窗晾衣架，精装修肯定是沒有的，你要不要自己安装？这种情况非常多。从吊棚到橱柜，各种设施，你可能一百个不满意。
大情况是，你要花一个星期，像福尔摩斯一样，找出问题，重新修补一遍。举例，精装修的厕所排气扇，一般都没有接通向室外，就是装个样子。各种插头，80%是坏的，网线口子100%是坏的。你可能要崩潰了。

+   3，精装修的好处是风格比较好。因为你是看了样板间喜欢才买的。个人装修，用材料肯定是没问题，就像给自己买吃的，你不会买很差的，也会逐一验收。但是，个人装修最大的bug，是风格不行。你把所有的心思都集中在材料上，老婆孩子丈母娘，个个都要提意见，最后搞出来一个实实用用的大花脸。
精装修正好相反，整体风格很好，毕竟是很多设计师挖空心思搞出来的。但装修质量一塌糊涂，装修队是一次性包500套，他面对的不是零零散散的小业主，而是甲方一个小头头来验收。小头头哪有时间检查500套房子的插头排气管？装修队长那个一下，小头头假装推荐辞职，也就从了。可想而知，质量如何了。

+   4，价格。交房精装修后，还需要多少钱才能入住？
一是一次装修补修。小改小动，20个。大改大动，100个。再低，装修队就不干了。你可能一开始想省10个结束，干着干着，这也要好一点，那也要好一点，最后就翻倍了。我见过一个家伙，每天劳心劳力，多花了120个，因为不漂亮，最后被一家人骂成了猪头。
二是家电家具。小白领风格，20个，土豪风是80个。
也就是说，如果你就想搞个入住标准，30-40个够了。如果要面子，100-200个。
