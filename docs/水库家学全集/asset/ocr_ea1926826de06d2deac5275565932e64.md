# 10

中年富二代的悲催。

我周围有一些老年土豪，已经七八十岁了。资产也不多，几个亿左右，但他们思维还比较清楚，死命抓住企业的资产和钱，不肯放手。手底下的部门经理也是老土豪一手扶持起来的，根本不认富二代。富二代非常倒霉。

+   1.  一是干的苦，很多富二代没有上过班，大学毕业就在家族企业实习，已经实习了二三十年，也摸不到钱。
2.  二是没钱。富二代结婚后，女方一般也会辞职进入家族企业白干活。小两口子一年也就几十万生活费。
3.  三是没资产。土豪这几十年，90%的钱投到企业里。偶尔买了一个大户型也是老头老太的名字。儿子女孙连个毛都没有。最搞笑的是，有一个土豪，在厂里修了一个欧式别墅（非住房），一家人住在里面，儿媳妇像个长期租客，跟她没有任何关系。

富二代在这种悲催的环境下，一天到晚操心，看不到一分钱。有的倒插门已经五十岁了，还是屌丝一根，惨的不言不要的。
