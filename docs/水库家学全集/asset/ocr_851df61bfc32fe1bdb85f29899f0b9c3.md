包邮区普通人家的吃饭菜谱。

如果不是赶时间，正餐一般如下，

+   - 一是正菜2-4个，例如鸡鸭肉虾蟹，河鲜海鲜。我家比较多的是水产品。也有小炒肉，红烧肋排之类的。

+   - 二是蔬菜1~2个。比较多的是鸡毛菜，空心菜。

+   - 三是菜汤1个。番茄蛋花汤比较方便。鸡毛菜汤最方便。

+   - 四是卖点点菜，例如卤鸡爪，鸭脖子，牛肉片。

+   - 五是饮料，小酒。南方人喝低度酒，例如啤酒，黄酒。在家喝白酒的，都是老酒鬼。我的酒量是很厉害的，一斤啤酒。
