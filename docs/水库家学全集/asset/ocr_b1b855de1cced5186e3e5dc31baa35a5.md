# **05**

关于老屋翻修。

这个情况越来越多了。主要是，人已经在城市里定居了，但是，继承了村里的父母房子。老屋，越来越破，也没人住了，要不要花钱翻新？因为翻新要花不少钱和精力，又没用，心疼啊。

答：分两个情况，

一是你的户口还在这个老屋里。你本来就是出来打工的，建议翻修一下。因为，你对这个房子有明确的所有权。以后如果自住或者其他大开发，你是名正言顺的主，享有各种权利。

二是你的户口不在老屋了。建议做安全性加固，只要维持不倒就行。因为没有本村户口，是不能享有集体土地使用权的（除非老家有其他特别规定）。如果这房子倒了，就和你没关系了，地皮收回。
