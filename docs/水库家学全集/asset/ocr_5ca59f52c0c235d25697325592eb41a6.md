# 百万年薪别参加世界。

百万年薪的悲惨世界。（投稿）

我是房子公司中层，年薪120-200万（睡前）。我养了一屋子人。

一个老婆，两个孩子，双方四个老人将来的医疗费，还有个弟弟没有结婚，指望我出个地级市首付。

我是我父母的骄傲。父母原来是在一个几万人的大厂上班，后来厂子黄了。但是，邻居们互相之间都认识。我的收入震惊了父母的朋友圈，所以，我父母也开始享受人生了。夏天要去避暑山庄，冬天要去海南。父母每到一个地方就要买房，50-100万/套。不买就是不孝顺，让他们在朋友圈丢脸了。我老婆一家人也把我当肥猪杀。

实际上，我高薪也就三年，还要买地级市别墅，养车，孩子读私立，实是不堪重负。包括小舅子结婚都要来借钱。三年下来，只存款了10万。

今后怎么办？

寒门贵子。

我这个年龄，还出现了一些寒门贵子。大学毕业后，搭上了市场经济的东风，实现了年入百万，豪宅豪车的生活。但是，这些人的父母不一定是好鸟。我见过好几次父母摘子女钱财的事情，不满足就闹，闹得鸡飞狗跳，子女颜面尽失，甚至离婚。举例，

有对北方城乡结合部的下岗工人夫妻，含辛茹苦养大孩子，孩子也很争气，实现了年入百万，嫁了一个同样有上进心的凤凰男，但是幸福并没有来临。

小夫妻合计年入两百万。都是小地方人。双方父母的朋友圈都是底层人口，一看到这个收入，基本疯了，拼命的吹捧双方老人。双方老人属于那种肯吃苦，很要面子的人。于是开始对子女疯狂索取了。

一是买房，五年前双方都要总价两百万左右的省会大户型。他们认为，子女是自己培养出来的，该享福了。

二是旅游。每年的费用大概是十万一家。满世界旅游。
