# 01

# 为什么学区房那么热？

这里面有个非常鸡贼的逻辑。买个学区房，孩子就轻轻松松读个重点小学了，过几年再卖掉，又赚一大笔钱，名利双收零风险。天底下有这好事，再贵也无所谓，以后卖掉就行了。我不搞岂不是傻瓜？事实上，学区房并没有你想象的美好。

# 一，小学成绩看家长

很多人以为，孩子进一个重点小学就万事大吉了，终于把这个烫手山芋交给班主任了。你觉得可能吗？班主任面对三十几个到四十几个小娃娃，要想把他们管好不受伤，已经是精疲力尽了。你还指望成绩也归班主任负责？你想多了。

九年制的成绩，百分百看家长，不要指望班主任。我家小娃娃在一个不错的小学，刚刚读了几个月，已经有比较明显的分成了。家长不太上心的，写作业都麻烦，拼音读不进去，数学有困难。家长很认真的，像菜媛那样的中年妇女，孩子成绩明显高一截。

# 二，学区趋势有变化

目前学区房的价格主要是两个影响因素，

一是学区调整的风险。这个风险是客观存在的，现在一个房子六年有一个名额，再加上提前一两年买，也就是说，七八年不能调整学区，否则就会头大。

二是报名规则的变化。总的来说，有关部门不太喜欢学区房这个概念。好处都给家长捞走了，学校没剩下啥了。报名规则已经有变化了，一种是一个学校对应多个学区，相当于学区房扩容，中签率大大降低。二是民办公办同时录取。这个目前看影响不算很大，但是揭露出一个趋势，单纯靠鸡贼的想，越来越难获利了。

# 三，所谓的风气

我家小娃娃现在读的是小学，我们小时候经历过各种各样的事情都有。到了初中，重点班就不谈恋爱吗？没这么简单。

小结：家长还是自己要多努力，不要以为甩锅很容易。另外，没有买学区房的家长也不要太遗憾，这玩意没有想象中的那么好。
