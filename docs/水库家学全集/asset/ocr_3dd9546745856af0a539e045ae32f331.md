# 为什么生活在小地方幸福感比较强？

幸福感是比出来的，比你强的人都走了，剩下的都是歪瓜裂枣的二本子，你就有心里优势了。

你愿意回老家县城，说明你家在县城还有点人际关系，所以糟心事情不多，心情舒畅。

县城生活成本低。一套房80万，贷款后都大家买得起。牛肉面12元，比西二道便宜多了，没有上班交通成本。骑自行车就去了。

找对象容易。方方面面给你介绍，你总可以找到一个女人过日子。

世界上只有下坡度容易走。

县城这么好，为什么还有那么多人跑到京沪广深去打工？县城的资源分配不是看能力，而是你懂的。县城生活缺点是缺乏就业。一旦你的子子孙孙在县城找不到铁饭碗，连喝稀饭都困难。

结论，如果你在县城有强大资源赶紧回去找老婆。
