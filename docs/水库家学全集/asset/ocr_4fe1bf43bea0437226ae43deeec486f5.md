# 14

白手起家罕见。

屌丝最喜欢的事情大概就是白手起家了，因为莫欺少年穷，屌丝没钱想发财啊！白手起家最多的时候就是现在四十岁的这批人。他们赶上了几个红利期。

一是文凭值钱。我们当年文凭很赚钱，好单位只要大专就行了。那时候大专相当于正儿八经的大学生。银行连投校车都抢着要，高中生可以当信贷经理，桂圆是工人编制，读个夜大专就有资格当副行长。现在的大专就是笑话，考不上大学的代名词。

二是买房容易。我们那时候，工资一两千，房价八九万，结婚从来不需要考虑住房。两口子只要有正经工作，就可以贷款买房，农民工一般是贷款买四五万一套的小户型。我们土著一般是买大二层，小三层，十几万一套，还是内环线。月供相当于一个人的工资，另外一个人的收入足够一家人正常生活了。

三是m2大爆炸。我们工资年涨，很快达到月入八九千，那时候贷款十万就是天文数字了。货币大增的结果是，以前的贷款好像无所谓了，再买一套。

四是土著大拆迁。大部分土著都遇到了拆迁，基本都有房子，当年住房紧张的情况，一扫而光。就像是曹杨二村的老公房那种，家家户户都有1~2套，相当于给了你几百万。当年，大专毕业，就是倒插门的黄金通行证。

这种奇妙的事，不是年年都有。今后不知道怎么逆袭了？90后已经慢慢变老了。祝她们幸福。
