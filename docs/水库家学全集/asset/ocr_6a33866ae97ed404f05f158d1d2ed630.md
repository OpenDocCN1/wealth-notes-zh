# 以前的单位是怎么分房子的？

财|上海微博 2020-05-03

# 01

现在的大学生应该没有见过中年妇女在单位为了房子哭的要死要活。我见过。

那时候，我还在实习，单位分房子，有个中年妇女以为自己勤勤恳恳二十年，唯唯诺诺，从来不敢反对领导，这次应该分到一个15平米的小破房子了，结果失望。我记得那天在单位主道（大门处），张贴红榜，就是分房子名单，她没有，哭的昏天黑地，当场瘫在地上了。其他妇女还在背后挖苦她。

他们家很可怜。老公是一般工人编制，儿子已经13岁了，还有个外地老人（无户口，不算分），根本没有其他分房可能性，全家唯一的希望就是她了。这一次，她准备了好几个月，到处卖惨，找每个领导哭诉，我经常看到她上班时间眼睛红的，低着头回办公室。大家也知道她去卖惨，也不说什么。

还有个老资历分房子之前挣表现。女厕所堵了，他居然用手去掏粪洞，感动了大家，开大会的时候，一把手特意表扬了他。这次，他顺利的分到房子了（分数也够，没人反对），现在那套房子价值700万左右。

大家不知道，以前分房子的规则有多么复杂。那时候，单位里就两件事情，升职级，分房子。

+   - **热门评论:**
  - **惠恩--**: 房子商品化后大家拥有一套房子更容易了，而不是相反。
  - **爱丽找爱美丽**: 课代表：房子拿钱买，已最简单最执行，可惜二本子还等半公送，真递轮到你吗？
  - **无为淡然**: 我婆婆为了分套房，她没分到，她就到上级系统跑桌尿子，最后分到一套一室户，后来卖了付了买房新的首付。
  - **有钱人王小姐**: 给我700万我也愿意用左手右手一个慢动作
  - **轻舟青山亦如是**: 太复杂了 不懂里面的门道 但分的房子肯定是一代代人的指望 是命根子了

# 02

# 当年分房子是什么流程？

一是确定房源，包括分到新房退出来的二手房。

二是建立一个分房小组。这个部门负责几件事情，

+   1. 制定打分规则。这里包括了大部分部门经理。这个规则制定是非常重要的事情，有些话点到为止。
2. 初审
3. 负责纠纷。总有不服的人。

三是总裁办公会。通过了，还要等几天发布，防止出现意外情况。

这里面利益实在是太大了，各种事情没法细说了。你要得到一套免费房子，大概要几十个人同意，真的是千山万水，
