# 05

没有人，会便宜卖掉自己的传家宝。

房价低就幸福？这是某专家的意思。如果你非要这么说，那么最幸福的应该是回农村了，50万，楼上楼下，村口别墅。还有什么东北小城市，几万块一套房。那他们当地人岂不是幸福当翘起来了？当地人怎么还会出来大城市送快递，到海南乡下开餐馆呢？

事实上，有人高兴，肯定有人就吃亏了。你希望家教降价，最好回到二十年前，20元一小时，可人家不愿意啊！

房价低的地方，实际上都是赚不到钱的穷地方。有本事的人都走了，也不想回来了，三瓜两枣就卖给你了。我十年前说过，房价取决于周围五公里的高薪岗位的数量。如果你在山脚下建一个大别墅，基本没有意义。因为在那个地方，你只能花钱，不能挣钱。你的钱够花多久？十年还是二十年？

我有一次挖到一个金元宝。我买了一个房子，偏僻地段。我当时想的是清净，以后退休了，市区房子给她，我过来乡下。没想到，一年后，附近建了一个牛校的分公司。突如其夜春风来。附近的中介，发了疯一样在小区门口，求加微信。因为有非常多的家长要过来。我大概了一下，今后几年，至少要增加1200个学生家庭，200个教职工家庭，50个服务商的需求。你可能不知道，学校周围做生意的人有多少。
