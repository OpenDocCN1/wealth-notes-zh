# 亲戚对公司有用吗？

![](bbox=[0.48, 0.03, 0.53, 0.06])

创业初期，亲戚超级有用。公司起步，穷人一个。半夜到货了，谁去接？厂里有人偷东西，谁去管？遇到突发情况，谁会不计得失的出头？只有自己和亲戚。

但是，用亲戚的后果很严重的。因为亲戚认为，这个公司有他一份，以后就靠你了。买房买车，儿子留学结婚，全部指望你了。你永远无法满足亲戚们的欲望。他们最好和你平分财产，还要怀疑你拿多了。

如果你不能满足亲戚们日长夜大的欲望，亲戚们就变成负能量了。我见过老板兄弟吃回扣的，乌烟瘴气，实在是没办法了。除非你结业，另起炉灶。

# 富人愿不愿意提携小屌丝？ 愿意，非常愿意。

富人风险很大，事情很多。需要能干的人替他完成各种工作。如果你能干，又不吃里扒外，在民企是会快速上升的。如果能赚钱，你就是土老板的亲爹。

天底下所有的单位都有个特点，你要积极争取。老板很烦心，一天到晚都是各种烦心焦虑的事情，没那么多时间观察你，提携你。你要想出头，必须自己积极争取。就是挣表现。

老板特别喜欢提携屌丝。因为屌丝往往没有其他花头，一心一意干活。当然，屌丝也不能要钱要位子要的太凶了，失去了性价比。

现在，很多屌丝一抱怨，没机会，实际上机会到处都是，只不过屌丝不想辛苦。你搞个技术创新，节约二十万成本。你多跑几个客户，争取两百万订单。你会吗？算了，还是打游戏吧。
