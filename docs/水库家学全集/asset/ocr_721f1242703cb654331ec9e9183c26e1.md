# 逆袭是什么样的？

某帅哥，我的大老乡，爹妈都是老实巴交的农民工。他靠自己读书，最后上了985研，九十年代毕业，入职大单位，转正后就是副科。单位分过一次小二层（现在价值3-4百万），当年结婚遇到低价房时代，总价36万买了一套三居室的漂亮小区（现在价值8百万）。自己也很努力，一路高歌猛进，现在已经是大单位科室一把手，正高。路路道，朋友遍天下。天天有人请客喝酒。他是老家亲戚里最有面子的人。

他每次回老家，县里都有很多朋友来拜访。那些有头有脸的人物，三天两头派车上门来接他去县里喝大酒。村长找他聊天，他都没时间。

总结一下：

+   1. 当年读书有用，因为社会上大多数人没有文凭。那时候，大专都是天之骄子。

+   2. 当年进大单位很容易，因为文凭稀缺。大单位里都是村炮，成人夜校毕业的。

+   3. 当年真的分房子，但要有级别。

+   4. 当年房价够低。

+   5. 当年一路崛起，是因为他的上一代都是六十年代初期的大学生，他一上班，老头老太就马上腾地方来。
