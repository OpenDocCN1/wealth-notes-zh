# 02

回乡下。

最近看了好几篇大城市小说回乡下的文章。这些人几乎都是村里人最不喜欢的品种，酸秀才。他们基本不会干农活，还喜欢骂骂咧咧，自以为什么都懂。他们把农村想象的很好，故意瞒了很多事情。我举个最简单的例子。

你在农村，夏天说话都要含蓄一点，嘴巴张大了，可能会吃到蚊子。大家可能不知道，乡下的蚊子，非常奔放，晚上都是抱团逛街。脸上咬一口，直接一个大包，乡下的蚊子没见过世面，不怕人，直接扑上来就是一大口。至于苍蝇，蟑螂，老鼠，只要不爬进被窝，就不管。

还有什么空气好。打农药，施化肥的时候，你在屋子里就能闻到各种奇形怪状的香味。

还有什么邻里温情。锤子！你要是没钱，村头一群老娘们就嘲笑你个，没用的瓜怂。狗剩，你今年挣了多少钱？

哪有什么岁月静好，只不过是没钱，不想动了。

# 03

为什么，我们的就业如此之好？

你们可能没有去过欧美亚非拉，不知道就业的宝贵性。但你问问家里的老头老太就知道了，30年前，找个工作有多难。这么说明！当时，如果你是一个大厂烧锅炉的正式工，十里八乡最漂亮的姑娘任你挑。丈母娘自黄来给你带盐，老丈人在地里给你种有机大米，半夜去抓野生黄鳝送你补身子，小姨子载歌载舞请你去吃饭。

现在没有了，因为找工作太容易了，没有人再把一个普通工作当回事了。为什么啊？有些事情，要多想想，你就明白了。成绩来之不易，且珍惜。
