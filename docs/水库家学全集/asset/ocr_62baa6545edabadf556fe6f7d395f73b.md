# 14

楼市热二十年，为啥？

有人说丈母娘需求，有人说是老婆要买。实际上，这只是表象。

我年轻时候，社会上也有欠款，那时候人们不买房，而是买东西，金项链，汽车，家电，烟酒，鸡鸭鱼肉，KTV潇洒，还有人买一箱天府可乐，一天喝三瓶。为什么现在买房了？原因是不买不行。

你丢去一些家庭大事，例如孩子入学，户口，没有房产证是头大了。为什么以前不买房。因为在以前，有没有房子，也不影响办事。如果有关部门出个规定，居民来办事盖章一律不得要求提供房产证，那就会好的多。
