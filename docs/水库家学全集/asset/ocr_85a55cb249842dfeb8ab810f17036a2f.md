# 01

倒插门如何讨好老婆？这是我二十年的独门秘籍。

一是赞美。我们倒插门就一点好，没钱，不会劈腿。但是，这一点还不够，必须天天拍马屁，讨好那个女人。你要想出各种各样的话来讨好。今天说她越来越漂亮了，明天说她皮肤越来越好了，后天说她越来越年轻了。反正，怎么骗应怎么说。不要怕，女人最喜欢听好话。

二是送礼物。我也不知道为什么女人这么喜欢送礼物，大的我也送不起，就送点力所能及的。有一次，我给家里那个女人送了一个lamer（涂脸的），大概五六十块钱，街上买的，获得高度评价。

三是请吃饭。我最喜欢清火锅，人均一百多。吃的满脸油光，再赞美一下老婆越来越年轻了。效果杠杠滴。

四是给钱。咱们虽然没什么大钱，但是不能小气。有一次去西湖，我就自告奋勇去买票，我告诉老婆，一人一百八，老婆很满意。

五是跑腿。咱们家买房，办证都是我去的，还有装修，从来不让老婆操心。这是男人应有的气量。一般情况下，我在装修上可以跳个五万八万，今后几年小日子好过了。当然，我也不是偷工减料，而是精打细算。有一次，老婆看上了一个大理石，要整块切割，纹路一致，我第二天去，就用了小料切割，装好看不出来，她便很得多了。

# 02

白富美也贪财。

我认识菜嫂的时候，正好是我人生中唯一的高光时刻，月入30000刀。老留学生都知道一个东西，电话卡。那时候没有Skype，也没有QQ，只有电话卡。

菜嫂那时候是个刚刷出来读书的郊区土妞，没见过世面。留学最大的苦恼是饿。因为饭菜不对胃口，你在食堂吃不了多少，晚上十点就饿了。一般人买一些饼干备着。我就没其所好，一直请客。不是那种到馆子里大吃大喝，而是在超市里买了鸡鸭鱼肉，带回去做饭。我请客，一般请一群人，就是菜嫂周围的同学都来。男同学帮忙做饭炒菜，女同学负责吃完了收拾，北方女同学特别仗义，不会躲懒，浙江女同学嘴一抹就躲了。

多请几个人有两个作用，一是有人帮忙，要不然我一个人也搞不定。二是大家也会说我的好话。我印象最深刻的是阿拉斯加的鱼缸，化冻一炒，撒点泰国辣酱，绝对美味。每次我请客，大家高兴的就像是过节。同学们也很愿意把菜嫂卖了，换几顿好吃的。于是，在同学们一致好评下，菜嫂算是同意跟我过了。
