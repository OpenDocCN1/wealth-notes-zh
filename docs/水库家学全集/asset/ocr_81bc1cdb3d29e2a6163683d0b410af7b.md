# 左右为难的妹妹。

菜菜，我是你老乡，外环线二本，小美自，165cm，丹凤眼，虽然是农村户口，但是从小到大没干过农活，对标菜花也不输。男票是老家省城的户口，他父母已经在郊区买房。我们毕业后，在内环线打拼，已经在一起过家家了。对这个男票，我是很满意的，但是，我们两个底子都是农村，在外环线买不起房子。我们昨天算了一下，如果贷款，我们大概要拼30年，我今年24，也就是说，我一个女人要熬到54岁，才付清贷款。在此之前，欧洲游，吃大餐，坐游轮，买包包，都别想了。

我也有少女心，也有粉色的幻想，但是，如果真这样结婚，我这辈子就没有盼头了，实在是不愿意。我们老家的行情是，不结婚领证就是历史清白，没人会说什么。现在，另外有个老王在追我。他经济条件好，但是，他本人条件不如现任男票，老王是169cm，今年47岁，低学历，包工头出身，现在是一个装修公司老板，开宝马，在南汇有168平米的叠墅（实际上面积很大，有六个房间，三个厕所，一个很大的厅，还有大型按摩浴缸，我和老王试了几次，很舒服）。我好喜欢！那个漂亮啊。

老王离异三年，女儿今年高中住校，跟前妻过，按照我们老家规矩，以后给个车做嫁妆也差不多了。我和老王接触三个月了，手机微信随我看不，确保只有我一个女票。我现男票当年也是很热门的，是我千辛万苦从别的女人手里撬过来的。此时此刻，我是左右为难。你也知道，选择太多，女人也是很痛苦的。若有下半场，我愿意一生一世服侍他。

今天我想问的是，如何补偿一下现男友？我不想用老王的钱来补偿他。

答：菜菜已经昏古七了。

# 我为什么能够成为学霸？

按照现在的教育流程，我是绝对不可能成为学霸的。我当年脱颖而出，就是一个原因，其他家长们不管，让我钻空子了。

我们家不重视教育，但很重视考试。你再厉害，读书读到清北，无非是混个中产而已，意思也不大。但是，如果想要逆袭，倒插门，那就必须考上985了，最低也要搞个杭州南京的985。老丈人的钱也不是那么好拿的，总要有个说法。最好的说法就是我是985。
