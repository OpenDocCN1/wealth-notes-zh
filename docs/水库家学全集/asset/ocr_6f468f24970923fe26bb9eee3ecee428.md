# 一线城市城市的特点是门类齐全，东方不亮西方亮。

财上海微博 2021-06-16

01
深镇是新晋明星城市，而不一定是完整的一线城市。

一线城市城市的特点是门类齐全，东方不亮西方亮。深的经济有点单一化，突出特点是，科技，而不是综合功能。

任何科技行业都有周期，一旦处于上升期，要风得风，要雨得雨。一旦转入下半场，那就大眼瞪小眼了。超级大城市要经历百年，几乎没有任何一类科技型公司，可以好过百年。因为在社会发展的各个阶段，消费者需求不同。近四十年，各时期的王牌行业分别是钢铁，石化，商贸，建筑，高铁，通讯。圳是赶上了一个特别好的机遇，一好好好。我不知道，下一个十年，王牌是什么。可能是医疗养老文教。

为什么行业周期会变？因为消费者喜新厌旧。一旦满足了这个需求，立马会去追求新的需求。大家可能不知道，石化产业在80年代有多么厉害？以前的人都是穿棉布衣服。棉布衣服很舒服，但最大问题是不挺刮，皱巴巴的，没精神，不符合审美。后来石化产业起来后，解决了这个老大难问题，非常畅销，风靡一时。谁要是买到一件化纤西装，回头率95%。

还有钢铁行业。现在钢铁行业不太过好。但是，在70年代，钢铁行业是绝对的王牌。老的五元钞票就是一个钢铁工人。

我们以前缺钢铁到什么程度，你去看70年代的画报，一般农村妇女都是扎辫子的，极少齐耳短发发型。为什么？因为没有发卡，那么小的一个东西，就是没有。因为缺钢铁。

发展多业态是很重要的。靠几个明星企业扛起了城市名片，并不可靠，很多方面是有所欠缺的，特别是医疗教育商贸服务文化等各个领域，还有短板。如果明星企业走过了行业巅峰期，若干年后不那么赚钱了，其他行业能不能顶的住千万人口的就业？

杭州南京成都都是综合性城市。完全有可能成为新一线。大家可能觉得天方夜谭。我举个例子。如果成都来了四五个明星企业，工资提到80万，清北复交的孩子，打破头要来，用不了三年，就是妥妥的超一线。

我对郑州是比较看好的，具备了起飞条件。

一是交通枢纽。所有的大城市，都是这个原因。

二是人口多。这是工业化的最基础原因。

三是能吃苦。现在包邮区的年轻人已经把当老板看成刚需了，这简直是有毛病。河南人还算可以，胡思乱想的人少。
