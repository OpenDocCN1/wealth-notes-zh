# 人际关系是个无底洞，不行就算了吧。

财上海微博  2020-01-23

01

社会上开厂的小老板们现在真的是拿命在赚钱。

一是抵押。现在借钱不容易，特别是企业级别的借贷，都是拿自己房子或儿子媳妇房抵押的。

二是是法律问题。有个罪，好像是拿错误的资料去申请贷款，还不上就要抓了。我问了一下小老板，所有的贷款都要求你的企业是赚钱的，逼得小老板拿出一套银行满意的资料，否则滚。想想也好笑，要是赚钱，有几个人会求爷爷告奶奶去贷这么多款？

三是市场变化特别快。前些年，我遇到一个屌丝小老板和我吹牛，他曾经做一个北美单子，一天赚四万，风雨无阻，旱涝保收，如果赚个三年，那就不得了，他已经在考虑要不要上富豪榜了。结果只开心了一个月，业务就没了，只剩下一堆破机器和库存和一大堆索债的友商。当年花五万买的桌子，现在五百块也没人要。最后成为了屌丝，被老婆骂的狗血喷头，狗不理。

有没有特别赚钱的老板？也有。主要是在低成本时期完成原始积累，例如企业技术人员配置完整，员工宿舍等重资产一应俱全，有强大的销售渠道，产品质量稳定，品牌有知名度，全国各地经销商愿意给预付款的企业。当然，数量很少。

我写的小老板系列，屌丝们不爱看，因为他们对企业经营没有概念。他们的心里一般是认为，老板都是坏蛋，抽中华，喝洋酒，下班开宝马，上班**小美，夜夜KTV。实际上不是的。绝大部分老板都是苦逼一个，穷的叮当响。自己在车间院子里扫地的老板比比皆是。
