# 02

在内环线生活需要多少工资？

也不多。我家之前一个钟点工保姆，老公是某老破小区的维修工，月入五六千，因为需要晚上值班，物业公司配有一间单独宿舍，老婆是钟点工，8000-12000元每月，儿子是送快递和外卖，月入八千到一万。一家三口月入2.6万左右（不精确），住房解决了，吃饭有人管，一般物业公司包饭，送外卖的，饭店给个盒饭，开支几乎没有。保姆更有意思了，她老公想吃班节虾了，她就给我买班节虾，煮熟了，下班顺三分之一回去，我假装不知道。什么锅碗瓢盆五粮液洗洁精，我家就是仓库，干了两年就在县城买房买车了。

# 03

为什么小企业不喜欢985？首先是985不喜欢小企业。据我了解，很多小企业的二把手，老雇丝出身，科技水平也就是发微信，看抖樱，但他们年入百万是很正常的，一般普工也就五六千。

小企业不喜欢浪费钱。小老板最大的需求是偷懒和赚钱。他们喜欢把企业交给头管理，又好又方便，工头就拿到了百把万。另外一个痛点是，怎么赚钱？985解决不了，所以没人要。
