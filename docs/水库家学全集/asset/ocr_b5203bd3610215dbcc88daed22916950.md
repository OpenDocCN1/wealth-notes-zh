# 01

富亲戚和穷亲戚真玩不到一起。

穷亲戚对富亲戚的要求有两个：

一是平时。我是你三舅，我是你大姑，你是小辈，要用我满意的方式给我好处。既要给足面子，还要给好处。否则，你就是瞧不起人。我家虽然穷，但也不缺你这六百块红包。

二是有事。我家孙儿好不容易考入了英国大学，你这个有钱亲戚，总要帮一把啊。还缺五十万，你看能不能赞助三十万？以后孩子毕业了，大出息了，会给你帮忙的。我家儿子娶媳妇要买房，还缺四十万，借一点，我这个正牌二舅担保，肯定还你。不出钱？你就是垃圾，看不起人啊？老子不开心了。滚！

富人一天到晚，焦头烂额，各种破事，心力憔悴。逢年过节走个亲戚，实际上就是散散心。到你家吃吃喝喝，回忆一下小时候的感觉，给你个一两千的红包买买菜，也就是表表心意，哪还有精力和你扯面子不面子，礼数不礼数的？一般情况下，富人没有精力或者时间，专门给穷亲戚摆一个排面，让穷亲戚觉得好吃＋开心＋大红包。你以为你是谁啊？爱吃不吃，不来就别来了。滚犊子！

我发财后，也遇到了这些麻烦事。你说你没惹好，十里八乡都看不起你。你要是混好了，来借钱的人坐一屋子，还给你带两斤今年的新毛猪。也不多想借三十万。你怕不怕？
