# 真的猛人

小时候读过一句诗，天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身。小时候不太懂这个意思。长大了，终于懂了。

猛人大部分出身贫寒。当然，你家虽穷，不一定是猛人。出身贫寒，意味着其中部分人的意志坚强，能够忍受巨大的痛苦。这个非常了不起，如果大家水平差不多，就看谁多拼最后五分钟了。

猛人天资很好。记忆力惊人。这是天赋，考试最起码混个985。

猛人情商极高。特别是农村出来的人，情商极高。特别会搞好人际关系，单位里大大小小的头头都喜欢他们。城里孩子这方面不足。举个例子，如果别人买了个车，情商高的人会说，“啊呀，这车太漂亮了。我们家县太爷的车也不如这个”。我们这种城里250是说：“这车不行，发动机烧机油”。因为这个破嘴，我们是吃亏大了。

当然，你具备了这些条件，也不是肯定成为猛人，你还缺一个机会证明自己。这种机会是非常难得的。我年轻时候，由于太猖狂，被人恶整过一次。单位里给我派了个活。全国某技能竞赛。单位里的老阿姨是这样想的。你不是牛逼哄哄吗？给你露露脸，你去厉害啊！结果，兄弟我，凭借机缘巧合，得到了前三名。这些老姨嘴气的牙根痒痒。最后没办法，说了一句，“菜菜这个人，业务能力比较好，就是做人太猖狂”。

姜就着吧，老子不伺候了。老子就是要让你难受。后来，我把聪明劲用在了做塑料桶，也混得不错。是金子总会发光的。老子是电灯泡，天天发光，就气你。
