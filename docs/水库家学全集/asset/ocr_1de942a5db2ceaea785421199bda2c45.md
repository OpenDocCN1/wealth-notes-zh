# 如何识别名媛？

我不知道什么是名媛。以前有过，例如什么纺织大王，肥皂大王的女儿，现在不一定有几个了。因为名媛是存在社会地位的。现在，一律改称"小富婆"。就是不上班，也有钱的那种。

我就简单说说小富婆的生活。我对她们实在是太熟悉了，熟悉到不想见上面的程度。这些女人，一般都是家里开公司的，老爸赚了几个美钱，了不起啊，老子最烦这种。她们的家庭资产一般是几个亿左右，再多就要上财经版面了，我熟悉的小富婆，都是挤不上财经版，也挤不上娱乐版的土肥圆。圆润好啊，镇宅，看的喜庆。

有钱的单身土肥圆，不会去半岛喝下午茶的。因为她们也有点忙。忙什么？一是事业。包租婆也很热爱事业。有个包租婆居然开了个咖啡店，自己做蛋糕。二是忙相亲。包租婆在相亲市场是爆款。我认识一个非常漂亮的包租婆，一年收入大概一两百万的那种，给未婚夫买了保时捷，还给他五十万零花钱，未婚夫当场被拿下，现在结婚了。

小富婆，一般不会搭你的车，自己有个不错的车，大概是50-150万，自己开。

小富婆，一般不会浑身名牌，那是批发市场小太妹的风格。

小富婆，最恨别人问她学历，一般都是大专，高职，二本或者英国研究生。她们最喜欢讨论中学，因为她是自费生。

小富婆，一般不会经常去看画展，她们经常去看建材市场。大部分包租婆对贴砖和电子马桶的价格清清楚楚。

小富婆绝对不会找你耍礼物，超过几十元的东西，一般不收。除非特别熟悉了。

关心小富婆之前，最好的识别方法就是，你去她家，故意指一个不常见的电器，让她开一次。如果是租房，十有八九不会开。或者问问她水管电路总阀在哪里，或者维修工具箱在哪里。女人一般不太注意这个。
