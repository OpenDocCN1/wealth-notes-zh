# 一个私企业务员是怎么成为霸道总裁的？

老王的上一份工作 是私企的业务员，工作是卖女式秋裤，干了30年，已经52岁了。这个生意，主要是在农村地区集贸市场销售，也没有什么人脉关系，最多认识几个村会计，鸟用也没有。唯一的收获是吃苦耐劳的好脾气。但是儿子马上要结婚了，没钱买房。老王急的在家里直跳。

就这么一副烂牌打出了新高度，我佩服的不要不要的。十年前开始，农村慢慢普及了热水器。老王就开始销售这个。他奇妙的利用了在农村人头熟的优势，挨家挨户的做工作，一下子打开了市场。

几年后，他成了某品牌的地区分公司老板，手下有五个人，又过了几年，总公司提拔了他，成为省级分公司老板（承包），配司机和n女会计。

到了60岁，他已经攒下了360万现金。他问我买哪里，我才惊讶的发现，身边居然还有这么个其貌不扬的小土豪。后来，没买房。他儿子媳妇一口气做了十几个大银行和大公司的小股东，现在没钱了。

# 如何做副业？聚焦主业衍生，关注周边项目。

绝大部分人的主业是不能直接转化为副业的。老子是xxxx，你说怎么转？我举个亲眼所见的故事。有个地方队的女子举重运动员，业务水平高，但是专业太冷门了。没有哪个女人会去自费练习举重项目的。年龄过了，毕了业，除了包分配，她还能干什么。很多人想不出来。我就看到了精彩的转身。

她成为了一个健身房优秀女教练。专业指导怎么举杠铃，拉铁块，仰卧起坐。很多女人健身都是有意切目的的，产后恢复，相亲恋爱，参加比赛，表现为急于求成，有时候会造成一些伤痛。专业人员就会告诉你，如何避免这些问题。一名冷门项目女运动员，只要扩展一下眼光，瞬间成为了大家非常欢迎的女教练，收入也高。
