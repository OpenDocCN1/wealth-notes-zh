# 08

往下走的路最舒服。

我是1998年冬天，替亲戚入手了他们家第一套房子，当时不是住的，而是一个其他的奇怪原因，和找工作有关系。这套房子一直是空关，当时没人要租。年轻人可能不理解，二十年前，没有房租一说，大家觉得借房子住几年，就像亲戚找你家借两万块钱一个感觉，不可能要利息。

当时是十万左右买的，我和房东斗智斗勇一晚后，便宜了五百块。我也很高兴。那个房东被我说了五百块，气的发疯，他老婆一天到晚冷言冷语，把房东恶心坏了。交房的时候，房东想出了一个绝招。他要把门板和室内的水龙头全部带走。我很愤怒。双方谈了一个上午，我又把五百块钱还给他了。

因为亲戚是老家的人，工作单位距离房子有十站路，从来不住，就这样空关了好几年。没多久，亲戚发现这个本木变成40万了，用他股票思维，已经是300个涨停板了，不跑是傻遍了。他已经想好了，有了这几十万，可以潇洒走一回了。我当时恼羞成怒，因为这家亲戚要我继续办手续，收钱打给他，没有给我任何辛苦费。我就没理他，说不会办手续。

那个亲戚是农村人，没见过世面，根本不知道交易中心在哪？一晃二十年拖过去了，不多，现在也就5000个涨停板。
