# 07

放大招，货币分布的不均衡性。你想明白了就可以躺赢。

世界各地，货币如开闸的大坝，哗啦啦的奔涌而出。但是，他们流向哪里是平均的吗？假设，市场上多了一千亿纸币，他们会均摊到每一个商品的价格上吗？不会的。

这是商品的特性决定的。

一是储存性。假如有人告诉你，西瓜菠菜要涨价了，你会不会提前一年买个西瓜，一斤菠菜？不会的。因为西瓜无法储存。

二是辨识性。那我买个翡翠手镯或者金戒指，行不行？也不行。因为这些东西很难鉴别。古代有专门的当铺钱庄负责鉴别，现在不存在了。

三是流通性。我买个股票行不行？股票流动性好！也不行。因为流通性太好，反而是麻烦。市场上绝大多数人都是追涨杀跌的，只要两个涨停板就想跑了去吃烧烤，再和老红来一曲《明明白白我的心》，不跑都睡不着觉。你和这些人玩，就一下场，踩踏。
