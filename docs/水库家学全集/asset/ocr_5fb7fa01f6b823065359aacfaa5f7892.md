# 如何培养出清北当次的孩子?

以前考清北，基本上是自学成才，没人管。大家都没人管，你考一点就脱颖而出。现在，大家都在管，卷大了。

我以前有个女同事，属于大姐的年龄，她女儿考了一个很好的大学。我是亲眼见过他们家是怎么搞的。两口子是双副高。儿子，区重点高中。
