# 01

男人没钱太惨了。

我很喜欢吃一种巧克力，是意大利品牌，但是很贵，一条十元，一口就是五元。我没钱买，就找菜嫂买。那个受气啊。

为了一口吃的，我要苦苦哀求半个小时，不停的赞美她，贬低自己。一般情况下，菜嫂会买两份，一份是给娃娃。我的吃完了，就去找娃娃借一点。娃娃不借，我还要哀求菜嫂去通路子，找娃娃借一点，过过瘾。

结论：男人一定要有私房钱，女人管钱，痛不欲生。

# 02

哪些人是真正的低收入？

以我的经验，认真工作的农民工肯定不是。最有可能的是办公室吹空调的二本子。这些人干活轻松，工资不高，基本没有什么存款。实事求是讲，很多人不愿意赚钱。举例，我在工厂看到，很多二本宁宁愿两三千元一个月，溜明几乎净，节衣缩食，也不愿意去流水线送快递兼拿七八千。
