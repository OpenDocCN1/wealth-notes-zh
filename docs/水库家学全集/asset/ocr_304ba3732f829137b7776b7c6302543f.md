# 新式倒翻门，越来越多了。

不要看不起小店，一个外企妹的华丽转型

我家门口有个面包蛋糕店。小小的店面，晶莹剔透，有伦敦风格，很漂亮。小店主要是卖各种各样的点心，夹心面包，奶油蛋糕之类的。作为一个大老爷们，我本来是不感兴趣的。只不过，我家小娃娃周末在附近上兴趣班，每次上完课就要来吃点东西。

我不喜欢街边传统肉馒头，这玩意，香精多了一点，吃完后，嘴角和手指还会残留浓郁的肉味，久久不能散去，需要洗手液才能除去。附近还有两个选择，一是各种洋快餐，主要是芝士汉堡，二是小的面包蛋糕。我感觉不到有香精。

我家小娃娃就是垫一垫肚子，一般买小小的蛋糕面包。蛋糕面包特别贵，一个夹心面包28元，我最喜欢的肉松面包，小小的，一个6元，8个一盒卖，48元。我家小娃娃最喜欢就是这个肉松面包，一次吃一盒。去的次数多了，老板娘就熟悉了。也我们聊哪家常。有一次，快下班的时候，店里的打工妹扎在盘点结账，突然对老板娘说，“今天还可以，（营业额）8千多”。

我心里一惊。这个店一年的营业收入要达到300万左右。这种蛋糕面包，原材料成本不多的，主要就是店铺和人工工资。我立马开动脑筋算了一下，店铺30，员工成本10，原材料成本20，品牌加盟费20，杂费20，装修要分摊好几年，毛估估一年净收入有200万，惊的我一身冷汗。我就研究这个店为什么生意好。

一是味道很好。这个店，甜的有奶油蛋糕，咸的有肉松面包，都是我特别爱吃的，味道好，非常精致。据老板娘自己炫耀，她每个季度都要去市中心学习新品种，也确实看到每个月有新品种。

二是顾客稳定。主要客户是两类，附近学校或兴趣班的学生，附近小区居民。我经常买他们家的点心，作为夜宵。

三是开拓顾客。附近有个银行网店居然流行下午茶，到她家几十份的买点心，生意好的飞起来。

我一开始很不自信，总觉得我是不是算错了，哪有赚钱的小店？有一次聊天，我故意和老板娘说，你太辛苦了，应该让老公来帮忙。老板娘说，她原来是外企的，后来辞职了。她老公是xx单位的，非常要面子，不同意她站柜，老公一般是早上四点多来做准备工作。至此，我彻底相信我的结论了。因为要让一个xx单位的男人，早上四点多干活，没有这个数是不可能的。

结论：不要小瞧任何小生意，这里面有你想不到的利润。
