# 01

研究成功的人。

很多屌丝看不起成功的人，屌丝会站在高高的山颠，像是发神经一般的评论一下，她就会拍马屁，他就是运气好。实际上，你不要这么狭隘。成功的人一般是两种，优秀的，运气好的。

优秀的再说了，屌丝的小心脏受不了。咱们就说说运气好的。假设这个人单纯就是运气好，要不要研究一下？要。

不管他是怎么成功的，一旦他成功了，就会看到不一样的风景。你某看爸爸，原来就是个二本子，一旦成功了，可以和世界上最厉害的大师对话，可以看到最牛逼的风景，可以听到最厉害的分析。

成功的人周围都是牛人，时间长了，他也就牛了。你尽可能听听这些牛人在想什么，做什么。你也会遇到更多的机会。你那一点点小脑袋仁里，没花头的，无非就是一些骂人的俏皮话。
