# 记忆北京。

二十年前，我在北京生活过，工作过。现在想起来，好像还在眼前。当年，我在一个当单位当小打杂。同事们经常聊 天，最痛苦的是穷。北京西直门房价居然是八干，怎么买得起？幼儿园要三百元，气愤！现在，我还记得同事们欲哭无泪 的样子。
