# 10

高考作文。

高考马上就要来了。时至今日，你宝贝儿子能不能考个好一点的大学？数理化也没办法了，基本就看作文了。作文多个十分八分很正常。要知道，一套985文凭，顶一套省会三居室。

现在的高考题很别扭，基本都是我们当年那一批成续不怎么好的师范生出题的。记得有一年，某高考题作文是，我想到一对隐形的翅膀。我估计你看到就像眼了。这是很正常。因为高考题必须做到一个要求，不能被押题押到。这个题目，培训班的正常人是不可能押题的。所以，你的第一个思想准备是，高考作文题目都是匪夷所思的，你压根想不到的。

你的第二个思想准备是，高考题目都是大的无边无际。隐形的翅膀，这个发散思维就无穷无尽了。农村孩子可以想象到飞到天上撒农药，城里孩子可以想象到上学不用堵车了，我像奥得曼特一样飞到学校去。 但是，你千万不能写这些孩子们的正常思维，因为立意不高。你要想一个阅卷老师最满意的答案。

第三，找到一个立意很高的切入。家长要注意收集重大题材。今年这个事情，很多人都想到了，所以要避开，怎么避开？你想一个更加细小的子类。例如，农民工爸爸在困难中的自强不息。

第四，接线头。立意有了，方向也抓好了，怎么把题目和内容结合起来？那就要接线头。隐形的翅膀和农民工有什么关系？你爸是送快递的，有了隐形的翅膀就可以帮助爸爸多送快递了。

第五，这是单独积分的。你对古诗词的记忆。结合主题，引用一下牛逼的唐诗宋词，单独加三分。
