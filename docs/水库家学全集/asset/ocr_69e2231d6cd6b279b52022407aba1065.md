# 不要对熟人抱有太高的期望值

很多人对熟人抱有很高的期望值，以为熟人会无条件帮你忙，借钱给他，这是不可能的。任何事情都是有成本的，不要指望熟人就不要成本了。就好像熟人开饭庄了，你也不能去白吃。人在社会上就是推销自己，就好比是开店，卖自己的才华，卖自己的人脉，社会上没有白吃的晚餐。

很多人以为，我对你不错，想当年，我帮过你一个什么事情。实际上，熟人想的是，某年，某事情上，我已经还过人情了，你别来烦我。

很多人打开手机通讯录，觉得很多人都是他的关系，轻易不舍得用。实际上，这是你的虚幻。我曾经在大单位，有五六个好朋友，都是十几年交情了。等我离开大单位，人家立马就把我的手机号删除了，我打电话过去，人家还问，你是哪位啊？wokao。

我曾经有个好朋友，关系熟感到可以去他们家吃晚饭的程度。那又怎么样？一旦你离开了原来的位置，人家就觉得你今后没用了，立马就是另外一个嘴脸了。发微信给他，人家不接，不回。你肯定是来找他帮忙的，烦人。实际上，我就是找他聊聊天而已。

还有各种直系亲戚，表面上，关系很好，一旦你离开位子了。借钱，也就是五千封顶，翻脸就翻脸，who怕who。人家还想找你解决困难呢。

年轻人不要多想什么关系网。这玩意极不靠谱，纯粹是心理安慰。

房子买好了伐？
