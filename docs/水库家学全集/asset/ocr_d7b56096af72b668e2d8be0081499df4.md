# 01

奖励自己，展望未来。

如果你家男人五十岁左右了，每家每户都会有的，拼博一辈子，也该调养一下身体了。最好是买个称心如意的大房子，关键是大，面积大。不考虑地段了，也不考虑增值了，就是自己的退休住所。

我的建议是，在上班的方向，买个大郊区房子（不卖的，纯自住）。理由如下：

一是纯自住，必须是面积大。以后，子女来度假。现在郊区打车进城也方便。

二是展望未来。你最少还要活三十年，你老婆可能是四十年。四十年后，现在的郊区，肯定是黄金宝地了。你给子女留下了一个值得骄傲的财富。自己也享受了。还在你负担得起的情况下。一鸭三吃。

这个思路是菜嫂最先提出来的。她看张爱玲小说，说那时候，虹桥是乡下地方，很多人去那里建房子。几十年，斗转星移，一转眼，现在虹桥是中心地带了，如果那里有个祖传大house，现在的子女就嗨翻全场了。

关键是选对大城市。

# 02

地下室和阁楼，有意义吗？

如果你不缺面积，这两个鸡肋，毫无意义。我家地下室有150平米，阁楼有70平米，我从来不去。因为没意义。我正大八经的面积都空了好几个房间，我窜上窜下干嘛呢？

实际上，这两个区域就是储物间，我把菜嫂当年的老照片和棉花被塞到阁楼，地下室就是个通道，出去是地下车库。

为了这两个地方，包括爵士白楼梯，屋顶隔热层，地下室防水，我花了一百多万，现在想想也不值得。

建议：如果不准备长期使用，这两个地方刷白就行了，不要花太多钱！没有实际意义。
