# 07

人际关系是个无底洞，不行就算了吧。

上海有句老话，有事有人，无事无人。意思是，有事求人了，到处巴结。没事的时候，想不起别人。这句话是告诫年轻人，平时多联系能帮忙的人，拎个水果多走动几次，不要临时抱佛脚。

我以前也相信这个逻辑，后来发现，这完全无意义。你在没事的时候要巴结人，你会遇到一个无法解决的难题。巴结谁？你无法预测将来求谁，也就没有方向了。最后还是瞎折腾，到处巴结。你忙的累死累活，春节基本没有休息，实际上人家也没觉得怎么样。有地位的人，来巴结的多了，不多你一个。

屌丝唯一的财富是时间。你把时间浪费在毫无意义的乱踢球上，没有效果的。我有一次去求人打个电话问问情况，人家一听觉得麻烦，直接回绝。这么多年白折腾了。

屌丝要强大，最好的办法是自己有能力，有和人交换的资源。你会小学数学，初中英语，高中数学，都可以。实在不行，让你妈给小头头家接送孩子，连续三年，效果也好。

我建议，屌丝不要把宝贵的时间浪费在毫无意义的人际关系上，没用的。春节提几箱牛奶，跑来跑去，人家当你250。你最好修炼一个技术，实在不行，去搞个中医执照，老头老太最喜欢。
