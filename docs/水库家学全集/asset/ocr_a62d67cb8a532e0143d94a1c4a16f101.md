# 怎么和富人打交道？

现实生活中，一般人很少接触到富人，基本不会和富人打交道。以我的感觉，比较多的是，她（他）拼命炫耀自己，“这个花了多少钱，那个很贵的。我也是见过世面的人，你不要小瞧了我。”这个是错的了。在你眼里的好东西，富人丝毫不感兴趣。

在富人眼里，你就拿出十个亿，我也不感兴趣。贵人同理。遇到贵人，你千万不要说什么，我认识谁谁谁，这个也认识，那个也熟悉。实际上，丝们这么说，内心是想和富贵结交，找个共同话题，但是用错了办法。你这么说结果是，别人不感兴趣，也不想认识你。那怎么结交富朋友呢？很简单。

你要说出，让富贵朋友感兴趣的内容。

一是信息。高级一点的信息是，张三李四家是怎么做生意的，最近怎么样子了？低级一点的是，张三李四家里，男人劈腿了，女人出轨了。因为是大热悉的人，都感兴趣。

二是专业。你是什么专业的，可能富人也需要这个。例如某爸爸高血压，你就说说怎么降血压。张三女的娃成绩不好，你就说说怎么考高分。李爸爸家里缺个保姆，你推荐一下。以此类推。人家觉得你有用。

三是不要自作聪明。有的臭屌丝，为了炫耀自己多聪明，经常语出惊人，讲一个自认为很聪明的，和他没有半毛钱关系的观点，（例如菜菜这个SB），效果往往不好。因为，每个人的想法不一样，你可能会让人不舒服了。关系也就结束了。
