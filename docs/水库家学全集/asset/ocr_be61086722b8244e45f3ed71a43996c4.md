# ### 心随我动。

京沪有一批发了大财的外地大学生（二本居多）。这批人也不是什么大富大贵，也不是才华横溢。基本都是2000年后，骂骂咧咧的进入京沪，结婚买房，生了孩子，把老家的父母叫来帮忙带娃，发现住不下，又买了一套。到了上海发现，人世间居然还有学区房这种奇葩，压压惊。咱们都是考大学翻身的，不能输了，砸锅卖铁也要给儿子再买一套学区房。男不劈腿，女不出轨，两口子平平淡淡二十年，攒下三套房老小，人生大赢家。

我在大单位，见过非常多的这种夫妻。与此相反，很多喜欢斤斤计较，追涨杀跌的聪明人，往往错失机会，成为彻底的岁月卢瑟。

他们就是我的同龄人，我就问他们，你们当年为啥眼光这么好？她们的回答惊人的一致。我们都是化学系毕业的，哪里懂什么经济。我们就一个想法，啥啥实验，没想过占便宜，也没想过精确抄底。我们没那个水平，就是根据人性的需求走。

我顿时想通了。人都要顺势而为。十年后，会发生什么？无非是小地方的人进城而已。我就提前打个桩钓鱼。心随我动，爱谁谁！
