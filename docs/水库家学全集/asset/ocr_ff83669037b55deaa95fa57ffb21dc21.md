# 赚钱的第一步是有单子做。

给丝终们普及一个财富知识。无论听上去多么高大上的生意，**99.9%**都是成熟技术模式，并不需要你有什么独门利器。如果有个老师教你，基本是三天就行了。举例，曾经很赚钱的莓老板，有几个技术？无非是买一大堆设备。再说服务业，服务业最牛逼的是开银行了，那又怎么样？以前都是技校小中专在干，他们现在也在支行里，人五人六，当头了。

说来话去，生意本身的技术含量是有限的，而且也不难，你又不是要当紫砂壶工艺大师。各种生意要想做起来，关键是有人给你单子。举例，现在装修公司很赚钱。装修本身是不难的，最难的拉单子。我可以很明确的告诉你，任何一个小区，拉单子的业务员比贴瓷砖的还多。

前不久，我装修了一个房子，我发现了一个有趣的现象。交房时，小区大门口，一字排开十几家装修公司。千挑万选几个月后，施工队进场了，我是目瞪口呆。每个环节真正干活的其实就那么几个人。贴砖的有两三拨，出垃圾的有两三拨，以此类推。所有的装修公司就是拉单子，给你画饼，有矛盾就负责吵架的。

这说明一个问题，生意最重要的事情是，有生意做。那么，怎么才能获得大家的信任感？无非是两个，一是砸钱，二是做人。砸钱是个无底洞。举例，你搞个超豪华的办公楼，按照毛利率**0.5%**来做，你就有生意了。但是，这毫无意义可言。你的出发点不是杨白劳。另外一个就是做人了。
