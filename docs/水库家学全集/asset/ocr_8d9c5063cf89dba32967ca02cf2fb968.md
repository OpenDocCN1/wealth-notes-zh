# 菜嫂的业余爱好：买房。我的业余爱好：死皮赖脸加名字。

原创 菜结小编 财上海微博 2020-01-30

409. 致敬东京房价。近来，很多人喜欢拿东京房价过山车，来预测京沪也可能会跌。我不懂日本，请教日本通：中国和日本，在哪个领域有相似性？实在是想不明白。

410. 如果有人从你银行卡上划走了五十万，你会不会说：反正是放在银行里的纸面财富，无所谓。房价同理。房价下跌的后果是，必须要有人负责。我肯定回家打老婆，你会找谁的麻烦？

411. 楼市秘密小 tips。开发商卖房，都是从小区最差的位置开始卖，越卖越好，越卖越贵。所以你记住，如果一个小区，第三次开盘如果不涨价，实际就是降价了。浦东正大家园，第一次开盘当天，我同学买了，三千元不到，最后一期大概是一万五千元，现在近三万了吧？

412. 解放前的房价。主席在北大图书馆月薪 8 个银元。与此同时，上海一个市区别墅，15 万银元。张爱玲小说对当时物价有描写，所以，不是房价贵，而是你不应该去想那些和你没关系的事情，你也不看看你的家世，这是你想该的事情吗？还是回乡下去，建设新农村吧。那里空气好，无雾霾。土鸡土菜土肥圆，多好啊！

413. 居丝要记住。在你背后说坏话的，和你抢老破小的，和你抢土肥圆的，给你妈开大处方的，给你爹卖保健品的，卡着你居住证的，和你在地铁上争位置的，还真不是房东。你今后的人生，就是和这些人纠缠一辈子。你努力啊。房东没时间和你对骂。我去买菜了。

414. 大家都懂的。//《蓝鲸财经记者工作平台:【陕西一足浴店曝行贿账单 涉多个政府部门】》最近，网上曝出了咸阳一家足浴店的行贿账单。据悉，上面详细的记录着送礼的单位名称和人员职务，涉及治安大队、消防大队、辖区某派出所以及工商、卫生等多个部门和人员。根据职位不同，送礼的金额也有区别。（西部网）

415. 希望在北京的外地人不要这样的：有好处就来了，没好处就跑，还要骂几句。//@贾樟柯:雾霾，下决心搬离北京。

416. 我看不起贾樟柯。贾的老家是山西临汾，从小就是在煤灰里长大的，现在高贵了，居然嫌弃雾霾。贾看不起山西，跑到北京混，然后把搞各种各样描绘北方人阴暗面的电影，跑到国际上去获奖。你以为你很牛？我操，我告诉你，只要是丑化中国电影小说剧本摄影照片，统统可以获国际奖，我最反感就是这种货。

417. 我最看得起的女演员，孙俪。从无绯闻，从不卖笑，完全靠本事吃饭，长得也一般，能够在影视圈这个是非窝里，混成这个地位，很不容易了。比较遗憾的是，上海姑娘嫁到外地去了。

418. 孙俪这个长相，在上海姑娘里算中上，可爱型，和漂亮无关，能够在年级排个前十名的水平。和校花，那是一毛钱关系也没有。

419. 凡是來借钱的穷朋友同学，你可以一律拉黑了。一个人，工作好几年了，还好意思向人借钱，说明银行卡已经刷爆了，那基本是不要脸的垃圾了，你这辈子都不必搭理他了。

420. 我可以说一下我工作 20 年的经验。年轻时，喜欢找朋友借钱的人，现在基本是没有自尊心的垃圾。那些从不找人借钱
