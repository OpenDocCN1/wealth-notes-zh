# 一个家族要想翻起来需要多久？

欧洲有种说法“三代出贵族”，我们的说法是“穷不过三代”。现代人不能有这种老观念了。但是，普通人家，三代人的时间估算，足以改变太多太多的事情。以我家举例，

第一代是抗日前到了内环线，一开始比较难。住的是竹房，你可能不知道什么是竹子房，我给你简单说一下。就是不用木头，直接用最便宜的竹子，搭出房子骨架，用泥巴块垒起来，室内是泥巴。一到下雨天，室内蚂蚁小虫子比较多。第一代因为各种原因，啥也没留下，就拿到了两个东西，户口和一个泥巴房。

本来混出来了，又遇到后来的一些变化，又没东西了。

第二代长大后，没有工作，基本去了乡下，插队，或者万人大厂。第二代也没留下没有什么东西，只不过，保证了孩子能够吃饱穿暖有书念。

第三代，就是我这一代，由于考试认真，考上了985，但也是两手空空，小光棍一条，到了市中心。一咬牙，一跺脚，发挥祖传技术，倒插门，娶了个媳妇。那时候遇到了时代红利，拆迁妖地都是，好单位不计其数。

第四代，我家娃娃算是混好了。

小结，不要急，认认真真熬。总有红利的。当然，倒插门也是有门槛的。
