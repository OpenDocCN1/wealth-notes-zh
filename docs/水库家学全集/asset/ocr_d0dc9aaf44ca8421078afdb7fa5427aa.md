# 不要急，慢慢来

今天和Q一个省城事业单位的小头头聊天，我非常意外的听到了中产的烦恼，孩子成绩。他们单位在外地属于特别好的单位，招聘都是985，211，年入二十几万打底，办公室里研究生比本科生还多。照道理这种单位是非常好的，员工应该很幸福，实际恰恰相反。

他们单位每年都有几个女研究生辞职的，就为了回家带娃考试。这事雷打中了中产的软肋，家庭传承。中产最大的问题不一定是房子，而是孩子。如果孩子不行，长大没有一个好单位，中产就断线了，退休后，生活没什么新突破了。而且，在人生大事方面，中产家长基本上帮不上孩子什么忙，包括婚姻，买房，就业，下一代可能一夜回到最底层。要想突围，唯一的办法就是考学。

我们现在的教育考试，纯粹是脑筋急转弯。孩子们比较惨，一天到晚学那个著名网课。家长们省吃俭用，日子过得一笔吊槽。有对夫妻，两口子都在好单位，年入50，这个女人十年没有自费旅游过，三年不买新大衣，家里装修也是草草了事，就是对自己十分苛刻，千方百计省钱，节约出来的钱，基本都交给各种各样辅导班了。想想真是欲哭无泪。

孩子也倒霉，一天到晚补习班的干活，每天写作业到深夜。两口子因为承受了太大的压力，脾气暴躁，经常揍娃。女的四十多看上去像是五十几岁的样子。那个孩子好像已经性格扭曲了，爸妈打他，他从来不哭。

我听完后，感到了很难过。我们小时候，不好上大学，还可以托人找个不错的单位上班，现在不可能了。我有几个感受给大家参考，

+   一是孩子能读就读，实在不行就算了。

+   二是争取学一个技术。发达国家的泥瓦匠，理发店托尼收入比教授不差。

+   三是早点给娃买个小房子，孩子以后有条件可以置换，没条件就凑合一下，至少能够找个老婆。

+   四是丈母娘不要再逼男方买房子了。公婆也不容易。

+   五是丈母娘要拎的清，以后大城市女多男少。我们还不一定你家姑娘！

想清楚，看明白，不要太累了。
