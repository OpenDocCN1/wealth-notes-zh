# 逆袭

我上一辈或者再上一辈也有很多牛人家庭，但是现在一半败了家。我仔细研究过他们的败家原因，往往是房子。

牛人有个特点，什么都不用操心，都有人帮忙处理。买房置业是个超级麻烦的事情，必须事必躬亲，自己处理。很多牛人有所谓的大住宅，也就不考虑买房了。但是，一旦他们挂了，房子就没 了。后面几代人就不一定舒服了。

做买卖开店，竞争激烈，往往是好三年，差三年，时间长了，也就归于平淡了，做成上市公司的极少，绝大多数人都是白折腾一辈子。但是，如果买了房子，子女往往舒服很多。
