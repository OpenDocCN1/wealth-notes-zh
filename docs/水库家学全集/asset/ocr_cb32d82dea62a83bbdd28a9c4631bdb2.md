# 03

为什么合伙都是悲剧？

我经商这么多年，一直是独行侠，从来不合伙。因为我我看多了合伙悲剧。合伙是必然出问题的。因为人性。

赚钱的时候，合伙也会吵架。一部分人想年底分钱，老婆还等着买房。一部分股东想做太大，千载难逢的机会，要做行业前三名。吵的一塌糊涂。如果后来不赚钱了，那简直变成仇家了。

亏钱的时候，那是天天吵架。因为合伙的目的就是赚钱，现在亏了，心里那个恼火啊。分析亏钱的原因，又会出现互相甩锅的局面，指责其他人没有尽力。技术副总不得力，销售副总垃圾，总经理没有后续资金，就是没有担当。我们被骗了。反正就是天天吵架。
