# 06

对孩子的期望。

我现在也有孩子了，也在思考这个问题。我回顾自己的人生，发现一个有趣的事情，所有的亲戚朋友，都希望你成为一个头头，而不是一个快乐的富人。我现在过得很好，但对我很热情的亲戚朋友已经不多了，以前我还在单位里的时候，他们对我是非常热情的。他们看我就像是在看一个潜力股。

原因很简单。你多有钱，也不会给我花，我们懒得应酬你。如果你是个头头，那就不一样了，你可以给很多人帮上忙。这个事情在老头老太群里是重量级的存在，即使你只是个大单位里的小板凳，即使帮不上忙，也是一种炫耀的谈资。回弄堂口，回村里，一说我家侄儿在市里省里上班，那绝对是吃席上主桌的待遇。于是，所有人都希望自家的儿，亲戚家的侄，去大单位里上班。万一光荣接班呢？

小结，不要太轻信亲人们的话，他们想法多着呢！
