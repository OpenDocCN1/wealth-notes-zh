# 10

代持矛盾。

一个简单的道理，超过一百万的利益，足以引发兄弟反目。我今天讲一个兄弟反目的故事。是我听来的。

十年前，哥哥有钱无资格，弟弟有资格无钱。一顿小酒后，双方同意，哥哥买后自用，弟弟出一个名字。那个房子也不大，大概是80平米左右，内环线。十年之后，利益多了600w，于是大家想法不一样了。

哥哥的意思是，过户费很高，节约一点。等自己孩子大学毕业拿到资格再过户，一步到位，所以拖了十年。弟弟的意思是，我孩子也买不起房子了，你当哥哥的条件好，就当赞助我一把，把房子原价给我算了。哥哥儿子拿到资格，弟弟拒绝过户，矛盾爆发了。后来，打官司了。

哥哥说，自己买的，协议，发票，转账单，一应俱全。

弟弟说，是找哥哥借钱买的。协议是原来想帮哥哥代买而写的，后来是自己买，协议就没落实，应该算作废了。

事情折折腾了好几年。我的意思是，代持是个很麻烦的事。人心会变的。尽可能自己搞定。

为什么大学文凭不值钱了？货不对版。
