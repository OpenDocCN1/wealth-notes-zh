# 你倒闭过几次？

我倒闭过两次，都是春节过年前。第一次倒闭是我赊账太厉害，收不回资金，直接挂掉了。第二次是卖不掉货。倒闭后，对我心理伤害最大的是人心。平时，我和员工关系不错，有说有笑的，一旦倒闭，员工立马大吵大闹。有一个人还给所有的供应商打电话，让他们抓紧过来搬家具搬机器。我只想按照正规方法补偿，但是员工们的算法千奇百怪，大大超过了预期，我不能接受，也无力承担，特别是些老油子，于是上演撕破脸，我实在是郁闷至极。

我没有跑路，因为我有房子，跑不了。
