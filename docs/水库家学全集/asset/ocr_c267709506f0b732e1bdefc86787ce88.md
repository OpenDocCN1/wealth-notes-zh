培养孩子，最重要的是考试

我孩子也读书了。家里有钱，菜嫂就开始飘飘然了，一口气报了近十万的兴趣班。

+   1. 骑马，3-4万
2. 拳击，1万
3. 歌舞，2万
4. 吹啦弹唱美术，2万
5. 游泳跳绳，1万

兴趣班请的都是名师，这个是全国一等奖，那个是奥运选手，反正你会觉得不去就是遗憾。每到周末，娃就很高兴。因为可以出去玩玩了。现在的兴趣班，采用的是引诱式，想出了很多让孩子喜欢的办法，例如当场发礼物，发现金，发奖品。我家娃娃还有好几个全国一等奖，各种各样金灿灿的金牌，可以拿到学校里，幼儿园里炫耀。

兴趣班上完了，菜嫂还要带娃去大吃一顿，各种各样的豪华餐厅，例如几百元一份的龙虾饭，半只整的大龙虾（半斤左右），还有各种各样的游乐园，娃娃机，把娃乐的直叫。

我家就是这么个氛围。如果我敢于跳出来反对，菜嫂立马冲上来就是一顿拳打脚踢。菜嫂的名言是，我花的是自己的钱，凶的不得了。

我家孩子考试特别好，经常是年级第一。我就把小秘密说了吧。现在的学校也偷偷，孩子的小考试卷子基本都是买的，印刷本，每次考，就撕一张下来给娃。你只要找到这些卷子的出处，肯定是满分。我和菜嫂就在学校附近的文具店，复印店，买了各种各样的卷子，谁来都是一百分。

但是，我们家这种高法，肯定是不行的。孩子的精力有限，玩多了，就没力气写作业了。如果以后买不到卷子，那就完了。

小结，

+   1. 学校附近文具店，复印店，是个宝藏生意。
2. 孩子不要把太多的精力放在兴趣班。
3. 家长不能偷懒，要老老实实教育娃
