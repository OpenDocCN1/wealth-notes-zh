# ## 我在海南去过好几个春节，已经彻底不感兴趣了。

财上微博    2021-06-26

### 01

我去过海南很多次。

三亚去的多一点。我当时住在大东海，是个挺漂亮的小区。春秋冬，都去过。夏天不敢去。我第一次去海南，那是五月份，当时，我的第一反应是想回家，太热了，而且是热的浑身无力的那种感觉。

海南最美的冬天，适合度假，其他的不感兴趣。我去过海口的免税店，就买了一点巧克力，给娃吃的。免税店里，主要有几个大项商品，

+   1. 二三线品牌的化妆品（没有大牌），香水特别多，估计占一半。实际上，我们的妇女也不怎么用香水。
2. 巧克力多。
3. 手表。我对手表也不感兴趣。

购买手续比较奇特，需要你出示机票信息和身份证。实际上，如果买日常用品，也便宜不了几块钱。因为都是进口商品，价格本身也不低。我印象中，好像巧克力花了五十几元，便宜了十元左右（记不清了）。

一般没有热门商品，没有lamer，苹果手机。

这次参观，给我的感觉是，毫无兴趣。

我的个人观点是，海南最好的经济项目应该是发展度假产业。海南有一个得天独厚的冬季热带资源，大家都喜欢，你搞好就行了。

现在的海南，海边的度假小区附近基本没有什么商业配套，业主们一天到晚就在厨房里干活。交通也不行，主要就是靠业主的私家车。去一次附近的集镇就像是过节了。
