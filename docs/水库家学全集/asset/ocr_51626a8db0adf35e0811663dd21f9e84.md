# 我们都是路人乙。

# 01

逆袭，袭的什么？

很多人以为，买房买车，老婆漂亮，就是逆袭了。实际上不是的。逆袭不是你有什么，而是你的社会排名。乾隆爷也用不上电灯泡，你用上了，就是逆袭吗？吗你个头。

真正的逆袭是社会排名。每年大城市有20万套新房子出售，其中1000万以上的，有9百套，你心里没点数嘛？

+   - **热门评论**:
  - **neOnlights**: 那三本考上世界前十大学ucl也不算逆袭吗
  - **袁伯伯呐**: 有道理呀。你特么的
  - **可达鸭爱果冻**: 一年300套肯定不止 我是18年买的一手房 我们小区都是千万以上的 光我们小区就300多套呢
  - **外贸小诸葛**: 这个得靠命，什么是命？投胎水平！
  - **北京高生**: 高考也是一样，重要的不是分数的绝对值，重要的是省内排名。由于普通人的主要资产就是房子，所以用房子多少，房子在哪里来衡量社会排名，大差不离。
