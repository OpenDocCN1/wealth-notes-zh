# 01

向上的路，怎么走？多走一步，是一步。

对于绝大多数人而言，向上的路太难算了。你让我怎么走？老子现在一个月，到手万把块，我怎么可能买得起大平层？

你不能因为做不成而不做了。你做不成的原因是上一代没有给你积累，你希望下一代也这样吗？

有人家里拆了好几套，村里也有其他人家拆的少。区别就在于，你家原来有啥情况。这是一代又一代人积累的过程。前人栽树，后人乘凉。很多事情，不一定在你手里开花结果，但是你要起个好头。

说了一大堆，我该怎么办？很简单，你有多少能力做多少事情。你买不起大平层，能不能谈个小户型？多一平米也是好的，多少给娃留点东西。

# 02

人抬人。

一个人到退休金攒多少钱？以90后为例，如果省吃俭用买面积，到了退休的时候，大概有5~800w。最后，你抽出100，回小县城买个二居室，剩下400~700给娃，再加个985，那你家娃就是这条街最靓的崽。道理容易懂，但是，做得到的人有几个？

我已经这么做了。还可以，不算痛苦，中年妇女基本接受这个方案。以时间换空间。咱们没完：你今天虐了我，我让下一代虐你娃。其实，说来说去还是几个字，

荫读传家。哇，一口老血吐在手机上。
