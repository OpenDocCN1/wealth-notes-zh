# 04

填志愿。211其实也不错。

我在心里，压根对211不感兴趣。985合计是39个，211一共有112个（包括全部985）。从这个数字你就可以看出，985相当于一线，211相当于省会。一本相当于地级市，二本相当于县城。大专相当于乡镇商品粮。985的比例，大概是两个班出一个，211是一个班出两个。班级前三名就这样了。

985内部也分个高低。一是普遍公认，例如清北复交，二是省内公认，例如浙大，北航。以我多年的观察，985一般不作为招聘的单独要求。我从来没有听说哪个大单位只要985的，最苛刻的要求，也是211和985并列。985的最大优势是在竞争激烈，多选一的时候，增加印象分。特别是在以学术技能为主的单位，例如科研院校，码农工厂。

211实际上也不差。一般是普通高中班级前三名的存在。我的意思是，填志愿的时候，不要一根筋，

一是冲稳保，三步走。

冲，是指如果你超级发挥，例如作文多了10分，是否能够到浙大，华师大这样的985。

稳，是指正常发挥，你大概是哪个档次？例如北航北邮。

保，是指发挥不够，作文少了5分，咱啥的选择题没蒙上，那么就要一个保了。我建议整个本省211保底。例如，上大可以考虑。

二是平行志愿（欢迎补充）。这是个新概念，家长基本不理解。简单讲就是，你写的所有志愿，通通当做第一志愿，分数够得到哪个学校，档案就按照第一志愿待遇送哪个学校。但是，还要注意冲稳保。因为你先送过去的学校没录取你，再退回 来，其他学校已经满了，你就滑档了。

三是滑档的意思。你的分数是一批次（985，211，一本），但是，你报的大学已经满了，都没要你，你又不服从调剂，就滑到第二档了（基本是二本）。相当于高中白读了。

四是服从调剂。我的建议是两步走，学校专业可以不服从调剂。现在的大学专业实在是太多了。你是文艺小清新，给你调剂到数学系，你这四年可咋过？二是各批次的大学调剂，强烈建议同意。因为滑档实在是太可惜了，除非你想复读。

五是大专高职要不要报？可以不报。有钱的复读，没钱的上班。
