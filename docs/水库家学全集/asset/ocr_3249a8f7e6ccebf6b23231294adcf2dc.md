# 04

很多人把高考捧到天上去了。

我是70后，也是高考的受益者。我一直在想，高考的作用就那么大？我仔细回忆了我们当年高考，实际上是，多重原因的。

一是有路子家庭也没没办法。他们基本不能影响大学招生。我知道一个很厉害的人，儿子没考上大学，就真的就没办法，后来去了一个技校。

二是富二代也没办法。那时候，不流行辅导班，完全看天赋。家长真有钱也没办法。那时候的教师，也对补课不感兴趣，毕竟要考虑单位名声。

三是机会多。我们工作后，各种各样的公司太多了，都在疯狂招聘，特别是一些外企。

四是青黄不接。我们进单位的时候，单位本科率不足10%，专业对口的本科率，5%不到，老师们基本都是职工业余大学毕业的大专生。那时候，大单位为了提高大学生比例，已经到了求贤若渴的程度。你们不要笑。我们当年，每个单位都有个单位简介，其中最显眼的位置是本科率占多少？一般单位也就5-8%，其中还有很多是因为各种各种原因调入的，例如食品公司的中文系本科职工，真正食品专业的也就1%。

我们这一批人到了四十岁左右，80%以上都混了个不错的位子。

为什么炒股的人基本都是输？

我家周围，近30年，有很多很多炒股的人，特别是喜欢打麻将的聪明人，期间也有几个赚钱的。但是，这么多年过去了，没一个人真的因为炒股发财。为什么？炒股的人，分为两种。

一是上来就输钱的。这种人输的不多，一般两三万，和老婆打一架后，也就金盆洗手了，就当买个教训了。
