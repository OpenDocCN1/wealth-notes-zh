# 我的破案过程。

一是看房本，百分之百是有民间借贷抵押的房子。

二是看价格。一般情况下，房东只要现金。价格低于市场价三分之一。但是首付要求很高，他们急于拿钱。最后能不能给你房子，另说吧。老夫今天累了，你随便吧！

三看门框，一般都有补漆痕迹，我怀疑是追讨债务纠纷留下的。

四看房东姓名。我把房东姓名输入法院文书公告系统（公开信息），立马就知道这家欠了人家多少钱了。
