# 如何保住女儿幸福？

财上海微博 2021-03-17

# 01

农村孩子在目前的考试机制下是吃亏的。

我最近通过保姆一个个细问，基本知道了她们村的孩子考试情况。大多数不是很理想。咱们首先要承认一个事实。农村中小学生，完全靠自觉性成为尖子生的不多，主要功夫还是靠家长督促和后勤保障。

目前，绝大多数农村青壮年是在外打工，农村孩子扔给爷爷奶奶奶奶外公外婆。老年人能够做到的，主要是吃饱穿暖不受伤，真管不了孩子考试成绩。昨天，菜嫂拿着一年级的数学题发呆，题目是，多画两条线，拼出几个相同的三角形。

这是一年级的数学题啊！菜嫂想来想去，实在是没办法。最后搜索栏解决。你说一个大学毕业的中年妇女都不会做一年级的题，你上农村老年人怎么辅导？

现在，我们不要太指望农村学校的老师了，一个班级四十个人，你说怎么弄？在这种情况下，农村孩子会出现成绩分化。小部分天碧卓越的孩子，自学成才。另外一部分是拿到身份证就不读了，去沿海电子厂拧螺丝了。城里的孩子不一样。他们可以通过家教补习班解决问题。农村老太太能不能帮助孩子学英语？基本不可能。城里的孩子可以花钱解决。

我的观点是，不要在中小学阶段就把农村孩子甩下，尽可能给他们一个直接上大学的会。现在二本也不是什么山珍海味了，给他就给他了，也没什么。

# 02

农村小学是怎么祸弄娃的？

我家娃比较惨，两个985盯着整，也不一定能够双百分。我家保姆说，我孙儿，一年级，没人管，门门一百分。我顿时觉得，我是不是上了个假的985？

因为我实在是忍不住好奇，我就让保姆回家的时候，把她孙儿的卷子拍个照给我看看。看完之后，我傻眼了。

农村小学一年级的数学题是，2+6=？

城里小学一年级的数学题是，加两条线，找出六个相同的三角形。

我心里有点难过，这些娃以后怎么办，再去拧螺丝吗？
