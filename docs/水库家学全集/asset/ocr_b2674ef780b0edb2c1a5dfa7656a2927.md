# 爱我，就给我加名字。

头婚对女性是一种非常残忍的赌博，女方头婚的年龄大概是二十几岁，一般只看男方颜值，会不会打篮球唱歌，女方还不太懂人心险恶。女方不知道眼前这货色，十年后会不会是否烂泥一滩，也不知道他婚后会不会抛弃大房，所以，中国古代采取了一个保护妇女的办法，交押金（彩礼）。古代彩礼的金额一般是巨大的，大到男方基本无法承受的地步。目的是让男方珍惜好不容易娶回来的胖花，不要打老婆，消灭了男方再娶（再交押金）的能力，同时明确了一般不得离婚的风俗，极大的保护了妇女。

现在所谓的取消彩礼，离婚自由，实际上是对女性不利的，本质上是取消了对男方的经济束缚，在大城市，只要男方有房有车，离就离，下一个更漂亮。女方处于极其不利的境界，甚至离婚后面，无家可归，流离失所，被迫急吼吼找嫁。

加名字其实是对男方的一种束缚。天底下没有白吃的饭，也没有白用的女人。年轻时候，让男人舒服了，不是白用的，必须一辈子管到底，想离婚，房子分一半作为补偿金。在这种情况下，绝大多数男方担心经济吃亏，就不敢离婚了。女方也有了一定保障。

这里面有个经济漏洞，如果女方先偷人，男方就吃亏了，怎么办?
古代是沉猪，现在没了。事实上，女方事先劈腿的情况不多。绝大部分女人是不会先劈腿的。世界上没有完美无瑕的方案。既然你喜欢这个人，也就要有信心，不要想多了。

不加名字，就是男方一家门认为女方是荡妇，很快会偷人，生怕男方经济吃亏了。既然防着我，那你给老娘滚！
