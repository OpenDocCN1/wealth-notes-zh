# 08

业主奇葩多。

我曾经买过一套欧式别墅。整个小区都是欧式风格，大开发商品牌，看上去很漂亮。我的一个邻居，买了一对石狮子放在门口，一大堆造型盆景占满院子，我差点笑的昏过去。

还有一个业主，开盘桑城出身，对浴缸有独特爱好，把地下室改造成为了一个大澡堂子，说是给孩子练习游泳。我看了差点晕倒。

还有一个业主，用奥特曼大理石贴满全部墙壁，我以为进了装修城展厅。

还有一个业主想把墙壁油漆一个淡黄色，结果最后变成了正黄色，像是吃斋的地方，算了不说了。

还有个业主，院子仿造拙政园，还有太湖石，在室内搞了一个北京街头的蓝砖，蒙元王朝风格，我以为进了北海小公园。

我家里穷，就买了一点爵士白大理石铺在地面，其他刷大白，简简单单不搁怪了。
