# 中介的市场有多大？

具体不清楚。我就说一下我熟悉的一个小区。大概一千户，估计有10%的出租，也就一百户。一户的中介费大概是五千到八千，至少就是40-50万中介费了。还有1~5%的买卖！这个很清楚，只要是买卖，一般会装修，一眼就知道了，买卖的中介费是2.7%，一户15-30万，大概有二三百万的中介费。
