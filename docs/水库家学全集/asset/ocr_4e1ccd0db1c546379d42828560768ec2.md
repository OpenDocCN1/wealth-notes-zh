# 1998年房价贵不贵?

现在你肯定会说不贵, 徐家汇最好的地段, 60-70万一套三居室, 首付2成十几万。但是, 当年是什么情况? 当时认为贵的离谱了。因为那时候, 绝大部分人的工资两千多, 存款微乎其微。如果一个家庭去买这种房子, 会被大家认为脑子坏了, 就想出风头, 所有人和他实质性绝交(不发生经济往来), 因为这种人太要面子, 做事不靠谱的。

这么多年, 理论界有一个学术难点, 一般工薪族工资和房价, 到底有没有关系? 县城现在一套房上百万, 你说有没有关系? 我的看法是, 买房和中低收入家庭没关系, 和家庭年收入top10%有关系。绝大多数漂亮小区不是给上班族的。上班族应该去看廉租房, 租赁房。

漂亮小区和你没关系, 你就不要操心富人买房了。

丈母娘也要实事求是! 我家闺女也不是什么沉鱼落雁, 万里挑一, 你就不要胡思乱想什么高级小区和地下车库了, 有个老破小婚房也可以了, 毕竟你家也是弄堂小户, 老破小的几十年常住客, 凭什么胡思乱想? 

结论: 任何时期, 大城市买房都是很苦恼的, 包括一百年前。有条件的, 抓紧搞一个房子, 基本能够应付三代人, 否则, 你可能就会每天在微博上骂骂咧咧的, 搞得全家心烦。
