# **12**

考上大学了。

家里另一个保姆告诉我，他儿子考上广东某三本了，专业特别好，我问她是什么专业？她说就是毕业了当老板的专业。我明白了。

估计是企业管理。我实在不明白，这些屌丝大学为什么开这种专业？不能脚踏实地干点正经事情吗？我们初中毕业分流的时候，有几个屌丝实在学不了什么了，去某技校当“饭乌龟”，就是炒菜打饭的。碰巧，我还去看过。他们在食堂里切肉丝！食堂后厨，臭味特别大。当时我还很同情他们。

这几年听说，他们都混的很好。有人在五星级大酒店当主厨，月入五万，老婆吃的又白又胖。有的还上电视了，圈粉无数。还有的去日韩或各地唐人街了，在当地混的风生水起，还有留学生姑娘要嫁给他。我尼玛的，你都四十岁，还好意思啃嫩草？我日。
