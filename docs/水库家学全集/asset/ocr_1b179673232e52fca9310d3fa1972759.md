# 有很多人，潜力是你无法想象的。

财上海微博 2021-05-08

01

今后赚钱的思路。

制造业已经越来越难搞了。如果哪个东西好卖，某宝会呼啦啦出来一大堆，最后互相杀价，杀到大家都不赚钱，我挣个❤️也高兴，就是看不得你高兴。造成这个现象的原因有两个，一是低技术，二是工业化。突围的赛道有几个，

一是高科技。这跟你没关系，你连二本都困难。

二是个性化。每个人的需求是不同的，我要补课老师，你要内科医生，他要养老床位，你要拿个性化的东西，就可以卖个好价钱。我也有烦心事。院子沉降了，漂漂亮亮的花岗岩地面出现了一个上下差距几厘米的大裂缝。这能修吗？

三是干别人不想干的，例如送外卖一个月也有八千了。

02

有很多人，潜力是你无法想象的。

曾经一次，我的销售总监辞职了，我从营业员里找了个最空闲的中年大叔顶了一阵子，我的想法是，等我找一个牛逼的人来就换了。但是，转来转去没有合适的。就在这两个月中，那个油腻大叔居然把公司销售部管的井井有条，我实在是非常诧异。

招聘，往往是看你以前干什么，再聊聊天，看对不对脾气。这就把可能的人才埋没了。后来，这个油腻大叔，从入月三千，干到了年入百万，一群老板抢着要挖人。我问他怎么回事。他说，遇到这样的机会，他发了疯一样工作，把每天的经营资料背下来，每天晚上一店一店复盘，研究问题所在。还发明了很多小技巧。举例，

我们以前销售奖励是给店长的，实际上没用，店长老是老一套干活，只不过增加了一点点小甜头，他就把销售奖励直接发给了营业员，一下子爆单了，营业员发了疯一样干活。

如何用好员工，真的是一个大学问。我一直在想，如果没有那次巧合，这个还有十几年就退休的油腻男会是怎么样的人生。不敢想象。
