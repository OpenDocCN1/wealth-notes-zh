# 05

住在乡下大宅院的感觉。

现在的生活越来越先进，地暖，保姆，一应俱全。

这种大宅院是不能增值的，因为接盘侠少，很难卖掉。当时我的想法是，就当个度假房，逢年过节去住住，没想到春节前去了之后，一直住，没走。

一是舒服。有地暖，不冷。有保姆，不累，春节期间保姆一天七百，费用高。

二是孩子比较开心。房子大，优点多。各玩各的不干扰。孩子在院子里打羽毛球，在地下室打乒乓球，在地下室唱k，随意。

三是老头老太比较开心。乡下空气好，绿化多，阳光好。我这么多年第一次看到夜空里的星星，简直无法相信。

四是网购到达。日常生活不是问题。青菜，牙刷都有卖。

缺点1，个性化购物不方便。我想买个小凳子，坐在院子里晒太阳，市区到处都有卖的，郊区没有。

2，狗叫多。市区养狗一般在屋内，干扰小，郊区到处是狗，很可怕。

3，昆虫多。这几天太阳好，昆虫都出来了。屋子里飞进来一只蜜蜂，吓得我浑身发抖。

4，别墅间距太近，对面干扰大一点。

买郊区别墅不可能获利，也不可能炒作，接盘侠不会买这种房子，就图个开心，心情好。
