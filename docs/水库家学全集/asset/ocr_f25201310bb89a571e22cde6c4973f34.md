# 05

房子是怎么定价的？

房子肯定和成本无关。举例，你在三十年前零成本，单位分的房子，现在市场价是380万，你会以成本价卖掉吗？不可能的。

房子和租金无关。商品房和办公楼，外观差不多，单位租金差不多，但是价格差一半。
