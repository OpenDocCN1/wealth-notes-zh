# 02

不要给老公买豪车。

丈母娘说，我每天开个一百多万的小破车，不利于事业发展，要给我换个宾利。实际上是丈母娘想回村里显摆一下。她们家一直是外环线乡下人。我觉得也是好事。没想到，菜嫂跳出来把事情搅了。

菜嫂的意思是，我开个豪车，会有小美白误以为我是有钱人，产生错觉。什么叫误以为，看不起人吗？我钱包里也有几千块的。再说了，我偶尔占点便宜不行吗？又不是天天占便宜！要你管？怪伐？

# 03

你小时候的梦想是什么？

我的梦想就是，天天可以吃方便面。坐标，八十年代的外环线。你可能不知道，我们小时候吃一次方便面是多大的事情！那时候，还不叫方便面，叫快煮面。我非常清楚的记得是五毛钱一袋，只有一个味精调料包，没有牛油之类的。

那时候，刀鱼也就三到五元一斤，五毛钱可以买三袋话梅，是大钱了。我平时是吃不到方便面的，只有逢年过节可以吃一次，简直是人间美味。一家煮面，一个楼的邻居都可以闻到味道。
