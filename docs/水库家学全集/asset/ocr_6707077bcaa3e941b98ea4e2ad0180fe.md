如何让村花对这个大叔死心塌地？很简单，帮助村花完成一个梦想。

村花的梦想是什么？大多数是两个，面子，或安全感。

面子不一定是钱，也可能是地位。有些村花看上了大叔的地位，倍有面，村长都会提两瓶酒来她们家客气几句。

安全感就是钱。女人的好日子也不多。就那么十年八年。如果不能在这十年八年里找到一个锚，那就麻烦了。加名字，你看加几套？

每个女人都是村花，她们心里都有一个你想不到的梦想。

# 05

女人和男人的思维差异。

我家门口有颗树移走了，在花园里留下一个两平米左右的空地。菜嫚开始搞事了。她去苗圃，花了五千元，不惜代价，动用了五个劳动力和一个带塔吊的大卡车，移植了一棵非常漂亮的大桃树在那个地方。我家花园已经装修好了，没有办法再种树了。

我坚决反对。理由是，你花钱在公共绿地，产权不明确，纠纷多。菜嫚坚决要买桃子树。理由是，以后可以在家里摘桃子吃了，这是她从小到大的梦想。结果是我战败了，菜嫚高高兴兴把桃树植进来了。

这两天，桃子树有点小果子了，不能吃，就是开始挂果了。这下子热闹了，各种各样的人，不断的折断树枝，去摘果子，有业主，有小孩，有快递，有装修公司的人，各种各样的人都有。菜嫚大怒，就一天到晚，抓着拖把杆子，像个母老虎一样在窗口守着这棵树，一有风吹草动，就跳下去，谁要动她的桃子，她就和谁吵架。经过多次交锋，菜嫚已经情绪恶劣了。

女人是直线思维，我花钱了，就有效果。男人是双向思维，虽然你花钱了，但是别人会不会阻碍你获得成果？
