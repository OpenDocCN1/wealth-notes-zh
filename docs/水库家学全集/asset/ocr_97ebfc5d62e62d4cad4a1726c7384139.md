# 01

为什么你在公司里升不上去？

好多人以为，我年年考核前三名，就应该升我。这就可笑了。你先要搞明白，升职的流程。

在现实中，升职=考核偏上+互相推荐。你觉得有多少人推荐你？绝大多数人，如果业务能力特别好，情商一般不高，这是很普遍的现象。因为业务能力强的人，一天到晚在研究事情，往往忽略了人与人之间的微妙关系。这就让人讨厌了。你天天加班写论文，一年发表三个论文，是不是就显的我们很蠢很偷懒了？老子不高兴了。我要你好看。

绝大部分人，只要你业务强，肯定有一大堆人在周围说你坏话，时间长了，肯定给单位留下了极不好的印象，你等于白干。大不了，看你可怜，退休前赏你个副高，还不忘教育你一顿。

**热门评论：**

+   * xucornie：考核偏上即可，其他的看自己的善缘。
* 豆浆不加糖：1、在大单位，真正的聪明是厚积薄发 2、在大单位，不要觉得自己聪明
* 1986的爱：不进圈子=原地免圈
* 卫衣就完事了：想想你爹你叔你舅是谁
* 忘名同心：业务能力要过得去，和主管关注的领导关系要好，还得没得罪过周围同事。最好有主管升迁的领导和不敢得罪的上层关系打打招呼...这差不多能升迁了。
