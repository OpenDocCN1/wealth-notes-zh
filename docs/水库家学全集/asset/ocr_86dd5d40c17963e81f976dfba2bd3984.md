# 你幸福吗？我不幸福，但我让老婆孩子幸福了。

财上海微博 2020-08-20

01

出口不好做，内销就好做？

出口工厂有个自信的想法，我们的质量比国产同行好一些，肯定做的好。实际上，问题没有这么简单。你又不是专利秘方，不就是做个耳机吗？你做得好，别人也做得好，没什么了不起的。内销厂并不是做不出超优的产品，他们不做的有其他原因。

内销厂无论怎么做，绕不开网店的竞争。网店是全球比价。如果你没什么名气，还贵一点点，基本就难办了。很多时候，内销货是故意做的便宜一点，主要是用的原材料便宜一点，这不是技术原因，而是竞争原因。

另外一个难题是销售渠道。内销除了网店，主要是小店铺。人家凭什么卖你的货？市场上同品种的东西多了，要多少有多少，你给我什么好处？不是所有的商品都适合网店的。

我买鞋从来不看网店。因为必须试穿才敢买，一双鞋几百上千，还是仔细一点。还有一些女人结婚后发胖了，不试穿是很难买衣服的。不沾杠，你是标准身材。

热门评论:

农村泥娃娃：便宜仍然是大多数国内顾客的首选。

Mr吴坤彬：出口的质量拼不过网店的，我做原材料的，人家卖网店的就要最烂的材料，价格能低20%以上。只要样子像就行。淘宝和拼多多只看价格，不看质量。

_三姨太_：希望内销的质量能好一点，别总往便宜两个字上靠

绕小圈Sam：是这样，内销很多时候是为了控制成本

02

我对内销江湖是非常熟悉的。

内销有很多心照不宣的规则。不过，现在内销也不好做了，主要是网店的样子货把很多老实卖货的厂坑苦了。举例，

你家出一个爆款，例如dx骨饭车，因为你是正规的企业，用料扎实，开价220元。隔壁小王做了个样子货，看上去外观差不多，只要120元。消费者就急眼了。老实人就完了。
