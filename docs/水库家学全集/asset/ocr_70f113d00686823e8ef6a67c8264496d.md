# 为什么35岁真是个坎？

我年轻时候不相信这个说法，我觉得，35岁的时候，身强力壮，只要自己心态放好，根本没问题。人到中年才发现，老人说话还是对的。

一是技术停止了。你想想，你的技能是不是都是35岁以前练就的？基本都是。

二是破事越来越多。老婆不高兴了，孩子成绩不好，老头老太跑医院，越来越多的家庭琐事把你逼疯了。

三是贪财了。年轻人相信明天更好，所以贪财的少。但是，当你到了35岁，要钱的事情扑面而来，你又束手无策，就慌了。

四是惰性上升了。没钱也不想干活，积极性没了。

当然，随着年龄阅历的上升，经验值是多一些了。可这对单位意义不大。单位要的是一个工具人，你八面玲珑对单位有毛的意义？

解决办法，你要在前十年打好一个赚钱的基础。否则，你只能创业了。

还是要买大城市。
