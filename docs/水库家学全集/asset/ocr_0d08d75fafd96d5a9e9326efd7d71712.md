# 06

学了那么多的道理，为什么我还没发财？

很多人把学习当做努力。一天到晚学习各种绝学，上知天文，下知地理。世界和平，尽在胸中。但是，他们从来不做事情。他们最喜欢研究事情，把各种各样的问题研究一遍，他们就认为自己干过了。上下五千年读一遍，就是历史学家了。这是有毛病。

绝大多数赚钱秘诀不是研究出来的，而是在干活的过程中，偶然发现的。发大财，往往是因为经济运行中出现了一个空挡，你恰巧有能力或者就近，去弥补了。但是，这种空挡是不多的，一旦被大家知道，就有无数的人冲进去，把缺口堵死。

经济活动，千变万化。每一个变化都会形成各种各样的需求空挡。这种需求空档需要新的企业填补。举例，在编教师不能堂而皇之补课，但是居民需求还在，需要人去填补，于是各种家教和网络补课，犹如雨后春笋就起来了。这里面大概会出现1-5个十亿级老板。

各行各业都有这种情况，规模大小不一。人世间的道理太多了。你不需要研究那么多，踏踏实实做一个就行了。一招鲜！吃遍天。找风口的方向其实是很明确的，你家需要什么，但还没有得到满足。我最需要灭蚊神器，大户型的那种。
