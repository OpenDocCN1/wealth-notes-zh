财上海微博  2021-04-18

# 01

买婚房。

成家立业生孩子，是天经地义的。这就涉及买个婚房了。那么，买婚房要考虑哪些有限因素？

+   一，离离家近。年轻人奔事业，不能在上下班路上耽误太多时间。如果路上一个小时，到了单位已经头昏脑涨了。最好的婚房是单位附近，2公里以内最佳。至少靠近一方单位，男女都行。最好是走路也可以到达。我曾经租房子在单位附近，每天早上迎着朝阳走20分钟，简直是享受人生。我有一次买了距离单位四公里左右的房子，有时候刮风下雨，根本打不到车。

+   二，总价低。年轻人结婚，一般是靠父母。他们也有自己的利益，不一定都愿意拿出来。总价低基本等于面积小。我还建议，可以考虑六楼，朝北，绿化少，这种房子便宜几十万。反正，你白天在家的时间也不多。

+   三，噪音小，睡觉休息比较好。没有噪音是不可能的，尽可能找个相对影响小的。避开垃圾站，马路，商铺。很多人说高压线信号站的事情，以我的科学观点，只要是合法小区，不存在什么问题。电厂的人多了，电工也活的倍精神。

+   四是学区房问题。我不赞同过多考虑学区房。你家孩子成绩好不好，不是这个原因。就算请北数学系系主任来教你宝宝，也不见得就好。成绩靠家长，不要推卸责任。

+   五是变化。大概率，你的一生不会只买这一套，遇到问题，以后置换的时候一了百了。先解决有没有，再考虑优不优！

先用起来，以后有条件再换好的。
