# 现实的女人

菜菜，我有个大学女友，已经谈了三年，大学里用了一年多，毕业后不给用了。

我家是北方小镇子上的，城镇户口，吃商品粮的。女方是农业户口。我家有二上二下的村头别墅，爷爷奶奶名字。女方家就一个九十年代的老破农民房。

我爸妈现在大城市的厂里上班，一个是电工，一个是质检，也算是行政人员了，比流水钱好多了，爸妈两个人合计月入1.6万，在我们老家，已经是响当当的富裕家庭了。女方是老家破落户，他妈五十岁就在家打麻将，他爸是个懒汉，一天到晚也不做事，就在自留地里种点蔬菜。他们全家基本没有收入，在家里摆了两桌麻将，卖点盒饭。不是我看不起女方，是他们家真的一无是处。

女友长得真是不错，肤白貌美大长腿。他们家基因好。他妈从年轻时就是十里八乡著名破鞋，搞出过好几个丢人的事情，改嫁两次，是我妈托人去他们村问出来的。他爸年轻时候，偷鸡摸狗不学好，被村里教育多次，实在是要不到老婆，才要了这么个破鞋。
