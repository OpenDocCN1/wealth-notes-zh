# 发财是什么感觉?

很多人从来没有体验过发财的感觉，他们一般误认为，发财是每年赚一百万，十年赚一千万。实际上，我问过很多人，大概是这样的，前8年不赚钱，第九年赚了200万，第十年赚了800万，然后发了。五六年功夫就过亿了，一大波美女上门推销私人飞机了，你别说，长得还贼他妈好看。然后你就看不上前台小美了，总觉得她土里土气的，尺码也不到位，总是差一口气。

一般有这个过程，前几年，大家都不注意，不看好这个行业的时候，你在那里悄无声息的积累技术人才，管理经验，悄悄地建仓。大家觉得你有毛病。突然，风来了，你就飞起来了。

我说这个的意思是"财不入急门"。如果大家都知道某个事情容易发财，你就发不了财了，因为做的人太多了。

建议：各位上知天文下知地理的二本子，你不是很聪明吗？你就预测一下，今后二十年，什么事情会发财，你赶紧去布局。

莱莱，你说什么会发财？我发财后给你分红。答：你去买套房子慢慢贴瓷砖。

# 闻香识女人，看透读老婆

内环绕的房本有三种，大绿本，小绿本，红本。性质完全一样。

但是这三种本，是不同年代出品的，代表了不同的情况。

大绿本是二十年前的进贷，现在至少十倍了。

小绿本大概是十年前的，现在至少五倍。

红本是这两年的，还没太大的发展。

这意味着这个家庭的财务压力不同。
