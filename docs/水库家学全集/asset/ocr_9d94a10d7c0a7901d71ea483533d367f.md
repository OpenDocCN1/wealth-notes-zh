# 二本子怎么办？

如果你没考好，只混了个二本，也不要灰心，办法总比困难多。我以自己的工作经验，提几个建议，给你参考，帮助你在今后的工作中飞黄腾达。

一是认真学好专业课。大部分985和二本子，专业课的设置是差不多的。985有些专业课很难，但在实际工作中，用处不大。所以，你也不要太自卑了。

二是放弃幻想。不要想入非非，例如什么今后去留学镀金，没用的。你中文都没考好，用英语考，你就好了？不可能的。

三是放弃花里胡哨的课程。例如外语，交响乐欣赏，还有一些搞笑的选修课。及格就行了。绝大多数二本子在工作中，不可能用到专业英语。

四是养成吃苦耐劳的精神。有些985，一天到晚兮兮的，看的就生气。这就是你们二本子的机会。在单位里，态度好比能力强重要。

五是学习一些职场礼仪，今后不要得罪老板凳。

六是注意打扮。倒插门比加班爽多了。老婆归我，家产我有。
