# 认知水平越低的人，越喜欢回复“收到”

财上海微博  2021-04-14

你可能不会想到，在工作中某些时候，你回复一句“收到”会引发很多问题。

最近就收到了一个读者的留言：

“为什么同样都在工作，一起入职的同事就成了我领导？”

“兢兢业业工作好几年，凭什么工资还没一个新入高？”

我们都知道，只有努力才会有收获，但努力了就一定会有很好的收获吗？

未必。

很多人整日忙碌，却没有在职场换取高价值。

疲惫、抱怨悄然滋长，让人渐渐失去动力，却始终没能解开困境。

# 01

就像我一朋友老何。

他在一家互联网大厂上班，每天几乎忙得像个陀螺，加班加点是常有的事。

去年，他想要竞聘一个经理的位置，其中最大的竞争对手就是他同事。

为了这个位置，老何付出了非常多的努力。

当同事七点就下班的时候，老何九点还在加班；

同事十点在群里交付工作，老何就定半夜三点的闹钟，起来发邮件给领导。

我经常能刷到他朋友圈，都是给自己鼓励打气的励志鸡汤。
