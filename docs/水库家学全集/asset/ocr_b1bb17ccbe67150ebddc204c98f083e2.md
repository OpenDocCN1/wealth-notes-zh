# 如何为人父，为人夫？

财|上海微博 2021-05-26

# 01

上班的人都觉得赚钱很容易。

以我为例，当年上班的时候，遇到过个捡废品的农村小老板，他居然赚了好几套房子，而我当时一个月五六千，打个车都是手发抖的穷比。但我还看不起人家小老板，嫌弃人家穿的没我好。

就你一个捡破烂的农民，有啥啊！告诉你，老子是985，如果我做生意，分分钟秒了你。只不过我在大单位里，没和你竞争而已，懂伐？当年的我就这么狂野，现在想想真的是个大sb。为什么上班的人有这种感觉？

+   1，他接触到的人都是幸存者，那些已经破产的人，他没看到。

+   2，大部分生意并不难，和塑料桶流程区别不大。你看，英语老师也可以做出来智能手机，开发最好用的APP。有啥啊！

+   3，发财的老板看到单位里那些鼻孔朝天的985，一般比较谦虚。人家精明，没必要恶心你。

+   4，老板聊天的时候，往往把非常复杂的事，简化了。你没有经历过，听上去好像很简单。实际上没那么简单。

最重要的是，你心里不服！老子是985，怎么可能比你一个小老板差劲，只不过运气没到。

# 02

卖房度假。

刚才看了一个帖子，小夫妻从大城市的朝阳区搬到了广西桂林，买了个依山傍水的学区房，幸福感爆棚的帖子。这简直就是扯淡了。

他们在广西幸福的唯一原因是有钱，他们的钱比广西的朋友多的多。但是，他们的钱哪来的？不就是在大城市赚到钱了，再加上大城市的增值红利吗？相当于 是，卖房度假。任何一个人要想干这事，肯定是爽到肠子子乱摇的程度。但是，这值得炫耀吗？向下的路都是好走的。

他们把小学生孩子带到广西了。相当于切断了朝阳区的人际关系和思维模式。也就是说，他们下一代要从广西起步，二次拼搏了。
