# 07

痛苦和失败。

每个人都有过刻骨铭心的痛苦。如果没有痛苦和失败，你爸现在应该是首富了。正因为你在生活中经历了各种各样的痛苦和失败，你才变成了你现在的自己。读大学的时候，我觉得以我这样的水平，至少应该搞个全县首富。没想到，我现在在蜗在老婆家里当倒插门。不过还可以，吃穿用，没有亏待我。

我回顾了一下我周围的人，他们大多数经历了巨大的失意和失败。有个熟人，曾经那么辉煌，现在也不过是退休老汉，保姆也时不时吼他几句。

面对痛苦和失败，我们应该有个理性的态度。这是我们人生的一部分，必然遭遇。我们不要害怕痛苦失败，我们应该温柔的看待它。

当我们正在经历这种痛苦，我们应该怎么办？

一是不去想了。或许你很没面子，昔日手底下的小弟已经和你平起平坐了。或许你羞愧不已，曾经是前呼后拥的大哥范，现在已经是手机欠费，到处求人借钱了。或许你噶食难支，距离登顶就差临门一脚了，偏偏踢飞了。但这就是生活，本来就是那么的变幻莫测。不想了，你就放下了。

二是选择忍耐。很多失败是有后遗症的。这不，三天两头还有人上门要钱。那你就忍耐一下。债主闹几天，也没力气了。

三是学个鸟技术，至少不要天天喝酒。实在不行，当个保安也行，多多少少给自己留点退休工资。

四是人生还有下半场。广场舞，老太俏，看啊，婀娜多姿的张阿姨，带着三套房正缓缓向你走来。退休之后也可以抱上大腿，现在有钱有路子的老头老太太多了！

让我们积极拥抱生活。老天不负有心人！
