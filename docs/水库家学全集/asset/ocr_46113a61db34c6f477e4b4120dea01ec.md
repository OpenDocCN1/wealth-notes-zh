# 03

白手起家。

你没有钱，没有资源，要想白手起家，只有靠技术了。我说两个熟人白手起家的故事，仅供参考。

老王是农民，高中毕业，人挺聪明，以前在一个大厂车间里睡觉，也没什么本事。

有一次，厂子里要加盖一个无尘车间，请了建筑队过来。但是，甲方也要派一个人去监工。这活要加班，环境脏兮兮的，条件也不好。除了吃几顿饭，也不怎么样。大家也不感兴趣，老王积极争取，得到了这个机会。

在随后的一年里，老王和建筑队一起，天天在工地上泡着，学会了建筑工程的基本工艺和流程。老王还在家自学了这方面的书，不懂就找人问。一年后，车间搞好了，老王也把建筑上的事情，摸的门清。最重要的是，他结识了一大批人脉。有干活的，有送货的，还有价格，质量等等，包括"吊机拆，水泥张，挖土李，门窗赵"之类的。

无尘车间投入使用后，来参观的同行，络绎不绝。慢慢的，老王找到了商机。有几个同行也想做，但不知道怎么做。于是，老王乘机拉起一个建筑队，就干这个。没几年就发达了。

再说一个老张。

老张是厂里的销售员，老家农村，也没有多少钱。但是，老张非常聪明，基本摸索了其中的小奥秘。几年后，老张自己办了一个销售公司。大江南北跑业务。因为他对这个行业里的人头，人品，货品，非常熟悉，也发达了。

丝丝起步，最忌讳夸夸其谈。你不需要懂天下风云，海湾局势，你只要把具体的小事做好就够发了。当然，丝丝们是不感兴趣的。

小结，没有资源，就靠技术。你也可以的。
