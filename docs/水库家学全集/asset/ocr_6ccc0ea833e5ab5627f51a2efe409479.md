# 文凭为什么重要？

对于土老板家庭，教育的目的是为了孩子融入社会。我家孩子在学校里混的如鱼得水，他总结了一个经验，“成绩好，长得帅”。只要符合这个标准，娃就很开心。我一天到晚教育他，要帮助别人。别人考试有困难，就把卷子拉的近一点，人家瞄起来方便。

我家对成绩不在意。因为，我家已经不需要再靠文凭赚钱了。我只希望孩子有一个快乐的童年。菜嫂为了让娃在学校表演上出个风头，一天到晚巴结班主任。我觉得没必要，我家那个中年妇女就把我劈头盖脸骂一顿，好像我不要面子的一样。但是，娃娃也有痛点，因为关系户。娃娃班级里有一些本校子女，霸占了各种小队长的位置。一年级的娃娃，内心备受打击。

对于一般家庭，屌丝逆袭的唯一办法就是考试。清北太难了，那是文曲星下凡，咱小门小户的，就不考虑了。但是，一年招14万的985，我们还是可以考虑一下。

考上985，意味着几个事情，

一是大单位就在眼前。

二是找老婆可以挑一挑了。

三是丈母娘赔嫁房子。

四是倒插门走上人生巅峰。

总体而言，985这张牌，就像农村妹长成了范冰冰，可以甩的出神入化，就看你会不会玩了。如果考不上985，你那份产的父母就没办法了，有路子也没办法。我一个同学是三甲副高，他最大的痛苦是，如果儿子不能考上博士，以后就难办了，他的副高也不能像房子一样继承。你房子买好了伐？
