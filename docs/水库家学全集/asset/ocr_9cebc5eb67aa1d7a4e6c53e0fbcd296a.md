# 01

（嚼舌根）土豪招人恨

最近在装修一个房子。期间，有一个奇葩土豪，我没见过她，是装卸工在闲言碎语里告诉我的。我们这个小区，是大山当中凹进去的一个平地。小区绿化，就是周围一大片山林和内部一块大草坪。楼王是双拼组成的，理论上不是独栋，位置在东面边缘，背靠山林，面对草坪。

她买下了两个双拼，相当于一个大独栋，还嫌不过瘾，又看上了周围一大片山林，这片山林，理论上是小区公共绿地，但是地形类似于高耸出来的悬崖，很难走上去。于是土豪和开发商商量，在他们家后院出口，由开发商修了一个土坡梯，他们家就可以从院子，直接走山林。其他住户要从一个很麻烦的入口进入山林。

这就导致了一个有意思的情况，这片山林，表面上是公共的，实际上就她一家玩。她又自己出钱，种了很多名贵树木，搞得非常漂亮。如果你要想进入，就要绕一个大圈，一般也不去了。

这个土豪还把一楼打通了，修了一个40米的泳池。内部金碧辉煌，把老子气的只冒火。我发现，很多人在装修的时候，经常发神经。明明是欧式大别墅，非要在院子门口放一对石狮子，还要在院子里种一个迎客松，实在是滑稽。

# 02

土豪的世界我不懂

最近，小区里搬来了个某大牛逼公司的老板，这个公司在几年前是非常著名的。人家怎么经营，我们管不着，但是，这家人住进我们小区，大家就看热闹了。

太隐秘的热闹，我们也看不到，大家能够看到的基本也是表面。我听保姆和装卸工说了几句。

一是有管家团队。据说有十个八个，司机，花匠，管家，领班。脑补福建土豪的视频。

二是古董家具。这是装修工和我说的。装修工是按天算的，一进门，管家说，不要碰家具，打坏了，赔不起！

三是这么大的房子就一个人住。房子是老爸买给女儿的。老板是土豪，女儿是一个某知名事业单位金融系的老姑娘，嫁不出去的那种，据说也很漂亮，就是找不到合适的男人。爸妈心疼女儿，就给她买了个房子。

我在想，这个大金库要是被哪个屌丝想住了，那就直接IPO了。册那，想想都开心。
