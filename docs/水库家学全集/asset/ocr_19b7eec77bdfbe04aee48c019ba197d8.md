# 如何规划你的中小学成绩单？

上了考场，你会发现，会做的自然会做，不会做的题，你一个小时也想不出来。发现这个问题，就很容易解决了。

考前多刷题，刷到也老天荒，海枯石烂，就考上985了。

考清北有点难，还需要一点点运气。考个中等985，例如什么南大浙大，那是不难的。

# 警惕中小学英语乱教。

我刚才和几个小孩子问功课，发现他们的英语发音是一塌糊涂。主要是元音乱读。我问了一下，老师上课没办法一一纠正，都是班级集体吼一遍就稀里糊涂过了。孩子学了一大堆错误的读音，好可怕。

热门评论:

+   * 漂亮小绿茶: 害 我一堆学汉语言的同学 毕业了都在机构当英语老师
* _sowinnie: 我是一名培训机构老师，曾经也在公立学校教过书，说白了些公立学校老师水平真的没有多好，自带口音还是很多。一线城市抓得严，其他二三线城市就...
* 是七啊不是八吗: 别说英语了，就是普通话
* 棒盘仔玩: 我家幼儿园时期上的迪士尼，发音比较标准
* 初二77: 别提了，我初中英语老师是苏北人，Chinglish还夹带着一些苏北口音

03

我不建议幼儿园孩子去读英语兴趣班。

我听过几次课，那些在社区附近教英语的二本子，自己都不会英语，纯粹是糊弄家长。绝大部分孩子是爷爷奶奶奶妈带过去的，听不出好坏，一学期几千元是小事，以后再改麻烦大。要学就找个正规老师，最好是985。
