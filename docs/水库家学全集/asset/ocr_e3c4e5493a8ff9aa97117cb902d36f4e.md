# 02

大城和小城有什么区别？

我有几个员工来自小县城。我和他们聊聊天发现，小县城除了房价低，没有一个方面比大城市好。普通关心的人关心的几件事：

一是住房。大城市就这个不好。房价比小县城高好多倍。京沪一套房可以抵得上成都都家主五六套。

二是教育。大城市有发达的补习系统。不仅仅是语文外，还有各种特长班。例如唱歌跳舞骑马射箭，小县城几乎没有。

三是医疗。省里一头马。去一次省级城，还不如去一次京沪。

四是工作。县城七、八干就是金领了，还不如在京沪捡垃圾。人比人啊！

我问他为什么背井离乡？他说，就业。家里这么多人等钱用。儿子要买房，老婆要生活，父母医疗费，只收现金。他就搞不懂了，为什么医疗费不收稻谷？
