# 05

月入一千以下。

据说有好几亿人。我感觉主要是因病致贫，或者在农村没有出来的。2009年以后，我已经很少听到一千块钱招人的事情了，基本不可能。请个保姆就是六千打底，还要求很多。吃住不好，一个星期就走人了。

农村的一千元和城市一千元是不一样的。区别是吃住行。

一是住房。农村住房，大多数是自建房，和大城市不一样。我这几年的研究过，自建房五十万成本，就是楼上楼下+简单装修+有污水管的那种了。你千万不要以为农村还是厕所和猪圈在一起的老样子了。现在的农村，基本就是家家户户小洋楼。和大城市别墅比只，只不过有两个地方差，装修不行，小区道路和绿化不好。城市人口要负担买房，这个亚历山大了。

二是吃饭。现在两亩地的懒汉田，谷子都是口粮，蔬菜可以自己种，花钱的地方要少很多。

三是交通费。农村人基本没有交通费的概念。城里人一个月交通费两百是比较正常的。如果偶尔错过地铁，从陆家嘴干到周浦，大概就是100块了。
