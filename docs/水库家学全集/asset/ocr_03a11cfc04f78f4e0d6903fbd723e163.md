# 01

现在的农村是什么样的？

很多人没有去过农村，跟外国人一样，可能还是贾樟柯电影里的印象。我简单说一下。现在的农村，

+   1，室内装修和城市新装修的小区房差不多。你装修的师傅都是农村的，他们回去也这么装修。

+   2，小区规划。现在有很多经过改造的农村，基本就是城市小区的样子，我见过几个农村别墅区，除了材料差一点，风格基本一致。绿化苗木没有城里小区的品种多，一般是就近取材。

没有改造的自然村，基本上家家户户是小楼，门口一块水泥地。

+   3，吃饭。天天吃剩菜。因为春节互相请客不断，剩下的菜，一般也不会倒了，热一热，可以吃。

+   4，娱乐。广场舞 + 打麻将。打谷场，绿化带也有健身器材，用的不多。

+   5，小区垃圾桶也基本普及了。

区别也有，

+   1，就业。主要是外出。本地就那么点人，你看我，我看你，也没什么风头。

+   2，婚房。大部分是镇子或县城里。少部分是自家的村口大豪宅，姑娘们不喜欢。

+   3，读书。去镇子上为主。

+   4，医疗。村里有医务室。镇子上医院也不远。

+   5，买车。很多很多。村头堵车是正常情况。
