# 07

痛并快乐着。

大家可能不知道，我家是个什么样子。你就脑补一下电视剧《炊事班》里的班长宿舍，或者五星级开业那一瞬间的整洁。我家叠被子都有棱角的，真是很讲究。菜嫂喜欢整洁，已经到了有毛病的地步了。家里两个保姆一天到晚就是不停的擦拭。我觉得很干净了，没必要这样，菜嫂不同意，非要擦，还羞辱我的自尊心，“又不用你花钱，闲着”。我是合租房大杂院出来的屌丝，哪里受得了这种折磨？

我最喜欢的生活是，衣服扔在地板上，袜子甩在沙发上，喝茶的杯子三年不洗，只要顿顿吃的好，就行了。可菜嫂这个中年妇女，有着极其苛刻的环境卫生标准。地上不许放东西，白天不得坐在床上，凳子时时刻刻要摆好（这一条最折磨人），家里不许买塑料制品。而我最喜欢买便宜的一元店。一个塑料盆，3块钱，五颜六色随便选。一个小凳子，20元，随便放。花10块钱，可以买好几个花里胡哨的塑料玩具逗娃。

有一次，我在一元店花了一个下午精挑细选了一个漂亮花瓶，玻璃的，带乾隆款的，纹龙和彩人物瓶，花了我十七元。我兴高采烈抱回家，给菜嫂显摆了一下我的知识。没几天，菜嫂去买了个维多利亚风格的银花瓶替换了。这是明显的不尊重老爷们啊！这能忍吗？我一怒之下，把我珍贵的乾隆花瓶扔垃圾桶了。

因为生活习惯不同，我经常要用这个中年妇女。我是看她可怜，暂时留着她而已。一个大男人，混到这个地方了，在家里也没地位，实在是忍无可忍。唯一的快乐是给你打电话，“小王啊，明年的房租要加一点了。别哭穷了，大家都难啊！”
