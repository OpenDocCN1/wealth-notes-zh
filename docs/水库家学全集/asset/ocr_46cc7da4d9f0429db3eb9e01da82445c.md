# 年入一万美元是农民工的分水岭。

财上微博 2020-04-07

# 01

年入一万美元是农民工的分水岭。

也就是月入六千。现在大批的农民工在城市工作，极大的支持了经济发展，农村发展。但是，这些岗位主要是城里人让出来的，并不是城里人不会干，城里人一开始嫌弃这些岗位没面子，钱也不多，不想干。

如果这些岗位达到月入六千，城里人就会跃跃欲试了。现在很多维修，专业快递（重要单据），上门服务，本地人已经开始做了，基本都是月入五六千打底，很自在，但比较辛苦，特别是天气不好刮风下雨的日子。人有个特点，一旦做了，就会很快习惯。

例如有次保险箱钥匙找不到了，厂家派人上门维修，一次两百，还是三百，我记不清楚了，也就是三分钟。维修员是个五十岁左右的老师傅，骑助动车来的，看来上班也不远。动作熟练，工作敬业，乐呵呵的，看得出已经是干了很多年了。我相信，他会一直干下去，直到退休。

现在，京沪本地人开滴滴的也越来越多，一个月上万左右。原来这些活，京沪本地人不干的，嫌钱少。现在，钱多了，也就干了。一旦干了，就会习惯，一直干下去。一个月五千到一万家里的主营收入，不可能轻易放弃。你想不干，一家老小不会同意的

这些岗位慢慢的就回到本地人手里了。也就是说，外地人开创了这个行业，本地人凭借自身优势，成本优势，慢慢的拿回去了。例如，本地人休息的好，一般不会疲劳驾驶，开出租车就是个优势，况且熟门熟路，遇到问题，也容易解决。

结论：农民工工资不可能无限提高，因为他要面临本地人的竞争。现在很多高薪岗位还在外地人手里，仅仅是因为本地人不熟悉而已。例如月入一万的高价保姆，用本地人还是放心一点。

# 02

上海人也干装修。

我印象中，装修都是安灰人干的。没想到，遇到几个上海人，也干装修，冲击钻使用熟练。我家门口有个建材小店，我时不吋去买个小灯泡，遇到几个上海人在采购材料。聊了几句，我正好有个小事清他们帮忙，两百块，十分钟，因为我没有工具，也不会用工具，只能找人了。

在路上聊嗊天，这些人原来是在工地当小包工头的，或者是各区县建材批发城的小老板，物业经理。后来因为杂七杂八的原因，自己拉杆子，成立装修公司单飞了。
