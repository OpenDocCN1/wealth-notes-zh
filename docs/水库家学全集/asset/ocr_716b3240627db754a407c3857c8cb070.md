# 08

人有很强的适应性。

我大学毕业后，上班那个痛苦啊。朝九晚五，还要挤车，实在是痛苦。更倒霉的是，中间还去外环线待了一段时间。但是，上班几年后，我就深深地爱上了上班，不上班就觉得自己像个犯了几年错的250。后来我不上班了。一开始还不习惯。特别是遇到困难的时候，还怀念上班，每个月按时发工资。家里蹲了几年，又习惯不上班了。

买房子也一样。买套首房，我心里怕的不行。买了之后，第一年价格没什么大变化，一有个风吹草动，起起伏伏，我就像是一只惊慌了的兔子，龇牙咧嘴，急得直跳。后来就习惯了，反正发大了。

结论，买房后，心态就好了，生活品质不一样。
