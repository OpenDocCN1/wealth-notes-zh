# 14

二本子怎么混出年薪百万？

我的各个部门经理基本都是二本子，一小半达到百万水平了，大部分是20-60万年收入，所以我很轻松。

企业招聘大学生不看你是什么文凭，只关心两个：

一是聪明。你的学历和企业实务，八竿子打不着。聪明的孩子，学习快，我就节约了培训期间的无效工资成本。有的250，连复印机也不会用，气色特我了。

二是勤奋。绝大多数企业，都是成熟技术，不需要你发明创造，你就是一个作用，执行。几年下来，天差地别。有的已经是自信满满，大客户三五个，有的是垂头丧气，每月只有基本工资，老婆一天到晚骂他，公司开会不敢抬头。

为什么区别这么大？因为勤奋。举例，一个业务员一个月跑十个客户和跑一百个客户，结果完全不同。有的屌丝睡觉，骗公司说去跑客户了。有的屌丝到了外地出差，就是旅游了。还有的屌丝把客户经费拿去泡妞请客，然后回公司报销，你随便。三年后，你就哭了。

一般情况下，第一年，个别屌丝就可以拿到20万提成了，然后逐年累计，等你掌握公司一半客户的时候，你就是年薪百万的销售经理了，也可以出去单干了。

生产部门同理。不需要你发明创造，只要勤奋。

小老板不会埋没人才的，因为小老板每天都在生死线上挣扎，如果有个厉害的屌丝替他赚钱，那就是亲爹了。绝大部分二本子没有能力，就是一天到晚抱怨，提要求，那是混不好的。

本公司不缺人。
