# 为什么别墅装修时间那么长？最后是筋疲力尽，头脑脑涨。

+   一，别墅自身复杂

这一点比较容易理解。楼上楼下，各种拐弯抹角的装修细节，特别多。

二，人为因素

1，运营模式。装修公司自己是干不活的，只负责拉单子和吵架。他们一般有两个三亲戚，负责前期砸一房，房东就不能后悔了。接到单子后，分解，压价，分包出去。

别墅是所有装修中最赚钱的单子。一是面积大，总价高，二是别墅业主相对好说话，大方，用的东西比较好，装修师傅在建材市场有搞头。

2，积攒单子。装修公司老板千辛万苦接到一个大单子，还开不了工，一般先度假样砸一，然后放一放，一般要凑满十八个单子，才有搞头。因为单子多，批发出去利润高。这个过程基本就是三个月。

3，员工住宿。很多别墅房子，晚上可以住员工，有的人亲戚在附近打工，时不时来聚一下，要是装修好了，就不能住了，装修队老板也烦心，不如多拖几个月，反正住别墅的都是有钱老板，也不急。我家有套房子是带地暖的，装修工过了一个冬天，住出了深厚感情，居然不想走了。

4，拖时间的办法有很多，例如出难题。别墅装修往往会遇到各种各样你想象不到的问题，例如地下室发霉，某个管线走不下去了，装修错了，墙壁渗水，门窗漏水。然后，大家就停下来，装修公司的解决方案肯定是大搞，最好拆了房子重新搞。你肯定不愿意，千方百计想办法，然后你来我讨论一个月，这种事情特别多。装修一年算快的，两年正常，三年也有理由。我经常是搞两年。

三，解决方案

一是业主定主意，提前详细设计。这一点很重要。如果边设计边施工，三年也干不完。

二是隐患解决办法，业主主要提前想好。主要是渗水，防潮。不要指望装修公司会为你考虑。装修公司只希望多赚钱。

三是业主不要无休止无比价。有个58买浴室三件套，比来比去，搞了一个月也没有定下来。

四是不要多改方案。改方案，时间就没底了

五是不要苛求完美。有时候，你会为了一点点小细节，百转千回。你可能会认为，这是人生最后一题了，必须精益求精。我的看法是，功能设计，提前想好，美观设计，一概不改。

六是合同必须写好完工时间。对装修公司也是个督促。
