# 出国

我有两个高中同学出国n年了。

甲是外国大公司职员，拿工资的，折算下来，据说年入50人民币，一年存款也就10万左右。甲是当年十里八乡数得着的才俊，读书成绩超级好的那种，而且特别能吃苦。

乙是结婚出去的。她老公在外面遇到一个卡，她就辞职去了，据说还在那里生了个二娃。

他们的共同特点是，在当地扎根了，买房买车，白领家庭。但是，她们好失落。

一是离乡背井，没有文化氛围。他们最大的乐趣是在网上看中文电视剧。

二是生活质量一般。虽然房子车子都有了，但是吃的不习惯。男的天天上班打卡，没什么奔头，只求不被辞。女的就是家庭主妇，一天到晚洗衣服，拖地板，买菜，吃冷冻鱼。穿的还是五年前南京路商场里的衣服。

三是没有成功的快感。当年，甲是远近闻名的才子，乙是远近闻名的美女。如果没有出去，她们的生活应该远远比一个家庭主妇或者小职员强得多。现在，他们回来探亲很寂寞，大家对她们也没什么大的兴趣，知道他们收入不高，也不让他们请客。不像九十年代，如果是有卡一族，那是十里八乡光荣耀祖了。

四是没钱。他们的结余收入和同学们比，算比较中下的，但是他们当年都是佼佼者啊！他们回来请客，有的同学比较忙，就没去了，有一次请客一桌，只来了有一半人，令人唏嘘。

现在年青一代对这个已经不感兴趣了，因为有了更好的选择，京沪广深。
