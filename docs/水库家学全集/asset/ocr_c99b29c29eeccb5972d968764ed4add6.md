# 01

# 买房压力大不大？

二十年前，我们工资很低，房价大概是郊区2000，到市区漂亮小区8000元左右，主要是看品质和地段。那时候，大部分农民工工资大概是千儿八百。房子也很差。我们的目标大概是，你现在看到的老破小，30-40平米一室户（大概是10-20万）。当然，我们靠自己也买不起。当时，解决的办法是几种，

一是父母挺身而出。略。

二是自己硬扛。走这条路的人，是真的惨。我有个985同学，农村爸妈给了三万，其中两万是姐姐出嫁，老爸硬要彩礼。他的收入全部还房贷。身上基本没有零花钱。同学聚餐从来不参与。他在毛坯房里住到结婚，几年里，浑身上下发酸臭，没有洗衣机的那种。

三是老丈人出赔嫁。那时候，名牌大学还是可以骗篇丈母娘的。丈母娘一般也没多少钱，主要是靠积蓄，资助5-8万已经是天大的恩情了，或者卖掉一个老破小。

四是单位小补贴。以前有福利分房，后来没了，就给点现金补贴，大概5-8平米。

以前的人，和现在不一样，一万块钱就是天文数字了。一听说要借钱十几万，老父母基本都是死磕在田埂上了。就是这么困难的条件下，我们一大批人闯出来了，想想也是太可怕。二十年过去了，那么压力是不是增加了？如果按照相同房子，

对于体力工，压力减小一点了。大学生压力增加了。如果老两口加一个大学生，估计压力小了。二本子肯定不高兴了。呵呵。

# 02

# 为什么现在的90后觉得买房压力大？

一是目标不一样了。当年，我们的目标是30平米小破房。现在，90后的起步目标是90平米精装修。

二是家里出钱。我们那时候，男的买房，家里父母是豁出去干的，哪怕是从女儿亲家那里敲一根子也要把钱转给你。现在的二本子有志气，不要家里出钱。这事情就没办法了。
