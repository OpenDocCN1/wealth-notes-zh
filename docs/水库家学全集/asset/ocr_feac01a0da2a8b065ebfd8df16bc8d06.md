# 01

一百万存款是什么概念？

很多人觉得是个大数字了，其实不然。如果拆开，一年20万，五 年一百万。这对一些有实力的课辅老师，不是大事。

我见过一个合法做课辅的人。给你大概算算账，寒暑假3个月。平时9个月。

一节课200，一桌小猪仔一晚上就是1500-2000。如果跑场子，讲两节课800也是有的。

寒暑假包月的，一个月三五千比较常见。接送娃上下学，每月也要1500，网课也近千了。

现在，课辅是合法的，就是正规注册的那种。我老家县城，有很多写字楼空置，后来，有些区域就便宜租给这些机构。孩子四点半放学后，先到他们那里写作业，一般写到六 点回家。父母正好做饭。这对双职工家庭比较方便。

这些机构，还有老师值班，孩子不懂的，还有少许讲解。我见过一些这样的。相当于看孩子，写作业。

# 02

在大街上驾驶敞篷跑车是什么感受？像个傻子！

绝大多数人没有在大街上开过敞篷跑车，不知啥感觉。我体验了一下，千万别再干这 傻事。

一，敞篷跑车一般比较低，旁边有个开机动车的人可以居高临下看你，就像 有个250一样。

二是晒的发言。我们的体质是老外不一样。我们受不了晒太阳，敞篷跑车的唯一感觉就是热。太阳晒得你受不了。如果是冬天，又冻得受不了。

三是灰大。我们的马路上，灰尘比较大。太阳晒的满头汗，灰尘一粘上，活脱脱一个猴。有一次，为了装逼，我穿了个白衬衫去同学会，开了个敞篷车，回家一看，领子都黑了。女孩千万 不要坐这种破车。

四是尾气大。敞篷跑车一般很矮，前面那个车的尾气全归你呼吸了。
