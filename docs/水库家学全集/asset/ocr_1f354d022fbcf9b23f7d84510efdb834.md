# 怎么当好富二代？人才。

我的读者里，有非常多的富二代，你们在不远的将来，可能会面临很多工作难题。富二代是很难当的。老话说，富不过三代。实际情况是，企业传到第三代的可能性大概是1-2%。就是因为富二代太难了。

先说第一代。老一辈发财不容易，千难万难。但是，发财的第一代人，往往有运气成分。他们也是失败过好几次，最后运气爆好，出来了。富二代就困难多了。因为富二代不存在运气问题。你即将面临的都是棘手问题。富一代给你留下了几个亿，但也把他们没有解决的破事交给你了。你无论多努力，也很难解决。那么，如何把企业做下去？不说发扬光大，至少不要败家。

我用自己十多年的体会，给大家两句话。

一是不要花太多时间学业务。一个大公司，业务太多了，你穷极一生，也就熟悉一两个环节。你知道个大概，基本了解一下就行了。

二是学会发掘人才。这个事情实在是太重要了。你就算不睡觉，最多项三个人，但是，一个公司那么多人，那么多岗位，你哪里研究的过来？最后你累死累活，企业还是不行。

三不要在内部喝妍头。
