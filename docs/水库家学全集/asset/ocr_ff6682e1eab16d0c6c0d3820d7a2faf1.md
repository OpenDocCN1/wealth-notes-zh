# 04

300w，在大城市能买房吗？

答：勉强。就是房子不太好。好一点的婚房是900-1500w。具体操作，

一是上班族家庭。内环老破小了。一般是40平米，反正也就凑凑混混了，至少心理上有依靠，不会被房东通知搬家了。刮风下雨天，可以在家吃个小火锅。

二是自由职业者。大家不要好奇，自由职业者现在非常多。例如，小生意人，律师，会计师，小演员，小歌手，小网红，网店小夫妻，小有名气的辅导班老师。这种情况，比较适合远郊区的三房两厅，有事，开个宾利去一次市中心就好了。

反正也不是什么一房定终身。就当摆个篮子占个坑吧。过几年，置换一个好的。我有小区邻居，两口子都是985小镇做题家出身，十结婚时候，凑合了一个小二居。十五年后，两口子事业发展的，一个是cpa，一个是公司部门经理。置换+贷款，住进了漂亮小区的最便宜户型。他们和我说，没想到这章子也住进了高级小区，幸福感爆棚。他们孩子已经和一般本地孩子一样幸福了，没有什么痛点。

小结，万事开头难。
