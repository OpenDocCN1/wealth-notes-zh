# 01

向下的路都是好走的。

刚才看一个短视频，某屌丝在大城市苦熬了十几年，最后接受灵魂的召唤，去了一个附近的一个小城市，我估计是惠州之类的。他感到好幸福，每天早上阳光洒满窗台，再也不用住城中村的老破小了。这里面有个明显的逻辑裂缝。

他在小城市买房的钱哪来的？很明显是在大城市赚的，也就是说，如果没有在大城市的十几年拼搏，他不可能有钱解决了惠州首付。接下来，他的好日子到头了，因为他不能够保证在小地方赚到类似于大城市的钱。

真正解决他人生困惑的还是就是大城市。向下的路总是好走的。十年后，他在小城市混不下去了，还可以卖房回老家。呵呵，儿子怎么办？不管了。儿孙自有儿孙福。

# 02

我为什么不啃饼头？

要说条件，我还有那么一点点小条件。但我坚决不啃饼头。

一是不能和屌丝抢生意。屌丝本来就很苦了，如果我们中年大叔再去踢一脚，和他们抢饭碗，他们该多惨啊！

二是给娃留条路。向下的路最舒服，那是把孩子的路给断了。不能这样。

三是我太小气。如果女人和你xx，怎么也要给套房子，现在房子太贵了，我也送不起。

想来想去，我还是睡客厅沙发比较好，有地暖，也不冷。莱嫂显然是个泼妇！但我忍了。如果我把她踹了，也不好。
