# 为什么老来得子聪明?

这个现象，是普遍存在的。但不是自然科学，而是社会科学。老来得子，最重要的是爹老了。

一是有经验了。人过四十，很多事情就渐渐明白了。二十几岁的时候，自己也还不明白。你教育儿子，相应的就清晰多了。

二是有耐心了。对孩子最重要的是耐心。

三是有钱了。人到中年，是财富最集中的时候，儿子幸福了。

四是有些门路了。生活中，你会遇到各种各样破事，有门路就方便多了，孩子也不会自卑了。

你要是25岁生儿子，这儿子估计要迎接生活的狂风暴雨。
