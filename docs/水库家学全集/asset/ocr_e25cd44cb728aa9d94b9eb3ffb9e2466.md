# 07

厂妹不多了。

现在，老家结婚负担越来越重了，很多小光棍想出了一个好办法，去工业园打工，主要是找个对象。以前有可能，现在，这个套路基本不可能了。

一是没有厂妹了。我问过一个厂子。你们那里未婚女青年有几个，回答是微乎其微。女青年去哪了？主要是一些大城市商超餐饮行业，例如大超市，小餐馆，工资也不低，还好玩一点。愿意去厂里干活的厂妹，越来越少了。现在的厂子太穷，吃住也不行，又不好玩，大家懒得去。

二是厂妹看不起厂弟。以前有个电视剧《打工妹》，那时候，国营厂一个月工资一百多元，珠三角厂妹是四百多。现在不能比了。为什么？因为小厂也不挣钱了。绝大多数厂妹希望在大城市改变人生。一个普通的厂弟，不能带来幻想，也不能改变生活，确实没办法凑合。

三是厂妹看透了厂弟的鸡贼心。不就是想不花钱娶媳妇吗？我还！
