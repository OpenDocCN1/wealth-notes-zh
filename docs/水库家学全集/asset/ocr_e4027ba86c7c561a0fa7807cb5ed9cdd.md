# 07

40+岁以后还能干什么？

我有个熟人码农，业界大牛公司，牛逼到格拉斯。他们年薪高，十年前就达到了50-90w的水平，出差必定是五星级住宿+路边摊牛肉面。我一直没搞懂，他们为什么要去吃六块钱一碗的面条，而住在一千元以上的宾馆。

他们公司几年前发生了一次劝退，特别是针对闲散中年人，一次性给70w补偿。自愿滚蛋的人不多。有一个人真走啦。他是45岁老技术员，勤勤恳恳干了20年。他心里想，70万算外快，以我的技术和资历，找个类似的工作应该不是问题。

几年过去了，据说他也上班了。他花了160万在小区家门口买了一个65平米的底商，自己当小超市老板，一天到晚给人送啤酒之类的。谁能想到，这个搬运沉重啤酒箱子的老男人，曾经是年入几十万的白领大拿。他老婆也是高级时尚白领，一天到晚劝他，“你也老胳膊老腿了，不要再搬箱子了，挣一降几十万啊！”

# 08

这个世界上有友谊吗？或许有，我没遇到。

小孩子之间有真挚的友谊，你给我一颗糖，我给你跑个腿。但是，当你成年以后，友谊就不多了。为什么？因为你要的友谊太贵了。别人付不起。我家儿子买房子，能不能借二十万？滚！

成年人的交往往往是以占便宜的心态出发的。“你是某单位的，好好好，以后挂读书找你。”“你是三甲的，好好好，我老娘腿脚不好，能不能上你们那瞧瞧？”“你有没有想过，这种紧缺资源，人家为什么要免费给你？就凭你你脸大吗？”

一个上班之后，多少少会识到很多联系人。你可能会误以为这是你的人脉，这大部分是你的幻想。直到有一天，你就会发现，发了20个微信，居然没有一个有效回复。那时候，你就知道，叫天天不灵，叫地地不应。这种感受，我是很有体会的。你换过单位就会明白，一旦离开，原来的微信好友基本没有联系了，过个一年半就慢慢消失了。
