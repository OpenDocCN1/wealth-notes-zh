# 06

我家保姆来自美丽的黄山脚下。

她家有一个儿子，今年25岁，身体健康，180cm，有点不光彩的档案记录，就是火气大，一吋失手，蹲了几年。儿子无房无车，小学五年级上学期文化，现在送货员，是优秀员工。一个月入八九千。想在上海倒插门。要求女方，

一是独女。上海户口基本都可以。

二是有房子。农村不低于二上二下。城里不低于人均一间房，近期有拆迁可能更佳。

三是要求大专以上文化，反正上海人都是大学生。

四是不能丑，最好165以上，肤白条顺。

五是心地善良，媳妇能够伺候公婆。

六是男方父母退休后，要过来一起住上海。公婆可以免费带孩子。

或许还有第七第八的要求，我借口喝茶，走开了。

我实在是没想到，在农村婆婆眼里，城里姑娘这么不值钱。
