# 高中差生怎么办？

你不要去问老师，没用的。高中老师见多了，无所谓，"这么多学生，总有差生，你家孩子不在学校里受伤，就好了"，或者假惺惺安慰你几句，赶紧滚，老娘在为房贷心烦呢！你也不要去问辅导班，他们的答案，无非是让你报班，"来啊，来啊，我们有精品班，一个五万，最后一席，走过路过不要错过。"你应该问谁？问财上海。兄弟我是，堂堂正宗985，千军万马top1。

高中学生的特点是，家长已经无能为力了。那些sin, cos，根本不认识了。立体几何，老娘当年也没搞明白。什么梦回天线啊留别，留你姥姥。还有什么过去完成时，固定搭配，外国人就是破事多。两个小球撞来撞去，有毛病啊。一句话，家长不要去想自己辅导了，你玩不了。很多高中数理化老师也做不出高考卷子。这是真的。只不过，他们看懂答案后，假装会了，给你讲一遍。

好多差生，不是一科两科差，而是全部差。家长你也傻眼了，下意识是全面开花，一口气报六个班，网课销售代表笑的花枝乱颤，"好好好，满五送一，多买多送，下一个！钱多人傻的250，快点来啊"。全面差，唯一的原因是孩子已经崩溃了，彻底没信心了。上课就像是上班，点个到而言。他自己也不相信能搞好了。怎么从零开始，争取搞个破二本？
