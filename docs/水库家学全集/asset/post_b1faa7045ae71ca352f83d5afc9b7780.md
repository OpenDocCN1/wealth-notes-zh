# 传说中的逆袭

逆袭的最佳时间段大概是1990-1998年。那几年：

1. 只要是个二本，去京沪广深求职，到处都是正式编制。内环线边缘的中小学来个大学生，校长当你是宝贝。那时候房价还比较低。夫妻两个买套房，就像买个苹果三件套一样，不难。
2. 大多数丈母娘不要房子，不要彩礼。那些年，谁家要彩礼就是卖女儿，一起谴责。我就是倒插门的。
3. 升职容易。那时候，大单位的本科比例一般是5-10%，大把大把的好位子等着二本子。现在银行里的支行行长，分行副总，很多都是那几年的二本子。那时候四大行也自不怎么样，还不如电信公司。
4. 赚钱容易。做生意的爆发点是2002年入市后的外贸大爆发，之前打下业务底子的生意人，几年后成功比例极高。
5. 找老婆容易。我们那时候，如果不挑不捡，大学生找个老婆是很简单的，到处都是拆迁妹，等待您的挑选。那时候拆迁妹还很自卑，乡下女人能够嫁个大学生，赚大了。
6. 京沪户口容易。那时候大单位都有户口，只要你是录取，立马送户口。实在不行的，还有买房送户口，十万元中环线两室一厅，当场送一蓝蓝印户口。北京郊区二十年前也有类似办户口情况。
7. 单位发房子。只要是好单位，混到副科就发房子。房子也不算太好。现在3-4万的那种老公房，白送。我有个熟人，当时分了一套房中心的高层，现在价值6-700万。

真正买不起房子，应该是2012年以后，也就是扩展的那些名额进入市场之后，2016年房子有个大爆发，二本子彻底死心了。

### 01 怎么签合同？

做生意免不了签合同，特别是不太熟悉的人。先小人后君子，大家把话说清楚。但是，大部分人都把签合同当做是法律顾问的事情，自己就看看价格，付款时间，实际上做生意不是这样的。

我做生意这么多年发现，所有的经济纠纷分为两种：

一是写到没做到。这个是非曲直比较清楚。这家伙就是个骗子，该怎么办怎么办。

二是没写清楚。特别是一些细节问题，好不容易谈成了，你就想着赶紧定下来，在网上找个免费合同模板，改几个字，签字就行了。大部分出问题，往往就出在这个地方。大量的细节不清楚，谁出钱不清楚，后面吵架不断。

我有个用了多年的办法，你考虑一下：你在谈合同的几天里，把这个事情的全部流程在脑子里过一遍，你把自己定位是对方，你会遇到哪些事情，一个一个写下来。这个合同就完整了。

有一次，我遇到一个租客，不知道什么原因，最后一个月不见人了。怎么也无法联系。房间里东西还在。我就发愁了。破门而入，容易纠纷，万一他有什么贵重资产，例如金戒指，金项链，我说不清楚。不进去吧，一直拖下去，我损失也大。怎么办？这个人我后来联系上了，他回老家离婚，手机关机了。

后来，我专门在合同里写清楚了，如果合同到期无法联系租客（规定联系方式），房东有权收回房子，另外出租，不赔租客遗失的东西。

### 03 做生意一定要做最优秀的那个吗？不需要

很多二本子认为的做生意，就是优胜劣汰，赢家通吃。事实上不是这样的。绝大部分消费者并不能找到最优的解决方案。举例，我家安装一个纱窗花了2480元。我也觉得可能贵了。但是，我实在是不知道哪里的东西，又好又便宜。我只能是去一个比较贵，但是质量还不错的批发城。

这个原理就是很多农民小老板生存的秘密。

你也经常遇到类似情沉。举例，你去买一个你不是年年买的东西，例如运动鞋，西装，房子，洗衣机，电冰箱，瓷砖，装修，房子。面对无穷无尽的选择，你根本不知道怎么挑。最后就是随机选一个。虽然贵一点，但是，你会认为，反正也是难得到买一次，损失不大，东西好就行了。

做生意，很多营业额就是这种随机消费。如果你的顾客都是专业用户，市场上就不会有那么多商品了。例如电脑系统xp，全世界就一家。你也不用考虑了。

结论：让顾客方便找到你，比物美价廉更重要。

### 07 投资人最关心什么？

投资圈有两个流派：

一是靠山屯风格。他们希望一粒米换回一座金矿。他们不关心项目赚不赚钱，他们最关心成长率，如何在一年里开一千个店，两年覆盖所有县城市，第三年去敲钟，邀请前女友和前女友的老公参加庆功宴。

二是内环线风格。胆小慎做，战战兢兢。可以不赚钱，但不能亏钱，否则老婆要骂他。他们最关心的不是规模，而是利润率。新开的店能不能自负盈亏。如果不能上市，也可以卖出去。

所以，当投资人忽悠你的时候，你也可以忽悠他。对症下药，一针灵，三天包好。

### 08 我是打工族，怎么发财？

我一天到晚上班，一没技术，二没资金，三是胆小。我一天到晚想发财，就是发不了啊！这是绝大部分人的现实情况。因为你们的成长路线就是这样的。小学中学到电子厂或二本，然后到处找工作，混个租房房VIP，再想办法骗个不花钱的胖花，凑合用用。结婚生子，再一次恶性循环。我以前也基本上都走过一遍。后来我发现走不通了。

我的建议是，不要再这样下去了。下一次辞职后，就不要再找工作了。想办法自己做个小生意。然后凭借你的聪明才智，争取二十年后上市，再换个小美白。

如何创业？其实也不难。你仔细观察观察你能够接触到的小老板，看看他们是怎么运作的？花三个月，你基本就可以想明白。然后，你砸卖铁，忽悠几个250也参点钱，就可以开始做了。

创业难不难？不一定。其实绝大多数小老板能力不行，只不过，你畏畏缩缩不做事情，没人和他竞争，他发了，你去了，他就垮了。
