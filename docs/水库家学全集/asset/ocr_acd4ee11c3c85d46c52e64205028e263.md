# 01

一桌三千。

我已经听到好几个合法辅导老师和我说道，现在的行情很好，一档百万，二档减半，三档喝稀饭。我觉得特别好奇，凭空想象，大概计算。

辅导班一晚儿200-300是比较多的。每天晚上，凑满一桌（十人）就是两三干。如果有20人（分两拨来），每周末2次，就每星期一万多。一个月大概有5。九个月大概有45-50。

寒暑假三个月。一晚上人均消费300。如果你凑出三桌（比较难），轮流转。一个月是9万，三个月27万。

再加上正常工资8-10，全年80是可以预见的。如果非常有名气的，单价贵一点，人数多一点，一桌3500元。那就超过百万了。
