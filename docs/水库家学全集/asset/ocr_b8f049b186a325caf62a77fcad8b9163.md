# 为什么父子或母女关系不好？

大多数情况是子女看不起父母。父母又觉得，自己一辈子精打细算的绝学，无人传授，气急败坏，张嘴就骂。子女觉得，你这么有水平，一辈子怎么就混在老破小而不是大平层，我痛苦了二十四年，更加嗤之以鼻。

话不投机半句多。很多时候就是这样互相生气，时间长了也就无所谓了。怎么解开心里结？

关键是在套房子。一家人坐在大平层里谈人生，子女就听得满了。这房子能不能留给我是未知数，不管对不对，假装哄哄两个老家伙，别让老头老太去广场舞潇洒了，以后鸡飞蛋打。

结论：父母要是混不好，你的话都是惹人烦心的噪音。
