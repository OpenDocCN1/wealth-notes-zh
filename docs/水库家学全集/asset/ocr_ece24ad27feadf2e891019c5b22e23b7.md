# 如何使用错题本？

错题本是非常宝贵的。遇到错题，二本子和985的区别就出来了。

二本子是把答案看一遍，以后会做就行了。985就不是了。

我们985，一般是脾气凝神，对着做题想一遍，为什么会错成这样？一步一步下来，你就知道了错的原因。一般是两个原因：

一是不知道这个知识点。忘记了。背下来就OK了。

二是不知道这个知识点还可以这么用，我靠！

你只要坚持两个月，保证你飞黄腾达。

# 07

如果你家孩子不是中学毕业班，可以看一下。

毕业班的同学，还剩两个两了，把前面那条错题本看就看好了。不是毕业班的同学，你至少还有一两年，这就够啦。我谈几个争先创优的小办法，给大家参考。

一是刷很多题不是最优办法。最优办法是少量刷题，吃透理解。你拿到一个题，你能不能用一分钟想想，这个出题的龟儿子到底想干嘛？他要考什么？在哪里绕了个圈或布了个迷魂阵？

你放心，那些命题组的人，基本都是我们这个年龄段的二本子，他们的水平有限。能够转弯子的地方就那么几个。你看多了，就明白了。别管是sin多少角度，基本就是辅助线。

二是制定备考计划。每个星期完成多少内容，不求多，务必要做成。不完成不睡觉。

三是尽可能利用好寒暑假，把下一个学期的课程维一把，你开学后，就更好的适应了。人家是学新货。你是翻旧账，肯定你厉害。
