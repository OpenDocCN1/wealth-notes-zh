# 05

# 四十不惑。

这句话，我小时候就知道，但是一直不理解。老子top1，有什么不懂的？什么叫四十不惑？我现在四十岁出头了，也理解了：我终于看清自己是什么货色了！

如果你是二十几岁，三十几岁，周围的人对你有很多幻想，他们对你的态度往往是假的，伪装的。等你到了四十岁，一风水落石出，人们就撕下了伪装，赤裸裸的剃刀见红了。你刚刚考上大学，回村里，大家会很热情。你考上正式编，大家对你热情似火，女儿也可以嫁给你。

这时候，他们对你如此热情，只不过把你当成一个潜力股，希望你发达了拉他们一把。你在四十岁之前，存在各种不确定的可能性，大家也不想得罪你，多个朋友多条路啊。所以，村里人会对你假客气。你可能会非常受用：老子是二老了，光荣耀祖了！在这个年龄段，你往往会错误认识自己。

如果你到四十岁，还没有升职发达，大家就放弃你了，很多事情就撕下了虚伪的面纱，坦诚相见。这时候，你突然觉得，咦，咋回事？他们不是一直很喜欢我吗？为什么这样了？

你以前看到的，只不过是假象。你现在终于看清楚了吧！如果你想提前知道答案，你去看你父母是啥地位，你基本也差不多，没那么多逆袭，只不过换了一个马甲而已。

我在大厂里敲代码，就是以前村会计在煤油灯下拨算盘，声音都一样，噼里啪啦。

# 06

# 我和三姥爷

是截然相反的人。我是自己很快乐，但是不能给其他人帮忙的货色。三姥爷是个牛人，有面子，有路子，对你很难很难的事情，他就是几个电话搞定，很简单的。

我们是走在不同的路上。我一天到晚过小日子，撸吧撸吧叉搞一搞，反正也没人关注我。三姥爷就不一样了。无论星期几，他们家都是人来人往，拎着各色土特产，求他帮忙。三姥爷为人豪爽，基本上有求必应，是圈子里响当当的人物。他们家从来不买水果，因为乡里乡亲送来的，也吃不完。有一次，三姥爷给我一大包成品燕窝，就是开罐即食的。他就随便放在客厅小角落里，多的堆起来了。
