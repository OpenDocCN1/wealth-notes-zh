# 15

加工厂的生存秘诀。

很多人以为,加工厂只要做好技术就分好了。实际上,加工厂最不需要的就是技术了。绝大部分加工厂,都是成熟技术,买几个大机器,找几个工头就开干了。但凡能够熬过一年的加工厂,技术基本没有问题,很多小老板本身就是技术员。但是,加工厂发不出工资,拉卷帘门的,时有发生,司空见惯。为什么?

加工厂的秘诀不是技术,而是拉单子。而且不是越多越好,而是要平均。举例,你们厂的生产能力是一个月十万个拖鞋,那么小老板就必须每个月拿到九万左右的单子,不能今天5万,明天15万,必须是整整齐齐的每月九万份。多了,做不出来,纠纷一大堆。少了,发不出工资,员工堵你门。
