# **06**

# 复本位。

这是五道口金融学的一个小概念。一般学生很少关注它。我们也就是在教货币起源的时候讲几句。大家还记得货币起源的故事吗？货币的本质不是票景，也不是金银，而是一般等价物。你要是理解了金融的底层逻辑，你就会看明白财富的密码。

一开始，大家互相交换东西，改善生活，但是东西越来越多多了，交换过程就很麻烦，于是出现了一般等价物。例如，大家都喜欢茶叶，于是大家就把所有的商品和茶叶进行核算。一只羊20斤茶叶，一头牛60斤茶叶，一斤青菜0.5两茶叶。你把自己的东西换成茶叶，再用茶叶去换你要的塑料桶。大家多方便啊！而且，你也不用担心茶叶会砸在手里。这就是货币的起源。茶叶就是货币，这叫茶本位。

由此可以看到，货币不是天生的金银，而是一般等价物。那么，一般等价物需要具备什么特点？
