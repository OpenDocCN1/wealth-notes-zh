# 02

刚才有个同学和我杠精，北京服装学院比小地方的985如何？肯定是北服好啊！

一是大学本身。你知道菜宝上最赚钱的小店是干什么的？就是服装店。

二是各种专业。服装学院不仅仅是服装专业，还有各种其他实用性专业，例如会计专业，PPT，ps，摄影摄像（统称视觉设计）。以后打工不香吗？

# 03

减轻压力。

现在高考没这么重要了。即使考砸了，也不要灰心。人生道路千万万，不仅仅985。

一是留学。大概是四五十万。

二是学技术。现在一般的大学生，也没有多少工作技能，社会上也不受待见。你要是有个技能，更赚钱。

三是待遇。考大学，即使是985，也不会直接给你带来什么钱，只能保证退休前搞个副高。也就这样了。所以，也不要太担心。

我说个自己的可笑经历。我考进本科的时候，大概18岁。我宿舍附近的食堂里，有个小伙子，大概也是我当时的年龄，看上去就像个大孩子。有一次，我在大教室里听课走神了，突然想起了他，觉得他很可怜。我们是一样的年龄，大学生在窗明几净的985里上课，是社会的栋梁。他还是个大孩子，却只能在昏暗潮湿的厨房里切肉丝，实在是太惨了。我在今后很多年，对这个事情，伤春悲秋的好长时间，毕业后，我还念念不忘。我甚至暗暗下决心，要拯救这些丝丝。

前两年，我意外听说了结局。人家因为切肉丝技术好，一步一步发展起来了，已经是校园附近四个餐厅的小老板了，年入百万，买房买车，老婆换了好几个新的，在海淀三套房。而我这个堂堂正宗的985，现在混成了倒插门。不知道谁应该可怜谁。

小结，做一个有用的人，永远胜过 985。高考不决定人生。
