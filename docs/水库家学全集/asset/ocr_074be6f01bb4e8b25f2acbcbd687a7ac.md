# 年轻人越来越懒了

我们这一代的城市人还不知道去菜市场买菜做，卫生又便宜。80后的菜嫂，直接叫外卖了，说啥也不会去买菜，都是网上下单。如果没钱了，就找家长要钱，如果遇到屌丝家长，就剩下在网上喷了。

现在读高中的农民工子弟也这样了，一天到晚刷题，刷成小眼镜，啥也不会了，一张嘴就是大词汇，你和他没法沟通。这些人中的绝大多数可能会过得不好，父母没有能力给他们在大城市定居，自己内心已经狂野了。我不知道他们今后还有什么办法成为亿豪？
