# 01

回想起一个屌丝。

那是2005年，亲戚托我卖一套房子。陆家嘴地铁站附近的小房子，总价60万。那个亲戚是外地的，钥匙给我，如果有人来看房，就陪一下。

某日，遇到一个光鲜亮丽的陆家嘴sb，一进门就和我聊美联储和国际风云。然后，嫌弃这个，嫌弃那个，也就没有下文了。后来，我问了中介小哥，中介说，他觉得，这房子在他们铁岭老家也就三四万，大城市的房子肯定会腰斩，不要了。现在这套房子，450了。他一生中最大的一次中奖就这么错过了。

# 02

回忆相亲。

当年，top1是不值钱的。因为大家都在单位里，只要是本科，待遇一样。我马上坠入深渊了，在不到几个月的时间里，我失去了十几年来形成的骄傲。我终于看清楚自己了，就是没钱的无房户，没人待见你。

单位同事把我当个保底相亲对象，没人看得上的姑娘就介绍给我。有一次，单位同事给我介绍了一个农村的小学老师。因为是弱弱联合，大家认识了一段时间。

人家实际上班鄙视我的，就一个原因，没房子。你无法想象，二十年前，一个无房户小伙有多惨。她也是没办法，长得丑，收入低，只能捏着鼻子和我交往。在谈的过程中，人家根本不当你一回事。我也没办法，没房子，见人矮一截。后来，人家有了新的相亲对象，利利索索就飞起一脚把我蹬了。
