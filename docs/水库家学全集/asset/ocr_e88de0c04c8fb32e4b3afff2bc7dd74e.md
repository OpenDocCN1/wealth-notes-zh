# 穷孩子适合做什么？

首先是要走正道，否则，下半辈子蹲号子就没意思了。大概看起来，有几个方向，

一是考试好的。码农，三甲，补课，是优选。

二是考试不行的，那就方便了。炸油条，装修队，配钥匙，修助动车。

三是不上不下的。深山老林里修砖头，汽修厂里换刹车片。这个活，需要一些技术，但主要是下力气。夏天蚊子咬，冬天冻得直跳，半年看不到一头老母猪。

千言万语一句话，你不要和有路子的人拼。有路子的人，轻轻松松甩你十条街。你要做的是，别人不愿意干的活，你干好干漂亮。再厉害的主，遇到三甲和装修队长也没脾气了。你说多钱就多少钱。

女生有个比较好的活就是护士。考试成绩要求不高，找工作容易，收入稳定，有社会地位，而且有一定人脉。以后班主任看到你也会给你几分薄面。护士的工作选择面不仅仅是医院，甚至有些好的单位，也会招聘几个护士。当然，护士也有难处，就是比较辛苦，夜班多。富裕家庭的女生不会和你抢生意。我有一次坐出租车，遇到一个师傅，女儿成绩不好，他说，以后就做护士，自食其力，也很光荣。
