# 票据整理意识。

用正规的说法就是档案意识。绝大多数普通人没有这个意识。举例，你老婆买手机的票还在吗？100%不在了。这还是小事情。很多人连中学文凭都找不到了。等你遇到破事的时候，票据是很重要的很 重 要 的 事 情。万一，你被死男人蹬了，你够不能有足够的票据证明资产？你十有八九没有。

绝大多数人家里可能就一个抽屉，办完事就扔在抽屉里，过段时间，你觉得没用了，就扔垃圾桶了。实际上不是的，很多票据可能是二十年后才会用的到。举例，你户口变化过好几个地方，你还能不能拿出原始凭证？基本拿不出了。呵呵，当你要办某个不常见的事的时候，某窗口就要这个，你急的上蹿下跳。

但是，你又没有耐心去收集整理这些东西，太多了，受不了。我教你一个小办法。家里留一个电视机大小的纸箱 子，有什么东西全部扔进去，一个箱子可以管十年。我家阁楼上有好几个纸箱，什么都有。
