# 世界上最难当的“长”是家长。

财上微微博 2021-06-10

![](bbox=[0.48, 0.13, 0.52, 0.15])

公办学校，给辅导班创造了无穷无尽的顾客群。

课外辅导班，已经通过金钱的力量，冲击了公立教育的根本。辅导班里有优点小名气的老师，收入远远高于一般正常中小学的死工资。这就让公办优质老师，心态不好了，也越来越多的流入高收入的辅导班。人才走了，剩下的走不掉的公办老师，相对而言，总体质量就不高了，教育效果也不好了。这又进一步加大了课外辅导班的优势，于是，家长们把精力慢慢转移到了辅导班。

这好比，公办学校设立高难度的考试，但公办老师又接不下来，直接给辅导班创造了无穷无尽的消费群，而且不惜一切代价，十几万的学费都有人愿意。我以前没感觉，现在有娃了，体会很深了。当妈的非常疯狂，绝大多数愿意卖房子给娃上学。我见过一个邻居，出了一年十几万的补课，而他们家还住在20年前的房子里。

大多数公办学校对于孩子的学习成绩，嘴上肯定重视，但实际上又是一言难尽。

一是无能为力。一个班级四十个人，你让老师怎么办？

二是指望家长。现在，很多学校通过给家长施加压力，解决所有问题。特别是娃成绩不好了，他会无休无止的心理折磨家长。

三是心不在焉。学校老师收入也就是平均水平，大城市每月一万多一点点，刚刚够正常体面的生活。如果遇到各种麻烦，很难应付。在这种情况下，你让老师去拼了命干，对于现在的90后年轻人，多多少少不那么简单。

如果高考指挥棒不停，课外辅导班是很难消停的。毕竟，一个中产小资很难接受，让娃中学毕业后去送快递。你一定要停下来，家教就会出现。家教是很隐蔽的，你要想管理，就不容易了。

建议，解决问题，要从源头解决。保留少量985，其他大学彻底放开了算了。宽进严出，全部兜底，娃她们想读书，就让他们读。
