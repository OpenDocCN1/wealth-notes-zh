# 02

读书有用吗？

从增加个人修养的角度来说，有用，祝贺你成为一个有知识的二本大学生。但是读书和赚钱没关系。你读得再好，是你个人的事情，和消费者有什么关系？没有一个消费者会因为你高考分数高，给你发钱的。消费者要的是什么？服务。

你会唱歌，我愿意买单，我也高兴一下。

你会跳舞，我就看看，也可以买单。

你会读书？和我有什么关系？你给我儿子做个家教！不高兴？好走不送。

+   **热门评论：**

**孤独之恋：**读书要为赚钱服务。否则就是白读，修养再高，没有钱，最后也会折服的。

**＿＿＿：**不读书，二本都考不上~不读书，cpa怎么考？读书现在已经不是选做题了，是必做题

**北海不打烊：**读书真的有用，特别是国企单位，如果你是985之类的，进来的等级就很高，工资可以和那些老油条差不多

**明七茶：**这就是用户思维啊。用户要么为喜欢的买单，要么为需要的买单。一般人还是得多读书，才能更好的提供服器呀。

**首城区区草：**对短暂的生命而言，啥都无意义，一切如过眼云烟

# 03

我已经很多年没有读书了。我写微博和读书没关系。

一是文体。我的微博是小学生文体，和读书没关系。

二是内容。我写的内容都是原创，来源于商业战斗，没有什么抄书的成分。

三是信息量。我从来不喜欢蹭热点，和读书看电视没关系。
