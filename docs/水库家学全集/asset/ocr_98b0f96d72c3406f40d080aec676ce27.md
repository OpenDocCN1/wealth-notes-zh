# 06

为什么房东看不上股东？股东太TM穷了。

我见过一个老爷爷，单位里也是部门经理了，这个人非常有意思。单位电脑上永远是一个股票软件，就是一个屏幕都是数字，红绿跳来跳去的那种。他除了开会，就是看盘，然后一天到晚吹他的股票。现在他抱着一个软件退休了，新来的大学生立即把他电脑格式化了他家里就一套房子，还是福利房置换的。他儿子老婆天天骂他。你说他亏了吗？也没有。据说，他炒股二十年，赚了45万左右。他也拉我炒股。我发现股东有个特点，喜欢拖人去炒股。我因为没有余钱，就没去。

有房子的人一般是看不上那点小额的。有房子的感觉不是一般的好，而是好的不得了，评论区可以补充。房子动不动就是几百万的飞跳地平线，直升机蹦哒。股东最多也就是几万块的盈亏，扣扣搜搜的，一点也不开心。还要提心吊胆，生怕一个高台跳水，完了，回家打老婆。我不喜欢炒股票，有一个账号已经几十年没动了，印象中里面可能还有几万块钱，反正密码又忘记了，就当做贡献了。这点小钱，实在是看不上。

我现在也无法理解，为什么有人可以在电脑前看数字，一看就一天，十年雷打不动，有那么好看吗？我还不如看看小区里的中年妇女呢！

# 07

世界上最难学问是管理。

很多二本子笑了，老子最会管理，可惜没人请我。我就说个简单的问题，你在公司里做到了你简历上和面试时的豪言壮语了吗？没有，大部分公司是按照你的表态和能力付款的，但实际上你做不到，再举个常见的例子。公司让你出差，是要你去催款或者跑市场的，你去做干什么呢？你做了很多旅游攻略，主要去玩了一圈，看了三个风景点，然后回来报销跑路费了。

为什么会出现这种情况，因为老板和员工的利益是不一致的。员工最好老板不赚钱，利润全部分掉。老板最好员工996，拼了命给公司拉单子，事实上，谁也做的不好，最后的结果是混沌状态，不知道会发生什么结果。
