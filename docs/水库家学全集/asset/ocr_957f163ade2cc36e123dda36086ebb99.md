# 08

村花要逆袭！

莱莱，我是中部地区的农家女，老家经济不行，都是山里种茶叶，腰酸背痛的，还有小虫子。高三那年，我拿到身份证，就毅然离开，去珠三角打工了。家里有个弟弟，也没条件再读了。我在厂里干了三年就当线长了，当时管了六个人。

下班的时候，我用工资买了个二手笔记本电脑，Word，Excel，都会一点。后来，我觉得流水线没有发展前途，就辞职了。一开始想当带货主播，没有傍一大哥刷火箭，无法生活，就没干了。现在某批发城附近的饭店做收银员。我们那个饭店很高级，一桌都是上千。来的顾客也是当地有头有脸的人，停车位上，有一半是宝马奔驰。

现在，我的想法是在当地买房。我自身条件好，希望找个当地对象，条件也要好的。当地房价三万左右，男方两百平米总要有。我愿意一起努力还贷款，加名字。浙江都喜欢开好车，男方至少也要个宝爷。我家有弟弟，彩礼28万，意思一下就行了。我希望男方是个开厂的，我可以直接去做管理，这是我的老本行。女人也要有自己的事业。对伐？

我今年23岁了，162cm，在我们老家，我算高挑的，皮肤也好，气质也好，很多人都说我看上去像大学生。我压根看不上村里的同龄人，又土又穷。去年端午节，我找一个老乡借五百元，他竟然没回信息了。还大学生呢，这都什么人啊？还不如我的客户。有一次，我的一个顾客吃完饭，给了三百元小费。你看看人家，多大气啊。我当场就留了个信。

我要努力提升自己。有句话说的妙“没有试过，怎么知道自己有多优秀呢？”我没读大学，是家里困难，不是我力行。我现在每天都在宿舍读书，主要是经济管理方面的书。宿舍是四人间，有点吵。不利于我的学业发展。请问，我今后怎么做才能实现人生目标？
