# 06

别墅和复式的区别。

这两种产品，我都住过。我是2001年住的大楼复式。就是高层塔楼里面有个二层楼的单元房子，内部木楼梯。现在不算什么了，当年还是不错的。我对这两种产品的体会是很深刻的。

复式实际上不实惠。我住的复式，楼上楼下都算面积，意思不大。最占便宜的复式，应该是楼上面积算赠送的。以前有一些房子有这个情况，尖顶房子的隔热层，你悄悄打开，装个木楼梯，有种在路边采到人参果的快乐。

复式和别墅，室内差不多，都是客厅和房间。区别是花园。总体来说，花园面积，决定了别墅价值。复式没有花园，也没有别墅的感觉。只不过就是居住面积大一点。
