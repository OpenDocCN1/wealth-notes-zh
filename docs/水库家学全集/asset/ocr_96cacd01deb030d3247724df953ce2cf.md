# 06

房子的钱，从哪里来的？又去哪里了？

这个话题是不能多说的。我尽可能简单一点，讲讲身边事。

+   1，我们这个年龄的人，小时候都见过三蹦子，驰骋在大江南北，田间地头。我们小时候，在火车站，长途汽车站，都可以看到这些人。但你知道这些人是什么人？我们村有个熟人就是搞这个的。附近农民，农闲的时候，每天赚个十块二十块的。生意很不好做，一天到晚在太阳底下，夏天热的受不了，冬天冷的受不了。驾驶员之间还经常有矛盾，你懂的。但是没办法，他不能不做，家里还有几个娃啊，实在是找不到其他的话。

+   2，我家在大城市的亲戚里，有一大半的娃买房了，基本上是双方家长凑300个首付，买个800的，然后小两口还贷。

+   3，现在，我村里的邻居，两个儿子加一个女婿，已经是装修队的小队长了，发的不要不要的，早就不开三蹦子了。他们在大城市赚钱很多，每年过年的时候，就是喝金种子，抽南京烟。还买了宝马。羡慕啊。

大概讲，城里人省吃俭用，把钱投到了房子，农民工通过房子的劳动，赚到了钱，完美了。

一是这事情基本不需要算微积分，农民工可以做。
