# 06

户口。

我家小区里，小男孩的头头是小明。小明和其他孩子不一样，他父母是皖南来这里做生意的小老板，所以小明也是老家户口。他们家买的是小区最便宜的小户型，靠马路的14楼，是个很奇怪的头头户型，比其他大户型的便宜35%，只要八九百万，勉强也算有了个落脚地。虽然现在小明也和大家一起上幼儿园小学，但是，他很快会待不下去了。

小明还小，很活泼，经常带着一群小娃娃在小区里骑儿童自行车，捉蝴蝶，摘果子，呼啦啦的一大群，非常拉风。我看他好像也很享受孩子头的感觉。小明还不懂什么是户口，所以，没什么心理阴影，也不懂得大人之间的窃窃私语，等他长大了，他很快就要离开了。想想也挺心酸的。

我和他爸说，以后娶个环内钱媳妇，一了百了。他爸说，自己一天到晚忙生意，老婆也不会教，孩子学习成绩不太好，以后可能难办了，拜托大家，看看有没有哪家的豪宅姑娘合适的？
