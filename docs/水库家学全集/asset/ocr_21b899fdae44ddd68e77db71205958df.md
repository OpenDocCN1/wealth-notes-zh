# 亿豪生活是什么样的？

我认识的 generally 是十几亿或几个亿的散户壕，大鳄级别的不熟悉。散户的生活状态基本和小白领差不多。亿豪一般有两种，一种是在职的亿豪，还在做生意。一种是闲散的。生意已经做垮了，靠一些资产收入和积蓄过日子。

亿豪，除了在KTV潇洒，平时非常抠门。我有一次在路上遇到一个老亿豪，他在路边买水果，非要人家小贩多送两个车厘子，小贩不同意。两个人就在马路边叽叽呱呱的吵架。吵完架后，他和老太婆拎着一袋车厘子，骂骂咧咧上了宾利，“乡下人，拎不清。再也不买你的了。”

他们一般都有比较多的银行债务。买车厘子的钱，严格讲也是贷款的，肯定抠门了。靠积蓄过日子的，基本就亏酸厉害。我连买个体恤衫都心疼，也要近百元了。我最喜欢打折促销活动。

我以前还收集大超市的贴纸，小小的，四四方方的，大概一厘米见方，集满多少个，可以换个锅。我那个激动啊，有时候买个卷纸也要特意去一次，就为了集贴纸，换个锅。有一次我出来，有几个黄牛看我像是有钱人，就问我要贴纸，我死活不给。哼，我要留着自已换奖品。

还有啤酒盖可以换一块钱，我真的激动大了，有一次请客，买了20瓶啤酒，有一个啤酒盖被保姆擦桌子的时候，扔垃圾桶了，我也不敢脏，不怕累，一点一点找出来了。气的菜姨直跺脚，至于吗？

真正花钱大方的，不一定是资产最多的，而是抓到一个涨停板的股民。这些人赚了钱，基本上当天晚上就会花了。

亿豪实际上也没多少钱。假如他们家有10个亿，大概98%是企业资产，剩下一点点是不能用的房和车，零花钱还不一定有我多。有一次，某个亿豪家的八媳妇过生日，我送了个包，两万多，把人家媳妇乐的。从此以后，对我刮目相看。
