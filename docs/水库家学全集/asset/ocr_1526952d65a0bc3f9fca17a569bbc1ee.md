# 13

郊区有没有好学区？

答：免费的极少。收费的极多。好学区，传统上还是在长宁，卢湾，徐汇。郊区就是原来的县一中，镇一中，农村小学。这是免费的。

但是，现在出现了一个新力量，民办，例如宋校，一大批这种xx外附中附小民办，实验小学等昂贵学校。

如果家庭条件好，郊区读书也不是问题。以后，英国自费研究生走起。幼儿园小学一百万，中学一百万，英国一百万，预算三百万够了。

但是，郊区最大的困难是上班远。一般白领就不适合了。晚上加班费可能就是把车贷了，不划算。
