# 为什么父母讲道理，孩子不爱听？

你要是给孩子说，明天去游乐场，孩子肯定记在心里了。孩子也是个人。他最关心的还是自己的利益。讲道理是需要的，但不能干巴巴的讲，你要把道理和实惠混在一起，胡萝卜加大棒。

我小时候是学霸，内心动力也很简单。我特别爱面子。当学霸是有很多利益的。

最重要的是小红对我青睐有加。我们班的小班长，坐在我后面一排，成绩中下，她看我都特别喜欢，经常讨好我几句。我也特别开心。考试的时候，我经常把身体侧一下，班长就可以考到前十名了。

其次是老师青睐有加。我们高中班主任是个超级凶悍的老太婆。她从来不骂我，因为我成绩好。有很多男学渣被她骂的怀疑人生，女学渣经常被骂到痛哭流涕。

三是在男同学里面有面子。学渣虽然人高马大，一般不会无缘无故欺负瘦弱一点的学霸，这叫血脉压制。学渣看到学霸，心里就矮一截。

四是我也很向往读大学。那时候，读大学就是铁饭碗的保证。

正因为有这么多好处，我对当学霸特别来劲。我是自觉自愿，加班加点的，背书。

现在，好多家长给娃讲道理，是干巴巴的，孩子哪里愿意听？我们家不讲道理，直接金钱刺激＋惩罚。表现好，发钱，看动画片，去游乐场，吃海鲜大餐。表现不好，直接站墙角十分钟。当场兑现，绝不含糊。

我们家的年终奖比娃的同桌高十倍。所以，娃特别珍惜。当然，我们家也有不足，因为中小学注重分数，情商培养差了。我准备到大学再改善。

娃有了工作积极性，再加上合适的读书方法，我家娃目前各方面遥遥领先。
