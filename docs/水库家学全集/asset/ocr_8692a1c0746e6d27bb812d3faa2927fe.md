# 08

不能用大米价格推算金条和大洋的价值。

很多人看民国电视剧，搞不清楚大金条和小黄鱼到底是什么含义，也不清楚一个大洋值多少钱？于是，一些所谓的250专家开始用大米来推算。这是很不科学的。因为以前的大米小麦，是纯绿色食品，产量很低，现在农药化肥上去！一千斤都是很正常的。

比较科学的是按照工资比较。一个学徒工资4-8个大洋，相当于现在3-4千元吧。40个大洋换一个小金条（37.5克）。和现在的金价有出入，但比较真实。
