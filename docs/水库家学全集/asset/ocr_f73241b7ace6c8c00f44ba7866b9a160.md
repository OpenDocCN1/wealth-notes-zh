# 开公司能不能用亲戚？弊大于利。

你的亲戚和马路上的张三李四差不多。而且，愿意在小公司给你干的亲戚，基本都是社会上混得不好的，其自身的缺陷都很大。公司小的时候，亲戚有一定作用，因为可以监督一下其他员工偷懒。但是，这是低层次的。等公司发财了，亲戚就是祸根。你开公司的目的是一直做个小公司？

公司做大了，亲戚们的感觉不一样了。他们觉得自己是公司的恩人，最好你把资产给我们平分分了，你当然不同意。那么，他们就觉得你没有人情味，天底下老板都是一样的糟。然后，好戏上演了。近水楼台先得月，该吃吃，该喝喝。

管采购的，就会和供应商唱歌。

管销售的，那就五花八门了。

管财务的，就会到处说小话。谁谁是妍头，这个月工资两万多。

管人事的就会被老家侄儿塞进来。

娘家婆家的亲戚还要互相干架，你拉都拉不开。

最后，你会发现，真正心疼你的是前台小美。那个温柔啊！
