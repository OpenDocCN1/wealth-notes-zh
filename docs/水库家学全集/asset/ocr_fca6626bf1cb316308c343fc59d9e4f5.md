# 01

考985难不难？理论上你要挤入全省2%的名次。

但是，2%就是凡人，不存在无法超越的因素了。怎么办？很简单，家人比他更利害。现在的利害，已经不是一个人的事情，而是全家总动员。

一是全学中学六年看电视。这个以前很难。现在不难了，家长看手机就行了。或者你家的房子足够大。

二是营养要好。每星期补二次红烧牛肉，清蒸海鲜，红烧排骨，荤素搭配，吃饱吃好。

三是父母有钱砸教育。请好的家教。避免走弯路。有条件进一个好的中学。

四是家里有，来回不累。

五是孩子有拼命的勇气，顽强的耐力。每天刷题到深夜。

六和在学校关系好。家长和学校一起，尽可能避免引发孩子情绪波动的打嘴，早恋，打游戏。

大多数家庭，能留给子女的东西不多。父母的职称和单位是不能继承的，父母的人脉也很难直接给你。重视考试是孩子立身的法宝，也是父母留给子女最好的礼物。当然，这一切到高三就算拉倒了。接下来，就看婚房了。
