# 我说两个熟人白手起家的故事，仅供参考。

财上海微博  2021-06-20

# 01

股权激励基本就是个笑话。

很多不怎么赚钱的老板相信一个事情，如果员工拼命干活，公司就发了。于是，老板搞所谓的股权激励，就是把股权分给大家，以此激励士气。结果好吗？不怎么样。因为这件事情违背了一个常识，努力就可以赚钱的吗？绝大多数企业赚钱，并不是努力这个因素，更多的是抓住机会，而怎么抓住机会这种事情有点玄乎，不是努力就可以的。举个例子，今年的滑板车（或者裤子）流行宽版的，还是窄版的？你努力一个我看看。

股权激励确实可以提高工作积极性，但是，企业赚钱的原因和积极性关系不大。更多的是企业家对市场的判断和运气。股权激励的第一年，企业内部是一片祥和，大家都等着发大财。如果第一年不赚钱，那么效果是相反的，员工互相指责，互相吵架，最后一地鸡毛。与此同时，股权都给出去了，老板对企业也就失控了。

# 02

大厂的高薪能长期维持吗？

现在，大厂员工的收入非常高，特别是有几个著名大厂。这个能够维持多久？我们先要搞清楚，高薪是怎么来的？

在企业高速成长的过程中，新增的利润和市场份额很大，企业的现金流可以支持高薪。但是，一旦进入增长停止，或者生意不好了。高薪是难以维持的。

现在的企业，老板都想通了，如果公司挣钱了，老板是很大方的，真的愿意给钱。但是，这钱的来源是企业利润，不是老板女儿的嫁妆钱。如果利润上不去，分分钟就散场了。

在利润增长期，企业内部一片喜气洋洋，互相吹捧，一大群人兴奋的青春痘都冒油光。但是，增长期是有限的，不可能无休无止，可能会因为你想象不到的原因而改变。我经历过好几次突变，都是千分之一的偶然因素。

我的意思是，天底下没有一成不变的高薪，大家要居安思危，积极进入朝阳产业，果断抛弃夕阳。
