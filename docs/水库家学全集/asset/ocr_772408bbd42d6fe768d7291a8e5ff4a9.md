# 我的心路历程。

财上海微博   2021-03-05

# 01

我的心路历程。

1，我起步是7+3万，买了一个老破小。当时是1999年，马路上也有中介，好像是一个国企下面的，金xx的，记不清楚了。因为有个特殊原因，我家有个住房补贴，大概是两三万，不用就作废了，只能再套七万买了。那时候，十万对一个家庭而言是一大笔巨款了。很多人的工资也就1000左右。

2，第二次买房，是因为我们单位真的取消分房了，以前我们还不信。但是，为了安抚一下我们一大群新屌丝受伤的心，单位给我们发了5万块补贴。我就拿着补贴，又找各种各样的亲戚朋友凑了一点钱，又买了一个小套。我当时买房，实际上就是一个原因，把补贴提出来。

当时，我们全家都公积金加起来有1.3万。

两套房 子，一个自住，一个空置。当时，内环线房子租不出去。小商贩和农民工没有租房的习惯，大学生还没来。过了一年，发生一个有趣的事情。我家有个认识的远亲小伙子，大学毕业，在内环线上班，就租了我的房子。我们老家的习惯是不收钱的，不就是一间房吗？乡里乡亲的，提钱就没面子了。但是，人家小伙子比较懂事情，给我每个月65元房租。你看到这里估计要笑昏古七了， 65元，是的，就这么多。一年780元。我当时也挺高兴。毕竟是收入。那年头，鲫鱼是3块钱一斤。

我当年根本没有想到房子会变成现在这样，我反应过来是2008年。因为我学金融的，就是货币银行学，我对信用货币和抵押贷款的机制区分是很清晰的。然后，就搭上快车道了。

骑上我可爱的小摩托，它 永远不会堵车。。。。
