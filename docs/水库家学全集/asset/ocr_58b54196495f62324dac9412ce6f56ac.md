# 怎么让斗头满意？

额外付出。

一般情况下，你的岗位做得再好，斗头们也觉得是天经地义。就好像你家贴瓷砖的工人，洗碗的保姆，他们再辛辛苦苦，你也不会有什么感觉。但是如果有额外利益，那可不一样了。

+   1，替斗头赚面子。你要是能给斗头发表几篇论文，获个业内大奖，那就OK了。

+   2，额外干活。我上次遇到一个会计师事务所的实习生，他的领导有个麻烦，孩子下午放学没人接。他自告奋勇，天天去接孩子三个月，顺利入职了。

你要是能把斗头的傻儿子初中数学救出奥赛三等奖的水平，你就值钱了。你就是师徒眼里的大功臣。你要是能够找个三甲床位给斗头的丈母娘，你就厉害了。

+   3，斗头有难事了，你找到人，能够搞定，OK，啥也不说了，我认你这个兄弟了。

你啥也做不到？啊，窝囊废，好好搬砖，不要想好事。轮不到你。你就是个废物。
