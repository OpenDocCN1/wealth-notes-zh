二是怎么赚钱？装修小队长的胃口是很大的。一年没有五十万是不感兴趣的。他们报低价，怎么赚钱呢？加项目。

你不要忘记了，他们是免费设计，你在看方案的时候，往往会忽略一些小项目。做到一半，人家会提醒你。这时候，你就跑不掉了。他们的利润来源，就在这里。

如何解决？

- 一是你也要给人家一点噱头，人家忙几个月，也是要赚钱的。
- 二是详细研究方案。一点一滴也不能漏。如果改方案，加项目，你就是人为刀俎我为鱼肉了。这个非常难。特别是隐蔽工程。
- 三是遇到突发情况。我以前遇过一个事情傻眼了。因为隐蔽工程走线不科学，设计的方案没法做了。此时，你要冷静，不要大吵大闹，最简单的办法是迅速放弃或改项目。
- 四是工期。正常是单元房三个月，别墅六个月，实际上都是翻倍，除非他们又接了大活。否则不愿意迅速做完。可以采取奖励。

我家门口有个邮局。我观察了很长时间。我发现他们比较热门的业务是，缴费水电气，邮局存折，卖理财，寄资料。我家的小信箱里，经常有各种广告单。

最近还发现一个有趣的业务。有个大叔在邮局寄包裹，好像是一些糕点。估计邮费超过物品了。大叔和邮局反复解释，我家大姨是年轻时候，从内环线出去的，现在回不来了，住在一个偏僻的地方，一般快递不到。她喜欢吃上海点心，特意要求寄一点过去。

# 普通家庭填志愿，可以考虑师范。

- 1，有面子。教师在家长面前绝对是无敌的存在。管你是什么人，见到学校就要趴着。
- 2，假期长。寒暑假三个月是很幸福的。
- 3，待遇好。有编制的教师收入各地不一样，据我了解，西部小城市大概是一年7个（相当于当地5-7平米），大城市大概是12（相当于当地1.5平米）。还有个别民办校，收入超级厉害。
- 4，有发展空间。一是行政管理岗，一级一级升。二是专业职档岗，中级高级职称。一旦有了中高级职称，还是很好的。
- 5，家长群，略。
- 6，找对象加分。一般而言，教师找对象是比较受人认可的。
- 7，一般不会担心中年失业。

当然，这些优点也不是你躺着就可以得到的，也要尽力争取的。现在，评职称是比例制，竞争激烈。

网课是怎么来的？

以前没有网课，条件好的家庭，例如一些个体户，小老板，把孩子送到老师那里，一对一，或小圆桌。但是，这种搞法成本太高。

一是教师收费，现在一个小时多少钱，大家都明白。

二是来回成本。孩子有时候还要买瓶水，吃个盒饭，一次几十元是可能的。如果孩子小，或者路途远，家长不放心，还要接送，搭进去一个大人。

后来，网课普及了。成本大幅度降低了。那么，能不能不上网课？这个事情有点难以启齿。娃成绩不好了，你说家长还能怎么办？家长想的是，娃长大后会不会埋怨我没尽力？大多数家长实在是扛不住内心的纠结，必须做点什么。但是，家长能做什么？自己教也不会啊。请家教，也没有条件。这时候，网课来了，就当是心理安慰。老子给你付钱了，你再不行，就是你的问题了。

这个问题的关键是，中考高考卡在那里，家长没办法。现在，大多数家长希望体面就业。娃又那么小，你和他讲道理，要好好考试，那是没用的。最好是，宽进严出，大学放开算了。娃想读书是好事，那你就让他读。何必绑着？
