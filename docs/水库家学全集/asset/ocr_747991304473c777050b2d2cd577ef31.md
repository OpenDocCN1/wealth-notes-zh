# 02

买房一定要买地下车库。

最近和几个朋友聊聊天。他们给我一个信息，无论大江南北，出租还是买卖，有地下车位的房子抢手。现在，车已经便宜了，十万二十万都可以，但是，大中小各类城市，停车位越来越难了。很多宝马benz成为小区附近的流浪猫，一天到晚在大街上找车位，车辆很容易被坏，例如被划蹭，砸玻璃。有的人开车回家路上就发找车位。夏天暴晒，冬天积雪。下雨天一身水。

地下车库就很方便了，下雨天到了车库，也没有水，穿薄一点也不冷，直接电梯回家，干干净净，地下车库，一个月管理费80元左右，十年前总价十几万。很多人买房装修把花完了，刚刚入住的时候，附近车位不紧张，租一个车位150元。有的可以直接停在马路边，也没人收钱，一年下来也节约不少钱，也就不买了。但是，第三年后，车位会非常紧张。
