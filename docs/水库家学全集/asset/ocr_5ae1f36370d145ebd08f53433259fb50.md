# 富人是怎么富裕的？

好多人以为二十年前遍地都是金子。这是胡扯了。二十年前，比现在更难。当时没有正经人做生意。都是一些边缘人，例如待业，找不到工作的，村里穷的过不下去了，有问题的人，实在没办法了，撇个小凳子，这路边做生意。

正经人都在挤破脑袋往单位里钻。那时候，单位分几种，一是大单位，可以发房子，二是大集体，发工资，三是随便混混日子，乡镇企业，个体户。进入第一档大单位的人不多。大集体的，相亲都难。我家有几个亲戚，一个中年大叔，在大厂干后勤，就是食堂，包小馄饨，属于正式编制，还有一个精神小伙，在大集体的餐饮店，也是做小馄饨。两个人的待遇，天差地别。中年大叔离婚后也有对象，精神小伙根本找不到老婆，苦的一毕。

现在回头看，发财的主要是随便混混的那群个体户。这些人资质不是最高的，运气也不好，所以无所畏惧了，冲啊！想当年，一边做老师，一边干翻译社的，绝对是不安分人员，单位知道了，肯定要被骂的狗血淋头。

二十年前做生意，是非常难的，我是亲历者。举个最简单的例子，你想做皮鞋，原材料就买不到。机器设备也没有。就算有，也有砸进去一套房子的钱，当年一套房子也就十万八万，你敢吗？你不敢。

我（老婆）家有点投机取巧的。没有买新设备，利用职业技能，修好了一批二手废品机器，组了一条流水线，华丽丽起家的。那时候，时间多，人力不值钱，生产队的场地不值钱，现在不可能了。后来老两口辞职的时候，全家慌得不得了，总觉得没保障了。现在但也没什么了。

总结，一个家族必须有一代人不畏艰辛，自我奉献。运气好就起来了。运气不好，就来一次。我现在要做的是，不要惹事，把各种风险消除，安安稳稳交给娃。一代一代考985。
