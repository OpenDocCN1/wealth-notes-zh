# 08

穿透高考的底层密码。

很多人研究高考，主要是侧重题型，内容，难度，这没有什么意义的。你要是沉迷于这些零零碎碎的知识点，那就无穷无尽了。我们换一个思路，直击高考的逻辑。

这个世界上为什么会有高考这个东西？是为了筛选。也就是说，你只要考进千分之一，就是清北，丈母娘跪着选。考进百分之一就是985，丈母娘必须贴房子。考进15%就是二本，考进80%，就是大学生（谷贱伤农啊）。也就是说，你的任务不是知识，而是竞争。

大家都是人，就看你怎么高效利用时间了。一些打鸡血中学就是这个套路，吃饭排队的时候也在背单词。早上五点起床，六点半就开干。如此疯狂的压榨自己，就是为了多利用一些时间。

不管这个办法是不是内卷，反正打鸡血中学是有效的。那么结论也明确了，把高中三年的每一分钟都用好，你就赢了。

吃得苦中苦，方为人上人。丈母娘欢迎你！
