# 互联网寡头的几个事情。

一是网络放贷。现在谁会去网上借钱？绝大多数是老屌丝家的孩子。这些孩子涉世末深的时候，就被那很高利息的贷款勒住了脖子，根本无力挣扎，实在是太可怜了。

二是网络卖菜。现在谁在卖菜？基本就是一些进城农民，中年人为主。他们背后是一个一个的农村家庭，儿子正在读书的那种。我家附近的菜场，里面的人，基本都是四十几岁的中年人，儿女估计都在读大学，技校之类的。砸了他们的饭碗，确实是有点心酸。

三是网络游戏。现在网络游戏的第一受众应该就青少年了，特别是那些留守儿童。给他一个手机，立马就安静了，否则极为暴燥。这些孩子将来怎么办？

最后形成了一个闭环，小时候让你打免费游戏，长大了去卖力送快递，想花钱就借钱给你。你还能逆袭了？

# 互联网寡头发财的基础。

我们的寡头，实际上是吃到了时代红利。

+   1，九年制，消灭了文盲。App的前提是，没有文盲，能够熟练使用电商软件的人，基本是初三以上文化。这个成本是巨大的。
2，国企不计得失，形成了电信设施普及。我走过千山万水，可以确定的说，我们的电信基础，网络信号，是五大洲最好的。我们已经习惯了从来不断电，在发展中国家是很难得的。哪怕是你在一个犄角旮昇的小山村，也可以用手机支付买地瓜。
3，m2突飞猛进，普及了遍及城乡的高速交通。网购的前提是速度。要想江浙沪包邮，各地三天必达，离不开天量的m2投入，形成三横三纵的交通骨干网。这些钱是无法计算的。
4，农民工进城，造出了大量的快递员。网上生意做成了，谁去千家万户送货呢？农民工来了。这些农民工都是年轻力壮，文化程度还可以，分分钟塞满了大街小巷。
