# 如何超越身边的人？

很多人天天看马爸爸，幻想也抓住风口，做个上市公司，每天晚上找好几个36d陪你喝酒。这种事情想想就算了，不要当真了。你要做的就一件事情，超过身边的人。如果你已经超过了，就不要看下去了。

一是不要乱花钱。能够自己做的事情，就不要花钱。例如叫外卖，一个几十元，你完全可以去集贸市场买些菜，自己做饭。清蒸鲈鱼，自己做，25元吃一条。还有什么很贵钱的辅导班，你小学课本总全会吧？你和畔花辅导，一年节约一两万了。

二是攒钱。不买車，不买保险，不理财，安安心心存点钱。

三是给娃买个小户型。大的你也买不起。你家娃今年10岁了，还有十五年就要结婚了，你先把手首付交了，慢慢还，就当是零存整取了。以后，交给娃，置换也好，自住也好，都OK。

屌丝不服了，那我的人生怎么办？大兄弟，想开点，广场舞上，什么没有啊，大长腿，大阳台，要啥有啥，还不要钱。你现在加把劲，苦练拉丁舞，争当老王子。再去十六铺做几套手工西装（几千块），可以每天晚上点菜，舒舒服服用。运气好，还可以找个三套房的张阿姨，你看你看，婀娜多姿的王阿姨正缓缓向你走来。不要羡慕隔壁老王升职加薪，老婆大长腿，放心吧，那些以后都是你的。
