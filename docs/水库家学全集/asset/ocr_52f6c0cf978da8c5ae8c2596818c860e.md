# 当土老板开心吗？大部分时间不开心。

老板做大了，会遇到一个无法回避的问题，无穷无尽的人要搞你。你必须像学霸一样每次都考一百分，不能有一毫的失误。这个太痛苦了。

有一次，因为采购部的失误，有一批原材料没到，这下子四面八方的压力就来了。生产线停下来，大家嗑瓜子聊天，你还得发钱，不发钱就和你吵架。采购部说是财务部打钱慢了几 天。财务部说是采购部提交的资料不足。法律部说要考虑合同违约金，市场部大哭大闹，好不容易搭个单子，这下子提成没了，不行，你要赔钱。客户说，连续损失太 大了，一天到晚打电话烦你。

遇到这些破事，你也傻眼了。这种事情非常多，甚至厕所堵了，都会闹出一幕幕吵架，员工不高兴。物业开高价。这种事情实在是太多了，无非是想从你这里敲一把大的。能不能解决？

很难解决。今天花钱解决了这个事情，明天又冒出那个事情。好不容易三天没事了，你又紧张的不得了，不知道明天会不会又有大损失。二本子笑了，这是不会管理。实际上，这事情没法解决。每次遇到问题，最糟心的不是亏钱了，而是不知道要亏多少钱。每个人和你谈都是狮子大开口，你要像侦探一样抽丝剥茧，一点点抠。

但是，你也不是什么都懂的，要化精力解决问题是很难的。有一次公司厕所装修后发现，居然没有窗户，气得破口大骂，但是，没用。大家都无所谓。设计的说你没要求，施工的是我干活的。这种事情太多太多了。我实在是心力憔悴。

有一次花了冤枉钱，我买了一个厕所排气扇，前前后后，算来算去，花了不少安装费，最后发现，安装师傅把管子没有接到外面，而是随便一放就走了。事隔一个月发现问题了，谁也不管。没办法，老子自己爬梯子去解决。还有什么屋顶渗水，墙面开裂，电线断路，设备故障，员工要加薪，工艺错误，太多太多的事情，每一个事情都要你的钱，土老板一天到晚急得直跳。
