# 作为老屌丝和各位小屌丝聊聊天。

财上海微博 2020-03-27

# 01

混单位的我，将来会如何呢?

作为老屌丝和各位小屌丝聊聊天。我年轻的时候，也是天天盼望：单位提拔，单位提拔。事实上，很难发生。有的人，25岁不行，盼30岁。30岁盼35岁，以此类推，到现在，有的人已经50岁了，一辈子就想着单位里的那一点点破事，啥也不关心，最后还是老油条一根，啥也没实现，老泪纵横，就等退休了。如果子女读书一般，那就惨不忍睹了。

与此同时，我看到的飞黄腾达的人，一般在30岁就和同龄人拉开了足够档次，一般比同龄人高两个层级，如果你在30岁，还没有遥遥领先，我劝你想开点。人家到了45岁，已经是你望尘莫及了，只剩下点头哈腰的份了。女人也是如此。

如果落后了，怎么办？人生不是只有这一条独木桥。我建议，开辟第二战场。结合专业和工作的能力，做个合法副业，哪怕是写写微博，以后也可以发广告。

# 02

改变我人生轨迹的不是上班。

而是对新事物的敏感度。想当年，我把101%的精力花在单位，加班加点，毫无怨言，可又如何？啥也没有，就剩下一张张优秀论文案的红皮壳子，毛都没有。

在工作之余，我敏锐发现，自媒体是今后的新事物。一个猛子扎进去，意外火了。想当年被人笑称是菜场经济学家，我也不生气。我本来就没有什么面子了，还气个鸟。我现在已经是小广告红人了，也算懂票价了。一天两个小广告是完全可以的，还有上市公司要收购，我简直乐的不知所谓，就想换几个老婆了。

其实，单位有单位的逻辑。你在单位没混出名堂，不一定是谁不好，可能是你性格不适合混单位。那就清楚了，找一个适合你的地方。那么，找哪里？

我认为，传统行业已经人满为患了你把注意力放在新事物方面，或者传统行业的新打法上，应该有收获。我不能强迫你发财，但你也要留点心。
