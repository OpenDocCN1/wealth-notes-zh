# 菜嫂经常说的某家人。

# 01

菜嫂以前雇了一个保姆，给她留下了深刻的印象。保姆，42岁，西南农村妇女，原来是附近大宾馆的保洁员，因收入不高，就做钟点了。做钟点工就一个要求，必须是别墅住家，否则不去。我一开始以为她脑子有病，后来仔细想想发现，这是智筹。因为别墅面积大，一个白班收入就是四五百，如果还有点加活，例如出去买个菜，接个娃，就是多一两百，这钱比较容易赚。

她业务特别忙，都是邻居互相介绍的。我为什么断定她是宾馆保洁员，因为她不怎么喜欢和客户闲聊，工作流程也完全是大宾馆的做法，包括叠被子的手法，非常专业。特别是清洁水龙头。她每次擦的亮晶晶，我估计是专业清洁剂，水龙头都会调整为下水模式，这是宾馆的操作要求。普通农村保姆从来不擦淋浴水龙头。我家是小锅炉，一开就是热水，不存在冷水的问题，根本不需要下水模式。这是她长期工作形成的惯性。

她一般做三家钟点工，她的一个长期客户是xx女星，也住在附近。因为春节没来了，她就抽空打个散工。她一个月到手大概一万多，老公和她住一起，是开车的，主要做机场路线，一天下来，到手六七百以上。两人月入两万左右，没什么开支。房子租的是郊区农民房，一个月五百多，一间房也就是睡觉，白天不在家。保姆吃饭是在东家吃饭。老公吃饭是在驾驶员餐厅。一个月可以存1.5万以上，如果她老公生意好，春节期间多接了几个机场打车，那就存两万。他们这个活，干干净净，没有灰，也不需要抛头露面，保姆一家也很满意。

一个月稳定可以存下1.5万，对于很多农村家庭夫妻是个很开心的事情了。他们有个孩子在老家读书还可以，估计大专没问题。他们现在准备在大城市买个房子，预算四百w，他们一直纠结，是外环线三层，还是内环老破小。

菜嫂经常对我说：你看看人家，这么困难都活出精彩了。你一个大男人，还找老婆伸手要零花钱？我就不高兴了，大声答她：

> 我是大学生，能去开车吗？
