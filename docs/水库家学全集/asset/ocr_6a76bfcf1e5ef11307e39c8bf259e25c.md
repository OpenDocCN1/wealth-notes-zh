# 11

为什么制造业越来越南了？

制造业是有成本的。最大的成本是人员工资。现在的情况是，你不敢辞退，人员成本几乎是固定的，每年上升。制造业的利润是很低的，有3-5%已经高兴的飞起来了。也就是说，在成本很难下降的情况下，只能拼命多做。

举例，这个厂，人员工资是一千万，每个产品赚十元，你必须做一百万个产品才能持平。如果第二年工资涨了，要1200万，你产品很难涨价，那你就必须生产120万个产品，才能持平，日积月累，一年比一年高。

但是，市场容量是有限的，你生产这么多？能不能卖出去？最后可能卖不出去了。你就结束了。如果你卖出去了，OK，每年要做更多。因为工资成本又上去了。
