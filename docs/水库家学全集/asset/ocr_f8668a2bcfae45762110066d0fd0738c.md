# 03

我们的经济还是很好的。

由于现实原因，现在全世界能够大规模出口的，就我们了。如果那些老外脑子发热，不买我们的产品了，可能吗？绝无可能。

假设，他们去东南亚某国买。那么，小国即使全部出口，也满足不了老外的大市场。最后只有一个可能性，把单子甩给我们，他们赚一个过路费。

过路费谁承担？我估计还是老外。因为，我们的出口价格已经接近极限了，不可能再降低了。市场上缺货的时候，谁有货谁牛。

小国能不能复制我们的生产链？绝无可能。你不要以为，生产链就是皮鞋厂里那一点点机器和农民工。生产链包括，高质量的水电气，配套产业集群，机场，港口，高速公路网，高铁，几千万训练有素的工程师和员工。

这个规模大到你无法理解。举个例子，塑料桶很不起眼。但是，你要想做塑料桶就不容易了，你必须有完整的石油工业，否则就没有价格优势了。以此类推，我们十几亿人，花了三十年四十年搞起来的基础设施，不是你几年可以穿越的。

# 04

我们的出口利弊分析。

我们的出口，基本都是民企，面大量广，就好像各家各户老娘们种玉米。这就产生了一个难点，互相杀价。你不做有人做。有很多新公司，一开始抱着“交个朋友不赚钱”的心态，互相杀价，杀得眼红，我不赚钱也要做。举例，东北很多实木家具厂，东西是很好的，后来扛不住了。

老外很聪明，他要定制一万套家具，是分散化下单。你家做一个万电视，他家坐一万个沙发。最后，全部发到某港，他们自己拼出来一万套完整家具。因为量大，你哪怕只赚一块钱，你都会上钩。这样做的后果就是，你没有钱去发展其他销售渠道了，也没有能力自建渠道。人家不下单，你就饥渴了。所以，很多出口企业，现在日子不好过了。

但是，物极必反。由于跨国企业的价格，杀的太凶了，锻炼出我们举世无双的成本意识。我举个例子。我家有个非常漂亮的兔兔小板凳，是木材厂送的。他说，我定制了那么多的木制品，多多少少有点边角料，他们就把边角料收集起来，做成非常漂亮的儿童小板凳，动物造型的，我家小娃娃高兴的真跳。

再举个例子，他们为了控制成本，居然在外地的一个山窝窝里办厂，那个地方原来是生产队养鸡的。老板就一天到晚睡在土房子里，到处都是鸡屎老鼠，气的他老婆三天两头跟他打架。
