# 01

什么是读书？

以我的读书经验，大部分学问本身不难，难得是没人好好教你。一个简单的事情，七转八绕，再搞点微积分，把你折磨的欲仙欲死。

很多学问晦涩难懂，是因为老师把学问搞复杂了。如果有一个 人把非常复杂的内容，以你容易理解的方式教给你，大部分高深莫测的学问也没什么大不了的。但是，没人愿意这么干。因为没有好处。如果学问太容易了，

一是教授就混不下去了。最顶级的魔术师跳起来解密魔术，这还有意思吗？

二是学生愿不愿意学？大家都会了，我这么辛苦学他干什么？就像高中的解析几何，曾经是非常厉害的学问，被破解后，大家都不感兴趣了。

教和学，两方面都没兴趣这么干，谁干谁傻逼。

结论：读过大学的家长，你把你毕生绝学总结一个简单的教育模式传给子女，你家就快发达了。
