# 01

屌丝的顽固性。

绝大多数屌丝对于自己的经济条件是不高兴的，也想改变。但是，屌丝的所谓改变，是不影响舒适性的情况下改变，而且你要包我赚钱。最好你告诉我一个，投机取巧的好办法，要躺赢。

你让他考副高，他说不喜欢念书。你让他贴瓷砖，他说不想太累。你让他加班，他说996不是人。你让他讨好小头头，他说老天天生不会拍马屁。他就想知道，下一期双色球号码，下一个茅台是谁。你知道吗？能不能免费告诉我？

屌丝没希望了。我只是想告诉妹纸，不要指望你通过给他用几年，就可以改变一个屌丝，嫁人之前想清楚。

屌丝的顽固性是他生长经历练就的，难以改变，会奔跑所有愿意帮助他的人。最后，他就一副上下五千年都欠他的吃相，浑浑噩噩30年，很快就去广场舞报到了，

"王阿姨，别跑，我来了。"

# 02

考证有用吗？各有各的用途。

证书分为两种，一是初级证书，很容易，一两个月就出师了。这种证书对于去民企求职有一点点用。因为用人单位觉得，你至少掌握了基础知识，以后进步快一点。但是，这种打激素的小证书对于真正的工作，意义不大。考完就算拉倒了。

二是高级证书。用人单位招聘高薪人员的时候，不仅仅是看证书，更重要的是看业务。没有一个用人单位愿意花很多钱，再来培训一个所谓的高级人才。用人单位想的是，我花了钱，就要立马见效，直接干活。

三是不上不下的中级证书。和高级证书一样，你能不能干活？
