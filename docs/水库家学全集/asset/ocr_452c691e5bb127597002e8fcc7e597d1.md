# 屌丝逆袭

成功需要具备几个要素：一是吃过大苦。因为吃过大苦的人，对江湖险恶的认识更加清醒，也非常珍惜来之不易的财富。富二代好日子过惯了，认为一切都是理所应当的，缺乏危机意识。这种人非常多，我周围比比皆是：富一代创造了几十亿的财富，就是发狠儿子守不住。

二是智慧。这个需要长期磨炼和见多识广。有些人看上去聪明，打牌很厉害，但这不是智慧，而是反应快，小聪明。真正的智慧是，你要看到三年后的事情，能够冷静应对，意想不到的复杂局面和复杂人性。富二代一天到晚很幸福，不愿意考虑这么痛苦的事情。

三是运气。运气是个概率。一百个人只有几个中大奖的。屌丝基数大，中奖机会多。富二代人少，中奖也就少。

屌丝逆袭是经常听说的事情，富二代败家子也是大家喜闻乐见的，这两个类型的故事传播很广。事实上，屌丝败穷家，拆迁去赌博的更多。只不过，大家不感兴趣，没人讨论而已。

逆袭不是一厢情愿的冲动，而是一场痛苦的旅途。你已经吃过了苦，现在需要静下心来增加智慧，再有点运气。
