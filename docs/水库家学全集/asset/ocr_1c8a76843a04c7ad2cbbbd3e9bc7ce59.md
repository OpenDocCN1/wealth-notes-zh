# 人生大事，该不该听父母的？

这个问题比较复杂。一方面，我们也要承认，部分老年人有丰富的经验，他们已经吃过了各种各样的苦头，听他们的话，或许，你会少走弯路。另一方面，很多老年人一辈子都是卢瑟，他们能够精确的选错每一个人生选择题。

那么，年轻人该怎么办？如果父母一直是成功者，你应该毫不犹豫的相信他们，能长期成为成功者，应该是有各种各样的悟性，至少经验丰富。

如果不那么成功，有两个办法，一是他们有没有个别的成功点，如果有，这方面可以听。二是近五年有没有明显的进步，如果有也要听。因为他们反思了过去的教训。

如果一个老年人，近几年也没有改善，一辈子都是窝窝囊囊的，那就算了。即使他们说的天花乱坠，也是道听途说的，没有什么自己的感悟，就是胡同口下象棋的老头，你就笑笑，假装拼命点头就行了。
