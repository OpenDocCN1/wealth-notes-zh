# 为什么会出现天价商品？

去年，我听到一个事情。老家某三线小地方，家教物理，一个暑假，18万。我当时以为是笑话，肯定没人去，后来

听说，他真的找到了两个土豪家里的小猪仔。36万，爽歪歪了，一个暑假就搞定了县城首付。

我就在想，为什么啊？土豪这么蠢吗？后来我想明白了一部分。

一是教师厉害。当地物理头牌。

二是一对一。一门心思教一个娃。

三是当地富人慢慢多了，愿意花钱。

四是花这钱有赚头。如果孩子考不上高中，自费读重点高中，家长妻到处求人，几年下来花钱也不少。如果这个短板

突破了，就不求人了，以后考上985，几百万的收益啊，去内环线娶媳妇，房子都不用买了。

结论，东西不怕贵，关键是值这个钱。
