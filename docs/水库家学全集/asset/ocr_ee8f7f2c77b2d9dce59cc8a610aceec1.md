# 03

985的难度增加了。

九年级以下，一般是两个普通班考上一个，比例是0.15%。我原来以为考上也没什么，最近发觉，不太对劲。我家小娃娃的成绩和其他几个同学，怎么也甩不开。也就0.5-1分的差距。这个差距只是面子，不代表实力。

我把菜嫂派出去研究了一下。菜嫂假装小媳妇，七拐八绕打进入家委，终于搞清楚了状态。原来，各家各户都在发力。现在的大学生家长已经越来越多了，很多全职妈妈更加是劲头十足，娃娃们比拼的是背后的实力。有个985家长发了疯一样训练儿子，一放学就是上网课，我是目瞪口呆。

要不要跟？我和菜嫂憋了好几天。最后，我像一家之主的老爷一样，拍了板：不跟。菜嫂也得听活话。这个中年妇女平时凶的像个泼妇，动不动就要和我练散打了。这次很乖，从了。

菜嫂遇到几个全职妈妈，他们的决心，说出来你都不敢相信。小明妈妈是个阔太太，老公是某连锁酒店的老老板，年入过万的水平，她每天上午七点多把娃送到学校，然后就没事了。她苦中作乐，就去学校附近的小餐馆，吃一顿好的，一般60-80元。然后开车出去瞎逛了。她一般逛几个地方，

一是大商场。各种时髦衣服裙子包包，基本都买，时刻为斗士准备。

二是考素质培训班，各大知名机构的儿童培训班，亲自试听。

三是研究售楼处。她一天到晚去看盘。从早上八点看到下午3点去接娃。日积月累，对于学区房规定，门清！

小结，现在中小学的部分家长，劲头十足，你们也要考虑适当方法。
