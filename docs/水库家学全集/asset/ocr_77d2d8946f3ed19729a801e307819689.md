# 04

桑塔纳和一室一厅。

在我刚上班时，内环线三四千，一室一厅也就12-15万，相当于一辆桑塔纳（14万）。我年轻时认为，要是有一辆桑塔纳，我就是这条街最靓的崽。我可以带着女票去宝山松江旅游。那时候，各地来的漂亮姑娘，遍地都是，纯天然，要啥款式都有，不稀奇。

我们当年的利益格局是这样的。中层头头，可以固定用桑塔纳，随你怎么开。底部小头头是两个人一辆，隔着开，或，一辆桑塔纳换成两个五菱。当时，很多小头头愿意换，毕竟有一个自己的车就是幸福人生。

我有一个同事也是车迷。他属于冷板凳类型，五十岁了，还没混上一辆车，实在是心酸了。他老婆是本地人，拆了。这时候，刚放开私人买车了。两口子一合计，他就买了个赛欧，也算是个人了。当时，赛欧最便宜，六万多，相当于半套房子。

有了这个车，他们家过上了幸福生活。他和老婆每个周末都出去郊游。车后备箱里带上火腿肠和面包，去宝山南汇旅游，偶尔来个户外小烧烤，幸福极了。我们也很羡慕。写到这里，大家觉得马上要悲剧了，事实上，恰恰相反。

我们那个年代的人，就是活个面子。那个年代，面子就是3个东西，位子车子房子。既然位子车子不行，那就房子。当时已经不能回乡下修房子了，在郊游途中，他们意外看到了一些小别墅。当时，这些小别墅在郊区，也不贵，三四千。

当年的土鳖设计师，也不懂别墅的意义。设计师采取了一个土老倔的办法。在KTV里抄一个别墅的外观，再配一大块花园。冷板凳和他老婆，千挑万选，搞了个靠近中环线的入口别墅。我印象中在张江附近。

二十年后，当年有车的头头都退休了。一大帮老头排在一起发现，就这个冷板凳，凭借一个有大花园的别墅，笑到了最后。人生真的是有无数个意外。
