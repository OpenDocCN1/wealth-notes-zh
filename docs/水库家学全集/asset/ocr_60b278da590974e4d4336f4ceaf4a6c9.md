# 03

面积。

对于在市区憋屈过很多年的人而言，居家面积是个无法抵挡的诱惑。但凡有一点点可能性，你都会不惜重金挣面积。我就是这样的。结果，被包工头引到沟里了。

现在，各地流行送面积。最多的是两种，底楼送地下室，顶楼送阁楼。99.99%的人是抵挡不住这种诱惑的。甚至，开发商以此作为噱头，卖高价。

为了这个诱饵，我付出了沉重的代价。希望大家以我的教训为戒，不要为了一些实在是用不上的面积，肆意花钱。我的建议，

+   1, 如果你家面积在100平米以下，那么有必要折腾，如果超过一人一间房，就不要浪费钱了。

+   2, 层高低于两米的阁楼，没有窗户的地下室，不规则的区域，没有通道的区域，不要多花钱，就算你搞好后，最后只能当仓库，放一下不值钱的破烂，绝对没有利用价值。不要试图通过巧妙的设计去浪费钱。你搞好这些可能多花三十万，最后放些不值钱的纸箱箱，没什么意思。

# 04

不要把房子当股票分析。

最近，有些屌丝无事生非，把股票的分析手段，改头换面用在了房子分析上面，创造了很多这个比例，那个率的概念。这样做的目的是，他天天有话讲，几个数据翻过来，翻过去，一天到晚讲啊讲的，还讲的头头是道。好像还有迷惑性。这是很二逼的事情。

房子是长期居住项目，绝对不能用股票的思维去看。二十年前，你家买的房，会不会因为几百个涨停板就卖了，全家去跨桥洞了？不可能的。

我专门考察过欧美，我发现我的同学里，日子过得好的，基本是父母有家族房子，自己赚多少花多少，不用买房的家庭。发达国家福利比较完整，如果不买房，就很潇洒了，不需要存钱。

我的建议是，不计得失，千方百计搞到位，留给子孙。长期看，你肯定是赢家。
