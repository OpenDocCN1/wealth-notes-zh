# 03

为什么屌丝越来越懒了？因为没有生存压力。

上一代人，勤快一点的，都赶上了好时候，基本上解决了房子车子，有拆的，有买的，好一点的在大城市，差一点在小县城。

自己好像读过几年书了，看故事会没问题，好赖也是文化人了。现在高职也是大学生，怎么能去干农民工呢？

瞌睡就来枕头。现在，各地方居然有个考编制大赛。我要正式编！以此为由，可以在家玩很多年。简直是太好了。

有了小县城的房子车子，搞个黑胖花不是问题。

你看，一下子什么都有了，房子车子女人，舒服死了，还不用上班。小县城物价低，隔三差五，吃顿好的，两百块钱的火锅，那是满嘴流油，还可以对着服务员阿姨，大呼小叫，你们快点，顾客不高兴了。周末，带上黑胖花，去附近的小水库玩一下，自驾游也不花钱，到了山顶，吟诗一首：像我这样优秀的人，本该灿烂过一生。

老子不服啊！

# 04

男比女多是很正常的社会现象。

女性比男性寿命长，放到大数据中，也没什么。实际上，大城市女人找不到男人的情况更多。我周围，女人没男人的，到处都是。男人没女人的，基本听不到，哪怕是老爷爷老保安，也时时刻刻有个四五十岁中年妇女用。

我家小区有个保安大叔，五十岁左右了，虽然穷的一笔毛糟，但个人生活丰富多彩，还经常换女友。他的女友，大多数是保姆，收入高，看上去白白净净，脾气好，肯定爽死了。他还挑挑捡捡，不肯确定下来。我家隔壁是一对中年夫妻，白天很忙，基本不在家，保安和老保姆就在他们家的大花园里喝咖啡，谈恋爱。法式大宅，鸟语花香，绿树成荫，是该情说爱的绝佳场所，比大学环境还舒服。保安还喝男主的肥宅水和虫草，有吃有喝，还有免费用，干好了，还可以回去睡一觉。那那，舒服的不得了。

有一次，女主回家遇到他们。保安说，来检查门铃，也就掩饰过去了。我实在是太真的是羡慕嫉妒恨。我家以前有个保姆，我曾经问过，保姆谈朋友的情况，她说一大半是这样的。保安人头熟，经常介绍保姆中介，还提供电瓶车服务，充电停放照看，很受欢迎。保姆觉得，和保安熟悉，也是一个很大的面子。不谈朋友的保姆，如果有介绍生意，保姆还要给保安一条红双喜。

哼，等老子以后翻起来了，也要去当保安！
