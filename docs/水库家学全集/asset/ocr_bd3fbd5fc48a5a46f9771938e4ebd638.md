# 08

交朋友要少而精。

成年人的世界里，交朋友，实际上是两件事情。一是花钱。吃喝玩乐KTV，互相攀比买个股。这些都是消费项目。二是时间。你要花很多时间去帮忙。各种各样的事，烦的你头大。

事实上，你投入了这么多，99%的朋友也不会有什么回报的。你认为手机里都是你的朋友，实际上只是些熟人。几块钱的小事情，收个快递，可以帮忙，大一点的事情，你就不要胡思乱想了。人家也不傻，你来吹几次牛，就想换个工作工作。你想多了。

成年人的气义，一般是资源交换的铺垫。你出个老k，我出个皮蛋。如果你仅仅是空手来的，那就没什么事了。我有个屌丝亲戚，一心想做老板，半辈子在结交高端人脉，实际上就是和人家用个酒，买个单，啥也不是。他折腾到四十岁，经济上一笔吊糟，老婆都离婚了。

真正的手空手套白狼，实际上是少而难。朋友不需要很多，有那么一两个不看眼的，误认为你是人才，就够了。

# 09

占便宜。

我长这么大，没有占到过什么人的便宜（直系亲属除外），偶尔卖鱼的给我抹掉一块钱零头，是有的。实际上，我也想占便宜，就是没办法啊！为什么呢？因为，别人也想占你便宜。两个丝丝互相算计。实际上，啥也没有，白忙一场。

人到中年，我悟出一个道理，别人不比你傻，明面上，你不可能占便宜。那么，怎么才能发家致富？要靠时间的沉淀，时间是有价值的。

我本科班级里，有不少聪明同学，毕业后，各奔东西。二十年后听说了一些情况，令人唏嘘。现在高低差距很大，无非是一个原因，地段不好。有个同学在北方小城市，比在大城市的，直接打3折。想当年，他也是很聪明的。人比人，不能比啊！
