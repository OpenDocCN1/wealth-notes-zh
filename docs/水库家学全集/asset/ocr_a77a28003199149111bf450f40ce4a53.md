# 我有过一个神奇的经历

体验过大半年高考落榜的感觉。我们当年发成绩不是电脑查分，而是学校派一个老师去考试院抄分数，一般只抄上线同学的总分。过几天，详细分数单会寄过来。我那年考的太高了，抄成绩的老师一激动，就专门用香烟壳子，把我各门成绩，全部抄下来了。抄完成绩，老师就找了个公用电话把分数报给学校。因为我的成绩，他是另外写的，忘记说了。这就导致一个意外发生了，电话里漏报了我的成绩。

当时，同学们都在学校操场等分数，我最后发现没成绩（等于落榜）。那个时候的痛苦，是语言难喻的。当时，校长爸爸还在教室里可惜，菜菜怎么落榜了？考上的同学，弹冠相庆。没考上的，就拿我做心理安慰。

等查成绩的老师回来，告诉校长爸爸，这次第一名是菜菜。校长顿时傻眼了。于是，两个老师紧急赶炮跑到我家来，我记得那两个老师，夏天热的上气不接下气，通知我考上了。我当时还是个娃，已经哭的像个傻透了。

我那一天经历了人生悲喜剧，也看到了很多同学的嘴脸。当他们知道我没考上的时候，一万种嘲笑，铺面而来，没有一个人安慰我。后来，同学们也陆续知道我考上第一名了，有个家庭条件很好的小斑花主动要和我搞对象。那时候，我还不知道以后的路有多难走，居然没同意。珊那，蠢啊。
