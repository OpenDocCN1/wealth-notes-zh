# 为什么贴瓷砖这么贵？

因为没人干。上海人为什么不干贴瓷砖了？多年前，我有个亲戚在内环线建筑公司上班，做的就是这个工种，上海人管这个叫“泥水匠”，就是泥工，玩水泥沙子的。后来，外地农民工来了，他就不做这个泥水匠了。每天安排一些杂事就算OK了，再后来就不会干了。

第一代农村瓦工，赚到了很多钱，回老家盖楼是轻轻松松的。但是，瓦工也有难处，主要是灰尘大，有点脏，瓦工自己的儿子也不愿意干了。

于是，这个行业慢慢的没人干了。现在大修基建，泥瓦匠很吃香，工资飞上天了。今后会如何？

泥工肯定是继续涨的，除非m2不搞了。但是，m2涉及方面面不仅仅仅是泥瓦匠，还有太多太多的一般制造业，例如近三、四十年，空调好卖，就是房子多了的原因。空调厂投资很大，一般企业开不起来，所以都发了。

我不知道为什么有人想当然认为大城市房价要暴跌，这是不可能的。想都不要想。我已经等了几十年了，还想再买几套。你暴跌一个看看？有梦想是好的，胡思乱想就不好了。

反正腰折你要买不起，你看是不是干脆送给你一套苹果园的三居室，好吗？
