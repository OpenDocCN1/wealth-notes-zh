# 04

做生意

我老婆家是1993年下海的。我前两天问：当年一起创业或做生意的友商现在怎么样了？

老丈人说：除了自己，其他全部呵呵了，个别人粘上了高利贷，下场非常惨。我听的汗毛都竖起来了。

老丈人说，现在交往的那几个几十亿的友商都是后来认识的。特别是进入某商会后。幸存者偏差而已。

2008年是个分水岭。之前赚钱的人挺多的。之后就没什么好消息了。

2012年是关键一年。那一年很多人被担保拖垮。

这两年更难。只有佼佼者才活下来了。

本来以为熬过2019年就好了，没想到，还会遇到更艰难的事情。

现在，随他了，爱咋咋地吧。
