# 怎么拿下白富美?

白富美和屌丝们想象的不一样。绝大多数屌丝以为白富美是高端大气上档次，天头条等舱，龙虾鲍鱼五星级，实际上不是的。白富美大部分和普通人没什么外观区别，只不过多了一些房子车子存款。一套房子就两千万了，如果多几套，就近亿了。

白富美有个很痛苦的地方，高不成低不就。白富美的生活圈子很小，要么是几个闺蜜啊聊天，要么是同学出门溜达一下。在生活圈里，互相认识的基本都是各公司的老板儿子，也就是点个头的事情，大家也不熟悉。特别是人家也是娇生惯养，凭什么给你笑脸相迎。因此，非常多的白富美在生活中根本遇不到合适的男人。到了27岁，家长就急了。

安排相亲，基本是有条件。一开始要求挺高的。但是，好货早就抢完了，哪里还有剩下给你相亲的？不断的降低条件。最后170cm，也有机会了。白富美当然是各种看不上。然后就单了。而且，绝大部分白富美很拒绝相亲这个流程，她们希望有几个条件特别好的舔狗。一天到晚围着她汪汪汪。实际上不可能。

我家周围就有一大波这样的白富美，她们经常是急得直跳。一到过年聚会，老姑娘们吃一桌，可怜的不受不卖的。我当时看的是目瞪口呆。没想到你们也有今天啊！那么，如何拿下她们？

一是985，土豪不看重房子车子，就看学历。他们总娶妻一样。正常情况下，你没有小鲜肉的外表，只能走学历这条路了。如果是二本子，也没关系，像我一样，读个函授top1。老子是函授top1，理直气壮。小秘密，不管你是不是函授，学位证书看不出来，都是一样的。二婚的，建议搞个博士学位。

二是尽可能接近各种土豪。白富美不太轻易相信人，必须有人介绍，你才能进入圈子。接近土豪，就是给你介绍一下。放心，很多人愿意介绍。他们把这个当做交际手段。

三是假装舔狗。不要怕，放心大胆的舔。抬手不打笑脸人。你就安安心心舔一年。你放心，绝大多数白富美扛不过29岁。

四是做好两手准备。老家县城的翠花也不能放下。总要有个退路啊。你当我傻啊？
