# 亲戚没什么意义了。

财上海微博 2020-05-19

亲戚没什么意义了。

在我们小时候，亲戚的作用是巨大的。那时候大家没钱，亲戚就是一种互助机制。举例，搬家，九十年代以前没有搬家公司，你根本找不到人给你搬家，只有找亲戚了。我们小时候，女儿出嫁，送嫁妆是个大事情，全部是亲戚帮忙，一路上敲锣打鼓，到了男方家里，还要放鞭炮。再比如找关系买彩电，亲戚越多，你找到源头的可能性越大。

现在，亲戚就剩下一个作用了，借钱不还。现代服务业高度发达，需要亲戚做的事情，社会分工就解决了，搬家有搬家公司，婚庆有婚庆公司，婚宴有厨子公司，买彩电有黄牛。什么事情都不需要亲戚了。农业社会的习惯是万事不求人。你今天找亲戚，意味着你今后要付出巨大代价（若有能力）。有本事的，你帮侄儿找个工作。没本事的，你就出力气。反正把你搞得团团转。
