# 大部分没有发财的聪明人

其实就一个缺点，太懒了。

很多赚钱的机会，大家都看到了，但是真正赚到钱的人不多，因为聪明人不愿意去干。聪明人最喜欢，什么事情都有人教会我，扶我上去，利润全归我。

世界上没有这种事情，我教你写自媒体，但是我没有教你怎么挖掘热点，这个需要结合你的业务特点，自己开拓。什么是开拓？多干。干一百次，有可能成功几次，总结一下成功的那几次是什么原因，再试验一下。

我以前卖塑料桶，也不知道哪些塑料桶好卖，哪些地区生意好，就是拼命跑，一年又一年的总结。这么多年，我遇到过太多的聪明人了，无一例外他们都没有好结果。因为他们投机取巧，但他们的实力不允许有一次失误，实力小又偷懒，最后都倒灶了。

这么多年来，我一直说，苦干 + 巧干。什么意思？

苦干就是在热门行业去搏杀，热门行业生意多，你总能找到几个业务先把生意做起来。巧干的意思是说，你要不断总结经验，让自己的劳动力越来越有效率。
