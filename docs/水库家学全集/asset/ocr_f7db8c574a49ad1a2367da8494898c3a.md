# 你告去呗！

赶紧赶紧，告的人多了，不缺你一个。这句话，我实在是听的太多了。主要是物业说的。因为小区里存在大量的脏乱差，物业只喜欢收废品，对其他不感兴趣。你有什么投诉，他就一句话，你告去呗，令人顿时卡住了。

告状是个非常耗时间的专业技术。

一是首先要写个妆纸。我估计95%的人写不好。抄也抄不全。

二是时间。打官司一般是非常漫长的，绝大多数人都是要请假去的。写各种各样的法律意见文章，引经据典，找法律条文，不是一般人可以完成的。

三是精力。一般打官司都是双方各有一片道理，甚至是无中生有，你要找各种证据驳斥对方的污蔑造假，这个工程量巨大。

很多人上有老下有小，各种事情，焦头烂额！没时间去打官司。如果对方是个超级必胜客，一大群专家和你辩论每一个字，就算你是清北法律系博导，你也没精力去——搞定。漏了一个，你就头大了。

大企业一般有律师，一天到晚专业打官司，打几年都可以，十年也没问题，最好天天有官司，这是主营业务啊。普通人哪里受得了？至少心里压了一块大石头，严重影响生活。

大企业的傲慢，就是看准了你耗不起。

小样，和我斗？你也不撒泡尿照照。

我家这两年被人欺负了，你们爱我啊。
