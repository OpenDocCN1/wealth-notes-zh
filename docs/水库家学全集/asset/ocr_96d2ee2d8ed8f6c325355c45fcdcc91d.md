# 找老婆，能力也很重要。

大部分痛苦是看房带来的

![](bbox=[0.48, 0.12, 0.52, 0.14])

我年轻的时候正遇到买房热，单位里的人都在买房，装修好了，一般会请大家去看看新房子，我也就跟着吃饭。每次看完，心态都有损了。

买房的一般是中老年人，单位发的小房子卖掉，置换成大房子，十多年前，我去看了一个同事新装修的别墅，三天没缓过劲来。那时候，我还在老破小蹲着，这个刺激实在是太大了。

现在，售楼处免费看房，很多人没事情就去看。你看完了，估计回家就想哭一场。尼玛的，老子什么时候能够得一个这样的房子。

没有比较就没有伤害。年轻人千万不要没事给自己添堵，八百一千多的房子，是咱们应该开的吗？咱们最多也就是看看存款三倍的房子，例如单位附近的老破小、好房子看多了，心态就不好了，就像看到别人家的大长腿，你回家就看不上自己的柯基了。

特别是女人，没事不要乱串门，串多了，心态就不好了。张翠红还没我漂亮，凭什么住豪宅，老娘也是正牌985，现在混到了老破小，天天面对一个猪队友，你说气人不气人？

不要羡慕那个死女人，说不定她在豪宅里，天天挨揍，买的包包是七浦路的地货，老公也不回家。这样想想，心情就好了。当然，豪宅里的大部分女人没这么惨。

也要说说大老爷们。你都28了，还没当上霸道总裁，还在老破小里当VIP贵宾，每个月还要和房东嚼几句房租晚几天，好意思吗？买房是小事情，就交给女人算了，你要把精力集中在大事上，最近阿塞拜江又不开心了，你分析一下，看看和珠江新城有没有关系？

二本在手，天下我有！依房子买好了伐？
