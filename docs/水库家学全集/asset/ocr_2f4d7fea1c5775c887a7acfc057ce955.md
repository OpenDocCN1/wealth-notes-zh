# 万丈高楼平地起

很多人对卑微的生意不感兴趣。他们喜欢马爸爸那种，动不动就是几百亿。实际上，你不要研究了，没用的。

所有的大生意都是小生意起步的。莱嫂家开厂的时候是九十年代，那时候太可怜了。员工们一个月几百元钱，还要托关系才能进来，加班加点997是正常情况。小老板也不挣钱，为了买几箱螺丝，反复砍价，东窜西窜。出差五个人住一间房，轮流睡床铺，其他人用被单打地铺，第二天被清洁大姐跳起来骂，就为了节约一点点小钱。出差吃不起好东西，就在路边小面馆解决。

没有卑微，哪有高大。现在，莱嫂发达了，再也不用开金杯送货了。我的意思是，大家不要鄙视小生意。从小生意做起，一点一滴积累经验和本钱，慢慢往上走。我以前买房的时候，在工地泥水地里面走来走去，身上一身泥，像个拾荒的。为了贷款，到处复印资料，跑的上气不接下气，哪又怎样？

老王去年花了十几万包下了我们村里的半座泰山（山坡不大），说是买茶叶送客户。我和老王熟悉的，这屌丝就是个破落户，初二辍学，家里穷的小偷都不来。当年实在没办法，十八岁出门打工，拎灰桶，拌水泥，打工五年学会了贴砖，16年后，成为装修公司老板，现在年营业额1500万。你想想，装修是多暴利的生意。现在，他出门开了个benz，还有一个本地驾驶员，老板长，老板短的叫他，除了老婆岁数大一点，其他都已经更新换代了。

前两天，他发了个朋友圈，人模狗样穿了个西装，用法式高脚杯喝葡萄酒。不知道的人还以为是大老板。我还。
