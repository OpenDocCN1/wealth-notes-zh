# 做生意如何起步？我折腾了很多年，说说体会。

财上海微博 2020-05-04

# 01

外贸企业能不能转型为内贸？基本不可能。

外贸企业没有什么自担风险的思维。外贸厂很有意思，他们相当于一个品牌企业的生产车间。你发个样品过来，或者ODM，自己做个样品，你下单付钱。

品牌企业最大的难题是，本季度生产多少？举例，做滑扳车的，做洗衣机的，做手机的，那么你提前生产多少？生产少了，各种费用太高，不赚钱。做多了，卖不掉，直接亏损。只有做的刚刚好，才能赚钱。

外贸企业从来不考虑这个事情。因为他们做多少是按照合同来的。也就是说，他们是零库存思维。内贸是库存思维。

外贸能不能赚钱，看的是你拉到多少单子。内贸不一样。滞销商品，例如某款手机，打五折也没人买。爆款，例如某口红，有多少卖多少，内贸不存在拉单子的问题，完全看产品是不是畅销。

你让外贸厂的董事长预测哪个产品卖的好，提前多做一些，那是绝对不可能的，保准那个总经理吓得尿裤子。

聪明的二本子马上跳出来了，我会用Excel统计数据，只要卖一个月就知道哪个是爆款了，我再加倍生产。这是不可能的。因为，错过时机，消费者就失去激情了，与此同时，竞争对手会生产出类似的产品充斥市场。

# 02

外贸。

举个最简单的例子。外贸王老板拉到一个花裙子订单，一件25元。人家拉回休斯顿卖250元。这段时间，王老板生意不好，他能不能自己做一万件拉到石家庄去卖150元？不可能的。因为他根本不知道石家庄的姑娘喜欢什么花型，万一不对路子，那就赔大了。

就算你老婆是石家庄的，但你知道怎么卖掉一条花裙子吗？你不知道。肯定有人告诉你，网上卖。那你告诉他，30元一件，一万条，问她敢不敢进货自己去网上卖？他不敢的。因为这些人都是在吹牛。
