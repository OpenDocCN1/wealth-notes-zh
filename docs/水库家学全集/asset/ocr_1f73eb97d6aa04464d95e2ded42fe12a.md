# 12
不要焦虑。

所有的焦虑，其实就一个事情，你的实力配不上你的幻想。你一个农村二本子，也想在大城市有房有车，还要找个肤白貌美大长腿的收银员，还看不起老家县城，你可不就睡不着了吗？

我年轻时候，因为没房子，被一小群美女看不起，日子可不好过了。那时候我就幻想，要是我也有朝阳三村的二居室，岂不是美哉？想着想着就睡着了。你也可以试试，先来一杯牛二，再想个好事，例如白富美哭着喊着要跟你。

后来，我也想通了，倒插门也是人，不能错过，于是我过上了有房有车的美好女婿生活。倒插门也要提高警惕。现在的丈母娘要有空城计，有一夜发达，也有不如人意。你看好了，买定离手，各安天命。现在，倒插门竞争激烈，要有提前准备的考虑。

一是收拾干净。每天洗衣服，熨平衬衫裤子。我现在已经完全适应了西装笔挺的生活。

二是逢人就夸，妹妹长得真漂亮。你放心，夸一百个，总会捞到几条傻色的。也别客气了，先用起来。

三是筑巢引凤。狗子也有个窝呢！你总不能让母的，在人家家里下崽。

四是不走回头路。你混成这样了，你儿子要不要再来一遍？

社会 很单纯，复杂的 是人。
