# 05

白手起家。

老王是我远房二舅。从小不喜欢读书，三代贫农，十六岁辍学，家长把他送到一个只有十几个农民组成的乡镇小厂搬砖头。就这个出身，也熬出了千万身价。

搬砖头，有工资。二舅很高兴，一天到晚快乐的搬砖。那时候，乡镇企业最重要的销售，厂长每次出差总要带个小跟班，厂里每个人都很忙，就二舅的事情不太重要，二舅就跟着厂长到处跑销售，时间长了，认识了天南地北的客商。

厂里又缺个修机工，需要一个年轻的，二舅又转行当了修机工，机器也熟练了。

后来，老厂长退休了，需要一个懂销售的管理人员。二舅就当上了销售科办事员。然后经过十几年摸爬滚打，当上了副厂长，管机器维修。

后来搞市场经济了，二舅自己搞了个小厂，后来WTO，二舅就发财了。

结论，做人做事，一定要苦干+巧干。光会吹世界格局，是不行的。

# 06

经济学是干什么用的？

经济学最大的一块内容是借钱，利率，信用，反正就一个意思，怎么借钱，怎么赖账？借到钱就是王道。为什么经济学如此关心这个点？说起来好可笑。这是因为经济学起源是个美丽的误会。

世界上本来没有经济学这个科目。两百年前，欧洲还是一大批王子宫女的天下，这些王子没事喜欢打个架！抢人家老婆和庄园。打来打去，时间长了，出现了一个问题，打仗是个奢侈品，欧洲的王子也就是个乡镇的规模，支撑不起打仗的开支。那时候的钱还是金币。于是，王子和公主在被窝里吃了几口窝头，然后想了个办法，打仗能不能分期付款？

先找人借钱，打完了，以后慢慢还钱。于是，各国的枢密院就把工作重点转到了借钱。发债券，凑股份，算利息，分期付款，千奇百怪的事情就发生了，一群屌丝就在研究，金币太恶心人了，能不能发纸币，哄哄那些厨娘和理发师的儿子。这纸币马克就是大王说了算了。白雪公主一拍大腿，高兴的跳起来了。

于是经济学中最重要的内容，货币学就诞生了。
