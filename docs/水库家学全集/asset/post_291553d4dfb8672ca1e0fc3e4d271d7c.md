
# 04
**吃苦专业。**

绝大部分是经专业，反正听上去挺苦的专业，一般不考虑你是哪个大学的，也不考虑二本大专，只要你有真才实学，能够在现场解决问题。

我厂里请过几个大工，一般都是中文化，我根本不关心学历。现场给你一个有点难的问题，解决了，就是50万年薪，解决不了，好走不送。你是六安师专的，还是清北的，都可以。

读经济和法律类的专业，尽可能去大城市。原因是大城市招聘多。举例，你在阜阳大学读经济法律。但是，当地可能满足不了这么多本科生的就业需求，你就会去南京，苏州，合肥，北上广，碰碰运气。但是，你在大四的时候，每个月不停的坐火车，来来去去招聘面试，你受得了吗？不仅仅是金钱，还有时间，精力，信息来源，同学间的互动交流，事先准备，衣食住行。

举个例子，你在本地面试，可以穿的干干净净，一丝不苟，但是，你把西装抱到火车上五个小时，再下来面试，就麻烦大了。

小结：
1. 艰苦专业，只看本事，不看其他。
2. 花里胡哨专业，和原地经济发展水平密切相关。举例，北上广每年要招收大量的金融基础岗，你在本地就方便多了。

以我们家为例，想来想去只有一个远房亲戚，真的分到市区小房子了，其他人没有。远郊区房子不算。我家亲戚当中，五花八门，各种岗位的都有，一般都是国企。以我最熟悉的几个亲戚看，完全没有分到房子。原因，当年分房子有各种各样的打分，老是分数不够。

# 08
**刚才有同学私信。叠墅产品，上叠好，还是下叠好？各有千秋。**

叠墅的结构是一个联排，分为上下两户。上叠是3/4/5层。5层是阁楼，利用率不高。下叠是，花园+地下室+1和2层。地下室利用率也不高。

我对这个品种有一定了解。我们家，在全国各地，各种品种都有。观点是：中老年朋友买下叠，年轻人买上叠。

叠墅产品优缺点非常明显。缺点是，地段差。优点是，漂亮，绿化好，容积率低（大部分是1.2以下），人车分流。业主逛妹很舒服，老年人睡觉非常好，每天在鸟语花香中醒来。下叠的卧室，一般在二楼，也就是上叠客厅的下方。相当于单元房的变形。你希望的零干扰是不存在的。但是，互相干扰也比较小。因为晚上上叠客厅没人了。我建议年轻人选择上叠的原因。

一是上叠便宜50-80w。一般大家认为，地下室的面积比阁楼大，所以贵一点。实际上，地下室和阁楼就是个鸡肋，一般是难度纸壳。
二是上叠安静。上叠是空中别墅，再上面没人了。
三是上叠以后置换容易一点。二手房市场，总价低还是好卖一点。
四是上叠肯定有电梯，也不累。
五是上叠装修费少。下叠花园装修，非常贵。装修费在二手房是不算钱的。

当然，下叠贵，也是有道理的。下叠的好处是花园面积大，进出方便，出门就是小区绿化带。这对于老年人很方便。对于年轻人，你用花园的机会会微乎其微，就是心理作用。

叠墅也有一些设计缺点。我的感受是楼梯太窄，大家具上不去。一般是在窗口用绳子拉进去。
