# 屌丝逆袭四步法。

逆袭无非是几个因素，你特别能干，运气又特别好，遇到好的机会。我以自己作例子，谈谈逆袭的过程，献给一般家庭的儿子。

# 一，特别能干。

你的家长，或者你自己，从小要学会特别能干的技能，或者考试，你要在同龄人中遥遥领先。例如搞个985。也不需要特别好的青北复交，浙大就可以了。

# 二，遇到机会

很多人认为，自己特别能干，就是没有机会。实际上你误解了能干的意愿。能干不是你自认为的，而是你对别人有用，别人认为你能干。你是三甲副主任，重点高中数学老师，cpa，精通PPT的大拿，都可以。

机会是怎么找上你的？很简单。你能干，别人就会关注你。我第一次被大家关注，并不是我天天加班，而是英语特别好。当年，很多猎头出国回来，都要带一些小化妆品送你。我就把化妆品上的说明书，翻译的整整齐齐。大家非常满意，迅速认识了所有的猎头。

# 三，愿意帮助别人

你有了能力，机会就多了。你要善于帮助别人。有段时间，很多家长拿个什么孩子英语考试题来问我。我迅速成为了大家喜欢的人。

这个事情是义务帮忙，人家记得你的好。多多少少会回馈一点。

# 四，倒插门

其实，倒插门之前，还有很多人为了解馈我的热心帮忙，给我介绍了好几个拆迁抹，都是中环十套八套那种。那时候中环就是农村，要坐小巴士才能到达的。拆迁抹也普遍自卑。我嫌弃庄抹抹学历不高（中专），工作不好（镇里面上班的），土里土气鬼血曲（不漂亮），配不上我，就没答应。后来遇到了那个七宝的农村妇女，也就认命了。
