# 05

在北京的小日子。

我在北京生活过。我当时是住在王府井那里的东华门某小区。我在北京生活的第一个惊奇是，吃晚饭。你们可能不知道北京土著吃晚饭是什么样的。我当场是震惊的外焦里嫩。那是二十年前了。

晚饭是几个烧饼（肉夹馍），一碟拍黄瓜，一碗小米粥。我第一次见这个，以为是餐前小点心，就意思了一下，没吃几口。我想的是，过会儿肯定有八大碗，六个炒菜。没想到，吃完这个就结束了。这就是他们的正常晚饭。我不知道，现在是不是这样了。当时，我内心是超级震撼的。没想到，他们日子就这？

那天夜里，饿的，翻来覆去。实在是震惊了。
