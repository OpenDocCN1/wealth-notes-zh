# 05

六七千万的房子谁在买？

肯定不是普通人。大部分人工作30~40年，就算年薪30万，合计也就900万，如果算上贷款利率的无效支出，大概是可以买700-1000万的房子。老婆收入当做家用养成了。以后离婚，房子归我。屌丝都是这么想的。不服，你给媳妇加个名字？

能够拿出六七千万买房子，一般是二套房了，首付也不多，四千万出头。没有哪个银行会给你半半个亿的房贷。哪些家庭拿的出这么多现金，还是比较多的。

一是互联网大佬。这点钱，小意思了。

二是上市大股东，身价几十亿，抵押一些股票也够全款了。

三是各行各业的明星，年入千万还是很多的。有个做滑板车的兄弟，前两年，行情好的时候也有年入几千万的利润。演艺圈更多了，不需要买机器，除了买车，其他都是买房。

四是置换。有些房东，近二十年，零零碎碎碎了一大叠老板被小，如果女儿嫁入豪门，或者出国了，他们愿意拼凑一套大户型的。

五是一夜暴富。我认识一个中年妇女，前两年，她父母一栋外地的大户型楼拆了，赔了不少，父母心疼第三代独苗，就包了一个两千万的大礼包，给外孙，她就买房了。

这种房子买了干嘛？偶尔住住也行。主要是拿去抵押的。京沪广深的房产，相当于一个大存折，可以抵押的。
