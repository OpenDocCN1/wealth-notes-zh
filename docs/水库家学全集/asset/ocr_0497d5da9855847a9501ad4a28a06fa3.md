# 富人有时间刷微博吗？有

真正的富人，闲的发慌，时间很多。有的人一天到晚品茶，有的人买车玩车。有的人喝妍头，有的人刷微博。我一年只需要做几个大决定，其他时间就是等结果。这种等待是很痛苦的。你看抗日剧就知道，一个团长把任务布置下去了，他就只能在指挥部里下象棋，等结果。他那个还算好，只要等几天就行了。

我们就惨了，一般要等几个月。举例，我下令做一个滑板车。从设计开始，到最后卖出钱来。一般是好几个月。这几个月，你非常难受，但也无能为力。你一个人也干不了什么事情，总不能去和员工抢活干吧？

你看某爸爸，一天到晚在网上吹牛逼，教大家怎么做人为，为什么？闲的！因为真正的大生意，老板只要点个头就行了，一切细节都有人做，剩下就是老板等结果和承担结果。一刃刃一刃富，不是所有人都有能力承担后果的。有的是等几个月，有的是等几年，度日如年啊。

# 我现在基本不打电话了。

网络基本摧毁了实体商业中的利润，当然，还有些国企过得不错。各地商铺和办公楼卖不出去了，网销摧毁了中小商业店。微信摧毁了手机和短信。快递抢占了城市间的包裹业务。网络补习班收割了家教。餐饮一条街变成了骑手一条街。

再这样下去，小县城基本没什么后劲了。现在的小县城大概就剩下水电气，吃喝玩乐，装修维修，便民服务了。我比较担心的是就业。

轻工业被珠三角和长三角包圆了。重工业都是大企业，数量不多，很多在大城市的郊区，小县城一般没什么大工业集群，以前还有几个化肥厂，啤酒厂，饲料厂，现在没了。服务业是小县城就业的主力军。而重中之重的商业一条街，在县城很难混下去了。

如果经济高度集中在少数大城市，那么农二代都郁闷了。他们要有现金收入，必须进城，那就面临一个巨大的困难，房子。没有房子就可能没有老婆，我家保姆告诉我，在哪里相亲，就问那里有没有房子，老家房子一概不认。如果在京沪广深贴瓷砖，县城房子就不算房子。
