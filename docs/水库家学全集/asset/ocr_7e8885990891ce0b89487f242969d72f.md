# 大城市房价贵的离谱了，这个循环到底是怎么转起来的？

财上海微博 2021-01-22

# 01

（屌丝科普）大城市房价贵的离谱了，这个循环到底是怎么转起来的？

基本上，大家都承认，靠打工在大城市买房，是非常困难的。除非你家是在大筒厂。大城市是指郑州以上的省会城市。

1，超过五百万的房子，基本都是置换的。就是卖掉老房子+贷款+存款。凑一凑，基本够了。也有白手起家的，例如互联网大咖，买房像买白菜，人家股票一上市，就是大几佰上千万。我周围有个熟人，公司上市了，他分到了425w。

2，大城市房子热，最基础的推动实际上是外地大学生，把本地人的老破小收走了。一般情况，老破小在200-300个左右，资金来源大致是这样的，首付70-100，其余贷款。

首付的比例基本是三七制，男方女方各出1/3，大概35-40万，小两口自筹1/3，男女分摊，一人15-20万，这对于工作5-8年的人，基本是可能的。你没有能力，是你收入不够，不要叽叽歪歪了。父母筹钱有两个渠道，一是存款，现在各大单位，好单位，工资收入是不错的，一辈子攒下34-40是可能的。二是小地方的房子卖掉。以前，小地方房子不紧张，很多家庭有多套房，孩子去外地了，留着也没用了，索性卖给附近农民。

有了第一轮的老破小卖出去，第二轮的老破大就动起来了，房东有首付了。要想卡住房子，必须打断老破小。但是，老破小的接盘侠是大学生，大多数结婚。上一次五年限购，就是打的这个环节。

# 为什么大城市房子贵？

绝大多好工作在在大城市。一个年轻人读了十几年都想去大城市转转，碰碰运气，很快，他们就面临结婚生子要买房了。这事情无法避免。

房子不是消费，而是储蓄。你花五百万，住了几年，不但不损失，以前都是赚了。与此同时，房租是实打实消费，花了就没了。所以没人嫌弃贵，只不过很多人够不到，心里不高兴。老家便宜，你不喜欢，那有什么办法呢？
