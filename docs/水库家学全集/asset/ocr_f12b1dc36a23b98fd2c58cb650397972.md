# 09

买车关键是车价，而是维修保养的价格。

前两年，流行买世界著名汽车，看上去价格也可以，面子大于天，一咬牙一跺脚忍了。黑木耳收割机，一想就开心。

后来傻眼了，知名品牌原来是卖打印机的套路。机子低价，把你忽悠进来，后续必须的维修保养费的一塌糊涂。一个后视镜，汽车耳朵（电动的），转弯的时候被拉坏了，更换一个汽车耳朵，要八千多，金杯的汽车耳朵一百多就够了。大品牌的小保养二千多。比中级车费五倍以上。而且他们]通过芯片，自己换不了，必须去4s。价格人家说了算。

建议：想买名牌车的人，你最好先找个买过这品牌的人问问，维修保养费用多少。

不一定。有的零件是通过芯片锁死品牌的，有的可以，例如点烟器。所以，不要考虑这个事情。
