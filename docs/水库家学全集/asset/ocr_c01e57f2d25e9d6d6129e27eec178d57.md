# 03

白富美很有钱吗？不是的。

绝大部分白富美，可能有二十万零花钱，再多就没了。她们看上去很有钱，实际上也不是多有钱。她们的富，主要是资产，例如汽车，大楼，商场，股权，七七八八加起来几个亿，但这不是钱，不能花。所以，绝大部分大部分白富美不见得有多少钱。

如何讨好白富美？砸钱。有一年，我家老房子拆迁，我分了八十万，把菜炖乐的，那个小存折看了又看，小心翼翼藏起来，稀罕的不行了。我豪宅的上交了，换了一个三居室加名字。
