# 逆袭是多长时间？

我和很多土老板聊过这个问题，从一无所有，睡集合宿舍，到家财万贯，小美白跪舔你，需要多久？我发现绝大多数土老板是一样的，找到发财路子后，也就2-3年。

很多人不知道什么是一夜暴富。我听很多土老板说过，就是一天赚十几万，连续大半年。有个土老板是做滑板车的，曾经找到一个爆款，生意好到爆，请了六个人给他发货，一天几卡车的发，一年下来，就赚了几千万。第二年他又找到了一个小爆款，赚了几百万，然后不做了，买了喜婚房，开开心心结婚了。他老婆是他的员工，非常漂亮。

但是，发财之前，他是怎么也不赚钱，经常是兜里比脸还干净。那怎么才能找到赚钱的路子？这个事情是，孩子没娘，说来话长。我周围都是土老板，没有互联网大佬，我就说说我的观察，

一是长期从事一个生意。一开始是打小工，干杂活，几年时间把套路摸透了。这个阶段非常重要。很多人是二本毕业，不喜欢下车间，趴柜台，最希望有个师傅，给你讲一讲，就算学会了。这是不行的。

你要吃透一个行业，绝对不是有个师傅给你讲一讲就行了。举个例子，历朝历代，给阿哥们讲课的老师多了去了，成才率很低。为什么？最重要最关键的道理，一定是自己悟出来的。你把高等数学看三遍，你也成不了薛定谟。

二是钻研规律。各行各业，包括烤鸭子，都有很多小秘方，你要善于总结各种各样的小秘诀。这些小秘方就是你和别人拉开距离的利器。

三是肯吃亏。以前有句话，吃亏就是占便宜。以前一直不理解。现在，人到中年，我才慢慢体会到一点点。你吃亏了，就有人占便宜。绝大多数人还是有点回馈之心的，觉得你人不错，可能会无意中给你一个意想不到的机会。

四是早点买婚房。读三遍！！！
