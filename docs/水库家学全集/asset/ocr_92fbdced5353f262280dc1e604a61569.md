# 亲戚找你，总没好事。

财上海微博 2020-02-16

01

上网这么多年，我有个直觉，绝大多数人和我的穷亲戚一样，永远发不了财。因为他们只相信及时回报，不相信提前打桩。要想赚大钱，不能把眼睛盯在立即有回报。我现在给你干一个小时家务，你给我35元的黑车司机思维。

赚大钱实际上就是赚时间发酵的钱。

# 热门评论:

+   - 孤寂恋恋：放长线，钓大鱼。考验的耐力和魄力。
- 码字熊猫：干一天拿一天钱是临时工，干一个月拿一个月是工薪族，拿年薪的是职业经理，不要工资还拼命干活是老板。
- 追梦人：都饿久了，巴不得干完就吃饭啊。
- _后山：没有赚到过大钱，也不相信自己能赚大钱，但是不相信自己去穷
- 突破格局：一个人的格局决定的。

02

有个屌丝错过了暴富的机会。

我买了一个房子，装修，小老板是隔壁家一个小学老师找的装修队，我相信那个小学老师的眼光，直接对接了。最后小老板多要了我八千元，就是乱算账，他给我拉根网线，一楼到二楼，算了75米，报价2800元。他以为我家在这里，跑不掉的，我拗不过他。装修总体还是可以，很多朋友希望我介绍这个装修队。我那天正在生气，就没介绍。后来我统计了一下，大概有18套豪宅的单子，一家80万，也要1500万的营业额了，就给一条网线给毁了。如果他接下来，就做大了。他错过了人生的最佳机会，可惜。

结论：做生意的目的是发大财，而不是赚小钱。你之前折腾小单子只是为了给自己一个腾飞起点。不要把起点做成了终点。
