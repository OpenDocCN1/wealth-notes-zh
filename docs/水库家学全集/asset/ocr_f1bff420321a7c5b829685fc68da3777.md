# 05

# 大城市遍地是金子?

很多人都说，我下了火车南站，没看到金子，只看到一大堆人啊！是的，金子不是在马路上堆着，等你来，而是躲在各种小角落里，你轻易发现不了。

谁能想到，一个保洁大姐也能够年入几十万。大城市这种事情特别多，内环线是资金信息人流物流超密集的地方，只要用心钻进去，你就会发现金子。很多看大门的，都赚到钱了。

举个例子，我曾经去一个地方办事。现在办事的大单位都没有停车位，停车场门口写着一个牌子"内部停车场，社会车辆勿入"。气的我，干瞪眼也没办法。

这时候，隔壁小区的看门大爷找到商机了。专门搞做生意。凡是来停车的，都要问，你干什么的？一般人就说去隔壁办事。大爷高兴了，"半天15元，没票"。这个价格低，你来回打车不划算。特别是天气不好，一位难求。有时候还会占用业主的停车位，买的没有卖的精。他知道你用不了半小时，就几个临时车位，一天能够转出几百元。我也没办法，非要去办这个，只能掏钱。也有不服的，停在马路边，很快栽了。

我在好多地方发现了各种小商机，甚至在某地方门口摆个二手复印机都可以衣食无忧。不过，我也挺喜欢这样的，至少花钱还解决了事情。
