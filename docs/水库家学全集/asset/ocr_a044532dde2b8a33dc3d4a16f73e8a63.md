# 现在指导娃是很难的。

财上上海微博 2021-06-28

# 01

只取消辅导班，不取消中考和高考的淘汰机制，你家娃今后怎么办？

我和菜嫂已经准备自己上了。我负责中学，菜嫂负责小学。反正是两个闲人，就当是锻炼身体了。我已经开始研究将军饮马和蝴蝶理论了。你们也加油。

# 02

家长会上，一个奶爸哭的稀里哗啦。

我家娃的家长会，菜嫂回来和我谈了一个事情，有个男家长，哭的恸恸横横。

他家娃成绩很差，一年级的黄冈卷子，只能考40分。家长是很有面子的大单位985。他们是小地方来的，一直信奉文凭为王。现在，孩子搞成这个样子，他们一切的希望都破灭了。今后的生活，他们就是完成任务了，只不过是给娃吃饱穿暖，初三后，就让他去送快递了，没有一丝丝改变的希望了。他们两口子都是靠自己拼出来的，单位里的大忙人，还有房贷车贷的巨大压力，也不可能怎么样了。男的一边哭，一边哭，眼泪鼻涕一大把。菜嫂看的心惊肉跳，害怕极了。

大家帮忙一起分析一下原因，因为涉及教育理念，我也不多说了，反正是家长像个被人骗了的SB一样，孩子就是一张白纸就交给学校了。他们以为，学校会把娃搞好的。

事实上，现在的学校，老师也没办法，一眼望去四五十个小朋友，你说老师怎么办？只要不出伤害事故，就是千恩万谢了，学校是一个赛场，你家娃只不过是一个参赛选手，不要想多了。

我们这一代还有成逆滚蛋，那是因为以前的家长都不管孩子，现在不容易滚蛋了。你去看看班级前十名的娃，一个一个都成了精了，他们背后的家长就是一大群农村考出来的985。你来试试看？我们这一代人，虽然研究成果上没什么好说的，但是，考试经验是一箩筐一箩筐的。有的家长自己也没考明白，现在指导娃是很难的。
