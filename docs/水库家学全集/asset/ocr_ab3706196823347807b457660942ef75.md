# 如何分辨有钱人？

现在很多人喜欢装逼，但毕竟不是有钱人，所以装逼的时候，他们要考虑成本和效率最大化。他们喜欢干一些你一眼就看懂的项目，例如买一个百万的车，买个五千的围巾，买一个万的手机。故意把玛莎拉蒂的车钥匙拍桌上，一说话就是自己认识大人物。你记住一点，你第一眼就感觉他很有钱的，往往是没钱的。有钱人早已经过了炫耀的过程。

第一，真正的有钱是，做生意，不欠钱。答应你的事情，肯定办到，说好几号给你打钱就是几号。这是富人最有面子的标志。

二是隐藏方面花钱多。我去外地，一般是住当地最贵的酒店。有几个原因：一是舒服。二是吃的可口卫生，最贵的宾馆，一般餐饮都很好。三是安全。四是领略一下当地文化。出去办事打个小破车，也没什么。

三是谦虚。不愿意吹牛。绝对不会和你说他认识谁谁谁。富人已经到了很高的地位，不需要靠吹嘘了。

四是不一定讲究豪车，生怕被坏人盯上。

五是住得好。一般都是面积很大的房子。因为他们需要比较多的私人空间。打电话，放资料。
