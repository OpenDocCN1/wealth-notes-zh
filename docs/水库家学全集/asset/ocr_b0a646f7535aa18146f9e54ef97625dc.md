# 为什么我爸不是老板？

很多屌丝有个误解，他们认为二三十年前，做生意很容易。我家几代人做生意，我从小到大都是在商人圈里泡大的。我可以很肯定的说，以前做生意也很难，甚至比现在更难。举个例子，

90年代，我有个亲戚想做客运小巴。他到处打听怎么做？去哪里办？根本没人告诉他，他忙了一年多，不了了之。现在好多了，你想做什么事情，至少知道怎么起步。如果当年做起来，熬到现在估计也是几个亿的身价了。

我印象中，网银是2005年才见到的。你知道以前做生意是怎么付款的吗？邮局银行汇款，或者带着一包现金到一个人迹罕至的小地方，一手钱，一手货。那时候，很多厂子都在农村，晚上没有路灯，黑漆漆的，很吓人，我都不敢去。

以前，各种基础设施都不存在，每个细节都很难，做生意非常痛苦。有一次，我去银行汇款，大厅里都是人，我等了三个小时才轮到我办理业务。

前两天，我家人说起某个上市公司老板，当年，他们两个是同时起步的，面对面做生意。后来，他自己实在是受不了长途奔波的辛苦，就没有坚持下去，收摊了。对方因为家里穷，没办法，咬牙坚持下去了，现在一天到嘴吃牛皮。二十年前，发货收货是很困难的，经常是半夜三更到货，老板就半夜守在仓库里驱蚊子，还要自己当做搬运工。各种心酸实在是太多了。绝对不是你想象中的那么简单。

结论：发财是很累的，吃得苦中苦，方为人上人。二本子千万不要好吃懒做，否则很难出头。
