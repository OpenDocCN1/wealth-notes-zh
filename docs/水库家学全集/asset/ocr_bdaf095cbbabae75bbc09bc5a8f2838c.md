# 08

刚才有同学私信。叠墅产品，上叠好，还是下叠好？各有千秋。

叠墅的结构是一个联排，分为上下两户。上叠是3/4/5层。5层是阁楼，利用率不高。下叠是，花园+地下室+1和2层。地下室利用率也不高。

我对这个品种有一定了解。我们家，在全国各地，各种品种都有。观点是：中老年朋友买下叠，年轻人买上叠。

叠墅产品优缺点非常明显。缺点是，地段差。优点是，漂亮，绿化好，容积率低（大部分是1.2以下），人车分流。业主逛妹很舒服，老年人睡觉非常好，每天在鸟语花香中醒来。下叠的卧室，一般在二楼，也就是上叠客厅的下方。相当于单元房的变形。你希望的零干扰是不存在的。但是，互相干扰也比较小。因为晚上上叠客厅没人了。我建议年轻人选择上叠的原因。

一是上叠便宜50-80w。一般大家认为，地下室的面积比阁楼大，所以贵一点。实际上，地下室和阁楼就是个鸡肋，一般是难度纸壳。

二是上叠安静。上叠是空中别墅，再上面没人了。

三是上叠以后置换容易一点。二手房市场，总价低还是好卖一点。

四是上叠肯定有电梯，也不累。

五是上叠装修费少。下叠花园装修，非常贵。装修费在二手房是不算钱的。
