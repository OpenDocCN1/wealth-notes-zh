# 男方婚前买房，女方不加名字的利弊。

财上海微博 2020-08-31

# 01

你们见过年入百万的打工族吗？我见过两个真的。

一是大房企中层。他老婆也是同一个公司的，为了这一百万，老婆只能辞职了。他们公司规定，夫妻不能存在上下级的可能性。他老婆一天到晚招蜂引蝶的，估计那个了。

二是张江镇某码农。交大毕业，39岁，秃顶了。老婆不上班，丈人退休，丈母娘也不上班，三个人带娃，婆媳关系非常恶劣。公婆和女方父母吵了好几次。公婆认为，儿子年入百万，应该给自己享受一把，也不多余，海南买个海边小户型，那时候是89万，写儿子名字。结果儿媳不同意，在内环线买了个小套，丈母娘住上了。公婆极度愤怒，三天两头去干架。

还有一个是在外国打工的。外国五百强的经理人，常驻东南亚，加上出差费，大概折算是这个数。我看他也像个屌丝，熟人聚会，他选了个商场的顶楼小吃区，已经拉黑了。
