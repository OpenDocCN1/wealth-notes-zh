# 04

说个身边的小故事。

某小两口，多年前，各自都达到了年入等于老家50平米的水平。于是双方家长开始了疯狂的索取。

起初是女方，因为女方家里特别穷，老爸老妈四十多岁就蹲家里待业了，靠干保姆，把孩子送进了top1。女孩心疼父母，就攒了几年工资，给父母在老家买了一套房，漂亮小区。这下子，老爸老妈瞬间达到人生巅峰，周围一群差不多老头老太羡慕嫉妒恨。把这两口子撵上了天。

房子有了，那配套也要跟上。于是，女孩又给家里买了一个国产车。老爸不千保安了，就去学车。拿到驾照，就带着一群老头老太，在包郊区自驾游。他们也穷惯了，自驾游消费不大。

自驾游后，女方虚荣心得到了极大满足，又给老头老太报名了欧洲游。买房买车，吃喝玩乐，前前后后花了大概90万。于是她父母成为了待业群里最励志的故事。

女方把钱花完了，自己的生活就靠男方了。好在男方也爱这个女的，不计较。没想到，公婆不高兴了。于是，也要求男方回老家买房，女方也不好意思拒绝。说是买个90平米。公婆不同意，非要130平米的。最后，小夫妻没在大城市买房，各自在老家挣了大面子，现在大城市的出租房里混的一笔吊糟。

这事情后，双方老人都觉得对方家庭太会算计，他们要多了，自己吃亏啦。于是新一轮疯狂要钱又开始了，各种各样的借口，层出不穷。

最后，小两口实在是崩溃了，毕竟他们是拿工资的。小两口在被窝里开了个会，一致决定和老家父母拗断。他们浪费了一套京沪三居室，换来了父子反目，母女翻脸。真的有点心酸。

小结，发财后，要低调。
