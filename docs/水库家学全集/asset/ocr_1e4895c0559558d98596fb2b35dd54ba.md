# 石家庄是怎么来的？

原来河北的省会是保定。当年阎老西修正太铁路，呵呵，很古老的名词了。因为铁路有声音，所以大家都不喜欢铁路经过自家门口，于是一合计，就把铁路站点，赶到了一个只有三户人家的小村庄，这三户人家也没实力去搞事情，只能默认了。因为这三户人家都姓石，当时建筑队的小队长就随便起了个名字，"石家庄"。

这个故事说明一个问题，大城市的发展，基本是地理因素决定的。

上海是长江的出海口。

广州是珠江的出海口。

武汉重庆原来也是大码头，后来因为长江大桥把航运堵了，基本就不行了。南宁是邕江的大码头。天津是渤海湾。南方地区以前都是内河航运，只要是大码头就是省会，大码头和出海口相连，就是一线城市。福建浙江有点亏，因为海港上来后，都是山，运输困难。

苏州发展的比较好，也是和杨林塘的内河航运有关。浙江以前来上海，就是在晚上漂一夜，天亮就到十六铺了。
