# 二，日常生活

这就简单了，你去看看《飘》，南北打架之前的Jane奥斯丁的日子就差不错了。简单说，你只要嘟嘟嘴，就有人给你办妥了。例如，你说想吃什么，中午肯定有。买房买车不值一提。土老板比得是谁家花园有几亩？我见过一个土豪，他买了一个双拼打通，在一楼修了个游泳池，还自建了一个物业组，有二十几个服务人员，做饭的扫地的，样样都有，就是他老婆贼难看。我看他心情不好。

# 四，烦心事

这个就多了。一天到晚有人来找你说个事。有几种，

一是遥想当年，某件事情没有我，哪有你今天？借钱，五十万。

二是小美要加钱。“帅锅锅老板，工资加五千行不行？我给你跳个舞，乘风破浪的小姐姐。”

三是小舅子又离婚了。“姐夫，借点钱？”

四是大专辞职。这个最要命。一般企业往往是五六个大专支持，少一个就麻烦。

五是市场变化。这个很厉害，往往一夜之间，订单就跑了。你看我，我看你，互相翻白眼。

小结，不用担心找不到老婆，等你挣钱了，就有了。介绍相亲的，你忙不过来。

# 网络小贷赚了谁的钱？

表面看是大学生在借钱消费，背后是家长在还钱。一个家庭供养大学生是非常努力的，宁可自己酱油泡饭，也要把钱给你寄过去。有的孩子贷款后还不上了，或可能编造一些谎言，买书买资料，找家里多要钱，家长也无法分辨，只能给钱。换句话说，就是每个月家长给孩子钱是非常准时的，信誉好到爆。于是有公司就开始想绝办法了，你不是信誉好吗？那我也沾点光。设计一些高利息的小贷给大学生。反正家长当冤大头买单。
