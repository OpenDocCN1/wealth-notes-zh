# 04

高科技产业区和高首付地区是完全重合的，为什么？

如果首付低，有利于高科技，那么鹤岗和我们老家村里应该是全球硅谷了。与此同时，我们最出名的四个高科技城市，京沪深杭也是价格最高的地方。

高科技离不开人才，但是，又不知道将来需要什么样人才？与此同时，各行各业的人才，要想找个好工作，最好是去大城市，因为大城市岗位多。这就形成了一个聚集效应，供需双方在大码头汇融了。反过来，又刺激了当地的居住需求，变成了正反馈激荡。

与此同时，高收入人群支付能力高，其他服务行业也会拿出最好的产品，互相激励，把城市搞得越来越好。吸引各行各业的成功人士和服务人员。二本子可以负责给码农作活条。

结论是明显的，小地方没有完整的人才供应，生活服务也很不上，对高科技发展没有明显的促进作用。你要在小县城
