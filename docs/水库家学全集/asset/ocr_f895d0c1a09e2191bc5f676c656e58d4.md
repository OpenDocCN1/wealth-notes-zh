# 01

现在不缺房子，缺的是大城市房子，一线和省会。

小地方的房子都长辈了，也没人住。二狗子只看房子数量，不看房子分布，鹤岗，个旧，几万元一套房子，给你你也不感兴趣，因为你在那里找不到好工作。

我的意思是，瞄准有好工作的城市，努力上车。京沪广深你是去不了，想办法搞个省城。

热门评论:

深南视界：北上广深四大一线之后，杭州南京成都武汉苏州重庆。青岛厦门三亚三个滨海城市。然后是珠三角大湾区城市。例如东莞珠海中山。长三角宁波无锡南通。再就是省会城市，郑州长沙合肥西安济南。

东城区穷人：省城仙女妳妳也眼瞅了，好不容易攒了点钱想去成都买房，前几天咨询了成都的中介，说需要连续上 24 个月的社保

便有天使：省会搞不起就苏锡常

一朵豆神：不要轻易到一线城市，现在一线城市离开去省会的人比比皆是，除非你有家庭儿或者自己挣钱能力超群，不然还是去省城去提高快乐指数拥有幸福人生。当然，能在一线城市活下来的，都是好汉。

【兆驰股份：其实就是个房子的事儿，一线城市市区，环境好一些的三房，至少 1200 万，这个价格超过了绝大部分工薪阶层的上限。所以，一线城市，要做好一辈子住破房子的准备。】

# 为什么大城市能够挣钱？

因为大城市人口多，需求密度大。做生意，最需要的是连续不断的生意，或者一个时间里，更多生意。

为什么在农村老家，送快递不赚钱？因为摩托年跑了白天才送了一个，只有四块钱。气的二本子在河里直哭。大城市就不一样了。一个小区，每天进出出出的快递就有几百个，一个上午走三个小区，一天六个小区，赚的满嘴流油，晚上撸串。

再比如，开个 大碗面 ，你在村口开，一天三个顾客。你在大城市，流动人口多，一个中午，三百碗就卖掉了，毛利润三四千，面条又不值钱。

再比如，有些挣大钱的小众生意，只有大城市才能实现。例如卖字画，一副几万元，你在村口卖，三代人都卖不掉一个，只有去潘家园，城隍庙，才有人来看。还有些翻译，设计，软件等高级工作，小县城根本不需要。偶尔需要一次，直接去省城请人。

现在，各个地方都在抢人口，就是这个道理。人在哪里，生意就在哪里。老家县城都是老老少少的，除了电气维修，其他生意都不好。
