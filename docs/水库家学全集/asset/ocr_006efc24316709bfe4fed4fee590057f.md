# 中学掐尖是什么原理？

一个中学生不牛？校长有没有人求？完全看学校教育质量（985比例）。大城市一个重点中学的校长，暑假都是不接电话的。因为来求办事的人实在是太多了，不敢开机。而且，一个优质中学，往往是一个地区的骄傲，只要成绩不错，校长可以做到退休，没人会冒着学校下滑的风险搞换你。

如何保持一个学校分数遥遥领先？招录优秀的学生。但是，优秀的中学生哪来的？一般是家长教育的结果。老师家里的破事一大堆，哪有什么心情个别辅导。但家长不一样了，哪怕是单位累个半死，也要管孩子学习。

掐尖的最好方法是，表格化筛选，孩子成绩好，一个家长不上班，天天管孩子，而且家长要本科以上，可以辅导一下。这就是学校要考家长的原因。大部分学校不喜欢土豪家长。因为老土豪太忙了，你的钱又不会给我学校，孩子娇气，我何必在意你呢？

学校最喜欢的家长是，富裕，父母双985，工作不忙有时间管孩子，最好是公家单位或者全职妈妈，没离婚，家里吵架少，如果在重要部门有资源更佳。你有钱？呵呵，你愿意捐多少？
