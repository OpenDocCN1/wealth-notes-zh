# 现在不缺房子，缺的是大城市房子，一线和省会。

现在不缺房子，缺的是大城市房子，一线和省会。

## 02

为什么大城市能够挣钱？

因为大城市人口多，需求密度大。做生意，最需要的是连续不断的生意，或者一个时间里，更多生意。

为什么在农村老家，送快递不赚钱？因为摩托年跑了白天才送了一个，只有四块钱。气的二本子在河里直哭。大城市就不一样了。一个小区，每天进出出出的快递就有几百个，一个上午走三个小区，一天六个小区，赚的满嘴流油，晚上撸串。

再比如，开个 大碗面 ，你在村口开，一天三个顾客。你在大城市，流动人口多，一个中午，三百碗就卖掉了，毛利润三四千，面条又不值钱。

再比如，有些挣大钱的小众生意，只有大城市才能实现。例如卖字画，一副几万元，你在村口卖，三代人都卖不掉一个，只有去潘家园，城隍庙，才有人来看。还有些翻译，设计，软件等高级工作，小县城根本不需要。偶尔需要一次，直接去省城请人。

现在，各个地方都在抢人口，就是这个道理。人在哪里，生意就在哪里。老家县城都是老老少少的，除了电气维修，其他生意都不好。
