# 普女笑到最后。

我这几年时不时参加私人银行的各种小活动。简单说说，这玩意基本就是，拉你买银行产品的，意思不大。其中有意思的是，什么人去这地方？

我每次参加，根本不关心主嘉宾什么样，反正都是满嘴跑火车。我最关心的是，哪些人参加活动。由于大家又不熟悉，没办法说的太深入，基本都是简单聊几句。但是，我是个有坏人，通过简单对话和找银行经理说说话，把我感兴趣的几个人的大概情况了解了。

这种活动，人不多，两到三桌为主。一般是先找个大嘴巴嘉宾吹吹牛，天下格局我都懂，然后就是大家闲聊聊几句，最后吃饭喝红酒，类似于好年俱乐部。我一直怀疑银行经理买的红酒不正宗，是关系户的红酒，不好喝，每次她还要巴巴的带过来。参加这种无聊活动的，大多数是中老年妇女。我就研究一下这些人怎回事。

一是整体不漂亮。我发现富贵婆一般都不漂亮，基本都是普女样子。有几个还是五大三粗的感觉，就找不到一个漂亮的。有一次，意外看到一个中年美女，后来发现是宾馆餐饮部经理，心情沮丧。这段话的意思是，美女不一定会笑到最后。普女有大希望。

二是普女如何逆袭。我发现绝大多数中年妇女的逆袭套路是一模一样的。年轻时嫁了个屌丝，然后屌丝运气好，发达了。她也变富婆了。还有一个看上去不像富婆的女人也出现了好几次。我就问经理她是怎么回事？不像老板啊？经理说，她可能是买了一套房，存款一千万，半年没动，就邀请来了。那那，她什么银行产品都不买，气色特了，白请客了。

三是普女打扮。中年女人最喜欢作妖，居然喜欢买各种各样的方巾，不论什么品种的，我都见过了。有一次，我去七浦路也买了一打，放在车里，随时准备送人，结果被装菜收没了。陶闷啊！

四是话题。普女最关心的不是赚钱，而是儿子读书。实际上我去讲，肯定比那些大嘴巴嘉宾说的扎劲。

结论，普女不要气馁，世界上笑到最后的都是甘比。
