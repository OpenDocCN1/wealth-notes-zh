# （嘲笑二本子）什么是人才？

肯定不是吹牛逼的那种。我们经常看到所谓的聪明人，他什么都懂，天下风云，海鸿局势，侃侃而谈，就是没钱。一起聚餐，吃完了，就装傻的那种。他连懂王家里的小花狗叫什么名字，他都知道，就是结婚没房子，不想给彩礼。这不是人才，这是v信群爱好者。

真正的人才，能够办成事情。

+   1. 给你一个潜在客户，你去拿下他。老子是做拖鞋，二本后校门的那条街有3个五星级，8个小宾馆，你能不能把他们的一次性拖鞋业务全部拿下？

+   2. 对面马路要安装一溜的杆子，你能不能去把单子拉过来？

+   3. 你开了个外卖店，一年后成为这条街生意最好的亮仔。

在大家都不知道怎么办的时候，你把事情做成，这才是人才。千万不要把人才误认为，我有几个高明的见解，那是一条SB。人才是做出来的，不是吹出来的。一天到晚抱怨不公平的，不是人才，是二货。

真正的人才是可以改变困境的。你看看人家菜菜，这么困难的情况下，居然改变了困境。你别管人家是不是倒插门，这和你没关系。那是人家两口子的事。你就想想你什么时候搬去大平层。
