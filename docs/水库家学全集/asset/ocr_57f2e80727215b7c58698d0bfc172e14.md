# 老头老太也有自尊心

每家每户都有几个老头老太，明明没有多少鸟本事，一天到晚装的人五人六的，好像他多厉害似的，特别是看你长大的一些老头老太，自以为聪明的不得了。

绝大多数老年人，前数十年是在单位里度过的，没啥见识，最多就是有一些小算计的本事。后二十年，也没有做出过什么成绩，就是一张嘴，什么都懂，非要投资。你还不能劝。“老子什么没见过？老子吃过的盐比你吃过的饭还多。”就这么个货色，实在是没办法。

前不久，听说一个老汉的事情。这个老汉，以前很有面子。退休后，拉了一群老兄弟，经常吃饭，喝咖啡，聚个餐。结果，在饭店里，被一个理财混混盯上了，最后他们那群老汉，被一锅端。现在全部喝肠粉饭了。

老年人有个迷之自信。他们用以前在单位里形成的思维，看待野路子长大的人，非常容易出问题。但是，他们完全不接受别人的劝解，一说就冒火之类的。

遇到这种人怎么办？就一条，躲着走。让他自生自灭了。如果是你至亲，那只能是硬受了。实在劝不了，也没办法。
