# 京沪有多少家庭能掏出100万？

一百万是什么概念？就是一个京沪最破的老破小的首付，一般是七十年代的老房子。那么掏出一百万有多难？

如果父母有房贷，再有余款年存十万是很难的，这大概需要合计收入35万，基本上是扣扣搜搜过日子。

如果这个未婚男大概是30岁了，一家三口存一百万，十年，相对容易一点。

结论，年轻男买不起房子是很正常的情况，女主要把目光放长远一些。如果是985，就不要房子了吧。

# 京沪广深一个家庭有二套房是什么档次？

2016年以前，这种情况比较多。之后就很少了。原因是现在二套房首付七成，这基本堵死了买二套房的可能性。

当然，这个政策是精确对着外地人的，本地人无所谓，大不了把房子转给双方父母，也有合法离婚后，各买一套的。

现实中，有一类人是最近购买第二套房子的，这就是土豪了。第二套房一般是改善型，面积大，漂亮小区，总价一千万左右是正常情况。二套房首付七成，能够一口气拿出500-700万首付的家庭，基本就是上市公司大股东的规模了。

结论，小姐姐们遇到二套房的京沪年轻男，不要计较太多了，二本子也行，牢牢抓紧。
