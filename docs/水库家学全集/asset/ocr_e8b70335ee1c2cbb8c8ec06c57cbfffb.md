# 35岁是分水岭

35岁之前，大多数人的收入是逐年增加的。所以，很多屌丝产生幻觉，以为永远会增加，实际上不可能。35岁以前，大多数人身体好，加班加点多，学习快，所以单位愿意给机会。

过了35岁，家庭包袱越来越大，女人一生孩子，就不太想干活了。男人腰酸背痛开始了。大多数单位的老板是年轻人，不太喜欢老油条。事业编制也不要35岁以上的人。

这时候，你尽可能不要主动辞职，除非是有绝活。一般人都从事可替代性很强的普通工作，人家宁愿找个年轻人，也不愿意找一个一身坏习惯的老板凳。

怎么办呢？超过35岁，你的体力下降了，但是经验上去了，用脑子赚钱啊
