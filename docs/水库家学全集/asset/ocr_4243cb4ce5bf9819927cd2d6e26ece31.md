# 05

(商业的秘密) 做工程为什么还有亏钱的？

大家装修过就知道，做工程是超级暴利。一件事情可以拆分成五个事情，单独计价，不把你榨干绝不罢手。有一次我家装修拉一根网线，也就是12米，装修公司 在结算单中给我算了1280元。包括吊顶开洞费，人工费，材料费，测量费，检测费，修补费，前后耗时8分钟，就要1280元。我和他吵了半天，也讲不清楚道理。

但是，每年都有很多做工程的老板倒闭破产睡桥洞。为什么？要不回钱。做工程一般都是后付钱，你先做。小老板以自己婚房找银行贷款，垫资做完了，但是甲方没钱买单，于是甲方找你挑毛病，一拖三五年，你就完了。
