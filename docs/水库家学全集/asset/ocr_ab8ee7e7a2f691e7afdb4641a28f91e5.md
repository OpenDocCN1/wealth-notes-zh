# 海南游客大减，为什么？

刚才微博有个吐槽。这两年，海南游客大减。为什么啊？

我说的直观的感受，楼市。我每年都要去海南过冬，也会遇到很多熟人。我问他为什么来啊？他们说，来看房子。

有很多人买了海南房子，就会疯了一样把亲戚朋友叫过去过年。来的是有钱的亲戚，就怂恿他们也买在附近，以后可以蹭他们，海南的海景房，附近交通吃住都很麻烦，如果有个大家族，大家互助会方便很多。来的是蹭吃蹭喝的穷亲戚（搭着富人），地主就自我炫耀一把。不管有没有钱，既然来了，肯定要去各大景点看看。游客肯定多了。

我就是这样被挤过去的。现在限购了，有钱亲戚就不去了，反正也不能买，剩下的穷亲戚，我也懒得叫你，穷亲戚一看富亲戚不去了，自己也不去了。。游客肯定就少了。

海南旅游开发几十年了，（大部分人过去了），再去肯定是有个具体原因的。以前是买房，现在你要找个借口啊。去海南的游客，大部分没钱。我举例看到，有很多北方车牌，黑A车牌，几千公里赶过来，还不如在机场租个国产小车，100元/天，也不贵，一个月三五千。我经常租的。

楼市涨价的弊端很多。但是，楼市有个正聚力量，经济启动的作用，买了房就要装修，家具，家电，一大套床上用品，这都是大额生意啊。海南本地除了农产品，香蕉西瓜芒果，剩下有多少大工业？
