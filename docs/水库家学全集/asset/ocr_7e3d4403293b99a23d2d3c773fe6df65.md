# **“新就业形态”，很重要。**

很多副教授看不懂了，这是什么意思？理论上说叫做古罗马古希腊的契约自由。通俗讲就简单了，你情我愿，合理合法。

王老汉在村里放羊，穷的叮当响，也没文化。这种人非常多，农村留守妇女和老头老太，几个亿的基数，基本都没正式工作。附近村子开了一个米粉厂，半夜前可能卡车到货，需要一个人做小夜班，在门卫睡一觉，车来了，你去检查一下车牌号，开一下门就行了。王老汉完全可以胜任这个工作。

实际上，能不能这样做？不行。因为劳动法卡住了，必须签合同，五险一金。这样做的后果是，简单事情复杂化了，米粉厂不愿意招聘了，担心以后解雇又是一大堆难题。

新就业形态的意思是，实事求是，合理合法，企业和劳动者之间形成丰富多样的招聘合同，不一定非要五险一金，非要1234。增加收入的出发点是劳动，而不是签合同。

# **增加就业**

潜力非常大，但是被劳动法卡住。举例，我是小厂子，缺一个扫院子的老太婆。我愿不愿意招聘？太复杂，不愿意。怎么办呢？我给车间员工分配任务，一个人干一天。如果是100个人，基本上就是三个月扫一次，大家也就强接受。

结果是双输。企业以技工的工资扫扫地的任务。市场上少了一个长期稳定的低端就业岗位。很多人认为，就业岗位越高级越好。实际上不是的。因为有很多人只能胜任低端岗位。你让一个老太婆做流水线，她干不了，她要接送孩子上学。但是，你让一个老太婆做点小事情还是可以的。例如村口小企业有个食堂，老太婆洗半天碗，洗两个小时菜，还是可以的。

现在，农村男性，55岁身体还可以，但很难就业了。实际上，有非常多的岗位适合他们，例如扫扫地，食堂后厨打杂，搞搞卫生。但是，势力单薄的小老板担心劳动纠纷，不敢找他们。他们怎么办？找子女呗。你是金凤凰，家里就靠你了
