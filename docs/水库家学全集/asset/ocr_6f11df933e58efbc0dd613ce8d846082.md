# 05

（纯理论）机遇和站位。

人和人的综合实力不会差太多，达尔文的进化论不是开玩笑的。你可能考试强一点，我做事强一点，你智商高一点，我情商高一点，各有所长。但在现实中，人过四十，天差地别。人和人的区别，主要不是能力问题，而是机遇和抓住机遇的心。

为什么大家会有不同的机遇。古往今来有很多说法，但我觉得，机遇和你的站位有关。举例，在土豪马爸爸周围的人不会太差。他随便点你几句，给个机会，你就起飞了。你也不会害怕，因为马爸爸成功了，你就会信心倍增。人生永远不会知道，明天会发生什么？

小结，你应该告诉孩子，争取和厉害的人一起玩，仔细看看他们在干什么，在想什么。人生的机遇有不少，抓住一个就够了。
