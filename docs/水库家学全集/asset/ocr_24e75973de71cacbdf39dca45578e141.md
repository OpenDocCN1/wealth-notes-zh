# 辞职前的心路历程

我原来做一个大单位，还是可以的，放到现在，985也很难进去。后来我辞职了。表面原因是没混上去。实际原因是，我自己不会做人，油腻。有联系的大佬退了，没办法了。想来想去，干脆算了。菜嫂也同意我辞职，因为我每天早上六点半起床，会把一家人吵醒。我还有房租可以收，生活不担心。

辞职前，心里那个气啊，辛辛苦苦这么多年，点头哈腰，加班加点，从不抱怨，不就是想混个好前途吗？论考核，我每年都是前几名，比新提拔的那250强多了。可又有什么用呢？

辞职后，开心了两个月，因为再也不用早起早睡，追剧，出去玩，想怎么来就怎么来。辞职后，第一个星期，电话多的不得了，都是老同事来问情况的。看起来，他们好像也很憋屈，想走不敢走，很羡慕我。

慢慢的，电话没了。现在，除了骗子电话，再也没人找我了。所有的熟人都消失了。人情没有意义。

辞职后一两个月，心理压力比较大，觉得自己已经无依无靠了，遇到困难，也有点后悔，但是过了那个阶段，就无所谓了，我适应了。

第三个月后，玩也玩够了，总要找个事去做做。没办法了，去菜嫂家族企业兼职做了个董事长，可惜前台小美长得太丑，实是不想再去。

后来，我找到了人生新价值，等拆迁。

等啊等，等啊，等啊，怎么还没轮到我？如果拆了十个亿，怎么花呢？
