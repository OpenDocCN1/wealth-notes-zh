# 985和二本子有什么区别？

一是自信。985特别适应竞争压力。他们对竞争有特别的渴望。二本子害怕竞争，二本子希望别人把房子建好了免费发给他，而且必须有精装修厕所。985不在乎，大家凭本事买也可以。

二是聪明。你去看论文数量。985明显比二本子多一大截。

三是上手快。不管学什么东西，985一看说明书，基本上就行了。二本子大脑质量比较差，手把手教也不一定。

当然，985也有极大的缺点，性格不好。绝大部分985看不起别人，他们觉得，小学四个班才出一个985，老子就是厉害，你服不服？这种心态会得罪人的。

在一个单位里，你厉害不厉害并不重要。你厉害对我有什么好处？老子看着你就烦。

- 管竹峰：厉害并低调，才是真厉害
- 黑崎skenko：你说的是一个成熟的人和不成熟的人
