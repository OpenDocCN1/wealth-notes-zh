# 什么样的人适合去京沪

一是985，绝大多数小地方是没有什么大的产业或者优质公司，需要985的，二本子足够了。985的唯一作用就是点缀一下。然后就看你会不会做人了，你家有办法也可以。最好是一毕业就去正式编上班，相亲都会加五分。京沪广深就不一样了。这里有很多很多公司，什么行业都有，哪怕你是学海洋生物的，还有好几个海洋馆给你练练手的机会。我认识一个哥们，是在外国学船级社的，我还是第一次听说居然还有这玩意。他居然也找到了一个不错的工作，现在成为金光闪闪的部门经理了。

二是农民工。反正都是打工。哪里工资高就去哪里。京沪广深最好，就算送外卖，也不会闲着。在我们老家村里，也有很多打工机会，但属于是间歇性的，不是每天有活。做一单算一单，一年下来，估计少赚不少钱。

三是想碰碰碰运气的小二子。有些充满梦想，但也没有什么技术的小杆子，纯粹是靠运气瞎溜的，那么，京沪广深的运气可能要多一点。前不久，我周围又发生一个想不到的事情，有个白富美去洋快餐打工，被一个我们老家村里的小杆子摁住了，妥妥的三套房。据我了解，这个白富美属于缺爱型的，老爸老妈长期打架，她读大学后，周末也不回家。因为老两口互相提防，有几套房子女就写在了女儿名下，被屌丝一锅端。那那，如果要他自己赚两千万，估计要从唐朝干到现在了。
