# 01

# 烂泥扶不上墙。

亲戚家的孩子，不成才都是有原因的，你不要去帮，帮也没用。我有很多亲戚逢年过节就来我家卖惨，我也很难受，总希望做点什么。二十年前我在投资部，偶尔得知，自学大专也可以考律师证教师证。我盘算了一下，第一时间通知了几个对我不错的穷亲戚的儿子，我告诉他，先读函授大专，然后考律师，我还给他们买了书，打好好报名时间，你去就行了。几年后，我给他拉点业务，买个房子拿个蓝印上海户口不成问题。

穷亲戚兴奋了。第一个孩子去报名，路上丢了身份证没有报名，其他几个孩子读了一年就读不下去了，陆续开始在家里骂我，一看书就骂我，他父母也觉得，我是不想帮忙，故意给孩子找麻烦，居心不良。之后就断绝来往了。

最后，那几个孩子没读完就全部放弃了，现在无所事事在家里啃老。我后来又遇到几个大专考律师的，和亲戚儿子年龄差不多，现在年薪几十万，房子好几套，小三个几个。回想起来，我感慨万千。他们错过了人生的最后机会，现在成了老屌丝，老婆天天在家里砸碗砸碗，骂他们没钱买房，连炫N都买不起，更不要说苏A沥A苏K了。

现在回忆，亲戚们实际上要的是躺赢，而不是辛苦拼搏。我哪有本事给他们躺赢啊？
