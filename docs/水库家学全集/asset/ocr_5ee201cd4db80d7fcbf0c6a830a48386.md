# 02

避暑胜地。

春节过完了。下一次就是避暑胜地了。你有没有发现一个奇怪的现象。大家冬天去海南，但是，没有人夏天去靠山屯避暑。为什么？因为靠山屯的夏天也热成狗。

南方人没有在东北待过，我待过一段时间。你在东北，无论多热的天，只要在树荫下，就凉嗖嗖的。

避暑胜地的竞争对手非常多。你可能无法想象，号称夏天火炉的重庆武汉，附近居然有好几个避暑胜地。因为避暑胜地很容易找。因为只要有座高一点的山，山上就是避暑胜地。我有一次在夏天去海南，我发现一个特点，太阳下，海南夏天热的冒油，你只要在室内，走廊上的小风一吹，就挺凉快的。还有人去海南避暑。

小结，避暑山庄没有任何价值，太多了。
