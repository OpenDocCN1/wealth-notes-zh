逆袭的方法和感悟。

这么多年，我见过，也亲历过很多的逆袭历程，我把感悟写下来，给下一代人看看。

+   1，乡镇企业蓬勃发展，成就了一批人。我有个远房亲戚，是农民。18岁中学毕业后进入乡镇企业。那时候，进入乡镇企业就像是在进入互联网一样，是很多人梦寐以求的事情。那时候月入90元。

+   到了90年代，厂子不行了，没人要，就搞了改制，他倾家荡产，把这个厂买下来了。后来成为一个附近三个村的首富。

+   2，外贸火热。我有几个亲戚在浙江做小作坊，就是做一些塑料小零件，现在也发达了。

+   3，内贸爆发。举例，一个厂子生产辣椒，你承包一个地区，例如一个县，完成多少销售，就提成多少。其他产品同理。

+   4，股票害人。这个是近30年的事情了。我周围这么多亲戚，没有一个因为股票赚钱的。套牢很多年的，比比皆是。当然，有人肯定会说，我亲戚赚钱了。

+   5，电商带货。确实有一批人赚了钱，但不多。我知道有一个，原来是营业员，瞒着小老板，就把店里的羊毛衫在网上卖，吃差价发了一笔，也就两年时间，后来就纯粹白忙了。杠精不服了，我朋友怎么样怎么样的，“西开！”

+   6，结婚买房，略。很多农民工进城打工，买了个小户型，发了。

我发现一个规律，大规模逆袭往往是有深刻社会进步原因的。普通人在时代面前，是渺小的。丝丝不要一天到晚想改变，你应该顺势而为，站上风口。
