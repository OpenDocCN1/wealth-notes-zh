# 2.三人行必有我师的数学原理

你注意到没有，生活中有时候会有像石头剪子布一样“循环相克”的现象。比如满清末年中国流传一个说法叫“官怕洋人、洋人怕百姓、百姓怕官”；在足球比赛中，也常会有“A队怕B队的逼抢，B队怕C队的技术，而C队又怕A队的身高”这样的局面。

出现循环相克的根本原因，就在于他们比的不是一个单项技能，而是一个工具箱。
