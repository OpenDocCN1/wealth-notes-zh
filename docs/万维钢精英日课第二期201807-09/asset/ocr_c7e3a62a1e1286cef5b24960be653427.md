# 日课197 | 创造的脚手架

日课197 | 创造的脚手架

今天我想探讨一个可操作、又比较高级的创新方法。我们专栏经常见所说创造就是“想法的连接”，今天我要说的这种连接，就比简单的“山寨”高级得多，但是又不像各种发奇想的神来之笔那样难以操作。这个方法其实被创新者在各地大量使用，是他们日常都在于的事情，但是外行一般看不出来。

这个方法的特点是直接借鉴同行作品——但是不是直接使用。

我向你推荐一部奇幻小说，《西游记》……当然我推荐的是一个阅读《西游记》的新视角。我们小时候——作为中国文学作品的外行——读《西游记》总觉得这些故事实在匪夷所思，真不知道吴承恩是怎么想出来的！长大以后你看到有无数沉默。

创造就是把东西连接起来。如果你有创造力的人是怎么做出东西来的，他们会有一点负罪感，因为他们并没有真正“做”东西，他们只是能够“看到”东西。一段时间之后怎么做就会变得非常明显。这是他们能把自己的经验和新东西综合起来。因为他们拥有比别人更多的经验，他们对自己的经验想的更多。
