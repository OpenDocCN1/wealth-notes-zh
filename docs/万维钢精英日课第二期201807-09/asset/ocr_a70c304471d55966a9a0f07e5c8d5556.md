# 日课192 | 人类平均智商正在稳定上升……现在又下降了

今天咱们说一个有关 “智商” 的最新认识。这是一个有点让人困惑，有点让人担忧，但是现在几乎可以确定是真实的消息。

# 1.弗林效应

你很可能听说过一个叫做 “弗林效应（Flynn effect）” 的现象，说的是二战结束后到当前的这几十年内，世界各国人口的平均智商在逐年上升。我们专栏在《到底 scam么叫 “智商”》这期答读者问里说过这个效应，王晓老师的“30天认知训练营”里有一期叫《为什么上一代总是像弱智》专栏说了这个效应。

有时候我们觉得这一代人比上一代人聪 明，也有某些人担心年轻一代沉迷游戏智商下降，那总的来说人是普遍变聪明了呢还是变蠢了呢？新西兰学者詹姆斯·弗林在上世纪九十年代发表研究结果，说美国人的平均智商大约每十年增加三分。

这差不多是说，如果1960年的美国人的平均智商是100，那么如果用同样难度的题目在1990年测试的话，美国人的平均智商将是109分。“弗林效应”在很多国家都得到了验证，有发达国家有发展中国家，结果差不多都是平均每年增加0.3到0.4分左右。中国的数据没有那么多，但是我也看到一个2016年的研究 [1]，说从1982到2006年间，中国大陆和香港地区儿童的智商每年增加0.44分。

# 2.逆转弗林效应

最早引起公众关注的是英国人的研究 —— 为什么又是英国 —— 大概是2009年有个研究 [2] 说，全世界人民的智商都在增加，可是英国人的智商却下降了。英国人对此可能很无奈，但是英国人本来也不是一个乐观的民族，所以这条消息没有引起太多波澜。

# 3.实锤

2018年六月，PBAS 期刊上发表了一份新的研究报告 [5]，证明弗林效应逆转是个实质性的效应。这项来自挪威的研究用一个非常巧妙的方法抓住了实锤。
