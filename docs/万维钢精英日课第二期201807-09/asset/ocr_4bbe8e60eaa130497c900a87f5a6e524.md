# 日课206｜启蒙与此时6:资本主义的本质

我丑陋用了一个特别大的标题，但我们今天的确也是要讲一个特别大的的话题，那就是到底什么是资本主义。

资本主义不是被某个总设计师顶层设计出来的。我们前面讲了，资本主义是很多因素放在一起共同促成的一个现象。你也可以说这是一个“涌现”现象。参与者只是做自己的事，哲学家也只提出某一方面的思想，没有人通盘设计过资本主义这个概念，结果却是产生了一个完全不同于传统的这么一个社会形态。

聊吧资本主义出来以后，学者们也没搞明白它到底是什么。过去的学者——比如卡尔·马克思和马克思·韦伯——对资本主义有过各种不同的解释，咱们今天要说的这个解释也不一定是对的，但是我觉得开卷有益，值得你了解。

马克思所处的年代还是资本主义的早期，韦伯则是个十九世纪末二十世纪初的人物。他们当时看资本主义，可能看得没有那么清楚。这就好像看人不能只看他的童年和青年时代，你得等他成熟以后再看。

现在在资本主义已经成熟了。我们从历史大视角回过头来看，有些东西也许能看得更清楚一点。我们还是讲戈德堡的《西方的自杀》这本书。

资本主义的本质是什么呢？到底是一个什么东西，有它就叫资本主义，没有它就不叫资本主义吗？

传统的理解，这个东西是“资本”。

# 1.资本主义与资本

卡尔·马克思和马克思·韦伯都认为之所以出现资本主义，关键在于有资本。咱们先简单说一下他们两个的思想。

卡尔·马克思所处的时代还是资本主义的早期，当时工人的工作环境和生活条件很差，马克思作为一个知识分子感到无法接受。其实平心而论，按照现代学者的考证，当时工人的生活条件已经大大好于资本主义出现之前农民的生活。但是马克思看到的苦难比我们今天看到的多，他看到的创新比我们今天看到的少，所以他形成了一个观点，认为资本主义的本质就是认利润。

利润是哪里来的呢？马克思认为利润来自“剩余价值”。马克思说所有价值都是工人创造的，去除原材料之类的成本，资本家给工人发完工资之后，还剩下的那部分价值，也就是“被资本家无偿占有的”利润，就是剩余价值。资本家通过剥削工人、占有剩余价值来积累资本。有了资本就可以扩大再生产，再进一步用资本去建更多的工厂，赚更多的钱。资本家越来越有钱，工人还是那么苦，资本主义就是这么回事。

马克思鄙视资本。马克思说“资本自从来到这个世界，他的全身上下每一个毛孔都流着血和肮脏的东西”。

今天的人通常把资本家称为“企业家”，我们会说企业家要搞管理创新，企业家得承担风险。但是在马克思看来，所有企业家自己的创新和冒险都不创造价值，一切功劳属于活的工人。

今天的人认为凡创新都要冒险，企业家的冒险精神值得赞赏一但是马克思对资本家的冒险，是嘲讽的态度。

马克思说“有50%的利润，资本就<|start|>走险；为了100%的利润，资本就敢践踏一切人间法律；有300%以上的利润，资本就敢犯任何罪行，甚至去冒绞首的危险。”今天的企业家听到这句话，不知会作何感想。

卡尔·马克思出生于1818年，而马克思·韦伯出生于1864年。韦伯见到的资本主义比马克思见到的要好看得多。韦伯对资本是另外一种态度。

韦伯1905年出了一本名著，《新教伦理与资本主义精神》，认为资本家——这里应该叫“企业家”了——聚集资本靠的是……勤俭持家。传统基督教鄙视赚钱，而新教鼓励赚钱。新教伦理要求你勤奋工作努力赚钱，但是赚钱不是为了自己享受，而是为了把事业做大。如果你赚很多钱，那就说明你是一个成功的人，也说明上帝对你的认可。

韦伯描写了一个勤俭创业的精神，美国历史上很多人就是这样的精神，咱们中国今天的很多企业家也是这样的精神。韦伯赞赏这个精神，认为新教伦理——而不是剥削——才是资本主义的真正精神。

# 2.资本的作用

我们比较一下卡尔·马克思和马克思·韦伯的说法。马克思讲资本家剥削工人获得的剩余价值，韦伯讲过企业家勤俭奋斗获得的过量资本，他们说的其实都是资本决定了资本主义。说白了，他们都特别看重金钱。

人的传统思维，对金钱有一种复杂的情结。人是既喜欢又反感钱。但不管你是喜欢还是反感，你总是首先想到钱。戈德堡认为，这个复杂的情绪，让马克思和韦伯都高估了资本的作用。

勤俭持家就能带来资本主义吗？任何时期都有只图赚钱不顾享受的有钱人。咱们中国的地主，一有钱就去买更多的土地，或者也开店铺经商，他们的故事至今还在电视剧里流传，那中国怎么就没发明资本主义呢？

韦伯可能有点过度美化新教了。历史上的新教非常反科学的，搞过很多极端的事情，比如猎杀女巫。这哪里符合启蒙精神了？

而如果是剩余价值能带来资本主义，那奴隶的剩余价值难道不是更高吗？美国1870年代打完了内战之后，彻底废除奴隶制。那这时候剥削不能像以前那么狠了，按理说棉花的价格应该上升，对吧？而事实上，棉花的价格反而比废除奴隶制之前下降了42%。

资本主义演化的大趋势是剥削减轻了，效率反而提高了，这个现象马克思会怎么解释呢？

当然，马克思和韦伯的理论也都有一定道理。如果资本家不剥削工人，就不会那么容易积累资本。如果没有新教精神，资本家也的确不会把赚钱搞得那么光明正大。

这个要点在于，资本也只是产生资本主义的诸多因素之一。资本主义的本质特征不是资本，而是别的东西。

咱们还是看看现代学者怎么理解资本主义。

# 3.对创新的态度

伊利诺伊大学经济学教授戴尔得丽·麦克洛斯基（Deirdre McCloskey）对资本主义有一个全新的研究。她在2016年发表著作提出，是人的观念和想法，而不是资本或者政府机构，带来了资本主义和世界的繁荣[1]。戈德堡接受了这个观点。

麦克洛斯基说，资本主义的真正标志，是人们对市场、企业和创新的态度发生了重大转变。

所谓对市场和企业的态度发生转变，说白了就是人们对赚钱这事儿的态度发生了转变。韦伯强调的是资本的作用，麦克洛斯基强调的则是态度。关键不在于积累了多少金钱做资本，关键在于对金钱的态度。资本积累是资本主义的“果”，态度转变才是资本主义的“因”。

传统思维都是鄙视赚钱的，学者看不起商人，连商人自己都看不起自己。特别是“以钱生钱”——也就是放高利贷这个做法，在各国和各个宗教眼中都是坏事。
