# ◆ 反叛

◆ 在美国社会学家看来看，人 的行为的 “酷” 的意思，是 “积极正面的反叛” —— 是 “对不合理的主流的一次正当的打破”。

酷，体现了一种自由独立的精神，一种反抗精神。但是 “酷” 也有个约束，那就是必须 是 “正当的”。
