# 1.多样性好处的数学公式

(1) 群体能力 = 平均个人能力 + 多样性

(2) 多样性 > 能力

群体预测的方差 = 群体中个人预测的方差的平均值 - 群体多样性。

# 2.多样性产生红利的条件

| 这个问题必须足够“难”，要难到没有一个人自己就简单独解决方案的程度。如果是一个人就能解决的事儿，强调多样性就是浪费人。 | 最高 的山峰很难找到。如果一个人就能喊出哪里最高，用群体就没有意义。现实是我们没有地图，每个探险家只能看见自己附近的一小块区域。 |
| 群体中的每个人，都必须有一定的预测能力。也就是说每个人都够格才能，国图变量手可以，但球速不行。 | 每个探险家都能迅速找到自己附近的“局部最高点”。这是因为探险家随着更高的山峰，找不到更高峰的探险家，否则就是个来旅游的。 |
| 群体中每个个人都有跟别人不一样的视角和解决问题的办法。那也就是说每个人都有他独有的价值。 | 把全体探险家随机分配到各区城去，不要让他们堆。如何去给探险家足够与其他人不同的条件，那么地就是多余的。 |
| 群体的规模必须足够大。 | 探险家的人数足够多。 |

# 3.多样性认知工具箱

第一个工具：视角

所谓视角，就是你*怎么看*这个东西，你把这个东西*看成什么*。

视角的三个洞见：

+   1. 视角的选择，对解题的难易，关系重大。 2. 要想有利于解题，你这个视角最好自带某种结构。 3. 对任何一个问题，都存在一个能让答案一目了然、脱颖而出的视角。

> “学者存在性定理（Savant Existance Theroem）给了我们希望。一道难题摆在面前，可能当前谁都不知道怎么解决，但是你要相信，总有一个视角，会让答案看起来那么简单，能够脱颖而出。

第二个工具：启发式

> “启发式是这么一个规则：在某个视角里，使用这个规则能够得到一个解一那么你受此启发，也许可以把这个规则用在别的问题上，得到别的解。”

启发式就是思维的套路。更基本的含义，大约可以称为“思维快捷方式”。

| 拓展启发式：看看周围附近的地方。 | 你读到一本书觉得有意思。你就想看看这位作者还有没有别的书。 |
| 梯度启发式：梯度启发式也等察邻近的地點，但是它有一个明确的方向。 | 做凉，尝尝觉得有点淡了，你就放它变成一点儿，你想要的就是有一个明确的上升量 — 在数学上，这就叫“梯度”。 虽然你也很加料，但是不加料。你的探索有另一个明确的方向。 |
| 允许犯错启发式：所谓允许犯错，就是你可以随意“某些 任意的震动”。 | 探险家可以先不着急选一个方向一心一意前進，也先四下看看后再，这看起来像是完全随机的做法。也会看到意外的惊喜，也可以就能够到右边那更更高的峰。 |
| 种群启发式：用模拟生物进化的方法来最优解。 | 把配对分数编码化，每一组数字代表一个配对的“DNA”。选出代表的，彼此互相“配位”、“生育”出下一代配。以及此推，得到特别优秀的配对。 |

第三个工具：解读

解读，就是在一个视角之下，把东西做进一步的分类。

投影解读：如果你的分类方法是选择视角中的一个维度并且忽略其他维度，那么就叫 “ 投 影 解 读 （ projection interpretation）”。

聚丛解读：你也可以不管什么维度，任意选择几个东西说它就是一类，这就叫“聚丛解读 (clumping interpretation)”。

第四个工具：预测模型

预测模型 = 分类解读 + 预测

每一个解读，都要忽略一些东西。每 一个预测模型，都是主观的选择。不分类，你就没效率；分类，你就会歧视。解决这个矛盾，就需要多样性。

# 4.怎样利用多样性

多样性具有“超加性（superadditivity）”。把两个视角“加”起来，有利于你解决新的问题。这也正是我们常说的，创造性就是“想法的连接”。
