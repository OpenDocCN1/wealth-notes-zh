# 設計一套簡單的營業計畫

如同本章標題所示，交易是一種事業，因此也應該當成事業來經營。成功的交易者會在進行交易前，先擬定簡單的營業計畫。運用前面討論的內容，編製一份自己的操作指南。舉例來說，稍做評估，判定自己是嫌惡風險或者能夠容忍風險，然後再配合可供運用的時間、財力，挑選適當的交易工具。

+   ▶ 購置一台高性能電腦，一台或數台顯示器，尋找適當的網路服務商，或許還要租交易軟體，支付交易所費用（如果需要期貨市場報價資訊的話）。另外，你可能需要購買研究資料，訂閱報章雜誌。

+   ▶ 嚴格規定一項法則：任何單筆交易所承擔的風險，絕對不可超過帳戶淨值 2%。舉例來說，假定交易帳戶內有 1 萬美元，則任何單筆交易虧損都不可超過 200 美元。當然，帳戶淨值如果變動，最低風險也要隨之調整。

+   ▶ 核算每個交易日允許產生的帳戶最大淨值耗損，虧損一旦達到這個金額就停止交易，檢討交易程序。
