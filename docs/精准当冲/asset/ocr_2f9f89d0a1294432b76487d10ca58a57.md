# 技術分析

技術分析代表另一套股票研究方法，研究主題包括時間、價格與人氣心理。技術分析最常使用的工具是走勢圖。股價走勢圖顯示該股票的歷史價格資料，使用者經過練習後，可以在短時間內看到他需要知道東西。

走勢圖上的價格並不是隨機產生。各位是否還記得前文討論的供給、需求與價格？走勢圖呈現的價格型態，反映市場參與者的集體看法和心態。價格型態之所以重複發生，因為這些買家和賣家都憑記憶操作。他們或許從未見過股價走勢圖，但即使在每股 50 美元買進「簡單軟體」股票的投資人，他們也會記得在買進股票後不久，股價下跌。經過 3 個月後，當股價再度回升到每股 50 美元，這些投資人為了避免陷入虧損，決定解套賣出。這種行為造成股價型態。

圖 5-1 顯示我們如何辨識走勢圖呈現的買進狂熱、不確定、恐慌與瘋狂賣壓。等到上漲或下跌的強勁力道平息後，股票陷入橫向盤整，價格在特定區間波動，因為買賣雙方力量相當，任何一方都不能取得明確優勢。

走勢圖除了顯示時間、價格與成交量資訊之外，還會呈現各種技術指標和擺盪指標（超買／超賣指標）。每位交易者都有自己偏愛的指標（後文會更詳細討論技術指標與擺盪指標）。走勢圖的成交量直方圖，代表一天、一週、一個月或任何特定時段的成交股數。移動平均則代表某特定时段收盘价格的平均数。这些技术指标看似复杂，令人眼花缭乱，不过不用担心，阅读本书后，你就可以轻松解读。
