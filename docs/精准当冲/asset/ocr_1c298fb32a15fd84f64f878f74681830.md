隨機指標可以「看到」收盤價轉弱；若是如此，%K 線會向下發展而穿越 %D 線，代表賣出訊號。這意味著上升趨勢將拉回，或多頭宴會將暫時告一段落。

另一方面，明顯的下降趨勢，收盤價大多落在盤中最低價附近。一旦空頭後繼乏力，多頭就會進場，逐漸蠶食，於是收盤價慢慢往盤中高價移動。等到隨機指標察覺到收盤價逼近高價，%K 線會由下往上穿越慢速 %D 線，這代表買進訊號。

# 如何運用隨機指標

+   ▷ 超買訊號：讀數超越 80。

+   ▷ 賣出訊號：訊號線（慢速 %D ）在超買區折返，%K 線向下穿越訊號線。

+   ▷ 超賣訊號：讀數跌破 20 。

+   ▷ 買進訊號：訊號線（慢速 %D ）在超賣區折返，%K 線向上穿越訊號線。

+   ▷ 背離現象：價格創新高，%K 線卻沒有創對應新高，此為空頭背離；價格創新低或橫向盤整，%K 線卻走高，此為多頭背離。

+   ▷ 時間架構：隨機指標適用於任何時間架構。有些交易者用於盤中走勢圖，我則是用於週線圖、日線圖與小時走勢圖，藉以確認進場、出場與風險管理決策。
