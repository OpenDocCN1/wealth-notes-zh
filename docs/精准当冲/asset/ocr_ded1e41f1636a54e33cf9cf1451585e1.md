# 有意識地生活，並獲得成功

> 「我們的一切是所恩所思的結果。心智是一切，你想什麼，你就變成什麼。」

——佛陀

每個人都可以選擇：有意識或沒有意識地生活。當我們選擇有意識地生活，這種意識源自內在力量。我們享受每一天，享受它帶來的積極能量。

如果選擇沒有意識地生活，我們只能被動反應。不能藉由問題汲取教訓，而是把問題推往一旁。然後，我們還搞不清楚為什麼相同的問題總是重複發生。

終極生命的過程，對每件事、每個人都扮演著某種角色。你只需要觀察大自然如何完美地協調地球所有力量，就能體認其中真相。每個人都被賦予某種獨特才能，某種獨特的表達方式。我們應該發現自己的潛能，然後去實現。如此一來，既實現了自我目標，也幫助了周遭的人。

透過自家潛能的鏡頭觀察人生，就會意識到人生目標的急迫性。每天都有新的意義。我們不會帶著應付了事的態度處理每天的事務，而是把每件事都視為一個學習機會。我們所擬定的決策，是根據內在核心某種不具批判性的認知。
