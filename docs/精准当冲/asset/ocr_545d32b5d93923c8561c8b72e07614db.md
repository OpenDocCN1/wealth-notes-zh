+   10. 精明的交易者會在突破當時建立半數部位，另外半數部位，則趁著拉回走勢反轉或突破時建立。正確或錯誤？

# 答案

+   01. 實際進行交易前，由上而下的交易者會考慮整體市場趨勢、檢視市場內部指標、評估產業類股、確定相關企業不會公布令人失望的盈餘或經濟報告，以及研究股票的週線圖、日線圖與盤中走勢圖。

+   02. 錯誤。不是好點子。

+   03. 連續型態與反轉型態。

+   04. W。

+   05. 錯誤。永遠要等待 W 底排列完成，並出現拉回走勢，進行數天盤整，然後才趁著向上突破走勢買進。

+   06. 顯著大量。

+   07. 就日線圖觀察，每當股票走勢停頓或呈現連續型態，停損就調整到相關支撐低點下方 25~75 美分位置。
