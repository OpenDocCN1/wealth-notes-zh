# ## 交易指令類型

我知道各位兩眼乾澀，頭腦像糨糊一樣，但請打起精神，學習下列的交易指令。

各位可以使用的交易指令類型包括：

市價單（market orders）：如果按照「市價」買賣，等於給專業報價商或造市者全權委託書。他們決定你需要支付或取得的成交價格。當你的交易指令到達他們手中，這些人可能不會按照當時顯示的報價撮合（我曾經目睹造市者接到市價賣單時，調降他們的買進報價）。你所交易的股票成交量如果很大，交投狀況穩定，而且你不想追價，不妨採用市價單。你如果不計代價而急著買賣，可以採用市價單。除此之外，請採用限價單。如果不能成交，就不要追價。市場永遠都有機會。
