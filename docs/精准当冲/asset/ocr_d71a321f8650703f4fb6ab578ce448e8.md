+   3. 記住，信念與希望的情緒讓你虧損。你禁不起這種虧損，代價太昂貴了。

# 為什麼所有的虧損都是「魔鬼」造成？

身為初學者，你逐漸熟悉自己的各種特性，某些特性協助你獲致成功，有些則需要受到控制。及早認清楚那些會影響交易的特性。對自己的認識愈清楚，對交易生涯的幫助愈大。

在交易過程中，你如果採取某種值得懷疑的行動，先問心自問：

> 「我為什麼這麼做？究竟是什麼特質促使我這麼做？」

答案若是「我太衝動」，再回頭想想自己是否習慣先採取行動，然後才思考？這可不是好習慣。你必須設法把「衝動」取代為「完全按照計畫進行交易」，並避免在行情波動劇烈時進行交易。

答案若是「我太樂觀」的話，你是否期待最好的情況？樂觀是信念與希望的孿生兄弟。有色的眼鏡會扭曲市場現實。

答案若是「我太頑固」的話，通常是堅持自己的判斷正確，這種心態也有礙交易。訓練自己把這種態度改為「臨機應變」與「順勢而為」，並瞭解市況發展隨時可能反轉。撇開頑固的心態，才能擬定成功的決策。

# 有利於交易的特質

你是否有追求完美的特質？這種特質往往讓周遭的人為之瘋狂，某個角度來說，也有助於提升交易績效（這種特質可能導致焦慮，所以不要對自己要求過多）。
