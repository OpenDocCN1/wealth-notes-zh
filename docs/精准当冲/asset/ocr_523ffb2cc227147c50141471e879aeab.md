# 你的願景，是生命對於偉大的邀請

> 「如果知道自己不會失敗，你會怎麼做？」
—— 羅伯·舒勒博士（Dr. Robert Schuller）

你的願景隱藏在內心深處，它代表最純粹的潛能；即你的真實自我。真實願景代表最核心的自我，它說明了你是誰，世界定了你個人的偉大程度。

想要瞭解自己的願景，使其形成可辨識的思想形式，就必須撇開老舊、有限的信念，並看到真實的自我——由天賦智慧、能力與智識構成。這個自我可以發揮你的最高潛能，創立目的明確的人生。

一旦清楚自己的願景，你可能不知道如何完成它。很少人知道。可是，就如同種子埋入溫暖的土地，陽光自然知道如何讓植物生長，願景所蘊含的宇宙智慧也會讓它自然開花結果。

為了讓願景萌芽，你只需傾聽內心指引。按照它的指示行事。踏出第一步，然後第二步。如同來自陽光與雨滴的照顧，滋養種子成為強壯、健康的植物，你對於願景投入的能量愈多，它就成長得愈快。你將被自動引導到正確的人、正確的地方和正確的情況，推動你的旅程繼續向前邁進。

在你心中成長的願景，是無限的你、強大的你、睿智的你。只有你才有信心，滿懷熱情向前邁進，抓住最具挑戰性的機會。

你的願景是生命對於偉大的邀請。你是否願意接受這個邀請？
