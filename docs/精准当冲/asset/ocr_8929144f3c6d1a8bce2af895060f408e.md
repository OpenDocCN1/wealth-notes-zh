# 培養頂尖交易者思維

# 巧合或同步發生？

> 「在是所有形式背後，都有一種精巧完美的智慧，它以同步發生的方式運作。每件事情的發生都有其目的，讓生活的拼圖完美地組合在一起。當你相信與瞭解這些想法，每天都會發現你相信同步發生的證據。」 ——韋恩·戴爾〈相信什麼，看見什麼〉
Wayne Dyer, *You'll See It When You Believe It*

有多少次，當你拿起電話筒，還來不及說「喂」之前，就突然知道電話那頭是誰？又有多少次，當你想起來某個許久未見的人，卻發現他在同一天出現？

在更深的層次上，你回顧過往，發現在最困難的時候，不知從哪裡出現對的人或事，總是幫助你度過難關；或當你經歷某個艱困情況，最終卻帶來令人驚訝的嶄新機會。

有些人將這類事件稱為巧合。或許真是如此。可是，我相信它們是透過同步發生的過程產生。卡爾·榮格（Carl Jung）把同步發生描述為兩件有意義而無因果關係的事情同時發生。

地球完美地圍繞太陽運轉，不會偏離軌道而自我毀滅。對於這個星球上的每個人，重力的作用都是相同的，不會有所差異。自然界的一切如果任其發展，都會呈現一種微妙的僮同作用，彼此完全同步。

我們的環境如果經過如此完美的安排，我們的生活是否也可能如此？每個人的生命是否都存在某種內之目的？每個生命都是經由某種智慧悉心安排，透過完美的同步，而實現某種更宏偉的計畫。
