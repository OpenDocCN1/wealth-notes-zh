# 開盤跳空：處理方式

股票開盤價如果高於或低於前一天收盤價，就稱為「向上跳空」或「向下跳空」（譯按：一般來說，開盤跳空是指今天開盤價高於〔低於〕前一天最高價（最低價）而言。如果根操作者定義，只要開盤價不剛好等於前一天的收盤價，就屬於跳空開盤；若是如此，開盤跳空的現象恐怕十分普遍）。

股價之所以開盤跳空，通常是因為公布經濟報告、盈餘數據、產業新聞、信評升級／降級或其他新聞的影響。

舉例來說，ABC 股票週五下午收盤價為 52.25 美元。隔週的週一上午開盤 53 美元，開盤價上漲 $\frac { 3 } { 4 }$ 點，因為週一上午的買單與賣單不平衡。買單超過賣單，促使專業報價商或造市者開出較高的價格。

價格向上跳空，可能是祝福，也可能是詛咒。那些週五晚上持有 ABC 股票的人，週一上午起床，每股就賺了$\frac { 3 } { 4 }$點或 75 美分。可是，你如果未曾擁有 ABC 股票而正打算買進，由於開盤價格向上跳空，恐怕會打消買進的念頭。

「逆向操作跳空缺口」（fade the gap）是交易圈常用手法。換言之，針對任何特定方向的跳空缺ㄩ，交易者採取逆向操作；所建立的部位，其方向與既有趨勢相反。

開盤價格跳空的後續行情發展，成交量扮演重要角色。開盤如果夾著大量向上跳空，意味著需求足以克服空方與賣壓。行情可能繼續走高。開盤價格向下跳空的情況則相反。

反之，開盤價格向上跳空，如果成交量很小，可能吸引空头進場，就像腐肉吸引蒼蠅一樣。成交量小，代表承諾不足，針對跳空缺ㄩ反向操作的成功機會很大。向下跳空的情況相反。
