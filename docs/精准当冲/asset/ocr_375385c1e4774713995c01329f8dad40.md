+   - 網站瀏覽方便，能夠迅速顯示圖形。總之，網頁反應必須夠快。

+   - 交易介面規劃合理，具有防範資料輸入錯誤的設計。

+   - 快速回報系統，帳戶餘額與投資組合即時更新。

+   - 方便使用、內容豐富的研究資料。

+   - 多種替代聯絡管道。碰到緊急狀況或市場崩盤，交易指令的傳遞與執行效率如何，系統是否會塞車？伺服器是否會當機？是否可以透過電話聯絡經紀人？速度是否夠快？

+   - 融資成數夠高（保證金成數夠低）；各家券商提供的融資成數差異可能讓你訝異。

+   - 如果交易帳戶設定最低開戶金額，規定應該合理（如果符合美國證管會對於「典型當沖交易者」的規定，在 5 個營業日內進行 4 趟或以上的來回交易，帳戶內至少必須維持 25,000 美元淨值）。
