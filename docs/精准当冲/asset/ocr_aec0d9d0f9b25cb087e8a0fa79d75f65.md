卻要賣出 600 股。真是這樣嗎？」

我嚇了一跳：「喔，不，我是想賣出 300 股。我賣了兩次嗎？對不起。」

或者：「透納女士，妳下單買進 5,000 股 TT 卡車運輸。如此一來，妳的保證金帳戶餘額將不足 20,000 美元。妳真的要這麼做嗎？」

老天！「5,000 股？保證金不足 20,000 美元？不，我要買進 500 股，不小心多按了一個 0 。很抱歉。」

很幸運地，累積一些經驗後，就可以減少這方面的混淆，但在此之前，仍然可能發生大災難。為了避免浪費時間和金錢，務必及早採取必要的防範措施。

# 防範混淆的最佳措施

+   1. 剛從事交易時，每筆交易規模不要太大，譬如 100 股，最好不要超過 300 股。如此一來，萬一股價下跌，或不小心買多了，還不至於造成不可收拾的災難。

+   2. 完成一筆交易之前，不要進行另一筆交易。對於變動快速的股市來說，每次進行一筆交易就夠了。你大可不必擔心錯失機會，股市從來不缺機會，前提是你必須有資金可供交易。

+   3. 先做紙上模擬交易，直到你覺得準備妥當，可以進行實際交易。

+   4. 務必摸熟使用的系統，尤其是新的券商系統，然後才可以實際進行交易。

+   5. 任何時候僅學習一種策略，而且僅利用該策略進行交易。聽
