# 恐懼的真相

> 「 圖難於其易，為大於其細。天下難事，必作於易；天下大事，必作於細……千里之行始於足下。 」

———《老子》

我們都熟悉恐懼和它帶來的感覺。然而在適當情況下，恐懼確實是一種正面情緒。它警告我們迫在眉梢的危險，讓我們得以採取安全措施。

不幸地，我們往往在恐懼過後很久，仍然受其影響。因為恐懼會轉變為各種有害情緒，包括自卑、壓力，乃至於恐慌。當恐懼的魔爪深深扎進你的身體，你需要有意識地抒解恐懼感。下列三件事情可以幫助你。

首先，當你感到恐懼時，你必須承認它。留意相關的感覺，觀察它如何影響自己。很多人會在腹腔神經叢感受到恐懼。默默坐著；讓自己不带批判地去感受它。你產生活想法？恐懼傳遞了何種訊息？

對待自己的恐懼，就如同對待小孩一樣。如果 4 歲小孩哭著走到你面前說害怕妖怪，你會怎麼做？你會擁抱他，請他解釋自己害怕什麼。等他說完後，你向他保證，妖怪不是真的，運用愛與正面情緒安慰他。恐懼畢竟不是真實的東西。恐懼沒什麼，卻試圖想要成為什麼。恐懼只能顯露我們賦予它的力量。

回想你生命中最安全、最穩當、最受珍愛的感覺。記住當時的感覺。然後把負面感覺慢慢取代為記憶中的正面珍愛情緒。
