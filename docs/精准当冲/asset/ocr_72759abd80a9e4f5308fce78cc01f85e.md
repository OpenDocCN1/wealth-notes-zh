# 頭肩底型態

後文談到放空操作時，將討論一種頭肩頂的反轉型態，但現在我們先講解一個很重要的頭肩底型態。就結構來說，這種型態就如同人的頭部，以及左、右兩肩。

初學者往往不太容易辨識頭肩型態。關於這點，我想到小時候，母親曾給我看過的圖畫書。

她指著一張森林圖片問我：「你可以找到 12 隻猴子嗎？」我緊盯著圖片瞧著。最後，一隻又一隻地找到隱藏在森林裡的猴子。經過幾分鐘後，終於找到全部 12 隻猴子。

同樣地，交易者只要專心觀察走勢圖，終究可以找到頭肩型態。

# 新手筆記

+   1. 對於部位交易，我會在價格走勢圖與成交量中間增添一個面板，用以顯示隨機指標，運用多頭背離現象做為進場策略的一部分。一旦建立部位後，我運用 MACD 指標取代隨機指標，觀察 MACD 提供的賣出訊號。記住，對於價格波動劇烈的股票，隨機指標會喪失預測功能，因為指標讀數很容易進入超買區，並且停留在該處。
2. 底部有時呈現很淺的圓形，稱為「碟狀」。
3. 很多基金經理人會監控那些價格日線圖由 50 天移動平均與 200 天移動平均回升的股票。讀者如果發現某股票由上升狀態的 50 天移動平均反彈，同時展開向上突破，這種良機非常適合從事盤中或波段交易。
