# 反轉型態

下列反轉型態相當可靠，而且容易辨識。不論是長期或短期時間架構，交易者都必須能夠辨識價格反轉型態。當個股或大盤趨勢由多轉空或由空轉多時，你應該要知道何時結束既有部位，並根據後續趨勢建立新部位。

雙重底、杯狀帶柄、頭肩底等排列都屬於底部反轉型態。

如果想進一步瞭解價格型態，可以閱讀專門書籍。但剛學習交易時，不妨專心研究 2、3 種型態。保持單純。如此更容易賺錢，也更有趣。

# 雙重底型態

這是我偏愛的底部反轉型態之一，也是威力強大的反轉排列，經常出現在各種時間架構的走勢圖。雙重底如果再增添一個 V 狀底部，就成為三重底排列，威力更可觀。同理，三重底如果又增添一個 V 狀底，則四重底威力更大。記住，某下檔支撐接受該成功測試的次數愈多，所醞釀的力度愈強大
