# 順勢而為，鈔票自然隨之而來

美國人從小被教導要採取主動，不是被動因應，而是改變自己與環境的關係。如果不滿意房間的顏色，你就重新油漆；如果不滿意伴侶，你就更換伴侶；孩子如果行為不當，你就糾正他們。

股市就像一條河，你不能要求河流逆流，也不可能要求它呈現另一種顏色。你不能對它表達不滿，或要求它展現不同的行為。你只能控制自己，被動因應。

一旦抱持這種心態，你的目標是每天來到市場，以絕對客觀的態度對待市場，譬如說：

+   ▷ 你觀察市場，然後依據市場的狀況（而不是你希望的狀況）與其互動。

+   ▷ 你的內心異常平靜且自信滿滿，除了按照預定計畫行事之外，你不覺得有必要做任何事情。

+   ▷ 全然沒有恐懼、拒絕、錯誤的感覺。

+   ▷ 全神貫注，但又具備置身事外的客觀。

+   ▷ 市場一旦出現符合預定交易計畫的訊號，就斷然採取行動。

# 責任與尊重：對於成功的影響

身為專業玩家，交易過程採取的每項行動，你都必須負起全責。最致命的缺失是推卸責任、歸咎他人。交易如果不順利，你不能歸咎別人，甚至不該責怪自己。

可是你必須負責。市場沒有拿走你的錢，也沒有拿錢給你。你做了選擇，因此要接受選擇的結果。
