# 提升搶帽子獲利潛能

根據自己的交易風格，謹慎挑選一、兩種搶帽子架構，全
心研究，並針對這些架構進行交易。累積足夠經驗後，再慢慢增添其他架構。

實際進場前，先做風險／報酬分析。檢視日線圖、5 分鐘、15
分鐘走勢圖的上檔最近壓力，距離如果還不到 75 美分，就另外尋找其
他機會。高勝算的搶帽子機會，應該有更高的獲利潛能。

記得檢視盤中走勢圖的最近壓力水準，尤其是 5 分鐘和 15 分鐘
走勢圖的 200 期移動平均。這條均線如果位在價格上方而向下發展，
最好尋找其他機會。你有八千多支股票可供選擇。如果有勝算更高的
架構，為何要退而求其次呢？

持有搶帽子部位期間，如果看到標倉期貨趨勢突然反轉，你持有
的股票也跟進，怎麼辦？立即逃出市價單結束部位。或採用限價單，
賣單設定在最佳買賣報價下方 1、2 檔（買單設定在最佳賣出報價上
方 1、2 檔）。價格為何要設定得保守一些？如同前文談到的，因為
大家爭先恐後想出場，交易者需要預留一些緩衝。

否則的話，你可能必須撕裂心地不斷改價向下賣。如果沒有人
願意接手，出場價格可能往下跌 1、2 點，甚至更多。我有過太多這
類經驗，尤其是初學期間。所以從事搶帽子交易，尤其不能貪心，不
要想多爭取幾美分。這也是為什麼你必須趁著買進動能賣出，必須在
能夠出場的時候出場，不是在不得不出場的時候出場。最後，這也是
為什麼你需要有最靈敏的手腳，以及鋼鐵般的意志。

記住，市場內部指標如果告訴你，大盤市場呈現強勁的上升趨勢
或下降趨勢，你可以從事當沖交易，讓獲利部位持續發展。可是行情
