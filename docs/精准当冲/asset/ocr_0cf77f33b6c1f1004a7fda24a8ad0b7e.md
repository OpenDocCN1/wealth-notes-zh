# 進場之前決定停損位置

幾年前，我在一場講習會和某位學員談話，他的交易經常虧損，但仍樂此不疲。他拿出正在進行的一筆當沖交易和我討論。就我看來，這筆交易風險極高，我很自然就問：「你的停損設定在哪裡？」

他有點不太好意思地聳聳肩。我雖然蠻喜歡他，但根據經驗判斷，他根本沒有設定停損，所以這對於他的交易帳戶造成嚴重損失，就如同科羅拉多河切割大峽谷一樣。不幸地，我的猜測沒錯。這位年輕小伙子搞砸了交易帳戶，被迫重返過去的工作崗位。從那時開始，我就不斷看到此類案例，發現交易者很容易忽略風險管理。
