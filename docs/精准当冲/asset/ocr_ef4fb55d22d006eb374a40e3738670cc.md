交易者如果考慮採用直接下單交易平台，不妨評估下列要點：

+   1. 交易指令輸入系統能夠直接下單到所有主要交易所，且不僅透過單一電子通信網絡。就目前來說，那斯達克的市場第 2 級報價資訊總覽顯示的市場參與者數量最多。

+   2. 系統執行交易的速度如何？記住，速度是最重要的武器。快速執行能力可以幫你節省很多錢，尤其當你急著出場時。

+   3. 系統是否方便鍵盤操作？需要用鍵盤輸入交易指令嗎？最好採用按鍵方式。買進與賣出的勾選方塊是否夠清楚？學習使用電子系統已經夠難了，千萬不要再無謂添亂。我剛學習交易時，偶爾會搞混買進與賣出。

+   4. 系統是否穩定、可靠？當機的情況有多普遍？你與市場的連結將因此被切斷。這點很重要，因為市場女神有著非常奇特的幽默感：就在你抱滿價格波動最劇烈的半導體股票時，某個壞心腸分析師剛好調降半導體產業評等，而在半導體股票行情崩跌的過程，你的系統也當機！不要輕易放過系統的業務代表：這套系統究竟有多少人使用？萬一發生問題時，方便透過電話聯絡嗎？系
