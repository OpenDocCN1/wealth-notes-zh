# 培育頂尖交易者思維

# 我們彼此相互連結

> 「我們曾經駐足片刻，彼此相遇、相愛、分享。這個時刻稍縱即逝，卻是永恆的小插曲。我們如果能夠分享關懷、無憂無慮與愛。我們將為彼此創造豐頌與愉悅。然後，我們會懷念這個時刻。」

——狄帕克·喬布拉

《人生成敗的靈性7法：讓一生圓融無遺憾的關鍵法則》

環繞地球的太空人在接受訪問時，大多表示從如此壯觀的角度觀察如此精緻的世界，說服他們相信有個神聖宇宙心靈在運作著。

科學家告訴我們，地球在數十億年前由恆星碎片形成。從宇宙塵埃聚集而萌發生命。太陽溫暖了地球，然後單細胞植物與動物奠定了後續一系列演進的基礎。

你和我是這個演化過程的重要構成部分之一。我們的生命是這個延伸到未來之更大鏈條的重要環節。

我們慶祝生日時，實際上是慶祝自己從上次生日以來，又參與了地球繞太陽公轉一週。我們是地球生命的一部分，就如同細胞是我們身體的一部分。

我們如果拓展思維，就能體認自己和鄰人都是為了履行更大的任務而展現的生命本身，我們彼此相互關連。雖然我們有不同的信仰、膚色與文化背景，但每個人都源自於孕育所有生命的智慧和能量。這
