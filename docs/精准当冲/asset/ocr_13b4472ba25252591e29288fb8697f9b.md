# ## 承諾的力量

> 「除非有所承諾，否則你就會心存遲疑、退縮，導致行動無效。所有倡議（與創造）行動都蘊含一項基本真理，如果無視這項真理，將扼殺無數創意與優秀計畫：人們一旦明確許下承諾，老天爺也會動容。藉由這個決定，一連串事件將接踵而來，包括各種不可預見的事件、巧合與物資協助。」

威廉．哈欽森．穆雷（William Hutchinson Murray）

如果你針對某個特定目標全心投入，將釀釀某種積極力量去達成該目標，正如同「鎖定」目標的飛彈一樣，不論目標如何移動，飛彈都會自動追蹤。

承諾也會誘發令人興奮的機會，明顯改變自己的人生。

各位或許察覺成功人士總是具備某些特質：他們未必定是最優秀、聰明的人，也未必是反應最靈敏或最強壯的人。可是，他們永遠都會做那些足以讓自己成功的事情。

沒有承諾的目標會演變為虛無縹緲的東西，通常因旁觀者缺乏興趣，導致半途而廢。只有當我們完全致力於特定夢想，才能最大限度證明自己的存在。

承諾需要設定明確、可行、積極的目標；其次，宣布自己打算實現這個目標，同時認定此目標已成為生活的一部分。如果你內心深處秉持堅定的信念，就能克服前進道路上的任何障礙，帶領自己邁向目標。
