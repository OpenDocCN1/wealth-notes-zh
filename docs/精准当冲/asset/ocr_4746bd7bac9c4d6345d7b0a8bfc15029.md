# 謝詞

這幾個月來，我第一次鬆口氣。感覺很棒！不久前，我完成第一本著作《精準當沖》的第二版修正（另外兩本著作分別為《短線交易初學指南》〔A Beginner's Guide to Short-Term Trading〕與《新股市短線交易》〔Short-Term Trading in the New Stock Market〕）。

就寫作來說，本書是我的第一胎，對我的人生具有非凡的意義。

就如同養育小孩一樣，本書不免牽連到許多人。

本書得以完成，有賴許多人的貢獻，我想借此機會致意，感謝他們在過程中給予協助。
