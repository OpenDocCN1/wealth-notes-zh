# **情節 6：行情反覆**

你從事當沖交易，看到大盤走勢強勁、個股走勢強勁，於是你找到絕佳買進點進場。股價先是走高，然後停頓。差勁！

行情出現反向走勢。股價指數期貨下跌，TICK 讀數下滑，可是……TRIN 讀數仍然偏低。很好。你決定繼續持有部位，嘴裡喃喃自語：「TRIN 決定結果。」

期貨價格突然大跌，TICK 跟進。老天，怎麼回事。股價指數與某些技術指標雖然下滑，但 TRIN 仍然相對低檔，還不到 0.8。

買進報價隊列的造市者陸續消失。你的股票跌破下檔最近支撐，甚至穿越你的停損。麻煩了。可是，支撐畢竟是個「區域」，不是嗎？很多專家都這麼說。實際認賠前，你決定再通融 20 美分的緩衝。

買進報價很快向下跳動 20 美分。就在你準備送出賣單前，股價反彈了 25 美分。還好，差一點。

可是不到幾秒鐘，行情又恢復跌勢。TRIN 稍微走高，其他技術指標慢慢跌破支撐。跌勢進行得相當緩慢，像是凌遲。這是拉回走勢，對吧？價格畢竟不可能直線上漲。漲勢總是夾雜著折返。

股價下跌，每支陰線都夾著大量。夠了！你咬緊牙關認賠。倒槌透頂。

突然間，你想要報復。這支混蛋股票如果要下跌，或許可以放空。反正總是要從這支股票撈回一點。等待價格反彈（反彈過程才容易掌握價格向上跳動的空頭機會），你放空了 500 股，停損設在反彈高點上方 25 美分。就是如此了。
