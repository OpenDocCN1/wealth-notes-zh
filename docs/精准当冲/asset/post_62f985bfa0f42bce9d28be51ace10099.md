
與者難以捉摸的群眾心理。一會能源類股當紅，一會零售類股失寵；這會房屋類股價值高估，那會黃金類股價值低估。

你認為微軟股價不合理？太不幸了。隨便你怎麼想。你認為自己持有的小型股價值應該向上翻一倍，實際上卻被腰斬。你喃喃自語：「不公平。」市場根本不知道你怎麼想，也完全不在意公平不公平。

你所想像、期待、希望、相信的事情，對於股市都不會造成任何影響。身為交易者，如果發現並攫取市場機會，你會受到歡迎；如果讓機會從指尖溜掉，市場則會吞噬它們，頂多打個哈欠。市場根本不在意任何藉口、抱怨或感謝。

馬克·道格拉斯（Mark Douglas）在《紀律的交易者：培養贏的態度》（*The Disciplined Trader*）書中提到：「此處要強調的重點，是你一向認為正確與錯誤的概念，並不存在於市場。」

如同市場永遠正確一樣，股價也永遠正確。我們按照某價格買賣股票，理由很可能偏頗、不合理、古怪或瘋狂。交易行為可能受到恐懼或貪婪情緒愚弄，或受到滿月影響。這一切都無關緊要。股價永遠正確，至少當時是如此。

你或許認為，交易者可以藉由大額買賣行為，影響價格走勢。沒錯，確實可以，你可以短暫影響一、兩檔價格跳動，但除非你是不可一世的大富豪，否則不可能真正影響股價走勢。其他的力量遲早會接手，不論是否受到你的支持，股價走視取決於所有市場參與者的集體心態。

身處這個環境要如何求生存，甚至成功？面對價格波動的市場，你尋找其中的機會。你評估各種機會蘊含的風險與報酬關係，尋找那些值得交易資本承擔風險的賺錢機會。

不妨把股市視為水果攤。你造訪水果攤，觀察攤子擺放的各種水果。水果如果已經成熟，就買來享受；水果如果已經腐敗，或者價格過高，你就離開，鈔票仍然擺在自家口袋裡。

務必記住兩句話：市場永遠正確，價格永遠正確。這兩句話所蘊含或試圖培養的心態，對於交易成功至關重要。

# 交易者的最大敵人

金融交易最常聽到的另一種說法是：「交易像戰爭。」這種說法完全正確！想獲得勝利，你需要知道敵人是誰，然後抱著必勝的心態參與戰爭。我的願望是協助各位達到交易者得以生存和成功的境界。

首先，我要讓各位看清楚交易者的最大敵人是誰。我想各位已經猜到了：情緒。

身為交易者，掌握技術分析的每個細微環節並不難；配備最先進的電腦；安裝最精密、最快速的軟體與第 2 級報價系統；計算自己的技術指標。可是，你仍然可能嚴重虧損。因為你讓最致命的敵人控制自己的交易：情緒。

學習在交易過程控制情緒，這可能是你需要跨越的最大障礙。

《紀律的交易者》書裡，馬克·道格拉斯曾說：「致勝的交易者被詢問成功祕訣時，他們一致強調，如果沒有學會自律規範、情緒控制，並隨著行情脈動而調整交易方向，就不可能穩定累積財富。」

我可以肯定告訴各位，當我能夠在毫無情緒波瀾的情況下，心平氣和地進行交易，就是我身為成功交易者的一天。

在此之前，我可以精準判讀技術分析走勢圖、成功解析市場互動關係、靈活運用各種技術指標和擺盪指標，同時採用最先進的交易平台與第 2 級報價資訊，卻還是遭逢嚴重虧損。

直到我可以根據自己的判斷進行交易，而且完全不受情緒干擾，此刻起，我才開始穩定賺錢。

我深深訝異自己當時的感受。我並沒有就這方面做積極的安排，虽然我早就期待自己能夠如此！有什麼特別的感受？好像自家庭部發生了重大位移。打從一開始進行交易以來，經過了多久才出現這種感覺？一年。為什麼需要這麼久呢？因為要磨練自己成為冷酷無情的計算機器，我必須克服最核心的某種人性成分——情緒。

各位在大學如果修過心理學，你可能還記得一個基本前提：思緒加上感覺等於行動。人類就是這樣運作的。如果嘗試消除其中某個要素，不難理解相關的難處。

首先，讓我們考慮以下的情境：思緒加上感覺，但沒有行動——尤其是涉及愉悅的行動。

思緒：我忙了一整天，晚飯後想喝啤酒。自然而然地，你想到冒著泡沫的黃金液體。

感覺：愉悅。嘴巴的味蕾似乎能夠感受到涼爽、清新、扎實的飲料口感。

行動：是的，我要來罐啤酒。你打開冰箱卻看不到啤酒。可惡！

現在，預期產生的愉悅變成懊惱。思緒加上感覺，卻沒有產生預期的行為。

自然行為發生前，也會有對應的思緒和感覺，雖然出現得很短暫，譬如：坐下來、踩煞車、親吻愛人等。

對於這個因果關係，你不能排除思緒；任何感覺或行動都來自於思緒。與生俱來的感覺告訴我們，如果根據某種思緒採取行動，將產生愉悅或危險。因此感覺或多或少會控制我們的行動。想要控制這些感覺，需要異乎尋常的決心與意志。

人性自然會追求愉悅，就當沖交易來說，這意味著令人刺激、興奮的快感，感覺自己「即將發財」、「我對於這支股票的判斷完全正確」，一種自我實現的滿足。一筆交易若能獲致成功，就如同中了彩券，不僅能夠賺進大把鈔票，還可以向親朋好友吹噓。這給人一種置身世界巔峰的感覺。

交易的情況可能如下。思緒：嘿！看看雅虎股票走勢，感覺像是不錯的機會。接下來，根據當時情況，你會出現下列情緒：

- **刺激**：哇！看看雅虎股價怎麼上漲的。全世界似乎都搶著買進。他們必定知道某些我不知道的事。我最好趁著還有機會的時候趕快買進！下單，進場。
- **興奮**：我就知道……雅虎股價會直上九霄雲外，我一定要搭上這個轎子！我要駕著小貨車把鈔票運到銀行戶頭裡。下單，進場。
- **迫不及待**：等我一下，鮮紅的小跑車。是的，寶貝，我馬上就要把你開回家。雅虎會幫我賺大錢。下單，進場。

不幸的是，我所認識的成功交易者，幾乎都不會出現這類情緒。反之，同樣不幸的是，凡是具有這類情緒的交易者，多數是失敗者。

拜託，請不要誤解我的意思，每當完成一筆好交易，我確實有滿足的感覺，我會拍拍自己的背。每天交易結束，我對於自己來到市場，然後帶著成果返家，感到揚眉吐氣。

第二天早晨，寫滿情緒的小黑板已經擦乾淨。新的一天，新的市場，新的開始。

對於真正的玩家來說，前述雅虎情節可能如下：

- **思考**：根據既定的交易計畫，這是買進雅虎的進場點。迅速評估其他市況。很好，所有系統都顯示啟動。
- **感覺**：平靜、自信、沉穩。
- **行動**：下單、買進。

想成為成功的交易者，刺激與興奮的感覺必須留給其他人，你只能平靜、客觀地執行交易。唯有在市場收盤後，你才會感受到激情——當你計算當天的收穫與成果時。

下面篇幅將討論成功交易者不希望涉及的情緒。

# 混淆

交易新手經常處於混淆狀態。不過，這一點並不奇怪。

這就如同學習滑雪。你覺得寒冷、笨拙，相關裝備對你來說，仍然顯得神秘無比。你做出一連串需要頭腦與身體協調的動作，結果跌倒在滑溜的冰面上。可是，這樣好像還不夠，你嚇得不知所措。

剛學習交易時，對你來說，市場走勢顯得異常神秘。你完全沒有經驗，無法體會各種市場走勢的可能徵兆。你想藉由電腦進行交易，不論是網路券商或直接下單券商也好，但不知道接下來應該按哪個鍵。股價突然上漲，然後又下跌，好像全然沒有理由，你覺得自己落後別人十幾步。聽說每筆交易背後，都隱藏著「這個行業裡最頂尖的玩家」，他們隨時準備奪走你的錢。雖然不願承認，但你真的很害怕。幾年前，剛從事交易時，我的雙手顫抖，滿腦子一團亂，有時候誤把買進當成賣出，反之亦然。有一次，我透過網路送出交易指令，網路經紀人打電話過來：「透納女士，妳持有 300 股伊古魯冰淇淋，卻要賣出 600 股。真是這樣嗎？」

我嚇了一跳：「喔，不，我是想賣出 300 股。我賣了兩次嗎？對不起。」

或者：「透納女士，妳下單買進 5,000 股 TT 卡車運輸。如此一來，妳的保證金帳戶餘額將不足 20,000 美元。妳真的要這麼做嗎？」

老天！「5,000 股？保證金不足 20,000 美元？不，我要買進 500 股，不小心多按了一個 0。很抱歉。」

很幸運地，累積一些經驗後，就可以減少這方面的混淆，但在此之前，仍然可能發生大災難。為了避免浪費時間和金錢，務必及早採取必要的防範措施。

# 防範混淆的最佳措施

1. 剛從事交易時，每筆交易規模不要太大，譬如 100 股，最好不要超過 300 股。如此一來，萬一股價下跌，或不小心買多了，還不至於造成不可收拾的災難。
2. 完成一筆交易之前，不要進行另一筆交易。對於變動快速的股市來說，每次進行一筆交易就夠了。你大可不必擔心錯失機會，股市從來不缺機會，前提是你必須有資金可供交易。
3. 先做紙上模擬交易，直到你覺得準備妥當，可以進行實際交易。
4. 務必摸熟使用的系統，尤其是新的券商系統，然後才可以實際進行交易。
5. 任何時候僅學習一種策略，而且僅利用該策略進行交易。
6. 除非已經累積足夠的經驗，否則不要同時進行不同時間架構的交易，譬如先進行一筆當沖交易，部位還沒有平倉前，又進行另一筆動能交易。同時進行不同時間架構的交易，情況往往很混亂，尤其是碰到行情快速變動時，風險太高。

# 堅持自己的判斷正確

我認識的初學者幾乎都有這種毛病，他們相當堅持自己所做的行情判斷；換言之，他們希望自己對於行情的判斷正確，而且態度相當堅持。這種心態往往會造成重大虧損。

請注意，希望自己正確，等於害怕自己犯錯。一般人的成長過程，都深刻體會行為正確的重要性。那些犯錯的人，就代表失敗者或輸家。成功者或勝利者永遠正確。一般人自然希望是成功者、勝利者。

問題在於：正確往往只是幻覺。我們做出選擇，然後據以行動。某種選擇產生一種結果，另一種選擇又產生另一種結果。

在交易過程中，堅持自己判斷正確的態度，可能造成不必要的嚴重虧損。舉例來說，A 交易者買進 500 股 TT 卡車運輸股票，價格為 52 美元，進場點拿捏得相當好。過不了幾分鐘，股價跌到 50.85 美元而觸發他設定的停損。可是，A 交易者不僅沒有斷然認賠，反而咬緊牙關堅持：「我才不要認賠，TT 卡車運輸是支好股票，剛宣布很不錯的盈餘績效。這筆交易最終會賺錢，我知道自己的判斷正確。」

TT 卡車運輸股價繼續下跌，來到 45 美元，然後是 40 美元，A 交易者繼續持有。現在，他如果賣出，虧損將嚴重損害其交易帳戶，還有自家顏面。他已經不是交易者。他變成投資人——這也是用來安慰失敗交易部位的名詞。如果有朋友問 A 交易者為何繼續持有股票，他會抬頭挺胸地說：「這是一家好公司，股價還會漲回來。」

股價或許會漲回來，但起碼有很長一段時間不會漲。另外，損失就是損失，不論帳面損失或實際損失都一樣，即使有一天 TT 卡車運輸股價漲到 52 美元，可能也需要數週或數月時間。這段期間，A 交易者原本可以運用相關資金進行其他交易。堅持自己判斷正確的心態，讓他承擔沉重代價。

# 如何糾正這種心態？

1. 練習聳肩說：「我不知道。」很簡單，也很有趣，不過確實有效。這種態度可以整治自己必須正確的症候，幫你省下許多錢。聽聽吉姆·羅傑斯在 CNBC 怎麼說。主持人問他有關金融市場的後續發展，這位世界級富豪聳肩笑笑，然後回答：「完全沒概念。」
2. 你如果打算置身這個行業，務必幫自己一個忙：進行任何交易時，不要堅持結果必須如何，不要認定行情一定朝哪個方向發展，也不要對公平有任何幻想。如此一來，你就不必堅持自己的判斷必須正確。
3. 交易前必須擬定計畫，然後按照計畫進行交易。這個議題稍後詳細討論，各位現在只需知道，交易必須預設明確的進場點、出場點，防禦性停損，這是糾正判斷必須正確的最有效方法。完全按照計畫行事，可以限制交易所承擔的風險，有效控制虧損，保留獲利潛能。
4. 不要因為犯下愚蠢的錯誤而自責。嚴格要求自己必須正確，將妨礙交易生涯，因為這會讓我不敢嘗試下次機會。另外，這種態度也會損害自我意識，讓我更難進入平靜、自信的交易境界。你是做出選擇，而非故意犯錯。不同的選擇本來就會產生不同的結果，但每個結果都是一種學習經驗。不論成功或失敗，試著研究每筆交易背後的想法、選擇以及結果，從結果中學習。

# 貪婪

貪婪經常是促使初學者從事交易的動機，甚至許多經驗老到的交易者也是如此。如同本書第 2 章所解釋：「牛（多頭）能賺錢，熊（空頭）能賺錢，豬（貪心）則被宰殺。」

市場就是知道那些基於貪婪心理而進行的交易。每當聽到有人說：「我把整個家當都押進去，因為某支股票會翻幾倍。」這經常成為他們的最後一筆交易。

追價行為往往源自貪婪心理，這容易讓你買在整個走勢的頭部，或賣在底部！

# 克服貪婪心理

1. 身為初學者，為了減少風險，你決定進行小規模交易。這個決定可以幫你克服「愈多愈好」的念頭。
2. 報價螢幕上，看到某支股票價格直線飆漲，你會產生一種眼進的衝動，請務必克制自己。去冰箱拿瓶飲料，或是和狗玩一玩。如果必要的話，暫時出門走一走，就是不要碰觸滑鼠。如果你堅持看後續發展，不妨留意買盤消失而賣壓湧現後，股價會怎麼下跌。最好讓別人承受後果，而不是你。

# 恐懼

對於交易者來說，恐懼是最致命的情緒。恐懼有不同程度，由稍微憂慮，乃至撕心裂肺的害怕。恐懼對於交易者造成的傷害，遠超過任何情緒。

事實：如果真的想達成什麼目標，恐懼根本無關緊要。

小孩子總是害怕黑暗；孩童時期，晚上睡覺時，你害怕怪物躲在床下，心臟砰砰跳，口乾舌燥，全身冒汗，身體捲成蝦子狀，等著怪物來抓你。

當然，床底下並沒有怪物。可是，恐懼的感覺非常真實；長大後，你知道怪物並不存在，種種感覺都是自己想像出來的。

對於初學者來說，恐懼有許多不同層面，從溫和到嚴重：

- **驚慌**：你正確地建立某個部位，然後看到標普期貨暴跌。你的股票會跟著下跌嗎？
- **驚恐與挫折**：網路斷線，你持有未平倉部位。
- **害怕**：每隔幾秒，你的股票就下跌 1 點，卻找不到接手的買盤。
- **恐慌**：你持有隔夜部位，開盤價格暴跌 8 點（沒錯，確實會發生這種情況）。

害怕虧損讓你看不清楚實際狀況，不是提早結束成功交易，就是繼續持有失敗部位。

# 取代恐懼心理

如何克服恐懼心理？不，你不能克服恐懼，你要取代恐懼心理。

如同烏鴉用石頭取代瓶中水一樣，你可以用正面的東西，像是知識、經驗與自信等去取代恐懼。這些都環環相扣，創造一種共生關係。

首先，運用知識取代恐懼。多數初學者會汲取某種程度的知識，然後就停止學習。可是，他們繼續從事交易，不斷犯下相同的錯誤，直到不堪虧損為止。

我記得有位初學者，他參加某個為期 3 天的課程，然後就一頭栽進市場，開始做交易，買進任何會動的股票達數千股。我曾經警告他，他具備的知識不足以管理如此龐大的部位，他相當不以為然地回答：「我已經懂得夠多了。我不認為股票交易有太多東西值得學習。」我們不難猜想他的結果。

我可以跟各位承諾，即使你研究交易藝術直到眼睛脫窗，所知仍然有限。閱讀你有機會接觸的任何交易書籍，不論認同其方法與否；研究股價走勢圖，直到筋疲力盡為止；記錄交易日誌，記錄每天交易給你的啟示；聽到 CNBC 節目提到某些你過去不懂的概念或專有名稱，也記錄在交易日誌內；想辦法每天都學習一項新概念。

其次，用經驗取代恐懼。經驗可以強化你所學習的知識，並彙整為強大的交易武器。經驗還可以幫助你瞭解如何掌握市場與股票脈動，告訴你最適合自家個性的交易風格，以及協助判斷哪些技巧有用，哪些沒用。你將發現自己與其他交易者如何因應某些市況，並且知道最好的獲利和逃脫辦法。

隨著知識與經驗累積，你慢慢培養出一種無價的態度：自信。等到你能夠自信滿滿地進行每筆交易，就不會再感到恐懼，並在交易過程保持沉穩的態度。這時除非你故態重萌，否則市場再也不能傷害你。這種自信讓你覺得自己能夠全然控制交易，你成為真正的交易者。

# 為何要擱置信念與希望？

孩提時期，大人教我們要保持信念和希望。這兩種特質可以讓人生各個層面更豐富，但交易卻是例外。每天踏進交易所前，你應該放下信念與希望。

信念：我知道自己應該結束這個部位，但我還是要抱牢，直到扳回虧損為止。市場存在上漲的偏頗，不是嗎？再過幾天，一切都沒問題。

希望：（對於交易之神的祈禱）「拜託，拜託這支股票不要再跌了。拜託你協助我在虧損更嚴重之前，及早結束這個部位。我發誓將來絕對不再違背交易法則！」

如果你發現自己喃喃唸著，「價格會漲回來」或「拜託上漲」，你就是抱著信念和希望的情緒進行交易。換言之，你沒辦法控制自己的交易。反之，交易控制了你了。

# 如何擺脫信念與希望

1. 如果發現自己產生有關信念和希望的情緒，就要立即警惕自己，重新評估交易，採取必要的行動。
2. 如果發現自己受到信念與希望的情緒影響，試圖持有失敗部位時，就應該斷然認賠。馬上承認的虧損，永遠是最小的虧損。
3. 記住，信念與希望的情緒讓你虧損。你禁不起這種虧損，代價太昂貴了。

# 為什麼所有的虧損都是「魔鬼」造成？

身為初學者，你逐漸熟悉自己的各種特性，某些特性協助你獲致成功，有些則需要受到控制。及早認清楚那些會影響交易的特性。對自己的認識愈清楚，對交易生涯的幫助愈大。

在交易過程中，你如果採取某種值得懷疑的行動，先問心自問：

> 「我為什麼這麼做？究竟是什麼特質促使我這麼做？」

答案若是「我太衝動」，再回頭想想自己是否習慣先採取行動，然後才思考？這可不是好習慣。你必須設法把「衝動」取代為「完全按照計畫進行交易」，並避免在行情波動劇烈時進行交易。

答案若是「我太樂觀」的話，你是否期待最好的情況？樂觀是信念與希望的孿生兄弟。有色的眼鏡會扭曲市場現實。

答案若是「我太頑固」的話，通常是堅持自己的判斷正確，這種心態也有礙交易。訓練自己把這種態度改為「臨機應變」與「順勢而為」，並瞭解市況發展隨時可能反轉。撇開頑固的心態，才能擬定成功的決策。

# 有利於交易的特質

你是否有追求完美的特質？這種特質往往讓周遭的人為之瘋狂，某個角度來說，也有助於提升交易績效（這種特質可能導致焦慮，所以不要對自己要求過多）。

你做事是否有條不紊？遇事泰然自若？不心存主觀偏見？如果是這樣，那就太好了，請繼續保持。

你是否信賴直覺？憑著直覺或第六感進行交易，其實不大可靠，很有可能招致麻煩。如果搭配知識與經驗，直覺就會變成交易的助力。

我相信交易中的直覺，或者你寧可稱之為神經質。對我來說，這種直覺很可靠。例如，所有市場指標都顯示應該進場，但基於某種看不見的理由，也就是直覺，我總是覺得不對勁，像缺少了某種東西。碰到這種情況，原本明確的趨勢，十之八九都會反轉。根據我的經驗，必須相信直覺。經過一陣子後，各位可能也會有類似的直覺。

# 面對現實：股市呈現什麼顏色？

交易最具挑戰性的能力，就是客觀判斷大盤市場或個股的情況究竟如何，而不是你認為它們會如何。每個人對特定客體都有自己的感知，這些感知可能截然不同。換言之，每個人的感知都不免受到過去經驗的影響。

對於當前市場，你可能認為充滿獲利機會，而坐在你隔壁的交易者可能覺得充滿危機。真相究竟如何？你們兩個可能都正確。市場原本就是你認為的情況。

你如何感受市場？機會無窮？步步危機？花點時間琢磨看看。你必須誠實回答這個問題，因為你對於市場的感知，將決定自己的交易生涯結局。
