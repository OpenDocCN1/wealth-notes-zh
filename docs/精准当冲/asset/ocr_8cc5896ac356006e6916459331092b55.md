# 多頭與空頭吞嚥型態的特質

+   - 相關股票當時必須處在明確的下降或上升趨勢，包括短期趨勢在內。

+   - 型態由 2 支線形構成，顏色彼此相反。

+   - 第 2 支線形實體必須吞噬（吃掉）第 1 支線形實體，雖然不必吞噬影線。如果第 1 支線形實體很小，第 2 支線形實體很長，則型態反轉的意涵更明確。

+   - 第 2 支線形除了吞噬第 1 支線形之外，如果還吞噬更早一支線形，則反轉訊號更明確。
