# ### 健康的自私

「 你想成為世界強者嗎？那就做自己。忠於你至高無上的靈魂，不允許自己受制於任何不符原則之習俗、慣例或人為武斷法則的支配。」

——拉爾夫·瓦爾多·愛默生（Ralph Waldo Emerson）

想瞭解自己，需要花費時間和努力。那些相信花時間琢磨內在成長是自私行為的人，可能需要重新檢視這個想法。

為了達到平衡、獲取真正的力量，我們必須兼走在和外在的道路。任何單一道路都不能帶領我們到達目的地。內在道路最難行，因為這是自我認知與發展意識的道路。

過去兩個世紀以來，我們探索、開拓了外部世界領域。我們剖析原子，研究其中奧祕。我們發明許多新奇玩意、機器和電腦網絡，使生活現代化。我們登上月球，運送照相機與望遠鏡去探索遙遠的星球。哈佛望遠鏡揭露的宇宙，遠較我們瞭解的更古老、龐大。事實上，我們發現把時間用在研究外部世界，顯然是相當值得的。

可是，我們卻很少探索另一個領域，也就是獨特的自我內心世界。

對於周遭的人來說，花費時間思考與研究自我情緒、信念和個人目標的行為看似自私。但花費時間探索自我潛能的人，真是自私的嗎？嘗試瞭解自我能力、發現自己最高潛能的人，真是自私的嗎？深入體認生命意義，並從自我意識中獲得滿足，這種行為是自私的嗎？
