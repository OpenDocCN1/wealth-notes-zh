如果大幅震盪，這時或許只適合搶帽子——甚至更適合洗車。有所疑惑，就留在場外觀望。

# ## 搶帽子交易的核對事項

以下列舉搶帽子交易的核對事項。初學者不妨列印這部分內容，隨時參考，直到成為習慣為止。如果發現任何需要增添的事項，請自行增加。

# ### 搶帽子交易核對事項

+   1. 符合由上而下的交易準則（大盤市場紐約證交所或那斯達克，股票所屬產業，TICK，TRIN，標普期貨 E 迷你契約，那斯達克 100 期貨等趨勢；你需要這些指標呈現上升趨勢，或下降趨勢）。

+   2. 日線圖或盤中走勢圖的壓力（包括移動平均或上檔密集交易區）不會造成立即的妨礙。

+   3. 盤中走勢圖呈狹幅橫向盤整，絕大多數線形收盤價逼近高價。

+   4. 價量配合；大量向上突破。

+   5. 第 2 級報價資訊：最佳買進—賣出報價的碼差不超過 3 美分。

+   6. 最佳買進報價存在足夠深度——至少有 4 個專業報價商或造市者。

+   7. 買單吃掉賣出報價。
