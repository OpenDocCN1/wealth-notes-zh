適合挑選當沖、動能交易與「搶帽子」。

具有鋼鐵般意志與超人能力的經驗老到交易者，可以扮演最勝任的動能交易者。他們一隻眼睛盯著一連串技術指標，另一隻眼睛則盯著股價走勢圖和第 2 級報價螢幕。股價走勢只要稍有不對勁，他們就出場。

動能交易者或帽客如果沒有預先設定停損，可能連上廁所或喝杯咖啡的時間都沒有，甚至不能和旁人講話。如果你喜歡交際，餓的時候就想吃東西，或缺少駱駝般的膀胱，最好還是把這類交易留給更勝任的人。

身為初學者，你最好先學會如何操作波段交易和當沖，然後才考慮如何搶帽子。否則的話，你恐怕搶不到帽子，只能搶到天上掉下來的刀子。

# 大盤各時段特色

市場是無限的，沒有明確結構，也沒有時間性，但每個交易時段在某種程度內都各自具備固定特色。某種程度內是此處重點。市場隨著時間進入某個時段而呈現特定的反轉和變動，但這種特色也落入「某某現象總如此，除非不是如此」的範疇。以下敘述皆以東部標準時間為準：

+   - 上午 9:30：股市開盤。

+   - 上午 9:45~10:10：第一個反轉期。

+   - 上午 11:20：午休開始（交易沉悶）。

+   - 下午 1:30：午休即將結束，某些股票交投轉趨活絡。

+   - 下午 2:30：股票出現比較明確的突破（向上或向下）。
