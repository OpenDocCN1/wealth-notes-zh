# 買進架構 2：圖 10-9

同樣地，尋找一处處於上升趨勢的標的股。昨天走勢呈現正面發展，日線圖價格幾乎以最高價收盤。收盤期間最好呈現整理。

今天，開盤價與昨天收盤價大致相當，或許稍微開高。在上午 9:45～10:15 的反轉期，5 分鐘走勢圖夾著小量下跌，向下跌試前一天的支撐（跌幅不得超過 1.5%）。然後，出現一支觸底小線形，顯示下降走勢可能即將反轉。次一支線形確實向上反轉。當反轉線形超越觸底線形 1～10 美分位置（不要追價），進場建立多頭部位。停損設在進場點下方 10～40 美分處（做必要的調整）。價格一旦穿越開盤初期的高價，停損就向上做調整。

圖 10-10 顯示 Monster Worldwide, Inc.（MNST）的 5 分鐘走勢圖，顯示買進架構 2 的運作。由於這屬於中等程度的架構，等到走勢動能轉弱，我就結束部位。

請記住，所有這些架構都必須滿足由上而下的交易準則。
