# 新手隨堂考

# ## 題目

+   01. 處於強勁上升趨勢的股票，有價漲量增、價跌量縮的現象。正確或錯誤。

+   02. 有效的向上突破，需要大成交量配合嗎？為什麼？

+   03. 股票夾著大成交量向上突破，不過成交量在價格拉回過程仍然很大。這是什麼意思？

+   04. 股票交易（當沖或波段交易）對象，每天平均成交量少於 10 萬股，這種情況合適嗎？為什麼？

+   05. 移動平均代表重要的支撐與壓力。正確或錯誤？

+   06. 對於當沖交易，你考慮的股票 5 分鐘走勢圖，顯示股價正處於 20 期移動平均附近，但上檔緊靠著 200 期移動平均。這種情況下，是否適合建立多頭部位？理由何在？

+   07. 某股票呈現橫向區間走勢。20 期移動平均呈現水平狀發展。這種情況下，移動平均提供的資訊是否值得參考？

+   08. 隨機指標、CCI 與 MACD 為何是有效的決策輔助工具？
