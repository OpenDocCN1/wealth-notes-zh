犯下的錯誤。某些交易者會買進任何會動的東西，而不是等待適當機會，甚至在午休時段（機會不多）也積極交易，或逆勢交易。他們就是手癢難耐。虧損加上佣金，老天！

+   - 秉持務實心態。記住，只要建立部位，馬上就會虧損（佣金成本），你必須先扳回這部分損失，才有機會賺錢。往來券商的 · 情況則不同，無論你的交易輸或贏，他們都會賺錢。如果從事融資（保證金）交易，傷口會更深：你還必須支付利息。

但願以上針對滑價與佣金的討論，能夠讓各位更清醒一些，不要過度交易、追價，也不要秉持不切實際的預期。做個謹慎、睿智的交易者，唯有如此，你才有機會擊敗市場，在逆境求勝。

# 保證金交易（融資／融券交易）
