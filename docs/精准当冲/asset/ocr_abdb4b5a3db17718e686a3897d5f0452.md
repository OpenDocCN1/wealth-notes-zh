傲慢或自以爲是，而是自信。

你是否剛和親密伴侶分手？是否和某個最親密的人吵架？是否有家人正罹患重大疾病？你是否擔心孩子單獨在家？

你是否罹患感冒？昨天是否發生嚴重交易虧損？是否感覺十分沮喪？

不論什麼緣故，只要感覺很差，就不要進行交易，否則很難不發生虧損。

# ### 應該遵循的交易法則

我知道的成功交易者，都把他們奉行的交易法則清單，貼在電腦螢幕附近。請各位也考慮這麼做。書面交易法則可以提醒我們隨時記得目標，以及行為準則；就心理效應來說，其功能如同書面停損一樣：內容明確，沒有討價還價的空間。不妨將它們視為自己的意識。當我們受到市場催眠，認為自己可以蒙混過關時，書面法則會帶領我們回到「核心」。

以下是我嚴格遵循的法則。各位如果願意的話，也可以採用它們，或做為某種形式的基準，並做必要的調整。把你的交易法則擺在隨時可以看到的地方。

# #### 務必嚴格奉行的交易法則

+   1. 永遠要保護交易資本。

+   2. 完全按照計畫進行交易，不要考慮賺錢與否。

+   3. 除非交易機會符合由上而下的交易法則，否則不進行交易。

+   4. 進行完整的風險／報酬分析後才進行交易。
