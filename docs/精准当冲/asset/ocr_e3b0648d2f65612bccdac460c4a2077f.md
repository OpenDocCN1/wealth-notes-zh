# # 過度狀態的交易

對於初學者來說，在過度狀態進行交易是一種常見的弊病，即使經驗老到的交易者也難以避免。我坦承自己有時不免如此。金融市場畢竟是龐然巨物，隨手可得的資訊浩瀚如海，整體規模幾乎無法想像。

想要跳脫過度狀態，並在清晰而冷靜的境界安身立命，就必須體認自己不可能知道或掌握市場隨時發生的每個細節。

明智策略：記住，你的時間與精力畢竟有限。想要有效地運用它們，必須根據自己的個性與風格，精選交易工具、時間架構、交易架構以及交易管理策略。試著專精某個領域，成為這個領域的真正專家。
