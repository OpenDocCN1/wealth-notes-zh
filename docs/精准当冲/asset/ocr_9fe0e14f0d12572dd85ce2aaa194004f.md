# 答案

+   01. 每筆交易是基於什麼動機而進行？將來如何提升交易績效？

+   02. 至少做部分獲利了結。

+   03. 行情發展通常相當沉悶。

+   04. 錯誤，錯誤，錯誤。

+   05. 最高。

+   06. 謠言，新聞。

+   07. 至少等待 2、3 天，讓市場充分消化相關新聞，如此才能更精確判斷未來價格行為。

+   08. 不，波動劇烈而沒有明確方向的市況，既不適合做多，也不適合放空。

+   09. 錯誤。真正值得生氣的，不是標的股票，而是你自己。交易一旦涉及憤怒情緒，只會徒然增添虧損。交易過程如果發現自己出現憤怒情緒，就應該盡快結束部位。出去走走，甚至當天不要再交易。情緒一旦變好，交易也跟著改善。

+   10. 股價遠超過移動平均。舉例來說，觀察日線圖，股價較 20 天移動平均高出好幾點。

+   11. 從事短線交易（波段交易、當沖或搶帽子），股票走勢由強轉弱。
