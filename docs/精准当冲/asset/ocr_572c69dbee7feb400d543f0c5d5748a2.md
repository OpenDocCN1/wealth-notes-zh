# 搶帽子技巧：及早進場

當今的帽客等不及價格向上突破。由於部位持有時間非常短暫，需要及早採取行動。為了運用最初的動能，帽客趁著股價還處於整理階段就提早進場。等到股價實際向上或向下突破時，他們可能加碼。另一些交易者可能趁著隨後的向上或向下突破而結束半數部位，動機也是運用當時的市場動能。實際上如何操作，取決於個別交易者。不論風格如何，目的都是盡快獲利了結。

美式足球接球員需要「好手」，而帽客需要的是「快手」。對於多頭部位，如果可以的話，你要在別人出價時買進、在他們要價時出貨，同時還需注意股市走勢發展。
