# 買進架構 3 : 圖 10-11

這種架構很容易辨識與操作，前提是需要下午盤的走勢配合。標的股處於長期上升趨勢。昨天的走勢不重要。今天的股價走勢強勁上漲，上檔潛能可觀，日線圖顯示目前價格附近沒有迫切的壓力。5 分鐘走勢圖早盤創新高價，午休時段稍微拉回整理，拉回幅度最好不要超過 50 美分，或不要超過 1.5%。

午休時段，價格在 20 期移動平均附近呈現幾乎直線狀的盤整。

下午 1:30 後，走勢可能呈現正面發展，價格逼近高價。等到所有的系統都發出「進場」訊號，股價向上突破，展開下午盤的漲勢。

午休時段即將結束，如果看到盤整發展出現大量，可以先建立少量部位，停損設定在盤整區低價。如果當時的股價在 20 期移動平均下方，或許應該等到收盤價站上 20 期移動平均才進場。價格一旦向上突破橫向盤整區，部位就可以加碼，並在當天收盤前結束部位。這類交易通常可以創造不錯的獲利。
