# 「如果……，則……」的心態模式：

# 協助各位提升到專業等級

各位可還記得，大學有門數學課程叫做「邏輯」？上這門課時會提到一個句型，透過數學方程式的邏輯推理去驗證其有效性。這個句型的前半句以「如果」開頭，後半句以「則」開頭。簡單說，如果前後句的陳述為真，則整句陳述為真；如果其中有錯誤或不確定，則整句陳述為假；如果前後句陳述都是錯的，當然整句也是假的。邏輯可以揭示真理，適可協助評估陳述，譬如政客演講。

各位的交易經驗累積得愈多，愈能發現各種市場現象之間的關係。交易者愈懂得如何有效運用這種關係，就愈能確保交易成功。

因此，交易者將學習「如果……，則……」的思考模式。「如果」可能代表某地緣政治事件、經濟報告或其他新聞事件發生，「則」代表前者造成的市場行為反應。「如果」某兩種指數或技術指標發生某種現象，「則」市場會有某種反應。「如果」是「因」，「則」是「果」。「如果」這件事情發生，「則」某個結果通常也會發生。

舉例來說，全球各地金融市場，按照某種時間順序開盤與收盤，彼此相互影響，就像骨牌效應一樣。如果亞洲市場開盤大跌，則歐洲、南美與美國市場也會受到負面影響。

所以本章很多內容，我偶爾會強調「如果……，則……」，碰到這種情況，讀者的思考也要進入這種模式。
