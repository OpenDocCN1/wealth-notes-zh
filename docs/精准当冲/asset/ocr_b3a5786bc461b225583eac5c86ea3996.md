+   你訂閱的新聞通訊社，如果提供盈餘預測服務（譬如：路透社或 Zacks），查閱它們的預測數據如何。這些預測雖然未必可靠，但起碼讓你知道專家或市場的看法為何。

+   標的股票如果是紐約證交所成分股，就要查閱道瓊與標普 500 日線圖走勢；如果是那斯達克掛牌股票，則查閱那斯達克綜合股價指數走勢。大盤指數會影響個股行為與走向。

+   你已經知道如何查閱市場內部指標，包括紐約證交所或那斯達克的 TICK 與 TRIN，還有標普期貨 E 迷你契約（TICK 應該呈現正數，TRIN 應該小於 1.0，期貨應該呈現上升趨勢）。

這些程序看起來或許繁瑣，但不用擔心，只要經過適當練習，就可以在短短幾秒內做好所有相關盤算。

# 市場類股

美國股市可以劃分為 12 種類股，所有產業都隸屬於這些類股，譬如：銀行、生化科技、半導體、黃金與白銀、汽車與卡車製造、航空公司等。

+   1. 金融（Financials）

+   2. 科技（Technology）

+   3. 醫療保健（Health Care）

+   4. 消費者循環（Consumer Cyclicals）

+   5. 消費者非循環（Consumer Non-cyclicals）

+   6. 工業（Industrials）

+   7. 能源（Engergy）

+   8. 通訊（Telecommunications）

+   9. 基本物料（Basic Materials）

+   10. 公用事業（Utilities）

+   11. 綜合（Conglomerates）

+   12. 運輸（Transportation）
