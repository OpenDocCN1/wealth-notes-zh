# ## 移動平均交叉

所謂的移動平均交叉，指較快速的短期均線向上或向下穿越較慢速的長期均線。舉例來說，20 天移動平均向下穿越 50 天移動平均（死亡交叉），或 50 天移動平均向上穿越 200 天移動平均（黃金交叉）。這類穿越訊號，代表價格可能朝短期均線移動的方向發展。

很多交易者運用移動平均交叉現象做為交易訊號。做為放空架構，我喜歡採用 20 天移動平均向下穿越 200 天移動平均。日線圖如果發現這種現象，且其他指標也給予確認，我就會立刻進場建立空頭部位。

直接下單的交易平台，譬如 RealTick 會針對移動平均穿越（交叉）現象提供警訊。這個便利的功能有助於建立和管理交易。

現在，各位已經成為移動平均專家，但還是要注意前文提到「某某現象總是……，除非不是如此」的情況。移動平均適用於趨勢明確的股票，如果股票呈現橫向發展，移動平均往往會反覆，缺乏預測功能。

圖 7-14 到圖 7-17 的案例，顯示股票與移動平均的關係。趨勢明確的股票，移動平均扮演有效的支撐與壓力功能。另外，之後觀察的所有走勢圖，幾乎都會運用這些關係，所以當各位讀完本書，對移動平均的運用應該很熟悉。
