# 施捨的奇蹟

> 「愛人者，人恆愛之；敬人者，人恆敬之。」

——孟子（西元前第3～4世紀）

你希望餘生是成功與富足的受惠者嗎？你可以辦到這點，如果你現在更願意慷慨施捨的話。

我們的世界透過因果律運作。沒有東西是靜止不動的。生命源源不絕，能量流經我們，然後流動於世界，最後又回到我們身上。你和配偶、老關、兒女與朋友之間的關係，不斷地在施捨與接受的圖圈中循環。

你的事業、健康、精神、家庭，甚至銀行帳戶，都需要施捨與接受之間的能量流動。如果你停止對生命某方面的施捨，不論是知識與熱忱、食物與休息、對內在和諧的追求、摯愛與培養、財務援助等，那部分的生命回報就很有限，因為你阻礙能量的流動與循環。如同河流一樣，能量必須流動，才能保持活力，否則就陷入停滯。

施捨與接受形成一個圖圈，而圖圈是沒有盡頭的。我們生命某個領域想要富足與成長，就需要秉持感激心態，慷慨施捨。

想要啟動循環程序，首先是施捨你最想獲得的東西。你希望有更多錢財嗎？盡你所能，心懷善念，不求回報。你希望得到更多關注和讚賞嗎？給予最誠摯的讚美，給別人意想不到的幫助。奉獻你的時間與關懷。
