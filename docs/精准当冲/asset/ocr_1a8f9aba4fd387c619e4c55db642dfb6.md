# # 強化個人信念

「個人潛能是無限的，立志要高遠，相信自己的能力、品味及判斷。設想並感知自己想要的形象，用熱情與勇氣強化這種形象。感受這種「新」的真實自我；時時刻刻心存偉大的期待，你的潛意識就會實現它們。」

——布莱恩·亚当斯（Brian Adams）

個人信念可以協助勾勒生命紋理，它通常伴隨著能量和行動，成為實現目標和夢想的強大力量。它幫助我們獲取內心深處的資源，並用這些資源來實現希望。

缺乏積極信念的人，就像飛機沒有機組人員和自動駕駛設備，只能過著毫無目標的日子，最終為生活所遺棄。

相信自己正邁向美好未來的人，對於自我能力充滿信心，發現人生旅途到處充滿機會。

建立自我信念是一種心靈的內在過程；不論你有意識或無意識，每一個信念都是從一個選擇開始。做出選擇後，不論積極或消極，它都會過濾你與外界的交流，並透過某種態度來改變你的看法。信念愈是根深蒂固，就愈難以改變。

信念是世上最強大的力量，大至全球，不同的信仰體系導致文化隔閡以及意識型態的衝突與戰爭；小至個人，信念反映在每天的日常生活中。
