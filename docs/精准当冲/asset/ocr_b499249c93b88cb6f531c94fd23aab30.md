+   ▷ 個別股票呈現強勁的上升趨勢（最好收在當天最高價附近）。

+   ▷ 個股透過向上突破而展開第一天或第二天漲勢（不是第三天）。

+   ▷ 建立小規模隔夜部位。這些股票如果在收盤前表現有問題，我就結束部位或縮小規模。

+   ▷ 所持有的股票如果開盤向上跳空，起碼就結束半數部位。

如果想培養自己持有隔夜部位的賺錢技巧，請放手去做。可是，你持有的隔夜部位如果容易吸引專業分析師調降評等，那就算了。

# 當沖交易的本質

前文提過，交易者應該設立兩個帳戶，分別處理部位交易／波段交易，以及動能交易／當沖。我也強調，各位如果決定管理兩個帳戶，這兩個帳戶就必須分開。

不論是部位交易、波段交易、動能交易與搶帽子等，每種交易的目標和風險／報酬比率各自不同。風險／報酬比率會受到時間架構影響。部位交易與波段交易性質傾向於投資，部位交易尤其是如此，其重點在於個股本質。某個上午或下午，如果大盤走勢不佳，部位交易的停損只要沒有被引發，就繼續持有。

可是，盤中交易涉及的時間架構較短。這類交易部位受到大盤各方面表現影響。大盤就像家庭主婦，如果她心情不好，大家都倒楣。如同俗語所說：「如果媽媽覺得不高興，全家人就沒有人會高興。」
