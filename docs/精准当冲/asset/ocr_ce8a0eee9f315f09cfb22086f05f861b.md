# 釋懷過去

> 「 人們總是把現狀歸咎於時勢。我不相信時勢。凡是在世上有所成就者，都會努力尋找其想要的時勢，如果找不到所需要的時勢，便自己創造時勢。」

——喬治．伯納．蕭（George Bernard Shaw）

你知道有誰能夠完全忘掉自己的過去？很少人可以享有這種自由。對我們來說，過去並不是真正的過去。痛苦的事情即使發生在幾週、幾個月或幾年前，依然會牽動我們內心深處的情緒。

我們試圖埋葬過去，但過去仍然影響現在的生活。後悔與怨恨在無意間消耗我們的內在能量，因為我們並未意識到自己正為消極和不愉快的情緒感到困擾。除非透過某種方式釋放這種負能量，否則過去會影響現在的經驗，甚至影響我們創造未來。

想活出生命最高的潛能，就不要累積憤怒、怨恨和恐懼等負面能量，因為這些負面情緒會阻礙我們產生積極能量。

釋懷過去的最好辦法，就是寬恕……寬恕曾傷害我們的人和事。就像身體能夠治癒生理傷害，我們的內心也希望治癒情感創傷。透過釋放這些傷害來治癒，透過寬恕來釋放。

為了寬恕，我們必須面對事實。承認此身背負的負能量，再也不能影響我們。我們選擇離開和拋棄，唯有如此，才能寬恕。

寬恕是我們給自己的禮物，讓心靈得以從過去解脫，讓生活能被賦予正面情緒，讓個人得以自由創造豐盛、成功的明天。
