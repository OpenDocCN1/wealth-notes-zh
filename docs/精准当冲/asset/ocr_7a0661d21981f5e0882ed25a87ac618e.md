股票可能透過兩種方式進行修正：（1）橫向發展或整理，（2）拉回。對於下降趨勢來說，拉回過程則是「反彈」。

不論透過哪種方式修正，只要價格不跌破原先突破關卡的支撐，修正走勢一旦結束，價格重新上漲，就是絕佳的加碼進場點。

反之，修正過程如果跌破原先突破關卡價位的支撐，就代表出場訊號。

# 如何繪製趨勢線

交易者應該養成繪製趨勢線的習慣。瀏覽走勢圖時，你可以在腦海裡繪製適用的趨勢線，也可以在走勢圖上實際繪製趨勢線。

理論上，繪製趨勢線時，可以銜接兩個低點或兩個高點，就如同繪製橫向走勢的支撐與壓力，以下將說明得更精確一些。

繪製趨勢線是研究技術分析的基本功之一，每位交易者與投資人都應該要熟悉這種方法。

# 新手筆記

+   1. 有些交易者認為首度向上突破後，價格最好做橫向整理，而不是拉回到原來的突破關卡附近做修正，因為這類的向上突破，力量更強勁。另一些人則認為無關緊要，拉回走勢只要守住低檔支撐，其本身就是正面訊號。

+   2. 不論什麼東西，怎麼上去，通常就怎麼下來。股價也是如此。你的持股如果出現兩天飆漲走勢，回檔通常也是直線下降，這種情況幾乎看不到買盤支撐，刺激程度恐怕超出預期。
