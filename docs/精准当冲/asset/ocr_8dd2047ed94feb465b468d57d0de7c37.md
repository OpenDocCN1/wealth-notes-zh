# 基本分析 vs. 技術分析

投資人／交易者挑選股票的方法，可以劃分為兩大陣營：基本分析派與技術分析派。某個派別的信徒總是嘲笑另一個派別，情況頗類似共和黨與民主黨的關係。

基本分析者樂於宣稱，他們從未看過任何富有的技術分析者；技術分析者則嘲笑基本分析者，堅持本益比會影響股票價值（本益比是股價除以每股盈餘的比率）。就像共和黨與民主黨一樣，他們都各有論述。

從廣義的角度觀察，投資人（不論個人或機構）的選股方法，傾向於採用基本分析，而短線交易者大多運用技術分析。由於投資與交易的風險／報酬比率截然不同，且長期投資相較於短期交易的時間架構差異也很大，所以這兩套方法各有不同的運用領域。另外，很多成功的投資人認為他們可以輕鬆跨越到當沖領域，結果發現自己陷入麻煩，因為投資與交易是兩種全然不同的東西。
