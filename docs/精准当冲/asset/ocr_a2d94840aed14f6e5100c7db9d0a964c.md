# CCI

CCI 是由一條曲線構成的超買／超賣擺盪指標，該指標最早由記者唐納·蘭伯特（Donald Lambert）運用於商品交易。

# CCI 為何重要

CCI 是衡量目前價格相較於統計平均數的位置。

# 如何運用 CCI

CCI 可以直接用其超買／超賣讀數，也可以用其與價格行為之間產生的多頭背離與空頭背離。CCI 指標計算的預設期數為 14 期。

+   > 超買：CCI 讀數超過 +100 為超買。

+   > 賣出訊號：CCI 由 +100 以上折返。

+   > 超賣：CCI 讀數跌破 −100 為超賣。

+   > 買進訊號：CCI 由 −100 以下折返。

+   > 替代性買進（賣出）訊號：價格向上（向下）穿越中線（0 線）。

# 新手筆記

+   1. 隨機指標運用於盤中走勢圖，開盤跳空線形經常造成指標讀數與訊號扭曲。

+   2. 日線圖上的超買／超賣資訊，應該運用於當沖交易。從事當沖交易過程，如果知道相關股票處於超買或超賣狀態，往往有助於瞭解下午盤的價格為何漲跌。
