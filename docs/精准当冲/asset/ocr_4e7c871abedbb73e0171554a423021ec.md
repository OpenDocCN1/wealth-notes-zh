# # 直覺的功能

> 「唯有用心看，才看得清楚；重要的東西，用眼睛是看不見的。」

——聖修伯里（Saint-Exupery）

如何界定直覺的意義，也就是難以捉摸的「第六感」呢？根據韋氏字典說法：「這是一種不需明顯借重理性思考和推理，可以直接取得認知的力量或能力。一種立即呈現的洞察力。」

西方文明推崇理性、合乎邏輯的思維過程，而依賴人類五感之外的知識被認為是欺騙，實在令人遺憾！當我們堅持用邏輯和理性來判斷事物的同時，卻忽略了個人與生俱來的神奇智慧天賦。

現在，科學證實人類思維有兩種層次：有意識的理性思維，以及潛意識的直覺思維。意識的運作就像電腦，可以處理經驗數值，根據過去經驗做判斷，並計算相關結論。

但直覺思維卻可以超越個人界限，進入一座龐大的智慧和洞察力倉庫。當我們需要時，這種能力可以分析資訊做為指引。這種洞察力又稱為直覺，或第六感。

尊重並滋養個人的直覺力，讓它成為我們生活的指導力量，我們的自信心會因此增強，生活各方面更有安全感，也更充滿力量。

如何運用直覺力，並聽從直覺的指示？方法之一是體認其存在。另一種方法是針對這個最明智的能力提出問題，譬如：我現在需要知道什麼？以目前的情況，我應該怎麼做？
