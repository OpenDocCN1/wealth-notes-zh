# 其他「如果……，則……」狀況

如果油價上漲，則運輸類股價格下跌，反之亦然，因為燃料價格上升，這些類股獲利減少。

如果通貨膨脹壓力變大，則黃金與白銀股價上漲，因為人們會為了對抗通貨膨脹而買進貴金屬。除了黃金與白銀個股之外，投資人也可以買進黃金與白銀的 ETFs：iShares Comex Gold Shares（IAU）、StreetTracks Gold Shares（GLD）、Market Vector Gold Miners（GDX），以及 iShares Silver Trust（SLV）。

如果美元升值，進口貨物更便宜。類似如 Nike Inc.（NKE）與 Toyota Motors Corp.（TM）股價會上漲。反之，美國出口到海外的貨物價格變貴，例如英特爾（INTC）與嬌生（JNJ）等股票就會受害。
