各位如果是第一次接觸隨機指標，對前段描述可能摸不著頭緒。但請有點耐心。事實上，隨機指標的運用很簡單。

隨機指標讀數介於 0 到 100 之間。

隨機指標的標準預設期間：%K 採用 14 期。訊號線%D 採用 3 期。如果想採用慢速隨機指標，慢速%D 的預設值是 3 期（如果不清楚我說什麼，可以採用分析軟體的預設值，不需做調整）。

# 隨機指標為何重要

隨機指標讀數顯示收盤價距離特定期間最高價的相對位置。這是很重要的參考資訊。

正常情況下，強勁上升趨勢的收盤價大多接近最高價；若是如此，隨機指標讀數會偏高。反之，上升趨勢發展轉弱，多頭支持力度放盡，即使價格勉強走高或盤整，收盤價會慢慢向盤中低價靠攏（交易期間，收盤價是最重要的價格）。

> 新手筆記
警告：隨機指標有個麻煩特性，就是很容易發出超買訊號。換言之，股價由底部向上突破，價格只要走高一陣子，隨機指標很快就顯示「超買」狀態。這時，價格如果繼續上漲，讀數會愈來愈逼近 100，重新發出超買訊號。我們稱這種撞頂現象為「隨機指標突出」（Stochastic pops）。一旦發生這種狀況，該指標就喪失做為預測工具的效力，直到指標讀數下降，發出明確賣出訊號。
