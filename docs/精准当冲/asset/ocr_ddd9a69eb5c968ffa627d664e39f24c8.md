# 法則二、交易資本必須是禁得起虧損的資金

這點相當殘酷，卻是初學者必須面對的現實，因為剛從事交易時，必定會賠錢。很多交易者賠掉交易帳戶，甚至房子、家具、汽車等。千萬別讓自己列入這份傷亡名單裡。禁不起虧損的資金，就不能拿來交易。如果籌措不出足夠的交易資本，不妨多等一陣子，直到你擁有足夠的「閒置」資金為止。

準備交易帳戶資金時，初學者還必須留意一項原則：你起碼必須學習 6 個月，才能穩定地在市場上賺錢。

# 選擇交易工具

我在第二本著作《短線交易初學指南》談到，美國人對於股市情有獨鍾。這種說法現在仍然成立，且熱情愈演愈烈。交易者學會如何從市場賺取利潤後，他們張開雙手迎接市場推出的各種投資和交易工具。

每位交易者都應該根據自己的個性與生活形態，挑選適當的交易工具。初學者犯下的最大錯誤，就是魯莽地挑選價格波動最劇烈的股票或期貨契約進行交易，只因為親朋好友或鄰居也這麼做。關於金融交易，想和其他人較量或比拚交易工具、交易方法、獲利多寡等，純屬浪費時間。

評估自己的個性，你可能對於高風險環境感到「如魚得水」，也有可能只適合低風險環境。其次，你需要考慮準備交易的工具。雖然選擇很多，但初學者大多挑選股票、ETFs，以及股價指數迷你期貨契約。
