# # 新手隨堂考

+   **>> 題目**  
01. 股票交易不可動用哪種性質的資金？請說明相關的兩個法則。  
02. 描述目前股票交易採用的三種層級報價資訊。  
03. 設立兩個交易帳戶的三種優點。  
04. 何謂滑價？  
05. 避免支付過多佣金的三種方法。  
06. 避免收到追繳保證金通知的安全方法。  
07. 模擬交易是否值得運用？

+   **>> 答案**  
01. 運用於交易的資金不可害怕虧損，只能運用禁得起虧損的資金。  
02. 第 1 級報價即時顯示最佳買進報價與最佳賣出報價；第 2 級報價顯示所有市場參與者遞入的買進報價與賣出報價；第 3 級報價屬於專業報價商和造市者專用，允許他們更新或改變報價。  
03. （1）碰到追繳保證金的情況，可以從另一個帳戶調度資金。
