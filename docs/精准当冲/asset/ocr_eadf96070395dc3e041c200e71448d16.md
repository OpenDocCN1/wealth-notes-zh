# 部位交易：買進核對清單

+   1.股票處於上升趨勢（一系列價格波動的中折高點與低點持續墊高），或者日線圖有強烈徵兆，顯示價格即將向上突破，而展開上升趨勢。

+   2.股價位在上升狀態的 50 天與 200 天移動平均之上（最好觸及 20 天移動平均而回升）。如果想低檔承接，股價應該位在 20 天移動平均之上。

+   3.移動平均應該呈現多頭排列（愈短期的移動平均位在愈上方：20 天移動平均位在 50 天移動平均之上，50 天移動平均位在 200 天移動平均之上）。排列沒有倒置，除非是低檔承接。若是如此，收盤價必須位在 20 天移動平均之上。

+   4.進場當天的成交量很大。

+   5.隨機指標、CCI 與 MACD 呈現超賣讀數，並且由超賣區折返，呈現多頭背離，或趨勢向上發展。

+   6.運用進場價格、停損價格與獲利目標價格等資料，進行風險/報酬分析。風險/報酬比率至少必須 1:3。

+   7.如果所有條件都顯示「進場」，等到價格較起尖突破壓力高出 10 美分，買進半數部位。

+   8.拉回走勢反轉日，如果價格夾著大量收在最高價附近，買進另外半數部位。

+   9.或者在拉回走勢反轉日隔天的大好春天，當價格超過反轉日
