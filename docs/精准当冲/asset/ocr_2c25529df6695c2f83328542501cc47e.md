# 橫向盤整

第三種橫向發展為「盤整」（consolidation）。學習如何精準判斷盤勢。這種型態顯示在日線圖或盤中走勢圖，結構相當清楚，可以成為你的好朋友之一。

顧名思義，橫向盤整就是呈現橫向的狹幅整理，價格線形相當短，且排列緊密。從交易者意圖來看，買賣雙方實力相當，所以價格在有限的區間波動。橫向盤整區間一旦突破，可能發展成為急遽的漲勢或跌勢，價格波動可能轉趨劇烈，展現充分的獲利空間。

# 下降趨勢

股票的橫向發展如果告一段落，買方可能放棄，空頭攻擊轉趨積極，股票發展將進入下降趨勢。

股票處於下降趨勢，其波段轉折高點與低點持續下滑。除非股票收盤價向上穿越先前的轉折高點，否則股票就是繼續處在下降趨勢。

股票可能因為本身不具吸引力（成交量很小）而下跌。可是股票如果爆量下跌，那就代表有問題了。股票爆量下跌，意味著交易者的恐懼可能演變為恐慌，大家都爭搶出脫股票。

股票下降趨勢不論是展現秩序或呈現恐慌（長黑線），都代表賣方掌握盤勢主控制权。碰到這種情況，多數交易員與投資人會另尋其他機會。只有堅定的長期投資人或放空者，才在下降趨勢過程繼續擁有部位。對於放空者來說（持有空頭部位的人），股價愈是下跌，他們愈高興。股票處於下降趨勢，尤其是行情接近底部時，我們稱股票處於「超賣」狀態。
