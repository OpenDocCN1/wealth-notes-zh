## 四种地形的行军宿营守则
《行军篇》开篇名言："凡此军所..." 处就是教你要如何布置你的军队，在处军守营论里面，不只是行军，还包括行军和宿营。相较就是我们下一讲要讲的，相较就是倚察。

那应该怎么行军宿营呢？主要还是看地形，这里主要讲四种不同的地形，有四种不同行军和宿营的原则。

## 第一种地形是山地，军队在山地行军和宿营，要注意三条：

- 第一，你带兵要靠近山谷。因为山谷有水源和草料，不靠...
- 第二，不要谷底行，行军要有一定的高度，特别注意你要顺风向走。
- 第三，如果你从山谷通过的时候，敌人在山顶上攻击你，这时候你一定不要进攻，要赶紧走。

## 第二种地形就是河流，孙子说，渡河之后要快退进，尽可能地远离河流。因为敌如我从那边来，你就背着水一战了。

## 总结加餐 | 七大商业思维模型

## 一、自我发展模型

- 1. 做决策之前要先做 SWOT 分析
- 2. 不破碗不换碗可能事情
- 3. 先存好库，再考虑增量
- 4. 等待是一项重要的行动

## 二、形势判断模型

- 1. 形势可以被判断，不能强求
- 2. 能够取胜就要放松有可能出错
- 3. 将问题分解，行动它不要受影响
- 4. 不要等人，要看预期有没有适时势

## 三、非竞争思维模型

- 1. 争不过你就不要争
- 2. 顺其自然自己争
- 3. 战争是整个商业竞争不是
- 4. 偏离主战是取气势

## 四、虚实思维模型

- 1. 专注自己的战场主战场
- 2. 学会转换，接受每个人都有弱点
- 3. 调动刺激，而不要被动加入动

## 五、兵力原则模型

- 1. 一生只做一件事情，心无定而心不焦虑
- 2. 找准战略重心，压力倒置投入
- 3. 时间管理原则：集中使用时间
- 4. 不忘本心，不忘初心

## 六、领导力思维模型

- 1. 用兵之道：驾驭、仁义、严厉、廉明
- 2. 养兵之道：爱护它，也要让它依赖你
- 3. 职场之道：协同在名，组织在利
- 4. 人生之道：不是名，也不是利

## 七、成本思维模型

- 1. 要保证每个动作都是有效动作
- 2. 总裁级思维：算总账不算小账
- 3. 用规律式思维解决结构
