# —— 重中解金句 ——

孙子曰："用兵之法，全国为上，破国次之；全军为上，破军次之；全旅为上，破旅次之；全卒为上，破卒次之。"

"百战百胜，非善之善者也；不战而屈人之兵，善之善者也。"

"故上兵伐谋，其次伐交，其次伐兵，其下攻城。"

# 全国为上，破国次之

在《谋攻篇》一开始就说："用兵之法，全国为上，破国次之；全军为上，破军次之；全旅为上，破旅次之；全卒为上，破卒次之。" 实际上不同的单位，从最人的全国全军，到一个旅（古时500人兵为旅），一个卒（古时100人为卒），到一个兵，战后只有五个人。所以这些概念为全为上，破为次之，全，全都是全已，破，就是把它打烂了。
