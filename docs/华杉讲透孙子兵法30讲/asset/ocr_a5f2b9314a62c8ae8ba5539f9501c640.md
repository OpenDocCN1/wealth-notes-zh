# 现场有神灵

这一讲我们进入《孙子兵法》的第十篇《地形篇》。这一篇原文有680字，将五个层次的内容：

+   第一层，讲解六种地形的战/ne/要/点；
第二层，讲了将领犯错会导致的六大险局；
第三层，对应二层的內容，孙子阐述了地形重要性；

# 六种地形的作战要诀

《地形篇》讲透了六种地形：通形、挫形、支形、险形、隘形和远形。
