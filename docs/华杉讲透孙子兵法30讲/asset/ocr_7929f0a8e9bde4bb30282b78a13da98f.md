# —— 重点解析孙句 ——

> 孙子曰：“故诡道而行之，后人发，先人至，如此真至之者也。故军争为列，军争为危。举军而争利，坌不及，委军而争利，则崩军而争利，颠覆者。”

上半讲，我们谈了《虚实篇》的破釜和陷等，这是一 些我们工作和生活的基础原理。如果能够从小事 情上讲清楚兵法的原则，并且始终带着把战术做故 事，你就掌握了《孙子兵法》。我希望在整 个课程里 面，你都能贯彻这种会不会一点。

# 行军的原理

> “举军而争利不及，委军而争利则崩军而争利，颠覆者。” 这就是行军的基本原理了。

# 赵奢救韩国

> 行军的基本原理是：急行军会耗损军队的精力，要想办法调动敌人到我的战场。
