# 12 虚实篇：想要得到，必须先放弃

> —— 重点解析金句 ——
孙子曰：‘我专为一战，敌分为十，是以什其众，夫夺人之众者也。’

这一讲，我们开始解读《孙子兵法》第六篇《虚实篇》，讲了三个层次：

+   - 第一层：敌人而我弱于人，你就应该让敌人觉得我人迹稀少
- 第二层：兵法原是相生，要以实击虚，以少胜多，而以多胜少，是常法；以虚道盛成而实之，敌之必胜之处，是虚处
- 第三层：确立了偏实的意思，事情的变化也是不断改变的

# 虚实与偏强的三原则

真正学习《虚实篇》，就需要通过这三条来认识虚实：
第一条，就是能打头的，以虚击虚。
第二条，敌人有实我有虚，我能坚守有我。虚实相对...让敌人从我这边转移。
第三条，我看得准就能大概看，...只要有一个法，就是用虚换实，通过把一些东西放弃，让他掉，...

# 做商战战时重心的选择时，有策略地做“虚”，能保障最重要“实”。 —— 华杉

# 军事上的“致人而不致于人”

《虚实篇》开篇就是这么说的： “凡先处战地而待敌者逸，后至而趋战者劳。” 你先抢占战地，在战场上摆兵布阵等着人来，就叫做“以今用逸”；“后至战地”别人把地利形地拿给你，你事后赶过去，就等于你去送死，你是以“劳待逸”今夕用逸了。”

# 虚实要应用到生活中

> 调动敌人来主场有两个关键点：一是对他有利，二是不来对他有更大的祸害，他不得不来。

# 《孙子兵法》原文

孙子曰：凡先处地而待敌者逸，后至而趋战者劳，故善战者，致人而不致于人。能使敌自至者，利之也；能使敌不得至者，害之也，故敌从我欲之，迎而勿拒，安而勿动之。

# 战略上的五个“不可为”

战场上的五个“不可为”
第一“不可战”。
第二“不可战而战”。
第三“不可胜而求战”。
第四“不可胜”。
第五“可战而不可战”。

用毛泽东的说的话说，就是主要矛盾。这就是战略思想的核心。任何一件事情都有一个战略重心。

# 将领的五种性格缺陷
