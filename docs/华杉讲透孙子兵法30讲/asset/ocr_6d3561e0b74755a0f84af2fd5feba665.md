# 战略上的五个“不可为”

战场上的五个“不可为”
第一“不可战”。
第二“不可战而战”。
第三“不可胜而求战”。
第四“不可胜”。
第五“可战而不可战”。

用毛泽东的说的话说，就是主要矛盾。这就是战略思想的核心。任何一件事情都有一个战略重心。
