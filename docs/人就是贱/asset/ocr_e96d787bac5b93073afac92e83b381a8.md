# 為何那支點燃別人的蠟燭不是你？

每個人都希望這世界可以多一點熱情、付出、有愛的人，但我只想問：「為什麼那個人不是你？」

我要再鬼打牆般地問你一次，你希望別人成為熱情、付出、有愛的人，但：「為什麼那個人不是你？」
