# 你要什麼？

# 讓你看到自己在乎什麼，願意為什麼付出代價

想把時間和錢花在哪邊，這一切都沒有對錯，每個人覺得有價值的東西不同，只是要讓你知道自己真正在乎的是什麼，也讓你瞭解大多時候說「沒時間」、「沒錢」，其實只是極為表面的理由罷了。在你邁向心靈成長的路上，「探索自己」是極為重要的一件事，如果你看不到自己做這件事最根本的原因，看不到自己最終想用金錢和時間換來什麼，你就無法真正瞭解自己。

而「錢」和「時間」，這二件需要付出代價的事情，就是幫助我們看見自己真正想要什麼的好工具。
