# 人生，是一个圆

# ——真相，让你的心自由

这是《人，就是贱》的第一篇主体文章，也是让你<|start|>解我写出每篇文章背后，所要传达的核心概念的一篇文章。

「人生，是一个圆」，这个概念其实是我当初从学英文里体悟到的。当我不断去思考：「为什么这个文法概念是这样？」、「为什么关系代名词要这样用？」、「为什么『love』和『like』明明就不是实际上的动作，它却是动词，为什么？」

我问了自己一堆为什么，试图从英文中找一个逻辑，清晰一条脉络；经由不断思考、不断动脑把这些英文的概念都想通以后，我发现最重要的一件事，那就是——「整个英文的概念，就是一个圆」。

每个英文的小概念就像是一个点，当把几个点想通后，我再继续思考，这几个被我想通的「点」，很快就因此连成一个「面」。最后这些一点一滴的想法，竟然汇成了一个「圆」。到最后，无论你从任何一个英文的「点」来问我，我都知道这个点是在哪边，我都可以从这个点，结合成一个面，最后画成一个
