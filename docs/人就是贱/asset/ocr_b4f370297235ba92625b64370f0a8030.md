# 重點不是你說什麼，而是你怎麼說

這二年多來，因為上了一個潛能開發課程的關係，有機會和許多人聊到「你要什麼？」(註1)。令我意外的是，我以為聽到最多的答案會是「我要賺錢」或「我要找個好老公、好老婆、好工作」之類的標準答案，沒想到，我聽到不少人都說出同一個答案，那就是：「我要做自己。」

當我聽到第一個人說「我要做自己」時，我以為這只是個案，後來聽到愈來愈多朋友說出這個答案，我才發現，「原來做自己，對他們來說有這麼難呀！」我在課程中還學到另一個很重要的概念，那就是：「當很多人都說了同一件事時，這件事不一定是真的或是對的，但其中一定有值得我們注意的地方。」

這麼多個案，讓我不得不發現其實「大家都不敢做自己」，但為什麼你不敢做自己呢？因為你怕別人討厭你，所以你不敢說自己想說的話，也不放做自己想做的事。
