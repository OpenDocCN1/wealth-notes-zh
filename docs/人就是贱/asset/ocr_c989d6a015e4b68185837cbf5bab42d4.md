# 你騙得過所有人，但你騙不過自己

二十歲時做錯事情，身邊大多數人都比你年長，會覺得你才剛出社會，還是個孩子，不會沒關係。但當你四十歲時，身邊的人都比你小，他們會認為：「你都幾歲了，為什麼連這麼簡單的小事也不會？」什麼時候該學什麼就去學，不要逃避，不要閃躲；你可以躲得了一次、兩次，但躲不了一輩子。該面對自己的心情時，就學著好好面對。你可以騙過所有人，但你唯一騙不了的，就是自己的心。
