# 只要你覺得它重要，你就會撥出時間，
而且願意「付出代價」

人一直覺得「我真的做不到」的事情，或許你也真的覺得他做不到；但只要背後的原因不一樣了，或是他想付出的人不一樣了，他就做得到了。因為他覺得這件平常做不到的事情，今天「天級的」值得了，所以重點不是事情本身，是它背後的價值。

所有事情都是相對而非絕對的。如果覺得這件事很值得，你就做得到，無論它再難，需要花多少時間，你都不會抱怨，你都會忍，因為你不覺得那是犧牲。人都有一種特質，就是會「看著事情背後的價值來做事」。同理可證，當你覺得它不值得，無論它再簡單，你都會說：「我做不到，我沒時間。」如果有人逼你做，你會怪東怪西、會怨天尤人。
