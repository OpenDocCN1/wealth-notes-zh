# 富有一種選擇

我認為，富有一種選擇，而這過程要靠你的堅持。

這跟大多數人的認知不同，很多人以為「富裕」是天賦，自己之所以生活無法富足，就是因為出身不好或基因不好，沒有賺錢的「命」。又認為，有錢人之所以會有錢，大多數都是因為會投胎家裡有錢，因此過著無憂無慮的生活。

但事實上，富有一種可以培養的能力，雖然出身決定起跑點，但是不會影響你富有可能性。最終，是否要致富的選擇，還是在自己身上。一般人所渴望的富裕，並非成為暴發戶，而是「財務自由」。所謂財務自由，指的是：就算你不工作，被動收入也能在有生之年支應日常生活所需。
