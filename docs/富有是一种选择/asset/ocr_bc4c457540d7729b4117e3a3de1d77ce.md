# **表一** 簡易都更&危老比較表（註：不要看的可以跳過，細節其實還很多。能夠津津有味看完的，恭喜你，你好棒棒，必然可從事此行業）

| 項目 | 都更條例 | 危老條例 |
| :--- | :--- | :--- |
| 申請人 | 實施者（如建設公司、都更會、都更中心、公部門） | 土地建物所有權人 |
| 基地規模 | • 面積 > 1000 平方米<br>• 面積 > 500 平方米之更新單元需經都更審議會同意 | 無面積限制規定 |
| 條件 | 公劃更新地區或符合自劃更新單元標準或指標 | • 結構安全評估未達最低等級<br>• 經建築機關通知限期拆除之危險建物<br>• 屋齡 > 三十年，耐震評估未達標準的建物<br>• 已不具改善效益或沒有電梯的建物 |
| 容積獎勵額度 | • 不得超過法定容積 1.5 倍或 0.3 倍法定容積 + 原容積<br>• 可另申請海砂屋、輻射屋、開放空間等其它獎勵 | • 法定容積 1.3 倍或原容積 1.15 倍<br>• 不得再申請其它獎勵 |
| 同意比例 | 採多數決，須土地及建物所有權人 75% 及 80% 以上同意 | 須全體土地及建物所有權人 100% 同意 |
| 稅賦優惠 | 土地增值稅、契稅、地價稅、房屋稅 | 地價稅、房屋稅 |
