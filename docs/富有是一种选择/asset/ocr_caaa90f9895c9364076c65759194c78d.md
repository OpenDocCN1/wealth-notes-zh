# 富人的品格：你有做好變有錢的準備嗎？

很多人都以為我是文青，因為我從大學畢業就在寫書，那也是因緣際會。但其實我不太喜歡跟文青來往，有些文青（或是自認為文青的人），心裡有種高人一等的感覺，古人稱之為陽春白雪。現代一點的說法，就是自認為高人一等瞧不起商人，但是又渴望能夠洛陽紙貴，大大暢銷；萬一作品不那麼受歡迎，就批評別人不懂他的品味。

宋高宗曾經問岳飛：天下如何能太平？岳飛回答的是「文官不愛錢，武官不惜死」。說穿了，當朝文官的問題就是貪財。表面清官，背地裡卻積攢營私，貪財得要命，只是假惺惺。
