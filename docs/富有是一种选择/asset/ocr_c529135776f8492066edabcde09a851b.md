# ③ 為了買房你願意付出多少代價？

除了要估量夢想的價格，還要知道自己的能耐。這裡的能耐指的不單是你有多少錢？還有你願意為此付出多少代價。不管是存頭期款，或者是後續繳房貸，你的生活勢必會受到影響。

還算低利時代，如果可以使用寬限期不必先還本金，就不要客氣！用寬限期，五年內只付利息，不付本金，好處是可以維持生活品質，並且有多餘的資金注入其它投報率較高的 ETF 或股票，也還有筆應急用的生活資金。
