# 缺乏自我效能必成魯蛇？

如何面對壓力同時保持冷靜決策，正是我們在人生中和投資與理財時經常面對的挑戰。事實上理財的原則並不難，最大的挑戰在於投資人對於堅守紀律的決心。

行為經濟學中有一個名詞叫「處分效應」（Disposition Effect），也就是當股票上漲時，投資人傾向於賣掉變現趕快獲利了結，但股票下跌時反而選擇持有，堅決反轉機會。這與人類「不甘損失」的天性有關。如此一來，會造成手上賺錢資產過早變現，被套牢在虧損資產上的時間過長。

人性的確具有「損失趨避」的特性，害怕損失的「痛感」會比獲得的「喜悅」要來得高——甚至有研究發現，會高出兩倍以上。如果賺 100 元的喜悅是 +1，虧 100 元的痛感至少是 -2！
