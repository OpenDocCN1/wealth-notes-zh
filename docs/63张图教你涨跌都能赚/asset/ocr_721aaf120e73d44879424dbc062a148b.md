# PPP 的成功和失败案例

在之前的章节提到很多次均线的排列所形成的 PPP 和反 PPP，我想各位已经记住了，本节则再次探讨成功和失败的案例。

如下一页的日本邮船所示，当均线的排列完美呈现5日线>20日线>60日线>100日线的状态，就适合进场买进。

但投资人不能因为完成 PPP 状态就放心。由于均线的性质，红色的5日线仍然会配合股价上下波动而上下摆盪。

当 PPP 状态出现时，我们的买卖操作是一边确认中长期均线间隔相等，且以20日线>60日线>100日线的排列方式一起往上走，然后一边配合红色5日线的上下波动，重复「下跌时买进，涨不上去就先卖出」的模式。

在这个案例中，黑鲸①和黑鲸②之后出现了 ，看起来会发生分岐讯号，所以在此时进场买进。到了黑鲸②跌破5日线，形成反下半身讯号时，就是脱手的时机。
