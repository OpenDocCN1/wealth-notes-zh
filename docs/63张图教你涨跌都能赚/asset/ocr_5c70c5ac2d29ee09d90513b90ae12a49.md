# 從暴跌到反彈的
訊號判讀方式

就讓我們來看看疫情造成的暴跌，以及其後反彈上揚的訊號有多明顯吧！

圖6是日經平均股價指數線圖，並將2020年3月暴跌後至反彈上揚過程放大後的結果。圖中隨處可見相場式經典訊號。

舉例來說，開始暴跌後的第七根K線是紅線，指數暫時在這裡止跌。接著又開始暴跌，持續好幾根黑線，在第九根K線第一次出現了較長的紅線，呈現反轉上揚的局勢。

這個現象正符合相場式訊號「9日法則」：際優銷下股價上漲信號會將優劣轉K線（之後將於第2章詳述）。

在正式進入反彈上揚的地方，也亮起了漂亮的「N大」訊號。N大指的是在向上走的20日線上，5日線如「N」字形般，呈現上揚→短暫下跌→再度上揚的變化，暗示著股價將轉為上漲走勢。
