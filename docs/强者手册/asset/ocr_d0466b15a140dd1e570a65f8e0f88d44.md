# 心是什么？

第四条：这个心啊，就是接近真理，就能够造就真相，或者这个造出幻象啊，就是所谓强者之心。

第五条：举例，有了强制之心，就可以通过造出整个社会的机构啊，整个社会的政治经济，整个价值啊，整个鲜血肉，整个灵魂啊，全都能招得到，没有这个心啊，就是活着，就是很，我是很，至于我是活着一个点，一个线对着一个念。

第六条：就是通过这些东西，通过所有的召唤啊，最后就进入道德经所讲的道德经里面的智慧啊，其实就是幻化出来，就是破我是最好的手段啊，无为无所不为，无证无所不争啊，无欲无所不欲啊，就里面的东西，所有的东西就是生命能够还原啊，能够召唤。
