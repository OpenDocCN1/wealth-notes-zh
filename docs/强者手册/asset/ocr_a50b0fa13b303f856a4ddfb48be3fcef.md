# 强者心法 3 “打破枷锁”

人人都被“锁住了”，会开锁才能逆袭！

管理就是给人“上锁”，锁头就是恩怨得失，左右徘徊。

一个人的弱，并不是智 NH 的弱，而是锁在原地打转。

这与人思想边际之锁一个逻辑。

人脑子里有个穷，心也有。都需要打开才行。

任何管理者都会让人处于一种中间态，绝不会把人推向两极，两极就是开锁。

一个人如果没有什么可失去的了，那就是他最强大的时候，勇气非凡，智慧自然来！

一个人如果尝到了成功的甜头，自然循着脉络，但大概率还是会陷入“中间态”。

所以底层能逆行的人很少，这种人不是疯子偏执狂，就是精神病患者。

所谓正常人，其实都是病得很深的人！人得病不可怕，可怕是认为自己没病！
