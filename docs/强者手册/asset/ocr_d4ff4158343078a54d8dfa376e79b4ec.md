# 人为何会区分出层次？

表面看是财富、教育、关系网等等

# 抓住本质其实就一个：意识形态

# 为什么？

因为人的竞争不同于动物，人是将低维感官竞争升级到意识之争，人类社会的各种竞争创到根都是意识型态的竞争。

# 意识维度的竞争，会把人们划分成两类：

往下走，越是把人们固化在某种形态之内，让其活在“某种设定”里；

往上走，越是能够挣脱种种固化，能“跳出来”就能看到“设定”，能看到就能制造。

而挣脱固化最有效的方法，就是把自己打开。

相对应的，固化做得最精巧的是儒家

挣脱固化至关简效的是道家

帮助人们打开自己的最佳路径是佛家

意识在佛家讲，就是第六识，99.99%的人基本都在第六识里转圈圈。
