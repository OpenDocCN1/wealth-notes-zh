# 认知一阶层

一个人的阶层，决定了他每天接收的信息；他所接收的信息，形成了他的知识结构；他的这些知识结构，构建了他的认知体系；而他的认知体系的水平，决定了他怎么思考，怎么行事，这也决定了他未来所处的阶层。

这个阶层→信息→知识→认知→阶层的封闭循环，能够让大多数人，一辈子在同一个圈子里打转。这也是社会阶层稳定的重要原因。

同时，对于小部分先知先觉的人来说，他们在这个封闭循环中，能够做到螺旋上升，随着社会认知水平的提升，实现阶层的上升。

那么，想要螺旋上升，而不是原地转圈，转折点在哪呢？
