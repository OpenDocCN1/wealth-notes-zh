# 为什么？

因为土地本身就是财富，就是财富之母，就能够获得货币的增殖。

注意，达叔用的这个词汇“增殖”，是货币增长、繁殖。

这是打开《资本论》扉页，达叔看到的，第一个令达叔震惊的词汇，很生动，形象。

哪怕，历史课本上说中国明末清初，产生了资本主义萌芽，如果不被拔，肯定能自己发展出资本主义。

达叔读完《资本论》，对这一结论，是极其悲观的。

为什么悲观？请看下方分析。

我们来看一下欧洲，是怎么被出资本主义的，根源还是土地制度。

欧洲长期生活在封建时代，封建封建，分封、建国，土地这玩意都是王室分给贵族的，而且还是世袭。

平民即使做生意，侥幸赚了钱，那也是暴发户，没有资格购买土地的，因为你们不配。

W—G—W，这条用货币购买土地实现货币增殖的道路，在欧洲根本走不通。

那怎么办？

逐利，实现资本增殖，是所有人的梦想，此路不通，就开启了旁路建设。

欧洲拼命追求资产增殖，G—W—G’，其中一顿忙活下来，必须实现 G’ > G。
