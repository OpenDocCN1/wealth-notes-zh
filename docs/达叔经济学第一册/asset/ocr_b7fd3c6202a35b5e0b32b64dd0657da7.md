# **如何看待北大毕业当房产中介的现象，以及引发的热议？高学历去做房产中介，是人才的浪费吗？**

近日，房产中介里的高学历话题，引发热议。据报道，全国各地从事房产中介的，不乏北京大学、复旦大学、浙江大学、武汉大学、南京大学等“双一流”高校毕业生。

![](bbox=[0.13, 0.58, 0.92, 0.7])

达叔的观点旗帜鲜明：
不仅不是对人才的浪费，而是这个行业的从业者终于变得更合理了。

分析任何一个行业，一般至少要分析三个要素：
行业人才的供给端、行业人才的需求端、行业人才本身要素。
