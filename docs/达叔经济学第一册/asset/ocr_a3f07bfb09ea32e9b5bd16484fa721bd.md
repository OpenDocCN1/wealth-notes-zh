# 选择

+   1、命运对人的考验，不是在你在忙的时候，而是你在

闲的时候，你会做什么选择。

达叔第一次觉得自己有丰沛的表达欲，想写文章，

是 2015 年。

那一年，达婶正在怀孕，职场也不是很顺，达叔拿

个小本子，里面画满了自己的自媒体路线图，给她讲了

半天，要如何如何。

就如同达叔给她吹的无数个牛，达婶是无视的，事

实证明，她是对的，达叔写了几篇，就没坚持下来，后

来工作一忙，就荒废了。

完美错过一次发家致富的机会，没有赶上公众号等

文字自媒体的超级红利。

再次想起这事，是 2020 年初，被疫情关在家里，

憋坏了，才开始写自媒体。
