# 第三十二篇  FC#31 限你一万年

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

如果不出差的话，都是达叔早上七点爬起来，送孩子去上学，俺很珍惜每天相处的这点时间。

最近女儿，特别喜欢让达叔问问题考她，她看了一点西游记，就一直让俺出题。

达叔就问，孙悟空为啥被压在五指山下了？

女儿说，是因为调皮，不读书，天天打架。

达叔问，后来被谁救出来了？

女儿说，被唐僧。

达叔问，救出来，干嘛去了，是不是去读书了？还去很远的地方去上学。

女儿点点头说，是的，但是爸爸，上学读书之后，就不用被欺负，不用被山压着什么？

达叔一下子就犹豫了，觉得这是个好问题，遇到一个事儿，能问然后呢？再然后呢？

顺着逻辑，一路推演下去，这个小家伙，以后长大应该不是个笨蛋。
