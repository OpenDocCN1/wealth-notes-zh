# 第四十三篇 JJ#3 如果大萧条来了，普通人应该怎么办？

达叔这篇文章是为了回答知乎的一个问题：
https://www.zhihu.com/question/380644941，原问题是：如果大通胀和大萧条来了，普通人该怎么办？我们2020年是不是遇到了经济危机？目前来看是的。那么会不会遇到大通缩？达叔对着头上的电灯保证：绝对不会。

而且，大通缩的时代，再也不会了。如果你连这个都没搞清楚，你还上个哈B呼。为什么？因为全球的货币体系发生了巨变。纸币的时代太短了，以至于绝大多数人没有意识到纸币的本质。

全球货币体系演化轨迹：
复本位时代----金本位时代----金汇兑本位时代----美元霸权纸币时代。

以前为什么会发生大通缩？
是因为遇到危机的时候，人们不愿意花钱，市场流动性紧缺、物品价格暴跌，加上劣币驱逐良币，人们更不愿意花钱，导致恶性循环。
谁可以解决这个问题？政府。
