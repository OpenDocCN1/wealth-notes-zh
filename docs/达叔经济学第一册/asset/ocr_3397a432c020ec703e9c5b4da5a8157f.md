# 第二十四篇  FC#23 人是怎么早早进入投资性死亡的？

大家好，我是达叔。

一个想和大家一起慢慢变富的伙伴。

今天出差回到家，一打开门，家里冷冷清清的，连个人影都没有。

赶紧给达婶打个电话，你跑哪去了？

达婶那边很嘈杂，在和我妹买房子，今天付定金了。

达叔听完有点生气，也有点开心，生气的是这货对自己家投资，从来

没这么上心过。开心的是，她妹终于距离被屠杀，又远了一步。

很多人，以为达叔那篇 FC#21 这一次的屠杀静悄悄，是写着玩的，

但凡你长点心眼，出去浪一圈，就会知道，达叔那是在救你。

当然，也有人进来看了一眼，给达叔留了个言，你说的都是啥玩意，

一点营养都没有。

对于蛆虫来说，营养都在粪坑里。
