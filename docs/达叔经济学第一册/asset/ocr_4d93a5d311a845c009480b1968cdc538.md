# 大主任的困惑

2019年，夏。

某人口大省的顶级医院，6个主任，一个护士长，由经销商销售带队，来上海参观考察，达叔负责接待。

第一天晚上，吃香港菜，包厢，大家先破个冰，瞎聊，主要聊两地的行业发展。

大主任说起自己那个省医学会内部争夺名利，用了一个词，叫“热闹”，然后问达叔，你们上海这边好像更热闹，对么？

达叔听完，狂点头，钦佩不已，多么杂梁血腥的场面，被人家用一个喜庆的词汇给表达了，这特么真是高手。

一年半过去了，达叔对“热闹”这个词，还是记忆犹新。

能在这个人口大省的头部医院干到主任，大专家，情商智商都是一流的，业务水平也是一流的。

但是，第二天中午吃饭，日料店包间，困惑了。

日料店，在上海某大医院旁边。

达叔点了很多刺身拼盘啥的，中间两个寿喜锅，达叔一边吃，一边观察，觉得不对劲了。

我们三文鱼蘸酱油，直接吃了，几个主任和护士长，都把三味鱼和贝类，放在寿喜锅里煮熟了再吃。

达叔心里一凉，这餐厅可点错档了。

得赶紧找个刺激的话题，转移一下注意力，想了半天，什么话题够刺激，还不低俗？
