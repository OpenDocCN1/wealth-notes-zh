# 第三十篇  FC#29 只有地产，能给高科技公司的结局留

点尊严

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

今天遇到三波人，感觉到一个奇怪的事儿，俺可能真的红了，至少在小圈子里，红了，像个刚出锅的螃蟹一样。

三波人，样样不同，却都认识达叔，都看我的文章，还都挺神秘的。

1、中午和年轻有为的富二代吃饭，对方想搞医疗，说了几个医院，说能搞定，请达叔吃饭，问产品，算是读者来对接资源的。

对方家里开厂，踏入医疗行业，是因为疫情，搞了口罩和手套生产，还玩商业地产，非常认可达叔的判断，未来20年，是医疗行业的黄金二十年。

达叔为啥见他？

因为他把达叔近百万字的文章，全读了，达叔的文章絮絮叨叨的，很不正经的样子，能看完，那是真爱。

2、和达叔的经销商务经理，去拜访医院，在等客户时，对方神神秘秘的问，有个公众号叫达叔经济学，是不是你写的？太牛逼了。
