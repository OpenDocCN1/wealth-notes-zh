# **第九篇 FC#9 看着很漂亮，为什么是个坑？**

达叔今天本来要写了一篇“35 岁职场危机”的话题，发在知乎。

其中提到职业性收入和财产性收入，希望各位年轻人能够在赚钱的同时，一定要记住，你和公司只是短暂的**合作关系**。

工作是手段，赚钱才是目标。

职业性是赚钱，但是手停口停，永不得闲。

财产性收入不断增长，才是通往财富自由的阶梯。

能玩的投资就是那几个品类，有的玩股票，有的玩基金，有的玩房产，其他的期货、外汇等都是更专业的领域，会吃人的，达叔不碰。

经常看达叔文章的人都知道，达叔主要投资房产，空隙期间买些基金。

但在劝别人买房之前，先来聊一聊投资房产的坑，劝诫一下，这个领域很专业，不要乱碰。

普通人不要碰国外的不动产。

有各种帖子，试图说明，国外的不动产便宜，在某国某城，100 万人民币能买多多好多好的房子。

是真的吗？是真的。
