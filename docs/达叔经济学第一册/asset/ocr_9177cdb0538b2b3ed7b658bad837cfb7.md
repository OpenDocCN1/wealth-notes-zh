# 第三十三篇 FC#32 从两千年前的那次抢劫讲起，房地产商是当代盐商

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

最近上海的天气，阴晴不定的，俺不知道这天气到底是变暖了，还是变冷了，反正现在是穿着羽绒服，躲在书房里，给大家码字。

昨天写了一个文章，SK#139 我在尝试着贿赂你，前面讲了同一时空，不同人群在平行世界里，各行其是，是想和大家说，只要你肯折腾，无论有没有专业知识，都能赚到钱。

绝大多数人，平日生活，圈子太小，达叔天天接触很多人，在外面浪，很早之前就写过，SK#108 边界与荒谜，见过的人，更容易有钱，这些都是掏心掏肺的话，能看懂多少，就看各位造化了。

但是，昨天文章落笔收尾，最后一个章节，才是俺最想说的，做任何事情，一定要研究结构，经济结构、人口结构、变化趋势等。
