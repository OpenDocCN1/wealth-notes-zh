# 第五十一篇 JJ#11 不到万不得已，不要掺和地摊经济

今天达叔出差，碰到个朋友，说自己工作不顺，问达叔可不可以去摆地摊，前几天两会，总理记者会里，不点名表扬明星城市成都，全面放开地摊经济。

达叔来聊一下，普通人的崛起很难，不到万不得已，不要掺和地摊经济。

达叔小的时候，生活在农村，赶集，卖过辣椒、蒜苗等农产品。

上学的时候，在上海摆过地摊，卖过运动鞋。

这两段经历，都是贫穷且惨痛的，风吹日晒，不赚钱。

一直到 2008 年，达叔率队参加创业大赛，百联集团举办的，杀入决赛，有了更多的体验。

决赛的规则，简单且粗暴：

四只队伍，在百联商场上百家店铺中，挑选一个店铺的产品，在商场门口摆摊销售，8 个小时，销售额最高者，成为最终冠军，赢取创业奖金。

半决赛的时候，达叔的队伍是第一名，所以达叔拥有优先选择权。

每个队伍有 4 个人，达叔和另外三个小伙伴，研究了商场的各个品牌，结合当时的季节交替，最终选择了当时比较火的一个服装品牌—佐丹奴。
