# 第四十一篇  JJ#1 疫情让我们思考：财富的源头是什么？

经济学是一门刚刚起步、派系林立的学科，但本质都是在探讨财富如何产生和分配。

中国发展到今天，目前所有的主流学术思想都来自西方，无论是左翼思想计划派，还是右翼思想自由派，都是西学东渐的结果。

伴随着中国经济的腾飞，中国重新崛起，在话语权、社会科学知识体系如何升级？摆脱左右之争，讲好中国故事，成为更加急切的 任务。

话语权的重要性，在疫情期间表现的尤为明显，同样的事，中国做和西方国家做，得到的评价截然相反。财富的源头是人还是物？

达叔以前看过央视的纪录片《大国崛起》，其中非常感慨的是葡萄牙、西班牙平分地球，占领美洲最好的拉美，土地肥沃、矿产丰富。而后来的英国，只有更贫瘠的北美，后来的故事大家都都看到了。

从时间轴上看，古自至今，人的能力在不断提升，努力摆脱自然的束缚。

从空间轴上看，世界各国，越是经济发达的经济体，其第三产业在经济中的占比就越高。
