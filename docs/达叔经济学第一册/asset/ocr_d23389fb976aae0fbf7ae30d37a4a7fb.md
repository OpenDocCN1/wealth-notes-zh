# 第五篇 FC#5 大神们的争吵，我们该相信谁？

2020 年突如其来的新冠疫情席卷全球，各国抗疫，波及巨大。

伴随着中国新冠疫情收尾，知乎等平台开始陆续多了一些话题，就是 2020 年的房子还能不能买？会不会涨？

从 20 年前开始，这种多空对块的舆论就没有停息过，每次都是空军气势汹汹，人多势众，言论广受欢迎，最后都被空军吊打，满地找牙，在此孰对孰错去权就不复述了。

这是世界观的问题，道不同不相为谋。

达叔长期投资长三角城市群的楼市，这一点在之前的个别文章里一定的陈述，今天这篇文章，主要来梳理一下多军内部的几个大神观点分歧，各有道理，供君参考。

达叔长期关注的有很多，但比较代表性的头部有这三个人：

开宗立派的水库欧神，吴晓波阵营的刘德科，还有草根起家的卢俊。

其他的比如平米、朱红之泪、城市挖掘者、地图、楼市大酱、三鱼说等都是衍生出来的小分支，或是联盟。

由此，达叔感慨还是那句话：穷人都在相互撕逼，富人都在相互扶持。
