# 第二十九篇  FC#28 新春假期，如何给长辈反向洗脑

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

新春假期这几天，达叔准备写一个系列的假期聊天文章，昨天写了 FC#27 新春假期，如何与烧钱的父辈好好聊天。

达婶看完，嘲讽的说，你这几个故事，都是我领着你去见的，我都在场，我也能写。

达叔看了看这个漂亮且无知的姑娘，问道，那你说说，我一共讲了几个故事？先后顺序如何？谋篇布局如何？

为什么有的在前，有的在后，有的展开的很多，有的有一笔带过？

每个故事展开写，细节都可以单独写一篇，为啥要揉在一起写？揉在一起，想表达什么？

达婶听完，气鼓鼓的去洗澡了。

出来之后，达婶憋了一句，那你只是陈述问题，没给解决方案，这也不像是你的风格，你不是总说，只抛问题，不给方案的家伙，是不负责的么？

在一个问题上栽了跟头，立马能开辟一个新战场，找出一个新角度发起攻击，这种家伙，就是比较厉害的角色。
