# 第三十六篇 FC#36 部分觉醒的体制人

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

昨天开了两天的大会，终于结束了，今天留在郑州，给新招的一批新员工，做产品知识培训。

早上，在自助餐厅遇到了老板，手里拿个小本子，一起吃饭，坐下后说，你昨晚还见医疗人了？

达叔说，是的，你昨晚出去逛街了？

老板说，我从来不逛街，我八点多出门遛弯了，走了四十分钟，找到了一个房产中介店，去看了下郑州的房子。

我发现我有一个能力，就是瞬间把人说生气，对方给我推荐了一个四环外的房子，我就问她，你推荐这么远的，是因为佣金拿的多么？

对方当场差点就崩溃了。

达叔哈哈大笑，你这个家伙，太调皮了，那个房产销售，是太低估你的购买力了。

老板说，那个中介马上推荐了另外一个楼盘，说她有一个表姐，在她的推荐下，考虑了两年，买了这个楼
