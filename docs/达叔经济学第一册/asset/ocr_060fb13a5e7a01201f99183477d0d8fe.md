# 第十三篇 FC#13 泡沫制造繁荣，拒绝泡沫，就是拒绝财富

泡沫，是一个被妖魔化的词汇，没有泡沫，就没有繁荣，就没有人类科技的进步。

泡沫被妖魔化，就如同“改革”被神话了一样，都是中国目前特定语境下的产物。

历史上各种改革、变法，有成功的，有失败的，改革是个中性词，没人保证一定会成功，但目前所有人都觉得改革，深化改革，带有褒义的色彩，这本身就是40年的思维惯性，是一种思维懒惰的行为。

泡沫，中国所有人闻“泡沫色变”，新中国建国以来，什么资产有过泡沫？什么泡沫破灭过？

除了连赌场都不如的股市，韭菜收割机，谁能给达叔举出几个例子？

所有媒体小编嘴里说的楼市泡沫，完全是一派胡言。

经济发展必然伴随之资产膨胀，这种货币现象，不叫泡沫，叫繁荣。

繁荣和泡沫，如影随形。

世界三大坚不可摧的泡沫，美国的股市，日本的债市，中国的楼市。
