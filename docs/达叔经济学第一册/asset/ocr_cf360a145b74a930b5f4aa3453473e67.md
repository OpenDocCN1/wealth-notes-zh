# 1

接原來先生的武汉游学团广告，原因很多，我把我看到和想到的，和大家分享一下。

达叔是做医疗的，在我們公司，湖北長期被劃在东区，所以好多年前，就能一直看到湖北的相关数字。

最近几年，研究城市比较多的人，会发现有一个词汇，叫“强省会”，或“首位度”，达叔第一次看到这个词汇的时候，首先想到的城市，就是武汉。

为什么？

因为我们公司在湖北的生意，长期以来，武汉的占比接近 50%，这在其他省份，是极其罕见的。

这个占比，在任何一个省，都是高的离谱，也就是说，整个湖北的优质医疗资源，几乎被武汉占完了。

其他的省会，比如南京、广州、杭州、合肥、郑州等所谓省会，医疗生意在全省占比，基本在 20% 多。

这是武汉，给达叔的第一个直观印象，非常深刻。
