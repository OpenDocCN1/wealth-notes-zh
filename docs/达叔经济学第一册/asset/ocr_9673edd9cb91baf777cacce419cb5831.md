# 第三十九篇   **PC#39 不要去干别人看一眼就懂的生意**

大家好，我是达叔。

一个想和大家一起慢慢变富的的家伙。

昨天出差，来了某省会，有点失策了，遇上五一假期，明天回家的火车票，差点没买到，这要是耽误了回家，估计达婶那边就解释不清了。

在知识星球里，发布了一下行程，约了几个潜在的医疗人，谈合作，不见面还好，大家都存在幻想。

一见面，竟然发现对方是医疗行业的省市级管理单位，其配偶还是我们的客户，某重点目标科室的。

见完，对方问，一直以为你是那种油腻干练中年男，没想到，还是个温润如玉，才貌双全的小伙子。

你们那些在朋友圈里夸达婶、惹达叔的家伙，好好学习一下，这就是中国体制内，优秀共产党员、国家的中层干部，对达叔的评价。

就这评价，连达婶都说不出口，目前能把俺夸成这样的，除了这位读者，就剩达叔的女儿了。

这次过来，两天时间，见了7个人，聊一下关于赚钱的感慨。
