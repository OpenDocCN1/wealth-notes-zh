# 2、限价。

扭曲价格信号，增加寻租空间，这种事，历史上没有一次有好结果，都是一地鸡毛，不利于解决问题，只能拖延问题。

最惨的人，是这一代人，估计再也看不到啥好产品了，产品质量堪忧，当然，这是你摇号中标，少付几十万的代价。

喜忧参半，而已。

# 3、限购、限贷，这俩估计会长期存在了。

一直想把这个产业的投资属性和居住属性分开，能不能成，达叔不方便说。

达叔能说的是，30年前，这块是个香饽饽，是朱老板花大气力，才干成的支柱产业。

30年后，是这个个待遇，挺有意思的。

允许居住，限制投资，防止房价快速上涨，导致贫富进一步扩大。

所有限制政策，都只能限制普通人，不能限制“刁民”，结果，惩罚了顺民，奖励了“刁民”。
