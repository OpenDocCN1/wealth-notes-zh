# 第二十一篇  FC#20 知识越专，越糟糕，聊点房价

大家好，我是达叔，一个想和大家一起慢慢变富的家
伙。

从头研究过达叔这个账号的人，不难发现，达叔的文章结构，发生过几次变化。

刚开始的时候，达叔给自己的定位是写三个板块：经济、思考和房产投资。

写的特别随意，字数也没有限制，一顿乱写。

偶然看了一篇写医疗网红郭天玉的文章，顿时受到启发，我也是医疗的，写医疗我也拿手啊。

于是，一发不可收拾，一口气关于医疗的内容，写了几十篇，专门写出了一个系列。

但是，为什么刚开始的时候，达叔不写医疗？

因为，达叔觉得医疗人更缺的，不是医疗内容，而是经济学思维，和投资思维。

包括医生在内的，所有学医、学检验、学器械等医疗人，知识面，太窄了。

达叔学财经的，进入医疗行业，化学名看不懂，也念不顺，每次产品知识培训，都像学天书一样。

但为什么生意做的还可以？

因为我懂一点底层逻辑，万变不离其宗的东西。
