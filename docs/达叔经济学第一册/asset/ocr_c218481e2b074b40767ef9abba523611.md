# 第六篇 FC#6 你与脚下的土地共命运

你能量的源泉是什么？

达叔之前在相关文章里，一直陈述一个观点：你能量的源泉来自于你脚下的土地。

这一点，很多人都没认清楚，比如很多贪官在国内耀武扬威、前呼后拥，一呼百应。赚了很多钱之后，畏罪潜逃跑到美国，基本上就过上了富足且枯燥的生活，与整个美国主流社会脱节，没有了社会关系和朋觉，基本也能干的工作也就是一些不入流的了。

人是社会动物，一旦沦为二等公民，基本也就废了，至少是精神上废了。

比如《人民的名义》里丁义珍，出场时，光彩夺目、意气风发，所有大老板都来敬酒。出逃美国后，想依靠资源再赚钱就难了，被黑社会勒索，沦为刷盘子的。

人还是那个人，但是原来的能量，没有了

这就是个人与脚下的土地，与组织之间的关系，赋能，能量是被赋予的。

但很多人，没有机会进入到这阶段，更多的是一步步攀爬，争取赚更多钱的阶段。
