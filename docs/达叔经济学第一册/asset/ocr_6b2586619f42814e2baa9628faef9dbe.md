# 2

在宣传舆论界，几乎所有媒体，都在鬼喊，房价太高，年轻人压力太大，把梦想都棒干了，把未来都棒岔了。

把房价打棒的方法，有很多种，无论是香港，还是东京，甚至美国底特律，都有腰斩，或彻底崩盘的经验。

学一下，干一票就能救万民于水火，请问，为什么不干？在任何城市，但凡有一个楼盘要降价，都会被当地政府拉出去批评，不懂政治，不懂站位，不够忠诚。

你翻开所有新闻、所有政策，没有任何一个文件，要把房价给降下来，最多就是稳房价，要把房价过快上涨的趋势，给打下来。

把房价一直控制得很低的网红市长，没进庙堂反下野，俺也不知道为什么。

当你想清楚这些，拨开层层烟雾弹，舆论界的言论方向，在学术界和政策界，就是用来争取时间的，都是用来打掩护的。

嘴上说不要，身体极其诚实。

因为房价低，有更大的危险。

房价高的危险，老百姓受点苦，当作为国做贡献了，为家乡做建设了，地铁、医院、高校、绿化、歌剧院等等，美丽城市有你出的一份力。

房价低的危害，地方政府、国家、当地人民，没有一个人，能跑得丁，全都得承担损失。
