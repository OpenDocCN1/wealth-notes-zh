张华考上了北京大学；李萍进了中等技术学校；我在百货公司当售货员：我们都有光明的前途。

所以，《新华字典》，只有在小学的时候用一下，长大就不再用了，有毒。

职业有贵贱。

达叔以前讲过，达叔小时候在农村放牛、很长时间，都以为自己将来能成首富的，为了这个事，从高中开始，还真的谋划过。

别的同学，上体育课、自由活动时跑去谈恋爱、打篮球了。

达叔一个人跑到操场前面的图书馆，把所有商业杂志拿出来研究，尤其是财富排行榜，主要研究两个方向：

+   1、富豪们出自于哪些行业；

+   2、富豪们出自于哪些地方。

达叔上高中那会，IT 类科技新贵还没爆发，富豪主要集中在地产、能源、金融几个领域；地理的分布上，就主要集中在北上广江浙。

掐指一算，上海距离最近，金融中心，考大学就去上海，挑了一个上海的经济类院校，稀里糊涂还考上了。

虽然最后没有从事金融行业，原因和经过在 YL 05 医疗经济学，构建个人发展和投资的方法论，这篇文章里写过。

但心里一直清晰的知道，如果没有金融的加持，一个人或组织，甚至产业，是翻不出什么花来的。
