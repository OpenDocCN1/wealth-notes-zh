# 第四十八篇 JJ#8 如何看待逆全球化？还能好好赚钱么？

这两天，美帝特朗普又发疯 了。

5月14日在接受福克斯电视台采访的时候，口出狂言：如果美国和中国“彻底切断关系”，可以省下5000亿美元。虽然全球除了他之外，没人知道这5000亿是怎么算出来的。

话毕，道琼斯指数在 30 分钟内，急跌 450 点。

随后，美国疑似启动全面针对华为的进一步打压政策，引起全球广泛关注。

全球化结束了么？如何看待逆全球化？

看“逆全球化”，要先看懂“全球化”。

而全球化的概念又要分为两个：“广义全球化”和“狭义全球化”。

广义全球化，是一个大概念，是从发现美洲大陆开始的，长达500年的大历史。

期间发生过无数次的波折，无论是西班牙、葡萄牙的崛起与衰落，还是荷兰、英国的崛起，德国崛起、美苏争霸，全球化，是一种秩序安排。

只要是秩序，就要有维护秩序的成本，这个成本由谁承担？
