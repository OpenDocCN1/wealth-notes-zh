# 第十八篇 FC#17 心口不一的自救者，深圳和天津的两条路

昨天晚上，达叔在书桌前正在写文章，朋友说我带了一些东西，你帮忙给看一下能卖多少钱。

然后，从包里掏出几个大信封和两卷东西，一打开，是一些字画。

外包装上还标着价格，2万-20万不等。

朋友问，你接触的人比较多，这个玩意能卖掉么？

达叔看了半天，问你这是哪来的？

朋友说，自家哥哥是当地小有名气的书法家，一部分是哥哥给的，一部分是别人送给当地官员的，流到我手里了，看看能不能变现。

达叔问，你手里的那个医疗设备市场价多少钱？

朋友说，大概一台20万。

达叔问，你能搬一台送给地方官员，说是送了20万么？甚至说是10万，会不会挨打？

朋友说，会挨打。

很多东西的价值，只有在圈子里，才会被认可，一旦出了圈子，就啥也不是。

比如这个字画，比如医疗设备，甚至不同城市的房产价值，个人的工作能力，亦是如此。
