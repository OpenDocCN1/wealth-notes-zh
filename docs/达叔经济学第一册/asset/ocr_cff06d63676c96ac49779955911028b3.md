# 第四篇   FC#40 中国的房地产税已经试点征收十年了

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

昨晚写完文章，《药械十年》小说 0060 不动公司的钱，不动公司的人，尺度有点大，达婶过来审稿，把结尾修改了一些，让变得更温和一些。

达婶说，你别这么刺激，读者会对你们这个行业联想不好的。

达叔说，不是我们这个行业有问题，而是各个行业，都有这些问题。

只是穿制服的行业，比如公检法系统、金融银行系统、空姐、医疗，穿上了制服，有了更多的新闻价值，仅此而已。

达婶说，你这个故事，有原型么？写成这样，人家看到了，会骂你的。

达叔说，我的小说里，所有故事都是深加工的，都有一点原型，但都是错乱的，这位许姑娘，不会看到我的文章了。

达婶问，为什么这么肯定？
