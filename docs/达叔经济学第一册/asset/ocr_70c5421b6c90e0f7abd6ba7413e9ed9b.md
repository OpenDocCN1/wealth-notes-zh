# 未来二十年的机会

无论从哪个角度，全球各大智库对中国的分析，中国经济增速、城市化进程还有 20 年的机遇期。

我们所遇到的任何一个困难，不要激动，不要盲目跟风，沉下来思考一下，比如这次新冠疫情是一个什么性质的困难？中国的楼市是一个什么样的资产发展？

+   一、是节奏问题还是结构问题？
二、是周期问题还是趋势问题？
三、是局部问题还是普遍问题？

疫情会打断中国的城市化进程吗？大概率是不会。疫情会打断中国的经济增长吗？大概率也不会。疫情会改变土地财政模式、纸币发行的温和通胀么？更不会。

那么，我们应该一手研究自己所在的行业努力充实自己的现金流，一手研究自己脚下的土地、自己所在的城市性质。
