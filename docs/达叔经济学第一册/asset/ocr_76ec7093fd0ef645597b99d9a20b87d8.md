# 什么是大事？

这是一个价值观的问题。

比如，很多姑娘认为买包是大事，男生给买包就是 真爱，要存钱买房，就是渣男。

在农村，花三十万办个盛大婚礼，一顿胡吃海喝， 越风光、越给长辈长脸，越是大事，要是想留着付个房 子首付，那就是不孝。

地方政府，也是如此。

有的政府卖地，成立基金投资、孵化高科技公司， 去赌一把试试。

有的地方政府，卖地之后，有钱了，去修几个关公 耍大刀，去修个奇怪的风水楼阁。

今天遇到的三波人，都在各自追寻自己的大事，都 在未来要增值，都在用今天去战斗。

每个人聊起自己的项目，都是极其忘我，极其狂 热，恨不得与天地同寿。

三个人，在同一天，不同的时刻，拍着胸脯和达叔 说，我这个项目，太牛逼了，放眼望去，没有敌手。
