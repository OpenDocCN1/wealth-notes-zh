+   1、达叔之前的文章里曾经说过，楼市比股市要公平的多，楼市里最大的庄家 是政府。

这个庄家为了要继续高价卖地，不会砸盘，土地是一级市场，楼市平稳上涨，最符合地方政府的利益。

你买了这个城市的房子，就是买了这个城市的股票，享受这个城市的红利，你屁股就坐在了庄家这一侧，对面的都是空军。

+   2、在部分限购、限价严重的城市，比如杭州、南京等，出现万人摇号的宏大场面。为什么？因为一二手房价倒挂严重，一旦摇中，就相当于地方政府送了上你上百万。

这比买彩票都刺激，买彩票还要花钱，而摇号几乎不用，只要动脑筋，就有资格。

+   3、这个摇号有漏洞可以钻么？以前有，现在达叔能保证的是，上海、杭州、南京肯定是没有，没人敢顶风作案。

有漏洞可以操作的城市，都衍生出了茶水费、号头费等一系列灰色地带，每一楼盘，都遣富一批新贵。
