# 第二十三篇 FC#22 以《资本论》架构、土地视角，分析一下欧洲和中国

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

今天，是南京大屠杀的纪念日，满朋友圈都在纪念这一个特别的日子。

昨晚写的 FC#21 这一次的屠杀静悄悄，被屠刀屠杀的生命值得纪念，被纸币屠杀的生命，也应该值得纪念。

但是，很多人意识不到，这种静悄悄的屠杀，是在剥夺生命权。

为什么意识不到？

因为时间跨度太长，逻辑链太长，看不清、看不懂，就当做成不存在了。

所有人，在年轻时所做的劳动，如何把这些劳动成果储存下来，保值、增值，在晚年，丧失劳动的时候，进行变现，支付医疗。

这一个过程，就是生命权。

别人生病，有钱治疗，能多活几十年。

你一生的劳动剩余没有完成积累，没钱，挂掉，这一切，就是被剥夺了本该属于你的生命权。
