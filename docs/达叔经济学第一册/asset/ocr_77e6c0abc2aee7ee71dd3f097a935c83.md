# 规模的意外。

历史上，发生过好几次意外的事件，每一次都导致 了规模的错配，最后引发新的抢劫。

有一个姓马的说过，他弄了一个什么宝，在于的那 一天开始，就想清楚了，只要国家需要，随时随地，都 可以献给国家。

其实，当一个产业，规模大到一定程度的时候，不 是你献不献的问题，而是必然要被抢的问题。

但凡，一个产业还没有被抢，那是因为你太小，没 有被抢的资格，导弹炸茅厕，不值得。

两千年前，经济制度和政治制度，也是相互匹配 的。

在政治上，皇权之外，还有相权，皇室和政府，是 分开的。

在经济上，赋税制度与之对应，全国的农田租入归 政府性收入，收钱的人叫大司农，这是大宗收入。

而山海池泽，这方面的收入，专供皇帝私用，收钱 的人叫少府，这部分钱是少数。

但是，一个奇怪的事情，发生了。

经济慢慢发展之后，人口暴增，盐铁之利大增，本 来占小头的山海池泽，收入开始大于全国田租。
