# 第十七篇 FC#16 不懂就是不懂，即使他职位再高，说的也是错的

达叔几年前，时间自由，工作之余，在上海某学校教了两年《经济学原理》。

面对一群群懵懂的少年，每次在第一节课，和最后结业，达叔都会提醒一句，你们所听的，可能都是错的。

你们还很年轻，不要轻易迷信任何人、即使他是你的老师，他是你的领导。

经济学，是一个非常年轻，内部学派相互打架的学科。未来步入社会，面对的社会学，亦是如此。

正确的，未必有用；有用的，未必正确。

人，要对自己负责。

M 总，是达叔接触过最有能量的领导者，极具领袖气质。

在 500 强公司，先后两家都待了十几年，前一个做到了中国区总监，后一个担任中国区总经理，年收数百万。

但长期以来，一直坚定的认为中国房产存在泡沫。
