# 第三十四篇 SK#140 流水不争先，争的是滔滔不绝，一周年记

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

周末连续两天网上，现实踩点，在给父母寻找能照顾失能老人的养老院，前几天不舒服，导致左眼有点感染，像兔子一样，昨晚就没写文章了。

顺手接了一个广告，就学会了连发两篇文章，把星哥对达叔的投资，顺便也发了一下。

不出意外，就有读者，在后台给达叔留言，你这货不是刚吹完牛逼，不接整版广告，要讲一千零一夜的故事，你怎么解释？

不解释，就是牛逼吹大了。并且，学会了一天发两篇的技能后，达叔猛然发现，恰饭和日更，竟然也并不冲突。

今天眼睛没好利索，缓解了一些，达叔提醒俺，今天是您账号的一周年生日，你可得写一篇好文。

她一边说，一边在厨房切莴笋，达叔站在旁边问，什么样的文章，叫做好文章？你想看啥样的？
