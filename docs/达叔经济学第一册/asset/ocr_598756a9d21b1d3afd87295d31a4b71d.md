# 第五十二篇 JJ#12 大萧条来了，一批人失业，一批人崛起，他们的区别是什么？

新冠疫情导致的全球动荡，看样子，一时半会是解决不了了。

东亚地区基本控制住，欧洲也在逐渐缓和，北美人民忙着游行，仿佛新冠已经被忘记了。

北半球的夏天已然到来，南半球即将进入冬天。

拉美、非洲等第三世界的疫情即将上演。拉美和非洲的社会治理以及医疗水平，面对新冠，基本上躺平，真的要靠上帝了。

如果南半球和北美控制不住，那么全球经济在新冠阴影下，冬天夏天一轮，就又是一年，新冠在很长时间内，都要和人类共存了。

直到一年以后，疫苗被研发出来，再过一年，逐步完成接种。

如果是这样发展，全球经济中，东亚保全自己，已然非常艰难。

大萧条来了，达叔本篇来探讨一下，历史中的大萧条，普通人是如何被收割，又是如何崛起的？

对世界的认知，什么是本质，什么是假象。
