# 父辈的阴影。

达叔以前看到富二代交接班和商业故事，都没太当真。

上次晚上出门遛弯，听到戴老板讲投资的案例，讲了他一个同事，突然就动情了。

达叔就自己琢磨，这种转变，是为啥？

应该是自己的女儿，慢慢长大了，很多道理，时间不到，是不会想清楚的。

戴老板说他的同事，搞基金投资的，长期研究能源矿产领域，俩人经常在黄浦江边，喝着啤酒吹着牛逼，聊理想。

一个做大宗商品，一个做能源矿产。

同事干的好好的，突然一天，就提离职了，晚上和他道别。
