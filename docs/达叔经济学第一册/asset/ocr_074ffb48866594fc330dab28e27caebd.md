# 第二十八篇 FC#27 新春假期，如何与烧钱的父辈好好聊

天

大家好，我是达叔。

一个想和大家一起慢慢变富的家伙。

每次过年，达叔的心情都非常沉重，一方面是假期打断了达叔的工作节奏，另一方面是要见很多人，看到的很多是每况愈下的人生，很悲伤。

这两个沉重，很多人是体会不到的，比如你不是工作狂，你就不会被假期困扰；你不对生活百态敏感，不对家庭财富选择敏感，你就不会对别人悲伤。

所以，每次放假，达叔都想在家里宅着，看点书，喝点茶，哪都不想去。

但是，领导权在达婶手里，去哪，见谁，得听安排，所以每次放假，都会看到一些故事。

以下内容，不一定正确，各位随便看看。

+   1

舅舅。

达婶带达叔去见了她的大舅，一个患了严重肺病的老人，现在每天要吃很多药，已经基本丧失了劳动能力。

达婶感慨，这个大舅是她小时候，整个家族里，最有钱的，自己家里如果实在缺钱了，基本上都是向这个大舅借。
