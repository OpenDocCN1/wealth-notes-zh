# 第十五篇 SK#63 一个草根是如何爬起来的，关于成长和投资的一点思考

今天的文章会写一点达叔对成长和财富的思考，仅是个人经历和感悟。

不熟，不做。

这个道理，看着十分的简单，但是很多人不交一遍学费，就永远不知道自己的边界。

好多年前，达叔在上大学的时候，有一天，某学弟兴冲冲的跑到达叔宿舍，说在网上一批运动鞋，价格非常便宜，50 块钱一双，总共有 600 双，要不要做？

算一下账，50*600=3 万，达叔和学弟还有另外一个同学，每人凑了一万，去淮海路把货给拿了。

那一年，达叔二高。

鞋子是耐克，是高仿，肯定不是真货，这我们三个心理都是有预期的。看着质量挺好，觉得拿回来，卖 100 块一双，1-2 个月翻一倍，是肯定没问题的。

为什么这么自信？

因为达叔当年在学校也算是一个小小的风云人物，搞校园旅游等，能调动的资源还是挺多的，掐指一算，能覆盖三个大学城，十几万的潜在客户。加上觉得运动鞋这个东西是个刚需，就把货给进了，连价都没讲。
