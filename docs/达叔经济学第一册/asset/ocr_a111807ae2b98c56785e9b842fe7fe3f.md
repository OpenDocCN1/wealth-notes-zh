# 重庆地票制度。

在讲重庆地票制度之前，要先回答一下前面的问题，重庆的房价为什么这么低？

坊间有很多传闻，把这个归功于某个市长多么厉害，能化腐朽为神奇。

在舆论界，成为了网红市长。

如果这位网红市长真的那么强，为什么正是当打之年，不进中央，却被“流放”了？

封疆大吏，用个人的智慧，解决了全国人民的住房难、住房贵问题，难道不该加官进爵，去拯救全国人民么？

可惜，不能。

价格不是由某个能人决定的，价格是由供需决定的，任何违背经济规律的行为，都会被啪啪的打脸。

重庆的房价低，是由重庆天量的土地供应量决定的。
