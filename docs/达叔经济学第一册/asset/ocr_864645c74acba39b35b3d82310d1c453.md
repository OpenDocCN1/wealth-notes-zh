# 为什么？

觉得 50 块钱一双，很便宜。

卖家是一个住在上海淮海路，老破小，一个女的，浓妆艳抹。

这批货是他一个朋友的，鞋子堆在她的房间里，除了床，全部堆满了。等达叔再长大一些，推测这应该是一个性工作者，鞋子是她一个客户的。

中间有很多的故事和艰辛，在这里就不展开了，除了直销之外，达叔慢慢发现，好像掉进坑里了。

+   1、鞋子是有尺码的，好销的尺码卖的较快，越到后面，偏大和偏小的尺码，滞销了，这一点，年轻时代的达叔，竟然没想到，绝大多数的生意人，最后都是死在库存上。

+   2、开始做分销。发现同样是学生，隔壁一个同济的，研究生，比达叔大 4 岁左右，明显工作就做的很扎实。

他过来看了一下产品成色，达叔当时给他的报价是 60-70/双，他回去做了 3 天的调研，告诉达叔，你手里的货价格大概在 15 元/双。

这种震撼，好多年过去了，一直深深印刻在达叔的脑海里，达叔本能的反应，就是觉得这个家伙是个骗子，是杀价的策略，完全不相信。

这个同济的研究生，一脸怜悯看着年轻的达叔，问，你的拿货价是多少？我把研究的路径和你说一下，你研究一下是不是拿高了。
