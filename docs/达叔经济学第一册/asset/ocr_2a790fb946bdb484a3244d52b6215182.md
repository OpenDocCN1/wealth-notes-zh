# 上海房价。

达叔指着包厢窗外，一个破破烂烂的老小区，问几个主任，你们觉得这个房子，多少钱一平米？

几个主任，猜了几个数字。

达叔说，具体的我也不知道，我用链家看看谁猜的准啊。

打开一看，均价 8 万/平米。

大主任把筷子一放，就开始大骂房价泡沫，太特么贵了，然后就是一顿房地产拖累中国经济等言论。

达叔在那边笑着问，你在省会有几套房子？

大主任说，有两套，一套自己住，还有一套近期正准备卖，2016-17 年那一波涨幅，直接翻了一番，泡沫太大，准备抛了。

达叔说，我在你们那边出差，除了做业务，还研究你们那的楼市，你要是想卖，咱俩可以聊聊啊。

大主任问，你不觉得有泡沫么？涨了那么多。

达叔说，之前涨了多少，那是你感受到的，未来还能至少再翻 1-2 倍，是我看到的。

在座的各位主任，你们的身家未来都能破亿，即使年龄大点，好好操作，也能破 5000 万。

几个主任，齐刷刷的把筷子放下，直勾勾的看着达叔。

达叔知道，上课时间到了。
