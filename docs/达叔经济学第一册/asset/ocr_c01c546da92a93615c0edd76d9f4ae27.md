# 第二篇 FC#2 美股暴跌，会影响中国的房价么？

# 一、美股连续发生熔断，和疫情有关系么？

肯定是有关系，但疫情只是一个小小的导火索。

我们不能把第一次世界大战责任都推在萨拉热窝上，对结构性矛盾视而不见。

换而言之，即使没有这疫情来捅破吸了十年的泡沫，几乎所有人的预期美股无以为辅，最多坚持到大选之后。

在疫情的加持下，出现熔断，且多次大幅度下跌，国运已尽的象征。

当中国发生疫情的时候，A 股和全世界的股票稍微波动、比较稳定，说明世界对中国控制疫情是充满信心的。

但按照欧美目前这个装焦作哑的尿性，能通过媒体骗得了普通民众，可骗不了掌握真实数据的大财阀。金融的涨跌本质是对未来的预期，目前来看，只有越演越烈的趋势，继续发生金融踩踏也是正常的。本来一个预计大选后软着陆的事，活生生被一个蝙蝠给搅黄了。

# 二、会影响中国房价吗？

会。
