# 第四十九篇 JJ#9 大人，钱都会被吹牛的人赚走了！

达叔本来想起的标题是《你以为你以为的就是你以为的么？》。

想了半天，太绕了，大家应该不会喜欢。

关注这个号的应该还是喜欢，简单粗暴的。

上海虹桥那边的国际会展中心附近，达叔今天过去见个朋友，他过去做副总了，打电话让一定过去一起坐坐，和他大老板一起聊下。

上午十点，到了一楼大傣来接。

气势恢宏，整个园区，两栋高大的写字楼，都是自己公司的。

先由副总和两个秘书陪着，逛了几层展厅，各国产品，机器人之类的。

大老板到了，聊了个把小时，达叔还有别的安排，就先撤了。

下楼的时候，看着满墙的荣誉证书，不由感慨，太能吹了。

这里里面绝大部分都是一口一吹出来的。

很多人都不喜欢吹牛，甚至认为吹牛的绝大部分都是骗子。

为什么？
