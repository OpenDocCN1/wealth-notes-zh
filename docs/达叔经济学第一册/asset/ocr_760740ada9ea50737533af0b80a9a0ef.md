# 第五十三篇  JJ#13 不忘初心，什么才是你该关心的经济学

有几个读者给达叔发微信，说达叔你写的文章有点特色，很少写宏观的事。

这就是属于特别聪慧的读者，在读文章的时候，还在动脑子，会总结，懂辨别。

在中国，太多人天天关心中美关系、中东局势、石油价格、华为制裁，这些和你有关系么？

上知天文，下知地理，世界局势，尽在掌握，就有一条，不赚钱。

这是穷病，是一种知识吗啡，把有限的脑容量，挤占了，浪费了。

你看的，都是人家想让你看到的，它既不是真相，甚至也不是假象。就是一段操纵你情绪，让开心、让你愤怒，塑造你价值观的道具。

静下心来，关心一下自己的家庭，自己的钱包，别天天自嗨。

达叔平时脾气不太好，但开始玩自媒体之后，见识了更多的网友之后，经常把达叔给气笑了。

有一个家伙，曾经给达叔留言：你懂个啥经济学，现在什么世道，怎么啥人都来说几嘴经济学。
