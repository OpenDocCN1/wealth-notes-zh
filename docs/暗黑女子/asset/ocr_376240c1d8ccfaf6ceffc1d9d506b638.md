# 小說。

為了接近老師，我決定讓文學社復活。社團必須至少有兩名成員，學院方面才會核准，所以我讓小百合也提出了入社申請。

雖然現在文學社的成員增加了，但起初只有我們兩個人而已。文學社剛復活時，老師為了我和小百合兩個人熟切地談論文學，並要求我們寫散文、詩和短篇小說。

我寫了熱情洋溢的情詩在老師面前朗讀，在讀書會時，挑選了杜拉斯的《情人》等情慾小說做為主題。他漸漸發現了我對他的感情，最後，我終於不是以學生的身分，而是做為一個女人和老師結合了。

「這次真的很開心，太好玩了。」

「妳和老師有時間相處嗎？」

小百合當然知道所有的事。

「嗯，我有時候會從寄宿家庭溜出來，去他住的飯店。」

「太好了。」
