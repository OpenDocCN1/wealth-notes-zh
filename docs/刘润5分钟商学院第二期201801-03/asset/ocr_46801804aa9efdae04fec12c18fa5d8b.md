# 087 | 设计冲刺（草图）：用前人的智慧，解决今天的问题

每天5分钟，解决一个商业问题。欢迎收听，《刘润5分钟商学院》，实战篇。

设计冲刺第一天结束后，萨维公司已经有了四样东西：目标、问题、地图、和写满“我们应该如何”的便签纸。

目标：更好的住店体验。

问题：1）流畅的递送服务；2）方便的机器人互动；3）为机器人而再次住店的吸引力。

地图：从前台到房间，再回到前台的“机器人递送地图”。

“我们应该如何”的便签纸。

那么，然后怎么办？

开始头脑风暴解决问题方案吗？不行。因为“凭空”头脑风暴出来的方案，通常质量不高。为了提高方案质量，我们还需要一件威力强大的武器，那就是：前人的智慧。

其实，在不同领域，同样（或者类似）的问题，可能早就被前人很好地解决过了。

# 概念：设计冲刺（草图）

第一，列清单。

请每个成员，都列一份可以得到灵感的产品清单。比如，Uber打车软件，也许可以获得解决“服务高峰低谷问题”的灵感。列完清单后，大家可以破例使用电子设备，研究清单上的产品。

第二，3分钟演示。

找完灵感后，每个组员花3分钟介绍，他找到的产品有什么亮点和参考价值。这一部分也可以用电子设备，比如电脑。

第三，记录重要的启发。

在白板上，记录下给大家启发的亮点。数量控制在10-20个左右比较好。

经过这三个步骤，我们就终于集齐了设计备选方案的全部5大素材：目标，问题，地图，我们应该如何，和前人的智慧。

# 今日得到：

+   1. 什么叫草图？就是通过固定流程，获得大量、多样的方案，再从中选出最可行的。\n2. 具体怎么做？上午通过“闪电之旅”，从前人的智慧中获得启发，下午通过“四步绘图法”，画出自己的备选方案。记住，不要偷看别人的方案。第一印象只有一次，我们把它留到明天。\n3. “草图”的一个核心，其实是学习“前人的智慧”。不论做什么事情，都要问问有没有人已经做过了，前人的经验和教训，会让我们少走很多弯路。
