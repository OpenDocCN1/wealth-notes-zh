# 为什么要举办线下大课？

在5分钟商学院的线上课程中，我们用65期的内容，十几万字，讲了行为经济学、流量、品牌等等，透彻理解用户的内容。

这将是一堂无删减版的线下大课。

一切商业的出发点，都是消费者获益。

到底消费者是谁？他如何思考？他需要什么？他是如何决策的？

价格是第一重要的因素吗？满足用户的功能需求更重要，还是满足情感需求更重要呢？不同社会背景的人在做决策的时候有什么不同？家庭因素会不会对一个人在做决策时有很大的影响？

人与人之间的比较，会不会是选择一些产品时真正的潜在原因？我们如何能够抓住这些潜在原因给客户做分类，然后找到真正的，他没有说出来的那些需求？我们如何能够知道消费者属于什么样的决策类型？抓住消费者的决策流程，在一些关键点上能够助推他的选择，我们如何能够让他喜欢上我们的产品？

它最大的价值是希望大家在做一切产品之前要彻彻底底全方位地了解最终买单的这个人。为他花再多的时间都不为过。

5分钟商学院在2018年有个小目标，就是实现立体化运营，线下课程就是其中非常重要的一环。预习一下这些已经被你收入兵器库中的内容，对线下学习非常有效。我在这里为大大家画出了几个关键词：行为经济学、语义效应、确定效应、心里概率、反射效应、鸡蛋理论、比例偏见、锚定效应。我建议你参加大课之前，做好预习工作，现场会有惊喜。

这次的大课，我们依然会开放稀缺的“私享会”环节，针对你的问题，提出建议。

最后，期待和大家线下相聚，也希望通过线下大课，能给5商的同学们提供一个彼此结识交流的机会。
