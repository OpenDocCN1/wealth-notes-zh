# 三、团队和融资

咱们专栏第四季度的课程中会花很大篇幅来讲团队建设的问题，在这我先简单说说。

首先，你一定要有能力互补的合伙人。比如你是有建筑背景的一个创始人，那么你可能至少得有一个懂孩子、懂教育、懂母婴产品市场的人，他会知道销售和渠道的很多问题，和他一起你就能避开很多坑。另外，你还得有一个懂技术、懂产品的人，比如以前做过玩具的人。这样你们三个人在一起，成功的可能性就会大一些。

另外，投资方面，关于投资的天使轮、A轮、B轮等等的融资逻辑，咱们课程的第三季度中会讲得很清楚，今天我们先不说太远，只说第一步：拿你的想法不断去找身边的有经验的人士，跟他们聊，看看他们对你的想法是不是感兴趣，有没有人愿意给你第一笔启动资金，也就是所谓的天使投资。天使投资最重要的目的是把这个东西启动起来，把第一个产品原型给做出出来。拿到原型之后，你再推销到家庭中去试用，收集意见反馈，继续做调整。

这个阶段你可以验证两个很重要的问题：第一，你们团队是真的靠谱，还是origin一时兴起，靠谱的人才能真正做出口东西来；第二，你做出的东西是不是真的有价值。

好，以上就是我对于这个问题答案，这位同学可以再结合咱们的课程内容多做一些思考。总之，我认为父爱产品这是个很好的想法，如果你下定决心了，就希望你能勇往直前，做出好东西，祝愿你创业成功。
