# 建议：

针对人群多为等待客群或临时消费群体，类似火车站、汽车站、银行等等。

根据企业年龄层、男女比例、饮食习惯等调整，真正能满足需求。

提前为企业提供好一系列的解决办法，如：摆放可选择接待室或等候区，消费群体多元化；利用食品安全协议书，对食品管理体现专业化，从管理走规范化。

做成企业的文化、终端消费的同时，企业从中能体现什么价值，商家与企业成为利益的共同体，这样企业有价值，服务跟上，安全保证，企业会作为文化宣传。产品去平均化，服务管理规范化，价值差异化。

你的问题有三个层次：

首先我觉得先有了需求痛点，再进行创业才是更合适的逻辑。现在再来反思需求痛点，来调整来吸引目标客户可能有一点难，但是有没有另外一种可能，可以调整目标客户呢？我不太清楚无人货架为什么要跟企业的基层管理者或者领导谈，是要放在公司内部吗？你的盈利模式是如何的？是通过销售货物利润分成还是卖货架呢？我觉得你的最终客户就是CBD里面上班的人，只要能够让货架放在职员接触到的地方都是可以谈的，为何不跟物业谈呢？他们负责管理办公楼，让这些货架作为物业其中一项服务不是更好吗？可以在每一层的公共位置放。不单单可以跟CBD的物业谈，还可以跟居住的物业谈，拓宽货架的使用场景，只要销售的货物不同就好了。关于无人货架能够满足什么需求痛点，我们除了目标客户之外，还得思考到底是解决现金流、物流、信息流的什么问题？其实我觉得可以考虑除了差异化供应货物之外，鉴于现在货架覆盖面挺大的，还可以跟天猫超市之类的合作，展示天猫超市的爆品，然后跟天猫分成。我觉得电商和无人货架可以实现互利共赢，除了可以稍快速度买到货架里的商品外，无人货架的优势并不明显。

我们公司共10层楼，每一层都有两个零食货架，每一次零食货架上新后，一周之内就基本卖光。因为加班比较多，我也是零食货架的重度消费者。在此提供两点建议：

+   1. 零食货架相比较于电商、便利店，最大的特点是购买行为在公司内部完成，从公司的角度看，这种方式可以节省员工外出购买零食的时间，提高员工的工作效率；从员工角度来看，在工作、加班的时候可以有零食吃，可以提高工作的幸福感。因此，可以多在文案做文章，把零食货架打造成公司与员工沟通交流的一个桥梁，成为一种员工日常福利。可以与企业的行政部、企划部合作，为企业打造个性的对员工感谢、激励文案贴在每个产品的包装袋外侧，体现企业关怀，比如：“加班工作辛苦了，吃袋薯条放松一下”。还可以每月推出特价零食，这部分零食，企业承担一半的费用，员工只要付半价就可以购买。这样，员工和企业通过小小的零食货架实现更好的互动，达到企业、零食货架供应商、员工实现共赢的局面，相比较于其他零食货架也更有竞争力。

+   2. 从我们办公室的零食货架看，最大的问题是补货不及时；从提升用户角度出发，可以通过多增加一个摄像头的_projects，每天轮询每个货架来解决这个问题。
