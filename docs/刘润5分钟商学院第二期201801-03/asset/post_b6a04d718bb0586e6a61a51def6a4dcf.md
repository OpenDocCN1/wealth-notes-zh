
# 084 | 未来设计：未来，不懂科技就不懂设计

![](img/6b086af319379c0fa7ce76dc48c3f1a1_49_0.png)

每天5分钟，解决一个商业问题。欢迎收听，《刘润·5分钟商学院》，实战篇。

我有个朋友，是某著名家电企业洗衣机部门的设计师。老板让他结合今天的科技，设计一款更现代的洗衣机。他绞尽脑汁，在洗衣机背后插了根网线，让家庭主妇在洗衣服时，可以看电视。结果被老板痛骂。他很痛苦，也很委屈：好好的洗衣机，非要高科技，有必要吗？怎么办？

要解决这个“怎么办”的问题，我们首先要理解它的本质。这个问题的本质是，未来、甚至今天的设计，已经越来越多地基于快速进步的科技。不懂科技的设计师，不是好设计师。

为什么设计师必须懂科技？我举个例子。

一位设计师想设计一款商旅人士随身携带的音箱。当然要音质好，当然要能用蓝牙与手机连接。然后呢？然后做得好看点。再然后呢？再然后包装得精美点。再再然后呢？再再然后……就没有然后了。 一位传统设计师，也许只能设计出越来越好看的音箱。

商旅人士对便携音箱的需求之一，是把自己从手机上解放出来，在酒店房间，能无拘无束地开电话会议。“这做不到，距离太远说话就不清楚了。”真的做不到吗？如果想在远距离，任何方向，都能把声音清晰地传达到对方，就需要一种叫做“麦克风阵列”的技术。

这种技术，在小小的音箱里，全方向配置了7只麦克风，同时收音，然后通过强大的软件技术，声源定位，增强语音。这7只麦克风的摆放，尤其是软件系统，是设计的核心。

这，就是现代设计。

![](img/6b086af319379c0fa7ce76dc48c3f1a1_49_1.png)

开完会后，我还有个需求，就是把5个人的激烈讨论，自动转化为“张三说了什么”，“李四说了什么”的会议记录，发到我邮箱，可以吗？

当然可以。你可以设置自动录制会议，会议录音会自动传到云端，转为文字，然后根据声纹特征的不同，加上张三、李四的标签，生成一篇完整的会议记录。

# 概念：未来设计

这，就是未来设计。

那我这个朋友，可以怎么设计这款洗衣机呢？

过去，我们的衣服上都有个小布头，上面记录着衣服质地，能否水洗，洗衣水温等。今天，有种新技术，叫做RFID（射频识别技术），你就把它理解为一个不用插电，不怕水的小线圈，把它缝在那个小布头里，就可以记录有关衣服的一切信息。

然后在洗衣机里，装上RFID的识别器。你把衣服往洗衣机里一扔，“嗒”地一声，洗衣机就知道你扔了什么衣服。

我如果扔了件白裤子，又扔了件红衣服，洗衣机会提醒我，这两件衣服不要一起洗，会串色。

然后我就把红衣服拿出来，先洗我的白裤子。这时，我的洗衣机会告诉我：这条裤子已经洗12次了。最近这个品牌在打折，要不要买件新的？

我买了两条新裤子后，又把我的西装扔到洗衣机里，这时它告诉我：西装不能水洗，离你家500米有个干洗店，洗这套西装只需39元，你点“确认”按钮，干洗店的小帅哥，就会在15分钟内上门，取走这套西装。

太神奇了。那我怎样才能具备这种“基于科技的设计能力”呢？

今天的设计，是让冰箱在达到设定温度后，自动停止制冷。“有增强作用的智慧型冰箱”会对你说：“对不起，你不能再吃鸡蛋了，除非你的血脂下降，体重下降。体重计告诉我你还要再减五公斤。几次的体检报告都说你的血脂过高。我都是为你好。”

# 085 | 看比赛：马斯克为什么要花1亿美元送一辆特斯拉跑车上太空？

每天5分钟，解决一个商业问题。欢迎收听《刘润·5分钟商学院》，实战篇。

北京时间2018年2月7日凌晨4:45分，由埃隆·马斯克（Elon Musk）的SpaceX公司研发的人类现役运力最强的火箭——“重型猎鹰”（Falcon Heavy）成功发射，并完成了一级火箭的回收。这枚火箭携带着一辆樱桃红特斯拉跑车，跑车上坐着一位假人驾驶员，车上还放着大卫·鲍威（David Bowie）的成名曲《太空怪咖》（Space Oddity）。这辆特斯拉的目的是火星轨道，如果一切顺利，它会在宇宙中行驶10亿年。

![](img/6b086af319379c0fa7ce76dc48c3f1a1_50_0.png)

哇，一辆在火星轨道上行驶的跑车，这也太酷了吧。但马斯克做这件事情可不是为了酷，他的重点在火箭的回收上。今天的看比赛，我们就一起来看看，火箭回收这件事情背后有什么商业逻辑。

首先为什么要发射火箭和回收火箭？发射火箭本身不是目的，火箭只是一个运输工具，发射火箭是为了把它携带物送入太空，比如载人飞船，比如航天站，比如目前最有商业价值的人造卫星。

人造卫星有什么用呢？人造卫星的用处就多了，比如天气预报，比如无线电通信，比如你手机上每天都在使用的 GPS 定位，比如今天很多航空公司在飞机上提供的无线网络，它不是来自于地面的基站，而是来自于人造卫星。

据统计，截止2017年，我们头顶上，约有1500颗在轨运行人造卫星（现役卫星）。而 SpaceX计划在2024年前通过猎鹰9号火箭发射4425颗小人造卫星。

那发射人造卫星这件事，过去的商业模式是什么？大部分人造卫星，都不是属于火箭公司的，火箭公司是运输公司，只负责把卫星公司的人造卫星送到既定的轨道。在过去，发射一个人体卫星后，火箭就报废了，不是坠入大气层被烧毁，就是变成了太空垃圾。所以卫星公司想要发射人造卫星，他首先要“买”个火箭，然后还要付一笔服务费，请火箭公司来发射。这种商业模式叫做“买”。

这就像什么呢？这就像你每次运输货物的时候，都要买一辆新车，然后再花钱请一个司机，开车把货物送到目的地，送到之后再把这辆车扔掉。所以你其实要付两笔钱，一笔是买车的钱，一笔是司机的服务费，这个成本是极其昂贵的。

那有没有一种可能性，就是司机的服务费我照付，但是能不能不要每次都把车扔掉呢？这也太浪费了。每次送完货之后，把车开回来，下一次送货的时候再用行不行呢？

这就是今天 SpaceX 正在尝试去做的事情：回收火箭，进行再利用。过去因为技术的局限这可能做不到，但是今天随着科技的进步，让我们有机会可以做到了。一旦实现火箭的回收再利用，那发射人造卫星的价格将极大降低。

2015年12月22日，SpaceX 发射了猎鹰9号火箭，在把11颗通讯卫星送入轨道后，成功回收了一级火箭。这是人类历史上首次让火箭载荷发射后安全返回地面。以这次猎鹰9号为例，它的单次发射成本为5400万美元，如果火箭回收技术变得成熟，发射费用就有可能降低到每次600万美元，这相当于把发射成本降低到了原来的1/10。

于是发射火箭的商业模式就从“买”变成了“租”，从买车送货，变成了租车送货，

我们都在赞叹 Space X 的技术进步，但其实现马斯克真正的了不起之处，在于他被称为“第一性原理”的商业思维。在成立 Space X 的第一天，这家公司的商业逻辑就极其清晰：

+   1. 通过回收火箭的技术，把传统商业卫星的交易结构，“变买为租”；
2. 从而把发射卫星的成本降到原来的1/10；
3. 用极低的成本碾压全球火箭公司。

腾讯是非常有用户思维的公司，微信是个非常有产品思维的产品，但微信真正打败中国移动的短信，靠的不仅是用户思维和产品思维，而是交易结构思维。它使用了一种“你收费用，那我就免费，然后去赚别的钱”的交易结构，颠覆了传统生意。

当然，但距离真正实现“变买为租”，马斯克还有一定的路要走。这次“重型猎鹰”的发射，成功完成了两枚一级火箭的回收，但是芯级火箭（指在中间的主推进器）坠落在太平洋，没有成功收回。将火箭回收技术商业化还需要更多的努力。但无论如何，这次“重型猎鹰”的发射，都是航天史上的一个重要的里程碑。

# 第17周周末私董会 | 如何帮一款国产产品走向国际化？

第17周周末私董会 | 如何帮...

每天5分钟，解决一个商业问题。欢迎收听《刘润•5分钟商学院》实战篇。

5分钟商学院的同学们，大家周末好！

本周获得私董会提问资格的同学是：伊春莺歌。

创业三年，我从小兴安岭原始森林采集自然蜂蜜，首创自然结晶洞藏技术，做出了可以嚼着吃的蜂蜜品牌“洞藏雪蜜”，不仅获得了《舌尖上的中国》总顾问沈宏非的称赞，还被China Daily报道得到欧洲皇室关注。现在我手上已经有了这款打磨好的产品，请同学们指导，我希望对标国际一流品牌做国产传统食品，现阶段应该进行哪些方面的布局，如何更好地组建一支团队，一步步实现国产蜂蜜品牌的国际化呢？求您高见。

刘润

首先我要对伊春莺歌表示祝贺，祝贺她有一款不错的产品，受到了《舌尖上的中国》的沈宏非的认可，而且已经在考虑国际化了，我们在第一季里面也用她的蜂蜜做过奖品。

另外，我也祝愿《5分钟商学院》能成为她和未来合伙人梦开始的地方，因为《5分钟商学院》确实是一个能人辈出、高手如云的地方，希望她能在这里搭建一个不错的创始人团队。

然后我们来谈谈伊春莺歌提出的这个问题：如何把一个国产品牌做到国际化。

在我看来，这个问题其实不应该称作一个问题，而是课题，因为这个问题太大了。怎么实现国际化这件事，我觉得写个二十本书都未必能写得清楚。所以在留言里，我也看到了同学们来自各角度的建议，这些建议对于“如何实现国际化”这个课题来说，可能不是解决问题的路径，而是一个可能性，但每一个可能性都有它的价值，所以最后我们会挑出10个建议呈现给大家。

接下来我谈一谈我对这个问题的理解。由于这个课题确实太大了，所以我来讲几个重要的点，希望能给伊春莺歌和其他同学一些启发。

中国其实已经有一些很不错的品牌。比如海尔，全球排名第一的白色家电品牌；比如联想，全球第一的PC品牌；比如猫狗的CEO傅盛，刚创业没多久就在美国做了一款很成功的软件叫清理大师，Clean master；还有一家很知名的公司叫做传音科技Tecno，2015年我去乞力马扎罗爬山的时候，发现我的黑人向导拿的就是传音科技的手机，看上去是一款比较廉价的功能机，但是他跟我说这个手机是你们中国的第一大手机品牌，当然我们都没听说过，因为这款手机只在非洲卖。所以传音科技也完成了国际化，只不过这个国际化没有中国的土壤，完全是在国际上做好的。

所以说，不同公司可以通过不同途径完成国际化。那么你就要想清楚一件事：你说的国际化指的到底是什么概念。所以我们来区分一下国际化这个概念。

+   1. 最简单的国际化指的就是产品的国际化。

什么叫产品的国际化？比如我们刚才说的“清理大师”和传音手机，这两个产品就是典型的产品国际化。很多中国人都没用过美国的Clean Master，也没用过传音科技，但是它符合当地人对功能 transverses特殊需求，就能在国际上卖得很好。

+   2. 品牌的国际化。

+   3. 文化的国际化。

现在我们来总结一下今天谈到的国际化的逻辑：谈到国际化的时候，你首先要明确

逻辑：谈到国际化的时候，你首先要明白，你是要把产品国际化，还是把品牌国际化，还是要把文化国际化。

+   1. 如果要把产品国际化，就要做到所谓的全球化，也就是每一个国家的本地化，本土化；
2. 如果要把品牌国际化，核心就是在当地建立信任感，通过宣传尤其是收购的方式，购买已经被信任的品牌，把自己的产品装进去；
3. 如果你要做文化的国际化，那么需要做的是一些有时代意义的工作，不仅仅让大家喜欢蜂蜜，更要让大家喜欢蜂蜜背后的文化。

今天我们梳理了国际化的逻辑的问题，最后我再补充一点，那就是：在如今的移动互联网时代，有个工具可以帮助我们做产品国际化、品牌国际化和文化国际化。这个工具就是跨境电商。

今天其实很多中国人已经在通过跨境电商向国外销售产品了，所以现在出现了很多叫小微国际化的企业，公司虽然不大，年收入就是几百万，上千万，了不起就是几亿，但它从出生的那一天开始，就已经是国际化的企业了，因为它一开始就是通过天猫国际、亚马逊等平台，直接向其他国家销售自己的产品。通过这个渠道，他不仅可以了解国际消费者的偏好和信任度，也有了验证自己产品的机会。所以，你不妨试一试用跨境电商的方式来走出你国际化的第一步。

以上就是我对伊春葛歌同学的问题的回答，希望能够给伊春葛歌同学和其他同学一些启发。当然，我也选出了10名同学作为这次私董会问答的获奖者，他们分别是：

我品尝过葛歌同学的“洞藏雪蜜”，感觉到了不一样的口感和品质。我认为这款产品就是要打造中国蜂蜜第一高端品牌。

+   1. 差异化定位：任何商业成功的关键，都是创造并提供差异化价值。蜂蜜品种众多，为什么用户要买“洞藏雪蜜”？就是因为它是“固体”，直接嗑着吃的蜂蜜。“好蜜不是说出来的，是嗑出来的”。
2. 目标顾客群：蜂蜜有很多功能，但是功能“多”反而不利 Wish 宣传。蜂蜜富含健脑的“镁”元素，我们就抓住“蜂蜜健脑”这一个功能，将目标顾客定位为脑力劳动者，功能是促进用脑过度后的恢复。同时锦鲤也会安神镇静，促进血液循环。
3. 营销策略：产地和生产过程可参观、蜜源可认领、蜂群可“包养”，我们与用户不仅是买卖关系，更是朋友关系，甚至可能是伙伴关系，我们只是替你在养蜂、酿蜜。可以考虑招募社群营销的高手，打造“爱蜜公社”。在这个过程中，“名人”、“网红”的宣传和背书，应该作为营销重点。
4. 定价策略：现在好产品不怕贵，就怕假冒伪劣。雪蜜一定要高端定位，为了让消费者放心，可采取单独编号、总部直销、销售轨迹可查询等措施。如果产量不高，可以考虑定价为“中国最贵”的蜂蜜，走礼品路线。

# 加餐 | 机遇与陷阱：让真正的区块链技术，健康成长，再次改变世界

每天5分钟，解决一个商业问题。欢迎收听，《刘润5分钟商学院》，实战篇。

学习了什么是区块链，比特币，和ICO之后，也许你摩拳擦掌，也许你惊恐万分。它们到底是机遇，还是陷阱？我们从5个方面来一一解析。

# 第一，创业区块链。

既然区块链作为一种“加密的分布式记账技术”，可以建立“不需要中间人的信用体系”，那就有机会取代传统“第三方信任机构”，更高效地解决信任的问题，帮助商业机构节省大量金钱。

所以用区块链技术解决信任问题，是一个创业方向。具体做什么呢？高盛在一份报告里提到7个方向：声誉管理助益共享经济，用区块链构建分布式智能电网，减少房地产产权保险交易成本，现金融股市 场，区块链试验平台，再回购协议，杠杆贷款交易，反洗钱和“知晓客户”合规性。

但是记住，创业永远是个九死一生的游戏。你可能一将功成，但更可能白骨枯。

# 第二，投资创业者。

我不想创业，但我想投资创业者，可以吗？可以，但你首先要是“合格投资人”。

什么叫“合格投资人”？为了避免“韭菜”疯狂进场，不管不顾地扑向“骗子”的怀抱，很多国家都规定：符合一定条件的人，才可以投资ICO。而中国大陆，则是完全禁止了ICO。

为什么？因为在这个市场上，骗子和被利益迷惑了本心的精英，占到了99.9%。陷阱，远远要比机遇多。

# 第三，投资代币。

除了在“一级市场”投资创业者，还有很多人人在“二级市场”投资代币。

但是，就像股市能从3000点涨到6000点，再从6000点跌倒2000点一样。代币的二级市场也是跌宕起伏；甚至因为几乎完全没有监管，而更加惊心动魄。

空气币，就是明显没有任何价值，虚无飘渺在空中的代币；传销币，就是蓄意包装空气币，通过三级分销体系收割韭菜们。

在代币的“二级市场”赚到钱的人，几乎都是在用“打新股”的心态，把尚未被验证价值的代币，用击鼓传花的方式，不断涨价转手。如果你是已经获利离场，祝贺你；如果你打算再次重仓买入，一定лін冷静，冷静。

# 第四，挖矿。

获得代币还有一种方式：挖矿。所谓挖矿，就是用特殊的电脑，参与区块链项目的计算网络，通过付出算力，获得代币奖励。

挖矿是否能赚钱，有两个变量。

第一个变量，是挖矿成本。以比特币为例。挖矿成本，包括一台目前2-3万人民的“矿机”，和因大量计算产生的电费。全球参与挖矿的算力越多，你挖到一枚比特币耗费的时间就越长，电费也就越多。

第二个变量，是代币价格。比特币的价格一直在波动。随着比特币期货的出现，有了做空机制后，比特币是否还会疯涨，你要有自己的判断。

中国的矿场正在被逐渐清除，有些大型矿场正在迁往海外。有技术宅想自己在家挖，那你最好有阁楼或者地下室，否则我保证你受不了它的巨大噪音。

# 第五，给掘金者卖水。

当全世界都去新大陆掘金时，给掘金者卖水，就变成了一个机会。

因为显卡可以用于挖矿，NVIDIA特定型号的显卡你现在根本买不到；专门生产矿机的公司，就像2000年专门生产网络设备的思科，简直就是印钞机；前面提到的以太坊坊，也是因为封装了区块链的基础技术，让掘金者可以轻松生成自己的代币，而大获成功。
