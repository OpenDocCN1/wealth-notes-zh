# 7、Tony to ni

小小鱼想进行扩张，面临着两个选择：一条是直营，一年开一家；二是找资金快速复制。我理解第一是自己独资做；第二种是引入投资人或者股东，合伙开新店。因为你也做了一家店，如果做加盟模式，恐怕还不具备品牌条件。直营的话，自己可以全面掌控店面运营。因为足浴店是属于服务行业，不同于产品，服务因人而异，许多地方无法标准化。你在这家成功了，并不意味着你再开一家就能成功。直营可以控制节奏，稳打稳扎，缺点是自有资金，复制速度慢。而找资金的话，确实可以快速的多开几家。但是涉及到合伙，就要有分工和协调，可能无法完全按自己的意愿去运营；多家店面复制，管理和运营难度大大增加，这也是为何服务业很难出现一家公司占据大部分市场的原因。
