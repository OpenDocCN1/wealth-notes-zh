# 今日得到：

+   划重点
1. 什么是产品化？技术和能力，对用户没有直接价值。只有把它们打碎、打包、打磨成产品，才能真正解决用户的问题。这个过程，就是产品化。
2. 怎样做到产品化？你至少可以考虑几个方向：对象感，你服务于谁；场景感，他在什么情况下用你的产品；价值感，你的产品能解决他什么问题；结构感，他用的过程体验如何？
3. 产品化，用在个人身上也一样。你自己，是身怀绝技的一组能力，还是用户界面友好的产品呢？
