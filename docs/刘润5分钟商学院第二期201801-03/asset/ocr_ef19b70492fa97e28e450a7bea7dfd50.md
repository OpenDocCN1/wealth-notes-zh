先温习一下员工、合伙人和事业合伙人的区别：

# 1. 员工类型：

员工是来赚钱的，他不承担风险，只付出劳动力，给予尊重和薪资即可，是最容易找到的团队成员。

# 2. 合伙人类型：

愿意在短期利益和长期利益之间做出取舍，愿意承担一定风险，换取未来更大收益的员工。优秀的事业共同体型员工，一般为核心员工，可以通过发放奖金或持股的方式捆绑，使其能够共享企业发展的成果，锁定长期的合作关系。

# 3. 事业合伙人：

和你一样看好企业的未来，把其当成自己的事业，愿意付出所有努力去实现梦想与目标，与你真正同生共死的人。

您的现状处于创业前期，未来还是充满了不确定性。这个时候必然需要出让利益，换来和你一样看好百合蜂蜜酒未来的命运共同体人才，如果成功共享荣华，如果失败一起沦灭。所以我认为这个阶段非常"需要找到自己的事业合伙人！"

合伙人的特征：

+   1.价值观契合的人，有的人有能力有资源，但是价值观有问题。大家花在互相猜疑上的时间和精力比做事业还要多，所以这一点非常要紧。

4.能力互补的人，比如你擅长的是财务和管理，那么就要找到擅长技术、营销或渠道的人。
