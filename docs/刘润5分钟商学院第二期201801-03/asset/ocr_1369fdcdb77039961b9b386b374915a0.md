# 加餐 | 刘润：我的人生算法之“概率思维”

罗胖在刚刚结束的“时间的朋友”跨年演讲中讲到一个概念：人生算法。

什么叫“人生算法”？就是把同样公平的机会，放在很多人面前，不同的人生算法，会导致全然不同的选择。

# 第一. 另一种人生算法

![](bbox=[0.15, 0.45, 0.85, 0.52])

比如现在有两个按钮，按下红色按钮，你可以直接拿走一百万美金；按下蓝色按钮，有一半机会，你可以拿到一亿美金，但还有一半机会，你什么都拿不到。你会选择一个？

按红色按钮吗？直接拿走100万美元，落袋为安呢，还是赌一下，按蓝色，万一拿到一个亿，人生的小目标不就实现了吗？可是，万一什么都拿不到怎么办？还不如按红色，虽然比一亿少很多，但最差也有100万美元吧。

这就是我们在《5分钟商学院》第2季第6课讲过的“确定效应”，“二鸟在林，不如一鸟在手”，大部分人为了看似更大的收益冒风险，他们更喜欢虽然小一点但是确定的收益。“确定效应”就是他们的人生算法。

# 第二. 创业成功的重要因素——运气

不久前，我在微软GTEC二十周年的聚会上，访谈了原子创投的创始人冯一鸣，他成功投资了途牛养车网等众多独角兽巨头。访谈中，他提出一个令人印象深刻的观点，“大家要有清晰的认识，创业成功非常重要的因素之一，就是运气”。这听起来非常政治不正确，因为大多数人更愿意听到，创业是要靠努力靠勤奋。

对我们有利的概率，称之为运气；对我们不利的概率，称之为倒霉。所谓创业靠运气，去掉感情色彩，就是：创业成功非常重要的因素之一，就是概率。
