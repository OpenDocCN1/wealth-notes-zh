接下来我想从下面三点来说这个逻辑。

# 一、为什么要做App？你的目的到底是什么？

做App、网站或者是任何一个工具，我们都要弄清它的目的 是什么。

过去我锯木头比较慢，我用电锯锯木头变快了，它是来帮我提高效率的。

# 2.改变你的模式。

比如我借助互联网销售，我就可以不用线下来卖了。

所以不管是使用App还是其他工具的时候，都要知道它是否是冲着这两 个目的去的，而不是觉得大家都有App，我是不是也应该有一个，这就是赶时髦了。

一个工具除了赶时髦或者作为一种营销手段之外，更重要的是另外两个东西有没有想清楚。你打算如何借助这个工具提高效率，或者如何改变你的商业模式。

提问的同学说他的店里有200多款香水，顾客根本试不完。如果我们把帮助顾客高效找到合适香水设为最终目的的话，就满足了刚刚讲到的第一点。那么我们就要思考解决这个问题的方法是什么？然后才是思考用什么工具手段？

首先你要知道提高效率的手段是什么，比如说他试得不够快，那就通过一些工具来加快试的速度。如果说试香方法不对，那就分场景试香。

那么App如何能够提高试香的效率呢？因为App是无法真闻到香味的，所以App本身一定不是用来试香的。App只是用来帮顾客根据标签来进行分类，比如做个小测试，根据客人的生活习惯和爱好来为他们匹配香水。但这并不能解决香水试香的问题，因为对于味道每个人的喜好是不同的，人们喜不喜欢真的能通过这些标签能把它区别出来吗？会不会有可能到最后所有的标签场景都选过了，但那些香水的气味顾客就是不喜欢呢？这其中的逻辑关系是否真能找到，我还是有一些许质疑的。

但是为什么有些行业可以？我来举个例子，在《5分钟商学院》第一季的时候我们讲过一个叫零时尚公司的案例。有两个女孩子，都是理工科背景，她们觉得女生每天挑选衣服搭配很麻烦，于是她们就做了一款App软件来卖衣服。这个App让你先输入自己的身高、身型、三围比例，结合各种各样的数据，它会根据你的社交场景、衣橱里有什么颜色的衣服等等，把大量的数据整合后，给出建议的配色和搭配形式。App搭配之后用照片的形式呈现给你，你一看就觉得这东西穿身上没准还真好看，然后她们就把搭配好的衣服寄给你，但寄给你的这个盒子里大约有十几件衣服<|message|>里面配了一整套搭配方案，你可以根据搭配方案来试穿。她们通过App来帮助用户搭配衣服，从而达到卖衣服的目的。

但是衣服和香水还是不一样的，因为衣服的穿搭是通过视觉来完成的，所以可以通过互联网或App的形式实现声音、文字和视频的传递。而试香软件在试香的整个过程中，无法真试闻香味，所以就算上线了这个App也始终是一个辅助作用。顾客还是只能通过线上的大概了解之后，到线下来闻香。所以你要想清楚这是不是你真的要马上着手做的事情，是不是做出了这个软件就可以大幅提升效率。

作为经销商，我们过去卖香水的方法可能已经非常传统和固化了，所以我给你一些别的思路，你来思考一下。

在2016年，有一家美国公司叫Scent Bird，这家公司拿到了200多万美元的融资。那么他们是做什么的呢？他们在网上签了400多个香水设计师，然后就开始创造一种商业模式。因为香水太多，而且使用场景过于复杂，一般的消费者根本搞不懂什么时候用什么香水。这个商业模式就是，用户每月就付几十美元的订阅费，然后这个公司就不断寄你各种各样的香水小样，反正就几十美元，用户就一直用下去。因为香水这种东西有的时候你会觉得用着习惯了，但有的时候也会想换一个新鮮的，闻闻看其他的香水是什么味道。当你有这种欲望的时候，你就会不断订阅下去，直到用到一款你喜欢的香水时，就想要去买它。当然也可以，当你购买那款香水后，公司会在第一次时送你一个特别精美的香水瓶子，每个月底如果你剩的不多了，他会再寄一些补充装让你来把它装满。

你看，他就把香水变成订阅模式，然后通过让你不断试用的方法，来让用户体验不同的香水。因为香水正装一瓶量都很多，用户不可能每一款都买回家，但订阅的模式可以帮用户去解决这个问题。

对于提问的同学来说，可以通过互联网跟线下的模式结合，但做的这个App不一定是用来选香的。这个App可以变成你跟用户之间不断互动的平台，也用付费订阅的模式。这个互动平台可以不断建议用户，给用户更多选择。这是从商业模式角度来思考。

# 总结

当我们要去做一个App的时候，我们要知道做这个App的目的 是什么？它的目的 一定不是赶时髦。如果真的是为了赶时髦，那你可以把它作为营销手段，尽量降低成本，而不要真的花费大量心思去做这件事。
