首先，要解决这个“怎么办”的问题，我们要理解这个问题本质。你的目的，真的 是想做试香的App吗？首先你要知道，App只是提高业绩的手段。研究手段久了，就 会慢慢把手段当成目的，从而隔离真正的目的。那什么才是真正的目的？真正 的目的是提高香水的销量。那怎么能提高香水的销量呢？我们学习用著名的 STP理论可以解决这个问题。

+   1. 梳理店内香水品类并营造场景感，把店中200多款香水根据不同场景进行分类，如家人聚会、朋友聚会、面试求职、人性魅力等。用户试香难，是因为用户不知道用这些香水能够达到怎样的角色化展示。
2. 基于分类后的香型程度细分在第一步完成后，可制作香味程度或香型标签，为每一类场景的香水进行明确标注。
3. 根据用户偏好轨迹，推送新款香水，完成第一步和第二步后，基本可以了解到较为精确的用户偏好。

我的结论是不建议做App，理由是：提问者目的是帮助用户智能推荐香水，但本质的目的，是带动销售。所以App只是工具，我们要考虑的问题是如何增加引流和提高流量转化。

# 不做App的理由：

+   1. 难以规模化、低频。成 本香水相对于是一个低频应用和需求，在引导-下载-打开-使用-停留-留存，每一步都面临着用户的时间挑战。投入了很大的开发成本，往往真正使用的人不多，也难以规模化。
2. 数据收集和算法处理。智能推荐最难的不是算法处理，最难的是有效数据收集想要达到精准推荐用户合适香水，需要收集很多维度的数据，这些数据的收集成本是很高的，甚至连收集哪些维度目前都难以确定。
3. 香水消费体验的本质是场景化产品。
4. 设计好服务蓝图。
