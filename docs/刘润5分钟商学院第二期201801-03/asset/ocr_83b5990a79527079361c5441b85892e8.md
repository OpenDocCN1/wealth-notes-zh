# 第12周周末私董会｜你的商业难题，我们一起来帮你解决

每天5分钟，解决一个商业问题。欢迎收听《刘润·5分钟商学院》实战篇。

5分钟商学院的同学们，大家周末好！

第一季的基础篇里，我们每天一起学习一个经典实用的商业概念，到了第二季的实战篇，我们进入到了真刀真枪的商业投掷中。尤其是周六的私董会环节，更是直接把陈同学们的实际商业问题，让大家一起用学到的知识帮当周的提问同学出谋划策，我也一起参与其中，和大家一起共赢解决方案。这几周下来，咱们已经帮助很多同学的商业实战问题，出谋划策。上上周提问的李筱锋同学还特别发来了感谢回复：

> “谢谢刘润老师的精心点评，我们会在老师的建议上好好讨论下一步的方向。作为没有快销品经营经验的新手，这次创业是非常大的挑战，从开始的信心满满到现在越来越感觉到难度了。在这里给自己加个油，坚持，不忘初心。

借助私董会的平台，我也和同样做蜂蜜的伊春英c歌同学联系上了，她给了我很多专业的建议，还有很多同学主动联系我，从各自的角度给我提出很多建议，还有同学专程来到天津和我当面沟通，咱们的同学们都很有优秀，希望大家在线下也能多多交流沟通，多多合作。最后，也希望有机会和大家一起推广俄罗斯的优质产品，明年俄罗斯世界杯，喜欢足球的朋友可以找我，人数足够我们可以组团参加。”

上周，获得咱们私董会提问资格的是赵爱娣同学，来看看她的问题：

> “我们公司主营摄影器材、数码相机及配件，代理和零售两种经营形式，代理业务和线上的客户以及线下客户一直保持着很好的合作关系，这块的业务营收还可以。但是我们还做零售，在摄影器材城里开店卖相机和配件，我们的店铺位置、品牌口碑都还不错，但现在摄影器材这块市场萎缩的厉害，铺租高、同质化竞争激烈，生意越来越难做，今年零售已经亏损几十万，但是因为做了十几年了，放弃这块业务又觉得特别可惜，换店面位置又怕流失老客户，陷入了两难的境地。想请问同学们该怎么办？公司现在考虑在门店里扩展产品品类，比如代理或者经销手机及周边配件、音箱音响，耳机耳麦，早教益智等相关产品，不知道这个方向是对的吗？或者还有没有其他方法可以把已有资源利用起来、增加利润，来保证实体店经营不亏损，还能长期经营下去？”

赵爱娣同学出价1000元，我也贡献了1000元，咱们的奖学金池一共2000元。同学们给了非常多精彩的回复。我挑选了其中尤为精彩的10条留言。我挑选这10条留言的原则，主要是从这四个方面考虑：

+   1. 专业性，对应领域的专业人员的留言；
2. 可行性，有具体的方法建议、实操性强的留言；
3. 独特性，思考角度独特、有增量信息，有自身感受或经历；
4. 应用性，和5分钟商学院的课程知识有效结合的留言。

下面我梳理了这10条留言的回复要点，和我对留言的点评，你可以对照着看，希望你从别人的解决方案中，获得自己的思考和成长。希望下周，你的留言也能入选。

# 2、大客创新互联网咨询-Jackson 董坤

今天这位同学的问题，我理解为，在一个越来越缩水的市场中，希望获得转机。

+   1. 组织老客户一起参加风光摄影活动。用旅游，摄像，交流的方式，促成线下的摄影活动。也可以与旅行团活动。根据情况，设置不同的服务和收费档次。
2. 给老客户出影集。让摄影爱好者的作品集成，甚至可以运营公众号来展示以及推广，从而形成新流量。
3. 举办摄影作品评比活动。
