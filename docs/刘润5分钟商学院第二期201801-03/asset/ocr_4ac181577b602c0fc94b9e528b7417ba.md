# 第22周周末私董会｜只有产品，如何开展创业计划？

每天5分钟，解决一个商业问题。欢迎收听《刘润o5分钟商学院》实战篇。

5分钟商学院的同学们，大家周末好！又到了本周私董会的时间了。

本周获得私董会提问资格的同学是：

润总，您好！我是五分钟商学院学员。我有一家环保设备公司，已经经营了十几年，在业内也小有名气。现在我又用独创的“双控”发酵技术，生产出了一种用蜂蜜和百合酿制的酒，获得了发明专利，通过了国家科技成果鉴定：“技术水平达到国际领先，添补了国内外空白”。我还购买了“百合”商标，并通过了马德里国际商标注册。酒的口感和味道也赢得了消费者的认可和赞誉，甚至一些葡萄酒的专家都认为同葡萄酒相比，百合酒的营养价值更高，更有文化内涵。著名葡萄酒评酒师、山东省葡萄酒研究院副院长王咏梅女士评价：‘酒体色泽淡黄、晶莹剔透；香气清新优雅、精美别致；入口圆润舒顺、纯净爽口；初次品尝，回味略有淡淡苦感，再次品尝时则回甘绵长、留香满颊。’‘百合网也对这个项目很感兴趣，去年提出了全资收购的意愿。’
我自己更是对这个项目充满了信心。我的问题是：百合酒的形象定位是‘时尚、浪漫’，市场定位是婚嫁为主的中高端消费。但由于我的环保设备公司处<|message|>于一个北方的七线小县城，在这个区域内，很难建立一个适合百合酒的营销团队。我计划到靠近上海的苏州，组建营销团队，并把苏州打造成线下的样板市场，与线上营销结合，开拓全国市场。万事开头难，自己组建团队，过程会很长，而且，我的精力还要兼顾环保设备公司，担心会因此失—。那么，我应该在苏州找一个合作伙伴吗？如果我合作伙伴的话，合作伙伴的选择标准是什么？如何找？

刘润

好，我来说一下这个问题。

这位同学说他做了一款酒，我上网去查了一下，在网上也查到了非常相似的产品。说明这个百合酒并不是一种新发明，而是一个品类。同时，这位同学做了一些酿造技术上的创新。这个酿造技术上的创新，可能是体现在口感上的。另外，有一点值得注意，这位同学原来是做环保的，现在想做百合酒。

我们还是套用一些商业的基础逻辑来解释。

这位同学目前还没有搭建团队，只有一款产品刚刚诞生，所以是从零开始创业的状态。他并不是遇到了一个具体的难题，而是需要展开一个计划。

我曾经讲过，一个公司的经营大概是三件事情，叫做产品、营销和渠道。

# 总结

这位同学其实没有具体难点，只是事业刚刚开始不知如何展开核心业务。按照商业的逻辑，我们梳理了产品、营销和渠道三个方面。

第一，在产品上，工艺所带来的口感差异可能是细微的，这个差异可能对高端品酒人士有影响。但对婚庆这个市场来说就是没有差异，所以不能把核心能力架构在这一点上。

第二，我们分析了营销才是核心能力的原因。对照江小白来看，要从营销角度重新调整组织结构。要么自己来干，要么自己找一个信任的、懂营销的合伙人在苏州一起干，再或者找当地的公司来做，建立公司与公司之间的营销和代理合作。总之，营销是驱动整件事情的最大一个核心。

第三，在渠道方面可替代性很强。在婚庆桌上摆什么，其实只是过个口彩，所以你要oltre在用户心中建立不可替代性。这个时候渠道才会为你发挥真正的作用。而在用户心中建立不可替代性，是靠营销来完成的。

以上就是我给这位同学的回答。希望给大家一点启发。也感谢其他同学提的各种各样的建议。
