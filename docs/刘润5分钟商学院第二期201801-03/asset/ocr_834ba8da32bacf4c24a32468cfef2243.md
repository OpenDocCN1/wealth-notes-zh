+   1. 统计所有老客户资料，拉入微信群，引流到线上，尝试进行线上经营。 2. 线下店铺未来更会是展示产品的作用，因此，如果线上引流成功，可以考虑减少线下人员，转换经营地点，来降低运营成本。 3. 线下店面主要是2C，现在自然流量在减少，加上摄影城的定位，即使在线下扩充相关品类，个人感觉效率不高，会被自然流量减少的大势所淹没。除非能通过营销来引流，不过引流成本太高的话，又不合算。 4. 新零售目前的趋势是线上线下融合，零售店的人可以考虑将一部分人转成线上运营人员。或者，除了留守门店的最小人员，其余人员去做2B的拓展，这样人员利用率更高。 5. 如果线下转型不成功，是否有可能壮士断腕？集中火力攻线上，以及渠道。因为日益衰落的门店会拖累其他业务。
