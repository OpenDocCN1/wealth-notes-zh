# 概念：布局原则

什么叫布局原则？

James最近在找工作，把精心准备的简历，发给几家心仪的公司。公司的HR特别忙，于是用15秒扫了一眼简历，什么信息都没得到。

“好乱”，HR心想，于是把简历放 perioadă“日后联系”的文件夹里。

![](bbox=[0.22, 0.9, 0.82, 1.15])

喀？这也叫“乱”吗？那什么样叫不“乱”呢？

别急，我们先通过四张图，看看到底什么叫“乱”。

![](bbox=[0.15, 1.4, 0.9, 1.62])

第一张图，显然非常乱。为什么？因为有太多孤立元素。

![](bbox=[0.2, 1.77, 0.9, 2.05])

第二张图，还是非常乱。为什么？因为有多种对齐方式。

![](bbox=[0.18, 2.185, 0.9, 2.5])

第三张图，依然非常乱。为什么？因为对比不明显。

![](bbox=[0.15, 2.64, 0.88, 2.95])

第四张图，绝对更加乱。为什么？因为信息没有分组。

那什么叫“不乱”呢？

罗宾·威廉在他的书《写给大家看的设计书》里说，有秩序的布局，就是让人身心愉悦。打破秩序，杂“乱”无章的布局，就会让人不安、焦虑、排斥。这个“秩序”，就是组织性、一致性、统一性和互补性。

他举了个例子。比如下下面这张名片。

![](bbox=[0.2, 3.47, 0.88, 3.75])

第一，要素之间没分组，缺乏“组织性”；第二，要素之间没对齐，缺乏内在的“一致性”；第三，要素之间没呼应，缺乏“统一性”；第四，要素之间没对比，缺乏“互补性”。

所以，你看着就是不觉得美。

那符合“秩序”应该是什么样子呢？你再看看下面这张重新设计过的名片。

![](bbox=[0.22, 4.26, 0.88, 4.55])

是不是不觉得“乱”了？

为什么？因为上下的分组、靠右对齐的一致、粗体的统一、大小粗细的对比，暗合了深深埋藏在你心中的“秩序感”。

# 运用：

那我到底应该怎么做呢？你只需要记住这四个“布局原则”：亲密、对齐、重复，和对比。

亲密，就是让逻辑上相关的信息，表现得更亲密一些，比如靠近一些、放在同一个框里面，等等。亲密的本质，是体现“组织性”。

比如下面这个封面设计。

![](bbox=[0.24, 6.67, 0.88, 7.55])

封面有6行文字，但显然有3个逻辑组。大标题一组，副标题一组，作者和时间一组。但是在这个设计中，6行的间距都是同样的，没有体现出信息的“组织性”。

那有秩序感的设计应该是怎样的呢？比如下面这张图。

![](bbox=[0.26, 8.05, 0.88, 8.95])

这样的布局，很有条理，更易阅读，也更容易被记住。

任何元素，都不能随意安放，而应该与其 他元素有某种视觉联系。这种视觉联系，就是“对齐”。
