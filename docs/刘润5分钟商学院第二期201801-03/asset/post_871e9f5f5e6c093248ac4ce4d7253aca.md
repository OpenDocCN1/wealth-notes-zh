
# 105 | 看比赛：为什么南京、西安、宁波等城市同时放开了户口政策？

每天5分钟，解决一个商业问题。欢迎收听《刘润5分钟商学院》，实战篇。

3月1日，南京市突然宣布，研究生或者40岁以下的全科生可以直接落户南京。而之前，想要落户南京其实挺不容易的，早些时候你得先买套房吧，后来有了积分制，落户就更困难了。而不止南京，珠海市也全面放宽了落户政策。再之前，2月28日，宁波市也宣布放低落户门槛。

不仅如此，更早的时候，落户西安，服务已经堪比海底捞了。有段子说，去西安走亲戚，警察问：“你是西安人吗？”“不是，我来走亲戚的。”带回派出所，他符合亲友投靠落户的条件。“去西安火车站转车，警察问：”你什么学历？“”本科。“带回派出所，办理学历落户，火车票的钱给他报销。”

早在2月11日，我发了条朋友圈说：很快，各大城市将从“人才之争”，变为“人口之争”。各地户口制度，将对年轻人口完全开放，甚至疯狂倒贴。

> 刘润
很快，各大城市将从“人才之争”，变为“人口之争”。各地户口制度，将对年轻人口完全开放，甚至疯狂倒贴。鼓励生育政策，也可能会慢慢出台，生了就给钱。整个社会，更开始防群体性冷淡、啃老，甚至虐待老人的现象。

为什么会这样啊？今天的看比赛，我们就来分析一下，这背后到底有什么商业逻辑。

过去，各大城市为了吸引优秀人才，给出了非常优厚的待遇，户口，别墅，高额奖金和补贴等等。当然门槛也非常高，至少你得是研究生吧，你得是国家千人计划的成员吧，或者你得是国际认可的专家吧。

而今天不同了，你只要是40岁以下的全科生，就可以直接落户了。大家从抢“优秀的人才”变成了抢“年轻的人口”。为什么？

在《5分钟商学院 基础》第28课“人口抚养比”中（详见底部相关课程），我们学习了中国人口结构的变化：90后，比80后减少了44.2%；00后，又比90后减少了33.7%。也就是说，如果80后的总人口是100人，那么90后就是56人，00后就是37人。

这意味着，在未来，劳动人口的供给会大大减少，退休人口会急剧增加。大约15年后，90后和00后成为社会主流，中国将从一个9亿人工作，5亿人无法工作的国家，变成一个5亿人工作，而9亿人不能工作的国家。

年轻人的剧烈减少，会导致城市的竞争力大大下降，所以各大城市开始上演“抢人大战”，纷纷开放户口政策。

过去的很多行业，比如制造业、服务业、快递业能够繁荣兴盛，很大的原因，是中国的人力成本非常便宜，这让我们在过去30多年有巨大的竞争优势。

但现在年轻人人口在锐减，这几乎必然会导致人力成本大幅上升。据统计，中国制造业的平均时薪在2005年是1.2美元，到了2016年已经涨到了3.6美元，翻了3倍，超过了金砖四国。

那在这种情况下，我们应该怎么办呢？我给大家四个建议。

第一，不要把人力成本作为竞争优势，而是要想办法用你的方式来代替人力，降低成本。

许多快递巨头，比如顺丰和京东，它们正在试着用无人机、机器人送货。许多工厂，正在用机器人取代人手脚，用人工智能取代人的大脑。

李开复说，人工智能很快会取代50%的工作。这到底是好事还是坏事？过去我们对这件事是极度恐慌的，但在劳动人口越来越少的情况下，这其实是件好事。日本因为超级少子化，已经完全进入老龄化社会。在日本，很多服务业，比如商场，比如开出租车，都是老年人再工作。

## 第21周周末私董会 | 对于不完美的产品，如何提高它的销量？

每天5分钟，解决一个商业问题。欢迎收听《刘润5分钟商学院》实战篇。

5分钟商学院的同学们，大家周末好！又到了本周私董会的时间了。

本周获得私董会提问资格的同学是：曾宇帆。

刘润老师，您好！新能源汽车是热点，我们却是腾势纯电动汽车品牌在深圳的经销商4S店，去年我们的零售销量并不理想，主要受到客户顾虑充电问题和产品定位30万元高端价位受众较少的影响。现状是新改款的腾势500开始预售，腾势厂家也开始预热，同时深圳燃油车牌照拍卖均价已经到95000元，而纯电动车牌免费免摇号。2018年想把握这两个契机，从集客量入手，重点做好网络集客。作为小众品牌小众车型，请大家支支招：如何找到客户的需求点？有什么方式和渠道让集客既量多又有 效？同时如何提高转化率增加成交量？

刘润

好，我来说一下这个问题。

这个问题其实是一个很大的问题，我也看到很多人留言里提出了自己的见解。大家的见解主要分成两种，一种是站在腾势电动车品牌商的角度来思考的，另外一种是站在销售的角度思考的。这两种回答都很好，但后者可能更是提问的同学需要的。因为这位同学他是一个经销商，他并不对汽车的制造、定位，甚至充电桩和政策的问题负责，他面临的只是怎么把产品卖得更好的问题。所以，我也建议未来同学们提建议的时候，能够站在经销商的立场，这样给别人建议的时候才不会走偏。

下面我来说说我对这个问题的看法，希望能给这位同学一点启发。

对于传统的汽车销售来说，基本做法就是：一方面，品牌商在电视上、飞机上、杂志上疯狂地打广告，让客户对他们的品牌产生熟悉感；然后另外一方面，经销商在城市的郊区开一个4S店，收集地面流量。因为看了广告的客户如果觉得合适的话，就会来这个4S店买车。品牌商负责营销，4S店负责收集流量，这个模式运行了很多很多年。

但是今天，为什么这位同学会遇到一些挑战和问题呢？因为他用传统的方式去卖的这辆车是纯电动车。纯电动车和传统汽车的区别就在于，它还不够成熟。这么说可能有些同学会不高兴，凭什么说电动车不成熟？但你换个角度想，现在购买电动车有那么多优惠政策，为什么有这些政策，就是因为这辆车还不成熟，如果它成熟的话，根本就不会有优惠。而且，目前电动车的行驶公里数，好的也就在300公里，太远的路你是不敢开的。所以说，它还是一个相对不太成熟的产品。

所以这个问题的第一点就是，电动车是一个不完美的产品，而且它还是一个相对不成熟的产品。

那个问题的第二点，就在于谁来买它。

你想说服一个思想传统的人去买一个不完美的新产品，这是非常困难的。那么我们可不可以换一种思路？我们不去说服那些难以接受新事物的人，而是去找到那些喜欢新事物的人？如果把这群人找出来，然后把优惠送到他面前，说服他们的机会就大得多。

在《5分钟商学院》第一季里面，我们讲过一个非常重要的模型，我们称之为技术采用生命周期的（详见文章底部链接）。

第一阶段，面对的是创新者。创新者天生对新科技充满了好奇，你不用找他们，他们都会找到你，他们甚至愿意参与创造新事物。但这种人是极少的，大概占所有用户的2.5%。

第二阶段，面对的是早期采用者。这类人的特点是：当一款新产品基本成型之后，他们会试一试，如果不好会推荐给朋友。这群人占整个市场的13.5%。但这群人还不代表大众。

第三阶段，才会面对真正的大众，这个阶段的大众叫早期大众。这群人占整个市场的34%。他们只关心需求，根本不关心技术。所以，相对现存产品，你的技术必须有明显优势，并被反复验证稳定可靠，他们才会购买。

第四阶段，面对的是后期大众。他们更保守，对风险更敏感，可能身边的很多朋友都做了激光近视手术三五年了，他们还是会说：20年后再看吧。这群人，也占整个市场的34%。

第五阶段，面对的是落后者。这群人可能要等到路上加油站都找不到，才会买电动车。这群人，占整个市场的16%。

如果我们从技术采用生命周期的角度，重新去理解用户的话，你就要问自己一个问题：

进你4S店的那些人，他们到底是什么人？可能这些人当中，绝大部分都是不可能买电动车的后期大众，以及在充电桩普及之前基本不可能买电动车的早期大众，还有此生都不会买电动车的落后者。

所以，要想提高成交率，你必须主动去找到那些早期采用者，愿意尝试新产品的这类人，这是最关键的战略。

这些人有什么特征呢？

这些人特别追求新鲜事物，他们觉得开电动车很酷，他们想告诉所有人自己是环保主义者。我们要找的就是这种人。

怎么找到这种人？

我要告诉你的是，这种人是集群存在的。他们虽然不会结队来你的店，但他是以某种形态在某个地方集群存在的。你要把你的用户分成几类去找到他们。

举个例子，比如说登山者。登山者都是喜欢冒险的人，愿意面对极大的不确定性，因为登山的时候，没人知道明天会发生什么。而且登山者这一个群体，大部分都是有资金、有能力的人。如果你和登山俱乐部、户外运动俱乐部建立合作关系，跟他们一起搞一些试驾活动，或者用电动车来赞助一些城市内的活动等等，或许能够收获比较好的效果。

再举个例子，你可以去找那些家里计划买第二辆车的人。这群很可能是住别墅的人，他们家里有车库，已经有一辆车，虽然不在于补贴，但是也想做一个环保的人，所以可能会再买一辆电动车。一辆车出门开，一辆车在市里开，或者夫妻一人开一辆。要找到这类人，你可以考虑和高端的房产中介建立合作，刚换了大房子的人群可能更会有这个需求。

当然，刚才只是我举的两个例子，如果你再继续找的话，我相信你一定会找到更多。但是记住，基本原则就是：每个人都有自己的心理状态，对一个尚未成熟的产品，不要去说服早期大众，更不要妄图去说服后期大众，而是要找到早期采用者。找到早期采用者的方法，就是找到那些愿意冒险、有经济能力、喜欢新事物的这群人。他们也许在户外俱乐部，也许是刚买了别墅，又或者是创业者。总之，跟这些群体、社群去合作，也许是一个很好的营销方法。

以上就是我给曾宇帆同学的一个方向性的建议。至于把这个人群领进门之后要怎么去说服他购买，我相信你们公司作为经销商会有很多方法，你也会有很多研究，在这里我就不多说了。希望今天的内容能给大家一些启发。

- 3. 认为新能源车是未来趋势，环保
- 4. 操作简单，噪音低

在深圳不买新能源车的原因：

- 1. 充电难，充电慢

- 3. 售后服务跟不上
- 4. 续航差

我重点针对你提到的第二点，如何让集客量多又有成效进行阐述。你已经积累了很多过往消费者提到的痛点经验，总结来看无外乎5点，而前3点说到底都与电池相关：

- （1）充电桩问题。消费者顾虑所在城市的充电桩分布有限，担心行走在外，车子没电也找不到充电桩；消费者还顾虑自家小区车位紧张，没办法安装充电桩。

- （2）充电时间及效率：现在市面大多电动车，慢充需要7-8小时，快充约半小时，但快充频繁会损伤电池寿命。总体来看，充电效率太慢，时间太长。

- （3）电池问题。消费者担心电池用不久，三年到五年就折损到需要更新，害怕更换电池的费用和麻烦。

- （4）续航里程。去年我试驾的腾势是最少400公里续航，已经算很不错了。但消费者拿来与汽油车相比，仍然担心续航里程导致不能长途。

- （5）价格。腾势的30万元定位，在电动车中略显尴尬，与相同价位汽油车相比，明显处于劣势。

仔细分析这5个痛点，第1、2、4点，参照当下各自国家政策及市场大环境难以解决；第5点价格难以解决；第3点电池问题，你可以通过企业服务，免费更换电池、免费提供更换及检修服务等来解决。

结合如上分析，你会发现，大多数痛点不是你能解决的，那么怎么让集客量多而有效呢？可以尝试如下战略，下决心大胆放弃“存在如上痛点”的这部分消费者，将重点放在发展、培养、找出没有上述痛点的...

点放在发展、培养、找出没有上述痛点的那部分消费者。

这些顾客应该是为价格烦恼、小区有地方装充电桩、不担心续航里程（或者家中已有 一辆汽油车）的潜在消费者。

如何做到呢？

第一，选择营销地点。这部分潜在消费者偏向中高端，那你的线上、线下活动地点的选择也都是要找能有中高端人群较多的地方。鉴于篇幅有限，仅提供线下方案供参考。选择中大型企业、中高端商场、商业中心区人流量大的广场等地。

第二，利用调查问卷筛选出这部分潜在消费者。无论是线上还是线下活动，原则都是付出成本购买流量，以给他们礼物、奖励但填写问卷的方式进行。问卷的关键指标包括：年龄、工作职位、工资区间、是否有车、是否有购车意向。同时要注意，你要尽量给出选项，只让他们打勾。你的问卷设置，让大家写字越少，大家越不反感，你得到的有效信息才会越多。免费试驾、赠送礼品、填写问卷。记得一定先送礼品，再让对方填写问卷，这牵扯心理学知识，这里不赘述。

第三，根据问卷结果筛选出这部分潜在消费者，指定下一步持续跟踪计划。你已拿到这部分集客量资源，要重点维护好这部分群体，持续跟踪，伴随着你的优良服务、适当活动，甚至寄送礼品等。

做到上面三点，应该就可以得到你想要的潜在消费群体以及较高的有效性。在此基础上加入后续跟踪、服务，相信购买转化率也不是大问题。以上是结合经验和我的思考给出的建议，希望曾同学今年的新年大卖！
