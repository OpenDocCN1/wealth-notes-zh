# 117 | 二级价格歧视：什么东西，买得越多价格越贵？

每天5分钟，解决一个商业问题。欢迎收听，《刘润·5分钟商学院》，实战篇。

小李开了家儿童玩具共享中心。很多家长花了不少钱买新玩具，可孩子只玩一两次，就不感兴趣了。小李希望用“买卖为租”的商业模式，让家长们少花钱，孩子们多体验。

玩具中心开业后，非常受欢迎。但小李很快就遇到了问题。不少家长借了玩具一直不还，导致流动性很差，后面家长等得很不耐烦，于是很多人到期就不在续费了。

小李很苦恼，怎么办呢？或许可以用“二级价格歧视”，来解决这个问题。

# 概念：二级价格歧视

什么叫“二级价格歧视”？

二级价格歧视，就是“按量定价”。按量定价的价格歧视，在商业世界中，千姿百态，无处不在。

最常见的，就是“批发”。你在商场买瓶啤酒，10元钱。但你到批发市场“批发”一箱啤酒，7元钱；你到啤酒厂买一车皮，估计只要5元，甚至3元。这就是“二级价格歧视”。

"团购"也是典型的二级价格歧视。你一个人来买，正常价格，你团结10个人来买，就便宜一点，你团结1万个人来买......我们好好谈谈，你有什么要求？

还有"套餐"。你去吃肯德基，单点汉堡，单点薯条，单点可乐，一定比一份包含汉堡、薯条、可乐的套餐要贵。

还有。比如"优惠券"。你一进商场，就有人给你张"满100减20，满200减50，满300减100，满500减200"的优惠券。不用算了，意思就是说：买得越多越便宜。

# 运用：正向二级价格歧视

"批发、团购、套餐、优惠券"，这些形式都有个共性：买得越多越便宜。所以都是"正向二级价格歧视"。

这不废话吗。不是"买得越多越便宜"，难道是"买得越多越贵"吗？

什么叫“逆向二级价格歧视”？

你平常交电费吗？你知道居民电费，白天贵，晚上便宜吗？你知道？很好。这叫"谷谷电价"，鼓励大家晚上用电。但是你知道，同样的在白天，居民电费也是"阶梯定价"的吗？

在某市，居民电费分三档：

+   1）每月用电260度以内，每度0.617元；
2）每月用电260-400度，每度0.667元，涨了5分钱；
3）每月用电400度以上，每度0.917元，居然大涨了50%左右。

为什么会这样？鼓励大家节能能源吗？当然有这个原因。但一套<|message|> 一样，再怎么省电，都不可能省到一居室的水准。供电局这么定价，其实不仅仅仅是为了节省能源，而是让住大房子的，也就是对价格不敏感的人，为同样一度电，付出现更多钱。

每户用电260度，400度，和400度以上，相当于把住户粗略地分为了"温饱型、小康型、富裕型"。富裕型因为房子大，再省电也比温饱型用电多，但他们有钱啊，那就让他们多付点。

这就是"买得越多越贵"的逆向二级价格歧视。

# 运用：逆向二级价格歧视

那怎么用"逆向二级价格歧视"，来解决之前说的租赁玩具不还的问题呢？

你可以这样设计价格体系：

+   1、每次出借玩具，需一周归还，收费100元；
2、延期到两周归还，收费300元；
3、延期到一个月归还，收费1000元。
4、归还后，如果无人排队，可以再次借走同样的玩具。

# 划重点

1.二级价格歧视，就是"买得越多越便宜"，比如批发、团购、套餐、优惠券。 2.逆向二级价格歧视，就是"买得越多价格越贵",比如电费的阶梯定价，上网套餐。 3.不管是正向，还是逆向,"二级价格歧视"，就是"按量定价"。
