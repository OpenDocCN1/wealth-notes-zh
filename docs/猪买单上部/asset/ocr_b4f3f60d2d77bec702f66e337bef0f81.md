# ## 第07节：媒体置换合作的跨界打劫案例

### 案例：广播免费产品赚钱

哥伦比亚有一家广播电台，他们日子生活得很艰难，员工工资发不了，房租缴不了，没办法了，它拿广告时间找商家换，来，我帮你打广告啊，你不用付钱，你拿产品之置换就行了。

换了一堆东西，小家电，五金大堆。

但还是没有钱，工资还是发不了，很发愁，要怎么办？

老板看这堆小家电、五金很发愁，后来想我们不是有广告时间么，我们自己的广告，主持人也是我们自己 的，于是主持人在广播里面吆喝，开始卖这些小东西。
