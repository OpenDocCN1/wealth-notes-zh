# 分账的好处是什么？

第一个你为结果付费，你为客户线索付费，你花出去的钱都是保证已经赚到钱了，然后你再付给媒体。

没有别人给你推荐顾客，你压根这笔钱都赚不到。

你只是别人给你推荐顾客，你把收到的钱分了他一部分而已。
