好多消费者在买东西的时候，因为有赠品买了，没赠品不买，因为赠品好买了，因为赠品不好不买。很多人是很看重赠品的，赠品是你操作当中很有利的一个杠杆。

馈赠产品在设计的时候，要注意几点：

![](bbox=[0.11, 0.55, 0.82, 0.69])

+   - 首先，馈赠产品也要塑造价值，否则客户不稀罕；

+   - 其次，赠品要跟核心产品要能够关联互补；

+   - 最后，为了更好的促成交易，不光要送一个赠品，一个赠品只能打动一种类型的客户，我通常会送客户 3 个以上的赠品，这样几乎可以通杀。
