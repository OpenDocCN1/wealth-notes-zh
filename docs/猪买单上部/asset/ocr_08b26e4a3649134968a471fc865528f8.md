# 第二个他要留下多少信息？

有一次一诺老师调查一个企业的案例，登陆一个网站，在线注册的时候，对方又让我留身份证号码，又要留年龄、性别、血型、星座，我一看，烦！

我直接关掉网站走人了。

给的又没太大吸引力却要留这么多信息，太麻烦了。

> ![image](https://placeholder.com/image1.png)

设的门槛越简单越好，给的诱惑越吸引越好！

——诺老师

所以你要思考让他留多少信息，通常让对方留的信息越多，资料越完整，跟踪起来越方便。
