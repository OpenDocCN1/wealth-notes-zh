# 卖产品的第三个境界——卖股权

股权买单的是股东，也就是投资者，股东是金字塔的顶层， 是系统的所有者。

那些看好你企业未来发展，同时又不愿出力干活(代理、经 销、经营)的，可以投资成为你企业的股东，这个过程就是股权 融资。

原始股权诞生了很多奇迹和一夜暴富的神话故事，曾经一 度被定性为一夜暴富的代名词，所以后来一诺老师讲课的时候 市场说的一句话：天下无难事，只要股份制！

![](bbox=[0.12, 0.56, 0.84, 0.7])

做股权对企业有什么好处？

+   1. 巢引凤：留住内部人才，吸引外部人才；

+   2. 提升效率：扩大市场占有率，减少浪费，提高利润；

+   3. 金色降落伞：老员工（股东）退出，消除有股阶阶和无

当你看《猪买单》超100遍以上，奇迹将在你身上出现！这种奇迹叫做:羊毛出在狗身上猪买单！
