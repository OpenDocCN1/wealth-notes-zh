# 激情能让一个人摆脱平庸创造奇迹

爱默生说：“不倾注激情，休想成就丰功伟绩。”

激情常常使最精明的人变成疯子，使最愚蠢的傻瓜变得精明。——[法国]拉罗什富科

激情是使航船扬帆的飓风，有时也使它沉没，但没有风，船就不能前进。——[法国]伏尔泰

没有激情，世界上任何伟大的事业都不会成功。

——黑格尔

我们的激情实际上像火中的凤凰一样，当老的被焚化时，新的又立刻在它的灰烬中生出。——歌德
