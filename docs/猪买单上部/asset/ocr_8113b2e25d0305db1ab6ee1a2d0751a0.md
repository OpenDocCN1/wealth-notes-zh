# **第 3 步：记录竞价排名的网站**

做竞价排名的网站所销售的，就是你要做的细分市场的相关产品，也就是未来你可能要操作的产品。

那么，用 EXCEL 表格，把这些产品及相关信息记录下来。

例如：网址、电话、产品名、独特卖点、售价、竞价中的排名，并记录下当前的日期。

# **第 4 步：跟踪做竞价排名的网站**
