# 第 08 节：是永恒的激情让企业家立于不败之地

什么是激情？

举个例子：鸡蛋和鸭蛋哪个更好卖呢？

谁都知道是鸡蛋好卖，顾客容易接受，为什么？是鸡蛋便宜吗？更有营养吗？不是的，研究表明，是因为鸡下蛋以后比鸭子兴奋，会到处呱呱叫，兴奋引起注意！

这就是企业家立于不败之地的秘诀——激情。

始终寻找激情，保持兴奋度，把这种激情传染影响到团队、股东、顾客、加盟商、代理商等一切跟你相关的人，你就成功了，为什么？
