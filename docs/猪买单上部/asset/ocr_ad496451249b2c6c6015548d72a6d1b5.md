# 第一：垂直供应链整合

未来没有省代理、市代理、县代理等代理商，没有分销商，可能有的中间环节就是企业直接的业务推广及区域服务网点，这是整个商业进化的结果，传递价值的方法会发生巨变，你已经看到，李宁店关了上千家了，百盛开始关门了，杭州关了一半的店铺。

怎样以更便捷的方式更低的成本传递价值，这是必然的！
