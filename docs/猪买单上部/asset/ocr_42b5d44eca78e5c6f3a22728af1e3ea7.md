# 最后谈谈下策：付出模式。

付出模式有两种：付出现金、付出股权。

先谈谈付出现金——

如果你试了上策、中策，都不奏效，那么你可以跟对方谈，“我还是愿意交您这个朋友，为了表达我的诚意，我愿意先付钱，我可以付您进场费或者广告费！”

当你拿出付费这个杀手锏的时候，每人可以抵挡——只要你付的足够让对方动心！

不管你是以哪种名义付费：公关费、赞助费、堆头费、促销费、广告费、进场费………
