# 不是你要卖什么东西，而是顾客想买什么东西。

这是一种从外到里的思维！

“我们正在从“请消费者注意”过渡到“请注意消费者”！

什么意思呢？

“要占领消费者的心智。” 不是你要卖什么东西，而是顾客想买什么东西。这是一种从外到里的思维。

未来不是你需要什么，而是请问我能为您做点什么，所有人都变成顾问式销售，这是更符合人性的。

产品畅销的关键不是拼广告！

不是拼成交能力！

不是拼招商能力！

更不是拼一些忽悠的话术……

那拼什么？

所有的组织比拼的是谁更能通人性，谁能真正站在客户的角度，谁能给客户带来更好的体验。

·体验经济的最重要的一个词是——爽！
