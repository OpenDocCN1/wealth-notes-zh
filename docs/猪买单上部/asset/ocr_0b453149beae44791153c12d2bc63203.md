# 第 05 节：媒体合作的购买方式及成败关键

花钱是最直接的，前提是你只要测试好你广告文案的成交 率。如果广告文案的效果还没测试出来，花钱是砸钱、是烧钱、 是浪费钱，就是把钱、把白花花的银子扔到臭水沟里，这就是 大多数广告人都在做的！
