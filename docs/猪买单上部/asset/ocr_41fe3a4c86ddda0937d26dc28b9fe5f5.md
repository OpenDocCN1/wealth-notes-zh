# 第三个：最平衡

你不能一昧去追求结果，你更要注意结果背后的后果。有时候结果很美好，后果很严重。

手术很成功，病人死掉了，这就是悲剧！

我们要考虑平衡，平衡每个参与方的价值观和利益。我问你：什么是大人物，什么是小人物？

我告诉你，只要参与你的系统的，每一个都是大人物。
