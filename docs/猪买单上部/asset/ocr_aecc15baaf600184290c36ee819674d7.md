# 乔布斯第二板斧：推介会

乔布斯除了一身长期不变的衣着之外，还有什么？

——产品推介会

每当苹果有新产品的时候，乔布斯就上台“表演”了，

![](bbox=[0.12, 0.35, 0.86, 0.5])

我们看看乔布斯 1998 年—2011 年这段时间，几乎每次新产品都是乔布斯做新产品推介会……

永远不变的装束，身穿牛仔裤、黑色 T 恤衫、运动鞋，然后手里拿着最新的苹果产品，展示产品如何给人类带来了最新科技、公司实力、产品市场前景等等……

然后呢？然后就没有然后了……
