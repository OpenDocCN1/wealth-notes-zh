# 课程描述：

本课程讲解了现代传播的特点：软文炒作。同时讲解了炒作所要遵循的原则、网络炒作源于宣传策划，并以案例讲解软文炒作策划。

# 学习目的：

本课程指导学生：要注重“他们用网络炒作，我们用网络写作”，强调作者在“炒作”面前应保持的心态。

# 涵盖主题：
