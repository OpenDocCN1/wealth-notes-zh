# 课程描述：

本课程讲解了软文写作的五要素：主角、素材、思想、写作手法、写作载体。同时讲解了撰写软文时的十二项注意事项。

# 学习目的：

写作要素是软文写作时的不可避免，不可缺少的基本因素。通过学习，学生要掌握写作时的要素把握，同时要注意一些写作规律和问题。
