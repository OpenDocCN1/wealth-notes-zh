# 课程描述：

本文讲解了什么是软文，全面介绍了软文的作用、软文的本质、写作的本质、软文写作的特点、写作意识、软文写作的弊病，并强调软文写作要善于叫读者的胃口，其核心是强大的说服力。

# 学习目的：

本文是软文写作系统学习的入门课程，讲解了软文写作的基本知识。

# 涵盖主题：

创业者，初创公司，知识产权，中小企业，知识产权保护，技术公司
