# 课程描述：

本课程讲解了：软文的首要作用是宣传，并指出宣传是软文长期的一项性工作。“行动即宣传”围绕这一核心思想，本文讲解了宣传的概念、宣传的目的、宣传的地位、宣传的成功、宣传的原则、宣传的艺术。

# 学习目的：

通过学习，本文强调学生必须了解软文强大的宣传作用，要明确软文是为了宣传，是长期的努力。
