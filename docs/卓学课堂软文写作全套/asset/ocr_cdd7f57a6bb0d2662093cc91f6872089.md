# 课程描述：

从编辑角度看软文，只剩下无情的删除与“石沉大海”。本课程从编辑角度入手，来讲解软文写作的特点、软文需要注意的问题。

# 学习目的：

其一，软文即文章；其二，软文写作要抄，不要套，本课程旨在使学生全面了解软文写作中的注意要点。

# 涵盖主题：

软文，软文写作，写标，写作手法，写作指南，写作技巧
