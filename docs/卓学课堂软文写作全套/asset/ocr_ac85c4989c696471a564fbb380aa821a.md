# 宣传的成功

共产党和国民党都很重视宣传，但效果却有很大差距。毛泽东在井冈山时期多次谈到这种差距，他提出了一个问题： “共产党是一个穷党，又被国民党广泛地无孔不入地宣传为杀人放火，炉泽抢掠，不要历史，不要文化，不要祖国，不孝父母，不敬师长，不讲道理，共产公妻，人海战术，总是一群青面獠牙，十恶不赦的人。可是，事情是这样地奇怪，就是这样的一群，获得了数百万人民群众的拥护”。解放战争时期，蒋介石也不得不承认，“现在所遗憾的，是我们政府里面一部分人员受了共产恶意宣传，因之心理动摇，几乎失了自信。”

毛泽东常常这样告诉全党：“我们要attrs在人民群众中，广泛地进行宣传教育工作，使人民认识到中国的真实情况和动向，对于自己的力量具有信心。” 同时他不断纠正宣传中的工作方向。例如毛泽东起草的《纠正土地改革宣传中的“左”倾错误》就是典型，通过那次纠正宣传中的偏差，他规范了宣传部门几个月检查一次工作，发扬成绩，纠正错误的制度。毛泽东把党的领导机关的工作概括为两项任务：了解情况和掌握政策。它对宣传工作的领导，就是在了解敌我友三方面情况的基础上不断调整政策宣传。
