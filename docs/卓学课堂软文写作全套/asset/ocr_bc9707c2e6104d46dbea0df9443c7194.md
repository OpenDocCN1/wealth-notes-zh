# 08年1-9月汽车网络软文媒体监测分析

据慧聪研究媒体监测统计数据显示,2008年前三季度汽车共投入网络软文884070篇，其中乘用车的软文篇数占96.8%，商用车仅占3.2%；在乘用车中以中级轿车软文量所占份额最大，达四成多。与平面软文相比，乘用车的网络软文量接近平面软文量的3倍，商用车网络软文和平面软文相差不大，可见乘用车汽车厂商更注重在网络上加强软文的宣传攻势。
