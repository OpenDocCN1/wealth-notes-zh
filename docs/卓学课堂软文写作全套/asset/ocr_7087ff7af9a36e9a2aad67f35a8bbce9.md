# 软文投放

以 08 年 1-10 月药品业报刊软文投放媒体监测分析

根据慧聪邓白氏研究媒体监测统计，2008 年 1-10 月药品报刊软文投放总篇数接近 1 万篇，总字数达 2 千多万字，其中报刊软文字数前四位的分别是肿瘤疾病用药、脊疾病用药、肝胆疾病用药和精神疾病用药，这四类药品报刊软文总字数占药品总体报刊软文字数的六成以上。（见图 1）下面将重点对这四类药品的报刊软文投放情况加以分析。
