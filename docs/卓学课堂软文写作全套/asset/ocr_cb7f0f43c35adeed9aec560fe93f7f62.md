# 课程描述：

本课程讲解了快速写作的方式，讲了解批量写作的特点，阐明写作中“下笔如神注，洋洋千万言”的学习历程。

# 学习目的：

通过学习，学生要注意：在写过过程中，下笔绝对不能停顿。本课程同时强调：学生要苦练文摘能力。

# 涵盖主题：

软文，软文写作，写传，写作手法，写作指南，写作技巧
