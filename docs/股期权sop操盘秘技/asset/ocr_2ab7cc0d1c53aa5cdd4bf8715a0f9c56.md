# 期貨指數的應用（上漲波段指標）

期貨指數如何波段操作呢？首先必須學會判定指數是否有波段行情。SOP的「波段指標」其功能就是在判定指數或個股是否有波段行情。若完成波段指標的三個條件，就有波段行情可期。波段指標的四個條件可參閱本書第五章的內容。
