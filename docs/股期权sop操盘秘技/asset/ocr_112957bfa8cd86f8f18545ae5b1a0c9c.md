# 上升與下降45度線的實例

畫45度線對初學者是比較困難的，除了要設定K線圖的黃金矩形與K線的數量之外，最重要的是不知從何處下手畫45度線。原則上有三個重點如下：

一、對於操作期貨的朋友，在每一波的低點或高點皆可畫45度線。因為期貨大都是短線或當沖操作。可利用突破或跌破45度線出手。

二、若欲判定漲、跌、盤的轉折點，必須突破下降45度線之後，才能反向畫上升45度線，或是跌破上升45度線之後，才能反向畫下降45度線。

三、畫線的技巧，盡量以不要切到K線（棒）為原則。

45度線是股市三寶的「寶王」，它的應用非常廣泛，尤其運用在選擇權的成功率最高。期交所於民國101年11月「週選擇權」上路後，更可利用45度線的轉折點操作選擇權。

筆者繼本書之後，會再寫一本《週選擇權獲利大解密》。其中就會多次引用45度線的轉折點操作週選擇權，您會發現成功率非常高。因此建議讀者應學會畫45度線。
