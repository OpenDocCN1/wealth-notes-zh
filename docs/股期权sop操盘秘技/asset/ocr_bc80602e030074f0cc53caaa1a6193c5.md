# 四、問：何謂領先指標？

答：政府對於經濟景氣循環除了以燈號判定之外，也設定七項的領先指標：1.外銷訂單指數。2.實質貨幣總計數。3.股價指數。4.製造業存貨量指數。5.工業與服務業加班工時。6.核發建照面積（住宅、商物業、工業、倉儲）。7.SEMI接單出貨。領先指標好比人要感冒之前會先打噴嚏，那麼打噴嚏就是感冒的領先指標。

# 五、問：股市的領先指標有幾個？

答：我們設定了四個領先指標：1.價乖離。2.軌道線。3.RSI臨界值。4.技術指標二次背離。其中技術指標包含RSI、KD、MACD三種。只要其中有一種出現二次背離，皆可視為領先指標。

# 六、問：領先指標會準嗎？哪一個比較準？

答：技術分析沒有百分百的準確度，我們設定的四個領先指標皆有8成以上的可信度。它可以讓我們買到相對低點或賣到相對高點，至於哪一個較準，筆者認為各有千秋。如果硬要比較，其順序為軌道線與技術標二次背離以上、價乖離、RSI臨界值。
