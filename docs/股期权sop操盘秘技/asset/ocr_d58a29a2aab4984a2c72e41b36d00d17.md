# 股票SOP的應用（領先指標軌道線）

本章第八章的第一節主要是講如何把SOP應用在股票的操作上。前面已談了很多領先指標、波段指標的應用。或許讀者會問：為何股市三寶與成功法則這兩個方塊談得比較少？因為我們在《股市三寶》書中都有論述，讀者可自行參考。

領先指標中的四個內容：軌道線、價乖離、RSI臨界值、技術指標二次背離以上。其中軌道線的成功率最高，但也是投資人最難學會的畫法技巧。建議可參考《10倍數操盤法》書中第四章的說明。

# 軌道線的領先指標要注意的兩個重點

+   一、在上升軌道中的上沿才是領先指標，下沿不是。

+   二、在下降軌道中的下沿才是領先指標，上沿不是。
