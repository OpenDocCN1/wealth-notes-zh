# 完成波段指標的失敗實例

現在筆者舉一個已經完成下跌波段指標三個條件以上，但失敗的例子給讀者參考。

如圖（7-4）是大盤指數日線圖

+   一、圖中①所示，均線做出三線合一向下。

+   二、圖中②所示，跳空跌破長期上升趨勢線。

+   三、圖中③所示，成交量低於基本量三天以上。

+   四、若從週線圖（7-5）亦可看出技術指標，週RSI做出雙頭向下。週KD也做出雙頭向下。

+   五、嚴格講起來，波段指標的四種條件已全部完成。理應有下跌的波段行情，至少會有500點以上的下跌空間。

+   六、雖然下跌方向抓對，但是指數自8089下跌到7688不到500點，就反轉向上。這是一個失敗的實例，不過就週線來看，自8175跌到7688也接近500點的空間。

究其失敗的原因，可能是當時有立法委員質詢財政部張盛和，是否有520總統就職行情？財政部長回答：「值得期待。」，再加上台積電法說發表業績大好的利多消息。台股受此消息面的影響提前止跌回升。因為消息面的影響力，本來就大於基本面與技術面。
