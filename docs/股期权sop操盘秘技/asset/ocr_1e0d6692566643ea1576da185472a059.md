# K線上漲一竇的完成條件

K線可取三根組合K線，做出四種組合狀態，如下圖所示。若三根K線符合四種狀態其中的二種以上，K線這一竇就算完成。

K線上漲一竇的四種狀態

+   1. 頻頻出現下影線
2. 長紅吞噬前面2根黑棒
3. 跳空上漲缺口
4. 三天不破新低
