# 期貨SOP的應用（領先指標正價乖離）

前兩個例子是負價乖離。現在筆者舉一例正價乖離給讀者參考。

# 領先指標（正價乖離）的出手點

如圖（8-19）是期貨指數的日線圖

+   一、圖中①所示，期貨指數在98年9月9日，當天的6日均線7176。

+   二、圖中②所示，隔天9月10日指數急漲出現正價乖離，價乖離的參數5～6%。

+   三、正價乖離的算法：$7176 \times 1.05 = 7534$ 或 $7232 \times 1.06 = 7606$。指數在9月11日最高來到7758，收盤7361。

+   四、這次出現正價乖離當天就拉回，若在第一天眼手至少有200點以上的利差。

重點提示：

+   1. 或許讀者會問當指數或股價出現連續幾天價乖離，要在第一天或第二天或第三天…才出手？

+   2. 筆者認為要看當天的氣勢與技術指標的位置高低有關。對領先指標有信心的朋友可分批攤平降低成本，最後還是會贏。
