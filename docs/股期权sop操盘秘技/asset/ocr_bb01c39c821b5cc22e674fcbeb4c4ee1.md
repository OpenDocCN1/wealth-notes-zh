# SOP的操作順序

第四個（STEP-4）

成功法則：從SOP方塊流程圖（2-1）可看出，當進入第二個方塊「轉折指標」之後，箭頭指向第四個方塊「成功法則」。換言之，當股市三寶判定指數或股價由「跌」進入「盤」或由「漲」進入「盤」之後，就可進入第四個方塊「成功法則」，開始進場操作。

+   一、在成功法則的方塊中，筆者設定三個要點：1.可利用看（移動平均線），算（黃金切割率），畫（畫線技巧），預估指數或股價的支撐與壓力。2.可利用選股八大法則開始選股、換股、設價（買進、賣出或停利、停損）。3.遵守紀律執行停利、停損。

+   二、在圖（2-1）中也可看到在第二個方塊中另一個箭頭指向第五個方塊「續航力道」。這表示股市三寶判定是「漲」勢或「跌」勢。就可預測指數是否有續航力道（波段行情）。不過在上一頁我們有提示，若單靠股市三寶判定波段行情，證據力薄弱。必須靠第三個方塊「波段指標」補強。因此在圖（2-1）你會發現「波段指標」有另一個箭頭指向「續航力道」。

重點提示：

+   1. 在成功法則中，操作股票的重點步驟。如何選股換股可參閱《K線實戰秘笈》的八大選股內容。

+   2. 遵守紀律執行停利、停損，這一點非常重要必須確實執行。
