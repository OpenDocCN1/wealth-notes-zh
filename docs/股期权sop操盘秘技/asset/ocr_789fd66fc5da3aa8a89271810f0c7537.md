# 6-3 守紀律執行停利停損

國有國法，家有家規。當一個人違反國家的法律就必須接受法律的制裁，這是天經地義的事。若有人違法不受法律制裁，豈不是天下大亂。

又例如開汽車或騎機車不守紀律違反交通規則，必定接受開罰單。以前筆者為了趕場上課，在高速公路一不小心超速，回家後不久就接到罰單，經過幾次被罰之後，現在筆者在高速公路開車時，就特別注意不能超速，至今就很少收到罰單了。

操作任何金融商品也是如此，務必要有停損觀念。筆者近20年的股票教學中，發現投資人虧損的最大原因就是沒有停利、停損的觀念。

當過兵的朋友都知道「紀律」的重要性。若不守紀律違反軍法，判刑很重。因此再次呼籲投資朋友務必要有停利停損的觀念。

通常股市新手大都沒有停利停損的觀念，筆者也是過來人，經過痛苦的經驗才改正過來。因此奉勸投資人務必養成停利停損的習慣。謹記「寧可錯賣，不可錯買」。只要發現不對就該停損退出。
