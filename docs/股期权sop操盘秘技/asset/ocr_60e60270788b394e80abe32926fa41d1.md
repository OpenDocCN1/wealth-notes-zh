# 長期上升與下降趨勢線的實例

現在筆者舉個實例印證長期上升與下降趨勢線，給讀者參考。

如圖（5-3）是大盤日線圖

+   - 圖中①所示，長期上升趨勢線。您會發現指數自民國 100年12月19日一路上漲，直到民國101年3月20日才跌破上升趨勢線，時間長達3個月。

+   - 當指數跌破長期上升趨勢線，又配合三線合一向下， 再加上成交量小於基本量三天以上，符合波段指標三 個條件，因此形成下跌波段行情，指數下跌500點以 上。

如圖（5-3）是大盤指數日線圖

+   - 圖中②所示，長期下降趨勢線。您會發現指數自3月 28日一路下跌，直到101年6月18日才突破下降趨勢 線，時間長達2.5個月。

+   - 當指數突破長期下降趨勢線，又配合三線合一向上， 再加上成交量出現攻擊量，符合波段指標三個條件， 因此形成上漲的波段行情，指數上漲500點以上。
