# 蔡序

這是一本很值得參考的書，看的當中您應去想：我自己的SOP是怎樣順序？也就是我為什麼買一檔股票透過什麼？為什麼不依照陳霖老師的SOP，那麼成功率就大增了。最近奧林匹克集團也正在把各部門的SOP流程整理中，接到陳霖老師寫這本書的序頗有共鳴，深深覺得這是陳霖老師集大成之作。

陳霖老師一直是鑫報很受歡迎的分析師，每次演講、教學都是很叫座都有很好的口碑。其實我最欣賞陳霖老師的是他對股市與全體股民的愛心、慈悲心，他出書的出發點是要幫助人們，他希望接受他的人用心把技術學好，不要在股市中受傷，還能從股市改善自己的生活，以這樣的態度來經營一個事業，他必然成功。

各位讀者，一本好的書不是只有著者在告訴您什麼，一本好書還要讓讀者跟著思考一股市能不能由『過去』去抓住『未來』，那裡藏著無窮的財富。

前面幾本書都大賣，陳霖老師的書永遠有三個特點：

+   一、他把股票期貨教學『口訣化』，例：三大原則、六大口訣、九大重點，把內容用口訣來重點化，讓大家易記易操作。
