領先指標（技術指標RSI、MACD在高檔區二次背離）的出手點

如圖（8-26）是期指日線圖

+   一、圖中①所示，MACD柱狀態在零軸之上做出一次背離，不是領先指標。只能視為最佳指標，指數仍會回檔，但回檔幅度較小，僅回檔兩天。

+   二、圖中②所示，MACD柱狀態在零軸之上做出二次背離，可視為領先指標。隔天指數開始回檔。如圖中⑤所示，指數自8196回檔到7821。

+   三、圖中③所示，RSI在高檔區做出一次背離，不是領先指標。只能視為最佳指標，指數仍會回檔，但回檔幅度較小，僅回檔兩天。

+   四、圖中④所示，RSI在高檔區做出二次背離，可視為領先指標。隔天指數開始回檔。如圖中⑤所示，MACD與RSI同步做出二次背離之後，指數自8196回檔到7821。
