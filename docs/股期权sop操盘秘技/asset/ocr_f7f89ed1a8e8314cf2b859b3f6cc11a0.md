# 以《股期權SOP操盤秘技》為藍圖研讀老師的著作更有效率

廣大的投資朋友又有福了，股市名师-陳霖老師又要推出新作了，這是一本關於在投資商品上操作SOP（Standard Operation Procedure/標準作業程序）的書，涵蓋股票/期貨/選擇權等投資商品，當然仍舊承襲老師一貫寫作風格，以淺顯易懂之口語，並加上許多實務操作經驗與圖示，讓讀者能過細細咀嚼品味的吸收。

在投資股市世界中要學習的技能與知識是相當的廣泛，而老師把它簡化後並用更口語化的教學來讓大家更能了解股票市場，學習如何判定漲跌盤及出手時機，作為股市的裁判，這些基本功夫通通在老師的著作中，舉凡如「10倍速操盤法」、「股市三寶」、「期權賺很大」、「K線實戰秘笈」、「45度操作獲利秘诀」等著作，都是老師對股市的研究心血與實務經驗、而SOP方塊流程圖更可說是將操作技巧展現無疑，讀者可以此為概要藍圖去研讀老師的著作，可更有效率的加快學習效果。
