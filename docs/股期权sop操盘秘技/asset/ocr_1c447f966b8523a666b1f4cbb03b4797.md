第四個方塊（成功法則）：

+   1. 功能：判定漲、跌、盤之後，可利用看、算、畫三種方法預估指數或股價的支撐與壓力。所謂看：就是看移動平均線。所謂算：就是算黃金切割率。所謂畫：就是利用畫線技巧，如趨勢線、頸線、軌道線、45度線...等，以上三種方法預測壓力、支撐，可參閱《期權賺很大》第二章的說明或《45度線獲利秘訣》第八章的說明。

+   2. 選股換股設價。如何選股可參閱《K線實戰秘笈》第九章第三節的八大選股要領。此八大選股要領就是選股的SOP。

+   3. 遵守紀律執行停利、停損。這一點非常重要，必須嚴格要求自己做到，才能規避風險。

第五個方塊（續航力道）：

+   1. 功能：從波段指標可看出指標的續航力道，也可以說是波段行情。波段行情可分為上漲波段行情與下跌波段行情。

+   2. 若完成波段指標三個條件以上，對大盤而言，指數有500點以上的漲、跌空間，對個股而言則有2～3成以上的漲、跌空間。
