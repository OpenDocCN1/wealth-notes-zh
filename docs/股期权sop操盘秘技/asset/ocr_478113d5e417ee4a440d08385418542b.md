# 選擇權SOP的應用（組合採取策略）買權多頭價差

當您決定要做「多頭價差」時，首先必須研判指數到結算日是偏漲的趨勢，但是又怕上檔有壓力，漲幅不高，或怕做錯方向。此時可採取「多頭價差」。

圖（8-49）是大盤日線圖。如圖中①所示，在102年4月19日指數跳空上漲，且均線做出三線合一向上。研判指數到結算日（5月15日）是「偏漲」的趨勢。但又怕前波高點3月11日（8089）的壓力無法突破。因此操作一組買權的多頭價差，履約價設定在買進買權7800，賣出買權8100。
