# 大家一起來，團結力量大

上一頁所統計的17種指標中，每一個指標皆可獨立使用，若合併使用成功率就會大幅提高。換言之，當您發現在同一天或3～5天之內，同時或陸續出現2～3個指標以上，此時出手切入操作就可大幅提高勝率，這就是筆者所說的「大家一起來，團結力量大」。

筆者撰寫至此，適逢陸軍下士洪仲丘禁閉生遭虐死案，引起大家質疑军方隱瞞真相，導致「公民1985行動聯盟」發動上凱道抗議，人數超過20萬，逼使馬總統與江院長對軍中沈冤提出了四點解決方案。這就是「大家一起來，團結力量大」的最佳寫照。

無論操作股票、期貨、選擇權或國際金融商品皆是如此，在期貨指數的訓練課程中，筆者亦設定的「分鐘線」的九個切入點，當您看期貨指數1分線或5分線的K線圖，若發現同時出現2～3個切入點一起來。此時切入操作，就會大幅提高勝率。

本節筆者會列舉一些實例給讀者參考，雖然技術分析不可能百分百，但可以靠自己的實力將成功率提高，只要操作10次，能做對8～9次，那麼不成功亦難。除非「做錯的部份」沒有快速停損，導致虧損擴大，侵蝕到「做對的部份」的利潤。從事金融操作的朋友務必要有停利停損的觀念，否則白忙一場不如不做。
