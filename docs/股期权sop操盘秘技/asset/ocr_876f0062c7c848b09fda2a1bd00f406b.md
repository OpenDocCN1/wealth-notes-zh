# 股票SOP的應用（領先指標RSI臨界值）

在SOP方塊圖的第一個方塊（領先指標），我們設定四個：1.價乖離、2.軌道線、3.RSI臨界值、4.技術指標的二次背離。其中價乖離與軌道線是屬於「線型指標」。而RSI臨界值與技術指標二次背離是屬於「技術指標」。

# 領先指標（RSI負乖離臨界值）的出點

如圖（8-7）是美律（2439）的日線圖

+   一、圖中①所示，3日RSI與6日RSI負乖離過大（開口太大）高達負24（3日RSI－6日RSI＝－24）。符合RSI臨界值的條件22～25以上。

+   二、圖中②所示，隔天股價未再破新低。且K棒出現紅K或強線即切入短多。股價自45.7元漲到48.75元。可賺取短線價差。

+   三、圖中③所示，3日RSI與6日RSI負乖離高達負29（3日RSI－6日RSI＝－29），符合RSI臨界值22～25以上。

+   四、圖中④所示，股價自50元漲到54.5元，可賺取短線價差。

重點提示：

+   1. 領先指標是逆勢單，因此只能短線操作有賺就跑，不能久抱。

+   2. 除非在反彈中，完成上漲一竄或改變成漲勢才可波段操作。
