# ## 股期貨SOP 操盤祕技

+   2. 切忌每天一定要出手，惟有指數來到自己預測的支撐與壓力區，觀察分時線有無九重點出現2～3個以上才出手，如此勝率很大。若看不懂盤勢，則不做單。

+   3. 領先指標出現時，因是逆勢單，所以藝高人膽大者操作時請少量為之。然而我把領先指標視為平倉的時機。例如上漲趨勢出現領先指標，多單平倉，不做短空，下跌趨勢出現領先指標，空單回補，不搶短多。

+   4. 我覺得越簡單越受用的就是葛蘭華法則的4個買點與4個賣點。因為一條多空線就告訴你現在是漲勢還是跌勢，甚至盤整。

+   5. 當方向做對，就勇敢抱著等待賣出訊號，若獲利的方向走多久，那就抱多久這樣才有出場的理由，若做錯就必須馬上處理，所以賠多少自己決定，所以賺多少由市場決定，但虧多少則自己決定。

最後每個操作者都應該有自己的一套SOP。若你還是沒有的話，趕快參加陳霖老師的訓練課程，制定自己一套進出場的SOP，才不致隨著盤勢隨波逐流，葬生股海。
