最佳指標的應用（香港恆生指數）

SOP的各項指標與筆者篩選出的九個最佳指標皆可用地於國際指數或其它各項金融商品。很多操作國際金融商品的學員，現在皆引用SOP的領先指標、股市三寶、波段指標與最佳指標尋找最佳的出手點，且獲利頗豐。

香港恆生指數實例

如圖（9-10）香港恆生指數日線圖

+   一、圖中①所示，3日RSI做出三個頭與一次背離。

+   二、圖中②所示，KD指標的K值做出三個頭且一次背離。

+   三、圖中③所示，MACD柱狀體在零軸之上做出一次背離。

+   四、圖中④所示，K線做出島型反轉（3島）向下。

+   五、圖中⑤所示，K線拉長黑之後，均線又做出三線合一下。

因此指數自23512一路下跌到19426才止跌反彈，從圖（9-10）也可看出指數要反彈之前，3日RSI做出二次背離（領先指標）。KD與MACD柱狀體在零軸之下也做出一次背離，醞釀反彈。

如圖（9-10）香港恆生指數日線圖

+   一、圖中⑥所示，3日RSI做出三個底，且出現二次背離的領先指標。

+   二、圖中⑦⑧所示，KD與MACD做出雙底，且出現一次背離。因此指數自19426開始反彈到21964。
