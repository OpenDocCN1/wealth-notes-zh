# 8-3 選擇權SOP的應用

筆者時常遇到很多投資朋友問我，選擇權好不好做？我回答：「好做。」，但是會補充一句「必須學會做」。任何一件事情，只要學會做，就覺得好做。若沒有學會做，當然不好做。

就以股票、期貨、選擇權這三個商品而言，我還是認為選擇權比較好做。分析如下：

+   一、股票：無論做多或做空，都必須選對股票才會賺錢。

因此單單花在選股方面就浪費很多時間。縱然大盤的趨勢方向看對，若選錯股還是不會賺錢。

+   二、期貨：操作期貨指數對投資人而言難度更高。因為期指主力操盤的跡象很明顯，若看盤的技巧不夠，無法買到當日的相對低點，或放空到相對高點，很難賺到錢。

+   三、選擇權：只要判斷大盤指數的方向正確就會賺。若再學會預估壓力與支撐，那麼可利用組合操作策略，多空皆可獲利。在《期權賺很大》書中皆有詳細的說明。
