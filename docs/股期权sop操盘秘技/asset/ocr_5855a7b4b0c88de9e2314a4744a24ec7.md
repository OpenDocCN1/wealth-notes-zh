# 選擇權SOP的應用（組合操作策略）買權的空頭價差

當您決定要做「空頭價差」時，首先必須研判指數到結算日是偏跌的趨勢，但是又怕下檔又支撐，跌幅不深。或怕做錯方向。此時可採取操作「空頭價差」。

圖（8-54）是大盤日線圖。如圖中①所示，在102年6月3日指數跳空下跌，且均線做出三線合一向下。研判指數到結算日（6月19日）是「偏跌」的趨勢，但又怕跌幅不深，研判拉回前波高點8089會止跌。因此操作一組買權的空頭價差，履約價設定在買進買權8300，賣出買權8000。

買權的空頭價差：買進買權8300，賣出買權8000

+   一、如圖（8-54）所示，102年6月3日在壓力區8300的位置買進買權（BC）。在支撐區8000的位置賣出買權（SC）。

+   二、如圖（8-55）行情表所示，6月3日當時8300履約價的權利金42點。8000履約價權利金226點。

+   三、如圖（8-56）行情表所示，6月19日結算日。當日買權8300的權利金0.1點。8000的權利金30點。

+   四、8300（BC）履約價虧損0.1−42=−41.9（點）。8000（SC）履約價獲利226−30=196（點）。

+   五、合計獲利：196−41.9=154.1點。
