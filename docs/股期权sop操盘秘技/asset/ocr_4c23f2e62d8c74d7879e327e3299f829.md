# 大家一起來，團結力量大（大陸深圳A股指數）

先前已提過SOP適用於國際股市或其它金融商品，筆者以大陸深圳A股指數做例子說明如下。

如圖（9-19）大陸深圳A股指數

一、圖中①②③所示，下降軌道下沿是領先指標，當指數觸及領先指標之後，皆會反彈，但未完成波段指標的三個條件以上。因此沒有上漲波段行情，領先指標僅能短線操作有賺就跑。

二、圖中④所示，均線做出三線合一向上（最佳指標）。

三、圖中⑤所示，指數突破長期下降趨勢線。

四、圖中⑥所示，RSI、MACD在低檔區做出三底或雙底（最佳指標），且出現攻擊量，完成上漲波段指標的三個條件。指數自944上漲到1092.54。

五、圖中⑦⑧⑨所示，RSI、KD在高檔區做出三個頭且出現一次背離，成交量低於基本量（5日均量）以下，均線再做出三線合一下，完成下跌波段指標的三個條件。指數自1092.54下跌到805.89。直到RSI、KD、MACD打出雙底後，才開始反彈上漲自1027。
