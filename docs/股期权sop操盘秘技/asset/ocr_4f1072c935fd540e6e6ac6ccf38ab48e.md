# 7-3 完成波段指標失敗的案例

我們知道技術分析不可能百分百，試想若有一個指標成功率百分百，我們就可用全部家產押下去，一夜之間就可致富，事實上是無可能的。

學習技術分析的朋友要體認技術分析仍存在一些盲點，因此偶爾也會失敗。因此在操作上不能大進大出，應以循序漸進的方式穩健操作，穩健獲利，才是正確的作法。

每一個人技術分析的功力不一樣，端看每一位投資人對於各種指標的看法是否精準。換言之，每一位分析者對於各項指標或同一種指標的看法不盡相同。換句話說，即使同樣一個指標如RSI、KD…等，每個人的看法也不同，當然就會產生不同的結果。

筆者歷經20年的淬鍊，在技術分析的領域中，不斷的實驗、統計、實戰、印證、尋找出成功率比較高的指標，做為上課的題材。非常多的學員參加我們的訓練課程之後功力大增，紛紛來函表示谢意。筆者實在不敢居功，因台語有言：「有狀元學生，無狀元老師」。

看到學員們反敗為勝，快速累計財富，離苦得樂是筆者最感欣慰的事。
