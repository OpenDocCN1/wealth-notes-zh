# 日圓貶值完成上漲波段行情的三個條件

如圖（8-63）是美匯日圓的月線圖

+   一、圖中①所示，RSI、KD指標皆做出雙底或三個底交叉向上。

+   二、圖中②所示，K線突破長期下降趨勢線。

+   三、圖中③所示，均線做出三線合一，且K線突破前波高點84.17。

+   四、如上述完成SOP第三個方塊「波段指標」的三個條件，日圓開始展開波段的上漲（貶值）行情。日圓自75.58急速貶值到103.74，貶值的幅度高達37%。

日圓貶值從消息面的解讀，可說是日本首相<u>安倍晉三</u>的主導，但從技術面來看日圓在75.58時，技術線型做出三線合一已醞釀將完成波段指標的三個條件。剛好又遇到<u>安倍晉三</u>祭出量化寬鬆政策，讓日圓大幅貶值，應驗筆者常言：「線到消息到」。
