# 6-1 判定漲、跌、盤的轉折點並預測壓力、支撐

SOP的「成功法則」是屬於第四個方塊，當第二個方塊「股市三寶」判定指數或個股由「漲」進入「盤」或由「跌」進入「盤」整趨勢，此時就可進入第四個方塊成功法則，可參閱第二章SOP方塊流程圖。

在成功法則中，我們設定了三個重點：1.判定漲、跌、盤的轉折點並預測壓力支撐。2.選股、換股、設價。3.守紀律執行停利停損。

首先討論第一個重點，當股市判定「盤」之後，我們就可以開始選股操作，不必等到「漲」再切入。因為等到「漲」勢確定再進場操作，通常已經太慢了。期貨、選擇權亦是如此。

其實比較積極且手腳夠快的投資人在第一個方塊「領先指標」出現時就可酌量切入，才有機會買在相對低點，或賣到相對高點。

當我們開始切入操作股、期、權的時候，亦可利用看、算、畫，三種方法大約預測壓力與支撐的位置，便於設價買進或賣出。

+   - 所謂「看」是指看移動平均線，預測壓力與支撐。
- 所謂「算」是指算黃金切割率，預測壓力與支撐。
- 所謂「畫」是指利用畫線技巧，預測壓力與支撐。
