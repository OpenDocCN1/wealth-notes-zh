# 選擇權SOP的應用(組合操作策略)賣權的多頭價差

上一頁所分享的是買權的多頭價差，如果您選擇操作在賣權，那麼就稱作「賣權的多頭價差」。其操作方法與買權的多頭價差雷同。

只要是多頭價差，無論是買權或賣權，都是買低賣高，所謂：「買低賣高」其語意如下：
買低：買進較低履約價的買權或賣權。
賣高：賣出較高履約價的買權或賣權。

現在我們沿用上頁的例子，操作一組賣權的多頭價差。

+   一、如圖（8-52）行情表所示，4月23日買進賣權（BP）7800，權利金40.5點。賣出賣權（SP）8100，權利金191點。
二、如圖（8-53）行情表所示，5月14日結算日前一天出場。當日賣權7800的權利金0.2點。8100的權利金0.6點。
三、7800（BP）履約價虧損0.2－40.5＝－40.3（點）。8100履約價（SP）獲利191－0.6＝190.4（點）。
四、合計獲利：190.4－40.3＝150.1點。
