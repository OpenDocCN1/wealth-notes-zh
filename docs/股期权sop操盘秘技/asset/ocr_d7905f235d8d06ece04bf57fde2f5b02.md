# 股海指南針SOP

從事金融市場操作其時間有多久學習（研究）時間該有多長。隨時懷抱謙卑的心與態度。

不斷修正自身操作盲點，方能在市場站穩那一小塊沙洲，既是沙洲總有被股海沖毀之慮!!!

為使沙洲進化為堅不可摧如金字塔般的堡壘，因此必須建立優良且成功的操作模式，此模式我們稱它為「股市SOP」。

# 股期貨SOP是技術分析的精要

老師研究發明的股市SOP乃技術之精要，把繁複.雜亂.難懂的技術如魔術般的演化為成功的操作系統，有道是:成功的操作模式簡華化重覆做。

+   1. 按表操作:以趨勢為前導判定漲、跌、盤。

+   2. 用策略執行：擬定操作計劃。

+   3. 再用紀律把關：確實執行停利與停損。

# 戒掉窮腦袋才有富腦袋

市場唯一不變的定律是瞬息萬變，茫茫股海中若沒有一套屬於自己的操作模式且這套模式需要確實精準且實用，如何以不變應萬變之姿，成為股市常勝軍？
