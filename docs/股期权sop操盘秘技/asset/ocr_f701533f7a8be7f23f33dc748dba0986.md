# 七、問：當出現領先指標之後，是否馬上出手？

答：領先指標出現時，可能當天或隔天就反彈，有時會連續維持1～3天，很少超過5天以上，因此新手可在第二天或第三天才出手成功率較高。而且領先指標是逆勢單，因此只能短線操作，有賺就跑，除非扭轉趨勢才能久抱。

# 八、問：股市三寶的功能為何？

答：SOP一共有五個方塊，股市三寶是第二個方塊。其主要的功能是判定漲、跌、盤的轉折點與控管資金，當股市或股價由「跌」進入「盤」，或由「漲」進入「盤」，就可進場操作。

# 九、問：波段指標的功能為何？

答：波段指標是SOP的第三個方塊，其主要的功能是判定是否有上漲的波段行情，或下跌的波段行情。波段指標設定四個條件。必須在短時間內，如3～5天或5～10天內同時完成三個條件以上，才會形成波段行情。所謂波段行情代表指數有500點以上的漲、跌幅空間，個股則有2～3成以上的漲、跌幅空間。
