# 股票SOP的應用（領先指標價乖離）

前面談到領先指標「價乖離」，筆者曾舉一檔個股茂迪，如圖（8-4）的例子，它是「正價乖離」。現在筆者再舉一個「負價乖離」的例子給讀者參考。

# 領先指標（負價乖離）的出手點

如圖（8-14）是可成的日線圖。可成是屬中型股（股本50～100億）。其價乖離的參數：12%～14%以上。

+   一、圖中①所示，可成在101年7月31日當日的6日均價160元。隔天8月1日盤中最低135元，出現負價乖離。

+   二、圖中②所示，可成在8月1日出現負價乖離。

其算法：160元×0.86=137.6元。當日最低價135元。

+   三、圖中③所示，可成在下一個交易日8月3日再出現負價乖離。

其算法：154元×0.88=135.5元。當日最低價135元。

+   四、連續兩天出現負價乖離之後，股價開始反彈。

+   五、圖中④所示，可成在101年10月29日又出現負價乖離。隔天就反應上漲，敢搶短多就有價差可賺。

# 重點提示：

+   1. 出現負價乖離不一定當天就反應，有時會連續出現1~3天才反應。

+   2. 如果沒有反應反而跌破負價乖離的K棒最低價位置135元就該停損退出。
