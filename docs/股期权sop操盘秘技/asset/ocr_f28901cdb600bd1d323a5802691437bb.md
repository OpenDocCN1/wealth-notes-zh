# ### 5-2 三線合一（波段指標第二個條件）

三線合一是波段指標的第二個條件，所謂三線合一是指5日均線、10日均線、20日均線，三條均線看起來很密合。在《10倍數操盤法》書中對三線合一都有描述。《期權賺很大》談到分鐘線的買賣點也再次提到三線合一。三線合一也是選股八大法則的其中一個重要條件。

# 上漲三線合一的選股口訣（做多）

+   一、三線合一，且K棒跳空上漲或拉出一根長紅突破前波高點。

二、前面3～6個月成交量小。

三、基本面佳，且有利多題材。

# 下跌三線合一的選股口訣（做空）

+   一、三線合一，且K棒跳空下跌或拉出一根長黑跌破前波的低點。

二、前面3～6個月成交量大。

三、基本面差，且有利空題材。
