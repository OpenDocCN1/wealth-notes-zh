# 股票SOP的應用（領先指標RSI臨界值）

上一頁舉美律的例子是RSI負臨界值。現在再舉兩檔個股榮化與飛宏兩檔出現RSI正臨界值給讀者參考。

# 領先指標（RSI正乖離臨界值）的出手點

如圖（8-8）是榮化（1704）的日線圖

+   一、圖中①所示，3日RSI與6日RSI正價乖離過大（開口太大）高達正24（3日RSI－6日RSI＝24）。

+   二、圖中②所示，隔天股價未再創新高。且K棒出現黑K或弱線，即切入短空。股價自34.7元跌到32.8元。可賺短線價差。

如圖（8-9）是飛宏（2457）的日線圖

+   一、圖中①所示，3日RSI與6日RSI正價乖離過大（開口太大）高達正24（3日RSI－6日RSI＝24）。

+   二、圖中②所示，隔天股價未再創新高。且K棒出現黑K或弱線，即切入短空。股價自25.1元跌到22.65元。可賺短線價差。

# 重點提示：

+   1. RSI負臨界值負乖離（開口）越大，且開口位置越低反彈成功率越高。

+   2. RSI正臨界值正乖離（開口）越大，且開口位置越高回檔成功率越高。
