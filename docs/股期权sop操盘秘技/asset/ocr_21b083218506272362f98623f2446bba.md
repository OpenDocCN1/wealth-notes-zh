+   一、圖中①所示，是下降45度線的標準畫法。
二、圖中②所示，是小波段頭部（高點）的精緻畫法。
三、圖中③所示，是下降45度線缺口的精緻畫法。當K線突破③之後，可視為完成45度線的上漲一寶，指數就會有「跌」改變成「盤」。

# 重點提示：

+   1. 畫線以不要切到K線為原則。
2. 跳空上漲缺口，畫在缺口上限。
3. 跳空下跌缺口，畫在缺口下限。
