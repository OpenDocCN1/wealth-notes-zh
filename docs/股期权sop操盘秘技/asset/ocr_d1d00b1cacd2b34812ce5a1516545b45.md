# 2-3 SOP的操作順序（邏輯）

了解SOP每一個方塊圖的功能之後，筆者再談一談SOP的操作順序。

# 第一步（STEP-1）

領先指標：當我們打開技術線型圖的第一件事，要先看的就是『領先指標』。您可從日線、週線或月線找找看，有沒有領先指標出現，如何找？往後的章節會詳細介紹。

+   一、如果有：就可少量切入操作股票、期貨或選擇權，其中期貨、選擇權的成功率較高。因為股票若選錯股就無法賺到短線的價差。

+   二、如果沒有：則進入第二個方塊「股市三寶」。查看股市三寶是否完成上漲一寶，或下跌一寶，並判定由「跌」進入「盤」，或是由「漲」進入「盤」。

+   三、若指數由「跌」進入「盤」，就可切入3成持股短多。期指也可設價多空操作。選擇權則可切入做多（賣出賣權）。

+   四、若指數由「漲」進入「盤」，就可切入3成持股短空。期指也可設價多空操作。選擇權則可切入做空（賣出買權）。

# 重點提示：

+   1. 領先指標它可以讓我們買到相對低點賣到相對高點。

+   2. 領先指標是逆勢單，因此投入的資金要少，且手腳要快有賺就跑，沒賺應設停損。
