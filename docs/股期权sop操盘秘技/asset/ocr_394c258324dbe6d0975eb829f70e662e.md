# 上漲45度線精緻畫法的三個條件：

+   1. 跳空向上的缺口
2. 橫盤後的突破
3. 小波段的低點（底部）

# 下跌45度線精緻畫法的三個條件：

+   1. 跳空向下的缺口
2. 橫盤後的跌破
3. 小波段的高點（頭部）
