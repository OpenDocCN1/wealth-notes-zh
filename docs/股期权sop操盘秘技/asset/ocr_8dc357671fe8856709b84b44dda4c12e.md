# 指數價乖離實例

如圖（3-1）是期貨指數日線圖

+   一、指數在100年11月23日與24日出現負價乖離，經過一個交易日後，指數在11月28日反彈。若在11月23日、24日搶短多期指11月28日高出，就可獲利50～100點以上。

+   二、指數連漲三天之後，在100年12月1日又出現正價乖離。隔天12月2日指數就開始拉回。若在12月1日短空期指，12月2日又可獲利50～100點以上。

+   三、讀者可以將價乖離寫成程式式追蹤，就可印證價乖離的可信度。

+   四、如圖（3-2）就是用程式繪出指數價乖離的圖形，上面兩條曲線是正5～6%，下面兩條曲線是負5～6%。若出現負價乖離，指數通常會在1～3日之內就反彈。反之出現正價乖離通常會在1～3日內回檔。

# 重點提示：

+   1. 領先指標有時會延續1～3天，最多不會超過5天。

+   2. 因此當領先指標出現時老手可分批切入。新手則等第二天或第三天再切入，以避免短套。
