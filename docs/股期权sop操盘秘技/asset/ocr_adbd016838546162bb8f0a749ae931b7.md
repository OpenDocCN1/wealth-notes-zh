# 10-2 桃園學員

# 股市SOP可說是縱橫股海的神兵利器

常聽人說：「最好的投資就是投資自已」，身處在這個M型社會裡，雖然有著穩定的工作，但一直提醒著自已要有憂患意識，所謂人無遠慮，必有近憂，誰曉得有一天公司會不會突然要求放無薪假、減薪甚至被裁員，連一個國家都有可能破產了，更遑論是私人企業。所以，培養第二專長也一直是自己努力的目標，也就因為如此，前前後後參加老師的訓練課程也有好幾遍了，每次老師來北部開課時，只要時間允許，都會固定去給老師「捧場」。

表面上是去給老師捧場，實際上是去挖寶的，幾乎每一輪課，或多或少都有一些新的體認，學到一些新的觀念與方法，尤其是近幾期課程中提到的股市SOP，有系統地將「領先指標」、「股市三寶」、「波段行情」串連起來，配合著「選股設價」及「續航力道」來做應變並判斷後續的走勢，循著這些步驟一招一招解讀千變萬化的市場行情，小至細微的相對高、低點，大至漲勢、跌勢及盤整勢都難脫SOP的掌握，真可說是縱橫股海的神兵利器，也提供了許多面對盤勢不知如何下手的股友們最直接也最有效的判斷方法。
