# 技術指標做出雙底或雙頭以上的完成條件

現在筆者把波段指標的第四個條件再寫一次。

# 波段指標的技術指標雙底以上完成的條件

+   一、RSI或KD在低檔區做出兩個或三個底以上。

+   二、MACD在零軸以下做出兩個或三個底以上。

+   三、若日線無此現象，而週線、月線有此現象亦可。

# 波段指標的技術指標雙頭以上完成的條件

+   一、RSI或KD在高檔區做出兩個或三個頭以上。

+   二、MACD在零軸之上做出兩個或三個頭以上。

+   三、若日線無此現象，而週線、月線有此現象亦可。
