# 最佳指標的應用（台指黃金期貨）

筆者再舉台指黃金期貨指數的例子給讀者參考，雖然台指黃金期貨目前成交量比較小，但隨黃金的大起大落，未來成交量亦會逐漸闊大，屆時投資人亦可考慮操作台指黃金期貨。目前我們的學員大都操作國外黃金期貨，操作技巧仍然以SOP或最佳指標作為切入點。

# 台指黃金期貨指數實例

如圖（9-12）是台指黃金期貨指數日線圖

+   一、圖中①所示，均線做出三線合一向下，且跳空留下一個下跌缺口。指數自5053下跌到4340。

+   二、圖中②③所示，連續出現二次島型反轉向上。指數在4340止跌反彈，島型反轉的成功率非常高，在八大選股指標中，排名第一名的就是做出島型反轉的個股。

+   三、圖中④所示，3日與6日RSI做出高爾夫球桿。

+   四、圖中⑤所示，均線再做出三線合一向上，因此指數持續反彈。

從圖中②③④⑤所示，連續出現做多買點，就是筆者常言：「大家一起來，團結力量大」。下一節筆者會舉一些「大家一起來，團結力量大」的例子，讓讀者大人參考。
