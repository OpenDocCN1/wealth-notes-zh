# 期貨SOP的應用（領先指標負價乖離）

筆者再舉一個負價乖離的例子給讀者參考，如圖（8-18）是期貨指數的日線圖。

# 領先指標（負價乖離）的出手點

+   一、如圖中①所示，期貨指數在100年9月22日，當天的6日均線7464。

+   二、如圖中②所示，隔天9月23日指數急跌出現負價乖離。價乖離的參數5～6%。負價乖離的算法：7464×0.95=7090或7476×0.94=7016。指數在9月23日盤中最低來到6972，收盤7048。

+   三、如圖中③所示，9月23日的6日均線7405。

+   四、如圖中④所示，下一個交易日9月26日出現負價乖離，其算法如下：7405×0.95=7034或7405×0.94=6960。指數在9月26日盤中最低6855，收盤6882。

+   五、雖然9月23日與9月26日連續兩天出現負價乖離，當天指數皆沒有反彈。但在第三天9月27日，如圖中⑤所示，指數跳空大漲強力反彈247點收7129。

重點提示：

+   1. 價乖離通常是在指數或股價連續大漲或大跌才會出現。

+   2. 如圖（8-18）圖中⑤所示，指數在第三天才強力反彈。因此我們才會建議初學者第二天或第三天才出手，成功率較高。
