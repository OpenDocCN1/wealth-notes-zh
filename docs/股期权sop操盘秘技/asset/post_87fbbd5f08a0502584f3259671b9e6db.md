
# 選擇權SOP的應用（組合操作策略）

前面幾頁所舉的例子皆是單一操作策略，接下來這幾頁筆者再舉一些組合操作策略給讀者參考。

組合操作策略的使用時機，在於「盤整盤」。換言之，上有壓力，下有支撐。指數區間大約在300點上下整理。此時可採取組合操作策略多空雙向操作。

組合操作策略有很多種，本書僅舉常用的四種說明如下：

- 買方：買進勒式，買進跨式。適用於大漲大跌的行情。
- 賣方：賣出勒式，賣出跨式。適用於區間整理的行情。

依筆者的經驗操作組合單，以賣出勒式的成功率最高，但先決條件必須確認大盤指數進入「盤整盤」。如何判定盤整盤？可利用「股市三寶」判定漲、跌、盤的轉折點。尤其是寶王45度線可精準的判定由「漲進入盤」或由「跌進入盤」。再加上量價關係就很容易判斷出盤整盤。

至於買進勒式或買進跨式是以「賭」的心態操作。賭指數大漲大跌或在結算前幾天指數大幅震盪，賺取倍數利潤。尤其是「週選擇權」上路後，更有機會賺到買進勒式或買進跨式的利潤。筆者在《週選擇權獲利大解密》書中，會分享一些「賭」的訣竅，讀者可買一本閱讀必有所獲。

## 選擇權SOP的應用（組合操作策略）賣出跨式

上一頁的例子是賣出勒式，其使用時機是研判壓力在7900支撐在7700。果然到結算日指數在7809，即沒有突破7900也沒有跌破7700就可賺到多單與空單的權利金（時間價值）。

沿用上一頁的例子，若研判指數到結算日呈現狹幅震盪，此時也可操作一組賣出跨式。所謂跨式即是履約價相同，因為研判指數可能在7700～7900之間狹幅震盪，因此可以選擇7800的履約價做一組跨式。

在4月8日操作一組賣出跨式，履約價設在7800，如圖（8-43）行情表所示，當時履約價7800賣出買權（SC）的權利金104點，履約價7800賣出賣權（SP）的權利金39點，合計收受權利金143點。

- 在4月17日結算時，履約價7800賣出買權（SC）的權利金8點，履約價7800賣出賣權（SP）的權利金0.1點，可參閱圖（8-42）的行情表。
- 結算時指數收7809，吻合狹幅震盪的預測，因此可獲利143 - （8 + 0.1）= 134.9（點）。

## 選擇權SOP的應用（組合操作策略）買進韌式

買進韌式主要是做在買方，買方的特性必須靠指數大漲或大跌才有利潤。否則權利金易受時間價值的關係而流失。因此操作買進韌式必須有能力研判指數在短時間內會大漲、大跌才進場操作。

不過在「週選擇權」上路後，筆者發現在每週三結算日之前1～2天試作一組（賭）買進韌式或買進跨式，在結算日若逢指數大幅震盪或大漲、大跌皆有機會中獎，賺到數倍的利潤。

週選擇權在民國101年11月上路，筆者在102年農曆年後，開始統計在結算日之前1～2天操作買進韌式或買進跨式的成功率和，發現成功機率很高。因此特別撰寫一本《週選擇權獲利大解密》分享操作心得，預估在2013年的年底出版，投資人可購買參閱，以小搏大靠實力也靠手氣。

操作買進韌式或買進跨式，如同購買券商所發行的「權證」一樣，以小搏大。只要會操作買方的Call或Put，就會操作認購權證與認售權證，下一頁筆者以實例說明買進韌式與買進跨式的操作技巧。

- 筆者選擇在8100的履約價作「買進賣權」。當時的權利金5.4點。同樣在8200的履約價作「買進買權」。當時的權利金6.1點。合計給付權利金（5.4＋6.1）＝11.5（點）。

- 如圖（8-46）所示，102年5月8日週選擇權行情表
- 5月8日結算日，當日指數剛好大漲104點。從圖（8-46）的行情表可看出8200履約價買權的權利金58點。8100履約價賣權的權利金0.1點。

重點提示：

- 當我們操作買進軋式之後，只要指數大幅震盪盤中，有賺就可先獲利平倉出場，不一定等到結算日在平倉。
- 因為買方的權利金流失很快，若手腳不夠快反而虧損。

## 選擇權SOP的應用（組合操作策略）買進跨式

買進跨式的使用時機與買進勒式相同，差別在於買進勒式的履約價不同，而買進跨式的履約價一定要相同。至於如何選擇哪一個履約價最有利？在《週選擇權大解密》書中會有詳細說明。

現在筆者沿用上一個例子操作一組買進跨式給讀者參考。

如圖（8-47）是102年5月7日的週選擇權行情表。

- 5月7日是結算日的前一天，筆者決定操作一組「買進跨式」，賭一賭5月8日結算是否獲利。
- 筆者選擇在8150的履約價做「買進買權」，當時的權利金24.5點，同時在8150的履約價做「買進賣權」。當時的權利金20點，合計給付權利金（24.5＋20）＝44.5（點）。

如圖（8-48）是102年5月8日週選擇權的行情表。

- 5月8日結算日，當時指數大漲104點。從圖（8-48）的行情表可看出8150履約價買權的權利金108點。賣權的權利金0.1點。
- 買權與賣權的權利金合計（108＋0.1）＝108.1點，扣掉成本44.5點還可賺（108.1－44.5）＝63.6點，大約可獲利1.5倍。
