# 期貨SOP的應用（波段指標）

操作期貨的朋友是否可波段操作？答案當然是可以。但據我所知，台指期貨的投資人大都不敢波段操作。因為晚上睡不著覺，台指期貨很容易受國際股市的影響，尤其是美股。

清晨美股的收盤會影響台股早上的開盤。換言之，台股的開盤易受美股的影響，早盤常以跳空上漲或跳空下跌開出。若今日多單留倉，晚上美股大跌。明日台股開盤也隨之跳空大跌，一夜之間大賠。因此很多投資朋友操作期指皆以當沖為主，不敢波段操作。

俗話云：「孔子不收隔夜帖」。因此目前台股期貨投資人，大都以當沖為主。不過如果判斷有波段行情而採取波段操作的朋友，其獲利一定比當沖高很多。

期貨若欲採波段操作，除了保證金要足夠之外，最重要的是自己要有能力判定台指期貨是否有波段行情。此時SOP的第三個方塊「波段指標」就派上用場。當我們判定期指有波段行情時，就可採波段操作。如此獲利驚人。下一頁筆者就舉幾個波段操作的例子給讀者參考。
