# 選擇權SOP的應用（單一操作策略）

現在筆者舉個SOP應用在選擇權的例子給讀者參考。

操作選擇權首先必須確認大盤的方向，再考慮採取「單一操作策略」或是「組合操作策略」。

如圖（8-30）是大盤日線圖

+   一、圖中①所示，大盤跳空上漲突破45度線。且均線做出三線合一向上，出現攻擊量。在加上MACD柱狀體在零軸以下做出三個底。符合波段指標的三個條件。研判有上漲波段行情，因此決定做多，選擇單一操作策略（買進買權）。

+   二、圖中②所示，突破45度線與三線合一的指數位置大約在7800。因此在4月23日拉回時選擇7800的履約價做（買進買權），當時的權利金167點，如行情表圖（8-31）所示。

+   三、在結算日5月15日的前一天平倉，7800履約價的權利金漲至472點。如圖（8-32）所示。可獲利472點－167點＝305點，獲利1.8倍。

+   四、操作選擇權，若有獲利隨時可以平倉，不一定等到結算日再平倉。若無獲利也應該設定停損點。
