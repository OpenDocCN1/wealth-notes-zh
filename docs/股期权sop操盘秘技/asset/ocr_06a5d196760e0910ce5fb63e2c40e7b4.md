# 4-1 K線（棒）

在第二章第3節談到SOP的操作順序，當我們打開技術線型圖（K線圖）的第一件事，就是先看領先指標。因為它可以讓我們買到最低點（相對低點）或賣到最高點（相對高點）。

當領先指標過了之後，或者找不到領先指標，就可以進入第二個方塊「股市三寶」。股市三寶的主要功能是判定漲、跌、盤的轉折點。我們取三種指標：1.K線、2.均線、3.45度線，作為判定漲、跌、盤的依據。

# 如何判定漲、跌、盤的轉折點

在筆者著作的書籍中，《股市三寶》、《期權賺很大》都有講到如何利用股市三寶判定漲、跌、盤的轉折點，本書不厭其煩的再將其重點重複講一次。

+   一、當指數或股價處在「跌勢」中，若完成上漲一寶（任何上漲一寶），其趨勢會由「跌」改變成「盤」。若完成上漲二寶亦視同「盤」或「盤整趨漲」，若完成上漲三寶，其趨勢會由「盤」改變成「漲」。

+   二、當指數或股價處在「漲勢」中，若完成下跌一寶（任何下跌一寶），其趨勢會由「漲」改變成「盤」。若完成下跌二寶亦視同「盤」或「盤整趨跌」，若完成下跌三寶，其趨勢會由「盤」改變成「跌」。

+   三、至於K線、均線、45度線所完成的條件，後面會逐一說明。
