# 袁序 PREFACE

一般投資人都非常瞭解影響股價漲跌的因素很多，但主要的有消息面、基本面、技術面這三大類，消息面的來源都是太突然，無法預測；如美國的911恐怖攻擊，因此很難學習預防。至於基本面，則永遠是老闆、大股東掌握第一手的資訊，而投資人從報章雜誌所取得的往往是落後資訊，因此參考價值不是很高。技術面則包括K線、移動平均線、成交量及各種技術指標，這些工具都是對股價變動做規律的統計分析探討，因此實用價值頗高。

陳霖老師是位非常專業的股市投資老師，尤其在技術分析領域更是有精闢獨到的見解。長期以來使用本公司所研發的股票技術分析軟體。其令我敬佩之處，就是利用過人才智，結合軟體優異功能，創造出令人激賞的股市實戰工具，並出書與投資人分享。

陳霖老師在這十幾年當中陸續推出了《10倍數操盤法》、《股市三寶》、《期權賺很大》、《K線實戰秘笈》、《45度線獲利秘訣》等多本精彩好書，並引起廣大投資朋友的回響，陳霖老師觀察到大多數的投資朋友即使學了技術分析，但因為操作的邏輯順序不當，所以績效始終不理想。因此將多年來，出書的精華部份，有系統的整合處理，推出新書《股期權SOP操盤秘技》詳細說明金融市場操作應該有的標準作業流程（SOP），值得投資人仔細研究學習。相信這本書必能幫助想要在金融市場獲勝的投資人；也會是一本非常暢銷的好書。
