# 期指分鐘線切入的九重點

如圖表（二）所示，是期指分鐘線九重點的切入點。

筆者要特別提醒操作期指分鐘線的朋友，在看一分鐘線時不要忘記日線的存在。因為日線是母線，分線是子線。母線對子線有支撐與壓抑的作用。

很多操作期指的朋友因為專注在分線的出手點，忘了其出手的位置剛好是日線的壓力或支撐。因此當發現分線出現買點，切入買進之後，馬上被壓回，主因是遇到日線的壓力。反之，發現分線出現賣點，切入做空之後，馬上被軋空。主因仍是遇到日線的支撐。這就是所謂的「螳螂捕蟬，黃雀在後」，不得不慎。
