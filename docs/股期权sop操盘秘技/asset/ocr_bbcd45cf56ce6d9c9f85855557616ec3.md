# 波段指標的應用實例

前面談到波段指標的內容一共有四個條件，必須完成三個以上，才有機會形成波段行情。

現在筆者先以大盤指數做例子說明印證，讓讀者參考，在第八章SOP的綜合應用再舉個別股印證。

# 波段下跌行情實例

如圖（5-5）是大盤指數日線圖，且完成波段下跌行情。

+   - 一、圖中①所示，均線做出三線合一拉長黑跌破前波低點。

+   - 二、圖中②所示，K線跌破長期上升趨勢線。

+   - 三、圖中③所示，成交量低於基本量（5日均量）連續三天以上。

+   - ◎上述大盤指數完成波段指標四個條件的其中三個以上。

因此產生波段下跌行情，指數自7789下跌到7050，下跌幅度超過500點。

+   - ◎當我們預測指數會產生波段下跌行情，就可採中長線波段操作股票、期貨、選擇權。尤其是選擇權，除了操作賣方的Call之外，也可加碼買方的Put。
