# 技術指標二次背離實例 (KD)

如圖 (3-13) 是期貨指數日線圖

KD指標在高檔區做出二次背離

+   一、圖中①所示，KD指標K值在高檔區做出一次背離之後，指數拉回一天。

+   二、圖中②所示，KD指標K值在高檔區做出二次背離之後，指數拉回幅度較大。

如圖 (3-14) 是期貨指數日線圖

KD指標在低檔區做出二次背離

+   一、圖中①所示，KD指標K值在低檔區做出一次背離之後，指數反彈兩天。

+   二、圖中②所示，KD指標K值在低檔區做出二次背離之後，反彈幅度較大。

+   三、技術指標，RSI、KD、MACD背離越多次，其漲跌幅度就越高，指數或個股皆是如此。
