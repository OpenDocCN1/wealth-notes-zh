股期權SOP是一套操作金融商品的成功法則，在結束本書撰寫之前，筆者綜合投資人的一些疑問，在此做個簡單扼要的回答。亦可藉著問與答之間做重點提示與複習，加深讀者的印象。讓閱讀本書的讀者發揮最大的效益。

# 一、問：為何操作股期權要建立SOP？

答：SOP是一種標準操作流程，亦可說是安全規範。按照此流程操作股票、期貨、選擇權，或其它金融商品，可以趨吉避兇，減少失誤率提高成功率。

# 二、問：SOP真的很重要嗎？

答：確實很重要，建立SOP是踏出成功的第一步。例如心肺復甦術（CPR），也有一套SOP，必須按照CPR的SOP才能在第一時間將停止心跳的心臟恢復正常，達到急救的目的。

# 三、問：股市的SOP是否與產業界或工程界所講的SOP一樣？

答：是的，工廠所生產的產品其製造、品管、檢驗皆有一套SOP才能提高良率與品質，工地的施工或機器設備的操作也有SOP才不會發生工安意外，操作股期權也是如此。
