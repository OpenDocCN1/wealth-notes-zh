# 大家一起來，團結力量大

現在筆者舉大盤為例給讀者參考。

如圖（9-13）是大盤日線圖

+   一、圖中①所示，102年6月21日出現大量，雖然6月25日跌破大量K線的低點，但是3日RSI已降到3.9出現「準領先指標」，如圖中②所示。

+   二、圖中②所示，6月25日除了3日RSI出現準領先指標之外，您會發現RSI、KD、MACD（柱狀體）打出三個底。

+   三、圖中③所示，6月25日的大長黑可視為騙線，因為隔天6月26日指數開高，重回6月21日大量K線的低點以上。何謂騙線可參閱《期權賺很大》85頁。

+   四、圖中④所示，6月26日K線重回6月21日K線低點之上，且RSI、KD、MACD的三底完成交叉向上。

+   五、圖中⑤所示，6月27日指數跳空上漲出現：1.島型反轉向上（虛線框起來的部分）。2.出現第一個上漲缺口。3.K線完成上漲一竄。4.突破45度線。5.站上6月21日的大量K線的最高點之上（換手成功）。

從上述可知從6月25日～27日連續出現3～5個最佳指標，尤其是6月27日當日一共出現4個最佳指標，可視為「大家一起來，團結力量大」。指數自7663漲到8265形成上漲波段行情。
