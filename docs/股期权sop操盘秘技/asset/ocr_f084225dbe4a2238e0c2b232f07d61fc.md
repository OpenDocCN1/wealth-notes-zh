# 8-1 股票SOP的應用

第八章主要是談SOP如何應用在股票、期貨或選擇權。或國內外的其他金融性商品。前面1～7章筆者已有舉一些實例印證SOP的成功法則。本章再舉一些例子，強化讀者對SOP的信心。有信心才敢出手操作，好比會游泳的人才敢下水。

現在大家再複習一下SOP的操作順序，也可說是操作邏輯，可回頭參閱第二章的SOP方塊圖，其操作順序如下。

+   一、當我們打開技術線型圖的第一件事，先看第一個方塊「領先指標」是否出現。
* 如果有：可少量短線操作有賺就跑。若不敢操作可觀望。
* 如果無：進入第二個方塊「股市三寶」判定漲、跌、盤的位置。

+   二、當股市三寶判定由「跌」進入「盤」或由「漲」進入「盤」，就可進入第四個方塊「成功法則」，並投入3～5成資金開始操作。

+   三、當股市三寶判定是「漲」或「跌」勢，就可進入第三個方塊「波段指標」，研判是否有波段行情。

+   四、當波段指標完成三個條件以上，就可進入第五個方塊判定其續航力道的強弱。
