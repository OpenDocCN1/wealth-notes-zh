# 作者序

首先我以感恩的心，感謝全國熱情的投資朋友10多年來的支持與愛護。不斷的購買筆者出版的一系列技術分析的工貝書。如《10倍數操盤法》、《股市三寶》、《期權賺很大》、《K線實戰秘笈》、《45度線獲利秘訣》等。筆者除了感恩之外還是感恩。再次向購書以及參加訓練課程的朋友們說聲謝謝！

工欲善其事，必先利其器。操作股票、期貨、選擇權或是其它金融商品如黃金、歐元…等也是如此。我常接到很多投資朋友來信，讚嘆筆者出版的工具書簡單易學，且實用。尤其看到投資人開始反敗為勝，不斷的提高獲利績效。筆者甚感欣慰且與有榮焉。

不過還是有些投資人雖然學了技術分析但操作績效不彰。原因在於操作的邏輯順序不當。換言之沒有建立一套成功的操作系統。也就是本書所要談的SOP（Standard Operating Procedure）標準作業流程。

選寫本書的動機，除了有感於投資人操作邏輯順序不當之外，另一個因緣是筆者參加一項勞工局所舉辦的「勞工安全衛生教育訓練」。課堂上播放了許多慘不忍睹的影片。全都是因為職災或工安所發生的不幸事件。究其原因大都是沒有按照SOP的安全規範操作。才會導致受傷或死亡。
