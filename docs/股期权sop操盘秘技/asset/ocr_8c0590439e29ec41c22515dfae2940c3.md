對於如何選股設價，筆者的看法是建議投資人採取選股三步驟：先看技術面，再查基本面，解讀消息面。如此面面俱到，就不難選出強勢主流股。

# 選股三步驟

（先看技術面，再查基本面，解讀消息面）

+   一、先看技術面，從技術面選股，筆者設定了八大指標。亦可說是強勢股的八大條件。如下－頁圖表（一），若個股的技術面符合此八大指標的三個條件以上，就可列為強勢股。

+   二、再查基本面，篩選出強勢股之後，再查－查其基本面的資料。如最近三個月的業績是否成長？或與去年同期比較業績是否成長？

+   三、解讀消息面，當市場或個股傳出利多或利空時，投資人必須冷靜解讀，不能人云亦云。否則把利多當成利空，或把利空當成利多，反向操作得不償失。原則上，利多不漲反跌，不宜追價。利空不跌反漲，不宜殺低。
