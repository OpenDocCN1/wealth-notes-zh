# 完成波段指標三個條件以上

筆者再舉大盤指數為例說明完成波段指標三個條件以上給讀者參考。

如圖（7-3）是大盤指數日線圖

+   一、圖中①所示，成交量大於基本量三天以上，且出現攻擊量。

+   二、圖中②所示，均線做出三線合一向上。

+   三、圖中③所示，技術指標MACD柱狀體做出三個底。

+   四、完成①②③三個條件。因此指數自7688漲到8300以上符合500點以上的上漲波段行情。

+   五、從圖中也可看長期下降趨勢線的條件並未完成，因為此下降趨勢線的時間不到二個月或三個月以上。因此不符合突破長期下降趨勢線的條件。

台股本波如圖①②③所示，完成波段指標的三個條件之後，筆者在書友會網站（http://chen-lin.idv.tw/）預測台股會形成波段行情，果然印證。不少書友因此賺到波段利潤。書友會網站每週三、五的文章很值得讀者參考。
