# 選擇權SOP的應用（組合操作策略）

前面幾頁所舉的例子皆是單一操作策略，接下來這幾頁筆者再舉一些組合操作策略給讀者參考。

組合操作策略的使用時機，在於「盤整盤」。換言之，上有壓力，下有支撐。指數區間大約在300點上下整理。此時可採取組合操作策略多空雙向操作。

組合操作策略有很多種，本書僅舉常用的四種說明如下：

+   買方：買進勒式，買進跨式。適用於大漲大跌的行情。
賣方：賣出勒式，賣出跨式。適用於區間整理的行情。

依筆者的經驗操作組合單，以賣出勒式的成功率最高，但先決條件必須確認大盤指數進入「盤整盤」。如何判定盤整盤？可利用「股市三寶」判定漲、跌、盤的轉折點。尤其是寶王45度線可精準的判定由「漲進入盤」或由「跌進入盤」。再加上量價關係就很容易判斷出盤整盤。

至於買進勒式或買進跨式是以「賭」的心態操作。賭指數大漲大跌或在結算前幾天指數大幅震盪，賺取倍數利潤。尤其是「週選擇權」上路後，更有機會賺到買進勒式或買進跨式的利潤。筆者在《週選擇權獲利大解密》書中，會分享一些「賭」的訣竅，讀者可買一本閱讀必有所獲。
