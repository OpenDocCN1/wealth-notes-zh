# 個股軌道線實例

在筆者所開設的訓練課程中，有一堂課是「畫線技巧」。主要是訓練學員如何利用畫線技巧尋找壓力與支撐。畫線內容包括：頸線、趨勢線、扇形線、45度線、陡線、軌道線等。其中軌道線與45度線比較難畫。

軌道線的上沿，下沿可以各畫二條，成為支撐區或壓力區。其他如45度線、趨勢線、頸線…等也可畫二條，成為支撐區或壓力區。這是活用畫線的技巧，不必拘泥於單畫一條線。
