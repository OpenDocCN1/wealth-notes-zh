# 吳序
# PREFACE

金融商品的操作，即使技術面了解甚深，基本面研究透徹，也無法保證百分之百獲利，原因在於操作金融商品時受情緒影響甚大。技術面所陳列的價量指標相當多，即使全部了解透徹也會有無所適從的感覺。本書作者對於技術面的價量指標研究多年，對於行情判斷、選股設價歸納出一套標準作業流程。擬定一套標準作業流程，若能不受情緒影響而臨時改變主意，犯錯的機率自然減少，勝率自然提高。本人相當推崇作者對於技術面的價量指標作歸納整理，擬定一套標準作業流程。除此之外，本人也建議從「笑傲股市」一書所歸納出的CAN SLIM策略初步篩選股票，因為CAN SLIM涵蓋基本面與籌碼面的操作策略，再套用技術面價量指標運用的標準作業流程，如此（基本，籌碼，技術）面面俱到，避免受情緒影響而臨時改變主意，本人認為勝率應可再提高。

# 前言之一

在技術分析的領域裡，筆者把它分成兩大類：線型指標與技術指標。

線型指標包括：K線、均線、趨勢線、45度線、成交量、型態、黃金切割率、波浪…等。

技術指標包括：RSI、KD、MACD、DMI、OBV、TAPI、威廉、寶塔線…等。

本書《股期權SOP秘技》是針對所有操作股票、期貨、選擇權失利的朋友們所設計。筆者篩選出數種成功率較高的線型指標與技術指標。把它們分成三大類：領先指標，最佳指標、波段指標。再將這三大類分成五個方塊。形成所謂SOP的方塊流程圖。為了讓SOP的方塊圖更簡化，關於「最佳指標」的部分，筆者把它製作成一張總表放在第九章。讀者可自行參閱。最佳指標可細分為日線的切入點與分線的切入點。其中分線的切入點是專為操作期貨的朋友設計的。在《期權賺很大》書中有詳細的說明。

由於本書篇幅有限，且考慮到與先前著作的重複性。因此最佳指標的部分，除了參閱本書第九章的內容之外，亦可參閱筆者先前的幾本著作。
