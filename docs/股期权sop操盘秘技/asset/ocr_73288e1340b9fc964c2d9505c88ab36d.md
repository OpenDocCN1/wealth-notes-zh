# 觀念與方法是股海成功賺錢的關鍵

觀念與方法是股海成功賺錢的關鍵，在陳霖老師的技術分析課程（或著作），絕對可以傳授給我們正確觀念與方法，上課中老師傳授「股市三寶」判定漲、跌、盤、轉折（讓我們懂得進出買賣的時間點）。畫45度線也可以判定漲、跌、盤、轉折點，並觀察突破或跌破45度線的買賣點（在操作期貨、選擇權有方向就不會茫然，搞不清楚多空方向）。

在技術指標方面，老師常提起RSI、KD三種買賣點①交叉  ②乖離  ③背離及位置的重要關鍵點。

有了賺錢的方法，每天可在期貨市場獲利20～30點

RSI、KD、MACD有時做出雙底、同步的要領，喜歡操作期貨為主的我，不但概念清楚信心十足，在原本似懂非懂的情況下，經過不斷的學習與調整，現在我已可以隨心所欲，每一天可在期貨上獲利20～30點。在此非常感恩老師把他在股市研究的心血與實務經驗傳授給我們。讓我今天有這成功的賺錢方法。在此非常感恩老師教導才有今天的我。
