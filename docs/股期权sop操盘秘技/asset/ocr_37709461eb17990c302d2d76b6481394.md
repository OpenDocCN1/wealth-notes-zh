# 選擇權的設價

本書的書名《股期權SOP操盤秘技》，即是代表SOP適用於股票、期貨、選擇權。前幾頁談到股票、期指如何設價，現在筆者再以選擇權做例子。

如圖（6-5）是大盤指數日線圖

+   一、圖中①②所示，大盤在102年4月19日突破45度線且做出三線合一向上。指數由跌勢進入漲勢即可操作選擇權的多單，買進買權或賣出賣權。

+   二、因為突破45度線的位置大約在7850。因此可選擇7900履約價的位置做多。

+   三、圖（6-6）是102年4月19日「週選擇權」的行情表。履約價7900買權的權利金68點。賣權的權利金18.5點。

+   四、圖（6-7）是102年4月24日「週選擇權結算日」的行情表。您會發現履約價買權的獲利金116點。賣權的獲利金0.2點。

+   五、買進買權獲利（116點－68點＝48點）。賣出賣權獲利（18.5點－0.2點＝18.3點）。

重點提示：

+   1. 選擇權的操作必須確定大盤方向再出手，成功率較高。

+   2. 大盤方向只有漲、跌、盤三種。選擇權可擴大成：大漲、大跌、小漲、小跌、盤漲、盤跌六種。
