# 國際金融商品SOP的應用（倫敦黃金現貨）

筆者再舉英國倫敦現貨黃金完成下跌波段指標之後，展開波段下跌行情的實例給讀者參考。

# 黃金完成下跌波段指標的三個條件

如圖（8-62）是英國倫敦黃金現貨月線圖

+   一、圖中①所示，RSI、KD、MACD先做出雙頭交叉向下。

+   二、圖中②所示，K線跌破長期上升趨勢線。

+   三、圖中③所示，均線做出三線合一向下。K線跌破前波低點1540。

+   四、如上述完成SOP第三個方塊「波段指標」的三個條件，黃金價格開始展開下跌波段行情。每盎司自1791下跌到1227。

當黃金完成下跌波段指標至1791開始起跌時，筆者在上課中預估黃金至少回檔到黃金切割率0.5的位置。換言之，如圖（8-62）所示，自709.6漲到1898。回檔0.5的位置大約在1300，結果跌到1227，才略見止跌跡象。

當時在上課中的學員，就有幾位學員利用SOP操作國外的金融商品如美元、歐元、黃金…等。其中放空黃金期指的學員賺得最多。
