# 國際金融商品SOP的應用（美匯日圓）

延續前一頁美匯日圓的週線圖，如圖（8-64），在圖中也可看出日圓貶值到一美元兌換103.74日圓之後，出現技術指標RSI在高檔區做出二次背離，吻合我們SOP的領先指標。日圓自103.74回升到93.77。

三、技術指標做出二次背離符合領先指標的條件，日圓自103.74升值到93.77日圓。

當日圓升到93.77，RSI出現負乖離（12－30）＝－18。RSI負乖離超過16以上，我們把它稱為「最佳指標」。當日圓回升至93.77日圓之後，又反彈續貶。

何謂「最佳指標」筆者在下一章會做說明，最佳指標也是操作股期權的出手點，可搭配SOP的領先指標、股市三寶、波段指標…等，一起使用。如魚得水，如虎添翼，效果更佳。
