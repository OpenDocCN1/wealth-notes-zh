# 4-3 45度線（股市三寶寶王）

談完前面K棒與均線二寶之後，現在要談一談最重要的第三寶：45度線。因為45度線堪稱股市三寶的寶王。因此我們要畫45度線時，K線圖的版面其長寬比必須有一定的比率。

# 畫45度線的K線圖必須設定二個條件

+   一、K線圖的長寬比率必須是黃金比率1.618 : 1，如下圖所示。

![](bbox=[0.25, 0.48, 0.74, 0.67])

+   二、在黃金矩形裡面的日K線數量控制在110～111根。

> 重點提示：

+   1. 以上兩個條件是畫45度線的必備條件。如此畫出的45度線精準度才會高。

+   2. 會畫45度線的朋友單用45度線這一寶就可判定漲、跌、盤的三種變化。
