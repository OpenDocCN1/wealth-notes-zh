# 股期權SOP 操盤祕技

如要選股就要利用股市三寶：1.K棒2.均線3.45度線。如要判定漲、跌、盤的轉折點，當完成二寶以上就可視為選股條件，將資金分成三等份依漲、跌、盤分配切入。再配合量價關係1.基本量、攻擊量2.進貨、出貨、換手、止跌、止漲量3.四種量價關係與六大比較法。如此就可研判漲、跌、的續航力。
