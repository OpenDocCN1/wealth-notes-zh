# 個股波段指標失敗的實例

在我們舉辦的訓練課程中，有一位朋友提出質疑坊間技術分析的書籍，所舉的例子都是成功的，很少舉失敗的例子。因此筆者從善如流在本書中就多舉一些失敗的例子。

如圖（7-6）是國泰金（2882）的日線圖

+   一、 圖中①所示，跌破長期上升趨勢線。

+   二、 圖中②所示，均線做出三線合一下向。

+   三、 圖中③所示，成交量低於基本量（5日均量）以下。

+   四、 圖中④所示，技術指標RSI完成雙頭交叉向下。

+   五、 雖然完成波段指標下跌的四個條件，但股價自42.6元跌到37.1元僅下跌13%，未完成下跌波段行情的2~3成。

重點提示：

+   1. 我們常講技術分析不可能百分百，何況波段指標的漲、跌幅，它是一種預測值，當然不可能百分百準確。

+   2. 當股價未跌到我們的預測值就反轉向上，我們也會看得出來。因為有股市三寶可以判斷漲、跌、盤的轉折點。

+   3. 當股價未跌到我們的目標區之前，完成上漲一寶，由「跌」改變成「盤」就要停利或停損出場。這一點很重要切記！
