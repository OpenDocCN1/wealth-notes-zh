# PREFACE

金融商品的操作，即使技術面了解甚深，基本面研究透徹，也無法保證百分之百獲利，原因在於操作金融商品時受情緒影響甚大。技術面所陳列的價量指標相當多，即使全部了解透徹也會有無所適從的感覺。本書作者對於技術面的價量指標研究多年，對於行情判斷、選股設價歸納出一套標準作業流程。擬定一套標準作業流程，若能不受情緒影響而臨時改變主意，犯錯的機率自然減少，勝率自然提高。本人相當推崇作者對於技術面的價量指標作歸納整理，擬定一套標準作業流程。除此之外，本人也建議從「笑傲股市」一書所歸納出的CAN SLIM策略初步篩選股票，因為CAN SLIM涵蓋基本面與籌碼面的操作策略，再套用技術面價量指標運用的標準作業流程，如此（基本，籌碼，技術）面面俱到，避免受情緒影響而臨時改變主意，本人認為勝率應可再提高。
