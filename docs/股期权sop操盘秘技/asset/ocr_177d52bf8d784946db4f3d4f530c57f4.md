# 最佳指標的應用（低檔區高爾夫球桿）

筆者設定的九個最佳指標可單獨使用，若九個最佳指標同時來了2～3個以上，則成功率更高，這一點特別重要，也是筆者常講的「大家一起來，團結力量大」。

# RSI在低檔區做出高爾夫球桿

技術指標RSI若在低檔區鈍化，如高爾夫球桿的「桿頭」，則在未來1～3天或3～5天內就會反彈，可切入搶短。所謂低檔區是指3日RSI或6日RSI皆在20以下。

+   一、如圖中①所示，RSI在低檔區虛線部份做出如高爾夫球桿的桿頭，當RSI交叉向上之後，股價開始反彈。自33.75元漲到37.2元，若切入短多可賺取價差。

如圖（9-3）是彩富的日線圖

+   一、如圖中①所示，RSI在低檔區虛線部份做出如高爾夫球桿的桿頭，且RSI負乖離（開口）過大達到（8-26）=-18，符合二個最佳指標，當RSI交叉向上之後，股價開始反彈。自45.35元漲到50元，若切入短多可賺取價差。
