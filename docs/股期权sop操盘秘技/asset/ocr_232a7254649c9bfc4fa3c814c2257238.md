# 期貨當沖SOP

在這零和遊戲市場上，能穩定且持續賺錢者，約佔百分之一以下，也就是說這個人所賺到的錢是靠九十九個人來供養。而這九十九個人就是一般說得沒方法、沒資金控管概念（跟賭一樣）、輕視市場（認為可以很輕易的賺到錢）、甚至有些連基本交易規則都不懂，跟陳霖老師學期貨操作已經2年了，越來越覺得操作SOP的重要性，自己也建立了一套SOP。

股市SOP包括日線級以上的週線，甚至月線--領先指標（價乖離、軌道線、技術指標二次背離、RSI臨界值）+股市3寶＋波段指標。

# 建立自己操盤的SOP

以下是我一些精華分享

+   1. 操作期貨首重趨勢，股市3寶就是判斷漲跌盤的不二法寶
漲勢----支撐區做多，不做空；
跌勢----壓力區做空，不做多；
盤整----可以退場觀望，或是支撐短多，壓力區短空。

順勢而為，富可敵國，逆勢而為，不知死活。每個散戶都知道這個道理，但是奉行者又有幾人？尤其喜歡老做逆勢單，常常贏了一隻雞，卻輸了一頭牛，總是賺大賠小，所以長期下來總是賠錢，只好被迫退出市場。
