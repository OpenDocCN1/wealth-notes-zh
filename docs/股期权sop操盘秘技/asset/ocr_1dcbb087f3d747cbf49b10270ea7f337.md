# SOP的操作順序

# 第五步（STEP-5）

續航力道：續航力道顧名思義即是波段行情。波段行情有上漲的波段行情與下跌的波段行情。波段行情如何認定呢？

上漲的波段行情：對大盤指數而言必須漲500點以上，對個股而言必須漲2～3成以上。

下跌的波段行情：對大盤指數而言必須跌500點以上，對個股而言必須跌2～3成以上。

+   一、在圖（2-1）的第二個方塊「股市三寶」就有箭頭指向第五個方塊「續航力道」。而第三個方塊「波段行情」也有箭頭指向「續航力道」。

+   二、剛才提到單靠股市三寶判定續航力道，證據力薄弱（不足）必須靠波段指標輔助判定，才會提高判定續航力道的精準度。

+   三、本章節介紹了SOP五個方塊流程圖的操作邏輯順序，希望讀者大人能按圖施工、照表操課。如此就會大幅提高操作勝率，只要提高操作勝率自然可累積財富。

重點提示：

+   1. 單靠股市三寶無法精準的判定續航力道。

+   2. 必須以波段指標輔助股市三寶，才能精準的判定波段行情。
