# 10-1 台北學員

# 根據SOP操作，充滿自信

跟著陳霖老師學習已將近二年，從有一點懂，再來慢慢懂、然後「一點就懂」也經歷3~5次的上課過程。同學們常問我：「你已經會做單，而且是賺錢的，為何還來上課？」我回答說：「溫故知新！」。我總希望自己能夠更精進，這次聽懂了上次沒聽懂的，是件很快樂的事！而且隨著老師的SOP方塊流程圖来做單，失誤率低、成功率高，因為成功的次數不斷的増加，做起單來自然不害怕。無形中、自己也充滿了自信心。

# 利用SOP的指標在關鍵時刻擊出安打，獲得勝利

陳老師的SOP方塊流程圖，簡單易懂，從領先指標、股市三寶、量價關係、波段指標，成功法則到續航力道，只要不斷的重覆練習，不管是短線的期貨、中長線的股票、甚至是國際性的金融商品都派得上用場。像我已經用的很熟悉，所以很快而且很容易的就能在短線中獲利。我現在的樂趣便是在各種商品中尋找；找尋符合SOP方塊流程圖中的商品。當我找到的時候，就等待著，等最好的出手點，在關鍵時刻擊出安打，獲得勝利。我要說的是：「當你把做單變成一種簡單的模式來思考時，一切真的就是變簡單了！」

祝福大家擁有神奇的SOP做單模式！

台北學員 李玉英
