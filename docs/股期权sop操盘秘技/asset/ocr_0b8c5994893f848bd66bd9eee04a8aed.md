# 個股價乖離的實例

如圖（3-3）是個股宏達電（2498）的日線圖

+   一、股價在101年8月7日與8日連續兩天出現負價乖離之後，隔天8月9日股價開始反彈。若在8月7日與8日敢搶短多，至少有15～20元的價差。

+   二、股價在101年9月17日與18日連續兩天出現正價乖離之後，隔天9月19日開始拉回。若在9月17日與18日敢短空至少有15～20元的價差。

+   三、股價在101年10月12日又出現負價乖離之後開始反彈。

+   四、圖（3-4）是用程式所繪出的個股價乖離圖形。當股價出現負價乖離，通常會在1～3天內反彈。反之出現正價乖離，會在1～3天內回檔。

+   五、其他三個領先指標也是如此。讀者學會領先指標之後，可利用領先指標出現時，伺機出手操作賺取短線價差。

重點提示：

宏達電的股本85億，屬於中型股。因此其價乖離的參數是12～14%。
