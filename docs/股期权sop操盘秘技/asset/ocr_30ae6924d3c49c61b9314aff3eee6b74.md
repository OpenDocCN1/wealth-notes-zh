# ## 股票SOP的應用
### （領先指標技術指標MACD二次背離）

剛才談到領先指標的「技術指標二次背離」有三個：
1.RSI、2.KD、3.MACD柱狀體。我們已經就RSI、KD舉例說明完畢。現在筆者就以MACD柱狀體的二次背離舉例說明，讓讀者更了解技術指標二次背離的切入點。

# 領先指標（技術指標MACD柱狀體零軸以下
二次背離）的出手點

如圖（8-12）是敬鵬日線圖

+   一、圖中①所示，MACD柱狀體，在零軸以下出現第一次背離。
二、圖中②所示，MACD柱狀體，在零軸以下出現第二次背離，可視為領先指標。
三、當MACD柱狀體在零軸以下作出第二次背離，柱狀體開始「縮腳」時，就可出手搶短多。何謂「縮腳」？是指MACD的柱狀體比前一根短。可參閱《股市三寶》書中第二章第六節136～137頁的說明。
四、您會發現MACD柱狀體在零軸以下作出二次背離後，股價開始反彈。自29.1元漲到33.3元，若即時切入可賺取短線價差。
