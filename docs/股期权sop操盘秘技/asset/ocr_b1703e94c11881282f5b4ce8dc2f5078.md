# 5-3 長期趨勢線（波段指標第三個條件）

長期趨勢線是波段指標的第三個條件，趨勢線大家都耳熟能詳，趨勢線可分為上升趨勢線與下降趨勢線。可是對波段指標而言，讀者必須注意「長期」兩個字。所謂長期，顧名思義，代表需一段時間。換言之，時間必須2～3個月以上。這是以日線為準，若是週線至少要5～6個月以上。月線則1.5～2年以上。

# 波段指標長期上升趨勢線的完成條件

+   一、從低點畫起的上升趨勢線，直到跌破此長期上升趨勢線，其時間必須2～3個月以上。

二、時間最好是2.5個月或3個月以上，時間越長成功率越高。

# 波段指標長期下降趨勢線的完成條件

+   一、從高點畫起的下降趨勢線，直到突破此長期下降趨勢線，其時間必須2～3個月以上。

二、時間最好是2.5個月或3個月以上，時間越長成功率越高。

**重點提示：**

+   1. 長期上升或下降趨勢線，其時間越長，成功率越高。
