# # 指數上升軌道線實例

如圖（3-5）是大盤指數的上升大軌道圖形

+   一、您會發現只要指數觸及到上升軌道的上沿就會被壓回，成功率很高。操作期貨指數的朋友就可利用指數漲到上升軌道線上沿出手短空，大約1～3天內就會拉回。
二、所謂大軌道是指其軌道寬度較大，小軌道則是軌道寬度較小，上升大軌道的上沿不易被突破，因此成功率較高。
三、上升小軌道上沿易被突破，因此成功率較低，但也值得參考。
四、從圖（3-5）可看出指數在102年2月3日、2月20日、3月11日都觸及軌道上沿後，開始拉回，敢出手短空，皆有利可圖。

如圖（3-6）是期貨指數的上升小軌道圖形

+   一、小軌道的畫法通常是用夾心餅乾的畫線技巧所規劃完成。
二、圖中也可看到指數在102年3月29日、4月1日都觸及或接近軌道上沿後，開始拉回，敢出手做空，亦有利可圖。

**重點提示：**

+   1. 大軌道通常是用A、B、C三點式的畫法。
2. 小軌道通常是用夾心餅乾式的畫法。
