# 選擇權SOP的應用（組合操作策略）賣出勒式

現在筆者列舉組合操作策略的例子印證SOP應用在選擇權的實例，給讀者參考。

如圖（8-40）是大盤日線圖

一、圖中①所示，指數在4月8日跌破45度線研判指數在短時間不會突破7954。因此在履約價7900做空（賣出買權）。

二、圖中②所示，研判跳空上漲的缺口位置7717～7739。支撐力道強。指數雖跌破45度線，研判拉回到缺口位置可獲支撐，因此在履約價7700做多（賣出賣權）。

三、如上逑4月8日同時進場操作一組賣出勒式的組合單，當時SC7900履約價的權利金44.5。SP7700履約價的權利金19.0如圖（8-41）所示（4月8日選擇權行情表）。合計收受權利金44.4＋19＝63.5（點）。

四、圖中③所示，指數在4月17日（週三）結算日，SC7900履約價的權利金0.2，SP7700履約價的權利金0.2。如圖（8-42）所示（4月17日結算日的行情表）可賺全部的權利金63.5－0.4＝63.1（點）。

重點提示：

+   1. 操作賣方的組合單可同一時間進場，也可利用指數震盪時分兩次進場，或許可收到更多的權利金。

+   2. SC（Sell Call）代表賣出買權，SP（Sell Put）代表賣出賣權。
