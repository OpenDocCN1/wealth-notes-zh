# 下跌三寶的條件

如圖（4-6）是大盤日線圖

+   一、圖中①所示，K線頻頻出現上影線且三天不創新高，符合K線下跌一寶（四種狀態的其中二種）的條件，完成下跌第一寶，指數由「漲」進入「盤」。

+   二、圖中②所示，跌破上升45度線，完成下跌第二寶，指數可視為「盤整趨跌」。

+   三、圖中③所示，K線跌破5日均線三天以上，完成下跌第三寶，合計完成下跌三寶，指數由「盤」進入「跌」。

重點提示：

+   1. 當指數由「漲」進入「跌」，並不代表指數會形成下跌的波段行情，股市三寶只是負責判定漲、跌、盤的轉折點。

+   2. 若欲判定是否有下跌的波段行情，必須符合SOP第三個方塊「波段指標」的三個條件以上。

+   3. 波段指標會在下一章談到。
