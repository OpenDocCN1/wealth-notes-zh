# 10-8 屏東學員

# 投入才會深入，付出才會傑出

在未參加陳霖老師的課程之前，已經花了幾拾萬參加過很多老師的課程。而且又買股票軟體，又加入會員，但还是沒賺到錢。剛好有一位朋友送我一張陳霖老師的書籤。裡面寫「投入才會深入」、「付出才會傑出」、「不要看破，而要突破」、「若不能打敗失敗，就會被失敗打敗」。當時我的內心非常震撼，決定參加陳霖老師的課程試試看。

老師將技術分析整理得有条不紊，讓我忽然之間茅塞頓開。尤其是老師整理的SOP與最佳指標，讓我判斷行情和選股更精準。例如：這一波指數自7633開始起漲，我就搭上了上漲列車，又選上了強勢的汽車股和泰車和汽車零組件的車王電，真的感恩老師的教導。

# 看錯方向寧可錯賣不要錯買

以前不敢操作期貨與選擇權，現在技術分析已進步很多。開始練習操作期權，想不到賺得比股票更快。雖然偶爾也會失敗，但我已學會停損。老師說：「看錯方向寧可錯賣，不要錯買」。養成停利停損的好習慣就不怕做錯方向。賠少賺多。最後還是贏家。
