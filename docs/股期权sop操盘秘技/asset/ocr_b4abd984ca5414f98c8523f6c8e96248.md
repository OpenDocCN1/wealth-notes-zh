# 台灣操盤界四項第一

我進入股市超過15年，有300本以上股市技術分析書，也曾經跟過4～5位老師學習操盤，其中對我操作最有實際幫助的當屬陳霖老師的全套SOP。依我經驗，陳霖老師的SOP操盤法至少可拿四項第一：

+   1. 台灣第一位教完整標準作業程序（SOP, Standard Operation Procedure）的老師，也是第一本SOP專書：

在操作中有許多環節，例如選股設價、資金控管、停損停利等，任一環節沒做好就可能賠錢。一般坊間老師只教一招半式，一旦出江湖則左支右絀，錯誤百出，無法賺到錢。故若要靠實力賺錢，則更要依照一整套陳霖老師的SOP，要一窺全貌，須學習整套技巧須詳讀陳霖老師全套書。光看書還不夠，推薦一定要去上老師的課，才能融會貫通。陳霖老師上課將這一套很完整有系統的操作方法口語化變成口訣，方便學員記憶及迅速操作。所以，上過陳霖老師課的學員口袋裏都裝有三個錦囊：領先指標，股市三寶，量價關係。領先指標可領先買在相對低點賣在相對高點，股市三寶看趨勢，量價關係則看籌碼，防止被主力坑殺。
