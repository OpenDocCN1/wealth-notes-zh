# 期貨SOP的應用（領先指標RSI正臨界值）

上一頁的例子是RSI負臨界值，筆者舉RSI正臨界值給讀者參考。當指數在上漲中，技術指標RSI出現正臨界值，可出手短空期指。回檔有賺就跑，沒賺宜設停損。

所謂RSI臨界值，是指3日RSI與6日RSI乖離（開口）過大，超過22～25以上。尤其是25以上，出手操作成功率更高。

# 領先指標（RSI正臨界值）的出手點

如圖（8-24）是期指日線圖

+   一、圖中①所示，出現RSI正臨界值77-53=24。若出手短空，隔兩天拉出一根中長黑。

+   二、領先指標出現時，可能當天就反應，也有可能延續出現1～3天再反應。

# 重點提示：

+   1. RSI正臨界值乖離（開口）越大，而且位置越高，回檔的成功率更高。

+   2. 若RSI開口的位置不夠高，可能只反應一天再續漲，此時操作手腳要快，且應善設停損。
