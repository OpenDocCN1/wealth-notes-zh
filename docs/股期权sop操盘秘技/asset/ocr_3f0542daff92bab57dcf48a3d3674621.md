# 盤整亦有續航力道

也許讀者會認為續航力道是只有在漲勢或跌勢才會產生，其實也不一定。當指數或股價進行一段長時間的「盤整」。換句話說，「盤」很久，也是算是「盤」的續航力道強。

不過在一般投資者的觀念裡，都把續航力道認為漲很久或跌很久。換言之，漲勢的力道強或跌勢的力道強，忘了「盤整」的力道有時候也會很強（久）。
