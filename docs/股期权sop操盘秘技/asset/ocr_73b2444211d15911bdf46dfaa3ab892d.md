# 選擇權SOP的應用（組合操作策略）買進韌式

買進韌式主要是做在買方，買方的特性必須靠指數大涨或大跌才有利潤。否則權利金易受時間價值的關係而流失。因此操作買進韌式必須有能力研判指數在短時間內會大涨、大跌才進場操作。

不過在「週選擇權」上路後，筆者發現在每週三結算日之前1～2天試作一組（賭）買進韌式或買進跨式，在結算日若逢指數大幅震盪或大涨、大跌皆有機會中獎，賺到數倍的利潤。

週選擇權在民國101年11月上路，筆者在102年農曆年後，開始統計在結算日之前1～2天操作買進韌式或買進跨式的成功率和，發現成功機率很高。因此特別撰寫一本《週選擇權獲利大解密》分享操作心得，預估在2013年的年底出版，投資人可購買參閱，以小搏大靠實力也靠手氣。

操作買進韌式或買進跨式，如同購買券商所發行的「權證」一樣，以小搏大。只要會操作買方的Call或Put，就會操作認購權證與認售權證，下一頁筆者以實例說明買進韌式與買進跨式的操作技巧。
