現在筆者再舉一個RSI在高檔區做出高爾夫球桿的例子給讀者參考。

# RSI在高檔區做出高爾夫球桿

技術指標RSI若在高檔區鈍化，如高爾夫球桿的「桿頭，快則1～3天，慢則3～5天內就會回檔，可切入短空。所謂高檔區是指3日RSI或6日RSI皆在80以上。

如圖（9-4）是奇美材的日線圖

+   一、圖中①所示，RSI在高檔區虛線部份做出如高爾夫球桿的桿頭，當RSI交叉向下之後，股價開始回檔。自39.2元跌到34.65元，若切入短空，可賺取價差。

如圖（9-5）是智易的日線圖

+   一、圖中①所示，RSI在高檔區虛線部份做出如高爾夫球桿的桿頭。當RSI交叉向下之後，股價自45.8元回檔到38元。

# 重點提示：

+   1. 3日RSI與6日RSI必須走平才可稱作高爾夫球桿。

+   2. 在低檔區高爾夫球桿的桿頭位置越低反彈的成功率越高。反之，在當檔區桿頭的位置越高，回檔的成功率越高。
