# 第四個方塊：成功法則，其內容有三種

+   1. 判定漲、跌、盤並預測壓力、支撐

+   2. 選股、換股、設價（買進、賣出、停利、停損價）

+   3. 遵守紀律執行停利停損

# 第五個方塊：續航力道，其內容有二種

+   1. 指數漲（跌）幅500點以上

+   2. 個股漲（跌）幅2～3成以上

以上五個方塊圖是筆者設立的SOP。而每一個方塊皆有它獨立的功能，若把它的功能串聯起來，就非常的完美無缺。

在2-2節，筆者就會將每一個方塊圖的功能，做詳細的說明。長江後浪推前浪，前浪死在沙灘上。筆者有很多學員的功力已經勝過我，他們會將此五個方塊圖的內容改為更精準的指標，筆者欣然接受，因為「有狀元學生，無狀元老師」學生比老師更強是老師的榮耀。
