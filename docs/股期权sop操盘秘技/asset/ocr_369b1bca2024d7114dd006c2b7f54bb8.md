# 熟練SOP以後，就可得心應手

小時候看布袋戲大師黃俊雄先生所演的布袋戲當中，有一個老和尚，他學了很多的武功，但遇到壞人時，卻因為功夫學太多而不知道要用那一招，所以常常挨揍，需要旁人提醒他後就能反敗為勝。所以當陳霖老師應學員的要求，寫《股權期SOP操盤秘技》時，我的內心會然一笑。同樣的，當開始在學手排車時，一下子要踏離合器，一下子要入檔，還要注意前後左右，行進時緊急煞車，還怕熄火，真的是滿身大汗手忙腳亂，但這個過程一定要經歷，熟練以後，方向盤可單手操作，眼睛瞄一下，要做什麼動作都可得心應手。
