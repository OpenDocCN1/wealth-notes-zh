# 莊序

系統化交易一直是個人相當認同的期貨交易方式之一，原因倒不在於系統交易擁有較誘人的獲利保證，而是如同陳霖老師本書中所提到的，多數期權投資人交易都缺乏一套一致性的邏輯或是交易規劃，導致交易變成隨機交易，沒有章法地建立部位就代表沒有事先把資金管理想好、就代表將被人性缺陷牽著走，賺小賠大、貪婪恐懼等老毛病很容易就上身了。

陳霖老師用SOP（Standard Operating Procedure）標準作業流程的概念重新演繹了系統性思考與規劃在股期權交易的運用，老師在其《10倍數操盤法》、《股市三寶》、《期權賺很大》、《K線實戰秘笈》、《45度線獲利秘訣》等前著的基礎上再推出《股期權SOP操盤密技》更有總結統合、畫龍點睛的用意，讀者透過老師生動實務的範例，一方面運用其教授的交易技巧，更重要的可以學習到如何把整個交易流程有系統地、很明白地定義出來，包括怎麼判斷行情方向？怎麼找點位進場？怎麼加減碼？怎麼出場？等等每一個交易細節。各位讀者用心看完這本書，再自行比對、檢討自己過去的交易模式，相信一定會有很大的收穫與進步！
