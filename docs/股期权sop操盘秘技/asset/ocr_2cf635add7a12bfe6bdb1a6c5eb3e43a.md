# 技術面選股的八大指標

做多：

+   1. 島型反轉向上或底部區出現上漲或突破缺口。
2. 完成上漲二賣以上（含突破45度線）。
3. 三線合一向上拉長紅突破前波高點，前面3～6個月量小。
4. 突破長期下降趨勢線。
5. 型態做出雙底以上或突破頸線。
6. 技術指標RSI、KD或MACD在低檔區做出背離或雙底以上交叉向上。
7. 三大法人連買三天以上且基本面轉佳有炒作題材。
8. 上述選出的個股前面3～6個月的成交量要小。

做空：

+   1. 島型反轉向下或頭部區出現下跌或跌破缺口。
2. 完成下跌二賣以上（含跌破45度線）。
3. 三線合一向下拉長黑跌破前波低點，前面3～6個月量大。
4. 跌破長期上升趨勢線。
5. 型態做出雙頭以上或跌破頸線。
6. 技術指標RSI、KD或MACD在高檔區做出背離或雙頭以上交叉向下。
7. 三大法人連賣三天以上且基本面轉差無有利空題材。
8. 上述選出的個股前面3～6個月的成交量要大。
