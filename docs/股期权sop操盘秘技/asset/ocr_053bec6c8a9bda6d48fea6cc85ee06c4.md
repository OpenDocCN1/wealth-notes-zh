# 期貨SOP的應用

# （領先指標技術指標低檔二次背離以上）

領先指標有四個，其中第四個是技術指標二次背離以上。技術指標包括RSI、KD、MACD柱狀體。若其中有一項出現二次背離以上皆可視為領先指標。

當指數在下跌中，若出現技術指標在低檔區做出二次背離以上，就可出手短多，反彈中有賺就跑，沒賺宜設停損。

+   二、圖中②所示，KD指標在低檔區做出二次背離，可視為領先指標，隔天指數開始反彈，反彈幅度較高。
