# 期貨指數的設價

SOP方塊流程圖亦適用期指。本書所討論的是以日線為主。日線對期指而言是屬於波段操作。不過目前操作期指的朋友，較少波段操作，大都是當沖或短線操作。因此大部分的投資人皆以「分鐘線」為看盤重點。

筆者所著《期權賺很大》的期貨篇，就是以分鐘線為主要設定的買賣點。我們設定了九個重點。如圖表（二）。

# 大家一起來，團結力量大

在期指的訓練課程中，我們時常講一句話：「大家一起來，團結力量大」。換言之，當期指1分線或5分線同時出現九個重點的其中三個以上。此時切入的成功率最高。其中排名在前面1～5名的重點最重要。

在此筆者必須補充說明第二名（成交量）的位置如何切入。

+   一、在下跌趨勢中，若連續出現三次以上的大量，必須等到最後一根大量換手成功，再切入做多，才不會誤判。

+   二、反之在上漲趨勢中，若連續出現三次以上的大量，必須等到最後一根大量換手失敗，再切入做空，才不會誤判。
