# # 沒有三兩三不能上梁山

沒有真功夫不能上戰場，沒有三兩三不能上梁山。不管投資方向做多與做空，只要方向不對應立刻修正，不能堅持已見或主觀的看法認為會漲或會跌。股票市場瞬息萬變，各路消息五花八門，不論如何最終將反應在股價上，只要趨勢向上則做多，反之趨勢向下則做空，

# ## 增強操盤IQ改正不良EQ

讀者起初入股市時，由於沒有獨立判斷行情的能力每買必套，直至最近幾年來經過多次上陳霖老師的股市三寶、期權賺很大與實戰教學後，才深深地體會操作策略與善設停損的寶貴經驗。藉由有紀律的操作，不斷的提升自己操作勝率，記起老師的叮嚀「要注意成功的次數，不要在意獲利的點數」，增強操盤IQ改正不良EQ，現在已經慢慢恢復投資信心了。

# ## SOP讓我臨危不亂 做出正確的判斷

如何應用股市SOP避免心肌梗塞的發生，當我們身歷在股海之中尚在猶豫不決，如何判斷買點浮出或賣點的浮現時，因有SOP當準則，加上股市三寶與領先指標當護身符就可臨危不亂做出正確的判斷。

領先指標：1.價乖離2.軌道線3.RSI臨界線4.技術指標二次背離。以上有出現二種以上只能短線操作有賺就跑。
