# 螳螂捕蟬，黃雀在後

期貨指數分鍾線的九個切入點，在《期權賺很大》中寫得很清楚，讀者可自行參閱。

上一页提示從分鍾線切入時要特别注意日線（母線）的位置，現在筆者就舉個實例讓讀者參考。

如圖（6-3）是102年5月3日1分線圖

+   一、圖中①所示，期指早盤跳空上漲馬上突破缺口最上限，是一種強勢上漲訊號，即是買進（螳螂捕蝉）。

+   二、圖中②所示，指數漲到8174遇到日線壓力（黃雀在後）。

+   三、若早盤從1分線缺口最上限（8152）切入做多。手腳夠快在日線壓力8174高出，還有20點利潤。若來不及高出，被日線如圖（6-4）壓回，指數最低來到8119不但未賺反倒賠。

如圖（6-4）是102年5月3日的日線圖

+   一、圖中①所示，就是102年5月3日K線觸及軌道上沿，留長上影線。下一個交易日再度觸及軌道上沿，K線開高走低收黑。

+   二、圖中②所示，就是軌道上沿8174的壓力，當日1分線漲到此位置被壓回。如何判定會被壓回，可從1分線跌破多空線看出。

+   三、若從日線上升軌道上沿（領先指標）8174切入做空，反而獲利較大。
