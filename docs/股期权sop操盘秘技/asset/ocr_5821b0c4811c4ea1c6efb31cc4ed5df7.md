二次背離）的出手點

如圖（8-13）是和泰車日線圖

+   一、 圖中①所示，MACD柱狀體，在零軸以上出現第一次背離。

+   二、 圖中②所示，MACD柱狀體，在零軸以上出現第二次背離，可視為領先指標。

+   四、 您會發現MACD柱狀體在零軸以上做出二次背離後，股價開始回檔。自173.5元下跌到146元，再續跌到128.5元。若即時切入可賺取短線價差。而且RSI與KD亦同步做出一次背離，因此下跌幅度較深。這就是筆者上課中常說的「大家一起來，團結力量大」。
