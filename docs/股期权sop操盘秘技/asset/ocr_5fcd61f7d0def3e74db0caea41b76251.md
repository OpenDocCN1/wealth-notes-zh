# 2-2 SOP方塊圖的功能

# 一、第一個方塊：領先指標

功能：1. 可讓我們買到相對低點或賣到相對高點。

2. 它是逆勢單，因此只能短線操作有賺就跑。

3. 若從其他指標研判有波段行情才可久抱波段操作。

# 二、第二個方塊：轉折指標（股市三寶）

功能：1. 判定漲、跌、盤的轉折點。

2. 可用於選股，只要完成二寶以上（含45度線）就可視為選股條件。

3. 控管資金，將資金分成三等份，依據漲、跌、盤分配。

# 三、第三個方塊：波段指標

功能：1. 成交量具有預警作用，可研判漲、跌、盤的續航力。

2. 量是價的先行指標，價是量的決心指標。

3. 四個波段指標必須完成三個以上，成功率較高。換言之，較有波段行情。所謂波段行情就是指數有500點以上的漲跌空間。個股則有2～3成的漲跌幅。
