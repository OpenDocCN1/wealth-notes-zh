# 聯電的下降軌道圖形與波段指標

筆者以聯電（2303）實例說明如下

+   一、圖（8-1）是聯電日線圖。其K線圖表已設定畫45度線的規格。

+   二、圖中①所示，出現下降軌道線下沿的領先指標。可搶短多有賺就跑。領先指標過了之後，就看股市三寶。在反彈的過程中皆未完成上漲一寶。因此指數反彈後仍然繼續下跌。

+   三、圖中②所示，直到101年11月23日才突破精緻畫45度線完成上漲一寶。股價由「跌」進入「盤」。就可進入第四個方塊「成功法則」，可投入3～5成的資金操作。

+   四、圖中③所示，完成上漲三寶，股價由「盤」進入「漲」。就可進入第三個方塊「波段指標」研判是否有波段行情。

+   五、從圖（8-2）可看出圖中①所示，出現攻擊量。圖中②所示，均線三線合一。圖中③所示，MACD做出三底，研判有波段行情。就可進入第五個方塊「續航力道」研判其續航力道較強。

+   六、股價由10元漲到12.55元很接近3成。雖不滿意但可接受。
