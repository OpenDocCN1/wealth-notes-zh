# 個股RSI臨界值實例

如圖(3-11) 是華碩個股日線圖。

+   一、圖中①所示，股價在101年1月16日，當日3日RSI
(14) 、6日RSI(39) ，相差(14-39)負25，隔天
股價開始反彈。

+   二、圖中②所示，股價在101年2月16日，當日3日RSI
(15) 、6日RSI(37) ，相差(15-37)負22。隔天2
月17日的3日RSI(15) 、6日RSI(37) ，相差
(15-37)負22。連續兩天皆出現相等的RSI臨界值
(負乖離) ，第三天2月20日開始反彈。

重點提示：

+   1. RSI的負乖離（開口）越大，位置越低，則成功率越高。
反之，正乖離（開口）越大，位置越高，則成功率越高。

+   2. 領先指標有時會延續1~3天才反應。
