# 1-1 何謂股期權SOP

SOP（Standard Operating Procedure）翻譯成中文：標準作業流程。我們知道任何一個行業，如製造業、服務業…等都有一套「標準作業流程」，簡稱SOP。

對製造業而言，大到生產線的流程，如工作母機的操作。小至產品的品管…等。都有一套SOP，如此才能確保商品的品質。操作機器的技術人員，若照SOP操作，其安全性亦有保障。

在勞工局所舉辦的職災防護課程中，可以看到很多勞工朋友受傷或是死亡的影片。大都是沒有按照SOP操作機器所引起的。換言之，「推高機」有操作推高機的SOP。「塑膠射出成型機」也有其操作的SOP…等。若能依照SOP操作，至少安全無虞。

對服務業而言，也有SOP。SOP廣義的解釋也可視為「成功的操作系統」。如我們所熟悉的麥當勞、統一超商、85℃…等。他們都有一套成功的系統在運作，而每一家分店都複製成功的系統，因此每一家分店大都會賺錢。您是否發現台灣有很多知名的公司，要求其員工連接電話都有一套SOP，例如：接電話的員工拿起電話筒會說：「台大公司您好！我是王大維，很高興為您服務」。而且公司也會不定時派員以電話稽查員工是否按照SOP接電話。
