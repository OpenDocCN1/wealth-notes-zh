# 敬愛的陳霖老師您好：

首先恭喜陳霖老師您又有新作要出版了，《股期權SOP操盤秘技》一書，真是我們股海中的燈塔，它照亮各位股民的投資方向，讓我們在茫茫股海中不要迷航，更指導我們在股市中賺錢的方法。老師您就像菩薩下凡濟世救度眾生一樣，慈悲喜捨、無私無我、犧牲奉獻，把自己一生精研的股市祕訣全部告知我們這些股市眾生，真是感恩，再感恩！

盛耀在股市已浮沉二十多年了，從不懂到懂，從不會到會一點，除了自我摸索學習之外，也曾跟幾位老師學習過，還是無法學到任何可做為在股市生存的方法。但在七年多前一次偶然機會，有幸聽一位朋友介紹鑫報一位陳霖老師的專欄很棒，要我參考看看。因緣巧合下，讀了老師您的股市專欄作品驚為天人，下定決心要跟老師學習，更購得「十倍數操盤法」與「股市三寶」兩書，經詳細拜讀後才知在股市操作竟然有這麼簡單又明瞭的好方法，真是喜出望外、雀躍不已。為了探討測試並積極學習，迄今我已重複詳讀數遍，更積極參加老師在台北師大的股票技術訓練課程，從第一堂課「股市三寶、K線搏擊與均線的買賣點」；第二堂課「畫線技巧：趨勢線、45度線、軌道線」；第三堂課「成交量各種名稱與看盤技巧」；第四堂課「各種型態與技術指標的買賣點」等…，經過一個月時間上課，讓我在股市操作上精進不少，後又陸續參加老師
