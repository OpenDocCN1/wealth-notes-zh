# 國際金融商品SOP的應用（歐元匯美）

最後筆者再舉歐元匯兌美元為例子給讀者參考。

如圖（8-65）是歐元匯美的週線圖

+   一、圖中①所示，RSI、KD、MACD柱狀體，三個技術指標皆打出雙底交叉向上。

+   二、圖中②所示，K線也突破長期的下降趨勢線。

+   三、因筆者使用的軟體目前看不到成交量，若無出現攻擊量，那麼僅完成上漲波段指標的二個條件。因此歐元兌換美元雖然展開升值行情，但無波段的升值行情。但至少也從1.2040升值到1.3711。

+   四、圖中③所示，當歐元升到1.3711的時候，技術指標RSI、KD做出雙頭向下，MACD柱狀體在零軸之上做出三頭向下，且跌破長期上升趨勢線（如圖中④所示），歐元開始回貶。

+   五、圖中④所示，K線跌破長期的上升趨勢線與RSI、KD雙頭向下也僅完成下跌波段指標的二個條件。因此歐元雖然貶值，但貶值的幅度不高。

+   六、整體來看歐元呈現區間的橫向盤整走勢。
