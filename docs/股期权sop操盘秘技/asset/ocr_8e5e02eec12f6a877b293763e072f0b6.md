# ## 6-2 選股換股設價

剛才談到只要指數或個股由「跌」進入「盤」，就可開始選股操作，對於操作股票的朋友，選股是是最大的挑戰。換言之，獲利多寡與每一個人的選股功力有關。

指數或股價之所以會有漲、跌、盤的變化，是受到基本面、技術面、消息面等三大面相的影響。而其中消息面的影響最大。基本面與消息面我們很難掌握，不在本書的討論範圍。

雖然本書是針對技術面的探討，但投資人仍應注意基本面與消息面對股市或股價所造成的衝擊。例如102年第一季外資法人對台積電的業績頗有疑慮，除了降低評等之外，也紛紛拋售持股。結果102年4月份台積電法說會中，董事長張忠謀聲稱台積電業績大好。隔天4月19日台積電跳空上漲鎖漲停。留下4.5元的大缺口。市場戲稱此缺口是「張忠謀缺口」。股價自100元不到兩週漲到112元以上。

由此可見基本面對投資人而言是落後指標，除了內線消息之外，一般投資人很難取得第一手資料。基本面況且如此，更何況消息面，投資人更不容易掌握。因此建議投資朋友可由技術面先學習起。
