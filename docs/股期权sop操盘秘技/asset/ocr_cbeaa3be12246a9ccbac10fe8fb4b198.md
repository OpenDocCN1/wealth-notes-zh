# 最佳指標的應用（RSI乖離、多重底或多重頭背離）

先前的幾本著作已談過多次，筆者把技術分析的技術線型圖分成「線型指標」與「技術指標」兩大類。
線型指標：如K線、均線、畫線、成交量、型態…等。
技術指標：RSI、KD、MACD、DMI、OBV…等。

我們研判行情或設定買賣點應以線型指標為主，技術指標為輔，但是若技術指標出現領先指標或打出三個底、三個頭…等，其精準度優於線型指標。此時就該以技術指標為主，線型指標為輔。
