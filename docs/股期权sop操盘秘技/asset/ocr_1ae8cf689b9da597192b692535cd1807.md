# 10-4 台中學員

# 人生像一杯茶，不會苦一輩子，但總會苦一陣子

跟著陳霖老師學習技術分析已經快三年了。從不懂到懂，從不會到會，從賠錢到賺錢。在股市嘗盡酸甜苦辣。終於苦盡甘來。相信很多操作股票、期貨或選擇權的朋友一定會體會套牢、賠錢的椎心之痛。當我學會操作股票，從賠錢到會賺錢的過程中體會出「人生像一杯茶，不會苦一輩子，但總會苦一陣子」。苦盡甘來的感覺真的很好。

陳霖老師將上課的內容彙整成一本《股期權SOP操盤祕技》真是投資人的福音。以前我上課時做了很多筆記。現在只要擁有這本SOP的專書就等同於先前所做的筆記。也可說是「股市的葵花寶典」。不過以我以過來人的身份，還是建議投資人親身上老師的課體會較深。

# 一個人有多優秀，要看他有誰指點

「一個人有多優秀，要看他有誰指點」，「一個人能走多遠，要看他有誰同行」，「一個人有多成功，要看他有誰相伴」。若跟著流浪狗走，就會遇到一堆屎。跟著獅子走就會遇到一片森林。我很幸運能跟隨陳霖老師學習操作股票、期貨、選擇權的成功方法。雖然還談不上成功致富，但已慢慢累積財富，謝謝陳霖老師並祝福老師身體健康，萬事如意。也祝福投資朋友心想事成，操盤順利成功。

台中學員 Rober
