# 投資無捷徑 一步一腳印～感恩陳霖老師

高齡107歲的投资大師—歐文·卡恩有兩句名言：「成為一個成功的投資者，一定要不斷的學習」

「作投資、最重要的不是跑得比別人快，而是持續在跑道上。」問題是如何能夠持續在跑道上與人競逐，而不遭淘汰？大師明訓：「不斷的學習！」

很高興陳霖老師股市投資的SOP即將出書，實在是令人期待的一件事！投資是圓夢的一個階梯，唯有透過不斷的學習會有正面的結果！在漫長的投資學習摸索中，從憑感覺到尋找願意傾囊相授的老師是一段不易尋求的機緣與福報！

投資市場是一個爾虞我詐，極度波動與不確定，多數人在這市場上想要一夜致富圓人生的夢，鍛羽受傷遍地哀鴻的人多過成功者，主要的關鍵是想要投資的人常常不得其門而入，找不到真正的良師，市場上所謂的老師，能夠真正的無私分享，願意傾囊相授，且不藉機詐財的如微塵般之少，這是我經過多年痛苦的摸索與尋求後的心得，相信也是多數人的痛！
