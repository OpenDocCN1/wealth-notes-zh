# 選擇權SOP的應用（組合操作策略）價差策略

所謂價差策略廣義的解釋具有保險的功能，主因是當您偏多操作時，又怕看錯方向，此時可加一口空單。萬一看錯方向可減少虧損，以達到避險效果。反之當您偏空操作時，又怕做錯方向，此時可加一口多單避險。

先前提到價差策略有四種

一、買權的多頭價差：（買低賣高）

使用時機：指數偏多，但又怕看錯方向，可做一組多頭價差。

組合內容：買進較低履約價的買權，賣出較高履約價的買權。

二、買權的空頭價差：（買高賣低）

使用時機：指數偏空，但又怕看錯方向，可做一組空頭價差。

組合內容：買進較高履約價的買權，賣出較低履約價的買權。

三、賣權的多頭價差：（買低賣高）

使用時機：指數偏多，但又怕看錯方向，可做一組多頭價差。

組合內容：買進較低履約價的賣權，賣出較高履約價的賣權。

四、賣權的空頭價差：（買高賣低）

使用時機：指數偏空，但又怕看錯方向，可做一組空頭價差。

組合內容：買進較高履約價的賣權，賣出較低履約價的賣權。
