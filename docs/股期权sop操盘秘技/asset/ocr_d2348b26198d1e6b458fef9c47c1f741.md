# 選股與設價

上一頁是技術面選股的八大條件。當我們選擇一檔股操作時，無論做多或做空皆應設價。所謂設價，即是設定買進價、賣出價、停利價與停損價。設價技巧可也可用看、算、畫，三種技巧預測支撐與壓力。再進行設價買進、賣出與停利、停損。

# 選股設價實例

如圖（6-2）是合肥（1722）日線圖

+   一、圖中①所示，技術指標RSI打出雙底交叉向上。
二、圖中②所示，股價突破長期（2～3個月）下降趨勢線。
三、圖中③所示，均線做出三線合一（5、10、20日均線）向上。
四、圖中④所示，股價突破頸線（前一波高點）且出現攻擊量。
五、圖中⑤所示，股價跳空出現突破缺口。

由以上五點，可發現合肥完成「做多」八大條件的三個以上，因此可設價買進。

# 如何設價：

+   一、可設在均線三線合一，且突破長期下降趨勢線的位置。
二、可設在突破頸線的位置。

由於上市上櫃股票有1000多檔，投資人可利用股票軟體自行撰寫選股程式。由電腦初選，再經過自己複選就可選到強勢股。
