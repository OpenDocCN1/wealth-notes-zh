# 上升45度線的標準畫法與精緻畫法

45度線有上升的45度線與下降的45度線。無論是上升的45度線或下降的45度線皆有兩種畫法：1.標準畫法。2.精緻畫法。

首先我們先談上升45度線的標準畫法與精緻畫法

# 一、上升45度線的標準畫法

所謂標準畫法是在上漲趨勢中，自波段的低點畫上去的第一條上升45度線，稱為標準畫法。

# 二、上升45度線的精緻畫法

在上漲趨勢中除了畫出標準畫法之外也可加畫精緻畫法。因為在上漲趨勢中，K棒可能出現三種情況：1.跳空上漲的缺口。2.橫盤後再漲。3.每一小波的低點（底部）。

若出現上面3種情況時，可再加畫一條上升的45度線，所加畫的上升45度線，我們把它稱作精緻畫法。

當指數或股價跌破最上面那一條精緻畫法的上升45度線時，就可判定45度線下跌一賣完成了。此時大盤趨勢由「漲」改變成「盤」。文字說明或許讀者不太了解，後面再舉例說明。

重點提示：
1.上漲跳空的缺口：必須在缺口的上限位置加畫上升45度線。
2. 橫盤的突破：必須等橫盤突破後，再從低點畫上升45度線。
3. 小波段的低點：必須在每一個小波段的低點畫上升45度線。
