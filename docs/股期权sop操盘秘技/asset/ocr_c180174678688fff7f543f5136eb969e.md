# 下降45度線的標準畫法與精緻畫法

再談一談下降45度線的標準畫法與精緻畫法。

# 一、下降45度線的標準畫法

所謂標準畫法是在下降趨勢中自波段的高點畫下來的第一條下降45度線，稱之為標準畫法。

# 二、下降45度線的精緻畫法

在下跌趨勢中除了畫出標準畫法之外也可加畫精緻畫法，因為在下跌趨勢中，K棒可能出現三種情況：

1.跳空下跌的缺口、2.橫盤後再跌、3.每一小波的高點（頭部）。

若出現上面3種情況時，再加畫一條下降的45度線，所加畫的下降45度線，我們把它稱作精緻畫法

當指數或股價突破最下面的那一條精緻畫法的下降45度線時，就可判定45度線上漲一竄完成了。此時大盤趨勢由「跌」改變成「盤」。文字說明或許讀者不太了解，後面再舉例說明。

重點提示：

+   1. 下降跳空的缺口：必須在缺口的下限位置加畫下降45度線。
2. 橫盤的跌破：必須等橫盤跌破後，再從高點畫下降45度線。
3. 小波段的高點：必須在每一個小波段的高點畫下降45度線。
