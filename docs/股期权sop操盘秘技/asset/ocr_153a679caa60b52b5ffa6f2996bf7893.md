# 最佳指標的應用（技術指標低檔或高檔背離）

技術指標（RSI、KD、MACD）若做出一次背離，亦視為最佳指標，在低檔區做出一次背離至少會有雙底。反之，在高檔區做出一次背離，至少會有雙頭。

技術指標（RSI、KD、MACD）若做出二次背離，可視為領先指標。在低檔區做出二次背離至少會有三個底。反之，在高檔區做出二次背離至少會有三個頭。

如圖（9-7）是仁寶的日線圖

+   一、圖中①所示，3日RSI在低檔區做出二次背離（領先指標）且打出三個底，且位置夠位。

+   二、圖中②③所示，KD做出一次背離與MACD柱狀體在零軸之下同時打出雙底，可說是「大家一起來，團結力量大」。因此股價自16.05元反彈到19.5元。

如圖（9-8）是宏達電的週線圖

+   一、圖中①所示，3週RSI做出雙頭交叉向下，且第二個頭RSI正乖離（開口）過大，高達18，股價自672元一路下跌。

+   二、圖中②所示，3週與6週RSI正乖離（開口）夠大，高達（87-60）=27，出現RSI臨界值（領先指標）。股價自325元一路再跌到191元。當然與宏達電的基本面轉差也有關係。
