
## 選擇權的單一操作策略

當我們確定大盤的方向之後，就可採取選擇權的兩大策略擇一操作，所謂兩大策略就是「單一操作策略」與「組合操作策略」。說明如下：

### 單一操作策略：內容僅四種

- 1. 買進買權（做多）：當判定指數有大漲機會時，可採取「買進買權」單一操作策略。
- 2. 買進賣權（做空）：當判定指數有大跌機會時，可採取「買進賣權」單一操作策略。
- 3. 賣出賣權（做多）：當判定指數有小漲有壓時（漲幅不高），可採取「賣出賣權」單一操作策略。
- 4. 賣出買權（做空）：當判定指數有小跌有撐時（跌幅不深），可採取「賣出買權」單一操作策略。

或許讀者大人會問如何判定大漲大跌呢？在《期權賺很大》書中選擇權篇的第四章第二節（231～233頁）有詳細說明。筆者在「線型指標」篩選出四個，作為大漲、大跌的條件。在「技術指標」篩選出三個，做為大漲、大跌的條件，讀者可自行參閱。

在SOP的方塊流程圖中，第三個方塊「波段指標」也可作為判定大漲、大跌的條件。因為它可判定是否有波段行情。若判定有波段行情，就可在當月份選擇權可採取操作價外的履約價。或操作遠月份的選擇權，獲利更高。

## 選擇權的組合操作策略

選擇權組合操作策略非常多，如勒式、跨式、蝶式、鷹式、價差策略…等。本書僅舉八種比較常用的策略，至於其他較複雜的策略可參閱《期權賺很大》書中的內容。

### 組合操作策略：比較常用的八種策略

- 1. 買進勒式：當指數大漲大跌來回震盪時，可採取買進勒式策略，多空操作。
- 2. 買進跨式：當指數大漲大跌來回震盪時，可採取買進跨式策略，多空操作。
- 3. 賣出勒式：當指數盤整時，可採取賣出勒式策略，賺時間價值。
- 4. 賣出跨式：當指數小漲小跌時震盪區間狹小，可採取賣出跨式策略，賺時間價值。
- 5. 買權的多頭價差：當指數盤整趨漲時，可採取買權的多頭價差策略。賺取多方的利潤。
- 6. 買權的空頭價差：當指數盤整趨跌時，可採取買權的空頭價差策略。賺取空方的利潤。
- 7. 賣權的多頭價差：當指數盤整趨漲時，可採取賣權的多頭價差策略。賺取多方的利潤。
- 8. 賣權的空頭價差：當指數盤整趨跌時，可採取賣權的空頭價差策略。賺取空方的利潤。
