# 建立一套屬於自己操作的SOP

我們了解SOP的重要性之後，無論操作股票、期貨、選擇權的新手或是老手皆該設立一套屬於自己操作的SOP，然後按照SOP一步一步的操作，必然不會患得患失，而且可穩健獲利。

筆者從事股票教學的生涯中，發現很多投資朋友之所以操作失敗，就是沒有自己的SOP。常常受到他人或消息面的影響，心無定見，做出錯誤的判斷，事後才後悔莫及。

同時筆者也看到很多成功的例子，原來他們都有一套成功的SOP在運作。如何判斷行情、如何選股設價、如何解讀消息面…等都有一套SOP，難怪操作股期權非常淡定，獲利是必然的。

技術分析非常浩瀚，各種門派、絕招比比皆是，對於初學者很難抓住重點。筆者特別把比較重要且成功率高的指標結合在一起，並按照順序規劃出五個方塊流程圖，作為自己操作的SOP。且分享給購買本書的每一位讀者。

當學員們有了一套SOP之後，操作股、期、權的技巧就大幅提高，當然勝率也不在話下。目前就有很多學員已成為專業的投資人在股海中不斷的累積財富，完成人生所要的夢想。
