# 股期權SOP操盤祕技

# 九種最佳指標的出手點

一、**島型反轉**：島型反轉的成功率很高，反轉向上（做多），反轉向下（做空）。

二、**缺口**：上漲缺口或突破缺口（做多），下跌缺口或跌破缺口（做空）。

三、**45度線**：突破下降45度線（做多），跌破上升45度線（做空）。

四、**三線合一**：均線做出三線合一且突破前波高點（做多），反之跌破前波低點（做空）。

五、**陡線**：這是逆勢單，利用突破或跌破陡線當沖或隔日沖短線操作，可參閱《期權賺很大》第六章。

六、**準備先指標**：3日RSI跌到5～2以下（做多），漲到95～98以上（做空）（中大型個股較準，小型股較不準）

七、**技術指標**：RSI、KD、MACD在低檔區一次背離或雙底以上（做多），在高檔區一次背離或雙頭以上（做空）。

八、**RSI乖離16以上**：3日與6日RSI在低檔區負乖離過大（做多），在高檔區正乖離過大（做空）。

九、**技術指標做出高爾夫球桿**：RSI或KD在低檔區做出高爾夫球桿（做多），在高檔區做出高爾夫球桿（做空）。
