# 期貨SOP的應用（領先指標RSI負臨界值）

領先指標的內容有四個。其中第二個是RSI臨界值（可分為正臨界值與負臨界值）。當指數在下跌中，技術指標RSI出現負臨界值，可出手短多期指，反彈有賺就跑，沒賺宜設停損。

所謂RSI臨界值，是指3日RSI與6日RSI乖離開口過大，超過22～25以上。尤其是25以上，出手操作成功率更高。

# 領先指標（RSI負臨界值）的出手點

如圖（8-23）是期指日線圖

+   - 一、圖中①所示，出現RSI負臨界值38-63=-25。若出手短多，隔天拉出中長紅高出，就可賺到價差。
- 二、圖中②所示，出現RSI負臨界值16-39=-23。若出手短多，隔天雖未拉出長紅，但盤中高出仍有價差可賺。
- 三、圖中③所示，出現RSI負臨界值12-33=-21。雖然未達負22以上的標準，但兩天之後仍拉出一根中長紅。

重點提示：

+   1. RSI負臨界值乖離（開口）越大，且位置越低，反彈的成功率越高，可能當天或1～3天內就反應。
2. 若RSI開口的位置不夠低，可能只反應一天後再續跌，此時操作手腳要快，且應善設停損。
