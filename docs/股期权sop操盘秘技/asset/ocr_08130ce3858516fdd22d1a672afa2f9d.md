# 滅火器的SOP

現在筆者舉個例子：滅火器的標準作業流程（SOP）

滅火器的SOP：拉、拉、壓。

+   一、第1個拉：是拉開滅火器的插銷。
二、第2個拉：是拉起滅火器的噴管對準火苗底部。
三、第3個壓：是向下壓即可噴出泡沫滅火。

以上三個步驟就是滅火器的SOP。一定要按照先後順序才能讓滅火器成功的發揮效果。

您會發現有人看到失火了，因為太緊張忘了第一個步驟：拉插銷，就猛壓。當然無法壓出泡沫。或者已經拉開插銷，而忘了第二個步驟：拉噴管。結果壓出的泡沫不是噴在火苗，反而噴在自己的腳下。由此可見SOP的重要性。

言歸正傳，我們操作股票、期貨、選擇權或其他金融商品…等。亦要建立一套SOP。也可說是建立一套屬於自己操作的成功系統。每一個人操作方式或許不盡相同。但至少成功率要達到8成以上的水準，才可在股票、期貨、選擇權的市場中獲利。
