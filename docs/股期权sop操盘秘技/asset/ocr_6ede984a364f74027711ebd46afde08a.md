# 導讀

為了讓讀者能快速閱讀本書的精華，因此筆者特別撰寫導讀。引領讀者視自己所需要的內容優先閱讀，以節省閱讀時間。

+   一、本書內容共有十章，其中第一章與第二章說明SOP的重要性與SOP方塊圖流程圖的操作順序與功能。

+   二、第三章至第七章敘述SOP每一個方塊所使用的指標的功能，其中領先指標有四個、股市三寶有三個、波段指標有四個。

+   三、第八章是SOP的綜合應用，筆者例舉一些實例，分享如何利用SOP操作股票、期貨、選擇權，以及其他金融商品，如匯率黃金…等。

+   四、第九章最佳指標的應用，是將過去筆者所著作的書籍整理出九個比較準確的買賣點，提供給讀者作為出手的買賣點，與SOP的指標相輔相成，進而提高操作的成功率。

+   五、第十章是學員們感性的分享。學習別人成功的經驗是邁向成功的最佳捷徑，值得一看。

+   六、讀者大人，如果您已看過筆者先前出版的書籍，可直接看第五章、第七章、第八章、第九章。因為它是本書新的內容。

+   七、至於從未購買筆者著作的新朋友首次購買本書，建議從第一章至第十章依序閱讀。若有不瞭解的地方，可參閱筆者先前的著作。或參加我們的訓練課程，必可功力大增。

我為您祝福！
