# 選擇權SOP的應用（組合操作策略）買進軋式

現在筆者就舉「週選擇權」買進軋式的實例給讀者參考。

+   1. 如圖（8-45）所示，102年5月7日的「週選擇權」行情表
2. 5月7日是結算日的前一天，筆者決定操作一組「買進軋式」，賭一賭5月8日結算日是否獲利？
3. 筆者選擇在8100的履約價作「買進賣權」。當時的權利金5.4點。同樣在8200的履約價作「買進買權」。當時的權利金6.1點。合計給付權利金（5.4＋6.1）＝11.5（點）。

+   1. 如圖（8-46）所示，102年5月8日週選擇權行情表
2. 5月8日結算日，當日指數剛好大漲104點。從圖（8-46）的行情表可看出8200履約價買權的權利金58點。8100履約價賣權的權利金0.1點。
3. 買權與賣權兩者合計權利金58＋0.1＝58.1（點），扣掉成本11.5點，還可賺58.1－11.5＝46.6（點）。大約可獲利4倍以上。

重點提示：

+   1. 當我們操作買進軋式之後，只要指數大幅震盪盤中，有賺就可先獲利平倉出場，不一定等到結算日在平倉。
2. 因為買方的權利金流失很快，若手腳不夠快反而虧損。
