# 4-2 均線

均線這一寶的完成條件比較容易看得出來，但它是股市三寶中比較晚完成的指標。而K線這一寶比較早完成。45度線的完成時間介於兩者之間。不過因整理型態的不同，股市三寶出現的順序亦會不一樣。

# 均線的完成條件

均線上漲一寶：當K棒的收盤價突破5日或6日均線，且連續站穩三天以上，就可視為完成上漲一寶。

均線下跌一寶：當K棒的收盤價跌破5日或6日均線，且連續跌破三天以上，就可視為完成下跌一寶。
