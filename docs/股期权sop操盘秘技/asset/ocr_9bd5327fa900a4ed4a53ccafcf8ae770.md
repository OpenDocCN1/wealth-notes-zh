# 技術指標二次背離實例（RSI）

如圖（3-12）是期貨指數日線圖

RSI在高檔區做出二次以上背離

+   一、圖中①所示，3日RSI在高檔區做出第一次背離之後，指數拉回兩天。

+   二、圖中②所示，3日RSI在高檔區做出第二次背離之後，指數拉回兩天。

+   三、圖中③所示，3日RSI在高檔區做出第三次背離之後，指數拉回幅度較大。

RSI在低檔區做出二次背離

+   一、圖中④所示，3日RSI在低檔區做出第一次背離之後，指數反彈兩天。

+   二、圖中⑤所示，3日RSI在低檔區做出第二次背離之後，指數反彈幅度較大。

重點提示：

因此我們得到一個結論，技術指標無論是RSI、KD、MACD，若背離越多次其漲跌的幅度就越大。
