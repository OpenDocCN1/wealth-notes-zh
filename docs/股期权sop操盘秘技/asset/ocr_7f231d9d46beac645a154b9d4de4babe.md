# 心隨勢轉不預設立場

人們總是選擇自已所想的方向來走，當一心想做空時耳中所聽到的便只是空方的言論、眼裡所看到的也全是空方的消息，這便是「心隨意轉」，亦就是所謂的「我執」。就個人淺見應導正為「心隨勢轉」，亦即不預設立場，順著盤勢走，盤勢走空便做空，盤勢轉多便做多，相信修習過老師課程的股友們應該更能深刻體會「漲、跌、盤」的判斷及其應對操作的方法才是。

還是老話一句：找到適合自已的方法，才是走向成功的不二法門。這個社會有一天一定會從小m逐漸擴大變成大M，當貧富差距愈來愈大時，希望投資朋友們也能身在M型的頂端。也再次感謝老師與師母多年南北來回奔波，傳道、授業、解惑於浮沉股海的投資朋友們，也由衷地祝福老師與師母心安體健。

桃園學員 楊過
