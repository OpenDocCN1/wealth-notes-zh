# 洞燭機先 乘勝追擊

進入金融市場，能洞燭機先掌握正確的趨勢方向乘勝追擊。是人人所欲求之也是大家所期望的。

成功是可以複製的，股票市場永遠都是「漲、盤、跌」相同的步驟不斷的重演。因此要踏入金融市場，沒有僥倖、沒有速成。僥倖是偶而好運氣，只有充實技術基礎，反覆演練才能解讀股市密碼。

有人將股市比喻作賭場，即使要進入賭博，也要掌握有利的勝算條件，才能降低風險增加高勝率。這就要靠遵守股市「 SOP」才是明確獲利之道。

交易不是只有買賣，也是一門藝術。用心觀賞不斷的思索，紮實的技術分析功力。經歷實戰演練做好資金管控，保持去蕪存菁止於至善的心才能成功。

股市是平凡窮人翻身的機會，投機能夠致富最重要的原因，是要有一套精準的「 SOP」作準則判斷。

老師說過：樹的方向由風決定、人的方向由自己決定。努力不一定會成功而成功的人一定努力過。
