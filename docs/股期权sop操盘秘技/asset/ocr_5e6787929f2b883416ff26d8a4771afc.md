# 三線合一的完成條件

前一頁所提到的是三線合一的選股條件，在波段指標的四個條件中，三線合一也是其中一個重要的指標，其完成的條件與三線合一的選股口訣雷同，說明如下：

# 上漲波段指標，三線合一的完成條件

+   一、三線合一，且K棒跳空上漲或拉長紅或連續上漲，突破前一波的高點。

+   二、前面3～6個月成交量小。

# 下跌波段指標，三線合一的完成條件

+   一、三線合一，且K棒跳空下跌或拉長黑或連續下跌，跌破前一波的低點。

+   二、前面3～6個月成交量大。
