# 求人不如求己

以前做股票都是看報紙、電視，或聽朋友介紹，有時賺，有時賠。直到有一天在報紙看到陳霖老師舉辦新書發表會。那天剛好有空，就到高雄聽看看。

會中陳霖老師的一句話讓我聽进去了。就是「若不能打敗失敗，就會被失敗打敗」。當下我買了三本老師的著作。並決定靠自己的力量學習操作股票的成功方法。回家後看完老師的書，還是似懂非懂。可能是我從來都沒有學過技術分析，因此決定參加老師的课程。

# 按SOP操作，嘗到賺錢的滋味

在上課中才恍然大悟，學習操作股票是有成功的方法。那就是老師所精心設計的SOP。這本《股期權SOP操盤秘技》是老師把先前幾本著作的重點濃縮在一起。我按照SOP的步驟研判行情與選股，感覺愈做越順。開始嘗到賺錢的滋味。現在很多朋友都會向我問「明牌」。我告訴他們「求人不如求己」。建議他們趕快買書來看，最好再去參加老師的课程，這樣進步比較快。

最後我要謝謝老師的教導，因為現在我已不必為錢煩惱，更希望做股票的朋友都能賺大錢。

屏東學員 張小姐
