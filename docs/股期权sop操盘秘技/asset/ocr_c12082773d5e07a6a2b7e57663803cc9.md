# 大家一起來，團結力量大

如圖（9-15）瑞儀日線圖

+   一、圖中①所示，3日RSI高達95（準領先指標），且做出雙頭交叉向下（最佳指標）。股價自120元回檔到113.5元。

+   二、圖中②所示，RSI負乖離（開口）大於16以上（最佳指標）。股113.5元反彈到123元。

+   三、圖中③所示，RSI又出現負乖離16以上（最佳指標），股價自112.5元反彈到122元。

+   四、圖中④所示，RSI做出雙頭交叉向下（最佳指標），股價自122元再回檔到113.5元。

以上皆是出現一個或二個最佳指標，因此反彈或回檔幅度不大，僅能短線操作。若出現3～5個（領先指標與最佳指標）或完成波段指標的三個條件以上就可波段操作。

+   五、圖中⑤所示，長期上升趨勢線。圖中⑥所示，長黑跌破上升趨勢線，且均線做出三線合一向下。圖中⑦所示，成交量低於基本量（5日均量）連續三天以上，完成下跌波段指標的三個條件。因此形成下跌波段行情。股票自122元下跌到88.4元。

+   六、圖中⑧所示，RSI、KD做出二次背離（領先指標），MACD出現一次背離。圖中⑨所示，出現上漲缺口。連續來了四個包括（領先指標與最佳指標），因此股價自88.4元反彈到108元。
