# 選擇權SOP的應用（單一操作策略）買進賣權

前面的例子皆是做多的單一操作策略，現在筆者再舉個做空的單一操作策略給讀者參考。

首先仍然必須確定方向再考慮採取單一策略或是組合策略。

如圖（8-35）是大盤日線圖

+   一、圖中①所示，大盤在102年3月14日跌破長期上升趨勢線，且跌破45度線，且均線又做出三線合一下。圖中②所示，成交量亦低於基本量（5日均量）三天。研判可能產生下跌的波段行情，因此決定做空，選擇單一操作（買進賣權）。

+   二、在102年3月14日跌破長期上升趨勢線與跌破45度線的指數位置大約8000。因此選擇權8000的履約價（買進賣權）當時的權利金61點，如行情表（8-36）所示。

+   三、在102年3月20日（結算日）平倉。8000履約價的權利金205點。如行情表（8-37）所示，可獲利205點－61點＝144點，獲利2.3倍。

+   四、操作選擇權，若有獲利隨時可以平倉，不一定等到結算日再平倉。若無獲利也應該設定停損點。
