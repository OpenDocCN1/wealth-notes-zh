# 指數下降軌道線實例

如圖（3-7）是大盤指數的下降大軌道圖形

+   一、您會發現只要指數觸及到下降軌道的下沿，就會反彈，成功率很高。操作期貨指數的朋友，就可利用指數跌到下降軌道線的下沿出手短多，大約1～3天內就會反彈。

+   二、所謂大軌道是指其軌道寬度較大，小軌道的軌道寬度較小，下降大軌道的下沿不易被跌破，因此成功率較高。

+   三、下降小軌道下沿易被跌破，因此成功率較低，但也值得參考。

+   四、從圖（3-7）可看出指數在102年4月9日觸及軌道下沿後，開始反彈。

如圖（3-8）是期貨指數的下降小軌道圖形

+   一、小軌道的畫法通常都用夾心餅的畫線技巧規劃完成。

+   二、圖中可看出指數在101年10月26日觸及小軌道下沿後，開始反彈。

重點提示：

+   1. 大軌道通常是用A、B、C三點式的畫法。

+   2. 小軌道通常是用夾心餅式的畫法。
