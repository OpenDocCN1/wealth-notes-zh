# 7-1 何謂續航力道

SOP的「續航力道」是屬於第五個方塊。續航力道是研判指數或股價是否有波段行情。在我們開設的訓練課程中，很多學員認定只要用股市三寶判定是「漲勢」就有波段行情，其實並不盡然。

雖然利用股市三寶判定出漲勢也有機會形成波段行情，但失敗的例子也很多。為了提升判斷指數或股價續航力道（波段行情）的成功率，因此筆者才選出四個條件設定第三個方塊「波段指標」。

早期的手機或筆電因電池的續航力道不強，因使用沒多久就必須充電。現在新型的手機或筆電，電池的續航力道較強，當然使用的時間就較久。同理，若投資人能判定指數或股價的續航力道較強，就可採取波段操作，利潤較高。

波段指標的四個條件中，必須在短時間內完成三個條件以上其成功率最高。若僅完成一個或二個條件則成功率較低，這一點要特別注意。所謂短時間，就是3～5天或5～10天之內。
