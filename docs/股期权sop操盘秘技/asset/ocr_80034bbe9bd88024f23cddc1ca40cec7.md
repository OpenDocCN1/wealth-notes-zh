# ## 最佳指標的應用（美匯日圓）

筆者再以最佳指標應用在匯率的例子做說明，印證我們所篩選出的各種指標其可信度值得信賴。

# ### 美匯日圓的實例

如圖（9-11）美匯日圓的日線圖

+   一、 圖中①所示，RSI負乖離（開口）過大，高達（11－33）＝－22，出現RSI負臨界值的領先指標。日圓開始貶值自97日圓貶到103.74日圓。

+   二、 圖中②所示，RSI做出高爾夫球桿大約三天，且3日RSI高達97，符合95以上的「準領先指標」。接著均線做出三線合一向下。日圓開始回升，自103.74日圓升值到93.77日圓。

+   三、 圖中③所示，RSI與KD同時打出三個底，且做出一次背離之後，日圓又開始自93.77日圓回貶到101.55日圓。

除了美匯日圓可利用SOP或最佳指標操作之外，其它如歐元、黃金、石油、大宗物資…等，亦可如此操作。
