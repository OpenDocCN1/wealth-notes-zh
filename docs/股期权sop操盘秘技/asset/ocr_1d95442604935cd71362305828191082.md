# 股票權SOP 操盤祕技

讀者大人閱讀本書時，或許會覺得有些文字或指標，筆者一而再，再而三的重复撰寫。主因是筆者認為它具有相當的重要性，為了讓讀者能牢牢記住它的重要性，不得不多寫幾次，還請讀者大人多多包涵。

筆者曾閱讀佛教的一本重要經典「金剛經」，發現釋迦牟尼佛在金剛經裡不斷的重複對他的弟子須菩提強調「空性」的重要性，且重複提到「無我相，無人相，無眾生相，無壽者相」的文句。讓須菩提聽了之後，涕淚悲泣，並且說從來沒有聽過那麼好的經典，且證悟「空性」。須菩提在佛陀的弟子中被稱為「解空第一」，並證得阿羅漢果。

筆者只是芸芸眾生中的泛泛之輩，沒有佛陀那麼偉大。只是模仿參照金剛經的寫法，把比較重要的文字或指標，多寫幾次。讓讀者牢記在心，以便在股市大顯身手成功致富。

在技術班的訓練課程中，我最常重複講的一句話：「大家一起來，團結力量大」，它的意思是指：「很多指標在短時間內同時出現，其準確率最高。」，如領先指標的四個指標同時出現，幾乎可以買到最低點或賣到最高點。波段指標亦是如此，若四個條件一起出現，就有波段行情可期。
