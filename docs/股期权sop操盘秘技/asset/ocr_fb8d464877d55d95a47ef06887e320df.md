# 張序

![](bbox=[0.7, 0.05, 0.94, 0.11])

承陳霖兄就其所著《股期權SOP 操盤秘技》示下，並請 代為撰序，雖不勝惶恐，然亦頗感與有榮焉。

長久以來，追求財富是許多人努力不懈的夢想，尤其在 證券市場，散戶挖空心思、四處探索，無非想在證券市場求 得不敗秘技，能有良好操作績效，以改變生活品質，為自己 或家人創造更理想人生。然，多數人並無法如願以償，究其 主因，多數散戶用錯方法、無法以專業角度從事投資理財， 常成為主力、做手套利之魚肉。

陳霖兄以其多年股市與期貨、選擇權投資經驗，不吝藏 私，頃心血著成《股期權SOP 操盤秘技》一書，內容詳精， 對投資人有暮鼓晨鐘之效，如何有證券與衍生性金融商品投 資之操作準則，記載以供大用，實為不可多得之作，特以為 序，期有拋磚引玉之效，使台灣投資市場更趨健全。
