# SOP的操作順序

第二步（STEP-2）

轉折指標：亦是股市三寶，當領先指標過了之後，第二步就是看第二個方塊「股市三寶」，判定指數或股價處在漲、跌、盤的哪一個狀態？

+   一、若在下跌趨勢中，完成上漲一寶或二寶，代表指數由「跌」進入「盤」。亦代表指數或股價在短時間內不會跌破最近的低點。操作股票的朋友就可切入3成持股做多。操作期貨的朋友就可設定支撐壓力多空操作。操作選擇權的朋友就可操作多單，賣出賣權（Sell Put）賺取時間價值。

+   二、若在上漲趨勢中、完成下跌一寶或二寶，代表指數由「漲」進入「盤」。亦代表指數或股價在短時間內不會突破最近的高點。操作股票的朋友就要減碼應對。操作期貨的朋友仍可多空操作。操作選擇權的朋友可操作空單（賣出買權Sell Call）賺取時間價值。

+   三、若指數完成上漲三寶，由「盤」進入「漲」，就可加碼持股到5成以上。期指可順勢做多。選擇權可加碼買進買權（Buy Call）。

+   四、若指數完成下跌三寶，由「盤」進入「跌」，就應出清持股亦可券空。期指可順勢做空，選擇權可加碼買進賣權（Buy Put）。
