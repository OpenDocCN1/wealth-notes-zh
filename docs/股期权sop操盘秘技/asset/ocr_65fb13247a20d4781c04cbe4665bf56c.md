# 波段指標（完成下跌三個條件以上）的出手點

如圖（8-29）是期指日線圖

+   一、圖中①所示，長期上升趨勢線。所謂長期是指2～3個月以上。

+   二、圖中②所示，均線做出三線合一向下。

+   三、圖中③所示，成交量低於基本量（5日均量）連續三天以上。成交量可參考大盤現貨的成交量比較準。

+   四、圖中④所示，技術指標RSI做出三個小頭交叉向下。

+   五、從以上分析得知期指在101年10月8日完成下跌波段指標的四個條件，符合下跌的波段行情。

+   六、若採取放空波段操作，指數自7810下跌到7029。超過500點上。

**重點提示：**

+   1. 為何成交量要參考大盤的成交量比較準？

+   2. 因為期指的成交量在結算前有些已轉倉到遠月份期貨。因此當月份的成交量比較不準。
