# 1-3 SOP是股期權的避風港

影響股市漲跌的因素非常多。整體來看，有三大面向：基本面、技術面、消息面。其中影響層面最大的是消息面。但消息面不是我們所能夠學習的。筆者撰寫本書時剛好遇到大陸爆發H7N9禽流感，再加上兩北韓情勢緊張，這些都是屬於消息面，無法事先預知的。

而基本面是屬於落後指標，因為投資人無法取得上市、上櫃公司營運的第一手資料，若從報章雜誌所獲得的資料皆屬於二手資料。其可信度值得商榷。除非是大股東才有機會得到第一手資料，何況有些不肖公司會利用基本面利多宣佈時倒貨，不得不慎。

因此我們只能從技術面學起，但技術面亦不可能百分百。只能盡量提高操作的成功率，以賺多賠少的操作手法累積財富。至於研判行情或選股技巧，可採三步驟。筆者建議先看技術面，再查基本面，解讀消息面，如此面面俱到，就可大幅提高勝率。

由於技術面不可能百分百，因此我們才要建立SOP將勝率提高，風險降低。如果您還未建立自己的SOP，筆者強烈建議可參考本書所设立的SOP。如法炮製，必可大幅提高勝率，規避風險。
