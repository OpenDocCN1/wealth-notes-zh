# 上漲三寶的條件

如圖（4-5）是大盤日線圖

+   一、如圖中①所示，突破下降45度線，完成上漲第一寶，指數由「跌」進入「盤」。

+   二、圖中②所示，K線三天不創新低，且留下跳空向上的缺口。符合K線上漲一寶（四種狀態的其中二種）的條件，完成上漲第二寶，指數可視為「盤整趨漲」。

+   三、圖中③所示，K線站上5日均線三天以上，完成上漲第三寶，合計完成上漲三寶，指數由「盤」進入「漲」。

# 重點提示：

+   1. 當指數由「跌」進入「漲」，並不代表指數會形成上漲的波段行情，股市三寶只是負責判定漲、跌、盤的轉折點。

+   2. 若欲判定是否有上漲的波段行情，必須符合SOP第三個方塊「波段指標」的三個條件以上。

+   3. 波段指標在下一章會談到。
