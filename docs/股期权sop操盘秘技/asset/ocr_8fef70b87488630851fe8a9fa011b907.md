# 股票SOP的應用（領先指標技術指標KD二次背離）

筆者再舉一個技術指標二次背離以上的例子。以圖（8-11）台塑（1301）為例。它的KD指標做了三次背離。其中第二次背離反彈幅度較小。第三次背離反彈幅度較大。

# 領先指標（技術指標KD低檔三次背離）的出手點

如圖（8-11）是台塑日線圖

+   一、圖中①所示，KD指標K值在低檔區出現第一次背離。

+   二、圖中②所示，K值在低檔區出現第二次背離，可視為領先指標。股價自68.5元反彈到70.4元。此次反彈幅度較小。若手腳不夠快就會小虧。

+   三、圖中③所示，K值在低檔區出現第三次背離，亦可視為領先指標。股價自67.6元漲到72.7元。此次反彈幅度較大。

+   四、或許讀者會問：到底要在第二次背離出手，還是第三次背離再出手？

+   五、筆者認為，要看當時大盤的氣勢或個股的氣勢強弱而定。原則上越多次背離出手成功率較高。或是RSI、KD、MACD同時出現，此時出手成功率最高。亦是筆者在上課中一再強調的「大家一起來，團結力量大」。
