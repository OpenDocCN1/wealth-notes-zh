# 個股波段指標失敗的實例

上一頁國泰金完成下跌的波段指標四個條件之後，雖未形成下跌波段行情，但股價仍然自42.6元下跌到37.1 元，至少方向是做對的。

承接上一頁，筆者再舉國泰金完成上漲波段指標四個條件之後，雖然形成上漲波段行情，但漲幅還是不符合2〜3成的目標區。

如圖（7-7）是國泰金（2882）日線圖

+   一、圖中①所示，突破長期下降趨勢線。

+   二、圖中②所示，均線做出三線合一向上。

+   三、圖中③所示，成交量出現攻擊量。

+   四、圖中④所示，技術指標RSI、KD同時做出雙底交叉向上。

+   五、雖然完成上漲波段指標的四個條件，但股價自28.1元漲到33.1元僅上漲18%。漲幅不符合波段行情的2~3 成。不過也很接近2成。

重點提示：

+   1.筆者認為大型股或高價股，雖然完成波段指標的三個條件以上，但有時漲幅不會達到2~3成的目標區。

+   2.反而中小型股或低價股，較容易完成2~3成的目標區。
