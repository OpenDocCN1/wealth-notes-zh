# 期貨SOP的應用（領先指標負價乖離）

本書對於期貨的出手點著重在日線出手，至於分線如何出手就請讀者参閲《期權賺很大》書中的說明。

SOP的第一個方塊是「領先指標」其內容有四個：1.價乖離、2.軌道線、3.RSI臨界值、4.技術指標二次背離。當期貨指數出現上述四個內容的其中一個就可出手。若同時出現兩個以上，成功率更高，亦也本書提過多次的「大家一起來，團結力量大」。

# 領先指標（負價乖離）的出手點

+   一、如圖（8-17）是期貨指數日線圖，期貨指數價乖離的參數是5~6%，其算法與個股價乖離的算法一樣。

+   二、如圖中①所示，是6日均線位置7689。預估隔天負價乖離的位置7689×0.95=7304或7689×0.94=7227。圖中②所示，盤中最低7191比7227還低，但無反彈，因收盤僅7197。

+   三、如圖中③所示，第二天的6日均線7605。預估隔天負價乖離的位置7605×0.95=7224或7605×0.94=7148。圖中④所示，盤中最低7160剛好在負價乖離（7224~7148）之間，收盤7251。再隔一天反彈收紅大漲253點。敢搶短多就可獲利。

重點提示：

+   1. 先前提到出現領先指標時不一定馬上反應，有時會延續出現1~3天才反應。

+   2. 因此初學者可在第二天或第三天再出手成功率較高。
