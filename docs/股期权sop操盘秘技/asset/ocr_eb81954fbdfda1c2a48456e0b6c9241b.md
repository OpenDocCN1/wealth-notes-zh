# 放手才可逃走

筆者講一個猴子被逮的故事，分享停損的重要性。在國外很多農場易遭猴子偷食農作物。農場主人想出一個辦法。在樹上綁一顆椰子，椰子挖出一個小洞，此洞剛好猴子的手能伸進去。椰子裡面放了一些猴子喜歡吃的餌，當猴子看到椰子裡的誘餌不疑有詐，就伸手進去抓住誘餌，此時猴子的手已握拳伸不出來。主人看到猴子手伸不出來就一步一步的逼近猴子。猴子心想已經到手的食物豈能放手，還是拼命的想把手伸出來，但是還是伸不出來，終於被主人活逮。

試想只要猴子放手就可逃走，放開手中的食物就可逃離現場，可是猴子為了貪圖一份食物，終於被人逮住划不來。

# 放下才無罣礙

操作金融商品也是如此，要學會放下。學習捨得，佛家有云：「放下才會自在，有捨才會得有。」，大捨大得，小捨小得，不捨不得。

筆者有三句話與投資人共勉

+   - 有賺就跑→不貪：積小利成大利。
- 買了就跌→不懼：守紀律執行停損。
- 賣了就漲→不悔：祝它一路順風。
