# 掌握漲、跌、盤的轉折點，就可以贏在起跑點

福音：陳霖老師又出新書了。書名是《股期權SOP操盤秘技》，SOP就是：標準作業流程，操作股期權也不例外。簡單說就是如何在股期權市場操作成功且賺到錢。

股有量、價、勢，勢有漲、跌、盤。掌握漲、跌、盤的轉折點就可以贏在起跑點，當轉折點出現時，就是買賣點出現（要把握時間點切入）。

舉例最近操作的一檔股票做說明：勤美（1532）

+   一、從101年11月20日的最低點24.2元漲到102年5月31日的最高點47.8元，以黃金切割率算0.5的滿足點36.0元。

+   二、102年6月24日至6月25日出現小缺口，低點未到35.9元，跌幅滿足點到了。

+   三、週線7/5，3日RSI與6日RSI開口19（最佳指標出現），就開始試買、續買，此時設定停損點102年4月16日的低點34.7元。

+   四、7/8 RSI出現背離，MACD縮腳，盤中跌破35.9元，感覺會騙線嗎？

+   五、7/9拉長中紅，果然是騙線，出量，拉高到缺口上限。

+   六、7/25盤中3日RSI出現99，賣出三分之二持股（因為沒跌破5日均線）。
