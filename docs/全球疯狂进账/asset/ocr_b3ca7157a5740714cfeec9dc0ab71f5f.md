# 二、海洋教练是谁？

中国的金融平台太多了，但没有几个老师能把钱读懂读透，他做到了！！！来到的课程的人大多数都是负债的人，如果课程对大家没有用，那将是会激怒一帮穷凶极恶的穷鬼，谁敢这么牛？没有两把刷子，谁敢开这样的课程呢？但事实见证了他的能力与实力，负债几百万、几千万乃至上亿的企业主从哭着进课堂，到笑着离开，不仅解开了心结，而且拓宽了思路，找回了勇气、开启了智慧，并且在他的指导下走出债务的迷局！

他不是教授、他也不是老师、他更不是什么大师，他只是一个农民的儿子，身无分文来到深圳，摆过地摊、卖过甘蔗、干过直销，最后聚焦金融界，实战20多年，他的经历与天赋才华让他对金融的工具了如指掌，所以他很有经验！他是普通的人，但他有不同的经历、不同的格局、不同的智慧！他只是一个读懂钱的人！
