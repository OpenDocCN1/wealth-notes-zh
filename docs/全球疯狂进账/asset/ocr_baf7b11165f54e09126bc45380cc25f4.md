何为 NLP？ NLP 是神经语言程序学 (Neuro-Linguistic Programming) 的英文缩写。它起源于研究卓越人士成功的原因，然后把结果化成一套一套的技巧程序，使其它人也可以成为卓越人士。所以，NLP 的基础是"模仿"，不只是模仿他人，还模仿自己：去发现自己的大脑和身体如何工作，运用同一模式去使某些事的效果更好。NLP 有若干精髓，其中就有：

+   A、有效果比有道理更重要。
B、只有由感官经验塑造出来的世界，没有绝对的真实世界。
