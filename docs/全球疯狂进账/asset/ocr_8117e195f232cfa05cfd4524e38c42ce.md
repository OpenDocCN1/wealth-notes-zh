# 二、分论

1234 这个理论，其核心点就是要解决那三种人的三个问题，比如说小白想要有钱的，有钱想有更多钱的，或者是负债要翻转的，那么要解决这三类人的问题，最核心的就是要种福报的种子，因为财富是福报的显现，当福报满满时，财富会源源不断地来到你；如果你账上没有一定数额的资金，当你的融资有风吹草动时，你就会像鱼缸里没水的鱼一样扑腾甚至翻白眼，此时必须要有管道进水，方能化解危机！

经营性现金流，就是你得要有一个为你持续产生不断进账的渠道，或许是你的企业，或许是你其他的收入管道；融资性现金流，是你通过银行的信用与贷款从方方面面融来的钱，用融低息的钱，然后放到高回报的地方，产生的现金流叫融资性现金流；而资产增值性现金流是通过购买房产或其他增值的产品，能够带来增值的收入与回报就叫资产性现金流；而运作性现金流呢，就是通过了更多的渠道，运作你的资本，全方位进行优化配置而产生的收益，这一序列四个管道目的都是在于要无限
