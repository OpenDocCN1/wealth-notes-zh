# 3、具有离开问题的能力。

道法自然，你看自然界的河流都不是笔直向前的，而是蜿蜒曲折奔向大海的，这是因为河流在前进中，会遇到各种各样的障碍，有些障碍是无法逾越的，所以它只有绕道而行，也正因为走弯路，让它避开了一道道障碍，最终抵达了遥远、浩瀚的大海！面对债务问题同样如此，我们可以不与之硬碰硬地对抗、拉扯，我们可以开辟新的疆域，可以带着问题前行，在发展中解决问题，让进账成为我们的关注点，让进账成为我们的主旋律！就像我们每个人身上都有癌细胞，但只要我们正常细胞活跃并且免疫力正常的话，癌细胞是无法演变为癌症！负债就是癌细胞，只要保持不断的进账，就相当于维持正常的免疫力，那么负债就无法演变成债务危机！
