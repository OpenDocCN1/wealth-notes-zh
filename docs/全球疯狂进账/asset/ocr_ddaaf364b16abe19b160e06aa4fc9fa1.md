# 5、钱与自由

在所有的词汇中，我最喜欢的词就是自由，无论是身的自由，还是心的自由，都是我热切追求的东西。在追逐自由的过程当中，我走过弯路：曾以为，想自由就可以自由，但在现实生活中，当看到家人躺在病榻上受苦的时候，我是不自由的；当家里装点需要钱的时候，我是不自由的；当想买一份心仪的礼物送给爱人但囊中羞涩时，我是不自由的；当心里对家人有无数美好愿望想实现，但在时间、金钱都不许可时，我是不自由的；每当我有一些新的想法想在工作中去实施时，领导告诉我，你这样会影响业绩，我是不自由的；更不要说在不同的季节，我想去不同的地方领略不同的风土人情，迫于这份工作与收入，我是不自由的……
