# 6、你真正爱钱吗？

别以为这是个笑话，很多 人爱钱只是停留在嘴上，就像叶公好龙一样，当真龙出现时吓个半死，当钱真正来时，心里是排斥的。

为什么我们中国人会出现对金钱这种状态呢？首先是经济方面的因素。经济基础决定上层建筑：我国曾经历漫长封建制的农耕社会，其思维方式受经济模式的影响，在农业生产过程中，强调更多的是依赖天时与精耕细作，更容易把收成与财富理解为汗滴禾下土、粒粒皆辛苦的辛勤耕耘，如果财富的到来与此不同，人们会普遍质疑甚至反对，与此同时各种文学艺术作品都有意无意地贬低金钱，这样的观念会无形中渗透到每个中国人的骨子里。
