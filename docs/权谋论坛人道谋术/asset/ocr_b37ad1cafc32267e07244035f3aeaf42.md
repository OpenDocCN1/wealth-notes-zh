# 5. 资源整合的五大内涵

如果要更深刻地理解资源整合，还要知道它的五大内涵：

+   第一，资源整合是企业战略调整的手段，也是企业经营管 理的日常工作。

+   第二，资源整合就是要优化资源配置。

+   第三，资源整合就是要 有进有退、有取有舍、有合有分。

+   第四，在战略思维的层面上，资源整合是系统论的思维方 式。

+   第五，战术上，资源整合是活用资源，获得整体的最优。
