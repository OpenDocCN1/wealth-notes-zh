# 怎样才能对自己有一个正确地定位

# 为什么要对自己定位

+   1. 不定位就没有方向感、目标感

+   2. 可能某些地方在别人眼里你是成功的，但是你自己也觉得不是你所追求的。

# 如何对自己进行定位

+   1. 大至定位你想成为什么样的人：

建立自己的信念或者价值观，就是你认为什么样的事情值得你去追求的，你想成为什么样的人。所有的行为的驱动力都是来源于你的价值观；有了价值观，你所做的事情你都会有一种感觉值。
