这一讲, 我们要探讨另一个人生难题, 那就是「概率」。我们总是一个人孤独, 孤单寻找同伴, 我们就拿姻缘问题来举例, 跟你探讨一下, 这一类婚姻姻缘的概率。

姻缘, 是讲婚姻的缘分, 这个词本身就有「概率」的意思。

有句耳熟能详的话: 「千里姻缘一线牵, 所谓『千里姻缘』指的是距离很遥远的婚缘, 难到几率很低, 很多人认为「一线牵」的姻缘都是命中注定, 自己一定要从茫茫大海中, 找到那条天命或者真命天子。其实并非如此。

你认为这个世界真正适合你人的有多少呢?

还有谁人推想过结婚的人的朋友人的数量, 也有的「普适公式」, 这个计算是这样的:

+   1. 住在我附近的女性有多少? 假设有400万人吧。
2. 多少人年龄适合呢? 多20%, 那就是80万人吧。
3. 多少人是单身呢? 假设有一半吧, 还剩40万人。
4. 多少人有大学文凭? 假设是25%, 所以是104000人。
5. 中间又有多少人有人有魅力呢? 5%吧, 那么5000人。
6. 这些里面又有250人。
7. 那对我多上有人有可能和我合得来呢? 假如是10%, 那就还剩26个人。

这一看, 假设住在住区有1000万人的人口城市, 那么符合条件的女人, 一共也就只有26个, 要找到他有可能没机会遇到了。听完了你应不会对于爱情很绝望呢?

那我们应该怎么找到合适的人, 解决孤独难题呢?

我给你准备了五步心法, 每一步解决一个问题:

+   *   第一步, 教你如何找人;
*   第二步, 教你用什么心志去待人;
*   第三步, 教你何时停止寻找, 确认目标;
*   第四步, 如何判断一个人不适合长期相处;
*   第五步, 如何经营一段长久关系。
