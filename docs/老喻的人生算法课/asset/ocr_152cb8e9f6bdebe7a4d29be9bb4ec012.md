# 我们能改变命运吗

好，开火大脑的时刻到了，请问：

> 假如你现在可以搭乘一部时光穿梭机，改变你一生中任意一件事，你能否改变自己 的命运？

我的答案是否。

具体原因我们先放一放，想要深入理解这个问题，我们先做一个大实验：

一个欧洲城市按照统计规律，每年大约发生100起凶杀案。举个例子，如果我们可以坐时光穿梭机回到过去，提前找到这 100 个凶手，把他们关起来，会把这座城市的凶杀率降低到零吗？

听起来很好，但真正的结果也许很难如愿。

因为即使提前抓获了这100个疑凶，仍然会有其他地方产生新的犯罪。

近代统计学之父高斯曾在一篇论文中说：

> 是社会创造了罪恶，有罪的人仅仅是执行罪恶的工具，绞刑架上的牺牲者 从某种意义上说，是社会的牺牲品。

这个听起来哲学意味很浓，但它指明了一个真相，犯罪是一个复杂系统出现的现象，它是一个系统的产物。改变个体的选择，并不能让犯罪在整个社会上消失。

那岂不是，对城市的犯罪率没有办法了？也不是，是有办法的。但你要做的 不是控制 1-2 个犯罪者，而是探究本质原因，去改变整个社会的系统。

不仅仅是罪案这样，其他统计数据也是这样。2017 年想出租车事故是 3713 人，2016 年这个数字是 37451。为什么这两年数字如此接近，好像死神也有 KPI 一样，其实是因为车祸是一个系统的结果。

一片森林出现凶数、一些国家新生婴儿数，一个地区晴天的天数等等，这些重复出现的事件发生的次数，都会在 一个稳定的区间内波动。

改变任何一个选择，都没办法影响最终的结果。因为你 冥冥 中有大数定律这个东西，在决定一切。

在统计学里，大数定律是用来描述，随机事件多次重复发生，它结果是呈现长期的稳定性。比方，发生车祸是随机事件，但一个城市每年车祸数就相对稳定。

大数定律 的重要性就在于，它让我们意识到：当一些随机事件重复发生的时候，从整体来看，它会呈现长期的稳定。就是偶然之中包含着必然。

# 大数定律是怎么起作用的

大数定律 听起来似乎很简单，想明白的真 没多少人。

在统计学里，大数定律是用来描述很多 次重复实验的结果，重复次数越多，结果就 越趋近于平均值。
