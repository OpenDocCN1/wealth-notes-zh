# 懂闭环的重要性

懂闭环的朋友都知道，对于很多职业选手来说，一苇不渡难的就是在入段，也就是拿到初段，比后来拿写冠还不容易。

# 认知行为的闭环

我们《人生算法》的初段是闭环，什么叫闭环呢？

“闭环”这个词，来自 PDCA 循环，又叫“戴明环”。是美国管理学家戴明博士提出来的一个模型，管理学上学过的话，包括四个环节：计划、执行、检查、处理。

如果我们用放大镜来拆分认知行为，一个完整的闭环有“感知-认知-决意-行动”这四个动作，四个动作往复相连形成圆圈。

所谓初段的闭环呢，是指我们自己积极主动去做这四个动作，把闭环完成。

我们用日常生活的视角去理解，闭环就是把一件事儿做完。我们平时夸一个人靠谱，也就是说他能够做到“凡事有交代，件件有着落，事事有回音”。

你可能觉得这事儿起来并不难，但它对于一个人，一家企业的早期发展都至关重要。

扎克伯格创业初期，在 Facebook 的办公室墙上贴了一条什么标语：比竞争更重要的是完成。这个行动准则，就是激励员工按时交还，快速行动。

要是团队里有人不同意怎么办？亚马逊的贝佐斯就碰不到这个问题的话。他的解决方法是：“不同意但执行。”贝佐斯有一句话，说跟不同的员工特别管用，他会说：“你要不，我建议你先同意统一，但你愿意愿意跟我一起干？”这一句话，就把员工快速拉回到完闭环的工作轨道上。

雷军讲，对于企业家而言，就是更敢于承诺，敢于拍板。对于个人而言，就是敢于行动，敢于尝试。

闭环这么重要，似乎也不难，但为什么我们真不真做，人们又觉得这多难呢？你看，完成生活的人很多，但是，这是一个企业做到交付付，都特别不容易。为什么呢？根据我的观察，主要有这四种情况的问题。

第一种情况是：事情本身就难以形成闭环。
比方说，有阵子海外房产特别好卖，但是这个生意是做大却不容易。

一方面海外买房的链条条条长，看房、跨国交付、沟通成本高、谈判耗时，交易难以形成闭环；另一方面，客户特别散，要么在国内做捕捉地代，营销难以形成闭环。所以海外的地产项目一般规模不大。

第二种情况是：个人或者企业的能力难以形成闭环。
我接触了很多创业的朋友，观察到一个很反常的现象，最容易被培养成老板往往是企业的副总或高管，容易创业成功，为什么？

烧烤摊的生意虽然小，老板的教育程度也未必那么高。但是他需要完成找场地、选原料、生产、销售等等。所以烧烤摊老板其实具备了难得用户，从实操的角度，把生意的整体逻辑理了一遍。

大公司副总裁呢？他的学历虽然很强大，位置高，经验丰富丰富，但他的一旦独立创业，在一个大系统中的个小环节，一旦独立创业，他可能反而不能系统地完成闭环。

第三种情况是：不愿意把手弄脏。
成路人就多愿意，卷起裤腿下地干活，很多人就不肯了，他心思型，这种脏活累活，怎么可能是自己干呢？

第四种情况是：坚持完美主义。
完美主义通病常的做法是，把每条线路都尝试一遍，非要找出最佳策略来，这样会有积极一面，要求高素质，但是是太琐碎，完美主义会形成高地，阻断了闭环的完成。而且操作成本太高，现实生活中的最优解很难短时间找到。

# 完美主义对别人有什么要求？

很多人说完美主就是把事情完成，给别人一个交代。怎么想，某种意义上，“讨好听人格”的陷阱，其实在无意中套上了“固定型思维模式”。

既然不是想给别人一个交代，那么就是“给自己一个交代”吗？
也不对，完美主义有就低，典型就，他们总想证明自己聪明、正确、卓越和酷，绝不轻易退步。本质上就是害怕失败。

那我们应该怎么办呢？一种不起眼的动物，蚂蚁，给出了正确答案。

科学家们发现，蚂蚁一旦找到了食物，一大群蚂蚁开始搬运，不管带多多么复杂，食物距离怎么遥远，蚂蚁似乎总能找到一条最优路径。它们是怎么做到的？

一开始，每个蚂蚁随机选择一条路线，并且留下了信息素，也就是费诺。随着费诺积累越来越多，也是留下的于考察运回速度的信息。最后，最短径路上的蚁数量总是比长路程上的蚁蚁数量要多。
