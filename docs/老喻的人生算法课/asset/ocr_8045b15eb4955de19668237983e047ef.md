# 18 非理性：如何管住你的‘动物精神’

你好，我是老翰，欢迎来到我的课程《人生算法》。

前面三讲，我们讨论了在概率的视角下，我们应如何解决人生难题。

这一讲，我们开始一组新的问题：如何去完成决定、决策，行动这些关键的动作？这一讲我们先跟你探讨认知环节的关键：如何战胜非理性。

![](bbox=[0.0, 0.43, 1.0, 0.46])

让我们一起来做个实验：假设你现在要买耳机，有以下两个型号可选。你会挑哪一个？

一号耳机，价格是270元，在购物网站的10分评价制中，这个耳机的得分是6分。

二号耳机，价格是540元，价格整整是一号的两倍，在购物网站上得分是8分。

你会买哪个？

实验的结果是，大部分人选择了一号耳机。因为6分和8分差别不算太大，但价格差了一倍。在人们衡量取舍一点钟，会购买一个还过得去的东西，只有一小部分人，愿意花双倍的钱去买一个更好的耳机。

接下来，让我们稍微改变，再做另外一个类似的实验。

![](bbox=[0.0, 0.72, 1.0, 0.75])

请你从下面三个耳机里选一个：

一号耳机，价格是270元，在购物网站上得分是6分。

二号耳机，价格是540元，在购物网站上得分是8分。

三号耳机，价格是840元，在购物网站上得分是7分。

一号和二号没有任何变化，和刚才一样，只是增加了三号耳机。但是仔细看一看，这个三号耳机纯属是用来捣乱的，定价是840块钱，比二号耳机高出300块，但评分只有7分，选它要么就是买对了，要么就是买多了。

奇怪的事儿出现了，就是因为多了这个捣乱的三号耳机，尽管尽管有人选它，但人们另外两个耳机的选择却发生了翻天覆地的变化。
