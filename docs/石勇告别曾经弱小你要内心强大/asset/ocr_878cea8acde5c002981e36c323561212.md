# ◎“自我”的虚假

没有一个“自我”，人在心理上就活不下去。但是，如果他的“自我”并不是他自己，只是社会上的东西驻扎在自己心里的“代理人”，他就会和自己失去联系。

用“假自我”来维持自己心理生存的人从一开始就失去了防御能力。
