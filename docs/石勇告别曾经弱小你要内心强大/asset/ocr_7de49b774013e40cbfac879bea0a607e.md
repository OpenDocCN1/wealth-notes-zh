# 如果一个人已不复是当初的角色，那么，继续按那个角色演戏是愚蠢的

多年前，我曾经目睹过一位80后的好学青年，在表演中改变了命运。现在还原一下当时的情境，提炼出一些有用的规则。

我把这位好演员叫做“80后张”。他的师傅，我曾经和同事，我把它叫做“60后李”。

“80后张”当年进入我工作过的单位的时候，和“60后李”一个科室。后者是这个科室里的副主任，由于性格以及其他方面的原因，他一直得不到升迁。可以想象，这样的人会颇有烦言。
