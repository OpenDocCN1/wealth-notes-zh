# 心理弱小让一个人大踏步向“心奴”迈进

心理弱小的人，往往容易沦为中心奴隶。

“心奴”，即一个人心理上依赖他人的状态。

关键在于，谁是主人？谁是奴隶？

如果一个人心理弱小，那么，奴隶和主人就会变得模糊不清。

你可以不信邪，但确实无法不和这些打打交道。

心理弱小，是一个人走向奴性的起点。

# 一个人越恐惧，他求助的人在他心中越像上帝

一个心理弱小的人在陷入困境时，往往会将原因归结为他人的干扰破坏或自己的无能。

一个溺水的人之所以会死死地抓住他面前的任何一个漂浮物，是因为死亡的恐惧让他只剩下求生的本能。人在心理上也会这样。

多年前，一个旧识以祈求上帝般的态度打电话给我：“只要你能帮我把文章写好，我跪下喊你爹都行，求你了。”

那一刻，我被雷击了。我们强烈谴责那种要做别人父母的行为。

同样，被人尊称为“爹”的，在道德上是不应得的。

我静静地听着他的哭诉，脑海中闪过两个身影：一个是奥地利作家卡夫卡《变形记》的主人公格里高尔，他因工作失败而变成了大甲虫；另一个是俄国作家契诃夫《一个公务员之死》的主人公切尔维亚科夫，他因打喷嚏而导致了巨大的心理恐慌。
