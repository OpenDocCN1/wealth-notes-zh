# 两部门（Two-Sector）模型

+   - 两部门模型假设经济有两个部门：制造业（生产商品和服务）和“知识业”（生产“知识”）。
+   - 制造业的生产函数为
+   
+     $$Y_t = F(K_t, (1-u)L_tA_t),$$
+   
+     其中 $u$ 为知识业就业比例。
+   - 知识业的贡献是技术进步：
+   
+     $$\frac{\dot{A}_t}{A_t} = g(u),$$
+   
+     其中 $g(u)$ 刻画技术进步速度如何依赖知识业。
+   - 资本积累过程：
+   
+     $$\dot{K}_t = sY_t - \delta K_t.$$
