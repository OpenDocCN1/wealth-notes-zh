# 政府购买的乘数效应

+   - 假设消费函数为线性，
+     $$C(Y - T) = C_0 + C_1(Y - T),$$
+     其中 $C_0$ 为“自主消费”（autonomous consumption），$C_1$ 为“边际消费倾向”（marginal propensity consume, MPC）。
+   - 对以下方程应用隐含函数定理，
+     $$Y = C_0 + C_1(Y - T) + I + G.$$
+     可得
+     $$rac{\partial Y}{\partial G} = \frac{1}{1 - C_1} = \frac{1}{1 - MPC}.$$
+   - $\frac{1}{1 - MPC}$ 被称为政府购买乘数（government purchase multiplier）。
+   - 投资增加也有同样的乘数效应。
