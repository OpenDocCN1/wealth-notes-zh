# 流动性陷阱（Liquidity Trap）

+   - 流动性陷阱是指增加流动性（货币供应）无法降低利率的情况。
+     - 当 $L_1 \equiv \frac{\delta L(r,Y)}{\delta r} = \infty$ ， LM 曲线水平，同时 M 上升无法下移 LM 曲线。
+   - 流动性陷阱中，货币政策无效 $\left(\frac{dY}{dM}=0\right)$.
+     - 凯恩斯眼中，美国1932年所发生的流动性危机
+     - 日本90年代“失去的十年”
+   - 但财政政策在流动性陷阱中有效:
+     $\frac{dY}{dG}=\frac{1}{1-C'}$ and $\frac{dY}{dT}=-\frac{C'}{1-C'}$.
