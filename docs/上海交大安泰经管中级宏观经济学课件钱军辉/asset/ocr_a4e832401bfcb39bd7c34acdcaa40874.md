# 结构模型

+   - 国债供需模型是一个结构模型（Structural model）。
+     - 先验假设（即“结构”）：供给曲线和需求曲线，均衡
+       $$Y^s=f(P,X^s)$$
+       $$Y^d=g(P,X^d)$$
+       $$Y^s=Y^d$$
+     - 该模型刻画了内生变量和外生变量之间的因果关系。
+   - 此类建模思路被称为“结构建模”（Structural approach）。

+   - $P$：债券价格
+   - $Y^s$：供给
+   - $X^s$：供给侧外生变量
+   - $Y^d$：需求
+   - $X^d$：需求侧外生变量
