# 货币

+   - 货币是随时可用于交易的资产。
+   - 货币的基本功能:
+     - 储值（Store of value）
+     - 计量单位（Unit of account）
+     - 交易媒介（Medium of exchange）
+   - 货币种类:
+     - 商品货币（Commodity money）
+     - 法定货币（Fiat money）
+       - 数字货币（Digital money）
+   - 货币形态
+     - 纸币和硬币（physical cash, coin）
+     - 银行存款（bank deposits）
+     - 储备（reserves）
+     - 其他
