# 推导

+   - 让 $p_t = \log(P_t)$. 于是 $\pi_t = p_t - p_{t-1}$. 重写线性AS方程为
+   
+     $p_t = E p_t + \phi(Y_t - \bar{Y}) + v_t$
+   
+     其中 $v_t$ 为新加入的价格冲击。
+   - 方程两边减去 $p_{t-1}$ 得到
+   
+     $\pi_t = E \pi_t + \phi(Y_t - \bar{Y}) + v_t$.
+   - 用 Okun’s law, $(Y_t - \bar{Y}) = -\gamma(u_t - u^n)$, 得到
+   
+     $\pi_t = E \pi_t - \alpha(u_t - u^n) + v_t$, with $\alpha = \phi\gamma$.
