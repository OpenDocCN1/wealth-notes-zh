# 一阶条件

+   - 关于K的一阶条件：
+   
+     $$F_1(K,L) = \frac{R}{P}.$$ 
+   
+     - $F_1 \equiv \frac{\partial F}{\partial K}$ 为 “边际资本产出”（Marginal product of capital, MPK）。
+   - 关于L的一阶条件：
+   
+     $$F_2(K,L) = \frac{W}{P}.$$ 
+   
+     - $F_2 \equiv \frac{\partial F}{\partial L}$ 为 “边际劳动产出”（Marginal product of labor, MPL）。
