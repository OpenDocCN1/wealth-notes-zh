# 一个例子

+   - 假设 $n = 0, \delta = 0.1, f(k) = k^{1/2}$。解稳态方程
+     $s k^{*1/2} = 0.1 k^*,$
+     得 $k^*(s) = 100 s^2$.
+   - 假如 $s = 0.3$，我们有
+     $k^* = 9.$
+   - 黄金律水平满足：
+     $\frac{1}{2} k_{gold}^{-1/2} = 0.1,$
+     于是 $k^*_{gold}=25.$
+   - 关于黄金律水平对应的储蓄率，解 $100 s_{gold}^2 = 25$，得
+     $s_{gold} = 0.5.$
