# 有效个体生产函数

+   • 让 $y = \frac{Y}{AL}$, $k = \frac{K}{AL}$。$y$ 是有效人均产出（output per effective worker） $k$ 是有效人均资本存量。我们有
+   $$y = \frac{\hat{Y}}{AL} = \frac{F(K, AL)}{AL} = F(k, 1).$$
+   定义 $f(k) \equiv F(k, 1)$，上式重写为
+   $$y = f(k).$$

+   • 我们称 $f(k)$ 为有效个体生产函数（*effective individual production function*）。我们假设：
+   $$f(0) = 0,\ f'(k) > 0,\ f''(k) < 0.$$
+   以及
+   $$\lim_{k \to 0} f'(k) = \infty,\ \lim_{k \to \infty} f'(k) = 0$$
