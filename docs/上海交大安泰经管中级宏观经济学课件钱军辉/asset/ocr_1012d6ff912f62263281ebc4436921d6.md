# 政策分析

+   - 固定 $P$，对 IS-LM 全微分可得
+     $$(1 - C')dY - I' dr = dG - C' dT$$
+     $$PL_2 dY + PL_1 dr = dM$$
+   - 全微分将关于 $Y$ 和 $r$ 的非线性方程转化为关于 $dY$ 和 $dr$ 的线性方程。
+   - 应用克雷默法则（Cramer's rule）可分析
+     - 增加政府消费的效应: $\frac{dY}{dG}$ and $\frac{dr}{dG}$
+     - 加税的效应: $\frac{dY}{dT}$ and $\frac{dr}{dT}$
+     - 货币扩张的效应: $\frac{dY}{dM}$ and $\frac{dr}{dM}$.
