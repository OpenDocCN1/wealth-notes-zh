# 索罗模型 II

+   - 第一个索罗模型无法解释人均收入和产出的持续增长。
+   - 第二个索罗模型引入**技术进步**，用以解释**持续增长**。
+   - 我们假设：
+     - 封闭经济（$X=0$），最小政府（$G=0$）。
+     - 劳动增强的生产函数，$Y_t=F(K_t,A_tL_t)$，其中
+       - $F$ 规模效益不变
+       - $A_t=A_0e^{gt}$ 为技术水平，增长速度为常数 $g$。
+       - $L_t=L_0e^{nt}$ 为人口，增长速度为常数 $n$。
+     - 储蓄率为常数，$S=sY$。
+     - 资本折旧率为 $δ$。
