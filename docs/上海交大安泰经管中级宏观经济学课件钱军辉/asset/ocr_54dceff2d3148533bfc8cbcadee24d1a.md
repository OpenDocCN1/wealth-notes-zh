# 资本积累

+   - 我们假设：
+     \dot{K}_t = sF(K_t, A_t L_t) - \delta K_t
+     \dot{L}_t = n L_t
+     \dot{A}_t = g A_t

+   - 于是 $k_t$ 的变化如此刻画：
+     \dot{k}_t \equiv \frac{d}{dt}\left(\frac{K_t}{A_t L_t}\right) = \frac{\dot{K}_t}{A_t L_t} - \frac{K_t \dot{L}_t}{A_t L_t^2} - \frac{K_t \dot{A}_t}{L_t A_t^2}
+     = s f(k_t) - (\delta + n + g) k_t.
