# IS 方程

+   - 我们考虑如下 IS 方程
+   
+     $$y_t = \bar{y} - \alpha(r_t - \rho) + u_t,$$
+   
+     其中 $y_t = \log(Y_t)$, $\bar{y} = \log(\bar{Y})$, $r_t$ 为实际利率, $u_t$ 为需求侧冲击, $\alpha$ 为常数（利率变化如何影响总需求），$\rho$ 为自然利率（natural rate of interest）。
+   - 实际利率 $r_t$ 设置为事前实际利率,
+   
+     $$r_t = i_t - E_t\pi_{t+1},$$
+   
+     其中 $i_t$ 为名义利率，$E_t\pi_{t+1}$ 为 $t$ 时刻对下一期通胀率的预期。
