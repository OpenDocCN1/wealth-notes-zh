# 货币政策规则

+   - 我们假设央行采用如下货币政策规则（monetary policy rule），
+     $i_t = \pi_t + \rho + \theta_\pi(\pi_t - \pi^*) + \theta_y(y_t - \bar{y})$
+     其中 $\pi^*$ 为通胀目标, $\theta_\pi$ 和 $\theta_y$ 分别刻画政策利率如何应对通胀和产出变化。
+   - 刻画美联储的泰勒规则（Taylor’s rule）为
+     federal fund rate = inflation + 2 +0.5(inflation − 2) + 0.5(GDP gap)
+   - 该规则体现了货币政策的双目标:
+     - 通胀
+     - 就业
