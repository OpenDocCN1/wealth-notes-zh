# 论证2：粘性价格和异质性公司

+   - 假设有两种类型的公司
+     - 价格灵活类，其价格设定遵循
+       $P_f = P + \gamma(Y - \bar{Y})$.
+     - 价格粘滞类，其价格设定为预期价格
+       $P_s = E P$.
+   - 假设 $s$ 价格粘滞类占比。于是总体价格水平为
+     $P = s P_s + (1 - s) P_f =$
+     $s E P + (1 - s)(P + \gamma(Y - \bar{Y}))$.
+   从中可得
+     $P = E P + \frac{(1 - s)\gamma}{s} (Y - \bar{Y})$.
