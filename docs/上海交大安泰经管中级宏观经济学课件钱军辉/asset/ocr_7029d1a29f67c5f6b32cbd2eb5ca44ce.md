# 储蓄的影响

+   - 稳态方程如下：
+     $$ s f(k^*) = (\delta + n) k^*.$$ 
+   - 用隐含函数定理可得
+     $$ \frac{\partial k^*}{\partial s} = - \frac{ f(k^*) }{ s f'(k^*) - (\delta + n) }.$$ 
+   - 因为 $\lim_{k \to 0} f'(k) = \infty$, $\lim_{k \to \infty} f'(k) = 0$, 曲线 $s f(k)$ 与斜线 $(\delta + n)k$ 在 $k = k^*$ 处相交，所以
+     $$ s f'(k^*) < \delta + n.$$ 
+   - 因此高储蓄率对应更高的人均资本存量和产出。
