# “拒绝”的六项基本技巧

# ✦ 技巧 1 暗中留下 YES 的余地

面对对方的要求时，断然地说“办不到”是需要勇气的。像我们身为律师的人，向人说“NO”是我们的工作，说起来并没有什么困难，但平常不习惯拒绝别人的人，要他们说“NO”，心里应该相当挣扎吧！

因此，为了不要给人全面否定要求的印象，必须懂得使用说“NO”的方法。也就是说，暗中传递并非全面的否定，同时留有肯定的余地。这里有两种模式，说明如下：

① 时间分割法：“现在不行，不过改天的话……”

这种方法是将时间分割为现在和未来。如此一来就可以说，“以目前的状况而言没有办法”，从而加以拒绝。由于留有未来可能“YES”的余地，对方便很难对你抱有完全否定他的印象。

或者也可以说，“如果无论如何都要我现在立刻回答的话，我办不到”。这么一来会留给对方这样一个印象，“现在虽然说不行，那是因为目前的阶段，条件还不成熟的缘故，日后条件成熟就会答应了”，让对方感到将来的可能性。

如果采取这种拒绝方式，对方可能会说，“那么什么时候可以？”步步进逼。
