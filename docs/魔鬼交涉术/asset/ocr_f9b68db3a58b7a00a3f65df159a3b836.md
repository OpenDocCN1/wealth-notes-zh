# 满足对方的自尊：明褒实贬法

若有一个下属，在工作中老是长时间打电话，却始终找不到讲话重点，让你觉得很无奈。但如果你突然对他说：“你的电话每次都讲那么久。如果你讲话有点儿要领的话，很快就能把它处理完的。”你的下属可能会反驳你，说出“我当然有我的考量啊！向对方亲切地说明有什么不对！”之类的话。

让我们来想一个不会制造情绪对立，又能迫使对方改变行动的方法吧。

会让人开口反驳，主要是自尊心作祟。人类这种生物，永远相信自己不会有错，而且希望别人给予自己良好的评价。如果突然被指责“你电话总是讲得又臭又长”，这不只是被批评行动错误，还能感受到对方给自己的评价是“不具有掌握要领、清楚说明的能力”，于是便觉得自尊心受伤。其实与其说这是为了保护自尊心而展开反驳，不如说是抗议对方的观点，认为对方错了、自己是对的。

+   ◇先掌控对方的“自尊心”

这里有一个解决的对策。

只要先称赞对方的行动是正确的就好了。这样一来，便可以对方的自尊心得到满足。即使接下来要求对方改变作法，对方也不至于认为是否到了批判。
