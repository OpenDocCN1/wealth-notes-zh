# 摸清对方底细

# ◇ 交涉前须彻底调查

交涉之前，针对即将交涉的一切事项进行彻底的调查是非常重要的。

举例而言，如果想要卖出一套系统，首先要通过公司简介、网页、杂志报道等渠道调查预备出售的目标公司的历史、概要、组织、员工人数、公司文化、评价，等等。如果有朋友在这家公司就职，可以托这个朋友事前调查公司内的系统或架构，一切就绪之后，再去和这家公司会谈。

由于这个时候尚未进行正式的交涉，因此可以说些类似“我一定可以提出对贵公司有利的提案，请务必给我一个机会”这类的话，争取会谈的机会。

届时再尽量详细地收集这家公司目前使用的系统的内容、满意的部分、不满意的部分、今后有可能不满意的部分、希望能改良的部分、工作的流程、日后事业的发展、采购的关键人物等相关情报。

在这个时候，还不能将系统卖给这家公司。因为之所以要进行这些调查，仅仅是为了制作交涉的脚本而已。
