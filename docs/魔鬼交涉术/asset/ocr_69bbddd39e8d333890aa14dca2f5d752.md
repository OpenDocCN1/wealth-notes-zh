对于电话讲很久的下属，可以先对他说：“你和客户讲电话的时候，可以借闲话家常来消除紧张，解释的时候也花了很多人时间仔细说明，我一直觉得这点非常好。”

接下来再找机会让他改变做法。如果刚称赞别人就马上要他做出改变，这样给人的感觉会很奇怪，所以最好还是等待一会儿。

“本年度 的优先课题是让业务效率化。以往你在电话上会很仔细地向客户解释，但今年希望你只花以往一半的时间就能把事情讲完。我相信即使是在这么短的时间里，你应该也能够跟以往一样让客户感到满意。”

这样说的话，并不会伤到他的自尊心。这番话只是让他认为自己以前的做法没有错，但为了配合公司的状况，必须做出变更。

做出变更之后，还要再给予一次优良的评价。“我刚刚听到你讲电话，觉得你的说明很有效率。以后也照这个样子，朝着业务效率化的目标努力吧。”

如此一来，对方会以有效率的说明作为努力目标了。

这里有三个重点：

+   ①对对方之前的作法予以“正确”的评价。

+   ②以与之前的做法成效无关的理由迫使对方变更作法。

+   ③在对方变更做法之后，给予更好的评价。

这么一来，就可以在不发生冲突的情况下，让别人改变行动了。
