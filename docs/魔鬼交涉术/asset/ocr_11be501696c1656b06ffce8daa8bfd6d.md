# "颅内控制"感性→理性

我们的大脑可以分为左脑和右脑。据说右脑掌控感觉，左脑分管理性。

在第一章曾经提过，交涉时必须将感性和理性分开思考。我们必须先动之以情，之后再说之以理，让对方可以判断究竟这么做是不是正确的，是不是合理的。必须先让对方释放出愤怒之类的感情。

因此，在设定交涉策略的时候，必须采取感性→理性这样的组合。

当对方怀着愤怒的情绪时，绝对不能突兀地采取理论性的说明。必须先让对方释放情绪才可以，而且必须先包容这种愤怒的情绪。然后，再针对对方愤怒的原因是什么，看他究竟愤怒得有没有道理，从而制作出可以令对方理性思考的交涉脚本。
