# “狐假虎威”威胁法

在交涉的时候，威胁是一种非常有效的手段。它是一种能驱使别人行动的动力，有追求“奖赏”和避免“惩罚”两种。如果想获得金钱、名誉或自尊心的满足，人们会因为贪图奖赏而行动。而为了逃避恐惧的威胁，人们也会拼力行动。

黑道之所以擅长交涉，是因为他们利用暴力这种“恐怖”做为背景来展开交涉。“如果拒绝他们的要求，不知道会对我施加什么样的暴力。”因为有这种恐怖的阴影，对于对方的要求只好心不甘情不愿地一一接受。

既然恐惧感对驱使别人行动这么具有影响力，当然要好好地加以利用。

“咦？气势都已经比不上人家了，怎么可能还去威胁别人啊？”放心吧。就算不像黑道那样威胁别人，也可以对别人进行一定的胁迫。这样的技巧，即使是老实人也可以运用自如。
