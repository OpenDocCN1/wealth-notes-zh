# 活用脑部控制

这种方法也可以应用在邀约上。比方说，面对一个刚认识不久的对象，心血来潮想邀约对方，但却很有可能会被拒绝，这时候如果问对方“这个礼拜六一起吃饭吧？”

对方很可能会想，“要不要和你这个人一起吃饭？”如此一来，对方或许会告诉你，“我刚好有事。”对你加以拒绝。

在这种情况下，就可以使用脑部控制。如果对方喜欢吃意大利面的话：

> 你：“你知道吗？有个意大利的知名厨师，在银座开了一家意大利面餐厅。”
对方：“咦？不知道耶，在哪里？我好想去。”
你：“我上次和朋友去过，真的是太棒了。”
对方：“什么店名？”
你：“店名我忘了，这样好了，这礼拜六一起去吃吧？”

如果采用这种邀约方式，成功的几率应该会提升不少吧？

为了说服对方，脑部控制可以运用在各种场合之中。不过顺序十分重要，开始要说一些可以打动对方感情的话，等到对方动心之后，就可以切入主题了。
