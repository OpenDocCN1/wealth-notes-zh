# 别人说什么马上就相信的“儿童”型

这种类型的人，别人说什么都会立刻相信。当然，以人格而言，这样是非常光明磊落的。但是，在交涉中会往往出现各种虚虚实实的招式，谎言和夸大其词更是家常便饭。如果说什么都立刻相信，这样就会被对方视为“容易应付的人”、“容易控制的人”。

渡边先生就属于这种类型。渡边先生同样为了原料高涨导致进货成本大幅提高，不得不去和客户进行提价交涉。

渡边：“今天是为了涨价的事情来拜访你。”

客户：“唉呀，真是抱歉啊。老实说，我前阵子才见过贵公司以外的厂商。他们提出的价格很便宜哦。”

渡边：“咦？真的吗？可是，贵公司和我们公司已经往来很久了，应该不会想要更换厂商吧？”

客户：“我们公司的处境也很艰难啊。如果贵公司的产品涨价的话，我们也只好重新考虑以后是否继续交易了。总之，这个月还是会跟你们下单，不过下个月就不知道了。”

渡边：“请……请等一下。我明白了。既然已经和贵公司往来这么久了，以后也以这个价格交易好了！”
