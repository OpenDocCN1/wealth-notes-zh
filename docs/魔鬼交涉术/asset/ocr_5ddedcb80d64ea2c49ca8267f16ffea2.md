# # 建立在人性之上的交涉术

“一直着重于技巧，对人类的本性却存在误解！”

我终于觉醒了。

以前我一直认为，只要谈话的内容正确，别人就会照着去做。因此，只要自己的道理可以说服别人，即使不用注意对方的情绪，也能加以说服。

然而，实际 上人是感情的动物。在做任何决定的时候，人们会因为感情上认为“要这样决定”，并借由论述将自己的行为合理化，进行做出决定，并非一开始就是凭借理性来做出决定的。因此，要说服一个人，与其先以理性打动他，不如先动之以情。

察觉到这一点时，我的脑海浮现出伊索寓言中《酸葡萄》的故事，相信你也曾听过这个故事。

有一只狐狸想要摘取垂在葡萄树上的葡萄来吃。可是再怎么尝试，都摘不到，最后它只好死了这条心，离开葡萄树。临走时它说：“反正那个葡萄是酸的。”

这不是和我们日常的很多行为如出一辙吗？
