# 制造间隔的交涉法

面对你说一句，他便可以顶十句的对方，交涉往往会陷入苦战状态。在这种情况下，最好的作战策略是设法制造一些间隔。

第一个方法，就是先试着制造间隔，也就是制造休息时间。

“请让我休息一下。”

“我刚刚接到紧急电话，请同意我回一通电话。”

“可不可以借用一下洗手间？”

借由以上各种说法，腾出时间。

特别是当对方以“请立刻签名”或是“如果现在不立刻决定的话，这些内容就不成立了”之类的方式来强迫你的时候，更要格外注意。一定要趁休息时间的空档，让自己冷静下来才行。并且仔细考虑一下，“如果现在不立刻回答，对方真的会当场决裂吗？”绝对不能草率地立刻回答。很多人被迫使要立刻做出回复时，通常都会不假思索地回答“YES”。
