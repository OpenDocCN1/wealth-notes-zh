# 不再是以前的我

就在这一时期，我接到一起继承方面的案子。由于父亲死亡，母亲和女儿因为财产继承权而起了争执，我担任女儿这一方的律师。和对方达成“在遗产税申告期期满之前必须要有结果”的共识之后，针对如何分配不动产和现金、存款展开了交涉。

然而，一直到最后关头，双方都没有让步。时间到了交涉的最后期限，也就是遗产税申告期限的前一天。再拖下去就会超期，因此必须设法让双方达成共识才行。

对方方面对我提出了责难：“申告期限已经到了吧？身为女儿的，不要一直耍赖，快点取得共识不是很好吗？律师可以不遵守申告期限吗？”

“我……我知道了。那我就让一步吧！”

如果是小时候那个懦弱的我，一定会这么说，以使交涉得以解决，并且会提出“这也是没有办法的事啊。如果这时候不让步的话，谈判就会破裂，后果反而会更惨”一类的辩解。然而，我已经不是以前的我了。

“你这么说想侮辱我吗？身为妈妈的人，你让一步不就好了？现在期限就要到了。我已经提出最后的提案了。你究竟是要接受这个提案，还是要让谈判决裂，请你选择。如果决裂的话，责任都在你身上。”
