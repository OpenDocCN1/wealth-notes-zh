# 究竟询问法

有时候交涉可能会花费很长的时间。在争论点很多的交涉中，必须讨论的对象也会有诸多分歧，谈论的内容也会相当广泛。

如果进行这样的交涉，经常会在不知不觉之间，朝着和原本目的不太相关的方向而拼命努力。而且，因为当事人可能太过投入，完全注意不到这件事，结果在这些细枝末节上耗尽了时间。

如果发现脑子已经一片混乱了，就必须重新回到交涉原本的目的上才行。这时候，你可以询问自己以下的问题。

+   1. 究竟这场交涉是基于什么目的而进行的？

+   2. 究竟在这场交涉中，重要的是什么？不重要的是什么？

+   3. 究竟在这场交涉中，对我有利的点是什么？不利的点是什么？

+   4. 究竟在这场交涉中，如果交涉决裂，我有几个其他货源？做出妥协和转向其他货源，究竟怎样比较有利？

借由以上这些问题的自问自答，可以在脑海中整理一下目前的状况。而目前拼命争论的争议点，在自己交涉的任务中究竟占什么样的位置、具有何种程度的重要性，就可以一目了然了。

这时候，请以冷静的态度重新展开交涉。
