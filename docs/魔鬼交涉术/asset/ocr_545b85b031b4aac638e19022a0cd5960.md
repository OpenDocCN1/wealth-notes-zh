# 哈佛交涉术

然而，在我将哈佛交涉术运用于辩护的实战中时，却经常会 出现无法适用的状况。

“真是太奇怪了。应该很顺利才对吧……”

其实这也是必然的。律师的工作，是在解决纷争之时扮演一方的代理人。比方说，在争吵不停的夫妻离婚官司中，代替一方的当事人 和对方展开交涉。在这样的场面中，由于对方已经感情用事、完全 无法理性思考了，即使有效运用哈佛交涉术，也很难发挥作用。

追根究底，**哈佛交涉术必须在对方处于理性的状态时才有效**。 在当事人处于杀气腾腾的战斗态势时，则根本不是使用哈佛交涉术 的好时机。

“懦弱也不行，太强势也不行，哈佛交涉术也不管用，究竟该 怎么做才好呢？”

我再次感觉到一股强烈的无力感。
