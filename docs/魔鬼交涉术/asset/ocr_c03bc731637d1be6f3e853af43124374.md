# ◇ 有了替代手段，就能轻松面对交涉

所谓的交涉，目的在于获得自身的最大利益。因此，如果能够让对方让一步就尽量不让步。要想做到这一点，必须有替代的手段才行。

以刚刚的交易为例，在知道除了 A 公司之外，没有其他原料供应来源的状况下，首先必须倾其全力寻找替代手段，再与 A 公司展开交涉。或者是这次就放弃这批原料，把心力专注在其他的业务上。如若不然，就会被撕掉退路，陷入不得不交涉的局面。

当然，是否有替代手段的确相当重要，但对对方而言亦是如此。以刚刚的例子而言，如果这家公司是 A 公司的大客户，一旦 A 公司无法接到这张订单，立刻就会陷入资金周转困难从而破产的状况，那么，A 公司就不得不让步降价了。不过，如果除了这家公司之外，A 公司还有其他的买主，那么 A 公司就能游刃有余，而不会有所退让。

从以上的例子可以看出，在决裂的时候是否有替代手段，对决胜负确实具有莫大的影响力。因此，应该采取确保本身备有替代手段，同时破坏对方的替代手段这种战略。至于该如何破坏对方的替代手段，方法相当之多，比如可以约定在一定的期间之内，只能和自己的公司进行交涉，从而独占交涉权，等等。
