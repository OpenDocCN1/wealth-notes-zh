# 容易感情用事的 “公子哥” 型

感情丰富的人，相比其他人，可以感受到加倍的幸福与喜悦。这种人的人生往往波澜起伏。

可是，商业行为的目的是要增加利益。究竟能不能获利，必须进行冷静的计算。因此，从事商业行为时，必须理性行事。

然而，感情丰富的人即便在从事商业行为时，也会以 “喜欢”、“讨厌”、“快乐”、“悲伤” 等感情来判断事情的倾向。

属于这种类型的吉冈先生，同样为了商品涨价的事情和客户展开交涉。

吉冈：“今天是为了涨价的事情来拜访你。”

客户：“真伤脑筋。你们不会是在欺负我们公司吧？”

吉冈：“没有这回事。你这么说真的让我太意外了。”

客户：“话是这么说没错，但是我们也很难熬呢。”

吉冈：“我们才难熬吧？都已经生意往来这么久了，你讲话还要这么刻薄，让我很伤脑筋呢。”

客户：“刻薄的应该是你们才对吧？一下子要涨 10%，未免也太过分了吧。如果是 5% 的话还可以考虑。”

吉冈：“我并没有刻薄，只是很难过而已。今天就先告辞了！”（啊！烦死了！这家伙真讨人厌，我以后再也不想来了！）
