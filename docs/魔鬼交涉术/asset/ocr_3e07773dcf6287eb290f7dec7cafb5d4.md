# 拒绝变 OK：正向应对术

人们基本上都是讨厌被强迫的。即使对方有所要求，也想由自己决定如何回应或满足对方的要求。如果由旁人强迫式地帮自己作主的话，自尊心便会出现反弹的情形。因此，从事推销工作的人，无论再怎么努力，还是难免会遇到被拒绝的情况。

现在以推销员为例，介绍一个如何逆转拒绝的秘诀。

+   逆转拒绝的“正向应对说话术”

首先，必须让自己的心态一直维持在正向。无论对方怎么拒绝，也要朝对方“有购买意愿”的方向思考。

你可能会觉得，“既然人家都说不需要了，再怎么说都没有意义”，对吧？但事实并非如此。实际上，对方是“有购买意愿”的。

> 客人：“我没有预算。”
→“其实我是很想买的，只是预算不够。如果价格能让我感到满意，或许我可以拔出预算。”
客人：“我没有需要。”
→“我虽然清楚这是个好东西，但是你要证明这个东西能带来多少好处。如果能让我感到满意，我就会买。”
客人：“我没有决定权。”
