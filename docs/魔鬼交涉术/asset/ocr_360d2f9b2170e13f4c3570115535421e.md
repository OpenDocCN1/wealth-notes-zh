# 头脑风暴

调查完毕之后，接下来就是心理准备了。不管对方说什么，必须让自己觉得这是“设定范围内”的内容。

为了达到这个目的，先进行头脑风暴吧。头脑风暴虽然一般用在企划会议上，但用于交涉也十分可行。

交涉的目标是要让自己和对方取得共识，因此必须先找出自己和对方都能够接受的内容才行。为此，必须尽量考虑自己可能采取的立场与对方可能采取的立场，并加以组合思考。

◇ 尽量写出相互的立场

头脑风暴的方式，和一般企划会议所采用的方式相同。首先一一列举出自己所采取的立场。先不要考虑“如果我这么做的话，对方会这样回应”这类事情，只要把想到的尽量写出来就行了。

接下来，一一列举出对方可能采取的立场，不要加上自己的评价。这时候也不要提出像“这种要求绝对无法接受”之类的立场。尽量站在对方的立场上思考对方可能提出的问题。

这个阶段完成之后，将列举出来的双方立场相互比较，并将各自的立场一一进行推演。如果对方表明的立场是“希望能便宜一点儿”，在自己列举的立场中就找出“可以降价到 × × 元”。如果找不到可以对应的内容，就写出可以对应的其他条件追加进去。
