# # 做时间的魔术师

面对憨厚老实的人也好，面对作风强势的人也罢，时间都在同样地一分一秒地流逝，没有人可以抗拒。也可以说，时间拥有着非常强大的力量。

既然如此，就让我们和时间交个朋友，利用时间来交涉吧。

有关时间的交涉方法，之前已经提到过一个，就是在“限定法”中介绍过的“时间限定法”。

在时间限定法中，是以“如果在×小时内不做决定的话，你可能无法取得这件商品”的方式设定期限。接下来，利用不断逝去的时间迫使对方做出决定。

这种设定期限的方法，基本上是相当自由的。不过一定要给对方一个合理的理由才行。

此外，像我们做律师的，在向对方提出任何请求的时候，一定会设定期限。举例来说，当我们在请求未付款的时候一定会采用以下的格式：

“此笔款项三千万元，请于本书面送达后七日内支付。如未支付，将立即采取法律行动。”

像这样订下的“七日”期限根本没有任何根据。然而对方一定会觉得，如果七日内不采取任何行动的话，就会进入法律程序，从而对期限的强制力感到担忧。
