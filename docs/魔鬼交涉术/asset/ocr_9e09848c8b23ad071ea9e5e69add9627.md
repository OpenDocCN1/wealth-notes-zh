# 以假设性的说法提出条件

远藤先生服务于一家广告公司。这个礼拜天，他本来和孩子约好要去爬山。可是礼拜五的时候，课长突然告诉他：“这个礼拜天，有一家客户的老板，要我们公司派一个人去参加他们的高尔夫球会。不好意思，就由你去吧。”由于孩子们很期待这次爬山，所以远藤想要婉拒球会的活动。究竟要怎么开口才好呢？

![](bbox=[0.03, 0.73, 0.13, 0.87])

远藤：“课长，老实说，这个礼拜天我已经跟孩子们约好要去爬山了。由于是很久以前就约好的行程，所以孩子们都很期待。有关车票之类的各种准备也全都弄好了，要是我不守信用的话，可能会完全丧失孩子们对我的信任。这次可不可以不要派我去？”

![](bbox=[0.81, 0.72, 0.98, 0.84])

+   * 将课长自己的主意与“结果会失去孩子们的信任”做比较，形成一种威胁。另外，以“车票都已经买好了”这种既成事实，来暗示不能破坏约定。
