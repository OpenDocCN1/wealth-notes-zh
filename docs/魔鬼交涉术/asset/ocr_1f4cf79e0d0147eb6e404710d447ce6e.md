你已经了解我们撑得很辛苦，应该不至于会再提涨价这码事了吧。”
前田：“啊！嗯。不……”
客户：“谢谢你。那么下个月依旧维持这价格吧。”
前田：“啊，这个……”

这种类型的人宁可牺牲自己，也要满足对方。明明自己也有要求，但 because 不想伤到对方，所以根本无法开口。但是，就算说不出自己的要求，也犯不着去说一些对对方有利、让对方感到高兴的话吧。

# ◇ 不用考虑有利对方的事

前田先生犯了两个错误：

+   ① 说出有利于对方的话。
② 无法提出自己的要求。

首先，交涉的时候并不需要说出有利于对方的事情。有利于对方的事情，让对方自己思考、自己说出口就行了。如果由自己口中说出有利于对方的事，则表示自己同意这一点，会被列为当下双方达成共识的要素，再想要反驳将变得十分困难。

因为前田先生说道：“我当然明白贵公司的处境比我们还要难为。因为你们的定价也都订得很低，真是太感谢你们了。”所以客户顺势说道：“你真的知道我们的价格订得很低呢。”如此一来，这点便获得了前田的同意，之后他就只能被对方牵着鼻子走了。
