# ### 不要说出有利对方的事

◇ 不提出要求的话，永远无法开始交涉

前田先生自始至终没有提出自己的要求，也自然无法促使对方接受自己的要求——“希望涨价”。

交涉是促使对方接受自己的要求或条件的过程。因此，如果无法向对方明确地表达自己的要求，怎么可能使对方接受呢？

# ### 明确地表达自己的要求

即使是个大好人，只要遵守“不要说出有利对方的事”、“明确地表达自己的要求”这两个关键点，还是可以达成目标的。若前田先生依此方法进行交涉：

前田：“今天要跟你们商量一件很难开口的事。”

客户：“什么事啊？这么慎重。”

前田：“老实说，是有关商品价格的事。由于原料上涨，使得进货成本大幅提高，影响到我们公司的经营。我今天来拜访是希望贵公司能够考虑到这一点。”

客户：“因为原料涨价而深受打击，我们公司也一样啊。你们公司应该不会比我们更难为吧？”
