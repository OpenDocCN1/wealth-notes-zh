
# 摸清对方底细

## ◇ 交涉前须彻底调查

交涉之前，针对即将交涉的一切事项进行彻底的调查是非常重要的。

举例而言，如果想要卖出一套系统，首先要通过公司简介、网页、杂志报道等渠道调查预备出售的目标公司的历史、概要、组织、员工人数、公司文化、评价，等等。如果有朋友在这家公司就职，可以托这个朋友事前调查公司内的系统或架构，一切就绪之后，再去和这家公司会谈。

由于这个时候尚未进行正式的交涉，因此可以说些类似“我一定可以提出对贵公司有利的提案，请务必给我一个机会”这类的话，争取会谈的机会。

届时再尽量详细地收集这家公司目前使用的系统的内容、满意的部分、不满意的部分、今后有可能不满意的部分、希望能改良的部分、工作的流程、日后事业的发展、采购的关键人物等相关情报。

在这个时候，还不能将系统卖给这家公司。因为之所以要进行这些调查，仅仅是为了制作交涉的脚本而已。

# 头脑风暴

调查完毕之后，接下来就是心理准备了。不管对方说什么，必须让自己觉得这是“设定范围内”的内容。

为了达到这个目的，先进行头脑风暴吧。头脑风暴虽然一般用在企划会议上，但用于交涉也十分可行。

交涉的目标是要让自己和对方取得共识，因此必须先找出自己和对方都能够接受的内容才行。为此，必须尽量考虑自己可能采取的立场与对方可能采取的立场，并加以组合思考。

## ◇ 尽量写出相互的立场

头脑风暴的方式，和一般企划会议所采用的方式相同。首先一一列举出自己所采取的立场。先不要考虑“如果我这么做的话，对方会这样回应”这类事情，只要把想到的尽量写出来就行了。

接下来，一一列举出对方可能采取的立场，不要加上自己的评价。这时候也不要提出像“这种要求绝对无法接受”之类的立场。尽量站在对方的立场上思考对方可能提出的问题。

这个阶段完成之后，将列举出来的双方立场相互比较，并将各自的立场一一进行推演。如果对方表明的立场是“希望能便宜一点儿”，在自己列举的立场中就找出“可以降价到 ×× 元”。如果找不到可以对应的内容，就写出可以对应的其他条件追加进去。

如此一来，即使交涉时对方提出与以往不同的主张，但这项内容极有可能已经通过头脑风暴考虑过了，因而便可以轻易地以下一招来回应。这样一来，不管对方如何出招，都能够冷静地应对。这是防止交涉时出现差错的有力方式。

# 预测“中立点”

交涉的时候，双方的目标都是谋取自身的最大利益。如果自己最大的利益就是对方最大的利益，那么交涉就会没有任何问题，能够获得圆满的解决。

然而，事实上并不存在这样的例子。虽然最后的目的是要实现双方最大的利益，但这要建立在双方都做出让步的基础之上。

在面临交涉时，必须事前充分考虑对方的情况，并思考我方可让让步的幅度，找出某种程度的中立点。如果不这么做，就必须在交涉中当场考虑在某种条件下是否可以做出让步。这么一来，可能会因为困惑、不够冷静而犯下判断不足的失误。因此，先写好“预测中立点”的交涉剧本是非常重要的。

## ◇ 如何订定降价幅度

例如，价格交涉中，如果可以接受的底线是一千万的话，一开始提出的金额是三千万。大致来说，降价的幅度会如下表所示：

| 步骤 | 金额变化 |
| :--- | :--- |
| 1 | 三千万 → 二千万 |
| 2 | 二千万 → 一千五百万 |
| 3 | 一千五百万 → 一千三百万 |
| 4 | 一千三百万 → 一千二百万 |
| 5 | 一千二百万 → 一千一百万 |
| 6 | 一千一百万 → 一千零五十万 |
| 7 | 一千零五十万 → 一千零二十五万 |
| 8 | 一千零二十五万 → 一千万 |

一开始的让步幅度相当大，越到后来幅度越小。这样可以让对方知道，已经慢慢接近中立点了。

不过，如果没有设好中立点，只是胡乱喊价的话，最后会变成这种情况。

| 步骤 | 金额变化 |
| :--- | :--- |
| 1 | 三千万 → 二千万 |
| 2 | 二千万 → 一千八百万 |
| 3 | 一千八百万 → 一千二百万 |
| 4 | 一千二百万 → 一千一百万 |
| 5 | 一千一百万 → 一千万 |

如果采用这样的降价模式，对方完全无法预测我方可以让步到什么程度。如此一来，可能会给对方错误的讯息，认为“既然可以从一千八百万一口气降到一千二百万，最后应该可以用八百万成交吧？”结果即使价格到了一千万，对方也不肯妥协，最后交涉破裂的可能性相对增大。

# 交涉必须以底线的 1.5 倍做目标

净土宗的开山祖师法然曾经说过：“想要跳过一丈壕沟的人，必须激励自己可以跳过一丈五尺。”这句话的意思是，想要跳过一丈壕沟的人，如果一开始的目标只是跳过一丈，就会根本跳不过去。如果想要跳过一丈的壕沟，必须朝着跳过一丈五尺的目标努力。

交涉也一样。如果订定的中立点是一千万的话，就必须以一千五百万做为目标尽量争取。因为如果一开始就锁定一千万的话，最后很有可能只以七百万或八百万成交。

话虽如此，但因为是和对方的交涉，所以在设定中立点的时候，也不能利欲熏心，订得过高。

# 模拟交涉

一旦决定了中立点，就要进行模拟交涉了。

如同下页的图表所示，先想好“我先这么说。如果对方这样回答的话，我就这样回应”之类的实际对话。这就好比拳击里的挥空拳练习一样。通过这样的模拟，在面对实际交涉时，就能够沉着应对了。

模拟时最重要的是，不管如何进行，必须先想好将对方导引至原先设定的中立点的脚本。就算无法到达中立点，也要先想好尽量接近中立点的方法。

事实上，我每次都会先进行模拟，而当交涉真的如模拟一般顺利的时候，精神上将会感到十分愉快。

# "颅内控制"感性→理性

我们的大脑可以分为左脑和右脑。据说右脑掌控感觉，左脑分管理性。

在第一章曾经提过，交涉时必须将感性和理性分开思考。我们必须先动之以情，之后再说之以理，让对方可以判断究竟这么做是不是正确的，是不是合理的。必须先让对方释放出愤怒之类的感情。

因此，在设定交涉策略的时候，必须采取感性→理性这样的组合。

当对方怀着愤怒的情绪时，绝对不能突兀地采取理论性的说明。必须先让对方释放情绪才可以，而且必须先包容这种愤怒的情绪。然后，再针对对方愤怒的原因是什么，看他究竟愤怒得有没有道理，从而制作出可以令对方理性思考的交涉脚本。

## ◇ 电视购物所使用的脚本

请回想一下电视购物的画面。究竟他们是怎么销售健身器材的呢？首先，他们会先播出一个胖子的画面，接下来会切换到一个肌肉结实、体态曼妙的画面，让观众的渴望沸腾起来。再由使用这个器材而成功瘦身的人谈谈自己的经验，博取观众的信赖感。不停地利用影像，填满观众的想像空间。

到目前为止，这些画面的目的都是要打动观众的感情，因为如果感情没有被打动的话，就不会转化成实际的购买行动。而通过排山倒海的影像打动“感情”之后，观众的理性也会慢慢觉醒。

“到底多少钱？”“真的会有效果吗？”就在这时候，画面上出现价格，而且还出现分期付款的选项。这个部分会打动理性。如此一来，价格的问题就迎刃而解了。

其中还有一些商品会大肆宣传“无效保证退款”。事实上，这么一来又可以解决理性提出的疑问——“真的会有效果吗？”很多人就因为这样而买了健身机。

电视购物是不是早就想好了一套说服观众的脚本呢？那还用说。他们为了让观众采取购买行动，当然会准备好一整套脚本，对观众加以说服。

如果顺序出了差错，观众将不会购买。比方说，一开始就把健身机的构造和价格全部秀出来。这时候我们的理性将会发生作用。

“哦，原来是这种构造啊！价格要三万啊？这玩意儿要怎么锻炼身体呢？”

观众的心里可能会这么想。这么一来就完全被理性占据了。之后再看到大量的画面，会有什么结果呢？

“嗯嗯。这东西值三万吗？这只是煽动的效果吧？有没有效还真是个问题。”

换句话说，当一个人先感情用事的话，理性会让感性正当化。不过，如果是先理性思考的话，理性就会持续冷静判断。

因此，在拟定交涉脚本时，必须特别注意先后顺序。

## ◇ 写下可以控制对方大脑的脚本

健身机这种器材，可以控制身体的状况。而电视购物的脚本，则可以控制消费者的大脑。

让我们也试着在交涉的时候控制对方的大脑吧。既然我们已经开始了解了诀窍，就试着来扮演一下汽车销售员吧。

首先，我们要调查来到展厅的客人，“为什么他想买车？”

几乎所有的顾客都不会因为轮胎或悬吊系统的优劣而选择一辆车。他们考虑的是搭乘的舒适性、操控的容易度、可以开着车带全家去露营从而留下美好的回忆、可以受女性欢迎等原因。他们要购买的是未来的乐趣、舒适性、稳定性等等。在购买梦想的欲望形成之后，才会针对轮胎、悬吊系统等进行理性的考量。

因此，汽车销售员绝对不能从一开始就针对汽车的性能加以说明。必须先了解顾客的愿望，再放大对方的梦想。这时候再选定建议的车款，并向对方说明，对于实现对方的梦想，这款车能扮演多么重要的角色。

在买车之后，顾客可能会说，“因为操控性很好，而且跑起来又舒适，所以我才选这辆车。”不过事实上并不是这么回事。原本是为了实现梦想而产生了购买欲，为了让购买欲合理化，所以才自己制造出操控性佳或跑起来很舒适这样的理由。是他的理性在尽量说服自己，这个购买的行动是正确的。

# 活用脑部控制

这种方法也可以应用在邀约上。比方说，面对一个刚认识不久的对象，心血来潮想邀约对方，但却很有可能会被拒绝，这时候如果问对方“这个礼拜六一起吃饭吧？”

对方很可能会想，“要不要和你这个人一起吃饭？”如此一来，对方或许会告诉你，“我刚好有事。”对你加以拒绝。

在这种情况下，就可以使用脑部控制。如果对方喜欢吃意大利面的话：

> 你：“你知道吗？有个意大利的知名厨师，在银座开了一家意大利面餐厅。”
> 对方：“咦？不知道耶，在哪里？我好想去。”
> 你：“我上次和朋友去过，真的是太棒了。”
> 对方：“什么店名？”
> 你：“店名我忘了，这样好了，这礼拜六一起去吃吧？”

如果采用这种邀约方式，成功的几率应该会提升不少吧？

为了说服对方，脑部控制可以运用在各种场合之中。不过顺序十分重要，开始要说一些可以打动对方感情的话，等到对方动心之后，就可以切入主题了。

# 交涉，细节决定成败

## 交涉致胜的六个关键

选择在什么地方交涉也是一件很重要的事情。

以我们律师而言，就会尽量选择在自己的事务所。由于是自己的地盘，可以很放松地进行交涉。如果是到对方的办公室，由于环境不熟，对周遭的事物全都相当注意，会导致交涉时精神分散。此外，交涉的场所也可特别指定在法院或律师协会。一般人会很难适应法院的特殊气氛，律师协会也是一样。在这样的情况下，对方便会摇摆不定，稍加诱导，便会出现错误。

你是如何选择交涉地点的呢？ “没什么特别的，就是看当时的情况……” 绝对不能采取这种漫不经心的态度。

# 在自己的地盘进行交涉

## ◇ 如果主动邀约对方见面，应指定适中的地点

关于交涉场所的选择，基本上是“主动提出见面的一方前往会面”。因为不想见面的一方，并不需要特地出门。

如果是你主动要和对方见面，究竟该怎么做呢？例如，“我们在双方都方便适中的地点××饭店见面好吗？”可以采用这种指定适中地点的作法。此外，也可以首先由自己主动前往，谈论一些无关痛痒的内容，等到触及重要的交涉时，再询问对方：“上次是我前往拜访，这次是否能请你光临我的办公室呢？”这种将对方引到自己地盘的战略也很有效。

总之，擅长交涉的人，对与交涉相关的任何细节都会十分注意。交涉场所的选择，的确是其中不可轻视的一环。

> 在自己不熟悉的地方和对方一较高下相当不利。
> 还是在自己最有把握的地方进行交涉吧。

# 准备就绪之前，不可接对方电话

如果打算见面交涉，由于时间和场所都已经确定了，所以可以在正式上场之前做好充足的准备。就像准备上场的拳击手一样，在正式上阵之前为了全力出击而提升自己的气势。

然而，如果此时又进行电话交涉，就会让人措手不及。在电话中，必须立刻反应并做出回应才行。慌乱之中，有时候可能会反应不过来，从而被迫做出承诺。比方说，突然有一通电话打来问道，“关于你所委托的文件，由于临时有急事，明天之前无法完成。可不可以延迟到下礼拜？”由于事出突然，无法好好进行考虑，所以最后可能会仓促地回答“YES”，导致之后的日程都无法顺利地进行。

这里只是以交件日来举例，其他相关的金额、数量、担保之类的重要问题，也有可能会在电话中逼你做出回答。如果在这个部分犯错的话，很可能会害你损失更大。

## ◇ 如果突然来电，就用电话录音！

有很多人不擅于应付突如其来的强迫要求，最后，在自己还没有作好充足准备的情况之下，被迫说出“YES”。像这样的状况，该怎么做才好呢？其实，只要使用“电话录音”就好了。等到自己一切准备就绪的时候，再 by 自己主动发起攻势。或许这次就轮到对方措手不及了。

电话具有强制力。如果对方打过来，往往会觉得非接不可。事实上，电话只不过是交涉的工具之一。只要事后回电，并没有什么失礼的地方。应该让交涉的工具帮助自己发挥最大的力量，这是不变的原则。

如果不小心接了电话，又不能立刻做出回答，可以说，“我现在正在处理，稍后再回你电话。”用这个借口挂掉电话吧。这是防止犯错的秘诀。

> 面对突然来电，先回应说“稍后回电”，
> 将电话挂掉，等准备妥当之后再回复。

# 替代手段决定输赢

所谓的替代手段，是指一旦交涉破裂的话，接下来可以采取的手段。面对交涉，一定要先想好替代的手段才行。这跟气势强弱无关，而是所有交涉都必须具有的条件。

有一家公司，原料一向固定从A公司购买。有一天A公司突然发了一份通知，要涨价10%。这时候，这家公司的采购表示，“办不到。我们必须维持之前的价格。”完全不接受新的价格。

后来，他们收到了A公司寄来的解约通知。采购做梦也没想到交易会被解约，只能急急忙忙去寻找其他材料供应商。结果，他没有办法找到其他的替代渠道，在不得已的情况下，只好向A公司低头。如此一来，A公司看准了他们的弱点，一举把价格抬高了20%。因为没有其他渠道，这家公司的采购只好按照A公司提出的价格购买。

这家公司起初的态度非常强势。然而，在供货厂商只有一家的状况下，由于没有替代手段，因此双方的相对关系也随之逆转。既然这家公司必须采购原料，只好落入了弱势的立场。

由于非得从A公司进货不可，在这种状态之下，这家公司会对这桩采购交涉非常执着，最后被迫做出退让。然而，如果A公司不行还有B公司可选择的话，由于对交涉的执着程度较低，如果A公司抬高价格，这家公司的采购也不会自乱阵脚。

## ◇ 有了替代手段，就能轻松面对交涉

所谓的交涉，目的在于获得自身的最大利益。因此，如果能够让对方让一步就尽量不让步。要想做到这一点，必须有替代的手段才行。

以刚刚的交易为例，在知道除了 A 公司之外，没有其他原料供应来源的状况下，首先必须倾其全力寻找替代手段，再与 A 公司展开交涉。或者是这次就放弃这批原料，把心力专注在其他的业务上。如若不然，就会被撕掉退路，陷入不得不交涉的局面。

当然，是否有替代手段的确相当重要，但对对方而言亦是如此。以刚刚的例子而言，如果这家公司是 A 公司的大客户，一旦 A 公司无法接到这张订单，立刻就会陷入资金周转困难从而破产的状况，那么，A 公司就不得不让步降价了。不过，如果除了这家公司之外，A 公司还有其他的买主，那么 A 公司就能游刃有余，而不会有所退让。

从以上的例子可以看出，在决裂的时候是否有替代手段，对决胜负确实具有莫大的影响力。因此，应该采取确保本身备有替代手段，同时破坏对方的替代手段这种战略。至于该如何破坏对方的替代手段，方法相当之多，比如可以约定在一定的期间之内，只能和自己的公司进行交涉，从而独占交涉权，等等。

> 交涉时过于执着的人将处于不利的位置。
> 准备好替代的手段，轻松地面对交涉吧！
