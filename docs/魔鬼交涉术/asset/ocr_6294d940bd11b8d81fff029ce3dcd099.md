# 在自己的地盘进行交涉

+   ◇ 如果主动邀约对方见面，应指定适中的地点

关于交涉场所的选择，基本上是“主动提出见面的一方前往会面”。因为不想见面的一方，并不需要特地出门。

如果是你主动要和对方见面，究竟该怎么做呢？例如，“我们在双方都方便适中的地点××饭店见面好吗？”可以采用这种指定适中地点的作法。此外，也可以首先由自己主动前往，谈论一些无关痛痒的内容，等到触及重要的交涉时，再询问对方：“上次是我前往拜访，这次是否能请你光临我的办公室呢？”这种将对方引到自己地盘的战略也很有效。

总之，擅长交涉的人，对与交涉相关的任何细节都会十分注意。交涉场所的选择，的确是其中不可轻视的一环。

> 在自己不熟悉的地方和对方一较高下相当不利。
还是在自己最有把握的地方进行交涉吧。
