# ◇ 技巧 4 推说是决策者的意见

在无法拒绝对方要求的时候，可以跟对方表明，这不是自己的意见，而是当家作主的人的意见。

比方说，对一个热心工作的厂商，可能不方便传递这样的讯息给他。“很遗憾，我们无法和贵公司交易，因为没达到我们公司所要求的水准。”

不过，如果是“我觉得这个产品真的很棒。我也很努力推荐了，但是仍然没有通过我们公司的决策。请原谅我的能力不足”。这样的话应该可以说出口吧，如果这么说的话，对方应该可以明白，并非是你拒绝了他。

而且，这么说也不会伤害对方的自尊心。因为他会认为，他有一个为了他而努力说服决策层的伙伴。

# ◇ 技巧 5 拒绝之后，立刻也让对方拒绝一次

心理学中有一条“反馈法则”。这是一条不管从对方那里得到什么，一定都要加以回报的心理法则。过年过节收到礼物一定要回礼，也是基于这种心理。

并不一定只限定于收到东西才会启动此项法则。这是一条让心理获取平衡的法则，不管好事还是坏事，都一样适用。比方说，如果被人欺负了，一定要报复，也是基于这种心理。
