# 导向理性，再做选择

前面事例中最重要的一点是：顾及对方的情绪，引导他以理性做出选择。

对方对我进行“律师可以不遵守申告期限吗？”这样的人身攻击，如果当时我也和对方一样感情用事的话，应该当场就会不欢而散。

不过，我选择让对方的情绪冷静下来，接着让对方了解，截至目前为止，往来交涉已经是多么的辛苦，如果现在决裂的话，之前的辛苦都将化为乌有。而且让对方自己思考，谈判决裂之后要打好几年的官司，与现在和解相比，究竟怎样做更加有利，借此唤醒对方的理性。最终，谈判有了结果。

采取硬式交涉的人难于使用这种交涉方法，因为他们一定会以牙还牙，以眼还眼。然而，这种交涉方法在懦弱或口才笨拙的人用来，却往往是得心应手，事半功倍。

俄国小说家契诃夫曾经说过：“如果一个人无法以温柔的话语征服对方，那么用恫吓的言语就更征服不了了。”交涉并不是只有以强硬的方式进行才能取得成果的。
