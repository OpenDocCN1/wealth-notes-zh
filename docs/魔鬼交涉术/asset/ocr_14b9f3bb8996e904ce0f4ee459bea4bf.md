# 把弱势当作武器！

原本因为懦弱而和交涉谈判八字子打不着的我，却莫名其妙当上了律师，每天都要进行谈判，而且还获得了一定的成果。

一个人如果放弃自己、蔑视自己，这个人就完了。美国棒球大联盟有一个名叫吉姆·亚伯特的选手。虽然他的右手天生没有手掌，但是仍然参加了奥运棒球赛，并获得金牌，最后进入大联盟，成为一位叱咤风云的投球手。

如果是我们没有右手手掌的话，有没有可能打棒球呢？“那样只会变成别人的笑柄……”，我们大概会这么想吧！

可是吉姆·亚伯特并不这么认为，借由不屈不挠的努力与斗志，他甚至可以进军大联盟。

你的情况又是如何呢？

懦弱？不爱与人竞争的和平主义者？口才笃钝？因为懦弱而无法与人交涉，所以放弃了？

“我真的很懦弱。所以在交涉的时候完全无法说服别人。”这和《酸葡萄》里面的狐狸有什么两样呢？

懦弱又如何？和平主义又如何？你的懦弱、你的口才笨拙，反而能够成为交涉时的武器。只要能活用本书推荐的交涉术，即使面对强势的对方，你依然能够游刃有余。
