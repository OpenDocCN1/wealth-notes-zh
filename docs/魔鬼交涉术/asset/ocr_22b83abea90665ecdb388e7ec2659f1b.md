# 微笑着提出威胁

小田服务于一家规模很大的不动产公司，在销售部门任职。不过，最近公司进行了人事变动，他被派到了业务性质截然不同的行政部。由于小田在分店的业绩一枝独秀，所以他感觉，这次的人事变动是公司派系斗争导致的不当人事调度。于是，他争取到一个向人事部长藤井先生申诉的机会。

![](bbox=[0.01, 0.57, 0.14, 0.69])

小田：“这次能够获得这个机会和您会谈，真的十分感谢。”

藤井：“我希望你以后能够站在行政的立场，为公司好。好努力。”

小田：“这点我没什么自信。对公司来说，真的需要我这个人吗？”

![](bbox=[0.01, 0.72, 0.14, 0.85])

藤井：“你说的这是什么话？那是 一定的啊。你在分店的业绩可是第一名呢，我们也很期待你日后的表现。”

小田：“如果是要以这次人事变动的名义要我自动离职的话，能不能请您撤回人事变动的任命？”
