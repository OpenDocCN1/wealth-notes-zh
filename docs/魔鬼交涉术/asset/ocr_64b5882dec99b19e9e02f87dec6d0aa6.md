# ◇ 写下可以控制对方大脑的脚本

健身机这种器材，可以控制身体的状况。而电视购物的脚本，则可以控制消费者的大脑。

让我们也试着在交涉的时候控制对方的大脑吧。既然我们巳经了解了诀窍，就试着来扮演一下汽车销售员吧。

首先，我们要调查来到展厅的客人，“为什么他想买车？”

几乎所有的顾客都不会因为轮胎或悬吊系统的优劣而选择一辆车。他们考虑的是搭乘的舒适性、操控的容易度、可以开着车带全家去露营从而留下美好的回忆、可以受女性欢迎等原因。他们要购买的是未来的乐趣、舒适性、稳定性等等。在购买梦想的欲望形成之后，才会针对轮胎、悬吊系统等进性理性的考量。

因此，汽车销售员绝对不能从一开始就针对汽车的性能加以说明。必须先了解顾客的愿望，再放大对方的梦想。这时候再选定建议的车款，并向对方说明，对于实现对方的梦想，这款车能扮演多么重要的角色。

在买车之后，顾客可能会说，“因为操控性很好，而且跑起来又舒适，所以我才选这辆车。”不过事实上并不是这么回事。原本是为了实现梦想而产生了购买欲，为了让购买欲合理化，所以才自己制造出操控性佳或跑起来很舒适这样的理由。是他的理性在尽量说服自己，这个购买的行动是正确的。
