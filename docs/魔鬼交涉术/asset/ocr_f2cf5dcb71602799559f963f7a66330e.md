# ◇ 如何订定降价幅度

例如，价格交涉中，如果可以接受的底线是一千万的话，一开始提出的金额是三千万。大致来说，降价的幅度会如下表所示：

| 三千万 → 二千万 → 一千五百万 → 一千三百万 → 一千二百万 → 一千一百万 → 一千零五十万 → 一千零二十五万 → 一千万 |

一开始的让步幅度相当大，越到后来幅度越小。这样可以让对方知道，已经慢慢接近中立点了。

不过，如果没有设好中立点，只是胡乱喊价的话，最后会变成这种情况。

| 三千万 → 二千万 → 一千八百万 → 一千二百万 → 一千万 |

如果采用这样的降价模式，对方完全无法预测我方可以让步到什么程度。如此一来，可能会给对方错误的讯息，认为“既然可以从一千八百万一口气降到一千二百万，最后应该可以用八百万成交吧？”结果即使价格到了一千万，对方也不肯妥协，最后交涉破裂的可能性相对增大。
