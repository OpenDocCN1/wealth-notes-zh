# ### 策略地制造限制

第一个实例，主角是奉命向客户收取货款的横山先生。必须回收的金额是一千万元。对象是非常难缠的一人公司老板手塚先生。然而横山是个非常胆小的人，根本招架不住这么强势的对方。究竟他能不能收到货款呢？

横山：“社长，六月份的货款还剩下一千万元……”

手塚：“是啊，付款拖太久了。对了，我想跟你谈谈上个月商品的事。”

![](bbox=[0.0, 0.668, 0.13, 0.735])

横山：“社长，今天我只想专心跟您谈未付款的事情……”

※ 用“专心”来确定交涉的目的。

手塚：“不要那么急嘛。你应该也很清楚，我的客户破产了，我们也被搞得焦头烂额，对吧？我们真的很惨。”

横山：“这个我也相当清楚。现在这个环境，客户会破产，一点儿也不让人感到意外。老实说，我们公司的状况也……”
