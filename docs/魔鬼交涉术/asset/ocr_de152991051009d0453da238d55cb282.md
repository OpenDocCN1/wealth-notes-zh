# 准备就绪之前，不可接对方电话

如果打算见面交涉，由于时间和场所都已经确定了，所以可以在正式上场之前做好充足的准备。就像准备上场的拳击手一样，在正式上阵之前为了全力出击而提升自己的气势。

然而，如果此时又进行电话交涉，就会让人措手不及。在电话中，必须立刻反应并做出回应才行。慌乱之中，有时候可能会反应不过来，从而被迫做出承诺。比方说，突然有一通电话打来问道，“关于你所委托的文件，由于临时有急事，明天之前无法完成。可不可以延迟到下礼拜？”由于事出突然，无法好好进行考虑，所以最后可能会仓促地回答“YES”，导致之后的日程都无法顺利地进行。

这里只是以交件日来举例，其他相关的金额、数量、担保之类的重要问题，也有可能会在电话中逼你做出回答。如果在这个部分犯错的话，很可能会害你损失更大。

◇ 如果突然来电，就用电话录音！

有很多人不擅于应付突如其来的强迫要求，最后，在自己还没有作好充足准备的情况之下，被迫说出“YES”。像这样的状况，该怎么做才好呢？其实，只要使用“电话录音”就好了。等到自己一切准备就绪的时候，再 by 自己主动发起攻势。或许这次就轮到对方措手不及了。
