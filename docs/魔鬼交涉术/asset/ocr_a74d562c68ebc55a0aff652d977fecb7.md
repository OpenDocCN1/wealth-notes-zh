# 最后的手牌：沉默说话术

交涉全都靠说话。不管是直接见面，还是通过电话交涉，任何方式都是利用口头的言语进行交谈。

既然如此，或许你会认为，只要比对方说更多的话，应该就会更为有利。有种说法是“量重于质”，说得一点儿都没错，在大部分的状况中，比对方说更多的话，确实能够使交涉朝着于己有利的方向发展。然而，这并不是绝对条件。

试举一个极端的例子。

服务于一家系统开发公司的加藤先生想要出售一套系统。报价是一千万，并且以这个价格和木村先生展开了价格交涉。然而交涉当天，木村先生却因重感冒而完全无法说话。这实在是太糟糕了，完全无法出声，要怎么进行交涉呢？
