# 导致交涉不利的四种类型

现在就为大家介绍一下四种“好人”的类型：

# ◇ 好人“半熟瓜”型

简单来说，这就是个大好人。就像夏日漱石的小说《少爷》中所出现的“半熟瓜”一样，绝对不会去想一些卑鄙狡诈的事，永远都只为对方着想，因而总让自己陷入不利的境地。不过，如果做为朋友的话，倒是值得信赖的类型。

# ◇ 避免对立的“和平主义者”型

这是一种与其说是为对方着想，不如说是讨厌和别人陷人对立状态，希望所有的事都能获得圆满解决的和平主义者。他们对于厌恶的事会立刻忘记，只想着人生快乐的一面。正因为如此，一旦产生对立关系，他们就会不断让步，不断陷入失败的模式之中。

# ◇ 别人说什么马上相信的“儿童”型

不管别人说什么，他们都会相信，并且照着去做。在这种人的观念中，别人是不可能说谎的。即使对方说谎或夸大其词，他们也会相信，从而总在交涉之中成为落败的一方。
