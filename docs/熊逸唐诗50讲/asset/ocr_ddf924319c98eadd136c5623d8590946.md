# 39 张若虚《春江花月夜》时间面前的悲和喜

![](bbox=[0.05, 0.12, 0.9, 0.18])

张若虚《春江花月夜》（摘录）

江天一色无纤尘，皎皎空中孤月轮。
江畔何人初见月，江有年年望何人？
人生代代无穷已，江月年年只相似。
不知江月待何人，但见长江送流水。

你好，欢迎来到《微选：唐诗50讲》。

这个单元的主题是“感时”二字，时间到底是一个，谁也不晓得。

时间是一种客观存在吗？或者仅仅就是我们的主观感觉？严格来说，我们感受不到时间，只能感受到运动，然后运动的位移被称之为时间。

太阳每天东升西落，一年我们日行春之夏、秋、冬——在天又一天的延续里，我们看到寒暑往来之变，看到生死轮回。

我们感知时间的轮转同步于生命的轮转，相信这就是老子的哲学。几乎每个人的一生都在努力地想要为自己赢得更多的时间。

生命是一场关于时间的博弈，每个人都在自己不被别人交换掉时间的博弈中。不得不为之而工作，是把别人生命时间卖给他人。

当你拥有了更多的资源，也可以役使更多人，你的时间就完全为你自己所有，可以消耗在你最感兴趣的理论上，让千万百年后的人还在讨论你几百年前的想法。所以，当人在争夺资源的时候，本质上是在追求长生。

吊诡的是，属于你的时间越多，时间反而过得飞快。每个在油灯下的油钱水上去寻找生机的工人都明白，几千年里能拥有长生不老的感应，只有非富即贵的人，才会有十种丰年四季去，也会在昼夜轮转的流逝中，感受到时光的流逝。

你以为让樱桃花的速度放慢一些，所以没有人享受过全世界所有的富庶。它可以分配给所有人的时间都一样有，也可以分给两拨相反的人。你的时间一长，就有更多的机会在时间的流逝里获得一些经验，也可以写诗来慰藉自己。

在时间面前的无力感总是很让人失落，但又能怎么办呢？只有每一遍读一首诗来缓解，而一首诗是可以超越时间的。打倒每一个热爱生命到不可留驻的感伤。

这一单元，我们会谈论唐诗中感时的佳作。首先是张若虚的《春江花月夜》，它被誉为“诗中的诗，顶峰上的顶峰”。然后是“初唐四杰”之一卢照临的《长安古意》。它是《初唐四杰》里的《与韩荆州书》。再往后是《燕歌行》，它把战争的苦难得到了进一步的展现，也写进了一种无形的无解悲。

# 1. 诗歌的花花草草

这一首讲的《春江花月夜》虽然篇幅比较长，但几乎没有生僻字，也没有生僻的字词，也没有冷门的典故，从头到尾自然流畅，明白如话。

诗人张若虚只有两首诗流传下来，却因为这一首《春江花月夜》可以争气地成为第一流的诗人。

诗的题目几乎涵盖了全诗的所有要素：春、江、花、月、夜。这五个要素被诗人做出了各种排列组合，每一种组合都能翻出一幅新的画面，景物在一种变换中能够显现出一种新鲜的、可感的画面。而花间的流水月，于是时间就随了时间的流向。

读这首诗，就算对哪一句没有立刻理解也无所谓，局部的语言和下面的画面本身就会打动人。读几遍就会发现其细腻。

诗句是从眼前的江水开始写起的，写江面上涌起潮水，仿佛与天连成了一气。而在江潮涌动的时刻，明月也从海上升起，千万里月光的江面都因为月光而显得明亮。

这当然是月光先照的场景，一个人的视角，是想象与想象空间里的那种场景。

接下来继续描写江水和月亮，把月光比作洒在花朵中的雪霜。这句不禁令人想起了它的出处，但是诗人问出了不少的疑问：“江畔何人初见月，江有年年望何人？”到底是月亮的历史更长，还是人类的历史更长？

如果历史更短，那么人类那一个最早感知月亮的是谁呢？如果历史更长的话，那月亮照亮那一个最早的人，是看到谁呢？现在人类在顶端的那一个，是什么样子呢？

问题可以以这里不断往下追，追问到底的时候，问题就变成了宇宙从何而来，人类从何而来，对于古人来说，这样的终极问题太无答案了，太有诗意了。

# 2. 哲学问题的诗歌解

会有人产生到强烈的生命意识，才会进入思考这样的问题。进入意识的自己，在衰老，在走向死亡，亲朋好友先后离自己而去，这个时候，就会对那些看似永恒不变的事物产生强烈的反感。

看到江水时而激荡，时而低迷，但永远在流转不息，看到月亮有时圆满，有时残缺，但永远东升西落，多么像循环一样呢？

从暴涨到低落，从圆满到残缺，几乎是一个循环的进程。而在季节里，一个冬天刚走，一个春天又来，人自然意识到只有自己的生命是单纯的线性进程。

自己不会有两个青春，不会返老还童，不会进入下一个轮回。这种感慨，很容易触动那些敏感的心。所以诗人会感叹，“人生代代无穷已，江月年年只相似”。一个人的时代不是个体的青春与衰老的轮回，而是一代代人的生与死。

所谓“人事有代谢，往来成古今”（《与古良字留赠》），这是道法自然的句子。月亮会不会也和人一样呢？也许每月的月亮都是崭新的，正如每一刻的江水都是崭新的。

人在找不到答案的时候，会有一个非常简单的想法：人类有着各种各样的目的，各种想法和企图都因为各种目的达成或没达成，而月会永远如我们一样呢？

如果它存在是毫无目的，那它又没有存在过什么意义？“江月何年见？但见长江送流水。”也许它一直在等待什么什么，但我们永远不得而知。

以上引到的这几句是全诗的详略，其他的句子都在围绕着这几句的主题打转。从月光等到离别，从离别到思念，淡淡的忧伤像月光一样，几乎不可得，淡淡忧伤也像水一样，无处不流，无处不在。而我们那对离别与思念和看着江月，还是因为我们的生命没有像月亮和江水那样永恒啊！

但是，永恒与短暂，往往只取决于我们的关注度。

初唐还有几首诗，《春江花月夜》里，其中有一首陈子昂的《春夜别友人》，里面的名句有“夜夜梦长，夜夜梦长，夜夜梦长，夜夜梦长”，看起来和“人生代代无穷已，江月年年只相似”如出一辙。

但因为是拿来和人类参照的，是遥远的，是身边的，对于人来说，让我们更着重看其中的道理，如果我们取得它的意象，就一定在语句反说来看，说成“年年岁岁花相似，岁岁年年人不同”。

其实人的生命比人的生命更顽固，只不过是它的真实人生，关于它的生命，是更关心的自己。呢喃在千万里都到了一种自怨自艾的调子，也会像万里，完全在宣子里宣子的花儿已经凋谢了，又被风吹落了几朵。

月是不是真的永恒，如果换一个角度，也无非是“前有唐宫琼歌，后人悲喜难言，世事难言”（苏轼《水调歌头》）。

我们不能拿《春江花月夜》和《春江恨》比较，还是苏轼的《水调歌头》，甚至所有的诗词诗歌比较，你会发现很多诗歌都是从月亮到那里诗歌，都会见到，很多很淡雅很淡淡的，并且染着那样的情感，淡淡的愁绪。

诗人自己更多地会从诗句中间，没有浓烈的喜怒哀乐，像一个不喜不怒人在当中独得，月归去去，这样的一个心态，在他的大自然难得，所以这样的诗也会显得格外难得。
