这样一首诗，应该说会让你对诗人王之涣产生更浓的兴趣。但是，这首诗的作者却到底是谁，其实没有确切的定论，在古人留下的各种记载里，对其字词的归属各有不同，但我们这里就不做复杂的考证了。

# 今日得则

登鹳楼这个学号词是由东汉六年的王褒定下来的，悲态是它的主旋律。

流水成为时间流逝的意象，来自孔子的名言"逝者如斯夫，不舍昼夜"。

诗歌语言主要以形象思维取胜，而用形容词思维，最好的方式莫过于运用意象。

《登鹳鹊楼》的主题，是由对时不我待的紧迫感里意识到勇猛善断的必要性。
