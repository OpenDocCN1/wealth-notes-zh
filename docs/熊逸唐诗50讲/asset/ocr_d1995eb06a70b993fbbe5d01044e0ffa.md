大都会永远洋溢着魅力，尤其对于年轻人来说，这里有无限机遇，天花眼几乎是无底的高尚。这里也有种种美妙的事物，无论是不是美食还是艺术精品，无不是志同道合的知众还是让人心潮澎湃的美色。甚至还有很多的人生赢家可以你摹为楷模，甚至你还有机会得到他们的帮助。

但是，这里也最容易尝到挫败感。因为海量云集，竞争的压力太大，而感到让人沮丧的痛苦；竞争的失败也太容易让人跌进深谷的不信。在这高繁华里，你也许会许远正明的形很俗，而那些豪门大族、香车宝马投下来的阴影格外大的，也格外的阴沉。

那些处在阴影之下的人们，到底应该怎样直面这活色流溢的美，又该怎样释解这一切，给那些万马平驰在强盛疆国里的信心注掉这一讲我要说的《长安古意》，就是来解答这种问题的诗篇。

# 1. 初唐四杰

《长安古意》的作者卢照邻是著名的“初唐四杰”之一。

今天谈到“初唐四杰”，我们很容易误以为这是四位名满一时的年轻俊彦，在那个诗歌为王的初唐显得有些从们分龙鱼会，其特不是。他们确实成名得早，人们就是著名的神童。

但在有生之年，人们对他们的文学才华质疑不小，更重要的则是对他们的世俗性为人处世的做做很看不过。他们这所谓的“四杰”，人生轨迹都不太好，下场更是一个比一个惨烈。

王勃犯了罪，遭受父亲被谪远迁到交址，自己在探望父亲的旅途中落水而亡。杨炯因两参排挤，被安置在边远地方做了小官，四十多岁就死在任所。骆宾王去政坛上站错了队，写信讨伐武则天，失败之后下落不明。

但如果你了解了他们的生平，就会觉得前面三位真的太幸福不一提了。

卢照邻出身于一个名门望族，从小就得到了良好的教育，自己也很上进，就会有一个大好前途。结果才情出众便出就仿佛一场佛魔坐下了车。这到底是怎么回事，我们就简略不详了。

卢照邻出狱之后，虽然还有小官可做，但怨怼上了伤症。他说这病，卢有他得到了一回良医的救活，这位高人手上求得了道教养生医术。从此以后，他的病症就越来越重，再也没有好过。

卢照邻有一位老师，是当时最伟大的医生，也是当时最伟大的人生进。具有深厚的玄学思想，自然是很推崇道家思想的，但自己的病情还是一天恶化下去，半身不遂，痛苦难当，家业也被拖垮了。

最后卢照邻和亲友诀别，他河自杀。在无法选择生与死的时代，这已经是他最好的选择了。

# 2. 长安城的日与夜

《长安古意》大约写于卢照邻生病之前，至少是病情稳定之前写的。这是一首长到尽的长篇古体诗。堪称唐代诗歌界的一幅《清明上河图》，里面的重点其实说在于长安的繁华，不如说在于长安的奢华。

开篇就是最华丽的场面：“长安大道连狭柳，青牛白马春争道。玉鞍珠剑过下第，金毂铜花傍御道。”“狭里”里的玉鞍是道士装束四边的路阔，路上的香车宝马络绎不绝，在主公和侠王的邻邱之间穿梭。

“龙马花车春日，凤丝齐御引长条。百尺游丝绕树，一群娇鸟共啼花。”车子上招摇着华丽的车盖，车盖上垂着像花的流苏，车车玉，从鲜明到金白，人群就仿佛一片明湖。
