# 彩蛋 | 李白的“败笔”和杜甫的“精英日课”

熊逸 猜诗50讲

我幸听到《精英日课》主理人万维钢老师的讲诗（谢静安的叙述里），我也在听，一边听一边思考老师讲得。

这“一句，我和万老师调换一下位置：万老师务虚，谈的是诗歌的感受；我来务实，谈的是实用性工具价值。

让我们先看一首诗，李白的《关山月》：

```
```text
明月出天山，苍茫云海间。
长风几万里，吹度玉门关。
汉下白登道，胡窥青海湾。
由来征战地，不见有人还。
戍客望边邑，思归多苦颜。
高堂明镜悲，朝若白发间。
```
```

这首诗将会在《猜诗50讲》的第19讲专门来讲，这里要说的只是它的最后两句。当年我读这首诗，读到最后仍然感到很奇特：

# **整首诗明明在写征夫妇人，也成为戍守边塞的读者所共情，那么为什么结尾会突然出现“高堂”的意象呢？**

“高堂明镜悲，朝若白发间”，这是说家乡的妻子在当日光的镜子上看到白发。而他们想象中的高堂里能拥有高堂，而他们想象中的高堂里能拥有高堂，但高堂只属于大城市里的富贵人家。

如果换做杜甫来写，他会用一个很实用的笔法来描述：“缘边羁征戍，独依寒床眠。征夫思乡土，白发何堪见。”

这，才是寒苦征人的真实的生活状态。李白为什么偏要写“高堂明镜悲，朝若白发间”呢？

如果按照这首诗的基本情感，“高堂”的意象确实不太适宜，可以换成悲苦或凄凉的土语。但我今天想，李白也许并不是不知道高堂的问题，而是为了受到诗歌的影响太深。写诗的时候，还是为了受乐府的影响太深，因为当时的乐府民歌里面，李白也自觉或不自觉得这样写。

在乐府诗歌里面，“高堂”和“思妇”是常常搭配出现的两个意象。

因为在当时的诗人看来，高贵族的人家在高楼之上看着远方的丈夫，这样的才显得优雅；如果是农妇或乡村少妇，一边叹息着远方的夫婿，还是多么美呢？

比如《古诗十九首》里有一首“西北有高楼”，楼上有“清歌”，“清歌”是“谁为”？“清歌”是“谁为”？是“主父”的“清歌”，“清歌”是“谁为”？是“主父”的“清歌”，“清歌”是“谁为”？是“主父”的“清歌”，这里的指代是在外部不可见的女性人物。

再比如曹植的七哀诗：“明月照高楼，流光正徘徊。上有愁思妇，悲叹有余哀。”“明月”为什么会？“明月”为什么会？“明月”为什么会？“明月”为什么会？做在楼顶上叹息，是唱和唱。行遍十千里，孤夜多长闺思。她的大夫远行，十多年也没有回到家，她一个人很寂寞，所以才会哀叹。

这两首诗都是很有名，同一类型不太有名的诗还有不少，都是指“高堂”来“思妇”的，这个传统在诗人的诗歌里面形象比较深了。

《关山月》既都是乐府旧题，李白写这首诗也不难解释，但我们读到这里的时候，应该知道“高堂”这个突兀的意象是为什么会出现的。

今天我们读诗往往是从修辞讲起，但唐朝诗人写诗往往是直接从修辞讲起，所以乐府的旧题会自动让我们产生联想，而我们不熟悉乐府，所以对这样的写法感到怪异。

在唐朝的诗人里面，李白对乐府诗歌格外着迷，努力学古、模仿，然后求超越，或者求创新，这样的学古之态，也为学古努力过，也会陷入前人修辞的套路里。

在学诗方面，杜甫比李白得力得多，所谓“读书破万卷，下笔如有神”。这话应当是成好诗：“为学如金字塔，不可半途。读书破万卷”是基础，下笔如有神是结果。
