# 春节专题3 | “岁”到底是什么东西

你好，欢迎来到《挑壶·唐诗50讲》。这里是春节的特别专题。

上一讲里，我提到了宋代《大傩图》引发的争议：吴昌硕的大傩儿，人们会戴着嬉闹，在想象中的巫和恶鬼张牙舞爪，吃着糖卷也是这么写的。然而在画面上，人们拿的却是农具和乐器。

![](bbox=[0.05, 0.23, 0.95, 0.45])

这到底是怎么回事呢？到底是乾隆皇帝抬鹿为马，还是现代学者考过度呢？

答案很简单：礼仪也像很多事情一样，会随着时间悄悄改变。

早在《论语》里边，就记载过孔子参加大傩礼的事情，只是记载过于简单，只有一句话：“乡人饮酒，朝服立于阼阶之序。”字面意思是：当乡里的人举行乡大傩礼的时候，孔子会穿上正式的朝服，站在东边的台阶上。到底这是什么意思呢？

我们知道，元朝，朱元璋的《四书集注》成为官方学术经典，那么朱熹是怎么理解的呢？在《论语集注》里边，朱熹解释说：“傩者古礼而近于戏，亦必服朝而临之者，无所不用其敬也。”

意思是说：大傩礼虽然源于古礼，但太像游戏，一点都不庄重，貌似值得尊重的态度。可是，但孔子身着最讲究、最庄重的状态，这是一种极致的精神，说明孔子对待任何事情都以诚和敬为意。

朱熹是不是解读过度了呢？有一点。但正是这一点解读过度的，给了我们很大的线索：朱熹是南宋人，他所谓的大傩礼太像游戏，不够庄重，恰恰是他的南朝大傩的样子。

宋朝的大傩也是在除夕夜举行的。《东京梦华录》给我们留下了北宋末年都城汴梁的过年场景：

教坊艺人们扮演神鬼怪物，上干人的队伍从皇寺开始，向外驱逐鬼魅，爆竹声喧。市民家全家老小都围坐在自制的火灯前，彻夜不眠，称为守岁。当然，爆竹既是除旧迎新，也是发泄想睡也睡不着的火。

我们看到，大傩礼的参与者，由汉唐时代的武将、官员成了歌舞艺人。所谓歌舞，用今人的话说，就是娱乐文人。既然连娱乐文人的大傩礼，自然更像游戏而不是像祭祀了。

到了南宋，南宋崇敬教坊戏，文工团演员人们就再难想办大傩礼，大傩礼也逐步消失于人。由此一来，大傩礼就逐步由官方典礼变成了民间狂欢了。

相应地，驱邪的红色变成了喜庆的红色，驱邪的爆竹变成了喜庆的爆竹，驱邪魔鬼的傩面具变成了拜年舞艺的傩戏，驱邪魔鬼变成了在天地间的驱岁，方里氏和上承条子的傩面具，而狂舞到底驱二龙，方里氏和上承条子的傩面具，而狂到结束，除夕过完，每个人都长了一岁。

新问题出现了：所谓长了一岁，到底长一个什么？换句话说，“岁”到底是个什么东西呢？

晚唐僧俗惟有一首《除夜诗》：

```
九冬三十夜，寒与暖分开。 坐到四更后，身发一夜白。 鱼灯延酒火，宫寝换衣裘。 今宵应告老，此觉见几回。
```

除夕是个很特殊的夜晚，到了四更天，人就添了一岁。以太太的准确来讲，所谓在十二个节气中，有一个“岁”，是“一年十二节气”正中间的节气。所以，如果以岁起头，一个更就是完整的时段，进入四更天就算跨年了。

你可以做一个问题：如果一名孕妇在今年除夕夜的生出了半岁的了小孩，这个孩子该买宝还是买生日呢？

我们的核心问题是：当我们在说“身添一岁”的时候，我们到底在说什么？

还可以换一种问法：一岁和一年有什么区别吗？

通常的理解是：岁和年就像外裤和拖鞋，名称虽然不同，说的却是同一回事。正如通常称人时常用名号同：“年同年岁似花红，岁华年人人不同”，“年年岁岁”和“岁岁年年”是同一回事。

但是严格来说，岁和年还真不是同一回事。举一个初识的例子：如果只身外是黑乌叫，大命也不怕担心本命年了。本命年黑乌叫本命“年”，其实真正发影响的却是“岁”。

追本源流，岁母文的“本”字，样子很像一支点燃的油烛。“年”的本是“亩亩亩”意思。古汉字里岁表某地方“有”，这不是说这个地方有了个叫“岁”的东西，而是说这个地方覆盖了亩数。因为东西需要一年一个时间，所以“年”才有了我们熟悉的熟田涵义。

“岁”的来历更加奇特，它指的是天上的木星。农业社会靠天吃饭，依靠木星来计时、定位。太阳系里，木星是五大行星，很容易辨认。但一年，地球就绕太阳公转的一个周期，该记它怎么定呢？

至少从甲骨文、古汉文都发现了木星运行的规律：木星的轨迹和公转周期于近十二年，木星的公转周期大约等于十二年。那么，把木星划分的天空平面成十二等份，每一份对应着位置。只要观察木星出现在哪一份的位置里，就能基本准确地读出当下的时间，这就是古代中国的“木星纪年”。

数字十二既然有如此好的出处，所以是诗得很外尊数，被称为“天之大数”。由此衍生出十二宫，大傩礼上的傩舞之所以是一百二十支，正是取十二的平方。

天之数在今天我们看起来带神秘感，因为在现在看来，历史实在是一个太遥远的东西。但在古代，观测天象、确定历法却是一门高深到极致的学问。关于天体方位，也有过名数，向下颁发历法，告诉大家新年应该从哪一天开始。

一年的第一个月，叫作正月；一个月的第一天，叫作月正。“正”和“朔”连用，叫作“正朔”，就是正月初一的意思。

古时候改朝换代，新王朝确定新历正朔。这首诗是的意思是，朝廷的政事，显示君主对自己进谏。所以“正朔”是一个特别有政治味道的概念。一般知道这个出处，就听到正朔的意思，反倒把一声的正读成四年正了。

一个王朝里边真正从天象角度确定正朔的，都是中书星殿的大文官，其实定正朔，甚至也不存在省级、市级的天文台，所有天文台都归中央直接管，这是一个政治制度。

这样的安排会有一个很实际的好处：观察计时其实很容易出错，但只要天穹正径是唯一的，那么出了错不妨错错就，等问题积累严重了再改就是了。

木星纪年，确定黄道很容易。古人把天穹一分为四象，分别是东方青龙、西方白虎、南方朱雀、西方玄武。在黄道上，每一条又分为七个区域。四七二十八，这就是我们熟悉的二十八宿。

木星十二年走一轮，每年走过的区域称“一次”，或者叫“一旋岁”，由此衍生出“小次”、“次”这些用词。星次的名称非常古，甚至有生僻字，分是是：

+   星次，共轸(zhī)、娵訾(jū zī)、降娄、大梁、实沉(chén)、鹑尾、鹑首、鹑、鸡，有、大火、析木。

这就是中国的黄道十二宫，朝前人曾经这些名称来对应西方的黄道十二宫。

这个十二宫，或者叫十二星次，可以分为四组。四象的每一象含三个星次。在这三个星次里边，中间那个对应三个星座，两边的两个对应两个星座。这就构成了十二宫或二十八宿的双重关系。古代中国的占星术就是从这些关系出发，来推吉凶福祸的。

我们来看《左传》的一段记载，读两干五百多年前的事。

赵简子是孙和夫工在天黑前路过这位家者，看他们家的人们天上出了彗星，怎么办？“于是说曰：‘这颗彗星有象过家？’”说这是家彗星，赵简子怕，因为他听到事，到处看有人，所以所有人都望着他死。

接下来，《左传》原文说：“于是岁在降娄，降娄中旦已。”所谓“岁在降娄”，就是大过一年的表达方式，指的是木星整行降娄星次的这一年。
