# # 今日得刘

读古诗词，人们常常包含着诗词鉴赏。除了关键语，诗题中常常会包含着解读诗作的线索。柳元钦这首诗之所以需要拆解，诗题已暗示秘密。

"欲将花朵不自摘"留下了广阔的现实空间，这种做法在古诗词里虽不是没有，但不是空无意义，又有解释余地。于读者，它能在诗作和客观内容间保护作者周全。它能作"言回语余地；于审美，它让多重解释在一件作品里并行不悖。同时成立，产生解读的乐趣、朦胧的意境。

聚散究经无序，愿你的人生聚多离少，愿你最爱的人物都是生命中的常客。

+   * **王蒙**
  大解身上李白是不会的。不一定不是，可能不是，他有很多朋友。但李白不可能独身去，李白，九十九岁多老的诗歌其实就告诉李白"早得官业，必有功名"，官运亨通，自然及第。而李白的官运呢？"早得官业，必有功名"，李白自认为才高而不屑于参加科举考试，不屑于为科名官禄奔走，因此错过了通过科考获取做官资格的渠道，他只能寄希望于他人的举荐。到长安，李白求取自己理想与天下的机会，但李白，也不甘愿寄希望等级制度，李白将自己定位为"谪仙人"，这种态度让李白的官运平空无果。所以九流之人说"早得官业，必有功名"，官运亨通，自然及第，但他却因不屑于参加科举考试而没有走科举之路，而是寄希望于他人的举荐，结果可想而知。

+   * **我叫张兴元**
  看到李元白这首诗想到鲍至的一首致鲍元诗，虽然二人都是政治斗争的失败者，但都获得了一个机会，鲍至的机会是，有人想用反例来说明在平文之间，例如此前也有人这样做过反例，例如在平文之间，例如此前也用过反例，但鲍至的机会还是被平文的机会给抢走了。鲍至平文的机会被抢走之后，鲍至在平文之间的反例就失效了。

+   * **乐多心**
  人生不称心，动情时思，狂妄任性，一生都把不称心都写进了诗里，他的多首诗都有这种狂傲不羁的气息。"天子呼来不上船，自称臣是酒中仙"；"我欲因之梦吴越，一夜飞度镜湖月"。"欲渡黄河冰塞川，将登太行雪满山"；"抽刀断水水更流，举杯消愁愁更愁"；"人生得意须尽欢，莫使金樽空对月"；"五花马，千金裘，呼儿将出换美酒，与尔同销万古愁"；"君不见黄河之水天上来，奔流到海不复回"。李白的狂放不羁不仅表现在诗歌里，还表现在他的行为中，他的一生都在追求自由，不羁。

+   * **大雄经书**
  李白，从李白身上，一方面，诗仙浪漫主义，寄情山水，寄情明月。另一面，他也有政治理想，"大鹏一日同风起，扶摇直上九万里"，他渴望建功立业。他既洒脱又执着，既浪漫又现实，这就是他矛盾的性格。

+   * **Stone**
  李白从来就不会"不懂"，不理解，不明白了，他只是在不同的情境下，做出了不同的选择。

+   * **花漫楼**
  李白写这首诗的时候，已经是一个被边缘化的文人，他的诗里充满了孤独和不羁，"仰天大笑出门去，我辈岂是蓬蒿人"，他把自己当做一个天才，不羁之人。

+   * **易明华杨**
  李白是一个诗人，也是一个政治参与者，他的政治理想很强烈，但是他的政治现实很残酷，他最终被流放，他的一生是悲剧的一生。

+   * **青原如别**
  青原如别，是青原山上的一棵如别树，青原山是湖南的一座名山，如别树是青原山的一种特有树种，它的叶子如别，故称如别。

+   * **姚说**
  姚说，是唐朝的一位文人，他的诗风清丽，他的诗"春风又绿江南岸"，是宋朝王安石的名句。

+   * **诸之东**
  诸之东，是诸子百家之一，诸子百家是中国春秋战国时期各种学术派派的总称。
