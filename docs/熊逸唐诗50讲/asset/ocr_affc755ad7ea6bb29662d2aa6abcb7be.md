# 基于每一句之外，不同的意象和意象群形成对比，比如“风急天高猿啸哀”这一句里，“风急”对“天高”，“寒”和“大”相对，“渚清沙白鸟飞”里，“清渚”和“白沙”对仗，一组小品对组成的单元形成更大的一组对仗。

这是只有古汉语才能达到的形式美，其比任何其他语言表达美意上要高出很多。让这首《登高》来代表唐诗的最高成就，已是当之无愧的了。

# 今日得到

杜甫的《登高》不但登意高层里的千古绝唱，也可以说对诗章发挥了极致，所以成为最为代表性唐诗最高成就的篇数。

近体诗是唐期的新兴诗体，特别讲究对仗格律和音色美。

杜甫是近体诗领域里用力最重，成就最高的诗人。

这首《登高》可代表唐朝最工整的整篇章法，那悲音从来不可断绝，古语说茫不知从何说起的感受。
