# 30 柳宗元《酬曹侍御过象县见寄》| 如有隐忧，欲说还休

柳宗元《酬曹侍御过象县见寄》

> 破陂山前春浪远，骚人通沆太三舟。
春风吹不满湖湘意，欲采荷花白自由。

你好，欢迎来到《唐诗·盛唐50讲》。

有一种相聚很像吵架，两个人明明可以会面，却都懒得一开些原因：明明有千言万语想说，却只能问三不近凑：说了句话，然后匆匆分手。如果你也有过这种难缠的感受，就会很容易理解柳宗元的《酬曹侍御过象县见寄》。

# 1. 一默如雷

绝句在短小的诗歌体裁里，越是短小，就越是刻意在言内、内有意言未尽的意思。写怎样，内容才容易显示出这种效效果呢？我们的题是：叫一些没有的内容，用掉字的语话，读着那一股沉默，虽然沉默，什么都没说，也会给人知听雷响。

所谓没有内容的内容，当然不是真的没有内容。而在内容上情感，所分也千转。说《诗经·北风·柏舟》早就说过：“欲默不深，有隐忧。”

在唐朝的绝句里，最能体现这种味道的，莫过于柳宗元的《酬曹侍御过象县见寄》。隽永的语言，在似有若无的内容里，给读者留下了深深的品味。

我们先看一个诗的题目：“酬”的意思是“酬答”，一定是曹侍御先写了一首诗给柳宗元。礼尚往来，柳宗元才写了这首诗歌为酬答。

“曹侍御”，是一位姓曹的“侍御”，但是他对官职，重要是指他的职务“侍御”，这是封监察官的简称。唐代监察御史叫侍御曹台，大约相当于今天的检察。御史台每年出会派下大的官员，通过巡查监察御史，巡视各方，也就是地方的行政监察官。

既然监察御史是负责监察工作，既然监察的对象就是地方官员，那么可想而知，他们应该和远方官保持够一定的距离，指出当地的姿态，做好官地地方的监察。

而被监察的地方官员，当然也会怕被监察御史到什么事做，害得自己的性命。所以在接下来诗句里让诗题意思时，不复言半以为，当时曹侍御下查柳州时，有些监察事件，曹公会知“曹侍御”和“酬曹刺史”“酬曹孟相”的意义显然不同。

这位曹侍御“过象县见寄”，象县是今天的广西壮族自治象州北部新州县，在柳市市。柳宗元在当过刺的时期，正是担任柳州刺史，象县就是柳州下的一座县。

曹侍御“过象县”并不是从象县经过，而是到象县，所以古诗的“过”有“拜访”，也就是“拜访某人”过“过”意思是“到”是“到那里去”，过过“过”意思是“到”是“过过”意思，“过过过”的“过”是“经过”的意思，一般用的字是“经过”的“经过”。

现在题目意思就很清楚了：曹侍御抵达象县，给柳宗元写一首诗，柳宗元写了这首诗词为酬答，题目里还暗示出来三个信息。

第一，曹侍御和柳宗元应该有过交接；第二，曹侍御到象县应该借公务要事；第三，曹侍御是中洲县令，而曹县却是柳州下县，柳宗元是当时的柳市市长。

还有第四点就是题目中没有交代到关键字眼：柳宗元因此为政务斗争遭受中贬，又被贬到柳州这个蛮荒之地。

掌握这些基本信息之后，我们就可以来赏析这首诗《酬曹侍御过象县见寄》了。

> 破陂山前春浪远，骚人通沆太三舟。
春风吹不满湖湘意，欲采荷花白自由。

字面意思大概是这样的：碧绿的河水在破陂山前流远，那位骚人通地乘船下了船。美妙的春风仿佛要我们之间深厚的情感。我想采湖水中的荷花送给知己，却无法这样去做。

一旦把诗歌这样直白的解释出来，你一定觉得莫名其妙，不明白柳宗元到底要说什么。所以，我们必须先去体会这首诗词里的一系列南方方意象。

首先是“骚人”，因为屈原的《离骚》，人们称诗人为骚人。“木兰舟”则是古传中用木兰造船的小船，后来用作船舶。

“潇湘”是湖南一带的水系，湖南人常常用潇湘指湖南境内。今天我们可以觉得湖南是个偏远地区，而在古代，湖湘属于文明的地区，中平原华夏文明几乎是漫无边际的。

唐朝中原的人如果被贬到湖湘，那种感受或多或少会被出。如果再向南，到广西柳州这种地方，那就是万里投奔了。

“潇湘”作为诗歌意象，常与“死”和“愁”联系。大诗人杜甫“死在苍梧之野，他的两个知己为娥皇、女英闻夫之死后南下去，走到湘水的时候，一直为远别而悲伤，跳进湘水死去。李白有一首《洞庭西》说：“洞庭西，古寺基姜是二字，乃在洞庭之南，潇湘多泪”，讲的正是这个传说。

再看“荷花”，这是一种水生植物，有点像四叶草。南北朝时代，柳惓写过一首著名的《江南曲》：

> 江南可采莲，莲叶何田田。
鱼戏莲叶间，鱼戏莲叶东。
鱼戏莲叶西，鱼戏莲叶南。
鱼戏莲叶北，鱼戏莲叶间。

采莲、潇湘、故人、相思这几个意象的关联就是由这首诗奠定下来的。

2. “不自由”的不同向

让我们回到诗句，柳宗元有感于“春风吹不满湖湘意”，于是“欲采荷花”向别人曹侍御表达心意，但是曹“不自由”。不自由，为什么不能采呢？柳宗元没说，自曹以想象的空间就大了。

简单来想，曹侍御是查察官，柳宗元是地方文官，曹侍御“过象县来”的象县是刺史所辖区。所以两个人必然小心避嫌，被监察的首员不敢和负责查察官员亲密眼色，自相误会，不然两方自会丑言。曹侍御。

往复杂一点来想，柳宗元原于政治斗争中被贬黜打身入一个派系，所有敌对者，看不再有不自由，任何人敌对敌对，无法不及。他自当也清楚这一点，虽然看似，千万生怕一个“无所通湖湘意”的诗人，也把自己置于更加危险的环境里。

所以，不如就让人“适还太”，远远地相视，不如相见，多少话还没说出口，索性也就不说了。两个人就这样貌重逢，却没有太多的相握，互相颔首，却看不见他的“手书自交去”。这样的默契，却最是耐人品味。

你也许还记得语文课文里学的鲁迅的《为了忘却的记念》。那里有一段很著名的意思很长：“年前老舍向鲁迅告别时，鲁迅问他的什么有梦？鲁迅没有回答。然而，现在我们都。”

鲁迅的这类“不自由”，也有他“吟罢低眉无写处，不堪重提风漫潇湘，欲采荷花不自白。”吗？

你也许会问：“柳宗元如此充满隐喻的难道不会使故友困惑吗？”就算诗面上什么都没有，但是读到诗分也讲清了一半。

如果这样的的问题真问到了柳宗元头上，其实他还大有解释的余地，他会说：“你完全不理解诗么。”欲采荷花不自白”，不是说我不想从花来，采来采来送给曹侍御。

这样的解释完全可以成立，因为在唐朝人那里，“不自由”的意思既可以指自由自决，也可以指不是自由，也就是情不自意的意思。

表示前一种意思的诗，比如白居易的“巢燕巢太有人，大燕燕意不自白”（《喜钱校书及第》），表示后一种意思的诗，比如韦应物“百感中来不自持，角声孤起夕阳残”（《登楼州七楼楼长答长》）。

现代汉语里的“自由”只剩下第一种意思，它来从佛家说的。佛讲人生是都由自己牵系的，所以，不自由是指自由自由自白结果，人才才会自由自白是自由自由自白结果，不自由，只有思想才能得解脱，获得绝对的自由。

今天我们说“自由”时，常说的一句话就是“由我”。而“由”这个字在佛里也是出现的，“绝对的真我”是“绝对的自由”，“绝对的真我”是相伴随的“绝对的自由”，也就是说，你的存在仅为你的存在为而存在，而不依赖干任何人。任何环境。“自由”在于这个存在是决定出来的。

“不自由”的两种含义在这首小诗里可以同时成立，这首诗妙的处，同时也意味诗人的笔力。如取第第二层含义，正因为“春风不满湖湘意”，情过深太复杂，诗人才会情不自白来采荷花见寄。一首短诗饱含着隐痛的一下子就看得清清楚楚。
