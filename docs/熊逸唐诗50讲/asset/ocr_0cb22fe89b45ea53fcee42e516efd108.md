# # 春节专题6｜本命年该怎么过

熊浩·唐诗50讲
02-29
52

你听，欢迎来到《熊浩·唐诗50讲》。这里是春节特别专题。

上一讲我们说到，唐朝人就已经有本命年的说法了，知道白居易也写过本命年，你是不是觉得它也没什么土了？

今天我们也确实十二个月为一个本命年的周期，这是古代也是古代的常态。本命年应该这么过呢？从上一讲到今年的华山开采采矿的矿子里，你可能会想到：如果一个华人本命年一点都不动工地，也不去开矿打仗，甚至不张卡片点，全年都保持一动不动，是不是就能安然度过呢？

很遗憾，答案是肯定的，因为本命年虽说是方位临近的，本命年的关键时间上。它就是，只要到了本命年，不做点儿什么，哪怕什么都不做，也会各种倒霉事发生。

这个道理要如何成立呢？首先，十二年的周期显然跟观察到的生肖周期的相关，或者是同一地年的周期的相关，也就是在十二太岁的周期，太岁作为占虚的太岁，在占虚体系里属于岁星，人格化的太岁神掌管刑法。

一个人遇上本命年，就意味着太岁这个煞星到你面前了。你可以简单理解为有一个人来通过这个太岁，在你家里，想让这里过太岁，赶快，还活法也翻出去。更过分的是，每隔十二年都要来你家住上一年。

你不能怎么办？必须对症下解，先要搞清楚这个太岁环境长什么！

而边讲到，古人认为太岁是阴性的，所以也叫岁煞。那么吉就属呢，就采用阳性来解。这就像做属太岁先要使用生火要用一样。在这样的解法里，貌似本命年应该多吃一点，太阳气的食物，有阳光性的东西，没线的吃主食、但是，这样的做法出于形而下了，达不到采术的科学高度。

神秘体系里的阳性，最强烈的办法就是使用红色，红色有颜色，阳气是最，盛阳之气，盛含阴阳性质的阳气。

所以古礼民俗，仅仅一个基本原则：凡是天冷，雨水大的时候，地上火就多用暖色调；凡是天热时，雨水大的时候，地上土就尽量多用黑色。这是中国版本的‘红与黑’。

红色越多，阳气也就越重，驱邪避邪的力量也越强。但是本命年穿上红袜子来给人不会觉得很高，比如红色上衣手红鞋，多一根红绳子。这样做其实很无效，被很小的红绳子，正是本命年最核心的驱邪力量。

一根小小的红绳子到底能起到什么保护作用呢？有人说，手绑的红绳子相当于一个护身符，其实这是一种严肃的解释。

护身符的作用类似于外来的侵犯，比如一只害虫有精力要危害庄稼，结果还没靠近，就被护身符避过去了。或者说有过来，护身符就像一个盾牌挡开一样，挡回来护住你。我们一看到护身符这个名字，会认为是一种很神秘的，有一种超自然的东西。其实，护身符往往就挡出了邪恶势力的一轮进攻。

但是和护身符不同，红绳子的作用不是防护，而是禁锢。因为本命年的邪恶势力是在于人的，到时候你，你可以简单地理解邪然来附体了。红绳子是用来禁锢这个煞星的，不给他捣乱的机会。

红绳子的用法由来已久，而边讲到，当日光发生的时候，人们会用红色的绳子缠住桃树枝，这叫‘朱丝紫发’，有颜色的天地就这样被人们捆绑起来了。

> 《孟子》有一句名言：“民为贵，社稷次之，君为轻。”所谓社稷，稷动合就是土地神和谷神，一个是土地，一个管粮食，在农业社会受到高官祭祀。可是当日光发生的时，人们不但要祭祀谷社土地，还要拿红绳子捆住他，难道忘了他的利益吧？

在儒家解释里，太阳和粮食都是阳性的，大多数月亮都是阴性的，日月食都是阴侵了阳，性质相当于臣子犯上作乱，属于天灾之等。人们面对天灾之异，就该挺身而出维护正义，不管这个正义有多大杂。

我们知道‘独尊儒术’是从从董仲舒开始的，董仲舒的重要代表作叫作《春秋繁露》，深刻探讨春秋问题。这部书从‘朱丝紫绳’有过高度赞美，原文就是太阳而发表有声：

> “此乃《春秋》之不可毁漫也。故天变之也，日者，月也，三者也。行之其道而不忘其艰难（nán），又足之也。”

大意是说，人权力能帮助天地恢复正秩序，这是最大的正义，就是威力再大、对手再强都不能作恶。那么可想而知，天地阴阳要惩罚有限破坏自然秩序，可以能释轻正义，要利用两股红绳子的力量把于它捆起来，让它不能为作非什么。

现在你可以试着解答一个问题了：新年的红色和本命年的红色是不是一回事？

答案当然是肯定的，两者都是为邪。

新年和本命年有一个重要的共同点：两者都是太轮到的起点。

起点意味着初生，萌芽，意味着力量最弱小，需要小心呵护。必须小婴小崽一样，自身抵抗力很弱，大人必须给他提供适量的食物和新鲜的水一样，对于新年和本命年的满眼红色，你也可以看作神做新生命。

但你也许还有疑虑：红色的鞭子拿来驱邪，这容易理解。可是红色的春联上面写着各种吉祥话，比如我特别常见的‘向阳开寿增福，积善家富贵有余，再比如’东风迎福海，财源滚滚水丁丁，福如东海，寿比南山。怎么都不像是为了驱邪。

这些确确实实都驱邪毫无关系，但是春联的载体（也就是挂在大门两侧的两条张长的红纸）原本就是驱邪的，不然它怎会是红色的呢？

春联有个别名，叫作桃符。宋前诗人王安有诗《除夕》，其中有两句：天于未去草领，岁领春领符，自己法却看与除夕之时，或者，邻居家自请写着看春联，所谓‘写桃枝’，就是写春联。

但春联有什么桃树呢？你是学过《桃都》唐诗50讲到，应该记得严的《桃都》是唐的近似诗，无论五言律诗还是七言律诗，当中两联都是平领诗，相反在直接诗中却是四言，是不可能写对仗的春联。春联是写在门上的，是真实具体的两快木板。上面各画一个凶神恶煞。

西片入者中国人过年，会奇怪明月庙的日子，家家户户为什么都在门上挂着听人的图像。反过来想，中国人看西方画，也很难理解不是画一点儿画，画脸谱，画各种挂住的、中国的、被杀死的人。

中国人桃树上画的凶神恶煞，是最古老的两个，一个叫郁（lv），一个叫神荼（shen shu），四个字里五个字都不能被规读发音。

桃树上也可以画画，也可以写字。新潮词人秦观有一首《鹅竹志》，描写大写的‘生话。最后两句：‘削木为人间字，佛至神荼齐写真。’说明是新年挂桃符的习俗：很多人会画桃树，或新桃画直接在桃上写上太阴小神的之名。要要就是这样的，而且交给小孩子去做，但佛、神荼这四个笔画太多不好写，小孩子难免会‘写木真。’

桃木有驱邪的奇效，两位门神也是驱邪犯鬼的专业高手，而以桃树结门，不是为了喜庆，而为了驱邪。

逐渐桃木变成红纸，驱邪的味道还在，但门神变成了春联，吉祥吉祥终于上了上限。今天联挂在大门两边，但门神的样子变得笑逐开齐，一点都不凶了。对于门神来说，时间不是未猪门，而是美言。

讲到这里，这个新年特别专题就结束了。最后回到最开始的时候我送你的那副春联：

上联：春晓成德，解带之心动未来；
下联：神舞至莲，弦歌之意在言前。
