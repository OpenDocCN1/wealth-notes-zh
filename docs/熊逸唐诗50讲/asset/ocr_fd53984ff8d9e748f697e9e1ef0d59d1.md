# 彩蛋｜卢照邻《长安古意》朗诵完整版

熊逸·唐诗50讲
今天

卢照邻《长安古意》

长安大道连袂斜，青牛白马七香车。玉辇纵横过主第，金鞭络绎向侯家。
龙衔宝盖承朝日，凤吐流苏带晚霞。百尺游丝争绕树，一群娇鸟尽啼花。
游蜂戏蝶恋门侧，双栖绿凤开丹崖。
复道交窗作合欢，层霄连甍垂珠翼。
梁家画阁中天起，汉帝金茎云外直。
楼前相望不相识，陌上相逢詎相识。
借问吹箫向紫烟，曾经学舞度芳年。
得成比目何辞死，愿作鸳鸯不羡仙。
比目鸳鸯真可羡，双去双来君不见。
生憎辟颜绣孤鸾，好抱筝颜栖凤尾。
双燕双飞绕画梁，罗袖带金风。
片片行云着蝉鬓，纤纤初月上鸦黄。
鸦黄粉白车中出，含娇态语情不一。
妖童宝马铁连钱，娼妓盘龙金屈膝。

御史府中乌夜啼，廷尉门前雀欲栖。
隐隐朱轮临道，遥遥翠幢没金堤。
挟弹飞鹏杜陵北，探丸借客渭桥西。
俱邀逸客芙蓉阙，共宿姻家桃李蹊。
媚来日暮紫罗裙，清歌一曲吐氛氲。
北堂夜夜人如月，南陌朝朝骑似云。
南陌北堂连北里，五街三市控三市。
弱柳青槐拂地垂，佳气红尘暗天起。
汉金吾五千骑来，翡囊屋苏鹦鹂杯。
罗襦宝带为君解，燕歌赵舞为君开。

别有豪华称将相，转日回天不相让。
意气由来排灌夫，专权判不容萧相。
专权意气本豪雄，青琐蘼芜春风。
自言歌舞长千载，自谓骄奢凌五公。
节物风光不相待，桑田碧海须臾改。
昔时金阶白玉堂，即今唯见青松在。
寂寂寥寥扬子居，年年岁岁一床书。
独有南山桂花发，飞来飞去袭人裾。

生僻字读音标注：

陌上相逢詎（jù）相识
片片行云著（zhuó）蝉鬓
遥遥翠幢（chuáng）没（mò）金堤
南陌朝朝骑（jì）似云；汉代金吾千骑（jì）来

+   1.  佳娟：听熊逸老师讲课时，常先生老师朗诵。听金老师字斟句酌字声地朗诵已觉得舒心，而当出现“愿作鸳鸯不羡仙”，这一句耳熟能详的诗句时，更是让我对这首“陌上”诗歌亲近了许多，好感度大增。

+   2.  姚妮：很喜欢卢照邻的《元日述怀》：筵花申中秋，归耕有外臣。人歌小岁新，花舞大唐春。草色迷三径，风光动四邻。愿得长如此，年年物候新。过去的元日是农历正月初一，放在现在新年伊始，也算应景。以前疑惑“王杨卢骆”的排名是怎么来的？因为个人认为王勃、骆宾王才气最高，可是杨炯就曾不服气地说：“愧在卢前，耻居王后。”可见在当事者心里就有异议。陆时雍《诗镜总论》说“王勃高华，杨炯雄浑，照邻清靡，宾王坦易，子安其最秀乎？调入初唐，时带六朝颜色。”很好地概括了四杰各自的特点和对初唐文坛的贡献。

+   3.  缘：听着金北平老师舒缓紧急、抑扬顿挫的朗诵，更易身会诗中之意境，和作者复杂的心路。真是诗不读不足以明景，诗不通不足以通情。
