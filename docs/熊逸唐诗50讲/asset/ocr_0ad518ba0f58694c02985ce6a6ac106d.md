# 09戎昱《咏史》| 史学视角下的和亲

戎昱《咏史》

汉家青史上，计拙是和亲。
社稷依明主，安危托妇人。
岂无前水士，谁为解纷云。
忠言有长短，恸感涕无垠。

你好，欢迎来到《精读·唐诗50讲》。

这一讲继续看羁怨主题，主要谈戎昱的《咏史》。我会先联系同类题材的胡曾的《平城》，白居易的《过昭君村》和刘长卿的《王昭君歌》，去看看他们如何采取了和王昭君这部《怀作》完全不同的视角。

在昭君出塞的故事里，你有没有注意到一个细节：昭君不是汉元帝的公主，和汉烈祖王朝是有半点沾亲带故，所以她出塞的婚事并不是特别正常。如果和亲者是汉元帝王的一个公主，你觉得诗人们的同情会更浓些还是更少些呢？

# 1、和亲到底该不该

边锋接着说道，唐玄宗召开高级会议，要商量一下解决边患办法。老成持重的大臣们集思广益，一致认为和亲是上上策。

唐玄宗不置可否，忽然顾左右而言他："最近听说有个诗人，姓名很特别，一时忘记他到底叫什么？"

宰相回答道："是不是冷朝阳，或者包公子？"

唐玄宗摇摇头，说道："我记得那人的《咏史诗》：

'汉家青史上，计拙是和亲。社稷依明主，安危托妇人。岂无前水士，谁为解纷云。忠言有长短，恸感涕无垠。'

吟咏一番之后，完颜笑道："魏尚书等何德能配？这首诗出自唐宣宗，这把武陵之花要献给，这才配得有这样的好诗。"

唐玄宗当然不是在说文学，而是在给边疆派定调子。

《咏史》诗的大意是说：汉人历史上的所有国策里，最糟糕的就是和亲政策。国家安危只能仰仗柔弱的君王，哪能够托付在国人的身上呢？历史上虽然有很多相父大臣说和亲策，真不配作为国家栋梁！

"安危托妇人"，'托'，在古汉语里就是'不托'，简单讲就是反应去依靠。'托'就是'不托'。唐玄宗提到的那位国难，是春秋时的晋室大臣，是中国历史上最早提出和亲政策的人。

唐玄宗如此褒奖《咏史》诗的作者，如此贬低魏忠贤，那些重臣们被的大臣们该说就从此告退了。关于'此也以此道言'的《咏史》，知道了它的作者戎昱——原本不太出名的一位诗人。

站在唐玄宗的角度来看，戎昱的见解当然后确。但是唐玄宗和大臣和百姓的角度，他们也许摘自蒙山，你们说，李昌胤在几位公主和亲换来了几年平安，免除了千万的军队征调，这难道有什么不对吗？难道什么不应该这样做？他这当然必要，但和亲至少可以作为一种缓冲的手段。

早在唐中宗神龙三年（707年），金城公主和亲吐蕃。文人们寄寓写诗，有的说'忠情寄亿夜，刻念得生还'（'却怨《送金城公主适西蕃应制》'），有的说'主歌送曲，帝重西蕃定制'，（《送王昌龄赴岭南幕府，主还西蕃》），都是委婉含蓄的讽言，和亲是祸患。

其实金城公主也不是真公主，只是李唐宗室之女，只好多与王孙李杜家族的血脉。但是文人们寄寓写诗，即把戎昱思想下，会不会好和亲是一样的呢？这跟如果皇帝答应了和亲，你们作臣民，心里的耻辱感难道不应该放大很多倍吗？

胡曾是唐朝最会写咏史诗的诗人，有一年他路过平城，写下这样一首绝句：

汉帝西巡乐未央，一朝倾国议和亲。
当时已信尘上剑，何事无人杀李唐。

（《咏史·平城》）

当年汉室和刘对远征匈奴，在平城陷入重围，剿匪之后，刘邦认为暴力不是匈奴的对手，才采取柔亲策略的提议，安排宗室女子与匈奴和亲。

中国大一统王朝的传统帝制，是把这件事看做历史的耻辱标记，给他一顶'千古罪人'的帽子。

在古人的概念里，奸臣大抵可以分为两种：一种是自己把家底、娘舅的命、钱粮的粮、打打自尽，他的死是死心；比如我们的怨愤王翦；另一种是与私己、严于律已，兢兢业业、鞠躬尽瘁但是道义的忠良好臣，比如比干。

第一种奸臣造成的损害是人性的，基本只限于当时，第二种奸臣造成的损害是制度性的，可以深远千代万代。在朝堂的末了，对这些种人当时就该赶紧要办死他。潘子词：宁为王碎，不为瓦全，尊严不是应该向利益让出任何妥协的。

你应该能想到，这些诗人一定对汉武带有独特：汉武帝不是耗光全国的武力人力吗，硬砸硬地和匈奴开战，损失大获国难。

但奇怪的，诗人们提到汉武帝，总是把他当做大功告成：刘民民的远送武员，比如苏武在他的《华清游三万里》里借回到诗评诗人，说他'玩兵弄事，兵事可平也'（dao gan jiang），像汉武帝一样'玩兵'，事打仗不打事，结果祸临天下，民富民穷，也误了自己。

诗人怀古咏史，往往就一事论一事，在宏大的议论上他贵不当家不如采来贵。

# 2、命是归为红颜，还是因为自负？

如果能把以下天家国为己任的雄心暂放下来，用普通人的视角来看昭君的一生，感受自然会不相同。

当初杜甫写那首《咏怀古迹》，只是远远地眺望昭君的方向而已，并不曾真正走进过。

但白居易是进来了，一边追论昭君的遭遇，一边忏悔老年的老进这里的人生风情。他那首《过昭君村》成为唐代吟咏昭君的诗里很别具一格的：

浔溪有无子，彩云飞雨花。
亦如双燕，亦如燕飞花。
燕自衔泥，衔泥入人家。
燕来归故处，纤纤一顾。
事往欲不复，不得而自苦。
旦月既可厌，丹青何以久。
使楼恨云北，远望巴东流。
惟见白云去，依稀怀故秋。
烟花化已久，但有村名存。
中有古遗迹，指点为言。
不取征者意，忍悲者谁悲。
至今村女面，烧灼成烟。

白居易里的是昭君找一个'退路'的地方，既解自己心结，也解自己遗憾地造成古代佳人，只能让人感叹"魂梦无神，彩云无无依"，像蔡美娘不出处一样。

美女总是被人发现，昭君注定被选召，却因为人的嫉妒，落选就选择自杀。皇帝既然不拿你，但事总有所造，无可奈何。人间有那么多大自留的的事情，又何必偏做恨那些画家呢？

时过境迁，村子里找不到昭君的遗迹，只有村子的名号昭君遗都往那里。村子里的老人告诉我，昭君的遗踪都在村里。大漠前的生云，也可以看到今天，村姑的脸上还会看到自伤昭君的危绝。

在村民的眼里，"薄命"仅仅因为"红颜"，与其天灾人祸，倒不如说失土。

这是很能引起读书人共鸣的心语：凭着自己的才华进入权力场的漩涡，下场如同水中蛟龙寂寞，难有显身巧成功，下场还不如安分分的普通百姓。

历尽宦海沉浮的白居易最能领会这样的道理，所以白居易的后半生大体是在"心静"当中度过的，养着那些半是仕途、半是处士的心情，能不默默不做坏事。简简单单地享受人生，比什么都好。

但是，如果再换一个角度，难道王昭君自己就没有一点点错吗？刘长卿有一首《王昭君歌》是这样说的：

自矜颜色美，不顾青春。
闻道匈奴使，上辞辞报汉使君。
上辞得辞辞，王嫱对人人。
化去为雪落，万里飘萧向羌。
托身须得所，双袖双清泪。
琵琶声中苦，萧萧寒秋自留。
可怜一曲《胡笳》，更在秋草留。

整首诗需要就是最后四句，大意是说：昭君对自己的美貌太自负了，相信是金子就一定会发光；这不想把家底押在跟，不肯向他们低眉折腰，哪想到自己的生一就放在这样一个细节上。

那么可想而知的是，在读书人身上，这样的例子实在太多了。对长卿本人又何尝不是如此。
