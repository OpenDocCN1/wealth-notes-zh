# **回答专题4：是猪年，也是屠维大渊献**

你好，欢迎来到《熊逸·唐诗50讲》。这里是春节的特别专题。

如果有人问，今年是什么年？你最有可能听到的回答是“猪年吧”。如果你朋友喜欢中国书画，正月里画了一幅梅花图，落款的时间大概也会是乙亥年。如果你想要显得很高大上的话，我教你，可以说成“屠维大渊献”。这是怎么回事呢？

我们上一讲最后，说到左传里一个著名的预言，神巫伍相有还话这么一个终究。果然，有死的时候，《左传》的记载是“岁在觜觿（zī xī）之口，其明年，乃在降娄”。意思是说，木星这时候来到到觜觿星次和降娄星次的交界处，但还在觜觿星次的区域里。

神灶真能这么神吗？

答案是，除非有什么神秘力量，否则仅以春秋年间的天文观测水平，很难算到这么准。

我们从古代的除夕，是从戌月跨入戌月。如果古代年历的角度来看，年底跨入鼠年。如果是这样，涉及的是木星刚从星次跨入降娄星次。真是巧了，涉及的星次刚好和《左传》里预言的星次一致。

但是这只是完美的谎话。事实上，《左传》里的设计对写谶语迷信了，到天观测才变得精密起来。古人发现木星运行一周大约需要十二年，而且11.86年。这意味，每十二年就会积累出五十多年的误差。

这下麻烦来了，以前是照着木星运行来计算一岁年，一岁12年。观测变得准确了以后的结果，想要中划分的星次，跟天上实际的位置对不上了。

这实在太不方便了。于是聪明的古人想出了一个解决办法：假设天上有一颗星，和木星差不多，但运行一周大约是整整十二年。他们真的这么做了，这颗假设出来的星体，叫作太岁。

注意，你熟悉的那个“犯太岁”的太岁终于出现了。它从一开始，就是古人想象的事物。

既然是想象当中的东西，运行必须规则才不杂乱无章，除了让太岁流行一周一刚好十二年之外，还要让它和木星的运行方向相反。

为什么要特意相反呢？因为原来十二地支虽然是天，也就是木星的十二星次一一对应。但是问题是，两者偏离得越来越远，这一在操作层面上带来很多的麻烦。那么，想象一个太岁，让太岁与十二星次和地支的顺序一致，这真能让轻松很多。

地支总是和天干配对的。我们今年是己亥年，是己亥、癸丑、戊戌、丁未、甲午、分别是甲、乙、丙、丁、戊、己。天、共十二个。地支一共十二个，分别是子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥。

古人用天干、地支配到十，两个天干对十个地支会产生两个，这两个再从天干开头的甲、乙开始配起，配到六十之后开始重复。比例今年是己亥年，下一个己亥年会出现在六十年之后。

既然太岁是新的，十二星座也有了一套全新的名字，分别是：

+   - 摄提格、单阏（chán yān）、执徐、大荒落、恊章（dàng）、敦、沛、困敦、作鄂、阏（dàng）、单阏、... （此处为十二星次与岁阳名称列表，原文为多行排列）

在阴阳观念里，太岁既和木星的运行方向相反，彼此之间必然存在阴阳关系。木星实在天空运行，天属干阳，所以太岁该在地之运行，地属干阴，进一步推测，木星属阳，太岁属阴。

太岁的十二星次叫作岁阴，那么，是不是木星的十二星次叫作岁阳呢？并不是。古人认为岁之岁干支叫作阳位，不是阴位，称为岁阴。还应该有一套对应的天干，称为岁阳。十个岁阳就这样被编排出来了，也有一套奇怪的名字：

+   - 阏逢（yán páng）、旃蒙、柔兆、强圉、著、屠维、旬始、摄提、上章、重（chóng）光、余（é）维、昭阳

如果你热爱中国历史的话，就会发现这些奇怪的名词竟然有点眼熟。比如《资治通鉴》，每卷开篇首先交代本卷内容的时段。第一卷是“起黄帝有熊氏，至玄诃玄，凡三十五年”，那些听着很陌生的词，都是太岁编年体系的一部分。如果替换成干支，可以这样表述：起于戊寅，止于壬子，共一十五年。

《资治通鉴》为什么要用简单明了的干支纪年，采用既复杂繁琐的太岁纪年呢？很简单，太岁纪年体系是天文观测的结果，干支纪年仅仅体现排序。所以前者会显得庄重、专业，而且很有格调，能和老百姓拉开距离。

今年己亥年，如果我们高来高大上的话，可以说成屠维大渊献。

显然干支用起来比太岁方便太多，而且干支不但可以纪年，还可以纪月、纪日、纪时。如果把你的生辰精确到时辰，能用于岁支排进年月日时，四柱干支用于算命先出生年月，四柱八字就是从四柱开始推算吉凶的。

年、月、日、时的干支很容易被重复，关键位置的重复又很容易被赋予特殊意义，就像我们今天发的微博。那么，以某年份为例，如果己亥年的正月遇到己亥日，这一天就被称为太岁日，唐朝人把它当作节日庆祝。

杜甫有一首诗，题目就叫《太岁日》，题下有一小注：“太岁日干，太岁戊申，正月丙午。三日为戊申日，太岁戊申。”戊申是唐代的年号，“岁戊申”其实唐德宗改成年号，只是加上“岁”字，显得古雅一点。正月初三按历史上，朝廷开始搞活动，发贺诗：

> “阖署开黄道，衣冠拜紫宸。荣光启日月，赐与出金银。”

我们看到，就连“读书破万言”的杜甫，竟然也在使用“岁戊申”这种极不规范的表述呢，那么不难想见，普通百姓不可能不讲屠维大渊献、擎雅摄提格这些怪词，就连天地生肖也不通。所以民间给十二地支配了十二种动物，这就是我们熟悉的生肖，属相。

讲到这儿你应该明白了，今年属“猪年”，是最靠谱的正确答案。如果一个人问“己亥”，说明他有点文化。最有文化的回答，当然是“屠维大渊献”。

这倒不仅是异名同实的问题。纪年的称谓不一样，意味着纪年的标准不一样。纪年的标准不一样，意味着寿命的理解不一样。

民间命，就是我们熟悉的所谓“鸡猴不到头”，意思是属鸡的人和属猴的人不适合结婚，就算结了婚也不长久。民间还相信属牛的人勤劳，属马的人容易受欺负。所有这些观点，都是生肖动物本身的特性带带来的。

但在知识分子看来，所谓生肖，只是简化的标记。所以，无论是把牛换成水牛，还是把羊换成大龙，或者把鸡换成十二生肖里谁，都无所谓。因为真正揭示吉凶祸福的，是太岁系统所表达的天象。

东汉年间有一部书叫《移徙诀》，顾名思义，是一部关于搬家的歌诀。这部书上说：搬家的方向如果正对太岁，这叫岁破，凶；如果背对太岁，这叫岁破，同样是凶。

我们可以想象一下——当然只是想象：今年的太岁纪念猪维大渊献。太岁的位置在西北偏北。如果一个人要搬家，新房子偏偏位于现住址的西北或西南或东南偏南，那就要看是否有事情发生在他人身上。

古人盖房子最重视太岁方位，有一句话你听过：“太岁头上动土”。这话的引文意思是想做大事，而它的原话意义完全是避忌太岁：凡是破土动工之类的事情，必须避开太岁的方位，否则会招来不幸。

如果有人偏不信邪，偏要在太岁头上动土，首先会遇到怎样的凶兆呢？古籍里不乏记载：首先，在动土的过程中，会挖出一个活生生的太岁。
