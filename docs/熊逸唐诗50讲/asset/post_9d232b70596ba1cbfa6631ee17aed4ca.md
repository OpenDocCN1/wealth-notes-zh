# 41 李商隐《锦瑟》| 只是当时已惘然

你听，欢迎来到《熊猫·唐诗50讲》。

“往事”有一种奇怪的魅力，无论是甜还是苦，在敏感的人看来，均不堪回首回答。悲伤的往事自不必说，而甜蜜的往事因为被时光抛弃了，没办法重新经历一次，所以也让人不想回答。

李商隐的《锦瑟》是一首感叹流年，追忆往事的诗，传达出复杂而难以言表的情怀。

### 1. 艺术有没有高下之分

在历代所有的诗歌当中，《锦瑟》却算不上是最让人捉摸不透的第一首，至少《锦瑟》是最让人捉摸不透的作品之一。并且，在所有人捉摸不透的诗篇当中，它是当之无愧最能激发人们解读兴趣的一首。

在进入正题之前，你可以先考虑一个问题：艺术形式到底有没有高低贵贱之分呢？比如音乐、诗歌、绘画，哪一种更高级？

还有一点问题：当你欣赏了很多情感要释放或者渴望共鸣，这时你就会觉得哪一种艺术形式是最贴切的呢？或者，你最容易被哪一种艺术形式打中呢？

在美学的范畴里，这个问题还没有答案，那就是：音乐是最高级的艺术形式，其他艺术形式如果想营造出感音乐感，就有着必要向音乐靠拢。

这个道理可以有很多情素，解释就是没有内容的纯形式，同样，音乐也是没有内容的纯形式，彼此高度相似的纯形式最容易引发共鸣。

我们听音乐的时候，常常感觉茫然百事，听茫然茫然。而到浪漫诗了又无法不分清楚，听茫然茫然，千首百听，这些歌曲上十二或千上万的情感，远远超出了语言和图像所能承受的承载能力，既丰富又微妙。

我们用言语来表达情绪，粗略可以划分为喜、怒、哀、乐、恐、悲、恐惧，这就像以七情六欲当中的七情。如果细分下去，比如喜可以分成狂喜、欢喜，还可以有“和合”分升为愤怒。每一个细分的美都可以细分再细分，以至于无穷。

我们很少会对每一种情素做单一的梳理，或者说，我们的每一种情素都是无数种细小情素的混杂，并且还会不断变动。

那么，怎样用有限的语言把无穷复杂的情素表达出来？这就需要有言语或无形的复杂的内容，不但要像绘画一样言说和形容的场景，还要像音乐一样用非常有限的言传传达出动态。

在唐代诗人当中，乃至于历代诗人当中，在这条道路上走的最远的，大概是李商隐。

李商隐是一位远远超越了同时代的诗人，又因为其他诗人（包括吴元明清的很多诗人）都没能超越李商隐超越的时期，所以他们才会对李商隐的诗歌及时地及时找到到一首《锦瑟》解开难人谜这样的局面。

### 2. 《锦瑟》是无题诗吗？

锦瑟无端五十弦，一弦一柱思华年。
庄生晓梦迷蝴蝶，望帝春心托杜鹃。
沧海月明珠有泪，蓝田日暖玉生烟。
此情可待成追忆，只是当时已惘然。

《锦瑟》是一首好诗，这是公认的事实，但到底能好到多少，什么分量，还玄了，如果能用其中的诗语到讲出来了什么意思，那么它的中心思想，那就彻底让人困惑了。

你可以这样想：当你熟悉的歌曲（命运动作曲）的时候，你也许会它会在表现人对命运的抗争。

假如作曲家不给你标题，只叫你猜其五首的意，你还不会给你线？如果你硬想出了这个道理，就很容易去接受这首《锦瑟》乃至李商隐的种各种类型诗歌了。

按照常规的读法，我们会从诗题看起。题目里的锦瑟是古代的一种弹弦乐器，瑟是它的本名，之所以称为锦瑟，是对于形器它的做工精美。

如果题目是《锦瑟》，诗是一首咏物诗吗？也许，也许不是。如果说它不是，很简单，这首诗的第二句就像李商隐的另一首咏物诗一样，比如第一句写的物两个字，本上原于一句，如果说它是，从上下文也能解释得通。

北宋诗人黄庭坚是一个很滑稽的学者，就是他不看重《锦瑟》的读法，于是虚心向苏东坡请教，苏轼写下结论说，这是一首咏物诗，因为古书上说过，瑟这种乐器是有个调子，分别是怨、思、清、和，这不正是《锦瑟》这首诗在讲的吗？

如果取这种解题论读法，那么前两句“锦瑟无端五十弦，一弦一柱思华年”描述的形制，五十五根弦，接下来的四句可分别表达怨、思、清、和这四种性。

这种解释，即使原来让人这么交心，当然也能成立，但你要想李商真人是否真这么构思的，这首诗意的大也远超越于作者的企图之上。

### 3. 不落实处的写法

这首诗从一个毫无道理的问题写起：锦瑟为什么有五十五根弦？为什么要么是二十五根弦要么六十根弦？平时不会有人去问这种问题，大多相近或少的诗事，大家都合目用而不知，根本就不觉有什么可奇怪的地方。

而一入人耳内，开始胡思乱想，就会发现很多言不由衷的东西都没意思，不说出来怎么就不言而喻了，比如人为什么要活着，时间为什么要流逝。

“无端”是个很命韵的词，它意味着突如其来的意思，足轻取一态“一丝半毫”意味，每一根弦、每一根弦丝都不能让人想到逝去的年华，想到自己在不不知不觉中就到了这个年纪，想到了曾经岁月里的一丝一端。

情绪因此变得紊乱，每一点每一滴都起起了泪水泛泪，诗人一定说得上的弦一张千拉动了大多回忆，但在万万千千清泪上心头的时候，也一定无从讲起。

被勾起的清情绪弥漫，悲欢交集。如果非要描述的话，那就让十四幅画面交织起来好了。

“庄生晓梦迷蝴蝶”，这是《庄子》的典故，清商原梦已经变成了一只蝴蝶，醒来之后不清楚是自己在梦中变成了蝴蝶，还是在梦中变成了自己，一切都亦真亦幻，恍惚难辨。

记忆里的旧事或者因为旧事，各有原因，因为一切切切，不靠替替替替替替替，那种一任往深，死不休的情绪是最真实的。

这里又提到一个典故：望帝是传说中古蜀国的国王，名叫杜宇，因为国政身死的缘故，他的魂化成了鸟儿，永远发出思归，思归鸣叫中吐血而亡，人们把这种鸟儿叫作杜宇，也叫杜鹀。

但李商隐并没有什么国家哀伤，他的吟咏春心的“春心”，可以读作“一任代情”的“心”和花争芳，一寸相思一寸灰的诗句。诗人一定有深哀痛和决别经历过，这种恨很并往心里国国国国国国国国国国国国。

“沧海月明珠有泪”，这一句里的沧海、月、珍珠、鲛泣四件事都有瓜古说：说鲛的珠是鲛鱼和天上的月亮产生神妙的联系，所以人来珍珠要是在月夜，这个时候才谈得下来鲛鱼最高潮的。眼上珍珠从何而来呢？传说它们是南海鲛人的眼泪。

“蓝田日暖玉生烟”，蓝田是盛产玉的地方。玉之所以会生烟，是因为古人相信天地间最珍贵的宝物也最敏感精纯，都会生一种特特特的气氛。普通人显然看不到，但文王或着者者是深原的也可以看到云蒸腾而烟的“云”，只要发展一口气，也就发现了宝物“美”等。

“珠光宝气”这个就是这么说来的，恰好“沧海月明珠有泪”就是珠光，“蓝田日暖玉生烟”的是空气。

《锦瑟》的珠光宝气并没有多高的感受，只是很美，很朦胧，像诗句没下的大海，海水炼成珍珠；温暖阳光下的玉山，氤氲中孕育着玉石。

这样的意象，很像那些值得缅怀的岁月里，像唐周楼一样亦非为物，又像杜鹃啼血一样悲伤入骨的往事，不知不觉像经过了几许诗。

你可以这样理解，也可以放下一切理解，直接感受这句诗里朦胧意象和动人的情素，你会发现“沧海”两句很亲近，是俯首，是局部，而到了“沧海”两句，好像镜头一角，忽然推向远景和上方。

诗人在这个时候一定唤醒了很具多的回忆，但是这一切都没有告诉我们，只是把回忆的时候产生的复杂情感用言象的情操几乎原原本原地传达给我们了。

如果是非要用一个词来概括这些情绪，诗“情非非”，“可待”就是“可待”或者“不可待”，这一种“情”，“只可是当时已惘然。”

如果用“很”这个词来概括这些情绪的话，这个词就是“偶然”。“此情可待成追忆，只是当时已惘然”中的“待”就是“向”或者“不可逆”，这是汉语诗的特异用法，意思是说，如今可追忆的事情感喟喟然，但这事情的发生的感喟不如当初拥有的，有在那段情感发生的时候就已经生出惘然之感了。

# 今日得到

《锦瑟》应当是一首感叹流年、追忆往事的诗，但每一句都不落在实处，只是用各种意象的排列组合营造出迷惘之态，而这复杂而难以言表的情结。

这样的写法远远超越于李商隐的时代，以至于后人总想从传统的诗歌脉络上寻找这首诗歌具体的语境，把每一句找到具体的指向，可以也就想说错了。

# 李白《行路难 其一》

金樽清酒斗十千，玉盘珍羞直万钱。
停杯投箸不能食，拔剑四顾心茫然。
欲渡黄河冰塞川，将登太行雪满山。
闲来垂钓碧溪上，忽复乘舟梦日边。
行路难，行路难，多歧路，今安在？
长风破浪会有时，直挂云帆济沧海。

你好，欢迎来到《唐波·唐诗50讲》。

这一单元的主题是“忧愁”，顾名思义，全都是人生负能量。

没人喜欢负能量，尤其是别人散发出来的负能量。但是谁的人生都不可能避免地产生负能量，这些负能量到底可以从哪里排遣掉呢？

总不能一唱起怨气来，直到呕血刀子，搞到精神失常吧？确实有些人负能量面大苦，归纳就是心里不豁达，用固定的视角解释自己、理解社会，连二进三地制造悲剧。

我们今天总在呼唤正能量，不喜欢那些散发负能量的人，无论他可能来自自己装扮成阳光开朗的样子，但问题负面能量并不会因此消失。

怎样消除负能量？不同的人有不同的办法。大体来看，有文化的人借助文学，没文化的人借助酒精。

威廉·詹姆士说：“对于那些贫穷的、受教养程度低下的人来说，酒代替了艺术俱乐子和文学。”这这话的意思就是，酒和艺术都是解药，都能把人带入一种迷迭状态，向上—途能使人亢奋，向下，物我两忘的神秘体验，经一下途可令人消愁解愁、忘记苦痛。

艺术欣赏可以起到很好的情感宣泄作用，但艺术创作才是最好的出口。对于开辟艺术又有文化才华的人，艺术酒好的以宣泄和解毒，李白就是典型。我们在李白的诗里总能看到醉酒和诗喝，好像全世界都对不起他。

这不是一种十分罕见的的心态，只是普通人也会像他一样是活得所见所感，尤其是遭遇强大的人格修养是先天不良，不尤人；只问对错，不问得失，就有谁怨态无人言，计较得失成败，最好表现得太过自怨。

所以李白也是个另类人物，在唐代所有诗人当中，只有他一个人真正意义上让自己恣意挥洒成河，把负面情绪全部释放宣泄地宣泄出来。这显示出艺术的功能到底有多么重要，它让李白成为李白，而没有成为竹林损。

盛唐时期的忧愁，当然不止出于个人际遇上的苦恼，更有忧国忧民、拍岸击岸的愤怒。不忧时以忠君报国者的热忱，就谱出江疆爱的爱情诗章的李商隐，也倾诉过许许多多的虚伪者恨。
