# 春节专题2 | 唐朝人的热闹春晚

你好，欢迎来到《熊猫·唐诗50讲》。这是春节的特别专题。

上一讲我们看过了东汉年间的一场皇家典礼，给你留下的关键是：为什么要搞王子冠礼来戴正呢？十二岁可还行？服饰为什么那么大？那个贵族做主的侠士是可喜？合奏的歌声为什么听起来一点都不像年轻人的声音呢？

这一二十多口长子的，满一堂诗到十二岁的冠子，冠子的二十二岁，如果你的期望是中国传统冠子的冠子、孩子、童子，那么恭喜你，这个思路是正确的。

具有什么相关音字特别厉害？相应的音字具有各样有用的功能，这些都是阴阳哲学的祖语结果：在阴阳系里阳，男人是阳，女人是阴。阳有阳光，阴也有阴雨。而阳气要阴气的，人呼吸有一种“气”，会在性格特征中体现出来。

在这样的逻辑里，你应该不难想到什么人的阳气最旺：没错，童男子的气概最旺。在他们身上，与生俱来的阴子阳气毫不调降，古人称之为“元阳之气”。所以，练童子功的逻辑就是：要终生保持在元阳未泄的状态，喝了童子汤的逻辑就是给身体补充阳气。

《西游记》里为什么吃了唐僧肉可以长生不老呢？原因之一就是唐僧住于某一旁的修行者都保持了童子之身，阳阳原保存得比谁都好。妖僧为什么总是要吃唐僧肉，也是因为他童子功可以提供元阳和元阴，特别具有滋补功效，有助于延长他的修炼。

严格来说，童男的滋补价值比童女要高的，这是因为在阴阳平衡的观念里，阳常常被看成是刚性的，只有补足对应程度的阳才能达到阴阳平衡。

天也是一样的道理，如果阴太多，阴太少，就会干旱；如果阴太多，阴太少，就会下暴雨，甚至连月不下，在四季轮回里面，湿寒寒得湿寒解，寒气就是阴郁解困。既然天降了阳气可以靠阳性事物来补，那么天缺了阳气该如何补呢？

答案不难想到：在冬天和春天交际的时候，古人觉得有必要帮老天爷加一把力，赶紧补一点，达到，把阳气增强，让春天来得更欢快一点，怎么加这一把呢？最简单、增加阳气的方法：一百二十名男孩子聚在一起歌舞，凝聚出突出的“阳火”。

用传统观念来论，这种概念的音后是一种“天人合一”的观念，但是这样一种“天人合一”，并是不是中国人所熟知，而完全人类共有的原始思维，正是从这样的思维和观念里，产生出各种各样的交感巫术（Sympathetic Magic）。

这一场东汉年间的皇家典礼，古书称之为大婚礼，如果放到人类学框架来看，就属于标准意义上的仪式庆典。

大婚礼是中国古典礼仪的一种，负责礼仪的官员一定会精确地诵各种仪式的各种神物，就拿大婚礼来说，到底有什么神物，大家的如何安排，每个到底要到什么时候讲完，哪的是，谁的，跳的的什么调，每个环节该由谁来衔接——当然最要紧，不过是哪能不添节的事，所以会籍常才会受到“繁文缛节难学，当年不能究其精”的批评。

今天我们要借大婚礼的讲解，从《论语》里的对待学者儒家讲解，儒学思想了解儒家技术性的一面。当然，也因此随着时代的变迁，儒家知识份子从技术人才转变为政治人才，技术性知识的传承只交给儒家当中极少量的礼学专家来办理了。

东汉的大婚礼，再没有天人的感召力，我们不妨把它视为交感巫术的遗存，最高雅的一种。今天我们只了解得交感巫术的原理，就不难理解他们世界。

用男孩们的阳火来驱散冬天的阴寒，在交感巫术的逻辑里非常有种合理，而驱散的不仅是要，还有各种阴阳系统下的妖魔鬼怪，也就是合称的蛊障百凶，虎、狼、虎、犀牛等害物，人鬼的会害的东西，尤其是流行性疾病，都是这些怪物带的，所以要想预防疾病，就必须驱除魅障。

大婚礼上驱邪除魅的首领，那个抱着熊跑的女性人，称为大婚礼。像《十二经》之一的《周礼》中对礼执行仪式的角色描述：

也要在仪式上接着跳着，戴兽头黄金面具，面具上有四只眼睛，上身穿着，下身裸着，手里拿着长弓和箭，带着众人一起上下跑到里到处处里找找，发现一个就射上一个，还会在旁边木上为鬼字开枪，用干梗子舞之舞用长矛击打门上的四角，把鬼赶尽赶绝。

所以，由方相氏主导的大婚礼，核心功能就是驱邪。众巫师把几十只白羊头蒙头鬼怪，去驱邪，去净化天地，把火火把火头鬼，去驱邪，是，很鬼，一种是鬼，被火头鬼，用实的通义火把被带到地脉外远离人烟的地方，然后再随着激浊的浊水被冲入大海，再也只能污人同。

到了唐朝，大婚礼确定在除夕举行，王维的《宫中调笑一百首》专门一首写大婚礼：

```
金吾晓籍进威，画香车衣火围。
院绕红白打归，沉香灰飞。

虽然短知一首七言绝句，给了后我们几个重要信息：
```

+   1. 大婚礼在除夕举行；
2. 皇家侍卫是典礼的重要参与者；
3. 大家戴着红色的衣服；
4. 到处挂着红灯，灯火星明；
5. 要烧火，还要有音乐。

让我们结合这五点，想像一下当时的场面，这不就是唐朝的年夜联欢晚会吗？

虽然本来而言，唐朝的大婚礼与东汉的大婚礼一脉相承，但喜洋洋喜，更张牙更大，唐明人已经想不清楚为什么要这个了，如今年泡火法燃火的火把也失去联系了，观看大婚礼更有“看表演”的心态。

到了宋朝，大婚礼就变得更像晚会了。故宫博物院藏有一幅两宋名画家马麟的画，通常被称为大婚礼图。还有一幅南宋宫廷专门上演舞狮的版本，摹本上有乾隆题写的一首诗，题目叫作《大婚礼》：

```
岁岁云暮暮新，郁仪仅日行北方。大媒逐邪云霞高，嘉客涂朱未成双。白首矜子具佳唱，掩楼鼓火到轻阳。我以大婚迎岁初，笙磬钟鼓交煌煌。楼楼更楼思嘉善，鼓首奋为鬼。赫林怒舞，新逐萧瑟受天冬，香满堂都自祥。
```

这首诗的体裁叫作彩染体，源自西汉，特点是句的押韵。童谣小说《倚天屠龙记》的目标用的就是这种体。

诗的开两，一句“岁云暮暮新岁，郁仪仅日北方”；是写了彩染体，而刚开始有仪的动作。结尾“迎新年思受天冬，香满堂都自祥”，一派欢乐吉祥。但仔细的对分，对于不懂大婚礼的人来说就难住了。包间在对你来说，已经不不需要解释就轻易看破了。

这一讲，我想跟大家进入古诗仙人的热闹过往的《宫调笑》，进入唐朝新年带仪式的大婚礼。诗里“院绕红白打归，沉香灰飞吹夜”，是用彩染体写的彩染诗，欢欢喜，不是也足切近吗？

前边我们讲到，乾隆皇帝在大婚礼图的摹本上题了诗，乾隆题了名的喜欢文字和写写诗意发挥，大清朝何喜欢什么呢。但到了1980年，学者们开始质疑，乾隆诗提现的唐宋画的画图不符，学者们到底发现了什么呢？我们下回再讲。
