# 08 杜甫《咏怀古迹》I 昭君的尊严和代价

杜甫：《咏怀古迹》（其一）

群山万壑赴荆门，生长明妃尚有村。
一去紫台连朔漠，独留青冢向黄昏。
画图省识春风面，环佩空归夜月魂。
千载琵琶作胡语，分明怨恨交在论。

如果有一个能决定你一生命运的机会，而需要你稍微下那么一点尊严，向一个无耻小人脸上笑笑，打点金钱，你觉得这是一桩难事吗？如果是的，你愿意去死还是苟且呢？

如果有一家公司，只要脸下点尊严就可以换来多年死战的高昂薪水，你这样做法能算吗？

如果有一个国家，只要付出一点尊严就可以换来和平，你觉得这样的尊严不应该放弃呢？

有一位历史学教授将这三类难题于一身，它就是我们所知晓的屈原，

这三类难题当出，

给了诗人们一个绝不会有的舞台，让各种种烈的见解在激烈的诗话的包围下争夺升斗。更问汉王昭君的美德的诗歌，其实也是诸多知识分子或多或少或都听过，或者必将面对。

我其实王昭君的苦难，如果剥开各种高大上的标签，倒倒都是一个很普通也很经典的职场难题，在历史上两个非常有代表性的，职场和戏是同样玲珑的两种话语，但确是种截然不同的视角。

# 1. 昭君怨

王昭君是在汉元建朝年间被选入皇宫的。如果得到君主的是欢宠，她就会被从宫女提升为嫔妃，从此彻底改变命运。但后宫的女人实在太多，汉元帝老着看不过未，只能安排宫廷画师给众人作上画相来看，所以选的肖像越得美些，谁能得到君子的恩德。

既然女人们也运算是画师的手里，地位卑微的画师也就有了权力扣制嫔妃者。主动巴结送礼的女人可以享受美颜的待遇，至于那些不倾慕的女人们，自然会受到画师的歧视。而汉朝后宫女子，大多都是没有得到皇帝的宽幸，而青春是不会等人的。

到了竟于元年（公元前33年），匈奴单于呼韩耶（hán yú）向汉室示好，提出和亲的要求，正常情况下没有哪个女人愿意远嫁到荒边。但王昭君主动请缨在昭君出塞里置的史实，她更希望抓住这个机遇，赌一下自己的命运。

汉元帝是是不得已要有这样一个深明大义的女人出嫁，当他真正见到王昭君的美貌时，才后悔已己被当掉。不过王昭君已经来不及反悔了，王昭君在汉成帝时期出，于是有了昭君出塞的故事。汉元帝怒想越气，杀掉了画毛延寿为首的一千家奴。

王昭君从此没有再回过家乡，死后葬在塞外原庭。她的家乡称为木源，如今已经是内蒙古的一个游历胜地了，虽然这些细枝节都不起太大的作用，但汉并不重要，更重要的是，历代诗人几乎都是从这样一个故事来理解王昭君的。

如果站在人物的角度，把王昭君的人生当成一个范本的话，你会得到怎样的启发呢？

我可能有些一些人，王昭君刚到皇宫的时候，只是稍微稍一下拉上眉，大庭下让宫廷画师好处，轻松就能获得美丽的人缘。那时候还有机会出身边治那些世家，当初的一口正气也就可以有了，用不到去和谁。

但是，站在古代读书人角度，王昭君的坚持实在有特殊意义的。清人吴曼容几句讲得特别到位：

‘不花臭买画工，进争着与自谋同。如知绝代佳人意，即若有千秋国民。”

诗的题名叫题目《明妃》，是因为避宣帝司马昭的讳，把昭君改叫明妃，后人因此称她为昭妃。

诗里所谓‘自谋’，自顾名思义，就是自己给自己做媒，不经过中介者主动同意中人求媒，从简家礼来讲，这纯属是不合规矩。好似要听父母之命、媒妁之词，半也不能主动。

读书人何苦是一样道理，要等着有人发现你的才华，专程来请你，

你若偏解一个人来请你，你就一辈子不去做官了，绝不能自己主动去讨官职。所以，谋者人以加解者，其实就属于莫不要的自媒行为，作为君子所不达。

但县，自从商朝科举制度以来，一直到古代社会终结，科举偏偏都是主要的人才上升通道。如果个人不去努力竞争，大概率上真就一辈子没机会。

这就容易让读书人有种种精神分裂：一方面儒家经典熟透决不能是加样精，另一方面画家家里边点黑历史，明确反自媒当自的。

人要知道识，‘和’和‘行’就瞬间就分开，本书想讲成汉语成汉和就如此，时间久了，大体就只形成对成风俗。王昭君提的‘和行合一’，意思是在成汉的这种风气，更大家用真诚的态度对待书法本身知道。

而王昭君不过是诗史时代里的名弱女子，却甘默以自毁生为代价，甘愿就死于那些画家和朝廷的共同中。这样的情节是出于某些目的，即使全书会有格调做天下读书人，‘手手和千载’争锋。读书人在前面，总带着些愤愤和惭愧的。

吴曼容的诗还有后面四句：

‘环佩几曾归夜月，琵琶谁许诉无鸿。天心特亦留胡塞，春草年年汉汉。”

这是说他若开关宫之西，就魂语也不曾回来过，说一声，一生之情只得魂飞在琵琶里面，徒劳地付给南飞的大雁。当昭君死后，上天特地把她的坟塞在汉地青，每每都墓丛生的景象仿佛是汉里的样子，这是对他的恩眷了。

单章来看的话，这是一首很好的诗，但是经如潮人写的很多诗一样，是从中讲道德变化来，因此可以说是杜甫《咏怀古迹》第三首的回应。

# 2. 豪杰昭君

杜甫的《咏怀古迹》一共五首，第三首怀的就是王昭君在杜甫的故乡，村子里已经改名为昭君村了，是这样写的：

群山万壑赴荆门，生长明妃尚有村。
一去紫台连朔漠，独留青冢向黄昏。
画图省识春风面，环佩空归夜月魂。
千载琵琶作胡语，分明怨恨交在论。

浩瀚笔气就极雄厚，昭君村的附近有长江三峡和荆门山，在两岸的山群里，随随着高山深流的群山方物仿佛是千里来归山，所以在这样的奇绝地势上，还可以看到昭君生长的那座小村庄。

不觉得杜甫这样的写法有什么奇怪吗？难道描写一代尊贵的美女，不是用更典雅的环境来衬托她吗？如果像张‘留’村‘昭’村’，按下来好像说‘长江’还是‘万山’更好？‘长明妃’还是‘村’相搭配，杜甫就是这样，他并不把昭君当作弱女子，而当成英雄豪杰的。

第三、四两句，‘紫台’代指皇宫，‘去’是‘离开的意思。昭君一‘去’宫出舍永别，‘独留青冢向黄昏’，一个‘出’字含意思是余。

接下来写汉元帝只肯信赖画师判是非，致使昭君永远离开了故土，只有魂魄在月色归回。昭君只有借琵琶弹奏胡音，与琵琶是胡人的乐器，曲也是胡人的旋律，就哀哀悲泣诉。

杜甫的《咏怀古迹》是一个‘怨’字，但昭君怨恨一注定满怨恨，怨怨恨定深，他也一定思念故乡。

因为杜甫就是这样的人，所以他以这样的情怀来理解昭君。

另一位诗人与杜甫有不同的看法，他在这里说：

‘莫怨只身人画卷，莫留明主道中来。当时若不容胡汉，只是宫中一个美人。（‘解妃’”

意思是说，昭君不该怨命，如果不是远嫁和胡地，和胡地人心心相悦，终干过了开心的日子，凭什非要苦命故国不可呢？

王安石把心相如同为进退取舍的基准，这在古代史里面也见多的。

从王安石的反应中，我们能够看出杜甫诗歌即是对英雄，对弱家的什么情操，因为杜甫的诗歌中，也是常理要面对什么，请会在历代被作为诗歌意境形态上的最高典范。
