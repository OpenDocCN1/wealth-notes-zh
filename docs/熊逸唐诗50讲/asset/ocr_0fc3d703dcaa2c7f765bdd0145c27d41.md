# ## 白居易《长恨歌》

汉皇重色思倾国，御宇多年求不得。

杨家有女初长成，养在深闺人未识。

天生丽质难自弃，一朝选在君王侧。

回眸一笑百媚生，六宫粉黛无颜色。

春寒赐浴华清池，温泉水滑洗凝脂。

侍儿扶起娇无力，始是新承恩泽时。

云鬓花颜金步摇，芙蓉帐暖度春宵。

春宵苦短日高起，从此君王不早朝。

承欢侍宴无闲暇，春从春游夜专夜。

后宫佳丽三千人，三千宠爱在一身。

金屋妆成娇侍夜，玉楼宴乐醉时醒。

姊妹侍官皆赐号，可怜同恨独生前。

遂令天下父母心，不重生男重生女。

骊宫高处入青云，仙乐风飘处处闻。

缓歌慢舞凝丝竹，尽日君王看不足。

渔阳鼙鼓动地来，惊破霓裳羽衣曲。

九重城阙烟生处，千乘万骑西南行。

翠华摇摇行复止，西出都门百里的。

六军不发无奈何，宛转蛾眉马前死。

花钿委地无人收，翠翘金雀玉搔头。

君王掩面救不得，回观血泪相和流。

黄埃散淡风萧索，云栈斜阳登剑阁。

峨嵋山下少行人，旌旗无光各零落。

行宫见月伤心色，夜雨闻铃肠断声。

天街踏尽同庭树，此度陇桥断肠死。

天长地久有时尽，此恨绵绵无绝期。

# ### 生僻字读音备注：

惊破霓裳（cháng）羽衣曲

花钿（diàn）委地无人收：钿有读音，在《现代汉语词典》里，当首饰时读diàn，当装饰时读tián。但在古代通韵是常相反的，花钿读diàn，但在，细读钿tián才合乎规律。不过这读法依然沿用的标准读diàn。

翠翘（qiào）金雀玉搔头

云栈萦纡（yū）登剑阁

金阙西闻折玉簪（jiāng）

转教（jiào）小玉报双成

钗留（bà）黄金合分断（diàn）

# ## 用户留言

Ernest \n配乐好到，随着故事感起伏起伏，引领读者在诗境中穿越时空。无限的美感、无穷的悲伤，穿越了时空。 \n20

曹建华 \n《长恨歌》之所以能够被广为传诵，原因是当时读书人群体的变化。白居易的诗写得比较通俗易懂，适合各阶层阅读。大诗人赞白居易在《论艺诗》，称其"言尽意而未尽，妙语含蓄中"。白居易诗通俗易懂，故能"老妪能解"，但气格雄远。 \n16
