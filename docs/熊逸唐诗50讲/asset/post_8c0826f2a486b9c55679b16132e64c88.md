
# 14 李硕《古从军行》：士兵必须承受的残酷代价

野云万里无定所，雪风惊沙暗交漠。
胡雁北飞飞度雪，胡儿牧马马如龙。
闻道玉门犹被遮，应将富贵逐轻生。
年年战骨埋荒外，空见蒲海入汉家。

李硕《古从军行》（摘录）

### 1. 朋友圈和私聊到底有多重要

李硕有一篇《致陈行》，总结了自己的前半生：

小来未身景穷通，须髯被无两所依。
暮春经过石漂旁，朝阳入过龙须泉。
结交社陵轻骨肉，调首岂宜生死。
一寸心无时有，肯向斯生取利。
男儿立身身自须，十岁千顷水田。
成败须见成败，击锋须见血。
二八娥峨娥娥，美须须食。
文官言词强权，长官喜信侍郎。
五皮皮从中解衣，三省省省省省省省。
早知今日读书事，悔作从前任性。

### 2. 热性诗人的不计代价和老成人的蜘蛛必较

《古从军行》问的是国家打这样的仗值不值得...（后续为长段落）

这样一位成者诗意的诗人是能和个人的两个层面彻底相融并相融的诗人，他能够敏感自己的诗，让想象的中心和热如的社义和社会一构类冷冷地下来，想一想一个美好的社会和个人关系的人生究竟应该是什么样子，想一想为了释放社会心里不承认我的承担不起的代价。
你也许会一度觉得自我的迷恋，但你会测别着这样的状态一定非现实的意外空间。

偏偏不是。李陵和杨柳相视成双，但也相格不一，从来没有谈诗名实真实了的战争生活，所以这样的诗读得是真实浪漫，但诗里所有的意象都来自想象和书本。

我们总是以诗为艺术来源生活，其实不完全是这样的，艺术也来源于想象和书本。

正如哈姆雷特的一句话：“即便被困在一个小小的贝壳之中，我也仍会把想象成无限广阔的君王。”这句话可以当成一切诗人和艺术家的创作宣言。

那些将书本可以极大约来描述到想象界里，便想和现实世界的矛盾和困扰，可以超越现实世界之上，用超越的视角去观生造生，并可以对生活。
一切缺少超越感的东西，都不可能是诗。

## 今日得别

李陵尽管没有交去过边塞，写过的边疆诗句之一，却是唐代最优秀的几位边塞诗人之一。

李陵凭借想象和书本，走上了和杨炯相反的创作道路，以未体验的姿态去揭示心地的代价，揭示社会的现实。

# 15 李白《侠客行》：侠：游荡于自然和文明之间

![](img/3e79664a0fdf78f5bd10a506f1206c1a_29_0.png)

李白《侠客行》

> 赵客缦缦剑，吴钩雪霜明。
> 银鞍照白马，飒沓如流星。
> 十步杀一人，千里不留行。
> 事了拂衣去，深藏身与名。
> 闲过信陵饮，剑赴燕市。
> 三杯吐丹心，五千报一饭。
> 易水歌易水，风歌歌易水。
> 纵死侠骨香，不惭世上英。
> 谁能书阁下，白首太玄经。

你好，欢迎来到《熊逸·唐诗50讲》。

李白的名作《侠客行》同样是一首很让人血脉贲张的诗，是对任侠精神的极致表达。

说起古代的任侠精神，和今天你读小说里的样子有些不同，更在意息怒是非，重义轻生。人们对较劲的生活方式中有一种天然的渴望，不喜欢野马的合法生活，所以侠客多生作为两者的折中，格外让人憧憬。

这个道理可以从今天的 学习方式看出端倪。今天几乎每一位家长都操心孩子的学习成绩，怎样提高成绩呢？

我们可以听一句话：“兴趣是最好的老师。”所以，培养孩子的学习兴趣是一件迫在眉睫的事，但说来容易做来难，这个兴趣实在不好培养。

如果我们作为成年人很难提起对上班的兴趣，就说没存够格资格孩子学习提不起兴趣。回看一儿们的童年时代，读书上学分明是一桩苦差事，尤其是对于男孩子们来讲。

从本质上讲，读书上学就是一件逆天的事，是文明的进程迫使我们不得不如此。而在我们的天性里，学习其实不是自然而然的习得结果，各种知识的获取在自然状态下，耳朵和嘴巴是一回事，用相同的方式获取对生存所需的信息。从这个角度来看，孩子之间的打闹斗非但不是禁止，反而应该得到鼓励。

但文明的进程给我们戴上了太多太重的枷锁，让我们必须放弃以天然为自己天性，让自己驯化的孩子 同时充当文明的社会人。因为反性的程度越高，在文明社会里的生存就越容易。

有些天性很强的人很难忍受这种枷锁，因此提出了解脱的，回归天真的主张，庄子就是他们当中最核心的一位。

每一个时代，都有很多人对庄子的学说深深敬仰，像渊渟岳峙的大儒说：“久在樊笼里，复得返自然。”（《归园田居·五首之一》）文明就是樊笼，摆脱文明的干扰才能返回自然。

但吊诡的事情发生了：只有那些聪明绝顶、又高度文明化的人才产生这种觉醒，在他们产生对文明的觉醒之后，又难得在舍弃文明思维上超越那套文明的装饰语言，比如让深渊而不写诗，这就很难。

所以最渴望的生活是一种适度的放任，是文明和自然的中项。而最理想的是哪一种生活方式和性格，毫无疑问，就是侠客，李白的名篇《侠客行》写的就是这样的角色和这样的生活。

### 1. 任侠精神的心理背景

《韩非子》“有一句话”：“儒以文乱法，侠以武犯禁。”这意味着，并不是借道德，而是试图一切掌握了文化与能力的人。

《韩非子》推演的逻辑，用今天的话来套就是：无法无天，做了什么不能，他做了不能做的事，要受到怎样的惩罚。

但无奈文化了一个巨大的弊端，那就是无论官方还是非官方有文化，只要人 有足够文化的文，就有足够机会来钻法律上的空子。这种乱象先秦到西汉，从 来没有 断过。

侠客走的是另一条路，仗着自己武艺高强，不把法律放在心里。虽然偶尔义气汹汹，仗着 自然不反着，侠的做派突然向人发问。之所以有这种关怀的原因，是因为我们都 在本 质上都是朋友，心底潜藏着我们纯净的 本我。

天然的情感会违背社会文明社会的各种规范，比如受到欺负人的冒犯，天然反应一定 是毫不 妥协的 互相残杀，而非 克制 的忍耐；起冲突，等待漫长的 法律程序；如果你 的 最好 友受到 侵害，你的 天然反应 一定会帮，谁都不会 反应 这种要求。

这样的天然情感尽管早已被文明驯化，却始终 潜伏在我们心里，所以直到 今天，我们还 会对侠客 的故事心 神颠倒，被《侠客行》这样的诗歌 深深吸引。

> 赵客缦缦剑，吴钩雪霜明。
> 银鞍照白马，飒沓如流星。
> 十步杀一人，千里不留行。
> 事了拂衣去，深藏身与名。
> 闲过信陵饮，剑赴燕市。
> 三杯吐丹心，五千报一饭。
> 易水歌易水，风歌歌易水。
> 纵死侠骨香，不惭世上英。
> 谁能书阁下，白首太玄经。

这首为剑为金庸 同名小说的缘故，变得广为人知。

诗里描写一位赵国豪侠，因为赵国有袒露时 的，所以位侠仗剑杀 白，敲 击 剑风 的，替，侠仗 剑杀，义侠义侠，杀 白，敲 击 剑风，侠仗 剑杀，义侠义侠。

至于人群，尽管更多时候担心同情，好奇是发生在身上，因为人们这样的感情来得更加自觉，更加符合人性的本真。

“报答知己，快意恩仇”的抱负，就是所谓一“敌志必偿，冤仇必报”。

做个江湖侠客，在人情淡远社会得到他们的释放，让内心的准则而不是太多的藩篱成为自己唯一的遵循，这是多少人想做却做不到的。

## 今日得到

侠义精神强调心理基础，也会有社会基础，前者直至今依然广泛存在，后者却已经随着文明化和法制化的进程渐渐消失。

纯粹的文创让生涯重新压抑，压抑的自然生活又显得过于野蛮，所以人们常常游荡在文明和自然之间找一个平衡点，过一种适度的角色和生活，而最能体现这样一种生活方式的意象，就是侠客。

李白在《侠客行》里半是地带着吹捧生语，诗中的侠客有这样的六个特点：报答恩仇、快意恩仇、不矜小节、一诺千金、淡泊名利、重义轻生。前三点比较常见，后三点则相对少见，这三种生气的出现关系恰好体现了文人江湖的折中。

# 16 李白《结袜子》：豪情背后的知遇感恩

朗读：唐诗50讲

16 李白《结袜子》豪情背后的知...

```
「李白《结〔ji〕袜子》
燕南轻丈莫门客，筑中留白倍伤心。
感君恩重许命，泰山一掷轻鸿毛。」
```

你好，欢迎来到《唐诗·唐诗50讲》。

唐朝人特别喜欢歌颂知遇之恩，你觉得这是一种文风问题？还是还是看现实，很功利的用心呢？这个问题在《侠客行》里不容易看明白，这一讲，我带你读李白另一首歌友题材的诗：《结袜子》。在这个题目里，“结”的“结”应该读成“系鞋带”的“系”，“袜子”就是“鞋袜”，“结袜子”，是把松掉的袜带系紧的意思。

### 1. 袜子里有深意

《结袜子》，这个题目相当古怪。看完全诗，你也找不到任何一个和袜子有关的内容。这到底是什么意思呢？

因为这首子并不是李白的原创，而是来自汉朝的乐府旧题。后人常常沿用汉魏乐府的题目，乐府的题目通常有特定的主题，后人沿用这个题目的时候通常也会写同样的主题。

元末明初的刘伯温，这是大家都很熟的历史人物，他也写过一首《结袜子》，劈头就说：“昔有游侠客，冠盖尘埃黑”，然后说“袜结”“结”在袜子上，然后说“君子不结袜”，“结袜”，是朋友之间的亲密表现。

讲完这个故事也讲完了，感觉说：“千古不可复，安独怅人奇”，“我”多么希望，感叹今天的朋友和古人风范不会存在于遥远的古代，如今完全不见了。

我读这首诗也可以叫《侠客行》，可是逐字逐句读下来，神秘的袜子依然缺席，还是要回到《乐府诗集》，看看题目之下的解释了。

《乐府诗集》收录“秦王出”，说燕太子讨伐栗侯的时候，有有一天晚上的太子讨伐，左右看他，找不到人来帮忙，只好自己弯下腰，把袜子系紧。而盖武王伐带手下的臣子，在燕王太子去手武王时，夺了手武旗帜，忽然发喊，让太子结，身边人才帮忙，只好放下旗帜，自己提紧袜子了。

古代的袜子和今天不同，是有鞋带一样的带子，需要束紧才行。另外，身份高的人不给自己系袜子。

《汉书》《张释之传》有一段记载，说汉朝名臣张释之担任士卫，有一天在正式场合，朝里的达官显贵都在，王生忽然说自己的袜子掉了，叫张释之给他系好，张释之当即跪下来，给他系好了袜子。

后来到有人批评王生：“你太过分了吧，怎么能让大臣来给他系袜子？”王主回答说：“我年纪已经这么大了，身份也很低微，估计没机会让大人给我系什么了。张大人天下有名的敬重人，在皇上大臣之间，张大人能得到上下的敬重，以结子为例，是从自身形象的牺牲，张释之来取形象，这在重视名节的人看来，实在是难能可贵。

所以《结袜子》的主题是说人的遇合，借张释之的故事来说，李白的《结袜子》把整个主题写得更加明确：

```
「燕南轻丈莫门客，筑中留白倍伤心。
感君恩重许命，泰山一掷轻鸿毛。」
```

在前两句里，“燕南壮士”对应的是“筑中留白”，“莫门客”对应的是“鱼腹”，分别是先秦传颂的两个侠客。

荆轲刺秦王的故事是大家都熟悉的，荆轲路上送行，途径易水的时候，好友高渐离为他击筑送行。

筑是一种打击乐器，高渐离是当时首屈一指的击筑名家。荆轲刺齐失败，秦王统一六国后，战乱并没有达到结束，秦朝需要更借用燕的高渐离，他救不了的他死了，但救不了他的双股，让他为自己击筑，高渐离暗恨，筑，筑的时候故意放箭朝秦始皇，可惜手被砍。

“莫门客”说的是春秋时代的吴国刺客专诸，当时勾无义利是吴王阖间专诸是专诸，但吴王做危险任务，这就是需要既有不常有妙处的方案，还必须有用命博命的必死之心才行。

公子专诸的专诸，就像刺客行动到鱼里那样，专诸是先说鱼，把刀藏在鱼肚子里，成功刺杀了吴王僚，但自己也当场被攻吴王的武士杀死。

这两个典故，古人可能会会有各种解读，也许专诸杀吴王是“知恩图报”——吴王给他赏赐，专诸杀吴王是对恩情的报答，也许是报答知遇之恩的的举动，但性命交给了君王，这多一种荒唐的忠？

但李白不在意这些，他只在两个典故最美、最感人的那一环，那就是“感君恩重许将命，泰山一掷轻鸿毛”。

家中人会一定会受到如此之大的感动，甘愿为来人来效卖命，但除非义字之外，无论任何人都做不到。对，在那些英雄豪杰看来，他们甚至不会把一掷性命看得有多重，在他们看来也不过如鸿毛，随随便便就可以舍弃。

### 2. 求知己

但李白仅仅是写侠义吗？未必。唐朝以科举取士，类似写了一个很公平的考查，但唐朝的科举绝不是考单纯的眼战技巧，考生还必须能向皇上或达官，推荐各种达官显贵文人交友的门路，获得成事的机会。只要关系能打通，几乎就算成功了一半。
