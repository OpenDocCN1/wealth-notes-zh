# 春节专题5 | 犯太岁和本命年

![](bbox=[0.03, 0.055, 0.96, 0.085])

你好，欢迎来到《熊斋·唐诗50讲》。这里是春节的特别专题。

春节里你会常常听到两个涉及禁忌和忌讳的词，一个是犯太岁，另一个是本命年。这两个词，我从未在历史和文化的语境，给你讲讲这两个词的故事龙还来呢。

上一讲我们说到，如果人生不偏房，偏要在太岁头上动土的话，首先会遭到凶兇的关照。若前两边不忘记载，首先，在动手的过程中，会给出一个活生生的太岁。那么问题来了：既然太岁只是一个想象出来的天神，为什么能被人从地里下挖出来呢？

你一定很好奇，这个被挖出来的太岁到底长成什么样子。

简单讲，它就像一块肉肉，所以古人也称它为肉芝、肉团、匿名老肉，有像肉如肉，但不入药，如肉如团，肉芝者似，也有书上叫它肉菌人，聚肉。它又软又嫩，是个活物，有胆大的大把它切开来看，它自己复原。

这种东西是真存在的，「本草纲目》把它归为肉芝，归入芝类，和蘑菇同类。用今天的分类法来看，它是介于真菌和原生动物之间的一种生物。

1993年9月22日，《中国地质报》报道了一件怪事：河北省易县容庄打工，钻进地下百多米的探眼，突然从钻孔中喷出很浓的红浆，在动土的过程中，还有人把肉挖出来吃了，也没吃出什么毛病。

我们来看唐朝人士的记载。唐朝的牛李党争是很多人知识深度，牛李党争中描写有一个「外」字，名叫洪诺，很有才气。张说写了一部《宣室志》，你能从本官里面读到什么？「宣室」取自汉武帝召贾谊坐前殿问鬼神，你可以回忆一下我们唐诗课第七讲的内容。

宣室里的对话主题无关乎政治，只关于鬼神，所以李商隐诗说：“宣室求贤访逐臣，贾生才调更无伦。”可怪无逢虚前席，不问苍生问鬼神。”

张说的《宣室志》，记载各种怪力乱神，读起来好像《聊斋志异》。书中说到一位讲道的手士，有一天修房的花园，讲到一个入手一样的怪东西。讲是太大色色，知道位置已动了，犯了这条禁忌的人会被出师房，预示着某场降福。

只要怎么办？隔壁户忽然想起，还有人，只要修房，就只能避开天降。事到说开，只好让怪手房把修房关死了。给来人意料，隔壁户竟然逃无果了。

这是一个处处生的例子，但更多的记载，却挖出修房的人都坏了大事，甚至被人伤亡。为什么会这样？

原因倒也不难解释，在阴阳关系上，木星在天空正面向生，大岁在地下反向运行，所以在天上能动的太岁能大岁，大岁就是太岁从天上来，但用了多年就人格化、实体化了，在人格化、实体化之后，也就自然有神力。

修房被认为是太岁神的化身，所以大岁太岁上动土，犯了大岁神，就意味着触犯天，太岁上动土，冒了太岁神，就意味着触犯上天。

今天普通人动土的机会已经很少了，你一辈子都不会“犯太岁”，但实际除了动土以外，还有不“犯太岁”的情事。

《孟子》有另一段名言：“天时不如地利，地利不如人和。”这是“在讲用兵之时。所天则时，唐到的是方解释是“天时所渭日、支干、五行、旺相（xiàng）、气运之类。”这是指吉年吉时的精确占算，只要有掌握了这些知识，才会知道在什么时间，从什么方向做什么样的动作才有的利。

行军也好，交战也好，让自己的军队避开太岁的方位，这是一项重要的天时知识。

中国人讲到兵法，人人都知道《孙子兵法》。但是假如你在读《孙子兵法》之后，想研读古代军事学，你会发现《孙子》能上谈兵，根本不知道指挥军队该如何下。

因为《孙子兵法》主要是对实战术则的总领，不具体在实战术略中，只送给那些已经有丰富作战经验的军官采合使用。所以《孙子兵法》做到，认为中国人在兵法上远远走在西方的前沿，这是一种错觉。

西方人虽然从长远没有哲学性的兵法著作，但凯撒的《高卢战记》、色诺芬的《长征记》都被奉为兵法名著，这两部书有丰富的战术细节可以指挥军队选择方向。

但是，也因为《孙子兵法》的哲学性太强，所以在远离军事环境之后依然很有生命力，这才是它的长处。

如果看我们一部古代中国正实用型的兵书，你可能会看明白《武备志》，厚厚的一大部书，既含军事百科全书，也是战场指手手册。这部书里，关于大岁之类的天知识占了很大的篇幅。

至于唐朝，出了一部很奇特的诗体兵书，叫作《兵要六》。作者是谁，用一个《江湖》词牌写了七百首，每一首都用一个有题目，多数内容和兵方有关。指挥官不仅看懂兵法，还看云天气象。关于大岁的一首是这么说的：

“今岁为相，太极一官。”
“梦君何如，假以本命年。”
“这些诗句是是乙意意思，现在现在已经得定了，但我们至少可以知道，行军打仗必须重视太岁。”

虽然今天已经没有人相信这些东西了，但是，太岁依然和我们的生息息息相关，这是因为在太岁和本命年的名词里，有人会有什么样的本命年，都是因为它犯太岁。民间还有一种关于本命年的谚语，你可能听说过：“太岁当头坐，无灾必有祸。”

本命年之所以流年不利，因为我们来看看本命年的“本命”是什么意思。

唐玄宗的宋代有一位韩相李国，因为怕李林甫的陷害，辞掉了宰相职务，为此写了一首很著名的诗《罢相》：

“罢职朝相和，车引到里门。
为问门前客，今朝几个来。”

诗意萧条，充满人世凉薄的感伤。而在诗的背后，李国面临季选子的计谋，正是利用了“本命”方法里的：

李林甫私下告诉李国，说华山有金矿，开采出来就为唐玄宗，李国很高兴，向皇帝献出建议。唐玄宗征求李林甫的意见，没想到李林甫说：“华山有金矿的事情我早就知道，但华山是下的本命年。开矿下界，不宜开矿，所以我才一直密报。”唐玄宗因此发怒李国，疏远了李国。

为什么华山是唐玄宗的本命年？因为唐玄宗的出生年支正是玄武，玄武属水，华山属金金，开金矿是玄武星的余气。开金矿是玄武星的余气。一语中，华山金矿破，唐玄宗本就该各种不不。

我们可以看到，一个人所适本命，是从占术的意义上市的。出生在本命年的方位决定一个人，是人的，那么出生年太岁的（或者说天下），对确定本命年来说有意义？

我们可以看白居易的一首诗，《七年元夕对酒》：

“今岁各言，相对一欣然。
梦君何如，假以本命年。”

诗题题目里的“七年元旦”，指的是唐文宗太和七年（833年）的元旦，按今天的说法就是立春，大年初一，这首首诗写的很明白，诗后边有个小注，说自己和刘黑籍同在一个年岁，今年四十二岁。

在第十二年的年纪遇“假过年”，显然不指本命年，而是把自己的年龄和本命年合在一起。以本命年（也就是人生本命年第二个子年），称为本命年。

你看，不光是现在的你，一千多年前的唐人也，就在留意着自己的本命年了。过年，我们仿佛就穿越回去了古代。

那么本命年的应该怎么办？下节课，我们就来给你讲讲古人的应对法。
