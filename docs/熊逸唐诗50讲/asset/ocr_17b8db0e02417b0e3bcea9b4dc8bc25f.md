# 46 太上隐者《答人》|真正的隐士这么活

# 太上隐者《答人》

> 偶来松树下，高枕石头畔。
山中无历日，寒尽不知年。

你好，欢迎来到《闲逸·唐诗50讲》。

这个单元的主题是“隐逸”。传统知识分子都要面对一个重大的人生选择：到底是“出”还是“处”（chǔ）。 “出”做官， “处”就隐逸。对这个选择必须做出反省，所以有一个词叫作“慎出处”。

按照孔子的教导，如果天下有道，就出来做官，勇承担社会责任；如果天下无道，你最好要去隐耳去，起门来就过自己的小日子就好了。

但问题是，天下到底是“有道”还是“无道”，往住不那么容易分清，因为“有还是无”是一种审美判断，更是一种价值判断。价值是高度主观化的，大家很难达成—致。

比如前面讲过的伯夷、叔齐，在这两位大隐士看来，武王伐纣是一场以不犯下仁义不杀。而孟立隐的则是在这无道的世界上，别切到山顶坚持不吃周的粮食，躲到首阳山上吃野菜，—起饿死了。

宁肯饿死，也不肯生活在无道的世界，这就是气节。但周朝的无道吗？在儒家看来，自不无道，反而更无道，周王室是受人，辅佐周王天下的周公也是圣人，孔子做梦都到梦到周公为荣。

再比如唐朝，它是一个社会吗？我们今天提起唐朝，尤其是盛唐，总充满着民族自豪感。但我们在这个口题上的看法很不—致。有人像我们一样沉浸盛唐，也有人认为人发起玄门口之变，为了夺权杀条哥哥和弟弟，还灭了兄弟两家的门，又逼父父亲进这。

这样得天下怎么能说是有道的世界呢？有道，国力再强大，人民就富足，就不“有道德”的要求吗，不须，听话的说“天下有道德”， “笑笑大家说“岂”岂不是都成了道德根律，谁都不用啦？

无道的时候就该隐居。古人选择隐居的话，远不如这种方式，因为他们反正也没有钱，没有自来水系统，不是手机和王道，所以隐居还是不隐居，主要是人多点和人少点不同，热闹一点和冷清点的差别。

隐居最主要的障碍有两个：—是没有政府系统，二是没有政府系统。

第—个得碍基本没有解决力案，因为古代知识分子的出路几乎没有做法。

第二个障碍可以解决，只要考上一个小品名，让户籍上边的身份变成士，就可以免除劳役了。不让你读书和苦力—起搬砖头，就真象体吃喝，面子丢挂不住。如果没有功名，想隐居啊，你只知道到很偏远的地方去，做一个没有户管的野人。

如果世道乱—些，或者天下没有—统，这还容易一。但如果是在—统-的时代，就着皇家的口情了。隐唐诗人陆龟蒙有一首小诗《新沙》，是这么说的。

> 渤澥声中众小山，官家新得海南州。
蓬莱有路人教到，应亦年年税赋来。

意思是说，渤海岸边露出了—片沙地，按照 “奉天效天”的办法隐。最先知道官同的“往送海无入”东边的海边的海防。这是官方目为指，因为海草，马上望着这个沙地准备征税。征税就更远，如果新沙上有路可通的，也一定年年都派官往收税。

诗写得很浪漫，也很夸张，该说夸张里反映的社会现象却很真实：官方为了税收，不留下多空间呢？肯定恨不得把隐士都抓来种田。

不想说隐士，就算是出家人，也难逃一劫。中国历史上有一“三免—条”，发生唐朝就是唐德宗时，能变成编户，给得国家交税。

所以，隐士的生活住在像大家想象的那样潇洒、浪漫。

这一单元说几首著名的隐逸诗，既有太上隐者的《答人》这样的浪漫、浪漫，但未必真有的；也有李白《问五峰》这样的醉子那样的无奈选择；还有白居易《中隐》这样的很潇洒，又很真实，但很纯的范例。

# 1. 太上隐者

太上隐者到底姓甚名谁，不知道。他是哪人，做什么职业，做什么为生，—概都不可道：我们对他的确切的知，只有太上隐的代：隐者，如就管我—种的名字：太上隐者，还有一首小诗：《答人》。显然，这才是真隐。

为什么会有这首小诗流传下来呢？据说是好事者见到了他，追问不着，他才吟出这首小诗来回答的。全诗二十个字，答他的是“我是谁”这个问题。

> 偶来松树下，高枕石头山。
山中无历日，寒尽不知年。

这首诗明白如话，很好理解。太上给自己画了幅禅静的速写，说自己过着自白自在、漫无目标的生活，说了就是他个他自定。这不刚刚便下了，正好走到—棵松树底下，在树下便躺下了。

睡觉需要枕头，怎么办？很简单，随手找—块在头就枕着。 “高枕” 两个字特写写出枕无忧无虑的味，没有啥心事，睡啥啥舒服。

但怎么办故去收土隐呢？这可是野外避免的难题。太上隐者完经完全有这必要，也许天生对他的免，也许他们有相，正正谈着说，他的日子过得天—年浑浑噩噩地度过，吃了就吃，困了就睡，什么都无关无，而。

既没有目标，也不用制定计划，不定计划的生活自然不历。今年到底是哪—年，今年到底几月几日，这些对我们做人至关重要的问题，在他那里变得毫无意义。

人只有活成这样，才是真正庄子上的自然天，无来无去，然应道天性。庄子推的，就是这个样。

你不一定吗？ “如果山上断了水，或草怎么办了，或者有人上座有机器来探候的话，可呢？” 如果太上隐者有机会回答他的话，我相信他会答庄子的精神回答这样：

“你之我以间出而隐，是因为，你心已染上之义的根，被扭曲而不知，听水了又怎么样？大石又怎么样，塌了又怎么样？天不把你死。生病或者致残了又怎么样？无不是把你发化。中—环，又有什么得的什么呢？

可你看着方物事，难道不是每时每刻都正在着变化吗？如果变成一条鱼的话，它就又变成了虫子；虫子变成了虫子，他物也变成了。而我自己也在不停变化着，你所得的在生死是非变化当中的一，又有什么得的呢？

# 2. 寒山

在有真名可考的诗人里，直有一个像这位太上隐者，他就是著名的寒山。

说寒山名，既不在于他的有生之年即名，也不是后来的诗人发现了他的价值，他是在国中出。

日本人格外崇信寒山的诗。到了当代，美国壁皮土动运的时候，寒山又成了壁皮土的像。那时候美国国起冷国人的当代人，知道寒山的人，是国，杜国和的—代人。

这不奇怪，因为寒山的诗简单口说，既形式美，又没有着痕迹的美式所谓禅诗，翻译译成外语很容易。

但没听过寒山，也从没读过他的诗，应该见过他的形。因为他他的好朋友—国诗人的—起，都被画成了和合二仙，着和合，美名。

他们的形象经常出现在观礼上，屋上，几乎都是中国式的避。逢求都着—拜二仙，虽然二仙—个和尚，—个挑着食子。

寒山原是个僧，性烈，但考上科举。要着究到底，日子过不下去了，亲着，可学怎么办，？这个候想当尼，可学怎么办，？

人到这种境，最的办就是独处。因为人活总有意想不到的东西，苦味要基本吃个，有个能力才会实到—个人。个离尘、离弃的人再用去看人的眼光。

寒山隐在在台州（tái）的寒山，那里即在真天台山的深山，从山者自号了寒山这个名字。他的本名是什么，从此人。

寒山的诗通没有题，都是事写在上、石上，号着抄下来的，总三百多首，用编号来区片。我们看—下第287号。
