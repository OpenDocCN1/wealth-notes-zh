# 17 李白《夜泊牛渚怀古》
## 壮心未酬，呼唤知音

牛渚西江夜，青天无片云。
登舟望秋月，空忆谢将军。
余亦能高咏，斯人不可闻。
明朝挂帆席，枫叶落纷纷。

你好，欢迎来到《唐诗·选讲50首》。

在唐朝，读书人的出路只有一条，那就是进入仕途，要么为朝廷做事，要么为将军做事。这是壮士心得以施展的必经之路，而要通过这条路，仗重的友谊就变得必不可少。

所以在诗海里看到盛唐诗人热心地呼唤知音，一定要想到除了那些自甘淡泊的隐士之外，如曾往与有能身份、有技无人的人，要么是高高仕者，要么是未能自拔之人。

李白的《夜泊牛渚怀古》就是这样一种激越壮心来呼唤知音的诗。

## 1. 可遇而不可求的知己

《夜泊牛渚怀古》是李白年轻时代的作品，全诗五言八句。

你可以试着把它归一下类：它到底算五言古诗呢，还是五言律诗呢？

初学者容易理解这个问题，但如果你对唐诗有一定的感性认识，马上就会被它难住。律诗是新时代的诗歌体裁，讲律诗和律对仗，因为是很严的，所以对仗必须讲究合律，那么因应地，自己则以对仗的联联种也不讲对仗诗联，更完全不讲究对仗的诗歌体裁，就被称为古体诗或古诗。

我们翻开《唐诗三百首》，它收录这首诗《夜泊牛渚怀古》，归入“五言律诗”的部分。它律似有章有道理，因为这样简单的律确实合律诗的规范，铿锵铿锵，比古诗清亮多了。但是，律诗中间四句应该两两相对，这首诗却全都没有对仗，所以把它归为律诗其实还是错误的。

我们既可以说它是有律味感的古诗，也可以说它是古体诗味道的律诗。这是李白诗的特点，对诗联文不太大讲究，只要少许所需就随意挥洒成篇，只有最高天才的人才会适合这样的写法。

诗题当中的牛渚，全称牛渚矶，就像你不熟悉这个地方，也可能听说过后来的名号：采石矶，它的位置在今天的安徽省铜陵市长江南岸，南东夹金陵著名的采石之战就是这里发生的。唐文化多以水景、大景充背景，这大概是每个中学语文都熟悉讲的一段历史。

在李白年轻的时候，牛渚矶虽然还没有发生过这样慷慨的故事，但刘寄奴还在长江水泊之处“此地商周谢安袁崇庆处”，说自己未怀的古老不边的事情，而是发生在谢尚和袁宏之间的一段往事。

事情发生在秋初，当时镇军将军谢尚镇守牛渚，在一个秋夜，临江而卧看江下风光，忽然听到附近的货船上传来吟诗的声音，吟诗的诗歌非常精彩，自己前所未闻。

谢尚又叫来人问到货船上的人情况，原来吟诗的是一个名叫袁宏的流民头儿，吟诗的语歌是他自己创作的《咏史诗》。这位袁宏虽然出身于书简门第，但谢尚早就有耳闻，只好在牛渚头码头，给其装备加货。如果不是谢尚的这次偶遇机会，袁宏上岸吐一肚子也报读不出体力劳苦的大运。

谢尚把袁宏邀请到自己的船上，越聊越投机，不知不觉聊到了天亮大家。后来谢尚袁宏做了自己的幕僚，袁宏的人生从此不同。

我们这段历史来看李白的诗，“牛渚西江夜，青天历片云”，开了见山，写出了夜泊牛渚，下接下来“登舟望秋月，空忆谢将军”，同一轮秋月下望见这里望见识谢尚和袁宏的相遇相识，但一个“空”字说出了李白的无奈。

这无奈从何而来呢？来自“余亦能高咏，斯人不可闻”——我当然能写出表袁宏一样的诗，但高冷的江风上高吟高诵自己的诗，感怀在诗里面的壮志激烈，但像谢尚已经不可能碰到了，我也没能找到如当过谢尚一样的人。

我该何去何从？“明朝挂帆席，枫叶落纷纷”，明天一早还要继续航行吧，那样的早晨，枫叶一定会在秋风中纷纷飘落。

## 2. 羚羊挂角

这首诗《夜泊牛渚怀古》当然是一篇佳作，但要说它能代表唐诗的妙处，不管怎样是若干代表作之一，不知道你会不会同意呢？

维华小说有一种“高维消失”的经典诡计，比如爱德华·霍普的《辐射列车站》，或让人在雪地上行走着的一场车祸，或发现车雪地在 上栏杆突然消失；保罗·普尔特的《混血之子》，雪地上一定会有手走过去，可看不到凶手的身影。

其实在中国古人的知识里，羚羊天生就有这种本领。传说羚羊是一种叫“高维”的动物，每夜晚它会抱一块木头，在树上挂好，用角挂住树枝，身体完全悬空，这才能够放心睡觉。

如果有猛兽追踪羚羊的足迹，追到树下会茫然不知所措，想不透羚羊是如何凭空消失的。所以禅人们很喜欢说一句话：“羚羊挂角，无迹可求。”

你可以把羚羊的足迹想象成我们的语言文字，每一句话，每一个字都是看得见、摸得着的痕迹，要想体验会禅境，就必须超越语言文字之外。

宋释仁严写过一部《沧浪诗话》，借用禅宗概念，把诗歌艺术的精妙之处比附为“羚羊挂角，无迹可求”。

到了清，康熙年间有一位文坛盟主王士祯，到号渔洋山人，在诗坛提出了一个“神韵”概念，认为写诗用神的诗才是最好的诗。神韵到底是什么呢？简单说，其实就是羚羊挂角的境界。

他越发喜欢平淡的诗歌和平淡的人生，但平淡之中，非平凡之中必须蕴含着不凡，不同凡之处，是让人一看便喜欢，必然看若若。若明若暗，若让人想看清，必不能看清，若让不看清，它却淡淡地在他的心里缠绕缠绕。

正如海面的皱纹比往比海面的波澜更加有力，隐藏在平静水波之下的比比比波涛而出的情绪更加动人动情。

## 今日得则

李白的《夜泊牛渚怀古》是介于古诗和诗词之间的，既有平水古式的古之古韵，又有诗歌之感，是李白年轻时代的一点点动作。

唐代半科举、半军功的晋身方式使读书人格外渴望名誉，如陈子昂等人皆以名自己的功名，而进士制更使其以诗赋为敲门砖。而进士制度只是唐代诗歌的一大推手，且古人的知音和今天的知音，对人身的意义截然不同。

李白的《夜泊牛渚怀古》和孟浩然的《晚泊浔阳望庐山》被史家作为心境观照神韵的典型之作。

长久羁居异乡，或者常年奔波在旅途之中，无法回家除夜，古人或把这样的情形称为羁旅。在羁旅生涯当中，往往只要一一盏-抹微光便能动人的悲怀。

这一个单元里，我们来读几首羁旅主题的诗。有戴叔伦的《除夜宿石头驿》，写出了一个即将年底、万里未归人的名句，亲吻千古的乡愁；还有李商隐的两首诗，《关庙山》写两地离别的思念，《春日偶成独城市》让一股声成为所有乡人的催泪声。

当然，谈到羁旅，也少不了温庭筠的《商山早行》。读读这首诗，也许更能理解古人为什么漂在路上。

回家过年，这几乎每个中国人都经历过的经历。即便年底真有那样的交通压力，可即使你在千里之外的异乡，你也会通过各种交通工具赶在除夕之前回家，和家人一起围炉守岁。就算真的赶不到家，至少还有电话和视频可以帮你。

但古人就没有这些条件了，一旦背井离乡，回家就是一条漫漫的山水的旅程，平时是没有任务快速返乡方式的，只有书信，也不知道能否寄到，也不知道一封信到目的地在路途上耽误多久。

就算踏上了回家的旅途，心里也总是盘着，不知道自己离开了这么久，家里会不会发生什么变化，从才会写"近乡情更怯，不敢问来人"这样的话。

我们必须知道古人的平均寿命很短，古代医学也远不像传说中那么神奇，即便是高门大户出身的青年仕，也很有可能一半是平常的寿命，生命，小孩的夭折是最常见的现象。

古人生活中的不确定度远高于今天我们，所以他们才会格外不能分离、渴望团聚，疏散会因此成为古代诗歌里最常见的主题。

这一讲先从中唐诗人戴叔伦的名作，被誉为“唐诗中除夜之绝唱”（胡应麟《诗薮》）的《除夜宿石头驿》说起。当我们的人生进入不随心的旅程，诗歌就会成为最好的宽慰。

## 1. 孤独的除夕

我们先看一看这首诗的题目：除夜就是除夕，石头驿，就是驿站的名字。这首诗是戴叔伦晚年写的作品，当时他在江西做官，大约要取道长江返回江苏老家过年。

时间已经到了除夕，他却滞留在半路上，独自在驿站过夜。所谓驿站，唐代的官方旅行机构在驿站，通过安排人员与马匹向外界供马，私营旅社称为旅馆，完全商业化。

诗的题目要落实在实背景，所以诗人强调住宿的具体的驿站；而到了诗的正文，诗人往社会类实，所以戴叔伦将“旅馆”这个词代替了“石头驿”。

于是，任何在旅途中住酒店的人都更加直接地以诗句中间告他们：

```
旅馆无良伴，寒夜独可亲。
一年将过腊，万里未曾旋。
客鬓衰添白，乡心淡处新。
愁颜与衰鬓，明日又逢春。
```

今天到了春节时期，大城市往往太空无一多半，各街区的街道也是冷清清的。唐朝的情况虽然没有今天我们这么发达，到了除夕，该回家的人通常已经到了家，和家人一起守岁，旅馆里边也不会有几个人了。

戴叔伦偏要在旅馆里边度过除夕，当然就零零寡只一个人，只注视着房间里的灯火，那是自己仅有的同伴了。

"旅馆惟相伴"，一个句间，表示人独自生活，"寒灯孤青伴"，只有唯唯的一盏灯太相住，这既是荒寒的现实，唯一一点光亮。

接下来的两句是全诗的精髓，点古中传诵的名句：“一年将过腊，万里未曾旋。”除夕是一年的最后一夜，过了今夜就是新的-一年，而在团圆的年节过程中，诗人却没及时回家，也不知道何时才能到家。在这样的对仗里，忽然涌出归乡悲思。

其实从江西到江苏，路途并不很远，"万里末日"看似过于夸张了，但借用古汉语造成的诗语言有着很大的模糊性。

一句"万里未归人"，我们既可以理解为诗人已经漂泊万里千里外，至今还未能还回家；也可以理解成心里愿意走的"万里"，和家乡的地理距离已经不远了，但 because 除夕的缘故，会让人产生天地悬隔、咫尺天远的悲心。

因为伤心，所以反证，“客鬓衰添白，乡心淡处新”两句似乎是驳驳，明明已经鬓如霜的鬓发了，自己还应该会愁思和衰老当中振作起来呢？

但全诗下来的意思，我们只要觉得啼哭"明日又逢春"下诗意是故作欢欣，只是一种反语。忧愁还会更新，衰鬓还会更衰，怎今年除夕都不能属于自己，来年的春思又怎可能属于自己呢？

## 2. 佛里的孤灯

羁旅之中，最自目的意象就是孤灯。白居易有一首《除夜宿寒驿》，用相似的意象写出同样的愁苦：

```
感时思伯未，不获言生事。
万里思亲处，孤灯伴此宵。
病非新旧日，归思逼新正。
望里教老远，羁离长此心。
```

诗人和兄弟分别多年，除夕夜不能团聚，对着一盏孤灯不禁悲思生发，无法入睡。

第三、四两句是组很经典的对仗，“经年”是第二年的意思，“万里”对“孤灯”，“经年”对“此夜”。

用最大的数字对最小的数字，用漫长的时间对短暂的时间，因此，显得孤独格外的，孤孤单单的，孤苦。

如果常年羁旅漂泊、流浪江湖，和亲家疏离多离，孤独几乎都是每个夜晚的唯一陪伴，这一点光明也显出无限凄凉。

宋朝诗人黄庭坚写过一个名句：“桃李春风一杯酒，江湖夜雨十年灯”，自己和好友曾经在桃李春风下把酒共谈，一分别转眼就过了十年，两个人在不同的轨道上各自适应着定定的生活，度过了多少个只有孤灯陪伴的夜晚。

孤灯在什么时候才不会孤独呢？这可不是一个容易回答的问题，但唐朝诗人给我们一个丰富多彩的阅读，我们有一首纪念离别诗的题目是《送僧中归日》，是一位回国的日本人在送诗，句句里满是禅道慈思：

浮天沧海远，去住法船归。

# 17 李白《夜泊牛渚怀古》
## 壮心未酬，呼唤知音

牛渚西江夜，青天无片云。
登舟望秋月，空忆谢将军。
余亦能高咏，斯人不可闻。
明朝挂帆席，枫叶落纷纷。

你好，欢迎来到《唐诗·选讲50首》。

在唐朝，读书人的出路只有一条，那就是进入仕途，要么为朝廷做事，要么为将军做事。这是壮士心得以施展的必经之路，而要通过这条路，珍贵的友谊就变得必不可少。

所以在诗海里看到盛唐诗人热心地呼唤知音，一定要想到除了那些自甘淡泊的隐士之外，如曾往与有能身份、有技无人的人，要么是高高在上的仕者，要么是未能自拔之人。

李白的《夜泊牛渚怀古》就是这样一种激越壮心来呼唤知音的诗。

## 1. 可遇而不可求的知己

《夜泊牛渚怀古》是李白年轻时代的作品，全诗五言八句。

你可以试着把它归一下类：它到底算五言古诗呢，还是五言律诗呢？

初学者容易理解这个问题，但如果你对唐诗有一定的感性认识，马上就会被它难住。律诗是新时代的诗歌体裁，讲律诗和律对仗，因为是很严的，所以对仗必须讲究合律，那么因应地，自己则以对仗的联联种也不讲对仗诗联，更完全不讲究对仗的诗歌体裁，就被称为古体诗或古诗。

我们翻开《唐诗三百首》，它收录这首诗《夜泊牛渚怀古》，归入“五言律诗”的部分。它律似有章有道理，因为这样简单的律确实合律诗的规范，铿锵铿锵，比古诗清亮多了。但是，律诗中间四句应该两两相对，这首诗却全都没有对仗，所以把它归为律诗其实还是错误的。

我们既可以说它是有律味感的古诗，也可以说它是古体诗味道的律诗。这是李白诗的特点，对诗联文不太大讲究，只要少许所需就随意挥洒成篇，只有最高天才的人才会适合这样的写法。

诗题当中的牛渚，全称牛渚矶，就像你不熟悉这个地方，也可能听说过后来的名号：采石矶，它的位置在今天的安徽省铜陵市长江南岸，南东夹金陵著名的采石之战就是这里发生的。唐文化多以水景、大景充背景，这大概是每个中学语文都熟悉讲的一段历史。

在李白年轻的时候，牛渚矶虽然还没有发生过这样慷慨的故事，但刘寄奴还在长江水泊之处“此地商周谢安袁崇庆处”，说自己未怀的古老不边的事情，而是发生在谢尚和袁宏之间的一段往事。

事情发生在秋初，当时镇军将军谢尚镇守牛渚，在一个秋夜，临江而卧看江下风光，忽然听到附近的货船上传来吟诗的声音，吟诗的诗歌非常精彩，自己前所未闻。

谢尚又叫来人问到货船上的人情况，原来吟诗的是一个名叫袁宏的流民头儿，吟诗的语歌是他自己创作的《咏史诗》。这位袁宏虽然出身于书简门第，但谢尚早就有耳闻，只好在牛渚头码头，给其装备加货。如果不是谢尚的这次偶遇机会，袁宏上岸吐一肚子也报读不出体力劳苦的大运。

谢尚把袁宏邀请到自己的船上，越聊越投机，不知不觉聊到了天亮大家。后来谢尚袁宏做了自己的幕僚，袁宏的人生从此不同。

我们这段历史来看李白的诗，“牛渚西江夜，青天历片云”，开了见山，写出了夜泊牛渚，下接下来“登舟望秋月，空忆谢将军”，同一轮秋月下望见这里望见识谢尚和袁宏的相遇相识，但一个“空”字说出了李白的无奈。

这无奈从何而来呢？来自“余亦能高咏，斯人不可闻”——我当然能写出表袁宏一样的诗，但高冷的江风上高吟高诵自己的诗，感怀在诗里面的壮志激烈，但像谢尚已经不可能碰到了，我也没能找到如当过谢尚一样的人。

我该何去何从？“明朝挂帆席，枫叶落纷纷”，明天一早还要继续航行吧，那样的早晨，枫叶一定会在秋风中纷纷飘落。

## 2. 羚羊挂角

这首诗《夜泊牛渚怀古》当然是一篇佳作，但要说它能代表唐诗的妙处，不管怎样是若干代表作之一，不知道你会不会同意呢？

维华小说有一种“高维消失”的经典诡计，比如爱德华·霍普的《辐射列车站》，或让人在雪地上行走着的一场车祸，或发现车雪地在 上栏杆突然消失；保罗·普尔特的《混血之子》，雪地上一定会有手走过去，可看不到凶手的身影。

其实在中国古人的知识里，羚羊天生就有这种本领。传说羚羊是一种叫“高维”的动物，每夜晚它会抱一块木头，在树上挂好，用角挂住树枝，身体完全悬空，这才能够放心睡觉。

如果有猛兽追踪羚羊的足迹，追到树下会茫然不知所措，想不透羚羊是如何凭空消失的。所以禅人们很喜欢说一句话：“羚羊挂角，无迹可求。”

你可以把羚羊的足迹想象成我们的语言文字，每一句话，每一个字都是看得见、摸得着的痕迹，要想体验会禅境，就必须超越语言文字之外。

宋释仁严写过一部《沧浪诗话》，借用禅宗概念，把诗歌艺术的精妙之处比附为“羚羊挂角，无迹可求”。

到了清，康熙年间有一位文坛盟主王士祯，到号渔洋山人，在诗坛提出了一个“神韵”概念，认为写诗用神的诗才是最好的诗。神韵到底是什么呢？简单说，其实就是羚羊挂角的境界。

他越发喜欢平淡的诗歌和平淡的人生，但平淡之中，非平凡之中必须蕴含着不凡，不同凡之处，是让人一看便喜欢，必然看若若。若明若暗，若让人想看清，必不能看清，若让不看清，它却淡淡地在他的心里缠绕缠绕。

正如海面的皱纹比往比海面的波澜更加有力，隐藏在平静水波之下的比比比波涛而出的情绪更加动人动情。

## 今日得则

李白的《夜泊牛渚怀古》是介于古诗和诗词之间的，既有平水古式的古之古韵，又有诗歌之感，是李白年轻时代的一点点动作。

唐代半科举、半军功的晋身方式使读书人格外渴望名誉，如陈子昂等人皆以名自己的功名，而进士制更使其以诗赋为敲门砖。而进士制度只是唐代诗歌的一大推手，且古人的知音和今天的知音，对人身的意义截然不同。

李白的《夜泊牛渚怀古》和孟浩然的《晚泊浔阳望庐山》被史家作为心境观照神韵的典型之作。

# 18 戴叔伦《除夜宿石头驿》
## 旅途中的一盏孤灯

戴叔伦《除夜宿石头驿》

```
旅馆无良伴，寒夜独可亲。
一年将过腊，万里未曾旋。
客鬓衰添白，乡心淡处新。
愁颜与衰鬓，明日又逢春。
```

你好，欢迎来到《唐·唐诗50讲》。

长久羁居异乡，或者常年奔波在旅途之中，无法回家除夜，古人或把这样的情形称为羁旅。在羁旅生涯当中，往往只要一盏抹微光便能动人的悲怀。

这一个单元里，我们来读几首羁旅主题的诗。有戴叔伦的《除夜宿石头驿》，写出了一个即将年底、万里未归人的名句，亲吻千古的乡愁；还有李商隐的两首诗，《关庙山》写两地离别的思念，《春日偶成独城市》让一股声成为所有乡人的催泪声。

当然，谈到羁旅，也少不了温庭筠的《商山早行》。读读这首诗，也许更能理解古人为什么漂在路上。

回家过年，这几乎每个中国人都经历过的经历。即便年底真有那样的交通压力，可即使你在千里之外的异乡，你也会通过各种交通工具赶在除夕之前回家，和家人一起围炉守岁。就算真的赶不到家，至少还有电话和视频可以帮你。

但古人就没有这些条件了，一旦背井离乡，回家就是一条漫漫的山水的旅程，平时是没有任务快速返乡方式的，只有书信，也不知道能否寄到，也不知道一封信到目的地在路途上耽误多久。

就算踏上了回家的旅途，心里也总是盘着，不知道自己离开了这么久，家里会不会发生什么变化，从才会写"近乡情更怯，不敢问来人"这样的话。

我们必须知道古人的平均寿命很短，古代医学也远不像传说中那么神奇，即便是高门大户出身的青年仕，也很有可能一半是平常的寿命，生命，小孩的夭折是最常见的现象。

古人生活中的不确定度远高于今天我们，所以他们才会格外不能分离、渴望团聚，疏散会因此成为古代诗歌里最常见的主题。

这一讲先从中唐诗人戴叔伦的名作，被誉为“唐诗中除夜之绝唱”（胡应麟《诗薮》）的《除夜宿石头驿》说起。当我们的人生进入不随心的旅程，诗歌就会成为最好的宽慰。

## 1. 孤独的除夕

我们先看一看这首诗的题目：除夜就是除夕，石头驿，就是驿站的名字。这首诗是戴叔伦晚年写的作品，当时他在江西做官，大约要取道长江返回江苏老家过年。

时间已经到了除夕，他却滞留在半路上，独自在驿站过夜。所谓驿站，唐代的官方旅行机构在驿站，通过安排人员与马匹向外界供马，私营旅社称为旅馆，完全商业化。

诗的题目要落实在实背景，所以诗人强调住宿的具体的驿站；而到了诗的正文，诗人往社会类实，所以戴叔伦将“旅馆”这个词代替了“石头驿”。

于是，任何在旅途中住酒店的人都更加直接地以诗句中间告他们：

```
旅馆无良伴，寒夜独可亲。
一年将过腊，万里未曾旋。
客鬓衰添白，乡心淡处新。
愁颜与衰鬓，明日又逢春。
```

今天到了春节时期，大城市往往太空无一多半，各街区的街道也是冷清清的。唐朝的情况虽然没有今天我们这么发达，到了除夕，该回家的人通常已经到了家，和家人一起守岁，旅馆里边也不会有几个人了。

戴叔伦偏要在旅馆里边度过除夕，当然就零零寡只一个人，只注视着房间里的灯火，那是自己仅有的同伴了。

"旅馆惟相伴"，一个句间，表示人独自生活，"寒灯孤青伴"，只有唯唯的一盏灯太相住，这既是荒寒的现实，唯一一点光亮。

接下来的两句是全诗的精髓，点古中传诵的名句：“一年将过腊，万里未曾旋。”除夕是一年的最后一夜，过了今夜就是新的一年，而在团圆的年节过程中，诗人却没及时回家，也不知道何时才能到家。在这样的对仗里，忽然涌出归乡悲思。

其实从江西到江苏，路途并不很远，"万里末日"看似过于夸张了，但借用古汉语造成的诗语言有着很大的模糊性。

一句"万里未归人"，我们既可以理解为诗人已经漂泊万里千里外，至今还未能还回家；也可以理解成心里愿意走的"万里"，和家乡的地理距离已经不远了，但 because 除夕的缘故，会让人产生天地悬隔、咫尺天远的悲心。

因为伤心，所以反证，“客鬓衰添白，乡心淡处新”两句似乎是驳驳，明明已经鬓如霜的鬓发了，自己还应该会愁思和衰老当中振作起来呢？

但全诗下来的意思，我们只要觉得啼哭"明日又逢春"下诗意是故作欢欣，只是一种反语。忧愁还会更新，衰鬓还会更衰，怎今年除夕都不能属于自己，来年的春思又怎可能属于自己呢？

## 2. 佛里的孤灯

羁旅之中，最自目的意象就是孤灯。白居易有一首《除夜宿寒驿》，用相似的意象写出同样的愁苦：

```
感时思伯未，不获言生事。
万里思亲处，孤灯伴此宵。
病非新旧日，归思逼新正。
望里教老远，羁离长此心。
```

诗人和兄弟分别多年，除夕夜不能团聚，对着一盏孤灯不禁悲思生发，无法入睡。

第三、四两句是组很经典的对仗，“经年”是第二年的意思，“万里”对“孤灯”，“经年”对“此夜”。

用最大的数字对最小的数字，用漫长的时间对短暂的时间，因此，显得孤独格外的，孤孤单单的，孤苦。

如果常年羁旅漂泊、流浪江湖，和亲家疏离多离，孤独几乎都是每个夜晚的唯一陪伴，这一点光明也显出无限凄凉。

宋朝诗人黄庭坚写过一个名句：“桃李春风一杯酒，江湖夜雨十年灯”，自己和好友曾经在桃李春风下把酒共谈，一分别转眼就过了十年，两个人在不同的轨道上各自适应着定定的生活，度过了多少个只有孤灯陪伴的夜晚。

孤灯在什么时候才不会孤独呢？这可不是一个容易回答的问题，但唐朝诗人给我们一个丰富多彩的阅读，我们有一首纪念离别诗的题目是《送僧中归日》，是一位回国的日本人在送诗，句句里满是禅道慈思：

```
上随佛性空，唯尘逐梦归。
浮天沧海远，去住法船归。
水月通禅观，鱼龙听梵音。
惜将一灯影，万里报中阴。
```

这首诗里，每一句都用到了佛教意象，但并不全是浮屠意义上的感受，反而是一番双关：既可以从事面上做字面的理解，也可以从修辞上做佛学上的解读，这是很精明的写法。

我们只看最后两句：“惜将一灯影，万里报中阴。”，“惜”的意思是“爱”，“一灯”字面上就是一盏孤灯，随着僧人的船只行驶了万里，船上那盏孤灯会让出洋经道的诗人渐渐看不清了，所以你会觉得奇怪：

```
茫茫海里面，一盏孤灯，怎可能在万里眼里呢？从字面上看，我们很容易理解这是诗人带着的乡愁，最末表示诗人在岸边，望着越来越远的光芒，久久不忍离开。
```

但在佛学的角度，它更多是借唐朝很流行的《维摩诘所说经》，简称《维摩诘经》。经的主维摩诘病向百万方天众传说道法方法达彼岸，这个方法叫作无尽灯。

它的涵义是：菩萨度化世人就好比点燃一盏灯，这盏灯还能继续点燃千百盏灯，使漫漫黑夜变成无尽光明。

借小借佛法，就像一盏灯点燃千百盏灯，金黑暗从佛的人情世故，“一灯大师”的佛旨就是从这里来的。

与铁塔告别的这位日本僧人又何尝不是漂泊在羁旅之中？“浮天沧海远，去住法船归”，渡海的漂泊又何必如此孤独，自目界的羁游更
