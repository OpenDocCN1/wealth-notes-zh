# # 发刊词 | 唐诗为什么值得你花时间？

刚刚：熊猫·唐诗50讲
1 昨天 进入课程

你好，欢迎来到《熊猫·唐诗50讲》。接下来的日子，我会带你进入唐诗的世界。

作为一个成年人，我猜大概率上，你小时候一定被父母逼迫在众人面前背过唐诗："鹅鹅鹅，曲项向天歌"；还有"白日依山尽，黄河入海流"；"床前明月光"；以及上学的时候几首；如果是文学爱好者，大部分人跟唐诗的缘分基本上就止步于此了。

1

这样的人生有什么问题吗？当然没有，绝大多数中国人都走过这么一段路，不读更多的唐诗，既不贬低你职业的选择，也不妨碍财富的积累。

毕竟这个时代离唐朝已经隔了1000多年，要付钱听我谈唐诗的代价，和学英语的新东西推倒重学，压力和感受太多，而时间的新因素太多。

那么，古老的唐诗还值得花功夫去学吗？

如果一定要用理由的话，三个够不够？

第一，唐诗能给你语言匮乏的人生场景，提供更佳表达方案。

人总有那么一些时刻——

你站在城市最高的楼顶，望着下面的万家灯火心绪难平；

你出差在外半夜梦回，一时恍惚自己身在何处；

你工作勤奋家眷情牵，却总觉得无法抵偿；

你站在立交桥上看着车来车往，想起家乡清荡的小溪和远处的青山；

你为一个人辗转反侧，不知道如何表白，说不出大如话语；

你说你的好友远行，饭局上觥筹交错，人散后长街孤影；

你看着秋去秋来，镜子里的自己又添了一些白发……

总会有一些这样的时刻，你百感交集，心里马万奔腾，话在嘴边却只能发出最高调、直白甚至粗浅的几个感叹词。

幸好，科技进步很快，但人性很像很慢，你经历的场景、煎熬、寂寥、孤勇，你体验过的欢喜、惊愕、悲怆、豪迈，唐人也有。不一样的是，他们还有诗。

如果亲近唐诗，你就有了这样表达的可能——

登高望远，你可以说"江涵秋影雁初飞，与客携壶上翠微"；

思念未归的亲人，你可以说"一年将尽夜，万里未归人"；

事业暂时低于低端，想换工作，你可以用"宁为百夫长，胜作一书生"激励自己；

厌倦红尘，你能解语"松风吹解带，山月照弹琴"来自我慰自；

告别时刻，你说"浮云游子意，落日故人情"，到朋友有依不念，也是静享朝幕；

心有罅隙，醋味不明，可用空发一句"落梅迟韵香疏疏，分香还赠对门红"，懂的自能释然了……

唐人的诗句，可以填补你胸中的块垒：自己说不出来，让她替你表达。

第二，唐诗能提升你对美的感受力。

美在生活中的存在无所不在。对古人天地、古今中外，但一个无所感到不忧闲不见，还是会被敏锐捕获。到底能不能以平凡的，惯性的生活，还是能否超越日常的，审视的生活，则取决于对美的感受力。

唐时里岁月某软、风物怡然。里有明月关山，心有天地高旷；里有春寒荠菜，春日东风酥软，枕花灼灼；夏有雨脚麻鞋，奉子金莲；秋有素娥，白露落；冬日温酒，得归人。

山川四季浩浩荡荡，足以激发现代人的审美具象、欣赏节奏和审美能力。更重要的是，你也许会因此发现生活中更多更深刻的美。
