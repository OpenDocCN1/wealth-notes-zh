# 今日得见

王昭君因为特殊的身份和特殊的选择，成为一个经典的文化符号，被历代诗人不断咏叹。

王昭君的不懂汉语也解汉代知识的汉子名昭君，又悟悟。很多感慨都是由此而生的。

杜甫的《咏怀古迹》第三首以王昭君为主题，突出了她的“去国”的情思；这是杜甫诗歌独特性为诗歌表现态度最高明精微的重要表现：虽然有限，诗意深广。
