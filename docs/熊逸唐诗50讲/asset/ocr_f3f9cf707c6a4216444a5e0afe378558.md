# 12 白居易《长恨歌》| 盛世的真相与粉饰

陶选 唐诗50讲

白居易《长恨歌》（摘录）

临别殷勤重寄词，词中有誓两心知。
七月七日长生殿，夜半无人私语时。
在天愿作比翼鸟，在地愿为连理枝。
天长地久有时尽，此恨绵绵无绝期。

《长恨歌》全文涉及杨白氏与唐明皇，明清时期开始被看作“下一世”的爱情。

你好，欢迎来到《甄选·唐诗50讲》。

唐朝诗人古诗诗歌，或恢恢古韵，或是唐朝以前的；也有诗篇的，真正的，却是安史之乱前的盛世。后辈中篇，最出名的就是白居易的诗《长恨歌》。

不过今天的听众看来，这首诗的主题不像牡丹，更像是“爱情的代价”。

今天爱情故事被演绎得爱的意义渲染到无以复加的地步。如果一个人为了爱情不再牺牲一切，非常有所保留，他就是一个不纯粹的人。一个有污点的人，一个配不上爱情的纯洁光环的人。

我们可以想象一下——
你是一个漂亮的女孩子，正活在梦幻般的年纪，这十年中，有一个全世界最帅气的男人来爱你。这个人因为太优秀了，身边总吸引无数美女，但你对他完全无视，只是无条件、无保留地爱他。

他的工作相当重要，关系着天下人的生与死、祸与福，但他为了多陪你一小时，宁愿让工作停了。自从你在一起，他不再加班，休假也多了起来。所有东西因为你的缘故，对你都上各种保险。

他总是把天下最好的东西给你，从来不讨成本。他因为爱你，对你妥协的一切。他有一颗至纯至洁的心，对身边的每一位家人都有，甚至帮家不合理的哥哥解决了就业问题，让他在国君那里很生气。

我们今天虽然见过各种幻想型的爱情故事，但恐怕还没见过这样完美的人设。

如果你生来铁石心肠，还没有被打动的活，那么请你继续听：

他因为太爱你，全心心思都放在了你身上，以至于对爱憎的防线彻底失守了。身上了江山。而在危急的关时，他把你在身边，那去救身上的人在危险地方，反正他们都是别的妇人的儿子。

如果说这样的精诚所至还未能金石为开的话，那我们只能说，所谓爱情从来就没存在过。

不过，接下来的情节就不太美了：生就砍头，的时，他为了保全自己的性命，先杀掉哥哥哥，再杀掉了你。当然，他的眼里一定饱含泪水。

这就是唐玄宗和杨贵妃的故事，在爱恨纠缠的古代社会里堪称一朵奇葩，所以引来了后人们的无限沉思。

但是，在新刚刚经历过动的唐朝人看来，这爱情在此心恰复着。有的人痛斥王朝的衰落，恨透了国事之乱的罪魁祸首，面到底才是最罪魁祸首呢？

在传统的儒家思想里，当然是女误国；也有的人在萧瑟的末路里怀念当初的太平盛世，唐玄宗和杨贵妃的爱情故事就成了最成全的悲剧和美好的怀旧的情感替身。勾起既甜蜜又苦涩的伤痛。

陈鸿创作的《长恨歌传》属于前者，白居易创作的《长恨歌》属于后者，两者都是那个时代的伤凭之作。

# 1.《长恨歌》的创作由来

在安史之乱爆发的半个世纪之后，唐贞元元和元年（806年），三十五岁的白居易踏入官场，到河南县（这个地方原先叫陆浑）县尉。县尉是基层县令手下的武职胥吏，负责治安、征税之类的事。

白居易很开心，一来嘛事务琐碎，二来职责所在，有时候办不出什么惊天动地的事也好。

今天中文读文本版的白居易《长恨歌》就是自唐贞中唐贞中时写出来的，刘（ýi）麦的场面就是他在周县的所见所闻。

县尉工作虽然任人即职，幸好当地有山有水，还挂着一些可以结交的文人绅士。白居易常常和这些朋友一起游山玩水，最去的地方就是附近的香山，那里有一处从唐朝的宫殿改建成的仙游亭。

就在这一年的冬天，白居易和好友陈鸿、王质夫一起，在仙游亭品茶谈到了唐玄宗和杨贵妃的故事。越聊感慨越深，于是王质夫提议，请“深情，多于情”的白居易就这个题材写首诗。

白居易真的写出来了，就是著名的《长恨歌》。写成之后，陈鸿为它配了一篇文字，叫作《长恨歌传》。

虽然从创作动机上说，这一诗传是配套的，但两作者的立意并不一样。《长恨歌传》更符合传统的情感态度，而《长恨歌》忽然一开始也是这个态度，但写着写着就转入情，然后一往情深，不可自拔。

所以《长恨歌》到底写的是什么主题，该怎样归队中？如果说，是批评评唐玄宗好色误国吧，还是很纯粹歌颂的爱情诗？让人看不清，前前后后争鸣不下。

还有一个背景需要交代，就是白居易和陈鸿在一年写上了《长恨歌》和《长恨歌传》，有一个地出的特殊性。

唐朝的县分赤、畿、望、上、中、下七等，首县直接的叫京署，首都旁边的叫京副县。周县就是畿县，离长安很近。

当初安史之乱爆发，唐玄宗从长安出走，随行兵马骑乘兵，杨贵妃就死在这个鬼城，到在周县附近。事急之下，唐玄宗继续出逃，到四川周边，一个经过的地方就是周县，所以周遭的一山一水、一草一木，在文人眼里，很容易地引发怀古之情。

但白居易的历史，才一开始就写得真实：

> “汉皇重色思倾国，御幸无处寻。”这是用汉末指唐事，说玄宗多恨找不到一个倾城的美女人，但好多好过去了就是找不到。

> “杨家有女初长成，养在深闺人未识”，杨家人是真实有这样一位美女，但养在深闺之中，外人没见过她。

> “天生丽质难自弃，一朝选在君王侧”，是金子总会发光的，是美女总会被发现的，于是这位姑娘就被选中进宫陪伴皇帝。

> “回眸一笑百媚生，六宫粉黛无颜色”，她的笑容是娇媚就是那迷人，压倒了后宫里所有女人。

这几句是客观交代了故事起因。不过问题是，在这简单事情中，白居易说“不无不知隐细，就是公然默许了。如果对《长恨歌传》，高就高其他人的记忆，那么后者的可能性显然更高。

# 2. 真相与粉饰

假如世界上没有留下其它史料，而只有这一首诗的话，我们就会相信杨玉环是从娘家被选入皇宫的，就像我们熟悉的选秀一样。

但事情的真相是：杨玉环本是杨贵妃、杨玉环是唐玄宗的儿子，所以唐玄宗和杨玉环是公公和儿媳妇的关系。

而所谓“御幸多年求不得”，让人误以为杨玉环是唐玄宗求的，其实唐玄宗一直宠爱杨玉环，但是唐玄宗对帝王、玄元皇帝、杨玉环的忠心，这个时候人们推荐了杨玉环。

唐玄宗第一次见到杨玉环时便一眼钟情，对杨贵妃的怀恋马上又了。他怎么能允许儿媳变成贵妃？他想让她怎么办？

需求总能创造出供给，给人指杨玉环，让她自己说出要当上独身女子，事又虽然婚姻不变，但转嫁给李仲子，又自己当了出家，还原了道观中的太真。唐玄宗倒也不吃亏得妻子，又为李寿立了一门亲事，自己生活和太真姑妈既能幸福又不羞不地生活在一起。

终于到了天宝元年，冒封太真为贵妃，礼仪和皇后相同。

我们读《长恨歌》，首先要了解这几句定下的基调将事情真相与之间的差距，这是理解全诗的关键。

白居易并不想作一篇全然反思的伤痕文学，他所给予那份的完成了好感。

虽然用一句“汉皇重色思倾国”表现出儒家传统的评判精神，但是他想要歌颂的永远远于想要批判的。他会在自己的想象和逻辑，来写那个美妙的年华，但公公和儿媳的乱伦写成一多情男女的恋恋。

在写作《长恨歌》的几个月前，白居易参加考功，在试卷上把唐玄宗大大表扬了一遭，说了这里的年，只对他晚年的政治稍做了一点批评。

唐玄宗由于开创盛世，对于年轻的白居易来说，仅仅在于开元盛朝的怀年景。
