# 17 李白《夜泊牛渚怀古》
壮心未酬，呼唤知音

牛渚西江外，青天片云在。
登舟望秋月，空忆谢将军。
余故能低垂，斯人不可寻。
朗月照高楼，风林夜纷纷。

你好，欢迎来到《唐诗·选讲50首》。

在唐朝，读书人的出路只有一条，那就是进入仕途，要么为朝廷做事，要么为将军做事。这是壮士心得以施展的必经之路，而要通过这条路，仗贵的友谊就变得必不可少。

所以在诗海里看到盛唐诗人热心地呼唤知音，一定要想到除了那些自甘淡泊的隐士之外，如曾往与有能身份、有技无人的人，要么是高高仕者，要么是未能自拔之人。

李白的《夜泊牛渚怀古》就是这样一种激越壮心来呼唤知音的诗。

# 1. 可遇而不可求的知己

《夜泊牛渚怀古》是李白年轻时代的作品，全诗五言八句。

你可以试着把它归一下类：它到底算五言古诗呢，还是五言律诗呢？

初学者容易理解这个问题，但如果你对唐诗有一定的感性认识，马上就会被它难住。律诗是新时代的诗歌体裁，讲律诗和律对仗，因为是很严的，所以对仗必须讲究合今律律，那么因应地，  自己则以对仗的联联种也不讲对仗诗联，更完全不讲究对仗的诗歌体裁，就被称为古体诗或古诗。

我们翻开《唐诗三百首》，它收录这首诗《夜泊牛渚怀古》，归入“五言律诗”的部分。它律似有章有道理，因为这样简单的律确实合律诗的规范，铿锵铿锵，比古诗清亮多了。但是，律诗中间四句应该两两相对，这首诗却全都没有对仗，所以把它归为律诗其实还是错误的。

我们既可以说它是有律味感的古诗，也可以说它是古体诗味道的律诗。这是李白诗的特点，对诗联文不太大讲究，只要少许所需就随意挥洒成篇，只有最高天才的人才会适合这样的写法。

诗题当中的牛渚，全称牛渚矶，就像你不熟悉这个地方，也可能听说过后来的名号：采石矶，它的位置在今天的安徽省铜陵市长江南岸，南东夹金陵著名的采石之战就是这里发生的。唐文化多以水景、大景充背景，这大概是每个中学语文都熟悉讲的一段历史。

在李白年轻的时候，牛渚矶虽然还没有发生过这样慷慨的故事，但刘寄奴还在长江水泊之处“此地商周谢安袁崇庆处”，说自己未怀的古老不边的事情，而是发生在谢尚和袁宏之间的一段往事。

事情发生在秋初，当时镇军将军谢尚镇守牛渚，在一个秋夜，临江而卧看江下风光，忽然听到附近的货船上传来吟诗的声音，吟诗的诗歌非常精彩，自己前所未闻。

谢尚又叫来人问到货船上的人情况，原来吟诗的是一个名叫袁宏的流民头儿，吟诗的语歌是他自己创作的《咏史诗》。这位袁宏虽然出身于书简门第，但谢尚早就有耳闻，只好在牛渚头码头，给其装备加货。如果不是谢尚的这次偶遇机会，袁宏上岸吐一肚子也报读不出体力劳苦的大运。

谢尚把袁宏邀请到自己的船上，越聊越投机，不知不觉聊到了天亮大家。后来谢尚袁宏做了自己的幕僚，袁宏的人生从此不同。

我们这段历史来看李白的诗，“牛渚西江夜，青天历片云”，开了见山，写出了夜泊牛渚，下接下来“登舟望秋月，空忆谢将军”，同一轮秋月下望见这里望见识谢尚和袁宏的相遇相识，但一个“空”字说出了李白的无奈。

这无奈从何而来呢？来自“余亦能高咏，斯人不可闻”——我当然能写出表袁宏一样的诗，  但高冷的江风上高吟高诵自己的诗，感怀在诗里面的壮志激烈，但像谢尚已经不可能碰到了，我也没能找到如当过谢尚一样的人。

我该何去何从？“明朝挂帆席，枫叶落纷纷”，明天一早还要继续航行吧，那样的早晨，枫叶一定会在秋风中纷纷飘落。

# 2. 羚羊挂角

这首诗《夜泊牛渚怀古》当然是一篇佳作，但要说它能代表唐诗的妙处，不管怎样是若干代表作之一，不知道你会不会同意呢？

维华小说有一种“高维消失”的经典诡计，比如爱德华·霍普的《辐射列车站》，或让人在雪地上行走着的一场车祸，或发现车雪地在  上栏杆突然消失；保罗·普尔特的《混血之子》，雪地上一定会有手走过去，可看不到凶手的身影。

其实在中国古人的知识里，羚羊天生就有这种本领。传说羚羊是一种叫“高维”的动物，每夜晚它会抱一块木头，在树上挂好，用角挂住树枝，身体完全悬空，这才能够放心睡觉。

如果有猛兽追踪羚羊的足迹，追到树下会茫然不知所措，想不透羚羊是如何凭空消失的。所以禅人们很喜欢说一句话：“羚羊挂角，无迹可求。”

你可以把羚羊的足迹想象成我们的语言文字，每一句话，每一个字都是看得见、摸得着的痕迹，要想体验会禅境，就必须超越语言文字之外。

宋释仁严写过一部《沧浪诗话》，借用禅宗概念，把诗歌艺术的精妙之处比附为“羚羊挂角，无迹可求”。

到了清，康熙年间有一位文坛盟主王士祯，到号渔洋山人，在诗坛提出了一个“神韵”概念，认为写诗用神的诗才是最好的诗。神韵到底是什么呢？简单说，其实就是羚羊挂角的境界。
