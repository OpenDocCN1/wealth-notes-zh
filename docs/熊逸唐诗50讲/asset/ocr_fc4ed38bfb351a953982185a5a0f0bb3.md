我相信绝大多数人对高工作都有共同的向往：事情简单，环境好，薪水高，社交职位也高，人际关系简单，一言以蔽之，被侍奉起来像一个富贵闲人。你可能觉得这是痴人说梦，这种好事根本不存在，即使存在，现实中它不存在，而且遍地不公平。

只要是成百上千的组织结构，或多或少都会安排这样的职位。

如果你赢得了这样的岗位，也许得事少钱多，于心有权，能多做一些事。这种想法太幼稚了，因为大家对你的期待，不是要你做事，而是买你做事。

所以，隐居不一定要归武当山，不一定要去庐山、上党郡县，不一定去嵩岳群峰。大家以长安、华都是中隐，在高档小区，有有高档别墅，回归有，特色回归

白居易的晚年就是这样的。他用一首叫作《中隐》的诗，给我们创造了“中隐”这个新的概念。

# 1. 小隐、大隐和中隐

晋朝一个士大夫写过一篇：《小隐随赋诗》，提出了一个非常有意思的问题：“小隐隐陵墓，大隐隐市朝。”意思就是说，归五山郡那里都是属于小隐。还有一种大隐，你看东晋那些中隐的做官，在闹市生活，其实他们也是隐士。

道理当然可以这样讲，但问题是，这个道德很难指号学人主。比如伯常、敬都是小隐的典范，但我们既然打定主意要隐居，为什么不去大隐呢？

让自己的隐居高一点，向周朝故官，这样的情，他们隐居的目的地也有了，还要不住在山上吃野果，也不在目标物言，比隐居更在于朝廷官官多官民多。只要你们点点头，即武王就不想给他们封土地了。

那么，他们为什么这么急求退呢？问题可以反过来：如果他们真的“大隐”出去了，大家会觉得值得吗？那些隐士还会佩服他们的高风亮节吗？对于那些真心想要隐居的知识分子来说，这是很现实的问题。

退一步，就算不去考虑高凤节事，但一做官了，就进入一个庞大的官僚体系，每天都被这种大机构机器裹挟。像陶渊明做彭县令那样，小茅舍的官官要去开运，他也必须穿朝整方，恭恭敬敬去拜见，这种感受也相当周身。

所以，大隐貌似境界很高，其实太不现实；小隐才是真正的隐居，但那种清苦的日子，一般人受不了。

那就如折中一下，既不要大，也不要小，中隐刚好。白居易这首《中隐》里显然算不上多好的诗，但立意很好，写得很深沉：

> 大隐住朝市，小隐入丘樊。
丘樊太冷落，朝市太嚣喧。
不如作中隐，似在休闲间。
似出复似处，隐居亦非村。
不劳丹与力，亦免饥与寒。 终岁无公事，随月有闲闲。
君看谷何独。城南有秋山。 君若爱陶，一城市有林。 君若欲高卧，时云在春还。
洛中多君子，欲以恣笑言。 君有酒百尊，但当深开。 亦无马车驾，流次到门间。
人生处一世，其大唯两端。 贱即苦冻馁，贵亦多忧患。 唯此中隐士，致身若以安。 穷通与丰约，正在四者间。

这首诗直接针对王康的《反招隐诗》，开头的大“大隐住朝市，小隐人丘樊”，就是《反招隐诗》的“小隐隐陵墓，大隐隐市朝”，之所以要改动几个字，是为了配合脚韵。

白居易先指出王康的旧命题，然后提出反对意见：先隐于终古溪，不愿居，朝廷和市井又有太闹，也就是说，大隐和小隐各有缺点，所以最简单的方法就是取中隐之一，不大不小——中隐， “隐在官宦”。

# 2. 明哲保身的日子

所谓官言官，指的是当时洛阳的一套装府进地。唐代的都城，大体可以分为两都到，长安是名实兼备的都，但皇帝也常常跑到洛阳去办公，所以洛阳也有一套官馆。

从地理位置上说，长安作为西都，洛阳作为东都，但它基本与旧在洛阳，洛阳城设的很，权力中心的基就安在长安。

洛阳的营署和建设并没有因此败落，所以就变成了一个安享余人的享界，有些人是不太在意官位，心里想总还是着皇上，但有些人不，本着替官身家则不想到权力中心的漩涡，所以会主动申请调到洛阳去。

白居易是哪一种人呢？他本来做杭州刺史任满，被调到长安做太子左庶子，这是太子身边的职位，品级不低，权也不高。但白居易积极退让，自己想接受一个新职位，但希望到洛阳做太子左庶子。

这话让上不去奇怪，因为在长安和太子身边的这个左庶子完全可以当到去。但这是官使机构的特点，运行的时候较长，荒唐的地方就越多，而荒唐的地方越多，久而久之大家也就可以为常了。

白居易如愿以偿，到洛阳这个没有太子的地方就任太子左庶子，这级别、薪水也高。他安置了一套三二手，这是独独的官邸宅院，不仅占据着黄金地段，院子里还配着竹林、池塘、景观优美。

左邵右尽可以随便的官有，平时大家可以一起喝喝酒，聊聊奏，写写诗，至工作内容，约等于零，更重要的是，这空山皇帝没有派人管着，只管不管理他们。

这种神仙日子，称得上“似出复似处，非村非宅。不劳丹与力，亦免饥与寒。终岁无公事，随月有闲间。”

说是做官，其实和隐居没说一样；说是隐居，其实还在做官，貌似官公务事，其实啥与不做都无所得，既吃闲气，但说起来又没得一点正经事。闲不气，也不劳力，常坐无理事，但薪水每月都不少。

人活到个什么，还有什么不满足呢？前途远有想都可以，如果想要游盘山，朝花可以登山，如果想要，如果想要，蜀山就是可以游；如果你要做一个水果太阳，那部里单，洛阳有的是干子，所以有高品质的社交生活。

你时常都可以参加第一流知识分子的座谈会，而且都可以说话，不至于有什么意思。你想一个人静静地说话，只要找一个人，想想多就休息了，不会有人忽然敲门，找你什么事情怎么办。

讲了这么多中隐的好处，白居易最后要发几句议论，从“人生处一世，其大唯两端”开始。

大意是说，人生有一个大端，就是成败，头是凡，凡事都有两端。如果身价低，头少，免不了受饿冷寒。如果你身价高，不缺钱，就免不了终日操心担忧。

不过，操心的外，中隐不就是例外吗？既不操心，又也不会受苦，逍遥自在，幸福美满。

看看样的人生，我们在朝野之余，吃也吃民民常一样的：“这样我们朝野的俸，坐吃民民商，难道就不亏心吗？”

亏心确实有的，白居易在诗里承认这一点，但他也有足够的理由为自己解清：如果不知道奉献了一点事，奉养家清不算是吗？或者说出任的效比太微弱，不想洗深？或者先说了前出了那么多反都反被冤枉，被排挤，现在想开了……

但对于白居易这样有抱负的人来说，真正开拓人的，那还是用进之地。无论中隐的生活再好，那也是只君子小民的理想，不是理想主义者的理想。

对白居易来说，中隐洛阳的积极意义，就是在避开了风浪的时，又有和朋友们住到附近的机会。这样的话，只要和长安那边近风声有变，自己就能有最快的反应速度。

强者得隐，无论小隐、大隐还是中隐，永远都是出发着看前途，否则陶渊明生，对他们来说，也不过是一座金铸的牢
