# 今日得到

秦韬玉晚唐一个不太出色的诗人，他全部的诗歌，尤其《贵公子》广为流传，特别引起共鸣，尤其是最后两句“苦恨年年压金线，为他人作嫁衣裳”。

这首诗像一名女性的遭遇折射出人类遭遇的不公平问题的视角，但苦，个人感受会很大的差异，不公平客观存在，不公，个人感受会不会有大的差异呢？

# 今日思考

第一个问题：不被社会认可的价值，有它存在的意义吗？

第二个问题：秦韬玉还有一首《寄怀》，写得很有见地—

总欲爷事风雷力，来催今如陈。

欲寄苦辛兼粒瘦，且张网络赖炎凉。

苏公肯留唐旧骨，莫替无穷黄发翁。

若有董宣太甲平，也应自道管夷求。

大意是恨天下如今已经一统，国家所延揽人才，无异于把英雄豪杰困在网里。只有在天下动荡的时候，英雄才有用自己的机会。好比战国时代，苏秦可以凭六道用臣，但如果遇到盛世，苏秦再有本事也不会有多大成就。这首诗倒是有拿来回应李白的《行路难》。

不过，你能赞同诗里的观点吗？欢迎在留言区分享你的看法。
