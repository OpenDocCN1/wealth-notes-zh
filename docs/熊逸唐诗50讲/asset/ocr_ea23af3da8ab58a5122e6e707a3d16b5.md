# 今日得到

李白的《南陵别儿童入京》里，明显题目只说到儿童，其实重要的人是“别君”。在君子那里受到的太多委屈，终于在这首诗里洗涤一空。

仔细想的看，虽然有点困惑，格局再高，但平凡人生的平伏与快乐，恐怕真的莫过于此了。

# 今日思考

你有没有相似的情境呢？先是在别人的轻视里无力反击，最后终于有机会扬眉吐气。

我相信很多人在这时候都会故作淡定的，但心里一定是暗爽着：“仰天大笑出门去，我辈岂是蓬蒿人。”你要不是这样的吗？还是像李白一样真正用语言行动表达出来了呢？欢迎在留言区分享你的经历。
