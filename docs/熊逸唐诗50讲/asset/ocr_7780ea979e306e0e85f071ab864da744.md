历代礼制有规定，礼仪上有所到的数字十二作为上限，超过十二就属于“非礼”。春年末周，暴发户因国吞食者多而粮食需多费，牛、羊、猪、谷各一百头，严重超过“十二”的标准，所以鲁国不干了，说吴国非礼自己。

吴国当然不背锅，反正十二也是礼仪标准。但是，像墨家第一篇《君访篇》里为什么偏偏提十二是十二家国的关系？《司马法》为什么说不少部分不是十二篇，《红楼梦》里为什么有金陵十二钗，都是《红楼梦》。

秦汉以后，数字的政治意义发生变化，“十二”的敏感逐渐渗透进神话世界，令人最难忘的神数字变成了“九”，比如皇帝是九五之尊，这是从《周易》来的。

你再读诗的时候就可以留心一下这些数字的意味：

凡是讲到建筑物之类可以体现礼制的东西，用“九”的（主要和皇家有关，比如“九天阊阖开言宽”）；十二主要也和皇家有关（李白《玉阶怨》：“十二娉娥临秋扇”）（李商隐《月夜重寄宋华阳姊妹》中也是。

# 今日得到

李商隐写于商朝的先锋字“朦胧”，他喜欢用华丽而华丽的意象，若若若无来表达炽烈而复杂的情感，这使得他的诗歌独树一帜。炽烈而复杂的，也很讲任何逻辑，读诗边美意的爱情诗大多出自他的笔下。

《锦城》三首是李商隐朦胧诗的代表作，描写道观禁地的隐秘爱情。

数字禁情是所有古代女性的共性，中国也不例外。在道教语境里，“十二”这个数常带有女性和仙修道有关。
