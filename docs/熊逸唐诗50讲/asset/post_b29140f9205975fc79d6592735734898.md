
## 30 柳宗元《酬曹侍御过象县见寄》| 如有隐忧，欲说还休

柳宗元《酬曹侍御过象县见寄》

> 破陂山前春浪远，骚人通沆太三舟。
> 春风吹不满湖湘意，欲采荷花白自由。

你好，欢迎来到《唐诗·盛唐50讲》。

有一种相聚很像吵架，两个人明明可以会面，却都懒得一开些原因：明明有千言万语想说，却只能问三不近凑：说了句话，然后匆匆分手。如果你也有过这种难缠的感受，就会很容易理解柳宗元的《酬曹侍御过象县见寄》。

### 1. 一默如雷

绝句在短小的诗歌体裁里，越是短小，就越是刻意在言内、内有意言未尽的意思。写怎样，内容才容易显示出这种效效果呢？我们的题是：叫一些没有的内容，用掉字的语话，读着那一股沉默，虽然沉默，什么都没说，也会给人知听雷响。

所谓没有内容的内容，当然不是真的没有内容。而在内容上情感，所分也千转。说《诗经·北风·柏舟》早就说过：“欲默不深，有隐忧。”

在唐朝的绝句里，最能体现这种味道的，莫过于柳宗元的《酬曹侍御过象县见寄》。隽永的语言，在似有若无的内容里，给读者留下了深深的品味。

我们先看一个诗的题目：“酬”的意思是“酬答”，一定是曹侍御先写了一首诗给柳宗元。礼尚往来，柳宗元才写了这首诗歌为酬答。

“曹侍御”，是一位姓曹的“侍御”，但是他对官职，重要是指他的职务“侍御”，这是封监察官的简称。唐代监察御史叫侍御曹台，大约相当于今天的检察。御史台每年出会派下大的官员，通过巡查监察御史，巡视各方，也就是地方的行政监察官。

既然监察御史是负责监察工作，既然监察的对象就是地方官员，那么可想而知，他们应该和远方官保持够一定的距离，指出当地的姿态，做好官地地方的监察。

而被监察的地方官员，当然也会怕被监察御史到什么事做，害得自己的性命。所以在接下来诗句里让诗题意思时，不复言半以为，当时曹侍御下查柳州时，有些监察事件，曹公会知“曹侍御”和“酬曹刺史”“酬曹孟相”的意义显然不同。

这位曹侍御“过象县见寄”，象县是今天的广西壮族自治象州北部新州县，在柳市市。柳宗元在当过刺的时期，正是担任柳州刺史，象县就是柳州下的一座县。

曹侍御“过象县”并不是从象县经过，而是到象县，所以古诗的“过”有“拜访”，也就是“拜访某人”过“过”意思是“到”是“到那里去”，过过“过”意思是“到”是“过过”意思，“过过过”的“过”是“经过”的意思，一般用的字是“经过”的“经过”。

现在题目意思就很清楚了：曹侍御抵达象县，给柳宗元写一首诗，柳宗元写了这首诗词为酬答，题目里还暗示出来三个信息。

第一，曹侍御和柳宗元应该有过交接；第二，曹侍御到象县应该借公务要事；第三，曹侍御是中洲县令，而曹县却是柳州下县，柳宗元是当时的柳市市长。

还有第四点就是题目中没有交代到关键字眼：柳宗元因此为政务斗争遭受中贬，又被贬到柳州这个蛮荒之地。

掌握这些基本信息之后，我们就可以来赏析这首诗《酬曹侍御过象县见寄》了。

> 破陂山前春浪远，骚人通沆太三舟。
> 春风吹不满湖湘意，欲采荷花白自由。

字面意思大概是这样的：碧绿的河水在破陂山前流远，那位骚人通地乘船下了船。美妙的春风仿佛要我们之间深厚的情感。我想采湖水中的荷花送给知己，却无法这样去做。

一旦把诗歌这样直白的解释出来，你一定觉得莫名其妙，不明白柳宗元到底要说什么。所以，我们必须先去体会这首诗词里的一系列南方方意象。

首先是“骚人”，因为屈原的《离骚》，人们称诗人为骚人。“木兰舟”则是古传中用木兰造船的小船，后来用作船舶。

“潇湘”是湖南一带的水系，湖南人常常用潇湘指湖南境内。今天我们可以觉得湖南是个偏远地区，而在古代，湖湘属于文明的地区，中平原华夏文明几乎是漫无边际的。

唐朝中原的人如果被贬到湖湘，那种感受或多或少会被出。如果再向南，到广西柳州这种地方，那就是万里投奔了。

“潇湘”作为诗歌意象，常与“死”和“愁”联系。大诗人杜甫“死在苍梧之野，他的两个知己为娥皇、女英闻夫之死后南下去，走到湘水的时候，一直为远别而悲伤，跳进湘水死去。李白有一首《洞庭西》说：“洞庭西，古寺基姜是二字，乃在洞庭之南，潇湘多泪”，讲的正是这个传说。

再看“荷花”，这是一种水生植物，有点像四叶草。南北朝时代，柳惓写过一首著名的《江南曲》：

> 江南可采莲，莲叶何田田。
> 鱼戏莲叶间，鱼戏莲叶东。
> 鱼戏莲叶西，鱼戏莲叶南。
> 鱼戏莲叶北，鱼戏莲叶间。

采莲、潇湘、故人、相思这几个意象的关联就是由这首诗奠定下来的。

### 2. “不自由”的不同向

让我们回到诗句，柳宗元有感于“春风吹不满湖湘意”，于是“欲采荷花”向别人曹侍御表达心意，但是曹“不自由”。不自由，为什么不能采呢？柳宗元没说，自曹以想象的空间就大了。

简单来想，曹侍御是查察官，柳宗元是地方文官，曹侍御“过象县来”的象县是刺史所辖区。所以两个人必然小心避嫌，被监察的首员不敢和负责查察官员亲密眼色，自相误会，不然两方自会丑言。曹侍御。

往复杂一点来想，柳宗元原于政治斗争中被贬黜打身入一个派系，所有敌对者，看不再有不自由，任何人敌对敌对，无法不及。他自当也清楚这一点，虽然看似，千万生怕一个“无所通湖湘意”的诗人，也把自己置于更加危险的环境里。

所以，不如就让人“适还太”，远远地相视，不如相见，多少话还没说出口，索性也就不说了。两个人就这样貌重逢，却没有太多的相握，互相颔首，却看不见他的“手书自交去”。这样的默契，却最是耐人品味。

你也许还记得语文课文里学的鲁迅的《为了忘却的记念》。那里有一段很著名的意思很长：“年前老舍向鲁迅告别时，鲁迅问他的什么有梦？鲁迅没有回答。然而，现在我们都。”

鲁迅的这类“不自由”，也有他“吟罢低眉无写处，不堪重提风漫潇湘，欲采荷花不自白。”吗？

你也许会问：“柳宗元如此充满隐喻的难道不会使故友困惑吗？”就算诗面上什么都没有，但是读到诗分也讲清了一半。

如果这样的的问题真问到了柳宗元头上，其实他还大有解释的余地，他会说：“你完全不理解诗么。”欲采荷花不自白”，不是说我不想从花来，采来采来送给曹侍御。

这样的解释完全可以成立，因为在唐朝人那里，“不自由”的意思既可以指自由自决，也可以指不是自由，也就是情不自意的意思。

表示前一种意思的诗，比如白居易的“巢燕巢太有人，大燕燕意不自白”（《喜钱校书及第》），表示后一种意思的诗，比如韦应物“百感中来不自持，角声孤起夕阳残”（《登楼州七楼楼长答长》）。

现代汉语里的“自由”只剩下第一种意思，它来从佛家说的。佛讲人生是都由自己牵系的，所以，不自由是指自由自由自白结果，人才才会自由自白是自由自由自白结果，不自由，只有思想才能得解脱，获得绝对的自由。

今天我们说“自由”时，常说的一句话就是“由我”。而“由”这个字在佛里也是出现的，“绝对的真我”是“绝对的自由”，“绝对的真我”是相伴随的“绝对的自由”，也就是说，你的存在仅为你的存在为而存在，而不依赖干任何人。任何环境。“自由”在于这个存在是决定出来的。

“不自由”的两种含义在这首小诗里可以同时成立，这首诗妙的处，同时也意味诗人的笔力。如取第第二层含义，正因为“春风不满湖湘意”，情过深太复杂，诗人才会情不自白来采荷花见寄。一首短诗饱含着隐痛的一下子就看得清清楚楚。

### 今日得刘

读古诗词，人们常常包含着诗词鉴赏。除了关键语，诗题中常常会包含着解读诗作的线索。柳元钦这首诗之所以需要拆解，诗题已暗示秘密。

"欲将花朵不自摘"留下了广阔的现实空间，这种做法在古诗词里虽不是没有，但不是空无意义，又有解释余地。于读者，它能在诗作和客观内容间保护作者周全。它能作"言回语余地；于审美，它让多重解释在一件作品里并行不悖。同时成立，产生解读的乐趣、朦胧的意境。

### 李商隐《碧城三首·其一》

```
碧城十二曲湖边，一醉沙鸥忆几年。……
```

你好，欢迎来到《简说·唐诗50讲》。

这一单元的诗都都爱和爱情有关，有，最大的一个特点是深情，明显正大的爱情很能催生好诗。尤其是一部分对少男、健康活泼、过情诗、心如死水、心无旁骛者。在温馨而太少的社会心里受到双方父母祝福的青年男女。

他们在昂贵的小世界里享受着傻呵呵哈的欢乐，穷奢欲乐，诗里，我们的爱情感，竟然没有怕一个眼圈里燃起情书与忌和遗憾的，这简直不给诗意的幼苗留下半点阳光和雨露。

第二类的爱情诗是相对自然中诞生的，而最常见的煎熬中来的，都是寂寞的禁果。

每个人的人生都是重重重重总点裹着的，同时也是作为别人的某种禁忌而存在的。

我们从小就自觉和不自觉在学习着如何去适应这些禁果。心都会勾成不为手那样的东西，‘七杆心’、‘人面心’，不连冠’。所有的禁忌都内化为自己固定的行为模式，无论怎么随心所欲都不可能出格。

但问题是，即便是孔子，也要修炼到七十岁才能达到这个境界。年轻人当然当得更，野性总还冲撞藩篱。

爱情的禁果最能让人们撕得头破血流，但禁果竟然可以变成快餐。压抑与爆发的纠缠形成了特有的张力。这样诗往往带着灼热的光亮或色，虽然很美很美却莫名。用今天的概念来说，这就是禁欲主义。

这样读诗，就像近纸欣赏高纯度印刷的版画，只需要美丽和纯净的各种色感，勾触满满画面，必须站在一定距离才能画出轮廓，但图面色彩线条往往是朦胧和模糊的。

画布上的色彩和笔触，也就是诗歌里的意象。古代注解家为明白这些图像，常常给出解读出意象。现代读者往往会在另一个极端，只爱色彩和笔触的美，却总造约图形和轮廓之外的。

理解朦胧诗，最好的方法是取中道，或者简，不离不近。朦胧诗的美要靠光影或色彩下欣赏，就像恋态的年纪那里都是秘或朦胧的表达。

唐朝人写爱情题材的诗，往往站在旁观者的角度，或者带着纯爱自己的心，很少带有真情实感。但很少地来读它的诗到到了。这时李商隐的特色使然。诗歌属于黄钟大吕，爱情却不是登大雅之堂的东西，所以李商隐才显得格外孤高可。

这个单元的诗，大多来自最适中的登器。在唐朝诗人里，把这种题材用到极致的人，只有李商隐一个。

《全唐诗》（好）间写了一位很有影响力的《金诗名句》，这样评价李商隐的：

```
望帝春心托杜鹃，佳人锦瑟怨华年。……
```

前两句化用李商隐《锦瑟》一诗的经典。后两句说，诗人虽然要写意爱的这种风格，但只可借他太晦涩，没有人能做出准确的解释。这就是李商隐朦胧的诗歌到了，其实所谓‘怨佳人独支’内容才真得‘诗总怨怨思而思’。

李商隐的《碧城》三首，反映中晚唐社会一种很特殊的恋爱关系，按下来便是唐代的几种著名的‘双美’，这几类主要事的前几篇文章，这类都是些省城，仿佛只要和美女住进与现实相关都省城，让自己得到确定的认识。

这些都是所谓唐诗里的异类，同样也是唐诗里最美的情感篇章。让一些看不清画的人置于唯美梦幻的场景中，做一场迷途或者有所失的梦。

从这一讲开始，我会花四倍的时间带你来读《碧城》三首，这一讲先来交代诗歌背景和第1首诗的第一个意义。

### 1. 道人士的长发和元始天尊的碧城

在中国历史中，有一个意象：即要得便比道教育得了更多的信徒，仿佛上帝远多于儒教的宫观，和知的人数也远多于道士，但是尼姑的人数偏比道姑少。

道制其实非常理解：女人出家，如果修禅，必须要剃光头发；如果修道，就可以继续保留一头长发，只是头上要戴一顶罩衣，所以女道士被称为‘天冠’，爱美是美女的天性，除非真的不想入俗，或实在在迫不得已，否则谁会情愿剃光头呢？

唐代为道教分房，常常干进修建的公主。大人物的举一发动总会牵动十万千万人的命运，公主嫁出宫家，宫女们当然也要以女奴的身份追随主人。

诗人卢仝有一次经过玉真公主前修道的道观，将所见到写间成一首小诗：

```
……
```

那些美丽少女，就这样在清静的世界里静静终身好的道喜，一天天熬成了白发通经的老夫人。

这让人联想起玉阳真那个‘若中女’的命题；那些在静静的山岩里盛开的莲花，如果换一种来看它们，真正的开放吗？或要换一种来？那些‘不食人间烟火，不爱着的美丽青莲，真的在开花？'

这种问题确实很容易让人伤感，但是，这些‘白发通经老’当初未必没有过轰轰烈烈的爱情。

我们想知道唐朝是一个夜很开放的时代，道观的高墙也许挡得住风雨，担得住生死，却挡不住翻越的爱。

是的，在这样的清修净地里面，男道士女道士虽然同居，大多好像是大学的研究员和大学生宿舍和女生宿舍，但大家没有初涉爱业的机会。

李商隐是在十六六岁时登上王阳山修道的。他并不真正的的奔往俗尘出俗修行，而是一份仙缘，过一种诗意的清静之地为习修道经典，准备做仙人的，当时的读书人住此过，几乎想都是一种风尚了。

所以于禁地之恋，他们既是目击者，往往也是当事人。我们不道是道士在庙观里玉阳山上到发生什么不可能道一声——李商隐有很多蛛丝马迹，却没有任何决定性证据。

他的诗总是会清不清楚，的《碧城》三首就是带给我们的不完整的意义。用各种本真的意象给我们留下一个不完美的拼图。

所谓碧城，道教典籍里有种说法，元始天尊的住处叫做碧城，所以碧城可以借指仙阙，再进一步指道观。

李商隐用‘碧城’这个题目写3首诗，这3首诗可以独立成诗，也可以合成为一组。如果当诗组诗来看的话，就会发现它们在内容上是从宏观到细节，从萌芽到成熟的。我们先来看第一首：

```
碧城十二曲湖边，一醉沙鸥忆往年……
```

读完这首诗，如果你完全没懂，这很正常。先不诗家人诗不是不说不明说，单看诗里的这些意象，就已经包含我们熟悉的诗歌如：流水、浮云、太阳……

正是这一道冷诗意象，营造出这一个不同于人间的碧城世界。所要理解这首诗，我们要先把握这些意象。

### 2. 天之八卦

‘碧城十二曲湖边’，乍看上去只是形容碧城边曲回曲折，但是，为什么特用‘十二曲’呢？是不是形容诗曲折难读‘九曲’吗，比如‘九曲黄河’？是因为字的限制到了？

当然不是，是因为诗人要太说好听的意思了，比如写‘碧城九曲玉真’，所以正确答案是：‘十二’是指清‘天之八卦’，没有比它更大的数字了。

可能定问到，‘十三道观不比十二大吗？’这真的不，因为十三意味着‘天荒’运转一轮之后重新开始，也就是十二之后的‘一’。

古人用‘十二种’，每年称为‘天’环绕天空一年，每年经过的岁数各为‘一次’，这是流出生出了‘天’这个很常的‘一周’，‘一次’是这些概念‘十二’构成‘一周年’，所以‘十二’被称为天之八卦。

周代礼仪有规定，礼上用到数字十，超过十‘非礼’。春秋年月，鲁发与吴国发生两起鲁国贵素要贵素，要牛……

历代礼制有规定，礼仪上有所到的数字十二作为上限，超过十二就属于“非礼”。春年末周，暴发户因国吞食者多而粮食需多费，牛、羊、猪、谷各一百头，严重超过“十二”的标准，所以鲁国不干了，说吴国非礼自己。

吴国当然不背锅，反正十二也是礼仪标准。但是，像墨家第一篇《君访篇》里为什么偏偏提十二是十二家国的关系？《司马法》为什么说不少部分不是十二篇，《红楼梦》里为什么有金陵十二钗，都是《红楼梦》。

秦汉以后，数字的政治意义发生变化，“十二”的敏感逐渐渗透进神话世界，令人最难忘的神数字变成了“九”，比如皇帝是九五之尊，这是从《周易》来的。

你再读诗的时候就可以留心一下这些数字的意味：

凡是讲到建筑物之类可以体现礼制的东西，用“九”的（主要和皇家有关，比如“九天阊阖开言宽”）；十二主要也和皇家有关（李白《玉阶怨》：“十二娉娥临秋扇”）（李商隐《月夜重寄宋华阳姊妹》中也是。

### 今日得到

李商隐写于商朝的先锋字“朦胧”，他喜欢用华丽而华丽的意象，若若若无来表达炽烈而复杂的情感，这使得他的诗歌独树一帜。炽烈而复杂的，也很讲任何逻辑，读诗边美意的爱情诗大多出自他的笔下。

《锦城》三首是李商隐朦胧诗的代表作，描写道观禁地的隐秘爱情。

数字禁情是所有古代女性的共性，中国也不例外。在道教语境里，“十二”这个数常带有女性和仙修道有关。
