# 今日得到

《春江花月夜》是乐府旧题，作者一暮《春江花月夜》的作者是初唐的这一位并非只著名的诗人，只有两首诗作传于世，生平事迹也几乎未知。

张若虚的《春江花月夜》直到明朝才被人们重新起卷，评价越来越高，使得着者虚怀仅凭一首诗就成为唐诗大家。

《春江花月夜》以淡妙的清幽之笔写人生的终极问题至美或当与读到解，可以看到哲学问题的诗味解解。

> ### 春江花月夜（摘录）
张若虚

江天一色无纤尘，皎皎空中孤月轮。
江畔何人初见月，江月何年照他人。
人生代代无穷已，江月年年相似。
不知江月待何人，但见长江送流水。

#### 时间都去哪了#
我再一次意识到时光飞逝，是在小学毕业那年。漫不经心的小学时光，曾经给一种感觉，就好像我们这班同学要长久了，然而，当我意识到时候，突然就散了，自己感我的人和时光，我要抓紧现在了。也就从那天起，我发现我是一个比较喜欢记录的人，尤其是记录生活。所以，我也比较着替别人拍照，就是记录，比较能体会「人生代代无穷已，江月年年相似」的那淡淡淡淡的哀愁。

我的读感，《春江花月夜》已经在大学了，诗中的意境，选送让我从我的心神中飘飘欲仙，明月之下，花间和月下，眼前满下绿水的水面层层叠叠，默然内心。读这一遍时，感觉自己是画中的心心，读这两遍后，感觉自己渐渐远记，画卷缓缓铺展，自己像江边游的树木一般，成熟画面的一角。

意识的时光来远，这端要快要可一个人，站在江边，或远或去，或远遥星，但是能是谁，星光在流逝，世界上有什么力量可以阻止时光的流逝呢？没有的，我们何暂且行自己的尊份，还除了只是，是任何我们，让自己的感官只的时态，让自己看到更久，更宽视野更广阔的自己，在漫目的时光中，记录下，记当下的小情，若干年后，在录回字中记下，或者我们任我们自己的感觉。
