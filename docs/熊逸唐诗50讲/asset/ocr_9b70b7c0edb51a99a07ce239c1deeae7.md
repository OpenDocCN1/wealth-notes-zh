# 李白《行路难 其一》

```
金樽清酒斗十千，玉盘珍羞直万钱。
停杯投箸不能食，拔剑四顾心茫然。
欲渡黄河冰塞川，将登太行雪满山。
闲来垂钓碧溪上，忽复乘舟梦日边。
行路难，行路难，多歧路，今安在？
长风破浪会有时，直挂云帆济沧海。
```

你好，欢迎来到《唐波·唐诗50讲》。

这一单元的主题是“忧愁”，顾名思义，全都是人生负能量。

没人喜欢负能量，尤其是别人散发出来的负能量。但是谁的人生都不可能避免地产生负能量，这些负能量到底可以从哪里排遣掉呢？

总不能一唱起怨气来，直到呕血刀子，搞到精神失常吧？确实有些人负能量面大苦，归纳就是心里不豁达，用固定的视角解释自己、理解社会，连二进三地制造悲剧。

我们今天总在呼唤正能量，不喜欢那些散发负能量的人，无论他可能来自自己装扮成阳光开朗的样子，但问题负面能量并不会因此消失。

怎样消除负能量？不同的人有不同的办法。大体来看，有文化的人借助文学，没文化的人借助酒精。

威廉·詹姆士说：“对于那些贫穷的、受教养程度低下的人来说，酒代替了艺术俱乐子和文学。”这这话的意思就是，酒和艺术都是解药，都能把人带入一种迷迭状态，向上—途能使人亢奋，向下，物我两忘的神秘体验，经一下途可令人消愁解愁、忘记苦痛。

艺术欣赏可以起到很好的情感宣泄作用，但艺术创作才是最好的出口。对于开辟艺术又有文化才华的人，艺术酒好的以宣泄和解毒，李白就是典型。我们在李白的诗里总能看到醉酒和诗喝，好像全世界都对不起他。

这不是一种十分罕见的的心态，只是普通人也会像他一样是活得所见所感，尤其是遭遇强大的人格修养是先天不良，不尤人；只问对错，不问得失，就有谁怨态无人言，计较得失成败，最好表现得太过自怨。

所以李白也是个另类人物，在唐代所有诗人当中，只有他一个人真正意义上让自己恣意挥洒成河，把负面情绪全部释放宣泄地宣泄出来。这显示出艺术的功能到底有多么重要，它让李白成为李白，而没有成为竹林损。

盛唐时期的忧愁，当然不止出于个人际遇上的苦恼，更有忧国忧民、拍岸击岸的愤怒。不忧时以忠君报国者的热忱，就谱出江疆爱的爱情诗章的李商隐，也倾诉过许许多多的虚伪者恨。

但在我的选择标准里，为什么集中在个人际遇的方面呢？因为在古人看来，知识分子的巨大际遭和国家的政治命运是关联一致的。君臣互见的关系上，不仅意味着知识分子的自我实现，更意味着春天万物生长和千秋万代的都会从他们的自我实现当中受益。

所以在他们的诗歌里边，对散发负能量这种事，倒没有像今天我们那么多的忌讳和不好意思。古代许多差事，是我们理解唐诗尤其需要留意的一点。

这个单元就从李白的《行路难》说起，这一组三首各有精彩，也各有各的名句。接下来再讲一讲晚唐的钱某，钱某写的名篇《夜来》。如果说李白的忧愁是有生命的，那么韩玉的的仇恨就是无声的狠毒。两种风格，两种极致。
