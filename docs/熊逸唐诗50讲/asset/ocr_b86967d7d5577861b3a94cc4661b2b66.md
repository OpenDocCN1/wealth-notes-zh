# 李商隐《碧城三首·其一》

```
碧城十二曲湖边，一醉沙鸥忆几年。……
```

你好，欢迎来到《简说·唐诗50讲》。

这一单元的诗都都爱和爱情有关，有，最大的一个特点是深情，明显正大的爱情很能催生好诗。尤其是一部分对少男、健康活泼、过情诗、心如死水、心无旁骛者。在温馨而太少的社会心里受到双方父母祝福的青年男女。

他们在昂贵的小世界里享受着傻呵呵哈的欢乐，穷奢欲乐，诗里，我们的爱情感，竟然没有怕一个眼圈里燃起情书与忌和遗憾的，这简直不给诗意的幼苗留下半点阳光和雨露。

第二类的爱情诗是相对自然中诞生的，而最常见的煎熬中来的，都是寂寞的禁果。

每个人的人生都是重重重重总点裹着的，同时也是作为别人的某种禁忌而存在的。

我们从小就自觉和不自觉在学习着如何去适应这些禁果。心都会勾成不为手那样的东西，‘七杆心’、‘人面心’，不连冠’。所有的禁忌都内化为自己固定的行为模式，无论怎么随心所欲都不可能出格。

但问题是，即便是孔子，也要修炼到七十岁才能达到这个境界。年轻人当然当得更，野性总还冲撞藩篱。

爱情的禁果最能让人们撕得头破血流，但禁果竟然可以变成快餐。压抑与爆发的纠缠形成了特有的张力。这样诗往往带着灼热的光亮或色，虽然很美很美却莫名。用今天的概念来说，这就是禁欲主义。

这样读诗，就像近纸欣赏高纯度印刷的版画，只需要美丽和纯净的各种色感，勾触满满画面，必须站在一定距离才能画出轮廓，但图面色彩线条往往是朦胧和模糊的。

画布上的色彩和笔触，也就是诗歌里的意象。古代注解家为明白这些图像，常常给出解读出意象。现代读者往往会在另一个极端，只爱色彩和笔触的美，却总造约图形和轮廓之外的。

理解朦胧诗，最好的方法是取中道，或者简，不离不近。朦胧诗的美要靠光影或色彩下欣赏，就像恋态的年纪那里都是秘或朦胧的表达。

唐朝人写爱情题材的诗，往往站在旁观者的角度，或者带着纯爱自己的心，很少带有真情实感。但很少地来读它的诗到到了。这时李商隐的特色使然。诗歌属于黄钟大吕，爱情却不是登大雅之堂的东西，所以李商隐才显得格外孤高可。

这个单元的诗，大多来自最适中的登器。在唐朝诗人里，把这种题材用到极致的人，只有李商隐一个。

《全唐诗》（好）间写了一位很有影响力的《金诗名句》，这样评价李商隐的：

```
望帝春心托杜鹃，佳人锦瑟怨华年。……
```

前两句化用李商隐《锦瑟》一诗的经典。后两句说，诗人虽然要写意爱的这种风格，但只可借他太晦涩，没有人能做出准确的解释。这就是李商隐朦胧的诗歌到了，其实所谓‘怨佳人独支’内容才真得‘诗总怨怨思而思’。

李商隐的《碧城》三首，反映中晚唐社会一种很特殊的恋爱关系，按下来便是唐代的几种著名的‘双美’，这几类主要事的前几篇文章，这类都是些省城，仿佛只要和美女住进与现实相关都省城，让自己得到确定的认识。

这些都是所谓唐诗里的异类，同样也是唐诗里最美的情感篇章。让一些看不清画的人置于唯美梦幻的场景中，做一场迷途或者有所失的梦。

从这一讲开始，我会花四倍的时间带你来读《碧城》三首，这一讲先来交代诗歌背景和第1首诗的第一个意义。

# 1. 道人士的长发和元始天尊的碧城

在中国历史中，有一个意象：即要得便比道教育得了更多的信徒，仿佛上帝远多于儒教的宫观，和知的人数也远多于道士，但是尼姑的人数偏比道姑少。

道制其实非常理解：女人出家，如果修禅，必须要剃光头发；如果修道，就可以继续保留一头长发，只是头上要戴一顶罩衣，所以女道士被称为‘天冠’，爱美是美女的天性，除非真的不想入俗，或实在在迫不得已，否则谁会情愿剃光头呢？

唐代为道教分房，常常干进修建的公主。大人物的举一发动总会牵动十万千万人的命运，公主嫁出宫家，宫女们当然也要以女奴的身份追随主人。

诗人卢仝有一次经过玉真公主前修道的道观，将所见到写间成一首小诗：

```
……
```

那些美丽少女，就这样在清静的世界里静静终身好的道喜，一天天熬成了白发通经的老夫人。

这让人联想起玉阳真那个‘若中女’的命题；那些在静静的山岩里盛开的莲花，如果换一种来看它们，真正的开放吗？或要换一种来？那些‘不食人间烟火，不爱着的美丽青莲，真的在开花？'

这种问题确实很容易让人伤感，但是，这些‘白发通经老’当初未必没有过轰轰烈烈的爱情。

我们想知道唐朝是一个夜很开放的时代，道观的高墙也许挡得住风雨，担得住生死，却挡不住翻越的爱。

是的，在这样的清修净地里面，男道士女道士虽然同居，大多好像是大学的研究员和大学生宿舍和女生宿舍，但大家没有初涉爱业的机会。

李商隐是在十六六岁时登上王阳山修道的。他并不真正的的奔往俗尘出俗修行，而是一份仙缘，过一种诗意的清静之地为习修道经典，准备做仙人的，当时的读书人住此过，几乎想都是一种风尚了。

所以于禁地之恋，他们既是目击者，往往也是当事人。我们不道是道士在庙观里玉阳山上到发生什么不可能道一声——李商隐有很多蛛丝马迹，却没有任何决定性证据。

他的诗总是会清不清楚，的《碧城》三首就是带给我们的不完整的意义。用各种本真的意象给我们留下一个不完美的拼图。

所谓碧城，道教典籍里有种说法，元始天尊的住处叫做碧城，所以碧城可以借指仙阙，再进一步指道观。

李商隐用‘碧城’这个题目写3首诗，这3首诗可以独立成诗，也可以合成为一组。如果当诗组诗来看的话，就会发现它们在内容上是从宏观到细节，从萌芽到成熟的。我们先来看第一首：

```
碧城十二曲湖边，一醉沙鸥忆往年……
```

读完这首诗，如果你完全没懂，这很正常。先不诗家人诗不是不说不明说，单看诗里的这些意象，就已经包含我们熟悉的诗歌如：流水、浮云、太阳……

正是这一道冷诗意象，营造出这一个不同于人间的碧城世界。所要理解这首诗，我们要先把握这些意象。

# 2. 天之八卦

‘碧城十二曲湖边’，乍看上去只是形容碧城边曲回曲折，但是，为什么特用‘十二曲’呢？是不是形容诗曲折难读‘九曲’吗，比如‘九曲黄河’？是因为字的限制到了？

当然不是，是因为诗人要太说好听的意思了，比如写‘碧城九曲玉真’，所以正确答案是：‘十二’是指清‘天之八卦’，没有比它更大的数字了。

可能定问到，‘十三道观不比十二大吗？’这真的不，因为十三意味着‘天荒’运转一轮之后重新开始，也就是十二之后的‘一’。

古人用‘十二种’，每年称为‘天’环绕天空一年，每年经过的岁数各为‘一次’，这是流出生出了‘天’这个很常的‘一周’，‘一次’是这些概念‘十二’构成‘一周年’，所以‘十二’被称为天之八卦。
