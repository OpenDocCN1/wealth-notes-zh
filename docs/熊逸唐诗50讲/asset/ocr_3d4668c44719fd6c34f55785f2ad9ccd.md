# 1. 维摩诘其人其事

王维的禅意，禅意中人四大皆空的道理，认为财富是修行的束缚、解脱的阻碍。王维难道不明白这个道理？

这个问题要从王维的名字说起。王维，字摩诘，虽然他的名和字在语义上都没有关联，但也联系王维姓维的达真维摩《华盖摩诘经》，维摩诘经的主人公维摩诘，也把他寄身的中国名称和佛道学习和写作，而王维的人生也真的在维摩诘经中获得了智慧。

《维摩诘经》的偈译名，是《维摩诘所说经》，是大师佛教重要经典，站在大乘立场批判小乘教条。佛教传入中国之后，大乘和小乘的竞争远不如在古代印度那么激烈，所以中国人反而更容易从静气佛学中习得智慧。

这部经里的维摩诘，表面上是毗耶城的大富豪，其实是佛菩萨，尊号不动如来。他示现疾病，以“空”字为佛说法，并度化众人。《维摩诘经》第二品，维摩诘示疾，在佛教界中是“第一义谛”，也是经中的核心。

小乘佛教讲解脱，该守的戒律一定要守。而大乘佛教可以随缘说法；只要心态是端正的，手脚就可以灵活活动；只要心态是坚定的，生活就可以随心所欲。

维摩诘虽然是个富豪，那么随遇而安的生活当然就可以享受了。他倚靠富贵、禅观玄理、化妻、助友，以及施药、布施、供养、赞叹，甚至以入风神为佛。

所以《维摩诘经》的出现意义非常重大，让社会各阶层的人都以入富贵时享受精神，或特别赞赏佛陀和佛可于求法者的时空精神。

酒肉穿肠过，佛在心中留。至于不要把“出家人”，那非但要多，更要无所得。不出家并不妨碍成佛，人家维摩诘都没有出家，始终保持着“白衣”的身份。

僧人该穿什么颜色的衣服呢？今天我们在寺院里见到的僧人，还穿影视剧里常穿的僧人，日常大多穿黄色袈裟，其实这是从清朝延续下来的传统。

追本溯源的话，就这个，本义是不正、不、不俗的颜色，出家人不该穿好白，所以衣服必须用坏，除青、黄、赤、白、黑这五种纯色是允许的。

白衣就是纯粹的服装。在古代中国，这是佛教以外的人穿的朴素衣服，穿罗汉和俗众穿外家。所以佛经里说，穿“白衣”这向来代表俗人，用“白衣”或“染衣”代指僧人。

“缁衣”是黑色但略带黄或无的无染色，在古汉语里，叫“缁”，当“无染”讲。意思是“缁”是“缁袢”、“染”。

但是在儒家传统里，“缁”和“白”另有一种含义。《礼记·曲礼》中说：“用之不白，”“白”是“非白”的意思。孔子不说“白”是“非白”，是“白”，“非白”是“白”，“非白”是“白”，“非白”是“白”。

南北朝时，太诗人谢灵运写过一个名句：“谁服衣杂染，维摩亲来。”（《酬王长史》）这个意思就是说，人太大会杂染，愿太平干净的大众维摩诘上土再回来，引申来说，在大都会时间久久，志和品格都被那里的繁华熏染了。
