# 1. 洞房与辟芳

《碧城》第二首描写恋爱中男方，第三首把 重点放在女方身上。

我们先看第一句：“七夕先来小有期”，字面 上很好理解，两个人提前约好在七夕约会，但 七夕早已经过去了。“闲房停宿至今昏”，洞 房的帘幕依然没有打开，等候的人始终未来。

既然说到洞房，恐怕这一对情侣有了婚约，毕 竟在现代人的印象中，只有结婚才谈得上“入 洞房、还世情”。

但洞房的本义是幽深的房间，今天我们住酒 店，如果住的是套房，最里面的那一间就可以 说是洞房。

有人在洞房里边痴心等待，有人在洞房外还进 还不出来，这是恋人的任何一方大在家里都还可 能发生的场景。也有简斋诗人将第一流的洞房， 他的修证一定要有高尚的地方。

我们回头来读一句“七夕来小有期”，这可不 是单纯的叙写，而是用了一个神仙典故。正是 那些神仙感物、非仙则幽的，营造出碧城这样 一些处虚幻缥缈又真切的时空。

典故出自道教经典《汉武帝内传》，用今天的 视角来看，这本书应该是一部魏晋南北朝的神仙 小说，文字很华丽，细节很浪漫，讲述与汉武帝 相关的故事。

书里说到，元封元年（前110年）四月戊辰日， 在一个很有灵气的阴云，武帝正在强华殿休 息，东方朔和董仙的除名，忽然显现出一名 美丽的青衣女子，说自己是碧虚宫玉女王子 登，受玉君的差遣从昆仑仙来。

王西母听说武成帝求心术，说会在七月七 日那天来见汉武帝，要求武帝准备七盒不同 一品。一天，东夷南翔不得过，汉武帝的 从西边历了，到了七月七日晚上，果然有 来七盒不同的玉果来，西母帝带来了仪仗 歌舞，声势浩大地降临人间。

汉武帝和西王母就这样开始了偷快的会合，而 在李商隐的诗句里，事情竟然反了过来，在等 的人始终未来。

也可以等待下一个见面的日子，但时间似乎 很紧迫。读“玉轮顾散仙尘断，铁网珊瑚未 有枝”，读者可能会认为两个美好，李商隐是 出自一个不同的现实：女方已经有了

“玉轮顾散，又何自圆”原句“玉”，而“圆” 在题？”月亮有什么了不起的本事，竟然可以 和月轮？月亮的月影影那是什么？月亮的肚子 里是不是有一只小兔子？

《天问》和《楚辞》里的其他难题一样，很难 对下一句找出确定解释，不过这不重要。我 们只要知道死人的规矩理解就可以。月亮 缺圆，死而复生，肚子里的小兔子“月 生”。

“铁网珊瑚未有枝”用到了另一个更加生僻的 典故：海边的人们为了采珊瑚，会先做一张 铁网，把它沉入海底的岩石上。珊瑚长在石上， 缓慢生长，等到珊瑚枝茎足够坚韧的时候，就 可以收回铁网，把粘好的珊瑚捞上来。

唐代诗人韩云曾有一首《赠看花者书》，说 “管得仙洞人，要得珊瑚树”，这种 诗的妙处就是浪语，意思是，我是一下网 捞起来的

当珊瑚还没有枝的时候，也就是刚刚生长 出来，还没有长成枝茎的时候，铁网是捞不 它出来的。而人并不知道珊瑚是自由缓慢生长 的，慢慢堆积起来的，如果只凭肉眼观察到， 可能会慢慢堆积起来的，如果只凭肉眼观察到

仔细体会这两句话，所有的意象都暗示出萌芽、 新生、孕育。

# 2. 辟芳之后

这一对小情侣想来有点手足无措，该怎么办 呢？“含情，举方”，“举”，“上”， 是“封禅（jì nà）”，把封禅加在口头上。“神方” 就是神仙仙方，也是修好的秘宝。“辟 藏”的意思是常住，引申义是长生不老。

这一句的上下文还是来自《汉武帝内传》：汉 武帝喜欢西方的上古天女家仙子，自己仙方， 上天下凡，至于简，传说她“六甲左右 之上下方七十二周”，简是仙子的修身 秘法。这类东西很荒诞很玄奇，所以很华 丽的“八色玉芝，文言之篇”仔细包装。

如果说联系进洞房里的真实，诗人或许 也联系到入迷了某个方子，或者药品，或者 礼品。希望两个人都健康，而神仙 人收到景异，而仙家仙家仙家仙家。

但这样的秘密恋情终究是要露馅，那该他们 还能怎么办？“武皇内传分明在，莫道 云间总不知。”诗句中武皇内传分明， 也就是《汉武帝内传》。
