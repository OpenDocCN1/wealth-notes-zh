
## 32 李商隐《碧城》三首21 禁地之恋

你好，欢迎来到《颜歌·唐诗50讲》。

这一讲我们继续梳理《碧城》第一首诗里的冷僻意象。先来复习一下这首诗：

```
碧城十二曲栏杆，头角端枭锦带官。
宝月夜开莲眼静，女真香断玉龙寒。
霜晴野落当开眼，雨过溪湍涨碧澜。
若此晓珠犹又定，一生长在水晶盘。
```

这些意象勾勒出真正的女神气质，归纳起来只有两个字：高、冷。自古至今，当人向往的女神都是高冷的。这是来自天空佳人的道理，所以放在今天照样适用。

女人如果不高不冷，就容易激发男人的征服欲。而在热烈的爱情里，征服从来都是必不可少的。

### 1、没有温度的人间仙境

三国时代的嵇康是当时很闪光的一位知识精英，他聪明，也很有学问。他写过一篇《养生论》，探讨长生不老的问题。他整体很显然对长生里谁也没有见过神，但各种图画、史书里记载过那种神仙样子的总，不可能是瞎编的，所以说神仙一定存在。

我们不该夸嵇康，因为他那时候还不知道人们很容易相信自己愿意相信的东西，市场也特别喜欢满足人们的期望。如果大家都希望地球有两个月亮，那关系到第二个月亮的理论一定会有很多很多。

如果你像嵇康一样喜欢古籍，你会发现关于神仙的奇闻轶事一样记载的很多，相关的记载甚至还可以彼此印证。

比如有一本叫《述异记》的书，说海里有一种神名叫山，名叫赤龙洞。如果把它的耳朵取下来，放到房间里，房间从此一尘不染，再也不用打扫。

还有一本叫《岭南异异》的书，说蛇之属的角被发现用作干净的牙齿，女子涂上这种发青，头发永远干净又亮，再也不怕洗头发。

《杜氏通仙记》也是一本书，说唐玄宗会昌五年，（841年），会昌国卖了一种红色的玉石，叫女牛玉，能发出红光。如果你拿它往器皿里滴满清水，再拿几块玉放到底下，那么很快冷水就会沸腾。

正经一些读书人会咨询这些故事，有学者“子不妄传”之乱，这是古籍，但奇闻异事是很有说服力的。李商隐喜欢读这类书，所以写诗才会有些特特的形象和语言风格。

在《碧城》第一首里，开篇：“碧城十二曲栏杆，丹凤空上端枭官”。简要交叠成双雄城的风格，这种用尾巴的尾巴，还有奇异的异宝，用犀牛角而不是扫麈和拖地还有巨，用火玉而不是柴来取暖。但有什么奇怪的呢，仙家难道不应该是这样子吗？

仙缘当然应该是这样子，但双雄里边一定不是这个样子的，李商隐的《碧城》三首是写观道生活的。

这就是诗歌的艺术，用话接事实的很来说成文字表达，于是诗仙好像写的完全在道观和想象里的仙宫云岛。仙宫云岛一样的仙宫云岛，让人觉得虚的一笔也许是写实，做梦似真，让人难忘。

接下来的两句继续写仙宫：「阁夜有书斜鹤，女真无树不栖鸾」。阁夜和女真是神仙们的两处仙宫区。

你对阁夜也许会很陌生，因为《红楼梦》里有一个是阁夜仙宫，一个是灵虚玉无瑕，林黛玉的世就是阁夜里的一座炼丹房。阁夜的金云叫羽灵之苑，坐落在昆仑山上，是西王母的住处。

女床并不是女人住的，而是女仙山——座仙山。

「阁夜有书」，这里的书不是书籍，而是书信。仙鹤是道教的使者，当信使捎了之后，系在仙鹤的腿上，它送到收信人的手里，这就是「阁夜有书斜鹤」。

而女床上树，根据《山海经》的记录，有一种凤凰，叫青鸾，也叫青。每一棵树上都有鸾凤栖息，这就说「女床无树不栖鸾」。

在道观的世界里，禽往往象征君臣。那么，阁夜里的这些信是神交给这些君子的吗？或者，是写给这些君子的吗？里边到底说说了什么呢？

道教仙有那么多，诗人为什么会偏偏选了女床山呢？又写的是仙女，为了收编仙山，也省了一“山”字便保留了“女床”这两个字吗？阁夜和女床是不是真的有彩影封？因为山看上去像是分别指代男道士的住处和女道士的住处。

但如果阁夜真是阁夜，女床山真是女床山，神仙们每天过的日子就是「雨凝海落当开眼，雨过溪湍涨碧澜」，窗外的雨会纷纷洒下，还可以看到窗外雨水过溪河源头的景象。

李商隐是一个非常精于典故的人，这一组对比充分见出他用典的功力。「雨」真的是一对双源的源头吗？旁边边注说，周院有昆仑之高，蜀唐人认为那里就是黄河的源头。

但黄河的源头又说明黄河，又有一部古书《河图玉册记》，说汉朝打通西域之路的名将张骞经常派进关里去探源寻河识，不知不觉一路走到铁门，还见到了牛、织女。

那么继续探究下去，就可以从黄河之源来到银河，这也就有「昆仑海落当开眼」，银河好像春天可以大海岸，这样的奇观，凡人不敢想象，却更添神性的日常。

诗的最后两句特别让人迷惑：“若是晓珠犹又定，一生长在水晶盘。”晓珠是什么，水晶盘又是什么？这样只引出这两句的诗，解读者只能从每种意象上可以申出到这两句诗，对整首诗有不同的理解。

在我的理解里，当「晓珠」和“水晶盘”两个意象联系起来的时候，我就可以推断，这应该是来自汉或宋的一则歌诀：

```
汉武帝曾在宫里建造过一座水晶室，顾名忘义，高阶六尺可以云开。又在天然水晶上合承雨露盘，天上来云星辰天的寒露在组合成水珠，和玉石的阵一起服用，相信这样可以成仙。
```

唐朝诗人王昌龄写过一首绝句《甘泉歌》：

```
紫泉望上仙药，雨沾古衣香雾湿。
时逢玉井冰净，万年长在水晶盘。
```

这首小诗让汉武帝开水晶宫的场景再现。但在那个充满玄幻的水晶盘里，真的有所谓「万年甘露」吗？甘露一定是有的，但那一滴雨水也并不会长生。

在李商隐的诗句里，「晓珠」就是露水，「水晶盘」就是承载，露珠晶莹剔透，露珠一样动人，无水，不长生。

「若是晓珠犹又定，一生长在水晶盘」的意思是：

如果露珠可以长生，那就说明神仙之遭并不荒唐，那么在水晶盘下耗费一生，天天窗风览道，这样的牺牲一点值得。

但是，露珠既然不能长生，神仙之遭也不一样的虚幻无望，为之不过虚耗青春，青春都是无法的，究竟又怎能值得？如果花半辈子的功夫，不如去追求清规戒律的太玄观，只想做耳畔清露里的小仙童，也许算不得难过。

当然，这些意思诗人都不曾说，但只要读懂了「珠」和“水晶盘”的难题，就不自己提出了这些问题，转而想要现里的青春是不是虚度？

“碧城十二曲栏杆，丹凤空上端枭官”是问有没有女神，对于不高冷的人情？「阁夜有书斜鹤，女床无树不栖鸾」的歧义是观是否有意，是不是非该该遭遗弃，反不应该被祝福呢？

### 2、修仙的迷狂和诗人的态度

这样的意思看上去很有实际的意味，但在道观里迷了青的上去到底实并不相信神仙。

在李商隐生活的时期里，唐宗宗用道金丹发了疯，被官吏害死，外孙宫道是金丹丹死的；唐穆宗是真是服金石亡，唐宪宗也是个金丹狂人，在脱胎换骨的修道里真正的脱胎换骨，只不过是从正常人变成了喜怒无常的疯子。

“胎脱换骨”这个成语就是从道来的。道教的信徒通过服食金丹药丸，人也可以说金丹药，换上仙胎脱凡胎，羽化他生。据说完脱胎换骨的时候，道工会给他安心，这就是脱胎换骨的正宗表现，是好消息。

由一代一代帝皇唐引导的玄门迷狂，李商隐选择带着冷静，在诗里表达暗道暗道地表达讥讽和同情。著名的作品比如《瑶池》：

```
瑶池阿母绮窗开，黄竹歌声动地哀。
八骏日行三万里，穆王何处去来？
```

这首诗既是怀古，又暗指王和王的去事。传说周怀王是“旅游家”，驾着四辆八骏马驾的仙在云里转周间，在乾丘山遇到了美丽的西王母。两个人偎缘接，乾...

这首传统以怀古，怀的是周瑜和东五西八的故事。传说周瑜不是广陵县人，驾着一辆帕八匹御驾到长县的西汉越王楼替朱元璋看风，在昆仑山遇上了美丽的西方美女，两个人自由投缘，老好三年之期。没想到周瑜死于东征途中，再也未能复归了。

李商隐说给王昌龄的诗来得等得很妙，给读者的暗示是：隔壁东西到不了东西是这诗境的好，孙尚香为什么还是像有情人一样死活了？晋文公母难道没有什么神话传说得预仙女啊，为什么也会遭遇这场悲剧呢？

还有一首《嫦娥》：

云母屏风烛影深，长河渐落晓星沉。
嫦娥应悔偷灵药，碧海青天夜夜心。

字面上的上首是嫦娥，其实嫦娥像西厢记的女道士。在天上看看未来，这实质是神话里一样的，远远如同神仙，让人留恋甚至悬想。但月宫不过是孤独寂静的华丽牢房，女道士也不过是道观里的寂寞的徒子了。

在你理解到了这些背景之后，会不会觉得嫦娥里边那句轻浮的爱情里其实充满辛酸呢？

## 今日得句

李商隐生活的唐朝是一个对修道、炼丹和画狂迷的时代，修道和长生被看成是今生下世就可以做到成的事情，但包括问题是：“殿餐寿神仙，多历所不情。”

道观里的生活在外人看来 “碧城十二曲阑干，犀辟尘埃菊花蕙。砌花堆藓，卧风雨，夜离心。” 在人性的俯瞰之下，爱的火焰在幽谷更容易点燃。

## 李商隐《碧城三首·其二》

```
对影闻声已可怜，玉池荷叶正田田。
不逢叶晚留，莫让洪兰又拍肩。
紫风放娇衔错语，赤鳞群舞报清涟。
鄂君长想月中夜，绣被焚香独自眠。
```

你好，欢迎来到《墨鱼·唐诗50讲》。

### 1. 对影闻声的风凡天涯

《碧城》第一首像是从旁观者的视角写出来的，第二首换成恋人的视角。

如果你读不懂诗里想象的形象，至少也可以朦胧地感觉到欢喜、思念、嫉妒、疯狂、纠结这些热恋中的人通常有过的心情。

如果你读不懂诗里的形象，你就会发现这首诗不得不靠一些解释性逻辑解读，它就跟一封男人与女人写的炽热的情书，因为变得太露骨，连修辞都显得不起来了。

开篇“对影闻声”，是说“望着你的身影，听着你的声音”，有一种死不见得，可遇不可即的意思。“可怜”的意思和现代汉语完全不一样，意思是“可爱”。

“对影闻声已可怜，玉池荷叶正田田”，意思是说，望着你的身影，听着你的声音，虽然双方正在接近，但已经显得不可自拨，池塘里的荷叶才正在美丽地舒展着。

“田田”是形容荷叶青翠苍郁的样子。这里忽然提到荷叶，并不仅仅意思是写景，而是让我联到乐府诗歌《江南》：

```
江南可采莲，莲叶何田田。
鱼戏莲叶间。
鱼戏莲叶东，鱼戏莲叶西，鱼戏莲叶南，鱼戏莲叶北。鱼戏莲叶间。
```

这是乐府诗歌里非常著名的一首，大多是来自江南的民歌。古人多说它好听，但不说它写什么。它好，也是诗句里自然淳朴的感觉让人忘什么学说去引用它。

莲叶就是荷叶。“鱼戏莲叶间”是对求爱的隐喻。民歌里边经常很喜欢用谐音，“莲叶”的“莲”谐音“怜爱”的“怜”。“莲子”谐音“怜子”，莲子就是多子多福的意思。“莲”谐音“怜”，“怜”又是怜惜的意思，双关，“莲子”谐音“怜子”，“莲”谐音“怜”，“莲”谐音“怜”，“莲”谐音“怜”。

李商隐的爱情诗里经常运用这些谐音，这次是从“对影闻声已可怜”的“怜”字谐音到“莲叶何田田”。莲，自然是莲花。李商隐诗里“玉池荷叶正田田”，让我们产生“鱼戏莲叶间”的爱情感觉。

接下来“不逢叶晚迟归客，莫让洪兰又拍肩”，是男人心里的小小嫉妒。黄史和洪兰都是传说中的神仙人物，诗句里以是表达男女之间，以洪兰比喻别人的男，这个热恋中的女，在专心地心口痛我的恋人，又或者是心里这样想着：你可不要随意想别的男子结识啊。

“萧史”还有更深一层的涵义，说萧史是春秋年间一个善于吹箫的英俊青年，秦穆公的女儿弄玉爱上了他，两人结为夫妇，一同修炼，有一天终于乘紫鸾同飞入天去了。

而说到杨容宗的《薛镠看侍御得见曹君书》，御史追鲁宗，公听他来说他得见便看薛才行，所以像侍御要曹御史一般是不做到的事情。但为了众姓投奔官，守官官员也不做列府这场宴会。

再看最后两句：“虽是皇将是将军，不敢公然子细看”，诗人说自然皇帝和唐侍御们对侍曹君细看，即列到来看，即不敢在大席前做位放这位属吏

为什么会这样呢？因为这里很巧妙地用一则典故：

三国年间，魏文帝曹丕在宫中设宴，喝微喝到微时，让鼓吹伎（也就是传说中的曹操为他写出的《短歌行》的那位文官，来吹奏笛音。在场的所有人都努力地目自比，但都不见曹丕，只有对他很失礼，尽情地看着玩着看，结果被问了下来。

李商隐提到了这个典故，暗示出这位曹君已故成为主人的隐者，所以自己才会“不敢公然子细看”。

对于年轻的女道士而言，如果生命里只能有三种选择：

- 要么在“簪花十二围中席，屈膝尘楼玉屏里，就教更”，
- 要么就教着“素风吹新扇，赤鞋托海泛”，不计着名与后果，
- 要么“乘凤仙上燕云，便似烧得赤血晶”在另一个世界里度过一点拥有别人烟火的生活。

你觉得哪一种更可取呢？

## 今日得闲

《题破壁》第一重用相对明朝的表述写了女道观里的一场恋情。一对情侣在人群中“对影同枯”，在私卫重难缠继缘。这样的爱爱注没有结果，却狂热地发生过。

《天平山中舍司令命》写出了女道士的另一种选择：还俗，和青春、美貌和歌技交换取富足生活，而在还俗之后，爱情反而离她们更远。

## 今日思考

就像年轻的女道士只有三种选择一样，在今天的爱情和生活当中，关键的抉择其实机会会是同样的情形，只是由几种不同的结果中来选择一个
