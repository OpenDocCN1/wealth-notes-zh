当诗人接受了现实生活的压力，理想放飞自我的时候，就会散逸，就会解带。而散逸和解带对应的生活，就是前边讲过的返照解组。

“明知故友南柯去”这一句里，“南柯”的意思对应的生命也是散逸、慢、慢、迷生的“涂”。这都是套语，李白古诗最多，就会发现，哪怕再天才的诗人，也离不开各种套语。

# 今日得则

教科书总是把伟大的文学家描述成道德楷模，真相往往相反与之相悖。李白就是一个典型，他极度自我，对别人的关心少得可怜，一生特别放纵来我。通常人的远行给朋友留下的赠别诗歌，在李白笔下，也能变成说朋友走，讲自己的故事。

古诗词中有些词汇虽沿袭至今，一字不改，但意思可能已发生翻天覆地的变化，这是我们在读古诗时要格外留心的陷阱。不能轻率地以今又读古，否则就会读错词意。比如“中间小谢又清发”里的“中间”一词，在现代汉语里指两事物之间，但在汉语里却还有“居然”的意思。
