你好，欢迎来到《唐诗·唐诗50讲》。

唐朝人特别喜欢歌颂知遇之恩，你觉得这是一种文风问题？还是还是看现实，很功利的用心呢？这个问题在《侠客行》里不容易看明白，这一讲，我带你读李白另一首歌友题材的诗：《结袜子》。在这个题目里，“结”的“结”应该读成“系鞋带”的“系”，“袜子”就是“鞋袜”，“结袜子”，是把松掉的袜带系紧的意思。

# 1. 袜子里有深意

《结袜子》，这个题目相当古怪。看完全诗，你也找不到任何一个和袜子有关的内容。这到底是什么意思呢？

因为这首子并不是李白的原创，而是来自汉朝的乐府旧题。后人常常沿用汉魏乐府的题目，乐府的题目通常有特定的主题，后人沿用这个题目的时候通常也会写同样的主题。

元末明初的刘伯温，这是大家都很熟的历史人物，他也写过一首《结袜子》，劈头就说：“昔有游侠客，冠盖尘埃黑”，然后说“袜结”“结”在袜子上，然后说“君子不结袜”，“结袜”，是朋友之间的亲密表现。

讲完这个故事也讲完了，感觉说：“千古不可复，安独怅人奇”，“我”多么希望，感叹今天的朋友和古人风范不会存在于遥远的古代，如今完全不见了。

我读这首诗也可以叫《侠客行》，可是逐字逐句读下来，神秘的袜子依然缺席，还是要回到《乐府诗集》，看看题目之下的解释了。

《乐府诗集》收录“秦王出”，说燕太子讨伐栗侯的时候，有有一天晚上的太子讨伐，左右看他，找不到人来帮忙，只好自己弯下腰，把袜子系紧。而盖武王伐带手下的臣子，在燕王太子去手武王时，夺了手武旗帜，忽然发喊，让太子结，身边人才帮忙，只好放下旗帜，自己提紧袜子了。

古代的袜子和今天不同，是有鞋带一样的带子，需要束紧才行。另外，身份高的人不给自己系袜子。

《汉书》《张释之传》有一段记载，说汉朝名臣张释之担任士卫，有一天在正式场合，朝里的达官显贵都在，王生忽然说自己的袜子掉了，叫张释之给他系好，张释之当即跪下来，给他系好了袜子。

后来到有人批评王生：“你太过分了吧，怎么能让大臣来给他系袜子？”王主回答说：“我年纪已经这么大了，身份也很低微，估计没机会让大人给我系什么了。张大人天下有名的敬重人，在皇上大臣之间，张大人能得到上下的敬重，以结子为例，是从自身形象的牺牲，张释之来取形象，这在重视名节的人看来，实在是难能可贵。

所以《结袜子》的主题是说人的遇合，借张释之的故事来说，李白的《结袜子》把整个主题写得更加明确：

```
「燕南轻丈莫门客，筑中留白倍伤心。
感君恩重许命，泰山一掷轻鸿毛。」
```

在前两句里，“燕南壮士”对应的是“筑中留白”，“莫门客”对应的是“鱼腹”，分别是先秦传颂的两个侠客。

荆轲刺秦王的故事是大家都熟悉的，荆轲路上送行，途径易水的时候，好友高渐离为他击筑送行。

筑是一种打击乐器，高渐离是当时首屈一指的击筑名家。荆轲刺齐失败，秦王统一六国后，战乱并没有达到结束，秦朝需要更借用燕的高渐离，他救不了的他死了，但救不了他的双股，让他为自己击筑，高渐离暗恨，筑，筑的时候故意放箭朝秦始皇，可惜手被砍。

“莫门客”说的是春秋时代的吴国刺客专诸，当时勾无义利是吴王阖间专诸是专诸，但吴王做危险任务，这就是需要既有不常有妙处的方案，还必须有用命博命的必死之心才行。

公子专诸的专诸，就像刺客行动到鱼里那样，专诸是先说鱼，把刀藏在鱼肚子里，成功刺杀了吴王僚，但自己也当场被攻吴王的武士杀死。

这两个典故，古人可能会会有各种解读，也许专诸杀吴王是“知恩图报”——吴王给他赏赐，专诸杀吴王是对恩情的报答，也许是报答知遇之恩的的举动，但性命交给了君王，这多一种荒唐的忠？

但李白不在意这些，他只在两个典故最美、最感人的那一环，那就是“感君恩重许将命，泰山一掷轻鸿毛”。

家中人会一定会受到如此之大的感动，甘愿为来人来效卖命，但除非义字之外，无论任何人都做不到。对，在那些英雄豪杰看来，他们甚至不会把一掷性命看得有多重，在他们看来也不过如鸿毛，随随便便就可以舍弃。

# 2. 求知己

但李白仅仅是写侠义吗？未必。唐朝以科举取士，类似写了一个很公平的考查，但唐朝的科举绝不是考单纯的眼战技巧，考生还必须能向皇上或达官，推荐各种达官显贵文人交友的门路，获得成事的机会。只要关系能打通，几乎就算成功了一半。
