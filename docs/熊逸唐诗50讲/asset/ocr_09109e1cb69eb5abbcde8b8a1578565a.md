# 22 王维《辋川闲居赠裴秀才迪》| 田园里狂欢散浪

寒山转苍，秋水日潺湲。

倚杖柴门外，临风听暮蝉。

渡头余落日，墟里上孤烟。

复值接舆醉，狂歌五柳前。

你好，欢迎来到《熊逸·唐诗50讲》。

现代人在都市里打拼，读几首田园诗是唯一亿光年里，身心彻底放松，读几首田园诗是最后的治愈。诗意岁月漫长，风物渐浓：

春日鹅黄，东风解冻，桃花灼灼，柳絮作雪；

夏日薰风长，雷雨阵阵，梅子金黄，满架蔷薇一夏香；

秋日寒蝉鸣，白霜降，连雁一封传去；

冬日万物萧杀，落下红泥小火炉，温三两盏淡酒，等待风雪夜归人……

山川四季涤荡浩荡，卷走人心的悲苦。

唐代的山水田园诗人以“王孟”并称，“王”是王维，“孟”是孟浩然。但是在我看来，王维的冲远在自然之上，两个人最明显的区别是：孟浩然写得用力，显得是用力自然的痕迹；而王维显得轻松自然，这种由然而来的佳作，有就是没有，没有就是没有，全凭本学。

所以在他的选择里，“田园”这个单元的五首诗，全部出自王维之手。

王维写田园，狂也是人生的不同境界。

“复值接舆醉，狂歌五柳前”“径转，从风秋草。掩山房，闻蝉更五”“野径秋荒，坐看云起时”“最喜”“白发缘经堂，黄金不惜换名缇”“最喜”，“都无一物红”，“终归”“山光无限”，“空翠湿人衣”“宁静独处，人在田园山水中获得了修养和安慰。”

为什么不呢，或者少说也向往田园生活呢？道理很简单，这些都是因为在人生无非是琐碎的打拼，几十个人聚居在有山有水的小镇或大村落，种什么、生活什么，围着篝火在祭祀的仪式下狂欢。

无奈文明发展得太快，我们原始的天性被束缚起来，在拥挤的办公室的丛林里，在几百上千平方英尺的大公寓里，做各种各样名为工作实为维系生计的事。

我们的工作和天性和我们天性相性，我们对田园的渴望就是希望，本质上来讲，田园的向往是一种野性对野性的呼唤，我们想从远离的野性中获得一些安慰。

所以田园这个单元，我们来看《辋川闲居裴秀才迪》，看王维在田园里是如何的狂放。
