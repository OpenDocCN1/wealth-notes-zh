# **彩蛋 | 万维钢：唐朝诗人的敏感度**

闲录专栏《精读日课》的万维钢老师，也是《焦虑·清谈50讲》的用户。万老师听完整门唐诗课，觉得特别有收获，写了一篇读后感，来邀请诗词的同学一起分享。以上就是关于这篇读后感全文。

1879年，有人在西北非巴巴的奥尔塔米拉岩洞里发现了很多旧石器时代的人体画。这些粗犷的笔法很现代，不但很粗，而且来自一面很原始的人体画。人们才知道了。原来几万年前，人类，美有这样一个文识。

据说加布莱着这些岩画后有一句评价——奥尔塔米拉之后全是堕落。

我们喜爱的熊逸老师在得到开了一门新课，叫《唐诗50讲》。我听懂唐诗，但是我在学他这门课的时候，有一个新的感悟。

唐诗之会总是堕落。

你会背诵《登高楼楼》，你知道诗是一种优美的语言表达方式，熊逸也说唐诗给我们提供了最佳表达方式。但是我说这个课程的敏感，这是不是一个情感不能怎么样表达的问题。这是有没有“这个感”的问题。

你登上一座高楼，看着楼下密密麻麻的人群，旁边熙熙攘攘的市声，半空中来方不同的轰鸣，你小心的了万法迷足之众，进不会白“时光”正匆匆匆匆匆匆，有一种紧迫感。但只要你没有更高的见识，你就没有机会”这样的情绪。

唐朝诗人王之凌到上面高楼的那一天，未必不是身怀怎样的信仰期待吧。可惜他听到山寺中，但自他看到，都是“白日光西山，黄河入海流”，想到的却是“欲穷千里目，更上一”，王之凌感受到了诗境，而你。

瓦尤尔·赫拉让你在这个人文学时代，应该去关注人生的体验，提高自己的敏感度。当然我们不知道什么叫人主义，但是我们显然是比更多的人有的敏感度。

现代人不是好词多不用诗的问题，是敏感能力的问题。唐朝人是有诗用的，才去写诗。而我们只能跟着唐诗去体悟一点诗意。

熊逸说唐朝最能想象到的我们对世界的感受力，我们绝对为感觉，而我想说的是人类感受能力。美学了没有。比如课程中杜牧《九月齐山登高》中有两句——

但恐怕的翻佳叶，不见留痕清落。”

要想产生这个感受，你得过度许多诗，知道那你想产生不速的人看到落叶，读时诗会感，留自己可以展示才的时间已经不多，会感到伤感，可能来于这伤感的基础之上，产生强烈作的感受。

你得先用诗歌给自己喂出来一个高度感受，才能在这个高度感受的基础上体验一个更高级的新感受。

这是二阶导教意义上的诗感。

所以感应力和诗歌修都是互相促进的关系。唐诗以满用的古诗是全世界各国选集诗最多的语言，我们任哪一个听惯说汉语的都是有诗性感的言，在《精日课》讲课讲到不全能性不合理的时候，不管是多种精的语言，只要它的字国可数奇，表意就不完备。人总能发展出道不道表达意思。

而熊逸说，古代汉语诗就好像是一个模糊的语句。“正因为是”这种模糊性，使我们言达丰富的表达之力。我们在这门课中看，唐诗中诗人会使用对偶、对义、用典之类的方法达到目，除了些诗之外，还可以用给、叠音和头来对抗到这些感受。

所以同样一个意思，用白话写出来就“死了”，而意式诗中可用很多意思，可分有诗明有理，又太精洁一很人力，可以分体会你的意思，并且是的全部意思，其诗有些意思无法表达。而唐诗歌，却能让人充发他对他有对的感觉。

可是这么厉害的信息传递方式，现在似乎已经失传了。

好一点的，是有感受，没表达。事实是现在已经没人写有诗歌了。前一两有教去，人们感觉发现一下对古诗的。这节，你是否有让特别值得引用我的发话来说：“维只看到前曾经，我充死意我思我”。李敖曾感受过那种诗意，他也用的是古人的诗歌，我们引用李敖的用。

更差的，则是连感受都没有。六小龄是著名清教，人们不能指他的水平，甚至它指能每一次采访中说同样的话，在每年的节日几乎相同的微微地“甚至还配”图样。六小龄章不说这有什么“不足道”，圆脸群众是最近才意识到这是一个吃人的事材料。

现在很多人也开始不会不出一种经进改的“神人”，他们以有们我着最的力和改能力，是高级的物质。这些人可曾过高估计了基因编码的能，我们未来不一定有对神入——而是唐朝。相对于现代人，也许可算是高级的物种。

唐朝诗人对各种情绪的敏感度，对汉字的理解和运用，跟我们现代人有本质别。

时代也许进步了，可是在“诗意”这个面，也许退步了。也许可以说，“了”。

人类的能和力不及动物。比如鲸鱼，能有过的一些能，比加感感感别的人的放，现或这着也。爱德华·威尔在《创造的故事》这本书里，认为未来出，是用科学手段开发一些以前没有感知能力。

我对的敏感对我不太期望。但是我知道，唐朝人对那些诗歌的感知能力，现在的人什么没了？

是因为中国没有的知识可学，一天到晚“国学”学，学的是现代，是只学学的人，他们怎就不行了？

是唐朝诗人都贵，过着生活。是才能体会活的穷，现在人社会大时部分贫困贫困活，现很多人只意思，完全可以不任何生活。那，是什么时感受品物的需求？

唐朝诗人所能够到些诗歌，关键在，唐朝诗人的心目中有一个体。

或者，中国古代来的民族精神，到唐朝那个时候，还没有完全消失。

熊说课程中到“才不”这个诗。唐朝中，取名为，有有诗的人才出考的事。当然在考中，那就只能自己生。这个包含三层：第一，我我才能意；第二，朝廷不用我也不可我，是限很；第三，后只说是我命了。

这贵的气，清代的读书人，不是这种情。他们会：第一，是不是真诗是科？第二，朝廷了？我，第三求你们只让千行。

就我唐朝人的高雅多是假的，去态，你说你不认，至少人尊重那，象的精神体。

什么，把“荡层山，入”当没，什么，这力量城，认大过千变，是读书人

如果一个唐朝人穿，我觉得可，他会现或人，是“真”，也可，好我在种中，仿佛也是古，用唐的。

美国作家高人文，沃尔·，曾未有一个判断，他说人来的本如何发，要有，感受或没意，到人们求受义，刻历模仿历史上各个时代人的生活。

我，他们会感模仿那些些，是充的唐朝。我知道是，诗会是很宝。

要少诗或诗，感，能在身上，或，我们半落成一个物种。
