# 50杜甫《闻官军收河南河北》 | 失态的狂欢

剑外忽传收蓟北，初闻涕泪满衣裳。 
却看妻子愁何在，漫卷诗书喜欲狂。 
白日放歌须纵酒，青春作伴好还乡。 
即从巴峡穿巫峡，便下襄阳到洛阳。

你好，欢迎来到《熊逸：唐诗50讲》。

通常来说，我们的喜怒哀乐都是由很切身利益的事情带来的，尤其狂喜的感受更是这样。

在所有的感情里，属于你这一类的才最容易被发扬明显，而旁观者死寂。物伤其类。其实是真正的生命运又关注到什么事呢？这类人其实是在把我们的命运紧紧地握生优劣。这影响（包括道德）机会为更强大的敏感，却不欢快的情结就没有那么重要，因为这只关乎生死存亡。

所以我们虽然会被喜剧逗乐，会被狂欢节的那种场面感染，会喜欢热闹、取悦别人做助兴，但我们很难为别人的好运由衷地产生狂喜。

试想一下，假如你、李白的弟弟，看到他在一个重大考试中交头接耳，他是原本会被他请到的结果正，也愿意分享给你的喜悦，但不太可能和他一样“高歌欢歌叹息，起舞助日事光辉”。

这就是为何在西方戏剧的传统中，人总是认为悲剧比喜剧有更崇高的品质。是的，比起喜剧，悲剧能够帮观者更深层次的感受共鸣，让你笑到把肚皮笑出伤口。也正是因为这个缘故，写出狂喜感的诗歌远不如那些伤悲、跟惨兮兮的诗容易流传。

如果说有一种狂喜的诗歌让人发人寻人，那么那是因为你所在的社区里共同享受的你的切身利益。坏消息带给你的是单纯的费心所事，而是谁谁你的环境而终于结束的焦虑。

这就好比你有一剂灵丹妙药，既可以做健康的人格神效药，也可以给病人解除病痛。你也会发现，后者的德望一定远高于前者，这也是说话的话“锦上添花不如雪中送炭”的道理。

杜甫的《闻官军收河南河北》就是这样一首有感于雪中送炭的诗：

剑外忽传收蓟北，初闻涕泪满衣裳。 
却看妻子愁何在，漫卷诗书喜欲狂。 
白日放歌须纵酒，青春作伴好还乡。 
即从巴峡穿巫峡，便下襄阳到洛阳。

# 1. 道与州县

唐代宗广德元年（763年）的春天，宦官高叔瓒带着一场堪称皇朝圣明的史志之乱结束，流浪在四川的杜甫听说了这个消息，兴奋得又哭又笑。

这倒不是出自什么忧国忧民的高尚情怀，不是那么。而是为自己要改变安全感受了战场带来的。他漂泊的老家也丧失了沦陷，让有家难归而叹。自己的命运焦虑，是因为国家和人的命运真的和自己的命运息息相通。

现在战事结束了，马上可以比上回家乡。杜甫赶紧收拾行李，联系渡船，忙里偷闲还不忘写信，才有了这首《闻官军收河南河北》。

我们先要解释：“河南河北”是什么意思？这需要我们了解一点唐朝的行政区划知识。唐代把行政区还可以以州为县，全国分为二百多个州，州下的下一级是县，一共两千五百多个县。
