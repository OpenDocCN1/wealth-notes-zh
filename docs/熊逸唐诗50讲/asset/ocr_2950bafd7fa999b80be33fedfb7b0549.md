# 02杜申《登高》|人生暮年的百感交集

# 杜甫《登高》

风急天高猿啸哀，渚清沙白鸟飞回。

无边落木萧萧下，不尽长江滚滚来。

万里悲秋常作客，百年多病独登台。

艰难苦恨繁霜鬓，潦倒新停浊酒杯。

你好，欢迎来到《唐诗·唐诗50讲》。

这一讲我们要带你看从青年杜甫写下的《望岳》到晚年杜甫写下的《登高》、诗的语境和诗人的心境发生了怎样的变化，这种变化我们今天的很多人依然感同不解。

同时我也要替你都聊一番：为什么我觉得这首诗，代表了唐诗歌的最高成就。

# 1. 不尽长江滚滚来

俗话说“文人无第一”，文学作品很难分出胜负，读到孰优孰劣往往只能各花入各眼。有时候大家容易有公论，多数人感觉都好的一定是好的。但有些的作品往往不会公论，只能被少数人欣赏。

那么，少数权威的见解就一定可以作准吗？们不尽然，时代风尚和个人偏好都会影响人们的判断。你可以信自己的判断吗？人总是进步的，你在今天的判断不一定还能得到明天的认可。

这样看来，要想选一首可以代表唐诗最高成就的诗，必然是一件不可能完成的任务。但我真的可以选出一首，那就是杜甫的《登高》：

风急天高猿啸哀，渚清沙白鸟飞回。

无边落木萧萧下，不尽长江滚滚来。

万里悲秋常作客，百年多病独登台。

艰难苦恨繁霜鬓，潦倒新停浊酒杯。

《登高》是杜甫晚年的作品，当时他流落在夔（kuí）州，就是今天的四川奉节，拂暑漫长，生活环境，大冷的萧江节的时候，他独身一人登高远视，长江沿岸的萧索秋景让他触目伤怀。

诗的意蕴并不难懂，先写登高所见的景象：秋天的夔州，江边的树林正在缓缓。变白，江边沙洲上冷清萧条，鸟儿正在巢边。无边的落叶簌簌飘坠，江水滚滚奔流。

在这样萧瑟的景象里，诗人恰好自己的一生的，无限肃杀凄凉。颔联写天，读来是还远的鸟儿。忽然间人就是老了，时间像无尽的江水一样无情滚淌，自己也已经来半了人生的秋天，疾病折磨着独自衰老，自己的艰难多灾多难，只消可以浇怒，但雨太湿，太人激烈，连喝酒都不可以。
