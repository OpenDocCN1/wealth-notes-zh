# 今日得到

白居易的《池上》对传统的小隐和大隐做了折中，成为一个崭新的隐逸概念。

你可以拿出白居易的《池上》和边韶的仕途生涯半官半隐的生活方式做一下比较。唐朝人并不讳言对物质生活的追求，即便想清隐，也必须先有财富自由为主，这是对传统隐逸概念的更新。

无论小隐、大隐还是中隐，对于满怀抱负的人来说，都是不得已之下的选择。
