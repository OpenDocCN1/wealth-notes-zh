# 03 王之涣《登鹳雀楼》
找到时间的形象代言人

![](bbox=[0.08, 0.1, 0.75, 0.14])

**王之涣《登鹳雀楼》**

白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。

你好，欢迎来到《雅途·唐诗50讲》。

这一讲我要跟你讲的，是王之涣的《登鹳雀楼》。我相信你的第一反应会是：这首诗太熟了，还有必要来讲吗？但我打算带你从熟当中还可以生。

登高容易感怀，感怀时间是最易触发的情感反应。通过这首诗，我要给你梳理一下：中国文学当中，“黄河”这个意象隐喻时间之间的隐晦关系是如何形成的。

# 1. 登楼：文学史上的关键事件

古人登楼，要么是山楼，要么是登楼。登楼感怀这种活动，从三百年间就开始了。

东汉末年天下大乱，群雄割据，这段历史是从小说发展出《三国演义》的同学们很熟悉的。大家最感兴趣的是三角戏法战吕布，关羽如何过五关斩六将。

很少有人留意到一个叫王粲的文辞书生，他在动荡的时候有一笔避难，依附到刘表曹操的门下。刘表有华汉一雄雄心，但在刘表这里得不到施展的空间，这让他郁郁寡欢，常常生出怀乡恋土之心。

荆州境内有一座高楼，就是关羽“走麦城”的那座麦城。如果不是因为关羽的光环太盛，麦城本该因为王粲而留名青史的。

某一天王粲登上麦楼极楼极远而望，禁不住百感茫茫，写下了一篇《登楼赋》，文章的主题有两个：一是怀才不遇，二是思乡恋国。

王粲当时一定不曾想到，他这一次登楼将会成为文学史上的一个关键性事件，一个“登楼”的文学史。从此他的名字、身世和“登楼”这个意象牢牢纠缠在一起，在千年后不断激起诗人们的共鸣。

在王粲以后，大约四百年的时间，历史经过了三国、魏、晋、南北朝。北朝是边有个字家族建立的北朝，后来在内战的崩塌中诞生了大一统的隋朝，很快隋朝又被基础诞生了。

**当初北朝的宇文玄武在山西蒲州城外楼边的黄楼上建成一座高楼，因为常有雀（quán）雀住在楼上栖息，所以人们把这登高楼称为鹳雀楼。**

唐朝诗人待鹳雀楼，形形色色登楼题咏，写尽各种诗或和韵赋。但众口铄金，今天大家能背诵的，就只有一首王之涣的五言绝句《登鹳雀楼》：

白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。

诗很短小，似轻写意，却蕴含激越的哲理，用明晃晃的意象给我们点开了某条不老的秘密。但是只言片语地心情，还是因为悲怆的基调并没有真正消失，只是被雄浑的意象淹没住了。

让我们重读前两句：“白日依山尽，黄河入海流”，到底在表达什么？最直接的问句是：这当然是如实描写眼前的景象。

但是我在我面前讲过，诗人描写风景不存在“如实”这件事。最真实意义上的“如实”随着客观室，没有事，就像外行人穿起衫看手机拍的照片。

但拿出去拍前照，按内容来呈现的话重点突出出来，把不需要的内容变化下去，通过巧妙的安排构图、明暗、光影等真实的场景构建起一幅充满主观色彩的艺术品，所以旅游杂志上的照片和电影里的美景往往都比实景要漂亮很多。

那些实例用照片去拍的地方，都有一个共同的特点：天际线，有些微妙的天际线为公共的景观更美，正是因为天际线勾勒出的轮廓，夜幕把各种乱七八糟遮回去。

同样道理，诗人登临鹳雀楼目送人，看到的事物多很多，如野马、路人、立柱、岸塔、近处的稻田的吆喝、天上的浮云和地上的牛羊。如果诗写到这样的时候是不和谐的，但是一篇文章，一定会铺垫出很多景物。但是诗词必须体现，五言就句加每句只有十个字最短小的诗歌体裁或更加需要凝练。

# 2. 流水：如何成为时间代言人

登楼远目，在一初景物中，最让诗人产生感触的只有“落日”和“黄河”两个。它之于千百百的内容就必须从诗歌的画布上通通隐藏。

那么，西下的夕阳和东去的流水，这两种意象到底在表达什么呢？

它们在表达同一件事，那就是“人在时间流逝面前”的感慨。

你也也许会， “白日依山尽”当然可以这样理解，但“黄河入海流”关心时间什么呢？

这是因为在古人眼里，江河奔流的意象早就成为一个文学意象了。还可以追到：“逝者如斯，子在河这发出了这一奇名的感叹；“逝者如斯，不舍昼夜！”这是在感叹时间就似流水一样日夜奔涌，片刻也不停留。

当流水和时间发生了这样关系时，人们才会“悲远水年”。正因为有这种代码，诗人才可以言在此而意在彼，言有尽而意无穷。

此诗之所以要“感伤”，很大程度上就是要去体会项羽给诗人的言外之意：在现代人的代码，理直气壮的，要说的，最简练的，或着，我们失去了和古人的默契，看不出他们埋下的梗。

那么，诗人为什么要用流水来表时间呢？

这需要谈到中国古典诗词“意象化”的特性了。

诗歌之所以打动人，是要调动的是人的形象思维。如果说，用抽象想象来说理，虽然都能让人感觉到，但更让人感同身受，自然而然让人产生共鸣。

**调用形象思维，最好的方式莫过于运用想象。**
而精心设计出来的形象总会让人无法去调用理性去被感动，被释怀了。

今天的广告行业最推崇的这种方法，很成功的广告都采用非理性的，纯粹心理想象路径。

我们还可以用《纯粹小说》。虽然我自己就是一个“纯小说”，但是我必须承认，好的纯小说虽然可以唤起读者、引人入胜，给人新鲜的快感，却都很难读实深刻的感动。所以想表达，无论写得再好，都无法跻身于第一流文学的行列。

黄金时代的那些推理大师，无论是阿加莎·克里斯蒂还是柯南·道尔，他们的小说多成了经典，拥有全球范围的忠实读者。但无论多么经典，小说都无法与诗歌、音乐、电影文学并驾齐驱。这不是他们的创造力不足，而是因其载体本身的限制：理性趣味文学作品总是如此。

回到关于时间的意象。“时间”是一个抽象的东西，如果用通用诗歌意象写到的时候，就必须把时间意象化。

时间的特征是它没有流动着留滞，无论白天还是黑夜，它不分不流，但它也无声，而且一去无返、无法逆转。言如古，千年后人也是过眼云烟。那么，最合适的找一个“形象代言人”，再没有流水更恰当的。

今天我们看到大公鸡都为自己的产品去找形象代言人。这逻辑最早是从古早语诗歌的理：结果要为一形象代言另一形象，要用一种形象的某特点来凸显另一种形象的某特点，不等价又得相同，就导致消费者要么印象不深，要么领会不通。

用流水作时间代理，还可以做许多推论。上一讲里提到杜甫的《乐府》“长歌当哭”里。长江水的奔涌是一种感觉，不觉得，在“黄河入海流”，黄河的去势更为大是一种感觉。去势给人以压迫感，去势更会无边的时间感。那么，当落日与流水的形象交织，诗人会做出怎样的反应呢？

《史记》讲过庄子豫让的故事，说伍子胥带着吴国的军伐进围国都的首都，向仇人吴王复仇。

楚国大司马鲍叔牙伍子胥做事过甚。伍子胥说：“昔日老父老，臣就像个逆贼似的。”这话说的是老父，我就像个逆贼的人，太子扶高出了还得多要，没办法，只能选择富贵，不得已了。成语“倒行逆施”就是从这来的。

**对于一切有志向、有抱负的人来说，“时不我待”是一种本能和焦虑。**

杜甫用英雄的人生在总体中想“出而表其美”，长使英雄泪洒落，也是这样的道理。

那么，王李辉给了最能体现那股激愤的时间呢？王之涣给了一个激愤的答案：“欲穷千里目，更上一层楼。”正因为时不我待，才需要抓紧去攀登人生高峰。

当你理解了这两句诗里的时间观，才能真切体会到这副诗句里的登楼意境，体会到登楼的高度是如何来看人生的高度的。

这样一回顾，应该会让你对诗人王之涣的生平作出...
