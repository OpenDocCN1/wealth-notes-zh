这不是交易一步步地上了科创板【重磅消息：证监会优化高压标准，取创收板不能够先限制】

简要解读：

+   1. 对取消盈利上市以定利润中等的“盈利门槛”；
2. 拟将暂停首次公开的计划期同一并不超过36个月（她先买先后注入资产或相关程序均可）；
3. 允许借壳创业板；
4. 允许配股融资；
5. 明确配套要求。

详细解读：

+   1. 创业板重组重上市（借壳上市），以前是不允许创业板借壳上市，创业板一旦马上就下城到进入与新股的破例，破例并无恢复。
2. 上市公司实际控制人变更后，36个月后注入资产并不构成重组上市（借壳上市），不用按照同IPO的规定来处理，以前的是最长60个月，现在算是审核两年。
3. 这个是关键问题，对产业重组的影响，不是用来炒杂概念，大量创业板新科技公司，因为公司本身重组进入上市公司，以前并不允许，现在允许重组和融资，考虑3年的时间带来重大的影响，要关注主营业务和业绩，要是一定是重组相关。
4. 对于融资的同时配套融资资较更便民的条款，从而改善资本结构，例如一个公司上市公司收购一个相关的创新型科技公司，同时可增发，让企业的现金流不完全依赖。
5. 展开试点，结合当前的现状，未来的监管较为严格，方法是通过头部机构带来流动性，市场形成的成熟从？这里来。
