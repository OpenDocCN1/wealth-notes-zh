# * 【第八章：团队的管理】

# 1、自己喜欢的事情，找员工干自己不喜欢干的事情

我们要做一个事业，总是会有很多事情要去做，总有些事情，我们不愿意做，或者说是
doi，因为责任，工作需要不得不做，这样的活，人就会心力交瘁。

所以，我的策略是只要是自已不愿意做的事情，我统统交给员工做，我自己呢，只做自
doi的事情。

为什么？因为，人做自已喜欢做的事情 感觉不到累，比如，我们喜欢唱歌，那我在 ktr
del，吃了晚饭，还能继续唱到半夜。比如我们有些人喜欢打麻将，2 天 2 夜不
睡下来。还想继续。但是如果碰到不 喜欢做的事情，2 个小时，人就不能坐了。

在工作中也是这样，工作中，有些事情我们非常喜欢，做起来也得心应手，那么喜欢干
的工作，我们就自动动手去干，干起米不会疲惫，而且还让自己进一步的喜欢上这个工
作。练习好这方面的技能，最终可以把这自己喜欢的工作，做到极致，做到别人难以达到的
高度。长此以往，我们的工作就会成为我们的核心竞争力。

一旦，我们工作的时候，发现我们不喜欢手头上的工作，千万坚持做下去，也不用说什
么责任心的东西，赶快把这个工作交给员工做，不断的给自己做减法。道德经上有句话：
学道日损，损之又损，以至于无为。我想，可以用来解释为什么这个套路可以让人越来越
牛逼，就是因为做事简化了。

一个人靠坚持，靠责任心来跟我竞争，而我是靠快乐，靠兴趣，靠喜欢，显然，他是竞
争不过我的。这完全不是一个数量级的比拼。这一招，当你的企业人数增加的时候，你
可以把这个观念教给你的核心领导层，让你的核心领导层都去发挥自己的兴趣特长，当然，人
数少的时候，你一个人用就可以了。

一个人的竞争力，取决于这个人脑子里学什么先进的观念，如同一个电脑可以玩什么
游戏，取决于电脑里装了什么游戏程序一样，希望各位创业者，好好思考一下我今天讲
的观念。

经验不足的创业者，总是以为组织内部的事情才是与他关系最密切的。就算他要关注企业
外部的事情，也是通过下属给的材料，报告之类的东西来认识企业外部。

而不幸的是，报告都是经过下属的主观 加工，高度抽象的材料，所以，如果创业者不
到市场一线去走动，仅仅靠在网上搜索，靠同事给的报告，材料，他其实很难得到真实
