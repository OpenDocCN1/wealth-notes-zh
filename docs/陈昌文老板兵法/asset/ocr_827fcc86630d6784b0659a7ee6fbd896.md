学习是偶尔的，练习是时时的。学一招，用一招，练到极致，再进行下一招，行有余力，则以学文。贪恋沉溺学习是玩物丧志和逃避现实。学时而习，劳而无怠，生生不息。

+   2、述而不作。

述而不作，信而好古，一切成功来自复制。述而不作，信而好古，愚而好自用，贱而好自专。聪明人复制改编优化，听话照做执行，直接复制牛人、强者、成功者，并且虔诚，持之以恒。述而不作，上上之策。

+   3、近悦远来。

近悦远来，内生力量，德不孤必有邻，远人不服普修文德以来之，修内安外，近悦远来，内生力量，已所不欲，勿施于人。交于道，结于礼，近者悦，远者来。你让心享受，心让你事有成，心享事成，近悦远来。近悦远来是一种战略思维，是成就大事业的策略，如同兵法战略远交近攻一般。

+   4、贤贤易色。

贤贤易色为善去恶，万恶淫为首，色心不去，善法难存，正心必从我色始。色食，人之大欲，只有提高境界，唯有跨越才能戒，树立圣贤之追求，超越低俗之欲念，此为治本。人无远虑，必有近忧，贤贤易色，好德替代好色，更高追求。
