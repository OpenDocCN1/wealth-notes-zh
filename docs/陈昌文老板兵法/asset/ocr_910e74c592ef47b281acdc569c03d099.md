# 11、今天学一点，明天学一点，主要是日且不断之功

学员：

恩师：我这两天一个视频快百万播放量，我一天讲了快十个小时，连着干了两个十个直播，讲到想吐了哈哈！我很努力了，就是人气上不来，奇怪的很！没出结果。可能是这个号被封过一次的原因吧。

恩师：我今晚在反思自己了！两天直播时长加起来 20 小时没出单的原因：1、直播时太长，头晕状态不佳；2、对儒家思想不太明白，传播时心中有障碍。直播间有人问我儒家思想核心是什么？我就答不上来，半部《论语》治天下，也常挂在我嘴边却没悟到。

恩师：学生知道自己学识浅薄，即便有人会笑话说：初中都没上过，还来讲《论语》，但是我觉得这个一定跟学历无关！我学东西慢一点，但我非常认真＋勤奋，相信一定可以搞懂的，下午特意去看了两集《孔子》，想了解孔子是个什么样的圣人！难道是还需要更多的去在生活中或者直播间去实践，才能有所感悟吗？恩师赐教。
