# 5、道学会了，术就无师自通

做事的方法很重要，但其实一个人真正能成功往往不是方法所决定的，而是那些优秀的品质所决定的。当一个人具备了我下面谈的这些优秀品质，很多东西都可以无师自通。

第一个品质，耐力。

很多人做事有爆发力已经很不错了，他能持续拼搏一小段时间，但是不能长久的拼，这样的人注定只能给别人打工。

我本人非常喜欢长跑，一般早上跑一万米以上，因为长跑最考验一个人的耐力。很多跑步的人跟我一起跑步，开始的时候，他们能跑上三四千米，可是他们很难继续下去了。如果你想锻炼自己的耐力，可以开始学习长跑。

人活在这个世界上，要做事业，要赚钱。你需要选定一个领域：首先，你需要往前跑，不一定是这个领域里跑得最快的，但是要跑得久！大部分人都跑不久，他们迟早换行业，而如果你跑得久，那么优势会积
