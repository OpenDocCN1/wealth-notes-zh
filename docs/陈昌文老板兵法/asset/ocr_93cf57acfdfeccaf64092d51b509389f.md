# 16、互联网在线教育必定是一个趋势

互联网的发展，让每一人都有机会靠一台电脑就致富，如果你有特长，有经验，愿意在互联网上分享你的特长、你的经验，不管是什么东西，只要对人有幫助，总是会有人跟你学的。有学生，有老师，就是教育，然后你可以酌情收点学费，这样一个非常棒的商业模式，你没什么成本，赚到手的都是纯利润。而且，互联网在线教育必定是一个趋势，你可以做得非常大。

第一，以前学生想学习，只有学校，这是一个垄断资源，你只有到学校里学才行，而且学校基本是以老师为中心的，谈不上什么服务态度。他们根本就没认识到教育实际上是一个服务业。而互联网的出现，你可以在互联网上服务好学员，以学生为中心，这就极具竞争力。由于学校是政府性质的，没什么营销能力，慢慢的，民营的互联网教育必定啃掉传统教育很大一块肉，就如同民营快递啃掉了邮政快递很大一块肉一样，也如同互联网金融啃掉银行很大一块肉一样。互联网教育也必然会啃掉国家教育很大一块肉，接下来，这一幕必将发生。
