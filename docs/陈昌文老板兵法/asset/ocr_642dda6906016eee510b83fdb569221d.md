# 1、老板到底是种什么人

老板就是喜欢折腾的人，是个拥有勤劳的双手，并且拥有活跃脑袋的人。想发挥**自己的才华**，不愿意甘居人下，想获得**财富自由与精神自由的人**。最重要的一点，**他行动了**。而打工仔，怕这怕那的，混点日子，在别人的企业里得过且过就行了。他们获得了暂时的安稳，牺牲掉了自己的自由意志，自己的特长也很难充分发挥，基本上也就牺牲了财富自由与精神自由的可能。

老板是喜欢解决问题的人，是碰到问题就兴奋的人，而打工仔碰到问题就头疼，喜欢推卸责任。老板也是解决问题的人，你总是喜欢解决各种各样的问题，然后让业务正常化，让企业盈利正常化。老板也是没事找事的人，当业务都正常了，我们总是要折腾点新业务出来让大家干。
