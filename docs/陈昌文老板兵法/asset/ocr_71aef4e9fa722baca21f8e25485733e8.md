# 第一章 社会的本质

我们选朋友，就是为了组成一个战斗力强的组织，群策群力，一起去寻找更大的财富，而不是脑子里都是平均主义的人。这些平均主义者，只会让他们自己赢，让你输。跟这种平均主义者交朋友，结果是你输，这种朋友会削弱老大的竞争力。

只有老大混得好，才能让大家一起发财。要是老大竞争力被削弱，越混越惨，这个组织就会完蛋。如果你交平均思维的朋友，那么结局就是大家一起完蛋。

只有选择懂得互利共赢、明事理的朋友，大家在一起才能越混越好。如果选择平均思维的人做朋友，这些人都有红眼病，老是算计你比他多了多少钱，车子又比他的高档，那么最后只能“同归于尽”。

# 第二种朋友，有前途的朋友。

什么样的朋友有前途？一个人要有前途，需具备如下几个特征：

+   1、学习能力强，特别好学。

天才其实根本不是天生的，而是后天不断地勤加练习，努力学习加实践的结果。一个人的种种能力都源于后天的学习，没有人生下来就是赛车手，就是足球健将。学习能力要排在所有能力的首位，只要有很强的学习能力，慢慢的很多能力都会强起来。如果学习能力弱的话，注定是个废物。
