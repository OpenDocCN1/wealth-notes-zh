# 13、赚钱，必须了解钱的性格

为什么要这么看重钱？答案非常简单，因为有了钱，你才能去旅游，才能去买房子，买车子，才能保证 60 到 120 岁还有活头。敢活到 120 岁，是因为准备好了足够的物质条件。而赚不到钱，是活不到 120 岁的，因为物质条件不允许你的生命力这么坚强。
