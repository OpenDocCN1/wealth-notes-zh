也越来越好，水到渠成的自己就组建了一个团队。

所以，我发现，做公司，做生意，是个水到渠成的事情，就像栽树苗一样，从一颗种子开始培养起来的，而不是直接长成大树 的。也就是说，我认为直接做个豪华写字楼，相当于直接成长为成熟的公司了。

开始的时候，招聘一个人力资源主管部门都是没必要的，当业务成长到一定的时候，不得不招聘行政部门才招聘。就是我认的水到渠成的做项目，做生意。当然如果你背后有足够的养料，你可以直接成长为大公司，每个辅助部门都配备起来。比如有风险投资，否则，还是不要违背规律的好，按部就班的找到你的第一单，慢慢做大，不要急，也不要放弃。

最难的是第一单，也就是从 0 到 1。从 0 到 1 意味着，你开始有业务了，也就是说，你终于迈进商业的大门了。你为自己赢得了肯定，同时不再怀疑未来。能够坚定的付出劳动而不会去怀疑这样干下去会不会成功，这是非常重要的。

第一单的付出是巨大的，因为做项目刚开始，我们都不知道怎么赚钱，我们需要探索，需要实验。需要掏自己的钱出来支付房租、水电、饭钱。其实我一般建议大家开始做点非常小的生意，找找经商的感觉，就算摆个地摊也好。其实我认识很多老板，最开始都摆过地摊，因为摆地摊成本极低，而赚到几十块钱会给自己极大的信心，就是说，你看商业书籍，或者听我讲课，不能给你商业的感觉。摆地摊能让你快速的找到商业的感觉。
