# 2、心智能决定人的贫穷与富有

一个人到底是贫穷还是富有，除了跟外在的环境有关，还与自己内心的**心智能**是什么样子有关。学过物理的人都知道，钻石与煤炭都是碳原子组成的，但钻石坚硬无比，煤炭就没那么坚硬的了。钻石晶莹剔透，煤炭乌漆墨黑，仅仅是因为它们的碳原子的排列方式不同。美国有一个跟踪那些中了大奖的贫穷普通人的调查，发现过 5 到 10 年，这些人又贫穷了。
