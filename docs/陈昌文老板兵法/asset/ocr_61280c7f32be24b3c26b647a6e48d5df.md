# 42、您对我们家的影响太大了，此时我妈坐在沙发上听您的录音

学员：

感恩您陈昌文老师。老大，我真心的感恩您，我一直想给您发私信，但是我没脸见您，我现在还没做出什么优秀成绩。我都不好意思说，我今天忍不住了，写下感恩信。

我去年六月份就接触您的音频了，但是听了几分钟就听不下去了，去年的我很自以为是，还骂您讲乱七八糟的。去年六月份我哥叫我搞抖音，我搞了三天就放弃了，又去打游戏，去玩了。直到自己搞生意赔了。

过年期间又帮我哥做小号，天天听文案，天天剪辑几十条视频，后来我就被影响了，潜移默化的很多文案都可以背下来了。我哥一直在帮助我，是我不好好歹，他很铁不成钢，我却浑然不知。

后来喜欢上了听您的课程，我才恍然大悟，自己是个傻叉。您对我们家的影响太大了，此时我妈坐在沙发上听您的录音。此刻我眼泪在眼眶里打转，不知道如何去表达此时此刻的心情，哎哼心里很难受。

感恩您老大，我在群里不爱说话。我要干活，我知道我太菜了，弱者没有资格讲话，我悄悄的学，悄悄的干。老大，真的我打心底里感恩您。
