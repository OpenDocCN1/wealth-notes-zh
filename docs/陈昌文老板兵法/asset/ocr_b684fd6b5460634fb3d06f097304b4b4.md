# 7、赚钱的创意从哪里来

知识就是生产力，财务知识、企业知识、投资知识，合起来就是致富知识。一个人头脑里有什么知识，就会影响其思想，进而影响其行为，再进一步就会影响其事业，最后就会影响其生活品质。

比如当年我脑袋里拥有的是战士、法师、术士、盗贼的关键词，我明显是个游戏脑。我的脑子都用来打游戏了，所以生活过得很惨。后来脑中拥有的是 MFC、SQL、C++、JAVA、PHP，明显是个程序员脑子，只能领一份薪水度日。再后来脑中拥有的是绩效考核、目标管理、公司的财务报表、资产负债表，明显是老板的脑袋，收入就有所提高。再后来拥有资产收益率、资产回报率这些概念，这些明显就是投资人的脑袋，生活水平进一步提高！

富人是靠知识与概念赚钱的，普通人是靠体力赚钱的。从现在起，若想富有，你就可以改造自己的脑袋了。比如，财务知识认识得越深刻，你越能注意到你眼睛看不见的东西。你可以选择变成债务人，也可以选择变成债权人。而如果你不懂这些知识，你就没有能力做出对的选择。
