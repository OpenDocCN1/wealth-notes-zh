# 11、赚钱这件事根本不是计划出来的

为什么很多读书成绩好的人都去打工了？

为什么一直在思考人生方向的人，基本上都没啥出息？

而那些街头混混却成了老板，那些看似没什么远见的人，却拥有不错的事业？其实道理很简单，因为街头混混的口径就是：先干一票，弄点吃的再说。典型的先生存下来，然后再做打算的理念。

其实有经验的人明白，我们做计划，想策略，然后拿到市场上去用，根本就行不通，因为市场变化太快。经常出现计划的是A，做着做着就变成了B，以为能在C处赚钱，结果是在D处发家。所以，赚钱这件事根本不是计划出来的，而读书成绩优异的人、成天思考人生方向的人，总是想有一个完美的计划策略去做事，这就导致这些人做不了老板。

我招聘的时候，想选一些优秀的人来带领项目组工作，最怕碰到一些高材生问计划，问策略。因为赚钱这个事情，就没有具体的套路，我要的是给他一个大方向，他就直接去干且能赚钱的人才。我不需要一个
