# 第六章 人才的招用

靠利益生存的，有钱，企业才能活下去；无钱，企业只能倒闭。所以开除不合格的员工，股东要毫无内疚之感，并且要迅速。公司越大，越是只看成绩不看恩情，一切按照天道来。中国人喜欢讲一句话，“饮水要思源”。其实这个思，就是记住就行了。不是说一个人对你有恩，你发达了，就必须无条件的提拔他。就算你给他机会，他自己没本事，你还是应该放弃他。道理很简单，假如你曾经掉下山崖，被一个农夫救了，你以后奋斗成皇帝了，不是说就得把这个农夫弄来当宰相。老板呢，必须分清是感情与利益，不可混为一谈。

做企业就是有用的人就好吃好喝的待着，没用就让他走！

那么，员工应该如何培养成有用的人？

+   1、让每个部门的老员工写业务操作手册。新员工进来先学习老员工的经验。

+   2、讲清楚哪些应该干，如何干最有效率，哪些不应该干。

+   3、公司的领导必须给员工洗脑，树立正确的世界观，讲清楚公司的企业文化，认可公司企业文化的人留下，不认可的立刻请他走。

+   4、满足员工的短期期望。比如员工想来赚钱，我们就告诉他，公司会对优秀的人分红，给予高待遇。员工想升官，我们就告诉他，有能力的人，业绩好的人，我们就给予升官的机会。总之要看人下菜碟，满足不同员
