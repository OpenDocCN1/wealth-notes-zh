# 1、做自己喜欢的事情，
找员工干自己不喜欢的事情

我们要做一个事业，总是会有很多事情要去做。总有些事情，我们不愿意做，或者说不喜欢，但因为责任、工作的需要不得不做。这样的话，人就会心力交瘁。所以，我的策略是只要是自己不愿意做的事情，我统统交给员工做，我自己呢，只做自己喜欢做的事情。为什么？因为，人做自己喜欢做的事情感觉不到累。比如，你喜欢唱歌，那你在KTV里面唱一个下午，吃了晚饭，还能继续唱到半夜。比如有些人喜欢打麻将，2天2夜不下麻将桌，还想继续。但是如果碰到不喜欢做的事情，2个小时，人就受不了了。
