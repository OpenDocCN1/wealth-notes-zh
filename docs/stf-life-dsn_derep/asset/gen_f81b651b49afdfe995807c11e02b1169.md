# 第八章 工作不是在路边捡到的，是你亲手搭出来的

思维误区：我心目中的好工作，早晚会自己出现。
重新定义：好工作不会上门等你，你得主动去找、去拆解、去重新拼装。

前面说了那么多，归根结底一件事：别再等一份“理想工作”从天而降。它不存在。没有独角兽，也没有白捡的午餐。你能遇到的，是成堆让你有点心动的可能性。公司靠谱、同事对味，你才会在里面待得下去并真正投入，这才算理想。但问题是，这些位置大多藏在看不见的就业市场里。

先说个残酷的数据。在美国流到网上、被大家刷到的招聘信息里，真正有用的大约只占两成。剩下八成的工作，从来就不会出现在标准渠道上。难怪很多人投得心力交瘁，却一次次吃闭门羹。

隐形市场有门吗？没有。门只对已经在圈子里的人敞开，这是个内部人的游戏。求职者硬闯不进去，但如果你换个身份，以一个想听故事、想搞清楚自己兴趣的人出现，就能撕开一道缝。第六章讲过的原型访谈，这时候正好派上用场。搞清楚自己想要什么之后，用这种方式试探，往往就是进场的钥匙。

库尔特是耶鲁和斯坦福的毕业生，照常规投了38份简历，零反馈。后来他停下投递，转去做人生设计式对话。和对自己感兴趣的人聊了56次真诚的原型对话，收到的高质量邀约变成了7份。他最后选的那家公司离家近、时间灵活、收入可观，还做的是他喜欢的环境可持续设计。邀请不是因为他找工作，而是因为他去问别人的经历。

人生设计访谈的本质是弄清楚某个具体的工作或某个人是否值得你去试，而不是立刻去求职。对话里你不是求职者，你是听故事的人。

那从“听故事”怎么变成“拿offer”？答案很反常识，多半是对方先开口。“库尔特，我看你对我们这个行业挺在行的，有没有想过来我们这种公司看看？”

如果对方没主动，你可以轻轻把话题带过去：“我了解得越多，就越想进入这个行业。埃伦，像我这样的人要怎么才能进入这类公司呢？”一抛这个问题，对方就会把你从访客切换到候选人的视角，开始评估你。时机对了，你该争取就争取。

别问“你们现在有空缺吗？”多半的答案是“没有”。“怎么才能进去”是个开放问题，比直接问缺不缺人有效得多。你和埃伦已经有点信任，她会告诉你实情，甚至会说：“我们现在没招人，但你认识绿色空间公司的人吗？我觉得你很适合那里。”

这就是常态。库尔特收到的7份邀约里，有6份他根本没问过职位空缺，是对方主动提的。唯一一家公开招聘的公司，也是他在和CEO完成一次人生设计访谈后，招聘才对外发布的，等信息一出来，他已经被内定了。

还有个细节。面试时5位董事开场就问：“你刚搬到佐治亚，怎么在这圈子里建立伙伴关系？”库尔特看着他们说：“我已经和在座的三位喝过咖啡了，很乐意继续为公司扩展这些联系。”他通过了。但前提是，他先花时间织好关系网。

## 关系网不是让人厌恶的东西

库尔特在做原型对话时，不得不广撒网。熟人、熟人的熟人，甚至在网上找陌生人求教。想了解亚特兰大可持续建筑该问谁，就去问懂行的人。过程很累，但必要。

很多人一听到“关系网”就皱眉，觉得虚伪自私。可真正在利用别人的人是少数。

思维误区：关系网就是一群虚伪的人。
重新定义：关系网其实是为你指路的工具。

想象一下散步时一辆车停下来，司机苦恼地问最近的咖啡店怎么走。你会不会想掏辣椒水？绝大多数人第一反应是“他需要帮忙”。你指路，他道谢就走了。你会觉得被利用吗？不会，因为你就是提供方向。大量研究显示人天生乐于助人。

库尔特在亚特兰大找不到进入可持续建筑的路径，你去香港的纳米技术区、在威奇托找精酿啤酒的人，也一样得问本地人。问路就是职场里的引荐、倾听经历。关系网与其说是名词，不如说是动词，是加入一个领域、参与一场特殊对话的过程。

斯坦福有个关系网，硅谷有个关系网。多数人都有两张网：职场上的和家人朋友的。行业新人最常见的进入方式，就是靠私人网络的引荐。网络存在的意义就是让圈子里的人把事办成，也是进入隐形就业市场的唯一通道。

互联网能帮你找工作，但不是刷招聘。贝拉是我们的学生，她想做发展中国家的影响力投资。做完人生设计后，她只投了三家高薪公司，其中一家是她以前没听过的小公司，却成了现在的工作。半年200次对话，她做到了。超过一半的联系人是通过谷歌和领英找到的，能走关系就走关系。网络的价值在于帮你找到人。

## 你要找的是机会，而不是一份工作

全美高校和雇主协会数据显示，2014年美国毕业生找工作时最看重的是“工作性质”，其次是薪水和同事友好程度。这是典型的思维误区。

你根本没接触过，就不可能知道一份工作的真实模样。职位描述常不准，很多人提前否掉的工作，恰恰是他们不知道在拒绝什么。这是个先有鸡还是先有蛋的陷阱。

思维误区：我正在找工作。
重新定义：我正在寻找大量的工作机会。

区别很大。找工作会让你拼命说服HR你爱这份工作，可你根本不了解它，于是要么撒谎要么放弃。找机会则让你保持好奇，真实地评估。在一家公司里，有20%的概率能发现有趣的事吗？有的话，就值得去看。

好奇心是人生设计的底色。原型访谈和原型体验的核心就是带着开放和好奇去追逐潜在的精彩。没做过调查、没争取过机会，你永远看不清工作的本质。任何机会都值得珍惜，可能里面就有适合你的。

库尔特靠真诚对话找到了好工作，你也可以。这条路难，需要功课，偶尔会怕，但过程很带劲，也是打开隐形市场的唯一方法。联系越多、原型越多、机会就越多。

38份简历，颗粒无收。
56次对话，7个机会，一张能用的工作网络。

你选哪个？

用设计思维不会让你一夜暴富，但能让你不断设计下一份工作，把工作观和人生观拼在一起。别信“梦想工作在等你发现”的童话。它需要你像设计师一样思考，用原型去验证，用行动去选择。

好好学，好好想。
