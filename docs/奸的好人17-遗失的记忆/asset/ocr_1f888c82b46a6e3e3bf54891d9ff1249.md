# 「第一章」

李想回到家后，拖着倦怠无力的身躯进入浴室。

他任由热水从头淋下：心中着实爽快！

今天一整天，他呼吸的会是胜利的空气。

他拿起毛巾抹过身体，喜不自胜地走到洗手台镜子前。

贴近镜子，他想把自己这副得意的神情再看清楚一点，于是他将镜子上的水蒸气抹了又抹，轻轻抚摸着 自己额头上凹凸不平的疤痕，一边狞笑着看着自己显得特别大的左眼和几乎眯成一线的右眼，他紧握拳头说：

「李想，你果然了不起，一出手即解决掉胡静怡。胡静怡，看那胖子还敢不敢再播你唱诵的往生咒。」

他随手将毛巾丢进浴缸内，拿起睡袍穿上，懒洋洋的躺在床上，他的眼皮愈来愈重……

# 「李想遗失的记忆3」
