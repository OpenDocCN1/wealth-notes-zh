# 「第三章」

李想又从梦中惊醒，他愤恨地用力摇头，一边哭泣一边呐喊着：

「梦中那个上女佣的人不是我，这不是我、真的不是我！我没有那么窝囊！那绝对不是以前的我，是幻象，我不要再寻找以前的记忆了，黑暗的护法神，你告诉我，那个绝对不是我！」

他嘴里不断重复着：那不是我！那不是我！

之后，李想慢慢冷静下来，口中不自觉又呢喃说：「老爸，我永远记得你的教训：永远也不要相信人，包括你的老爸！」

当李想惊觉自己说出这句话时，他又开始懊恼起来，又自言自语：

「妈的，二叔是谁？为什么我完全记不起老爸说的这件事？二叔到底是谁？为什么老爸会说帮我报仇，我脸上的疤痕真的是二叔留下的吗？我的头又好多痛啊！」

疑惑的噩梦总是层见叠出，一次又一次把李想推向崩溃的悬崖边，摇摇欲坠。

「造飞机、造飞机……

蹲下去、蹲下……

蹲下去、蹲下……」

「我怎么对这首歌一点印象都没有？」

李想不断用手捶着脑勺，希望能把这段回忆敲出来，可惜，这首歌根本不在内存的档案夹里。

司徒彪仁从床上坐了起来，心中极度惊慌，浑身发抖，简直快尿裤子了。

「怎么搞的、怎么搞的？为什么我会梦到那怪物的事情？是真的吗？李卜真的是这样训练他？而他二叔又是怎样的人？他的大小眼是在四岁就受到残害的吗？」

「不，我还是不动声色比较好，否则让李想这怪物知道我梦过他的记忆图片，我又有得难受了！」彪仁计谋着。
