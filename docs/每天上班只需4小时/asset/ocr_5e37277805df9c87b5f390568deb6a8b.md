# ◆ 掌握「自己的關鍵字」，成功的不二法門

「齊藤式速讀法」裡，有一個名為「關鍵字法」的執行方式。

這個方法的意思是，當我們集中精神閱讀一本書時，關鍵字一定會一直出現在眼前，此時你必須降低速度，讀取關鍵字周邊的相關情報。

各位知道關鍵字總共分成兩種嗎？

一種是「自己的關鍵字」——「我想知道這件事」、「我對此事抱持高度興趣」、「這是目前自己的人生方向」等，只要心中有了這些關鍵字，就算在快速翻閱資料時，關鍵字也會自動映入眼簾。
