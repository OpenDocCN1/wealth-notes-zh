# 〈二八定律〉

前二○%人的生產力，是其餘八○%人的十六倍

![](bbox=[0.1, 0.27, 0.9, 0.52])

就「二八定律」的觀點來說，不管什麼樣的國家或團體，皆可從下列的計算方式瞭解到這個事實：前20%人的生產力，是剩餘80%人的十六倍——

+   - 這裡有一個由一百人所組成的團體，假設生產力較高的前20%（A組，共二十人）能創造出80%利潤。而這20位生產力較高的人，每 人所創造的利潤相當於80%÷20人＝4%。
- 在這個一百人的團體中，扣除生產力較高的20人後，剩餘80人（B 組）所創造出的利潤總額為20%。因此剩下的80人，每人創造的利 潤相當於20%÷80人＝0.25%。
- 因此生產力較高的A組20名成員，每人的生產力為4%；生產力較 低的B組80位，每人的生產力為0.25%，將兩者比較之後可發現生 產力之差為A組（4%）÷B組（0.25%）＝16倍。
- 由此可知，假如將這個定律套用到工作上，只要處理前20%的重要 案件，生產力就能提升到平常的16倍。
