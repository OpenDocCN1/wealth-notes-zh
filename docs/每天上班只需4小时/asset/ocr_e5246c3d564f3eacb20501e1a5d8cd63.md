# 高速世界裡工作的人，能獲得較多的創意及靈感。

有一位擔任產品企劃的人曾經跟我說過：「想要做出暢銷商品的人，必須隨時打開接收創意的天線，注意每一個小動向，並跟上這些動向的流動速度。雖然後我的工作聽來似乎有點辛苦，但只要習慣此種速度，即便你在這過程中適度的休息、享受私人時間，工作速度也不會因此停滯。」

企劃案或創意，常常是坐著速度之毯，在我們頭腦空空時突然飛入，讓人不需多加思考，就能從中蹦出好的靈感。
