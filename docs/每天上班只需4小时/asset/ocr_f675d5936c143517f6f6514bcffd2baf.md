# 一 價值工程 科學公式的實際驗證

在價值工程的領域當中，有一個計算價值的公式。
V（Value 價值）= F（Function 功能・成果）÷ C（Cost 投入費用・時間）
托這個公式的福，開始能夠在生產方式中，以數字來計算提高價值的方式以及找出創造價值的方法。這是一個劃時代的做法，有筆者甚至將這個方式套用在知識產能的領域，完成了論文的寫作，而該論文也被刊載於日本價值工程協會的雜誌首版與前言。

究竟這個公式代表什麼意思呢？

依據此公式所表示，V（Value 價值）與 F（Function 功能・成果）成正比，但與 C（Cost 投入費用・時間）成反比。

在 F 的值愈高，以及 C 的值愈低時，其 V（價值）愈高。
