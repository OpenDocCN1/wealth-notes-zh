# 快速閱讀，儲備知識，人際關係能變好

請將「閱讀」變成一種習慣。接著你就能透過速讀技巧，快速閱讀眾多書籍，並從中找出當下對自己最重要情報。書籍是智慧的寶庫——專家或熟知各

方面領域的行家們，將他們長年研究的知識與經驗，全部匯集於一本書裡。
