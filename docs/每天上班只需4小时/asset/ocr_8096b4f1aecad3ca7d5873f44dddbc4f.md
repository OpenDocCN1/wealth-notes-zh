# ◆「接合黑點」，串連大腦思維

人類的大腦中，每一個腦細胞皆有神經纖維呈放射狀向外延伸，同時與其 它細胞不斷地錯綜複雜地連結著，藉此構成了「思考迴路」。 這時候擔任「接合大臣」角色的是一種位於神經纖維尖端的接合部位，名為 「突觸」（Synapse）。

在突觸裡存在著許多的「粒線體」（Mitochondrion），但大多處於休眠狀 態。但是，當所有細胞聚集在一起後，它們則會開始活躍，並且生成能量。接 著，突觸將釋放出神經傳導物質，將情報傳到下一個細胞。

因此，我們在心智圖當中也有類似這個功能的接合大臣—當主要分支線從 中央的橢圓形向外延伸出更多小分支時，在它們的連接處，以「黑色圓點」標 示，就等同於突觸的功能。
