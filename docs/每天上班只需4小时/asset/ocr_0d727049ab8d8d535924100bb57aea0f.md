# ◆掌握整體樣貌，不再瞎忙

「明明一個接著一個把眼前的工作處理完了，為什麼事情還是一堆？再這麼下去，我似乎會永遠迷失在工作的迷宮中，也必須辭職了。到底要怎麼解決這個混沌的狀態？」一個陷入工作苦惱的人向我求救，提出了這樣的問題。
