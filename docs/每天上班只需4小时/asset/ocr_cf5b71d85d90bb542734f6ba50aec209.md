# 「大腦筆記術」，完全釋放腦中創意

能幫助你實際運用於工作中，這就是「心智圖」的全部樣貌。

像是從複雜的糾葛中走了出來，感覺十分輕鬆，當我為企業進行研習課程時，許多人在真實體驗心智圖後，紛紛發表這樣的感想。

「心智圖」就是一種一五一十地將大腦的思考迴路呈現於紙上的筆記方法。我將「心智圖」自行命名為「快速思考心智圖」。為什麼要加上「快速思考」四個字呢？因為只要透過心智圖就能環顧整體的思考樣貌，瞬間做出正確判斷。

大腦中每一個腦細胞都有許多神經纖維呈放射狀往外延伸，並且不斷地與其它細胞接合，因而創造出了思考迴路。而在心智圖中，第一步必須在紙張的正中央畫一個橢圓形，並在裡面寫下主題。隨後，再將自己的想法全部依據畫葫蘆，一個接著一個地，從橢圓形呈放射狀，往外畫分支（關連線）。這完全是模擬神
