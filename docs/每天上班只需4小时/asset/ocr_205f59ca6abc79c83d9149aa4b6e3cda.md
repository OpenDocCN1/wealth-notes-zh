# ◆善用千億腦細胞，創造高效思考迴路

據說人類的大腦細胞總數為一千億個。不管是像蘇格拉底（Socrates）或亞里斯多德（Aristotle）這些出色的前人們，還是得到諾貝爾獎的科學家們，以及工作能力較強的A先生，甚至你自己，大腦的細胞總數皆是相同的。

人的神經細胞被稱為「神經元」（neuron），而這些神經細胞往外延伸聚集成套，即為神經纖維（nerve fiber），也就是我們一般統稱的「神經」。腦細胞便由神經元及神經纖維所大致構成。

每一個腦細胞透過神經纖維，以及神經纖維頂端被稱為「神經鍵」（Synapse）的接合部位，與其它的腦細胞相互連結，形成一個複雜的網絡。而這個網絡便稱為「思考迴路」。
