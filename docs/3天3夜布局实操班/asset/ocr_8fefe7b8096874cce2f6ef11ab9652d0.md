7，卖故事的不如卖品牌的。

为什么说卖故事，不如卖品牌的那。

因为一旦形成品牌，就会有品牌连锁。就代表了形象和标志。

但凡做品牌的，都不是说我做2年就不做了，至少围绕10年的目标来做。

一般品牌为了把控质量，和更好的管控。 通常情况下不会采用招商加盟的策略，而是使用直营方式，更加。

比如：周黑鸭——采用直营模式。不开加盟店，不招收任何分店。
