# 近80%的富人

# 每天花60分钟在实践或学习上

科里在书中说：

> “每天我采访过的富人都会花时间强化一些和他们的事业有关的技能，学习一些相关的知识。

这种日常的习惯帮助他们维持并提升他们的能力和知识储备，让他们成为自己行业里的行家里手。”

富人更愿意学习，而不是娱乐。根据统计，88%的富人每天至少会阅读30分钟，内容以自学和自我提升类阅读为主。

“股神”巴菲特，每天有80%的时间都在阅读，他曾在出席哥伦比亚大学商学院活动时表示，成功秘诀是“每日阅读500页”。
