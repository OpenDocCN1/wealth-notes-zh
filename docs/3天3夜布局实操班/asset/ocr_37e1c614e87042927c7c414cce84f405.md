同样：比如街道上有4家超市，我给其中一家超市的绝招就是：让他们的鸡蛋，大米，以及馒头，和部分商品，成本价出售。 人家卖馒头5元10个，我们就卖12个。

其实：这种方式，很多人就感觉这家超市很便宜，结果都会来这家来，自然可能顺带掏带一些东西回去。

所以：就形成了某些竞争了力。

用前端来捆绑客户，用后端来赚利润。

比如：平常的很多洗车店，都是10-30元洗一次车，我们直接搞一个活动：

+   1, 先免费洗车

+   2, 引导充值100元我们送12次洗车，但是我们有半次洗车，因为洗车分为车内和车外，如果只洗车外算半次，那么基本上算24次洗车的机会。

基本上洗车都是相当于成本价，不靠这个赚钱。主要靠这个锁定客户。

+   3, 提供免费检修服务。小毛病不需要更换零件的不需要钱。

+   4, 提供低成本，或者成本价的保养服务。 让消费者黏上我们，喜欢我们。

通过以上动作，黏住客户后，那么我们下一步就是靠后端：维修，保险，信贷，换轮胎等进行赚钱。因为只要有足够大基数的客户，我们就有了可持续赚钱的来源，前提就要舍弃短期利益，去获得长期利益。

低成本洗车：是不是黏住客户了。

免费检修：是不是也可以。

提供低成本，或者成本价的保养服务

这些头都是通过一些高频，或者常用的一些东西，进行黏住客户。
