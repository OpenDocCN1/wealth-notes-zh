# 【玩跳一跳游戏有感！】

我不相信自己能日入过10万，当我身边有一个人日入10万，我了解到他是怎么做的之后，不久，我竟然也达到了日赚5万，真的是那么神奇。

人从不相信自己没见到过，没发生过的东西，然而真正有这样的人存在了，你也觉得不是什么难题。

所以找榜样，了解他的模板，思路是多么重要。

人性从来不相信自己幻想的，永远只相信已经存在的（身边人，熟人），所以：多找一些比你牛逼很多的人，看他们都在干啥，是如何做的，亲自沟通，学习，体验，比读多少书都更加重要。

这1就是读书不如阅人无数增长见识，自信最大，最有效的方式之一了。

任何时候保持高度好奇心很重要。

假设：一个乞丐收入一天才30元，然而有一天去上海他遇到一个乞丐竟然日赚2000元，他就很好奇，怎么做的，于是偷偷摸摸跟着他，发现很多秘密，然后他回家，把这些方式方法用到本地，竟然也日赚500了，同行是最好的老师，在不经意之间竟然翻翻了利润，然而在过去本地乞丐最高收入不过日赚300元，从来不相信什么日赚500，1000的段子。所以5年了，还是这么微薄的利润，然而意外就在看到上海乞丐后，为何突然1个月内，收入瞬间倍增那。

人性从不相信身边人没有人做到的事情（当然：身边人做到了，他也一定相信，他也可以）

什么叫坐井观天，这就是了。
