1辆车就是1个移动门店，合作100辆就是100家移动门店，整合一个城市500辆出租车，500家移动门店，估值2000万，融资1个亿。

这些都是利用线下渠道，通过一级倍增，实现快速做大做强的基本方法。

如果，你也有生意，完全可以换一个思维，换一个角度，通过倍增的思维，去做我们的市场，无论是三级分销，做加盟，直营-代理，区域代理-终端等多种方式，都是快速实现倍增的基本思路。

对于线下一般最常用的基本都是这些方法。没有捷径可言。

对于线下：这幅眼镜价值2000元。但是你只要介绍一个客户过来，每次给你返利200元。介绍一个人过来，减价200元。

在线上可以简称为：砍价模式。拉一个人砍价，就可以少一些价钱。进而引爆流量。
