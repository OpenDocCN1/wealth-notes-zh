# 【卧龙营销内部资料】布局实操班

如果说对于开创性的团队主要靠不断制造需求，引导需求，通过激励，刺激，股权，捆绑员工的话，那么服务性的团队，则需要温水出青蛙。

哈叫温水煮青蛙？

就是要打造一种企业文化，制造一种独一无二的企业氛围，让员工满足于当下工作状态，依赖于这种工作氛围。

如果我们是服务性团队，你非要搞什么成功学，搞什么早中晚会费尽心机，刺激他们的需求，升级他们的欲望，结果是悲剧的，大多数人就渐渐变的不安分了，没几天就走光了。肯定只会剩下孤零零的你。

不要过度模仿，崇拜，别人的管理手段。

如果企业存开创性团队和服务性团队，那么我们就可以采取两种不同的管理举措就可以了。

比如：我老岳是砂石料场的老板，我就给他出了一个方案，就是员工除了装沙子，卸货，运输之外，那么我就给他准备了休息室，里面有麻将机，打游戏，上网，老虎机，沙发，液晶电视，只要完成工作，没事儿，就可以打打牌，斗斗地主，看大片啥的....

（反正就是让他们消沉，这样我们才能捆绑住员工。他一旦去其他公司：其他公司没有这个文化和氛围，他就受不了，结果又TM回来干了... 哈哈。我们就是让他们赖疼，糜烂，让他们不求上进，安逸现在最好了）

自从开了休息室，麻将机和扑克牌经常是满的，因为只要完成了任务，就可以搓几把，但是如果有活了，就可以找人代替，当然：如果老板和合伙人要玩几把的话。我们就规定：他只能输，不能赢，这样他们就很有虚荣心，更加愿意玩了。

但是如果因为玩麻将，耽误了活，那就罚款。 就那么简单。

总是，就是让他们感觉来这里上班没有那么多条条框框，只要做好份内的事儿，剩下的就是玩，愉快了。

这样从适应到依赖，以后想跳槽都难了。

结果什么情况那：很多员工休息日，也跑休息室打牌，玩。说明什么问题那。 哈哈~~这招绝吧。

但是我们对于开创性的团队，销售人员，业务员，营销经理，我们就不让他安逸，天天给她讲谁谁做的比咱们还好，给他们危机感，另外团队里面设置pk机制。 让他们业绩斗狠。

另外那，我经常带这些销售人员，去我的别墅，去住一晚上，问他们：”这别墅舒服吗？”他们都说舒服。舒服就好，那只要努力，很快这房子就是你的了。我要把这套房子
