# 【卧龙营销内部资料】布局实操班

我记得我们上次分享：还没有几个月，你看这个做贴膜培训的小美女，之前是几万粉丝，现在都已经涨了25.8w粉丝了。

初步估计：初步估计一个学员收费3000净利润X1000=300万净利润。

所以，各位选择倍增环境的时候，一定要选择线上为主，线下为辅的方式。

因为线下你做什么都需要成本，坐公交，找兼职人员，开设场地，而且只能在本地城市，覆盖面有限，所以相对裂变速度会难一些。

对于互联网环境裂变就不一样了，可以瞬间裂变到全国，而且低成本，覆盖面广，更重要的是可以零距离沟通，随时随地成交对接。

记住：线上传播的速度是线下速度的100-1000倍以上。

线上赚钱的速度也会是线下赚钱速度的30倍。

就看我们怎么玩了。

目前我们接触的企业中，现在很多都已经往互联网方向转移，只要做的，一般都有不小的收获。
