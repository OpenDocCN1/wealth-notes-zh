## 【这里面就要用到几何倍增学】

过去没有微信，只能打电话通知。

于是他就把几何裂变分销倍增学用在了这次电话通知780名代理商工作中，结果只用1小时就圆满完成老板的任务。

第一步：给其中1号到5号共5位代理商分别打电话，讲清楚本次电话的主要任务后，再请他们每人帮小明打电话通知5人，每人用时间3分钟共用去15分钟时间。

第二步：由1号到5号每人再分别给5人打电话，内容和小明的一样，时间也是每名要用3分钟，5人同时进行下来又用15分钟时间，这第二步下来就将6号到30号电话通知完了。前两步共用去时间30分钟，共电话通知了30人。

第三步：又由6号到30号共25个人每人各打电话通知5人，每个的内容、时间和前面一样，结果通知了31号到155号共125人，又用时间15分钟。前三步下来，共用去时间45分钟，共通知了155人。还余下625人没有通知。

第四步：又由31号到155号共125个人，每个按前面的时间、内容、方法各电话通知5人，奇迹出现了，这15分钟下来，这125人共通知了625人。这四步的结果，小明共用时间4个15分钟即1个小时就完成了780人的电话通知，提前一个小时完成了老板的任务，他最后得到老板的嘉奖和重用。

这个世界上最好的裂变，就是几何裂变分销。

- （1）让每一个客户成为我们的分销商。
- （2）让每一个客户带来的客户，继续成为分销商。

其中：这点我们必须跟直销模式，传销模式学习。

通过这个故事，可以看出有几个好处？

- 1、节省时间。

为什么说节省时间呢？小明本该用39小时来完成的事情，他只用了1小时就完成了，所以说他节省了时间；

在我们生活中，对于赚钱这个事情，也完全可以节省自己时间，让自己赚更多钱。首先你必须先学会劳心，而不是老力。没事多看书，少吵架，少动嘴皮子。

往往很忙的人都是穷人。

小明用剩下来的38小时，他又可以做更多的事，推销更多的产品，所以他倍增了利润；

诸葛亮最大的失败莫过于，什么事情亲力亲为，从来不会倍增自己的时间，培养一批才干，让他们去犯点错，进而成长，以后可以充当一线，二线指挥。
