# 晨会系统

中国有句老话：“一日之计在于晨”。对从事终端销售行业的企业的人来说，晨会是每日工作的第一步，是鼓舞士气的重要环节，它对激励员工斗志，明确每日目标，凝聚团队向心，强化企业文化，达成业绩目标，激发个人活力，提高个人成长的有举足轻重的作用。

但很多企业员工一听到开会就觉得枯燥无味，甚至痛苦难忍。如果你公司现在拥有一套完整的晨会流程，那么原来无效的晨会，痛苦的晨会立刻变为开心的、疯狂的晨会、最有绩效的晨会。作为一个企业的老板，如何可以不用时刻时刻盯着员工做事，而把全心的精力投入企业的策划与产业发展当中呢？

首先要解决的问题就是浓缩管理时间，用15-30分钟来达到你一天所要的结果。

现在我把自己研发的、目前在我公司运作非常有效的一套晨会教育模式告诉大家，希望业内人士能从中有所受益，从而提高管理水平，实现企业更高的业绩和利润。

# 【第一步：快乐舞蹈】

1、假如8：00正式上班，那么07：50就可以播放激励舞曲，比如《兔子舞》、《请你恰恰》、《相信自己》、《真心英雄》、《精忠报国》、《我真的很不错》、《向前冲》、《眉飞色舞》、《阿拉伯之夜》、《不如跳舞》、《动起来》、《独一无二》、《浪花一朵朵》等快节奏的动感歌曲，让员工一听到音乐就跟着节奏动起来，兴奋起来，用动感音乐把之前的睡意和懒洋洋的情绪一扫而光，这是激情预热阶段。

2、7：55，主持人（经理、店长、主管、领班）向各位员工拍掌问好：“早上好，你是最棒的！”
