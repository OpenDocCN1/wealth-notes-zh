# 【第九步：快乐体罚】

每一次活动，每个月的业绩都可以让员工自己设立奋斗目标，如果没达成目标就做50-100个俯卧撑来体罚，并让其他的员工在旁边为他们加油鼓劲。但如果 늳违纪就不體体罚来代替，只能拿现金投入捐款箱，不用开罚单，因为我们把这种方式叫做“乐捐”。

当然这里还有一个心态的问题，很多 人知道自己要被罚心里很不痛快，甚至一整天都郁寡欢。我建议被罚的人向积极思维的“牛仔大王”李维斯学习，当他遇到挫折时，他会立即大声地对自己说：“太棒了，这样的事情竟然发生在我的身上，又给了我一个成长的机会。凡事必有其因果，必有助于我。”

# 【第十步：圣洁宣言】

激情的预热和工作通报及必要的奖惩之后，就剩最后一项了——圣洁宣扬。这是一个自我表态，自。此暗示的过程，大声地说出自己的宣言，给自己压力的同时，也增添了很多动力。而且诵读拟定好的宣言，有利于团队达成统一的目标，强化团队的共识，降低沟通成本。

比如可以由企划部拟定这样的宣言词：

我不是为了失败而来到这个世界上的！在我的字典里面也没有“行不通”、“办不到”、“没有希望”、“失败”、“挫折”、“放弃”等愚蠢的字眼。我相信滴水穿石的道理，我相信古老成功法则：每失败一次就等于向成功迈进了一步，这一次的拒绝就意味着下一次的赞同。今天的不幸，往往预示着明天的leman。

（举起右手，高吭的声音，三遍）
我宣誓
我要以十二万分的精神，
以全力以赴的态度达到巅峰状态
遇到拒绝、绝不绝不放弃！
只要心中相信，梦想一定成真！

我总是心存感激，感激给我挫折和帮助我的人。我不因昨日的成功而感到满足，也不因昨日的失败而感到气馁，我我深信：只要生命不息，就要坚持到底！

以上10个晨会步骤可以当作一个完整的晨会流程，其中有些环节可以根据公司的实际情况做相应的变换。总之目的只有一个：实现有效率的管理。如果公司老板可以不用时刻盯着员工做事，而把全心的精力投入影楼的策划与产业发展当中，那就是企业发展最大的幸事。而高效的晨会就是企业家最省心的源头管理。
