# 【卧龙营销内部资料】布局实操班

# 《二十四项检讨定义》

01、完成结果：我是否依日程安排行事了？我是否已完成当日所定业务量的指标？

02、全力以赴：我是否真正做到百分之百的投入，只看到目标，不找任何借口，凡事以结果为导向？

03、用心：我是否细心观察每件小事，仔细倾听别人讲话，用心感受、体谅他人感受，并且思考如何把事情做得更好？

04、认真：我是否认真工作，仔细思考，努力把品质做到一流？

05、责任感：我是否清楚自己对哪些事负有责任？我是否肩负起了这些责任？

06、态度良好：我是否虚心听取了别人对自己不足之处的指正，不论对方口气如何，只要是我错了，我都无条件改正？

07、脚踏实地：我是否依系统、流程及规律来做事，并无心浮气燥，急于求成之过？

08、坚持不懈：我是否每天练习基本动作，并坚持不懈地练习基本功？

09、情绪稳定：我是否能控制自己的情绪，并无放肆过激的行为？

10、为人着想：我是否用心思量别人的需要，并给别人所想要的？

11、不断付出：我是否有在各个方面不断主动帮助别人？我是否在不断为公司团队的发展尽一份心力？

12、努力四倍：我是否在工作、学习、个人成长上比别人更加努力，行动次数及行动品质超过别人4倍以上？

13、有使命感：我是否清醒自己的使命，并在为使命全力以赴地工作？

14、言行一致：坐下来冷静地问自己的内心，今天我是否时时处处都真诚地面对自己的内心在做事？有无自欺欺人之处？我是否真的做到了思、言、行的统一？

15、快乐微笑：我是否对每个人都微笑了？并把快乐传递给了每个人？

16、勇于突破：我是否在永无放弃的精神下坚持做事？并时时寻找自我突破？

17、愿景梦想：我是否还有一个伟大的梦想让整个团队成为伟大或卓越？

18、感恩的心：我是否怀揣感恩之心，不断地用行动去感谢那些曾经帮助过我的人们？
