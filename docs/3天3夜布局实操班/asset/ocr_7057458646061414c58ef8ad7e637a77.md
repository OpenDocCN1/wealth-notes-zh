# 【卧龙营销内部资料】布局实操班

黏性+价值最大化，才可以吸引新用户，同时保留老用户。

新客户开发成本是老客户的6倍数以上，黏住客户很重要。很多人，比如：辛辛苦苦，甚至亏本把客户引流到店里来，可能人家根本不买账。

其实80%的净润开发，都是来源于老客户。

或者人家来了第一次，第二次人家再也不来了。

如果是线上，可以比作为：你只是把客户吸引来，不管通过广告，软文，还是其他，暴力加粉等，但是你没有培育，没有持续给客户贡献更多价值，最后客户还是不相信你，不信任你。 人家还是会退群，或者直接拉黑你，就那么简单。

什么叫真正黏住客户？

你看，比如你们的店面从3个人过来，到5个人，10个人过来，然后100个，500个人，客户主动帮你转介绍，而且客流是逐步稳定上升趋势，这就说明你的产品和服务，真正黏住了对方了。

而是说，刚开始来了3个人，然后到50个人，慢慢竟然就变成了30人，新客户进来，老客户没留下。

或者新客户来了第一次也没留住，那么无法持续黏住客户的，即便你商业模式在厉害最终都会倒闭。

怎么黏住客户？ 培育客户？

方法一：引入高频，嫁接高频产品和服务到店里面。
