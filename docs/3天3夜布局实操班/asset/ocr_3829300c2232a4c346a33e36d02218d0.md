# 【卧龙营销内部资料】布局实操班

于是那：还真收了不少。

新中国成立后：国家就出台保护古董，回收各种古董的政策。

这个政策出来后，古董一下就成抢手货了。价格一下翻了几十倍。

这小子，一下就身价成土豪了。

我们一定要注意到一个问题：如果这个人不去北京。他这辈子都不可能知道老物件可能会值钱。

所以：这就是见识多的，获得了市场信息。

信息差决定财富差，一点也不足为怪。

同行业交流互动：如果你要做什么项目，我们不如找一些行业内的人，去问问情况，做一个参考意见。

这样的话，我们失败的概率是不是就大大降低了。

首先：我们明白为什么失败，为什么这项目不行，为什么不好做。 。。。

弊端，劣势在哪里，我们能不能改进，或者升级模式。来换一种思路来玩，可能就成功了。

但是如果：我们不去这样做。单纯自己瞎猜，没有用。

几乎项目失败了80%。

但是如果我们市调足够清晰，明确：我们就知道会遇到什么问题，怎么解决，至少有一个大概的准备和预防。

是不是。

很多傻逼，就是看到一个项目，单纯凭借招商的人，一面之词和自己的直觉，冲动就干了。

还说什么：“光膀子，不怕穿鞋的”

最后成功了那：他说你阻挡他成功了。

失败了那：他说都是你诅咒的。
