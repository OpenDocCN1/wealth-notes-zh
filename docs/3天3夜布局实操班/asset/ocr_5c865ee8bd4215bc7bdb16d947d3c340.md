# 1，路过的自然流量（客户）

比如你开了一间街边店面，你不去做任何宣传就会有路人来人往的顾客进店，这就叫路过的流量。路过的流量，指对实体店而言，门口人来人往的路过，它是门店自身的特性，不需要进行任何宣传就会产生产品的潜在流量。

所针对的企业，分为3种：

+   1，大型门店：游乐园，百货商场，景区…
2，中型门店：餐饮店，奶茶店，酒店…
3，小型门店：地摊，水果摊，煎饼摊…

而对于淘宝，电商这类企业营销，其“过路流量”就是自然访问量。也可以算同一种说法。
