# 【卧龙营销内部资料】布局实操班

紫色：促进睡眠；提高想象力；
粉色：让人变得温柔；消除紧张感；让人看起来年轻；
白色：让人清晰的印象；让人感觉比实际重量轻；
黑色：让人感觉压抑；让人心情沉重；让人感觉比实际重量重；
灰色：有品位，让人心安；平凡严谨的印象；

举个例子，有个快餐厅，开始时候，是红色装修，结果很多人吃完，还不走。导致换台率低，而赔钱。

于是我建议，装修为白色，很快就得到改善，都是吃了就走，没有停留。

红色让人不自觉攀谈起来，而白色，则更清晰还有事情要做。

对于产品包装的要点：

+   1, 投其所好

根据目标客户群体的喜好筛选适合的产品构思和设计点子，无需兼顾所有用户。

例如：年轻人喜欢新奇，抽象，多功能笔，只需要设计各种鲜艳颜色，造型独特，携带方便的笔，而无需过多考虑笔本身的耐用性。
