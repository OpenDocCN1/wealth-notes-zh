# 【卧龙营销内部资料】布局实操班

这是郑州市鹿总做一个项目：

他这个智能电视盒子。

就是免费送：1，需要缴纳押金。

2，可以给儿童在线播放教育频道。

3，可以考电视盒子本身的弹窗广告，以及电视广告进行赚钱。

其实，像这类项目也很多。有很多人来找我投资，我发现也有很多这样的项目。

比如：投放广告机然后靠app下载赚钱，还有靠投放广告赚钱，然后卖机器也能赚钱。

很多这样的公司，可能梦想和初衷都是很好的。

但经过我们投资部市调就发现，事实赚钱的基本上都是在大城市。

小城市几乎很少赚钱。

二三线更是赚了一部分钱。

不多，后台显示，最多的一個月几千块，但是真正赚钱的不足10%。

所以：有时候，我们选择项目的，一定要考虑是不是刚需，别人为什么会下载app，另外广告商为啥愿意投放广告？

如果不是刚需的话，其实很难做起来的。
