因为小东心里想：“花椒是我们厨房日常菜品必备的大料，每天都在用，现在市场价30-45元，他学过三大思维，就市调了往年花椒的批发，销售价格，发现都很稳定，从来没有过低，或过高的情况，觉得这个属于比较平稳的产品。”

过市调，他觉得这件事情可以做。

于是在家里承包了80亩地，种植花椒。

2,终于到了收获花椒的季节了，小东悉心管理了3年的花椒树，终于产出产量丰厚的花椒籽，满是欣喜，这一下就让他赚了80万，然后他竟然用这个钱，分期买了一辆大奔，并在老家盖了一处大院，并到处找人宣传他这一下就赚了80万元，这几个步骤一出手，附近的村民听到风声，都来参观，膜拜，想要学习学习，怎么种植花椒。
