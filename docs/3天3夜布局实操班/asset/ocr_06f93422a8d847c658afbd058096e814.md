# 【卧龙营销内部资料】布局实操班

76%的富人坚持每天有氧运动30分钟以上。

有氧运动包括跑步、短跑、快走、骑自行车等。

有氧运动不仅对身体好，对大脑也有很大帮助。

有氧运动可以增加神经元(脑细胞)，体育锻炼还可以增加体内葡萄糖含量，葡萄糖就是大脑的燃料。

大脑获得的养料越多，发展就会越好，你也会变得更聪明。

健身是每时每刻的事，它是吃进去的每种食物，是充足的睡眠，是压力管理。

> ——斯科特·迈纳德（债券投资大师）

# 结识成功人士

你会和你常常来往的人一样成功。

富人总是在寻找目标明确、乐观热情、心态积极的人做朋友。

另外也要避免与负能量的人或影响接触，负面的、消极的批评会让你离成功的道路越来越远。

格雷厄姆的学生们是一个好的圈子。沃伦·巴菲特人非常不错，他每隔两年邀请我们，我们会去某个地方聚聚。
