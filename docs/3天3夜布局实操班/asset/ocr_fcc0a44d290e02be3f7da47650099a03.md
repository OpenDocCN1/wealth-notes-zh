# 【公司内部管理落地机制：管理中的狼和羊】

企业本身主要分为2种团队：

+   1， 开创性团队（销售，市场，公关竞标，营销等）
2， 服务性团队（仓储，运输，技工，售后，客服，财务等）

开创就是狼，主要目的就是争抢客户，甚至自相残杀。但是服务性就是羊，只需要老老实实用心服务好，客户，维护市场就好了。 根本不需要像很多业务员面临很大的压力和困难。
