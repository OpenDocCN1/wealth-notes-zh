同样是突破1000亿元的成交额。阿里巴巴用了10年，京东用了6年，而拼多多竟然只用了3年。

是不是砍价。

他们利用微信端的流量：利用砍价。 或获得一个指数级的裂变。

假设：一个人砍价，发给10个朋友，或者群里。

那么可能有10个人看到了，这10个人再去砍价。那么就会形成一个10X10=100个。

100个有效人数，那么每个人再传播10个有效人数：就是1000个有效人数。

每一次都是呈现指数级的倍增。

所以拼多多为啥能在1年内实现几千万，几个亿的用户量的本质原因。
