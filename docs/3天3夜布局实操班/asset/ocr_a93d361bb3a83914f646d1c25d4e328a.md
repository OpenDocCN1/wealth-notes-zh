# 2，再次消费的流量（老客户）

如何让已经购买的客户，经常来？

如果让咨询但未购买的潜在客户，下次来买？

策略1：建立数据库(微信，QQ群，手机号(短信)，身份证…)，保持沟通和联系（所有潜在客户：购买，未购买客户进行管理…）

比如：让客户加微信。 或者让客户留手机号，然后我们加他微信。
