# 【卧龙营销内部资料】布局实操班

我们是问题是解决者，我们不会被问题所解决！

我们的员工理念是——”，员工答：

+   - 不怕拒绝，拒绝是因为顾客对我们还不了解
- 不怕拒绝，拒绝是因为我们对顾客还不够好
- 不怕拒绝，拒绝下低头是因为我们还不够爱
- 不怕拒绝，拒绝下低头是因为我们不够坚定
- 不怕拒绝，拒绝下低头是因为我们没有信念

在口号宣扬完之后，这时公司的经理宣布一些关于公司的利好消息，让大家对企业未来的发展有信心，还可以分析一下竞争对手的进展情况，从中找出之间的差距，让员工看到希望。对已经制定的业绩目标，经理可以在会上发出挑战，激发员工的挑战欲望和参与热情，这样可以在今后的工作中促使员工更加积极地投入工作。

作为晨会主持人，也要注意几个要点：

+   1、精心 的准备，保持好心情。
2、营造热烈的气氛，适时互动。
3、语言要形象生动，具有一定的煽动性。
4、晨会主题要具有吸引力，要让员工对晨会有期盼。
5、适度赞美。
6、要控制好场面。

# 【第九步：快乐体罚】

每一次活动，每个月的业绩都可以让员工自己设立奋斗目标，如果没达成目标就做50-100个俯卧撑来体罚，并让其他的员工在旁边为他们加油鼓劲。但如果是违反纪律就不能用体罚来代替，只能拿现金投入捐款箱，不用开罚单，因为我们把这种方式叫做“乐捐”。
当然这里还有一个心态的问题，很多 人知道自己要被罚心里很不痛快，甚至一整天都都郁寡欢。我建议被罚的人向积极思维的“牛仔大王”李维斯学习，当他遇到挫折时，他会立即大声地对自己说：“太棒了，这样的事情竟然发生在我的身上，又给了我一个成长的机会。凡事必有其因果，必有助 于他。”
