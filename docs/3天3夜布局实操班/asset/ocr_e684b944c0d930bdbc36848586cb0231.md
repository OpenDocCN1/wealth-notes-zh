# 【卧龙营销内部资料】布局实操班

很简单：就是该单一的时候，就单一，该多元化的时候就多元化。

> ——你可能说了：老孔你不是说废话吗？

其实在我们做生意和做项目，还是引流过程中，我们要遵循这样一个原则：

先多元化——单一聚焦。

比如：我们做了10个产品，我发现8个不赚钱，那么我们直接砍掉所有的项目，只搞这2个，做到极致。

多元化——单一项目的专业。

比如：在2001年，那时候，我跟我哥去卖全场9.9元的商品。

其中哪，有各种小家电，小家具，雨伞，弹弓，锅碗瓢盆……

各种用品。

那时候我就发现有一个东西卖的最好：什么东西？

就是弹弓。

后来我就找一个朋友：什么也不卖了，只卖弹弓。结果真如我说的那样。

生意真好。
