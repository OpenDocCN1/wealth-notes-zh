# 狗不理溯源

狗不理始创于一八五八年。当时，在天津郊县有一户独家，四十岁富得孩子，为求平安取名“狗子”。“狗子”长到十四岁时，来别天津学艺，在一家蒸食铺做小伙计，由学狗子，览手巧，做事努力，练就了一手好泡儿。狗子不甘心寄人篱下，便自己便开了包子铺儿。他发明了水浴包面工艺，做出的包子口感柔软，味香不腻，包子水表如同一条线条的音褶花。他，香、味、形独具特色，吸引了十里百里的人们都赶来吃包子。生意十分兴隆，“狗子”代即顺不止说，人们都说：“狗子做的包子不理人”。就这样天天长久人们就叫他“狗不理”了。

当时直隶总督贾世凯也别吃过狗不理包子觉得好吃，随即把家入宫将包子献给慈禧太后。太后吃得钟品赞了包子尤为大似，夸赞曰：“山中无鱼亦中庸，甜地牛羊海成峰，不及狗不理包子香，食之长寿也”，从此狗不理名声大噪。
