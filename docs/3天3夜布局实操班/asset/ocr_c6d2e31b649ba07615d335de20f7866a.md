# 【卧龙营销内部资料】布局实操班

你说：是一天按摩30个客户周到，平均单价100元。 还是 一天只服务一个客户：赚3000元。轻松？

所以说：有时候，真正做高端服务的都比走数量，卖技术的要赚钱。

因为客单价高。往往都是高端客户。

消费潜力非常大。

3，卖服务的不如加盟，代理的。

为什么这么说？

在郑州有一个小伙子做的保健品公司。

我就送他一句话：“战略上卖代理比你卖多少产品都赚钱”

什么意思？

因为我发现通过他们的話术，流量思路，普通人大概一个月还能够赚1万多块钱。

我说：你这个东西既然可以复制。那么不如招募代理卖出去。

但是：如果自己招募的员工，都卖保健品能赚几个钱。

一个人帮你一个月赚1万多。除去各种开支，你净利润如果达到5000元／人的话。

那么现在有20个员工，最多一个月能赚。 20*5000=10万。

但是我们换一种玩法：我们让这20个员工，以招募代理为核心战略。

就是我们所有的朋友圈，都是代理拿货，截图，反正导向就是以招募代理为导向。

然后如果我们能招募200个代理，再通过200个直属代理继续扩大市场，招募更多代理。

当然招募代理的时候，也可以兼营卖货。

只不过我们的方向以招募代理为战略。

那么这样你的裂变指数会更加大。 如果每个代理帮你创造2000元，那么每个员工招募10个代理，就是2万净利润，再加上代理后面还有代理。

这样更容易覆盖全国市场。
