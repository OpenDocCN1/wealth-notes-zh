# 【卧龙营销内部资料】布局实操班

其中：这点我们必须跟直销模式，传销模式学习。

通过这个故事，可以看出有几个好处？

+   1、节省时间。

为什么说节省时间呢？小明本该用39小时来完成的事情，他只用了1小时就完成了，所以说他节省了时间；

在我们生活中，对于赚钱这个事情，也完全可以节省自己时间，让自己赚更多钱。首先你必须先学会劳心，而不是老力。没事多看书，少吵架，少动嘴皮子。

往往很忙的人都是穷人。

+   2、倍增利润。

为什么说他倍增利润？

小明用剩下来的38小时，他又可以做更多的事，推销更多的产品，所以他倍增了利润；

诸葛亮最大的失败莫过于，什么事情亲力亲为，从来不会倍增自己的时间，培养一批才干，让他们去犯点错，进而成长，以后可以充当一线，二线指挥。

然后自己喝茶，指点江山，就能耗死司马懿。成为最后的胜利者。

+   3、倍增生命。

为hour大家容易理解，我们把单位扩大一下，把“小时”改为“年”，小明要用39年来完成的事情，他只用了1年就完成了，所以他大大浓缩了奋斗旅程。
