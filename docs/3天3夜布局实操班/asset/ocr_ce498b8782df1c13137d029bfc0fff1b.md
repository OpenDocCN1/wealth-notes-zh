# 【卧龙营销内部资料】布局实操班

这就是什么病毒裂变的阵核。

第一步：简单讲，你需要制作一个别人很想要的东西，无论是干货，还是分享课程，或者其他，然后我们需要链接到我们这里，形成通道。

第二步：裂变条件。对于索取人，进行裂变：要求其转发到2个群领取下载地址。
或者设置一些其他要求。既然放出了好处，就让对方为此付出一点条件。要么付一点钱，要么你帮我拉2个群，要么你转发一下到朋友圈，要么你发布到群里，都可以作为裂变传播的引入源。

第三步：我们前期务必做好铺垫工作，足够数量的精准客户群。因为他们都想要这些东西，自然会自动形成转发，形成传播循环。如果铺垫基数比较小，或者不做任何铺垫，那么裂变的速度会慢一些。

简单讲，你如果弄了这样一个图片裂变，如果单纯发一个群，无疑几乎形成不了裂变的效应。你需要准备n个，几百个，甚至几千个群，同时展开一个裂变，就会形成良性裂变循环。

这就是我们前期需要做的裂变铺垫工作，不然你的裂变根本没有太大效果。当然了，你如果仔细测试，你会发现，一般50个看到了，会至少有5-3个人进行按照我们要求操作。
形成再次裂变。

总结一下图片裂变的方式：超级震撼价值，想要的好处+链接方式（微信，微信公众号，微信群）+裂变条件+精准客户群铺垫。

只要把这些方法，重复循环做，简单的事情继续做，形成裂变就会很容易。
