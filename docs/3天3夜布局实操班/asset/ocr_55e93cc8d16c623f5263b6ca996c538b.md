# 【卧龙营销内部资料】布局实操班

![](bbox=[0.15, 0.07, 0.55, 0.35])

异常强调【产品包装的重要性】——因为：包装设计至少占到产品价值的60%以上。

不管是什么产品，只要产品卖不出去，核心是产品不够美。

客户去买东西有预期心理价格，抓住这个价格把包装做到最美，即有最大的销量。

一个完整的产品至少有3个层面：

+   (1) 底层基础：取材，原物，做工，工艺，技术，科技等。

+   (2) 中层层面：功能，效果，概念，卖点，需求，娱乐等。

+   (3) 高层需求：情怀，浪漫，品味，精神，文化，感知价值，惊喜，故事，意义感，里程碑等。

底层是基础：就好比一瓶水，如果你定价很高，诉求功能，都很好。但是你口感不好喝。

即便再浪漫，再有故事。可能最后都难以有大的销量。

所以：我认为我们的基础工作一定要做好。

好比：LV能卖高价。 最基本的是质量绝对过关，极致。 其次才是功能和品牌故事。
