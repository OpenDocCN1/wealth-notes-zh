3. 获取价值

思路：

定位人群：那些人需求最大？在哪里出现？（什么样圈子，什么样机构，QQ群，论坛，学校…）

我们能不能用焦点思维写出来20个以上的方法？

很显然，只要我们去认真做这件事，一定可以。

最怕的是很多人，太TM懒了。

分析用户群：这些人想迫切解决问題？最关注什么？所有吸引，从人性讲：利益(好处)，情感（喜欢什么）。

具体怎么了解？

第一种常用方法就是：市调。 市场调查，问询，询问客户等。

第二种常用方法就是：我们自己体验一次客户，看看是什么感受，我们想要什么等。

只有这样，我们知道对方想要什么，我们才能设计出我们想要的方案不是吗？

就好比：我们去哪一块肉去钓兔子，肯定钓不到的。

白费力气。

设计诱饵：给予他们最想要的低成本小东西，看起来高价值的东西（塑造后的电子书，视频，行业报告…），或者免费服务？ 得到本东西，需要什么条件。

比如：壹玖资本的免费沙龙。 课程上故意不给你说完整怎么玩。结果，你被诱惑的睡不着觉。

想要这种效果也可以：赶紧报课。

推送诱饵：派谁去把这些诱饵传递给我们想要的人？怎么传递？（微信，文章，优惠券…）

收集流量：引导留下QQ，QQ群，微信，姓名，手机号，身份证，加入我们社群：线下活动，促销活动，QQ群，微信群…；并做一个普通的调查问卷，以便更好的跟进流量，帮助解决问题。
