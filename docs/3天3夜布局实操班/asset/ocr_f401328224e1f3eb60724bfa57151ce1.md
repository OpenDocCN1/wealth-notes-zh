第三种方法：时间（习惯）：让对方形成习惯。

比如：第一次去吃板面吃着不赖，这时候这是新客户，我们在给他2张~4张，半价卷，客户第二次，第三次，一定会先考虑我们。

当他形成习惯，就不自觉来到我们店消费了。就算旁边新开了一家牛肉汤店，他也不愿意去尝试。因为替换有点高，万一不好吃咋办。更重要的是他已经形成习惯了。

第四种方法：替换，转换成本高——绑定住对方通过一些方法

归属感（氛围）：就好比你微信现在有几百人，甚至几千人，做什么事情都是在这上面沟通，每天几乎每个15分钟我们都会看一次微信。

这就是有微信就有归属感，感觉自己还活着。

但是如果突然出来一个新的版本比如：网易，或者淘宝推出一个微信，转换成本就太高了。

因为你要重新添加那么多好友，而且很多人好友也都不玩这个，况且现在微信本来就很好用。  所以替换成本太高了。

就好比我们跟供应商，原本是在一起合作，一直合作的很好。因为对方质量还算不错。

但是这个供货商就给我连续涨了好几次价格。

我去问：其他竞品，的时候，我看他们的报价也很高。我又怕他们质量不怎么样。

因为一旦跟第一个供货商合作比较长，我们就难以再转换了，因为万一换了供应商，产品质量不行，都是麻烦。

所以虽然价格高了一点，我还是会坚持选之前的供货商。
