【布局小模板】是我们做战略工具的第一种用法。

【卧龙布局预测小模板】谋定而后动，战略上抓住趋势，战术上果断执行，提前做预测，必将大有可为。

核心一：见微知著，以小见大，知一二知全局。
核心二：人心所向，顺应人心，人性自然就顺应了规律和趋势。

（1）大量的市调，反复的市调（弥补信息量不足）

+   如： 1， 从身边朋友入手做市调，咨询
2， 从陌生人做分析。 
3， 市调报告，问卷调查
4， 从互联网大量市调，书籍上，以及其他所有能给我们一些细节信息的地方。 
5， 做数据对比，做量化，做分析。

（2）做样板抽样调查，推演，演绎，倒推反复推敲逻辑和事情的变化方向。

简单讲：一个镇的现状，在一定程度上决定全国的现状，又在一定程度上影响世界的现状。

（3）提升格局：站到世界角度的最高层，极点。根据过去曾经发生过的事情，做推算。

记住：因为历史总会经典重复性的上演。

提前做：投影，排练，倒推布局。【投影思维】；
