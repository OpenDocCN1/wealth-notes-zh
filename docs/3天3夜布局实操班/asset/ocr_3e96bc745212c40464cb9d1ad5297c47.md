# 【卧龙营销内部资料】布局实操班

![](bbox=[0.15, 0.07, 0.82, 0.32])

简单讲：我们的产品和服务。先影响另外3个人，然后由3个人，去影响9个人。

然后用9个人去影响27个人。

27个人去影响更多。逐步指数级放大。

到一定程度：我们就可以形成一个传播或者裂变分销机制。

（1）产品和服务客户体验者，就是我们最精准的招商加盟客户。

（2）让一些稍微有实力的人，在他的范围内，或者让他的影响力，去辐射更广的人。

其中要点就是：1，东西和服务足够好（内容好） 2，有意见领袖帮你做裂变

假设你有一款产品很好。但是你在努力，也传播有限，但是找几个意见领袖：1，明星 2，有粉丝基数的网红 或者其他人。

让他们帮你做一个推荐。

那么，这一下就很容易辐射更快。

直接缩短了成功的时间。

这就是裂变的一种指数级玩法。

但是往往：现实生活中很少有人有这种驱动明星的能力。

那么只能使用我们另一招了。
