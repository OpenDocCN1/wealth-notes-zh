结果：是不少外地的人都听说了这个故事，纷纷也加入种植花椒种植的项目中去。

这里只是故事的一部分，故事很长，后面的可能很多人还玩不了。我们暂时先说这个故事的4个小部分。

简单讲：

第一阶段：小东是属于自主创业种植花椒，他再怎么赚钱，都是赚的辛苦钱。很难发大财。

第二阶段：小东开始卖发财机会，通过自我包装，自我炒作，推广，结果引来更多人加入种植花椒的阵营。（这个时候，紧跟他的人，其实也能赚不少钱）

这个时候，他可以赚百万，发一些大财。

第三阶段：小东整合上下产业链，进行资源整合，上面对接批发商，市场，下面对接种植户（面临销售难题/选择项目难题），帮助更多人发财的同时，整合100~1000个人，一起干这个事。

此时战略已经转移至种植苗圃，周转销售。

第四阶段：通过政府，媒体，的合作共赢，进一步获取公信力，媒体的公信力，进行再次自我炒作，获取更大，更广泛的合作。
