# 【卧龙营销内部资料】布局实操班

方向不对，努力白费，用80%的时 间做顶层设计，战略布局非常重 要。

2、用最大的精力去做自己根本不擅长的事。

没有金刚钻，非要烂这瓷器活，结果不单单事儿没做成，还浪费了大量的时间和精力，得不偿失。

所以提高效率，避免犯错就有了相应的两点：

一、用最高效率找对方向，然后做最重要，最核心的事。

其中做战略，提前布局，这件事，花费多少时间都不为过。

二、专业的事找专业的人来做。

一件事能否成功，重在效率，效率的“率”是有用功占比，这点异常重要，值得深思。

不要瞎忙活，结果还吃了钉子……懂了就懂了……

一句话：

一定要记住：就是在每时每刻都要做最有生产力的事情。

有人就说：“老孔你说的这是鸡汤吧？”

谁不想做最有生产力的事儿那。

如果一个项目和目标，你感觉能力不足，准不够充分或者考虑还不够周全的时候

最有生产力的事情就是继续准备，继续考虑。

简单讲：就是继续做战略规划。

而不是头脑简单，向前冲，执行起来。

因为：战略做不对，努力可能大多都是浪费，白费功夫和精力。

就好比：没有军师的谋略，大将军拼光了兄弟们的命，也不见得一定能赢的战争。

但是如果你能力圈内，考虑已经充分了，准备做足了

（不管最终证明是不是准备充足或考虑充分）。
