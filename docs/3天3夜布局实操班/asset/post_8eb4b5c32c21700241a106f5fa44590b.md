可能有人会问了，有没有捷径可走？

当然是有的

什么是捷径？

举个例子：一个人年赚10万，他突然想年赚1000万。这就是捷径，很显然，不真实。

因为一个人年赚10万就意味着他只有年赚10万的能力和责任。

突然1年扩张到100倍，很显然需要满足几个必备条件。

你过去1年赚10万，然而今年把目标定到：年赚1000万。

那么必须具备什么条件？

做一个假设：（1）既然薪资增加了100倍，那么你的工作能力能不能增加100倍，只有这样你才能达到这个目标。

换句话讲：你努力工作，必须是去年的100倍。你过去每天工作10个小时，现在必须每天工作1000个小时。以同样的方式。如果假设成立。

那么还有没有其他方法？

+ (2) 当然有：你的客户数量增量，是过去每天的100倍。

+ (3) 借别人的时间：你一天24小时。能不能招募100个员工过来。借用100个人的时间，同样可以达成，而你这10小时，则是用来管理，培训好这100个人。

保持到你的轨道不偏移。

+ (4) 或者说，你必须开设100家分店才行。

（5）或者你去管理好10个合伙人，去让他们裂变100甚至1000个合伙人。也可以轻松达成。

记住一句话：任何时候，只要条件满足，结果一定呈现。

如果我们没有达成自己想要的结果，一定是你的基本条件根本没有达成。

要么就是：还是用过去的方法在做事情。

因为：用过去的方法，条件，也同样只能得到过去的结果。

# 2，卖技术的不如卖服务的

在当时那：很多老板都买不起这车，看都不敢看。

所以：很多企业家和老板，真是那个羡慕啊。那里见过这真实，课程门口停了不少豪车。

很多人就是听了这个陈安之，如何讲成功的故事。

结果都报了陈的课程。

结果陈就真的买了一辆劳斯莱斯。

所以：讲成功故事很有意思。
