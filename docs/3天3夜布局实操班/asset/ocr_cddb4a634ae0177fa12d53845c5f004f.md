# 【卧龙营销内部资料】布局实操班

这个东西就很有意思。

但是记住一点：当下用的人不多。 可能会非常有效果。但是一旦如果大家都用了这招。

基本上=失效了。

因为当大家看到这种已经成为共识：就毫无意义了。 因为东西多了，没人珍惜。

那时候，我们要换玩法。升级玩法才行。

卖点交互（折扣抽奖，让客户参与评选，投票）

![](bbox=[0.26, 0.35, 0.64, 0.62])

简单讲：我们用一个折扣抽奖与客户互动。

比如：有1折，二折，三折。 以及原价购买。

我们把原价购买的概率设置为：50%。

其他的折扣为1折，二折，或者7折。

然后很多人，就可能就很喜欢这个互动。

可能会买很多东西。

然后再去抽这个奖品。 因为不管他怎么抽奖，全价购买的概率为50%。
