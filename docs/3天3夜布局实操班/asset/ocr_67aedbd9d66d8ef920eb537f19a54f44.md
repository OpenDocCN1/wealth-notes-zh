# 【卧龙营销内部资料】布局实操班

互动产生粘性策略1：

关系运维（点赞，用户代言人，赞美，送小礼物,关系维护）

简单讲，就是我们要给客户点赞，如果客户说我们产品好，真棒。

——那么我们怎么办。

要不要给他发一个：最牛客户奖。

比如：如果我们开的是一家饭店，那么我们可不可以每个月从所有客户消费中，做一个排名。
直接搞一个：用户消费排名。

第一名我们就专门给他发一个奖：本月最牛奖。

然后我们专门给这个客户举行一个仪式，来当着所有客户的面给他发奖。

这个，是不是所有的客户都感觉很惊讶，惊喜，是不是体验，参与了这个发奖过程？

+   （1）客户本身获得了奖品。感觉受到本店极大的欢迎。他很高兴。\n（2）所有观众看到竟然还有这个服务，会不会也考虑自己上一次榜单。

或者客户会觉得这家店有创意。那么粘性会更加高。

送小礼物，惊喜，关系运维：小策略。
