# 身体模仿秀

+   1、主持人事先准备好纸条，每张纸条上分别写上1—9的数字，作为抽签条。
2、主持人请5—6位参与者上场，让他们抽签来决定表演顺序。
3、主持人按照排定的顺序，让每位参与表演者用身体将自己抽取的号码表现出来。
4、由现场观众投票选出最佳表演奖。

做这个游戏的意义是为了增强每个人肢体语言的表达能力，开发想象力和艺术的表演能力，对发现人的美姿也有帮助。

# 集体故事

+   1、主持人挑选8名语言能力较好的选手上台。
2、游戏规则：请大家一起来编一个故事，每人一次说一个词。提示：每个人都必须尽可能地选择那些有趣、新颖的词。
3、然后开始进行集体的故事创作，玩语言接力游戏。由主持人开始，选手们依次接着说，让故事顺其自然的发展。最后得出一个故事。
4、主持人讲解此游戏的寓意，如果每个人都努力使他人感觉良好，为他人圆场，你的团队会发生什么变化？要对集体的智慧有信心，相信大家正朝着一个正确的方向前进

# 【第六步骤：士气展示】

+   1、各部门检查《今日员工六大仪容仪表》：（1）发型是否整齐；（2）妆面是否到位；（3）衣裤是否干净；（4）鞋袜搭配是否合乎要求；（5）胸卡佩戴是否正确；（6）乐观的表情是否展开。
