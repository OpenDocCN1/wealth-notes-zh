# 【卧龙营销内部资料】布局实操班

第一：赞美要及时，要立刻表达并很自然地说出。

第二：赞美要恰当，要明确，要讲得很清楚，用词得当，配合适当的动作会更理想。

第三：赞美要诚恳，态度积极，伴有笑容的赞美就容易得到对方的认同。

第四：赞美要巧妙，要在公开场合承认别人的地位和价值。

第五：赞美要具体，从细节观察客人的自身优势，让对方可信。
拥抱和赞美是要让员工意识到他的价值得到别人的认同，从而受оно鼓舞并形成积极的心态。

# 【第五步：益智游戏】

玩益智游戏有助于训练人的思维模式，这时改变一个人行为模式的前提。因为员工的行为模式都是被要求出来的，如果在思维模式上能给他们一些引导和启示，有助于他们自发修正自己的言行。即使这样不能改变一个人，但至少可以影响一个人。所以只要我们每天做一些这样的益智游戏，就能影响员工的工作态度和行为。

因为刚才放松按摩后，队列已经比较混乱了，所以要重新归整好队列。主持人：“向左（或向右）看齐，向前看！稍息、立正、跨列！”队列重新整好后，主持人宣布开始晨会的开心话题的活动。

首先，主持人可讲一个笑话以活跃气氛，这样可以让员工的心情彻底放松下来，有助于提高他们思维敏捷度，为之后的游戏做一个铺垫。比如可讲这样一个故事：有一只鸟妈妈带着一只小鸟在天空中自由地飞翔，这时从它们头顶上“喀”的一声飞过一架飞机，小鸟问妈妈，“那只大鸟为什么飞得那么快啊？”鸟妈妈说：“你没看见人家屁股上点了一把火吗？如果你的屁股上也点一把火你会怎么样？”

# 添字游戏

+   1、主持人将一个“口”字写在黑板上。

+   2、游戏方法：在“口”的基础上添上两笔，形成另外一个字。每个小组为一个竞赛单位，从第一个小组开始，每次组成的字不能重复，30秒钟之内说出，如果在指定的时间内说不出或和前面队员说的重复即被淘汰。最后剩下一组为优胜组。
此项游戏的目的不是为了比出输赢，而是为了体现团队的力量，也是脑力激荡的方式。
