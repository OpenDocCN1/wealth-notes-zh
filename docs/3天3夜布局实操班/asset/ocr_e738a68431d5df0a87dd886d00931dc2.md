# 【卧龙营销内部资料】布局实操班

19、以身作则：我每天是否都在用榜样的标准来要求自己并以身作则，以此来提高自己的影响力，加强自己的领导力？

20、坚忍不拔：我是否每天都勇敢地面对工作、生活中的挑战，并不断挑战自我？

21、自我操练：我是否每天都全力以赴地进行了严格的自我操练？

22、品质：我是否清楚地了解品质的内涵？并时时检讨自己的品质？

23、真诚称赞：我是否真诚地去发现别人身上的优点，并大胆而适当地称赞别人，使别人感到开心而舒适？

24、检讨日程：我是否对自己的一天进行了仔细地检讨，并不断地修正自己的行动？

在给每个员工指出各自的问题之后，剩下的工作通报就是奖励先进，鞭策落后了。比如根据每周的业绩考核结果，奖励业绩冠军，并对最后一名给予一定的惩罚。除了门市部，其他部门的奖惩也不能少，如每周评出的最佳热情工作奖，最佳人缘奖等。相关负责人还要对这些工作突出者和落后者做一些点评，希望先进的再接再厉，落后的紧紧跟上。

在奖惩完之后，经理开始简述本月业绩目标和本月的工作重点，告诉员工月初抓什么，月中抓什么，月末抓什么，以及现在工作的进展情况，让员工对自己的工作任务有更清晰的认识并作好下一步的工作打算。

# 【第八步：强化企业文化】

企业文化是企业基业常青的根本，因此每个公司都要有自己的文化。很多时候，文化的表现形式很多时候就是把习惯形成制度，把制度形成习惯，长期坚持的结果。晨会的时间就是给员工灌输企业文化的时间，要让员工认同企业的文化，就需要让公司上下坚持一致言行，一致的信念。比如很多公司都有些固有的口号，这些口号可以在晨会上让员工齐声喊出来，由主持人提问：

我们的作风是一一，员工答：认真、快捷、诚信！

我们的愿景是一一，员工答：共享企业发展成果，人人都要有车有房！

我们的价值观是一一，员工答：爱心、责任、创新、感恩！

我们的理念是一一，员工答：真诚爱人、真诚爱己、真诚付出、真诚面对！

我们的精神是一一，员工答：
我们是天生的领导者，有困难我们会迎难而上；
