我们镇上有一个人，他在80几年-9几年，去北京打工，那个时候，他有幸遇到一个机会。

什么机会？

当时：他从北京文物以及古玩城，了解到这样一个信息，就是古玩未来一定会涨价，而且这老东西会越来越值钱。
