# 【卧龙营销内部资料】布局实操班

# 【活动】联盟营销活动

让一家幼儿园如何地堆式增长50%！我是如何让这个幼儿园报名期间成交近100万，一学制近1000万收入。

当时情况是这样：在珠海有6家不同社区幼儿园，之前每个幼儿园都能招到近90名左右小孩，现在落到55名生左右，一般情况下收费标准大概在1380元左右/月，除了去请幼师、幼儿餐费、园长、维护费用、家长回馈、其他等费用一年6个幼儿园能赚300万左右。而现在情况是招生很难，原因是附近社区多一家幼儿园，规模差不多，只不过是竞争对手设施齐全、园房成新、娱乐多、园景景色也很不错吸引家长，就是因为这个优势占据了家长心智。

当我接到这个问题在不改变园景情况下确实很辣手，后来经过市场分析与调查。

黄老板还是有很多优势与很大的资源未被利用。

+   1、黄老板有3年幼儿教育历史，有一定市场占据口碑与附近社区悠久历史，还有大量过去幼儿生家长资源（这是未利用资源）。

比如叫幼师全部去邀请过去的家长来参加“以孩子智慧成长快乐记忆”大聚会，再通过地面几轮造势推广，三年见证多少位家长，成长多少位宝贝，现在宝贝们是多么聪明、活泼伶俐、优秀（附上照片，最好找到现在班级当班长的宝贝做客户见证），某幼儿园覆盖该社区86%家庭宝贝。将在某日某社区广场三年家长见证“宝贝智慧成长快乐记忆”的大聚会约定隆重举行。

同时还可一次规模抽奖活动，赠品有健身卡，美容卡，乐斗城门票，品牌冠名衣服，抽奖学习机，免费升学名额5张，1000元购物卡赠送机会

这些赠品都是通过整合过来与附近商家冠名现场赞助。

然后在现场活动推出家长动员营销，介绍一名幼生送1000元购物卡（前端让利，后端赚钱），其实也是现在海尔全员营销，支付宝全民营销时代，从而引动几百号家长动起来。

通过这次活动后直接提升幼儿园影响力与口碑传播，还有几百号家长转介绍，所幼儿园同时不同社区广场操作就近千家长传播了。

+   2、黄老板幼儿园所都是几位年轻气质型舞蹈女幼师（这是未利用资源）。

比如可以在社区广场教大妈跳各种舞蹈，教孩子们唱英文歌，跳幼儿舞，提供免费玩具，画画赛，智力游戏与开发。
