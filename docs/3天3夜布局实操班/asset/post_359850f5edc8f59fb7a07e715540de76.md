我们现在直接进入我们【产品策划系统】的内容。

首先我们做任何项目或产品。

我们首先做的是：1，选什么产品。 这个东西，到底是不是趋势。

无非：卖产品（实体产品+虚拟商品），卖服务。

如果说：这个产品没有消费趋势，或者没有重复消费的话，我们就不要去选。

我认为一个好产品必须具备这样几点：

1，可以重复消费。

简单讲，你卖火箭，卖大炮，或者卖高尔夫球，汽车，这类短期不能重复消费的商品。

我认为：你做任何项目都会很累。

因为没有沉淀。 老客户最多消费一次。不可能说，二次，三次，1年换一次车吧。

2，轻资产

如果一个人，养猪，他养一辈子，哪怕再赚钱，他都不可能成为河南首富，最多成为养猪大户。

为什么？ 1，养猪属于重资产 2，养猪不确定性很高 3，养猪场不容易复制。

做什么可以成为首富？ 卖养猪饲料的人绝对可以成为首富，但是养猪的人最多成为养猪大户。

3，容易复制

讲一个故事：李斌和王阳两个人毕业后，李斌有一个梦想，就是将来要开一个饭店，于是李斌就去学了厨师，然后进入一家饭店打工2年后创业自己开了一家店，自从开了店，因为手艺很好，结果生意好的不得了。

但是那，他每天都再忙，真的忙不过来。

当然：李斌也非常高兴，自己的生意非常红火。

而另外一个王阳做了什么？

他那，去开了一家烧饼店，然后生意还行，就招募了很多徒弟，合伙开烧饼店。

一年之内就开了40多家店。

表面上看：李斌一年是赚了很多钱，但是王阳，因为项目可复制性很强，结果1年赚的钱比李斌还要更多。
