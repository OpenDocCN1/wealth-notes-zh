# 【卧龙营销内部资料】布局实操班

我们做任何事儿，一定要给自己一个时间概念。比如：在几月几日，几号，内必须完成。
否则自我惩罚。

但是很多人定目标：定战略就缺乏一个时间概念。

比如说：“我要赚100万”。也没有一个时间，结果十年后也毫无结果。

但是如果：你把我要赚100万定到1年-2年。

那么至少你会有一种动力感，压力感，知道自己现在当下最需要做什么。
而 isnt 糊弄自己的潜意识。

就像小时候：你妈问你，儿仔。写完作业了吗，还在玩那。

你不好意思的说：“我写完了”

然后那，结果这事儿就给忘记了。  结果去学校就被老师批评教育，打板子了。

所以：我们定战略3-5年的话，必须要有一个时间概念。

越清晰，越明确，比如：每周，每月，每季度，每年需要达到什么目标，干成什么事儿。

越详细，越有持续动力。就越容易感知，实现的可能性就非常大。

另外要提醒的是：战略是跟情报系统结合来做的。

不是说凭空就做起来的。

比如：一个人开了一家餐厅，结果一下就花费了150万。

然而那，我们经过调查发现你的目标客户基本不在乎你店铺装修如何，你却花费了150万，去装修，这是不是傻逼？
