久久鸭脖：走的是招商加盟模式。

但是久久鸭脖的利润：却没有周黑鸭利润高。

虽然久久鸭脖有1万多家店。 而周黑鸭之后几千家店。

所以：如果我们想做大，做持久，还是开直营店更靠谱一些。
