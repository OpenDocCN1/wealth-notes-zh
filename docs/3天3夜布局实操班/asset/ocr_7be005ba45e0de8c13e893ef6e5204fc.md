# 人头马 V.S.O.P 特优香槟干邑

人头马V.S.O.P特优香槟干邑，源于法国人头马的高贵血统，凭借其卓尔不群的非凡档调，带来一如既往的绝佳品质再度突破极限，成就时尚潮人们水恒不懈追寻的情调。

+   - 净含量：700ml
- 酒精含量：40%
- 包装情况：琥珀瓶，有外盒。
- 配料：纯净水、葡萄、焦糖色。
- 储藏方式：常温、避光、直立保存。
- 口感：入口醇香丰盈，伴有成熟的水果香味及甘果的清淡芬芳。
- 闻香：突出的香草气息，随之而来的烤苹果和成熟杏子味，并伴随着浓郁花香
- 酒体：液充分活跃，舌尖上停留的丝绒柔滑，酒体轻盈和润，原大感丰富。
- 饮用方式：净饮、加冰或加水，可与苏打水或苏打水调制畅饮，也可作为基酒调制成各种鸡尾酒

+   - 产地：法国
- 类别：干邑
- 色泽：悦人的琥珀色
