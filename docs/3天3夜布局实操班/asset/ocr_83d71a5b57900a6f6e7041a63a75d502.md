# 【卧龙营销内部资料】布局实操班

但孙正义不服输，硬是想出了各种办法解决这些难题。

没有好想法：

孙正义就把字典里的名词抽出来，随意组合，组合成什么就是什么，最后出现了一个“可以发声的多国语言翻译机”，这是由字典、声音合成器和计算机这三个单词组合而来的。

没有技术：

孙正义就找到本校教授、世界语音合成领域专家莫泽尔博士，经过苦苦劝说，终于把教授拉来当首席技术官。

没有钱：

孙正义就跑回日本，一家家地找公司们谈，推销着自己的想法，最后终于拿到了夏普公司的100万美元融资。

就这样，没钱没技术没资源的孙正义，就这样实现了自己“50年人身规划”的第一步——在20多岁就大赚100万美元。

是不是特别像？

其实：很多顶尖的高手都在用布局小模板。

只不过他们没有一个模板和思路罢了。

但是他们头脑里面有这样的思维方式。

只不过被我通过几年的总结给提炼出来，形成模板了。

王中军，刘一秒，俞凌雄，孙正义，蓝总，李才文，袁国顺，我接触的这些人中，我发现，他们都在用这个思维。

只不过他们只是用了1-2个步骤，或者3-5个，并没有一个可以形成系统模板的思维。

那么我们要想超额达成目标：快速达成自己的战略。目标。我认为这个布局小模板，各位一定要学好。
