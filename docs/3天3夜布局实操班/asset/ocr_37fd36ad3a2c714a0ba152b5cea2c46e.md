# 【卧龙营销内部资料】布局实操班

有些小白：就很羡慕老太。

作为布局人：你就 不应该做点什么？

机会一直存在，好不好。

看到这个除了羡慕就是羡慕，羡慕有个毛用啊。

羡慕嫉妒恨，又有毛用了。

我们应该善于分析这个实物背后的本质和逻辑。以及运营原理和思维。

其次，你应该多做这样几件资源配置的事：那么你发财就是迟早的事儿。

我敢说你有了这样一个资源配置思维：你到任何地方，见到任何人都是财富。

都是机会。

而且比普通人有更多机会。

比如：你羡慕这个老太是吧。你有没有夸奖人家，赞美人家，拍人家马屁那。

然后下一步就是：资源配置思维。

+   1， 你有没有问，这个老太，怎么和小工厂谈成合作的？

（那么我们可不可以学一点谈合作的方法。然后自己在自己家搞一个？）

或者复制到其他剩余劳动力的地方？

很显然，绝对可行。没毛病吧。各位。

+   2， 你没有打听一下，像这种小工厂那儿还有多少家？

那么这种吊篮的商业模式是啥，投资多少，赚钱吗？      我们这有没有其他合作机会？

+   3， 你有没有挖掘一下，通过老太关系，让那小工厂负责这件事的人帮你介绍其他小工厂？

+   4， 你有没有打听一下，你们周遭，能用的劳动力有多少？
