# 2，卖技术的不如卖服务的

这个什么意思？

一个人做按摩的，他给很多普通的客户，1小时的单价，最多60-300元不等。

如果他一天能工作6个小时的情况下，最多能赚1000多元。

但是现在我们的玩法变了：我们只做高端客户，做功能性的按摩。一个客户收费20万-100万/年。

比如：有很多有钱人，他们都有颈椎病，腰间盘突出等。

我们就给他先免费体验，然后做一个客户教育，优化一下流程。

只做高端客户。做服务。

过去都是一天给很多人按摩。

现在情况变了，一天就按摩2-3个，我们喝着茶就事儿给搞定了。

同样还是按摩，但只是我们把它变成设计了一种高端客户服务，而不是单纯就是玩按摩。

那么我们玩法变了，方式变了。收入并没有减少。
