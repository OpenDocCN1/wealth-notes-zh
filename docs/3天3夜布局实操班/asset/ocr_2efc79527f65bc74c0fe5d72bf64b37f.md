# 【卧龙营销内部资料】布局实操班

衡水老白干，定位——低端。

纵向定位：低端——中端——高端。 或者低中端——中高端等。

我们第一步就是：先纵向定位。

第二步就是：我们要横向分化，进行定位。

很多人说产品竞争力大，那么我们如何重新定位产品架构，挖掘市场空白点，打造一个新的蓝海市场那？

很简单，就是在大概念中找细分领域，这就是空白点。 就是我们的横向定位。

布局，是卧龙的定位。

智慧，是刘一秒的定位。

成功学，是陈安之的定位。

潜能开发，是安东尼罗宾的定位。

免费模式，是壹玖资本的定位。

没有一个好的定位和概念，再好的产品和服务都不好卖。

反过来呢，给普通的产品一个好的定位和概念，也许突然就火了。
