这样每个区域我们就可以招募一个有实力的分公司。

比如：一个代理拿货100万，你可以成为某区域代理。

好了，剩下所有的代理都是从你这里拿货。

那么这样就构建了一个完美的系统。

具体开拓市场的任务，我们只需要交给区域代理，然后让他们培训市场就可以了。
