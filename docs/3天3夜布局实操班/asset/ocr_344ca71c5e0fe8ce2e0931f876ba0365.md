# 【卧龙营销内部资料】布局实操班

布局小模板：永远以结果导向。

明确自己想要的结果（目标）

无论面对什么事，都先问自己：我做的这事与我目标有关吗？如果有关立即行动，如果无关立即屏蔽，一个人能成事就是绝对聚焦，一个人平庸普通就是因为，他将有限的精力分散到了各种与结果无关的事。

![](bbox=[0.15, 0.23, 0.61, 0.43])

之前我们分享过这样一个笑话：这个人叫郭台铭，鸿海集团总裁。他去自己工厂视察的时候，简单和厂里工程师做了一个交流。

而其中有好事者追问总裁：“为什么累死的是我，首富却是你？紧接着，凭什么……你个管孙，舅孙．不带这样欺负人的……”

他的回答震憾全场，我们之间有三个差别：

第一：30年前我创建公司，是赌上全部家当，不成功便成仁（富贵险中求）。

而你寄出履历表后就来我们公司上班，而且随时可以走人（不用承受巨大压力，责任）。

我们的差别在：创业与就业。

第二：我根据市场不断创新（差异化），到处对接资源（做核心的事情）。

这里面：我强调一下。

我希望我们每个布局人：一定要有一种空杯心态。

另外一定要誓死，2年内务必强迫自己升级，革命，革新一次。
