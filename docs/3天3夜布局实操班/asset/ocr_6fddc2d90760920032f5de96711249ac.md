# 【卧龙营销内部资料】布局实操班

李素荣（石家庄同城商圈）：
大部分人的真实写照

这是很多年轻人犯错的错。要么就是布局段位太低了。需要修炼才行。

要么不吃几次亏，改不了这个习惯。

为什么很多人，牛人：大起大落那。

就是因为他们不懂这个道理。

我那，喜欢稳，不求快，你看我做的任何决定，基本上有60%的把握。

就是因为我掌握了这些方法。

我们举一个例子：大量市调能花费你多少时间和精力？

可能一周，1个月，甚至2个月。

但是如果你盲目去搞，成功了：还好。你说我的决定真对。

但是一旦你失败了：你到底是割肉放弃那，还是继续经营？

四个字：宁缺毋滥。     宁愿2-3年市调，也不做盲目的选择。——卧龙

很多人一般现状是什么情况？

+   （1）随便搞一个生意，然后，如果生意好，会一直经营下去。

这一类是比较好的。

+   （2）盲目搞一个生意之后，发现有收入，但是不多，属于不痛不痒的状态。

比如：开一个饭店，每天有200-500的收入。但是又不敢放弃。也想生意好。

反正就这样不痛不痒，耗着呗。

中国很多商家都是如此。

结果耗着耗着，青春没了，根本没有机会去找其他机会。
