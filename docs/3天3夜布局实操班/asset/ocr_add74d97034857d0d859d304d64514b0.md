# 【卧龙营销内部资料】布局实操班

这会给当时用户有概念体验和印象留存是不是特别惊喜那。

运维策略：用户代言人。

客户每次住过的酒店，或者吃过的饭，然后让他们做一个评价和服务，或者写上自己的一句名言或者对某某人的祝福。

然后我们就贴在墙上，这样做的目的：1，给其他客户一种共鸣  2，如果客户是单身还可以留他的微信，让别人来加他。  3，客户在这上面找到了自己的价值。

虽然只是一个很小很小的互动。

比如：很多奶茶店，或者果蔬，美甲店，等。  都会写一些爱慕的话，或者对自己的评价，以及店铺的评价等。

其实给人一种感觉，也是一种触动。

至少心灵上会有不少感觉。

我们也可以让客户：写下自己的梦想。

他们的目标。或者今天的心情。

或者一些格言等。都可以。

表面上看：是一个很小的互动。  但是粘性真的还是不错的。

为什么？

1，如果你写了之后，那么你再体验产品的过程中，感觉会与其他不一样。

就有感情的因素在里面。

2，对于用户写过的东西，他可能会有一个回忆，看着自己曾经在这里做过什么，这都是慢慢的记忆啊。

有一家店我也找不到照片了。

他们怎么做的那？
