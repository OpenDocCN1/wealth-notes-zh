# 【卧龙营销内部资料】布局实操班

简单的几分钟。

主要任务不是成交，也不是介绍学校的各种情况，更不需要回答家长的各类问题。

只需要送给校家长两份“礼物”（设计诱饵）。

礼物包括两个方面：

第1份礼物，价值68元的儿童英语学习指导光盘一张，光盘里详细介绍了一些可以让孩子学好英语的方法，以及介绍了这家英语机构的独特教学理念。（只要登记一下联系方式，就可以免费领取。收集数据库，便于跟踪。）

如果光盘不方便，那么我们就送他一个在线视频vip学习会员卡。

让他们在家就能在线学习英语。

第2份礼物，送一堂价值180元的英语公开课，家长可以带着孩子，在本周六的下午2:00——4:00来免费学习，亲身体验一下，学校的师资水平，和教学方法，以及让孩子感受一下是不是喜欢这里的教学环境。

第二步：在每周五，通知所有的家长，确认明天的课程人数，并告诉家长，只要明天到场，还有礼品赠送。

第三步：公开课找出学校最优秀的老师，来展示学校的师资力量。在课程最后，报出参加培训的价格。

结果非常轻松的很多家长就给孩子报名了，简直不可思议。

我们现在一起来回顾一下，整件事情。为什么同样的学校，同样的老师，同样的产品，同样的顾客，只是换了一种方式来介绍，成家率就会提升差不多3倍呢？

下面我们解析一下人性：

现在假如你是一个家长，当你去一个培训机构，哪怕是再好的培训机构，你会不会因为别人跟你介绍的很好，就立刻报名呢？

很显然，绝对不会。

现在奸商，被骗的经历那么多，人都有很多抵触心理。（人性对任何东西都会质疑，顾虑....）

我敢说你不会这么冲动的，你一定希望多了解一些，再做决定。
