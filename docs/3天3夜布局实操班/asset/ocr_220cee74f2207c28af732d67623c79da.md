# 【卧龙营销内部资料】布局实操班

那么我们就需要偶尔花费一些功夫，来真正体验，找出问题的本质原因。

或者你躲在某个角落里，偷偷观察每个员工的举动。

上班状态，以及早会情况。 等。

找托来体验反馈数据：很简单，就是我们找一些局外人，真正体验公司，以及门店的真实情况。

毕竟有时候：下棋人，不如观棋人，看的更明白。

那么我们就需要：找一些人过来体验，观察，分析，并提出各种建议，问题。等。

通过这样几个内部市调，我们多少会发现很多地方不足。

为什么要这样做？

有一次我们给一个舞蹈公司做策划，我们方案做的很好，活动物料，活动内容，活动传单，活动方法，以及渠道，我们都给他做好了。

剩下的就是按照方案，去执行落地就可以了。

但是：我们就发现一个问题。

结果方案出来了，也执行了。但是效果一点也不好。

究其原因：我们就发现，很多员工啊，没有按照活动的内容来认真执行。

比如：发传单，他没有好好发，直接把传单给收垃圾的阿姨了。

另外那，在门店里面，本来要背诵的话术，也没有背。懒懒散散的。

本来人家买咨询，要的是一家有能量和动力的公司。

结果员工状态爱理不理的。

所以：做的再牛逼的策划，最后执行不到位。

也是白费力气。

所以：我们后来在给企业做一些策划的时候，我们就学聪明了。
