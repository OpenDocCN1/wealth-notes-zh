# 【卧龙营销内部资料】布局实操班

一句话能帮你节省10年的话：“这个世界上所有有巨大成功的人和企业，都是从一个点切入，最后获得了巨大的成就。”

——wo long

懂了就懂了……

讲一个故事：以前我做事情，也是什么都想做好，最后发现这个想做，另外一个也想做，最后2件事情什么也做不好。

其实在我们创业，找项目过程中，以及选择职业，或者学习的过程。

我希望各位一定要记住这句话：这句话悟透了，搞懂了，真正体会到了，你会发现真的能帮你节省十年的时间。

什么意思？

成功一定有一定的共性：都是从一个点切入进去的。

史玉柱也好，马云，孙正义，王健林，以及马化腾等。

每个人的成功，其实都是从一个点做好，切入到更大市场的。

记住：所有创业，千万要专业，不高盲目搞多元化，拉长战线。

所有的成功企业和成功的人都是从一个点进行切入，最后取得巨大成功的。——wo long

这个世界上有一个最大的僭遢思维就是：

+   1, 不要把鸡蛋放到一个篮子里

+   2, 木桶理论

+   3, 要多元化，不能太单一，要丰富产品线，这样才能东方不亮，西方亮。加强抗风险能力。

我认为：这点并不适合大多数盲目想要成功的人。

那么到底要不要多元化？

有些企业多元化成功了，有些过度单一死了。
