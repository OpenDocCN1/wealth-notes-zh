# 【卧龙营销内部资料】布局实操班

![](bbox=[0.15, 0.09, 0.79, 0.43])

我有一个朋友是做手机店的，过去大家充值话费，还都是到店里面。

现在都是直接微信充值，或者淘宝充值了。几乎客户没有买手机需求，一般绝对没空去手机店转转的、

对不对。
所以：这几年，他们生意就不行了。

因为没有人来。

我就给他出了一个主意：让申通快递入驻过来，免费给他们提供一个位置，然后我们再多加一项手机维修服务。

以及卖手机配件和手机贴膜，手机壳等。

当然，这些原本他就有，只不过没有维修的。

现在那，自从快递入驻：他们的人流一下就大了起 来，很多人取快递，会顺便充值，办理一些业务，咨询一些套餐，或者办理宽带，以及买一些手机配件什么的。

同样：还有一家奶粉店，我给他的绝招，也是这个：让快递入驻。
