# 【市场情报系统】

如何做项目100%成功那。

这就需要我们超级厉害的，市场情报系统。

+   （1）花费多少时间市场调研都不为过。

+   （2）花费多少时间，市调研消费者都不为过。

+   （3）花费多少时间，研究竞争对手都不为过。

+   （4）花费多少时间，研究自己都不为过。

+   （5）花费多少时间，用大数据来做战略规划都不为过。

我们只要把这5点情报工作给做好了，几乎做任何一个项目都可以成功。

第一：高手级市调     没有数量级市调=项目失败；

凭借直觉做事的都是傻逼。就算我做咨询工作那么多年了，我也不敢凭借过去的经验来做事。

所以：如果你要问我怎么做市场，我认为你第一个要做的不问我，而是做情报系统中的市调。

你问我：我肯定要花费一些时间去现场，去很多地方获取一些信息。

然后在根据市场的情况，现状，做出针对于性的方案。

毕竟：每个区域，环境，条件，资源，都不一样。对不对。
