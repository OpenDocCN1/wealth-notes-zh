# 【卧龙营销内部资料】布局实操班

所以，很多时候，当有些人吃一些东西，或者去一些美容院，或者去理发店，或者做其他什么消费。 人性喜欢依赖，很容易形成消费习惯。

所以：有时候，我们一定要培养消费者这样一个习惯。

就好比：支付宝总是培养我们扫码支付的习惯一个道理。

只要你喜欢上了扫码支付，慢慢形成习惯，依赖，基本上出门都不会带什么现金了。

我现在出门，基本都不会带任何现金。直接所有事儿，微信扫码，支付宝扫码。

# 策略3：代金卷模式

比如：我们为了培养客户的消费习惯和依赖。

那么当客户第一次来理发，或者吃饭，餐饮。那么我们就可以送他2-3张半价代金券。

让他下一次再来我们这里吃饭。

就可以形成一个短期范围内的客户回流。

目的不在于赚钱，而是在于让他形成消费习惯和依赖。

# 策略4：现在办会员，即可免单

比如：客户买了一个衣服，或者刚吃过饭。

我们直接给客户讲，你今天充值多少钱，你今天的饭钱就可以免单了。

一般来讲：只要客户吃着，体验还不错，感觉还行的话。都会去充值。

但是如果客户充值的很少。我们就应该考虑是不是我们自己的问题了。

一定要反思我们的产品是不是有什么问题。这点值得我们深思和发现这些问题。

充值的目的，同样也不是为了赚钱。 而是舍一些前端利润，去赚取长期的利润。

如果说客户来一次，基本上是没有什么感觉的。
