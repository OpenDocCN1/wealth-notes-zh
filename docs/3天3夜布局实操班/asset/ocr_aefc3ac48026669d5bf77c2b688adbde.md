# 【卧龙营销内部资料】布局实操班

我们了解的信息越多，我们的优势越大。

人与人最大的差别，同行与同行业之间最大的竞争差别，我认为就是：信息差的差别。

简单讲：人家有50元一斤的人参渠道。

但是你只能批发200元一斤的人参渠道。

你说你能竞争过人家吗？

我认识一个亿万富翁和一个百万富翁：他们做的都是一个行业。百万富翁的能力，比亿万富翁的能力还要强。

什么意思？

百万富翁：他那，专利技术多，管理能力强，核心底蕴能力绝对一流。没有人可以比到他。

但是亿万富翁就说了一句话：“我没有你有才，我没有你能力强，你知道为什么？”

我比你更有钱吗？        差别到底在哪里？

差别就是：你不善于玩信息战，情报战。

什么意思？

百万富翁里面的有部分员工，其实都是亿万富翁里面的人了，他们早就成了他们的间谍。专门为他提供各种高端技术，和高科研发产品。

所以：外面有什么第一信息，他就能第一手获得。

而这个百万富翁不行，他就只会用心钻研技术，怎么管理。

最后却相差甚远。

在我们生活中：我不知道你有没有发现有这样一类人。

他们那，虽然能力不强，技术不强，但是却玩的风水水起。

他们则善于混圈子，与各种各色的人打交道。

但是最终他们比我们要活的潇洒。为啥？

人家不干活，就是吃吃喝喝，玩玩，混混，就把事儿干成了那。
