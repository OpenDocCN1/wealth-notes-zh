+   1）百分之百对自己的时间负责；
2）百分之百遵守公司所有的规定；
3）百分之百有求必应帮助别人；
4）百分之百尽力服务好每一位顾客；
5）百分之百做一个有团队精神的员工；
6）百分之百全力以赴达成公司所设立的每一个目标；
7）百分之百相信自己所推广的产品对社会有帮助；
8）百分之百每日自我检讨，充分发挥优点，改善缺点；
9）百分之百用心做好自己的专业工作；
10）百分之百拥有行动力并立刻执行；

# 【第七步骤：工作通报】

在气势调整好之后，晨会的另一项重要的工作——工作通报就可以开始了。这时可由店长、经理或者老板做一天的工作相关事项通报和昨天成功日志的完成情况。请读本月工作重点，经理简述前日业绩，表彰优秀，发小奖品。这个环节可以增强员工信心，让员工了解整个团队的进度。

这里我提供一个记录每日工作的“时间圆饼图”，它是一个时间与绩效的管理图，记录每个小时你在做什么，看出你的工作是不是饱和的，有没有人浮于事。如果写不出来说明你缺乏绩效；如果你虚写那说明你不诚实。这样可以有效督促员工把最重要的时间花在最重要的事情上。另外，填写时尽量把所做的任何事情用数字量化，比如绩效评估量化、指标量化、时间量化、工作职责量化等。

当把每天从上午8点至下午5点的工作轨迹都详细记录下来后，员工可将“时间圆饼图”交给店长。通过圆饼图，可以看出哪些员工是认真的，哪些则没有尽力。店长在第二天的晨会上表扬绩效突出者，并发送一些小奖品。

另外为了培养员工自律自省的习惯，我制定了《二十四项检讨定义》，让员工每天从小处做起，时时处处对自己的言行进行反省和思考，提升他们的素质和修养。另一方面这也是一种管理方式，可以帮助管理者及时发现员工身上的不足，并在第二天的晨会上提醒他，这样员工自己也会慢慢领悟，晨会的效果就初步显现了。
