# 【培育成交系统】

培育：就是把流量留住。

如果说一个餐厅，一个服装店，一家企业，新客户进来了，或者使用了很多引流方法，抓取了不少客户。

客户如果消费一次，或者体验一次，第二次再也不来了。

那么你做的在对的营销方法，都会很累。

当下营销环境最需要的是：培育客户，黏住客户，让客户持续在我们这里，我们必须保证：老客户不流失，新客户不断进来，而且那，新老客户还一起帮忙介绍新客户。

那么说明我们做的很成功了。培育就做的很到位。
