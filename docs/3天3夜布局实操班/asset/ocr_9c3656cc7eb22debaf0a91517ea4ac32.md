# 【卧龙营销内部资料】布局实操班

润，也不流失。

这样一个项目就是有增长的项目
那么就可以持续撑下去。

如果说1-2年，你自己不能进步，升职，或者能力增加的职业，或者一个行业前景再稳定的项目，如果不能持续稳定增长，我们就不要考虑去做。

当然了，有些人觉得稳定也挺好的，那我也没办法。
道不同，不相为谋。

要想获得巨大的成功，一定要学会做有价值投资的事儿。

1年之内都要自我革命，革新，增长一次，或者一个季度，一个月，一周，甚至每天，每分每秒，我们都在进步。这才是永恒的法宝。

我在一个阶段，绝不会什么都不变，这样事儿我宁愿不做。
死了都要做有进步的事儿。

比如：我开工作室那会，我就说下一年一定要注册公司，然后第二年我又逼自己必须要成立分公司，第三年我就要逼自己，继续扩大规模。

只要不死，就能完成的事儿。一直在升级。

这里面野心和信念很重要。

一定要学会驾驭自己的野心。

很多人为啥做不成？

要么安于现状了，没劲头了，没野心了，要么刚开始有劲头，结果信念被现实抹杀了，一蹶不振，最后放弃了信念。

终归还是无法完成自我升级。

说起这个：我想起一家花店。
