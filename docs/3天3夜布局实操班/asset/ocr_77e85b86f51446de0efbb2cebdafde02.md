目前而言，我个人认为，做任何生意有4个阶段：

+   1， 选择一个行业，个人起步，扎实深耕经验，行业人脉阶段。

简单讲，我们刚开始是一个人干，可能是跟着别人干，也可能是自己干，对这个行业并不是很熟悉，有陌生——到初步认识——初步了解——慢慢摸索——逐步通透——创新升华自己的产品或模式。

也就是完成从0-1的过程。

第二阶段：与人合作，合伙创业，开个店，或者以个人经验，扩大生产，经营，销售，推广规模，进一步升级自己的生意模式。

此阶段也可以称之为：小打小闹，从陌生到熟悉——真正自己玩的阶段。

第三阶段：如果我们门店，小工作室，小公司做的不错，就可以考虑加盟，招商，做品牌区域销售，传授技术，或者卖授权，卖资格，卖赚钱机会，帮助有钱，没项目的人+帮助没钱，没项目，想发财的人+帮助有钱，有资源，但没项目的人……

实现进一步连锁式，加盟方式，或以技术，品牌，方式的商业模式，快速扩张，赚取加盟费，以及店铺红利，或授权股份分红等。

当然，要完成这一步定然也是有要求的。但是看我们每个人怎么去设计商业模式，怎么来运营这样的平台。
