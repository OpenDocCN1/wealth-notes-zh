# 【卧龙营销内部资料】布局实操班

就是这样的机器：跟手机店，以及火车站，还有一些人流比较大的地方进行投放，然后给他们免费提供机器，并且每个月支出一定钱给他们。

然后他讲完了收益，前景，肯定你们不相信那么厉害，对不对。

那好：然后工作人员就领着我们去线下手机店，火车站，去一些地方现场来看这个东西到底受不受欢迎，然后看下载量一个月到底能达到多少。

结果我们就去看了，火车站，一些大的营业厅，人还真不少。

结果我就有了冲动的投资的心态。

这也是为何他们能招募那么多代理一起玩这个项目的本质原因。

我贿赂的那个小孩还告诉我：有个小伙子，也是河南的，投资了100多万，不想干了，准备撤资那。

从这个故事：你们看到了什么？

加盟的核心就在这里。必须要有一個真实的样板店存在。

然后下一步就可以做全国招商。
