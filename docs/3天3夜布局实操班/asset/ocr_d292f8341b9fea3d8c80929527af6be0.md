# 【卧龙营销内部资料】布局实操班

一个月下来则要4百多，费用感觉很高。

但是成为美容院会员，则免费参加沙龙。

一年可以节省4800元，成为美容院会员则不过5，6千。所以很多人会选择成为会员。

就这样，俱乐部推荐率就上升，利用这个模式，实现了1年扩展7家直营店，利润提升10倍。

> 【营销谍言：所有营销模式都是朝这个5大板块去走，我们要做的是去填充各种策略。流量就这样被核爆。】

当你没有流量时候，觉得生意非常少的时候，老客户维护不住，新客户不进来。那么我们就从这2大方式：五大流量板块。寻找捷径。 这就是个系统。

+   1, 通过什么方法增加过剩流量？
2, 怎么让客户再次消费？
3, 怎么增加主动宣传流量？
4, …
… 共计五大版块。

就可以很快找出策略，引爆流量。

有人说：老师，线上和线下不一样啊。

其实：如果/µ你真的做营销时间长了，你会发现，其实线上线下的玩法本质上都是一样的。

只不过需要我们转换思维，去玩而已。

这点：一定要多学习我们【布局系统】思维。这里就是让你掌握本质，背后原理，和运营规律的思维。

只要掌握了本质，掌握了规律，掌握了有效的思维，其实线上，线下都不难。

最怕的是你不懂脑筋，更不去测试。

而是每天都喜欢吃现成的。

才是最可怕的。

做生意，有没有捷径那：当然有。

+   1, 抓住趋势  2, 顺应趋势  3, 找对人  4, 用对方发  5, 开花结果。
