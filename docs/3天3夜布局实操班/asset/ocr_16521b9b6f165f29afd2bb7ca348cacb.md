# 【卧龙营销内部资料】布局实操班

现在做数据库管理，最好的方法还是通过微信进行互动，贡献价值，进行培育，效果最佳。

如果是淘宝上的客户那，我们也要引导让他们加我们微信。

因为微信粘性最高。他们要么总是看到我们朋友圈，要么可能看到我们的祝福和消息。有需要就可能找我们。

而不是说：客户成交了一次，就没有第二次了。

或者说，客户来我们店里了，就走了。

比如：很多进我们店买衣服的人，是不是他可能会有买衣服的需求？

可以说当下很多服装店，一般如果有100个客户进去，肯定至少有70个没有成交，就走了。

那么基本上就很难又第二次成交的机会了。

那么这个客户：既然来我们店，真的没有需求吗？

还是说，只是当下没有需求，可能未来哪天会有需求，或者他的朋友有这个需求，或者我们卖给他其他店家的东西，赚差价等。

我敢说：只要来买衣服的人，肯定至少是有那么一些需求的。

所以：我们必须想一个办法，把客户的联系方式或者微信留下来。

比如：抽奖免单机会。 就是你不需要买任何东西，也不需要任何方式，至少抽中了，你就能免费领走一件衣服。

来店里的人，就会非常感兴趣。 条件只有一个：关注公众号，添加微信。

那么这样我们通过一个小小的抽奖活动，就获得了许多潜在客户。
