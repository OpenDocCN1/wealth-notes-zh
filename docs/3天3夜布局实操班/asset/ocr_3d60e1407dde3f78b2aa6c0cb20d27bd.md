# 【卧龙营销内部资料】布局实操班

# 预防癌症

大蒜中的硫磺化合物是消除人体内亚硝酸盐和阻断内源性亚硝酸胺的有效成分，可抑制胃癌源亚硝酸盐还质菌合成亚硝酸胺，从而降低癌症的发生率。大蒜经成熟发酵后，其所含的大蒜素生成蒜酶被释放出来，发挥其抗癌的作用。

# 减肥瘦身调理便秘

黑蒜有助于调理肠胃，促进肠胃蠕动，润肠通便，从而起到改善便秘，抑制肥胖的功效。

# 调节血糖提高免疫力

黑蒜通过进入人体血液循环改善胰腺功能，活化胰岛细胞，促进B细胞分泌胰岛素，从而增强人体糖的代谢，改善血糖能量，调节人体血糖平衡。并通过参与微循环改善人体免疫力。

# 降血脂改善动脉硬化

蒜素可减少并排出积存在血管中的脂肪，有明显的降脂作用。同时黑蒜中含有的二烯丙基二硫化物和含氨基酸可以增强纤维白溶解的活性从而起到降血脂，抗动脉硬化的作用。

# 调节睡眠缓解疲劳

黑蒜有助于促进大脑神经细胞分泌褪黑激素的物质—五羟色胺，从而起到镇定安神、促进睡眠的作用。黑蒜对血液循环的促进，对减轻肌肉酸痛和僵硬，缓解人体疲劳有一定的功效。

# 养颜美容抗衰老

氧化是衰老的最大威胁，补充抗氧化物有助于自由基的活动。黑蒜中的抗氧化物质，能够增强营养系统，保护细胞免受自由基侵害，促进新陈代谢，延缓肌肤衰老，使肌肤时刻保持青春光采。
