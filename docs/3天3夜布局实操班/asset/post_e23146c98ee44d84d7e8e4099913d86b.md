对于找到了一些同行：对于小白，我建议不适合搞原创，搞创新。

最简单的动作，就是复制。

具体指全方位，立体式的复制第一名。（我常说：我们只跟顶级高手学习！找到行业第一名-解读模式-研究模式-分化模式-复制模式-微创新模式。）

如：ZARA，七年做800亿，香港单店年营业额超过2亿，一个服装企业，没有工厂，没有设计师，到底是什么？

ZARA服装，靠复制，成为了世界第一名。

这点是不是非常值得我们学习？

其核心秘密是：复制模式

A：复制LV旗舰店大小，都是2000平

B：复制地理位置，永远在LV对面开店。

C：复制LV的设计

D：复制一线品牌的布料

料子，款式一样。省了大量设计，打版费用。价格更低。

E：复制一线品牌的营销策略

如：制造短缺，新产品只有5件，卖完错过一辈子。

唯一的差别就是：LV是手工制造，而ZARA工业流程化制造，而价格只是LV的十分之一。

复制行业第一名，在另一个定位成为行业第一名。

运用此方法：如何运用到企业中那？

A：复制行业第一名的分配政策；
B：复制行业第一名的营销策略，产品政策，定价；
C：复制行业第一名的包装，设计。如：产品包装，网站包装，宣传册等；

……

当下师为无上师，当下法为无上法。敬畏第一，才能成为第一。懂了就懂了……

有的人一辈子都不明白此道理。

当然了，我们复制了对方，一定要比对方要有差异化和不同的优秀卖点才行。

要不然就是傻逼复制了。就好比：小时候魏永奇抄我的卷子，连名字也一起抄了。

比如：ZARA模仿国际一线品牌的服装和包包。 布料和材质都是一样的。

设计也一样。

但是就是：一个手工制作，一个工业流水线。

但是价格却模了十分之一。
