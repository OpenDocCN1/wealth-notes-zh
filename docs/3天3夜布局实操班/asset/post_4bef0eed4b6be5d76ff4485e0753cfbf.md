（2）定品牌颜色。

【产品包装色彩认知】色彩所代表形象在某种事物扎根我们内心。

绿色：代表和平，稳定，和谐，健康等想象。

如：绿色食品通常绿色

结婚红色，葬礼一定是白色+黑色....

每一种色彩都有固定的形象在大脑里面。不会轻易改变。他成了我们所有认知的基礎。

所以，在包装广告，我们至少要选择互相协调的配色。不是为了限制，而是为了达到最低限度达到的目标。

从这个角度选择合适的颜色。

颜色对人的影响：

+   红色：让人积极向上；促进肾上腺素分泌；感觉温暖；增进食欲；让人感觉时间过的很快
桔色：增进食欲；使人充满活力；给人一种温柔和放松的感觉；
黄色：让人精力集中；提高记忆力；心情变的愉快；
绿色：消除疲劳；让人镇静，缓和紧张情绪；让人心情平静；
蓝色：提高专注力；降血压；促使食欲减退。

紫色：促进睡眠；提高想象力；
粉色：让人变得温柔；消除紧张感；让人看起来年轻；
白色：让人清晰的印象；让人感觉比实际重量轻；
黑色：让人感觉压抑；让人心情沉重；让人感觉比实际重量重；
灰色：有品位，让人心安；平凡严谨的印象；

举个例子，有个快餐厅，开始时候，是红色装修，结果很多人吃完，还不走。导致换台率低，而赔钱。

于是我建议，装修为白色，很快就得到改善，都是吃了就走，没有停留。

红色让人不自觉攀谈起来，而白色，则更清晰还有事情要做。

# 预防癌症

大蒜中的硫磺化合物是消除人体内亚硝酸盐和阻断内源性亚硝酸胺的有效成分，可抑制胃癌源亚硝酸盐还质菌合成亚硝酸胺，从而降低癌症的发生率。大蒜经成熟发酵后，其所含的大蒜素生成蒜酶被释放出来，发挥其抗癌的作用。

# 减肥瘦身调理便秘

黑蒜有助于调理肠胃，促进肠胃蠕动，润肠通便，从而起到改善便秘，抑制肥胖的功效。

# 调节血糖提高免疫力

黑蒜通过进入人体血液循环改善胰腺功能，活化胰岛细胞，促进B细胞分泌胰岛素，从而增强人体糖的代谢，改善血糖能量，调节人体血糖平衡。并通过参与微循环改善人体免疫力。

# 降血脂改善动脉硬化

蒜素可减少并排出积存在血管中的脂肪，有明显的降脂作用。同时黑蒜中含有的二烯丙基二硫化物和含氨基酸可以增强纤维白溶解的活性从而起到降血脂，抗动脉硬化的作用。

# 调节睡眠缓解疲劳

黑蒜有助于促进大脑神经细胞分泌褪黑激素的物质—五羟色胺，从而起到镇定安神、促进睡眠的作用。黑蒜对血液循环的促进，对减轻肌肉酸痛和僵硬，缓解人体疲劳有一定的功效。

# 养颜美容抗衰老

氧化是衰老的最大威胁，补充抗氧化物有助于自由基的活动。黑蒜中的抗氧化物质，能够增强营养系统，保护细胞免受自由基侵害，促进新陈代谢，延缓肌肤衰老，使肌肤时刻保持青春光采。

# 狗不理溯源

狗不理始创于一八五八年。当时，在天津郊县有一户独家，四十岁富得孩子，为求平安取名“狗子”。“狗子”长到十四岁时，来别天津学艺，在一家蒸食铺做小伙计，由学狗子，览手巧，做事努力，练就了一手好泡儿。狗子不甘心寄人篱下，便自己便开了包子铺儿。他发明了水浴包面工艺，做出的包子口感柔软，味香不腻，包子水表如同一条线条的音褶花。他，香、味、形独具特色，吸引了十里百里的人们都赶来吃包子。生意十分兴隆，“狗子”代即顺不止说，人们都说：“狗子做的包子不理人”。就这样天天长久人们就叫他“狗不理”了。

当时直隶总督贾世凯也别吃过狗不理包子觉得好吃，随即把家入宫将包子献给慈禧太后。太后吃得钟品赞了包子尤为大似，夸赞曰：“山中无鱼亦中庸，甜地牛羊海成峰，不及狗不理包子香，食之长寿也”，从此狗不理名声大噪。

![](img/b007b81b7b78642d97f2196ce4d77155_66_0.png)
