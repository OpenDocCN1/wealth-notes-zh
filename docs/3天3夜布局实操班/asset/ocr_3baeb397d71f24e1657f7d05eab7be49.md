然后我们就跟本地所有的五金店进行合作。 一个灯箱+一个展柜。

就这样铺设了543家门店。

基本上覆盖了本地很多五金店。

所有卖的商品：都是以批发价高一点的价格给他们五金店做利润。

剩下的我们还能自动赚钱。

这个商业模式是：我提供产品、柜子，你销货···

比如，你是卖传统瓜子干货店的，通常的模式，你就是守店卖，通过这样一个倍增设计，但现在，变成了全市分销了。

你可能这个觉得有点大？

皮带，各位应该市场上在某些衣服店门口常见，一般售价在：39元，59元，99元左右一条。这里都是这样的一种合作模式。

如果你不这样卖：你自己去卖，成本5元，你售价30元，一天最多能卖几个？

但是我们换一种玩法：给对方15元，我们还有利润10元。售价30元。

如果有50个人帮我们卖。

那么我们一天什么也没干，就是赚了500元。 如果一家店卖一条的话。

相当于打造了一台自动赚钱机器。

或者我们换一种玩法：招募50个跟我们一样的傻逼。 也一起在大街上喊着卖。

每天平均每人卖5条：50人*5条*10元=2500元

我们的利润是这样：他们一个人赚15X5=75元。 如果他们是大学生。他们也很开心啊。
