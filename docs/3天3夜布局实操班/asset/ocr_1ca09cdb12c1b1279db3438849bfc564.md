可能有人会问了，有没有捷径可走？

当然是有的

什么是捷径？

举个例子：一个人年赚10万，他突然想年赚1000万。这就是捷径，很显然，不真实。

因为一个人年赚10万就意味着他只有年赚10万的能力和责任。

突然1年扩张到100倍，很显然需要满足几个必备条件。

你过去1年赚10万，然而今年把目标定到：年赚1000万。

那么必须具备什么条件？

做一个假设：（1）既然薪资增加了100倍，那么你的工作能力能不能增加100倍，只有这样你才能达到这个目标。

换句话讲：你努力工作，必须是去年的100倍。你过去每天工作10个小时，现在必须每天工作1000个小时。以同样的方式。如果假设成立。

那么还有没有其他方法？

+   (2) 当然有：你的客户数量增量，是过去每天的100倍。

+   (3) 借别人的时间：你一天24小时。能不能招募100个员工过来。借用100个人的时间，同样可以达成，而你这10小时，则是用来管理，培训好这100个人。

保持到你的轨道不偏移。

+   (4) 或者说，你必须开设100家分店才行。
