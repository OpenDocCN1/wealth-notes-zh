# 【卧龙营销内部资料】布局实操班

所以一定要无时不刻要升级自己的认知框架，获取更多顶尖的信息，永远不要安逸现在，对自己说不可能，不如先找一些更牛逼的人学习，贴身请教，看他怎么做，绝对让你少走不少弯路，实现捷径式发展。

一句话：人性永远从不相信身边人没有人做到的事情（当然：身边人做到了，他也一定相信，他也可以）

一有人出单，立刻鼓励，奖励，全体都起立，奖励他。

然后再让这个销售，把成功故事讲一下。

这样很多没有出单的员工，新员工，会比较有信心，感觉出单距离自己并不远。

对于老员工那，咳呛，他一看，新手都出单了，他会怎样。

会不会着急？ 怕新员工赶上自己了。

同样：如果我们在线上的话。

我们就在微信群里面做一个：收款截图+恭喜某某出单，又赚1500大洋

这样一直都保持出单，是不是很多人的希望。

好了，对我们就是要打造这样一个能量场。

但是如果：你不及时保单，会有什么感觉？ 可能坐一会就没有激情和动力了。

3天不出单，又TM阳痿了。

但是我们保持每天都有单子报的话，很多人就有希望，也压力，也会从对方的分享中，总结一些自己的经验。

我们培训系统。大概的框架基本如此。

一定要记住一句话：

我们做老板的人，一定要随时随地给员工希望。

简单讲，就是看到身边的人一个一个都成功了。他也会相信自己也一定会成功。

即便没有成功案例。

我们也要包装出来，给员工希望和信心。
