# 【卧龙营销内部资料】布局实操班

后来那，我就很聪明，贿赂了他们的员工：让他们的员工给我看他们的赚钱后台。

结果我就发现了问题：虽然他们通过这样一招招募了很多市级，省级，以及区域级别的代理，大大小小有上千家商户。

基本上覆盖了全国的市场。

但是我仔细一看后台：除了上海这几台机器数据很厉害，很完美，还有一个合肥的公司做的也不错，每台机器能达到2万多收入。

每月。

但是我发现几乎90%的商户，几乎都在苟延残喘。     都是几千，几百元的收入。

幸亏我没有投资，结果去年我就听那个我贿赂的小伙子给我讲，公司倒闭了。

现在连工资都发不出来。    连续欠工资欠了快半年了。

我那，就思考一个问题：为什么他们还能招募那么多代理？

很简单，他们有样板市场：具体里面有没有猫腻暂时我不清楚。

凡是从招商网，百度竞价来的客户，他们会一一招待，然后开一个会议，讲述公司的发展前途，以及广告机的收入。一台广告机2600元，然后按照上海的华丽数据，一台机器就可以赚1万元每个月。     那么每个月净赚了5000元还多。

如果投放100台机器，那么每个月自动收入就是：50万。

100台机器才几个钱。     26万。不到一个月就收回成本了。

是不是很给力？

要不要加盟，各位。
