# 【卧龙营销内部资料】布局实操班

牌话语体系，设计了全套品牌形象、产品包装，并创意了全部产品广告，这就是“所有的事都是一件事”的华与华方法的完整展示。

葵花药业市场表现：

小葵花已成为在中国儿童药市场，从品牌影响力、到品种数量、生产能力等全面领先的儿童药专业品牌。葵花儿童药战略发展势头显著，推出了小儿肺热咳喘口服液、健儿消食口服液、小儿化痰止咳颗粒、小儿氨酚烷胺颗粒等不同类别的儿科品种，同时带动小葵花全线药品的品种销售。

目前我们的儿童药妆护理，儿童保健食品等产品也相继面向市场，未来葵花将迎来更卓越的市场表现。

华与华为葵花药业整体服务以下内容：

一、制定企业战略

先“品类”后“品种”，“品类”的本质是“品牌”，通过品类品牌解决可持续发展的问题。根据葵花药业的品种资源，华与华提出了进军儿童药品类的战略。

二、规划产品结构

产品结构是企业发展的路线图，华与华为葵花药业规划了各品类的产品结构，解决可持续发展的问题。

三、管理品牌

以“葵花”商标为背书，华与华为葵花药业创作了小葵花、葵花姐姐、葵花爷爷的家族形象，分别代表葵花药业的儿童药、妇科药和其他常用药品。

四、设计包装

包装设计的本质是为产品写剧本，做舞台。

华与华的一贯主张是尽量单一品牌，通过用直观、强烈的形象去区隔不同的品类，在包装上获得最强陈列优势。

五、创意开发新产品

产品开发的本质是给消费者提供一个购买理由，让顾客“心想事成”。

华与华从小葵花中国儿童药领先品牌 Bo 的战略入手，开发创意了符合市场需求并能够带来优势效益的产品。

六、创意拍摄了所有的电视广告

自07年开始华与华为葵花药业创意并拍摄了所有的电视广告。

七、策划了“小葵花妈妈课堂”并将之发展成为一个品牌体验平台

华与华以“小葵花妈妈课堂”为起手式，定位为“儿童用药专家”，是葵花药业全力打造的专业的儿童健康公益平台。
