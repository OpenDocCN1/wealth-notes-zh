# 【卧龙营销内部资料】布局实操班

慢慢，我们一定要形成潜意识，自动自发的去运用。

这是必不可少的一种思维模式。

不管任何目标，只要你想要，你都可以写下来。可能你现在没有这个能力，不妨也写下来。

不论你是想日赚10万，日赚100万……

生活中的任何大小事情，如果你想快速实现整合倍增，无疑这个模板，就是我们练习实操的捷径。

可以帮助你解决和实现，看似不能实现的一些目标。

# 2，必需具备的资源（列出必备的几十个条件）

你想要达到这个目标，必须具备哪些条件？一定可以列出10条以上。

比如你想年赚100万这样一个小目标。那么需要满足一些条件。

你必须有能力每个月至少赚10万

你必须有一款产品或者服务，来获得利润的来源

此项目必须具有可持续性，趋势性，稳定

或者你能找到一个帮你月赚10万元的职业经理人……

# 3，分析现有资源（有多少差距）

不管你有什么资源，你一定要罗列出来。看看距离你想要的条件还差多远。

简单讲，如果你这些条件都不满足，你想实现目标，那岂不是天方夜谈吗？

# 4，还缺少那些资源？（缺少的条件）

记住：永远都不要等到条件具备才开始，因为那一天永远不会到来。

# 5，缺少的资源在谁手里？（所缺的，都放在那里）

所谓知识，经验，能力，资源，产品……有一说一，有二说二。绝不可糊弄。

没有经验，学习经验，没有知识学习知识。
