# 【卧龙营销内部资料】布局实操班

就是因为他们掌握了最关键的就是：信息。

表面上看我们认真钻研技术，提升能力，但是人家吃喝，晚乐，与各种狐朋狗友一起玩要，最后他们比我们都要牛逼。

就是因为获得了信息差。

比如：某某人给他介绍一个项目，对接一个信息。了解一个内幕小道。

可是我们钻研，用心，能力强：获得不了这些信息。

最后往往与机会失之交臂。

线下市调：陌生拜访+体验竞品+同行业交流互动+客户调查问卷+假应聘+间谍反间。其他行业经验嫁接，业内指标(大数据分析)。

市场调研：是所有营销成功的基礎。

这里记住一句话：商业的一切竞争均是信息的竞争。

任何产品情报，消费者认知情报，以及活动，以及行业模式的玩法，无论是技术，服务，还是资本玩法，最后的竞争，都无疑取决于信息差。

信息差，就是财富差。

在古代：很多穷人家的孩子为什么永无出头之路？

就是因为在当时：穷人家的孩子是读不起书的。

只有皇帝的儿子，还有大臣的儿子，以及富豪贾商才能读起书。

因为当时的纸张非常贵。

一般更多的书籍都是在皇帝的后院。

很多大臣也没有资格，享受这些知识和信息。

包括现在：其实有很多知识，一般都是无法公布和公开分享的。

那么价格很高，一般人享受不起。

要么太过绝密，没有人愿意分享。
