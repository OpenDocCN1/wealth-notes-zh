# 【卧龙营销内部资料】布局实操班

案例：五谷养生

操作模式，就是食疗，一个柜台，展示各种五谷材料，旁边给你搭配，现磨，食物搭配图，提供解决方案：美白、肠胃、养心、便秘等等。

帮你搭配打磨成粉，你可以熬粥或泡开水吃，卖结果，很简单的一个项目，整合几个五谷食物，就变成养生项目。

然后打包弄成创业项目，招募一些妇女，进入一些渠道，超市货其他进行直接合作。形成一个市场1级倍增。

如果生意很好：就以这个店为样板店，进行全国招商。

如果生意还行，能实现部分盈利，但是表面上看生意还算凑合，那么就可以多开几家类似如次的分店。
