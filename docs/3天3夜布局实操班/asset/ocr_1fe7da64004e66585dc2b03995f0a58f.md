# 【卧龙营销内部资料】布局实操班

![](bbox=[0.15, 0.085, 0.85, 0.415])

我们知道国美电器：他们怎么做的资本运作。和类金融那？

他们那，集合了很多厂家的电器，是先卖货，在付账单。

他们卖的电器，有一个比较长的回款期。

简单讲就是：厂家给我们1万台冰箱。 先在我们店里卖，我们卖完了再给你钱。

这里面有一个资金沉淀时间。

+   - （1）他们就利用这个空闲，去大量开更多分店。\n- （2）然后开更多店，进更多货，压更多沉淀资金。\n- （3）另外还靠电器本身也有利润来源之一。

他们回款也比较慢，一点点给厂家还款。

就会出现一些什么情况？

开的店越多，拿的货越多，谈判力越强。 成本更低。回款可以延长更长时间。

开店越多，每个月的现金流，集合起来也会非常大。
