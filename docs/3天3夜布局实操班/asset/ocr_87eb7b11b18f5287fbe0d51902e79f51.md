这个圈子里的宝妈需求是什么？我们必须了解，他们喜欢什么样的阅读风格？【分析用户习惯，需求】可以看看哪些流量高的帖子。

好，根据我了解到，这些宝妈的奶水不足，想要追奶。【用户痛点】

我们就可以去网上收集关于追奶的资料。(一定要精，而且是宝妈们最需要的。)整理成一份文档【诱饵】。这样就可以去论坛发帖。

怎么发才能让宝妈迫不及待的想要这份资料呢？

当时我们软文是这么发的：

生下宝宝的17天，我就发现我的母乳完全不够宝宝喝，对于一直希望母乳喂养的我来说，如同晴天霹雳一样。一时不知道该怎么办。我就直接去了医院，医院给我拿了一些追奶的东西。吃了第一天，可是一点效果都没有。我又赶紧跑去了一个老中医那里，让我喝点中药，慢慢调养，注意心情的调节，不要太过急躁，睡眠时间一定要充足，饮食方面也要注意。

拿着中药我就回了家，平复了心情，每顿都少不了一碗鸡汤或者猪脚汤。大概过了三天，胀奶的感觉始终没有出现。眼看一罐奶粉就要喝完。我又开始慌了。突然想到我一个同学也是刚生下宝宝。怀着试一试的态度给她打去了电话。
