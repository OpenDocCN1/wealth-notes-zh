# 48.幸存者偏差思维模型

我们经常应该以不同的方式去思考问题，以此来对抗这个复杂万物的世界。因此我们将前几期基础通俗“识见通识”翻译出来，为大家提供解决问题的可视化思维工具。

幸存者偏差或幸存者谬误 (survivorship bias)，也称为生存者偏差，是一种逻辑谬误，属于选择偏差的一种。幸存者偏差指的是当取得信息的渠道，仅来自于幸存者时，此资讯可能会与实际情况存在偏差。幸存者偏差，是由优胜劣汰之后自然选择出的一個道理：未幸存者已无法发声，人们只看到经过某种筛选而产生的结果，而没有意识到筛选的过程，因此忽略了被筛选掉的关键信息。与幸存者偏差类似，数据的筛选还导致“伯克松悖论”，以及电话民调偏差等。

# 举个栗子

二战大战期间的1941年，英国伦敦比兰大学统计学家亚伯拉罕·沃尔德被美国政府征召，请求他能用在统计方法上的专业知识来解决关于“飞抵欧洲战场的如可被”，才能被瞄准飞行中的敌机。几次的分析，研究得出结论说如果是要制服飞机就要打击后机翼较为敏感的部位，并进行研究和发展。机器是每一个飞机是如何承受攻击的，而发动机的最脆弱的位置是发动机，因此美国军方指挥官认为加装装甲应该优先在这数处，可这反过来导致飞机中弹后生存率提高却忽视了被击毁的飞机，我们对这部分数据进行分析时的盲区。

沃尔德提出以下面的结论：被击毁飞机与幸存飞机的差别在于，幸存的飞机，文件中没有数据时被击毁的那架飞机的弹痕。

沃尔德理性的说中弹区域的弹痕应当平均地分布在机身各处，而如果没有被击毁的飞机中弹数量最多的区域，就是被击中时也并不太会致命的部位。

机器击中中次的部件越大型，多半只是影响飞行效能，一旦中弹，其发动机或机身的其他原件并不多影响中弹，并且一旦中弹，其生存到安全的概率的可被性就显著其高。

正是基于沃尔德的理论后来被的美国空军将其装备进行了改进，结论是这种研究的旁边也让他们在更早初期阶段专业培养具有很强的潜力。

# 启发应用

# 学“失败者”

局势或市场规律中或许存在被排除，正因如此无法归类，以为未来项目或失败者所造成的推论会被忽视。失败者会更加关注失败的原因之类的，它们也使我们对事物认识的更加合理，对我们了解失败的原因的重要工具，因此，这个对成败的因素是相对更为关键性的，是对未来的关键性的事。
