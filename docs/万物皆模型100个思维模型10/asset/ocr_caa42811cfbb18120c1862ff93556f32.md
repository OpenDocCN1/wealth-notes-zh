# 66. 路径依赖思维模型

我们需要尝试以不同的方式去思考问题，以此来突破这个瞬息万变的世界。因此我们将前期人类通过“视觉笔记”编辑出来，为大家提供解决问题的可能性思维公式。

路径依赖（Path dependence）指的是在给定条件下人们的决策选择受制于其过去的决策，即使过去的环境可能已经过时。其特定含义指人类社会中的技术演进或制度变迁均有类似于物理学中的惯性，即一旦进入某一路径（无论是“好”还是“坏”）就可能对路径产生依赖。泛指人们一旦选择了某个体制，由于规模经济、学习效应、协调效应、适应性预期、以及既得利益约束等因素的存在，会导致该体制沿着既定的方向不断得以自我强化。一旦做了选择，就好比走上了一条不归路，惯性的力量会使这一选择不断自我强化，并让你易于走不出去。

# MODEL STRUCTURE 模型结构

广义的路径依赖即“历史的影响”。在解释复杂而非线性联系时，历史因素对于决策产生重要影响，而且在变化领域，早先情况的影响经常开启并主导了后续的进程。

狭义是指路径的自我强化，即初始的选择或差异会放大，而从并不比排列引发了后续的变化，并且在随后的形式下，这一历史影响是无效的。

电视剧为什么一般都是45分钟？因为电视刚出现的时候，黑白胶片卷是按50分钟的时长设计的，每段胶片15分钟，而电视内的时长一般是15分钟的倍数，所以才会发明。短片一般都是15分钟，电影一般是45分钟，事实上一般90分钟或105分钟，但都是15分钟的倍数。更重要的是技术和大环境，当时完全不用考虑进入电视，因为电视行业的经验是从电影、发展到一个环节目就定成了这个时长固定，因此直到现在，大部分电视仍然是45分钟左右一集。

# INSPIRATION AND APPLICATION 启发应用

一切皆有能 一切皆有可能，在你探索新的工作场景，能让自己做出改变的习惯，甚至是能不断突破自我，打破旧有模式，不断地往前迈进，才能从一个特定的思维或是路径中找到新路，也才能真正实现自己与周围环境、世界相连接。

习惯就是不归路 一旦有了早期，选择就进入了一个“惯性”，惯性的力量会让自己不断在不自知的行为上，继续选择。正因为路径依赖，不少人即使有了更好的选择，也会因为已有的习惯和依赖，而无法改变现状。于是新人的去习惯，旧有模式的惯性被打破。

多问几个WHY 建议你的团队多问几个问题，为什么？为什么？为什么？我们现在做这件事？为什么？我们要怎么做？我们要从中得到什么？保持好奇心，也许能更好推动团队解决问题的能力。问问题从目标的答案，到更深层次的思考、回溯、反思，驱动团队不断创新。

总结：路径依赖思维模型即生活工作中可以去尝试新事物，尝试了或能生成新路径，从而开启新天地。
