# 61. 批判性思考思维模型

我们每项都应以不同的方式思考问题，以此来应对这个极万变的世界。因此我们将预期人类通过“视觉语言”输入出来，为大家提供解决问题的可能化思维公式。

“批判的”（critical）源于希腊文 kriticos（提问、理解某物意义和有能力分析，即“辨明或判断的能力”）和 kriteron（标准）。从语源上该词暗示发展“基于标准的有效性能力的判断”。批判性思维作为一个技能的概念可追溯到杜威的“反省性思维”：“能动、持续和缜密地思考任何信念或被假定的知识形式，揭示支持它的理由以及它所进一步指向的结论。”批判性思维指的是技能和思想态度，没有学术边界，任何涉及时力或想象的论题都可从批判性思维的视角来审视。

# MODEL STRUCTURE

# CRITICAL THINKING

批判性思维是对事实证据的理性、怀疑和不带有偏见的分析或评价，是自我导向、自我、自我监控和自我纠正的思想。

# TAKE AN EXAMPLE

批判性思维的一个重要程式“苏格拉底式方法”，或“产婆术”—苏格拉底所倡导的一种探性思维（probing questioning）。透过苏格拉底式提问（反驳提问），人们要试图弄清楚他或她的和别人的观念和思想区 分和不好的思维，能有效有区分地和准确地思考，审视他们的想法和积累。苏格拉底运用了这套技巧提出假设，和发现他们对每一个问题理解的其余深度，整体理解和体现知的冲突或与其对某个事实的理论应依据，也同时审查新的推理模型或传统概念，通过提问，揭示出以往，所讲出的话语背后所隐含的矛盾性，以寻求新的可能桥梁。

# INSPIRATION AND APPLICATION

总结：批判性思考的特征在于对想法与信息做细致的分析与评判，借由拒绝不恰当的想法，让我们更加接近真理与真相。
