# 36. 时光机理论思维模型

我们需要以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前人工智能理论“微软语言”翻译出来，为大家提供解决问题的可视化思维公式。

时光机理论是由孙正义个人正义提出，时光机是一种转移比喻，意指在同一时间内不同空间的差异以及在同一空间不同时间的差异。指充分利用不同国家和行业发展的非平衡，如果产品的 development 路径先由发达市场如欧美市场开展业务，然后等时机成熟后再进日本市场，之后进中国市场，最后进印度、东南亚等市场发展。而整个发展路径仿佛坐上时空机，穿越过去和未来，而时光机思维原指充分利用不同国家、不同行业发展中的不平衡，将先进的技术和思想带到落后的地区。

# 模型结构

多用于投资上的应用，是充分利用不同区域和行业发展的非平衡。即使是某类来操作外在投资。比如先在发达市场A发展，随后进次发 B，再次发展 C、D...

多用于个人成长方面应用，是充分利用不同阶段不同能力形成的非平衡，即随着时间推移的视角与能力在不同方向的发展向下差距的一种规律。如101010思维模型...

# 举个例子

# 孙正义的时光机

MASAYOSHI SON'S TIME MACHINE

1996一跃 从PC到INTERNET
2006二跃 从INTERNET到手机(移动互联网)
2016三跃 从手机到IOT(INTERNET OF THINGS)

每一次跃迁完成的是不同空间——同一时间与同一空间不同时间的重叠

# 横向、纵向穿越时光机用来为“当下”出主意

01. 横向穿越时光机回到过去参考，借鉴经验与知识，但时间、空间是不定时变化的，所以且不要忽视自身条件因素。
02. 纵向穿越时光机回到历史中去参考，借鉴古代先贤经验与知识，是同样，且不要忽视自身条件。

101010思维模型即从10分钟、10个月、10年后三个时间维度来审视当下的问题与决策，以此来调整心态做出正确的决策

# 启发应用

# 不同空间、同一时间思考

不同空间同一时间(同时)可以根据行业的发展现状来判断，衡量未来。比如美国的行业已经成熟，中国的行业刚刚起步等。或者不发展的行业...所以可以正确地生产，可以用时光机的思维导向，产品的开发与产品定义。

# 同一空间、不同时间思考

同一空间不同时间，比如在不同阶段去看，当下、未来、上个月、10年后...不同时间，不同阶段...等等

# 不同空间同一时间与同一空间不同时间重叠

总结:时光机思维是复盘思维，是指导我们站在不同的时间、空间，时空之间去审视当下或逆向复盘的一种思维模型。
