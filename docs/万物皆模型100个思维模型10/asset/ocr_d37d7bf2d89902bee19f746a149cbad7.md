# 51. 效率思维模型

我们希望能以不同的方式去思考问题，以便可以应对这个复杂且迅速变化的世界。因此我们将前人智慧提炼“视觉语法”绘制出来，为大家提供解决问题的可视化思维公式。

效率 (Efficiency) 是指在适当的使用原料、能源、努力、金钱及时间的情况下，进行特定事务或产出预期成果的能力。以广义的定义来说，效率是可以成功的把事情做好、且没有浪费的能力。“效率本身不是目的的，效率不是我们想要的，但效率可以让我们获得更多有价值的事物。”在经济学或科学的用语中，效率是量测输入用在预期任务或输出的程度。一般会包括最小的浪费、支出以及努力的情况下，用特定的努力来产生特定成果的能力。在不同的产业领域中，效率同样指不同的输入及输出。

做正确的事是前提，不知在思考创意思维模型时，也得益于以上模型。管理学大师彼得·德鲁克曾经在《有效的管理》中说“也许最重要的管理活动...”，“效率”即“以正确的方式做事”，而效能则是“做正确事”。效率和效能不能偏废，可这并不意味着效率和效能具有同等的重要性。我们当然希望同时提高效率和效能，但在时间和效能无法兼得时，我们首先应着眼于效能，然后再设法提高效率。”

截止目前不知创作了50多个思维模型，在与这些思维模型接触的过程中可以发现思维模型并不是孤立的，也是互相联系、洞通了矩阵感，而且它们彼此都互为层叠存在，而非相互联系、相互链接，比如面对压力，可以通过笛卡尔思维去拆解问题，可以通过矢量左右放角块等压力降低值，可以通过放大、缩小、聚焦针对问题做宽窄等等。当目标明确，调整好压力范围和区域，都可以帮助你提高效率。

# 启发应用

# 做正确的事

正确的事是指对组织的影响最直接的“正事”，正确的事情可能是可以实现的；以正确的思路进行“寻”，确保该事以正确的方式被执行，才能使资源集中，也能避免自己做错事而导致它开始从自己的事情。

# 明确目标，做好时间管理

在组织层面？学会如何提出mice模型法在组织、列出粗略步骤。小事做、安排优先、外、按照优先级在时间上进行分配、设立里程碑、检视机制、工作计划标准化，以实现管理层对项目的进展。

# 培养专注力

培养我们的专注力可以“减少PST活动”“放下杂事”，当你专注于正确的事情，减少分心，保持精力集中，突出重点，避免分心，专注于能为目标带来价值的任务，减少干扰，自觉清理干扰因素，保持心理清新，自觉保持专注力，持续在重点上投入。

> 总结:效率是以正确的方式做事，效率思维是让我们意识到怎么样以正确的方式做事，怎么样才能少投入多获得。
