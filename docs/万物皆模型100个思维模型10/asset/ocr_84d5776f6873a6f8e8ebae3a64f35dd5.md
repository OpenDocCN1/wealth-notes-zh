# 76.SWOT思维模型

我们都很应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将有一系列人通过“视觉语言”解读出来，为大家提供解决问题的可视化思维公式。

强弱危机分析(SWOT Analysis)，又称优势分析法、SWOT 分析法或道斯矩阵，是一种企业竞争态势分析方法，是市场营销的基础分析方法之一。SWOT 即基于内外都是非稳恒环境和竞争条件下的态势分析，就是将与研究对象密切相关的各种主要因素优劣势、劣势和外部的机会和威胁等，通过调查列举并依矩阵形式排列，用系统分析的方式把各种因素相互匹配起来分析，从中得出一些系列相应的结论，而讨论通常带有一定决策性。S (strengths) 是优势、W (weaknesses) 是劣势、O (opportunities) 是机会 T (threats) 是威胁。

# 举个栗子

| S 自身优势 技术领先 | W 自身劣势 传统模式 |
| O 外部机会 市场趋势 利用趋势加大深下游合作 | O 机会+劣势 利用趋势加大深下游合作 |
| T 外部威胁 竞争对垒 优势+威胁 模仿学习同行新型策略 | T 劣势+威胁 规避消除不足 |

面对互联网的冲击，很多企业都有转型临时的过程，看到了传统对转型反响良好的(T)，自立于整个业务领先的技术(S)，但是传统的运作方式效率太低，逐渐满足不上上下游的需求(W)，于是必须继续开发技术优劣，加深上下游的合作(OS)，同时要改进现有的管理模式，学习借鉴同行的信息化策略(ST)，以及同样的转型经验(WT)。从而根据适合自己的信息化模式，提高降本，满足市场上下游需求(OW)。

SWOT 分析是否满足充分是这个模型最难的地方，也是却说是你不能完全成反哑各各条件的情况，你所做的所有模型都是理想的，所以首先你必须对自己的优势与劣势有客观认识；是什么差距？是必须区分自己的现状与期望；如果要领先必须做到什么？二是你考虑全面，如果考虑全面？四是必须与竞争对手进行比较，比如成功于你的竞争对手；如果确定竞争对手的真实水平？

# 层级应用

# SWOT 的前提条件

SWOT 适合研究的是能够对企业进行调查，也必须对不同因素，本结论的多个层次，进行分析，例如组织、市场、产品、市场等。威胁确实，必须结合企业现有的资源和潜在的市场定位，这本结论是与组织、本结论的对比，但如果多数因素是在同情中在同一层次。

# SWOT 即系统思维

有了对竞争条件的认识，真正 SWOT 的分析依赖的是综合分析与归纳与分析与归纳的形式；SWOT 分析的四大矩阵结果会相互影响并根据系统结构的原则进行相互转换，这个过程会通过结构化编码确定并最终的策略。

# SWOT 的底层逻辑

SWOT 分析中，机会与威胁是外部环境，优势与劣势是内部环境，这两者会相互影响，形成策略矩阵，每个策略都是一个不同的结果。这就像一个系统，分析者可以把它们与外界的联系以及考虑具体情况，进行深入的分析。若条件成熟，也可以将同样的方法应用于其他领域。

总结:SWOT分析可以帮助我们对研究对象所处的情形进行全面、系统、准确的研究，从而根据研究结果制定相应的发展战略、计划以及对策等。
