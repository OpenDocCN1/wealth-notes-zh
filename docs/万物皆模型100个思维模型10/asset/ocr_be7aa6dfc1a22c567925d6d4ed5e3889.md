# 100.护城河理论思维模型

我们应该尝试以不同的方式思考问题，以此来应对这个万变不离其宗的世界。因此我们希望人类越过“狭隘语言”跳出为，来为大类提供准确问题的可能性思维公式。

巴菲特的护城河理论 The moat theory，护城河为人 reliant 挖掘的围绕城墙的河，古代为防守用。巴菲特在给投资者的信中常常喜欢强调“经济护城河”的重要性：“你们不要忘记经营企业如同守城应当前先考虑挖一条深沟，以便将盗贼隔离在城堡之外……我们不一定要具备杀死恶龙的本领，只要躲开它近一点就可以做得很好。”企业护城河即防止竞争对手进入市场的壁垒，以保证公司能持续创造价值。拥有护城河的公司必须能持续获得超过其资产成本的收益，并获得高于竞争对手平均水平的回报。

# 规模优势 有形资产

由于优化商业模式，不可替代的地位位置和资源，远超行业绝大多数竞争对手的规模，从而形成的独有的成本优势

# 启发应用

巴菲特提出了企业的护城河理论，这也是企业构建竞争优势的理论，例如：可口可乐的品牌权，联想对渠道的掌控等，都构成了该企业稳定的护城河，从而维持较高的利润率。而对于个人成长而言，保持开放心态，保持主动学习，保持输出突破，保持反馈，提升自己的专业度，信誉和持久成本，也会构成个人稳固的护城河。总之护城河不在于你是否是个体，就是不断地打造你的不可替代性的优势。

# 护城河对个人

护城河可以对于个人来说，最好的就是不断提升自己的专业度，成为领域内的专家，建立自己的品牌和口碑，扩大影响力。并且要不断学习新的技能，保持竞争优势。在职场中，建立自己的人脉网络，建立个人品牌，增加自己的不可替代性。

# 护城河对企业

护城河是企业的核心竞争力，它能让企业长期保持高利润率，抵御竞争对手的冲击。企业可以通过技术创新、品牌建设、规模优势、网络效应等手段，建立护城河，从而保持市场领先地位。

# 用系统的眼光关注护城河趋势

因此有护城河的企业，也会不断变化，因此要密切关注市场变化，竞争对手，技术创新等因素，及时调整战略，保持护城河的优势。

总结护城河理论帮助我们判断企业的长期竞争优势，给企业未来战略布局提供支撑点，对于打造个人护城河的关键就是构建独特的优势。
