# 52. 福格行为模型

我们希望你能以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将此前“翻译成‘视觉语言’”翻译出来，为大家提供解决问题的可视化思维公式。

福格行为模型以 BJ Fogg 命名，表明一个行为要得发生，行为者需要有进行此行为的动机和 C 作为此行为的能力，因而才能够在被触发时施行既定行为。即个个体要实现某一行为，需要有为行为的动机、完成该行为的能力、剥某激发行为的触发器三个要素，三个要素同时具备，行为者才能够跨越行动线，行为处于“触发成功”区域，才能够实现用户完成某一行为。福格行为模型可以示意为 B=MAT，其中 B 是行为（Behavior），M 是动机（Motivation），A 是能力（Ability），T 是触发（Triggers）。

# 模型结构 MODEL STRUCTURE

B=MAT SUCCEED HERE 触发有效区 行为曲线 FAIL HERE 触发无效区

生活中我们经得于是：
动机(有) x 能力(有) x 触发(有) ——而后成功

动机(无) x 能力(有) x 触发(有) ——无所谓而不动

怎么解？
提高动机（例如通过恐惧或渴望的问题）
降低难度（帮助信息和拆解步骤）

# 要素拆解 ELEMENT DISMANTLING

# 要素一：动机  动机有三个来源：P（人物）A（行动）C（情境）即PAC小人

+   - 人物 想做或获取行为的人
- 行动 采取行动获取或损失
- 情境 因环境引发的动机

动机不只是为改变或原动行为，在福格行为模型中，3要素缺失，则行为是不可能预视或不可靠的，动机最强，行动才更有成效到目标。

+   1. 找到一个你习惯的日常行为，锚定它，例如刷个牙

# 要素二：能力

+   - 人物 提升技能
- 行动 针对行动具体而微小
- 情境 获取工具和资源

# 要素三：触发

+   - 人物 通知自己
- 行动 避免重复
- 情境 提供时机
提供线索

福格行为模型中，动机和能力是持续存在的，而触发是此即触发。
人们会看到别人的行为，比如：司机自动反应，获得操作提示或提醒周期执行的事件；比如利用手机提醒，触发事件。行为信号。把行为作为日常的习惯，当提示，以此来提供或触发期望的行为，比如走到后，很多人在左办。

# 常见举例

原本计划要做的事情，但却没有为什么？
也许是你的行为可能因情况而改变，也已完全不重视。有些人有很强的动机却无行为，这叫损失行为，下行。
有时行为发生是因时间因素减少，也许你的行为是因时间原因而减少；
也有可能是因你正做其他事情而完全忘记了要做过去，例如她朋友出去散步，喝酒等。在这种情况下你的执行行为是没任何因只是少个触发点。

# 启发应用 INSPIRATION AND APPLICATION

# 想而可能也不动

当动机时，既可推动行为产生，行动将为；如果动机不足或能力不足，则行为不会发生。即缺乏能力，缺少动机，无法行动。

# 能而想也不动

无论是动机的缺失，或者能力不足，都会导致行为的缺失。即行为的触发时，正视动机不足的信号，防止产生。
当行为被触发前，行动者处于 wait 等待，忙碌，行为图被控制。这时，提升动机和能力。

# 想和能力俱备，但没有触发也不动

福格行为模型在设计产品时，用户通过日常体验，一次行为的成功会产生随后行为。
设计中，需要有动机和能力触发，触发行为。
建立行为后，信号可被强化。后续行为通过信号被触发，触发信号，行为行为的产生。
每次行动产生之后，之后的反馈。

总结：当我们理解和掌握了福格行为模型，就可以在产品设计中做出现友并具有有效性的行为设计，也可以用改变自己的行为和习惯，逆转自己的人生。
