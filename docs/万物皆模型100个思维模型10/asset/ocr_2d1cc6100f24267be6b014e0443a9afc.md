# 43.蝴蝶效应思维模型

我们思维版以不同的实务思考问题,以此应对这个复杂无常的世界,因此我们希望借助“视觉语言”翻译过来,为大家提供解决问题的可视化思维公式。

蝴蝶效应指在一个动力系统中,初始条件的微小变化,会导致不同事件发展的顺序,有显著差异。常见延伸的看法是:初始条件的微小变化,能带动整个系统长期且巨大的连锁反应。蝴蝶效应是一种混沌现象,说明了任何事物发展均存在定数与变数,事物在发展过程中其发展轨迹有规律可循。一个微小的变化能影响事物的发展,证实了事物的发展具有复杂性。延伸的“蝴蝶效应”是连锁效应的其中一种,其意思即一件表面上看来毫无关系、非常微小的事件,可能带来巨大的改变。

# 启发应用

# 建立长期主义价值观

蝴蝶效应是一个确定的现象,即蝴蝶效应带来的,会带来生活重大变化及困惑,因此长期主义价值观是非常重要的,让认识到即使例子大小小从长期来看的回影响也很大,如果把东西管理好“举措”,放的投人与自制力,放的努力与自律,甚至让慧关注。

# 拥抱不确定性

要活出最大的心态,要在系统的中部区域中与长期协同与系统协作,并把握事物动态变化的规律,还要保持开放性,做出相应的调整,更多是观察时,不要只关注局部,而看整体。并观察事物本质,不要把心态的重点放在结果上,因为不同结果都是信息释放。

# 从预测路径转向进化自我

相信生活即将能够实现与结果,我们需要意识到生活本身就是一个动态的与不断变化的过程,而且任何事情的发展都经历着一个不断变化与发展的阶段,任何事情发展都经历着一个不断地过程,建立自我意识,拥有自己的发展体系与模式。

总结:如何应对不确定性,我们可以采用曾国藩的秉烛法则,实事求是、脚踏实地的从初始条件(小事)开始做起。
