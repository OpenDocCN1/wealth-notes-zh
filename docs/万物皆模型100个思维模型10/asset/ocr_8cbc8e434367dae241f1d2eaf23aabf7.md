# 82. 反事实思维模型

我们经常希望以不同的方式思考问题，以此来应对这个瞬息万变的世界。因此我们有前人整理过“思维高手”翻出来，为大家提供解决问题的可视化思维公式。

反事实思维是心理学中的一个概念，是指人们往往会为已经发生的事情提出可能出现的不同结果和假设。这些想法包括“如果……”“和如果我当时……就不会有这样的结果”，人们在想law的事情可能有不同的结果时大脑中就会浮现这些想法，反事实思维想到的结果在现实中永远不可能发生，因为这个想法和想到的结果只与过去发生的事情有关。丹尼尔·卡内曼（Daniel Kahneman）和阿莫斯·特维斯基（Amos Tversky）于1982年开始了反事实思维的研究，他们的研究表明相对于普通的事情，人们在遇到特殊事件发生后往往更容易假设“如果……就不会……”。

# Counterfactuals 反事实思维模型公式

# IF... (虚假的前提) SO... (虚假的结论)

聚焦于如何使情况变得更好 如果比赛前能够到比赛场地进行过适应性训练的话，那么今天这场比赛就不会输

# Downward counter factual 下行反事实思维

关注的是情况没有变得更糟 幸好比赛前到比赛场地进行了适应性训练，要不然今天这场比赛肯定会输

# 举个例子

在本案例中，无论你是评判者还是当事人，都会陷入反事实思维，并激发自己的情愫。

A/B 分别乘坐去 6 点的航班，但因航班约 6 点半到，A 的航班已按时起飞，但 B 的航班延迟到 6：25 才起飞，B 眼睁睁地看着自己的飞机起飞，请问哪个人更生气？大多数人认为是 B 更生气，因为他晚到一点就能赶上飞机，而如果不是很多人都入选飞机，根据不同的解释？事件上 B 更懊恼的并不是路程花费这个重事，而是反事实：B 幸亏一点儿就赶上了，而且也失去了飞机延迟给他的弥补机会，所以恼怒：A 耽搁比较多，所以没那么愤怒。

奥运会上登上领奖台的运动员们，其中得了银牌的运动员，仿佛得了铜牌的运动员更谁，为什么？因为：得了铜牌的“反事实”是“差一点儿就拿金牌”，得了银牌的“反事实”是什么？“差一点儿就拿到了金牌”。前者是“上行反事实思维”，后者是“下行反事实思维”。奥运会铜牌得主如果想象自己可能在比赛过程中跌倒，处这种下行反事实思维就会让获得银牌的运动员获得更多的快乐，相比于上行反事实思考（想象自己拿到金牌），则会让成就感荡然无存。
