# 98. 正确非共识 思维模型

我们应当以不同的方式去思考问题，以此来应对这个复杂万变的世界。因此我们将前人智慧通过“微觉悟者”请讲出来，为大家提供解决问题的可能性思维公式。

共识指一个社会不同阶层，不同利益的人所寻求的共同认同、价值、理想。共识决策是指一种决策过程，不仅追求参与者的多数的同意，而且还解决和减少少数人的反对以达成最多同意的决策。而反共识或非共识，即不拘泥于旧的准则，不局限于共识性思维，敢于做出变通，当一个想法是正确的，且与广大大多数观点不一致时，那么这个想法就很有可能成功，所以要想获取一定的成功，你必须成为一个独立思考者，因为共识通常是错误的。
当然非共识并不是抬杠蛮干的行为，而是通过逻辑性思考，找到真正的正确的标准。

# Poggendorff illusion 波根多夫错觉

波根多夫错觉指一条直线被直线截断后，分离出的两段直线看上去在另一条线上重新连接，当人们还没所观察的视觉时，他会经常认为被截断的是直线，其实是错觉以及自己所认为的直线，而大相径庭的为另一条直线延伸而构成，但是视觉错误，造成了视觉错觉，所以要记得回到找出真相。

# 启发应用

# 批判性思维 —敢于承认我错了

批判性思维指一种对事物进行独立思考、分析和评价的能力，它强调客观、公正地审视问题，避免主观偏见和情绪影响。为了培养批判性思维，我们需要在信息收集、判断和决策过程中保持开放心态，善于接受不同观点，并愿意承认和修正自己的错误。

# 第一性原理 —追本溯源

第一性原理指通过分析、分解、归纳、总结等方法，从根本原因出发，重新审视问题，避免受传统观念和经验的束缚。第一性原理可以帮助我们理清事物的本质，突破思维定势，找到创新的解决方案。

# 全局视角 —拒绝细节陷阱

全局视角指在思考问题时，要从整体出发，考虑各个因素之间的相互关系，避免过于关注细节而忽略了大局。为了培养全局视角，我们需要学会从宏观角度审视问题，关注长远目标和整体利益，避免盲目追求短期利益。

总结：正确非共识可以帮助我们坚持独立思考、用逻辑三洽找到正确的非共识、勇敢地坚持下去。
