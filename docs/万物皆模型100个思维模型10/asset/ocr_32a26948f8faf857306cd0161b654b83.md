# 94. 蘑菇管理思维模型

我们都很习惯以不同的方式思考问题，以此来避免这个瞬息万变的世界。因此我们将前期人类借助“视觉语言”翻绘出来，为大家提供解决问题的可视化思维公式。

蘑菇管理 Mushroom Management 指在公司或组织中，管理者与员工间的沟通出现断裂。即管理者在不告知用意的情况下指派工工作的一种管理形态。蘑菇管理意味着员工的好奇心或自我表达行为并不被支持。员工常常不知道公司的整体状况，因为管理者倾向独自决定所有事项，而不去咨询其他人关于自己的决定如何。这种状况下管理者是无法理解员工的工作内容，从而导致前者无法很有效地与后者沟通。因此管理者要提早认识到这种现象并且加以预防利用。蘑菇管理一词是以蘑菇培养时的场景做隐喻：养在黑暗环境以生胞。

# 启发应用

# 成长来自真实是

我们并非希望对人们今天的工作有更多的了解，相对地要更善用真实数据来解决问题，而不是依赖经验或假设。

# 潜龙勿用不是不用

新员工刚入公司，需要先观察和学习公司的文化和体系，应用并不断改进。

# 成功者都是反人性的

管理者应保持开放并积极应对员工的反馈，而不是一味的顺从。

总结：我们此生的对手，只有我们自己，并非是你的眼中钉，客观事实是他们才是帮你成长的人。
