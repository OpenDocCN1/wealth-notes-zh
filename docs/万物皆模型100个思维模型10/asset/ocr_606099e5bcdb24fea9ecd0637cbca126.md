# 04.决策树思维模型

我们应尽可能以不同的方式思考问题，以此来应对这个瞬息万变的世界。因为我们期盼人类最终通过“微笑语言”聊出来，为大家提供解决问题的可视化思维公式。

决策树 Decision Tree，由一个决策图和可能的结果（包括资源成本和风险）组成，即一种通过图示罗列解决的有关步骤以及各步骤发生的条件与结果的一种方法，以此用来创建到达目标的规划。决策树建立并用来辅助决策，不仅可以帮助人们理解问题，还可以帮助人们解决问题。决策树是一个利用像树一样图形或决策模型 的决策支持工 具，包括随机事件结果，资源代价和实用性。 它是一个计算显示的方法。决策树经常在运筹学中使用，特别是在决策分析中，它帮助确定一个能最优达目标的策略。

SCHEME BRANCH | 方案分支
PROBABILITY BRANCH | 概率分支
ROOT NODE | 根节点   INTERNAL NODE | 内部节点   LEAF NODE | 叶节点
PRUNING | 剪枝

每个决策或事件（即自然状态）都可能引出两个或多事件，导致不同的结果，把这种决策分支画成图形像一棵树的枝干

# 举个例子

有房无房
有 → 批准放款
无 → 有无工作 → 有 → 批准放款
无 → 拒绝放款

职业选择
创业：5% 100W+ NO；20% 50W+ YES；10% -10W NO
打工：0% 100W+ NO；10% 50W+ YES；30% 10W+ NO

投资
不投 → 0
投 → 1000 → 成功概率为P → 10000；不成功概率为1-P → -1000
10000P-1000(1-P)>0，P>9%
P>9%，能接受可投，不能接受不投。

订票回家过年
不订 → 0
订 → 回家价值为A
回家概率1/3 → A；不回家概率2/3 → -700
1/3*A > 2/3*700，A > 1400
A > 1400，即回家价值大于1400元。

生活工作中我们面对复杂，不妨拿出一张决策辅助图，可以通过最后点击自我去处理事项的路径，通过方案分支、内部节点和概率分支两种结合完成从模型思考去辅助自己做决策，最后得出客观、理性、符合自身的节点，即目标 – 也会渐渐清晰明确。当然这个过程存在你无法确定的变量、概率，所以及时调整你的决策树是必要的

> 总结:决策树思维即是将会你的决策思维路径以可视化的形式展示出来，以此帮助自己做出客观理性的决策。
