# 64. 耗散结构思维模型

我们需要应该以不同方式去思考问题，以此来对这个复杂万变世界，因此我们将前几章里提通过“假设语言”阐述出来，为大家提供解决问题的可视化思维公式。

比利时学者伊利亚·普利高津在对热力学第二定律研究的基础上，提出了“耗散结构理论”。即一个远离平衡态的非线性的开放系统（不论是物理的、化学的、生物的、社会的、经济的系统）通过不断地与外界交换物质和能量，在系统内部某个参数的变化达到一定的阈值时，通过涨落，系统可能发生突变即非平衡相变，由原来的混沌无序状态转变为一种在时间、空间、功能上的有序态。这种在远离平衡的非线性区形成的新的稳定的宏观有序结构，由于需要不断与外界交换物质或能量才能维持，因此称之为“耗散结构”(dissipative structure)。

# MODEL STRUCTURE

模型结构

![](bbox=[0.07, 0.31, 0.9, 0.62])

当一个生命系统从环境中接收到能量丰富的输入，这个系统就会变得越来越活跃，这种增变运动的过程被称为“扰动”。在“分岔点”，系统会不会分裂，要么会跃进到更高、更复杂的层次，以便能够应对更大的挑战。

# TAKE AN EXAMPLE

单位黑子

![](bbox=[0.06, 0.76, 0.92, 0.9])

舒适区内固有在熟练的环境中，和熟悉的人、熟悉的事物，似乎是“平衡态”，因此需要强大外力的推动或有意突破到一个新平衡状态。比较舒适的状况，然有平静也意味着大局，但如果进入到新的、挑战性更高的状态，虽缺少舒适与安全，但是机器会如磨修理人、生物进化，挣脱束缚与远离平衡态，也是最开启对让我们踏非舒适的区域、主动走出。

居处应用

总结:耗散结构思维模型，即通过保持开放、持续做功，从无序走向有序，实现减减问题的思维模型。
