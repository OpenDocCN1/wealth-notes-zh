# 77. PDCA 思维模型

我们应该以不同的方式思考问题，以此来应对这个瞬息万变的世界。而我们却有新人警惕通过“微笑语言”预设出来，为大家更好地解决问题的可能性思维公式。

PDCA循环是美国质量管理专家沃特·阿曼德·休哈特(Walter A. Shewhart)首先提出的，由戴明采纳、宣传、获得普及，所以又称戴明环。在生活与工作中我们面对每一件事情首先是做计划，计划完成后去执行，执行过程收到反馈进行反思检查，完成这一步骤后修改原计划并行动，至此并设有终结，继续周而复始的Plan(计划)、Do(执行)、Check(检查)和Act(处理)，这个循环即PDCA循环。PDCA循环在个人成长优化、企业品牌优化、产品质量管理等领域广泛应用，目的在于确保可重复的阶段性达成，并进而促使品质持续改进。

# 模型结构

P(Plan)计划，确定方法与目标，制定活动 D(Do)执行，实施计划中各项活动，实现计划中的目标 C(Check)检查，总结合执行的结果，评估效果，找出问题 A(Action)行动，对总结得到的结果进行处理，成败经验总结并将当期结果、失败教训以及改进方法，以避免重演，未解决的问题可以延续到下一个PDCA循环

Multiple iterations of the PDCA cycle are repeated until the problem is solved.
重复 PDCA 循环的多次迭代，直到问题得到解决。

+   特点1：管理圈
PDCA可作为管理进行循环、持续、螺旋上升的动态过程，各项活动分别属于PDCA中的不同阶段，循环往复不断提高

特点2：循环体系
一个循环结束并不是终点，而是进入下一个循环的基础，PDCA循环体系从下到上呈现层层递进

特点3：螺旋上升
PDCA循环每进行一个循环，就会上升一个台阶，达到一个新的水平

特点4：统计工具
PDCA循环需要借助统计工具进行分析，如帕累托图、因果图等，帮助找到主要问题并制定改进措施

# 层发应用

PDCA 的无限性
PDCA 可运用于任何个人性中，可以循环、可以演化成为企业的核心竞争力的关键，在企业中，随着企业业务的扩展，企业可以不断地将PDCA应用于不同的业务领域，而在个人成长方面，通过PDCA循环，人们可以不断地进行自我反思和改进，从而实现个人成长和职业发展的目标。

PDCA 的有限性
PDCA 中问题的解决并非全能的，它依赖于问题的清晰定义，并且需要一定的资源和时间来完成。在实际应用中，有时会出现问题无法完全解决的情况，这时需要重新评估PDCA的适用性，并根据实际情况进行调整。

成长利器——PDCA
今天我们所追求的每一个目标，都可以通过PDCA循环来实现。通过持续地计划、执行、检查和行动，我们可以不断地提升自己的能力和素质。同时，PDCA循环也可以帮助我们更好地应对复杂多变的环境，从而实现持续的成长和发展。

> 总结:学习思维模型的目的在于提升自我认知，不可贪、不求多，每天进步一点点，就 可以打造自己的“知识复利”。
