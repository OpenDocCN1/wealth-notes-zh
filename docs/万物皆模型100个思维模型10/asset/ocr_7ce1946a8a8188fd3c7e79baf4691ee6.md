# 32.黄金圈思维模型

我们应该尝试以不同的方式思考问题，以此来应对这个瞬息万变的世界。因此我们将前人智慧通过“微说话”翻讲出来，为大家提供解决问题的可视化思维公式。

西蒙·斯涅克说：“世界上所有伟大的领导和组织，无论是苹果公司，马丁·路德·金，还是莱特兄弟，他们的思维、行动和沟通方式都与其如出一辙，而与其它所有人都不完全不同。我所做的只是将其编辑拆解，它可能是世界上最简单的观念——黄金圈思维模型。”“黄金圈法则”、“黄金圆环(GOLDEN CIRCLE)、黄金圈规则、黄金圈理论，即 WHY—HOW—WHAT 法则，在我们解决问题、做决策、与人沟通时请先说明原因，之后再说怎么做到和做什么。

# 启示参考

# 启示一：以终为始

思考问题从“为什么”开始，通过“挑战现状，挑战自我，挑战自我”，从而实现创新与发展。

# 启示二：由内向外

从“为什么”找到新目标；再研究“怎么做”；然后通过“是什么”明确结果，落地实施。

# 启示三：循环提高

从“为什么”、“怎么做”到“是什么”，不断设定新目标，完善新思路、发展新成果，循环优化、循环提高。

总论:黄金圈思维模型是一个帮助我们清事物本质，并能激发自己或他人达成且称的思维模型，凡事以终为始、由内向外、循环学习。
