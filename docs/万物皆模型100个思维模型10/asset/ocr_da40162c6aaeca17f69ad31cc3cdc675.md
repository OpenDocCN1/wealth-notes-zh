# 79. 煤气灯效应 思维模型

我们应该尝试以不同的方式去思考问题，以此来面对这个瞬息万变的世界。因此我们制作人工智能通过“微语音”薅掉出来，为大家提供解决问题的可视化思维公式。

煤气灯效应 Gaslighting 是一种心理操纵的形式，其方法是一个人或一个团体隐秘地让受害人逐渐开始怀疑自己，使其质疑自己的记忆力、感知力或判断力，其结果是导致受害者的认知失调和其他变化，例如丧失自尊，产生自我怀疑，无法施脱。因为其使用否认、误导、矛盾和错误资讯，煤气灯效应使受害者心理上不稳定化以及使受害者不再相信他／她原先的的信仰。煤气灯效应非单方面，而是双方共同打造的一种关系，往后涉及一个或一组加害者，以及第二个人(受害者)。其中一方是煤气灯操纵者，播种困惑和怀疑；另一方面是被操纵者，为了使该关系继续，不惜怀疑自己的认知。

# 举个例子

美国知名舞者与演员。最近他指出，这些舞者在广播在深夜子夜后出动，东北水中，有个人对她引发了一些意见。第一次夜训半夜里，她从房间里出来，鞋子忽然不见了，当她问起当时是否有人离开，她笑着解释说，不要多想。于是她决定离开。（她在演说时却没有）之后一朋友被她欺骗后，走了一起说事后，她在长谈后却换口味。里面说明情况，也无意自己说，很多情况是她说的，她在表达及生活里，只从之前的记忆，模糊的记忆而回忆，却将“我”官方置于她说而忘记。一共分为三阶段：

# 不自信-产生质疑 我是不是真错了？

# 辩解-为自己辩解 我没错，为什么不可以？

# 压抑-放弃辩解 我错了，对方是对的

# 启发应用

# 不要太依赖别人

不要依赖别人，因为你需要面对自己无法面对的事实。听从别人的意见，依赖别人的想法，长期的发展容易有依赖别人而完全依赖于别人的方式，容易导致。不要依赖别人，要学会自我依赖，学会独立思考，独立判断，独立人生态度。

# 从小事开始

在日常的生活中可以尝试从小的细节开始，尽量提升自己的自主性，学会在日常生活中独立解决问题，学会独立思考，学会在生活中培养自己的独立性，培养自己的批判性。

# 实事求是

在日常生活中，保持客观的态度，了解自己的定位，理解自己的不足之处，同时也要承认别人的优点，尊重他人的选择。

总结我们学习思维模型的目的之一在于帮助我们看清这个世界的本质，并非易事，次则是看清自己及自己所需，看懂人性及人性的弱点，避免。
