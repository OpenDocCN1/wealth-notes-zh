# 84. 鸟笼效应 思维模型

我们是应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前人整理通过“貌似诗歌”翻出出来，为大家提供解决问题的可视化思维公式。

鸟笼效应 (Birdcage Effect), 又称“鸟笼逻辑”，是人类难以以脱离的十大心理效应之一，其发现者是近代杰出的心理学家、美国心理学之父威廉·詹姆斯。鸟笼效应是一个很有趣的规律，人会在于获得一件物品后，会继续添加更多与之相关而自己不需要的东西。经济学家解释此效应即是由于人们只知道为自己比解决为什么只有一个鸟笼变得重要便得满足，却没有任何人来，或者不需要加以解释。鸟笼效应，也会造成人的一种心理压力，使其为了去买来一只鸟与笼相匹配，生活当中，鸟笼可能是双鞋、一张精致的书桌、一个忌讳举例，道德层面上鸟笼可能是贷款上的一件商品、一张优惠券、一份有较大礼包的卡，万事万物，有形的无形的，物质的精神的，仅仅都可以在当前所谓的“鸟笼”，那么为什么人们会因为一个普通的物品，自觉不自觉地增加更多并不需要的东西？答案很简单，那就是人的贪婪心理需求。

# 模型结构

# Birdcage Effect

自动化思维 太在意他人 → 不舍得扔掉 束缚于鸟笼 → 不舍得扔掉 那就去填充 → 不舍得扔掉 持续的填充 +n

# 举个例子

攀比炫耀心

追求完美心

求心理价值最大化

比如因为不想被人说买不起房子，在买了一房子后因恼带有车库，于是又买了一辆车，这是攀比和炫耀的心态；因为买了一个全自动马桶而配齐了卫生间装修一遍，这就是追求完美的心理；因为爱唤来了大家心里额外一笔的期望和不自愿的目标，去取买一只鸟，这是追求心理价值最大化。鸟笼的存在会触发人类心理活动，如果说，求爱，求买，求价值的心理，正是由于心理需求的存在导致了添加更多自己并不需要的东西，即是产生像多米诺骨牌一样的连锁反应。

鸟笼效应无处不在，比如小时侯买方便面就要水饺，比如果现今的游戏产业更是如此，揣据统计公布，2022年第三季度收入就高达 429 亿人民币，而收取收入的一部分正是利用的玩家的“鸟笼效应”心理。比如何如我们熟知的和平精英，王者荣耀等等，都是通过让你首先可以免费获取一个整体的部分，而这一些部分恰好就是一个鸟笼剩下，相当诱惑大部分人都会选择继续买装备这一些部分继续游戏下去。商品促销、优惠政策等等都都。包括我们之前讲过的一项损失规避思维模型。

# 启发应用

# 反思自己 突破黑箱

需要培养我们对所拥有的一瞥而后知，绕过偏见做实际的反应；增加自我认知，思考你是否真的需要这些东西，面对压力保持冷静，才能像鸟笼，究竟是喜欢还是迫使。把大单一的体系拆解，延伸思考和判断。人的自我约束心里自我成长的决定，该如何去发展，怎样把人从鸟笼中解放出来。

# 实事求是 勇于追逐

树立正确的价值观和消费观，人会因现实环境和需求而改变。坚持做正确的事，需要不断审视自己的需求，而不是盲目的跟从。市场对我们依赖而形成一种惯性，很容易使人迷失自我。认识到鸟笼效应的存在，我们要理性消费，有计划的消费，而不是以满足心理需求为目的。

# 全局视角 打开视野

P&G 全局视角通过识别问题，才能破解鸟笼效应？我们自己在思考、分析问题时不能只盯着局部而不能全局。一定要有长远眼光，视野开阔。我们通常会因鸟笼效应而陷入固定的思维模式，从而局限于局部问题，解决问题时要考虑更大范围的可能性和多变性，多思考，迂回而不局限，学会打破局限，真正提升决策力。

总结:鸟笼效应是一个揭露人性以及能够帮助你看到一般规律的模型，对于自己可以结合机会成本思维做出适合你的决策与选择。
