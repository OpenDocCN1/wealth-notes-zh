# 20.卡尼曼双系统理论

我们应该尝试以不同的方式思考问题，以此来适应这个多变万象的世界。因为我们前面人智睿通过“貌似语言”推出出来，为大家提供解决问题的可能化思维公式。

大脑有无法克服的结构性缺陷，你可以理解为进化的副产物。大脑的目标是求存而非求知，对于外界的环境。符合最小作用力原理，能不动脑筋不动脑。卡尼曼双系统思维模型重点讲述人们的大脑如何在直觉和理性之间进行选择，如何做出判断，如何充分利用与智力无关的理性进行重大的选择。如果了解我们的大脑，并合理的使用，才能更好的帮助我们在面对问题时更好的做出选择。

# 基本结构 THE 2 SYSTEMS

# 系统1—快思考 System 1-Fast Thinking

# 系统2—慢思考 System 2-Slow Thinking

# 结构剖析

# 快 System 1-Fast Thinking

# System 2-Slow Thinking 慢

系统1 (默认模式) 直觉本能 百分之95

+   - 持续扫描我们的环境
- 速度快但较容易出错
- 通过快捷键轻松工作

系统1的运行是无意识且快速的，不怎么费脑力，没有戒心，完全处于自主控制状态。

+   - 懒惰的
- 缓慢的
- 演绎的
- 基于规则非经验
- 不容易出错
- 耗费资源的
- 辩证不济的
- 深度熟虑的
- 理性推理的
- 逻辑的
- 结构化

系统2 (备用模式) 理性思考 百分之5

+   - 用于特定问题 仅在必要时使用
- 需要努力分析推理 解决复杂问题锻炼自我控制
- 速度慢但很可靠

系统2 将注意力和转移到需要费力的脑活动上来，例如复杂的计算。系统2的行动遵循与行为、逻辑和专注等主要属性很相关。

02 旁观者纠正系统1的快思考
03 系统1反应快但不耐久，有意中断，回归理性
