# 49. 冰山理论思维模型

我们应该以不同的方式思考问题，以此来应对这个瞬息万变的世界，因此我希望将《智慧通》翻译出来，为大家提供解决问题的可视化思维工具。

冰山理论是萨提亚家庭治疗中的重要理论，泛指一个人的“自我”就像一座冰山一样，我们能看到的只是表面很小的一部分——行为（如现象等），而更大一部分的内在世界却隐藏在更深层次，不为人所见，恰如冰山。而隐藏在水面之下的更大的山体（自上而下依次包括行为、应对方式、感受、观点、期待、渴望、自我七个层次），则是长期压抑并被我们忽略的“内在”。揭开冰山的秘密，我们会看到生命中的渴望、期待、观点和感受，从而看到真正的自我。

# 举个例子

# 冰山理论了解自我的基本应用方法

依次画出7个格子并写下根源问题，如下图一样先走第一步（个人行为），清洗目前的问题根源，再走第二步（成因），以及为什么是这样的问题，步调并非固化，最后走第七步“自我”。这个过程精妙之处是能让人了解到问题产生的根源，然后根据自己到底是遵循符合你自身的决策与选择。

# 冰山理论下的师生冲突

病例分析：C学生被B学生推着走，老师A好拥着B甚至A、B让门口堵住，B看不到方向导致发生冲突，老师B将自己在冰山上和老师自己的冰山：行动为A拒绝之，拒绝造成情绪上的调整，如愤怒、冷静？老师B：行动... 当学生在... ...

当师生面对两座“冰山”即景时很难沟通清楚，缓和下冲突，两座“冰山”即内容相对稀少、无...无论是愤怒的学生，都期待自己成为有能力、有价值的人，渴望被认可、被接受。此为人类共通的生存需求。
