# 87.归因理论思维模型

我们应意识到不同的方式是思考问题，以此来应对这个变化无常的世界。因此我们将前人智慧通过“微语言”提炼出来，为大家提供解决问题的可量化思维公式。

归因理论 Attribution theory– 社会心理学的理论之一，归因是指观察者从他人的行为推演出行为的原因，因果关系。归因理论是指研究人们如何做出归因，以及为何在某情况做出某种归因，在另一情况做出另一种归因的理论并说明和分析人们活动因果关系的理论。人们用它来解释、控制和预测相关的环境，以及随着环境而出现的行为，因而也称“认知理论”即通过改变人们的自我感觉、自我认识来改变和调整人们的行为为存在的模型。归因理论的假设是建立在个人随时重建认知平衡的欲望之上。主张当个人发生言行秩序紊乱时，会主动运用存在心理中认知为自己找出原因，或为别人找理由。

# SITUATIONAL ATTRIBUTION 情境归因 外因–将行为发生解为情境（环境）因素使然

# DISPOSITIONAL ATTRIBUTION 性格归因 内因–指个体行为之发生解释为自己性格使然

# 共变模式（三维归因理论）

# 共识性 CONSENSUS 不同人在面对相同刺激，行为反应是否与观察对象的行为一样？

# 特殊性或区分性 DISTINCTIVENESS 观察对象是否对类似的刺激都做出不同的反应？

# 一贯性或一致性 CONSISTENCY 在不同时间点、不同情境中，同一行为人面对同一刺激的反应是否相同？

# 举个例子

比如你看到一间餐厅的老板（行为人，观察对象）在骂员工（刺激），你会认为老板是否常有（内归因）？行为人的思维，如面对此刺激时特别对你如何？或同今天不同不（不同于）？还是其它员工有问题（或因同因同）？行为人本身外因？如车手茶？或行为本身？还是由于某个因素的其他地方因素想到（外归因），并且本次见到刺激未关联到其他？

家庭有孩子的伙伴们，你是否会考虑成绩来归因孩子学习呢？考试成绩是一个很好的归因对象，尽管孩子有了成绩，家长或老师对孩子自己的表现可能能够尽可以归因到自己的努力和勤奋程度，而当孩子不是自己的表现，家长或许会归因于外部条件，如老师或孩子可能归咎为归因于考试难度、教学的水平、标准或外部因素，担心归因于是学生本身努力不足。即使成绩为内归因，即归功于自己，于内部因素，才失败归因于外部因素，以保护自尊心。

从共变（三维归因）<|start|>解：
第一、共识性一大家都骂其员工
特殊性-老板不是常骂其他员工
一贯性-老板常骂其员工

第二、共识性低-仅老板骂其员工
特殊性-老板也会骂其他员工
一贯性低-老板常骂其他员工

第三、假设性一无固定性或肯定性较高或低，人们倾向与做不利于别人的归因，例如假如回家看见一对、老板如何随便等等。

先条件：观察到一新事件在特定情况下能确定或假设；
充分条件是：若如果这个假设在其他情况下也能出现，通过比较能更推断是否发生减少发生。

共变模式理论告诉我们：每个人都需要稍微归因（或承担充分、必要条件的证据在认识上，解释身旁的事物。
