# 45. 上帝视角 思维模型

我们建议您应该以不同的方式思考问题，以此来应对这个瞬息万变的世界。因此我们将前几期“视觉语言”翻译出来，为大家提供解决问题的可视化思维公关。

上帝视角思维就是让人摆脱处身“局”中又或“从自己出发的视角”所产生的对外界认识的局限性，目的在于让我们跳出主观思维，以一种高维的、客观的、理性的动态视角去看问题，即实事求是的看待问题，从而洞察事物的本质，做出合理的决策。上帝视角并不是简单的俯视或者旁观，而是包含时间、空间的动态的视角。例如，我们看一块石头落地，似乎只看到石头落地，而伽利略看到的则是石头与大地都随着地球自转的方向向东移动了一段距离。

# 举个例子

# 透过现象看事物的本质

伯乐教人马，A 指着一匹马说：“这匹马善跑人”。伯乐听后前来看了看，然后从后面掀起那马的屁股，而那匹马却知不踹人，A 看甚惊讶不解，便问：“你说这匹马善跑，这匹马是爱踢人的马，可是它被你掀了屁股，踢人的马都是那样后脚提起重来；你甚至能顾掀着马，无落地支撑全身的重量。所以后腿举不起来，你看于认识骗人的马，却不善于观察别的膝盖。

# 模型思维即是

上帝视角思维可以帮助我们去解决生活与工作中的沟通问题，当你在说或一个观点的时候，当你处在你所表达出来的观点之下的时候，从自己出发的角度，即主观视角下的表达，如此你你看到的是“6”，而对方看到的是“9”。这样的沟通不仅仅引发双方的冲突，社会还会完全无法沟通。上帝视角就是当你将自己跳出主观去看这个问题时，你会发现，此问题是“6”没错，是“9”也没错。
