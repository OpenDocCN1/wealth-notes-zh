# 22.三层解释思维模型

我们都应以不同的方式去思考问题，以此来对应这个瞬息万变的世界。因此我们将前人整理透过“感觉语言”筛出出来，为大家提供解决问题的可视化思维公式。

批判性思维的过程可以分为三个层次或水平：体验、解释和解析。但要记住，这种分类是人为的，只是为了重点突出批判性思维的过程。尽管分析处在思维过程的最高点，但三层模型是循环往复、不断变化的，有时人们为了进一步确认会从分析水平返回到经验水平，也会根据对新信息的分析重新修正原来的解释。人们决不会只有单纯的经验或分析。

# 结构拆解

# 经验层 EXPERIENCE

+   - 直接经验
经验层是一个思维过程，我们只描述自己观察到的事物，而不是它可能是什么。
- 间接经验

# 举例子

+   01 在工作面谈中，我被拒绝了。
02 当我表演开始时，马虎为我开门。
03 在美国，克美人是合法进行。
04 尽管黑人仅占美国人口的12.9%，但却占据因数量的45%。
05 在2004年的总统选举中，只有58.4%有资格的美国选民进行了投票，比例在18-25岁的年纪人中甚至更低，仅为41.9%。

# 解释层 INTERPRETATION

+   - 依据事实
解释层是第三个思维阶段，解释需要依据我们对事实的了解和它们是什么。
- 偏离事实

# 举例子

+   01 我没有获得这份工作是因为我没有熟人。
02 马克是一个大男子主义者，他认为女性太弱小，自己开门合适。
03 如果克美人认为这是违法的话，那也许是确定的不是道德。
04 人们在印度中古继承地方的比例是因为黑人男性天生比白人男性更暴力。
05 美国年轻人在选举中不投票是因為他们對政治不感興趣

# 分析层 ANALYSIS

分析层

+   - 审视自己
分析层是第三个思维阶段，主要功能是审视自己与他人之间的解释。
- 审视他人

# 举例子

+   01 我没有得到这份工作，是因为我没有熟人，面试技能不足，还是没有达到这份工作所需要的条件？
02 马克为我开门？目的是否在帮助？
03 为什么克美人看起来违法？是否存在某些情况，克美人也许可以被宽容？
04 有没有证据表明黑人男性被拘留向更强？有没有可能是因为黑人男性比白人男性受到的歧视更多？有没有其他因素能够解释…男人因在印度中古继承地方？
05 为什么越来越多的美国人，尤其是年轻的美国人，不参加投票选举。联邦政府的选举票是不是应该该有的国家那样实施强制措施？会不会是感染的原因？

# 抗拒

由于我们大多数人都需要证明自己是正确的，因此我们都要遵从一种模式来接收自己的“客观事实”和接受它，并把它推销给别人，它的实质为“适用的 becomes 防御机制，这种机制过激化、冲动，避免不明确和加深分歧”。

# 总结:该模型一个非常重要的点在于三层模型的循环往复和不断变化，任何模型都是如此，并非固定不变，切记。
