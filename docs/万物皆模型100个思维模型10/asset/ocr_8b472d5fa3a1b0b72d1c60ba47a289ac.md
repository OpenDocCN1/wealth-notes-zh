# 28.破界思维模型

我们应该尝试以不同方式思考问题，以此来应对这个瞬息万变的世界。因此我们请前人智慧通过“破规律”翻译出来，为大家提供解决问题的可能性思维公式。

古名词“田边沽之界”，界限即为物理层面的一种划分标准，那么在精神层面同样可以用“界”来划分。可以是能力 Barca、价值边界或者是原有、固有的认知边界。破界思维模型指的是跳出原有的认知系统或能力 Barca，突破时间、空间的局限性，从一个全新的视角来思考问题、探寻自我，提升自我的思维模型。

# 应用：两反一突

反思
反思是任何的前提和基础，没有主动的反思意识的存在，就不上升，而主要反思的意义是，一旦被觉醒，才能驱程界的开者。

突破
突破是思维的一个目的和最好，接下来需要依据目标进行提炼和与实践，如果在驾驶时中需要一条长采集来参照随时参照方向的方法。

反思
实现目标的手段试，没有进一步地定位表现，则把它变得大方面的问题，换成更简单的目标，根据反馈回来的信息重新修改自己的方向。

> 总结破界意识是自己给自己画的地改变牢，人們习惯于此，处于边界内是安全的，如井底之蛙、三芝之鸟，破的前则是主动觉醒。
