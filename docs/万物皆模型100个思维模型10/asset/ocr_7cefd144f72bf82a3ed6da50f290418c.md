# 07.易得性偏差思维模型

我们应该尝试以不同的方式去思考问题，以此来应对这个瞬息万变的世界。借此我们将前人工智能通过“致胜密码”翻讲出来，为大家提供解决问题的可视化思维公式。

可得性偏差（Availability Bias / Heuristic）也被称为易得性偏差或易得性偏见，人们在不确定性的情形下，会抓住问题的某个特征直接推断结果，而不考虑这种特征出现的真实概率以及与特征有关的其他原因。在很多情况下，代表性法则是一种非常有效的方法，能够帮助人们迅速地抓住问题的本质推断出结果，但有时也会造成严重的偏差，特别是会忽视事件的基本要素（base rate neglect），即无条件概率和样本大小。简而言之，人们往往根据认知上的易得性来判断事件的可能性，比举容易出现偏差。

# 模型结构

所有信息
你做决定的信息
易记忆 易关联 易提取

+   - RECENT - 最近的、最新的信息
- FREQUENT 频繁出现的
- EXTREME - 极端的
- VIVID - 生动的、鲜艳的
- NEGATIVE - 否定的

RECENT FREQUENT EXTREME VIVID NEGATIVE
三个“易”提醒你对信息要保持客观

# 对应方法

认知局限
认知局限的结果即是盲人摸象、疑见一斑、以偏概全。

易记忆
主动采取批判式思维来考虑问题，从而发现自己的小圈圈。
察觉局限

盲目自信
容易忽略客观事实情况，从而自以为是认为自己是对的。

易关联
主动实事求是的考虑问题，面对问题，多了解事实，避免盲从。
察觉盲目

经验判断
经验是惯性思维，是大脑根本走捷径的偷懒方式。

易提取
主动切换惯性思考，通过反思或复盘等方式来验证。
察觉经验

> 总结:主动运用批判性思维仔细评估，主动问出why，进而规避认知偏差做出正确的判断或者行动。
