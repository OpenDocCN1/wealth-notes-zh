# 70. 遗忘曲线思维模型

我们应该以不同的方式去思考，以此来应对这个瞬息万变的世界。因此我们将前期人类最透过“视觉笔记”翻译出来，为大家提供解决问题的可视化思维公式。

遗忘曲线(Forgetting curve)是用于表述记忆中的中长期记忆的遗忘率的一种曲线，该曲线描述了人类大脑对新事物遗忘的规律。人们可以从遗忘曲线中掌握遗忘规律并加以利用，从而提升自我记忆能力。又经过新研究发现记忆过程记忆的保持在时间上是不同的，有短期和长期记忆两种，平时的记忆的过程是：输入的信息在经过人学习后，便成为短期记忆，再经过进一步强化后成为长期记忆。长期记忆的保持时间有长有短，如果不及时复习，这些记住过的东西就会遗忘，而经过及时复习，长期记忆就会继续保持下去。

# INSPIRATION AND APPLICATION
启发应用

# 保持定期定时的练习

艾宾浩斯根据遗忘曲线绘制了记忆规律图，它意味着每隔一段时间后，需要对之前所学的东西进行复习以达到巩固记忆的效果，这样可以达到记忆和遗忘之间的平衡。并通过这种方式，推导出一个记忆和复习的模式，学习后的第一天，复习后的第二天，复习后的第三天，复习后的第七天，复习后的第十四天，复习后的第三十天，循环往复，依次类推。亦即是，每次复习的时间间隔会递增，间隔越长，记忆的保留效果越好。

# 保持对外部的态度

很多人在学习的过程中会产生惰性，沉浸于自己的世界中，忽略了对他人的尊重和关怀。他们可能会因为自己的压力和情绪而对他人产生负面情绪，进而导致人际关系紧张。为了避免这种情况的发生，我们需要保持对外部的态度，与他人保持良好的沟通和交流，尊重他人的意见和感受，积极地与他人互动，增强自信心和自我认知，从而建立良好的人际关系。

# 关联成为你的认知网络

学习过程中，我们经常会遇到一些新的知识和概念，如何能够将这些知识有效地存储在记忆中呢？我们可以借助联想的方式，将新知识与已有知识联系起来，形成一个完整的认知网络。通过这种方式，我们可以更好地理解和记忆新知识，同时也可以提高我们的思维能力和创造力。

总结：艾宾浩斯遗忘曲线指出了人类遗忘的核心规律——其先快后慢。既如此便可以通过遗学习来帮助我们提升记忆。
