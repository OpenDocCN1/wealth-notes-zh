# 96. 双目标清单思维模型

我们经常信它不同的方式思考问题，以此来应对这个瞬息万变的世界。因此我们将前人智慧通过“觉现语法”翻译出来，为大家提供解决问题的可视化公式。

双目标清单系统 Two-List System，也叫 25-5 生产力规则，有目标是非常重要的。《孟子》曰：“吾必有为，然后可以有为。”即人要审时度势，决定取舍，选择重要的事情去做，而不做或暂时的不做某些不该做的事情，表示为 час有人有原则、底线。它也指人的精力是有限的，只有放弃一些事情不做，才能在别的一些事情上做出成绩。当有了具体的目标，你才能反复地推演实现这个目标的方法和路径，才能在每天早上升眼之后明白自己应该围绕什么东西优化和努力。

# 模型结构

# Objective 目标

# CHOOSE 有所为一得

得，即有所为的事情，为“舍”与“舍”反而显得更重要。因为要先理想，确认自己最想要得到的结果，确认自己最想获得的目标，这个目标也并不是说你怎么想怎么要，也要符合你自身条件去选择。

# List A 最重要的目标

# GIVE UP 有所不为一舍

舍，即放弃的项目，不为不求是不抱不抛弃的精神，如若事情进展？不积？大智慧告诉一句话，物有所失，事有终始，知所先一近远者。所有不做不是不做，而是先考虑重（本）的做好。

# List B 要舍弃的目标

# 重要目标三问

+   一：所选是否符合客观环境发展趋势？
二：所选是否符合自身条件？
三：所选是否过于主观自以为？

# List A 5 Mike Flint 20 List B

巴菲特的私人飞行员 Mike Flint，在请求巴菲特自定的职业生涯目标时，巴菲特让他首先写下他职业生涯最重要的 25 个目标来。Flint 写下这些目标后，巴菲特要他审慎地看一看这些目标的前5个，之后 Flint 有了更深的认识——是一项很重要的一个，还有 20 个目标，巴菲特问：你现在知道这20个目标吗？Flint 试着从先开始宣布实现这 5 个目标。另有 20 个，放开在后面消失掉，最终他能够更好的实现。巴菲特说：“不，Flint，你搞错了。剩了的项目，不是应该在短期内去实现，而是你应该拿出全部的力量去做的事情，你应该避免像疲惫一样浪费它们。不要花任何的时间和精力把它们放在上面。”
