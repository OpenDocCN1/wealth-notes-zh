# 16. 反脆弱思维模型

我们信念应以不同的方式去思考问题，以此来应对这个貌似万变的世界。因此我将前人智慧通过“微诺言”臻述出来，为大家提供解决问题的可视化思维公式。

反脆弱指在受到外部不确定性的条件影响时，让自身变得更好，从这种不确定性的条件中获益。“反脆弱”比“坚韧”更进一步，具体指的是一些人和事物在面对冲击时，不但能够不受损伤，还能从冲击中受益。当暴露在混乱、压力、风险和不确定性下时，他们可能逆势成长。

# 模型结构

A= 脆弱
B= 坚韧
C= 不确定因素
A+B+C= 反脆弱

脆弱的现象 如求稳、习惯舒适区
脆弱的对手 推手本身也为脆弱
脆弱的根源 非线性，如事项干扰
