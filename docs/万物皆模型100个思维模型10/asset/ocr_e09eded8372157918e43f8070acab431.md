# 26. 局部、全局最优思维

我们常常习惯以不同的方式去思考问题，以此来对应这个瞬息万变的世界。因此我将前人智慧通过“视觉笔记”翻译出来，为大家提供解决问题的可视化思维公式。

LOCAL OPTIMAL SOLUTION（局部最优解）和 GLOBAL OPTIMAL SOLUTION（全局最优解）是数学中的两个概念。局部最优是对于一个问题的解在一定范围或区域内最优，或者说解决问题的手段在一定范围或限制内最优。全局最优是针对一定条件或环境下的一问题或者目标而言，若一项决策和所有解决该问题的决策相比是最优的。

# WHAT IS HAPPINESS? 什么是幸福？

# 如何应用

# 明确局部最优解的范围

万物不称其算，这个世界上唯一不变的就是变化本身。由此万物万物规律！即因为自身条件所能改变之前，首先要明确自己的范围。

# 叠加升级或迁移局部最优解

在明确自己的范围之后，刻意致富，叠加升级自己的范围。这是第一个叠加的过程。这个过程并不简单，而是在有基座上的叠加升级。

> 总结：生活中由于外部因素的干扰，我们只需要明确自己的局部最优解，在此基础上只需扩大、叠加升级或迁移局部最优解即可。
