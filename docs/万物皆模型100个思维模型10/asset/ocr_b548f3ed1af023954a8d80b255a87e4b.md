# 42. 思维投影 思维模型

我们意图应该以不同的方式去思考问题，以此来应对这个变化万千的世界，因此我们将前几篇“视觉语言”翻译出来，为大家提供解决问题的可视化思维工具。

思维投影指的是在现实生活中，我们的采取的行为，说话的表情或语言，以及我们做出的决策等均源于我们思维投影出来的影像。这让我们意识到，从影像倒推便可以窥探自己内心的变化，即反应的过程。所以我们内心有什么样的思维，就看得到该思维投影所呈现给我们的现象（自身具体行动），但是这种相并不是固定不变的。"表里不一"就是这个固定思维的一种变化，所以对内通过检查自己的思维，来修正自己，即反思；对外让自己跳出固定思维的局限，一览全景，看待对面的相。

# 曾国藩识人术即是从自己视角看他人的A→A

曾国藩《冰鉴》中从 7 个方面去研究识人术，这 7 个方面分别是神骨鉴、刚柔鉴、容貌鉴、携带鉴、须眉鉴、声音鉴以及气色鉴。曾国藩先生通过常人 A—A 的惯性思维归纳的以上 7 个方面是对常人思维规律的总结，即思维投影模型。

# 居发应用

# 主动觉察、反思、联系、升级

A—A 思维投影被发现，该种规律能可视化找到问题，然后我们就可以像测试产品的人工发现 BUG 一样，通过思维的反馈来对接问题，找到规律，对照下内部已经呈现的规律。主动发现了作为一个个体，已经处于这个环境了，告诉我们有个人或事情是人们内部状态的映射，当他们与我们的关系有了变化就意味着我们发生了变化。

# 主动升级才能自己规避风险

在认知提升的情况下，我们可以更大地扩大我们视野和认知范围，换言之，我们的 A—A 思维投影被他人观察到时不必担心被利用。假如我们将思维不断升级，也能在他人测量到我们的 A—A 时对自己进行“调试”，让他人对我们不构成威胁。

# 通过学习主动提升自身维度

我们生活了就应该对人们的认知有所理解，如何向不同的人传递同一种信息，如何在他人评价中保持稳定的心智状态，如何在不同的人际环境中建立自己的安全感，都是非常重要的问题。学习通过主动提升自身维度，可以让我们在复杂多变的环境中保持自己的真实性，从而有效地提高自己的思维能力，使我们的思维在不同环境中得到更好地发挥。

总结：每个人的行为、决策、情绪等言行举止，其背后都是其内在思维的投影，因此，对此觉察，不要被现象迷惑。
