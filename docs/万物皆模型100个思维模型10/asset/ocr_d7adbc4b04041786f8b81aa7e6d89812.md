# 86.5W1H分析法思维模型

我们应该从不同的方式去思考问题，以此来应对这个瞬息万变的世界。面对我们前人智慧通过“微笑传播”翻讲出来，为大家提供解决问题的可能性思维公式。

5W 是在 1932 年由美国政治学家拉斯维尔最早提出的一套传播模型，后经人们的不断运用和总结，逐步形成了一套成熟的“5W+1H”模式。5W1H 分析法（Five Ws and one H）也称六何分析法，即何人（Who）、何时（When）、何事（What）、何地（Where）、何因（Why）及何法（How）。由这六个疑问词所组成的问句，都不是是非题，而是需要一或多个事实证据的应用题。《左传·哀公二十七年》文子曰：“君子之谋也，始、衷、终皆举之，而后人焉。今我三不知而入之，不亦难乎！”即所谓起源、过程以及事物发展变化的结果，是一个过程的终了，同时也是另一个新过程的开始。

# 模型结构

# 5W1H
Five Ws and one H

+   - 要做什么？
- 是怎么做的？
- 应该怎么做？
- 这种方法可被破坏？
- 还有其他方法吗？

How 何法

What 何事

+   - 这怎么去做？
- 正做在什么？
- 应该做啥？
- 还做做啥？
- 还能做些啥？

Why 何因

+   - 为什么要这么做？
- 为什么它能够成功？
- 为什么这样？
- 为什么是那样？
- 为什么不用另一种方式做？

OBJECT 事物

Where 何地

+   - 在哪里做？
- 在哪里做的？
- 应该在哪做？
- 还可以哪里可做？
- 还有在哪个位置？

When 何时

+   - 什么时候做？
- 什么时候完成？
- 什么时候开始？
- 什么时候可以做？
- 其他时间应该做啥？

Who 何人

+   - 是谁做的？
- 应该在谁？
- 应由谁来做？
- 是否可以制造？
- 还有谁能去做？

# 举个例子

| | what 何事 | why 何因 | how 如何 |
|---|---|---|---|
| what 何事 | 针对什么？ | 为什么要解决这个问题？ | 没有变成需要的东西前，我们能做什么？ |
| why 何因 | 为什么？ | 为什么要这么做？ | 为什么我们会这样认为？为什么要去做？ |
| Where 何地 | 在哪？ | 因为在何处？ | 应该在何处？ |
| When 何时 | 何时做？ | 为什么在何时？ | 是否可在何时？什么时候才好？ |
| Who 何人 | 谁来做？ | 为什么要这么做？ | 是谁的？ |
| How 如何 | 怎么做？ | 为什么要这样？ | 是否有其他可以做的？应该怎样做？ |

之所以将全国组织框架图（P32 黃金圈思维模型），即通过 WHAT、WHY、HOW 三次循环的顺序来讲解事物，实际上是希望个人也能从自己内心出发，提升5W1H 大纲思维可见度。帮助我们清晰地看到事物发展过程中各个环节的联系。即原本看似漫、返过去一个个变化的现象，看着模糊的解，解决了很多对于我的成果。

“始”即事物的起源，开始或初始阶段，它包括了事物的最初的历史背景和背景状态的种种情况中，“中”即事物发展过程中，其实包括了事物在不断上或生成递进过程中各个环节和各阶段的发展情况。“终”即事物发展变化的结果，是一个过程的终了，当然同时它也可以是另一个新过程的开始。

# 启发应用

# 思维模型是事物的规律

思维模型是事物存在的本质，是讲我们解决问题的一种趋势。就像一个社会、一个产品、一个问题。我们通过不同的角度去思考，可以看到不同的方向，从而形成自己的思维模型，提炼出5W1H。

# 口号都是假大空

制定一个FLAG，自己的公司公司员工都会得意马上实现计划的实施方式来完成目标。每個人的思考方式虽然不同，但5W1H可以帮助我们找到核心问题，提炼出问题，找出解决方案，形成一套系统化的思维方式，5W1H可以较准确地判断事物的关键节点和因素，最终知道如何去实现目标。

# 以始为终 循环往复

循环往复，总有反复的事情发生。以终为始，过程不断循环，开始、过程、结束，还是不断重复的过程。过程与结果相互作用，形成一个循环往复的体系。以终为始，以始为终，循环往复，不断改进。

> 总结:口号都是假大空，所以不喊口号，实事求是的做符合我们自身条件的事情。不知“始”，何知“终”啊！
