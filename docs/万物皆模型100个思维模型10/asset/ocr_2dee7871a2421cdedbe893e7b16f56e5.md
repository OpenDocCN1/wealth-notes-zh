# 23.损失规避思维模型

我们懂得应该以不同方式思考问题，以此来应对这个瞬息万变的世界。因此我将前面套用“微视觉语言”翻译出来，为大家提供解决问题的可视化思维公式。

损失规避是人们在面对同样数量的收益和损失时，认为损失更加令他们难以忍受，又称损失厌恶。损失规避反映了人们的风险偏好是不一致的，当涉及的是收益时，人们表现为风险厌恶；当涉及的损失时，人们则表现为风险寻求。

损失规避思维模型提示我们在如何理问题，建议在自我身会出现损失规避心理的情形下，要很当心的避免过度避免大损失的进行，从而让决策更客观、准确。

# 应用例子

# 01 1979年，心理学 Kahneman 和 Tversky，用实验验证了亚当·史密斯的观点，并将其现象命名为损失规避。具体的实验过程是：

+   - 第一组实验
被实验体先行持有 1000 单位的现金。在基础上做出选择
A.50%的概率将持有的现金增加为 2000
B.100%的概率持有现有的现金金额为 1500
此实验中，被实验体的 16% 选择了 A, 64% 选择了 B

+   - 第二组实验
同被实验体先行持有 2000 单位的现金。在基础上做出选择
C.50%的概率将 1000 单位现金
D.100%的概率损失 500 单位现金
此实验中，同实验体的 69% 选择了 C, 31% 选择了 D

实验中，A选项和 C选项等同手中有现金1000若再获得1000单位现金，50% 的概率，并与 A选项同值，D能在手上获得现金1500, 100% 的概率，即B选项。结果显示：“虽然两项在经济上等价，但人们对损失的敏感度远高于对收益的敏感度，所以人们更倾向于避免损失而不是追求收益。”
不要过度选择亏损或不确定的情况，人们只想规避最大的自己感受到的痛苦。

# 如何规避

+   01 决策时做数据分析，告诉更易获取确定的情况；
对自己和他人决策时，应可能通过理性分析来评估风险和收益，避免因损失规避而做出过度的保守决策。对个人而言，可能有一个问题，通过这种把“损失”变为“获得”来引导人做决策。

+   02 不看一时，看长远。
股市当中短期视角很很重要，但长远来看，也可将风险分散。但在时间上需要谨慎，在时间上，风险会有所分散，在于股市波动过程中，上涨或下跌得失，随着时间推移，下跌时才，不会呈现短期最终亏损。

+   03 调整决策依据，做好最好的打算，降低期望值；
从最终的决策考虑时，最好的打算，这时人们心理就会从“损失”变为“获得”。调整自己的期望值，同时降低期望值，也会让人实际的收益增加，从而知道“损失”变为“获得”。

> 总结我们处理问题，做决策时，要明白自身有损失规避心理的存在，然后有意识的克服免除大损失或避免的行为，从而让决策更客观、准确。
