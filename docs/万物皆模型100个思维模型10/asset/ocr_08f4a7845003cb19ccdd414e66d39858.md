# 88.HOOK上瘾思维模型

我们都应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前期人工智能通过“貌似诸葛”翻译出来，为大家提供解决问题的可视化思维公式。

上瘾模型 the Hook Model, 即 HOOK 模型(或称为钩子行为模型), Hook 上瘾模型由《上瘾》的作者尼尔·埃亚尔、裴安·胡佛提出,其本质是设计一套让用户连续循环的行为模型,即“触发(Trigger)→行动(Action)→奖励(Reward)→投入(Investment)”四要素,也就是让用户养成使用习惯的四大产品逻辑,以让用户在不知不觉中对产品上瘾。上瘾模型即讲用户的问題与你的解决方案联系起来,并以足够的频率形成一种习惯,通过不断地穿过这些“钩子”,习惯就会形成,从而成为忠实用户。

# 启发应用

# 上瘾的前提条件

产品是满足用户的需求, 并提供用户可以持续使用的完整方案。产品要有差异化、无同质化需求, 需要产品与用户的关系清晰, 用户在产品的使用过程中认识到自己, 并且满足需求, 有需求的产品就被用户持续使用, 用户对用户价值的感知, 有利于建构用户的忠诚度。产品是解决用户的问题, 让人回想自己的价值和期望的产品。

# 切勿本末倒置

上瘾模型是为解决用户问题而设? 如果用户不存在问题, 上瘾模型一开始, 即用户没有需求, 企业将很难提供上瘾的有效办法和满足需求, 然后会被认为只是一种商业套路, 并且会带来负面影响, “问题解决、价值创造、产品改进、内在需求的产品”：成功的产品, 往往只是解决用户需求, 并且去满足用户需求, 这种产品就像泥沙, 人们会因此而买单。

# 万事开头难

上瘾模型的核心是用户的需求, 也就是产品设计中需要不断去解决用户的需求和提升产品的独特性, 并且提供用户的体验, 通过循环反馈不断的去满足用户, 以便于使用产品的频率, 提高产品的粘性, “用户”也就会被锁定, 甚至成瘾, 而“最终用户”不断的去提高用户的使用体验, 形成升级就成为用户忠实拥护的。

总结: 生活工作中, 我们所学的一些思维模型的对像均是围绕人而进行的, 因此不脱离对人性需求的思考。
