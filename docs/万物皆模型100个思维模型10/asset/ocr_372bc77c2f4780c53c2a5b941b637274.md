# 56. 费曼技巧思维模型

我们应该设法以不同的方式去思考问题, 以此来应对这个瞬息万变的世界, 因此此我们前面已经帮通过“视觉语言”翻译出来, 为大家提供解决问题的可视化思维公式。

费曼技巧或称费曼学习法的灵感源于诺贝尔物理奖获得者理查德·费曼 (Richard Feynman), 运用费曼技巧, 你只需花上 20 分钟就能深入理解知识点, 而且记忆深刻, 难以遗忘。知识有两种类型, 我们绝大多数人关注的都是错误的那类。第一类知识注重了解某个事物的名称; 第二类知识注重了解其重要物, 这可不是一回事儿, 诺贝尔物理学家理查德·费曼 (Richard Feynman) 能够理解这二者间的差别, 这也是他成功最主要的原因之一。事实上, 他创造了一种学习方法, 确保他会比别人对事物了解的更透彻。

# TAKE AN EXAMPLE 举个栗子

不知所做的可视化思维模型便是费曼技巧的思维缘, 芸格说: “你必须拥有多元思维模型——因为如果你只能使用一两个, 研究人员的心理学家说, 你将会扭曲现实, 直到符合你的思维模型, 或者至少对你认为符合的模型为止。”为了解决这个问题, 模型思维的可视化不断开拓, 模型可视化只是把原本不容易理解以视觉的形式翻译出来, 在输入输出之后最后需要的是能够各方面理解的, 能说的明白的, 简单的可视化语言(即说人话)表达各...可以此帮助各方面快速学习, 了解这些伟大的理论, 以帮助我们更好地预测风做, 做出合适的决定。

曾拥有写日记的习惯, 跟现在写微博很像。我们知道, 一则微博是一百四十个字, 曾国藩的日记也不长, 一天大概也是二百字, 而且夹着字写完之后, 他会接着读, 读完之后的要求每个人的点评, 就相当于我们在布置任务, 如今每天把微博下面的人的跟贴, 国难藏的日记帮助他有很多的进步, 输入、输出、认识人、 devastating 反复, 再修身改进自己, 从而提升自己的认知与格局, 孔子学而时习之时, 即身试学(实践), 甚至学习, 要依据自身条件转化去“习”, 即练习, 实践获得反馈以来来修正。

# INSPIRATION AND APPLICATION 应用启发

子曰: “学而时习之”
孔子曰: 独学而无友, 则孤陋而寡闻。独学而无友, 则怠惰而荒废, 教学相长。相依相辅, 彼此勉励, 相互促进。即使只学习不去实践, 也无济于事, 只有学而时习之, 才能真正理解并掌握知识。

总结: 面对卡壳, 接受卡责, 并且可自以为是, 忽略而过。如此才能接受事实, 才能透过现象发现事物背后的本质。
