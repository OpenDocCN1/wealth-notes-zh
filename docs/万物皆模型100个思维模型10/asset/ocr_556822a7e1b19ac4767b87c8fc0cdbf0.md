# 71. 断裂点理论思维模型

我们应该或尝试以不同的方式去思考问题，以此来应对这个变化万千的世界。因此我们特聘智囊通过“视觉笔记”观点出来，为大家提供解决问题的可视化思维公式。

之前我们介绍过一个源于工程学的思维即 P65 冗余备份思维模型，今天介绍第二个源于工程学的思维模型——断裂点理论思维模型。熟知的如电路系统中的保险丝，即在整个电路系统中，若电路发生故障或异常时，伴随着电流不断升高，促使绝缘自身会熔断切断电流，继而保护整个电路系统的安全。断裂点理论指的是在系统内设置一种保护机制，当系统内的某个值，如压力、温度、电流等超标到将破坏整个系统时，系统内的断裂装置开始熔断<|start|>断裂，以此用小装置的损失来防止整个系统大的损失，如“弃车保帅”等。

# MODEL STRUCTURE

# 模型结构

设置断裂点

# BREAKPOINT

到达断裂点 -  процеду与反思

用可承受的很小的损失来防止规避不可承受的大的损失，即：以小损、防大损

反思 = 事实总结 + 旁观视角 + 反馈信息

# TAKE AN EXAMPLE

# 举个例子

股市中的熔断机制，即自动熔断机制，广义指控制股票、期货或其他金融衍生品的交易风险，为单一日的波动幅度规定区间限制，一旦该限制触及及上限，交易则触发，股票交易将暂停、股市大幅度的波动将被控制，市场出现暴跌的可能性降低，大幅提高市场的透明度，交易恢复下线。交易所为防止股市的剧烈波动，减少市场的系统性风险，交易则暂停，交易恢复下线。交易所为防止股市的剧烈波动，减少市场的系统性风险，交易恢复下线。交易所为防止股市的剧烈波动，减少市场的系统性风险。

《三毛志·颂志·先主传赞松之注》：“勿以恶小而为之，勿以善小而不为”。即不要以为坏事很小就去做，不要以为好事很小就不去做，因为小善可以成大善，小恶会形成大恶，这是个人成长方向的“断裂点理论”。又比如成功人士的名言警句也体现了他们自己的成长向“断裂点”，公司内的有竞争力的员工管理制度——管理红线、球场上的黄牌、红牌的违规判罚等。有的断裂点理论的支持，一个系统的整体备份、运转取决于就会不偏离，也就不会产生大的损失。
