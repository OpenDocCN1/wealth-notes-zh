# 27. 不平衡性思维模型

我们应信应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们利用人皆看过“视觉通俗”翻译出来，为大家提供解决问题的可视化思维公式。

不平衡性的原理是矛盾发展，事物都是由矛盾群构成的，事物矛盾群中的多个矛盾以及矛盾的各个方面在事物发展中的地位和作用是不同的。不平衡性有主要矛盾和非主要矛盾、矛盾的主要方面和非主要方面。这种矛盾力量的不平衡性，是矛盾特殊性的重要表现。因此，矛盾发展不平衡性的原理是矛盾特殊性的重要表现。

# 不平衡性之木桶理论

+   • 老木桶理论：木桶盛水的多少并不取决于桶壁上最高的板而取取决于最低的那块板。即要想提高木桶的容量，必须先提高最低的板。
• 新木桶理论：是否有木桶理论要有一个平衡点，平衡点在无论是提高短板还是提高长板上、其实木桶理论的本质上是一个平衡问题。
