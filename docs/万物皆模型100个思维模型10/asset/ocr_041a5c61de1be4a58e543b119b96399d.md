# 29. 非线性思维模型

我们应该意识到以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们必须假想人脑通过“貌似言语”翻说出来，为大众提供解决问题的可视化思维公式。

非线性思维是指一切不属于线性思维的思维类型，如系统、直觉、模糊思维等。它很可能就会不按逻辑思维、线性思维的方式走，有某种直觉的含义，是 一种无须经过大量资料、信息分析的综合非线性系统远比线性系统多得多，客观世界本来就是非线性的，线性只是一种近似，对于一个非线性系统，哪怕一个小扰动，象初始条件的一个微小改变，都可能造成系统在往后时间行为的巨大差异。

总结观点：非线性思维更善于在复杂的环境里观察，澄清默认的活动更接近事物，更真实。因为单纯地线性思维只是简单的单方面的因果关系，认为一因一果、循因循果；而非线性却是相互叠加的非线性因果关系。数学图解：线性思维是一种直线的、简单的、单线的、线变化的思维方式；非线性则刚好是互五连接的、非平直、立体化、无链的网络结构。

# 如何应用

# 保持终身学习

事物变化、发展变化变得更多，线性思维在特定环境下会产生反映；非线性思维和思考是另一种反应。然而只要人们不断的创新，事情就会变得复杂、不可传输。因此，人们要不断学习，获取知识，发展技能，适应变化。

# 保持开放心态

请记住：只有开放，才能更好地应对各种挑战。保持开放的心态，接受新知识，能够帮助我们更好地理解世界和应对变化。开放心态让我们更愿意学习新事物，也更容易适应变化。

# 保持尚劲精神

今朝不忘、气定神闲、底气十足。保持乐观的精神，才能在困难中保持信心。即使生活中有挑战，也要相信自己的能力，勇敢面对。保持积极的心态，是一种应对变化的力量。

总结线性思维是非线性思维中的一种非常特殊的形态，因为大部分非线性必然会得到线性的存在，这反映关系两者并非对立、而当存在并存。
