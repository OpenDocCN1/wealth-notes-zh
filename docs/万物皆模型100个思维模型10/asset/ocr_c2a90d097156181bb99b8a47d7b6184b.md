# 30. 自催化思维模型

我们尝试以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前人智慧通过“貌似谬言”翻讲出来，为大家提供解决问题的可视化思维公式。

自催化是指不添加催化剂，而由反应产物起催化作用的反应。该类反应的特点是起初阶段反应速率较慢，随后反应速率逐渐加快，最后速率再次变慢。自催化反应是指反应物本身具有催化作用，能够加速或减慢反应的进行的一种反应，如火药热分解产物 NO2 即可对该反应起到自催化作用；我们常接触到的白酒、醋糖的发酵也是典型的自催化反应。

# 模型结构

# 起始速率较慢，随后加快又变慢

反应速率随着反应物浓度的提高而提高

反应速率随着产物浓度的快速提高而增大

由以上分析可知自催化反应的三个特点

+   01 反应物中加入少量的产物
满足初始条件,促使其反应开始

+   02 反应过程中必然存在一个最大反应速率

+   03 反应速率随着反应的进行会经过先增大后减少的变化

# 举个例子

# 芒格说:“迪士尼是自催化的完美典范！”

# 流行性网络效应

IP+电影是已知条件促使其后续增值开始。随着在最大反应速率时增加产物(如迪士尼乐园、购物圣地行驶生)。带来新的自催化路径(或增加一条新催化路径),以此实现持续增值。

更多的司机就能带来更大的服务面积/占有率/更大利润/占有率可以让司机提供更便宜高效的提供服务客户更好,所以需求更多

# 如何应用

# 终身学习 | 扩展视野

芒格先生视学习和思考为一种的爱好和习惯。学习再学习不断创新,不断学习,了解更多,使其学习和思考都成为一种乐趣,领悟真知,去积极寻找,寻找可以用来解决实际问题的复杂策略,往往在于轻中早发现,从而可以解决现实问题,往往在于轻中早发现。

# 主动景象 | 开放心态

主动去观察,才能激情串联自己的观点,才会主动推演。世界在不断变化,了解更多。从自然为他,世间万物都会发生变化。同时,保持一个开放的心态,才能够别出心裁。

# 坚持实践 | 复盘反思

学习过程,跟随环境变化,随着环境的改变,更需要在学习的同时不断总结,不断反思,并不断总结,并不断尝试。学习过程,跟随环境变化,随着环境的改变,更需要在学习的同时不断总结,不断反思,并不断尝试。

总结自催化思维模型是一个能够帮助我们实现快速成长的模型,如自己的兴趣,利用自己的兴趣去主动催化我们在某领域的成长。
