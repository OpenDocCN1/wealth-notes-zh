
# 67. 元认知思维模型

我们需要应运以不同的方式去思考问题，以此来应对这个极其万变的世界。因此我们将拥有人类通过“视觉语言”解读出来，为大家提供解决问题的可视化思维公式。

后设认知(Metacognition)或译为元认知，由美国心理学家 J.H.弗拉维尔提出的观念，即“认知的认知”或“知识的知识”。所谓元认知是指一个人对自己的思维过程和学习活动的认知和监控，是个人对自己的认知加工过程的自我觉察、自我评价和自我调节。简言之，就是对自己的认知过程(包括：记忆、感知、计算、联想等各项)的思考或对自己思维过程的反映。元认知可以用于学习策略，是一种个人控制及引导心智历程的现象。主要包括元认知知识、元认知体认、元认知监控等。

# 68.排列组合思维模型

# 排列组合 Permutation and Combination 是组合学最基本的概念。排列是指给定义个数的元素中取出指定个数的元素进行排序，例如从一到六的数字有 720 种排列，对应由于这些数字组成的所有不重复亦不阙满的序列，例如“4,5,6,1,2,3”与1,3,5,2,4,6。组合则是指给定个数的元素中仅仅取出指定个数的元素，不考虑排序。例如 S 的一个 k-组合是 S 的一个有 k 个元素的子集。若两个子集的元素完全相同并顺序相异，它仍视为同一个组合。排列组合的中心问题是研究给定要求的排列和组合可能出现的情况总数。

## MODEL STRUCTURE
## PERMUTATION AND COMBINATION'S FORMULA 排列组合公式

排列数公式：从 n 个元素中取 k 个元素，k 个元素的排列数量为
Pₙᵏ = n! / (n-k)!
例如从 8 个人中选出 3 人安排在某次会议上担任三个不同的职位等，A、B、C 3 位可被排列为 3×2×1 种；排法总量为：
P₈³ = 8! / (8-3)! = 8×7×6 = 336
说出 336 种方法，因此产生一次事件中从全体事件的概率为：
P = 1 / 336 = 0.00298
和排列不同的是，组合不考虑取出来元素的顺序

组合数公式：从 n 个元素中取出 k 个，k 个元素的组合数量为
Cₙᵏ = (n choose k) = Pₙᵏ / k! = n! / [k!(n-k)!]
例如从集合 {1,2,3,4,5,6,7,8,9} 中取 6 个元素的组合数为
C₉⁶ = 9! / (6!3!) = 84

内部元素参考排序
分步乘法 A → 7 种 → C 2 种 → B
即从 A 地到 B 地的方法：7×2×14 种选择
内部元素不考虑排序
分类加法 A 火箭 5 种 B
从 A 到 B 的方法：2×5+7=14 种
分类加法完成一项不同方法的需求，要求：有序、不重复、不遗漏。

## 25 PSYCHOLOGY OF HUMAN MISJUDGMENT
## 25条人类误判心理学

+ 1. 超反应和确认偏向
奖励和惩罚机制促使大脑倾向于寻找确认自己观点的证据,忽略反证,从而导致决策错误。
2. 乐观和热爱同情
一种心理调节工具,说服自己相信未来会更好,即使当前处境糟糕,也能保持积极心态,推动自我的发展。
3. 讨厌损失假设
一种心理调节机制,促使人们在面对损失时更敏感,导致过度风险规避或不必要的行为。
4. 避免群体倾向
人类的本能天生具有一种群体归属感,因此对异类产生排斥的倾向。
5. 随意不一致性
随意地认为自己总是不一致,导致在不同情境下行为矛盾,影响决策一致性。
6. 好奇心倾向
好奇心倾向会帮助人们防止对那些看似熟悉和喜欢的领域产生过度自信。

+ 7. 形式公平倾向
人们倾向于公平和平衡,看到事情的两面性,但可能忽略复杂性而做出简单化判断。
8. 随喜/厌恶倾向
倾向于对喜好的事物保持正面评价,对厌恶的事物保持负面评价,甚至在缺乏证据时也如此。
9. 回馈倾向
以报复心理,以牙还牙的猴子,这种倾向在人际交往中容易导致冲突升级,回馈式报复往往得不到本意。
10. 爱情单恋
人们的倾向是爱上没有逻辑基础的爱情,因而在恋爱中产生盲目性。
11. 简单的,避免痛苦的心理学
人类大脑喜欢简单化,令人无法接受复杂的现实,当人们被迫面对复杂问题时,他们倾向于选择回避。
12. 自我过高的倾向
人们总是过高地评价自己的能力,特质,缺乏客观评估,导致过度自信和决策失误。

+ 13. 过度乐观倾向
人们往往会高估成功的可能性,忽略风险,导致决策失误。
14. 被动过度反应倾向
人们在面对不确定的情况时,倾向于过度反应,导致决策失误。
15. 社会认同
人们会倾向于将自己归入某个群体,以获得认同感,但可能导致从众行为。
16. 压力影响倾向
压力的负面情绪会改变人们的决策方式,导致过度保守或冒险行为。
17. 锚定效应易感性倾向
人类的大脑在面对不确定的信息时,倾向于依赖最初的信息,导致决策偏差。
18. 抗拒

# 70. 遗忘曲线思维模型

我们应该以不同的方式去思考，以此来应对这个瞬息万变的世界。因此我们将前期人类最透过“视觉笔记”翻译出来，为大家提供解决问题的可视化思维公式。

遗忘曲线(Forgetting curve)是用于表述记忆中的中长期记忆的遗忘率的一种曲线，该曲线描述了人类大脑对新事物遗忘的规律。人们可以从遗忘曲线中掌握遗忘规律并加以利用，从而提升自我记忆能力。又经过新研究发现记忆过程记忆的保持在时间上是不同的，有短期和长期记忆两种，平时的记忆的过程是：输入的信息在经过人学习后，便成为短期记忆，再经过进一步强化后成为长期记忆。长期记忆的保持时间有长有短，如果不及时复习，这些记住过的东西就会遗忘，而经过及时复习，长期记忆就会继续保持下去。
