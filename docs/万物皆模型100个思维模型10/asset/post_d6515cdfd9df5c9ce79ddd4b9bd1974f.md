# 01. 机会成本思维模型

我们应该以不同的方式去思考问题，以此应对这个变化万变的世界。鉴于我们暂时无法穿越“就餐请客”，提供给大家解决问题的可视化思维公式。

机会成本 Opportunity Cost 是指决策过程中面临多项选择，放弃而价值最高的选择（Highest-valued Option Forgone），又称为替代性成本 Alternative Cost，就是俗语的世界上海没有白吃的午餐、鱼与熊掌不可兼得。简单来说，机会成本就是所牺牲的代价。机会成本所指的“机会”必须是决策者可选择的项目，若不是决策者可选择的项目便不属于决策者的机会。机会成本 = 外显成本 + 隐含成本（外显成本即实际的支出；隐含成本则为时间、效益等）。

# 模型结构

# 鱼与熊掌不可兼得

CHOOSE B

OPPORTUNITY COST IS THE PRICE OF SACRIFICE

# 举个例子

本次决策的机会成本是 放弃追剧可能取得的收益（学习、成长等）是实行“读书”的代价

本次决策的机会成本是 放弃读书可能取得的收益（学习、成长等）是实行“追剧”的代价

# 局部应用

（所放弃的最佳选择的价值）-（实际选择价值）=（机会成本）

机会成本越高，选择越困难。因为在我们的抉择面前常常是不愿意放弃任何可能得到的乐趣。谁都知道要做“价值最大化”选择，选择价值最大的，那自然，机会成本就低。然而似乎对外如此，对内却又时常为正。这取决于你如何对待自己的本性。

> 总结：《鱼我所欲也》中孟子曰：“鱼，我所欲也；熊掌亦我所欲也；二者不可得兼，舍鱼而取熊掌者也。”

沉没成本 Sunk Cost 指已发生或承诺、无法回收的成本支出（如时间、金钱、精力），如因失误造成的不可回收的投资。从决策的角度看，以往发生的费用只是造成当前状态的某个因素，当前决策所要考虑的是未来可能发生的费用及其所带来的收益，而不考虑以往发生的费用。人们在决定是否去做一件事的时候，不仅仅是看这件事对自己有没有好处，而且也看过去是不是已经在该事件上有过投入。在经济学和商业决策制定过程中会用到“沉没成本”的概念，代指已经付出且不可收回的成本。

# 04.决策树思维模型

我们应尽可能以不同的方式思考问题，以此来应对这个瞬息万变的世界。因为我们期盼人类最终通过“视觉语言”表达出来，为大家提供解决问题的可视化思维公式。

决策树 Decision Tree，由一个决策图和可能的结果（包括资源成本和风险）组成，即一种通过图示罗列解决的有关步骤以及各步骤发生的条件与结果的一种方法，以此用来创建到达目标的规划。决策树建立并用来辅助决策，不仅可以帮助人们理解问题，还可以帮助人们解决问题。决策树是一个利用像树一样图形或决策模型 的决策支持工 具，包括随机事件结果，资源代价和实用性。 它是一个计算显示的方法。决策树经常在运筹学中使用，特别是在决策分析中，它帮助确定一个能最优达目标的策略。

SCHEME BRANCH | 方案分支

每个决策或事件（即自然状态）都可能引出两个或多事件，导致不同的结果，把这种决策分支画成图形像一棵树的枝干

# 05. 非SR思维模型

我们需要应付以不同的方式去思考问题，以此来应付这个瞬息万变的世界。因此我们将前期人工智能通过“视觉语言”翻译出来，为大家提供解决问题的可视化思维公式。

20 世纪初在巴普洛夫条件反射实验影响下，美国行为主义心理学奠基人华生提出了“刺激-反应学习理论”，又称为“行为学习理论”。刺激-反应理论认为人类的复杂行为可以被分解为两部分：刺激和反应。而人的行为是受到刺激的反应。学习的实质是形成习惯，而习惯是通过学习将对刺激做出散乱、无组织、无条件反应，变成有组织、确定的条件反应过程。SR 是刺激 (Stimulus) - 反应 (Response) 的缩写, 非 SR 思维模型, 指的是在刺激-反应中间加上思考的过程, 即刺激-思考-反应, 而由被动的必须反应转向主动有选择反应。

SR 基本公式: S → R (刺激→反应)    非 SR 基本公式: S → T → R (刺激→思考→反应)

刺激事件 → thinking → 言 → 做出反应
                  ↘ 行 ↗
三思后行

三思后行：思危、思退、思变，思前因、思后果之后，再做出反应。

# 举个例子

接收到对手屡屡比自己好的信息 → 惯性刺激 STOP→WHY → 焦虑

思考：别人都在发展，而你没有别人发展的快，于是产生焦虑、自卑等等情绪。
生活工作中，当我们遇到类似以上的问题时，可以通过思考(为什么会焦虑？自卑？) 来反求诸己，找到自己的问题，来调节自己的情绪，改变自己的自动化思维！

总结:非SR模型核心目的是打破“惯性刺激”下的反应，提醒我们要主动思考，要有意识的去做决策。

可得性偏差（Availability Bias / Heuristic）也被称为易得性偏差或易得性偏见，人们在不确定性的情形下，会抓住问题的某个特征直接推断结果，而不考虑这种特征出现的真实概率以及与特征有关的其他原因。在很多情况下，代表性法则是一种非常有效的方法，能够帮助人们迅速地抓住问题的本质推断出结果，但有时也会造成严重的偏差，特别是会忽视事件的基本要素（base rate neglect），即无条件概率和样本大小。简而言之，人们往往根据认知上的易得性来判断事件的可能性，比举容易出现偏差。

# 09.六顶思考帽思维模型

我们应该以不同的方式去思考问题，以此来应对这个变化万变的世界。由此爱德华前人智慧通过“视觉语言”翻译出来，为大家提供解决问题的可能性思维公式。

六顶思考帽 SIX THINKING HATS 是法国学者爱德华·德博诺 (EDWARD DE BONO) 博士开发的一种思维训练模式，或者说是一个全面思考问题的模型。它提供了“平行思维”的工具，避免将时间浪费在互相争执上。强调的是“能够成为什么”,而非“本身是什么”,是寻求一条向前发展的路,而不是争论谁对谁错。运用德博诺博士的六顶思考帽,将会使混乱的思考变得更清晰,使团体中无意义的争论变成集思广益的创造,使每个人变得富有创造性。六顶思考帽是管理思维的工具,简洁的操作框架,提高团队 IQ 的有效方法。

# 使用六顶思考帽的方法：

- (1) 聚集并思考想法和过程
- (2) 鼓励创意,平行和水平思考并重
- (3) 改进功能
- (4) 加快决策
- (5) 避免争论
