# 06. 确认性偏差思维模型

我们应该尝试以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前人智慧通过“视觉语言”翻译出来，为大家提供解决问题的可视化思维公式。

确认偏误或称确认偏差 Confirmation bias 是一个人选择性地回亿、搜集有利细节，忽略不利或矛盾的资讯，来支持自己已有的想法或假设的趋势，属于其中一类认知偏误和归纳推理中的一个系统性错误。当人们选择性收集或回忆信息时，又或带有偏见地解读信息时，他们便展现了确认偏差。这种偏见尤其显见于带有强烈情绪的问题和传统观念上。例如，人面对冲突，大多难以割舍，会在反复的情绪中来回谩骂抨击，过程中不断回馈并对自己给予合理的解释与交代，直到身心得到平衡安稳为止。
