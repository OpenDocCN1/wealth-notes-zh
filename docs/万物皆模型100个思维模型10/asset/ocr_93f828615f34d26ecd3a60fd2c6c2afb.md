# 31. 优先排序思维模型

我们能够思考以不同方式思考问题，以此来应对这个瞬息万变的世界。因此我前人智慧透过“领悟请”翻译出来，为大家提供解决问题的可能性思维公式。

优先排序思维模型是时间管理理论的一个重要方法，世上万事万物均有其根本的因，也有末端的那个果，在面对因与果、根与末的时候， priorit... 优先排序即是让我们能够有重点地把主要的精力和时间集中地放在处理那些重要但不紧急的工作上，这样可以做到未雨绸缪，防患于未然。

# 举个例子

# 水烧开了，孩子哭了，电话响了…

+   01 家里的开水壶烧开了，不及时处理就会溢出来
02 自己的孩子嘻醒了，哭着要让你抱，很可能需要换尿布
03 家里的电话响了，不知道是谁打来的，很可能有急事

# 石头、沙子、水…

讲着手拿空杯子，先往杯子里放石头，放满后大家这个杯子满了？人们会认识回应了。讲者再往里面放沙子，放满沙子讲者向大家满意了？之后讲者再杯子里加水…

引申思考：大趋势变化瞬间极快，不及时的事情，就风险，对学习条件较差的事件，...临时优先级...但做好的事，既可...

引申思考：假设思维…以认真设计流程完全验证，并牢系按流程遵守…

这个例子是大家日常生活中常见的困境/会经常遇到的事情。事实上在讲卡同学双亲急需反应的时候，我认为大姐姐可能可以先去不紧急的事物，或是是先整理得到反映的方式安抚... 期间...

# 巴菲特曾给其私人飞机员弗林特介绍过其确定优先次序的三步走策略

巴菲特让弗林特先列出他的前 25 个目标
他让弗林特选出 5 个
不管怎样，这些事情都不应该引起你的注意，除非你已经成功地完成了前 5 个目标

# 应用参考

+   01 写出你当前想要实现的多目标
02 运用优先排序识别你的“5”个目标
03 完成目标前，不考虑其他任何选项

总结:优先排序思维模型,即依照紧急、不紧急、重要、不重要、困难、不困难等六个维度来审视问题,以此帮助我们更好的做决策！
