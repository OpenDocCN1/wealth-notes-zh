# 73. 长尾理论思维模型

我们应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将有人智库通过“视觉语言”解读出来，为大家提供解决问题的可视化思维公式。

长尾（The Long Tail）或长尾效应，最初由克里斯·安德森（Chris Anderson）于2004年发表于自家的杂志中，用来描述诸如亚马逊公司、Netflix和Real.com/Rhapsody之类的网站之商业和经济模式。长尾效应是指当商品流通和储存的渠道足够大时，那些原来不受重视的销量小但种类多的产品或服务由于总量巨大，积累起来的总收益超过主流产品的现象。这个理论是信息化社会的必然发展结果，在虚拟商品中特别适用。“长尾理论”被认为是对于传统的“二八定律”的彻底颠覆。 MODEL MATH 模型结构

帕累托法则：被商业界视为铁律，其内诠认为企业80%的业绩来自20%的产品，而长尾理论认为互联网的崛起已打破这种藩篱，广泛的销售局面让98%的产品都有机会售出，而不只依赖20%的主力产品

过去我们只能关注重要的人和重要的事，如果用动态分布曲线将给这些人或事，人们只能关注曲线的“头部”，而忽视由曲尾、尾部、带更多的懒力 and 成长潜力能关注的大量分散且交易频繁、顾客网络的成员。自媒体平台增进了个人的影响力，一个普通人也可以通过自己的网络跟随影响力平台上个人的粉丝，成为“网红”。关注的成本极大降低，每一个音视频都蕴藏着巨大的机会，所以在联网网络时代，厂商们挖掘关注普通消费者。

Google是一个典型的“长尾”公司，其成长历程就是把“广告商和出版商的“长尾”商业化!以占据了Google半壁江山的AdSense为例，它面向的客户是数以百万计的中小型网站和个人小网站的媒体和广告商而言，这个群体的影响力微不足道。但是Google通过为其提供个性化制约的广告服务，把这些数量众多的群体汇聚起来，形成了非常可观的经济利润。

# ENLIGHTEN 启发应用

头部并非孤立一而是相对存在 外部主导与内部主导并存，随着社会的不断变化，长尾理论也并非完全颠覆二八定律的铁律性存在，而是在信息时代变化的条件下，长尾理论不断壮大到自媒体平台的用户生成内容时，消费者开始有了主导“内容创造”，从生产到消费，实现了自己决定消费，而不是通过渠道来营销，从而使得供给和需求的关系得到重构。每一家企业都应该从长尾的视角切入，创造长尾的商业价值。

长尾增长，而非长尾终结，只有当长尾相关的无限供给等于需求，加以成本下降时，长尾才会形成一个长尾经济，一个巨大的产业链，“长尾经济的根本原因是信息技术的发展带来的供给和需求的匹配效率的提高，随着互联网和数字化技术的发展，信息传播的成本大幅降低，从而使得原本不可见的产品和服务得以被发现和交易，长尾效应得以形成。

系统视角下长尾 学习了更多的揣摩机制，从而能够从众多多层面来理解复杂的系统结构，并且形成自己的管理行为。传统的管理思想关注大体量、大流量，而长尾理论则关注于小众、细分市场，通过信息技术手段，把分散的消费者汇聚起来，形成规模效应，从而实现可持续的收益。这是长尾理论的核心价值。

总结:长尾理论并不是鼓励我们违背这个法则，而是用系统的视角来整体看待时代、社会及个个人未来的方向。
