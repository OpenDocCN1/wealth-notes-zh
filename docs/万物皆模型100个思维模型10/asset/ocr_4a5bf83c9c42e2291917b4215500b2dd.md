# 60. 启发式偏差思维模型

我们应该以不同的方式去思考问题，以此对应这个变化万千的世界。因此我们前情“视觉谬误”翻牌出来，为大家提供解决问题的可视化公式。

因走捷径而导致的判断偏差，称为“启发式偏差”。当人们要对一个既复杂模糊又不确定的事件进行判断时，由于没有行之有效的方法，往往会走一些思维的捷径，比如：依赖过去的经验，通过对过去的经验进行分析处理得到启示，然后利用得到的启示作出判断，这些思维的捷径，有时帮助人们快速地做出准确的判断，但有时会导致判断的偏差。这些因走捷径而导致的判断偏差，就称为“启发式偏差”，查理·芒格对其偏差进行总结，提出“启发式偏差思维模型”。

# 结构拆解

代表性偏差

依赖判断事件本身经历的经验
的相同事件条件下的经验结果
忽略样本大小
忽略难易程度

+   - 样本越小，与真实数据越差距大
- 样本越大，与真实数据越差距小
- 当面对复杂难以判断的问题易导致判断
- 根据不规范的和与资料无明细的描述判断
- 忽略掉不熟悉的或看不信任的信息判断

导致判断偏差

EXAMPLE 1
很多入比较喜欢买均值币，如果某五次的结果都是正，那么第六次很大的会是负。因为这多个结果比较均值(其实每一次结果接近1/2 正负)。事实上，每一次抛硬币的结果是独立的，不论之前的结结果如何，下一次的结果是几乎半半正反。

可得性偏差

依赖最先到来的经验和信息

+   - 容易知晓的事件
- 易遗忘的事件
- 依赖短期的事件

+   - 对判断是没有必要的不断的
- 近期发生的不断事件
- 过去经常会发生的事件

导致判断偏差

EXAMPLE 2
飞机和飞机起个安全。几乎所有的人都会告诉你飞机更安全,飞机事故概率大,飞机事故的发生率远小于火车事故的发生率。然而一旦飞机出事,电台、电视、广播、报纸等传播媒体都会有头版消息,人们一听见,听说了许多相关信息。

导致判断偏差

EXAMPLE 3
假设 A 店与 B 店都陈列会统一的 99 元钢笔。A 店主要卖百元内的商品为主，所以顾客看到 99 元的钢笔，会觉得“贵”。但是 B 店大卖百元以上的商品，看到 99 元的钢笔，会觉得“便宜”。

# INSPIRATION AND APPLICATION

# 启发应用

你以为你以为的就是你以为的吗
一旦你的观点变成了你的信念，而信念又变成你行动的指南，你的思考过程就会减少，思维被固定下来，逐渐变得僵化。所以我们要保持警惕，对自己进行反省，检视自己是不是有这样的倾向，及时纠正自己。尤其是当我们做出判断时，应问自己是否受到了启发式偏差的影响。

保持空杯心态
人一生中应该保持对以下 1: 不断反思自己不断学习，并从实践中获取新的知识 2: 保持客观的态度，面对客观事实 3: 保持谦虚的态度，接受他人的不同观点 4: 不断更新知识，保持好奇心和探索精神。

用费曼技巧来破解固有认知
费曼技巧，人人自做简单解释的方法，需简单清晰的来阐述一个观点，只需通过三个步骤来解决问题，1: 选定主题2: 用简单的语言解释出来 3: 找出难以解释的部分（也就是你所不知道的部分）反复阐述，直至把你的固有认知和理解完全剥离出来，真正的实现自我认知，并成长。

总结,用后发法去快速应对常规事情，以谨慎的态度去应对不确定，认识到自己大脑的后发式偏差，最大化地规避决策陷阱。
