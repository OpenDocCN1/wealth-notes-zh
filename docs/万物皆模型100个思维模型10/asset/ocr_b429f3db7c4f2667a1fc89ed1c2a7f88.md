# 78. 周哈里窗 思维模型

我们经常应该以不同的方式去思考问题，以求更好地应对这个瞬息万变的世界。因此我将前人工智能通过“觉醒语”精炼出来，为大家提供解决问题的可视化思维公式。

周哈里窗 Johari Window 展示了关于自我认知和他人对自己的认知之间在有意识或无意识的前提下形成的差异，由此分割为四个范畴，一是开放我——指面对公众的自我整洁范围，即自己和他人都了解自己；二是盲目我，指被公众获知但自我无意识范围，即他人了解自己但自己不了解自己；三是隐藏我，指自我有意识在公众面前保留的范围，即他人不了解自己但自己了解自己；四是未知我——指公众及自我两者无意识范围，即他人及自己均不了解自己，也称为潜意识。

③ 与他人相处时，积极地收集他人的信息，增加自我认知，使自己知之大都了解自己就可以帮助自己与其他人更好地应对好环境。

# 举个例子
