# 09.六顶思考帽思维模型

我们应该以不同的方式去思考问题，以此来应对这个变化万变的世界。由此爱德华前人智慧通过“微波炉”翻译出来，为大家提供解决问题的可能性思维公式。

六顶思考帽 SIX THINKING HATS 是法国学者爱德华·德博诺 (EDWARD DE BONO) 博士开发的一种思维训练模式，或者说是一个全面思考问题的模型。它提供了“平行思维”的工具，避免将时间浪费在互相争执上。强调的是“能够成为什么”,而非“本身是什么”,是寻求一条向前发展的路,而不是争论谁对谁错。运用德博诺博士的六顶思考帽,将会使混乱的思考变得更清晰,使团体中无意义的争论变成集思广益的创造,使每个人变得富有创造性。六顶思考帽是管理思维的工具,简洁的操作框架,提高团队 IQ 的有效方法。

# 使用六顶思考帽的方法：

+   - (1) 聚集并思考想法和过程
- (2) 鼓励创意,平行和水平思考并重
- (3) 改进功能
- (4) 加快决策
- (5) 避免争论

# 关于思考的安排,控制

+   1. 我们时的控制点是？ 现处什么阶段？
2. 这个过程的步骤是？
3. 下一步的方向是？

# 客观思考,事实,数据和信息

+   1. 我们有什么信息？
2. 我们还需要什么信息？
3. 我们如何获得需要的信息？

# 直觉思考,感觉,预感与直觉

+   1. 我现在什么感觉？
2. 我的感觉是什么？
3. 我的常反应是什么？
