# 75. 飞轮效应思维模型

我们都很应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们特意从人智慧通过“视觉语言”翻出来，为大家提供解决问题的可视化思维公式。

人在进入某一新的或陌生的领域的时侯，都会经历这一过程。如果要让飞轮转起来不花大代价，条件是要有足够的坚持，这也意味着要得时间足够来保证。“飞轮效应”让我们看到胜利的曙光，只要我们坚持不断地推动事业的飞轮，总有一天，它会自己飞快地旋转起来，而无需耗费多大力气。当达到一个很高的速度后飞轮所具有的动量和动能就会很大，使其短时间内停下来所需的全力就会很大，便能够克服较大的阻力维持原运动。飞轮效应为了使静止的飞轮转动起来，一开始你必须使很大的力气，一圈一圈反复地推，每转一圈都很费力，但是每一圈的努力都不会白费，飞轮会转动得越来越快。

# ENSAMPLE 单黑子

贝索斯为亚马逊设计了一个“增长飞轮”，其核心驱动模型是：低成本结构 → 更低价格 → 更好客户体验 → 更多流量 → 更优质供应商 → 更低成本结构。贝索斯“增长飞轮”的底层逻辑就是，用户的追求是不变的，即用最低价格买到最好的产品。

FORWARD FLYWHEEL 正向飞轮 努力 → 过程 → 反馈
REVERSE FLYWHEEL 反向飞轮
GAME OVER

飞轮效应的反面是“死亡循环”。陷入死亡循环的人或企业同样想实现成长变革，但因缺乏足够的热忱去产生飞轮效应，反而以一种狂躁的热喘去推动变革，想法一口气吃个大胖子，他们的战略往往只有一个方向，一旦遭到挫折之外的抵抗，离开战略另一方向——失败之后不是进行很好的反思，而是“脱胎换骨”，开始新的改革运动——继续失败。
