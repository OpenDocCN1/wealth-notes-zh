# 50.邓克效应思维模型

我们应该尝试以不同的方式去思考问题，以此应对这个瞬息万变的世界。因此我将用“视觉语言”翻译出来，为大家提供解决问题的可视化工具书。

邓宁-克鲁格效应 (Dunning-Kruger effect)，简称邓克效应或达克效应 (DK effect)，亦称井蛙现象，是一种认知偏差，能力欠缺的人有一种虚幻的自我优越感，错误地认为自己比实际情况更加优秀。大卫·邓宁和贾斯汀·克鲁格将其归结为元认知上的缺陷，能力欠缺的人无法认识到自身的无能，不能准确评估自身的selected... 能力 他们 的研究还表明，反之， 非常 善于的人会低估自己的能力，错误地假定他们自己能够很容易完成的任务，别人也能 很容易地完成。但能力欠缺的人对自己的能力的评估并不比能力较佳的人高。

模型结构

# 模型拆解

1. 对特定任务不熟练的人通常会高估自己的技能水平，但他们能从他人的反馈中意识到自己能力低下；
2. 对特定任务熟练的人会更正确认自己的真正水平以此找到自己的水准；
3. 对特定任务熟练的人会认为自己还不够好，以及其他人之所以擅长，
4. 如果对特定任务熟练的人能意识到自己的能力大幅度提高之后，他们便会意识到他们之前的能力程度，

# 第一阶段 虚假之巅

在第一个阶段的人，通常不知道自己无知，察觉不到自己的能力不足。完全被自己的认知所局限，导致他们对自身的认识严重失调。因为他们缺乏足够的知识和经验，所以根本无法认识到“无知”的存在。

在流行文化中，邓宁-克鲁格效应常被错误解释为低智商人对自身智商的错误估计，而不是特指在任务不熟悉的人对特定任务的错误认识。

总结:无能者的错误标度源自于对自己的错误认知，而极有才能者的错误标度源自于对他人的错误认知。
