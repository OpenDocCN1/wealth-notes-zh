# 57. 复利效应思维模型

我们整个应设法以不同的方式思考问题，以此应对这个瞬息万变的世界。因此我们将前一智慧透过“视觉语言”输出出来，为大家提供解决问题的可视化思维公式。

复利是一种计算利息的方法，即复合成息，利滚利，把上一个期的本利和作为下一期的本金来计算。最简单的复利公式：收益 = 本金 × (1+ 利率)^ 周期。按照这种方法，利息除了会根据本金计算外，新得到的利息同样可以生息，因此俗称“利滚利”、“驴打滚”或“利叠利”。只要计算利息的周期越快，财富增长越快，而随着年期越长，复利效应亦会越来越明显。复利是现代理财一个重要概念，由此产生的财富增长，称作“复利效应”，对财富可以带来深远的影响。

# 复利思维模型公式

FV(Future Value)是指财富在未来的价值，即收益
FV=PV(1+i)^n  — n 则是累计的周期，即期数
i(interest)是指周期内的固定利率或固定回报率
PV(Present Value)是指现值，亦即指本金

THE VISUAL THINKING PATH OF COMPOUND INTEREST
利滚利的可视化思维路径
做事情 A 得结果 B
循环往复
而结果 B 反加强 A

行动结果 = 认知 *(1+i)^n

# INSPIRATION AND APPLICATION

复利三要素之本金积累
如果说复利的原动力是本金，那么你就要有足够的本金，创业、做生意、理财等方式，增加自己的本金积累，复利才会产生。

复利三要素之提高利率
在一定的本金下，你要想办法提高回报率，提高利率，提升收益率，让复利速度加快，比如投资、学习、技能提升 十年才会有效果，教学相长也是一种复利。此外投资从各渠道获取较深投资理财知识，学习投资学，懂得投资规律，从而提高收益率，积累更多本金。

复利三要素之时间
复利的核心逻辑是时间，你要让财富持续复利，越长的时间，复利效应越明显。时间的价值在于持续、坚持和积累。你要持之以恒地投入，长期持有，复利才会产生。对于每个人而言，时间是公平的，时间越早开始，复利效应越强。

> 总结：查理·芒格说：“理解复利的魔力和获得它的困难是理解许多事情的核心和灵魂。”
