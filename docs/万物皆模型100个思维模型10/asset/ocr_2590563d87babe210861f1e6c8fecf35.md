# 81. 推论阶梯思维模型

我们常使用不同的方式去思考问题，因此 ya 对这个复杂万变的环境。因为我们拥有人类智能通过“被动语言”翻译出来，为大家提供解决问题的可能性思维公式。

推论阶梯 Ladder of inference 即在没有意识到的情况下，人从事实到决策或行动所经历的思维过程。思维阶段可以看作一架梯子的不同阶级，数据位于梯子的最底部，假设、结论、信念和行动位于梯子的顶部。处于执行模式时，我们会根据有限的数据快速得出结论，我们每个人需要放慢脚步，培养耐心、保持开放，倾听谅解词，不断询问再下结论。在做出任何决定前，我们必须意识到我们存在核心偏见和测谎。推论阶梯是用来检视我们思考过程的工具，能够帮助人们学会更好地认识自己的思维和逻辑推理方式。

# 启发应用

# 行有不得，反求诸己

孟子曰“行有不得，反求诸己”。我们对于“学习”时需要随时检验自己的思维和行动是否合乎正解。如果我们遇到的任何疑惑，都应该先检查自己的思维模式是否正确，而这正是推论阶梯的价值所在。通过推论阶梯，我们可以不断反思，调整自己的认知，以更好地适应变化。

# 由单一向双向循环

知识和实践的互动是双向的，从经验中学习并通过实践验证知识，形成闭环。

# 打开思维的黑箱看看

打开思维的黑箱，审视自己的思维过程，能帮助我们更好地理解问题。

总论:当我们经验足够多或现象得更全面时，问题就会更全面。如果做得到从错误中积极提炼更好的“想法”，就会形成一个正反馈循环。
