# 21. 冯诺依曼思维模型

我们经常应该以不同的方式去思考问题，以此来对待这个系统万变的世界。因此我们将前面人类普遍通过“貌似奇据”翻出来，为大家提供解决问题的可视化公式。

冯诺依曼思维是将一个复杂问题拆解成一个可执行的简单单元，然后将简单的单元重新组合成具有某种意义指定属性的大问题。由以上定义可知，该模型具体包括两个部分，一是把复杂大问题拆解成一个个小细节；二是把一个个小细节组合成具有某种意义的大问题。

# 拆分≠拆解

# 拆分是将一个整体的不同部分单独拆分开

拆分公式 | 整体 = A + B + C + …

# 拆解是将整体拆解成一个可执行的简单事情

拆解公式 | 整体 = A × B × C × …

# 重新组合

创新并不是创造全新的事物，而是把不同的系统要素重新组合起来形成新事物，新系统的过程。

互联网 + = 互联网 + 传统行业

“互联网+”简要的说就是“互联网+传统行业”，固定制造业等的发展，利用互联网和传统行业相连，提高、改善互联网与传统行业结合，即两个不同系统的重新组合创新。

婴儿摇篮 = 玻璃盒子 + 恒温系统

19世纪80年代初，波兰军官学L.S.蓝氏 非常流行地与4次在德国儿童一个在学 会会会的当先进，他们大多来自于物理生物于 另一个系统结合的新型教具这一切。

思维模型 = 模型概念 + 认知图形

大多数所看到的思维模型图是介于如图基础 上用图形+文字的组合来形成概念认知 这给读者。两者的数学的构建成事，就要从原 而表达的准备必须严格正比。

总结:该模型的本质是“拆与组”，“拆”要拆解（找到问题本质），而非拆分。用错了“拆”，也就用错了“组”。
