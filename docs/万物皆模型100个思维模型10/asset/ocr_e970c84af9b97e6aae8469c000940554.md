# 63. MECE原则思维模型

我们应该以不同的方式去思考问题,以此来应对这个变化万千的世界,因此我们将前人“智慧结晶”翻箱出来,为大家提供解决问题的可视化模型公式。

MECE 原则或称 MECE 分析法, 是 Mutually Exclusive Collectively Exhaustive, 中文意思是“相互独立, 完全穷尽”。也就是说对于一个重大的议题, 能够做到不重叠、不遗漏的分类, 而且能够信此有效把握问题的核心, 并解决问题的办法, 即所谓“不重不漏”。是把一些事物分成互斥 (ME) 的类别, 并且不遗漏其中任何一个 (CE) 的分类方法。该思想的起源最早可以追溯到亚里士多德。MECE 原则在进行商业计划的过程中很有用, 在这一过程中, 信息分类的最佳效果存在, 且分类效果最佳时不会把任何信息放入两个不同的种类。

A 去询问自己的代餐香产品, 目的是否交换一个产品包装升级的, 换句话说, 宝宝及婴儿等就其它等家将会用到, 换用户第一项第三方供应商, 按我这里及这样对应的时间, 及产品在发货前是否能提供一个产品及用户体验等以此判断反馈体系, 在和谐等级时间, 提出产品咨询等提到用户体验。
