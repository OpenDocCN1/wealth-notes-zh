# 44.能力圈思维模型

我们整个应以不同的方式去思考问题，以此来应对这个信息万变的世界。因此我们希望“视觉语言”解读出来，为大家提供解决问题的可视化思维公关。

芒格说一个人在一生中可以真正得到的真见识仍然非常有限，所以正确的决策必须局限在自己的“能力圈”以内。“能力圈”概念是1996年，巴菲特在伯克希尔·哈撒韦的年报中提到的概念，是为了解释为什么在互联网行业形势如此之好的环境下，自己不投的原因。互联网超出了我的能力范围了，所以不投——也正因为不懂不投的理念，帮助巴菲特在投资上少犯很多的错误。能力圈即通过学习和实践，在某些领域积累的知识，且知道自己知道这些知识和知道自己知道知识的边界。

# 启发应用

能力圈并非固定不变，而是一直在变
本我，这些小圈子里，并不是一个固定的圈，也不是一个圈，成长是一个不断循环的过程。我的能力圈就是这个圈，所以我们也需要不断地调整。能力圈是不断变化的，它随着我们的认知而变化，随着我们的学习而变化，随着我们的经验而变化。随着我们的改变，它也在不断地改变。

成长圈的目的地——求得本我
掌握环境，1. 本我，自我认知是影响行为的重要因素。好环境通过过程内有自然的环境，调整方向，从而达到自我与环境合一。2. 通过自我认知，调整环境，3. 通过自我认知，调整环境，寻求环境与自我合一，形成知识体系。总体而言，能力圈并非固定不变，仅在不断改变。

总结：生活中间面对问题、决策时，去思考是否存在于自己的能力圈内，并且只在自己明确界定的能力圈内行事。
