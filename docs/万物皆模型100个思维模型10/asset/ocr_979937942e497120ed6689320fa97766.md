# 24.替身决策思维模型

我们常常应该以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们前人智慧累积“貌似谬误”留出条，给大家提供解决问题的可能性思维公式。

替身指的是替别人的人，对本体而言，指替代本体的人。生活中则是模拟决策人所处的环境及其背景，去做决策的场景代入法，让替身有一种身临其境的感觉和思考过程，此时你就是决策者，你需要对这个决策负责责任和义务，也有相应的权利并为此做出决策。简言之替身决策思维就是站在他人的角度或换成特定角度去做决策的一种思维方式。

# 模型结构

# SURROGATE DECISION MENTAL MODELS 替身决策思维模型

替身 OR 分身 站在对方的角度思考问题

# 举个例子

# 立场不同 少说多做

立场不同，所处的环境不同，提供的值值不同，很多事情如果是一双见 况不妥结论，用替身思维模型（或称转换思维模型）换己所处岗。

收人将信将人告诉他出了事，只听大人吩咐，陆地反而反对和配合时反而不妥结论，换体制人设说设被说，都是很烦所以大声门时。

设想对方清楚永远亲耳听见，我人说 但是，只是为了帮您的毛绒到牛奶， 牛奶的口味，却好像没办法！ 听见这个声音很舒适的！

# NLP位置感知

位置感知，在NLP心理上指的是，试着换个“位置”，多角度去思考问题，就会产生不同的想法和感受、态度。而这样的“位置产生观点”，称为“感知位置”。如下介绍五个感知位置：

+   ① 自我位置
(1) 凡事以自我为核心，更关注自己的感受和感受。
(2) 对自己和自己谈话，发怒，反感。

(3) 与对方的立场，这就是同理

NLP 讲究灵活应变，对相同事物有多不相同观点，并对各种不同的观点予以尊重。灵活移动感知位置，有助于发展观点的弹性，善于移动感知位置，拥有多重观点，让人行动皆有理。因为各种不同的观点，互相补充互补，可以增加更多资讯，更好地处理，使人不致于陷入僵化或让思维的闭锁感。
