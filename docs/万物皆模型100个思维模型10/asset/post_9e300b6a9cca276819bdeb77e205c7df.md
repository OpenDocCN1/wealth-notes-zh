# 26. 局部、全局最优思维

我们常常习惯以不同的方式去思考问题，以此来对应这个瞬息万变的世界。因此我将前人智慧通过“视觉笔记”翻译出来，为大家提供解决问题的可视化思维公式。

LOCAL OPTIMAL SOLUTION 局部最优解 和 GLOBAL OPTIMAL SOLUTION 全局最优解 是数学中的两个概念。局部最优是对于一个问题的解在一定范围或区域内最优，或者说解决问题的手段在一定范围或限制内最优。全局最优是针对一定条件或环境下的一问题或者目标而言，若一项决策和所有解决该问题的决策相比是最优的。

+ 03 B 够稳定后通过叠加升级 B → A

### A GLOBAL OPTIMUM 全局最优

### B LOCAL OPTIMUM 局部最优

# 30. 自催化思维模型

我们尝试以不同的方式去思考问题，以此来应对这个瞬息万变的世界。因此我们将前人智慧通过“貌似谬言”翻讲出来，为大家提供解决问题的可视化思维公式。

自催化是指不添加催化剂，而由反应产物起催化作用的反应。该类反应的特点是起初阶段反应速率较慢，随后反应速率逐渐加快，最后速率再次变慢。自催化反应是指反应物本身具有催化作用，能够加速或减慢反应的进行的一种反应，如火药热分解产物 NO2 即可对该反应起到自催化作用；我们常接触到的白酒、醋糖的发酵也是典型的自催化反应。

## 模型结构

### 起始速率较慢，随后加快又变慢

反应速率随着反应物浓度的提高而提高

反应速率随着产物浓度的快速提高而增大

由以上分析可知自催化反应的三个特点

+ 01 反应物中加入少量的产物
满足初始条件,促使其反应开始
+ 02 反应过程中必然存在一个最大反应速率
+ 03 反应速率随着反应的进行会经过先增大后减少的变化

# 31. 优先排序思维模型

我们能够思考以不同方式思考问题，以此来应对这个瞬息万变的世界。因此我前人智慧透过“领悟请”翻译出来，为大家提供解决问题的可能性思维公式。

优先排序思维模型是时间管理理论的一个重要方法，世上万事万物均有其根本的因，也有末端的那个果，在面对因与果、根与末的时候， priorit... 优先排序即是让我们能够有重点地把主要的精力和时间集中地放在处理那些重要但不紧急的工作上，这样可以做到未雨绸缪，防患于未然。

## 举个例子

### 水烧开了，孩子哭了，电话响了…

+ 01 家里的开水壶烧开了，不及时处理就会溢出来
+ 02 自己的孩子嘻醒了，哭着要让你抱，很可能需要换尿布
+ 03 家里的电话响了，不知道是谁打来的，很可能有急事

### 石头、沙子、水…

讲着手拿空杯子，先往杯子里放石头，放满后大家这个杯子满了？人们会认识回应了。讲者再往里面放沙子，放满沙子讲者向大家满意了？之后讲者再杯子里加水…

引申思考：大趋势变化瞬间极快，不及时的事情，就风险，对学习条件较差的事件，...临时优先级...但做好的事，既可...

引申思考：假设思维…以认真设计流程完全验证，并牢系按流程遵守…

这个例子是大家日常生活中常见的困境/会经常遇到的事情。事实上在讲卡同学双亲急需反应的时候，我认为大姐姐可能可以先去不紧急的事物，或是是先整理得到反映的方式安抚... 期间...

### 巴菲特曾给其私人飞机员弗林特介绍过其确定优先次序的三步走策略

巴菲特让弗林特先列出他的前 25 个目标
他让弗林特选出 5 个
不管怎样，这些事情都不应该引起你的注意，除非你已经成功地完成了前 5 个目标

## 应用参考

+ 01 写出你当前想要实现的多目标
+ 02 运用优先排序识别你的“5”个目标
+ 03 完成目标前，不考虑其他任何选项
