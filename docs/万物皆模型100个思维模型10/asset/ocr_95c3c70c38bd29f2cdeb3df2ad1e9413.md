# 12.笛卡尔思维模型

我们应该应以不同的方式去思考问题，以此来应对这个瞬息万变的世界。由此我们将前面人曾经通过“微说话者”铺述出来，为大家提供解决问题的可视化思维公式。

笛卡尔说，唯一独自己的思考是可以相信的，世界上所有的事情都是值得被怀疑的，但是唯独“我怀疑和思考这个世界”这件事情是不能被怀疑的，所以，只有我们思考和认识到的事情，我们才能真的接受，其余的都是存疑的。这种怀疑的意义就是去追问问题的本质，去寻找事物的特征，从而通过严密的逻辑建立学科的基础。

# 模型结构

怀疑 DOUBT → 解析 ANALYSIS → 整合 UNIFY → 检验 CHECKOUT

# 结构解析

客观审视 why → 怀疑 → 解析 → 整合 → 检验
构建自己的认知大厦

# 观点事件
我们身边发生的任何事情，任何观点，都不要轻易的接收。

# 保持怀疑
凡是有明确认识到的东西，绝不真的接受，要继续保持怀疑的态度去拆解和先入之见。

# 分析解析
把需要研究的难题进行合理分解和分析，分层块状处理。

# 整合封装
先分后难，一层一层逐步识别，最后合并，再从大到小，向上传导，直到认识到最复杂的对象。

# 完善检验
尽可能全盘的考察，认真地验证，保证最大程度的无遗漏。

# 举个例子

观点事件
据说第三级分音曲线是拉格码尼尼最难，第五级“拉三”是世界最难弹奏的钢琴曲

保持怀疑
为什么是最难弹？难在哪里？难在哪里？和弦太快？太耗体力？

+   分析解析
1. 整首曲子分成段
2. 每一段拆成和
3. 每个音拆成音符

+   整合封装
1. 先从每个音开始
2. 再从每拍开始
3. 再从每段开始

完善检验
在整个过程中，遇到问题反复练习，再输出，以此类推，直到弹奏整首曲子

当你能够弹下整首曲子时，这个据说世界最难的曲子，只是相对而言。

# 构建自己的认知的过程，是一场拨云见日的过程

> 总结生活工作中培养自己的笛卡尔思维，即培养自己的逆向性思考，善于怀疑，并通过分析解析，统一整合，实证检验来获得一个科学可行的方案。
