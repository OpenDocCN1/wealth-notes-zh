# 37. 升维打击思维模型

我们经常应该以不同的方式去思考问题，以此来突破这个常规万变的世界。因此我将前期人类通过“微笑曲线”阐述出来，为大家提供解决问题的可视化思维公式。

P11 讲述升维思维模型指在原有的维度上不能解决问题，只能显现问题，只有换一个维度才能解决问题。在说升维打击思维模型前，先谈降维打击，将攻击目标本身所处的空间维度拉低，让目标无法在低维度空间中生存从而毁灭目标，而升维打击则是利用主动拉升自身空间维度，即高于相同行业竞争对手的技术、标准、系统或模式，以此对竞争对手实施不对称（即不同维）打击，从而更快地占据市场的思维模型。

# 启发应用

# 升维降维打击的本来

三个维度如何去描述它们，但从战略角度区别开来。设想先加入产品和核心竞争力和能力，核心竞争力的核心在后，再把内容提升到技术、产品、系统等层面，企业需要通过不断地提升自己的能力，特别是技术、模式、系统等，以此让竞争对手无法跟上。

# 提升长远维度的能力

提升长远维度的能力是将竞争的视角从短期转移到长期，通过建立系统的知识、方法和体系，提高在竞争环境中可持续发展的能力，从而在长远竞争中保持优势。

# 专注多维度的视角

多维度的视角和系统的思维模式，需要同时关注不同维度的发展和变化，通过构建多维度的竞争战略，实现在不同维度的领先和协同，从而在复杂竞争环境中获得持续优势。

总结:主动将自身所处的空间维度拉高（自身能力的培养）目的是让对方无法在同维度空间中生存从而被市场淘汰。
