# ## （3）哪些影响命运的因素是可控的

第三个社会定位，是个人所在的社会，处于什么样的社会历史进程。

经过认真的观察，我发现有五个因素可以影响一个人的命运：

+   - （1）原生阶层
- （2）自己
- （3）他人
- （4）运气
- （5）社会历史进程

这五个因素中，原生阶层是完全不可控因素，谁也无法选择到底出生在哪个家庭，哪个阶层里。用巴菲特的话说，如果出生在较高的阶层，一出生就含着金钥匙，那就是一种“自然彩票”。

像王思聪这种，作为“幸运精子”，就属于中了自然彩票。

当然，巴菲特本人也算是中奖的人，虽然不是大奖。他父亲是议员，同时也做过股票经纪人。

只是必须看到：巴菲特收割财富，主要凭的是自己的实力，而不是原生阶层的荫庇。他的原生阶层也许通过教育传递了些内在实力给他，但还没有可以让巴菲特不自己努力，就可以大把抓钱的能耐。游戏规则也不是这样的。

相对来说，一个人是可以把控自己的，他的实力，更是可控因素。

比如巴菲特可以选择炒股还是当老师，可以选择是不是要洞察人心，就像你可以选择下班了就打游戏，还是学点社会人心运作的知识一样。
