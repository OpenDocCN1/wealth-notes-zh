# 为什么叫心理结构？

因为心理就像是一个大仓库，深不见底，堆太多东西了，你今天爱这个人，明天恨那个人，你10年恐惧某个事物，10年后渴望某样东西，还有本能、欲望、情结、各种情感，非常之多。它们甚至都没有经过任何整理，堆在心理，在某种机制（心理机制）下，就构成了一个结构。所以叫“心理结构”。

总之ABCDEFG，在某种机制下，一会儿排成一字形，一会儿排成人字形，就是一个结构。

# 你单位或公司呢？

从领导，到副手，到中层，到基层，在机制和游戏规则下，也形成了结构——权力结构和利益结构。

如果有了结构概念，理解社会是一个庞大、复杂的结构，也就不会有障碍了。

社会学在考察社会的一些东西时，直接就会把它说成‘社会结构’。

那么社会是一个什么样的结构呢？

真实情况是，它比蜘蛛网要复杂N倍。就像经度和纬度一样，我们要从横向和纵向来理解。

就横向而言，按宽松的标准，中国9亿多人口构成了结构下面的一些层级，有农民工、小商贩、快递员、农民、五保户……近4亿中阶层，同样分布在中间的一些横向的纬度上。人数不详的社会上层，分布在上面的一些横向的纬度上。
