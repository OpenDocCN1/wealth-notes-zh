这个机制反吞噬的结果。

这好像是反面的。

正面的呢？还记得 2020 年疫情期间 “破格提拔”的人吗？

在那段时间，体制内的运作机制，要求出现有大担当的人，而那个时候，有些人站出来了。请问，如果你是领导，为了激励这个机制运作得好，是不是要破格提拔一下站出来的人？

没有这个杠杆，一些人可能这辈子，都没有上升机会。

# 5）金融杠杆

这个好像就不用说了。很多人，很多企业，都要玩金融类杠杆，从按揭买房到上市融资，莫不如此。

# 5）游戏规则杠杆

游戏规则分配利益、心理、社会实力，及维持社会运作的。既然是分配利益、社会实力，那它就是一个杠杆。

不仅是一个杠杆，而且是被普遍运用的大杠杆。它的放大倍数，甚至金融杠杆都望尘莫及。

现在说起 “陈永贵” 这个名字，很多人肯定不知道。但你百度一下，会发现他原来就是半文盲，山西省昔阳县大寨村党支部书记，一路往上，1975 年做到了国务院副总理。阶层相当于从弱 6，攀升到了弱 1。

原因是什么？是 “农业学大寨”。是这个游戏规则。全国农业都要学大寨，要达到这个效果，你觉得，陈永贵来当分管农业的国务院副总理，是不是很符合逻辑？

事实上，在体制内，以及科层化管理的公司里，无数人几乎是利用游戏规则的杠杆攀爬上去的，不符合游戏规则，或和游戏规则对抗的，几乎不可能放大自己的社会实力，也许干了很多年，还是那个位置。

# 6）趋势杠杆

雷军当年说过一句话，“在风口上，猪也能飞起来”。说的其实就是趋势杠杆。

就算内在实力有限，没法 N 倍放大，也能分沾到它的 “流量损摘”，总会有滴到你那儿。
