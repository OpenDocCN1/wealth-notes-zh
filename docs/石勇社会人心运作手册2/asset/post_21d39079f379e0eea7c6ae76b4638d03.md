
我们因此可以得到势的第一个公式：

势 = 趋向 + 大众的选择方向 + 实力 + 正确

可以根据这个意思下一个定义：所谓趋势就是在社会中或在社会时空中在特定社会状态或氛围中所表现出来的就好像是正确的拥有实力的或者有关选择的某些趋向或趋势。

从势的第一个公式中我们可以看到，能够形成势的东西，其实就是人（体现为人心）、资源、观念、社会机制。

所以我们有了势的第二个公式：

势 = 人心 + 资源 + 观念 + 心理 + 社会机制

在这个公式里，势意味着，在某个社会时空中，人、资源、社会观念、心理机制、社会机制，往某个方向跑了，从而形成巨大的实力、流量、能量。

前面第一个公式，是关于势的定性分析。势就是趋向、大众的选择、实力、“正确”的相加。

第二个公式，是关于势的定量分析。势就是人心、资源、观念、社会机制的相加。

如此一来，势的身影也就不再模糊了。

定性分析，主要涉及的是“如何判断势”的问题。而定量分析，主要是“造势”“控制局势”“顺势而为”，以及博弈时给对方“去势”等技术性操作。

## 3、如何判断大势？

下面我们分别来讲。

先说对势的判断。

萧何、曹参为什么不敢当带头大哥？是因为无法判断总的趋势，对沛县起义的那一帮人所代表的势也没有十足的信心。

黎元洪为什么开始不敢坐湖北军政府都督的位置，连说“莫害我，莫害我”？同样是以为大势还在清朝一边，没法未卜先知地看到推翻帝制、各省独立、建立民国这样的天下大势。

搜狐没有看到移动互联网的趋势，诺基亚没有看到智能手机的趋势，也是如此。

我们没法看到大势的第一个重要原因，是社会是高度复杂的，远不止一种势，而是N种，我们搞不清楚哪一种势最终会怎样，甚至都不一定能够看到关键的势。

用革命领袖恩格斯的话说：“历史是这样创造的：最终的结果总是从许多单个的意志的相互冲突中产生出来的，而其中每一个意志，又是由于许多特殊的生活条件，才成为它所成为的那样。这样就有无数互相交错的力量，有无数个力的平行四边形，而由此就产生出一个总的结果，即历史事变，这个结果又可以看作一个作为整体的、不自觉地和不自主地起着作用的力量的产物。”

换句话说——

- 有无数种势。
- 在运作、博弈中，有的势会强化，占据重要位置，有的势会弱化，甚至消失。
- 最终的结果，会形成一种“天下大势”。
- 当然，仍然有很多小势，在其运作的时空里，依赖于某些条件继续存在。

在这无数种势中，我们知道哪一种会成为大势吗？

好像很难。

我们没看到大势的第二个原因是，社会是一个生态系统，各种势不仅有物理属性，也具有心理属性，随时在此消彼长。有复杂的心理机制和社会机制，导致某种很强的势可能会消亡，而某种很弱的势也许会变强，当然也可能很弱的势会一直继续存在，很弱的势则难有出头之日。

现在我们都知道，互联网是多么厉害。互联网公司的利润，让制造业等黯然失色。2020年6月23日，腾讯的市值是46717亿港元，阿里巴巴的市值是46572亿港元；马化腾身家达到534亿美元，马云则达到440亿美元。

但这是从现在去看。如果时间回到20世纪90年代末，尤其是1997年、1998年，就不会有多少人能够看到，互联网从那时起就是一个大势。

马云看到了，但他几次创业失败，被很多人认为是骗子。

我们没看到大势的第三个原因，是不知道是哪些重要的变量，加入了社会运作，以及，社会的运作，会被什么类似于“黑天鹅事件”的变量所改变。

前一种变量，是社会内部产生的变量，具有某种规律，倒好说。比如随着中国的经济发展，工业化就必然意味着要城市化，也就意味着农村的人口会越来越少，这是谁都可以看到的大势。但后一种变量，却具有偶然性，没有什么规律可言，就很难预先看到了。比如2020年初出现在全球蔓延的新冠疫情。

所以，基于技术难度，要看到大势，我们只能用公式来进行定性分析。

回到1911年10月。那个时候，中国社会存在N种势。最大的势是清朝的统治，从政治军事力量到社会资源都掌握在它手里。但还有其他很多游离于清廷的势之外，甚至和清廷对抗的势。比如地方的“议会力量”（咨议局），比如科举废除后失意的读书群体，比如要推翻清朝统治的同盟会等革命党，比如受种族主义影响对满清统治不满的民众，等等。

如果所有这些势放置在一个静止的社会结构里；作为一个生态系统，并不随时间的流逝，以及它的运作而发生变化，那么，看上去，当然清朝廷的势最大，其他势都不值一提。如果有人敢起义，那清朝肯定会把它扑灭，就像两百多年前那样。

事实上，在武昌起义前，革命党已经组织发动了多次起义，其中影响最大的，是广州黄花岗起义。但这些起义都失败了。

黎元洪目睹了这一切。他大概就是在那个时间段里，从静止的角度来看势的。得出的结论当然是清朝廷的势远超出其他势，革命就是找死。

可是从生态系统运作的角度看呢？如果能找到关键的变量呢？如果能够分析当时的心理机制和社会机制呢？

毕竟，势 = 趋向 + 大众的选择方向 + 实力 + 正确。我们先用这个公式，来比较一下太平天国起义和辛亥革命。

太平天国起义代表历史趋向吗？其实不。

它发生在1851年到1864年间。那个时候，清朝的统治已经相当腐朽，贪污腐败，民不聊生，按照中国的王朝周期律，这已经是王朝的末期了。所以起义代表了一种大势——建立新朝代。

但这个大势，到太平天国打下大半个中国，在南京建都为止。原因在于出现了这个极关键的变量：全球化。

西方从大航海，到工业革命，到全球殖民，开启了全球化进程，终结了古代社会，“现代性”的逻辑摧枯拉朽，对于古老的王朝社会、部族社会完全是降维打击。清朝之所以被打得一败涂地，根源就在于社会结构还是一个王朝社会，比由资本主义和现代性武装起来的英国低了一个维度。

而从1840年开始，全球化和现代性的逻辑已经影响到中国，中国的社会结构已经悄然开始向现代性转型。这是最大的大势。所以，太平天国的“专制制度式”的改朝换代，而不是“资产阶级革命”，并不符合社会演化的趋向。放大视野，太平天国肯定最终失败。

再看大众的选择方向。

如果纯粹是“阶级斗争”式的起义，追求以“天朝田亩制度”所说的那些东西为纲领（事实上它从未实施过），那么，肯定会有非常多的人加入。从这个角度看，太平天国还是符合大众的选择方向的。

问题是，它是通过宗教，而不是政党组织起来的起义，宗教色彩相当浓厚，是有很强的组织效率，但组织效率具有限制性，无法达至全国范围。毕竟不信拜上帝教和不是为了活命的人，都对它没有认同。从历史上看，有很多造反或起义确实是以宗教为号召或组织体系的，比如黄巾军，比如明教，但从来没有一次改朝换代的成功是靠打宗教的旗帜。阶级、种族、天命、文化等层面的号召，才是大众的选择方向。

我们看实力。

太平天国的实力还可以，而清朝的八旗和绿营早已烂透。所以太平天国对清军作战一度像秋风扫落叶一样。但清朝能够组织起来的实力，要比太平天国广泛。比如曾国藩等人就可以组织具有“私家军队”色彩的兵勇。

最后再看一下“正确”这个指标。

太平天国打的是宗教牌。它本来可以打别的牌的。而打宗教牌，它对儒教的各种“破除”，非常不符合从底层民众到士绅阶层千年来的文化观念，因而引起他们强烈的反感和抵触。在他们看来，太平天国这种搞法无异于“亡天下”，因此对太平天国的痛恨使他们站在了清朝一边。

从定性分析来说，太平天国代表了王朝周期律上的大势，不代表社会演化的大势。

武昌起义呢？

武昌起义发生前，包括清朝统治最高层在内，都清楚：中国自1840年以来，之所以被西方列强打得一败涂地，是因为从器物到制度等“体系性”都不如西方。实际上就是西方已经进入现代社会，你还在做中世纪的梦。所以，清廷进行了“君主立宪”式的多种改革，比如废除科举，比如兴办新军（武昌起义正是新军里的革命党发动）。只是，清廷当然不想像英国、日本那样“虚君立宪”。

但社会演化的趋向，就是终结君主专制，建立现代国家。所以武昌起义所代表的辛亥革命，是历史的潮流，符合趋向，代表了大势。

它也是大众的选择。除了革命的口号，它还有很多“反满”的口号，蓄积了推翻满清统治的能量。

从实力上来说，一开始，确实看不出革命党有多少实力。但是，这只是一个错觉。从太平天国被曾国藩、李鸿章镇压下去开始，汉族官员和地方督抚就开始坐大。1900年，在清朝廷对外宣战，引发八国联军侵略时，两江总督刘坤一、湖广总督张之洞、闽浙总督许应骙等人，竟然在上海和各国领事敲定了“东南互保”之事，说明清朝的政治结构已发生重大变化，地方的权力已非常大。清朝所控制的社会实力，只是一个形式上的，只要有什么冲击，就能够动摇其统治体系的瓦解。

更何况，咨议局之类机构的设立，说明地方士绅，其实已经在很大程度上影响了地方政局。这些都是清朝的离心力量。

所以，实力结构是否发生巨大变化，看的就是武昌起义引发的心理机制和社会机制，其连锁反应效果如何。从各省都有革命党来看，连锁反应效果不错。

至于“正确”这个指标，就不用说了。除了少数顽固派，无数人，甚至包括西方列强在内，都认为革命具有合法性。

所以这么一分析，虽然黎元洪在武昌起义后当都督，是一场巨大的赌博，但也不至于害怕到“莫害我，莫害我”这个地步。因为赌赢的可能性是很大的。

## 4、势和造势

在社会变化中，能够捕捉和分析势，站在势的一边，至少不与大势对抗很重要，可以迎合趋势，或者借势、顺势。当然有的人发挥到极致，不局限在认知-行动领域了，心理-人格上也不问是非地趋炎附势。

但如果没有势可迎合，或以借，可以顺呢？那自已也可以造势。而且很多势确实是造出来的。

从势的第二个公式或我们可以看到，势是“人心+资源+观念+心理-社会机制”。所以，只要能够拿出些资源影响人心，制造观念，并且通过心理-社会机制进行转化、放大，势就出来了。

骗子最懂得造势。无论是官场上的骗子，商场上的骗子，甚至仅仅是骗财骗色的骗子，一上来的标准动作都是要砸社排，把自己包装得具有通天本事，掌握雄厚资源，是富二代或具有强势的社会身份。他们很清楚，如果他们不造这个势，那些屈服社排的人，没人看他们一眼。而把他们造势一造出来，屈服社排的人，就会被激起强烈的需求，那就好骗了。

造势同样是很多商家的基本操作。比如雇人排队买奶茶，搞出一副“要排队抢”的样子，流量很大，就有了势。而人是屈服于势的。首先流量就给人一种压力：那么多人排队买，说明选择是对的；其次它还暗示社排，因为它好像代表了社会时尚的方向。

造势也是政治-军事领域的常规操作。在赤壁之战中，曹操号称百万大军，就是造势，目的是吓唬孙权、刘备赶快投降。结果江东有很多人真的被吓尿了，包括“内事不决问张昭，外事不决问周瑜”的张昭都主张孙权投降。

但曹操真有百万大军？没有的。细细分析下来，也就十五万人左右。当然，肯定比东吴和刘备的多。

当我们说造势时，主要是一个技术判断。当然有人是欺骗、制造假像或虚张声势，这个时候我们就需要能够看穿了。但在很多时候，造势是合理的，是成事的需要。

为什么我们在贫穷、艰难之时，对未来也需要有希望、有信心？因为我们的心理、人格状态，也参与了对未来的创造。从来就没有一个预先摆在那儿的未来等着我们。未来永远是创造出来的。而我们心理-人格的很多东西，比如希望、信心，正是创造未来的资源之一，甚至是稀缺资源。所以有句话说，“信心比黄金还宝贵”。

参与对未来创造的，还有很多东西。其中之一，是他人对你的信心，以及可能投给你的资源。

这个时候，似乎有必要给自己造势。

所以好像有这样一个现象：“你要变得牛X，首先就必须显示出牛X的样子”。“显示出牛X的样子”就是造势。有了这个样子，投资人才可能对你有信心，才会把资源、流量投给你，你才能用这些资源、流量去发展自己，最终变得牛X。而如果一开始显得自己什么都不行，那也就没有资源、流量、机会投过来了。最终，确实是什么都不行的样子。

造势离不开对人心的影响，对资源的吸纳，并且要抢占观念的制高点，而且通过心理-社会机制，转化为资源、流量对自己的流入，最终强化势，形成社会实力。这是一种技术，也是一门艺术。

# 第七章 同盟

## 1、有人的地方就有利益同盟

利益同盟、心理同盟是非常重要的社会实力。对此阐释得最经典的，是前面我们引述过的毛主席在《中国社会各阶级分析》中的这句话“谁是我们的朋友，谁是我们的敌人，这是革命的首要问题。”

“朋友”就是利益同盟-心理同盟或心理同盟-利益同盟。

这两章，我想揭示利益同盟、心理同盟的本质和它们的运作。

先说利益同盟。

说起利益同盟，你绝对一点也不陌生。

比如，过去你没有买房的时候，你和那些没有房子的人在“车下”，都痛恨房价涨。你们在舆论上相互呼应。房价上涨，剥夺的是你们的利益。

但有一年你买房了，你在利益结构上的位置已经变了，你惊奇地发现自己好像不痛恨房价上涨了，而是担心下跌。这个时候，你不再和那些没有买房的人一致，而是和开发商、炒房客、房产中介有了共同语言。

有没有买房，你实际上和很多不认识的人，分别形成了松散的利益同盟——房地产既失利益者的同盟，房地产既得利益者的同盟。

![](img/d8bc4c9286e8efa0ea0769b9c016ab8a_225_0.png)

再以你所在的单位、公司为例。从领导到所有同事，凡是单位、公司的人，都构成了一个利益同盟。毕竟单位、公司是利益组织，凡组织内皆是利益同盟。而是利益同盟也意味着，每个人都有义务维护单位、公司形象，也就是维护大家的利益。损害单位、公司形象的人，在利益上必然会被惩罚。

我们再放大一点。

三国时，蜀汉和东吴的联合，就是利益同盟。

第一次世界时，英国、法国、俄国、塞尔维亚等国是一伙，组成“协约国”；而德国、奥匈帝国、奥斯曼帝国、保加利亚等国又是另一伙。它们是一个政治-军事同盟，很典型的利益同盟。

美国喜欢说“盟国”，把英国、日本、韩国等，在政治、军事上，也视为是利益同盟。

利益同盟非常之多。有人的地方就有江湖。有人的地方也有利益同盟。

在贬义上，利益同盟就是“拉帮结派”“团团伙伙”；在褒义上，利益同盟则是“一个好汉三个帮”“三个臭皮匠，赛过诸葛亮”；而就中性的意义来说，利益同盟是A和B（C、D、E……）在利益上联合，互为对方的社会实力。

我们在这里采用技术分析，不被道德义愤和道德赞美影响，所以采用中性的含义。

从前面你买房前后心态、观点的变化可以看出，A和B（C、D、E……）要形成利益同盟并不难。只需要三步曲：

- 他们在某条利益链上，因为彼此的位置，具有共同利益、共容利益，或利益趋向一致。
- 有形成利益同盟的意识或意愿。
- 以有文本的契约，或无文本的心理契约的方式，进行一致行动。

形成利益同盟的两个人，当然不是在所有方面都有相同利益、共容利益，或利益趋向一致。很有可能，他们是有利益冲突的。比如你买了房，当然在“房价上涨-房产增值”上和开发商有共同利益。但是，你和开发商在房子的质量等方面也充满了利益冲突，甚至利益算计。只是，这种利益冲突、利益算计，好像不影响你们共同期待房价上涨。

有很多利益同盟，在利益冲突中不仅会相互防御，而且也会“狗咬狗”。大家很清楚“没有永远的朋友，只有永恒的利益”，都知道哪一天利益同盟就玩不下去，甚至会翻脸。但只要还有共同的敌人，彼此仍可选择成为利益同盟。

比如二战的时候，美英两国和苏联肯定清楚一旦战胜纳粹，大家就会有意识形态和利益上的冲突。但是，当前的敌人是纳粹，是日本法西斯，得先形成牢固而强大的利益同盟战胜共同的凶恶敌人。

## 2、利益同盟各方可能各怀鬼胎

利益同盟有不同的层次，就像两个人的关系有深有浅一样。所以，我们要问一句：“到底是什么样的利益同盟？”

战国的时候，秦国军力最强，经过商鞅变法，改造了人民，像变魔术一样把老百姓变成了只会种粮食和睁着血红的眼睛杀人换爵位的一群奇怪的人，被称为“虎狼之师”。而关东（函谷关以东）六国文化相对发达，统治相对宽松，没有玩这一出。

所以如果秦国要和齐楚燕韩赵魏中的任一国单独PK的话，秦国可以把它们——灭掉。

从常识上来说，在这种“一强众弱”的国际格局中，六国应该形成共同对抗秦国的利益同盟，避免唇亡齿寒。因为一国如果被灭掉，那么很快就轮到下一国了。帮别人其实是帮自己，而不是做慈善。

事实上，在人类社会，强者最忌惮的，就是弱者的联合。拿破仑时代的法兰西第一帝国是当时欧洲的霸主。为对付法国，英国、普鲁士、俄国、奥地利等国组成了七次反法同盟。最终，1815年6月，法军在滑铁卢战役中覆没，同年10月拿破仑被流放至圣赫勒拿岛。

如果几个拿枪的侵略者，就可以统治一个县城的话，那肯定是这个县城的人，完全是一盘散沙，任人宰割，没有联合起来反抗的意识。几个侵略者面对一盘散沙，博弈格局其实不是几对N，而是几对1。

鬼谷子的学生苏秦看到了六国的处境。在秦惠文王那儿求职不顺后，他改弦易辙，抛出“合纵”战略思想，跑到关东六国去游说。经过一番艰苦的努力，让六国合纵起来形成抗秦利益同盟，苏秦居然还做成了。

做成之后，他身佩六国相印，给秦王写了封信，说六国已经联合，秦国不是想打谁就打谁了。你打其中一国，剩下五国都要帮忙。而从实力上说，无论秦国多么强大，都不如关东六国的总和。1:6，秦国必败。

秦王不知虚实，但当然懂1:6不利于自己的常识。所以，整整十五年，秦军没有出函谷关一步。

但如何对付合纵利益同盟？秦国总要想个法子。这个法子无非就是：你结成利益同盟，我就拆你的利益同盟。来干这个活的，是秦苏的师弟张仪。

我们可以发现，六国的这个合纵利益同盟，漏洞相当大。

第一点，从地图上看，从北到南，赵国、魏国、韩国、楚国和秦国接壤，而齐国、燕国根本没有和秦国接壤。在和秦国接壤的国家中，又是魏国、韩国较小且处在交通发达的战争之地。这意味着什么呢？

意味着：像齐国、燕国这种国家，从利益出发进行思考，帮魏国、韩国，根本不会觉得是在帮自己，而是感觉像是在做慈善。

而且它们还会担心：如果战胜秦国，能够得到地盘的是与秦国接壤的魏国、韩国们，而不是自己。如果魏国、韩国们扩大了地盘，那就比以前更强大了，和自己相比，在原有利益结构中的优劣势就变化了，对自己并不利。

所以，至少齐国、燕国对结盟不那么积极。楚国、赵国一般，而最积极的恐怕只有魏国和韩国。

第二点，六国的联合，结成的合纵相当于提供了一个公共产品，一块“公地”。如果是按照利益来思考，它一定会导致“公地悲剧”，即所有人其实都希望别人多出力，而自己能搭便车。但如果大家都想搭便车，那每一个人其实都不想用力去提供这个公共产品了。

第三点，对于六国中比较强的齐国、楚国来说，它们的利益一方面是形成合纵利益同盟对抗秦国，另一方面，则是兼并六国中其他国家的土地来强大自己。换句话说，从利益上，它们彼此之间，既是盟友，其实也可以是敌人。

这就露出巨大漏洞了。因为只要秦国假装和齐国、楚国等结成同盟，说我打魏国、韩国，你要是不帮它们，那么我打下的土地，我们八二分成；你要是帮我，我们五五分成，那齐国、楚国可能就动心了。
