# 2、谁得到什么，谁失去什么？

毛主席为了解决“谁是我们的敌人？谁是我们的朋友？”这个问题，写了比较经典的《中国社会各阶级分析》。

我们考察阶层的原理，当然不是为了解决这个问题，而是解决对社会的认识问题，以及改变命运的问题。

阶层随时都在流动和变化。资源在不同的阶层中有不同的分布。识别阶层的关键是要看一个人在某个社会位置是否有什么样的资源。

美国学者格尔哈特·伦斯基在划分社会阶层时，用的就是这个标准。

如何划分阶层呢？如何确定一个人属于这个阶层而另一个人属于另一个阶层呢？很复杂，但也很简单。他这样告诉我们：

+   第一，看这个人、这帮人在社会中得到了什么；

+   第二，看他、他们为什么会得到。

我想加两个维度：

+   第三，他们是如何得到的？

+   第四，在一个人、一群人得到时，另一个人、另一群人在社会中失去了什么？

得到的，以及失去的，指的是资源。

这些资源，大家都想要，但并不是所有人都能得到，或能得到同等份量。
