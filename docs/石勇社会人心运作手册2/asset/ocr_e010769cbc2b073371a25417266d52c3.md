那个时候，在我的心里，情绪无法保持稳定，剧烈起伏，身体也有点颤抖，好像有什么东西在涌动。

这个流动的东西，就是能量。

# ## 3、心理能量

我把心理结构里流动的这个能量，称之为心理能量。

我愤怒的时候，就是心理能量在我的心理结构里被激发出来，充溢于心理结构，然后，在身体里流动。是有心理能量剧烈流动，我才可能情绪不稳定。

假如我虽然愤怒，但面对一个可以威胁我的人，我不敢愤怒了，我表示人民群众情绪稳定呢？这个时候，显然心理能量被我压抑了。它不流动，不沸腾，自然就撑不起我愤怒的情感情绪。但它仍然在，只是被压抑不动而已。

心理能量跟“力量感”“无力感”之类有关系吗？有人就这方面问了我一个很好的问题：

> “有愤怒、焦虑两种情绪，假如它们心理能量的单位是一样的，为什么你愤怒时有力量感，而焦虑时却没有？”

我的答案是：方向！

愤怒的时候，我是对某一个人，某一个对象愤怒的，相当于我的心理能量的倾泄方向是对准他，对准它。心理能量聚焦起来指向他，指向它。

因此我有力量感。

可是焦虑的时候，没有方向了，我的心理能量只是无序地弥漫在我的心理结构，全散开了，反过来淹没我。所以感觉特别无力。

就像水一样。在一个池子里，水这股巨大的能量，到底是往哪几压呢？往这边压，有了 一个方向，且具备了一定强度，才能推开阀门。

所以，就算你有 N 个立方、M 个能量的水，如果没有冲向阀门的方向，也就推不开阀门。推不开阀门，不是这 N 个立方 的水没有能量，而是它没有力量！从这里，我得到了一个解决心理问题的非常重要的方法论——
