# （5）在市场中的地位

一线明星在市场中的地位高不高？2019年、2020年，李佳琦在市场中的地位高不高？

回答是：太高了。他们一出手，轻易就可以赚取大把银子。

长三角私企的产业工人呢？在市场中地位就不高。

之所以一线明星、网红和产业工人在市场中的地位有着天壤之别，是因为他们拥有在市场上非常抢手的东西：IP、特殊的技能（表演），形成了巨大的流量。这些东西在社会的利益分配中有很大的话语权，产业工人则没有。在市场中，谁都可以具有的那些技能，总是廉价的。
