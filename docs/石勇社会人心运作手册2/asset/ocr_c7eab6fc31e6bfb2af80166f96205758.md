# （5）文化资本：文凭会通货膨胀

文化资本这个概念首先由法国社会学家皮埃尔·布迪厄提出，意思是一种表现行动者文化上有利或不利因素的资本形态。

文化资本，是可以转化为社会资本、经济资本、政治资本的。事实上，各种资本之间，存在相互转化的社会机制和心理机制。

最直观的就是，如果一个人有博士学位，那他就拥有雄厚的文化资本，在仕途上，当然是重点培养对象。“博士市场”之类说法早就传递出了关键信息。

要转化为经济资本同样也很容易，至少在一间公司里，博士的起薪比硕士、本科要高。

社会资本更不用说，博士圈调动资本和影响规则、人心的能力，比文凭低的圈子要高。

文化资本是一个很抽象复杂的概念，我们就来看一下布迪厄是怎么划分文化资本内容的。他认为文化资本有三种形态。

第一种是身体形态。“身体形态文化资本通常指通过家庭环境及学校教育获得并成为精神与身体一部分的知识、教养、技能、品位及感性等文化产物。”

表述还是很抽象，但很好理解。很多家长让小孩学跳舞、弹钢琴、打高尔夫，培养一种优雅、从容、高贵的气质，以及审美上悦目的身体，其实就是给小孩打造身体形态上的文化资本。当然啦，学礼仪，具有贵族女性风范或绅士风度，也是身体形态上的文化资本。
