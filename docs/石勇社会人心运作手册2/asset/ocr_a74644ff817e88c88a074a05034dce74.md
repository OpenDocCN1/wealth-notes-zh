# **3、获取稀缺资源，不是一件容易的事**

如果我们给稀缺资源列一个清单的话，排在第一的是权力；排第二的是金钱，排第三的则是影响力。

然后还有声望、颜值、机会、较高的职位、高文凭和职称，等等，不过我觉得应该不分先活了。这些稀缺资源交换或转化成别的稀缺资源的能力，以及在社会资源争夺过程中的顺序难以直接一较高下。

前面说到了稀缺资源之间的转化和交换。不错，一种稀缺资源，从来不是孤军作战，而是要转化成，或交换到别的稀缺资源。或者说，它骨子里就倾向于转化成、交换到别的稀缺资源。

这有点类似于“自私的基因”。基因一旦存在，就倾向于复制、扩大自身。

我们能够想象一个拥有权力的人没有影响力吗？或者，能够想象一个富人除了钱，什么都没有吗？

显然无法想象。

我们来看一下稀缺资源之间的转化和交换关系。它们中，有些转化或交换能力较强，有些则较弱。同时，一种稀缺资源 A，在和稀缺资源 B 转化或交换时，能力较强，在和稀缺资源 C 转化或交换时，则可能较弱。
