+   B、非普通资源：影响力→自由→权利→福利。

看到没有？这三种稀缺资源中，它们的转化和交换能力，从左到右呈现递减态势，但权力在一个很强的能力上，可以转化或交换到最稀缺的东西。

所以，权力越大，当然影响力也越大。

# 4、阶层划分的标准

说到这里，回忆一下，在前面我们总结出了一个初步的公式：阶层＝所占有的稀缺资源＋非普通资源。

这是划分阶层的指导原则。但它有点抽象、笼统，得分解，一个一个地衡量。

按照社会学对阶层的划分，稀缺资源＋非普通资源具体可以分解为以下十种

+   （1）权力

+   （2）生产资料

+   （3）收入（金钱）

+   （4）职业

+   （5）在市場中的地位

+   （6）社会资本（关系、人脉之类）
