# 忍生变, 变则生

原文: 《史记》

勾践之困会稽也, 喟然叹曰: “各终于此乎? 种曰: “汤系夏台, 文王囚羑里, 晋室斗奔翟, 齐小白奔莒, 其卒王霸。由是观之, 何难不为福乎? 吴既赦越, 越王勾践返国, 乃苦身焦思, 置胆于坐, 坐卧即仰胆, 饮食亦尝胆也。曰: “女忘会稽之耻邪?”“身自操作, 夫人自织, 食不加肉, 衣不至采。折节下贤人, 厚宾客, 赃贫死, 与百姓同其劳。

译文:

越王勾践被围困在会稽山中, 他长叹道: “我在这里完了吗? “文种说: “商汤曾被关押在夏台, 周文王曾被囚禁在是里, 晋文公室斗(曾遭掾言)出奔翟国, 齐桓公小白避乱到莒国, 他们最终建立了霸业, 由此看来, (忧患)为什么就不能转化为福呢? “天王赦免越王后, 越王勾践返回国土, 于是亲身经历痛苦, 深深地反思, 把苦胆放在座位旁, 坐处卧处抬头就看到苦胆, 吃饭也尝苦胆, 常自语: “你忘了会稽失败的耻辱了吗?”他亲自去
