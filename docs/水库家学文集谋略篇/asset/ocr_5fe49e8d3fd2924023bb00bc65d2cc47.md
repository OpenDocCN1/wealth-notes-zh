# 集万变，行于一事。

原文：

法正至荆州，阴献策于刘备曰：“以明将军之英才，乘刘牧之懦弱；张松，州之股胧，响应于内；以取益州，犹反掌也。”备疑未决；

庞统言于备曰：“荆州荒残，人物弹尽，东有孙权骑，北有曹操，难以得志。今益州户口百万，土沃财富，诚得以资，大业可成也”
