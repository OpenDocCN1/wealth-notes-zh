# 大忍莫过藏

原文：《韩非子 · 喻老》

“楚庄王莅政三年，无令发，无政为也。右司马御座，而

与王隐，曰“有鸟止南方之阜，三年不翅，不飞不鸣，

默然无声， 此为何名”王曰“三年不翅， 将以长羽翼，

不飞不鸣，将以观民则。虽无飞，飞必冲天，虽无 鸣，鸣

必惊人。子释之，不谷 知之矣。 ”“处半年，乃自听政，

所废者十，所起 者九，诛大臣五，举处 士六，而邦 大治。

举兵诛齐，败之徐州，胜 晋于河雍，合 诸侯 于宋，遂 霸

天下。 庄王不为小善故， 故有大名，不 圣显示， 故有大

功。 故曰“大器晚成， 大音希声。-
