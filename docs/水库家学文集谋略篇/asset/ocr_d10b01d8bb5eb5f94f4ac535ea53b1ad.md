# 明处惹是非，暗中生变化

原文： 《左传・隐公十一年》

公元前712年，郑庄公回国，大阅军马，择日祭告于大宫，聚众诸将于教场。重制张弧“大旗建于大车之上，用铁绾之。这大旗以绵为之，绵方一丈二尺，缀金铃二十四个，旗上绣奉天讨罪四大字，旗竿长三丈三尺。庄公传令有能手执大旗，步履如常者，拜为先锋，即以辂车赐之。言未毕，班中走出一员大将，头戴银盔，身穿紫袍金甲，生得黑面虬须，浓眉大眼。

众视之，乃大夫瑕叔盈也。上前奏曰“臣能执之。只手拔起旗竿，紧紧握定。上前三步，退后三步，仍竖立车中，略不气喘。军士无不喝彩。瑕叔盈大叫“御人何在?为我驾车。”方议未已，班中又走出一员大将，头戴雉冠，绿锦抹额，身穿绯袍犀甲，口称“执旗展步，未为希罕，臣能舞之。”众人上前观看，乃大夫颍考叔也。
