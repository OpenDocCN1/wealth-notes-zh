# 《资治通鉴·卷第六十五》

# 翻译:

诸葛亮在柴桑见到孙权，对孙权说：“天下大乱，将军在长江以东起兵，刘备在汉水以南召集部众，与曹操共同争夺天下，现在，曹操基本已经消灭北方的主要强敌，接老南下攻破荆州，威震四海。在曹操大军面前，英雄无用武之地，所以刘备逃到这里，希望将军量力来加以安排。如果将军能以江东的人马，与占据中原的曹操相抗衡，不如及早与操断绝关系；如果不能，为什么不早点解除武装，向他称臣？现在，将军表面上服从朝廷，而心中犹豫不决，事情已到危急关头而不果断处理，大祸马上就要临头了。
