# 人性解析：

兴利除弊是自古以来多少仁人志士的崇高追求，故有黄帝战蚩尤而华夏定；大禹疏浚而江河畅；周公置礼而朝纲正；嬴政灭六国度杂务而成一统；中华兴利除弊而民族兴。

西门豹在中国，也是颇有知名度的人物。魏文侯时，邺地民不堪其苦，原因是百姓为河伯娶妇，以致贫困。河伯就是河神，当地官员认为河伯虽是神，但也和人一样，需要娶妻。这就得为其操办娶妻大事，操办此事除需大费资财外，还有一套隆重的程序："洗沐之，为治新缊缦衣，间居斋戒；为治斋宫河上，张缇绅帷，女居其中，为具牛酒饭食，十余日。"

河伯娶妇，妇从何来？河伯虽为神，不在神族中娶妇，却要在凡人中娶妇，这是极容易引起质疑的。但这十分浅显的道理却没能成为邺地百姓用以自卫的理论武器，政权的力量在邺地大于客观真理。在相当一段时期中，地方官员竞以"为河伯娶妇"为由，"常岁赋敛百姓，收取其钱得数百万，用其二三十万为河伯娶妇，与
