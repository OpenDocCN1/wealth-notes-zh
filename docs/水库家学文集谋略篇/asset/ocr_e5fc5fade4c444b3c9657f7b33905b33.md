# 赌一半，嫖白嫖

清朝人朱绶清撰有一本叫《埋忧集》的笔记小说，里面也讲述了一个奇葩赌徒的故事，让永宜再次见识了赌徒的可怖和可恨。

某甲沉迷赌博，三年功夫就把家里败光了，妻子气得卧病在床，也无钱治疗，奄奄一息之际对他说：“我就快病死了，你没钱给我治疗就算了，死后不能光着身子吧？还得买一身寿衣吧？”
