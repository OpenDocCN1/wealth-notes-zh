# 人性分析：

人性的弱点很多方面是有普遍性的。比方好色，比方好赌，比方好抽，比方好喝，比方好斗等等，一般的“好”，好多人骨子的是都有的，只要不过，也算不上大错。但这种好一旦成“瘾”成“癖”，久而久之，那必然给自己和亲人带来难以想象的灾难。我现在想说说说赌。

赌，是于百年来渗透到国人骨子里的一种癖好。古往今来因了好赌这一癖好倾家荡产有之，妻离子散有之，命丧黄泉有之，而因欠赌债狗急跳墙非偷即抢者更是前赴后继，绵延不绝。不论小赌抑或大赌，都能把人性中的弱点体现的淋漓尽致。赌博是五毒之首，万恶之源。赌博不仅是造成家庭不和以至婚姻破裂的主要原因而且还是一种违法犯罪行为。

许多人对赌博的危害性认识不清，认为工作之外，茶余饭后，与几个同事或亲朋好友打点小麻将和二七十，输赢不多，够不上违法犯罪。
