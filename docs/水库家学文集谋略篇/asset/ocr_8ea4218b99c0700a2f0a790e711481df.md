# 人性分析:

> 别人笑我太疯癫，我笑他人看不穿。

懂得装傻，并非就是傻瓜，而是大智若愚。人不能处处装聪明，想面面俱到，路路皆通，结果变成肤浅无知，路路不通。真正的聪明人，是不愿意显露自己聪明得与众不同的，因为这只会让自己遭受无妄之灾。

做人切忌恃才自傲，不知饶人。锋芒太露易遭嫉恨，更容易树敌。功高震主不知给多少下属臣子招致杀身之祸。不露自己的高明，也不以纠正对方的错误为喜，才是真正的智者。那么，卖弄聪明的人，自以为高明，实际上只是给自己画了个花脸，让别人耻笑不说，更有可能成为别人攻击的对象。

如果秦桧真的把子鱼送上去，则可能被皇帝抄家，如果箕子直的滴酒未沾而知道今日为何日，不会被王赏识，又会显得与其他大臣格格不入。他们的故事告诉我们一个道理：聪明人应该是不显眼的！
