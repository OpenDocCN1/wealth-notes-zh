# 人性分析：

扶不起是阿斗背负于年的骂名，甚至直接成为骂人的话，这对于一国之君直是莫大的讽刺。在中国历史上，做皇帝的人不知凡几，亡了国的皇帝也是不少，但为何被骂最惨的却是刘禅？

说起来很有意思，刘禅被骂倒和亡国没有多大关系，却只是因为那句——此间乐，不思蜀。但通过上面的文章，我们知道，刘禅并非是个只看乐子不想事情的人，他很努力地做老一切。曾经，他努力地平衡自己和诸葛亮之间的关系，曾经，他努力地希望闭关息民，曾经，他睿智地看清了魏延造反事件的本质。
