# 前言

年轻时，用一袋子钱换一袋子书。

中年时，用一袋子书换一袋子钱。

年少时，家离古玩城、旧书店较近，时常游走其间，我喜欢逛这些地方，原因是那里的书比市面上的便宜，看著一摞摞书籍杂乱无章的摆放，一头扎进去，一天也出不来，有时连吃饭都会忘记，有时有收获，有时是白忙活一天，不过也接触了一些新鲜事物，总比赌博喝酒省钱多了，每每想到此便不觉得荒废。

忠于二手书原因很多，一是他不融于世俗，二有读者的注释，在波浪线中注意和发现诸多细节。

人丢我取，从外观上看二手书破烂不堪，也许对于不读书的人来说，他们就是一堆破烂。

正如同我挑剩下的对于我来说没有任何价值，但还会有后来者认领。应了那句话，所有垃圾都是放在错误位置上的珍宝。
