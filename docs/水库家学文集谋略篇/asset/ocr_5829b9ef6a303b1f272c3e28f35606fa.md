# 人性分析

秦穆公能死里逃生，与他认知人性的气度、格局息息相关，在衡量“马”与“岐下野人”时通过利益计算，“君子不以畜害人”，把“人”看得比“马”重要。正是他宽容豁达，体谅他人，不计小过，才得到“食马肉者”的知恩图报，冒死救难，才有了秦晋韩原之战的剧情大反转，可谓集人者意者胜天。
