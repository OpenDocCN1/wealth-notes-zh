# # 藏智避祸，大巧若拙

秦桧虽然对下面是一手遮天，但他毕竟不是天，因此经常派老婆到宫中拉拢太后和嫔妃一干人等。一天，秦桧的老婆又到宫中与太后聊天，太后就抱怨：这些日子啊，宫里很少看到大尾的予鱼了。秦桧的老婆一听，予鱼？

这东西我们家多的是啊，终于找到机会巴结太后了。于是，她对太后说：太后要是想要，臣妾家里有，明日臣妾就给太后进贡一百尾来。太后听后说好！

秦桧的老婆回家就和秦桧说：今天我可找到机会巴结太后了。老太太也怪可怜的，想吃大尾的予鱼，我看咱家那东西有很多，就说明天给太后送过去一百尾，让她也解解馋，日后也好向着咱们说话。秦桧一听，脑袋就觉得嗡嗡的，责怪老婆太招摇，这下可惹下乱子了。第二天，秦桧命人准备了一百尾腯青鱼送入宫中。

秦桧为什么会听老婆说给太后送鱼竟然觉得头大？
