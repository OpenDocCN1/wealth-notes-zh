# 忍

凡人，注定有七倍六欲缠身，不能自控者，反遭其噬。

# 藏

财不露白，韬光锡玉，俗话说狼莫大于藏，志手过招时已经不再是拼技术，而是拼谁在心理上先行松懈出现漏洞。

# 防

时移势易，当初的弱点，可能变成如今的优点。强弱之变，转瞬之间。是攻是守，都要防护好自己的七寸，才能地久天长。

# 牵

凡事都讲究个“切中要害”，人性都有弱点 贪婪 嫉妒，虚荣，自私，猜疑，俗话”提了粽子的绳头，可以拎起一长串的粽子”。

# 变

以变为本，以应实用，防不住，躲不掉，变一变，变化越多，越是游刃有余。

# 退

在自己应得的物质利益上，由于贪婪的欲望驱，使人难以做出选择，择机而退，名利双收，是智者行为。
