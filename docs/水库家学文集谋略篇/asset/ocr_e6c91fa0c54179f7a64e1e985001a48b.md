# 牵其怒，控其行

原文:

亮见权于柴桑，说权曰：“海内大乱，将军起兵江东，刘豫州收众汉南，与曹操共争天下。今操失夷南大难，略已平矣，遂破荆州，威震四海。英雄无用武之地，故豫州遁逃至此，愿将军量力而处之。若能以吴、越之众与中国抗衡，不如早与之绝；若不能，何不按兵束甲，北面而事之？今将军外托服从之名而内怀犹豫之计，事急而不断，势必至无日矣。
