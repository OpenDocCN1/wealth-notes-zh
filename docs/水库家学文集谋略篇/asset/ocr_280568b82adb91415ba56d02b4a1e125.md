# 牵其怨，控其行

原文:

初，鲁国孔熙先博学有纵横才志，文史星算，无不兼善。为员外散骑侍郎，不为时所知，久不得调。初熙先父默之为广州刺史，以赃货得罪下廷尉，大将军彭城王义康保待之，故得免。及义康被黜，熙先密怀报效，欲要朝廷大臣，未知谁可动者，以晞意志不满，欲引之。

而熙先素不为晞所至，无因进说。晞外甥谢综，雅为晞所知，熙先尝经相识，乃倾身事综，与之结厚。熙先藉岭南遗财，家甚富足，始与综诸弟共博，故为拙行，以物输之。综等诸年少，既屡得物，遂日夕往来，情意稍款。

综乃引熙先与晞为数，晞又与戏，熙先故为不敌，前后输晞物甚多。晞既利其财宝，又爱其文艺。熙先素有词辩，尽心事之，晞遂相与异常，申莫逆之好。始以徽言动晞，晞不回，熙先乃极辞警说。晞素有闺庭论议，朝野所知，故门胄虽华，而国家不与姻娶。
