# (2)对比激将法

对比激将法是要借用与第三者(一般来说是强者)对比的反差来激发人的自尊心、好胜心、进取心。

用对比激人, 选择对比的物件很至要。一般来说, 最好选择被激物件比较熟悉的人, 过去情况与他差不多, 各方面条件与其差不多的人。而且对比的反差越大, 效果越好。

# (3)煽情激将法

煽情激将法需要用具体的有感染力的描述，用富有煽动性的语言激起人们心中的激情、热情。所用的可以是严酷的现实，也可以是轻松的远景，不拘一格。
