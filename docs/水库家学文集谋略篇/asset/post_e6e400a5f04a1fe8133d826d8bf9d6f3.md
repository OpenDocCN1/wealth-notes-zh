
# 庄子：乱世中的修心与处世

在濠水桥上看见水里的鱼，庄子谈到鱼儿自在游水多么快乐，惠施问道：“你不是鱼，从哪知道鱼的快乐？”庄子闻言反驳：“你又不是我，怎么知道我不知道鱼的快乐？”两人随后展开一段精彩的辩论。

这两个故事，让不少人觉得庄子似乎喜欢谈论形而上、看来无解的议题，造成庄子思想出世、不食人间烟火的印象，和一般人的生活无关也派不上用场。

相较于儒家，我认为庄子更加入世、更加热情。而且，在这个混乱的时代，正是时候读庄子。

### 为什么说庄子思想比儒家更入世？

蔡璧名举例，《论语》里谈到“危邦不入，乱邦不居”，就孔子看来，有能力和资格做官救世的人，必要进入危急混乱的国度；若不能救，则避祸远走；孟子也说“知命者不立岩墙之下”，告诫弟子要远离危险。但庄子却说：“治国去之，乱国就之。”一个已经治理好的国家，你尽大可离开；但当一个国家非常混乱，反而要积极投身到那里尽力拯救。庄子期许自己是个救死扶伤的大医生，让逆境变顺境，不幸变幸福。

另外，儒家面对乱世，讲求治世要以天下为大，当私人利益跟国家、宗族相互冲突时，主张为了大我，小我可以捐躯。可是庄子却不这么想，他认为天下的太平，要从修炼个人的心灵做起，只要人们拥有稳定而强健的心，就能冷静且明智地应付生命中的各种变化及困境。

庄子还说“绝迹易”，表明一个人要避世隐居太容易了，算不上什么好汉。能隐于市井、处于纷乱的滚滚红尘中还能练心，才是真正的高手。因为从我们一呱呱落地，就不是活在无菌室当中，必须和亲人、朋友、陌生人相处，因此用心的对象不只是自己，也必然包括了其他人。

对庄子而言，职场就是个滚滚红尘中的一处绝佳修心房。那么，他又是怎么看待工作场合中的人际互动与角色定位？

### 和而不唱；赞同别人，不坚持自见，更受人爱戴

《庄子·人间世》的《形有所忘》故事中有个人叫哀骀它，他相貌丑得天下人看到都害怕，没权位、没财富、没知识，甚至也没主见，从来不主动倡议什么，都只是应和别人的意见。

但是，男人都想跟他做朋友，女人纷纷想嫁给他，君王想让他当宰相，后来竟想把整个国家都让给他。这是庄子笔下最理想的人物形象。

哀骀它的魅力在哪里？庄子说哀骀它有个最了不起的本事，他不管遇到生死、困顿、遭到别人毁谤或称赞、身处贫穷或富裕，都能把这些看成世事自然的变化、运行，不让这些事情扰乱内心，只是像感受季节的自然流转，没有过度的情绪与哀伤。庄子称这叫做“才能全备”，因为他的心灵是安静的海洋，能宽大容纳他人，才使所有人爱戴他。

另外，哀骀它的“和而不唱”在现代职场也很有意义。许多人常强调工作者要培养领导能力，家长都把自己的儿女当成领袖来期待。但后来他们往往都没有领袖的能力，只有领袖的架子。近年在经济学或社会学中，开始谈追随力与配合力，便是对这样的想法有了反省。

“和”其实很难，不能等着别人要求才上前配合，要自发而主动，因此反而要更积极。心情上也并非不甘愿，而是乐于承担更多责任。身为部属，在主管有很好的意见时要支持，但当他错了也要有勇气反对。当一个配合者，得拥有很强的能力，却也要有愿意居于副手的胸怀。

庄子认为，当一个“和而不唱”的人是更难能可贵的工夫，只要能够做得好，反而可以吸引到更多人，彰显自身价值。

# 韩信：功高震主的悲剧与性格缺陷

西汉开国皇帝刘邦曾经这样评价韩信：“连百万之军，战必胜，攻必取……”西汉著名丞相、开国元老萧何也曾经评价韩信“国士无双”。

萧何曰：“诸将易得耳。至如信者，国士无双。王必欲长王汉中，无所事信；必欲争天下，非信无所与计事者。顾王策安所决耳。” ——司马迁《史记·淮阴侯列传》

（注：韩信先是被封为齐王，后来刘邦将他调到楚国当楚王，最后，刘邦以打猎为由，到楚国借有人告韩信谋反为由，削去了他的王位，羁押到京城长安软禁，贬为淮阴侯。因此，《史记》中才没有说是《韩信列传》，而是《淮阴侯列传》，其实都差不多。）

如此看来，韩信的军事能力是毋庸置疑的。但是，这样一个盖世英雄，却落得个兔死狗烹的下场。

前文提到，刘邦将韩信软禁在长安，但是，可能是念及韩信战功赫赫，为西汉王朝的开创建立了汗马功劳，因此只将他软禁，并没有立即杀他。但是，吕雉（吕后）并没有打算放过他，她与萧何商议，骗韩信说，刘邦已经消灭了叛军陈豨，让韩信入宫庆贺。最后，韩信被吕后杀于长乐宫的钟室。

一代战神，英年早逝。

对于韩信的悲剧结局，不少人都说刘邦猜忌功臣，吕后心狠手辣。但是，韩信本人也并非完全无辜。今天，就让我们从《史记》里的这3个细节，来看看韩信自己身上所存在的缺点。

### 1、在汉军中犯罪，说明韩信对规则不重视

一开始，在所有反秦的义军中，韩信选择追随项梁。项梁死后，韩信自然就属于项羽的楚军麾下。韩信向项羽献出自己的计策，奈何项羽并不重视。心灰意冷之下，韩信转投刘邦的汉军。

在汉军中，韩信还未崭露头角，就迎来了一场小风波。他触犯了法律，同伙的十三人都被杀掉了。

“汉王之入蜀，信亡楚归汉，未得知名，为连敖，坐法当斩，其辈十三人皆已斩……” ——司马迁《史记·淮阴侯列传》

可惜的是，韩信具体触犯了什么法律，《史记》中并没有提到。但是，从这个细节中，我们可以看到，韩信对于规则不怎么重视。他并非那种穷凶恶极之人，但是法律是公平的，一码归一码，不会因为你平时多行善事、多作贡献，就可以脱离法网。而且，韩信触犯的法律还很重，到了要杀头的地步。这种性格特点，可能就会导致韩信在生活中更加倾向于我行我素，而不是明哲保身。

好在，当轮到韩信被杀头的时候，他靠着自己的一表人才和远大志向，救了自己一命。

韩信对滕公说：“汉王不是想统一天下吗，为什么要杀壮士？”

滕公见韩信仪表堂堂，说话也不同凡响，就放过了他。真是有惊无险，韩信捡回了一条命。

在后面，就是大家所熟知的“萧何月下追韩信”、“韩信登坛拜将”、“暗度陈仓、背水一战”……了。

### 2、因为贪功，害得同僚被煮，舍不得功名和利禄

韩信的实力是真的强，但是他想建功立业的欲望也是真不弱。

攻下赵国后，韩信打算继续东进，攻打齐国。还没有渡过平原津的时候，韩信听说刘邦已经让辩士郦食其去劝说齐王归顺了，就打算停止进攻。但是，韩信身边的谋士蒯彻（剧透，OCR误识）却并不赞同，认为应该继续进攻齐国，韩将军东征西讨，凭什要把功劳拱手让给一个只会读书，凭借口舌收服齐国的人。韩信一听，有道理啊，于是就继续进攻齐国。齐王本来已经被郦食其说服，但是韩信突然进攻，他立马认为郦食其是在骗他，目的是拖住齐国，用来降低齐国的防备之心。齐王一怒之下，就将郦食其煮了。

这个历史事件中，蒯彻的劝说是导致郦食其身死的直接原因，但是韩信潜意识里对于功名的渴望才是根本原因。韩信并不傻，堪称军事天才，蒯彻也是知名谋士，他们不会不知道他们进攻齐国，郦食其会有什么下场。

但是，他们还是这样做了。身为谋士，蒯彻可能只是为自己效忠的将军韩信着想考虑。关键还是在韩信自己身上，他想要建功立业的渴望，是自己那一点点道义气压不住的，外力稍微一推，就按捺不住。

要知道，有舍才有得。张良能舍得远离权势中心，才能收获闲云野鹤般的闲适生活。

而从《史记》中的这个细节看，韩信很难舍弃功名爵禄。他舍不得，自然就难以消除刘邦对他的猜忌防备之心。

更何况，在刘邦身陷危难的时候，他还趁势提出让刘邦封自己为齐王。

### 3、刘邦身陷危险的时候，要求封王，不懂人心

汉四年，也就是公元前203年的时候，终于如韩信所愿，他平定了整个齐国。

韩信是春风得意，但是刘邦那边却流年不利。

刘邦被项羽围困在荥阳，等着韩信过来救驾。但是，韩信却派来使者，让刘邦封自己为齐王，好方便管理齐国。刘邦气得破口大骂，还是张良、陈平在旁边劝解，说不如趁机封了韩信，好安抚住他，免得韩信叛乱。刘邦这才控制住了情绪，同意封韩信为齐王。

想提要求，在别人心情好的时候才比较容易成功。心情不好的时候，一般看谁都不顺眼，除非你能帮他解决难题和困扰。而这个时候提要求，无异于火上浇油，让别人的心情更加不好，觉得你这人怎么如此不识时务。

韩信不会揣摩人心，因为他已就不是喜欢计较的人，从胯下之辱就可知。但是，这也是他的缺点，不是所有人都跟韩信一样不拘小节，每个人都有自己的脾性。

韩信以为要求封自己为齐王是顾全大局，方便管理齐国，但是在刘邦眼里，可能就是恃功自傲，趁火打劫了。

### 4、带给我们的启发

当然，韩信的悲惨结局值得我们同情，他也没有犯下滔天大罪。他的悲剧，是各方面原因综合作用的结果。

然而，正是因为这样，韩信的教训才更加值得我们深思，不要犯跟他同样的错。

# 郑庄公与许国之战：明处惹是非，暗中生变化

原文：《左传·隐公十一年》

公元前712年，郑庄公回国，大阅军马，择日祭告于大宫，聚众诸将于教场。重制张弧“大旗建于大车之上，用铁绾之。这大旗以绵为之，绵方一丈二尺，缀金铃二十四个，旗上绣‘奉天讨罪’四大字，旗竿长三丈三尺。庄公传令有能手执大旗，步履如常者，拜为先锋，即以辂车赐之。言未毕，班中走出一员大将，头戴银盔，身穿紫袍金甲，生得黑面虬须，浓眉大眼。

众视之，乃大夫瑕叔盈也。上前奏曰：“臣能执之。”只手拔起旗竿，紧紧握定。上前三步，退后三步，仍竖立车中，略不气喘。军士无不喝彩。瑕叔盈大叫：“御人何在？为我驾车。”方议未已，班中又走出一员大将，头戴雉冠，绿锦抹额，身穿绯袍犀甲，口称：“执旗展步，未为希罕，臣能舞之。”众人上前观看，乃大夫颍考叔也。

御者见考叔口出大言，更不敢上前，且立住脚观看。只见考叔左手撩衣，将右手打开铁绾，从背后倒拔那旗，踊身一趔，那旗竿早拔起到手。忙将左手搭住，顺势打个转身，将右手托起。左旋右转，如长枪一般，舞得呼呼的响。那面旗卷而复舒，舒而复卷，观者尽皆骇然。

庄公大悦曰：“夷虎臣也！当受此车为先锋。”言犹未毕，班中又走出一员少年将军，面如傅粉，唇若涂朱，头带束发紫金冠，身穿织金绿袍，指着考叔大喝道：“你能舞旗，倘我不会舞，这车且留下！”大踏步上前。

考叔见他来势凶猛，一手把着旗竿，一手执著车辕，飞也似跑去了。那少年将军不舍，在兵器架上，绰起一柄方天画戟，随后赶出教场。将至大路，庄公使大夫公孙获传话解劝。那将军见考叔已远去，恨恨而返，曰：“此人敌我姬姓无人，吾必杀之。”那少年将军是谁？乃是公族大夫，名唤公孙阂，字子都，乃男子中第一的美色，为郑庄公所宠。

次早三营各各放炮起兵。那许本男爵，小小国都，城不高，池不深，被三国兵车，密密麻麻，围得水泄不漏，城内好生惊怕。只因许庄公是个有道之君，素得民心，愿为固守，所以急盼未下。齐鲁二君，原非主谋，不甚用力。到底是郑将出力，人人奋勇，个个夸张。就中颍考叔，因公孙阂夺车一事，越要施逞手段。到第三日壬午，考叔在略车上，将“弧”大旗挟于胁下，踊身一跳，早登许城。公孙阂眼明手快，见考叔先已登城，忌其有功，在人丛中认定考叔，陡的发一冷箭。也是考叔合当命尽，正中心，从城上连旗倒跌下来。

瑕叔盈只道考叔为守城军士所伤，一股惯气，太阳中迸出火星，就地取过大旗，一蹦而上，绕城一转，大呼：“郑君已登城矣！”众军士望见绣旗飘飏，认郑伯直个登城，勇气百倍，一齐上城。砍开城门，放齐鲁之兵人来。随后三君并入。许庄公易服杂于军民中，逃奔卫国去了。

### 翻译

那年夏天，五更里，郑庄公在宫前检阅部队，发派兵车。一位老将军颍考叔和一位青年将军公孙子都，为了争夺兵车吵了起来。颍考叔是一员勇将，他不肯服老，拉起兵车转身就跑；公孙子都向来瞧不起人，当然不肯相让，拔起长戟飞奔追去。等他追上大路，颍考叔早已不见人影了。公孙子都因此怀恨在心。

到了秋天，七月间，郑庄公正式下令攻打许国。郑军逼近许国都城，攻城的时候，颍考叔奋勇当先，杀敌无数，爬上了城头。公孙子都眼看着颍考叔就要立下大功，心里更加忌妒起来，便抽出箭来对准颍考叔就是一箭，只见这位勇敢的老将军一个跟斗摔了下来。另一位将军瑕叔盈还以为颍考叔是被许国兵杀死的，连忙拾起大旗，指挥士兵继续战斗，终于把城攻破。郑军全部入了城，许国的国君许庄公逃亡到了卫国。许国的土地于是并入了郑国的版图。

### 人性分析

我们平时会表现得很单纯，什么东西都光想到好的一面，被理想的目标一时间冲昏了头脑，忘记了这样做不好的一面。

其实我们无论做什么事情都会有双面性的，有时我们选择了这样去做只是因为事情利大于弊。

有时我们也应该在权衡了事情的利弊后，不顾一切的向前冲，毕竟我们没有什么顾虑，轻装上阵要好发挥。

可是人心叵测，世事难料，无论在职场还是官场中，由于竞争和嫉妒，往往在我们希望很大的时候也就是最危险的时候，也许就有些人在背地里暗算你，而且这种事情也是我们最不容易想到的，我们当时只想怎么去快点成功，成功后要怎么去庆祝呢。

所以在我们得意的时候一定要防着点。

人际交往中，我们常常会听到一些类似的话：

- 害人之心不可有，防人之心不可无。
- 防小人，不妨君子。

确实我们好好的对待别人，可别人在背后捅你一刀的滋味绝对不会好受，所以我们平时在跟别人的交往中要认真去观察每个人，去了解他们，了解他们的人生观、价值观，了解他们的内心想法，把握他们的心理动态，要对其将要行为有所判断与预防。

要想在关键时刻顺利点，我们平时跟别人的交往中就要注重对别人的把握。

要想对别人很好的把握，我建议自己掌握一些自己吃得特别透彻的观点、问题和某些突出事情的做法，以便通过他们对这些观点的看法、问题的处理或事情的做法来把握他们。关键是我们对要测试的问题了如指掌，别人怎么做我们就能吃透他们的心里。

在把握了每个人的心理之后，我们就可以很容易的控制住他了，而且也应该知道在什么情况下防那些人了。

# 春申君与李园：宅中有狗，护院吃肉留两手

原文：

楚考烈王无子，春申君患之，求妇人宜子者进之，甚众，卒无子。

赵人李园，持其女弟，欲进之楚王，闻其不宜子，恐又无宠。李园求事春申君为舍人。已而谒归，故失期。还谒，春申君问状。对曰：“齐王遣使求臣女弟，与其使者饮，故失期。”春申君曰：“聘入乎？”对曰：“未也。”春申君曰：“可得见乎？”曰：“可。”于是园乃进其女弟，即幸于春申君，知其身有身，园乃与其女弟谋。园女弟承间说春申君曰：“楚王之贵幸君，虽兄弟不如。今君相楚王二十余年，而王无子，即百岁后将更立兄弟。即楚王更立，彼亦各贵其所亲，君又安得长有宠乎？非徒然也，君用事久，多失礼于王兄弟，兄弟诚立，祸且及身，奈何以保相印、江东之封乎？今妾自知有身矣，而人莫知，妾之幸君未久，诚以君之室而进妾于楚王，王心幸妾，妾赖天而有男，则是君之子为王也，楚国封疆尽可得，孰与其临不测之罪乎？”春申君大然之。乃出园女弟谨舍，而言之楚王。

楚王召入，幸之。遂生子男，立为太子。

### 翻译

楚考烈王没有儿子，相国春申君为此甚为忧愁，寻求宜于生子的妇人进献给考烈王，虽然进献了许多妇人，却始终没能生儿子。

这时赵国李园想把自己妹妹献给考烈王，可是又听说自己的妹妹并无生子之像，又担心将来得不到考烈王的宠信。李园就请求能当春申君的舍人，当上舍人后，请假回家，又故意晚回。回来见到春申君，春申君问他为什么迟到。李园回答说：“齐王派人来娶我的妹妹，我和使者喝酒，结果耽误了回来的时间。”春申君说：“送过聘礼了吗？”李园说：“还没有。”春申君说：“可以让我见一下令妹吗？”李园说：“可以的。”于是李园就把妹妹献给了春申君，得到春申君的宠爱。当李园知道妹妹有了身孕，就和妹妹商量了一个计谋。

李园妹妹向春申君说：“君王宠信你，就连兄弟也不过如此。现在你当楚国相国已经20多年，可是楚王还没有儿子。等到楚王死后，必然拥立兄弟为王。楚国王位更换，必然重用自己的亲人，您又怎么能长久得到宠信呢？不仅如此，您出任相国的时间又长，难免对大王兄弟有许多失礼得罪之处。将来大王兄弟如果能登上王位，您定会身受大祸，又怎能保全相国和江东的封地呢？现在臣妾已经知道自己怀有身孕，旁人却谁也不知道。臣妾受你的宠爱还不算久，假如能凭你的高贵身份而把臣妾献给楚王，那楚王必然会宠爱臣妾，万一臣妾能得上天保佑生个儿子，那岂不是你的儿子作了楚王，到那时楚国的所有不尽在你的掌握之中吗，这和面对着不可猜测的罪过相比，哪一个更好呢？”春申君认为这话很对，就把李园的妹妹迁到一个秘密的地方，并向楚王说进献李园妹妹。楚王把李园妹妹召来后就非常喜欢她。后来果然生了一个男孩，而且被立为太子。

### 人性分析

如果没有春申君，历史上根本不会有李园的记载。但这个人一定是个不简单的人，事前肯谋划很久，能把春申君拉下水，自己上位。

李园借助别人（其妹妹、春申君、楚考烈王、楚幽王）的力量从一个白丁当上了国舅。这棵大树上开的花，好多好大好利用啊……可怜的是春申君临死不悟，他所犯的逻辑错误就是模式化谬误。

模式化谬误是一种在推理或论辩中误把某一模式当作关于某类对象整体的准确概括而加以运用所引起的谬误。所谓模式，是指人们用来对人群、对象和事件加以归类的某些普遍性的信念，不过这些信念往往表现为某种概括性的命题，并非必然总是真的。

春申君根据李园在门下的表现，却认为李园是“软弱”和“知恩图报”的人，这就是把李园的为人模式化了。人有两面性，如同正义和邪恶，真实与虚伪，克制与放纵，爱和恨一样地存在于一个躯体内，就像一架天平的两边，总是在动态的过程中追求一种心理上的平衡和社会的认同。如果只看到某人的一个侧面就盖棺论定，且又听不得旁边人的规劝，那么必然会被另一个侧面所蒙蔽。

李园事前事后所作所为，可谓机关算尽，反映出了他的人品：当面是人，背后是鬼；既有“恭维”，又有“杀机”。春申君就是犯了模式化谬误的一个错误，以至于归黄泉都没有思考的余地，死得不明不白。

李园的手段固然狡诈险恶，但春申君之死，却有咎由自取的地方。考其致命错误有三：

- 一是“不识时务”。楚王一去世，迫切追逐权力的李园，势必抢先夺权，杀掉春申君。站在李园的角度，这样做既能剪除异己实力，又能达到杀人灭口、掩盖利用妹妹争夺权力的无耻行径，此为“时务”之一。继位的新君实际上是春申君的儿子，春申君可以利用这点大做文章，揭穿李园以巩固自己的权位，并且可以先发制人除掉李园，此为“时务”之二。他的门人朱英就充分认识到了这两点。但春申君错误地估计了形势，没有清醒的洞察局势，也就意识不到即将到来的凶险。
- 二是识人不明。李园安排其妹嫁给春申君，待怀孕后再嫁楚王，将自己妹妹的幸福作为自己进身的阶梯和工具，只有利益和野心，少有血肉亲情。春申君对这样不择手段的人认识不清，对其罪恶本性估计不足，缺乏识人的犀利眼光，反而认为李园是软弱无能之人，对自己很好。
- 三是听不进不同意见。春申君的门人朱英有智慧，对形势洞若观火，对利害得失了然于心，有谋略，为春申君出谋划策，找到了解决问题的方法——先发制人，除掉李园，将权力掌握在自己手里。朱英没勇气愿意自己涉险入宫中除掉李园，但春申君对朱英的建议竟然充耳不闻，既不采取措施进攻，也不想办法自保。
