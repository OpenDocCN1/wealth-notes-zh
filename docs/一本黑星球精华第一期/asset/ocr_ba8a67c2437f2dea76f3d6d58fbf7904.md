# 第二章：牛人分享

店面必须要求装修，保证品牌形象。你不懂，不用担心。品牌商有专业的施工团队，你只要付钱。如果没钱，也不用担心，他们有着颇多的金融合作机构帮你贷款，分期返还。

店开了，要有员工。有些品牌加盟是集中招聘分配，就是你招的人要按照他们的标准来。他们来培训，然后派到你的店里，工资他们定，但由你来付，和直接做些差不了多少。

有些品牌支持店主自主招聘，但对你负责，要由专业人员培训员工吧，你要付培训费，而具体的报价由他们定。毕竟这不像商品，没有标准价。

像火锅、快餐、奶茶呀，品牌为了保证食材质量，要统一供应，这个价格可能比市场上自己买贵，你也没办法。

还要对你做开店必备，均分很可怕，要从你的店里流水抽成。好吧，到最后，你试行、行、经营多年，竟然没达到社会的平均、准备老老实实去赚钱，不加盟了，要求品牌退回保证金、返还带路加盟费、折价收回没用完的原材料。

品牌商会用他们的专业法务人员，对合同上的那一条条约定，告诉你，长得不美、想的矮美，帮助到死，给你社会最后的毒打。

何况有些品牌的初衷就是花大精力做几个样板店，数据不行的刷刷数据，找水军来排队，花钱做广告，声势做起来了搞加盟。加盟也许够了，就贩于搞新项目，甚至加盟商喊着、看命咯。
比如之前在抖音爆火的某茶，一口气签了6000多家加盟，最火爆的时候，一条街能有3家茶饮店，3个月不到，倒闭了80%，但这不重要，因为厂家早就赚够了，换一个新品继续卖。
加盟就像打游戏，你加入一个帮派，不管你睡多少级，多牛逼，最后都是这个帮主赚钱得名声。你最多是比较有面子的打手和活跃喽啰。
所以想开点，这个路上就没容易赚钱的事。带你装逼，带你飞，很美好，也的确有一些这样的品牌，就看你的资产、眼光、能力和运气咯。
记得决策前，三思。
