# 第三章：杨金思维

到了4月份，冰丝袖套有两个淘宝商家PK战争，直接离到2块9，百分之九十佣金，我也拍了袖套，一不小心又爆了，一百多万流量，出了接近四千单，佣金二万左右，然后隔了二天，冰丝袖套又发了一次，又爆了五十万流量，出了(chat)一千多单，这次因为商家在Q群是做免单，我出了一千多单，还一单给我补一块，又多赚了一千多。

本来准备来投抖音的，谁知道天猫小二给商家降权重了，我真是无语，少赚几千块一后而且也出了几个三百到五百万的视频，但是就型多和百分之六，少赚了很多钱，然后开的节号也是慢慢做了，又订了二台苹果二手手机，开缩多账号做了，其他新账号没有这个老账号玩了，一直做到六月底七头，抖音就开始带货视频了，收入就降下来了，然后到了九月就做其他事情了，带货就放下来了。几个号加起来，佣金三十多万，投入成本加抖音，三万多不到。

给大家举个例子。五月到六月抖音带货火，每天都是成千的人进入，我当时一个小时的咨询费也是500起。有图为证。种草原因我想通过了一些东西，自己总结了几个原因，各位大佬看看；

+   第一点：当时看好了，就找我有没有合适的培训班。而不是想着在家自学，因为短视频是新行业，自己都都不懂，自己当时的做法就是用钱买时间，只想学皮毛，大家也不要求能学到很多，以免心里有落差，我就苦闷到用什么软件，怎么打标签，买什么灯，买什么机，还这样别的人节省很多时间，红利期现在很短的。但是各位小伙伴们还是要提醒下，培训班都是B是割韭菜的多的，我能成功有几个原因的，下面再来说，我们一期学员二十个人，只有我赚钱了，其他全亏了。

+   第二点：我是老婆早就就在抖音，她对视频剪辑前、角度方面还有点感觉，我是都看不懂，我真不会拍照，所以都是她拍，我剪。我软件上手快，当时剪映还没有出来，都是手机用VIPD，同一期我软件上手最好了，平时电影看的多，对视频运镜还是有点感觉，不会剪的前后很乱，最少视频很顺。这也是成功的一个小原因。

+   第三点：说下错过的是失败的原因，最大原因是JB不喜欢做抖音。
