# 分析潜在用户行为：

你的用户不可能都集中在一个贴吧，你要试着去分析他们的行为，会去那些相关吧做些什么？然后去展现你的价值，吸引潜在用户。

如果你是减肥类产品，你的精准用户在减肥吧，而在瘦身吧、塑形吧里还会存在大量的潜在用户。
