# 第一章：认知升级

有钱人玩股票票才叫玩，大多数普通人只能说 tank 股票玩。
别人的红利是零花钱，而你的红利可能是全部身家或者婆家身家。

还是那句话，千万不要借钱去炒股或者玩基金。
一定要用自己的闲散资金，保证这笔钱即使是亏了，也不会影响自己的正常生活。

不要因为别人赚钱就眼红，不要因为别人暴富就羡慕，这样只会扰乱自己的生活节奏。

最后，可能会有人问了，捞哪里这么多钱、不给读者们发个红包庆祝下？
哎，我也想发啊！
主要是。
