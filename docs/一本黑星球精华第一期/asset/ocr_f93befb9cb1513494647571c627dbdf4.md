# 聊聊我 23 岁赚到的第一个 100 万

前段时间有人在知识星球向我提问，想让我聊一聊我的第一桶金是怎么赚到的，赚了多少。

我回答说有点满一百万，我就找时间写一写。刚好周末没事，我就简单回忆了一下。

以往的经历不可复制，但里面的很多商业模式其实和我现在做自媒体是有共通之处的。

希望看完能给你们一些启发和思考。
