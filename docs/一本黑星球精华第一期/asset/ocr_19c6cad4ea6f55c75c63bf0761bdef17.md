# 贴吧引流，出单不愁——天枢

有個加了我 2 个月的粉丝问我，自己是做抖音培训的，有什么办法引流多收点学员？

考虑到测试过抖音上做知识付费转化很低，我说，你可以去做贴吧有效果的。

他没回我，可能觉得我是傻子吧。

其实去年我的合伙人就搞抖音培训的项目，百度竞价和低价引流课都没收回成本，反倒是贴吧这条推广线安排了一个兼职每天发帖回帖闻频出单。

因为贴吧的账号越来越贵，发帖的存活率低，再加上顶部软件横行霸道，把小白都拒之门外，失败的人往往会给自己找个借口：贴吧京东，所以不敢做了。

既然毫无价值，为什么仍然有这么多的广告？为什么贴吧账号的市场价格上涨了快一倍？到底是谁在买账号？在贴吧引流成本不断走高的背景下，到底是谁还在不知疲倦地坚持引流？这些人难道不是傻子。

行了不啰嗦了，本文就详细讲述如何选择贴吧，怎样发帖不被删，帖子如何被百度收录，一滴水都不漏。
