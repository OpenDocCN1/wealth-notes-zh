# 第六章 写作

写作对我们好处作者列出以下四点：

+   1、写作能让我们播明白，提升我们的文档质量。
2、经常写作你会比一般人更能捕捉价值信息
3、写作会在各种争夺更有优势，尤其在这个互联网时代。
4、公开写作，能结识很多同频的人。

如何打好基础作者也做了 3 大说明：

+   1、多读好作品，好好读书。
2、写出来多看几遍（ps 本人第一遍看完发现有什么错别字排版刷，过几天在看还是有问题），写得多写少你总会发现都不是很够。
3、我一本读得不精的书，不要多也不要少，认真读几遍（像专业书籍读一遍，用途不大，除非你过目不忘），对作者表达布局做自己理解与推测。

写什么？？你方便写的，对本人和自己有启发都可以写。

比如你的辞库，读哪些书对你的影响，学到你了，你哪些成实现事情，怎么做到，有的经验分享，还有你探险坑，你的遇到事情……通过这些文章你能了解自己也能让别人了解你。

还有就是细分领域在细分领域想在领域写书成减，打造个人品牌（我认识的一个新大，她在饭前开始写了个公众号写的是她领域对医学的见解）。

不会起标题嘛？作者教你起名字。

写文章，标题很重要，重要的哈呢比谁的目录，我在考虑买书会去图书首先看目录，翻点点，然后考虑买不买（ps 当然了，买了未必有时间读，工作、家庭、社交让我们大部分人无暇看书，有时候我都来不及精读和认真写好笔记）

+   1、提高自己起名字，去看人标题，公众号、b站等你会快速浏览一遍，会动心的就把标题记下来。
2、多起几个标题，让自己确认哪个好，这样我们就能够成为一个不折不扣的标题党。
