# 五、私信设置

头条和公众号一样有一个自动回复设置，这个功能为我们引流提供了便利，直接让用户私信一个关键词即可。

其中设置的关键词尽量简单，比如让用户回复“学习”、“交流”、“001”这种即可。

然后自动回复时话术也要想好，说明情况，比如“头条不常在，亦或者由于XX问题，头条不能XX，如有需要请加微信等”等，这样才能提高转化率。
