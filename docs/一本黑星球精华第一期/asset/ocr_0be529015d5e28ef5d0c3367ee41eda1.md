# 第四章：炼金实验

不成熟，也没有完整的团队，我建议你可以做“蓝海冷门小类目”。哈喇蓝海冷门类目，举个例子，开心果， 大家都知道吧，这就是一个红海类目。

我们可以看看， 前几位，三只松鼠占了两个位， 天猫超市占了两个位， 百草味占了一个位， 良品铺子一个位， 剩下的两个也是两个天猫旗舰店。试想， 如果你自己是消费者， 你会选择前面销量几万、视觉效果统一的天猫旗舰店， 还是选择一个刚刚新开的月销前几十笔的小店？答案是明显易见的嘛。实际上， 更多的時候， 你是连曝光的机会都没有的，更不要说给顾客选择对比的机会了。

这种情況， 竞争非常惨烈， 几乎不给小卖家活路。 如果你要去做这样的产品， 前排全是实力卖家， 销量都是破万的， 就算前一百名几乎全是天猫店， 并且在线商品超过 100 页， 这个时候， 做淘宝确实费， 非常难。 但是若是你选择的一些蓝海冷门小类目产品， 你就可以得到比较深的， 做淘宝对你而言， 也不一件那么辛苦的事情。
