# 第五步：成立时间与基金规模

不选择成立时间小于三年的基金，不选择新基金。关于规模，我比较偏好 30-100 亿规模的基金。30 以内太小，100 以? 太大。都会影响到收益和风险的综合比。

# 四、什么时候该买，什么时候该卖？

在赌场里有一句话：在你离开赌桌之前，所有你赢的钱都不是钱，只是纸。在资本市场里一样，在退出之前，所有的盈利都只是浮盈，随时可能一把亏回去。会买（股票／基金）的人只是弟弟，会卖的才是哥。择时甚至比选基更重要。
