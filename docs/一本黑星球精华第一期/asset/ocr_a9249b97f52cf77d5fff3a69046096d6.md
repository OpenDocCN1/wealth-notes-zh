# 操作盘 100 个抖音账号总结出的 5 点建议

和老师傅相识非常有缘，每次写了文章都会第一时间跑来这里分享给大家，感恩。

2017 到 2019 这两年，从网红 MCN 机构的流量号、各领域搬运号到现在的树洞开车带货号，作为抖音的一颗老韭菜，前前后后我经手的抖音号已经不下 100 个。

花了 2 根万宝路的时间，总结出了 5 个不成熟的小建议，如下：

+   1. 抖音的近况。
2. 关于抖音账号标签。
3. 关于抖音推荐机制。
4. 要不要开通抖音蓝 V。
5. 抖音带货的基础流程及注意事项。

# 一、抖音的近况。

现在的天猫淘宝直播大商家都注重把客户引导到微信 QQ 做二次三次 N 次成交，年前罗旭抢着我的大腿说做淘宝也别搞直通车，40 多岁的老男人哭成这样还是人生第一commend。搞的我现在都不敢碰淘宝。

目前抖音也是这个情况，只能能休矣，甚至微笑，整个行业就会被砸烂卖卖，四个字形容这件事情的感觉就是军事演习，旁边还有人一直提醒你：请注意！这不是演习！我勒个去。

我们这些互联网人，前赴后继的往抖音里跳，像城市黎明的灯火，总有光环在陨落，模仿者一个又一个。
