# 不同年龄段买保险的建议—Kenny

最近看是境内讨论保险的比较多，分享下个人看法，不一定好，错了请大家指点。

其中谈到生死，希望不要介意，保险就是保这个。本人在全球TOP3和国内TOP3的公司都待过，前后共7年多，主要是从事寿险。

首先是说下买保险顺序。

很多业务员或者客户都喜欢从小孩冤起。但是这个本末倒置了，一是小孩保费（身故或全残赔付额）低（寿险一线城市最高10万？非一线5万，离开行业久了不确定是不是这个数，只是举例说明）。

小孩万一有事，赔几万块对父母来说谈谈多大意义。但父母如果有事，对小孩来说就是致命打击。

所以买保险顺序应该是先是父母，后小孩。

父母的保障确定后，有余力再考虑小孩的，比如教育金。教育金的意义在于强制自己提前存钱给小孩读书，备好创业金、婚姻金等。它的分红也不算多。养养老险（你没看错，就是养老险，这个年纪小孩买很划算，相当于给小孩存钱），还有重疾、医疗险、意外险都可以考虑。

然后说到年轻人，尤其是刚毕业收入不稳定，弄其是靠健康换钱的，还是很有必要买保障的。毕竟父母辛苦苦苦挣钱养你出来，就是指望你有所回报，或者靠家庭亲戚带你并不好一件事回报父母也有点安慰。这个年龄由于资金问题，就不要买什么分红险，最好是买些低保费，高赔付的消费险（意外、外，寿险和医疗险都需要）。分红险几千块一年，最多搞10万，披的时间没多少钱，这个分红从投资角度来说也没多大意义）也没多少。

目前市面上的意外险都可以投，100块保10万。寿险几千块保100多万，这个万一有事，最起码父母的生活都能得到保障。
