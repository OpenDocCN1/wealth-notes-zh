# 打造 IP 一些心得

# 1. 差异化

在任何时代，你想要脱颖而出，一定要思考 3 个字：差异化。如果整件事大家都在做，做的<|message|> 特别多，你要脱颖而出，你将会付出巨大的成本！所以在我做自己 IP 时候，我就想着差异化。我给自己定了几个比较难的差异化。周更，这个点对于绝大多数设计师来说都是比较困难的。很多人坚持半年更新就坚持不下去了，坚持周更，意味着你必须大量学习的前提下，所以我特别感谢我当初定下的这个承诺，也让我这三年养成学习的好习惯。

# 2. 信任感打造

信任是一切的基础，用户买你的内容付费其实就是相信你。我们需要把每一次信任维护好。我这三年期间，我见过了几百个设计师，很多设计师都成为了我的好朋友。

我把这些设计师当朋友一样去对待，我知道的能够帮助他们的，我一定帮助他们，同时我也让这些设计师通过我建立了很多链接，真正地聚到了一家人

# 3. 把用户当朋友，把自己当产品

做产品的人都知道，产品是需要迭代的，做内容也是，我们需要不断去迭代我们内容，让我们的内容也是与时俱进的，这就要求我们必须走在你的粉丝前面，你必须去影响他们，另外一点就是把他们当朋友，而不是流量和韭菜！
