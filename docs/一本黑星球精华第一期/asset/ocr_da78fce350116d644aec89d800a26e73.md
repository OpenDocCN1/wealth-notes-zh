# 五、转折

17 年我和她还睡在出租屋里， 她睡的很熟， 我又躺在床上睁着眼睛等天亮， 天亮后把萨耶写好一看时刚好早上七点。

我决定管换， 因为我一无所有， 1 1 便失败同样还是1 1 无所有望了。

我在家里面做了三个月公众号， 按照之前的模式，  但涨粉就慢了很多， 但是能比过公号另赚 5K 缺钱， 比上班多一些。

为什么我去这段时间职业的比全职在家多呢？
我自己总结了 3 点：

+   1. 之前的成功成分运气成分， 比如写作、 爆文的标题可以很快涨粉， 也有人儿童年写作都棚不到我。 
2. 我的信息来源太少、 玩法没有更新， 自己单兵作战很野蛮。 
3. 我知道的赚钱方式很少， 能不能通过加入某个组织或者培训实现递差呢？

刚好看到广州有一家做公众号项目的网络公司在招聘， 我就去应聘了， 这个时候我的身份依旧是打工仔， 但我工作的态度发生了巨量变化， 我拿着小编的工资， 却主动去做市场、 编稿、 排版的活儿。

我发现这家公司起有几个优势：

+   1. 公众号人场时间早， 手上有了几个百万粉丝的地域号， 从烂粉里面洗垂直粉， 让矩阵更加宽大， 粉丝更加值钱。 
2. 分工明确， 工作流程工厂流水线化。
