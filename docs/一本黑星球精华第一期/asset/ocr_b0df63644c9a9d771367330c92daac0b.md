# 三、今日头条的流量机制

头条和抖音同属字节跳动，流量机制基本差不多。发的文章以及微头条都会先给一部分流量，若受这部分用户喜爱（如完整阅读率、评论、转发等），则继续推荐。

同时，头条会为每个用户以及文章都打上标签，和抖音也是一个原理，每个用户在头条上经常看什么类型的内容，往后也会经常推荐这部分内容。因此推荐的用户基本上是精准用户。
