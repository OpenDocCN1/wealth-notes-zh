# 5、内容来源

可以从各平台采集，比如知乎、公众号等，当然不能去找那些存在版权问题的內容，即使找这些内容后也需要进行适当的修改，也能算是伪原创。

进入营均日难后先看平台规范，其中会对头条、简介等都做详细规范，不要傻乎乎的什么都看，截止日后还不知道缘由，其中对健康领域会有特别的要求。

在录制音频时会有个破防图标，强烈建议观看，对你的作品会有很大的帮助。
