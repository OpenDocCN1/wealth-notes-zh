# 关于做好省，第三次复盘分享——艾斯zw

从12月1号开始尝试好省，今天终于升级团长了。

# 团队情况：

升级前团队217人，升级后团队272（升级后统计2级以后合伙人），其实真正做团队也就前两次复盘的两个星期，12月中因为家里人生病住院需要照顾，就耽误了两个星期，年底工作也忙，基本上班没有花费精力在拓展团队上。记得当时才几十号人，后面纯靠团队自己裂变变成了现在近300人。

“这个时代最大的商业模式就是利她”，可见好省这个东西确实是真的能够利他，给用户带来实实在在的好处，既能省钱也能赚钱，大家才肯这样去口碑相传。

# 收入情况：

目前总收入414.35元，一半来自自己买卖东西赚的佣金，一半来自下级购物的佣金。相当于一半主动收入+一半躺赚。

有些人可能会笑话这收入少的可以，你见过几个项目，0投入0风险，躺赚哪怕400块钱的？任何的副业都是从赚1块钱线开始的。咱们后面拭目以待吧。

不过恐怕你会经历马云说的“任何一个商机到来都会经历四个阶段：看不见、看不起、看不懂、来不及”。
