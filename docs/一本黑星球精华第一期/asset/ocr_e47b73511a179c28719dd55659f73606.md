# 没有钱到底要不要创业——天枢

# 一、创业的真相

“三更灯火五更鸡，正是男儿读书时。”

七岁的时候我大uyan给了我两百块钱，让把这句诗背下来，永远都不要忘。干裕年，这句诗让一个小学生热血沸腾。

一晃二十载，我不记得当年的百元大钞是什么版面，甚至连太爷爷的样子都记不清，学堂里背诵无数遍的课文，只依稀记得老舍、鲁迅、骆驼祥子。仅几个名字而已。

唯独这句现在却没忘，还特别爱看书。

创业就是这样，这颗种子也许在我们年幼时就已经埋下：听到老爸不经意间跟你讲比比，盖茨的时候，你立志有一天名字要出现在福布斯富豪排行榜。

也许，工作后加班加到公牛都依旧，由于年纪阅历少，你的努力老板不认可同事羡慕不，后恨加你点点狠狠地问自己，为什么已经那么努力了却还是得不到应有尊重的生活？

也许你愤世嫉俗生了无数个创业点子，或许你脑子里一团浆糊难以副打滚，无论如何，你都设有行动起来，被生活按倒在地动弹不得。

你没有想想成功的念头，更没有一个可以执行的方案，因为现在的生活还将就过马马虎虎。
