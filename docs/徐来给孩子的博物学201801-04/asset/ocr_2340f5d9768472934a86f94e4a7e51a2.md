# 徐来

现在大家都注意到减压这件事了。因为，现在很多人都觉得自己的压力大——生活上的压力、工作上的压力、学习上的压力，反正哪儿哪儿都有压力。所以要注意，不然，精神和身体都可能出现毛病。甚至是抑郁。减压的方法也是各种各样，按摩、玩游戏、冥想...

可是，大概没有多少人会想到，在一百多年前，有人本来的目的就是，反而减压减出了病来。这个可不是什么坊间传说，就在昨天说的那个布鲁克林大桥的正上方，今天，我就继续跟你讲布鲁克林大桥的传奇故事。

# 小罗布林举孝业

昨天咱说，在老罗布林的努力下，纽约市政府终于决定要修建布鲁克林大桥了，而且任命老罗布林当总工程师。可惜，因为一次意外事故，老罗布林感染了破伤风，竟然去世。

老罗布林去世后，他的儿子，也就是小罗布林，华盛顿布鲁克林被命为新一任布鲁克林大桥的总工程师。

听到这里，你可能会疑惑，说，美国人在这么大人情面子，爹死了我来接班，这可是造桥的总工程师，万—这个小罗布林是个不学无术的人，造桥造出事来怎么办？

这你可就多虑了，小罗布林比他爸爸，真的是半点都不差劲。他从小就接受良好的教育，他的爸爸也教他关于桥梁的知识，而且这些知识还学得好。

# 被诅咒的布鲁克林大桥

小罗布林面临的是一个难度非常大的工程。在当时，这座桥的跨度将近500米，为达到这个要求，就必须建造两座具有相当强度的塔架。而塔架必须建在曼哈顿和布鲁克林的河岸上，才能保证它的坚固。
