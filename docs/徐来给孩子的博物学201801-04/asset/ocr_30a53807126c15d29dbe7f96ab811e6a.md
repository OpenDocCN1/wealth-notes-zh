+   徐来

前段时间跟大家说过我去澳大利亚看到鹦鹉的事儿，我在家也经常喂我们小区的小朋友们的鹦鹉。得了得了，把小朋友好开心也包起来了。这事心，她哭着喊着说要养两只鹦鹉试试。

这个鹦鹉可不好养，我不是一时又说不服不了她，行，你不是要养鹦鹉嘛，咱们先去看看鹦鹉到底怎么样。到了花鸟市场，虽然咱们去之前，但花之前完全没有想到，鹦鹉除了好看，它还会拉便便，还会发出刺耳的叫声，一看到这些，她就不想养鹦鹉了。

说这个是想告诉你们，你决定饲养一种宠物之前，那首先先要了解它，近距离接触它们观察它们，认真想想，自己到底是否愿意照顾它们，陪伴它们。

# 只有三种鹦鹉是可以养的

还有一点非常重要，鹦鹉有很多种类，而且，只有三种鹦鹉是可以由普通的鸟类爱好者作为宠物或者合法饲养的！包括最常见的虎皮鹦鹉、还有从黄到白到红白黑绿色的牡丹鹦鹉，以及身上有块红毛，脑袋上戴个风扇，体型稍大一些的虎皮鹦鹉。其他的鹦鹉，如果你想养的话，需要一些特殊的下续才合法，而且一般的爱好者是无法办理这样的手续的。

很多人都喜欢养鹦鹉，因为从某种意义上来说，鹦鹉真的是非常棒的伴侣动物——所谓的伴侣动物，就是可以虽然跟其他生活在一起，陪伴人类的食物。虽然鹦鹉非常吵闹，但它们也非常聪明。比如，很多人都会说使用工具的能力是大人和动物最本质的区别。然而，鸟类学家们观察到，很多种鹦鹉也会使用工具。有一种鹦鹉叫侏儒风头鹦鹉，它们会捡起小树枝，用它们来把声音从巢洞传进信息；或者抓起小木棍、小石头，投向敌人，驱赶它们。此外，还有很多人观察到鹦鹉拿起羽毛痒痒还用……

而且，鹦鹉是一种很愿意亲近人类的鸟类。如果你有它，它只会飞得离你非常近，即使你，那么它也会变得非常黏你，愿意站在你的手指上、肩膀上，甚至愿意接受你的训练，来帮你做一些事情，或者进行一些表演。

正是因为这样的特点，很多鹦鹉都受到了非法贸易的威胁。有些人，他们从野外捕捉鹦鹉。破坏鹦鹉的正常生态，说的非法的饲养者。所以，除了上面说的三种鹦鹉之外，其他的鹦鹉，你都不不要随便饲养，因为很可能是违法的。

# 最长说话的的灰鹦鹉

鹦鹉另外一个重要特点就是会说话。咱们中国有一句话叫“鹦鹉学舌”，这个成语的出处就是鹦鹉会说话。其实，大多数鹦鹉可以接受训练，开始说话，只不过，有些训练起来容易，有些训练起来很。比如前三种能够训练的鹦鹉里，虎皮鹦鹉就是相对比比较容易训练说话的。

但灰鹦鹉的说话能力比不上灰鹦鹉。灰鹦鹉是最长的说话鸟，而且能发出200种完全不同的声音，其中有相当部分是模仿其他鸟类。

最著名的一只灰鹦鹉，名字叫亚历克斯。亚历克斯是1976年出生的，由美国鸟类学家莱尔·赖伯特（Liberator）养大的，被称为世界上最聪明的一只鹦鹉。

包括艾琳在内的，很多鸟类学家相信，亚历克斯不只是靠形象盲人一目，而是能理解词语的意义。它甚至能做做一些简单的加减运算。艾琳甚至尝试过把亚历克斯的词汇做扩充。比如，它学过核桃这个词，cherry，也学过香蕉这个词banana。但是它并不知道苹果这个，Apple。然而，为了吃到苹果，它创造了banana-egg这个词，来表示形状像樱桃，而吃起来又有点像香蕉的东西，也就是苹果。

不过，亚历克斯已经去世了。2007年9月的一天，晚上，艾琳离开实验室的时候，亚历克斯向她告别了。没想到，这是它说的最后一句话。那一年亚历克斯31岁，考虑灰鹦鹉能活60年左右，亚历克斯去世时的年纪差不多相当于人类的40岁。

# 最珍稀的是小蓝金刚

因为非常稀有，所以灰鹦鹉是非法贸易的严重受害者。但它们依然不是最珍稀的鹦鹉，甚至这个世界上专门给鹦鹉介绍的鸚鹦鹉都不是世界上最珍稀的鹦鹉。世界上最珍稀的鹦鹉叫做小蓝金刚鹦鹉。

这种鹦鹉现在活着的个体，几乎完全不存在人类的饲养条件下，而野生小蓝金刚鹦鹉，大概有110只左右。

1990年的时候，人们在巴西的森林林找到了现在是已知的最后一只小蓝金刚鹦鹉。它是一只雄性的鹦鹉，被于是是拯救整个物种的唯一希望。尽管鸟类学家们非常期望给它找个媳妇，好让它们结婚生子，但找了很久，都没有找到。再后来，大家没有办法，只能选了一只雌性的蓝翅金刚鹦鹉，这两种鹦鹉比较接近，鸟类学家希望它们结合之后，能生出小鹦鹉来。然而，这样的尝试失败了。随后，人们又试图养这只雄金刚中挑选了一只雌鸟，小雌鸟果然死了。再之后，再没有人敢乱提它介绍给对象了。2000年，雄性小蓝金刚鹦鹉也终于死去了。

小蓝金刚原本生活在巴西雨林里，然而它们的故事也打动了万里之外，哥伦比亚的一个女人，这个人叫谢琳。她是阿拉卡兰岛上一个叫卡塔纳的猴子的王手。他非常喜欢各种各样的鹦鹉，也喜欢动物，在了解到小蓝金刚的处境之后，把自己房子捐献了出来，建立了一个保护中心。随后，他和鸟类学家合作，买出了大概，购买了30多只小蓝金刚，组成了世界上最大的小蓝金刚群。

随后，他们通过人工繁殖的方式，繁育小蓝金刚，如今，这50几只繁衍成的小蓝金刚鹦鹉已经增长到了60只。它已经成为世界上小蓝金刚鹦鹉恢复项目的最重要参与者。更重要的是，谢琳建的保护区也并不是想要养这些鹦鹉，他们将希望它们这些鹦鹉送到它们巴西老家。为此，谢琳又出了一大笔钱在巴西购置了很大一片土地。他在土地上还购买了很湿大。种种小蓝金刚喜欢的树木，最终目的是，希望让这些小蓝金刚，这种世界上最珍稀的鹦鹉回到它们的故乡。
