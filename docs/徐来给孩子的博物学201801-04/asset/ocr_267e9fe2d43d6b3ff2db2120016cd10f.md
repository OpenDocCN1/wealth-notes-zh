# 奶牛都是黑白花的吗？

前段时间，我们先来讲牛奶的生产过程。我那时去参观新西兰和澳大利亚的农场参观考察了几年，这并不是我第一次接触畜牧业了，其实，我也去过爱尔兰和美国的农场。但咱们是奶牛的。

养奶牛是一件特别费事儿的。养奶牛可不是养其他肉牛肉牛，你要每天给奶牛不一样的奶。即便是今天的农活工作已经比较自化了的，并不是像电视剧里描述的奶牛，要挤奶女用手来挤，但是挤奶还是要挤奶女用机器，还可以保持低温的储奶的。更重要的是，牛奶每年2次交配，一部分奶牛赶往挤奶设备上。

不知你留意到没有，我说的是一“部分”，这是为什，奶牛并不是时时刻刻都能产奶的，产奶是有条件的。

奶牛的奶是生了宝宝之后，分泌出来的给小宝宝吃的。奶牛牛完小宝宝之后，农场主会让小牛犊，然后又会不断挤奶的方法，延长奶牛的产奶期。

如果你愿意挤奶，就不得不照顾小奶牛肉，每隔一段时间，牧场主也需要让奶牛再次怀孕，再次生下小牛犊，才能继续供奶。

![](bbox=[0.1, 0.63, 0.9, 0.71])

也有一些国家，为了动物们的健康，规定了奶牛的最长产奶时间，比如在澳大利亚，一头奶牛月13个月的奶之后，就必须休息6个月。

说到，我还是要回答两个经常被问到的问题，它们是不是都是黑白花的，以及奶牛有没有公的。

其实，黑白花的奶牛只是一个特殊的品种，它叫荷斯坦奶牛，是世界上最有名的奶牛品种，因为荷兰培育出来的，所以也叫荷兰奶牛。瑞士还有其它品种的奶牛，比如娟荷牛。这是在美国被培育出来的一种奶牛，它就是黄色的。

![](bbox=[0.1, 0.86, 0.9, 0.94])

另外，奶牛牛当然也有公的。它们怎样生小奶牛，牛公奶牛产奶，生活中有鸡的数量少，平时很难见到它们。

# 鸡一年能下多少蛋？

好了，说完天奶牛牛和牛奶，接下来该说今天重点讲的鸡蛋了。鸡蛋也是畜牧养殖行业提供的丰产品，我们几乎都吃肉食品，应该很少有人机会去关注鸡蛋的问题，比如，鸡到底能下多少蛋？

在工艺当中，总是描述鸡有规律地下蛋，一年差不多一个蛋。按照这个规律，鸡一年也能下365个蛋。

但我们看野生环境下的，没有被驯化的鸡，也就是原鸡，会发现，它们只是每年下1个左右，最多是几个左右，一般每年下8个蛋。在极少情况下，也会多生2个蛋，但也不多。
