# 什么是感恩节？

感恩节，在世界上只有美国和加拿大这两个国家正经过。它是这两个国家的法定节假日，美国的感恩节在每年11月的第一个周四，加拿大是每年10月的第二个周四。虽然加拿大人也过，但感恩节说到底是美国人发明的。

那美国人为什么要发明这样一个节日呢？

按照传统的说法，这和美国的早期历史有关，那是400年前的1620年，有一艘船叫五月花号，从英国开到了美国东北区海边一个后来被称为普利茅斯的地方。当时，正值初冬，这个时候，美国东北部的沿海地区的环境条件是非常恶劣的，风很大雪也很大。五月花号上装载的食物并不多，所以在一整年里，船上的人们登上陆地，就立即陷入了困境：周围是凛冽的寒风，没有房子可以躲避严寒，也没有足够食物吃。眼看着，这一船的英国移民就快要被活冻死在异国他乡了。

可就在这个时候，当地的印第安人向他们伸出了援手。不但搬出了村庄给他们居住，还提供了足够的粮食补给给他们。在印第安人的帮助下，五月花号上的乘客才没有被严寒打倒。

第二年，在印第安人的帮助下，他们开始种植粮食，并且得了个丰富的收获。这些英国移民为了庆祝自己在新土地上的第一次大丰收，邀请印第安人来一起分享自己的成果。他们这个庆祝习俗延续了下来，变成了感恩节——他们感恩的是印第安人的帮助之恩。

![](bbox=[0.2, 0.94, 0.9, 0.0010400000000000001])

不过仔细想想这个故事，就会觉得似乎很可疑，其中有些说法，是违反自然规律的。

在自然生态的条件下，如果一个环境食物是充足的，那么人口就会自然地增加。随着人口的增加，食物就会变得不那么充足，甚至变得非常紧张——我之前跟你讲过复活岛的事。复活岛的崩溃，实际上就是这么一个过程。

在故事中，印第安人能拿出很多食物来支援“五月花号”移民，那么，他们为什么不去占据更多的土地来发展生产呢？还腾出土地和村落来给移民们听——听起来有些不合理哩。

还有，欧洲人发现美洲这块土地是在1492年，那是伦布发现的。但又过了100多年，五月花号才到来，在这100多年里，到底发生了些什么呢？

实际上，和很多人想象的不一样，当时的美洲并不是荒芜的大陆，这里居住着许多印第安人。沿着如今美国的东海岸线一直走，就会发现，到处都是村落，人民非常稠密，在这100多年里，不少欧洲人造访这里，有些人大张旗鼓做生，也有些人被直接杀光或者赶走。

迎接“五月花号”的印第安人，是一个名叫万帕诺亚部落的。这个部落原先有2万人，是规模很大的部落。他们并不喜欢欧洲人，但愿意跟欧洲人做生意，把从欧洲人手上收购来的货物，转卖到内陆地区的其他部落去，再从这些部落里收些皮货之类的货物，卖给欧洲人。

然而，就在五月花号到来之前的几年里，这个部落的人口数突然开始下降，而且降得非常快，从1620年的时候，这个部落已经只剩下1000多人，大部分村庄都已经没人了。

更糟糕的是，万帕诺亚部落还受到了来自附近的其它印第安部落的威胁。一个名叫纳拉甘西特部落就开始向此地发动进攻，纳拉甘西特将十分危险。当时万帕诺亚部落酋长马萨萨依做出了一个影响深远的决定：要在当地搞联合阵线，和“五月花号”的乘客们联合起来。玛丽安提供了粮食和居住的村落，而“五月花号”的乘员则要帮助他们打击纳拉甘西特人。

战争并没有如所期而至。而是超过了50年。欧洲人终于消灭了纳拉甘西特部落。不过，和纳拉甘西特部落一起消失的，还有当地的许多其他印第安部落，甚至包括万帕诺亚部落。实际上，这是一场欧洲人和印第安人之间的战争。

这场战争的领导者就是酋长马萨萨依的儿子，“号”非利普。他联合印第安人诸部落对抗欧洲人的定居点，并且掌握了其中的大部分。而欧洲人的反击也让印第安人损失惨重，最终，印第安人战败，“非利普王”也战死了。

# 瘟疫削减了印第安部落的人口

听到这里，你是不是会感到疑惑呢？为什么在“五月花号”抵达之前，印第安人“万帕诺亚部落”的人口会突然下降，变成原先的十分之一？答案可能出乎你的意料：是因为瘟疫。

很多科学家认为，欧洲人亚洲的和非洲的流行病，所以这里的人民有更多的流行病斗争的经验。而在美洲，流行病相对比较少，他们一旦感染那些来自欧洲的疾病，身体完全不知道该如何抵挡，很容易就会丢掉性命。在“五月花号”抵达之前，正是由于这些疾病，万帕诺亚部落遭受了巨大的削弱。

所以说，我们现在已经很难去查考“感恩节”起源的故事到底是真的还是假的了。

其实，这种说不清楚来由的节日历来故事，不比现在国内在中医做过的端午节的情。比如说每年5月份会放假的端午节吧，咱们现在在说着“午”节，总老是说人们为了纪念大诗人屈原而设立的，这个说法后面有一点是出错的，那就是端午节起源于古代的楚地，也就是现在的湖北、湖南地区。

这个节日的起源，其实是最原始的“恶日”，恶魔的时候，这是一个毒辣的节日，因为这时坏天气转暖，各种毒辣虫子都出来了，瘟疫疾病也开始变得常见起来。所以大家办一些祭祀活动，来祛除邪气伤害，迎接新的东西。后来，这个节日就被赋予了纪念屈原的意义，原先“恶日”的说法，反而渐渐淡忘了。
