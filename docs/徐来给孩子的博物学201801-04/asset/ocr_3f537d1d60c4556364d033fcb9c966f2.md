# 医学·人类 | 医生为什么要穿白大褂？

世界好大，奇妙的事情每天都有，就让我们一起出发去吧！

听到“医生”这两个字，你脑袋里会出现怎样的一些东西呢？打针吃药，听诊器还是体检证。不管怎样，你只看到穿白大褂的人，于是对于大家来说，医生穿什么，都会有点紧张着。从问题来说了，医生为什么会穿白大褂呢？这个象征到底是什么呢？

白大褂几乎就是医生的象征了。这个特征太有代表性了，以至于你只要有看到穿白大褂的人，不管是不是学医，是医生的社会地位，都会下意识地把白大褂和医生联系起来。

今天我们就来说说医生为什么要穿白大褂。

# 医生的早期着装

其实最早的时候，医生并没有固定的穿着。不管是在东方还是西方，医生的穿着都很随意。比如中国古代，医生是包医大户的，一般的读书人穿什么，他们也就穿什么。在西方，很长一段时间内，医生们穿的衣服跟宗教神职人员一样。原因很简单，在古代，西方人，能够接受救治的，不是贵族就是神职人员，贵族肯定不会当医生，那只能由神职人员来充当医生。后来，出现了非神职人员大夫，但大家也习惯穿着神职人员一样，给大夫看病。

再往后，差不多两百多年前。这个时候的医生已经发展的很好了。医生的社会地位提高了，收入也变得相当不错。这个时候，欧洲的医生穿着也变得讲究起来了，纷纷穿得像是神职人员，戴上了帽子，穿着束腰礼服、绅士，一尘不染，看起来斯文。但得指出来的是，在那个时期，医生的穿着是与众人不同的。这就是欧洲的所谓“黑衣时代”。

当时，一种叫做“黑死病”的瘟疫传遍了欧洲，据说一天欧洲两千人因此死去。在黑死病流行的时间里，医生的工作变得尤其重要，而且，他们自身也要防止感染。所以，一开始，穿一身黑色的服装，宽大的拖到脚面地的长袍，像鸟一样的面具，宽边礼帽和手杖。衣服边缘是皮质的，浸过药膏，据说能防毒。面具那个长长的鸟嘴里面塞满了草药和香料，也是为了防毒。听起来就可以让医生在检查病人，无需直接触摸病人的身体，这样装束当然没有太大防菌的实际意义，至少所有人都有这装备，就不会有黑死病了，对吧。

后来，白袍就因为这个形象看起来阴森可怕，竟然成为了恐怖电影里的经典形象。

# 医生着装与死亡率之间的关系

事情的变化跟巴斯德有关。我之前在《牛奶为什么开始喝奶》里面讲过巴斯德的故事，他就是如何发现微生物导致疾病的原因的，又如何发现了狂犬病疫苗，救了在美国的病人……其实，这个白大褂也是来自他的影响。

英国有个医生叫李斯特，他发现一个有意思的规律：骨折的病人，如果伤口是开放性的，骨头就愈合了，但血和肌肉暴露了出来，那么在治疗的过程中，他很可能就死掉；而如果伤口是闭合性的，也就是说皮肤没有受到伤口，那么多半能康复。李斯特很好奇这些不同现象的原因，意识到在伤口里乱的环境里感染了微生物，发生了感染，这才导致伤口病人死亡。

于是，李斯特在自己的诊所里开展了一系列改革，比如说，如果要做手术了，那么所有的手术工具，都要先消毒药剂浸泡过。医生在接触病人之前，也要先用消毒药涂上。与此同时，李斯特让医生们都穿上白衣服——这就是现在医生的白大褂的前身。

李斯特的一系列改革，其实挺成功的。来他诊所看手术，死亡的病例大幅下降。但是，当时大多数的医生并不相信他，就他洗手，换件衣服这样的事儿，就能降低病人的死亡率。他认为，要真正这样简单的，那病人如果洗手，换件衣服，是不是就不会生病了。

也有些医生注意到了李斯特所说死亡率下降的事实。不久，德累斯顿一家医院里的夫人将细菌放到自己的医院推广了李斯特的做法。没想到，效果立即出现了，死亡率开始下降，而且下降得如此明显，令人不能忽略到这一点。

李斯特的大名一下子就传开了。欧洲各地的医院纷纷开始效仿他的做法，很快，白大褂就变成了医生们在做手术时的标准装束。

我在下面配了两幅画。它们出自同一画家之手，美国人伊萨斯，这两幅画描绘的时间，相差也不过两年：一幅叫《格雷医生》，是伊萨斯1875年的作品，第二幅，叫《阿格纳诊断》，绘制于1889年，前后相差14年。在你看这两幅画，感受到差别。在前面那幅画里，手术室里忙碌的医生都是西装革履的，而后面一幅作品里，医生们都换上了白大褂。

选择白色的原因很简单。因为白色象征着纯洁，无论是希腊神话中的众神，还是古代罗马的议员，身上穿的都是白色的袍子。

当然，白色的大褂还有一层更深的意义，那就是这是最显脏的颜色。任何污渍、血迹在白色大褂上，都无法对显示，污迹还是血迹，也是时刻提醒着医生们，在接触病人之前，一定要保持清洁，避免把更多的疾病带给患者。

不过，现在也并不事所有的医生都穿白大褂。在有国家，几种类医生或者科研人员根本就不穿白大褂。因为研究发现，白大褂很容易让人上火。这一点无非是对患者的心理，甚至是对于需要精神护理的病人来说，都未必是好的东西，这些科室的医生就有可能会选择他们颜色的工作服装，或者干脆穿便装来给病人看病了。

——博物学家养成记——

不知道你们注意到没有，虽然最开始的时候医生们是手术室里穿白大褂，然后才出现在医院的各个科室，但现在的医生，医生而不穿白大褂，穿紫色或者蓝色的手术服。

原因很简单，因为在手术的时候，医生的视野里有大量的红色，在盯着红色的东西看了太久了，看到白大褂其他衣服，护士自己也大，会看到白色的背景上出现多绿色的鬼影，这种现象被称为“视觉后像”。你自己也可以试试，先盯着红色的东西看一会儿，再看白墙，也不是也觉得怪怪的。这种现象可能会干扰
