# **师弟,你好**

我是徐来。

咱们这一年的博物学探索旅程虽然暂时告一段落，但学习的旅程才刚刚开始。

所以今天，我想把「 少年得到」App，郑重推荐给你。

简单来说，「 少年得到」就是专门为像你这样的优秀少年服务的学习类App。

咱们「 得到」是专门服务成年人的，你和父母在一起学习，毕竟不方便。再说，咱们少年，就应该有自己的新天地，对吧。

我给你介绍的「 少年得到」App，就是这样的一个新天地，我觉得里面的内容更适合你，也更有意思。

我自己体验过，里面的内容特别多。有各种课程，有专门给少年的听书。我最喜欢的是这里面专门给少年听的新闻栏目，叫「 地球电讯」，每天5分钟，会讲世界上各种有趣的新闻和长见识的知识。

我和我女儿都特别爱听，每天早上我们都会在餐桌上聊聊听到的新闻热点，常常还能热烈讨论很久。别说他了，我都有收益。

除了「 地球电讯」，我还很喜欢林欣浩老师的「 数学有意思」这门课。最近，我女儿和女儿一起听，发现全是她上小学时没听到过的内容。我当时就在想，如果小时候能有这样的老师给我讲这些内容，那今天的我会变成什么样子呢？

另外，我还有一个最新消息要告诉你。「 少年得到」今天上线了郝广才老师的写作课！郝广才老师，就是「 得到」里「 今天」订阅专栏的主理人。他是中国著名的作家，也是我的偶像。据说这次「 少年得到」非常难得，把郝广才老师33年积累的、最珍贵的家底都挖出来了，编成了一门特别有意思的写作课。这门课肯定是要听的，因为写作这件事儿，是一辈子都学不完的，他的课一定能对我有帮助。你听完这门课，肯定会有很大的收获！

另外一个好消息，我给所有我们博物学专栏的同学们都申请了特别福利。你需要到手机应用商店搜索「 少年得到」，点击下载这个App，注册完后，点击你的头像进入到「意见反馈」里面，输入我们的福利暗号：博物学

这三个字，就能得到我们专为你争取的，也只有博物学专栏的同学们才能独享的10元奖学金。

钱真的不多，但是我的一份心意。以后我有新的课程，也会在「 少年得到」推出，让我们相约少年得到。现在就下载吧！
