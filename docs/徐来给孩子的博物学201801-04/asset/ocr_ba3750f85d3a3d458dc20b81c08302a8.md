这种鱼，大家会比较喜欢生着吃，因为鱼里面含有丰富的高的油脂，口感非常柔软鲜美。如果煮熟了吃，不管是清蒸、烤还是红烧，都会失去那种爽软肥嫩口感，但是在咱们口中，生吃肉，对大部分人来说都像是一种残忍。

确实，如果习惯了这种生吃的口感，三文鱼还真是非常美味的。今天我就来跟你一说说这种美味的三文鱼的故事。

# 三文鱼到底是什么鱼？

三文鱼其实是一个音译，它的英文是salmon，听起来跟中国的三文鱼也不是很像呀？现在，我们会用上三文鱼这个名，来称呼很多种鱼。但是最初，它指的是一种鱼，这种鱼叫“大西洋鲑”。它是一种鲑鱼。

大西洋鲑，你看名字就知道了，生活在大西洋里，尤其是欧洲附近的海峡，这个鱼特别多。它在习性上有一个非常有意思的特点，它们总是在一个非常上游出生，然后沿着河流流向海里，在海水里长大。之后，又要回到河中，向上奋力溯流而上，碰到浅滩就冲洗过，碰到瀑布就跳上去，努力自己出生的地方，产卵。而且，在它们流出生的时候，它们身体的颜色也越来越红（下图）。

三文鱼的这种习性，叫做洄游性。很多海洋鱼类都有这种习性，三文鱼是其中最典型的一种一想象一下，它们也真是不易。

不管怎么样吧，反正欧洲人对三文鱼，那真是要多熟悉有多熟悉。后来，欧洲人到美洲，经历了千辛万苦，终于摸索到了大美洲，抵达这个地方时候，他们很快就发现，在这个地方竟然有很多跟欧洲这些非常相似的鱼。所以，欧洲人开始把这些鱼全部都叫“三文鱼”。可我们现在这些鱼会吃到真正三文鱼。我拉斯的三文鱼，其实就是太平洋的鱼三文鱼。

其实，太平洋里鱼的这些“三文鱼”，对当地人来说一点都不知道，比如咱们国家东北地区的小朋友们，刚接触认识和吃这种鱼了。大家都叫它们大马哈鱼。

后来西方人也注意到了，生活在太平洋里的三文鱼和生活在大西洋里的不太一样，所以把它们分成两群，一群叫鲑属，一群叫大马哈鱼属或者太平洋鲑属。但无论如何，它们都是亲戚。

现在，为了把最那种三文鱼，也就是大西洋鲑从大多“三文鱼”当中区别开，有时候，人们也会把它们叫做“挪威三文鱼”。

# 半路杀出了条吃鳃

刚才我们说到，三文鱼有洄游的特性，总是逆流而上，回到淡水河流上游，自己出生的地方，才能继续繁殖下一代。

这里，体现着鲑属鱼类和大马哈鱼属鱼类之间一个非常重要的不同之处。大部分鳃属的鱼类，在回到出生地繁殖之后，还是健健康康，然后它们又将一个个顺流而下，返回大海，再孕育下一代繁殖它们的卵故事，再次繁殖。我们平时最常见的挪威三文鱼就是这个样子。

但大马哈鱼属的鱼类就不同了。它们当中的绝大多数，一生只有一次繁殖的机会。等到时机成熟的时候，它们同样逆流而上，回到自己出生的地方。在这个过程当中，它们中的一些品种，身体会变成鲜艳的红色。随着河流渐渐变窄变红色，它们成群结队挤在一起，变成鲜红色的一大片。最后，它们会在自己出生的区域交配繁殖，繁殖完成之后，它们就会在这里死去。

或许你会想，河流的上游，水其实非常少。如果有大批的大马哈鱼死在这里，那岂不是光用鱼肉就要把河道堆满，把河水都脏了？

其实，这样的情况很少会出现。因为这样大群的鱼肉马哈鱼冲过来，那简直就河中流浪着的猫狗，尤其是遇到很多群猫都围，就像很容易饿死。在很多地方，有大马哈鱼的地方就有熊，熊会定期聚集到有产卵的鱼流上，捕获它们。在有鱼比的位置上，鱼类真的是毫无意义，比如小河里的边上。大马哈鱼为了跳上瀑布，往往会用尽全力躲开。有些会跳得太高，直接落到了飞熊嘴里。

实际上，因为熊的捕杀还有路途中是繁多死亡，每年只有百分之三十的大马哈鱼能回到出生地内进行繁殖。

# 鱼肉为什么这样红？

无论你是吃过三文鱼，是否喜欢三文鱼，看一种肉的这种有配的肉色就会发现，这种鱼肉是一个非常有趣的点：它是橙红色的。在这种动物食物当中，还很难再了。那么，三文鱼的鱼肉，为什么是橙红色的呢？

其实，这种鱼肉当中所含有的一种色素有关。它叫虾青素。虾青素就是橙红色一实际上的，这种色彩跟胡萝卜素非常接近。所以，有些三文鱼养殖者会在饲料中添加胡萝卜色，这样，三文鱼的肉色看起来就会更鲜更可爱一这因为肉色加胡萝卜对人体没有坏处，所以这个做法在很多国家都是合法的。

至于虾青素明明是橙红色的，为什么却要叫虾青素呢？其实，顾名思义，虾青素类的动物身上，也有很多种颜色。而且，在虾的身体上，它也会和一些蛋白质结合，呈青绿色一这就是虾青素名字的由来。也是为什么螃蟹和大虾活着的时候看起来是灰绿色绿灰绿色的，一熏煮后，原来的那些蛋白质就失去了活性，不能跟虾青素再结合了，虾青素才露出了红彤的本来面目。这也是为什么虾蟹类的食物加热之后，会变成红色的。

博物学家养咸记

是不是很有意思？不过，关于三文鱼，有一件事情一定要知道。在一些地方，人们会把淡水鲑鱼，比如虹鲑也吃成是文鱼，并当来生吃。这种做法是很危险的，因为淡水鱼的寄生虫比较多，而且这些虹鲑往往也没有经过冷冻处理，所以这样做很容易感染寄生虫。请务必不要生吃所谓的淡水三文鱼。

+   1. 我们最熟悉的那种橙色鱼肉的三文鱼，正式的名字叫大西洋鲑。后来，欧洲 渔民在太平洋东岸发现了类似的鱼，就它们也叫太平洋三文鱼。太平洋三文鱼 也就叫大马哈鱼；

+   2. 三文鱼和大马哈鱼都有洄游的 习惯，总是逆流回自己的出生地内繁殖。三文 鱼大都可以多次繁殖，而大马哈鱼多半 只有一次。阿拉斯加的大马哈鱼繁殖的 重要参考。每次只的0大马哈鱼， 能完成逆流而上的征，参与繁殖；

+   3. 三文鱼体肉的红色是虾青素。虾 青素在鱼体内部会和蛋白质结合，呈现 蓝绿色，煮熟，蛋白质活失活，呈现 红色。在三文鱼内，它们一直是 橙色的，还有些养殖者会在饲料中添加 胡萝卜素，让们变得更鲜艳。

三文鱼，中文名叫大西洋鲑，欧洲渔民 在太平洋东发现的大西洋三文鱼，其 实是鱼的大马哈鱼，它们都洄游性， 要找到它们出生和繁殖的地方。
