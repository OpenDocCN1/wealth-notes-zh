# 气象学 地球 | 雪花是怎么形成的？

世界这么大，奇妙的事情每天都有，我们一起去发现吧！

现在，在中国的很多地方，天气已经非常冷，北方很多地区的地上，积雪应该已经铺满了。

但是今年华北地区因为降水太少，所以并没有怎么下雪。很多人对此感到很失望，因为错过了今年最珍贵的赏雪时节，就像没看到漂亮的雪景了。你在课本上很可能见过雪花的细节书，当是一种非常六角形的小冰晶。但雪花到底是什么东西呢？它为什么会长成六角形这样规则的形状呢？今天我们就来说说雪花的故事吧。

# 雪花的第一篇论文

古代的人们很早就注意到了雪花这个奇形怪状，也有很多科学家对雪花进行了研究，写下了很多的研究论文。其中最著名的一篇，作者叫做开普勒，是一位天文作家。开普勒已经是咱们熟悉的熟人了，我以前跟你讲过开普勒定律的事情。

当年开普勒曾经在神圣罗马帝国的布拉格这个地方，正在做给皇帝鲁道夫二世当数学顾问，那是某一年的年底，快到圣诞节了，很可惜，鲁道夫二世不知道是忘了还是怎么的，竟然好几个月都没开开普勒发工资了。

年关将近，开普勒又烦又冷，走在布拉格的街头，想想朋友买东西，自己却身无分文，不知道该怎么办。开普勒有些伤感，自己的真的是一个只有nIx的人。Nix是德语，拼写就是N·h·I·X，意思是“一无所有”。这个时候，突然，天空中飘落下一片雪花，落在了开普勒的怀里。开普勒突然有一种心情。Nix这个词由字母组成的单词，有一个叫拉丁语的更古老的语言版本，是雪花的。开普勒心想：那我自己就给朋友送一个“一无所有”吧，嗯，不对，是送一个NIX雪花的。

开普勒说干就干，赶紧回到家屋里开始写关于雪花的论文。论文本身就是用拉丁语写的，讨论的问题就是雪花为什么是六角形的。为了想对英语的这个特别的礼物，开普勒写的也很随意，他没有去认真地研究这个问题，只是根据地域假说，六边形、三角形和正方形是可以平面全部铺满的图形。有趣的是，你自己可以画画看，有边多不是六边形，为什么雪花的形状必须是它可以平面全部铺满的，为什么只能是三角形或者正方形……关于这个问题，开普勒没说到。

就这样，开普勒就直接把这论文作为新年礼物，送给了朋友。虽然他没有给出明确回答，但他毕竟是第一个问出“雪花为什么是六边形”并试图探究这个问题的人。后来，人们追认这篇论文为雪花研究的开端之作。

# 雪花的研究历程

后来，很多科学家都尝试记录和研究过雪花的形状。

法国非常著名的数学家、哲学家笛卡尔第一次用文字详细地描述了雪花晶体，其中有一些雪花的形状非常常见。他提到，构成每朵花的一些，每朵花都是六角，每一个夹角都像彼此一样。雪花结构真的是太精巧了，笨手笨脚的人类恐怕是做不出来这东西的。

第一个直接记录雪花的图像，是罗伯特·胡克。胡克是一位物理学家和发明家，他亲手制作了一台显微镜，并且用它来观察身边的万物。他是最早观察到晶体，且为细菌命名的人。他用自己的显微镜观察了雪花，还把自己看到的雪花的样子给画了下来。（下图）
