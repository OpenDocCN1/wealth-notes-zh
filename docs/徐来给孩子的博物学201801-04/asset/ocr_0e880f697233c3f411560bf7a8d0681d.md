# 行为学动物｜两岸猿声为什么啼不住？

世界好大，奇妙的事情每天都有，我们一起会发现吧！

你听过李白的《早发白帝城》吗？这首诗非常朗朗上口，几乎背得出来，读着读着，诗意就出来了：朝辞白帝彩云间，千里江陵一日还。两岸猿声啼不住，轻舟已过万重山。

这首诗是诗人站在长江边上所作，长江是诗人最熟悉的河流，所以他能将这首诗写得那么栩栩如生，读起来就特别有画面感，仿佛身临其境。

那么，诗中的猿是指哪些动物呢？根据科学家的研究，长江流域曾经生活着一种叫长臂猿的动物，它们栖息在高大的乔木上，善于跳跃和悬挂，是典型的树栖猿类。

# 曾经分布到四川的长臂猿

关于长臂猿分布的最有力的证据，就是一些化石和骨骼的出土。这些出土的标本分布范围广，从南到北，跨度达到7000公里。其中，最北的长臂猿骨骼化石是在四川省北部发现的。这说明，至少在数千年前，长臂猿在四川地区也有分布。

# 长臂猿的“语言”：跳跃和鸣叫

虽然长臂猿在长江的两岸都发现了它们的踪迹，但科学家的研究表明，诗中的“啼”很可能指的是长臂猿的鸣叫，而非人类的啼哭。长臂猿拥有非常发达的发声系统，它们可以通过跳跃和鸣叫来进行长距离的交流，这种行为在生物学上被称为“长臂猿合唱”。

据观察，长臂猿的合唱往往在清晨开始，此时是它们活动最频繁的时刻。它们会站在树冠层，用响亮的声音彼此呼应，有时会持续数小时。

# “哀鸣”到底是怎回事

古人听到长臂猿的鸣叫，结合当时多愁善感的时代背景，往往会联想到离别的悲伤，因此用“哀”来形容它们的声音。而现代研究发现，长臂猿的叫声其实非常悦耳，有时甚至被形容为“森林里的交响乐”。
