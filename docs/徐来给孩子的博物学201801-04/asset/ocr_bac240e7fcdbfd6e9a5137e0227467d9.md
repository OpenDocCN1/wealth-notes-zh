# 历法学人类 | 2月30日的...

今天我要先问你个问题：有那么一个日子，如果谁的生恰好赶上了，就会变得很“悲催”，当然了这个悲催是带引号的。一倒霉，这就是什么恶运？

想不出来的话，翻翻日历就知道了，这一天是2月29号。因为2月一般只有28天，每四年才会出现一个闰月。闰月有一天，才会有2月29日，也就是说，如果谁的生日是2月29日这一天，他得4年才能过一次生日——你说悲不悲催。

你可能会想，其他月份都至少有30天，为什么2月是30号都没有呢？今天，就给你说说这个问题。

# 罗马时代留下的历法

大家现在用的这个日历，在咱们国家，就叫公历，意思是公用历法。也有人叫阳历的，因为这是2个月份的依据是地球绕太阳公转的周期。但是东西方的方法就不叫公历了，而叫格里高利历，诶呀，这个真不好念，所以有时也简称格里历。这个格里高利，是一个人，名字是格罗里高利，他是罗马教宗，也就是罗马天主教会的教宗，在教会里的名字叫做格里高利。罗马教宗一世的姓名，不是个高利罗格里高利的。咱们今天叫这个名号，是所有教宗当中，第3个名叫这个名号的一位，所以大家称他叫格里高利十三世，生活在400多年前。

再往前，公历就叫做儒略历。儒略也是一个人，不过这位是罗马的翻译王哈，可在咱们这儿算了。叫朱利叶斯，对，他就是大名鼎鼎的朱利叶斯·凯撒，2000多年前，罗马共和国的统治者。

再再往前，叫罗马旧历法，是传说中罗马有以来的第二位国王田庞皮乌斯制定的。咱们叫它儒的历法历法，得多感谢田庞皮乌斯制定的这个日历，比如罗马1在一年有12个月，这就是庞皮乌斯规定的。这12个月有8个月是29或者30天，唯独2月是28天。这么一来呢就是355天一年很明显，这样多了一天，因为正常的公历周期是略多于365天，差了10天。所以呢，庞皮乌斯利又规定了多少出来的10月为闰月，在2月份的前中间，每两年出现一次。总之，就把历法搞得非常繁琐。

# 闰月的大麻烦

繁琐的历法很容易被搞混。所以到了凯撒那个时代，历法各季节的实际情况已经相差很多了。凯撒决定大刀阔斧地修改历法，那是公元纪元前45年的时候，他确定了自己名字命名的儒略历。这个历法，确定了一年现在用的月份及每个的的长度，一年十二个月，大小月交替。大月是31天，小月是30天，这样一年来就应该得是366天。不过，一年应该是365年又略多于一点，儒略历却也因此定成了365天，就要从这里头扣除掉一天。扣掉嘛，这样呢，反正2月份就挺短一点，就扣这个月的吧，这么一来，二月份就是29天了。

朱利叶斯·凯撒本人是7月份的生日，大家一听，这是不是太人物，咱们得纪念一下，就叫朱利叶斯，现在英语读起来是Julius，就是从这儿来的。凯撒死后，他的继承者是大维，罗马独裁官凯撒还是厉害，是罗马帝国的第一个皇帝。他是8月份的生，既然7月份给了凯撒，那8月份也得拿出纪念一下。于是，大家都亲切的称奥古斯都来命名8月了，现在英语里说八月是August，也是从这儿来的。

这么就有了问题，8月本身是小月，但是不能让它小一点就是小月呢。于是，大家就以十一月分为界线，7月份之前，单数月是大月，双数月是小月；8月份之后反过来，双数月是大月，单数月是小月。可是这么一来，每年又多了一天，怎么办呢？老办法呢，继续从2月份扣。

不知道你有没有意思，我刚才说了一年的长度，也就是说地球绕太阳公转一圈的时间是365天又多一点。儒略历规定的一年是365天，少了一点方式来，补法，就是设个闰年。但是，当时大家放宽时间的规定不太准确，跟地球公转的实际情况还是差了不少。

一晃就过了一千多年，儒略历的日子比地球实际的历情形已经差了整整10天。罗马教会有些日子已经了，怎么为了月历的误差太到了他们推算一些宗教节日都推不准了。当时正好是罗马皇帝格里高利十三世的时候，他一言下令，在儒略历的基础上重新制定了闰月的安排方法，这个方法，一直沿用到了现在。
