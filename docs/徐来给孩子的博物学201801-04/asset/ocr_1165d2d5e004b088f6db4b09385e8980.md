昨天我给你讲的是白鱀豚的故事。在结尾的时候，我跟你提了一个小问题，长江里还生活着一种豚，它叫什么名字。

可能你已经看到了一种，那就是长江江豚。虽然同样生活在长江里，但江豚的外形跟白鱀豚差别很大，别的不说仅颜色就不一样，江豚是黑色的，而白鱀豚偏白。

你可能要疑惑了，是黑色只有四种淡水豚，长江、恒河、亚马逊河、拉普拉塔河各一种嘛，怎么又多出来个江豚呢？

其实，江豚虽然可以生活在长江里，但它们是主要生活在海里的，叫做露脊鼠海豚，生活在长江里的，只是其中很少的一部分而已；从分类学上，差别也很明显，前四种淡水豚属于淡水豚科，而江豚则属于鼠海豚科。

不过，咱们今天不说江豚，要说的是鼠海豚里的另一种，叫做加州湾海豚。

# 加州湾鼠海豚数量为何急速下降？

顾名思义，加州湾鼠海豚生活在加州湾。加州呢就是加利福尼亚州，可别一听到加利福尼亚这个名字咱们就想到美国，加州湾和墨西哥也有关系。咱们看看地舆，加州湾有一点点像是一只松鼠的侧面，在袋鼠腿的一前一半，合身的一个半岛，那个那个是佛罗里达半岛，自身的那个就是加利福尼亚半岛，被加利福尼亚半岛围起来的，就是加州湾了，这个地方完全是属于墨西哥的。

加州湾鼠海豚既然生活在的这个海湾，它差不多就是最早被发现的海豚之一了。整被发现的1958年，因为几个奇怪的个体游进了海洋，科学家们才注意到有这个物种存在。

虽然知道这个物种的存在了，但在随后的几十年里，科学家们却始终不能清楚这种动物一共有多少头。直到1997年，他们才设法比较准确地估算出这种动物的数量。不消多不要紧，一清点就清点出一个濒危物种来，这种鼠海豚一共约500多头。

在这之后十几年里，加州湾鼠海豚的数量一直在不断地减少。2008年，也就是这个物种被发现之后50年，科学家估计，它们只剩下200只左右了；又过了6年，2014年的时候，这个数字竟然下降到了97！过了两年，也就是2016年，一份报告显示，加州湾鼠海豚只剩下68头了。仅仅半年之后的2016年11月，这个数字又被砍掉了一半—这是最近一次对加州湾鼠海豚数量的估算，这种动物已经到达灭绝的边缘。实际上，所有动物学家都相信，加州湾鼠海豚被列在濒危的面后，成为第二种因为人类的活动而灭绝的海豚。

可是，在这短短的60年里，到底发生了什么？

# 黄昏鱼为何陷入濒危？

这件事儿还要从中国的花鲢说起。

在咱们国家，尤其是南方的一些地方，有一种名贵的食物叫做花胶。你可能已经忘了，花胶我不知道，这个食物专专栏是讲过的，让人感觉金头发是软是软的，这一麻麻的感觉差不多是52赫兹，跟那个孤独的海豚的声音一个频率。

对，我之前讲过花鲢。但今天我要的这个花鲢跟之前那个花鲢不同，花鲢都是一个，jiao是不同的jiao。今天要说的这个花鲢，就是金枪，意思是黏糊的属于胶质的东西。这个花鲢胶不是鱼上取下来的，而是从鱼的上取下来的。所以，它有的叫来就是称作鱼胶。一般，咱们说花鲢是某花鲢的“肚”。这都就是它的胃，牛肚、猪肚、羊肚，都是这个意思。但鱼肚不是鱼的胃，而是说鱼鳔。

鱼鳔是个神奇，它就相当于鱼身体里一个气球的。鱼在水里游的时候，如果要想浮上来，就让自己的鱼鳔鼓点大气，体重轻了，就升上浮；如果要它下，就比较鱼鱼里的气体挤出去，这样鱼就比较重了，就会下沉。

有些鱼，块头很大，它的鱼鳔也很大，很笨重。渔民们捕捞到这样的鱼，把它取出来，晒干，就可以当做很名贵的食用。而所花鲢胶中受到重视的是来自黄昏鱼的“金钱鱼胶”。因为求这种食物，黄昏鱼大量捕食黄昏鱼，结果把黄昏鱼杀到了极度濒危的程度。

等等，今天不是讲加州湾鼠海豚吗，怎么变成了黄昏鱼黄金“财”了。其实，这两种动物之间的关系在某件有关联。黄昏鱼濒危了，从它身上取下来的金钱鲛也变得非常名贵，所以有人开始寻找它的替代品。

# 世界上最危险的鲟鮀

难道人们从加州湾鼠海豚身上找到了金钱鲛吗？哈哈，那没有希望，鲟鮀既不是乳动物，它体内也没有像鲛胶这样的东西。鱼鲛还是从鱼身上去取，这个替代品是加州湾石首鱼。

加州湾石首鱼是黄昏鱼近亲。它的身体里也有石鲛，而且看起来跟金鱼鲛非常相似。所以，就有人取了加州湾石首鱼的鱼鲛，当做黄金鲛胶的一个新商品卖到市场上去了。市场倒也接受这个东西，卖得也还不错。

一看到有利可图，就有人开始打这个加州湾石首鱼的自主了，开始大规模捕捞这种鱼。捞来捞去，你猜怎么着，竟然生生地也把这种鱼也捞成了极度濒危。实际上，现在墨西哥的禁止捕捞加州湾石首鱼了。不过，因为利益诱大了，所以非法的捕捞一直都在进行。由此产生的金钱鲛胶都通过走私的途径被送到了市场上。
