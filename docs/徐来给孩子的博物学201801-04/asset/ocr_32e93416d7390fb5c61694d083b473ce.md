# 追溯母亲的最近祖先

如果我们想要推算现世界上所有活着的人的共同祖先，这将是一件非常困难的事。最理想的状态下，在人类发展的过程中，突然出现了一个大灭绝事件，把一对夫妇之外的所有人都杀死了。

然后，再让这一对夫妇繁衍出所有人类，这样一来，这对夫妇就是人类的共同祖先了。

这样的情况虽然非常极端和夸张，但是在地球的生命史上有可可能发生的，尤其是一些比较重大的灭绝事件之后，当绝大多数的大型生物体都被杀死了。不过，根据人类学家们的推算，他们人数的数量，从来没有低到过这么可怕的程度，最少也要在两千到一万人这个水平上。要构造出几千人的后代巨大的谱系图，那也是极其复杂的难题。

所以，如果我们要搞清楚这个问题，就必须要把问题简化。

简化的方法很简单，不考虑父亲那一支，只考虑母亲那一支。科学家很快就发展出一个人，她被称为“线粒体夏娃”。这是咱们人类母亲的最近祖先。

# 如何追溯祖先

夏娃，这是很多民族的母语中，出现的第一个人类的名字。线粒体就比较难理解了，它是咱们身体里面每一个细胞都含有的一个超级微小，专门供给细胞能量呢。这个超级微小有一个线粒体的信息，它自己带着一套遗传物质，这一套遗传物质和这个细胞本身的遗传物质还不是一回事儿。一些关于这个细胞的一点推测到，线粒体很可能原来是一种独立的生命体，当它被另外一种生命体吞食之后，变成了后者的一部分，而后者也带着线粒体继续进化，直到慢慢进化成我们。

因为我们只能从妈妈那里得到线粒体，自然线粒体的遗传物物质，也是爸爸妈妈的基因。相对于其他细胞都是爸爸妈妈的两套遗传物质拼在一起，这种直接遗传的过程，线粒体要容易计算得多。

科学家还知道一件事，那就是遗传物质在传递的过程中，发生变化的速度是一定的。这样一来，科学家只要去检查各种各样人的线粒体，把人家的线粒体都放在一起对比，而后两者就带着线粒体复制，再根据这个去推断出那个女人来。

这个女性生活在大概20万年前。虽然我们并不知道她到底长，是怎样的一个人，但科学家给她起了名字叫“线粒体夏娃”，认为她还是考虑母系系统，现在地球上还活着的人的所有共有祖先，我们最近的相同祖辈。这句话听起来有点像，你可能是那么理解，如果地球上的人都是一大家子，那距离我们最近的相同祖先，就是线粒体夏娃。

# 一个容易起误会名字

虽然很多人，甚至包括大多数的生物学家都接受了线粒体夏娃这个名字，但是依然有很多人把夏娃认这个名字的，意义，并批评了这个名字。这些人给出的理由从一定角度看，也确实有道理，我们来分析一下。

因为“夏娃”是一个带有宗教色彩的名字，它很容易让人对“线粒体夏娃”这个产生误读。比如，她并不是指地球上第一个女人，实际上，她的年代不一定有很多人类，当然里面也会有很多女性，线粒体夏娃是其中之一。其次，她所存在的时间也不是一定的，有可能她在研究的时间点上发生变化，而且，如果过了一段时间地球上活着的人类发生了进化，因为有的人出生，有的人死去了，那么也有可能“给”线粒体夏娃的认定带来变化。

还有很多人会忽略事实当中的“最近”的含义（注）。其实，现在活着的人类共同母亲祖先可能会有很多很多—线粒体要夏娃，她的母亲也是，她母亲的母亲也是，我们说 Scientific 是科学严谨的，它也就在这里体现得淋漓尽致了。

人类的母亲祖先可以通过线粒体的方式来确定，那父亲祖先呢，其实，逻辑基本原理，所不同的是大小不同，关键在于，正如“线粒体”是从母亲那边继承的，寻找父亲祖先需要先确认一个“祖”而不传女”的遗传物质。这个科学家也找到了，那就是Y染色体。

人类有23对染色体，其中最后一对被称为性染色体。我们的性别是染色体上的。如果两条性染色体都是大写字母X，这个人就是女性；如果一条是X，另一条是Y，那么就是男性，所以，有Y染色体才构成男性，而男性的Y染色体只能从父亲那边获得，这样，我们可以通过Y染色体算出我们最近的男性祖先和线粒体算出来母系最新的共有祖先，是20万年左右。

不过，还是要提醒你们注意，没有任何证据表明线粒体夏娃和Y染色体亚当有可能生活在同一时间的同一地点。
