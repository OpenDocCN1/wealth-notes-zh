# 如何复活一只恐龙

要想弄清楚能不能造出侏罗纪公园来，首先得弄清楚，小说里，作者到底是怎么让想象中变成小说中的现实的？

在《侏罗纪公园》的故事当中，科学家们在复活恐龙的遗传物质，也就是DNA来复活的恐龙。

首先，他们在进行恐龙化石发掘的时候，偶然发现了一块琥珀形成在琥珀的一只蚊子叮咬了恐。琥珀是宝石，包住了树上的汁分泌出来的树脂凝固之后，在包住了这些昆虫和植物，有的植物会包到了甚至包含这些生物。比如蚊子的琥珀就是因为蚊子不小心被树脂粘在一起。

故事里，科学家开始寻找，取出了蚊子，结果发现，这只蚊子在被封印成琥珀之前刚刚吸了很多恐龙血。把这些血液取出来，发现，结果竟然是恐龙的血，至少，恐龙的血。这是世界上仅存的恐龙血标本。

然后，科学家从这些血液中提取出了一些恐龙的遗传物质，再把这些片段补充完整，再进行复制，制造出了活的恐龙，甚至复活了各种早期的恐龙。

总结一下小说里科学家的方法，就是先想办法找到恐龙的遗传物质，然后对这些遗传物质进行比较和筛选，再用某种近似的动物来复恐龙基因，让它在发育的过程中使用恐龙的遗传物质，最后变成恐龙。

那么，这篇文章的现实生活中到底是不是可行呢？

# 琥珀里的藏着恐龙

说到恐龙的遗传物质也就是恐龙的DNA，你一开始想到的是各种各样的恐龙化石。甚至恐龙化石里的恐龙的骨骼或细胞。那么科学家会含有骨骼细胞中的DNA呢？可以想象从电影里那样的场景，科学家运气很好，找到了一块保存着吸收了恐龙血液的蚊子琥珀。

现在我们想知道的是蚊子种类，年久远的可以追溯到1亿多年。可科学家们认为在1.5亿年前，时间上可以追溯，最少在恐龙和哺乳动物出现之前。理论上讲，蚊子有机会吸到大量不同种类的恐龙血，而且，恐龙的血跟哺乳动物和鸟类的太不一样，更容易提取到DNA，所以故事里描述的情况，还是有点依据的。

不过，咱们现在根本不用去蚊子的体内寻找恐龙基因，为了最古老的古生物学家们已经在琥珀里发现过恐龙了。2017年底，中国地质大学的研究者博士和他的团队的一块琥珀当中，找到一个恐龙恐龙，其中的恐龙可能是一只恐龙。我在文章中给你配了它的标本。
