# 乌鸦与水罐

这个故事，我们见过的最早出处，是古希腊的《伊索寓言》这本书，故事的标题叫做《乌鸦与水罐》，伊索寓言相传是伊索写的，伊索曾经是个奴隶，生活在差不多相当于咱们中国的春秋早期那个时期。他写这个故事的时候，没有太大的影响，到了一千多年前公元五世纪的罗马帝国时代，才有高手将其整理。这个故事表达的意思是，智慧比蛮力更重要。后来，很多作家都尝试过这个故事，甚至有人认为，这个故事表达的意思：有时，你才会去创造相应的新事物……由它本身就是一种寓意，不同的方法可以从不同的道理来，所以，这些解称似乎都很合理。

但是，所有人都没有解决这样一个问题：乌鸦到底能不能喝到瓶子里的水？在什么情况下从瓶子头进水，一里水，就要在一个寓言故事里的细节是合理，看起来有点过于死板了，不过，乌鸦没有办法从瓶子里弄到水，甚至，这种瓶子里扔石子儿，就可以喝到水的想法根本就是错的，那个故事对人们的启发也就无从谈起。

# 什么是孔隙率？

我们来模拟一下这个故事的情况，假设，一个装着水的瓶子扔进去一块石头，会发现石头到瓶子之后，会在水里占据它这个头那么大的一块小空间，把原先在这的水挤开，水可以流到瓶子里又，水就不能往边上流，水位只能往上上升一点。

如果我们再往里扔石头，效果也是一样的，石头占把水挤开，水位上升一点。这看起来，似乎很快就可以把瓶子水提升起来到足够快的程度——如果你真这么想，那就错了。

咦，怎么能了呢，错在哪儿呢？

其实，如果这样想的话，实际上忽略了一个问题，那就是——一个瓶子里面能容纳的石头数量有限呀。如果石头足够大，那么只能扔几块儿进去，石头就足够了，再往里扔石子儿，就不用了。
