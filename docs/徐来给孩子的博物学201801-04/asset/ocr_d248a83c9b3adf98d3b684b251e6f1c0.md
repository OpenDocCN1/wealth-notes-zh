# 世界上数量最多的动物分别是什么？

![](bbox=[0.05, 0.12, 0.95, 0.14])

**徐来**

其实，这个问题是无法回答的。因为我们并没有这样的统计世界上一切动物的每一种物种的具体数量。

虽然没有具体的数值，但我们可以通过一些方法推断出来，得到一个大致范围的结果。比如，按照严格的生物学定义来讨论，世界上数量最多的动物和植物肯定都是微生物，也就是那些肉眼没办法看到的微生物。

所以，我要把这个题目调整一下。一般人问数量最多的应该可见摸得着的植物当中，数量最大的是什么呢？每种农作物虽然具体数量不太好听。就是这个数量大致上和种植面积会有关系。所以，我们知道，世界上被种植面积最多的植物是小麦。现在全世界种植小麦的面积大概是400万平方公里出头。想一想，咱们中国的面积是960万平方公里，快到中国国土面积的一半儿了。排第二的是玉米，大约有100多万平方公里，但我们平时吃的小麦，20多种植物。平时大家吃的，主要是普通小麦，也是有硬质麦。当然，即使排掉硬质小麦，普通小麦依然很常见。

至于世界上最多的动物，我们只能说脊椎动物。也就是说像人类一样有骨架的动物，包括鱼类、两栖类、爬行类、鸟类和哺乳动物。所有这些动物当中，数量最多的肯定是家鸡。目前世界上大约有240亿只鸡，这是数量最多的脊椎动物单一个种。

# 牛奶盒为什么是方的？

![](bbox=[0.05, 0.28, 0.95, 0.34])

**徐来**

有人认为，牛奶盒之所以是方的，跟牛奶的生产、储藏和运输环节有关系。方方正正的盒子，可以紧紧地排列在一起，不会浪费空间。但是，这个想法实际上只说到了一部分，它遗漏了一点，那就是牛奶并不会装在方方正正的牛奶盒里面，也会有圆或者其他什么容器盛放的。而且，甚至还有装在塑料瓶里的。对，而且，甚至还有装在塑料瓶里的，也不能装牛奶，很多饮料也会用到它。

所以，这个问题很难精确地回答，为什么牛奶盒或者某类饮料的盒子是方方正正的？

其实方形更容易制作，因为这些盒子是纸做的，方形可以降低成本，节约时间和成本。

你自己去试做最试一试，要做成一个能装东西的容器，最简便是做成方方正正的形状。但是，说起来是做成圆的，但是做起来比较费劲，因为圆形很难折叠或成型。比方说我们常见的饮料瓶，就是圆形或者是方形的，但是方形比圆形更容易制作。

# 为什么云可以停在半山腰 却不能停在楼的顶部 为什么云不能停在楼层低的地方呢？

![](bbox=[0.05, 0.44, 0.95, 0.46])

![](bbox=[0.05, 0.47, 0.95, 0.49])

**徐来**

浮空云啊，我就是要批评你了，你观察云没有很仔细。难道云不会停在低矮的楼房，停在特别低的地方？

我大家看云，就是看白白的一朵朵，可云在高空处，能飞好多千米，它们变成了各种类型，包括低层云、中层云和高层云。

不过，有一些我们看不到的云的类型，例如卷云，它们的高度非常高，在几千米以上，多的在万米以上的高空中。卷云主要是由冰晶组成的。而层云、层积云、雨层云、碎云，位置会比较低。它们可以很低，甚至低到只有几十米的高度，这时云就成雨了。

当云飘到大楼附近时，大楼遮挡了云，其实也是云在运动。

所以，并不是说云不能低到那个位置，而是我们没有机会或者没有仔细观察到这一现象。
