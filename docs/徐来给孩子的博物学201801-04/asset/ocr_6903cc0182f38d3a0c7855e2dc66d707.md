# 说汉语的人口最多

要弄清楚这个问题，首先要弄清楚世界上到底有多少种语言。有一套学术叫语言学，它是专门研究人类的语言的。专门研究语言学的当然是语言学专家。他们统计和分析了现在世界上所有语言，最后得出一个结论，世界上现在存在着着的语言有5000到7000种之多。

可是为什么语言的种类为一个范围，而不是一个准确的数字呢，因为一方面有些语言的使用者真的太少了，只有几千甚至几十人，这样的话，语言学学家们很难查探到，所以，只能估估；另一方面呢，可能有两种或几种语言，彼此太接近了，有人会认为它们是同一种语言，有些人又认为它们只是同一种语言的不同方言，所以，可能存在着争议。

当然，有些语言的使用者非常非常多，比如说咱们说汉语吧，就会我说的这个语言，全世界至少有15亿人会说汉语。这其中大部分人把汉语作为自己的第一语言，也就是母语，也有一些人把汉语作为第二语言，所以，汉语是当之无愧的世界使用人数第一的语言。

英语则是第二大语言。不过，直接以英语为母语的人口并不多，只有不到4亿人。但另外有8亿人会说英语，所以，全世界使用英语的人也有接近10亿。

如果我们能多学几门语言就会发现，有些语言，彼此之间差异非常大，比如说汉语和英语吧，汉语是拼音字，英语你也一定学过，差别对吧，汉语是方块字，你学好多好多字词，英语是拼写的26个字母好单词。中国的语言俄语，俄语也是拼写的，它的字母有33个，当然，也有些语言，听起来差不多，比如欧洲很多语言，听起来都差不多，跟英语很像。

所以，语言学我们根据不同语言彼此之间的远远近近，给它们分了类，语言在生物领域、动物、植物，有门有科属的分类，语言也有，分成语系、语族和语支，比如咱们的汉语，就属于汉语跟系的语言，其他语言里也有，比如说英语吧，英国人说的英语，美国人说的英语就不太一样，跟澳大利亚人说的英语又不一样，在印度呢，虽然很多人以英语为母语，但是跟美国英语差别就更大，在美国，不同的地区，不同人，说的英语也不一样。

# 语言到底是怎么来的？

那么为什么会有这么多语言呢？要回答这个问题，首先要回答为什么会有语言。或许你会觉得这个问题根本没有必要问，人就是会说话。

实际上有一些语言学家的观点和你是一样的，他们认为语言就是一个非常顺理成章的东西，是人类大脑发育到一个程度之后，自然而然地突突出来的一个东西，有点像孙悟空从石头里蹦出来一样。

不过，也有许多语言学家不认同这个观点，他们认为语言是一个连续的过程，我们现在说的语言，肯定是从某种古老的东西当中变过来的。

无论语言到底是怎么样来的，它产生了之后就经历了一系列的进化过程。这个过过程有点像动物的进化，一群人使用某一种语言彼此交流，后来，其中的一些人离开了群体，去其他地方定居，他们的语言越远，越遥远，再也无法和原来的同伴们合拢。但是他们又遇见了新的同伴，在新的同伴的沟通中，他们的语言受到了对方的影响，变得和原来不一样了，一种新的语言就这样诞生了。

根据这样的变化过程，我们甚至可以把人类的所有主要语言都画在一棵树上，就好像各种动物、植物的进化树一样，它就成了语言的进化树。

# 语言的多样化

在语言的演化过程中，也会出现一些奇怪的变化，使得某些语言变得和很多语言非常不同。比如说西纳人的话，在很多语言当中，都要通过在句子的结尾加特定的字来表示疑问。比如说你的汉语，你问最近一般加个吗，啊，你吃了吗？对吧，然而日语，一般用ka这种方式来表示疑问，全世界大多数语言都是这个方式来提问的，但英语不是，英语是靠改变词的内部来示疑问的。用这个方法来提问的语言，在全世界主要语言当中只有13种，除了英语之外，德语和西班牙语也是这么干的。

在谜间这件事儿上最奇怪的，是一种叫做图米塔斯特别克的语言，问问题和说完全一样的一句话连音调都不会发生变化，这种名字奇奇怪怪的语言，在中美洲墨西哥的尤卡坦地区，它的使用者都生活在一个小叫卡辛古斯的城镇附近，总共大约6000人。实际上，语言学家们对于只言进行了比较分析之后得出结论，这个世界上最怪的语言，图米塔斯语是最小的，也是最怪的。无论是发音，还是词汇，或者是包含句子的方式，它都包含着最多的与众不同之处。
