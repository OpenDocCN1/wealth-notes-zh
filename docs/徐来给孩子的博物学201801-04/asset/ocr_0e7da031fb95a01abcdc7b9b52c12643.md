# 杜鹃大都是寄生者

我们平时说的杜鹃鸟，不是一种，而是有很多种。杜鹃实际上是一个门，还记着我之前说过的生物分类法多，门纲目科属，这科包含 130 多种鸟类，名字都叫杜鹃什么什么鹃，其中有超过 50 种，父母都会把孩子寄养在别窝里。用术语说，这个叫“巢寄生”。在鸟类里常见。

最典型的寄养者叫大杜鹃，或者叫普通杜鹃，这是最常见的杜鹃了，我们平时说的杜鹃鸟就是指它。布谷鸟自己不筑巢，而把蛋生在其他的鸟类巢里。

不过，想要这样做，也得有点儿技术含量才行。不知道你有没有注意到，不同的鸟，它们的蛋颜色不一样，有些是蓝色的，比如鹌鹑蛋；有些颜色偏红，比如鸡蛋；有些则发青，比如鸭蛋。如果大杜鹃下的蛋跟别人巢里的蛋差别太大，那是很容易被发现的。

所以，雌性的大杜鹃总是要模仿某一种被自己巢寄生的鸟类，尽量让自己的下的蛋看起来很像被对方的蛋，然后对方就会把它当成自己的孩子来养。不过，可以给它寄养的鸟，种类实在是太多了，有超过 100 种。要想每种都能模仿这个太难了，所以每只母鸟都只寄养一种：由底原色的、深蓝色的、浅蓝色的、粉色的……等。

虽然形成了这么多不同颜色的蛋，但所有的大杜鹃都是同一种鸟。现在问题来了，不同颜色的蛋孵化出来的大杜鹃会怎么混呢？答案是，依然是按照雌鸟的颜色去。

不过，不同颜色的蛋孵化出来的大杜鹃，彼此之间难以基因混合，还是会影响颜色变化。好在，整体来看，大部分大杜鹃的颜色和寄养它们的鸟的其他颜色相比，只是稍微有点相似而已。说到后还是因为“巢寄生”的鸟智力水平有限，分别不出其中的差别。

# 产生更强烈的刺激

在杜鹃里，还有一种叫大斑凤头鹃，大斑说明它体形比较大，又有斑点，凤头呢就是指它在额头上面又一点儿装饰性的羽毛。它的名字要比大杜鹃长一点，本领也要大不少。比如说，它会把自已的蛋生在喜鹊或者鸟鸦的巢穴里，去骗它们给自己带孩子。要知道，喜鹊和乌鸦在鸟类中都是战斗力很强的，号称鸟类当中的地位很高。能欺负地位很高的，那一定是更厉害的角色了。
