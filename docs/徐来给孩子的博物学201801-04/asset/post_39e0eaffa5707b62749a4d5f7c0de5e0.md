### 说汉语的人口最多

要弄清楚这个问题，首先要弄清楚世界上到底有多少种语言。有一套学术叫语言学，它是专门研究人类的语言的。专门研究语言学的当然是语言学专家。他们统计和分析了现在世界上所有语言，最后得出一个结论，世界上现在存在着着语言有5000到7000种之多。

可是为什么语言的种类为一个范围，而不是一个准确的数字呢，因为一方面有些语言的使用者真的太少了，只有几千甚至几十人，这样的话，语言学家们很难查探到，所以，只能估估；另一方面呢，可能有两种或几种语言，彼此太接近了，有人会认为它们是同一种语言，有些人又认为它们只是同一种语言的不同方言，所以，可能存在着争议。

当然，有些语言的使用者非常非常多，比如说咱们说汉语吧，就是我说这个语言，全世界至少有15亿人会说汉语。这其中大部分人把汉语作为自己的第一语言，也就是母语，也有一些人把汉语作为第二语言，所以，汉语是当之无愧的世界使用人数第一的语言。

英语则是第二大语言。不过，直接以英语为母语的人口并不多，只有不到4亿人。但另外有8亿人会说英语，所以，全世界使用英语的人也有接近10亿。

如果我们能多学几门语言就会发现，有些语言，彼此之间差异非常大，比如说汉语和英语吧，汉语是拼音字，英语你也一定学过，差别对吧，汉语是方块字，你学好多好多字词，英语是拼写的26个字母好单词。中国的语言俄语，俄语也是拼写的，它的字母有33个，当然，也有些语言，听起来差不多，比如欧洲很多语言，听起来都差不多，跟英语很像。

### 语言到底是怎么来的？

那么为什么会有这么多语言呢？要回答这个问题，首先要回答为什么会有语言。或许你会觉得这个问题根本没有必要问，人就是会说话。

实际上有一些语言学家的观点和你是一样的，他们认为语言就是一个非常顺理成章的东西，是人类大脑发育到一个程度之后，自然而然地突突出来的一个东西，有点像孙悟空从石头里蹦出来一样。

不过，也有许多语言学家不认同这个观点，他们认为语言是一个连续的过程，我们现在说的语言，肯定是从某种古老的东西当中变过来的。

无论语言到底是怎么样来的，它产生了之后就经历了一系列的进化过程。这个过过程有点像动物的进化，一群人使用某一种语言彼此交流，后来，其中的一些人离开了群体，去其他地方定居，他们的语言越远，越遥远，再也无法和原来的同伴们合拢。但是他们又遇见了新的同伴，在新的同伴的沟通中，他们的语言受到了对方的影响，变得和原来不一样了，一种新的语言就这样诞生了。

根据这样的变化过程，我们甚至可以把人类的所有主要语言都画在一棵树上，就好像各种动物、植物的进化树一样，它就成了语言的进化树。

### 语言的多样化

在语言的演化过程中，也会出现一些奇怪的变化，使得某些语言变得和很多语言非常不同。比如说西纳人的话，在很多语言当中，都要通过在句子的结尾加特定的字来表示疑问。比如说你的汉语，你问最近一般加个吗，啊，你吃了吗？对吧，然而日语，一般用ka这种方式来表示疑问，全世界大多数语言都是这个方式来提问的，但英语不是，英语是靠改变词的内部来示疑问的。用这个方法来提问的语言，在全世界主要语言当中只有13种，除了英语之外，德语和西班牙语也是这么干的。

在谜间这件事儿上最奇怪的，是一种叫做图米塔斯特别克的语言，问问题和说完全一样的一句话连音调都不会发生变化，这种名字奇奇怪怪的语言，在中美洲墨西哥的尤卡坦地区，它的使用者都生活在一个小叫卡辛古斯的城镇附近，总共大约6000人。实际上，语言学家们对于只言进行了比较分析之后得出结论，这个世界上最怪的语言，图米塔斯语是最小的，也是最怪的。无论是发音，还是词汇，或者是包含句子的方式，它都包含着最多的与众不同之处。

温泉是怎么来的？山上不是很冷吗？为什么还会有温泉呢？

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_67_0.png)

这个问题其实很简单，因为温泉的温度不是来自空气，而是来自地球内部。

越高的地方空气就越冷，因为高处气压低，空气膨胀就会变冷——这个之前我跟你解释过。不过这个冷主要是空气的冷，大地深处远离空气，受影响很小。这就是为什么就算炎热的夏天，深井水和自来水也很凉。

再往地球深处说，反而会变得越来越热，这是因为地球内部部分会产生热量，如果地下灼热的岩浆流到了离地面比较近的地方，就会把这些水加热。这些热水喷涌出来，就成了温泉。这个热量远比空气中的寒冷效果大多了，所以就算在山上也会有温泉。

这是替我们家的龚嘉婷小朋友问的，鱼被我剥了后，连内脏都取出了，为什么还能跳动？

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_67_1.png)

刚剥的鱼会动，是因为鱼作为整体虽然死了，但是它的一部分细胞还没有死。

平时的时候鱼之所以会动，是因为鱼的神经里存在着一种电开关，一旦这个开关接触到了信号，就会给鱼的肌肉发出命令，肌肉就消耗能开始运动。一条刚剥掉的鱼，可能头被切掉了，内脏也被切掉了，一定能开关还在，肌肉也还储存着一些能量，所以遇到刺激还是会自动。这个刺激可能很小，比如也许是碰了一下或者水滴在上面，看起来好像就是它自己动。

不过，维持这个电开关是需要能量的，而鱼的肉已经分解了，就无法给这个开关补充能量，所以开关很快就会坏掉。开关坏了坏开，它所指挥的肌肉也会坏掉而无法自动，所以之后鱼就不会动了，或者就死透了。

人类就常常发生这样的情况，因为人类的神经系统比动物复杂，所以人死后会陷入一种假死状态，不会因为没有电的肌肉乱动，当然如果你有强烈的刺激，比如电击，那也可以动起来。

# 雪花的第一篇论文

古代的人们很早就注意到了雪花这个奇形怪状，也有很多科学家对雪花进行了研究，写下了很多的研究论文。其中最著名的一篇，作者叫做开普勒，是一位天文作家。开普勒已经是咱们熟悉的熟人了，我以前跟你讲过开普勒定律的事情。

当年开普勒曾经在神圣罗马帝国的布拉格这个地方，正在做给皇帝鲁道夫二世当数学顾问，那是某一年的年底，快到圣诞节了，很可惜，鲁道夫二世不知道是忘了还是怎么的，竟然好几个月都没开开普勒发工资了。

年关将近，开普勒又烦又冷，走在布拉格的街头，想想朋友买东西，自己却身无分文，不知道该怎么办。开普勒有些伤感，自己的真的是一个只有nIx的人。Nix是德语，拼写就是N·h·I·X，意思是“一无所有”。这个时候，突然，天空中飘落下一片雪花，落在了开普勒的怀里。开普勒突然有一种心情。Nix这个词由字母组成的单词，有一个叫拉丁语的更古老的语言版本，是雪花的。开普勒心想：那我自己就给朋友送一个“一无所有”吧，嗯，不对，是送一个NIX雪花的。

开普勒说干就干，赶紧回到家屋里开始写关于雪花的论文。论文本身就是用拉丁语写的，讨论的问题就是雪花为什么是六角形的。为了想对英语的这个特别的礼物，开普勒写的也很随意，他没有去认真地研究这个问题，只是根据地域假说，六边形、三角形和正方形是可以平面全部铺满的图形。有趣的是，你自己可以画画看，有边多不是六边形，为什么雪花的形状必须是它可以平面全部铺满的，为什么只能是三角形或者正方形……关于这个问题，开普勒没说到。

就这样，开普勒就直接把这论文作为新年礼物，送给了朋友。虽然他没有给出明确回答，但他毕竟是第一个问出“雪花为什么是六边形”并试图探究这个问题的人。后来，人们追认这篇论文为雪花研究的开端之作。

# 雪花的研究历程

后来，很多科学家都尝试记录和研究过雪花的形状。

法国非常著名的数学家、哲学家笛卡尔第一次用文字详细地描述了雪花晶体，其中有一些雪花的形状非常常见。他提到，构成每朵花的一些，每朵花都是六角，每一个夹角都像彼此一样。雪花结构真的是太精巧了，笨手笨脚的人类恐怕是做不出来这东西的。

第一个直接记录雪花的图像，是罗伯特·胡克。胡克是一位物理学家和发明家，他亲手制作了一台显微镜，并且用它来观察身边的万物。他是最早观察到晶体，且为细菌命名的人。他用自己的显微镜观察了雪花，还把自己看到的雪花的样子给画了下来。（下图）

不过，在胡克的年代，大家只能通过手绘的方式来，把自己从显微镜里看到的东西画下来，更精细地观察雪花形态，要等摄影术发明了之后，才会实现。1879年，德国天文学家、摄影家弗劳热尔拍摄了已知的第一张雪花照片。（下图）

通过这张图，你可以大概了解这两个数据对雪花形状的影响。简单来说，湿度越大，雪花越复杂；而温度的话有个最适宜的范围，这个范围之外，无论是太高还是太低，雪花都会变得简单。在零下10到零下20度之间，湿度又合适的情况下，雪花才会变得最复杂，最漂亮。

# ◆ 博物学家养成记 ◆

怎么样，有机会的话，也仔细观察一下雪花吧，想想，你看到的某一片雪花，可能是在怎样的温度和湿度条件下形成的。

- 开普勒是第一个正式撰写雪花论文的科学家。虽然他的研究并不深入，但他是第一个严肃提出这个问题的人；
- 笛卡尔、罗伯特·虎克、弗罗热尔等科学家都讨论过雪花的问题。美国NASA更是试图通过人海战术收集雪花的形状来进行研究；
- 通过X射线晶体衍射，我们可以发现，水分子在凝结之后，是形成六边形的，这是雪花呈现六角形的基础；
- 科学家已经确定，雪花的形状和温度、湿度这两大要素有关。湿度越低，雪花就越扁平，形成普通的六边形，湿度越高，花纹用越复杂。而不高不低适宜的温度，也是雪花形状发育的前提。

# 科学家·地球｜伽利略是怎样打官司的？

世界好大，奇妙的事情每天都在发生，我们一起去发现吧！

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_71_0.png)

如果要让你说出自己所知道的最伟大的物理学家，你第一个想到的肯定是爱因斯坦。再往前追溯，多半就是牛顿了。如果再往前，那一定是伽利略。

确实，伽利略在科学史上的意义非常大，在物理、数学和天文学领域都做出了非常重要的贡献。被认为是现代科学的起点。他最为世人所传颂的两件事，一是通过比对月球斜纹球体的证明了一个没有质量的两件事体，下落速度相同；另一件就是坚持地心说，因为因此被教会斥为了两。

不过，这两件事的真实情况，跟你去认识的可能都些许出入。今天咱们就聊一聊伽利略。

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_71_1.png)

# 伽利略没有做过斜塔实验

伽利略的比萨斜塔实验流传很广，你的教科书上可能还有一个故事。不过，有意思的是，伽利略本人却并没有对这个实验做任何记录。这事儿并不太寻常，因为做对实验记录是每个科研工作者都非常认真对待的事。更何况，这一个实验常被重视，吸引了许多人围观的实验。

实际上，关于伽利略在比萨斜塔做实验的说法，最早是一位学生提出来的。如今，绝大多史学专家们都已加利略并没有做过这个实验。实际上，目前有记载的最早的实验就是被工程师西蒙·德·蒙蒂法在荷兰的一间教堂里做的一座斜教堂有一个斜坡。

当然，没有做过比萨斜塔实验，并不意味着伽利略没有做过类似实验，更不是意味着伽利略否认过不同质物体的两件事物下落速度相同，实际上，伽利略在自己的书里明确地写过这个观点，他认为，只要下落时间地受到阻力微不足道的话，或者干脆就是真空当中的，那么任何物体的下落速度都是相同的，而且其加速的水平都是均匀的。

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_71_2.png)

# 被允许讨论的“日心说”

相对与曾经出现在教科书上的“比萨斜塔实验”，伽利略对后世影响更大的是他在“日心说”方面的工作。所谓日心说，就是地球绕着太阳转的这样一种学术观点。

这种观点在我们现在看来，是一个对宇宙最基本的认识，但在古代世界却并非如此。很长很长的时间内，世界各国的人们都认为，宇宙是围绕着地球转的。尤其是在欧洲，这种观点发展成一神论，叫做“地心说”，这是一种得到教会认可的理论知识。

不过，也有一些早期的科学家，通过长时间的观测和计算，发现“地心说”存在一些漏洞。有些现象无法用“包绕太阳在内的各种星座都是静止旋转”这说来去解释，反过来，如果认为地球是围绕太阳转的，似乎反而能解释得通。

![](img/a78d2f6ae4f22f8288ba71e0f6a7c79d_71_3.png)

伽利略也是一个持“日心说”观点的科学家。他认为，当时“日心说”的证据已经非常充分了，而且无论经验上，还是宗教方面，对于支持理论已经做得了准备——甚至有一些主教向他承诺，如果“日心说”证明是正确的，教会将会修改宗教经典。伽利略对此感到非常高兴，他就想去积极地推动此事。

又过了几年，这些主教中的一位成了罗马教宗——这个基督世界，这是最有权力的一个身份了。所以，伽利略兴高采烈地跑去找他，他保证，自己已经找到了非常充分的证据，足以证明，地球确实是绕着太阳转的！

教宗一听，唉，不错啊，他就允许伽利略去写一本书来这个理论。但考虑到当时的宗教界还是复杂，他同时也提了一个要求，在书中能不能用假设说成一个事实，只能把它作为一个假设来描述——除非他有非常确凿的证据可以给予证明。

唉哟，这个伽利略可得着意了，一个欧洲人，不怎么，反过来就是这意思吧，兴高采烈回去书了，心想，这个“地心说”就是在我伽利略手里被推倒呗。说，回到屋里没多时，他写出了一本在科学史上非常著名的著作《关于托勒密和哥白尼两种世界体系的对话》。

# 被误解的审判

不过，这个伽利略在这本书里，有那么一点太过份了。一心想把所有东西说完，他就在书里对地心说“没什么的人进行了非常激烈的嘲笑，把“日心说”描述成了一种事实，并且给出了他自己认为是非常有力的证据。

这个证据是什么呢，伽利略认为，大海会有涨有潮，这个现象表明地球是绕太阳转的，这比较难想象。因为在地心说之前，另一位伟大的天文学家开普勒就已经讲过开普勒的这个潮汐现象，决定证明在月球。用这个来证明“日心说”，可就被坑了。

更麻烦的是，根据伽利略的潮汐理论，地球上每天应该发生一次潮汐，但是我们都知道，事实上每天涨潮两次，涨潮两次。

很快，伽利略的反对者就注意到了这一点，并且抓住了这一点进行反驳。而这个时候，伽利略竟然找不到合适的证据来为自己辩护，接下来，反对者的命了，并且用自己的书来批评不符合宗教经典的观点。

到了这一步，他原先的教宗朋友也保护不了他。伽利略被送上了宗教法庭。

这场审判进行了非常多年的时间，很多人指控伽利略，有人为他辩护，甚至有些人希望他为他提供保护。但是，最终他还是被判有罪，并且，法庭要求他放弃“日心说”这个观点。最终，伽利略在一次非常有名且无效的文书上签著了名字。很多人认为，在这个过程中，伽利略受到了毒打和虐待，不过实际上这种情况并没有发生。

接下来，伽利略被软禁在一座别墅中，并且被禁止继续进行科学研究。不过，这个判决并没有被认真对待，他还是会经常去另一个城市，在那里的宫中居住，会住住。实际上，他的科学研究工作也没有停止，伽利略最重要的一本学术著作《论两门新科学》就是这个时期写出来的。
