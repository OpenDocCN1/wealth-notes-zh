# **营养学·人类 | 冰淇淋是怎么做出来的？**

世界大好，奇妙的事情每天都有，我们一起去发现吧！

冰淇淋你喜欢吃吗？我也喜欢吃，口感冰冰凉凉的。以前，冰淇淋和夏天联系在一起，只有在夏天才能吃到这个东西，满大街有，吃上一口冰淇淋，可真是说不出的痛快。不过，现在的情况不同了，大家在冬天也会吃冰淇淋。

可是你想过没有，冰淇淋到底是怎样被做出来的呢？今天就跟大家讲讲冰淇淋的由来。

![](bbox=[0.0, 0.18, 1.0, 0.23])

很多人都有一种错误的观点，不知道你有没有，那就是古代的皇帝、贵族，他们能享受到比我们现在更好的东西；穿得更好、用得更好，什么时候都更好，最重要的是，吃得更好。但你想过没有，真的是这样吗？

其实这是非常错误的观点。咱们现在的衣食住行所能享受到的很多东西，换在古代可能是最稀有和权力最大的人都无法想象的东西。有霜和雪花，冬天君威，有能舒服的地，有密封性和保温性足够的门窗，有新风系统来保证通风换气，这样的条件，在现代社会已不是什么稀奇的事物，但在古代则是根本无法想象的。

取暖想不冷，制冷那简直就是奢望。古人要想知道冬冷夏热真是难死了啊，都要等到寒冬腊月最冷的时候，大河边或者湖上冻了，然后有专门的工人去冰面上把冰凿成一大块儿一大堆儿的，运到特别的冰室里，储藏的时候还得裹上外面盖上百的稻草，隔绝热量。这样才能保留到夏天，盖好热给贵族们使用。根据《诗经》中的记述，大抵2500年前，中国人就已经开始把类似的冰储存起来。后来，人们又发明了直接制冰的技术，虽然这个技术的成本很高，但使用效果也更加好了。

西方的情况也差不多。古代希腊和古代波斯贵族，就已经可以吃到用雪和果汁、牛奶东西混合在一起制作而成的甜品了。不过，在那个时候使用的还是从高山下取来的积雪。

到中世纪的时候，最顶级的贵族已经让吃雪上到奢华生活的一部分。据说，法国的亨利二世的女儿，孟菲斯，大肆的贵族凯瑟琳·孟菲斯，把自己家族当中的一些厨师带到了法国。这些厨师就会制作冰淇淋一类的食品。后来，美国厨师查理斯·二世在法国吃到了这些食品，赞不绝口，特地把自己制作这种食物的人带在身边，作为一个御前顾问。

不过，这些都只是传说而已，并没有可靠的证据表明它们都是真实发生的，我们无法确定，假如这些故事真实存在，它们和我们现在所说的冰淇淋到底有没有关系……

我们现在可以看到的最早的关于冰淇淋的纪录，是在世纪中出现的，距离现在大概是300多年前的样子。

不过，在这个问题上，你也别想着一定追觅出一个结果来。因为冰淇淋的诞生，并没有一个明确的时点，而是各种早期冷饮的制造过程中一点点改变而来的。

到了17世纪的时候，因为科学的发展，人们逐渐掌握了造冰的方法，所以，类似于冰淇淋的食物就在这个过程中间出现了。如果有人把自己做冰淇淋的过程、配方记录下来了，就成了我们现在考证的依据了。

当时，意大利人先发明了制作冰的方法。这个方法用到一种叫硝石的东西，硝石就是含有硝的石头。他们现在知道东罗马的主要矿石是一种叫做硫化的化合物，硝酸很容易溶于水，而且它有另一个特点，就是当它溶解在这个过程当中吸收了热量。把周围的西都带走的凉爽的，如果把它放到雪里面，那就可以让周围的温度降到比雪还要冷得程度。

如果在一个大桶里面，放上冰雪和硝石的混合物，再在里面放一个小桶，那么大桶里的低温就可以让小桶里的东西冻成结实。意大利的科学家发现，把牛奶、奶油、糖、果汁以及其他好吃的东西的混合物倒进小桶里面，不断搅拌，就可以小桶里面结块并得到不好吃的凝固物。好几代以内著名的周利记录了这个方法，比如安东尼奥·博萨尼和范莎夫人，他们都被认为是最早记录冰淇淋的人。我下面给你们配了一张制作图，你可以看一下。

![](bbox=[0.0, 0.82, 1.0, 0.87])

不过，用冰桶来制作冰淇淋太麻烦了，制作过需要不断搅拌小桶里的东西，并且把冰淇淋到拿出来，做一次冰淇淋就需要上几个小时。后来，有个美国发明家，设计出了一种手摇柄的搅拌器，可以把搅拌和制取这两个动作合成为一个，并且极大地简化了劳动。

再后来，美国医生盖斯发明了制冰机，而德国工程师卡尔·冯·林德则发明了冰箱——这些发明让冰淇淋的大规模制作变成了可能。冰淇淋终于不是贵族和有钱人独享的好东西，渐渐的，每个人都有可能买得起冰淇淋吃了。
