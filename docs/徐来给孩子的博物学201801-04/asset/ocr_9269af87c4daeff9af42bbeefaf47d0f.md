徐来

我年轻的时候，曾经在江苏扬州住过一段时间，扬州是一座很古老的城市。大概在2500年前这里就已经有城市了，这座城市的位置非常好，交通便利，物产也很丰富，所以，在古的时候，每期每代，这里都是重要的商业中心，是以繁华著称的，这座城市有非常多的古迹，也会有很多好玩的景点。如果有朋友来到扬州较多，我通常会先带他去一个比较奇特的地方，这个地方，有一个传说——我今天就再跟你说说这个传说，以及它背后的故事。

# 扬州城里的“大槐安国”

对大多数游客来说，乾隆巷最出名的是“八怪纪念馆”，不过，我带朋友们来到这个地方，主要目的并不是为了参观“八怪纪念馆”，看那些著名画家的作品和生平事迹。我们的着点，其实是在“八怪纪念馆”的门外。

在八怪纪念馆的民宅旁边，有一处小花圃，原先只是简单的绿地，现在也装上了漂亮的石栏杆，放了几石头桌子石头椅子，供小息。在小花园的一侧，则是一颗很大的槐树。

这才是我带朋友们来参观的东西——它可不是一棵普通的槐树，而是别有玄机的，据我了解，扬州的专家，判断，这棵老槐树是唐代种下的一棵老槐树，换句话说，这棵树到现在，已经至少有1200岁了！

树木的寿命要比动物的寿命长得多。假设，1000岁的树，也算不上太古老。要知道，现在世界上活着的树龄超过2000年的树也有不少，里面多是合欢树里的“阿山神木群”，里面很多红杉，树龄都超过了2000年，而在美国还有现存的裸果松树，树龄超过了5000年。这还只是单一的树，我之前跟你讲过，植物可以进行无性生殖，它们可进行克隆。在美国有一群鹅枥，依靠着这种方式，至少活了8千万年。

虽然这棵槐树按年龄来说，说不上是一数二的，但它却拥有一个传说。这里的传奇，不是指们在一般的传说故事，而是一个特定的术语，是唐宋传奇的一种小说体裁，一般指用文言写作的短篇小说。唐代有《当，出过很多的著名篇目。其中有一篇叫《南中太守传》，大槐的意思就是，有人在槐树下午休时做梦，梦见自己进入了大槐安国，迎娶了公主，当上了南迁地方的地方官，不久之后，不过是大槐上的一窝蚂蚁罢了，而南中也只是槐树树蔭的一根枝桠。

这篇《南中太守传》是作者李公佐曾经长期在扬州为官，这篇作品的写作出也可能是扬州。从某种意义上来说，那棵槐树或许是扬州李公佐笔下的大槐安国吧。

# 大树里面有君子

你有没有去看这棵大槐安国，只发现一个很有趣的情况。这棵树虽然很大，但是树心儿却是空的。只剩下外围的外壁，一圈儿插在那里，而另一边全都在外壁，一个门洞似的，看起来就像是一间大树做的小房子一样。

说来也奇怪，虽然树心已经没有了，但这棵大树依然活着，树苗部位也是枝繁叶茂的，到了生长季节，也能造出好大一片树荫来。

可是问题来了，这棵槐树的树心明显已经烂掉了，难道树心烂掉了，树还能继续活起来，这就要从植物底层是怎么东西说起起。

我们平时所看到的植物，绝大多数，它们的体内都有一种叫做血管的组织，你可以把血管想象成一根根细细的小管子，它们一头扎在植物的根里，把头养分从地中抽取出来，另一头，连着头顶上的叶子。

我在“到底可以长多高”那篇文章里，曾经跟你说过这个结构的作用。借助这些小管子，通过毛细作用和蒸腾作用，水和小分子就可以被源源不断输送到植物的全身，从这个意义上说，这些管道结构就是植物的血管。

就像咱们人类的血管，动脉和静脉两种一样，植物的维管结构分成两部分，一部分叫木质部，一部分叫韧皮部。木质部分你有名字知道，它是树里面，所以说树木有点儿关系，而韧皮部则跟皮的名字一样，也就是树皮的部分。

这两个部分，各自的工作不太一样，木质部主要负责输送水分和矿物质，而韧皮部，主要运输的是营养物，比如淀粉等。

你可以为，这些维管组织跟我们人类的血管一样，用就是几十年，而维管组织可是不一般，苹果刚来水果来，苹果树身上的韧皮部器官，能够不超过3年，而木质部的导管，也就是用1年多的样子。

好在，在木质部和韧皮部之间，还有一个形成层。它从中间那小层细胞开始，往两边生长，接着索质的，就形成新的韧皮部，接着韧皮部的，就形成新的木质部。这样一来，树木也就有了源源不断的新血管可以用了。

# 为什么说树活一张皮

新血管是有，可是，那些被废弃的老血管怎么办呢？韧皮部情况好办，因为它们总是树皮的一部分，有的植物就会让皮慢慢往外长，变得越来越厚，有些，干燥会坏掉的老韧皮部会直接被掉，有一些则会全到到树皮的外层，比如樟树，那些掉下来的，就是被废弃的韧皮部。

相比之下，木质部就比较麻烦了。因为它是最里面的，一旦里面的部分失效后，那些旧的木质部就永远运不出来，只能就那样留在里面，与此同时，那些空隙的管道会被侧根之类的物质填满，这样，这些管道变成会变得更加坚硬的木纤维，这就是为什么树木中心的材料，要比外面一些材料更加，更好用的缘故。

听到这里，你应当明白吧。如果一棵树被动物啃食，生虫或者被其他什么外力，树心会全被掏空了，那么，它失去的只是最里层的已经死去活死的木质部导管而已。这些分区的流失，实际上并不会影响到树木的生存，因为实际上输送水分矿物质和营养物质的运输管道，只是靠近树皮的一那层一层而已。有时候我们说树活一张皮，原因也就在这里了。
