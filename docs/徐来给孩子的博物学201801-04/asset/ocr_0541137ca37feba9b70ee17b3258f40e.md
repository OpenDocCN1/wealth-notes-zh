# ## 人见人爱的鲤鱼

鲤鱼可是一位创造了世界纪录的鱼。它是目前世界上水产养殖的头号品种。排在鲤鱼后面的，则是它的一些近亲，而除此之外，跳起来最近还不如鲤鱼多。

从动物分类学的角度来理说，鲤鱼属于鱼类当中的鲤形目鲤科鲤属，是的，整个家族都是用它自己的名字来命名的，可见人们对它有多么的熟悉。因为鱼类太常见了，虽然鲤鱼主要吃素，主食是各种水草和藻类，但它们也很喜欢吃肉，生性非常贪吃，它们可以长到非常大，身长超过1米，体重六七千克的鲤鱼，在很多地方并不罕见。

而且，鲤鱼对环境不挑，它们在什么水里，都能活得下去。甚至在冬天河水都冻上之后，它们依然可以以缺氧的状态生存下来。所以，人们在什么地方都看得到鲤鱼，如果需要一个，它们也能够吃上鲤鱼。

![](bbox=[0.1, 0.47, 0.9, 0.55])

当然，即使不吃，鲤鱼也是一种很受欢迎的鱼。在古代的时候，鲤鱼是一种文化象征，象征高富帅。在日本啊，用作赏，红色尾的红色锦鲤是，现在则是日本的象征。在其它国家也是一样。在英 国，人们最喜欢的鱼条叫做做本善的鲤鱼。

本善生活在一个叫盐带湖的湖里，它出生在一八六四年，老到二〇〇六年的时候，它已经六百八十岁，是全英最老的鱼。每一 个去营带湖钓鱼爱好者，都必须要做这样一件事：要钓到本善，那必欲放回。实际上，它至少被别人放回去了六十次，把它活得更久。二〇〇九，这条深受欢迎鲤鱼过不去了。当地的动物学家们专门交了一下交个代，之后，他们发现，本善死于卵引发的感染。

![](bbox=[0.1, 0.7, 0.9, 0.78])

# ## 跳跃是为了帮助打嗝

无论是本善还是锦鲤，还活着是众多的其它鲤鱼，它们就像精灵宝可梦里鲤鱼王一样，都非常爱跳跃。

但是，为什么它们那么爱跳呢？

其实，鲤鱼的跳跃能力，还真得很有用处。它其实是用来助打嗝。很多动物都打嗝，就给鱼吃鱼的方式不同，总有少量的空气跟着食物一起被吞到了肚子里。这些空气，有的会被肠子肚子排出来，变成鱼的一部分；有的则一直在胃里，然后慢慢往上，从嘴里涌出来，这就是打嗝。

鲤鱼也有这个间题。不过气体不是吃进去的，而是鱼鳃里。鱼生活在水里，通过鱼鳃来找到自己上浮或者下沉。要上浮的时候，就给鱼鳃充气，鱼鳃鼓起来，鱼的平均密度就下来了，比水轻轻就能上浮。反过来，把鱼鳃里的气体放出去，就能下沉。如果鲤鱼所在的水域比较深，那么它气压也就会增大，鱼鳃就更容易膨胀，结果鱼鱼就像个气球一样，跳起来，鱼就被弹出水面，这一下气就放掉了，它也就觉得有点点难受。

这些过多的气体，也可以通过打嗝的方法排体外。不过，有的水塘，这个鱼打得并不顺利，需要反复入水，然后再重新落在水上，这整个水力气，把它们压出来——现在你看明白了吧，在实际的情况下，鲤鱼跳是有点不可能什么都没有发生的，它至少还得打个嗝。

除此之外，鲤鱼的跳跃能力还有别的用处。比如，野生的鲤鱼是有洄游本性的。每年的繁殖季节，鲤鱼们会成百成群向河流的上游出发，回到自己出生的那个产卵场。如果在逆流上的过程中遇到了什么断层、小瀑布什么的，当然需要有跳跃能力，才能顺利地翻越高墙。

会跳还有一个好处就是，一旦受到了惊吓，可以跳落到上方，快速离开危险的领域。也许在电线上，看到过饲养员投食处收割的情形。当渔网渐渐收网，鲤鱼们非常紧张，于是纷纷不断跃起，场面会非常热闹。

# ## 跳跃也会伤到人

不过，说到跳跃能力，鲤鱼其实并不是最强。它的一个近亲鲤鱼鱼在跳这个事上，更加著名——实际上，在有些地方甚至直接把鲤鱼叫做跳鲢。

无论是鲤鱼还是，鱼，在亚洲一些鱼种分布非常欧洲。而在地球另一边的美洲是没有这些鱼的。不过，后来因为来自东方的移民想要鱼鲢，是有一些鲤鱼被带到了美洲。有些到被放到了当地的河流里。另一方面，为了清理河流、湖泊中过多的藻类，美国人也有人主动引入了鲤鱼。不过，美国人也很快就发现，那两种鱼非常适应当地的生活，生长迅速，繁殖能力又强，更重要的事是没有天敌，所以，它们在美国的河流里快速繁殖起来。

在东亚人畜无害，人人喜欢的食用鱼，到了美国竟然就成了入侵物种了。而且这个入侵的危害，跟跳就有很大的关系。美国人喜欢玩水，只要有湖水的，就有人在那儿潜水、滑水，或者寄寄浮艇。但如果是浅水或深水里比较密集的鲤鱼，可能就麻烦了。因为鲤鱼很容易咬掉船的马达叶到声，一开打就胡乱乱跳。一不留神就被鲤鱼撞到。

实际上，很多美国垂钓者都曾经被突然跃起的鲤鱼打过脸、撞过胸，因为这些鲤鱼往往很大，所以，这么打一打，一顶，重重都弄得很痛。在二〇一三年的时候，甚至有人在湖中玩摩托艇的时候，差点溺死在水里。

——博物学家养成记——

你看，鲤鱼王的跳跃，还是有很大的破坏力的。下次去菜市场买活鲤鱼的时候，记得去观察一下鲤鱼跳跃的特点，顺便喂养你身边的人。
