# 医学·人类 | 破伤风如何影响一座大桥的建造？

世界好好，奇妙的事情每天都有，我们一起去发现吧！

在纽约这个老特别开始的时候，我就跟你讲过关于纽约曼哈顿的故事。还记得嘛，纽约堪称世界最大的美国城市，以及它们曾经需要小心防范的天敌猛犸象。

在曼哈顿南边，是纽约的另一个部分布鲁克林。如果说曼哈顿是纽约的核心区域和最时髦的区域，那布鲁克林曾经是纽约人口最多的区域。两个区域之间没有陆地相连，只有两座大桥，布鲁克林大桥就是其中的第一座。这座大桥，堪称传奇。接下我要分两文来写。跟你说一说这座大桥的传奇——真是令人感慨的一段故事。

# 德国工程师造美国桥

纽约的这座桥的历史并不久远，差不了多久于咱们中国明朝末年时，这里才有的城市。然后，它用了100多年的时间，变成了美国最大的城市。城市太大了，人口更多，交通问题就显得突出。尤其是曼哈顿和布鲁克林两个区之间，一直都得要乘船来人去，非常不方便。这事，就一直是有人在讨论，要不要在这两个地方之间建一座桥？

讨论建桥的人很多，但真的去推动这件事，把它建立起来的并不多。最后这座桥实际上是一个家族给造起来的，叫罗布林家族。

罗布林家族扎根美国的第一个人，叫约翰·罗布林。是因为美国，是个出生在德国的一座小城。他父亲是个商人，所以家庭还行，早早地就开始接受教育。这个约翰罗布林是挺聪明的，在音乐和美术方面，都显露出很好的才能。不过，他的妈妈既没送他去学音乐，也没送他学美术，而是让他学数学去了。后来，他又转向了建筑、力学和工程，并成长成为一名成熟的工程师。

不过，那个时候的德国，整体上比较动荡，约翰罗布林在家乡有点待不下去了，于是，来到了美国，寻找自己的梦想。不过，美国的状况其实也不好，幸运的是，约翰罗布林在这里还是能找到工作。他在这里结了婚，并且开始参与一些桥梁的建设工作。慢慢的，他作为一个桥梁工程师名声也响起了。

终于，他把目标也对准了纽约和布鲁克林之间的东河。建造布鲁克林大桥的计划是他一再提起，并坚持和交给了纽约市政府。他为此花了整整10年的时间，才让市说服纽约人，开始投资兴建这座桥梁。

# 出师未捷身先死

这座桥其实是很不好建的——至少在当时，差多少150年前建的实际东河，说宽开了曼哈顿和布鲁克林的这条河流，说是一条河流，但有点上像像运河，河水受潮汐的影响特别大，水位一会儿高一会儿低的。河流的宽度差别也很大，最宽的地方980米，而最窄的地方只有超过500米。水深也是，最深最浅的地方大概接近30米。更重要的是，这里和其他的河流入海口的不一样，并没有沉积大量的沙土。这里的河床有多米厚的烂泥，然后是3米厚的粗砂和石块，再往下是大石块和岩石河床。

不过，老约翰罗布林还是自信满满的，他觉得自己凭经验和聪明才智，一定能把这座桥修得又快又好。在纽约市市政府认可了建桥计划之后，他被任命为这座桥的总工程师，并且立即投入了对两座桥墩的工作。一开始就得确定，到底在哪个位置建造这座桥。

正当约翰罗布林全力勘查地，觉得差不多了，自己修建布鲁克林大桥的愿望就能实现的时候，天降灾难。有一次，他站在在一座码头上观察水流的情况时，不知道怎的，一条正在靠岸的慢慢船撞到了他，直接撞他的脚趾给砸碎了。

这个事儿就是把大夫给吓坏了。约翰罗布林却立即检查了。医生要他做砸坏的脚趾切除。然后，医生要求他被继续用清洁消毒。因为在那个时代，还没有现代的消毒流程也没有建立起来，手术很容易造成各种各样的并发症，如果不做一些预防的话，很容易出现感染的问题。

然而，约翰罗布林并没有把医生的话当回事。果然，很多问题都出现了，只用了三周，他就死于手术的并发症。布鲁克林大桥造不下去了。

# 被破伤风击倒的工程师

杀死约翰罗布林的，是一种名叫破伤风的病。这个病，你该也应该听说过吧。这曾是一种非很可怕的病，很小的时候，就听说过这种病，说人的身上如果出现了几种开口，就会得这种病，最后死掉。所以，我非常不信任，哪怕手上破了一个小口子，都很得很得。

不过我们现在已经知道了，破伤风到底是怎么回事。其实，就在约翰罗布林受伤之后没几天，人类就可以破解破伤风的谜底了——只可惜约翰罗布林没等到那一天。

那是1884年，老罗布林死后的第15年，两位大奥地利学家发现了导致破伤病的元凶被皮双伏氏体杆菌。是之前巴斯德等那帮老专栏提过叫这个名字，它长得像个网球拍一样。文森里，我配了图片，你可以看一下，到底像不像。

![](bbox=[0.3, 0.00124, 0.7, 0.00133])

破伤风梭状杆菌它最喜欢住的地方，在于它分泌一种毒素。它会让我们我们的肌肉组织发生痉挛，然后收缩。最后，感染了这种病菌的人，要么被自己的分泌物撞进窒息，要么可以感染，严重的部分感染，导致各项功能丧失死亡——换个说法就是被自己活活给累死的。所以，可以想见，老罗布林死得有多痛苦。

知道了病因，在去克服它就会很容易，我们现在已经有了破伤风疫苗，即使不注射疫苗，也可以用青霉素很轻松地杀死它。然而，这一切在老罗布林的时代，还不存在。

老罗布林死了，在布鲁克林大桥甚至都还没有人工程设施建设，就官们来了。不过，工程并没有停下来，很快，新的总工程师接任住了，他就是老罗布林的儿子华盛顿·罗布林。罗布林家族的第二代开始继续为这座大桥努力了。

可是，小罗布林的遭遇比起他父亲，并没有过之，而无不及。之后又发生了一件，以及小罗布林是如何建造布鲁克林大桥的，我们明天再讲。

+   1. 美国纽约最重要的两个区域曼哈顿和布鲁克林之间，有一条东河相隔，人们希望建造一座桥来解决交通问题，最后确定的是罗布林家族的时代工程师。
2. 老罗布林在布鲁克林建造大桥时，在一座码头上被商船的浮桥砸掉了脚趾，虽然很快他接受手术，却感染了破伤风，去世了。
3. 破伤风是由破伤风梭状杆菌导致的。这种细菌可以分泌毒素，让人的肌肉发生痉挛，并最致命。虽然青菌和青霉素都可以解决，但他们当时并没有被找到，无法拯救老罗布林。
