# 为什么不会有巨人？

为什么呢？原因很简单，就在他那两条腿上。人是直立行走的动物，身上所有的重量都压在两条腿上。人的体重都是增加的，肌肉承受的重量越来越大，尤其是膝盖这个关节位置，它是很脆弱的。假如支撑不住太小的体重。比如姚明，在他们人类当中，他已经是很大的了，两米多，他的膝盖就非常容易受伤。实际上，身高在一米八几，个子长，都要体重增加，大一点的膝盖，膝盖和脚腕都要承受着。如果我们看一个身高可以在1米10米以上，那么，想要能走路的话，他的腿和骨头一定粗到吓人，所以，不可能有人长到10米那么多高。

其实，不光是直立行走的人类，绝大多数动物，都是遵循这个规则。你的腿越太粗重，你的骨架就要加粗倍，否则腿就支撑不住身体，就更要命。不光是嘛，实际上浑身骨骼都要变重。不光变重，还要加粗，比如呢，体形比较大的猫，加上尾巴的长度，也不过比半米长左右，它体重也在5公斤上下的样子，随便随便就可以抱在你怀里，这样一只猫，它浑身上下骨头只占到它全部体重的7%，可它已经是把自己的身体给撑得起来。可是假如换成是陆地上最大的动物非洲象，体重超过10000斤，最重的甚至能到10吨，而它们的骨头，光腿得占全身的20%多，身上五分之一都是骨头。你，体重一大，骨头的分量一下子就上去了吧。

说完重量，咱们再比比骨头的粗细，咱们人类的大腿骨，其实挺细的，你伸出手，把拇指和尖指捏住的大拇指指尖的1/2，圆起来这个粗。这是咱们人类的大腿骨。刚才我们说大象，大象现在是陆地上最重的动物，体重是人类的100倍左右，体是10米，大象的腿骨，比用手指来包了，需要用两只手才能够把它包住，还包不严实。那陆地上能长到最大的动物，那一定是恐龙叫阿根特龙，体积是大象的10倍，它的大腿骨，比它爸爸的腿还粗，它的骨头变粗的程度，可比体重增加的还要大得多。

# 海洋里的“巨人”

说会陆地动物，我们再看看水里的动物，水里的动物确实可以不用遵守这个规则。因为它们不需要用腿来支撑它的身体。如果是生活在水里，那说是长到两米长大就来了，你就是长出100来长，也没什么大用处。而且，你如果告诉我，水里的浮力，咱们游泳的时候，就是靠水的浮力，像在水上。既然有这个浮力，那么体重大一点也不用担心了。反正也有水帮你撑着，所以，水里最大的动物蓝鲸体长，比人牙来大，它的身体粗到跟网绳差不多，但最重最粗的是它的舌左右，可以达到一百多吨。

# 天空里的“巨人”

最后再看会飞的，为了更好得飞行，鸟类的身体结构又发生了一些很不同寻常的变化。比如说鸟平时吃鸡，吃鸭子，吃鹅，反正就是吃家禽的时候，如果用它们骨头，比如家鸽的骨头，或者大蛇上的骨头，你会发现，家鸽的骨头头跟家象的骨头不一样。家里的骨头是实心的。但是鸟的骨头，里面是骨头的，是空的。这样一来，它们骨头的强度没有减很多，但是骨头的重量却变轻了很多，那么鸟可以长多大呢？如果是这种不会飞的鸟，那么它可以长到非常大，现在最大的鸟——鸵鸟，比人还高，但是在远古时代，还活着比鸵鸟更高大的鸟。

如果是擅长飞的那，那就得分析情况了。有些鸟体重大，但体形并不见得太大，有些鸟体形大，但是体重并不见得很大。比如海鸟大鹅种鸟，在动物园里算是比较明显见到的，头和身体是白色的，翅膀是棕色的，体重看起来有点水鸟像是一只大鸡，但脖子显得那么长。这种鸟很大，但是飞行能力一般，有记录显示，大鸟最大的体重是12公斤，嘛，好重的一只大鸡。要说飞行最灵活的，且会飞的鸟，就是一只大鹅。信天翁是一种海鸟，但是我们常看见的海鸟和鹅类多得多，最大的信天翁翅膀打开，两翅端头之间的距离能有4米了，这个长不可能让你自己家的鹅长出这么大。这是，自己信天翁能轻松地在海上飞起来。它们飞行的时候，甚至可以几十个小时不拍打一下翅膀。

无论是什么里的动物，就是有四肢的动物，鸟类，哺乳动物，爬行动物等等，都有可能长得很大。但有些动物却很难长大。比如说，蚂蚁你肯定知道，它们生活在泥土里，会悄悄啃松土，很有用的一种蠕虫。蚯蚓，是用身体表面的皮肤来呼吸的，这一点决定了它没有办法长太肥大，因为身体越大，需要呼吸越多的空气，但用来呼吸的皮肤，不会同样的速度变多。还有些长得多类似蛇，蛇是，也是更多蛇。但是长到多长呢，那就看往长体要更长，有的甚至好几千米，但是横截面呢，仍然是薄薄的一层。
