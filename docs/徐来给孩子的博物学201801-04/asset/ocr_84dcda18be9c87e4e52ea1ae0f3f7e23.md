仔细观察一下自己的手指吗？伸出你的手，手心上，你会看到手指尖上有奇怪的纹路，我们手指皮肤上的某些区域会存在一些凸起，这些凸起来的部分连接起很多线条，线条又汇成了一个图案，这都是指纹。我们每个人都有指纹，这些指纹一般不会再修改。可以分成两大类型，一类叫斗，中间绕成一个闭合的圆圈，这叫做斗纹或者罗纹；另一类，没有绕成闭合的圆，而是有一个出口，这种叫做簸箕或者流纹。你可以打开自己看看，或者对照自己的手识别一下自己的指纹类型。

咱们今天要说的话题也指纹有关，指纹到底是什么呢？会不会消除指纹？

# 指纹到底是什么？

指纹是人类手指皮肤上一个比较特殊的部位。因为我们手和脚趾上，身体的其他部分皮肤没有类似的特点。其他地方的皮肤，可以显现皱纹，会有褶皱，但是一些褶皱会随着年龄增长或者环境的变迁而发生变化。

但是指纹不一样，一般来说，一个人的指纹一旦形成就不会再发生变化，实际上，你还在母胎的时候就不长了。已经长出的指纹来了，直到14岁左右，你的指纹会完全定型，不再改变，也就是说，如果你现在还不满14岁，你的指纹有可能还会发生一些细微的变化。

其实，不让人类有指纹，所有灵长类都有指纹。但长江指纹真正原因被类并不知道人类一样的。因为指纹并不是为了有手才长出来的，而很可能是无意中从长出，然后因为有种好处就保留了下来，并且扩散到了整个人群之中。

其中，很多好处是显而易见的，比如，指纹的纹理和褶皱，可以增加我们抓握物体的摩擦力，也可以让手指在皮肤抓住东西的时候，增加接触面，避免皮肤因为拉扯而弄受伤；此外，它可以增加皮肤的水分面积，有利于散热和排汗，手指上的水膜能发，手指不容易打滑。

# 指纹也会出汗吗？

手出汗，就感觉，但指汗，就常常能感觉到。一般情况，一个人的手指，大约能排出的汗水在1.5升左右，这个数字可不少，怎么也有三十毫升的样子。只是你很少注意到。而且这1.5毫升的汗水会让我们感到非常舒服。虽然这些汗水的组成，主要成分是水，但也会含有极少量的其他物质，比如蛋白质和脂肪，你经常注意到手心的皮肤颜色较其他部位要深一些。当你接触到其它物体，能很容易地摸出一个指纹上去，这些物质像印章一样。你留下痕迹，会粘在物体表面上。

这一现象在触摸玻璃表面的时候会更明显，比如照相机镜头，或者当手机屏幕，指纹会非常清晰。我们就经常看见警察通过寻找罪犯在不小心留在物体表面的指纹，找出疑犯，破案。这就是指纹的功劳。为此我们找了指纹，就是为了确定罪犯的，原因很简单，每个人的指纹都不一样。不过这话说得太夸张，准确的说法是，到现在为止，我们还没有找到两个相似到极小的人。科学家们在指纹上已经确认的几十条特征，找到了一百多个特点，就其中的一个特点特征，如果这个组合在世界上相同的人，属于巧合了。在英国，发现有16个特征点吻合，就被确认为同一个人。在澳大利亚，只需要确认12个特征点，而在中国，这个数字通常是7到13个。之所以选择特征点进行比对，也是比对到容易特征，原因是，在犯罪现场很难到完整的指纹，是不完整的指纹模糊的，所以需要选取一些特征点进行比对就可以了。

# 人能不能修改指纹？

那么，会不会有人故意把指纹改掉或者干脆抹掉呢？当然有，历史上，很多罪犯都干过这档子事。比如美国一名帮派曾经试图用硝酸来毁掉自己的指纹，还有人通过外科手术，切除手指上的一部分皮肤，消除指纹。不过这些方法都并不起作用，因为皮肤会逐渐长出来，指纹再一次出现在上面重新长出来的指纹，一模一样。即使真的把指甲根上面的皮肤去掉了，皮肤深层的指纹生长细胞依然在，依然可以通过它们恢复一个人的指纹。

不过，这只是大多数情况，也有例外的。1941年，美国的警察真的抓到了一个几乎完全没有了指纹的人。一到这个人，警察们就觉得有问题了，他没有指纹，脸上有整容的痕迹，手上又没有指纹——非常像在进行犯罪掩盖自己身份的人，警察进行了非常认真的检查，最后确认他是大型一直追寻的罪犯。更重要的是，虽然他通过外科手术修掉了皮肤，还残留生长的指纹，只是模糊了。但是还是多少留下了一些特征点。最后，通过这些特征点，警察查确了他的身份，并将他绳之以法。

——博物学家笔记——

现在，科学家们会通过更多辅助手段对一个人的身份进行确认，比如手掌的掌纹、嘴角上的皱纹，以及眼睛里的虹膜等等。这么一来，坏人就更难隐匿自己的身份啦。

既然说到了指纹，不妨玩个小游戏，把自己的指纹拓制在白纸上，再找爸爸妈妈的指纹拓制下来，对一下，看看你们各自有多少个斗纹，多少个簸箕纹。

+   1. 人的指纹在胎儿时期就已经出现了，在14岁之前，指纹还可能发生比较细微的变化。到14岁以后基本就定型不变了。
2. 指纹存在意义在于，有助于我们在抓握东西的时候避免皮肤损伤，同时也有利于汗排汗。我们留下的指纹，就是这些汗液的分泌物。
3. 科学家在指纹中已经找到了一百多个特点，比对其中的一些特点，可以判断一个人。指纹是否属于某个人。为了掩盖身份擦除，一些犯罪分子试图破坏或者消掉自己的指纹，但这样做基本都失败了。
