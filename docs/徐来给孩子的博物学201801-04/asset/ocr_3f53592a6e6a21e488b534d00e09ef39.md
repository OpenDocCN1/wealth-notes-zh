# 突然出现明亮的新星

在古代，每当科学家们已经发现了恒星时常常会出现新亮的发光，有的时侯是本来有恒量的地会突然出现了恒星，有的时侯是本来有恒量的地方，恒星却一转瞬明失了。当然，在很多情况下，变化会怎么做以戏性。在很多的情况下，本来不怎么亮的星座突然变得非常耀眼，或者非常耀眼的星座突然暗了下来。

根据伟大的古罗马学者查尼尼的记录，古代希腊著名的天文学泰戈·尼德哈特就注意到了这种现象。实际上，古尼德哈是变得以前注意到好几天去，然而他受到这个发现的鼓舞，才开始专心观察恒星的

世界上第一次记录这种情况，是在中国的一部史书上，叫《后汉书》。记录的那一年，是公元185年。当时，一颗奇怪的亮星突然出现，这个情况持续了6个月的时间。

古代中国的天文学家称这种现象叫“客星”，不是克星，是客家的客，客是意思是属于某个区域，然后突然到那里做客的星。这个名称，听起来还挺贴切的。

再往后，这种现象的记录就渐渐多了起来。最早发生是在公元1006年那一次，被认为是最高光的一次，直至今1天都可以看到。除了中国入之外，在埃及、伊拉克、日本和瑞士都能到关于它的记录。而最著名的一次则是发生在1572年的1054年。1054年那颗星星亮了足足超过一年，其中有20多天时间，它在白点都能看到。而一年之后呢，它消失了，只下一个很模模糊糊的影子。后来人们把那个影子叫做“蟹星星云”。

当时的天文学家搞不清楚为什么会有这样的情况。一直到上个世纪30年代，天文学家们才终于彻底搞清楚这是到底是什么。美国的两位天才潘塞巴德和兹威茨最先确定，它们是一类独特的天体，然后给它们起名字叫“超新星”。这样来，这些奇怪的现象有了名字。它们的专门用来描述，这就是“超新星”这个词的英文缩写。而且超星多数是新发现的年份，如果那一段时间有着数量星新的，那么再次宇宙来表示先先后。比如我上面提到的两颗超新星，编号分别是 SN185、SN1006 和 SN1054。

# 恒星的“突变”

为什星变得不太亮亮的星座会突然变得很亮呢？其实，它们本来都是都很普通的恒星，和我的太阳一样。内部会发生变化，核聚变反应，向外辐射大量的能量。在核聚变反应中，比较轻的元素聚变来变成它们比较重，受到重力的影响，它们就慢慢往恒星深处聚落。这来，年久日，恒星上的元素，从下到上，从轻到重，这样的布局，看起来像一个大洋葱。

同样是年久日，恒星可以拿来维持核聚变反应的材料越来越少，核反应的规模越来越小。你可能会说，还记得我之前引力的时候，你提到过的吗？星的一半，那是受到恒星自身万引力的吸引的。对于那些特别巨大的恒星来说，因为引力太了，所以恒星上的各个部都有的中心掉落下去的趋势，所以没有稳定的核聚变，但是恒星在进行剧烈的核反应，在外释放能量，这个量和掉落的方向抵消了。

但是反应太弱了，就抵不住掉落了。巨大的核聚变都慢慢向中心掉了，天文学家管这个过程叫坍缩。掉到一定程度呢，就掉不下去了。到不了。但因为热速度太大了，突然一刹车，反作用力就它们又反掉了出去。这样就成了巨大的爆炸。超级明亮的客机就是这么来的。随着研究的深入，科学家们发现了一些更可怕的东西。上世纪60年代的时候，美国的科学家在太阳当射，伽马射线。伽马射线能力很强，能量高，非强大。

这都很吓人，一开始科学家们就了很多人都不知道这些伽马射线是从哪来的。这个问题直到1998年才解开。当时，天文学家们记录到一次伽马射线的爆发，同时又记录到新近新星的爆发。两个被认为是有关联。随后的一些研究证了这个关联，大家才确认，原来这种伽马射线爆发的情况和新星爆发源发来的。

原来，如果一颗恒星非常非常大，那么微过程中，有些高能粒子会沿着它的自转轴向喷薄出去，这样就形成了伽马射线。天文学家估计，这类伽玛射线就10000光年远地方，而且地球正好也在伽玛射线喷射方向，那么很可能会对地球成相当严重的影响。

不过，你不用为此担心，因为截至目前，天文学家都测到离我们最近的伽玛爆，离地球有13亿光年远，比一个万光年，远了十万倍！。
