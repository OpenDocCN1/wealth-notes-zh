# 生态学·植物 | 森林大火一定是灾难吗？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

1987年，我们国家发生过一件震惊世界的大事儿，这件事持续的时间很长，总共有一个月的时间。所以我们这一代人的记忆里，印象非常深刻——那是大兴安岭火灾。

这是非常可怕的一次灾难，燃烧的面积，相当于小半个英国，损失惨重。所以，对我这一代人来说，森林大火那可是非常糟糕和恐怖的事情。但后来，我知道了一件非常颠覆常识的事，那就是：森林大火对森林本身其实是有好处的。

你是不是也很意外？大火造成的不就是破坏嘛，怎么可能还有好处？今天我来说说大火对森林的好处吧。

# 有些树非大火不能活

说到森林和火的关系，几乎所有人都会觉得，后者给前者带来的是毁灭。这个咱们生活当中就能感受到。有些东西一旦被打点着，就可能瞬间烧成灰烬。木材就是易燃的东西，所以，由树木组成的森林是非常容易引发火灾的。

但有些树就跟别人……嗯不对，跟别的树不一样，它们反而喜火，偏偏喜欢大火。说这些树喜欢火，当然不是说，它们在火灾里生存下来，是真能听过火灾了。它们身上也会着火，温度一高了，它们也会被烧死。

但大火能帮助这些树木做一件事情。这件事对这些树来说具有极其重要的意义，就是帮助它们撒播树籽。你听过蝙蝠、蜜蜂、鸟类可以帮助植物传播种子，还没听说过大火可以帮助传播种子吧？

先给你介绍其中一种，它是生活在美洲的北美短叶松。听名字就知道，这是一种松树。松树的种子就是松子儿。松子儿你肯定吃过，外面有一个硬壳，松子儿最开始是整个儿被包裹在松塔里面的。种子成熟了，松塔就松开了，种子就掉下来了，被松鼠之类的小动物带走，有些就有机会长出的松树了。哎呀呀，刚才那儿真疯。可是北美短叶松不是这样。它的松子在松塔里，但松塔不会松开，而是被它自己分泌出的厚厚松脂给封住了，变成了一大坨。光是靠时间是不可能让它裂开的，得加热，烧到50度以上松塔才会打开。所以，北美短叶松的繁殖必须要借助山火的力量。

还有些植物，比如短叶斑莲花，短叶是它的叶子有短斑，斑莲花音译来的。它的种子，皮比较厚实，不怕高温，火灾的时候，只要不是盯着它烧就没事。正常被土里，等火熄灭了，正常发芽。而且森林大火把周围的植物都烧死了，空出一大片地方来，正好给新生的短叶斑莲花提供了足够的生长空间。

其实，不光是具体的某几种植物，对整个森林来说，火灾也并不一定是坏事。有的时候，一些自然界的小规模山火会清除掉森林地面上枯萎的落叶和杂草，为新一轮的植物生长腾出空间，也防止过多的枯草枯枝堆积，引发更大的火灾。因为森林火灾的问题太过复杂，在这个方向上甚至兴起了一门新的学科“火生态学”。

# 老鸹也能从大火中收益

科学家们发现，从森林大火当中捞到好处的，可并不只有植物，有些动物也能从中收益。在澳大利亚，有一位消防员曾经报告了一件很离奇的事情。

这个消防员名叫尤森。他是在上世纪80年代，也就是差不多大兴安岭火灾前后那段时间做的一份，事情发生地点，在澳大利亚北部的一个叫卡杜国家公园附近的一座矿山。当时，这座矿山引发了很大的山火，尤森和同事们被指派去当地灭火。作为一名资深消防员，尤森对处理这种山火很有经验。他和大家一起，找到一处着火点，然后把周围可烧的东西周围的植物都清空，等到着火点上着点的东西都烧完了，自然火就灭了。可谁想，眼看森林的火里飞过来一只鹰，准确来说是一只啸栗鹰，啸栗鹰，这是这种鹰的名字，这只鹰从火场里叼起一根还冒着烟的树枝，飞到不远处扔了下去。

这只啸栗鹰不停地把燃烧着的树枝到处乱扔，其中一些造成了新的起火点。那一天尤森和同事们一共处理了7个类似的起火点。

本来，尤森没把这当回事。可是到了2012年的时候，他在处理另一处高速公路旁边的森林大火时，又亲眼看到当地的另一种鹰，叫黑鹰，通过这种叼树枝的方式硬是把火种引到了高速公路的另一边。
