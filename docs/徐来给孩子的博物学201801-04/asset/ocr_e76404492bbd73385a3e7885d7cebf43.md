# 宇宙里会下雪吗？

![](bbox=[0.15, 0.36, 0.85, 0.48])

徐来

在地球上形成降雪，需要有两个重要的条件，一个是温度，空气当中要有足够的水分，可以凝结成雪花，再飘落下来；第二个是温度，温度足够低才能够让水蒸气凝结成固体，变成雪花。当然，还需要一些其它的东西，比如说凝结核，像是灰尘啊、花粉啊一类的东西，能够吸附水汽，给水汽一个凝结的起点。还有呢就是地球的重力，没有重力的地方，雪就到处乱飘了，不会有“下雪”这样的情况。

那么宇宙里满足这样的条件吗？咱们来看看着宇宙的温度和湿度部分，温度都是极低的，宇宙的很多地方，温度都非常非常的低，这个低不光是冬天感觉冷的那种低，地球上任何地方的温度跟它都比不了。宇宙里大部分地方的温度绝对零度（也就是一切东西可以达到的最低温度），只高出来一点点。

温度够了，那湿度呢？很抱歉，宇宙里大部分地方都是空的，没有任何物质，当然也包括水。换言之，宇宙的绝大部分区域都不可能有雪。其实有些没有物质的地方，可能会满足温度和湿度大的条件，有可能形成雪，比如某些星球上，有但这种生也不是构成的，而是其他物质，比如，冥王星和木卫二上就有甲烷雪。

# 我想我们家的牛牛问，为什么有些狗喜欢吃便便？

![](bbox=[0.25, 0.73, 0.75, 0.83])

徐来

这个问题里包含一个很大的误区。对于牛牛来说，粪便是一种很脏的东西。相信包括牛牛在内，很多人把它看成垃圾。但在动类的粪便里，其实有很多没有消化掉的食物残渣，还有各种有机物，有些动物的粪便里甚至包含一些特殊的营养成分。所以，有些动物会吃，比如狗，吞便本身就是一种好的食物。

还有，在野外生活，不可能像是家里一样，你一张嘴，爸爸妈妈就把饭菜送过来了。在野外都是自己去找办法，所以，每一点食物都不能浪费，狗狗为什么喜欢吃便便？因为有吃的就吃嘛，还客气干嘛。

# 我想我们家的孩子问嫣然，问几个关于牙齿的问题，动物是如何让它们的牙齿保持洁白的，以及它们为什么不会蛀牙？

![](bbox=[0.2, 1.0, 0.8, 0.00109])

徐来

这个问题里，嗯，嗯，可能还是有点误会。首先，牙齿不是白色的，而是有一点自然的淡黄色。动物的牙齿也不会太白。之所以会觉得动物的牙齿白，那是因为可能你并没有太多机会好好观察动物的牙齿，所以把它想象白了。

蛀牙这个问题呢，要更复杂一些。首先要说的是，狗的蛀牙比较少有几个原因，一个是食物中含有的糖分少，另一个是很多食物本身有经过撕咬的过程，这个有清洁牙齿的效果，再就是有些动物牙齿结构比较简单，但这不等于动物不会蛀牙。狗狗会蛀牙，黑熊也会蛀牙。有些动物呢，蛀牙不太常见，但会患有其它的牙齿问题。比如狮虎，虽然很少蛀牙，但牙周疾病就很多见。所以啊，你说的这两个问题，其实都是假的问题。

最能说明这个问题的，人类牙齿结构非常，很多人一都是人类的食结构，我们就吃糖太多了。如果不配合正确的牙齿护理，确实很容易得蛀牙。所以，你也要少吃糖，勤漱口，早晚刷牙，多用牙线。

# 鱼是怎么睡觉的？

![](bbox=[0.25, 0.0013, 0.75, 0.00138])

徐来

鱼肯定也要睡觉，不睡觉可不行。不过，鱼的睡眠不太容易观察到，因为鱼不像咱们一样，睡觉闭眼睛，鱼没有眼皮，所以不会用眼皮。还有，鱼是生活在水里的，它不可能像是陆地上的动物一样找一个地方闭上眼，或者成动来睡觉。所以，它们睡觉的样子，和醒着的时候，差别并不大。

如果你家里养着小鱼，可以观察一下，如果你养着金鱼，一动不动的，你鱼缸里养着鱼，鱼看着一动不动，多半就是已经睡着了。在自然水域中，很多鱼在睡觉的时候，会给自己找一个隐蔽的地方。

沐沐说，这是寒假期间自己带着沐沐去参观自然博物馆和天文馆之后，沐沐提出的问题。其实蛮有意思的，小朋友的核心思想是觉得动物有有年龄的过程，也会动，那有年龄、有生长过程、也会动、这也是生物的定义对？显然不是。

因为原则上来说，这个宇宙中所有的东西，包括这个宇宙本身，都是有年龄、有生产和消亡的过程以及运动的。难道宇宙中的一切都是生命吗？显然不是。

生命还需要符合另外一些特征。比如说，生命需要新陈代谢的过程。简单来说就是吃进一些东西，把它们吸收成为自己的一部分，然后把这个过程的废排出来。地球居然没有这么个过程。再比如说，生命能够自己制造，动物就不用了，即便是植物，比如一棵树，你砍它一刀，它会自己分泌出东西来保护伤口，慢慢地把伤口长长结疤，形成一个疤，最重要的一点是，生物是进行自我复制的，能够不断地繁衍进行...
