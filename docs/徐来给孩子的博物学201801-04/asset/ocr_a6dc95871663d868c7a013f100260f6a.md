# 上不了大学的科学家

关于女性科研工作者在她们领域中遭遇不公平待遇这件事儿，咱们之前就说过了。比如说咱们给玛丽·安吉的的。还记得吗？她是一个贫穷的英国人。

不过，因为她生活的小镇附近有很多化石，所以她从小就学着挖掘化石。进行发掘工作，然后用这些化石来换取一些钱，她的工具真是太出色了，不仅来发现和整理了很多物种最大的一些爬行动物，还在当时的学术刊物上发表了一些文章，指出当时在化石层叠上出现的一些错误。

当然，尽管工作成果非常抢眼，而且她同时也很符合玛丽·安吉在古生物学上的成绩，但因为是个女性，所以她一直没有获得英国地质学会的正式会员身份。

玛丽·安吉出生在200年前，她去世的时候是92岁，刚好是170年。而也许你猜了，是不是因为她所处的时代太早了，所以人才会认为男性才没有资格做些什么事情，女性没有资格的话，也做不好。今天要说的另一个玛丽，玛丽·居里，也就是居里夫人，比玛丽·安吉小了70岁。然而，她的境遇跟玛丽·安吉并没有太大的区别。玛丽是波兰人，她的父母都是很有名的老师，所以从小就接受着非常好的教育。她中学成绩优秀，还要继续读大学深造。一打们来说，再过个十几年，去读个大学，甚至读个研究生、拿个博士学位都不是问题。但对玛丽来说，问题可大了——波兰的大学只收男生，所以，她不得不去读一个叫飞行大学

简单来讲，就是非正式的学校。后来，玛丽跑到了法国巴黎。在这里，她顺利地进入了巴黎大学，并且正式开始了自己的大学生涯。在拿到学位之后，玛丽很快遇到自己的祖国波兰，把自己的学问传授给同胞。然而，波兰的大学却拒绝给她工作的机会，原因很简单：她是女性。
