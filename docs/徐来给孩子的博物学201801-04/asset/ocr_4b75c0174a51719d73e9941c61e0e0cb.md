# 岩矿·地球 | 钱是怎么产生的？

世界大，奇妙的事情每天都有，我们一起出发吧！

过去的时候，你应该听到了不少压岁钱吧，对于你们来说，不一定有直接支配日常这笔钱的会，钱可能也是你使用接触到的最大一笔钱，也许你很开心。

可是你有没有想过，钱到底是什么呢？为什么大人会爱呢？

钱，简单来说就是一把尺子，用来量量咱们平时做的、穿的，用的，以及别人对你做事的评价。在太多情况底下，有了这把尺子，我们好评判，自己值不值得出用用上的东西，去换其他人手上的东西。

# 黄金和白银为啥会成为“尺子”？

古代最重要的钱是黄金和白银，尤其是黄金！即使到现在，它也依然是财富的象征。

人类当然不是约好了要使用黄金的。这是由黄金自己的特性决定的。第一，它固体，便于携带，易于交换。第二，黄金这种金属的性质很稳定，不像铁一样，容易生锈。第三，它不需要用很昂贵的方法就能提炼出来，不会像提炼白金一样，需要超过1700度的高温才能溶化到，这对古代人类型来说完全是不可能达到的。

更重要的是，黄金在地球上的存量不特别多，物以稀为贵嘛。否则这些“钱”就不那么值钱；但也不能不够少，否则制作的成本太高，也会影响生产和使用。

要满足这么多的条件，黄金就进入人们的视野了。黄金这东西，有一个非常明显的好处，那就是非常稳定，不容易跟其他物质发生化学反应，或者说它的个性特别“杠”，不喜欢跟其他人交往。不信，你可以看看爸爸妈妈爷爷奶奶外公外婆的金项链、金首饰，不管戴了多久，都是金灿灿的。而且，黄金在自然界里天然存在，自然界中的金块儿叫“狗头金”。而且，自然界中的黄金不少，人类到之前已经产出超过18万吨黄金，显然是很为多，但是加上其他一等的白银，就足以当作货币来流通了。

# 世界上最大的钱

当然，在世界各个地方，也有过黄金白银以外的钱。比如古罗马帝国，古代就把铜当做钱。如果你看过一些古书，特别是秦汉时代的古书，你会发现，他们说的话，也是钱，也会这里的钱，指的是铜，不是黄金。还有地方，曾经流行过贝壳、动物的牙齿、特定物种的种子做钱来用。

还有些地方甚至会用特定的石头。在所有奇的钱当中最奇怪的，来自太平洋的一个小岛：雅浦岛。

这个雅浦很小，现在岛上总人口也就是一万人出头，人很少，但很多人更少了。但是这个地方很有名，就是岛上的人使用的钱不是石头做的，叫做钱——钱石像铜钱可不是铁钱嘛，这些钱都是圆形的一块儿，当中有个窟窿像儿——你别觉得这个钱就跟咱们中国古代的铜钱一样，圆形有个窟窿眼好绳子串起来带着呢，这些钱每个石头其实都非常大。最小的，它的直径有30厘米，个头，最大的也有，重量超过4吨，个头越大，这块石头也就越“值钱”，这么大，这么重的钱，显然是没有办法带着跑的。那么怎么花这个钱呢？

这就是这个岛的神奇之处了。在花钱的过程中，雅浦岛的居民根本不需要移动这些钱。他们的钱是放在那里的，交易双方之后，还是原来。研究者发现，科学家们发现，这个岛上的人形成了一种特别神奇的交易方式。

你看，这些石头很靠近，所以它摆放的位置可能是拥有它们的人很远。比如，你有一块大石头，但是在你家的院子中间，而你的石头那块大石头，放在隔壁村子之外的一个路口上。那么大，去前某块石头属于谁呢？它的可能，那简单，在石头上刻上自己的名字不就结了，如果你在这上想到那就错了，其实都不用。你只需要让这个岛上的人都来认认，这块石头就属于你的就行了。要这块儿石东西，也很省，只要带着石币的接受者，还有一些见证人对这块石币的方面交了交。大家也就认可石币的主人换好了。

更有意思的是，有学者发现，即使这块石币丢了，大家也会依然认可它的存在。比如，制作石币的大石头上出现个岛岛，而造出了附近另一个头。有个岛家去那个头岛开了一块特别大的石币出来，让他在船上运回雅浦岛，谁知道，船在半路上这块石头给掉进了海。尽管如此，岛上的人们依然承认这块大石币的存在，照样可以用它来进行交易。

说到这里，你一定会觉得雅浦岛上的人们真的太随意了，找几个人说案一笔钱是谁的，那就是谁的，而且还承认看不见摸不着的钱也是存在的——这不是太搞笑了嘛。
