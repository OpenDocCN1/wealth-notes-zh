# 什么是水晶头？

水晶头盖，顾名思义，就是用整块儿水晶雕刻成的类似人脑一样的东西。水晶头盖，以前被人认为是珍贵的，但实际上水晶都是无色透明的石英罢了，作为一种矿物，石头在地球上 的石星那是相当大。所以，即便是大块儿的水晶头盖也不是很罕见的东西。不过，水晶这个东西，非常硬，而且十分难，加工起来不是特别容易，需要慢慢的琢磨。很早以前，人们没有掌握如何处理水晶的方法，水晶头盖曾很珍贵。

你可能在想，那时候人们见到了那么大块儿的水晶头盖，又说它是古老的古董，于是由那些非专业的土著作们制造的，肯定不是特别好。

所以说，关于水晶头的说法，很快就越传越开来了，大家越说越神，越说越迷。大家说，很多人都相信，这些水晶头是有法器的法器，所以，具有神奇的力量。

还有一些人，声称水晶头盖和世界末日有关。他们认为，这个月世上一共有13个水晶头盖。如果在一个日子，有人把这13个水晶头盖都找齐了，那么世界将会陷入各种灾难之中，人类将毁灭。而日 这个月是世界末日，就是著名的"2012末日"，2012年12月21日。你可以算算，这个日子已经过去多久了，是不是还在运转？

因为水晶头盖的说法非常多，一些著名的探险电影里也出现过它，并且进一步渲染了它的神秘感，电影让一些电影也让它的传说越来越有神奇。

# 水晶头打哪儿来？

那么，水晶头盖到底是 怎么发现的？

实际上，水晶头的说法可以追溯到很久的时间。最早的水晶头记录，是一个法国人有关，他叫欧仁·博班，是一位考古学家，据古语言学家，这个人很小的时候就到墨西哥，后来加入一支考察队，到处搜刮古董，成了当时非常著名的古董商人。
