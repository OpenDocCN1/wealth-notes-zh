# 化石之战：柯普VS马什

化石之战的双方，一个叫柯普，一个叫马什，都是古生物学史上响当当的名字。

先出场的是柯普。柯普是当时美国最著名的古生物学的学生，也是起格很厉害。年轻时就做了博物馆的馆长。而且，在1866年的时候，他发现了个头不很大的恐龙化石。这个恐龙化石个头不小，估计身长至少有7.5米。更重要的，实际上他是最早发现的恐龙恐龙之后，第二种被发现。

# 装错了镰刀龙的头

接下来柯普又碰到了好事。他收到了一箱化石，这种化石简直太特别了。因为里面一种新类型。这种类型，不是蛇，也不是水底爬行动物。跟他的关系不大，但是特别地。

# 挖化石挖到打群架

为了获得更多地古生物化石，马什决定向东部进发。他组织了一支远征队，进入印第安人的保留地探索化石。而柯普呢，也毫不示弱，同样组织了团队，加入了同样的地点，两人开始了正式的竞争。
