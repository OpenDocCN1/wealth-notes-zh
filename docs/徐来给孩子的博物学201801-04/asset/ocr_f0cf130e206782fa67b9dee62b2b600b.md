# 语言学人类｜谁破解了罗塞塔石碑上的古代文字？

![](bbox=[0.1, 0.13, 0.9, 0.16])

前一阵，我在《群星为什么有尾巴》里提到了冯·哈曼的那个飞艇，名字叫做罗塞塔号。

还记得我当时是怎么说罗塞塔号的吗？它实际上是考古学家破解一种失传的古代文字的工。科学家给它起这个名字，是用了一个比较新的手法，希望它能帮助人类破解太阳系的秘密。

那么，罗塞塔到底是个什么东西，它又是如何帮助考古学家破解古代文字的呢？今天，我就来给你说说罗塞塔的故事。

# 什么是罗塞塔石碑

罗塞塔其实是一座城市的名字。这座城市在埃及的北部，城市不大。18世纪末的时候，法国纳、拿大偶像的拿破仑带领军队进攻略，拿破仑很会打仗，当时他带着两万五千人的军队，和埃及的十万大军作战，只损失了300人，就取得了决定性的胜利。

这个拿破仑有点儿意思，他自己受教育的程度很高，在数学、天文学上的造诣是很高的。他知道埃及是个文明古国，预料到在这里会挖掘到很多有意思的东西。所以，他不仅带去了一支军队的军队，还带去了好多学者，一边儿打仗，一边儿还做点儿科学研究。

当时，驻扎在罗塞塔这个地方的人，是拿破仑手下的一个军官，名字叫做布夏特。为了防范埃及军队的反击，布夏特开始加固罗塞塔城外的要塞。士兵们挖地基的时候，挖到一块巨大的黑石头，一下子激动起来。

布夏特过去一看，喏，好大一块石头。高度超过一米，宽度呢一米不到，厚30公分，是黑色花岗岩材质，上面密密麻麻刻着稀奇古怪的文字。布夏特会有感觉了什么叫做埃及文字。布夏特一看，就刻有图画，阴着看是一块石碑的一部分。虽然看不出石碑上刻的是什么，但他知道这种和古埃及有关的报告给总领了自己的指挥部。而后者，则直接把石碑送到了拿破仑专门设立的埃及博物馆。因为这块石碑是在罗塞塔这个地方被发现的，所以大家都叫它罗塞塔石碑。

不过，拿破仑占领埃及没多久，英国人就开始过来了，直接给法国人给跑了。罗塞塔石碑又落到了英国人手里。英国人一看，这是好东西，就直接装船返回了伦敦。现在你去大英博物馆，在展示埃及文物的那个厅里，最重要的一件展品就是这块罗塞塔石碑。而法国人，只带走了石碑的拓片。

所谓的拓片，就是把纸张在石碑上淋湿，拍平，然后用墨里的小刷子去涂纸的表面，石碑上刻了字的部位会显进去，碰到墨水，就留出了白色的印记。

# 物理学家读出了一个名字

经过检查，学者们发现，罗塞塔石碑上有三种不同的文字。其中一种，是古代希腊文，这是当时的学者们了解的，他们就可以解读出其中的内容来。而另外两种，则是他们不认识的。

这两种中，一种看起来，都和古埃及人，通过拼音的方式来构成语言。这和古埃及，是普通人使用的文字。而另一种，看起来像像漫画一样，比如画个眼镜，画一个老鹰，画一个狮子。这种文字出现在古埃及人的很多寺庙和墓碑里，看起来似乎和祭祀活动多有关系。

其实，学者们早就知道这两种文字的存在了。但是他们始终无法读出其中的内容。现在，谁写明白，有下面两种古代希腊语的引导，破译上面两种古代埃及的文字，只是时间问题了。

全世界的学者们都开始赛跑，英国和法国的竞争尤其激烈。

英国队派出的选手名叫托马斯·杨。这个杨先生很有派头，不只是个物理学家，还是一位物理学家。他的一些研究成果后来也影响到牛顿。从某种意义上说，爱因斯坦也曾受到过他的启发。

![](bbox=[0.1, 0.0010400000000000001, 0.9, 0.0011])

当然，英国人让托马斯·杨来研究罗塞塔石碑并非毫无道理。因为托马斯·杨本人也是一位语言天才，他可以讲10多种语言，对其他事情的涉猎也颇具兴趣，比如是最后一位百科全书式的学者。所以，如果要找一个人读古埃及文字，托马斯·杨，足够。不过，托马在破译这块石碑上的工作，成就有限。实际上，他只拼出了一个单词：托勒密。这是当时埃及国王的名字。

# 商博良大获全胜

就在托马斯·杨对罗塞塔石碑努力工作的时，英德皇家学会收到了一封来自法国的信。是一个名叫商博良的17岁的年轻人写的。他想向皇家学会提一张图，以便更好一点的罗塞塔石碑拓片。

皇家学会吃了一惊，难道这个人也能破译罗塞塔石碑上的古埃及文字？皇家学会很快就联系了起来。不过，人家有礼貌地来拒绝，也不得不得回应对方。于是，一开始托马斯·杨给博商博良回信。一边教托马斯·杨，同时问他，一块罗塞塔石碑的拓片值多少？被一个小子给破解了，那岂不是太没面子了。

不幸的是，这么纠缠的一件事情，真的发生了。正当托马斯·杨继续保持优势的时候，商博良只用了几年时间，就完全破译了石碑上最上面那些看起来复杂而又好听古埃及文字——那一年也，又一家学者破解出来的普通民用的古埃及文，这让罗塞塔石碑上的内容，终于被完全解读了出来。

原来，这确实是一块与国王托勒密有关的石碑。它位于一个叫托勒密五世的国王。这位国王加勒比第一年一年的纪念。上面刻的，是托勒密五世立获的正当性，以及这位国王做的许多好事。

通过博良的工作，大家不但完整罗塞塔石碑的内容，而且还获得进一步了解古埃及各种国家、部落、城市、墓室铭文的可能性。
