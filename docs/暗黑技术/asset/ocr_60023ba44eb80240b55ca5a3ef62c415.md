# 因自負而陷入困境的無印良品

木村：松井先生於二〇一一年起擔任無印良品的社長，而無印良品的業績也正從那
年開始急轉直下。

松井：公司經營出現問題，大部分是內部因素，我認為有九成以上都是。
在業績下滑的前十年，營收跟獲利每年都以三成左右的水準成長，業績年年成長，因
此大家充滿了自信。好像一切都如自己所預料，計畫完美無缺，使大家既自傲又自滿。
在那種狀況下會發生什麼事呢？大家心態變得安逸，討論的內容也越來越封閉，外頭
的世界連看都不看了。反而是越來越多其他公司來參訪交流。無印良品當時的業績非
常好，所以有不下百圓店、家具專賣店、文具業、化妝品業、寢具業、沙發展造商等
公司，購買無印的商品，排列於會議室，然後下令要求員工：「用更低的成本做出跟
無印一樣的東西。」
