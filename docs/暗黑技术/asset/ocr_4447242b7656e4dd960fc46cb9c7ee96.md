# 成為「我不知道」的專家

全錄的前會長安·穆凱伊，在二○○○年時突然被指名接任營運長。當時的全錄面臨倒閉危機，負債高達兩兆日圓。股價也從穆凱伊就任前一年的六十五美元，一路跌到穆凱伊接任時只剩十分之一左右，大家都認為全錄應該要申告破產。

穆凱伊過去主要是執掌人力資源管理，當然不可能精通事業的營運。她在接任營運長之後，做的第一件事就是組織團隊跟查明事實。也就是說，她非常了解自己什麼都不懂，因此，上任後便開啟了「連串「我不知道」的策略。如果不懂就跟懂的人請教，具體來說，例如，集結精通財務、研發、產品開發等領域的人，組織團隊。那樣的策略奏效，成功扭轉情勢，讓全錄起死回生。

當身分地位越來越高時，「我不知道」就變得難以說出口。身分地位越高，為了維護自己的面子，會無法開口說：「不知道」「請教我」，但穆凱伊放下了無謂的自尊，不恥下問。她的綽號是「『我不知道』的專家」。只要是派得上用場的人就善用之，因而做出了成果。
