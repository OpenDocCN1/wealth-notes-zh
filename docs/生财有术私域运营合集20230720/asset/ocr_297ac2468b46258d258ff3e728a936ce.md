# ## 中国茶类大全

+   1. **中国六大茶类**
	1. 绿茶
		1. 烘青绿茶 (六安瓜片)
		2. 炒青绿茶 (碧螺春)
		3. 蒸青绿茶 (玉露)
		4. 晒青绿茶 (滇红)
	2. 白茶
		1. 白毫银针
		2. 白牡丹
		3. 贡眉
		4. 寿眉
	3. 黄茶
		1. 君山银针
		2. 蒙顶黄芽
		3. 霍山黄芽
	4. 青茶
		1. 闽北乌龙 (武夷岩茶)
		2. 闽南乌龙 (铁观音)
		3. 广东乌龙 (凤凰单丛)
		4. 台湾乌龙 (冻顶乌龙)
	5. 红茶
		1. 小种红茶 (正山小种)
		2. 工夫红茶 (祁门红茶)
		3. 红碎茶 (滇红)
		4. 湖北青砖茶
	6. 黑茶
		1. 滇红黑茶
		2. 四川边茶 (雅安藏茶)

| 茶类 | 制作工艺 | 代表特征 |
| :--- | :--- | :--- |
| 绿茶 | 杀青·揉捻·干燥 | 清汤绿叶 |
| 白茶 | 萎凋·干燥 | 灰白毫密 |
| 黄茶 | 杀青·揉捻·闷黄·干燥 | 黄汤黄叶 |
| 青茶 | 萎凋·做青·炒青·揉捻·干燥 | 绿叶红边 |
| 红茶 | 萎凋·揉捻·发酵·干燥 | 乌润红汤 |
| 黑茶 | 摊放·杀青·揉捻·渥堆·干燥 | 黑汤褐叶 |

| 茶类 | 发酵程度 | 特点 |
| :--- | :--- | :--- |
| 绿茶 (不发酵) | 不发酵 | |
| 白茶 (微发酵) | <10%-20% | |
| 黄茶 (微发酵) | <20%-30% | |
| 青茶 (半发酵) | <30%-60% | |
| 红茶 (全发酵) | <80%-95% | |
| 黑茶 (后发酵) | <90%-100% | |

| 产地 | 代表品种 |
| :--- | :--- |
| 安徽 | 霍山黄芽，黄山毛峰，祁门红茶 |
| 浙江 | 龙井，西湖藕，六安瓜片 |
| 江苏 | 碧螺春，云毫 |

我国茶文化历史悠久，根据制作工艺的不同，
可分为：绿、白、黄、青、红、黑六大茶类。
