# 小红花该在最重要得时候开

上上周，国豪突然说要从昆明来南京，吓我一跳。早上她只是想省出门去上个班，结果晚上就到了禄口机场。所以想来那天，什么都没带，我抱着羽绒服去接她。

我问她来干麻，她说，看病。

结果呢，她看完病以后，一个人去看了场电影，送你一朵小红花。

那天是南京近十年来最冷的一天。冷的扣扣搜搜，钻进一号线，发现坐的恰好是小红花主题列车。

> 闺蜜一个人看易烊千玺和刘浩存谈恋爱，
电影里他们是韦一航和马小远，
看他们相识，看他们相爱，
看他们和疾病对抗，
看他们对世界说我不信。
一路哭一路笑，最后他们分开了，又如同没有分开过。

闺蜜回来告诉我，她印象最深是她们吃烧烤的这一设，

因为吃烧烤不吃包装豆腐，是说不过去的。

易烊千玺都吃不到的云南包装豆腐，两盒包邮。

这篇小作文收获了第一批好评。
