# **2.抖音无人直播搭建：**

1）准备物料

抖音号（粉丝1000+，实名认证，上传营业执照开通企业账号，付费蓝V可不开）。

电脑，直播伴侣软件：

[https://www.douyin.com/faloon/webcast_openpc/pages/streamingtool_download/index.html](https://www.douyin.com/faloon/webcast_openpc/pages/streamingtool_download/index.html)

2）直播间视频素材制作

用剪映制作5-10秒的视频。

内容文案为标题/攻略/干货/福利（滚动字幕）

**目的是拉长用户在直播间的停留时间**，增加留存率，想全部看完要看3遍以上才可以。
