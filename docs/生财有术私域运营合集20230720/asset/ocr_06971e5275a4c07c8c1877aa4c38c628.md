# 四、收益来源

# 1、合伙人推广佣金：

每位合伙人都有专属推广链接和海报，拉新有60%CPS（即每有一人通过你的推广海报加入成长学院，你获得学院售价60%作为收益，每月结算）。鼓励每一位合伙人都能做出自己的线上课程并上架，既可以丰富学院的课程内容，又可以在主题训练营中单独售卖获得收益。

# 2、社群整合：

鼓励合伙人将自己的社群以补差价的形式整合到学院中，大家一起做交付，提供更好的服务。举例：你自己原先的付费社群是¥399，那可以选择赠送季卡（价值相近）或者补¥600差价升级成年卡（这部分差价你还可以赚取佣金）。如果你的社群是免费的，那可以推荐体验卡（时限1个月）或者季卡，后期再做转化。
