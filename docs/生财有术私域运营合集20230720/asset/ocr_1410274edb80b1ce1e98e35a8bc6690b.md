# 小野

总结一下，云南包装豆腐的做法主要有「烤、煎、炸」三种。

烤。能火候最佳，口感、色泽和饱满度都完美胜出（图1~2）；烤箱或空气炸锅次之，优点是快和方便（图3），PT8分钟，刚刚好，出锅时豆腐是鼓鼓的。

煎。一定要选平底锅或摩飞/小米的多功能热盘，两层薄一层油，边煎边煎特别爽（图4~6）。千万别用含粘锅的炒煮锅煎，可以说这样做不太尊重美食，别问我怎么知道的。

炸。这时候可以用炒煮锅了，反正油加得多，不怕粘锅了。炸的口感其实很好，外皮会要加糖酥，但缺点易漏看见。特别容易月牙。

包装豆腐做法和优缺点都帮你总结好了，你可能就是一份包装豆腐来实践了。
