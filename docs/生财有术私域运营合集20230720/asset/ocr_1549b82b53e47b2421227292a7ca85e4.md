+   - 视频爆了后，微信加人比较多，消息回复过于频繁的活会被限制聊天功能。所以加人特别多的时候，要控制回复消息的频率；

+   - 最好不要直接用微信红包、转账的方式收钱。量大了，对方会收到风险提示。不利于用户付费。最好的方式是办一个微信商业收款码，安全稳定，可持续。
