# 公众号 VS 个人微信 VS 企业微信

| | 对比项 | 公众号运营 | 个人微信 | 企业微信 | 
| --- | --- | --- | --- | --- | 
| **客户管理** | **认证机制** | 支付宝认证 | 不支持 | 支付宝认证，代表企业形象 | 
| | **认证资料需求** | 需有企业运营的内容载体 | 个人名片 | 企业个人名片，带企业后缀 | 
| | **拉方式** | 被用户关注，好友无上限 | 上限5000；好友超过23-30人 | 单个成员添加上限2千；邀请成员无上限3千 | 
| | **专人服务** | 不支持 | 不支持 | 多成员组成团队，客户危机分配，团队轮流承接能力 | 
| | **客户标签** | 手动标签 | 手动标签 | 一个客户可多个标签，标签范围无限制 | 
| | **客户标签自动打标签** | 不支持 | 不支持 | 可重复自动设置的客户标签：添加规则、聊天数据 | 
| | **群** | 不支持 | 500人 | 内部群；无上限外部群；200人 | 
| **内容运营** | **自动回复** | 分类发布图文 | 支持群发文字个人消息，每天上3个 | 分类群发消息 | 
| | **群发次数** | 4次/月 | 无上限 | 客户每天只能收4条信息，5条则封号；每月可接收企业微信发送的11条群发消息 | 
| | **快捷消息** | 支持设置快捷回复 | 不支持 | 设置群聊快捷消息卡片 | 
| | **自动回复** | 支持设置关键字自动回复 | 不支持 | 支持设置关键字自动回复及加入群欢迎语 | 
| | **朋友圈** | 不支持 | 图片、视频、文字 | 朋友圈 | 
| | **客户群自动回复及触达** | 不支持 | 不支持 | 可以设置客户群发消息的触达：朋友圈，群内信息 | 
| **营销转化** | **个人主页** | 不支持 | 不支持 | 支持富文本，支持图片，展示更多 | 
| | **企业介绍** | 不支持 | 不支持 | 支持上传图片或图片文字说明，并且设置产品展示 | 
| | **商城** | 支持 | 不支持 | 可分享购买渠道入口，链接到商城 | 
| | **直播** | 不支持 | 微信视频号直播，可接入人群标签 | 在视频直播中发企业微信的活 | 
| **数据运营** | **客户列表** | 属于企业 | 属于个人，离职即失去 | 属于企业，离职可分配记录 | 
| | **数据权限** | 不支持 | 支持普通和迁移，不支持数据营销 | 支持普通和文字聊天永久不消失 |
