# 一、活动目的

本次社群活动的需要建立 32 家超市连锁的线上社群体系，同时通过基础种子用户进开展发发展的用户进入社群。

# 二、目标人群

+   - 目标人群：县城超市的用户，年龄 30-45 岁之间，女性用户为主
- 用户在县城居住并且一般在超市附近。
- 习惯每周或每隔几天到超市来。
- 喜欢看超市是不是有优惠活动并线下购买商品。
- 会使用微信进行基础操作

# 三、活动主题

夏日狂欢节老顾客大回馈

# 四、活动时间

+   时间：21 号-23 号
14 号 打印海报张贴门店
15 号 培训导购，海报领取
15 号 门店陈列
20 号 晚上导购开始朋友圈
21-23 日为活动裂变成交时间
