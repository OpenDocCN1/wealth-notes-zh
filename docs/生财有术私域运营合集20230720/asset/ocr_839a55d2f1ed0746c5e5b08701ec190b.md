③再在圈里加上一些出其不意的灵感性内容，比如你的生活故事、你的突发奇想、你看到一个新闻引发的观点，让你的圈整体灵活生动起来。

# 逻辑线

**【主线剧情】**
构成朋友圈的主要内容
支撑起一个有可读性的朋友圈

# 灵动性内容

**【支线剧情】**
增加朋友圈的丰富度
诸如：你的生活故事、突发奇想

![](bbox=[0.47, 0.15, 0.81, 0.43])

所以大家会发现，逻辑线发圈，其实是你需要先找到一根线，去把一个或者多个事件串联起来，按照一定的逻辑呈现，就像电视剧的展开一样。

电视剧也有主线剧情和支线剧情，所以我们发圈也是，不能只发主线，也要有些其他的生活穿插，也就是在串联之后，再加一些灵动性内容的点缀，就会让你的圈变得多彩。

在之前的生财精华帖里，我曾经给大家讲过连续剧式发圈，大家发现是不是有点像，这里为了避免大家概念混淆，要给大家讲一讲区别。

（精华帖指路大家也可以看一下这篇文章，学习下自动成交型朋友圈。）

连续剧式发圈是什么呢？是可以在朋友圈里进行一个连续剧式的内容连载，比如记录一个顾客来你这里购买产品的过程，你就可以分几个时间段儿去分别的记录：

第一条是晒成交，是这个顾客小A他成交了 products；半个月后呢，再说小A收到了 products，试用后觉得效果不错，来给了你一个反馈；再过一个月之后，又来复购；再过两个月，觉得产品不错而且还能赚钱，于是来做你的代理。

大家发现了，这个连续剧式发圈，它是跳跃性的，可能遍布在【不同时间节点】的朋友圈里，但是是从时间的长河上看，它是一个连贯的剧情。这就和我们去看视频平台的电视剧，它可能是每周末固定更新新的剧集一样。
