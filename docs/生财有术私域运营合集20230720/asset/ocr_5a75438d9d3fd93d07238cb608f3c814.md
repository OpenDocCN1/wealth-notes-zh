# 如何搭建社群

# 1. 门店私域（餐饮、产康、超市连锁）

拓客是很多行业的干货需求，因为拓客相对来说短平快有效果，对门店来说就是刚需品，因此私域有一大帮操盘手都是以门店拓客作为切入点、一直在讲发售的。那么门店拓客的类型也很多，并不只有一种，所以下面介绍三种有代表性的。

# 1）餐饮

关键词：到店需求、转介绍、品牌口碑效应、KOL筛选
