最后一部分是临门一脚，有些人也会卡在这里成交不了，明明客户的问题都帮他解决了，为什么她还不付款呢？我一般会用3个方法搞定：

+   - 利用限时福利或者赠品

+   - 提供零风险承诺

+   - 清晰明确的下单指令

# # 参考话术

您可以放心拍，如果资料不好，三天内都可以找我退款，不辜负你的信任嘛～（零风险承诺）

你直接通过链接报名，报名成功后把支付截图发给我，我来邀请你进网盘群。（清晰的指令）
