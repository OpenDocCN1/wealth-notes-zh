# 2.5 有了自己爆品后，再去做选品拓展和领域延伸

刚开始，我的美食团定位只做云南美食，也做出过自己团里的几个小爆品，除了包装豆腐，还有咖啡、鲜花饼、西双版纳玉米、云南米线……分别都自己开团卖了一两百单。

但因为我一个人又做供应链开团、又要做营销，实在忙不过来，而当时做云南美食供应链的大团长并不多，能帮卖的团很少，于是我决定做选品拓展和领域延伸，我把定位从云南美食拓展到了全国特色美食。

![](bbox=[0.38, 0.425, 0.62, 0.685])

我那会儿纠结过到底要不要做定位的延展，后来想明白了，在了自己私域定位和爆品后，再去做延展其实是不突兀的。只要讲清楚你为什么要做、有什么立场去做就可以了。

前面说，刚开始不要着急推太多品，要集中去推属于自己的爆品；而当有了爆品后，也不要怕去拓展选品和领域，大大方方做生意，就兢兢业业去挣钱。
