# 案例 4：连带性框设

你看很多人都会问你，你是想成功还是一定要成功，你会怎么回答？
一定要成功的话是现在行动还是今后行动？现在行动的话要方法还是不要方法？要方法的话是要先进的方法还是落后的方法？先进的方法是跟有成就的老师学来的还是自己摸索来的比较快？你们是要马上学了更快的成功还是痛苦的回去摸索？这就是一步一步把一个人框进来的。这就是连带性框设！这是一个心灵框设里面一个很重要的技巧。

# 破解式选择
