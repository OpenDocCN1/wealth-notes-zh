# 四大重要事實

我們先來談順勢交易的四大重要事實：

+   - 事實一：順勢交易是最安全的交易方式
- 事實二：趨勢帶動市場，是所有利潤的基礎
- 事實三：順勢交易人很可憐，因為 67% 的交易會虧損！
- 事實四：順勢交易有兩種方式
  - 突破交易
  - 折返交易
