# 模式邏輯

模擬器的邏輯很簡單。它根據你的資金管理策略和交易方法，去模擬交易。我使用一個亂數產生器，以決定一筆交易是獲利或虧損。如果你的方法有很高的準確率，模擬器產生的獲利交易會多於虧損交易；但是亂數產生器會決定獲利和虧損的順序。在一筆交易之後，模式會建構一條連續的淨值曲線，衡量任何賠償的深度。一旦從新近的淨值高點下滑的賠償到達你定義的賠償破產水準（例如50%），這個模式會停止，並且使用下列公式計算破產風險：

破產風險 = 自上次淨值高點以來的虧損交易筆數 / 自上次淨值高點以來的總交易筆數

請注意，這個模擬器會忽略最近一次淨值高點之前的所有交易。這是因為這個模擬器只對淨值高點和賠償破產水準之間的交易感興趣。這個模擬器想要知道在淨值高點之後，需要多長的時間，才會到達破產賠償水準，因為這將決定破產風險。

為了避免這個模式陷入無限的循環，如果淨值曲線達到2億美元，或者交易筆數達到1萬筆時，若還沒有達到預定的破產賠償水準，模擬器就會停止。模擬器假設，兩種情況之一都足以顯示，交易人已經"你已經躲開財務破產的惡運。
