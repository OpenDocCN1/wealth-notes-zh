# 》二擇一單（one cancels others；OCO）

允許交易人同時下兩張委託單，但顧問在其中一張委託單的附帶條件先觸發時，會只執行那張委託單。

例如，你對FTSE的分析顯示兩個相互衝突的情境：如果FTSE開低，它會立即下跌；如果FTSE開高並且勁揚10點，則可能顯著上漲；也就是說，一切取決於FTSE的開盤狀況。這時，不錯失任何一個交易機會的方法，就是下OCO委託單。如果在你的分析中，開盤走軟是指價格下跌到6,420，而開盤強勁是指價格漲到6,460，那麼你可以遞出如下所述的條件委託單：
