# 圖 8.20 固定百分率資金管理策略如何因應災難性虧損

如果只拿 1% 去冒險，則要 528 筆連續虧損的交易才會破產。大部分專業交易人設法拿低於 1% 的錢去冒險。如果冒險的百分率只占帳戶餘額的 0.5%，則需要連續虧損 1,058 筆交易，帳戶餘額才會成為零。

換個方式來說。採用固定風險時，將小額帳戶分成 20 個資金單位，這是交易人想要以低破產風險交易，應該嘗試的最小數字。使用固定百分率和將風險限制為 1%，將提供 528 個（遞減）資金單位。在發生一連串虧損時，有機會額外交易 508 個訊號，有助於提高固定百分率交易人的生存機會。
