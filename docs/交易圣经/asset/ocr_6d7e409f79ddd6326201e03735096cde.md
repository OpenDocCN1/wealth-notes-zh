# 表8.5 交易合約口數

| 金額風險 | 交易風險 | 交易合約口數 |  |
| --- | --- | 實際 | 取整數 |
| $667 | $800 | 0.8 | 0 |
| $667 | $350 | 1.9 | 1 |
| $667 | $265 | 2.5 | 2 |
| $667 | $200 | 3.335 | 3 |

必以無條件捨去法取整數。公式如下：

```
合約口數 = 金額風險 / 交易風險
```

如果個別交易風險是 200 美元，根據這個公式來計算，你將交易三口合約（$667 / $200）。假設固定風險為 667 美元，將交易的合約口數如表 8.5 所示。

現在，固定單位不同於固定風險的地方，在於金額風險並沒有維持固定。在帳戶餘額成長時，它會增加。表 8.6 顯示當帳戶餘額成長和單位數維持固定，金額風險如何增加。

圖 8.13 顯示，如何利用固定單位，快速累增合約。
