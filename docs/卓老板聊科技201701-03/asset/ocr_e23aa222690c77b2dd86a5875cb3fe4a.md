# 艾滋病感染的警示

艾滋病感染的警示

要点：
浙江省中医院艾滋病感染事件的来龙去脉；
淋巴细胞免疫疗法如何治疗习惯性流产？
中医在国际医学中的定位；
龙胆泻肝丸会导致肾衰竭。

# 知识清单：

—— 1 ——

# 浙江省中医院的5位艾滋病毒感染者

+   1. 浙江省卫计委对这5位艾滋病毒感染者的公告是，“一名技术人员违反‘一人一管一抛弃’操作规程，在操作中重复使用吸管造成交叉污染，导致部分治疗者感染艾滋病毒”。并没有提到是什么治疗、什么疾病。
2. 事故中的这家医院在院内开展了保胎、护胎服务，而这家医院并没有相关服务的牌照。这些服务的具体疗法是淋巴细胞免疫疗法，简称LIT，就是把丈夫血液中的淋巴细胞注射给妻子，以期可以增加怀孕概率。
3. 这些治疗者中有一个丈夫是同性恋者，实际上，他也是病毒携带者。这批患者60人都接受了取卵器，都是一针多用，现在已经有5人确诊，55人还需后期观察。
4. “一针多用”的背后是有人会把节省下来的医疗器械私下卖给黑市，或者是医院为了减少成本，在院内约定俗成，所以在中国出现一针多用并不罕见。
5. 这次事故中的取卵器采购价格1万元一只。

—— 2 ——

# 淋巴细胞免疫疗法怎么治疗习惯性流产？

+   1. 所有习惯性流产的孕妇中，大约有3%是和免疫系统异常有关的，孕妇的身体会把受精卵当作入侵者消灭掉，于是就流产了。
2. 最初的治疗想法是希望把父亲的免疫细胞注射给母亲，以期达到调整免疫的目的。但是这只是一个想法，人体免疫是非常复杂的功能，不是想当然就能有效果。
3. LIT疗法在80年代的美国就已经应用过，但是很多科研人员在质疑这种疗法。后续的十几年里，更多的机构做了验证，1999年《柳叶刀》上有一个最大规模的对LIT有效性的研究，结果证明，它的治疗效果弱于安慰剂。
4. 2002年，FDA最终决定禁止在美国开展LIT疗法。

# 浙江艾滋病事件的后果

+   1. 本次事故比魏则西事件更严重，因为魏则西本来就是癌症中晚期，但这次被感染的都是健康的准妈妈。
2. 这次的处理结果是院长、副院长、检验科主任、医务部主任、感染科科长都撤职，党内严重警告，然后是公安机关立案侦查，该负刑事责任的再负刑事责任。

# 中医只是「替代医学」的一种

+   1. 中医在世界范围内属于替代医学的一种，替代医学是一个和现代医学相对的概念，其中包含：芳香疗法、按摩疗法、膳食疗法、顺势疗法、冥想疗法、祈祷疗法、催眠疗法、维生素疗法、音乐疗法，还有印度草药、中国草药等。
2. 替代医学都是缺乏科学证据的疗法，大都源自人类古代医学。在很多发达国家，替代医学的医师没有执照，也没有处方权。
3. 目前，中药没有一款通过了FDA的认证，而这项认证是目前世界上对药品审核最严的标准。中药在国内不需要清楚不良反应，只需要填“尚不明确”即可。

—— 5 ——

# 西药的有害，和中药的有害有什么不同？

+   1. 西药因为安全性问题退市，在这种药品退市之前，是不存在它不安全的确凿证据的。凡是退市的药物也都列出了详细信息。
2. 中药的有害是缺乏研究的，不良反应的空缺不是没有副作用，而是因为从来没做过这方面研究。而且中国药监部门袒护中药企业，甚至对大量导致肾衰竭的中药也不做任何监管，直到新华社的报道出现，才有行动。

—— 6 ——

# 龙胆泻肝丸事件

+   1. 1992年，比利时发现多名妇女患了急性肾衰竭，她们的通性是都在发病前吃了香港进口的一种减肥中药产品。这种药在1993年就确认了会导致肾衰竭，原因是药里的马兜铃酸诱发了肾脏基因突变，这种伤害是积累性的，不存在安全剂量，还对肝脏致癌作用。
2. 到了1998年，已经出现了很多关于龙胆泻肝丸危害的新闻报道，多家医院（朝阳医院、中日友好医院）也都向药监局报告了问题，但药监局还是没有行动。
3. 2002年，药监局组织了一次关于龙胆泻肝丸的内部会议，内容不得而知，但此后，2002年底，同仁堂的龙胆泻肝丸就不再使用关木通这种含有马兜铃酸的植物了。可除了这一款药外，市场上其他龙胆泻肝丸依然在使用含有马兜铃酸的药材。
4. 直到2003年新华社刊登了一篇《“龙胆泻肝丸”——“清火良药”还是致病“根源”》，才最终推动药监局把含有马兜铃酸的成分禁止，但这时距离马兜铃酸被证明有害已经过去了10年。只按同仁堂龙胆泻肝丸的销量推算，就已经造成大约10万人患了肾衰竭和尿毒症。
