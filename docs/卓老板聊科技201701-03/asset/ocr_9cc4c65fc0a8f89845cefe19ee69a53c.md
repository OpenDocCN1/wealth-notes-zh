# 中药在海外的情况

1.在美国，从事替代医学的人没有处方权，替代医学药物也大部分不能纳入医保，中药只能以膳食补充剂注册，销售中也不能包含任何暗示疗效的语句。美国每年膳食补充剂的销售额是64亿美元，每年药物销售额是4000亿美元，如果膳食补充剂中有1/5是中药，那么中药在美国医疗体系中的比重是3‰。

2.在英国没有中医执照。中药从前只能当食品进口，但后来因为来自中国和印度的草药经常发生食品中毒事件，于是欧盟从2011年起严控草药进入。凡进入，必须通过《草药注册方案》的认证才可以，到目前为止，没有一款中药通过。

3.在台湾是存在医师和中医师的，但他们从上学起就是分开的，毕业时只能从中医和现代医学中选一个执业，选择中医的占比不到10%，台湾药品销量里中药占比4%。

4.在日本，从1868年起就废除了中医，中医在日本没有执业资格，但是他们保留了100多种“汉方”，汉方占日本药品销量不到2%。

5.在韩国的中医最早叫汉医，后来由于大韩民族的自豪感改成了韩医，但韩医不许开西药，医师不许开韩药。韩药占药品销售的4%，主要是老年人消费。

6.在中国，中医受到政策保护，中药占药品销量达50%。政策规定了中医师、中医科要以一定比例存在，中医师可以开西药，中药中常常混有西药的有效成分。
