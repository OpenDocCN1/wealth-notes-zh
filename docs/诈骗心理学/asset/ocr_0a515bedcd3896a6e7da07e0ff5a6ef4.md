# 「催眠術應當被毀滅」的兩大本意

「催眠師應當被毀滅」、「根絶催眠術一詞」等等，雖然我不斷這樣訴說，但我真正想要表達的是，「應該停止催眠禿的現有形式」、「不需要用到催眠術這樣的說法」。

拘泥於催眠術的形式，最後肯定會碰到困難。

「他真的被我催眠了嗎？不會只是配合演出裝出來的吧？」不禁開始懷疑自己。

手掌握不開、無法從椅子上站起來等等，若有過親身經歷那還好，但許多人是未曾體驗過催眠術，初次想要嘗試被催眠的感覺。
