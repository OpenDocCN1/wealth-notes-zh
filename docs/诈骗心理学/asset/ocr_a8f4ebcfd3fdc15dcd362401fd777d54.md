# 完全推卸責任的說話技巧

然而，魔術師得在了解手法、把戲的前提下，成為「昏睡類型」。專業的魔術師果必須具備天才般的自我暗示能力。

稍微接觸魔術之後，會學到宛若超能力般的技巧「魔術師選擇」。

此技巧是表演者如同預期演出，卻讓觀眾覺得是以自己的意志選擇。

假設你手邊有紅色紙牌與藍色紙牌，想要讓對方選擇紅色時，說：「紅色和藍色，請選擇一種顏色。」

如果對方選擇紅色，「你選了紅色。」繼續表演下去；如果對方選擇藍色，「那麼，我也選擇藍色吧。難得有機會一起上台遊戲，你不如選紅色吧。」運用言語上的詭計，讓演出如同預期進行或者得到相同的結局。
