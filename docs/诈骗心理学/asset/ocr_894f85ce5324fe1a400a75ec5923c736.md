# 詐騙的第一步

前面多次提到「建立投契關係」，但能自然接受這個概念的人，或許之前有讀過心理學的文獻。

投契關係是指，心理學用語上的「相互信賴的關係」。換句話說，建立投契關係相當於雙方完全信賴對方，此狀態被認為是所有治療與療法的必要前提。

當然，「騙子」才不会考慮相互信賴。「這傢伙，完全相信我了，好極了。」騙子只會打歪腦筋。

說個冷知識，第一位利用投契關係的人，是被稱為催眠師始祖的法國茲安東•梅斯梅爾（Franz Anton Mesmer）。

梅斯梅爾醫生認為每個人身上都具有「動物磁力（Animal Magnetism）」，提倡以手部運動控制磁力，整頓磁力流動來達到治療的效果。

患者在治療過程中會發生痙攣或者昏厥，他稱這樣的症狀為「感應到動物磁力的狀態」，亦即「建立投契關係的狀態」。
