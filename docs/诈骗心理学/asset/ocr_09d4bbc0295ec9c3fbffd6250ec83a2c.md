# 嚴禁濫用！催眠男性這樣說

那麼，面對男性一開始該怎麼說？
基本上是相同的思維。

「溫柔體貼的男性容易被催眠。」就算這麼開場，通常不會真的有人說：
「我被催眠了。看來我是溫柔體貼的男性。」因為這樣太過於厚臉皮。
目的是刺激男性的悲劇英雄主義，「憂鬱男子傾向被催眠」這樣開場就可以。
如果想要保守一點，那就說成「潛在的憂鬱男子……」吧。
不過硬要說，男性比較傾向慵懶瘋狂。常用開場白的例子，感覺像是這樣：

「催眠術說穿了就是對方的想像力，喜歡妄想的人比較容易被催眠，這類型
的人認為自己不行時，就真的事事不順；認為自己可以時，就真的無所不能，是
不論結果好壞都往前衝的人。這樣的人可能時常感到憂鬱，潛在地抱持著自殺願
望。』
