# 大户老师，我有个法

(提问)长颈鹿：大户老师，我有个法律的问题请教：中介在房东没有把房源信息给他的情况下，私自介绍房源给我们，后面我们绕过中介自己和房东签了。现在中介找我们闹，要中介费。这个中介费我们该出吗？

回答：先批评你们一下。 既然总公司不准走中介，说明你们一开始内心知道，无法给中介付费。 那么就应该一切靠自己找，不应该去撩中介。毕竟如果100%确定不能付中介费的话，再去找中介，就等于白占人家劳动力的便宜。干嘛要白占别人便宜呢。虽然这个世界充满了类似的行为。 比如明知准备网上买东西，却偏偏跑去实体店看样品，白试一次。 比如去超市试吃一圈，吃饱了就走人…… 等等等等。 如果我们看着这种事情，觉得不合理，最应该做的就是约束好自己。已所不欲，勿施于人。如果你是商家，不愿意看到这样的客户，那么你就不要当这样的客户。 ——————— 其次，是关于这处争议房源的问题时，你们跟中介交流的时候，也不够坦诚。 本来事情是站在你们这一边的： 因为第1：你们先知道了这个房源， 因为第2：这个房东的联系电话是公开的，等于所有人都可以去联系，并不是你们私下里偷偷找房东跳过了中介。 所以既然事理是站在你们这边的，就应该坦诚相告。 而不是藏着掖着。 你们有几次机会： 第1次是，当得知同事已经先知道这处房源的时候，就应该立刻把这个信息披露出来。 （哪怕是当时看房时不知道，事后回到公司跟同事一汇合才知道，也应该把这个消息告诉对方。） 第2次是，看到这处房子上挂着房东电话的时候，就应该明确跟中介说：“这种公开的房源，你们就不要介绍给我们了，我们公司有好几组人在扫街，不用你们介绍也能看到这里，用你们中介啥事。
