# # 【帖子编号0242

珍大户：【帖子编号0242】《说下小城市》

看到楼下宜宾买房的帖子，我又想唠叨几句。

提问：你所在的城市，现在直径有多大？

这是一个很直观的认识，想要迅速建立这个认识，可以直接打开卫星图，调到同样比例尺下（比如我截图的**20公里**），目测下水泥颜色的建成区面积，比照比例尺估算一下直径。

一线城市，北上广深的数量级是：建成区直径在50公里的数量级上。

二线城市，直径20-30公里数量级。

再往下，能达到10公里的，基本算是比较大的地级市了。

再往下，直径5公里的，都是小城市。

房价能不能涨，跟城市大小息息相关。
