# 老师，我大学专业是

(提问)开心：老师，我大学专业是会计，毕业后也一直再做财务工作，我现在已经32岁了，想考法律硕士研究生，想上学再沉淀一下。我目前状况：老家河北，有省会房子一套，贷款一个月3700，无车，打算要孩子，老公在北京工作，他工作相对压力小，挣钱少。我工作压力大，相比较挣得可以。我现在纠结的是，考研的机会成本太大，如果非全日制的工作压力也大，又怕到时候无法兼顾，而且现在非全日制的考试难度和全日制的是一样的，但认可度却低，我一直纠结该如何选择，是选择全日制还是非全?是选择好的学校还是选择河北学校?还是直接放弃考研的想法踏踏实实的工作考注会？我也一直在考虑全日制毕业后可以带来的切实利益，毕竟年纪也不小了。望老师指点。

2019-11-04

回答：【会计读硕士】里面有几个问题，先从容易回答的说： 1，考好学校还是河北的学校？一定要先考好学校。因为你的目的是为了工作，从工作角度来讲，好学校的认可度更高，考老家的学校意义并不是很大。 2，全日制还是非全日制？ 全日制是年轻人最好的选择，最好是刚毕业没几年时选择全日制，而对三十几岁的人来说成本太高了。 非全日制的优势是你的职业生涯不会中断。毕竟对三十岁的人来说，学历不是找工作时唯一被考量的因素，工作经验也很重要。 另外，如果是好学校的话，一定程度上是可以弥补非全日制的认可度问题。但如果是不好的学校，再叠加非全日制，怕是很难看了…… --------------- 你这个问题里，最难解的问题是你没问到的部分：为什么要考法律硕士？ 法学领域有两种硕士：一个是法律硕士，一个法学硕士。法学硕士是给法学本科的人深造的，法律硕士是给外行人半路转型的。 （不像其他专业，你读个xx硕士，跟别人本硕一起的xx硕士就是一样 的东西） 所以含金量来说，法律硕士的含金量是被低估
