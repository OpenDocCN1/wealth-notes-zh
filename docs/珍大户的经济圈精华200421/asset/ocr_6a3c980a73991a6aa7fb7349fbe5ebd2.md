# 珍老师您好，想听下

(提问)小雪：珍老师您好，想听下您的意见，最近的抖音蓝v号很多，有必须去申请吗？现在拍抖音还有钱挣吗？

2019-07-07

回答： 【帖子编号0314】 《再说抖音》 这几天新来的朋友比较多。大家可以尝试使用右上角的搜索功能，查看之前积淀的内容。如果自己想拍视频，我不建议申请蓝v，原因见旧帖我的账号最近流量又上来了，比较喜悦，一直在分析原因，经推断可能有两种： 1，我自己猜测的原因：经过前期直播，大家力撑，外加那条支付宝广告的作用，给抖大爷贡献银子了，于是抖大爷把我账号重要程度调高了。 2，我的抖音经济人猜测，是因为暑假到了的原因。因为寒暑假是日活跃用户数比较高的，抖音的算法是数据到了一定基数，就扩大推荐的池子。所以日活跃用户基数多的时候，就会贡献数据量，更容易数据好看一些。 但还有一种概率比较低的推测，就是抖音算法改变了……（这条因为数据量不足，无法确认）我之前发视频，能明显感觉到视频有几个关口。 播放量到2万时，视频会明显停下来，等个10分钟以后才继续播放（我猜测这个时候开始，后台做数据统计，根据数据决定是否投放下一波流量） 第2波流量的播放量在10万，一些视频播放到9.7万会停。 第3波流量播放在20万。我的大部分视频都播放量停留在18点几万到21万之间。 第4波流量在50万以内。我只有少数几个视频播放量到了四十八九万的样子（包括那个支付宝的广告） 第5波流量在100万以内，我发了近200个视频，超过这个数的可能只有两三个。之所以确定出100万是个关口，是因为我跟大家讲过，之前f先生测试抖音，当时另一个号能反复测试出这个数据，所以比较确认。但到昨天那个杠别人的视频突然不一样了，我时不时的打开手机，发现播放量在2万，10万，20万，50万，100万的关口都没有停顿，一口气播过去了。而且速度是匀速的，跟以前一批一批给流量
