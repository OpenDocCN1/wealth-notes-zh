# 珍姐，是去北上广好

(提问)超大帅: 珍姐，是去北上广好，还是去长沙，杭州等新一线发展好呢？
是搞高考考前培训好呢？还是少儿美术好呢？想创业，不想打一辈子工。

2019-03-20

回答：目前一定要往各个新一线、二线、省会城市去，不要留恋北上广。 过年放假期间跟北京一个教育集团的高管有交流，他们目前正在加速布局各个二线城市，还举了一个长沙门店的例子 说每个门店前期投入大概100万左右就能开起来了，年营业额能打到一千万，利润20%左右，就是两百万。
不过他们是图上市的玩法，做规模，做增速，然后上市这种。 但依然能看出来，一是新一线二线城市的潜力，二是行业利润率，都是很好的。 至于考前培训还是美术。建议考前培训，这个领域目前仍未饱和。大家要进入的话，就迅速抢占市场。 细节分析上，之前开过一个帖子，有说过，各个培训项目是属于“第一轮竞争”还是第二、第三轮竞争，分别属于分数竞争、素质竞争、家庭实力竞争 一线城市已经晋升到二轮三轮了，二线城市还是第一轮，所以去二线城市首选考试培训。 复习，(30赞)
