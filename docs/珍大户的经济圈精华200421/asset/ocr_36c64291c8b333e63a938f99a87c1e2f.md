# 珍姐好，我老公是银

(提问)sophia：珍姐好，我老公是银行的一名对公客户经理31岁，现在想转行做小微中心客户经理。原单位领导挽留我老公继续做对公客户经理，说以后有机会让他做中层领导。您如何看待小微信贷业务的发展？我老公该换岗吗？2019-05-06

回答：【帖子编号0267】完全错误的选择。所有的客户经理，岗位性质上都是销售。（请大家别对销售这个词带有色眼镜，我在阐述销售的性质时，并不带有褒贬含义。金融系统中，很多金融产品对接到银行系统时，作为“基层销售代表”参加会议的，基本都是各个支行的行长。另外之前讲过“投行是什么”的视频，里面的承销岗是直接销售岗位，甚至整个投行在金融业的定义都是“卖方”、sellside，全公司的定位就是销售。所以，不带有色眼镜地说下，带有销售性质的岗位，选择的原则）我在0015贴里写了关于销售的几个原则：再扩展一下，应该说有以下几条：能做对公销售的，不要做对个人的销售。能做大客户销售的，绝不做散户销售。能做高单价销售的，不做低单价产品。能做高利润率产品销售的，不做低利润率产品。因为上面每一项，都代表着更高的门槛。门槛越高越可能维持住高利润，越可能给你发高薪。门槛越低，竞争越激烈，替换性越高，越不可能有高收入。随便举个例子，同样是销售，一边是对散户，一边是对大客户。对散户的，可能招几百个电话销售，每天打满多少通电话。完不成随时滚蛋。骚扰到客户了？无所谓。对大客户的，哪个公司敢随随便便三天两头换销售？同时派三五个人，一起跟进一家大客户搞竞争，然后弱者淘汰？时不时跟大客户打招呼，说我们公司客户经理换人了，请你更新一下联系方式？不可能的。同是工作很多年的人，只见过对公销售拿着大客户资源去另起炉灶了，没见过对私销售另起炉灶的。所以看见提问中的选择方向……除非你期望的目标
