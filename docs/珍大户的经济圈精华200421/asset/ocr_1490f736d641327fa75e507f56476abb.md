# 珍姐，我95年的，

(提问)David：珍姐，我95年的，现在985机械硕士，今年正在找工作，但是我本科比较差，是个二本，考研考到了985的硕士。家是河北的，家庭条件比较差，父母是农民。现在找工作有两个选择，一是去北京的航天所，航天所一般要求至少双211，然后现在家里有一点关系可以去一个差点的航天所，给户口，工资不高，年薪13w-15w吧。但是北京房价很高，家里又没条件，我觉得在北京要买房可能要花几十年，但是家里觉得航天院是央企，肯定会给员工解决住房的(我不太信...)。二是不去北京，去徐工，潍柴，英特尔大连之类的机械企业，虽然工资也不高(12-15w，机械近年来就这个价)，但是在徐州，潍坊，大连的这些城市买房会轻松很多。现在不知道咋办

2019-09-24

回答：这个问题好难回答...... 我有朋友是部某的公务员。即爽又愁。 爽是因为： 1、未来能排队分到房子； 2、在分房子之前提供位置在四环、交通很方便的两室一厅的住房（极低租金）； 3、一日三餐有单位食堂解决，味道卫生营养都兼顾了； 4、北京户口解决了； 愁是因为： 1、每月工资确实不高，大几千块。虽然基本没有太多花销，但想富也是没门的； 2、户口虽然解决了，但是不是在东西城海淀这种教育资源很好的区，而是在郊区（我也记不清了，可能是大兴或者房山之类的），以后孩子上学又是个问题。如果没有学区房，就意味着只能在户口所在区入学，就等同于注定上不了好大学。然而靠他们的工资想买学区房，那是根本没可能的，一想到以后孩子读书怎么办，我朋友就犯愁。 3、包括他在内的周围所有同事都是名校高学历（北京交复人大央财硕士博士这种），然而目睹着身边很多人开始渐渐的被环境所变化，言谈气质越来越像菜场大妈，工作越来越混日子，能力越来越退化，这个朋友就开始有很深的危机感。
