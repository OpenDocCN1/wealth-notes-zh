# 珍老大，看新闻说：

(提问)唐小爰:珍老大，看新闻说：中国人民银行在香港发行央行票据。能否科普一下什么是央行票据，在香港发行的目的与实际意义。谢谢 2018-09-22

回答： 【帖子编号0092】这个问题涉两个知识点： 1：央票是什么？央行用这个东西来做什么用？ 2：中国的汇率，以及到岸人民币和离岸人民币问题。先说1： 央行管货币发行（俗称印钱的），但其实还包括货币回收（可以理解为货币回收）。 央行一个最大的职能就是，分析这个国家，到底需要多少货币？然后保证社会上一直有应有的货币量，货币少了就多印点钱，货币多了就回收点钱。 这部分钱，叫“基础货币投放量”。一般是稳定的变化，没有太大的短期波动，不能今天少明天多。 不妨把它理解为，平静的水面。平稳的像镜子一样，没有波浪。 （这是不担负宏观管理职责的央行，所谓的被动的、中立的职能，只要做好这个最基准的职责就好了。） 然而除了最基本功能之外，央行还有一些进阶的能力，就是做宏观调控： 通过压低利率——>促进企业借钱扩大生产——>从而促进社会的经济增长。 通过提升利率——> 压抑企业借钱的冲动——>使经济过热时稍微熄火一些。

（我在之前公众号的文章里，有对这种逻辑的梳理，可以参考一下）你看央行对宏观经济的调控，其实只有一个针对的对象，就是利率。（延伸阅读：（可读可不读） 正是因为针对对象太单一，央行会在特殊时期遇到两难问题，像是受夹板气一样。特殊时期特指滞涨。 滞涨期：经济停滞+通货膨胀。 一般单纯经济停滞是通过降低利率刺激gdp的增长，单纯通货膨胀的时候，通过提升利率，压低通货膨胀率。然而到了滞涨期，无论利率怎么变化都是错的，这就是央行的两难。） 而央行如何使利率变动？ 其实本质上还是看，市场上钱多还是钱少。钱多了，银行求着你贷款，自然利率低。市
