# 最近太忙，半个多月

沐宁Shine：最近太忙，半个多月没进圈儿看看。冒个泡，想问问大家谁知道年收入200万（月薪、奖金、股票等等都算一起200）在金融圈儿算什么水平。2019-05-19(11赞)

评论区：

+   - 李777：算上水平啊，想知道怎么能达到年入200

珍大户：属于少数岗位的少数人才能达到的区间。一般月薪上，基本到七八万就封顶了，每月薪过十万的很少。至于股票、期权什么的，这些都是企业才搞的，金融行业里也没怎么见过给分股票的。或者你说的股票，是自己炒股的收入？这种就发没打断了，大家都默认不能互相打听，因为里很容易就互相推算出来有多少资产，钱多的人怕追债或者怕举报（很多人是证券口的，属于受禁止炒股的），钱少的人怕被人知道了丢人，所以大家默默都不交流这个。所以能达到200万的，基本都是靠奖金。能有大额奖金的岗位不多。投行（承销/承股票的发信托的都算）的承揽/承销岗位（承销可能性更高，业绩说话），承揽岗位一般都没有这么多钱。早几年的债券交易岗（我很多年前的同事，一年工资在上海买静安300万的房子了）。证券研究所的头牌（钱的来源是，基金公司冲着这人的研究报告，把股票交易走这家证券公司的通道，于是带给他们手续费，这种收入会分一部分给研究所，研究所的头牌自然拿大头了。）剩下的，管的规模几十亿别的基金经理基本都过这个数（规模低于，就难说了，尤其是规模不过亿的话属于快清盘的，基金公司都是亏损的，经理收入也会很难，过50都难）。总之，大部分能达到这个水平的，收入来源跟项目相关的比较多，销售性质相关的比较多。以上我说的都是正规路径。灰色的打着金融旗号的没法一概而论。见过赚快钱的，10年前后搞各种山寨交易所（什么煤炭/邮票/艺术品/金属交易的），12年前后搞“石油大宗商品”（其实还是非法交易所），还有什么云南的什么稀有金属交易所，15年的股票配资，16年之后的各种小贷，还有外汇的（外汇是铁打的市场，流水的外汇公司，一波接一波的骗局），17年的各种币。每一波，都有很多人年入百万元以上的。但是我相信这种是很难长久的。Counter：我想知道明年两年还有什么缺钱项目吗？
