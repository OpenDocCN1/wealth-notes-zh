# 珍大户好！现在有很

(提问)匿名用户：珍大户好！现在有很多类似"弹个车""神州买买车"的汽车金融公司，能不能帮忙分析下他们的盈利模式和商业弊端。而且很多公司都在招加盟商和拓展人员，请问这样的生意可以做吗？谢谢谢谢！

2018-10-28

回答：【帖子编号0150】这行业也不知道怎么就突然爆发起来的，上个月逛街一连见到两家，还挨着的。然后我也研究了一下。本质就是吃利息。但贷款利率比其他渠道高很多。所以目标群体是次级客户。就是那些资质更差 的客户，这些客户，以下传统渠道走不通：1，又走不了银行的商业消费贷款，又走不了信用卡买车分期，甚至可能根本没有信用卡。（银行爱看工作证明和工资流水，说明这部分人工作不好，甚至可能没有工作）2，4s的汽车金融公司不给办贷款。（几大车厂都有自己的金融公司，只要首付30%以上，都能给办下贷款。说明这部分人存款付不起三成首付）所以属于资产存量也不好，资产流量也不好的次级客户。可能是为了面子炫耀原因，愿意接受高额的利息，去买个车（我看了广告，他们分期的车型好像也都是十几万的入门车）那么这个商业模式的风险，实际上就是客户不良率，本身就是次级客户，故意跑路躲着你怎么办？不跑路但就是不还钱怎么办？车子醉驾撞坏了，保险还不理赔怎么办？不知道他们加盟是什么模式，出钱的话要承担多少比例的资金风险？总公司负责催债吗？如果不负责，是不是自己先要想办法找个讨债团队？风险其实可以参考，前些年很火爆的汽车贷款公司（拿车抵押办贷款），后来倒了一批，基本是被烂债给逼破产的。
