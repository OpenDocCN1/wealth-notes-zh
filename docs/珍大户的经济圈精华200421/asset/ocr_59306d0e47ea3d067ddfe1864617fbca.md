# 老师，您好！基本情

(提问)匿名用户：老师，您好！基本情况:本人80后，运营着一家小家电工厂，传统的出口型生产制造行业，市场在欧美。工厂第五年，一直租场地生产，大约年20-30%复合增长，现年产值1.2亿，但因为一些策略和决策失误导致年利润只在300-500万，并在未来2年不会大幅提高。现场地不够用，面临的问题是额外租用五千平方厂房，年租金120万。购买厂房五千平方约2000万,每年本金加利息差不多两百多万，压力会比较大。我们在佛山市顺德区，请问老师这种情况是否合适咬咬牙买个厂房，厂房价格这5年差不多贵了一倍，总感觉现在不买，赚钱的速度也跟不上厂房的涨速，特别是现在顺德三旧改造把很多厂都往新工业园去赶，有点供不应求的感觉。

2019-03-05

回答：我比较倾向于建议买下厂房。（隐含前提条件：要买的厂房不存在产权问题、包含地皮、剩余使用年限还比较长） ____________ 但是仍然有一些信息需要你考虑。买厂房的风险，主要是未来生意可持续性的问题（怕未来生意不好，但还本付息是刚性的，压力就会很大。但如果租厂房，就会容易退出）。租厂房的风险，主要是怕运营场地出问题（怕未来生意太好，一堆人跟你抢厂房，租金大幅上涨，从而吞掉你们业务增长带来的红利。更甚的，因为环保或者用地规划问题，导致你们需要搬迁，明明运营还好的，却被迫中断，损失就很心痛了。）租与买之间，120万与200万，每年的压力会大一些，但仍属于可承受。况且一种是纯成本，付钱后随着使用就等于消费了，另一种算是资本投入，账面上有厂房和地存留。所以最终，要考虑的就是这个项目的长远情况，五年后，十年后会怎么样，这其实也就是你目前无法取舍的内心隐忧。 ____________ 如果只看提问中提到的年复合增长率来看，我会认为你们的项目前景仍然比较
