# 大公国际信资被处罚

(提问)咖啡: 大公国际信资被处罚，即将要去大公任职，想问这个公司是否有发展前景

2019-03-25

回答： 【帖子编号0245】 这个公司是很有“钱景”的，但前景与你们无关。原因不是跟被处罚无关，主要是这个行业本身存在一些问题。我默认你是做大公里面的“核心”职位（这个引号的意思，你看后面）就是信用分析师。与大公一个级别的评级公司，之前就五家，中诚信、联合资信等等，后面又增加了一两家，东方金城什么的，现在貌似是有7家了。这七家，有几个问题： 一是壳资源。别的公司想做评级，监管机构首先不认，想要资本市场融资，必须现有评级。这么听起来似乎评级机构很占优势的。然而，第二点就是，收费标准都是统一的（我不是行业内人，不知道这是行业协会定的，还是监管机构定。总之都是评完一单，25万还是30万，大概就是这个标准的收费。）所以评级评的有“多好”是没用的，没人会给你市场化的奖励。评一个项目，花4周还是花2周，没人在意，反正价格都是一样的。第三点就是，好公司不能涨价，坏公司不能降价，那么如何抢客户呢。靠卖评级。如果公司资质介于aa-和aa之间，松一点还是严一点？谁严谁吃亏，松的才能抢得到客户。渐渐的，市场上评级越来越松，那么继续把aa的往aa+上输送。（一个历史统计，评级公司每年上调评级数百次，而下调评级只有十几二十次……可以看出这种手松的迹象。 而这种方式之所以能够奏效，是因为评级结果需要违约数据检验，而国内其实是没有那么多违约数据供检验的。 就像如果没有高考的检验，那么各个老师都会称自己是名师，然后送出去超多的三好学生名额当人情。）第四点，公司每单收入固定，靠什么盈利？ 一方面，壳资源是有用的，每年进资本市场融资的企业越来越多，虽然一单25万，但是单数越来越多，盘子在变大。另一方面，其实就
