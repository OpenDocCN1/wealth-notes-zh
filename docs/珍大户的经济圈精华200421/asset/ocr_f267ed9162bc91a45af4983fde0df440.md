# 珍姐，您好！我是第

(提问)小陶：珍姐，您好！我是第一次提问，马上要过年了，关于什么时候买猪肉我和媳妇有一点小分歧，所以想问问您！

我的观点：目前本地猪肉（湖北襄阳）是37 排骨33 鸡鸭13 鹅10 鱼稳定在6块，过年买猪肉是刚需，我认为现在就买！年前猪肉必定大涨！就算政府处政策干预市场，最多也是稳定在现在的价格！想掉价可能性太小！

媳妇的观点：等！掉价再买！（我之前给她讲过国家进口多上猪肉供应市场的新闻，她是铁了心了）

所以我想问，年前猪肉是否有掉价的可能呢？

回答：好久没说话了，借这个帖子补充一下： 我刚才又看了一下最新的数据，10月数据还没出来，只能看到九月份的，九月的母猪和小猪数量（生猪存栏）还是在减少的。9月小猪1.9亿头。2018年基本是3点几亿头。 这减少的1亿头猪，靠进口根本是杯水车薪。———————————————再详细一点说：小猪6个月后出栏，所以小猪数据就是6个月后价格的直观反应。 2019年9月1.9亿头，对应着明年3月的猪价…… 2019年5月2.4亿头，对应的就是现在，11月的猪价。 2019年1月3亿头，对应的是6月份的猪价。 2018年6月3.3亿头，对应的是2019年1月的猪价。 所以这么看，应该就心里有点数了吧。——————————————— 进口猪肉的数据我没查。大家如果有心的话，可以看一下新闻，预计进口多少万吨？ 我再给一组对比数据：咱们国家每年消费猪肉约5500万吨，每天15万吨。大家可以搜下，进口猪肉能进口多少吨吧(37赞)
