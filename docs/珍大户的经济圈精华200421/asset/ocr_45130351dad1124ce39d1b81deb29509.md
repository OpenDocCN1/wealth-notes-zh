# 最近在做服装批发，

(提问)JC：最近在做服装批发，想在家乡小县城陇西自己开一家做韩版中高端女装的小店，这种小生意需要注意哪些？2018-11-24

回答： 【帖子编号0178】《卖产品or卖服务》 有一个关于商铺的回答，建议你搜一下。里面有写被电商颠覆了哪些行业。 目前个人的（非品牌直营）的服装店，不建议做。属于已经过气的行业，尽量不要在这上面投入。 能被互联网颠覆的行业，一般都是属于通过互联网销售，能够降低流通成本的。 而服装销售渠道的变更，正是经济领域“成本”降低，这个概念的非常好的例子。 我们不妨梳理一下： 第一轮： 在电商前时代，买衣服是要去服装店的。商场卖的贵，个人服装店卖的便宜，不管什么价位档次，都有自己的顾客群体，都有自己的生存空间。 第二轮： 电商出现，成本压低。 举例来说，实体店服装店，展示品类不可能有网店多（否则营业面积要增大，人力店租都要增高，性价比降低）；品类少，上新频率和周转率就会慢，周转率慢就会摊高成本。 实体服装店打折做促销，难度大于网店（网店通知所有潜在顾客，要比你通知所有老顾客都店里一趟更容易。而且你的折扣区域的存在，会导致你店里的顾客更想跟你砍价）。所以，库存压力会更高。 所以实体店是不可能跟网店比拼成本的。顾客形成了网上样子更多，上更便宜的认知，于是我们可以看到，个体服装店近些年来越来越少了。 第三轮： 实体服装店（其实所有产品的实体店都一样）只能从别的地方想办法。（A）或者，做标准化的产品。 专业术语说，sku比较少（每个型号算一个sku。你会发现，服装的sku是最多的，每一款衣服，如果有四个尺码，三种颜色，就是12个sku。有可能同一款衣服，红色的s码畅销了，黑色的l码畅销了，结果红色的m、l、xl，黑色的s、m、xl都滞销了。 这就是服装店最让人头疼的地方——库存。每个sku都库存，那么sku越多，库存压力
