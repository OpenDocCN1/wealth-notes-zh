# 珍姐姐，茶艺茶花培

(提问)Sasa：珍姐姐，茶艺茶花培训机构有前景吗？
2019-07-15

回答：【帖子编号0320】《茶道插花》[捂脸]这个没前景！我说了一堆培训行业有前景的事。但是......茶道+插花这两个是没前景的。所谓需求分析，离不开分析人性。各种培训的前景无非就是社会的竞争压力大，人们有更多的提升自我（或者提升孩子）的需求。茶道和茶花就两个，纯粹属于消费啊！消费兴趣类的东西。脱离【经济利益驱动】的培训是没有前景的。就说烘焙培训，培训完了，手艺好的能去开蛋糕面包店，手艺不好的对不起，自己在家里也可以做点东西吃，能省钱！茶道和插花这两个东西是烧钱的！烧钱=消费，消费就要看到底买到什么东西里。你去旅游还能发发朋友圈，标榜自己是有钱人，买的是游玩+面子（相信我，这世界纯粹只愉悦自己，假期偷摸出去玩，既不告诉同事朋友，也不发朋友圈的人......肯定不是普通老百姓）你孩子送去学钢琴还是击剑，买的是孩子的入学加分（特长加分）+你的身份标签（告诉学校你家是高收入人群）+你和/或孩子的圈子，等等一堆东西.......——————————————在看茶道或茶花这玩意......带不来经济价值。标榜一下自己，怕是一说自己“爱好插花”，别人都觉得是个没用又败家、还指不定情绪化又很作的人。信不信找对象别人都绕着你。——————————经济学上有一个“保护稀有动物”的做法。就是告诉大家这玩意能吃，值钱，有【经济价值】。大家愿意花钱买，于是养殖的人就多了，于是稀有动物就数量上去了……如果纯靠“爱好”、“热爱”、“情怀”，你信不信全世界找不出50个这么高尚的人？这种保护动物只会越来越少，最后灭绝。——————————————同样的道理，培训班该培训什么，大家懂了吗？别玩什么情怀、爱好。先看看经济利益在哪里。现在社会压力那么大，能随心所欲消费“爱好”的，都是富人家的女
