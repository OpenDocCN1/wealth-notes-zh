# # 为什么现在不流行，

(提问)志：为什么现在不流行，滑旱冰了呢？就目前现在和未来的娱乐项目，还有那些是这样，具有多少年的生命周期？
2019-05-05

回答：【帖子编号0264】 也流行啊。只不过地点变了。 我小时候都是室内旱冰场。现在基本都室外跟广场舞大妈抢地盘。 原因无他，这玩意因为门槛不高，被当做平民运动，买个鞋随便在哪都能滑了。就跟羽毛球似的，买个拍子找个空地就能打了，属于没什么门槛的。 地价贵了，肯定是先把这些哪都能玩的项目挤出去，挤到街上。 毕竟，房租这么贵，肯定先找盈利更高的项目来搞。给孩子上补习班，可以收费一小时一百两。学个钢琴小时费更高。但哪个父母愿意花一小时一两百去让孩子学轮滑，甚至玩轮滑？ 地价贵了，能留在市面上的东西都是“竞拍房租”后留下来的了。滑旱冰作为一个商业项目，收入不够，因此竞拍不起地价。 （同类原因，为什么90年代常见的台球厅没了，游戏机/尤其是老虎机还在。 因为台球厅面积大，耗时长/翻台率低，单位面积的营收太低。而老虎机面积小，耗时短/翻台率高，所以按面积算的营收高、暴利） ______________ 轮滑能不能做 见老贴0224，里面有写轮滑的场景。 轮滑是属于下一代教育军备竞赛中被淘汰的项目。 下一代军备竞赛的三轮竞争之中，第一轮是学科补习，第二轮是素质教育补习，第三轮是贵族教育补习。 轮滑被排挤出这种正面战场了，留给无力参战/不愿参战的家长们，作为一种“我也培养孩子了/我给孩子快乐童年了”的安慰项目。 这种项目也能做，并且也能赚钱。但要注意： 第一，位置。 定位的地点必须是非学区房地区。较差的学区最好。（跟补习班反着来） 第二，价格。 单价不能贵，按月收费，定位是人头数量。用孩子吸引孩子。另可卖装备。(18赞)
