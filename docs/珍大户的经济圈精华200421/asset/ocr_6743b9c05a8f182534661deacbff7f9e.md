# 珍姐，我看好孕婴行

(提问)浩博.李飞: 珍姐, 我看好孕婴行业, 想先从加盟进口母
婴用品入手, 成熟后成立自己品牌发展月子中心, 婴儿护
理, 母婴用品, 我想问母婴用品是加盟好还是自己创办一个
新品牌好?

2018-10-01

回答: 【帖子编号0121】 今年早些时候, 2018年1-3月的新增
人口/新生儿数据迟迟不见发布。但民间大概已经心里有数
了, 大家都知道, 新生儿数量下降了近三成。而数据来源
是: 母婴用品商家的讨论。很多母婴用品商家, 今年的销售
额直接下降了三成, 所以推导出新生儿少了三成。到了后
来, 数据终于公布了, 各地都有下降, 平均起来, 我记得大
概是下降了29%左右。也就是说这些母婴用品商家的直观感
受是非常准确的。看完这个数据, 你还会看好母婴行业吗?
我给你建议是, 不要再考虑什么母婴用品了, 无论是自己
的品牌还是加盟的品牌。但确实可以从月子会所的角度入
手。为什么这么说呢? 因为母婴用品这个行业, 已经发展了
很多年, 现在市场上所有商家所占的市场份额, 加在一起,
肯定接近100%了。意思就是, 所有有孩子出生的家庭, 都会
消费母婴用品。现在几乎不会有家庭还自己纯母乳喂养, 还连辅食
都还手洗的尿布, 给孩子自己做衣服和玩具。如果新生
儿数量, 还是会增加的话, 那么对新入场的玩家, 还
是有希望的。有可能在增加的市场中, 吃得一小块份额。但
很不幸, 这个市场是递减的。所有的玩家, 哪怕维持住市场
份额不变, 营业额也会逐年递减。如果你是虎狼之师, 能够
凶残的从别人手中掠夺来市场份额, 那么或许能维持住营业
收入不变。这就是母婴用品市场, 现在的残忍之处。相反,
月子会所这个事, 现在还是可以的。因为, 不是所有的孕
妇, 都会去月子会所 (现在只有很小一部分孕妇去月子会
所), 只要选择月子会所的比例提升, 那么就可以视为, 这
