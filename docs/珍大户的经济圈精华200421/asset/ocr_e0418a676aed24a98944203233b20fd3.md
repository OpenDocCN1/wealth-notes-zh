# 珍大户，我想问问你

(提问)王小米的饭盒：珍大户，我想问问你和大家，对于现在餐饮实体店怎么看？现在经济低迷，很多人2018年各种投资好像钱都少了，消费能力降低，中国食品安全也是消费者的一大顾虑，物价不低，大家又希望能够吃到好的食物，成本大，顾客都蜗居，不愿意出门，也没有以前的消费力，美团，饿了么这样的线上平台扣点很高，商户之间为了竞争，经常做满减打折活动，利润空间被压缩，可能做了几个月，发现有营业额没利润，倒贴钱，但是新店又是这样恶性同行竞争！！对于餐饮到底是属于一个什么时期的行业，该怎样经营。。大家和珍大户有什么意见给吗？

2019-01-18

回答：【帖子编号0220】餐饮这个东西，是纯粹只看微观个体的行业，看大环境完全没用。因为每个人都一日三餐。有无数人“自认为”自己不是外行，自认为这个东西很容易做。导致无数人创业先选择开餐馆，餐饮的竞争对手，进进出出的频率是最高的。大家想象一下，实体店里，卖产品的，无论是母婴、化妆品，还是便利店、水果零食、生鲜，所有人 在开店之前，都要掂量一下，认真想想去哪找进货渠道。

（敢贸然去批发市场批点水果就开店的人都是炮灰，活不过六个月，也不足为虑）卖服务的，比如美容美发，整形美容，保健按摩，保母月嫂，陌生人进入也会心里打鼓，觉得自己是个外行，会思前想后，会仔细思考怎么吸引顾客，怎么提升服务等“技术性难题”。而涉及到吃，会有无数人觉得自己“不是外行”把这个当成低门槛的，当成自己懂行的。（大概就跟很多人喜欢说自己是个“吃货”似的，然后你会发现所谓的吃货，就是经常吃而已，但不是吃货的人，也不会比吃货少吃几顿饭。所以真是没见差别）这种进进出出，导致了总有价格战，总有新店产生让顾客去“尝鲜”，总有无数竞争对手是跟你在同一水平的。怪到外界因素也没用。如果
