# 珍老师 你怎么看这

(提问)BIn G: 珍老师 你怎么看这几天的美股大跌，会变成熊市吗？ A股会也会就此跟熊吗，对世界经济影响会持续很久吗。

2020-03-01

回答：【帖子编号0410】<站在2月底看> 美股本来今年就有要跌的迹象。元旦后几天错过预测写圈子里了，特意说了美元美股美债要规避。目前看疫情要把这个过程提前了。（预测美股帖子见帖子0396） 记得去年视频讲的美债利率倒挂，意味着今年美国经济出现衰退的概率大幅增加？ 看衰美股逻辑见帖子0397 其实就是经济增长不动了，股市再涨不现实，因为美股市场太大了，不是一个小市场，不是靠一堆人众人抬轿就能捧上去的。 再说国内，我周五颈椎病犯了（估计是隔离在家，运动量不够），结果从周五一直睡到周六，周六才看到发生了什么[捂脸] 感觉很多人恐慌了，因为一直以来都是美股涨a股不涨，美股跌a股跟着跌，大家都害怕外围继续跌会带着a股。 但是这次逻辑会不一样。 大家要注意一点，人民币兑美元的汇率。 年初预测美股的时候，有说过，美股趋势反转是一个缓慢的长期的过程，这个过程中会引起资产抛售，然后转移到其他国家，预计国内会有收益（所以才让大家不用再换美元了） 而现在的逻辑更强烈了。 我们推导一下疫情情况： 假设1：如果各国开始恐慌了，试图防御，则减少国际往来（大幅减少航班）。那么中国是产业链最完备的地方，一国之内能生产出的东西最多。 假设2：如果各国感觉防不住，放弃抵抗。那么中国就是最避险的地方。 年初的时候，我还按照旧有逻辑，避险一般先去日本、北欧、瑞士等等。但中国经济增长/股市价格低，会吸引一部分进来。 而现在看来，这个一部分要大幅增加了。 但毕竟还是有很多人按照旧逻辑，看见国外跌也会恐慌，这个过程可能还要持续个两周，等意识到一
