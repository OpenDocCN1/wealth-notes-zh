# 珍姐姐你好～本人9

(提问)常青：珍姐姐你好～本人95岁，女，家在武汉周边一个地级市（黄石不知道您有没有听说过～）考虑年后辞职去广州、成都、或者武汉发展。这三个城市对我都有吸引力，也有让我犹豫的地方，不知您建议去哪个城市更好呢？家中还有一个弟弟，父母也还年轻康健。我是高中毕业就出来上班了，网吧收银，商场卖衣服，期间考了会计初级职称就去武汉了，前两年家中拆迁又回来了，在一家酒店做会计一直到现在。家里拆迁分了我20万，目前存入余额宝没有动。想选择一个可以留下来成家立业的城市。对自己的规划是：1、考CPA考学历（目前是函授大专已拿到毕业证）在会计这条路上走到黑 2、去外地点学新东西找点商机不行回来做点小生意字数有限还请不吝赐教～

2018-11-04

回答：【帖子编号0164】借这贴说一下会计。我之前听闻教育部有个什么内部会议上，对很多省教育厅的人提示，要求各省限制会计专业招生，因为目前明显专业过剩了。现在全国范围内，从中专到大专到大学，所有的学校几乎都有会计专业，从卫校、铁道学校，到农林类这些明显应该很小众专业的学校，无一例外都开会计专业。这些年金融火，我见过很多破烂学校想开金融专业，但可能是因为群众眼里，金融还算挺高端的，于是破学校的金融专业很难招生，这些学校就会开始想办法，在专业名字上，想方设法，搞些花样出来，比如改叫“互联网金融”金融什么的，其实学校里连金融专业都教不好，但为了能招到学生，只好把专业名字往往最火的名词上靠。但会计不用搞这些小花样，只要叫“会计”，就有一堆人报名，学校能招到学生，自然乐不得，搞得要到教育部发声让限制招生规模。之所以有这种差异，是因为群众的观点几十年未变过，从我小时候，我妈那一代人开始，就说“会计越老越吃香”，到现在还这么说。家里孩子读了十
