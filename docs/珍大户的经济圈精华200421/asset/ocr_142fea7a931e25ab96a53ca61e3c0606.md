# 老师，你好，看过您

(提问)那年，夏天。：老师，你好，看过您抖音的課程后转过来的，受益匪浅，现有个案例您能否从百忙中抽空帮忙看看帮忙分析一下：现有一款产品，我们称为A，为低频产品，现计划投入市场，目前的营销方案有如下三种：1，传统销售模式，推销产品获取利润。2，租赁模式，按照月租形式获取利润，预计一年可达到第一种模式的利润空间。3，免费使用模式，开始销售时收取押金，合同期三到五年，合同期结束后退还押金，并收回设备。以上三种模式烦请帮忙分析一下哪种模式可以快速占领市场并达到利润最大化，是否能在同一区域内投入三种模式销售运营，利弊各是什么？谢谢 2018-09-11

回答：【帖子编号0059】《三种销售模式》 三种模式都有可取之处。理论上可以同时推出。但实际上必须要分析，你们产品的特质。 这个问题让我想起前几天有个提问净水器材的同学的问题。 以那个同学的提问为例，他问的是一种，市场上新型的产品。这类产品想要用传统的推销模式，销售起来会很缓慢，因为涉及到消费者教育，生活习惯引领的问题。 但第一种销售方式是一个明显的锚定标准，虽然销量很少，但是如果没有这种方式做支撑，消费者很难直接认识到你的产品的价值。所以第一种方式是必然要存在的，但重心未必在这上面。 第二种租赁的方式，有很多细节需要思考。比如你们的产品价值高低。如果价值很高的话，那么就涉及到，产品有没有被转移跑路的可能？是否需要押金担保？如果需要押金的话，那第二种跟第三种就矛盾了。 当然，你可以宣传说第三种因为有期限限制，而第二种是自由选择，可以随时结束。 但第二种和第三种之间，是有很强的比较心理的。 如果同样有押金，第二种收租金，第三种免费，顾客马上会有一种你们就是想要别人押金的错觉，然后会有不好的联想，想你们会不会拿着押金跑路。 如果押金金额不同，顾
