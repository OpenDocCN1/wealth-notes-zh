# 珍姐你好，我没看到

(提问)李雨风: 珍姐你好，我没看到问题付费在哪里选，就先问了哈。我是做水果零售门店的，做了3年。目前年营业额在一千万，（只做好吃的水果，一般我店里除了柠檬百香果，其他的都是甜的，对产品口感细腻程度要求比较高）现在进入这个行业的人越来越多，也有很多朋友开始增加零食，卖菜。我一直觉得未来会是少即是多，专业细分越来越厉害，可是增加了很多东西以后，营业额利润都有上升（这个行业本身就会有很多固定客户，客户也有除了水果以外的需求）。我现在很茫然，到底是坚持一条路走到底，还是把客户引流出去做多样化。

2018-09-14

回答： 【帖子编号0067】 《水果门店》 你展现出的，对于水果的挑选，以及少就是多的理念，让我想起来，美国的一个品牌brandless （有一篇介绍的文章，可以参考）你可以先看一下，在往下。 首先，总的产品数量一定是有上限的。 当你的店只是一家水果店的时候，顾客进店是有明确的意图，是想要买水果。这种带着明确意图的进店，是转化率非常高的。 但如果你的产品类目持续扩充，给顾客一种超市的感觉，消费者渐渐会迷失掉"进你店里的目的"，那么反而会影响购物频率和消费欲望。 所以，在后续的过程中，脑中要时刻保留这种警醒，扩展一定要很克制。因为品类扩充的过程中，营业收入和利润会提升返回，给你带来麻痒大意。但这种品类扩充是很容易更改店内的消费氛围的，当氛围改变后，再想挽回的成本就要高很多了（可能需要停业重新装修，来让顾客的记性清零。） 其次，在扩充的过程中， 如果你认同少就是多的理念，那么上面那篇文章我相信会在你的，脑海中引起一些想法。 我比较认同这个品牌的观点。 品类可以扩充，但每个品类下的产品种类，一定要求做到精简。 第三，在扩充的类目上如何选择呢？ 提问中提到的零
