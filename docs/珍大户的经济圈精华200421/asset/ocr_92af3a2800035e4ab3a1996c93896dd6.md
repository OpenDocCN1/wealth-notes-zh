# 还有我想请问一下基

(提问)小公主：还有我想请问一下基金定投怎么样？可以投资吗？

2018-11-10

回答：【帖子编号0169】（内有干货：当前经济形式下，股票、债券）基金定投，可以投的。其实算是一种让自己强制储蓄的方式吧。虽然现在公募基金面临着头出走的很多问题，但在管理能力和投资水平上，仍要比背景来历都不清不楚的私募或是p2p公司靠谱的多。注意选的时候看一下基金规模（不是指基金公司总的规模，而是指你要买的那支基金，存量规模有多大）有很多特小基金，连1亿的规模都没有，这种基金纯属等清盘，没有进的意义。但是规模特别大的基金也很尴尬，属于钱多了必须买，市场上好东西本来就s不多，挑来挑去就变成不得不买了。目前的行情下，货币基金里的钱越来越多，说明群众不是没钱，而是市场普遍比较恐慌，都放到货币基金里避险了。股票是在底部区域了，但到底转折点在每一天谁也说不清，所以这个时候定投，分散建仓，算是个比较理智的选择。债券市场上，有一个很容易理解的逻辑：利率升高，就等于债券下跌，利率越低，就等于债券升值（这个大家可能不太懂，以后我抽空讲）根据这个简单的逻辑，一般常见的情况是这样子的：经济下行周期，因为要刺激经济复苏，所以国家会不断的降息，就变成债券大涨的周期。反过来经济越来好的周期，一方面，民间借贷会越来越活跃，利率逐渐升高，另一方面，国家为了抑制经济过热，也会不断的加息，结果就是，债券大跌的周期。所以债券的周期性，比股市更强，逻辑也比股市更简单。目前我们是属于经济下行周期，唯一的不确定性是，美国那边要加息，中国跟不跟。上个月大家问我这个问题，我还只能说：不知道（因为不跟着加息，则外汇流失，汇率崩。如果跟着加息，对国内经济利空，实体经济、房地产都崩。反正
