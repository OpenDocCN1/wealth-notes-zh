# **90年 男 未婚**

(提问)Jas on：90年 男 未婚 未恋 东北三线城市出生 目前东北二线城市工作 在一家连锁公司做管理，公司有意调我去南方沿海城市，基本收入不会有太大变化，主要沿海业务好，绩效高！去还是不去。

2018-08-21

回答：【帖子编号0005】喵！这问题好难答，要考虑好多情况哎[撇嘴]。 按顺序来： 1，调沿海后还能调得回吗？如果过几年随时能调得回，果断去，先赚几年钱，增加几年阅历再说。如果调不回，往下看2。 2，既然单身，介意找南方女朋友吗？找到了以后，愿意在南方定居吗。再预估一下未来五年的收入涨幅，能支撑长久定居不。都能的话，果断去。如果存在问题，看3。 3，你所在的行业，南方更发达吗？现在的公司知名吗，如果跳槽的话是否方便。如果南方有利于工作发展，尽量选择去。 4，最后补充考虑一下，父母是什么情况，养老需要你一直在身边吗？不过这条应该阻碍不大，一是你现在还年轻，二来东北老人愿意到南方养老的概率貌似也很高。(54赞)
