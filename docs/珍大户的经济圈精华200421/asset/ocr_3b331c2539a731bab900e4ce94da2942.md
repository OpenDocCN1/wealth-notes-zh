# 珍姐，刚看到一位朋

(提问)星: 珍姐，刚看到一位朋友说一百万可以投资信托，本人不懂这块，想知道靠不靠谱，怎么操作，懂的朋友也来提点下，谢谢！

2019-06-07

回答: 【帖子编号0296】 对的，100万是可以投资信托。但是现在，不建议投信托！信托最好的时候是08年之后，13年前。收益率普遍有12%以上。最早是各种资源/能源融资，煤矿之类的，后来是各种房地产信托。信托普遍有个特点，就是某类行业过热，国家想要限制的时候，一般都限制银行贷款。但是信托融资等于曲线救国了，钱就曲线拐进去了。（然而去年限制房地产融资的时候，连房地产信托都开始限制了。）信托的风险怎么样？ 信托期限一般都比较短。1-3年，属于短期融资。到期后还不还得上钱？这取决于经济环境，只要经济环境好，企业就永远能够继续借款，继续发信托，借新还旧。但是如果经济环境不好，现金流断的时候，肯定是先还银行借款，先还公开市场债券，信托属于最不受重视的（别指望遇到法律中规定的，各个债权人享有平等的受偿权。这是规定给破产时的，借款人肯定不想破产的，所以会挣扎着先还重要的钱，不重要的钱往后排。）所以，经济环境好的时候，信托基本没风险。小老百姓攒不出100万，也进不了信托的门槛，只能收着理财5-6%的收益，而有钱人买信托普遍12+ 然而一旦到经济环境不好的时候，信托爆雷就会变多，一旦打水漂，有钱人也是投诉无门的。毕竟借款的是各地的挖煤的、采矿的、盖房的，都是"支柱企业"，地位像红毛药酒一样。所以这就是我劝大家现在不要投信托的原因。（至于为什么信托属于不受重视的债务，还款次序很靠后？ 信托属于"私募"，是发给少部分有钱人的。一只信托发5个亿十个亿，最低投100万。有些人会投个几百万，所以就算这只信托爆了，才影响几百人？ 另外，信托门槛是，你
