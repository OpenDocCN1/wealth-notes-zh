# 您好！一直关注，今

(提问)李大仙：您好！一直关注，今有疑惑希望得到博主指点！我在新二线城市，有两个问题，一是想从事宠物行业，主要专卖宠物粮食和用品，不想提供洗澡美容之类的服务，宠物店的粮食和用品利润基本上百分之一百，我想专做粮食和用品采取低价策略毛利润控制在百分之四五十以内，在方圆一两公里的半径内宣传并可配送上门，不知这种模式可行吗？第二个问题，我干了多年拍卖，因为行业门槛低，现在竞争愈发激烈，已经半年没开张了，不知该何去何从！希望能得到您的指点，谢谢！

2019-01-12

回答：【帖子编号0211】第一个，这个路线绝对不行。圈内搜“商铺”，把过往文章全都看一遍先。反复强调的重点就是——未来的商铺一定是立足服务的。单纯卖商品是没有未来的。尤其是很标准化的产品。你想用价格低，利润低来切入，只会有比你利润率更低的人。网商的利润率一定可以压低到比你更低的水平（因为覆盖率更高，单位成本只会更低）。所以单纯把低利润率当成核心竞争力，就等同于没有核心竞争力。其次，你看到的是宠物食品的毛利率很高，都在100%以上。但你还应该看到，任何实体店的毛利率都很高。为什么？这部分成本是别人都砍不掉吗。所以你先计算一下，自己在降低毛利率的同时，商品销量应该大到多少程度才能养得起房租水电和人工，方圆一两公里的大到又有多少呢？最基本的经济学原理——弹性。宠物食品卖一包赚100块，一个月卖一百包，你想把利润压低到赚50快的水平，那么最起码保证，销量能翻倍到两百包的水平。否则就不是一个好的决策。那么问题来了，多增加的一百包，肯定不是你店铺一公里内的宠物激增，也不会是宠物突然饭量翻倍。只会是你抢别人家的生意。所以别的店有什么理由不跟进？人家还有宠物洗澡的项目，洗一次澡送张猫粮减免50元优惠
