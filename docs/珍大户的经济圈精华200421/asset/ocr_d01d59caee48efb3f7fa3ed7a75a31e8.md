# 大家好，想咨询一下

(提问)对方正在输入...：大家好，想咨询一下能源投资项目。澳洲目前有个公司，专门做太阳能项目，成功案例包括shopping center 光伏停车场和太阳能电站。主要就是利用澳洲充足的太阳来发电然后卖回给电力公司。（澳洲电费超级高）一个小的200KW的电站为42万 澳币。大概两百万人民币。投资回报率百分之12-13左右。本人在澳洲居住。在房地产投资和这个能源投资间徘徊。地产回报率5%左右。资金有限，只能投一个项目。长远来看哪个比较划算呢。有没有懂的朋友给支个招。

2019-09-19

回答：【帖子编号0361】（投资电站）刚好像以前接触过发电行业，投过水电三峡，拒过华锐风电（当年有种风气，就是觉得只要是上市公司都没风险，如果闭眼投或许也就过了，然而我分析了一圈，感觉不是太好，当时就锯掉了这个项目）。这两个行业都研究过，所以对发电这块有点了解。先扫盲一下：口语中的一度电，学名上叫1千瓦时（1kw/h），中间的斜杠不是除号，而是表示“每份”。而发电机的功率，是用千瓦（kw）来衡量的，一个功率是1kw的发电机，每小时能发出一度电。在往上加几个零的换算关系，一般都是按照西方的每三个零加一个逗号的习惯往上加的1,000=1k（英文单词千kilo）1,000,000=1m（英文单词百万million）所以发电机如果标1MW，意思就是1000KW。每小时能发1000度电。火电水电核电这些，发电机机组的功率一般都到百万KW的水平，风电一个机组的容量有1.5MW（太阳能发电没研究过，记不太清了）。其中，核电不能关，昼夜不停的开。水电、风电这两种属于靠天吃饭，有风了就发电，风停了就歇菜；丰水季发电，枯水季歇菜。而电又是不能大规模存储的，即发即用，所以为了避免浪费，国内都是优先安排核电、水电、风电这些新型能源上网，由火电承担调峰功能
