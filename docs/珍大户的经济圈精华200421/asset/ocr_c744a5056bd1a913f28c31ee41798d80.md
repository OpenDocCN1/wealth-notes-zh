# 分享一篇文章。是建

珍大户：分享一篇文章。

是建筑领域的学者，对城市收缩的研究。

但我要提示一下：是这个文章里都是“过去”的数据。

比如：

虽然人口在流失，但流失的程度并没有那么多。西方有的收
缩城市确实少了很多人，像底特律一下子少了60%的人，但
我们只是星星点点少了5%、3%，最多可能在十年中少了
8%;

要知道这个数据是来自于十年前。（文中说是靠2000-2010年
的人口普查数据，加上2013-2016年的卫星光线数据。）

当时还处在城市化进程之中。就是中国有大量的农村人口在
向城市转移。所以这个过程中，“城市人口”的总量应该是大
幅提升的。

但是城市化进程到目前应该是开始放缓了。意思是，现在剩
下的农村人口大部分都是难转移，转移不掉的。比如各个农
村都会有很多留守老人，这部分人是没兴趣转移到城市之中
的。

所以未来就是从“增量博弈”转变成“存量博弈”。
一个大城市的崛起，带来的有可能是十个城市的衰落。
