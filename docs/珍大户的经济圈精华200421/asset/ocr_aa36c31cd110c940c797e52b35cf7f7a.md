# 珍姐，我是刚刚加入

(提问)Mika：珍姐，我是刚刚加入星球的小白，我想问您一下关于纹身行业有没有得做，近期看见不少人在学这个，貌似利润可观，请您给分析一下，万分感谢，坐标北京，小众行业，目前基础收费论图案收费，高级的师傅按小时收费。
2019-07-13

回答：【帖子编号0316】《纹身》 第1次出现关于纹身的提问[呲牙] 这个绝对有的做。 第一，服务业，无法替代。 第二，现在还算小众的，行业还没竞争到激烈的程度。目前客单价还挺高。 如果经营的话，注意侧重点： 第一，纹身是一个小众群体。这群人自己的群体特性，有自己的群体审美认知眼光。作为店主，你自己的穿着打扮，你店铺的装修风格，一定要跟这个群体融入，别让人感觉你和他们不是一个世界的人。 第二，纹身顾客的担心点之一，审美不好/或者手艺不好。 手艺和审美要跟上。就跟纹眉似的，你纹坏一个，店铺口碑就难以挽回了。 第三，顾客的另一个担心点是卫生问题。纹身因为有血液接触，被认为是“如果消毒不规范，是容易传染艾滋病的”。同理与洗牙，但洗牙单位一般是以诊所的形式，诊所会让人觉得卫生问题有保障。而纹身店不具备这种特质，所以你们要想法打消顾客的疑虑。 虽然我一家纹身店也没见过。虽然电视上演的纹身店，都是昏暗的小馆子，给街头gangster准备的似的。但要注意，在北京这种一线城市（二线城市也一样），能接受单次上千元消费、有消费力的年轻人们，普遍教育水平比较好，只不过因为思想开放，接受多元化的文化，所以才纹身的。 你店面可以任何风格，哥特也不要紧。但操作台（类似于手术室的地方）一定要干净明亮，消毒严格，做好卫生防控问题。千万不要像电影那种苍蝇馆子似的。(19赞)
