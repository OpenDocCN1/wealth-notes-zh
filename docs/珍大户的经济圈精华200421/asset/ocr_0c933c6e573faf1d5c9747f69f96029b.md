# **本人31岁在浙江金**

(提问)匿名用户：本人31岁在浙江金华做阿里巴巴批发（水晶礼品），一年收入40万左右，老婆和孩子在南通（是在编老师），手中有120万闲钱，现在准备再买一套房子，南通房价和金华房价差不多，如果在金华买的话每年就不用租房（3.5万一年），南通距离上海比较近，过2年高铁通车，房价应该比较稳定，现在不知道在哪里买？希望珍姐给点建议？
2019-04-12

回答：如果非要两边选一个的话，那么选南通概率更高些。一个是因 为跟上海衔接的跨江交通必然会打通，另一个是有传言说要建机场（不知道准确性如何），这些都是属于未来有可能带来增量的。金华的话，环境很好，但是目 前没看到什么未来的增量。而且批发业务应该主要在义乌吧？和金华市区有属 于两个不同的地方，这就很尴尬了。买义乌属于县级市，地位尴尬了点。买金华，金华的经济中心都在下面县，而不是在市区。另外，感觉你老婆的工作更属于不 可调动，所以未来全家定居应该更多在南通，而不太可能让家人到金华。从使用性上来说，这套也更高些。至于你说的每年房租能省3万块，我觉得，一方面 你掏200万买个房子，为了省每年3万的房租，这个投资收益比太低了。另一方 面，你现在一个人居住，其实对居住环境要求并不是很高。我猜可能这个每年3 万多的房租，其实有一部分应该是花在了产品的仓储上了吧。这种仓储需求也 没必要靠买房来实现。（26赞）
