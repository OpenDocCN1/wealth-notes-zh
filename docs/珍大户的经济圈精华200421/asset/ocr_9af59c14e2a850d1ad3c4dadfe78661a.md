# 现在去学习和做软件

(提问)A278刘鹤鸣：现在去学习和做软件开发项目，会不会太晚。27了，有车，收入也还稳定。

2019-04-11

回答：【帖子编号0250】我妈喜欢给别人介绍对象。介绍着介绍着，就跟我抱怨，说很多“老姑娘”、“老小伙子”特别多。他们往往因为觉得自己保养的比较好，自认为外表很显年轻。 常见的话是这么说的：“我看起来也就30多岁（实际年龄四五十），所以我要找年轻的异性，不接受年龄大的”最极端的是50岁的男人，觉得因为自己看起来像30几岁，所以坚持要找20几岁的小姑娘相亲。我妈听说以后就反问，说，你50岁看起来像30岁，难道30岁看起来还能像50岁的？必然不是啊。既然人家30岁也一样看起来像30岁，那你的外表，就绝对不是什么优势。所以不值得拿外表来当砝码，不要自我感觉良好，还是先想想自己还有什么“额外”能说的优势吧。 ------------------这种思维也影响了我。以前也有不少人问我，二十七八岁了，再重新考研读金融，毕业了能找个交易员或者研究员的工作吗？二十七八岁开始换行，等学习完毕出来已经30岁了。换行的人往往会附带说：我学习能力强，又勤奋刻苦，指哪打哪，任劳任怨，愿意重头开始，能接受低待遇。套用上面的思路，反问一句：难道说，25岁以下的职场新人，就学习能力差？不够勤奋刻苦？不愿意从头开始了吗？肯定不是。所以，我对要换行人非常坦白的说一句，所有的肯学、勤奋、刻苦、努力、愿意从头开始，这些都不是有点，这些都是必要条件。人家年轻人也一样有，那么你必须要考虑，自己还有什么额外的东西。如果没有额外的东西，那么你全然没有任何优势。又何必换行，去另一个全新的领域被人挑挑拣拣呢。 -------------------- 建议所有需要换行的同学们，必须先考虑自己过往的经历中能带过去什么。只有能带过去一些额外优势，比如让自己成为一个跨领域的、或
