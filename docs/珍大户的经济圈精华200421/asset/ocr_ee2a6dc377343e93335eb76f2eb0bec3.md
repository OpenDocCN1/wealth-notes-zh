# 珍老师你好，最近在

(提问)D: 珍老师你好，最近在成都看上一个楼盘，均价1.2万/平，自己是刚需准备购买，看网上很多人说现在不要买房，房价明年会跌；第一个请问现在这个时候我的情况可以买房吗？第二个问题是成都现在房价在1～2万泡沫严重吗？2018-11-06

回答：【帖子编号0167】成都泡沫不严重，跌也就是属于心理层面的（因为很多人怕跌，于是观望不买，开发商资金紧张，于是打折促销）。但后续因为有新增人口，买盘还在，所以未来的价值，就依然在。不像某些城市，是属于跌下去就多少年回不来的，比如厦门的四五六万均价，就业机会和工资还没到特别高的地步，房价就特别高，就会直接影响到毕业生的就业选择，高房价直接影响人口流入。再比如一些县城，直接涨到一两万，除了靠本地的出生人口，根本吸引不到别人进来，那么就祈祷出生率一直很高，生出来的孩子也一生不迁徙吧。在帖子0153里说过一个观点 未来没有普涨了，都是存量博弈。有涨的地方，就有跌的地方。涨的地方一定是人口流入的，跌的地方是人口流出的，或者现在泡沫严重，房价过高的。目前可以认定，一个城市在两千几百万的水平内，都能使效率提升（虽然城市最有性价比的人口上限是多少，仍然无法确切的说。但可以确定的是，到了某个临界点时，就会因为交通，资源运输等原因，导致成本上升，效率降低，各种风险增大）所以未来的城市化进程，一定会出现一批新的2000万人口规模的城市。（按效率排序，10个200万的城市，效率低于4个500万的城市，又低于两个1000万的城市，更低于一个2000万规模的城市。因为城市效率高，所以城市居民收入高。又因为收入高，引起居民迁入，直到达到人口上限的临界点）成都没什么疑问的会人口持续流入。而成都房价，从1-2万这个区间来看，在全国范围内做对比，其实并不算高，所以不用太担心泡沫的问题。另
