# 珍老师，您好！您的

(提问)张耕尘：珍老师，您好！您的忠实粉丝，想咨询您中老年教育的项目是否可行，如何开展。我家社区600户，周边大概1000户，但楼下面海的网点因为不临街，.txt

回答：【发科】【帖子编号0370】<老年培训>你这个事就别想做了。每隔个几年就能看见新闻上投“最老考生”，报道的往往是六七十岁或者七八十岁的人，去参加高考、或者参加司法考试之类的。这种事情能上新网的就是因为太稀奇了，像发现个106岁的老人那么稀奇。少儿教育遍地开花，是因为少儿教育是带有“功利”性质的。要么帮助升学，要么音体美什么的，帮助提升外形、帮助更容易行走社会、甚至20岁以后帮助赔找对象。如果没有这种功利性质，试验开一个“冥想”培训班，保证赔死你。少儿培训遍地开花，试也因为是儿童存在着各种不确定的未来可能性。所以家长愿意多方尝试。年龄越大，可能性越来越少，能培训的东西也越来越少了，所以越到成年人的教育，种类越少，到老年人的教育更是难。想 做老年人的培训班，各种纯“兴趣爱好”是没可能的。老年人普遍比较节俭了，你宣传说写个毛笔字，下个棋，看个书，泡个茶，做个蛋糕之类的兴趣爱好培训，老年人普遍第一反应就是：这种事还要花钱？在家自己弄弄不就
