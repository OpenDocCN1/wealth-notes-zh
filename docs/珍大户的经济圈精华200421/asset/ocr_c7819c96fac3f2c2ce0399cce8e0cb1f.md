# 感谢 提供的一个照

珍大户:感谢 提供的一个照片
(作为0236贴的续续，再叨叨几句)

只看照片的话，墙面/天花板/地板，颜色很统一，是白色为主色，绿色为辅色。

柜子看不清细节，但是入门的前两三排，先放了几个高度不一的“矮柜”，这个高度就很反常。（对照前一贴里提的“外国人”比喻）

东西码得像强迫症患者。

灯光图片上看不出是白光还是暖光。但是感觉应该是调色过的。

细节处处精心设计。如果不仔细思考，只会觉得这个店让人挺舒服，氛围感觉还行。

营造出来的是，这个店不会让人感觉到“廉价感”，而进去一翻价格签，咦，竟然还不贵。然后就买了……
