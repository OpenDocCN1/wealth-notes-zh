# 坐标成都（附近的区

(提问)匿名用户：坐标成都（附近的区县），女，29岁，未婚未育，药学本科，今年考过主管药师（也有执业药师资格证），在社区服务中心工作，事业编，待遇一般（交际面狭窄）但是比较清闲。去年通过司法考试，但是还没有参加实习。请问珍老师，考虑职业发展前景，我是应该去成都改行做医药销售，还是应该在成都换行业从实习律师做起，或者继续呆在区县做现在工作发展副业。我设想过成都做医药销售，顺带读法律方面的在职研究生。我的家庭经济条件一般，自身无房无车，和父母一块住父母的房子。

2018-12-06

回答：【帖子编号0187】你说的这两种职业，偏偏都不是靠“分析职业前景”就能做出决策的。单从职业前景来看：医药行业，整体销售费用占比一直很高，所以医药销售的收入不低，甚至我知道还有不少医生受不了高强度工作和低收入，转行做药代的。而且未来，无论怎么改革，医药都是高利润率行业，就有可能给医药销售支付高薪。律师行业，我了解的情况是，上海这种一线城市，前期熬过去后，5年以上的律师收入不低。我看过一个律协的统计数据，说浦东区5年以上的律师，平均收入据说能到100万（当然，有熬不下去的比例，但是熬不下去的就转行去公司做法务，领月薪了，我听同学说的行情是，有个几年律所经验的法务，1万5到2万5的样子）。合肥这种二线城市，行情要差不少，我去年进过一家还不错的律所，了解了两个月的情况，发现从业5年以上的律师，普遍只有20-30万一年，律所主任这个级别也只有70-80万左右，于是就打退堂鼓了。但对比合肥市的平均收入，律师整体还算不错的水平。所以，从前景来看，这两个选择都是可行的。——————然而，在我看来，这两个工作都算极端的有特色。必须结合自身的性格特点，才能做出头来。如果忽视自身的特质，贸然选择，过了两年发现自己并不适
