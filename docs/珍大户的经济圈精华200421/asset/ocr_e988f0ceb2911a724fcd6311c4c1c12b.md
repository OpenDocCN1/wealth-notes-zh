# 珍姐您好，我是您的

(提问)March：珍姐您好，我是您的小粉丝一枚，现如今有一个困扰想跟您请教。首先我想做一个以社区为依托，类似丰巢和自动饮料机这样的一个冰鲜、冰冻柜。里面的内容是半成品的蔬菜、经过处理的蔬菜，甚至细化到葱姜蒜末，和分割好的肉品。冰鲜类是牛排、南美虾、冷冻肉片等等的冻鲜。在部分城市有看到这样的鲜花贩卖机，和共享健身房。想在一个城市建立1□N的模式，1为中央厨房、中央仓储、行政办公和产品展示，且可做半成品加工。N为每个中高档小区建立这样的冷藏柜、冷冻柜。我想问下这样的形式是否具有可行性？
