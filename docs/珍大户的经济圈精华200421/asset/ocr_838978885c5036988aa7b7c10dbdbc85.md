# 大户你好。本人92

(提问)匿名用户：大户你好。本人92年。结婚两年，有一个1岁半的儿子。陕西安康贫困县城，18线，体制内教师工作5年半，收入6000. 5年多来工作没有任何晋升。老公一直在上海从事健身工作，收入2万□。因长期两地分居，双方想要改变现状。老公想法是一起去西省份会发展。他继续做健身行业。我重新择业，线上教育或教育培训行业。目前已经在西安3环边上买了房，还有两年交房。现在的问题是，我想在体制内边工作边参加公务员考试。考入西安。老公强烈反对，觉得十八线小县城没必要再继续待下去，锻炼不了自己的能力。他觉得我毕业以来，能力退步了很多。不能再体制内混混沌日疫情结束，马上要开学了，我不知道该怎么办，求帮忙，跪谢。

2020-03-01

回答：你们这个不是大矛盾，非常好解决。首先城市选择上没矛盾。越到小城市，越缺少工作机会，很难同时让夫妻二人都有满意的工作。如果你继续留在县城，意味着要么长期两地分居，要么你老公到县城后满意度很低，会抱怨你。不管哪种情况，家庭基本都要散了。所以为了家庭你也得去西安，这个就不要犹豫了。工作大不了就换一个，家庭不能换来换去。那么，到西安后该做什么。不同的工作，性质是不一样的。比如当老师就不可能有很好的晋升，这个从你进去之前就得想清楚。如果你想要超长期的寒暑假、想要工作的稳定性，社会尊重，由此选择了教师职业，随之就要放弃高收入增长。有得必有失。公务员也一样。如果你选择了公务员的保障、稳定、社会地位，就等于放弃了收入的高增长。（但是考虑到很多人就算自己去拼搏，最后也未必能得到收入的高增长，所以与其奋斗一圈，最后没得到，还不如刚开始就放弃，直接选择到手的好处）。你这边走怎么选都很容易。教育培训行业收入高，公务员社会地位/人身保障/
