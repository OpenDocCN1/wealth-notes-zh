# 老师你好，我是家里

(提问)Try: 老师你好，我是家里自己开工厂的。从毕业到现在4年都在这个行业，现在不想在继续呆下去了。突然觉得很迷茫，不知道该去做什么，好像出了工厂我什么都不会了。第一点：我个人比较看好以后各行业培训类的机构。第二点：餐饮是我感兴趣的。第三：就是跟上互联网时代，网络影响等。请问您对我目前的这种尴尬处境有什么建议，我该如何抉择。谢谢。

2018-08-22

回答：【帖子编号0010】套用一句俗语，谁的人生不迷茫[偷笑]到了人生该选择的时候，迷茫是正常心理吧，只有开始行动才能缓解迷茫。你选的三个方向都有可取之处，建议可以做一些前期的思考准备工作，会让你更有头绪： 1，关于培训类的，搜寻你的合伙人，可以担任培训老师的人选。因为培训是轻资产重人力的行业，找到合适的人最重要。 2，对于餐饮类，要做基本的当地市场调查。先去观察几家店，花时间计算他们的客流量，乘以人均消费水准推算单日 / 单月流水，按毛利率60%，扣除当地的房租，人工，装修折旧等，看盈利空间有多少。细节上，琢磨各家点的菜单，菜品，摆盘，装修，店内布局，员工培训是否有各种提升改进空间。 3，互联网，随时关注各种新应用，新趋势，做缓慢积累。这种前期的准备工作不占投入，但可以摆脱迷茫，做着做着你就会渐渐想清自己想要转型的方向了(45赞)
