# 珍姐，我想请教您个

(提问)阿妫布艺：珍姐，我想请教您个问题，我是做窗帘的，
做了6年了，生意一直还可以，今年下滑很厉害，大概受经济
影响了，能维持下去，今年生意都是靠老顾客介绍的，客户
都说做的可以，效果也漂亮。我自己本人就是不知道怎么让
更多的需要做窗帘的认识我，知道我的店，我是开在社区门
面的，就想请教您一下，我现在改怎么办？

2018-12-08

回答：前面有一个说窗帘的帖子，不知道你看了没有，可以
搜索关键词找一下。 窗帘属于软装，涉及到装修类的东西，
大部分都是一次性消费，会二次换窗帘甚至隔几年定期换窗
帘的基本少之又少。基本都是新房装修，才有买窗帘的需
求。 而社区店的问题是，辐射半径很小。 一个大型商场的辐
射距离，基本上不超过五公里。一个社区店的辐射距离，基
本上不超过2公里，甚至只有一公里。 所以你说的今年行情不
好，真的未必是经济环境原因，而有可能是你这个店的辐射
半径内，该装修的人都装修过了，潜在顾客都挖掘完了。除
了别人介绍更远的人过来，基本没有二次消费的。(15赞)
