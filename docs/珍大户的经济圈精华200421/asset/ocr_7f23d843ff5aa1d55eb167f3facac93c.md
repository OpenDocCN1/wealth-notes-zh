# **老师，我是刚从部队**

(提问)向前：老师，我是刚从部队退伍的军人，本科学历，有一定的社会经验。现在面临两个选择，一是去中国平安做综合金融客户经理，没有五险一金，工资纯靠自己业绩，好处就是可以接触到很多人认识很多人，也是工作所需，被逼的要去认识一些人。二是在演讲与口才杂志社旗下的演讲力国际教育培训公司做销售，无责底薪6000，有五险一金。这边呢有客户群体，可以认识一些中高端的人群。我以后想自己创业，所以现在也摇摆不定，说实话自己也很想赚钱，所以想请教一下老师，老师能帮我分析一下嘛？

2020-01-04

回答：【帖子编号0395】<职业的消耗与积累>这两个都不是好选择。如果非要选的话，选后一个带五险一金的，然后继续留意其他工作机会。 ————— 大概解释一下，为什么这两个都不是好机会：前一个是保险公司无成本的堆人力做保险销售，你是属于没有任何成本的“备胎”。你能做的好，保险公司有收益。你做不好，保险公司也没损失。至于你是不是浪费了时间、损失了其他机会，这不在他们考虑范围内。人力宣传，由一个人对他身边的一群人点对点的销售，这是上世纪90年代就在使用的销售方式，已经30年没变过了，这种销售效率很低。低效率其实代表的是高成本——高时间成本，高机会成本。如果保险公司正常为每一个保险销售者支付时间成本工资，那他们保证不会招聘如此之多的业务人员。正是因为只发业绩，不发底薪，对你们的时间成本、机会成本无偿使用，才敢召这么多的业务人员。而招这么多人的目的，其实就是让每个人开拓自己身边的人际关系网，从自己认识的人中转化客户。（所以一旦你进去之后，即便是你想要开动脑筋，搞出更多的渠道来，也一定会被里面的氛围影响，开始对自己的亲戚、朋友、邻居、同学、战友们做销售来）所以，这两份工作虽然都是业务销售性质，但是
