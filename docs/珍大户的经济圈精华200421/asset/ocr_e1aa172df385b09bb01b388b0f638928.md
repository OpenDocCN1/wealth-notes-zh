# 我想问个就是关于现

(提问)□、您的小仙女: 我想问个就是关于现在的教育体制。现在国家非常注重语文。要求学生背各种古诗文言文。国家的发展是靠科技，医疗，创新产业等，这些无一例外都是靠数理化。为什么要把重心放到古诗文言文上面？？我是一个二年级学生的家长。现在学校每月至少一次要求小孩背社会主义核心价值观，我忍。除了教科书上的古诗，额外还要家长带着读不少古诗，我也忍。现在要求背弟子规。背这么多古诗文言文，小孩自己都不能理解，背了有用吗？如果小学一二年级能读懂文言文了，那还学小学语文干什么？本来教科书的内容多，又要要求孩子有特长，现在背这么多没用的东西跟机器一样。。。我内心是非常抗拒的！所以中国的教育 未来到底是要怎么发展？？ 坐标长沙

2018-12-19

回答：[发抖] 我一直觉得，小学里最需要开的课，第一门是逻辑...... 现在回忆起很多中小学时的教育，会觉得很多内容没有逻辑。比如语文课教写作文，套路就是引用名人名言，似乎就能证明什么事情。然而名人名言又不是公理定理，有什么证明意义呢。还有议论文先举一个观点，然后写一个身边的例子，最后在文章结尾再重申一遍观点。导致现在网上看到所有人辩论，基本都是这种套路。你说毕业生平均收入多少，他说“我同学两万”，你说读书有用，他说“我小学同学辍学现在当老板”。基本都是小学议论文套路。 第二门要开设的应该就是法律基础。学习权利与义务，既要认识到，每个人行使权利都会对外界造成影响，因此权利不是无限的；又要认识到，要保护和捍卫自己的基本权利，不能让别人侵犯。 然而这都是理想世界...... 我确实也不知道现在小学基础教育是什么样的了。看到要求背诵社会主义核心价值观，还有弟子规这些，听起来真的很反感。在个人层面，做家长的只能自己先放宽心，知道自己追求什么样的教育，真的看不
