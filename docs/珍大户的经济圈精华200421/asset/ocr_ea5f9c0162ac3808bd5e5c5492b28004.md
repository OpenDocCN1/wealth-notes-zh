# 创业有7年左右，有

(提问)A阿拉广告.胡世挺:创业有7年左右，有见到脚踏实地风生水起的，也有近几年突然崛起爆发的，有老一辈逐步褪去的，还有很多努力但深陷泥潭的，自己还算顺利，没赚到什么大钱但积累了经验，车房儿都有。去年进圈前换了房，有点微跌，利率高，越发觉得选择大于努力这条至理名言！大户的很多抖音内容看了挺有感触，赚钱要选对行业，而且要在行业黄金发展期为好。感觉自己广告行业已经是没有多少提升空间。去年开始一直想开辟个副业，本人86年的，浙江人在广东佛山家具制造基地。我身边都是做家具行业的，这里有完善的产业配套，我想咨询大户，家具类现在处于什么期了，未来前景如何？还能否介入，是从哪里切入比较好？生产，营销（面向全国），还是零售或是电商？谢谢

回答: 【帖子编号0246】谢谢前面的认同，副业不要进家具行业。 我所理解的副业，是指投入的精力占用不会太大，有比较不错的利润率。 所以问题来了：为什么有这么好的副业？这么好的副业，为什么不会变成本业？ 原因： 我们把事业简单划分，一种是标准化的，能够大规模扩大的。这种，大部分情况下，竞争激烈，利润率不可能太高。但是因为规模能够扩大，所以大部分人都奔着做大的目标而去。——这种必须都是主业。 而另一种是非标准化的。可能是差异化带来的不可直接对比，也可能是小众导致的无法扩大规模，还可能是信息传递不畅导致的市场有限。总之，就是小而美。小而美的未必都是副业。但副业一定是小而美。 意味着市场上可以容纳很多商家，再多你一个也能容得下。但又因为大家都不一样，所以不会因为恶性竞争，导致大家都利润微薄。 —————————————— 家具这个东西，大部分人第一感觉，会以为这东西很差异化，像是“小而美”。然而这是错觉。 我们社会现在的审美发展，还没有到这个程度。目前仍旧是同质
