# 本人95年，老家在

(提问)春风得意马蹄疾：本人95年，老家在安徽芜湖。2016年自国内某985本科毕业后来上海一个央企工作，满三年（也就是2019年）可以落户，届时可以取得购房资格。

2016年毕业时，父母在芜湖市区投资了一套住宅，以对冲未来上海房价上升的风险，同年赶上了涨价升值，目前公允价值约165w。我个人觉得在省内，合肥一旦取消限购，房价会有一定幅度的增长，同时导致芜湖楼市的资本流出（投资合肥）。

不知道我的担心是否多余，还望珍姐帮忙分析一下合肥和芜湖2019～2020年楼市的趋势，现在（3月）从芜湖套现投入合肥是不是正确的方向？

2019-03-02

回答：【帖子编号0239】3月份房产 这个问题就比较容易回答了。 因为是抛一套、买一套，这个问题的本质等同于问《城市之间的相对变化》，所以就容易回答的多了。对于抛一套买一套的城市之间套利，最容易判断——就是看【人口的流动趋势】，对比两个城市对人口吸引力的大小，买高吸引力的，抛低吸引力的，保证没错。除了少部分地区，估值严重偏高以外（比如杭州、南京，虽然仍然是人口流入城市，但是价格太高了，有些透支未来的涨幅，所以性价比不是太好。）所以这一贴的答案，现在卖掉芜湖的房子，买合肥的房子，是正确选择。—————————我再稍微引申一点。
