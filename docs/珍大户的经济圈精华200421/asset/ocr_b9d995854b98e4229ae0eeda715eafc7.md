# 珍妮老师你好，我是

(提问)可爱的嘟嘟：珍妮老师你好，我是前几天才加入圈的，这几天都在看置顶的帖子，您知道"元谋"这个地方吗，元谋人是迄今为止（截至2019年4月2日）中国境内发现的最早的人类。我父母是四川的，来这个县城20年了，想听听您对县城的看法，之前看到您说县城的房子不要买，但是我们这边现在房地产多起来，政府也意在把元谋人这个文化推广出去。圈里除了北上广深和新一线，应该也有许多县城的同学，希望能详细分析一下现在县城的趋势走向

2019-06-25

回答：【帖子编号0304】《县城前景》 我隐约记得，谈过县城的前景（今天做目录的时候好像见到过）。但是考虑到县城在国内的基数，这个问题，其实有必要反复强调的。 0153 这个帖子的观点，是随着GDP增速的下降、货币增速也会变得缓慢，全国范围内普涨的局面不太可能再继续持续下去了。未来就变成了此消、彼长的状态。有的地方房价下降，有的地方房价上升。【在这个帖子里，提到：格力拾奥克斯、伊利拾蒙牛，这些都是在GDP增速降台阶的过程中出现的必然结果。因为以前市场高速增长，你卖不影响我卖，反正增速很大，大家先去抢占新市场。然而当市场增速放缓之后，你多卖一台，我就少卖一台。因为市场增速放缓后，会发现盘子就那么点，不激进的抢，就被别人占光了。同理汽车销售，表面看起来是国六新政策。然而实际根本，是汽车销量下滑。去年每家卖2万台车。今年每家只能卖1.5万台。想要保持住2万台，就得去抢别人家的。让别人家只卖出1万台，自己就能保住了。房子现在也是一样道理】房价涨的地方，一定是人口流入。那反之，人口流出的地方，房价都一定下降。人为什么流动？因为人随工作走，人随工作走，人随工作走。哪里有机会，人就会去哪里。所以，某地人口能不能流入，看这个地方有没有新增的工作机会。有没有
