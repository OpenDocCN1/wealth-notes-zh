# 还是之前的问题，我

(提问)芮吉斯：还是之前的问题，我是做千层蛋糕的！价格贵了味道好，顾客嫌贵！价格便宜材料缩水又没那么好吃！顾客还是流失，应该如何取舍？

2018-08-21

回答： 【帖子编号0004】 (你之前的微信提问我看到了，没回答也是因为信息太少，大家如果希望回答的详细一定要细节补充清楚，有图片还可以上图片) 1，蛋糕如果是按斤卖的，改成按盒卖的。尽量模糊掉消费者心里便宜还是贵的界限。(如果盒装蛋糕，每盒价格还是太贵，一盒内容又太少的话，多开发一些品种，每盒凑一多个品种，用种类吸引人) 2，材料应该不止“好的太贵，便宜的不好吃”这两种选择，你必须增加对原材料的考察，找到中间的、更中庸的选项。 3，你的店里有多少产品？如果千层蛋糕只有一种，如果没有对照产品，那么你怎么确定别人不买是因为嫌贵，或者是嫌不好吃呢？(27赞)
