# 珍姐您好，看到您发

(提问)匿名用户：珍姐您好，看到您发的智慧门店加盟案例心中一惊，最近要转行如何选择加盟公司能不当小白鼠，共享洗车您看不看好。

2018-09-13

回答：【帖子编号0063】《共享洗车》说一下加盟选择，能加盟什么样的店？先说一个案例 十几年前，加盟四通一达做快递的，都赚到钱了。原因有很多条。大部分人分析原因时会说，当年快递业不发达，预期随着网购的盛行，快递行业会有很大的发展，所以加盟能赚钱。但如果做个假设：假如淘宝是2018年才出现的，网购今年才兴起，那么现在是加盟快递行业的好时候吗？答案就是否定的了。因为当年四通一达开通加盟模式，是因为缺少资本，不得已才用加盟的模式，省钱。现在的社会，资本太充足，一定会进入资本大战的结局，先烧钱，把加盟的（钱少）对手烧死，把行业清洗干净了，再开始正常经营。所以我们必须要思考，什么样的行业是资本最愿意进入，并且清洗竞争对手的。大致说两点，第一，非常标准化。第二，能够产生规模效应（如数量多会降低运营成本或管理成本，数量多会增加顾客的选择，降低获客成本等等）。快递，租车，共享单车，等等，这些都是非常标准化的产品，而且网点越多，对顾客越产生吸引力，所以如果是产业初期，行业龙头还没出现，就肯定会有烧钱模式。而不符合上面两点的行业，餐饮，不符合标准化，大家对吃的口味认识没有，完全标准的模式，所以行业容得下五花八门的店，就不可能玩统一。教育，不符合规模化，家门口的补习班就算全国有1400个分校，我又不给孩子转学，有什么用呢。补习班的成本都是老师和房租，开得再多也降低不了成本，有什么用呢。所以，这种倒是不用担心巨头进来玩清洗。再看共享洗车 我不知道你说的共享洗车是否是指机器洗车？我体验过几种，包括上门洗车，和机器自
