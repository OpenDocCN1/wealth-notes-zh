# 我现在生产汽车坐垫

(提问)鲁宾逊1301467*：我现在生产汽车坐垫，今年生意特别差劲儿，矜姐了解这个行业么，还适不适合折腾，想弄点钱扩大产品线，扩大产量！

这个行业属于什么周期现在

2019-01-20

回答：【帖子编号0222】《模仿性》别再投资，不要试图扩大规模。 作为外行人，我理解的汽车坐垫有两种，一种是椅子上再铺一层，冬天铺毛垫夏天铺凉席一样。另一种是改装，把地板配的织物座椅改装成真皮座椅。 但这事就跟三十年前，家家都喜欢搞个电视剧罩子，洗衣机罩子，沙发罩子。有点“老年人行为”，同理的还有“方向盘套”这种东西。（F先生老吐槽他爹，为什么明明是真皮的方向盘，还要再买一个“真皮方向盘套”）但所以说出来，从业者肯定是不信的。 尤其是汽配城的从业人员，看到的都是去装修的车，各个都是座椅上有垫子、方向盘有套子、后镜上挂坠子，就很容易觉得，估计大部分的车主都这样。 但这是幸存者偏差。就是一小批人的行为，而他们之间还会互相介绍着去汽配城，所以汽配城的从业者看到的其实都是这一个小群体。 那么大群体的趋势是什么样呢？ （以下是分析） 前景还要从“模仿性”上说。（要结合我在抖音上讲的拎录音机绝育那个例子的模块，以及纸带模型的模块来看） 两千年初开始，汽车最开始销量上升的年代，那个年代还没有那么多的好车。 当年买帕萨特的人，给外界的档次印象大概跟现在四五十万水平的奔驰奥迪捷豹的档次了。本田丰田都是超有面的车。（记得互联网上曾经有一个大事件——“雅阁女”，一个女的开雅阁，就可以炫富了，放在现在，还怎么好意思炫。）提这个历史，就是让大家回忆起来，当年“车”还是一个很扁平的整体，车主内部并没有分化出高中低档。 当年的车，全都是高档货，连现在不入眼的桑塔纳也是高档
