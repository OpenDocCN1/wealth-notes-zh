# 大户，我对于不锈钢

(提问)匿名用户：大户，我对于不锈钢筷子那集没懂，不锈钢的筷子很好打理啊，这个说明了什么呢

2020-02-26

回答：是大家对“档次”的认知。这个必须是大众的认知，而不能根据自己的喜好来。而大众的认知，又是来源于“各个阶层”用什么。看到普遍属于高阶层的人用的，就会认为都是“高档”的，看到普遍属于低阶层人用的，就会认为都是“低档”的。一个东西给别人的印象，有几种情况：一种情况是，这种东西特常见，你一眼就知道是什么群体在使用它。比如，赵本山戴的蓝帽子，是以前工人戴的。军大衣，是保安穿的。小木头板凳，是农村用的，等等等等。这种常见的，还带着群体印象的东西，档次已经被固定了，哪怕英国女王跑来穿一次军大衣，也不可能把这个东西的档次拉起来。另一种情况是，这个东西超级不常见。那么档次这个东西就有些变数了。老说外来的和尚好念经，因为不认识，没有先入为主的印象。比如之前lv和巴黎世家，都出了款像蛇皮袋子似得手提包。蛇皮袋子在国外不常见，没有群体印象，所以大牌这么强扭认知，是有可能搞得定的。相反，蛇皮袋子在国内太常见，还有群体认知的，绿皮火车上常见，所以即使lv再宣传也没用。再看一不锈钢餐具。这是高中、大学食堂里最常见的东西。因为太常见，已经有既有印象，所以不可能高档得起来。那家餐馆是韩餐馆，可能是想着接轨韩国，觉得韩国人爱用不锈钢餐具吧。然而刚好撞上了国内的群体印象，就不太好了。反之，如果开到其他国家，别人没怎么见过不锈钢筷子，也没准会以为这是高档东西。有时候看不见高阶层的人用什么，那么就凭想象，找点不常见的也能冒充一下。然而只要是常见的，就都会被联想到档次。(82赞)
