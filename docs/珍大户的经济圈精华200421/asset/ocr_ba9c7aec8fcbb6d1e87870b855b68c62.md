# 珍姐，为啥说房地产

(提问)不辣的皮特厚: 珍姐，为啥说房地产泡沫破灭后会导致通货膨胀呢？能否举个简单的例子给大家说说，谢谢。

2019-01-03

回答：【帖子编号0203】 不是这样的，这种说法明显是博眼球。房产泡沫破灭后，正常情况下是导致通货紧缩。因为所有人的“资产”都会大幅减少，只会更加减少消费，于是物价更加下跌，陷入通货紧缩（参见0108贴货币幻觉）。参考日本房产泡沫破裂后的通货紧缩。 但还有另外一种非常汉奸的情况，会导致通货膨胀。就是国家继续大幅印钞企图“救房地产”。 但是在当前如此高价位的情况下，能拿出全款炒房的人又有多少呢？只能首付来炒房，就意味着你的杠杆几年内都退出不掉。你要押注于后面n年里，依旧大规模放水，有人来接你的盘。这种想法肯定是不现实的。所以，此时还会继续炒房的比例存疑。 但另一种人的比例，无疑会增多。就是高位趁机卖房换汇的人，因为再大幅印钞就意味着，人民币被稀释，货币价值变低，所以换汇避险才是最正常的选择。因此这种时候，换汇的人只会更多，人民币汇率会大幅贬值，然后贬值迹象会导致继续有更多的人卖房换汇。 所以大幅印钞的结果，不但救不了房地产，还会导致人民币屯强。（其实现在这种情况下，虽然很多媒体都说，国家不愿意看见房价下跌。但在我看来，国家更不愿意看见房价上涨，因为上涨一定带来套现跑路，汇率保不住。就像是假设现在股市炒到一万点，靠印钞，能继续炒高到两万点吗？光靠印钱，还不能能保证。你必须还得保证没有大规模的卖出套现。然而让大家都别卖根本不现实。涨的越高，越有人觉得这辈子的钱赚到手了，去国外享福吧。）(35赞)
