# 珍姐您好，看到新闻

(提问)匿名用户：珍姐您好，看到新闻说天津取消上千个事业编制，以为是假的专门上政府网查了一下，您觉得若干年后所涉及的范围地区会不会更广，改革会不会变得更深，例如Z_.F人员，如果是现在需要做哪些准备？
2019-08-03

回答： 【帖子编号0339】《事业编制》 特意搜了这篇文章来看。但是没看懂……到底是行政的编制还是事业编制…… 目前国内的编制有两种。一种是政府内的，就是公务员。另一种是不承担行政职责的事业单位，以前的科教文卫，承担一点社会职能的普遍是事业编制。 后者未来大部分都是要取消的。（这个话题，记得之前有一个职业规划帖子，是问去沿海的市级事业单位，还是去内陆的省级事业单位。我刚才在圈子里搜了半天，没搜到[发呆]不知道是不是星球的内容审核系统上线以后把我老帖子给删了一圈……） 现有的事业编制里，能市场化的肯定要市场化了，市场化之后就不会再有编制了。比如广电系统下面，电视台、广播电台，这种继续接受广电系统监管就好了，但是里面的工作人员没必要带编制，大家都是干活拿工资的。有些是社会福利性质，无法市场化。但未必需要“编制”这种东西的，比如小学老师，或者是医院医生。大家都是相同的岗位，非要用编制来说有的人带编制，有的人不带编制，这种也不够合理。还有一些冷门的，有社会效益，但是难以转型为经济价值的行业。比如之前提问的朋友是在气象部门。这种想要收钱也是可以的，所有天气预报付费提供，让手机厂商花钱买呗。不花钱的手机，查不到天气预报。但这么搞，就给社会拖后腿了，弊大于利。总不至于别人没交钱，连个洪涝预警都收不到，那社会得成什么样。所以必然是国家掏钱统一购买。但其实也一样并不需要编制。气象部门毕竟还不是肥缺，属于没有大油水 的部门。像是民政系统下，火葬场殡仪馆才是赚钱的……
