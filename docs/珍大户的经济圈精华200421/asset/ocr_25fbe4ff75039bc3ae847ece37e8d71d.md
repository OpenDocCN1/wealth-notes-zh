# 今年三月份在县城开

(提问)大白菜：今年三月份在县城开了一家女装店（在临街的老巷子，这个巷子以前人是非常多的，今年突然没人了）三月份的时候还有点人，四月中旬到现在基本没人，街上都空空的，每天就卖个一两单，有好几次都白皮，现在是在想，是女装店继续坚持到九月份看情况，还是七八月份装修改成一间童装一间女装？亦或者直接退出，我就是在想现在县城经济收缩，以后还会繁荣起来么？还有必要在县城坚持么？而且现在招聘好难，招聘信息贴了都有两个月了，一个应聘的人都没有

2019-06-15

回答：翻出来吧。没啥好解释的了，因为都是老观点。老观点一：服装店是旧模式，个体服装店是逆势而为，经营难度会比较大的。老观点二：小城市/县城的人口流出我确实觉得大趋势对人生的影响是很大的。所以这些观点，都是说的趋势性的改变。观点基本都维持稳定。（写完这段话，突然一瞬间担心起圈子的续费率呢[发抖]，毕竟经常变更观点在网会更吸引人，但是我是做不到了……）—————————楼来介绍一下县城的基本情况吧。比较重要的就是人口基数。基数三十万，状况改变起来起来是很快的，能肉眼可见的感觉人少了、商业环境萧条了。但也有些是一百万人口的大县，这种县还能再顶个五年十年都没问题。所以你们如果是前一种，那这店就早关了吧。如果是后一种，可以再坚持开几年。(15赞)
