# 这个不是要大户回答

(提问)奶牛养家里：这个不是要大户回答的、自助餐经营、200一人、进去收10元押金、又提到峰终理论、我也看到消费者的不满意本来是消遣结果变成监督、开自助餐的人好矛盾啊、是不是收费少了

2019-02-15

回答： 【帖子编号0235】 《自助餐》这个没太看懂你要问啥。我大概说一下自助餐。两个角度，商家与顾客。 商家角度：所有的自助餐，最终都是靠“量”取胜的。客流量少于一定数值的时候，绝对是亏钱的。只能靠客流量大时，才能赚钱。一方面，压低食材进价低，这个道理大家都懂，我也不多说。另一方面，人越多，总的浪费数值就越少。数学角度，一是取用过程中，产生一种“拼桌”的效果。同一道菜，有越多的人吃，浪费的人就越少。人越多，越能找到“最大公约数”。二是，到营业时间结束时，为了最后一批顾客的客户体验，你必须还要保证，每个产品上都有一些存量给顾客提供选择，不可能最后一个顾客刚巧把你所有的吃的都吃完了。所以最后关门的时候，总归是有剩下的要浪费“损耗成本”。假设每天关门的时候，要损耗掉X斤的剩余食材。 那么今天500个客人，平均到500个人头上是什么损耗成本。如果今天有1000个客人，损耗成本就会降一半。这就自助餐客人越多，成本越低。最终着眼点一定是：提高顾客人数。 而我截图的那家店，他们把着眼点，放在了顾客吃不完的浪费上。这部分浪费怎么解决呢？直接强迫顾客吃完，这是降低客户体验，让客户人数减少的措施，最终就会丧失了自助餐店安身立命的根本——“客流量”。 这期视频讲完时，评论区有人提到不同的操作方式，比如改为吃完奖励的方式提升“终值体验”。这种方式很聪明，但依然没有到本质。 本质上，应该往“峰值体验”上去考虑：聪明的店铺，应该在每天关门的时候统计一下，客人剩掉的菜品里，最多的是哪几样？ 客人
