# 珍老师你好，想咨询

(提问)人生长路漫漫:珍老师你好，想咨询下您的意见和看法。我有个很好的闺蜜，办了一家教育机构，主要以兴趣培训班为主，主营（钢琴，声乐，播音主持，中国舞以及素描），有一个合伙人，他们合作从开始到现在还没有一纸合同。有两个问题：1、他们所选的地段属于租户外来打普工人偏多，对于价格这块不能接受太高，但是请老师以及房租毕竟也很贵。有没有什么好的建议，具体能分析下最好～谢谢。2、她这个合伙人，个人是觉得：推责，也不自己代课，经常不来，有问题也不解决，还想拿钱，做会计工作的。就是对于合伙人，有没有什么你觉得需要必备的条件，或者说合伙人以什么样的身份或者什么样的条件来做约束。毕竟她一直都是自己办钢琴培训班，没有经商的管理和经验。2018-09-17

回答：【帖子编号0075】合伙人得是资源/能力互补，具有短期甚至长期不易替代的作用。如果仅仅是会计，代理记账毕竟只要200元每个月，作用实在是有限。对于教育行业，最基本的要素是人，优秀的师资是最应该列入合伙人的。如果老师够格，就基本经营没问题，可以成为一个小而精的小店。其次是管理者、运营人才，如果只定位于一家店，没有扩大规模，连锁经营之类的，这部分人是没没太大作用的。如果想要扩大规模，那么这部分人是，有必要列入合伙人的。最后是一些小部分，可有可无的，包括地区资源，有好区位的门店，可以成为小股东，但仅限于小店的情况下。(16赞)
