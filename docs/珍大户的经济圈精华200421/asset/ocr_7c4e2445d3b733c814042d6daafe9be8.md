# 珍大户，你好！请问

(提问)祖儿: 珍大户，你好！请问长沙靠市中心的江景公寓是否值得投资，价格2万左右，毛坯房，50到60平米之间

2019-04-17

回答： 【帖子编号0254】 大概率不值得。公寓产权的税很重，买来一定要认知清楚，就试图使用价值（自己住）或者出租价值（吃现金流的）。所以值得买的公寓，至少有这么些点： 1，最重要的：位置必须好。交通很便捷，所以你自助很方便，不住了出租租金也能租很高。 2，也是很重要的：性价比必须好。我们都知道住宅目前租售比都不怎么样。所以公寓必须要比住宅有折价，从而使租售比恢复到合理区间。

（公寓折价的原因是因为商业用地地价比住宅用地便宜，而且40年产权比70年也短很多，所以才折价） 此外还有造成租售比恢复到合理区间的原因，包括楼层挑高，比如4.8米或者5.2米，能做成两层，开发商送装修等等。 因为公寓的得房率极低，基本70%。你买50平套内面积才35。除非是买一层送一层的复式，能搞成实得面积50平的样子。否则根本居住不舒服的，反而很难租出去。 【概括总结：你买住宅，是为了图未来“房价上涨”。 你买公寓，是为了图未来城市“租金上涨”，买的时候算好租金收益率4%，预计有个三五年，随着城区发展，能涨到租金8%收益率，这就值得买了。】

所以，再看你这套，单价2万，跟住宅的折价空间呢？这可是40年产权！这可是商业性质！ 没有送面积，也没有送装修，那么等于光吃得房率低的亏了，一点便宜都没占。 你这房子迷惑性在于，一是靠近市中心，二是江景。我不知道靠近市中心，是有多近。但这两句话挺有迷惑性的，让人以为黄金位置，比较稀缺。 但实际上是不是真的黄金位置，和稀缺江景，就需要你仔细考虑了。 但就算假设是的话，不送面积的得房率就是35平，这房子只能你自己装修好用来做民宿，搞短租。否则长住的话真的太小了，影响
