# 你好！我今天和朋友

(提问)胡明君1326017*：你好！我今天和朋友探讨了一个问题，他在爱奇艺，他所在部门是做流量变现的。例如电影前面的那段广告。但是他现在的困惑是，当平台用户全部变为会员用户的时候，所有观众就会过滤掉这条广告。于是会员收入成了平台的主要收入来源。而他们却进入了困境。当然从公司角度讲，广告收入和会员收入都是成为公司业务收入。但是对他来讲那是其他部门的事情。他们部门该怎么办？请老师琢磨琢磨？

2018-11-16

回答：【帖子编号0173】有时候我想不明白，爱奇艺到底想不想赚广告费？广告从最早的15秒到30秒到60秒后来已经到90秒了……现在是不是120秒我不知道。因为我真的无法忍受已经办了会员。而且在我看来，这个广告，就像是根本不是为了赚广告费，而是为了逼着用户办会员的（谁愿意忍受的了那么久的广告呢）—————先说点题外的。小时候我妈一直教育我，做人要厉害一点，不能让人欺负，一定要让别人“怕”，才能不欺负你。我在上大学之前基本一直按着这个路线，确实挺凶。后来到了谈恋爱的年纪，才觉得有问题。难道结婚还要按照“驭夫术”一样，让对方怕我，在家里不敢发表反对意见，不敢出轨，什么都不敢吗？那么只有哪个男人特别倒霉，才敢娶我。这很明显是错的。而稍微一推延出去，人与人之间，非要东风压倒西风这种思路，也是挺可怕的。我妈一直耀，她工作的时候，领导怕她，客户怕她，因为有她“坐镇”，没人敢造次……可以想象一下，在她身边，是多么可怕的情景。人际关系上的这种逻辑，大家很容易想通。追求“谁压倒谁”的关系，肯定是有问题的（包括微博上各种“结婚靠不住，想办法转移财产在自己手上”的思维，肯定都是有问题的）。我们应该追求的是一种让双方都舒服的状态。如果我舒服，你不舒服，这种状态肯定是不能长远
