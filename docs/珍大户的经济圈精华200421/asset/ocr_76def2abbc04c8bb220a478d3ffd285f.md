# 珍姐你好，如何看待

(提问)希希宫主Nikita：珍姐你好，如何看待烟草这类国企垄断行业的将来，过去由于行业的垄断特殊性，行业福利待遇甚至一度超越公务员，如今商业的发展趋势，以及政策的调整感觉未来国家会一步步解除垄断的护城河，您如何看待这类企业的将来。

2019-07-18

回答：【帖子编号0323】《烟草行业》 不会的。烟草专营只会持续下去，不会拆除垄断的。国家从税收角度考虑，自然会想要有很多的专营（变向的税）。类似的产业可以分成三类：一种是，具有“自然垄断”倾向，就算不是政府专营，也会因为市场竞争、企业合并，最后变成一家巨头。这种在经济学上叫自然垄断，比如地铁、铁路、电网、自来水网这些，因为投资大，建了一条线路之后，别人再在同样位置搞第2条线路就是脑子有病。所以自然而然就变成一家独大了。另外，投资很大的产业，比如研发成本很高（如造飞机），比如设备投入很大（炼石油）这些都有这种趋势。对这一类来说，最终早晚都是垄断。与其让资本家垄断，还不如让国家垄断。-------------------------- 第二种，是不具备自然垄断倾向的，而是政府强行垄断。比如古代的盐铁专营等等。比如现在的电视台隶属于广电系统。大家念叨最多的是通信运营、中石化中石化，出租车专营这些。还有福利彩票行业，殡葬相关的。这一类，本身民营可以做，被政府限制了于是极大的降低了竞争，造成居民购买产品时，要支付更高的价格……等同于损害了全国人民的利益。解除垄断能对社会有利。所以一定是从这一类入手。-------------------------- 第三类就是烟草了……为什么不会解除垄断。因为这玩意是对社会有害的。解除垄断，让更多的企业进入，最终结果是国民吸烟率大幅的上升，二手烟比例更高，医保等项目，负担会更重。之所以没禁烟，完全是因为：第一，烟草税收比较高，国家经营
