# **感觉抖音要出大事，**

(提问)鵬大很幽默：感觉抖音要出大事，就是昨天我清理关注，我发现很多100万，几十万，甚至有两百万粉丝的抖音号，出现有的停更，有的没赞，百万粉丝作品有的几十个赞，是不是以前系统后台给他们刷的？现在不刷了？感觉大网红赞也少，没有太热门的话题和个人。用户量我现在捉质疑，大家都转站了？朋友们你们觉得呢？

2018-11-20

回答：【帖子编号0175】这事你发现的晚了。（这贴就当讲下抖音运营）今年4月份，媒体报道抖音的时候，我们才知道这个软件。因为想知道这东西为啥卡，就下载来看看。下载完第三天，F先生说我：你竟然每天晚上不睡觉刷抖音，还乐的哈哈哈，不对劲，太反常了。正常人肯定是说我玩物丧志，浪费时间。不过F先生说，如果我都 被吸引 了，说明这软件有前景，值得好好研究。然后他就开始使劲刷抖音了，基本上我每天回到家看到他的时候，连吃饭上厕所都手机不离手（花絮一句：后来有一天，他突然把抖音视频刷到底，再也无法上翻了，当时怀疑是库里的视频全刷光了，我们笑言——打通关了）在刷的过程中，就需要分析热门视频类型，大号的视频规律，需要关注很多的账号。我在去年年初的时候，写了一段时间的知乎和公众号。记得知乎第一天涨了1500粉，两周时间粉丝过五千了，到一两个多月的时候，就有一万多粉丝。到三月份，粉丝一万五之后，明显感觉到平台给限流了。又坚持到6月份，丝毫没有好转，气得我就直接搁笔了。F先生刷抖音的时候，看到不少账号，一条视频就粉丝过万了，于是就劝我开个抖音，说人家一条顶我半年[流汗]，让把我之前在知乎上写的怎么谈恋爱的内容，拿抖音上去说。我当然是不肯的。一把年龄了，搞个化名，写写文章是可以的，真要露脸上镜去当情感导师，那我肯定是不愿意的。F先生这个时间也没闲着，开始研究怎么发视频。我们
