# 老师，经济学和金融

(提问)戴广林：老师，经济学和金融学有什么区别？

2020-02-23

回答：经济学是研究“比较”的学科。在经济学眼里，什么东西都可以拿来比较。 比如，人和机器比较，汽车跟房子比较，什么都可以比。 但是不同的东西， 第一、在不同的人眼里，价值大小的结果不一样。 比如，一个女人和500只鸭子哪个更好？ 有可能甲就觉得女人好，乙就觉得500只鸭子更好，俩人答案根本不一样。 第二，因为“单位”不一样，所以没法进行数学运算。 举例，一个女人加500只鸭子等于什么？这俩单位不一样，根本没法做加减乘除，没法进行“数学计算”

（经济学里逻辑推导很多，但是纯数学计算很少）所以经济学分析间题，最后得出的结论，都是有很多前提条件的。 答案往往是：在a种情况下，应该如何如何；在b种情况下，应该如何如何……分析和论述的情况特别多，没什么直接数字结果。 金融先是把经济学研究的领域缩小了：只研究钱（货币、债务、股份）。你可以看成金融学是经济学的特例。（从这个角度看，金融学比经济学内容少了不少）在只研究钱的情况下，上面两个问题都解决了。 不管是甲还是乙，他们对钱的价值认知是一样的，一元钱纸币和一元钱硬币都是一元钱。 并且，钱还可以“用数学计算”…… 当数学计算搞的多了，金融学就衍生出了自己的研究方法，金融工程什么的。（从这个角度看，金融学等于比经济学又多了很多内容） 这就像是，<辟邪剑谱>出自<葵花宝典>的残本，在残本之上，又自己衍生出了新的东西，于是起了个新名叫<辟邪剑谱> 所以两者是有联系的。 ————————— 经济学比金融学研究的领域更大，除了钱、经济增长之外，人口、政府效率、社会福利、道德、法制、家庭关系，很多东西都可以纳入经济学的考虑。 金融学简单，就是计算钱，只不过要用高等数学。(97赞)
