# 开个高频消费品的炒

(提问)人生如梦:开个高频消费品的炒饭店，主要做美团饿了么外卖，有什么好的提议或者操作
2018-08-21

回答：【帖子编号0003】1，选好地点，尽量附近是办公区，或者学校。否则如果只有住宅区的话，单一品类怕是不好卖。2，本身是炒饭，顾客基本是“人懒又不挑剔”这类人，所以别考虑同时有太多选择(可以类比为，咸菜还需要那么多口味吗)，但是又要防止别人吃腻，又需要开发出不同的口味来。两者均衡，所以你可以考虑搞一周菜单，每天固定换不同口味这种，帮消费者选择的套路。(结合你选的地点，分析消费者群体。如果就是普通消费者，那么这一步就够了。否则还需要进一步设计)3，剩下的就是做质量了，比如，考察好大米的选择。如果真的用的米比较好的话，也一定注意重点宣传。(23赞)
