# # 老师你好，在抖音关

(提问)匿名用户：老师你好，在抖音关注你开始你的更新都是我必看的，讲的太棒了。有个问题想请教一下希望老师帮忙解惑，我是家里长期在海南做生意的，因为这两年经济不景气，海南房地产又因为各种政策涨的飞快，所以这两年把多余的钱投了房子和写字楼，在海口和三亚有几套房子和在海口一套写字楼，现在各种调控把整个市场搞得冷冷清清，心里对这个城市有点迷茫，请问老师对这边有什么看法和建议？房子是留还是抛？

**2018-09-11**

回答：【帖子编号**0060**】一般不太想回答具体的买卖问题，但是看到这个问题是付费提问[捂脸]所以专门回答一下。住宅这块，三亚建议抛，海口随意。因为，首先三亚的限售政策，对炒房抑制很大。但其实就算没有这个限售政策，三亚的价格也在很高的区间，风险蛮大。而且三亚售房的模式（旅游车拉一车游客去采新盘，然后人多闹哄哄的情况下，一人买就会带动一堆人买），显然对新房销售更有利，对二手房不是太友好。毕竟三亚购房大部分属于游客，游客如果买二手房，需要一家一家的去看房，花很长的时间去挑，所以挑二手房意愿会下降。如果扣掉房价上涨预期引起的炒房需求，那么就纯剩下养老和度假了。但这部分可替代的选择很多，高端去酒店包月，低端去民宅托月租。三亚的酒店这几年一直也在不断增加供给，未来东南亚（如泰国之类）和其他地区（如云南等）的也会导致三亚养老和度假需求的分流。像前几天我朋友去希腊买房，在雅典套内150平带装修的房子约200万人民币，还送欧盟绿卡，听得我都有些心动了。对尚在工作的人来讲，每年度假时间短，住酒店自然更划算。对退休的人来说，时间上限制较少，那么就可以考虑更多的地方。对于海口的住宅，只能说随意。首先，海口的房价目前在全国来看，并不是高。但另一个角度来说，也预期
