# 大户：你好，支付宝

(提问)匿名用户：大户：你好，支付宝这个短期收益大概有多少呢？能预估一下吗？谢谢□

2019-01-28

回答：【帖子编号0226】《货币基金》特意看了一下余额宝。收益太低了。 货币基金这些年基本都是万份收益每天一块钱左右，就是一万块放一天收一块钱，一万块十天十块钱，十万块十天一百块。（如果是问年化收益率，给个参考，单利3.65%的收益率就是一万块一年365块钱）不过这半年来，收益率下降，大部分货币基金的万份收益，都降到八毛五左右了。但是刚才特意看了下余额宝，发现万份收益只有0.66元[惊讶][惊讶][惊讶]，这个属于超级低了......真的没必要存了。 跟余额宝一样的，能随时存取的是货币基金类产品，想要方便的话，可以放在微信理财通里-货币基金里面，比较好的有“华夏财富宝”、南方、易方达。 微信理财通属于比较方便的。但是因为每日买入数量的限额。 钱多的话进出还是有些不方便。（印象中，大部分银行每天只能转5万进去，唯一不同的是，浦发银行每天能转60万进去，搞的我都动心想去办个浦发了）。所以钱多的话，也可以看一下各家银行的app，毕竟银行卖理财产品已经品种很丰富了。我没对比过太多的银行，平时就用招行比较多，所以理财的也比较经常在里头买。随时存取的，不少于3.6%、3.7%的收益（约等于万份收益一元以上的）。【大家还知道哪家银行理财产品很有吸引力，可以评论区说一下】————一般的货币基金，基本都是存入后，下个工作日起息。所以，如果周四存入，周五就开始计利息，那么周六周日也能吃到利息。 但如果周五存入，下个工作日起息就等于到周一了，等同于周末就浪费掉了。所以在长假期间，记得提前一个工作日存入，否则蛮吃亏的。（也有些银行迎合客户，改了规则，比如招行说是当天开始计息） 取的话，快速取出、立即到账这种，
