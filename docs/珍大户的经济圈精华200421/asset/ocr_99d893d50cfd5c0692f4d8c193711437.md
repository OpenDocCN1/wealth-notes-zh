# 刚才直播的时候，聊

珍大户：刚才直播的时候，聊了会智能家居。

结果我在直播的时候，F先生在收快递，买了一堆智能灯泡，换了家里的廊道灯，装饰灯，落地灯……目前都是语音控制了[发呆]

现在我家里客厅都是天猫系。各个房间里是小米系。唯一可惜的是，两边不兼容……

这玩意是有爆发的潜质，想想其实大部分人是不知道有这种东西的，也不知道有这种功能，但普及起来很容易，只要哪个电视剧里，插个演示镜头就能被观众知道了……

我现唯一好奇的是，除了灯、除了扫地机器人，还有什么可以智能的？
