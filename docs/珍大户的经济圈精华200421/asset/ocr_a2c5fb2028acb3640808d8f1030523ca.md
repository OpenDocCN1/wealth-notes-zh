# 姐，我现在遇到一点

(提问)喜欢海边喜欢浪：姐，我现在遇到一点问题。想咨询下您，麻烦您有空的时候给我解答一下，万分感谢。

我在一个集团下面的一个分公司A挂名公司法人，现在公司A注册资金3000万，实缴，我占45%，集团通过A贷款4个亿，没用我个人担保，是集团里的另一个实业钢铁公司担保。我感觉公司不太想还这个钱，我现在后悔，不想当这个法人，集团大领导安排不想当就得我辞职。我想问下，如果这个贷款还不上，是不是我有连带责任，会被执行失信人吗，对家庭有什么影响？

2019-12-16

回答：【帖子编号0388】《法人代表》稍微解释一下，大部分人都管“法人代表”简称为“法人”，这是错的（包括F先生也这习惯，我时不时就能听他说“我是法人”这种话，听的我忍不住吐槽……）。法人是指公司，意思是“法律规定，让你把这个公司当成一个独立的人来看”，因此简称“法人”。（你想象一下“假人”、塑料人、机器人之类的，假如法律某天突然规定，说塑料人就是人，简称“塑人”，享有跟人一样的权利。塑人可以去银行开个“塑人账户”，自己存钱；塑人可以买房，还不限购；塑人还可以当地主，雇佣长工了。大概就是这个意思……因为塑料人不会说话，不会签字。所以去银行开户的时候，需要一个“塑人代表”，去买房的时候也需要个“塑人代表”去代替塑料人按手印。但理论上来说，这个“塑人代表”其实是“塑人”雇佣的长工，来充当嘴和笔的功能而已……法人和法人代表，就是这个意思）—————————另一个法律常识是：每个“人”都独立承担责任（这里的人是包含“法人”的）。父债子偿是错的，因为父亲和儿子是两个不同的人。法人和法人代表，也是两个不同的人。所以公司欠债（法人欠债）就是公司自己的债，不会追到法人代表头上去的。所以法人代表不会被成为老赖，不会成为失信被执行
