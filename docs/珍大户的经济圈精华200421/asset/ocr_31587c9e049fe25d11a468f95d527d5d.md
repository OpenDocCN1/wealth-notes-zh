# 请问您知道整理师这

(提问)、媛媛：请问您知道整理师这个职业吗？我想问一下您，这个职业未来是可以发展的吗？三线城市可以发展自己的团队吗？是一个好的发展吗？谢谢！

2019-03-02

回答：超级小众的一个行业。一个新的商品或服务，我们首先要问他，需求是什么？目标客户在哪？我猜的这个领域的需求：一种是类似于日本人的情况，富足但是人均居住面积小，因此存在对整理和收纳的需求。另一种类似于美国人，富足且居住面积大，但是东西太多（记得看过一个八卦，说玛丽亚凯莉光真丝睡衣就有三千件），于是产生了整理需求。两种情况抽象一下，就会有一堆前提条件。第一阶段，先要富足。富了以后要物质消费。狂买东西。家里衣服一大堆，饰品一大堆，手办一大堆，收集的东西一大堆。第二阶段，物质消费满足了以后，要有隐藏的进阶需求出来了。要求东西开始讲究品质而不是数量，不是快销品，否则衣柜都是ZARA这些只穿一季的东西，没多久就扔了，也衍生不出太强的整理需求。一个人必须先认可自己东西的价值，才可能继续为这些东西做后续支出。其次要求居住环境，整洁、美感，甚至是艺术感这些很虚拟的东西。这些范畴，已经脱离掉实用性了。对于生活要求还停留在以实用性为主的人群，是不可能有后续的进阶需求的。—————我知道说完上面这些的时候，大家可能还有些摸不着头脑，因为概念太抽象。那么我举一点实际例子。大家找阳光灿烂的日子，在自己的城市走一走。看看每个小区，阳台窗口，上面是否晒着红的绿的各种颜色的被子？或者小区楼下两棵树上挂根绳，晒被子晒床单？这种行为是很影响美观的，但是，大部分人认为这是有实用性的。再观察一下，各个家庭的阳台，是不是都是升降晾衣架？上面挂满了颜色各异的衣服？像旗子一样飘飘荡荡。这种行为，依旧是影响美观，直接牺牲了阳台
