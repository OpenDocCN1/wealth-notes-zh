# 珍姐好，我在成都，

(提问)嵐：珍姐好，我在成都，现在有两个offer。一个是国内私企的培训行业全外教的教學督導（不包吃住6000左右）。一个香格里拉的宴会销售主管（包吃住过后到手4700左右）两个不同的行业。不知道选哪一个会发展更好一些

2019-03-12

回答：前一个好一点。原因：1，岗位属于偏管理的，对个人提升更大。2，培训行业属于轻资产，高利润率的。如果没野心，在这里跟着公司走，如果公司能做大，你个人的收入空间也是有的。如果有野心，这个行业领域是支持个人创业的。（其实培训行业一直是比较容易个人创业的行业）第二个工作，酒店的这一块工作内容是很边缘化的。未来对公的商务会议，估计要渐渐的对接给商务会议服务公司，由会议服务公司承担起从承接客户，到会场布置，礼仪服务，鲜花礼品纪念品采购，宴会安排等等一条龙服务。对私的，比如婚宴，估计对接给婚礼服务团队了。所以宴会销售的岗位，未来是有可能消失掉的。（当然，也有可能香格里拉就自己搞子公司，专营商务会议服务。但仍然可以看出，这个工作肯定不是香格里拉核心的职位，随时可能消失掉。）(25赞)
