# 珍姐，怎么看现在朋

(提问)匿名用户：珍姐，怎么看现在朋友圈流行的轻断食，酵素减肥产品，例如森米等诸如此类。属于大健康方向吗
2019-09-09

回答：【帖子编号0357】《无效不等于没市场》 这玩意儿根本不属于大健康的方向，但不代表没前景。因为用户的需求太蓬勃，市场本没有那么多“符合大健康方向”的产品出来。市场需求就摆在那，就算没有酵素减肥这种产品，也会有其他产品。———————— 记得2017年，我开了个公众号想写点文章。F先生为了表示对我的支持，于是花了点时间去研究各个新媒体平台的状况和规则。研究了不记得多久的时间，他突然跟我说，想到了一个很容易赚钱的方式。当时他他发现头条的文章都是机器推荐，阅读量很大。当时写头条文章的写手都是挂官方广告，赚点击量的广告费。他看到广告费的价格就动心思了，但不是想赚广告费，正相反，他看见广告费的价格，就觉得广告费太便宜了。靠写文章赚广告费的话，怕是累到吐血也赚不了多少钱。但如果广告费便宜，就意味着有利可图。他说，我们可以去买别的写手的广告，然后卖暴利的产品赚钱。 所谓的暴利产品，互联网中就几种：减肥产品，丰胸产品，迷信产品。然后他就去阿里巴巴上找各种瘦身减肥丰胸的产品。找了一圈感觉没什么进展。这时候就显示出我们自身能力的弱小了。因为我们都没在生产型行业待过，如果完全考虑自己生产产品，属于无从下手的那种。（其实也是因为当时衣食无忧了，所以行动力下降，太难的事情也懒得做了。如果还像10年前那么困难的阶段，估计再难的骨头也去啃下去了，没准就去自己开发产品去了）而完全当一个二道贩子，卖别人的产品，又很不放心。总觉得能找到的都是三无产品，有点不太放心。虽然这个业务就算真做起来了也是悄悄摸摸的私底下运行，不会被人知道，也不会有名誉影响，但是仍然觉得卖三无产品不太
