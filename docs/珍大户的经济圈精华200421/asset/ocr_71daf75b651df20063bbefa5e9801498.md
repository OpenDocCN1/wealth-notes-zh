# 珍老师，各位前辈，

(提问)元桃子：珍老师，各位前辈，我在河南的一个地级市当老师，现在学校在建教师公寓，价格较低，但没房产证，需要一次性交清，如果购入的话，也是作为投资备用。我现在学校附近有一个待装修的婚房，预计装修费用得20万左右，所以现在在犹豫，学校的房子要不要购入，购入之后家庭没有一点流动资金了，还需要贷款。

2019-01-23

回答：过去几十年里，很多 人的财富来源都是因为有单位集资建房和分房的渠道，因为低价购入了房子，后来若干年房价大涨，于是虽然工资不高，积蓄不多，但是家庭总资产丰厚。但是 现在我们必须看到，后面还想重复“房价大涨”的路线不太可能了。所以这种低价的集资建房还买不买呢？我的建议是： 如果你们学校是高校/大专、在郊区，那么买来没什么意思了。 如果是高中（有陪读的家长什么的）、在市区，那么就买。因为这个房子没有房产证，就等于没法买卖（就算买卖，因为办不了房产证，也会按市场均价大幅打折），所以这个房子的价值就在于使用价值。所以最终思考的结论，就是看房子好租出去吗，租金收益怎么样。租金划算，你就当买理财产品了。 我观察的一般是高中的学校比较容易出租，因为会有家长觉得高中宿舍居住环境不好，影响学生高考，所以原因付租金租房子。其他阶段，初中、大学，似乎都没有这种需求，学生或者家长租房子都是很零星、很偶然的，这种属于今年租的出去明年就未必租的出去，空置时间很难控制，那就不是 一笔好投资。(30赞)
