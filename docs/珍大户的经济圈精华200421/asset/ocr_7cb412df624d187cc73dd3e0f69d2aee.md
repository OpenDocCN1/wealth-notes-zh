# 同学们好，我这边是

(提问)逆 光°：同学们好，我这边是三四线的小县城。现在经营一家120平米的儿童摄影工作室。定价在我们这边相对高一些。但是一个月赚的不少，要怎样经营好一些呢？没知识没文化，第一次创业有点没有头绪。希望看到的给点意见哈

2019-07-18

回答：【帖子编号0322】（照相馆）直播的时候，说了个结论，就是：照相馆会比较难经营了。除了一些少数的场景的，比如高校附近，给学生拍职场求职使用的证件照。这种是带有强烈目的的，是自身包装的一部分。和面试培训、演讲培训、化妆培训这些，属于类似的需求。但除此之外，如果仅面向个人用户的拍照，这种只会觉得越来越难经营了……去不去照相馆，取决于几个差值：1，个人的照相设备，和照相馆照相设备的差值。2，个人的场景环境，和照相馆场景环境的差距。3，个人的服装道具，和照相馆服装道具的差距。4，个人的化妆打扮，和照相馆化妆打扮的差事。5，照相技术因素……论设备，10年前手机照相才刚刚开始应用，5年前手机的拍照的画面还是渣渣，当年还流行什么单反穷三代的说法。但是现在手机拍照水平已经开始pk掉一些入门相机了。入门的相机也让人不至于咬牙就能买得起了。论场景，家庭装修突飞猛进，外出旅游越来越普及。连消费场所，比如咖啡馆都能变成拍照场所。论服装道具，网上瞎买，百十块钱买个一次性的服装道具，还能开心一整天。比去照相馆省钱多了。（前几年还流行过宠物照相馆，是给猫给狗照相的，有各种可爱的狗衣服和狗道具。后来好像也没戏了。一想就知道，自己买回去自己拍，狗子在自己家里反而更放松，更容易出各种表情）目前还没被突破的，大概就只剩下化妆和技术，这两个比较虚的因素了……中国人化妆的年代太短。上数N年，流传一种说法，说上海女人很时髦。因为当年其他各个城市的人都是素面朝天的，也就上海女人
