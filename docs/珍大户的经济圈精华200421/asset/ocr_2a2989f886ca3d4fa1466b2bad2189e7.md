# 【关于镜头恐惧症】

(提问 a 1 陈浩：【关于镜头恐惧症】第一次提问，不知道能不能被翻牌

提问：我是在浙江温州做微课幕课视频录制的，帮助一些教育机构和企业单位录制课程和培训展示，刚开始做。——那么问题来了——在课程录制过程中讲师都有一种面对镜头的不自然，眼神会飘来飘去就是不能注视镜头，导致后期的剪辑效果就无法直视，珍妮老师，您平时在录制 DY 时是如何做到面对镜头做到这么自然，可以分享一下从不自然到注视的过程吗，谢谢！——

2019-10-31

回答：【帖子编号0373】《练眼神》 我上初中的时候，我妈在海南做实体行业：开酒厂（以前提过，后来倒闭了……）那时候每到展销会，我就得去当童工站台。到了逢年过节，还要去当地最大的超市去当免费促销员。这种事做多一段时间之后，我妈就开始批评我了。她说别人一眼就能知道我是没社会经验的小屁孩子，太嫩。原因是，我那时候很害羞，只要别人的眼神一看到我，我就尴尬的用微笑演示，或者干脆低头躲避别人的眼神，或者眼神瞟向别的方向（比如眼神转到产品上，或者手里的拿的什么东西上面）。我到现在还记着她说的话。她说，你躲什么眼神？别人看你，你就得看回去。互相大眼瞪小眼，就一直瞪着不要停。谁先眼神躲闪，就算谁输气场……然后她指着电视上采访海航集团陈峰的节目举例。我印象极其深刻，陈峰在整个节目中，说话时基本不眨眼，眼神及其的凌厉（大家好奇的话，现在也可以搜一下有陈峰的视频，我觉得一个人的特质习惯可能很难改变，估计现在还能看出来）。她说，看到没，人家的眼神盯着别人时，可以连眼睛都不眨，能把别人盯到汗毛倒竖的人，肯定是个大人物，绝对不是个普通人。这句话我是真听懂了而且印象很深刻，然而离真学会还要很久。
