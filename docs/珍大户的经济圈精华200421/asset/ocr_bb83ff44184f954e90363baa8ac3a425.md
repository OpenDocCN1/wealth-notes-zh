# 珍老师您好，想咨询

(提问)微笑以后：珍老师您好，想咨询一下，就是公寓和住宅的区别，公寓以后是不是和住宅的差异会越来越缩小呢？现在有的公寓也有双气，民水民电，生活成本小很多，价格也要比住宅便宜不止一点点，要是投资需要注意些什么呢？谢谢您！

2018-10-31

回答：【帖子编号0157】 公寓这个，政策可变性太大，所以我不敢说什么。 虽然我家也有买公寓，但纯粹是从消费的角度考虑的，因为不想跟老人住一起，租房又怕他们有芥蒂，所以买公寓，面积小，总价低，带装修，自住比较方便（说起来又像是给老人买套房的，好听，其实连真房子的价格零头都没有）。如果他们不往的话，因为500米内有不少写字楼商场，按装修水准，租给单身的，出去应该也挺受欢迎。但是从投资角度，我是不怎么推荐买公寓的。 单纯去博取政策变更、重大利好，那太不确定了。（就跟博拆迁房、博划入学区房一样，谁能说得准呢？陆家嘴那边有些老房子，从九几年开始，就户口冻结迁入，准备拆迁，口气准备了二三十年，都没拆迁成，当年等待拆迁结婚的小伙子，都熬成老头了） 如果不考虑政策变更，那么公寓就和商铺、写字楼一样，纯看租售比，别考虑升值。另外，写字楼和商铺都是有明确用途的，你选的写字楼比其他写字楼好租，你选的商铺，比上其他商铺好租，这就算跑赢了。公寓你还得考虑一下，比住宅出租也拉进来当竞争对手，所以很多细节都需要纳入考虑，如果周边住宅很多，有可能就租不出去了。另外，就算买公寓，也一定要买纯居住用途的公寓，“商住两用”这种东西一定是坑，办公一定会影响居住，居住一定会影响办公，最终是造成无论租给住户，还是租给公司，都很难提升租金。 其次，最好是开发商都设计装修好的。因为很可能没有“物业”，造成无人协调管理，装修吵闹，劣质装修气
