# 您好，大户姐，我是

(提问)高德东：您好，大 户姐，我是旅游专业批发商，在这互联网发展的时代，机票，酒店，景区，车队，都可以在网上预定，各种成本都非常透明的情况下，传统旅游批发商将何去何从
2019-02-17

回答：会渐渐消失。其实很多批发商都渐渐没了，最传统的服装批发，已经有很多商家都放弃了。批发商属于处于中间的流通环节，互联网就是在创造新的流通环节，取代旧的流通环境。旧的信息流通环节最容易被颠覆，然后是实物流通环节，最后是服务流通环节（最后这个是比较难以被完全颠覆）。所以……没法逆转。这种趋势下，说什么提升服务质量，提高附加价值，基本都是无用的废话，趋势不可逆才是真的。————————圈子里第一次出现这个行业的提问，我也不能这么快放过你[偷笑]打听一下，你所说的批发商是批给谁？下游客户是谁？你们是携程艺龙定酒店时显示的“某某平台/某某旅行社”吗？能否找到其他行业的业务对接人，比如联系各个城市的婚庆团队，搞蜜月旅行定制业务。各个学校/辅导班，联系寒暑假旅行业务。各个美容院/整形医院，联系处境整形游业务。各个医院/医生，联系出镜割肿瘤业务等等……？这些新的定制服务或许能拜托批发商的定位。(30赞)
