# 大户老师，想问你是

(提问)easy：大户老师，想问你是怎么选定抖音这个来营销自己的？为什么不去一些知识类的媒体？如果我想针对大专、本科学生做营销推广宿舍清洁服务，应该怎么玩？

2018-09-27

回答：【帖子编号0112】因为抖音有【红利】。红利这事儿必须要说一下。大家觉得红利是什么？其实就是短期的市场供需失衡。抖音有巨大的用户量（需求者），但是在我讲的领域内，基本上没有供给者，没人跟我竞争，或者竞争者水平太渣渣（等同于没人跟我竞争），这就叫红利。我们是在4月底刚注册的抖音，那个时候刚一上抖音就惊呆了。看到了抖音上出名的“黑脸V”和“会说话的刘二豆”，当时是什么感觉呢……“黑脸V”的特效水平非常的简陋，可以看出是初学者，但是竟然能有2000万的粉丝，这就是红利带来的。因为当初抖音上没有这一类型的题材，他就是唯一，所以获得了巨大的红利。F先生刚好认识一个特效行业的从业者（自己开公司带领特效团队的），非常牛。他给北京奥运会开幕式做过特效，还给很多大片做过特效，比如成龙的《铁道飞虎》，最近的《阿修罗》等等。很多大片儿都是他带领的特效团队成果。F先生赶快找到这个朋友，让他立即做抖音。结果不巧的是他那段时间还比较忙，结果在提醒了两次以后，也没见这个朋友有动作（其实都是借口，本质上，还是没有对【红利】的影响力认识不够）大概到了六七月份的时候，特效视频这个小品类下，已经竞争到白热化了，无数的特效师疯狂涌进斗抖音……到9月底，F先生和这个朋友又碰了一面，这个朋友后悔得直拍大腿。如果当初进入的话，他现在应该也会有几百万粉丝了吧，至少小有知名度，那么再去跟甲方谈合作的过程中，也会有不少优势（他们这个行业，甲方常年是大爷……）而现在再开抖音的话，难度要比当初大了很多。你看，这就是【红利】。或者说先发优
