# 亲爱的珍大户，我现

(提问)A 宠物店～嗨宠宠物*：亲爱的珍大户，我现在在苏州相城经营着一家100多平的宠物店，主要做的是洗澡，美容，寄养，物品，活体，店里目前只有一个美容师+我两个，每个月的营业额6万左右，净利润在2.5万左右，似乎是到了个瓶颈，一直想突破，但目前就是一直这个样子，最近接触了狗粮代工，发现市场上狗粮猫粮乱价不说，品质太差，放弃一部分利润，猫狗可以吃的非常好，所以我有打算去做一款自有品牌的狗粮，猫粮，让至少自家的猫狗吃的放心健康，再一步步的渗透周边(初时采取免费试吃一阶段，是否可行)，不知道这样的方式是过于理想还是可行？
2019-10-21

回答：【帖子编号0368】狗粮猫粮这个领域确实大有可为。以猫粮为例。猫的饭量小，一个月就四斤的量，所以很容易让用户接受品质上升（换句话说，用户对价格不会太敏感）。对比来看，如果让一个人把自己的伙食由一顿30块钱预算提升到一顿50块或者100块水平，难度就大的多了。（就类似于，愿意买名牌口红的人很多，但是买名牌衣服的人并不多。因为一件tom ford的西服几万块，而一个tom ford的口红才四百，所以入门真是非常容易。）——所以，看你是想做小而美，还是想做大。如果只是为当前的宠物店做利润提升，做小而美，只覆盖周边的用户就够了。那么可以考虑做手工猫饭/狗饭。塑封冷藏，有一定保质期这种。然后每周配送，或者每双周配送一次。对用户来说，内容看得见，并且与固体颗粒状的猫粮狗粮相比，有一种“消费升级”的直观感受，【心里满足感】会很高。所以销售难度会低很多。（注意最好是开封即食的，一定不要再二次加工。不要加重用户的使用麻烦，毕竟猫粮狗粮作为一种伟大的发明，最大的优势就是方便快捷，解放主人的双手）但如果仍然做成传统的颗粒状狗粮的话，销售难度就要大很多了。对用户来
