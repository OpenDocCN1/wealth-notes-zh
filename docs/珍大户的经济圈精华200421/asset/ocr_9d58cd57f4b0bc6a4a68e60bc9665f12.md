# 老师您好，我是从抖

(提问)迷失的兔子: 老师您好，我是从抖音过来的，看完您的视频让我受益匪浅，脑海里突然又有了想做点什么的想法。我在一个沿海三线城市的事业单位工作了十年，班上最有意义的事也就是考考证吧，慵懒的生活让我和社会脱节了十年，在商业上我是纯小白。问题可能有些空洞、外行，希望您别见怪。如果开发一款互动性较强的APP，我大概需要投入多少资金，而且我不具备这样的专业电脑知识需，需要怎样的渠道雇佣或构建一个客户团队呢？软件内容构思我大概有了，但是我第一步该干嘛□？

2018-11-10

回答：【帖子编号0168】 □脑子里突然想起了“完事具备，就差一个程序员的笑话”目前开发app是投资蛮大的一件事，几百万打底。但最重要的问题不是钱，而是，对电脑盲来说，有很多路上的坑绕不过去。第一点就是，在你过去的工作经历中，应该没结识过几个特别让你放心的程序员，那么就需要自己去招聘。而对外行来说，鉴定一个人是优秀程序员还是半瓶水程序员，是一件盲人摸象的事情。这两种程序员，从工资上来说，差距可能未必很大。（如果你有关鉴别能力，找到靠谱程序员，那么每月其实多付不了多少成本）。但导致的结果是，事后成本差距很大。对一个app来说，最初的框架做出来很容易，但当使用人数达到一千人，一万人，十万、每增加一个数量级，对软件的兼容与稳定都是一次考验。初期的框架做的不好，那么后期就要花更多的时间和人力去修补，对服务器的投入也会更大。（软件公司，时间和人就是最大的投入，一个10人的团队，每多工作一个月，就要烧掉至少十几万工资。所以前期软件构架设计的好，后面每省一个月的时间，就是省很多钱。前期设计的不好，那么后面就要烧钱修补。修补不好，就只能大更新，推导重做，然后用户数据平移）第二点就是，目前的时代做软件依然是
