# 珍姐，今天有个新闻

(提问)Fan：珍姐，今天有个新闻说房贷可以变更为与LPR挂钩，您认为这个变革的目的是什么？对买房者来说是利还是弊呢？长期来看（比如30年）LPR大概率的趋势是升还是降呢？谢谢您！

回答： 【帖子编号0415】 以前贷款是参照基准利率，以后是参照lpr利率。为什么要改呢？因为基准利率是由央行自己决定的。而lpr利率是由央行+十几家大银行共同报出来的，等于央行在放权。央行代表“政府”，大银行代表“市场”，所以从基准利率过渡到lpr利率，其实就是从完全由政府定价，换到政府+市场共同定价。物价已经脱离计划经济时代很多年了，大家都忘了当年物价局定所有物品价格的时代了。这次是利率作为“钱的价格”，开始逐渐脱离“政府定价”，其实这就是利率市场化的过程。如果简单理解，那么把存量房贷，由基准利率体系换到lpr利率体系，就像是考试分数体系的换算。就像是以前只考语数外，后来改成素质教育，要加考你音体美了[偷笑] 那么说，你以前语文90，折算音乐也给你90分算了。 具体怎么换算，参照这个帖子 ———————————————— 选择换与不换，提问中问到关键了：未来30年大趋势是升还是降。之前有一个帖子，是我推荐大家进圈子必须要读的，利率的本质：利率的本质，是分享经济增长。我出钱，你出力，大家一起赚到钱之后，分我一部分。这就是利息的本质。所以在农耕时代，因为经济基本没增长，所以借贷很难繁盛，衍生出的都是趁人之危时敲一笔的高利贷。如果刨除高利贷，那么在低经济增速时代，利率都会超级低…… 就像日本，买房利率只要1.5%，跟白给的似得。 ———————————————— 所以，未来30年利率会怎么变化，这个问题的本质就变成了：未来30年的gdp增长会变成什么模样[偷笑] ———————————————— 我简单说一下，大规模的经济增长有
