# # 理财公司已经开始延

(提问)domperidon* :理财公司已经开始延期兑付了，起死回生的可能性大吗，作为公司员工（非销售）应该怎么办？

2019-05-10

回答：【帖子编号0271】（95%）没戏的。（还有5%遇到强势国企/省国资委收购注资什么的，概率跟娶到白富美、嫁给高富帅差不多。）出现延期兑付后，两个影响，几乎不可能活得下去了。一个是挤兑，一堆人到门口拉横幅讨钱，不管到没到期，肯定开始急着要钱。另一个是，后续经营会受影响。毕竟，如果是实物产品，比如说卖拖拉机的企业，如果现金流出问题，不至于让买家担心到不敢来买产品。那么公司就还可以继续运转。然而金融类公司就是这个问题，一旦现金流出问题，就没买家敢上门了。所以就算第一关能捱过去了，陆续有回款能后续兑付成功，公司也会因为第二关，难以继续正常经营了。基本都是死。____________ 你上次我说的正常情况（明面上能说的）还有一种无法明面说的。有些理财公司，经营并不正规，资金去路不明，借新还旧。这种公司，等到很多人收不到钱时，一堆人报案后，有可能会被定性为非法集资/诈骗案件。那么在里面的员工甚至都是有风险的。（5年前一般这类案件只抓法人高管，不抓普通员工。但今年有扩大迹象，一抓抓一票人，所以员工也有风险）（但并不是说你们公司一定有风险。如果不是资金投向不明确的话，那么没这种问题）____________ 但总的来说，依然是早跑为妙。(22赞)
