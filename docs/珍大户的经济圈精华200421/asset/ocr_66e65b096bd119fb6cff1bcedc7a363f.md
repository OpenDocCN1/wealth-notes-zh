# 老师你好我是做护肤

(提问)膜法诗品牌负责人-杨*: 老师你好
我是做护肤品品牌的 目前只有一款面膜洗面奶
主要销售渠道在微信
我感觉护肤品品牌很难做出差异化区别其他品牌
老师有什么建议吗
2018-09-10

回答: 【帖子编号0056】 替你惋惜一下，这就是属于不懂商业常识，进错了领域选错了路。 如果产品难卖，你个人就算有一百分的努力，最后结果怕是得分也不会太高。 相反，如果产品好卖，就算个人没有100%的努力，结果也会好很多。 护肤品是一个大的体系，最好的产品框架肯定是多重品类的组合，每个产品吸引到不同的人，再基于此互相转化，提升总体销量。 如果只有单一产品，那么你能吸引到的客户就会少很多很多很多……缺少了协调效应。 这是单一产品的缺陷。 而在只有一款产品（本就没什么优势）的情况下，你该选择什么产品？ 实际上最应该考虑，这个单一产品的吸引力有多大。而现在这个时代，实际上很大程度上取决于竞争对手多寡。 护肤品里，最底层的产品就是洗面奶。为什么，因为，第一，他的门槛太低，已经做滥了。第二，顾客已经相信这种在脸上停留时间很短的东西，是没什么技术含量的东西，所以很难靠它形成吸引力。 你能见到一千块以上的面霜，但是很难见到200块以上的洗面奶。虽然你说的是面膜洗面奶，我猜可能是清洁作用的面膜，或者是涂抹性质的洗面奶之类，但清洁作用已经属于最底层的需求了。所以在产品矩阵里的作用，要么是做赠品，要么是跑量——顾客买本品牌其他产品的时候，顺带来一支洗面奶，那么销量就大了。 这种产品，甚至不属于我说的预防定价中的用来做低价的选项。因为这是别的品牌拿来做赠品的东西，客户是没有什么忠诚度的。所以，这种产品是不能拿来当打开市场的拳头来用
