# 您好老师，我是做餐

(提问)铁金光乐麻辣香锅：您好老师，我是做餐饮小吃的，现在餐饮不是很好做（也可能是我没做好），小吃这个行业也需要创新，包括口味型式品类方法什么的，我重点说品类，因为我发现很多小吃项目是根据溶器而来的或者是有关联，比如鸡公煲，火锅，麻辣香锅，铁锅焖面，瓦罐等等，我就想可不可以吧我们的溶器特定化，略微的改一下，然后把它申请个国家专利来减少被抄袭，被仿造，让它成为一个新的小吃的项目，最后在做这个项目。老师你觉的我的这个思路行不行？

2019-06-15

回答：【帖子编号0300】《专利保护》外观的更改，一般是申请“实用新型专利”，不是大家认知里的发明专利。这种是可以申请的。难度也不会太高。但周期会比较长，审核起来有可能个把年，等是等不起的。其次就是线下的保护力度，需要靠自己去打击模仿者，这种难度是挺高的。类似的就比如，一个街头小店，拿着刘翔的头像做广告，刘翔是很难发现，也很难去举报或起诉的。前几天例子里提到眼镜店，我就突然意识到，街头很多“宝岛眼镜”，很多都是冒牌的。这种对商标权和肖像权的侵犯，就和你申请实用新型专利后，将会遇到模仿者的境遇类似。但这种专利仍然有必要申请。优势是，第一，在线上还是挺方便的。尤其是在淘宝平台、京东平台之类的，因为有一个平台方，投诉或者诉讼都更容易一些。可以直接下架对方的商品。所以，如果你的产品有走网络渠道的话，这可以大大减少竞争对手的数量，不至于让你家店被淹没到数据海洋里。第二，街头小店模仿你的话，你管不过来但大的商家，你还是可以去管的。比如有个厂专门批量生产你的器具，或者有个商家拿你的创意去发展了几十几百家加盟商。如果这种规模的仿冒，就得过去管了。说到专利，圈子里有知识产权律师，申请时可以找他们
