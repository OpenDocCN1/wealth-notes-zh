# 我想和3到5个朋友

(提问)匿名用户: 我想和3到5个朋友一起合伙开酒店管理公司初始投资在500万左右一家酒店总投资估计在1500万左右其余缺口我有其他拆借资金渠道，年利率在10个点左右，如果我们初始投资不够会追加资金，这个公司用来投资加盟中端连锁品牌如丽枫，亚朵等，位置是广州或深圳或广东省内，现在位置没定所以品牌也定不了，我想问我们如果3到5个人股权架构怎样合理，其中有甲一人在行业内有工作不能抽身有相关资源和人脉懂行业运行融资等事情都是他来运作提供资源，其中乙可以出人对接公司业务，但乙没有相关资源不懂管理运营目前也只有乙一个人有时间可以出来对接公司业务，其余丙丁等人都暂时出不了人，一，问现在加盟这种中端酒店行业可以吗在广东哪里最好？

回答： 【帖子编号0384】(股权分配) 最简单的一个方法，把整个股权划分为a、b两部分。 a部分完全按投钱比例多少来分配。 b部分为管理股权，谁出力给谁。 比如ab比例为80:20或85:15或90: 10之类的。因为酒店是重资产行业，最主要还是钱来说话的，人其实并不是那么重要。 (ps, 我怀疑你那个借1000万，最终要个人连带的。如果最终算成是你个人借款的话，那么你的最终出资额要加上这一千万。 如果是只以公司名义借款，那么就大家的出资额都不用算这1000万) 最终a部分的比例是按你们“出钱”决定的。 而b部分“出力”部分，则是变动的。 因为管理者未必永远是当初那个人(包括说的“提供资源”。有无数的负面案例，因为前面说给资源结果给了股权，最后资源毛都没有，或者跟承诺的差距很大，然而给出去的股权不好再要回来，最终就是股东之间产生矛盾……) 所以这部分股权，可以由谁代持一下，然后公司章程里约定好这部分属于管理者奖励部分，每年股东考核后发给管理人。 具体甚至可以约定更细，比如带来融资分
