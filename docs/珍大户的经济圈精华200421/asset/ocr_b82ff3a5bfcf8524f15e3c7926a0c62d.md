# 珍大户好，我爸在学

(提问)在田：珍大户好，我爸在学校，学校宣传一个私募融资，说可以投，如附图，然后去对应的银行问了人，说是镇政府做的。请问有什么风险吗？谢谢。

2019-12-23

回答：【帖子编号0390】<城投债>有风险。这种叫城投债，就是各级政府的国资委设立的城投公司，以公司名义对外融资，投资于当地的城市建设项目。一般大部分的城市的基础项目，都属于免费公益的，没有收益。所以也不像高速公路或者铁路之类的能收费还钱，最终还款都是由政府拨款到这家公司账上，然后再还钱。12年以前，各级政府还常常发个公文，以“承诺函”或者是“支持函”之类的政府公文的形式，说某某政府会“支持”某城投债的还款。但即便如此，在投资过程中，依然要做最基本的调查。常规调查包括：1、看过去三年的当地财政收入有多少，其中有多少是卖地收入（卖地收入不可持续）、有多少是正常的税收收入（税收收入一般可持续、不会突然缩水）。再看当地财政支出有多高，毕竟各级公务员的工资都是刚性的，根本没法压缩。2、看当地有多少家城投公司，所有的债务累计有多少？看债务负担比例高不高。因为……即便有承诺，也是需要实实在在的钱来还款的，如果政府钱不够，掏不出来钱，你又能那他怎么办？你也没法把政府大楼拍卖了，只能干瞪眼。后来14年之后，明着的是，国家严格限制政府出担保函，意味着不希望各级政府无限借债下去，暗示未来有可能会出现在不上线就让城投公司破产的状态。暗着的，是各家金融机构对各地调查，发现很多地区的隐形政府债务很超标了，也开始暗暗担心。所以开始逐渐减少、限制对城投债的投资了。很多常规的做法，就像是民间流传“投资不过山海关”这种顺口溜一样，城投债的规避原则包括：县级的不投/小城市不投（更严的甚至只投省级的）、偏远地区不投/西部地区不投/云贵川蒙藏陕甘
