# 珍姐：我在小县城经

(提问)夜面人：珍姐：我在小县城经营一家酒店 价格两百多 另外有两家酒店竞争对手 一家握有垄断性的政府资源 一家比我地理位置好 我新装修的硬件要好一点点 小地方人口很少没啥流动性消费能力很差 我现在客房入住率很低 我不想打价格战 但是我不知道该咋整？ 望指点迷津 2018-12-11

回答：你房间装修啥样，发个图来看看，省份也说一下。 很多三线+的地级市，两三百块是打折过后的四星级的档次。 所以我确实想了解一下当地的行情，感觉两百多块不便宜了。 所以，计算一下你的酒店房间数量有多少？初始投资大不大？目前有几个员工？这部分问题不用具体回答，但需要思考考出一个结论，现在酒店有多大的折扣空间。 当地可能没什么旅游资源，与其他城市的商业往来人群也不太多，那么，可能本身目标客户群体就不大。具体要不要打折，需要区分对待。 第一部分：先是针对旺季刚需，就不用打折的手段了。刚需，诸如已经迁走的本地人，逢年过节，回乡走亲戚的，还有什么办婚礼需要入住的。 第二部分：挖掘一些本地的需求。降价需要针对这部分人。 试试白天的钟点房（针对已婚出轨的或是未婚约会的），还有打麻将的房间（想办法把一些社交场景搬进去）。跟来的人聊聊，问他们还有什么需要吗，手机号登记个会员这些地方，搞定向打折。 再想办法琢磨下周围的学校、医院这些地方，一方面，这些学校医院其实是有兄弟单位之间的交流的，而且也未必跟政府是同一个资源，未必被你的竞争对手全部占据。另一方面，或许有家长，或者病人看护的住宿需求。 如果当地有什么公司的话，也联系一下，给他们个协议价。 最后，传统的网络平台（携程艺龙团购点评）都上了吗？聊胜于无吧。(12赞)
