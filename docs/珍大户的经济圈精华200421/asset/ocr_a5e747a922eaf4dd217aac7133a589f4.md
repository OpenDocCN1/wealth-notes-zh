# 大家好，今天看到一

(提问)阳光：大家好，今天看到一个加盟项目，是做云纸的，就是在公共厕所的厕所，提供云纸智能硬件，用手机扫一扫即可1秒免费取纸，加盟商通过扫码的客户得到公司的流量变现的提成。

因为没接触过这种流量变现的项目，所以想请教一下，这种项目可做吗？

2019-09-24

回答： 【帖子编号0363】 《流量变现逻辑》 现在很多人谈流量，但是流量不是必然有价钱的。有没有价值，要思考流量背后的【变现逻辑】是否成立。我举个例子： 很多年前，有种商业模式，是印免费报纸在地铁里发，因为地铁里流量大，坐地铁的人没事儿干，就愿意领个报纸， 随手翻翻，翻完扔到垃圾箱里就完了。看免费报纸的人多，报纸有量了，就有人投广告。印报纸的人靠着边广告费变现。 然而，这是很多年前的模式。2011年之前我还住郊区的时候，是喜欢路上领一份报纸看的。因为当年，手机还是诺基亚……每个月的流量也没多少，手机还是要省着用的。所以愿意领免费报纸。 之后我就几乎没怎么坐过地铁了。但是猜一下也知道：现在手机流量如此便宜，谁还愿意看报纸呢。领报纸的人少，最后报纸全都落入收废品大妈手里了。之后就是广告商不会再继续投广告，那么这套模式就玩不转了。 到合肥以后，地铁线都是新开通的，我和F先生就去体验了一把，结果又见到发免费报纸的了。 既然地铁线都是新开通的，这个报纸必然也是新创办的。我本能的就在想，哪个创业团队这么天真，竟然还照搬n年前的老模式搬到合肥， 却不看看外界环境已经天翻地覆，变现模式很难继续成立了。 \_\_\_\_ 我们再来看一下免费厕纸。来思考两问： 一流量怎么样？ 二变现逻辑成立吗？ 美国所有的厕所都有卫生纸， 在国外待久的人突然回国时，会遇到一种坑————上厕没带纸。然而，国
