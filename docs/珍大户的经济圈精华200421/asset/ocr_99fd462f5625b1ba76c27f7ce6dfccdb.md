# 大珍，您好。我身边

(提问)静潼：大珍，您好。我身边现在有很多中大型美容院、健身房这种服务行业的店家都在做合伙人计划，就是让会员买股份，让一些会员成为股东。我想了解，这样的合伙人计划可能会 出现弊端在哪里？还有如果之后让员工认购股份的话，可能存在的弊端都会有哪些呢？

2019-08-16

回答：【帖子编号0345】《找谁入股》 很久以前，我跟一个朋友聊天。这个朋友是传统行业的（酒店行业的），完全不懂金融，知道我懂，就问了我在一个问题。他说，网上一堆人说的上市，到底是什么意思？为什么要上市？我说我拿你在的酒店行业来举个例子吧。假设一个小酒店，年利润100万，意思是你作为这个酒店的老板，每年可以赚100万的利润。这是突然有投行的人过来，把你公司搞上市吧。上市估值20倍市盈率，意思就是，按照利润的20倍买你的股权。这不就等于，一下子把你未来20年能赚到的钱，几天一口气给你咯。你拿着这20年的钱，可以提前退休了，也可以再去重开一个年盈利100万的小酒店，这样等于你未来20年就赚双份的钱了。我这个朋友想了半天，说那买股票的人不是傻吗？我就乐了[偷笑] 后面再深入的解释，我就没有做了。但很明显的是，如果一个企业上市，不是圈钱的，至少要有几个条件：1，成长性。现在年利润100万，未来预期年利润1000万，这时原股东才不会把自己的股份全卖了养老。（必须要用原股东的贪婪，来让原股东继续工作）（否则就不能给他高估值，给7倍pe都嫌多）2，进入壁垒。原股东拿着旧公司卖股份的钱，立即搞个新公司出来，那旧公司价值必然贬值，买旧公司股票的人就等于套住了。解决这种问题的办法，不是搞什么限售制度。而是要找有进入壁垒的行业。没法很快另起炉灶这种。壁垒可以是因为政府限制的行业；可以是原公司已经占据了市场份额，挖不动墙脚；可
