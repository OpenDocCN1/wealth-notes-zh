# 珍妮姐，固安的房还

(提问)阿柯:珍妮姐，固安的房还有升值空间吗

2018-09-30

回答： 【帖子编号0120】 《一线周边》 一般不回答某地的房价问题，但这个地名我犹豫了一下，然后特意搜了一下固安在哪？ □ 发现是在北京市中心向南60公里的地方，这就涉及到，一个城市的最大辐射距离有多远了，能否辐射到直径120公里？ 这让我想到今年早些时候的一个消息，在今年年出的《上海2035年城市总体规划》，金山区，由原来的“新城”级别，降级为“核心镇”级别。临港主城区（滴水湖）降级为“南汇新城镇”。 意思是什么呢？上海最南边的金山、奉贤，现在是农村， 十年后还会是农村。上海已经放弃这个地方了。这片区域，距上海市中心大概也是60公里的位置。 而在这一前，上海是有很大的雄心壮志想要开发的，但终于意识到了困难，因为经济规律不可违背，超出某个距离，效率就降低了。 一个城市的辐射区域是有限的。一个主城区比较可能的辐射范围，也就是直径50公里，半径30公里。 超出这个范围，就只能考虑卫星城。 就像是生活大爆炸中几个主角所在的城市，帕萨迪纳，因为有加州理工，靠着高校优势，带动了一批科研产业，于是这里成了洛杉矶地区的明星小镇。 能否成为卫星城，首先要有一些自己的优势，如果什么都没，单靠距离，那是没有任何可能的。(55赞)
