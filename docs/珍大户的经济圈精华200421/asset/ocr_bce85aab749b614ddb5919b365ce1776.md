# 老师你好！从抖音看

(提问)Boss机《羅茗》：老师你好！从抖音看了你的视频！你好厉害啊！学位那么高！

像你的这个知识！定价99，然后增加50个人就加价10块！怎么不定价199，298等！这是什么思路啊！

2018-08-29

回答：【帖子编号0023】《星球定价》从产品的角度来讲，知识星球不是一个标准的产品，每天的内容都有增长。而内容是用户交流的过程中逐渐产生的，所以必须对早期用户给予补偿。从用户的角度来讲，早期什么都有没有的时候就敢付费进来的人，必然更可能是铁粉才会付费。后期人数多了，会有人是从众进来的，所以我也愿意给前期用户优惠。当然，上面这两点，是从公平和同理心的角度考虑的，未必具有普适性。大家进来肯定是想要听干货的，所以我再说点有普适性的。知识星球这个界面，能看到简介和人数，价格，最新贴的摘要，和精华帖的数字。把它当作产品来销售，就要仔细考虑这几个因素对客户的作用。假设这个东西最终定价298，那么前面购买的人是最犹豫的，因为收到的信息有限，不确定值不值。而后面购买的人看到已经有一堆人认可这个价值了，而且精华帖数量很多了，反而犹豫的小。（参照因素或从众心理皆有之，所以才会有淘宝上刷销量的，网红奶茶店雇人排队的，造成一种火爆的样子）。根据上面的分析，前期的销售速度肯定会慢，而很多围观群众看到销售慢，就更加会产生质疑。所以降价促销，积累前期种子用户是有必要的。（但我肯定想把优惠先给铁粉，所以就需要在简介上不能写的太吸引人[捂脸]等涨价之后再修改成吸引人的文案，这算是内心的小九九吧）那么问题来了，为什么不先定99，满足一定人数后在直接涨到298呢？之前在抖音评论区，就有过几个评论说，一些饭店做活动打七折就有人来，活动结束就没人来。只好不断做活动。这里反应了一种
