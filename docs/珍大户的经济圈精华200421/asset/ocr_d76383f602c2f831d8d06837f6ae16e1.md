# 珍姐，你好！我想问

(提问)Zuohong：珍姐，你好！我想问一个困惑的问题，我1981年生，四川人，在重庆上的大专然后就在留在重庆工作，目前在一家德企做工业设备销售，年收入25-30w（税后），迷茫的是我有没有必要提升下学历？如果有该怎么提升？另外公司销售按区域划分设立办事处，在西南区域就我一个人，就是说在公司没有向上的空间的。慢慢有销售人员的恐慌，麻烦帮忙分析以后怎么转行之类的呢！谢谢！

2019-01-15
