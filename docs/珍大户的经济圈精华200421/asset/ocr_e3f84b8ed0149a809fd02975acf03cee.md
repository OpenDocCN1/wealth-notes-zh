# cpa和司考

(提问)宵夜：cpa和司考
2019-05-23

回答： 【帖子编号0283】 大的原则：看身边，哪种人少考哪个。 原理——（从升职竞争力的角度考虑的）
小的原则（假如你身边有这两个证的人都不多，或者都很多，按照前面大原则“人多 人少”的考量，没法做出选择的话，参考下面的点），看你的岗位性质。如果是跟人打交道更多，考司法考试。如果是跟钱打交道更多/跟贷款的事前审核有关联，那么考cpa 如果是跟贷款的事后跟进处理有关，考司法考试。 以上是从工作中实用性的角度考虑到。

——— 至于提问中间到的考完有没有用？在工作时，懂得更多，多少会觉得职业硬技能会有些提升。但是能不能升职加薪，这点不一定。还是取决于环境中的竞争力，大家都没有，你有的话，那么会加分不少。 ——— 最后，如果要考司考的话，参考听免费网课就够了，但一定要把笔记做全，否则内容太多，没多久就忘光了。(15赞)
