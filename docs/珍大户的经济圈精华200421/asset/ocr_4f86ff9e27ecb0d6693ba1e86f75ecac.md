# 应该卖房子投资理财

(提问)白慧捷：应该卖房子投资理财产品，还是出租房子收租金？

在重庆有一套全款购买的房子，每个月收租2300元，现在要养小孩压力很大，还请了阿姨带小孩，想多挣点钱，是卖房子投资理财，还是继续收租金？

2020-02-05

回答：【帖子编号0403】<房租天花板> 重庆还是人口流入地区，房租就还有上涨空间。是不是人口流入地区，大家自己感觉下：找工作的年轻人多不多？二三十岁单身的年轻小姑娘/小伙子，这样的租客比例越高，未来房租就越可能上涨。（因为他们还处在收入的快速上升期，说白了房东的租金收入，其实就是捆绑年轻人的工资收入……）相反，如果这类人群占比不是很高，房租后续上涨空间就很有限了。三四十岁拖家带口的，再租房就很难承受房租的大幅上涨的。租金涨不涨，其实就是房东和房客的价格博弈。

__________________ 房租最高能涨到多少？——平均月收入的一半左右。房租占月收入1/3是宜居状态，极端情况能占 2/3（纽约/伦敦这种城市，未来北京上海估计也这样）。但新冒 出几个新一线城市，就是靠宜居吸引人的，所以不太可能到2/3。我预期未来房租会上升到人均收入的40%-50%水平，另外还要叠加一个人均收入上涨的过程。比如，未来几年，人均收入会累计上涨50%之类的。------------------- 我不知道现在重庆的房租水平，盲目猜测一下，你房子可能是两房或者三房，两人合租的话，每人1000出头的负担是很轻的。你会发现过个两三年，整套的总房租很容易就3500+了，然后再过两年就4500+了…… 相反，理财利率后面基本不会涨了。那么以这套房子现在能卖出的价格当做本金，你可以计算一下当前的收益率（租售比），以及未来预期能达到的收益率，做个对比，就能决定了。__________________ 再说过花累。我
