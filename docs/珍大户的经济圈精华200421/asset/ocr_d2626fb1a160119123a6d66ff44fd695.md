# 珍老师：能不能聊聊

(提问)小杜：珍老师：能不能聊聊中欧国际工商管理学院EMBA含金量，我现在领导在上他们这个课，我很好奇这个有啥用，学费贵的吓人/捂脸……

2019-07-13

回答：【帖子编号0315】〈EMBA〉EMBA我真的了解不多。 毕竟27-35岁的企业中层去读mba，40-50岁的高层去读emba，宣传和定位一般都是这么分的……所以我是够不上那个级别，也就没接触过。 但是两个年龄段和圈层的人群有明显不同，所以需求也是不同的。 像读mba这种，平均工作年限在5-7年左右，基本是刷学历+提升工作竞争力，目的是为了升职，或者跳槽。那么选择是比较多的。 真狠下心来，工作一丢，去香港或者国外读一年书然后职场重新新开始，也不是不可能。毕竟工作年头短，沉没成本低。 所以虽然mba也挺贵的，但是还会受到其他各种竞品的价格所限制。 但是到EMBA这种，就完全不同了。年龄最起码40岁以上，工作经历20年+，这些人的沉没成本是极高的，所以绝对不会放弃自己已有的，跑去国外读书什么的。等于没有外界竞品。这些人里，有的就是自己的企业，有的是职业经理人，但职位上升空间也基本到头了，想跳槽的概率也不是太高了。 那么目的，就不是学学历（四五十岁的人还需要学历干嘛呢？），也不是重新创业或者升职或跳槽，毕竟沉没成本太高。 emba目的很精准，基本是做资源整合。每个人进校之前，都觉得自己是自己原有的小圈子里的人中龙凤了，但不知道别人都是做啥的，想去看看，了解了解。万一发现更好的项目，万一有人牵线搭桥，赚的钱肯定比学费多多了。以“学习”为名的资源整合。 与此类似的，上海松江的高尔夫俱乐部算是。以“休闲”为名的。会员费也要上百万。（当年f先生很想去看看，跟我说这要是就5万8万的也搞一个玩玩呗，结果进去一看……根本不是我们能消费的起的东西[流汗]） 这次去杭
