# 我是健身房主管，之

(提问)郭静: 我是健身房主管，之前一直做教练现在做管理没有什么经验，想向您学习一下如何经营一家健身房，怎么样吸引客源留住访客成为我们的会员，然后以怎么样的销售模式吸引他买私教课程，现在这个小区住户只有一百户，6月一日交2期房我想做一批预售，卖一些健身卡，我们健身房没有游泳池，附近一公里有一个健身房有游泳池，年卡2580两年第一年免费，两年以后再办年卡是2580，请问我们该怎么定位，我们的卡卖多少钱合适，以这样的模式更有竞争力，我想本小区业主交房时，送一批优惠券，三张卡起购再送一千块钱私教课程优惠券，我们这边房价是一万六一平，针对这些人群如何做一个方案，以这样的思路做呢。

回答：【帖子编号0288】这个提问，很明显属于一个不合格的提问[偷笑]但是分析这个提问不合格的原因，其实很有代表性。提问中确实暴露的，是非常普遍经营思维、竞争思维的短板。我们从几个部分分别看。

# part 1

先说缺点 先看看题目中透露的有效信息。只有三条。 1，小区住户100人。 2，对手的定价2580元。 3，当地房价1万6（想靠房价来推测人群消费力）然后提问是问：如何定价，如何做营销。 这种思路是有弊端的。定价要是考虑顾客的接受度，在能接受的前提下，尽可能价格更高，赚到更多的钱。 但不是顾客有钱了，他们就能接受高价。更不是比对手便宜了，顾客就能接受了。这就假设自己就是顾客，来用挑剔的眼光来检视一遍自己。 自己怎么样才是最重要的。（在具有压倒性的优势的时候，你甚至可以完全不用考虑外界。无需考虑你的竞争对手，也无需考虑别人接不接受你。这不仅是在商场中，在人与人之间也是如此。 很多时候我们见到某些人有强大的自信、强大的气场，不畏惧一切外界眼光，这是建立在强大的自身优势之上。这种人，是可以不需要分析
