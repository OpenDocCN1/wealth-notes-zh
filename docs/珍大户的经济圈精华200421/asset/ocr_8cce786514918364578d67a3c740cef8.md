# 大户，码农频繁跳槽

(提问)匿名用户：大户，码农频繁跳槽到底好不好？我发现有的人一年跳一次，工资是涨的快了，但是感觉对简历不好。没有积累，而且感觉哪里都差不多，都有问题和好处

2019-01-26

回答：【帖子编号0225】《跳槽》珍惜能够频繁跳槽的行业吧。 因为加薪全靠跳槽（本质是招聘方的市场竞争）。 很多人以为， 薪水取决于行业技术含量——越是高精尖的行业，收入越高； 薪水取决于供给多少——求职人数越少收入越高； 薪水取决于自身学历、能力等等——海外名校会明显提升收入。 我给大家举一个反例。 2015年的时候，上海大飞机公司，做研发的工程师还是只有5000块的收入。并且这又是欧洲留学的水平，学费教育经费砸了一百多万人民币供出来的顶尖校硕士。 因为没法跳槽，全上海就只此一家招聘单位，你不去就没地方去。 全国范围来看，也不过三家招聘单位，另两家分别在成都和沈阳。 这种就业市场，是没有讲价条件的。 给你五千你也得应着。否则就只能放弃自己的学历，去干一个完全不想干的行业去。 汽车行业也差不多啊。上海、广州、长春几家就没了。但数量至少比造飞机的多多了。所以造飞机的年薪7万，造汽车的能年薪二三十万。 况且因为大部分是合资企业，不是所有领导岗位都等着国资委指派，所以还有一定的晋升管理岗位的机会。迎来升职，还能有一波涨薪的机会。 ------------------ 另外，对不少hr来说，本身水平也没够到能够准确判断求职者的能力，所以大部分HR其实是参考上份工资来定价格的。这就造成基数低的人很吃亏，往往要连续吃很多年的亏，才能渐渐缩小差距。 鸡肋行业跳槽涨幅30%以内。很多行业跳槽涨幅30-50%。 抢人的行业或许可以开到涨幅50-100%。 如果起薪低，基本只能靠跳槽来救济。如果跳槽次数不够，等着让HR们破格给你提升薪水是不太可能的，因为对HR来说，这要让他们承担更多的
