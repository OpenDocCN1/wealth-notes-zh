# 老师您好，给一些小

(提问)viking: 老师您好，给一些小微型公司个体做代理记账的工作有没有前景，本是代理了部分小的公司个体，但近年大量出现很多极低价格做代理的，竞争之下不好扩展。想问下这个行业以后会是什么前景，有没有适合的衍生产品或服务可以固本增收一下～

2019-11-20

回答: 【帖子编号0380】《人工智能先替代谁？》 四五年前有个国外的新闻，说人工智能将取代交易员、分析师、律师、会计师等等。 刚好前三个都跟我有关，后一个又略微了解一些。所以我是确实在思考过，自己的工作到底有没有危险…… 拿提问中的代理记账公司举例： 目前国内的代理记账公司，基本都是承包小公司的会计业务，按月收费，每个月费用从150-800之间，大部分都是200-300元。 从好的角度说，虽然每个公司只收两三百。但是基本都是同时承包七八百家，每个月二十万的营收，而且业务及其稳定，不用像别的行业一样担心淡旺季。 但从坏的角度说，这就是一个完全劳动密集型的行业，公司数量越多，需要的人越多。 而劳动密集型行业，也往往是技能重复度高，是最容易被人工智能取代的。 （同理还有银行的信用卡中心。银行的信用卡中心，按说应该属于总行的某个部门。应该在银行总行才对。 然而大部分的信用卡中心都是独立于总行，独立的办公楼，与银行总部完全分离的职场，并且人员大部分属于劳务外包。 只是因为，银行总行是资本密集型行业——“人数不需要大规模增长，就可以管理10倍的资产，从而增加利润”； 而信用卡中心是人力密集型行业——靠叠人力增加电话营销/催收密度，从而增加利润。） 人力密集型行业，因为工作的标准化程度高，可以被电脑分析替代出标准环节。也因为人力成本贵，只要标准化了，就可以大规模的节省人力成本。所以这是最容易被人工智能取代的行业。 记账公司也是如此。
