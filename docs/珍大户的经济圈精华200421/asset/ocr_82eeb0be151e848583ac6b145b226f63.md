# 大户老师好，我想答

(提问)M：大户老师好，我想咨询一下外汇可不可以炒，我家里有人在炒外汇，说是某东南亚国监管的，受那个国家的法律保护，然后他是投入了十万，选择了一个操盘手，一个月能有一万左右的分红，现在要拉我一起做这个，我想问一下这个原理是什么啊，靠谱吗，谢谢大户老师

2018-09-07

回答： 【帖子编号0049】先说逻辑，再讲现实。从逻辑上说，股市是“正和”游戏（就是赚钱的人和亏钱的人家加一起，最后余额是正的，因为正常来讲，上市公司的分红肯定会比手续费高）。期货和外汇是“负和”游戏（不算手续费是“零和”，就是赚钱的人，赚到的就是亏钱的人亏掉的。但考虑到手续费以后就变成是“负和”了，亏钱人亏的钱还要扣掉手续费才是赚钱人的钱）。正和和负和，导致的结果就是，股票市场上，或许还可以有合作的可能。而期货和外汇，是万万不可能合作的。就拿你说的例子“投十万给操盘手，每个月分红一万”，月收益超过10%的操盘手，分析一下，为什么这种人会缺钱呢？为什么还要帮别人赚钱呢？我们可以猜测一下： 第一种可能，他会说缺少本金。但一个缺少本金的人，是如何练就出的操盘本领呢？你相信一个穷光蛋生下来就会交易？ 第二种可能，他说觉得接客户的钱能“管理”更多的钱，拿客户五千万肯定比自己的50万赚钱快。如果是这样，他就不可能十块的账户都接，因为手上账户多了，切换会很麻烦。而如果他真有稳定盈利的能力，凭着交易记录就能去敲动可以去正规的大基金公司的门，一样可以“管理”更多的钱，顺便还有大几十万的底薪外加奖金。为什么不这么做呢？ 因为他肯定有正规金融机构看不上的地方。标准的考核不仅要看能否盈利，还要看回撤（是否剧烈亏钱）。这种所谓的“操盘手”说句难听的话，都是被挑剩的残渣，都是因为没有责任心，觉得拿着客户的钱，赚了自己
