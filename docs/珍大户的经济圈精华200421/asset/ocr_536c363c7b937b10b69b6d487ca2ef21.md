# 珍老师您好，在抖音

(提问)叶巍穗:珍老师您好，在抖音发现您后觉得您真是一个宝藏女孩，果断加入星球，刚加入不久我朋友就遇到了一个创业上的问题，请教您一下。她是学美术的，在重庆洪崖洞有一个小门面，给游客画漫画像，画一张大概十几分钟，由于重庆近几年很火网红城市一到节假日特别是洪崖洞网红景区人流量相当大，所以生意不错，平时生意也不错。最近有一个财大气粗的老板在她门面对面盘下了一个更大的门面，而且请了15个画师，其中有2小有名气，有一个画师在抖音有十几万粉丝，算是小网红，现在她们在画画实力上不相伯仲，但是她们没有大老板有钱，大老板就想把他们挤出这个景区，并且霸占她们在朝天门另一个景区的位置。现在该如何做呢？她想在抖音当网红思路对吗？

2019-07-13

回答：【帖子编号0317】（形象营销）女的？你知道那种民国风的衣服吗？上半身青衫下半身长裙，穿上再画画。记得让她留上长发，直的，不能烫。如果化妆，只往白了化，不要往彩了化。（形象参考南笙、张辛苑）摆出一副文青的，不食人间烟火的样子，继续画画就行了。对面的画师比不上的。 ———————— 她这种业务，搞什么抖音、当什么网红是没意义的。首先，她没有持续的潜力。就算抖音一时火了，也只能像摔碗酒一样。吸引一时的眼球可以，但用不了多久就会被观众忘掉。（相反，如果能有的持续的潜力，那么值得经营抖音。经营是有价值的）其次，如果没有持续潜力，那么，爆红最大的价值是带货。比如你是某个厂商，生产某种产品，那么带货价值是很大的。抖音火了后，月销几十万件xx都是可能的。所以就算不持久，但至少能赚几个月的钱。这是商人经营抖音的价值。而这个画师小朋友，15分钟一幅画，一个小时最多4幅，产能又无法扩大，火了有什么用？
