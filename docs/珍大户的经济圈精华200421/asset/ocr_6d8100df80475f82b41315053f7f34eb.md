# 珍姐姐，您好，想请

(提问)小嘛小二郎:珍姐姐，您好，想请教您的意见，是关于我老公个人职业规划的，请教的问题是:1新媒体渠道销售风险怎么样？2.应不应该合作还是重新谈判或是待在单位寻找其他机会？

2019-06-19

回答: 【帖子编号0301】融e购是什么渠道？我是第一次听说。但天猫店铺是知道的，按照天猫店铺来判定，这种条件是有问题的。想起旧帖子0038，评论区写的:【经济学中一直认为，合作的力量一定能带来效率的提升，最终是所有人都收益。但分工与合作能够进行下去，必须要让人有信服的分配依据，如果参与者觉得分配不公平，那么没人愿意合作。以我们国家为例，在分工与合作过程中，最大的问题是利益分配不均......】这个提问里，明显看到开出的条件是有很大问题的，所以我不认为这是一个能进行的下去的合作。先说天猫店铺的分工:整个产业链如果简化一下，应该是产品从生产商到天猫店铺再到买家手里。举例，我床头刚好有个放衣服的筐，用这个筐当做做一个商品，来举例:假设:生产者人力/材料等生产成本20元——》出厂价格35/既天猫店铺进货价格——售价52/既消费者到手价格。前一个环节（从20~35元的过程）是生产环节，厂家在这一环节利润15元。后一个环节（从35~52元的过程）是流通环节，销售商在这一环节利润17元。电商最基本的模式就是这样的子的。在最初竞争不激烈的时候，开一个天猫店铺，线上自带搜索流量，产品自然就卖出去了。天猫老板也不需要操心什么自媒体，只要雇美工，把店铺装修好，雇客服，把顾客接待和打包发货之类的事情处理好。然而天猫店铺越来越多，线上搜索出来的流量，被越来越多的店铺瓜分，每家如果只靠平台自带的流量，每个月只够个低保收入，饿的半死不活。这种结果就是我之前说过的，淘宝/天猫的红利期已经过去了，没有优势的
