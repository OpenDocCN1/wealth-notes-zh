# 珍姐，能不能分析一

(提问)可可咪咔:珍姐，能不能分析一下跨境电商行业发展潜力？发展成熟的亚马逊和速卖可能需要强大的资源优势，能推荐一些市场空间和前景的平台吗？

2018-11-24

回答: 【贴子编号0177】跨境电商，现在大家就把它当成十年前的淘宝——仍处在红利期。是把传统的b2b外贸模式，改成b2c的对国外的零售模式。考虑现在做不做跨境电商，大概就跟你十年前要不要做淘宝，类似的分析思路——优势是有红利，能够赚到钱，劣势是，难以形成资源的积累与沉淀(做淘宝沉淀的客户，不算沉淀。客户随时可以转头去别家)。关于个人发展，我认为大概是分几个阶段的。第一阶段，肯定要先去找，这个社会有什么还没被人注意到的高利润的产品，或者是还没被人做烂的低利润，且能够迅速做大销量的产品——之所以用词说是“产品”，而不是“行业”——因为，倒买倒卖来钱快[捂脸]。第一阶段的目的，是赚足本金。到第二阶段在考虑长远的发展，资源的积累与整合。当然如果第一阶段实在找不到，那么就老老实实的工作，咬紧牙关存钱。在自己工作的行业里，直接谋求第二阶段。记得前两个月，圈子里有个地产商家的孩子，问跨境电商。对这些起步点很高的同学，我是不推荐的，因为他们起步点很高，就需要眼光放长远一些，更早的考虑投入时间后，资源积累问题。跨境电商这事儿，现在是红利。但十年后，早晚小商家众多，红利消失，互联网巨头逐渐挤压小商家的生存空间。到了行业洗牌阶段，继续留下来都是鸡肋，除了存款，可能什么都积累不下来。但对于平民起步的同学来说，能留下存款就是目的。—————跨境电商，现在是要把中国生产的东西倒卖出去。大家现在看一下，抖音一堆商家开通购物橱窗，但是大部分人卖的，都是一些奇奇怪怪的几十元的小东西，我们看起来，很廉价的小玩意。但就是这
