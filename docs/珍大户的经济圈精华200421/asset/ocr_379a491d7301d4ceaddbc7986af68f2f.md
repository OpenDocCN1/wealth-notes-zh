# 未来三到五年LNG

(提问)阿修罗ciium: 未来三到五年LNG的市场会怎样?，相对于油品有更大发展的空间吗？
2019-01-30

回答：你这行业是好行业，不止三到五年，发展空间有可能超过十年的。一是目前基数低，还在刚起步阶段，随便搞搞都是需求迅速增加的阶段。在这个时间点，基本不用操心后面若干年的发展问题。 二是国内为了分散能源来源，必须搞能源的多元化，（我国过去用煤为主，因为是世界上的储煤大国，但是因为烧煤污染重、挖煤破坏地表生态等等很多原因，所以需要发展其他能源），单纯靠进口原油，风险不够分散。后续肯定要发展多重能源来补充，就像曾经的光伏和风电，能够发展火爆，也是国家在支持的原因。未来所有新的能源都是很有前景的，包括LNG，也包括核电。 第三，其实是预期。很多探测都说海底有巨量天然气储量。所以各个国家，谁都不想在未来石油枯竭之后，错失这个新能源的布局。（政治上也代表了国家的海权和世界海洋资源的争夺）所以，哪怕是现在LNG的性价比不行，也依然要支持这个行业的发展，现产生需求，然后需求带动上游的探测、开采，中游的提取提纯、仓储和运输，下游的使用和销售。
