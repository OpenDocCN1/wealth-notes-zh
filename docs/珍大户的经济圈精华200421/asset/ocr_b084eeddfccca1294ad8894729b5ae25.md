# 请教珍姐和各位大神

(提问)～～～：请教珍姐和各位大神十八线县城市县区月子中心能做吗？

2019-10-26

回答：【帖子编号0369】这几天被英国卡车发现39个尸体的新闻震惊了，然后看了关于偷渡客的评论和新闻。印象比较深的是，说福建某些小城市，人均收入也不低，也不是很贫困。但因为当地长期受蛇头洗脑，传递各种“国外生活就是好”的信息，结果造成当地民众都有一种“偷渡出去就有面子”的心里…… 很多年轻人觉得，别人都能偷渡成功我怎么不成功。偷渡出去的人哪怕日子过的苦逼，也要咬牙说自己过的好，然后摇身一变站在鄙视链的顶端，继续鄙视没偷渡成功的同乡，于是后面的人受制于这种氛围，又前仆后继去偷渡…… 越是在小城市，县城乡镇的级别，越容易被“一种观念”占据主流。不像大城市什么声音都有，早婚的也有，晚婚的也有，不婚的也有，丁克的也有。 越小的地方，往往只有一种“主流声音”。 所以在小地方的月子会所能不能开成，会有两种可能：一种是，当地的主流声音是：婆婆要照顾月子。如果不照顾，就要遭受周围人白眼，会被人说闲话。如果是这种声音占了主流，你的会所就很难开的起来。另一种是，如果当地主流声音开始把住月子会所当成一种新的炫富手段，就像结婚开攀比礼金，攀比婚车婚房，攀比婚纱照和蜜月地点时，你这月子会所就厉害了。

小城市是很难按需求分析的。 如果按需求看，大都是本地居民，亲戚很多又都住得近，再加上普遍房子大、大多不怎么忙碌/时间充裕，走传统的在家做月子的模式就能化解需求了，月子会所根本没什么市场。 然而小城市是特别容易因为“只有一种主流声音”而产生鄙视和攀比，就会搞出各种额外的需求。 他们老家，据说结婚在礼金、婚车、酒席之外又衍生出新花样了，男方给女方家送彩礼的同时还要送各
