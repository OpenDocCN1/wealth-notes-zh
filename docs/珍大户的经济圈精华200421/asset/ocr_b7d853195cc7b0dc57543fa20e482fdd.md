# 珍姐，我注册了一家

(提问)Olivia: 珍姐，我注册了一家进出口公司，前两天有人打着两会的旗号说对小企业有政策扶植，让我去开个会，我没多想就去了。到了先是放中央电视台采访马化腾和58老板还有其他几位老板的采访视频，后来有一位叫陈紫云讲师的讲了互联网创业的趋势，举了几个做的比较成功的BAT(微信，支付宝，腾讯)致富的案例，最后就说政策扶植五个名额，一年优惠10000，要连续签三年的合同，然后我就签了。回去就发现被忽悠了，第二天要跟他们解除合同，可以扣掉违约金，可是他们不同意坚持让我去他们公司，我去后，领导不出面见我，其他的人说做不了主。报警应该用处不大，仲裁不知道有没有用？请问这样的情况怎样才能把钱要回来呢？
2019-03-21

回答：【帖子编号0243】《创业骗局》简单选项：如果合同里有违约金选项，而你要求解除合同，但是找不到对方的
人。这种的情况下，去邮局拿ems寄《解除合同通知书》，记得面单上要写清，邮寄的是解除合同通知书，邮局会有盖章。然后去起诉，要求对方退掉除违约金以外的钱。

难一点的选项：去法院起诉，具体的要求：因为订立合同前，虚假宣传，订立的合同里“显示公平”，依据合同法第54条，要求撤销合同。（视证据情况，不确定一定能胜诉）（我从你的提问里看不出太多细节，但是只做推测： 1，他们宣传时候是给“政策扶持名额”，这里的政策应该是政府的扶持政策了。但是与你签合同的肯定是一个公司主体，那么公司是没有资格做这种承诺的，所以肯定是虚假宣传。（但他们肯定不敢把这种话写进合同里，所以要求你要想办法录音录像，保存证据。现在没有的话就得想办法重新收集）2，他们在合同中肯定不会写明“交一万给扶持名额”这种一眼就能让人发现bug的词语。所以，合同里你花1万元，对应的是什么服务呢？这部分是用来主张合同“显示公
