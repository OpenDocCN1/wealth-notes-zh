# 家里父母存了一辈子

(提问)张威龙: 家里父母存了一辈子钱买了一套商品房，现在房子存在质量问题。是该找物业还是开发商。该怎么有效维权。

2019-05-29

回答：【帖子编号0286】维权找开发商，物业基本无能为力。 如果是能修补的小问题的话，基本以“投诉”为要挟，去闹一闹就能解决了。可以打个市长信箱热线什么的。 但如果真是房屋质量的大问题，怕是就很难弄了。 一个原因是，监管部门本来应该属于利益第三方。但是因为有审批、验收的环节在，一下子被卷成相关方了。真出问题 时，肯定是有责任的，所以更有动力去掩盖。 另一个原因是，涉及到需要赔偿的人数很多的时候，法院就喜欢“多想一步”，怕每个人都赔很多钱，把企业赔垮了，所以人越多越不敢使劲判赔偿。 律师基本都躲着这种案子，因为人太多，每个房主都想拿意见，意见极难统一，吃力不讨好，总会闹埋怨。 如果是钱多也就罢了，钱还收不到多少，又牵扯到跟某些 部门交恶的问题。于是基本没律师管这种案子。 所以基本是制度问题。明明是经济纠纷，出事了就赔好了，赔不起倒闭嘛。结果，减少了经济赔偿，增加了行政问责，就出现了阻力。 怕企业倒了影响当年的就业，就不怕住几十年的楼倒了影响到人命。 想起某个社会学的观点，大概说的是：人类的愚蠢就在于永远只解决当前，而不把未来的问题当问题……(56赞)
