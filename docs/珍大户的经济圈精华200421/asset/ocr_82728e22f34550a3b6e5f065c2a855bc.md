# 珍姐，我是一家城商

(提问)哈哈□：珍姐，我是一家城商行职员，现在做授信审查相关工作，工作到了瓶颈期，升职得论资排辈，还要有关系。在小县城跳槽也有难度，想考些证书，一直在frm和cpa之间犹豫，望珍姐指点一下银行员工以后的职业生涯规划，谢谢啦！

2019-05-09

回答：【帖子编号0268】 两个证书认可度都很高，但怎么选呢，需要看一下你身边。如果有cpa证书的不多，那么考cpa即可。如果有cpa的人不少，那么就改去考frm（难度在纯英语考试，费用也要高不少）。所有的原则，无法就一个，把自己打造成具有少数资源的。记得体制内有个说法，说“无知美少女”（无党派人士、有学历的知识分子、留学背景、少数民族、女性）最容易升值。原因无他，就是人群中太少了，稀缺反而成了优势。你也说在小城市，翻译一下=“升职的机会并不多、比较稀缺”，当地论资排辈，翻译一下=1大部分人硬件都差不多所以只能排资历、2你没有特殊背景。这时候你要加硬件，就得加别人没有的，才算有效。否则大家都有，根本无法让你竞争到“稀缺的机会”。——————————————— 回答问题之外，额外叨叨几句。很多年前，我经验也不足的时候，当时也算占了法学复合背景的便宜。当年cfa,frm证书好像还没流行，很多人首先追求cpa。但当时复合法律背景的人还不多，稀缺就是竞争力。现在越来越多的证书很硬的毕业生出现了，研究生毕业，就拿着cpa六门+cfa二级的学霸越来越多，如果你手上什么证书都没有，怎么跟他们竞争？有时候，走在老路上去追赶别人很慢，不如走没人走的偏门。举例：你如果去应聘，说自己马拉松成绩很牛，或者你是一身肌肉的壮汉，保证面试印象深刻，机会大幅提升。因为现在这样的人还很少，稀缺！加之为工作还有用（会被认为身体好、精力旺盛、能应对高强度的工作），所以就是竞争力。
