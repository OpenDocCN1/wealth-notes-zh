# 借珍老师的地方问一

(提问)骑着小猪看太阳：借珍老师的地方问一句，请问各位星友，有没有谁买过，法院拍卖的房子。有没有需要特别注意的地方。谢谢大家啦

2019-02-03

回答：【帖子编号0228】《法拍房》 我没买过。所以纸上谈兵一下。 需要注意的包括： 1，价格方面，一般是三拍制度，第1次按照评估价去拍卖。流拍，就下浮百分之多少再二排，二次流拍，价格二次下浮去三拍。三拍还没人要了就不拍了，貌似可以私下转让内部处理等等。（一般到这个阶段，是什么渠道处理，我就不太知道了，有人知道吗？） 所以如果想等好价的话，稍微等一等，等到二拍或者三拍时候再下手。 2，上门看一下这个房子是否有人住着，问一下法院是否负责把里边人赶走？ 曾经法院是不管房子交付问题的，只判产权给你了，能不能交付你自己搞定。所以有一些房子买完之后，发现里边住个80岁的老头，你一进群老头就挺尸给你看，搞不好房子到手了最后要配几十万的丧葬费出去。 后来，某些地方的法院（主要是浙江）发现，如果不负责交房，容易造成没人敢买法拍房，所以有些地方是承诺交付的。由执行庭法官带着法警，再叫上120担架一起去强行搬迁。 但仍然不是所有地方的法院都能这么给力。所以交房风险要提前问清。免得产权交到手了，房子却用不了。 2，问清这个房子下面有没有长期租赁合同存在。 主要是基于法律条款“买卖不破租赁”，房子产权过户了，但是不可以赶走以前存在的合法租户。正常租户一年一签，租房合同剩余期限在半年到一年半之间，这种都算是正常的。就怕有些人会利用这个条款。目前法律规定最长租约是20年，所以最怕的是，里面还有一个剩余18.5年的租赁合同。 更可怕的是，合同还不是用“一年一百块钱”这种奇低的价格来签订的（这种可以去找法院判合同无效，或者干脆就违约，按
