# 珍老师 现在生猪价

(提问)飞：珍老师 现在生猪价格跌到谷底了 想囤些来可行吗？冷冻肉貌似销路不是很好？

2018-12-15

回答：以前各个研究所的菜鸟研究员最喜欢去研究“猪周期”。因为太容易研究。 猪肉平均几个月出栏，那么只要提前几个月统计好存栏量，就能预计好供应量，猪肉消费比较稳定，基本都是供应量影响价格。 于是提前几个月就发文章说，因为生猪存栏量上升或下降，预计6个月后cpi将上升/下降0.1个百分点。 按照以前的规律，价格下跌完一年半载的，肯定价格又反弹了，毕竟几个月出栏的东西，产量扩大或缩减，就几个月的事。 然而这次不一样。这次跌是因为猪瘟。这玩意咱国家没有先例经验，多久能消除不好说。只要不消除，那么随时都有可能报导有新感染，随时都有黑天鹅，啥时候能起来呢，真说不准。(18赞)
