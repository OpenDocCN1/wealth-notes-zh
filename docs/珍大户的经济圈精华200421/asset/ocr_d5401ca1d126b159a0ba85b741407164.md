# 珍老师，您好。咨询

(提问)ai: 珍老师，您好。咨询下传言的新的征信政策对房价是有影响，比如降价、涨价、没啥影响。再问下购房问题，在长沙，同样的位置（图书馆边、地铁口）安置区只要5000-6000元/平方米，商品房新房8000元/平方米（我不是本地人，排号买不到新房），商品房的二手房预计10000。我打算买安置区自己住，比商品房的二手便宜一半，可否（我是上班族，家里不会帮忙）谢谢☐。2019-05-10

回答：【帖子编号0270】 长沙已经限购很严了，所以新征信对长沙而言，影响不大。（看这个价格我也很吃惊，长沙房价真吸引人）__________ 一般而言，不建议买安置房。（一方面是怀疑建筑质量不如商品房，这个我不知道真假，只能听建筑行业的发言，他们说的才更准确些。） 主要是因为，一般安置小区的物业都比较差（主要是安置小区拒交物业费的比例更多，很可能就换个稀松烂的便宜物业上岗了），然后多年之后，小区里环境和绿化会明显的差于周围小区，于是均价也会差一点。但这种不建议，是指在购买的时候差价不大的情况下。（见过买入时差价只差几百甚至一千多的，后期差价20%+的）__________ 但如果买入差价很大，比如你这种情况。二手商品房1万，二手安置房五千。如果未来房价上涨，假如涨50%，商品房到1.5万，那么安置房也是50%，到7500的水平吗？ 当然不会了。现在差价是5000或50%，未来不太可能是继续差价7500或50%。 而更有可能是依然差价5000，但比例已缩减至33%。 所以这种差价，我觉得低估的有点明显（除非在交通和配套方面有硬伤）。买安置房吧。（11赞）
