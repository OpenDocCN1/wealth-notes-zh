# ## 美丽的珍姐，我弟今

(提问)小红旗：美丽的珍姐，我弟今年高考完，高考成绩还没出，他是文科生，能选的专业不多，如果是二本以上的学校报金融专业怎么样？我在经济圈翻以前的文章，里面有关于会计的，但是没能找到针对金融专业的分析，小语种跟法学推荐给他了，他担心没能排上，想多报一个金融专业，方向还没想好。所以想来请教美丽又智慧的珍姐怎么看？

**2019-06-29**

回答：【帖子编号0307】<文科报考专业> 如果只是二本的话，不要报金融！我做了解读金融专业的视频，但是不知道什么关键词儿被限流了。金融行业里的基础性岗位，这几年会大幅减少（跟银行撤并减少分支行的网点的原因一样——移动支付、app功能太强，互联网导致的传播渠道改变，不需要太多的基层人员了）基础性岗位招聘减少，那么会造成连续好几年的毕业生就业时都拥堵着，这种拥堵会需要好多年消化的。所以现在去读二本，就业会很难的。互联网渠道只改变了金融行业的基础性岗位需求，但是核心岗位还没受什么影响，所以如果是很好的学校，那么还值得去学金融。不建议你弟去学金融。之前直播时说过一个观点，文科生，技能不好衡量、不好考评，在就业时，不管你真的学习好还是学习不好，别人基本都分辨不出来的。所以这个时候，要搞复合技能。推荐几种方案：法律+大外语，考虑法律行业就业，或者有对外业务的企业就业途径。小语种（硬技能）+管理类/财务类（软技能），这种基本要出国，企业就业了 广告/营销类专业+一些其他什么技能（语言/文字/图片/海外文化类吧），会比单一专业的竞争力强一点。其他的，像是之前有一个职业路线的回答里面，旅游管理专业是对旅游行业就业，如果你再复合一个热门技能，比如语言或者财务或者法律，竞争力会强一些，那么更容易抢到本行业里有限的优质就业名额。总之，逻辑就是，现有各个行业都挺人
