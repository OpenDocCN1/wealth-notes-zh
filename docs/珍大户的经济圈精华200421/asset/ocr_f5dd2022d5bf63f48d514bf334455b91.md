# 请救珍大户：

(提问)匿名用户：请救珍大户：
请问，对印度了解么？现在去印度开设一个小加工厂，合不合适？
先说一下基本情况，我合伙人是做手机售后维修配件的，就是手机上的屏幕，属于易损件！现在国家对这方面管控越来越严。(涉及到商标，侵权的问题，主要做小米，OPPO，VIVO，三星等屏幕)。
印度市场是对这方面不管控的，我们主要客户也在印度！现在印度的客户想和我们一起把工厂开到印度去，一来是可以降低他货物进口的税费，降成本。二来可以缩短清关时间，交期减短。
因为没有出过国门做生意，想请教一下珍大户的建议！

2019-06-11

回答：如果是小加工厂的话，不建议去印度。 印度属于英美法系国家，各种破事你都得带着律师，租个房最好都带律师的那种。 中国文化跟印度差异很大，所以想不带律师完全裸奔，是很容易掉坑的。所以虽然人工成本低，但是法律费用高。如果厂太小的话，性价比不划算的。 我不记得以前在哪看到的，还是听说的各种印度规则，准确性不确定，随便写一点，给大家当奇闻轶事看。 印度人普遍说话夸张，说过的话立马不认帐也不稀奇。所以要确定什么事必须跟他们敲定合同。 合同的话，印度有印花税，据说是通过卖合同专用纸的形式控制逃印花税的，所以必须去法院买合同专用纸，申报合同金额，然后缴税。否则合同有可能作废。 合同是双方签字就生效，但好像有些限制，旅游去的人是没签字权限的，所以即便签了合同，但可能因为你没有签字权限，所以合同作废。 商业上的合同，需要工作签证（否则没签字权），第一我不知道好不好办，第二工作签证的纳税问题需要注意一下。 有些企业搞不定上述两个问题，于是
