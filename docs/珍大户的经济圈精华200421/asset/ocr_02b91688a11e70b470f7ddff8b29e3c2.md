# 珍姐，你好！想问一

(提问)小黎黎: 珍姐，你好！想问一下，我从来没有做过理财，存款不多，但是银行里面的理财产品让人很心动，我好不容易选了一个保本保息的理财产品，虽然不多，但是稳得，我很高兴，在和银行的工作人员聊天的时候试探的问了一下她们是如何理财的，经理告诉我说她们都是哪种得息高就买哪种，我问她那风险不大吗？她说“反正我没亏过，你见过银行亏过吗？”我还是不敢，你可以给点建议吗？

2018-10-31

回答：【帖子编号0155】《理财产品》 先回答具体问题，再讲点共通的东西。银行的保本保息理财肯定是没问题的，可以买。不过这种“保本保息”的产品肯定会越来越少了，因为今年年初银监会新发的规定，银行理财不再再保本保息，但没一刀切死，而是设了个过渡期。所以现在能保本保息的产品肯定是越来越少了。再说一下，如果未来没有“保本保息”产品了，该怎么买？对大部分银行员工来讲，理财产品内到底装的什么东西，他们也不知道。包括那些直接向你销售的大堂经理。理财产品内有什么东西，只有直接负责这个理财资金投向的投资人员才知道。而他们只会告诉银行的销售人员最最基础的信息，包括预期的收益率（比如告诉你收益率5%），期限（是3个月还是一年），理财产品的发售规模（募集多少亿）。对银行投资人员以外的其他来说，完全是一个黑箱。（投资人员只在每个银行的总行，所以，任心分行、支行的人，从行长到理财经理，也对理财产品里是什么，都无从知晓）既然都不知道里面是什么，那么就闭着眼睛，挑收益率最高的买了。但理财产品的条文还是有必要读一下的。首先要认识到，这个理财产品，虽然是银行卖的，但是谁发的？银行有可能卖自己的产品，也可能代卖其他金融机构的产品。比如，这个提问里，虽然从浦发银行买的，但产品其实是代销，真正的管理人是长江证券。银行可能卖
