尽管现在的记账会计工资已经很便宜了，但是只要引入电脑，还可以继续砍掉人力成本…… ----------------------- 所以虽然现在，你们想的更多的是，恶性竞争怎么处理（你家收300，别人家200抢客户怎么办）…… 但是长远看，早晚上马云家再来跟你们抢工作（你家降价到200，马云家只收50……）

无论是防止现在的同行降价竞争，还是防止未来的人工智能竞争，解决方式都是“个性化”，而不是“标准化”。 ----------------- 怎么个性化？ 我只能说点细节，启发一下了。 以我这个小公司为例，刚成立几个月，每个月没几笔账，于是就找了代账公司。 找代账公司的过程也很好玩，当时公司一注册好之后，信息就全都变成公开的了，于是电话每天被各个代账公司爆打。 我每次接了电话就开始问，费用多少，有没有更高端一点的套餐？因为当时考虑的是，我对财务也是略懂一些的，考虑把账做的规范一些。方便以后从管理的角度去做财务分析。 那么就少不了要常常跟会计沟通。 如果一个月就200块，这钱怕是只够记几笔账，怎么好意思再占用额外的时间…… 所以当时心里想的是，如果合肥行情是200块一个月，那么我就预算800-1500好了。 希望能提供点个性化服务吧。 结果电话接了一圈，没有一家公司有这种服务。 最后我就放弃了，找了一家普通话说的最标准的公司[捂脸]。 这几个月记账的过程中，果然碰到了不少细节问题： ---------------- 第一件事，是关于餐饮费： 我周四直播，助理晚上会回去的很晚。于是晚上必然要请吃顿饭。 餐饮费发票交给代账公司以后，我突然想到，他们看见餐饮费肯定默认做成招待费。于是打电话问会计，餐饮费发票怎么做的？ 会计说：招待费。（在这里给对不懂财务的朋友解释一下：发票是用来做成本的。 招待费，是用来招待公司外部的人。这个费用当然也是成本，然而税务局有个规定，说招待费只按60%记成本。 所以如果问这个费用算成招待费，就会被少算40%的成本……） 于是我就做了个表格，把每个发票发生的原因给写下来了。 餐饮费里特别注明，这是员工加班支出（具体会计科目我不知道，但是应该属于行政成本之类
