# 珍老师你好，我是一

(提问)Marcus lia*: 珍老师你好，我是一个大学刚刚毕业准备前往西班牙留学读MBA硕士的学生，家里是在成都搞房产的，有一定积蓄。在一带一路政策下，觉得中国和欧洲贸易日渐紧密，包括电商境外贸易也要越来越多，觉得中国把国内很多小商品销售出去。在这种前提下打算出去学习，希望带着对欧洲人的了解回来，大展拳脚。由于对自己家乡成都还是比较自信的，所以未来作为一个对欧洲有有一定了解的MBA留学生，在成都和国家发展的政策下，可以提前注意一下哪方面学习。

2018-09-30

回答：这个问题有点散，我都不知道回答啥[捂脸] 第一，成都算是最有潜力的城市之一，西南第一，你家的地产生意后面仍不少年的前景，考虑接班。 第二，国内传统的纺织业已经开始往外转移了，以前一直说欧美买东西，一买全是 made in china，但这种现状在改变。最直观的，衣服，你可以注意一下，中低端的被东南亚和东欧替代了，高端的还是欧洲本土制造。 这是第一步，因为劳动力优势已经逆转，所以还会有更多的高人力的中低端制造业向外转移，那么中国制造的“小东西”，剩下的优势是什么呢？我觉得是“快”。新产品，创意产品，开模快，批量生产快，由于人口多市场大，所以创意也多，创新快。 另外还有一个需要规避的，是欧盟对商品的检验标准全球最严，所以涉及到食品，儿童用品，或者其他跟人体密切接触的，在前期还没有熟络的情况下，先规避一下吧。 你看是想成为这类产品的渠道商（2B），还是直接在开些线下的“名创优品店”（2C），还是线上销售（2c），我不知道欧洲是否有流量红利，但就算是可以通过社交营销、话题营销，制造爆点促成销量，这也是一种赚快钱，而不是能够长远发展的方式，更适合普通人创业的起点，而对于像你这样能够有着很好的起点和不错的资源的人
