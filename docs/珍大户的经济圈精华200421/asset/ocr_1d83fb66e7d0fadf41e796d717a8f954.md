# 请问珍姐，南京商住

(提问)yiso：请问珍姐，南京商住两用房值得投资吗？什么类型的房子投资最好呢？

2018-11-15

回答：（旧帖参考：，另外推荐使用搜索功，搜关键词如商住、商铺等等） 不管是哪里的商住两用，都不值得推荐。这种产权的，一般物业都不太好。 当你想居住的时候，你会发现左边开了一个美容美甲，右边开了一个电话催债，这个楼层每个月都有装修。 当你想办公的时候，你会发现楼上改成了群租房，不断漏水，上班时间有穿着睡衣的邻居下楼取快递。 电梯里不断有外人进来，贴满搬家、贷款、水管疏通的广告，因为是商用，物业根本不会给你拦访客搞登记。 时间久了，你会发现，租金比不上写字楼，更是比住宅差远了。当初所有买过的人，都纷纷在内心安慰自己，这是投资，这是投资......会升值的。 但最后这个楼越来越萧条，交物业费的人也越来越少，楼下的保安经常时不时就消失不见了，楼里看着像皮包公司聚集地，投资客也不敢接盘了。(20赞)
