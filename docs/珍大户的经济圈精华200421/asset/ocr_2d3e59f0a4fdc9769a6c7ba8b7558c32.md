# 如何正确理解SWO

(提问)Steven Han：如何正确理解SWOT分析法中的“机会”。麻烦举一个服务业商铺的例子。

2019-08-02

回答：【帖子编号0338】《swot》swot分析（读音一般读斯沃特分析）。里面是两对概念，要两两结合的分析。第1对概念：s和w，这是内因，自己具有哪些优势(strenghts)和劣势(weaknesses)。第2对概念：O和t，这是外因，机遇(opportunities)和威胁(threats)，就是看有哪些利好因素或不利因素。opportunities，我一般把它理解为“天时”、“时机”。这个分析方法，属于普遍适用的。比如圈子里各种职业选择分析，一是结合自己的学历、经验、兴趣，分析自己的特质在哪个行业有优势，扬长避短，这就是swot里面的s和w。其次分析某个行业有没有前景，是有红利的成长期，还是即将被新技术、新习惯颠覆。这是swot里面的o和t。

提问里，问商铺的例子。刚好这几天都已经在将二代商场和三代商场。二代商场时代，商业街是逛街的好去处。因为二代商场的各种缺点，导致逛起来没有商业步行街舒服。所以当时的商业步行街租金不便宜，一个黄金铺子租金超级贵。三代商场出来以后，提升了逛的体验，对步行街商铺造成了很大的分流。（比如上海的租金来看，新天地的商场租金已经大幅高于新天地马路上的商铺租金了）所以商业步行街面临的是opportunities机遇的反面，就是threats威胁。而面临这个外因，就需要商业街做出改变，包括：不能各自为政，各家独立对外出租，想租给啥店就租给啥店，而是要全盘统筹规划，做好布局的分配。要集体做一些共同的事，比如给街上装灯带等等，用于提升环境……
