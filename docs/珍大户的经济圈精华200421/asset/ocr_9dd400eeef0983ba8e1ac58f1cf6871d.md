# 珍老师，您好！想请

(提问)□ □ □: 珍老师，您好！想请教您个人职业发展的问题。我老公，沈阳k12一对一数学老师兼教务主管。工资旺季1万+淡季6000+，周末时间基本排满，工资再有突破很难。教育机构的老师再做三五年，仍然是用钱换时间，没有时间、经验、以及平台带来的发展，我觉得本质上和其他简单体力劳动没有区别。所以想转行，做销售市场运营管理等方面的工作，在沈阳什么行业对于个人的发展空间更好？

背景：90后物流专业本科毕业，有物流师证，在校在外联部拉过很多赞助，做过学生会主席。毕业后带过小的销售团队，兼职过培训机构校长。销售能力和授课能力都比较好，情商高。

希望得到珍老师指教，感谢！

**2019-06-15**

回答：一对一，是很难有收入提升的。前面讲了，要么价格不高但量大；要么量不够，你就得单价高。你的时间是有限的，一对一的量已经被限制住了。那么收入想提升，意味着别人付费的单价就要贵了，这是难度比较大的。所以都是从提升人数的角度来考虑的。至少也要小班教学，一个班几个学生。学生不是一个人，还能有些互动和竞争，氛围也会好一点。所以一对一的辅导，我看不出有什么独到的优势是必须存在的。其次，很多名气起来的名师，是不可能搞一对一教学的。就像以前的新东方名师，一个班要多少人来听？这一点上反过来想，你一直搞一对一教学，就算你教学水平很高，你的名气也不可能传播得出去，那么就积累不下优势。目前k12教育已经是社会上现存的行业里，难度不大，利润率和收入又不低的行业了。要不是现在政策阻拦，资本肯定使劲在这一领域扩张，把员工都转化成生产线上的零件，也就没高工资什么事了。现在行业还处在比较好的阶段，这种时候你觉得赚的少，首先应该反思自己的模式是存在哪些问
