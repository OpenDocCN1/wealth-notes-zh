# 老师您好，我现在从

(提问)匿名用户：老师您好，我现在从事外汇行业，之前自己做，现在有三主券商公司在合作，现在需要客户了解参与，请问怎么精准找到这些客户及发展呢。政府最近公告也在提到三年左右开放外汇市场，未来会不会进入红利期。那么现在开始接触去发展会不会更好

2018-09-28

回答：【帖子编号0116】 思考行业前景，最主要的问题不是客户哪来，而是你的收入从哪来。 现在外汇行业很灰色，很乱。 不说ptfx这种假外汇真非法集资（打着外汇的旗号招揽客户，但是客户是不会真正去操作买卖的，都是把钱交给这家公司，等同于庞氏集资骗局） 就说真正的做外汇交易的公司，客户自己交易的手续费是一方面，所谓的“老师”喊单，带着客户频繁交易刷手续费是另一方面，还有很多灰色甚至黑色玩法， 比如，利用大部分顾客都是最终亏损的这种概率，所有的资金都没最终进入市场，而是这家公司自己承接掉了，直接吃客户亏损资金（万一某段时间，单边行情，顾客全都盈利了，公司就会衡量，是赔钱还是跑路）。 还有在外汇软件上做手脚的，人为做出延迟，让盈利单变亏损等等。 正是因为有一堆不正规的手法，让这个行业变得暴利。但一旦外汇行业变正规，猜测还剩什么收入可以保留？ 所以最后，请参考第0110贴，金融销售。（编号忘打进正文里了，搜数字不到，你搜金融销售）(24赞)
