# 家住的社区（一个开

(提问)dc：家住的社区（一个开发商开发的在一个岛上，三面环水，有桥有快速公路，交通还是很发达），有大概1万余户住户，还有小学到高中的私立学校，小区正门口算是黄金地段有门面出售（开发商卖的，房子去年底交的房），带招行5年租约（招行正在装修），120平米，每平110元（通过了解该区域租金目前是90—110），总价310万，目前是第一家入住的银行，请问个人可以投资吗？

2019-06-05

回答：【帖子编号0294】这个真可以买。首先看基础信息，能分析出来确定的因素包括：1，三面环水，正面的门面商铺就属于比较稀有的社区商业了。未来无论如何，这里的餐饮和社区服务都一定是有市场的，这就是支撑价值的基础。2，算收益率，月租13,000，年租16万。收益率是总价的5%了，非常好。（未来房租大概率只会升值，收益率只会更高）。3，面积比较合适。100多平，算是商铺里面比较适中的面积。太大（比如300平）、太小（比如四五十平）都会限制住出租的范围。（另外，大家注意，看这个均价310万/120平=2.58万。现在有些商业的房子要价很宰人，明明就是社区商业，均价开个五万八万的，也有不少的，这种价格进去就是纯坑了。所以后台也有人问一些很大而概括的问题，比如【现在买房收益高还是买商铺收益高】，就很难回答了。因为商铺价格定价特发散，有值的，也有坑的，不可一概而论。）只凭以上几条，就认为可以买了。不确定的因素还包括：这种在岛上三面环水的岛，我猜一般属于比较高档社区了，学校还比较全，居住环境会比较不错，那么入住率以及入住的人群属性，推测会比较偏中年、收入较好的群体，消费能力都比较好。（反之，如果没有那几个学校的话。有可能会因为环境比较好但设施不便利，那么入住的就都是养老群体了。）（我在抖音上说过一期上海的，规划失误的“江湾
