# 珍老师，为何国内的

(提问)雨宸：珍老师，为何国内的管理会计师报考费要比中级会计师贵几倍，目前管理会计师报考费要9600.我已经考取了中级会计师资格还有必要考这个证吗？这个证圜□多少含金量？

2018-11-30

回答：【帖子编号0183】没必要考。考cpa了吗？想考就考这个，不想考都都不要考了。国内有一些个考试，纯属盈利产业，是由一堆大专都没毕业的江湖老混子，专门包装各种考试。给人社部有些运作途径，据说是每年交固定的费用，就可以颁布某个证出来，至于这个证受不受认可，有多少人报考，就全靠老油条的运作水平了。据说"注册心理咨询师"就是当年被运作出来的一个证，但是因为刚好强占了一个空白点，结果运作的十分成功，上百万人报名，累积有七十万拿到证的，从报名费到培训费、书本教材费，整个产业赚到很多钱，但是最终因为操作太不严谨（据说武汉考区可以直接买证），总之是一锅端地取消了。还有很多各种师的证，都是运作出来的。这种证书的特点就是，报名门槛极低，不做资质审核（或者几遍有审核，也可以交钱通过），但报名费极高，忽悠你必须报补习班，各种押题班等等。之所以知道这个情况，是因为去年从上海搬到合肥，开始接触了很多人，了解到很多行业。有个土老板特别希望我能帮他开发一个金融类的证书，用"非常赚钱"地来给我描绘了这个运作方式的赚钱前景。所以如果我要是个什么钱都想赚的人，你们今年应该能听说，有个某某协会主办的由人社部颁发的"某某分析师的证书"出现了。然而，我是鄙夷这种事的。至今想起来仍想呕。(64赞)
