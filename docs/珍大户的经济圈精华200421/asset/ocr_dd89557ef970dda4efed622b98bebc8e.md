# **大户知道这种推荐股**

(提问)牧马人：大户知道这种推荐股票的是怎么操作的吗？

**2020-04-20**

回答：【帖子编号0430】<推荐股票> 老牌骗局了。我刚从上海搬到合肥时，时间比较闲，就给过几个大学开过讲座。于是有些大四的学生就加了我联系方式，说毕业找工作比较难，好不容易找到两个录取意向，但都很犹豫，不知道选哪个：一个是武汉国营证券公司的客户经理岗位，月薪两千四。另一个是上海的证券咨询公司的电话销售岗位，月薪4600。 我说，去前一个。因为前一个，你累计的客户会长期属于你的，不管你工作做的好还是不好，客户一直在累积着，这是属于你的资源。从收入上来说，只要持续维护，因为客户会持续为你带来收入。如果某一天随着工作经验升级，你自身从量变走到质变了，这些客户可能会发挥更大的价值。 相反，另一个工作，通过电话向股民销售“证券咨询付费会员”。从客户付费的那一刻，客户就变成公司的了，不再是你的客户了。他对你的作用就清零了，下个月你必须要重新开发客户，如果开发不出新的客户，你就没有任何业绩。至于旧客户，哪怕他续费，也和你没有任何关系。这份工作没有积累，没有积淀，永远没有从量变到质变的机会。 分析完，我还建议他：去联系一些高年级的学长，打听一下上一届或者上上一届的人里，去不同公司的人都有什么反馈信息。就是这个建议，后来我就听到了很多反馈信息。
