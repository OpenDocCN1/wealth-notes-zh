# 珍老师你对现在房价

(提问)怡荷食府:珍老师你对现在房价怎么看？在江苏的小城市张家港（三线城市）离的上海也不远。我的情况呢自由职业、九一年，有几套房但是全部的资金都在上面每个月还要还贷款。等于说全投资了房产现在房价虽然涨了点但没前几年那么凶了。现在算算上涨收益其实也只能抵扣银行利息。问题上银行利息每个月要付上涨收益必须要等卖出才能变现。这样周期拉的太长心里也没底。去年看中间公司发的信息都是房子多少抢购。今年的信息绝大部分都是房东忍痛低价几万变现。这算不算也算市场一个信号。我的想法呢其实想抛但做别的也没把握能有年息12%的收益。可有良方 2018-08-26

回答：【帖子编号0014】今年必须改变一个态度，就是别想着高收益，年12%都是前几年留下的思维惯性，以前信托随便买买都能12%了，但今年我是想不出来有什么可能了。大家思路还是要及早转变，要对大环境有个认识。还记得我在抖音上第一节课，三只小猪分房子的故事吗？是生活中就是人力、科技和资本，三个模块在分利益。中国经济增长8%，这个收益就是三个模块分一分，资本能分到12%，能够高于8%，是因为有的模块被压低的低于8%了。但更重要的前提是因为大环境还能给大家8%去分。 今年的任务是投资先保证安全。 至于房价。不敢说太多，毕竟判断错了影响的是别人的钱。 但我是整体不看好。因为： 1，宏观经济上，过往的货币扩张结束了。（虽然保不齐如果遇到危机扩大，国家这帮喜欢下猛药的人也存在继续大防水的可能性。 但因为现增加放水的边际效用已经很了，反而容易引起通货膨胀。而一旦通货膨胀率增长，房贷月供也会增长，反而会给贷款人增大压力。所以，不放水=房价不涨。放水=月供增加，虽然货币贬值对贷款人有好处，但必须要想清自己现金流的压力程度。而且就算自己不断供，但肯定会有人断供导致抛售。所
