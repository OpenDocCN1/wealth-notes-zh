# 您好，我想在三四线

(提问)孟珏：您好，我想在三四线城市开一个射箭馆，目前市场空白，之前有过倒闭了。身边人都不建议做，觉得是小众产品，在其他城市也了解了这个产品，效益一般，而且在我们这地方属于高消费产品，想让老师给下建议，或者应该怎么做。

2018-09-13

回答：【帖子编号0065】射箭馆很尴尬，因为需求定位不明。这种场所考虑三种需求：一是最直接的运动健身需求，但射箭的时间太短，射个几轮，直接的运动效果不明显（射一个小时？玩法太单调）。所以吸引力比不上舞蹈瑜伽跆拳道之类的。二是社交娱乐需求。这要求至少容纳两个人以上，能够消磨时间，满足社交需求。但还是射箭的时间太短，场景上，并不倾向于支持社交需求。没有打桌球，玩桌游吸引人。三是生活场景代入。这就要求这种运动是大家向往的一种，高档的，甚至是贵族的运动。最基本的发发朋友圈能不能显摆？去射个箭，发一次是尝试新鲜玩意，周周去射箭发朋友圈，就……所以你看这个消费需求，三不沾，很尴尬。如果要经营，怎么办？想办法发掘其他的需求。现有的射箭馆，一块场地，墙上贴几个靶纸，然后画几个赛道，几个射箭位，人站在那儿拉弓射箭，这种玩儿法是注定没前途的。往户外野外生存（美剧行尸走肉）上靠（但是安全性怎么保证又有点麻烦了）。尽量户外的场地，用走动，移动，来拉长参与的时间，一方面有场景代入，搞出新的需求来（比如学习“黑暗森林”生存法则之类的），另一方面，通过时间拉长，来满足社交和运动的需求。具体自己想。（11赞）
