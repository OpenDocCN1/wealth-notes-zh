# 半夜提个问题：本人

(提问)匿名用户：半夜提个问题：本人在珠三角地区最差的卫星城生活，2000中专毕业后自考大专及本科，由于时常执笔忘字，专业职试书一直未有考下来，现在主要为私人老板（也可理解为包工头）工作，年收入约20万元左右，算是个项目的管理层，项目完成后可能会有半年左右空窗期。银行存款40W其中25W是定期，股票1W，微信理财1W，16W基本放支付宝各项目。现在市中心有一套120平步梯住房价值85W左右，生活着2老2大2少，每年生活开销约10W万左右，因两小孩长大分房及入学学区想购置多一套100平新区房产，不带车位100～130W左右，请问我的条件可以现在购买吗？还是观望再入手？如果暂不买房应该如何理财？字数限制未能详说

2019-04-25

回答：【帖子编号0257】这个问题不含地域分析，只看财务杠杆水平。风险不大，可以买。因为，第一，目标房子100-130万，自有流动资金58万，就算买完后的负债也不高。看提问，可能是有担心工作稳定性的问题。但目前收入中消费部分也不高，结余不错，其实用不几年就负债结清了。所以没什么风险。第二，这一贴没提到具体地点，但是似乎也不用从城市红利角度去分析。因为题主的资产都是低风险的银行存款和低风险余额宝（收益也是最低的），说明是属于低风险，求稳的人群，并不追求高收益。所以题主追求的不是城市红利，而更多是从风险角度的考量。那么从风险角度，反正这里均价不高，而且是给孩子买的，属于长线持有。那么长线角度，10年以上，我觉得不太可能一直不涨或者是跌到，从而在这个价格还能被套。风险就是有可能不涨，或者涨的少，跑输。但银行存款和余额宝是肯定跑输的。所以我觉得还是买房子好了。毕竟卫星城也有可能因为广东省生育率比较好，或者城市版图扩大而受益的可能性。(27赞)
