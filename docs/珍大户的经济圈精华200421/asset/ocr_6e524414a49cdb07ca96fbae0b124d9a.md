# 有幸成为星球一员！

(提问)Olivia：有幸成为星球一员！有个问题想请教，我打算买天津静海的房子，为了给娃娃上学，可是对于我一个人来说房价还是很高，学区片得老旧房子还12000左右呢，稍微新点的得15000。最近听说房子处于拐点期，会降，对于人才引进和限购政策即将满两年的天津来说(17年天津限购政策出台，外地人满两年社保才可以买房)，不知道会怎样？我的目标房子都是学区房。

2018-10-11

回答：【帖子编号0131】这个问题有意思，刚好暗含了一个知识点：什么时候该买新房，什么时候该买旧房？我们把卖房者分为两类，一个是二手房，卖房者是个人。一类是新房，卖房者是房产公司。个人的行为模式比较符合行为经济学，有各种不理性的地方。而房产公司的行为模式，则是从金融投资和财务管理角度去预测。行为经济学中有一个很重要的概念，叫损失规避，说损失带给人们的痛苦，会比获得带来的快乐要大得多多多得多……这种心理影响，最终会导致一种像鸵鸟似的行为——装死，拒不承认。最常见的，在股市中，下跌时候的痛苦是很明显的，而遭遇到股票下跌的人，往往不会立即卖出，而是等待反弹——反应很滞后。（卖不卖，这个行为并不是基于理性的分析作出的，而是看，怎样才能让自己痛苦更轻一些）所以，在一个散户为主的市场中，大部分情况下很难暴跌，而是缓慢的阴跌。这种状态，在融资融券开通前的中国股市中，非常的普遍。而15年的股灾，应该大家都很印象深刻，一反常态地改阴跌为暴跌，这是因为当年有很多杠杆资金，1比10的配资户，1比5的配资户，1:3的配资户，再到1:1的融资融券账户。于是下跌首先引起最高杠杆的配资户，不得已平仓，然后再次下跌，引发了连锁反应。如果按照个人的行为模式，他们是不会这么快的割肉平仓的，但因为有融资融券债务，面临着还款压力，必
