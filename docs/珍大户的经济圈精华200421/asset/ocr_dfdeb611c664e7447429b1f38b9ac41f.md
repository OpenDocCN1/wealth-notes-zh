# 大眼青霞老师，请教

(提问)voke：大眼青霞老师，请教您对于当前小微企业saas软件行业发展及我的现状是否适合我离职创业给些意见。

现状:就职于传统erp公司，负责某省小微企业saas业务渠道管理工作。去年才回长沙，马上30了未婚打算明年买房。现在感觉晋升和薪资提升很慢，心理很迫切出来单干，想做小微企业信息化服务，对金融也很感兴趣想积累客户后期再提供金融咨询服务。

2018-09-26

回答：【帖子编号0107】大约在六年前，国家突然开始大力推北斗导航设备。F先生的老公司，有一个个人大客户，跟F先生一直私交甚好。这个大客户自己的公司刚进入到北斗导航这个行业没多久，前面几个月都经营的特别好，乐观的得不得了，于是找到F先生说，有个好项目一起做，有钱大家一起赚。他的公司是在上海，针对的也是上海本土客户。但上海本土的物流企业，其实不是很多，所以他想拉着F先生一起进军安徽市场。六年前我还仍是一个投资研究员，于是按照做行业调研的思路，帮F先生做了行业分析：1，安徽全省，有货运车辆17万辆，在全国范围内能排进前三。2，行业出现了巨大的政策利好：国家强制要求所有货运车辆必须安装北斗导航设备，不装设备，车辆不给年检。3，市场存在巨大的空白，安徽全省没有同类企业。立即去开一家公司，存在很大的先发优势。4，这个设备，物流企业一旦安装，可以跟踪行驶位置和行驶速度，油耗情况。可以不被吃超速罚单，可以防止司机偷油等等（年头比较久，很多功能细节我记不清了，但确实是对安装的企业有一些实质性的好处的）5，项目的营收逻辑是，收取初始的设备费（每台几百块），加上后续的流量费（每年几十块）。只要利用前期先发优势，迅速的卖出初始设备，即可锁定客户，之后只要坐等收钱就可以了。6，在当地还有很多可以借助的资源，用于各个环节。
