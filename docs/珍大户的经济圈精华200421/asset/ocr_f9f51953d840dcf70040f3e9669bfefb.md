# 珍姐，想问问你做县

(提问)燕妮：珍姐，想问问你做县城一些品牌代理商前景是是越来越差，就是供超市的一些品牌，或者说未来超市生意是不是越来越难做？

2019-11-04

回答：【帖子编号0374】<中间商> 做各种品牌代理，说白了就是中间商。这是90年代很有前景的方式，到2012年之后 就逐渐没落了。说白了，因为你们已经提供不了什么价值了，因为你们的作用越来越有限了。所以你们要被淘汰了， 很残忍但很真实。

记得《激荡30年里》有一个桥段：作者跑到新疆还是西藏的什么小山村时，发现偏远的地区竟然也能买到娃哈哈矿泉水。于是作者就感叹娃哈哈的销售渠道多么的牛逼。这么牛逼的销售渠道，是因为从省代到市代到县代的几级中间商充当产业链的传递渠道。无数人在其中的努力，才让一种产品铺满全国的各个角落。 这时候中间商的作用很大，创造了很大的价值，也因此收入不菲。（农夫山泉的创始人在90年就是娃哈哈的省代，积攒了不少家底儿，后来才创办了农夫山泉。）当年巨头和小厂之间，最大的差异就是销售渠道。巨头如宝洁、联合利华、卡夫食品之类的，他们最有价值的绝对不是商品品牌，而是销售渠道网络。 只要销售渠道网络存在，他们就可以按照下面的模式，源源不断的创建新品牌： 第1步：先起个新品牌的名 字。 第2步：想一个广告，给品牌奠定个基调。 第3步：在 全国的电视上疯狂铺广告。 第4步：让销售渠道把所有新产品铺满全国的每个角落，让消费者能够看得到。 第5步：重复两 三年，这个品牌就成名牌了。 只要销售渠道一直存在，他们就可以源源不断的创建新品牌。 而这些销售渠道越做越大，把持着全国各个销售终端超市的黄金货架，不让其他的品牌进入，就形成了市场壁垒。 渠道就是巨头的护城河。
