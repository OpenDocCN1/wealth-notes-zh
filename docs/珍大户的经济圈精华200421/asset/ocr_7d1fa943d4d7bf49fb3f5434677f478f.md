# 珍老师，看了您在抖

(提问)猪仔会飞:珍老师，看了您在抖音上发布的锚定理论有些疑惑。如果把价格高的产品展示在外面，是否会让客人觉得价格太高从而不想进店，真正想卖的便宜实惠的产品就无法展示了呢？

2019-10-31

回答: [捂脸][捂脸][捂脸] 第一，这是让你展示有美感、有质感、档次高、品质好、倍有面子的产品，不是展示价格签。 顾客如果不进店，怎么会看到价格呢？又怎么会“知道价格很贵” 只要顾客进店之后，感觉实际价格比门口拔高的预期要低，这种落差会让人愉悦从而转化购买的。 第二，确实会有些人不敢进店的，尤其是年龄越大的人，越容易被高档装修环境而吓到。 但总有人进店，进去之后，你能让人愉悦的停留在店里的话，这些人就会有示范作用的。 人们的潜意识、或者说直觉有很强的判断力。路过户外的时候花一秒的时间往里面瞄一眼，就能感觉店里的人都是跟自己差不多的人，而不是“只有一堆大款才敢进店”的感觉。 只要店里有人，就会吸引到更多的人进去。 而两种情况: A初始印象拔高，进去发现价格低 B门口摆低价把人吸引进去，进去后发现价格不如自己预期的低 A比B绝对能让顾客停留的时间更长。(39赞)
