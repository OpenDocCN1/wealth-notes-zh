# 珍姐，我想创业做有

(提问)貘：珍姐，我想创业做有机梨，目前在北京郊区有上百亩梨园～想请问定价、销售这方面怎么弄，因为之前没有涉猎这个领域，近几年想要搞生态旅游一体这样的项目，有什么好建议吗希望抽到我啊谢谢🍐

回答：【帖子编号0093】 看见前面发帖的探讨了。 提问第一是想在网上找销路。 目前单品销量比较好的网上平台： 1.拼多多（只有一种产品时，主推这里，像淘宝的思路是开店，拼多多没有店，只有单品）2.京东生鲜3.苏宁拼购 尤其是1，短期内量集中，至少会让你跟快递议价的能力比较强。 第二是定价： 从几个角度考虑： 1、是成本角度：（话说：有机梨的成本比普通梨会高多少？[发呆]如果差异比较大的情况下，考虑这个方式）租地的成本+种树原材料成本+劳动成本（按工人小时工资算）+你承包山林的时间机会成本（假设一年最基本的十几万），这些是总成本。再算总的产量。然后，假设最终产量的1/3按网销的市场价X销售掉，1/3用低价处理给批发商（处理价为X的1/5~1/3之间），1/3处理不掉，烂到沟里。 按这种假设收入约等于成本，来算一下价格X应该为多少。 （具体的1/3还是几分之1，可以做微调）这种销量是保本 的盈亏平衡点，超过这个销量，额外的就是利润了。 2、是市场价格角度 （因为我也不知道有机梨是什么含义[捂脸]如果大家都是有机梨，那么别人定什么价你就定什么价吧） 第三是营销，结合生态旅游什么的。 因为在北京周边，区位优势不要浪费，生态旅游还是可以搞的。 先，把果园分成几片。 从离出入口最远的地方开始，摘下果子满足网购需求。 离出入口最近的地方开始，卖果园门票，一张门票二三十元的样子，果园内自采摘，摘完送个十斤八斤的梨子（折算要比市价高些），顾客会觉得，玩到了，还能送梨，门票像是没掏钱一样。其实本来也没有门票，就是让他们来
