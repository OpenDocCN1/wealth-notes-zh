# 懂得看看这商业保险

(提问)瓶□□：懂得看看这商业保险的价值
2018-12-12

回答：【帖子编号0190】《钱商第一讲：复利》这几天刚好在抖音上讲了个“钱商大局观”。但是抖音上时间很短，总感觉讲得不够深入。在此开个帖子细说一下。学金融类，或者是対理财有些了解的人，一般都最先学习的就是复利。巴菲特曾经说过一句话，大意是复利是人类最伟大的发现，能量不亚于原子弹。复利的力量很可怕。然而，认知总是被不断的推翻，再重建。多年以后，如果再评价复利，我想说，复利既是对的，也是不对的。然而想要讲后面的内容，必须要先保证大家都已经了解复利了。复利的力量有多大，我做了一个图片。按照年利率3%，5%，7%……一直到17%。（17%是巴菲特的记录。具体是保持了30年还是更久，我没有详查，但应该是还没人能够打破）按照10万元初始资金，各个收益率下，分别持有10年，20年，30年后，会到多少钱？具体数字文章里不说了，大家看文章后的截图。总之，持续的时间越久，效果越爆炸，最后的数字都是惊人的。至今回忆起来仍然觉得很欣慰，自己早早就了解到了这部分内容。于是我开始相信，现在花掉的每一分钱，都是一颗种子，多年后会变成一笔巨款，于是我变成了一个很节俭的人，早早就开始省吃俭用，为了攒第一个十万块而努力。总之，靠着这个信念，我度过了人生中艰难的时期。我穿过淘宝上1块钱和10块钱的衣服，每天兴冲冲的去上班，充满了希望，贫穷而快乐着。也是靠着这种信念，因为坚信自己早晚会变成有钱人，既然老年时一定是个老富婆，那就没必要早早为了钱，就把自己的良心给卖了，所以幸运的，人生没有留下什么污点。如果人生重来一遍，那么我的人生依然会按照这个路线，这么开局再进行一次。存钱很重要。虽然，我是基于复利的信念去存钱，虽然……很多年后，当我认识到……其
