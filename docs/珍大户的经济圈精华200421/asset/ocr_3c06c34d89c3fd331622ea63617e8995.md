# 美丽的珍妮，怎么看

(提问)、Anne🙈：美丽的珍妮，怎么看罗振宇的得到团队今年取消年终奖这个事儿🙄

2019-01-12

回答：【帖子编号0212】《谈年薪》圈里有hr的同学吗？hr更适合评价一下。互联网行业我不知道，但是金融业里，谈年薪的时候，谈的整体的年薪，是包含至少13个月的收入（会写进合同里，并且注明是在年底随12月工资一同发放，一般跟绩效无关，但是跟全勤有关，如果请产假或超过多少数量的病假后会扣发，这部分有一次年终扣税优惠，税很少），外加三四月份发的绩效奖金，看上年度的盈利水平和各部门业绩，确定发几个月工资（合同里仍会注明，比如：祝年终考核水平，年终奖为3-6个月之间。这部分没有扣税优惠，会交的很心疼）固定月薪加上以上两个部分的奖金，是入职之前谈年薪时谈的内容。对员工来说，这些都是提前谈好了的，属于应得收入的一部分。对公司来说，这种操作是为了减少风险（降低月薪，那么，第一，遇到不合格的员工，试用期开掉的损失会小。第二，等同于工资分期付款了，如果员工提前离职了，那么年终的工资等同于省掉了。第三，遇到极品，入职就搞个怀孕或者病假工伤之类的，每月负担要小一些。第四，万一日子不好过，需要裁员，离职补偿的时候也能安全一点。）还有企业为了避税方便，会吧入职谈的package，一部分月薪做成车补、油补、话补之类的。（当然，话不会说的这么直接，而是会说：我们单位福利很好的，每个月“还有”1200的车补/停车费补助、800的油补和500的话费补贴。但员工算月薪的时候，绝对不会认为是“还有”而是肯定在脑海里，把这2500当成自己的月薪。加上这2500以后，跟自己跳槽前的工资做比较。数额达到预期了才跳槽，达不到就不跳槽。所以你看，无论什么名目，最终都是月薪的一部分。如果某天突然说，为了保护环境，
