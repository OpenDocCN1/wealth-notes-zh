# 珍姐，这是想问您的

(提问)匿名用户：珍姐，这是想问您的第二个问题。老公在海口当地开了3家餐厅，目前一家社区店盈利不错，一家购物中心持平，现在又新开了一家。
一直觉得店里的菜品太复杂了
北京火锅+烧烤+小龙虾+炒菜+蛙，不仅采购复杂，还会造成食材浪费，如果不是味道好，生意分分钟被拖垮（底下附了菜单，因为菜品太多，有点模糊）。经常浪费大量时间研究不属于这个店定位的菜品，比如东北菜、朝鲜冷面、各种水饺主食都有十几种。
这次新开的店又在原基础上加了烤肉，我都替店里的采购捏把汗。
劝过，因为没有说服力，都不听。所以很想向您请教专业的分析，这样下去会有什么样的危害。不知道您会不会回答，都跟谢您！

2019-07-23
