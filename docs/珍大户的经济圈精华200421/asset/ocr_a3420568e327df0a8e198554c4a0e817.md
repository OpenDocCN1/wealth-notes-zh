# 有些好奇珍老师现在

(提问)匿名用户：有些好奇珍老师现在是偏重读书，还是从各类渠道获取实时信息更多？对这两类有什么建议吗？

2020-04-09

回答：【帖子编号0427】《世界全貌的拼图》上学的时候读书多，现在已经读书不多了。但是跟大家想的不一样，我获取“实时信息/新闻”也不多。更多的是，每天还在继续看着、积攒关于“现实状态/基本面貌”的信息。（来源于深度的研究报告、行业分析的文章，外出四处与人交流打听，乃至圈子里大家透露的点滴信息）举个例子来说：要不要屯大米？“我国大米年产量是xxx”，“自给自足率是xxx”，“每年进口量是xxx，进口国是xxx”——这类信息是基本面貌。“越南宣布停止大米出口”、“世界粮食署官员警示粮食危机”、“某某声称粮食充足”——这是新闻动态。了解基本面貌，这种内容能管好多年。了解新闻动态，这种信息效期很短。最早我刚当交易员的时候，就发现一个现象：每个人的反应速度/敏锐度是不同的。当年有个内部测试软件，反应速度在0.8秒内才算合格（超过这个数就太慢了，不适合当交易员，我刚好在0.8以内一点点，无论如何锻炼都不能进步了）。而有些人天生反应速度就低于0.6秒，反应超级敏捷。这些反应超级敏捷的人，每天追的市场信息进出出出，我很快知道，自己做不到。（能观察出来，这类反应速度飞快的人，往往都是体型偏瘦，四肢修长，手指长，生肖属猴属鼠之类的，星座是双子座之类的，O型血或b型血。而我是天生体型粗壮，手指短粗胖，生肖星座血型都是反应巨慢的，天生不行……）像我这样既不勤奋又不敏锐的人，如果每天去追最新动向，结果就是只会因为自己反应慢，而跑到别人屁股后面。所以我该怎么办呢？第0048帖说过一个关于孩子教育的话题：要看到更大的世界，见更多的世面，你才能知道这个世界上存在更好的选择。才更会有奋斗的动力。而解决我不够敏锐的方
