# 您好硕士[微笑]我

(提问)A乘黄公司一粒沙白：您好硕士[微笑]我很认真的有一个问题想咨询一下。我公司生产高中低档 木门橱柜衣柜榻榻米定制产品的，现在市场订单骤减，现在我想放弃传统渠道，以工厂直营的方式将产品直接以出厂价略高的价格推向终端市场，消费者直接可以拿到出厂价格。如果我这样做算不算市场变革，算不算低维度打击，算不算找到了降低交易成本的方法。可是，定制家具产品属于低频消费品，我又担心没有很大的销量。很纠结。劳烦赐教。

2018-12-06

回答：看见你的问题了。 首先需要分析市场订单骤减的原因。是外界因素（所有你的竞争对手都面临一样的情况），还是就是你公司自己的情况？ 销量不好的原因有很多种。排在前面的是产品和品牌（自身愿意）。其次是渠道是否存在问题。 各种原因都找的差不多，最后才是考虑价格（你在这里想的是价格低是不是就能刺激到销量）因为降价容易涨价难，所有能够使终端价格降低的措施，都是不可逆的。一旦你发现做错了，想要再改回去，基本改不回去的。

再看你说的这种工厂直接面对消费者，削减价格的方法。 我没太理解，怎么直接面对消费者？（希望你能解释一下传统渠道是什么渠道，直接面对消费者要怎么面对） 因为毕竟木门和榻榻米，就算定制，也是要上门安装的。应该是你的传统渠道承接了这部分的服务内容，所以你要改革，首先各个城市的服务团队又要重新组建，这样成本不见得能降低。 其次，最重要的其实是销售的渠道。价格降低肯定是有优势的，但是如果不能让消费者知道你，那一切都是白费了。 所以你在砍掉传统渠道的同时，有什么对策能够应对上面两个问题呢？ 来谈一下吧，看你是否细节已经到位了。(23赞)
