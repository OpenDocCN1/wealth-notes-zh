# 老师您好，原始股股

(提问)domperidon\*: 老师您好，原始股股权证分为正本和副本吗？我们购买的原始股只给我们了副本，而且协议中写明于2019年2月给我们提供正本，且封闭期结束时转换需要正副本一起，可是目前没提供正本，这个算是违约吗？副本能说明我的股权生效吗？
2019-05-18

回答：【帖子编号0278】看见“股权证”就感觉，你们可能进原始股骗局了。毕竟电视上和网络上还流传着，90年坐火车去收购原始股，然后上市后暴富的传说。很多人会以为，现在还和当年一样，花钱买到纸质的票证到手就ok。然而这么多年，法律都改过好多轮了，再也不是当年的情况了。现在国内证明股东资质，没有什么股权证，正本副本之类的。就 看两个体系。一个是工商的股东登记证明。第二个是，公司的股东名册。因为不是所有公司都愿意去频繁更正工 商登记，所以也可以以公司的“股东名册”为准。以上两条，一个保存在工商局，一个保存在公司内部，所有股东手里有什么呢？股东手里只有证据。靠证据甚至可以推翻上面两条。举例来说，假设一家公司，注册资本由500万增资到600万，等 于需要新吸纳那100万的资金进来。那么事前，需要这个公司的老股东坐在一起开股东大会出个决议，同意增加股东（同意吸纳你进来）事中，你和公司签一个认股协议，注明金额，股数，资金到账的时间等等，最重要的，协议中的得附上股东大会上，一堆股东签名同意你进来的“股东决议”，以此证明不是公司私下签协议骗你的。然后你把钱打进公司账户，附注写上“认股金”三个字。那么你手里的合同和转账证明就是自己持有的证据了。事后，你作为新股东和老股东，坐在一起聚集一堂，重开个股东大会，然后更新一下“股东名册”，如果可以的话，还要去工商登记一下。第2种情况，假设你的原始股来自于老股东转让给你，流程和证据跟上一种
