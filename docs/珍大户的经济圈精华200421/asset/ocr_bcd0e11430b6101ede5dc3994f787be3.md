# 再说下怎么选类目：

商标申请，每“一件”，商标局收费300元。

全部的商品大类有45类，不同类下，必须分开算“件”。

而每个大类下，又有很多细小的分类，300元只能保护一个大类下的10个小分类。（在大类下，多加一个小分类，就要多加30元钱）

所以，商标申请就分成了两种。

一种是，你真的有相应的产品，需要使用这个商标，那么你就必须要上把这一类下，有可能经营到的小类，尽可能多的全部选上。那么价格必然超过300块了。

有可能这一个商标，因为你需要用到，所以选了20个小类，最后这一件商标需要付600块。

另一种是自己不实际经营的，只是怕别人抢注，自己先抢注上。所以要用尽可能少的钱，来覆盖更多的领域，那么就需要策略了。
