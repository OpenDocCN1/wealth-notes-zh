# # 老师您好...请问一下

(提问)Mr.White：老师您好...请问一下沈阳的未来发展空间大吗？可否当下投资房产？看了您分享的房产分析，但大多数城市限购，本人沈阳户籍，政策允许再买一套，现在考虑中...请老师指点！谢谢
2018-11-29

回答：如果东三省还能有一个大城市，肯定就是沈阳了。然而，更大的可能是，一个都留不下。因为趋势还是挺可怕的，每年一点点，连续多少年，差距就会累积的蛮大了。 目前大部分省会是能够做到“吸引本省内人口流入”的，所以会有相对强弱的涨跌——省会相对省内其他城市，优势会越来越明显。在这一段省会与省会的竞争中，掉队的城市就是老龄化严重的省份，和本省内人口基数太小的省份。在这一段省会与省会的竞争中，强者还可以吸引别的省份的人过来。然而在这一段竞争中，还有一小部分省份，是参与不进来比赛的——就是，对自己省内人吸引力都达不到的城市...... 从人口变化趋势看，哈尔滨属于严重流出的，长春流出严重，沈阳，可能是黑龙江和吉林人的流出中，有部分进了沈阳，但即便如此，人口变化刚勉强打平，不增不减。但沈阳的老龄化程度全国出名，挺不了几年，靠死亡率都能把人口拖向净值减少的地步...... 所以，钱先持着吧。毕竟钱可以全国流动，但房子不能。(24赞)
