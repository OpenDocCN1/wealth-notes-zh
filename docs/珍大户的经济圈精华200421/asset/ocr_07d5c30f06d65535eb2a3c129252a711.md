# 聊一个大家没怎么做

姜科：聊一个大家没怎么做过，但是肯定遇到过的行业—选秀。

昨天晚上跟朋友一起吃饭，聊起他现在在做的生意，他现在在做电视节目选秀，偏重少儿。

模式是这样，由电视台或者文化主管部门发起一个全民选秀，比如XXX儿童模特大赛，XXX儿童舞蹈大赛等等，这些选秀节目影响力有高有低，普遍没什么影响力，至少他做的几个我都没听说过。但是有一些在圈内还是有些含金量。

这些节目发起后会在全国范围内找代理，由代理负责本城市的推广，包括广告，招生，安排赛事等等，而他就是他所在城市的代理。比如前一段时间搞了个舞蹈大赛，电视台要求他们筛选80人进入复赛。他们作为代理就要想办法筛选出这80个孩子。

收入来源呢，主要有这么几点：1.赞助商，尤其是新楼盘地产商很喜欢。2.住宿和培训费用。他所做的相对专业一些，来参赛的都是各个培训机构送过来的，没有基础的很难参加。那么就会涉及到需要安排住宿和餐饮，有些会有2-7天的培训。3.上一级给的佣金。按照送选的小孩子人数给佣金，一个小孩几百块钱，如果有小孩子进入决赛圈甚至走的更远，那每晋升一级他们会得到一定的奖励。4.服装道具的差价。对于进入复赛的孩子，他们会让家长准备专业的衣服，也不贵，一般选择市面上两三百一套的，他们和工厂谈个低价，赚些差价。

主要支出就是场地布置，租赁设备，广告投入，这些一般都交由一家文化传媒公司负责，全权打包给他们来运作。

赞助商的赞助是主要收入，原则上，这个钱要完全满足一次选秀的所有支出。剩下的就是稳赚的钱，主要是在培训上赚，一个人一次培训能净赚300-500。服装和食宿一个人能够赚50-100，这块不多，毕竟需要的人少，而且不是高档酒
