# ## 中证50不是指数基

(提问)zzz：中证50不是指数基金吗

回答：中证50，意思就是50只大盘股组成的指数。（指数成分等于这特定50只股票。）中证500，意思就是500只有代表性的股票组成的指数。不管是哪个基金公司，只要他们的基金是追踪同一个指数的基金，就得按照指数成分来配置股票。中证50就是买这50只股票，中证500就是买这500只股票。连比例都是固定的。所以指数基金，各个基金公司都是差不多的。你也不用担心什么基金经理水平差，或者基金经理搞老鼠仓什么的。指数基金就是【跟着大势走】，没有那么多要操心的。————我是建议大家自己挑股票买。确实有研究个股能力出众的人，赚的比指数更多。然而：1、这事有概率，有可能你研究半天，还亏的更厉害。2、对资金量不大的人来说，你自己花这时间去研究，不值得。之前直播的时候，有说过，每个人/不同的赛道上有不同的【上限】。对于工作的人来说，不同行业里会有个年薪10-30万的坎，标志着你是否走出基层。年薪五六十万又是一道坎，标志着你是否走到管理岗位。之后100多万则是工薪族的天花板了，能突破天花板的人很少，已经不取决于自己的努力了，则是需要站对行业、选对企业、需要机遇和贵人等等，需要很多运气因素。所以看自己在什么的位置。从0到突破10或者20或者30（看行业）不难，从20突破50就难多了，从50突破100，则没有机遇就不太可能。再举例，对于创业的小企业主、生意人，上限要略高一些（毕竟存在风险）。比如各种创业经营里，只要做的不好不坏、能活下来的，一年很容易能达到五六十万、六七十万的利润。想要冲过这个区间，就需要经营水平很高，领先周围的人，然而仅靠这种，
