# 您好，大户，法院拍

(提问)V270007878：您好，大户，法院拍卖房有哪些后遗症…….

2019-11-20

回答： 问清以下细节： 1，限购？ 问一下当地政策，法院文书能绕开限购吗？ 如果绕不开限购，最终你办不了房产证。 (不过也就是多等几年的事） 2，租约。 因为“买卖不破租赁”，会有人利用这种方式签下个15年20年的租赁合同。那样你就干瞪眼儿了……（这种是目前最坑。如果有话一定规避） 3，税收。 问清楚现在房子欠了多少税？一般买家税卖家税都要你个人负责的。 4，法院负不负责腾房？ 如果不负责，你需要实地调查一下，现在房子有没有老头老太，或者很凶的“社会人”住。 考虑一下把他们赶出去的难度。 5，打听一下欠的物业水电。 不过这一项跟税前比，应该都是小头了。__________ 听说某些法院为了便捷拍卖人，已经开始“含税一口价、包腾房”了。 这种遇到坑的比例就很低了。 (31赞)
