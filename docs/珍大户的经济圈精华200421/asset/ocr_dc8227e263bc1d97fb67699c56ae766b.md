# 请问一下。禽蛋行业

(提问)白手套～:请问一下。禽蛋行业会不会火箭蛋后，引发倒霉蛋，，印钞鸡变倒霉鸡？

2019-05-14

回答：【帖子编号0274】 如果碰上禽流感这种事，那没招。毕竟意外因素无法预期。但如果你只是怕行业因素导致的不景气的话，没必要。猪的问题一两年、两三年都未必搞得定。禽蛋作为替代消费，几年内都会很好。再长期看的话，就是消费习惯更迭的问题了。 对个人从业者而言，最大的变数其实是：冷链运输，目前价格已经降得很低了。这是利好大的养殖企业，利空小养殖户的问题。举例来说：（以下数字都是我为了举例说明，胡编出来的，只有逻辑说明意义，没有实际参考意义）假设，小户养一只鸡5元 钱，大厂因为规模化，技术高等等原因，养一只鸡4元钱。成本5:4（差价20%）如果都需要冷链运输的话，假设运费5 元，两者差价就变成了10:9，差价变成10%了。（意味着，如果距离优势能够降低超过10%成本，那么小户是有竞争优势的）现在冷链运输价格已经降低到可以堪比普通快递的价格了，比如假设运费1元。那么比例就变成了6:5，差价17%。如果运费继续降低到0.5元，那么成本就是5.5:4.5，差价约 18%。运费比例越低，越能提现任低成本的优势。那么，大厂的打击距离越远。 不过我并不了解养鸡这个行业。或许大厂小厂之间的成本差异并不大，那么上面的问题就不是问题了，红利大家可以一起吃，挺好。(21赞)
