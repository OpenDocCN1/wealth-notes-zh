# 老师您好。这是我们

(提问)快哉风：老师您好。这是我们开的一家小儿推拿馆，效益一直不是太好，想向您请教一下。我们的店面在小区的侧门，不是正门，这里不允许车辆和摩托车经过。人流量的话比较少，人注意的也比较少一些。

小区里面有1500多户住户，但是知道的人特别少，发的免费体验卡来的很少有人要，小区里面也不允许做活动进行宣传，怎么样能够让小区里面的人更多地知道这开着小儿推拿店，或者说是说有机会接触下？

2019-04-17

回答：不好意思，我的头脑里遇到了盲区。 关于“小儿推拿”，我完全没有概念。这项服务是针对哪一种使用场景的呢？ 具体来说，肯定是小孩儿。但是什么样的小孩需要推拿呢？推拿之后，“理论上”能起到什么样的效果呢？ 因为小孩子大都不会表达，所以这种理论上的效果，是如何传递给付费的孩子父母，或者孩子爷爷奶奶呢？ 我比较担心以下原因：（因为我完全不懂小儿推拿是什么，所以仅作猜测）第一，小区居民的年龄结构。里边的小孩有多少？如果年龄结构与70后，甚至60后为主，可能里面小孩就没多少。 第二，你们宣传主要针对小孩的什么症状呢？在小孩中，有各种症状需要推拿的比例又有多高？（因为我也没孩子，具体某些症状到底常不常见，我也确实不懂。） 第三，就是居民中，像我这种对小儿推拿连基本的认知概念都没有的人，又占多少呢。如果比例不低，那么，怕是这个地区的市场，你可以放弃了。(16赞)
