# 我亲戚被说的很动心

(提问)□□:我亲戚被说的很动心想去卖保险，学历中专，请问卖保险有前途吗，这个行业真实情况怎样？那种开会很鼓动人，想知道真实情况，到底有没有发展前途，是不是一个月几万收入？真实情况到底如何？目前现工作一个月能有一万多，想辞了去卖保险，您建议吗？谢谢□□

2018-08-27

回答： 【帖子编号0015】 确实有一月几万的情况。 销售保险这种产品，比销售其他商品的优势就是，提成比例及其的高。 但是需要详细了解能达到每月几万的几种路线，看是否有适合自己性格和能力的。 1.社交销售型，从自己周围的社交圈开始，一层一层向外辐射（这种人天生适合干销售，即便不销售保险，也可以销售其他产品） 2.保险专家型，不仅仅像上一个类型那样对外宣传“买个保险多好”，而是能够解决“买什么保险，买多少保险”的问题，相当于可以给客户私人定制保险计划，甚至是香港或其他海外地区的保险。 3.关系销售型，维护本地大中小单位的社会关系，拿到大型国企、学校等各种事业单位的团体保险的单子。 4.新媒体销售型，利用网络搜集分散的客户（最近几年新衍生出来的方法）或者你想想还有没有其他路线。 保险销售也是销售，必须仔细考虑自己性格适不适合干销售。如果适合干销售的话，我觉得同样的人去销售不同的东西，也会有不同的人生境遇，总体来说，我持有以下观点： （1） 当对公销售（面向企业客户的）优于对私销售（面向个人客户的）。 （2） 高单价产品（如面向企业的大型设备、面向个人的车房等）优于低单价产品（如日用品销售） （3） 高利润率产品（更可能支付高提成）优于低利润率产品。 从这个角度来讲，保险的1和2，可对公司对私，金额可大可小，虽然不是最好的，但也不差。而3，保险算是属于的（大部分人寿保险的销售提成应该比卖车高）。(24赞)
