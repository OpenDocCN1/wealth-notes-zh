# 如何给公司取一个好

(提问)袁鹏Neo口：如何给公司取一个好名字？好的形象？ 2019-03-15

回答：什么都不想的话，那就是查重，找一个不重名的就行了。如果想得多，首先要思考一下，你们要面对的客户群体是谁？年龄段，区域，共同的群体特征等等。一个好名字，首先在你的客户群体眼里是好名字。面对中老年人50岁朝上的，最传统的字词，什么康，什么正之类的，基本接受度很高（翻字典背面历史朝代表，在过去的帝王年号里找字，基本不会出错。注：年号在位时候定的，死了定的叫谥号，谥号没准有什么“哀宗”之类的就不好说了，但是在位的，一般不会有问题。）同理，如果客户是政府机构之类的，你跑政府工作报告里找字词重新组合。面对中年中产人群，已经经过众多轮市场开发洗礼了，别直接谈钱，什么“鑫”、“利”、“金”、“盈”、“泰”之类的，一看就是土鳖暴发户。也别太直白。你是做什么的，就往什么上靠，这种是90年代做法了，对现在的中层来说过度直白了。要认识到马斯洛的需求层次理论——客户越高端，你越得有点理想、精神层面；用户市场越下沉，你越得直白、实用主义。举例来说：几十万的电动车，肯定是二辆以上的改善需求了。五万以下的代步车，必然是下沉市场。所以“神驹”、“酷驰”、“雷电”、“金速达”、这些名字应该用给谁？“深蓝（贴一些类似诗与远方的名字）、“rubyone（与车无关的高档玩意）、“旗鱼（其他动物）、“凡尔纳（历史名人）、“摇光/参宿（星星名字）、等等，这些名字该用给谁？（以上名字是我随口想的，未必多好听，就是随手举例，传达一个基本观念。真到起名时，你们肯定会比我上面举例更深思熟虑）（再类比点无关的……需求层次理论，大概就跟追女生一样，文化和阶层不高的，给人讲黄段子，直接说性；稍高一些的，要谈爱情，讲情话；再高一点，改谈理想和认知……谈科学与艺
