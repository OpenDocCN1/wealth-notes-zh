# 姐姐好，第一次提问

(提问)（^v^）：姐姐好，第一次提问，关于择业的问题，不知道合不合格，如需要更多细节，我及时补充。

2019-04-25

回答：【帖子编号0256】第一个问题，关于交叉型行业，到底要不要去？比如提问里提到的“移动出行”，这个行业是新型行业，可以去，但不是所有专业都可以去。这个行业算是IT和交通行业的交叉行业。你要看各个专业技能，在其中的重要性怎么样。IT技术，在里面很需要，所以学it的人可以进。这个行业也需要用到路线规划这些技术，所以学交通规划、运筹学专业的这些人也可以去。但你是学汽车专业的，你就不能去。因为你所掌握的技能属性，在里面不重要，你又是一个以“技术管理”立身的人，既然你所学的技术在里面不重要，你自己连带着，在里面也很难有重要作用。（除非你是以个人特质、个人属性立身的人，比如销售技能、社交技能、公关技能等等，那么你就不需要考虑行业的技能点需求，各个行业都能需要你。）另一个提到的行业，汽车金融。听起来像是汽车行业和金融行业的交叉，但其实不是。因为汽车虽然是大件，但仍然属于消费品。消费品的信息要透明的多，所以其实对“汽车”方面的知识和技能需求的并不多。我举一个例子，你对比一下就明白了。如果是大型的采矿机器，这个东西值多少钱？抵押贷款能贷多少？如果是工厂排污设备呢？如果是机床、仪器呢？如果是医疗检查设备、核磁共振呢？跟这些东西相比，你还觉得汽车金融里面，会需要很多汽车知识吗？（所以上面举例这些领域，是可以需要有一两个理工科、化学专业、医疗专业转行的人才的。然而汽车金融专业不需要汽车人才。）所以汽车金融这个行业，我建议，学金融的人里面，如果对自己核心竞争力存疑的，觉得在主流金融战场不好竞争出头的，可以找这些非主流战场。包括汽车金融，包括各类抵押贷款、互联网金
