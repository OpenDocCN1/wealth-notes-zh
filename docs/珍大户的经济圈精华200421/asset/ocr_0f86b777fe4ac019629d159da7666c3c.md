# 珍老师，您好！我姐

(提问)匿名用户：珍老师，您好！我姐前几年在上海翡翠寄卖公司工作，后来就自己干，在云南、广东、北京辗转，生意不见起色，现又去了郑州，家人都在上海，总是聚少离多，这样下去我担心事业不成，后院又着火，想问一下翡翠这个行业前景如何？请指点一下

2018-09-27

回答：【帖子编号0115】这个行业，用经济术语说，对经济环境的弹性特别大。 翻译成俗话，就是：只有在经济环境好的时候才有顾客。一旦经济环境不好，就没顾客。所以今明两年，经济环境不好，靠吃老本渡日吧，家底不够，就撑不过去的。 为什么会这样，因为它是纯炫耀性消费品，保值和转让的功能开发的不太好。 拿些类似的产品做比较： 1，黄金首饰，很多老人都会有买黄金首饰保值的心里，并且，这个东西确定是能回收的（工艺价值比较虚，但按克计算，是实打实保底的） 2，瑞士名表，这玩意儿在国际上，都快变成硬通货了。当年犹太人被迫害，全部家当换成几块表，套胳膊上，身上套难民衣服一盖，出境，再换回钱，基本可以保障身价不受损失。 后来瑞士人有意控制产量，产量比各国的中央银行印钱的量控制的好，所以二手一直能做到保值增值，算是硬通货了。 3，爱马仕等限量包，价值稳定，二手还经常增值。 4，钻石，这个比上面三类已经坑多了，除了大克拉的原钻，钻戒等首饰一买上就贬值一半，而且不少店铺是不收钻石的。但仍算有转让市场的存在，靠4c标准来衡量价值。 上面这些东西，尤其是123，因为存在二手流通市场，所以产品由消费品，转身升级成为投资品了，也因此能够穿越牛熊。 反观翡翠，二手流通，变现慢，价差大，因此很难脱离消费品，变身成投资品（虽然无数销售会告诉你，这玩意儿能投资）没有这种转变，那么一个炫耀性的纯奢侈消费品，受经济周期变动真的非常大。 ——（以下是经济方面的
