# 大戶您好，非常荣幸

(提问)千里眼视力:大戶您好，非常荣幸能加入到您的经济圈，您知识渊博好魅力！我是一名医生，想起盘做健康养生系列项目连锁加盟，有成熟的产品和技术。想本本分分的做，不夸大宣传，靠技术产品赢口碑。这个行业本人知道属于暴力行业(其它行业我也没有做过)，投资也不大。首先我考虑终端客户的需求和持续消费，我把一次保健的价格放低比如五十元每次，要的是顾客重复消费和店内其它衍生品的输出，店内只要有持续客流量，就会有利润空间。不知道我这种思维模式可行吗？目前可以做的项目有鼻腔护理、眼部护理、男士保健、妇科护理、小儿推拿都可以做。大戶我这种想法可以落地吗？这种想法最致命的缺点是哪方面？坚决反对某健直销轻松调理各种癌症！脑细胞随意激活

2019-01-31

回答：【帖子编号0227】我感觉你可能没考虑到周转率。客人做保健的话，需要占用多大的空间，多长时间？暴利只是毛利率高，毕竟直接的材料成本没几毛钱，但是房租、装修、设备的钱需要摊销进去，有个最低的时间价值。假设房租A元每平每月，算几个档次：A1，300元(一线城市不少地方是十元以上)A2，230元(合肥万达茂商场的价格水平)A3，150元(我不知道具体每个地方什么行情，在此只是打个比喻)，假设你店面150平，那么每个月房租就是4.5万(A1)/3.5万(A2)/2.3万(A3)。商业的公摊蛮大，使用面积可能只有100，里面扣掉前台接待区间，后台保健区可能只能同时接待6个人。但是不同的项目、不同的设备锁，肯定不可能满负荷的，但在此先不计算。人员，你一个医生作为支柱，带加三到四名助手。那么人力成本，最低也要2万一个月(最低水平)。以上是最大的成本。医疗设备需要多少钱我不太懂，装修医院风格或者偏工业风格，成本会比较节省，另外水电费，各种点评/美团的抽成，这些都属于小头
