# 亲爱的珍老师：我和

(提问)匿名用户：亲爱的珍老师：
我和三位健身行业朋友一起在南京新区的绿地广场写字楼一楼底商开了一间24小时的健身房。按照现在的经营状况估计要两年才能回本前期投入和成本。我们定位是小而美型的健身房，用户通过手机扫码进店夜间无人管理；价格最低七八百的季卡，私教均价在300左右一节。现在又出现了乐刻这样通过融资的健身房只要99一个月，这类健身房就是更小，器械少，没有淋浴间，没有服务人员、私教课卖的也便宜。我们的定位更是显得不上不下了

新区市场就这么大，当时空白。现在光绿地广场已经出现了一家专业瑜伽馆、一家乐刻24小时健身、一家私教工作室。远一点的还有更全的大型健身房
请问我们怎么下面怎么样才能更好的差异化经营下去呢
2019-01-06

回答：【帖子编号0205】翻了好久，终于把几个月前的这个提问翻出来了。因为最近特别想去健身。但是看来看去，发现健身房行业真的生态环境不太好。对想办健身卡的人来说，很明显会觉得健身房套路太多。然而在我看来，健身房老板应该也很日子不好过吧。毕竟，面积越大，房租就越高，每个月的房租水电，保洁前台的工资，都是净流出。所有人健身都图便捷，找近的。所以健身房的覆盖半径是非常小的。扣掉老年人和学生，再扣掉时间不够的，没兴趣健身的，剩下的精准目标客户群体，数量是有限的。这么有限的人群里，经过促销办卡之后，一次性收到了钱，然后顾客不来健身，对健身房来说，是收益还是损失？很多健身房认为这是收益，赚了卡的钱，连水电的成本都省掉了，然而在我看来，这明明是亏损。因为等同于这个顾客就死掉了。他不会在给你第二次利润。健身房打算跑路吗，如果不跑路，那么每个月都要有支出的，以后怎么办？前面办一年两年三
