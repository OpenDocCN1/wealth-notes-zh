# 美丽的大户，我之前

(提问)陈小 米:美丽的大户,我之前在合肥工作过一年半,对合肥印象很好,但是觉得合肥被低估了,首先是城市规划很好,没有像武汉那样大面积的老城区,此外发现合肥有很多金融,像四大行、人行等各大中心一条街,当时觉得以后合肥可能会发展成全国金融中心(地理位置上非常适合,离上海很近),不知道我这种想法对不对?2019-06-20

回答:【帖子编号0303】合肥这里规划了一个金融后台中心。同样的还有郑州,也规划了一个金融中心。事实上很多城市都觊觎金融产业,想要建金融中心。但这是不现实的,对这种不切实际的城市远景,我一口嗤之以鼻。0174帖 写过一个观点,越是高端产业,越是只有寥寥几个城市才有。但0174帖写的太抽象了,可能大家会觉得难以理解。我用现实情况的来举一个例子。大家搜一下“欧盟罚款谷歌”的新闻。欧盟反复罚了谷歌好几次钱了(而且以后还会继续罚下去),每次都几十亿欧元的罚款。为什么呢?无理取闹吗?原因是这样子的:谷歌是全球人都在用的网站(同理于他们旗下的油管、安卓什么的)。这个公司注册在美国,经营地点也在美国,但实际上,这种服务是全球性的。一个欧盟的公司,比如坐落在巴黎的一家小公司,假如,是卖家具的,那么这个小公司其实是只服务于巴黎本地人的。在谷歌出现之前,这家小公司,会在本地的报纸上刊登广告,宣传自己的家具店。如果做的大 的话,没准会往巴黎某电视台、巴黎某电台,甚至公交车车身上做广告,来宣传自己的家具店。过往的这种金钱流转,都只停留在巴黎内部,你会发现,钱根本没流出去,只在本地之间转啊转。然而谷歌出现之后,情况不一样了。这家公司会改投谷歌的地域用户广告。投广告的公司是巴黎企业,看广告的对象是巴黎市民。然而,广告费却是给美国公司。于是钱就流出去了。谷歌是美
