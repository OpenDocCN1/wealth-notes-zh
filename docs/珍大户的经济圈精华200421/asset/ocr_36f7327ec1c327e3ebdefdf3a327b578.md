# 珍姐你好，我是在江

(提问)阳光：珍姐你好，我是在江苏无锡从事餐饮店（安庆馄饨店）的。目前自营一家生意还算稳定。也有几家加盟的不过都是亲戚。只是在我这买料子不收什么费用。我们这个牌子不好注册商标带地域名的，但是这边人就认、想着珍姐学历高能否讨个名字。想着注册以后自己开个连锁店。

2018-10-31

回答：【帖子编号0156】《商标》店名叫“安庆馄饨店”？用地名无法做注册商标。如果不能注册商标，那么理论上谁都可以用。你所谓的亲戚加盟，你又没收加盟费，又没收他们材料钱，咋能算加盟呢。只不过人家近水楼台先得月，既然张三李四都用得，二姑三姨用还能用不得？提醒所有有雄心小生意主（哪怕没有雄心做大，我也要提醒，你吧目标设100分，才可能完成60分，你把目标设成60分，最后怕是只剩30分了）无论多小的店，都要从长远考虑，如果你从最开始，就没做好店名的起名，和logo的设计，以及商标的保护工作，那么万一做大了，就有得后悔。就像我在网上写个文章，一老早就想着先设计个头像（防止个人照片形象变化，导致识别度降低），起个上口又不重名的好名字（毕竟网上一搜珍妮，就出一串珍妮佛安妮斯顿……）我也不知道哪天会火，但准备工作要做好。同样的，抖音上“商业小纸条”，这个名字起的跟拍脑袋一样，到现在连姓甚名谁都不知道，而且辨识度太差，因此也无法在其他网站上平移过去，包括他们整个团队什么“xx说创业”，全部都犯了这个错误，这是绝对的商业失误。我猜肯定有不少人后悔爹妈给的名字，但至少别给你自己的商业项目留遗憾。(42赞)
