# 珍大卢，你好。我想

(提问)、媛媛:珍大卢，你好。

我想请问一下，有这样一个平台，叫购车无忧。它是一个商贸公司做的，具体有两种业务，一就是油卡业务，5000块钱一个单位，比如你投10000到他们公司，次月每个月返还1000，共反20个月。开始的时候每个月都返1000，后期政策改到第10个月返60%，（到第20个月返还结束，如果你不排车就一次性付给你每个月扣的40%）如果你第十个月参与他们的排车活动，就还是会返还1000，直到返够20个月结束。二排车活动，分三赠一队，五赠一队，比方说捷达车6万，如果你排三赠一队你就交30%，外加2000会员费就可以等到排到你提车，大票绿本全是你的名字，五赠一队交20%，依此类推。

2019-02-17

回答：新鲜的骗局又出来了。第一个模式搞返还的，就是资金盘/庞氏骗局，参考这贴 第二个模式是赌博做庄，会员费是给庄家的抽成，剩下的参与者之间，互相摇筛子赢大小罢了。赌博做庄，实际就是一个概率游戏，一堆人之间的零和，如果算上庄家抽水，那么参与者之间就是负和。赢的人赚输家的钱罢了。最小的赌博坐庄，其实是微信红包刚出来的时候，很多红包群，进群就可以免费摸红包，但是摸到最大额的那个人，要负责发下一轮红包。群主是庄家，群主不参与发红包，只摸红包。这种就是最最基本的赌博做庄。以上两个骗局，如果想赚钱的话提供一个方法。先找当地派出所咨询，举报赌博给多少奖励？（因为举报赌博会没收赌资，一般会有个赌资返还的奖励，比如10%，也是不少的钱了），咨询好以后，然后拿到庄家给的宣传材料，比如微信截图或者是录音，直接举报公安局，等着发钱就可以了。要是当地公安不发钱，或者你是有闲钱，非想参与赌局的话，听姐姐的话，现在去买A股好了，都熊三年了，至少现在进去
