# 珍老师，中小学生研学教育体验这块前景怎么样？

(提问)匿名用户：珍老师，中小学生研学教育体验这块前景怎么样？

2019-09-07

回答：【帖子编号0354】《中小学游学》按照教育细分这个帖子里写的三轮竞争：第一轮先拼分数。高分的孩子越来越多，分数区分度不够的时候，第二轮就变成了拼“加分”。英语奥数音体美、素质教育项，拼“加分”。第二轮比赛区分度还不够时，好学校面试的孩子，个个都是考试接近满分，每个人都英语口语牛B，学过奥数还会个乐器的，区分度又不够了，这时候就是第3轮了，拼父母和家境。研学教育说白了就是游学，带着孩子去见世面。其实就是这一轮的性质的。的小外甥不记得几年级了，暑假花了六万去英国参加夏令营。去年的热门电视剧《我的前半生》里，凌玲给亲儿子报了三万块的美国夏令营，给前妻的儿子报了八千块的国内夏令营，应该都属于这种。这种项目是有前景的，因为确实是消费升级过程中刚出现的新产业，历史还很短，完全还没有经过充分竞争，所以市场还没有经过充分开发，利润空间也很大。做的时候一定要注意地域属性。一线城市和富裕城市、富裕省会直接做高端项目。其他不够富裕的省会，用高端项目做“价格、品味的锚定”（锚定我讲过，老视频里有个蛋糕店门口开放高档婚礼蛋糕的例子），然后主推国内的游学项目积累客户数量先。（比如我感觉合肥就不属于富裕城市，购买力肯定比不上杭州南京。总之，要兼顾到当地的消费能力）(25赞)
