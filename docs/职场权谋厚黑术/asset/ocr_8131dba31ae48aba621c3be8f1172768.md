# 第六章：体制内应掌握的83条基本规矩，让你省五年磨刀功

虽然，已经写了七篇付费的文章，几乎将我关于体制内的感悟写完。很多同志，看完以后，点点头，嗯嗯嗯，觉得写得不错。但是，却没胆量在工作日常中贯彻。人最大的勇气，就是敢于改变自己。不能学其道，而不用其道，这样学到的一切都只能是像赵括一样，纸上谈兵，叭叭叭地教别人可以，轮到自己上了，却熊包一个了。很多人建议我再写把这感悟写得详尽一点，恰逢大领导进京开两会，事情相对较少。借办公室电脑，敲下如下83条，让各位体制内的年轻人，更进一步的了解体制内的台面上的事和台面下应该注意和了解事。，很多道理可能你们都懂，但是没引起重视，或者没去做。希望你们若真觉得老A说得有道理，便落实在行动中。承蒙各位看得起，大家都是付费看文章的，十几块钱，对于涨薪后的体制内人来说，不算多，但是看后没收获，没改变，也没什么意思，既浪费了金钱，也浪费了时间。

所以，我盼各位要做行动上的巨人！

开始：

+   1、每天上班，要把自己收拾干净，穿着整洁，不留指甲，尤其是男同志，更不要留长指甲。每天洗头。给人一种精神的印象。尤其是头发干净，千万不要临风飘香屑。打扮可以稍时尚，但不要大图案，尽量穿成熟一些，不要装扮成小可爱，单位不是家，没人看到你可爱，便给予你父爱，除非干爹。

+   2、抽时间把单位的工作手册认真的看一遍，知道自己该做什么，不该做什么。免得以后被老资格忽悠过来忽悠过去的。

+   3、年轻人，如果家中没有特别重要的事，尽量早一点来，晚一点走，平日里八个小时，谁高谁低、谁敬业谁懒散，领导看不出来。但是如果你坚持在八小时之外找机会，一天不行两天，一个月两个月，一年不行两年，领导一准会发现一个敬业的你！

+   4、年轻人初进机关，待人接物说话做事，把握好一个度，既不用力过猛过度表现，处处都有你，哪哪就你能。也不要羞羞搭搭小家子气，或懒惰，或骄气，都不好。大大方方说话，面带微
