# 第五章：体制内答疑 20 条

一、问：我是某乡镇公务员，工作三年了，今年我们乡的副乡长转正成为乡长。年底了，我去他办公室送了两千元，他死活不要。说：心领了，心领了。我放下就走了，但是第二天他路过我办公时又把钱给我退回来了。我该怎么办呢？

答：他不要就算了。你们的交情未必达到要收你钱的份上。一般送给领导现金，有两种情况，一是有求于他，二是有恩于你。这两种情况，领导一般会收下。你一没什么求他的事，他又未曾帮过你过什么，所以不收是很正常的，并非对你有偏见。新的乡长，刚上任，恪守下廉道很正常。下次别送现金，送东西。

二、问：我想去给局长拜年，但是有没打听到他的住址，所以我想直接把东西送到领导办公室。但是，提着东西去领导办公室不太好吧。我打听到他有一个小儿子，现在正在读小学一年级。我该送点什么好呢？答：单纯拜年，一般都是送烟酒。找不到住址，就送到办公室也可以。放在背包里，说句给您拜个年，放下就走。不要打算在这个节骨眼上给领导汇报工作，汇报工作，速战速决。领导收了东西，以后你有的是时间来找他汇报工作。

如果有孩子，你可以买一套百八十块的套书，准备个红包，放在一起，给领导时就说，过年了，也没给大侄子买什么东西，就买了一本书。

三、问：我在畜牧局，是合同制的工作人员，没有任何编制。工作五年多了，领导对我都挺好的。我在过年过节的时候也会给领导送礼，送钱。但是领导都不要。领导说我也听不容易的，工资也不算太高，只要把干好就行了，不需要做这些。

现在马上过年了，我真的就不去送了吗？

答：领导从不收你东西，是领导怕收了你的东西，你会提一些要求。而你提的要求，恰恰是他没能力办到的。比如，你提解决编制的问题。我建议你好好打听一下，其他单位的合同工有无解决编制的先例，哪怕是工勤岗。
