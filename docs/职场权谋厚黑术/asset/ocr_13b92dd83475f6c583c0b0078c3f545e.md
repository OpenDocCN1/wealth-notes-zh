# 单位里的老实人，都有这些毛病

老A按：可怜的人，总有不可爱的地方，比如说单位的老实
人。老实人一般都有以下几点不可爱的地方：

+   1：藏才华，掩抱负，坐等伯乐

持有这种心理状态，说明你是一个对自己的能力缺乏自信的人，有极强的依赖性与惰性，也许你会默默地做许多工作，而且是一些对你来说，引不起任何兴趣与激情的工。
作。

但由于抱有这种心理，不会努力去争取感兴趣的位置，更不会向领导展现特长与才华。只希望领导朝一日，看到你勤奋工作的样子，进而发现你、提拔你，而你在他发现你这位“能人”之
前，所做的只是苦苦地等待再等待。

+   2：太在意别人，小错也自责

由于本身谨小慎微，深知在单位人际关系很重要，熟知人言可畏的后果，所以处处留心，生怕得罪了同事或领导，生出什么枝节。常常有求必应、笑脸相迎，从不对人说过“No”，渐渐成了办公室里，最遭冷漠的一个人。有时会感到疑惑和委屈，许多额外的工作，占用了大量的时间。其他人的思维定式是：过度随和，使人觉得虚伪，不可相信。

+   3：不求结果，不推销自己

婷为了一个讲话，几天几夜地泡在办公室，直至最后定稿。
