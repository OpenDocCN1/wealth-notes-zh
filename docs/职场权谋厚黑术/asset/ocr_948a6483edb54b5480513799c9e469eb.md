+   9. 不要贪小便宜不要贪财，钱再多也有花完的时候。

+   10. 屋里有人的时候，出门要轻手关门。

+   11. 学会温柔学会聆听。

+   12. 如果问别人话，别人不回答你，不要死着脸皮不停地问。

+   13. 不要跟同事议论上司或其他同事的是非，你的无心之言很可能成为别人打击你的证据。

# 个人素质篇

+   1. 坐椅子不要翘起来。

+   2. 最后一个进门要记得随手关门。

+   3. 送人走要说：“慢走。”

+   4. 站有站相，坐有坐相。

+   5. 捡东西或者穿鞋时候要蹲下去，不要弯腰撅屁股。

+   6. 别人批评你的时候，即使他是错的，也不要先辩驳，等大家都平静下来再解释。

+   7. 做事情要适可而止，无论是狂吃喜欢的食物还是闹脾气。

+   8. 人活在这个世上，首先要学会一个“忍”字。

+   9. 任何时候对任何人不要轻易告诉对方你的秘密。

+   10. 钱不是靠攒的，会花才会赚。

+   11. 学无止境，不仅仅是学书本知识，更要学会怎么待人处事，社会远比你想象的要复杂。

+   12. 做事情，做好了是你的本分，做得不好就是你失职。

+   13. 是你去适应社会，不是社会来适应你。
