# 二十四、金字塔的规律

为什么每个人都喜欢带上一定乌纱帽呢？不是因为它能给你带来每个月多几百块的收入，因为他能够让你觉得站在金字塔的上端，让你觉得自己能够更多地掌握自己一部分的命运。因为，相对于垫底的塔基，你越往上走，你对自己处境的掌控能力就越大，当你爬到一个副局长的位置时，你会发现，在这个单位，只要你自己不犯事，基本上没人能动你，也没人能随意调派你了。但是，塔基虽然垫底，但是它最平稳，风险也越小，塔尖虽然很显眼、很风光，但是稳定性也越小，风险性也越大。

# 二十五、竞争上岗的学问

很多单位都搞竞争上岗这一套，美其名曰为了公平公正，其实主要的决定权还是在领导手中。突出民意、强调民意，并不一定就是遵从民意。但是，相对于一把手搞一言堂提拨人，竞争上岗对于大多数人来说，还是可以争取一下的。竞争上岗需要演讲，在台上不能全部都讲专业的事，这不仅因为别人在那种场合下，很难进入你的业务细节和情境，更因为你在上面说得越起劲，下面听的人会越来越觉得烦：怎么就能干呢！也不能把发言全部说成自己的工作总结，否则别人会觉得：怎么就你干活了。也不能抨击单位之弊，虽然在争取民意上，效果可能很好，得票会很高，但是领导是不爽的，哪怕是最没小心眼的也会恨你。因为他会想：你有这么多意见，可以平时来办公室交流啊，为什么非要弄到场面上讲？最好也不要长篇大篇地讲对单位蓝图的描绘，你描绘的越好，也保不准会惹了大小领导中的哪一拨人不爽，他们会想：你懂个屁啊，一个小人在台上滔滔不绝地宏大叙事，多搞笑！领导也可能在你的一堆蓝图中听出相反的意思，比如觉得你是影射他干得不好，所以你才会有这么多想法。
