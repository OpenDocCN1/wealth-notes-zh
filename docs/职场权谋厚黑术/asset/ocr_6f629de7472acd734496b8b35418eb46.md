党委和政府，一年能发布十几个或二十几个不等的文件。

还有一类文件是以县委办和政府办的名义下发的文件，这些文件一般是常规性的工作，或一些临时性的工作，如开展植树造林活动，环境卫生整治，机关作息时间安辑等事项，这样一些工作和事项一般都是由党政两个办公室联合或单独发文，文件也较为正式，也以红头文件的形式出现，也编有文号，这样的文件较多，也是党政发文的大头，一般每年三四十个或四五十个文件不等。

对县市党政机关而言，更多的文件是一些针对某项工作，或某个部门的请示而做的，一些指示性和批复性的文件，此类文件一般不以红头文件的形式出现，而是白头文或以文件处理单的形式出现，上面标有主要领导，的批示和指示。

以前的文件一般通过邮局或专人，递达到每个单位和部门或相关的个人，现在则一般是国内部的公文网以无纸化的方式由各单位和部门在网上下载。当然不论红头文、白头文，文件的拟定和形成，皆需要有一定的格式和要求，包括拟稿人、批准人、字体、字号、页眉、页边距和落款以及发放的范围等，皆有一套具体的规定和要求，不能随心所欲。

# 三是典型带动法。

即在开展一项工作或活动前，先培养和发现一处或几处典型单位或典型人物，通过宣传典型的做法和事迹，来带动面上的工作。这些典型有的是事前树立和培养，有的则是在工作中发现。

当然，这些典型大都较为正面积极，反面典型一般很少使用。在具体的运用时，一般是通过当地新闻媒体进行宣传报道，有时也由县委和政府出面组织报告会，到各乡镇和单位进行巡回宣讲，有时也组织各乡镇、各重点企业和部门到典型所在地，进行实地观摩和学习，通过这些形式以激起每个单位和个人的工作热情。在此基础上，党委政府再顺势而为。

具体而言，单位典型以观摩学习为主，个人事迹典型以宣传报道为主。此类方法以前偏重于经济领域，如新农村建设、企业管理等方面树立几个典型单位，并加以总结推广。而今则大多用在社会管理和意识形态领域，且大都为优秀个人。
