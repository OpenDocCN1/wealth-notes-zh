# 盘点在单位，我们经常忽略的基本礼仪：

# 吃饭礼仪篇

+   1. 别人给倒水时，不要干看着，要用手扶扶，以示礼貌。

+   2. 吃饭要端碗，不要在盘子里挑拣。

+   3. 帮别人倒茶倒水之后，壶嘴不要对着别人。

+   4. 盛饭或端茶给别人时，如果中间隔了人，不要从别人面前经过递，而要从别人后面绕过递。

+   5. 在酒桌上与别人碰杯，自己的杯子一定要低于对方的，特别是对方是长辈或领导。

+   6. 吃饭的时候尽量不要发出声音。

+   7. 递刀具给别人要记得递刀柄那一端。

+   8. 给人递水递饭一定是双手。

+   9. 吃完饭退席时说：“我吃完了，你们慢吃。”

# 同事相处篇

+   1. 别人对你说话，你起码要能接话，不能人家说了上句，你没下句，或者一味地说着啊啊啊，是是是。

+   2. 有人盯着你看的时候不要直视对方，假装没注意到。

+   3. 别人释放“有毒气体”的时候不能嫌恶地躲开或者拿手扇，装作若无其事。

+   4. 被领导训斥的时候，不要低头，要直视领导，面带微笑，表示接受批评，领导的火就会慢慢消退，否则，领导会火上加油。

+   5. 洗了手不要随意甩手，水会甩到人家身上很不礼貌。

+   6. 不揭别人的短处。

+   7. 听别人说话的时候，眼神不要游移。这样显得很没礼貌。

+   8. 说道就一定要做到，做不到的就不要承诺。
