# ### 应该攀谁？

再给大家讲技巧性之前，我先给大家讲一个选择的问题，这个选择的问题就是单位的领导那么多，到底该攀哪一个，都攀的话没有那么多精力啊？当然不能所有的领导都攀，一是我们没有那么多精力，二也不必要，不需要攀那么多，我认为在单位，只攀附一个就够了，但是具体该怎么选呢？到底该选谁呢？这个选择是很重要的，不然你随便攀附一个领导，你对他付出真心一片，到最后才发现，这个领导是个白眼狼，或者是一个不识好歹的领导，那么你付出的心血都是白白付出的，所以这个选择你一定要慎重。

# 选择要注意那些标准呢？

首先，这个领导一定是要愿意帮助自己身边的人的领导，并且为了照顾身边人，舍得下大力气，这个应该好打听，也好观察，你可以观察这几年围绕在这个领导身边的人，现在到底混得怎么样，就可以大概知道你愿不愿意帮助自己的身边了，这个是非常重要的，你一定要看清楚，有些领导看上去，好打交道，就觉得这个领导可能会照顾自己的身边人，因为很多领导是典型的笑面虎，对谁都笑呵呵的，但是对谁都不是真心，即便你攀附他，他也是笑呵呵地接受，但是一旦等你遇到生钱的问题的时候，他不会真正的帮你；而有些领导，虽然有时看上去很臭，脾气古怪，动不动就骂人、拍桌子，看上去十分的强势，十分的不还接触，但是这种人他往往愿意强势地帮助自己的身边人争取利益。所以不要被领导表面的东西所蒙蔽了，因此，你要多观察，多参加单位的饭局，看看这个领导是不是愿意帮助自己的身边人，判断出这个领导是不是真的愿意帮自己身边的人，如果愿意帮，这个领导肯定是首选。这是第一个原则，就是这个领导必须懂得为攀附他的人 в 关键的时候争取关键的利益，不然花了那么多精力去攀附，攀了也是白攀。
