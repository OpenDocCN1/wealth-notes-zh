# 攀附的原则

我再讲一下攀附领导其他的一些原则性的东西。在一个单位最好只攀附一个领导，不能做两面派，也不能做老好人，谁都想攀，谁都不想得罪——天下没有这样好的事情，你只能综合考虑后认真地去攀一个，全身心的去攀一个。当然我的意思不是说攀上了一个领导，就不理会其他领导了，我的意思不是那样的，我的意思是要把认准了的领导，你所要攀附的领导当成自己的父亲，而其他的领导你把他们当成叔叔，直白一点就是虽然你攀附了某一个领导，但是对待其他领导也要在面地上说得过去。这是在本单位，本单位只能攀一个。

当然，你还可以攀附其他领导，但是要在本单位之外。我的建议是一个层级上的领导只攀一个。因为，这个精力都有限，所以一个层级上的领导只攀一个。比如你还是地税局的普通职工，你已经攀上了局长，那么就不用再攀其他部门的局长了，你可以去攀一个常委，县常委，或者是市局部门的局长，或者是市季的常委，这就是我说的一个层级上只攀一个，因为，你只要在这个层级上攀上了一个领导，这个层级上的方方面面的事情，如果领导视你为心腹，领导都能够在这个层级上帮你把所有的事情解决掉。

看到这里，你也应该知晓了攀附领导是自己职场上的捷径，想必你心目中自己所要攀附的领导也基本确定了，现在是万事具备，只欠东风了，这个东风是什么呢？那就是怎么做才能攀附上领导呢？下面我给大家详细地讲一讲。
