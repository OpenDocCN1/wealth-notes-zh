她不是一个善于表现自己的人，只从自己的公文中，获得满足与自我肯定。也许正是因为这个原因，对于每次的成功，在领导眼中，是秘书科整体努力的结果，而丝毫没有注意到老实人的作用。就这样，婷拿着与其他人相同的薪金，却干着超出旁人几倍压力，与辛劳的工作。她感到了一种失落与不公，毕竟她也要照顾小孩和老人。她提出了换岗，好在寻此时也意识到了什么。

# 4：不善沟通与合作，特别与异性

由于单位上上下下，男同事较多，琪无形中便成为一朵众人竞捧的金花，再加上演性格外向活泼，更成为单位里不可或缺的一颗明星。可因此也生出了不少是非，不久一些不好的话，便充斥了整个大楼，成了一个被人议论的中心。男友因为一些议论，也进入了一段冷战期。

# 5：陷入斗，被迫还手，两败俱伤

严是二科的科长，与二科科长是死对头。一次因小事被背黑锅，与二科斗争激烈，从而导致单位上下，沸沸扬扬领导调停并各打 50 大板，单位领导不管缘由，他要的是大家都顾全大局。

# 6：把工作当苦役，不会忙里偷闲

静通常是每天，最后一个离开办公室的人，回到家已是精疲力竭，啥力气都没有了。到了周末，只想昏天暗地睡上 2 天。至于休闲、外出根本就是心有余而力不足。渐渐地，静发现自己简直就是一个工作机器，皱纹猛增，工作事倍功半，生活了无生趣。

# 7：恐惧挑战，不愿改变

“我一直在这个部门工作，属于比上不足，比下有余的一类。所以对现状很满足，直到有一天，单位内部重组，领导找到我，问我是否愿意去挨个新部门。当时心里真是没底，一直拖延至今。领导不高兴。”

# 8：一切往坏想，成牢骚族、抱怨族

有的老实人碰到难题，往往先发一通怨气，翻旧账，而很少从问题的实际出发，寻找自身的缺点，进而解决它。最后事自己办了，还得罪人。
