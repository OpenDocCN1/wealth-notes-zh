# 第十章：功在散席之后

> ——求人办事的饭局，一定要在散席后抓住机会，抓什么？怎么抓？

很多年轻人，请人吃饭，吃完了呢？各回各家，各找各妈？

那不行的。

因为整个饭局最关键的，在我看来就是饭后的独处时机，因为前期铺垫了那么久，饭后的独处是要把诉求提出来的时候了，很多人觉得饭局后大家都喝得差不多了，领导也想休息了，就让领导回去休息了，想等到第二天再去领导办公室去说。

你可想错了！打铁要趁热，明天领导酒醒了，在办公室正襟危坐，没有酒精的刺激，他一切又恢复往常，你把求他的事说出来，他要么说研究研究，要么说考虑考虑，大概率不会痛快地说行还是不行。

所以，当晚散席后，一定要抓住时机。

比如，你最好 在九点半左右就结束饭局，因为还要留足时间说正事呢。如果一不小心闹腾到十一点、十二点，哪还有什么说正事的时间。

散席后，你护着领导走出饭店，悄悄地给领导说：旁边有个小茶馆，想再领导喝茶，正好有一个事情想给领导汇报一下。

领导说：不去了，有什么事你直接说。

你要接话道：那好吧，那我们散散步吧，就当消化下吧。这样说的目的是，把说正事的时间稍微争取得长一些，虽然，在送领导回去的路上也可以说，但路上顶多只有一二十分钟的时间，如果他一口回绝，或模棱两可，你都没有进一步做工作的时间了，并且你们都喝酒了，肯定是代驾或驾驶员开始，稍微谨慎点的领导是不愿意再第三者面前表态任何不利于自己的事的，你求的事越大、越难，说明在规则之下越难办到，就越需要他突破规则帮你办，他就越不会在第三者面前表态。所以，最好是在争取稍长时间的前提下，摒弃任何第三者。

至于怎么跟他说，因为涉及到具体的事情不同，言辞也不同。
