# 第二章

我把大家平时经常会遇到的一些小问题，统一放在这一个课程里，我建议大家单纯地听效果不太好，如果在听的过程中有一些可取的地方，我建议大家把这些地方用笔记录下来。以备不定时地翻出来看，这样才能巩固，灵活地运用到实践中才能够融会贯通。

今天给大家讲一讲如何拍领导的马屁。拍领导的马屁，有很多人是存在认识的误区的，很多人都不想或者不屑于拍马屁，一是怕领导可能不喜欢，二是怕同事会觉得自己是小人，其实这里。这都是多虑的，在现实中领导既不缺钱，也不缺权力，更不缺女人。

缺的是什么？

缺的是精神层面上的舒服感！所以大部分人都喜欢被人抬着，都喜欢被人吹捧，都喜欢被拍马屁，拍马屁不仅是人际关系的润滑油，更是上下级关系的黏合剂。另外你的一个担心是怕同事说你是小人，更是不足为虑，大家都是职场中人，有流言蜚语只能让你变得更强大，大部分的同事都只不过是乌合之众，你不必太在乎他们的看法。所以一定要更正这一个认识上的误区，不要有不屑于去拍马屁这个错误的认识。

如何拍马屁

我再给大家讲一下，如何巧妙地、不显得过于奉承地拍领导的马屁。

第一个方法就是向领导虚心的请教问题。我们从小接受的教育就是要自力更生自立自强，这导致很多在职场中的人很不好意思向别人请教问题，觉得请教问题会显得自己很愚蠢，上级向下级请教问题更是难上加难。然而不耻下问一直是一种美德，而且请向领导请教问题，却是一个非常好的拍马屁的利器，在职场上最上等的！

拍马屁的方法就是虚心地向领导请教领导擅长的，并且很熟悉的问题，这样让领导有一种好为人师的快乐感，并且领导还会认为你这个人虚心好学，值得培养。
