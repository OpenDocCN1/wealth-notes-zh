# # 第五章

每个职场中人都有或多或少的困惑，不管是刚入职的新人，还是已经在单位工作一二十年的老同事，你总会遇到一些工作上的难题，人际关系上的一些僵局，等等，包括我在内，我也是有困惑的。比如我一直想外放出去，但一直没有机会。

所谓的外放在古代也就是说补个实缺，在省委办，我认为我距离领导多近，始终只是一个服务人员，连师爷都算不上，更谈不上是领导的幕僚了。是的，只是服务人员，手里其实并没有任何直接的权力，只是靠着狐假虎威，间接的有一些权力罢了。而一旦补了实缺就不一样了，手里肯定会有或大或小直接的权力。但是我一直没有这种机会，这种事情又不太方便跟领导提，因为我见过太多在领导身边的服务人员，因为非常急迫地想要求进步，没有掌握好跟领导提的时机，导致被领导疏远。

有句话说得非常好：君威难测。要官的事情，要么不提，要一提就一定要成功。所以这个时机要么等着领导给，要么等着一个非常好的时机才提出来，所以大家也看得出来，我也是有无法解决的难题的。只是我知道解决不了，那就等待。

有时等待是解决问题最好的办法。
