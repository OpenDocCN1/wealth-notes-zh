# 拖后腿

我再给大家讲第二个问题，为什么要拖别人的后腿？

在一个单位上升的空间是很有限的，领导的宠爱也是很有限的，所以一个人的成功的概率也是很有限的。所以一旦有人捷足先登，你基本上就没有什么希望了，或者说即便有希望也可能要等很多年了。

比如你和王鹏在一个办公室，你们是同一年进单位的？都是研究生毕业。你们两个都是正科级，现在办公室缺一个副处长，你们两个暗暗较劲，但是你确实能力比不过王鹏，并且关系背景也不如王鹏强硬。

单位要举办一次全省的大会，你们处是牵头来做，处长把这个事情甩给了王鹏，让王鹏负责具体事务处，处室其他人员全力配合王鹏。这个时候你该怎么做呢——当然是在工作中神不知鬼不觉地寻找好一个机会，使劲托王鹏的后腿，一定要让大会出现差错，并且这个板子一定要打在王鹏的身上，进而让领导对王鹏的工作能力产生怀疑，进而削弱王鹏竞选副处的资本。

你可能会觉得这是小人之举，或许是吧。但单位的位置就这么多，等王鹏当了副处，你怎么办呢？一直被王鹏这样压着，等他熬到了正处，然后你接他的班成为副处，要等多少年呢？升官发财的事不能等，一步落下，就步步落下了。

怎么拖他的后腿呢？拖后腿最有效的做法就是让领导不满意他。很多人拖后腿就是单纯的拖后腿，没有一点技术含量，为了拖别人后腿而拖别人后腿，到最后不但没拖住别人的后腿，反而因为自己算计不精，给领导留下的印象就是这小子天天磨洋工，这是愚蠢的做法。

天下精明的厚黑之术都是要经过通盘算计的，都是要精心设计套路的，都是自己去设好陷阱，然后等着猎物往里钻的，都是在背后下黑手的，然后转身离去，做的神不知鬼不觉。做不到这些，你的那些所谓的厚黑手段，基本上都是自毁前程。
