# ### ◎ 如何创建自己的“自我度量表”

你可以以上面说的广告为例，把你写好的销售文案，用“自我度量表”检查。在电脑上，你可以用下划线实线或虚线标示（手写的可以用铅笔），计数所有有自我迹象的词，包括标题、正文：

+   - 我
- 我是
- 我愿意
- 我已经
- 我的
- 我们
- 我们愿意
- 我们已经
- 我们是
- 我们的
