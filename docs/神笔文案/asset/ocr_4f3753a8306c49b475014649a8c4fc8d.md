# 你是不是想……？

# 你是否知道如何……？

# 你是否因为晚上睡不着觉，而烦躁，焦虑？

我建议你在自己的文案中使用这种标题。它的效果非常好，不过前提是，你一定要非常清楚潜在客户在想什么。

# “问题&解决方案”标题（亦称作“引起惊慌”标题）

这种标题比较棘手，但是用的好，可以非常强大、有力。这种标题会让潜在客户走出舒适区，让他们为自己现在的处境感到痛苦。然后……你提供给他们解决方案。

有时，人们会把这种标题看作消极标题，但是不管怎样，它有效。如果使用得当，恐惧带给人的激励是最有力的。

人们通常害怕失去以下东西：

+   - 性
- 吸引力
- 朋友
- 年轻
- 金钱
- 健康
- 工作
- 地位
