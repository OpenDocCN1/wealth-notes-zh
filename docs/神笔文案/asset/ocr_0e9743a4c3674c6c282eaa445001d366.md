# ◎ 你的一段应该多长？

答案：避免过长的段落。例如，销售信中，如果一个段落超过6行——或者超过160个字——都被认为是过长。有时候，一句话，几个词，都可以作为一个段落。

# ◎ 段落太长，如何拆分段落？

通常，一个段落包含一个观点。因此，拆开它，就意味着破坏统一。但是每一个观点都是建立在一组较小的观点上的，所以，你可以利用它们从一个段落过渡到另一个段落。
