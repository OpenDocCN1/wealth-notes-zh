# QUADRANT3  煩事 (Q3)

緊急但不重要的事，像是接電話、開會或是突來的訪客等。當你在這象限時，你可能会覺得跟第一象限「急事」很像，可是這兩個象限最大的不同，就是第一個象限是關於自己的事，而第三象限通常都是花時間在別人的事情上，更會造成瞎忙的狀態。

最好的解決方法，就是要勇於讓這件事變得有效率，像是在會議中要抓緊主題報告、講電話時避免瞎聊等。
