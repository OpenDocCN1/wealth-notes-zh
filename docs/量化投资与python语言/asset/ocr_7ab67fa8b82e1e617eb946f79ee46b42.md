# ## 8.2 基本数据结构

一般的原则是,数据结构是包含其他对象的对象。Python 提供的数据结构包括以下几种:

+   - 元组 (tuple)。任意对象的集合,只有少数可用的方法。

+   - 列表(list)。任意对象的集合,有许多可用的方法。

+   - 字典(dict)。键-值存储对象。

+   - 集合(set)。其他独特对象的无序集合对象。
