# 6. 算数运算和数据对齐

算数运算，举例如 图 10-24 所示。

![](bbox=[0.21, 0.16, 0.78, 0.42])

在这里，读者可以看到自动的数据对齐操作在不重叠的索引处引入了 NaN 值。缺失值会在算术运算中保持和传递。

对于 DataFrame，对齐操作可以同时发生在行和列上，如图 10-25 所示。

![](bbox=[0.2, 0.51, 0.79, 0.71])

大家看到的，没有重叠的相加的就是 NaN。
