# ## 绘图和可视化

在使用 Numpy 进行学习统计计算时是枯燥的，大量的数据令我们很头疼，所以我们需要把它图形化显示。

Matplotlib 是一个 Python 的图形框架，类似于 MATLAB 和 R 语言。
