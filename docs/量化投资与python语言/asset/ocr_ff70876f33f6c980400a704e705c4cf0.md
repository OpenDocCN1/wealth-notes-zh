# **10.2.4  DataFrame 和 Series 之间的运算**

# **1. 加减法**

先看例子，如图 10-27 所示。

```
In [37]: df1=pd.DataFrame(np.arange(9).reshape(3,3),columns=['open', 'high','low'],
index=['day1', "day2", 'day3'])
df1
Out[37]: open high low
day1 0 1 2
day2 3 4 5
day3 6 7 8

In [38]: df1+8888
Out[38]: open high low
day1 8888 8889 8890
day2 8891 8892 8893
day3 8894 8895 8896

In [39]: df1*10000
Out[39]: open high low
day1 0 10000 20000
day2 30000 40000 50000
day3 60000 70000 80000
```

