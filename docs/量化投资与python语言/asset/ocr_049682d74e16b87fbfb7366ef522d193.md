# ### 3. 字典

字典对象就是按照键码读取的数据字典，也是一种可变序列。字典用的是大括号，如图 8-28 所示。

```
In [60]: dt={'name':'二娃','age':'18','country':'china'}
         dt
Out[60]: ['age': '18', 'country': 'china', 'name': '二娃']
```

![](bbox=[0.45, 0.24, 0.55, 0.25])

从上面的例子可以看到字典的对象是没有顺序的，如图 8-29 所示。

```
dt.copy
         dt.fromkeys
Out[59]: dt.get
         dt.items
         dt.keys
In [60]: dt.pop
         dt.popitem
Out[60]: dt.setdefault
         dt.update
In [ ]: dt.values
         dict
`'age': '18', 'country': 'china', 'name': '二娃`
```

![](bbox=[0.45, 0.41, 0.55, 0.42])

字典的方法有多种，如图 8-30 所示。

```
In [62]: dt.keys()
Out[62]: dict_keys(['country', 'age', 'name'])
In [63]: dt.values()
Out[63]: dict_values(['china', '18', '二娃'])
In [64]: dt~age
Out[64]: '18'
```

# ### 4. 集合

这种数据结构没有多大用处，或者我们做金融行业的可能用得不多。不过，集合的好处是可以去掉列表对象中的重复元素，如图 8-31 所示。

```
In [65]: set([1,2,3,3,4,4,4,5,5,6,6,7])
         x=set(x)
In [66]: x
Out[66]: {1, 2, 3, 4, 5}
```
