从上面的例子中可以看到, lambda 的结构就是自变量, 然后冒号, 后面提供关于自变量的一个函数关系,上面的例子显示的是关于 $x$ 的平方关系。

lambda 匿名函数经常被用到 filter(), map(), reduce(), sorted() 的函数中, 这些函数的共同点是均需要函数型的参数, lambda 表达式正好适用。举个例子, 如图 8-35 所示。
