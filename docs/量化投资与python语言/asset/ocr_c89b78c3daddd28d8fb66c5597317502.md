# 表 10-4

| 方法 | 描述 |
|---|---|

| sum | 样本值的总和 |
| mean | 样本值的均值 |
| median | 样本值的算数中位数 |
| mad | 根据平均值计算平均绝对离差 |
| var | 样本值的方差 |
| std | 样本值的标准差 |
| skew | 样本值的偏度（三阶矩） |
| kurt | 样本值的峰度（四阶矩） |
| cumsum | 样本值的累计和 |
| cummin,cummax | 样本值的累计最小值,最大值 |
| cumprod | 样本值的累计积 |
| diff | 计算一阶差分 |
| pct_change | 计算百分数变化 |
