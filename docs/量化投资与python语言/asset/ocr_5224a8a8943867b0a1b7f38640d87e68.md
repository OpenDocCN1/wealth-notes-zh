# NumPy 基础

NumPy 是 Python 的关于高性能科学计算和数据分析的基础包。最重要的是, 提供了矩阵运算的功能。其实, list 已经提供了类似于矩阵的表示形式, 不过 NumPy 为我们提供了更多的函数。我们主要是介绍 NumPy 的数组和矩阵计算。
