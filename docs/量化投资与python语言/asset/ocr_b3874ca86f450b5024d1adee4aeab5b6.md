# 1. 构建策略

若昨日收盘价高出去 5 日平均分，今天开盘买入股票；若昨日收盘价低于过去 5 日平均分，则今天开盘卖出股票。

每天看看昨日收盘价是否高出去 5 日平均分，是的话开盘就买入，不是的话开盘就卖出。每天都这么做，循环下去。
