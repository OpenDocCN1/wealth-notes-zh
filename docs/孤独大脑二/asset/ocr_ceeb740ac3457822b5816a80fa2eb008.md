# 《复利的谎言》

幸福的普通人比不幸福的牛人更幸福。

本文阅读量是年度最高。

“复利思维”，这个看似有些鸡汤的话题，其实包含了“不确定性、连续性、对称性、预测、幂律分布、肥尾、下注、决策、贝叶斯、长期主义”等好多 个有趣的话题。

本文的观点是：

+   · 绝大多数人对于复利的理解是错误的；
· 极少有人能够靠复利获利。
