# 四

克拉玛在《2001太空漫游》里说:

毁灭无法理解的东西是野蛮人的标志。

法拉第发现电磁感应之初,被人问:

这有什么用处呢?

法拉第回答:

一个新生的婴儿有什么用处呢?

新生事物大多是虚弱的,微不足道的。

我们大脑里的范式来不及转移,怎么可能用老的想象力为新的生命插上翅膀呢?

于是,名言大叔爱因斯坦说:

如果一个想法一开始不荒谬,那么它就毫无希望。

对于科学,人们也许只是怀疑和嘲讽。

但是,对于已经通过“工程技术”实现了的科学,其命运更加不可预利。

当魔法变成现实,很多人被吓到了。

当这些现实伤害到自己的面包,有些人愤怒了。

卢德主义考,是19世纪英国民间对抗工业革命、反对纺织工业化的社会运动者。
