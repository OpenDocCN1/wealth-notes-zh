# L5：完全自动化

各级水平的自动驾驶技术，有一个非常本质的区别，那就是：责任的主体是谁。

+   •L1跟L2责任的主体是在人类的司机；

+   •L3的特点是双主体，正常情况下是智能机器人开车，必要时人类司机接管；

+   •L4的责任主体完全是机器人，但有限定的场景和气候条件；

+   •L5则是完全无人化的智能机器人负责。

“小蛮驴”作为物流机器人，服务于末端物流，是因为：末端物流是整个物流体系中成本最高、效率最低的环节。

那么，在“社区、学校、园区”行走的“小蛮驴”，是什么无人驾驶水平呢？

阿里达摩院给出的定义是：L4、L5级别。

这是因为，即使是在校园等半封闭的末端场景，其复杂程度并不低于城市道路，包括人车混行，红绿灯，以及各种突发交通事件。

与此同时，为了实现量产，智能机器人不仅需要表现稳定，还要降低成本。

小蛮驴制造成本的大幅度降低，主要源自三个环节的技术创新：

+   •一是改进了包含激光雷达等昂贵传感器在内的感知体系，比如，达摩院自研的感知算法，实现了对低线束激光雷达的高线束模拟；

+   •二是自研嵌入式计算平台，定制了高性能、低成本和低功耗的计算单元；

+   •三是深度定制了包括运动底盘在内的硬件设备，实现了软硬件高度一体化。
