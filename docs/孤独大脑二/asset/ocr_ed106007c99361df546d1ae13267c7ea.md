我在《财务自由，靠“投机”能实现吗？》讲投资的期望值计算，提及投资人需要估算某一笔投资上涨的概率和可能的上涨幅度，很多人无法理解，说，这不就是赌博吗？

事实上，“随机过程”一词的英文是 stochastic process 或 random process，而stochastic一词来源于希腊文σχοχαστυκος，本意就是“猜”，即表示猜想随机现象的规律。

所谓概率思维，就是聪明地猜。

来，测试一下，你会不会猜。

有个游戏。现在你面前有100张牌，已知70%是红色牌，30%是黑色牌。

所有的牌都是背面朝上，而且长得一个样子。

请你来猜牌的颜色，猜中一张奖励一万块。

请问，以下两种策略，你选择哪一种？

+   •策略A：70%的时候猜是红色牌，30%的时候猜是黑色牌；

+   •策略B：每次都猜是红色的牌。

你会选哪个？

答案是B。

据说在实验测试中，即使参与者都是聪明人，但是大部分选择了策略A。

但事实上，策略A猜中的机会是：

70%×70%+30%×30%=58%。

而策略B的猜中机会是70%。

你看，在配置环节赌努力，其实没啥用，只是制造确定性的幻觉而已。
