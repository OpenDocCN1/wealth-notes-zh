# 《病毒时期的概率》

**他们超越了概率计算。**

概率并非冷冰冰的数字。

回头看这篇，写得小心翼翼。

我很庆幸写了这些，尽管孤独大脑的绝大多数文字去除了时代感和烟火气。

这些伟大的专业人士不仅是要去拯救“**可识别的鲜活人命**”，也是在用自己无法计算的生命价值，去拯救我们每个人“**统计意义上的生命**”。

**恳请所有人牢记他们的付出，并给予真实的、持久的回报，给他们，给他们的父母和孩子。**
