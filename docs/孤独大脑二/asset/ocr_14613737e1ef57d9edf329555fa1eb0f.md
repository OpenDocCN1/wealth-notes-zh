别指望去学来什么大局观、远见、一眼看穿本质的能力。

脱离了计算的长期主义毫无意义。

# 5、AI根本分。

什么叫本分？

就是该稳的时候稳住，绝不心存侥幸，绝不能想“万一对方傻逼一下呢”，尊重每一个对手、堂堂正正；

更重要的是，该狠的时候一定要狠，绝不手软。毕竟是下棋嘛。

AI经常走出很平常的招法，像缓慢的铁锤，朴实，强大，效果之好令人意外。

# 6、AI都是宇宙流。

稍微懂点儿围棋的，都知道“金角银边草肚皮”，意思是说中腹不要围空。

人类历史上敢下中腹且下得好的，可能只有吴清源和武宫正树。

AI既能爬二路，又非常会围中腹。

真的是“高手在腹”。

说来说去，还是计算力强。
