# 《原因的原因不是原因，结果的结果不是结果》

“让自身没入深深泉源的黑暗之中”。

老子说：知其白，守其黑。

黑门之间，即为灰。

现实是灰度的，而我们的此刻必须做出黑白分明的选择。

这就是我说的“灰度认知、黑白决策”。

人类的存在极其偶然，于有限的岁月里编织的因果传说，在无尽的宇宙里只是一缕暗淡的光亮。

我们该如何找寻不在灯下的丢失之物？

海德格勒的回答是：

“让自身没入深深泉源的黑暗之中”。

# 《病毒时期的概率》

**他们超越了概率计算。**

概率并非冷冰冰的数字。

回头看这篇，写得小心翼翼。

我很庆幸写了这些，尽管孤独大脑的绝大多数文字去除了时代感和烟火气。

这些伟大的专业人士不仅是要去拯救“**可识别的鲜活人命**”，也是在用自己无法计算的生命价值，去拯救我们每个人“**统计意义上的生命**”。

**恳请所有人牢记他们的付出，并给予真实的、持久的回报，给他们，给他们的父母和孩子。**
