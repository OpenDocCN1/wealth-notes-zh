> “地球上最后一个拿到驾照的人已经存在了。“赫格尔博士如是说。

这句俏皮话说出了乐观者的预期：

自动驾驶在不久的未来，即将全面实现。

也就是说：我们将在有生之年见证人类驾照的消失。

到2030年，全球将有60%的人口居住在城市，交通将面临巨大压力。

人们一方面依赖于汽车交通，一方面成为汽车的受害者。每年全球有50万人不幸死于车祸。

自动驾驶通过人工智能技术，不仅解放了司机，还能大幅提升交通效率，最大限度地降低交通事故率。

多少生命将被拯救，多少美好的时光将被创造。自动驾驶，将会彻底改变我们的生活方式。

作为特斯拉的车主，我偶尔会试一下自动驾驶。

特斯拉当前的自动驾驶是L2级水平，驾驶者会被要求将双手放在方向盘上，并保持一定压力，否则就会通过声音和闪烁来警告司机。

这种水平处于什么位置？

让我们来看看。自动驾驶从L1到L5，分别是：

+   - **L1：驾驶支持**

+   - **L2：部分自动化**

+   - **L3：有条件自动化**

+   - **L4：高度自动化**
