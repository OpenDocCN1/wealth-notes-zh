# 拜金女塔特雅娜

賺錢的密碼在移動平均線，可惜世上有很多人不懂得這個切入點，而想一些歪點子要謀財，結果是自誤誤人；看來，她們應該讀讀《移動平均線密碼》！

英國《獨立報》2004 年七月 14 日報導，自稱「拜金女」的卅三歲德國名媛*塔特雅娜·葛塞爾* 2004 年六月十三日在法庭上坦承她雇用偷車賊——偷自己的車詐領保險金，以倒貼新男友，沒想到偷車賊，竟然砍死自己的老公。

這宗發生在 2003 年一月的謀殺案轟動一整個德國，主嫌*塔特雅娜*是德國最知名的「人工美女」，全身上下動過廿多次整形手術，替她動刀的正是她親夫——76 歲的整形醫師葛塞爾，也是本案被害人。

常在德國報紙、雜誌與電視節目露面的*塔特雅娜*在紐倫堡法院首度出庭時表示，她一手策畫偷車案詐領保險金，因為她從事二手車買賣的新男友貝克財務吃緊，已欠債十萬歐元。她說：「我對丈夫死亡感到遺憾。我策畫這起詐領保險金案，因為我財務狀況吃緊。']
