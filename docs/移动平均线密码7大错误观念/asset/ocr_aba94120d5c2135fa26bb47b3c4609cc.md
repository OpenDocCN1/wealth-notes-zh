# 反彈的逃命線

M 字頭的最後一段，被稱爲是「逃命線」——因爲這是股價的可能的最後一次高點的反彈，價格逼近頸線，但無法超越頸線；這時，不走就要重度的套牢了！經過逃命線之後，觀望的投資人大多是以套牢收場。

# 標準型態的變型

投資人在市場上遭遇的例子，往往與教科書上劃的標準型有所不同。雙重頂的兩個頭部的位置不必全然相同，它的兩個峰位的價格未必完全相同；如果第二峰位稍低於第一個峰位，那應該不構成識別上的困難！但是，如果第二峰位稍高於第一峰位，就比較麻煩了！因爲這是屬於繼續走高的峰位，上升趨勢（Uptrend）似乎仍在發展中。爲瞭解決這是一個問題，投資人大多求助於濾網的原則。
