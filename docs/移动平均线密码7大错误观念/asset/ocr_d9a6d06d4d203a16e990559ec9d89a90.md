# 創新高的個股

賺錢老手喜歡一年內創新高的個股；理由是強者恆強。這種
創新高的個股比較容易持續的漲；背後的支撐是在股價創新高之
後，賺錢的人多，套牢的籌碼相對的少。

長線投資人在價格一高之後，就不再追漲；但是投機客是以
賺取差價爲目的，與投資客不同；他們在乎的是上漲機遇的把握
，價位高低——並不太在意。

# 股價超越 200 日平均線

華爾街所重視的移動平均線

華爾街的分析師，十分重視 200 日平均線！市場價格穿越
200 日平均線時，被看成是多頭市場的指標！

如果當日收盤價穿越 200 日平均線的是漲勢的「「中長紅線
」」，那就當然的敲進。通常它的突破幅度是比較大的；突破的
幅度愈大，將來的漲勢就會愈大。

如果當日收盤價穿越 200 日平均線的是觀望的「十字星線型
」，那就暫緩下注；重點在於收盤價是否站穩在 200 日均線之上
的。
