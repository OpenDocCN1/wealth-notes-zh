# 不必火中取栗

市場之中瀰漫著很多的迷湯，像是「火中取栗」之類的話就是。

富貴穩中求就好了！不必講什麼「富貴險中求」的話！有的
公司的業績忽上忽下，看似得了躁鬱症一般，通常這種股票的下
一步都是打入全額交割股之列。

便宜的股價，並不能保證公司不會倒的。

市場之中，有一派人愛看趨勢，還有一派愛看價值。但是看
趨勢有一個缺點就是，愈會漲的個股，你就愈樂觀；愈會跌的個
股，人們就愈悲觀。

相對的，如果你是看價值投資的人，愈跌你就愈覺得便宜了
，愈漲你就覺得貴了！

# 三支股票護一生

撿對了績優股，三檔股票的波段操作，加上填息填權，就能
讓自己的退休金豐厚的。市場上的個股那麼多，怎麼研究的完？
熟悉那幾檔股票，像是台灣的中鋼、台積電、中華電、台塑四寶
，就夠自己好好退休的了！
