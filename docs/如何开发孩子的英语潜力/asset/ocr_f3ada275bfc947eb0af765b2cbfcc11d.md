# 1. 词汇量: 学龄前 1000 个听力词汇的积累

孩子上小学前，在听力上，完全可以达到 1000 个听力词汇的积累，这是未来英语学习最为必要，但是很多爸爸妈妈没有重视起来的基本功。

注意，我说的是听力词汇，什么意思呢？就是孩子听到了知道是什么意思，无论是以单词的形式出现，还是在简单的句子里，都能听懂。但并不需要孩子马上能够认识、能够拼写。

为什么孩子要积累这么多的听力词汇？

首先，听得不仅是能说的前提，也是发音标准的前提。只有掌握足够的听力词汇，知道这些词的意思，才能在合适的场景下正确使用，从而解决了先听说的问题。大量、反复通过听积累起听力词汇，尤其是听到不同的人对于这个单词的发音，无论是外教、以光盘或者 APP 为载体的听力资源，还有你平时跟孩子一起做的游戏，都会很大程度上帮助孩子发音标准。

你可能听说过“自然拼读”，甚至还听说，英美国家的孩子，刚上小学，通过自然拼读，就能大量阅读。但我要告诉你，之所以人家能做到，是因为他们大量的听力词汇。所谓自然拼读，本质上是把看到的单词转化成听力词汇。所以，自然拼读上接听力、下启阅读，有了听力词汇的积累，自然拼读才能学以致用，最终把听力词汇迅速转化成阅读词汇。
