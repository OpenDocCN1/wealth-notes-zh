另外，动画片中的场景变化太快，而且它们并不是为了孩子学习语言制作的，词汇和句子重复出现的频率很低。要知道，只有重复出现的频率足够高，孩子才能对复现的词汇和句子，进行反复的辨识，产生理解和输出。当然了，如果是那种专门为了语言学习制作的动画或者视频，又另当别论。

所以，动画片就是动画片，即使是英文动画片更多的也是一种娱乐。就孩子的英语启蒙来说，你就不要对看动画片寄予太高的期望了。

# 2. 巧用图文字典排除干扰

既然动画片不是孩子英语启蒙的好资源，那什么是呢？我特别推荐那些美国家专门为孩子们设计的图文字典和儿童字典。这种词典很有用！专门帮助孩子进行阅读词汇的积累。

孩子是用形象思维的方式学习的，看到图片最有感觉。在难度方面，大可不必担心。国外的图文字典有很多不同的难度，最简単的图文字典甚至只有图和单词，没有解释。供大一点孩子使用的字典也基本上是图文的，有图，也有简单英文解释。更大孩子使用的字典，图片逐渐减少，文字增多。这样的字典往往都是薄铜版纸全彩印刷，仅仅是翻一翻，都是享受，而且现在也很容易买到。
