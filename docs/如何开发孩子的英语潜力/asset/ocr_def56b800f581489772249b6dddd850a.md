# ## 5. 怎么组合使用分级书单

你好，我是 Wendy，欢迎来到我的得到精品课《如何开发孩子的英语潜力》。

上一讲的四步法，说的是一本书应该怎么读。这一讲，我来说说，这 450 本分级阅读和英文绘本，应该如何进行安排，能达到最好的效果。

阅读这件事，单拼数量不是最重要的，反复读、组合读才更有效。

我们要达到两个目的，一个就是帮孩子扩充听力词汇，另外也是提供机会让孩子进行英语表达。

给孩子做英文启蒙，真的不需要重金购置海量原版绘本，3 年一共 450 本分级阅读加英文原版绘本就非常棒啦。

下面就给你介绍一下我总结的三个定律，用来给孩子进行英文阅读启蒙，教你用五本书读出十本书的价值来。

# ### 1. 每周两次坚持读

孩子上小学前，中文英文都需要大量输入，得全盘考虑。中文书每个礼拜要读至少三次，那英文的书两次就可以了。想要持之以恒，你的工作量已经挺大了，一周 7 天 5 天亲子阅读——坚持几年也不容易。

中英文阅读，我建议是 3:2 的一个比例。换句话说，你不要给自己施加太大的压力，养孩子是持久战，不能先把自己的能量耗光了。
