# 2. 第二步，抄

这一步要进行的就是抄写，你现在给孩子一个卡片，上面写了个 apple，然后你跟孩子说，要把这个 apple 给照猫画虎地写下来，这就是抄。不要看这一小步，这对孩子来说难度增加了一大截。在进入拼写之前，要训练一下抄。

甚至于不仅仅是抄一个单词，也可以是一个非常简单的句子，比如 I love you，抄这个阶段也不用持续太久，一两个月就差不多可以抄得很不错了。更重要的是拼的练习。

当然，每一次让孩子描也好，抄也好，都别忘记给孩子一些即时性的鼓励，比如在本子上贴一个贴纸，或者盖个卡通印章，只要是孩子喜欢的，都可以。

# 3. 第三步，拼

抄得比较顺了，就要逐渐开始进入拼写的阶段。所谓拼，就是听写：别人说一个单词，孩子能够正确地把它拼出来，这个比刚才的那两步就要难很多了。

所以这也是为什么我前面几节课一直在讲，英语启蒙最终一定得到的一个重要结果，是 1000 个以上的听力词汇，否则再往后很难进步。比如拼写单词，即使能拼出来，自己不知道啥意思，那有什么用呢？孩子写下来 apple，脑海中就应该能够浮现出一个苹果才行。
