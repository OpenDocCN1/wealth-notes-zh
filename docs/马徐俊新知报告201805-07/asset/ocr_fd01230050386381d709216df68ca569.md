# 今日报告：区块链能够颠覆网络霸权吗？

对比昨天今天的消息，井不会过于惊讶了，现在的新闻是：在当下我们已对前15个互联网的概念中，我们拥有网络公司（包括10家最大的）“去中心化”的平等体制。

> ——《纽约时报》

马修狼

《纽约时报》专栏认为：互联网目前存在严重的垄断和信任危机问题，那么，区块链技术能颠覆互联网行业，甚至革掉谷歌和Facebook的命吗？

今天的议题分为三个部分：

+   1. 互联网的结构性问题是什么？
2. 为什么区块链技术能颠覆互联网的现状？
3. 区块链技术迎合了人们的哪些需求？

最近《纽约时报》的专栏作家Steven Johnson发表了一篇长文，他在IT界最热门的区块链技术上锁定价值，给出了很独到的解释。Johnson认为区块链技术，将会革命性地颠覆整个互联网，并且可以从根本上解决目前网络存在的问题。它信任机制，甚至可能革掉谷歌和Facebook这样的科技巨头的命。

# 互联网的结构性问题是什么？

对于像Johnson这样，在互联网初期就开始使用网络的人而言，最近几年的互联网让他们感觉很沮丧。因为，他们认为互联网造成了让任何一个时代都罕见的垄断，同时对互联网上存在大量金融诈骗、虚假信息、以及无效的其它问题。

除了Johnson，还有很多业内人士都对互联网前景的问题表示不满和担忧。比如，谷歌前总编辑James Willams在接受《卫报》的采访时就说：“经过40年的发展，互联网开始腐化，不仅仅是互联网本身，还有我们自己。”“注意力的经济活力，正在结构性地危害着人类的意志。”

纽约资深的风投公司 Union Square Ventures的管理合伙人Brad Burham在自己的博客里也是这么写的：“谷歌搜索算法的一个微小变化就导致某一家网络供应商的流失。当互联网决定在哪里直接买买商品，并重新规划自己商品着点时，美国的制造商就只能眼睁睁地看着自己的销售额下滑。”

甚至互联网的发明人Berners Lee，也写了一篇博来表达自己的忧虑。其中有这样一句话：“广为普及的社交媒体和搜索引擎创造了一种环境，这种环境让那些假人新闻、或专门为引发偏见而发布的虚假故事，像野火一样在网络上肆虐传播。”

文中更犀利地指出，借助互联网的力量，资本主义富豪统治的模式被发挥到了极致，而财富的不平等，被推到了有时代以来前所未有的高度。

那为什么互联网会这腐化堕落呢？答案可能是很简单的不一样，这就是人类或者互联网头犬的道问题，也是互联网的结构性问题带来的。

我们先来解释一下，什么叫结构性问题。Johnson把互联网分为，开放的第一层，和封闭的第二层。

上世纪七、八十年代的公共软件协议组成了互联网技术的第一层，比如发送电子邮件的SMTP协议。我们都知道，HTTP协议，这些协议是公开的，不属于任何人，这也意味着所有人都可以使用，它们相当于互联网的基础设施。

在这一层面上，构建了如今的第二层——服务层，比如身份认证、社交媒体和支付机制等等。但是和第一层不同，第二层是建立在封闭技术之上的，这些技术被Facebook、谷歌、亚马逊、推特这样的网络巨头所控制。之前的结构性问题，就在这封闭的第二层。

我们来具体解释一下：第一，世界上数千人信息，包含身份、位置、兴趣、消费习惯、消费能力、社交网络等等，都控制在少数几家的私有数据库里，而信息是网络商业里最核心的资产。

第二，这些巨头掌握你的个人信息，他通过对你这些数据的分析，了解你的需求和喜好，就可以把你特定的信息和广告在合适的时间发送给，这是他们的盈利模式。这样一来，你所看到的世界就不再完整了，而是被操控和精心设计的。

第三，因为巨头和权威通过的信用看上去有保证，所以人们会选择通过他们进行交易，由此产生的巨额收益都集中在这些巨头手里。

那为什么互联网会从开放走向封闭呢？Johnson认为，根本原因还是利益的驱动。在互联网发展初期，大多数人都不知道它的存在，开放激进的做法，是为了让更多的人参与进来。

但是，等到互联网进入大众视野，资本就开始了它的疯狂追逐，只要屏幕保持亮着，顾客有几手无用的就会对其进行投资。为了独占利益，人们就开始选择维护技术。

另外，除了资本因素，还有一个技术上的原因。从当下的技术角度来看，信息需要存储在一个集中的数据库里。要想创建一个能够适应数以亿计的人的互动关系的数据库，这不是一个人能解决的，甚至都不是一个庞大的组织或者公司才能解决的问题，所以巨头们应运而生。

因此我们就会发现，现在互联网的逻辑就是：谁出钱，谁就能控制网络；谁有数据源，谁就能控制网络。但是，区块链技术的出现，颠覆了这种逻辑。

# 为什么区块链技术能颠覆互联网的现状？

对于我们普通人来说，现在的网络技术，其实我们的数据和资产、数字身份都不在自己的手里，而是掌握在互联网巨头的手中。比如谷歌、Facebook，他们利用这些数据，来获取巨额的利益。

但我们只需要进行身份认证的时候，却只能通过第三家的身份，来证实你是谁或提出申请。换句话说，我们在网络上个人身份，并不是我们想要的东西，而是属于科技巨头们。我们每次要证明自己的时候，需要去向巨头们借信数据，用完再还回去的。

至于那些有关消费行为记录下来的信息，我们根本没有权删除，更加别说是了。那么，是不觉得有点可怕？在网络上，我们是不是自己，那肯定不是我们说了算。

但是区块链技术可以解决这个问题：什么是：简单来说，它用区块链的方法，区块链是采用分分布式记录的方式，把交易信息，交给网所有的节点，都进行记录；每个交易区就是，一个区块，每个节点把区块保存下来串在一起，就叫做“链”，这个过程都是由计算程序事实的。

也就是说，当我们使用区块链技术进行交易的时候，既没有中间商，也没有社交媒体收集交易数据去做精准推荐，更没有信用信息机构制造次贷。

好，明白了区块链的技术逻辑，你会发现，它之所以能解决目前互联网的垄断问题，是因为交易信息不是某一个数据集中在记录，而是向所有节点的都有记录，所以它实现了“去中心化”的目的。

其次，它解决了信息造假的问题。因为信息都是，会被全网所有的节点验证。

最后，它解决了信任的问题。因为每个节点都有记录，你也不会需要去为一个权威机构，开类似“我是我吗”的证明，只需要吼一声，所有节点都会复用，只要大家的答复是一样的，你的身份自然就被证实了。

所以Johnson认为，区块链技术会改变如今的互联网格局，打破大公司的垄断，以及利用你的数字身份为公司利润。
