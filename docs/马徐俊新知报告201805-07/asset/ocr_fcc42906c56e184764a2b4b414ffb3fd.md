# **今日报告：空气污染被证实会导致糖尿病**

空气污染会提高糖尿病的发病率。 
——《柳叶刀》

![](bbox=[0.05, 0.18, 0.25, 0.22])

空气污染会导致糖尿病，一直以来都是个热点，前一期刊杂志《柳叶刀》发表的新研究，给出了支持。

今天的报告分为三个部分：

+   - 空气污染被证实会引发糖尿病
- 空气污染引发糖尿病的机制是什么？
- 如何应对空气污染的危害？

咱们都知道，空气污染会导致很多疾病，特别是呼吸系统相关的病。但医学界都杂志《柳叶刀》最近发表了一项研究，证实空气污染会引发糖尿病了，这是咱们之前没想到的，咱们都是糖尿病。

一提糖尿病的原因，咱可能想到的是肥胖、遗传、暴饮暴食、缺乏锻炼等等，医学界对糖尿病的研究已经有几百年的历史，但很《柳叶刀》发表的这项研究，证实了空气污染，尤其是颗粒物PM2.5，会引发糖尿病。

调查数据显示，仅仅2016一年，全球就有320万人因为空气污染而导致了糖尿病，占当年糖尿病新增病例总数的14%，这在全世界患得糖尿病是820万人。你可能会说这也太少了吧，但全球820万人可就是很大的了，平均下来320万在全身，那相当于每个患者就会因为空气污染，而减少了两年寿命。在全世界所有空气污染，证实了空气污染和糖尿病有这大的影响。这个病值得大家关注了。所以今天的报告，一定要仔细分析。

# **1 空气污染被证实会诱发糖尿病**

《柳叶刀》的这个研究，为什么值得重视呢？这么说，如果说之前空气污染和糖尿病影响的研究，还停留在这“假设”、“猜测”的数据，那么《柳叶刀》的这个“推测”是证实二者的关系更证实了。这篇报道明确的告诉我们，空气污染和糖尿病的发生，是正向相关的。

《柳叶刀》这本杂志，在医学界权威性。我们可以一定有所关注，在这里我不多说了。这次《柳叶刀》发表的这项研究不仅规模大，不仅取样样本非常精挑，而且规模也大。

研究者收集了170万退伍军人数据，你注意这两个条件——170万，是目前关于空气污染和糖尿病关系的研究中，样本规模最大的；糖尿病研究的变量而很多。一般的实验样本，很难确定单一变量的影响有多大，这些退伍军人，这些数据都有跟多来源，样本就是体检及环境数据。这样的实验样本条件，对于医学研究者来说，用四个字来概括，那就是“梦幻级采样”。除此之外，这个研究的时间跨度也特别长，研究者追踪了这些老兵有足足半年的时间。

研究者通过一系列的数据统计模型，控制了各种糖尿病病因的变量后，他们发现军人糖尿病水平，与美国环保署（EPA）和美国太空总署（NASA）记录的污染水平进行了比较。
