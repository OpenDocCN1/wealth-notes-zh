# 今日报告：埃隆·马斯克的第三次all-in时刻

生产一款大众消费领域的电动车可不是发射火箭。从某种程度上而言，它难得多。

> ——《彭博商业周刊》

为了将特斯拉的新款电动车Model 3提高产能，达到原计划每周 5000辆的产量，在过去三个月中，埃隆·马斯克都经历了什么？

今天的议题分为三个部分：

+   * 什么是马斯克的第三次all-in时刻？
* 为什么说造电动车比造火箭更难？

过去的三个月，特斯拉非常地艰难，用马斯克自己的话来说，这是一次地狱般的经历。

因为产能问题，特斯拉原本承诺，要在去年生产20万辆新Model 3电动车，结果到了今年6月底，只生产了4万辆，但特斯拉每个季度要烧掉10亿美金，如果产能持续不来，特斯拉有整体崩盘的危险。所以马斯克亲自下场干脏活，终于让产量达到了每周5000辆，算是半只脚踏出了地狱之门。

最近，马斯克接受了《彭博商业周刊》的采访，分享了自己过去几个月的经历。《彭博商业周刊》动用了几位记者，写了一篇特写文章《造电动中级车比造火箭更难》（Why Making a Midsize Sedan Is Easier Elon's Hell）。

今天我就来给你讲讲这篇文章的内容，你会知道，为什么在过去的三个月，是马斯克的第三次all-in时刻，他到底经历了什么？

是什么Model 3对于特斯拉来说，会是一次“产能地狱”？造电动车真的比造火箭还难吗？

# 什么是马斯克的第三次all-in时刻？

我们一般人聊起特斯拉，谈起码克，都觉得他特别厉害，从少年，到过英雄影里的男主角，只要动动手指，下个指令，一切问题就搞定了，但真实的他肯定没那么简单。

这次接受《彭博商业周刊》采访的时候，马斯克自己提到，在特斯拉创立至今，已经历过三次押上全部身家、不成功便成仁的all-in时刻。

第一次是马斯克决定要做电动车的时候。特斯拉的第一款电动车，叫Roadster，作为汽车行业的新人，毫无经验的特斯拉研发出这款车，做出了这款车，在这个领域迈出了脚步。

第二次是生产轿跑Model S的时候，这款车整车的复杂程度更高很多，并且产能从600辆一年下提升到两万辆，那是特斯拉的第一次all-in时刻。特斯拉又成功了一次，打开了市场知名度。

而现如今这款Model 3，是一款相对便宜的车型，可是马斯克走的大众消费领域的最重要一步，马斯克希望，这款车未来可以达到年产25万辆的规模。但没想到，特斯拉却Model 3的产能遇到了大问题，远远低于原来预计的一年5000辆的问题。

更糟糕的是，特斯拉背着100亿美元的债务，每个月都要花掉10亿美金来造车。按照《彭博商业周刊》的说法，在大众、宝马、戴姆勒和其他竞争对手不断推出几十款电动车，市场竞争达到白热化的时候，特斯拉就没输过。

外界普遍质疑特斯拉不能挺过去，大批华尔街分析师给出的投资建议，都是不看好特斯拉。在内忧外患的情况下，六月初，在特斯拉的年会上，马斯克一度哽咽落泪，说，真的太难了，就像是在经历地狱般的折磨，他希望Model 3的生产，是特斯拉的最后一次all-in时刻，未来不要再有这样的情况发生了。

为了提高产能，特斯拉进入了总动员状态，就像是打大场战争。工厂全天无休投入生产，员工三班倒，每班的工作时间长达12至16个小时。特斯拉甚至免费提供红牛这样的功能性饮料，帮助工人们抵抗疲劳。

特斯拉的员工有多卖命呢？新来的工人，都是生龙活虎、精力充沛的样子，过不了几周，你看再看他们，个个都一副精魂离体、呆滞、双眼无神、活像垂暮般的样子。员工还给这种状态起了个绰号，叫“特斯拉之凝视”。

马斯克自己也没到哪儿去。从7月底开始的时候，他直接睡到弗吉尼亚工厂，睡在办公室里，忙到一连五天都没空休息。终于，在今年7月，特斯拉达到了每周生产5000辆Model 3的原定目标。用马斯克的话来说，算是半只脚踏出了地狱之门。

你可能会奇怪，马斯克的Space X公司，可能加速造出了火箭的？特斯拉已经不是造了首款电动车的制造经验，怎么生产Model 3这么难呢？

# 为什么说造电动车比造火箭还难？

其实关于这个问题，《彭博商业周刊》已经把答案写在了封面上。你可以看到下面的这张图上面是一车款大众消费领域的电动车可不是发射火箭，从某种程度而言，它难得多。

具体来说，Model 3的生产面临以下三个问题，量产，设计和制造，三个一个接一个。

首先，说造电动车比造火箭还难，还真不是一个夸张的比喻。你想啊，火箭每次只造一辆车，全部零部件都可以手工打造，仅使用一次还能见报废；但大量消费领域的电动车，可是流水线生产的，那有可能像火箭这么精确地？

大型造厂几乎每十分钟要产出一辆汽车，一辆车由几十个零件组成，要经历酷暑、严寒、雪地、山路、城市等各种极端天气和路况的考验，还要保证使用很多年以上不出问题，这中间的困难可想而知。

进一步说，火箭出事，会带来一定的经济损失，但一款车的安全性能如果出问题，造成的大规模生命财产损失是，杀伤力可能是前一个级别的。一般人不会买一枚火箭，但买车的需求就普遍存在，毕竟就是除了房子之外，普通家庭最贵的消费品了，想要打动消费者，被大众接受，考验的要求刻薄着。

造火箭，是个时间线系统的短期目标，但造电动车，是开放系统的长期目标。

上面这些问题你可能会想到，但特斯拉的Model 3面临的困难，比上面说的还多，这主要是因为后面的两个因素——设计和生产流程。

Model 3是一款要求极高的车型，它得满足一次充电能跑200英里的目标，还要让普通家庭消费得起，这就需要看重很多更优秀的材料，来精挑细选和很多零部件，好让车子跑得更远、耗能更小，同时价格还不能高，因此，许多设计因素都要重新考量。

在车的内部设计上，马斯克希望突出科技感和未来感，把传统的仪表盘全部集成到一块大型屏幕里；他还特意取消设计遮光罩，不能遮挡任何一条光线，暴露在视野内，所以，传统的汽车设计方案根本无法满足，必须全部推倒重来。
