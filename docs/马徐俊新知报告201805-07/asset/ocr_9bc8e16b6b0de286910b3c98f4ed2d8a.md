# | 刻意实验是什么？

要理解我们为什么需要刻意实验，我们得先明白刻意练习到底有什么问题。
刻意练习，又叫1万小时理论，简单来说，想成为任何领域的世界级大师，你都要进行1万小时的刻意练习。
但是研究告诉我们，刻意练习更适合规则稳定、环境变量小的领域，如国际象棋等。在刻意练习可以使选手的表现提高25%；在音乐领域，可以使选手表现提高21%；在体育领域，可以使选手表现提高8%。
但是你看这些领域，国际象棋、音乐、体育，都是固定的规则，需要严格遵守，而且变化也比较慢。
而在我们生活的这个商业科技时代，每天都能发现日新月异的变化，刻意练习，已经不能成为走向成功的保障了。
如今我们更需要的是，1万次实验法则，也叫刻意实验（deliberate experiment）。

那到底是什么是刻意实验呢？
刻意实验指的是，先提出一个假设，通过测试来验证这个假设对不对，是不是合理，再分析结果，基于这个结果，再来调整假设和实验。
很多人都会认为是爱迪生发明了第一个灯泡，但实际上，在他之前，已经有23个人发明了早期的商业用途灯泡，但街道和建筑物照明等等。
爱迪生发明的是第一个家用灯泡，他可能成功，其实他在1879年，爱迪生加入到底竞争时，他已36岁了，本来没什么竞争优势，但是在1879年，他只新了一年左右，就创造了第一个家用灯泡，而他为了这个灯泡，进行了将近9000次实验。

可以说，刻意实验贯穿了爱迪生的一生。他这一辈子的1100项专利，不是因为他投入的时间很长，而是他实验的次数够多。
所以，我们需要的不是1万次的刻意实验，而是1万个小时的练习。
在科技时代，刻意实验更是无处不在，就好比互联网公司里有A/B测试，又叫对照组实验—controlled experiments。
它的可能是一个网站，A版是一种设计，B版是在A的版式上调整过的另一种设计。把这两种同时投给用户用，用户也不知道自己使用的是哪版，但公司可以从用户那里收集两个不同的数据进行分析，这样就知道这个B版的调整到底对不对了。
比如说美国共享租房公司 airbnb，他们就利用A/B测试，让订单增长了两倍。airbnb通过观察发现，房屋的照片对用户是否决定下单，会有影响，但到底有多大影响，还不清楚。

为了验证这一点，airbnb设计了一组A/B测试，同一间出租房，A房房屋简介用的是房东自己的照片，B房房屋简介用的是摄影师拍的照片，测试结果显而易见，有专业摄影师拍照的房子，预订量翻了2.3倍。所以，现在airbnb已经雇了一批职业摄影师，专门负责给房屋拍照。
亚马逊的CEO贝索斯就说过，“亚马逊的成功是基于每个星期，每天进行多少次实验的结果，”扎克伯格说，任何时候，facebook都有1万万个左右版本在测试运行。

那么，对我们来说，刻意实验该如何操作呢？
刻意实验的核心流程是这样的：首先提出假设，然后通过测试验证假设，分析结果，提出新的假设，然后再根据新的假设进行新一轮实验，如此循环，不断重复。
刻意实验强调1万次实验法则，这意味着，在进行实验时，你每天要写的不仅是待办事项清单，更是待实验清单。
在开展实验的这一天，你要针对这个设想不断尝试，收集结果，如果一天实验之后，再进入思考和反思，以便第二天进行新实验。
然而，刻意实验这么好，为什么做的人却不那么多？
一个原因是短期主义。事实上，很少有人能够接受做一次长期不能带来回报，而且还无法预测结果的事，哪怕这件事看起来，有很大的好处。
还有，给定多做，做实验不仅需要投入大量时间，给大多数的事实还都没法设失败，这会持续带来挫败感和羞耻感，让人们产生畏难情绪。
不过，如果你想清楚了这背后的数学逻辑，可能就不这么想了。

亚马逊的CEO贝索斯说过，大家看之最前，都曾因为失败的实验付出过极大的代价，但假设10%的可能性去获得四倍的回报，你就会这么干。
虽然每次都输，十次里面，有九次你的这些都会输，但只要你押对了一次，就够了。创业世界更是如此，你不断实验不断犯错，但只要做对一次，就可能带来上千倍的回报。
对我们自身来说，无论是改拿决策还是技能，都带着刻意实验的想法去进行，是提高我们收益的有效策略，每一次的实验都建立在前一次的思路和总结上，这样能为我们的成功曲线，带来指数性与非线性的变化。
