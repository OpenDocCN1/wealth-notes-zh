# 今日报告：物理和知识的思想实验

任何难题都有两个真正的阻碍：物理和知识。

+   —— 原子学新思维 2/4 @ 多伊奇

马徐欣

为什么人们设立的目标，大多都没有实现？

你知道到底有什么作用？我们都可以通过积累经验事实性知识，来获得竞争优势？

今天的议题分为三个部分：

+   1. 为什么说物理和知识是成功的真正阻碍？
2. 知识到底有什么作用？
3. 如何利用知识获得竞争优势？

2018年的一半马上就要过去了，是时候回头检查一下年初制定的目标、进度了。绝大多数人年初制定的目标，无非就是这么几类：更富有、更聪明、更有影响力、变得更美好、更美、更快、更健康。请问这些目标，实现了多少呢？

如果我们大部分都没实现，那到底是什么阻碍了我们达成目标呢？

有人觉得是因为缺乏动力，就像我们常说的那句：“知道了很多道理，却依然过不好这一生。” 有人觉得是因为缺乏信念，或者自己都不相信自己能做到，你再去努力都没用。

但有一个人的话，这些说法都不对，这个人叫理查德·西蒙斯（Richard Simmons），他是专门为肥胖设计运动计划来减肥。

他是专门学方法和思考方式的学习教练，他认为，我们之所以无法实现目标，所有的障碍，都来源于知识不够。

西蒙斯最近写了一篇文章，他在文章中引用了著名量子物理学家戴维·多伊奇（David Deutsch）的一个非常独特的观点。多伊奇认为，任何事情都有两个真正的阻碍：物理和知识。

> There are only two real obstacles to any problem: physics and knowledge.

这是物理很简单，唯一麻烦，就是在可以实现的事情范围。想一想，我们达成目标的就是知识的匮乏。

# 我为什么说物理和知识是成功的真正阻碍？

多伊奇这句话里的“物理”指的是，你的目标必须符合物理学的定律。在物理学范畴内可实现。如果超出了这个范畴，不管有多少知识，都不可能实现这个目标。比如说，不想看到太空旅行有多了解，你都不可能开着汽车到达火星。

如果你的目标在物理学范畴内可行，那么，多伊奇认为，实现目标唯一的问题，就是没有足够的知识。

多伊奇在他的《无穷的开始：世界进步的真实规律》（The Beginning of Infinity）这本书中用了一个想法来解释知识的重要性，他说，这是有史以来，展示知识重要性最好的思想实验。

这个思想实验是这样的：想象一下，在宇宙中有一个太阳那么大小的立方体空间，里面除了氢原子，别的基本上什么也没有。如果让你在这个立方体空间，你能看到什么？

没有物理学家，在这个物理学家眼中，他看到了everything。

那么，有没有可能，在这个什么都没有的立方体里面，创造出一切实？

多伊奇说，只要有足够的知识就可以。

他在书中详细解释了过程，大概的步骤就是，把现有的原子集中到一起，然后通过核聚变反应堆，就能把这些原子组成任何一种元素，最后，通过分子组装达到原子级和DNA打印，就能把这些原子转换成人类和人类所需的一切。

其实，这个实验说白了，就是通过物理学知识，一步一步地创造出来这些原子。

你，去制造一些，这不难，你不能清楚看到这个思想实验的全貌。

你可能会说，我不搞物理，这和我有什么关系？ 我想，我花几百子，才能学会这些知识。

其实，你不知道，最难、最不能实现，物理学家以为的，在这个范围内，无论你多困难的目标，只要你没有足够的知识，都能被实现。

# 知识到底有什么作用？

多伊奇想要通过这个实验让我们了解的是，知识是具有杠杆作用的。而每个问题，其实都是个知识检查问题。

在医学界有个话就是这么说的，“一分预防胜于十分治疗。” 知识就具有这样的杠杆作用。

举个例子，18世纪时欧洲曾经爆发过结核病，当时欧洲大概四分之一的人都死于这个病。

即使在中国，在也有“痨病九亡”的说法。

但，当科学家发现了结核病的发病原因，又找到了针对结核病的药物，也就是抗生素——链霉素时，知识开始发挥作用，挽救了无数结核病病人的生命。

到现在，关于结核病的知识越来越多，结核病的治愈率已经可以达到90%左右了。

这就是知识的杠杆作用，它能帮助我们用最少的成本去获最大资源的收益。如果没有知识，我们就会付出惨痛的代价。

接下来，我们来看，为什么每个问题都是个知识检查问题。

其实人生中，无论是实现目标，还是解决问题，我们都需要先回答下面两个问题：我需要哪些知识？我要从哪里找到这些知识？

这一部分多蒙斯特的比较少，几句话就带过了，我要给他补充一下来自畅销书《知识管理》的里德说：这本书的标题，是美国著名的思想家雷德思威德·庞德思特。他曾经两度得到普列策奖。

庞德思特知识分成两类：事实性知识和方法论知识。

事实性知识就是看各国的首都，各省的省会、历史大事件的日期，这种具体的知识。而方法论知识就是各种批判性思维和技能，像用互联网搜索信息，就是典型的方法性知识。

庞德思特对于评价一个人的学识和认知能力有一个比喻：水塔。我特别认同他这种说法：事实性知识是砖瓦，方法是知识是水，砖瓦和水塔一起，就成了知识的水塔。

也就是说，看一个人的学识和认知能力，就看看他有多少水。

现代人的问题就是，水塔太多了，砖瓦不够用。

方法知道太多了，事实性知识本身太多了，说白了就是，你甚至不知道自己不知道什么。这应该是最可怕的。

所以，庞德思特在中强调的事实性知识的学习，就是随时可以使用互联网来搜索。

你可以自己搜索的是什么是，这也是你可以自己使用导航软件信息，但前提是你，你得知道你的起点和终点，这就是事实性知识。

我以前常写学生英文写作时，学生总会问，我能写出思想，有深度的英文文章吗？

我能看到他们，你读过多少篇有思想，有深度的文章或者书？

学生说没读过。

我读你写什么学生说，我不能说我读，重点是说语言。

你有看过、想过，你才有可能说出来。

因此，这个路径就很清楚——想要解决问题，最重要的是，你要先知道自己不知道什么，最后你知道去做什么，也知道什么。
