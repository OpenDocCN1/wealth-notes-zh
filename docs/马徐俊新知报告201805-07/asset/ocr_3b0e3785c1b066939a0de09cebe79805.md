# ## 什么是Web 3.0？

如果你不是互联网从业者，可能听到这个说法会懵，什么“Web 3.0”都还没搞明白，就来了个Web 3.0？

简单说，Web 1.0指的是，由网站的运营者生产内容的互联网形态，比如原来新闻、搜狐的新闻，门户网站，大家上看的文章，都是网站本身提供的。

我们现在处在Web 2.0的时代，这个时代是微博和个人为主，主要是用户提供的，比如微博、微信、Facebook, Instagram，我们在上面看的内容，是别的用户发布的。

Web 3.0指什么意思，严格来，目前科技界还没有特别精准明确，大家约定成俗的定义，但基本上可以把它理解为一种新的网络互动形态，在Web 3.0时代，用户的数据所有权掌握在自己手里，并且能在不同网站使用。

如果说从信息的使用方式来看的话，Web 1.0的本质的解释，Web 2.0的本质是互动，Web 3.0的本质的去中心化。

你可能会问，Web 2.0用着也挺好的吗，为什么要变成Web 3.0呢？

这是，对于互联网的发明者和推动者来说，现在的Web 2.0时代可不是啥时代，跟他们理想中的互联网形差，可以说是南辕北辙。

最早互联网的诞生，是为了解决军队之间的沟通问题，如果指挥中芯被摧毁了，大家依然可以通过数据路由连接，所以互联网的本质是去中心化，最早的网络安全机制是免费公开的。

随着互联网越来越多被关注和商用，大家开始在网上获取信息，互联网记住了用户产生的数据，这使得在网上经商几乎不可能，因为你不知道谁来了，买了啥，电子商务就没法做。

后来网管公司制作了一种叫cookie的技术，可以辨识用户身份，当做数字消遣记录来使用，就出现了一个标识符，成为用于用户数字身份的记录者：Google记录网站访问你的历史，Facebook记录你和你的身位互动行为；亚马逊记录你用什么买啥，这些都是Web 2.0时代。记录这些的用户数据，可以用来精准广告，这更进不了，用户越多数据越多，广告收益越好，所以这些互联网公司，就成了围积用户数据的大堡垒。

但是注意，用户在这些公司网站、App上产生的数据，可属于我们自己，而是属于这些公司。比如说，有一天你不用Facebook了，那么上面所有的信息都没了，你Facebook上所有朋友关系也没了。换句话说，你的网络身份不属于你自己，而是属于这些公司。这点在咱们之前2020年也讲过。

Web 3.0要解决的就是这个问题，要把用户自己的数据使用权，交还给用户。比如，有一天你用着Facebook的服务，你想微博，微博希望其他社交服务，你Facebook上所有数据可以接口，迁移过去，你甚至也可以不用在网络上交互。这就是Web 3.0了。
