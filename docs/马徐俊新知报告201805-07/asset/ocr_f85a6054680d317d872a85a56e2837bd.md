# “信息落差”的危机

在信息不发达的年代，多数人在资讯上都是“吃不饱”的状态，一旦你掌握了别人不知道的信息或者渠道，就能利用“信息落差”，取得压倒性的优势。

但如今，我们愁的是信息过剩、“吃撑了”，消化不良。“信息落差”的分水岭在于，你是否知道该做什么？怎么做？你能不能从海量信息中筛选精华，获得洞察力？

在这一部分，我会列举两个“新知”，来让你看到“信息落差”可能造成的危机。

# “环嗅血癌”——对“硅谷神话”的盲目迷信有多可怕？

最近，硅谷有一家“天霸”级别的科技企业被揭穿了骗局。

这家公司叫Theranos，它称自己发明了一项突破性的血液检测新技术，只要29美金就能做250项血液分析，比医院检测的费用便宜得多、也快得多。

整蒙14年来，数百万美国人使用了这家公司的血液检测服务，它的估值一度被抬到了90亿美金。

但是在最近，它被《华尔街日报》揭露了根本不存在，血测的检测。所谓的新技术根本半步在去，血液检测原理漏洞百出，许多人发现自己的病情被耽误了，可惜为时已晚。这件事，给美国民众的生命安全带来了巨大的冲击，引发了大规模的信任危机。

这家骗子公司为什么能维持14年，而且被扯出神坛？其中一个原因，是硅谷创业环境对“硅谷神话”的痴迷——过度依赖圈子、关系网为创业者背书。

即使你根本没有掌握任何核心技术，但只要投资圈、政商界的大佬肯为你站台，你就能在资本市场上呼风唤雨，Theranos的美女创始人伊丽莎白·霍华德就是这么干的。

但更深层的原因在于，普通老百姓盲目迷信“硅谷神话”，对所谓“硅谷明星”的话语不加思考和分辨，全盘接受。

这其实就是“信息落差”造成的后果。因为那些高级圈子所知道的信息领域，你根本触及不上，你不知道的全是骗局，反正有各界精英替他们站台，那我们也相信好了。

所以，我们作为普通人，该怎么避免在这样的骗局上呢？最关键的办法就是，多了解科技趋势和前沿信息，看到它们的运转机制，保持理性思考，解决“信息落差”带来的问题。

# 区块链能颠覆网络霸权吗？

《纽约时报》的专栏作家 Steven Johnson认为，颠覆火遍全球的区块链技术，很可能会颠覆谷歌、Facebook这些巨头造成的网络霸权。为什么这么说呢？

简单来说，互联网行业已经发展到了封闭技术的极限了，出现了结构性问题。全世界几十亿居民的私人信息，包括身份、地址、消费习惯等数据，都掌握在几大网络巨头手中，变成了他们的核心资本。

普通网民们的数字身份，并不能我们自己掌握，而是科技巨头们。我们每次证明自己是谁，需要向科技巨头去调取数据，来再现自己。而他们的信息和数据，被巨头用来推送广告、提供交易服务等等，他们从中赚取了巨额的利润。

其实，这也是“信息落差”给我们造成的困境，甚至不知不觉的有各种数据行为被监控、被记录、被利用了。没有意识到，自己生活在一个互联网越来越垄断、越来越不公平的时代中。

那么，区块链技术“去中心化”分布式记账（区块），真的可能颠覆现在的网络霸权呢？这是值得期待的，如果这一天真的能实现，那么，在互联网数据领域的“信息落差”，也许会得到一定程度的解决。

# NASA没有征服火星，是败给了政治而不是科技

今年2月份，马斯克的Space X公司发射了一枚探测新型火星，飞向火星，并开启了人类探索火星的新征程。这使得美国国家航空航天局，也就是NASA，成为被全球耻笑的对象。

一个坐拥两万多人的民营研究公司，居然败给一个只有一万人的民营公司，真的是因为技术不如吗？

当然不是。《新科学家》杂志就发表文章说，其实从技术上而言，NASA的这代火箭的技术已经很厉害，远远不输 SpaceX 在月球上的“土星号”，况且NASA的人才储备也是无可匹敌的，NASA 公司的技术人员物体流，以前就是NASA的员工啊。可以说，在这个地球上，还没有一家公司在航天探索领域能超越NASA。
