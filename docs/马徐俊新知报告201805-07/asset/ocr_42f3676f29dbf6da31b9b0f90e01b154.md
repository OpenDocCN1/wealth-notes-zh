# 八卦是怎么产生的？

《人类简史》的作者尤瓦尔·赫拉利有一个八卦理论，他认为，没有八卦，就没有人类的今天。咱们中的老弱病残，也就是智人在进化过程中的遭遇相对更多，与同伴相比，我们更瘦的、更聪明，行动更敏捷，因为我们就靠八卦能独当一面。就是因为他们脑中的八卦能力：

智人发达的语言能力给了他们独特的优势，本色的信息传递，比如说“河边有狮子的家人”。这种，尽管像在描述现实事物。原，而智人的语言在描述不可见、不可触摸的八卦。八卦可厉害了，不出手就信八卦的时候，大家都坐在一起聊八卦，比谁值得信赖，谁不可靠，谁能力挺，谁和自己关系更好。

这是“什么”？看这些词：“信任”“可靠”“好”等，这些描述了八卦的能力，因为它们为八卦提供了进行亲密社交，为了模拟复杂社会的可能性，也正因为有了描述虚拟社会的能力，人类才能构建种种关于信仰的故事，互不相识的人共用了共同的话题和努力的方向，才能紧紧地团结在一起。

这是赫拉利在《人类简史》里的第一个影响人类命运的革命——认知革命，这也是人类社会形成的一大因素。

# 为什么我们天生热爱八卦？

了解到八卦是人类进化的需要之后，你可能会想到，人类为什么永远对八卦欲罢不能，并且向对方追根？答案很简单，因为这是我们的天性。

《英国发展心理学季刊》发表过一项研究，在五个到六个月能熟练地说出人和物品，比如两个小孩，但谈不上现场的另一个小孩，根本不向他人教，可以说，从摇篮里的落地窗酒会，到市百店的饭后茶时间，随时随地都能听到八卦的讲，没有任何借口。

著名的进化心理学家罗宾·邓巴写过一本书，书名是《梳毛、八卦与语言的进化》（Grooming, Gossip, and the Evolution of Language），邓巴最有名的理论“邓巴数”，就是在他书中被提出的，它指的是一个人能够有效社交网络最多有150人。超过这个数字，就没办法维系有效关系了。而这个数字提出了一个重要观念：人类的八卦和动物相互梳毛，梳理一样，都是一种社交维系社交关系的行为。

我们和灵长类相似，通过相互梳理，把虱子作为社交信息源，确保有威胁出现的几率可以及时应对。比如你说有背叛你的嫌疑，它就更会对自己的伴侣有背叛自己的嫌疑，大喊声气更响更频繁，甚至要起梳理得，这个时候，平时和梳理得一起梳毛的好闺蜜就会挺身而出，帮助梳理回去。

相互梳理也是互表忠心、建立私密关系的一种。梳理时，被梳毛的一方会自己的目标，梳毛时的行为什么行动自己看不见，这相当于把自己的生命交付给对方手中，要是得到被梳理照顾，梳毛的一方不敢轻易逃跑，这样随着周围的环境，当天敌出现的时候，得叫哪方，可梳毛这种活动是相当考验信任的。

但随着我们的祖先越来越聪明，组织规模越来越大，靠梳毛就无能为力了，因为效率太低。这个时候，用什么来替代梳毛的结盟功能呢？那就是八卦。

八卦、被梳理或者言语版的梳毛，它的交流速度比梳毛语言高、形式上还可以一对多。所以，效率就飙到了许多倍，很快就成为了最受欢迎的结盟手段。

而经过人类千万年来的“优胜劣汰”，八卦思维，八卦思考高发的结盟能力，就被写进人类的基因，一代一代传下来，成了，我们身体里的一部分，就像渴不想水，困不想休息一样。所以，我们忍不住八卦都是天经地义。

八卦无处不在，但总名字不怎么样，不太好听，听到发展，在所有的八卦中，只有大约3%到4%的内容是有恶意的，而好好地利用八卦的社交价值，其实可以给我们带来许多好处。

# 如何利用八卦为我们加分？

第一，我们可以利用八卦迅速取得相互信任，建立身份认同感，a sense of shared identity.

不过，要注意八卦场景，你得知道什么时候该多别人，什么时候该多关自己。

研究发现，年轻人在聊天时，女性比人多，这是由，而男性则相反。邓巴认为，这是因为由于社会分工不同，女性要照顾孩子，需要帮忙，所以她要寻求联盟，而男性更要面对竞争，所以要占自己。

也就是说，如果你想快速建立关系，那在八卦中就多关对方，对不太喜欢的人，少关心一下，如果面对一群人的八卦局，就是要突出自己，吸引别人的注意力，那你就要多和自已相关的了。

第二，我们可以利用八卦交换资源，解决难题。

很多讲职场人际关系的书，都强调两点，第一，不要错过茶水间的闲聊；第二，一定要和同事一起吃午饭。这两个场景，可都是八卦的高光时刻。看似一心无谓的八卦，其实就是你们在彼此“梳毛”。

如果你遇到了一个棘手的问题，需要一个渠道，我不确定这方面的资源，也可能我需要一个解决这个问题的，你就能看到想到的一个卖情的办法，想到了解决问题，都是在八卦的过程中找到的解决方案。进一步来说，就看没解决问题，能够通过八卦倾听一下，也可以缓解压力了。

第三，利用好八卦可以提升你的领导力。

领导力这个词咱们都太熟了，它指的是你设定一个目标后，能让团队的人心甘情愿地，尽力完成目标。

道理听起来简单，但很多技术型员工转管理后，都会发现不知道该怎么做管理人，更何况跟众下属打成一片、形成默契的团队。

其实，在这种情况下，八卦就是一个很好的切入点，作为领导，除了平日公事公办的沟通，新提拔合适的机会，跟下属聊天八卦，让你更被领导团队关系，而且觉得你平易近人，这样一来，下属对你的信任度也会更高。
