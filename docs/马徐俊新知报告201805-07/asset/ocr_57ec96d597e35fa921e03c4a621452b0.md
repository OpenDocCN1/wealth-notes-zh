他们支付全部的医疗费用，也没有富到可以买得起个人医疗保险，结果还是有很多人看不起病。

通过这两个部分，你会发现，全民医保不是我们想的那么样，需要一个国家特别有钱，也不是我们之前认为的，全民医保就是国家单方面砸钱，没什么回报。我反对全民医保派的那种刻板印象是不成立的。

# “穷国”如何推行全民医保

无论对于个人、公司，还是国家，在资源有限的情沉下，在资源的分配，都要精打细算，把钱花在刀刃上。

精打细算的核心有三点。第一点就是结合自身情况，首先解决基础医疗设施的问题。如果不能解决基础医疗设施，就先把要解决的问题建立起来，定制性较差的严重的疾病。比如说埃博拉，当年在非洲暴发时，就因为人们已经感染了一具感染了几埃博拉病毒的人，连送医院，死了365人。

有一位当地的医生事后说，他当时听说埃博拉引起死亡的新闻时，就知道完了。这个病毒会杀很快，广泛地流传，因为埃博拉的这个情况可以说法是医疗的沙漠，没有任何留病，没有公共卫生设施，也没有任何的医疗保险，但病人平均寿命到50岁，1/3的婴儿都活不过5岁。而大多数的诊所都非常少，也没办法提供有效的治疗，人们有病了，也不愿来看病。

在埃博拉爆发之前，莫里利邦全国每5万人有个医生。在这个环境下，病毒爆发时，人们只能被动等待的外救物资。但外部救援也只能及时，等到医疗物资到达的时候，可能病毒就已经大爆发完了，只能收拾残局。

那在这种条件下，就需要从建立基础和有数的医疗中心医院，以及出现过的问题，也能做出积极的应对。这个才是最重要的。

第二点就是，控制疾病得有优先级。去年11月，华盛顿大学发布的《疾病控制重点报告》，《Disease Control Priorities Report 中，列出了100项高优先级医疗服务，比如伤口和骨髓愈合，免疫、抗生素，基本的手术健康等，这是很好的参考。这份报告书，如果可以实施的话，每年能救下将近200万人。

最后一类是，如果说大家，能不能加补到这类费用上少点国家，像是孟加拉、印度尼西亚、巴基斯坦，这些国家能源耗力助上花的钱，比在医疗和教育上花的钱还多，明显是不合理的。这是‘经济学家人’的建议。

# 总结

我们来回顾一下，国家经济状况和全民医保并不是相反关系，不是说只有国家有钱，才能推行全民医保。丰富民生服务。对于资源有限的国家，更要精打细算，做事要考虑优先级。

从今天的看内页里，我们不知道了，如何统筹看待全民医保这样国家层面的问题，落到个人身上，其实道理也是相通的。

我们总是觉得，必须要达到什么样的条件，才能做某件事，结果只是白白地时间都浪费了，像前面说过，我在《Man's Trash is Another Man's Gym》一书里讲的非洲加纳的一群青年，因为没钱，投了健身的瑜伽和健身房，为一个极其烂旧的健身房，还是免费的，但他们个个练得都极其健美生。

相反，那些去豪华健身房办卡、买一堆专业好看看的装备的人，多数也只练出好身材。

这就像你说的美国和条件有限的利昂国，在全民医保上打的过一样。重要的不是如何利用有限资源的，针对住关键问题，工作学习哪个又不是这样呢？
