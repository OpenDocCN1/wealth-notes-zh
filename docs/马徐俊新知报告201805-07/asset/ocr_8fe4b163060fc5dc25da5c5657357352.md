# 今日报告：人类的死亡率也有“平台期”？

如果真的有一张所谓的“死亡率平台期”，那将意味着人类的寿命没有极限。

《科学》

马徐瑞

《科学》杂志最近发表的一项研究表明，活过105岁之后，人类的死亡率将趋于一个平台期。这是否意味着人类有可能长生不老？

今天的问题分为三个部分：

+   “死亡率平台期”的新发现如何颠覆常识？
“死亡率平台期”是如何被发现的？
人类的寿命到底有没有极限？

生者所死，是生命的必然规律。我们越知道，随着年龄增长，人类就会越近死亡，这是人类常理。可是，《科学》杂志最近发表的一项研究告诉我们，事实也许不是这样的。

科学家们发现，人类的死亡率并不会无休止地增长下去，而是存在一个平台期。到了一定的年龄，死亡率将不再上涨了。具体来说，这个平台期到来的年龄，是105岁；105岁之后，死亡率会最终稳定在60%左右。

这是什么意思呢？简单来说，如果活到了105岁之后，死亡率平台期，就解释了人类为什么死亡率不会一直上升。

《科学》杂志对此表示——如果真有一个所谓的“死亡率平台期”，那将意味着人类的寿命没有极限。

```
If there is no mortality plateau, then there is no limit to human longevity.
```

这听起来是个很糟的好消息啊，谁不希望长生不死呢？更况且，随着医疗卫生条件的进步，人类的平均寿命也在不断增加。

新中国成立之后，中国人的平均预期寿命是35岁，而2017年中国居民平均预期寿命已经超过了76.7岁，整整增加了一倍还多。照这个趋势，万一咱们一不小心活到了105岁，死亡率又不往上涨的话，那之后，岂不是可以越活越久？
