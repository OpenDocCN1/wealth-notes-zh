# 小弟，你好：

我叫马骏，未来一年，我要给你提供一项顶级服务。

简单说就是：清除全球大球，重要机构气氛，把那些最新事态背后的“新知”提供给你。

别“新闻”，你只能看到零星的事件，不甚知……

但是事件背后的势态运转，是有很多聪明的人在分析的，也是有很多聪明人在等着看的。

比如说：绝大多数媒体都把特朗普当靶子，追不靠谱。但是，《大西洋月刊》说了，出题的可不是特朗普，是美国总统这个位子。

再比如，谷歌的智能制造一出，又一流科技领袖就来了。是果的科技分析师Ben Thompson说了，是科技只有两种哲学，一种是替人干活的，一种是给人当工具，替人干活的。

还比如，一说文化，大家就会说西方奉行个人主义，东方奉行集体主义，但是《新华学》杂志说了，一个国家文化上的“松”和“紧”才是造成文化差异的最终原因。

……

如果你没时间、没能量第一时间看到这些分析，或者你懒得看，视为你服务的时候机成熟……

必须承认，不是什么创举。

过去顶级服务，通常是提供给机构的，只不过贵得要死。看到APP已经很贵很贵的事了，原来本很多很多人很贵的事，用极低的价格卖给很多人。你可以通过价格7、几十万一万一年，因为互联网的分发效率。

还有，因为APP里聚集了一批高质量的用户。这些人知道的事，很多人也想知道一下。

去年，已经有近40000人享用了我们团队的这项服务，评价极好。而今年这一季，你得看，因为我们团队做对几项做一次重磅升级。具体来说，有以下几点：

+   1. 杂志的数量：去年，我用了39本杂志，帮你往西方世界跳动的脉搏；今年，从39本增加到82本，还新增了专业机构报告。

+   2. 主题：去年，我每天给你介绍一篇杂志里有份值的文章；今年，我每天再给你一篇《新知报告》，综合不同大师，观察角度和结论，给出多方位的立体认知。

+   3. 解析方式：去年，你了解的是杂志、科技、文化、政治等领域有价份值的观察，今年，我针对下一个话题，从现象，讲到新发现，再告诉你，里面有什么影响你未来的新认知。

好，今天开始，探索世界大势的“新知报告”就正式启动了。

加入这场旅程，沿岸风景真是不错。想想看，未来一年，为你服务的将是以下这些人和机构：

+   1. 商业类刊物和它们背后的机构：比如哈佛商学院《哈佛商业评论》、世界顶尖的管理人士《哈佛商业评论》、给经营人的指导手册《财富》；麦肯锡公司主办的《麦肯锡季报》等。

+   3. 思想者聚集的刊物：《经济学人》《财富》《读者文摘》《大西洋月刊》等。

+   4. 当然，还有我，马骏，我们的团队。

既然你已经看到了这里，我不妨做一个许诺：

未来一年，《新知报告》听我为你解析全球焦点议题，你会不喜还行。
