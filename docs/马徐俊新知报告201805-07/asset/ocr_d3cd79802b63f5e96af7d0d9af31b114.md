# 1 接地活动为什么会流行？

接地活动是一种非常简单的活动，说白了，就是让身体和大地进行直接接触，比如光脚在室外的地面上行走。接地的英文叫earthing，也叫grounding，意思大致都是“和地面接触”。

这么简单的一种活动形式，为什么最近大受推崇？不只是《华盛顿邮报》（盖茨文章推荐了），其它的媒体，比如《赫芬顿邮报》也曾经写文章报道过；关于接地活动，还有专门的学术书籍，叫《接地气（Earthing）》，主要从一个角度介绍接地活动对健康的好处，从医学研究角度来看，在美国医学谷歌文献搜索引擎上PubMed上一搜关于接地活动的研究，更是一搜一大把。

《华盛顿邮报》的作者在文章中提出一个观点：由于社会和科技发展，人类的活动和生活状态方式发生了巨大的改变，而正是这种改变，导致了现代人的各种健康问题。

过去人类光脚走路、睡在地上，或者用动物的皮做鞋子，这都是直接和大地接触。而现代人的高楼大厦也好，穿的橡胶底或者塑料底鞋类也好，都破坏了人体和大地连接，把人类变成了一个绝缘体，和大地电流彻底断开了。

与此同时，外部环境的变化，比如 various 各种产生的电磁干扰、环境污染等，也扰乱了人体的生物电场。环境医学也研究者认为，现代社会的慢性病毒、免疫性疾病和炎症疾病的急剧增加，就和这种断裂有关。

而接地活动可以修复现代人与大地电洛的断裂，平衡人体的生物电场环境，改善人的健康状况。
