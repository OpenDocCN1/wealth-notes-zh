# | 高手靠运气，普通人靠纪律

《经济学人》报道了去年在赌城拉斯维加斯举行的一场德州扑克比赛。在这场比赛中，你会看到，冠军只有7%的胜率进过决赛，凭借最后手一牌获得惊人大逆转，成为了冠军。

穆斯塔里的成功靠的是什么？两个字，运气。

难道《经济学人》就想告诉，你不是需要努力，凡事都凭运气就够了？当显然不会，在这个故事中，我们得到的启发是：高手靠运气，普通人靠纪律。

为什么这么说？

举个简单的例子吧。一般人打牌，通常先分析牌面，然后再下注，最后再看自己有多少筹码，才决定下注，这是普通人的思路；而职业选手正好相反，他们先看自己的筹码，再分析对手，最后再看牌。

最惊艳的高手，真正的高手其压根就不看牌，他们打牌，打的是另一种技能。

而能打出这种牌面的人，三年至少要打十万手牌，才练出来。你没有这个积累，就别想跟职业选手PK。

所以，高手对下，实力对比已经微乎其微，拼到最后，只剩下运气的因素。而普通人，根本上不了高手的牌桌，也轮不到运气的因素。

这说的什么？如果你没有经过几十万手牌的残酷训练，你就没有资格成为高手，就别想着用高手的思维方法。

而如果你也不是高手，无论在桌还是职场，你只能记住两个字：纪律。你应该老老实实定位，遇到好牌就赌，不好就放弃，才能让自己安全。
