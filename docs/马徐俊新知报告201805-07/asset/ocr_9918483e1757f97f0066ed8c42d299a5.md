# 今日报告：未来的建筑如何被机器改变？

自动化之前的时代，是机器改造环境，而当自动性开始，环境将会被设计去匹配机器性能。

> ——“《大西洋月刊》”

卢诗溪

随着机器的出现和进化，人类社会的建筑思维，一直在随之改变。从自动化时代到机器人的到来，建筑带入了后人类时代，它对我们的生活和人际关系，将会造成什么样的深远影响？

今天的内容分为三个部分：

+   机器是如何改变建筑形态的？
什么是后人类时代的建筑设计？
自动化时代的建筑将如何影响人类生活？

和过去的任何时代相比，我们这个时代最重要的变化就是自动化。你一定感受到，我们生活的世界，随着机器是被自动性设备制造包裹。现有ATM机，家里智能机器人，工厂里有各种自动化流水线，还有汽车、手机都有自动驾驶。还有看，出行各种设备，都在节省我们的时间，改变我们的生活方式。

自动化带来的上述影响，我今天就先不讨论。今天要和你们谈的话题，平时很容易被忽略，但其实又特别重要，那就是，自动化正在改变我们的建筑。

你有没有发现，与我们朝夕相处的建筑正在发生变化？这些变化背后的原因是什么？我们如何处理变化以及这些变化又会给我们的生活方式带来什么样的影响？

最近在《大西洋月刊》上，我看到一篇文章，讲的是自动化的时代之间，对建筑的设计来说，还有人与人的交互方式，都造成了很大的影响和改变。这篇文章的作者是卡罗兰·米兰丝（Carolina Amirante），她是《洛杉矶时报》的专职作者。

《大西洋月刊》认为，自动化之前的时代，是机器在适配建筑。而在自动化时代，建筑将会被设计之初就去适配机器。

```
If buildings once had been awkwardly repurposed to integrate automation, now they can be designed to streamline machine interfaces from the start.
```

在今天的内容里，我将带你走一趟这个机器与建筑的变化之旅，当你走在路上，再看向各种建筑之后，相信会有新的理解和感受，因为你知道，从建筑中，我们可以从另一个角度来看待历史，而自动化对带来的空间变化中，见证了一个时代的变迁。

# | 机器是如何改变建筑形态的？

如果问你，是什么事件标志着人类自动化建筑的开始，估计你怎么也猜不到，这个起点，其实是世界上第一台ATM机的出现。换句话说，ATM机的出现，代表着建筑开始考虑机器的需求了。

1967年6月27日，伦敦的巴克银行，推出了世界上第一台自动取款机。当时你如果想使用这个机器，得事先购买许可券，一张券能取10英镑。客户取完钱后，系统不能自动从客户的客户那里扣除，还需要人工操作。虽然听起来是个很笨拙的开始，但这台ATM机，标志着自动化设备开始进入人类建筑。
