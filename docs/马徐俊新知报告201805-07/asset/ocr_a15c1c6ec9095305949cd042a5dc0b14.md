# 今日报告：如何从经济角度解决性骚扰问题？

没有什么东西，比钱更能改变美国社会。
——《华盛顿邮报》

马修·戴维森(Matthew David)是《华盛顿邮报》专栏作家。他认为反性骚扰运动需要解决的根本问题是经济成本。

性骚扰运动一直走不到突破口，如果能让其造成的经济损失算一笔账，能从根本上解决这个问题吗？

今天的议题分为三个部分：

+   * #howmuch? 运动的突破口是什么？
* 性骚扰带来的经济损失有多严重？
* #howmuch? 运动面临的困境？

反性骚扰运动在过去的一年席卷全球，各大媒体争相报道，众多名人出面据声呐喊，咱们专栏也做过相关的内容。遗憾的是，这些运动虽然提高了整个社会对性骚扰的重视程度，却没有带来根本性的解决方案。那么，到底有没有办法，能够巧妙地解决性骚扰问题呢？

之前在《华盛顿邮报》上看到过一篇专栏文章，作者是美国政府问责署专栏记者乔希·戴维森，内容是说：美国参议员柯克·拉维·布朗利提出了一种新思路和观点来关注经济：着着性骚扰问题，或许应该从经济领域入手看性骚扰，从这个角度出发，才能让人们更直观地判断性骚扰的严重程度，引发真正的社会变革。

吉丽布赖恩塔基给出了这篇文章的一个口号，叫#howmuch？

乔·戴维森在专栏里，非常赞赏吉布莱尔提的观点，因为没有什么东西，比钱更能改变美国社会。

Nothing moves America like money.

# | #howmuch？运动的突破口是什么？

在互联网上取得影响的反性骚扰运动，是一场非常具有影响力的全面浪潮，从哈维·温斯坦开始，西方世界的众多娱乐界、商界、新闻界、政界大腕纷纷落马，甚至连上于美国联邦特别陪审，在《华盛顿邮报》的专栏文章看来，这些反性骚扰运动，存在着两个根本性的问题：

首先是穿透性不够。虽然反性骚扰声势浩大，但媒体主要是在联网，落马的也多是社会地位比较高的性骚扰者（predator）。但是，施加性骚扰的，远不是聚光灯下的那小撮人，它是一个很隐蔽的社会问题，只牵涉几个大佬，作用有限。相对而言，很多来自社会底层的性骚扰事件，比如遭遇了性骚扰，却没有发声渠道的女性，因为没有公开投诉的渠道，她们的声音无法被听到。

其次是解决力度不够。之前的反性骚扰运动，只是鼓励受害的女孩“说我的故事”，或者选择“坚决说不”的态度，但没有系统性解决性骚扰问题的方案。某些情况下，参与反性骚扰运动，甚至成为了一些人假打、博取舆论声量的工具，反而打击了人们妇女权益的声援。这个情况，咱们专栏在上学期就讲过了。

想要真正推动整个社会，去痛下决心解决性骚扰问题，需要找一个更有效的武器。乔戴维森在专栏里说，之前的反性骚扰运动，已经营造声势上完成了使命，如今到了讨论系统性解决方案的时候。而#howmuch？运动的目的，就是一个突破。

# 1 #howmuch？运动面临的困境

看到这里你可能一愣——不就是个性骚扰运动，怎么会牵扯到影响整个国民经济的？这不是扯虎皮张犬大旗，乱扣帽子吧？

还真不是。

# I 性骚扰带来的经济损失有多严重？

在一般人看来，性骚扰带来的经济损失，无非就是法律费加上各种赔偿。但实际上，远不止这样。

乔·戴维森在文章里说，性骚扰问题的真正成本，在于它会导致受害者工作效率低下、请假病假，跳槽甚至转行，造成人力资源的严重流失。有调察数据显示，女性在遭受职场性骚扰后，跳槽的概率是一般员工的高6.5倍。

除此之外，一旦发生性骚扰丑闻，公司和机构的各名商誉也大打折扣，劣质人才吸引不到，其他公司和机构也不愿意与之合作。换句话说，性骚扰问题正以一种不易察觉的方式，伤害着雇员和企业，阻碍着社会经济的运转。

今年4月，《华盛顿邮报》的记者莉莎·潘基出了一份报告，调查了美国政府内部从2014年到2016年的性骚扰状况，结果触目惊心一6万人的样本里，有12%遭遇过职场性骚扰。换句话说，女性在政府系统内部遭受性骚扰的比例达到25%，男性也有9%。而性骚扰的比例则更高，男性比例高达27%。此外，美国退伍军人事务部的比例高达26.4%，国土安全局也有25%之高。

要知道，美国联邦的雇员人数有1400多万，它是全美最大的用人单位。而且有政府作为公信力的象征，其内部的性骚扰状况就如此严重，其他的私人公司和机构，就更不必说了。

其实对于性骚扰可能带来的经济损失，美国在1980年代有过一次统计，不过范围仅限政府部门的，计算出来的损失是3.2亿美元。放到现在，大概是5.5亿美元。你可能觉得，损失好像也不算大啊，也是。但是，性骚扰的根患是很容易被忽视的。因为没有人愿意去相信或承认自己遭遇了骚扰，如果我们做一个类比，你就知道问题严重有多重了。

美国的种族问题就很严重，这个咱们都知道，根据专业的统计，由种族歧视产生的损失，每年给美国造成了高达2.5亿美元的损失，相当于GDP的14%。对比种族歧视，性骚扰其实造成的损失，可能远远超过我们的想象。

因此今年一月，刚才提到的民主党女参议员科林斯·格林斯潘，就责问其他22名议员，要求美国劳工部详细调查性骚扰带来的经济损失。然而劳工部拖到了4月才给了回复，回复是一拒绝展开这样的调查，这是为什么呢？

劳工部给出的理由有两个，一个是太贵了一太oo hard and too expensive。

首先，要收集准确的数据非常困难。在美国，性骚扰是个非常小范围的事，就算有人站出来提供指证，接下来的取证和处理程序的开销也非常高，谁也不愿意自找这些的官司麻烦事，被原告告上法院之后就难以脱身，就只能默默被媒体渲染成全网头条了。因此，就要求受害者站出来，也很难简单地量化性骚扰的定罪。

其次，调查性骚扰的业太专业了，需要统一一批专业人员，这个太专业了会判刑，得经过培训、认知测试、数据理解和培训，对性骚扰的数据涉及隐私，调查过程非常敏感，可能仅仅是一次质询，都会引发一大堆法律问题。

因此，去跟布赖尔为代表的参议员们，下属的独立办公室，也就是政府问责办公室GAC（Government Accountability Office）进行调查。至于调查结果能不能行下去，不会有进展，现在还不知道。

无论结果如何，#howmuch？运动为性骚扰运动，找到了一个理性更有力的突破口，让人们从一个更现实的角度，去设法攻克这个长期难题。

# I 总结

总结一下今天的内容，席卷全美的反性骚扰运动引起广泛关注，却没有拿出具体的解决方案。因此，本文参考马修戴维森提出的思路，从经济的角度去调查性骚扰问题的成本，用具体的数据来证明这个问题的严重性，从而引起社会重视。

但是，要说让这笔账，不仅很难，并且很贵，因此目前还在艰难的推进过程中。

我觉得，这个事件能体现美国人的办事思路，得用民立法，用具体的数据做立论，然后用立法的方式来做改变，从立国到种族平等都靠这套逻辑，使得美国社会也沉淀了一套的方法。
