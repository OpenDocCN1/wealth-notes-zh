# 今日得到：

+   1.《柳叶刀》杂志的新研究，证实了空气污染特别是PM2.5，会诱发糖尿病。

2.PM2.5诱发糖尿病的机制主要有两点：PM2.5会引起身体器官的炎症，影响胰腺功能；PM2.5有毒性，影响细胞的氧化进程，最终影响胰岛素的分泌。

3.仅仅2016年，全球就有320万人因为空气污染而患上糖尿病，占全年新增病例的14%。

4.今后对糖尿病的预防和控制上，必须把空气质量作为重要的参考因素。
