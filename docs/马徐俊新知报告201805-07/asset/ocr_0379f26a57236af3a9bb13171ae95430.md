马修·马斯克SpaceX向火星发射了超级远程火箭后, NASA遭到了大众的痛击, 登上月球的时刻, 人们看着马修·马斯克一直无所事事, 那么, NASA真的在 技术 上被政治困住了手吗? 今天的内容分为三个部分:

+   NASA的技术真的不如SpaceX吗?

政治如何阻住了NASA的手脚?

NASA该如何找到“脱困之路”? 

自从今年2月份, 埃龙·马斯克的超级运载火箭“猎重型”飞向火星轨道之后, NASA,也就是美国国家航空航天局, 遭到了全球人民的痛击, 你看别人家马斯克多有情怀! 他的SpaceX才5000人, 就能展开火星之旅, 我们NASA有20000人, 早在1969年就登过月了, 干了几十年, 花了这么多钱, 结果只打了个平手, 怎么说连一家民营的航天科技公司都不如了? 你们好意思啊?

不过, 最近我在《新科学家》杂志上看到了一篇文章, 叫做《火星遍地钱》, 让NASA的这个问题分析得非常透彻。这篇文章告诉我们, 其实并不是NASA不想有所作为, 而是政治因素限制了它的手脚, 阻碍了它飞向火星的步伐。

前NASA科学家、现航天评论家查德·康宁说: NASA面临的最大问题, 是上压下放的指令, 始终在更改和切换。

> The biggest problem confronting NASA is a constant shift in what it is told to do.

# NASA的技术真的不如SpaceX吗?

说到公道话, 马斯克做得非常厉害, 但其实, SpaceX的能力还远远达不到NASA的水平。

从技术上说, 猎重型火箭的载荷是63.8吨, 半个世纪前NASA登月的“土星5号”, 载荷是118吨, 是“猎重型”的一倍半, 可就是火箭, NASA至今全世界保持了大批顶尖的航天人才, 比如马斯克的副手扬·弗格森, 他本来就 是 NASA的火箭引擎工程师, 被马斯克挖过之后, 成了SpaceX公司可用人、打造出了“猎重型”火箭系列的梅林发动机。

可以说, 时至今日, NASA依然是这个地球上, 在航天和太空探索领域最强的机构, 没有之一, 但是, 让大众吐槽NASA原因, 主要在于, 它的确实很长时间没有什么大的作为了。

自从1969年成功登月之后, 半个多世纪, NASA对于探索太空的热情从来没消退过, 而且目标很明确, 去火星!

然而, 对于该不应该去火星, NASA内部就分裂成了两个不同派系。一派主张, 先返回月球, 再去火星, 另一派人认为, 就应该直走火星啊!

“月先走派”的理由是, 现在去火星的技术条件还不成熟, 应该先在月球上做测试, 等待了足够的把握, 再去火星, 成功率更高, 而且月球测试的过程出现什么问题, 月球近而低, 方便补救。总之, 这一派科学家走的很稳健路线。

“火星派”的理由是, 如今所有的条件, 可以通过自动机器人技术来搞定, 再次登陆火星是一件很危险, 会拖住征服火星的步伐。很明显, 这一派科学家是激进型的。

所以难辨的局面出现了——尽管大家目标一致, 但路径有有很大的争议。两派科学家, 争了半个世纪, 始终没有达成一致。曾经登陆过月球的12名宇航员里, 只剩下4名还健在 了, NASA内部竟然还是没能在争出了结果来。

但说到底, 这个问题一直悬而未决, 是因为始终没有一个拍板的人, 为什么会这样呢?

# 政治如何阻住了NASA的手脚?

简单来说, 在美国能拍板NASA如何去火星的, 有两种人——民众和总统。

但遗憾的是, 美国老百姓对太空探索这件事, 压根就没兴趣, 根据皮尤调查的最新结果来看, 63%的美国民众认为NASA应该关掉探索预算, 防止人类行星上地心运动, 只有31%的人支持继续进行太空探索。

这么低的民意支持率, 别说拍板去火星的路径了, 就连太空探索这个领域, 都别指望了。

我们都知道, 大众的兴奋度和注意力, 从来都是一阵一阵的, 比如去年新冠初期, 美国人为争夺氧气, 在超市下一单上, 要人把药送到家门口, 如今, 新冠之下, 美国人民也失去了对航天事业的斗志。毕竟, 相比之下, 眼前看似可见, 摸得着的内部问题, 太空问题显得太遥远, 太缥缈了。
