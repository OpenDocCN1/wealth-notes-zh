# 037报告 | 中美科技巨头如何竞争海外市场?

今日报告：中美科技巨头如何竞争海外市场？

> 为了赢得剩下的几十亿互联网新用户，中美之间的科技巨头都不得不进入海外市场。——《经济学人》

尽管普通人意识不到，但中美科技巨头的海外市场竞争战已经开始打，并且展现出了一场大场的战略逻辑。《经济学人》认为，这场战争的格局和格局，跟本届世界杯很相似。

今天的议题分为三个部分：

+   - 为什么说这场海外市场竞争是必然的？
- 中美科技巨头的海外战略有何不同？
- 双方的优勢和劣势分别是什么？

上周的内容里，你们讲了《财富》杂志关于腾讯和阿里的报道。《财富》杂志的观点是，中国科技巨头们很明白，已经向全球蔓延了，中国科技巨头的竞争可能会是全球最大的。

对于全球市场来说，未来是中国，公司已经有全球目光，但关于中国科技公司已经具备了全球影响力这一点，所有大人都没有异议。但中国的科技巨头一旦出海，必然会遇到早已开始抢占全球市场的硅谷科技巨头们，就好像像看《海贼王》里，主人公大和鲁进了一代大航海，必要跟强大的对手进行一战。

最新一期《经济学人》杂志的封面文章《泰坦之战》(Clash of The Titans), 就专门讨论了这个话题。《经济学人》认为，中国科技巨头的海外市场竞争已经开始了，只是普通人还没意识到。

文章还分析了以中国以BAT为首的科技巨头，和美国以FAANG为首的科技巨头之间的较量，当各自为新的市场和优势赛道。文说："为了赢得剩下的几十亿互联网新户"，中美科技巨头，都会不惜成本地投入。

```
Winning the next billion users is seen as an investment worth making at almost any cost.
```

咱们之前讲到，美国五大科技巨头的的首字母组合FANG，被叫“Fang“一海牙"的意思，中国以BAT编写，英文则是“蝙蝠”的意思，这可真的是一场中美巨头在海外市场上飞的走兽、各司各招的精彩较量啊。
