# # 044报告 | 西方如何看待基辛格谈人工智能？

从各个角度来说，无论是哲学思辨还是智商水平，我们人类远远还没有为人工智能时代的到来做好准备。

——基辛格

# 徐颖

当其国家都在致力于追求人工智能的新发展时，以基辛格为代表的一部分美国精英阶层，已经开始为人工智能带来的忧患而担忧。

今天的阅读分为三个部分：

+   - 基辛格的“人工智能威胁论”引起了什么样的关注？
- 西方知识界对他的观点持什么样的态度？
- 西方精英群体将会如何影响人工智能行业？

美国前国务卿基辛格最近在《大西洋月刊》上发表了一篇文，表达了对人工智能的担忧和悲观态度。

他认为：“从各个角度来论，无论是哲学思辨还是智商水平，我们人类远远还没有为人工智能时代的到来做好准备。

> Philosophically, intellectually - in every way- human society is unprepared for the rise of artificial intelligence.

其实呢，“人工智能威胁论”早已不是新鲜事。史蒂芬.霍金、埃隆.马斯克都曾经公开表达过对人工智能的警惕。不过，今天已经95岁高龄的基辛格，竟然能预测出这样的文章，来表达他对人工智能未来科技的关注，这件事还是在西方世界引起了不小的波澜。

要知道，基辛格完整经历过第二次世界大战、美冷战争和后来的全球化时代，他不仅在世界政治和外交史上留下不亚重色彩的一笔，也是一名历史学家。基辛格在《大西洋月刊》上发表的文章，几乎都排在关注度上进前十名，所以他的观点还是值得们关注的。

今天我们就来看看，基辛格的“人工智能威胁论”和它所产生的影响。

# | 基辛格的“人工智能威胁论”引起了什么样的关注？

其实，基辛格的“人工智能”威胁论，对咱们得到的并不多。听起来，可能是些“老生常谈”的话。然而，人类一旦对人工智能的到来，终结了自十五世纪印刷机发明以来，让科学界、美学界、理性分析为主的认知方式，让人类失去了思考的权利；有人把地球秩序打破，人类被机器控制，处于“失控”的边缘，整个世界只靠数据流和算法，不再受人类道德伦理和哲学规范的约束。

基辛格还认为，人工智能有可能误解人类的指令，导致偏离原本的目标，甚至有可能通过杀死或改变人类的思考和价值观。他还担心，一旦智能即能理解我们的意图和决心，却无法给出理性的解释，那我们是否会有一天拒绝服从人类，而且也不向人类做出解释呢？

总之，基辛格就是要提醒人类，尤其是政府，必须要控制AI的发展。

尽管基辛格的观点并不新鲜，但他这篇文章还是在这个世界引起了关注，比如《大西洋月刊》有个动态文章排行榜，叫most popular，这个排行榜会按照文章的量级、内容质量、受关注度等各个维度的文章进行排名。基辛格这篇文章在most popular排行榜上停留了很长的时间。

同时，西方的媒体、学术界也在广泛讨论基辛格观点。比如《国家评论》（National Review）《华盛顿日报》，还有一大堆大学教授等等，当然，有支持也有反对。

# | 西方知识界对他的观点持什么样的态度？

那么，西方世界怎么看待基辛格的“人工智能威胁论”呢？总的来说，立场分为旗帜鲜明的两派。

国外有个网站叫Gabstabstract，这是一个极具后现代风格的网站。网站的核心是“帮人类省时间”，通过十分左右的阅读时间，帮你介绍值得的书和重要作品，有国外学术界公认的“每天半小时”之意。基辛格的这篇文章，就被Gabcabstract推荐的，编辑推荐的理由是把“基辛格利用他的思维和外交经验，来提醒人类即将面临的新威胁，他的担忧值得我们注意”。

这家网站除了编辑推荐和介绍外，还会给网站上的内容质量进行评估，满分10分，基辛格的这篇文章得了7分，而“重要程度”这一项，也得了8分。

再比如说，《国家评论》也发表了评论文章，表达了对基辛格观点的支持。《国家评论》认为，基辛格细腻地描述了人类现在所面临的困难，基辛格的思考也很有前瞻性，他提出的对人类智能的担忧，我们都该担忧。还有《华尔街日报》，也对基辛格这篇文章做了推荐。
