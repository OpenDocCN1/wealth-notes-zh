来。

![](bbox=[0.0, 0.065, 0.9, 0.18])

一般传统的汽车厂商，推出一款新车的时间是5年，而特斯拉只有两年半。倒推回去，留给设计的时间更短，逼得特斯拉的设计总监弗朗茨·霍兹豪森连圣诞节都在工作，这相当于中国人过年都不回家，坚守岗位，这在西方是很少见的情况。

而到了生产环节，马斯克本想用全自动化的方式来生产 Model 3，号称要做到“机器制造机器”，尽量减少人力参与，他还给自己的高科技工厂起了个很炫酷的名字，叫“外星无限殿”，听着是不是非常帅气？

但是理想很丰满，现实却比维金的模特还骨感。开始运作之后，自动化系统和机器人不断出现各种各样的问题，一个环节出问题，所有环节都要停下来等待，这是 Model 3 生产初期产能始终上不来的根本原因。丰田造一辆车大约需要30个小时，特斯拉要花三倍还不止，最后逼得马斯克只好放弃自动化生产方式，大量用人工顶上去，这也是工人累成了僵尸的原因。

由于生产环节太过仓促，导致特斯拉出现了各种安全问题，工人的工作环境非常糟糕，马斯克和特斯拉饱受外界批评。马斯克挤进工厂办公室，一方面是为了解决生产问题，另一方面也是为了鼓舞全员的士气。

他说，在通用汽车，高管是有自己专用的电梯的，但他的办公室却是全公司最小的，而且几乎都不坐在办公室里，始终与员工们在一起，“哪怕我只要走到街对面，就能舒服地睡在酒店的床上，但我也要睡在办公室的地板上，我想让他们知道，他们经历的痛苦，我经历的只会更多”。

面对外界的质疑和传统汽车厂商的嘲笑，马斯克对《彭博商业周刊》说，“他们对特斯拉说，你们这么干不行。这不是一次两次了，他们什么时候看好过特斯拉吗？过去的15年里，一次都没有，但特斯拉依然走到了现在。如今我们度过了最艰难的时期，特斯拉是一家真正的汽车公司了”。

# | 总结

总结一下今天的内容，Model 3 的生产，是特斯拉和马斯克的第三次 all-in 时刻。设计和生产的周期太短，要求却极高，这是特斯拉经历“产能地狱”的根本原因，就像今天的金句说的，生产一款大众消费领域的电动车，某种程度上比造火箭难得多。但马斯克和特斯拉总算是挺过来了。
