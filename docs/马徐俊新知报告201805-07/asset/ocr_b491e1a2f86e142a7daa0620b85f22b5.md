# | 承受压力是领导者的常态

领导者有发布命令、做决断的权力，但 同时也面临着巨大的压力。

如果一个总统想，因为他的领导，有多少 孩子失去了父母，有多少孩子失去了母 亲，他可能都没有勇气担任三军总司令了。

当年朝鲜战争结束时，杜鲁门总统收到 了一封来自朝鲜战场士兵的信。信很短， “因为，我失去了妻子，”杜鲁门总 统说，“我的信，挂在我的办公室里， 那是我的妻子，我的女儿，死了，躺在 朝鲜的战场上。”杜鲁门总统 一直把这封信留在这个抽屉里，作为 自己这生涯的纪念碑。

2007年，当小布什总统，不得不派遣更 多的部队去伊拉克执行任务时，但是公 众和媒体都把矛头指向他，但想到他 可能失去了妻子，可能失去的孩子，他 可能都没有勇气担任三军总司令了。

总统的专注力是高度不自私的，为所有 人所关注的，他的一举一动都受到了 所有人的注视，一个表情都会被反复解 读。

奥巴马曾经提过一个小故事，他说他 梦到自己和一位朋友一起，他正走在 路上，朋友正在跟他聊天，然后他朋友 突然停下了脚步，奥巴马没有察觉，结 果脚踢到了一根树桩，然后他就醒来 了，发现自己其实是在白宫的地板上。

在特朗普上任100天的时候，他曾经接受 过媒体的采访，他表示，自己低估了总统 职位的困难程度。

其实每个总统都，林登·约翰逊也说过， 当上总统，就像是一个小孩子， 在圣诞节的时候，圣诞礼物全都没有，他 发现，自己的位置，是一个非常困难的 位置，是一个需要承担巨大压力的位置， 是一个需要面对巨大挑战的位置。

美国总统只能是这个世界上面对最多压力的 工作，总统既是政党的领袖，也是一个 国家的政治领袖，一个外交家的角色， 一个军队的统帅，一个国家的元首， 一个国家的最高行政长官，一个国家的 最高立法者，一个国家的最高司法官， 一个国家的最高决策者，一个国家的最高 领导者，一个国家的最高指挥官。

在他办公的地方，墙上挂满了前任们的照 片，还有一些荣誉勋章，这些东西，是 一种无形的压力。

但是，是一个领导者要面对的常态，抗压 是领导学非常重要的一个课题。

# | 关注长期是领导者的责任

曾经美国人们的理念是，领导者不应当 迎合民意，关注短期，而要坚持长期的 国家利益。这样的理念运行了一个 多世纪，保证了美国的崛起。

但是进入20世纪以后，出现了新的政治 理念，主张总统应该与民意保持一致， 这样才能更好地代表选民。

加上大众媒体的出现，给了总统候选人 更多的机会，通过电视广播等 媒体向选民展示自己的观点和政 策，以争取选民的支持。

当政治变成宣传的时候，只有政客而没 有政治家。

政治家和政客的区别在于，政治家会高 远谋划，关注长期，而政客只会讨好 选民，追求短期利益。

约翰·迪克森说，在今天的美国，竞选能 力和执政能力被混为一谈了。竞选需要 的是说服力，执政需要的是执行力。

总统候选人关注的只有选民，但总统处 理的是选民、国会、利益集团、外国领导 人之间的关系。

为了迎合选民，刚上任的时候，总统会 签署大量的行政命令，来满足选民或者 竞选时许诺，但是在任期过半后，这 些承诺往往难以兑现。

所以总统很难专注于一项任务，而 且应对美国国内的长期问题，比如医保、 气候变化、枪支管控等问题，都面临 着巨大的政治压力。

他们只能通过对选民作出一些短期承诺， 来维持自己的执政地位。

我们都知道，在普通人的日常生活里，为了 工作而工作，没有意义和乐趣，总 统也不例外。

文章里提了几个例子，美国总统 总是被媒体追问，是否喜欢自己的工作， 他们总是以同样的方式回答：喜欢，但 不是所有的部分。

从这个角度来说，现在的美国总统其实都是 缺乏领导力的，因为他们只看短期， 不看长期。

# | 学会管理是领导者的必修课

文章里花了很大的篇幅，提了不少如何修 炼管理思维的建议，我把其中跟管理 相关的三条跟你们分享一下：

+   1. Actions speak louder than words—— 行为胜于语言

作为领导者，能够激励你的，是鼓励你的 团队，而不是你自己。

但是问题是，领导者往往很难 激励下属，因为他们总是希望下属能 够超越自己。

+   2. If you want to move fast, you first need to move slow——想走得快，你 得停下来

一个习惯靠权力的人，都会对自己 自信，认为自己做得到，但问题是， 领导者往往很难做到，因为他太 相信自己的判断。
