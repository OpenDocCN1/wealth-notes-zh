# 现代国际物流的运作方式和问题

你有没有发现一个现象，现在在国内发个快递要么便宜，京东自营、天猫超市都能做到次日甚至当日送达，顺丰这些快递公司的效率也是一直在提升。

但是一发国际快递，尤其是空运，就特别贵！贵到什么程度呢？

比如说，从上海到伦敦，一个70公斤的包裹运途的价格，要比同一件的海运贵4倍。而走海运又太缓慢，你要去海关，就会知道，比国内物流体验差很多。

问题到底出在哪里呢？我先带你看看看国际物流是怎么回事。

通常，想要运送货物的话，有两种选择，一种是国际快递公司，比如像国用DHL、FedEx和UPS这样的快公司，的确是快，但是非常贵。所以，绝大部分的国际物流，用的都是集装箱海运轮渡，也就是航运。

航运，其实是现代物流的核心。据美国著名咨询公司BCG的统计，虽然承运大量的货物是大约2.3万亿美元，但航运只占其中的1%；航运占国际物流的大约70%左右，就是航空。

首先，在国际航运中，有很多的规程和法定程序要走，比如报关、保险以及海洋、公路、铁路之间的转运等等，这些程序一般会交给专业的货运代理来处理。

其次，国际运输的合同都比较复杂，贸易方式也比较多。

繁琐流程和复杂交易的结果就是，产生了各种各样的单据，至少有半的航运操作中要求提供纸质单证，比如：纸质的提货单些什么的，繁琐到外行人根本搞不清楚这些凭据是怎么回事。想要从事这个行业，得花大量的时间学习，对业内人士来说，也是苦不堪言。

有调查显示，42%的从业人员告，为了准备这些文件，他们至少要花上2个多小时的时间。而且一般纸质文件不是跟着货走的，而是通过其他渠道的发货，所以常常是货到了，通过文件还迟迟的，货物只能滞留在港口，不能进入下一个运输环节，根据调查显示，有1/4的文件都是迟到的。

根据联合国的一项测算，如果将所有亚太供应链相关的文件电子化全都数字化后，可以节省44%的时间和31%的成本，同时可以增加一年2570亿美元的出口。所以，很明显，国际航运业里面的这种传统操作方式大大拖累了效率。

你可能也感应到了，既然可以节省将近一半的时间，和1/3的成本，这么大的效率提升，干嘛不改嘛？

问题没那么简单。航运改革之所以难，有三方面原因：一是航运巨头的傲慢；二是货运代理人的利益；三是政府的原因。

首先，航运其实是相对于垄断的行业，巨头就那么几家，像个DLI这样的行业巨头，觉得市场足够大了，没必要担心新技术对行业的威胁。

而像集装箱运输巨头，马士基，过去的精力还在想着建造巨型集装箱运输船上，现在才开始对开始巨大的收益有运输业。

其次，货运代理人的收入一般占到整个国际运输业收入的20%以上，有时甚至占到45%。一旦程序简化了，他们就可以失去了存在价值的理由，所以他们不想革自己的命。

第三点就让人更无奈了，2008年，联合国会议上就通过了国际航运组织应该承认电子签名的合法性，但是有个规定要求，必须得到20个国家的批准，但由于这项改革对政治来说太敏感了，直到现年，只有4个国家批准了这项提议。

好，我们知道了现代物流的核心是航运，但是航运效率低，要改革又困难重重，那么到底怎么能做什么改变呢？

# Thinking outside the box：数字化对物流行业的改造

这是《经济学人》杂志这一期核心文章的标题，翻译过来叫“创造性思维”，是个英语俗话，在这个文章场景里，表达了另一层含义，就是拿出一份快递的盒子和集装箱，container的形式，来思考改革办法。

现在对于传统物流行业的变革动力，不来自于行业本身，而是来自于互联网和数字化。比如互联网巨头，像电子商务公司，亚马逊和阿里巴巴，都在进入这个领域，有点跨界野驴的意思。

2017年，亚马逊在物流上投入了250亿美元，成立了自己的物流部门和货运代理公司，并且已经获得了海关的资格代理，现在亚马逊还成立了自己的货运代理，现在已经拥有了33架飞机。虽然FedEx还很强，但亚马逊投资15亿美金建造的全球亚马逊运货中心，未来可以容纳100架飞机。

根据BCG咨询师的推测，亚马逊公司会用平台优势，整合各个环节的数据，实现对整个物流体系的管控和控制。

现在，马士基已经意识到了亚马逊的竞争威胁，正在开发“马士基线上操作系统”，目的是实现电子数据替代纸质操作的流程。

阿里巴巴在中国拥有超过5亿的客户，去年的交易额达到了5500亿美金。

中国的电子商务产生的所有包裹中，有70%是通过阿里巴巴的菜鸟包裹来运输的。现在，阿里巴巴已经自己的目光投向了国际电子商务，并且在去年9月向菜鸟裹裹增加了150亿美元的投入，用于提高跨境运输的能力。

根据权威机构的预测，到2020年，基于跨境电交易的运输额，会从2016年的4000亿美元上升到1万亿美元。以前，大家都认为国际会是数百万亿美元的商品，而现在阿里巴巴已经在运输大量的低价商品，比如把美国的尿布和奶粉送到中国。

那些电商业巨头究竟会为这个行业带来什么改变呢？

《经济学人》指出，有了电子商务巨头的参与，未来国际航运的运作模式会发生根本性的改变。

通过计算机和大数据，可以实现对整个运输链条的跟踪、分析和资源调配。比如，如果船晚点了，等候的车就不需要等到被排解再跟着别的继续等着，而是可以前解去跟别的运输链线。这就是相当于航运业仿效Uber和空乘的“约打车新模式”，把空载的船舶和航空运输调度起来，实现资源的最优化使用。

阿里巴巴和亚马逊，还在尝试虚拟货币技术的方式来自配仓储，不仅可以大大降低运输的速度，而且运输工，比如集装箱船和卡车，本身又可以充当仓库的角色。应该说，这些都是非常好的互联技术，应用到传统行业里，会引发效率革命的方式。
