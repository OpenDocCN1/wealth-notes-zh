# 011报告丨反击黑客能否合法化？

马徐俊

在现实生活中，我们被攻击或抢劫，警察是会提供援助。然而，在网络世界里，很难有人能够保护我们的安全。面对黑客的攻击，我们是否有权反击？

今天的议题分为三个部分：

+   - 人们在今天如何应对黑客入侵？
- 现行网络安全法律存在哪些争议？
- 黑客反击行为会带来哪些严重后果？

《纽约客》杂志最近刊登了一篇名为《数字自卫队》，Digital Vigilantes的文章，讨论了我们是否应该合法地点反击黑客”。这个问题，我先把这篇文章的观点告诉你。

“如果让黑客反击的做法合法化，对网络犯罪中的个体受害者可能会有所帮助，但不可能形成一个更为安全的网络环境。”

```
Should hacking back become legal, it may well help individual victims of cybercrime, but it is unlikely to make the internet a safer place.
```

# 丨当下的人们如何应对黑客入侵？

根据权威机构的估算，有90%的美国公司都遭遇过机构的攻击。从被攻击的公司最大的证验机构Equifax 获取了半数美国人的信用信息，从Uber 窃取了 5700 万用户的账户信息，从Liber 窃取了5700万用户的数据信息。

这些数据是不是很耸人听闻？

话说回来，“黑客”这个词最早并不是贬义词，它指的是擅长IT技术的人、计算机科学家，与今天的黑客，指非法侵入别人的电脑，窃取信息，盗取权限或者实施破坏的一群人。

在现实世界中，如果有小偷偷你家的门锁，偷走重要的东西后会销毁一些。但若是黑客闯入你的家，把东西偷掉，然后还删长而去， 你最想做的肯定是报警，让警察把这些罪犯绳之以法。

但当你发现现实世界里的黑客入侵，报警有什么用？现在你清楚地是黑客基本只是走个形式，因为目前警察还没那么高的水平，也没那么多精力去帮你查黑客。
