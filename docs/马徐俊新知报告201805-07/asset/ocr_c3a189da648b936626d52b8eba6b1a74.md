# 今日报告：如何有效地传达自己的观点？

> 如果你想向某人讲真话，先让周围的人笑笑，否则的话可能你死定了。
—— 乔治·萧伯纳

马徐骏

在职场上和生活中，我们如何避免禁区，有效地传达自己的观点？美国医学专家保罗·奥菲特通过自己在大众传媒做科普的经历，为你带来三条行之有效的“锦囊”。

+   - 挑选有利于自己的场合
- 用幽默的方式传达观点
- 事实是最好的保护网

最近在《鹳鹏鸟》杂志上，我看到一篇访谈，说的是一位英国著名的儿科医生、流行病学家和预防医学教授保罗·奥菲特，如何通过在大型传媒、电视访谈和脱口秀节目做科普的故事。

奥菲特在美国是非常知名的医学专家，获得过美国总统颁发的杰出贡献奖。迄今为止，他已经在各类学术期刊上发表了160多篇论文。

但她始终认为，学术做得再好，也只是在医学圈子里传播，对医学专家来说，更重要的是提升大众的医学认知水平，所以他要写书，开设了六本科普书，从1993年开始，就经常出现在美国的各种电视节目上科普医学知识。

你可能觉得奇怪，我知道这个有什么用？但是我看完了这篇访谈的感受是，科普真的是一件很难堪，也很容易玩坏的事儿，尤其是出现在电视上的大众媒体上，说服普通人来信任和相信严谨的科学观点和数据知识，对于一个人的表达素养要求极高。日积月累，保罗·奥菲特先生总结出几条关于如何有效传达自己观点的经验之谈，很值得一听。

# │ 挑选有利于自己的场合

先来说第一条经验：Don’t go on a show where the host isn’t on your side.

不要去一个主持人明显不站在你这边的节目。换句话说，不要在一个充满敌意的环境中，试图洗化受众。

其实就难地说，第一条经验是个惨痛的教训。2007年，奥菲特受邀参与一个非常著名的节目《奥普拉脱口秀》，参与讨论注射天花疫苗，也就是我们俗称的“牛痘”，这是会导致孩子患上百斑疹的问题。本来奥菲特先生觉得，这是一个特别好的科普机会，能纠正大众对于接种疫苗的一些错误认知，他毫不犹豫地答应下来了，不料结果却是车祸现场。

先给你介绍一下背景，在中国，小朋友接种天花疫苗是习以为常的，但在英国和美洲，天花疫苗普及的第一天起，争论就没停止过，直到今天，还有很多人拒绝接种。

拒绝的理由主要是三个，首先是宗教原因，很多天主教权士认为，把牛身上的病毒打进人体，是一件非常邪异的事，发文叫unchristian，这是不可以的。其次是很多人对于现代医学依然抱有怀疑态度，他们压根就不相信疫苗能够防治传染病。

最后一个就是自由问题，不少人认为政府强制要求接种天花疫苗，是对个人私利的侵犯，为此，在美国甚至有专门反疫苗接种的民间组织存在。

过去的200年里，英国和美国围绕着应该该接种天花疫苗的主张，爆发了过无数争论，打过官司，甚至一直打到了美国的联邦最高法院。

1998年，英国一个叫爱德华·维克菲尔德的医生，宣称预防麻疹、腮腺炎和风疹的MMR疫苗，会导致许多肠道疾病和自闭证。这件事被媒体大肆报道之后，在美欧可就是炸锅了，虽然后来这位维克菲尔德医生被查出，是狡好求才论说的，并且被吊销了行医执照，但是他制造的那些怀疑，至今仍然被很多英美普通老百姓接受和传播着。

你看，不在哪里，各种谣言总是比真相传播得快，辟谣总是比造谣要困难，有句话怎么说来着，真理刚穿上衣服，谎言已经地球一圈了。
