通用户参与进来。另外虚拟货币现在也很集中，在某些项目中，90%的虚拟货币掌握在2%的用户手里。

最后就是大部分人还没搞清楚，区块链到底是啥？获得虚拟货币，也被当作一种发财的投机行为，这对推广真正的区块链技术，迈向Web3.0，都是不利的。

不过《经济学人》的报告里也说了，虽然要实现Web3.0，看起来像是跟解开戈尔迪之结一样难，但Web 2.0这个概念的提出者提姆·奥莱利说，也许某天突然出现一个技术突破，就像亚历山大大帝的宝剑一样，一下子就劈开了区块链技术的戈尔迪之结，也说不定。

报告最后说，有一点是肯定的——互联网越是控制在少数科技巨头的手中，越不可能是个自由的地方，所以Web 3.0是大势所趋。

# | 总结

好，总结一下今天的内容，想要让互联网从大局控制在大公司手里的高塔状态，回到用户自己拥有数据、更加自由的广场状态，就是从 Web 2.0向 Web 3.0演化的过程。Web 3.0的最终实现，需要依赖区块链这样的技术，而只有解决区块链技术的延展性问题、彻底实现去中心化，以及区块链的投机泡沫破裂，这一天才有可能真正到来。

就像报告里说的，想要阻止互联网变得太过中心化，是很难的，但如果不这么做，后果会更严重。

Stopping the internet from getting too concentrated will be a slog, but the alternative would be worse.
