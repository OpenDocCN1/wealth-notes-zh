# 很多东西都能换成钱！你竟然不知道？

一切都能互相转换

拿钱来说

赚了钱，用来干嘛，买吃的，买穿的，买用的，买房子，买车子等等

+   - 也就是钱可以换资源
- 钱等于资源，资源等于钱
- 资源也可以换资源

+   - 比如做资源整合的，就是用资源换资源
- 你有产品资源，我有客户资源，一整合，就变成钱

+   - 或者客户资源互换
- 你有 100 个客户名单，我有 100 个客户名单
- 交换一下，彼此创造更大的价值

+   - 钱等于流量，流量等于钱
- 钱也可以换钱

+   - 100 元，可以买 100 个客户数据，印刷几百份宣传单，租用临时摊位，雇你兼职地推，加100 个群等等

然后赚回更多的钱，就可以不断放大
