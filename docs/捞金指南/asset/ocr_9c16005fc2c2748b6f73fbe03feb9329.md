# 人都有耐心

打球，羽毛球，乒乓球
刚开始，你用拍子去发球，可能经常扑空
但是你很有耐心
一次次的去练习

别人球发过来，你可能接不住
但是依然会继续打
你不会说：‘死我了，再也不玩了’

打篮球，你投篮没进
会继续投
你不会说：我再也不投篮了，反正很难进

你学游泳
刚开始经常呛水
你不会说：怎么老是呛水，再也不游了

你学做菜
菜炒焦了，盐放太多了
你不会说：再也不做菜了

你打麻将
赢了很开心
输了会继续

你学习骑单车
摔了一跤
会继续练

你看，人做这些事情时，都不怕失败，遇到困难解决困难
很有耐心，而且乐在其中。

因为你把他当成了乐趣

那为什么赚钱，做项目
很多人却没有耐心呢？

遇到项目一点点困难，就放弃了

比如找客户，那所有项目都需要去吸引客户啊
你换个项目，就不需要新客户了？
