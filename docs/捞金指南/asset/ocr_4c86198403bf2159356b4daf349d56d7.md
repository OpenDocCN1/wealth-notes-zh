# 40 越能习：如何凭空创造价值，获得钱和资源？

有很多方法，可以给对方好处，但是自己并没有额外的付出

创造价值是很神奇的

举例，租房

你自己租房，有个人也租房。
你们分别都要拿出房租
但通常情况，一个人住和两个人住，房租是一样的

你让对方搬过来合租，相当于他原来该付的钱，就不用付了，但是你并没有额外付出。却给了对方好处
