# ## 2 為何要整合
## 時間地圖？

# ### 製作兩個欄位

「時間地圖」的基本形式就是整合約定和工作事項，接下來說明為何需要整合的理由。

就某種意味來說，約定和工作都是利用自己的時間進行。因此約定較多的日子，最好別安排工作，相反地，工作繁重的時候，也不適宜安排約定。然而分開計畫的結果，往往無法確定工作量和就算勉強訂立計畫也容易漏失。

「審視」計畫是為了避免這般情況發生，整合約定和工作則是為了讓這道程序變得更簡單。

約定往往取決於時間，所以要寫在有標示時間的欄位，而且必須和工作分開寫（依日期書寫）。這麼一來，無法更改時間的約定就不會和可以自由選擇時間的工作混為一談。

計畫不是訂一次就能搞定，也有可能追加或變更，必須視情況而變更改實行的時間。總之，在約定時間不變的原則下，可以調整工作。
