# 給不懂長「料理型」步驟法的人的建議

書寫報告時，不妨邊筆記工作內容，邊書寫報告。<br>只要列出作業清單，下一次便能活用「購物型」步驟<br>法。（但若是提交不同種類的報告，一定要先確認有無必須追加之於<br>清單上的東西）
