# 將寫下來的步驟  排進自己的工作排程

# 實行「購物型」步驟法的第二階段

前頁的「步驟清單」也適用於計畫管理（稱為「WBS（Work Breakdown Structure）」）。牽涉範圍較廣的計畫管理會用到「步驟清單」和前面介紹的「倒推步驟圖」，但管理自我工作時，選擇其中一種方法即可*。

但也必須符合前述的「活用步驟化三要件」的第二和第三要件。接下來介紹「購物型」步驟法的第二階段。

首先依清單的項目，決定實行順序，再將每個項目排進自己的工作排程（Part 2的「時間地圖」）。千萬別排得太緊，否則無法實行就一點意義也沒有了（請活用「填字遊戲原則」）。

像這樣將工作與約定排進自己的工作排程，確定日期沒問題後，便完成了步驟化**，按部就班地處理工作。若中途追加工作，也要配合排程進行。

> * 若屬於個人工作，要將步驟化的結果排進「時間地圖」，進行管理，因此選擇一種方法即可。（參照88頁）

> ** 若發現問題，務必重新審視日期和內容，考慮請別人協助。
