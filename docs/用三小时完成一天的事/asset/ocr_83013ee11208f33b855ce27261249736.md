# 確認「完成期限」，決定「何時」開始進行

如下圖，依日期寫下工作內容，但不用標示工作完成期限，只要考慮何時開始進行（何時可以動工），決定實行日即可。

![](bbox=[0.88, 0.21, 0.95, 0.27])

重要的是，不只確定「完成期限」，也要決定「何時開始進行」，才能養成有計畫的行動力。

# 一旦決定好，立即寫下來

| 週一 | 週二 | 週三 | 週四 | 週五 |
| :--- | :--- | :--- | :--- | :--- |
| ☐ 完成 A 資料 | ☐ 收集關於 B 報告的資料<br>☐ 完成 C 資料 | ☐ 完成 B 報告<br>☐ 決定 D 企劃的資料內容<br>☐ 和○○先生洽商 E 事 | ☐ 取得課長對 B 報告的認可<br>☐ 完成 D 企劃的資料 | |

最好標上確認是否完成的小方格☐，以便確認*。

此外，對於必須跨好幾天才能完成的工作，最好先將工作「分解」，確認每天需要完成多少的工作量。Part 3 開始會說明如何將工作分解。

* 除了標註確認用的小方格，另一個方法是完成後畫線刪除。
