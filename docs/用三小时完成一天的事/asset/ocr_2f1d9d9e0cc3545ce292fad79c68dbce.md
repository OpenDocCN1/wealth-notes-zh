# 活用步驟化的要件②：

# 擬定工作和約定的先後順序

要是等麵煮好了才調理醬汁就太晚了。最好趁麵條冷卻時，烹調醬汁。

將工作步驟化的道理也一樣，按部就班地進行才能順利完成一件事。因此思考步驟時，不能只想著：「要做些什麼」，也要思索：「進行的順序」，才能順利地實行，因此思考「順序」也是步驟化的要訣。

# 活用步驟化的要件③：

# 配合完成期限，訂立全盤計畫

必須花點時間燒鍋開水、煮麵條，才能完成一道美味的義大利麵。要是沒有抓準燒開水的時機，便來不及如期完成。同樣地，一定要配合「完成期限」訂立計畫，否則無法如期完成。

若想達到如期完成的目標，最好事先思考「每項工作和約定要從何時開始進行」，這也是步驟化的要訣。
