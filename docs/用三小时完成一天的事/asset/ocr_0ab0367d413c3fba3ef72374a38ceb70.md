# 4 影響拖拖拉拉毛病
的思考方式

預防萌生拖拖拉拉的念頭

「時間地圖」能有效改善拖拖拉拉的毛病，若能更瞭解前述所說的兩個念頭，不但效果加倍，還能廣泛運用於各方面。

如同前述，「想做」和「不想做」這兩個念頭與未來和現在有關。意即為了得到未來的結果而萌生「想做」的念頭，以及重視現在的心情，因而萌生「不想做」的念頭。

這兩種念頭又分別細分為兩種（合計四種）。

「未來志向」＝想做：想行動的念頭

+   - 「要是（何時）不做的話就糟了」的念頭
  - （必須遵守完成期限）

+   - 「要是（何時）做的話就會很開心」的念頭
  - （想達成目標，想早點解脫）

「當下志向」＝不想做：現在只想落個輕鬆的念頭

+   - 「（現在）不想做」的念頭
  - （避開麻煩、討厭的事）

+   - 「（現在）想做別的事」的念頭
  - （想做別的事，讓自己更輕鬆）
