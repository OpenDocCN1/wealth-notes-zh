每一个特定人群，愿意付费的特定需求，都是细分赛道。

举第一个例子，【古琴】。

古琴这个小众乐器，可能大家只在历史剧中见过，相比吉他、钢琴这些家喻户晓的乐器，它足够细分和小众了吧。

但你觉得一个专门卖古琴的 IP，能有多少粉丝？每年的营业额能做到多大呢？

有个叫【古琴 x 记】的公众号，面向的粉丝就是精准的古琴爱好者。

他每天早上 5 点钟公众号准时发文，一篇头条文章带着七八条次条。
