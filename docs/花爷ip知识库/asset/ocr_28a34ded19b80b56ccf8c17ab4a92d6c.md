这些 IP 全部都是被迫转行的，但是都取得了不错的成绩，非常有意思。

就是你真的要去听一听，用户在想什么，顺应市场的需求。

如果你说自己干这一行的，就只守着这些做。

我是卖板栗的，我为什么要卖开口器呢？我就只卖板栗。

我是做竹筐的，我为什么要去做猫窝呢？我就要卖竹筐。

如果是这样闭门造车地做生意，就是死路一条了。

顺应市场，听用户的话，感受到用户的需求，你的生意才能够长远地走下去。
