但是笔记本怎么放？字多大？什么字体？多少个字？

这些细节加一起，看上去一样，效果差远了。

其实月入 30000 的自媒体，秉持的策略非常简单：

第一，找到一个好模板，一比一复制 5-10 篇，看是否有效。

第二，如果有效，照着模板一直憋，憋到这个模板失效为止。

信不信，就这么简单……

看几个正面案例吧。

同样是做好物分享，我们经常用“平铺法”。
