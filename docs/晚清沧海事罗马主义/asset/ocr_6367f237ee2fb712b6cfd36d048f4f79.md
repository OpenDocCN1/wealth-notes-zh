# 14：群魔乱舞（七）和阗大屠杀，到底是怎么发生的？

在新疆最危险的人，永远都是宗教人士，特别是去麦加朝觐回来的宗教人士。

说实话，我非常佩服伊斯兰教的这个设计，因为如果朝觐变成了一个人的人生目的，那么这个人的心，就会永远留在麦加，他就再也难以融入到其他文明之中，更不要说，向其他文明效忠了。

马福迪.哈比布拉就是这样一个人，他虽然出生在和阗，从事着宗教工作，但是他的一生，都想着去麦加朝觐，1864年，终于完成了这个夙愿的他，回到国内的第一件事，就是发动了和阗叛乱。

同所有的穆斯林叛乱一样，他们要做的第一件事请，就是杀光所有的异教徒。

不过哈比布拉走的更远，他不仅仅要杀光异教徒，甚至就连不同教派的人都要杀光，因此除了少量的清军和他们的家属以外，在和阗一带众多的汉族穆斯林，也都被他杀了一个精光。

因为哈比布拉去沙特阿拉伯转了一圈以后，他也学会了瓦哈比派，也就是本拉登的那个教派，同样也是今天海湾地区，大多数阿拉伯国家所信奉的那个教派，以及他们所暗中支持的，ISIS所奉行的治国理念。

所以哈比布拉自然也看不惯信奉苏菲派的汉族穆斯林，也就是从也门传入中国，今天在伊朗和也门的什叶派，共同信奉的那个教派，他认为他们也没有资格活着，所以必须杀光。

对于哈比布拉这种宗教极端分子来说，在这个世界上，需要他杀的人实在是太多了，所以他很忙，在和阗一带，勤勤悬悬的砍掉了上万个汉族穆斯林的头颅，因为在他的世界里，他们不需要的人，实在是太多了。

依靠着残忍和邪恶，哈比布拉成功的夺取了和阗的领导权，自称为哈比布拉汗，他在这里建立了一个小小的伊斯兰王国。

不过穆斯林极端分子，通常也都是欺软怕硬的，他们永远是把屠刀强加给他们更弱的人，把膝盖献给给他们更强的人，就像今天的海湾国家，不管他们信奉多么极端的教旨，一样必须跪舔美国，都是同一个道理。

所以当阿古柏成为新疆最强大的军事力量以后，哈比布拉也必须去跪舔阿古柏。
