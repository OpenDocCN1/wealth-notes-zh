# 16：伟大的西征（七）阿古柏之死

上一期写完了以后，有很多读者问了我一个问题，一下子就把我给难倒了，这是一个什么问题呢？

原来有些细心的读者问我，既然俄罗斯人停止了供粮，那么清军即使在原地据守，也应该缺粮，相反，如果清军的粮食，足够原地据守吃，那么为什么又不能够南下呢？

说实话，即使这些读者不问，这类问题我以前也注意到了，在新疆以往的多多次战役中，经常有将领汇报说，无粮进攻，可是他们驻守在原地位时，似乎又活得有滋有味，这又是怎么一回事呢？

以前我没有深思过这个问题，现在这些读者再次提出以后，我仔细一想，确实是一个怪事！

开始我想，是不是打仗的时候，军人会吃得更多，可是仔细一想，这个说法站不住脚呀，运动了是要多吃一点，可是又能吃多少呢？

按照我们的日常生活经验来看，也就是大概百分之二十？三十？这点增加的量，似乎影响也不是很大，那到底又是什么原因，造成的粮食不足呢？

左思右想之后，我也找不出答案，然后我赶紧去查资料，结果发现作战的时候，给士兵的配给并没有明显增加，也就是多发了一点盐菜钱，数量的增加也是微乎其微。

而且我还注意到一个事实，由于战争中，后勤供应经常跟不上，士兵被迫时常忍饥挨饿，消耗的粮食，有时甚至还不如原地驻守。

既然不是这个原因，我又想，会不会是因为向前进攻的时候，需要加大运输补给，因此增加了大量的人手，所以消耗比平时更多呢？

这个看起来似乎有点道理，可是我把古书中的数据，拿来仔细一推敲，发现还是站不住脚，因为即便是固守一个地方，在新疆也是需要长途运输的，所以粮食的支出，并不比平时的消耗多多少，那么到底是哪里需要额外的粮食支出呢？

为了回答这个问题，我不停的在古代寻找答案，把那些枯燥的数字——研究，可是还是找不到答案，这个问题一直让我百思不得其解。

没想到机缘巧合，本周巧遇一位玩马术的朋友，和他的一席闲聊，让这个困扰我许久的问题，一下子有了答案，原来是马要吃饭。

乍一听到这个答案，你可能会觉得，这岂不是典型的废话吗！

马当然吃饭了，不然它怎么活？但是问题是它们吃的是草呀，新疆有草的地方可不少，走到哪里，就让马吃到哪里就好，怎么又和粮食扯上了关系呢？
