# 哥萨克骑兵

现在，僧格林沁面对的这支英法联军中，有很多人都参加过克里米亚战争，他们面对眼前黑压压的蒙古骑兵，心中没有一丝的慌乱，反而是信心十足，因为他们在那场战争中，曾经面对过，在猛烈炮火掩护下的哥萨克骑兵冲锋，那个规模和强度，远远超过现在他们所面对的。

# 克里米亚战争
