# 春田兵工厂的博物馆

事情的起因是这样的，我最近在美国著名的春田兵工厂的博物馆里，发现了一挺诺顿菲尔德速射机关枪，枪身上写： “英吉利，诺顿菲尔德，敬赠李中堂”。旁边附说明：此枪在1900 年，八国联军侵略天津时缴获，此战役中共缴获清军这种机枪上百把。

# 被缴获的机枪和相关文献

当时我看到这里，脑袋嗡的一下就发鸣了起来。 “什么鬼！清军居然还有机枪！而且在一次战斗巾居然被人缴获了上百把！ 不是说好了他们只有大刀长矛吗？！ ”

在这件事的刺激下，我查阅了大量的资料，特别是西方的资料。结果我发现，关于晚清的历史，我们所知道的一切，或许，都不过是些流传已久的谎言罢了……
