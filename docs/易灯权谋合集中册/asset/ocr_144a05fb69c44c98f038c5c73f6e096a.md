+   3. 讨论并对目标取得共识

利用需要被完成的任务吸引员工。每个员工都需要明白你的思考方式、认同计划、并且清楚知道需要完成的工作，以及需要完成的时间。考虑采纳有建设性的批评，因为这可以改善你的计划，并得到其他人的认可。

+   4. 把资源和权力放在对的位置

提供必要的资源和权力。这样一来，你的员工就可以做决定并采取行动。每当需要的时候就给予你的员工支持，他们会需要知道你就在他们背后。

+   5. 监控进度

确保员工会负责履行对他们的期待。拥有整体的目标和定期的目标将会帮助员工保持专注、配合截止时间，并确保有达到标准和结果。目标是要让员工保持被激励及走在正轨上，以及在必要之处提供额外的支持。

+   6. 审核进度

从经验和回馈中学习。和参与其中的人比较并讨论结果和目标。检视运作良好的计划，以及可以再做得更好的部分。利用这个步骤来改进未来的计划。
