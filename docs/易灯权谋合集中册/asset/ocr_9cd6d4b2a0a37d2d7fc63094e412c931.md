就知道你的回答是故意想中断他的谈后。这样一来，他不得不少说几句或中断谈话，你也可以多说几句，他自己或许也能知道少讲停讲。这样一来，你也能腾出时间来干一些有益的事。

# “咄咄说教”者

“咄咄说教”者和上面的“喋喋不休”者有类似的地方，但还是有一定的区别。有些人喜欢对他人“谆谆教诲”。在他说的十句话中，你完全可以找出“你应该”、“你必须”、“你不能”之类的词语高达七八处。这种人往往自以为是，居高临下，盛气凌人，唯我独尊。在他们眼里，众人都是无知的幼儿，只有他是博学的先知圣人。和“喋喋不休”者不同，“嗦嗦说教”者虽然令人生厌，但对你并非全无益处。能咄咄说教者往往多少有一两刷子，你可以吸取其中有意的地方，学习提高。另外认认真真地倾听，会使他觉得心理满足，对增进情谊有好处。
