# 憧憬权术也会失败，原因有以下几点

李斯是历史上很令人迷惑的人物。

李斯的成功，有着如此夺目的光辉。但李斯在历史上最引人注目之处，却不是他的成功，而是他的失败。

李斯的失败，两千年之后，还令人浩叹。

他是当时最有名的政治哲学家荀子的高徒，也算是当代大师那里拿到了政治哲学博士学位，但最后却败于一个宦官之手。
