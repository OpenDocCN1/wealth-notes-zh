
# 脸皮与事业

然诸葛亮其人，乃是一个脸皮揭不尽之人物。他虽然气死周瑜，却又能换一张脸皮去东吴吊孝。只因脸皮换那恰到好处，于是灵堂内哭那真的一般。不仅感动了东吴将士，连小乔夫人也埋怨自家的丈夫人胸太窄。至于诸葛亮，只是用一场假惺惺的哭，不仅完成了孙、刘联盟，且自家的屎屁股也擦得一干二净。

还有刘备，也是脸皮多不胜数之人，他不仅能“三顾茅庐”，还能多次寄人篱下。虽也野心勃勃，但从不敢喜形于色。在同曹操“煮酒论英雄”时，他把想当皇帝的那张脸皮揭而藏之，惟恐曹操看出破绽。如图西川时，虽众人面前吃肉撒腥，但很快露出庐山真面目，硬是把同族兄弟刘璋拿下。至于五十多岁，又娶人家十七、八黄花闺女，也并非是一张脸皮所能办到的。

譬如袁绍，虽有雄兵百万，谋士如云，然因只有一张脸皮，故非但不能一统天下，反以强败弱。于是“官渡一战”，便刹时元气失尽，不仅没那“来年再战”的勇气，反悲愤之中与世长辞了。所以，干大事者，万不可只有一张脸皮。不然非但事业不成，且一旦失败，又势必气出绝症。想那干大事之人，原本走的就不是常人之路。如不能有几幅、乃至几十幅面孔，如何能在成千上万的面孔中应对自如？故多一张脸皮，就会多一群朋友……

## 做事不被领导理解如何化解

### 原文

江淹，字文通，济阳考城人也。少孤贫好学，沉静少交游。起家南徐州从事，转奉朝请。宋建平王景素好士，淹随景素在南兖州。广陵令郭彦文得罪，辞连淹，系州狱。淹狱中上书曰：

昔者贱臣叩心，飞霜击于燕地；庶女告天，振风袭于齐台。下官每读其书，未尝不废卷流涕。何者？士有一定之论，女有不易之行。信而见疑，贞而为戮，是以壮夫义士伏死而不顾者也。下官闻仁不可恃，善不可依，始谓徒语，乃今知之。伏愿大王暂停左右，少加怜鉴。

下官本蓬户桑枢之民，布衣韦带之士，退不饰《诗书》以惊愚，进不买名声于天下。日者谬得升降承明之阙，出入金华之殿，何尝不局影凝严，侧身启禁者乎？窃慕大王之义，为门下之宾，备鸣盗浅术之余，豫三五贱伎之末。大王惠以恩光，晒以颜色。实佩荆卿黄金之赐，窃感豫让国土之分矣。常欲结缨伏剑，少谢万一，割心摩踵，以报所天。不图小人固陋，坐贻谤缺，迹坠昭宪，身限幽圄。履影吊心，酸鼻痛骨。下官闻亏名为辱，亏形次之，是以每一念来，忽若有遗。加以涉旬月，迫季秋，天光沉阴，左右无色。身非木石，与狱吏为伍。此少卿所以仰天抳心，泣尽而继之以血者也。下官虽乏乡曲之誉，然尝闻君子之行矣。其上则隐于帘肆之间，卧于岩石之下；次则结缓金马之庭，高议云台之上；次则虏南越之君，系单于之颈；俱启丹册，并图青史。宁当争分寸之末，竞刀锥之利哉！

然下官闻积毁销金，积谗糜骨。古则直生取疑于盗金，近则伯鱼被名于不义。彼之二才，犹或如此；况在下官，焉能自免。昔上将之耻，绛侯幽狱；名臣之羞，史迁下室，如下官尚何言哉！夫鲁连之智，辞禄而不反；接舆之贤，行歌而忘归。子陵闭关于东越，仲蔚杜门于西秦，亦良可知也。若使下官事非其虚，罪得其实，亦当钳口吞舌，伏匕首以殒身，何以见齐鲁奇节之人，燕赵悲歌之士乎？

方今圣历欽明，天下乐业，青云浮雒，荣光塞河。西泊临洮、狄道，北距飞狐、阳原，莫不浸仁沐义，照景饮醴。而下官抱痈圜门，含愦狱户，一物之微，有足悲者。仰惟大王少垂明白，则梧丘之魂，不愧于沉首；鹄亭之鬼，无恨于灰骨。不任肝胆之切，敬因执事以闻。此心既照，死且不朽。

景素览书，即日出之。寻举南徐州秀才，对策上第，转巴陵王国左常侍。

### 翻译

江淹字文通，是济阳考城人。他年少时孤苦贫困，但是勤奋好学，性格沉静，很少与人交游。初任南徐州从事之职，转任奉朝请。

宋建平王景素喜欢士人，江淹就跟随景素住在南兖州。广陵令郭彦文因故获罪，供辞连及江淹，江淹被拘囚在州中监狱里。江淹在狱中上书说：从前，低贱的臣子击胸表白心志，就会突然有霜袭击燕地；普通的女子向天呼告，就会突然起风袭击齐台。我每次读到这些文字，没有不拖卷流泪的。为什么呢？因为士子们有一直坚定的信念，女人也有不能改易的德行。诚实却被怀疑，忠贞反遭杀戮，所以壮烈之人侠义之士宁愿赴死，决不顾顺，原因就在追裏。我听说仁和善都不可依靠，一开始我认为这是虚话，到今天才明白其中的道理。我诚恳地希望大王暂且停止身边的事务，稍稍施予我些许怜悯和监察。我本是住在用蓬草编门桑树做户枢的简陋房屋裹，身穿麻布衣服，腰系韦皮带的无官之人。退居时不用《诗》《书》装饰自己来惊骇愚人，进用时也不向天下人收买名声。先前，我侥幸能在承明宫阙裹上下，在金华宫殿中出入，我何曾不拘束我的形影，凝聚我的庄严，侧身行走于宫门禁中呢？我敬慕大王的道义，才成为您门下的宾客，我准备了些许鸡鸣狗盗之类的浅薄之术，还预备了三五种贱技的细枝末节。大王把恩泽光辉施惠于我，和颜悦色地厮视我。遭实际上是使我如同佩有荆卿那样的黄金赏赐，私下裹感到如享有豫让那样的国士的名分了。我常想结好帽带身伏利剑，从容就死，来稍稍感谢大王的恩德于万一，披肝沥胆摩顶放踵，来报答大王。不料小人固塞鄙陋，遂给我留下诽谤毁损之辞，使我的业迹坠毁于昭明的法令，身体受限制于卤冷的囹圄。我踩踏自己的身影，怜悯自己的心情，每每鼻子发酸，痛入骨髓。我听说使声名受损是最大的耻辱，使形体受损伤还在其次，所以每一次这些念头上来，心中恍惚，如同有所遣失。再加上时间已遇了一个月，迫近秋末。天色阴沉，周围没有好景色。我的身体不是木头也不是石头，却和狱中吏卒为伍。这也正是尘圣仰天长叹捶心自责，眼泪流尽接着流血的原因。我虽然缺乏乡里部曲的赞誉，但是也曾听说过君子的德行。首先就是隐身于市肆之间，退居安卧在山林岩石之下；其次就是在金马之庭上佩结印绶，在云台之上高谈阔论；再其次就是俘虏南越国君，系住单于的颈子；遣都能启用丹书铁券，留名青史。人难道应当争夺一分一寸这样的微小益处，竞争刀刃锥尖这样的细小利益吗！可是我听说毁谤的话积累多了可销熔金子，谗言积累多了可以使骨头腐烂。古代的高生被怀疑有盗窃金子的行为，近世的伯鱼被加上不义的名声。他们这样两个贤才尚且如此，何况事情发生在我的身上，我哪里能使自己免祸。从前上将军遭受的耻辱，可以举出绛侯系囚在牢狱中的例子；名臣所受的羞辱，可以举出史迁被下蚕室遭受宫刑的例子，像我这样的遭遇还有什么话说呢。鲁连有智慧，辞去俸禄而无反顾；接舆贤明，边行边唱忘记归去。王陵在东城闭关自守，仲蔚在西秦杜门谢客，他们也很可以谅解。假如我的事不是这样虚假不实，而是罪名与实际相符，那么我就应当闭不言，身伏匕首来殒灭自身, 我还有什么面目见齐鲁那些有奇节的人, 燕趙那些慷慨悲歌之士呢如今圣上理政英明, 天下人安居乐业,青云飘浮在雒水的上空, 荣光充塞黄河。西到临洮、狄道, 北到飞狐、阴原, 没有不沉浸沐浴在仁义的恩泽裏的, 人们揽镜照影, 饮用甘甜的美酒。然而我却在牢狱裏抱深痛含悲愤, 這一件事情虽然微小, 却有值得悲伤的地方。我恳求大王稍稍垂察, 把我的事弄个明白, 果真如此, 那么梧丘的冤魂, 就不会因为头颅变成水中污泥而羞愧; 鹤亭的游鬼, 也不会因为骨朽为灰而遺憾。我不能忍受肺腑之情的急切，祇得恭敬地通过大王左右的人来使您闻悉我的事情。我的遣片心意已经宣明，那就死也将不朽了。

景素看过遣封上书后，当天就放出了江淹。不久又举拔江淹为南徐州秀才，江淹对答皇帝的策问，结果列入最上等，转任巴陵王国左常侍。

### 解析

人,往往不被理解。

真的。这一方面最典型的例子就是“和氏璧的故事”。春秋时候，楚国有一个叫卞和的人，在深山中得到一块宝玉，于是，他怀着对楚国国君的一片赤诚，把宝玉献给了楚厉工和楚武王，可是，两位昏庸的国王都认为这是一块石头，卞和的行为，纯属欺诈主上，因而残忍地斩断了卞和的双脚。等到楚文王继位，卞和抱着宝玉在深山痛哭三月，楚王派人落实，发现果然是一块宝玉，这才为卞和平反昭雪。

这种人间悲剧一直没有间断过，《淮南子》中记载了这样一个故事：有一个叫邹衍的优秀人才，对燕惠王非常忠诚，可燕惠王却相信谗言，将邹衍抓入大牢。邹衍仰天大哭，悲怆之情感动了苍天，时值盛夏，天上竟为之降下了层层霜雪。

历史上最不被人理解的杰出人物也许就是屈原了。屈原对楚怀王竭尽忠忠，可楚怀王却听信谗言，疏远屈原甚至流放屈原，终于酿成了屈原“汨罗沉江”的惨剧。

本篇中的主人公江淹亦属此类，他对宋建平王刘景素非常忠诚，却因一判乱事件被连累，遭及莫须有的罪名，因而，他要奋笔疾书，在书信中为自己伸冤。

江淹真是幸运，因为他的主子建平王还是一个重情理的人物，首先，建平王重情，他永远难忘从前江淹在他门下与他亲密相处的那些情节，他是一个恋旧的人。其次，他是一个重理的人，建平王一，不昏庸，他善于动动脑子想一想事情的来龙去脉，调查了解一个事件的真实情况，绝不冤枉一个好人。

可历史上不幸运的人物就太多了，殷朝末年的暴君纣王残忍无道，他的叔伯父（纣王的庶兄）比干满怀对自家肉骨的忧虑和关怀之情，强行劝谏，却使纣王龙颜大怒。有人劝阻纣王，说比干完全是一番好心和忠心，但纣王竟说出这样的话：那我就把他剖开来看看吧，结果，比干被活活剖心而死。

所以，历史把人教聪明了，于是人们不再盲目提倡忠诚，不再莫名其妙地为人冲锋陷阵，甚至为人抛洒热血。于是人们响亮地提出“士”只为“知己者”死，并且发誓：“良禽择木而栖，贤士择主而行。”

## 学与用

知识即商品，然商品有贵贱之分。之所以贵，乃因知多，有一长也；之所以贱，乃因知寡，而无一长也。故欲人贵，非好学不能贵；欲使人高造价，非自奋不能高造价也。

夫人有不学而能身价高乎？不能！尽管有贻娘老子“商标”而贵者，然只可贻一时，而不能贻一世；尽管能贻一世，然因“伪劣商品”，不能为人所敬重也。故欲贵之，必先学之。学即买进，用即售出。

然买进，是为售出而买进；而售出，是为赢利而售出。盖人之大脑，如一储备库，又如一生产厂家。学习，即我购进原材料，一经加工，而后售出。故人生之过程，乃是不断求知，又不断致用之过程也。

孔子曰：“精义入神，以致用也；利用安身，以崇德也”。故学习之目的，在于使所学有作用于国家，有作用于社会。所以，学习旨在提高做人之品位，然后使我进入最完美之境界。无人买则罢，但有人买，必不敢如酱油、醋一般讨价还价。

所以，少年贵于学，成年贵于用。然成年又不可不学，其如不断进货，不断售出，不断赢利之过程。且知识之交易过程，大不乏如商品之交易过程；而商品之交易过程，又不乏是人与人之交易过程也。

如均有买卖双方，均有商品名称，均有产地、包装、品类，以及质量高低之诸特征。所不同者，只是额头上不贴价格标签，也不标明价位，不设置防伪标志。且自身价值，从表面看，似乎也不按生产成本核算，而实际上也是以生产成本，工艺流程，质量品牌，以及诸多因素核算之。故一旦投放市场，予其说知识，还不如说是人与人之交易。

所以，人不能不学。不学，即我库中无货；无货，如何同人交易？然货多，又要看其紧俏否！紧俏与不紧俏，又要看其能推销否！如不能推销，即便货物再多，只能积压之，霉变之。故学习如进货，进货重在推销，推销重在赢利。

于是，凡善学者，当以善用为上。不然，虽有知识，而不能活用者，则如无知识一般。故学习如制商品，商品又不能不以社会需要而制作。只有按社会需要制作，方能使消费者踊跃购买。故拥有知识，不过是完成做人之第一道工序，而做人之最终目的，则是让知识成为紧俏商品，而使人购买，然后从中取利之。

所以学在于用，在于能否将所学发挥之，凡能发挥者，如所有商品悉数推销之；若不能发挥，如商品虽多，但积压霉变，无人购买之。故不在知识多少，重在能否发挥。如十分知识，只能发挥一半者，则按一半计算之；若十分知识，只能发挥一分者，则按一分计算之；若半点发挥不出者，则不能计算之。

故文凭不等于知识，而知识又不能等于人才。其如鲁迅笔下之孔乙己，虽有满腹经典，然因不能所用，不能将所学变为商品，虽有知识，乃死知识，故有知识如同无知识一般。其如生意，进一堆货物而不能推销，安能不赔乎？

相反，有大事业成就者，虽不曾高等学府就读，但不等于知识不曾买进。只是知识之进货渠道不同，故被人不以“知识分子”看待之。如电视剧《大染坊》中之陈老板，虽字不识几个，然耳濡目竭尽能悟不胜悟，于是不仅事业成就，且做人之品位，远比那些酸文人高尚得多。

故能事业成功者，虽多无名牌大学之文凭，然因“敏而好学”，且又能举一反三。于是知识买进越多，则售出越多，自然利润越大。又因其善于交易，虽仓库无货，却能先拿订单而后生产之。更有不生产者，能以人之产品，贴己之商标。

于是知识能买进，又能售出，且在一买一卖中，不仅能知识转换为商品，又能知识转换为荣誉与权力。

噫嘻！人如电脑。不学，是不输入也；不输入，即品牌再高，形同虚设。又学不能所用者，虽能输入，然无显示功能，即便输入再多，是白输入也。所以，编辑电脑之程序，是因用其程序，倘不能用，岂不自程序乎？

所以，求知是为理明，理明是为谋事能明。如理明者，采众家所长，为我家所长；分析众家之不足，而避我之不足。然后身价高，一旦遇之以买主，则势必以“高档商品”交易之。且又因其知多，因其有一能之务，所以一旦投放市场，安能不纷纷抢购之。

孔子曰：“待价而沽。”待价者，乃是等待机遇，又等待买主也；沽者，机遇至，买主求购，自然高价兜售之。如孔子周游六国，是推销其思想；毛遂自荐，是推销其才能；孙膑、庞涓、苏秦、张仪，是推销其谋略。然敢于上门推销，是因有知识推销，若无知识，何以推销之？

然尽能推销乎？有能推销者，又有不能推销。能推销者，未必货真价实；不能推销者，未必不是极品。所以，有逢其时，有不逢其时。至于有不愿推销者，如鬼谷子，司马水镜先生，定有其不推销之理由，故不属所论范畴，所以，暂且不论之。

夫学而致用之理，万劫不复之理焉。故能推销于当代者，自然为佳；倘不能，还可身后推销之。盖大千世界，又非一条路可走，故此路不通，当走之以彼路。岂能因一处受阻，便沮丧乎？如孔子不做魯相，方有《论语》、《春秋》、《诗经》成。周文王被囚，方有《八卦》出。司马迁被别，方有《史记》传世。

又如《红楼梦》、《水浒传》、《三国演义》、《西游记》、《儒林外史》、《聊斋志异》诸作者，无一不是仕路否塞。于是，以所学著之以书，以求青史留名。虽生前潦倒，然身后之名，决不逊于帝王将相、达官贵人也。

予锄地时，见一石。取之，有麦芽盘桓于石下，而后一旁出。于是感叹不已！方知天下有生命之物，但有一线生机，皆不放弃奋斗。其如麦芽，虽逆境中走不少弯路，然终不因石压而自绝之。植物倘若能如此，何况于人乎？故不能不自奋，又不能不以所学而作用于社会。

人云：有不贤而发迹者何也？予告曰：其如商品，假冒伪劣者多矣！然世人不识假冒伪劣者亦多矣！于是，庸人得志，自然情理之中。总之，能生前辉煌者，自然人生一大快事；若不能生前辉煌，决不可使所学知识霉变之。所以，当学之以先贤，能知识售于生前，则生前售之。若不能生前售之，则售之于身后，亦可名垂千古也！

## 被提拔的四门功课

### 原文

后起为镇南将军、武康令。愈厉廉节，除淫祀，正身率职，民甚称之。太守王彬巡属县，诸县盛供帐以待焉，至武康，远独设粗水而已。彬去，远送至境，进斗酒双鹅为别。彬戏曰：“卿礼有过陆纳，将不为古人所笑乎？”高祖闻其能，擢为宜城太守。自县为近畿大郡，近代未之有也。郡经寇抄，远尽心绥理，复著名迹。期年，迁树功将军、始兴内史。时泉陵侯渊明为桂州，缘道剽掠，入始兴界，草木无所犯。

远在宫，好开途巷，修葺墙屋，民居市里，城墙厮库，所过若菅家焉。田秩俸钱，并无所取，岁暮，择民尤穷者，充其租调，以此为常。然其听讼犹人，不能过绝，而性果断，民不敢非，畏而惜之。所至皆生为立祠，表言治状，高祖每优诏答焉。天监十六年，诏曰：“何远前在武康，已著廉平；复莅二邦，弥尽清白。政先治道，惠留民爱，虽古之良二千石，无以过也。宜升内荣，以显外绩。可给事黄门侍郎。”远即还，仍为仁威长史。顷之，出为信武将军，监吴郡。在吴颇有酒失，迁东阳太守。远处职，疾强富如仇雠，视贫细如子弟，特为豪右所畏惮。在东阳岁余，复为受罚者所谤，坐免归。

远钦介无私曲，居人间，绝请谒，不造诣。与贵贱书疏，抗礼如一。其所会遇，未尝以颜色下人，以此多为俗士所恶。其清公实为天下第一。居数郡，见可欲终不变其心，妻子饥寒，如下贫者。

及去东阳归家，经年岁口不言荣辱，士类益以此多之。其轻财好义，周人之急，言不虚妄，盖天性也。每戏语人云：“卿能得我一妄语，则谢卿以一缣。”众共同之，不能记也。后复起为征西谘议参军、中抚司马。普通二年，卒，时年五十二。高祖厚赠赐之。

后来何远又被起用为镇南将军、武康令。他更加砥砺清廉正直的节操，他除去各种不合礼制的祭祀，公正不阿，尽心奉职，百姓非常称道他。太守王彬巡视属县，各县都置办隆盛的宴席招待王彬，到武康，何远却只准备干粮茶水而已。王恣离去的时候，何远送他到边境，进献一斗酒一只鹅为王彬饯行。王彬和何远开玩笑说：“晋朝陆纳用一斗酒、一盘鹿肉送礼，你的礼物超过陆纳，会不会被古人嘲笑呢？”高祖知道了何远的才能，就把他擢拔为宣城太守。从县令提拔为京畿附近大郡的太守，这是近代没有的事情。宣城郡经过叛贼洗劫，坦达尽心安抚百姓，全力处理政务，又以政绩著称。过了一年，何远迁任树功将军、赵墨内史。当时星陆堡芦谥朗任挂职刺史，他上任的时候，沿路抢劫掠夺，但进入始兴地界，他连草木都没有损害。任职的时候，喜欢开修道路，修墙建百姓住房，街市里巷，城池仓库，他一一整理，如同营建家室。田秩俸钱，何远全不取用，到了年终，他挑选最为窘困的百姓，用自己的俸禄充作他们的赋税，他经常这样做。但是他处理诉讼案件也如同别人，没有超过一般人的地方，但他生性果断，百姓不敢干坏事，害怕他却又敬爱他。何远任职的地方百姓都为他设立生祠祭祀，又上表呈奏他的政绩，高祖常常下诏书褒美奖他。天监十六年，高祖下诏说：“何远先在武康任职，已经显扬廉明公正的名声，接着治理两个郡，更加体现了他的清正高洁。施政先修整道路，留下惠政百姓敬爱，即使是古代的贤良太守，也没有超过何远。应当迁升何远任朝中荣耀的职务，以表彰他在郡县任职的业绩。应当授任何远为给事黄门侍郎。”何远随即回郡，接着任仁威长史。不久，何远出京任信武将军，监吴郡。在吴郡常因喝酒而有过失，迁任东阳太守。何远任职期间，痛恨豪强富家，对待他们如同对待
