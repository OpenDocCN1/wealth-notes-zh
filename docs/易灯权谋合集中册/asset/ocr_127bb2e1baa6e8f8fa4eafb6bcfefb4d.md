# 老好人常吃亏的原因

如果你只是扮演一个不做任何抵抗的老好人，的确会有所损失。因为，这会让周围的人会觉得你没什么个性，而且也会让你越来越不引人注意，一点魅力都没有。即使错不在你，但在这种情况下，事实就是如此。以下这个实验，可以帮助你更加明白这个道理。

# 心理学常见的电击实验

首先，让接受测试的大学生观看**受到电击而感到痛苦的人的**录像带。之后，再将他们分成 A、B、C 三组，并让他们做出下列三种不同的反应：

+   A 表现出**没有受到电击**，只是假装痛苦的样子。

+   B 表现出**没有任何理由，真的受到电击的样子**。

+   C 表现出**虽然受到电击，但能获得三十美元报酬**的样子。
