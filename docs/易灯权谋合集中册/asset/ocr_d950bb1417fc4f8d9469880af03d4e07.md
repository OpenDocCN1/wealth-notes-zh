# 序

问这世上，是先有好书，还是先有好的**权谋**作家？

在古代是先有好的作家，如今只有好书，如今完成一部著作，多半是参照史书，古人的智慧对今处世有着重要的启示。

古人比现代人处境危险，学成文武艺，货与帝王家，是古人唯一的出路。官爵加身财禄相伴更比登天还难。

古人比我们寿命短，疾病战争瘟疫都可以随时要一个人的命，据学者林万孝的《我国历代人平均寿命和预期寿命》中统计，我国古代人平均寿命：夏、商时期 **18** 岁，周、秦大约为 **20** 岁，汉代 **22** 岁，唐代 **27** 岁，宋代 **30** 岁，清代 **33** 岁，民国时期约为 **35** 岁!这乍一看古人的平均寿命短到和猎狗相差无几!
