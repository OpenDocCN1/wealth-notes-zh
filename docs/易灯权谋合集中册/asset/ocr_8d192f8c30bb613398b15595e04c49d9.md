# 斗争的实质在于制衡，制衡的精神在于适度

> “大人虎变，未占有孚。’”

人与人相处以和为贵，世界也以和平为正途，而斗争冲突是和平共处的手段，和平共处是斗争冲突的目的。

写下这篇文章的目的并不是为了鼓励勾心斗角，只不过现实生活中有许多不平事，无妄祸。

往往君子失意，小人得志，以致世风日下，为了成君子之美，驱小人之恶，创立一番事业，匡扶一股正气，于是写下这篇文章。

天行有常，不以尧存，不以桀亡，残酷的现实是没有不变的朋友，只有不变的利益。我们有必要吸取春秋战国时代国与国斗争的经验，把无用的东西抛弃，有用的东西提炼出来，才能更好地纵横榷阖，自立自强于世界---既壮大了自己，又赢得了尊重。

但有一点是关键；斗争的实质在于制衡，制衡的精神在于适度。这个世界上只有相对好的结果，没有绝对好和绝对坏的手段。可以为了一个光明的目标，用阴谋的手段来实现。
