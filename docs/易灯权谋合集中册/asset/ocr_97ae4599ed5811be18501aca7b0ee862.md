# 下属只有三种，你是哪一种？

在我只是一个工作者时，通常只要花 60% 的时间及精力，就可以完成公司交付的任务。

虽然我可以轻松完成，保持着好整以暇的余裕，可是根据我对所有同事工作状况的观察，仍有许多同事要很努力投入，才能勉强完成。另外还有一部分的同事，无法准时完成公司交付的任务，经常面对主管的责备和脸色。

久而久之，我得到一个清楚的结论：在组织中，任务与工作者的关系存在 3 种不同的现象：

+   第一种人是能够勉强完成公司的任务，这种人大约占 60%；

+   第二种人是无法完成公司交付的任务，这类人占比不高，大约也有 20% 左右；

+   第三种人，就是像我一样，能轻松完成工作，而且还有余裕游玩耍，这种人也大约有 20% 左右。
