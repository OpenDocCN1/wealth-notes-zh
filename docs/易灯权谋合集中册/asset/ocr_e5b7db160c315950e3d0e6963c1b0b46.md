# 逆转情势的说话术

别再忍了！小小的反击让你更积极

大部分的人一听到讽刺、责骂或伤人的话时，都会感到相当气愤，甚至还会想哭。可是，很多时候，当你遇到这样的情形时，就只能选择忍耐。事后回想起来，才后悔的责怪自己：为什么当时不顶回去？

有一个心理测验，测试者安排多位玩家进行某种竞赛，游戏中将玩家分成三组，各自采取特定的战略：

+   * A 一味的攻击其他玩家。

+   * B 绝不攻击别人，但面对敌人的攻击，只会默默的承受。

+   * C 当敌人攻击时才反击，除此之外，不会主动采取攻击。

结果，成绩最好且获得最高评价的是 C 组。比起 B 组只会默默的承受，C 组当然更好。重点是，如果能够学会这么做的话，你绝对会比那些超级惹人厌，只会肆无忌惮的嘲讽和说坏话的主管（也就是 A 组），得到更高的评价。换句话说，小小的反击是很重要的。

不想老是被攻击吗？
