些对他目前正在做的项目有帮助的问题。他坚持认为，如果没有督促自己这么做，他就不可能坐到今天这个位子上。

对大多数人来说，比起费心培养关系网络，他们觉得培养专业技能更加自在。但是仅有专业技能是不够的。在大多数企业里，事业成功的秘诀就是接触那些了解内情的人。在这个关系网中，你不一定要当众人瞩目的明星，你只要确保自己不出这个圈子就行。如果你好像总是最后一个才知道将要发生什么变化，或者你总是不了解身边发生的情况，那很可能就是因为你没有与合适的人建立联系。人的大多数行为都要受某些标准或规则的影响。通过观察和揣摩别人的行为，你就能够掌握这些规则。问问自己下面这些问题，看看你对公司的了解有多少。

+   ● 在公司，谁跟谁说话？在什么时候说？

+   ● 谁先讲？讲多久？他们的日程安排是什么？
