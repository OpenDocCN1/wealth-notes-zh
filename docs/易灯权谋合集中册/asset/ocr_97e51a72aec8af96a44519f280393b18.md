# 官场大师是如何把握权术斗争的？

孔子是自己开办的“中国做官职业学院”的校长兼首席教授。虽然他本人仕途不得志，但绝对是给一点阳光就灿烂的人。在他晚年被季氏重用后，短短的四年时间里使鲁国男女分途、路不拾遗，一派繁荣安定的大好形势，搞得齐国都害怕了。他一生中如 何做人、做官的研究十分深刻和了得，其中关于如何把握官场权术争斗的心经，非常独到，值得学习。

官场争斗，自古有之，后世亦然。对于此，人们一般称之为“内耗”，我们的很多事情也正是坏在这样的内耗当中的。所以，对于官场争斗，我们一方面对它痛心疾首、试图改善，一方面又看到“天下乌鸦一般黑”，心里也是无可奈何。那么，作为“官场大师”的孔子是如何看待这些问题的呢？
