# 权术家都是公关大师

天魅星呼保义宋江，梁山大当家，又称及时雨。不少人以为宋江无用，什么本事都没有，还当了 108 好汉之首，但是不然，这其实就是宋江的最大本事。不错，就是笼络人心。

书中说，宋江仗义疏财，天下闻名，可谓黑白两道通吃，郓城县上上下下，没有几个关系不好的，用现在的眼光来看，就相当于一名公关大师，非常善于交际，想宋江身材黑矮肥胖，形象很是丕堪，能做到这样，谈何容易？反正这一点我是很佩服他。名声在外，出外旅行自然也不一样，只要将名号报将出去，对方立刻倒头便拜。由于名声好，在梁山上也能一呼百应，这就是宋江成为 108 好汉之首的基础。
