
两者相反相成。斗争是协作的手段，协作是斗争的目的。两者处于此消彼长的相对变化之中，平衡［斗争适度］则成就事业，失衡［斗争过度］败坏事业。掌握制衡原则，则有助于成就事业。而掌握制衡原则，就得从学会斗争开始。

## 人性如水，兵势如水。斗争的原理在于

- 1. 把握时机，
- 2. 利用敌人的弱点［包括性格上和形势上的］，
- 3. 因势利导，以己之长，攻对手之短。
- 4. 削弱对手，壮大自己。

**［一］根据对手的性格特点使其暴露缺点，丧失正常能力。可有下列几种：**

对于个性多疑者，不妨多设圈套迷惑之，使其犹豫不决，丧失进攻时机。就像诸葛亮设空城计迷惑司马懿一样。

对于刚愎自用者，不妨曲意奉承，使其逞强自伤，众叛亲离，失势而终。就像勾践应对夫差一样。

对于心怯者，不妨虚张声势，乱而取之。就像前秦和东晋的淝水之战。

对于骄横者，不妨隐藏自己，不断示弱加以迷惑，然后待其势弱时奇袭之。就像孙膑与庞涓的马陵之战。

对于有勇无谋者，不妨简单设谋；对于性聪者，要么设奇谋，要么直接了当，打破常规，出其不意发动进攻。

总之使对方暴露缺点，使其短之又短，疑之又疑，骄之又骄，怯之又怯，丧失正常的判断能力，从而发扬自己的优点。

**［二］根据敌我形势，采用手段来破坏瓦解对手的组织结构和运作机制。**

1. 去其爪牙，除掉为虎作伥者——破坏对方组织结构中的执行环节。
2. 去其耳目，除掉对手的狗头军师——破坏对方组织结构中的谋划环节。
3. 击其咽喉——破坏对方组织结构中的传达环节。
4. 击其胸腹——破坏对方组织结构中的行政中枢。
5. 擒贼先擒王——破坏对方组织结构中的首脑机构。就像刘秀在昆阳之战中的所为。

**［三］从进攻的方式来说，有正面进攻，迂回进攻，包围进攻，突入进攻，分割进攻几种。**

具体有移花接木，欲擒故纵，暗渡陈仓，驱虎吞狼，离间计，反间计，苦肉计，美人计等等。

其中前期的准备工作也非常重要，自身的动员和知己知彼的工作，有力的动员才能发挥自身最大的潜能。知己知彼才能选择正确的攻击时间，攻击方式，攻击地点。

**［四］只有发扬自身的优点，捕捉对手的弱点才有用。从自身的情况来说：**

首先应虚心实腹——致虚极，守静笃，万物并作，吾得以观其复。具体表现在信心，勇气，坚韧，智慧，专注的精神修养上和体力，观察力，捕捉时机的能力与身体素养上。

其次是正确的谋划，做事的方法有两种，一是阳刚［直面］进取，一是阴谋［暗地］筹划，两者并行不怠，缺一不可。

再次是强大自身，消弱对手。一是从外部联合朋友加强力量，可晓以利害，明以义，激其斗志，同仇敌忾。二是从对手内部分化敌人，可晓以义，明以理，收以利，威慑和恩惠并用。

**［五］利用一切可以利用的手段，比如官府有依靠，山有绿林有帮助，法律有依据，舆论有同情，军事有保障……其中心心向背是关键，而经济实力是基础。**

# 权术家都是公关大师

天魁星呼保义宋江，梁山大当家，又称及时雨。不少人以为宋江无用，什么本事都没有，还当了 108 好汉之首，但是不然，这其实就是宋江的最大本事。不错，就是笼络人心。

# 权术斗争玩死你

晚清著名的清流党，有青牛之尾之称的陈宝琛（后来做过溥仪的师傅），堪称忠诚正直、廉洁律己、秉书直言、无所畏惧，弹劾了很多朝廷重臣。无数人怀恨在心，包括攻下金陵的曾国藩的弟弟曾国荃。于是曾国荃邀请陈宝琛巡视长江入海口及沿海防务要塞，督促加强战备，预防法国兵船从长江口打入。

陈宝琛在巡视过程中，亲眼看到海防要塞军纪涣散，防守松懈，将士们对西洋进口的枪炮火药的使用，惘然不知。军中赌博之风盛行，有的通宵不眠。营官扣饷几成通例。更为严重的是前线最高将官陈缇靡靡贪侈，险诈骄纵，不仅品行恶劣而且才能平庸，当此非常之时，恐坏国家大事。陈宝琛回到江宁，将这些情况告诉曾国荃，岂料曾国荃不但不支持陈宝琛，反而指责他不该随便批评前线将士，扰乱军心。

但陈宝琛依然秉着他在京时的清流亢直之气，认为不向朝廷如实反应，则有负朝廷的重托，于是上了一道密折，将江南海防的实情，以及陈缇、曾国荃等行为一并上奏。这封密折刚到北京，便有平时用重金收买的宫廷耳目报告曾国荃。

曾国荃一面指使人上奏朝廷，无端给陈宝琛加上一个收受法国人五万两银子的贿赂罪名，又无中生有地说陈宝琛在江南期间狎嫖妓，行为不轨，有伤风化。同时在江宁城里，对陈宝琛彻底孤立，所有该陈宝琛管的事情一律不许他参加。陈缇更指使一帮兵痞在陈宝琛的住宅四周寻事生非，无理挑衅，弄得陈宝琛形影孤单、凄凄惶惶、日不能食，睡不安寝，处境尴尬、心绪烦乱，如坐针毡，如处火炉，狼狈至极。

而此时，正是中法战争一触即发的时候，朝廷需要能打硬仗的曾老九，为安抚曾国荃，将陈宝琛连贬 5 级。陈宝琛身心交瘁，索性以母老为由，申请回籍侍亲，朝廷准奏。

在陈宝琛登舟回籍的那天，江宁无人相送，只有一群兵痞在码头上焚纸燃炮，意为送瘟神。而此时京里，恭亲王、醇亲王、李鸿章均自私心庆贺，感谢曾国荃不但拔了钉子而且给大家出了气。当然慈禧是了解此次委屈了陈宝琛，所以才会有 24 年后将陈宝琛从家乡请回做帝师。

国与国之间，朝廷宰辅之间，强者与弱者做这种“玩死你”的游戏，下到一个小公司里，又何尝没有具体而微者呢？

我的朋友是中关村某大公司的前财务总监，一年前这家公司刚换了总裁，新总裁过去对她并不欣赏，但是新官上任，首先要了解公司，并根据财务宿弊来铲除异己。于是一年内，我这位朋友一不怕苦二不怕死，帮新总裁纠财务问题，干掉了几个眼中钉，立下汗马功劳。刀光剑影的一年过去了，我这位朋友满心以为去年立了功，今年可以舒舒服服地享受成果了，没想到新总裁新年第一件事就是将矛头对准她。干掉她的办法也很简单，新总裁把原来在她手下的一个她比较看不上的人提起来当她的领导，因为领导没有办公室，所以她必须从办公室里搬出来，给新领导腾地方，而自己坐到开放式办公区里去。

然后单位开始批评与自我批评活动，因为去年一年，她大刀阔斧，结怨甚多，而通过搬办公室一事，大家也看出新总裁对她并不照顾，所以就成为众矢之的。一堂生活会结束，我这位朋友觉得她已经没有可能再在这家公司做下去了，于是辞职。

直到这时候，她才明白，一开始新总裁就没有计划用她，只是要先借用她来杀人，目的达到后，就要把她这把戾气太重的武器扔掉，换一个和大家都没有梁子的自己人来做自己真正的左右手，这样公司就可以在团结而祥和的气氛中前进了。

后来有人告诉她，她曾经在这位总裁式徽时得罪过他，只不过她自己早就忘了。

# 帝王的权术

历史上凡有作为的帝王都会使用权术。武则天的权术用得很残酷，总起来分两个阶段。一是执政前，一是执政后。执政前用的是一哭二媚三骄四坑害。唐太宗死后，武则天当了尼姑。面对青灯古佛，一个正值青春年少的她，真不是一件容易的事。但是，高宗当太子时曾见到过她，很喜欢，可谓一见钟情。作了皇帝后有一天经过佛寺，武氏见了，大哭，高宗看到她眼泪汪汪的，受到触动，便把她带进宫，脱离了青灯古佛的清苦生活。这一哭，完成了进宫的第一步。

第二便是谄媚皇后。皇后是她的顶头上司，要高升，还得攀着皇后。于是她便“下辞降体”，低声下气，卑躬屈节，尽力侍奉皇后。皇后很高兴，便多次在皇帝面前称赞她，皇帝进封她为昭仪。这样她的地位提高了，受到天子的眷顾和宠幸，逐渐超过了其他妃子。她便不再曲意奉承皇后，并和她逐渐不和起来。同时买通宫女和女官，对皇后的事知道得一清二楚。时机成熟了，她便使用坑害了。武则天头胎生了个女孩，皇后去看望，等皇后走后，她便掐死了孩子，偷偷的放在被里。一会儿皇帝来了，她佯装不知，皇帝要看孩子时，掀开被子一看，孩子已经死了。左右都说皇后来过，武则天放声痛哭。皇帝不能觉察，非常生气。有瘗皇后的意思。她够残酷吧，为了害人把女儿也搭上了。她又经常到皇帝面前诬告皇后，还造谣皇后和她母亲请巫师诅咒她。皇帝不再犹豫，下令瘗掉皇后，立武则天为皇后。这样，武则天用权术完成了她的第一个飞跃，顺利地当上皇后。

取得皇后地位后她采取一迷二杀的方针。对高宗采取“痛柔屈不耻”，曲意奉承，极尽柔媚驯服，取悦皇上，并不感到羞耻，借此成就她的大事。这样的结果使高宗很高兴，觉得只有皇后能侍奉他，对他好。先让她批阅文件，慢慢地参与了朝政，甚至逐渐地取代皇帝。对于反对她的大臣，则不论何人，一律杀灭。皇帝大舅长孙无忌、大臣褚遂良“踵死徙”，皇帝的侍臣上官仪被杀后，皇权就旁落到她的手里了。武则天就这样用尽心机，一步步蹬上了皇后的宝座，并坐得稳稳的。为了当皇后，她够残酷了吧？

李敬宗联合骆宾王反对武则天当皇帝，起兵造反。被镇压后，她对臣下说：“朕没有对不起天下人，你们知道吗？”还说：“‘朕三十年忧劳天下。爵位富贵，朕所与也。朕不敢爱身，而知爱人。何见负之遽？’将相如李敬宗，程务挺，裴炎都被朕杀了，你们要造反的，早一点，不然，就恭恭敬敬地老老实实为朕办事。”‘群臣顿首，不敢仰视。’从思想上制服了臣下。这是动之以刑，晓之以理。为了更进一步制服朝臣，她提出十二条治国方略，其中有劝农桑，薄赋徭；广言路，杜馋口；父在为母服齐衰三年；等等。用富国之策让众人畏服。又提出增加官员薪奉，减免百姓人口税。争取了民心，取得了大多数人的支持。为了坐稳皇帝位子，她还发动大家告密。对告密者，‘吏不得何诘’，无论农人樵夫必定自己亲自接见。一时‘人人屏息，无敢议’。她对人才的选拔，也不拘一格，有一技之长者，都加以任用。采取了这些政策后，人心归伏，出现了一时的繁荣。

武则天在位四十年，国家统一，人民安居乐业。发展了经济，对开元盛世起了承上启下的作用。应当得到肯定。

# 权术与制度之别

《三国演义》是中国权术的大全。所谓权术，就是政治手段。但政治手段有些是必要的、负责的政策与策略，有些则完全是诡诈性、奇谲性的计谋手腕，后者便是权术。宋代叶适所作的《宝漠阁待制知隆兴府徐公墓志铭》写道：“三代圣王，有至诚而无权术”。把权术视为“至诚”的对立项，十分准确，权术的主要特点正是没有真诚，只有机变手段。叶适这句话的重要性还在于说明，中国汤尧禹舜时代的上古原形文化，没有权术，只有真诚。到了春秋战国时期，《孙子兵法》、《韩非子》、《鬼谷子》、《战国策》等兵家、法家、道家、纵横家等着作出现，中国文化才发生巨大的伪形，出现权术政治游戏的第一个高潮。东汉末年，也就是三国时代，则出现第二次高潮，后一次高潮，其规模之大、谋略之深、诡计之细密，是第一次高潮无法比对的。

倘若如叶适所言，“三代圣王有至诚而无权术”，那么，《三国演义》中的权人权术家们则相反，可谓“三国诸王有权术而无至诚”，个个都极会伪装、极善于耍弄阴谋诡计。被《三国演义》捧为正面形象的仁君刘备，其特点也是只有权术而无至诚，或者说，只在拜把兄弟的小圈子内有真诚而在圈子之外则无真诚。刘备的胜利，乃是伪装的胜利。

权术归根结蒂是种手段和技巧。“术”本来是与“道”相对立的概念。世无道，术便悖兴。中国文化以诚为本，诚能通神，诚即道，因此，世无诚时术也悖兴。三国时代是个战乱时代，中国文化中的“道”到了此时已全面崩溃，权术家们口中念念念有词的道，只不过是“术”的面具。曹操对皇帝早已失去忠诚，但还需要皇帝做招牌，“挟天子以令诸侯”，此时维护天子，不是道，而是术。

中国古代文化中所讲的道，在现代文化中则用另一套语言表达。如果我们暂且悬搁形而上层面的哲学表达，那麽，在现实社会政治层面的道，主要应当是指制度。而权术恰恰是制度崩溃后的产物，中国的权术那麽发达，就因为制度无效，反而是权术机谋有效，生存技巧有效。

钱穆先生一生研究中国文化，得其要点，他在《中国历代政治得失》一书中，特别指出“制度与法术”的对立，两者此起彼伏，制度衰则权术兴。分清“制度”与“法术”这两个基本概念极为重要。他说：

我们讲政治制度，有一些确实是制度，有一些则只能叫做事件或法术。制度指政而言，法术祇是件事情或手段；不好说是政治。大抵制度是出之于公的，在公的用心下形成的一些度量分寸是制度。而法术则出之于私，因此没有一定恰好的节限。所谓方法与权术，二者之间，当然又不能仔細分。而且一个制度之成立，也当然有許多複杂关係，总不免夹带有当时一些私意的。要说建立一制度，而绝对地大公无私，不仅古代历史未之有，就是将来的历史，要說一个国家建立某项制度，而绝无人事関係，绝无无私心夹杂，恐怕这希望也还远。不过公私之间该有分量的轻重。现在再说中国历代政治制度究竟是出于公的多呢？还是出于私的多呢？究竟法术的意义重呢？还是制度的意义重？论汉代，西汉可说是制度，东汉则多半出于光武的私心。论唐代，确实可说在建立制度，而宋代则有许多只算是一种法术。明代，有许多只能说它是一些事，不能说它是一些制。尤其是清代，可说全没有制度。它所有的制度，都是根据着明代，而在明代的制度里，再加上他们许多的私心。这种私心，可说是一种“部族政权”的私心。一切由满洲部族的私心发出，所以全只有法术，更不见制度。

（引自钱穆《中国历代政治得失》第五讲“清代”，台北大中国印刷厂，一九六年）

钱穆先生说，有些朝代有制度，如西汉、唐代；有些朝代则空有制度之名，实际上只有法术，如东汉、清代。东汉的第一位皇帝刘秀就开始露出术的端倪，到了汉末，则完全是权术的天下。当时政治大舞台，成了一个傀儡皇帝(汉献帝)当看守的权术比武大擂台。各种制度只是一张废纸，连圣旨也是废纸(只有密旨密诏在求诸于人)，那么，要存活就只能靠玩手段与玩技巧了。谁玩得好，谁就是胜利者。钱穆先生在论述制度与法术的区别时还指出关键性的一点，就是凡热中于法术者都有私心，这一意思实际上是说，凡玩弄权术者都是心术不正者。品端心正的大公无私者依仗健全的制度，无须依靠政治技巧和其他生存技巧。制度应体现社会公众的利益，权术家们一旦确认制度的权威，必定会损害自己的私利。《三国演义》中诸方的首领，从曹操到刘备、孙权，从曹丕到司马懿，哪一个不是私心当头呢？

# 王熙凤是玩弄权术的高手

王熙凤是在封建特权中泡大的，她的祖辈既管外交，又管贸易，父辈又掌握了兵权，对于权的妙用，她耳濡目染，感受深刻。她从小就充男儿养，因而培养了两方面的才能：一是" 从小就有杀伐决断"。所谓杀伐决断就是镇压别人、攻击别人绝不手软；二是心机又极深细（冷子兴）。所谓深细就是眼观八面，耳听四方，随机应变，见风使舵。有了权，又有才，于是就爱弄权。王熙凤深深懂得特权、地位、金钱三位一体的关系，她既要弄权，过那总是高人一头的权势瘾，还要通过弄权谋取私利，满足欲望。

她协理宁国府单纯是为了过权势瘾。本来事情并不是她分内的，而且又庞杂，连王夫人也担心她干不了，她却偏偏要揽到身上。你看她处罚那迟到者，多么神气！先是鄙：“原来是你误了！你原本比他们有体面，所以不听我的话！”次是打：“带出去打二十板子！”三是革：“说与赖升革她一个月的钱粮。”丧事完后，她用正话反说的语调向贾琏夸耀说：“珍大哥再三在太太面前跟着讨情，只要请我帮他几天，我再三推辞，太太做情应了，只得从命，到底叫我闹了个人仰马翻，更不成个体统。至今珍大哥还抱怨后悔呢。你明儿见了他，好歹配释配释，说我年轻，原没见过世面，谁叫大爷错委了她呢。”真是神来之笔，这段话可谓是话中有话，王熙凤弄权后那踌躇满志的神态跃然纸上。
