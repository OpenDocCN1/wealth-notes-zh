# 给自己找点“势”

在这个“白骨精”横行的时代里，但凡个人，似乎都在挖空心思追求所谓的成功。

成功自然有成功的好处，有成功的美妙，才让这么多人趋之若鹜、乐此不疲。从各种各样的成功励志类图书畅销不衰，各家各派的成功激励大师层出不穷的现象中，我们是可以“窥一斑而知天下”大势的。

一旦走向成功，就意味着个人的兴隆：香车长驱、美妻入怀、豪宅坐拥、衣锦光鲜，出入高贵之所，耳听赞誉之言……此种自我满足，乃大部分人生命中最大的快乐。

中国的老祖宗，早把世人成功后的态势，统归为“富”“贵”“功”“名”四字。富即财势、贵即权势、功即事业、名即声势。四环相扣，互为左右。所以古人把成就“富贵功名”的成功者，称谓：势要。
