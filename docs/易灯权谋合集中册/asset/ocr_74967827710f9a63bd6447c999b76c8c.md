# 创业与守成

他们是中国史上白手起家的创业皇帝：刘邦原是混混，却打败世家出身的项羽，取得天下；朱元璋当过小僧，却驱逐蒙古，建立明朝。他们是不同的领袖：刘邦知人善任，能屈能伸；朱元璋稳扎稳打，随势推进。进取与保守的经营之道，决定汉、明两朝不同的国运……

现代资本主义市场机制下，企业管理是重要的强项。过去，投资与经营都可由一个人（或少数人）直接处理。一个自然人可以全凭自己的意愿，驰骋于市场，运用之妙，存乎一心，并不需要管理理论。但是，今日的战场是许多法人角逐的竞技场。如何组织高效率的团队？如何筹募最佳的策略？都是这些企业群体盛出成败之所寄。而不论组织，抑是经营，这一群体的决策中枢，亦即领袖的领导功能，尤是举足轻重的因素。

大凡历史上的国家治理，何尝不是在处理群体组织及资源运用方式？近代以前，资本主义市场的企业还未出现，然而一个皇朝的开创与守成，又何尝不是经营与管理两个领域的操作？
