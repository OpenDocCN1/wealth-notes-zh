# 职场谋略之轻重术

当我们说一个人是重量级人物时,大概是指那个人位高权重或财大势大的意思,

因为位高财大,在他手里握有很多我们赖以维生的资源的决定权,他的一个决定都会影响众人的祸福生死,因此在社会之中他拥有胜众之资,他掌握权势一般老百姓不得不听他的,这是情势使然,这就是<势>的力,有权势的人在社会上做事为什么较一般人方便容易,就是因为他能握势而为,擅于借其势使其力,操控他人行为--- 刘邦灭了项羽之后,对功臣论功行赏，主要的功臣大都封定，还有些将领未封赏，有一天，刘邦在洛阳南官的回廊上，看到许多将领聚集在一起窃窃私语，刘邦就问张良说：他们在谈论什么？

张良回答道:陛下不知乎？此谋反耳。

刘邦骇然道：天下属安定，何故反乎？

张良回答道：陛下起布衣，以此属取天下，今陛下为天子，而所封皆萧、曹故人亲爱，而所诛者皆平生所仇怨。今军吏计功，以天下不足遍封，此属畏陛下不能尽封，恐又见疑平生过失及诛，故而相谋谋反耳。

刘邦一听急问道：为之奈何？
