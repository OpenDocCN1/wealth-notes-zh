
知，不限条件，充分竞争，当然，还不忘加上高管的福利待遇作为诱饵，比如有股票分红，有公司配车配房，年薪几十万，有没有被套路呢？当年我初出茅庐，不知道这些套路，刚入职没多久就去和一个老员工竞聘主管的位置，结果我被穿了半年多的小鞋。

# 用这几招吃定职场 “老油条”

他们仗着自己资历较老或年龄较大，便同资历不深的老板叫板；他们的眼里只有大老板，对他们毕恭毕敬，对你却爱答不理，即便是自己为公司创造过价值，却不断纵容自己的恶习，诸如无视团队合作、考勤纪律等；

他们靠着自己的工作经验而不思进取，自我感觉良好，却在困难面前脆弱无力；他们喜欢经营一个小团队，抵制对其自身不利的新规定、新计划；他们斤斤计较，缺乏奉献精神，却对公司的管理指指点点。

他们就是职场中的 “老油条” ——他们的骄横倦怠不仅让管理者头疼，还让别的员工反感。可是在这种情况下，如果让这些比较资深，经验比较丰富的“老”员工走人，可能会对公司造成很大的损失。

所以，如何有效的管好他们才是当务之急。面对这种情况，应该怎么办？有“手腕”的领导是这样做的：

一、稳中求降

何为老油条？一谓“老”，一谓“油”，老说明人家有资历，有经验，油说明人家处事圆滑，你轻易抓不住把柄。如果你能轻易抓住把柄，他们就不是老油条了。

对待他们，不可操之过急。如果你贸然解雇他们，可能会损失一些人脉或者资源，甚至他会将一些自己培养出来的小油条一起带走。

其次，他们虽然圆滑了一些，但毕竟是有些本领的。肯定工作经验比较多，若轻易放弃他们，可能没有更合适的人选来接替他的这个工作，毕竟培养一名经验丰富的员工不管是时间成本，还是金钱成本都不少，如此一来，可能得不偿失。

所以对付这种人，只能慢慢来，慢慢抽凋他的一些权利，或者找个合适的时机，给他调离一些重要的工作岗位。

### 二、由外到内

老油条不仅自己油，还带着身边的人一起油。举个例子，本来公司里鱼龙混杂，有老油条也不为过。

结果这个老油条又培养出了一位十分优秀的老油条，于是乎，二人每天合计着怎么收拾副总，后来副总实在拿二人没办法，只得让总部将其中一个调离到别的地方。

可想而知，老油条的影响力不容小觑。

所以这时候你要怎么办？你可以从老油条的周围入手，一个个攻破。今天整一个小油条，明天再收拾一个小油条。

时间久了，老油条身边没有陪他一起折腾的了，他也会老实些，自己都成光杆司令了，他还能折腾啥。

而且小油条们天天受惩罚，你觉得老油条能不害怕？所谓杀几只鸡，就是给猴看。

### 三、去刺法

对于老油条来说，如果你暂时没有什么大的能力去开除老油条，那就先尝试把老油条身边的人，跟着老油条一块学坏，不认真工作的小油条，给一点一点处理了。

当老油条发现，混日子真的是要挨处理的时候，估计自己就改正错误了，就算没有改正，他也成了光杆司令，又有多大能力再阻碍工作呢？

### 四、小恩小惠笼络着！

所谓“吃人嘴短，拿人手短”，老油条为什么不听话？因为他觉得和你的感情不深，了解不多，那怎么办？

工作之余，约个饭，约个茶，休息的时候大家一块去爬个山，相信经过这些活动的历练，你们的感情就会加深，感情加深的坏处是什么？

——坏处是，你不能很好的批评他，一是碍于情面，二是他跟你熟练了，会有一定的免疫力。

但是，也有好处，好处是，你交代给他的工作，他碍于情面，也不会推辞。甚至觉得你人不错，从而死心塌地的为你卖力工作。

每个公司或多或少的都会有老油条，如果在可掌控的范围内还好，如果超过了掌控的范围内，那么你就需要及时的处理了。

因为老油条并不可多可怕，可怕的是老油条会带来连锁反应。如果老油条再带出一堆小油条来，到时候再处理，就难上加难了。

# 破解权谋领导玩平衡术的手段

玩平衡术是指在用人行为中，通过玩弄各种不光彩的手段，来保持各种势力之间的平衡，进而达到巩固自己领导地位的目的的用人权术。

玩平衡术作为一种用人权术，既不让某一种势力过分强大，又不让另一种势力过分弱小，反正谁也不能吃掉其他各方，最后还得维护我的地位，听我的指挥，这是典型的“玩”平衡术。

玩平衡术手段

常见的玩平衡术的手段有：

- (1)不辨是非，调和折衷

前美国总统尼克松认为：在现实世界上，政治就是妥协。”(尼克松：《领导者》第375页)他在执政期间，在美国政界的各种势力之间，搞了不少无原则性的调和折衷活动，以此保持自己的统治权力。

- (2) 假意 “宽容” 反对自己的人，以此来调整各种势力的组织结构

有的头脑人物，看到某一种势力的代表人物企图取代自己，乘他尚未足够强大之时，故意对他的非礼行为表示 “宽容”，甚至假装将自己的位置让给他，以此激起其他各种势力对他的不满和愤慨，从而使他很快丧失取代自己的优势，重新建立起一种新的有利于自己统治的平衡均势。

- (3) 容忍甚至重用品性恶劣的下属

为了维持各种势力之间的平衡，进而巩固自己的领导地位，有些领导者，不惜出卖原则，有意容忍，甚至破格重用某个与某一势力有联系的品行恶劣的下属。

![](img/7609f5d1ba4dd6250f5273e53c0ea3cb_1145_0.png)

- (4)权力均摊，在用人时充分照顾各方利益

为了缓和各种势力之间的矛盾，在选用下属时，不是严格按照用人原则来物色合适人选，而是充分照顾各种势力的利益，丧失原则，尽量选用代表各种势力的核心人物，头面人物，使各种势力对自己产生好感，拥护自己的领导。

- (5)适时制造矛盾，阻止各种势力产生不利于自己的联合

有时候，在各种势力之间，始终保特一定的隔阂和摩擦，对于维持领导者的有效统治，也许是有益的。在这一指导思想的支配下，领导者便十分小心地 “玩”起挑拨离间的把戏来。这样做，往往能收到巩固自己的地位的奇效。

值得指出的是，从人才管理学的角度来看，在日常生活中，确实也存在着一些属性不甚清楚，界限不甚明晰的维持平衡的用人行为。这些行为，通常出现在用人谋略和用人权术的“接合”部位。作者认为，从理论上说，对这些界限不甚明晰的维持平衡的用人行为，依然是可以鉴别和区分的;但从实践上说，要做到这一点，却十分困难，而且有时也没有什么必要。为此，遇到这种情况，只要领导者认为，选择某一维持平衡的用人行为，有利于获取显著的社会效益和人才效益(用不是单纯谋取个人的私利)，就可以尽管放手去做。

# 识别和提防玩平衡术的要诀

- (1)及时发现、制止个别领导者对各种势力不讲原则的调和、折衷、妥协、忍让行为。
- (2)坚持查处、纠正个别领导者有意重用品性恶劣的下属的失职行为。
- (3)发现个别领导者在各种势力之间有意制造矛盾，玩弄挑拨离间的把戏，应给予严肃批评教育，情节严重者，应及时进行组织调整。
- (4)发现个别领导者出尔反尔，一会儿将下属抬上天，一会儿又将下属按下地，应及时撤换这样的领导者。
- (5)对于各种玩平衡术的用人行为，最彻底、最根本的防范措施，就是建立一套科学的人才管理制度，从制度建设上为根治这一用人权术提供有力保证。
- (6)自上而下，搞好各级领导群体的思想建设和组织建设，取消家长制、一言堂的领导恶习。
- (7)让广大群众参与各级领导管理活动。

# 小人能得利必定有这些因素

职场上的人员形形色色，千奇百怪，在职场这个大舞台上，每个人都扮演着不同的角色，生旦净末丑，将职场变得分外的复杂。职场如官场，芸芸众生、悲欢离合，让职场与官场一般显得分外扑朔迷离，平添了不少的神秘感。

唐宋八大家之一的欧阳修在《朋党论》一文中说：“小人无朋，惟君子则有之。其故何哉？小人所好者禄利也，所贪者财货也。当其同利之时，暂相党引以为朋者，伪也；及其见利而争先，或利尽而交疏，则反相贼害，虽其兄弟亲戚，不能自保。故臣谓小人无朋，其暂为朋者，伪也。”

由此来看小人还不是一个一个的出现，通常是一窝一窝的出现，结党营私，损害公义，甚至为了谋取私利不惜大肆陷害忠良。假如之间有了利益纠纷，马上就会反目成仇，然后狗咬狗一嘴毛。假如有了足够的利益，就会产生背叛心理，即使是亲戚朋友也会将之抛弃，甚至会出卖，小人们追求的是短期利益，就像股市上的投机行为，哪有利益就会往哪钻，或许这些人也会有修养，但是绝对没有人格，因为他们的人格是用来出卖的。

大体还有脸面的人还知道什么叫礼仪廉耻，可是小人没有，所以小人做事经常是肆无忌惮，孔子说这就是小人们的中庸。《中庸》原文：“小人之中庸也，小人而无忌惮也。” 所以小人做事可以撕下脸皮，不会有什么顾忌，唯利是图，而且手段无所不用其极。历史上的小人做了些什么呢？有豆子的，有吸脓的，有尝屎的，有做零号的等等，小人们又做了些什么呢？大肆结党，陷害忠臣良将，毁坏国家社稷，以至于民不聊生，饿殍遍地，而现在职场小人虽然在行为上或许没有以前这么露骨，但是绝对是学会了古代小人的精髓，打听上级有哪些喜好，然后进行逢迎满足，打听上级有哪些需求，然后费尽心思去迎合。甚至将为上级处理私事当成工作，上级对于他们而言没有一分秘密，由于掌握了上级的兴趣爱好，更会满足上级的兴趣爱好，这些人成了上级最离不开的人。

相比之下那些职场君子做了些什么呢？为了工作与上级发生争论，为了公利与那些破坏规则的人发生纠纷，为了公司利益兢兢业业，这些人的心思只放在了工作本身上，从未想过职场钻营之道，在这些人心里或许根本就没有这样念头。然而小人们又做了些什么呢？恶意中伤，背后造谣，挑拨是非，无中生有，栽赃陷害，排挤倾轧，最终败坏了整个公司的工作气氛，搞得所有人整日里人心惶惶，唯恐祸及自身。假如别人工作取得了功绩就会肆意打压，先是贬低别人，然后在鸡蛋里挑骨头，接着自我吹嘘，十足是专家能手的派头，最后是将别人的功劳据为己有，恬不知耻，不知仁义为何物。假如在分配工作任务的时候进行精心挑选一些相对简单的工作，即使分配下来以后，也会费劲心思地活动，唯恐自己吃了亏，做了一些难度比较大的事情，因为能力只在钻营上，工作能力很差，在途中又绞尽脑汁地请别人帮忙。在工作已经完成或者即将完成的时候，将请来帮忙的人一脚踹开，甚至还恩将仇报，在邀功请赏的时候，专走领导路线，先将别人的工作说得一无是处，然后再说别人的工作难度与自身比起来微不足道，其实目的很明确：贬低别人，抬高自己。即使有拼不过的情况，那么就在私下里活动：和上级领导活动，争取上级领导另眼相看，和有功之臣活动，意图能够分一些功劳。而一些上级显然耳根软，诱惑多，禁不住这些亲信在耳边磨，禁不住这些贴心人逢迎，在加上这些人专精钻营之道，善于揽功推过，陷害忠良，上级会认为这些人不仅忠心而且能干。

因为能力不足，难以形成影响力，所以小人们就会拉帮结派，在公司里称兄道弟，好一副热闹的场面，因为声势浩大、牵连甚广，因此其他人无不退避三舍，不敢缨其锋。而这种帮派中的人员如果占据了一些关键岗位就会排挤其他有能力的人，因为这些人可能会危及自身的地位，如果没有，就会将眼睛盯在坐在关键职位上的人的一举一动，稍有动静，就会趁机而动，目的就是目标扳倒，让自己人坐上了那个职位，然后尽可能斩草除根，以免留下祸患。接着他们就会将工作重心放在上级领导上，假如因为能力不足出了什么差池，就找个替死鬼代替，有时候甚至连‌“自己人‍‍”也不放过，然后跟上级领导说：‍‍“都是那个人的错，我本来是要这样做，结果他自己太自以为是，才将事情搞砸。‍‍”总而言之，自己总是对的，即使是错误的也是正确的，因为自己是他们的上级，下属只是他们推卸责任的工具。

由于经常在上级领导身边活动，那么就会和上级领导及领导身边的人混个脸熟，甚至也会走曲线，先去迎合上级领导身边的人，比如：家人朋友，司机、保姆、甚至连清洁工也在其内，其活动能量也太过惊人，为什么？因为这些人的生存之道就是这样，假如不这样做，职场上根本不会有这些人的位置，而上级领导本身也是苍蝇不叮无缝的蛋，谁没有七情六欲？而这些人似乎生来就是这方面的专家能手，工作能力或许很差，但是胜在忠心，一心为上级着想，因此也能在上级面前游刃有余，占据一席之地，甚至能够影响左右上级的决策。

而职场君子们似乎太单纯，太迂腐了些，只会将心思放在本职工作上，有时候为了工作难免与上级闹得不愉快，或许有些行为方式没有迎合上级的思维方式，甚至与上级背道而驰，惹得上级不喜欢。而那些有能力的人往往也比较有性格，常常让上级领导感觉到不听话，不好控制、不好管理，在上级手里既舍不得放下，又觉得扎手，这样的人上级绝对不会倚为心腹，因为对他们的控制不能如同手臂般随意，用则用之，但是心理会进行防备，以免事情脱离自身的控制，而且上级领导也会依靠这些人来出业绩、出成绩，因此会在有用处的时候扶起来，无用处的时候置之不理。

想想以上的这些情况，除了职场小人以外，还有那些人能够在职场上活得有滋有味？蚂蚁咬死象，即使一个人再厉害，也双拳敌四手，何况是一堆堆、一伙伙的上？因此和小人帮派有利益冲突的精兵能将纷纷败下下来，因为他们根本不是什么“精兵能将”，妨碍了小人帮派的利益的忠臣直臣无不死伤惨重，因为手段毒辣，有的是办法证明你不是什么忠臣直臣，而你根本就是一个“奸臣”，而公司企业空降过来的人才无不偃旗息鼓，因为在小人当道的企业里寸步难行，最终也只能证明自己不是什么人才，只是一个“庸才”。于是忠臣、直臣、能臣、贤臣日退，而奸邪小人日进，而上级领导在包围中，将这些人倚为长城，在一番手段之下，上级领导认为除了这些人以外再无人才。

再回看现在职场上的情形，没有人能够将全部心思放在工作上，也出现了很多书专门写在职场上的钻营之道，为什么？小人毕竟比其他人能够更好地在职场上生存。职场险恶，上有雷霆雨露，旁有明枪暗箭，即使有能力统御好下属，做好本部门工作，也不能保证在职场上的前途。而那些职场的君子们在深受其害之下，不得不研习权术，不仅为自保，也为寻求进身之途。一块臭肉坏了满锅汤，这句话虽然粗俗，但是也有大量的例证，因此职场上的君子们要时刻警惕着，别让自己成了小人们的进身之阶，而沦为公司斗争的牺牲品。

# 看清这几点明白你是否被利用

我经常说无论是职场还是官场，你是上司的人但是上司不一定是你的人，很多时候你为上司卖命，到头来才发现上司早已经把你给卖了，因为很多时候上司表面对你非常好，但是内心并没有把你当成自己人，什么事情都让你去干，结果到最后才发现他只是把你当成棋子，这样的上司在职场中是非常常见的，那么如何判断上司是不是把你当成长自己人，有五项标准对照：

一，是否让你加入他的圈子。职场中有各种各样的圈子，比如酒圈、麻将圈、篮球圈等等，这些大圈套小圈、圈圈相扣，进入这些圈子你就能了解信息、分享资源，从而达到资源共享的目的，所以职场中如果上司把你带入他的圈子，办事从来不对你避讳，这就说明把你当成了自己人。

二，是否为你办理私人事情。职场中新人刚刚参加工作，往往没钱、没本事、没关系，比如要孩子安排一个好学校，给老婆换一个好单位，职场中如果遇到这些事情，求助于上司，上司爽快答应，因为在这个社会人情用一次少一次，上司为你的事情肯动自己的人脉，对你的器重可见一斑，这样的上司可遇而不可求，这样的上司你一定要好好珍惜。

三，是否为你承担摆脱责任。职场中做的事情越多，那么错的也就越多，有时会出现一些岔子，得罪人不说，可能需要承担责任，如果说上司主动靠前为你化解，用于承担责任，把错误揽在自己身上，这说明他们内心不坏，特别有人情味，是非常值得你的跟随的。

四，是否和你谈论各种事情。职场中上司是上级，同样也可以是朋友，在闲着没事的时候和你拉拉家常，谈论单位、社会的一些事情，这些事拉近你们关系的润滑剂，彰显你们的关系不一般，如果有事的时候叫你，没事的时候对你爱答不理，只是一味的让你工作，那么你就需要好好的考量一番了，因为这说明上司并没有把你放在心上。

五，是否为你指明职场前程。职场中刚参加工作的人都希望在学一点本事，而职场中的老人则希望有一个好的岗位，总的来说都是希望有一个人為自己指明职场的前程，如果上司肯为你的前途上心，那么你比别人就多出更多的优势，获得别人的指点也是需要代价的，你任何事情都没有付出想不劳而获这是天方夜谭，只能是竹篮打水一场空。

无论是在官场还是在职场，一切都没有善意、也没有恶意，只有生意，没有比较级、最高级，只有上下级，所以官场或者职场中碰到一个好上司那是一种运气，如果你的上司满足这 5 项条件就说明非常难得，你必须回报上司对你的知遇之恩。

# 深挖 4 大潜规则

职场是一个神奇的世界。在这里，你可以看到团队协作的力量和伟大，也可以看到尔虞我诈，你死我活的无休无止的争斗;你可以看到睿智和龌龊并存，也可以看到善良者的狠毒和阴险者的良善。人类所知晓的各种兵法计策与厚黑谋略也在这里得到了发扬光大。职场如同战场，胜者为王败者寇，虽无流血却有牺牲，同样残酷惨烈;职场如同江湖，权术与智谋在这里激烈碰撞，智者和愚者轮翻较量，有小隐在野、大隐在朝，高手云集，各显其能。今天时代光华网要说的就是：中国式职场与4大潜规则，提高自己身的职业素养。

潜规则，顾名思义，就是暗藏的规则，是话中应有之意，但话表面不说明，靠自己去意会。公司政治这个潜规则当然也不是白纸黑字标出来的，而是约定俗成的。强调政治是人与人交往的一种关系，而不是厚黑学，上升到厚黑学的层次就有些可怕了，政治素质只是在职场生存及发展的必要条件。

要明利害，分清首要利害、次要利害。生存、内部竞争与末位淘汰属于首要利害。如一个公司两个高层势不两立，见着就掐、咬，不一定是他们个人有什么恩怨，很可能是他们的生存互相冲突，受到彼此存在的威胁。内部竞争则是一把双刃剑，采用末位淘汰的机制，刚开始也许可以提高业绩，但是从长期来看是一种慢性自杀，容易导致员工之间的互相倾轧和不正当竞争。分清首要利害后，还要辨别次要利害，这样才可以进退自如。

# 潜规则一：不要凸显自己脱离团队

“团结就是力量”是中华民族一直奉行的传统理念，但在工作状态中保持住这样的风范就不那么容易了。虽然美国崇尚的“个人主义”从表面上与“团队精神”有矛盾，但是老美们在工作中的确处处都在强调着“团队精神”。假如你来到一家外企公司工作，因工作能力突出业绩斐然而很快连跳几级，达到了“高处不胜寒”的位置，但却因为一时得意而忽视团队的存在，不仅与下属和同级同事很少沟通，在工作中出现分歧时还一意孤行，结果导致与团队间的关系很不融洽，工作无法进展。
