# 不用强势下令，也能使人服从

# 孙叔敖的仁慈领导：引导而非命令人民

楚国宰相孙叔敖原本是隐居的贤人，直到上一任宰相虞丘把他推荐给楚庄王，结果只做3个月的官，便晋升为楚国宰相。有两个小故事可说明他是循吏。

楚庄王不满意原来流通的钱币过于轻小，颁令改为大币，但人民却不习惯使用，因而引发市场萧条。孙叔敖认为，此事须考量国民的喜好与需求，劝楚庄王恢复通行小货币。改回旧制后，市场果然繁荣起来。

此外，楚庄王认为，国内使用的马车过于矮小而不利於马奔跑，因此打算下令全国将车子加高。孙叔敖觉得，常以命令变动国事，会让百姓无所适从，如果车身非改高不可，不如垫高城门的门槛，一旦矮小的车子无法顺利通过，民众便会自动改造车身。孙叔敖关怀人民的做法果然奏效。

孙叔敖施政相当宽松，但对于想要禁止的事却又能有效防止，官吏们不会违法违纪，人民都洁身自爱，几乎没有窃盗的事情发生。他也积极关怀人民生计，教导民众在秋冬季节进入山林伐木，春夏多雨季节再将木材顺流运出，使百姓可以过着富裕的生活。

司马迁称赞孙叔敖，不用下令就能感化人民，让人民信赖，身边的人都效法他做事的方法、远方的人也来观摩他的言行举止。
