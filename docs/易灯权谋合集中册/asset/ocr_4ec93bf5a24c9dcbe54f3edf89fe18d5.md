# 权谋操作技术布局

<布局>是谋略方法学中的核心课题，到底什么是谋略的布局呢？我们先来看布局的局，局是整体中的一部分，在礼记曲礼中就有左右有局，各司其局的一段话，而根据郑玄的注，这里一局一即是部分之意，类似今日政府机关中称呼分治一事之处所，即有教育局、工业局、公路局……等皆是取其整体中各有司之部分之意。

布是什么意思呢？布同布，布是用线经纬交织而成的织物，引申在动词方面就作全盘性、系统性的敷陈、安排之意，布和局连结起来，就是把全体的各部分，各就各位敷陈好。布局之意恩掌握之后，我们再回头来看谋略，谋是什么呢？谋是言某的组合，是一种少数几个人在交头接耳秘密密度计划的行为诗经小雅皇皇后华篇中，有所谓同爱咨谋，传曰：咨事之难易为谋其意即与言某相近而略又是什么意思呢？略是田亩的组合，田系在大地上划地筑埂种谷，以井田制度的井田来说，它即是一套划分土地权义的蓝图或计划，依此略的意义就出来了，它是一套做事的轮廓计划或大纲。再把谋略相连起来，我们就可以了解谋略是一种隐藏不外显的做事计划，这种计划的目的特别是要使事情的发生，一切都控制在预设的情况下，以遂行其目的。
