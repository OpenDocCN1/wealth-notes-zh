# 六、达成目标

不管你的执行力有多强，其实最重要的还是达成目标。管理的本质就是达成目标。这要求我们在做任何事情的时候，一定要不断地问自已：“我正在偏离目标还是达成目标？”当然，达成目标的能力需要我们学会系统思考、看透本质、找到核心驱动力，最后要能突破、能坚持。
