# **缺乏安全感上司**

有46%的新经理属于没有安全感的管理者，他们习惯将所有权限或大大小小的事情捏在自己的手上， 匿藏重要的工作信息，希望手下员工离不开他，只有这样，他们才有“稳坐钓鱼台”的安全感。

他们很少授权或者根本不懂得授权的意义，情愿自己忙得像陀螺，也不愿意给团队成员指派工作安排员工可能，更谈不上指导或培训。这类上司喜欢受命执行、听话、不好挑战其权威的员工，更有些人 从不雇佣比他们聪明的人，他们的团队就是“白雪公主与7个小矮人”。
