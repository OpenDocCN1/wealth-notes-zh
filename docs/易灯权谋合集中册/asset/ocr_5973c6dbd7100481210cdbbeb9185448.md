# 历史背景

乾隆三十四年，承袭三等轻车都尉。寻授三等侍卫，挑补黏杆处。四十年，直乾清门，擢御前侍卫，兼副都统。次年，遂授户部侍郎，命为军机大臣，兼内务府大臣，駸駸乡用。又兼步军统领，充崇文门税务监督，总理行营事务。

《清史稿•卷三百十九•列传一百六》

和珅曾参加乾隆三十四年(1769 年)己丑年科举，但名落孙山。他以文生员承袭三等轻车都尉。具体来说，这是从事管理最卑微士兵的职位。由于和珅的精明能干，乾隆三十七年(1772 年)，22 岁，十一月，被授予三等侍卫。终于在二十三岁的时候，得到一个机会，做了皇上的仪象队的侍从。具体的工作是抬轿和举旗杆的。由于他懂得利用机会，在乾隆面前展示自己的才学，终于在四年后，当上了大臣。有一次，乾隆帝准备出外巡视，叫侍从官员准备仪仗。官员一下
