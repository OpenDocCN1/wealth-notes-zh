导也许会用另外一种方式回报你，那就是把你摆到更重要的位置，让你也更有面子。

# 三、寻找职场中的贵人

王立群说过：“人的成功有三条路径：高人指点、贵人提拔、小人监督”。在职场中，能不能得到关键领导的赏识至关重要。工作中一定要想办法引起领导的重视，进入领导的视野，然后通过一些公关手段和领导保持交往和沟通，时间长了，必有斩获。

# 四、与顶上上司处好关系。

其实，顶上上司对你的评价至关重要。要处好与顶上上司的关系，最核心的是要尊重他，要多向他请示汇报，要认真执行他的各种指示，做到“到位而不越位”。让顶上上司想到你时，一定要有一种“给力”的感觉。
