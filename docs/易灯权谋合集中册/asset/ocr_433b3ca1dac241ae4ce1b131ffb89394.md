# 如何应对领导甩锅

一般来说，作为下属，对一些无关紧要的小锅，我们是可以主动去背的，如果领导有良心，会看在眼里，记在心里，在其他地方给我们找补回来，比如年终奖多发点，绩效奖金多给点，提成丰厚点。

但如果遇到那种领导，功劳自己独享，背锅扔给下属，遇到这样的领导，我觉得就不要在他手底下干了吧，良禽择木而栖，这样的领导也干不长，一个优秀的团队领导者必然是责任自己承担，好处团队共享。

现实中还有一部分人由于经济的压力，以及更好的去处没有找到，只能在这种领导手下接着干，那也有办法，就是凡事做好记录，尽量走邮件，聊天记录保存，会议谈话录音，这样等大领导问责下来，也可以直接发给大领导，写一份言辞恳切的邮件，邮件中首先承认自己工作没有做好，同时把自己被甩锅的过程说一下，然后表示自己愿意承担项目没做好的责任，最后把相关邮件、谈话记录、录音作
