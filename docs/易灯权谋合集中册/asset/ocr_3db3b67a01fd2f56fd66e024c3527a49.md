# 明太祖：按部就班得江山

明太祖是另一个创业成功的开国皇帝。他是一无凭借的贫苦孤儿，依附佛寺为僧，然后投入红巾，以其勇力，由郭子兴的卫士，逐渐独当一面，逶迤中原，荡平群雄，高举抗元民族主义的旗帜，驱逐蒙古政权，建立汉人的明皇朝。朱元璋能如此作为，当然有其雄鸷过人之处。论其用人，他以淮西功臣为将领，以浙东儒生为谋士，缺少宏大的气魄。他的谋略**广积粮，高筑墙，缓称王**，是在厚植实力的阶段，保持低姿态——这是稳扎稳打的策略。先灭陈友谅，后打张士诚，是由于后者恃富自保，不足为患；也由于前者占有的长江流域，腹地广大，进可攻、退可守，而张士诚的江南，虽然殷富，却偏居东南，不在要冲。削平群雄后，朱元璋才全力驱逐蒙元，一则当时蒙元已衰乱不堪一击，二则还是采取稳扎稳打的基本战略。凡此都是从保守中求进取的策略。朱元璋的开创业业，其做法与刘邦豁出去的作风相比，当是谨慎有余，进取不足。
