# 权术到底是什么

谋略学程序论中，最重要的四部曲，一是机识，二是权衡，三是决，四是布局，机识相当于决策论中的问题认知与情报分析，权衡相当于决策论中-对第方案的拟设与可行性分析，决相当于决策论中的方案评估与选择等，布局则是方案的执行。
