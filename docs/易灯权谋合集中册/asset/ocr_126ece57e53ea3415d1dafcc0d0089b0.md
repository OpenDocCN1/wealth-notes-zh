# 2、 挟知而问

意思就是自己知道结果，但是还要询问，看看他们是不是做了掩饰，不是真的对主子忠诚。宋太宗刚刚即位的时候，威信不是很强，手下人是不是真的忠心听话，不知道。恰好，微服私巡的时候看到一个乞丐和一个店家争吵。于是，宋太宗直接用刀杀了这个乞丐。留下刀走了，让京城市长查案，很快结果出来，是店家杀的，还有口供。这时候太宗拿出刀鞘，直接把刀要过来合了进去。太宗说，你们这样办案要冤杀多少好人，极度震慑了下属，立威而成。其实这样的做法在很多时候都在重复的上演。看胡雪岩的时候，胡雪岩一开始在钱庄干小工，扫地，发现地上有几枚铜钱，于是捡起来交给了东家。东家说你不用扫地了，去柜台帮忙吧。其实这几枚铜钱就是东家故意放在地上的，用来测试胡雪岩是不是一个贪钱的人，如果他不交出来，以后一辈子可能就是扫地了。用已知的结果来考验你
