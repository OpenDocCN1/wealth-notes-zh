# 项羽：败在能胜不能败

在反秦与对抗项羽的过程中，刘邦几次关键性的决定，却不能说是凭血气之勇。他在不断扩大自己的力量时，接纳了不少人才：张良与韩信是其中最著名的佼佼者。他听取伙伴的建议，信任他们的能力。在诸军忙于战争时，刘邦疾驰入关；又听取萧何建议，获得当时全国户籍、赋税档案与舆图。这一大批资料，使刘邦有了全国形势及资源的资讯，为当时其他武装集团所未有。

刘邦从汉中潜出陈仓，掌握了秦国故地，关中表里山河，易守难攻。毗邻的巴蜀、陇右，属北方边郡，握有盐、铁、战士，与马匹等重要资源，是其能取得天下的重要原因。天下既定，刘邦又听取娄敬建议，定都关中，也是为了继续掌握这些资源，高屋建瓴（编按：比喻居高临下，形势无法挡），控御东方。—这些计算就不能说是偶然的幸运，而是他能接纳他人的建议。
