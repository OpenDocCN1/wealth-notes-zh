# 厉害的沟通术，员工服气又有动力

现在的职场里，有愈来愈多人拒绝升迁，因为除了既有工作量，还必须多负担其他人的责任与情绪。

许多分歧与误会，都是因为指令与回答不够明确，或是彼此顾忌不敢说实话而产生。

换句话说，许多不满与冲突，都是因为沟通无效而起。主管无法确定员工是否真的收到指令；就算接到命令，员工心里不服，做起事来也没动力。无论你是自愿当主管，抑或是被升官，都必须理解，沟通的重点不在于天赋，在于能如何减少不必要的误会与冲突：

+   1. 让员工自己安排进度

每个人都不喜欢被规定、被指使，当你有想传达的事情时，用问的方式跟员工沟通，让他们自己思考、安排工作进程。比方说，3周后要客户提案，你觉得什么时候完成草案比较好？这样的方式能让部属依据自身能力，提出可达成的时间点。
