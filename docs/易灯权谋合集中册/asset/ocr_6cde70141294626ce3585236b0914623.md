# 麻烦：不知哪里得罪了同事，大家都很讨厌我，我打不进他们的小圈圈，怎么办？

对策：在军中，搞不清状况的菜鸟被称做**天兵**，在职场上也不乏天兵，最大特征就是**白目**，总是做些惹人厌的事，对人际交往的分寸、职场的基本生态，简直一无所知，对别人的情绪反应也漠不关心。

这类型的天兵，连自己的问题出在哪里都不知道，更不知道如何去改，最后落得被大家讨厌及排挤。

被同事排挤必定事出有因，不妨请同事坦言相告，了解自己究竟哪里有问题，例如情绪化、自私、不守信用、爱说是非等，改进之后，再想办法建立人际关系。

在同事相处上，不要一心想等着别人采取主动，**就像男生在追求女生一样，要主动示好、借故交流**。
