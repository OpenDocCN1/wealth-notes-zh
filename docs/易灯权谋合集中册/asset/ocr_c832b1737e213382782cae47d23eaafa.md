# 靠近给你带来机遇的人

在人的一生中，不能把注意力过多地集中在“机遇”上，而应放在提高把握客观规律的能力上。不能认为机遇会找上门来，所以自己就守株待兔。和珅的所有权利都是乾隆给的，他的人生因遇到乾隆皇帝而改变的，和珅更是不惜手段接近乾隆。

打个比喻在正常情况下，狗是吃不上牛肉的。不管是身材还是力量，狗和牛都不在一个数量级上。狗即使成帮结伙，也难以战胜牛。在自然生态里，狗捕捉不到牛，当然就吃不到牛肉。狗吃牛肉纯粹是沾了人的光。狗投靠了人，成了人的帮凶，才吃上了牛肉。为了吃饭就出卖自由，这是狗的活法。所以狗成了最早被驯化的动物。狗的经验表明，当奴才是很实惠的，依附权贵，可以改善生活，消除生存的不确定性。古今如此，连狗都不例外。
