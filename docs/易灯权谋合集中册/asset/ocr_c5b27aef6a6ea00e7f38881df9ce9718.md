# 部属叫不动管理的第一道坎

A 在公司做了五年工程师，经验愈来愈丰富，业务愈来愈熟悉， 很得同事和老板的信赖。有一天，公司主管希望 A 做自己部门的 直属经理，问 A 的意见。A 说：哪有什么意见，太好了！

A 第一次从个人贡献者成为管理者，很激动。可是，上任没多 久，他就遇到了人生中第一个管理问题——他的员工不如他。

交给员工做的事，得到反馈时，A 恨不得把报告撕得粉碎。 这都是什么垃圾啊！拿回去重做！可是，重做之后还是一样， A 简直要崩溃了。但专案等人，于是，他狠狠骂了一顿后说：算了算了，放着我来。

这样的场景，在全世界的每个角落、每家公司，每天都在发生。 A 确实用更少的时间做出了更好的结果。但这样正确吗？

当然不正确。A 犯了几乎每一个初级管理者都会犯的错误， 叫做看我来。拿主管的薪资，抢员工的工作，管理者愈来愈忙， 甚至成为团队的瓶颈，而员工却没有成长，更没有成就感。
