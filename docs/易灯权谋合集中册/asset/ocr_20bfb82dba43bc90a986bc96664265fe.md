# 权谋心智能量

人道有必然，天道或有偶然；
掌握必然以谋企其偶然，乾坤就可能转变。
而何者为必然？何者为偶然？又如何把偶然化为必然呢？关键就在“一机”一字上。

什么是机识？机与几字相通，是事物变动中至细至微的潜伏因子，易经上讲知几，其神乎！机者，动之微，吉凶之先见者也。换言之，机识即在识知事物的萌芽、发育、生长、甚至衰老、病死的变化讯息，并且掌握事物这种细微的变异轨迹，乘其初萌期，即加以改变或抑制或加以假借、寻用，以便于作成长管制，这是筹谋订策最紧要的一步。

韩信曾说到治天下之道，贵…识天下之机，…机者，辨兴亡、定治乱、穷几微、明隐伏，然后天下可得而图。亦见同样旨趣。
