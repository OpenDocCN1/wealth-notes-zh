+   4. 在未取得的充分信任的情况下，游说者尽说其
所知。如果主张得以实行并获得成功，功德就会被
君主忘记；主张得不到实行，其的才能就会遭到君
主的怀疑。（周泽未渥也，而语极知，说行而有功
则德忘，说不行而有败则见疑，如此者身危。）

+   5. 在有过错的君主面前情况下，游说者倡言礼义
等于挑他的毛病。（贵人有过端，而说者明言礼义
以挑其恶，如此者身危。）

+   6. 君主有时计谋得当而想自以为功，游说者同样
知道此计，如此就会身遭危险。（贵人或得计而欲
自以为功，说者与知焉，如此者身危。）

+   7. 勉强君主去做他不能做的事，强迫君主停止他
不愿意停止的事，如此就会身遭危险。（强以其所
不能为，止以其所不能已，如此者身危。）
