公司给的资源太少、其他部门扯后腿、公司产品本身有瑕疵等。如果运用得当，这位**监事**甚至可能被你**策反**，变成同情你的**传话人**，将你部门的窘境反映给上级，你反而因祸得福也不一定的！

# 麻烦：公司最近空降一个高官，而且带来一票自己的人马，我该如何跟他们互动？

对策：以人性来说，空降主管想要在短时间之内做出成绩的话，找一批自己信得过的人马班底，是再自然不过的事，**只不过城里（空降部队）、城外之间，需要时间加以融合。**

企业从外部礼聘专业经理人，通常意谓着旧团队出现问题，因此林涛认为，旧员工在心态上应该主动配合，**如果一直抗拒的话，公司很有可能会走向灭亡。**不要一心想着高层发生了什么事，而应该思考接下来你能做些什么事，如何在会议上求表现、如何做一场出色的简报等，以赢得新主管的信任。

而且，空降部队是否有真本事，很快就会得到验证，如果真是一块料的话，马上就能看出绩效，否则一块砖头再怎么用灯光照，还是一块砖头。
