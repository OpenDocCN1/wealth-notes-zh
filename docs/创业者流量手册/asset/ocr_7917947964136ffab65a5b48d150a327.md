抖音的路径，是切断一部分流量去电商商业化，要商业化收入、也要 GMV 产出，然后变成一个类似天猫的结构。

# 快手的逻辑是什么？

场景逻辑、私域逻辑、内容 IP 逻辑、信任逻辑。

接下来分开谈一下我的理解。

3.

快手是场景逻辑，人 in 场景中实现成交，让用户，也就是快手的铁子，在合适的场景中，消费到合适的内容，然后去成交。

场景逻辑不含满斗粮细运营的管理策略，和抖音完全不同。

场景电商与流量电商不同，甚至是相对的。

4.

快手是私域逻辑，是内容 IP 逻辑，以及信任逻辑。

这三个逻辑必须放一起讲，因为相互勾连。

快手给出的电商公式值得 mark：

GMV = UV * 内容消费时长 * 单位时长的订单转化率 * 客单价 * 复购频次

UV 是流量规模，这是流量端 DAU 的事儿，和生态玩家无关；

内容消费时长、转化率，甚至客单价和复购率，都和这三个逻辑有关。

内容负责在快手上是直播卖货，它是一个个在快手上的人与老铁，通过互动在卖货，而不是流量直达转化的落地页，这个和抖音是有差异的。

# 何为内容逻辑？

买卖的人之所以被关注，是因为做了他的内容，可能是有用的，可能是有趣，可能纯粹就是这个人好玩。

老铁关系之上后，拥有粉丝池，就必须要认真做内容，这就是 IP；

# 何为私域逻辑？

快手传统双列让用户花费更多时间关注了一个内容 IP，快手明确比抖音更强烈的保护这样的 IP 流量分发能力。

# 何为信任逻辑？

不断做内容，有不断大的粉丝，持续不断做内容、持续不断有粉丝，且粉丝因为内容的不断消费，增强对 IP 的信任，因此因为信任你，所以铁子买你的货。

这是三个扣在一起的良性循环，所以才有了俗说的，不要骗老铁。

5.

快手明确的私域 + 内容 + 信任 + 场景的电商逻辑，对商家和品牌来说，怎么入局。
