# 一、TikTok 对于中国互联网意味着什么？

TikTok 是突破主流美国互联网公司统治的全球互联网尖兵。

从 DAU 以及商业化的角度，并没有想象中那么夸张，但是从业务属性，以及全球视野下的互联网竞争格局来看，意义重大。

特别罗列一下，我们从 information 以及其他 source 里的一些信息，欢迎指正数据准确性：

+   1, TikTok MAU 估计为 8 亿
2, TikTok 在 2019 年下 Expended 7.38 亿次
3, TikTok 的总下载量超过 15 亿，使其成为 2010 年代下载次数第七高的应用程序；
4, 2019 年有 4600 万美国用户下载 TikTok；
5, TikTok 周留存率 26%，平均日使用时长为 45min，安卓 TikTok 用户在 2019 年花费 680 亿小时使用 TikTok；
6, TikTok 以 39 种语言在全球 150 多个市场上提供服务；
7, 根据路透社 2019 年 11 月发布的数据，美国 60% 的 TikTok 用户年龄在 16-24 岁之间。

总结一下，TikTok 为什么有着光明的 andre，为什么被寄托为字节跳动成为全球公司的第一桥头堡。

重点不在于 DAU 和商业化，这两个也在成长，与美国脸书，甚至与 Ins 都还有明显差距，但是核心重点在于：

全球突破，迅速崛起长；并且突破了以往中国公司永恒不能突破的内容疆界。

以内容平台的姿态进占美国市场，这个市场是全球 ARPU 值最高的市场。以往的中国公司，只能通过工具切入，而 TikTok 作为一家中国开发运营者的公司，第一次可以光明正大地在美军出击。

在最艰热、最为难的土地上，得到更大的流量池，意义重大、商业价值重大，出海公司貌似不可两美巨头——绕不开 Google、Facebook，哪怕是中国巨头。

出海要流量必然需要从两位爸爸这边买，DAU 不够大不能闭环，就只能接入巨头联盟变现。左手倒右手赚钱始终垄断且亏损。和国内的字节跳动生态内实事做 C 端产品是一样的。

而 TikTok，因为字节跳动决心成为一家全球公司，也有成长的勇气，以及商业化的底气，是强行撕裂开这个闭环。

当然羡慕，但是不急着变现，直接希望到全球所有主流国家的主流短视频平台。

中国的公司，在新的一波互联网内容革命中，抓住了短视频、抓住了算法推荐，迎来了这一波井喷。

这一波井喷最大的受益者，和引领者，是字节跳动。
