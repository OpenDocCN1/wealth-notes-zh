# 刘思毅的回答：

+   1, 个人微信
因为你们的客户数量不多，个人微信可以承包，在条件上看，其次，企业微信的朋友圈条数太少了，不 OK，最后，企业微信让你们真的穿着正装，我觉得不太适合建立信任；
2, 不适合打造你所说的「IP」
你想要的 IP 是明星，是意见领袖的话，那是不适合的，你要打造成的是你自己家用户可以想到，找到的客户经理，你要发的朋友圈要善于一个人营销的人设，而不是所谓你说的网红 IP；
3, 你做私域核心数据看几个：
第一，每天有多少潜在客户数从 1688 和其他平台加到你；
第二，每天你发了多少条和这个行业有关的，你的客户感兴趣看的朋友圈。
4, 补充每个点：
第一，成交是结果，不能强扰客户，不然客户会删除你；
第二，踏踏实实先承包和运营好你的已有客户，在私域，会有复购率和转介绍，不要期望私域带来爆炸增长；
第三，如果私域没有承包好，做抖音大概率失败，私域做好了，可以试试做抖音，抖音下课再说，先弄好私域。
