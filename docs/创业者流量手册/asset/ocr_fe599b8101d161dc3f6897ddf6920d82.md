# 四、企业微信是开放的，会永远开放，不管你选不选，都是腾讯的核心战略。

如题，这是我的判断，也是国平老师之前早就强调过的。

腾讯在 to B 端押注企业微信，从去年开始破例突破了很多微信的规则，一看就是高层的决心，突破了很多微信的很多克制边界。

简单说几个判断哈。

# 第一，企业微信已经逐渐成为电商保险教育大客户的标准工具，核心需求是：稳定大流量的批量运营，

以电商为例，所有 KA 都会把自己的日销售额导入企业微信，进行泛量转化；

# 第二，企业微信的服务商有机会，会出好几家上市公司，专门做工具的，但目前 SAAS 类客户的付费能力，太慢太弱。

# 第三，企业微信承接超级大的稳定规模日销售稳定订单流量，对于直播商家、天猫商家、网红机构，有重要的利润意义。

# 第四，企业微信对服务商会持开放友好的态度，比微信更开放包容地看他们的渠道服务商、工具服务商和代运营服务商。

# 第五，微信私域模型穷尽，变成为以下：1v1 攻单模型、企业微信洗量模型、IP 模型、服务号直营模型，洗量模型目前还是主流。

以上，总结一句话，张小龙杀音销售骗，只有好好为用户创造价值才能用微信号赚了钱。
