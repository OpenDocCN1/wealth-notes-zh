# 微信安全提醒

2020年6月19日 星期五

经用户投诉，并经审核确认，你在使用微信过程中存在违规使用微信账号、文明沟通。多次出现违规行为行相应处理。感谢你的理解与支持。

企业微信群发助手的规矩，每一条可以携带链接、可以携带一张图片或者小程序。 因此我们每周会群发给 4000 多位会员 3-5 条这样的「营销」信息，打扰肯定是有，因此会不断有人删除。 可以这是企业微信明确规则下的「营销」行为，好友也是合法渠道被动扫码添加，为什么就违规呢？ 封禁原因是「单聊传播广告」，那企业微信是否需要定义一下，群发什么才不叫广告呢，这世界限大模糊了。 群发助手一旦不能大规模对企业微信中的流量池使用，企业微信的很多功能都会被用户认为没有安全感，再加上企业微信还没有朋友圈。 那我们这是在绑羊献祭的 B 还是被用户企业微信，那又会回到原来的，用个人微信，打一枪换一处，相互防范、被管理而非互动和参与的状态中。 这个和微信本身的策划是否过背呢？

所幸，企业微信封禁只要不严重，是可以手工解封的，看作是一种微小警告。 但是令人不愉快至极，我想提醒的是，正是时刻刻的这样违疚、不安全、懊恼、焦虑的情绪，让我对微信很抵触。 另外接着看，由于企业微信绑定的就是我的个人微信号，个人微信号在被企业微信封禁功能 2 次之后，连续 3 天弹出这样的提醒，被谁投诉？违规在哪里？告诉我，告诉我，告诉我！

连带着的两个魔法效果，是朋友对我转账号被直接强行提醒，谨防诈骗，是否确转账的标志，要点击确认才能转账； 以及，我的微信 Mac 版一旦拉群过快、打字过快、多群聊天太多，就会被直接弹出，说我高风险。
