# 由此判断出，品牌做 IP 是一个伪命题。

因为创始人大多数都沉迷于研究抖音研究快手研究各种渠道，研究招聘，研究怎么公关各个渠道，
你让他像一个天天住酒店，天天写文章，天天见人，这是 impossible 的啊。
这件事儿，我为啥能干，是因为我的主业就是制造营销素材，让大家信任我，让大家对我感兴趣，
但是他妈的消费品创始人是要做供应链、做渠道、做营销的啊，天呐，你让一个创始人天荒夜。

# 第一，没有天赋，第二，没有时间，第三，没有兴趣。

那么，退回来，不好发的票圈，直接的反馈，
你品牌的核心私域只能用那么些恶心的方式去刷屏吗？
也不是，其实现在也可以用文章和票圈素材中台化 + 1 V 1 销售军团的组织形式去做品牌私域的。

可是问题又来了啊，这些人在直营大佬那边，一个月可以拿 15k - 20k，
但实在品牌这边，操盘手却特别一般惯通地向销售学习，而且流量、变现产品、一个比一个单价低，销售恐不齐齐。
那么这些私客，要做，就是全面私域直播答，能走吗？
能啊，但是可以走得更好吗？走不好……
品牌大佬我们还有借口，草泥马掉了。

# 所以呢，我觉得是兄弟们呢，不消费品私域不像我这样做，是因为创始人心力根本无法这样啊，
所以他们只能用企业微信批量承接粉丝，然后批量私截，批量发圈，批量发券，
批量出 GMV。

虽然早晚都会死的，但是死之前，让这些流量给我创造一些利润回填吧，
以及这些企业微信粉丝，至少让我看上去很有安全感啊。
这样做品牌私域，成为了基本操作，但是这样做浪费时间又赚不到钱……
品牌创始人别做私域了，你要是想这样做的话，就是想白嫖，
就是你一颗夜就，就系想非常荒诞地一波流。
但是你想啊，你的用户已经在天天源买过一次你的东西了啊，
他拿着券再在微信买一次，不就是只节约了一层天猫流量费用吗？
有毛用啊？？？？？？？？
