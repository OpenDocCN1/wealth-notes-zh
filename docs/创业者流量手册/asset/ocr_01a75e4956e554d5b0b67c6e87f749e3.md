# 群响
搞流量，来群响

阿里封禁的原因很简单，微信本身作为 IM 就是一个巨大的流量黑洞，如果微生态去中心化的交易，不能回到手机淘宝，那么阿里无法收取平台的流量费。

阿里从来在内容、社交、搜索这几个维度，掌控过任何自持流量。

阿里的流量全部来源于其他内容平台、社交平台，而砍断百度、砍断微信、封杀蘑菇街美丽说，以及和抖音目前这么拧巴的关系，都是由于自己对流量的终极不安全感。

微信的反制，在这个 Case 上，也是顺势而为，整个微信生态，要产生交易额啊，那么这些交易，先什么要留出去。

我十分尊重张小龙爷爷在产品上的洁癖和价值观，但实在有为上，腾讯有超额充实的动机，让所有交易、所有流量，全部在微信互联网上实现内部流动。

这大概是，一个 IM 互联网的终极想象，微信本身就是互联网，也是一个超级大平台，但凡要增长，就摆脱不了的路径。

# 三、于是，微信互联网出现。

于是，我们这样的微商、社群、公众号内容、小程序创业者出现。于是很多微信封杀的 Case 出现。

很多人 的资产都在微信上，在服务号上，在小程序上，在企业微信上，在个人微信号上，在社群里，三宫五地出来一些老板，一招不慎，所有流量资产全部被封禁，直言天台见的比如皆是。

更惨的是，有一堆客户老板们，所有的关系维护全部在微信生态。不明确的封禁规则直接打击后，直接让他们和客户之间的联系消失，而腾讯微信客服，是最不容易打通的电话，要知道自己的个人微信号，为什么被封禁，比登天还难。以往神农、铁总们心知肚明，但铁总们很无奈，找诉无门，暗地骂娘。

但似乎我们这些互联网从业者都已经把它当作平台的已有规则。无所谓又无理取闹的微信，似乎已经这么理小小龙似乎有自己的洁癖，但工人们爷爷的大锤、国家反垄断的大锤，已经敲响。

# 四、天скет微信封禁久矣！天下若微信互联网久矣！

一鲸落，万物生，绝对支持反垄断打破「微信互联网」「阿里互联网」「抖音互联网」，以及若干个隔绝的封闭中国平台互联互通。

我和超级大平台的 SVP 则过，她说，她实在反垄断后时常在想，超级大平台的出现，是不是过于垄断、过于集中了？对内容、对数据、对算法、对个人信息、对用户资产的全部集中，然后成为平台的商业价值的依托，这是对的吗？当时不明自，现在开始想，好象我们这些创业者，以及超级大平台，都是国家、人民、这片土地上的寄生虫，
