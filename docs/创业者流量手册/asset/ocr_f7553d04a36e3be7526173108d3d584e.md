# 对企业：有创新的精准、裂变营销

其实企业定制红包，在去年就开始有了，只不过去年的 เพราะ 时候，定制红包的个性化空间很小，只能在红包封面写上自己的企业名字，以及在打开之后的上方，展示一张图片，其余就没有任何空间了。2020 年的春节，微信也没有就定制封面，进行特别多的 KA 级别的联动推广，但是今年却不一样。

今年，企业定制红包增加了如下功能：

+   1. 支持企业可以定制更多样的红包打开后的详情页交互，包括图片、Gif、视频，垂类号中的 1min 之内的视频
2. 支持企业在微信搜一搜之后，与用户联动，送用户企业定制红包
3. 红包皮可以通过朋友圈投放的方式，与用户互动送出
4. 红包皮发放出去之后，支持链接：MP 文章、视频号、小程序、公众号等
5. 红包皮领取方式包括：链接、二维修码、序列号，可以在小程序、H5、搜一搜、品牌公众号中，让用户领取
6. 支持企业上不封顶购买红包皮，1 元一个，N 个用户领取，则花费 N 块钱，这是工具费

以上是企业的红包皮的规矩。我收集了很多很多企业的定制微信红包，非常非常地有意思，漂亮、且有营销精准的 to C 路径，且一直在我活跃的很多群流传，而且微信搜一搜和官方，都直接明确地推送了很多 KA 的红包上线路发时时间。可以先看看图。
