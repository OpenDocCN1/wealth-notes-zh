# （一）抖音资讯

# 1、字节跳动给你的，和你会失去的。

字节跳动是一个神奇的公司，吸纳了无数多创业失败、创业成功的人，还有无数从阿里、腾讯、百度这样的「百足之虫死而不僵」的传统公司进入的强悍候选人。基于笔者 5000 人黑圈中接近 200 人的字节跳动纯度，以及我武断的自我观察，来为即将去头条的人类一个总结，也给那些已经离开头条的宝贝一个总结，欢迎批判、欢迎撕逼。

首先，头条能给你什么？
第一，一个拿大额预算、一大波资源，基本在尝试的时候没上限，头条是一个用一个名字来命名新 App 都需要在信息流上一波 AB test 的公司，这意味着，爽歪歪的预算资源自由度；
第二，在中国迄今为止还在增长，还在野蛮式爆增长的公司是一件令人感到某糠和幸福的事情，荣耀的是有增长的就是好玩！
第三，对于某些人来说，工作体系非常美丽，在一个组织力量非常强大的 C 端产品公司工作，很爽；在一个周围都是兢兢业业希望做出业绩拼命努力的同事环境中工作，是有共同语言的。
第四，头条对于目前的互联网公司，特别是钱 To C 的社交、内容、电商平台的公司，是一个目光环，至今还有。所以越早进去，过一遍头条的 tag 加工，是非常有必要的，一个头条增长前 10 员工，可能会被外界 Tier 2 的公司开价很高很高很高，邀请你来所谓的「头条认知」变现，实际并不能，因为别的公司没有头条这样的散钱能力、组织能力、现金储备。
最后，在头条。你将失去什么？

第一，你将失去大部分周末和工作日的晚睡，始终创业，Always Day One 让你失去很多睡眠、休息的时间。大周、小周周末只能甩开，因为真的很累很累很累很累。这是互联网织女工，在头条的戏码，伪佛教天上演绎好，其特别以 25 岁左右的基础 PM、工程师和运营为主受冲击对象。
第二，因为数据数据数据数据是一切，你可能会丧失同理心和直觉，同事可能搬运大狼，大力出奇迹大狼。所以说从头条出去的典型面相都是觉得四面都是你的假想敌。
第三，你将失去创业的勇气，首先因为头条真的太强了，所以你觉得做 C 端产品育成干不过他；其次是头条太累了，没有时间想自己的方向；第三是 App 的运营和操盘，也没啥对创业的积累，新一代的创業者需要流量懂电商懂运营，然后 Day One 创造现金流，头条宝贝发现自己出去只知道花钱。
