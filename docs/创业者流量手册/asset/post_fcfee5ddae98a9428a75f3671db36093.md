第二部分、精准粉丝的私域运营，缺一不可！事实上，我之前写过好多案例，都是在说这个领域。
之前说的那个自播的品牌铁子，之前的那个微商大佬，都是这个的经典案例。

内容带来信任，信任塑造了 IP。但是内容要是带来的是不够精准的粉丝，说明白内容不够垂直，不够垂直的内容带来泛粉。这样的粉丝需求不刚、需求不频繁、信任度不高、流失率高，还需要继续筛选和漏斗漏下去。

私域运营要可以运行，必须要持续的流量反馈，精准流量筛选下来，恰好进入私域。

私域里通过自己的社群、朋友圈的持续创作内容和互动，特别是和 IP 有关的内容的互动，加强信任、加强 IP 曝光，平时养粉，活动成交，也持续成交。

这一套，可以抽象到任何一个高客单价、高复购、高毛利的业务中。特别是教育类、服务类、社群类、以及美护肤养生等服务驱动的电商品类，非常建议各位相关创始人和会员学习。

当然，这一套方法论理解非常大白话，但是要执行起来，需要以如下能力，大家可以盘点一下：

- 在不同的平台中，对自己业务对应的目标用户的理解能力
- 持续的原创能力，团队可以赋能，但是 IP 必须参与，由于 IP 是关键，因此需要 IP 和这个公司强绑定，最好就是公司的 CEO 和联合创始人
- 在公域流量中分发内容，持续引流的能力
- 私域的每日运营和转化，这是私域的基本功。

## 107、论垂直媒体的商业价值

媒体的商业价值被之前的我忽略，是在近期才明显发现的。

有 3 个例子让我发现，

第一个例子，微商圈子中的龚文祥和胖老板
微商中的有一个叫胖老板的社群，比龚文祥的运营水平和势能略差，但是赚的钱仍然只多不少，
核心就是有一本微商内刊，叫做微商内参，然后全年扒一些好的文章，然后再加上一些可以让微商买单的文章刊登。
然后仍然是收取会员费、以及会员费之上的更高的权益费用。
另外一个我写的文章写过龚文祥，龚文祥的本质不是一种社群，其实是用社群来卖现成的课程。
龚文祥在做微商社群之前，一直在做微博，微博的电商自媒体达人前三就是他，他之前打的是，微博 400 万粉丝。
400 万极其精准的，在传统电商时代积累的一群电商类的流量，才给了一定的洗流量价格。
然后才会做微商代理房愿意付承认几万块去持续洗他的流量，才会有 1000 个会员左右的基本盘。
这是微商媒体的变现通路，一个认识就是要兼听我们从号令，胖老板的物料数量姑且不谈，龚文祥的变现逻辑之所以不谈，但是从商机逻辑来看，是成立的。

第二个例子，是我一直希望学习的前辈，阿桂老师的中国美妆网

媒体兴旺之后，桂老师做的第一个决策是做展会，
行业展会是一个垂直媒体应该占据的好生意，结合自己的内容团队、策划团队，以及招商团队一起，

## 4、健身房年卡模式与健身从业者的辛苦

健身房业的 cruel 模式太高了。

健身房的商业模型意味着，一定要通过疯狂收便宜的年卡会员，作为流量池，然后疯狂忽悠健身年卡的同学，办理私教，而且充值越多越好。

为什么是这个逻辑，是因为私教单价高啊。

为什么私教单价高，因为之前是稀缺，所以确定了这个行业价格，然后之后就逐渐泛滥后，行业的价码做定了，所以就不变价格。

价格不变，转化率肯定对于国人来说是低的，因此只能逮着一个宰到一个，逮住一个区域的人宰到一个区域的人。

但是对于单个健身房来说，如果自己的品牌不能让同区域的专业的、健康的、持续发胖单人，记住这个健身房的私教，那么很快韭菜就会被割完。
不只是年卡的韭菜，更重要的是，能贡献私教现金流的韭菜。
韭菜被割完的时候，之前的年卡都是应该缓约以「年」记的，没有持续不断的高单价私教收入。但还是有大半年，甚至是不断涌来的年卡用户，履约义务不变。这特么不跑路，真想不出其他办法。
这个商业运营逻辑根本原因还是在于，中国人的能坚持续复购的高客单价支付能力的健身人群，还是太少了。
这个行业，对于教练，那叫一个残忍，持续淘汰，持续开会，持续逼单，真的很惨。
教练的梦想要么是成为下一个经理遥遥后生，要么就希望自己开一个工作室，幻想自己能有客户池。
每一个能得好的教练是可以从这个健身房获取种子客户，但是，持续性是一个大问题，没有大的健身房持续给你流量，你自己的工作室也就只能一茬一茬地掏牌接手了。
线下健身行业真的不容易……期待国人的消费升级。

高阅读量文章中，占比最多的电商及流量平台相关类型，其次是创业思考类和群响相关类，最少的两部分是生活感恩类和职场技巧类。

群响相关类中也是群响员工的话题最多。生活感恩类刘思毅的个人经历（特别是创业的经历）和读书笔记（阅读的是互联网相关大佬的著作）最火。

3. 个人创业详细经历和读书随笔
4. 职场规则可待开发

- 1. 标题是影响阅读量低的最重要的一个因素，太过模糊的标题要被淘汰，无论是什么类型的文章，还是需要点明主题才有机会吸引读者
