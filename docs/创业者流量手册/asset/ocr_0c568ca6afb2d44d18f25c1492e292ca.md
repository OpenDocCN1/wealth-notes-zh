# 要做 IP 的必备要素：

第一，热爱表达和影响别人，技能点和鸡血点，一定是点在「影响力」上；

第二，生命力强悍，体力强，一定是熊熊燃烧的火焰；

第三，要代表一群人、影响一群人、引领一群人，这一群人是具体的、确切的，你自己心里知道的，而只不是客户。

被你代表的那群人也知道、也明白、也认同。

第四，鲜明个人特色造就独特的人格魅力，人格魅力形成一个人在线下、线上的场域，吸引你的人群。
