# 37、100 万月销是抖音品牌自播的起点

# 一、品牌自播，100 万月销是一个能不能开始成功的门槛。

很多人一说起抖音品牌自播，都会觉得这件事儿真的是又慢又重要，是这样的的。
我们群响会员那些做食品和做美妆类目的铁子，创始人刚开始下场做抖音自播，都会直接被数字惊吓，
卧槽，怎么可能 GMV 哗啦哗啦卖了 12h，还特么不如去上一个达人直播 15min 的销售额，
甚至 1 个月还不如他们 15min 的销量哎。
从毛利结构来看，品牌自播没有坑位费和佣金，这样的利润结构更健康；
从控制度来看，品牌自播的核心不是孵化达人，而是卖出去东西，因此达人是可控的，而且是流水的；
从闭环的长期角度来看：
品牌自播可以直灌到自己的店铺 DSR 也好，灌溉到自己的蓝 V 矩阵也好，anyway，都是自己的资产，而不是别人的。
从稳定的角度来看，品牌自播真的是品牌为核心的落地页，
只要人流量可以支撑，我甚至可以 24h 吃抖音的流量，这就是一个落地页，稳定在持续经营。
