论是 to VC 赚钱，还是 to C 赚钱，还是 to B 赚钱。VC 的钱让整个市场热起来，这是 2019 年年初开始的事情，2018 年的时候，你做一个消费品，新国货都不好意思叫的，但是现在，不叫自己新国货好像都不是做消费品了。

# 二、消费品 VC 信心为啥集体消失。

VC 情绪恶化，从什么时候开始？雪崩的时候，没有一片雪花无辜。真实的感受到这一点，这是我最接近冬天的 一次哈唱朋友， 跟你们说一下。

+   1, 上市公司整体的市值都不咋地。

特别是完美日记、Popmart、奈雪为代表的上市公司，并没有表现很好，又特别 是完美日记，是“线上流量打法驱动 GMV 增长，然后驱动品牌杠杆大量资本，然后上市”的 途径，完美日记没走通，VC 比较尴尬了。

+   2, 击鼓传花逻辑不通。

大量的消费品公司，被 VC 投资的消费品公司，通过刷单、下水道、忍受超低的 ROI 投放、讲故事的方式，完成了一个一个的虚假繁荣，虚假繁荣之后，老股东合谋一起向下击鼓传花，泡沫太大，但是新股东确实看得到，原先觉得能撑到二级市场，结果发现上市第一无法，第二上了也 没钱。

+   3, 泡沫越做越大越亏。

大量的新国货公司，GMV 泡沫性肉眼可见。什么叫肉眼可见，就是不投就不增长，一投就亏，而且越来越亏，而且盘子越大越亏，投资人不是傻子都看得到的。大账这就亏了，VC 就不想投起来死了。也不想投资中不溢彩的品牌了，除非你品牌做了头部，而且看起来未来不是血亏，还有可能作为一个资产，期待一下被并购和上市的，其他品牌，一律拿不到融资。我在资本市场的融资的兄弟姐妹们，都已经焦虑很久了，VC 有钱但不想投资了。

# 三、VC 消费情绪带来的影响。

VC 对对于整个市场来说很重要，中国互联网一直以来被泡沫推着向前发展，其本质就是 VC 的杠杆带来的全行业预期。VC 不投资，这带来的情绪影响非常严重，让整个市场快速冷却。没有 VC 的投资，就没有新国货的投放费用和服务费用，那么一堆服务商就得凉；
达人也不会疯狂带新国货，而是只和头部玩家，特别是 KA 大品牌玩儿；原先品类上一堆要被 DP 割韭菜的新国货创始人自己没钱，要么就学会独颈发育做生意，要么就真的清算了；
