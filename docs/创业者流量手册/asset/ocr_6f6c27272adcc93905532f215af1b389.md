# 第一，存量周期开启。

简单来说，移动互联网 10 年，消费互联网红利期好像只有 5 年不到似的，眼睁睁看着红利没了。

这不是行业属性的问题，是整个大盘子的问题，红利不在、竞争饱和度极致，整个经济大面积累存量之后，互联网行业似乎都 Naj动不动了。

互联网不得不说确实是需要国民经济整体好才会好，我们都是波取国民经济养分之上的寄生物。

存量周期开启的具体逻辑和表现：

+   1. 反差差 - 大平台被打压 - 平台内生态进一步挤压，因为平台仍然需要增长；
2. 经济形势下行 - 消费者预算降低 - 支付能力下降，行业竞争更激烈；
3, 全行业不景气 - B 端裹包减少，特别是中小客户, to B 公司生存艰难,要求生存；
4, 中小公司生存艰难 - 全部在找机会、求利润, 利润成为核心追逐点

结论：存量周期到来，净利痼驱动导致精细化运营的回归，导致「创业就是做生意」的务实主义的回归。

# 二、资本的悲观预期影响极大。

我在之前都没有认识到，原来资本才是驱动整个行业发展的最核心的因素，
资本带来预期，资本带来现金，现金和预期就是泡沫，于是整个行业可以被炒热。

但是目前资本偏向头部化，而不是投天使，偏向确定性解，而不是靠感觉和投人，因为整个中国消费品好像像互联网这个赛道验证走不通了。

具体原因我下篇文字会详细说，今天只说结论导向逻辑：
在现实方面：VC 不投了 - 一批愿意忍受超低 ROI 的新国货品牌没钱 - 代运营没钱、平台广告消耗减少、流量主广告消耗减少、供应链没钱。
在预期方面：原先是新国货是浪潮，现在变成谨慎预期，甚至悲观预期，那个直接结果就是，中国新国货创始人开始务实、开始求生存、求活下去，不能继续增长速度直线下滑了。

VC 让我们行业有泡沫，于是人才来了，最优秀的人才都在直播，VC 让整个行业冷却，然后创始人开始务实，这是整个行业从热到冷的正常周期。
甚至觉得是好事儿。
