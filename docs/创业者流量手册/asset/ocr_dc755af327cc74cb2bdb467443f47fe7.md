不能只看那些已经在抖音上扛着很棒的大品牌，而是要看到那些广大的，还是在抖音做 CPM。
而主要和天猫合作海景房的大品牌，这些职业经理人，不仅是思想不打算动，根本上看，还是屁股被压根就不打算动。
第二种属性，我是孵路子供应链品牌。
这类品牌其实是行走的流量游牧民族，哪里有流量就去哪里的。
要赚他们的钱，真的难，真的难，第一毛利低，第二老板抠，第三他们也很懂流量。
第三种，我是新国货品牌。
这应该是我们理解中的 DP 的重点客户池，但是！我跟大家说，我群响蛮遗憾会谈集了大部分江湖上比较牛逼的 DP CEO 了，大家普遍还是反馈和这类 CEO 比较失规。
主要是这类 CEO 都觉得自己的团队实力会比较 OK 的，而且这类 CEO 确实学习能力很强，整个团队的整体实力也比其他两类要敏捷和精进很多。
所以，要求就是谈笔画止之后，自己 Inhouse 了自己的营销渠道团队，有些团队甚至就只是海盗门，要么就是自己不进，只聊不签单。
那么，最适合合作伙伴是，谁，其实想来想去，仍然是和 TP 合作比较习惯的那些品牌孩子。
但凡有一个问题了，他们的利益链条其实是和 TP 绑定的，你要和 TP 成为三方关系，怎么办以及如何处理 TP 这边的利益分割的问题。
以及这些品牌大部分就是屁股和实践两个方面都不打算快速进行行动和进化 KA 啊，那这样的话，怎么弄，DP 那么多，找客户就很 Forgot 了啊！
总结上所述，从客户的角度来看，能稳定发展的 DP 和品牌之间绑定关系有问题，而且服务的客户单价问题，规模也有问题。
综Loaded来说回答一个问题，代运营能从分享到足够多品牌在你这成长的收益吗？从过去 10 年的历史来看，基本是这样，除非投资，否则无法分享，品牌方不愿意投资并不是 DP 的主意。
我向这飞瓜杨老板这边问问题，胡老板反馈的点也是这个，就是不行，因为方向是不够专业做投资的，开挂次数太少，而且也不太愿意赌，所以赚资本的钱，从品牌和 DP 的角度两边来看，都不太现实。
第二，抖音不 Care 品牌，也不 Care DP，为了速度，不舍昼夜，DP 必然被生态抚压，当品牌其实也彼此生态抚压。
抖音自己进展很快，放到连自己的团队成员都无法去好好停下来整理和思考自己为什么出发，就必须被发动机拉着、推着向前走。
抖音生态的变化速度，快到生态方，其实来不及考虑代运营如何赚钱，现在在造路的路子以及自己的生长方式，是自己摸索出来的，而不是说抖音生态上十下掉的路子。
说了，这个路子要是抖音这边越想吃，或者抖音这边不愿意让任何人吃，关了也就关了，
