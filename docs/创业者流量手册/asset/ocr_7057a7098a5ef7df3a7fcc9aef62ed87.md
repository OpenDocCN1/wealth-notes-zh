# 第一，视频号直播是顺滑的。

视频号直播是如此的顺滑啊，顺滑到让人觉得爆炸。
可以直 接分享到票圈，票圈显示是一大块正在直播红点点的小方块，点击率很高；
可以直 接最小化，最小化之后，用户和主播都可以在社群、票圈互动；
可以直 接分享到社群，社群中是一个和视频号视频一样大的方块；
可以直 接上小商店，非常简单就能够直接让用户在上面卖货了；
用户点 击进来，是原生的体验，不是小程序 base，而是原生的产品体验，更顺滑。
为什么如此强调，因为顺滑太重要了，低成本的体验让用户愉快，让转化率上升！

# 第二，视频号直播是垂直的。

视频号真的很能 CRE IP，我们当天真的很用力了，800 人最高在线，
潘乱在我们当天直播完成之后，马上深夜开播，真的没有任何的预告，结果潘老师的 TMT 粉丝真的太多 了。
大家都希望听潘乱老师分享，然后也有很多没有深度体验过微信的视频号直播，就直接听朋友介绍来，很快达到了 1000 人直播在线。
1000 人直播在线，应该是真实的水平，这个在抖音和快手是非常平常的，但是在个人微信号上达到这个数据的价值，是更大的。
因为能够在私域中，有这么多 人来听直播，这些人都能，或者已经是你的私域粉了。
私域的认知深度好几倍，商业化价值也强好几倍。
为什么说他是垂直的，是因为没有会在抖音上听潘乱直播的，
但是微信上有一大堆这样的 TMT 精英、或者更窄众的精英群体，这些人可以链接到他们微信群这样的小的流量池，或是公众号，或是票圈，直接发起直播，让他们的受众进来。

# 第三，视频号直播是私域的。

视频号是一个组件，视频号直播也是一个组件。
什么是组件，就好像朋友圈、订阅号、社群、私信，这些都是我们这些做私域的组件一样，这些都是我们管理用户、运营用户、转化用户的工具。
它不是一个平台，它更像是一个私域的抓手，
之前的类似形象有了纯文字、图文富文本、图文消息文章、短视频。
现在，还有了直播，而且是原生的产品上的直播。这是很稀的一个媒介形态抓手，是一个补充。
我反复提「认知加工」这个词儿，真的很对，直播就是可以实现更深认知加工的重要方式，最深的加工就是让你的粉丝和用户在屏幕前面看到你啊。
