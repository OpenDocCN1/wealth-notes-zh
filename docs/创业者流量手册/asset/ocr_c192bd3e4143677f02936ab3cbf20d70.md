# 群响
掏流盘，来群响抖音

并不是说抖音的直播做的有多么否则，而是因为抖音有无数的内容创作者，直接播本上是他我们变现的方式。

今日的品牌，在抖音里哪怕我一百个薪主直播，也没有薇娅或李佳琦一个人的体量大，薇娅李佳琦的直播已成为品牌推架道的核心背书。

品牌仍重视当下的淘宝直播，而淘宝直播一定要在这仍被关注的阶段，解决主播不断地流失的问题。每年史书都在说，大好朝代死于青黄不接。

从品牌视角看，淘宝店铺直播，是淘宝内容生态的解救吗？

对于 Ka 级商家而言，做好淘宝店铺直播是这个转化系器，给自身带来千百万级的 GMV 增量。

平台对，危机点还是在于用户的选择。淡入期间的淘星尔克，抖音直播 GMV 冲击，消费更愿意去哪一个品牌自播相同，已经投票的明明白白。

站新国货品牌的视角而言，淘宝店铺直播是对存量的引导。通过直播工具提升店铺的转化效率，大前提是品牌本身有积累，有粉丝，有流量。

# 对于错起袖子干的新国货而言，需要的就是积累、粉丝和流量本身。

淘宝内容流量比玉米，如果花钱买不是一个自播流量，或着花钱买到的自播流量性比极低，自播就不只是一个可以看到被经营的内容。

很不幸的是，弃养看店铺直播的来到淘宝的用户很少，新国货真的买不到有性价比的直播间付费流量。
