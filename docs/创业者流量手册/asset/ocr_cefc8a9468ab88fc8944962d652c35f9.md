# 123、上市前夕，快手电商终于讲 ROI 和工业化投放了

快手在中国，中国有快手，时大漂亮这样的人在快手的走红让我更喜欢快手。快手能坚持是快手吗？

昨天晚上看到快手上市 IPO PDF，我会在之后的文章详细更新一篇 文章分析快手上市数据，
但看见重看一点，上市数据里，商业化的收入增长非常好。
这段时间除了好像火如荼的抖音直播、微信视频号还有淘宝双十一之外，还有一个铁矿石了快手都没有关注到，
但对于快手生态来说可说是一个巨大的至关重要的商业化和电商变化：
6月试运营的快手小店通正式上线。

和快手内部以及遥望的人对了一头，武断地说出我的结论，欢迎批判：
作为一个保护区域、变现商家和头部主播非常吸睛的电商生态，
小店通可以提供一波启动脉工业化的红利，也是快手公域流量商业化加速的起点。

我很庆幸地发现……快手这个缺铁子的直播带货生态中，官方终于开始讲 ROI 了。
虽然以前的我都在唱抖音，但今天我豁然发现，
马老师领导下的商业化，和笑吉老师领导下的电商团队，还是疯狂在进行快手的正规化、精细化以及平台收入的规模化操作的。
特别是别搞服务。
我觉得今日快手，各位商家朋友可以考虑看看赶紧试了，特别是一些美妆、服装、食品这样的全民类目，
不感兴趣的不合适了，毕竟是一个几千亿 GMV 的盘子，
而且关键是有一条比较明确的路终于可以支持从公域导流量卖货了，不用再单纯依靠主播精准粉、稀有域流量了。
对于我们这些玩流量的，是福音。

简单易讲讲：
第一，快手小店通是快手的 Feed 商业化，是快手比豆荚更强的功能，粗糙的信息流电商广广告的起点。

先科普一下，快手小店通，到底是什么。
简单来说，就是支持在公域中投放加粉，加强版对标抖音的 Feed 商业化一样，
在说白点，就是快手直播和账号的类似头条「巨量引擎」的一个新的广告投放点！
对于快手商业化和电商，都是变现工具，为马老师和笑吉老师鼓掌，
据说是电商和运营部门共同推进，也比较 make sense。
因为这个有预算的一定是能商业化的电商商家啊，所以这个和电商、商业化都有关系！
我看见介绍都是两个版本，一个是磁力引擎版本，一个是电商版本哈哈哈。
