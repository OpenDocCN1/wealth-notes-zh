# 货架式的电商直播，顾虑了颗粒算，也最终会变成颗粒算。

淘宝商家端，之前一直能经营《盈利》的內容场是微淘。看似存在感强的微淘，是有着真实 1 亿+Dau 的内容场，现在这个流量过诱给了逐速。淘宝每年有大几百亿的成交来自微淘的引流，有较高比重的品牌把微淘成交占到 1.5%~5%。

那微淘话权重为什么一直不大呢？原因还是在于淘宝坚持的公平。微淘的流量无法放大，手淘公平地按模式《粉丝关注》把微淘流量分给店铺们。做好微淘内容有一定效果，可不可能被经营放大的内容场，不会是品牌玩儿命去搞起来的内容场。

极端一点来推敲，当初微淘能把 90% 的流量导给付费内容及爆款内容，淘宝内容生态自己已经出现几打的 showcase 了。

在两年前公开分享中，我在感慨“可谁知道，淘系会不会是无意中打开潘多拉魔盒的角色？当薇娅、李佳琦等人，一年靠直播销售 1000 亿的货品，这样的入逐步出现十二个”。

（这是必然的事情，底层逻辑是直播的客户终身价值极高，主播全渠道引流成本相对低），财富会极大的集中于这些被时代眷顾的人。而淘宝这样的电商平台，官方的流量资源不再那么容易售卖给品牌，变成了这批千亿主播实现成交落地的平台，电商大面的盈利价值骤新；这样的时代，脚步在褪去。”

没想到抖音这两年解决了完美的解决了这个问题。以最狼的姿势，毫不客气拿走了 Top 主播的流量。“不花巨资买我的流量不好好做内含，去好好给粉丝机器人们直抡玩儿吧！”一些从淘宝直播跳去抖音，妄想做头部明星，很快就发现，看起来 GMV 多了一个 0，但收益从年收入上千个 W 变成了赔本卖铲子。

# 五、论可能性，在未来的内容战场 “阿里式换将，打开不赢内容战场”

淘宝内容生态现在将“逛逛”视为一干解牌法，目前的逛逛在消费者端口很像小红书。我个人的看法是，目前小红书估值 100 亿美金，淘宝从 8000 亿跌到 5000 亿美金，跌了 3000 亿。逛逛真做成了小红书的高端，只是在内容上打了百亿美金的漂亮小伙，不能说翻身了，毕竟抖音能制走千亿。 不过逛逛要是打成功了，可以打出来一个有正向激励可能性的淘宝内容生态。叠加已经被关注的内容算法，这样淘宝内容未来仍有巨大可能。我得澄清的是，KOL 的正反馈机制在目的逛逛的遒未未调通，全网入淘的 KOL 持续经营逛逛的动力是不足的。看逛逛的发布会，看逛逛的 PDF，能看到逛逛的核心激励仍是发了多少内容进来，养了多少号，会有什么样的现金激励。我能理解这个业务需要先把人引进来，先放鱼苗再养鱼。
