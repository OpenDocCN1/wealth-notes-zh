# 119、做 IP 抖音直播，核心就是内容、内容、内容！

自从我发表了「抖音直播是畜生行业」之后，收获了很多同学的教海，包括官方铁子，包括一些 IP 同行，说我眼光蒙圈了。
他们普遍同意, 毕竟消费品电商的日不落店铺, 当然是一种畜生行业, 但是抖音直播并不只有这个类型, 大部分 IP 主播, 也就是有人设、有信任、有专业内容的 主播, 并没有那么邪门多。

先看大狼狗和刘媛媛，这两个是电商达人 IP, 非常张的两条套路。
大狼狗，做内容做得好，直播间和短视频内容都做得不错，直播间的內容是什么？是做货盘，是直播间的长相，是直播间的氛围组的运营，这些大狼狗夫妻创造了一个像演唱会一样的美好场景。
然后加上大量的投流，他们做专场甩锅，可以卖 1 个亿以上的专场的货, 这是一种套路, 这就是畜生模式嘛！明显不是啊, 日不落可没有这个玩法。

再看刘媛媛, 大华养车, 草根家庭, 卖书出场, 影响一批小老板成为更好的自己, 做内容的特别特别六, 有100万的内容粉丝, 然后半年把自己活成了日不落主播, 8点到20点直播, 凭一己之力, 冲击到抖音7月卖货榜前10。

刘媛媛在我们私董会, 大家都说, 对刘媛媛敬佩, 敬佩刘媛媛的勤奋务实与努力。
这两个都是电商 IP, 我被前辈说了之后表示不服, 我说知识类、服务类的有吗？
他问说, 还真有, 而且他们真的也和你一样, 呈现以下几个特点：

第一，总场现少, 1h 5000 场观, 在大盘算是少的

为什么他们又稳定呢, 是因为通过 IP 的力量, 他们的粉丝关注度是有价值的, 粉丝对他们的认知是充分的, IP 本身的粉丝群体也可以发挥出一定的粘性。
可以说, IP 在抖音直播, 就是抖音私域和公域的一种共振。
