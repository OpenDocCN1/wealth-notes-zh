# 揽流量，来群响

只说快手电商直播，今天快手主播的固定路径几乎和辛巴的路径相似：强力影响生产供应链 —— 控制或自持工厂供应链，做自牌售卖 —— 体量足够大、创造出有品牌。
达人能卖货，而且不卖品牌货都可以卖，一方面铁粉子们有些尚未被传统电商渗透，一方面是铁粉们就是逍遥买、买着玩儿、买一个支持、买一个娱乐，低客单价 + 性价比 + 老铁真爱，三大抓手让铁货很好出，因此对供应链压价到底，吃掉供给侧绝对多多利润，中间没有新品带来的空间。
当体量足够大，可以直接吃掉生产端。当体量进一步扩大，流量体量、资本实力、供应链实力、团队选品技术扩⼤，那就可以直接做自有品牌，这是辛巴曾经实现 的。

第二，难以控制的顶流十分尴尬。
普遍说，平台的流量策略意味着在产品和运营上的，不能随心调整，因此养肥了的 KOL 要么动大动，对于快手而言来说，短期当然不用在意顶流的流失，随时随地都可以提拔任何一个顶流，只要平台想。
但是由于快手特定社区氛围，普遍的实质顶流都大概率出现一些问题，这些问题就是能不能在直播中呈现「反季节」「反党令」「极端下沉甚至庸俗」，或者不听官方号令，随意操纵营造破坏直播生态，以及其乎所有快手主播都拥流量而自重。

这是一个非常两难的管理境地，不能通过抖音直白、直接的产品流量指挥棒和运营策略直接落地当地进行直接管理，而只能在触及到极端危险或者塑造了一个直播 bad case 有被甲方警告之后才能雷霆一击。
雷霆一击对于一个顶流没关系，但当整个快手电商� silently 成交大盘的 KOL 都需要这样控制，而没有节奏、有力度的深度控制和影响，那只能说一句——「没有深度控制的资源，不叫资源」，始终存在萌盘风险。
第三，以辛巴为例。
辛巴是快手生态中电商 Case 的典范与唯一顶级闭环案例，他彻彻底底践顺了自己的快手电商之路，甚至大到贪天之功，签联盟家族、买主播资产、买供应链资产、做天猫品牌，一切都是快手难以忍受和控制的边界之外的动作，被平台打个半死不过。

然而，持续的辛巴是一种必然。
这是很困难的，由于快手本身对流量 的善意以及对私域的保护，私域的保护让 KOL 做再大做，手链链条和抖音一样 的颗粒度极细、响应更快 的流量分配机制，因而倒给了 一部分自己的 分发能力给 KOL 们。
因此做大之后，只能雷霆大动，处理头部，以儆效尤，而不能像抖音一样，像市场经济一样，胡萝卜 + 大棒的管理头部生态。
还是那句话，不能控制的资源，不是我资源。

第三，快手电商完全没有新国货品牌和互联网人的大机会。
无敌多做国货新品牌的群响会员们老在群响频道，看到主播卖货香，自己也想去看看快手，行不行，怎么就找不到抓手。
