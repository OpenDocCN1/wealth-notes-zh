# 为什么阿怀卖货，这么牛逼？

就一个核心原因，和我们做私域方法论一模一样：

优质的利他价值丰富的内容，带来牛逼的信任，牛逼的信任让她的人设超级坚固，—— 化妆品供应链 20 年专家，女性，中年，漂亮，为粉丝着想的选品坚特。
就这一点，让她直播转化率就达到了 16.85% 。

目前所有的视频下，都是她黑粉骂她的视频，人设彻底崩塌，退货率应该也非常高。
