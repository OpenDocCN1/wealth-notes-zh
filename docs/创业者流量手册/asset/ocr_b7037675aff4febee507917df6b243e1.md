# 52、抖音直播，卷到没有利润了。

抖音直播，真的发展成当代最高级「电视购物」了，佰草集的延禧宫廷让内卷从美少女美少年蹦迪直播间，上升了电视剧级别的剧情演绎。

他有什么呢？

沉浸式的演员和直播间、电视剧级别的剧本、超高清的画面，演员就是主播，主播就是演员，

人数拼的就是上剧本，流量回来了开始卖货，有很多人已经开始在这个直播间开始追剧了。

感受很深，只有一个感受，现在我的客户们太难做了……妈的，卷成这样，直播本身就是一个非常非常非常不赚钱的生意。

第一，人力成本极高，主播、投手、副播、运营、短视频脚本还有电商后续的运营配置都得上，这些比货架电商时也要高很多很多；

第二，流量成本极高，越来越多直播间进来，竞争会让 UV 成本更高啊，单个 UV 成本变高，直播间越卷，流量成本越高；

第三，货本身毛利率没那么高，一般品类，在抖音直播间销售，毛利率真的不高，加上流量成本和佣金真的没有那么多。

卷成这样之后，直播电商必须要找到一个利润支撑点，我大胆判断……

第一，明年会全民私域；
