# 147、微信、抖音、淘宝互通，会带来哪些机会？

昨天在我们 21 个会员群起一个互动，
当微信、抖音、淘宝互通，小公司会有什么机会，利好什么行业？
大家回答得非常精彩，YY 得很牛逼，立场很牛逼，罗列一下，感谢我们的会员，共创如此牛逼，目前已经有的回答：

+   01、
海客，变成多个流量端的肉类搬运工，会直接通畅的搬运，非常方便；
02、
私域从业者，所有流量顺顺利地汇聚到微信上，直接在微信上持续走 LTV；
03、
品牌方，也许真正的品牌 DTC、独立卖会在中国行得通，微信服务号 + 小程序 + 个人微信号 + 抖音直播间 + 天猫旗舰店 + 快手直播间，全面通顺。

04、
抖音偏流量、微信做转化，全面放开，会利好全部行业。
直播间直接说二维码可以 Work 的话，可以直接实现，人人在抖音直播间里导流，人人在微信号上做转化，小微商户会特别爽，惠及全行业；

05、
线下商家，会有更便捷、更简单的流通渠道，线下和线上的融合速度会更快；
06、
我觉得：流量从抖音来，在微信上裂变，然后又回到字节（以后的私域极有可能是在字节生态里维护的），最后回到抖音成交。
微信只成为了一个裂变的媒体渠道而已。

+   07、
对视频号的打击是致命的；
08、
对旺旺的打击是致命的。

09、
真的放开，利可可能还是天猫，因为天猫就是中国有品牌影响力的 DTC 的店，是属于品牌价值模型内的，大家还是倾向于把阵地放在天猫。
10、
但这样的话，天猫就变成工具，阿里会没有流量广告收入了，全面看袄阿里妈妈。

11、
不利于拼多多和快手这样的腾讯系公司，字节不再有意义；
12、
私域流量肯定回不到字节。抖音成交可能成为活动刺激的消费场景。但流量维护用户体系肯定不会在字节；
