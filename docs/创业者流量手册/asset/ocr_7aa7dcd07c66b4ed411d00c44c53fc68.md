# 136、知乎不得不了

知乎对我影响深远，想要记录和分享。

1,
和知乎的缘分始于我大三时期的实习，那是我ude第一份实习，我被一位给我留下毕生阴影的新疆维族直系师姐带着做知识点周刊和「盐」系列，直接到现在，大家去看原先前70本知乎周刊，都还可以看到实习编辑刘思毅的名字。
那个时候，知乎还是一个可以于情怀留住优秀应届生的地方，差不多应届生薪资在北京就是7-8k的水平，不高不低，但是可以由于知乎的title招聘到很多人。
黄继新就在我玻璃对面，做着知乎日报，知乎日报当时还在和今日头条PK，我记得他邀请了我3个KOL，黄继新和这些KOL讨论PGC的力量，知乎的PGC VS字节跳动的算法体系。
当时今日头条并不那么强，至少从冰箱挑成呃那个时候看，张一鸣和周源还是可以互相支持的，而且真的在接力，我们记录是当时周源冰箱挑战，在768居子的草坪上，全体同事围观。当时知乎是包中饭的，只有70个人不到，我刚去的时候就在768 A座，那个时候的饭真的很好吃，三荤一素，老板们对员工真的不错，我作为一个穷学生也可以领到5000元的认真实习薪酬。
那个时候的知乎，刚开始放注册一年，就已经经历了当时长期封闭测试的KOL们说，知乎变成了水平，知乎不再是原来的知乎了。

2,
对于知乎的泛化，我原先也和一群吃瓜群众一样，故作深沉地感叹，知乎再也不像是原来的知乎了，张嘉佳再也不是原来的张嘉佳了。我现在只想说一句，呸。

# 燕雀焉知鸿鹄之志，以及你们是不是没有治理过城市。

城市变得越来越优秀的一个核心推动力，就是城市规模越来越大、因噎废食，让城市萎缩，反而会让大家能享受到的服务和资源，越来越少、越来越贵。知乎的社区治理，和城市如出一辙，要是没有当时的开放注册，他就是一个曲高和寡的高端社区，高端有意义吗？有意义，但是有太大的意义吗？有现在的知乎这么有意义吗？当然没有，完全没有。当前的知乎是中国最大、最优秀的中文社区，乃至世界，都是数一数二的，在内容和用户的规模上，数一数二的社区。商业价值、社会意义，远远比做一个曲高和寡的社区来得大。

3,
当前的知乎和我的缘分，又来于差评。
