# 4、信息流投放能力

这是最鸡肋兼�瘸，也是最让 CEO 头疼，觉得信息流太难，然后看不懂，然后需要找外人。

但是我想说的是，这个的效果，靠投放，能够带来的本质悬殊，真的不如内容和直播间运营来得大。

怎么说呢，人们总是希望越快越好、越大越好，但是忽略了精细化运营的艰辛和长期主义的好处。

信息流能力，在未来反而会成为一个标配能力，我不看好所謂的用信息流投放出来的 show case。

虽然这是一个业外能力，但是本质上也就是一个平台买流量、卖流量的事儿啊，你觉得抖音会傻到让你因为投放能力强，骗了他很多免费的杠杆吗。这事儿，还不就是有钱就是爸爸的事儿吗～
