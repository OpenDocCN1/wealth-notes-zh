# 摘流盘，来群响

本次合作，京东和快手没有啥流量上的商业约定，核心约定放在一条上，即：京东作为自营的商品以及对应的履约基础设置，包括物流、客服、履约等，给快手小店、支持快手达人在小店环节交易上选择京东自营的好货、品牌货。从以上可以看出，并不是卖流量给作为电商平台的京东，在这次合作维度，京东是做货货归京东，流量和成交归快手。快手需要好的货，京东需要快速出货的渠道，更像是一个巨大的流量主和优质供应商的联盟。而非淘宝和抖音的流量采购框架协议。当非...作为竞争关系，快手电商也做，流量主当然也要做，并不排除未来也會有流量层层的深度合作，超过年度框架。

# 4. 针对快手，为何选择京东。为何不是其他？

快手上这个板块太窄，死了，要提振单价，自己的货太下沉，自己直播场景中的货，本身一个个板砖，源头好货和拼多多一样，都是低价白牌。要实现供应链的升级，也需要品牌货，品牌货的最大贸易商 — 京东，这就是顺理成章了。另外，快手对货的诉求，只有京东能干，因为京东的核心，是零售的京东，而不是流量的京东。京东不仅只是流量电商平台，更重要的资产形式，是要走货、走规模，基础设施对于京东也很重要。京东电商部门和快手电商虽然仍然是竞争关系，但对于阿里、拼多多这样的中心化电商来说，京东对于他们却是开放的。阿里是中心化交易平台，平台需要商家聚集，京东需要货品流动。包括拼多多、阿里在内，都与快手这一流量池非常直接接触，但他们两家核心都要求自控商家、自控流量，好的货源集流量，好的流量杠杆顶级供应链，这是交易平台的逻辑，这个和快手的诉求比较莽盾。

# 5. 对快手电商核心中的 KOL，会有什么影响？

如同抖音的精选联盟一样，真正的头部主播，甚至稍微运营的达人团队，都不会从官方的供应链平台走。核心是 CPS 太低，宁能与商家灵活谈判。京东自营库虽然尖货众多、品牌众多，但一旦平台统一接入，CPS 远远不能满足头部主播的期待。因此这次接入更多是从生态的角度，辅助快手整体提高白牌之外的货的质量，但头部肯向是自己玩儿自己的，不影响他们的业务决策，但可以为广大想尝试带货的人提供一站式流量电商实现的东西。这对快手生态是有意义。

# 6. 对于京东，这次合作的意义是啥？

对于京东电商的理解。京东对流量的能力更弱，对流量的坚持理念更弱，对交易平台的执念更弱，618、1111 和阿里是对垒是非常不得已塑造 Showcase，占据上升人群心智。京东对流量的能力向来不强，能够通过快手的下沉人群走货，实现一个故事上的 DAU 增量，用户增量，也是非常好解读的资本故事。双方一拍即合。
