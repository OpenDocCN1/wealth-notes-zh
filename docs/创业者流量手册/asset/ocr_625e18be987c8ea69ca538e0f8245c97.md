# 二、长期分润被视操油，短期服务商不愿投入

1，
你赔金制和 IP 分润，是有签约时间的，你的角色觉得永久分润吃亏，很难具备化解能力的人会觉得，我帮化雏都可以成功，为什么要赚短期的钱，而不是长期呢。
聊过几个合作方，家家都是要长期捆绑才愿意投入。
换句话说，现在 IP 的打造，你如果自己做不来，那大概率援案的成本也很大，
IP 的分润找一个好的操盘手，能够长期持续合作，也不是件坏事儿。
只是大部分时间你遇到的，你都不想跟他长期合作。

2，
一年太久、只争朝夕，你考虑后期期的钱太多，前期你又没能力做，那就是幻想自己赚不到的钱别让人分多了，也是一种要流浪。
要么自己觉得自己能干就自己干，要么请别人帮你干，纠结什么。

3，
其实我挺过群响的抖音引流到私域，看过一些同行的案例，觉得非常可行。
第二种方案佣金可以高一点，但是没有后期分红。

4，
如果你不是一个好项目不是一个持续能分钱的项目，别人的为什么要花时间精力把你服务起来？
群响本来就是号召大家知创付费的，勿忘初心。
