
## 抖音为什么要切割更多流量进入电商？宏观调控的必然结果，入场更多商家，流量不够用。

在抖音电商这一层，平台对每一个品类的流量池进行严格的 ROI 测算和消耗测算，平衡广告消耗额和 GMV 产值，进行平衡后，统一确定规则分配流量。
而架不住，抖音是一个内容平台，所以说内容最大、流量权也最大，因此流量总流是，主端 App —— 直播流量池 —— 电商流量池。
电商流量池在抖音主端中，目前占量的量，暂时不太大。
多说一句，这也是内部、外部博弈的最终结果，电商终究还是需要更多的汤，但凡 K12 没死，也不可能这么缺消耗额哈哈哈哈。

## 第二，达人直播进入新阶段，触底反弹的高潮

以大狼狗、刘媛媛为首，达人直播进入标志性的新阶段，
这里有两个思考。

### 1, 抖音需要达人的内容，就需要让达人赚钱。

内容，内容，内容，还是内容，抖音是一个内容平台，我们思考抖音方向从来不可能否定这个。
达人直播在去年这个时候开始被切削流量到抖音企业自播，鼓励品牌入场，到了现在，是时候回来了，因为他们委屈好久了哈哈哈哈。
达人包括刘媛媛和大狼狗，也包括创始人 IP 卖货的那帮人，其实这帮人抖音喜欢，他们身份也大贵，会做内容也是专业卖货者，是很吃香的。

### 2, 第一批用户需要达人的转化能力。

抖音需要达人的转化能力，特别是对于短视频到直播间的尝鲜抖音电商用户，为啥？
内容带来信任，短视频的内容建立了初步信任，
达人本身自己的直播间氛围，和自己的话术和情绪感染力，应当是一个店播的小姑娘能相比的。
不信你可以去大狼狗那边试试，太可怕了，
最近在放大的就是短视频用户到直播间，也就是说在做一个直播用户池扩容的问题，因为池子里里面的水有点少。
那如果池子里的水扩大的话，这些以前没有在直播间里有购物行为的人，能够接住他们的不是自播直播间是达人直播间。
自播直播间其实是需要用户有一点心智才能在里面有购买行为的，要么是品牌心智，要么就是内容心智了，气氛也是一种心智。
如果是完全不看直播的人，第一次在直播间买东西，他肯定是在气氛优势更大的达人直播间，先完成第一波行为教育。

### 一、超头挤压平台

### 淘宝直播 = 超头？淘宝 = 超头？

这是昨天在群响群里经常讨论的年经帖，甚至是让每个月都会有讨论。两大头部都源于淘宝直播，淘宝直播创始团队也源于淘宝内容营销的整个超头部，讨论图文、社区、短视频、直播。最后能跑出来的是，只有直播。而在直播中，由于淘宝流量可支配的规模特别小，且每一个流量又特别珍贵，因此从部门的 KPI 考核指向、业绩指向以及平台 GMV 最优的指向来看，

淘宝直播在前期只能依靠薇娅、李佳琦这样的优秀达人，提高每一个 UV 进入直播间的转化率和 LTV。

平台前期需要李佳琦和薇娅，哪怕没有他们俩，也会有赵佳琦，和刘境的现现，薇娅、李佳琦是站在直播成为一种 SKU 呈现媒介形式下，被淘宝直播选中并且推荐的。

成也流量，败也流量，当自己的流量池被两个超头把控太多，那么就完成了第一个核心矛盾认定。

### 第一，薇娅李佳琦锁定有限的淘宝直播流量。

淘宝直播对其生态位的优秀主播不再有吸引力，这个吸引力也是双向的，淘宝直播团队没有那么大的动力去完成新的 GMV 挑战，因为冒昧。流量一经新的主播，概率是明显，要是转化不了 GMV，转化不了持续的 GMV，就会被迅速放弃，回归到超头的怀抱。

### 流量贵吗？

往往都是，阿里和品牌去谈广告包，现在有一个小打手，也要分钱，而且这个小打手这个题，对于每一个手机淘宝掌门人，都是送命题，真的太难。

### 二、超级头部挤压品牌

我在双十一筹备期间，已经刷到过好多次这个抖音账号了，用的素材是李佳琦如何和品牌老板砍价的素材。

里面的品牌创始人 Gallons 的剧情安排总是特别 to C 很爽，就是李佳琦步步紧逼地寻求，给我们的女生多送 Offer，然后品牌创始人和高层在一起商量，被迫答应了这个 Offer。 然后皆大欢喜。

我突然想起了一个快手高层对接会上，一个美妆品牌 10 个亿上去了，他的创始人说的，明显是精神消费居多 的事情，非这个品牌跌落谷底，直接变成一个产业链成本递来的事情。

我品牌品牌力没有了，利润利润没有了，只赚了一个不知道怎么样的吃喝，也不知道品牌图啥？ 毫无尊严，谈判没有尊严，交易没有尊严，to C 没有尊严，但就在这里卷着，也不知道怎么活。

品牌确实是这样被摩擦的，但是很少有品牌能拒绝登临薇娅李佳琦的快乐，原因在于品牌势能在今天的直播赛道会得到一个非常明显的提升。

能够持续稳定上李佳琦、薇雅直播间的品，哪怕被薇娅李佳琦挤压得不行，也要有个支撑点。 第 naprawa，自己的渠间销售推品，会更顺利，无比顺利，因为全天下的主播都在这样做； 第二，自己的品牌天猫店的溢出，这是玄学了。

### 三、超头杀死渠道们，淘客、社群、公众号

不断被挤压就其是其他渠道的宿命，真的 是飞来横祸，抖音、快手、淘宝的主播不断破价之后，让所有其他渠道都显得不那么坚挺。

核心原因还是，性价比。 只有这些人才能有最低的破价，而且是最好的货，用最好的货的最低廉的价格，横扫全国。 在抖音投放，在快手投放，在微博投放，在线下电影院投放，在公众号宣发，获得一个 C 就可以得到巨大的 LTV，所以说薇娅、李佳琦的预算理论上是无限的。 我终于知道了，为什么我的有些会员会说，李佳琦薇娅，睡觉生病都在耽误。

直播抛却是新海客，而超级头部的直播是要比淘客还要更好使的催化剂，to 团队、to VC、to 销量。 各路流量都被牵引被吸收能里，丢了订单。 这真是一个达达的时代，Q4 之后，这变成了一个迅速明确的流量趋势。 无论是抖音，还是快手，还是天猫，在今年下半年，品牌自播日益常态化的今天，还是发现，只有超级达人 + 超级破价 + 超级品牌，才能炸出 GMV。 所以不断走在这条路上。

那我不禁要问，品牌怎么办？其他流量主怎么办？普通商家怎么办？当规模不断被挤压，利润为中心的精细化运营思想，就回归了。
