# 89、也许微信号会关闭「一证五号」注册入口

最近私域圈暗流涌动，有一个非常大的消息，被大家忽视了。或者各位做私域消费电商的，都忽视了，而私域专业户们，已经「春江水暖鸭先知」了。
这即将影响未来一年的私域行业的发展走向以及，大家能赚多少钱，请认真听，以及转发给你的私域负责人看。

从 7 月到目前，张小龙仍未重新打开个人微信号注册通道，官方说法原定于 8 月初开启。
十分担心本次关闭之后的重新开启，会限制「一个身份证，可注册 5 个微信号」，减少一个身份证对应的可注册数量。
一张身份证，5 个微信号，其实是个私域行业，没有兴起的时候，个人微信号的遗留口子，也因为这个口子，给了很多私域从业者包括薪酬，让员工和七大姑八大姨注册微信号，管理微信号的机会。也才有了今天 1000 个微信号直营销售团队，管理 10000 个微信号的 Case。
目前，微信注册从中国用户逻辑来说，已经预期，大陆这边直接从一证五号变成一证两号，完全 OK。
我大言不惭地说，哪怕本次不变政策，变政策也是时间问题。

此次关闭可能造成以下影响：
第一，个人号私域行业关门大吉，有个人号的牛逼，没有个人号的死翘翘，死一个号，少一个号；
第二，黑市的微信个人号价格大幅上涨，作为一种私域生产资料，直接涨价好几倍可能；
第三，全体从业者忍者恶心，走向企业微信，私域迎来越来越企业微信主题。
