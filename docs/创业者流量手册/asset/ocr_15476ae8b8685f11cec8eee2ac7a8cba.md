# 第四，视频号直播和抖音快手直播不一样。

我一直觉得某小龙对公众号的那句 slogan 真的是十分牛逼，
「再小的个体，也能有自己的品牌」，这个 Slogan 真的十分初心，十分初心。
我经历过公众号蓬勃发展的 8 年吧，10点读书当年在红点直播的时候，第一次突破 1000 万粉丝，这是头部 的，还有一些很多很多腰部的，现在活得很 好 的。
我说的活得很好，是指作为一些垂直的公众号也好，个人号也好，
他们可以用微信作为一种赚钱工具，而且效率至少等于自己去工作和打 工。
这一点是伟大的。视频号直播和视频号也是如此，和快手去中心化之后绝 对 PGC 希望不一樣，和抖音的平台掌控一切节奏不一样 ——
我希望没有猜错，张小龙的心心仍然是 to C 的，仍然是 to 那些长尾的，既 可以是用户，又可是以需求提供方的 C 的。
每一次微信的更新，都要想，这是一个真正的全民级别的产品。
最后，谈回来，视频号直播、视频号，以及微信小商店这些新功能，对于微 信，是否对鸿蒙，是怎样的？
我仍然不看好视频号的战略作用，偏小了。
核心原因就一个，这是我的个人看法 —— 视频号流量太小。
因为就不能大，不可能打破基本的拟破坏森林生态的原则，
所以说微信的公园只能用发现页的「海景房」或者叫「金刚位」来解决固定的 流 流量。
然后也支持私域中顺滑转发，也支持微信票圈直接分享带流 量，这 些都 很有棒 的功能，用起来真的很顺滑，
但是我担心的事，这些并没解决流量问题。
这些都属于「私信」「社群」「朋友圈」「订阅号」「服务号」这些抓手功能 上的附着功能，为私域玩家提供一种运营和商业化的补充，这些都很棒，
但是，这些功能不能提供抖音快手一样的原生流量。
微信是一个伟大的产品，从即时通讯工具变成今天包罗万象的生态工具基础设 施，作为基础设施，不动就是最好的动作。
但是踏实的商业化尽头是什么，除了生态创造的资产价值之外，微信要指望广 告营收吗？指望微信支付的费率吗？
这些都不够呀，要指望什么新的增量呢？
今年微信给的答案是视频号和微信小商店，但是我都认为还是只是底层基础设 施的工具施工。
得益于去中心化，微信成为了一个巨大的中国互联网流量的尽头和源头，商业 化和最核心的用户资产，几乎都在这里发生；
受限于去中心化，微信不能动所有人的私域筐糙，因为 to C 他是通讯工具， 一个通讯工具不能有强力的平台指挥棒。
这样就会让森林枯竭。
这是摆在今天需要新增长的微信面前的难题。
PS，不过对于我们民间创业者来说，视频号直播绝对是一个平行于订阅号的文 章、朋友圈的图文、社群和私域的媒体形象，
