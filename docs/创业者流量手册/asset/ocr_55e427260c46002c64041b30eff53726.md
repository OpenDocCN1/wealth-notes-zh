# 第一种套路：先有社群起盘的框架，然后做内容，做社群 + 培训 + 孵化 + 投资模式，一般在微商、电商等生意领域，持续更新内容，前 IP，后行业社群，做培训、做投资、做培训。

例子：姜文祥、老高、群响
这样的 IP 一般的商业模式就是做社群 + 培训，以及基于社群这一品类做各种变现，包括孵化和投资。

事实上，一个稳定的社群变现实上限大概是 5000 万左右。

单纯靠社群变现触碰到上限自然而然就会想到生态这个词，啊我好烦生态，但是确实在做生态。

老高电商圈子，3 -5 万一年的会员，传统电商的大佬都在里面，针对于每一层的电商商家都可以提供对应的服务。而而且高起量很快，现在很多的情况下绑定了很多品牌的投资股权。

架构也可以赋能，这是群响一直想学习。

再说群响，群响一开始用的是刘思毅自己在 VC 和互联网圈层中积累的营销、CEO 和操盘手资源，其中底层发现流量和电商最相关。会员几乎都是电商和社会分，于是刘思毅的解决方案，就是持续靠刘思毅写这样的日更文章，持续有 200 个左右的朋友会加我好友。
姜文祥更是如此，微商第一教父的 IP，应该也是自己封的。
但是确实是，每一个做微商的人都需要去拜一下码头，为什么。因为虽然姜文祥老师的内容输出不怎么滴，但是只要姜文祥在微商界持续不断的输出。
而且还跟随时代迭代，从微博到微信公众号，到个人微信号，再到抖音和快手，非常常疯狂极致的去尝试。
姜文祥的例子告诉我，要持续，IP 要持续才有影响力，高水平的闪现，不如低水平的持续。
因为低水平的持续，其实本身就可以形成对应的用户习惯，习惯自然有心智。

# 第二种套路：先有内容，再有 IP，再持续有社群，持续更新内容，做社群、持续不断做社群，共享参与，带来商业复利，带来持续的 IP 增值。

例子：Scalers（书 + 公众号）、刘艳一只猫（书）
认真拜读过这两位老师的书，真的书是真抓手，书上面灌输这两位的核心理念。Spenser 的核心理念是持续输出、持续学习、持续向上，刘艳一只猫的理念是很多很多素材的大道理构成的。
刘艳一只猫老师的书真的很推荐，大白话一则有一则，对我启发很大。
比如说他写，人不要浪费时间给不重要的人，不重要的人包括不想看见的，见不识的人，等待自己才自己谋财害命，太好了好吗……
书和公号等平台形成势能，持续不断地梳理这个理论大旗下社群商业模式，滚滚洪流，川流不息，学习。
