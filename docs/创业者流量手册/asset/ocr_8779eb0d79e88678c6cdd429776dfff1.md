从微信产品的变化来看，张小龙完美体现了创业者一直在说但很难实现的 8 个字：「战略清晰、执行坚决」。
不轻易抛弃露面表态，深度思考过后，一旦对公众界说的东西，就在被缓缓认真的推进行。

小程序时代，人人都觉得微信互联网会基于小程序成为一个一个中心化的私域端。
可是张小龙偏不，他要让小程序成为链接人和信息、人和商品、人和交易的管道，这是管道；
视频号时代，操盘手们都在叫嚷，视频号没流量啊，怎么弄啊怎么弄啊，不好弄啊。
张小龙说，直接播和视频号是我们针对每一个用户的客观看需求创造的，人们需要另一种内容素材去创作和消费。

注意，没有提流量，仍然是「管道」和「载体」。
微信视频号团队和小程序团队，在声音中不动作色，完成了缓慢但坚定的「管道化」工程，这是张小龙的意志，称这种意志。
张小龙不同于张一鸣，不读 All in 和大力出奇迹，更多从产品底层出发思考，微信的 C 们，要什么，能以什么样的过程，抽离出本质的给得到。
他都是不大力出奇迹的典范，都是坚定不移、静水流深、缓缓更新，
但是现在回头来看小程序、企业微信、视频号、视频号直播、群折叠、公众号的各种小功能，
还是觉得非常初心不改呢，to C 的，
每次研究微信功能更新的时候，总会看到背后的张小龙哲学，也许是一种过度解读，但好受爱。
微信这么大的 App 里做产品更新还趋奇妙的，鳌丝壳里做道场的感觉。
张小龙总会成功，我们也需要这样的「神」成功，微信生态在萎缩，但仍然持续稳定中。
我仍然要这样去中心化的坚守者，让私域存在，让大家能吃饱饭喝足汤，守护自己的存量。
再小的个体，也有自己的品牌，祝福张小龙和微信团队。
天不生张小龙，万古如长夜，天生张小龙，PM 就有了神的高峰，不仅仅是 PM，而是一个经营者的高度。
