# 42、抖音「天猫」化，快手「微信」化

好久没有写过行业咆哮文，历史在催促着我，我的圈阅读者们也在催促我，所以我赶紧出山，正好这几天我有好几个信息输入。
一个是看，看了「快手是什么」这本书，这本书是快手官方研究院联系中信出版社的。
非常详细而且权威地介绍了生态方、创始人、内部业务负责人、网红，都来讲了快手，很稀缺关于快手的信息源。
一个是我经历了抖音、快手双双召开的电商大会，都有电商负责人直接明确地公布自己的电商政策和生态价值观。
今天想对比两场大会和我自己看的书的理解，来谈谈我对抖音和快手两个端的直播逻辑的理解，有非常本质的相同，也有非常本质的不同。

## 一、快手和抖音直播间转化逻辑，都是内容消费转化

## 笑古，快手电商负责人、快手 SVP 说过，以及快手创始人程一笑在「快手是什么？」也这样说过：

## 一、电商品需求来源于：

用户的需求其实就分为三类：确定性需求、非确定性需求和半确定性需求。确定性需求是货架电商满足的，而非确定性和半确定性需求，其实就是直播电商在满足的事情。

本页上，抖音的兴趣电商 VS 快手的非确定性、半确定性电商需求，其实说的就是一个逻辑，一回事情。

直播电商有两个利益点，可以实现很大的交易额，而他们这俩，都在说第一点——直播的本质是递内容，然后产生成交。

用户对于逛一买一逛一买的路径，来源于「逛」的需求，本质是来源于对于内容的需求。

人们可以边消费内容边买东西，甚至不一定是好玩儿、有趣的内容，也许就是电商的内容，也是可以被消费的。

逛买的逻辑，在淘宝也是存在的，淘宝直播不必说，但是淘宝的千人千面，其实更进一步说明了这个问题。

只不过淘宝无法解决的问题是，抖音和快手天然是内容平台，所以天然是先逛（消费）再成交。

但是抖音，还是先买，然后发现，卧槽还可以逛，然后继续成交。

快手抖音，从内容切入的话，DAU 更稳定，以及上限更高，淘宝，牺牲还是一个要买东西的，它们的 DAU 只能上限更低，然后价值更高。

所以，对于抖音和快手而言，其实电商化，对于 App 整个大盘的增长，不仅是 GMV 和广告费，甚至就是用户应该有一个环节，电商消费就是内容本身的一个重要组成部门。

我和抖音、快手交流的时候，都有一个结论，非常明确的结论，从数据来看，快手和抖音的电商交易，并不对 DAU 和时长，产生太多的损耗。非确定性，和兴趣电商，成交从 variance 开始，从消费内容开始，这个本质逻辑，两者完全一样。

## 二、抖音正在 tac 企业化

但是，两者的流量逻辑是完全不一样的，对应的，他对于生态参与方的策略、姿态，都截然不一样，也可以进行对比。

抖音正在加速「天猫化」，什么是天猫化？

抖音天猫化，大概做了 3 个动作：

## 第一，抖音的电商，是从主端这边切到一部分流量，直接通过抖音官方无形的手，通过商业化流量和推荐流量的形式，给到直播间；

## 第二，政策上大量设立权益和引导电商品牌进入，大量签约品牌年框框架，对赌 GMV 之反向返佣流，让 GMV 倒挂出来；

## 第三，产品模式上，直播间、小店、短视频，都大量露出蓝 V 痕迹，向蓝 V 倾斜，并且鼓励「企业自播」。。

你看，品牌的持续长时间自播的直播间，本质上，是不是一个一个，在抖音电商流量池上的动态落地页。

## 揽流盘，来群响

这个和天猫的 SKU 详情页的本质逻辑，是一样的。

总结——一抖音，制造山头、吃流量凿地、扶持牌自播、做持续消耗，和天猫电商的逻辑一样，扶流量控品牌，然后形成生态。所以才会有坊间传闻，抖音电商单独 App。
当然，这还早得很呢……一个 6 个亿的 DAU，今年目标也不到 8000 亿，没到 1 万亿之前，抖音主端远没有到被电商吃干抹净流量的時候。快手亦是也。

## 三、快手一直很「微信」

快手，一直很「微信」，我的意思是说，快手今天笑吉说，直播电商 2.0，我认为其实现没有和快手的 1.0 有本质区别。
我觉得还是这样，快手电商没有变， media 被抖音在过去两年打得很凶，压力很大，但是——同样来， 快手电商的生态根本逻辑，没有变过。

## 本质是——在直播间的场景，用短视频收获的 IP 信任，持续卖货变现。

朴素、简单、直接，这句话在抖音上不可能实现。
因为抖音种了生态方式的私域分发能力，甚至不叫囤牲，叫割割，然后自己控制，自主分发，用商业化、它本身就追求商业化的极致。

快手不一样的是这个价值观，我读那本书才知道因为创始人和生态方的共创，是化学反应。
也是这个价值观，让快手有一群规模不小的基本盘，这个基本盘在抖音的冲击下，还有保持了不小的 C 端的数量，以及 B 端的数量。
这些 C 端用户，只用快手消费内容，只在快手买家人的东西；
这些 B 端用户，只在快手生产内容，陪着他的家人，然后卖给他家人的货。

快手的电商变现，我说过有几个关键词，是形成一套完整业务逻辑的：
内容——借助短视频内容，持续做；
可信任的 IP ——铁子们知道你是可信任的家人；
场景变现——在直播间，每天晚上给家人带货带来实惠。

这是今天十几万人在快手的支撑，正在做的逻辑，当然这个逻辑对品牌就难受了，所以快手商业化，也是需要一点分流量来作为品牌起量和反哺的抓手。
但就算如此，快手生态的入局，品牌还是需要耐心，特别是新国货品牌，我其实内心是觉得速度可能来不及冷启动成功，他就死了。
或许还是应该在快手生态，卖一些不需要解释成本的品牌，这才是快手铁子们眼里的「好品量」。

# 43、创业公司 CEO 应该如何做抖音？

入局抖音半个月，还没有学会怎么持续做内容的我，记录一下俺的困惑和心得喽喽：

+   第一、
**抖音的本质一定是内容平台。**
要在抖音刷流量，必须要持续创造优秀的短视频内容才有流量，没有内容，没有一切。

+   第二、
**创业人的时间是珍贵的。**
先做短视频，然后再做直播，直播要想清楚目的，而不是盲目地追求存在感和互动。
没有日常不直播，特别是自有自己的业务模式的商业公司 CEO。
我非常不建议各位年入 5000 万以上的 CEO All in 抖音直播，我认为短视频的杠杆没吃透之前，别他妈尝试让自己每天直播啊啊啊，没有意义。直播是需要策划分策划划的。
我总结了一些月入 1000 万的抖音 IP 流派和形式，分享给你

+   第三、
**短视频需要长期形成两个目的：稳定质量 * 稳定数量。**
数量和质量相互杠杆，带来基础流量，没有内容，没有投放的 base，也没有任何的流量杠杆进来。
建议大家不要追求爆款，爆款可遇不可求，但是稳定播放量下的量产，是很有意义的，因为这些流量都是抖音免费给你呀。
