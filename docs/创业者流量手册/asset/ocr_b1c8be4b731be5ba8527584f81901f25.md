# 第一，快手的内容运营和电商运营变得更激进

丁真和马保国，这两个的速度都很快，马保国这个事儿啊，真的只能说运气实在太差。

其实在我情绪中的时候，我就看到快手一直在密集做很多很多运营 KOL 的动作，然后到周杰伦来直播。

看到快手的运营团队日益娴熟的花钱技巧，我既欣慰又困惑，欣慰的是快手的执行力，这一年终于稍稍越上一些挡音了，

# 困惑的是，在于：

# 快手的铁子文化的精髓，真的要丢弃么，真的不要他么？

就，快手邀请的那些人，真的都特别的「抖音」，这是我对快手社区化的终极困惑。

快手是要走向一种和抖音全面贴身肉搏，还是要坚持快子文化与下沉市场，当然作为一个 1 亿以上的用户产品，肯定是全民量级的，

但是社区方和产品价值观到底要鼓励什么，要推崇什么。

快手目前的电商 show case 也是，逐渐的和品牌挂钩，希望更洋气一些；

快手目前的 KOL 运营和邀约，也是非常非常地「抖音」，就是全民关注什么，就关注什么。

我很害怕，快手哪一天，真的丢掉了「铁子文化」，打散一个东西，不能用他同样的路径，

但是数据又告诉你，你这样做，你的商业化效率，你的用户数据，也会变得更好。

这两条路，你会选择哪一边呢，我相信快手内也正在选择和观察。

我们私董会会员快手大叔文倩过一句词，「DAU 才是生命」，我相信快手的操盘手们可能更加有切肤之痛，此处十分希望祝愿快手。
