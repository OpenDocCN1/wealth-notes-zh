虽然最真实可能大部分都已经是素人、中腰部为了恰饭的虚假真实，可是仍然不排除小红书在中国上升人群的这一地位。
只要磕青草智商不死，小红书就不死，因此商业化的优先级，要以保护和不损害心智为前提。
那么，直播会损害吗。
不会，但是小红书做直播流量有限，且长期坚持只种草、不拔草，所以交易习惯没有养成的話，不会形成生态，只会是一个一个的桥头堡下的自营养销的流量灌溉产生。
那么，自营交易闭环会损害吗。
其实是会的，但是小红书是很谨慎地把品牌商号和小红书的品牌旗舰店绑在了一起，仿佛在告诉用户，你,id,你可以在这个社区买买。可使用户会买单，用户的路径不以社区运营者的运营路径为转移，因此小红书给品牌带来的渠道销售价值不大。
因此也不能得到优质品牌的精力投入，对于小红书的商业价值也就没有那么大。
还有我们说过 1000 亿以下，毕竟是无论吗？当然要小红书吃负债营，又是另外的模样，但是这样是不是更爱，即做赔偿，有做选择了呀。
要保护心智，还是做 CPM 的营销订单来的最顺，可是这能赚多少钱啊。
还有就是信息流，已经被验证的流量商业化之路，可是 DAU 要是只有 2000 万的上限，那似乎也无法承担起小红书的百亿美金之路。
小红书，半年 150 万稳稳上升人群的种草社区，却要不断拆撸，不得不摇摆，破局点是什么？
谨代表群响若干做小红书种草生意的 MCN 会员，向小红书团队表达敬意和祝福，小红书加油。

# 133、千篇一律的小红书

逐渐从小红书的 DAU 用户转变成一些垂直公众号 IP 的日活用户，令人感慨。小红书和大众点评，供养了一群 PGC 的达人制造业网红店，引导大家造逐同样相同的千篇一律的美食、酒店、发型的、网红打卡点。
我越发觉得，这是一件邪恶而遗憾的事情，然而这是谁的罪？
参差多彩才是世界真实的样子。

但是当你打开小红书，你看到的是什么？
每一个网红都成长一栏：女生必须包头巾、男生必须要有腹肌、野餐必须要有车厘子不能够有黄瓜和鲜肉月饼。
每一个打卡点都必须去拍照的：咖啡必须要有 Arabica，去一个地方一定有一些网红经典去拍照，然后网红经典的元素一定是 Ins 风格。

都一样流水线作业，让人恶心。
