# 群响
獵流派，来群响

甚至针对有一些只有 10 万粉丝、5 万粉丝的博主，他必须要加入联盟，不然广告主多费力啊，投一个就得跟一个人沟通，这些中间的费用，就是广告主愿意付出服务费，差价相当高。
在最早的时候，仍则是百分之一个非常不透明的广告刊例时期的时候，可以多方套娃，广告主也因麻烦，管理这么多腰部的投放沟通，不如放血加价一倍，然后一个服务商来接。
服务商直接回扣 20-40% 给甲方负责人、负责人、MCN 创始人都在一个圈子，新媒体营销圈子，这就是微博时代到公众号时代的狂欢。
那个时候的皮条客，养活了很多小老板，而且真的不需要建造任何内容团队来支撑博主、达人，文字的媒介形态不需要周边基础孵化，全靠博主才华。就比如，每一部手机硬核打出 。
第二类，抖音 MCN 们，必须做内容、必须控流量？必须做变现。
2017 年开始的抖音短视频直播到现在，该入局的已经在局中，短视频对微信没有任何的留恋挤压，通讯工具当然还要用，短视频真正的挤压，是在对爸友圈流量的、公众号流量的，本质上是一个视觉感更丰富的新媒介对老媒介的淘汰。
一段时间，公众号流量上的先锋流派主播他们都一窝蜂开始做抖音短视频，都号称矩阵，都号称千万级粉丝账号矩阵。
这些 MCN 一开始就中了抖音的计，或者说抖音官方也不自知，和生态的内容方的关系发展为何如此近距离和亲密的关系 [对于抖音官方而言其就道路和亲密]：
抖音平台的推荐机制，一开始就强调内容方，有了好的内容就可以得到曝光，虽然一开始 MCN 就知道，粉丝对应的分发能力真的有限，但是是不得已公众号时代做粉丝心态，以及粉丝数量被截囿放在 Pitch Book 上的虚假繁荣光荣，于是一颗辛苦的第一代抖音 MCN 都陷入了一种先投入巨大成本养号、做头部达人、做一个头部号，再来几个的阶式。
很发端，这一种推荐机制下的 DAU 虽然很大，但是是由于推荐机制的存在，用户的倦怠感超级强，内容团队需要不断推陈创新，短视频的创作团队也是一个非常非常非常吃成本的事儿，群响会员应该知道每一个 MCN 团队要养多少个剪辑、脚本运营、拍摄，要签多少个素人才可以成就一个头部，甚至一个 500 万的腰部。
成本高就不说了，要是能变现，本身就算是赚钱好，要命的点是在于，头条的政策是，CPM 订单我需要和你一起喝汤，流量收入你别想吃、流量外移除非你给钱，不然不许你。
唉，你说跌价，你说不听话，不好意思，降权、封号、不沟通，拜拜就拜拜，下一个更乖，抖音官方的流量规则、分类机制、运营团队都是如此的无情。
而正因为流量分发能力不掌握在自己手里，MCN 的达人广告收费受到很大的价格制约，除了头部 MCN 坚定的赚钱、早期入局，成为了头部，除了有一些明星资源和强大商务能力的 MCN 可以早且顺利地运行，其他的号称手握几千万粉丝的抖音矩阵都没啥卵用。
关于这类 MCN 除了变现难之外，还有一个非常头疼的问题，就是 IP 的控制和长期培育复制问题。
