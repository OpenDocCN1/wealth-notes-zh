# 73、视频号不会成功，但私域镰刀有必要进场了！

继在视频号内测的时候，我说的持续不看好视频号的结论。
在视频号大规模开放内测，小龙爸爸以产品之神亲自站台 Mark 数字之后，我休整一下我的结论哈：
视频号从产品维度仍然不会成功，不会比抖音成功，也不会影响什么鬼快手和抖音的 DAU；
但它落下沉流量的、痛著营销训练的精准流量的铁钳子，真的可以入场了，这里水大鱼大，精准流量多！
一、说说我对现在视频号的体会。

大致上：
流量上，放大了 DAU 的入口，赞变多了、内容变多了、评论变多了；
产品上，有了类似票圈一样的好友红点 icon 提醒，吸引人们养成对票圈一样的习惯，但我估计最多最多是「看一看」的习惯；
内容上，主流还是偶部分，一堆孵发美女，一堆孵发营销、励志和个人创业
IP；
整体什么人再用：
对视频号仍然十分有偏见，肉眼看上去，长期使用的是，是偶发的下沉流量
（抱歉还是要说这个词）。
因为视频号的内容真的十分下沉，我看了我爸妈的视频号喜欢，都是非常非常年轻，小板装 style 的。
以及互联网营销人群流量，有非常多被「视频号将是下一个风口」吸引而来的流量竖销的朋。
全都是做营销和流量，但有些是来当镰刀的，有些是来当韭菜的，有消费者，也有生产者。

二、视频号的整体判断。
接受讨论和批判，欢迎留言。
1，视频号不会打败微信和快手。
独立 App 的内容分量、用户记忆、品牌预算、DAU 规模，都不是一个臃肿的微信嫁接的入口能够相比并论的。
从微信维度来讲，视频号的上像是看一看达到的效果，有利于微信小修小补自己被日紧箍的抽搐。
下限是 Story 時刻，浑浑噩噩不知自己的位置，现在中不溜秋地挂在朋友圈上方。

2，视频号对提高私域信任度有妙用。
通过一段时间的观察。
小 IP 原来只能靠朋友圈、社群还有私信，以及中不溜秋的看点直播，来全方位维系自己的 IP  属性，保持和粉丝的互动，维持高信任度。
现在，可以用视频号定期更新，放在自己的图文消息推送以及朋友圈中。
