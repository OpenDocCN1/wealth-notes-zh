# 7,
代运营是指自己啥都不想干的，代运营完了事，省事省心。但是做代运营，对于服务方来说，有三个方面：

+   - 唯基础制作费盈利
- 靠推广技术服务费盈利
- 靠分成来盈利

我感觉是运营的过程，前期可以制作费+技术服务费，后期可以降低基础服务费用，提高佣金比例。
毕竞效果是双向考核，对谁都公平。
