# 83、企业微信养号、裂变、转化实操手册，向张国平学习

继上次广州之行的微信官方团队拜访之旅后，我在我们群响组织的 2021 年新年第一课的世界里，找到了张国平老师对于企业微信的真知灼见。

张国平是一个人很少话多的男人，但是对于企业微信的实操认知和未来发展，特别是对于大中小企业如何使用的细节，他的分享中，说的特别多，特别详细。

我认真打印了他的逐字稿阅读，并记录了我自己的一些思考和学习笔记，真的非常实操。可以和上一篇分享互相借鉴和参看，简直就是企业微信养号、裂变、转化实操手册。

1、
单个企业微信。 الرجاء ملاحظة...

单个企业微信。一天只能发送少于 100 次的主动添加好友请求。且，大部分没有“成熟”的企业微信号就算你发送了 100 次请求，客户那边实际上收到提醒的只有 20%。

2、
关于个人微信号转移到企业微信号，做流量池的情况。

目前很多企业微信服务商提供群控系统批量添加，但这个请求发送到客户那边的时候，也只是一个“业务通知”。大部分 C 端用户是不会看到这个东西的。有一个笨办法的，在企业微信里拉群，再把个人微信拉到群中，在群里，用企业微信添加个人微信的方式，我们操作过，有 40% 的转成成功率。

3、
如果养号是问题。

养号是核心关键的，企业微信风控考核的数据指标有：客户加人通过率、客户回复率、删除率和投诉率。第一、刚申请主体，不要立刻马上加人，一旦加人通过率不高，以及聊天指标不好，这个号陷入恶性循环，号很难养了。第二、一开始，建议大家先愁办法让客户来加你，被动聊天远比主动聊天；第三、聊天天数指标很重要，有很多客户聊天，企业微信看的就是一开始的 1000 多人和你的聊天天数；第四、投诉指标很重要，尽量不要有投诉；第五、被动加人是非常有利于养号。

4、
国平说，他们摸索了 2 年，最佳的养号场景，就是新主体、新账号注册下来，用它来做客服。只要你的业务是正常的业务，指标不会差到哪里去。以及用企业微信做客服，真的比用其他系统做客服，服务优秀太多了。离客户近，就是很重要的。
