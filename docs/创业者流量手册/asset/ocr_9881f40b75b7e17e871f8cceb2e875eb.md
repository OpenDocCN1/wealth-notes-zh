# 做账号那种。

做赚钱与和中间商、做流量和供给端的中间商，随着流量浪潮的迁移而迁移，然后不 All in，赚差价和服务费；

这就是抖音平台的源单时代，出来了出来了，明年预计大规模常态化，现在在水下游默无闻赚钱中。

这一幕最大的挑战是，

第一，流量不够多，因为做账号需要天赋、需要成本、需要时间，而供给端只要 ROI 跑平就喊破；

第二，抖音有随时随地关闭渠道的权力。上一层视角的抖音知道一切，只是看关不关你，罢了。

另外，号也是一个非常大的成本！也是非常大的门槛！他们怎么解决号的问题呢？

他们对抖音账号的封杀号的封杀策略，和微信个人号的对抗一样，叫做「大隐隐于市」，他们用真正的号对战封杀号。

什么叫真正的号，就是真的让人肉注册的，真实的人、真实的身份证、真实的账号运营；用这些人来上传短视频、来买东西，他们的账号不被封杀的核心原因，竟然是他们都是真人儿啊。

抖音矩阵的难度是，如何让批量生产的内容，可以长期持续俺抖音给的公域流量，而第一个难度就是怎么有长期的安全的白号了。

白号本身的生产和持续运营都需要时间与巨大的成本了，可怕。

派单适合我，感觉这个生意。

还有好多品类都可以，满足以下特点即可：

+   1. 可以线上微信成交；
2. 可以线上轻量级履约；
3. 抖音内容可以获取到精准流量。
