# 20、抖音知识镰刀的盘点与调研

# 镰刀应该长什么样？

给几个我的观察，供诸位参考：

+   1.

有圈层类产品，卖圈子，圈子是一个非标品，这个东西、目前张诗童卖得最好，4000 份左右。
但作为一个在私域 12 万粉以及已经有了 1999 元的会员圈层产品的创业公司，我们在圈层产品上，要谨慎、再谨慎。
他很核心的点在于，他可以免选你的粉丝，然后因为你的粉丝爱你，他会直接来买，而且无理由，无退货。
虚拟产品嘛，而且是爱的虚拟产品，买卖达成的那一刻，其实大部份行为都完事儿了。
但是他很不棒的点在于，其实你还是要运营一个圈子的。
圈子不变还是会带来一些不是粉丝或者报一些粉丝的差评，差评带来的反噬是很大的。
所以说圈层要卖也就要把他“标”起来，非标变标。
所以，抖音上卖圈层的铁子，没有卖过 5000 份的，还都他妈是 199 - 399 元，我想说卖了个寂寞。

+   2.

199 爆款课、知识付费和引流的角色
