但直播间会消耗时长、消耗用户心智、消耗用户的广告库存，比短视频广告消耗更快，转化率反而未必更好。

# 二、全民直播后，红利期迅速退散，卷到地主家也没余粮。

如此大的流量消耗，为什么抖音要大水漫灌直播广场。

因为需要形成用户的成交习惯，直播的流量消耗大，但是一旦进来，转化率高，且高客单价必须需要靠直播转化。

核心目的就是交易额，以及内容用户标签。

直播内容、短视频内容、成交信息，三维度的用户标签的让算法吃得更饱、推得更准。

抖音官方平台大水漫灌，让直播间算法推荐和短视频算法推荐平行。

就算是 0 粉起号，只要你的停留、你的成交指标好，就可以作为一个基础单元，承接抖音爸爸给予的流量扶持，俗称「推荐流量」。

推荐流量占比较 50% 是及格线，这是几乎所有电商直播间运营的基础，也是抖音电商直播为什么如此疯狂的原因。
