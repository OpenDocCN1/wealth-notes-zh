# 5,

有预算的客户, 在企业微信中建议用私有化部署的方式来做, 因为只要流量够大, 一定会涉及到系统平均分配加人请这个事儿, 分配到 N 个手机。
这个技术的难点在于, 要避免让腾讯检测出你是用软件批量加的, 因此最安全的是私有化。
(刘思毅评价: 当然, 小客户最安全的是, 被动添加。手动添加这么辛苦的话, 真的应该是很少很珍贵的量吧, 那还是建议平行使用个人微信号)

# 6,

请务必注意电话号码的保密性和安全性。
2021 年执行的民法典中规定, 使用来历不明的手机号码进行商业操作是一件违法的事。
以及, 未知的号码, 通过率非常低, 会影响账号权重。

# 7,

在企业微信做私域, 我们还是提倡和官方共赢, 即: 官方禁止的不做, 官方提倡的遵行。
我们觉得有一个路径, 就是实时加人。
如, 你的天猫店刚刚有人买了一商品, winkel 钟后你就找一理由加他们, 或者你让他们主动找你。
如, 你的 App 刚有人注册, 马上找个类似的「为了更好服务 ta」的理由加人。
基于用户正常体感上的加人通过率, 高于 30%, 是最好的私域拉新方式。

# 8,

被动加人的技术细节: 加人二维码的选择问题。
不能用企业微信客户端员工号的二维码, 这个二维码被动加人有明确的限制, 一天 500 个 (应该是比较好的号了); 
应试用企业微信官方后台管理的「联系我」功能, 在这里生成的活码, 即使活码后面是一个员工, 也比前者好。
我们以测试过, 活码在一个企业微信账号外套一层, 一天被动加 4000 多没有到上限。

# 9,

私有化部署有利于大批量流量的承接、客服, 私有化部署可以支持机器人回复, 用极致的人工智能来筛选实在不能回答的问题, 然后再推送到人工去回复。
