# 哪儿的成功可以复制，天才及奋斗家会自动去哪儿。

淘宝是中国在过去 5-10 年中最大的创业阵地，这么大的创业阵地里面成功的内容人，却寥寥无几个人。

淘宝帮助无数品牌和人成功，但淘宝的内容生态让无数的内容人，在这里面做了无用功。

淘宝做内容本就是一条艰难的路，和抖音等平台是非对称竞争。从先发到落后，这八年是非成败，本文为大家娓娓道来。

# 一、这些年淘宝内容没打赢的仗

“我没有输，只是我打不赢”

约十年前，网页淘宝有了自己 SNS 内容社区“淘江湖”，引导用户及商家分享购物攻略，早上小红书十年试水内容社区。

14 年起，基于提升手机淘宝停留时长、避免淘宝变成交价工具（去做 ול链路从种草到成交的一体化）等原因，高层对内容的重视程度加码，布暑了“淘宝达人”及“淘宝头条”两条业务线，启动了手机淘宝的内容生态。

“淘宝达人”业务源自做成的淘宝淘淘，由时寰客这十年淘宝内容生态的总负责人人周钟带领。

那两条业务重心是为淘宝内容生态引入专业的的内容创作者，找了很多媒体、淘女郎（服装店主及模特）及电商从业者，邀请他们成为淘宝达人创作者内容，同时在手机淘宝页面逐步搭建内容呈现的场 景。

# 淘宝头条从传统/线上媒体侧挖来近百人入职，并引入中国大部分的头部媒体账号进入淘宝头条运营，也邀请了各类内容创作者来淘宝头条里面做内容。

淘宝头条受限于电商内置产品的角色，极难实现自身全面对标今日头条的野心。

而媒体变现困难及淘宝型内容逐渐占据主番流，是淘宝头条在内容电商上由盛而衰的主要因素。

淘宝内容场中，一篇标题是《天了噜，我发现了比离式的马桶更好用的东西》的文章，用户点击进来看到的是一组式的马桶的照片及 100 多的文章。这一篇文章阅读两百多万，马桶卖空当场，CPS 拿走上百万。

无数嗅到血味的淘客型团队，打着内容创作者的名义入驻。

他们找到了做内容的持续的动力，一天养一百个账号，每个账号每天发几十篇内容，一天上万条淘客型内容迎来赚爆文。
