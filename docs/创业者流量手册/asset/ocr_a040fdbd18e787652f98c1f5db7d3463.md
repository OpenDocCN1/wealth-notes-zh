# 掏流量，来群响

我们这次万人报名大会，包括上次的群响续费活动，包括群响刚刚开张时候的宣传活动，我们都以一费之地秉承着一个方针：

+   - 第一，坚守 C2C 地推进；
- 第二，只要转发只要有效果，不害怕手紧；
- 第三，苍蝇腿儿也是肉，不放过一丝一毫的有效流量。

群响做的是一个 to B 的生意，to B 的流量其实不来自于公域流量，其实来自于各位客户的朋友圈，客户的朋友圈才是<|message|> 最精准的流量池，以及一些精准的社群，才是有效的流量池，以及一些和我们非直接友商的 to B 伙伴，也是有效的流量池。

这些流量是散落的，有些是需要人肉淡谈的，有些是需要直接私聊跟进的，要落实性的发散策略，就必须全员用私聊的方式，去推动转发，促进整个 event 在行业范围内的扩大。
所以很多读者和社会同问我们，为什么群响每次做出来的行业声音这么大，我都想说，这夸夸都哈每次活动用了很多时间戳出来的啊朋友们。

另外，我们的类细分化运菅经验，延续现在我们的活动上，和得到的逐步类似，我认为一切线上的东西，一旦停止运营一周，用户就会淡忘你，或者觉得你是不是跑路了。

因此我们每周做两场线上活动，高密度地积极触及我们的用户，每周一场是信息类，一场是资源对接类，用专业的运营团队去触达内容的生产者，目前已经坚持了一年。
