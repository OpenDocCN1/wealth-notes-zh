# 第三，流量有巨大的不安全感。

05,
品牌对于天猫，是主营阵地，核心是，天猫最牛通的就是常销。
第一，用户心智；
第二，日常动销；
第三，客服、供应链、活动、品牌故事、正品旗舰保障的全链路阵地。

06,
日不落自播的本质，是模仿货架，塑造长销。

07,
品牌不断}}+品牌不断?品牌不断减价、不断促销，不促不销，天猫旗舰店的自然销量降低到没有意义，变成了锚定价格的工具，而不是阵地。

08,
抖音为什么要提「私域」，为什么要做搜索流量，为什么要做独立 App，要给品牌肉，要给品牌希望。
当品牌在抖音专营绝望，绝望的话，抖音也越来越难以收得上消耗和 GMV，商家的话语权，会让他们的预算消失。
要让商家自治，要让抖音成为新的经营阵地。

09,
直播间的供给也是有天花板的，短视频的供给是几乎无限的，
平台的核心竞争力是内容供给能力；
商家的核心竞争力是内容带来的转化能力；

10,
疫情后，抖音的短视频供给成指数增加，单列短视频消费效率本来就高，抖音的单列有了充足的短视频供给，就有了更优秀的体验。
疫情让快手和抖音的 DAU 都增加，但抖音单列吸引了更多人，留住了更多人。

11,
短视频团闭、利消更可观：直播团队，除了顶流达人，利消太少了。

12,
抖音不仅仅竞价排名，即使抖音只有你一个人出价，也会把价格拉升，保护用户的耐受度，保证用户的停留时长和用户规模。
不断提升单价，不断压缩利润，提高用户引入到电商的速度，这是抖音平台对用户和商家的取舍和平衡。

13,
算法推荐的流量切割，让平台、商家、用户纷纷导入内卷啊，失控，快手和抖音对流量的颗粒度和推荐，都是很强的，但是会导向不同的商业安排。

14,
用户时长是一切，从直播和短视频的流量分配，从达人和商家的流量分配，都是如此，快手和抖音都要看这个，一切以用户为主。

15,
小店无论是快手还是抖音，都缺乏经营抓手，通路太少了，只有短视频和直播，无法经营，无法有存量。
