# （三）案例分析

# 99、种草、刷单、SEO，一种虚假的「真实繁荣」

这一周接待了很多做种草的会员，广义的「种草」业务品类繁多、劳尽地话，有小红书种草、抖音种草、品牌 SEO 管理与知乎营销、微博种草公关、刷单。5 个大类，运营行为的本质，都是要为品牌，或者是更广泛的甲方，制造 to C 的虚假的「真实繁荣」，抛开道德正确，可以细品一品。接下来一个一个类举去分析。

# 一、小红书种草：消费品标配，素人 + 腰部 + 头部配合。

小红书 MAU 4000 万，DAU 1200 万上下浮动，是中国目前最 Ins 的地方，这个心智影响广告主，也影响普通的用户。对普通用户来说，平时去哪里玩儿、买啥东西，不可以只用大众点评，更应该用小红书。小红书上带火了相当多的国货品牌，2018 年整个一年是小红书的最大红利期，职业种草的机构不多，品牌不多，可以捕捉到大量的真实流量在小红书种草，在天猫放草。PWU、完美日记为代表的早一批新国货享受到了这个红利，甚至自己组建一堆小红书推广团队（实习生完成），与素人进行对接。目目前小红书种草业务，杂活了国内至少 1000 家小工作室，3 万一单起，300 - 500 条素饵营销人员发布，良心的会有的专业收录，这个业务对于国货品牌来说，虽然是没有效量红利但又不得不做的业务。小红书种草业务的核心环节，沟通文案、把握大量素人资源，并可以有效管理，一触即发，看起来毛利不高，实训实现 SOP 化后；能有 70% 左右的毛利，重在管理，且对于品牌营销来说起码按例需。目前酒店、消费品、餐饮等行业，普通都要做小红书营销。

# 二、抖音种草：对接商品与 KOL，用无数个微信群，然后期待一点点品效合一。

抖音种草是一个似乎比小红书更难度，而且有运营成本的生意，因为媒介形态的生产成本还是要更高的，要拍摄一个短视频、需要给 KOL 或者素人 KOL 寄送样品，需要沟通清楚价格，甚至还要挂车，设置佣金。群响有一家机构，专注于做抖音素人种草邪恶营销服务，成为一个劳动密集型业委会企业的代表，毛利不高但重在产品化之后，能接到多的素人且多稳定（意味着可以靠样品批量稳定的触达），自己对品、对短视频内容的理解可能也会有经验和与小红书种草一样，素人适合与中腰部投放、大型事件、头部投放结合起来，作为一种繁荣的基调，且抖音也有可能得到一些几率较低但并 feasibility 不可能的直接跳转淘宝成交，素人的短视频有这个转化 ROI 之后，抖音支持你用抖 + 作为杠杆，这是比小红书更好的点。
