# 第三，To 外部的 CEO 学习者

啊，对于外界而言，我真的是字节跳动文化的忠实粉丝和学习者，我热爱张一鸣作为 CEO 的魄力和勇气，以及热爱字节跳动这家公司在 lark 等产品上体现的简洁和精致。
OKR 这个方式对我受益匪浅，对我们公司的条分缕析也非常有帮助，可那就这样了。
CEO 不应该过早迷恋成字节跳动，也不应该过早觉得自己就是张一鸣，张一鸣的很多观点，在我看来，不适用于小公司。
大打出奇迹，小公司没有钱，没有大力；
延迟满足感，小公司的团队要是延迟满足感，人都没有了；
招聘高的人，小公司没有办法招到最棒的，最合适的，现在就要，现在就来；
保守对兄弟，小公司没有预判。
我觉得 CEO 大可不必听信和学习张一鸣和字节跳动在组织上的一些学问和认知，因为大部分的都还用不上，我指的是还没突破 5000 万的 CEO 哈哈哈，太大的我没见过，但是 5000 万年销售额的 CEO 爸爸们告诉我，这些都是扯淡子。
5000 万之前，仔细学，然后自己学，然后再说。

# 第四，To 互联网全局局

短视频和数据化，是两个时代级的主题。
短视频是一种基础媒介形态，这是已经被验证的了，用快手和抖音的 DAU 和时长累验证的，也是用微微信的视频号来验证的。
数据化是真的特别特别有魅力。
想象一下，我们以后所有的的数据全部在云端的巨头手里，那我们几乎一丝不挂，无法掌控一切，反差断和无序扩张的意义是有。
字节跳动对于这两个主题，拿着至少 1.5 张牌照，数据化，在交易层面的数据还欠缺。
