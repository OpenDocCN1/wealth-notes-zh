# 揽流篇，来群响

从今日头条这样，算法推荐的图文消息悬浮流的产品形式看，瀑布流被用户不断刷新，不断阅读。
在瀑布流中 5 条内容加塞一条广告，广告的密度被提高，因此广告的库存提高，而广告的单价也变得更加亲民。
这个错误是更适合规模化放量，且适合更低客单价的模型。
但是对于高客单价、或者是高决策时间的产品，这个模型仍然大概率不能直接成交，只是能拿 leads。
而且只能拿 leads，去慢慢在私域中做转化，这是今天的教育 K12 在抖音上做的，尚德教育也是如此。

而搜索不同，用户主动搜索和被动推荐，用户的认知、以及决策的成熟度有迥然的差异。
当一个用户主动搜索某项东西，转化率和认知加工的深度已经决定了 —— 基于搜索逻辑的内容营销非常适合高客单价、高决策产品获客和短期转化。

# 搜索逻辑下的平台有什么？
除了百度、知乎这些传统的搜索逻辑，群响会给大家很多意想不到的搜索环境，搜新知、到 QQ 群、EDM、微信、微信煲。

# 二、搜索逻辑下的获客流程

以知乎和百度为例，看用户在不同转化周期中，是如何做各种决策，然后映射到搜索中的呢？
因此第一步——即把用户的转化周期切段，其实本质上，大部分高决策类产品，（大概率高决策就意味着高价格，高价格本身就是高决策的重要原因哈），包括 3 个阶段

# 1, 需求萌芽阶段——

萌芽阶段是一层漏斗，需要用第一层漏斗的大池子来进行更进一步的运营，这个池子要大。
以群响为例来思考问题，中层、小老板，遇到什么样的问题，才会去被激发需求，激发的是什么需求？
——思想的是为什么需要社群？社群可以帮助你什么？
以一个考公务员或者考研选择投放人群为例？什么样的人会思考什么需求的时候，想到他们？
——就是选中考和高考失利，选择职业方向

# 2, 需求比较阶段——

有明确需求，更要对比各种能满足需求的供给方是谁，有谁。
这个时候谁是关键。
因此核心是品牌曝光，要让他们知道这个品牌存在。
如群响要做大的就是，品类词上的营销和曝光，在知识上的映射就是——有哪些非常道的社群？

# 3, 决策最终阶段——

此时用户进入最后一个阶段，进行消费决策，明确决定，是不是需要买群响！
因此这一阶段的词和问题，变成了对于群响品牌的维护，以及官网的建设。
