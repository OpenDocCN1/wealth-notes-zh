# 48、抖音的水下派单生态

前些时候和一个抖音黑客一起喝酒, 了解了一下他们矩阵大如牛的打法。

她说, 目前有小说赛道、歌曲赛道、PPT 书单赛道这几个赛道在批量尝试。
变化, 这些赛道的变更很粗粝简单, 粗粝简单到我觉得微信公众号时代的派单生态还可以再来一遍啊。

小说赛道就是拿抖音的播放量去换私域量, 然后私域量直接卖付费小说。一个 CPM 能换多少钱, 算出来之后, 就变成了公众号时代的派单逻辑;
歌曲赛道, 更显粗暴, 和原先在今日头条 App 上派单的电影宣发一样, 歌曲发行渠道也需要多如牛毛的广撒网。
这些歌曲在海量账号上的传播, 就是有价值的, 因为也是派单逻辑。
发行公司嗅觉到抖音上, 让一个派单头子分发给更多的个体户, 做成歌曲赛道的个体户。
PPT 书单赛道, 更为简单, 每一个视频都要挂小黄车, 每一个视频都选择对应的高佣金的书来进行商务。
不用在意一城一池的得失, 就用人力去恐, 一个个体户要做 10 个号、100 个号, 疯狂起。

也有专门做这样的供应链的派单头子。
目前, 各个品类都有需要连接供应链和流量端的拉拢条机会, 因此每一个品类都可以有派单王, 这个派单毛利率不会特别高, 但胜在量大。

派单要做好,
一边是供给, 要稳定、要大量、要最低价, 把上游打死, 干到最低价, 这样你才可以有差价可拿;
