# 1、抖音小店会成为越来越稳定的交易赛道

很简单，因为抖音的流量都在那边，抖音是一个官方指挥棒大于一切的地方，官方希望跟工农告入，又有 GMV，所以说电商平台一定是抖音要发展的。

要发展电商，就不会绕过抖音小店，因此小店会成为流量转化的媒介基础，那么需要抖音赛道能流转。

尽管商家这边可能长年打开面向需要在淘宝天猫上运营的商家，但是直接成交带来的转化率肯定比跳转高，而且直播只支持小店来愁小店。因此，每一个进抖音的铁子，都需要做小店。

# 2、抖音小店还没有天猫的流量反哺，就不是闭环

目前小店还没有大的问题，除了抖音电商目前还没有完整的强悍的，如阿里一样的运营品类的能力，以及可调度的资源和话语权还不足以做更多活动之外，还有一个非常重要的一点。

抖音小店这今为止只是一个抖音中的「有赞」这样的交易工具，事实上起手也一样，为平台收集交易数据，然后为平台提供费率收入，这是 to B SAAS 啦。

当然，你可以说抖音有流量，就需要不断投，不断在这个媒介工具上成交，只要有源源不断的流量，就会有源源不断的成交，因此商家就来卖。这卖货的做法，这确实是短期主义的做法。

要说商家真的把它们当成一个平台来做，抖音小店需要在自己的流量池中让商家有自己的阵地。

什么是阵地，就是让品牌商家在抖音这个端中，有一个可以自己可以用来自忠诚度运营、品牌运营、用户运营的中心化流量池。
