三层筛选，一层是短视频内容运营的精准粉丝关注，然后基于关注下的精准粉丝引导直播，进一步最后第三层，直播下的下单购买用户，加入客服，客服不是人物，是自己做直播的 IP 人设吗。完美的手工流量操作方式，让内容在渠道中流动的完美案例，但是被端需要创始人热情和团队的耐心，大概率作为小公司需要是创始人或者二把手级别的人来担任 IP 输出的角色，就好像群响我的这个角色一样。祝大家在抖音赚钱啊。

# 8、抖音 MCN 要么灭亡，要么自己闭环解决商业化。

作为一个舶来的概念，MCN 在中国的发展已经远超过 Youtube 这样的舶来方。

得益于中国人对财富的渴望、对资源的极致运营以及对拉皮条业务的热 software 程度，在不同的流量平台作为主流的不同阶段，MCN 的业务形态都有非常大的不同。

但是不管怎么变，MCN 的业务关键要始终不变，有以下结构：

+   1. 平台的流量获取与变卖，核心关键是流量分发能力的把握，微信允许公众号号有强大的分发，是官方允许下的最强流量池，抖音则不同；
2. 作为 MCN 流量形态的关键的 IP、红人、基础流量参与方；
3. 作为 MCN 变现关键的广告主爸爸，或者自己操盘流量变现。
平台、达人、变现，核心的关键 3 个要素

MCN 与平台、MCN 与达人、MCN 与变现的 3个要素。在不同的流量平台、不同历史阶段情况不同，可以分别总结讨论，有助于希望进入军 MCN 的铁子们认清恐惧现实。

群响的很多会员都在问我，要不要进军短视频、进军淘宝直播、进军快手，去做 MCN，看到来一些群响会员做的非常好，流量非常好，变现，似乎也还好。

在这里我开个头：

+   1. 当前大部分短视频 MCN 已经进入拼战巨大、红海无限、流量紧缺、新生流量困难、已有存量达人变现艰难的时期，谨慎入场短视频 MCN。
2. MCN 作为一个典型的短视频行业的组成要素，要开始自己解决流量引导和商业化的闭环，才可以生存，这是目前流量状态对 MCN 行业提出的新议题和生存要求。
除 了短视频 MCN 之外，还有基于快手的直播家族 MCN、淘宝 MCN、卖货直播类机构 MCN、微信微博时代的老 MCN，我们下面一个一个来分析一下，彻底打消群响会员希望进军 MCN 的野心。
