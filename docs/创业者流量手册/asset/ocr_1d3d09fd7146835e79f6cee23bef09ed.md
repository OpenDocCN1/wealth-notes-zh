# 心不在焉。

想想也是，抖音自己公司的人就是快速轮训。从人性角度出发，自己在抖音都不太可能来考虑会怎么样，哪里会考虑别人的未来规划。
我们群响和抖音对接的感觉也是这样。

其实很多事情无法确定是谁来做，抖音这么大条船上，你知道吗，电商都不止一个部门在移动，更不用说更多的细节。

内部相互耦合，所以说生态和官方的连续性都很难，无从职业战略的更新速度，还是从生态政策延展来看，还是从人员的配备成熟度以及流动速度，都太快了。

这对于抖音来说，无疑很有棒，会因为持续在进化，但速度超出所有人的想象，很难有 DP 能够提供稳定的服务。

还有一个很重要的事，DP 很难稳定自己的业务线，SOP 都很难，因为抖音 3 个月一变的特点，使时代运营乙方，无法真正进入到标准化——梳理好的流程，又变了，又得重新学习。
然后代运营方的精力都在学习新的东西上，这就是一个投入成本很高的必然趋势。

但坦白说，目前代运营方和品牌，以及抖音小自自己三方都对这个没概念，对这个成本都没概念，大家还在一窝蜂地上和抢钱，但是钱是不是你的，真不一定。

第三，抖音允许极大的差距出现，DP 同理，抖音的削山头政策，又意味着不让别人做大，这里的别人，指品牌，指达人，当然也指 DP。
代运营一个品牌方，只能做得到几千万一个月，就无法再获得增长，你好不容易研究好的一类菜品，不吃饱到很多果实。
不能和淘宝那样吃到，大量的类目第一带的额外溢价，这样的话就算孵种，也不能实现一个很根的杠杆。
投入无上限，收入有上限，抖音是一个会吃掉品牌方和代运营精力和利润的怪物。

以及，没有巨大的差距，但大量的入局，又一次摊薄了本身的红利窗口，最近应该会很明显地发现，生意难做了很多很多，群响很悲伤的看到，直播流量还是不够吃了。

海去红了。

最后，但是还是不得不说，无论抖音 DP 好不好做，它仍然无法阻止品牌爸爸们把大量的精力和以及增长的希望，放在抖音上。

这几天收到的数据，分享一下蝉妈妈对 2021 年 2 月份带货超过 100 万销售额企业的直播数据分析：64.7% 的达人直播占比，35.3%，35.6% 的达人粉丝数低于 10 万。
