# 摇头流，来群响

从前年开始，甚至从更早期间，阿里巴巴就意识到，SKU 的内容形态可能从纯图文、视频溢价，要变成整版短视频，在这个路径尝试中，又发现了“淘宝直播”。

新电商时代的路上，又有了快手和抖音这两个巨大的竖版短视频内容平台，加上电商元素之后，赋予了不确定性的消费需求，巨大的 GMV 意义。

但是今天，业内还是对一个问题有困惑：从图文时代到短视频、直播时代，我们真的可以把每一个 SKU 在公域的分发逻辑，全部基于短视频和直播吗？

我和蘑菇街短播团队，讨论过这个问题，很有意思的答案。蘑菇街作为一块试验田，在这个问题上，非常坚决，因为流量盘子小，反而有一些更坚决和明确的容错。
他们有两点实践认知，值得品读：

# 第一，用户比想象中更懒。

大量的让内容进入类目和搜索中，从消费者用脚投票的角度来讲，点击率与销售转化比传统图文商品要好，尤其是转化率差距不让我透露。注意，是大量进入来播，短视频类的内容腰部了图文。

# 第二，直播的心智转化，短视频到直播路径更短。

电商的漏斗模型是有 一个新用户进来，下线了一个新用户，然后它变成了我的成熟用户，然后变成了 一个直播用户，当它成为直播用户之后，它的单播率很高，因为他的留存很高，复购忠诚度都很高，但难就难在他从一个购买用户变成一个直播用户。短播购买用户的几率和成为一个图文商品购买几率即使是差不多的，但更加速了它变成一个直播购买用户，因为那是一套体系的东西。

# 三、品牌的内在能力，是否聚焦在商品内？

这是我最近最大的困惑，在群响遇到很多很多商家，在抖音和淘宝两大平台的政策宣导下，都有一个两难的心态：

# 一方面

平台明确在政策上提出，必须要品加 加强内容能力，淘宝这方面的诉求是全方面短视频化需要内容（但这招没用，因为本质还是交易平台，不是内容平台），抒写这方面的诉求，是全面保住 DAU 对内容的消费需求。

# 一方面

商家就不 会做多样化的内容，抑或说，商家做多样化 的高质量内容成本，是极高的，是人力成本、组织成本还有本身操盘手的精力分配的问题。前后是互斥的，商家目前还没有对直播的精细化运营能力，却要被要求，提高在平台的短视频能力了，这是现状。

和蘑菇街讨论为，我觉得他们在自己内解，很明确：

# 第一，蘑菇街作为一个平台，就是已经消费者逛街心智的平台。

# 第二，逛街平台，这个平台电商属性第一，成交第一。

# 第三，基于以上两点，内容属性服务消费着成交，和电商相关的内容，也可以被蘑菇街的消费者持续接收并持续消费。
