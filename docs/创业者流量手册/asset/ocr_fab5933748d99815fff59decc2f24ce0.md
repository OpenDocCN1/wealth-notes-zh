# 2, 发现页面，默认添加了附近的直播和人

点击进入，可以看到附近的人的微信，可以打招呼（这是原先的功能，很奇怪为什么又放出来），可以看附近的视频号直播，可以看附近人发的视频号。这三个也是希望赋能 UGC 带来更多流量，让他们坚待。

可惜啊，我真的不觉得 UGC 能够被这样的金刚位带来的自然 UV 的短时间停留激励。从我们群响会员和群响自己做私域的垂偶来看，大部分的流量都是要囤积在微信池，然后经过自己的强力触达和运营，或产生信任，或本身自控量比较大，才能做得到。

目前 LBS 带来的流量，首先单个金刚位的位置带来的总 UV 有限，其次这个量分配到每一个主播手里，还是太小。我们首先要明确的是，直播是一个巨大的流量消耗品，其需要很多流量，这个导入对生态的 UV 有好处，但是对优质直播的赋能并不大。

什么，你说对 UGC，我再说一次，我认为视频号不是人人都能玩儿的。微信天天希望 UGC，全民开始玩儿视频 但是又加入了公域算法，加入了推荐，就是 PGC 的战场，PGC 的战场要解决的是：自控流量的分发推荐问题。这个问题即使加上了微信的社交关系推荐，有这个 buff，还是没有办法解决，微信自控流量池不大达这个核心问题，自控流量不大，吸引力不够。
