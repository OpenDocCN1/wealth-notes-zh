# （二）小红书策略

# 132、摇摆的小红书：种草社区、封闭平台还是阿里后花园？

摇摆的小红书，摇摆于交易平台的婆娑之路，还是做种草社区。

毛文超对社区有执念，非常强大的执念，从他一直以来对商业化的抑制就可见一斑。

小红书团队的电商部门，一直不够强势。在团队内部也不够有话语权，前任电商负责人 Gary 在协调商业化之后，迅速离职之后的电商部门不再是一个独立的体系。

事实上，社区类型的 DAU 驱动的产品，在电商商业化上都有一种明确的大困难，就是如何安置电商部门。

快手同祥如此，快手的电商生意根于社区流量、短视频内容和直播打赏，从业务分 tarn 的角度来看，电商几乎和所有基础业务部门都有交叉重合，要期待这样一个部门在一个社区产品中扮演何种角色？

调度和 savun 呢？需要 CEO 的授权，没有授权就势必会陷入一种扯皮；运营 agreement 的电商商业化整合吗？扶手的类双 tracked 类似的事情，分品类、模仿天猫有品类的二三生态平台演变，组织流量、组织商品、组织出 GMV。

但是小红书目前看来还是一片混沌，这是小红书自从树立起用户中心的第一种草平台之后，整个团队一直在会面临的问题：

小红书，究竟要走哪一条路？本质上有 3 条路：

# 第一条，彻底底层成为一个阿里 后花园，打通直达淘宝得交易渠道。

阿里是爱受流量，小红书要是有希望委身于阿里的话，或者小红书想卖的话，从业务视角来看，阿里几乎是唯一的理想买家，美团似乎也可以，但是如果阿里在业务线上望尘。

但是小红书从业务和融资格侧，都在极力讲述自己的故事，避免阿里化是小红书一直以来的坚持。

阿里的后花园，会是如何的，如同微博，全面开放给阿里生态体系，进行全盘的广告端频频商业化变现。

这一点对于小红书的社区坚守来说，几乎是一种毁灭性的打击，成为后花园意味着从上到下，整个生态由官方开始，被商业化的 ROI 主导。

效果广告全面对电商开放导致的第一结果就是，种草不公允、心智不稳定，后花园的荒芜几乎是一种必然。半载裁定终的流量资产，竭泽而渔的下场，是一个巨大的商业化引擎各部分的博弈的最终结果。

从阿里体系来看，阿里当然期待一个寿命更长、心智稳定的健康小红书，可是一旦流量入口打通，需要疯狂增长的 GMV 目标不允许这样的理想情况发生。

# 第二条，坚定的只种草、不拔草，成为一个坚定的生活方式社区。

这是最理想的状态，也是最舒适的状态，也是毛文超团队正在做且一直以来非常拿手。
