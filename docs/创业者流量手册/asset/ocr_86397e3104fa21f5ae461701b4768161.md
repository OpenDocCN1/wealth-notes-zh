# 微信为什么没有吃掉所有利润？

因为作为 IM 它是工具，工具的代价就是没有巨大的流量分发能力啊，而且还是一个通讯工具啊，他要是流量分发，用户马上抛弃他。
所以最好就是微信的生命周期足够漫长，在有限可腾挪的空间中，如抽屉一样的创新。

好处就是用户信任微信，是一个有一个消息就是我需要的消息的那种，所以用户不会觉得，微信要持续创新。

微信的持续创新，直播、视频号、以及各种各样的⼩插件、小窗口，很大部分是腾讯内部的焦虑驱动下的产品经理自我创新。

我并不觉得今天的微信没有这些创新会怎样的。

一句话说微信的矛盾之处是：腾讯集团日益增长的焦虑，需要求创新，与人民群众用微信用得好好的，其实没有必要和要创新矛盾的矛盾。

那 multispace，抖音的主要矛盾是：字节跳动需要更多增长的需求，与人群粉丝众虽然觉得抖音很牛逼，但是已经快被挤压得没有利润要跑路的矛盾。
