# 我在写公众号和朋友圈的时候，一直在想，我要对话的人群是谁？

大概有两个类别：一个是行业中关注我获取新闻的人吧，我负责带节奏和翻译总结一些操作盘手的话。

还有一个，是我一直在做，而且一直很 Enjoy 的事情，内心尚未崩坏之处。

就是写给那些可我的同龄人。

他们是 95 后，可能正在创业，可能即将创业，可能就一直打工，他们可能背景和我类似，可能完全不一样。

他们在走寂静的人生之路上，经历痛苦、纠结、迷茫、徘徊。

我想让每一个人都知道，无论如何内卷，无论如何困难，其实都可以向前走，且每一个人路没有任何对错。
