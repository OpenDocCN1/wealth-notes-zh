# 二、此刻时察，信息是高度不对称的，对所有国人都是如此，甚至对于字节跳动本身都如此

作为内容平台一定有价值观，因为内容就是有价值观的，不能说即使没有价值观，你做的就是内容消费服务的事情。

作为内容平台一定和政治密不可分，作为一个来自来自中国开发团队的内容平台，测更是非常显而易见的带的政治色彩。

有某些玩家字节跳动弱而不强，也有人建议字节跳动应该和川普来一场辩论，更有人说字节跳动应该在北美发动一场人民 PR 战争。

我想说的是，目前的局势，对于大洋两岸吃瓜的我们真是一片黯黑，甚至是对字节跳动，也是黯黑。

信息高度不对称，说啥好像都有可能性，但是也只有深知其中缘由的人才可以给出判断和回应。

因此不如沉寂。

另外，作为一个人民币公司的字节跳动，被鼓舞和激励说和一个大洋彼岸国家机器作为斗争、做反抗。

甚至是做政治斗争，我不知道你们是看热闹不嫌事儿大，还是没有听过某段的的故事。

任何技术操作在国家机器和政治力量面前必推枯拉朽地被摧毁和无视。

# 三、对于“VIE 架构下的中国公司根本不是中国资产”的驳斥。

这是一个新的时代，中国的力量不可阻挡，一个很重要的力量一秆来自互联
网。

新一波全球化，中国互联网人开始新的寻找，少年强则中国强，互联网强，则中国强。

这是我一直以来的信念。

而这些互联网的公司，这些互联网的人才，CEO 和操盘手，有很大的部分都是全球主义视野。

他们需要美元的时候，美元来到大陆，给了他们机会，也赚到了中国发展的红利。

而因为中国互联网资产在 A 股上市早年间的不便，以及互联网早年间 Borrow From America 的模式何其多。

因此大部分互联网资产从一开始融资，到最后长大上市，都是建立在 VIE 架构上，然后去美国资本市场上市。

这是有历史原因的。

今天有人说，美元投资下的中国公司，不算中国自己的资产，自己的国民只是被收割的韭菜，自己的雇员也是被资本主义收割的韭菜。
