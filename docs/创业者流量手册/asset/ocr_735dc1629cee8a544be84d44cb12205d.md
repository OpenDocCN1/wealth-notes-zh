# 90、微信上线【群折叠】，以人为本的时代到来

微信 iOS 端上线 8.0.14 版本，「折叠群聊」正式上线。先聊聊

什么是「折叠群聊」？简单来说，用户之前对群只有以下几个选择；

+   1. 退群并删除聊天记录，此时聊天记录和群全部一场地空，不可被搜索；
2. 消息免打扰，但红点持续更新跳跃到最新，此时聊天记录社群内好友均可添加 —— 应该是中国大部分用户的习惯性操作。
3. 被动被踢群，此时有聊天记录存在，可不删除，但不能添加群内陌生人。
