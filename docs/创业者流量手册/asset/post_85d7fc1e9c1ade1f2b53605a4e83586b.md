
# 群响
搞流量，来群响

淘宝（阿里的心脏），即将全面面临字节跳动的进攻，淘宝或死于流量不足，死于被微小、拼多多、快手、抖音极低的流量压力之下。

一、阿里的流量策略：只有草原，禁止森林。
手机淘宝面临的流量局势一直非常不乐观。阿里长期致力于买流量，手机淘宝的历届掌门，从来不惜于在各路流量主中薅羊毛、合纵联横，形成所有有价值的精准流量最大限度汇聚到淘宝做电商业务的大好格局。

阿里妈妈、淘宝联盟、各类电商、内容淘宝客、微博、微信淘宝客的蚕食雄兵、鼓动一直以来阿里商家去进行广泛、长尾的站外营销以期得到千面千面的算法流量奖励，这些都是超级牛逼的流量策略。

阿里既是中国领先的广告流量主委现公司，又是全世界第二大的流量变现的电商交易平台，这两者角色需要平衡，平衡各路流量进入阿里实现以及各路商家仍然向阿里缴纳流量税（而非只有通道费）。

正因为这样的策略，阿里需要维持外部源源不断的流量草原，进入阿里的体系，被阿里体系的变现工具和电商平台，消化为成交额，进而用成交额为杠杆，向商家收费、佣金费和流量广告费。

## 二、淘宝流量平衡被快手和抖音打破。

但目前这样屡试不爽的策略，被快手和字节跳动两个巨大、独立、活跃且有同样庞大的相当交易额的流量主公司威胁了。

你会发现，字节跳动特别是字节跳动，是从流量主身份希望转变为和阿里一样，既享有庞大的交易领地作为生态价值，又可以直接赚取生态内流量费的角色。

只不过字节跳动和快手是从流量主到交易平台，而非从交易平台到细分类别的流量变现。因此位置更容易，因为本身作为流量主，电商化的主动权可以在自己手里控制，即自己分配多少流量给电商玩家，这是自己可以通变的。

反过来看基于这样的决策下的阿里处境，受得较为尴尬。因为淘宝本身的流量一直很缺少，几亿的 DAU 很扎实，但是来自于大量的商家自营的站外营销，站外营销长期仍然会源源不断，因为淘宝对于「交易」这件事儿的周边设施、宇宙无敌的理解能力与生态价值。

但是，站外营销导入的成交额的递送递走，且只来自于 1-2 个超大平台，非常没有安全感。没有安全感来自于，对流量来源和走势有高度且长期控制；流量来自于其他一个独立的大的流量的池的时候，软硬兼施，不软也难受，在上游被卡死；
没有安全感还来自于，商家站外营销要占据比足够多，商家逐渐把站外营销作为主场，而淘宝以广告变现为核心商业模式，威胁可不见一斑。

最后，称赞一下我最爱的字跳模式，类似里面的纺织工人，成就伟大的头条模式。

第一，App 工厂和流水线女工；
张一鸣是一个字节点跳体系下的最大家投资人，搭建好了生态内如 SOP 一样势如飓风的中台，虽然经常被道德拷问，但是同一条增长方法论、放炮方法论、数据方法论，以及同一套公司鼓励的思维文化，构建了一个在流水线上尝试不同人群、不同场景、不同商业化的各路方向。在流量上，字节点跳是不可不扣的国内最快最好的流量工厂，产品、运营、增长都是在流水线上洋洋自得的流水线女工。
第二，无限预算和无限商业化。
这两个因素与利润无关系，流量是转动因果牵引的润滑油，有了流量，因此有了收入、收入被精细化算计 ROI，特别长期主义地奢于 DAU 地去投入到流量的增长之中。
由于需要不断的增长，因此有需要不断的提高收入要求，鸡蛋生蛋生鸡，循环往复相互倒闭向前的，整个模式处在一个类似交易平台那种精打细算、极端口运营驱动的逻辑。
真的不想跑，跑 C 端产品做了交易平台的筹码。
第三，极端运营驱动
这是阿里与字节点跳最相似的地方，腾讯和快手都是生态流，阿里和字跳是运营流，一个是因为流量缩缺需要不断事情、买流量、提高收入一个是因为流量需要不断增长、收入需要不断增长，因此需要不断探索新的无上限放血。
头条的运营驱动对于生态玩家是残忍的，无论是被动或主动，或有意或无意，你都需要跟随字节点跳的流量指挥棒，奔波劳累，赚一碗汤钱。

第四，分发一切就不用签约，这是产品层面的「运营驱动」，前辈们谈烂了。
