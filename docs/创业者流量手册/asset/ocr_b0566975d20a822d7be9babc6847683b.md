# 第五，是谁操盘？部门与部门之间的利益纠纷如何解决。

基本上这是五个问题。
最后，这是一想屁股就说一句话，私域的全民化正是私域的黄昏……嗯，这一点，我之后再详细和大家讨论。

开始谈点一下这 2 个模型。
第一个，生活方式 IP，咕 LTV，精细化运营的力量。

这个同学是流量黑科技团队和两位生活方式博主合作的，生活方式博主本身在微博上有 180 万粉丝，然后这是一对小夫妻，女生是涛女郎，男生和女生加起来就是夫妻店，男生懂尔出现人设中，夫妻衣品很到位，就直接卖衣装。
团伙由技术和运营一起合伙，技术原来解决流量问题，在微信尚未开启大封杀之前，吃了小几千万的精细分配，通过微博、抖音、小红书都黑科技的私信技术，引流了大量的女粉，也在自己的号上了。

但自从 2019 年 618 之后，技术团队 1min 分了 4000 个号，直接把私域团队的私域引流技术全部砍掉，只做存量流量，目前存量流量是 80 万粉丝。

在流量放权上，费用为 0，索性只做 LTV，技术流被排除，老老实实做私域的对手工，不做任何技术对抗。

团队架构上，80 万粉，一个人 4-5 手机，单部手机 4-5k 粉丝，这算是私域团队的一个销售标配，但是团队非常牛逼的点是，人销销售的核心不在于群发和群聊，而在于一票圈的极致运营。
他的销售员是 0 养发，就是用涛女郎的 IP，绝对不做任何主动骚扰，票圈极致这运营，运营什么呢？

杂志式的票圈，每天的两口子地内容就是票圈创造物料，好几百套衣服，所有场景，不做任何主动的推销。
由于长期做服装生意的，两口子的选品、物料打磨非常好，客单价 150 元，80 万 1.4 亿，50% 的毛利，今年还有增长。

这就是私域在当年沉淀的力量，虽然专业，但是仍然 to C 呈现成一个 IP 即创始人工作室，绝不做任何的天猫露出和公域露出，淘系的比价歪赣，对毛利也没有任何意义，客户的社交电商，很本质，形成了真正的关系。
第二，公众号流量沉淀、追求利马囤地的跑地。

上周还有一个杭州来的私域铁子，200 人的公司，一个月利润 200 - 300 万，非常可观，当然人效偏低。

这位铁子是当年看到微薄涨粉很猛，微博的一篇文章「大学生做微博精选月赚 1 万」让他心动，学生时代时间比较多，对流量、营销敏感的一群人，成为了新一代的微博粉丝营销号的代表团，和当年的 PC 站长相当一模一样。
后来，2012 年微信公众号，比微薄更深的朴素逻辑——得粉丝者得天下，于是开始做微博号，非常简单粗暴，发展到 2015 年，简单是公众号流量主的狂欢时代。

整个 2015 - 2017 年，公众号变现 + 广点通疯狂投放，最夸张的一天可回本 100%，后面就是赚线，第一波的开始尝鲜的就是这一群做微博粉丝号的流量主们。
