# 第四，必须要有格局，让大家都格局，容得下比自己强的人，特别是创始人。

初期创始人永远需要解决一个自己的「安全感」问题，自己作为一个业务的开拓者，

首先完成了业务的冷启动，然后要去启动新的业务，或者成为一个管理者的时候，

自己必须要把自己的精力收束，那么，必须要面临「操盘手」到「管理者」的转变。

你需要让比自己更强的人加入，特别是在某些方面可以给你带来一些新的认知、新的经验的人加入，

如果你不能容忍他们，就不能让自己的公司变强。

练格局，首先练自己的格局。

# 第五，C 端产品经理要慎重招聘，C 端已死。

停止招聘任何一个来自大厂的 C 端产品经理，因为 C 端的机会会在抖音、快手、微信这样的大厂，已经被尝试过 N 遍了。
