# 9、字节跳动去掉一切。

我对字节跳动这个公司感情太复杂了。
一方面，就是短暂的 10 天工作经历，让我种下了对大公司永恒的噩梦，让我再也不希望去一个我不能发狠影响力的公司；
另一方面，本人作为张一鸣爸爸微博手的忠实读者，阅读了不下 5 过，一路读，一路感慨，张一鸣真的是张一鸣，成为张一鸣的路径真的酷陡的，之后会为我一鸣总专门写一篇学习他的文章，真的是企业家从 0 到 1 的楷模；
还有一方面，作为曾经的移动互联网、C 端 App 行业的流量_ceo 秉手，我无数次地下听朋友们被操到这个公司，可是被这个公司盯着打，盯着抄，太刺激了。
下面要说的是，其实是老生常谈，但是仍然希望总结记录，多年之后字节跳动成为一个万亿级别的公司的时候，再回过头看哈哈哈。

一、字节跳动在全行业收割高质量的年轻人
每个人创业失败的忧伤年轻人，或是在创业公司呆烦了的优秀年轻人，都可以选择去字节跳动，字节跳动在北京、上海、深圳都有坑位，都有可以做业务负责人的坑位。

我来自名列举一下我的朋友们被字节跳动招安时候的画像：一个年薪收做到 2000 万的在中教育 CEO；一个 A 轮左右失败的 C 端产品增量负责人；一个工具类产品 5000 万用户的联合创始人，负责渠道开拓和 BD；一个相册工具类产品 CEO，被收购。
再看看市场上，字节跳动从很早开始就用高薪团队和高薪空降，买到高管和业务负责人的人，也匪眉，保护自己不过被吸，一个服务日历工具团队、一个写文章很厉害的猎头团队、一个被了之前 VP、一个车来了的 CEO、一个图虫的 CEO。
再来总结一下，我在圈里圈外，对于头条人的感受，
第一，犀利，互联网行业叫做很 Aggressive，真的超级 A，为了很多细节的事情能够和事非对刻意增强，而且双方互不退让，这才是真字节跳动人；
第二，数据驱动、增长驱动、普遍对预算没有感，对 DAU 有感觉，这是头条强势的流量产品增长文化缩影；
第三，极度依赖、熟悉头条的中后台、企业文化、各种基础设施和看似模模糊的企业员工福利，让头条人深以为傲，但是也让这一座围城。
头条与头条人，相互吸取对方的价值，头条给予的是年轻人的时间、创造力和生命力，年轻人的吸取的是头条高端的工程、以及令人愉悦的高密度优秀人才工作氛围。
然后夜深人静的时候，是否会感到一片虚无呢？
那句语录真的很好，「打工，是不可能打工的」，我觉得说的很好，打工对于一切有志青年，都是一种垫伏，为公司贡献价值，被他吸取全部闲暇之外，要为自己未来的创业争取最大程度的空间和价值。
从公司层面来看，和头条抢人真的好难，头条吸纳了无数多猎头、挖走好人，特别是能交付结果的业务负责人。
