# 5，做好渠道工作，精细化运营，大批量地驱动线上的 BD 招商。

渠道碎片化始于微信抖音快手等各个流量主，这些流量主都能带货，可直播可短视频可图文消息可社群，这些都是你的客户。

把能带货的爸爸当作你的客户，去敲，去叠加你的 GMV。

看有利润是从私域出，还是说从渠道 BD 中出，反正达人播、自播，就是在抖音这样的短视频平台做自己的基本盘曝光。
