# 二、快手的商业化变得更激进

我们得到明确的信息，商业化的节奏，自从与老师傅调岗之后，进入一个比较明确地增量发展期。

和一个快手官方的人聊起来，我说：

我判断最近这段时间以及未来这段时间，是不是进驻快手抢流量的最佳时期。

辛巴因为未回局，快手为上市要冲业绩，不只是 DAU 业绩，更重要的是 DAU 被挤压制之后 的商业化业绩。

所以流量站的放大盘肯定会有很多波澜要变。

想想原来的啊，品牌方要进一个快手，都需要靠网红自己买，网红又特么是割据的富翁富婆，极其不好沟通。

现在能不能进去了，做一个团队，就做自播 + 内容 + 私域流量。

用投放的速度，加上及格线的内容水平，把抖音那一套另辟蹊径，在快手玩儿起来。

也许会很合适

大概幸不幸，本质是平台货币化，但可能会引起主播特别以核心出 GMV 的主播，反弹，和被控角。
