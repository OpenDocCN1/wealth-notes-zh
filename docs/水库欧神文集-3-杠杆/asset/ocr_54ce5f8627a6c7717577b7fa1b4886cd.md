# 一）你有多少钱

在一个大牛市中，你想赚更多的钱，你就需要更多更早的买进。你就需要更多和更早的现金。

好了，现在问题来了。“你有多少钱”

这是一个极难的问题。当然屌丝们觉得不难。满脸青春痘的屌丝搜搜上衣口袋，再搜搜裤子口袋。将所有的硬币堆在一起，一共 123.45 元。

但是呢，对于一个大学已经毕业，毕业已经一三年的人来说，就不是立等可取的答案。对于 25 岁毕业三年的白领来说，他至少拥有：

+   1) 活期现金  
2) 定存  
3) 股票，基金，银行理财产品  
4) 汽车  
5) 其他另类权益
