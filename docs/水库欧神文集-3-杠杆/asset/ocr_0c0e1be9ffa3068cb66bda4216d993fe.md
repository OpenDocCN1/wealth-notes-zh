+   - 最早，在 2000~2006 年，所有的房贷都是基准 P

+   - 2007 年，房贷一律调整为 P=85%

+   - 2009 年，房贷一律调整为 P=70%折

这个 “ 调整 ” ，十分简单。银行发短信邀请，你去，带上身份证，签个补充协议就行。

高高兴兴，柜面大堂，五分钟就办完了。

因为这属于 “银行内部收费调整”。

只要在银行签字就可以了。

而银行可不可以反过来，“ 7 折调成 95 折 ” 呢。

答案是不可以。

因为商业契约，需要双方签字，你不签就行了。
