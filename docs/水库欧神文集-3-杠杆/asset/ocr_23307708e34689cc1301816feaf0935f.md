# 财富追赶问题 #2450

一条科技树分支，没有太大的意义。

原文写于 2013.11.29

+   - 假设有 A 和 B 两个人。A 是土豪，B 是金领。
- A 的净资产比金领多 X 元。
- B 的工资每年比土豪多 Y 元。

请问：
1. B 能否追上 A
2. 如果岁月有限，B 能否追上 A
3. A 有消费，会坐吃山空么
4. 利率的影响

答案比你们想象中的简单。

# 一） 简单模型

这是一个很古老的问题。包括马克思主义天天在宣扬仇富，宣扬“富者愈富，贫者益贫”。但其实贫富分化完全没有学术上的支持。无论理论还是现实，贫富分化都是“内生性缩小”的。
