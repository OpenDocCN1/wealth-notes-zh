# 杂食与多核之读后感 #2440

《杂食与多核》写于三年之前。 
另补一篇弥补上下文。

+   一) 多核

很多人都在问，“信用贷，信用卡，房贷”该按照哪个次序来申请。 
因为如果一个人名下的信用贷很多的活，他会办不了房贷。 
一个人名下信用卡很多的活，他会办不下信用贷。

这个问题问得不对。 
因为还没有摆脱“单核”的思维。

戏法人人会变，各有巧妙不同。 
很多事情，很多场景，就是一句话。讲出来，就“破局”了。

对于“信用贷，信用卡，房贷”这件事来说。你要站在“多核”的角度来看。
