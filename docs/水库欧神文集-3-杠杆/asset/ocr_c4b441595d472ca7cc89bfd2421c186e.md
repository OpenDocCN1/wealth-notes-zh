# WORD天啊，江北嘴和溉澜溪涨成这个样子了

这几天沿着北滨路、北滨二路沿线集中看了几个盘，发现这个价格已经看不懂了，毛坯房都没有低于12000的，而年初这个区域毛坯房也就9000左右，这个涨幅也是醉了。
