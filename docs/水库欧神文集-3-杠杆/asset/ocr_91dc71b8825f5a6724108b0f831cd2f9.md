# 四) 同事间的欺骗

你去和信义房产的小伙子聊聊，刚入门的小朋友，他们会和你说，“服务态度是很重要的”。

据说有一个衣衫平凡的老头子。晚上九点半，跑到店里面。时间这么晚，衣着又很普通。大家都很懒得理他。

这时，只有一个刚入门的小伙子迎了上去，耐心接待。

没想到，这个老头子是个亿万富翁。很高兴地就买了三套别墅，小伙子赚了几十万佣金。同事们羡慕得要命。

这真是一个很感人的故事。富有浪漫传奇色彩。

唯一美中不足是，你认识的中介朋友比较多。过二天你又和德佑房产聊了起来。

德佑告诉你，他们分行里的一個小伙子。坚持到晚上 21:30，结果来了一个衣着平庸的老头子…………

臣信房产告诉你，刚入门的小伙子，来了一个老头子…………

太平洋房产告诉你，来了一个老头子………

永康告诉你，来了一个老头子……………

你再仔细问下去，你会发现这个老爷爷光顾了上海的每一家中介。在每家中介都买了三套以上别墅。而接待他的，永远都是一个“新入门的，热忱的小伙子”。

这是什么呢。中介的欺骗是无所不在的。对外骗客户，对内他们连自己都骗。

这个故事的意义，就是告诉你：“老老实实加班到 21:30，看见一个衣着平庸的穷老头子也要热情迎上去”。
