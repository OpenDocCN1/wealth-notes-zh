# 四） 股市下跌

股市下跌，是最最最微小，最微不足道的一件事。微小得我甚至都懒得提它。

有些人从美国加息，特朗普贸易战，国际安全形势，blablabla 分析，全部都是废话。很Low 的。

你要记住一句话，“股市不是经济的晴雨表”。

如果说股市前二年，还有一点点预测作用的话。这二年已经完全不是了，目前是“计划股市”。

中国股市，2900 点也不是底。

股市最大的麻烦，是“区块链”。

随着“区块链赌场”的兴起，年轻一代人找到了更廉价，更便捷的赌场。
