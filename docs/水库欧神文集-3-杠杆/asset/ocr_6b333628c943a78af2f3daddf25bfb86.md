# 融创白象街:

在《婆罗门的世界》一文中曾有提到。

白象街最主要的卖点，是他在“解放碑”核心区。老土著传统上最看重的渝中半岛。

2016. 08 水库刚开始入手白象街时，建面不过 12000~13000.

因为卖掉了七成，孙宏斌立刻要求调价到 20000~22000.

白象街的缺点是:

+   - 周边的环境非常嘈杂。
- 渝中半岛完全没有拆迁开发潜力
- 传统意义上，融创的品牌定位是“贵・极贵”，品牌口碑不好。
