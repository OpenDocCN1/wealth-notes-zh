# 当商业升到满级 #1430

后发优势

+   一）淮海路

很久很久以前，全中国只有上海还有供销社。当时，因为“剩资本主义尾巴”，全国所有的物资，实行统一调配。货币形同废纸。

全中国唯一还存在“零售业”的，是上海。上海太大，太重要。还是财赋重地。贸易留了一条小口子。

所以外地的同胞要买衬衫，肥皂，热水瓶，都要跑到上海来。大包小包，满满采购再拎回去。

南京路上，有民国时期传下来的“四大百货”。石材殿堂式建筑，每一幢都耗资数百万两银元。[1]

从商贸的角度，上海远远领先全国。再没有这么气派的“已建成”区域。
