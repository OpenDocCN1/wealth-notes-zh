# 加大土地供应

# ### 加大土地供给，特别是普通住宅土地

**合肥：** 今年内市区再供应5000亩居住用地，力争全年全市居住用地供应超10000亩，主城区内90平方米左右中小户型新建商品住房**占比不低于50%**

**无锡：** 增加普通住宅用地供应，新增住宅用地年度出让计划100公顷

**成都：** 对商品住房销售偏紧的区域，适时增加供地规模，适度加快供地节奏

**北京：** 保证套型建筑面积90平方米以下住房面积**所占比重不低于70%**

**福州：** 力争三年内市本级住宅土地供应量在原有年度供地计划基础上**增加20%以上**，**住宅库存去化周期低于12个月**的县市要加大普通住宅用地供应量

**昆山：** 今后3年住宅用地供应计划每年确定为60公顷，**普通住宅用地供应不低于70%**

**南京：** 确保完成全年经营性用地出让计划，力争超额完成商品住宅用地500公顷计划

**苏州：** 今后3年住宅用地供应计划每年确定为400公顷，**普通住宅用地供应不低于70%**
