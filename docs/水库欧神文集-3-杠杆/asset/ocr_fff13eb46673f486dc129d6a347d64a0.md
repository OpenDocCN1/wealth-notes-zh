# WORD天啊，江北嘴和溉澜溪涨成这个样子了

这几天沿着北滨路、北滨二路沿线集中看了几个盘，发现这个价格已经看不懂了，毛坯房都没有低于12000的，而年初这个区域毛坯房也就9000左右，这个涨幅也是醉了。

恒大御龙天峰精装13500、融景城13000、寰宇天下全是大型户型，17000起，紫御江山也只有看江的小高层在，可是16000起；恒大中央广场精装13000，新鸥鹏12500（现在还没有房源可售），万科御澜道高层大平层也没房子卖，那个高层脚下的洋房都要20000了，连保利观澜也是13000了，而是还是没有预售证的房子，置业顾问都是一副爱买不买的样子。

这个区域感觉都不是重庆了，难道是因为被投资者吵起来的嘛？其他区域会被带动起来吗？

重庆人笑得打跌，“巴子，一群上海巴子”。他们到底懂不懂地段啊。

重庆人有好得多的选择。他们可以买照母山，买大学城。或者到二江新区买联体别墅。左右住的都是同僚和科长，形成了一个本地公务员权与责的社团。

重庆人觉得他们聪明无比，绝逼上海人买贵货。

而事实的真相呢，我们从来没打算“卖还给你”，亲。我们从来没打算，第二棒的接手人群，会是重庆土著。

我们也对于“土著聚集区”。对于照母山，大学城，江北土著别墅社区毫无兴趣。
