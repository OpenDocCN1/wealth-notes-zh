内圈经济，由重庆土著们主导。是民营企业，是奋发创新。是市场经济，是面对消费者的。

这一圈是有效率的。规模在 3000~4000 亿。

重庆的外围经济，是中央投的。每年的规模从 6000-8000-10000-15000 亿。

这一部分资金，这部分投资，是计划经济---无效率的。很容易重复过剩产能。违背资源配置。

举一个例子。典型“渝欧铁路”。

渝欧铁路基本被吹上天了。阿黄也真好意思，这混蛋居然也敢吹“天才市长”。

任何一个人用大腿想，都知道“渝欧铁路”这事不靠谱。

哪怕你真的要建立“中国---欧洲”大通道。其起点也不应该设在了重庆。更不应该把笔电，

汽车，装备制造业等诸多产业放在了重庆。
