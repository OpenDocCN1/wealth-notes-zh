# 六）大城市的未来

如果一切按照生产力的需求，则中国有可能“澳洲农场化”。

整个过程，需要漫长上百年的时间。

最早的时候，是乡，镇，村，完全消失。

方圆 30KM 内，除了农场主，一些简单的肉禽加工厂，不再有任何人类。

第二步，原有的小城镇，地级市逐渐消失。

原有的工厂，道路，不动产，虽然是巨大的固定投资。也不舍得炸掉。

但是“新增人口”全部往省会挤了。地级市只剩下老人，县委书记，四套班子。
