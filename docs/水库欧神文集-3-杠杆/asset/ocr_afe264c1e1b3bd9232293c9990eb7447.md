# 撸卡积分流 #2140

下面我们要介绍一个失败的流派 ------ 撸卡积分流

一）撸卡积分流

首先，什么是积分流。

信用卡主要有二个流派，“撸卡积分流”和“透支借款流”。

其中，“撸卡积分流”是绝对的大头。二者的拥趸者大约是9:1。

你如果看目前网络上一些大热的信用卡网站，诸如51credit，则基本上所有的BBS 分栏，全部是讲“积分流”的。

全部是讲哪里可以再去找一点银行羊毛。

“积分流”的特点。他主要的利润，以银行积分，银行活动，银行优惠为主。

譬如说，银行不定期的：

+   - “消费满就送”
- “消费排名赠送”
- “境外消费赠送”
- “6 笔 888 元赠送”
- “消费比上月多赠送” 等等
