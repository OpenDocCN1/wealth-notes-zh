+   一）王亚伟

大约一个月之前，微信圈疯传一篇文章《王亚伟：A股目前天时地利人和长期回报率很高》[1]。其中说，A股的长期复合回报有23%

当时我正在打海岛奇兵。俺LP兴冲冲地把这篇文章转发给我。我头也没回，直接说：“SB”。

俺LP大吃一惊，“王亚伟哦，很有名的”。

我说我知道呀。中国公募基金第一人，易方达传奇的创始人。

但我更知道，易方达核心旗舰那个基金，是从来不开放申购的。
