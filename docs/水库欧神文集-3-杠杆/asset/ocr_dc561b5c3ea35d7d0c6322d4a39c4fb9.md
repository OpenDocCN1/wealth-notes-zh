“上海房地产观察”。

信息综合全面，你才不会被骗。

中介把你 175W 卖了，还要在你背上踩上一脚，“猪”。

# 四）挂牌

挂牌价应该怎么挂。

在上述那段典型中介电话之后，中介会和你说，“200W 的售价，请问还有多少议价空间”。

一般人的回答，是“到时候再商量”。

这个回答是错误的。因为你很快就会发现，在中介的电脑系统上，把你的房源登记为 190W，甚至 180W。

因为中介默认你说：“再谈谈”，那就是还有巨大的议价空间。一般是 10%~15%。

然后，中介会拉二个 190W 预算的客户过来。客户又会在 190W 的基础上再试探着往下砍。“170W 卖不卖”。

这么没诚意的谈判。最终只能弄得大家痛苦不堪。

所以，正确的回答，应该是“零”。

“请问议价空间有多少”。

“零，一分钱也没有”。

那么具体的砍价应该如何进行。我们一般行规是“第二次带看”。

# 五）带看

“好的，那我想明天上午带客户来看看您房子，您看可以么”。

“可以的”。
