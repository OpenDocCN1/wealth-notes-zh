# ## 第6 完善商品房预售管理

# ### 禁止发布虚假信息（各城市均有规定）

取得商品住房预售许可、现售备案后10日内、一次性向社会公开全部可售房源，按规定在销售现场显著位置设置商品房销售信息公开系统，及时反映房源销售状态，按一房一价、明码标价对外销售

# ### 商品房预售价格限制（各城市均有规定）

+   合肥：同项目、同类房屋6个月内不得上调备案价格；再次申报备案价格超过6个月的上调幅度不得超过1%

+   成都：同项目分期销售价格增速不得高于城镇居民人均可支配收入增速

+   福州：同项目下一批次备案预售价格原则上不得高于上一批次售价的10%

+   昆山/苏州：楼盘申报价格3个月内不宜调高，6个月内调高幅度不宜超过6%，12个月内调高幅度不宜超过12%。下一批次申报价格不宜高于上一批次同类型房屋成交均价6%

# ## 第7 加强金融监管力度

+   严查首付款来源，严禁首付款、众筹购房、过桥贷等

+   对存在违法违规的房地产企业、中介机构，各银行机构应采取停止新发放开发项目贷款、中止叙做相关中介撮合的二手房贷款业务

+   加大对银行机构个人住房信贷政策签署情况的督查力度，把个人住房贷款业务列入重点检查范围

+   严格商品住房合同网签备案管理，严禁期房转让，商品住房合同网签备案后，不予变更、注销
