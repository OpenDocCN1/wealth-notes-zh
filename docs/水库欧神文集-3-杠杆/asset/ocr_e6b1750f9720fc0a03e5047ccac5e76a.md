# 二）定期定投

首先我要告诉各位，“定期定投”在学术界是没有地位的。

你翻开任何一本“学院派”投资学理论，绝对找不到“定期定投”的说法的。

这个揭示，估计又毁了很多人的三观。

简直就和水库前几篇，讲“拉内需是伪科学”。正统的经济学教科书，是没有拉内需说法的。
