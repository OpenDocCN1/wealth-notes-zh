# 七）比特币

回到我们最初，年轻人问“比特币”的问题。

比特币最大的问题，在于“总市值”已经高了。

按照1800万枚*4000，比特币目前总市值约720亿美金。

极限时冲高到3600亿美金。

这是一个非常非常高的数字，720亿美金，大约和二个京东估值差不多。

比特币自然也有庄家，无非是一只老庄股。
