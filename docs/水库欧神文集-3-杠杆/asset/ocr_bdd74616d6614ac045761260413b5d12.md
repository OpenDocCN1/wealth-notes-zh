# ### 资金的分层（下） #2250

本阵，锋阵和资金替换。

+   1. 风险

接着说一个撩妹的话题。很多人，譬如某久，会向小 MM 吹嘘自己的 “光荣战绩”。

在他的深语传说中，某哥以 36% 的年利率向高利贷借了五十万。

贷这 50W 元，买了一套深圳几百万的房子。首付，税费，包括月供全部都是借的。

接着故事的结局大圆满。深圳房价暴涨。

空手套白狼，赚了好几百万。

小 MM 听得二眼望里光。“哇，你好厉害哟。好崇拜你哟”

而另一方面，同样的故事，传到不同人士耳朵中，则是完全相反的解读。

因为 “收益” 的反面，是 “风险”。

你零首付纯搏命，杠杆玩得如此之大。你有没有想过房价下跌怎么办。哪怕不涨，利息也逼死你。
