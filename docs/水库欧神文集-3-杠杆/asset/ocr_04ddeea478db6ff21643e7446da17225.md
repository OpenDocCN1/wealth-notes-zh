当时，是申办工行白金卡的黄金时段。

按业内的叫法，“单张额度 50W”+“奉送 PP 卡”，这种工行白金卡被称之为“黑白菜”。

2009 年，战斗在第一线的职业多军们都疯狂了。那一年也是黑白菜丰收的一年。

![](bbox=[0.095, 0.18, 0.5, 0.55])

此后呢，一直到 2012 年，工行内部尘埃落定。

或许发生了人事变动，整个路线 180 度大转变。

不仅仅申新黑白菜无望，而且整个 ICBC 信用卡部发生了“战略收缩”。

此后，就是闻之色变的 2012“封卡潮”。

工行信用卡，在任何时候都是一个异类。

别人分期利率都是 14~15% 左右。而工行是 7.8%

大行风范，底蕴深厚。

而 7.8% 的分期利率，因为跨过了阈值。

所以工行分期，几乎可以当长期现金使用。
