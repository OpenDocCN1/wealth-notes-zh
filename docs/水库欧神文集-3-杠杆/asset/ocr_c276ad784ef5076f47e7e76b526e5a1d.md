# 一）计划经济

更进一步，连神灵和祖宗的约束也不存在。

对于独裁者来说，他是至高无上的。拥有一切的权力。

可是 他“执政”的结果，却是非常地糟糕。按照官方体面的说法，至少也是“国民经济濒临 崩溃的边缘”。
