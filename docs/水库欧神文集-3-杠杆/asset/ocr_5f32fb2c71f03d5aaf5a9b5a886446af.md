“借款流”和“积分流”是完完全不同的科技树发展方向。

在于“借款流”看来。你辛辛苦苦地把钱借出来，T+1 又急吼吼地还进去，是严重的“买椟还珠”行为。

“借款流”的另一个特色，他是要承担“风险，痛苦，压力”的。

+   如果你每天都结算工资，你是送外卖的。

+   如果你三年后才有收获，你是高阶白领。

“积分流”是没有透支的。也不用担心“三天后 5W 卡账到期，还不出怎么办”。

积分流天天数钱，每天 100，数得超开心。

而“借款流”是一条“风险，痛苦，压力”的派派。

它全部的秘诀，在于“靠信用卡拼凑出一条长期 300W 的现金曲线”。

好比管仲对鲍叔牙说。

“兄弟，我准备去炒一套房子。需要 300W 现金的首付”。

“这是一个非常有前途的项目，将来一定会大发特赚的”。

“只不过项目要到五年之后才能变现。五年之内，欠你的 300W 都不能归还”。

鲍叔牙凄惨一笑；

“哥哥，你去吧”。

“现金的事，你就不用管了。我会搞定的”。
