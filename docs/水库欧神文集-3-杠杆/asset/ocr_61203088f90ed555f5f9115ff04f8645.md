# 一）叠加贷

最近遇到一个单子。一套房子，按政策是可以贷 350W 的。但结果最后只贷了 250W。

悲剧发生的原因，是因为业务员手贱。
在网签的时候，贷款一栏写错了。350W 写成了 250W。

事前没仔细查。等到批贷款的时候却说金额错了。
而此后，因为限购锁定咳咳等一系列原因。他又不能改网签合同。

对于这样的哭泣悲剧，足足少了 100W 元“八折三十年”贷款。
心如刀绞，老鼠来舭。

但是，且慢，别急，它还有补救办法。就是所谓的“5+2”贷款。
5+2，或者“4+3”贷款。
