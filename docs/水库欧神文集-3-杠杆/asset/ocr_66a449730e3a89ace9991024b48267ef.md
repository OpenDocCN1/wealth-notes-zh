# 信用卡之旁门左道 #2190

我们继续讲信用卡之雕虫小道。呢，旁门左道

一）退货交易

你去到外滩大楼的 AIA，买一份保险。金额 100W 元。

按照保险法规定，10 天之内是“犹豫期”。保险可以退的。所以你过几天打电话给保险公司。原路退回。

但是，在信用卡系统显示为什么呢。
7.15 刷卡 100W 元。
7.18 退款 100W 元。
**但是，退款会冲掉“上期账单”。**

这就是“退款交易”。在传统的信用卡系统中，**退款被视为收入**。
并且会抵扣掉上期账单。
