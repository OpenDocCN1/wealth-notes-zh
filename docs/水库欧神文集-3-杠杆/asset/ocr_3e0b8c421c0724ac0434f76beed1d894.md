# 好玩的数学

# 1. 限时过桥谜题（2015年9月1日）

Can you solve the bridge riddle?

~ Alex Gendler (Sep 1, 2015)

![](bbox=[0.12, 0.24, 0.47, 0.38])

有4个人A、B、C、D面临一座桥，他们过桥需要的时间是1分钟、2分钟、5分钟和10分钟。由于是黑夜，必须拿灯笼过桥，但他们只有一盏灯笼。桥一次最多通过两人，两人一同过桥时必须一起行走。由于被僵尸追赶，他们必须在17分钟内全部过到桥的另一边。

请问应该怎样过桥？

鲍叔牙必须自己解决这个问题。在问题的内部“挖潜”。
一个解决的方法，是使用“二张卡”

好比你手里有 A，B 二张卡。
二张卡的账单日，分别是 1 号月和，和 15 号月中。

+   则：
* 月头刷 A，还 B 卡。
* 月中刷 B，还 A 卡。

> 这事基本上比你想象中的还要简单。

你只要很简单地将卡片分为 A，B 二批。
A，B，A，B，A，B 循环操作。
这样就能填掉“垫资七天”的缺口。
