我看这篇《肮脏的收藏业》可以改个名称，叫“部分肮脏的媒体从业者”。为什么呢？

+   1. 利益驱动，发文章关键是要博眼球，甚至越扭曲越好，毕竟阴谋论和离奇的故事最能博眼球，至于事实如何无所谓，损害了谁的名声都不关己。例如，这篇含沙射影的文章，通过在文章前开头加【网络谣言】这几乎来明日张胆的传闻。事实上，东方港湾在2015年之前根本没有收管理费一说，那篇谣言纯属捏造，完全瞎掰，全是扯淡。如果是一个负责任的媒体，大可查一查再写，也不至于又专门撰文一篇来传谣。

+   2. 堆砌专业概念，实则伪科学。可能外行看着似乎挺专业，实际上是混淆视听，以偏概全。这种看似有道理的谬论往往杀伤力最大，最容易被传播。例如这篇文章里引用的“价值、稀缺、供应量、收藏流、张维迎教授”之类的概念，还说定期定投是非常糟糕的思路，那请问什么是好思路呢？事实上巴菲特建议了多年，说定投指数基金是普通投资者制胜的不二法宝。把精力和时间用在本职工作上，换来的价值可能远比自己炒股被割韭菜来的划算。

+   3. 说了半天，这位作者yevon_ou连投资的基本概念都没有搞清楚。区别投资和投机的关键是现金流。我们投资一个企业，它的价值取决于未来全部现金流的折现。买古董，它能不能产生现金流呢？如果不能，那这件古董的价值只能取决于下一个愿意出最高价的人，这可能是一个亿也可能是一块钱，这样击鼓传花的游戏叫投机。这不是说投资就好而投机就不好，事实上投机更难。这篇文章中居然把买古董和买茅台股票比作一回事，excuse me? 这投资是考古学家教的吗。作者大谈“收藏流”之余，为什么通篇连现金流三个字都不提，是真的不懂还是故意误导读者呢。

+   4. 代理人问题，是各行业普遍存在的问题，尤其在信息不对称的行业更严重，这很多时候靠的是职业道德来约束，或者叫人品、叫底线。芒格说，很多事情即使不违法不违规，我们也不去做。巴菲特说，建立名声需要20年，毁掉它只需要5分钟 (It takes 20 years to build a reputation and five minutes to ruin it)。价值投资是靠复利来滚雪球的游戏，滚的雪球不仅仅是资产，更重要的是这份信任。金融行业可能有不少教子牺牲客户利益的同行，这就好像媒体行业中不乏这类缺少底线和职业道德的从业者。但我相信，不以客户的价值为追求的公司是不会长久的，时间会是最好的见证。
