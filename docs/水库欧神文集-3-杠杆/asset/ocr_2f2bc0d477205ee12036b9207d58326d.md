# ### 一）月供 pmt

等额本息月供应该是多少。

网络上立刻有无数无数人，打开所谓的“搜房网房贷计算器”。

你这样小白，一辈子没有出息。

月供的正确方式，应该是打开 Excel。

输入： pmt（利率，期数，金额）

其中，第一个参数“利率”，指的是月利率。

一般是 4.9% \* 90% / 12

+   - 国家基准利率 4.9%
- 九折优惠
- 除十二个月
