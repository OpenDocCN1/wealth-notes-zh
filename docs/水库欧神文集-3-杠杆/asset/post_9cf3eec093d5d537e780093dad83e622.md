# 没有

什么，什么叫没有。没有啥没有。
没有的意思，就是没有任何升级。

金茂大厦，始建于 1999 年。
SWFC，始建于 2008 年。
上海中心，始建于 2017 年。

可是上海中心的“生活理念”，几乎和前二幢楼一模一样的。
仅仅是多了几家餐厅，写字楼。
没有任何本质性的改变。

从 1980，1990，2000 年代，上海的商业“氛围”经过了三次大的<font color=red>升级</font>。

每一次升级，都和落后者拉开的距离。
市中心魔都的建设，都和郊区拉开了距离。
88 层摩天大楼的建设，都和外省拉开了距离。
