# 四) 低评

和“高评”相对应的另一个手法，则是“低评”。反过米也是成立的。

+   - 写高 100W，增加贷款 70W，付税费 10W，净到手 60W。借六还七。
- 写低 100W，减少贷款 70W，省税费 10W。净到手 60W。还六得七。

“还六得七”。我只要拿 85W 现金出来，就可以净获得 100W。
