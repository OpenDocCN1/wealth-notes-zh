# 六) 修图

比 “双卡制” 更进一步的。则是所谓的 “PS” 了。

PS 有几种方法。由于一般人都没有兴趣《从头构建》一份新的流水。因此大部分的 PS，都是 “半真半假”。在原有的基础上，稍做修改。最主要包括。

+   1) 在所有的结余中，增加一位。例如，统一多加 400W

+   2) 将所有的进出帐，乘以 10
