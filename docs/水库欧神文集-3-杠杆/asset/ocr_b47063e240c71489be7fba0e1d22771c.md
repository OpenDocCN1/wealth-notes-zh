# 第5 引导土地出让理性竞价

# 引导土地出让理性竞价，控制地价过快上涨

合肥：竞买保证金比例为**参考总价的50%-100%**，土地出让金必须在出让合同签订后1个月内一次性付清

无锡：设定土地出让最高限价，当网上竞价达到最高限价时，仍有2家以上单位要求继续竞买的，停止网上竞价，**改为重新挂牌或者摇号产生竞得者**

北京：在严控地价的同时，对项目未来房价进行预测，试点采取限定销售价格并将其作为土地招拍挂条件的措施

福州：土地竞买保证金由现行的20%**提高到30%**，全额土地出让金支付期限**调整为3个月**，付款比例为合同签订之日起30天内支付50%，其余在90天内全部付清

昆山：住宅用地竞买保证金竞买保证金由现行的20%**提高到30%或以上**，首付款由现行的50%**提高到60%或以上**。当土地价格溢价率达到50%~60%的，**工程结构封顶后方可申请预售许可**；当溢价率达到60%~80%的，**工程竣工验收后方可申请预售许可**。溢价率超过80%的，中止网上竞价，转为“**一次报价出让方式**”进行竞价。在一次报价出让环节，按最接近所有报价平均价的原则确定竞得人

杭州：溢价率超过100%，1）1个月内全额付清土地出让金；溢价率超过120%，满足1）条件外，且2）该地块所建商品须在取得不动产登记证书后方可销售；溢价率达150%，转为3）在此价格基础上通过现场**投配建养老设施面积**，并需同时满足1）2）条件

南京：网上竞价达最高限价九成时，开发商所建商品房须现房销售；当网上竞价达到最高限价时，仍有2家以上单位继续竞买的，**将摇号产生竞得者**，并在最高限价基础上附加一个加价幅度作为成交价

苏州：对部分地块设置土地成市市场指导价，**超过指导价地块提高预售条件**  成交价超过指导价，全额缴纳出让金期限缩短为2个月，**工程结构封顶后方可申请预售许可**；成交价超过指导价10%，**工程竣工验收后方可申请预售许可**；竞价超过指导价25%，中止网上竞价，转为“**一次报价出让方式**”进行竞价，在一次报价出让环节，按最接近所有报价平均价的原则确定竞得人
