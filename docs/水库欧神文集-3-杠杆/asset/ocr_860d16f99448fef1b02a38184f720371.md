# 中介篇（二）---房源 <sub>#2450</sub>

在很久很久以前，中介是分为寻找房源和寻找客户两个组的。

一）房源组

中介要促促使成交。他有两个方向可以努力：

+   1) 更卖贵的客户

+   2) 更便宜的房源

你门店开在那里，就是等顾客上门。最理想的是进来一个土豪，看啥都便宜。

随便聊几句就下一排订单。

优质的客户就意味着金矿，人形 ATM。就象温州富婆一样。

但是，中介还有一个努力方向。更便宜的笋盘。

譬如，你找套内环线的房子，只卖 5000 元/平米。或者找汤臣一品，卖 100 万元/套。
