# 六) 核的控制

很多人都在问，“核”的控制。

首先，“品德”是最终的保障。人品如果败坏了，则永远都能找出瑕疵。即使你能赢官司，纠纷和扯皮也能恶心得你吃苍蝇。

当对方“信用基本可靠”的基础上，控制“核”主要是靠抵押证。

小白们不知道，个人也是可以做抵押证的。

你如果在售楼 处买了套房子，银行办了一笔房贷。最后你拿到绿色的房本。此外，还有一张红色的抵押证。
