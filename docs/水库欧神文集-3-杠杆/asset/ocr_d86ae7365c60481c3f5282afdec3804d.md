# 零首付精算法 #2290

借六还七

一) 高评

对于房价一个最基本的技巧，就是“高评”。
通过写高价格，获得更多的贷款。达到“零首付”或者低首付。

举例来说，以一套 1000W 元的房产为例。
如果写高到 1400W 交易额，则可贷款 980W。实际首付 20W。

高评最主要的问题，是税费。
我们列了一个表格，比较高评的差异。

|  | 原先 | 高评 | 差异 |
| :--- | :--- | :--- | :--- |
| 合同价 | 1000 | 1400 |  |
| 贷款 70% | 700 | 980 | -280 |
| 实际首付 | 300 | 20 |  |
