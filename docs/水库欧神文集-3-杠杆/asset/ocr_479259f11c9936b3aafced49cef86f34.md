# 一）回报

您买一个理财产品，承诺给你 3%~4.5%的近乎无风险回报。
你发现一个非常有潜力的商机。去投资了，获取 20~30%的回报。
某一些股神，吹起牛皮来可是相当犀利。他们的最佳战绩有多少，50~60%年回报。
炒楼的回报有多高，100%
