# 三）宽限期

自 2014 年开始，应银监会要求。各大银行都给予三天宽限期。

可参阅水库贴于《信用卡修改账单日和宽限期详情汇总》
http://www.shuiku.net/forum.php?mod=viewthread&tid=26153

表格比较长。我这里就不贴了。只列出“非 3 天”的异类。

| 说明 |
| --- |
| 无宽限期 |
| 2 天 |
| 白金卡专享 T+9 晚还款 |
| 之前是 5 天，坑爹突然改成 2 天 |
| 默认 1 天，一年可电话申请一次 3 天 |

这里值得展开说明的是：

+   - 如果你是 T+3 还款，你最好是同行转入

因为银行内部的清算系统，是 T+1 额外一天的。
如果你 T+3 跨行给某些银行信用卡还款，卑鄙的银行（例如广发），会不承认的。他们会一口咬死你是 T+4，并要求你付息。

但是你先转借记卡，再同行借记卡还信用卡。银行就没有借口了。
