从 2014 年迄今，整整五年过去了。

五年内上海发生了什么呢，什么也没有发生。

没有任何令人振奋的科技创新，明星企业，青年创业，资本传奇。

整个城市昏睡百年，暮气沉沉。

我在上海这个城市，生活居住了卅年。熟悉热爱这里每一寸土地。

但上海，实在令我灰心。尤其是资本，更加不敢投在这样一个“白左”城市。整天净学些啥。

2019 年的预测，俺小心大胆。

从 2019.04.18~2020.12.31，还有约一年半的时间。同时楼市“蓄水”已久。

只要一波牛市，+50%可期，12/8/5 这个预测目标，应该还不致于打脸。

尽管这是我近十五年的预测，最接近“失败风险”了。

从 2020~2025 年，还有五年时间。运气好一倍还是有的。

我们还是冀望上海 2025 年能涨到 250000/m，也就是今天香港的水平。

No zuo no die.
