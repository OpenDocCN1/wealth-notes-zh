# 抵押贷款一 二三 #2320

抵押的一些基础知识

一) 全款流

“全款一 抵押”是一条非常好的路。

买房子追求二个KPI:

+   1) 价格尽可能低

+   2) 杠杆尽可能大

所谓“全款一 抵押”，是指你先拿着600~1200W 不等的现金。在市场上寻觅笋盘。然后反向抵押。

重点定位于:

+   中小企业破产

+   离婚分家产

+   转移财务
