# ## 我对重庆的态度 #2680

三件事：做实，投机和双城记

一）佛言

佛界，幽冥，座前。

他静静地漂浮在虚空中，视线从黑幕一直延伸至无穷远的尽头。无色无相，不净不垢。

“你想获得什么”。

“财富，很多很多的全钱”。

“你愿意付出什么”。

这是一个很重要的问题。如果佛祖每天接受 99999 个祈愿，则几乎每一个人都祈愿发财。但很少有人会认真想过，“我愿意付出什么”“我愿意放弃什么”。

所以他们通常都不发财。

很多很多以前，你非常穷。非常非常非常地穷。
