# 课程提要

关键词汇：禀赋效应 (Endowment Effect)

核心问题：没有吃到的葡萄，真的是酸葡萄吗？

预计阅读时间：6分钟（欢迎使用音频版，如知识全书听得到）

上一讲我们讲到大脑与心理的关系，说到了大脑为心理学提供了生理约束，同时心理也可以反作用于我们的身体，影响我们的身体健康。这也是我们心理学学的第二个关键公理。
这一讲，我们就来继续深化这个话题，谈谈心理学的第三个公理，那就是心理是具有扭曲现实的力量。
