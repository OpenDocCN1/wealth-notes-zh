# 基因多效性：基因是一把双刃剑

你可能要问了，自然界为什么产生出有害的基因？

其实呢，并没有纯粹的坏基因。基因的坏，主要是因为基因的多效性所导致的，所谓“多效性”，指的是一个基因同时拥有两种或多种效应。

为什么男性比女性死得早？

根据世界卫生组织和联合国人口组织的统计，全世界男性寿命平均比女性短5到10年。在中国，这个差别是5年。
