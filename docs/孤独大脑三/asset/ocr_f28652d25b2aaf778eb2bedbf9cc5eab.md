# ### 目的地消费品

所谓牛逼产品，就是你**非买不可**的“目的地消费品”。

每个价格区间最牛逼的产品，都是一个“目的地产品”。

这个概念来自“旅游目的地”，诸如旅行畅销书里推荐的，“你死之前一定要去的50个地方”，等等。

何谓目的地？

+   1、具有某种唯一性；

+   2、你非去不可、值得专门去一趟；

+   3、多少钱都得去（假如钱够的话）。
