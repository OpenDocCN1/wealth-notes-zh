# 老喻

30多年前，心理学家奥尔兹偶然发现，如果对老鼠下丘脑附近进行电流刺激，老鼠会喜欢上令它讨厌的电击。

为破解谜题，他们做了一个控制电流刺激的开关装置-横杆，由老鼠自己掌握。

老鼠一旦学会按压横杆来获得刺激后，就会以近乎疯狂的热情来刺激自己。这就是“奖励中枢”，一个非常原始的动力系统。
