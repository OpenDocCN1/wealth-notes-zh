# 五

在我看来，吴清源的围棋世界观是道家的。

回忆起当年史诗般的十番棋抗争，吴清源说：

“胜负对我来说无关紧要。不是想胜就能胜，这就是围棋。因此十局战从一开始我想的就是让自己委身于围棋的流动，任其漂流，不管止于何处。这就是我当时的。心情。”

这正是道家哲学有趣的地方，在一场寸土必胜、以胜负为目的的决斗里，吴清源用一种“不争”的态度，成为不败战神。

《东西之道》作者梅勒认为，对“人的能动性”的质疑，是《道德经》最有意思的部分。

+   现代西方哲学，从主体性的发现开始，一直关注自我和自我的力量

+   《道德经》“无为”的准则，通向了对世界的整体观察--把世界看作一个机制，以“自然”或自发的运作为基础。

梅勒称之为：自创生。

“和谐相依、方成棋局”，这就是吴清源对围棋的观点。
