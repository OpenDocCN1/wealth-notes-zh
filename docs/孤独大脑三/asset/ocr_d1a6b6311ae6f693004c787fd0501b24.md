问题来了，凯利公式真的“重胜率轻赔率”吗？

并非如此。

要想回到这个问题，我们需要简单了解一下，凯利公式是怎么得来的。

+   •某次下注，假如你赢了，总资金就会变成：

现有本金=原来本金＋下注金额×口赔率。

其中，下注金额=原来本金×口下注比例。

+   •某次下注，假如你输了，总资金就会变成：

现有本金”=原来本金”一下注金额。

因为我们在乎的是长期下来自己的总收益是多少，所以，要计算的是多次下注后本金的最大值。

在公式中，f为下注占总资金的百分比，p为获胜概率，b为赔率，E为期望值

+   ○当你赢了，你的本金增加为原来的（1+fxb）倍。

+   ○当你输了，你的本金减少为原来的（1-f）倍。
