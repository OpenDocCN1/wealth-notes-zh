这才是我们该从Costco那里学东西，和Costco能否扎根中国，以及是否会被亚马逊干掉都没关系。

假如你学会了，好事就会降临于你。

# # 最后

罗素说：在世界上一切道德品质之中，善良的本性是最需要的。

然而，善良的人也容易不自信。

有的人不自信，会因此而狂妄，暴躁，虚张声势，以及不要脸。

而温顺的人呢？他们的不自信，融合了孩子的好奇、以及对成年世界的害怕。

有些人的童年会因此而显得较长，甚至终其一生。

+   - 这是力量的一种，而非无力；
- 这能给他人以美好，没有理由令当事人不美好。

温顺的道路，是一条截然不同的逾逯。

这与我们从小被灌输的正统教育，以及步入社会后所接受的厚黑教育，都完全不同：

+   - 温顺者的轻声细语比振聋发聩更清澈；
- 温顺者相信享受世界之乐比占有这个世界更重要；
- 温顺者如水般绕开山脉，不与争锋，却又能对巨大的岩石发起一波又一波的进攻，哪怕粉身碎骨。
