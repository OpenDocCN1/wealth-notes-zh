假如你花100万买了一只基金，第一年涨了100%，第二年跌了50%。那么你的收益是多少？

**·按照算术平均值计算：**

平均收益率=(第一年收益率+第二年收益率)/2=(100%-50%)/2 = 25%。

**·按照几何平均值计算：**

年 收益 率 假 设 是 X ， ( 1+X1 ) x ( 1+X2 ) = ( 1+100%)x(1-50%)=1，计算结果，x=0。

也就是说，按照几何平均数算，年回报率是零。实际结果就是如此。

这里用几何平均值计算出来的回报率，就是所谓“年化回报率”。

**几何平均值几乎总是小于算术平均值的。**
