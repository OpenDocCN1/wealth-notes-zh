你觉得贾玲是有心机还是没心机呢？

+   - 首先，珍惜友谊，不随便消费别人，这是厚道；

+   - 其次，准备好大锅，把水烧开，再煮透泷腾，这是理性。

理性的“没心机”，会带来更大的回报。

而且，因为这“没心机”并不以回报为目的，所以便有意外的惊喜，和真正的快乐。

这背后的逻辑，解释了为什么“温顺的人将继承世界”。

当温顺的人拥有这个世界，其快乐有更深层次的意义：

他们怡然自得，对生活心满意足。

> 贾玲曾说：“我对电影的理解实在是太浅薄了，只能靠真情实感去打动观众。”

这看似自谦，其实透露出了某个秘密：

诚实是最好的策略。

她不仅诚实，也很聪明。

社交年代的电影逻辑很有趣，一部分人看了电影，然后通过社交网络网络放大赞誉或者批评。

所以，一部电影的票房，要么过于好，要么过于差。

从这个角度，《你好，李焕英》经历了“诚实效应”的双重放大：

+   - 一个是作为电影之被观看；

+   - 一个是作为话题之被传播。
