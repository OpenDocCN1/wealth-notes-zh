# 关待

喻老师，请问你怎么看待 选择比实力更重要 这句话？

# 老喻

以足球为例，实力是指球队的强弱（包括阵容、训练、天时地利等等），选择是指如何根据具体情境决定首发阵容，如何制定针对性的战略，以及比赛中如何灵活调整。

“选择”和“实力”二者之间是乘积的关系。但就结果而言，有时候“选择”是1，“努力”（发挥出来的实力）是后面的0。

# 陈愣

人到中年，觉得日子过得单调乏味，但是我是大家眼中幸福的楷模，有一份自己不喜欢但是收入还不错的工作，有爱自己的老公，还有很有主见的留学中的孩子。是还自己安慰让自己也觉得幸福？还是做点什么大的改变让自己不至于老了后悔？

# 老喻

幸福包括小幸福和大幸福。小幸福是指美满、静好，重点在于“不发生什么”；大幸福是指实现、意义，重点在于“发生些什么”。

试着去做一些有价值有意义的事情，例如重启小时候被迫终止的某个爱好，和老公计划一场旅行，与孩子一起做帮助弱势群体义工。
