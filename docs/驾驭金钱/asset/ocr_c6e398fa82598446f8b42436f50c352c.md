# 責怪

你可以責怪政府、經濟系統、銀行、政治人物、政策立法者、父母、獨立財務顧問（IFA）、媒體、消費者和客戶、買家和賣家，甚至是邪惡的土豪，卻依然無法改變現況。

且慢，我修正一下剛剛的說法好了，你的責怪會改變兩件事：其他人對你的看法，以及你對自己的看法。你會變得尖酸刻薄，但不會更好。你還會令人討厭，讓其他人完全不想接觸你。

我們都曾經傷人傷己。我的目的也不是要怪你，而是希望你立刻戒除責備其他人的惡習，做好完全負責的準備。

只要在你個人可控制的範圍內，你都應該負責全責。如果遇到控制外的狀況，那就放寬心胸，無須在意。倘若沒有能力掌握，卻費盡心思，奢望控制，其實非常浪費時間和精力。
