# 六度分隔理論—或者，三、九分隔理論

六度分隔理論認為，地球上的任何一個人，只要從認識的人開始建立人際網絡，最多不超過五個人，就能夠與地球上最遙遠的另一個人，建立人際關係。舉例而言，你的朋友可能認識另外一個朋友，而這個朋友的朋友還有一個朋友，最後這個朋友認識凱文．貝肯（Kevin Bacon）。因此，六度分隔理論也被稱爲「凱文．貝肯的六度分隔理論」。

為了重現一九四○年代的著名實驗，實驗者撰寫了一個程式，將四十個包裹隨機寄給全球四十位民衆，請他們以「認識名字的朋友」爲基礎，藉由人際網路將包裹隨機寄給一位住在美國波士頓的科學家馬克．維達（Mark Vidal）。最後有三個包裹成功寄給維達，平均需要六個轉寄者。
