# 不知道如何測量，就無法精通其中的道理

許多人認為理財變得愈來愈難，因為錢常常摸不到看不著。我們以前工作一個星期，就會得到一袋薪水。你可以實際接觸到錢，這是一種可以實際感受的測量單位，代表每個星期的工作報酬。時至今日，大多數的金錢都藉由匯款或電子商務交易，速度更快。薪水也會先扣除稅金和國民保險，就連帳單都變成電子帳單，愈來愈少實際接觸。錢來得快也去得快。愈辛苦賺來的錢，我們就愈珍惜。

我們必須改變舊的觀念，用新的理財方式。

# 建立理財系統的五個步驟

# （一）妥善管理金錢

只有你可以負責管理自己的金錢。父母、監護人、獨立財務顧問、理財專員、經紀人都無法，只有你可以。有一次，我到銀行想要進行一筆交易。他們剛整修改完，放新的會議桌讓你可以與理財顧問面對面討論。我我想要處理的交易非常簡單，銀行的承辦人員請我到桌子前稍坐片刻，等他們處理相關文件。該名顧問大概二十歲左右，制服的尺寸有點太大，名牌也並未配戴整齊。他在電腦上輸入我的銀行帳號後，興奮地把眼睛
