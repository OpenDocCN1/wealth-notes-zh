# 經驗（應用教育）

不必我贅言，讀者一定明白，如果你不願身體力行，就算圖書館中充滿豐富的知識也無法助你創造美好的成就。

教育和經驗不同，經驗來自數個小時的教育學習，再加上數個小時的應用，才能淬練完美。

這是個永無止盡的過程，重點是先求有，再求完美。千萬別像大部分人那樣，以為要累積足夠經驗後，才有實踐的自信。這是一種矛盾的想法：如果你想要等待自己變得完美，才願意實際追求，你永遠不會起身行動。人不可能變得完美，我們應該立刻行動，實際努力。卓越比完美更重要。我們獲得經驗，一切變得更簡單，發揮美好的時間槓桿效果。
