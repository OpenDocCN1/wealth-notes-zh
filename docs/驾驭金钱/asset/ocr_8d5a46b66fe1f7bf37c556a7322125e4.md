# 多重收入來源

建立多重的收入來源可以創造非常明顯而且誘人的好處。除了讓你擁有一足以與人分享」的優點，也能夠建立多層次的保護與照應。如果你的工作是高時間單位報酬的顧問（每小時獲得非常優厚的費用），從資產（房地產和股票）獲得被動收入，房屋貸款已經償還，資本獲得保障，擁有具體的資產、珠寶、智慧財產權、專利、執導電影的收入、創作史萊德樂團(Slrg)的聖誕節歌曲並且設計戴森公司的吹吸器，這本書應讓你執筆！你可能無法贏得上述的所有收入，但建立資本、淨值和收入三種形式的平衡是非常可行的建議，我個人認識、研究並且仔細理解的富人也非常強調多重收入來源。

我在另一本書《房地產的多重收入》（Multiple Streamsof Real Estate Income）中提出如何創造多重收入的模式。在房地產的领域中，建立多重收入來源是非常重要的概念，包括設置一到三種可以隨時管理的收入來源（資產類別），如何建立系統化管理和發展方法，以及何時應該在獲利組合中增加新的收入來源（正確的時機就是系統化管理最新收入來源，並且完整測試新的來源）。你應該準備完全獨立的收入來源，避免其他來源遭到影響，也要讓不同的收入彼此接合，創造既有收入的槓桿效應。例如，如果你擁有足夠的房地產，可以聘請租賃仲介人，增加你的獲利組合。
