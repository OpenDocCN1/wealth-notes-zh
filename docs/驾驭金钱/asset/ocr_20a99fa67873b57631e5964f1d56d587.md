# 缺乏公平收入的給予

缺乏公平交易或收入的價值，就不是真正的價值。大多數的人不珍惜免費事物。你曾經免費得到一本書，卻拿來積灰塵嗎？你是否努力增進「自我發展」知識，提出價值千金的建議，其他人卻不珍惜？如果你支付了五百英鎊，才能買下那本書，你是否就比較願意閱讀呢？答案是肯定的。你甚至會把伴侶擠到床的邊邊，讓這本書大刺刺地躺在你們中間。你絕對會對那本書愛不釋手，把它當成寶一樣對待。因為金錢的多寡某種程度上決定了該物的價值，藉由金錢進行量化，讓無形的事物變成實質且有有意義的東西。
