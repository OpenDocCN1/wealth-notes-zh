# 四、金錢是一種持續流動的能量交換

能量守恆定律主張「能量不會憑空而生或被摧毀」。宇宙的總能量從未改變，只是移動。

金錢的流動也是買方和賣方之間的能量流動，透過的方式可以是交易、債權和債務、服務和價值，以及解決問題。如果能量無法藉由金錢流通，這個金錢形式就不會繼續存在，也不能滿足人類持續改變的目標。
