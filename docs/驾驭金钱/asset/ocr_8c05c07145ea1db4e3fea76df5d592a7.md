# ## 沒有錢，並不是你或別人的錯

大多數的人沒辦法發財，並非因為他們能力不足，或是賺錢很難、世上的錢根本不夠分配、金錢很邪惡、父母並未提供良好的環境等等，這一切只是因為他們尚未成功，或者說，他們只是還不知道要怎麼成功。這些人還不知要如何将自己擁有的無形資產轉化為現金，也不明白要怎麼用有形財富來實現自己內心的最高目標與願景。

我們將教會讀者如何實現並且擁有財富。便利貼的誕生只是一場意外外，這個發明卻能帶來每年十億英鎊的收益，而一切只起源於一張能夠隨手黏貼的紙條！
