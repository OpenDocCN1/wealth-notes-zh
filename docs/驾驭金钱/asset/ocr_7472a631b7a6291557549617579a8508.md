# 流動或不流動

相較之下，資本比較傾向於不流動，而收入更容易流動。流動的定義是指一個人或組織的金錢調動能力，是否可以處理即刻或短期的需求，或者能夠迅速轉化為金錢的資產。「換句話說，流動性就是你可以立刻獲得金錢的速度。雖然流動性是一個人（企業）不可缺少的能力，但也是一把雙面刃。一般而言，資產的流動能力愈高，代表回報愈低；資產的流動性愈低，代表回報愈高。雖然這句話並非完全正確，但符合大多數的情況。例如，房地產是流動性最低的資產之一，要用好幾個月，才能創造流動，但房地產一直都是回報最好的資產。
