# 如何結合熱情和專業

從現在開始，詢問自己六個關鍵問題。隨著你逐漸成長，每年至少要重新回顧一次這些問題和答案。

# 一、我喜歡現在的事業嗎？

如果你剛開始創業，雖然尚未成熟，或者你事業有成，無論是基於專業或熱情，你已經擁有足夠的興趣和靈感，願意完成第一階段的工作，承受創業那些披荊斬棘的挑戰和時間付出。這個起點很好，確保你不只想賺錢，也擁有熱情。你可以隨時轉變方向，尋找任何有趣的事物，只要遵守財富公式，解決有意義的社會問題，能夠賺錢。

# 二、十年之後，我依然喜歡事業的生活嗎？
