# 私人財富就是新的銀行

每個人的私有財富建立的互動關係就是新的投資基金。群衆募資和募款是迅速成長的金融創新，並且降低了銀行的獲利空間、資本保留以及權力。「企業集團與大型企業」和「私人投資者與創業家」之間的競爭愈演愈烈。本書將讓你學習如何重新導向金錢流動，在達爾文式的金融世界裡，找到你的獲利，同時增進他人的價值。
