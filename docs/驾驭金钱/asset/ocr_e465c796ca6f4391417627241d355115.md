# 數十年、數百年來都非常有用的事業模型

研究歷史上的鉅富，雖然他們專注的利基領域不同，依然具備相似的特質，其中最
主要的共同特質就是「良好的事業網絡」。這個觀念是指，我們必須建立新的事業網絡，
或者發揮原有網絡的槓桿價值，創造廣泛的事業觸角。

近代的新興產業包括鐵路、鋼鐵、光纖網絡、半導體……等。鑒古知今，我們可
以獲得非常重要的知識。雖然這個世界可能不會出現下一次的金熱或鐵路熱，大多數
的石油也已經被開採挖掘，但隨時隨地都會出現下一個重要的事業網絡，創造可觀的利
潤。很多事業網絡將開創新的顛覆發展，照顧人類的基礎生活權益，例如環保和再生能
源、星際旅行、量子資訊交換。
