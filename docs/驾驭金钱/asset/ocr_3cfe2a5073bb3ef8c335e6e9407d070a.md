# 感澈和欣賞的力量

![](bbox=[0.76, 0.15, 0.92, 0.32])

感澈具備強大的能量，可以提升你的良知意識，「不知感澈」則會降低良知。無論何時，只要你無法對自己給予或接受的恩惠心存感澈，那就意味著你的發財之路被阻擋了。

其他人看見後，會認為你不值得信任、不在乎、不知感澈，或者不重視自我價值，換言之，這會降低你的吸引力。

欣賞（appreciate）來自拉丁文 appreciate，意指「設定價格」（set a price on），讀者也可以參考估價（appise），意思是「提升價值」。

從字義學來說，你感謝的事物，其價值將會因而提升。藉由感謝其他事物，你自身的價值也會上升。感恩是一種更為精細複雜的情緒，來自於欣賞。即使生活發生的事件，乍看之下很像挑戰或問題，只要你心懷感澈，就會因此成長，甚至培育非常良好的態
