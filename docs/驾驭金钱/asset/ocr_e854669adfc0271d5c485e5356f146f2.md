# 合夥人與商業合資

合夥人、商業合資或聯合經營都是良好的事業經營模型，讓雙方攜手合作，拓展事業。許多知名公司的合資非常成功，例如索尼和愛立信、英國維珍集團和NASA銀行、柯倫和德本漢姆、Zeis和喬登、荒原路基和捷豹汽車。當然，不是所有商業合資都會創造理想的結果，務必確定你和合作夥伴能夠結合彼此的願景和價值，擁有不同的專業技巧和客戶群。贊助和代言是特殊的商業合資，名人或企業投入金錢，支持合作夥伴，藉此贏得曝光機率。
