# 資本、淨值和收入

生產金錢的方法一共有三種，其中包括信用債務和槓桿效果，讓我們一一檢閱：

# （一）資本

資本是指企業體或個人擁有的財務資源或資產，能夠促成成長、發展和創造收入，包括：

+   ・ 集資發展特定的商業模型或計畫。

・ 企業累積的財富（扣除累積的債務）。

・ 公司的股權或所有權。
