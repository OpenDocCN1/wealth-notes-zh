# 八十／二十法則

一九〇六年，義大利經濟學維弗雷多・帕雷圖（Vittsido Pareto）發明了ㄧ個數學方程式，描述義大利境內的財富分配不均現象，指出二十㚥的人擁有八十㚥的財富。一九四〇年代晚期，約瑟夫・朱蘭（JosehJuran）博士將「八十／二十法則」取名為帕雷圖原則，意指二十㚥的人擁有八十㚥的財富。

帕雷圖原則逐漸應用於日常事物中的不平等分配，而八十／二十的比例也變成相對分配的原則。在極端的情況裡，可能變成九十㚥和十㚥，或者九十五㚥和五㚥，甚至九十九㚥和ㄧ㚥的財富和成功分配。

以下是八十／二十法則的例子：


二十㚥的付出，創造八十㚥的成就。


二十㚥的勞工，完成八十㚥的工作。
