# 金錢的目標和本質

金錢存在的目的，是為了創造一種有效、公平且適用各種環境的交易價值，藉此促進人類社會的發展。

為了處理未來的不確定性，我們認為金錢可以發揮保值效果。今日的儲蓄，可以用於明日或未來的消費。
