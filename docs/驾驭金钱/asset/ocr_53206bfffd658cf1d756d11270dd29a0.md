# • 提出新的問題，改寫大腦的想法

許多人經常有這些想法，「我必須做到」、「我做不到」或者「我要怎麼做到？」關鍵的問題在於他們並未發揮槓桿效果，才會引發壓力、過度工作或浪費時間。與其糾結「我要怎麼做到？」不如思考「我可以找誰來做？」提出更好的問題，就會創造更好的生活品质。

很多人相信，有錢人之所以可以建立槓桿效果，就是因為他們有錢，但你沒有資源。你必須支付日常開銷、孩子的教育費用、繳交房屋貸款，肩負重重大任，時間非常有限。你的想法沒錯。然而，請記得，你愈晚建立槓桿，你成為他人槓桿的時間就愈長。如果其他人做得到，你也可以。生活槓桿是每一位偉大企業家都知道的系統和哲學。
