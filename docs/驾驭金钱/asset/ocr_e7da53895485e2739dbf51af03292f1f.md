# 複利效應

如果睡蓮在池塘水面的面積，每天會長一倍，三十天之後就會蓋滿整個池塘。但是，第二十九天時，睡蓮的面積只有池塘的一半，而且最後三分之一的時間，睡蓮的面積會成長超過50%。

倘若你在高爾夫球場與人打賭，第一洞只賭一英鎊，但每一洞都加倍。到了第三洞，賭注金額是四英鎊，第六洞變成三十二英鎊，第九洞則是二百五十六英鎊。到了第十五洞，賭注金額已經高達一萬六千三百八十四英鎊，十八洞的金額為十三萬一千○七十二英鎊。如此高金額的賭注，起點只是一英鎊。

許多人的內心都悄悄懷抱鄉願的想法，渴望得到睡蓮最後一天的成長，或第十八洞的複利效應賭金。但人生和金錢的運作原理並非如此單純。最後一天（或者隔天）的成果同時具備最頑固的慣性和最強大的動能。
