# 周末小结｜如何抓住这个时代的商业机遇？（含语音特别版）

前人的思考，我们的阶梯，欢迎收听“刘润·5分钟商学院”周末特别版。

最开始做5分钟商学院时，我做的第一件事是先花了整整3周、15个工作日规划了260期课程。到今天为止，我有幸陪同大家一起学习了60期，这也意味着，我们还将在一起很长时间。不知道你是不是也和我一样期待呢。

在这3个月中，我感受到了同学们的学习热情，也听到了大家的很多反馈，主要有三个方面：1）开通学员讨论，2）期待组织线下大课；3）把课程内容集结成书。

这些声音，我和得到的团队都听到了。今天向大家集中汇报一下。

1、关于开通学员间的讨论功能，我想大家已经看到了，上周我们开通了“学生会”的功能，4.6万的学员们，终于可以彼此连接了。我知道，很多城市的5分钟商学院的同学们，瞬间集结，组成了很多线下学习小组。大家还把“看情况”作为了接头暗号。

2、关于线下的课程，今天，我要宣布，在得到线下课程团队的帮助下，我们的线下大课，也终于确定于2017年1月14日，在我出发去南极前，在北京举办。

这次大课，我将花一整天的时间，好好与大家分享我对商业世界的看法，以及如何抓住这个时代的商业机遇。我会从四个角度分享我的看法：

第一，洞察变化：感知正在生成的未来。所有的商业，都要顺势而为，一定要理解时代的变化，才能正确抓住变化。到底是什么在推动最近这几年商业世界翻天覆地变化的底层逻辑？我希望带领大家感受这个逻辑，并且根据这个逻辑，感知未来。

第二，抓住不变：深刻回归商业的本质。看清变化的，是观察家，而看清不变的，才是战略家。我会在这部分把大家从变化中拉回来，回到商业的本质，找到那个没有变的基础，思考我们应该如何应对。

第三，创造价值：必须脱离人口红利。回到一个企业的微观，任何一个企业，在商业大环境中都是微观个体。从个体角度看，我们如何做出改变？我会从创造价值的角度，分析我们看到的三个红利，其本质，是创新的机遇。

第四，传递价值：尽量短路用户距离。互联网今天对传统行业到底产生了哪些影响，又给了我们哪些机遇？为什么互联网对中国线下机构势如破竹，但对美国影响不大？我们应该如何利用互联网，提升传递价值效率？我将好好分享我的观点。

没有成功的企业，只有时代的企业。英雄造时势，更是时势造英雄。让我们一起抓住趋势的红利，成就更大的事业。
