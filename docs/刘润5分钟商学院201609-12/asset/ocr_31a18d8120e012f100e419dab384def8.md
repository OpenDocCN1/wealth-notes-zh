# 心法1：先站桩再练功夫

5分钟商学院的课程是一套商业学习的基础体系，我的设想是能够让大家：

+   - 一天掌握一个概念，一周学习一个学科，
- 一季更新一个体系，一年完成一次升级。

所以，课表中260节课程的设计，是层层递进的。越到后面，越需要前面知识的积累。越重要的逻辑，越是建立在其他逻辑的基础ISSION上。

这就需要同学们在学习后面概念之前，先把前面的商业逻辑弄明白。比如，本周讲了互联网世界的5大基本定律，彼此之间就是紧密联系的。“边际成本”是经济原理，“长尾理论”就是这个经济原理所引起的市场现象，“免费”，就是这个原理给企业带来的一种新的商业模式。

把所有的课程当成一个完整体系，打好基础，后面练拳练梗，就会轻松很多。

# 心法2：知识必须是自己的才有用

复述是特别好的学习方法，要有意识地训练自己的表达能力。学完每天课程，你可以讲给你的同事听，你的朋友听，你的家人听，看看他们是否能明白。他们听不明白，就是你没理解透彻。

评论区是《5分钟商学院》非常大的一块宝库，不同行业的同学们贡献了很多有价值的思考、分享了很多精彩的商业套路案例，结合大家的优质评论，你能更透彻地理解每一个概念背后的商业逻辑和商业思考，更好学习。

但除了看评论，我更建议你写下自己的思考。用更精练、准确的文字表述自己的观点，这是一种思维训练。而且，通过这种方法，你可以把新学到的内容连接到已有的知识上，形成体系，这样，5分钟商学院的课程才能长到你的大脑上。

# 心法3：直接向高手讨教

每个周六，我都会邀请一位客座教授过来，他们大多是身经百战、内功深厚的商战高手。他们会告诉你，在那些成功的商业模式背后，自己究竟是如何考虑的？当时的困难是什么，又是通过何种方式顺利解决的。有心的你，可以迅速偷师。

# 精选留言分享

看了一下手机里面的软件，发现大多数都利用了网络效应来留住我这个用户。想起之前手机用的音乐软件是酷狗，换了网易云音乐就再也没换过了，因为后者有强大的社群交流群体，大家分享自己的歌单，分享自己听某首歌的感受，在这里你不仅听音乐还会找到志同道合的人。用户越优质，吸引效应就越大，网络也就越稳定。

这个月装修房子时，某品牌的地毯、壁纸、卫浴、漆、家具等组成联盟，只要你在这个联盟（活动期限内）任意门店购物消费，都可享受消费金额的30%的返券，在其他门店内相当于等值现金消费，这是典型的利用网络效应，并且利用整合资源增强用户黏性，达到共赢的效果。值得提醒的是，同水平的、差异化的异业联盟，才能更好粘住用户。

感觉今天的长尾理论和昨天的边际成本是硬币的两面。修理铺内多增加一件商品，就会增加展示成本，书店多放一本卖不掉的书，就会增加陈列成本，而淘宝、谷歌、亚马逊利用网络效应的互联网优势，极大地降低了商品的边际成本，提高了竞争能力。

我是做学校安全管理，主要帮学校健全一卡通制度、学生考勤制度，帮助家长通过手机就可以了解到孩子在学校的情况。我们的产品对代理商免费，对学校免费，但家长需要了解孩子在学校动态，就必须向我们代理商买一张一卡通，售价一百元。第二，我们平台有个线上商城，卖一些孩子必需的商品，我们和这些代理商平分利润。第三，平台现有300万家长用户，我们拉了很多商家投放广告，和代理商平分利润。羊毛出在猪身上，狗来买单！

本周总结：信息对称，互联网带来的全新机遇，让新创品牌有更大的可能挑战大品牌；网络效应，产品对用户的价值，取决于用户数，突破临界点后，会产生“洪荒之力”；边际成本，通过互联网技术把多生产一件产品的边际成本降为零，挑战传统经营模式；长尾理论，小众产品也可以有大市场，规模化地满足用户个性化需求是大势所趋；免费经济，将免费商品的成本进行转移，“二段收费”。
