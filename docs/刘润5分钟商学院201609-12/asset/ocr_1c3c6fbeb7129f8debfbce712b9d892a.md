# 周末小结｜CEO思维是这样炼成的

《5分钟商学院》的同学们，

周末好！

本周我们一起学习了宏观经济学中的5个核心概念：节约悖论、看得见的手、人口抚养比、泡沫经济和再分配。

有些同学留言问我，为什么这周都是辩论，听不到我的观点？还有些同学问，这些话题离生活好远，学了有什么用呢？

其实，告诉你哲学世界里相互矛盾的观点，引发思考，带你体验思辨之美，比单纯的站队，更能锻炼思维、帮助大家提升。

至于宏观经济究竟有什么用？我举个例子，比如你看到政府花了四百万采购、拉动民众消费、大众创业都也没能把GDP拉回去，接下来就该出口了。汇率优势是出口的关键之一。这时，及早的配置美元资产，就能抓住红利。

换言之，学会从宏观经济的角度看问题，提前知晓未来趋势，才能抓住时代机遇和商业机会。

回顾这一个多月30期的课程，消费心理学和行为经济学，是商业中术的部分。商业世界的5大基本逻辑和互联网的5大基本定律，是基本规律，是道的部分。而微观经济学和宏观经济学则是势，要明白大势、顺应潮流，站在更高角度看问题。

从术到道再进入势，这背后的设计，就是为了帮助大家在商业的系统世界里，不断提升自己的高度和见识。从留言里看得出，有同学喜欢术、有人喜欢道、有人喜欢势。要成为一个成功的CEO，取势、明道、优术，这几个方面都要全面发展，不能偏废。如此，才能在一周之后，作为真正的CEO，而不是一个操作人员，毕业。
