# 有趣的小虎

随着微信群的普及，社群经济相对简单得多了，现在各小区都有很成熟的业主群，在里面的群名字基本是栋数＋门牌＋自己微信名，知根知底，彼此信任。以虫妈生鲜为例探讨，可以升级为虫妈厨房，提供一系列厨房用品，粮油米面蔬菜水果，建立用户大数据，反向定制的时候提供反向私人定制，一样的价格，不一样的服务，比如，我要的水果是否可以多种水果组合啊，送人的东西是否可以单独包装啊，买蔬菜时候是否可以帮我摘一下在配点作料拿回家就可以炒啊等等，因为任何一款产品都可以追根溯源，所以吃的放心，买的安心。社群经济就是最后一公里的实践版本，一种新的商业形态，不管哪个行业都应该好好研究，做出反应，然后践行。

# 柳大叔

之前的工作有过许多社群方面的经历。
想有一个良好运转并盈利的社群，至少要满足下面这5个要素：

+   1. 共同的价值观。简单讲，就是大家在社群里都能找到和自己有共同喜好，并且能一起交流自己觉得好的东西。

+   2. 内容。即上面说的“大家都觉得好的”东西。需要以文字、图片、视频这些形式承载起来，大家才有交流和互动的基础。

+   3. 活动。再好的社群，都需要真实可感的交流、触碰。内容能解决的问题有限，固定有规律线下的活动，能让社群中的人更有归属感、信任感、安全感。
