# 周末小结｜如何管理知识并从中获利？（内有福利）

《5分钟商学院》的同学们，

周末好！

这周讲定价策略，内容比较多，大家周末有空的话可以再重复听一下，同步推荐一本书，骆品亮老师的《定价策略》，感兴趣的同学可以找来看看。

另外，有同学留言，老师我觉得每期内容都很好，听完之后都觉得很有价值，但过段时间就忘了，有没有什么方法能彻底记住、用起来呢？

今天我就来说分享两个学习记忆的小方法：

1、当天学习法：学习每天上新内容时，先听音频、再看文章、结合自身经验回复留言、查看其他同学留言。第二天时间允许的话，把你觉得特别有收获的内容分享给身边朋友，这些都会加深你的理解和记忆。

2、整体学习法：每一天，先听当天的內容，听完后听昨天的，再听上一星期今天的内容，再听20天之前的哪期，一天20分钟，复习巩固。

即使你觉得所有都理解了，也建议你不断回顾，不仅可以加深记忆，还能系统性地思考，发现许多新的知识。

知识本身不创造价值，知识用在实践中才有价值。这也是为什么彼得·德鲁克说：行大于知，一定要去实践，要尽可能找机会去实践。

如果你发现，实在找不到实践的地方，那也是正常的，所有东西你都能去实践，说明你管的生意已经非常大、非常复杂了。大部分人，都只是在商业的一部分中运行，而商学院是系统全面的知识，一定有些知识是你今天无法用的，但通过学习的方法先积累起来，一旦遇到合适场景就去实践，这样也会变成自己的真正的CEO。
