# | 本周用户精选留言

关于线上还是线下更合适，个人觉得还是要从消费者的购买环节来分析：

+   1、产生需求环节，消费者是如何产生需求的。靠单纯展示、商品本身就能刺激需求的就选线下，如美食。通过内容而产生需求的选线上。
2、搜索环节，消费者如何获取信息。OPPO和vivo就是利用3、4线城市信息不对称相对滞后，实行大面积的分销实体店，极少网上搜索的老年人也是一个值得开发的市场。
3、备选方案评估环节，消费者到底买哪一家的产品。以个人主观感觉为主的选线下，如香水。而更注重第三方评价的选线上。
4、购买环节。在意时间便利性、立刻就要买到的选线下。而需求少个个性化的（长尾产品）或者偏远地区不容易买到的选线上。
5、服务环节。基于产品的服务选线下，如手机贴膜等等。基于人的服务，如社交交流，高频回答服务等选线上。

现在的发展潮流单独的线上或者线下都可能没有好的长远发展，更多是根据这5种环节里相互结合而发展自己的优势。
