# 毕胜，必要商城CEO

曾就任于百度，历任总裁助理、市场总监等职务，2005年赴纳斯达克见证百度上市奇迹。2008年还曾创办乐淘网并任CEO。2014年创办全球首个C2M电子商务平台——必要商城，并担任CEO。

必要商城采用的是用户直连制造的短路经济模式，它一头连着制造商，一头连着用户，去除所有中间流通加价环节，制造商按需生产，节约高额的库存成本，从而让用户只用平民价格就能买到奢侈品质的商品。
