# 运用：案例

我在领教工坊带领着一个私人董事会，十几位组员都是各行各业成功的企业家。有一位组员叫崔立建，他创立了一家叫做置诚城市管网的，做不给道路开膛破肚，就能往地下埋管线的，非常传统的工程企业。他在上海狗狗式的攻城略地，做得很成功。发展到一定阶段，他现在也开始慢慢进入农耕式经营。

他把公司从原来的三个事业部，拆散为若干个“资产承包责任组”，指定客户，然后用奖金制，和合伙人制度管理。这些小组，交足了公司的合理利润后的超额利润，小组拿60%，公司拿40%。这个制度，实行不到一年，整个公司的精神面貌大变，业绩暴涨了70%。

# 小结：狩猎式、农耕式

狩猎式、农耕式，各有特点，适合企业不同阶段。从狩猎式走向农耕式，你需要三件武器：单客经济，销售激励，合伙人制度。
