# 利用賣出賣權<br>在理想價格取得好股票

本章要鎖定在具有風險的賣出賣權（Sell Put），或者精確地說為「有現金準備的賣權（Cash Secured Put）」。稱為之「Cash Secured」的原因在於，你必須始終備妥100%接到股票的資金，因此與一般單純裸賣（Naked Put）將盈虧目標指向純權利金的想法迥然不同。

儘管實際上都是做相同的賣出賣權，但背後實際的目的不同。Cash Secured Put的目的是在理想的價格，擁有取得1張（通常是100股）股票的機會，而Naked Put則是希望藉由選擇權時間價值耗損的特性，在盤整與小漲的時候，獲取收訖的權利金。

然而，許多投資者會在這兩者之間，刻意保留灰色地帶。因為他們認為，即使Naked Put跌到履約價之下，還是可以換成股票，既然可以換成股票，那便無所畏懼。因此，肆無忌憚地不斷賣出賣權，逐漸加大口數，帶著僥倖的心理，只要不跌就可以坐收豐碩的權利金，就算跌了還可以接到
