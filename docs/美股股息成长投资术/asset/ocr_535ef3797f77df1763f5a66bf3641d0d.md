舉例來說，2014年CAH與CVS Health（CVS製藥保健，美股代號CVS）簽署10年協議，將學名藥的採購業務合併，這將使得CAH有機會提高獲利，因為合併採購量能夠從藥商端得到更好的議價優勢。因此，CAH即使作為中階層的銷售商，但擁有夠大的銷售渠道、夠多的銷售量與夠多樣的商品，加上長期的客戶合約，相乘之下，就能為其所屬的低利潤產業，提供經濟規模帶來的成本優勢。

尤其對醫療產業而言，低成本的需求變得愈來愈緊迫，醫院希望節省開支並減少醫療浪費，若CAH在成本結構上有愈多的優勢，就愈能夠滿足客戶需求。而醫療作為必要支出，隨著人口老化與中產階級人數提升，醫療支出也將隨之增長，CAH的業務則恰恰建構在這樣的背景之下。

# 3.經濟護城河

美國前3大醫藥通路市占率高達90%，共約2,700億美元的市場，除了龍頭CAH外，另2大通路商為美源伯根（AmerisourceBergen，美股代號ABC）、麥克森（McKesson，美股代號MCK）。
