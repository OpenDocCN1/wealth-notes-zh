總結來說，在轉倉時機的選擇上，可以在股價靠近履約價時，判斷超出履約價的可能性高，或者已確定穿價之後再轉都可以。但要知道的是，突破履約價愈多，轉倉的條件一定愈差，還有到期天數愈短，轉倉的條件同樣較差。此外，轉倉沒有限定次數，假如你轉到次月後再度被穿越，那就繼續轉倉。當然，轉愈多次，碰上條件變差的機會也會提高。

### 方式2》提早布局深度價內的買進買權，參與上漲

這個方式是我最不推薦的方式，因為變數過多。使用的時機是，在價格尚未突破履約價之前，你預估價格越過關鍵點時，有可能拉出大波漲幅。既然會出現大波漲幅，就表示原本的賣出買權（Sell Call）履約價極有可能被突破，且超過很大的幅度。

而因為你已經有Sell Call這個鍋蓋，蓋住了最大獲利潛能，因此股價大漲讓你覺得「少賺」，而使你感到痛苦難耐。此時，你買進深度價內Delta值＞0.9（意即股價與選擇權的波動極為貼近）的1口買進買權來替代1張現股的價值，意思就是股票上漲的部分，會與權利金幾乎相等，因此能夠亦步亦趨地參與股票價格上漲。

理論上，想法沒有錯，但這個過程會有相當多變數，右頁表4做了2種腳本以及可能引發的多種情況。

這部分用文字難以完全清楚解釋，然而假如熟悉選擇權的你就會看懂，無論是走哪一套劇本，都會讓整個過程變得非常複雜且難以掌握。

為了參與持續上漲，你必須額外付出許多精力，並且要時時面對多種複雜情況。最後也許持續上漲並帶給你獲利，但也可能讓你白忙一場，甚至遭受額外的虧損。起因都在於，你無法忍受「少賺」的折磨。

因此，這個方式看似美好，但實務上，必須非常小心地呵護，或許你善於此道，或者樂此不疲，但你仍必須確定你有能力應付各種狀況。

此外，我很少開券商軟體，也不喜歡將時間花在交易上面，這種方式要時時刻刻關注價格變化，嚴重違反我要的簡單與被動原則。

### 方式3〉靠近結算時，賣出價內賣權

沒錯，是「賣權」！在本篇這邊首次出現，後續章節會獨立介紹賣權。

我最傾向使用的方式是上述第1種——轉倉，然而，有時轉倉的合約或者權利金非常不理想，導致轉倉的效果不彰，這時，我便會放棄轉倉。此時還有一個方式提供最後的機會，雖然不完美，但還可以接受。使用情況在於，賣出賣權（Sell Put）的履約價扣除收取的權利金之後，接到股票的成本，仍然在合理價或之下的價格。

使用價內的原因在於，我很希望用此價格取回1張股票，雖然成本較高，但仍是理想價格。而如果結算在賣權的履約價之上，還可以收取額外的現金流。雖然本來的股票仍然遭到讓出，但多了賣出賣權，至少有機會接回股票，或者收取現金流，而不是只能等待結算一途。

但最好在距離結算前1週～2週再使用，原因在於時間假如太長，變數變大，若結算價格低於賣權履約價、又低於原有的賣出買權履約價，那麼到結算之後，原本的持股仍在，還又多接了1張股票，但這情況並非是原本的計畫。最佳的情況是結算價格低於賣權履約價，但「高」於買權履約價。

![](img/dfd1504d95bd8956cc82c7d5cbadb262_431_0.png)

如表5範例，假設當初取得阿瑟丹尼爾斯米德蘭農業（美股代號ADM）的成本為35美元，在8月18日時股價已漲至45美元，而8月25日到期的賣出買權合約履約價為42美元，評估結算時要跌回42美元的機會不高，且事前計算合理價格假設為48美元。

也就是說，賣出價內賣權履約價46美元，因為賣權履約價高於現股價格，因此為價內，結算時只會有2種情況：

1. 股價高於46美元：沒接到股票，每股收取權利金1.15美元。
2. 股價低於46美元且高於42美元：原本的股票讓出（因為高於一開始的賣權履約價42美元），但8月18日追加的賣出賣權反而接到1張股票，成本為每股44.85美元（46美元－1.15美元）。

雖然原本部位在每股42美元遭賣出，而新合約用44.85美元買回，相當於預估合理價48美元的93折，因此，在這價格買回還是能接受。此外，假如持續上漲超過46美元，還能額外獲取權利金，雖然股票沒了，並非股息成長投資者樂見，但至少不會完全處於被動，而什麼都不能做。

# 若無法避免股票讓出，就甘心放手吧

最後一種情況就是，什麼都做不了，可能是轉倉條件很差，或者價格漲到你也不想用賣出賣權接回，那麼當然只剩下讓出股票這一途。但接受讓出股票又分為2種情況：

1. 你本來就希望在履約價的位置被讓出，因為10年平均本益比已達到40倍或者超過股息折價模型（DDM）合理價100%以上……等極度高估的價格。
2. 你是被迫在履約價被讓出，而你堅定希望能長久保有持股。然而每種投資方式都有其限制，你必須清楚知道你不可能把把贏、筆筆賺，也必須了解自己的投資系統有其極限，你既了解優點，也包容其缺點。我常做的是，假如價格仍然低於合理價許多，則在隔天直接現股買回；或者繼續等待股價回跌，抑或改用賣出賣權的方式在幾個月後接回。

因為我清楚知道，我的投資系統就是如此，儘管不常發生，但我知道這種情況在我的投資生涯中仍會持續發生。

很多投資者，總會覺得賣了買權，豈不是少賺？我想問題就出在這種心態之上。買晚了，覺得晚上車，「我是不是少賺了？」；賣早了，覺得錯失機會，捶胸頓足，「我又少賺了？」在我看來，這種少賺的情緒，都是你自己製造出來的假象。

投資本該是開心、愉快的事情，它是你在專注本業之餘，善用時間滾出雪球效應，期望它協助你達成長期的財務目標；投資不該是每日生活重心，更不該左右你的情緒。

有一個研究提出，虧損的感受是賺錢的2倍。同樣地，我認為這種少賺的情緒，也是賺錢的2倍吧！但是實際上，你到底哪裡少賺了？假設你是一名堅定的股息成長投資者或者長期投資者，持有蘋果（美股代號AAPL）股票的成木在每股90美元，賣出買權在100美元，現在股價105美元，合理價140美元。那麼，即使你沒有賣出買權，請問你會105美元賣出股票嗎？顯然不會，因為你堅定地專注企業價值，而不急於實現資本利得。

既然不會，那麼當結算時，股票在100美元賣出，取得10美元的資本利得，你卻要對於那5美元（105美元—110美元）的少賺耿耿於懷？這5美元的差距，便是你虛擬出來的，不是嗎？而且你怎麼知道，2個月後蘋果股價不會回跌到90美元呢？到時，你會不會又覺得自己很聰明，在100美元的時候就被迫讓出股票了？這邏輯好像不太對，你不是堅定的股息成長投資者嗎？按理說價格的波動不會是你再意的，你在意的是企業本質。

當然，也有可能你確實是堅定的投資者，你著眼的是20年後企業價值。那麼的確，假如在100美元讓出，而後好幾年都沒有低估的價格出現可供買回，這確實是種機會成本。這也是為什麼我不會一股腦地恐賣出賣權，尤其在市場情緒高漲之時。然而即使我謹慎地賣出賣權，仍碰上了股票被讓出，我也沒什麼技巧能引導你轉念。但我必須說，放過自己吧。

就算我可能很難有機會接回股票，但我可以等，同時我還有許多其他高品質的企業在手。而且因為我尊崇良好的分散，因此單一企業讓出，實際上對我的影響並不大。此外，我還能把注意力放在口袋名單中其他低估的企業。而我相信，謹慎評估企業品質與價值，產生的效益更大。至於，在投資的漫長過程中，曾經失去的那一小部分，失去就是失去了，我何必執著在那一個點上，反覆地用悔恨來懲罰自己。

如同我在第1篇開頭便早早點出，股息成長投資法不適合多數人，而掩護性買權（Covered Call）也是。我也許不能說服你信仰DGI，但我可以幫你剔除一個不適合你的選項；而Covered Call也是同樣的道理，假如不適合，就放棄它吧。減少選擇的數量，反而能讓你更專注於尋找最適合你的方式。愛你所選，了解自身能力限制，理解策略的極限，而後甘之如飴。

# 利用賣出賣權在理想價格取得好股票

本章要鎖定在具有風險的賣出賣權（Sell Put），或者精確地說為「有現金準備的賣權（Cash Secured Put）」。稱之為「Cash Secured」的原因在於，你必須始終備妥100%接到股票的資金，因此與一般單純裸賣（Naked Put）將盈虧目標指向純權利金的想法迥然不同。

儘管實際上都是做相同的賣出賣權，但背後實際的目的不同。Cash Secured Put的目的是在理想的價格，擁有取得1張（通常是100股）股票的機會，而Naked Put則是希望藉由選擇權時間價值耗損的特性，在盤整與小漲的時候，獲取收訖的權利金。

然而，許多投資者會在這兩者之間，刻意保留灰色地帶。因為他們認為，即使Naked Put跌到履約價之下，還是可以換成股票，既然可以換成股票，那便無所畏懼。因此，肆無忌憚地不斷賣出賣權，逐漸加大口數，帶著僥倖的心理，只要不跌就可以坐收豐碩的權利金，就算跌了還可以接到實體股票。

然而，市場就是有能力見縫插針，找到你的破口之處。當風平浪靜對你而言是常態之後，一段時間的美酒佳餚，已讓你漸失謹慎意識。過度放大的槓桿，在突發時期，一次吞噬之前的所有戰果。

### 長短線策略雖可同時運行，但投資系統切勿混淆

即使可以轉換為股票，然而張數過高，一、若你並非透徹地研究過該企業而持有過高比重的股票，此時任何波動都會讓你承受不了，事前有計畫地持有股票與被迫持有股票，在心理與資產管理上是截然不同的概念；二、轉換為股票的過程，可能因為張數過多導致爆倉，你會被要求補繳保證金（Margin Call）。

我並非反對使用選擇權來交易價差，工具本身為中性，沒有好壞之分。因此，資產組合之中，並非只能存在一種方式，投資人可聰明地融合多樣性，以符合自身需要。

數年前，與我的啟蒙師父獨大學習時，他便告訴我，長線與短線是可以完全同時存在運行的。當時的我覺得有些震撼，難道不會混淆與思緒打結嗎？漸漸地，我明白問題不在於帳戶有幾個分類、或是投資方式同時採用幾種，關鍵在於清楚而有紀律地執行不同獨立的資產類型，而不該讓各種類型之間曖昧不明、混淆不清。

# 賣Cash Secured Put僅適用於「鐵了心要買的股票」

回到Cash Secured Put，對我而言，能與股息成長投資（DGI）完美搭配的原因，我將其視為達成相同目的——「以我要的價格，購買我鐵了心要持有的企業」，只是改換成賣出賣權的手段來達成，但在等待的時間中，增加了額外的收入。

還記得在4-3中談到，曾有價值作爲錨定，價格才有比較之處。因为有了價值，我很堅定地知道我要在什麼合理價格或之下購買，無論是95折、85折還是75折，依照產業與不確定性而定。總之，我已決定什麼是理想價格。

既然如此，假如不使用賣出賣權，我的選擇只有一種，就是等待，別無他法。然而，假如我換成賣出賣權合約，將履約價定在我認為理想的價格，白話地說，就像有人先付了一筆錢（權利金）給我，讓我等待價格回歸到我事先設定的「好」價格。

因此，我只使用賣出賣權在「我鐵了心要買到的資產」上，但是因為當前個股價格我不滿意，那麼我願意等待，因為除了買好的（高品質企業）、更要買得好（好的價格）。

# 固定留100%現金作為預備金，一點槓桿都不使用

也因為我的目的就是為了取得股票，而非選擇權的價差，故我保留100%的現金作為接到股票的資本，一絲槓桿都不使用。除了有多少錢做多少事之外，也不因為是保證金帳戶，就放大賣出的口數（在保證金帳戶中，賣1口賣權只需要20%的保證金，有些投資者便會「善用」此方便，賣了5口，放大了槓桿）。

再者，股票在保證金帳戶中，同樣只需要20%的保證金，但我同樣用100%的預備資金，在整體帳戶中同樣不動用任何保證金，因此我的保證金總是在滿水位。

因此，該賣多少口賣權，取決於你真正想要買幾張股票。而可以購買幾張股票，則是依照全球行業分類標準（GICS）比率以及單一企業占比的框架而定（詳見3-4、3-5），不因為一時的貪婪或者疏忽，而逾越了戰略級的準則。

# 範例》賣星巴克賣權，等待合理價時先收權利金

最後，簡單舉一個賣出賣權的示例：

假設你評估星巴克（美股代號SBUX）的合理價格為59美元，再假設當前價格為54.34美元。但你希望取得的價格為合理價9折53.1美元（59美元×0.9），因此賣出賣權在5過後的1口合約，履約價為53美元，收取每股權利金0.6美元。

而且你事先確認過，你有100%（5,310美元）的資金，並且屆時假如取得100股星巴克時，占比資產組合GICS「非必需消費」提升至13.5%（低於計畫配額的15%）；而星巴克持股占比提升至3.5%（低於計畫配額的5%），都符合你的分散性框架。如此，在合約之下，結算時只有2種可能：

1. 股價高於53美元：未取得股票，但等待的過程，仍有一開始取得的60美元權利金。
2. 股價低於53美元：按合約以53美元收到一張股票，成本為52.4美元（53美元−0.6美元）（一旦落入價內，同樣可能在合約到期前，被抽中提前執行）。

或者改用10過後的1口合約，履約價為54美元，收取每股權利金0.93美元，成本為53.07美元（54美元−0.93美元），也能達到同樣效果。端看你對於打折的期望程度，以及取得股票的機率高低而定，履約價愈高，取得股票的機率也愈高；合約時間愈長，權利金也愈高，但等待時間較長。

當然，假如目前54.34美元已是你理想的價格，自然不需要等待，直接以現股購買。因為用理想價格取得資產是惟一目的，而選擇權只是等待過程的替代手段，絕非主要目的。假如為了權利金而賣出合約，卻取得你沒有真心想持有的企業，甚至拉大口數，要是遇上你本以為可以僥倖逃過的狀況時，便是災難循環的開始。

# 釐清選擇權策略目標，別陷入「少賺」迷思

如同掩護性買權（Covered Call）該章節（詳見6-1）所提到「少賺」的心理狀態，我知道賣出賣權（Sell Put）在你心中，又跑出「少賺」的想法。同樣地，這仍然是一種你虛擬出來折騰自己的心理狀態。

賣出賣權後，在等待過程中，如果現股價格一直上漲，我是不是「少賺了」？賣出賣權後，在等待過程中，如果價格跌到履約價以下，我是不是「買賣了」？

# 價格漲》可在等待合理價過程多收權利金

首先解讀第1種心理，假設你是一名股息成長投資（DGI）或者深信高溢價會嚴重危害長期報酬的投資人，那麼，你會謹慎地選擇高品質企業，並且刻意注重合理價格。因此，「等待」是基本需要具備的人格特質，我願意收取一點點權利金，在我真心要持有的資產，用我要的價格買到。

你覺得少賺，那表示你用錯工具，同時你的目的是短期資本利得。假如你能預測價格將大幅噴出，那麼你應該重資買進現股，甚至重倉買進買權（Buy Call），而不是只想賺一點點權利金的賣出賣權。

再回到如果你真是一名堅定的股息成長投資者，現在的价格是溢價 10%，請問你會用現股直接買進嗎？顯然不會，因為你注重品質、也在意價格。既然不會，那麼在价格上漲的過程中，你賣了賣權，收了一點權利金來等待好價位，何來「少賺了」？因為你本來就沒有打算在溢價的時候買進，不是嗎？

你不能又想要在低價買進，又望著价格上漲心癢難耐，分不清楚自己現在到底是採用什麼投資方式。坐此山，望彼山，可能到頭來是一場空；雖然長短線可以獨立運行，但是，投資系統可不能混淆又糾結。

# 價格跌》可用低於合理價買到好股票

第 2 種心理，則是發生在价格低於履約價時接到股票，覺得買貴了。

首先，這個价格本來就是你心心念念想要取得資產的成本，不是嗎？如果是，那麼在希望的价格取得股票，此時正面而健康的心理，應該是我終於在理想价格，買到我想要的高品質資產，而不是一買到股票就感覺那是帳面虧損，不是嗎？

如果不能接受，那你為什麼要選在此履約價賣出賣權？你可能會說，「我沒想到要在低於履約價時取得股票阿！」好吧，如果是這樣，那就算你直接買現股，當它下跌的時候，你應該也同樣不能接受吧！這才是真正問題，這跟是不是用選擇權一點關係都沒有。

因為你不能理解或者很難接受，一個價值50美元的資產在價格跌至40美元時欣然購買。在價值不變之下，當價格再次降到35美元時，同樣值得購買。

只有當你能改用價值作為一切評量標準時，你才能豁然地以40美元接股票，並在35美元時，評估再次增加持股。

# 賣出賣權亦可轉倉，但徒增困擾與複雜性

當然，與掩護性買權中提到的轉倉（詳見6-2）如出一轍，雖有調整的方式，但是我認為徒增困擾與複雜性。賣出賣權同樣可以轉倉，如下示例：

假設在6月30日時，星巴克（美股代號SBUX）現股價格58美元。此時賣了9月8日到期、履約價56美元的星巴克賣權合約，預計以56美元的價格承接1張股票，收取每股權利金1.1美元，實際承接股票成本為每股54.9美元（56美元−1.1美元）。
