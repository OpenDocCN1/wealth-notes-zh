# 近10年股息貴族波動程度低於S&P 500指數
——S&P 500股息貴族指數vs.S&P 500指數波動程度

| 群組 | 年化報酬率(%) | | | 標準差 | | |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | 3年 | 6年 | 10年 | 3年 | 6年 | 10年 |
| S&P 500股息貴族指數 | 9.37 | 9.53 | **14.06** | 1.09 | 1.57 | 0.77 |
| S&P 500指數 | 10.06 | 9.46 | **15.15** | 1.07 | 1.60 | 0.50 |

註：資料統計至 2017.10.31 資料來源：S&P Dow Jones Indices

（1928.01.01～2016.12.31），報告中將美股分成6組，不配發股息的企業歸類為1組，配發股息的企業則依股息殖利率高低分為5組。

先看結論，配發股息的5組企業，年化報酬率全數勝過不配發股息的企業（詳見圖6）；有趣的是，不是股息殖利率最高的族群表現最佳，反而是股息殖利率次高的族群表現最好。假設1928年初投資100萬美元，截至2016年12月底，股息殖利率次高的企業組別「組別4」，可累積到175億7,400萬美元，年化報酬率為11.61%；不配發股息的企業組別僅能累積到13億1,000萬美元，年化報酬率雖也有8.47%，但累積金額差距相當驚人，前者整整高出了12.4倍。
