多數投資人會覺得很難穩定獲利，因為這需要很多知識，沒有想像中那麼簡單！

非常幸運的是，本書裡對為何要做資產配置、如何找出售你自己的投資組合風格、如何設計投資組合、為何與如何使用DGI、量化分析與質化分析的比較，都有詳細介紹。

尤其第3篇分析各種投資護城河的案例解析十分精彩，而第4篇的分析流程與投資組合管理、第5篇的實用工具介紹也都很實用，可以想像這日 Gucci是多麼想把自己的所思、所想、所學，讓讀者一次學會！這裡節錄幾句我覺得印象深刻的內容，讓大家體會一下本書的深度跟廣度：

+   1.與其說投資是門科學，但我看它更像是人生的修為過程。

+   2.投資的目標是什麼？最好能夠具體，但又要不過於不切實際。

+   3.無論投資的頻率快與慢，都需要面對心理層面的問題，也同樣需要一份計畫，並且理性執行。

+   4.以創造現金流為目的，擺脫了短線與價差思維，因此能夠讓投資人安定身心，把全部精力專注在工作表現中，這絕對比尋找迅速提升績效的投資方法還要重要得多。
