# 股息成長企業在市場波動時可提供較高報酬  
——VIX增加，配發股息企業vs.不配發股息企業報酬率

| VIX月增率 | 配發股息企業相较于不配發股息企業  報酬差程度(%) |
|---|---|
| 40% < VIX月增率 | 1.96 |
| 20% < VIX月增率≤ 40% | 0.59 |
| 10% < VIX月增率≤ 20% | 1.16 |
| VIX月增率≤ 10% | 0.31 |
| 平均（所有VIX三十五月份期間） | 0.87 |

註：2007.10.01 ~ 2017.09.30    資料來源：Santa Barbara Asset Management

根據基金公司Guinness Atkinson Funds統計，自1973年～2010年，美國共經歷5次經濟大衰退，每股稅後盈餘（EPS）平均跌幅42%，而股息平均跌幅僅有8%（詳见表2）。

可以想像，在經濟蕭條時期，企業獲利可能嚴重衰退，然而許多財務體質強健的企業仍然手握鉅額現金，且企業同樣有大筆營業現金收入，足以度過短期的衰退。
