# # 評估轉型企業未來發展
以迪士尼為例

迪士尼（Walt Disney Company，美股代號DIS）於2017年8月公布的季報（截至2017.07.01），與2016年同期相比，營收持平，調整後（Non GAAP）EPS減少2%、營業現金流上升14%、自由現金流上升33%。

而迪士尼股價在2017年8月9日出現最大跌幅6.05%，只是，讓市場感到震驚的不是其財務數字，而是重大的策略調整。
