# 親手撰寫企業分析報告
增加解讀深度與廣度

第4篇將統整第3篇提及的大部分概念，實際執行一輪質化分析、量化分析，以及到目前為止尚未提到的價值評估。

分析與思考是沒有止境的過程，每當看到他人對於產業分析透徹，對於未來獲利的預估之嚴謹，都讓我感到折服；這也是為什麼我提到必須不斷閱讀，因為透過他人的研究，往往會不經意地獲得大量啟發。

我從2015年開始撰寫企業分析文章，便是要求自己要與知識不斷互動。透過吸收與理解再轉述成文字，這是與「閱讀」完全不同的概念，如此才能真正將知識與腦部產生連結。
