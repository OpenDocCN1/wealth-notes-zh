# Step3

接下來，使用者可以自行設定篩選指標，以下僅介紹較重要的幾項指標：

❶「Market Cap」（市值）：單位為百萬美元。如果使用者只想投資市值超過500億美元的企業，可以自行將最小條件設定為「50,000」，左側「篩選結果區」就只會顯示市值在500億美元以上的企業。

❷「Chowder Rule」（喬德夫則）：由一位名叫Chowder的投資者所提出的概念，以「當前殖利率＋5年年化股息成長率」來評估企業的投資價值。他認為，殖利率與股息成長率應該一起觀察，而不是特別挑選殖利率高或股息成長率高的標的，畢竟股息成長率的動力來自於EPS的成長，唯有EPS不斷增長，股息才可能持續地發放。附帶一提，Chowder自己用的標準為12%。

❸「DGR」（股息年化成長率）：共分爲近1年、近3年、近5年、近10年的股息年化成長率。
