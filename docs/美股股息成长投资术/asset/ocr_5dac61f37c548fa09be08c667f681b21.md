# 近5年資訊可免費查詢

我最常使用的資訊網站晨星（Morningstar），雖然內容大多是以文字與數據呈現，但資料很齊全，整理的方式也很簡潔。網站上大多數是免費資源，但以財報數據而言，只有近5年是免費。另外有1/4的資訊是付費的，包括10年財報資料、分析報告、合理價與護城河寬度等。
