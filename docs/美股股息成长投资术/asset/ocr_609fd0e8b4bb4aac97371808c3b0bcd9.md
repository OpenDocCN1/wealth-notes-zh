# 53
Dividend.com 6 大重要配息資訊全都露

「Dividend.com」網站主要是提供跟股息資訊相關的資訊，免費與付費資訊各半。以下簡單介紹一般投資者常會參考的功能：

# 1. 配息基本資訊

進入首頁（www.dividend.com），在  搜尋欄位輸入個股代號，並按下「Enter」鍵，進入個股頁面，可看到個股代號下方有 5 個指標，分別為：  「Dividend Yield」（股息殖利率）、  「Annualized Payout」（年化配息）、  「Payout Ratio」（股息配發率）、  「Dividend Growh」（股息連續成長年數），最後一項  「DARS Rating」是該網站對這檔股票的評級（為付費會員專屬，有興趣者可申請試用會員查看）。
