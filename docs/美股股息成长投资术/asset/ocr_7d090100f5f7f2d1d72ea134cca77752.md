+   6.產業分配必須符合規畫的GICS產業占比（保留一定的彈性緩衝範圍，如5%）與單一企業最大占比限制。

# 範例2》退休族，可投入資金總量固定

假如已是退休階段，可投入的資金總量已確定，日後不太會再挹注額外資金，採取以下的買進計畫較為適當：

+   1.選擇波動度較低的20～40家企業。

+   2.以股息成長15年以上的企業為配置主體，兼顧收入、穩定與成長。

+   3.每月挑選1～2家企業，按照評分與折扣率設定買進順序（投資組合中尚未買進的產業或企業優先）。

+   4.某產業或企業被特別低估時，稍微提高購買比重。

+   5.預留至少1次加碼的空間，以降低平均成本。

+   6.因為已非在職累積資金階段，不會有新資金挹注以調整產業比重，因此產業分配必須完全按照初始規畫的GICS權重配置，不給予緩衝範圍。
