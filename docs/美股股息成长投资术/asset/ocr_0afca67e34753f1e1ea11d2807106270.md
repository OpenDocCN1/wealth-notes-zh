# 第 12 篇 建立正確心態 穩固投資信心

首先，部分投資人的需求是現金收入，這個需求不專屬於退休族群，在職族群也可能同樣需要現金收入。無論是作為日常生活花費，或者希望再投入這份收入來加速雪球效應，總之，這些投資人的目標就是「現金流」模式，並且採用收益型投資，畢竟S&P 500指數約1.9%的股殖利率（2017.10.20為1.95%），並沒有滿足他們的需要。

而採取收益型投資（主要以穩健型債券為主），大約可以達到4%～5%的殖利率，但可能因此在資本利得方面落後S&P 500指數，這能定義為失敗的投資嗎？我不認為是。

既然這些投資人的目的是現金流，那麼硬是要求他們的長期資本利得報酬要高於市場大盤，根本上就違背了他們的需求。因為，為了打敗大盤而去投資低殖利率的標的，很有可能使得每年領取的利息收入（如股息或基金配息）不足以满足其需求，導致必須賣掉投資部位以求變現；在熊市恐惶時期，還得強迫自己贱賣資產，這對他們而言一點都不實際。

賣掉投資部位，將使得持有股數降低，未來可能領到的利息收入也會變少，這相當於砍掉了原本每年結果的果樹；事實上，這些投資人一點都不想把樹砍掉，他們只想繼續持有，並享受每年收穫的果實。

我認為，選擇投資方式，其實很類似於找尋自我的過程。假如違背個人意志，顯得各方面格格不入，產生不了投資信仰，自然很難以此走完人生
