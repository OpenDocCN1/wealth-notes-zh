# 股息連續成長篩選器》
視覺化方式呈現CCC List數據

我自行設計的另一個工具為視覺化的「股息連續成長篩選器」（Dashboard），其資料基礎也是來自Dave Fish的CCC List。我將此工具定義為「篩選器」，原因在於，其功能僅類似於用Excel篩選CCC List，只是我用視覺化的方式來處理。

# 適合投資新手挖掘口袋名單，再依企業價值進行篩選

這個工具的用法非常簡單，我沒有加入任何公式，也沒有定義衡量標準與DDM（股息折價模型）合理價，就只是如實地呈現CCC List原來的數據，並且依據使用者挑選的指標，呈現符合篩選條件的企業。

+   Step1 進入我的部落格首頁（www.guccidgi.com），點選①「股息連續成長篩選器」，就可以開啟篩選器視窗，左側為②篩選結果區，有各種不同顏色與大小的方塊，每個方塊代表一家企業；中間為③企業分類區，
