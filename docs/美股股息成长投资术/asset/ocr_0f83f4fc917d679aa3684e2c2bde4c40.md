# 第 3 篇 精進分析能力 篩出穩健標的

1年後旳1元股息現值＝1/（1＋10%）=1/1.1=0.909

2年後旳1元股息現值＝1/（1＋10%）$^{2}=1/（1.1）^{2}=1/1.21=0.826$

3年後旳1元股息現值＝1/（1＋10%）$^{3}=1/（1.1）^{3}=1/1.33=0.751$

：

25年後旳1元股息現值＝1/（1＋10%）$^{25}=1/（1.1）^{25}=1/10.8347=0.092$

30年後旳1元股息現值＝1/（1＋10%）$^{30}=1/（1.1）^{30}=1/17.4494=0.057$

可以發現，當時間愈來愈長，回推到現值也會變得愈來愈小，小到一定程度，大約25~30年就明顯趨近於0。再把上述30年以10%折扣率，將未來收益回推計算到現在的價格，這就是DCF或是DDM的概念。當然，實務上並不需要一年一年的計算，後續會提到簡化公式以及免費推算DCF（DDM）的網站。

再用個生活化的例子說明，假設有個業務向我推銷一臺機器，每年可以幫我賺進1萬元，而我預期每年報酬率為10%，這台機器價值多少呢？
