# 活用股息折價模型
算出股票合理價

價值評估（Valuation）是質化分析與量化分析都做完了，絕對不可或缺的一環。本章將介紹如何運用股息折價模型（DDM）來評估企業合理價。

DDM是現金流折價模型（DCF）的延伸版，何謂DCF？簡單來說，一家企業的內在價值，約等於該企業長時間獲利的總和。適合使用DCF估價的企業，主要是不常配發股息，或股息經常不連續成長的企業；若是股息連續成長的企業，則較適合用DDM來估價，也就是預估企業未來所能配發的股息，並回推未來股息在目前值多少錢，進而估算該企業目前的合理價。

# 加總未來每年股息現值，即為企業合理價

為什麼要回推未來股息在目前值多少錢？因為錢是有時間價值的，今天保留1元，放到1年後才使用，這1元在1年的時間裡，可能產生1%、5%或10%的報酬，因此今天的1元，會比5年後或10年後的1元更值錢。
