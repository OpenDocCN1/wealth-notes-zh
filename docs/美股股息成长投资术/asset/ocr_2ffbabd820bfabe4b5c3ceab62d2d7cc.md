# 方向2》以CCC List為基本篩選標準

這絕對是股息成長投資者最珍貴的资料來源，股息成長投資者Dave Fish的CCC List除了依照股息連續成長年數區分為股息冠軍、股息競爭者、股息挑戰者外，也包含了大量財務數據。

儘管缺乏少部分數據，如股東權益報酬率（ROE）、利息保障倍數、自由現金流占營收比率等，但仍瑕不掩瑜。我們可以下載CCC List後，自己補充這些數據。

我放在部落格上的「價值投資獵人全自動計算機」（詳見5-8），便是以CCC List為基礎資料，再自行補充我認為重要的財務數字後做出評分系統，最後結合股息折價模型（DDM）合理價（詳見4-2）。除了方便取用外，也在初期建構DG時，節省我許多時間。
