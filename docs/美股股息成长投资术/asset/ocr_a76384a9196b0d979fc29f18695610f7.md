# 2. 股息倒數計時

點選上方選單⑪「Upcoming Dividend Payouts」（即將配發股息），或

直接將網頁往下拉到該位置，首次使用者，網站會要求註冊Email才能查看

此項資訊。

這個區塊分為上下兩部分，上方為⑤「Next Ex-Dividended Date」（最

近一次除息日期）、⑥「Next Ex- Dividened Amount」（最近一次除息金

額）以及④「Dividend Shot Clock」（除息剩餘時間）；下方顯示與配息

相關的3個日期，分別為⑦「Ex-Dividend Date」（除息日）、⑧「Record

Date」（股東持有名冊紀錄日）、⑪「Pay Date」（股息支付日）。想要

獲取股息，必須在除息日前一交易日購入。而⑧「Payout type」（配發類

型）指的是該次配息的類型。
