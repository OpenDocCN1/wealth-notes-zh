# **Step 4**

除了用Step3的量化數據作為篩選條件之外，使用者也可以按照股息連續成長年數區分的3類企業來篩選，或者選取特定產業、行業的種類，來進行更小範圍的篩選。

+   1. 「CCC_Category」（股息成長企業類別）：Kings→股息連續成長50年以上；Champions→股息連續成長25年以上未滿50年；Contenders→股息連續成長10年以上未滿25年；Challengers→股息連續成長5年以上未滿10年。

+   2. 「Sector」（產業）：按照GICS的產業分類來篩選，例如：只想篩選非必需消費產業（Consumer Discretionary）、必需消費產業（Consumer Staples）、健康照護產業（Health Care），則僅需要勾選這3個選項即可。

+   3. 「Industry」（行業）：每一個GICS分類下的子行業分類。
