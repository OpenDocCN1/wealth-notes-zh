# 投資股息成長企業
成本殖利率將愈來愈高

「成本殖利率」（Yield On Cost）簡稱「YOC」，也有另一個說法
「YOI（Yield On Investment）」。不管是Cost或Investment，指的都是初
次購買價格或平均成本，公式為「成本殖利率＝目前股息／初次購買價格
（即平均成本）」。

因為台股當中罕有長期股息維持年年成長的企業，因此也鮮少聽到這個
名詞。在長期投資中，成本經常是固定的，或者說不常變動，因此股息連
續成長的話，自然會讓YOC變得愈來愈高。也就是說，相對於一開始付出
的資本，隨著股息連續成長，過了一段時間之後，從這筆資本所獲得的回
收率，每年會逐步攀升。
