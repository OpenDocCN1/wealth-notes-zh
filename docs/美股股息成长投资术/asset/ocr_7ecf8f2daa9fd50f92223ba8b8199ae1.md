+   1. 投資需求為達到市場平均報酬：可選擇單純投資ETF，既可股價平衡配置、報酬貼近市場，標準差又在10%～18%之間，不易有過大的波動。ETF是透過個股方式交易，仍避免不了30%的稅，但可以達成投資目標。

+   2. 投資條件為資金總量很高，或投資需求為穩定現金流收益：可選擇波動很小的公司債混合公債，不須投資個股。

+   3. 投資條件為善於分析企業未來價值、善於控制風險、情緒穩定不易受市場波動影響：例如可專注尋覓成長股，成長股大多不會有30%的稅，因為這類企業多不配發股息，主要將現金用於快速擴張，例如輝達（NVIDIA，美股代號NVDA）、特斯拉（Tesla，美股代號TSLA）、臉書（Facebook，美股代號FB）等。

+   4. 投資條件為穩定不受情緒控制的性格：例如採取動能投資，完全以機率與期望值思考，有成熟的交易機制。

投資方法還有許多，你可能擅長某一種，也可能混合使用。本書多次談到投資方法的適切性，每個人的內在特質、外在能力、財務狀況與長期目標不盡相同；股息雖貢獻長期報酬半壁江山，但沒有股息，也不表示你無法達成長期財務目標，還有許多方式能達到相同效果。每一種方式都有其侷限性，也都有機會成本。最終，我要再次重複，請試想即使沒有了這30%的稅負，就真的能百里平川？抑或行為模式才是問題的癥結呢？
