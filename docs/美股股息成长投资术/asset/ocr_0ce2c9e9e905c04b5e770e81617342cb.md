# 量化分析最重要目的，是檢視質化分析的結果

在我的股息成長投資（DGI）組合建構到中期之後，我往往是透過閱讀他人文章來尋找投資想法。閱讀他人研究過的成果，除了節省時間外，還能看到他人不同的思考方式。如同3-2所提到的，分析並無對錯，看法各有千秋，分析重在長期磨練思考的過程，並不斷精煉。沒有人總能看得正確，但長期錘鍊思考，一定能夠讓對的機會逐步提高。

當然本章不是要指出量化分析有什麼問題，而是我無法單純依靠數字帶給我信心，能帶給我十足信心的往往是來自於企業的本質；因此量化數據是我用來確認量化分析的結果，而非要透過數字來找出哪個指標能夠指引未來報酬。至於確認什麼呢？比方說：

1. 看到淨利率改善，我必定會查看長期的營業利益率（Operating Margin Ratio）是否逐步上升；想確認長期債務是否不斷墊高？我得查看長期負債占淨值比率（Long Term Debt to Equity）。

2. 看到每股稅後盈餘（EPS）近年表現不佳，我得再多查看營業現金流與自由現金流狀況；看到資本投入回報率（ROIC）達 12%，看似不錯，仍必須要再與同業相比，才能知道其水平是否真的比競爭者優秀。
