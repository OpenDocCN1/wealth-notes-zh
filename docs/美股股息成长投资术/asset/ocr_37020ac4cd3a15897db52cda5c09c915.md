如果不能接受，那你為什麼要選在此履約價賣出賣權？你可能會說，「我沒想到要在低於履約價時取得股票阿！」好吧，如果是這樣，那就算你直接買現股，當它下跌的時候，你應該也同樣不能接受吧！這才是真正 的問題，這跟是不是用選擇權一點關係都沒有。

因為你不能理解或者很難接受，一個價值50美元的資產在價格跌至40美元時欣然購買。在價值不變之下，當價格再次降到35美元時，同樣值得購買。

只有當你能改用價值作為一切評量標準時，你才能豁然地以40美元接股票，並在35美元時，評估再次增加持股。

# 賣出卖權亦可轉倉，但徒增困擾與複雜性

當然，與掩護性買權中提到的轉倉（詳見6-2）如出一轍，雖有調整的方式，但是我認為 徒增困擾與複雜性。賣出賣權同樣可以轉倉，如下 示例：

假設在6月30日時，星巴克（美股代號SBUX）現股價格58美元。此時賣了9月8日到期、履約價56美元的星巴克賣權合約，預計以56美元的價格承接1張股票，收取每股權利金1.1美元，實際承接股票成本為 每股54.9美元（56美元−1.1美元）。
