# 透過買進買權參與上漲，可能遭遇多種變數
——2種買進買權（BC）模擬腳本

| 腳本1 | 行為 | 場景判斷 | 最終結果 |
| :--- | :--- | :--- | :--- |
| 步驟 1 | 買進深度價內買權（BC） | 價格持續明顯上漲 | 參與全額上漲價差，但須扣除BC成本 |
| 步驟 2 | 賣出持股，保留BC部位 | 漲勢趨緩而非大漲 | 實現股票資本利得，BC部位扣除權利金支出，可能虧損、可能獲利 |
| 步驟 3 | 加寬買權（SC） | 停止大漲，甚至出現反轉跡象 | 增加SC保護BC的時間價值流失，組合成買權多頭價差。此時看法轉為緩漲，而非起始的大漲 |
| 情況 1 | 持續持有BC+SC | 保持緩漲 | 扣除BC付出的權利金，加回SC收取的權利金，可能為獲利 |
| 情況 2 | 持續持有BC+SC | 反轉下跌至BC履約價之下 | 跌幅超過BC+SC付出的權利金總和，終至大幅虧損 |
| 情況 3 | 持續持有BC+SC | 反轉下跌但保持BC履約價之上 | 結算後重新接到1張股票，選擇權的部分可能損益兩平或小虧 |

| 腳本2 | 行為 | 場景判斷 | 最終結果 |
| :--- | :--- | :--- | :--- |
| 步驟 1 | 買進深度價內買權（BC） | 價格持續明顯上漲 | 參與全額上漲價差，但須扣除BC成本 |
| 步驟 2 | 保留持股，結束BC部位 | 漲勢趨緩而非大漲 | 原有股票還在，但BC部位扣除權利金支出，可能虧損可能獲利 |
| 情況 1 | 持股與原有掩護性買權還在 | 再度大漲 | 股票還是讓出了，但中間過程白忙一場 |
| 情況 2 | 持股與原有掩護性買權還在 | 盤整，價格沒有超過履約價 | 股票還在，但中間過程白忙一場 |
