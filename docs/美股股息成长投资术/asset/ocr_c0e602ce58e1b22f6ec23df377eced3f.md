器學習的一種，電腦自行從巨量數據找出規則）。所謂的投資系統化，是在投資時，簡單遵循幾條規則，以避免心理因素過於擾動。

當一樣的數據同時攤開在2位投資人面前時，這2人會做出全然不同的決定，甚至同一個人在这1分鐘與下1分鐘也會做出不同決策。即使是身經百戰的投資人，也會受到情緒影響，讓投資決策過程複雜化，進而對財富造成巨大傷害。因此，採用簡單的系統化準則，最大優勢就在於它能夠移除我們的情緒行為，避免傷害的產生。

# 觀念3》以長遠的視野投資，不要參與短線投資

著名避險基金機構Baupost Group創辦人，同時也是經典書籍《安全邊際》作者賽思·卡拉曼（ Seth Klarman ）曾說：「投資人唯一能安身之地就是長期導向的投資。」這段話其實貫串了前述2個觀念：

1.DGI需要的不是短暫的高殖利率，關注的是企業的實質與營運。

2.投資人應當遵循系統化投資策略，因為短期的價格總是隨機漫步，參雜著過多大眾非理性的情緒，無法如實反映企業真實價值；然而將時間拉長來看，價格終能回歸企業應有價值。沒有一種策略能總是擊敗市場，即使是大師也不能年年做到，DGI也不例外。有些時候，報酬就是會落後於市場。
