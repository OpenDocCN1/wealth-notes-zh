# **利用Moneychmp網站，算出DDM合理價**

Moneychimp網站提供的DCF計算機（www.moneychimp.com/articles/valuation/dcf.htm），可依照填入的EPS與EPS成長率推算現金流折現評價；若填入股息，其計算結果則可視為DDM股息折現評價。

+   ①填入目前年股息，如0.80（美元）。
②填入第1段預估股息成長率，如15（%）。
③填入第1段預估股息成長年數，如10（代表未來10年）。
④填入第1段預估股息成長率，如7（%）。
⑤填入折扣率，如10（%）。
⑥按下「Calculate（計算）」，即可得出合理價54.8美元。
