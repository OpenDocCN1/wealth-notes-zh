# 運用5大工作表，強化投資管理效率

雲端試算表預設工作表頁面為「Start Here」，提醒使用者必須先登入 Google帳號，並於①「檔案」功能表→②「建立副本」，才能建立一份相 同格式的試算表副本，並且儲存到自己的雲端空間以進行後續的編輯。

![](bbox=[0.17, 0.39, 0.87, 0.55])

以下僅介紹5張主要工作表的功能：「Portfolio」（投資組 合）、「Summary」（摘要）、「DivCalendar」（股息月曆）、 「DivPayoutCalc」（股息計算）、「Transactions」（交易紀錄）。

# 工作表1）Portfolio（投資組合）

切換到①「Portfolio」工作表，其顯示使用者的投資組合總覽資料，初始 顯示的是預設的範本，使用者須在②橘色儲存格內填入你自己購買的美股 名單，包含「Company Name」（公司名稱）及「Symbol」（代號）、 所屬GICS（全球行業分類標準）產業類別。③綠色儲存格的部分則是已經
