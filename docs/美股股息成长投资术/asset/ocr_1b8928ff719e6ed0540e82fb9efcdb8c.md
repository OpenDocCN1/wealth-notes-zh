評估投資人優勢的能力，我想沒什麼絕對的主臬可以遵循，只有不斷練習。投資是投資企業本體，而不是買進股票本身；遇到不確定性的消息時，別急著下定論，而要冷靜思考這是否僅為短期影響、短期情緒，並不影響企業未來3～5年的發展？試著用退位思考的方式，以更為宏觀的視野，來看清全貌。

# 時間維度優勢》趁天空布局，靜待企業回歸應有價值

評估優勢得當，也可能不會在短期得到回報，然而這類長期投資人，願意承擔短期的不確定，早早在低於合理價時買進，然後持續一段時間，等待市場智慧回歸企業應有價值。耐心與紀律不容易，因為做出對的投資決策，仍可能讓投資組合在幾年內的報酬落後整體市場一大截。

此外，多數投資人急於要看每天、每季的報酬，鮮少有人在乎3～5年後蘋果公司的發展如何，人們更在乎這一季賣出幾支iPhone？營收有沒有成長？市場上多數人的短期思考已成常態，且隨著網路發展而資訊加速傳播，更容易讓消息被放大解讀，導致價格波動超乎消息本身應有的幅度。例如在季報發布時，對於整年展望下修EPS成長7%，但是股價卻下跌20%之多。

當市場出現此類「非」效率的時刻，恰恰為長期視点者創造好的投資機會，這也是我認為一般投資人能擁有的大部分優勢來源。
