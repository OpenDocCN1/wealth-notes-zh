# 世上不存在神奇指標
只能盡力掌握2優勢

想要單憑幾個神奇指標或觀察價格波動，就能夠輕鬆取得理想報酬，這種事並不存在於投資當中。假如有「專家」號稱他知道許多你不知道的事情，或者告訴你，只要這樣做就可以年年輕鬆賺多少%，那麼請更謹慎地看待它。

因此，假如不是非常確定某個投資方式與個人性格及財務目標相契合，同時又具備自主投資的能力，那麼我主觀認為大多數人應該考慮指數化投資，因為自組投資組合並不容易獲得好的投資成果。至於剩下的那種少數適合自主投資的族群，則必須具備可帶來理想報酬率的僅存優勢，我認為，只有「評估優勢」與「時間維度優勢」。
