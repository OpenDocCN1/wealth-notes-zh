# 工作表5》Transactions（交易紀錄）

要能產生以上的綜合數據或者圖表，來源當然就是你自行輸入的交易紀錄，包括「Date」（交易日期）、「Type」（交易類型）、「Stock」（股票名稱）、「Transacted Shares」（成交股數）、「Transacted Price/Share」（每股成交價格）、「Fees」（手續費）等。其中，(6)「Type」包含「Buy」（購買）、「Sell」（賣出）、「Div」（股息）、「Split」（拆分）4種交易類型，試算表會依照你輸入的內容，自動計算結果。
