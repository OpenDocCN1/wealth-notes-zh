# 股息再投入，可持續產生複利效果
——股息循環示意圖

![](bbox=[0.17, 0.32, 0.86, 0.54])

率3.5%、股息成長率6%，前幾年差異還不明顯，例如第5年時，有DRIP的單年股息為503美元，無DRIP則為442美元；但差距隨著時間拉長而逐漸擴大，在第25年時，有DRIP的單年股息為3,384美元，無DRIP則為1,502美元，成本殖利率（YOC）分別為33.84%、15.02%，前者已是後者的1倍以上，主因便是在於累積股數的不同（詳見圖2）。

再引用「Dividend.com」網站的數據，若於1980年投入資金2,000美元於百事可樂（PepsiCo，美股代號PEP），並執行DRIP至2014年，其價值累積至15萬美元（詳見圖3），股數從80股成長至2,800股。
