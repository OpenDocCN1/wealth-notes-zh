# 工作表3》 DivCalendar（股息月曆）

這頁面會依每次收到股息的日期，按月份排列，顯示該企業在當月收到的股息，並且在下方①「Total」（總計）欄位計算該月份取得的股息。

另外，②「Estimated Dividends」（預估股息）則是顯示「假如能拿到全年股息」的總額，因為購買的時間可能是在配發股息之後，投資者自然不會領到全年股息，因此「Estimated Dividends」有時會大於「Total」。
