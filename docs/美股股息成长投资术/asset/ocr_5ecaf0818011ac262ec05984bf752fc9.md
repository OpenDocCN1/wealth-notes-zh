# 掌握3大元素 搿懂DGI致勝策略

第1篇談了許多我對投資的理解，也是我認為投資之中最重要的概念；至於方法，反而是其次才要關注的。我目前所采用的是「股息成長投資（DGI）」策略，DGI是Dividend Growth Investing（或Investor）的縮寫，在美國是一種普遍的投資方式。

簡單的说，DGI就是由「價值投資＋股息成長」的企業，提供持續而穩定的現金流，並收割長期投資之後的資本利得。逐項拆解DGI策略，主要有3個元素：價值投資、持續而穩健的現金流、長期資本利得。
