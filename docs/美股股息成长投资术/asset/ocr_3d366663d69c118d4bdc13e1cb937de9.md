# 5. Valuation (價值評估)

晨星的⓬「Valuation」頁面，除了在左側顯示⓫「企業目前數值」，例如常見的本益比、股價淨值比、股息殖利率等，右側也顯示⓬「產業平均」、「S&P 500平均」，以及「該企業5年平均」。投資者可以加以比較，得知目前企業處於何種「相對」的位階。接著，可切換至次頁籤⓮「Wall Street Estimates」，則提供華爾街分析師們的預估。
