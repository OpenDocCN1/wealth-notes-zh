# 資深投資人不須投入新資金，就能放大股息
————全新投資人vs.資深投資人產生股息600美元方式

| | 現在 | 1年後 |
| :--- | :--- | :--- |
| DGI 全新投資人 | 投入一筆 1萬7,200美元資本，打造股息成長投資組合 | 投資組合殖利率 3.5%，1年後可產生股息約 600美元 |
| DGI 資深投資人 | 投資組合已可創造股息 1萬美元，無須再投入新資金 | 投資組合的上一年度股息為 1萬美元，以股息成長率 6% 計算，1年後自然增加股息 600美元 |

以我個人投資組合近年股息殖利率約3.5%估算，假設現在一切從頭開始，想要獲得600美元的現金流，要掏出多少全新資本呢？

答案是，需要約1萬7,200美元（約合新台幣51萬6,000元，已是許多受薪階級1年的收入總額），才能用1年的時間，產生約600美元的現金流（1萬7,200美元×3.5%＝602美元）。

然而，對於已擁有股息現金流1萬美元的DGI投資人而言，不需要多做什麼事，下一年度就會自然而然地增加600美元的股息，增加的股息是從原有資金滾動而產生，不需要再加入新的資本（詳見表1）；這顆雪球不需要外力推動，也可以一天24小時不停歇地滾動，它不會生病也不會抱怨，比
