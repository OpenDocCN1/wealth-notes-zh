如果1年可產生10%的報酬率，1年後\(\$ 1\$\)元，在目前的價值（以下稱現值）就必須以10%回推，也就是約\(0.909\)元（\(1/(1+10\%)\)），這10%就稱為折扣率、折價率，或是預期報酬率。現值的計算公式為（\(D_n\)為每年股息、\(k\)為折扣率）：

```
\[
\begin{gathered}
n年後股息的現值 = \frac{D_n}{(1 + k)^n}
\end{gathered}
\]
```

如果是10年後的1元，以每年10%的折扣率回推，價值就只等於現在的0.386元（詳见表1）；換句話說，現在的0.386元，以每年10%的複利推算（亦即有10%的年報酬率），10年之後約有1元的價值。

DDM就是用這種時間價值的概念，將未來每一年能從企業拿到的股息，以預期報酬率回推至現值，再將每一年的現值加總，就可以算出企業現在的合理股價。

假設每年股息相同，DDM股息折現公式為（\(V_0\)為目前合理股價（現值）、\(D_n\)為第n年後的股息、k為折扣率）：

```
\[
\begin{gathered}
V_0 = \frac{D_1}{1 + k} + \frac{D_2}{(1 + k)^2} + \frac{D_3}{(1 + k)^3} + \cdots + \frac{D_n}{(1 + k)^n}
\end{gathered}
\]
```
