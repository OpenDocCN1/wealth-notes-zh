加機會、搶占先機；但投資領域不行，因為這些東西都不重要，若想獲取比平均更高的投資報酬，需要卓越洞察力、直覺、價值觀念，以及對市場心理層面的熟稔，想做到這些，就需要「第2層思考」。

你與其他人拿到相同資訊，或許你們一樣聰明、一樣消息靈通，但你必須要能洞察出其他人疏忽的地方、他們沒想過的事以及錯失的機會，進而有著不同的反應與行為。

第1層思考的人需要的只是「對未來的看法」，而且通常會很直覺地將其串成因與果，例如：「企業前景看好，所以股價上漲」；但是懂得「第2層思考」的人，思考的不僅如此。

以下引用《投資最重要的事》當中，談到「第2層思考」的人所需考慮的更多事情：

+   1. 未來可能的結果會坐落在什麼範圍？
2. 我認為會出現哪種結果？
3. 我的看法正確的機率有多少？
4. 市場共識是什麼？
5. 我的預期與市場差異多少？
6. 資產價格與市場共識，與我認定的價格吻合度有多少？
7. 價格反映出的市場共識是悲觀還是樂觀？
