也要同時考慮到質（種類）的分散，否則增加的企業數量不僅無法發揮分散效果，也降低決策品質，並增加管理精力。

你必須在企業家數、單一企業占比與管理精力之間取得平衡，沒有標準答案，你必須自己去尋找。假設希望組合的企業家數較少，那麼表示在產業內的廣度將較為狹隘，此時你必須更專注地挑出產業中的代表者。

我認為可從幾個面向去縮減：

+   1.放棄部分非核心的GICS產業：例如資訊科技、原物料、能源等變動性較高的產業，或是自己的掌握能力較差、且本來在股息冠軍或股息貴族產業配置比重就很低的產業。

+   2.只選產業中的部分行業為代表：例如健康照護，你持有的企業所屬行業，可能無法涵蓋該產業的完整範圍，如生技研發、製藥與營養品、醫療器材、個人護理、藥局批發與零售，必須更謹慎地從中挑選1～2個較有把握的行業。

+   3.聚焦股息連續成長逾10年的企業：以「股息冠軍」（股息連續成長25年以上）與「股息競爭者」（股息連續成長10年～未達25年）等股息連續成長年數較長的族群作為配置核心，而「股息挑戰者」（股利連續成長5年～未達10年）配置較低比重。
