# 近70年來，股息占市場總報酬比率達52.7%
——每10年股息占S&P500總報酬比率

| 時期 | 總報酬 (%) | 價格成長 (%) | 股息 (%) | 股息占總報酬比率 (%) |
| :--- | :--- | :--- | :--- | :--- |
| 1940 年代 | 143.1 | 34.8 | 108.3 | 75.7 |
| 1950 年代 | 467.4 | 256.7 | 210.7 | 45.1 |
| 1960 年代 | 109.5 | 53.7 | 55.8 | 51.0 |
| 1970 年代 | 76.9 | 17.2 | 59.7 | 77.6 |
| 1980 年代 | 389.2 | 227.4 | 161.8 | 41.6 |
| 1990 年代 | 432.2 | 315.7 | 107.5 | 25.4 |
| 2000 年代 | -9.1 | -24.1 | -15.0 | N / A |
| 平均 | 228.6 | 125.9 | 102.7 | **52.7** |

註：資料日期 1940.12.31～2011.12.31
資料來源：Guinness Atkinson Funds

酬將縮水約60%。

再以10年為單位來觀察，1940年代起每個10年，股息對於S&P 500指數總報酬的平均貢獻度占了52.7%（詳见表1），可以說，S&P 500指數的投資人所獲得的報酬，有一半以上來自股息。尤其是指數總報酬偏低時，股息的貢獻度更為明顯，例如1970年代的10年期間，S&P 500指數總報酬為76.9%，股息就貢獻了59.7%，占了總報酬的77.6%，可見在市場環境不佳時，絕大部分報酬來自於股息的支撐。
