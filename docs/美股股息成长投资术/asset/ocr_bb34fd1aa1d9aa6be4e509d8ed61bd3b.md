# ①2016年會計年度

+   ①營業收入年成長19%，達1,215億美元。
②營業利益年成長14%，達24億6,000萬美元；Non GAAP營業利益成長17%，達28億9,500萬美元。
③營業利益率2.02%。
④EPS成長20%，達4.32美元；Non GAAP EPS成長20%，達5.24美元。

其中，「GAAP」代表按一般公認會計準則編製的財報數據；「Non GAAP」意指排除一次性事件與非經營性質的收益，更精準地呈現企業的核心獲利狀況。然而Non GAAP相對於GAAP並沒有統一的標準，因此在閱讀財報時，應留意被排除的項目有哪些，並且判斷是否合理。

# ②2017年第1季季報

+   ①營業收入年成長14%。
②營業利益年衰退14%；Non GAAP營業利益減少9%。
③稅後淨利減少19%；Non GAAP稅後淨利減少13%。
④EPS減少17%；Non GAAP EPS減少10%。
⑤醫事事業部門：營收成長14%，稅後淨利減少19%，淨利率減少0.76個百分點。
⑥醫療事業部門：營收成長12%，稅後淨利成長26%，淨利率成長0.42個百分點。
