# ## 投資方式無分優劣

18世紀工業化之後，人類生產商品的能力大增，資本家在假設所有消費者需求類似的前提下，量產規格化商品，並用較低廉的價格，讓大部分的人都能享受類似商品。然而，我認為有些商品或服務是無法以單一規格強銷於所有人，理財或投資方法都屬於其中。

首先，每個個體的條件都不一樣，舉凡收入、家庭狀況、英文能力到軟性實力（如心理素質、紀律、耐心、好奇心等）不盡相同，很難以銀行專員販售規格化商品的模式，套用到所有人。

這有點類似保險，每個投保人在意的部分不同，有些人的需求是身後的財產規畫，有些人有大額醫療支出的需求，而有些人則在乎年金收入。各種保險商品在設計時都是中立的，沒有哪一種保險商品可以適用所有人；因此，業務員勢必要以客戶利益為前提、著眼於客戶真正的需求，才能為客戶規畫最適切的保單組合。
