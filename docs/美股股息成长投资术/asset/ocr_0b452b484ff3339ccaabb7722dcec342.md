# 前言

險，早已喪失年輕時最大的本錢——時間。

再回頭看看我那位大學同學的朋友圈與同事圈，長期以來，都是收入既高又穩定的階層，因此他認為舒服的日子能夠一直這樣過下去；且隨著收入提高，他也選擇大幅提高支出。

假如認為有錢就等於很會花錢，或是花很多錢，來滿足他人對於富人應有的期待形象，這是個人的選擇，也沒有什麼不對。沒有人能干涉他人消費的方式，我也對此不感興趣。誰說一定要提早投資？一定要讓複利雪球效應發酵？一定要會量入為出、聰明花錢，分辨需要與想要呢？

我慢慢學習同理心，站在他們的立場去理解他們的想法；我發現，每個人當下其實都在做其認為「最符合利益的事」，因此我現在的想法就是「無為」，不再想方法地催促朋友們積極理財。雖然現在只要談到理財話題，我仍是不厭其煩地搬出同一套說法：「高薪與高儲蓄率才是比投資方法更重要的東西！即使是高薪，也要小心避免消費隨著收入擴張。」因為高薪不等於很會理財，有錢人也不等於很會花錢，更不需要讓自己必須表現得「符合社會期待」。

同樣的，這樣無為的想法也延伸到我對於本書的中心思想。我不吹報報酬，也不為股息成長投資（DGI）擦脂抹粉，而是以中立的觀點，闡述我的投資方式。假如可以，我主觀的認為，95%的人應該考慮被動式ETF資
