# 3. Key Ratios（重要財務比率）

回到網頁上方，點選「Key Ratios」後，「Financials」（財務）欄目為財報當中較重要的數據摘要，時間長達10年。這區塊的每個數據都很重要，因此我會全部查看，而下方還有「Profitability」（獲利率）、「Growth」（成長性）、「Cash Flow」（現金流）、「Financial Health」（財務健康）及「Efficiency Ratios」（經營效率比）5個標籤頁，其中，我常看的是「Profitability」、「Cash Flow」與「Financial Health」。分別介紹如下：

Financials（財務）：例如在第4篇介紹撰寫企業分析的量化分析重點項目（詳見4-1），當中的長期基本面數據，這裡都可以快速看到數據。例如，「絕對數字類」包括營收、EPS等，我會看第1年與第10年，知道整體趨勢為何，再計算年化成長率。至於毛利率、營業利益率等「比率類」，則會看穩定性（能成長更好），然後計算10年平均估值。
