# 1.15
撇開主動、被動投資之爭
回歸需求適切性

在1-2談到「沒有最好，只有最合適的投資方式」之後，我想再延伸談一下主動式與被動式投資。因為這是一個很有趣的黨爭，但我認為其實沒有必要，原因就在於私人目標適切性。

自從指數化投資在近10年受到投資人青睞後，主動式與被動式議題爭論不休。就多數人的理解，機械化投入ETF（指數股票型基金），ETF會按照指數分配的持股比例投資指數成分股，普遍稱之為「被動式投資」；除此之外，幾乎都被歸類為「主動式投資」。

而一旦選擇主動式投資，就等於積極選股，甚至被貼上「好大喜功」、「想要擊敗大盤」等標籤。只要報酬不如大盤，就是主動式投資人不切實際；報酬超越大盤，就是運氣。

不過，我認為還是要回到我不斷提到的「適切性」。我會選擇主動式投
