
# 充分理解個股價值，以杜絕價格變動噪音

我們無法預期價格的路徑，價格一向是曲曲折折；我們能掌握的是了解企業本質，以及購買的理想價格，不能掌握的是預測每一天的價格變化。

立即的帳面虧損並不是件愉快的事；然而，充分理解價值，且假如評估正確，市場一旦發現認知落差，價格將慢慢回歸至應有價值，儘管過程可能需要好幾年。以價值的角度思考，能夠幫助我們處於不斷跳動的價格噪音時，更清楚地掌握主脈絡，減輕心理折磨。

工具終究只是工具，它無法立即幫助你改善投資狀況。雖然你會看到許多看似美好的劇本，然而，假使不能理解工具的極限，以及具備正確的心理素質，我建議你不要觸碰選擇權。因為槓桿會數倍放大人性的恐懼、貪婪與歡愉。

# 高薪、高儲蓄是累積財富雙引擎

坊間一點都不缺乏投資方法，也不缺少投資訊息。然而，彷彿擁有了這些就可以在投資路上平步青雲，似乎財富累積再也不是問題。我們的社會與價值觀已演變成快速與速成，包含知識學習領域也出現同樣現象，我們已漸漸摒棄那些享受緩慢累積的樂趣。

談到投資，最重要的並不是「不斷尋找新奇而厲害的方法」，因為無論是何種投機或投資的頻率，終究必須面對相同的敵人，也就是「自己」。唯有在心理狀態豐實的狀態下，才能在市場波動時泰然處之，朝著原有的理性目標前進。

因此，我想提醒大家，投資之前絕對不能忽略的核心觀念——財富累積的雙引擎是「高薪」、「高儲蓄」，再搭配「穩健投資」，才能踏實達成目標。

暢銷書《原來有錢人都這麼做》（1995年首次發行），是作者湯瑪斯·史丹利（Thomas J. Stanley）和威廉·丹柯（William D. Danko）耗費20多年，專訪500位富人与1萬1,000名高所得或高資產人士所做的問卷調查分析，規模堪稱史上最大的一次普及研究。作者探討的是這些富人的共同點，以及他們「如何成為有錢人」。

# 成為有錢人的關鍵是以工作為基礎

書中所定義的「富人」，指的是淨資產（扣除負債後的資產）超過100萬美元的人，當時美國1億個家庭當中僅占3.5%，而這些資產達100萬美元的富人，其中8成是白手起家，而非富二代，這與我在美國《Money》雜誌看到的數據86%相當接近。

這類所謂的有錢人，不開進口車，也沒有穿著高級西裝，住在中產階級甚至藍領階級的社區中，買鞋平均最高金額為140美元，手錶平均最高金額235美元。

衆多富人對於財富累積都總結了這麼一句話：「創造財富的旅程本身比達到目的地更讓人滿足。當我們回首打造財富的過往，憶起當初不斷設定目標和每次達成目標時那種強烈的喜悅。」

他們的意思其實是說，財富最終只是個結果，而過程中艱辛的付出、達成計畫中的目標，就如同生活與工作中完成的其他困難目標一樣，令人感到自我滿足。

這份耗時20多年的研究，以大量真實數據調查結果，確認了成為富人的幾個關鍵：
- 勤奮工作
- 為將來儲蓄
- 簡樸
- 時間累積
- 量入為出

我在自序中也有提到美國《Money》雜誌當中對於富人的訪談，關於他們談到如何累積財富的共同點，不外乎高薪、節儉、勤奮、努力不懈、規律以及紀律犧牲。說真的，哪一點不為大眾所熟知？很多時候，祕密不是握在少數人手中，只是一般人做不到而已。

# 追求薪資成長比投資成功更重要

國內薪資負成長是個久而不決的問題，通膨在過去15年，年化成長率2%，台灣是少數有通膨但薪資負成長的國家。而根據主計總處的調查，2016年度受薪階級的每月主要工作（不含加班費、獎金等非經常性薪資），未達5萬元占82.54%，達7萬元以上者僅占4.95%。

有人覺得未來毫無機會，但有一群人認為必須提早做準備，因而激發其旺盛的行動力。未來階層的流動只會愈來愈固化，階級跨越的機會將愈來愈少，環境不會改變，但是你的想法卻可以改變。例如，多數人通常有「用時間換錢」的觀念，輕易地販售掉有限的時間，換取不對等的回報；更嚴重的是，有些人認為永遠只能用時間換取金錢，特地排隊2小時、東奔西跑貨比三家，只為了少花幾十塊錢。

然而，金錢其實是可以買到時間的。花點錢購買、閱讀幾本好書，只要快速抓到作者的幾句精華，就能買到他人的時間、節省自己的時間，或是花點錢充實自己的能力，就有機會幫助自己提高薪資水準。

為什麼提高薪資比投資更值得重視？因為我相信，透過薪資獲得報酬，比透過投資獲得報酬來得容易。

簡單計算一下，想獲得月收入5萬元（相當於年收入60萬元）的投資報酬，以殖利率5%計算，必須擁有本金1,200萬元，才能創造1年60萬元的現金流，或是每個月買賣股票的價差要達到5萬元，這2種方式對一般上班族而言實屬不易；但要讓薪水達到5萬元以上，卻可以透過工作能力與經驗累積來獲取。

# 投資不是最後的救贖

再者，投資也不是萬靈藥或者最後的救贖。以美國股市為例，長期實質報酬率僅約5%～7%（根據25～30年S&P 500指數含股息再投入的長期年化報酬率並扣除通膨計算），每一次資產要翻倍至少需耗時10年。

資產管理公司J.P. Morgan提出的報告也顯示，一般投資人20年平均報酬率僅有2.1%（資料統計期間為1996年～2015年），換句話說，資產翻倍時間要大幅拉長到34年，若冀望以投資來大幅提升資產，並不實際！

# 後記

因此，對於正在投資路上摸索，或是才要開始投資的人，我的建議是，顧好本業、量入為出，妥善規畫財務後，再談投資。

投資是生活體悟的延伸，唯有在身心狀態都合適的狀態下，才能泰然地看著每一顆希望的種子茁壯。當你汲汲營營想要速成時，人心就容易浮動，更容易走歪了路。我不求投資能讓我錦衣玉食，但求自在喜樂。

最後，引用蘋果公司（Apple）創辦人賈伯斯（Steve Jobs）曾至史丹佛大學的演講片段，與讀者共勉：「當我在念大學時，無法預見如何將這些點滴聯繫在一起，但是10年後再回顧，真的就非常、非常清楚。再一次：你沒辦法預見這些點滴如何聯繫，唯有透過回顧，可以看出彼此關聯。所以你必須相信，無論如何，這些點滴會在未來互相連結，有些東西你必須相信，像你的直覺、天命、人生、因果，諸如此類種種。這樣的想法讓我永遠不沮喪灰心，也的確塑造了我人生中所有的不同。」
