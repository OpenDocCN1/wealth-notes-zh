# 22 搞笑菜單

搞笑模仿者也注意到餐廳過度使用語言文字包裝的傾向，我們特別喜愛下列這兩個假菜單網站：Fuds (www.fudsmenu.com/menu.html)，Brooklyn Bar Menu Generator (www.brooklynbarmenus.com)；兩者都任意挑選文字，為時髦熱點設計出搞笑的新菜單。

身為紐約客，傑夫可以作證，這些搞笑菜單和許多時髦餐廳的菜單毫無違和感！
