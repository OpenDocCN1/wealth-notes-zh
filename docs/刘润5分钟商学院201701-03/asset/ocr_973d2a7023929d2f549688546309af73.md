# 概念：X-Y理论

美国心理学家道格拉斯·麦格雷戈提出X-Y理论，他认为，一个人本质是否受激励者，作为经理者应该怎样对待员工，是否把员工看作是承担任务、寻求更高能力的希望；能为期望相对较高是人们为组织结构而工作的唯一方法；游荡在需要各个心理上作为操作者；激励力量和动机是人们广泛具有的。

# 小结：识X-Y理论

X-Y理论是人性的两种不同角度。X理论认为人的行为视作机械，需要外力作用才产生行动；Y理论把人视作一个有机整体，其不仅不反对管理，而且也愿意接受内在动机。作为管理者，你需要一手激励，一手压力，故而要像大橡树那样。
