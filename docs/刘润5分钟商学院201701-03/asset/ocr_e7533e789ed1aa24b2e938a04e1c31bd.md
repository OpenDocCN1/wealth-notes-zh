# 刘春林 3

国企联通，每年从211、985学校招聘一波新员工，先安排1-2个月的集中培训（公司制度、规范、文化等），后安排到一线的营业厅实习几个月，然后再到各个部门转一圈，每个部门由老员工带几个星期，然后就定部门，再在部门内学习具体的事物，一般也是打打杂、看看资料，一年后才基本能独立地完成工作。
但是小公司是没有这么多时间耗着，入职后，直接干活，边做边学，不懂自己再问，目的是快速满足公司工作需求为主。
我认为，不管是大企业还是小公司，得有针对新员工的培训流程，有基本的行为规范和价值观培训，给新员工关怀，有即时的反馈，严格的考核机制，让他们先从具体的小事情做起，然后观察，就可筛选出好的蘑菇，为公司注入新的力量。
