工资应该列在利润表的成本项。人工工资根据情况，可能属于固定成本，也可能属于变动成本。比如，工人的工资是固定的，那么人工应该属于固定成本。如果企业是以计件的形式来支付工资，那么人工应该属于变动成本。

不管是自己开公司还是进行投资，我们都应该学习如何去解读财务报表。但是在学习财务报表的过程中，一定把每一个概念辨析清楚。因为财务报表中实际到处都是坑，你不理解清楚概念，就有可能对数字进行错误的解读。

我举一个具体的例子：你看到一家公司的毛利润增加了，那是不是意味着这家公司今年的经营业绩上升了？其实很可能这个公司是由积压的库存才导致毛利润的增加。

我们具体来看看，比如有家工厂今年产量扩大了一倍，但是因为市场不好，产品销售数量和去年一样，即只卖出了一半的产品。这个时候，实际上经营状况和去年比是变得更差了。但是如果你看财务报表的话，会发现毛利润增加了。

这是怎么回事？因为有一半的产品没有卖出，变成了存货，所以固定成本只有一半跟随卖掉的产品，由生产成本进入利润表的营业成本。就是说营业成本相对去年来说减少了，而产品销售量和去年一样，意味着收入不变，那么毛利润自然就提高了。但这个毛利润的提高并不意味着企业的业绩提升，实际今年经营情况更差！这种现象在高固定成本的重资产行业会比较明显。

所以学习的财务报表一定要概念清晰，而且要多看例子，多思考，才能真正了解一下公司的实际经营情况！

大量的隐藏信息会藏身于上市公司财务报表中。财务分析应该先从三张表入手，即利润表、现金流量表和资产负债表。在看这些表时有许多通俗的技巧和秘籍，抓住重要的指标比较重要，比如看“损益表”的几个重要指标：

+   1. 市销率：相对于市盈率来说，该指标是上市公司股票市值跟该公司销售收入的比率。通常情况下市销率等于1是最合适的。而在这个指标里，销售收入是最重要的，如果一个企业销售收入不断增长而利润没有增长，这个企业的价值就要重估了。一般情况下，企业都是先出现收入的改进，后出现利润的增长，所以收入比利润更真实、市销率比市盈率更有效、收入比利润更快反映企业状况。（当然因为对企业和审计机构来说，帮助企业提前确认销售收入甚至虚构销售收入并不是很featured的事情；如果能排除公司作假行为，其模型结论可能可以成立）。

+   2. 毛利率：就是销售毛利润除销售收入。要跟踪毛利率的变化，要看历史上的情况，毛利率过高的现象不会持续（垄断行业例外），过低的现象也不会持续。所以，如果一个企业在毛利率很低的情况下有稳定的业绩，一旦价格上涨，利润的增加会非常明显。反过来，如果毛利率过高，企业业绩已经稳定，毛利率平稳的行业将受到投资者的追捧。

+   3. 三费操纵：所谓三费，即销售费用、管理费用和财务费用（三费也可称为期间费用），从理论上来说，销售费用很难操纵，而管理费用可操纵的猫腻最多，管理费用中最可以操纵的就是“计提”。譬如有的公司计提绿化费、福利费，有的公司计提坏账损失，有的公司计提资产减值准备，这一却，都会列入管理费用。而这些计提，多数不影响交税，都是上市公司，隐藏利润的手段。

当然，如果反过来，也可以成为故意增加利润的手段。比方说，钢铁公司的资产减值，计提坏账了。但如果某段时间后这块资产突然值钱，公司冲回这笔计提费用，那当期利润也会大幅度增加。另外，折旧也是操纵利润的手法。总之，三项费用变化无穷，一家好企业，一般会保持三项费用的相对稳定。正常的企业，在这期间费用与销售收入成正比变化并保持合理递增速度。企业在扩张的同时，三项费用没有同步增加，就是企业挖潜的结果，这样的企业才有价值。

+   4. 终级净利润（这是作者杜撰的词，会记学里面没有的）：主营业务收入减去主营业务成本，得出主营业务利润。主营业务利润减去三费，得出营业利润。营业利润加减其他收入再加减投资收益，得出税前利润。税前利润再减去所得税，得出净利润。净利润减去少数股东权益就是归属于母公司的终极净利润（这个指标再加上期初可分配利润余额后，就是终极利润，期末公司可分配利润余额。）
