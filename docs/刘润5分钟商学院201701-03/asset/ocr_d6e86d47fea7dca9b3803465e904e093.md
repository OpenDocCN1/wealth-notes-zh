# 概念：管理和领导

关于领导力，有各种流派。在我个人看来，每个管理者手中有两个工具，一个叫管理，一个叫领导。管理和领导这两个工具最根本的区别是什么呢？管理的核心驱动力，内心是靠“怕”来驱动的，无论是KPI指标的考核，还是做错了事需要罚站的这种企业文化，都需要有一个“怕”作为内心的核心驱动力。所以越发展，你会发现员工越来越难管，因为大量的团队都觉得最大的难题是员工不再怕我们了。

那为什么员工会不像前些年一样怕老板呢？我个人认为，因为互联网放大了每一个个人的能力。当互联网放大了每一个个人的能力以后，你还希望员工像昔年一样天天唯领导的马首是瞻，领导只需要制定相应的考核制度和指标，就能够管好员工的行为，这就变得越来越困难了。

那么是不是这样下去员工就没法管了呢？也不是，你会发现有大量的公司其实管得也蛮好的，尤其是很多年轻人居多的，像华为、京东、阿里巴巴这些公司都是年轻人，但是管得也还不错，原因是什么呢？就是领导在这里面发挥了巨大的作用。

领导和管理最根本的区别就在于，领导的核心驱动力并不是怕，而是尊重和信任。

# 运用：游戏改变领导力

那么怎么打造这些90后、95后和我们的团队之间的尊重和信任呢？

我要推荐大家用四个游戏化的工具，这来自于我们在《樊登速读》里分享过的一本书，叫《游戏改变世界》。我会把《游戏改变世界》延伸一下，变成“游戏改变领导力”。

任何一个事情是否是一个游戏要符合下面四个规则：

# 第一个规则是要有宏大的目标。你会发现我们小时候就算打超级玛丽，我们的目标也是要救公主，然后每一个游戏一定有一个宏大的目标，而这个宏大的目标会给你一个代入感，会让你觉得自己做的事情特别得棒，就像魔兽，你要带领你的部落去成长、去抵御外敌，这种宏大感是特别棒的。所以，你有没有试过，给过你的团队的人一个宏大的目标，还是大家每天来上班只是为了养家糊口，这个感觉是完全不同的。所有的这些指数型的公司，所有的独角兽公司都有一个特别夸张和离谱的目标，这就是游戏的第一个特征目的。

# 游戏的第二个特征就是规则一定要清晰。比如说在优步这样的公司，一个司机开车开得好不好或者这个月的收入高低，跟他和领导的关系几乎没有什么关系，他不需要讨好任何一个派单员，因为根本就不存在这么一个派单员，它的一切规则都是围绕着算法展开的，而这个算法其实就是游戏的规则。所以任何一个游戏都要有清晰明确的规则。而反过来，很多团队大家觉得没劲的原因是因为领导总变，你做得好不重要，你跟领导的关系或者领导对你的看法才重要。

# 第三个是即时反馈。你会发现打游戏的时候，几乎每隔几秒钟就会给你掏一个宝贝，每隔几秒钟让你得一个勋章，这都是即时反馈的方法。而我们在日常生活当中，很多领导把每个月发工资当作是即时反馈，我经常开玩笑说发工资不算即时反馈，工资少了才算反馈。所以当我们给大家的反馈频率太低的时候，你会发现大家慢慢就没劲了。

# 最后一条很重要，叫做自愿参与。我想大家可以扪心自问一下，我们是自愿来上班的还是为生活所迫而来的。怎么样才能够让员工做到自愿来上班呢？在这个地方又延伸出另外一本书，就是我在罗辑思维代班的时候曾经讲过的一本书，叫做《联盟》，你得把员工和你自己视作为一个联盟，包括离职的员工你都希望他能够发展得更好，这时候员工才会考虑到我今天来这里工作，那么五年以后当我离开这个地方的时候，我自己会成为一个什么样的人，这是他的目标。所以当用这样的方法把公司的目标和员工个人的目标统一在一起的时候，你会发现就比较容易实现让员工自愿来上班。

所以如果这四条能够合理恰当地运用到我们的工作当中的时候，你会发现团队的积极性就会变得完全不一样，这些都是我自己曾经用过，并且我在带我的团队的时候不断实践的方法，也相信能够给你的团队带来一些不一样的感受。

最后，祝大家在学习之余新年快乐，有机会可以到《樊登速读》来看一看，我们这里有很多好书等着大家。谢谢，再次谢谢刘润老师。
