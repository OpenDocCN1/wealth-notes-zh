# 周末小结 | 商业世界最重要的能力

《5分钟商学院》的同学们，

大家周末好！

今天的商业世界里，你经常能听到有人说，“别跟我谈理论，有本事你也去干几年，就啥都知道了”。

他们也许确实很有行动力，但不重视理论，很可能没有搭建起系统性的商业认知框架，这就使得他们的归因能力很成问题。

# 什么叫归因能力？就是他们做了一件事，做成功了，但是未必知道自己是怎么成功的。

于是，当面临企业转型或者再次创业时，他们往往很难获得二次成功。而那些获得二次成功甚至是三次成功的企业家，通常都被认为是战略家，因为他们具备基础的商业认知框架，能够理解商业行为的规律，能做正确的归因。

如何才能培养自己建立正确归因的能力？

+   1、搭建商业认知框架。《5分钟商学院》专栏的设计逻辑，就是要帮助大家建立系统的商业认知框架。有人觉得，只有我自己悟出来的才是我的，但如果每个人都靠自己悟出来，这个世界不会有进步，因为始终是在走原来的那一小步。只有在别人成功经验的基础上，再往前走一步，才可能超越前人。要学会把前人的思考当成我们的阶梯。

+   2、学习用关联的、整体的、动态的眼光看问题。这是作为商业顾问必须具备的能力，也是建立正确归因的另一个关键所在。关联的眼光，就是看到要素之间的关系。整体的眼光，就是把一系列的事物放在一块，把它变成一个系统。动态的眼光，就是加上一个时间轴，不要只看到结果，而是要看到过去是什么导致了这个结果，以及未来又会是什么样。

期待大家能从课程中拿走更多的内容，期待你的进步。

作为管理者第一步就是要敢于放权并信任手下，放权后要悉心指导，指导后还要承担责任，手下做出来的东西汇报给上级，出了任何问题，都是作为领导的你的责任，绝对不能回避，如果汇报上级后得到表扬，那么把表扬也让给自己的手下，这样，你部门的人才能服你，你这位领导才能越来越轻松。

作为领导或父母需要多加注意：
谈话时多用商量、建议和请求口气；分配安排时尽量照顾到个人能力/兴趣/爱好；对员工或子女，不要安排太具体，个人有相当的一定的自由，较多的选择与灵活；大部分管理决策是在领导或父母的鼓励下由团队或家庭讨论决定，而不是由领导或父母单独决定，政策是领导和下级或父母和子女共同智慧；领导或父母积极参加团体或家庭活动，与员工或子女无心理距离。

所以，管理家庭和团队是相通的。

将目标翻译成任务，然后将大任务拆分成阶段性的小任务，并且能记录进度，随时反馈调整，这对销售额分成业绩指标是非常有用的。比如，今年分配给我的任务是100万美金的销售额。那么，按照去年的销售数据来分解。这100万有40万会在钢铁行业，30万在环保行业，20万在造纸行业，剩下的10万比较零碎，来自一些不同行业的订单集合。

接着分，40万钢铁行业，主要有4个大客户，这4个大客户保持每月至少二次拜访频率，每次去的话都要去相应的连铸，以及高炉炼铁和转炉除尘工艺段见相应的人。然后可以将拜访计划初步落实在日历上。其余行业以此类推。

最后就是新客户的开拓，根据转化率算出要拜访多少新客户，分解到每月，每周，每天。通过发邮件，电话联系，登门拜访的步骤，建立联系并筛出优质潜在客户。每周的销售例会要对数据进行汇总和分析。分解的任务是否完成？重大项目进展到哪一步？下一步计划是什么？就是通过详细的任务分解，及时的数据统计和分析，到位的案例剖析，精准的方案制定。周而复始，持之以恒，你会发现，销售原来是个体力活。

+   我曾对团队全员讲过两点：
1、对外一句话:下属所犯的任何错误，对上级和外界，我就会讲一句话，这是我的错。因为如果我说这是谁谁的错，上级会讲一句话:那我要你是干什么的？
2、对内一册书:在团队内部要建立对错误的总结分享机制，把团队每一次错误记录编制成“错误手册”，把当下的错误损失转化为未来的经验财富，降低公司在同类错误上付出两次成本的风险。

中国的很多事没有绝对的对错之分，合理最重要，合理的决定要素就是要把握好度。人与人的关系也不会一层不变，要么越来越好，要么越来越差，关键是在不断的实践中找到合适的距离，把握好分寸，让关系为我们所用，而不是被其所累。
