《每日商学院学习七步法则》
一.分析年和周课表：第一时间关注周末发布的课表。对本周课程有宏观认知，准备提前预习。
由此可见：我并不是什么神人，十几分钟写出大篇幅文字。其实都是提前准备。

+   二.自我提问，深度思考：
按照之前的经验认知，给自己提问。
A.概念本身分析：
概念什么意思？产生原因及背景？经典案例有哪些？适用场景的标准？局限或弊端有哪些？
B.概念结合分析：
我为什么要学这个概念？不学和学习这个概念对我有什么影响？怎么结合运用到自己的家庭和事业？怎么帮朋友的行业出点子？
由此可见：每次写作业的角度可以很多。

+   三.作业初稿：
结合自己思考和整合的资料，撰写初稿。尽力做到简洁明了，条理清晰，层层递进，环环相扣。字数在2000-3000字左右。
由此可见：写出层次逻辑清晰的文字，是有前提的。

+   四.学习当天课程：
观察和学习老师分别在概念/例子/运用/小结/过招，几个部分的字文字表达。制作自己的思维导图。
由此可见：学习的层次推进感很重要。

+   五.完善作业并提交：
结合当天课程和之前写的作业初稿，进行完善融合，字数精简到1000-1500字，做好排版，以最快速度提交。目的是让自己有一个紧迫的仪式感，会更加专注，提升效率。
由此可见：十几分钟谢留言，只是一个精简的仪式过程。

+   六.学习其他同学留言思路：
将其他同学和自己的留言进行观察对比。思考自己是否有思维盲点，查缺补漏。顺手点赞他人鼓励，送人鲜花手有余香！
由此可见：互相学习很重要，还有互相鼓励。
