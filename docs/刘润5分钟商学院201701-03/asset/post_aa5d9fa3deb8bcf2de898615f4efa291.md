# 客座教授 | 企业转型过程中，如何获得各方认同？

![](img/5bc03606054caee6e4ef8bff8979929a_69_0.png)

《5分钟商学院》的同学们，

大家周末好！

这一周，我们请到了东方航空电子商务有限公司总经理、中国东方航空股份有限公司转型办公室主任，韦志林。他从事民航空业超过20年，近年来致力于战略转型、变革管理、商业模式创新、电子商务等业务，推动东航向现代航空服务集成商的业务转型，构建东航的空中互联网平台，组建并运营国内第一家航空电子商务公司。

很多人都佩服于他在渠道、产品、服务等方面的创新举动，这一周期，我们请他来分享一下企业转型过程中，如何平衡各方利益、获得各方认同？

![](img/5bc03606054caee6e4ef8bff8979929a_69_1.png)

您在带领航空公司进行转型的过程中，如何让已有的员工（特别是骨干员工）了解到转型的价值，参与到公司的成长中？又需要拟定哪些具体的岗位标准，让新招入的人才能够快速融入转型体系中呢？

企业转型，并不一定是转行，一定程度是基于现有业务的变革，在做深现有池塘的基础上如何挖掘新池塘，拓展新市场、挖掘新需求、获取新客户、赢得新增长。因此转型必须要获得企业上下的高度认同，上下同欲方可胜，否则现有组织格局和员工都会成为转型的阻碍因素。

最高管理层的持续推动、转型愿景及其行动计划的全方位培训、相关资源的足额配备，坚定企业转型的战略决心。同时蹄疾步稳推进转型，积小胜为大胜，让各相关利益方看到阶段性成果，树立转型成功的信心，重要的是让重要部门、骨干员工在转型过程中能参与其中并发挥积极作用并从中获益。

转型既是现有业务的变革，也是新业务的拓展，自然就会有新的岗位产生，这些新岗位可能短期内在企业现有人才中难以匹配到，必须引进外部人才。对于新业务的岗位需求，直接招募成熟人才，相对可以直接推动新业务发展。

能低成本地留住优秀人才，是每个企业梦寐以求的，您认为培养员工和留住优秀人才最好的方式是什么呢？除了给予员工匹配的岗位、适当进行培训，还有哪些更重要的方法？

培养员工的最好方式是因材施教，员工入职的层级与成熟度不同，培养的方式必须相适应。

针对新手，除了常规入职培训、岗前技能培训等常规动作外，完整的职业生涯设计及其配套的课程体系至关重要，同时指定相应的职业导师与相关岗位挂职轮岗也是重要手段。新人是企业发展和成长的未来人才与子弟兵，对其中有培养潜力的，还需要进行持续重点跟踪和关键岗位压担子锻炼。针对成熟且层级较高人员，则需要在重点项目和关键职位上进行历练，并辅以适当外训以开阔视野。

如何留住优秀人才，关键在于企业成长性、企业文化和恰到好处的激励措施。

这三者相辅相成，企业没有成长性，再好的企业文化和激励政策，对于优秀人才而言都觉得是不可持久，一样会毅然决然挂靴而去；另一方面，企业发展极具成长潜力，但企业最高管理者的管理风格和企业文化不能适应，再好的激励政策也未必能留住优秀人才。同样的，对于优秀人才，根据其成长不同阶段的需求，也应有相应的激励措施跟进，股权、期权激励不是万能的，能力肯定、平台拓展、管理幅度等自我实现的需求对某些优秀人才也许更有效。

管理无定势，合适的才是最好的。

在国有企业派遣制与聘用制并行，大多数人安于现状的形势下，如何调动员工积极参与到电子商务的工作中？如何做好新老员工的协作？

国有企业中人才济济，既有稳健性人才，也有开拓性人才。对于互联网+和电商类等新业务，需要建立一个相对隔离于原有企业文化、用人机制、激励机制的企业特区来推进。

优秀员工长时间没有晋级，是技术骨干的，可以增加技术等级薪酬，也可以给予技术攻关类任务；对于管理类人才，可以轮换岗位，也可增加年底绩效的方式，予以激励。东航电商筹建与运营过程中，外链招聘员工比例超过90%。新老员工的协作，传帮带和专业培训各有优势，基于不同企业文化，基于企业培训机制和能力，基于业务发展的成熟度等等因素，各有侧重。

+   1、做生意想清楚你到底想做什么生意，你是想做产品一端的生意，还是做流量一端的生意。你基本上只能选择一边。如果你决定从产品端进去，就应该做好你的产品，然后去跟所有的这些渠道商去谈合作，那你就变成to B的生意。如果你打算做流量的生意，就要去选经过你的店、或者在天猫看你店的人，他们想买什么，你就得给他什么。你要放弃自己的品牌，要把店做成一个买手店，找到最时尚、漂亮、最新的东西，进货去卖。
+   2、准备大干一番事情前，最好先单点验证你的逻辑。我们用平常融资的逻辑来看待你的商业模式。第一步，你要做出产品来。第二步，要在单独一个地方证明它的商业是成立的。什么叫“商业是成立的”？就是有人愿意为这个价值买单，并且应该有利润产生，单点盈利。第三个就是拿到单点盈利之后你要开始扩张，开始融资，在第二，第三，第四城市，形成一个联动的效应，进一步降低成本。这是分成三步来形成这个逻辑。
+   3、这个世界上永远有不对称。如果你不断地找到信息不对称的领域，你发现一个需求，满足了，然后需求还大于供给，你就获得了一定阶段内的定价权，可以赚到一笔钱。你可以通过一些小技巧，为自己争取多一点赚钱的时间，再去发现下一个不对称的领域。聪萌的人就是迅速抓到不对称，赚一拨再下一拨再下一拨。
+   4、投资人是不可能不着急赚钱的。风险投资都是有期限的，五年加两年，七年加两年，他一定要在这段时间之内要退出的。所以你一旦拿到投资人的钱，你就要开始按照投资人的逻辑去履行，就不能慢跑，你得忘掉慢跑这件事情。他必须要在轮一轮一轮拿到下面的钱，可能就会有一小点点，等到你下一轮，或者说不定上市以后再说，但是大部分就退出了。他不可能跟你同心同德，也肯定不会陪你玩一辈子的。

今天的课让我想到了一点，也是在《人类简史》里读到的，说为什么人比猴子、比猩猩、比老虎厉害？不是因为我们力气大，体力好，而是因为我们能够在一起协作，一个人的力量小，但是十个，一百个，一千个在一起的力量，智慧和创造力就是无限的。

但为什么猴子，猩猩，老虎不具备这样大规模协作的能力？因为他们不会讲故事，不会在一个共同的想象上协同工作。故事的核心是什么呢，就是 something big than myself，就是意义。所以一个会讲故事的人或者公司，就比只会下命令的人和公司有更强的协同他人进行合作的能力，自然，这样的人或者公司在竞争中的赢面就更大。

懒～慢～静而生慧，勤～快～醒而生威。古人讲禅定，静思，在安静缓慢的情景下，更容易思考，进而产生智慧。

懒蚂蚁，看着懒，只是工作形式不同！有些人看着勤快，但是思想懒。有些人看着懒，但是思想勤快。所以在公司发展中，领导者要有双慧眼识英才。不能只通过懒或者勤判断一个人的好坏，多维度的观察。识人，本身也是考验领导的水平。

+   1、公司制度涉及各个方面，所以在制度完善过程中，要有侧重点逐步推出，否则太多企业员工也会因为消化不良导致集体抵制；
2、化繁为简，制度要简洁明了，不要写成叙述文，让员工自己去理解就会产生一千个哈姆雷特；
3、推陈出新，很多制度都需要有一段推行期去发现制度推行中的问题，当然在制度整个运行期间，都需要发现问题，分析问题，解决问题，不断修改完善制度，PDCA（计划－执行－检查－纠正）循环完善。

在授权之前，也可以与第88课的“情境管理”结合起来一起思考。同一个员工，面对同一项任务，因为意愿与能力的强弱不同，就有四种情境。而不同的员工，也会因为处在D1～D4的不同阶段，无法直接授权。比如，公司中有成功经验的老员工，面临新项目或是新任任务时，也会出现意愿与能力强弱的问题。所以，也不能因为他是老员工或已经有过成功经验，就认为新任务或新项目也会没有问题，就直接授权。应该先协助他，等到其对新项目熟悉之后，再逐步授权。另外，对于新进员工，也可以采取循序渐进的方式进行培养，由S1:指示，到S2:教练，再到S3:支持，最后才是S4:授权。所以才说，管理是套组合拳。如何运用，存乎一心。

我对待员工的犯错，一般是看情况，也要针对不同性格的人，有的人能接受私 人场合的批评，有的人必须在大众场合批评那么一次，以上两种都慎用。后一种只有在屡教不改，你放弃他和他也放弃自己的情况下，又能警示他人时才用，即便这样，事后还需找他聊。

一般情况下，真诚建议的方式非常有效，一是站在当事人的角度，用多年的经验鼓励他；二是先肯定对方观点，但用事实证明对方行为并非如此；三是不用苛责语气，委婉而非责难。最后也是最好用的方法，自我批评找到自己的领导责任，和对方共同解决或善后。牢牢记住《了不起的盖茨比》中所说，每当你觉得想要批评什么人的时候，你切要记着，这个世界上的 人并非都具备你 tools 的条件。
