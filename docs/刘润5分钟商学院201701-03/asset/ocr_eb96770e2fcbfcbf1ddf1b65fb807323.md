# 刘润

作为管理者，你觉得你晋升到今天的职位，是因为表现优异而被奖励的，还是因为能力匹配而被授予的？作为员工，你觉得你公司里，管理者的能力，配得上他们的职位吗？来和我一起过过招吧。

4.22号，我将在深圳举办“第二季度管理篇线下大课”，让大家有更加深入学习，面对面过招的机会。如果说“商业”是讲如何对外，“管理”就是讲如何持家，两者缺一不可。我相信，很多学员在这一季度的学习中，已经深刻感受到了“不当家不知柴米油盐贵”，原来CEO真不好做，举手投足皆学问。所以，我打算在管理篇的大课中，分享这四个方面的逻辑：

第一，企业生命周期。这个世界上有所之四海而皆准的管理方法论吗？这世界上能帮助企业基业长青的战略和组织吗？为什么管仲，陶朱公的企业，没有活到今天？企业的发展有三个阶段：创业期，成熟期，转型期。我将在这个部分，帮助大家定位自己的阶段，并寻找合适的管理方法。

# 帮助大家定位自己的阶段，并寻找合适的管理方法。

第二，创业期管理。为什么小米说没有KPI，罗辑思维说没有组织架构，很多创业者甚至说他们痛恨管理？创业期的企业真的不需要管理吗？那他们需要什么？创业者成功，到底是靠努力，还是靠运气？我会在这一部分与大家分享，创业期企业的成功特征。

# 企业真的不需要管理吗？那他们需要什么？

第三，成熟期管理。企业越来越大，这到底是好事还是坏事？哪些创业期要的聪明、抖的机灵，必须被修炼弃？游击队如何变成正规军，狩猎如何变成农耕？战略必须流程化吗，流程必须工具化吗？我会在这一部分与大家分享，参天大树，和破土幼苗，到底不同在哪里。

# 游击队如何变成正规军，狩猎如何变成农耕？

第四，转型期管理。没有成功的企业，只有时代的企业。这就像人一样，死因各不相同，但死是必然的。健康长寿，不代表永生；医疗先进，不代表免死。那应该怎么办？我会在这一部分与大家分享，真正的转型，重获新生，到底怎么做。
