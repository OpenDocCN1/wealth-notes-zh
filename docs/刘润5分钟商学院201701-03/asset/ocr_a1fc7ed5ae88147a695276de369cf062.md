# 王鑫 2

+   1.个人更倾向"联邦分制制"，原因有三：
①联邦分制制首先明确了一个总路线和总目标（比如让公民安居乐业和组织的销售目标），前面的课程曾说过，"上下同欲者胜"，结合相应的激励手段，让个人目标和组织目标相统一，更容易做好组织建设。
②俗话说"船小好调头"，联邦分制制，把大的组织架构划分大若干小独立的小组织，在不违背组织原则和目标的前提下，每个小组向游击队一样，独立作战，充分发挥自主性，能更好的应对市场的快节奏。
③低头做事也要抬头看天，以结果为导向，让组织成员有目标感（即使生产部门，也有目标，比如提高生产效率，提高成品率等等），更有利于养成围绕目标配置资源的"战略思维"，而不是"应激反应"。
2.结合上一期《责权利心法》，分权的同事，也要建立对权力的监督机制，让权力和责任对等，让权力围绕组织目标所用。避免"联邦"各个"州"的掌权者自我膨胀，否则，分权就不是放权和授权，而变成了弃权。

# 温华阳 2

确实如老师所说，像流水线生产工人，属于技能型的岗位，工人的技能再熟练，8小时创造的价值也是有限的，更重要的是对行为的控制，是否有严格按照流程要求操作，简单讲就是听话照做，一切行动听指挥，这种岗位对人的能力要求并不高，适合采用职能分制制；而像销售等能力型的岗位，同样8小时，能力越强创造的价值越高，如果对行为加以控制反而会阻碍能力的发挥，所以销售岗位一般是采取目标激励法，采用联邦分制制。

# 云淡天山 1

思考笔记：这节课的概念虽然是分权机制，但是在我理解是分责机制，也就是目标与责任的不同分解方式。联邦分制制是把量化的目标直接按数量进行划分，而职能分制制是把实现目标所需的工作按性质进行划分。也即联邦分制制是对what的划分，而职能分制制是对how的划分。但正如院长所讲，这两者是无法绝对分开的，联邦制下再小的联邦内都需要划分职能，而职能制下的所有职能结合到一起自然也就构成了联邦。所以无论哪种划分，关键是需要有人将how与what建立起联系并为此负责，而这个人就是联邦的领导者。
