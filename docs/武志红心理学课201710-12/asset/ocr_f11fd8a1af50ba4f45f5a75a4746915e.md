# 动力16 | 无处不在的性

我们这一周的主题是“性”，今天是第二讲“无处不在的性”。

性是无比复杂的话题，在我的理解中，性包含着一切人性。美国心理学家罗伯特·斯滕伯格认为爱情由三个基本成分组成：激情、亲密和承诺。

> 美国心理学家罗伯特·斯滕伯格（Robert Sternberg）认为爱情由三个基本成分组成：激情（passion）、亲密（intimacy）和承诺（commitment）。完整爱情=亲密+激情+承诺，这是“爱情三角理论”。

+   激情：主要是欲望和需要的表达方式，多指肉体的渴求和欲望；
亲密：指的是亲密关系中所呈现的双方亲近、认同或者是分担彼此的感觉，与爱人心灵之间的敞开心扉、互相依赖，对爱人的尊重和体现以及对愿意与对方分享等都是亲密元素的体现；
承诺：由短期承诺和长期承诺组成。长期承诺指的是决定爱某一个人，而长期承诺谁则是决定要为一个彼此的关系负责，一起面向未来、愿意牺牲、奉献、经营爱。

但我认为，性绝不是只有这几部分，性方式的复杂程度超出一般人想象。我认为可以说是个。性中有教育，有创造有潜能，是与生死的交汇。性好像就是全能是自恋，因为性总是发生在关系中，即便思想，也都会在一个想象中的关系。

我讲的一个解梦自我性梦的技巧：不管什么样的梦，都暗含性和攻击的巧妙之吸引。我的这个小技巧，直接来自于弗洛伊德的理论，他认为性和攻击性是人类一切行为的两大动力。当然，我可以凭我的心理学知识和多年的咨询经验，建议你不要随意用这个方法解释自己和朋友周围的人，需要的话，在专业人员的协助下进行，才能全面、合理。

可我们意识上又觉得可能有点儿不对，人的行为为和道德不是真善美吗？这个矛盾，就是意识和潜意识层面的矛盾。意识层面，我们会把人行为，特别是自己的行为，朝着好的理想化的方向上解释；而潜意识层面，会直接地赤裸裸地原形人性。

有一次，我乘坐出国游轮，在游轮上给游客讲课，其中谈到了梦。后来一位游客找到我说，他昨夜刚做了个梦，请我帮他解梦。这位游客梦见他实现一个其实已经三四十岁的儿子，梦里才几岁，在家里，和一个女孩亲亲举动，他看见后大怒，上去把儿子一顿臭揍。

这位游客讲完梦后，我直接问他：昨天你是不是感受到性欲？他赶忙说，怎么会，你我都已六十多岁了，平时根本都感觉不到自己的性欲望了。我给他做了些解释：梦中青春期的儿子，代表着有性欲的本我，而父亲，代表着道德的我超我，父亲痛打了儿子一顿，意思是道德起来打了我一顿，所以可以推论，昨天你有稳定性能量被唤起，但被你给压制住了。

听我是这么说之后，他若有所思，说会不是我因为游轮上有许多姑娘国处，没有一个太漂亮了，我想给她拍照，但没说出口。

这里很有意思的事，在意识层面，他只想给女孩拍照，然后不好意思，没说出口；潜意识层面，他梦少年性，性能量被唤起，他本能地一顿揍，欲盖弥去头了。此外我认为，拍照是男人拿着镜头对着女性看，这里有十足的性含义在其中。

所以，我认为首先要有个认识：性，无处不在。尽管弗洛依德的解梦仍然有争议，但关于“性”的性在梦中，可以解释梦有一个更具体的认识：梦中一切直立的东西，都是男性生殖器的象征；一切容器，都是女性生殖器官的象征。甚至我觉得，不只是潜意识，人类社会到处可以见到这一切象征。

+   1. 各种各样精美的水龙头，它们的形状与男性生殖器官有关；
2. 高尔夫球，通常也是男人乐此不疲，他们聚精会神，就为了要把一个小球弄到洞里去；
3. 恐怖片《异形》，异形的形象和行性，专门模仿了人类性行为；
4. 诺兰的《蝙蝠侠》三部曲中，哥谭市中，矗立着罪恶大厦的超级大厦，也隐含着男性生殖器的象征；
5. 女人这么爱吃包，也可以解释为，她们这是在拿着各种漂亮的东西包涵诱惑男人，在男人眼里，她们有多么漂亮的生殖器官；
6. 恋爱中，男人给我女人送花，这行为也是在传递着性相关的含义，因为花就是植物的生殖器官；
7. 看了之后你可能会受不了了，觉得这些解释太牵强了，我最初学习精神分析的时候也是这么觉得。但后来随着对个梦和对自己的深刻认识，我越来越发现，性的隐愈无处不在。

关于弗洛伊德的性论，在心理学领域中有很多大学者表示不坚持，例如荣格，他反对弗洛伊德的性的决定，反对过分强调早期经验对人类发展的决定作用。但我个人对于泛性论还是接受的，因为它在我的临床经验中被证实。
