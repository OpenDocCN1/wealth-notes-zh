# 问答：先试试表达攻击性

武志红

这是我们每周固定的问答时间，我来回答一些用户的提问。

同一周谈攻击性，从留言中可以看出很多人感到不安，有些提问题说得已经在文章中解答过，但似乎还是要问些问题背后的意思，我就理解了你心里的那份不安。

我的助手Ammy看了大家的留言后发现，还是有很多用户在问自己何如表达、释放自己的攻击性，较多人在问什么是攻击性，也有人回答关于抱紧的问题，也有较多提问如果拒绝别人的攻击是否会让我被人唾弃，还是让别人害怕我脱敏？

对于这些问题，我想对你们说，也许你太少了展现你的攻击性了，也许你太压抑了，所以我想先讲关于如何安全和温和地表达攻击性。这个无害，包括不伤害自己，最后在动作中来表达一些攻击性。

但我得让你也许需要先试试，在一些安全的场合去表达攻击性，从体验的角度来看看看到底是怎么回事。一旦你体验到了攻击性是怎么回事，头脑上的很多疑惑就可以化解了。

# — 本周问答 —

现实生活中，由于害怕破坏人际关系，大多数人不能去直面表达自己的怒。

一般采取迂回或迂回的方式，比如如何安全和无伤害地表达不满，才能既不伤害对方，也不伤害自己呢？

武志红

我提一个原则，多使用"我的感受是什么"这样的句式，而少用"你伤害了我"，如果说"我很愤怒"，那就意味着在表达自己感受。而一旦说"你伤害了我"，就是指责性，是控诉。

当然无论多好的技巧，表达攻击性时，可能难免会给对方带来伤害。这时候要看这个关系是否能承受，甚至化破坏性到开释，一旦关系中有一方能很好地做到承受并释开，那么两个人会因为攻击性而更加亲近。

什么是攻击性？哪些表现可以视为攻击性行为呢？

武志红

举个列子：我对"你"很愤怒，这就是表达攻击性。如果你打了，这就是破坏性。

我实实在在地想去破坏别人的利益，这也变成了破坏性。

为什么我觉得我需要表达攻击性？母亲或客观体让你得以生存）的感觉？而是"母亲或客观体得以生存"的感觉？是我真的知道被吗？

武志红

"母亲客观体得以生存"，里面有两个含义，一是母亲客观体被"杀"，另一个是你母亲客观体被"杀"。这两个复合词，因此被称为是"杀"，两个含义中有一个共同点，即攻击性就是死亡的力量。

实际上攻击性的发展需要两个阶段：先是表达攻击性，而开始担心破坏性而破坏；接着当到了爱的阶段，当你不再担心自己会被惩罚，也不担心会伤害所爱的人，攻击性就完整地转化成了生命力。

有没有这种可能：我们通过电影、游戏和体育等娱乐节目释放了过多的攻击性？所以花的零钱很多时候是治疗的费用？

武志红

是的，这是非常好的理解。

没被驯顺的攻击性，不能被压抑的。单纯压抑、得不到光的攻击性，会合成为"恶灵"，一旦压抑不住，开始做恶，与压恶的，那是恶灵大闹，不是恶灵"，人们可以通过观看有攻击性的影视、玩有攻击性的游戏，以此来释放心中的"恶灵"。

所以，这一切都是治疗。单纯压制恶灵能量的表达，不能真正正负平衡。

父母接受不了攻击性怎么办？家里吵架，夫妻可能会叫上其他人帮忙

武志红

我给你的建议，不要攻击接受不了的人，也不要被攻击。

现在感受很慢，如果表达了攻击性，只会令关系受伤，会带来伤害，那当然要控制攻击性。你可以采取别的方式，比如找资深的咨询师，他们受过大量训练，更加知道如何转化攻击性。

有没有可能因为对A愤怒，而把这份愤怒发泄给B，然后对A的怒就随之消失？

武志红

我觉得不可能，这只是嫁祸行为，通常是不敢对A表达，而转怒到B，自己已经对A表达了愤怒，但对A的B的愤怒没有真正消失，同时又破坏了B的关系。

一个自身少发了攻击性，是否就是把自内心伤害的能量的状态？不向别人展示攻击性也不接纳别人的攻击性，就意味这个人就是孤的，也是交不到真正的朋友？

武志红

我认为是这样的。

我相信每个人都有身边都有人的例子，那些"好"人，人缘好，没有什么朋友。

因为攻击性是生命力，如果压抑了攻击性，就意味着放弃了生命力，既得不到自己的能量，也接受不到别人的能量，于是，也没有真正的独立关系。

实际上，太阳的人，常常在自己的内在想象和外在现实中，都建立起了一个不可侵犯的自己，另一方面是为了防止别人侵犯自己，另一方面是为了防止自己内心中的那个全能自足的"想象"攻击外部世界。

如果用爱去接受同事的攻击性，会不会让人觉得你太好欺负了会更加加重同事的攻击性？如果会加重的话，那些就应该有意识的不用爱去包容对方，是这样吗？

武志红

如果真的是用爱接受同事的攻击性，那放心，一定会有好结果。但我们常常不是用爱，是用软弱、胆小、害怕，不敢用攻击回去应对，而担心被报复或歧视。

我们太多次了，把软弱当成了爱，而事实上，爱，是需要权力的。并且，之前的内心冲突，也是通过权力表现和珍惜的。以工作为领地的社会领域，其本质规则就是权力，在社会会表现出珍惜规则，常常容易让事情糟在一起。

提这样问题的朋友，建议阅读陈天老师的经典《关系破壁》，讲的主要就是"理解社会生存法则"。
