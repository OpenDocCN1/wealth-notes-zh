# ### 心理健康的标准

在这一个章节中，我们讲述了心理健康关于全能力量的标准。

全能力量的标准包括：1. 能够感知和表达自我；2. 能够建立和维持客体关系；3. 能够进行自我调节。

当自体和客体的关系是和谐的，当自体和动力是和谐的，这就是心理健康。

如果自体和客体的关系是敌对性的，这就是心理健康问题。

在讲这两种能力中，我提到了一个核心概念：动力。

动力是一个能量的方向，它指向客体。

如果把动力从客体身上移开，投射到自己身上，这就是自恋。

如果把动力指向客体，这就是爱或者恨。

如果自恋是真实的，这就是成熟自恋。

如果自恋是虚假的，这就是全能自恋。

自恋、动力和客体永远都是绑在一起的，所以寻找动力的过程，也是在寻找自体的过程。
