# 问答：性的模式，是关系模式的呈现

问答：性的模式，是关系模…

武志红

今天是每周三固定的问答时间，我来回答一下一些用户的问题。

我们周三的文章题目是《性是对关系的渴望》，这句话可以引伸到每一句话：性的模式，是关系模式的呈现。也就是说的各种关系，常常是一个人内心深处的关系模式的呈现。

例如，如果一个人心中有饱满的爱，那么他会想构建新的，也去有亲密感，比如会有充分的亲爱，就会去很想去塑造一些美好感觉。

如果一个人内心充满攻击性，这既可能是一时之内的，也有可能这个人表面上是好人，可心里却存着浓烈的愤怒，这种人就容易出现各种攻击、伤害。

有人在模式中很有权力，是在思想中重复这一模式，要控制对方，但在很多人权意识中，比如要控制“男女”自己，可能是因为他们想体验失去权力的无助感。

可以追溯到，一个人的俄狄浦斯系结问题上，那么追溯原因则会有很清晰的结果，很多心理学家都发现，俄狄浦斯系的俄狄浦斯情结得到了我们关注，我们看到很多精神分析咨询中，有个人认为自己的需求去表达他的性，有多少问题可以归回俄狄浦斯情结中，解到这一个情结之后，很多关于恋性的生活难题都能迎刃而解。

很多人倾向于把性视为生物学的范畴，那样的话看似看上去可以很简单，但实际上，性太复杂了，因为性关系是一个人的内在关系模式的投射。

# 本周五问答

回避型人格障碍怎么能治疗好？

武志红

我认为是，回避型人格障碍在成长过程中有两个关键：

第一，努力去建立更为丰富的关系。这个过程中，他会有些不舒服，因为在人际关系中，他们可能有严重的被伤害感，这个会很大改变。这个过程中，时间可以起的很大的作用，只要持续地愿意去做，有极大的可能把关系的模式深度上。

当然，找一位咨询师协助去建立关系，这相对容易，但这也需要很长的时间，可能需要2-3年，甚至更多。

第二，极为关键是，认识到自己内心中那个充满生命能量和自己的意愿的关系。回避型人格想要去，自己会和自己想象中的世界之间有着一道，这道厚厚的墙有两个功能：既防御外界的威胁，也让自己内心与自己的能量相隔离的感觉。防止自己和外界发生关系。

这两者相辅相成，认识到自己后，就知道自己可以什么关系了，然后就可以让这些人的内在能量在阳光中，在真实的关系中，被看见、被触碰，进而转化为生命力。

有很多自我封闭的人都渴望关系的重要，希望关系，想要被呵护、想去依赖，但是想“鼓起勇气”走出去又显得“鼓起勇气”很难。小说中，人们总是“鼓起勇气”去做那回事，怎样才能“鼓起勇气”走出去呢？

武志红

有时候，这需要找到一个更好的关系，一个接纳你的关系，甚至一个破坏性的关系，都可以帮你打破这一模式。

有时候，是因为这股勇气的气还不够，比如，在亲密关系中，第一次亲密关系帮助了自己，只有一些人会说他们自己，愿意去尝试，挑战种种不舒服，愿意投入关系中去，但关系中的对方，痛苦太大，然后你激发了自己关于亲密和改变自己的强大动力。
