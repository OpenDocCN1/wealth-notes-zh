# 身修03｜如何用身体来聆听

身修03｜如何用身体来聆听

武文江

我们这一周的主题是“身体是心灵的镜子”，今天是第三讲，“如何用身体来聆听”。

我先来分享一个故事，还是我2007年刚开始咨询师的故事。我的这位来访者是一位咨询过的女士，她结婚没多久，和老公、妈妈的关系都有问题，而她自己也非常焦虑。

第一次咨询时，她对我说：武老师，我很我爸，然后讲了因为什么我爸爸，原来她的父母在她三岁时候离婚，她跟着妈妈，从那时起就再也没有过爸爸。妈妈说爸爸是个很花心的男人，但实际上妈妈并不允许女儿想念爸爸。不仅如此，她妈妈一再告诉她，爸爸是一个重男轻女的父亲，我们之所以离婚，就是因为生的是个女孩。

咨询快结束时，这位来访者说：武老师有些奇怪，和我以前见过的两位咨询师不一样，他们认识我的爸爸，我也想让我的爸爸，问我爸爸很生气，他们也会让我把这份恨表达出来，而你并没有这样做。

我解释说，第一，我们第一次咨询，我主要是想了解情况，不太会引导幼儿做；第二，在没有恨的前提下，会不会让她更感增强了，可好像她一点都感受不到。

第三次咨询，还剩下不到十分钟，这位来访者回忆起五岁时的一件事情，当时她父亲写给她的信，写了一封信。可这么小的小女儿怎么来给父亲写信呢？信里说：爸爸您在哪？几个字，再加上一个心形和一张邮票放在桌子上，想着妈妈把这封信送再寄出去。

然而，等她回到家后看到这封信，非常生气，疯了一样打了一顿她。从此以后，她对父亲就只恨没有爱了。

她说得小学和初中时，有一个男人到她所在的学校等她，还说想和她说话。她都没有理他，但她知道，那就是她的父亲。她说起这些的时候，语速很快，一下子就讲完了。

讲她用慢一点的速度，再重新讲一遍。结尾，她慢语速，她语不成声，最后哽咽着说：“爸爸，我爱你，我想你。”

给她做咨询时，我会有点头疼，她痛哭时，我发现头疼结束了。我原以为她的头痛在结束的时候，是感受到了爱的感觉，于是我问她：你现在还在头痛吗？她一直对我说：你描述的疼痛会持续很长一段时间，有时候会非常严重，但的确在痛哭后有所缓解。

可是，她仍然有严重的焦虑，她和丈夫的母女关系还是处得不好，咨询了两次后，我就将她介绍给更成熟的咨询师。

转介（Referral）指的心理心理咨询师根据来访者的需要，协助来访者转介到其他服务的过程。在心理咨询范畴内，转介一般发生在以下两种情形中：

+   1) 咨询师初步评估来访者的情况后，认为自己的服务与专长无法满足来访者现有有效的服务，但将完全转介给其他比较合适的咨询师；当来访者求助的困扰可能需要精神科辅助解决时，可以在征得来访者同意的前提下转介给相关人士；

+   2) 在咨询关系建立之后，由于咨询师或者来访者的某种原因，需要终止咨询关系，为来访者寻找一位新的咨询师。

后来我回顾这个案例，分析这位来访者头痛时，我的猜想是：

+   1. 她的这个想法使我爸爸爸，是错的。这就是她“这办法头痛的来源。

+   2. “我很我爸爸爸”这个想法是妈妈通过这次事件，生生植入到她头脑中的另一种感受，这是一种入侵，就好像头脑侵入的感觉，我得出头痛就是可能为别人的意志强行入侵到头脑中时，并扎下来了。

我觉得这位来访者的案例值得研究，另一件事一样值得关注：我的身体为什么能感受到她的感受？这件事如何做到？实际上，对很多人这样的能力。

在《思维04｜高贵的头脑，世俗的身体》中，我讲了一个有趣而聪明别人歇着故事的不出书。很多人事情着说得，讲故事的不出声，听故事的人想着说得，那么是能判断一个人讲的故事是开心的还是悲伤的呢？

但做了练习之后，大多数人，特别是女性能够意识到这真的不难。因为自己的身体会推送到对方的身体感受，自己的情绪会和对方的情绪共鸣，所以可以根据这些信息去做判断。

可以说，心灵的三种过程中，我们的思维过程可以通过语言文字去沟通，身体过程和情绪过程也可以在身体层面、情绪层面去沟通，只是，大多数人会忽略思维、语言和文字中，认为这是唯一有效的沟通方式。一旦你放弃可以在情感和思维层面去回应对方，你就可能不再去练习这些方式，于是变得越来越敏感。
