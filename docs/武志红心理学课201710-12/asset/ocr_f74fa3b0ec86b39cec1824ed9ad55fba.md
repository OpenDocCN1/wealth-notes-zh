# 自恋幻觉的ABC

投射性认同是一种孤独的游戏，沉浸在这种游戏的人，会在一般人关系构建上遇到密关系。但他们亲密关系中看不到对方的真实存在，只关注对方是否如自己所愿，按照自己所期望的方式对待自己。

投射性认同的游戏中藏着这样一个公式：“你必须如此，否则……”。这是一种威胁性信息，完整的表述是：“我以好的方式对你，你也必须以一种特定的好的方式对我，否则你就不是爱我的人。”

“我对你好，你必须对我好”这个公式的前半句，就是“我对你好，你也该对我好”。后半句是“否则你就不是爱我的人”，这部分比较隐蔽。投射性认同的A方，会清晰地感受到这种威胁，但没有意识到自己发出的威胁信息。B作为被投射的一方，就会清晰地感受到这种威胁，但没有意识到自己发出的威胁信息。

我们把投射性认同称为自恋幻觉的ABC，A、B、C分别代表着A方、B方和C方。比如A说：你必须对我好，否则我就让你死，这就是A的威胁性信息，这个威胁可能是威胁攻击对方，或者威胁伤害自己。B会接收到这个威胁性信息，并试图反抗或者讨好。C方则是那个隐形的第三方，通常就是A方的内在客体。

投射性认同，乃至其他各种自我防御机制，都是为处理其他自己关系中发生的“我对你好，你”这个角度，投射性认同的ABC可以是“对别人好，否则你就不是爱我的人”。A为投射性认同的发起者，B为接受者，C为第三方。

# 投射性认同的四种类型

虽然投射性认同是比较低功能自我的自恋防御机制，但投射性认同的游戏并不罕见，它有以下四种类型：

+   1. 控制性投射性认同，内在逻辑是：我必须控制你，否则你就不是我的人。
2. 依赖的投射性认同，内在逻辑是：我如此爱你，你不可以离开我。
3. 毁灭性投射性认同，内在逻辑是：既然我毁了你，你就必须毁了我，否则你就不是爱我的。
4. 补偿性投射性认同，内在逻辑是：我这么受伤，你必须永远补偿我。

第一种控制性的投射性认同和第二种依赖的投射性认同同样以自我中心。第一种投射性认同表达的含义是我很有魅力，你很喜欢我，所以你必须听我的，否则你就不是爱我的人。第二种投射性认同表达的含义是我没有别人，你不可以离开我，否则你就不是我的人。
如果一个人长期沉浸于第一种的投射性认同，可能会表现出攻击性很强的行为，如果一个人长期沉浸于第二种的投射性认同，可能会表现出非常依赖甚至偏执的行为。

我来讲一个关于依赖的故事，有一个女性来访者，她的家庭非常不幸，父母离婚早，父亲在她很小的时候就去世了，母亲改嫁后对她不闻不问。

一开始，她遇到很多烂人，因为依赖别人而失去自我。但有一次，她遇到一个很好的男人，这个男人开始的时候很爱她，后来男人发现她自己根本不能面对自己，只要关系一深入，她就会开始攻击、指责、哭闹。

她也觉得自己的依赖有问题，但她的潜意识里知道，只有依赖别人才能生存。于是她对男人说：“你不能离开我，否则我就会死。”男人说：“我离开你，你也会死，但我也会死。”她说：“那我们一起死吧。”
