# 动力02|自信与热情

武志红

我们这一讲的主题是“心理健康的标准”，今天是第二讲“自信与热情”。

这是美国心理学家科胡特的一个标准，他认为心理健康就是“自信+热情”。这么简单，但什么是自信，什么是热情呢？仔细解释的话，也有一些复杂。

我们第二讲的主题是“自我”，第三讲的主题是“关系”，这一章的主题是“动力”。这里面隐含的一个设计是：自我 = 关系 + 动力。

自信 = 关系 + 动力

一个人的自我，涉及到两方面，一方面是关系，另一方面是动力。

所谓“关系”，就是我和你；所谓“动力”，就是我和你之间能量的来往。如果你还记得小学语言的知识，也许会发现，这正是英语的动词结构“主谓宾”。比如“I’m”就是“我”是宾语，而“am”和“is”就是谓语动词，而名词“主语”（比如“I”）是主语。

我还可以说“自我”、“客体”和“关系”。比如“自我”、“客体”和“关系”（Self, Object, and Relation）——这就是关系型动力学的核心结构。

讲清楚了这些之后，我们开始讲自信。

什么是自信？

自信，是内在能量。

那么，什么是自信+热情？

首先，我们来理解一下这个“自信”（Self）。

自我，包括“主我”（I）和“客我”（Me）。

“主我”（I）是你，“客我”（Me）是别人眼中的你。

自我，是一个人对自己身体的感知和描述。

比如，你的身高、体重、性别、年龄，这些是客观事实。

但你对这些客观事实的主观感受，构成了你的自我概念。

比如，你可能觉得自己很瘦，也可能觉得自己很胖，即使你的体重是一样的。

这种主观感受，就是自我概念的一部分。

科胡特认为，自我是由“自体客体”（Self-object）发展而来的。

什么是自体客体？

自体客体，不是客体，而是你的自我与客体之间的桥梁。

比如，一个婴儿在妈妈怀里感到安全，妈妈就是他的自体客体。

妈妈让他感到被爱、被照顾，这种体验塑造了他的自我。

如果妈妈能给予婴儿足够的镜映（mirroring），婴儿就能发展出健康的自我。

什么是镜映？

镜映，就是像镜子一样反射出婴儿的自我。

当婴儿表达快乐时，妈妈也表现出快乐，这就是镜映。

这种体验，让婴儿感受到“我是好的，我是有能力的”。

这就是自信的来源。

如果妈妈不能给予足够的镜映，或者经常忽视婴儿的感受，婴儿的自我就会受损。

这种受损的自我，会导致自尊低下，甚至自恋。

除了镜映，还有一种重要的自体客体体验，叫做“理想化”（Idealization）。

什么是理想化？

理想化，就是婴儿把妈妈（或照顾者）看作完美、强大的存在。

当婴儿感到害怕或无助时，他会向妈妈寻求保护和力量。

妈妈的存在，让婴儿感到自己是强大的、安全的。

这种体验，也塑造了婴儿的自我，让他感到自己是有能力的、有价值的。

如果妈妈不能提供这种理想化体验，或者经常让婴儿感到失望，婴儿的自我也会受损。

除了镜映和理想化，还有一种自体客体体验，叫做“孪生感”（Twinship）。

什么是孪生感？

孪生感，就是婴儿感到自己和妈妈（或照顾者）是相似的、一样的。

这种体验，让婴儿感到“我和你是一样的”，从而获得一种归属感。

如果妈妈不能提供这种孪生感体验，或者经常让婴儿感到被排斥，婴儿的自我也会受损。

总结一下，科胡特认为，自我是通过与自体客体的互动发展而来的。

自体客体，包括镜映、理想化和孪生感三种体验。

这三种体验，共同塑造了我们的自我，让我们感到自己是完整的、有价值的。

这就是自信的来源。

如果这三种体验缺失或受损，我们的自我就会出现问题，表现为自尊低下、自恋、甚至抑郁症。

那么，什么是热情？

热情，就是动力。

科胡特认为，热情是生命力的体现，是让我们行动起来的内在动力。

这种动力，来自于我们的自我（Self）和客体（Object）之间的互动。

如果这种互动是健康的，我们的热情就是稳定的、持续的。

如果这种互动是受损的，我们的热情就会是波动的、易碎的。

比如，一个有自恋倾向的人，他的热情往往依赖于外界的认可。

一旦外界给予认可，他就充满热情；一旦外界否定，他就陷入抑郁。

这就是热情不稳定的表现。

所以，科胡特认为，心理健康的标准，就是“自信+热情”。

自信，是内在的稳定感；热情，是内在的动力。

这两者缺一不可。

没有自信，热情就没有基础；没有热情，自信就没有活力。

这就是科胡特关于心理健康的定义。
