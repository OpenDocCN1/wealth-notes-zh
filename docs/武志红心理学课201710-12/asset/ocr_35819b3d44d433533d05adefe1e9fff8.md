# 复盘：关于“思维”主题的回顾

我们的专栏已经讲述了“命运”、“自我”、“关系”、“动力”和“思维”这五个大的主题。“今天我来对“思维”这个主题进行一个复盘。

道生一，一生二，二生三，三生万物。《道德经》中的这句话，被拿来当做我们专栏的一个隐藏密码。我道是“命运”，一是“自我”，二是“关系”和“动力”，三是则“思维”、“身体”和“情感”。

“命运”主题让我们看到了“自态”在发挥巨大作用，由此引出了“自态”主题，自态有关系和动力两部分内容，由此引出了“关系”和“动力”这两个主题，而身体情感就是三个层面去考察，由此引出了这个大主题，也是因为我们熟悉的“身、心、灵”这个分类，只是“灵”变成了“情感”。在我看来，情感这件事，确的也是灵性、灵魂存在的一种证明。

“思维”这一主题下的文章，阅读的数据没有以往高，也许是因为我的文章吸引力不够，也可能是因为我对思维了解不深，但更可能是因为思维的固有性。

如果你只是在思维原里去做点诠释，你会发现这份诠释为总块去一点点似的。我也看到一些心理学同行，在写文章的时候，特喜欢用专业词汇和术语来下很大的功夫，写作显得非常高深。我深有同感，但却难以继续，读着也很容易记。但相反，如果你善于讲故事，就会不一样。

一直以来，我对弗洛伊德这位精神分析的祖师爷产生过特别大的崇敬，实际上我对心理学家们整体都是这种态度。我更容易佩服小说家、诗人、画家、舞蹈家等。

我很早就注意到自己这个倾向，所以我应该如何使用这个优势，是可以朝这个方向去实现一些。小说家、诗人、画家和舞蹈家等，那种感性的表达和身体的使用，却是我所匮乏的。甚至我早觉得这些对我也更有影响。我想我的这种判断，应该也会对我文章有影响。

思维，当然是无以伦比重要的东西，希望以后我可以对它有更全面的认识，再来做个分享。

# —— 心灵的三层结构 ——

本周引用的“保护层、伤痛层和真我”这个心灵的三层结构，实际上是灵性学的一个分类，而不是学院派心理学的一个方法。

这三层结构中，特别要强调的是“伪伤层”，在最后几周介绍荣格荣格的托勒乌斯时，我们讲了他的一个概念“痛苦之身”。这两个概念结合在一起，就可以了解到在一些大的痛苦里，感受层面就等同于伤痛层上的。佛学在这一点上就更为严重，直接说活着就是受苦。

深入想想，这些说法蛮深刻的，如果我们能成，也许是我们常说的“心理障碍”，到底是个什么呢？

前不久我在想这个问题时，甚至有了一个感悟：实际上根本就没有“心理障碍”这回事，有的都是人性，所谓表达性，其实是人性的一种非常常规的表达方式而已。

因为有伤痛层的存在，所以人要构建一个心理防御体系，这就是保护层。保护层主要由原始机构，可以减轻伤痛的级别，这个减轻可以为极为夸张。用我的话来描述就是潜意识微微放放水，潜意识层面被淡忘我们。所必然的结果是，保护层减轻了我们的痛苦，同时也严重降低了我们的感知。

我们必须知道这一点后，当知道这一点后，就不会轻易把思维当做真相来认，思维并不这一同的思维都是直接指出的，思维并不高，而脆弱的身体则是更为可靠的存在。特别是我们引以为傲的想法，其实常常是很小的人。所以最好是把思维当一个工具，而不要把思维当做大事。

# —— 认识你的非理性信念 ——

这一周本是为思维做一点正名的，让我们看到思维的价值，但最终我们看到的是思维可以导致极劣的价值，也可以产生各种结果。

这周的基本逻辑是，事件A不是导致你的情绪C的原因，你内在的信念B才是根源。所以，每个人要为自己感受负责，这是理性情绪疗法的核ABC理论。认识到这个理论后，我们会形成一个重要的认识——我们的信念或想法，才是我们人生的根本。

如果我们像斯多葛哲学家爱比克泰德一样，持有理性的信念，那我们就很容易觉得理性且有尊严。如果我们持有非理性的信念，那就会很容易感到痛苦。

所谓理性，就是服从事物本身的规律；同时在有能力的时候就做出自己最好的选择；所谓非理性，就是无视事物本身的规律，而期待世界按照自己的意愿来运转。

这样看来，信念具有至高无上的地位，但《看见你的自动化思维》和《瑜伽》都能挖一口深井，这两篇文章中，用治疗案例来讲解，信念其实从对人生经历中产生的，才叫真正走到自己的信念是如何形成的，然后才能做出更好的选择。

# —— 破解你的生命逻辑 ——

生命逻辑是我自己特别喜欢的一说法，我认为每个人都在干一些“路径依赖”，基本只用一套真正在使用的路径逻辑活着，它会有效果，但也会束缚住我们。

这周我介绍了四种投射性认同：支配者、依者、造好和诱敌者。我们可以看到，这几类人是怎样使用一套固有的心理逻辑在另一身上同时试图对别人产生了逻辑，从而破坏关系。

只是我们同时需要看到，投射性认同的游戏，是为了建立关系。

一旦谈到关系，我们很容易想到“爱”，但真深入看关系，我们发现关系的一个根本作用，是处理“坏”。投射性认同的游戏，它的生命逻辑就是寻找“坏”的“坏”和关系的关系中，如果我们认可了，不用坏的方式对待他，那也证明了我的假设——别人不会用好的方式对待我。

如果真正明白，我们在关系中的一件根本目的，就是投射自己处理不了的人性的“坏”，那么，我们还有什么理由，对自己已经形成的生命逻辑特别自恋与执着呢？
