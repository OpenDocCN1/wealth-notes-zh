# 动力13 | 挑战舒适区

我们本周的主题是“继续生命的韧劲”，今天是第三讲“挑战舒适区”。

我们来讲播客，什么是“舒适区”。就是你身体内的一股能量，你一开始会因恐惧而变得虚弱，但你终于承受住并转化了它，你转化成了能量，你因此变得更强。

“杀不死你的，会使你更强大”

如使用“生命力”和“死亡量”这样的术语，就可以说，一股能量攻击了你，并唤醒了你体内的一股能量。一开始你被迫去抵抗，你体验到脆弱，担心它会伤害你直至杀死你，但你终于承受住并化解了它，你转化成了能量，你因此变得更强。

就像尼采所说的：杀不死你的，会使你更强大。

有一本很流行的书叫《反脆弱》，我看到[得到]APP 的多个专栏提到过“反脆弱”这个概念。它的基本意思是，脆弱是因为自己和不确定而蒙受损失，反脆弱则是让自己避免损失定，甚至因此获利。

比如人的身体，平时我们有一个习惯的舒适区，而高强度的运动或锻炼，会让身体感觉到不舒服，超出了这个舒适区。但肌肉和骨节会改造自己变得更适应。

就像我们做过的学习、习惯的舒适区也都要挑战一下，否则我们就一定程度的被“杀死”，或者换个词，被削弱。

我记得前不久有一个新闻，说一个年轻人和别人比赛踢足球，他赢了，但因为在用力过度，出现了肌肉溶解，后单抢救及，没有生命危险。我去搜索后发现，类似新闻有很多。

尼采的这句话“杀不死你的，会使你更强大”，也许听上去像是一句劝人的励志话，但真正意思就是：生命是一个过程，我们总是在不断地被杀死，又不断重新生长。不被杀死，只是你还没有被杀死。

# 心理舒适区

每个字都有一个概念叫“舒适区”，意思是每个人都有一个最舒适的状态，在这个状态下，你会觉得一切安好。所谓不安，就是感觉到了危险。

心理舒适区（comfort zone），从心理学的角度，舒适区是一个让你保持一种相对静止的状态，而舒适区则是这个心理上的舒适区的扩展。

简单地说，你的心理舒适区就是让你觉得舒适、安全的区域。而简单地说，你的心理舒适区就是你的习惯、你熟悉的，或者说让你觉得熟悉的一切。

有的人舒适区非常大，比如有些人非常内向，喜欢自己待着，不喜欢跟人打交道，不喜欢变化。他们的舒适区就非常大，可以容纳很多东西，比如喜欢读书，喜欢听音乐，喜欢看电影。

有的人舒适区非常小，比如有些人非常焦虑，总喜欢改变，总喜欢尝试新事物，总喜欢挑战自己。他们的舒适区非常小，一点点变化就会让他们不安。
