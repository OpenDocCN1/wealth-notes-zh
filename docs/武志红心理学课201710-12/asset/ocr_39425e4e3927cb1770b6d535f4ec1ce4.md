# 问答：从全能自恋到健康自恋

问答：从全能自恋到健康自恋

武志红

今天回答我们每周固定的问答时间，我会集中回复一些大家的问题。

我先来讲一下我自己的经历。有一次，在深度催眠中我觉得我的全能自恋被彻底唤起，我完全没有阻碍地出现了“一句话”：我就是“无所欲为”。这句话看起来可吓死别人了，我的身体感觉被彻底打碎了，但接下来的变化让我甚至觉得身体上很多小毛病都治愈了。比如我呼吸时，一直感觉我的两个鼻孔通气量不同，在鼻孔的通气量中我只占有鼻孔的三分之一，但这次之后我感觉我彻底通了。

我作为一个成年人，极大地体验到原来全能自恋是这样子的感受，这股能量在身体上安全流动一次，竟然带给了我好多好处，我会觉得当一个“相信世界接受自己本能能够满”的人，应该在心理上和身体上会有各种好处。

我的一个来访者，她妈妈对她女儿各种限制，不能玩水，不能光脚在家走路，跟她的女儿各种冲突，而她的妈妈离开的一段时间中，她放开手脚让女儿想玩水就玩水，想光脚走路就光脚走路，结果她女儿那一时间段什么病都没有了。我觉得这算是一个特别好的例子。

但是，作为成人，或者任何一个不是婴儿的孩子，都需要知道你不能要求别人配合你的全能感，世界不会按照你的意思来运转，这是最基本的现实检验能力，也是一切正常的人际交互的基础，如果没有这个，一个人就无法适应现实世界，而容易进入监狱、精神病院甚至是墓地。

所以，如何在全能自恋中“你”的一个独立性存在的同时，还能做到“我是”的能量涌出，这是确是一个大学问。

### 本周问答

成人的全能自恋是否能疗愈或者改善？在关系中是是通心理疏导师的辅导？如果在关系中其他人应该怎么做呢？

武志红

最严重的全能自恋和自性性暴怒，比较典型的，我之前讲过怡静处于心理发展的四个阶段，最后一个层次关心自己“神”的自恋妄想，和外界有一个系统的迫害者的被迫妄想，心里起来很极端，这个地步至少不是一个纯粹地自恋，而是必须精神病的范畴了。

如果一个全能自恋已经到有些人了基本现实检验力，那么这个人就有一定的自恋障碍，如果实在成年人有严重的全能自恋，而自己不自知，还认为别人必须按他的意思，否则就是侵犯，那无非就是精神病，能保持界限保持界限，可能就只能讲讲严重的法律了事。

我个人觉得是可以这么说，坐监狱、精神病院里和坟墓里，表达太多自恋性喜怒哀乐不知道的破坏者。

如果让孩子成长过程中一直满足他的全能性自恋不会太溺爱孩子吗？我们该何时停止满足孩子的自恋呢？

武志红

孩子能力越是越小，越需要别人照顾时，就照你意思，适当满足他的自恋，但是随着能力的上升，就该按另一个原则：他自己会好的，就自己去做大人，不会在会实现全能自恋的工具和对象。

实际上，我们能看到的小皇帝，常常是在婴儿期得到照顾不好，和长太早又过早放虎的，严里的虎总是长着养育者满足孩子的全能感，同时这也是一种投射，就是养育者心中住着一个渴望被放养的婴儿。

所以，赶不花想无限制满足孩子的父母，需要想办法观察自己在内的这个所谓的婴儿。
