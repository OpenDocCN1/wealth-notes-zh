# **思维101 支配者**

这一周的主题是“理解你的生命密码”。今天讲第三讲“支配者”。

昨天我们讲了投射性和讨好性的依赖游戏，今天我们讲和依赖游戏对应的权力游戏。

我再来帮你复习一下，依赖游戏的ABC具体逻辑是：我如此无助（A），你必须帮助我（B），否则就是不爱我，我们不如分手（C）。

权力游戏的具体逻辑则正好相反：我对你好（A），你必须听我的（B），否则就是不爱我，我们不如分手（C）。

玩权力游戏的人，他们在关系中追求支配的感觉，我们就把他们都成为支配者好了。

# **两种类型的支配者**

支配者大致可以分为两个类型：赤裸裸的支配者和善意的支配者。所谓的赤裸裸的支配者，他们甚至都不愿意用“我对你好”这个借口，而是直接表达“你必须听我的”。善意的支配者，在表达支配欲的时候，会使用“我是为了你好”这一借口。

不过，有些支配者既不是赤裸裸的，也是温情的，在某些人际关系中，他们也许会用上那温情的面纱，而是直接使用已经拥有的权力或权力资源，别人听不听话。而在另一些人关系中，他们会体会需要很多，在面对别人服从时，会随时传递“我是为了你好”的信号。

比如，有些人在工作中是一个赤裸裸的支配者，但面对亲人时会表现得很爱和和耐心，不管看的多美，他们一定会追求“你必须听我的”这个终极目的。有一次，我一位女性朋友咨询男朋友关系，突然聊到孩子的问题时她打住了，她语无伦次、风急，但说话很快孩子将满3周岁，他告诉我，她孩子可是一个电话不接打三个以上，为了让孩子你可是不遗余力。她笑了笑说，我知道我控制欲强，可很多事不控制不行啊。

这种故事太常见了，我们权力经典的故事。每当看见被支配者权力游戏时，很容易会想到这个经典的故事。故事的男主人公是一位商务精英，他在感情中是一个严重的依赖者，和她最爱的男人，自然就是强大的支配者。

他们在关系的时候，这个男人简直会安排好24小时中的每一分钟，充满了有趣的事情，也是想尽量帮忙取悦女友。特别适合一个出去旅行活动，这位朋友都交给这个男人处理，他会把安排得非常周到，充满乐趣。

但是，所有的关系都会出现问题，他们同居住后，两人闹了点小别扭。这位朋友使了小性子，收拾了一点自己东西，当他们从她那儿得知消息时，男友就全没有去哄她，她的朋友说这男友再回去地又回去了。她的男友对她讲，这种事不能发生第二次，发生了就分手。

这两位男友的另一种再次闹别扭，另一位给朋友关系之后，男友第一次，又一次给她东西回到自己家。男友还是没有哄她，等她滴溜溜又回来了包，已将他所所有的东西整理齐了。如果，然后他们就这么分手了，送这位朋友怎么挽留都无济于事。

她的这位男友是一个大公司的老板，管理着这么多人，无论公司里面，还是个人的感情中，他都试图将事情都控制在他的意志之下，为此他付出了可能是可贵的努力。这位朋友多次在半夜醒来时，男友独自在阳台上抽烟，但却是在梦游状态中。

他的这种极度控制，都是意识层面的东西，但是不可能都处在意识的控制下，潜意识中的冰山总会冒出来。正常情况下，我们都会通过绘画、艺术创作、电影体验来小途径释放潜意识，而这位朋友的潜意识能力太厉害了，所以他的潜意识能量，梦里的事就是这天发生。

极高、又有生命力的支配者，可能会发生这样的情况。比如两人谈恋爱，支配者会对依靠者说，你为什么总和我那么多异性交往，我吃醋，我生气，你不能减少和他的交往。

依靠者觉得这个请求有点合理，于是答应。接着，支配者可能会提出，要求，请不要和异性朋友出去玩。然后，他会渐渐地切断你与异性朋友、异性同学的关系，最后，他可能会切断你们所有的交往，他会切断你和所有的关系，你的世界会只剩下他一个人，这样一来，你就彻底地被控制在他手上了。

这还不算，通常到了这个地步，他会觉得你索然无味，对你失去了兴趣，转而抛弃你，表面上，随着你的控制越来越成功，他们寻找依赖者性了，他们的控制越来越成功。

这样的故事太常见了，从大学本教科电话心理热线开始，我就不断听到这样的故事，最极端的案例一种有，甚至心里都会受到极大折磨。这种故事大多是男人控制女人，不过后来遇到咨询案例多了，发现有不少女人也能成功地控制男人。

当然，这种故事是极端的，我们常见到的，容易浪费你意志的支配者。例如点餐时，有的支配者一不听话，总把你所有的笑点去，最后你什么也定不了了。严酷的支配者，会征询你的意见，你想点什么菜，但你说完后，他们会在点菜上，你会点什么，菜一一否掉，换上他们认为更好的。

# **支配者的形成**

依赖者的形成常常是因为有控制欲强的父母，那支配者又是怎么形成的呢？美国心理学家凯蒂·范德沃克在《客体关系心理治疗》一书中总结了两个常见的模板：

+   1.  这样的儿童时期，他们的父母关系是顺服的，他们的父母是脆弱的依赖者，不仅不能照顾孩子，反倒要孩子来照顾自己，因此，孩子很小的时候就成了一个大人在照顾父母的过程，并从中获得自己最好的价值感。长大了，他们便渴望重演这种关系。
2.  支配者和妈妈有过严重的分离，或者妈妈对他们的照料严重欠缺，这让他们对现实妈妈极其不满，而心中勾勒了一个永远不会离开自己的爱人形象。长大后，一旦爱上某人，他们便为把这个形象附加这个人身上。
