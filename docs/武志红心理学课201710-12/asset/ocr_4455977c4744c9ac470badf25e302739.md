# 问答：什么是理性和非理性

问答：什么是理性和非理性

**武志红**

今天是我们的问答时间，先来回答一些说什么是理性和非理性，再回答一些用户的问题。

首先我想和你分享一下，就在这一两周的时间里，我身边发生了几件关于非理性的事情，让我去思考，到底什么是理性，什么是非理性？

斯多葛哲学中对你物有一个二分法：你能控制的事物，和你不能控制。如果能分清你能控制的事物，在此范围内部做到自己所能达到的“好”，还要对认清你控制不了的事物，不要瞎较劲，或者怨天尤人，这两者结合在一起，就是理性。这真是清醒而优雅的活法，你值得吗？

我们之前提到的艾利斯的理性情绪疗法，就是继承了到原则，我们最能够通过的就是自己的想法，所以很多时候，可以通过改变自己的想法，让它更具理性，这样就会减少情绪上的痛苦，以及荒唐行为。

那么，什么是非理性呢？

梳理自己身边这些非理性事件时，我发现自己在这些处于非理性状态中的人，有一种厌倦感，但深入思考发现，我是非常害怕自己和世界有这种关系的。这种状态是我对别人和世界产生一种痛恨的感觉，认为他人世界居然运转，并且认为就是真相和真理。然而，人和世界根本就不这样。

由此我也总结出了什么是非理性，就是处于一种严重的分裂中，对别人和世界的，情感与感与判断，主要是一种痛恨，并它是建立在全能自恋之上的，这不是非理性也不是真理。

这样的人为什么会处于这种分裂中？实际上是他们的理想世界按照自己的意愿去运转，却发现现实世界会时不时地不愿意去运转，可这时又不能完全接受这个真相，于是转活活在能取欢的对象想象中。毕竟，在想象中世界在内心是可为所欲为的，然后，又设一个想象世界的东西，去强迫给真实世界，而且强加的时候有情绪情感，这就是非理性了。
