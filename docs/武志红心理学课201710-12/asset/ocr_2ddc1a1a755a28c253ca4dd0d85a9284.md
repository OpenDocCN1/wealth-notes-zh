# 自我效能感

关于生死和时空的话题，之所以难以理解，也因为这就和我们平常的理解差别悬殊。生死，你认为就是一个人肉体的出生；而死，你认为就是一个肉体生命的死亡。

至于时间和空间，你会觉得，任何一个成年人都会知道，空间和时间构成了我们的“四维”物理世界——三维空间再加一维时间。这样理解时，生死和时空都是物理意义上的，而我们所讲的是抽象的心理意义上的生死感和时空感。

要理解前面几篇文章，关键是要知道任何一个存在都是一个独立的生命。分子、原子和电子也是。不仅仅，我们的想法、愿望等动力也是。你惊讶世界里有生和时空，我们的意识世界也是。其中的一个关键是，一个人的内心世界，需要在外部世界实现，这时候就等于生；如果不能实现，就等于死。而动力常常就是意念、愿望和渴望。也是，“想要常常”。

那么，我们可以做一个重要的推论：如果一个人的愿望都可以实现，这个人的自我效能是不是就是最强的呢？

这就涉及到一个心理学中广为人知的概念：自我效能感。

要理解这个概念，我请你来想象这样一个场景：一个3岁大的幼儿，离他十几米远的地方有一个玩具，要得到这个玩具，有有两种方式。一种是拿大人来助他的，可以让他跳给他这个玩具；他坐在大熊身上，到另一个方向去，他可以跳着跳着跳了十几米远，拿到了这个玩具。

通过这两种方式，他的愿望都得以实现。但是，两种方式会给他形成的感觉是，啊，大人很厉害；而后一种方式则让他感到，我太厉害！

后一种方式，就会增强这个幼儿的他效能感。所谓自我效能感，就是一个认知，我可以利用我的努力把事情做好。用咱们通常的大话讲就是说，“我能行！”。

最早提出自我效能感这个概念的是美国社会心理学家班杜拉，他给出的自我效能感的定义是：“人们对自身能充分利用所有的技能去完成某项工作的自信程度”。

阿尔伯特·班杜拉（Albert Bandura，1925年-），美国当代著名心理学家，行为主义的主要创始人物之一，社会学习理论的创始人，现任斯坦福大学社会心理学丹普教授。班杜拉心理学的最大贡献就是提出了社会学习理论与行为技术。

他认为来源于直接经验的一切学习现象实际上都可以依据观察学习的方式来描述，他中替代性强化在心理学习是一个重要因素。1974年当选为美国心理学会主席，1980年获美国心理学会颁发的杰出科学贡献奖。

这时候我们就看到养育孩子的两个关键点。一，孩子的愿望得以实现，他的生命力会增加；愿望受阻，死能量会增加。二，孩子愿望，最好通过他自己的努力实现，这样孩子可以增强自我效能感；如果只是父母去带大孩子，那就会破坏自我的自我效能感。

第二点很重要，但不能走极端。这时父母要做好孩子提供环境支持。孩子把事情做好了，可以，你，给他增强，坚持他；支持他，让孩子自己能量和负能量，也就是本能和死本能，在和父母的关怀中获得流动。

# 培养孩子的自我效能感

孩子越小，越是培养自我效能感的好时机。

原因很简单：孩子越大，面临的人生使命越激烈，比如一个成年人，他的对应着意志欲念，比如，生子、工作、理财等交叠着重大命题。做好不易，而一旦失败，代价很大。相反，越小的孩子，面临的人生使命就越小，成就很大，除了心理上的意义，现实意义时就没那么大了。

例如中小学教育，那些考试的成败，没有太大的自我意义，把我们的当做一个练习就好了。但很多家长长远的做法就是要去娃娃抓起，结果使得小学一年级开始就像打生死之仗一样了，甚至是幼儿园开打。

婴幼儿的世界，就是吃吃喝喝玩玩。这个时期，孩子其实是在一个彻底没有现实意义的成功得失的世界中，而他对自己生死欲念最赢得，以是一个绝佳地培养孩子自我效能感的场所。当孩子有了意愿时，他的能量，就让他自己去完成。当然自己力量完成不了，自我效能感就增强，同时的能量也增强。

当我们靠自己的力量遇到挫败时，我们会产生挫败感。这对人来说是，化解起来很容易了，因为根本没有现实意义的挑战，只有孩子意义自我的挫败感，没有时空意识的孩子意义上自己被限制了，他也很难去点什么，甚至整个世界。但他们发现，自己信赖的父母，还稳稳地在背后。他们没有被骗到，也不是现实能量的象征和代表，他们还充满活力。这时，孩子的挫败感就被化解，他会重新振奋起来，这其实靠的是父母的力量。

但是，父母主要就是一个容器的功能，而不是越俎代庖，替孩子去完成这个任务，那当他完成时，孩子会觉得是他的完成的，是他自己做的，而不是父母的。

当然，有很多事孩子是做不了的。比如孩子谈上什么幼儿园，很多的孩子甚至成人都会去等，这些都说明超过了孩子的能力范围，这时候当然是大人去帮他解决。

但总体上，在力所能及的范围，试着让他们通过自己的努力来实现自己的愿望，管好孩子的事。那能增强他的自我效能感，这是事，他们在那些看起来很小的小小，继续做有很好自我效能感，直到有了以后那些有现实意义的成就，到时他们可以把自我效能感做支撑，去化解各种挫败，实现自己的意愿。

回到刚才那个场景中，一岁多的婴儿，他想要自己十几米外的一玩具，这个对他很可能很难接受，甚至多次接受。有时候挫折，他自己的真的死生机会住往住，让他认为自己离真实不到这个事，这时候父母可以在旁边鼓励他，让他重新激发起生的力量，最终实现自己的愿望。
