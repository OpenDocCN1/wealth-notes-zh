# 身份04 | 让痛苦流动

我今天的主题是“身份是心灵的镜子”。

今天的内容，是我们依然在谈咨询师中的一个故事入题，大概在2010年，一位男性来访者到这儿咨询却滔滔不绝的事。读出来了一件让自己极度痛苦到启动的事。作为咨询师，我也感同身受，体验到了这件事带给我的巨大震撼感。

这里我要交代一下背景，我们的咨询已经进行了一多年，他每周前来一次，所以我们的咨询关系已经足够结实。这个时候，来访者讲述到一些难以启齿的事都是可以的，如果咨询刚开始，来访者就想起这种级别的话，我会制止他们，因为咨询关系还不够结实，可能会承受不住他的痛苦，会带给来访第二次伤害。

特别是第一次咨询刚开始的时候，有一些来访者可能就会宣泄他们生命中最为痛楚的创伤，你会必须制止的，通常情况这些来访者都是必须自我保护。

好，再回到这位男性来访者的故事上，虽然我们的咨询关系足够结实，但这难以启动的事带来的震撼感，实在太强烈了，他不想面对，于是对我说，武老师，我换个话题吧。

一直以来，我是个偏温和的咨询师，大都会控制访客，但这件事对我知道我是极难难难难，他在这话面对这件事，是开始想说，不行，我们该继续谈下去。不过，当他再次说“不想面对”，我也就不坚持了。

然后，我竟然睡着了。这是我在咨询中第一次出现这种事，大概睡了十几分钟，等醒过来之后，他无奈地看着我说武老师，看来必须说说这件事了。

我个人认为，这是深层关系的价值。深层咨询关系，不仅意味着能接受来访者痛苦的痛苦，也意味着能接受咨询者痛苦的痛苦。咨询关系越深，越容易让彼此的关系产生一种像自由流动，越无边界，越容易流动。

我也闭着眼睛，但这时我已经没有困难了，无心理障碍，而且这次精神病没有任何努力使我的成分。同时，我生命中的第一次真正明白“什么叫同频”，我咨询体验是看着，全身的那种都是暖的。

这次咨询，给我这位来访者带来了巨大改变，之前，他和妻子的性生活明显僵硬。咨询之后，他开始有能够充分地享受性事。有意识的，我自己也发生了一些变化，而个人感受，我发现这些痛苦是难以承受的痛苦。
