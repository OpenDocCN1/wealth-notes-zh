# 武志红

能量本身都是一种东西，只是不断地在转变形式。全能自恋，是一元关系中的能量，而这份能量进入到二元关系，就变成了性和攻击性，进入到三元关系中会变得更复杂。

能量随着关系变复杂而变成各种东西，这个具体的过程，我暂时也并不能理解特别清楚。如果孩子一直活在“世界准备好接受你的本能喷涌而出”的感觉中，那就意味着能量没有太多损失，而是不断变复杂而已。并且，因为孩子不断地投入到和人和事的关系中，他的能量反而会不断得到滋养。
