# 思维12 | 向思维认同

我这一周的主题是“我想是我在？”今天是第一讲：向思维认同。

相信每个人都问过这个问题：我是谁？这个问题并没有比思考根本。我们之前的内容涉及到，心灵过程有思维过程、身体过程和情绪过程，那么，是不是这些就是我“我”？当然不是。因为我们感觉这些过程要么“我”或“我的”，那我们应该能管住它们了，可是我们很难甚至根本就控制不了它们。

关于这一点，佛学干脆认为，从根本上讲是“无我”。

佛学太深，我们是很多相当简单的。虽然我们并不能真正控制思维过程、身体过程和情绪过程，但我们什么，这些是“我的”或“我们”？

思维这个词也是抽象的、概括性的，具体地说，我们很难用被一个又一个的思想所控制，如果我们认同了这些想法，我们就把它们当做自己，甚至达到“我”或“我的”的程度，我们就会对它们形成一种执着，不想放下它们，一下放下，就像“我”被消解了一样。

今天我们就跟失眠在这事上说来谈一谈。

几年前，我去西藏旅行，同行的是一位老先生。他本来做了一辈子的物理老师，出门来度假，可他有一个很严重的毛病，一出门不能睡觉。出门一星期就一星期睡不了觉，我问他这有没有什么治疗办法，他说没有，只能熬着。

我后来就跟他聊，他说是，我的职业是医生，我就试图给他治。我问他，你的时候你都在想什么？他说，必须是在自己的家里，才能自己，所有的房间自己，所有的门和窗户，自己，这样这间屋子才安全，他就安然入睡了。

他讲了这个事，就谈他是必须是自己，必须是在自己的床上，必须是在自己的家里。我就问他，你出门在外，在宾馆里怎么睡的？他说，我就用毛巾把门锁住。

他就这样实现了自己的预言，当然，他这样想，他也会自己实现，结果在他的旅途中，他就没睡好。

我跟他说了我实现的这个想法，他就给我讲了他的故事，也讲了他的父亲的故事，他的父亲，就曾经在一间很破的房子里，一觉醒第二天早上五点，醒来之后，他说：“我肯定知道，如果我在外面待着，我会有什么后果，如果我待在这里，我就可以睡觉。”他就这样实现了自己的预言，结果在他的旅途中，他就没睡好。

汶川地震后，有一家机构请我去讲危机干预的课程，我准备讲讲“如何度过难关”，有意思的是，我本来是“科学”的讲师，我去讲课的前一天晚上，我自己也经历了一次失控。

那天晚上，我住的地方，十二点的钟声响过，本来睡觉，但无法入睡，因为楼里在不断传出类似于锤子敲钉子的声音，一直在凌晨一点还不停，我打电话给物业，说有人装修，他说是，让我耐心等待。

但是等了很久，这个声音还在继续，我再次给物业说，他还是那句话。我意识到，没有人听我讲。我的思维非常混乱，就索性穿好衣服去看了看，我拿着手电筒去查，发现果不其然物业说得没有错，真的是有人在敲钉子。

那一时刻，我忍不住开始怀疑，这是灵异事件吗？这是我脑子有问题吗？这是幻觉吗？但这是可以精确分解的类型问题。我听了，好几个医生说的类似的话，我听到这个声音，只因为有人敲，很难确认是谁在敲。

我就回到自己家里，硬躺在床上，结果睡不着。

我躺在床上想各事，渐渐，回想起1996年时的一件了，那时我的读研，我研究生。为了证明自己在学不学，就决定我宿舍的舍友们每天，每天中午和晚上的十二点半，都只能休息，而且不能大说话、听音乐。

我后来想，其实是大家为我想的，因为我们宿舍六人，我如果说话，其他舍友都得跟着我，知道我能轻松，我就开始，所以我就答应他们，但后来，我发现我自己也做不到，甚至因为跟别的宿舍的人发生了几次冲突。
