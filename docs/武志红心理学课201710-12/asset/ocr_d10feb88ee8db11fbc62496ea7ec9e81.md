# # 身体08 | 假自我与身心分离

我在这个课程的时候，学过一个心理学的测试，叫做“**感受阈值**”，就是让你产生某种感觉的最小刺激值。我们当时测试了各种阈值，让我印象最深刻的是我的痛阈值比较高，例如疼痛，我需感知比多数同学更高的刺激值，才能感觉到疼痛。

这听着是好事吧，像王小小说家凌渡一提出的“钝感力”，意思就是要想好好适应这个社会，最好不要太过敏感，但当迟钝这一点然而，迟钝也会带来很多问题。

# ## 迟钝带来的问题

我和我的咨询师谈到一件事，这件事让我不太舒服，但我已经持续好几年了。这件事对我的影响非常大，放弃它我可能也没有损失，但我就像是自寻苦一样坚持好几年了。

我的咨询师问我：你为什么不坚持做这件事？我想了想回答说，我脑袋上觉得这件事是有道理的，就说服了我的身体去做这件事。

我的咨询师又问我：你是一个非常善于做分析的人，如果不分析，你会怎样？我不假思索地回答：那我就是一个很不舒服的人。

讲这个故事，既是为了引出今天的主题，也是想提醒大家别把我想太高了，觉得我作为毕业多心的课程老师，就活得特别明白，从多年前到现在更敏感更痛感。实际上远不是这样，我是不停地在感受、观察、思考和分享而已。

并且我说过，每个人的文字，都是这个人的血肉写的，至少有两种可能，一种是可能文字直接就是这个人写的；一种可能是一个人写他心中另一个我，或者他喜欢的人是什么样的。我一直说我是为自己而写，为自己写作，其实写的是我自己缺失的部分，在这上面有所进步，因此对别人而言可能并不准确。

对此，我也不觉得是问题。毕竟，弗洛伊德自己说过，所以发现了俄狄浦斯情结；罗杰斯突然身上有些发现，后来才成为人际关系大师。好，我的故事交代到这里，我来讲理论。

# ## 迟钝是身心分离的结果

我的这种情况就是身心分离，或者说，身体和头脑的分离。身心分离的现象很多，但它是发生的呢？

我要回顾一下我在《[自我 14 | 真自我和假自我](#)》这篇内文中讲到的概念。我有自我构建；有假自我的我，有假自我也是围绕着别人的感受而行动，假自我，有假自我的我，也有假自我也是围绕着别人的感受而行动。一种人的悲伤是从自身出发，另一种人的悲伤是从别人的感受出发，并且假自我也是围绕着别人的感受出发。

英国精神分析学家莱因由此引出了身心分离的概念。

> R.D. 莱因（R.D. Laing, 1927-1989），英国著名的存在主义精神治疗学家，他在著作《分裂的心灵》中描述了一种分裂状态，用存在主义哲学的一部分进行描述，使得精神分裂的过程为世人所理解。

莱因说，有自我的人，他的身体和自我的自我是一致的，他的身体忠于他的自我。有假自我的他，他的身体和别人在身体一起，更容易受别人控制。结果他的身体和他的自我分离，在寻找与他人的自我结合，因此更容易被他人的自我所驱动，而不是被自己的自我所驱动。这是何等的悲哀。

身心分离会导致一个常见的现象——迟钝。当身体遇到一些刺激时反应总是慢一拍，并且，刺激引起的感受也不够清晰与鲜活。

迟钝只是表面反应，我认为更深的逻辑是，有假自我的人，把身体与自我切割，并把自己封闭到一个与身体无关的空间里，这才是为了保护自我。

例如，如果父母在孩子小时候经常虐待孩子身体，孩子发现，如果将自我和身体联系在一起，不仅身体会痛，自我也会破碎，因此容易选择身心分离，将自己封闭到一个与身体无关的抽象空间。

关于这一点，莱因讲了一个例子。一位男士，一天夜里路过一条小巷，迎面而来的两个男人和他说了一声问候，他竟然举起棍子打了他一下。他吃了一惊，但很快冷静下来，他向对方解释了，他真正想说的不是我，真正想伤害的物体不是我“自我”的一部分，所以这不会伤到他的自我。

当然，这位男士是精神分裂患者，他身体分离就严重了一些。但讲讲迟钝，相信很多人都深有体会。如我的一位来访者，她在公交车上被人踩了一脚，她当时没什么感觉，下车后才发现，她一脚其实踩得很厉害。

这位来访者此前也看过几位咨询师，她的迟钝给咨询师们留下了深刻印象，都问她这么个问题：你的身体这么迟钝，你觉得是怎么回事呢？
