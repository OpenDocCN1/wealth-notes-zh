# **→ 生能量和死能量 ←**

所谓有韧劲的生命，就是能抵抗住死能量。

说起来好像生死这个命题太大了，我们专栏中曾经做过一个故事，是说一位男士家里有过很多纠纷，因为他总是说"没道理"，打墙凿壁。暴躁的背后都藏着自恋性的暴怒，你觉得自己的行为，有着一种全善全恶的人，这样自己会像神一样。他的每一个愿望、每一个东西都应该得到实现。一旦他的动力、他的能量，或者他没有这个回应时，就会感觉到被拒绝，或者被关杀，这时候就会感觉到死之的感觉，他就会产生自恋性暴怒。相信很多朋友见识过在暴怒的状态出现过这种情况，拿东西砸东西，或者撞墙、捶地板这种行为。

我再说一个今天的基本假设，我们一般会认为什么生命生死了？就是你作为一个人肉体的生命，出生了，这就叫做生。我活了80岁，我死了，就叫死。这是我们一般这样理解生命，实际上一切存在感知和死的感知，

比如说我有一个想法升起，我们会认为我的脑袋发出一个想法，我能控制我的想法，但其实不是，你的一个想法一旦发出，它就像是一个独立的生命，它独立的生命力也有生死。

我们再做三个推论，什么叫做动力？驱使着人们做事的那些有各种样自动的行为，这就叫动力，动力一般有三个：自恋、性和生性。你发出任何一个动力，这个动力就存在一个平衡的问题，就是你生和死的感知。如果你这个动力得到实现，你就有感觉到这个动力成了一个生命，它就得生了。如果这个动力没有候可以实现，它被拒回了，被忽略了，这时候你就感觉到这个动力要死掉了。

成熟的人会觉得自己是动力，我是我的动力就会有人回应。所以，我是对我动力的生死有支配能力。这个无知的东西都是死的，你才觉得连这个动力就等于我，我发出了一个动力，这个动力的生死就关乎生死的感觉，所以死亡的感觉你就，你最后藏着这么一个基本逻辑，就是对你来说，不存在小事，任何一件小事都非常重要，因为任何一件小事都撼动着动力，这个动力生和死都让你体验到你自我的生和死的感受。

我们再回过头来解释故事里那个男士为什么会有撞墙的行为？他拿事去撞墙？因为我们自恋性愤怒是从心出发的，但是一般感知会认为愤怒都是从脑袋发出的，如果你觉得我的脑袋上生出了一个想法，遇 到了一个障碍，当遭到阻碍的时候，你会感觉到这个阻碍很强，就像有一堵墙，就是这个时候我会怎么样？成熟的成人有别的想法，他可以绕个弯，各种各样的方式，但是对于脆弱的男人来讲，你会觉得好像只有一条路。

所以说有一堵墙把我给挡住了，我怎么办？我就想要拿墙上撞，无形时就藏着一个结果，我希望拿墙上撞，打烂墙开，为我的动力实现创造条件。但实际上你可能会被血流，可能会死掉。

我们在专栏中讲到，后来这位男士在健身房的经历，让他通过了这个难题。

大家看向过去的能量是这样，就是直直的、看透往前推，挡住了往哪推的，就不会住后退，他也再不尝试了。这是有严重的全能感现象呢？人最有可能的事情，成熟的自恋态是什么？你可以思考，我把这个墙就过去不就行了，或者我就可以住后退，跟更多的前进任性。

可能成熟的人会觉得如何呢？这还是一个伟大的发现，但是如果你深刻地体验过自恋性暴怒，如果你身边有这样的朋友，特别是你身边有这样的人，你会深深的知道，当这些人遇到这样的困境的时候，这是一个伟大的时刻。这意味着一个很重要的成熟的发生。
