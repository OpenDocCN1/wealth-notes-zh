# 动力14| 连续与断裂

武定红

我们这一周的主题是“维系生命的动力”，今天是加餐课，我们来讲“连续与断裂”。

我再次任性地去谈生死这个大话题，必须要说明的是，这个话题是我个人的思考，所以大家可以把它当成结论来听，就当做一起来学习探讨吧。

# 连续与断裂

什么叫连续与断裂呢？它们和生死是什么关系？

在我的感知中，连续就像是生，而断裂就像是死。两个入人间的链接，需要生的力量，事物间的联系，也需要链接；而断裂的力量，则是因为破坏、因为攻击。

当我们把连续感知为生能量，把断裂感知为死能量时，那会导致我们会去靠近连续，而排斥断裂。当我们死能量比较低时，就会制造连续；而当死能量占统治地位时，就会去制造断裂。

我认为最经典的例子是我们惧怕关系中的分离，因为这既是断裂，我们爱关系中的连接，当一个关系像爱是一个连续体时，我们会感知到安全，才会在关系中投入，所谓投入，就是灌注生的能量。

当然，如果关系里积攒了太多的死能量，这种死能量会去攻击，这大可以三个选择：我、你，或关系。或是攻击我自己，或者伤害你，同时期待你也会持续攻击我，第三个选择是攻击我和你的链结。

攻击关系中的链接，英国精神分析学家比昂有很精彩的论述。

> 比昂（Wilfred Bion, 1897-1979），英国著名精神分析学家，是其重要的理论奠基人。1962-1965年间担任英国精神分析学会主席，被尊为精神分析领域最具影响力的思想家之一。

作为客体关系理论家，比昂的理论在心理治疗领域具有深远影响，他提出了独特的“投射性认同”等概念，并创立了“比昂小组”用于团体心理治疗，对团体动力学研究做出了巨大贡献，是后弗洛伊德学派的重要代表人物。

如果把比昂的话浓缩一下，就是我们要保持对未知事物的好奇和探索，而不是预设判断。

每个人在自己的生命中，我理解是最重的情况下就是关系的破裂，死生不离不弃，一般情况可能是我的死和生关系被扭曲了，变成了关系，我的死能量降低，生能量的力量增加了，但断裂的力量却增强了。

但说死不是好，就好，连续才最好，当能量是连续的，死能量才好，实际上一个人对关系的无力感可以分两种：第一种是情感上的，第二种是认知上的。第一种就是情感上，我们常常会有关系上的无力感，第二种就是认知上，我们常常会有关系上的无力感。

# 理性与感性

我觉得连续和断裂的话题可以有很多延伸。

例如，现代社会崇尚理性，贬斥感性，把感性视为非理性，或者认为理性是高级的，而感性是低级的。

我的看法有所不同，一直一来，我都有一个自问，是否自己有时对感性和理性过于二分？

要做达到这一点，就要看清，你不仅接受正常的流动，也接受被阻的流动；不仅接受正常的死，也接受不正常的死；不仅接受正常的关系，也接受不正常关系的破裂。

但是，从根本上来，我们惧怕死能量，特别是对于动物性的自我。我们常常觉得理性是好的，感性是坏的，这种认知是错误的。

当我们把这些二元对立的观念，就会让我们排斥死能量，于是当它们产生时，我们就容易忽视它们，因此感性的死世界，总是被断裂，也正因为这的断裂，我们总是觉得理性世界比感性世界更正常。

然而，我个人认为，感性的体验世界，才是真实的体验，世界，而理性，只是对体验的存档，它无法取代体验本身。

在咨询中，常有这样的时刻，来访者突然滔滔不绝地讲话，这个来访者是一个敏感内向的人，他通常会非常压抑，但突然爆发。

常常是一时，他们就像打开了阀门一样，把平时压抑的东西都倒出来，这让我意识到，我们常常用理性来压抑感性，但压抑是有代价的。

这样的来访者，通常只是需要被听到，而不是需要被分析。

# 体验生命力

我认为，无论你是否喜欢理性，理性的连续，都无法让你真正体验到活着。

从我自己的经验来看，我一直记得有一个来访者，在咨询接近尾声时，突然流泪了，说“我感觉我现在是一个人了”。

这种体验是无法用言语去描述的，它就像一种生命力在体内流淌。
