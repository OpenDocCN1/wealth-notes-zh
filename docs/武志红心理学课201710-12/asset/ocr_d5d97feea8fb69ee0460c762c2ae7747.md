“注重身体的感受，学会与头脑中的观念保持距离”，那怎样才能既注重内心感受又不失理性呢？

# 武志红

无论什么时候，都要有一份觉知在，就是一直都会有一个观察者在，这样就可以不会失去理性。

但理性是可以失去的，当觉知能力越来越强，“觉知”和“我”可以一同消失，那时偶尔会进入到合一。所谓合一，就是“觉知者”和“被觉知者”、“观察者”和“被观察者”的合。

安全的形态下，也不妨试试让理性稍稍失去。我们很多休闲娱乐活动，比如喝酒，就是在做顿理性，而去感知生命力直接流淌的感觉。

身体过程，是做身体甚至灵魂指引我们做的事，那是不是与感性相似，做我们想做做的事？比如为了良好形象以及健康而选择锻炼减肥，现在已经能希望锻炼过程中的辛苦，完成后会有满足感，但同时控制不住晚上吃高能量食品的冲动。其中哪些是身体过程，哪些是思维过程呢？身体过程就等于身体本能吗？如减肥，减肥是为了健康，但身体却是抗拒的，此时应该如何看待呢？

# 武志红

思维过程、情绪过程和身体过程，常常紧密结合在一起。同时，也可以细细地觉知它们。

比如锻炼身体有满足感，这既有身体感觉上的舒服，也有意志力得到锤炼的满足。至控制不住晚上吃高能量食品，我觉得常看是为自己身体过程，但根本上是心理过程，也就是感觉到孤独无助，想像婴儿一样找妈妈的乳房吃奶，这时寻求的是人际关系的怀抱，是妈妈的怀抱。

“每个生命都想成为自己，当不能用成长的方式时，就干脆使用毁灭的方式来表达这份意念。”什么是“毁灭的方式”？是他不能接受的方式？还是甚至连自己都清楚是错误的选择，但还是义无反顾地去做？

# 武志红

比如我在文章中提到的学员唤晚的故事，她跳舞是父母逼迫的，她不愿意跳，但她不能在情绪和心理层面去表达自己的反对，于是就让自己身体长得很胖，来拒绝跳舞这件事。这是为了减少在和父母对抗的张力，在说“不是‘我’想反对你们，是我的身体不行了”。

身体也是受大脑控制，所以用身体去感受从根本上讲也是用大脑去感受。去感受也就意味着思维的过程，这还是逃离不了思维。

然而当我想到此处时意识到，放下思维用身体去感受，是指放下所在环境给你的种种信息，不去用头脑进行推导出结论，而是直接融入进事物中，用你的五感的心灵去触碰，此刻你不再是旁观者而是直接与之互动，这就是“我”与“你”，而这不正是回到本体吗？

# 武志红

有多位同行对我说，你的思想那么多，为什么没有得强迫症呢？我的回答是，也许是因为我有强烈的“我”都建立了“有感觉”之上。这时，思维过程和身体过程、情绪过程，就是有条件的，我比较少做这种事，就是使着头皮去看一本书。所谓摸着头皮，就是纯粹使用思维过程去理解吧。

当然，很多时候我们需要是有硬着头皮读书的，头脑先理解了其逻辑，而后再有身体的连接感。但整体上，我觉得应该试着让思维过程为身体过程服务，而不是反过来，让思维去控制本我，甚至逼迫身体。或者说，头脑本来是仆人，它不应该是控制一切的主人。
