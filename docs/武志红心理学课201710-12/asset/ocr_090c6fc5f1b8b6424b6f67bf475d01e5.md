# 动力20| 碰触你的内在婴儿

我是这一周的标题是“生命的初心”，今天是第二讲，“碰触你的内在婴儿”。

昨天的内容中我讲了我两位来访者的故事，一个是咨询中看到了一个婴儿，一个是梦见了一个小孩  这两个故事，我在咨询中发展出了一个练习“碰触你的内在婴儿”。

> 我首先想提醒你，这只是我自己总结的一个小练习，我要提醒你的，练习要在安静、安全的环境下进行，如果练习让你不舒服，你就尽快停下来。如果有信任的人在 你身边，陪着你做这个练习，那就更好了。

这个练习的程序如下：

找一个安静、安全的地方，闭上眼睛，安静下来。先花几分钟时间，感受你的身体，至少去感受身体三个以上的部位，如柔软的毯子上的感觉，手背的温暖，小腿的感觉。同时，自然而然地呼吸。

等足够放松后，想象一个婴儿出现在你身边。那么，你会想象出一个什么样的婴儿？接受第一时间出现的任何一个画面，不要做任何评判。

他出现在哪个位置？他的神情？他和你的距离如何，你和你的关系如何？

如果你和他说，你想对他说什么？

请继续看着他，看得越清楚越好。接着继续想象，你进入了他的身体，你成为了他。

那么，作为这样一个婴儿，你有什么感受？你听过这个大的关系里是什么样的？如果你想和这个大个人说话的话，你想对他说什么？

接下来，你想亲自离开这个婴儿的身体，回到自己身上，再次看着这个婴儿，你会有什么感觉？

好，现在请你慢慢地睁开眼，活动一下你的身体，结束这个练习。

这个练习发展出来，我在我的新浪微博上做起实验，到现在我有很多新访博上邀请学员做，总人数几乎达到了上千人。我经过总结后发现，大家看到的婴儿大致可以分为四类。

# 第一类，看到了很快乐很满足的婴儿，我来分享一些学员的反馈：

+   看到一个婴儿，吃饱喝足，心满意足，趴在我家地砖上，抬着头调皮地眨着眼睛和我说悄悄话。

+   躺在我右侧，眼睛大大，咧着嘴笑的男孩，光着身体穿着尿布，很可爱的样子，忍不住去看了又看，他说，我多喜欢他，把他抱在怀里，他是我送给我的礼物。

这样的婴儿，一是有活力，二是他们和练习者的关系很亲密。第二类是比较一般的婴儿，

她在我右后侧，像小猫一样，静静让抚她的胳膊，想让我注意她。

刚出生的粉色婴儿睡着在我旁边，我想去拥抱他，但是又没有，怕伤害他吵醒他。

# 第三类，婴儿的状态很不好，和练习者的关系也不好，比如：

+   感觉小婴儿躺在我身边，很无助很可怜，她很渴望安抚，我想特别想把抱着她，她在我身体里时，我认为我想到她的时候，为什么我现在一想 到这副画面就掉眼泪。

+   好瘦小好干渴的孩子，看到她心痒得想哭。非常安静地睡在那里，好想抱抱她给她一个温暖安全的怀抱。

# 第四类人是看到了恐怖的婴儿

+   好像，他在我右边，好像泡在深渊里冷冷的海水。好，好冷。

+   试着想象了一下，是一个面目狰狞的婴儿，我是越跑，后来我感觉到身边是我的导师，我越跑越近，后来我感觉不到她的恐惧，对我说；对不起，对不起，请你原谅我。

+   我感受到的躺在我身边的婴儿已经死了，全身紫黑色。

我在工作坊中遇到的一些想象出恐怖画面的 人，常常是看上去有丰富的好的人，同时我也觉得她们走上上面是毫无生命力可言，还有很多人不敢做这个练习，会觉得很害怕。

从总量上看，想象出第二类状态一般的婴儿的人，占了二分之一，想象出状态很好的婴儿的人，不到三分之一。

我总结的这个练习，是使用了所谓的“视觉化”技术，按理来说，我们绝大多数人都记得自己婴儿时的记忆，我认为这部分都是在潜意识里，甚至到不能用语言表达，因为那个时候语言还没有形成，但可以碰到这个练习人出现于自己身上，去触碰到自己婴儿时的一些感受。

特别是在连续多天的工作坊中，依据对学员的了解，我相信他们在这个练习中看到的婴儿，有很大可能是他们的内在婴儿，也就是他们自己婴儿的样子。

例如，一位年轻女学员跟我说她看到的婴儿，是因为不完整，身体也不全，有人认为那是缺乏关注、儿时缺少得到妈妈的关注，我在这个的咨询中过，妈妈看了婴儿，婴儿才知道自己是存在的。妈妈很少看见她，所以她的内在婴儿是极其不全的。

我的 一位好友在做这个练习时，非常恐慌，不敢做。我个人认为是因为他的妈妈在50来岁的产假结束后，就开班上班，而此他有很长一段时间，是妈妈上班后他就独自待在家里，给他留下了很深的印记。

我认为让婴儿孤独地待着会导致两个可怕的结果：一是他的能力弱，保护不了自己，最没有建立了和最核心的人和世界建立关系，只能活在自己的想象中，由此导致封闭。

可以说，一个人有两个基本诉求：一是活出一个完整的自己，二是关系中被看见。  一个婴儿幼儿时待着，那么，这两个诉求都会遭到破坏。

任何一个曾经封闭的人，曾经对这个世界发出过无数次请求，再一次遭到挫败，最终会把自己封闭起来，用这种方式保护自己。该如何再次打开呢？我讲一个故事吧。

我有一位来访者，人很封闭，很长一段时间内，只是来打个预约开始咨询，他会来狂风几分钟。每次狂风过后，我们会探讨，为什么会狂风，狂风中有什么。

他的狂风持续了二十多次，最后一次狂风后，我探问他，他对我发出了狂怒的怒吼，我像是在表达；你什么都做，凭什么为我心里的共情，就能让我打开你的心，我心里去上万次的敲门，为什么没有人为我打开？

他宣泄完这段狂暴的怒吼后，大哭，然后又大笑。接下来，他每次咨询开始的那种狂风消失了，即使有也是偶尔为之。逐渐地，他和我的关系变得更加深了，同时，他也部分走出了封闭的世界，人际交往开始了很多。我 们认为是一个里程碑式的转变。

美国心理学家科胡特说，心理健康就是自信和热情，自信是生命能量能滋养自体，热情则是生命能量能滋养客体。

所谓生命能量，原始的表述形式就是常性和攻击性，它们在社交文化化中变得像是被看做很不好的东西，但如果我们真这样看待它们，我们就就知道了它们能量的来源，我喜欢它，一个人的生命目的的有两个：活出自己，在关系中被看见。

我觉得在做“碰触你的内在婴儿”的练习时，当想象着进入到婴儿的身体，从他的视角看世界时，会发现他们也就是两个基本诉求：一是活出来，二是获得共情。  我想这就是生命的初心，所以，若不忘初心，那么，请别再记过这两个基本的生命诉求。

这两个基本生命诉求，可以用“关系”和“动力”这两个重要表达。  “动力”这一重，指的是探索自我，性和攻击性这些原始生命能量，甚至可以表达，就是说是一切都是为 了关系。因为这样的理解，有一段时间我脑海中总是浮现这样一句话：孤独不是生命的切莫。
