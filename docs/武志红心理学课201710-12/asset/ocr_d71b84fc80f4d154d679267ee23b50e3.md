# 问答：潜意识的层次

问答：潜意识的层次

+   武志红

今天是我们每周的问答时间，我来回答一下一些用户的提问。

在咱们专栏的不同章节中，潜意识地不同的定义层次，可能给大家的解释带来了一些困扰。所以我先为大家再次定义一下潜意识。

我的总结是，潜意识可以分为三个层次：

+   个人历史的潜意识，这主要是弗洛伊德讲述的。在这个层面，潜意识大约相当于心灵三层结构中的伤痛层，也包括本能和欲望这些带有原始生命力，以及生存能和死亡能，但还不包括普适性或灵性，弗洛伊德不太谈这个，也因此普适或灵性不沉溺于其中。

集体无意识，也就是荣格谈的潜意识，这是荣格提主要思想。

阿赖耶识，这是佛学所说的“第八识”，藏着人类乃至众生的一切信息，大概对应着真理、道等等。

我们多数时候谈到潜意识，是个人历史的潜意识，也是我工作的主要范畴，但在这周谈艾瑞克森派催眠的时候，潜意识指的是真我，至于什么是阿赖耶识，我也没研透，至于是不是菩提对我而言，目前主要是一个概念，拿来思考而已。

如果我们认为，意识和思想就是一切，那我们就忽略了这三个潜意识层次中的宝藏。

# —— 本周问答 ——

全身放松、积极进取或者不抵抗，是不是“我”的状态呢？或者是庄子说的无为？

+   武志红

我还没活出这样的状态，所以不知道是不是庄子说的“无为”。

我生活是在别的细节中，或者偶尔在咨询中生活中，进入到这样的时刻。这种时刻的的确是超越了头脑，超越了自我，是“我与”的关系系统，甚至最强烈时，我觉得连这个都超越了，没有我，也有你。

斯波得·吉利根谈话治疗中会做到全身放松及专注，他说谈话治，感到很舒服是全身专注地看着你，同时又极度放松。

催眠是否要穿越保护层、伤痛层，触摸真我？

+   武志红

斯波得·吉利根说，催眠分两种，一种是传统催眠（hypnosis），它通过催眠利用一些技术，绕过被催眠者的意识，操控潜意识。这个技术可以是传统的，也可以是产生不是普通的催眠。吉利根称它为 trance，是穿越意识，穿越身体，进入到“内在身体”，进入到真我，也就是灵体，然后它才能去找到它怎样样。从这个层面上讲，吉利根所说的催眠，确实是穿越保护层、伤痛层，而去触摸真我。

减肥这件事的心理理论也能用信任潜意识和内在的声音的方法吗？如果在不食欲控制内，和抵抗抗内，承认它存在，然后呢？继续优雅地吃吗？如何化解它呢？

+   武志红

我们文中提到了，就是在催眠状态下，也就是身体放松和头脑放空状态下，慢慢感受。

这不仅适用于减肥，也适用于吃。可以试试，如果是你吃减肥？这时你会发现，吃到很多减肥儿，同时，你会发现自己背后隐藏着什么样的心理需求儿，当你能深入到自己心里滋味儿时，有些东西会发生改变。
