# 自我效能感等于同于自信吗？

# ### 武志红

自我效能感高的人，肯定自信高，但看起来自信很高的人，未必有高自我效能感。

自我效能感，更像是个体自信，所以是真实的自信。而自信是有各种各样的表现形式，有些人的自信只是表象，内在很自卑。如果带着带带全能的自信，有时看上去也是很真实的，但没有韧劲也不行，一遇到大的挫败，就会崩溃。

当痛苦已经远远超过自我承受力，无法再经受任何关系，只能把门门修，在在一个最小的个人空间才能喘息。这种状况怎么办？
