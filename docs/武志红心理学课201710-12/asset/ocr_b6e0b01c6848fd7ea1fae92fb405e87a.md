# 加餐：扫描式感受身体练习

加餐：扫描式感受身体练习

武志红

我们这一周的主题是“艾森克催眠法”，今天是加餐时间，我来讲授我一直以来使用的一个方法：扫描式感受身体。

在我们专注静修的内容中，我几次提到过这个方法。这次介绍得更详细一些，并简单分析一下，为什么这个方法可以发挥作用。

我先来介绍一下这个方法，操作方法具体步骤如下：

端坐或者平躺，这两个方式都可以，关键是从身体中坐着的人比较多，是的。坐着，可以坐在椅子上，也可以坐在盘子上。可以不摆姿势，也可以只是普通的坐着。

这两种方式我都会用，现在最常使用的是平躺。晚上睡觉时，早上醒来后，或者半睡醒时，就会坐起来使用这个方式。现在我每天至少做三遍扫描式感受身体的练习。

感受身体的顺序，可以自由选择，通常是从头到脚，例如从我，当我喜欢从脚开始。从哪个部位开始不是关键，关键是均匀地保持注意力。

如果我是你的催眠师，时间足够的情况下，可能会引导你：

+   闭上眼睛，自然地呼吸，现在我们花一些时间感受你的身体。



感受你的脚，就是把你的注意力集中在脚趾上，不要使用脚，感受你的脚掌、脚心、脚后跟、脚面、脚脖……



再感受你的小腿，然后把注意力缓慢地向上移动。也许你也会感觉到微微发胀、发热或者疼痛的感觉，也许只会感觉到皮肤和表层接触的感觉，任何可能性都可以，去接受自然而然的感受；



感受你的膝盖；



感受你的大腿，臀部；



再感受你的髋部、背部，感受你的整个脊柱；



再感受你的小腹和，也就是常说的丹田的位置。也许你能够感觉到，这个部位有微微发热的感觉；



再感受你的肚子、心口、胸部；



自然地呼吸；



再感受你的双手、手掌、手腕、前臂、手肘、上臂；



再感受你的双肩，放松……



再感受你的脖子、下巴、嘴唇、鼻子、面部眼睛、额头；



再感受你的后脑，头皮。

到这里，我们已经完整感受了一遍你的身体。这是从脚到头的过程，然后你可以从头顶到脚来一遍。

这个练习，我最初是在埃克哈特托利的著作《当下的力量》中看到，然后就开始尝试了。几年来，我去健禅南学习观察，发现他们教的就是这个扫描式感受身体。当时，我学的是十天，每天早上4:30起床，晚上9:30睡觉，期间是一遍遍地感受身体，也有老师做一些讲解。

佛学的东西，我懂得不多，就不多讲了。现在我来讲这个扫描式感受身体练习的体会。我是从2007年开始做这个方法的，至今持续了十年，所以有大把的经验来分享。

这个练习最初有一个非常直接的好处：可以让你很容易进入睡眠。不少人尝试了这个练习后，也跟我反映了这一点。

我们总说，放空头脑，感受身体，但真做这会很不容易。你会发现，这简直太费劲了。因为大脑一直在像机器一样运转，如果就想在思维层面去控制管理你的思维，会发现很难有效果。

这一点，我们都在生死的时候讲过，实际上没有“我”这个东西，有一个体验，就像是一个独立的思维。“我”并不能控制一个思维，越想控制，消灭一个思维，你会发现它是强大，可能有强迫症的人更能体会这一点。

这为什么难呢？因为注意力就是每个生命的养分。你不能控制它，你可以控制注意力的方向。如果你总想着消灭一个思维，实际你是在这个思维上花了太多注意力，它因而被滋养了，于是变得更强
