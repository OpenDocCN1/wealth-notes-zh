# 爱比克泰德与斯多葛哲学

哲学家爱比克泰德出生于罗马东部的奴隶帝国，年轻时被卖到罗马成为大奴隶主阿迪奥之子，这位大奴隶主就是后来的皇帝提比里乌斯和卡利古拉（Caligula）的父亲，也是希腊的罗马皇帝尼禄，曾是尼禄的秘书。

爱比克泰德 (Epictetus，公元55~135年)，古罗马著名的斯多葛派哲学家，出生于古罗马奴隶制帝国为亚细亚的一个奴隶家庭。童年时被卖到罗马为奴，后师从斯多葛学派哲学家爱森，并获得自由。

爱比克泰德对斯多葛派哲学有极重要的发展和突破，是对希腊最伟大的哲学思辨集大成的爱比克泰德是斯多葛派哲学最后的一位系统理论家，他注重个人如何在现实生活中去实践这些哲学思想，主张顺应自然而非与上帝抗争，他的思想对后来的哲学和宗教产生过深远的影响。

在这位罗马大奴隶主里，爱比克泰德对斯多葛哲学产生了浓厚兴趣，也得到了主人的支持和扶持。公元68年，尼禄覆灭后，爱比克泰德获得了自由，随后罗马建立了自己的斯多葛学派，传授斯多葛哲学。

我来为你简单介绍斯多葛哲学。斯多葛哲学认为，世界是有秩序的，可以是宇宙的大秩序，可以是自然界的变化，也可以说是道德性，每个人则是神的整体中的一个分子。世界观是，该好的，有秩序的，完整的整体，所以，人应该顺应世界理性，而不是追求个人的欲求。

那些著名的斯多葛主义者，都会在生活中身体力行这些原则，例如爱比克泰德，他身上有各种缺陷，包括一条跛腿，可能是小儿麻痹，也可能是曾被主人虐待的。但他从不怨天尤人。他一生清贫，长期居住在一所小屋里，仅一张床、一张席、一盏灯，房门也从不锁上。

爱比克泰德的名声越来越大，罗马皇帝图密善忌惮他的影响力，将他逐出罗马，此后爱比克泰德在希腊各地，继续教授斯多葛哲学，一直到80岁高龄去世。

爱比克泰德对欧洲哲学有巨大影响力，著名的“哲学皇帝”马克·奥勒留自以为是他的门徒，奥勒留的名著《沉思录》也深受爱比克泰德的影响。

马克·奥勒留 (Marcus Aurelius，公元121~180年)，古思想家，哲学家，出生于罗帝国皇室，是罗马最后的“五贤”之一，也是著名的“哲学皇帝”，斯多葛学派代表人物之一，代表作品有《沉思录》。

在《沉思录》中，奥勒留解释了“何为斯多葛主义者”：

他即便生病在床，身处逆境，奄奄一息，他也坦然接受，不会恐惧，也不会怨恨上帝。

他放弃与命运斗争，不会为任何失去的东西感到失望，不会与反对他的意图，也不会感到愤怒和嫉妒。

斯多葛学者是怎样做到这些的呢？因为我们可以通过看爱比克泰德对自己的论述：

要想获得幸福与自由，必须明白这样一个道理：一些事情由我们自己控制，而一些则不能。只有真正接受这个基本原则，并学会区分什么事情能够控制，什么事情不能控制，才能拥有内在的宁静与外在的自由。
