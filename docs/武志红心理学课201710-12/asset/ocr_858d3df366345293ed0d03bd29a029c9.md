# 动力17|性是对关系的渴望

武志红

我们这一周的主题是“性”，今天是第三讲“性是对关系的渴望”。

我设想每个资深的心理咨询师，应该都治好过一些性障碍，我也不例外。

我在咨询中发现，有性障碍的来访者们通常会来到性心理咨询师面前，他们应该是去医院检验检查治疗。但有些，部分是心理医生对他们说，你没有生理问题，你应该找到心理医生；部分则是很矛盾的心理和生理咨询师。

我在咨询中听了各种各样的问题和故事后，形成了这样一句：性是对关系的渴望。有些人也许会感到惊讶，性对有些人来说，有些人根本不想探讨了，可能是有些人误以为自己有生理问题，仔细思考后发现，对性的渴望其实是指对关系的渴望。

我个人认为这可以有一个非常直观的例证，那就是自慰。我们容易认为这是自己为了满足自己，后看起来像是没有关系，但认真后会发现，在过程中必然会做各种各样的幻想。

我曾经还阅读情论，记得上面有人讲他们十几岁至上百个有伙伴，还有人非常年轻，这些人都说了同一种感觉：性的生活没有让他们愉悦，相反他们感觉自己的心灵越来越冷淡。

读这些文章时，我还没有开始做心理咨询，后来开始做后，有一个个案有类似的情形，他们也说过类似心理。

而像伊德为杰，本来奉行的是快乐原则，那应该是，仅仅是本我的一种人格因素。那么，丰富多彩的生活，应该带来极大满足和愉悦呀？为什么他们感觉自己的心灵在冷淡呢？

我个人的咨询经验得出的结论：他们普遍能力很一般，并且也不觉得是一件愉快的事。不过这不是我一个人的感觉，另有一位调查显示，那些有性习惯的男人，他们大多数时候都很不好，他们不只是道德让我在发挥什么，还因为性愉本身就确认了他们多么兴奋、刺激和愉悦。

那么，这些人又为什么要这么做？

昨天的内容中我们提到，这些男人有意无意地想着“世界之石”了。他们在意的不是生命，而是自己占了有多少女人，败害了多少男人，这种情况可能会发展到很荒唐的地步。

我在某电视节目的一个故事中，一位在某电视台做的丈夫时有性瘾，故诉他们周围所有女人。

我在咨询中也遇到过类似的来访者，一开始，新婚有点和，但他来我这儿见到大人，他甚至有气。
