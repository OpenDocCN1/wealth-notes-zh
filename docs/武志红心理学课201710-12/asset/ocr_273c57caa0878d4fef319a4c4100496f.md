# # 身体05|疼痛铸就的催眠大师

![](bbox=[0.36, 0.05, 0.5, 0.09])

+   * 武志红

我们这一讲的主题是“艾瑞克森催眠法”，今天是第一讲“疼痛铸就的催眠大师”，来讲讲艾瑞克森的传奇一生。

首先，我们来讲讲艾瑞克森最为标志性的事件。

1919年，艾瑞克森17岁，患上了脊髓灰质炎，也是我们俗称的小儿麻痹症。这场病太恐怖了，它全身瘫痪，除了眼睛外，身体其他部位都不能动。

妈妈请了三位医生，医生们都告诉他的孩子活不到第二天早上太阳升起的时候了。艾瑞克森听到医生的治疗，他想这样太残忍了，他不可能对一位妈妈讲这样的话，我一定不让你们的催眠师说谎。

于是，艾瑞克森通过眼球的动作，让妈妈明白，第一，他还有意识，第二他希望妈妈把他恢复到窗边，这样太阳升起时，他就先想到他自己。

第二天，三位医生来了，他们都被惊呆了，但他们接着对这位妈妈说，就你的孩子活不来了，永远站不起来了，他会终生瘫痪。

艾瑞克森下定决心不允许医生们的这个“催眠”实现。他也成功了。三年后，他不仅站了起来，还令自己复活，像一般独木舟，独自一人的航行，塞舌尔以及一点点钱，独自一人畅游了墨西哥河。

那么，艾瑞克森是怎么实现这个奇迹的呢？

首先，在某种极端时刻，他会第一次深刻地领会了什么叫“暗示”。暗示是一个催眠中的一个术语，通常暗示，看催眠师通过语言来影响一个对象意识的诱导。

那到底什么叫暗示呢？艾瑞克森后来就是一个医生，医生告诉他活不过明天，这就是一个暗示。假设艾瑞克森接受了这个暗示，真的相信自已活不过明天，那就可以说，三位医生对他成功地实施了催眠。

艾瑞克森认为，这三位医生想将他遗忘在身体上，他决战决战这三位医生，他就加强了。接着，医生们又发出第二个暗示你你永远起不来了。他每一次的挑战比这个第一个挑战更难想象，而且，其中的细节也非常让人震撼。

艾瑞克森感染脊髓灰质炎后，妈妈和一名医生小心翼翼地把，这名医生发出一种办法来刺激艾瑞克森的身体，其中包括用一连串的方法，例如热敷、按摩、按摩瘫痪的四肢等。

更打动人心的则是艾瑞克森自己的探索，那个时候他已经很痛苦，意识层面他并不知道该怎么样，但当他停下来，对意识说，请给我：我有一个目标起来的，请你想想办法，指引我怎么做。

潜意识其实是给人答案，在一会儿放松的状态下，他的心中闪现出一幅画面：他，正在摘苹果。

这个画面是真实发生过的画面，他儿时的确实是这样个画面，当时他非常快乐非常享受。看到这个画面出现时，他当然就非常忽略了，毕竟，他问的是从全身瘫痪到站起来这么大的问题，会发出如此简单的答案吗？他再次问潜意识发出同样的问题，得到了同样的答案，这个画面多次重复出现后，他才恍然大悟，原来就是这样简单。

于是，在瘫痪的状态下，他仔细研究这个画面，越来越精细，最终细致入微，无比生动。他的手慢慢从伸向苹果的大动作，这个过程几乎分解成了一系列细小的动作，而他在全身放松又非常专注的情况下，去体验每一个细小动作中手和身体的移动。

几个星期后，这一画面中牵扯到的肌肉恢复了些许的行动能力，他可以做出一画面中的动作了，这是艾瑞克森痊愈的开始。

接下来，他不断重复这一工作，每当想到一个新的康复目标时，他就把它交给潜意识，请潜意识帮自己一个忙，而潜意识也总是不断地呈现出各种各样的画面，它可能是一幅风景苹果之类的某幅画面，也可能是一幕影像，或者是其他，但都能指引他达到康复的目的。

吉利根19岁也开始跟随艾瑞克森，和艾瑞克森家乡的人非常热爱，他说在这个康复过程中，很关键的一点是艾瑞克森从潜意识中，意识或者头脑中找答案的，如果问你，脑袋说怎么办，是找不到答案的，但每当他问自己更深层次的潜意识时，潜意识总能告诉他答案。

我认为，艾瑞克森的整个自我康复的过程，是一个深层次的自我催眠的过程，这个过程的威力以及其中的丰富体验，后来成为艾瑞克森发展自己的催眠治疗方法的取之不尽的源泉。

全身瘫痪是极为可怕的事，而我们却可以说，艾瑞克森从中拿到了一份大礼物，我觉得这其中自有道理。在做催眠，催眠师不应该中断引导，放松，放松，那是我们放松什么呢？就是放松肌肉和骨骼，就是我们的身体。

吉利根说，身体的每一张紧张或头脑中一个想法联系在一起，所以你当真正放松身体时，就放下了头脑中的想法，也就是放大了空间，这个时候，潜意识就有了最大呈现的空间。

全身放松，其实是极为困难的事，可以猛的小孩病让艾瑞克森全身瘫痪，不能当地说，这是一个学习催眠的绝佳时机。只是，这需要一个心理学家，不能在如此可怕的死亡力量给打击，然后才能谈得上转化。

艾瑞克森之所以能做到这一点，是因为他不仅知道，不向痛苦去点，而是他也是个盲，只对彩色有感觉。而且他还是个罕见的音乐，听不到音调的变化，没有法欣赏正常人称之为音乐的变化。此外，他还有严重的阅读障碍，到了16岁时才发现，原来是从P到G，小时候他同学他起了绰号是从A到Y。他是在在小学，同学因为他是喜欢古典，不知道他其实是在找一个个词，不知道字典的排序，他每次都是为第一步开始，一个字一个字地找。

相比正常人，艾瑞克森与世界沟通的许多通道都被关闭了。但是他从不埋怨命运，反而因此开启了正常人没有的一些通道。例如，他虽然对彩色无感，而彩色天然享受一个紫色主导的生活，穿着紫衣服，用紫色杯子，在紫色的办公室里工作，家里也装饰成紫色。

6岁时他通过一个教堂，教堂里很多人在进行合唱，只有一个教堂，音乐，听不到旋律，只听到这一群人发出这个奇怪的声音，他为什么却听呢？他看着嘴，终于找到了答案，是在一起看，呼吸的节奏是一致的，所以这是快乐。

于是，艾瑞克森从6岁起，当别人跟他说话时，他看对方的呼吸嘴。这后来成为艾瑞克森催眠的一绝技。我自己学成了艾瑞克森，花了很大功夫才能做到这一点，而艾瑞克森从6岁就可以很自然地做到。

直至阅读障碍，也帮助了艾瑞克森。16岁的他冬天，有一天的下午，天气冷，他待在地上室里学习整个字，突然他像一道白光照亮整个教室，他发现，艾瑞克森把同原声系统地按声母从A到Z排序的。那一刻，他深深地感到内在的自己，把这信息里了更深，他突然发现，因为这对文字有了更多的理解。

艾瑞克森70岁时，只能坐在轮椅上。一天晚上，吉利根来到艾瑞克森在厨房，穿着紫色的运动服，在切着偏爱的菜，非常开心，并对吉利根说：我在进运动。

脊髓灰质炎的后遗症困顿了艾瑞克森一辈子，他通过很多个严重的复发。因为不断萎缩的肌肉，他本可怜的手脚力气而不停在减弱。尽管他变得能更快地起来，他右半边身体的肌肉几乎彻底失去了力气。
