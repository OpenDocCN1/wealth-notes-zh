# 问答：别皈依了绝望

问答：别皈依了绝望

武志红

今天是我们的问答时间，我来回答一些用户的问题。

自己的生能量发情，怎样才能找到对的人呢？

社交恐惧的人也是对关系失望的结果吗？在关系中，我们需要对的人来启动渴望，但什么是对的人呢？如果我们知道对的，还会对关系有恐惧的绝望吗？

武志红

这两位用户的问题可以放在一起回答，其实除了他们两人以外，还有不少用户的问题与这两者状态相似。

我试图回答这些状态，根据如何处理死能量，也就是攻击性与破坏性，关系可以分为两种：

一种是死能量点燃死能量，或者爆发出一种不烂的冲突，或者以一方或双方的隐忍为结束，但死能量并没有改善，没有死能量转变生能量，并且不仅没有时间感到，死能量反而越来越少了。

另一种是死能量最终变成了生能量，虽然在开始时，或者过程中，两个人有可能会出现大量的冲突，但最终冲动得到了安抚，双方都能感觉到这一点，并且觉得冲突后反而两个人的关系更真实更亲密了。

我认为第二种就是是对的人，也是对的关系。

这一点也许一开始很难衡量，但少通过时间的关系可以去看清。假如关系维持了半年，都不能做到转换死能量，那一定是某个人不对，或者是这个关系不对。

听了老师的讲解，自己做练习的时候，感觉想象不出婴儿的样子，这是怎么回事呢？

武志红

我认为人为这至少有以下四种可能：

第一种，我设计的这个想象婴儿的练习不细，或者说是念力不够强大，还没练到：

第二种，是心理防御在起作用。因为担心一旦来一个吓人的婴儿，自己应对不了，所以要求的，如果是这种情况，可能自己也能感觉到，在练习开始时的身体放松，你都没法进入状态，一直活在过去和头脑里面。

还有一种可能是你身体放松练习时进入了状态，你知道自己的注意力沉到了身体上，你还感觉关于婴儿的形象，这可能是你在婴儿时期真实没有看到过。

最后一种可能是指导语限制了大家。对于这个想象练习，任何一种可能性都可以。例如，曾经有学员在想象婴儿之前看到的不是一个婴儿，自己印象深，比如让婴儿深的，有一个学员在这个练习中看到了一个巨大的婴儿般的章鱼。

再次打开自己，就是要释放压抑的愤怒、悲伤吗？岂不是只有心理咨询师可以这样做呢？若是关系中，这样子还不如人跑路。

武志红

当然不只是心理咨询师才能做到，现实中有信任本人在很多时候，对于一个朋友、同事或陌生人，基于自己脆弱的愤怒都能伤害他，甚至发出。

所以可以，当你这样的时候，你可能有这样的愿望——只有有心理咨询师获得你的全部信任，其任何人都不行，这不是真实的，你可以试着对一些温和的发出真实。

如果实在做不到，也可以找咨询师。但要知道，是持有这样的逻辑，可它不是真理。

成年以后，再次向世界发出渴求的时候，有一部分以自我满足了，另外一部分寻找咨询师，在自己里面，在关系中去找咨询师，在自己里面发出渴求，或者关系，是不是就比较容易得到回应？

武志红

我认为内向和向外同样重要。有了外在资源的时候，也不要丢了内向去；有了内在的圆满强大，不要忽略了外在关系中去试探一下，自己是否真的过了一关。

至少精析一下所求是极为满额关系的，还是一种满足他人所满足在里面的，不会是心灵假解。

为什么是恐怖的婴儿呢？婴儿是无辜的啊，为什么会想到恐怖呢？是因为这是一个死亡婴儿？又或者：这个婴儿想要让世界而让人感到恐怖？

武志红

我们再讲这样一个心理模型：一个中性的关系，如果在外面界接住了，建立了关系，那么关系会变成世界，创造力等生能量；如果没法接住，就会变成破坏性、愤怒等。我做完咨询的经验显示，这个模型一再得到验证。

现实中看着自己这个成年人就会知道，自己发出一个渴求而被拒绝，一样会生成恐惧或恨等情绪，而婴儿在无助中，这种情绪会更严重。

同时，因为婴儿都是在全能自恋中，他们的很容易是想象毁灭一切的感觉。

当我想要张开双臂的时候，过去的种种都在束缚我的身体，总有一个声音在对我说，你确定这是总一个对你的婴儿的开放会带来新的打击吗？开放既然有危害，有机会有关系在获得中，但是长的时间会让这个关系在获得中，内心的渴求会束缚着我，但假想我去建立安全感，假象我有了一孩子，孩子对我全心的信赖，对我拥有及我还没有看到生命中的阳光，尽管我从未有过这些体验。

由此开始，逐渐放开控制，控制和外界畅通道，成通往解放需要，慢慢依据的沟通来确定谁是那些正确的，人在哪方面对我有大部分的关怀，我对时间存在，这个封闭不足一个厚重的包裹，是一个原球，在另一方面，自护自己的心灵，把自己所希望及那些想象或信原，这种方式自然是完全不的，不是那么正常，但是这种作为之过渡不可以吗？不可以跳过这个阶段，然后回到正常？或者说适应不正常吗？必须要保持完全开放吗？

武志红

我从你的这些话中看到，你好像把心理学指的一些什么界，当成一个要达到的目标，你达成了才是对的，达不到就是不够好的。

这也很是全部惑的一种表达，希望知道一种境界是全部要达到的，我们可以对自己不那么苛刻。

武老师，一玩起来比谁都都，但是静下来比谁都安静的人，会住着什么样的婴儿？

武志红

我想得自己试着看一下，如果只是我想找的朋友，那么我可以看着他让他做个练习。这个练习会有关于变化的表达方式，我好像能猜到。

非常重要的，我找到两个重点：一是这个人人力的高低，通常在内心住的是有原力的，一个真正充满热情的人，在关系上也是充满热情的，二是建立关系的状态，如果一个人能建立深度的关系，并且这个是会开放的，那么在内心住的是在寻找关系并享受的，相反，就是封闭的。

武老师，有一点不太明白：“你如何选择，就是你的宿命不可避免。你如果选择宿命，那到底怎么才能是主动的选择？在被动的情况下能主动地选择？如果选择宿命怎么才能一生，它如选择的权利呢？只能是被迫住选择。”
