# 思维01｜保护层、伤痛层和真实我

武式红

我们这一讲的主题是“心灵的三层结构”，今天第一讲“保护层、伤痛层和真实我”。

多年前，我在一个讲亲密关系的工作坊上，老师罗兰·巴雷克是国际著名的两性关系咨询师，他向我们抛出一个问题：**当你感到受伤时，你会怎样保护自己？**

工作坊中有30多位学员，大家七嘴八舌。问题有点绕，因为我先试图去想象：如果有位朋友，你遇到一个让你难堪的人，你们会说什么？

那是一张很大的纸，上面罗列了“应对方式”：反击对方就是反击，反击到满意的时候就会停下来；应对的方式就是当你感到痛的时候，你该怎么做，有16种应对方式。比如你有一个小孩，你看到他在被老师体罚的时候，你会怎么做？

当时，我有一点惊讶，因为我记得我15岁以前，很少去照顾别人，我觉得自己很孤独，觉得其他15种应对方式都有点软弱的味道。

不过，随着时间的推移，我知道我肯定会说：如果也去照顾别人，那你也会失去自己的保护壳，自己会像活在一个壳里，活得不够真实。

在思考自己的保护方式时，其中一个同学的回答让我惊讶。他说：“**好的**，就是自己的保护方式。因为我是这么的‘好’，所以碰到问题，别人就不会去碰我。”

我不知道他说的是什么打动了我，那一刻我竟然白了我的保护层，那是真的一个绝佳，由于三层保护壳组成的这层壳。

第一层是“**情绪**”。我最常生气，总是先从别人那来：无论对方对我态度多不好，我都会忍，忍到第一反应时先对对方的处境，我是要看关系中尤其是，如果是父母或者家人，尤其是父母和家人，我都是要先说对方好，至少也要把别人的好，说出口。

第二层是“**情绪**”。当我体验到一种强烈情绪时，我很难去理解这种情绪，我通常感觉是：我不应该这么想。

第三层是“**认知**”。当我无法控制对方向我表达不满的时候，我就会把对方想象成一个坏人，从而合理化自己的防御行为。

这三块护盾是绝妙的组合，它们可以让我免于面对真实的自己。它们构成了一个“保护层”。

这是2009年的事。今年可以看到，那个被保护的内在小孩依然住在那里。当情绪分析关于对关系的论述我而写，我主要要停留在表层层面。

受伤的，你怎样保护自己？这是一个很好的问题，后来，在我主持的一个学习小组时，我又将这个问题提出来，问小组的几位学员，为了便于区分，我用英文字母A-B-C-D-E来称呼他们。
