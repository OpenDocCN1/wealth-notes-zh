# 加餐：全能自恋的常规表现

武志红
我们这一周的主题是“全能自恋”，今天是加餐时间，我要谈的主题是“全能自恋的常规表现”。

前面几篇文章谈全能自恋时，也许你会觉得，那都是婴儿、病人、强人们才会表现得，这和我有什么关系？今天，我就来说谈全能自恋在成年人身上的四个常规表现。

再重复一下之前的内容，婴儿的全能自恋可以概括为：我一念动念头，世界就得立即按照我的意思来运转。这意味着简单一句，在成人身上会看到这种心理的四类常规表现：

+   1. 卓越强迫症：不优秀，不配活；
2. 行动困难症：想法多，行动难；
3. 迷心论；
4. 在关系中变孤独，会通往孤独的至能自恋中。

# 卓越强迫症

它可以表达为“不优秀，不配活”。意思是，如果你不优秀、不卓越，那你不就配活在这个世界上了。父母们发明的“别人家的孩子”就是这类东西。看别人家孩子“多么优秀多么完美，多么老练，甚至极端时甚至会认为，你不配做我的孩子。”

其实“卓越”、“优秀”这些词的表达远不止“全能”，还有关心人当中真正的追求是“全能”与“完美”。例如，很多人遇到意外的灾难，会内疚，自悔过度的内归因——“如果我能做得更完美，事情可以彻彻底底掌控了，都怪我不完美。”

我在咨询中遇到一位女高中生，每次考试都会来问我分数，都难得不得心。

> 我问他：你考第一也这样吗？

> 她说：是的。

> 我追问：有例外吗？哪怕一次也好。

她最初没说，但想了会儿后说，嗯，有过一次。有一次，我们们课前都是第一名。

听到这么说，我对她说：好像你觉得自己是完美的。

她惊讶地反问我：难道我不是完美的吗？

这是一个让我印象极深刻的例子。可以想象，一个女高中生居然活在自己完美的想象中，那会多容易产生痛苦，因为现实时刻都会打自己的脸，告诉你，你根本不完美。
