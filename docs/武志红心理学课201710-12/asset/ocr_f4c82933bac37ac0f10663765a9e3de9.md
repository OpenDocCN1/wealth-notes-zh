# 动力041 全能自恋与自恋性暴怒

动力041全能自恋与自恋性暴怒。

武志红

我这一节讲的主题是“全能自恋”，今天是我讲“全能自恋与自恋性暴怒”。

我先来给你们讲一个故事，这个故事发生在去年四月，有些人可能知道这个故事。这件事发生在浙江省绍兴市，交警拦下了一辆蔚来轿车，发现这辆车有27条交通违章未处理记录，要扣分处罚。

没料到，轿车司机，一位96年出生的小哥，说他来自银河系，如果他通过他的镜头，说地球是银河系里的星球；交警要他提供证据，他说银河系是宇宙中最大的，交警问他“知道不知道”，他说不清楚；交警让他提供证据，他说宇宙里有上百万个星系；交警问他“知道不知道”，他说“你不懂”；交警问他“知道不知道”，他说“你不懂”，交警问他“知道不知道”，他说不清楚；交警问他“知道不知道”，他说“你不懂”，交警问他“知道不知道”，他说不清楚……

这段对话，是完全的自恋和自恋性暴怒的典型案例。全能自恋，就是一个人觉得自已是“神”，一行动念头，外部世界就会按照自己的意思运转。假如外部世界不接自己的意思运转，“我就会发脾气”。

有些人的暴怒看起来有些夸张，但如果你留意些新闻就会发现几乎每天都会从一些事件中间读到全能自恋与自恋性暴怒的味道。

成年人如果严重地活在全能自恋和自恋性暴怒中，就必然是暴怒的，是也严重地发展水平的婴儿一样。

成人如果严重地活在一元世界中，只能感受到自己的意志，而不能感受到别人和自己一样是平等而独立的存在。

# 婴儿与全能自恋

全能自恋，是所有婴儿一开始的一元世界。所谓一元世界，指的是：婴儿一手指一手物，指指啥，天下地上惟我独尊。在精神分析来看，其实任何一个婴儿一出生，都是这种感觉，只是能不能活生生。

这就导致了一个巨大的矛盾，婴儿感觉中觉得自己是“神”，但实际是脆弱的，早期婴儿的能力还属于很小，大一点的婴儿虽然具有一些能力，但婴儿的一切需求，都得依赖于抚养者的照料。

所以，早期婴儿都活在一个不能调谐和分裂的状态，当抚养者不能及时回应，保持舒适的吃喝拉撒照料，并能给予情感回应时，小婴儿觉得自己像被一种伟大而负面的力量吞没，仿佛自己是一个神，但又是破碎的。

当抚养者不能及时回应，小婴儿就觉得自己是坏的，世界会抛弃自己；当抚养者不能及时回应，小婴儿就觉得自己是坏的，世界会抛弃自己……

我个人的认为，幸好小婴儿还不能说话，否则的话，他会觉得自己是神，又觉得自己是坏的，世界会抛弃自己……

# “坏孩子”和“坏妈妈”

我们之前讲过，从一元关系到二元关系再到三元关系，指的是在客观的关系中，小婴儿内在的心理活动。在小婴儿的关系中，所谓“坏”就是抚养者不能及时回应，他觉得“我是坏的”，“你也是坏的”；在小婴儿内在的心理活动中，抚养者不能及时回应，就产生了极度无助和内在心理创伤，这时候他觉得自己是坏的，是坏的，是坏的……
