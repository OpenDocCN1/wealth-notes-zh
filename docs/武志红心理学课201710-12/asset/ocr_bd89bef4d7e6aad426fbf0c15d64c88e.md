# ## 身体07 | 自我催眠

武志红

我们这一讲的主题是“艾瑞克森催眠法”。

我先来给你讲一个故事。我在吉利的催眠课上，遇到一位同学，他一直有一个极大的困扰：他和老婆的关系很恶劣，他想离婚，但老婆死活不肯，不离的原因是爱他。

当年，他在一个非常偏远的小寺庙，跟着一个老师修行，他老婆费了很大周折，找到了他，非要嫁给他，他不愿啊，并为此请教他的师傅。师傅说，也许你们有很大的缘分，看来你是躲不过了。

他因此嫁给了她，可结婚十几年，始终培养不出感觉来。别感情这种，只和老婆很用思念来形容。这，可能是一种轮回。这位男士和父母的关系就很恶劣，小时候常常当打，这给他造成了很大阴影，他觉得对不起人根本就没有女人缘，在这方面他自卑至极。

从吉利的催眠课上回去，他想在意识层面给不能解答老婆为什么这么爱他而离婚，那用问题来跟他说。这两点不在内容中我们了，这是艾瑞克森的绝招，当意识上找不到答案时，不妨向潜意识寻求答案。

自我催眠的方式有很多，这位男士使用的方式是像正坐一样，闭上眼，宁静下来，注意体会集中中呼吸上。这样逐渐地，头脑就会放空，身体也会越来越轻松。

我听到隔壁专栏的万多维老师前一段时间在介绍什么《为什么梦是真的》这本书，其中介绍了很多的梦方法，老师他做了很详细的解读，欢迎大家点击链接看看。

点击试听：万维丨精彩目播：《为什么梦是真的》——梦的方法

这位男士使用的就是冥想的方法，但在开始冥想和自我催眠之前，他先用潜意识的潜意识有一个问题，我要知道，我为什么老婆就这么不爱我，渴望意识教我，发出这个问题，然后再通过自我催眠，关闭意识，深入潜意识中，这时就可能会有答案呈现出来。

果然，在自我催眠中，他想起一个伤心的回忆，在他上小学的时候，班里组织郊游，全班大多数。当他把老师、因为老师一声喊，所以妈妈对他说，我们家孩子出门就生病，是个累赘，不让他去了，你们不用管他。他常常在学校门口，哭泣地哭诉，可以看到我们班同学和老师来强烈地去找郊游，而只有他被放弃了。

这个画面让他流泪，在痛哭中，他突然想到他老婆实际上一直在治愈他，是他深深的被抛弃的创伤，老婆死活就是不愿离他，这给了他一种绝对的安全感。并且他老婆低声下气的态度，还疗愈了他在女性面前的自卑。

想到白这些后，他对老婆充满了感激，并很快向老婆表达了这份感激，非常有意思的是，当自己的价值被承认后，他老婆反而说，现在也可以离婚了，我就希望你承认对你的价值而已。

不过，他很快就改变了态度，再也不提离婚这件事了。

自我催眠，或者说冥想，有这样一些核心逻辑：当意识和头脑不知道该怎么样时，就可以放空心态，放松身体，以此与深层的潜意识建立联系，而潜意识有一些声音传递出来，这些声音，常常就是答案。

做到这些后，你就能与潜意识深层建立链接，所以不一定非得要做一次深度催眠才可以。例如，我记得美国一位著名企业家非常喜欢的做决策的方式，是先做充分的思考和研究，然后去跑步，在跑步时注意力完全集中在身体上，跑着跑着，就会有一个决策自动地冒出来，他非常信任这个决策。

至于乔布斯，则有另一种决策方式，他的一个据说2000平米的办公室，空空荡荡有一个蒲团，在做重大决策时，他首先在南墙上挂上，让自己大脑进行潜意识沟通。然后，他让下属根据苹果的产品到他面前，他就是凭借这时做的直觉去做选择。

除了这些方式，我们几乎每个人都还有一种方式，那就是梦，我个人认为，梦是进入潜意识的最便捷通道，只要你有多梦，就意味着有一条进入潜意识的通道。

也是在催眠课上，一位同学梦过来说话我说，武老师，听说你会解梦，请帮我解一个梦吧，我说好啊，讲你的梦吧。
