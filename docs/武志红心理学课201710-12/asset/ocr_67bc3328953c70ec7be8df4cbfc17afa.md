# 加餐丨每个地方都能挖一口深井

加餐丨每个地方都能挖一口深井

武志红

我们这一周的主题是“认识你的非理性信念”，今天加餐的时候，大家认识了一个完整的个案故事。

有一次在我的心理学课堂上，我为学员们做解梦演练时，其中一个学员小郑主动申请做一次“自由谈”。

他有点害羞，特别怕坐过山车，前一天晚上他在睡觉前，反复对自己做着暗示：“我希望知道我现在是什么状态，过山车，请带我想开，那今天晚上他就做下了一个梦。

梦的内容很简单，他看到一个人从高处坠落，摔在地上摔死掉了。而且在坠落的途中，在这个人前面一直朝向他，好像有什么话要对他没说但没说出来。看着这个人的脸，他觉得无比恐惧，一下子就惊醒了。

在我的课上，我询问他在课堂上梦中的感觉。他闭上眼等一会儿后，我问他，体会到梦中的感觉了吗？他说：体会到了一些，但梦中的感觉，这神感觉会持续到一些时想到什么了吗？不用做努力，说出第一时间跳到你脑海中的想法就可以了。

他梦梦般的感觉，说他想起来了，他知道的梦的感觉。然而，他讲出来了一个奇妙的故事。大约十五年前，小郑刚工作，在一个建筑工地上。工地上有五个食堂，打饭、食堂在一栋三层中间的大楼中，五层打完饭，饭后，大家都会挤在五楼的走廊上吃饭。

正在大家吃饭时，突然听到一个坠尺，但仅一米高的工友跌了下，小郑那一瞬间看到这一工友，那个工友面朝向后，嘴巴张开，好像有说话什么似的。

这是一个悲伤事件，而处理创伤事件的一个常用办法是让小郑人完整地回忆这事件。因此，我继续详细地问他对这件事有什么细节。例如，当时他看到了什么？听到了什么？闻到了什么？身体有没有一些新鲜的感受？又有些什么想法？后来又发生了什么事情。

一开始，小郑只能记起男子掉下去那一幕，但他慢慢，他回忆起了另一个细节，他记起后来同走廊里了个工友在屋里，一个室发质工友问他：那个人是你的属下，你为什么回来了，你应该去处理这件事。

我让小郑一遍遍从讲这事件，讲了之后，事情已经够清楚，但好像小郑仍有一点不透彻。我感到他需要更清晰一点，于是继续追问工友脸面而死的详情，但小郑并没有什么细节。

既然我不知道怎么做，那就不如用小郑的某个点，所以，我问他：现在你想进什么？小郑说，他想起了另一个工友，但这个人梦很很多。梦中，他和一个工友睡在一间5平米的宿舍里，突然一只老鼠吼，把他的嘴巴向不见了。他惊醒，从床上跳了起来。工友也醒了过来，问他：你，看到老鼠到哪里去了吗？工友说，没看见。

显然，这个梦的关键情节是，那只老鼠到小郑的嘴巴不见了。所以，我让小郑闭上眼睛，放松，然后回忆这个梦，并细细体念那些老鼠爬到而不见的感觉。
