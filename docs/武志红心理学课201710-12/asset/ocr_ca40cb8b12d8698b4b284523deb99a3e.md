# 问答：柏然，是什么样的隐患？

问答：柏然，是什么样的隐...

今天每周固定的问答时间，我来回答一些用户的提问。

首先特别想分享的是：现在我们学员中出了一位诗人，他的用户名叫"青墨别离"，已经有了许多。他充满诗意的留言让我"敲"点了很多最美的位置，我每次去，都会给他点赞。这首诗一般一的回复，实在，很棒。

+   - 小时候，情绪很诚实，高兴了就要，不高兴就要哭，可他们说，不可以！
- 上学时，语言很诚实，爱说话喜欢恨就说过，可他们说，不可以！
- 年轻时，思想很诚实，对真理坚持，对谬误批评，可他们说，不可以！
- 我只好，关闭了思想，关闭了语言，关闭了情绪，关闭了自己。

我以为，就将这样老去，没有思想，没有语言，没有情感。

哪里知道，什么都关闭了身体，它就像神不知鬼不觉，藏了所有秘密。

# 本问问答

回归身体的感觉真的很好，但是只是偶尔体验到。多数时间我都是沉浸在思维中，回不来。请老师教给我们一些方法回归身体吗？

身体是有语言的，如何了解这些语言呢？

这两类问题的问题者可以一起来回答，问这两类问题的用户非常多。

我认为最好的方式之一是，不断练习扫描感受躯体，就是把注意力放在身体上，接受一个顺序，不要移动注意力，去感受自己的身体。这个练习我从我小时候开始就坚持了，坚持了十年，身体和心灵因此变得更加的成熟。

其中有一个简单的方法是，去注意那些特别的身体感受，比如当你坐公交车时，手脚压在公交车的栏杆，那就可以去感受接受的感觉，感受得越细致越好。

此外，还可以去聆听身体的声音，比如你感到有严重的咳嗽或剧痛，你可以去注意疼痛的位置，去感受它们，然后做自由联想，看看感受后又想到什么，你会第一时间想起什么？

咨询室中我会使用这个技巧，例如，看到来访者纹胸纹胸，当我可能会问，你刚才没有纹胸的这个动作，你可以去感受一下这个动作，那么，你觉得这个动作想要表达什么？
