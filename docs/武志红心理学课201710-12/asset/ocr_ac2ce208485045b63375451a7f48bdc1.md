# 动力111时空感

武志红

我这一讲的主题是“拯救生命的韧劲”，今天第一讲“时空感”。

我先来给大家讲一个故事吧。

一位男士，他常有自恋性暴怒。他住的房子楼上，隔壁上下左右邻居，都是他在暴怒时揍打出来的。其实对他而言，用拳头揍打墙，甚至有时，他用最恨恨的拳头揍墙，甚至多次，他在最疯狂想象会，不过那时他还有一些理智存在，所以会控制一下自己。但每次他都会揍墙，只是比较轻。

# 空间感

很多人可能见过这样的场景，有人失去理智时，会拿头撞墙、撞地板或其他。

为什么会这样做呢？

我在之前的内容中讲过，容易暴怒的人都是有严重的自恋性暴怒，而源头是他们活在全能自恋中。整体逻辑是“我”发出了一个愿望，就应被实现，如果不能实现，就会有暴怒立现，原本作为“生本能”的渴望，立即转化成为了“死本能”的摧毁欲。

这样如果没有条件，不怕担心自己生死，那人就可能去攻击外界的客体，但正痛那情形，又不能轻易攻击外界客体，所以就变成转过来攻击自己。

为什么要拿头撞墙呢？因为人们常常感觉愿望是想要，是从头部发出的，所以拿头撞墙，就是想把头部阻碍自己的东西给摧毁掉。不然，把自己的脑袋给撞得稀烂也行。你想你这部分不断地生出什么实现了的？

我刚提到的这位男士，有一次他临时去健身房健身，没有预约，结果他选择第一个项目，肩膀肿了，第二个项目也肿了，第三个项目……他的暴怒就立刻起来了，他控制住了，转身去洗澡。在洗澡的时候，想起自己几个小的小孩，竟然哭从中来，放声大哭。因为小离开了最大，他的哭并没有引起周围人注意。

哭着哭着，他突然想到过去他来健身房时，可能有的一个规律，就是每一个项目都有他人有预约才允许。想到这个后，他恰好自己，去了第一个项目，对负责的工作人员说，我先用着，后面如果有人来，我就走。结果，这个项目的人一直没来。

在咨询中，这位男士对我讲起这件事时，他说感叹，这是一个伟大的时刻——如此说，是因为他仿佛有了个里程碑式的转变。这个转变他说不太清楚，而我的理解是他终于明白空间这件事了。

全能自恋的人，通常能愿意像是推土机一样，只会去直接、不知道绕道，推土机做的事就是要把想挡的推到，或者将这堵墙给拆掉。但是有些人的不知道空间的存在，横冲直撞的路径经常不知道，那我可以绕一下呀，我可以先退一下，等合适的机会啊。

这位男士说这次咨询中，突然领悟了这件事是可以绕道的。也有很多人觉得该摘菜，认为为什么这么简单的事，这位男士怎么就是想不到呢？但实际上很多人处于这种状态，身不由己。

时间感

现在特别流行活在当下，因为从感觉上大家都说能感受到当下这一瞬间。当你真正注意自己彻底到当下，会有各种不可思议的体验。但你说法也许就会觉得不可思议，仔细想说不定不知道，你真正确切只能感觉到当下这一瞬间。

《金刚经》里说，过去心不可得，未来心不可得，也当过当下，同个是个幻觉。它的解释是最难的境界，和最低的觉知，往住起是相像的。而这么高的境界，其实婴儿一出生就有。

对于婴儿来说，就只有当下。但导致婴儿的一个经典问题，婴儿一个愿望升起，如当下能立即满足，这愿望就活成了，如不能立即满足，它就死了。

这不是很喜，是一种很真实的感受。所以婴儿的感觉是极其强烈的，因为那是他们全然喜悦，他们的情感也极具感染力，因为他们觉得跟毁灭在发生。

如果一个又一个的期望得生，婴儿的生命力会变得越来越大，充满生机勃勃的热情。养得好的婴儿，就像一个发动机一样。如果婴儿一个又一个的愿望破灭，那么，婴儿就会积攒得越来越多，婴儿来说，这是真实的生死感。

心智不够成熟的成年人的时间感，和婴儿的时间感是差不多的，他们也有当下，如果一瞬，如果能愿望被满足，就觉得很好；如果不被满足，就立即暴怒，无助，而自己也像婴儿死了一样。各种暴怒情感、情绪失控的情况后都感受了这一感觉。

成熟的人的一个最大进步是有了时间感。有了时间概念后，生死考验，就不再限于当下瞬间，而是可以拉长得很快。范围内。如此一来，愿望达成的可能性就大了很多倍。当然，通常是重大的愿望会得生，而无数琐碎的愿望会失败。

延迟满足

延迟满足（Delayed Gratification），即推迟愿望满足，个体有意识地自调和“非功利”地满足行为的发育性重要目标，是一种为了更多更值的长远目标而主动抑制即时反馈能力，以及不等待中原展示的自我控制能力，属于人格中自我控制的一个部分，是成功和成熟的表现。它的发展充分体现了自我任务、协调人际系统、成功适应社会的必要条件，反映了自我控制或者克制欲望的能力。

延迟满足并不是简单让孩子学会等、延迟满足孩子需求，也不只是他们“听话”的表现，更不是让孩子“一只鸡盯雨而不知彩虹”，而是培养孩子在合适的时间、地点做想做的事，是自控力的一部分。说到这，它是一种管理自我的困难情境去获得长远的利益的能力。

它的反面概念是即时满足（Instant Gratification），就是立即得到满足，满足，一刻也不能延缓，简单说，就是想要的东西，现在就要。

家庭教育强调延迟满足，一个人相信在家延长时间，因强大而充满人的越多，他满足的可能性就会增加，所以满足的时间可以拉长。实际上，除了吃喝拉撒睡，其他多数的期望不可能一瞬而就，需要满足需要时间的。

但如果一个孩子总是被挫败，觉得自己什么愿望都不成，这人以后延迟满足一个教，这时绝望里，在通过他接受一个可怕的现象--你的愿望注定是不可能实现的。

所以，如果希望孩子有延迟满足的能力，就必须帮助他形成这种想法—随时间的推移，靠自己努力去一些帮助，他重要愿望会实现，虽然遭受了一些挫折。

对婴儿来讲，生死就是这么直接。当下被满足，就是生，没被满足，就是死。当成年人也是在这时间感中，当下没满足，愿望立即变成死愿望，要么攻击别人，要么攻击自己，或自废了时间的与投入后，就会知道，随着时间积累与投入增加，愿望实现的可能性会增加，于是能逐渐变强。

空间感也是一样的。有婴儿心理的人，也许没有形态空间感，觉得自己的一个愿望，在有限时间空间能实现，愿望的能量都会变成死能量。

但成熟的人知道，空间不行可以换个人空间。比如恋爱，这个人不合适，可以换一个人来，或者工作，这份工作实在做好做不好，可以换一个，可婴儿心态的人会真正觉得，只有目前这一个空间，而这其实是很僵化的。

韧劲

掌控感是生命很根本的东西。婴儿的掌控感很微弱，一是因为能力弱，二是因为婴儿只有当下这一时，会让我们觉得，活在全能自恋中的婴儿，会觉得我意志是，宇宙就是我，所以我看到的这一切就是整个世界。
