
# 三国时代与攻击性的体验

三国时代，刘备入蜀后，作为大功臣，军师法正获得了很大权力，而过去得罪过他的人避耻必报。有人讲给诸葛亮听，诸葛亮说，法正对主公有大功劳，实在不易。这话传到法正耳朵后，法正收敛了自己行为。

相信很多人有这样的体验：在某一件小事上，你被得罪了，而你出于种种原因没有表达出你的攻击性、你的怒气，结果这件小事你一直记得，多少年都放不下。但如果有了一次，又发生了这种小事，你表达了怒气，然后你会发现，不仅你觉得真畅快，对方也没有恼火，甚至你们的关系可能还变得更好了。

这是攻击性的一个根本功能。

# 动力08 | 攻击性的意义

武志红

我们这一周的主题是“攻击性”，今天是第二讲“攻击性的意义”。

## 攻击性让人更有魅力

我们知道美国很多电影在讲超级英雄，不知道您怎么看这些电影系列？《蝙蝠侠》非常喜爱的，您最喜欢的电影是，至少我是非常喜爱，包括《蜘蛛侠》三部曲。

现在大家有了心理学视角，一说对这些电影的看法，也许有人会立刻想到，这不是全是自恋的吗？是的，但是对这些美国超级英雄影片，讲的首先是全能自恋，那些无所不能的英雄们担负着拯救整个城市乃至地球的责任。

此外，这两个系列的电影都讲了攻击性，并且直接用了黑色做隐喻。《蝙蝠侠》永远是一身黑色装束，《蜘蛛侠》三部曲的第一部中，讲到白色的蜘蛛侠只有受到真善美，同时你会看到他是一个典型的真男人，羞愤、封闭，总是有点踢腿等，并且虽然会感到闷，但似乎缺乏魅力。

第二部讲那外星人的黑色能量附着在蜘蛛侠身上，他也立即化身为带着怒气的男人。有意思的是他一下子变帅了，走路昂首挺胸，浑身都散着电，所以之处女人被迷倒一片，他有了十足魅力。

为什么蜘蛛侠黑化之后，突然有了魅力？

如果我们明白，攻击性是人的一个本性，那么就有了一个领悟：剥离了攻击性的男人，也剥离了自己的本性，而真有攻击性的男人，则是真实的，因此后者比前者更有魅力。同样的，这个领悟也可以放到女性身上：简单的女人被认为娇弱，但有攻击性的女人，更容易生动有魅力。

## 获得幸存的感觉

我们讲到精神分析的咨询与治疗把修通攻击性视为核心部分，可为什么大多数人不承认攻击性，甚至容易将攻击性视为破坏性，而倾向于压制它们呢？

在这里，我要介绍一个精神分析中非常有意思的说法：儿童需要变得乖或者客体可以在他出发攻击之后而得以幸存的感觉。

一开始我听到这话时，觉得这简直是太不可思议了，一得觉得难以理解和接受。后来从逻辑上推进了一下，就知道这是可以成立了：既然婴儿一开始觉得自己是无所不能的，那么当全世界担心我一旦发生攻击，母亲乃至整个世界会被摧毁，各种超级英雄片，都刻画过这种感觉，好像地球和宇宙太脆弱了。

不过，对这一点来访者的理解还是直到在一次咨询中，有来访者对我说：武老师，我不敢对您表达愤怒，是因为我担心一对您表达愤怒，你就会报复我。

如果有些来访者时候潜意识里对人的审视非常苛刻，那么我们就上会知道这不是他的想法，但在潜意识深处，他的内疚得这好像是因为他的攻击性所导致的。

比如，我的一位来访者，姐姐在她小时候遭受车祸死亡，长大后，她只知道这是车祸，是客观意外；但她潜意识深处很真切地觉得，这是她的攻击性导致的。

这种心理像可以延伸到非常多的地方，最集中可以出这一种例子：若干天地会认为，家里所有不幸都是他的攻击性导致的，家里的不幸如亲人意外死亡，分离离婚等结果，导致他压抑自己的攻击性，或者即便释放攻击性，也是以破坏性的方式呈现。

比如对我而言，我的妈妈是严重的抑郁症，她说在言语上说要更为我的痛苦负责，但通过深度的精神分析发现是我内心深处真切觉得，妈妈的脆弱和痛苦是我导致的。

孩子因为有可能自我攻击性，所以上这些推论是很自然的部分。父母需要特别注意孩子家里的那些事件是会导致的。但很快，我们很容易看不到，但会会一遍遍对孩子说我们离婚是因为你，我们不幸是因为你……这对孩子的心灵是摧残性的。

我的一位朋友和妻子离婚多年，他儿子上小学三年级时问他，爸爸，你和我妈妈离婚，是不是因为我学习不好？我听这位朋友听的时候这么说，心里很震动，眼泪一下就流下来，抱着儿子安慰说，这是我和你妈妈两个人间的事，怎么可能是你导致的，我说的爸爸觉得的学习是好的。他这样对儿子说，是很好的做法。

不过，在咨询中，我发现一些全能感特别强的来访者做这样的解释后，他们常盼望没有攻击性，甚至忏悔若天，再读下去就发现，他们很渴望自己有影响力乃至决定周围一切的能力。所以人性真的是很有意思。

## 攻击性等同于生命力

攻击性是人类的生命，攻击性又容易将这些世界摧毁，那该怎么办？

我要特别为弗洛伊德理论。在温尼科特那里，攻击性等同于活力或动力。他认为，每个人的自我就像是一个能量球，能够伸展自己时，自然会会有攻击性产生。

我对做个此引入，我认为当一个人对外界伸展开自己的意志时，就像他身展出了一个能量触摸，意如这个能量触摸与具存在了建立在了好的关系，那么能量触摸就能被保留了，变成热有热情、创造等生命力；如果这个能量触摸没有和其他任何建立关系，被忽略或被拒绝，那么也就会变成黑色能量，成攻击性。攻击性有时，改变成破坏性，而攻击性内收，变成抑郁。

我是说形象化的说法，温尼科特曾说，攻击性是天然的活力，在好的促进性环境中，儿童的攻击性得以保留，而在坏的剥夺性环境，中攻击性会变成破坏性，并以反社会的方式显示。

温尼科特说，如果母亲在婴儿攻击下得以存活，那么婴儿潜意识中母亲是他的一个部分，不在被控制权中，是他外部的一个存在。母亲得以存活的意思，母亲既没有死去，也没有离开，同时也没有报复惩罚。

# 动刀09 | 如何转化破坏性

武志红

我们一同的主题是“攻击性”，今天是第三讲“如何转化破坏性”。

## 攻击性是我和你之间的相互寻找

虽然接着上篇讲“攻击性”，之前我们讨论了大量偏讲“关系”之主题，但单论攻击性讲得还不够透彻，结果今早写第一部分时，看到有一个刘小视频，太有感了。

如果你想看这个视频，可以在我的微博10月16号转发的内容中查看。这个视频刻画了很多生活中普普通通的小事，如果是你一个人在怎样，如果是你在恋人又会怎样。

比如，如果是你一个人睡觉的话，一切都 在掌控中，而两个人的话，另一个人的头发会骚扰到你，你会抱着他、抓着他，有时 让你烦躁，有时让你快乐。

如果是你一个人吃饭的话，可以干净利落，而两个人的话，另一个人可能会很多事，甚至还要你，有时说你，有时会让你 觉得无奈。

一个人的时候，符合全能感，但世界 是孤独的、缺乏生机的；两个人的时候，你 的生活会变得丰富多彩，但会显得你总得“攻击”别人一点，也让你的生命变得色彩缤纷、生机勃勃。

我觉得这个视频生动地解释了什么是攻击性，以及我最近喜欢的一句话：攻击性是在寻找和补充的永恒寻找。攻击性，就是我和你的永恒互动。”

没有攻击性，就什么都没有了。我们想必都体验过，如果一个人过于礼貌，这个人也容易被当成无趣或冷漠。攻击性可以轻易转化为对别人的伤害，但也可以很容易表现为建设性。这时我们就需要学习如何转化破坏性。

## 如何转化破坏性

之前我一再说，创造性和热情是白色生命力，破坏性和恨是黑色生命力，它们本质上是一回事。因为仅仅是为了生命力被看见的生命力。而黑色生命力是没有被看见的生命力。所以，如果我们能转化破坏性，会非常有用，甚至可以看到转化。”

美国超级英雄片《复仇者联盟》中的故事里，蜘蛛侠和绿巨人之间有一段剧情，绿巨人破坏了一个小镇，结果蜘蛛侠和绿巨人之间的对话很有趣，绿巨人说“我只是想被注意到”，这句话揭示了攻击性的核心。

其实，任何破坏性行为背后都隐藏着未被满足的需求。如果我们能识别这些需求，并用建设性的方式去满足它们，破坏性就会自然减少。

所以，转化破坏性的第一步，就是识别其背后的动机。比如，愤怒可能是由于感到被忽视，暴力可能是由于感到无力。

其次，我们需要学会表达这些需求，而不是用破坏性的方式去释放它们。这需要勇气，但也是成长的关键。

## 诚实的反馈

我们今天讲的内容，也许会让你感动，也许会让你觉得有压力，因为像娜乌西卡那样的境界，也太高了一些。有时候，我们并不能做到这些，甚至都不愿意，那该怎么办？

诚实向孩子反馈就好，你可以告诉孩子：我的能力有限，我承受不了你的攻击，但这不是你的错，是我能力有限。

咨询师也是，如果发现自己根本接不住来访者的攻击，那可以向来访者坦然承认这一点，然后介绍给他更合适的咨询师。

我们的影视和小说中，有时会把这一点给完美化，刻画一个高大全的人，会接纳一个邪恶之人的肆意攻击，最终转化了他，这也是全能自恋的一种表达。比如电影《新少林寺》中，谢霆锋饰演的新军阀，简直无恶不作，而刘德华饰演的老军阀，对他百般忍受，最终还去救他的命，结果感化了这个恶棍。

金庸的小说中也多次有这样的刻画，例如《射雕英雄传》中，洪七公和郭靖多次救“西毒”欧阳锋，也多次让自己和所爱的人陷入危难。

我认为在正常关系中，接纳攻击性，转化破坏性，是非常值得的。你会看到能做到这些时，我和你，以及关系都会变得更有生命力，并且也只有在这个时候，真正的亲密才会发生。

- 3. 当我们不能甚至都不愿意做到这些时，诚实反馈就好，可以告诉对方：我的能力有限，我承受不了你的攻击，但这不是你的错，是我能力有限。

# 动力10| 生本能和死本能

武志红

我们这一周的主题是“攻击性”，今天要讲的一个概念就是和攻击性有关的一个很重要的概念，就是“生本能和死本能”。

这一周的进攻性，我前面几篇讲得有点谨慎，因为“攻击性”的概念本身在中文语境里是有点复杂的，所以今天专门讲一下“攻击性”这个词的内涵。

今天我不允许我放开一点，不讲其他大师的意思，只来讲讲我自己的个人理解。

先讲一个我经历的咨询故事。

前不久，一位来访者来到我的咨询室，她看上去非常焦虑。她告诉我，她最近总是感到一种无力感，觉得自己什么都做不好，甚至开始怀疑自己的价值。

她说：“我觉得我特别没用，总是搞砸事情。我甚至不敢去尝试新东西，怕失败了别人会笑话我。”

在听完她的倾诉后，我问她：“你觉得你是因为没有能力，还是因为害怕？”

她想了想说：“我害怕。我怕我努力了还是失败，那就更证明我真的很差。”

这个案例非常符合弗洛伊德所讲的死本能，也就是自我毁灭的倾向。

她不是真的没有能力，而是潜意识里有一种自我毁灭的冲动。当这种冲动被压抑后，就会变成所谓的“无力感”，进而阻碍生本能的运作，让她无法去探索和创造。

这就是为什么我们会看到有些人明明很聪明，但就是不行动；明明很想要，但就是不敢去争取。

因为死本能在暗中作祟，它通过让一个人自我怀疑、自我贬低，来阻止其生本能的扩张。

弗洛伊德认为，人的本能分为两种：一种是生本能（Eros），一种是死本能（Thanatos）。

生本能包括性的本能和自我保全的本能，它的目的是保持和扩展生命，追求快乐和满足。

而死本能则是相反，它的目的是回归无机状态，是毁灭和破坏的冲动。

很多人听到死本能，第一反应是：“那不就是自杀吗？”

其实不是那么简单。死本能是一种更深层的驱力，它表现为对他人的攻击性，或者对自己的破坏。

当一个人的死本能太强，又没有足够的社会化和超我制约时，他就可能成为攻击他人的人。

而当攻击性无法向外投射时，就会转向内部，变成强烈的自责、自我攻击，也就是我们常说的“内耗”。

这就是为什么有些人明明没有做坏事，却总是觉得自己很糟糕，很痛苦。

今天讲的这个概念，其实就和我们每个人的内心世界紧密相关。

理解生本能和死本能，不是为了吓自己，而是为了更真实地看见自己内心深处的动力。

## 今日得到

- 1. 生本能和死本能，也是生命力和死亡力，生本能，也叫色力，黑色色力
- 2. 力量，白色生命力和黑色生命力，白色能量和黑色能量，前者都是指向生长和滋养，后者指向攻击和破坏。两者的区别在于，它们是否被看见，是否在关系中被接住了。
- 3. 任何一个动力一旦升起，它就是一个独立的生命。如果它在关系中被接住，就意味着它得以生存；如果它在关系中没被接住，就意味着它被否定甚至要被杀死。这时，这股能量的死亡焦虑就会被唤起，于是产生了破坏欲望：要么想破坏乃至摧毁客体，要么想破坏自体。
- 4. 一份动力的发展水准，是和它主人的心理发展水准相匹配的。小婴儿或心理发展水准偏原始的成年人，一旦发出一份动力，最初是抱着“我是神，我的意愿一定会得到世界积极回应”的预期，而没有实现，就可能立即变成“魔”。
- 5. 当在做转化破坏性、去毒化的工作时，就是在将死本能转化为生本能，将死亡恐惧转化成生命力。
- 6. 攻击性，就是带着主体感展开你的生命，要从一生的尺度来看这一点。
