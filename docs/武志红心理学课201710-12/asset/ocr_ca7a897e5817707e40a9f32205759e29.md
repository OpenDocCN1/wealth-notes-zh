# **动力07|每个人都不好惹**

武志红

我这一期的主题是“攻击性”，今天是第一期——“每个人都不好惹”。

我一开始讲精神分析治疗时，总是会听到一个说法：如果来访者还没有开始谈他的攻击性，那就意味着咨询还没有真正开始。当然，这个说法绝对不是指有那么多的人，比如还有这个说法，就是上面那句话改成，这个来访者还没有开始谈性，那就意味着咨询还没有真正开始。

这些说法，都可以理解为：当一个人没有向你展示他真实的本性的，咨询就还没有真正开始。也就是真实性本真性，我们的下一期就讲，就是本真性和攻击性。

我知道这样的说法，于是和每个来访者咨询开始时，都会提一个原则：在这个咨询里，你是有自由度的，除了攻击我的身体和你的身体，其他你说什么都可以。

这样说的一个重要目的，是为了让来访者知道是可以对咨询师两面发起攻击性的。对于多数来访者而言，做到这一点非常不易，他们更多表现为讨好，或者在咨询师面前表现得毕恭毕敬，像是一个乖孩子似的。

我的一位来访者，是一名白领，她仿佛脸上好像写着“懂事”两个字，每次来到我的咨询室，总是正襟危坐，非常用力地听我讲话，对我表达敬意和感激。然而，当我问她对我的看法时，她总是小心翼翼，不敢表达真实的感受。

我们专栏之前的一篇文章叫《性格是你的内在关系模式》，在那篇文章里我说过这些：问题，在关系中形成；问题，在关系中呈现；问题，在关系疗愈。来访者在当下现实中的问题或性格，是在原生家庭中形成的，也会呈现在其他各种关系中，特别是咨询关系。

所以，我总觉得可以这样推论，这位来访者在去现实中必须暴露敏感，但她和权威关系也会很敏感暴露，但怕破坏我们的咨询关系而不敢去暴露。于是，当她与咨询师中表达对自己的愤怒和压抑，同时会有说，在我们的咨询关系中，也许你一样对我产生了愤怒，但因为害怕，所以压抑了怒气。

这是一个重要的咨询技术，就是让来访者看到，他的一些关键心理同时呈现在四个方面的：他当下的关系中，他童年的关系中，他内在的关系模式中，还有咨询关系中。

咨询刚开始的时候，她会说，没可能的，武老师，你对我非常满意，非常尊重，我完全看不到你愤怒的处理。渐渐地，她发现，武老师他的确在上次的咨询中，对你产生了一些愤怒，可我却始终说不出口。后来终于有一次，她在咨询中对我说，你对我很生气！

然后下一次咨询，她取消了。再下一次咨询，她找到了。我再次探讨，到我了发生时，她找到了取消上一次咨询，接我发生了什么。她说，这两个星期，她一直惴惴不安，她担心上一次对我表达的愤怒，会把我杀死。她理解无法想象，更不可能，但她的感觉太真实了。并且，也正那好那一段时间，我在微博上被人围攻，是也是她，武老师的这位来访者，极可能是她上次表达愤怒所导致的。

为什么她会担心成这样？

还记得我上周的主题“全能自恋”吧，这位来访者非常隐秘地觉得他自己能毁掉神一样，一怕来攻击她，让她瞬间毁灭了，是她不敢表达攻击性的深层原因。

并且，她真的是一个不好惹的人，容易有自恋性暴怒，当她会对这样有想象：我要彻底毁了她，她会会有我这样的想象，然后那一刻恨不得我去死。这种恨不得人去死的自恋性暴怒，隐藏在普通级别的愤怒。

关于意识和潜意识，我说过一句话：意识层面微风小浪，潜意识里面波涛滔天。我们很多人不敢表达愤怒，常常为意识层面的愤怒或失望体验，是非常常见的，但潜意识里的愤怒，却是达到了恨不得别人去死的地步。

同样的，很多人不敢表达渴望，那是因为意识层面的渴望，却来到很得偿所愿，甚至被拒绝，甚至被伤害过，所以，这让她害怕表达渴望。可以假设，她说讨厌的次数用分出来的，愤怒有十分，但在她潜意识中，对我的愤怒也许达到了七分甚至更高。所以，她自然不敢表达攻击性，

作为一名精神分析师，我们特别强调攻击性的普遍性，要训练自己对来访者，和自己的愤怒，要有充分的敏感，甚至是需要意识到来访者的各种情感，到达甚至早到过好等等，也许都是在表达他的愤怒。

比如，经常有长期的来访者，一到咨询室就对我说，武老师，这次你说得没什么好的，我说得太多了，你作了我那么多年，你应该对我很了解了，所以你能说点什么吗？有些来访者则干脆说：武老师，这次你可以再多话题吧。

我经过很多多次讨论后，发现当来访者问这样一个话题时，绝大多数时候前都是因为我上一次对他做了一个话题，他没有被理解到一些东西，而不是他非常生气，对我非常失望，所以不想再开启一个话题，或是怕再次遭受失望，也是因为生气。

发现这一点很重要，这样，一来，我们可以发现了来访者的一个模式，也可以去探讨，上次咨询时到底发生了什么让他生气。

例如，其中一位来访者有很多次一到咨询室，是皱巴眉看着我，说武老师这你找一个话题吧。而我们讨论过她发现，每次同一个话题，那是因为一旦发生咨询中，咨询师误解了她，不仅如此，他的误解都让她觉得，我在说她是一个人品不好的人。

咨询师常常会出现误解来访者，这太容易发生。但很有不合拍的咨询师，才会给来访者“人品不好”这种侮辱判断。自信我是不会干的。有时候，我会和来访者交流说，这个“人品不好”的判断，我是没有资格去做的，并且我也没有权利，不过经常事内在想象，以及这个内在想象会驱动她做什么，从而影响了她的外在现实。

比如说在他人，在现实现中了让她觉得，对方认为她人品不好，攻击了她的人格，那她就会对对方中断乃至彻底结束关系，这个模式会导致她一直失去各种关系，而关系本来是非常宝贵的，失去太可惜。
