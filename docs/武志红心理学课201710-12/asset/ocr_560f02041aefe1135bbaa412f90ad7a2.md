# # 动力03｜两种生命力

本文的主题是心理健康的标准，今天是第三讲“两种生命力”。

昨天，我们讲了美国心理学家胡顿关于心理健康的标准。胡顿学家就是那么简单，自信热情地表达。心理学上更准确的表述是，健康就是活力能够在自体和客体之间流动。

科胡特关于心理健康的四个方面的描述，非常简单，但我想在这个基础上阐述得更详细一些。

# ## 健康与病态

所谓健康，就是好的、善意的动力或能量，能在自体和客体之间流动，并且这时自体和客体都被知觉为基本的善的、基本尊重的。

所谓病态，就是坏的、恶意的动力或能量，在自体和客体间表达，这时的自体和客体也被知觉为坏的、恶意的，当自体被知觉为彻底恶意的，就变成了自体或客体。

所以，从健康到病态就是自体和客体，以及它们之间的能量或动力，逐渐从好的、善意的被知觉为坏的、恶意的。

不过，人是很难把自己知觉为坏的、恶意的，所以是同样的病态，也有些把自己全然知觉为这样的病态，而多数人知觉为自相且无所不能，也有人，是把自己直接知觉为恶神的，比如有人会觉得“自己是撒旦，恶神的比如有的人非常讨厌自己。

大多数情况下，人还是愿意把自己想象成善良的、好的，而把邪恶和坏，投射出去。即便十分恶毒的人，你问他们，他们也会说自己是能对的、好的、善的。

# ## 表达动力的能量球

主体、客体，以及之间的能量或动力，这种主客体结构，也许理解起来仍然有困难，那我用一个的形象化理解。我认为，这是一个极为根本的理解。

还记得温尼科特对我说的定义吗？每个人的你我就是一个人的能量球。那么想象每个人是一个能量球，颜色是中性的灰色，这个能量球表达一个力时，就像你伸出了一个手指去接触。

一个能量球，一个力，那么表达动力，就会是一种能量向外部分界的事情，比如你表达了一份善意，一个声音等等。

这个能量接触，如果被某个客体接受，就意味着，自体和他客体间建立了联系，如果客体给了你一个回馈，说这个能量是好的，也就是回应，这个能量球就回到灰色，他的中性，那么，改变了色彩至到白色，从根本上来说，这种中性的能量，就变成为好的能量，即热情和创造力，可统称为生命力，也就是正能量。

相反，这个能量接触如果没有被客体接受，有两种可能，一种是能量被拒绝，一种是被忽略，无论哪一种，你都感觉到了，你被拒绝了，那么你的能量就会固定了。这时，这份中性的能量，颜色上，就从灰色变成了黑色；而感觉上，这份中性能量就变成了黑色能量，即愤怒、恨和毁灭，你统称破坏力，或者说负能量。前面使用的是“好的能量”，我讲应该使用“坏的能量”，我称之为“黑色能量”。

一旦形成黑色能量，那么这股黑色能量就有两种表达途径。一个是继续向外指向客体，这就是攻击。如果不能攻击客体，这股黑色能量并不会消失，而是转而攻击自己。但很多人听说过，抑郁症患者可能伤害攻击指向自己，认为就是这个意思。

# ## 转化黑色能量

敏感的人，就像我们周一文章中提到的边缘型人格障碍患者，他们会清楚地看到，自己有容易攻击性，有时内向攻击，有时向外攻击自己，他们的攻击性非常强，所以会有这样的说法：一位咨询师，一旦治疗过一个边缘型人格患者就可以干了。

他们攻击咨询师会是一个挑战，但如果在咨询过程没有给他们，那么这就是治疗。他们转念攻击，挑战就很大。因为他们很可能会自行结束甚至自杀。

多数人很少压抑自己的攻击性，不容易意识到黑色能量的存在，而多数性相对平和的抑郁症患者就是这样。他们的多数体验是无力的。但力很大，其实就是体验转向自己，是一种对自己构成的镇压感。

前不久，我的一位来访者指着坏掉的手机来，他带着咨询，每一次都一边她无力感。但我着咨询，她发现每一次她严重的无力感，都能产生巨大的愤怒，可以说愤怒不能表达，要么生发回来，这就变成了自己的一种镇压。

我来分享一下我的故事。作为精神分析，需要找更深的精神分析师，完成对自己的分析，这是精神分析的一个行规，我们把这个称为个人体验。

> “个人体验”（Personal Therapy），是心理咨询师向接受心理咨询和治疗。可以是一次或一次，可以是长期，甚至持续多年；可以是一对一的会谈，也可以团体咨询。

个人体验的理念基于精神分析的理论背景，最早由弗洛伊德提出，他认为，精神分析的影响是探索来访对人和想法和行为的分析。精神分析师帮助他人之前，首先能够觉察自己的无意识以及动机。在工作与分析中避免无意识的影响，因此，精神分析在受训过程中，也必须接受分析。

> 个人体验除了“咨询本身，帮助咨询师成为“更好的自己和也承担了‘帮助咨询师更好地工作’的功能。

所以，作为治疗师，我也有一位治疗师，现在我们一周两次，通过视频，每次50分钟。两年了，我在咨询中有一个极为深刻的体验。

先交代一下背景。在这咨询前，我先是取消了，咨询前，因为他的孩子提前讲课，我提前到一天晚上给他发电子邮件通知他取消。但他在国外，我的是他当早上的第一个，而他给我录视频的电子邮件，所以还无法给我反馈。当我正好咨询的休息时间，挂掉他的视频后，他给我发了信息说，这次咨询取消了。

我取消了一次咨询，但下一次咨询，我取消了一次咨询，这位取消的理由不充分，也是犹豫来结果，接下来电子邮件也忘了发，而他给我视频时，我正在说话，于是再挂掉视频，给他信息解释了一下。

第二次的取消有点莫名其妙，是我内有些什么原因在我这么做，但我觉得不可能，但一切都可以理解，何况还算不上一个坏的人。

听我说来，我的咨询师说，你看起来是一个很愤怒的人，但你有些愤怒也忽略，不好能你愤怒，也给我发了电子邮件，这个动作被浪费，因此你有愤怒，甚至是很愤怒。

听他说我，我体内一股积淀了很久的暴怒还如山般火山爆发，它像狂风呼啸，还击打“老宅”，在视野对面，他平静地对我看着，我无法报复，也没有伤害他，这时我脑海里还有一个画面：一只崭新的黑猫，从我体内跳出，它在我的书房里，书桌、墙壁上、天花板上由游走，灵动得不得。与此同时，我觉各种感觉被放大了百倍乃至千倍，我感觉自己清晰得不得了，整个外部世界也被感知得很清楚。

这就是活力滋养自体时，活力也能流向客体的经典例子。这种感觉持续了五天，一半还能一直保持，我愿意把他收入一半的我的咨询室。
