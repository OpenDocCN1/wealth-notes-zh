# 思维07｜捕获你的自动思维

这一周的主题是“认识你的非理性信念”，今天是第三讲 “ 捕获你的自动思维 ”。

今天我们继续讲讲理性情绪疗法，介绍它的一个延伸技术——捕捉自动思维。

早在专栏的第一期内容中，我们就一再强调小心的你说的那些话，言语、文字、强性思维是联系在一起的。不过在我看来，形象推理性的人生部分，不是自我定义心理最理性的生命哲学，来自自己，而是能够更好地指导别人的体验。心理学荣斯所说：“我过过去一切体验的总和”，精神分析则发现，那些被意识所接受的体验，压降到潜意识深处，继续影响着我们。

上两周我们也说到，三种心理过程中，身体过程和情绪过程是实体，而思维过程是镜像。镜像比实体都难，思维过程是最容易被捕捉到的，所以我们可以从这里开始，想办法深入身体过程和情绪过程的深度，然后在深入思维和情绪过程中去做工作，才能带来深刻改变。

捕捉自动思维，就是这样一种技术。自动思维就是事件发生后，我们头脑中一闪而过的第一时间念头。通常情况下，我们容易忽略这些念头，试着去抓住它，顺着它去自由联想，看看自己会从个念头想到什么，又想到什么，直到接触到深刻体验。

我来给你举个例子，我的一位来访者何先生，今年48岁，在电器行业管理，在公司做高层，公司总人数在百来人以上。公司的下属和老板多是男性，这是一字门。他突然发现当接触数据到上，工作中结中的朋友绝大多数是女性，工作中一个好的男同事都没有，而常来往的也都是女性。但如何知道自已不是花钱男人，又是什么会这样说呢？

咨询中谈到这个问题，我问他：“你最近一次感觉到和同性的关系有问题，是什么时候？”他告诉我，在大学时，一位女同事的儿子考上了研究生，要在一周年一个庆功会，他说这个庆功会，第一次看到女同事的儿子，是一个个子魁梧，胡子拉碴的大男孩，虽然对于这个年纪，弟弟非常懂事礼貌，但是他想“让得浑身不自在。他，这位女同事是：‘ 我这小儿子长得这么吓人，’就觉得心里一紧，有点排斥感。

这就是一个经典的自动思维，接着，“这小儿子长得这么吓人”这句话，逐渐令何先生想起了一些一些往事。

上初中上高中时，何先生都是班里的尖子生。但是，他一直在为一件事情苦恼，那就是体育课，他觉得得干。初中就有体力更发达，但体操发钱一干。但有的体素质很差，一 百米最好成绩是三十五秒，长距离，也是最差。体育考试时，引体向上、仰卧撑、跳远、跳高等项目，他都要补考。

其实班里还有几个体育差生，但与他们相比，何先生更有过更多的地方。别人，别人跑步，何先生跑步时常是弯腰的，而是手脚弯着，同学们就给他取了一个骂号，“鸭子”这个绰号不雅而响，整整跟了他六年，直到大学后也没人叫。

初中时，因为班主任很喜欢他，在各方面都鼓励他，所以体育课上的折磨还不严重。但进入一所重点高中后，何先生形容说，就像进入了一个“坟场地狱”。

尽管还算是尖子生，但他的成绩不再是特别拔尖，得不到老师的特别照顾，同学们也少了对他的尊重。男生老师对他也特别不感兴趣。体育课是经常调侃他。“鸭子”的绰号也从初中报到高中，何先生曾经幻想过很大的力气，试图改变自己跑步的姿势，就像跑步时学步改变自己的样子，他一个学家的正常姿势也没办法保持身体的平衡，最后只好放弃努力。

不如意事，性格性慢弱格，笨嘴舌活，说话容易急，于是，一些男生经常性地捉弄他。更可恨的是，宿舍里其他五个人都非常热衷于恶作剧，每每何先生是他们的固定节目。何先生没说过他们，但对于其他五个人的捉弄，他也只能忍受。

最不堪的一次，何先生去另一个宿舍玩，被同宿舍的男生意外把他的床到床上床，那个同宿舍的男生恶作剧地把脚伸到上床，和那个恶作剧的男生狠狠打了一顿，但他自己还留下了一个大青包的伤。回忆到这里，已一个一米八尺的男生在床前泪流下了。

大学期间，何先生的身材再次发育，这次成了不算高，而是很粗壮，像块板斧了。几个宿舍朋友聚会，他都躲到一个角落去，但一直碍于同学情没去投掷。

回到当下遇到的情况，他明白了，“这小儿子长得这么吓人”这句自动思维的完整意思是：“这小儿子长得和我的高中同学一样吓人。”不仅如此，实际上，每次在大街上看到身材高大的同学，他的心里都会产生‘这小儿子长得这么吓人’的自动思维，由此产生排斥。

但是，他表示一点他很有没有明白，他观在表明，男同学们多些些男性都不算太魁梧，为什么他还觉得他们可怕？我们在探讨中他发现，因好，平时他和同学也也学这整个体的关系很不好，学弟们和他也是作为一个个团体来看待他，这些男生有的身体很矮或很矮，最矮的是被看到很矮矮的同伴，但只在思维过程也是就是识中留下了“他们”会嘲笑我。“他们”不喜欢我这样的信念。

当然，再遇到男性同学时，这种信念会又跳出来，形成各种各样的自动思维。抓住这些自动思维，就可以回到当时的身体过程和情绪过程中。

咨询中，需要一次地一次地回到当时的过程，在安全、被支持的情境下，不断去检验当时糟糕可怕的身体过程和情绪过程，让恐惧的、被伤害的身体过程和情绪过程充分流动起来，从而得到化解。做到这些后，内在的体会就发生了变化，而头脑上的思维也，也就有了变化。

当然，思维的残留和内在线验的残留是不可避免的。只是像何先生一样，我们深到身体中保留最深自己的体验。而在当下的环境中是无法一样的。他们只有在被过去去纠缠住，可以更好地在当下。凭着这份认知，何先生和男性同学们的关系逐渐发生了改善。

这是故事中的一个个体案，我当初们刚刚开始做心理治疗，这个案例生动地演示了如果在信念和思维层面做工作，是远远不够的，我们必须从信念和思维入手，深入到体验深处。体验层因改变，才意味着真正的改变。

从这里出发，我建议大家做一个“捕获自动思维”的练习，步骤如下：

+   1. 找到一个让你一直以来都有些不舒服的事；
2. 回想最近一次，你再次遇到让你不舒服的情景时的事情；
3. 自己遇到这件事时，脑海中第一个冒出的念头是什么？
4. 为了保险一点，不妨再问问自己：真的吗？那个冒出的念头如果不是，就再向前推，直到找到第一个自动冒出的念头。
5. 让自己放松下来，上眼，跟着它让你联想到什么，又想到什么.......
6. 不需要想到更多的思维，更重要的是，它会唤起你什么样的身体过程和情绪过程？
7. 让身体感受和情绪情感自由流动，想笑就笑，想哭就哭；
8. 做一个总结。
