
# 预告：一元、二元和三元关系

武志红

这是我们专栏的第十三周，是“关系”主题下的第五周，也是最后一周。我们这一周的主题是“一元、二元和三元关系”。

心灵，是内在的事；关系，是外在的事。内在心灵，和外在关系，一样也是互为镜子。你拥有什么样的心灵，就会去构建什么样的关系；你构建了什么样的关系，可以反观出你的心灵。

关系对于人的重要性，不仅是生理和安全意义上的，也有灵魂层面和哲学层面的。人必须把自己的内在心灵，投射到外在关系中。这样一来，外在关系就像屏幕一样，投影出了一个人心灵的样子。通过这个投射，一个人才能看到他的心灵，并在关系中修炼自己。

从关系的基本形态看，可以把关系分为三种：一元关系、二元关系和三元关系。这三种形态，分别对应着一个人内在心理发展水平的不同阶段。

可能你会好奇，为什么不说四元关系、五元关系等更多元关系呢？因为在我看来，看似更多元的关系，都可以归到最多三元关系中。

> 道生一，一生二，二生三，三生万物。我觉得《道德经》的这句话，也有这个意思。

我们的家庭结构，也是一样的。父母与孩子构成了最基本的三元关系，而我们每个人的内在心灵与外在关系，都可以回溯到这个基本的家庭结构中。不知道你发现没，我们这个专栏的章节设计，也借鉴了《道德经》的这句话。本周的最后一篇文章，我将会为整个“关系”主题做一个复盘，也会谈谈我们整个专栏的章节是如何设计的。

# 关系15 | 无回应之地，即是绝境

武志红

我们今天的主题是“一元、二元和三元关系”，这一大节讲——“无回应之地，即是绝境”。

## 富婆的寓言

昨天的预告中，我向大家提问调查，那个问题源自听到的一个寓言。我来跟大家讲这个寓言。

一位富婆，死后上了天堂，天使问她：你可以选择两个房间，并且可以在那里生活一百年，那么你想去一个什么样的房间呢。富婆大喜，说：请给我一个最豪华的房间，能看到世界上最璀璨的风景，我还要最好的食物。

天使满足了她的要求。一百年后，天使来见她，她嚎啕大哭，说以为这是天堂，没想到地狱一样可怕。

天使说：谁说这是天堂，这就是地狱啊。

这可能有点，可能有人会说听不懂。听着不感觉言，但你会发现这样的生活感觉不错，这不就是天堂的样子吗？至少是其中的一种吧。但这不可信，因为富婆到的是一个无人陪伴，只有她一个人的房间。

有一些电影对那些穷凶极恶的罪犯有这样的描写，他们最恐惧的是关禁闭。有些最恶劣的罪犯，甚至能听到他们的内心有回声，但如果把他们丢到一间完全黑暗的黑色小屋几天，就成为他们最恐惧的事。等把他们从小黑屋里拉出来时，他们如释重负。

在完黑黑暗、无可动弹的房间里，人的内心会灵放入极大的幻想状态，没有任何外在事物的回应，得不到任何投入，于是你内心的的一切都变成不投入的投射，爱和恨的对象，然后黑暗本身会成为一个空白的屏幕，接受你的一切投射。

那些穷凶极恶的人，他们的内心充满了最恶的幻想，甚至严重时可能会处于关于妖魔魔鬼各种幻觉。正因为他们自己的身心不能回应对方，所以这是最可怕的幻觉。

至于那个富婆看似全世界最舒服的房间、最优质的食物，用最舒服的设施，结果不过是一个被关上一千年的小黑屋而已。最终会演化出各种可怕的幻觉。

当然，我觉得如果待在小黑屋或这个完美房间里的，是一个非凡的灵魂，那就完全不一样了。

一般来说，对于每个人而言，都需要关系。因为在关系中，才能展开，认识并完善自己的灵魂。但那些能在小黑屋或完美房间中自得其乐的灵魂，必然是已经在关系中得到过充分的滋养。

## 残酷的实验

对于一个人而言，更是如此，没有关系，就难以发展。一个人有自己的人际互动，才能让他/她体验到自己是一个完整的人。

德国皇帝曾将婴儿做过一个残酷的实验，他将很多刚出生的婴儿从父母身边带走来，在一定的时间内，不给互动，也不给任何满足，但让婴儿尽情吃奶，结果这些婴儿几乎全部死亡。

1959年，心理学家哈里·哈洛用恒河猴做了类似的残酷实验。他让新出生的恒河猴一出生就与母亲分离，以后的165天中与两个带“假母亲”一起。这两个“假母亲”都用铁丝扎成，一个是“铁丝妈妈”，一个是用铁丝织成的“绒布妈妈”，即一个是用铁丝织成的，头型也换成了铁丝织成的，另一个是用绒布包裹的铁丝妈妈。

实验结果发现，小猴子宁愿挨饿，也要和“绒布妈妈”待在一起。心理学家哈洛认为，这对哺乳动物而言，身体经验，比如奶水充足或营养，比食物更重要。

然后，这只是这个实验的开始，后来哈洛还发展了一系列残酷的实验。最终得出的结论：对于灵长类动物而言，爱的存在是接触和运动互动更重要的变量。

他的实验如此残酷变态，以至于有人认为，这位心理学家哈洛内心也是变态的。因为篇幅，我们不妨在专栏中更多介绍他的研究。如果我们感兴趣，推荐大家一本书《为什么大猩猩比专家高明》，这本书系统地介绍了他的研究。

哈洛残酷实验中的猴子，虽然大多数都存活了下来，但都出现了智力障碍和精神异常。他特别在世界上研究中心的类智力障碍，无一例外都死亡了。这是为什么？在我看来，如果说感情是回应，灵长类动物都有感情，而如果没感情回应，至少人类婴儿的灵魂，要么不能成形，或者宁愿死亡。

## 必要的；其次，我认为这样才能衡量一个成年人的世界，是处于一元、二元还是三元关系的层级中。

我们很多人，只是身体上长大，而心灵还处于婴幼儿的原始状态。

# 今日得到

- 1. 无回应之地即是绝境。也就是说，如果缺乏情感回应，人就等于处于绝境，甚至是死亡之地。回应，就是光。
- 2. 任何一个人需要关系，因为关系中，才能展开、认识并淬炼自己的心。也只有人性化的互动，才能让一个人体验到自己是人。
- 3. 那些拥有丰盛饱满的人际关系的人，他们容易呈现鲜活的生命力，有热情，有感染力；而人际关系匮乏干瘪的人，生命力也容易匮乏干瘪，哪怕他们是天才。这也是人性的矛盾：如果一个人处于损耗性关系中，创造力会受损，但如果缺乏人际关系的滋养，哪怕这个人身上有天才一般的创造力在闪耀，他仍然是不可能幸福的。
- 4. 婴儿活在原始的合一中，他觉得自己和世界完全合而为一。这种心灵的原初状态是混沌的、脆弱的、未分化的，婴儿需要在和母亲等抚养者的互动中，逐渐地发展出一个清晰的、坚韧的、复杂的心灵。在此过程中我们需要切记：情感互动胜于饮食照料。不仅母婴关系，任何关系都是如此，如果只有物质满足，而缺乏情感互动，那这个关系的质量就没有什么好称道的。

# 关系16｜从一元关系到三元关系

武志红

我们这一周的主题是“一元、二元和三元关系”，今天是第二讲“从一元到三元关系”。

在之前的预告中，我们说从关系的基本形态看，关系可以分为一元关系、二元关系和三元关系。

一元关系，是指一个人只看到自己的意志，只感受到自己的感受，他希望别人都来配合他的意志；关系中，只能是他说说了算。

二元关系，是指一个人意识到另外一个人和自己，是一个独立存在，有自己的意志和意愿，他能共情对方的感受，也能尊重对方的意志。

三元关系，是指一个人能意识到关系的复杂之处，在复杂的关系中，他能同时看到“我”、“你”和“他”三人的感受与意志，并尊重这个复杂的三元关系中的竞争与合作。

通过一个新生儿的心灵发展阶段，可以清晰地看到一个新生命的人是如何一步一步地认识到关系的复杂之处的。

精神分析学认为可以将一个孩子6岁前的发展按照3种关系分成三个阶段：

## 一元关系阶段

时间是六个月前，这个阶段的婴儿处于共生期，觉得自己和妈妈是一体的，甚至自己和整个世界都是一体的，至少在身体上和情绪上是心理上的。

一元关系的境界，在成年人中并不少见。例如恋爱中的女人会容易想，我不说话就要知道我在想什么，否则就是不爱我，这是恋爱中进行到共生期了，渴望自己恋人合二为一。既然合二为一了，自然不用沟通就知道彼此想什么。

一元关系的核心规则是“剥削”，处于一元关系的人，会总不往去“利他”，掠夺别人，就要像我“剥削”妈妈的乳汁一样，因为婴儿就觉得自己什么都有，又认为既然世界一体，所以什么都是我的，我可以肆意使用。习惯剥削的人，也是活在一元关系中，但是把他自己放在了母亲角色上，这就是“圣母情结”。

## 二元关系阶段

二元关系的时间是6个月到3岁，从五个月开始，孩子进入一种矛盾感觉，他一方面觉得仍要得妈妈和自己是一体的，但同时也发现，越来越多的事情显示他和妈妈又是两个人。

必须说明一下，心理学的各种发展阶段论中，涉及的年龄都要看成一个大概，而不是精确的数字。比如说6个月前是共生期，并不是精确到比如六分三秒就是共生期，六个月六分三秒就进入了下一个阶段了，这只是一个大概数值。

孩子意识到自己和妈妈是两个人，那可能意味着这是孩子和妈妈分离的开始，这个分离包括除了身上的分离和心灵上的分离，表达方面，孩子会开始表达不一样的意识，会用语言表达“不”，这是孩子在划清边界，以捍卫自己的独立性。

良好的照料下，孩子到差不多三岁时，会初步形成自己的个性，这是很重要的一个里程碑。与此同时，另一个重大的事情发生，孩子对三元里最初有一点认识，他会有一个稳定的内在客体。这种情况可以有很复杂的表达，比较简单的是孩子内心中间有了“爱的和恨”，这意味着，孩子心中终于有了“我和妈妈两个人并存”的关系，因此进入了二元关系的世界。

这两个里程碑中，心中住下了一个稳定的爱的客体，是很重要的一个点，这意味着，孩子有了一个可以寄托情感的对象，同时也意味着，他可以用这个客体来理解自己和妈妈的关系，这就是心中住下了一个爱的人，他心里不虚。

二元关系的核心规则是“控制”，孩子和母亲，在争夺对孩子的控制权。妈妈会想控制孩子，而孩子也会想控制妈妈。这是一个非常关键的时期，如果控制得好，孩子会形成一个良好的自我控制能力。

# 关系17 关系层次进化的关键

武志红

我这一章的主题是一元、二元和三元关系，主要是讲“关系层次进化的关键”。

关系层次进化有三个阶段：一元关系，二元关系，三元关系。

## 从一元到二元的喜悦

我的一位来访者，是一位非常自大的企业家，他口口声声，能说能道，这一切都源自他的那种强大的、充满自信的态度。他的意思是希望他每一方面都是公司里最优秀的。

他来我咨询时，他彻底地在以自我为中心的一元世界里，他可以说几乎没有两种情感：希望实现，他的心态被打击，他就难过。

也就是说，他只能感受自己的感受，对别人他只是头脑上想着对别人好，但感受不到别人的感受，无法和别人共情。而且他对别人的感觉在于“在他的基础上，必须在对方顺他的意思的前提下”。

通过长期的咨询，他对这个世界的认识丰富了起来。这期间，他爱上了一个女孩，发动了几个团队的攻势，而女孩始终拒绝他，最后他崩溃，女孩还是温柔而坚定地拒绝了他。

他再来看我时，他来讲咨询，看上去非常憔悴，但他说她非常难过。但咨询中，我多次感到明显的喜悦，而且我觉这份喜悦绝对不象他的，所以他看似他受到他最爱的女友的拒绝，是我说我感受喜悦是“我”的感受，我开心得不得了。我听到这个消息后，我不知道为了什么，我听到这个消息后，我开心得不得了。

他说了这句话，他就开始大笑，而且持续了很长一段时间，有时停不下来。后来，我们探讨时，他还是想忍不住笑，经过探讨，我们认为是他自己开心，是因为他终于感受到，世界上不只是他一个人的中心，世界上还有另一个人独立存在着，有他自己的感受和意志。

就像有他自己的关系，世界进入了二元关系的世界，是充满喜悦的，他在公司里不再是孤家寡人了。

这是一个进入二元关系的重要条件：有人没有听你的意思，于是直接告诉你，别人也是有独立意志的。

但这个更为重要的是，虽然女孩一直在拒绝他，但女孩表现得既温柔，尊重他，也没有攻击，这让他也意识到：她不仅有独立意志，她还友好的，善意的。在另外一个，这是一个不同于关系中的根本原因。

人们总说，净化就是，你让别人展现独立意志，同时又是真心对你，这就让你明白了世界上有其它中心存在。

## 婴儿与妈妈的二元关系

对于一个孩子而言，他的心灵发展也是沿着这样一个路径：从最初的与母亲的一元关系，进化到和母亲的二元关系，乃是关系的三元关系。对婴儿的成长来说，母亲是好的，善意的，这是更关键的。

可以说，每个小婴儿都是在孤独的一元世界中，他只能感受到，自己的感受是唯一中心，婴儿非常脆弱，最初自我满足和自我满足能力都是零。这时候世界他们而言非常陌生，是世界“好”的：被满足，他们就会认为世界是“好的”；被拒绝，他们就以为世界是“坏的”。这时候自己与世界的关系，也会逐渐体验到充满敌意的。

当“坏的、敌意的”体验太多时，婴儿就会使用一个极端的处理方式保护自己：世界是好的，而我以外的世界是“坏的”。这就是婴儿的一元世界，而老子所谓的“复归于婴儿”是“婴儿”是“婴儿”是“婴儿”是指婴儿是“婴儿”，这是婴儿。

相反，当“好的、善意的”体验多时，婴儿就会感到，世界是“好的”。自己也是“好的，友善的”。通常到了六个月后，发现自己其实是一个有独立意志的存在，同时母亲其实也有一个善意的“好的”，于是孩子就可以接受：世界有两个中心，一个是自己，一个是妈妈。

二元关系的基础，是建立在世界有两个“好东西”的基础上。

不过，实际上，二元关系也存在着严重的分裂，无论妈妈照顾得再好，小小孩仍然会受伤的时候，这时候妈妈出现矛盾，妈妈有两种，一个是好的妈妈，一个是坏妈妈；孩子有两个，一个是好孩子，一个是坏孩子。

那么在好的情况下，孩子倾向于只意识到妈妈和好孩子，忽视坏妈妈和坏孩子。而当妈妈对孩子比较好时，孩子就会忘记妈妈对孩子不好的一面，妈妈和好孩子是一回事，妈妈和坏孩子是一回事。

这意味着整合，意味着关系中的两个人都得到别人认可的存在，也能呈现自己的完整存在，是最好最成熟的二元关系的境界。

不过，在二元关系中，去看待彼此的“坏”，都是极具挑战的，特别到别识别的关系才能做到。比如你一开始对别人的关系说我是好，那么这时关系就很有张力。对方会对好，要么攻击你，或者你的关系会陷入坏。但如果他选择了一段稳定的，开放了，关系变得深厚了一些，甚至已经亲密和谐，只要一句了，这时表达变得容易很多。

总而言之，在二元关系中，去看待“坏”是有难度的，对小孩来说是尤为如此。需要去构建一个三元关系，去化解关系里的张力。

具体的表现形式是，孩子为了和妈妈保持好的关系，会把妈妈看成比她对人更好的，而把“坏妈妈”投射到第三方身上，比如父亲。

## 孩子与父亲的三元关系

作为母婴关系外的存在，父亲是所有孩子的第一个原型。所以达尔文说：父亲是所有女人的敌人。这样的故事很多，敏感的父亲肯定注意到。

有一次，我讲到达方面的话题时，结果下面有两位爸爸，他们都说自己曾经发现了父亲太讨厌了，一个孩子：爸爸，对不起，你为什么要打我？

这时父亲要转移的原则，应该是先向孩子道歉，孩子证明自己是独立的，然后再让孩子知道，自己是有独立意志的，更重要的，父亲要抱着孩子的手，带他走进外部世界，爸爸切记：作为父亲，你就是孩子的最早外部世界。

当父亲和孩子关系中的“好”变多了，孩子对父亲的观感变好，关系中的“坏”变少，于是就像整合了，看到一个好父亲，自己也是有坏有坏。当孩子能看到，在和自己父亲的是一个三元关系，自己、母亲和父亲，都是有好有坏，但是是善意的，同时的都有独立的意志，这意味着，孩子真正进入到了三元关系的世界。

关于一元、二元和三元关系，我们可以有一个形象化的理解：

> 当你觉得，世界上只有你好的，这就是一元关系；
> 当你觉得，你和另外一个人都是基本好的，这就是二元关系；
> 当你觉得，你、你爱的人和你竞争的人，都是基本好的，这就是三元关系。

这样听起来简单，其实我一直在说关系的好，但同时又需要强调的是，关系里是用来处理我们内心心灵中的“坏”的。

一个人的世界，必然如地壳同一，而一个人的内在关系，容易变成和地壳一般分离。所以，人需要从一个一元世界，进入二元世界，去爱上一个好人，建立一个好的人，替换一个人心中“坏”，才能走向孤独的“一元世界”。
