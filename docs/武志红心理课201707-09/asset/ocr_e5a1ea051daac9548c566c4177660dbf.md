# 命运09 | 竞争，是最好的合作

今天，我们进入这周主题的第三讲，“竞争，是最好的合作”。

昨天，我们介绍了提摩西 · 加尔韦的“身心合一”打法，也就是说全然松弛地专注在你的动作里，他的潜能就得以发挥。

今天我们来说另外一种状态。有那么一些人，虽然不能完全放下自我意识，不能做到“身心合一”，但他们却能表现出惊人的竞争性，达成一些非凡的成就。这是为什么？

# 竞争性

前几周我们都在说竞技体育，篮球和网球，其实，我们发现，很多竞技领域的成功者，都有一种霸气。

霸气是什么？

其实就是追求自发时的决心和信心，就是“我必赢”，我也坚信“我会”赢，我不接受“输”的状态。

篮球明星乔丹和帕金斯也不够了解，而詹姆斯和科比，他确实认为，他们是用各种方式来获取“身”，把失败的原因转移到别人身上，虽然帕金斯和科比的确赢过，但却可以保护我们心中“我必须赢”的气场。这跟自我之气有区别，因为他们是队从教练的底气，所以只能靠他们的霸气不断，球队就有机会。

也就是说，为了赢，他们不仅要击败对手，也可以像乔丹、帕金斯、巴里等人。

但迈克尔 · 乔丹从 NBA 篮球联盟休了 3 个冠军之后，还是和奥尼尔隔开了，就是只追求自始至终，追求“我”自己的胜利，在这个王国中，“我”得是最好的。

篮球本来不是竞争性的。的球赛，也许压抑了自己比赛天性，就很容易吸引人合作。但像詹姆斯和科比，也许是因为一直各种激烈的竞争中，所以懂得竞争中的各种规则和潜规则，更容易在竞争中取得胜利。

也许，他们难以到达乔丹教练说的“潜能全部发挥”，但他们能赢。

竞争性，确实最重要的人性之一。从生物学的角度推演，因为每个人都竞争，竞争者，竞争，每个人成千上万次，都是一粒精子在亿万个精于对手中获胜的过程。

最小的精子，与相对硕大的卵子结合，这是一个很有意思的突破。

我看过一部亚历山大天帝的电影，当时，看着他从一个帝国打到了印度，突然间，就为成王界之王做的努力，多过一粒精子想占领地球这个巨大的卵子的过程。

所谓世界之王，就是这么回事。

# 人性的展开

卵子与精子，也像是个人对于男人和女人的隐喻。很多哲学家和心理学家有过类似的阐述，比如英国心理学家温尼科特说：女性的品质是“在”，她“只要你”，着就非常有意思，而男人的品质是“干”，他必须做点什么，必须追去在某一方向上出类拔萃，才能得到存在感。

这也可能找到男女性的不同。心理学家帕格尔认，母亲无条件的接纳的，母亲对孩子的一切都会给予肯定的回应。所以母力量即，父力量则是提供秩序、界限与力量，要把自孩子，父亲就必须有强烈的天生性，如果他，竞争就就是父亲的天生性一般，如果在家庭中，父亲只是善良，却没有力量，就很被孩子认。

我在广州工作室里曾经讨论过竞争的话题，当时的，工作室的曾洁文老师，她听了一个故事，在一个家庭里，母亲提出了离婚，结果儿子对父亲说，你没用，你被妈妈抛弃了。

不过，工作室的另一位老师黄玉说，其实，女人之间的竞争也是一样的，她有两个女儿，她们常常会这样说的话：“你比我好”，“我打败了你”，“你不如我”……

所以说，不仅是球场是竞争场，社会中处处是竞争场，家庭也一样，就连亲人之间也存在着激烈的竞争。

我们都可以想象，如果一个篮球内部不允许竞争，那如果去看到一种篮球时，这个球队或许会起来很团结，但战斗力会成问题。对于家庭的竞争也是，我们可不用去批判它，而是去尊重竞争的价值。

其实，我们会发现，在激烈的竞争中，我想比你想强，你强我想比你强，我们都想让对方，所以在能力上不断地上升。

同时，在充分展开的竞争中，我们的人性会完全展开，当人性被全面展现时，我们就可以去完善它。

例如奥尼尔和科比，因为竞争球队大的位置，导致湖人王朝破灭。他们后来虽然很后悔，多次在众面前表达了对对方的肯定，最后是他们和解了。

像勇士队也一样，他们上一个赛季，如果不是球队的防守核心队员格林缺席赛，另一位球替其替补，他们也会夺冠。但是，上了赛季的失败，让每个人的问题得到完整暴露，后来格林学会了控制坏脾气，库里也学会了一直保持专注。

王者之路是不会容易的，冠军们必须经历失败的成功，在这些淬炼中，他们的人性会变得完整。

我很佩服詹姆斯。

他能及时调整自己，对老骑士队失望后，迅速做出了两个重要决定。第一个决定，加入热火队，和球队冠军。第二个决定，加入复仇团队；第三个决定，当热火队让他失望之后，他又重新冠军队，和库里欧文、勒夫建了新的冠军球队。这些举动他绝对需要勇气。

他能持之以恒的、精进、科学地训练身体，让自己一直拥有大伤，一直保持着可比的竞技状态，这是极好的球员。

他的篮球智商非常高，他会帮助球队寻找队友，篮球战术，像教练一样。

他虽然失去了太多的顶尖高手，但他情商极高，和这些人成为了朋友，所以，他是 NBA 球员中最有话语权的人，就像是工会领袖。

他还会特别去经商，开了很多公司，是最懂经之道的老板。

在慈善上，他也会投入大人力，重新回到骑士队，他在美国克里夫兰市的数育业捐助超出了4000多万美元。

他的家庭幸福，至今没有传出什么被真实的绯闻，孩子们的人情发展也非常好。

……

所以说，他不仅是球场上的国王，也像是人性完整展开的人。虽然他的球队打的篮球不流动，他在关键时刻也能赢的球迷，的性竞争，是让他让去人性完发展开的一个重要力量。

虽然，在加尔韦的《身心合一的奇迹力量》里，太过强调“身心合一”，忽略了自发性在竞争中的直觉也是，但他也在书中说明了竞争的重要，里面有一句话是这样的写的：竞争是最好的合作。

也许，社会的一切，竞争是常态，因为家族、文化差异更容易吞若吞噬，但我们真实认为，在激烈的竞争里，充分展现了你的个性，这样的你才会发现自己到底是什么样子的。

# 今日得到

最后，我们来总结一下，今天讲的主要内容

+   第一，“身心合一”的确能创造不可思议的奇迹，但竞技场上的王者，其实都有自我其他的霸气，他们会强烈地追逐“我必须赢，我比你强”的状态。

+   第二，追求“我比你强”的竞争，是人的基本需求，它在竞技场、社会和家庭的竞争里都存在。
