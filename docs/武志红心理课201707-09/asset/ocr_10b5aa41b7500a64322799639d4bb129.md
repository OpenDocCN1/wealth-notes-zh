# ——→找到适合你的回应

我在留言里，观察到两种现象。

第一，我说自己有些敏感，忍不住就会多写，而他们说这样很好。

第二，有朋友提了问题，就非常希望我能够回答问题。

这两种现象中，在说明同一个道理：“我”发出了声音，就希望要到一个好的回应。这里的我，就是指我们心中的那个“自我”。

如果说，自恋是人类最本质的需求，那么这个需求衍生出来的，也是非常直接和本质的需求，就是当“我”发出了声音，这声音可能表达是、欲望、需求，也可能就是快乐的分享，“我”都希望，能听到“你”的回应。

“你，这样的‘我’存在。很多哲学家都表达过这样的意思，意思是，“你”给出了“你”的回应时，“我”才能确认，“我”是存在的。

所以，想完善自我的朋友，可以看到这个最核心的需求，对他人，都需要走在我们的关系中，借助各种好的回应，来完善自己。

关于这个问题，到了专栏的第三章内容，讲“关系”的时候，会更细致地来解释这一点。

今天我们先来看看，什么是好的回应呢？

在这周第三篇文章《自我的组织力》中，用户“磊磊”的回复很精彩：

> 自我组织力的表现还可以用这样的一段话来说解：

弟子问：“师父您有时候打人、骂人；有时候对人又彬彬有礼，这里面有什么规矩？”

师父又说：“对待上等人直指人心，可打可骂，以真面目相对；对待中等人多劝解、要讲分寸，既受不起打骂，也受不了太多好话，上等人能指能调，中间人不能指不能调，下等人不能指不能调，只能用好话。”

这段话非常有道理，但比较可惜的是，还是分了“上等”、“中等”和“下等”的人。
