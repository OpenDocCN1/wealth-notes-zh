# 复盘：关于“自我”主题的回顾

你好！今天周五，是我们课程第二章“自我”的最后一篇文章。我来做一个共一周四内容的复盘。

先回答一个小问题，周一的文章《真实和自我答案》中，讲了两位学生“完美七天”的故事，有不少朋友留言问：他是怎么做到的？

在这篇文章中，我们讲到了这个过程，关键是四句话从他心里升起：

> 终于可以不学习了！
你其实有很多爱，不喜欢我也好，那是你的事。
你爱我也好，不爱我也好，那是你的事。
我就是我！

前三句话，让他放下了三个重要的外部评价，放下后，他就找到了自我。

还有一个就是他复盘，他回忆，在这七天中，对父亲没有丝毫不敬，也没有对他们彻底屏蔽似的。但是不任然，是整天在家吃睡觉的，所以这选择很专注，而这也让他放下了父母的外部评价。

选择性注意：指视觉系统有时每刻都会收到大量信息。注意过程需要选择重要的信息进行优化加工，注意其中一些信息，抑制其他信息。通常来说，就是在外界很多刺激中，只是注意到某些刺激，和刺激的某些方面，而忽略了其他刺激。

留言中还有很多人问，做自己会不会不太私，会不会让别人有所为放，这个女生的故事看似有点争议，在七中，他故事慢慢，但并没有伤害任何人。在七中，还有很多朋友，怎样才能找到感觉，做回真实的自我。

这样的话，可以为试一试完整地成完本周任务的方法：列出十件想做而没有做的事情，并定一个完成它们的期限，在规定期限内完成它们。

这个作业，是我从一位同行那里学来的，我的文章《跟着感觉走》，成为自己的方法，并讲述了她为一位女士Anne的微信公众号“了为红大”更新了这篇文章，感兴趣的朋友可以去看看。

Anne给自己的十件事情都不是大事，他就可以立即去做，例如吃一餐海香鸡、泡、清、一个三明治如一香海红。这个未完成的愿望完成后，本来想自她，感自己不仅活过来了，甚至个人都变了，她决心痛快地完成这个。

愿你们都能体会到成为自己的感觉。

# ——“自我”主题复盘——

# 1.衡量自我的五个维度

谈到自我，就必须涉及两个方面：如何觉到自我，如何认识他人。我在第一节介绍了我是如何识人的。

在三篇文章中，我介绍了我自已理解的“衡量自我的五个维度”：自我的稳定性，自我的灵活性，自我的疆界，自我的力量和我的组织力。

自我稳定性，讲的是在关系中，一个人如何能保证“我”不崩塌；

自我灵活性，讲的是关系中，如何敏感地觉到“你”，并调整“我”。

自我力量，是“我”的事；而自我疆界则决于对“你”的感知。

自我组织，讲的是抗击力，特别是，自我遭受，一个人能压和以多快速度重新组织起一个新的自我。

这个五度中，稳定性，灵活性，疆界和组织力都可以变化，而自我力量似乎是个人以改变的概念。不过，这也许是人人。唯一断价更值：699250

在这周的问中，我特别讲了“我如何识人”。因虽然有理论，但识人才是识人时的一直法，其实就是凭感觉。
