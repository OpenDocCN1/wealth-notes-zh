# 自我01 | 自我的稳定性与灵适度

我们这一周的主题是“衡量自我的五个维度”，今天是第一讲“自我的稳定性与灵适度”。

首先说明一下，自我的五个维度，是我自己的一个经验性总结，不是严格的理论构建。

在这个专栏长达半年的准备时间中，我曾经犹豫过这个专题的内容，是讲我的个人化总结，还是介绍一个学理研究的学术资料。也就是：介绍大众的灵论（本文有补充资料）。多次犹豫后，我还是决定，就讲我自己的经验性总结。

关于如何知识的，我先不说，要么关系。乍周四周五的问答时间给大家分享，它是更有个性化的东西。

# —— 衡量自我的五个维度 ——

接下来介绍一下我总结的，“自我的五个维度”模型。它非常简单，我在理性衡量一个人的时候，会从下面的这五个方面入手：

+   - 自我的稳定性。分数越高，代表一个人的自我越稳定，越结实；分数越低，代表一个人的自我就越脆弱，越容易瓦解；
- 自我的灵适度。分数越高，代表一个人就越容易看到自己的自我；
- 自我的境界。一个人会将自我延伸到多大的空间；
- 自我的力量。一个人的力量程度，他是否有澎湃的力量；
- 自我的自知力。一个人能不能清醒地看自己的自我，特别是，在高压下情况下能否及时地调整，当自我被打碎后，能否得及恢复。

我会分成三篇来讲这五个维度，今天讲的是自我的稳定性和灵适度，明天讲自我的疆界与力量，后天讲我的自知力。

# —— 自我稳定性 ——

现在我创办的“心本汇”心理咨询中心，已经发展到北京、上海、广州、成都、厦门等咨询师，而我面试的咨询师，有数百位。

经常有人问我，你是怎么面试咨询师的？其实，除了专业方面的考查，我还会对一个咨询师的人格做出评估。我评估时最看重的两个标准，就是看一位咨询师的自我稳定性和灵适度。

关于自我稳定性，如果打比方的话，它主要就着看一个人的容器是不是结实。

一个人的自我，有外壳，也有内在。而自我稳定性，主要看的是，这个人的自我外壳是不是结实。

精神分析师做咨询，父母要做孩子的容器，老师要做学生的容器，咨询师要做来访者的容器……

这个容器指什么呢？就是对方的情绪，也包括活力。

当来访者有强烈的情绪爆发的时候，你作为一名咨询师，你的自我能不能像一个结实的容器那样承载住，不至于被来访者的情绪给弄得崩盘崩溃，让容器破碎，或者出现大的裂缝。

所以，你会发现，自我的稳定性，对一位咨询师来讲有多么重要。

容器的外壳，是有不同质地的。它最好是一层坚韧有弹性的皮肤，这样不仅可以承载住情绪和活力，而且还有足够的敏感度。

有些人的自我虽然很稳定、坚定，但他的自我外壳，不像皮肤，而像是一些过于僵硬的东西，比如树皮、石头、钢板或厚铁皮。这时候，稳定是有了，但却缺乏敏感性与灵适度。

你可以问问自己，你的自我外壳，是有弹性的皮肤，还是树皮、石头、钢板或厚铁皮，亦或是其他的是什么隐喻。

自我稳定性低的活，就意味着，一个人的自我外壳，有了大裂缝，他的自我甚至是破碎的。

我听过两位来访者和一位朋友，都讲过同样的比喻：

我早上醒来，我都发现我的心动（即日）碎了一地，然后我找了一个破丝网，把心的破块捡起来，放到破网里坐着，拎着它去上班。
