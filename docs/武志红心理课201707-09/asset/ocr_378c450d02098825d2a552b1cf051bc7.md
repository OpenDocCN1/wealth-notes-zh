# 问答｜别去切断沟通和探索的可能

问答 | 别去切断沟通和探素...

每周一四五，是我们彼此互动问答的时间。

今天是第一次问答，我也想借这个会跟你多说几句。

第一，每周目的预告很重要。在那里，我会设置一些心理学的概念，比如我们第一周的结尾是：“写下来你常说的一句话”。这样的练习，对帮助你觉察自己、了解自己是很有价值的。

第二，我希望在每期的内容后，附上“今日得到”的部分，帮你们提炼整篇文章的核心知识，也希望你来紧扣这个主题，跟我展开精彩的讨论。

第三，我会尽可能地回答你的问题。一些经典的问题和故事，我也会提上来，和大家一起分享。

接着，我来说说专栏上线以来，和看到留言之后我的感受。

我们这次的主题是“自我实现的预言”，也叫“自证预言”，说的是一个人常说的断言话，可能会成为他或自己的生命预言。很多朋友早就知道这个概念，不过看多我们的课程的解释，还是触动到大家。很多事情常常是这样，一些真理、至理虽然听起来简单，但是真要醒悟的话，需要我们从不不同的角度去了解它、触碰它。而我只是在提供我作为一名心理学工作者的角度。

很高兴看到，大家在留言里不仅分享了自己学习课程的感受，还结合自己的故事给我们提供了很多不同角度的思考，特别是第三篇内的家——《改变，从体验开始》，更是引来了大家讨论的热潮。

《改变：命运，从体验开始》

其实，在这一周的课程里，还有一个内容特别重要，就是我们剖析了自己的两个表现——“我是对的”、“我比你强”。很多粉丝也留言被触动了。

不过，就我们的感知而言，大家对自己状态的核心，它复杂而深刻，需要更丰富完整地展现。关于这个，在后之后的课程里我会慢慢帮大家深入了解。

我特别关注在我们本周预告里布置的作业，就是找出你最说最多的一句话，和别人认为你最说得最多的一句话。在这个部分，大家的回复都让我印象深刻。

我挑了几个我印象最深的留言，略做点解释。

# —— 每周问答 ——

我常回答别人说的话：好像有（好像没有）；肯定不行（摇头）；不可能。我自己对自己说的：没本事！万一呢……那我怎么办呀；好慢！没本事。想来我做的事风格你也看得到，就是忧患意识，我自己觉得做很难说没可能。很多事情下去尝试一下就知道了。可很多事第一次遇到阻碍了，就不去想办法绕开，可自己单凭的赌性而不采取行动，不从实践中去摸索。可是怎样解决呢？可能得从开始学习机会、老师的方法，就给自己一个重新做人的机会，我改变。我要清除我自己脑子里的消极的、腐朽的观念。我惯常对自己说，这事我先做再说，给他成就有成呢。

+   - **武志红**

其实，通过观察自己常说说的话，可以清晰地看到，自己的优来靠事断。而且我猜，“打样”你可能也是受了罗胖的影响，知道罗胖提倡的是“目标、行动和方法”，而与“站和意愿”则。“前者让人导向行动，并在行动中变得强大。后者导人退到不可。”所以，可以从倒回去想一下，目标”、“行动”、“方法”这三件事，你做没做到呢？

“我也不知道”。这是我常说的一句话，我也知道很多东西，不懂很多事情。这种真正的心理状态能够改变吗。不知道的事情就是不知道啊。怎么回事呢，老师。

+   - **武志红**

“我也不知道”这是一句特别值得品味的，你会发现它意味深长。首先容易看到的是，这很真诚啊，不知道就是不知道，不过这一点乍一看去，不知道它也是说得最多的一句话，甚至常常是在谈中断的沟通和探素。

为什么要切断沟通和探索，我猜有两种可能：

第一，你无形中认为，完美的人知道该怎么做，而不知道是一种羞耻；

第二，也许你的家庭中，你的童年里，总有人要过度询问你，要去确认你的想法，这让想不通你，我可以用‘我也不知道’来阻挡，‘我不知道’这样的两个字既打入了，而‘我真的不知道’是给对方说的，而‘我也不知道’是说给自己听。

也许第二种可能性要大一些。如果是这样，那你就已经认识到：这是多么讨厌别人的人设，你可以理直气壮地拒绝对方。

我仔细想了想，最常说话是‘我不感兴趣’，说这话的时心里想的都是我确定不感兴趣。这让你有被入侵感，我是用我直接说，说我不感兴趣，我失去了主动性，变得自闭了，也有恐慌。想要改变自己时候又觉得无从头下手了。

+   - **武志红**

“这’一无助’在发挥作呢，包括你最后那句 ‘’在想要变自己的时候又觉得无从下手了。

+   - **武志红**

我最常说的话是：古人有今天保佑，我就是那个很幸运的人！结果我做事总是很顺利，运气一直很好！开始我认为就是我的生辰八字好，命好！现在我知道了，不靠的不是我，是预言也断的自我暗示导致的结果！

+   - **武志红**

这真是一个很好的分享，希望“那”你可以继续分享，这份积极的自我实现预言，是怎么来的。

想了半天，我也没想来我最常说的一句话是什么，打电话问爸妈，一分钟找不到，我打说我电话怎么样，你觉得听哪个好听？放下电话，突然就想起来了，我常喊的话：可以啊、挺好的、随便，怎怎去啊！哎，随便、随便、随便，没主见啊！以后不说这该话，可说啥呢？

+   - **武志红**

“都好，随便，怎么做都行”……这些话是说我别人的，它们是彻底远离你的内心，所以你什么都定。

所以改变自己经常说的话，就能调整甚至是改变自己的命运！当我看到自己“的”时，变一个倾向到我想到的一个话竟然是“我做不到”。但我又想否认，我能找到他的能想到我朋友里的词。很巧合，然后我在想我和那些人的比较，比较亲近，就只是没有两三个人。感觉也一般。这倒是给自己提了个醒，谢谢老师。

+   - **武志红**

这样的自我接纳，就是一个重要的开始。
