# 关系13| 既可以A，也可以A

我这一周的选题是“关系你可以A，也可以A”，这是第二讲。

昨天文中，我们讲了当看到A的时候，也隐含着看到A了。A讲了一个故事，和七夕的女性找到了B，积极向上的美国家族诞生了幸福的孩子。

我这个人觉得，这个真理虽然简单直接，要想真的形成这样的眼光有问题，还是很有必要的。以今天，我多讲一些故事，来举例说明。

# 越外向，越内向

我曾在广州电视台参与做一个节目，是明星们的一个秀，其中会用到心理学的工具。其中有一个，上节目的是个超级外向活泼泼的明星，上节目之前，她在广东一个影视城录制影片，然后在节目之后，昨天晚上，她在影视城外的酒吧跳舞，最后几百人围着她一起跳舞。她就是这么热情，有感染力。

节目中，有一个心理测试环节“房树人”，就是测试者要在画板上画一张画，画上至少有一个房子、一个人和一棵树，其他随意。

![](bbox=[0.2, 0.27, 0.8, 0.33])

房树人测试（Tree-House-Person），又称屋树人测验，是投射分析技术的一种，主要用于治疗自闭症患者，始于John Burch的“房树人”测试，这一测试要求测试者在一张纸上画出的房、树、人，来分析其家庭关系、事业、人际关系的认识和对自己的看法。而后的论述来源于荣格的意识、个人无意识及集体无意识。

+   树：投射象征，代表安全感；
房：投射自我家庭，象征生命能量和支持系统，和事业和学业；
人：投射自我形象，以及人际沟通模式。

以前参与节目的明星，大概是受过一些绘画训练，画得很好看。这位明星我应该是没有给什么绘画指导啊，画的是火柴人，就是把人画得像“火柴人”这个样，整幅画也出奇地简单。

这么简单，她画的问题，她的问题也一目了然。节目中，她的咨询伙伴说，你说的房子只有窗户没门，那别人怎么能走进你的房子？这意味，这可能意味着，你的心可能向任何人敞开的。

这个解读她立刻受到这位明星，她痛快地一下趴到了画板后面，说：你们这些医生太可怕了，画和你们说，了这个动作和这些话，连着看活泼外向开朗的明星，非常可爱。过了一会儿，她把画板向后放出来。她说，从来没有人有把我画的心和人敞开的，我没有和别人说过我的心。

这次节目让我印象非常深刻，因为我恰好也有一位超级活泼、外向开朗的朋友，我觉得他的十分打十分都不够，如果十分是满的话，必须给到十二分或十五才行。

我后来听了这位明星的故事，问她，是不是也这样。她沉默了一会儿，对我说，是这样，你看我这么信任你，我什么时候给你一个过我的心？接着，她向我透露了一个小秘密，让我非常震惊，因为她说漏的这个秘密，在我看来，实在没有保密的必要——她是一人。可是，这是她这辈子第一次把这个说出口。

我当时感慨，越外向，越内向。反之也成立，比如说我自己就是一个很内向的人，但我很容易对人心敞开心胸。

# 越快乐，越悲伤

我有一个朋友，她是一个特别爱吃的人，我们读本科的时候认识她，感觉和她在一起时，她简直天天二十四小时都在笑，并且非常有感染力。

前几年再见到她，她还是特别爱笑，但已经那么老了，有时候脸上开始有一些忧郁，于是，我和她起她读本科时的那份爱笑有感染力的笑。

她也记得自己那时的笑，觉得本科四年，她笑得最开心的时候。我问她，那时让你觉得最开心的事是什么，你能多说吗？我这个问法，是职业病，是一种具体化的问法，不是为了寻机细节。因为魔鬼藏在细节，才说寻细节。

她想了一会儿，发现奇怪的是她好像都记不起来了，甚至整个本科四年的记忆，都好像是隔着一层，像蒙上了一层薄薄的塑料膜一样，不可触碰。

和她逐步深入聊天，我发现在她那高中时期的最亲近的人际关系，之后的她陷入了巨大的悲伤中，然后她对自己说，不能沉沦，要振作起来，本本，她也确实振作，而之后她越笑越深，她做到了快乐的高度。

原来她的笑，是用来疗愈悲伤的。

越快乐，越悲伤，这件事在很多著名的笑身上都有体现，比如沈殿霞、卓林林、憨豆先生，他们都是过世的喜剧师。梁永言曾经说过自己是“微笑抑郁症”，因为他脸上虽然有招牌式的淡淡的笑容，但他却是一名抑郁症病人。

> “微笑抑郁”（smiling depression），并不是“一种精神病学的诊断标签”，它是一类抑郁症患者对自己病情的反应模式。

这是一种非常典型的抑郁表现，当人们在别人面显得很开心，而内心却非常沮丧。表面看起来非常外向积极，能力人际关系的很好，所有人的都觉得这个人充满了价值，结果他却孤独，就像很多人在朋友中很受欢迎，可却发现自己一个人的时候经常感到悲伤、上当。他们看起来都在笑，但实际上的每天都在低落的情绪中挣扎。
