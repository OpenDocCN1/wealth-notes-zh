# 关系17 关系层次进化的关键

我这一章的主题是一元、二元和三元关系，主要是讲“关系层次进化的关键”。

关系层次进化有三个阶段：一元关系，二关系，三元关系。

# 从一元到二元的喜悦

我的一位来访者，是一位非常自大的企业家，他口口声声，能说能道，这一切都源自他的那种强大的、充满自信的态度。他的意思是希望他每一方面都是公司里最优秀的。

他来我咨询时，他彻底地在以自我为中心的一元世界里，他可以说几乎没有两种情感：希望实现，他的心态被打击，他就难过。

也就是说，他只能感受自己的感受，对别人他只是头脑上想着对别人好，但感受不到别人的感受，无法和别人共情。而且他对别人的感觉在于“在他的基础上，必须在对方顺他的意思的前提下”。

通过长期的咨询，他对这个世界的认识丰富了起来。这期间，他爱上了一个女孩，发动了几个团队的攻势，而女孩始终拒绝他，最后他崩溃，女孩还是温柔而坚定地拒绝了他。

他再来看我时，他来讲咨询，看上去非常憔悴，但他说她非常难过。但咨询中，我多次感到明显的喜悦，而且我觉这份喜悦绝对不象他的，所以他看似他受到他最爱的女友的拒绝，是我说我感受喜悦是“我”的感受，我开心得不得了。我听到这个消息后，我不知道为了什么，我听到这个消息后，我开心得不得了。

他说了这句话，他就开始大笑，而且持续了很长一段时间，有时停不下来。后来，我们探讨时，他还是想忍不住笑，经过探讨，我们认为是他自己开心，是因为他终于感受到，世界上不只是他一个人的中心，世界上还有另一个人独立存在着，有他自己的感受和意志。

就像有他自己的关系，世界进入了二元关系的世界，是充满喜悦的，他在公司里不再是孤家寡人了。

这是一个进入二元关系的重要条件：有人没有听你的意思，于是直接告诉你，别人也是有独立意志的。

但这个更为重要的是，虽然女孩一直在拒绝他，但女孩表现得既温柔，尊重他，也没有攻击，这让他也意识到：她不仅有独立意志，她还友好的，善意的。在另外一个，这是一个不同于关系中的根本原因。

人们总说，净化就是，你让别人展现独立意志，同时又是真心对你，这就让你明白了世界上有其它中心存在。

# 婴儿与妈妈的二元关系

对于一个孩子而言，他的心灵发展也是沿着这样一个路径：从最初的与母亲的一元关系，进化到和母亲的二元关系，乃是关系的三元关系，对婴儿的成长来说，母亲是好的，善意的，这是更关键的。

可以说，每个小婴儿都是在孤独的一元世界中，他只能感受到，自己的感受是唯一中心，婴儿非常脆弱，最初自我满足和自我满足能力都是零。这时候世界他们而言非常陌生，是世界“好”的：被满足，他们就会认为世界是“好的”；被拒绝，他们就以为世界是“坏的”。这时候自己与世界的关系，也会逐渐体验到充满敌意的。

当“坏的、敌意的”体验太多时，婴儿就会使用一个极端的处理方式保护自己：世界是好的，而我以外的世界是“坏的”。这就是婴儿的一元世界，而老子所谓的“复归于婴儿”是“婴儿”是“婴儿”是“婴儿”是指婴儿是“婴儿”，这是婴儿。

相反，当“好的、善意的”体验多时，婴儿就会感到，世界是“好的”。自己也是“好的，友善的”。通常到了六个月后，发现自己其实是一个有独立意志的存在，同时母亲其实也有一个善意的“好的”，于是孩子就可以接受：世界有两个中心，一个是自己，一个是妈妈。

二元关系的基础，是建立在世界有两个“好东西”的基础上。

不过，实际上，二元关系也存在着严重的分裂，无论妈妈照顾得再好，小小孩仍然会受伤的时候，这时候妈妈出现矛盾，妈妈有两种，一个是好的妈妈，一个是坏妈妈；孩子有两个，一个是好孩子，一个是坏孩子。

那么在好的情况下，孩子倾向于只意识到妈妈和好孩子，忽视坏妈妈和坏孩子。而当妈妈对孩子比较好时，孩子就会忘记妈妈对孩子不好的一面，妈妈和好孩子是一回事，妈妈和坏孩子是一回事。

这意味着整合，意味着关系中的两个人都得到别人认可的存在，也能呈现自己的完整存在，是最好最成熟的二元关系的境界。

不过，在二元关系中，去看待彼此的“坏”，都是极具挑战的，特别到别识别的关系才能做到。比如你一开始对别人的关系说我是好，那么这时关系就很有张力。对方会对好，要么攻击你，或者你的关系会陷入坏。但如果他选择了一段稳定的，开放了，关系变得深厚了一些，甚至已经亲密和谐，只要一句了，这时表达变得容易很多。

总而言之，在二元关系中，去看待“坏”是有难度的，对小孩来说是尤为如此。需要去构建一个三元关系，去化解关系里的张力。

具体的表现形式是，孩子为了和妈妈保持好的关系，会把妈妈看成比她对人更好的，而把“坏妈妈”投射到第三方身上，比如父亲。

# 孩子与父亲的三元关系

作为母婴关系外的存在，父亲是所有孩子的第一个原型。所以达尔文说：父亲是所有女人的敌人。这样的故事很多，敏感的父亲肯定注意到。

有一次，我讲到达方面的话题时，结果下面有两位爸爸，他们都说自己曾经发现了父亲太讨厌了，一个孩子：爸爸，对不起，你为什么要打我？

这时父亲要转移的原则，应该是先向孩子道歉，孩子证明自己是独立的，然后再让孩子知道，自己是有独立意志的，更重要的，父亲要抱着孩子的手，带他走进外部世界，爸爸切记：作为父亲，你就是孩子的最早外部世界。

当父亲和孩子关系中的“好”变多了，孩子对父亲的观感变好，关系中的“坏”变少，于是就像整合了，看到一个好父亲，自己也是有坏有坏。当孩子能看到，在和自己父亲的是一个三元关系，自己、母亲和父亲，都是有好有坏，但是是善意的，同时的都有独立的意志，这意味着，孩子真正进入到了三元关系的世界。

关于一元、二元和三元关系，我们可以有一个形象化的理解：

> > 当你觉得，世界上只有你好的，这就是一元关系；
> 当你觉得，你和另外一个人都是基本好的，这就是二元关系；
> 当你觉得，你、你爱的人和你竞争的人，都是基本好的，这就是三元关系。

这样听起来简单，其实我一直在说关系的好，但同时又需要强调的是，关系里是用来处理我们内心心灵中的“坏”的。

一个人的世界，必然如地壳同一，而一个人的内在关系，容易变成和地壳一般分离。所以，人需要从一个一元世界，进入二元世界，去爱上一个好人，建立一个好的人，替换一个人心中“坏”，才能走向孤独的“一元世界”。
