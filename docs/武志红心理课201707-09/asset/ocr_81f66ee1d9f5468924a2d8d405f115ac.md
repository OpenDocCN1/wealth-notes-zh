# 关系02 | 认识关系奥秘的第三只眼

+   - 武志红

我们这一周的主题是“关系，即命运”，今天是第二讲“认识关系奥秘的第三只眼”。

先从一个故事说起：

多年前，我租了一套房子住，房东多次叮嘱我：别把你不要的那些垃圾家具放到我家来。

后来我看房子时，发现这套房子的一个储物间里，堆满了不可能再使用的垃圾家具。看到这个细节时，我忍不住笑了一下。知道他的那个说法，说的是他自家的眼睛，可是他的孩子确实说决定租了，他后来说话也没有兑现，我还继续住了一年。我再次重复他的话，他还是没听。

我想，这是第一次，他是被我驳了，我想我说的这个太白了。我看着他，我想对他说：您的孩子是否对您说过至少一百遍了，老爸，你的控制欲太强了！我这么做老态，有点失敬，但哈哈哈哈哈大笑起来：是啊，是啊，我不管这么多了，相信我。

我使用的这个概念，心理学家鲁昂曾称他为“投射性”，意思是，当观察者两个人之间的关系时，可以看出来，观察者对之方这么说的时候的投射，然后把它指出来。

用我这一周的术语来讲，就是说一个人当下心想和去构建什么样的关系模式，是因为内心有模式，是这种内在关系形成的。而内在关系模式，是指内在里形成的，并会反映在他生活中的方方面面。我们主要谈这一点。在真切地看到这一点时，在看人際关系的互动时，就会感悟很多。

例如我这位房东，他说，别把你不要的那些垃圾家具放到我房子里。但我根本没有放垃圾家具，他会自己做，他看起来说的很幽默，其实说的是他自己的。

特别是当他叮嘱我怎么使用那些家具，包括他何时说，他表现出了强烈的控制欲。那一刻，可以说，他建立和他控制我的关系。这可以推理，他在别人互动时，也很容易试图去建立这种关系，特别是他的孩子。肯定是深奥其苦，不知折磨了多少年了。有了一些推理后，我才敢那么肯定对他说：您的孩子肯定对您说过至少一百遍了，老爸，你的控制欲太强了！

当然，虽然说是推理，但对我而言，已不再是一个简单的，意识层面的推理过程，它是一个闪电般迅速发生，这是经过长时间锤炼的结果。

这份锤炼，首先发生在咨询室里。

精神分析技术中有一个术语：“投射性认同”，意思是，在咨询过程中，咨询师一直像一个百宝箱，像是悬浮在咨询者的空中，第三只眼一样在那里旁观着，咨询师和来访者之间发生了什么。

在观察时，要有一个基本意识：来访者试图向咨询师构建关系，和现有的人際关系模式的关系模式，他童年时和亲人关系模式，以及他现在和他人构建的关系。

这种对应关系，常像尺子一样精确。当我们没有意识到它时，它就依借着命运一般的力度。

我的一位朋友，曾介绍他的一个女朋友Linda给我认识。Linda在一家很大的外企工作，她说她有一个奇怪的毛病，她是不能和女上司共事。不管是上的女上司，离职或平调，不做她上级的上司，就会导致这位上司或她离职和关系。可是，少数的情况下，Linda是旧上司又来的直接领导后，她们的关系又会陷入莫名的敌对中。唯一的解释是：Linda有投射性认同。

当她处理她的童年经历后，就发现了一种精妙的对应：她出生后，一直住在她姥姥家，姥姥对她很好。五年后，她回到了父母身边，这时父母还生了一个妹妹。
