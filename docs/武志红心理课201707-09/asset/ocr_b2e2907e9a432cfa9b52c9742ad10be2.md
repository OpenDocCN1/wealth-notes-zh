# ## 潜伏期

接下来，我们谈论弗洛伊德性心理发展理论的第四阶段，潜伏期，是6-12岁期间。

# ## 生殖期

和3-6岁的性器期非常不同的是，青春期的欲望，决定隐忍了，几岁的孩子，因为没有明显的第二性征，他们的种种表达可以被人当做笑话来对待。

但是，青春时期，青少年的第二性征会显著凸显，身体开始发育，男孩长出喉结、胡须，女孩的“第二性”更为明显，还进一步经期。这些都在提醒他们，他们的性别是什么。

还有特别重要的一点是，在体型上，青少年也逐渐接近成年，这意味着，他们终于有了可以平等待同性父母的生理条件。

原生家庭，其实是孩子人性的练习场，我们说孩子来看孕育家就是家的一个价值，6岁时，孩子主要是生活在家庭里，他要吸收营养，他要自主控制排泄，他还学习竞争与合作。

所以，让孩子在家最好是提供一个抱性环境，这样孩子在原生家庭中相对稳态地发展自己的能力，就像我们之前提到过的德尼科特的那个标准池——世界准备好接受我们的本能的那个海滩池。

当然，孩子也必须学会尊重界限的存在，其实就是学会尊重别人。也就是说，既可以获得自己的，做自己的，又能懂得尊重别人。这样的话，孩子就在原生家庭的关系场中获得了最初的宝贵经验，然后，就可以进入社会大熔炉了。

6岁后，孩子要进入学校了，这时学校和父母也是把他们“视为”孩子，而且会对待和保护，但再也不可能像在原生家庭那样，可以得到很好的抱性环境。

12岁后，孩子的身体和智都，都能向成人发展，他们的身体显现出来的能量无穷，如果处理不好，就会进入所谓的“残酷青春”。

如何能比较好度过青春期？我认为当然首先是在一个有抱性环境下长大，这样成长起来的青少年能发展出自己的力量，能懂得尊重别人，简单来说就是，能竞争，也能合作。

如果说，原生家庭是一个人人性最初的练习场，那么生殖期，也算是一个练习场，但已经是最近社会人的练习场了。

离开这个练习后，一个人就要进入真实的社会，在其中改造自己，去寻求自己的价值，去成为这个社会有基本竞争力的人。

# ## 小结

到这里，我们就讲完了弗洛伊德性心理发展的五个阶段，也是通常说的人格发展理论，现在总结下这个理论。

弗洛伊德认为，性能能和攻击本能，是人性的两大原力。因感受的变化有五个发展阶段：

+   1. 口欲期，1岁前，快感中心在口腔部位，这一阶段要发展出基本信任，也就是这个人开始相信他，外部世界是愿意满足自己，让他吸取部分的。
2. 肛欲期，1岁到3岁，快感中心在肛门部位，这一阶段要发展出自主感，去控制大便，这是孩子按自己的意图，也能聆听他对自己以及各种创造的态度，我认为这对其实是已可以命的全能感的去态。
3. 性器期，3岁到6岁，这一阶段孩子发展的是竞争性与合作精神，也是超级形成的关键时期。
4. 潜伏期，6岁到12岁，开始变得对同性更感兴趣，这一阶段特别要学习的是和同性伙伴的合作关系。
5. 生殖期，12岁到20岁，也即青春期，性能能和攻击本能都爆炸般呈现，青少年开始真实地学习，如何合理地展现自己的能量。

也许有朋友会疑惑，今天讲得不够过瘾，这一是因为没有展开，二是因为弗洛伊德的观点，也是在前面三个阶段的。我们关于弗洛伊德的人格发展，也就是性心理发展阶段的介绍，就进行到这里。
