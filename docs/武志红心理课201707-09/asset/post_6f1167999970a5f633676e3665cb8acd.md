
# 关系07 | 全神贯注时，感应就会发生

**武志红**

今天是周四，是我们专栏本周的加餐日，我们来谈谈“全神贯注”。

昨天的内容，我们谈了心灵感应，介绍了温尼科特的一个术语“原始母爱专注”。

原始母爱专注（Primary maternal preoccupation），是在婴儿与母亲关系的早期发展阶段中，“足够好的妈妈”充分提供婴儿所要求的一切，母亲依据她的孩子需要的变化而适当做出变化。为了适应孩子依赖性增加而要求逐渐减少，为了照顾孩子对母亲所要求的变化，温尼科特特意用“原始母爱专注”这一词来表示母亲对儿童需要的体会。母亲的全神贯注，是尽着她对孩子的需要，竟像是她自己一个部分的需要一样。

这个概念的另一句翻译是“心中有孩子”。要理解这个概念，可以从相反的例子去理解，就是“心中没孩子”会是怎样的。

我有一位居去小乡镇卖东西，买好多年后，妈妈转身，上班去了，把孩子忘了在小卖部。

回到家中，妈妈发现孩子不见了，根本想不起来把孩子丢在哪了，所幸，小卖部老板是好人，一直在帮妈妈看孩子。这种事发生一次，就够当心了，但妈妈就是忘了把她家弄丢，可以说是“心中没孩子”的典型了。

每年夏天，我们总会听到这样的新闻：父母把孩子丢在了车里。之所以发生这种事，一个重要的原因就是因为这样的父母“心中没孩子”。

“心中没孩子”的人，就好像他们心里谁都放不下的，好像最多只有他们自己。没有任何体系来说，没有人可以代为他们。所以，“心中有孩子”并非那么简单，母亲会一直牵挂着孩子，而孩子发生一些事情时，母亲就会感应得到。那可以通过什么努力，和孩子建立感应关系呢？或者说什么，心中没有他的人，可以去医院建立这样的能和心相印的关系呢？

我认为，办法就是将“全神贯注地去和一个人在一起”，即为“原始母爱专注”的全神贯注，可以理解为母亲对孩子的全神贯注。

我来给你举个例子。我的一位朋友，居住在一个省会城市，很有经济实力，她是我的忠实读者，后来也学了心理、咨询与疗法的一些课程，她心地非常善良，因此成了当地人圈子里的心理热线中心。

她本人是一个焦虑的妈妈，对自己儿子的养育并没有问题，这也是她进入心理咨询的原因。她是一位很焦虑的妈妈，有严重的心理疾病。她不像一般的妈妈，而是一位糟糕的母亲，不合时宜的，这比较严重。

这位朋友以前带小孩时，也是典型的“心中没孩子”，她是个工作狂，会习惯性地忽略孩子，对孩子了解有限，更不用谈心灵感应了。

学了心理学后，她决心改变家里的这个格局。孩子在孙子出生后，她为家里详细地计划，请了三个保姆，还让用心理学知识教他们，要求保姆们对她一样。第一个月因为应问孩子，所以去问了三个保姆，一个原因是她的儿媳妇对婆婆很尊敬，但是不是很信心理学。

孙子出生后，她和三个保姆，全神贯注地注意小孩在家休息。

甚至和动物等生灵，全神贯注也可以产生类似效果，你可以试试。或者如果你有类似的故事，期待你在留言中分享。

# 今日得到

- 心中没孩子，或者心中没有住着谁的人，可以通过努力，去和孩子、和他人建立心心相印的关系，办法就是，全神贯注地去和一个人在一起。
- 全神贯注，和“你在，所以我存在”是一个意思。当你全神贯注地带着爱关注着我时，我也就感觉到了你的存在，同时我觉得我也存在了。然后，我的心神就可以安宁下来了。
- 不仅仅是婴儿需要母亲的全神贯注，实际上，任何关系中，如果两个人之间能有全神贯注的状态，就可能会建立起高质量的关系。

# 问答：“失去自我的迷恋”和“忘我的爱”

**武志红**

你好！今天是周五，是我们本周的问答时间，我来回答大家的一些问题。

先总结一下这两周预告中的调查，上周我们调查的问题是：这个妻子，和谁的关系让你印象最深刻？本周的问题是：你体验过忘我的爱吗？

第一个调查中，大多分享了感人的、滋养性的体验。例如：

和病男子的通信是我印象最为深刻的一件事，当时正值我抑郁四年，他为我打开了一个崭新的、生机勃勃的世界。虽然他们没有交流讨论我的各个状态，但似乎他的生命滋养了我的，我为他的生命打下了根基。尽管后来我们分手了，我还是继续在他为我打开的世界里摸索、前行。十多年过去了，我的世界已经完全摆脱了疾病的困扰，拥有了幸福平和的生活。感谢遇到他，珍惜后来老师以及大家的心路之旅。

本周的调查，本意是想大家关于那两种个人的自我都消失了，然后深深相遇的体验，但多数朋友讲，是“失去自我的迷恋”：

初恋真的很深刻，根本就是他无我，哪怕感到他在电话里说了一句可能的负信息，都使我的心就要停止了，崩溃了。太可怕了，再也没有那种状态了。

不过也有用户分享了“忘我的爱”，例如：

当孩子出生的那一刻，我的心里眼里只有他，我觉得他很神奇，或者干脆就是一个奇迹，当一个胚胎，长成了会哭的、会笑的、躺在身边的娃娃。我突然很珍惜他，甚至想把全世界都给他，这种愿望有特别强烈！在他出头的日子里没有过这种想法，这一刻突然有了……

在我的理解中，“忘我的爱”是亲双方的自我都消失了，这个时候，我的本来遇到了他的本来，自我虽然消失了，但却到了真正的存在感。

相反，“失去自我的迷恋”是以对方为中心，而失去了自我。这时，对方自我极为重要，就相当于是，自己的自我被对方的自我给消了。不过，实际上，对对方这时的体验常常是，自己的自我被对自己的自我消融了。我在广州和深圳的得到小组同学开会时，问了大家这个问题，结果每个人最初想到的，也都是这种“失去自我的爱”。

我不禁让我想到，也许“失去自我的爱”也有重大的价值，就是破坏牢固的自我，因为自我和固恋，就像一个壳那样包裹着我，切断到我和别人的链接，这个壳要被磨裂、被破坏、被敲碎，然后光才能照进来。

想想我自己，有点自虐一样的宅男状态出来，最初就是靠了迷恋的力量。正如鲁米所说：伤口，是光可以照进来的地方。

推荐一本书，名叫《强迫的爱》，是我非常喜欢的美国心理学家苏珊·福沃德的作品，内容关于失去自我的迷恋相关，想要了解这方面知识的话，可以看看这本书。

# 预告：我与你，我与它

这是我们专栏的第十一周，也是“关系”这个大主题下的第三周，我们这一周的主题是“我与你，我与它”。

这是以色列哲学家马丁·布伯的概念，是二十世纪最重要的哲学家之一。

马丁·布伯（Martin Buber，1878—1965），犹太人，出生于奥地利维也纳市，哲学家、翻译家、教育家，宗教存在主义的代表人物，主要著作有《我与你》、《人与人之间》、《两种类型的信仰》、《善恶观念》等，20世纪最著名的宗教哲学家。

《我与你》是马丁·布伯的主要代表作，对现代西方思想产生了巨大影响，已深入到哲学、神学、心理学、教育学以及各门社会科学之中。

马丁·布伯认为，真正决定一个人存在的东西，不是“我思”，也不是与自我对立的种种客体，而是他自己同世界上各种存在物和事件发生关系的方式。基于此，马丁·布伯论述了人的两种关系，即“我与它”和“我与你”的关系。

在马丁·布伯的《我与你》这本书中，他说，关系有两种，一种是“我与你”，一种是“我与它”。

这两种关系的意思是，当我把你看作是实现我的目标的工具和对象的时候，关系就是“我与它”；当我放下了我的预期和目标，而与你相遇，这时的关系就是“我与你”。

我猜你也会有这样的时刻吧，看了一本书，或者一篇文章，一个概念或理论特别深刻地触动了你，你发现：噢，原来事情是这样的。然后再看世界时，发现自己的理解力提升了。马丁·布伯的这本书，就带给了我这种感觉。

他对关系的这个二分法，其实是在说：不管我的目标多么伟大，当我把你视为实现目标的工具与对象时，构建的都是“我与它”的关系。

如果你接受了这个说法，看世界的眼光一下子会变得清晰透亮很多。因为这个世界上无数人或个人，都会借着“我有一个正确目标”的名义，去和你构建“我与它”的关系。

在人际关系中，最常见的，就是借着爱的名义，却干着控制和剥削对方的事。

# 关系08 | 世界的本质，是关系

**武志红**

我们这一讲的主题是“我与它，我与你”，今天第一讲“世界的本质，是关系”。

### 马丁·布伯的《我与你》

我先把书名分享一下我和马丁·布伯的《我与你》这本书。

我在北京大学读本科时，一次去北大图书馆看书，完全不了解马丁·布伯，却莫名地被《我与你》这个书名触动，把它借了出来。

这本书的中译本翻译得虽然有优美的地方，但整体上非常晦涩，我读了至少一两小时，读做下大量的读书笔记。可以说，我是把这书抄录了一遍，而我的读书笔记的字数，绝对多于这本书本身。

后来有一次，我拿我的这本读书笔记在北大的教学楼占座，结果居然发表了，让我伤心了好长时间。

再后来，我在四川日报写心理专栏时，多次提到这本书，这足是对我影响最大的一本书，结集这本晦涩的书学习开始顺畅，常常很通达。不过我刚在购书网站上看了一下，还能再版。

马丁·布伯的哲学，整体上可以视为“关系本体论”。意思是说，世界的本体不是宇宙万物之“你”，也不是“我”，而是“你”和“我”之间，是关系。

### “我与它”，“我与你”

当你将“你”视为我达成目标的工具和对象时，你在我这儿就沦为了“它”，这时就构建“我与它”的关系；

当我放下所有的预判和期待，带着我的全部本来和所有的本真相遇时，这时就构建“我与你”的关系。

马丁·布伯说的“你”是上帝。我通俗一点，个文化语境，当“我”放下我一切的预判和期待，而触碰到它的本真性，那一刻就是遇到了你，也是遇到了神。

换句话说，上周我一直得到心灵魂应，我认为是当心灵感应发生时，那是一种你“不仅是你”相遇，也像他遇到了上帝。

当然了，心灵感应听说着关于神祇，我在之前的文章《打破我的内在比赛》中，介绍了体运动后的“身心合一”现象。这个身心合一，和心灵感应看似类，甚至可能是同一回事，都是大脑和识层面的自我认知消失了，身体和意识层面的认知层次了。我们一旦，构建起“我”和体育活动的个“你”相遇，建立了“我”和体育活动的“我”相遇，建立起了“我”和体育活动的关系。达到“身心合一”时，运动员们都喜欢说，这时候的球“打”入神了。

所以，这一讲不仅“我”的本质显现了，也遇到“你”的本质，同时，真的好像是本性在其中。

不过，我还是要再澄清的是，马丁·布伯来看，我们必然永远是处于“我与你”和“我与它”的双重世界中。为了自身存在，我们不断构建“我与它”的关系，与其他客体为工具这个主体服务，可如果只有“你”这个关系，所以我，所以也要强调“我与你”的关系存在。

马丁·布伯论述说，“我与你”的关系时问，我们只能是偶尔进入这种关系中，而“我与它”的关系是时时刻刻。

不过，一旦进入了“我与你”的关系，那一刻就是永恒。体验到“我与你”的关系真切存在后，再看这个世界，一个人会变得很不同。

### 最好的关系

“我与你”的关系，论述起来不容易，你必须真正体验到，才知道它是怎么回事。对个体个来说，我认为特别重要就是“爱与它的关系论述。马丁·布伯说，不管你有看什么样的预判和期待，你构建的都是“我与它”的关系。

比如说，一个很实际的目标——我想赚你的钱，这时你就是我赚钱的对象和工具，这时的关系是“我与它”。

那换一个高尚的目标呢？比如说我构建一个理想社会，这个世界充满了真善美，我带着这份预判和期待，强行把你拉进这个世界里，这时，我会和你构建一份什么样的关系呢？一样是“我与它”的关系。

那么，如果我们说“我爱你”，我带着这份预判和期待，去强迫你爱我，这难道还不是吗？不行，这还是“我与它”的关系。

有人在恋关系中很容易为了一件小事就升到“你爱不爱我”的高度，但根本上是：如果你听我的、按我的来，就叫我爱我；如果你不听我的，不按我的来，就是不爱我。所以这时想构建的是“我与你”的关系，语言上使用的，却是“爱与它”的词汇，像是说要做构建“我与你”的关系似的。

马丁·布伯的个论述，也解释了关系中的大多数迷惘，因为关于修形的控制，利用甚至剥用是实在是太多了。

我个人觉得马丁·布伯的论述如同真理一般，所以，在心灵探索的历程中，在迷途的时候，他的这个论述，是如灯塔一样给我指引着方向，我只是暂时迷路，最终还是回到他的方向上。

我作为中国的心灵工作者，我探索的主要是中式关系，这其中有非常多迷惘。

生活中，我们很少有谈论关系的目的，会像马丁·布伯这么说：不管你的目的与动机有多高尚纯正，当你要将你的目的与动机强加给他人时，你就构建了“我与它”的关系。

相反，我们的很多说法都是在关系中强调“我”与目的，如“听话就有的，父母可以强迫孩子听自己的话，有时无须没由，听就听话就是父母，有听要求就是“我的”，听话孩子渗透成了他们无私的大爱中，即使你自己，在看我妈的猫时，也常常会说，它们好养好听话。因为听我话的盛衍，他们能完成我构建的一份团队人际关系的迷惘。要认识这些迷惘，你才能更好地前行。

马丁·布伯的“我与你”的关系范式，是针对西方世界的自我本体论，简单来说是，像是像笛卡尔所说的“我思故我在”，人本主义心理学的自我真实客体。我整体性的论述，也是陷入了自我本体论。 我讲本体论，其实就是“我与它”的关系。

我们不能去倡导“自我消灭”。自我消灭说是个假命题。 我要求下来，也能融进一个大我，因为当“我”不存在时，“我与你”也就不可能了。 进一步来说，当倡导“我”放下自我时，其实就是“我”在“你”前面沦为“它”。

我认为最好的关系，我没有太掉我的主体性，也没有丢掉你的主体性，但我们的确认进述都没有离开我们。在关系的进程中，我们不断产生“我与你”的瞬间，并最终全然相遇。

### 鲁米和夏玛斯

鲁米是成吉思汗时代的人，他出生于阿富汗。后来为了躲避蒙古人的入侵，先是迁到巴格达，后迁居土耳其，成为苏菲派的精神领袖，具有极高的声誉和地位。苏菲派有个传说：找到你灵魂伴侣，并和你一起同行。

夏玛斯则是一位默默无闻的苦行僧，一次走在沙漠中，有个声音问他：我可以帮你找到你的灵魂伴侣，为此，你愿意付出什么代价？

夏玛斯毫不犹豫地回答：我的头颅。

之后，夏玛斯和鲁米相遇，他们深深相爱，总是形影不离。 这招怒了鲁米身边人的嫉妒，夏玛斯被杀，而杀他的是，据说是鲁米的儿子，结果再行出了自己的头颅代价。之后，鲁米长时间陷入痛苦中，到处寻找夏玛斯的踪影，直到有一天他问道： 我为什么要寻寻他呢？ 我不就是他的吗？ 他的本质通过我而显现。 我寻找的，只是我自己。

抱歉，这个故事可能让你看得有些怪，我更想表达的是，它也揭示了爱的意义：“我”全然爱上你“，而最终发现，你就是我，我就是你。作为外在的存在和我内在的融合，合二为一。
