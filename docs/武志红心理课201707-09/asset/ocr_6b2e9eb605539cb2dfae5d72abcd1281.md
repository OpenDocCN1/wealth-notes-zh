# 问答：人没有简单活着的部分

![](bbox=[0.1, 0.03, 0.3, 0.05])

问答：人没有简单活着的部分

+   - 武志红

今天是每周的问答时间，来回答一些本周用户的问题。

关于这个问题，我特别想说的一句话是：

人，没有简单活着的部分。

> > 我们大多数人会试图变得简单、单纯一些，但你没办法一辈子都保持着单纯，你必然会发现，那些极简单的事情，都可能会遭遇各种复杂，你想进入到复杂，真正的关键是在这份复杂中，你能否回归单纯。如果不能，那么可以说复杂没有滋养你，而是吞没了你。

# ——本周问答——

如果从小就单亲家庭，怎么引导孩子培养正确的二元、三元，以及日后正常的关系态度呢？

+   - 武志红

其实最关键的一步，是第一位养育者和孩子建立起一个高质量关系，这样孩子充分感知到“我是好的，你的，你是爱的”，有了这个二元关系的基础，再进入三元关系就容易得很多。

父母是外界意象的载体，即便孩子一开始失去了父亲，那孩子和外部世界建立起好关系，一样可以起到这里作用。

当你说“单亲家庭”的时候，相信你说的是孩子是父母的，但可能他们离开了。那么，特别重要的一点，别对孩子说你父亲是坏人，我们要的是共同敌人。

建议了解一下奥古斯特和哈的故事，奥古斯的妈妈一直对孩子说，你父亲是一个值得尊敬的人，他爱他的，你的他确实是个渣男，但依照我们的观点，他也曾是个不负责任的人渣。建议可以写个简单文章《奥古妈妈的育儿经》，如果您感兴趣的话可以搜索来看一下。

很多古代名人先贤，如庄子，陶渊明，苏东坡等，他们都是从孤独中活出来的，他们确实欢然热闹，确实是孤独的生活，他们不觉得痛苦，不痛苦吗？

+   - 武志红

我在之前的内容中已经解释过，能这样享受孤独的人，很可能是因为“心中住着一个爱的人”。一个孩子可以是心中的爱人，在我看来，是不能孤独修复的。

能享受孤独的人，是因为心中住着一个爱的人，这个人可以是自己吗？

+   - 武志红

很多用户问了类似的问题，心理学的解答是，不行。

日本漫画家石田彻也有一篇漫画，一个人睡着，他从身体裂开一个人，这个人体内又裂开一个人……可是，这个一层层裂起来的新的人，长得几乎和原来的人一模一样。这意漫画，显示一个人同他的孤独。

这位漫画家的其他漫画，都有这种彻底的孤独感，他死于车祸事故，但很可能是自杀，在我看来，也或许是孤独杀死了他。

一个独立自足的成年人应该以三元关系为主，但现实里我们都保留着一元、二元关系的空间。在成年人的世界里，这几种关系是怎样的联系？

+   - 武志红
