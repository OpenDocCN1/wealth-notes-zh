# 关系04丨你存在，所以我存在

武志红

我们这一周的主题是“关系，就是一切”，今天第一讲是“你存在，所以我存在”。

我先前给你们讲一个故事。

读研究生的时候，我认识一个哥们，他大我多岁，认识几个月之后，我们成了关系非常密切的朋友，几乎每天都要见面。这是我必须说一句，主要是我在找他，我其实想躲他，但那个时候，我作为“做好人”，没法儿拒绝他。

所以，在当时我们这么密切的关系中，主要是他感觉特别好。

渐渐的，我发现他有一个倾向：他恨不得把他每天发生的所有琐事，都讲给我听。比如他今天吃了一碗面，连面的形状是怎样的，吃面的感觉如何如何，也要讲给我听。

特别奇怪的是，虽然他们讲的是吃面，但我有一种避而不宣的感觉，他其实想告诉我的，是他排便的感觉。

我不好意思直接告诉他，他很难吃，随口不介意他怎么想，他那时的反应确实是理解这个，但觉得这实在是太奇怪，所以控制住，转而去给他吃了他面前的那碗面。就是如此奇妙，口欲和肛欲，竟然就这样混合到了一起。

后来，我实在受不了他这种倾诉欲望，于是对他讲，你那些感受，有什么好说的，你不必讲给我听，这点事，多讲有意思的话，他也知道讲这些琐碎的事很无聊，但他就是忍不住，所以都不肯讲我，让我知道，这就是他习惯性地控制不住似的。

给大家交代一下，我们都不是同性恋，当时我虽然是读临床心理学方向的研究生，但无论理论还是实践，都养得非常一般，所以没弄明白他到底怎么回事。

多年后，我在一谈咨询中，通过一个细节，才弄明白他的心理。

这个细节，是我向我的另一来访者，她最大的心愿是什么，她回答说，她最大的心愿是希望有一双眼睛，能看到她的一切。

这位女士的回答，让我立即想起了那位哥们，我知道，我们有一种共同需求，希望有一双爱的眼睛，能看到他们的一举一动。

他们的心理理论，可以说得不经，不过如果放在婴儿身上，这是非常正常的需求。婴儿会觉得，他和妈妈是一体的，而他的举一动。如果被妈妈的眼睛看到，那么就存在。如果一不被看到，意味着婴儿会觉得自己的一些部分，因为没有被看到，所以就等于不存在。

电影《阿凡达》中，男主角曾说过一句话：“I see you”，我看见你了。而看见，就是爱。
