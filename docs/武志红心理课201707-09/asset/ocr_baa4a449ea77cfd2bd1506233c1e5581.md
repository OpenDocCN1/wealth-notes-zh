# ——该不该放下自恋——

今天是本周的第二次问答。昨天，第一次问答中，我留了一个小小的作业：为什么这周的内容这么矛盾，一会儿讲放下自恋，也该是放下自恋；一会儿又鼓动自恋导致的竞争呢？

很多朋友给出了很好的答案。大家可以看精选留言区。我也给出一个简单的回答。

我们先来回顾一下本周的内容：

+   - 这周大主题，共赢的内在本赛；
- 周一，警惕你的自我成瘾；
- 周二，放下头脑，信任身体；
- 周三，竞争，是最好的合作。

周二和周三的内容，是一致的，并且和前两周的内容也一致，讲的是看到并放下你的自恋，然后才能与事物本身建立起链接来。所谓跟需要，本质上是链接与控制，让该需要，放儿童的本能体验放下，转而去依恋他比能力很强的妈妈，于是和妈妈之间建立起了链接。

但周三的内容突然转变了方向似的，又鼓励自恋的竞赛状态，并且说竞争会让一个人的人性更好地展开，然后你才能看到自己的完整性。

其实，伏笔在第一周就埋下了的。第一周我就强调，不可否认，自恋是各种问题的元凶，也许该说容易，自恋是不好的，但绝不能过度地否定。

首先，破坏自恋非常困难，必须达到所谓“开悟”才能彻底做到，所以自恋会跟我们一起生活。

网球教练加尔布显然发现，放下自恋、信任身体，会产生身心合一的奇迹，但我相信，即使是他，也一样无法彻底放下自恋。从书中可以看到，比赛中的胜负一样会影响他的情绪。并且，也许是因为没有强大自信导致的竞争焦虑，所以他自己在体育竞赛上，并没有多大成就。

所以我想，这对矛盾可以这样来理解：自恋性竞争，推动我们走追求变成、变卓越，这是一直存在着的力量；而关于自恋性的决裂，如果你能放下头脑去信任，信任身体，进入身心合一的境界，你就能产生奇迹，甚至达到。

> “简而言之就是，平时做好预备，而关键时，可以使用身心合一的方法，让自己超常发挥。”

做预备的时候，自恋和头脑一样重要，自恋是燃料，而头脑是分析工具，你只需要注意，别把头脑当成分析的东西，去做好坏对错高低的评价并搞坏坚持就可以了。

一些朋友，因为看到了身心合一的奇迹力量，有点小“吓”了着，认为考试或比赛的关键时刻，身心合一就是一切，而忽略了自己平时的准备。

例如一位朋友留言说：

> “我是英语很差，但是在英语考试的时候，两次感觉都看都懂，考的时候开心坏了，可是第一次99分，第二次63分。”
