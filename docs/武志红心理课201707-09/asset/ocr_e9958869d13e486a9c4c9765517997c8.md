# 命运用12 | 你想要什么样的自传

我们这个月一直在讲命运，今天是希望大命运，我们在外部在力量的定着命运，其实很大程度上，是我们自己的选择。只是很多时候我们不清楚自己是怎么做的选择。

既然都是自己的选择，也就是说，我们这一生，就像是活生活在地给自己写自传。

只是，在这个自传还没有彻底展开前，我们是不是可以再用一些方法提前认识它，从而改变这份自传呢？

当然可以，这也是学习心理学的意义所在。

# 认识你的自传

今天我就来给你介绍几个方法，帮助你认识自己的自传。

第一个最简单的方法是，设想一下你的墓志铭。想象你去赴后，要在你的墓碑上刻下最简的话，话上能体现出什么？那么，你希望自己的墓碑上出现什么样的字呢？

这是美国心理学家欧文·亚隆发展出来的一个治疗技术。我自己做过很多次这个练习，每次从临海者脑出来的，都是一句话：这是一个高明的观察者。

这句话特别戏剧性。如果到后来，我的墓志铭真是这样，那我得说我这一生实在是太失败了。哪怕再两书句，本刻到墓碑太人性，影响力又大无效论。这份墓志铭所揭示的人生，不还是毫无白力的吗？

我希望自己的墓志铭，是《红与黑》的作者、法国小说家司汤达的：

> 来世人亨列，贝尔本尔止于此。他活过，写过。

亨列，贝尔是司汤达的假名。他十分讨厌本兰，所以将自己叫本兰人。

喜欢他的这句话，是因为我一直不在意不地认知自己，希望能看到真实的自己。

我们之前一直在强调“一切皆自传”，其实，我的微博文也是我的另一种自传。大家如果查看我的情况，会发现，我不断地调节活力，无情地认识中国式好人，但我其实的活力一直是匮乏的，我自己就是一个经路的中国式好人。
