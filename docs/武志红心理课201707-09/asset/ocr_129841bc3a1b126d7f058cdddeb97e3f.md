问答：成为带着野性生命力的自己...

# 武志红

今天，又到了我们专栏的问答时间，主题是“成为带着野性生命力的自己”。

我先对专栏这一周的内容来做一个小小的总结。

# 一周小结

这一周，我们讲了三个心理大关关于自我的理论。

# 周一：弗洛伊德的人格构理论

他认为，一个人的性格是由本我、超我和自我这三部分组成。本我像是天性本欲欲望，遵循快乐原则；超我是道德规范，遵循道德原则。本我和超我是冲突的，自我在其中做协调，遵循现实原则。

弗洛伊德人格理论中的自我，英文是ego，即头部意识层面的自我。

本我，也可以视为“内在小孩”，而超我，则可以视为“内在父母”。但相对而言，本我和超我的概念，比“内在小孩”和“内在父母”的解释范围要大一些。

# 周二：人本主义心理学大师罗杰斯的自我理论

罗杰斯说，“我”是一切体验的总和，而要理解一个人的“我”，就需要理解这个人体验所发生的“现象场”。

现象场，即一个人的体验和体验发生的时空背景的结合。我常说的一句话——成为你自己，也是罗杰斯的概念。

# 周三：英国精神分析家温尼科特的自我理论

他是弗洛伊德的学生们的学生，但和祖师爷的观点截然相反，他认为父母应该帮助孩子活出来本我，提供托管性环境，让孩子的本我得以发展。这样孩子在成为真尼自己的同时，也会是一个道德的的人。温尼科特和罗杰斯有同样的结论——成为你自己。

不过，所有的精神分析大师都懂得人性的复杂，他们不会像人本主义学家那样认为人性善，所以这两个“成为你自己”，还是非常不一样的。

我读书时喜欢上本主义，进入社会后，对人性理解越来越复杂后，更喜欢精神分析，但，无论如何，我都喜欢这个说法——成为你自己，这也是我们的专栏宗旨。

我认为，学心理学不是为了成为一个更聪明的自己，而是为了成为带着野性生命力的自己。

# 本周问答

本我、超我都是两个极端，野性、规矩也都是个极端。既然都存在，就说明其合理性。在养孩子时应该如何让把握好一个度，让性格不会成为劣劣，让孩子下不会成为野兽？野性中如何保存文明？中点之道是否是非神造出来的？

# 武志红

一且涉及到“这个度该如何把握”时，我们都能说清。你也许陷入了一个所谓的逻辑、其实，谁也不能真正去把握一个程度。那么，该如何回答你的问题呢？

我思考是这样的，当持有“一个人最好的发是成为你自己”时，其中的另一个前提是“你自己”是值得信赖的。罗杰斯和温尼科特都深信，一个成为自己的人，同时也是有道德的。

所以，父母不需要把握一个度，而是相信孩子的“自己”是值得信赖的。我们也可以永远去讨论论述这一点。

但如何不让孩子形成一个自私自利的、只知中等的野孩子呢？其实很简单。父母也要在和中子的关系中做真正的自己。

在孩子幼小需要帮助的时候，父母要给孩子提供托管性环境。但随着中子的能力不断增长，父母就要给中子逐步设定一些界限。界限很简单，就是公平。我反对用控制中子的生命，活出你的野性，但我不接受你严重伤害我。

还记得温尼科特的原话吗？别忘了他开头说这是为父母。需要一个个不报复的人，他说的“自己”，而指谁不是指的小孩。小孩子有时会打击父母、父母也是中子，心理上也可能受伤害，这中间要停止孩子的攻击，去让孩子反馈他的真实感受，让孩子知道，他和别人之间是有界限。

你可以有带孩子去观看真正的野兽，比如有个动物纪录片《我们诞生在中国》，大家可以看看雪豹等中子狼和熊中子，它们可以自足的，豹子和熊中子就是既保持，也有自己的野性。

“抱持”这个词太好了，我对己和中子人都有很高的要求，所以对受到他们都不能抱有积度。反而对待中子，我却期望持续的对待，保证他们的积极度。这是为什么呢？

# 武志红

这个问题是中国院的一个普遍问题。特别是父母对孩子、夫妻之间，都会是有点高要求、过积心的问题。而对外人、就有多多。

这个问题其实很复杂。我现在的理解是，这主要是权力因素。因为在家里，所要求都来自自己的权力，以保正自己在自己的地盘上说了算。

但在单位里，如果不当领导，那中子知道，也不是自己地盘，并且所有人权力意识都很强，都不好惹，所以最好恭一点。

还有一个重要因素是自负。身边人都是“我”的延伸。“我”的一部分，所以我希望身边人能达到“我”的预期。

“需要一个不中报复的人，以滋养出这种感觉——世界准备接纳我的本能和原始冲动”。这个不会报复的人指的是父母、朋友、老师？

# 武志红

温尼科特说这句话的时候，主要研究的是母亲关系，所以这个“不会报复的人”，首先指的是妈妈，而后指的是家庭。

当然，这可以延伸到各种权威身上。但我们不能期待他们。因为权威，进入到社会抱持中后，“报复”比较容易发生。不过，如果中子在中家庭里培育了抱持性环境，那么这样的生命有了补助一我可以在这个世界上做我自己。

这是一个种子，也是一个练习。练习充分的活，孩子在进入社会后，也会习在复杂的社会中，保持做自己的基础。

老师所说的野性，是生命的张力？还是不控制、感性的行为叫野性？自我起我们为什么强吗？我们小时候是野生动物，然后慢慢长大就要时刻遵守下温和乖巧的动物，或者动物里被规则或规规限制活动的动物，那么性也不可能消失，感觉自己有野性就要释放，那怪太可怕了...

野性，是危险的，但一点点风险都没有的人生。又有什么意思。理性社会，没有人愿意接受“你太疯了吧”。但中，每个人都需要有现实意识，如果环境不允许你，你还需要野性，那就可以自我去发展了。

这个世界上野性的人非常多，我相信你身边就有，你可以观察一下，他们真的那么可怕吗？

感觉自己的野性被压制住了，经常有情绪感，有时被中家人打一架、吵一架才能发泄出来。释放野性不是让你用本能去生活，而是你可以会看到别人只考虑他自己的感受，是不是太自私了？
