# 问答：“我与你的”关系，难以“一蹴而就”

问答：“我与你的”关系，难以……

武志红

你好！今天是周五，是我们专属的问答时间，我来回答一些大家的问题。

本周五预告中，我向大家提了一个问题：你有过这样的经历吗？当懂得了一个概念或理论后，看世界的目光都变得清透多了。

对“我与你”关系，马丁·布伯的“我与你”和“我与它”，关系三分法，这是迄今为止我帮助最大的一个概念。当然，我学精神分析的过程中，这种概念有很多，精神分析很多东西“不言自明”和理论，很容易“我”三观，也能带给我非常痛彻的认识。

这周的留言中用户们也分享了很多，让我印象深刻的是有很多用户提到了咱们讲到的在《一个老禅师，来寺求师，》里的一些说法也“三观”，特别是写李笑来老师讲，比金钱重要。而注意力比时间更重要，这个说法，也让我注意到了。

大家的分享很多，我相信如果再做一个调查，很多人可能会增加一个新内容，就是我这里提到的珍惜规则和权力规则的概念。在这里我要强调一下，虽然这些观点和概念是有用的，但在传递知识时，我们之间的桥梁是帮助，其实“我与你”的关系，这些知识是帮助我们来“认识世界与人性”这个目标工具。

所以，这周的最后我必须强调一下，“我与它”起步于研究，不过我希望这些知识，也可以起到帮助你抬头去寻找屏障的作用，最终帮助到你，更好地进入“我与你的”关系。

“它”，是实现目标的方法和对象，而“你”也是生命，这里的区别，就好比恋爱中，你把对方当做征服对象，和与对方自然相爱，差别是巨大的。

# 本周五问答

我努力让自己变得更好，也尽量将学习的东西应用于身边，可是如果只把自己单方面的用于对方，可我是我行我素，那我是不是吃亏了？这样的想法是不是很自私？

武志红

这样的想法太常见了，也的确是妨碍我们与“我与你”关系的一个心理障碍。

我们进入联系，如果你的向我是你的真实，而你却是不“好的”，这时我就会觉得自己的太多了，会觉得我比你低一等，我的自恋就没有了打的基础。
