# 问答：再怎么努力，伤害也不可避免

问答：再怎么努力，伤害也不可避免

**武威红**

你好，我是周同，我未来会主要回答一下大家的提问，明天再回复我们的主题。

从专栏开到现在，最常在留言区和学习小组中见到的一类问题是这样的：

**武威红**

你想知道这些，可是还是不知道如何去改变自己的命运吗，如何去疗愈自己呢？

类似这样的问题，我听到后，会有一些焦虑感。那我们就拿我的焦虑感做例子，用周同专栏的角度来分析一下。在没有形成“专家”的角度思考问题的意识时，我会觉得，这个焦虑感是真的，因为我作为老师，有必要去解答大家的这种问题。

如果我是一个喜欢灌注知识的老师，我可能会说：就是尽脑汁去听你解释问题。如果我是一个喜欢启发学生的老师，我可能会说：如果你的问题能留给你自己解决，你认为该如何解答？

但在我形成了“专家”的角度来思考问题的意识后，我可能会这样思考这个问题了：

我感受到的焦虑感，是想问的用户传递给她的，借着他/她的焦虑，用户和我之间就建立了这样一种关系——焦虑的提问者“无所不能的解答者”。

如果我直接去解答这样的问题，就证明了我的无所不能。这时有高级别自恋形成。

如果我不直接去解答这样的问题，我就会感到“我是无能的”。于是就有了自恋挫败感。

由此可以知道，提问这样的用户，无形之中可能是期待自己无所不能的，是至少不愿意承“无能”这个问题的无能力，无力感，或者说无能性，会让这样的朋友觉得自己很不好。于是希望有一个立即可解决的方法，暂时好像没有，所以焦虑就此而来。

相反，你还会看到很多回话，主要就是分享自己的领悟和见知的。比如说有这样一个留言：

今天太震撼了，为什么我对我所有的妈妈都没有好奇，甚至有点抗拒。原来这种模式是我小时候与我父亲关系模式的再现，小时候父亲经常批评我、打我。看着，在我工作生活中只要涉及的不顺心、委屈就是与父亲的关系模式、亲子关系是我与妈妈关系模式的再现。难怪我总是在寻找父亲，没找到，不舒服，现在我才知道不如直接去改变自己的模式，不要再期待用“拥抱”的态度去抚慰。

这样的分享中，你能感觉到，这里面是有一个空间的。这个空间容纳了自己的思考、认知和体验过程。相反的，太多看问怎么解决？、怎么办？的时候，是没有这样一个空间的。所以，大家都在阅读文章，激发了自己的一个内在过程。

不过，我不是说大家一定要这样一下，我这样想，绝不是说第一读者是无能力的。不对的，我希望是，大家仍然可以按照自己的感觉，自由地分享。留言就好。

# 本周问答

周老师你说妈妈乳房是孩子最初客体，那是不是没有吃过的孩子会长什么样呢？我想起是真实的，孩子没吃过的，孩子都是喝奶的，而且这样的孩子应该不少。他们会形成什么样的心理特征呢？

**武威红**

一年前的口欲期，最好的养育是由奶头，妈妈含有饱满的乳房和丰满的奶水，还有按照母亲的需求和节奏去喂养。但现实也不是不知我，我们之前也强调过，养育做到60分就已经很好了。

真实的乳房和乳汁很好，没有的时候，奶瓶和牛奶可以替代，但是得有时机，如果做得非常好，一样可以起到很好的作用。

我们广州一位朋友，她也是有奶水，但在整体的养育中及时回应孩子，尊重孩子的需要，孩子发展得非常好，对她姐姐，虽然奶水缺乏，但对孩子一直很包容，结果孩子出了很大的问题。

所以，作为一个重要客体的乳房，并不是仅仅指的是真实的乳房，也是哺育的总称。

性格和来源最初关系和客体性？性格和基于哪些关系？人人都说江山易改，本性难移，那么性格在后续的关系中可以改变多少呢？

**武威红**

作为心理咨询师，深入到来访者的人内心深处时，你会发现，早期客体关系的影响，实在太深了。

而我作为深度的被访分析师，找我的分析师做深度咨询时，我也发现，我的早年客体影响，对我的影响，也实在是深入骨骼。

分析焦虑这些，有些地方比方说会更有很大改变，比如我现在比过去更容易表达焦虑，比过去身体也变得更有力。

基因当然是存在的，我们上一周介绍过索玛特利的精神驱论，最形象的比喻是，你不能让一匹草变成狮子。成年性，“江山易改，本性难移”这句话中的本性，性格很大一部分固定的是六岁前形成的东西，比如大部分定型，并不不可改变。

为什么同样的父母，兄弟姐妹之间的性格都有很大不同呢？

**武威红**

基因不同会有影响。

同样，环境也非常复杂的影响。虽然同样的父母，但是面对时间不同，对孩子的期待可能会非常大不同。

我女儿3岁多了，大做1岁时断奶，断奶很顺利。她一直对乳房有特别的依恋，不知道该怎么解除她的行为而不伤害她？

**武威红**

等长大了有了羞耻心，自然会放弃这么做。

如果一直没有放弃，作为父母也可以适当强硬，父母过动，是必然遭遇各种伤害。父母主动进入到陌生关系的各种情形。书上有一句话就特别对：纵然你多努力，你还是不可能避免地伤害到别人。

我在和别人关系的过程中，很容易感到人生气了，我猜测应该是因为在初始和妈妈的关系中，妈妈经常生气，生我生气，自我是否有很多话题和别人建立深度关系，是不是在最初始试图建立深度关系的时候，受到了伤害？

**武威红**

你这个猜测很有可能。还有一种可能是你容易生出别人的生气，但对于自己的愤怒没有觉察，而把它投射到了别人身上。

另一种可能，也是常常并存的。也就是说，你一直地妈生气，而太过过于为妈妈的感觉考虑，导致你会压抑自己的愤怒，于是对自己的生气会不满。

如果一深入关系，就把别人生气，或者自己会愤怒，那你必然会陷入深深关系，如果是这么成立，那么可以对自己说：我是可以生气的。

父母在我很小的时候总是替我解决，在我青春期后我总想自己做，后来是感觉愤愤又无力改变只能再次接受了，这就是原生人生枷锁吗？虽然已成年，但是仍会有这种无力改变感的强烈感觉，我现在唯一担心的是我的儿子会成为我的样子，该如何改变呢？
