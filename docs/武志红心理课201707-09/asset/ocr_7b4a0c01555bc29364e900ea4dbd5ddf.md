# 关系03 | 如何构建健康的关系

武志红

我这一讲的主题是“关系，或命运”。今天是第三讲，如何构建健康的关系。

本系列第一讲，我们介绍了“内在关系模式”，第二讲，讲了“内在关系模式”是如何影响着当下的关系模式的。今天，我们来谈谈如何“使用内在关系模式”的理论，去构建健康的关系。

# 内在关系模式的投射

先讲一个我朋友的故事：

我这位好友，1995 年大学毕业时，去了广东一家民营企业工作，职务是老秘的秘书。那一年这个民营企业招了十几个应届生大学毕业，在当时是很稀奇的事，被当地媒体一再报道。

但有一个问题，这个企业的老板对这十几个大学生的态度有点奇怪，他既会对他们委以重任，又对他们格外挑剔，动不动就说：我这些大学生不过如此，还不如我们那些没文化的。

这位老板，自己是小学文化。

这样一来，我们就会明白，这位老板面对大学生有点自卑；而当发现大学生也不如他时，又会去损他们，好把自卑传递给他们。

通过这个故事来讲一个观点：那些用来描绘性格的词汇，如果自卑，等，我们很容易理解为这是一种人格特质。但实际上，它们表达的是关系，都需借助关系的框架才能准确理解它们。

比如，自信，我们习惯上说是“自己相信自己做到的”，但我们说，有 A 相信 A 信自己的，有 A 信 B 信的。所以“自信是信自己”的说法准确的意思其实是“的一部分相信自己的另一部分”。

内在关系模式投射到外部关系中。比如，一位母亲对女儿很严格，女儿总是觉得妈妈不爱她，实际上她可能只是不知道如何表达爱。

用“内在关系模式投射到外部关系中”这个概念讲，自信是信 B，B 是你内化好的他人，通常来说是父母。

所以，任何一个用来描绘性格的词，都可以放到关系中理解。

这位民营企业老板，当他挑剔攻击大学生的时，就是把他的内在的自卑，反映到了当下的关系中。

这种关系中，如果你是我故事中的大学生，你会怎么做？

我这位朋友的故事，特别值得借鉴。在她工作了几个月的时候，有一天，她在办公室，她老板突然问她：“你觉得我这个人怎么样？”

一个刚毕业的姑娘听这种话会干什么？

我这位朋友听到这句话时，也是觉得莫名其妙，立即有了被鄙视的感觉，然后迅速回了一句：“是啊，我一生都没想过不信任你，可是你太傲慢了，不像个正常人。”
