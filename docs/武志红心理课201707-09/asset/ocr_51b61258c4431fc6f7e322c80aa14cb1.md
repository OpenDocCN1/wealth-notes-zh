# 关系08｜世界的本质，是关系

武志红

我们这一讲的主题是“我与它，我与它”，今天第一讲“世界的本质，是关系”。

# 马丁·布伯的《我与你》

我先把书名分享一下我和马丁·布伯的《我与你》这本书。

我在北京大学读本科时，一次去北大图书馆看书，完全不了解马丁·布伯，却莫名地被《我与你》这个书名触动，把它借了出来。

这本书的中译本翻译得虽然有优美的地方，但整体上非常晦涩，我读了至少一两小时，读做下大量的读书笔记。可以说，我是把这书抄录了一遍，而我的读书笔记的字数，绝对多于这本书本身。

后来有一次，我拿我的这本读书笔记在北大的教学楼占座，结果居然发表了，让我伤心了好长时间。

再后来，我在四川日报写心理专栏时，多次提到这本书，这足是对我影响最大的一本书，结集这本晦涩的书学习开始顺畅，常常很通达。不过我刚在购书网站上看了一下，还能再版。

马丁·布伯的哲学，整体上可以视为“关系本体论”。意思是说，世界的本体不是宇宙万物之“你”，也不是“我”，而是“你”和“我”之间，是关系。

# “我与它”，“我与它”

当你将“你”视为我达成目标的工具和对象时，你在我这儿就沦为了“它”，这时就构建“我与它”的关系；

当我放下所有的预判和期待，带着我的全部本来和所有的本真相遇时，这时就构建“我与你”的关系。

马丁·布伯说的“你”是上帝。我通俗一点，个文化语境，当“我”放下我一切的预判和期待，而触碰到它的本真性，那一刻就是遇到了你，也是遇到了神。

换句话说，上周我一直得到心灵魂应，我认为是当心灵感应发生时，那是一种你“不仅是你”相遇，也像他遇到了上帝。

当然了，心灵感应听说着关于神祇，我在之前的文章《打破我的内在比赛》中，介绍了体运动后的“身心合一”现象。这个身心合一，和心灵感应看似类，甚至可能是同一回事，都是大脑和识层面的自我认知消失了，身体和意识层面的认知层次了。我们一旦，构建起“我”和体育活动的个“你”相遇，建立了“我”和体育活动的“我”相遇，建立起了“我”和体育活动的关系。达到“身心合一”时，运动员们都喜欢说，这时候的球“打”入神了。

所以，这一讲不仅“我”的本质显现了，也遇到“你”的本质，同时，真的好像是本性在其中。

不过，我还是要再澄清的是，马丁·布伯来看，我们必然永远是处于“我与你”和“我与它”的双重世界中。为了自身存在，我们不断构建“我与它”的关系，与其他客体为工具这个主体服务，可如果只有“你”这个关系，所以我，所以也要强调“我与你”的关系存在。

马丁·布伯论述说，“我与你”的关系时问，我们只能是偶尔进入这种关系中，而“我与它”的关系是时时刻刻。

不过，一旦进入了“我与你”的关系，那一刻就是永恒。体验到“我与你”的关系真切存在后，再看这个世界，一个人会变得很不同。

# 最好的关系

“我与你”的关系，论述起来不容易，你必须真正体验到，才知道它是怎么回事。对个体个来说，我认为特别重要就是“爱与它的关系论述。马丁·布伯说，不管你有看什么样的预判和期待，你构建的都是“我与它”的关系。

比如说，一个很实际的目标——我想赚你的钱，这时你就是我赚钱的对象和工具，这时的关系是“我与它”。

那换一个高尚的目标呢？比如说我构建一个理想社会，这个世界充满了真善美，我带着这份预判和期待，强行把你拉进这个世界里，这时，我会和你构建一份什么样的关系呢？一样是“我与它”的关系。

那么，如果我们说“我爱你”，我带着这份预判和期待，去强迫你爱我，这难道还不是吗？不行，这还是“我与它”的关系。

有人在恋关系中很容易为了一件小事就升到“你爱不爱我”的高度，但根本上是：如果你听我的、按我的来，就叫我爱我；如果你不听我的，不按我的来，就是不爱我。所以这时想构建的是“我与你”的关系，语言上使用的，却是“爱与它”的词汇，像是说要做构建“我与你”的关系似的。

马丁·布伯的个论述，也解释了关系中的大多数迷惘，因为关于修形的控制，利用甚至剥用是实在是太多了。

我个人觉得马丁·布伯的论述如同真理一般，所以，在心灵探索的历程中，在迷途的时候，他的这个论述，是如灯塔一样给我指引着方向，我只是暂时迷路，最终还是回到他的方向上。

我作为中国的心灵工作者，我探索的主要是中式关系，这其中有非常多迷惘。

生活中，我们很少有谈论关系的目的，会像马丁·布伯这么说：不管你的目的与动机有多高尚纯正，当你要将你的目的与动机强加给他人时，你就构建了“我与它”的关系。

相反，我们的很多说法都是在关系中强调“我”与目的，如“听话就有的，父母可以强迫孩子听自己的话，有时无须没由，听就听话就是父母，有听要求就是“我的”，听话孩子渗透成了他们无私的大爱中，即使你自己，在看我妈的猫时，也常常会说，它们好养好听话。因为听我话的盛衍，他们能完成我构建的一份团队人际关系的迷惘。要认识这些迷惘，你才能更好地前行。

马丁·布伯的“我与你”的关系范式，是针对西方世界的自我本体论，简单来说是，像是像笛卡尔所说的“我思故我在”，人本主义心理学的自我真实客体。我整体性的论述，也是陷入了自我本体论。 我讲本体论，其实就是“我与它”的关系。

我们不能去倡导“自我消灭”。自我消灭说是个假命题。 我要求下来，也能融进一个大我，因为当“我”不存在时，“我与你”也就不可能了。 进一步来说，当倡导“我”放下自我时，其实就是“我”在“你”前面沦为“它”。

我认为最好的关系，我没有太掉我的主体性，也没有丢掉你的主体性，但我们的确认进述都没有离开我们。在关系的进程中，我们不断产生“我与你”的瞬间，并最终全然相遇。

# 鲁米和夏玛斯

鲁米是成吉思汗时代的人，他出生于阿富汗。后来为了躲避蒙古人的入侵，先是迁到巴格达和巴格达巴，后迁居土耳其，成为苏菲派的精神领袖，具有极高的声誉和地位。苏菲派有个传说：找到你灵魂伴侣，并和你一起同行。

夏玛斯则是一位默默无闻的苦行僧，一次走在沙漠中，有个声音问他：我可以帮你找到你的灵魂伴侣，为此，你愿意付出什么代价？

夏玛斯毫不犹豫地回答：我的头颅。

之后，夏玛斯和鲁米相遇，他们深深相爱，总是形影不离。 这招怒了鲁米身边人的嫉妒，夏玛斯被杀，而杀他的是，据说是鲁米的儿子，结果再行出了自己的头颅代价。之后，鲁米长时间陷入痛苦中，到处寻找夏玛斯的踪影，直到有一天他问道： 我为什么要寻寻他呢？ 我不就是他的吗？ 他的本质通过我而显现。 我寻找的，只是我自己。

抱歉，这个故事可能让你看得有些怪，我更想表达的是，它也揭示了爱的意义：“我”全然爱上你“，而最终发现，你就是我，我就是你。作为外在的存在和我内在的融合，合二为一。
