# 命运08｜放下头脑，信任身体（附直播预告）

今天，我们来说说“打醒你的内在比赛”的第二讲，“放下头脑，信任身体”。

昨天的内容里，我们说到，当你在追求自我成就的时候，会避免自我挫败感。但一旦产生自我挫败感，你会很容易将它转嫁给旁人，如果转嫁不出去，它就会影响容易损坏你的“我”的运作。

总之这样做，都是为了避免“我是好的”这种自恋。

但是现在，我请你仔细想想，自我成就感和我挫败感中的“我”是什么？

在《身心合一的奇迹力量》这本书中，加尔夫提过一个有趣的概念，他说，这个“我”有两个，分别叫“自我1”和“自我2”。

自我1，就是头脑和意识层面的自我，它的语言是文字。

自我2，就是身体和潜意识层面的自我，它的语言是图像。

既然“自我1”是意识层面的，“自我2”是潜意识的，那么就很自然，我们更容易认同“自我1”，因为我们很容易感知到自己的头脑里在想啥，我的“头脑”代表了我的我。

头脑本来是工具，但一旦你认为我就等于头脑，那头脑就会变成敌人，它会去命令你、评判你。这个“头脑是错的”判断，就这样是对的，那个“我是错的”的对的就去做；错的就要避免，这时候的“我”是该被谴责、该被攻击、该被否定的。

当头脑做了这种评判工作，你用这个结论来指导身体的时候，身体就会变得紧张。紧张就意味着，我们体内的能量流动被切断了。而能量的自然流动，是潜能发挥的关键，甚至就是潜能发挥的过程，所以，紧张就会影响潜能发挥。

这个道理，我们都知道。譬如应对高考时，我们都知道，严重的考试焦虑是正常发挥的大敌。

# “我”=思维和意识

再给你打个比方。

在NBA里面的勇士队和骑士队对决中，你可以看到两种风格。

我给这两种风格分别取了名字，勇士队打的是流动篮球，而骑士队打的是正确篮球。

什么是流动篮球呢？在勇士队里，球永远也在流动，即使是持球最多的球员库里，也不会给队友不给队友，其他的球员也都在积极跑动中。一旦你会到机会，不管是超级球星还是普通球员，大家都给你传球。

那么什么又是正确篮球呢？像在骑士队中，球永远都在围绕着球队“王座”詹姆斯运转。他严密监控，其他球员常常只能站在最空的位置，等着詹姆斯给他们传球。在这个过程中，大球员得到球的概率很大，但普通球员就难有有机会。

我来看，流动篮球直播，以前我很少看太阳队的比赛，是太阳队没落，前我都是很少看篮球直播了。不过，在勇士队崛起后，只要有空，我老都会看他们的直播。

流动篮球是很罕见的，绝大多数篮球队伍都是正确篮球，也是超级明星的球，已经验证过、行之有效的战术。

那为什么流动篮球这么难做，正确篮球却比是更好呢？这是因为，绝大多数人都有这个心理障碍，就是“我”等于我的思维和意识。作家索卡尔不是有句著名的话么，我思故我在。

其实，思维的价值在于分析，也就是说可以帮助我们理解事物是怎么运作的。但它最容易被我们的是非判断力，也就很容易被分析结果固定化，说“这是对的”、“那是错的”。而且，这个判断一旦和自恋联系在一起，就会变成“我怎样做是对的”、“我那样做是错的”，我为了“经历”、“我要是这种自我挫败感”，我也会使动去避免一些东西，这一使劲就制造了紧张。

# 放下头脑，信任身体

加尔夫发现了这个道理后，提出的解决方案非常简单，他让球员放下头脑里对评价的评判，信任身体，将注意力专注在网球上，让身体自发展挥，就功力了。

譬如他会训练球员，在打球的时候将目光聚焦在网球的接触点上，然后把思绪放空，不去有意识地指挥身体，让身体顺其自然发挥就好。

当学员能做到这些时，我们往往会有超常的发挥。

用加尔夫的话来讲：

> 抛开一切想法，不去感受你意识的变化，也放弃批判周遭的“自我1”，你不去挑剔自己在有状态和动作，也不去丢丑自己。在这种状态下，指挥的动作是“自我2”，也就是你的潜意识。

换句话说就是，超常发挥，就是你潜意识里的“真正的我”和其他事物的“真我”直接相遇，并且合二为一了。

很多名人都有这样的体验，譬如华人球星林书豪，他在尼克斯队为球队水起的时候，他说，我像是在上帝打球。

林书豪，是NBA中目前唯一的华人球员，他是哈佛大学毕业生，在NBA中一直不算有好。多次被多队裁掉，他算是NBA中的流浪汉。2012年2月，他在的尼克斯队多伦士上主力，林书豪成为首发后，他有了看不见的表演，打出了超级球目的数据，尼克斯队也接连取胜，他就因此成为林疯风。现在，林书豪在篮球队，虽然屡屡受伤，但仍是球队信任的首发队员。

迈克尔·杰克逊也曾经说过，我时常感觉，我只是一个通道，而上帝通过我表达。

像这样的高峰体验很难描述，但它们的共同点，就是好像“我”消失了。

享受高峰体验的时候，还有一些特别的地方，比如网球的球，因为相当专注，会突然觉得慢了。像是魔术师，过程的一瞬间就都变成了慢动作，就这时候时空感变了。

可以想象，当网球变大、时间变慢，你的发挥自然就会变得简单了很多。

至于篮坛球员，在享受高峰体验的时候会得，篮球的球径好像变得很大，怎么投怎么进。

这是一种非常精妙的意识状态，你十分专注，但头脑和身体又非常放松。在这种意识状态下，时空感发生了变化。

其实，我们很容易迷恋头脑，而现在大多数人做事，头脑都是先跳出来，这意味着我们很多时都是在用刚刚说的“自我1”在工作。即使在运动项目里，因为是直接使用身体，所以超级运动员和教练们，反而会有很多来自高峰体验的情报。

例如NBA超级巨星比尔·拉塞尔说：这就好像在用慢动作打网球，我几乎能够预见接下来会出现什么动作，下一次是谁接球。这一切都是因为我们能够集中注意力，保持专注。

NBA成就最高的教练菲尔·杰克逊也曾经说过：秘诀是要去思考。可不要让让所有事来神志，不要让无意义的复杂想平静下来。

那么，运动员怎么达到这样的状态呢？加尔夫总结了一句话的秘诀：

全然放松地专注。
