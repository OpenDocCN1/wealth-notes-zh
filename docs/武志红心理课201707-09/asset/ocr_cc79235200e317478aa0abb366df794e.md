# 问答"不要太急着说"是"。

问答"不要太急着说"是"。

今天我们本周的第二次问答时间。

昨天的问答发布后，已收到了上千条评论，大家都太积极踊跃，其中一位老师说，"得到"真是太有学习感受的平台了。

我大致读了上千条评论，有一个经验总结如下：

我们太容易说"是"了！

很多朋友说，他说得最多的是这样的口头禅："无所谓，没关系，都可以，都行，好，ok，对……"

这让我想起我有一次上"中英班"，就是英国和英国联合办学的精神分析课，课前有美国老师来做，其中一个老师让我提一个问题，结果我发现，英国学生说出的第一句话里，出现最多的字就是"不"。

不，是一个美妙的字，当一个孩子说出这个字的时候，就等于他在自己和养路人之间划了一刀，去告诉养人：我"不"想按照你们的意愿，在我自己的事情上，我想自己说了算。

就这件事，我发了条微博，一位网友回复说：

"不"真的是最强大的内在语言了，因为它代表着自我意志，代表着内心最真实的自己。

# 被弄丢的"不"

我相信，无数中国孩子开口的第一句话也是"不"，然而，在后来的成长过程中，我们把"不"给弄丢了。

为什么会这样？

因为，我们家庭教育，太希望孩子听话了，以至于孩子变得容易说"是"，逐渐忘了内心自己多想过自己说了算。

关于这方面，我在我咨询的过程中，也有过很多体验，很多来访者讲完一句话后，就会很胆怯地看着我，如果我不迅速回应他，他就会不安。

在咨询最初的时候，承受这份力的驱逼，有的时候是因为缺乏觉知，我们的对话，像两个人打机关枪一样，停得不得。

现在，我通常让自己处于沉默中，来让访者，我觉察到，如果来访者跟我对话起来看看，这份不安中到底藏着什么。

这份不安通常是这样的：如果你不立刻回应我，就代表我没有听，就会得。我刚才句话，我不确定认可接纳我，所以我觉得你恨我，才不回应我……

太希望孩子听话的家长，也是一样的，而孩子出于种种原因，在感受到这份压力的时候，会容易地去回应家长，满足家长的需求，所以忘了，自己是多么想在关系中说"不"。
