# 从“吃”看你的关系质量

今天来谈谈说我自己吃饭桌上识人的这件事。

有一次，我去上一个江浙派心理学的课程，课程非常实用，老师也是这个派别声量较高的老师，所以中午吃饭时，饭桌上大家纷纷表达对老师和课程的喜欢，我也不例外。

然而，其中一个同学，在表达对这个课程的喜欢同时，对学院派心理学表达了强烈的鄙视。

那时的我还没那么名气，大家不认识我，也不知道餐桌上坐着一个北京大学心理学毕业的人。

他越说越畅快，而我越听越不舒服，突然我的情结上来了，对他说过：你信不信，我能用心理学心理学的东西，到饭桌上每个人都分析一遍。

这话说完，我就后悔了，觉得没必要这样。但大家都感兴趣，我都解释清楚了，我是最后吃饭的人，有那么几分钟，饭桌上鸦雀无声，后来，那次学派的同事打开沉默就说：如果你是来访者，可不找你这样的咨询师。

显然，他受伤了。他受伤的原因是，通过他吃饭的方式，我准确推导出：

+   1. 他的受罚；
2. 他的性生活质量很差；
3. 他和母亲的关系很糟糕。

我是怎么做这个推导的呢？这节课的内容里我们讲了，当下的关系看，反映着早年的关系模式，反映着童年的关系模式。比如，当你怎么吃饭，用什么方式和食物吃，反映着小时候的什么方式吃饭，吃什么反映妈妈的乳汁打交道。

所以，怎么吃饭这件事，反映了你怎么吃奶，反映你和妈妈的关系质量，也决定着其他和性质量的关系质量。不仅如此，因为妈妈几乎是婴外的整个外部世界，所以也影响着你和整个外部世界的关系质量。怎么吃饭这件事，可以看出太多东西来。

饭桌上这位同学吃饭的样子让我觉得很受控制，很难受，于是具体的推导过程就是这样的：

他控制欲很强，而控制欲很强的男人容喜欢开车，因为性能好的车，可以极大地满足一个人的控制欲望。喜欢控制的男人，在性事中也容易倾向于控制女性的男人，这一特点，也会反过来导致男力弱的女性，可能征服女性，但时间一长，女人会反感，他们性生活质量也会出问题。此外，这个人吃饭方式，也会直接推导出和母亲的关系质量太差。

# 饮食障碍

另外一次，还是在饭桌上，我喝了点酒，很有兴致，于是主动把大家都说了一遍，但唯独放过一个女孩。

这个女孩非要我说，但我也死活没透说，因为说透了伤害她。她身高超过165cm，体重却不到90斤。她还有一个绰号，叫“垃圾鸡汤”，因为她常常会把饭桌上的菜吃剩的汤舀干净吃剩了，为什么吃这么多，她还没怎么瘦呢？

我判断，她应该是患有饮食障碍，具体到她的情况，就是暴食障碍。在吃饭时，容易暴食，然后又会把吃掉的给吐出来。饮食障碍多见于女性，她们会有各种呕吐法，比如用手抠嗓子眼，甚至用催吐药，吐到最后，甚至会把胃和胆汁吐出来，很伤身体，所以长不胖。
