# 关系09 | 珍惜规则与权力规则

武志红

我这一周的主题是“我与你，我与它”，今天是第二讲“权力规则与珍惜规则”。

我在读书分享里的时候，开始讲两个核心的世界观分成两部分：以工作关系为核心的社会领域，以亲密关系为核心的私人领域。

这两个领域各有自己的核心规则，社会领域的规则是权力，我们是谁在争谁说了算，当然是强者说了算；私人领域的规则是珍惜，也就是我尊重你的本真。

如果在社会领域主要使用珍惜规则，而摒弃权力规则，或者在私人领域大量使用权力规则，都容易将我们的生活弄得一团糟。

人际关系的关键，主要是在权力规则方面核心深入到关系中所致。在工作因为明型利益关系，所以我们很容易认识到这一点；但在性恋性和亲子关系中，容易忽视权力关系的存在，甚至把权力规则视为珍惜规则，结果导致了一种“糊涂哲学”。

认识清楚权力规则，并恰当地运用，这会避免我们在关系中沦为“它的提线木偶”。

我来跟你分享一个故事，我们的一位来访者，患有严重的产后抑郁症。我给她咨询后，认为原因是她生现的家庭和原生家庭中，都严重缺乏权力空间。

她是广东潮汕人，她的家庭是典型的重视女轻男，五个兄妹，最一个是弟弟。她每次放到父母哪里，有儿次是第一次。这些成为可的，经历，导致她性格软弱，不能去争取话语权和利益。

她在生的女儿，也是严重的重男轻女，虽然她生了一个儿子，但她的婆婆，是家中最小的婆婆，接着是丈夫，接着是最小的各种人，而她的地位最低。给她咨询过程中，我主要是给予她鼓励、认知和支持，她也逐渐开始转变，最后成为了一个甚至有些凶悍的女人，把公婆从家里请走，也严厉警告丈夫敢于听婆婆话。

对她丈夫，就是由古听计对，现在经常主动动手。丈夫对此很生气，但有一次，丈夫坦城地对说，过有他眼看到，我觉得挺好，不过说实话你看不起你的，也不爱你。现在你虽然变得很凶，但能力强了很多，我发现也更爱你了。

后来他们生二胎，丈夫是试图劝父母来给他们当婆媳，他们也想生，不过他们说，这月家庭重中所孩子，都是管带大的。这位婆婆这样说，明显是为了争夺权力，争夺当奶奶，在整个族里维护至高无上的话语权。

我的这位来访者不想让婆婆来照顾她，因为之前婆婆曾自坐月子的经历好像是噩梦，现在和婆婆坐不住，更照顾，所以她对丈夫说：那时候最需要被照顾的人是我，但你的妈妈根本就不会照顾我，所以，我恐怕，会因为这件事，他们的关系一定会陷入僵局。

我和她多次探讨这件事的过程中，把这个家庭中的“权力的游戏”讲明白了。生育和养育，就是权力。新生命的出世，自待修改整个家庭的权力格局，孩子亲属，认可能，就味着着她的权力会增强。

作为生育者和养育者，母亲在这一点上具有极大的优势。当然这也是付出了很大的代价换来的。这时候，如果有人嫉妒的这个权力，要去争夺它，就会导致严重的家庭权力战争。

过去我一直不能很好地明白，为什么女性在过去，按说是最需要照顾的时候，却容易遭遇到冷对敌？为什么我到的为数很高离婚的对象，是孩子出生后开始的离婚大战？当我着新生生命权力，生育和养育就是权力时，这一切就看得通了。唯一的：609250

比如我遇到来访者的婆婆最初嫁人时，她也是遭遇过整个家族的冷漠，她生下了四个孩子，而孩子门逐渐长大后，他自己的小家里面，就有至高无上的地位。而这位婆婆的丈夫，在无时是被争夺对象，在会自己女儿的位下，很容易把孩子了，在自己弄亲的边，是容易婆子和孩子，等孩子长大了，自也不忍他认你，你是老了，成了整个家庭中可有可无的存在。

四个孩子都成家后，就着意味着婆婆了离于她自己的家族。这个候，婆婆权力变空空的候，很容易看弃者，而后的我这位来访者的丈夫，也站在妈妈这一边，这个男人没有婆媳，他的权力在变无妻。如果说只是到单纯看母亲，而变成妻子和孩子，那么在他自己的新家庭中，他将失去自己的权力，等他老了时，也会成为和自己父亲一样可有可无的存在。

把这些谈清楚后，我的来访者和丈夫做了几次谈话，把这个权力游戏的变迁，清楚得细致地讲了。丈夫被被情况所动，但之后，他慢慢丈夫对丈夫的态度。于是，我这位来访者的第二个孩子，成了这位婆婆第一个没有自己亲自带过的孙了。

经过这样的战争后，我这位来访者第一次清晰地感觉到，她终于成了自家的女主人，她拥有了可以为自己说了算的权力。她的产后抑郁症，慢慢地说好了。我想家家关系的改善，是一个重要的原因。我很多个案时，都听到这位来访者的故事，许多人听了后，会被震到，之后就想要知道该怎么做了。

权力规则，其实就是“我与它”的关系。将你为达到达成的目标对象与工具，总之是图建立我一定是我说了算的空间。

珍惜规则，实际就是“我与你”的关系。我别说明，甚至都不忽视你的各种知和本质使用你作为身上。我只想让你那着本心的我，和你的心。真真实实。

著名中科幻小说家阿西莫夫在他小说《基地》中讲了一个这样的故事：丑星上地“靠了操人心心的能力，他能够控制一个有刻度表盘那样，藉此去设定中人的各种情绪喜好，因此征服了宇宙，但他一直不忍心他给这个本领，用他的心女人上心上，那个人，是唯一一个见到的丑陋，仍然关爱他的人。

讲到这儿，我再次想起我在之前的文章《如何的健康的关系》中讲到的那个故事。故事里的好多，当婆婆不他一回，比一羊都好，她要不光自己应得了老板，她老板用本心老板相互而尊重。是，般心人本心行在中的人，都是非可人的。

不过我也想说，我们需要完整地看到权力规则和珍惜规则。我们可以使用权力规则保自己的所要，也可以去珍惜和护他人所爱的，只是有两件事。同时，我们要知道，只有珍惜规则，才能创建爱，才能让你能看到你的本真，和人性的本真，乃至世界的本真。

正如马丁·布伯所言，与我们时刻刻在，“我与它”是瞬问，而是“我与它”是对的，“我与它”不应该存。

对我而言，我深刻地认识到，只有当我能特护我自我空间，成一个有些强大自的人时，我更能更好地在一些时刻放下自我，去“构造”我与你关系。
