# 问答 | 不要急着改变

今天我们本周的第二次问答时间。

在回答之前，我特别想先谈谈 “改变” 这件事。

# —— 关于改变 ——

人们都希望自己变得越来越好，如果出现 了让自己痛苦的心理问题，也希望能迅速地 得到改变。

这是人之常情，也是 “出于人类本质的 自恋需求”。看过这位阵子的写作之 后，“出于人类本质的自恋需求” 这几句话就要成为我的口头禅了。

我的专栏，就得到了两百篇，大家上方 的留言中，我读到很多留言都是在着急 地问：自己怎样才能改变？

譬如一位朋友问：

+   老师，我听了很多期的文章有个疑问， 为什么我总是控制不住自己，比如刷手 机的时候，明明知道该停下来了，就是 停不下来，为什么，我总是控制不住自 己？

对于这个留言，我的回复是：慢慢来。

我给很多朋友的留言，都是这句话 —— 慢慢来。因为，心里想的事，总急不来。

首先，心理咨询有了精神的朋友可能会 知道，心理咨询师，特别是精神分析取向 的咨询师，不会轻轻易地给来访者提建议， 也不会解决，办法，只是试着去帮你探索 你的内心发生了什么？你的内心是怎么 在运作的，有什么有意识的东西被你忽略了 呢？

听完昨天课程的朋友知道，我一直有 一位精神分析师在为我做分析。在这个过程中，有一件事让我印象很深，事情是这样的：

+   有一次，约定的咨询，竟然被咨询师 放鸽子，她定忘了。之后，我的精神分 析师对我说，你可能是对我的愤怒，但你 没有意识得到这份愤怒，于是通过逃避咨询 来表达。

一般人在咨询中，我们会认为，来访者 突然间愤怒的话，要么是对咨询师拖延来咨 询的时间，很有可能在他们的潜意识里藏着 对着精神分析师的愤怒。

+   当时，我想，你说得对，我不可能 生她的气，因为她没有做对不起我的事， 我甚至一直觉得她是我生活中最好的朋友， 她怎么可能对我有恶意呢？

但咨询师说，你的潜意识里一定藏着 一份愤怒，你平时一直对自己很严格，不 允许自己生别人的气，所以你总是压抑 它。

想到这一点之后，立即地，这份怨 恨像火山一样喷了出来，我对着我的咨询师 爆发了。她告诉我，这就是潜意识在工 作，它一直想说话。

经过这次咨询，我有两个巨大的收获：

+   第一，我深深地体验到了，不压抑怨 恨的感觉，是多么的爽；

+   第二，我也充分意识到，我其实太容 易有怨怼的负面情绪了，我是一个如此不善 待自己的人。

这这对于我的自我认识，是一个里程碑 式的改变。这个改变，是源自咨询师的 让我看到了我的一个盲点。

# —— 潜意识怎么 “破” ——

再回到那位朋友的问题上 —— 潜意识 怎么 “破”？其实，潜意识正是最容易被 打破的，而能 “破” 掉。

这里说的 “破掉” 潜意识，就是把潜意识的 内容，提升到意识层面来，当这份感知 发生的时候，改变就发生了。

对于这个，印度哲人克里希那穆提说：

+   觉知既是开始，也是结束。可以说， 觉知就是一切。

![](bbox=[0.1, 0.78, 0.9, 0.88])

回归到我们这两周的内容来看，我们讲了 命运，具体展开讲是自我期待和权威期待。

+   本来，我们很容易以为，命运，是外 在的命运之轮在摆弄我们；而当我们意识 到它，它的命运，常常是来自自我实现的 预言之后，我们的认识就改变了。

在第二周，我们谈了罗森塔尔效应， 了解这个之后，如果我们发现，你以为的 “自 我实现的预言”，很可能就是父母等权威对 你的期待内化到了心里，那么这个时候， 你以为的稳固的自我，也会被 松动。

你发现原来那些关于你的自我， 是权威 给你的，你既然没有自我，那就 可以缓慢 改变了。

所以说，对于这两周和后边的内容，我都 抱着这样的期待：希望通过各种各样的方 式，帮助大家打开我们的潜意识，然后一 点一点触及我们自己，知道 “我” 是谁。

当然，这只能是一点点来。
