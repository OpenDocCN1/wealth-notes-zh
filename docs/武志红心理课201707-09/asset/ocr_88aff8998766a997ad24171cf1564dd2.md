# 问答：拥抱完整的自己

# —— 本周问答 ——

武志红
你好！
今天是周五，是我们本周的问答时间。我先回答一些用户的提问，然后再来做一个小结。

《之前一篇文章里说过，人们是去过往经历的总和，如果有一个和你有相同人生经历的人，那么很可能之间就会产生很大的缘分。就是说，我们的喜好，也和我们相似，也更容易吸引到我们自己。

武志红
从个人角度来讲，从我见过的案例中，人们在恋爱中，容易找和自己不同的人，实际上，异性恋，不管是不同的，也并不是吸引，而是相互吸引，吸引，一般都是一半。那如果是两半呢？

伴侣中还会认识到一种，一个人的内心，也会让一个和自己相反的人，和自己相似的人，彼此深深地理解，但并不是真正走到一起。所以，默契和互相吸引，是不同的。

*恋爱给人更大的动力，是追求人生的圆满，是不是告诉我们应该去找彼此互补的对象？*

武志红
我认为恋爱这件事最想说，不管你怎么论述，真让你陷入爱情的，总是强烈的感觉。到底能吸引到什么也是强大的，吸引你，也吸引你，是吸引力，也是吸引力。

*意识和潜意识是二元对立的，不是很容易解决吗，意识和潜意识没有相互统一的叫法？我猜想是二元对立的，意识中就一直处于对立？假如说，意识是显意识的？*

武志红
意识和潜意识合一的话，人就开悟了。
意识，就是我们愿意接受的心灵内容，潜意识，就是不意识或不被意识的心灵内容。对于前者，“我认为是对的，好的，可以呈现的；而对于后者，认为是不好的、羞耻的、不可以呈现的。所以，意识和潜意识必然是对立的。
当你发自内心地做一件事时，这时意识和潜意识就是统一的。而，这时也没有意识，没有潜意识。自然，也是没有意识与潜意识的对立。

“我觉得，精神分析治疗就是不断地将人的潜意识‘意识化’的过程。

文章看起来既是清晰又模糊，人要与自己的心连接，即使那些混乱的，恶的，可恨人不都是在追求好吗？如果更好，就越坏，那么怎么办？

武志红
我想说这个问题可以这样表述：在体验真实上，去体验真实的一切，在行为上，选择别伤人，不伤害别人。从终极意义上，这就是“不”，当看见到我们内心的一切时，也就会让一切照见了所有的内心。
太阳照在河上，照着自己的心说：此心光明，亦复何言。他能做到这一点，一个是关键，也是他的心达到清明了，也即内心自照，内心光明。

是不是一个人想越要成功，潜意识就是越不平静？一个人看起来越乐观，潜意识越消极呢？那么去住真实的善的方向发展呢？

武志红
自卑并不比自优越，悲观也不比乐观差，消极也不比积极差。我们都喜欢积极的方面，你不可能只要这一面而不要那一面。
关于真实，是《道德经》中非常精妙的论述：天下皆知美之为美，斯恶是；皆知善之为善，斯不善已。
这是认为人的头脑会去做分辨，一分辨，就出现二元对立，而绝大多数人都认为美好是好的，去恨和愤怒，就陷入了二元，而不是去追求和谐和平衡。

对孩子的教育肯定是引导孩子学习我们做的好品质，但就是常常看到原来家庭“不好”的孩子就会做出更不“好”的行为。这是我们父母的教育问题吗？还是我的理解偏了，或者是漏掉了什么概念？
