# ## 命运10 | 一切都是自传

命运10 | 一切都是自传

我们这一周的主题是“读懂他人人生脚本”，今天来进入第一讲“一切都是自传”。只有了解为什么说“一切都是自传”，才会更清晰地认识到什么是“人生脚本”。

# #### —— 一切都是自传 ——

一切都是自传，这句话的意思是，每一人讲的故事，都是自己生活的故事，就像每一位作家最最心至爱的小说，在很大程度上都像他们的传记。

打个比方，日本小说家村上春树，他最受欢迎的小说《挪威的森林》，就是取材于他自己的真实人生，小说女主角绿子的个性，和他的夫人阳子是一样的。

![](bbox=[0.15, 0.37, 0.85, 0.5])

他小说里写的年轻人，很多都有自杀和精神崩溃的预兆，关于精神控制，村上什么书里的形容是，身体里被别人装了一个什么东西。

也许，村上春树多次见过年轻的朋友自杀，这给他造成了巨大的冲击，于是他一生都在用小说化解这个伤痛。

除了这个以外，他也常写到井，有这样一个情节出现过多次：男主角分进井底待着，后来发现，井底有一条路，走出去，就是他要去的目的地。

而这个“井”的出现，也跟村上春树自己有关系，他解释说：我的理想就是继续待在井底。

我特别喜欢他的这个关于井的隐喻，所以在给我的书签签名的时候，我经常总会写下这样一句话——深入你的潜意识之井。

话说回来，比起《挪威的森林》，其实美国小说家丹格瑞特·米勒的作品《飘》，更像是一个地道的自传。

在《飘》这本书里，米勒幻造的女主角斯嘉丽，既是经典的强健美国女性的形象，也是她自身形象的变形。小说故事的发生地亚特兰大，就是米勒出生长大的地方。女主角斯嘉丽的家庭结构，和米勒的家庭也很相似。
