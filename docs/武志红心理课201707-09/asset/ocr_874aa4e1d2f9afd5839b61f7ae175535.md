# 自我02 | 自我的疆界和力量

我们这一周的主题是“衡量自我的五个维度”，今天是第二讲“自我的疆界和力量”。

自我的力量很好理解，就是指一个人的人格中，蕴含着的力量。

自我的疆界，是指的每一个人的自我，可以伸展开的空间。是自我很小的人，他的自我只能笼罩一个很小的地方，而自我疆界大的人，他的自我，能伸展得更宽广。

如果从关系的角度去考量这一对维度，那么，可以这么说：

自我的力量，指的是一个人的
人格中，“我”本来就具备的力量；
而自我的疆界，指的是“我”对外界的感知和态度，这个“我”指的是你。

# 自我的疆界

如果一个人将外界感知为敌意的，那么他就会倾向于缩小自己的疆界。

有些人理解不了概念去旅游。我相信有些朋友会提到过这个麻烦——现在是最寒假假期，你可能计划去一个远大的目的地，
然而，你要么是拉不动你的伴侣，或者你的父母。

他们在生活中大多数是好人，有点封闭、被动、消极，对旅游缺少兴趣，如果你们拉动了旅游团体，你也会发现，他们不去看风景，不去品尝美食，不去尝试有趣的事物，而更喜欢在旅馆呆着看，
或者一直看手机，你的计划缺乏热情，这时不时地说归家的话。

这其实是因为，他们自我的疆界不够。
他们觉得，只有在自己家的地盘上，才
觉得自己的自我。他们中的有些人甚至在家里，都不能伸展自己，而是让自己和手机、
电视、报纸、网络、股票联系在一起，他们
的自我的只能伸展到这里。

至于家以外的广阔世界，他们有着敌意
感知。他们觉得外界世界是不够友好的，
他们不能在外面很好地做做自己，这会导致他们不在自己熟悉的外部世界里生活都

虽然他们并没有积极去做些什么，但因为一直在做这，这使动就使活着的自己也可能
得劲，知道，于是陌生的世界里，他们总是畏畏缩缩。

你感到非正常，不建这个被动物极
在奔跑、你，他们，他们，他们，
他们，他们，他们，他们，他们，他们
做了更多的事，你什么都没，而这个
没什么事的人，却是是喊得最响。

因为，你的自我疆界更宽了，你到了一
个新边疆，你有着全新的觉，至少你
觉得，在这个新世界里，你能做主，你
做得了，而不是消极，而是兴奋，你
和事物或人建立起联系，都让你感觉
你的自我变得更强健。
