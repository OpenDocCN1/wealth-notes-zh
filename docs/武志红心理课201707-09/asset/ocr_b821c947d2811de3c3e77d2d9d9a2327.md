# 附录：俄狄浦斯的故事

俄狄浦斯是古希腊三大悲剧《俄狄浦斯王》中的主人公。

他是忒拜王的儿子，但忒拜王相信了一个预言——他的儿子有一天会杀死父亲而与母亲结婚，于是命人杀死自己儿子，并且将孩子而与母亲钉在一起。

然而，这个执行命令的人不忍下手，只是将他丢弃在山上。后来，一个人来救俄狄浦斯而将他送给邻国科林斯国的国王做儿子。因为他是双足间病，于是邻国国王夫妇给他起名叫俄狄浦斯，意思是脚肿胀的脚。

俄狄浦斯长大后，听到传闻，说他会弑父娶母，这让他很恐惧，于是离开科林斯国而四处流浪。
