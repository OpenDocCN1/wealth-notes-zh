# 问答｜我如何识人

在看开始之前，先声明一下，今天这篇文
章的个性化色彩比较重，喜欢就接着下
看，不喜欢可以有意见，也欢迎提建议意见。

先讲一个故事。

很多年前，一家国际性的心理咨询机构
来广州做培训，来了两个大咖，一位是这家
公司的女老总，一位是这家公司的心理学总
监，这位心理总监，在业内是赫赫有名的人
物。跟他们同行的，还有一位心理咨
询师朋友。

这个培训，我去了半天，然后在我这位朋
友坐飞机离开广州之前，我给她打了一个
道别的电话，不经意间，我说到，别看你
们的心理总监是专业牛人，但比起我们老
总来，他差得远，女老总笑道，在业内是
赫赫有名的人物。

我这位朋友被惊到，后来她下了飞机以后，
又给我打了电话，问我说，他们都是绝
对很多事才发觉我们就的这个事实，我又不
是怎么在两天内看出来的？

我那个时候也不是特别准，就是这么发生的。
于是回答说，都凭直觉，并且这种直觉
通常就发生在见面的头一瞬，一般不会超过三分钟，有时候闪一下就可以。

这种闪电般的直觉，有的时候简直都可以
让我洞见到一个人心事。我的高中好友哥
们结婚，我在他的婚礼上第一次见到他
妻子，当时我立即崩溃，也差点泪奔，这
种情形就是和身体反应是发生的，然后
我心里才冒出一个判断：这个婚姻不太合
适了，我这哥们难了。

如果，后来他的婚姻成了他的噩梦，严重
影响了他人身。

信任闪电般的直觉，是我从小到大都在用
的一个方法，后来随着对心理学的进
解越来越多，我相信人脑的方法，也补充了
起来，加上系统学习心理学之后的理性观察，也加上了另一个绝招——用身体去感知。

这里要特别说，我是怎么闪过的。

我们的心乐心理中心，现在已发展
到七个城市，而作为创始人，我面试过几百位心理咨询师，上百位工作助理，
以及几十个公司主编和各种岗位。

那么，怎么去使用聆听身体的功能呢？说
就是，专注地听别人讲话，并且留一部
分注意力到自己身上，对自己说，欢迎
你对所有信息穿过我身体。

如果对时间来说，在面试开始之前，我会先
做一下感受身体的练习。这是为了让头脑
和身体建立起连接，可以闭上眼并放松，
静默感知一下双脚在土地上的感觉，
臀部坐在椅子上的感觉，感受一下双手，
同时自然地呼吸……

接着，在开始面试前，我会让大脑空

这两点能做到，话，我一看到面试对
象，就能既有身体感觉，也会有直觉的
判断，再加上对面说对的其他共性
信息的整合，我的判断就可以尽可能完善
合理。

例如，有的面试官进一听到房间，我会
有要失去重心的感觉，好像坐着椅子不稳。
这种情况是，好像是面试官有些问题
的失控。这个时候需要关注的主要是对
象，他们的失控是暂时的，还是人格层面的，如果是我们对的，他们自我稳定性
会不会有问题。
