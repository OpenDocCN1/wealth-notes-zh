# 关系101 关系怎样疗愈一个人

我们这一周的主题是“我与它，我和它”，今天这是第三讲“关系怎样疗愈一个人”。

# 关系哲学和关系疗法

最近我们的专栏一直在讲“关系”，关系和自我有一个非常对立的矛盾：关系是滋养着你，还是损耗着你？

如果关系有很大的“用”或“力”的特质，因为“终端很顺”的效用，那么关系就会成为滋养的部分；

如果关系有“力，‘我与你’了，那么除不开拥有权力距离，它会成为你上位变，否则他会感觉到：关系在损耗着你。

马丁·布比的哲学，和人性主义心理学家罗杰斯的理论，有很多类似之处。马丁·布比的关系，叫关系哲学；罗杰斯的疗法，也叫关系疗法。

罗杰斯将心理咨询师和来访者的咨询关系，视为治疗中最最重要的因素，而不是咨询师的技术。马丁·布比的哲学和学术来说，将咨询师使用技术时，就构建了“我与它”的关系；当咨询师使用本心时，就构建了“我与你”的关系。

罗杰斯特别强调，他的疗法是“来访者中心疗法”，也就是说来访者才是咨询关系的中心，咨询师重要的就是理解和接纳来访者的感受。他有一句名言：爱是深深的理解和接纳。

# 构建咨询关系的三原则

罗杰斯对咨询关系的重视，到了一个前所未有的高度。关于构建咨询关系，他提了三个非常简单的原则：

+   1. 真诚
2. 共情
3. 无条件积极关注

真诚很好理解，要做到却并不容易，因为真诚意味着：我所想的和我所体验的是同一的；我所想的，和我所表达的也是一致的。前半部分容易，不骗别人就好；但后半部分极难，因为要做到意识和潜意识的一致。

我们之前讲过“共情”，就是设身处地地站到对方的位置上，感受理想人想什么，更通俗的理解，其实就是深深地理解和接纳对方的感受。

无条件积极关注，它也基本等同于“无条件的爱”。顾名思义，无条件的爱就是：我对你好，是没有任何附加条件的。父母对孩子无条件的爱，会让孩子的自我被解放，孩子就能自己寻找精神胚胎的声音，走向成为自己的道路。

相反，有条件的爱就是我认可你、鼓励你、接受你，是有条件的，你必须达到这个条件，我才给你这些你想要的。如果达不到，我就不给。

现在的治疗流派，基本都接受了罗杰斯对治疗关系的论述，认为是说治疗成功的非常重要的因素，大多数人只是把它当作一个必要的基础，但对罗杰斯来说，治疗关系就是全部。

罗杰斯认为，越是高质量的治疗关系，能让一个人安全、自然地、自如地呈现自己，而这也可以让他超越受伤害的早期体验，治疗就越可能成功。这里成功定义的，就是帮助来者更好地成为他自己。

# 机体评价过程

为什么这样的治疗关系如此重要？因为在日常的关系互动中，人的本真自我很容易隐藏，甚至被扭曲。

我认为这里面原因在于，人们获得的关注大多是有条件的积极关注，它的逻辑是，你必须达到条件，人才能给予你赞赏。在这样的逻辑下，一个人会这样说他的经验：只能表现别人或集体认为“好”的东西，否则就会被拒绝、排斥，甚至遭到伤害。于是，长此以往，就成为了一个不断学习修正自己的历程。

罗杰斯还说，一个人必须相信自己的“机体评价过程”，这个意思是说做选择的时候要听从自己的机体，这个机体，可以理解为心和身体的总和。

如果我们理解了有条件积极关注，就会懂得，那些“你必须达到，我才能给予你”的逻辑都是借植在你大脑中的，你为大脑中的东西，是你的内心的，但其常常是权威和文化传递给你的。

相反，如果你得到足够的无条件积极关注，你会信你信任的你的评价系统，其实也是我最具信任感的“内部评价系统”，但对于习惯了有条件关注的人来说，很难相信自己的机体评价过程。罗杰斯的关连治疗，就是试图提供无条件积极关注，让来访者感受到，关系原来还可以是这样的。

我认为，当来访者身感受到这一点后，他在治疗关系的空间里会感到安全，从而慢慢放下防御，开始坦然、真实地感受体验自己内在的重要体验，真正地接受这些体验。而按照罗杰斯的定义，体验就是一个人的“我”。

当来访者在治疗中做到这一点后，慢慢会获得一种勇气，从而发现在现实中也能依照“我”的机体评价过程做出选择。其他治疗关系，依然有这样的因素。我在上下两的预感中，给大家留了作业，从留言中可以看到，让大家感动的、印象最深刻的关系，都是滋养了自己，让自己更加信任自己的体验的。

# 无条件积极关注

我的一位朋友，他认识我时，正好在和孩子的周围两件事来做无休止的扭歪道义：战斗，这两件事是吃糖和看电视。

我这朋友，他高度近视，所以特别害怕儿子和他一样，虽然孩子现在眼睛没问题。

他试图为孩子找到各种可能导致近视的因素，然后剔除掉这些可能性，比如说看电视有可能导致近视，所以他会让孩子少看电视，听不听；吃糖多也对眼睛不好，所以不让孩子吃糖。

这是他担心的，但是对孩子来讲，担心的后果是：如果他不听话，老爸就会不高兴，或者生老气，所以孩子有抗拒的听老师话的。但是，看电视和孩子最想要的诱惑太了，老的压力太，所以孩子也发展了各种方式，和老爸打起了游击战。

具体来说，当老爸在时，他就不吃糖不看电视，一旦不在他身边，他就跟电视或吃糖，他就这样来吃糖。

我这位朋友为这件事很苦恼，他把这件苦果进行一番梳理，他跟我说：“你对我孩子进行一次心理的倾听，看看他导致近视，吃糖会导致近视，而孩子现在正在控制不住他老爸，那么当他想电视想吃糖的时候，老爸的压力太，所以孩子也发展了各种方式，和老爸打起了游击战。具体来说，当老爸在时，他就不吃糖不看电视，一旦不在他身边，他就跟电视或吃糖，他就这样来吃糖。”

我的这个回答让他恍然大悟，然后他就不这么做了。后来，当他用“无条件积极关注”的概念，他开始发现，无条件的接纳，都是从自我组织里来，孩子都能自己组织里来，孩子都组织里来，无条件的接纳就做到了到组织里来的地步。

比如，孩子考试不好，非常容易，在家里发脾气，然后会对孩子的负面情绪进行干涉。但最后，孩子说：“你看，你这生，是因为太想考好了，那我们研究一下，以后可以学得好。”

后来，他们移民国外，孩子在融入当地环境是有一些困难，但这位父亲更愿意保持无条件积极关注。先是关注孩子遇到的事件，接着寻找什么他去理解，而做或情绪上的动力系统又是什么，然后去想怎么去改变和解决。

他的这个做法起了很大作用，现在的儿子心态很积极，也能在遇到困难时找到积极因素，在和朋友交往时也能很好地使用无条件积极关注。

关系就是一切，一切都是为了关系，我们不能再离开关系生活。但是，我们的需要去分离，一个关系，可能是滋养的，也是损耗的，衡量标准就是在这个关系中，有多少无条件积极关注，又有多少有条件的部分；有多少“我与你的成分”，又有多少“我与它的成分”。
