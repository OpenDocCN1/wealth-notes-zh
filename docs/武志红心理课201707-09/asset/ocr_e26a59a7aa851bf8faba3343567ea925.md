# —— 头脑与身体 ——

今天，是这一周的第一次问答。我发现自己已经开始习惯了，会把大家的留言先可能看一遍，然后说说话我的感受性总结。

第一个特点是，留言的大多数是男性，都过身心合一的体验，并且大部分朋友也都是，是各种各样自身体有体验的中体得到的，有时是体育竞技，有时是其他活动。

当然，这个总结不够严谨，因为在我本周选中，发出的问题是："你曾在任何一种竞技比赛中体会到"放松和专注"的状态吗？"因为这种的限制性的小问题，大家的回复自然会受到制约。

现在，我已经发布本周的三篇文章， 所以可以问一个开放性问题：

你什么时候曾经有过印象深刻的"高峰体验"呢？

都来说说吧。我会看看大家的这些体验，看看会有什么不同。

第二个特点是，本周的文章，回复和点赞，都明显少于前两周。

为什么呢？一些朋友的留言可能给出了答案。很多朋友说，"这周的故事故事都是体育方面的，我没有敏感。"

也有朋友说，这几周的内容，他没有读懂。
这或许有几方面的原因。第一，我写得不清晰；第二，很多女性朋友，确的对篮球不太了解，也不想了解；第三，一些朋友在体育方面少了一些体验，所以在听谈本周文章的时候，就觉得和自己无关了。

其实也不是体育达人，体有成绩在初中和高中里，都是列升的倒数第二名。

我们都知道，我们中学生的体质，是比较差的，原因很简单，体育课、音乐课等等，都给主课让路了。

与我们明显相反，是英国。在英国的中学，无论男生还是女生，都非常重视体育，体育学的学生，爱好程度，可以远远地超过只学过主课成绩好的同学，学习成绩好但体育差的学生，被视为书呆子，容易被霸凌。

所以必须感慨一句：还好我生在中国，我们现在就是典型的学习或我生在他国或他地的那种学生，如果到了美国这样的国家，也许会成校园霸凌的受害者。

这是半认真半开玩笑的，但说了一句非常认真的话：

我们必须反思，我们的文化是不是严重忽视了我们身体。

我总感，手无缚鸡之力之白面书生，在我们文化中是被美的，而一谈到身体健全的的人，好像总是容易归为这么一句话——身体发达头脑简单。

然而，离开了身体，只剩下头脑，会是一件非常可悲的事。

中国当代艺术家四大"天王"之一的方力钧，有一个让我印象最为深刻的雕塑作品，是一个人，只有胸、手、脖子和头，没有身体。我在我的微博上说到这个雕塑的时候，有一位朋友说，他父亲看到过这个雕塑的时候便叹一声，然后说，天啊，这不就是我自己吗？

# —— 放松与专注 ——

我们回去想想，身体是什么？头脑又是什么？

在以后，我会专拿三个月的时间，三章的内容，来谈头脑、身体与情感的复杂关系。

单从这两周来看，我们知道维萨·加兰曾有说过，自我分为两个：
自我1，是以头脑和意识为核心，容易发出好坏对错的评判，它的语言是文字；
而自我2，是以身体和潜意识为核心的，它是语意的直接体验。

当我们只处于自我1的领域时，我们会被"头脑性"的对待判断所限制住，还会引起各种身体的紧张，从而不能在体育竞技中发现最本体的潜能，而当我们在自己的领域工作的时候，我们就放了个"头脑"的对错判断，可能会达到身体合一的奇迹。

这当然不只是体育领域的事，其实仔细看每一位朋友的高峰体验，都可以发现，在这些体验中，你是因为有放下头脑与意识的语言化，所以体验到了"合一"的奇妙。只不过是体育方面的活动，更容易让你体会到这一点。

跟你分享一个我生命重要的转变历程。

在心理咨询中，也许是最基本的一个概念，共情。在之前是我主要人主义大师罗杰斯提出的，它的操作性定义是，设身处地地站在对方的立场，感人所感、想人着想。

我在北大读书的时候，对共情做了各种思考，但我总得这玩意实在太难，还怀疑它简单不够。我们怎么能感受到对方的感觉，想到对方的想法呢？我觉得，共情是一个"道"的技术吧，对方讲了普通话，我试着去理解他，并问对方，我这样理解的话，不知道对不对？

这就是，我总在头脑里达成共情，但根本就不可能，现在我明白，因为头脑不能建立和对方的连接，只有身体和情感才行，而共情就是联接。

直到2008年底，我去学催眠。催眠师布兰德老师向我推荐了得悉弟子斯蒂芬·吉利根，他在班上给我们讲过"身体去聆听别人讲话"。他说是"身体"，试着去留意聆听对方讲话时你身体的反应。

然后我震惊地发现，我竟然能在某时刻，感受到对方身体的感受，当我头脑放松下来，全身投注地聆听时，我的身体和情感状态都能奇妙地共振到对方身体的情感和感的变化转化。

当感应他人所感的时候，我也就能感他人所想了。这就是"身体共情"，如果有人进入对方的身体，他还有这样的感受，那他会想些什么。

这个听着简单，但不容易，我以后会专门谈，会详细谈，今天只是提了一下。

从我的讲述中，我想你也看到了，我也是在"放松而专注"地聆听对方讲话的时候，就能做到共情。

所以，"放松而专注"的秘密，不仅是加兰在体育竞技中的发现，其实也是一种生命哲学，一种朴素的技术。
