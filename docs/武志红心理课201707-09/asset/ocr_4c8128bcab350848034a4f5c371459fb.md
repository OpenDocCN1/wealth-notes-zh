# 命运11｜轮回，是为了疗愈

今天我们进入十二周主题的第二讲“轮回，是为了疗愈”。

有的人会把命运和轮回联系在一起。佛教意义上的轮回通常是指前世今生，但我们其实这里主要讲的，就是不断地在“轮回”。

我们这里讲的“轮回”，是心理学的一个概念——叫“强迫性重复”，并且，这个“轮回”，其实是我们自己追求的结果。

# —— 强迫性重复 ——

心理学家弗洛伊德很早就发现了这一点。1920年，他发表了一篇名叫《超越快乐原则》的文章，提出了“强迫性重复”的概念。他发现孩子最最喜欢的玩具是从小床里扔出去，再哭着把玩具要回来，并不停地重复这个过程。

弗洛伊德认为，在这个过程里，孩子是把玩具当成了妈妈的替代品，他们在不断把这种玩具重新扔回到，其实是希望在反复体验妈妈同时不会离开自己所带来的创伤。

![](bbox=[0.08, 0.43, 0.72, 0.5])

这些重复体验是有价值的，这也正是“强迫性重复”的意义，主要包含三个方面：

首先，因为妈妈时常不时的离开，这个行为是妈妈在主导，是孩子不能控制的。而在扔玩具的时候，其实是孩子在主导。他们可以用这种方式，好像能把不受控制的创伤，变成了自己能部分控制的创伤。

其实，我们成年人也有类似的行为，与某一个关系里被伤害，不如主动去甩掉别人，这样才可以保护自己的自恋。

第二，不断地体验这个创伤，可能会让我们对创伤的耐受度提高。

第三，在新的轮回里，会产生新的可能性，能疗愈这份旧的创伤。

在这里，命定要重复一万遍，成长的人生，就是不断地去经历各种创伤和学习处理创伤的过程。在这个过程里，可能还会包含一些哲理，像诗人鲁米就曾经写过这样的诗句：

> 伤口是光进入你内心的地方。

所以，我们可以不必对创伤这个词汇太敏感。

通过上面的解释，你了解了“强迫性重复”这个概念之后，就会发现，不在同一个地方跌倒，这句话是很少有人能做到的。

其实，“强迫性重复”的不只是创伤和痛苦，任何一种情感模式都会重复。这就可以寻到——简单的说：我们多数的人生，就是一个不断地重复同样的事情。

如果你得到了幸福，你就重复幸福；
如果你学会了信任，你就重复信任；
如果你学到了痛苦，你就重复痛苦；
如果你学会了欣赏，你就重复欣赏；
