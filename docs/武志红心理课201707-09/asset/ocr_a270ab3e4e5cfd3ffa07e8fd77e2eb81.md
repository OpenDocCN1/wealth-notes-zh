# 问答：“失去自我的迷恋”和“忘我的爱”

问答：“失去自我的迷恋”和“忘我的爱”

武志红

你好！今天是周五，是我们本周的问答时间，我来回答大家的一些问题。

先总结一下这两周预告中的调查，上周我们调查的问题是：这个妻子，和谁的关系让你印象最深刻？本周的问题是：你体验过忘我的爱吗？

第一个调查中，大多分享了感人的、滋养性的体验。例如：

和病男子的通信是我印象最为深刻的一件事，当时正值我抑郁抑郁四年，他为我打开了一个崭新的、生机勃勃的世界。虽然他们没有交流讨论我的各个状态，但似乎他的生命滋养了我的，我为他的生命打下了根基。尽管后来我们分手了，我还是继续在他为我打开的世界里摸索、前行。十多年过去了，我的世界已经完全摆脱了疾病的困扰，拥有了幸福平和的生活。感谢遇到他，珍惜后来老师以及大家的心路之旅。

本周的调查，本意是想大家关于那两种个人的自我都消失了，然后深深相遇的体验，但多数朋友讲，是“失去自我的迷恋”：

初恋真的很深刻，根本就是他无我，哪怕感到他在电话里说了一句可能的负信息，都使我的心就要停止了，崩溃了。太可怕了，再也没有那种状态了。

不过也有用户分享了“忘我的爱”，例如：

当孩子出生的那一刻，我的心里眼里只有他，我觉得他很神奇，或者干脆就是一个奇迹，当一个胚胎，长成了会哭的、会笑的、躺在身边的娃娃。我突然很珍惜他，甚至想把全世界都给他，这种愿望有特别强烈！在他出头的日子里没有过这种想法，这一刻突然有了……

在我的理解中，“忘我的爱”是亲双方的自我都消失了，这个时候，我的本来遇到了他的本来，自我虽然消失了，但却到了真正的存在感。

相反，“失去自我的迷恋”是以对方为中心，而失去了自我。这时，对方自我极为重要，就相当于是，自己的自我被对方的自我给消了。不过，实际上，对对方这时的体验常常是，自己的自我被对自己的自我消融了。我在广州和深圳的得到小组同学开会时，问了大家这个问题，结果每个人最初想到的，也都是这种“失去自我的爱”。

我不禁让我想到，也许“失去自我的爱”也有重大的价值，就是破坏牢固的自我，因为自我和固恋，就像一个壳那样包裹着我，切断到我和别人的链接，这个壳要被磨裂、被破坏、被敲碎，然后光才能照进来。

想想我自己，有点自虐一样的宅男状态出来，最初就是靠了迷恋的力量。正如鲁米所说：伤口，是光可以照进来的地方。

推荐一本书，名叫《强迫的爱》，是我非常喜欢的美国心理学家苏珊·福沃德的作品，内容关于失去自我的迷恋相关，想要了解这方面知识的话，可以看看这本书。

一个从小没有被看见，习惯隐形人一样活着的人，长大后天怎么能做到别人看见？

武志红

隐形的人，意味着在关系中总是隐藏自己，因此没有存在感。同时，因为接触不到自己，也无法去接触别人。所以，会有可怕的孤独。

我觉得办法是，努力去构建关系，将自己内在的那种渴望，大那里展现出，伪装累死人的无存在感，当然表现出来，是虚假性的关系，因此要去靠近那些温暖的、阳光的、善于理解和倾听的关系。如果在生活中很难，可以找心理咨询师。

罗斯托说：“我是一切体验的总和；蒙特梭利说，精神生活的开始是你感觉。所以，好玩用心去体验一切，不只是人际关系中的，也包括和万事万物的关系。

> 分享一段佩玛的请诗：

让你成为一个不吝啬的人，

以你所拥有的。

闭上眼睛，与第三只眼睛观物，

伸出双手，要是你希望被拥抱的话。

与别人建立关系，我的存在才有意义，只是很独立一个人，我没有意义。但为什么人会享受孤独，我不需要么，反而独处会让我感觉舒服呢？

武志红

独处时，一切都是自己可以掌控的，这可以很好地满足自己的自恋。在关系中，对方是自己没法掌控的，所以自恋容易受损。

太孤独的人，我个人认为是渴望型而不是，于是退行到孤僻中。当然，孤独的自享享受感也非常重要，有独处就是最好的休息，但没有“关系”，生命就不能展开。我也可以这么说，独处再好，生命也是缺色彩的。

为什么那些很宅的人，会认为自己不需要被那么多人看见，或者被那么多人看见会觉得不自在，尤其在公众场合？貌似他们觉得自己不厉害，或者需要特别少？

武志红

我觉得可以试试，让这些很宅的人，自己待上一个周、一个月甚至三个月，体会一下这种状态。要知道，闭关是修行中极大的挑战。

我认为，彻底没有极看见的人，在婴儿时就会遇到很大的问题，而被看见极少的，入也会面有种怪异的问题。

此外，我还觉得，所谓宅宅宅宅，其实仍然涉及在关系中。有人关注会觉得不自在，意味着他们内心可能还没处理好，有很多东西在黑暗中，怕别人看见，可能会投射到别人身上，看别人不顺眼。

自己是否可以成为自己的镜子？如何去修炼？

武志红

我认为，一个能很好自省的人，自然是在有一面内的镜子，但是，这面内在的镜子，最初必然是内化了一个好的客体的结果。

书是镜子，历史是镜子，但都不知人这面镜子重要。

文章中说：他们有一种心理需求，希望有一双爱着的眼睛，能看到他的头。就好像看到很大的问题，看不到他的头，好像看见了自己。我和朋友关系更更多的是，知道人变人很少了。在一起快10年了，婚姻还算平淡，如何才能成为对方的镜子呢？

武志红

我认为，婚姻中必须看彼此体验，多沟通感受，如果不能就就彼此的生命力。

体会和感受，简单地分为两种：爱和恨。所以，在婚姻中，需要好好来表达爱，也要好好学习、理解和接纳对方的恨。

现在很多人都喜欢发朋友圈，恨不得把自己一点事情都告诉别人，这是病吗？在关系中，会消除自卑，但人不是都是自卑的吗？这不会自杀矛盾？

武志红

渴望被看见，是巨大的、根本性动力，所以，现在全球人都得了一种共同的病——手机依赖症。

人是自由的，而真正的关系，会让人走出自信；体验到，我就是你，你就是我，我就是万物，万物都是我。
