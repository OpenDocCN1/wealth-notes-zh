有朋友注意到，这周我很少回复大家。

因为，这一周大家的留言都非常个性化，我很难回复，毕竟是大生命中的细节，我要反复回读，就得安静下来，细细去读，不仅要从文字上读懂，还要去体会这些细节背后的各种感受。读懂一位朋友的三个关键细节，我感觉就要用不少时间了。

并且，这些关键性的生命细节，这些我认为的“生命隐喻”，也的确是需要你自己去解读的。

今天，我介绍一个读懂这些细节的方法。这个方法，你就可以用在自己的身上，也可以用在聆听别人的故事上。

这个方法，是佛法中的“四念住”，不过我做了适当修改，把它变得心理学化了。

# 解读的五个要点

四念住，是佛修行业中的一种基础法门。它有四部分：身念住、受念住、心念住和法念住。

四念住是极为精深的佛学修行法门，我没接受过，所以并不真的很懂，如果大家感兴趣，建议跟着真的老师修学一下，它必须经过实修，才知道它是什么。

我虽然做了念住的术语，用心理学的概念做了一些修改，它可以被理解成：精细地觉察自己的身体、感受和心的变化，以中正的、不带评判的态度，只是如是、如实地观察。

要观察什么呢？佛家里“四念住”的观察对象是身、心、受和念头，不过，我把这三者变成身体感受、情绪情感和心理活动。

譬如，你有一个关键的命命叙事，你想读懂这个生命隐喻，那么你可以根据我下面将告诉你的五个要点，对照着做。

# 1. “具体化”回顾

先回顾这个事件中的细节：它发生的具体时间，是白天，还是晚上，具体是几点钟？回顾地点，国在哪里？还可以回顾那个事情里的人物，一样都是越细致越好。

为什么要做这个回顾？这是为了让自己回到当时的场景中，你越是能回忆起更多的细节，就越能全方位地回到当时的时空里，并唤起当时的种种心理变化。

做催眠的时候，催眠师有时也会做这个工作。在咨询中，当来访者谈到了一件非常重要的事，我也可以使用这个方法，让来访者谈论关于这件事的种种细节。

在第一周的课程里，我们讲过，这是“具体化”的谈话技术。

# 2. 探究感受

当“具体化”的部分完成，你陷入到当时的状态后，你会发现，你的内在活动有更多的东西，有时甚至会出现一些，这时你可以使用“四念住”的方法，来更结构化地观察自己的心理活动，你可以问自己三个问题：

+   - 我的身体感受是怎样的？这可以更具体，例如是我的视觉、听觉、嗅觉、味觉等等的感受是怎样的，还有我的内脏感觉等各种身体感受。

- 我情绪情感是怎样的？我有什么样的喜、怒、哀、乐、悲、恐等情绪体验？

- 我的思维是怎样的？也就是说我在想些什么，思想要更注意，我有一些关键的想法出现吗？

# 3. 不带评判地去觉知

观察自己的时候，保持“念念住”，也就是中正、不带评判地去觉知，这份观察里出现怎样的东西，就是怎样的东西，不修改，不添加，不评判。

并且始终保持觉知者的视角，无论当时的身体感受、情绪情感和想法多么强烈，都不要把它认为是“我”“自己”。

这个原则，编辑让一位感受“想法流经自己”，但是不要去认同，也不要试图去“知道”和“不知道”的冲突，这是为了让自己的“知道”和“不知道”都自然流动，避免二元对立。

当然，说“觉知”也许太玄了一点，因为当你做到了完全“不知道”，这本身就是一种知道，这就进入了禅宗的境界，我们这里先不谈这些。

但是，当我们“知道”了什么，这个“知道”本身就是一种执着，就会变成一种新的障碍，这就是我们所说的“所知障”。

当我们试图去“知道”的时候，我们就偏离了“觉知”本身，觉知是在没有“知道”的参与下，直接体验当下的实相。

# 4. 慢慢来

在回顾时，我们可能会发现，原来自己一直在逃避或者压抑某些东西，比如童年的创伤，或者是对某个人的愤怒。

当我们慢慢去观察这些，会发现它们其实已经改变了，或者我们有了新的理解。这就是疗愈的过程。

# 5. 寻找隐喻的支撑

最后，我们要找到这些生命隐喻的支撑，比如文化背景、社会环境等，这样才能更全面地理解自己的经历。

通过这五个要点，我们可以更深入地读懂自己的生命隐喻，并从中获得成长和变化。
