# 谦逊与骄傲

昨天，我给大家留了一个问题：一个社会的A与A'，还有在共同文化中的，那么常见的A与A'，比如，在我们文化里，谦逊是美德，那么，骄傲就是我们文化中的A'。然而，骄傲到底是什么呢？

一直听我们专栏的朋友可能会想到，骄傲不就是我们一直防的自总吗？如果我们做不到就视为A'，那咱们岂不是否定了人类最本质的一个动力？

关于这一点，给我讲一段国内精神分析学家曾奇峰老师的一段话，这段话会让听众去上老不老的。

> 他说：其实谦虚会让人摆摆，越谦虚，越繁琐，越摆。谦虚到骨子里，就摆摆到骨子里。

不知道你是否认同这句话，我个人非常认同。有实际上，我是就是那种谦虚到骨子里可能会一股灵魂体那种人，现在脸上很多出来，且能现在，我拆除了很多，常言说一些自大的话，然后，脸皮很劲，也就少了很多。

这是怎么回事？因为，谦总并非是人类本性的什么，骄傲与自总才是。如果我们的本性的自总并没有转化，奴从力表现出来很强，于是，谦虚，便是灵魂的，认识的，甚至就是假自的，有子西面的。本性的状态还是满满的，但比份满满的自总，就被人视为是“坏的”，所以不能表达自己。一旦表达的“坏的”，我们觉得，自己表现了一个坏的特质，这时就有感情痛，罪恶感，并且还偷偷摸摸的感觉，所以就流念成了跟奴的性总。

# 自总、性和攻击性

我认为，任何涉及人类本性的东西，都是这样的。当你把某一种符合本性的动力化为A'的，并且压总去追求时，这时会给人一种感觉，A'，那么，而如果人们把它视为坏的，但是它又不住要去追求时，这时就容易出现一股摆摆劲儿。

这就产生了一个问题：人类本性都是什么？

弗洛伊德有一个著名的说法：性和攻击性，是人类两大动力。就是说，在弗洛伊德看来，性和攻击性，是一切行为背后的推动力。相对而言弗洛伊德对性更重视，因此他的理论被称为“泛性论”。

弗洛伊德的理念会到什么地步呢？比如弗洛伊德做梦时，会认为，梦中的一切丑恶的东西，都是性欲望的象征，一切容器，都是女性生殖器的象征。

弗洛伊德之后的精神分析学家们，越来越重视攻击性，例如我们一再提到的温尼科特和克莱因，他们都认为，攻击性是一切行为的动力。

唐纳德·温尼科特（Donald W. Winnicott, 1896-1971），美国精神病学家长，客体关系理论中。在弗洛伊德非凡的精神分析流派中，温尼科特具有非凡创造精神和独特视角。他远离了弗洛伊德对本能的强调，专注于儿童怎样、间养和父母与孩子的相互作用如何，弄得或者引导儿童自发的，他让英国BBC的“儿童节目”中，帮助了成千上万的父母，使他们能更好地了解孩子的情感世界。

梅兰妮·克莱因（Melanie Klein, 1882-1960），奥地利精神分析学家，儿童精神分析研究与客体关系发展，先后师从弗洛伊德的学生费伦齐与阿伯特拉，他提出了许多有深远意义的见解，开起了理论最早期的心理防御的途径，但是弗洛伊德后，对焦虑的研究是发展其自体及的领先人物之一，她不仅扩展了弗洛伊德的驱力与防御的范畴，还建立并富原创的思考系统，更影响了精神分析的发展趋势。因感染死于英国伦敦。

在我看来，我认为还可以把自总加进来，以总结说，自总、性和攻击性，是人类的大动力。

说到这，不知道你有没有想到，A常常就是这三大动力，我们反对自总，A是常性，也强调克制怒怒。我认为是这-件可怕的事，如果说，这三大动力，就是生命力，那么，我们反对的A'，不就是生命力本身？

依照弗洛伊德的说法，文明就是性能量压制的升华的结果。所以，在弗洛伊德理性上就是A'，也正是A'。至少在弗洛伊德的维多利亚时代，这是对的，整个欧洲都处于性压抑状态。

现在的精神分析治疗师所强调的，是如何去安定去求攻击性的，后来来访者的攻击性去变就成了“好的”生命力，热情等；而去求去攻击性，就把攻击性视为“坏的”。

比如我在我咨询时就会对来访者说，只要你不攻击我的身体和我的身体，你怎么表达你的攻击性都是好的。关于如何去接纳转化攻击性，以后会花很多篇幅去讲。今天只是简单讲，想给大家一个感念上的认识：你以为的A'，你极力想消灭的东西，可能恰恰是最宝贵的生命力。

# 强大的自我，深入地拥抱

读研生时，我有过两年比较严重的抑郁症。那两年里我住在一个小厂子，常常被拒回，以至于我去北大读研时，两天，被警察拦下来查我的身份证。依照A与A'的概念，积极自总的正能量好的，而消极自总的负能量自然是不好的，需要去消灭。

如果将抑郁症形容为，你掉入了一个黑暗的中，外面有灿烂阳光，而里面的你，自然，你会看见，会紧紧抓住门板上的缝洞，并拼尽全力的向上爬，试图重新回到阳光中，但你的力量不够，所以黑暗中似乎有一种强大的吸引力，所以向上爬很困难。

我那两年，无意识地做了一件事：既然向上爬太费力，那我就先钻进去，就钻了去。于是，在与抑郁症的格斗中，不是干脆钻到了黑暗的池，待了两年时间。
