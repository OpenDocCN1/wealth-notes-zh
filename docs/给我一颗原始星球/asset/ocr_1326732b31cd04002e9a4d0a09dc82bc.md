# ### 1.1 原始阶段为真

第一： 此阶段从人类诞生开始直到我到来时，已历经上百万年

第二： 此阶段的人类一直都不危险，都是正常的

第三： 此阶段只有天道，天道尚左，道法自然，和谐共生

第四： 天道的存在是为了整个宇宙世界稳定有序

第五： 此阶段众生不苦，活着就是活着而已，不会说话不会思考，就是一坨肉，狗肉一样的肉，连苦这个字都没有，苦啥苦；但会像狗一样永远不会醒，因为不经历痛苦不会醒悟；永远也没有享受可言，因为没有科技发展

第六： 原始阶段一直是恒定的

# ### 1.2 混乱阶段为假

第一： 此时这个阶段已距今 7900 年左右

第二： 此阶段开始的标志是从发明文字开始说话学会思考

第三 众生皆苦开始。众生能不能不苦？不能，现在不能。这是设计好的苍生之局 众生皆为棋子，一个都跑不了。我整本书就在讲这个，力压天道、人道、天人合一之道的道，道上之道。

第四 自从发明了文字会说话会思考之后，人类就变成了很危险的生物，还不可逆，人类存在了几百万年都很和谐也不危险不恶心不那么贱，现在事情出来了，如果给你一个这样的星球，怎么办？只能一边维稳，一边向前看。即：为了社会稳定有序的同时，努力实现天下大同，这就是设计好的苍生之局总纲，人类世界的一切都是围绕这两点设计。
