# 3.1 你躲不了，因为无处可躲

人该经历的苦难，一个都少不了，就看什么时间经历，早经历是福报，晚经历只能卧槽。

+   第一：比如身体：年轻时经常生病，就会早早注重养生，早早学会自救，等老了还能跟老太太跳广场舞，那些老了天天轮椅天天帕金森的，年轻时生猛的很，还打拳击呢；
+   
+   第二：比如感情：年轻时没被渣男渣过，中年无情又无趣，突然被其他男人温暖一下，哎呀，被感动的是家也不顾、银行卡密码都敢给对方公布。余生在悔恨中度过，渣不死你；
+   
+   第三：比如事业：手里但凡有点钱一定会忍不住投资啊创业啊，年轻时没折腾这些，退休了闲的蛋疼就该接触乱七八糟的人了，套儿就在那、陷阱就在那，一辈子积蓄瞬间灰飞烟灭，爬不起来了，晚年凄凉。
+   
+   第四：小时候经常被打被骂活金刚活阎罗一个，踩着地球望着太空，要是六十岁还没经历被骂，骂你一句你想不通当场眼儿屁：耶？你卷我？六十年都没人卷我，你敢卷我？
