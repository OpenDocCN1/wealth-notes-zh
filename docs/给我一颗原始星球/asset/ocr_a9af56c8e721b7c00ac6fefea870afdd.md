# 2. 断相

断舍离。但凡是让你不舒服的地方，事情，人，那就是错的，对也是错的。想办法进行断、舍、离，不能让自已的能量继续减少。

比如夫妻相，如何断相？要断舍离掉让彼此能量消耗的任何动作

+   - 第一：比如因为说话多导致经常吵架，那就止语 少说话，少刷存在感，过日子就是陪伴，就是安安静静，就是平平淡淡

+   - 第二：如果对方发火，你别回应，或者离开现场

+   - 第三：从内心深处认为不能跟他一般见识。因为你知道夫妻是假相，你爱人没有醒悟他不知道，他这时就是一条被驯化的狗，你肯定比不会跟狗一般见识，跟狗吵架，跟狗解释断相就是给自己以前的大脑程序格式化的过程，能量不再被消耗

# 3. 正相

保持能给自身带来能量的正知正觉正念，把以前的杂念覆盖消磨掉，让自己大脑的下意识和肌肉的潜意识变成，经过刻意练习的正知正觉正念

比如夫妻相，如何正相？

+   - 第一：夫妻相是假的，要借假修真，不能把假的当真较真儿，只是体验婚姻带来的价值即可，价值是实在的，其他念头全是假的

+   - 第二：结婚的目的—定不是为了彼此消耗

+   - 第三：夫妻的存在是为了对方越来越好，是成就对方
