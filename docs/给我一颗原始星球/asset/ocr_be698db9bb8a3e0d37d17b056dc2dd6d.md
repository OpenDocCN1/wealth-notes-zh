# ### 1.1.3 灵魂与肉体

要意识到我是由灵魂和肉体两个部分组成。
肉体承载灵魂，灵魂驱动肉体。
肉体肯定越老越腐烂，需要灵魂越老越干净。
死的时候灵魂修的越来越高级才圆满，这样符合宇宙守恒规律

+   - 第一：肉体的你从外面看得见，向外求；灵魂的你从内心才看得见，向内求
+   - 第二：肉体是频率较低的波，具体频率和能量受人类世界的顶层设计所影响；灵魂是频率较高的波，跟宇宙跟自然一个频率
+   - 第三：肉体成长需要营养，灵魂成长也需要营养
+   - 第四：肉体需要把体内的屎尿屁排出去，灵魂也需要把精神的屎尿屁排出去

你是由灵魂和肉体两部分组成，灵魂才是真我，大脑为主的身体是假我，你的灵魂只是用你的身体几十年，大脑和身体就死了，你的灵魂不生不灭。你的灵魂从你出生那一刻就开始了地球之旅，从你大脑和身体死亡的那一刻，你的灵魂就开始了宇宙之旅。

比如用针扎你，你觉察到你的身体疼，但是你这个觉察不疼，那就是觉知就是你的幕后视角，这个觉察/觉知/幕后视角，这个注意力，就是你的灵魂

这个世界顶层设计的核心就是对你注意力的掠夺。
你的注意力在哪，结果就在哪，人生就在哪。
