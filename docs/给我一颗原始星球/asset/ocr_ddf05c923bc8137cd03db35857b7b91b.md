# 14.2 没什么也不能没自信

自信跟外在无关，即使一无所有，哪怕无脑自信也得自信，没什么也不能没自信

+   **第一：你的出生就是为了改变世界。**
+   
+   你从刚出生世界就多了一个不同的哭声，你改变了世界；你拉了泡屎，世界因你多了一泡屎，你改变了世界

+   **第二：自卑会放大自己的缺点，自信会弱化自己的的不足。**
+   
+   比如你胖比如你矮比如你脸上有胎记有疤痕等等，跟正常人相比，如果你能自信，不仅会弱化别人认为的不足，反而还会让你更有魅力。

+   **第三：自信才会不轻易否定自己，才会不在意别人的评价，才会不容易发生精神内耗。**
+   
+   因为真正的自信，在自己内心有一套让自己舒服且自动屏蔽外界的自我评价体系

+   第四：整个地球都在你脚下，地球上的事算个屁，有一个踩一个，有多少踩多少。

**我遇到的一切都是我筛选的结果：**

我找工作是我在面试面试官，我做你的员工是给你脸，我跟你结婚是你上辈子积德，我能活着是这个世界的缘分，我要死了是给阎王面子
