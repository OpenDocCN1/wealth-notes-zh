只有斗争才会让自己强大，只有斗争才会让敌人退却。

遇到这类事情，思路不要放在害怕、妥协、自证清白上，这些都是对方拿捏你的原因，你要是退缩了，有打不起还躲不起的思想时正合了小人心意，巴不得你赶紧离开呢！

但是凭什么是你离开呢？你被人冤枉不说最后还灰溜溜的走掉！

佛争一炷香，人争一口气，必须要把思路放在斗争上，干他！

具体怎么干？

+   第一：硬干，比如骂人，虽不道德但不犯法，朝死里骂，要具备泼妇的潜质，骂出整条街都是老娘的气势，一般人绝不敢再惹你

+   第二：阳谋：比如你要反过来袒护他，说你们俩的关系是最好的啊，还要装作很惊讶不相信是他说的。还要大声说出去，尽量让所有人都知道

+   第三：阴谋：你也故意冤枉他啊，在组织内制造点舆论还不简单，借别人的嘴办自己的事。借刀杀人、斗争传播学这俩组合拳百试不爽，传播的舆论要尽量炸裂，炸裂到足以干掉他

+   第四：提升自我修为，要对自己藏拙和自嘲，对小人敬而远之、删除拉黑。总之，避免更多的污蔑来袭才是长久之道
