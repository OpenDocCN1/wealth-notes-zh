# 8.2 伤害

斗争必然带来伤害，伤害是天道。在天道里斗争和和谐是混沌一体，可理解为既没有斗争也没有和谐，或者既有斗争也有和谐，它相对宇宙来讲，只是一份存在。

人生而伤害，生而掠夺，生而索取。你没出生前不会伤害任何事物，从你一出生，就从宇宙掠夺了一个灵魂，一走路就会踩死地上的微生物，一张嘴呼吸就会把空气中的微生物消灭，你考上大学必然意味着有人落榜，你升官了必然会导致其他人落败……

只是，__原始阶段的伤害是不起念的__。好比天下雨淹死了地上的人，不管好人还是坏人一起被淹死，但是天下雨的目的不是专门为了淹死谁谁；再好比树木长大导致大树底下寸草不生，但是树木长大的目的不是专门为了杀死身边的花花草草；再好比狼吃羊，狼只是为了生存，不是为了伤害羊，羊也没觉得这是伤害。

__可以伤害，不是不让伤害__

**第一、当有人伤害你时，对待熟人你必须斗争，对待陌生人尽量释放善意。**除非可能出现的伤害足够大；这时伤害对方是天道，是大道，是正道

**第二、当生存这个生命本质都出现问题时，你可以选择去吃鸡鸭牛羊，甚至吃人；**
你不是为了伤害别人，只是为了生存，没有起伤害别人的念。

__当生存都出现问题时，人为造出的道德是没有力量的，法律也没有力量。__

**第三、距离越近，越容易产生伤害！**天打雷，劈到的一定是正下方最近的区域；地震，掩埋的一定是正上方最近的区域；大树生长，寸草不生的一定是大树底下，与你最亲近的人才是你的主要伤害之源。

所以要对陌生人常怀有善意，对熟悉之人要抱有防备。

距离越远的陌生人一辈子就见一次，给他们一丝温暖的善意，人生将处处是惊喜，这个世界是反着的
