# ### 8.2.3 正相

借假修真别当真，正向的使用文字：使用正向的文字或者反为正用。

被编程了几十年的巨大惯性需要利用这些假的但正向的字给自己编程，直到形成正向的新的下意识为止。比如强者的语言都是正向的，根本没有负面语言没有弱者气息。

比如处理夫妻矛盾时，前32年我跟大家一样都会吵架辩解，当我说的话我的思考，也就是我的文字体系换成了：“我的存在是为了我媳妇越来越好，我们结婚的目的不是为了吵架”、“这辈子只有一件事：只管好自己”、“我媳妇没有觉醒开悟现在只是一只被驯化的狗我不可能跟狗一般见识”、“让我们夫妻有对立矛盾是个陷阱是个坑是设计好的局”等等这些话给自己编程了几个月，说久了次数多了就形成了我的新的下意识，再发生矛盾时这些话第一时间会出来，矛盾就不可能发生，马上画上句号；再比如当你遇到问题不要出现这样的文字：我不行、我理解了但就是做不到等等，因为你的下意识认可了这些话，你会证明自己不行实现自己不行

一切都可以为自己所用，不好的一切也都可以反为正用，一切皆有利于我，遇到任何问题永远都有方式方法，不要讨厌错误，对错你可以利用，不要讨厌自己的情绪，精神内耗可以灵活转化为好事，不要讨厌政策，要利用政策；不要讨厌文字，要利用文字，文字很好玩；不要讨厌人性，要利用人性，人性很好玩，跟狗一样。

再比如你觉得风好大，好烦人；但我可以风力发电，我觉得风越大越好。风对你是伤害，但我把它转化成了对我有用的能量。同样的，你觉得别人的伤害是痛苦，挥之不去；但我觉得伤害是从宇宙开始有人类开始一直存在，伤害是天道；而且痛苦确实使我强大使我进步；既然伤害无法避免，既然伤害能让我变强，那请就给我最大的伤害，化伤害为力量，化悲痛为力量，化苦难为力量。我的今天，得益于我曾经遇到的所有人所有事，尤其是垃圾的
