# 人性教育：

科技（能源科技+生命科技+AI 科技）+谋略手段+挣钱+历史+经济学+人际关系学等等。这些都是人性才能搞出的东西，手段和挣钱是生存底线，科技是未来发展、是天下大同的天时。

孩子的玩具包括看的视频和图书都是跟科技相关，以动画的形式他们感兴趣的方式，从小就培养兴趣；

手段可以不用但必须有，从小学鬼谷子、36技，千门八将等等；挣钱更得从小刻意练习，上学图啥，上学20年的标准答案思维和老好人思维会成为孩子日后的诅咒，必须改为连续练习20年挣钱的思维和习惯

主要指肉体层面，有健康方面、性教育、道德法律如何使用等。身体健康方面，比如学习背诵中医，上医治未病，学会起码自己少生病或生小病自己也能治；再比如培养运动爱好和习惯；
