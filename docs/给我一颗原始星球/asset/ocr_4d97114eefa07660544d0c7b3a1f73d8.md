# 8.11.2 债务驱动

顶层设计里的时间，过去可以作为大脑编程不断植入的信息，这是洗脑的主要素材来源，社会稳定有序。

未来可以用来提前透支，以此创造出了债务驱动管理模式，包括经济债务和情感债务，你的肉体世界是经济债务驱动，你的精神世界是情感债务驱动。

**你活着要么背一身经济债，要么背一身情感债，一定没有足够精力去影响社会稳定有序。**

其他的不要想，活着还债就行了

**经济债务驱动：**透支未来，提前消费，各种贷款，你要偿还的贷款是稳定的，你得每个月都得还固定数额，但是收入绝不会稳定，多数人的未来收入没有一点保障甚至会经历多次一段时间内收入为 0 的阶段，到那时你就崩盘崩溃。让所有人所有单位所有地方所有国家负债，既能促进经济发展还能操控人跟狗一样一直拉磨，目的：**社会稳定有序发展。**

**设计出的产品有：房贷车贷消费贷等**

**情感债务驱动：**让所有人背负原生家庭的亲情债、婚姻的爱情债、兄弟情师徒情等，既能促进经济发展还能操控人跟狗一样一直内耗，目的：**社会稳定有序发展。**

**设计出的产品有：父母、子女、爱情、兄弟等**

太阳永不落下，也永远落下，没有白天黑夜，也一直都是白天一直都是黑夜，你这里的白天是别人那里的黑夜；没有过去没有未来，也一直都是过去一直都在未来。时间只是工具，不做时间的工具，有用你就用，没用也千万别因为时间的概念而内耗，借假修真别当真别较真
