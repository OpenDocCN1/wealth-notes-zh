# 第四章.出奇+极端

做人极端不好，做事不极端不好；夹着肛门做人，露着胸毛做事。

守正出奇，基础是守正，做人和做事的基本功；出奇就是不按套路虎牌，不循规蹈矩，甚至是违法，因为很多伟大都是从“违法”干起来的。

反者道之动，弱者道之用。

出奇到极致就是极端，很多事情想不通搞不定时，用极端的思维最容易破局
