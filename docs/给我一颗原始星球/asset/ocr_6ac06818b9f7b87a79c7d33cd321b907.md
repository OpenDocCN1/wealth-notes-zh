# 所有宗教的核心特征

+   第一：造神
+   第二：宿命论
+   第三：下跪
+   第四：制造恐吓

对普罗大众妥妥的降维打击，因为人管人、人跟人相处总会有争吵有质疑，但是神跟人沟通呢？

**即使神说错了你都得说对，还得跪着说！**

这种来自未知且神秘的强大存在，就是**造神运动**，是为了社会稳定有序，然后后来很多统治阶级是为了自身利益而选择宗教。

而且每个地区的宗教都不相同，每个地区造的神也不同。

老子耶稣释迦牟尼这几个人他们本身不认为自己是神是佛，或者说他们认为每个人都是神都是佛，天道无相，神佛也无相。

他们基本没写书更没创立宗教，是后人为了解造世界创造。

现在地球上的国家里，除了中国，其他国家大部分是神权社会，中国在先秦之后就已经不再是神权封建社会，西方、中东等还处在春秋战国阶段，现在地球上唯一不推崇宗教治国的是中国，只是允许宗教这种文化形式存在而已。

创造出宗教的那刻起，就给违反思想的带来了巨大利益；创造出道德的那刻起，就给违反道德的带来了巨大利益；创造出规矩的那刻起，就给违反规矩的带来了巨大利益。

**宗教是人类迄今为止最大的思想牢笼。**

因为造神最容易引起盲目尊敬和盲目畏惧，盲目敬畏就会失去真正自我，全成了乌合之众，人类思想进步从何谈起？宗教正式命名的 2000 多年来，人类思想一直处于倒退中，没有思想之光的指引，人类找不到出路。万法归一万法皆空，更何况由法生出的教，万教皆空
