# 悟道级强者

相反，像地球上的毛泽东这种悟道级统治者，不会陷入此众生相
悟道级强者的典型特征之一是不敛财，金钱不再是目标
可以一辈子穿补丁的衣服，只拿微薄的工资，头顶白莲花，心中阳光执剑，与大众百姓为伍，为了正义，可以以血引雷霆，一辈子无我，杀身成仁，舍生取义，只为天下大同。

还有一种不是悟道级的白莲花：为底层发声的正义之士，俗称好人，数量也很少。

悟道者和正义之士都需要得到保护和尊重，他们跟绝大多数人类要斗争，跟邪恶斗争，跟不公斗争。

但是好人和悟道者都喜欢天道的孤独，都不怎么合群，也导致好人很难联合起来，喜欢各自为战，这也给了极致的利己主义-精英主义阶层团结壮大的机会，且污泥般的这些势力反而喜欢团结，当这股势力团结到可以一手遮天，普罗大众整体的生存遇到危机之时，好人和悟道者们才会被迫的团结起来跟精英主义阶层掰手腕，整个人类历史就是在他们这两个群体之间松松垮垮波浪式博弈中前进

但如果没有诱导出来的精英主义阶层，就没有毛泽东这种少数的悟道级统治者出现；
没有诱导出来的精英主义阶层百姓就不会那么苦，政治就不会打仗，资本就不会有资本主义消费主义陷阱、宗教文化就不会给众生洗脑；
没有众生相没有资本陷阱宗教陷阱人类就不苦，也就不会觉醒强大，不打仗科技就不会迅速发展，所以这种精英主义阶层似的“坏人”，站在人民的立场是坏人，但站在天下大同的立场，有这些“坏人”是为了没有坏人：打仗是为了不打仗，生病是为了不生病，挣钱是为了不挣钱，死人是为了不死人，内耗是为了不内耗，苦是为了不苦。。。。。。

统治阶级的本质也不过是一份职业一份工作，都是混口饭吃的形式；除了少数悟道级政治家、企业家、思想家，其他都是幕后那些百年家族千年家
