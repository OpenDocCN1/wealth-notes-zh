# 2.1.1 心不死，道不生

+   第一：不经历痛苦不可能觉醒开悟，不经历痛苦不可能变得强大
+   第二：人教人不一定学会，事教人一教就会
+   第三：痛的越狠，醒的越狠

# 2.1.2 与苦难共存：躲不掉的苦难

整个世界的顶层设计就是众生皆苦，你往哪逃？往哪躲？
该经历的众生相，你一个也跑不了，时间早晚而已

# 2.1.3 没有苦难也要制造苦难

+   第一：只要在承受范围之内，自己主动随意去经历，多经历
+   第二：你经历的苦难，都是你能承受得住，不然不会给你
+   第三：好好利用苦难，体验苦难，享受苦难，一切皆有利于我
+   第四：苦难是为了不苦难，没办法中的办法，置之死地而后生

# 2.2.4 与苦难斗争

苦难的存在既然这么合理、这么有必要，我们要逆来顺受吗？

正好相反，要跟苦难干！与天斗与地斗与人斗，其乐无穷；不管天灾还是人祸都得干他，不斗争如何提升自我磨练自我找到自我？

逆来顺受，苦难的意义便不再存在，即：苦难，就是用来被干的，不管是谁给你带来了苦难，干他！这是它的命！

学谋敢于斗争是第一步，第二步是善于斗争，就得学习斗争的谋略和手段。

术无正邪，人分善恶。如果懂谋略，不管阴谋阳谋，就像有了核武器谁敢跟你掀桌子死磕？

即使把对方逼急他顶多敢跟你小打小闹那也心里发慌，不敢激怒你。
