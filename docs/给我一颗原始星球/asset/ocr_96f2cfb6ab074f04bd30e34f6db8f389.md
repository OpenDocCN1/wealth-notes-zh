# 8.10 情绪相

情绪是假的。原始阶段天地万物都是平静的，花花草草猫猫狗狗婴幼儿强者，都是平静如水。

你会问：动物被惹毛了也会生气。呸！它只是大脑下意识的反抗，而不是带着情绪。不是带着火发火，更不会因为发火而发火；不会带着焦虑而焦虑，更不会因为焦虑而焦虑，有了主观判断就会因为接受不了抑郁而抑郁。<u>情绪是主观的，下意识是客观的，客观的表达情绪不是主观的情绪表达，身受心不受。</u>一只狗被欺负了，隔了三五年他不会一想起有狗欺负过它，他还生气，他没有思考，他不会耿耿于怀，<u>情绪是建立在文字之上的设计好的游戏</u>，为了社会稳定有序的游戏，有了情绪很容易被引导被控制，尤其是一条无成本的信息发布，就可以大面积数据采样大家的反馈，再根据反馈作出相应投入成本的计划实施。

娱乐、生意、社会管理、短视频创作、人情世故处理、国际新闻事件包括冲突等等都是情绪，与真假无关，是为了调动某一方情绪所为，为了满足一方情绪所为；因为大众已经被驯化的低级低频低维，喜欢幻觉，不喜欢真相。

<u>混乱阶段里，这是一个情绪的世界，一个个情绪的人，一件件情绪的事，一条条情绪的信息，都在用情绪表达，都被情绪困扰着，他们看不清这个世界</u>
