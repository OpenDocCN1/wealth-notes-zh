# 1.1.6.5 只在乎这三样儿

+   第一：我的情绪。但凡影响我情绪的人和事，断舍离
+   第二：我的资产。但凡刻意消耗我资产的人，断舍离
+   第三：我的健康。但凡伤害我身体健康的习惯，断舍离

# 1.1.6.6 不爱自己就爱别人要付出的代价

+   第一：不会爱自己就去爱别人，这不是真爱。

不爱自己怎么知道什么是爱，自己都没体验就去爱别人，这是瞎爱，没分寸的爱，虚假的爱，只会爱伤别人甚至爱死别人

+   第二：太阳越升起，越会落下；月亮越圆越会马上残缺；爱的太满，就会走向爱的对立面：伤害。

所以不能太爱别人，即使你真的很爱，这是在保护他们

+   第三：你越爱什么，越在意什么，上天越会伤害什么，甚至让你失去

+   第四：太爱别人就会无法放下。

当失去时，撕心裂肺的痛，无法呼吸的痛，你真的承受不住

+   第五：太爱别人，就会相对忽略自己。

爱是有限度有边界，不爱自己可是万病之源

+   第六：爱可以，别太爱；在意可以，别太在意；

最好无爱无意无念，像佛陀像老子一样，像苍天像大地像花草树木一样
