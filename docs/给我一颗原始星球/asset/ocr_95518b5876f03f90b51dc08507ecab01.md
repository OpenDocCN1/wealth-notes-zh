第二、有事的时候是 1。比如这个世界驯化了喜怒哀乐忧思悲，我只有平静；一天有五件事要做，我只专注一件，解决一件是一件；面临好几个选择，我只选一；创造的时间有过去当下未来我只有当下，有 1 点两点五点十二点我只有当下。

当下就是 1。遇到事就 1，不遇到事就 0。

0 和 1 就是世界的本质，但这个世界创造了 n：n 个情绪，n 个国家，n 个语言、n 个行业…让你无法 0 或 1

第一阶段：失去了自己，内核不稳定，自己乱七八糟，这是的自己是 n
第二阶段：找到了自己，定力十足，这时的自己是 1
第三阶段：没有自己或者自己无处不在，无我，这时的自己是 0，
0 是天道，1 是人道，天人合一

# 2.8 无住

任何事不往心里去，过耳不过心，慈悲不沾身，身受心不受。随时都是清零状态，随时都是当下状态没有过去和未来，参考花花草草猫猫狗狗、婴幼儿、强者、水

# 2.9 无言

这个阶段天地万物没有文字，没有语言，灵魂交流。

天不会说话，地不会说话，花草树木不会说话，猫猫狗狗不会说话，婴幼儿不会说话，即使现在的你一出生就扔到森林你也不会说话，强者智者惜语拈花一笑。因为一说出来就错，一说出来就有立场，一说出来就是偏见，再伟大的作家也只是书写自己的偏见，再有智慧的悟道大师表达的也只是高于人类的偏见，大道无言。
