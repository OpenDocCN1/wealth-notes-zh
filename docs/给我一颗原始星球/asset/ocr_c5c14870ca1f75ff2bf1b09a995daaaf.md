# **1.1.7.1 什么是向内求？**

第一：向内求，求出的是本自具足的真我；向外求，求出的都是欲望、讨好、在意别人等内耗的假我，向内求是答案，向外求是陷阱。

**自己就是答案，自己就是全世界：自己就是太阳，自己就是发动机，自己就是医生，自己就是财富，自己就是时代**
