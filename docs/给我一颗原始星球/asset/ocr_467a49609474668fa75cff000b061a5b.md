# 3.5 投员工所好

第一：只有做自己喜欢的事，才有最高战斗力，士气都不用激发，每个员工都有内驱力、创造力，他自己干的开心，这么简单的一个道理，鲜有公司考虑到，更别说执行。

既能让员工开心，还能降低公司管理成本，更能提高作业效率，如此一举多得的好事，地主思维就能做到

第二：拓展场地提供方时或者拓展拓展场地需求时，按照员工的爱好制作拓客地图。

爱好被满足，人脉圈层次提高，业绩还能完成，能力还能提高，是成长性的工作，这样的好事哪个员工不乐意？

比如你喜欢泡吧，那就把所有酒吧都发展成公司的异业联盟，每天上班除了来公司报个到和下班时来公司作总结，其他时间相当于就在酒吧上班，把公司以场地为主的免费资源给到酒吧，或者搞一些针对酒吧员工以及会员客户的专题福利活动，酒吧老板会把你当朋友，酒吧就是你的家。

比如你喜欢钓鱼，那就天天跟钓鱼协会、钓鱼的人群、钓鱼的地方在一起，用地主思维把城市所有爱好钓鱼的全部拓掉，给钓鱼协会举办专题钓鱼大赛、内部福利等活动，不就弄点水买点鱼，花不了多少钱

比如你喜欢美女，那就组织相亲大会，整合门当户对的企事业单位，把活动举办到项目现场合适的场地上。比如把国企的女员工介绍给公检法的男公务员，到时候公安局你都能随便进出，解决警察的单身问题你可是功臣。

比如你喜欢宠物，那就把城市所有猫舍狗舍整合，把喜欢养猫养狗的家庭整合，举办宠物交流会、选美大赛、宠物相亲会等
