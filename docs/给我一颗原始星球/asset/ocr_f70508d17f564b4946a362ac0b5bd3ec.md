# ### 2.3.2 存钱（守财之道）

打江山容易，守江山难；赚钱容易，守财难

但凡发了财，必然开始不装了，这种不装是人性被压抑 n 年后需要释放的你；这种不装，是无任何防御心态下的你；这种不装，是没有经历太多人性黑暗和人生磨难自以为是的你。此时的你，不听劝，一般都会乱投资、乱理财、乱消费、乱创业、乱借钱，甚至乱践踏道德和法律

+   - **第一：存款可以不多，但必须有。**

你得活着你家人得活着，且手有余粮心不慌，活着踏实些，更何况钱能解决 99%的问题，存款是解决问题的绝佳手段。不一定要大富大贵，最好能小富即安。

+   - **第二：谈钱不是俗，没钱你还活啥？**

没钱科技如何突破？没钱如何有实力提升人类福祉？悟道级强者除了出家修天道的，哪个不是善于利用钱善于挣钱的人？毛泽东不谈钱怎么打仗，怎么建立国家，怎么给百姓谋福祉？谈钱不寒碜，普通人挣钱为了混口饭，悟道级强者搞钱为了人民为了社会为了天下大同

+   - **第三：世界上除了你自己能给自己存钱，其他人或组织都在觊觎你的存款。**

你的存款是银行的负债，你的负债是银行的资产；你的负债是精英主义阶层的负担，你的负债是精英主义阶层的钱包；包括你的父母你的孩子，你的存款是他们的吸血包。所以你不存款、不保护好存款，命运里只剩下唾弃
