# 信命不算命

第一：除了专业研究玄学的人群和组织

建议普通人别跟怪力乱神类较真儿，你讨论不出个所以然。

如果极少数的人能看到，你无法证明给别人看

也就是你看不见也可以说看见

第二：可以信命，但不算命。

人类是活在语言文字下的生物，算命也是文字；

文字就会跟你发生纠缠，算的命好还挺开心；

一旦算出来的是不好的，你就会纠缠进心里去；

最终是自己证明了它实现了它；

也就是不管算的准不准

人性大都会被那种力量牵着自己与它奔赴。

**好比生活中你觉得谁有问题，就会努力证明他有问题。**

第三：如果命运早就是确定的了，你算它干嘛？

如果命运是不确定的，就更没必要算了。

无常是天道，生命是无常的，也是这个无常；

才让单调的生活有了点缀

请你学会接受无常、享受无常、变成无常
