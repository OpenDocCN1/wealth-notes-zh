# ### 8.10.1 追求快乐是陷阱

比如快乐这个情绪，很多地方包括很多几千万的大V都在宣传：活着就要快乐、快乐很重要······这些人都是工具，被利用的没开悟的狗。怎么能宣传这么恐怖的价值观？

快乐是资本需要，你为了追求快乐会消费；快乐是政治需要，因为快乐是假的基本追求不到，追求不到就会焦虑，追求到了马上会觉得无聊，陷入内耗，内耗了就没有精力他耗没有精力造反，社会稳定有序！

你一生真正快乐的时刻就那么几个瞬间，快乐占你人生的比例每天的比例完全忽略不计，怎么可能去追求这种极端行为！

这是陷阱、是坑、是设计好的局。

如果没有快乐难受等等这些字，人就跟天地万物一样没有情绪是平静的。你吃饭时平静吧，睡觉时平静吧，上厕所时安静吧，看我的文章时平静吧，你吃饭时快乐？撒尿时快乐？睡觉时快乐？no！

是平静，平静才是大概率事件，贯穿生命始终，快乐是假的，情绪都是假的，都是社会稳定有序的概念设计

# ### 8.10.2 恐惧情绪是陷阱

**天地万物里的花花草草猫猫狗狗谁有害怕这个情绪，都是无惧。**

狮子饿了才会追捕羊群，追捕的那一刻，羊跑，这是自然反应，没有恐惧的这个情绪；狮子吃饱了不追捕羊群时，羊就在狮子附近吃草，根本不存在恐惧。

无所畏惧的人好管理吗？

自此任何地方都在制造恐惧：家庭教育里一定有吓唬孩子的地方，学校教育里一定有吓唬孩子的地方，公司管理里一定有吓唬员工的地方，各种生意买卖一定会制造恐怖来下化消费者的情况，宗教文化一定存在吓唬修行者的地方，社会治理存在道德和法律，这就是要让你怕。

**你怕了，作为孩子作为学生作为员工作为子民作为消费者，才好对付，才好管理，才能达到目的，社会稳定有序。**
