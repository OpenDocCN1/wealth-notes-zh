# 8.2 文字相

# 8.2.1 破相

文字是假的，原始阶段哪有文字？文字是为了社会稳定有序认为创造出来的最核心工具。能写出来的的都是文字，包括文字和数字。

人类的精神世界被文字语法编程，物质世界被数字算法算死。

整个世界是建立在文字之上，一切都是文字：你说的话是文字，你的思考是文字，你的情绪是文字，你的行为指令是文字，读的书是文字，看的媒体是文字、道德、法律是文字，导致内耗的胡思乱想是文字。

造字是人类史上最大的工程，这可是人类世界的编程代码，每个人都像一台电脑一样被文字编程。

人类造出的东西你都得付出代价：造出了国家你是不是得交税，造出了药你是不是得花钱，造了字你想白嫖？

文字可以编程你，左右你的情绪你的思想你的价值观，来达到政治、经济、文化的目的，文字是你的工具，你不是文字的工具。

造字很复杂，要不你造一个试试？为什么造、怎么造、造出来怎么宣传、怎么让所有人认可使用，比造原子弹难百亿倍哪可能白造？你要付出的代价就是被洗脑被驯化被降维被降频，甚至被几个字就能困在原地一辈子，活了一辈子当了那几个字一辈子的狗。

花草树木会被几个字困住吗？猫猫狗狗会被文字困住吗？婴幼儿会被文字困住吗？强者会被文字困住吗？你被文字玩啦，文化不就是用文字教化，自从发明了文字，整个人类开始进入文字游戏：文字就是这个世界的编程代码，你看到的一切都是文字游戏，宗教、经济、法律、感情等一切都是。文字会变成语言，语言会变成思想，思想会变成行为，行为会变成结果，结果会变成你的人生，文字语言思想行为结果这五个一回事，知行合一，要的是合一，文字就是你的人生！

人就是被文字编程过的一个个系统，你一开机就显示什么，遇到啥事会自动生成文字如何处理，文字控制着决定着你这个系统的一生；你的大脑就是电脑的硬盘，是死的，纠缠进去什么文字就会显示什么。
