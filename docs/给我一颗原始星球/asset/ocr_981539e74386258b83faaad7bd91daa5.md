# 1.1.6.16 爱自己的心态

尘埃般的地球，螻蚁般的你，爱自己都爱不好？自信都自信不好？抑郁都抑郁不好？生气也生不好？活着不就这点破事。

别怂不拉叽，别吊儿郎当，爱自己就好好爱，自信就好好自信，抑郁就好好抑郁，生气就好好生气

祝你：爱自己爱的死去活来，祝你自信不打烊，祝你抑郁顺利，祝你生气愉快

# 1.1.6.17 这辈子最重要的事是让自己幸福

+   第一：想让自己幸福从做自己开始，想做自己从爱自己开始，想爱自己从只管好自己开始，这辈子能管好自己已经很厉害了
+   
+   第二：只要让自己不舒服，果断屏蔽或远离。
+   
+   哪天心情不好了就十倍奉还的怼他干他，与人相处有且只有这一个标准
+   
+   第三：不讨好任何人，物质不缺精神也不能要饭，不做灵魂乞丐
+   
+   第四：只活在当下，只享受当下，只体验当下，根本没有过去没有未来，整个生命只是当下这一刻的叠加
+   
+   第五：接纳有人性弱点的自己，接纳神神叨叨的自己，接纳有合理兽性的自己，接纳有屎尿屁的自己
