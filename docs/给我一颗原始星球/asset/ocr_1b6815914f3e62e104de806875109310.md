# ## 改变命运

念起即察，念是能量，控制起心动念或无念，任何人包括宇宙觉察不到，就可以改变命运

第一：修行到一定程度的人，命运算不出来，他们如如不动，命运怎么着那是命运的事，关我屁事。

运是面对剧本时的心态，能控制心态的人，运变；

命是剧本，一般人改不了，但是不起念，宇宙就不会觉察到能量波动，它怎么拿捏你？命变。

第二：别说命运，在日常生活中你的想法被他人捕捉到，你就会很容易被牵着鼻子走。

被人牵着鼻子走、被欲望牵着鼻子走、被文字信息牵着鼻子走。你那点心思别人都能猜到，你的命运都是确定的

第三：你再有钱有权，首富牛逼吧，能找到最厉害的大师，能帮你算的很准，能帮你挡一些业力，但这种治标不治本的向外求，只是延迟了命运的交付时间而已，他们的命运还是那样，该出事还是出事，该进去还是进去

第四：控制起心动念或无念就是向内求。

只有向内求才能真正改变自己的能量，无念就是无住，应无所住而生其心。大脑里住的都是人造的人类思维，生出的是一颗带众生相的凡心。

但你的真我、你的心你的灵魂在人类思维之上，没有住人类思维，生出的是清净心、平等心、平常心，是无，是空
