# 轻资产思维

创业根本不需要花钱，或者花小钱办大事，空手套白狼这句话倒是家喻户晓，现实却是背道而驰，基本都是砸钱创业。

你要知道普通人挣钱攒钱是真不容易，创业一把就梭哈没了，这种逻辑肯定不对

零成本或轻资产的核心：**倒卖+互联网。**

举例如下：

+   第一：小镇舍长爱人娘家的兄妹三人都做宠物生意，全部都是倒卖+手机互联网，客户打定金和尾款时再把定金尾款打给上游养户，不花钱，一部手机即可

+   第二：一高中粉丝，喜欢写爽文，每个月赚 8000 元左右，每天幻想的各种画面连载到学生微信群、QQ 群、公众号文章、小说平台、语音平台、短视频平台，不花钱，一部手机即可

+   第三：在农村倒卖成熟季节价格洼地的中药材、蔬菜、药膳等产品，低成本、高收益。不能向老农民那样只知道低头种地，学会抬头看天看市场很重要
