+   - 第二：倒卖是最赚钱的生意。国家倒卖地皮，银行倒卖钱，马云做了个线上倒卖平台，王健林开商场是线下的倒卖平台，小镇舍长做知识博主倒卖是大脑里的知识。
+   
+     倒卖的量没有上限，但自己生产、养殖、种植等都有规模限制

+   - 第三：倒卖回款周期最短。
+   
+     倒卖出去多少货，挣多少对应提成

+   - 第四：倒卖成本最低，甚至零成本。
+   
+     只需搞定客户端流量，前期不需要投入生产、租赁、装修、员工等各项成本，后期有了资本想玩产业链时再投入不迟

+   - 第五：倒卖的产品可以是实体产品，比如衣食住行吃喝拉撒等等，也可以是虚拟产品，比如资料、课程、会员等。
+   
+     比如倒卖蔬菜、中药材，都有淡旺季，收获季节最便宜的单品，采购回来，放入冷库，在旺季价格走高时卖出，冷库前期租赁，后期自建；再比如倒卖宠物猫，只要能掌握短视频至少几千粉丝的流量或者线下宠物店资源，每年的利润也很惊人；再比如近些年精神内耗的人较多，倒卖身心灵疗愈的资料和课程，入口有电商平台、优盘、短视频等
