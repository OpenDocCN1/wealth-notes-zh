# 10.定期清理

为了社会稳定有序，需要管理的核心群体是精英主义阶层。社会的动荡主要是因为精英主义阶层导致，在天下大同到来之前，这个阶层不会消失，任何手段也不可能消灭精英主义阶层，因为这个阶层的根源没有消失：比如人为造出来的欲望、等级、金钱没有消失，信息化时代没有到来等等。

有三种人最不好管：认知高、有钱、有权。

认知越高、钱越多、权力越大的人，越不好管；而且认知越高的人认知会越来越高，权力越大的人权力会越来越大，有钱的人钱会越来越多。

**钱会流向不缺钱的人，权力会流向不缺权的人，智慧会流向不缺智的人。**

这三种人还会合作、联姻，根系交织，让权力、金钱、智慧通过最原始的方式传播：血液传播、性传播、母婴传播。

这些群体如果不被定期清理，只会越来越强越来越多，容易失控引起社会动荡，甚至积累到一定程度就会颠覆原有统治，所以必须定期清理！
