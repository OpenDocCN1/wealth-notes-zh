只有人类会自卑，除了花草树木猫猫狗狗婴幼儿悟道级强者，都不会自卑，被驯化成的人类是最低等的生物；

你不是人类，你在人类至上，总有些人是人类教不了的
那人为什么不能是你！

# 14.1 自卑是对自己最大的背叛

自卑是对自己最大的背叛，只有自卑，才会看不上自己，慢慢也就失去真正的自己，这不就是苍生之局设计的初衷？

自卑就是世界的顶层设计，不自信就会他信，他信就是个坑是个陷阱，都自信了谁还愿意被驯化成狗？

# 一旦自卑，造成的心理阴影，需要花光一辈子的力气去克服

# 第一：自卑是拿自己缺点跟别人优点相比

比习惯了，就忘了自己还有优点。自己干自己，成了缺点的狗

# 第二：越自卑越敏感，越敏感越容易激发自我保护机制

越也就容易失控变得有戾气，成了脾气的狗

# 第三：越自卑越攀比

见到比你有钱的、比你地位高的、比你学习好的等等攀比成性，忘了初心，成了欲望的狗

# 第四：越自卑越在意别人的眼光评价。

生怕做件事，开始变的唯唯诺诺磨磨叽叽，执行力低下，而只有执行力才能让你拿到结果，失去了执行力就失去了人生主动权。成了失败的狗

# 第五：越自卑越容易掩饰

为了掩饰自己的不足而说的多做的多，那肯定错的越多，越容易招致失败，反而更加凸显本想掩饰的自卑，成了虚伪的狗

# 第六：越自卑越容易迷失自我

迷信权威迷信比你强的人，成为乌合之众，成为待宰羔羊，成了别人的狗
