# 修行三步走

第一：先见众生，得先入世，红尘中才是大修，不经历就没有发言权，尤其是不经历痛苦不可能醒悟，此阶段用儒家法家；

第二：再见天地，就是格物致知，宇宙自然的天地万物本是同根生，天地与我共生万物与我唯一，此阶段用道家；

第三：最后见自己，经历了人世间的痛苦，开始远离人世间，大自然治愈了自己，此时终于明心见性，找到了自己，此阶段用佛家。

儒家法家道家佛家同根同源（后来的犬儒主义不算真正的儒家是阉割版）

只有入世见到众生相才会被刺痛痛到醒，只有入世才能获得物质基础和生存手段，物质基础才能决定上层建筑；

见到了众生不再想见众生，开始喜欢接触灵性的天地万物，开始格物致知；最后格清楚了格明白了，发现天地与我共生万物与我唯一，见了本性见了真我，也就是见到了自己。
