# 2.4.7.3 流量

流量的核心是情绪

**第一：一切动作都是围绕情绪展开。**

因为短视频平台就是奶头乐，是以娱乐性为地基的平台，娱乐的本质是提供情绪，没有情绪谁还看？

绝大部分都是闲着没事了才打开短视频打发时间消遣。学习型的平台那么多没有一个有客户粘性，来短视频平台可以学到东西挺好，但绝不是为了学习才来短视频平台。

**第二：流量主要指的就是乌合之众的情绪，是普罗大众的情绪，是被编程被驯化成的狗的情绪。**

真正有智慧的人，尤其是悟道之人很少，形成不了流量，他们自身有足够的智慧，也没什么情绪，更不需要成为谁的粉丝，很难被人类玩的情绪游戏所诱导

**第三：所以如果小镇舍长哪天成了大 v，请一定远离。**

由高必然和寡，不被封杀就不错了，还会让你成为大 v？真相不可能被多数人认可，真相也不允许被多数人认可；好比钱多了还是自己的钱吗？粉丝多了还是自己的粉丝吗？声音越大越只是情绪，越远离真相；小镇舍长是来玩的，他火不了更不想火，粉丝多了就不好玩了
