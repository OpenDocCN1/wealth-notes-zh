# 第二章.性之三修

根据人的特性，可以分为灵性、人性、兽性，其中人性包括先天原始人性和后天驯化人性。

要修就修全乎，别偏科，别缺胳膊少腿

第一：打压了灵性，那就正向做加法修回来；

第二：驯化出了新人性，那就正向做减法修掉。

最务实的其实是人性的修行，可以获得生存谋略手段，获得物质基础，物质基础才能决定上层建筑；

第三：打压了兽性，那就正向做加法修回来。

总之，灵性修过了头、人性修过了头、兽性修过了头都不对，都应该经过正向修行正向引导，修行的目的：找回真正的自己
