# 5.2 相互关系

宇宙内所有东西的本质就是能量、振动、频率、波。看不见的声音、光、电、信号、文字语言等等，看得见的山河湖海、日月星辰、花草树木、科技发展、你我他等等，本质都是能量、振动、频率、波。

能量是万物的本体，振动才能产生能量，有频率才能振动，只有波才能产生频率，即能量、振动、频率、波是一回事。

频率低，会变成看得见的，就是实体，包括手机车子房子还有你我他。

现代物理学研究所有实体包括人体的分子结构，研究到现在发现最小粒子已不再是实体，是玄上的振动，是波。

好比乐器不再是乐器，而是音乐的律动；手机不再是手机，是无线电信号；你不再是你，你是无，无你。

只是频率低，变成了肉眼看得到的而已。“其大无外，其小无内；凡所有相皆是虚妄；色不异空，空不异色；缘起性空；无我，道生一一生二二生三三生万物，道就是无，无生了有，就是太极，太极生两仪，两仪生四象，四象生八卦”···

频率高的，会变成看不见的，包括手机信号、电、还有人的灵魂。

频率越高振动越快能量越大，比如老子佛陀他们仙逝已2000多年，但他们的精神能量从未消失，是地球上现存最强大的精神能量之一。

频率高的会带动和影响频率低的，好比你接触负能量的你就成了情绪垃圾桶自然能量减少，接触强者你的能量就会提升；

接触花草树木猫猫狗狗这些有灵性的也会提高能量。

好比频率高的声音会盖过频率低的，频率高的水波会带动频率低的水波。

我们的精神就是松果体发出的的一种波。

频率低时能量就低，低到一定程度就会焦虑抑郁等内耗，抑郁自杀的人就是精神能量没了，同理，人的身体能量没了也会死亡。
