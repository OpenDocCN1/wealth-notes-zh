# ### 1.1.6.14 只要对自己不好：别人一定会对你不好

**第一：破窗效应。**

你往一个地方扔垃圾，别人会认为那就是垃圾场他也会扔。越是自虐，自己越是垃圾场，别人除了往里扔垃圾还会拉屎，人性下坠的力量让人上瘾

**第二：人类不仅慕强还凌弱。**

你对自己不好就是自己看不起自己，内心认为自己是弱，你就会连自己都欺负，更何况别人

# ### 1.1.6.15 你的世界充满爱

**第二：苍天是爱你的：**任何东西都可以离开你，唯独天不可能离开你，整个宇宙都在拥抱你：

**第三：阳光是爱你的，空气是爱你的，水是爱你的，你身体的无数个器官和几十亿个细胞是爱你的，无怨无悔的爱你，义无反顾的爱你，你在爱就在**
