# 1.4 五个时代理论

人类的三个阶段会经历五个时代：\n原始文明时代-农业文明时代-工业文明时代-信息文明时代-精神文明时代（现在的地球处于工业文明时代末期、信息文明时代初期）。

除了原始文明时代和精神文明时代是恒定长久的，农业文明到工业文明再到信息文明的时间会越来越短，越来越提速，也就是原始文明和精神文明时期最长，其次是农业文明，再次是工业文明，最后是信息文明。本质是科技的加速，导致递弱代偿的出现

# 第一：原始文明时代就是原始阶段，存在了几百万年。

这个阶段严格意义没有文明的概念，但实则是文明的一种形式。

毕竟原始阶段在天道的运行下：众生不苦不内耗、人类不是邪恶的物种、星球不会出现人道主义灾难；只是此阶段人类没有享受，也没有应对未来未知风险的有效方法：饥饿、健康、战争等

# 第二：农业文明时代贯穿于混乱阶段的前半程

众生皆苦此时已经有了应对生存的有效手段，因与大自然与天地与万物沟通，所以会出天道智慧，但还没有应对更深层次风险的方法。

地球上农业文明的代表是华夏文明。

个人的发展只要围绕农业文明就会相对有保障

# 第三：工业文明时代应该会存在几百年

众生更苦，更加物质化，尤其是工业文明时代的后期，将是人类最痛苦的时期。
