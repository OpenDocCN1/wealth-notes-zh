# 16.讨好 破！

我自己已经活的很不爽，为什么还要假惺惺笑脸迎合别人？
让别人爽让自己更不爽？还要美其名曰：礼貌、素质、情商，要是这样
作贱自己是美德，作贱越狠越美，干脆把自己弄死，这样情商最高

+   第一：讨好型人格属于我对别人好，别人应该对我好，但是如果没有像他对别人一样好，他会很失望；

+   第二：讨好型人格的内心软弱，自己看不起自己，被人欺负是常态，被欺负了不敢反抗更是常态，最后只能自己闷着内耗

+   第三：讨好别人等于乞讨，你一个要饭的，有啥尊严，最容易伤害你的就是你经常讨好的人，在别人的眼里只会觉得你是条向他摇尾乞怜的狗

+   第四：人与人之间绝对平等，都得死，而且都是相互成就，没有谁比谁低一等，比如大家看小镇舍长的内容，说明能被你用是你给我脸，是你在证明我有用，我们是绝对平等

+   第五：讨好是人为设计的情绪陷阱，人类文明糟粕。

**天地、花草树木、猫猫狗狗、婴幼儿、悟道级强者都不会讨好别人**

+   第六：只有平等相处、只有只做自己、提升自我价值，是唯一能得到尊重的方式。

没有实力没有价值，对别人的好，别人都以为是讨好，哪怕你是真心，也会被人呸
