第二：纠偏，修行很容易修进误区，跟打游戏通关一样，各个环节都有陷阱和误区。**最好的老师就是干。**

# 2. 修行的乱状

修行本是一种体验生命的宇宙客观事实，像其他天道一样顺其自然运行即可，但现在修行不仅变得紧迫还很痛苦，一点也不道法自然，一点也不可爱

# 2.1 只有灵修

人性有灵性、人性和兽性，只有灵性修行这不是偏科嘛？人修呢？兽修呢？只谈灵修要么是不懂，要么是骗钱。只是灵修，很容易走向虚无，很容易愤世嫉俗，很容易躺平。天天吃饱撑的虚头巴脑，生存呢？健康呢？最基本的都舍弃还叫修行？

**最接近真修行的是道家道教：有灵魂修行，其至修仙；也有兽修，道医救死扶伤更能自救，道家养生功法在养生领域也是无敌的存在，且道士自己种药采药制药。**

更有人修，各种手段谋略都是人类顶级，最初级的也学会了一些风水、八字等等的术可以谋生，绝不会靠别人施舍生存。

没有人修获得的物质基础，一切都是空谈，没有人修入红尘见众生，修行是无根之木。

除了这个教派不仅务虚也更务实之外，其他教派的修行都是以灵修这种务虚为主

每个人都拥有身体和灵魂，都拥有物质世界和精神世界，都拥有大脑和直觉；也就是修行是要让自己的身体稳定有序，让自己的灵魂稳定有序；修行要让自己的物质世界稳定有序，让自己的精神世界稳定有序；修行要让自己的大脑稳定有序，让自己的直觉稳定有序；不偏不倚，不左不右，守中
