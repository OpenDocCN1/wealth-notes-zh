# 以夫妻相为例，如何破？

+   第一：见天地，格物致知。花草树木、猫猫狗狗、婴幼儿、悟道级强者、自己回到原始阶段、现在自己出生时扔到狼窝里让把自己养大，有夫妻吗？不存在
+   
+   第二：站在人类历史整个尺度上看。6000年来夫妻的形式一直在变化，原始阶段任何一对异性都可以做夫妻，做夫妻一次、一天、一个月；5000年前母系社会女人有十几个几十个老公；上下五千年里皇帝可以三千个媳妇另外三百个媳妇普通百姓有钱的可以三妻四妾，民国时期讲究亲上加亲都是表哥表妹结婚，到了父母那代一夫一妻不离婚；到了现在开始有了自由恋爱，不离婚变得不正常···
+   
+   第三：婚姻就是假的，是为了社会稳定有序，是社会保障体系的环节设计，不是为了你的幸福设计。有了夫妻相，你会消费；你会不懂保持距离而内耗就没有足够精力去他耗就是造成去影响社会稳定有序；你会有软肋；你会在最冲动的年纪被爱情被家庭转移掉大部分注意力；你不再是一个人是以家庭为单位减少社会管理成本，你会有上一辈下一辈的君君臣臣父父子子的秩序概念等等···

+   第四：如果夫妻关系让你长期处于能量消耗状态，你就得醒了，这事肯定不对。如果还把夫妻当成真的，就是继续执着这件事，越执着彼此间的能量消耗就越多，认识到是陷阱了，你还跳吗？还接着内耗吗？如果是，那就活该，神经病。
