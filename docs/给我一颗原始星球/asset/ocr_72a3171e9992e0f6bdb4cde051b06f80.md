# ### 1.4 地主思维解决的社会问题

本思维主要解决的社会问题是：场地资源过剩造成的严重浪费，也是社会浪费成本最多的地方；其自身的营销问题越来越棘手，客户越来越少；

地主思维则是通过把闲置的场地或者处于闲置期间的场地统一运营起来，免费共享出去，以解决各自的营销痛点，实现海量的客户到访；

即：闲置浪费的被利用起来，同时低成本解决了棘手问题。

与其在外面找客户，超过正常管理成本的管理外面业务团队，不如利用自家场地，让业务团队只专注一件事：把外面的客户海量的圈到项目现场

地主思维使用起来，门槛低，效果快，可复制
