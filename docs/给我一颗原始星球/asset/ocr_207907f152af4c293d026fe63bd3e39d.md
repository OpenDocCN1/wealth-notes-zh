# # 第三部分 地主思维（精简版）

营销大于公司的一切行为，没有之一，这是生意的绝对本质。营销是为了让尽可能多的人知道自己的生意，知道后尽可能多的实现线下来访，来访了之后再做最终的销售转化。如果项目现场的客户来访量是平时的 100 倍甚至 1000 倍以上，整个城市所有组织和单位挨个组团来到你的卖场，你还担心生意不好？

《地主商业思维》 适用人群：供职业经理人和创业者参考

提示：本思维首次公开发布，以往是作为企业内训课，很多行业都可以尝试用地主思维重新做一遍

# ## 1. 思维简介

# ### 1.1 名字释义

地主思维，顾名思义，你有很多的地才是地主，这里的地指场地，以场地运作为核心的商业思维

# ### 1.2 思维起源

本思维萌芽于 2014 年，正式形成于 2016 年，期间经过 3 年市场验证，先后在 17 座城市，34 个落地项目实操，合作商家近 2 万家，举办流量活动 8 万余场，形成了近 600 万的线下流量。后来又经过 3 年的升级实践，地主思维从 1.0 版本升级到了 2.0 版本，再到最后的 3.0 版本，于 2020 年小镇舍长选择归隐，地主思维暂时画上了句号

# ### 1.3 地主思维常见服务行业

本思维最初只赋能房地产行业，做集团营销管理体系搭建或老大难项目攻关
