# 3.3 大客户思维

第一：光有流量思维还不够，客户质量得上去，如果有些卖场天天来的都是农民工兄弟，来的客户质量不高、购买力不强，跟生意不匹配，到访就会成为压力；不仅不会促进销售，可能还会影响销售，所以大客户思维就是在流量思维的基础上，提升客户质量

第二：要把能接触到的每个人当成渠道，每个人背后都有所在的组织或企业，那他就是你的大客户，通过他撕开这条渠道的口子，把客户大批量搞到现场，搞到现场的每个人都是一个哥渠道，然后再撕开无数个渠道的口子。

第三：发传单、户外广告、拍摄视频等目前是最常见的营销宣传媒介手段，但客户触达率一般很低。

比如发传单平均一个人一天300张，真正会咨询的不超过10个，留下联系方式的不超过5个，形成到访的概率不超过1个；

发传单不是目的，到访才是目的。

那为什么不直接调整所有的营销动作就是围绕到访？

只是发传单，你要做不到定人定岗定位的监督，单页直接给你卖废品站或者扔垃圾桶了都，毫无意义

第四：哪些群体消费能力强呢？企事业单位，尤其是待遇不错的单位，或者中高端小区的业主群体的组织。

比如金融单位、政府机构、教育系统、国企单位、科技公司、中高端小区的物业、广场舞大妈等

第五：针对消费级别高、人数多的组织或单位，可以定向团购，并拟定团购协议，是大客户专属福利
