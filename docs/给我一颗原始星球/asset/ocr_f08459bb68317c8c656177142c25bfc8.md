干的次数多了剪辑技巧就会了，干的多了文案能力就起来了，干的多了从哪找到学习最佳途径就出来了，干的多了就知道平台的规则和粉丝的规律了

第四：你可以把流量不高的后期隐藏或删掉重发，有了粉丝重新发之前的观点照样会火

# ## 复制

少走弯路最好的方式是复制，比如大家公认的大师其实都是复制者，讲哲学的除了小镇舍长等少数博主其他都是复制古今中外的大师的观点，大师复读机，思想搬运者

复制的方式：

+   第一：只找流量高的作品。他能火，你只要展现方式得当一定也能火

+   第二：完全复制死路一条。要跟原有博主的表现不同，比如原博主是口播，你就做剧情演绎、思维导图、剪辑等新形式展现

+   第三：整合一个主题里流量高的不同作品的观点，多个视频揉合成一个视频

+   第四：进这些博主的群，加他的微信看他的朋友圈，或者跟他连线链接套取他的整套模式
