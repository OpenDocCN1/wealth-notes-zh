# ### 8.9.3 孩子

生孩子不是你需要，是社会需要，如果都不生孩子，最着急的是统治阶级。

20年前的计划生育，现在的鼓励生育，需要你生时就宣传生孩子的好处，不需要你生时就宣传少生优生的好处。

天地万物都没有传宗接代的传统，人类在原始阶段存在了上百万年的传统没有传宗接代，到了发情期正常配种而已，没有谁是为了传宗接代而发情。

不生孩子养老该咋办？自己办！

而且不死就不能把自己的钱给孩子，给了孩子他们就是你爹了。

都说养儿防老，自己当了这么多年儿子，儿子能不能养老自己不清楚？

养老是社会的事情，但是社会的宣传把这项成本转移给了大众百姓。花花草草需要孩子养老吗？猫猫狗狗需要孩子养老吗？强者需要孩子养老吗？好好看看那些权贵阶层不仅不需要孩子养老，他们还反过来补贴孩子。
