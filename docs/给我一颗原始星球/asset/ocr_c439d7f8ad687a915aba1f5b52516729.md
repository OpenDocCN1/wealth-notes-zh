# 沉淀三步走

# 第一步：记录

刻意练习出记录的习惯，不管你做任何事情，都可以把心得体会以及过程进行记录和总结，这是独一无二属于自己的资源

**记录的方式：文字、语音、视频**

能锻炼出总结的能力和文案的能力：说话办事能一针见血总结出重点，文案将是信息文明时代极其重要的财富资源

# 第二步：输出

总结出来的内容得想办法传播出去，温故而知新，费曼学习法

输出的方式：讲给别人听，发表到群里、开会期间阐述、短视频或文章发表

别管对错好坏，只有往外输出展示自己，才有更多露脸头角的机会，是检验自身理论的第一步

# 第三步：实践

实践出真知，理论是行动的翅膀，实践是检验理论的唯一标准，实践是完善理论的唯一方式，实践是唯一可以取得结果的方式

通过这三步，最开始输出的只是碎片化的知识点，时间一长回头一看，那些被记录的痕迹，发现了规律，点开始连成线，再连成面，最后形成体系。掌握了沉淀的力量，傻子都有机会翻身：当年的犀利哥，要饭的，被记录下来，输出了出去；现在好多傻子或者守村人被记录了下来输出了出去都能火起来；种地的农民把种地的知识和过程记录下来并输出出去，就可能会火；养个小动物记录下来过程和心得体会并输出出去，就可能会火；幼儿园老师把教育小孩的心得体会和过程记录下来并输出出去，就可能会火···
