# 8.3 保持距离

宇宙既对立又和谐，混沌一体，宇宙不会起念刻意制造二元对立，既有伤害也有爱。保持和谐、保持不被伤害的天道是：保持距离！

一切人际关系必须保持距离，这是天道

因为不保持距离是伤害，甚至是毁灭。

地球跟太阳不保持距离，地球都没了；花草跟大树不保持距离，花草都没了；城门不失火，就不会殃及池鱼。。。

原始阶段没有亲密关系，只是食色性也，在人为的混乱阶段就据此创造了亲密关系：家庭关系父母、婚姻、子嗣，朋友关系等等，亲密关系的意思就是不保持距离，所以家家都有一本难念的经。

比如婚姻，以前讲相敬如宾，互相尊敬，懂得保持距离，婚姻制度一直相安无事的存在；但今天的婚姻必然走向没落，甚至条件允许时可能会退出历史舞台，因为历史以来从来没有像今天如此宣传爱情：2006 年才有了法定节日七夕节这个爱情节日，现在倡导自由恋爱也就几十年的光景而已，满天都是爱情电视剧电影和书本故事，爱情里全是‘你要理解我、支持我、爱护我、关心我、呵护我’等等，意思不就是把距离越拉越近，导致婚姻制度面临崩溃，大面积的离婚现象必然出现！这是道，其他解析全是术

# 9.丛林法则

“人善被人欺，马善被人骑”、“软柿子就是用来被捏的”、“狼吃羊、猫吃老鼠”、“弱小的狼会被族群遗弃”。。。。

到处都是弱肉强食，弱者的命就是被强者宰割，这是天道。

当物种没有天敌，敌人将是同类，人吃人！这是天道，宇宙铁律！

只要宇宙还存在弱肉强食这个丛林法则，就不会存在公平；亦或者说：不公平就是公平，能保持部分公平，就已经要了人类统治阶级的亲命，几千年来一直如此。

公平是到了人为的混乱阶段人为创造出来的，是假的。
