+   - **第三：** 多活动少运动，尤其是 30 岁以后，剧烈运动更不适合。运动一般都不是养生，都是损耗身体，比如健身，肌肉的每次酸痛都是身体损伤，再比如运动员全身是病，那些都不是健康合理的运动方式，包括马拉松，是为了纪念跑死了的人创造的运动，这是冲着死去的运动。
+   
+      多活动，比如太极、易筋经、八段锦、站桩、呼吸吐纳、还阳卧、金刚跪长跪、拍八虚、握固、提肛、太乙回春功、全身拍打等动作每天做 3-5 次

# ### 3.3 自学中医

+   - **第一：** 中医是身体使用说明书，应该从小学就得教授中医基础理论，人人都得学习。
+   
+      中医更是无上智慧：上医治国，中医治人，下医治病。中医讲究天人合一，治病也治心。
+   
+      道医、蒙医、苗医、佛医等都是中医，中医讲究的是山医命相卜

+   - **第二：** 如果得了慢性疾病或者疑难杂症，更得靠自学中医，核心不是技术，是自己因为自学而掌握了某种习惯并坚持下去，只有坚持下去才对病情真正有效

+   - **第三：** 中医没问题，德行越高医术越高。
+   
+      现在是中药材出了问题，中医医生出了问题，上层的中医体系指导方针出了问题，大众对中医的认知和接受度出了问题

+   - **第四：** 饮食要根据自身情况定，大部分人不适合经常吃生冷食物、垃圾食品、多糖的食物包括饮料、不应季的食物，尽量保持饥饿感，饿了才去吃，才会激活体内的巨噬细胞。
