这三类都是悟道级强者，都找到了真正的自己，都已破局，在局之外。

他们有三个共同的特征：

# 第一：不违反天道，不让宇宙自然失衡；

不违反人道，不让人类世界失衡；更不违反自己的道，让自己失衡，都是极致真诚的做自己

# 第二：体验。

看透并看淡了这场苍生之局，表示完全理解和接受，选一种道，像游戏一样去体验：

# 天地万物皆不为我所有，但皆为我所用。

文字、经济、战争、情绪、亲密关系、医疗、教育，包括生死都是工具，都是假相，都是体验。

人生就是玩，就是体验，别当真别较真。

上学是体验而已，工作是体验而已，婚姻是体验而已，失恋失业失败失魂落魄也都是体验而已；

生病可以，活着可以，死亡也可以，不可以也得可以，就是整个生命周期里的各种体验而已。

灵魂出窍，跳出来，看着自己活，看着自己玩

# 第三：美好无处不在。

美好的事物无处不在，数都数不清，即使全人类都恶心，一次人口普查就算清楚了数量。
