# 2.1 修行各阶段

修行、觉醒、开悟、得道的这些文字概念是人为发明，是对宇宙客观事实的描述，是对你的生命到达某一状态时的总结。

修行的过程就是不断破相的过程，比如想要觉醒就得打破否定普通人的认知，想要开悟就得打破否定觉醒者的认知，以此类推。。。

# 2.1.1 普通人

你会活在一切概念之下，亲密关系之下、二元对立之下、情绪之下、规则之下、文字之下、自信之下、金钱之下、时代之下等等；被他们带着走，被这些概念控制，看不清真相，这个阶段的人认知最低但还最固执，最容易内耗，你是众生相的狗，你是一切的狗

# 2.1.2 觉醒

人类的顶层设计，这场苍生之局，主要就是针对觉醒人群。觉醒的人要么向内攻击，把自己于抑郁于焦虑，要么向外攻击，把社会于焦虑。

被现实无数次打击，醒了，看透了游戏规则，认知比普通人高，开始上道儿。

但大部分在觉醒初期只是看透并没有看淡，内心深处会觉得这个世界原来跟想象的、跟教育的不一样，有种被欺骗的感觉，容易戾气重，容易反社会反人类反文明。
