# 时间是工具，不是目的。

创造出的时间概念有昨天今天明天、白天黑夜、过去现在未来、一岁十岁五十岁、一点五点十五点，大概在什么时间大部分人会在做什么事，并以此设立政策设立制度设立行业，也就是世界上的人类在什么时间大概会发什么事基本都是可控的，这样社会才会稳定有序。

比如有了白天黑夜这个时间概念，规定了白天工作，夜晚睡觉，如果不这样设定和宣传引导，统治阶级晚上大部分都睡了，其他人不都睡，很容易把他们偷偷噶掉，他们出事了社会就乱了，所以不能允许这种不安全因素存在，就规定了白天大部分人都得上班，夜晚就得睡觉

在 6000 年前的原始阶段里，夜里不睡觉去捕猎生存反而更好，因为晚上其他动物都休息了，人类晚上不休息更有利于生存。

再比如一岁十岁五十岁这种时间概念，如果不这样规定，四岁可以上幼儿园二十岁也可以上，那不就乱套了，危险系数增加，影响社会稳定有序。

# 8.11.1 当下

再比如有了过去现在未来这个时间概念，你就会因此而内耗，没有精力内耗没有精力造反。因为有了这些概念你就会陷在过去、迷在未来，为了过去会后悔，为了未来会焦虑，但是过去已经消失是 0，未来有无限种可能性明天可能就会死未来是 n，0 和 n 都无法把握，只有当下是 1，是唯一，是确定的。

**活在当下的意思就是当下到极致，极致的意思是没有过去没有未来只有当下，而不是想着活在当下同时又讨论着过去和未来。**

时间是当下，那你的一生也可以正相理解为当下这一刻的叠加，没有过去左边右边未来只是当下这一刻的叠加，你的人生是在叠加是向上的，而不是从左边到右边的人生终点，预见终点多无趣。
