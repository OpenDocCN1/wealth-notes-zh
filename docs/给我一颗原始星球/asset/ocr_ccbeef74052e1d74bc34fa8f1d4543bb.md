# # 第二章.混乱阶段（人道）

6000 年前，人类这个生物开始发明了文字，学会了说话、学会了思考，人类变成了非常危险的生物，自此混乱阶段开启，人道出现。

目前此阶段已经持续至今 6000 年左右，这期间明面上的规矩只有一个：人道。从遵循了上百万年的天道换成了人道。但这 6000 年来的新规矩只是一般老百姓在遵守，除此之外的天地万物、婴幼儿、强者依然遵循天道。

这 6000 千年也不过是麦子熟了 6000 次，一觉醒来，太阳还是那个太阳，太阳底下没有新鲜事

人道就是人类世界的规矩和规律，主要以各学派思想为主 道家、佛家、儒家、墨家、阴阳家、纵横家、名家等，具体的比如科学、道德、法律、仁义礼智信等等，人类的一切行为都在这些思想之下。

适用范围是地球、太阳系和我的星球

# ## 1. 人类世界发展树状图

为了我星球的人类世界稳定有序和走向天下大同阶段，由此在混乱阶段整个苍生之局的顶层设计如下：

我在幕后的土壤里
根据人性种下种子
发出文字和金钱的芽
长出政治、资本和宗教的树干
再生成众生相的树枝
用爱的名义的力量浇灌
直至开出天下大同的花，结出幸福的果实

文字、金钱和爱，皆是我的工具；众生皆是文字的工具、金钱的工具、爱的工具。用文字和金钱造出给我赚钱的资本家，给我护法的政权，给我掩护的宗教。
