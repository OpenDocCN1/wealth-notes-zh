# 8.9.1.2 叛逆

整个混乱阶段的人类世界都是假的，都是错的，都不正常，都是反着的，
在合理范围内越叛逆，个人和社会的道路越正确，要正向引导孩子的叛逆，
叛逆出磅礴的智慧，叛逆出独立的自己，叛逆出美好的未来

几千年来父母对孩子的管理效果多好先不说，起码孩子叛逆反抗的是少
数，但现在的 00 后为啥不好管，为啥能整顿职场，为啥有各种逆天的想法。
根本原因是家庭结构发生了逆转。

以前家庭结构是正三角，人特别能生，比如一个爷爷奶奶生五六个孩子，
一个爸爸妈妈又生两三个孩子，它是个正三角结构，物以稀为贵众星捧月，
辈份越高地位越高越尊贵，7080 后的你得跪着。你接受的是侮辱式教育；

现在的 00 后是倒三角家庭结构，爷爷奶奶外婆外公，往下是爸爸妈妈
最底下是你，都宠着你惯着你由着你，你的思想你的灵魂是自由的，你的物
质条件是优渥的房子车子一大堆最终都是你的。

但职场的管理体制还停留在侮辱式管理阶段，那你能惯着他，加班？滚
检讨？滚；洗脑？滚；这对人类未来发展是好事，时代进步时代召唤，这样
的孩子思想和物质的枷锁都少，可以天马行空，敢于叛逆敢于说不，敢于坚
持做自己，人类进步的本质之一就是下一代永远不听上一代的话。

**跟父母相处，舒服就多接触多体验，不舒服减少接触，尤其是跟父母关
系处于崩溃边缘的，可以只负责他们的生老病死，法律上不断情感上断，自
己心安自洽即可，不要内耗不要对抗。**

每个时代的人的认知都是对应时代的环境产物。

**两代人之间的年龄差距 20 岁但认知差距可能是 50 岁甚至一百岁，很
难共情很难相互理解，请假借修真别当真别较真**
