# 3.8 软植入

第一：想要实现软植入最简单粗暴的方式就是活动，以活动的形式可以吸引大量的群体，参加活动的群体防备心较低，只需要在活动过程中植入项目信息产品信息即可。

比如现场能看到的听到的想到的都是跟你产品相关，比如活动过程中设置抽奖等互动环节，互动的问题都是项目产品信息，比如设置的活动流程动线图，就是产品的展示线路。

比如活动过程中留出 3-5 分钟做简单的产品宣讲。

总之，客户来到现场了，就会感受到你的产品信息，在过程中有专业手段筛选出意向客户即可

第二：活动又分为被动型和主动型，统称为圈层活动。被动型圈层活动指场地需求方主动举办的活动，比如少儿机构会举办六一儿童节，银行系统会举办内部运动会，医美行业会举办线下动员大会等等，都需要场地或者奖品福利等，都可以引流到项目现场，这些都属于被动型活动，我们要做的是配合。

主动型圈层活动指的是根据时代和人性，或者根据场地需求方的特性，主动设置主题活动。

比如搞第一届城市广场舞大赛，比如高金融系统内部联谊会，比如搞城市少儿画画比赛，比如项目现场根据自身实际情况，专门预留出固定空间做固定项目：**图书馆、瑜伽馆、轮滑赛道、会议室、联欢会广场、烧烤露台等等**，可以针对固定单位形成邀约，制作邀约门票等等私人订制方式体现出尊贵感。

再或者我自身条件单一有限，比如我是健身房，那就聚焦健身一事，制作排期表，邀约周边的企事业单位，在固定的时间段，可以让员工和客户来现场免费健身，现场有专业老师免费指导。
