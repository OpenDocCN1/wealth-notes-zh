# 6.创业方向启示

# 6.1 流量公司

第一：作为第三方，用地主思维给实体企业带来线下流量，按人头/按场次/转化效果收费。

传统的流量公司全是糊弄，革他们的命，比如活动公司、策划公司等

第二：可以从一个城市的专业领域做起，比如亲子领域，先做到这个领域的 top 水平，所有的亲子机构资源都在你手里，哪些地方需要亲子的线下流量就展开合作，比如商场、旅游景区等

第三：做大之后可以以城市为单位，深耕资源为主，把资源倒流给整个城市需要流量的机构；也可以专注细分领域，攻城拔寨，向其他城市扩张

第四：还可以跟需要流量的机构形成深度合作，比如共同出资打造更多收费的体验项目。以免费场地的免费项目为饵，到了之后一定会产生一定比例的新项目消费。新项目的位置、线下的动线设计和项目的选择很重要

第五：结合手机互联网，做短视频，把自己打造成线上流量+线下流量的 IP
