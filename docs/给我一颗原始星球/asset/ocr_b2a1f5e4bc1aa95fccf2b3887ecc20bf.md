可以跨越时代，跨越经济周期，不用被淘汰，不用经常换行业，一辈子围绕一件事，如如不动，能够踏实的活到死

世界上只有两种工作，一种不会被淘汰，一种随时会被淘汰。90%的人做的事是随时会被淘汰的，不管你是知名企业家，还是高学历，没有悟道就是时代需要时被驯化出来的一条狗，狡兔死走狗必烹。

比如煤老板辉煌十几年，好多都没了吧，破产、进监狱、流亡海外等等开发商老板辉煌了十几年，好多都没了吧；互联网大佬辉煌了十几年好多都没了吧。大学生哪怕是 985/211 毕业的高材生，大部分学的专业都具有时效性，有的可以干十几年有的就几年，甚至有些大学毕业即失业。因为行业或者开设的专业，都只是时代对应需要，不需要时一夜之间一刀切完。大部分人是典型的有术无道止于术，都不是悟道级，只是社会需要的一条狗。所以赚钱的第一步必须对学历、社会地位、权威等祛魅，他们都是狗而已，短暂辉煌的狗

一个行业一个专业的落幕，是必然，是天道，也是人道，但这恰恰也是千千万万个老百姓和大学生需要从头开始的操蛋人生。所以，想要幸福就必须找到适合自己的长效生存之道

# **2.4.2 生存**

+   - 第一：回归生命本质，活着就是混口饭吃，是生存底线。
+   - 第二：绝不是为了发大财，但可以发大财。**钱是工具，不是枷锁。**
+   - 第三：在生存面前，道德和法律都没有力量

# **生存方式有三种**

+   - **第一：上班。**

但世界上靠上班生存的人只有 50%左右，上班期间你去商场会发现人是满的。在很早的农村，大部分人都没工作才是常态。

是城市需要工作，城里的人需要工作。如果农村的人都去上班了，城里就会被养出一大批不用上班的人；总之整体上会维持 50%左右的社会群体是上班族，且这 50%里的 90%，会不断换工作、换公司、换行业。
