# 8.2.4 无相

天地万物都不会说话，花花草草猫猫狗狗都不说话，人类在 6000 年前也没有文字不会说话，婴幼儿不会说话，强者惜语，甚至归隐拈花一笑不再说话，不屑于说话，不屑于使用人类创造的文字陷阱。无相是开悟后的状态，可遇不可求，建议如下：比如你要是弱，就别说话少说话，不说话之前没人敢惹你，不了解你之前没人敢惹你，你被人欺负完全是自己吸引来的。比如两个人在一起久了之后多一点灵魂交流，少一些口舌相伴。就是平平淡淡，就是安安静静，只要陪伴着，哪怕不说话，也会岁月静好。少说话就会减少争吵，少说话就会减少临时需求的起意，遇到事情正常沟通正常处理即可。即使是面对当年灵魂多么契合的爱人，时间久了也要精神内守。不然你会变成事儿爹事儿妈，天天事儿事儿的。人类就是被驯化的狗，满大街都是被驯化的狗，满世界都是汪汪汪，跟狗说那么多干嘛？这个世界上的大部分要么敏感，要么傻逼，你跟敏感的人说那么多干嘛？你跟傻逼说那么多干嘛？跟任何人相处的文字使用方式：有事开启熟人模式，没事开启陌生人模式

# 8.2.5 二元对立诞生

二元对立是苍生之局的一环，所谓的对错好坏都是工具
正是有了文字才开始有了定义，有了定义就一定有人认为对有人认为错，就开始分阵营拉帮结派，开始有了对立有了战争有了伤害，男女对立、家庭矛盾、阶级矛盾、帮派组织民族国家，善恶好坏，白富美矮矬穷，包括战争等，皆是因为二元对立。电视剧电影里最大的卖点一定是打架、宫斗等二元对立，二元对立思维是社会稳定有序的重要手段，人类变得很容易被洗脑被引导，注意力被转移，灵魂被转移，能量被转移。文字都有偏见，都是站在自身利益角度的表达，再伟大的作家也只是书写自己的偏见而已，只要说出来就错，错了就有人纠错，形成二元对立，错上加错。
