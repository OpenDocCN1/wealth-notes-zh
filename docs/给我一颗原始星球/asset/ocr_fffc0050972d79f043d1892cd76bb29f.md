# 2.1 你为什么会被欺负？

狗为什么吃屎，因为散发着屎味儿；你为什么被人欺负，因为你散发着弱者气息

**第一： 要跟谁都敢翻脸，但凡让你不爽，加倍还他。**
世界上 99.99%的人你都得罪得起，剩下的你得罪不起的 0.01%，你根本碰不到

**第二： 人在底层必须有虎狼之气，要有匪气。**
只有到达一定高度自然会优雅知性；穷人需要狂野一点，优雅谦卑是有钱之后才配做的事。只有强者才能止戈为武，柔弱是你变强之后的选择

**第三： 单纯的柔弱心软和不好意思只会杀死自己。**
理性的薄情和无情才是生存利器，因为柔弱心软就是软弱，软弱就是无能，破窗效应之下，全世界都会认为你可以被欺负

**第四： 金刚怒目也是修行，反抗攻击代表着磅礴的生命力。**
你不向外攻击就一定会向内攻击；向外攻击，你的生命力越磅礴，向内攻击天天干自己，你会越来越弱，赶着去死啊

**第五： 你要是弱，就别说话少说话。**
不说话之前没人敢惹你，不了解你之前没人敢惹你，你被人欺负完全是自己吸引来的
