# 2.4 动作变形的修行

**第一：修出优越感。**

看不上自己周围的人，甚至都看不上人类，张嘴闭嘴都是你们人类怎样怎样，变得格格不入，一般发生在刚开悟不久。

**第二：修到向下虚无。**

一般发生在觉醒阶段，虚无就是觉得没啥意思。如果向上虚无直至归隐也算，但就怕觉得活着没啥意思，直接抑郁。

**第三：修到愤世嫉俗。**

自我感觉认知提升，看到很多真相，就是没看全，没看淡，变成愤青

**第四：逃避现实。**

现实中越有钱的人修行的越多，明星、企业家出家的最多。刻意修行在某种程度上可以理解为吃饱撑的，逃避现实的一种方式，因为当人生处于低谷，或者社会出现危机时，这时候人类开始务虚，甚至走向虚无，修行的人在此时会大批量出现，寻求脱离痛苦，追求觉醒。穷则独善其身，达才兼济天下。

**当你遭遇人生低谷，请你停止思考，你思考个鸡儿啊，修行修行，在行动中修正才是修行，行动起来才会从内心生出智慧。**

读了多少伟大的思想，你也只是思想搬运工，拜了多有名的大师，你也只是大师复读机
