第四：如果健身房的人每天都排满，每个人出汗了都会买饮料，饮料消费会是以往的几十倍，来的人免费体验时间到了总会有一定比例还想继续玩，那就得缴费，来的人多了老会员续卡的概率会增加，办新卡的也会增加，健身房老板还可以跟周边企事业单位的负责人变成朋友···都是好处

# 4.1.3 高等教育行业+案例解析

# 面临问题

问题一：高校的场地很多且利用率很低，室内场地室外场地都有，很多时间都是闲置的。

比如多媒体教室、大型会议室、操场、运动场、绿地广场等等

问题二：除了少数名校，绝大多数学校都要主动推销自己的学校专业特色、学生特色、老师特色，以增加校园招聘、学生社会实践、学生就业、老师项目实践等

# 1.0 版本的应用

+   第一：按上面地产行业的模型组建个小型团队
+   第二：拓展城市内企事业单位或民间团体
+   第三：把场地免费共享给他们，但必须预约
+   第四：比如企事业单位需要场地培训，可以来我校，但是我相关专业的学生可以旁听，这种实战理论比学校的纯理论教学有用多了；

比如企业有实习的机会第一时间要给到我校名额；

比如企业搞得大型活动可以让学生不出校门就长见识见世界，大疆无人机试飞起飞坪可以选择校园绿草地等等；

比如城市里的机关等各系统要举办运动会，可以来学校举办，以后学校的人脉更广，争取资源或者突发事件处理都会对我校有利等等
