# 8.3 金钱相

金钱是假的，原始阶段的上百万年哪有钱？花草树木猫猫狗狗谁有钱？
婴幼儿会在乎钱的事儿？强者想咋挣钱咋挣跟玩一样他们谁会在乎钱？

钱是工具，不是目的不是本质。每个时期金钱的表现形式一直都在变：最开始是贝壳、布块，后来是金子、银子、铜板，现在是纸，以后可能是数字。

但是整个世界除了建立在文字之上，同样也是建立在金钱之上，是文字和金钱一明一暗一公一母生出了整个世界。一切都是金钱，没有钱啥都没有！没有金钱会有国家？哪个上位者背后不是有钱的百年家族在支持？没有金钱会有资本家会有马云？没有金钱会有宗教？庙香火越旺，佛像越大，这是金钱。没有钱能上学？能看病？能结婚？能生孩子？是钱生出了这一切。

所以不管是什么人、什么阶级、什么组织，包括国家，这一生大部分的时间都在挣钱，不择手段的积攒财富，完成原始资本的积累成了首要任务

金钱不是一切，但金钱能解决个人或组织 99.99%的问题，金钱是人活着最大的底气，没有之一。金钱也是除了悟道获得无上智慧意外最能带来快感的事情。

金钱这个假的工具可以判断人的真假：金钱让高贵的人更高贵，卑鄙的人更卑鄙；让深刻的人更深刻，浅薄的人更浅薄。因为有钱之后一般的你就不装了
