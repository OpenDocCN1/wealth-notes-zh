# 第六：这俩孩子的成长和阶段性的被关注度，天然的不太同步。

往往大家都太专注于肉体世界的拼搏就会导致精神世界的修行减少甚至停滞。钱可能挣的多了，但精神空虚。所以心理出现拧巴感觉到迷茫内耗，也就成了极其自然的事。俩孩子都想成龙都想达到最高境界的概率做乎其微。太过于追求最高境界，野心太大，身体和心灵都可能承载不了。身体垮掉、精神垮掉或者都垮掉。

**第七：既然精神世界大多数时候会指导肉体世界，既然肉体世界比精神世界难，既然肯定存在阶段性的顾此失彼，那就告诉精神世界这个孩子：有个事情需要你理解，肉体这个小家伙难伺候，我得趁它年轻时多关注他，让他赶紧的先发育先拼搏先经历先去看看这个世界，它拼的越努力给你带来的条件越丰厚你就开心经历的多你也就越强壮，要不然到老了你们俩都过不好，肉体越老越完蛋，还后悔一辈子，后悔就是精神世你的事情了，最后肉体和精神你俩都难受，这不是傻吗？**

再说了，肉体世界早晚得听你的，别计较先关注肉体世界先感受一下世俗，才能让你这个精神世界清新脱俗，以后肯定你说了算，别计较别迷茫别拧巴。
所以年轻的时候多去看看这个世界，多去干多让肉体去经历，少胡思乱想少关注精神，这个才是这俩孩子发展的正道。
