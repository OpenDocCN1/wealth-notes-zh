没有邪恶，谁来伸张正义？有些人群还有存在的必要吗？要统治阶级干嘛？没有妖魔，哪来的神佛，谁还去烧香？越是灵山脚下妖魔越多；都公平了，还需要统治阶级吗？都道德了，还需要讲道德吗？但是如果没有统治阶级、没有圣人，当邪恶出现时，谁能有力量组织去对抗去消灭？没有超高思想没有绝对力量没有金钱积累，能战胜邪恶战胜妖魔？所以没有邪恶也要制造邪恶，没有妖魔也要制造妖魔，圣人不死，大盗不止！

好坏对错，善恶真假，神佛妖魔，皆是工具而已。

二元对立这场游戏的设计，是阳谋，无解，了不得。任何事的结论变得不再绝对，都需要多角度分析，尤其是阴阳两面。<u>整个人类世界也就在二元对立的此消彼长的周期轮回里，波浪式前行。</u>
