# 19.思虑过多 破！

# 思虑过多的本质是注意力被掠夺

注意力被掠夺的原因是大脑为主体的肉体被文字编程；
也就是大脑只要不动少动，精神内耗就会消失和减少；
天天搬砖的没几个精神内耗的

+   第一：每天必须保持足够的时间让大脑闲下来，停下手中的工作
+   第二：认识到所有的思绪和顾虑都是假相，都是设置好的局，别跳
+   第三：学会转念和断舍离。
+   当念头过多时听听音乐、看看电影、运动一下

+   第四：生命是有限的，不要无限追求财富，不要无限追求知识；
+   最寸土寸金的是生命，你从来都不可能拥有任何东西；
+   你只有体验的权利；要用生命体验生命；
+   而不是用生命去工作，工作只是生命的副业

+   第五：把注意力集中到当下行动和行动带来的感受上
+   让行动和感受统一，即：活在当下。
+   比如吃饭就是吃饭
+   好好享受吃饭，吃饭是多么美好的一件事
+   食物入口的一瞬间，全是多巴胺，浑身带来能量；
+   喝水就是喝水，跟着水走，他到了嘴里到了喉子到了身体的血管
+   这都是能量

+   第六：不专注当下的人，思虑越多越弱智：
+   即没享受到当下，也对不起过去好当下，更让未来充满不好的变数
