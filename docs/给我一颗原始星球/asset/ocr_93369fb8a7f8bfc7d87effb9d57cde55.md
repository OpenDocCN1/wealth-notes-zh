# 第一：熟能生巧。

比如奥运冠军也是天天练习一个动作，跟一个动作熟悉十几年才有可能是世界冠军，只要对这件事熟练的次数和时间够长，最差也是省冠军市冠军。

# 第二：熟能生自。

再比如你刚到新学校新公司新城市等等都是陌生地方都是陌生的人，最开始不适应甚至恐惧哪也不敢去也不敢轻易跟别人说太多，日子长了你对每个地方每个人都熟悉了自然很放松，闭着眼都能找到拉屎的地方，很自然

# 第三：熟能生知。

比如创业，没干过肯定害怕，害怕没有未来害怕回不到职场害怕赔钱，但是干过一次不行干两次三次再不行干十次八次傻子也拥有创业的知识了

# 第四：熟能生胆。

比如有人欺负你你不敢反抗，那是因为你没反抗过跟反抗这个事不熟，你反抗一次后就会发现原来如此，甚至感觉好爽，多干几次后完全熟练了，甚至见个人都想反抗试试

提前演练，多演练多干几次就熟了。

可以现实中模拟，也可以不断在脑子脑子的场景里建模，要模拟到具体细节。

# 第一：熟能生慧。

比如在未来可能或一定会遇到的重大困难，像失业、分手、离婚等等。提前模拟什么时间因为各种原因导致的失业，失业后你怎么处理你的家庭你的贷款你的下一步等等；提前模拟什么时候因为什么原因分手或离婚，离婚后自己怎么继续生活；现实中很多人分手离婚当成了家常便饭、每次都波澜不惊，那是因为经常离婚玩儿；做人的智慧。
