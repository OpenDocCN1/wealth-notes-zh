# ### 1.1.7.4 向内求一直求到本自具足

向内求才能变成有内核的真我，向外求会变成行尸走肉没有灵魂的狗。向内求一直求到本自具足，你啥都有啥都可以创造，自己可以完成生命所有闭环

+   - 第一：你是信仰本身自信本身能量本身，不需要向外求别人鼓励别人认可别人安慰，你是真人你眼里看到的都是假人，去求假人帮自己这个真人？

+   - 第二：你是钱本身，自己可以创造挣钱机会挣钱项目，专注提升自我感兴趣的核心技能，你在哪钱就在哪，不需要追着钱跑

+   - 第三：你是意义本身，自己的好自己的坏自己的对自己的错自己的屎尿屁就是意义本身，不需要向外求答案，求自己去

+   - 第四：是医生本身，可自学中医，靠自身免疫力和修复力，不需要向外求医生

+   - 第五：你是智慧本身，从内心生出来的自我感悟，也可以靠自学万物知识，不需要靠向外求老师，所有知识原本就没有，还不是人发明的，凭什么不能是你？

+   - 第六：我只求自己，我是一切本身，我是一切的根源，一切皆有利于我，天地与我共生，万物与我唯一，我心即宇宙，我是宇宙中心

# ### 1.1.7.5 不要同情任何人，真正的慈悲是让该发生的事发生

+   - 第一：不要想着当别人的救世主，你连自己的命运都干涉不了，怎么可能干涉得了别人的命运

+   - 第二：天底下没有可怜人或者人人都是可怜人，再有权有钱的也有可怜的一面。也就是你也很可怜，哪还有闲功夫可怜别人？
