# 3.3.1 颈椎病和精神内耗的关系

颈椎病非常容易引起各种精神内耗：焦虑症、躯体化症、心脏神经官能症、惊恐症等。原因是但凡肩颈胸开始紧张，呼吸就开始受影响，就可能会引起濒死感，颈椎病最容易引起胸椎胸腔膈子肩胛骨问题，这些都容易引起呼吸问题。

只要放松下来，症状马上缓解

颈椎病的康复，需要的对症下药+专业指导+耐心这三项。

第一：耐心，每天必须坚持，动物都没有颈椎问题，婴幼儿都不会有颈椎问题，只有长大之后的人类有颈椎病。

每天坚持，至少坚持三五年，把这件事当做跟吃饭一样的大事，形成自己的下意识潜意识

第二：颈椎病包括颈型颈椎病，神经根型颈椎病，脊髓型颈椎病，椎动脉型颈椎病，交感神经型颈椎病，食道型颈椎病。
