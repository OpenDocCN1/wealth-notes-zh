# 2.天道=无

天道是无，人道是有，天道是 0，人道是 1，宇宙就是由 0 和 1 组成。

我们终其一生要追求的是无不是有，无病无灾、无忧无虑、无欲则刚···无极生太极，无中生有，才有了后来的 人道

# 2.1 无情

万物有灵没有情，天若有情天亦老。

天地万物，既无情绪，也无情感。

天没有情感，下大雨淹死你不管你是好人还是坏人；地没有情感，地震震死你不管你是婴儿还是孩子；花草树木没有情感，在原始阶段的人类也没有情感，你不会同情一个残疾人，没有亲情爱情友情各种情

天没有情绪、地没有情绪、花花草草没有情绪、猫猫狗狗没有情绪、原始阶段的人类没有情绪、现在的婴幼儿没有情绪、现在的强者没有情绪，<u>只有平静，平静的笑，平静的闹，在情绪之外。</u>

比如一只狗被另一只狗欺负，被欺负的这只狗在被侵犯时会龇牙咧嘴，另一只狗只要不继续欺负，这只狗瞬间忘却此事恢复如初，不会过了一年还在生气；再比如婴幼儿之间闹别扭，既不记仇也不放心上；再比如婴幼儿无情，他不会对任何东西有感情，不会同情和害怕任何人，皇帝的儿子他都敢揍；再比如强者平静如水，都是身受心不受

天地不仁以万物为刍狗，圣人不仁以百姓为刍狗，父母不仁以孩子为刍狗。

天无情，但天有阳光雨露，给了万物生命，世人觉得天爱苍生，都在为老天歌功颂德；

花草树木无情，但绿意盎然和生产的氧气人类生存不可或缺，爱意洒满人间；

帝王无情，李世民无情了杀掉自己的兄弟和父亲，才成就了千古第一盛世，武则天把自己的孩子基本全部杀完，才成就了千古第一女帝，哪个开国
