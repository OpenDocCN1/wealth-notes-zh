# 万物都可以是你的狗

有五个典型的特征：

**第一：极低欲望。**

没啥消费，如如不动，很省钱，连吃饭都很少，几十块的衣服能穿好多年

**第二：很平静。**

开始懂得内观身体，甚至自学中医，也就是身体使用说明书；情绪稳定，追求平静平淡，根本不会追求快乐啥的乱七八糟的情绪；也不再跟人争吵辩解，甚至很少说话，心宽

**第三：瞬间看透本质。**

宇宙万物的本质、人类世界的本质、个人世界的本质，也就是能做到见天地、见众生、见自己

**第四：解决问题的能力。**

首先在他们眼里不存在问题，其次遇到任何问题永远都有方式方法，都是瞬间看到本质，**从第一性原理的角度出发，遇到啥解决啥，只是体验**

**第五：自成体系。**

对个人世界、人类世界和宇宙世界的各种问题有自己成体系的理解。看人类的一切行为就跟看小孩子玩过家家一样，入世和出世之间可以随意切换。完全无相随心，到哪都能修，干啥都是修，需要解决问题时就从高纬入世降维解决问题；不需要自己时就淡然出世，安贫乐道，采菊东篱下
