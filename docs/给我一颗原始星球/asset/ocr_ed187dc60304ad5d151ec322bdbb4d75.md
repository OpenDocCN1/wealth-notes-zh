# 第三：肉体世界发育长大完善需要现实世界里饮食、养生、学校、上班、拼搏以及各种社会游戏进阶法则，等等这些都是营养，吸收的多、吸收的好，肉体世界就越强壮越强大；

精神世界也一样需要营养，比如各种精神内耗各种痛苦，这需要通过修行来吸取才能强大。世界上都有各自很成熟的方法论和进阶法则，都给总结好了，找到对的并学习即可。

这个过程里别让这俩孩子摄入过多的垃圾成分，不然肉体和精神都会出问题。

# 第四：肉体世界比精神世界发育的早，且相互影响。

肉体世界发育早是因为精神世界心灵成长起码得懂事之后才开始发育，肉体从出生就一直发育了，且小时候谁都不太会关注心灵成长，主要去讲究这个肉体怎么吃怎么发育；而且还有个天然的本能，就是身体越年轻越利于拼搏，也就越有利于肉体的现实世界更加茁壮成长，后来的读书、工作很自然的忽略了精神世界。

前期主要是肉体世界主导精神世界，到了中后期主要由精神世界主导肉体世界，肉体世界经历的越多，精神世界越强大越丰富，同时精神世界越强大，肉体世界现实世界做事越顺手如意。

# 第五：俩孩子达到各自的成熟状态难度系数不同，精神世界发育难度看似大于肉体世界，实则恰恰相反。

因为精神世界只有你自己、完全由自己掌控、自己说了算，相比较会更容易达到或接近。但肉体世界相比较就很复杂了，外物太多，规则太多，不由自己说了算。
