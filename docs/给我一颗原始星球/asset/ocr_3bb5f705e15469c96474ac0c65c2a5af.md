# ### 1.3.2 分类管理

原始阶段上百万年里，没有等级，没有三六九等

就这样星球以人类为主、人类以统治阶级为主的星球世界组织架构就形成了，金字塔结构。所有生物以及人类内部的三六九等自此开始出现，家庭上中下三代等级开始出现。并想尽办法控制每个阶层的人数比例，通过分类，定期进行管理和清理。

# ### 1.3.3 欲望出现

有了温差，空气才会动起来，产生了风；有了位差，水才会动起来，产生了水流，有了等级差，人才能被调动起来，产生了欲望。

比如一个班级有了成绩第一名，就会树立攀比的榜样标杆；比如公司团队有了第一名，奖金奖励最多，就会树立攀比的榜样标杆；没有第一名也得故意制造出等级差，刺激出欲望，达到目的

有了欲望的生物，容易被操控，被引导，也就是容易迷失自我，社会就会稳定有序。没欲望的生物是不是很可怕？是不是很难管理？因为无欲则刚

# ### 欲望的分类

+   - 第一：在原始阶段只有食色性也这个生命本质的基础需求
+   - 第二：在混乱阶段除了食色性也，开始产生并引导额外的食色性也欲望、权力欲望、金钱欲望、认知欲望、娱乐消遣欲望
+   - 第三：天下大同阶段会保留原始阶段的食色性也这个基本欲望，和混乱阶段的娱乐消遣的享受生活欲望，以及思想创新和科技创新等极致真诚的表达自己欲望
