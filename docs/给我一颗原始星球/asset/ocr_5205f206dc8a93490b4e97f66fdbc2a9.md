比如公示财产、比如诛九族，还有好多方法都可以有效精准打击贪腐。
因为让你贪就是个设计好的局，是个坑，是个陷阱，跟养猪一样，把你养肥就宰了。

+   第一：发展初期不留这个口子欲望激发不出来发展就会慢，没动力，
+   一对比位置都做那么高了还是两袖清风住茅草屋蹬自行车，就泄气了。

+   第二：优秀人才招揽。
+   如果其他行业都可以发财，唯独当官喝西北风，优秀的人不可能被招安。

+   第三：发展过程中一定会遇到问题，就可以借沙滩管以泄民愤，转移注意力转移矛盾，并收复民心
+   第四：大型组织一定是臃肿的论资排辈看不到希望的，让那些贪的人腾出位置，内部活力重新被激活，这是个完美闭环

# 10.2 定期清理金钱

金钱最腐人心，因为创造出金钱后，金钱又创造出了欲望。

+   第一：清理金钱的方式有：房贷车贷消费贷、创业骗局、理财骗局、投资骗局、泡沫经济危机、不断印钞通货膨胀等等，不同的人群对应被骗的方式不同，但本质都一样

+   第二：就业；专业技能会随时被淘汰

+   第三：创业；创业需要经验和公式，普通人创业大概率把钱交给了房东、给员工发了工资、给政府纳了税，自己最后赔个精光还容易负债

+   第四：普通人根本不可能富裕，早就设计好了。
