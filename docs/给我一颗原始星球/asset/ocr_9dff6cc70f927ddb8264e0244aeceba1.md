# ### 前 2 秒法则

所有人刷短视频就是刷，极短的情绪刺激，前两秒不能吸引他，就刷过去了。所以前两秒必须要展现出情绪，可以在视频开头用任意一个情绪开关达到效果，也可以把整个视频中最有情绪的两秒剪辑到视频开头。爆点前置

# ### 四大内容来源

做短视频的重点就是把内容当专业朋友圈发，专业朋友圈：把你的注意力全部用在当下做的短视频上，任何你能利用上的都可以作为当下所做的短视频素材，任何你做的每件事、遇见的每个人、脑子里的每个想法、都要跟做的短视频产生连接，哪怕是随意跟人聊天时的内容、吃顿饭、拉泡屎，都可以作为素材的灵感来源。

天不能白聊、饭不能白吃、屎不能白拉

素材的来源有四个：

过往经历、当天经历、自我学习、蹭五个热点

+   - **第一：过往经历。** 以前最擅长、最熟悉、最感兴趣的事情，比如自己的职业、自己的爱好、自己的家乡、自己的家庭、自己的圈子等

+   - **第二：每日感悟。**

新的每一天，你都会有新的感悟新的想法新的轨迹新的圈子，这些都是素材来源

+   - **第三：自我学习。**

为了做短视频肯定要每天坚持学习，看书、向别人请教、看段视频等等学习中的感悟都是素材来源

+   - **第四：蹭五个热点。**
