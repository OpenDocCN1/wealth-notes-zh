# 8.7 我相

你认为的我是假的，你认为的我是被打压灵性、打压兽性、驯化新人性后的我，你认为的我只是肉体是躯壳。

比如我叫小镇舍长，这只是我的代号，一个称呼而已，我只是在扮演小镇舍长，在互联网上体验个三年两载就不用了，包括身份证上的名字，体验个几十载就不用了

不要执着这个假“我”，以及这个假我相关联的一切。比如若你执着这个肉体，但它会死，没办法执着，没办法较真。
