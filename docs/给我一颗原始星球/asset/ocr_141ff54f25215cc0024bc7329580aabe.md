# 8.8 人相

人是假的。

我们本不是人，跟其他动物一样都是一坨肉，原始阶段哪有人这种概念，
就跟狗一样，人是被驯化而来。如果原始阶段的是人，那为什么你跟现在
是完全不一样的人？

再如果你现在是人，那现在把你出生时就扔到狼窝里让狼把你养大，你
跟现在的人也完全不一样，现在的人会认为你根本没有人性。

只是为了社会稳定有序，统一给这个群体的下个定义而已。如果最开始
给我们这个生物的定义不是人，而是狗，那我们现在会称呼自己是狗，人类
的所有问题都是人类思维导致，所以解决人类问题得站在人之上。

但是回不去了，你只能是人，要表演的像人。你是人，你不是人，你还
是人。借假修真不当真不较真
