# 2.3 不负债有存款

# 2.3.1 不要负债

一旦负债，灵魂就跪下了，再也没有机会觉醒开悟；除非你是很清醒的把负债当成工具：利用负债可以赚钱，有钱人的负债是资产是前景是工具，但普通人的负债就是负债

如果已经负债的

**第一：必须还债。**

第一时间通知给债主，自己不会赖账，具体下一步的挣钱计划地点还款计划都告知他们，让对方放下心更不用催债

**第二：个人状态调整。**

负债前后你的生命状态没有发生任何变化，也就是生命本质没变。负债之前该吃吃该喝喝该睡睡该找点事干去干，负债之后还是该吃吃该喝喝该睡睡该找点事干去干。负债对于你从生命本质角度上不存在

**第三：你是有灵魂的，只是肉体负债不是真正的你负债**

**第四：负债是来渡你的，一切发生皆有利于我。**
