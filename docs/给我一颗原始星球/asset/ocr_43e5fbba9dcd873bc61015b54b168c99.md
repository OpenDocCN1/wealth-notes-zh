# 2.3 无常

天是无常的。说热就热说冷就冷，雨说来就来，天气预报也不准，有时慈悲的滋润万物，有时残暴的毁天灭地，天可以善良可以残忍；

水是无常的。能变成固态液态和气态，水能救你也能杀你，水可以在天上可以在地下可以在大海，可以在杯子里可以在碗里也可以在水壶里，水无处不在；

婴幼儿是无常的，说哭就哭说笑就笑，前一秒还在打架，后一秒就和好如初；

人生是无常的，水无常形人无常态，每个当下都是偶然，说生就生说死就死，半点不由人，有时能赚到大钱有时都吃不饱。

计划赶不上变化，只有猪圈里的猪，才什么年纪做什么事被定义好了，你可以变幻莫测，可以真真假假，比如人不一定要说真话，要说对自己有利的话等等

然而个人和社会都喜欢确定性，其实是喜欢安全稳定，经验主义就会诞生、固执就会诞生、规则规矩制度就会诞生，都属于封闭性自治，也是弱者思维，是到了混乱阶段驯化演化的结果，是为了社会稳定有序，所以你接受的信息从来都是按部就班、循规蹈矩。

相反，天地万物包括强者拥抱不确定性，接受无常，利用无常，享受无常，变成无常。

无常是天道，原始阶段的万物生灵包括你皆与天道一体，你就是无常本身。

当你意识到并变成无常本身时，一切无常的发生对你来说就是平常，一切发生皆有利于你，什么都能接受，什么都允许发生，来啥解决啥，遇到啥享受啥，**允许的力量大于一切！**

# 2.4 无相

在原始阶段天地万物是无相的，无众生相，更没有定义更不会被定义，连文字都没有定义个 der 啊。
