# 什么叫衡量定义？

什么叫衡量定义？

就是让客户说出他需求背后代表的意思。

当客户明确了他内心需求，并且知道了哪一个需求是他最重要的，最在乎的。

接下来客户会在心里面想，我要的产品具体应该是什么样子？比如我要买一台电脑，我很在乎价格，但是具体多少的价格才是我满意的？

是八千，还是一万，数字要明确，这就是衡量定义。

![](bbox=[0.15, 0.58, 0.85, 0.72])

举例：客户要投资一个项目，客户最重视投资回报率，那多少的回报率是他满意的呢？

假如30%以上的回报率，他才会投资，这就是定义！
