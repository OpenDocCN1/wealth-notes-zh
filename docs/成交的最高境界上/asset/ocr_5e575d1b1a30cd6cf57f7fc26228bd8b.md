# 决定动力 2 小问题的累积

什么叫小问题的累积？

比如今天有一个人开车，他感觉刹车不灵，明天刹车不灵后天刹车不灵，他不敢开快车，因为他开快车的时候他怕刹不住。

所以上班常常迟到，他约会常常迟到，他老婆常常抱怨，他儿子常常抱怨。

有一天，车子要借给一个朋友开，朋友又说，你车子性能真差，他感觉很没面子。

就这样累积了太多的小问题，有一次，他又刹车不灵，差点撞到前面的车，虽然没有发生灾难性的问题，可是他终于受不了，压垮骆驼的最后一根稻草出现了，所以决定要换车了。
