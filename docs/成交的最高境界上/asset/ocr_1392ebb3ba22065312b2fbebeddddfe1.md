# 如何建立客户信赖感四

每一个人都喜欢别人的肯定，每一个人都喜欢听到好话，所以你要给别人喜欢的东西，真诚地赞美而不是虚伪地赞美。

什么叫真诚的赞美，讲出别人有但你没有的优点，而且是你很羡慕的，这叫真诚的赞美。
