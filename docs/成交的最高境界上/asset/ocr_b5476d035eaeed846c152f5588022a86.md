# 第 58 课：第四阶段·衡量需求 5

成交万能公式·成交合作伙伴

有一次在一诺老师线下的课程里面，有一个弟子姓刘。

弟子问：“请问一诺老师，我们公司想要有更多合作商代理商，我怎么用您这个方法去成交他们跟我合作呢？”

一诺老师说：“只要你把《成交的最高境界》学得融会贯通，用这个方法你可以成交一切”。

一诺老师在现场就给他们演示如何与别人谈合作。
