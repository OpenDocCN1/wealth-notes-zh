一诺老师经常教导我们，每一次做销售见客户之前，一定要为结果做好准备，你要再问自己六个问题：

2.  **客户要的结果是什么？**

![](img/2191cd3cf6d1b6f0e330379fad132b9b_84_0.png)

3.  **我的预期是什么？**
