# 什么叫评估比较？

什么叫评估比较？

当客户从第六阶段，明确自己具体要什么产品的时候，在 这一阶段的客户，最常做的一件事情就是——到处看看！

到不同的地方，看相同的产品，找不同的业务员，来介绍 相同的产品！

![](bbox=[0.15, 0.47, 0.89, 0.59])

比如你要买衣服，你不会看上了立刻就买，你会到很多店 去比较比较。

比如你要买一台电视，你会去看很多品牌，不管买任何东 西，你都会去比较，金额越大越会去比较，当然如果你只是 买一瓶矿泉水那就没必要比较了。

所以当我们研究客户的心理学，其实也是在研究我们自 己，任何人的心理变化过程都是一样的，这是宇宙的规律。
