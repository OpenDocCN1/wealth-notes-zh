# 拥有冠军的心态,才能有冠军的结果

一个人在购买一件产品或选择跟你合作，这个过程就是内心下决定的过程。

内心做了决定才会做出购买的行为，而为什么有的客户会做决定购买，有的却决定不买？

这两种决定的不同，其根本原因就是，头脑的想法不同，客户在做决定的时候，会在内心思考，所以如果我们有方法能够预测到客户的内心世界，了解客户头脑的想法，你觉得成交率是不是会增加呢？

那要如何才能了解到客户的心理？
