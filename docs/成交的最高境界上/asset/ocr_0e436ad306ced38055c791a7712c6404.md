# 第 4 课: 知己知彼百战不殆

# 你要比客户还要更了解他自己

在孙子兵法中说: “知己知彼, 百战不殆; 不知彼而知己, 一胜一负; 不知彼, 不知己, 每战必殆。” 意思是说, 在军事纷争中, 既了解敌人, 又了解自己, 百战都不会有危险; 不了解敌人而只了解自己, 胜败的可能性各半; 既不了解敌人, 又不了解自己, 那每战都有危险。

![](bbox=[0.15, 0.45, 0.87, 0.58])

我们每天都会面对各种各样的客户, 为什么在过去你用同样的销售技巧和话术, 但是有的人会赞成你, 有的却反对你?

因为客户的性格不同, 每个客户喜欢听的话也不同, 所以我们的应对技巧也要所有变化。对症下药, 才会事半功倍, 只有在销售之前先了解客户有什么种类, 客户有什么性格, 当你一见到客户就能快速地判断客户的类型, 才能做到百战不殆。
