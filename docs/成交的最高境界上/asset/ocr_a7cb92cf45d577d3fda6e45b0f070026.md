# 如何建立客户信赖感六

人喜欢什么样的人？标准答案——像自己的人。

人既然喜欢像自己的人，当你像客户的时候，他感觉你们是同一类的人，他就喜欢你，喜欢你进而才会信赖你。

英文 LIKE 什么意思——喜欢。

LIKE 又有另外一个意思——相像。

当你 LIKE 别人的时候，就是像别人的时候，他也会 LIKE 你、喜欢你。
