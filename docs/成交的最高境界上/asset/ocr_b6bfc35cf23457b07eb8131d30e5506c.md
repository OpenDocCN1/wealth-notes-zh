# 分析竞争对手

顾客在听完你的产品介绍之后，感觉想买，但他会说：“我在看看、再想想、再考虑考虑、再对比一下……”

你要分析一下竞争对手——同样的产品，同样的服务，为什么客户一定要向你买，而不是跟别人买的理由是什么——

+   是因为他的产品没有你的品质好？

+   还是服务没有你好？

+   还是公司的附加价值没有你好？

> 人生是一场心理学的游戏，
你要比客户更了解他自己！
