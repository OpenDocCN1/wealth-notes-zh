# 第 19 课：产品知识准备

# 你要疯狂的爱上自己的产品

如果你是老板你可能对你的企业、你的产品非常了解，可是如果是员工那就不一定。

为什么很多销售人员常常被客户拒绝？

![](bbox=[0.15, 0.36, 0.85, 0.49])

有一个最主要的原因，就是当客户问销售人员一些产品问题的时候，销售人员不能很流利地答出来，客户会对你产生什么样的感觉呢？标准答案：你不够专业。

记住客户要的是一个专家，就像你去看病的时候，你会找一个不专业的医生吗？

一诺老师研究发现，有很多公司新招进来的员工都没有接受过培训，然后就让他们出去见客户做销售，结果常常碰壁！

这是一种不负责任的做法！
