# 第 20 课：客户背景准备

知己知彼百战不殆

# 1、客户的十大痛点是什么？

为什么客户会选择跟你购买产品？为什么会选择跟你合作？原因就是因为客户现在有问题需要解决，也就是说客户有痛点，而你的产品就是能够解决客户的痛点。

很多人面对客户说很多话，可是都打动不了客户，话说不到点子上，因为他根本就不了解客户的痛点。

![](bbox=[0.13, 0.49, 0.85, 0.61])

一诺老师经常教导我们：一定要找到客户的十大痛点！比如一诺老师经常跟一些企业家聊着聊着，他就想请一诺老师去做内训，因为一诺老师非常了解企业的痛点是什么。

比如有很多企业痛点是一——产品不好卖！不会营销策划！招不到人才！人才流失！销售团队没有业绩！员工上班没激情没状态！团队互相信任！
