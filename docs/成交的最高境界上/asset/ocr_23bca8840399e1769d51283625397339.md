# 第62课：第五阶段·衡量价值3

# 找到客户购买的价值观

每个人都有认为重要的价值观，对于客户也是一样，每个 客户也有购买产品的价值观：

![](bbox=[0.15, 0.33, 0.89, 0.47])

每一个客户在购买一件产品的时候，他在心里面对一件产 品、一笔生意也会有一个价值的衡量。

有的客户他的内心有很多的需求，那客户的这些需求可能 我们没有办法完全满足他，所以我们要找到客户对他最重要的 需求是什么，排列优先顺序，找到客户购买的价值观。

客户购买的价值观就是——客户最重视一件产品的哪方面！

比如买一台汽车，有人最重视品牌，有人最重视价格，有 人最重视操控，有人最重视油耗。

比如买一套房子，有人最重视楼层，有人最重视格局，有 人最重视价格，有人最重视环境。
