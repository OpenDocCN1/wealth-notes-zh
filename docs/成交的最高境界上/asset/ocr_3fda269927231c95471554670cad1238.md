# 正面思考客户抗拒

很多人就是在这一阶段常常遇到客户的抗拒，而没有办法去化解，导致很多人失去信心，甚至放弃自己的事业，这是很可惜的事情。

为什么会这样？

因为很多人根本就不了解这个观念，他整反了，他以为客户拒绝他，就等于他做得很失败，他的头脑联想出了问题，思考的方向错了。

![](bbox=[0.14, 0.53, 0.88, 0.67])

在《改变命运》课程里面一诺老师会讲到，影响一个人做决定的因素其中最重要的一个关键，那就是——思考。

什么是思考？

思考就是自问自答的过程。
