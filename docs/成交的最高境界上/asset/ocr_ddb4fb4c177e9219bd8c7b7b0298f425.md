# 第 24 课：借用资源

开发客户的上策

一诺老师研究发现，开发客户最快速、最省时间的方法就是——借用资源！就是别人已经有的资源你直接借用它！

你不需要再花时间和精力去寻找，如果你是老板，你想快速地建立销售渠道最快的方法就是借用。
