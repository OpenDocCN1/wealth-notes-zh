# 亂七八槽的技術圖，
鎖定移動平均線！

提高勝率的最大武器是移動平均線

看過大量的技術圖後，你會發現有些圖表看了之後也不知如何預測、看不出未來趨勢，例如你以為會急漲卻暴跌、陽線與陰線交互出現，像匹瘋馬一樣的圖表。

但即使是這種瘋馬般的技術圖，只要使用某項工具就能制伏。這個工具就是移動平均線。移動平均是是提高交易勝率的必備工具，非常重要。只要用得上手，就不怕遇到盤勢不穩的時候。

相場式股票交易法，使用的是五日、二十日、六十日、一百日及三百日這五條均線（我用的看盤軟體是Ranollin.Ce公司的「Chart Gallery」）。五日和二十日均線是當中很重要的工具。

讓我來稍微說明一下移動平均線。移動平均線是將一定期間內的股價相加並加以平均，得出一個平均值後，再將其連接而取得的平均線。例如，五日移動平均線就是將前四天和當天的收盤價總和除以五」而得到的平均值。移動平均線是顯示一定期間內股價變動方式的圖表。這個工具可以讓我們從高處俯瞰整個行情，了解方向。因此看技術圖時，請一定要看移動平均線。
