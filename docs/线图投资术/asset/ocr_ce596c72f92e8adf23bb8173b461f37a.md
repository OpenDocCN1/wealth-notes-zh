# 不看基本面！

看技術圖就夠了！所有訊息都在上面

各位應該都聽過「基本面」（Fundamental）這個詞彙吧。

它也被翻譯成「經濟的基本條件」等，是顯示國家或企業經濟狀況的指標。以國家來看，可指經濟成長率、物價上漲率、失業率；就企業而言則是業績、負債、資產等。企業的代表性基本面指數包括本益比（PBR，Price-Earnings Ratio）、股價淨值比（PB，Price-Book Ratio）、股東權益報酬率（ROE，Return on Equity）。

很多股票的專業書籍都會告訴讀者，利

用基本面來尋找值得投資的個股。

例如，選擇本益比或股價淨值比較低的低基期股票，或者股東權益報酬率一〇％以上的個股。

然而，相場式投資法並非如此。

我不關注基本面！

我只看技術圖！

如果你有時間學習基本面知識，那就請將時間花在分析技術圖上。

為什麼我會這麼說呢？因為只要看技術圖上的價格變化，就能預測未來股價的上下震盪。
