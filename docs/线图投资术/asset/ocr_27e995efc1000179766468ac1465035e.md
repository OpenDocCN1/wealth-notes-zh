# 星野

中小型IT企業的員工。25歲。女朋友年紀比他大，由於女朋友講究排場，也認為男朋友付錢是應該的，因此星野常常約會基金無知。由於想要增加額外收入，因此拜黑須為師。綽號「阿星」。

# 黃金黑須

孤高的股市職人。20歲就開始投資股票，35年來連戰連勝。可運用資產高達數百亿日圓。經典語錄有「股票靠技術」、「沒有勤學就無以致富」、「K線是煩惱的集合體」等。

# 泡泡

居酒屋「煩惱」的兼職員工。22歲。雖然看起來態度輕浮，但不時會說出中肯的話。在店裡一邊工作一邊聽黑須教學，並進入股票市場。個性大膽，有時候甚至會All in。

# 大膽

手藝極佳的廚師，經營一家位於巷弄裡的小居酒屋「煩惱」。與黑須是同輩。由於「放空」股票，所以散盡財產且婚姻破裂。然而，在黑須的建議下，宛如不死鳥般浴火重生。

# 凱倫

個性與名字相反，性格強勢，是與星野同公司的前輩。股市經歷10年。有穩定的股票獲利，夢想是將來能夠買下大樓頂樓。然而，現實是殘酷的。
