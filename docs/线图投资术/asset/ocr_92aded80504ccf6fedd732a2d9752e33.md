# K棒透露超多訊息！
K棒是技術圖的基準

我在前面說過，股票交易「只要看技術圖」就夠了。目前有各種技術圖，包括由K線和成交量組成的「等量圖」（Equi-volume）、以線型呈現收盤價變化的「線形圖」（Line Chart）等，但我們最應該看的是K線圖。

我將在這堂課介紹如何解讀K線圖。
K線圖是呈現股價在某段期間變化的技術圖，據說起源於日本江戶時代。

顯示一天股價變化的K線稱為「日K線」、顯示一周變化的稱為「周K線」、顯示一個月的則叫做「月K線」。

另外，搭配左頁的圖會就更容易懂了，K棒由實體和影線組成。實體記錄「開盤價」和「收盤價」，K棒分為兩種，分別為以白色（台灣多以紅色）表示的陽線和以黑色表示的陰線。陽線表示股價之收盤價高於開盤價，陰線則相反，表示收盤價低於開盤價。

以日K線來講，當日第一筆成交價格為開盤價，最後一筆成家價格則為收盤價。
因此，只要看是陰線或陽線，就能立刻知道股價在某個期間是下跌或上漲。影線分為上影線和下影線，上影線表示股價在某個期間的最高價，下影線則是最低價。
