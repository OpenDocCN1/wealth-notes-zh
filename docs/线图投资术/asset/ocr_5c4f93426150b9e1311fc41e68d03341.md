# 股價變動不驚的祕籍圖，只看移動平均線就夠

在第八十一頁的漫畫中，也介紹過下面這張股價劇烈波動的圖表；陰線、陽線交互出現，很難預測未來會漲還是跌。像這種情形的話，就不要看K線，只看五日和二十日移動平均線就好。

股價沿著移動平均線下降（如果只看K線的話，股價來到新低後，又出現陽線）。你以為之後會轉為上升趨勢，但碰到五日線和二十日線後，又繼續下跌。而當你覺得會繼續創下波段低點時，五日線卻向上勾起，最後碰到二十日線又再度下跌。

這要怎麼辦呢？其實，劇烈變動的K棒只要整理成移動平均線，就會非常容易判讀。從移動平均線就能看出是多頭還是空頭。
