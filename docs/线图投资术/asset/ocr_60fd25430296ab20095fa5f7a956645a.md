# 找出「鳥嘴」出現前的訊號，開始布局

〔半身〕、〔反半身〕是K棒形狀，這裡我將說明如何用移動平均線的形狀判斷買賣訊號。這個訊號的名稱其實也別具一格，讓大家看了就懂。

那就是「鳥嘴」和「反鳥嘴」。鳥嘴由五日移動平均線和二十日移動平均線組成。出現鳥嘴形狀後，趨勢很容易翻轉。

首先是「鳥嘴」，原本位於下方的五日线勁揚，突碰上昇中的二十日线，形成像鳥嘴一樣的銳角形狀。由於五日線由下往上突破向上升的二十日線，所以是強勢的上升趨勢。由於是從低檔反轉上揚的起漲階段，所以「買進」的話可以有相當好的獲利。與之相反的是「反鳥嘴」（下一頁）。原本在上方的五日线，摃破向下降的二十日线，形成反鳥嘴的形狀，即為強勢的轉弱趨勢。在這個部位應該「賣出」。
