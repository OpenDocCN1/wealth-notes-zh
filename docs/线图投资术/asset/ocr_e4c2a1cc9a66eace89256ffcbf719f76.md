# 重點是市值超過二千億的股票

由於市值是公司股票發行總股數乘以股價，所以說代表著企業的價值。豐田汽車（TOYOTA）、NTT、軟銀（Softbank）、三菱UFJ銀行、NTT DOCOMO、KDDI等，都是市值前幾名的個股。

成交交易量這個數字所顯示的，是股票買賣成交的交易量，因此每天的成交量都不同。成交量經常名列前茅的個股，包括日本瑞穗金融集團、日產汽車（NISSAN）、雅虎（Yahoo）、索尼（Sony）及豐田汽車等。

我在Mission 4中說過，要大量看技術圖，累積練習的經驗。然而，到處都有個股的技術圖，東證一部、二部、JASDAQ、東證創業板MOTHERS等，東京證券交易所的上市企業總計約有三千六百家公司。究竟該從中選出哪些個股來看技術圖？很令人疑惑吧。選擇你有興趣的個股就好……錯了，我不會那麼說。選擇個股是有標準的。那就是「市值達三千億日圓以上、一天的成交量超過五十萬股」。
