# 邊說故事邊學技術圖！


> 股價並非是隨機亂跳


接下來我要介紹如何預測股價變化的技巧。一看技術圖，每個人都看得出來股價反覆上下變化吧。任何個股都不可能一直漲或一直跌，一定會碰到頂部和底部，重複上漲和下跌。


有人說股價遵循「隨機漫步理論」(Random Walk)，這個理論認為我們完全無法預測股價變化，因此隔天上漲和下跌機率各占二分之一。


然而，絕對沒有這回事。技術圖具備再現性，股價的變化是可預測的。因此，我才


能成為股市的常勝軍。


那麼，該怎麼預測呢？第一步就是養成看圖說故事的習慣。


> 光看圖漫開。要怎麼考察下來的發展


讓我來解釋說故事是什麼意思吧。我使用的技術圖，所呈現的是K線和移動平均線。K線包括日K線、周K線及月K線，這些全都要看。移動平均線請設定為五日、二十日、六十日。通常看盤軟體會預設為五日、二十五日、七十五日，因此請手動變更設定。
