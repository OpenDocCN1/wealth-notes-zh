# 出現健康的「下半身」就是買進的時機！

「下半身」的訊號是上冊認識

大家都聽過「黃金交叉」、「死亡交叉」等作爲買賣基準的訊號吧。黃金交叉是短期的移動平均線從下方突破長期的均線，視爲「上漲訊號」。反過來，死亡交叉是短期的移動平均線從上方擴破長期的均線，視爲「下跌訊號」。

而我接下來要講解的，是超！簡單好記且可以掌握股價趨勢變化起點的超！獨門訊號。我用了兩個「超！」，對吧？因爲這真的是很獨創的訊號，你一旦記住就不會忘記名字了。

這個訊號的名字就是——「下半身」訊號！

……如何？你是不是聯想到什麼下流的畫面？沒關係。股價的變化真的就是你想的那樣。

讓我開始說明吧。

「下半身」是指用日線來移動平均線趨勢，再看週、月線移動均線，當週、月線出現下彎的趨勢時，出現這個形狀後，趨勢就會改變。這個訊號也可以應用在日K線、周K線。

當五日線五線均線向下彎折時，看K線實體有一片一片的，就是「下半身」成形。建議「下引」訊號。
