# 透過均線和二十日均線排列的「高中生時期」

我在第三章中利用「分手」、「N大」等技巧，說明了移動平均線的方向和排列方式非常重要。無論是上升趨勢或下跌趨勢，五日線與二十日線呈現漂亮的並排狀態很重要。

也就是說，兩條線同時往上或往下走的狀態，這表示兩條線想法一致，處於相親相愛的狀態。我將之命名為「高中生時期」。陷入熱戀後便不可自拔，能夠維持上漲走勢或下跌走勢。

由於突破轉折點或「前波高點、低點」後，能維持原本的走勢，因此可說是青春時期獨有的強勁趨勢。在這樣的狀態下，什麼時候買或賣都能獲利。若能及早上車，更可能有很高的獲利。

![](img/877145d338f92fa7bf65ebb12eb982aa_164_0.png)

若想在「高中生時期」的起漲點、起跌點就上車，就要觀察「下半身」的出現和移動平均線的排列方式（若是上升走勢，則五日線在二十日線上方，若是下跌走勢則相反）預測行情、監視個股表現。做好萬全準備，當行情如自己所料時，就能立刻買進或賣出。因此每天都要觀察技術圖，培養敏銳的感覺。

# 偷看技術圖未來走向

在實戰中投入銀彈之前，先「讀取」

我一直告訴你們觀察技術圖有多重要，並且介紹了各種可以預測股價變化的訊息。大家一定都躍躍欲試，很想進入實戰吧。

先等一下！

進入實戰前，還有一件事要做！那就是練習看技術圖。我稱之為「讀取」。

> 「讀取技術圖」是指觀察K棒和移動平均線變化，預測隔天或後天的走勢。檢視分手、下半身、烏嘴、ND……等訊號，並預測股價之後的走勢。看技術圖時，先用紙遮蔽右邊的圖，等自己預測好之後，再把紙往右滑，看真實的走勢。這要反覆練習幾次才夠。

預測失準時，就是你的機會！因為這樣你才能知道「自己的弱點」。

了解自己的弱點、進行「修正」。請根據移動平均線和K棒變化，思考股價為什麼會這樣走。練習過幾千遍後，你就會有感自己的「弱點」變少了。
