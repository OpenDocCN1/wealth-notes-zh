# 暗準股價下跌後的「分手」點



「分手」也是讓人輕鬆賺錢的訊號。兩條移動平均線越來越接近，但沒有真的碰到又慢慢分開，是令人感到淡淡哀愁的走法。利用這個訊號，初學者也能確實獲利。那麼，讓我來說明一下「分手」訊號。這個訊號分為兩種形狀。

+   ① 五日線位於二十日线之上的上升趨勢

原本與往上彎的二十日线並列的五日線，下跌至接近二十日线的位置，但沒有碰到二十日线，又分開繼續爬升的形狀。

+   ② 二十日线位于五日線之上的下跌趨勢

原本與下彎的二十日线並列的五日線，上漲至接近二十日线的位置，但没有到到二十日线，又分開繼續走跌的形狀。

在①的情形中，五日線沒有碰到二十日线，繼續爬升的話，代表上升趨勢不變。因此可以在漲的時候買進。即使K棒在五日線之下，只要形成「分手」形狀，就可以買進。上升趨勢不變，即使股價下跌，只要確認形成分手形狀，就能利用「下半身」和「七日法則」抱牢至大跌之前，增加獲利。
