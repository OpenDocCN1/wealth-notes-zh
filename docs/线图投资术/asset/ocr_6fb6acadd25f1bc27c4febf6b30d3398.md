# 挑戰實戰技術圖前，
先學會二個技巧

![](bbox=[0.65, 0.15, 0.7, 0.21])

我在第三章中講解了多種股票投資的買賣「武器」。所謂的武器，就好比是廚師工作時不可或缺的工具菜刀。因此，為了成為股票職人，所有的技巧都是必備的，沒有任何一項是多餘的。

然而，想要學會所有的技巧，因應局勢運用個別技巧或搭配使用各種技巧以克服難關等等，就現階段來講，還有一大段路要走。

只要練習再練習就能做到……不，一定可以做到！

那麼，以目前的程度，也就是與星野差不多的程度而言，只要先熟悉一種技巧，在適當時機利用這個技巧進行交易即可。

![](bbox=[0.5, 0.51, 0.55, 0.81])
