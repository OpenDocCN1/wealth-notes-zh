# 搭配日K棒和周K棒，
提升預測精準度！

![](bbox=[0.6, 0.15, 0.68, 0.22])

「七日法則」其實也可以運用在周K棒上。以周K線來講，無論上漲或下跌，七周就會止穩。上漲或下跌行情，都會碰到頂點或底部。連續出現四根陽線或陰線，代表股價短線上將觸頂或探底。連續出現四根陽線或陰線後，就能預測從隔周開始，短期的上漲趨勢將翻黑，或下跌趨勢將翻紅。

用周K線來看，就可以預測隔周的日K線吧。嘿嘿。

![](bbox=[0.22, 0.15, 0.42, 0.22])

是的。例如，日K線呈現出上漲趨勢，但股價低於昨天的話，若您知道這個下跌只是暫時的情況，或者是下跌趨勢的前兆，就可以用周K線來判斷。

若周K線短線上位於頂部，就要小心下跌。若還在上升第二周，可以判斷是上漲過程中的回測而已。
