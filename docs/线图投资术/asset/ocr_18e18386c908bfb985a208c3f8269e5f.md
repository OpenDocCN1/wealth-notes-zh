# 移動平均線的PPP和反PPP，是股市行情大好的預兆

我是在看Business Trip%特技飛行隊的表

演時，想到PPP這個名字。五架戰鬥機並列飛行，飛機雲在空中留下鮮明的軌跡。

這樣的景象讓我想到五條均線畫出漂亮上升趨勢的情形，腦中響起嘹亮的號角聲「PAN-PAKAPAN」。

另一方面，反PPP是指五條移動平均線皆向下的下降趨勢。

另外，雖然股價會漲跌互見，但從反PPP轉換成PPP時，幾乎可以確定將有一波大行情。

反PPP若要轉換為PPP，五條均線必須糾結在同一個位置。如果你從技術圖看到這種線型的個股，絕對要列入觀察。

PPP是PAN-PAKAPAN的省略。這到底是什麼意思？不懂也是理所當然，這是我自創的相場式詞彙。只要看過解釋，就不會忘記這個單字。

PPP是指五百、二十日、六十日、一百日及三百日的移動平均線全部向上，且K線站上均線，也就是上升趨勢。移動平均線之間保有適當距離、上升角度陡而非平緩的話，可說是最漂亮的PPP。

為什麼我會取這個名字？讓我來為你解答。
