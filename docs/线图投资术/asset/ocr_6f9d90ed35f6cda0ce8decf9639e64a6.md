# 不用靠學歷和Sense，好好「練習」就能懂股票

透過練習。數億圓圓的餐廳就會呈現在「看、讀技術圖」，這就是練習。重點在於「大量練習」，也就是看很多很多的技術圖。我最近經常還看「JPX日經400指數」（以下稱為JPX400）的成分股。
「JPX400」是從約三千四百家上市公司中，選出較能吸引投資人的四百家公司，並轉換為指數。這是自二〇一四年起推出的股價指數，其中也包含新興企業，如果我就能往前追溯的股票，我都會追溯過去三十年的技術圖一起看。

簡單來算，「四百檔成分股×三十年」等於「一萬兩千份」。看了這麼多技術圖，就能看出該檔股的股價變化有一定的規律——意思是，我們會了解到「現在的走勢與過去的走勢類似」、「即將上揚」、「即將下跌」、「這裡漲一點之後，馬上就會回

檔」、「應該會連續盤整幾個月」、「到頭部」等。
我現在也是這樣，無論睡覺或醒著，都在觀察技術圖、研究股價走勢。
我還真是股票技術圖的「變態」（笑）。不過，正因為我對技術圖如此著迷，才能成就今天的我。
透過練習、練習、練習、再練習·····反覆鍛鍊，成為變態！
我把希望大專觀察的個股條件列在第六十四頁，例如日經平均指數也是不錯的選擇。將十年份的技術圖看十遍並思考，就能產生全新的觀點。看第二遍的時候，可以注意到第一次看的時候沒留意的部分，第三次又能發現新的不同，累積越來越多的新發現。
到了第十遍，你就應該能察覺到個股股價走法的定律。這是值得慶祝的事，表示你離學會技術更邁進一步。
