# 想「赢钱」就跟我练！

相場式交易的目的是利用信用交易（向證券公司借錢或借股票來買賣股票的資方法），進行「做多」、「放空」的「多空雙向操作」，無論上漲趨勢或下跌趨勢，任何靈勢都能賺錢的投資法。為達此目的，必須具備能自由操作「放空」、「做多」的「多空雙作」高度技術。

我將之稱為「部位操作」，在學會這個技術、正式上場前，請先確實吸收本書所教導的技術，鍛鍊技術，讓自己可以透過「買進」或「賣出」賺到錢。

![](bbox=[0.12, 0.41, 0.84, 0.5])

本書主要利用日K線來判斷「買進」或「賣出」的訊號。在日K線所學的訊號，也可以用在周K線和月K線上。日K線的買進訊號，在周K線和月K線看來也是買進訊號。

也就是說，本書所教的技巧，不只能用日K線來做短線交易，也可以選用周K線、月K線來進行一個月、兩個月……甚至半年以上的長期投資。

首先，請切實解本書的內容，反覆練習。等學會技術後，再努力更上一層樓。
