# 「練習」比正式上場重要！

就像職人們學習技術一樣，股東投資必須靠練習和鍛鍊。

以壽司職人為例，剛拜師學藝的菜鳥，不可能馬上有能力在客人面前捏壽司吧。通常新人必須從洗碗、進貨等繁瑣的工作做起，不斷練習捏壽司，有朝一日才能站在客人面前。不只是職人的世界，運動領域也是如此，高中棒球隊每天反覆訓練才得以站上甲子園的球場。

因此，沒入現金前，必須不斷練習以學會技能。然而，現實是——幾乎很少書籍會教讀者練習的方法。因此，本書要從練習開始講起。

學會技術，人人都能賺到錢

「能在股市賺到一億日圓的人一定是天才，不然就是超級聰明，具備特殊判斷能力吧？」

你是否有這種想法呢？應該也會有人一邊操作股票，一邊自嘲地想「股票怎麼可能賺錢。只會賠錢」。

這完全是誤會，絕對沒有這種事。股票投資不需要學歷或特殊的判斷能力，在股票的世界裡，只要學會閱讀技術圖、預測走勢的「技術」、「技能」，任何人都可以賺到錢。不過，「學習」可不是一件容易的事。
