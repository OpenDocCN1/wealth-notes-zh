# 星野

那就是形成PPP（PANPANPAN）的時候。反下半身則是反PPP的時候。伴隨分手訊號出現的下半身或反下半身，無論是上升趨勢或下跌趨勢，都代表該趨勢相當強。

在上升趨勢中，伴隨分手訊號出現下半身時應該「買進」，在下跌趨勢中，伴隨分手訊號出現反下半身則應該「賣出」。
