# 卦意小解

姤讲不期而遇，有“遇”就有“聚”，“聚”则是萃卦讨论的一个重点。

萃不是简单的聚集，而是强调凝聚，能凝聚力量，就能办大事。萃卦是说你

怎么把聚集的那些力量凝聚起来办大事。

要汇聚力量、凝聚人心就要做事符合正义，做人要真诚。要想支配这些

力量，首先就得要能够控制、引导这些力量，这就得保持诚信。有了诚信做

基础，还要会在大方向上引导力量，这时候就要符合正义，以德服人。
