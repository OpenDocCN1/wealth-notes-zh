# 卦意小解

临在盎之后，祛除了盎祸之后，事业将会上升到一个更高的阶段。这时候君临天下的气魄开始出现了，要当领导了，就是临了。临卦主要在讲领导的艺术与驾驭的方法。

临强调上下的感知与共鸣，临卦说当领导就要让下属产生自然感应的共鸣，群众们响应你，你的领导根基就很稳固。要让群众响应，就要恰当地发挥领导艺术，把握好事态的发展变化。
