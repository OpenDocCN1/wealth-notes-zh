# 卦意小解

解决问题一定会有损失，损卦着重说怎么面对损失这个问题。损失已经发生了，就要保持“去者不追”的宽宏，还斤斤计较的话，不仅干事无补还
会惹人厌烦，反而扩大损失的范围。

损卦还强调一点，当损则损。有些损失是一定要发生的，这时候就不要
小气，要通过这些损失追求更多的益处。在并购中，企业怀着谨慎的心态做事，
即使有一些损失，最终的结果仍将获得大利益。
