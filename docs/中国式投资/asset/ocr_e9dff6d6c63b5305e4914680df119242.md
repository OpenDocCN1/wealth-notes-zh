# 卦意小解

解是解除，在� zorgt 后，就是对困难的解除，解卦象征着纾解困难。

怎么解除困难？整个解卦的原则就一句话，“无事静，有事动”。“无事静”是说形势不明朗的时候，你要观望，一边听风声，一边除内患。“有事动”则是在困难的苗头露出来的时候，就及早行动，不要拖延。在解决困难的时候要注意团结合作，尽可能多地争取“君子”做盟友，以对抗“小人”。
