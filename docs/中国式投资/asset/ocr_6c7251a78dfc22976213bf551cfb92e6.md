# 卦意小解

恒、遁接下来就是大壮。大壮就是大强盛。能进退自若、收放自如，就一定很强盛。强大之后要注意什么？这是大壮关注的核心。

这个时候的一个关键是谨慎。鼎盛之后最害怕的事，就是不谨慎。《易经》一直提醒我们环境是不断变化的，要看得到变化。你强壮了、上了一个台阶，竞争者的段位跟着也就高了，想抱你大腿、占你便宜的就更多了，这时稍微放松一下或者自大一下，原来的成功经验可能就完全派不上用场。
