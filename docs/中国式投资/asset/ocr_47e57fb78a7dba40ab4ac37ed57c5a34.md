# 卦意小解

有了共鸣还不够，还要能把这种共鸣长久地维持下来。恒卦专门讲怎么长久维持一段关系。

要长久，就要走正道。只有走正道，和谐的关系才能长久。走正道的核心是恪守本分。你在这一段关系中的角色是什么？与这个角色相匹配的行为是什么？这就是你的本分，恰当地扮演好自己的角色，才能保持关系的长久。
