# 卦意小解

随在豫之后，因为豫是快乐，如果能与人同乐，众人就会跟随。随卦讲的是怎么跟随别人的问题。

随其实是在说依附的艺术，要亨通发达就要用正确的方式依附对的人。随卦这里有个警示，就是：万不可过河拆桥。如果你依附别人起来，那么就不能在自己强大以后损害别人，这样会让自己陷入凶境。
