未来像卖电器一样卖房子 当房价在上升期,大家考虑的只是哪里的房子增值快,保值.所以位置,稀缺更重要的.当房价下跌趋势形成,失去投资属性回归居住属性,人们开始关注房子格局户型,朝向,电梯等居住舒适因素.特别是新一代设计理念的更新,以及智慧交通,智慧城市的发展,将加速推动存量房的贬值.房子可能变得便宜,成为消费品.每隔20年或30年要更换和重装修,以提高生活品质.那时候的思考角度是：
- 房子的寿命大概50年,二三十年的房子很破了,半价卖或买个二手的,都很划算
- 以后的房子装修更注重舒适,用料,舒适而不是个性,必然多个公版进行选择,类型也偏简约风.家装公司批量作业,专用工具半自动化,薄利多销.材料受益于工业化和科技进步,既环保又舒适,又便宜.
- 受益于批量公版半自动装修,装修费不高于10万
- 家庭唯一住房不交房地产税
- 常规房子为150平米,房价不超150万,半价还能卖70万,合计使用费用:90万.30年折合3万每年
- 10年后家庭平均年收入超20万.15%的住房成本是合适的
- 低收入家庭,可以70万买入二手房,10万装修,30年后20万卖开发商,合计使用成本60万折合2万每年
- 开发商20万买入,开发成本30万,资金利息10万,运营成本10万,合计70万.卖150万.毛利80万,税费30万,净利50万
- 以上像卖电器一样卖房子可以成为常态
