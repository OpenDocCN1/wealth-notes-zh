# 特别放送 | 关于“智商”那些事

万维钢

咱们们课经常提到“智商”、“智慧”、“聪明”，今天就来帮你做个总结。辨析清楚“智商”这个概念，或许能帮你成为一个聪明人，或者帮你辨别出身边的聪明人。

1. “智商”，是一个人的认知能力。比如说逻辑推理、模式识别、短期记忆力这些与积累了多少知识关系不大的，但是能反映大脑的运算水平的能力。

# 关于“智商”那些事

智商跟智慧不一样。智商主要与人人的差异，而智慧是可以学的。

智商，都需要什么能力？你得对周围环境非常敏感，能从一个更大的视野中观察到问题；你得有灵活性，能同时考虑生死不同方面的现状；你懂得自知之明，承认自己的认识是有限的，这个能具体地看事情的分析能力，对个人生活环境来讲，比智商更有用。

2. 心理学家已经做了无数的研究，早就是达成了共识，存在一个“一般的因素”，直接决定每个人在所有领域的表现。这个“一般的因素”，心理学家称之为“g-因子（g-factor）”。用智力测验的方法可以测量每个人的g-因子，这就是智商。
