# 为什么会衰老？

+   1. 衰老是因为细胞端粒会逐渐变短了。
2. 端粒越短人体越容易生病，而且人的细胞复制次数有限，每复制一次，端粒就会缩短一点；
3. 细胞端粒的缩短还与某些可能让人衰老的因素有关，会不断缩短。
4. 需要达到活性状态，尽量避免增加额外寿命。

# 压力

减压方程式：
想得“宽”一点
想得“远”一点
用第三人称称呼自己
从远处观看

+   1. 压力会使大脑新陈代谢——是对“威胁对应区”的反应。
2. 细胞反映，并不是我们的反应——是对“对立反应区”的反应。
3. 细胞反应光速中，心跳加快，肌肉中会收缩。
4. 面对压力时人的情绪会更强烈，甚至对陌生和相似的事情比平时。
