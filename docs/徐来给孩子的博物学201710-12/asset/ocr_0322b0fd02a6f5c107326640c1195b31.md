# 一座出过很多数学家的城市

这个故事发生在一个叫柯尼斯堡的地方。你知道这个地方吗？现在，这个城市开始衰落，它可能是一个废墟。可是，它出现在我们面前，准确地说，它是俄罗斯的领土。柯尼斯堡，是一个德国城市。1657年，这里建了一所大学——柯尼斯堡大学，它培养过一批非常出名的数学家。

最早生活在这里的人，叫普鲁士人，这是一个很古老的民族，大概在2000年前，我们就已经生活在大陆了。后来，普鲁士人为建起了这座城堡，并且以此为名，形成了后来的城市，形成了今天的柯尼斯堡。

这里，还来了一群非常能打的人，你听到的名字就叫，条顿骑士团。骑士团是13世纪时基督教国家的武装组织，他们拿着十字架，去打仗，去征服。他们非常厉害，他们打下来的土地，从波罗的海一直到了俄罗斯。可是，这个组织非常庞大，到后来，它变成了一个独立的国家，叫做条顿骑士国。这个国家，和周围的普鲁士公爵国，以及更远的波兰，关系非常紧张。最后，条顿骑士国输掉了战争，把大片土地让给了波兰。

又过了很多年，条顿骑士团的一位总团长，把条顿骑士国的领地改编为一个国家，国名叫普鲁士。这是最早的普鲁士，后来，这个普鲁士开始发展壮大，最后，成为了一个大国。它一直想向东发展，但是俄罗斯人总是挡着它。它想向西发展，又是法、国，又是英国，又是波兰，它很难。普鲁士人，是德意志人的一支，他们的目标很明确，就是要强大。

这是一个古老的城市，肯定出过很多伟大的数学家。比如出了著名的柯尼斯堡四大学数学家的欧拉。还有一位，叫康托尔，他是最早研究无穷集合的人。再有一位，叫庞加莱，他是研究拓扑学的大师。还有，希尔伯特，提出了著名的23个数学难题。你看，这里就是个大仓库。

# 连欧拉都解不开的问题

欧拉是18世纪最伟大的数学家之一，在他活着的时候，就已经被当时的学者们推崇了，因为研究太太阳了，他几乎把数学都推翻了。可是，在很长的一段时间里，他都没有发表论文。实际上，他发表了一些有差不多一半的内容，自己也没有写出来过稿子。

当他还没有发火的时候，曾经到过柯尼斯堡。在这里，他发现了一个很有意思的问题。

原来，有一条河流穿过了柯尼斯堡城，把城市分成两个区域，河流中有两个岛，岛和河堤上有7座桥，人们就想知道，能不能不重复地走过所有的桥。这个问题，后来就被叫做“柯尼斯堡七桥问题”。

![](bbox=[0.1, 0.87, 0.9, 0.92])

人们尝试了所有的方法，可是都没有找到答案。后来，欧拉就来了。他并没有直接画图来解决问题，而是把这个问题抽象化，变成了数学问题。这就是著名的“欧拉公式”。

欧拉在这一点非常领先。在当时，很少有人能思考这么抽象的问题。他把七桥问题抽象成了一个图的点，和线，构成了一个网络，这就是图论的开端。
