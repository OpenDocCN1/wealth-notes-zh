# 有列的动物像人类一样换牙吗?

![](bbox=[0.05, 0.39, 0.85, 0.53])

首先说说人类的换牙。人类的换牙, 其实有两种情况:

一种是乳(门)齿是大部分, 牙齿, 从门齿到臼齿, 臼齿也就是最后面的, 前端也就是靠近牙齿前面的牙齿。在, 我们的成长过程中, 它们会慢慢消失, 掉落的乳, 是乳门齿, 长出来的, 叫恒齿, 恒齿是终生的, 这些牙齿被称为再长出一会长出米两次的牙齿。

另一种情况是, 我们嘴里最靠后的牙齿, 它们是不换的。

在哺乳动物中, 很多都和咱们人类一样, 会有这种再次萌发的现象。也有人一些哺乳动物, 有类似的, 它们就不会换牙, 一旦长出来就不掉了, 和其他脊椎动物, 像鱼类、爬行类中, 而多长出来的牙齿会不断长出来, 长出来之后, 就会脱落掉落, 总之, 就是长不断, 掉不断。比如, 鲨鱼, 鳄鱼就是这种类型, 这种类型被称为多牙, 就是能反复生长出牙齿。

# 听说南极很冷, 零下50 ~ 80摄氏度, 但北极冷也不过零下30 ~ 40摄氏度。为什么北极和南极不是一样的冷?

![](bbox=[0.05, 0.82, 0.85, 0.92])

两极当然不会一样冷, 原因有很多, 但最关键的原因在于, 北极是一片海洋, 而南极则是一整块陆地, 水是一个非神奇的东西, 它的比热容很大。比热容是一个物理量, 它表示的是, 物体加热或者散热的能力。比热容越大, 它吸收热和散热的能力越强。

在常见的物体当中, 水可以是比热容最大的, 在周围温度比较高的时候, 它吸收热量, 然后在, 周围温度比较低的时候, 放出热量。

所以, 相比陆地, 海洋温度要比不了陆的地方要稍微温暖一些。海洋还有一个特点, 就是流动。水是流动的, 周边海域, 会有一些更温暖的冷水, 而冰, 比较冷, 温度会相对暖一些, 这也正常。
