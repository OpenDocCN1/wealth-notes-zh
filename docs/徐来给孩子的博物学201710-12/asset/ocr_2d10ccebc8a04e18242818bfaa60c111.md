# 科学史·化学 | 气球里的“气”

徐米

你们平时一定玩儿过很多气球。不过这里我说的气球，可不是一般的随便往里面吹一下气，就能够起来的普通气球，而是面气之后，能在空气里面浮起来的那种气球。

前阵子，我和朋友做了个挺好玩儿的实验。把大大的、可以漂浮在空中的气球绑在一位小姐姐的身上，然后看，要绑多少个，才能让她这位小姐姐直接飞上天空。当时，我们在她身上绑的是填充了氦气的气球。这个氦气真的是特别有意思，今天我就来给你讲讲氦气，和氦气球。

# 什么是氦气？

你可能要问了，氦气球是啥？我没有听说过吧？只能当普通轻气球。这里的轻气球，是指比空气轻的气球。是的，你没有看错，空气也是无重量的。实际上，我们生活在地球上，无时无刻，都有厚重的一层空气压在我们身上，只不过我们都习惯了，所以感觉不出来有什么异样。

就好像我们会把比水轻的塑料块扔到水里，塑料块会浮起来一样；如果我把比水轻的气体填在气球里，气球也会向上浮。这样我们就得到了一个轻气球。

这种比空气轻的气球，有的，就是用氦气来填的。一注气，氦气。氦是最轻的一种元素。

还有一些可以飞起来的气球，是用氮气来做的。氮是第二轻的元素。

无论是氦气还是氮气，都比空气要轻，而且要做好多。所以，它们都能在空气中浮起来，又阻止上它往下坠的绳子，它就会不断往上飞，飞到看不见不看得见的地方。

不过，实际上真的能拿来填气气球的，只有氦气。氮气不适合拿来当气球玩儿的——这样说，就非常危险，因为氮气是一种非常容易燃烧的气体，如果用氮气充满了气气球，那么在空中只要一点点小火星，就可以引燃这个气球，很容易把人烧伤。

上世纪二十年代的时候，因为缺乏通用的气体，德国人曾经在大气船中填充氦气，并最终引发了一场严重的灾难。火灾——如果你有心想多了解一下的话，你们可以查一下“兴登堡号”事件，我文末也给你们贴了一点关于这件事的资料。

所以，玩气球的时候主要需要注意一下，要弄清楚气球里充的是什么气体。能避免购买填充了氦气的气球，即便购买，也务必让它远离火源。

# 什么是超流体？

虽然氦气是最轻的气体，但氦气有个特性是氦气不占的，那就是如果要气体变成液体，那么氦气所需的温度，要比氦气低出10多倍。实际上，液体氦是地球上所有物质中温度最低的。

也许你要问了，气体就是气体吗，怎么能变成液体呢？其实，无论是气体，还是液体，还是固体，说到底都是一个温度有多高的问题。

比如水，水在一般情况下是液体，如果天气很冷，水就变成了固体，如果温度再一点，比如烧水开了，水就变成了气体，一点点都飞上天去了。

其他物质也是这样，无论是氦气还是氮气，它们平时都是气体，但是如果温度低到一定程度，就会变成水一样的液体，温度再高一些，就会变成固体那样的固体。

因为液体的氦能保持非常非常的温度低，所以，有些需要在低温下才能做的实验，必须要用到液体的氦。

液体的氦，还有一个非常有意思的现象。

咱们一般的液体，比如水，当它和其他液体的表面接触的时候，会有一个玻璃那种表面往下垂的侧向，比如我们现在玻璃杯子里喝水，等杯子里的水面平稳了之后，你再从侧面去看，会发现，粘着杯壁的地方，水的位置比靠近杯子中心的地方要高。水好像被杯子的壁吸上去了一点儿。

这是因为，水本来就有被杯壁吸住往上走的一个倾向，但同时，水的内部，自己有摩擦力，又阻止它往上爬得更多。而液体的氦，情况就不怎么样了，沿着杯壁往上走的时候，只有往里走的摩擦力，没有往里拉的力。它没有往里拉的倾向，没有人工给它往上爬，就一直在爬，就会不停爬杯壁往上爬，一直爬到杯子的口上，然后翻过去。从杯子的另一侧漏下去——没有那个杯子能拦往液体。科学家管这种现象叫做“超流体”。

# 氦气到底有多珍贵？

在我们所处的这个宇宙里，氦是第二多的元素，仅次于氢。但很奇怪的是，地球上却很少有氦气。虽然氦气能在源里不断地向地球表面喷涌，但却几乎无法到达它的地球外部，因为地球没有强力的磁场，还有厚厚的空气，把它们阻挡在外面。

那地球上的氦哪里来的呢？

其实，地球上的氦是通过地球上一些物质在自然界中自然发生的一些反应而来的。这个过程可以反复做，但两句话说不清，总之，你只要记住，这种反应在地球上并不多，由此产生的氦，常常和天然气出在一起。所以，在开采天然气的时候，可以得到氦。这样得到的氦气，主要存放在美国。

——博物学家养成记——

现在，氦气的价格还算算便宜的，所以我们能比较容易得到氦气。制作成气球，或者其它东西，拿来玩儿，但是，也有一些科学家担心，如果我们就这样玩儿氦气的话，氦气会这样存的时间，到地球上的氦气会消耗掉。这样一来，等科学家们做实验的时候，就没有氦气用啦。

当然，也有一些科学家认为，其实我们还有一些新的方法，可以用来得到氦气，所以在这方面，不用太过担心。
