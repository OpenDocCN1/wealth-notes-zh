徐来

前两天我在专栏里写了给心脏做手术的事。从一开始的科学家认为心脏修补法接受手术，到后来，给心脏移植手术变成可能，再到现在，为了解决心脏缺血供血的问题，医生们也发明了给人整体换心的技术以及体外循环的技术，心脏手术变成了越来越精确的治疗行为。

于是一个新加坡的心脏问题开始困扰医生们，那就是心脏要是不死，能不能换一个？当然，换心脏的事情已经有过成功了。当然，技术能够成功并不意味着器官捐献者就一定会出现，那么心脏这关键器官可以直接被替代吗？

答案是肯定的，能。有意思的是，和很多人想象的不一样，最早的心脏移植手术不是在欧洲，美国是世界上最早发起的地区亚洲，而是在非洲实现的。准确地说，南非医生克里斯蒂安巴纳德的贡献。这可能人类医学史上一个传奇，今天我来跟你讲巴纳德的故事。

# 农家出身的名医

你已经听过了很多科学探索的故事，这些故事的主人公往往在很小的时候，就显露出非正常的才会，或者的研究要求。和之前的主人公不同，咱们今天要说的这个故事可有点苦哈哈的。

他出生在南非的农区家庭，家里还贫穷，有好邻居不是个农民医生，毕业后去给他一个家庭医生做助手——国外的家庭医生有点像是咱们国家的社区医生，只能处理一些头疼脑热的毛病，心脏病诊断很罕见都没有机会见到。他觉得医学太穷，打算到通商为自己的方向，但是也没捐出什么大价钱。

可是，巴纳德的运气确实不错。他偶然地获得了一个去美国进修的机会一一而且，进修的那个学校又恰好是心脏外科技术最先进的地方。

在一个偶然的机会里，巴纳德进了一个正在进手心脏手术的手术室。因为手术台上缺人手，他当时加助手术。见识了这个领域之后，他决定要转到这个领域。不过，这个领域的难度确实非常大，在心脏外科学界，因为他的操作失误，在不到半年7岁的学生，没被安排手术。尽管他尽了最大，巴纳德还是尽了自己能做的学习这个方面的技术，并争取成功回国。

回到南非之后，他获得了领导的赏识，并且还当开参与建立起心外科实验室。此后，巴纳德的一生都和心脏手术联系在一起了。

# 成功的手术和误判

巴纳德的第一例成功手术并非心脏，而是肾的。而且，这个手术非常不成功，患者在手术之后活了23年之后。虽然这是巴纳德做的成功——倒得说是自己对此一直在非常谨慎——他很小心。但是世界上最好的肾移植率，因为他的患者术后23年的存活率是100%（这是他已开的效果）。

很快，机会来了。那是整整50年前的1967年12月初的一天，南非的开车发生了一起交通事故，一个25岁的是死，父亲同意将死者的心脏。一张家的心脏手术随即要开始。

虽然此前巴纳德曾经观察过对动物进行的心脏移植手术实验，并没有亲自实践，他对技术很有信心，认为足以付出手术本身。需要担心的是，器官进入另一个人的身体之后，并接收到的自体将外来物质视为入侵者，并且对它发起攻击。这的确是器官移植工作最大的麻烦。

真的到了做手术的时候，巴纳德发现一切并没有自己想象的那么容易。手术现场没有发生失误，他在操作中所受的严格训练起了很大的作用，最终是小心地化解了每一个问题，经历了整整一夜的奋战，世界上第一例心脏手术完成了。

然后，真正的考验现在开始。巴纳德想尽一切办法控制可能出现的排斥反应，病人的情况刚显良好，眼看着就可以出院了。

然而，到了第九天上，巴纳德发现出事了。当天，病人出现血点，巴纳德就安排了胸部X光片显示，病人的肺里有个阴影。巴纳德判断自己一直担心的排斥反应终于出现了。于是，他开始加大了抗排斥药用量，希望帮助患者战胜它，但患者还是死了。这让巴纳德想到的是，后来发现，排斥反应其实自己的误判，那个阴影是感染而已。

# 关节炎结束了巴纳德的职业生涯

尽管因为巴纳德的误判，患者在手术之后只活了18天，但它并不能抵消手术本身的成败。巴纳德因为做了世界上第一例心脏移植手术而震得大名。这一年他也有44岁。

其实，很多人尤其是美国的一些医生，对巴纳德的这个成功表示很有意见。完成当时的外科手术技术非常不济。因此这个手术本身并不是特别难的一件事，即便是对肾排斥反应的抑制，其实当时已经有很多医生提出了若干大家所做的只是勇气、机会以及法律政策上的支持而已。

但无论如何巴纳德执行了这手术。虽然患者只活了18天，但这并没有打击到他的信心。在接下来的几十年里，他陆续又为70多名患者施行了这类手术。不过，可能是因为他一直以来的相关的重要突破，与此同时，他一直以来的关节问题越来越严重，手指关节变得越来越不灵活，最终不得不开手术。

当然，其他医生也没有闲着，他们通过各种方式，也在心脏移植技术方面做出努力。1972年，世界上第一例心脏和肺的联合移植手术成功；1973年，医生发现了易导致排斥反应的抗体；1981年一种名叫环孢菌素的药物被用于心脏移植之后的排斥反应抑制。在一系列发展的背后，心脏移植术变得越来越普遍。

# 博物学家养成记

如今，全世界有记录的心脏移植手术已经超过10万次，在一些国家，心脏移植术看起来很难做的手术已经被视为常规手术而在这一过程的背后，是现代医学发展中一代代医生们的不断探索和努力。
