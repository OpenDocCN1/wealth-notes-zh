# 300万岁的人类祖母

说说到这里，你可能就疑惑了，凭什么这\n个非洲的露西就是“第一个人”？难道比\n咱们中国的炎帝、黄帝还要早吗？难道比\n北京直立人还要早吗？没错，真的比他们\n更早。

如果我们将炎黄二帝当做是实体的，\n那么他们大致的时间应该在四五千前，\n而北京的直立人呢，他们大致的生存在7\n0万年前，这个就要早好多多了。可是露西\n，她生活在300多万年前，这比你就知道\n更早。

说露西和我们非常相似，是“人类的\n祖母”，你还许的也是不是长得和咱们\n差不多。那其实并不是，其实露西和我们\n非常不同。首先，她非常非常矮——估计\n比你们都矮，因为她的骨盆只有1.3米，\n而她的个头，她的身高大约1米。而\n你，她个子非常小，可是脑子也非常小\n，脑子的容量是人类发现古人类中一个\n比较小的，大约375到440毫升，这\n比猿猴还要小。

不过，古人类学家发现，她的骨盆结构\n却和现代人的非常接近，这说明，她已\n经采取直立的姿势了。这一点非常关键\n，因为她直立行走的时间非常早，比大\n量古猿类直立的都要早。

# 露西为什么叫露西

露西是个上世纪的70年代被发现的。

当时，有一位法国科学家发现，埃塞俄比\n亚北部一个叫阿法州的地方，那里有一\n些非常古老的湖泊，他于是组织了一个\n考察队，和美国的古人类学家一起去探索\n这个区域。

当考察队差不多完成了工作，准备离开\n的时候，有一位考察队员忽然发现了一块\n小碎石，随后又在附近发现了几块大骨\n片。他们非常兴奋，立刻开始对这个地\n点进行了细致的挖掘。

他们最终发现了几十块骨骼碎片，这些\n碎片属于同一个体。经过比较研究和修\n复，最终确认了这是一位300万年前生\n活的古人类祖先，脑容量不大，但已经\n直立行走。
