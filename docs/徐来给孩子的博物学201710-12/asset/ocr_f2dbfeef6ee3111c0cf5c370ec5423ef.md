前段时间，我给你讲过“食物链”这个概念。还记得“食物链”是什么吗？在自然界，有生物负责吃别的生物为生，被称为“生产者”；有些动物吃食生产者的，比如吃植物的动物，就称为“分解者”；还有一些，通过分解让生物腐烂回到大自然，这就是“分解者”。这些生物一环扣一环，形成了链条一样的结构，这就是食物链。

说到食物这个话题，大多数人都觉得，动物吃动物，吃东西很残忍的，但动物也吃植物，就是有点儿顺应草草——你是不是也这样感觉呢？

可是，你有没有想过，植物置办的食物是要多动物的呢？植物又为什么要给动物吃呢？

植物对于“被吃”这件事儿的，大致有三种态度：

+   1. 第一种是避免被吃掉；
2. 第二种是有选择性地帮助动物吃掉；
3. 第三种是积极主动争取被吃。

看上去有些儿，今天就详细说一说这三种态度。

推荐阅读：《生态学进入》在食物链的哪几部？

# 态度一：避之不及

对于大部分植物来说，积累了全身的养分，一长就是靠自己用一生，二是留给自己的后代，帮助后代生根发芽的，这么重要的资源，怎么能随便被别的什么好东西给吃掉呢。

所以，这些植物想尽一切办法，避免动物来吃自己，比如植物人长一样，长出好多好多刺儿；还有一些植物让自己的种子尽可干吃就小自己的有毒的，谁敢吃它们，就会毒得发疯。比如蓖麻的种子、长柄青兰、毒芹，毒性都很强，但如果人类对它进行一些简单处理，毒性就会消失，像是蚕豆还有黄花菜。平时也会吃到这两种蔬菜，记得一定要提醒爸爸妈妈，必须充分做熟才可以吃它们，不然会有中毒的风险。

# 态度二：有选择性的

植物对于“被吃”的第二种态度，看起来还有点像被拉练了。允许一部分动物来吃自己，但是不允许其他的动物吃。

比如说到辣椒吧，辣椒就是这样个东西。你一定会恨辣椒，因为辣椒的味道的真让人恨得发疯。这是因为，辣椒所有的辣椒素会刺激人体的痛觉感受器，让人觉得疼。实际上，会因此感觉到痛的不仅是人类，所有的哺乳动物，都有这样的感受，所以，除了人类之外的哺乳动物，几乎完全不会去吃辣椒。

不过，鸟类就没有这样的感觉。它们完全可以吃到辣椒的辣，所以就可以抓着辣椒大啃一顿。那为什么辣椒这样的厚此薄彼，重视鸟类的感受，而完全不许哺乳动物来吃它们呢？

因为哺乳动物的消化能力太透了，可以把辣椒的种子给破坏掉，而鸟类的消化能力没有这样强，即便辣椒的种子被它们吃下去，被鸟类排出来之后，还有相当部分的种子能继续生根发芽。所以，辣椒就慢慢进化出了这种重视鸟类，而排斥哺乳动物的特点。

# 态度三：慷慨奉献

在看到第三类植物。这样说来，第三种植物简直就是慷慨了，不但会撒胡椒，不会用毒性或武器来防御其他的动物。

尽管非常友好，但这些植物也是完全来者不拒的，它们对来访的食客还是设定了一些要求。比如像是蔷薇科的水果，就列出了一个非常重要条件：谁都才可以吃，但你非要吃的部分，你才可以吃，我不许你吃的，你别碰。

蔷薇科水果，很多都是水果摊上常见的，甚至每天都要吃的，像是苹果、梨、桃、李、樱桃、杏仁、桃子、梨，都是很好吃的。但是吃这些水果，就只能吃它们肉的部分，不能咬它们的种子，也就是它们的核。

对蔷薇科的水果来说，种子就是“不许”的东西，其中含有微量的剧毒物质。如果不慎嚼碎，可能会进入口腔，如果吃很多，还是很容易出现危险。

和蔷薇科一样，五芯科的植物也挺好看的。这样的植物很多都生活在南美洲。不过，蔷薇科的植物会产出好吃的水果，而五芯科的植物则是会产出好吃的水果。比如说著名的巴西栗就是五芯科植物的种子。

你吃过巴西坚果吗？这种坚果（下图），截面是三边形的，非常特别，味道也很好。不过，要想吃到巴西果，可就要有做贡献了。因为作为五芯科的一门，巴西果非常娇气，要靠动物来输送小美味的种子，但是这种种子却很能到，因为它们总是成堆地包裹在一个很大的壳里，每个果壳里能装好几颗种子，有两公斤重，所以，采摘巴西果的工人需要携带着藤条才能把巴西果剥开，避免从高树上掉下来的大球中——真的是个力举，恐拍一下子就大做破坏。

等到种子成熟的时候，这些大果球就会从树上掉落下，然后裂开一个口子。不过，巴西果的种子很大，就那样一个小洞了，它不会掉出来，只有当地的一种特殊的鸟类，叫剥果雀，牙齿很坚硬，才可以把小袋口咬成一大口，把种子取出来。它们会把吃不完的种子里面藏起来，被埋起来的种子，日后就会生根发芽，再慢慢长成参天大果树。

# 博物学家养成记

最后，我一定要特别强调一句，今天我推荐对你的态度是分成了一共三种，主要是为了帮助你理解内容，但严格来说，这样分类是不严密的。整体来看，植物希望被动物吃下去，总和帮它们，把它们播种起来。植物希望动物帮自己，把种子带到可以生长的地方。
