# 医学·人类|你的大脑也会发“电报”?

世界很大，奇妙的事情每天都有，我们一起发现吧！

在这个专栏之前的一篇文章——《青蛙腿到能不能发电?》，里，我跟你讲过放电理论，这个理论就是说，手木触到了青蛙腿之后，青蛙腿为什么就会动。

伽伐尼和达托的整场博弈各执一词，哎，吵吵还打起来了。其中，伽伐尼就认为，生物电的存在吗，本身就是一种放电的现象，后来大家发现，伽伐尼这个观点是很有道理的，生物确实是有放电的现象。所以，他们这就发展出了一门学科，叫电生物学。很多人开始研究生物发电这个问题。

今天咱们要说的，也是生物发电的这事儿，而且是特定的器官在放电，它就是我们的大脑。

# “拦惊马”拦出来的科学家

咱们的大脑很复杂，由许多许多的细胞组成，这些脑细胞在活动的时候，会释放电信号，而且，随着细胞活动的变化，这些信号还会出现周期性的变化。用仪器把这些变化记录下来，听起来就仿佛有规律的电信号一样。所以，这些信号，就叫做脑波，或者叫脑波。

咱们现在对这个东西很熟，但是以前人们不熟，甚至完全不知道有这个电报存在。因为很简单，这些东西，需要经过多个技术点检验，才能检验到。如果没有这个技术，读不出来，那当时也就不可能知道它的存在。

不过，就像咱们这个专栏在科学技术史中一个方法的整样来一样，科学家们不会傻坐着等，他们本身会一直推动技术的发展，然后用新的方法去探索新的可能性。

在德国，有一位医生，名字叫做汉斯·贝格尔。贝格尔先生，年轻的时候，曾经在德国的军队里服役，当一个骑兵，骑兵在训练的时候，那得时刻骑着马，要骑马，在一次训练当中，贝格尔遭遇了事故，当时他自己骑的马突然受到了惊吓，突然前蹄离地，就要站起来。战马这下子不听使唤，可贝格尔没留神，直接被甩到了地上。

你说怎么那么倒黧，当时队伍正在行进，贝格尔身外就是看大看的马车，车轱辘压住人的话，能进还，马车的车夫直接没踩，还踩得使浑身的气儿吐了口白气，马也受了大枪，从贝格尔身下碾过去了。

事后，他听说远在千里之外的姐姐在那个时候恰好突然感觉到非常不安。其实这个事情是个巧合，但当时不知道怎么是事情，人类的大脑到底是怎么运动的，彼此之间到底是传输什么信息？为了搞清楚这个问题，他离开了军队，转行去做医生啦。

# 歪打正着的“大脑电报”

贝格尔的专业神经病学，这是一门研究人类精神疾病的学问——那个时候，还没有咱们现在的说神经科学或者脑科学这个专业，精神病学应该是离它最近的一个学科了。

但是，贝格尔没有把自己限在精神病学的范围内，他还在思虑人类的大脑思想法。因为他当时也在那个领域做研究，所以，贝德勒就把电用到了大脑研究上了。

在德国小城耶拿郊外的一座小房子里，他布置了一个实验室。在那里，他会在实验对象的大脑上贴一块金属片，一片在前额，一片在后面的头后部。金属片上连着电线，打开电流计之后，记录设备会记录下一波波变化。
