# 博物学家养成记

这是不是一个很神奇的过程呢？你没有想到吧，氧气的诞生还造成了地球历史上第一次生物大灭绝。除了今天讲的故事之外，你还知道哪些看似必不可少的东西，也可能存在危险呢？在留言区分享一下你的生活经验吧。

+   1. 植物的呼吸并不是吸入二氧化碳排出氧气。实际上，植物呼吸也需要吸收氧气，排出二氧化碳。只是它们自带一个氧气工厂，可以靠阳光、水和二氧化碳的作用产出氧气，满足自己的同时，还能释放出多余的氧气；

+   2. 有些生物不需要氧气，被称为厌氧生物，破伤风梭状芽胞杆菌和肉毒杆菌就是两种著名的厌氧生物；

+   3. 蓝细菌是最早有光合作用能力的生物。它们大量出现，并制造大量的氧气，最终提升了地球大气中的氧气浓度，引发了厌氧生物的大灭绝。

氧气工厂：植物呼吸也要吸收氧气，排出二氧化碳。但它们自带一个氧气工厂，可以靠阳光、水和二氧化碳产出氧气，满足自己的同时，释放多余的氧气。
