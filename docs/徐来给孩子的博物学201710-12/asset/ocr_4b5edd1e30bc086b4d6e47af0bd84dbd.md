# 人类的标志是什么？

研究人类的起源，先要有一个“人”说。研究人类学的科学家，叫古人类学家。他们的一项重要工作，就是到处挖化石，当然，新久有人类头骨至少是头盖骨化石。即拿到一块骨头，你怎么判断它是属于猴子，还是属于猿，还是属于人类呢？

化石上记录了很多信息，可以让古人类学家进行分析，尤其是头骨，信息量很大，比如在咱们的头骨上有一个圆形的洞，叫枕骨大孔，枕头的枕。这块骨头上面长着一个很大的圆孔，圆孔的作用可重要了。在咱们的脊柱里里外外，有很多神经，直接把大脑的信息传递到身体的各个部分，同时把各个部分的感受送回到大脑。所以，这就相当于咱们的耳朵里里外外有一根数据线缆，它要通过枕骨大孔才能接到大脑上。

我们常见的那些动物，比如鸡牛羊，再比如那种猴子，包括跟咱们猿猴关系很远的长臂猿，黑猩猩，它们基本上都是四足行走的动物。所以，它们的骨裂大孔是平行于地面的。这一来呢，枕骨大孔这个接口，就得开在头骨的后部。

可人类不是，人类是两足行走的动物，骨裂是垂直于地面的，这个时候，就枕骨大孔还是开在头骨后部，那就必须长得像一根又长又弯，像天鹅一样的脖子来接受了，这肯定不行，所以咱们的枕骨大孔就是开在头骨的底部的。因此，枕骨大孔的位置，号称是直立行走的标志，古人类学家们认，这是人类和早期非洲古猿之间的一个根本差别。

当然，除了枕骨大孔之外，还有很多其他的标志，比如咱们大胯两边的骨头，为了适应直立行走，也发生了很大的变化，跟四足着地的动物很不一样。比如牙齿，人类的牙齿和猿猴的牙齿差别也很大。总之，只要是在头骨上的一个定量的骨头，古人类学家们就能判断这个物种，大体上属于古人类，还是不属于古人类。
