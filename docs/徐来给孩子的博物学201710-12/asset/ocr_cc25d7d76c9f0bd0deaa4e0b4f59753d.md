# 问答：暖宝宝为什么发热呢？

我来啦，

大家好，今天咱们继续来聊聊冬天的暖宝宝。

说到暖宝宝，大家可能都觉得它很熟悉，但你对它了解多少呢？

今天咱们就来好好聊聊暖宝宝，看看它到底是怎么个发热原理，为什么能那么暖和，甚至还能一直发热好几个小时呢？

暖宝宝为什么发热呢？它的内部到底是什么呢？

好，今天我就告诉你，暖宝宝里面其实有很多的小铁粉，就是铁粉。这些铁粉在空气中会发生氧化反应，也就是大家常说的生锈，这个生锈的过程就是放热的过程，所以暖宝宝就会发热。

那它为什么能一直发热好几个小时呢？这是因为里面加了活性炭、蛭石这些材料。活性炭可以吸附空气，让铁粉跟空气接触得更充分，反应得更快。而蛭石呢，就是用来储存热量、慢慢释放热量的，这样暖宝宝才能持续发热，而不是烧一下就凉了。

暖宝宝为什么能持续发热好几个小时？

前面说过了，蛭石在里面起到了储存热量和慢慢释放热量的作用，再加上它整体的结构设计得特别保温，所以热量不是一下子全放出来，而是慢慢放，这样就能持续发热好几个小时了。

为什么是铁粉而不是别的东西？

其实啊，铁粉氧化放热是一个特别稳定的化学反应，热量很温和，不会烫伤人，所以特别适合做暖宝宝。再加上铁粉本身便宜、好获取，所以它就成为了暖宝宝的“发热核心”。

暖宝宝真的不能直接贴在皮肤上？

对，虽然暖宝宝的热量是温和的，但毕竟它一直在发热，如果直接贴在皮肤上，很容易造成低温烫伤。所以咱们用暖宝宝的时候，一定要隔层衣服贴，别直接贴着皮肤哦。

暖宝宝用完了能不能扔进垃圾桶？

当然可以呀，不过要注意的是，用过的暖宝宝可能还有点温度，最好等它完全冷却了再扔，这样更安全。扔的时候也别忘了把它扔进干垃圾桶，别扔进湿垃圾桶哦。

所以啊，暖宝宝虽然小，但里面的学问还真不少，铁粉氧化、活性炭吸附、蛭石保温，这些都是它发热的小秘密。希望今天你知道了这些，就能更聪明、更安全地用上暖宝宝啦！
