# ## 人类天生应该吃素吗？

如果你还记得咱们前面讲过的关于人类的演化历程，应该已经发现问题了，前面这个“人是猴子变来的”的说法，首先犯了一个错误，人并不是猴子变来的。现在活着的任何一种，无论是长臂猿、黑猩猩、还是大猩猩、红毛猩猩，都不会直接变成了人类，它们只是与人类有共同祖先。

当然，这也不能阻碍咱们去分析一下它们的食性。长臂猿跟我们是猿类当中在中它们植食性比例最高的了，它们大概有六成的食物是各种果类，剩下的则是嫩枝叶、花朵之类的。但它们同时也吃很多昆虫，甚至偶尔去偷蜂蜜鸟。红毛猩猩和大猩猩的情况也是如此，植物性食物占了它们食物的主体，但它们同时也被记录下来用工具去获得动物性食品的情况。红毛猩猩曾经被拍摄到，把树枝改造成鱼叉，打鱼的行为了。大猩猩，则有用小树枝当做钓鱼竿，伸进蚂蚁洞钓蚂蚁吃。

在所有动物当中，和我们亲属关系最近的是黑猩猩和倭黑猩猩。它们要食物，虽然果实依然是它们主要的食物，而且绝大部分人都认为黑猩猩、倭猩猩是吃素的，但实际上，它们不但非常喜欢吃肉，而且是有主动的捕猎行为。更惊人的是，科学家们发现，它们甚至会吃掉自己同伴的肉。

# ## 食物上的投机分子

传统上，我们会 把动物按照食性分成三类：食肉动物、食草动物，以及逮到什么吃什么的杂食性动物。

很多人会认为，食肉动物就是只吃肉动物，食草动物除了植物啥都不吃，而杂食动物呢，就是机机会主义。不过，如果你仔细观察一下就会发现了，其实情况并非如此。

比如说，你去动物园观察一下老虎、狮子、豹子这样的食肉动物，就会发现，它们其实也常常会去吃肉。如果在你家里养猫或者养狗，你可能也注意到了这样的情况，它们常常会主动地去吃点草。有时候，你的胡萝卜、西兰花之类的蔬菜扔给他们，它们也吃。

明明是食肉动物，它们为什么吃草呢？其实，这对动物来说，它们未必能更好地消化这些植物，但是它们把植物吃进肚子里以后，可以和吃进去的植物一起吃下去的动物毛发生长在一起，形成毛球，再吐出来。

食草动物的情况也是类似的，虽然就是食草动物，它们吃什么东西倒倒也是食草，甚至，大但有些会去吃点昆虫也是吃。前阵子有一个小视频在网上引起了关注，动物园里，一只非洲草原上的小羚羊前面放着一只山羊，只小山羊既不慌，低下头张开嘴，把那一小羚羊叼起来，嚼一嚼咬成碎片。然后低下头，叼一只小羚羊，兔子的情况也是类似的，如果你家过兔子，就会发现这个问题，一旦吃到了狗，它就会反复要求吃，隔三差五就得开个胃。甚至还有一条新闻说，在辽宁沈阳，有一匹马不但爱吃肉，还爱吃鸡肉...

除此之外，科学在人们的外观观察的时候，也经常发现一些在野外环境的食草动物，斑马，马之类的野生食草动物，在野外环境中还会捕食已经死去的同类的尸体。

所以说，其实所谓食草动物不吃肉，也是一个很不准确的说法，在自然状况下，动物的食性有可能是比较杂的。

# ## 吃肉为什么容易变得不健康？

这其实是一个非常难理解的事情。因为在自然界，动物总是处于一种相对匮乏的状态。所以，动物们总是会因为肉一丢就吃多吃一点食物，尽可能不浪费食物。这样一来，假如草食动物碰到了可以吃的肉类，肯定会去吃。它们甚至有的还会表现出对同类的兴趣很强。只是，消化系统长期无法消化植物食物，如果长期大量吃肉，有可能会造成健康上的问题。当然，如果是食肉食动物的话，实际对食草动物来说，也没有什么本质上的差别。

反过来说，如果是食肉动物，你总让它吃草，这个肯定也不行。所以，该被谁谁就是谁是，该吃什么就吃什么，其实人类应该说是偏向杂食的，既吃肉，也是动物，这不仅只是食物的食物，人类都可以搞得到的啊！哈。更重要的是，人类正常生理活动所需要的各种营养，有些必须通过植物食物来获得，有些则必须通过动物性食物来获得，缺一不可。

比如说，有一些微量元素，是人体必须的，像钙、铁，这些的，它们在植物当中含量相对动物性食品中，含量不容易被吸收，而在动物性食品中的含量却比较高，吸收也容易一些。所以，如果只吃素或者主要吃素者，这些元素就会缺乏。

还有一种人必须的东西叫做维生素B12，它只存在于动物性食品当中，如果只吃素的话，肯定会出现这种维生素不足的情况。
