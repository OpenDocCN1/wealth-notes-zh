# 渡过红海的蝗虫

这个故事发生在整整10年前，那是2007年，你应该还没有出生吧，或者可能刚刚出生不久。

那一年的5月份，在非洲的东非地区闹起了蝗灾。蝗虫是最可怕的农业害虫之一，它们个头都不小，非常擅长跳跃和飞行，大群蝗虫数量数不清。它们结成非常整齐的阵势，每一只蝗虫和它前面那只都保持一定的距离，然后几乎同步地向前推进。

你会不会觉得奇怪，为什么蝗虫会排出这样奇特的阵型呢？其实蝗虫中也是没有办法，只要有这种虫子几乎什么都是没有哪一只蝗虫落在群体里落后了，那么它就会被身后的蝗虫给咬到，同样的，它也也不太可能飞得更快，因为飞得更快的话，它就能赶上自己前面的蝗虫，咬它的屁股。所以，实际上，整个蝗虫群都是以同样的速度在向前行进。

这么贪吃的昆虫，着急起来连自己同类都不放过，所以，你可以想象，一群蝗虫所到之处，所有可以被它们吃掉的东西，全都会消失。有蝗虫经过的农田，啥都剩不下来。

这场蝗灾，从非洲东部一个叫厄立特里亚的国家爆发起来，并且，很快就向周围地方扩散开了。蝗虫基本是往东、往东和往南扩散的，却从来不往北飞。为什么呢？你看地下地图就知道了，厄立特里亚这个国家，你往北的海岸，是往北飞，那不就是红海了吗？

说到这里，你可能会以为蝗虫飞不过大海，所以不会往北飞过去了。不过，其实蝗虫并不是不会飞过大洋的，实际上，历史上有过不少蝗虫跨海袭击其他地区的记录，甚至有飞过一些公里远，蝗虫群可以在10天内飞过5000公里的海面，也就是说，并不存在什么蝗虫飞不过的地方。

为什么这个，蝗虫群就是不朝着北面飞呢？

# 偏振光阻挡了蝗虫

科学家发现，这和一种叫做偏振光的光线有关。

厄立特里亚这个地区，离赤道很近，太阳是很强的。刺眼的地面光照射到海面上，被卷越的海面反射出来，形成向周围漫反射的偏振光。这种光线，对蝗虫来说是很重要的导航手段。

海面上反射出来的这些强烈的偏振光，就好比在向蝗虫发出警告：别过来，别过来，除了一大片水什么都没有，不但没有吃的，而且如果体力不够好，还会掉进水里淹死。

而与此相对的是，陆地上反射着微弱的偏振光，也就是说这边是更安全的。

其实就蝗虫的能力而言，未必真的不能飞跃这片海域。但咱们只知道，这一次它们没有往北飞。红海的对面就是阿拉伯半岛，沙特阿拉伯的最南端。尽管和厄立特里亚这个国家只有一海之隔，但对岸却完全没有受到蝗虫灾害的影响。这得归功于偏振光的帮助。

人们发现偏振光的问题已经很久了。早在17世纪的时候，就有一位丹麦科学家，注意到偏振光这个现象。后来，越来越多的科学家也注意到了这一点，并且对此展开了研究。

其实你可以看到偏振光。找一个液晶显示器，打一个全白窗口，不管是哪个显示色彩恰好都是偏振光，总之一眼，你看到液晶做就是。然后你拿一片空，显示全白色的，对着你一下，空窗，如果你足够细心，运气足够好，眼前会出现这样一奇怪的现象（下图）。

# 偏振光造就了3D电影

这个现象，叫海丁格尔环，是170多年前，由一位奥地利物理学家发现的，这位物理学家名格老海丁。威廉·卡尔·海丁格·冯·海丁。这个海丁格环是一个脑很发达的人，一般人看到这样的现象，通常会觉得像十字或者像四叶草。但是海丁格，他偏说这个东西东西像是一揽子。后来，这个说法以讹传讹，变成了四把刷子，海丁格尔删了这个说法，也就是这么来的。

这把刷子的存在意味者，其实人类也是能感受到偏振光。到底什么是偏振光呢。其实，你可以把光想象成波，而且咱们平时看到的光线，大都是很多波浪混在一起构成的，这些波，动的方向不太一样，有些是在左右，有些是上下，有些是带着角度晃。假设一个东西像穿了一个很窄的缝隙，那么缝隙会先允许某个特定方向上晃悠的光波穿过，而其他波都给挡了下来。这样只在一个方向上波动的光，就是偏振光。

当我们看着显示屏的时候，显示屏发出的偏振光在垂直方向和水平方向上存在差别，这就像在这两个方向上看到的光线略有不同，导致了海丁格尔环的出现。
