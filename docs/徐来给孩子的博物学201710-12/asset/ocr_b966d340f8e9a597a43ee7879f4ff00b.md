# 蚁后死亡，蚁巢消失

你可能已经听说过蚂蚁家庭的特殊性了。在一个蚁巢里常会有一条，会一只蚁后，大部分都是雌性的，充当保卫蚁巢的兵蚁或者专职产蛋的工蚁，也多是母性蚂蚁结 婚生宝宝。在大多数情况下，如果一个蚁巢里的蚁后死了，那么这个蚁巢也会随之衰亡，分崩离析。

为了避免这种情况的发生，有些蚂蚁的繁殖就比较复杂，它们会由多个蚁后共同繁殖，如果一只死了，嗯，那还有一份的命在呢。还有一些蚂蚁，思路就更奇特了。

科学家发现，一般来说，一个蚁巢当中， 有繁殖能力的雌性蚁后，也就是新一代的蚁后，在孵化出来之后，会飞离自己的蚁巢，寻找一个新的合适的地点，先生一堆工蚁，然后再让这些工蚁帮着自己选房子，找吃的。然后它才开始专心致志地生产更多的蚁后和兵蚁，扩大自己的巢穴。不过，这对新的蚁后来说是特别艰难的一关，大多数蚁后无法完成这样的目标，它们的“建巢大业”也会在行途中突然中止。

但是那些最机灵的蚂蚁，往往不是靠一只蚂蚁后去建蚁巢，而是有多只一起行动，共同繁殖，在一些地方，建巢失败的新蚁后甚至会回到蚁巢里，来帮自己的母亲维护旧的蚁巢。这么一来，这些地区的蚂蚁会表现出非常有趣的现象，在一定范围内的蚁巢，里面的蚁群彼此之间都都是熟悉的。有些蚁巢的蚁后要是被驱逐了，若果一个巢穴里的蚁后死了，那么相邻的蚁巢里，她的姐妹或外甥女就会接替她的班。这样一来这个蚁巢也可以不断地控制这个地区，并且可以极大地扩大自己的领 地了。

# 成功的入侵者

有一种蚂蚁，名字叫做石狩红蚁，它生活在日本。这种蚂蚁就会在成成排好的家组成在 一起的家庭，在日本最北边的北海道地区，有一个巨大的石狩红蚁群。这个群由45000个蚁巢组成，估计拥有超过32只蚁后，大约有1000万。

怎么样，是不是感觉这个石狩红蚁群好像是建立了一个庞大的国家？但是，这样规模的蚂蚁家庭，其实是个小把戏。真正的 大型蚂蚁家庭，规模大到我们无法想象的 程度。
