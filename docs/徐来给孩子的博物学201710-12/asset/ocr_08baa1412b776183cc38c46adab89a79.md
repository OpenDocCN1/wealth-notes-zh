# 气象学·动物 | 穿越到恐龙灭绝那一刻

世界好大，奇妙的事情真多着呢，我们一起去发现吧！

恐龙应该算得上是这个地球上出现过的生物里，最迷人的了一种了。很多人从小就非常喜爱恐龙，甚至有些人因为特别迷恋恐龙而走上了科学研究之路；还有些人在家里收藏了很多恐龙玩具，不瞒你说，我家就有很多。

几乎每个人都知道，恐龙曾经是地球的霸主，这一类动物曾经统治地球。但是有一天，它们全都消失了。这次大灭绝虽然不是生命史上最可怕的一次，也是备受关注的。大家可能都想知道，为什么那么强大的恐龙会消失殆尽——你一定很想知道吧？

今天，就让我们来听听恐龙为什么灭绝了这件事儿吧。

# 被一条线“终结”的恐龙时代

科学家们一直在非常努力地寻找导致恐龙灭绝的真正原因。

当然，要解释清楚这个问题，肯定是没有那么容易的。毕竟，事情发生在6500万年前。所以一开始，大家都不知道怎么办。

没办法总比没没办法，但还是有人针对恐龙灭绝这个问题，做了很多的研究。比如地质学家们之前进行过，威廉·史密斯通过挖运河发现，我们脚下的大地，有点像蛋糕，是分层式的，而且相邻在不同的地方，这些层次大致也会出现在规律可循。

慢慢的，科学家们就意识到了，这一层一层，是按照时间顺序堆积起来的，越往下的地层，越古老。如果一个地层里藏着生物化石，那就意味着我们由此可以推知大致的年代，就能判断这些动物到底在多久前消失了。

恐龙的情况就是这样。通过研究恐龙化石出土的地质层，我们知道，最早的恐龙在2.3亿年前就已经出现了，然后这些恐龙在地球上生活了1.65亿年，然后，在6500万年前突然消失了。恐龙的出现，是一个缓慢的过程，而恐龙的灭绝确实是嘎嘣脆，绝不拖泥带水。

而且，恐龙的灭绝还出现一个很奇怪的现象，有恐龙的地质层上面最晚的那一层，地质学上叫白垩纪，而恐龙灭绝之后出现的下一层，地质学上叫做第三纪。在白垩纪和第三纪之间，还夹着很薄很薄的一层粘土。这一层似乎给恐龙们画了一条线，但没有恐龙曾经越过这条线而来。科学家们把白垩纪、第三纪这两个名字的第一个拉丁字母结合在一起，管这个薄薄夹层叫做K-T边界。

# 小行星与恐龙命运的关系

很明显，弄清K-T边界的来由，也就弄清楚恐龙灭绝的原因。为了解开这个谜团，专门研究古代生物的古生物学家们，还有专门研究我们脚下的岩石和土壤的地质学家们非常努力地工作着。

可是，关于这个问题最被认可的一个假说，也是目前世界上最被认可的恐龙大灭绝的解释，却既不是古生物学家提出的，也不是地质学家做出的，而是由看起来与恐龙毫无关系的物理学家提出的。

这可不是一位普通的物理学家，他叫路易斯·阿尔瓦雷斯，因为这段故事也和儿子有关，所以很多时候也被称为老阿尔瓦雷斯。他年轻的时候曾经是个过目不忘的“全能记忆体”，学习强项就是过目不忘。后来，1968年时，他因为在物理学家方面的贡献，拿到了诺贝尔物理学奖。

上世纪70年代的时候，阿尔瓦雷斯已经功成名就，而且到了退休的年纪了，按说应该休息了。可是，有一天，他听自己儿子小阿尔瓦雷斯说起自己在意大利的一个叫K-T边界采集的样品，突然就很有兴趣，开始盯着这些样品，找到了另外两位科学家，开始对这些样品进行检测。

![](bbox=[0.08, 0.0010500000000000002, 0.9, 0.00115])

一检测，他们几个简直怀疑自己的眼睛了。首先，在这些样品里出现了大量微小的球形石英颗粒。石英是地球土壤岩石当中的一种成分，制造玻璃需要大量的石英，它只有在高温高压下，非常大的压力下，才能形成这种微小的球形颗粒。这说明了，当这些颗粒形成的时候，一定发生了一个非常大的灾难。

更重要的是，他们从这些样品里发现了大量的金属钴。钴这东西，我之前跟你讲过，现在采矿的也说过，这个东西硬度极高，适合拿来做钢笔的笔尖，但是地球上很少。发现这个特性的时候，他们几个以为是搞错了。反复验证，结果依然是很多。阿尔瓦雷斯父子更是向各地的科学家求证，其他地区的K-T边界样本里，钴的含量如何，得到的答复依然是很高。

这两个答案拼在一起，阿尔瓦雷斯父子觉得，问题的答案已经给出了，那就是：在恐龙时代末期，一颗或者几颗巨大的小行星突然落在了地球，造成了放射性气候灾难。

# 古生物学家的猜想

虽然阿尔瓦雷斯父子提出的这个结论，是一个假说，可并非一个证明过程，好在他解释了K-T边界表面出现的种种情况，所以，这个假说很快就成了恐龙灭绝原因的一个解释。

不过，这个假说却让古生物学家们有点不开心。毕竟，恐龙之变之死是古生物学家们最关注的话题。现在解决这个问题的，竟然是一个“外人”，似乎确实有点说不过去。

后来，古生物学家和地质学家们又提出了好几种恐龙灭绝的假说。比如有些科学家认为，在印度的德干一带火山喷发是造成恐龙灭绝的主要原因，火山喷发出的火山灰和气体改变了地球气候，导致恐龙不适应而引发了灭绝浪潮。还有一些科学家认为，植物生态的变化导致吃植物的恐龙们吃不饱，并进而影响到了吃肉的恐龙，生活，并最终导致了灭绝。

# 博物学家养成记

现在，科学界普遍认为，恐龙灭绝是一个综合因素导致的结果，但其中最重要的一个事件，依然是K-T边界所记录的小行星撞击事件。
