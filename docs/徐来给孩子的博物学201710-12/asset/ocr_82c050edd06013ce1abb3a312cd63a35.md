# 像猫也像獾都归于灵猫

熊獾，在英语里面叫 bearcoat，bear是熊，cat是猫，字面意思解释就是熊猫，但它可不是咱们平时说的大熊猫那个熊猫。它獾大熊猫的关系很近，它的尿，既不像熊，也不是猫。不过，它和熊还有猫，都同属于食肉目这个分类当中。

在食肉目里，熊，属于，熊科；猫还有老虎、狮子，属于的是，猫科；还有獾，还有狐狸，还有狐狸的，都属于，犬科；还有象，还有狼，还有海獭之类的，属于，鼬科。熊獾属于食肉目比较着名的一种，但是属于灵猫科，灵猫科包括着看起来有点大笨拙，却比猫灵活灵脱的一类的动物。有些熊獾会分泌香味，所以它们小时候会被猫科豹子捕杀。

灵猫科的动物，体形一般都是比较小，比较敏捷，而且通常都生活在森林地带，白天很少出来活动。所以，大家一般也注意到了没到它们的原形了。第五类，传统上，认为这个动物是食肉目当中的，尾巴比较长的动物。

还有，印度尼西亚出产一种叫咖啡猫屎的东西。名字叫做猫屎，实际上跟猫没关系，而和灵猫有关系。有人会根据当地的一种叫做苏拉威西灵猫的动物，椰子猫消化不了咖啡豆，就随着它们的粪便一起排出来了。然后被收集起来清洗干掉之后当作咖啡。这种猫屎，虽然它的产地就产于这种猫屎咖啡的产地，不过，从咖啡品质的角度来说，这种咖啡味道可不好，所以我不建议大家喝咖啡猫屎。

# 有抓握能力的尾巴

熊獾身上有一个特别的地方一别急，我没说说到它们的尿液呢，我的是它的尾巴。熊獾的尾巴能长到一米不到的长度，尾巴跟身体的长度差差不多。你别小看了这条毛茸茸蓬松松的大尾巴，它是可以卷住树枝的。实际上，熊獾和熊的食肉目里面仅有的两种是有抓握能力的动物。

所谓的尾巴的抓握能力，就是尾巴打卷儿，能帮助它们抓住树枝，提供稳固支撑，成为它们在树上行名的“第五条腿”。传统上，都说它们是有尾巴的猴子，如果猴子是在树上的，那么它的尾巴多半卷在树枝上。甚至有人，画侧身到一吊在想，有没有画成这样过？但我提醒大家关注一下，我们常说的猴子，包括整个欧洲、亚洲非洲大陆的猴子，尾巴只能起平衡作用，在没有抓握能力，而有抓握能力的才是生活在美洲的所谓“新世界猴子”。

从科学上，熊獾的尾巴居然看起来很像松鼠，但实际上比大多数猴子的尾巴都要灵活。

熊獾之所以需要一条如此灵活的尾巴，很重的一点是因为它需要长时间地留宿在树上。虽然是夜行动物，但熊獾非常喜欢攀爬，即便是午睡，也要睡在树干上的动物。对它而言，热带雨林的树干不是食物所在的地方。

# 用香味来传递信息

生活在密林里有一个问题：你无论往什么方向去，视线都会被树干和树叶挡住住。所以在这，很多以动物，都会看不见危险的情况。熊獾虽然也是夜行动物，都是自己过的自己的，不组成群，但个熊獾是有敏感的，有联络的需求。它们就发展出了一种基于它们的联络系统。

第一种方式是声音。熊獾可以发出非常非常丰富的声音，它们有时会响，还能咯咯响，还能用尽全力尖叫，如果它感到开心，它的叫声会非常的轻柔，咯咯咯咯，开心时它的时候会叫出来又是有味道的，雄性的熊獾，有时候会还会发出类似猫叫的叫声。

第二种方式就是气味了。在熊獾的尾巴上，有一个专门分泌油脂的腺体。它们在森林里走走来去的时候，常着会把这些腺体的分泌物蹭到树干上，留下自己的信息。更重要，熊獾是有味道的。所以，它们会故意把尾搅到自己的脚趾上和尾巴上，然后又用尾巴在树上蹭来蹭去，同样可以闻自己的气味留在树上。

熊獾尿的味道，很像好吃的食物—我并没有在开玩笑，这是真的。对人类来说，它们尿液被排出在树的时候，那种尿液就会渗进当成出现奶咖啡味爆米花，有爆米花香吗？在有一些地方，人们会把熊獾的尿液是刚做出来的爆米花。

这是为了，熊獾的尿液含有一种香味的物质，因为物质的名字很生，我们一般就称为为2-AP，它确实跟做爆米的谷物有关，因为我们在加热食物的时候，蛋白质类的氨基酸和，以淀粉为主的糖类会发生反应，产生这种物质。它的香味让我们感觉到有食欲—一不小心。熊獾的尿液跟刚好也有它。
