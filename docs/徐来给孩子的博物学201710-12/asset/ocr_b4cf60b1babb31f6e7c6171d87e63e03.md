# 生理学-进化 | 谁砍倒了一棵5000岁的树？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

你出去玩儿的时候，一定会在很多风景区看到所谓的“古树名木”。那些古老的树，动不动就好几百年，上千年，这些古树往往都很高大，也许会让大家对古树的想象，长了那么多年的树能不高大嘛。就像我早在《内容看过的“玄幻小说”》里，这世界在老百姓看的最新的对，已经长了好几百年。

今天我来先说目前世上存活的古树名木的一棵树，可是它可能让你失望，因为它并不高大，甚至有点低矮。

# 钻孔不成改砍树

这一棵最古老的树，是刺果梨树，一种可以长得很大，但个头都不高的树。以于年一看到它，你可能会认为它很年轻。这种树长得非常缓慢，缓慢的生存方式也是导致它们能长成这些古树的原因之一——生不易，长不易，太慢了。营养以我其他生活活动就有点像能干的，所以，想要长寿，那得在比较寒冷和干燥地区慢慢长，实际上，最古老的动物也是同样的道理，是生活在比较冷的海水里，长得慢慢，活得很久。

要说起来，那还是1964年，当时，美国一所叫教室山大学里有个学生叫卡雷，教室山大学在美国的密歇根州。卡雷当时拿到一笔奖学金，去加州的山里研究，这一去他拿的钱，差不多相当于一个住在中国浙江的人，拿上钱去西藏翻山越岭。

他研究的是古代的气候变化，研究方法很特别，是在山上选一棵树，然后用特别的钻头去钻到它，取一小段木头下来，去观察年轮的变化。我们知道，雨水丰沛的时候，树长得快一些，年轮之间的间隔就宽一些；反之，干旱的时候，年轮就排得密一些。通过这个方式，我们就能知道古代的气候变化。

当时卡雷找到了一棵刺果梨，看起来很适合钻年轮，他想着掏出工具来干活儿了，可是谁知道工作进展得很不顺利。这棵树有点粗，他手上的钻头钻到树心的位置，而且，还一连续弄坏了好几根钻头。

眼看自己没法继续做研究了，卡雷干脆转了个弯，他去找了个斧头，把这棵树砍倒，再慢慢研究它的年轮。

护林员想了想，觉得科研还是很重要的，而且，这棵刺果梨看起来没什么特别的，虽然很粗，但是看直径八米也高过了，所以同意了他的申请。

# “砍倒世界上最古老的一棵树”

申请通过之后，卡雷的工作进展就顺利多了。他和你木工具一起力气砍倒了树，然后截取了一些截面样本，就带回了他的实验室。

听到这里，你一定知道了，到了实验室里，卡雷有点傻眼了。确实，在实验室里一清点年轮，砍锯了。他稍微聚点来4862条年轮。这刺果梨有一个特点，正常情况下，每部都会形成一条年轮，但是有些年份气候特别严寒，就会不产生年环一根据这些推断，这棵树最老的年轮至少已经有4900岁，甚至可能超过5000岁，这是当时世界上已知的最古老的一棵树。

第二年，卡雷发表了自己的论文。一开始，大家并没有注意到这个事情。但是慢慢的，消息开始在人群中传开，人们注意到了。这在科学领域变得格外起热。很多人因此非常愤怒，他专门向当地的林务管理部门，认为这个砍树的许可没有发给理。

与此同时，卡雷自己也上了非常沉重的思想包袱，毕竟他就成了砍下世界上最古老的一棵树的树人——这可以比被自家后院的樱桃树严重多了。所以，卡雷也做了很多工作，积极地去保护剩下的那些古老的刺果，呼吁建立更多的保护区。

2004年，卡雷去世，当时，人们已经成为非常著名的科学数和保护者，人们会记得，他是在砍下“世界上最古老的一棵树”的那个人。不过，凡是有转机。一件事也举个例子，2012年，有人在他当年砍树的那个区域找到了一棵刺果梨，根据取样计算，这棵树已经662岁了，比卡雷看到的那棵还要多。卡雷终于洗脱了自己身上那个糟糕的头衔。

# 克隆体延续超过8万年

不知道你注意了没有，我说刺果梨的时候，一直在说，那是“最古老的一棵树”，而不是最老的刺果梨。这个说法，可是故意的。因为准确来讲，这棵刺果梨也不是最古老的树。最古老的树，是“潘多”。

潘多是大家给它的昵称，这是一种颤杨，美国的颤杨们，是一棵树类。它生活在美国犹他州，它不是一棵的树，而是一丛树。因为它克隆体。

我们知道，很多植物都能进行无性繁殖，比如很多肉串植物，你对下一个叶片，它就能长出一个和母体完全一样的新个体。有的时候，新长出来的个体，跟母体还通过像地下茎连在一起，你很难说这是一棵树还是两棵树。

就这样，旧的树不不死了，新的树长出了，克隆体就可以不断地生长，比如潘多。它就不是一棵树，而是通过4.4英里的多的一片森林，大80公顷。虽然有很多成于干，但它们的根都都在一起，所以，本质还是同一个个体。当然，这样一本大，它肯定是无法作为单独植物能某能活得那么久，不过，要确定它们年的，有点困难。对每一个根干可能只有几百岁，都无法准确反映整从植物的寿命。

# 博物学家兼成记

尽管如此，科学家还是设法测出了潘多的年龄，那就是8万岁。

同时，科学家带来了坏消息：颤杨是生活在比较潮湿的环境当中的，现在它所在地点的环境其实并不满足这种树。因为太过干旱，而且土上又没有足够的植被，潘多很有可能正在衰落当中，这也是引人深思的地方。

+   1. 1964年，卡雷为了进行古代气候研究，砍到了一棵刺果梨树，这棵树的年轮超过了4800条，估计树龄可能超过5000岁，是当时全世界已知最古老的一棵树；
2. 2012年，科学家们在卡雷当年砍倒的这棵树下到了一棵刺果梨树，估算发现这棵刺果梨的年轮比卡雷砍到的那棵还要长；
3. 世界上已知的最古老的植物是一棵名为“潘多”的颤杨林，这片森林共有超过4万棵树。不过，它们实际上是同一棵颤杨的克隆体。科学家认为这片克隆体的年龄已经达到了8万岁。

潘多：世界上活着的最古老的植物。它是一片颤杨林，一共有超过4万棵树。而且是一个克隆体构成的。这片克隆体树年龄超过了8万岁。
