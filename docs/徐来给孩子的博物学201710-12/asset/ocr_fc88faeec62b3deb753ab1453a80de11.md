# 黑洞是怎么形成的？

要说黑洞，得先从苹果说起。这个苹果，不是白雪公主吃的那苹果，不是亚当夏娃吃的那个罪恶苹果，也不是拿来吃的小鲜苹果，更不是欧佩瑞里《你是我的》中那个一吃一个苹果指的是牛顿的苹果。我在我前面专栏里讲到过这个典故。据说，牛顿就是被苹果砸中，才发现了万有引力。

这个故事，有可能会让人产生一种误解，那就是，只有存在于地球表面的东西，才会感受到地球的引力。可事实并非如此，地球表面、离地球有一定距离的东西也会感受到地球引力，地球内部的各个组成部分，也会感受到这种引力。

这种引力跟两个指标有关，一个是距离有多远，另一个是分量有多大。距离越近，分量越大，这个引力也就越大。地球在宇宙当中，分量不算大，它也只是一个小得不能再小的星系之一，所以，地球给自身体内各个部分所施加的引力，也都算不大。

像太阳这样的恒星就不得了。它们个头巨大，自己给自己的引力也十分巨大。因为恒星在恒外发发光，发射出去的光和热会产生的一个推动力，这个推动力会把它自身的引力给抵挡掉。不过，恒上的燃料，会烧得越来越小，烧完之后，那可吃不完的这颗星球的引力就会拉着组成星球的各个部分，往它的中心挤压过去，换句话活说，这个星球就会变小缩小。

个头变小了，它的表面和它的中心变得很近。这就意味着，它表面的引力变得更多了。如果它的分量又足够大的话，表面的引力就会以光线为吸收，让它想逃逸出去，这个时候，要么被吸回去，这样这个恒星自己会发光，也不会把光线反射或者折射出去，这样就形成了它，通过肉眼直接观测到它。这就形成了黑洞。

科学家们做了计算，如果一颗恒星在坍缩结束之后，分量只剩下太阳的3.8倍时，它就会形成黑洞。注意是剩下的分量，但是坍缩之后，他会比之前的太阳大很多，所以现在就是太阳3.8倍的恒星，将来是不能形成黑洞的。
