+   生了很多伟大的科学家；

+   2. 伽伐尼在一次切青蛙腿的过程中，发现了生物体存在电现象，经过一系列缜密的实验，11年后，他才公开了自己的发现；

+   3. 伏打认为生物电并不存在，只是两片不同的金属在导电的液体内产生的现象，他还根据这个想法做出了人类历史上第一个可以持续产电的电池，名字叫：伏打电堆；

+   4. 关于青蛙是否产电的问题，最终的答案是：死掉的青蛙不会自己产电，但是活青蛙确实能产一种特殊的微弱电流，青蛙的身体也是借用了这个机制来控制腿部活动。

伏打电池（Voltaic cell）：人类历史上第一个能持续产电的电池。1800年，意大利物理学家亚历山大·伏打伯爵在伽伐尼的青蛙实验基础上制作出来的。
