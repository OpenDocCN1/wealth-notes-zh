# 有史以来最大的动物

24米长可算不上是大连鲸，真正的蓝鲸，体型要更大、更长。真正的蓝鲸，可能长到 30米，甚至比这更长。目前，已知最大的动物是蓝鲸，长度可达33米，比国家动物博物馆的蓝鲸模型大出三倍。而且，蓝鲸不仅是最大的，也是最重的，成年蓝鲸最重可达150吨，而非洲象成年只有6吨左右，蓝鲸比象重25倍。

这也难怪，蓝鲸是生活在海洋中的大型哺乳动物，它们的体重全靠海水浮力支持。

# 鲸是怎么小便的？

其实，鲸小便的场景并不罕见，毕竟它们的尿液也是无色的。如果机会去参观，看到鲸鱼排尿，其实也是正常的。

实际上，我们得这么想，鲸鱼的排泄物在海底，会被其他生物吃掉，最后变成营养盐，滋养浮游植物，被小鱼吃掉，大鱼吃小鱼，大鱼又被大鲸吃，就这样循环往复。所以，鲸鱼也是海洋食物链的一环。

科学家发现，由于人类捕捞鲸鱼的行为，导致海洋中鲸鱼的排泄物大幅减少，从而影响了浮游植物的生长，进而影响了整个海洋生态系统。

不过，现在科学家发现，鲸鱼的排泄物其实对海洋生态系统很重要。

# 博物学家养成记

今天我们说到了食物链这个事儿。其实，一种动物可能要吃好几种植物，而植物又吃土壤里的肥料，所以这整个链条其实很长。

+   1. 蓝鲸是生活在海洋中的最大的动物。即鲸类中体型最大的鲸种，也是目前地球上已知的最大动物。
2. 蓝鲸每天排出的尿液超过5吨。这些排泄物中，包括氮、磷等营养物质，对海洋生态系统有重要作用。
3. 现在，科学家发现，鲸鱼的排泄物其实对海洋生态系统很重要，它们能促进浮游植物生长，从而支持整个海洋食物链。
