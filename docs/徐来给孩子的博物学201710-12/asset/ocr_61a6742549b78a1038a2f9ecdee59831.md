# 徐来

金子是个好东西，虽然黄金在工业上的使用价值有限，但因为其它天然的一些属性，比如，金子比较稀有、质地柔软容易分割，可以加工成各种形状……所以，它被视为是最重要的贵金属，后来还成了可交换的货币。

如果有人能拥有满满一船的金子——那一定是一件非常好的事情吧？可有一个，做了这样一件看起来非常了不起的事情，而却受到了来自各方的嘲笑。

这又是怎么回事呢？今天我就来跟你讲讲。

# 探险家史密丝

我们先来介绍一位十七世纪响当当的探险家。他的名字叫约翰·史密丝，是英国探险史上非常有名的一个人物。

他今天这个故事的的主角，不过，被嘲笑的人可不是他，你想听怎么回事，你就得耐心地听我说下去。

这个人从一开始就充满了冒险特质。他家乡，本来是个一个比较富裕的农家子弟，是那个当地的贵族里比较富裕的，不过，他对于这个身份很不甘心，开始对外自称是一个古代贵族—史密斯家族的后人，把自己说成了名门之后。

后来，当上了几年学士，像当年其他的贵族、高人一样，又经过了军事和武术的训练，就离开了家乡，到世界各地闯荡去了，他当过作家兼雇佣军战士打过西班牙人，也曾经为奥地利人打过土耳其人，还一度当过海盗。

在亚洲作怪的时候，他被人拐了去，当做奴隶献给土耳其贵族。土耳其贵族又把他给了一位拜占庭贵族。最后，他逃了出来，从俄罗斯逍遥巴尔干半岛，然后再进入北非，花了很长很长的时间，才回到英国。

因为这样的传奇经历，史密斯成了名人，并且加入了当时英国的一个殖民机构—伦敦弗吉尼亚公司的殖民计划，并且接受委任，进入了所谓的殖民地的管理层里。

接下来，他就带领这个新加入了一个由三条船组成的远征船队，这也是伦敦弗吉尼亚公司的一次殖民远征，远征的印象是20年前由英国探险家命名的弗吉尼亚地区。约翰·史密丝就这样开始了新世界的征途。

# “从酋长手里买走”黄金

约翰·史密丝的美洲之旅非常不顺利。他的性格太桀骜不驯，太喜欢冒险了，常常做一些出格的事情，说一些冒险的话，所以一船人没有多少，就被怀雅特闹得支离破碎，直接被船队的领导给撤销了船长令。

纽波特看起来真的是很不喜欢史密丝，他甚至还一度以叛乱为由打算杀掉他，但考虑到史密斯身上的任务，倒不敢轻举妄动。

不管怎样，纽波特司令带着三条船，还有被五花大绑的约翰史密丝，到了新大陆，在第一趟准备在弗吉尼亚登陆的时候，受到了当地弗吉尼亚人的袭击，不得不改变了登陆地点，并且选了一个地方驻扎了下来，这个地方，很快发展成了一座城市，被称作“詹姆斯镇”。
