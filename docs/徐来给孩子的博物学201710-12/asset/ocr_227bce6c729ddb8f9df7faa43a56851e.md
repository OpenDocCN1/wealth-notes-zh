# 为什么笑的时候肚子疼？

![](bbox=[0.2, 0.078, 0.8, 0.105])

徐来

这笑啊，下次你笑的时候可以试着把手挡在嘴前感觉一下，这样一来，你就会发现笑的时候嘴里吸出了好多气——也就是说，需要交替快速地吸呼气。然后用手摸一下肚子，你会发现肚子在快速地蠕动。

人在深呼吸的时候需要用到手上的肌肉来向上挤压肺泡，如果你持续大笑很久，这些肌肉就要做很多运动，短时间内剧烈运动当然会疼啦。好在，这种疼痛不会有什么明显的害处。

我孩子苏子蕙嘉问：为什么昆虫翅膀边缘都是弧形的？

![](bbox=[0.25, 0.17, 0.75, 0.205])

徐来

这个小朋友问的其实挺特别的，苏子蕙嘉，小朋友，你在里面提到的问题，昆虫翅膀是弧形而不是尖角，有两个原因。

第一个原因是：这样的形状很简答，很容易飞。你玩过圆形吗？揉面团的话，它自然也会变成圆形；如果你要让它有棱角，那就得手动压出来。生物也是这样，活组织生长成弧形的样子是比较容易的，长棱角就比较难。

第二个更多地方的弯曲比较结实。弧形的边缘对很多地方的弯曲程度相差不多，受力也比较均匀。而如果是尖锐角，别的地方都是平的，就特别棱特别尖，那么这个尖头就很容易被折弯或者碎裂。如果你坐过飞机，注意观察一下飞机窗，你会发现它的玻璃都是圆角，早年，那里没有圆用角的飞机，还因此出过事故呢。

熊或北极熊，为什么吃鱼的时候不用吐刺？

![](bbox=[0.25, 0.3, 0.75, 0.33])

徐来

其实，哺乳动物都是能消化鱼刺的，人也是一样。这是我们胃酸的一个重要功能，所以，如果我们的鱼刺直接吞到肚子里，那是没关系的。注意，这是说你刺直接进入到我们的胃里面，那如果在进入胃之前，鱼刺卡在喉咙里，那就有危险了。

但是，熊吃鱼不会有这个问题，这有好几个原因。

一个是熊吃鱼的时候，就是如三文鱼，它们没有刺间刺，即鱼刺就是刺肉之间的刺，也就是我们平时说的小刺。

另一个原因是人的体积大，嘴咬的肌肉也更发达，刺不容易吐掉。还有，熊吃鱼是不吃的，经常大块直接吞下去，刺包在鱼肉中间，也不容易卡刺和刮伤喉咙，但你不要学它们，人吞不下去这么大的块，对小朋友来说，还是去咬那些剩下的、比较安全的部分，少吃鲤鱼之类刺多的鱼，或者在吃刺多的鱼的时候，要千万小心些。

在这里还要强调，鱼刺卡喉咙的话，喝醋、用强头硬吞这些方法其实都没有用，还是及时去医院找专业的医生去取出来。

我孩子儿朵朵问：猫或者狗为什么晚上眼睛会发光？

![](bbox=[0.25, 0.43, 0.75, 0.46])

徐来

猫和狗的眼睛不会自的，自己发光，但是它们的眼睛里有一面特殊的镜子，就算用很弱的光源照它也会变得很亮，就像自行车后面的反射灯一样，看上去好像是发光一样。这个镜子叫做“镜层”。用相机开闪光拍照或者手电筒照的时候，尤其明显。

其明显的作用是反射到猫眼里的光线更多地反射到视网膜上，让猫狗自己在黑夜里面更好地看到，在猫科动物这里来说，它的眼睛是进化上的意外，自然界很多事情都是这样的意外。

人为什么看到重影？

![](bbox=[0.25, 0.525, 0.75, 0.555])

徐来

我们看到的东西，每个点都在发反射或者正在反射，这一多光如果不小心的路径非常接近，大脑这时候都能把这些点分得清清楚，形成一个干净、清晰的图像。如果哪两个小光犯了一些错，那就会产生重影了。

最常见的重影有两种，一种是两个眼球之间没有对齐好，让两个视网膜在双眼中间，很容易看见这种的重影。

另一种是指自己的形状太过对，比如近视眼镜看到的重影，又比如，如果你在游泳中睡觉压到了眼睛，也会有这种情况。
