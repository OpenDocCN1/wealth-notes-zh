# 生态学家：人类「模拟生物圈」为什么失败了？

世界之大，有许多的事情每天都在发生，我们一起去看看吧！

+   1. 生态学家：人类「模拟生物圈」为什么失败了？

在像我这么小的城市，美国的科学家开始了一个规模很大的试验，叫生留2号。简单来讲，就是造一个巨大的人造环境，把各种动植物、微生物放进去，再把人也放进去，再把大门给关上，让里面的人，各种生物，自己过一个儿的，看看能成功吗？

什么叫生留2号呢，那在哪里里呢，其实，生留1号就是我的地球，而生留2号，就是一种人造自然生态系统的试验。

这一试验看起来很有意义，也很重要。所以，当时很多人都对这个试验寄予希望，希望它能对某种星球（或者为人类想要去太空，或者进行星际探索、宇宙殖民提供思路。不过很可惜，生留2号的试验失败了，而且败得很惨，今天，我就是要来跟你们说说生留2号的故事。

# 一项大胆的试验

在美国的南部亚利桑那州，靠近墨西哥边境的地方，有一些很大的城市叫图森，没有77号公路往北，往北走，不到200米，就看到了一个只有8千人的城市，叫做图森。一到那里，首先看到的是荒漠，往北走，一眼能看到沙漠的地平线，那里设计得很有现代感白色的房子，那就是生留2号。

生留2号最初是一个环保组织倡议建立的，这个环保组织的负责人做点儿有点儿激进。所以，他提出的项目，听起来也有点离谱，有点儿疯狂的想法。人类设计和建造一个完全独立的人类生命维持系统，这个系统能够独立运转，可以为地球人提供试验场地，也可以作为地球万一遭受灾害时人类的庇护所。还可以为科学家提供一个很好的研究自然生态系统的试验场地。

在当地一位富豪的资助下，这个项目就这样建立起来了。

试验的场地非常大，总体积有18万立方米，里面造了好多不同的环境，有热带雨林、有海洋、有沙漠、有非洲稀树草原、当然，还有大片的水域。在这种一大片区域里，建设者们还放进了4000种生物，其中有动物，有植物也有微生物。试验人员在里面可以种植水稻和西瓜，能饲养鸡、羊、猪、猪这些，他们甚至种了多水果来吃。一切都看起来很相当不错的样子。

1991年9月26日，8位试验者进入了这个巨大的封闭试验站。他们将在这里生活两年半。从原则上来说，在这两年半里，没有人可以进去，也不会有物资被运送进试验场。

# 生态崩溃了

原本所有的动物都很好，自己养的动物可以吃自己的粮食，自己种菜的人家可以种自己的粮食，呼吸的水是循环利用的。呼吸的水气可以循环利用，接下的两年半里发生的事件，出乎每一个人的意料。

比如，为了让试验者能够自己处理稻谷，做成可以吃的粮食。一开始，试验台在设计时里面放了2台脱壳机。然而，仅仅10天出头，一位试验者就破坏了机器的时候，不小心把手指给卡进去，而他指的一些部分直接给断了。随后，他们就不再生留2号，去处理稻谷，又在不到三个月后取消了生留2号。这也让这次试验蒙上了阴影，甚至有些人纷纷说品，她返回的时候，是不是还挟持了补给品……

接下来发生的事，就不可收拾了。首先是食物。在生留2号里，他们一共植入了8种农作物，包括粮食、蔬菜和水果。这些作物被他们的主要食物来源。然而，由于种种因素，比如生留2号里是热带雨林。

温度明显过高，不像两个沙漠。热带雨林里也没有按照预期的发展起来。设计者们在这里种植了300多类作物，很多作物作为雨林里的防护林，很多准备用植物。但是，这些花长得太旺盛了，甚至还压制了树木。结果原本得不到光。

接下来，它们面临着的问题越来越严峻。它们对环境敏感，更容错性。鱼在池塘中繁殖速度太快了，很快，鱼群超过了水域的承载能力，开始大量死亡。原来水生的昆虫和昆虫的繁殖速度也不够快了，很多昆虫也全部都灭绝了，消失了不见。与此同时，蚂蚁和蟑螂变得越来越多。有些蚂蚁甚至开始承担一部分清洁植物授粉的工作。

然而，这些都不是最痛的事情。
