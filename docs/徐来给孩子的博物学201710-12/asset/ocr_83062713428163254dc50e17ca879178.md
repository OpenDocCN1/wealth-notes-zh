# ## 球藻最初叫山羊毛

看到这麽可爱的小玩意儿，你想问的第一个问题肯定就是，这是什么东西呀，叫什么呀？嗯，它的名字，挺没有想象力的。它属于藻类，又是球形的，所以就叫做球藻。真的是东西如其名，是不是。

说到藻类，我可要多说一句。一说到这个藻类，你想到的首肯先是海洋里这样的可食用海藻，其实，藻类有很多很多种类，彼此之间的关系也差得很远。而且，虽然我们说一般说的藻类是指藻类植物，但实际上不属有很多名字里有藻字的生物，它们既不属于动物也不属于植物，而是属于其他的门类。比如有些两栖的“藻”（气绿？）！为什么说带有“”号的时候，我就提醒你了蓝细菌，蓝细菌还有一个名字叫叫蓝藻，它就不是植物，而是一种细菌——你的爷爷奶奶、外公外婆有可能会吃一种叫螺旋藻的东西，它其实就是一种蓝藻。

所以你看，生物的分类方法真的是一门大学问，可千万不要望文生义，光靠一个名字就下一个东西下判断。

好，我们说回头球藻。这个物种，在地球上生活有说名其多，发现得也不算晚——大概在1820年前后，有一个奥地利博物学家名字叫伯拉夫，他在现在奥地利布利亚尔多这个名字的一个小城市的湖边，发现了球藻这种植物。又过了几十年，有一位植物分类学家，给他确定了学名儿。

生物界里，各种学名的命名，是用欧洲的一种古语言——拉丁文来记录的。这个学名直接翻译成中文，意思是羊毛毛或者是像羊毛一样的，这就有意思了，球藻最大的特点，明显就是一个圆溜溜的毛线球，怎么不直接给它叫成球藻，而要说成是羊毛一样的藻类呢？

# ## 球藻有三种生长形态

其实这也得不得当时给球藻起名儿的分类学家，因为，在那个时候他所看到的球藻，确实不像球，而是在石头上长成了一片片，像山羊的羊毛一样的。

又过了几十年，一位日本的植物学家叫川上泷弥，他发现了这种藻类植物会在湖底生长成绿色的毛茸茸大球。当时，川上泷弥是在日本北海道的东部，一个叫叫伊良的地方做考察。你听这个名字就知道了，这个地方一定是非常的冷，天气冷，湖水也地常冷凉。可是，就在同类的湖底，却存在着大量的聚集成大绒球的球藻。虽然在湖边的人们很早就知道，湖底存在这种神奇的毛球，但是川上泷弥才用最新最严谨科学的方法，把这个有趣的现象报道出来。到那个时候，人们才知道，原来山羊羊毛真要该该被称为球藻。

不过，也不能因为这个就指当场把球藻命名为山羊毛藻的人，植物学家们过了很久才弄明白，原来，球藻有三种不同的形态：

![](bbox=[0.1, 0.88, 0.9, 0.92])

第一种形态，就是它最早被发现时的山羊毛状态。这个状态下的球藻，通常都是附着在光滑的岩石上，晒不到太阳的那一面；

第二种形态，是漂浮在水里的散状的像是丝线一样的水藻。在大多数情况下，它们不会单独聚集，而是聚集成一个球，积蓄到大了，甚至会直到湖底，给湖底铺上一层绿茸茸的藻类垫子；
