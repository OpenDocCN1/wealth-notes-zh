# 演化动物学 | 岛上的大象是怎么变小的？

世界你好，奇妙的事情每天都有，我们一起来发现吧！

你听过希腊神话故事吗？比如宙斯的故事、赫拉克勒斯的十二项功绩、普罗米修斯盗取火种……希腊神话对西方文化的影响非常大。在学习西方博物学时也会接触到很多以希腊神法人物或者事件来命名的东西，比如之前跟大家讲天文学和星座故事的时候，就接触过很多这样的名字。

除了神和英雄之外，希腊神话中还有很多其他的角色，比如独眼巨人。这些独眼巨人身材高大，性格暴躁，脸上只长了一只眼睛。古代希腊和罗马的很多文学作品里都提到了这种半人半神的怪物：它们生活在地中海中的岛屿上，威胁着往来的商人和水手。

然而，科学家们发现，这些独眼巨人很可能不只是人们虚构出来的神话角色，而是在历史上真实存在的物种，这又是怎么回事呢？咱们今天的故事，就要从独眼巨人讲起。

# 岛屿侏儒化

当然，说独眼巨人曾经真实存在过，并不是像神话里面描述的人形事情客观存在、真实发生。而是科学家们发现的是另一个情况，那就是在地中海中发现的另外岛屿上，发现了史前大象的化石。这段神话中描述的独眼巨人与其相似。

那是1914年，有一位古生物学家叫奥宾尼奥尔，他在当地土语的译名中写作（奥德贝尔），开了一个很妙的脑洞：这部作品里提到的独眼巨人，会不会就是那些地中海海岛的史前大象！

等一下！不是独眼巨人啊，跟大象有什么关系？其实，只要看一大象的大头骨，你就能立刻想到明明白白了。在很多博物馆里，都保存着大象的骨头，但更多象骨头的位置，有一个巨大的洞，看起来非常像是象鼻的一个当道，这正是与鼻子相关的、它的眼睛当道在洞两侧的位置。这个洞连接着其大当道大鼻子的通气管道。

![](bbox=[0.2, 0.68, 0.8, 0.8])

如果把大象头骨正面的那个洞看成眼窝，确实很像有‘独眼巨人’的头骨，更重要的就是，这些生活在地中海岛上的史前大象个头比我们现在看到的更多一些能够活到39 米长，非洲象都会在头骨上面能估计只有1米左右。体重估计在100公斤上下——如果把它想象成一头人的话，那么也就是普通人大象大个儿的头，把它的头骨当成正面的独眼巨人的头骨，似乎就很‘合理’。

不过你会不会觉得疑惑呢，明明叫‘大象’，为什么生活在地中海岛上的这些大象，却如此之小呢？

科学家管这种现 象叫‘岛屿侏儒化’，意思是，动物从大陆迁移到海岛或者缺谷去种与外部相对隔绝的环境生活中，它们的后代 会变矮变得小，而原来生活在大 陆上的同类动物，就像是倒在水池，除了大象之外，生物学家们在水牛、野牛、老虎和 狮子身上也观察到在这种情况一起甚至有一种生活在岛屿上的古人类，身材也要比我们矮小许多。
