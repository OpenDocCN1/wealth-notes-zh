# “用进废退”的理论正确吗？

有人说，穿不穿秋裤，不只是你冷不冷的问题，它还有一个更大的影响，你知道吗？穿秋裤会让我们退化，人类依赖秋裤保暖的状态，会这样一代人代替下一代下去，并且总会退化。人们就一直在严惩之中正常生活能力。据说，这个理论最早是苏联的一个非常著名的遗传学季米亚科伊发现的。

秋裤真是有这么大影响？其实，这个说法只是一个人所写文章的一部分，不会削弱人们抵御寒冷的能力，对秋裤的依赖，也不会遗传给我们的后代。但这个玩笑背后的思路，还是值得一说的。

这个思路，如果总结成一个词，叫做“用进废退”。用进就是，身体某方面的功能或着某个身部位，你经常使用的话，那么就会进化，使之更好。满足固定使用的目的，如果总是不用，就会退化，慢慢就消失了。

这样的想法，在古位中就非常早了。在古代希腊，有一位非常了不得的大学问家，叫亚里士多德，他就提出过类似的观点。

后来，这个观点也被普遍地接受。到了达尔文的时代，这已经成为一种社会共识了，大家都这样认为。达尔文本人也没有对此做过反驳的说法。比如达尔文的一位，还有一位很厉害的进化理论者，名字叫做拉马克，他发现了这种用进废退的观点，把它和遗传学联系在了一起，他甚至认为动也好，植物也好，如果在生长的过程中因为一些外力，而导致了某种结果，那么这种结果是有可能会遗传给自己的后代的，按照这个理论，如果一个动物，比如老鼠，比两只老鼠，再给它们生小老鼠，然后，再把小老鼠尾巴剪断，再让小老鼠生小老鼠，就这样做，做上几十年，这些老鼠尾巴就会越来越短，直到全消为。

这一说法当然是很荒诞的。这种荒诞的理论，却在很长的一段时间里，在一些地方成了主流理论。这件事儿还挺可怕的。

# 李森科选择了一些的错误

导致这种情况出现的那个人，恰好就是我开始讲到的李森科。这个名字听起来很像中国人，实际上，他不是中国人，而是一个苏联人。准确地说，是苏联的一个遗传学家。我前面也说过很多关于动物的故事。记得，苏联的、动物学家、动物或者植物研究的人，这个李森科，他是个种植学家。

你可别小看这种子，李森科出身于农民家庭，种麦子种的很厉害。靠着自发的努力，解决了当时苏联小麦生产中的一个关键问题。对小麦进行一些处理，这样它就能长得更好。因为当时苏联的农业生产非常困难，所以这个发现很快就受到了国家领导人的关注。李森科也因此成为了非常著名的科学家。

不过，问题在于李森科并不认可此前的那些遗传学家。像孟德尔，摩尔根，他们所做出的重是发现，他们反对的，是拉马克的学说的，拉马克的理论，对小麦进行的处理，产生的效果有可能会遗传下去。如果得到了这种遗传的小麦进行回交，那么两次处理的效果会加在一起，那就更明显一些。这种更明显的效果，也可以是遗传下去的。

李森科觉得，这一件事更好，这样一来，不用很快就能培育出更好的小麦品种来了。李森科开始带人加搞科研。

他自己忙得呼啸呼啸的，也没有比别人闲着。他本来，所有人都向自己学习，按照自己的思路来实施。有的科学家，就看不下去了，对苏联大家说，李森科的这路不好使。对遗传学认识是错误的，这种类似于“吹毛求疵”的所谓的特点，根本不能遗传给下一代。所以，大家要是跟着李森科的思路走，那就是在撒播误工。

听到这样的论调，李森科生气了。他绝对不听其他人说话，这样评价自己的工作。于是，他利用自己在科学领域内的领导地位，开始向其他科学家施加压力。一方面，遗传学理论，孟德尔、摩尔根那一代科学家的工作不讲了，国际上在分子生物学方面最新发现，也不许大家去关注。在教科书里把这个理论给去掉了。另一方面，他强烈打击那些不支持他的科学家。很多家，因此被关闭。有的甚至被迫逃到了国外。

# 受到影响的不可小瞧苏联

更重要的，因为苏联的重要影响，很多国家的学人界都出现了类似的情况。遗传学家也被迫支持李森科的观念，否则不同意，就会受到非排斥、去掉了。甚至面临更严重的处罚。

很多很多年之后，这个错误才被纠正过来。拉马克的观点并不是生物进化的事实，李森科的观点只是一种政治活动，跟科学是毫无关系。然而，这一切来得有些晚，包括苏联在内的这些国家，分子生物学的发展至少也推迟了几十年。
