世界好友，奇妙的事情每天都有，我们一起去发现吧！

前两天，是我们家小朋友过生日。我送给他一台小型显微镜，作为生日礼物。虽然只是一台小型显微镜，但是它跟一般照相机一样，配备了不同倍率的物镜，当然也可以自己动手制备各种标本。

这时候肯定有读者在问，显微镜现在的人还不是难。要知道，三四百年前的科学家们所用的显微镜那真是跟现在的小放大镜手上的这一台——在近代历史的记载里，这样一台镜子不仅要求放大本领高，清晰度也要达到一定的高度，但当时的人们并没有足够的技术，清晰度也远没有这么好。

那么，显微镜到底是怎么来的？这里头有很多好玩儿的事情。今天咱们就来说说显微镜吧。

# 透过“小窟”看世界

其实，古代的人很早就发现了显微镜的前身。在自然界会有一些透明和半透明的石头，它们被大自然打磨成扁扁圆圆地形状。这样的石头可以磨成烧平磨圆。而不透明的物质，放在眼睛前面，透过它去看，会发现，世界变成了另一番样子，有的东西变大了，有的东西变形了，有的形状也变了。

古代人，发现，有石镜，也有水镜。最早，人们是用水和冰制成放大镜，水镜可以制作各种形状的，冰镜则只有球形的，而冰镜的焦点极近，无法用于观察。人们发现，水晶等透明矿物磨制后效果更佳，而玻璃镜片则更加轻薄、透光，且易于加工，于是玻璃迅速取代了水晶。

人们发明了一部叫做“显微镜”的机器，它是把两个透镜连在一起，一个负责放大，一个负责聚焦。通过它，人们看到了肉眼看不见的微小生物。

# 列文虎克的秘密

后来显微镜也慢慢复杂了，比如1665年，列文虎克发明了“单镜显微镜”，它只有一个镜片，却能放大300倍。它比之前所有显微镜都小巧，价格也便宜，很快在科学界普及。

![](bbox=[0.1, 0.58, 0.4, 0.72])

这个显微镜上那个玻璃镜片，当时是通过手工打磨的方法做出来的。能把它磨成完美的半球形，实在不容易。

但是有一个人的做出了突破，他叫列文虎克。列文虎克是荷兰人，他发明了单透镜显微镜，比之前复合显微镜放大倍数更高、视野更清晰。他观察到细菌、红细胞、精子等，被誉为“微生物学之父”。

![](bbox=[0.1, 0.84, 0.45, 0.92])

为什么那么伟大？就因为他能制造出小透镜。他一生磨了400多个透镜，小的只有针尖大，却能放大200-300倍。他不仅看微观，还看宏观，看鱼虾、昆虫、植物，甚至用显微镜看星空，发现木星有卫星。

# 显微镜的大发展

借助自己发明的工具，列文虎克看到了很多自己想象不到的东西。比如，他发现了“微动物”——现在叫细菌和原生动物。他还在显微镜下看到了血管里的红细胞，这是人类第一次直接看到自己的血液细胞。

方法没发明，但至少在列文虎克的年代，复式显微镜还在萌芽。比如1670年代，罗伯特·胡克出版《显微术》，展示了他用复式显微镜观察软木细胞，首次提出“细胞”概念。

现在是，我们除了这种通过光学手段观察事物的光学显微镜，还有更有复杂更精密的其他类型的显微镜，如电子显微镜、扫描隧道显微镜等，能观察到更小的结构，甚至原子级别。显微镜依然是科研和医疗不可替代的工具。
