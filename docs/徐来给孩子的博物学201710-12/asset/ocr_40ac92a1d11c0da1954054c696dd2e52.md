# 博物学家养成记

如今，随着技术的发展，越来越复杂的心脏手术都变成了可能。医生们现在甚至可以把一个人的心脏移植给另一个人一一而 这些伟大的成就，正是这样一点一点积累 下来的。你想不想长大之后也参与到某一 项伟大成就的积累过程当中去呢？

+   1. 心脏是帮助我们保持体内血液循环的器官，最开始，被称为“外科之父”的比尔 罗特认为，心脏是无法接受手术的；
2. 美国医生塔西格和布莱洛克完成了最早的心脏手术，通过打开血管的方式，帮 助一些先天性心脏病的患者提高肺动脉的供血 量，减轻痛苦；
3. 为了解决血液循环的问题，医生们通过降低人体温度，以及体外循环装置，来 保证手术期间的人体正常机能。

心脏手术：因为手术需要没有血的手术 视野，因此心脏手术十分困难，一度被 认为是禁区。20世纪，美国医生塔西 格和布莱洛克完成了最早的心脏手术。
