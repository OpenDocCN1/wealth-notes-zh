# 生态学·植物丨森林里的植物是怎么争夺阳光的？

世界好友，奇妙的事情每天有，我们一起发掘吧！

"万物生长靠太阳"这句话，你一定听过吧？跟着所有的俗语走，这句话实际上也含点儿夸张的。准确说太阳，对地球上绝大部分的生命体来说，它们是阳光中直接或间接的获得能量，归根结底，都是太阳给予的光源。

听到这里你可能就会想了，既然所有生命的生长都直接或间接的依赖太阳，那么，太阳光照是否越多越好呢？

我当然，这就是我们说植物合太阳的关系，以及这又关系也造成了怎样的森林奇迹。

![](bbox=[0.1, 0.21, 0.9, 0.32])

阳光太厉害了，有些植物怕它

首先，太阳光也不是越多越好的。

如果你的爸爸妈妈、爷爷奶奶或者你外公外婆小时候种过一些盆栽，你或许可以问问他们，种过植物，太阳光是不是越多越好？他们也会说，有些植物不仅喜欢晒太阳，甚至会被晒到枯死，比如我们养的多肉、网纹草、红掌，这些植物在得到充足的阳光后，反而容易晒伤。

所以，确实有些植物受不了太强烈的阳光，喜欢待在比较阴暗但不是完全黑暗的环境里。

这个很好理解，你一到太阳底下，晒一会儿，浑身都热乎乎的，要是更久的话，早就浑身是汗了。这是因为太阳光拥有能量。

凡是能量的东西，多少都有点破坏性，比如你拿打火机来取暖或做饭，但是，如果你用火太久了，会烧成炭。太阳光也是类似，里面最危险的一个东西是紫外线，紫外线看不到，但是，能量高，可以破坏生物体上的细胞。破坏，会带给人类的表皮影响，所以，大家晒太阳的时候要记得不要晒太久。如果因为某种原因，晒着太阳，那么也要涂好防晒霜。

太阳光给生物造成另一个危险，是阳光直射带来的高温，会加速水分的蒸发。所以，如果你在这种环境里，一定记得多喝水。而且尽量寻找直接暴晒在烈日下活动。

所以，如果家里光照环境不好又有一些植物的话，那么种植一些不太喜欢阳光的植物，是一个很好的方案。如果它喜欢阴冷的地方，那么我们可以把盆栽放在室内，避免被太阳光直接照到。可是，室外的环境，太阳光又没有屋顶，又没有墙壁，这些喜阴的植物，一年到头也生活在黑暗里呢？

答案很简单，它们生活在森林的树荫底下。

![](bbox=[0.1, 0.88, 0.9, 0.99])

森林里，有些植物喜欢往高处长

说起来，你见过的森林吗？我说的不是公园里的小树林，是高大茂密的森林。自然界的森林，和人工的树林是有些区别的。比如你去一趟自然的森林，就会见到，越往森林的深处，阳光就少越。真的，森林很深的地方，阳光是找不到地面的。最危险的森林，是北美洲的红杉森林：那里的参天大树，树木高达百来米，顶上的叶子比阳光过得亮死死的。

为什么森林里很难见到阳光，为什么参天天大树长成这样？答案很简单，当然是为了争抢阳光。

阳光虽然有破坏力，但毕竟是能源，能量多才什么都是好的。所以，对于很多植物来说，都是希望能尽可能多获得阳光的，为了满足这些，又能避免伤害，很多植物想到了对抗太阳光的办法：涂防晒霜、多喝水，以及人类的做法——打一把大伞，让这太阳光照不下来。植物的目标虽然类似，但是确需要靠自己完成：它们先合成一些色素来保护自己免受紫外线伤害，其次可以吸收过多的水分，保持稳定，第三点就是，如果环境干燥，会停止进行光合作用，让工厂停止工作。

土壤中，水是一个植物自己无法解决的外来的，就算再怎么快活，要是天不下雨的话就没有办法，只有雨水不断的供应地方才有条件长出森林，不然就长一些小矮的草。

反观，如果水够喝的话，那有植物就开始动用一种阴险的招数了，他们把自己叶子的枝节到云上去，就抢阳光去遮光，而留给它们。这样一来，就把他们给阳光自己的了，被挡住的那些植物缺阳光长不好，就会不和我争夺土壤里的水分了。真是一举多得。

然而，抢阳这个主意的不只是——种植物，它周围的植物也是这么想的，植物之间，只会是一个抢阳，植物没有脑子，不会想这么复杂东西，它们只不过是意识地适应环境。

喜阴植物有喜阴植物的办法

这个办法的结果，就是森林中的，有些树为了竞争光照，长得高了一些长，有些树在理论上，没有太多的意义，比如红杉，大概长10米和长1000米的红杉差别；但是对于1米到10米的红杉，差别就很大了。所以这种竞争会一直持续水或者树的条件下限，比如在世界上能最高的红杉树，竞争光照，说，也只能无限地长高。这个高度是有极限的，大概130米左右，一棵现在活着的最高的树叫北美红杉，它一棵红杉树，它现在的高度是115米。

上面都是竞争的树，上面怎么办？，都被树挡去了，但还是有环境是阳光充足的。最阴凉潮湿的地方对生长非常的不利。为了适应这样的阳光，它们叶子非常大，能用“材料”制造出最大的吸收面，而且从土壤里挖出下很多叶子，所以喜阴植物一般不缺土壤养料，也能充分利用它来增加自己的能量接受率。

看到这里，咱们再回过头去看看那些阴的植物，不管它是红掌，绿萝，还是吊兰，它们都是一个样子，它们的叶片非常宽大，都是为为了它能接受林下很少见的阳光，保证自己的光合作用。

最后，当然还有些根本不需要阳光的生物，就是蘑菇之类的菌类。森林里的下面是它们的天命，它们不需要光合作用，只要有足够的腐殖质，它就可以分解腐殖质，从中得到自己需要的养料。森林下层多，有机物质多，所以蘑菇最好的地方就是森林地面了。
