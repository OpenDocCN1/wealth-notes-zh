# 学画画的化学家

巴斯德是法国一位非常非常重要的化学家和生物学家。

法国历史上出过两个很厉害的皇帝，叫拿破仑。第一个点儿就是整个欧洲给他统一了。巴斯德的爸爸就给在拿破仑的骑兵部队里当过兵，打过仗。后来呢，不打仗了，他想回国当个军官，可惜他没那本事，钱没挣到，也没有得到好的差事，最后只能去给巴斯德家当个下人。

巴斯德小时候，爸爸对他很好，给他请了很棒的老师，所以他成绩也很好。但是呢，他有一个毛病，特别爱画画。他画的画特别好，经常拿去展览，大家都说，画画的巴斯德比学化学的巴斯德更有名。

后来，巴斯德长大了，去上大学，学的是化学。化学系有个教授，特别欣赏他，经常找机会夸他。有一次，教授对他说：“巴斯德，你的画画得太好了，你应该去学画画，不要学化学了。”巴斯德说：“教授，我还是喜欢化学。”

不过，巴斯德也不是没碰过壁。他第一次参加研究生入学考试，没考好。第二次，还是没考好。那时候，大家觉得画画好的人，理科都不怎么样。

但是，后来他坚持学化学，终于毕业了，还拿到了化学学位。再后来，他做了很多很重要的研究，比如细菌理论、疫苗、葡萄酒保存法等等。

# 发明巴氏消毒法

巴斯德最著名的发明之一，就是巴氏消毒法。

1864年，有个葡萄酒商找巴斯德，说：“巴斯德，我的葡萄酒总是变酸，怎么办？”巴斯德研究了很久，发现原来是酒里有细菌，细菌把酒里的糖吃掉了，变成了酸。

巴斯德想出了一个办法，把酒加热到50-60度，坚持半小时。这样，细菌就死了，但是酒的味道还是好的。这就叫做巴氏消毒法。

后来，牛奶商也用了这个办法，牛奶就可以保存更久了。这就是为什么现在牛奶不一定要煮沸才能喝。

# 发明狂犬病疫苗

1885年，一个9岁的小男孩，被疯狗咬了。小男孩的妈妈求巴斯德救救他。巴斯德很担心，但还是发明了狂犬病疫苗，小男孩活下来了。
