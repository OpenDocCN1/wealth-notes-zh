# 行为学·动物｜为什么没有人骑斑马？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

斑马大概是动物圈里最常见的动物了，差不多每个动物园都有。虽然谈不上有多稀有、罕见，但是，大家都还挺喜欢这种动物的，因为它们很多都长得很特别，黑白相间。生活中的很多颜色，都能应用到斑马身上，比如斑马纹、斑马线。

不过你发现没有，虽然斑马，长得像斑马的有很多，却都没有人骑过嘛。那为什么没有人骑过斑马呢？或者继续追问一个问题是：为什么中间没有人，大规模饲养斑马，把它们驯服了，利用起来呢？

# 只有少数动物可以被驯化

首先，咱们要弄清楚两个概念：驯服和驯化。驯服是说，某一个动物，在人类的奴役下，它的野性被压制了，开始接受人类的指挥。比如马在驯化的那些动物，那是驯服的结果，驯兽员手里拿着鞭子，动物就先开始先屈服了。驯化，要求就更多了，它需要改变动物的天性，让它们对野营变得温柔听话，在驯化之中，还有一种类属的情况，那就是，不伤害人。也就是可以长期和人一起生活，不伤害人类。而且，饲养它们的时候，所需要的专业知识和专业技术能够减少。

所以，相当部分动物，可以能被驯服，但只有很少的动物可以被驯化，能被驯化的动物就要更更少了一些。美国有一个生物学家叫唐纳德·莫顿，他非常认真地研究了这个问题。他发现，这个问题挺有意思的。人类在20世纪之前的一千多年里，真正成功驯化的大型食草动物，当然也包括一些"食物以植物为主"的食草动物，只有14种以内。

不过，在世界范围内，体重达到一定水平的、生活在陆地上的大型食草动物，至少也接近150种，那剩下的90%都怎么了呢，为什么没有被驯化？

# 可驯化的动物未必可被驯服

戴蒙德经过深入研究，最后总结出了6条核心要素。如果想来驯化某一个动物，那么它必须完全符合这6项要素，缺一不可。

+   1. 第一，饲料越便宜越好。任何动物，包括我们自己，吃下去的东西不可能100%全部转化进自己的体重，这里有一个转化率的概念，每个物种转化率是10%左右的，也就是说，每吃进10斤粮食，会长出一斤肉来。如果你是动物是吃草的话，相当于它吃10斤草，长1斤肉。如果是食肉的动物，情况就变了，要先依靠10%的转化率，养食物草动物，然后食肉动物再以掉去食草动物，两个10%的转化率叠加在一起，最后只剩下1%的转化率，相当于消耗100斤草，才能在食肉动物的身上长出一斤肉来，这效率实在是太低了一一所以，几乎没有食肉动物，被驯化、养成，当做肉制品的来源。

+   2. 第二，生长速度越快越好。不同的动物，生长速度是不一样的，对于饲养动物的人类来说，生长时长可以繁殖的程度越好，因为开始繁殖，对繁殖来说是增加利的，现在人们人工家养的鸡，它们的繁殖周期都可以很简短了，鸡，往多一两年生二生就可以开始繁殖了。山羊，一年多一年左右可以开始繁殖了。相比之下，有些动物繁殖周期都太长了，比如大象，它几乎完全被驯服的程度，大概需要7年时间才能达到，可以繁殖的程度。大象的情况也是这样，它的繁殖周期长达十二三年一没有哪个饲养者愿意等那么久。

+   3. 第三，在圈养条件下能繁殖。圈养就是人工饲养的环境，这一点很容易被忽视，很多人动物，它们的繁殖条件需要是一些特殊的条件，比如生括需要特定的温湿度，还有一些动物，非要在广阔的面积空间来进行一些仪式性的行为。比如猎豹这种动物，人类很早以前就从小打捕猎动物，然后饲养它们，或者作为打猎的助手，但是，人类却始终不能猎豹繁殖，原因很简单，猎豹的繁殖模式非常繁琐，需要在跑遍整个草原时，持续好几次，每年在人工圈养的环境下，根本不可能达到这样的条件。有明确记录的猎豹人工繁殖是1956年才实现的。

+   4. 第四，性情不能太过猛。这个很好理解，太过猛的动物，饲养起来太危险。这是为什么虎熊狮子这样的动物，没有办法驯化的原因。虎熊之类是的情况，它们是杂食动物，吃喝得吃得多，生长速度也还比较快，繁殖模式也不慢，但杂种却对人类的威胁太大了。根本不能大规模饲养，看着很能引起人们的警惕，而那些"看似起来很温顺"的物种，如斑马，非常容易被驯服，比如它们的开始性也异常猛烈，这种动物不太可能对人类造成严重的伤害，它们不会有一个被驯成家上人的，在山谷中，在美国，每年被马咬死的饲养员都要被狮子咬伤的多。所以，即使是猛兽，也可能会危险。

+   5. 第五，胆子不能太小。这个在大型食草动物中体现明显。有些动物，在被威胁之后，紧张程度不是太高，通过聚集成群的方式，寻求保护，这样的动物比较适合家驯化，维羊和山羊就是这样的情况。但但动物，一旦受惊就会变得非常神经质，甚至有些危险。羚羊就有这样的习性，所以，胆子太小，情绪不稳定，几乎也不可能被驯化。

+   6. 第六，必须是群居动物，所有被驯化的大型食草动物都是群居动物，不是成群的，而且群体内都有首领，有等级。这样，人类控制了一个群体的首领，就可以控制整个群体。或者从另一个意义上来说，拥有这种结构的动物，它们甚至可以把人类视作群体的首领，服从人类的命令。
