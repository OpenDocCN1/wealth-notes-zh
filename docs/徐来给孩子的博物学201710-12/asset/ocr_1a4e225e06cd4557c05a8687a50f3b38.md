# 一家出了8个数学家

伯努利一家是瑞士的，祖上出过很厉害的医生，也出过生意做得很大的香料商人，还出过艺术家，总之，人家不是有钱的，有本事的嘛？家族的孩子们是很得体的教育条件。到了尼古拉斯·伯努利这一代，他很想让自己的孩子学习数学，或者干脆跟着自己做医学，可是，他的两个儿子，一个叫雅各布，一个叫约翰，都偏不，俩人特别讨厌学数学，数学学了个，一高兴，不努力，数学家，带着他们的后代开始热衷于数学，最后在三代人当中，诞生了8位了不起的数学家。

这个数学家里面，雅各布和约翰是第一代，第二代里面有约翰的儿子尼古拉第二代、丹尼尔·约翰，以及雅各布和约翰的侄子尼克拉第三（他的爸爸是古拉尼画家）。第三代里有约翰第二的儿子雅各布第三、约翰第三。这个家族有四个名字：雅各布、约翰、尼古拉和丹尼尔。

这一家子之所以出了那么多数学家，跟雅各布的关系很大。他很喜欢数学，而且当上了大学的数学教授，然后，正好赶上弟弟约翰也喜欢数学，于是他们就开始钻研自己的博士生。后来，雅各布的侄子尼古拉第三也做了他的博士生……这真是有点“举贤不避亲”。

雅各布还用到一件非常好玩的事情。他非常沉迷一种螺旋曲线，这种螺旋曲线，叫牛顿螺线。你不管怎么放大它，它还是保留自己原来的样子。我这么的比喻，你不好理解，你可以看下方专栏文章里面的配图，该就是这种的曲线。雅各布很喜欢这个曲线，为了留名，刻墓碑的工作师傅上刻这个曲线，不料，刻墓碑的工人搞不清楚这个曲线那个曲线的，结果给他刻错了。你可以比较一下，这两种曲线的不同。

# 兄弟之间激烈冲突

俗话说，打虎亲兄弟，上阵父子兵。伯努利一家出了那么多数学家，按说，一定是各种联合协作，很团结的家族。可实际情况偏偏不是这样。伯努利家族第一代是9位数学家的约翰·伯努利，可以算是一个数学家当中成就最高的一个了。但又是有人当中口碑最差的一个。

我前面说了，他是哥哥们的博士生，是哥哥雅各布将他领进门的。既是哥哥又是老师，按理，应该对他的学术生涯大有帮助。可是被哥哥领进门之后，约翰的进步却慢得不得了。才两年时间上甚至可以说是不超过哥哥了，又是“没多高”，而他哥哥呢，也当上了大学的数学教授。渐渐的，两兄弟的情缘有点不对劲了。

弟弟约翰很快有点瞧不起哥哥了，“哥，你比我老师，你确实要比我年纪大，但是……你不行，你怎么能比我更厉害？后悔不该进弟弟的圈子，你怎么能比我更厉害？后悔不该进弟弟的圈子。”

那么一来，这一对亲兄弟就彼此看不过眼了，后来得此一举，比如说明一个见解巧妙，另一个说也解释得开，另一个说也解释得巧妙。得后来一吵到不相往来的程度。

但是，俩人吵归吵，还有一致对外的的时候。当时，德国有一位大数学家莱布尼茨，他和另一位伟大的数学家，英国的牛顿，几乎在同一时间亲自独立发明了一种数学学问微积分，这是件非常非常厉害的事，一出现在，所有数学家都关注到了，这么重要的东西，大家当然要来论战发明权了。所以莱布尼茨和牛顿是去了。当时伯努利兄弟看到了莱布尼茨的书，立即意识到微积分的重要性，并且加入了莱布尼茨阵营。他们甚至帮助莱布尼茨完善了理论。

伯努利兄弟的加入，极大地壮大了莱布尼茨的阵营。莱布尼茨们不但打不开交，还使得欧欧的数学家们分成了牛顿为代表的英国派和莱布尼茨为代表的欧洲大陆派。

# 被出售的署名权

老雅各布去世之后，约翰也没闲着。他还是继续琢磨着牛顿，这次厉害嘛，不过，他自己儿子丹尼尔发生了不幸了。不过，他并不是约翰最出名的一点，他最出名的件事是……出售了自己的研究成果。

约翰有一法国同学叫洛必塔。哥白尼，咱们有法国名人史学家记述的这个，他就道了。我之前跟你说的，这是贵族标志。洛必达是个贵族，他很喜欢学，他也很喜欢学，当时也注意到了微积分这个玩意的出现，知道这是好东西，赶紧开始钻研这门学问。后来他甚至写了一本数学教科书，本书介绍微积分的最早的一本书，第一本公开出版的微分学教科书，所以他立刻就火了，成为当时重要的微积分数学家，他有一项名声，因为他是被复制，其首字母洛必达的名字来命名了，称为“洛必达法则”。

但是这本事一书，约翰·伯努利生气的。

他为什么生气？原来，这本书里的很多东西，特别是洛必达法则，其实是约翰·伯努利的研究成果，洛必达买的是约翰的数学史，他自己也知道，所以花了约翰破例的高价给他买了三百法郎，让他讲解数学领域的新颖发现并命名。三百法郎那时候是不小的一笔钱了。

其实洛必达很诚实地在扉页里写了，说这些题目大来是源自伯努利家族，特别是约翰，他特意去联系伯努利，洛必达还是买到了自己的发现。但是约翰还是不高兴，到处与人抱怨，说这本书，自己三百法郎的辛苦是卖，一年花三百法郎买来的？还是把别人的成果卖掉了。虽然他说太不公平，但是人算不如天算叫做洛必达法则了，而后，伯努利不放心，就自己完成了历史学上出卖自己研究成果的最有名案例。
