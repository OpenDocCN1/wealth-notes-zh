# 推薦序
# 投資成長型股票，獲利不再難如登天

暢銷書《我的操作之旅》作者
羅仲良

會認識喬泓是因為 FB 社團的聚會，從交談和後來觀察他 FB 上的文章，發現他的投資邏輯有很多都跟我很類似。因為投資理念接近，所以一些他買過的股票，如佳格、美利達、寶雅、儒鴻我也都有買過，只是其中好幾檔股票他都賺的比我多很多。以前不了解原因，看了他寄來的書稿後我才了解。原來他是從英國投資大師「祖魯法則」的作者吉姆・史萊特身上學到如何運用「本益成長比」這個簡單客觀的工具來計算一檔股票的合理價值，並評估買點。

除了吉姆・史萊特之外，其他投資大師諸如華倫・巴菲特、彼得・林區、安德烈．科斯托蘭尼、威廉・歐尼爾等人的投資理念、策略也對他幫助甚大、影響甚深。站在巨人的肩膀上！難怪他能全程緊抱持股，寶雅獲利一倍以上、美利達獲利 350％、儒鴻更是知名代表作，獲利 560％！創下近 6 年在股市平均年化報酬率繳出 40％以上的佳績！

他也因為在股市裡的傑出績效，由一個只能做對自己而言沒熱情的工作的小美工，變成不為錢煩惱、時間又完全自由的專業投資人。我在工作上一樣賺不了大錢，也找不到熱情，工作上有時更會被追做一些不喜歡的事，我選擇脫困的方法和喬泓一樣，是以基本面投資成長型股票，買股票後不可能每次都順順利利、
