# 青年啊，
要立志、並勇於冒險！

今周刊主編
謝富旭

曾經看過一部內容感覺很「匪夷所思」的日本漫畫，事隔多年，故事在講什麼，已經不記得了，但它的標題卻深深烙印在我的腦海：「嘻！！男塾年輕人啊，要立死志！」。

我一直深深認為，一個國家要強盛、一個年輕人要活出精彩活潑的生命，最重要的前提之一就是：勇於立志，並且付諸行動、勇於冒險！這幾年，台灣的經濟情況每下愈況，社會瀰漫著低迷、甚至是一點絕望的氣氛。年轻人不敢作夢了，甚至連最基本，也是很基本的「發財夢」都不敢作。

這幾年，我在雜誌做過不少理財與投資題，也做過一些理財與投資行為問卷調查發現，現在台灣的年輕人最主要的理財做法是「放定存」，比例一直高達4成以上；其次是「當包租公或包租婆」，比例也大概維持在3成上下，大約僅有1成的年輕人認為投資股票是主要的投資致富管道。
