# 科斯托輔尼給我的啟示

+   1. 別想單靠閱讀圖表預測市場未來走勢，技術分析雖然看起來像是一種科學方法，卻無法帶來知識。交易市場從來不是理性的，股市就像是個酒鬼般，聽到好消息哭，聽到壞消息笑，令人難以捉摸。

+   2. 長期來看，只有固執的投資人會是證券市場最後的贏家，他們的獲利是由熱衷於短線操作的猶豫型投資人支付。投資要成功，就必須當固執型投資人，在眾人搶購股票時從容賣出，當大家心灰意冷時大膽買進。

+   3. 運用雞蛋理論判斷大盤目前的所在位置是否過熱或是冷清，每一次行情的大漲或大跌，都由三個階段所構成：修正階段、調整階段、過熱階段。正確的判斷目前所在的階段，適度加碼或減少持股，對於資金有限的一般投資人，無疑是加快致富速度的好辦法。
