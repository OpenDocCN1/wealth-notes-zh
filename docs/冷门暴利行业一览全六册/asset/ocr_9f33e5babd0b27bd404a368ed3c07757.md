# 深入挖掘高考相关的偏门暴利项目

今年高考又到了，所以咱们来讲一讲与高考相关的项目。

首先互联网有很多项目，事实上都是一直存在的，同样的一个项目，有人能日赚 1k 块，有些人只能日赚 10 块，而真正包含的逻辑到底是什么？

高考过后，那么有很多的某某学院，某某大学的新生群就会建立起来。

![](bbox=[0.13, 0.395, 0.88, 0.685])

这些新生群其实都是可以做项目的，也就是说，你去这一个学校找到相关的群，然后把群名字改为 xx 学校大一新生群，xx 建筑工程系大一新生群，如果你有几千个关键词矩阵在 QQ 上，他们自然而然就会通过主关键词搜索，搜索这一一些主关键词的 99% 都是大一新生或者是学生党，这个是毫无疑问的，都是精准的流量。
