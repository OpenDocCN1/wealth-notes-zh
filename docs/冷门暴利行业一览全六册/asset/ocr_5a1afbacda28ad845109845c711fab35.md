# 农村4个冷门暴利创业项目，下一个“富翁”就是你

农村的发展带来了很多商机，创业成了农村的新热潮，但是问题来了，很多人有创业的想法，但却没有一个好的点子，今天小编总结了几个项目，现在看来可能比较冷门，但这片市场若是打开了，还是能挣不少钱的。

# 一、农家乐

城市和农村各有各的特色，所以并不是只有城市才能发展旅游业，农村拥有独特的美，开一个农家乐，提供农家菜服务，有水的地方可以发展特色垂钓，有种植园的地方可以发展生态采摘园，根据自己当地的特色来决定。

# 二、农产品中介

很多种植户虽然种植的作物品质好，但却因为对外界的接触太少，找不到好的销路，所以这时候就需要一个中介出现了，你可以帮农民介绍销路，也可以与收购商建立合作关系
