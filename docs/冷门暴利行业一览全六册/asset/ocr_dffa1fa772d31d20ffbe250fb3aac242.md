# 零食测评员一个不起眼的冷门行业但很赚钱

小时候，我们最爱干的事莫过于拿着一毛钱买包辣条，吃零嘴对孩子来说简直就是天大的事，宁愿不吃正餐，也要啃一口大白兔糖。

很多人以为长大后就不会那么馋嘴了，然而，事实表明，长大后我们更馋了，因为终于有钱买零食了，可以毫无忌惮的吃零食了。

也正是这样人催生了一个新商机——办公室零食。

![](bbox=[0.13, 0.56, 0.88, 0.84])

五花八门的零食令人眼花缭乱，商家纷纷绞尽脑汁打广告，给零食贴上了所谓的瘦身、饱腹、美容养颜、开胃的标签，然而，真正的效果如何呢？

对真实口味的渴求就成了一个新的需求，这就是我们今天要说的靠吃挣钱的路子！
