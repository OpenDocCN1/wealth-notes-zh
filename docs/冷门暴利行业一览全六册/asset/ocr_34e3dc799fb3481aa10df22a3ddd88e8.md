# 卖燕窝暴力项目

燕窝这个东西不一定每个人都吃过，但一定每个人都听过，对于大多数人来说，第一反应不是它有多美味，而是它有多昂贵。

其实你多花点心思去了解这个市场，你就会明白，燕窝分等级，有货真价实的极品，也有滥竽充数的次品。有时候我又不得不佩服有些人确实很有“生意头脑”有人的地方就有江湖，这句话说的一点也没错。

小编有一个朋友，结婚2年，每天赋闲在家，追追剧，偶尔跟小姐妹出去小资一下，老公很有钱，具体有多少钱我不得而知，但只要这不乱来基本这辈子不愁钱花。

她每个月必定会在某一家网红店购买燕窝，价格几千上万不等，店主是个看起来就非常网红，有气质的女人，年纪四十多岁，但看起来一点也不显老。

其实这个商业模式看起来很高大上，今天给大家手术刀式的解析一番，其实并没有想象中那么难，因为认识圈内很多朋友，就不好给大家举例了，我用一种最通俗易懂的方法跟大家讲这一系列的流程。

首先你要找货源，最简单就是上阿里巴巴，这也是对小白最包容的地方，采购一些价格适中，卖相好看的燕窝。
