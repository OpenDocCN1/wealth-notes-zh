# 偏门生意：真品猫爪杯不赚钱，山寨反而更暴利

星巴克的“猫爪杯”火了，成为 2019 年第一个爆款商品。

![](bbox=[0.15, 0.27, 0.58, 0.62])

星巴克官方售价 199 元的杯子，在淘宝、闲鱼上已卖经到 1000 元以上，只要转手就能翻几倍。很多朋友纳闷为什么一个普通玻璃杯能卖到这么贵，谁会买这种杯子？我告诉你，星巴克限量版杯子的不愁卖，因为它是一种暴利生意。

星巴克是什么？如果你在一、二线城市生活或工作，对它肯定不陌生。但如果不在一二线城市，可能对星巴克并不太熟。星巴克是一家美国的连锁咖啡店，主要卖咖啡和简易西餐。
