# 4、便利店

一个人选择开一家小型便利店也是一个不错的选择，生意的好坏，挣钱的多少关键在于选址。当然现在也可以选择加盟连锁，但坑多。所以，如果一个人找到一个合适的铺面，我还是建议自己可以直接开一家，这样费用会节省很多。这方面我调查了解过，如果一个便利店一天能有 1000 左右的营业额，那就非常不错的收入。
