# 01 什么是石膏彩绘

所谓的石膏彩绘又称为卡通彩绘、立体彩绘、克隆彩绘等，以石膏粉、模具和绘画用品为材料，经过倒模和彩绘制作而成的立体石膏工艺品。

简单来说就是用石膏模具做好石膏白坯子后给大家上色的工艺品，这东西其实不复杂，看起来很具有艺术感，公园、广场、夜市、景区、庙会集市、学校附近都有它们的身影。
