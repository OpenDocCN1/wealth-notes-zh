# 03、牙科医院

别被“医院”两个字给吓跑了，看着好像高大上，一般人搞不了。

说白了就是一个小小的牙科诊所，如果不好办理医疗证件，那么只要有美容经营资格也可以。

这个行业就跟抢钱差不多。一副牙齿成本 80-200 元左右，安装好后收费 1000-2500。这个开店资金不需要太多，主要是资质。
