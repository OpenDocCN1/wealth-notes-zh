# 偏门生意：塔罗牌长期可操作的虚拟暴利项目

其实我最看好的项目，就是虚拟性有增长性的项目。
这类项目有一个明显的特点，就是一个项目，能干很长时间，并且随着时间的推移，能够积累很多资源，赚钱也非常稳定。比如，一天一个微信，加 3-10 个精准客户就可以，我希望第二天也是如此，而不是第二天成了 30 个，第三天成了 50 个，这样的增长对于个人创业者来说，是一种麻烦，因为人太多根本服务不过来，服务质量自然就差了很多。整个项目很容易因为后期服务问题，而全盘弃漠。导致鸡飞蛋打，丧失一部分收入。有人说，你不会雇人来做吗？对于个人创业者来讲，实战在第一线，才能发现总结出很多问题，不断的改善，你才会拥有做大项目的能力和潜质。如果跳过这个环节，肯定是要失败的。毕竟操盘手的养成，可不是简单的用人思维。
