# 揭秘送娃娃暴利项目轻松日入上千

今天偏门分享一个暴利项目送娃娃，做的好的日收入就可以破千，赚钱那叫一个轻松愉快。

不知道大家见没见过，看下图：

![](bbox=[0.16, 0.35, 0.84, 0.66])

不知道大家有没有遇到过，反正小编我小时候挺喜欢来这种地方凑热闹。

游戏规则很简单：拿笔在纸上写阿拉伯数字，从1到500，不写错，不中断，字迹工整，就可以抱走任意一只娃娃，但是如果中间出了差错（比如写错字，或者停顿不写）就必须花钱购买摊主的礼品。

以为很简单吗？那你就错了，据小编的观察，上钩率起码90%，在人不少的情况下，即使摆上这么一天，也送不出去几个娃娃（送出去的其中也包括了摊主睁一只眼闭一只眼
