# 汉服是什么？

汉服是一种中国传统服饰，《史记》上的记载汉服始于黄帝时期，延续到清朝“剃发易服”时结束。唐装、马褂、旗袍等其实都不属于汉服。

![](bbox=[0.14, 0.46, 0.86, 0.74])

汉服包括四个部分：首服（冠、巾）、体衣（服装）、足衣（鞋、履）、配饰（花饰、扇子）等。而体衣又包括小衣（内衣）、中衣（衬衣）、大衣（外衣）等三层，大衣要有领、襟、裙、袅、袖、衿、衽、带、系等要件。
