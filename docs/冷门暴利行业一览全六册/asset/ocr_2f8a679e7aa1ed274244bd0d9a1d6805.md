# 五、照片行业

照片行业经过近几年的发展，现在可以通过互联网实现互联网照片行业，简单来说，我们可以通过技术储存照片，变成各类排版，非常适合现在年轻人的需求，而且照片上面可以添加任何背景、文字，创业成本极低，利润却相当高。
