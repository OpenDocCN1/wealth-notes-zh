一定要送了，但你的送法跟我的送法是不一样的。

# 三：拖住客户当你的活招牌

我既然答应要送，就必须送。不送是自己打自己嘴巴，送，但绝对不是那么容易的送给他，接下来讲的重点，你摆地摊三年也不一定能悟到的，请大家听好：

那么这个叔叔来了，我会说，叔叔你先戴一戴，你带多少度的，他说我戴200度的，我会说，我看你年龄不大，我拿个150度的让你先试试。大家记住，这个并不是让他戴多少度，而是试了150，再试200度，再试250度。

甚至给他说，叔叔，你要不再看看我这个，平光镜看手机的时候也可以看到，让他多试几幅。试了250度，再回头试200度。

为什么让他尽可能停留在摊前，多磨蹭时间，当你的活广告。因为人都是这样的，只要他站在摊前就是活招牌。他就会帮你招揽别人，你摊前就不愁人。

当他试的时候，旁边就有人来了，你就可以做其他人的生意了，该怎么卖就怎么卖。

# 四：让客户配合表演吸引人气

如果这个时候还没有人来，那大叔选定眼睛要免费带走的时候，你再来一招，“叔叔你带200度对不对，我说给你一定给你，我可以给你做个出厂检验，让你看看我这个质量怎么样，我拉给你看质量怎么样”，他肯定说好。
