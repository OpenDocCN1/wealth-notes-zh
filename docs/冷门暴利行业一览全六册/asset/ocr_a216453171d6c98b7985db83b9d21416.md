# 微景观冷门暴利项目一年净赚 40 万

最近，商场中出现了一种新型盆栽店，主要售卖的是微景观盆栽。微景观盆栽相比传统盆栽更现代，更容易被青年人接受。

微景观是什么？

微景观是用植物做出田园风光美景。微景观的花盆一般选择玻璃圆罐，在罐内铺上一层细石，起到储水作用，细石上铺一层保湿透气的水苔，第三层是选择微景观专用土，构成整个微景观的基底。

基底之上是微景观的创意部分。先铺一层苔藓模拟草皮，再用镊子轻轻将狼尾蕨、罗汉松、网纹草和常春藤等植物移植到器皿中，描绘一片茂盛丛林，最后在“景观内”上一一插入装饰品。这样一件“微景观花园”就完成了，对久居城市的白领而言，微景观就是“心的家园”。

做微景观和开店不同

做微景观是兴趣，开店是生意。开店前期需要了解进货渠道，门店客流等。初做微景观店面无需很大，仅需 10-20 平方米就可以开店，租金三四线城市在万元左右。因为微景观店属性更偏艺术范畴，所以店面装修要有一定艺术感，装修费要投入 1-2 万元。
