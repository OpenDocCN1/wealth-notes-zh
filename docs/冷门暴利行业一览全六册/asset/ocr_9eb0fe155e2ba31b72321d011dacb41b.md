# 建议

如果想要长久的运营这类项目，建议你的产品要稍微有点效果，我们都知道像这种治疗类的产品，想要达到自己心中所想的效果基本上是没有的，除非通过物理手段来治疗，那么我们只要保证我们的产品有一定效果，那么他们的复购率也是十分可观的。
