# 揭秘网络暴利赚钱项目之黑链交易买卖

估计很多人看到“黑链”这两个字，就会想到互联网中的黑色项目。其实黑链生意还算不上黑，顶多算是灰色项目。

经营网站的人都知道黑链并不黑。黑链是相对明链来说的。那明链其实你就可以理解为友情链接。我们都知道友情链接在网站中是可以看得到的所以称为明链。反过来黑链就是我们往往看不到的。我们都知道网站是由许多代码而组成的，当有心之人把这些链接隐藏起来，然后在你不知情的情况下，让你的网站上挂上了一个导向他网站的链接，这个就是黑链。
