# 第二个是养老产业

随着我国人口老龄化，未来养老产业一定是一个巨大的蓝海市场，老年群体分为失能不能自理的，和能自理的，那些失能不能自理的交给专业养老机构，咱们普通人不要参与，因为它成本高，风险大。
