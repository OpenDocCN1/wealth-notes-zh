# 现在创业适合做什么（小本投资赚大钱的生意）

创业是人们口中最常提到的一词，目前我国已经进入了全民创业的局面。在很多人固有的思维里，创业是需要花费大量时间与金钱的，没有足够多的钱是无法创业的，真是这样吗？我看不一定。其实在农村有很多小生意，的确不需要很多的投资，就能赚大钱的。

![](bbox=[0.17, 0.42, 0.82, 0.68])

能赚钱的低投资项目有哪些呢？

+   一、甜品蛋糕店

现在很多地方都流行起来了甜品蛋糕店，这种店就跟奶茶店一样，都很受年轻人的欢迎，很多都开成了网红店。甜品蛋糕店不仅仅只卖生日蛋糕，他们更多的是卖一些精美小点心；甜品蛋糕店卖出来的糕点非常精美，口味也很不错，当然了，价格也相当贵，一盒小点心卖 20 多块钱是正常的，有一些爆款甜品，小小一盒 a 卖价就跟一个大生日蛋糕差不多
