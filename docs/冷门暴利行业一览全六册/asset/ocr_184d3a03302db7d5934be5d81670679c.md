# 玄学这门生意到底有多玄？

产品端：

它是一个虚拟产品，看不见、摸不着，而且历史悠久，从古至今一直存在。只要是发生的任何愉快和不愉快的事，都可以拿它来解释。有钱、没钱、婚嫁、疾病……一切问题在它身上找到答案，它可以满足所有“需求”。

关于玄学的产品也没有定价标准，因为成本可高可低，我们通常对一个产品的利润计算=客单价-成本，当这两个因子都没有准数范围的时候，利润自然就很难计算出来了。

流量端：

每一个人从呱呱坠地到仰天长去，基本上每天都在经历烦恼，有解决烦恼的需求，就不愁没有市场了。据统计，2019年就有3亿人为自己算过命，这也只是能统计到的，多数是没上大数据的。注意，这只是一年的统计。

以往我们卖一款产品，总要讲究精准流量，比如脑白金是给老人的，纸尿布是给小孩的，那玄学产品呢？它的客户对象不分层次，老人、小孩、男人、女人，不管你是月入几千的工薪族，还是月入百万的土老板，都心甘情愿地为之买单。

转化端：
