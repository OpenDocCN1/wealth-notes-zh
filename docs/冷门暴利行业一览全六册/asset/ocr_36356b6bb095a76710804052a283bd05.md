+   ① 流量大更新换代也很快，大多数考试都是每年一至两次，考生换代快。

+   ② 流量的需求强烈，目的性强，都是为了通过考试，为了实现目的会产生冲动消费，变现更容易。

+   ③ 该类流量的 QQ 群极多，一个群动不动一两千人，流量都很大，而且加群都容易通过。

# 1 资料准备

这里介绍几种找资料的方法

+   1》直接用 QQ 自带的查找功能，搜索关键字，比如考研、资格考试等字眼搜索相关的关键词，加群后里面就会有相关的资料，然后多进几个这种相关的群，手机资料后进行整理归类即可！

+   2》如果想得到一手的资料那只能通过官方网站去购买。用的比较多的网站基本上是像某东方，某文等一些比较大型的辅导机构，都有二手资料。这里建议大家刚开始起步最好不要搞一手资料，因为成本太高，最好先去找一些二手资料去做。

+   3》就是去某宝找到相关的资料，然后去进行包装，任何项目和产品之所以能够激起顾客的购买欲，靠的都是包装。
