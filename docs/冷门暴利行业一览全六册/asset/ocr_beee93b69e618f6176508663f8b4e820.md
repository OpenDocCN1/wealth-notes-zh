# 现在暴力行业有哪些（5个不起眼但很赚钱的行业）

在国内有很多的行业，有些甚至都是小到你从来都看不起的行业。但是这些行业暴力到你可能根本就无法想象。今天就来盘点一下国内暴力行业。

+   1: 收废品

一说到收废品，大家脑子里想的就是一个人骑着三轮车到处吃喝收纸壳，收电视冰箱彩电的场景。实则不然，我这里说的是那种专门收废品的，有些还有自己专门的废品回收站，他们做的除了做一个中间商将废品卖给其他更高价的地方，还可以收回来的废品进行二次利用。

![](bbox=[0.12, 0.57, 0.78, 0.79])

比如一些电视，冰箱，洗衣机在你手里可能几十上百收回来，自己找人修好再卖成二手的几百卖出去。运气好的一天收废品几千的收入都是很正常的，但是这行业比较辛苦而且一天到晚身上都很脏。所以看起来不起眼。
