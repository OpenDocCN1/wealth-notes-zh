# 二、友情链接的交换

很多站长都有交换友情链接的习惯，友联交换的原则是要权重一样，如果你的权重是 0，你和一个权重 3 的人交换了友联，那么你的网站可能不需要多长时间就能达到 3.友联交换对于低权重网站的权重提升是很大的帮助的，但对于那些高权重的网站没有一点鸟用。因此站长通过刷流量的方式可以是网站的权重在明面上看起来很好看。

# 三、卖站

卖站在网站圈里算是比较常见的变现方式了，一般站长手里都要有十几个甚至几十个网站，一般他们都是把网站养到一定的权重之后直接来选择卖站来实现变现。据我所知一个权重在 3 的网站能卖到 15-30 万左右，这个因网站所在的领域的不同可能价钱差别比较大。
