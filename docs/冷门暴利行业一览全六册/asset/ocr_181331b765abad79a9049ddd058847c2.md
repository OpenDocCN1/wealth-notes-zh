# 五、圈内人士谈利润

小编问，一般收费多少？

对方表示，一般报价 6000 块，先付一半。包含心灵疏导，问题落实，出方案解决，后续跟踪，但如果挽回失败，另一半就算了。

挽回失败率挺高，10 单有 7 单都要凉，后续必须得安慰心碎的客户。

小编问，你们通常每个月有多少成交客户？

对方表示，三人操作，平均每天能开一单。但每月只能分到 4 万左右，随着短视频越来越火，准备单干了。

这操作是不难，但需要有耐心，客户宣泄，要耐心听并疏导，抓住他最舍不得放弃的东西，制造挽回点。

小编问，感情大部分费用是安慰客户，陪着聊天，引导客户自己挽回？听着就像，生女儿秘方，生错了退还？一半成功率？

对方表示，大多情况是这样，看感情基础了。

嗯，优秀。

以上是小编的复盘，很多玩法，外行人感觉，门槛特高，特神秘，其实不然。
