# 暴利又不违法的生意（8个本钱少利润高的小生意）

最近两年，由于我国受疫情的影响，很多工厂都不能正常开工，还有那些零售业、旅游业、饮食业都大受打击，所以我国开放了地摊经济，鼓励有能力、有条件的人可以来依靠地摊经济度过难关。一时间地摊经济就成了人们关注的热点，很多人都摩拳擦掌，购买起了摆摊用品，兴致勃勃的摆起了地摊。

![](bbox=[0.08, 0.42, 0.86, 0.7])

摆地摊虽然看起来很不起眼，赚的钱好像也不多，而且还经常被人看不起，但是摆地摊的优势也挺多的。比如摆地摊成本低，回本快，进货压力小，还有就是利润比较高，门槛极低，唯一付出的就是人工成本比较多，比较累。
