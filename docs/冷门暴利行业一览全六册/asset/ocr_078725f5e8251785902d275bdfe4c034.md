接着说街边收酒的小贩如何赚钱。

# 一、卖给散户

每个地区都有类似的群，群里有各种卖家与买家，只要收到一些好酒他们就会发到相关的群里，根据年份和稀有程度，一单赚个几百几千不成问题。如果要是掺假酒卖，那赚得更多。收酒小贩也有进假酒的渠道，人为做旧可以骗过大 多新手。

# 二、卖给烟酒店

给烟酒店供货也是一大渠道，一些收到老酒的小贩会直接卖给烟酒店，好处就是烟酒店通常一次性购买多瓶，出货量会大一点，不像散户零零散散的买。而且也经常会告诉收酒小贩什么酒比较紧俏卖得好，让他多收点。

# 三、收真酒酒瓶，用来造假酒

收来的酒瓶，卖给造假酒的人进行二次灌装，近些年假酒猖獗，少不了收酒贩子们的“功劳”，当然只在街边收来的量其实还不够，他们也会安排自己的“眼线”，一般都是酒店、餐厅、酒吧的服务员、酒保、保洁。他们一旦发现没有破损的酒瓶就会通知收酒，这种的回收价格比较低。
