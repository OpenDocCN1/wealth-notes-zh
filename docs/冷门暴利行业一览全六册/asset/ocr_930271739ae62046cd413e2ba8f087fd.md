# 第九个快递行业

笔者曾经在大学的时候，就干过菜鸟驿站，一天也能赚个两三百是很轻松的，跟快递公司合作，一个单子的成本在5块钱左右，收价在10-15不等，一天基本能发二三十个快递出去，但是由于各种各样快递柜的增加，菜鸟驿站的找到另外的盈利点，才能有新增的利润，要不然只能维持基本的生活，快递+增值服务一个月万把块钱还是没啥问题的。

# 第八个文具店/文体店

二孩政策开放后，再过三四年，小学生人数即将增长，学生时代文具是必需品，并且不同家庭条件的学生使用的文具档次也不一样，这些东西也是最容易消耗，从小学、中学、大学，一个人的教育时间可以持续一二十年，所以文具用品是必不可少的，所以开这种店也是又不错的收入，我们都能看到学校附近的文具店，没有哪家店是因为没赚到钱而倒闭的。
