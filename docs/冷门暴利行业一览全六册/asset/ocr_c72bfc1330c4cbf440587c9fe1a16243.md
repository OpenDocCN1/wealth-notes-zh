# 01、石头雕刻、篆字

人的一生生老病死很正常。人去世了，后人都会想着给他们，立个墓碑以作缅怀和纪念。

这无论在城市还是在农村，都很正常的做法，以表对先辈的尊敬和墓志。

光荣榜、芳名录榜、捐献榜，在石头上雕刻、篆字，以公布于众，留名千史。

牌坊牌匾，石刻对联等等，都用得到一门手艺，雕刻、篆字。

石碑雕刻、篆字，收个1000、2000是很正常的事。至于牌坊牌匾，光荣榜，那些难度大一些，字体多点的，收费3000、5000的也不出奇。
