# 孕妇防辐射服偏门暴利项目新手可操作（日入 500）

对于很多刚进入互联网的新手来说，从一开始就想着日入过千过万是不现实的。但通过自己的学习提高自己的能力，然后再做就可能会实现。

这就是我常说的同一个项目，不一样的人做，得到的效果截然不同。每个人的能力、知识、人脉、学习能力、思维方式不同，结果也不同。

只有学习和思考项目可操作性，才能赚到比别人多几倍的钱。在群中，有些人做项目，一个月就能放大操作，可以同时操作数十部手机，另外一些人每天都在问别人的收入有多少。

其实问别人收入能怎么样？钱还是别人的。你仍然看着别人赚钱，不行动，只有羡慕和嫉妒的份，还埋怨为什么不能赚钱。

看着别人再做，别人再做，这是最根本的区别。别人遇到问题正在解决问题，你还没开始，想着就以后有问题怎么办？

不管做什么项目，我们都需要前所未有的果敢和勇气才能实现。做事情果断的人基本上运气不差。
