# 01、开个锁，为什么有人花100块，有人花500块？

曾经，我隔壁家小姐姐脚刚一踏出门，门就被风给带上了。此时小姐姐穿着睡衣，可怜兮兮地站在门外，手机也被锁在家里，于是找我借电话用。

随即拨通了一个开锁师傅，师傅问了情况后报价150。小姐姐砍价到120。

师傅来了之后，观察了一下门锁，就皱着眉头说：你这锁芯是C级的，要破坏锁才能打开。120不够！

小姐姐说：那得多少钱？

师傅看了看穿着睡衣的她：500块。

小姐姐瞪大眼睛：什么？怎么会这么贵？

我插嘴说：要不咱打电话试试其他师傅，反正不急，你在我家看电视吧。我还有西瓜供你吃呢。

小姐姐点点头，准备打电话给其他师傅。

此时，这个开锁师傅说：等等，我再试试其他办法。

结果，他通过猫眼，3分钟搞定！

看到这里相信大家知道为什么了吧。

价格他们可以随意报，你越是不懂，越是急着开门，他们报价就越高。

谁让小姐姐穿着睡衣呢。
