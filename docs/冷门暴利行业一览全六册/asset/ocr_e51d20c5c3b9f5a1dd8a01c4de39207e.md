# 宠物殡葬利润高不起眼的新起偏门暴利行业

做什么生意暴利呢？有个偏门暴利生意最近引起了争议，那就是宠物殡葬。这是个在国内新起的行业，发展还不完善，但利润巨大。民众对于宠物殡葬争论不休，有的人表示支持，而有的人表示没必要浪费金钱和资源。宠物殡葬是怎么暴利赚钱的呢？

![](bbox=[0.13, 0.38, 0.83, 0.68])

国内的宠物殡葬主要花费是墓地的购买和告别仪式，费用从几百到几万元都有。

宠物墓地的价格在千元以上，安葬费等费用是要另算的，如果你打算购买了还得签署一份为期十年的合同，每年要支付墓地管理费。除了墓地，还有宠物骨灰盒、灵位牌等一系列物品也都需要购买。

宠物的告别仪式也很多样，遗体告别仪式的价格不等，有几千元的也有上万元的。也有的人愿意花钱请僧人超度念
