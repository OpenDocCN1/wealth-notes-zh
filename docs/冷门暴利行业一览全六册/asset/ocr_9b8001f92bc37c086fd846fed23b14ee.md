买菜时经常为了same一两毛钱讲价的女性，在给自己的美丽投资时可是一点儿都不手软呢。尤其是近年来，化妆美容、护肤、瘦身等观念随着网络媒体的猛烈宣传，激起了每个女人爱美的天性，推动了女性美容产业的兴起。但是目前美容行业定价没有统一的定价标准，美容护理机构都是自己定价，消费者的讲价能力很低，这中间的利润空间真是不容小觑。

# 三、保健品

众所周知，保健品并不像药品一样用于治疗某些疾病，它的研发与生产成本相对较低，只要不吃出毛病，就可以一直卖下去。我们耳熟能详的脑白金、脑黄金等，被很多 Mur用来送给老人。目前我国也逐渐出现了人口老龄化的问题，60岁以上人口占比越来越高，而老年人又是保健品的主要客户之一。美国安利一年在中国赚两三百亿，如今的行业老大无限极，一年收入也有200多亿。成本低、利润高、市场前景广阔，保健品行业仍然会继续发展。
