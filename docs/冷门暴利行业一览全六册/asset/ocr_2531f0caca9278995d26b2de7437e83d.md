# 农村做点什么生意好，几个比较偏门的小项目

现在去农村做什么生意能赚钱呢？今天给大家分享几个比较偏门的小项目，这几个小项目，大家应该都有所耳闻，不过真正了解的人却不多。

# 你没想到的 N个赚钱创业点子

# 一、收头发，年入几十万不是梦

我们在农村是不是经常能见到有人骑着摩托车，开着大喇叭，边走边喊:“收长头发，高价收长头发”？这些人收的头发一般都是按长短、多少、质量来谈价格的，一般给到的价格是 50-1000 元不等，这么高的价格在农村来说也算非常不错了，所以不少农村女人都愿意卖头发给这些人。

在农村卖头发一般都是先谈好价格，然后收头发的人帮忙把头发给剪下来。这个小生意在一般人的眼里就是一个小得不能再小的生意，可是一般人根本就不知道做这行有多少
