# 新型“暴利行业”崛起，有人年收入10亿

提到"暴利行业"，一般首先想到的是房地产，现在似乎越来越多的行业都表现出了"暴利行业"的性质，而这些行业大多依赖互联网。例如，"网红"实际上是两年年前网络直播的产物。然而，近两年来，互联网越来越受欢迎，各种新媒体竞相出现，这使得"网红"成为下一个市场渠道。

![](bbox=[0.17, 0.46, 0.74, 0.72])

现在的网红和以前的网络主播不太一样了，很多年前，大多数的网络主播都是坐在电脑前的一个固定的地方，通过互联网与网友"面对面"聊天。现在网络名人不仅可以聊天在电脑前与球迷互动,但也可以使用手机进行实时直播,并借此机会推出商品来赚取广告费用,宣传费用,当然,推广自己的产品网络名人可以更能够节省大量的宣传费用。

对于经常上网的年轻人来说，这是一种理想的生活。他们不必整天坐在电脑前为甲方设计，也不必每天四处推销产品
