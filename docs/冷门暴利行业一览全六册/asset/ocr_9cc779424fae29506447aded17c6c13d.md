# 有没有什么暴利的行业（不起眼但是很暴利的项目）

前段时间，偶然和一个做中介的朋友聊天，他说最近找他做人才落户的人非常多，以前我觉得这人才落户不都自己办的，后来我在知乎上看见有人以此业务来做引流，效果非常好。

于是我就去我们本地了解了一下，才发现人才落户非常简单，只要符合条件皆可以办，前期人都 可以不用来，直接交资料就可以了。费用和自己办的差不多，但是对于不熟悉的落户的人，可以节省很大的时间，有时候时间就是金钱。尤其对于公务员和做生意的。

# 一、那么我们怎么去操作这个项目呢？

对接有人才落户快速通道的人，达成合作协议，我们要做的是引流他办理，我们赚提成，一般 20 个点，根据三疯了解到市场价普遍都在 1 万以上,北上广深一线城市更贵。
