# 1、知识付费/培训行业

线上线下培训的机会，尤其是前几年互联网行业很火的时候，很多机构都是成批成批地培训。

有些机构占了红利，只要请一两位名师，就可以不停的招生。当时一个朋友做的事互联网 UI/UX 培训，每个月都会几十个学生来学，学费 1-2w，他们只花了一年时间打口碑，积累资源。

有些机构是一直积累学生，广撒网，到现在成了行业里基本都了解的那几个机构，只要一出课，都会有人买。这个是方的是放的长线，5 年时间是至少的。
