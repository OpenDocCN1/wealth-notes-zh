# 婚礼乐队月赚过万

![](bbox=[0.15, 0.19, 0.5, 0.45])

我这个个摄影师，以前是做婚礼跟拍的，跟拍一天的价格在 500-600。一个 разом 月收入在一万五左右。因为他招了许多大学生扛机器，自己负责后期剪辑。扛机器没有什么技术含量，学一个小时都能会。

每座城市都有这样的团队，城市越大赚的越多。

刚聊天，他最近过年他又开展了一项新业务。刚上道。

逢年过节最火的是什么？就是结婚和宴席了。

我们这里有几所艺术学校。

学校放假，学生都闲的没事干了。在家里吃家人也嫌弃。自己也没钱。

要么去当网管或者去饭店打零工。要么学驾照，打游戏消磨时间。

他就组了两个业余的学生乐队。一个队三个人。两男一
