# 3、婚纱摄影

一套精美的婚纱照是每对新婚夫妻都梦寐以求的，大家就算自己没用过也多少了解一点行情，小编的表姐结婚，一本婚纱照相册加一张挂照就花了一万元。

这里面的水有多深大家都清楚：场地、制作、服装这些成本加起来也就一千出头，加上人工这些，顶多也就两三千。

![](bbox=[0.22, 0.44, 0.68, 0.71])

不过对于消费者来说，只要有满意的作品，这钱怎么也得花，毕竟人生当中非常重要的时刻。这买卖做得是你情我愿，所以婚纱摄影确实是一个暴利的行业。

中国每年大约有 1000 万对新人喜结良缘，城镇新人在婚礼上的年消费高达 4183 亿元人民币，而其中婚纱摄影约占了整个婚庆支出的 15%。

因此，婚纱摄影仍然具有好的发展前景，不过这个行业也需要实打实的技术，也不是谁都能轻易入行的哦！
