# 暴利行业七：手机维修

手机作为当代文明科技的产物，已经逐渐成为了一个快消品，但在PEAT PodWag使用过程中难免会出现问题。

碰上手机充不上电，手机屏幕碎了、开不了机，这些问题普通人应该怎么办？当然是找人维修了。

我有一个朋友开了个手机店，有次一个客户送来一个苹果手机，说是开不了机,我朋友就告诉他主板烧了,报价700,客户留下钱就走了。

但真实情况就是手机里的一个螺丝脱落了，朋友把他拧上之后，手机在店里放了三天，净赚700。
