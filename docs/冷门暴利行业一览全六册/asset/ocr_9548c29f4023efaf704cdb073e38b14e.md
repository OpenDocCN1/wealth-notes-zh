# 项目分析：

如今养宠物的人越来越多，无论是孤独在家的老人还是一些白领等等都是有很大的一群人养宠物，在目前很多养宠物的人心中，养不不仅仅是宠物，而是当成自己的家人，给他们的呵护和关爱是很充足的。

正是因为现在宠物在人们心中的位置越来越重要，所以大部分养宠物的人都很是愿意给自己的宠物宝贝花钱，据调查表明，75%的人一年内为自己宠物花费 3000—10000 元的金额，所以这个市场是很大很诱惑的。
