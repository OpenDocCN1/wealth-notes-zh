# 夏天利润高不起眼的小生意，刚需且冷门的行业月入好几万

这几天，广东的天气又逐渐热了起来，晚上的时候，那些公园、商业区、广场逛弯的人也多了起来。

哪里人多哪里就有商机，巨大的人流必然催生生意，火热的夏季即将来临，正是户外摆摊赚钱的好时机。

可以挖掘，可以赚钱的项目有很多，比如冰粉、炒酸奶、绿豆汤、发光小玩具，甚至煎饼、凉拌菜、买卖二手空调等等。

这些小生意的优势就是成本低、门槛低、上手快、周期短、回钱快，缺点就是有点辛苦。毕竟大热天的谁不想呆在空调房里呢。

但千万别小看了这些小生意，月入几万的大有人在，这些个小摊主，靠自己的辛勤汗水和日复一日练就出来的手艺，既撑起了身后的家，又为城市增添了浓浓的生活气息。

有志于小规模创业的朋友们，一定要把握好夏天这个赚钱的机遇，如果干得好，哪怕是最简单的冰西瓜切片卖，那也足够赚到全年的生活费了。

# 一、夏天卖绿豆冰沙一个月也能赚 10 万

炎炎夏天吃什么最解暑？

俗话说：“夏天一碗绿豆汤，解毒祛暑赛仙方”，夏天不卖冰西瓜，不卖冰激凌，只卖冰绿豆沙，一样赚钱赚到家。
