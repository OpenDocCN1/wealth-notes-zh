# 05、入门门槛高吗？

一个入行 1 年不到的开锁师傅说：

我原本以为很赚钱才入行的，结果不是那么回事。

我入行时找了个师傅跟，花了几个月学习，交了一些学费，然后就开始单干。这一行不跟师傅是要走弯路的。但真要学会也不难，所以门槛很低。

像我这样，学会了就单干，相当于成了师父的竞争对手，所以你想想这个行业有多内卷？

也有做得很大的，确实赚了不少钱，但是他们主营业务是卖锁。

这种公司舍得砸钱做推广，也会跟地产商、装修公司、中介、物业合作。我这种小散户就别想了。
