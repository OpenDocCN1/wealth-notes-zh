# 偏门小众领域的推广项目日赚 1000 元（暴利）

前几天遇到一个朋友，做的是偏门小众领域的推广项目，平时常在群聊中看见，当时没大在意。

最近才告诉我，这个项目日入千元的，都是行业垫底，日入上万的，也非常低调。

小编听后比较意外，没想到平时越起眼的行业，越是非常赚钱。那这个是一个什么行业？

![](bbox=[0.13, 0.49, 0.86, 0.65])

先普及个概念，大家认为：一些大的互联网公司，主要靠什么赚钱？

游戏。比如腾讯，17 年一半以上的盈利收入都来自游戏。

会唬会这样呢？

因为游戏（不管是手游还是网游），是一个边际成本非常低的行业。
