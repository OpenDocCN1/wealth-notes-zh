# 收纳行业如何通过创业日赚 300 元

互联网发展到现在，主流引流的平台就那几个，很多项目翻来覆去的说，其实也没什么意思。

2019 年，可以感觉出来互联网越来越不适合小白去创业，如果你跟我说：撸羊毛，卖电影票算不算。按小编的观点，这个这能算是过家家。

但是，如果你玩的是撸羊毛的局，那可就不一样了，当初有老铁介绍我去北京的做羊毛的公司，老板就是做羊毛的局，手头上千个号，QQ+微信群也有上万个。

市场上能找到的羊毛都会被他们盯上，然后注册分享邀请码。上千个号同时推广，一天能有好几万同时代理，一年的流水 2000w，而且还都是毛利。

普通人只能下个 app，然后注册—登录—试玩，赚点零花钱而已。

所以，对于一些没有实力的玩家，个人还是建议先掌握基本的互联网基本技能，比如：个人号运营，公众号运营，网站搭建等。

当然，并不是说所有人都直接从网上创业，有些人本身有自己的工作或他们有自己喜欢做的事情。

那么，互联网上创业，就可理解为职业+互联网或者兴趣+互联网。
