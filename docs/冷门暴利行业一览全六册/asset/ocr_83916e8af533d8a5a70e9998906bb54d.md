# 7、卖凉皮

凉皮、凉面这类小吃深受广大消费者的喜欢，特别是一些初、高中学生，或者是一些年轻女性朋友，她们经常会约上几个朋友一起去吃凉皮。制作凉皮技术非常简单，不需要特意去培训，只需网上看看免费教程，自己多做几次就可以做出非常好吃的味道，就可以摆摊卖了。凉皮好不好吃，其实关键就是拌凉皮的料汁，只要这个料汁做好了，那么制作出来的凉皮味道肯定不会差的。总之，卖凉皮的利润很高，一碗售价 5 元的凉皮，成本可能只有 1-1.5 元钱，非常不错的一个小项目。

# 8、卖街头锅巴

锅巴，很多农村长大的人对它还是念念不忘吧？我们小时候农村基本都是用柴火做饭的，所以锅里会有香喷喷的锅巴，然后我们在里面夹一些菜，吃起来简直不要太好吃。现在农村人也都用上了天然气，所以很少能吃到锅巴了，不过没有关系，现在很多城市都有街头锅巴出售了，我们想吃就很容易买到。制作街头锅巴很简单，把糯米泡一晚上就可以直接放进机器里面烤制锅巴了，一般情况下一份锅巴的成本，包括电费、配菜钱全部加起来不会超过 2 块钱，而卖 5 块钱一份很好卖，一天卖百十份真不难，这利润也是很高的。
