# 二、眼镜行业

眼镜行业也是一个很暴利的行业，一副镜框进货价五六十块，放店里卖至少是上千块。

我以前的一位同事，她的家乡就是做眼镜的，非常出名。她说过，现在外面眼镜店，配一副 1000 块的眼镜，在她老家零售店可能也就卖一百块。
