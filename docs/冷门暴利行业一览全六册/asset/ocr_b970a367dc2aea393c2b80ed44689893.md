# 揭秘八字偏门赚钱项目，利用 SEO 思维月入过 2 万

其实与 L 先生认识几年了、最初 L 先生是作者几年前服务的客户、后面在我不接 SEO 的时候、L 先生找济南的 2 家网络公司维护排名、但不幸的是 L 先生找到的公司并没有给他维护住排名，从而导致排名下降、完全无流量！

于是 L 先生决定学习 SEO、自己做 SEO、后面找到了我(基于之前的信任)、然后有了今天的故事！

与 L 先生认识存在比较搞笑的成分，因为最初我与 L 先生合作之前、L 先生有一个要求、就是要拿我的真实八字给看他、看后决定合作不合作！

对于当时的我来讲、感觉非常的不可思议、第一次遇到这样的奇葩客户、合作不合作不看公司规模、不看技术实力、而是看八字！

当然、L 先生能凭借自己学到的 SEO 月入过万、其实是他自己会看八字，说的直白一点、是自己有技能、有项目、只是苦于没有流量！
