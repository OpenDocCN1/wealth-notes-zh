# OEM 男性成人用品年赚百万的暴利项目

成人用品的市场一直以来可以说都是用亿来做单位去计算的，基本上做这些的团队一年几千万甚至几个亿真的不是什么问题，就好比最简单的情趣内衣，其实就是一种带有特性的衣服罢了，看看某宝上卖这些衣服的人，哪个不是月收入上百万的，这还只是其中一件产品而已，如果是其他东西呢。
