# 学校旁边不起眼的暴利行业文具店年赚百万

学校旁边不起眼的暴利行业，一间三四十平方米的文具小店，一年居然营收上百万，你相信吗？这是真实的。

![](bbox=[0.15, 0.31, 0.82, 0.59])

阿泰原来是我一个朋友，他在某小学周围开了一间文具店，门面不算大，但也不小，这家店开了近20年，每年开工9个月，寒暑假跟着学校放假，他也休息，开着他的宝马到处玩。原来我一直觉得，一间文具店做不到这么大，但是跟阿泰一次泡茶，让我颠覆了自己的看法，真的是小生意大买卖。

首先是零售，这是最差劲的业务，基本上就是卖支笔、卖个橡皮这样的，虽然利润高，但是实际上算起来不赚钱。阿泰的业务在于，他跟里面的老师们都很熟。他举了个例子，开学了，啥东西卖最好？书包啥的家长都会去淘宝买，书皮就不会。当学校里发了新书，老师们都会让孩子们包书皮，
