# 老酒回收项目：你没有注意过的暴利行业

今早去了家老店吃包子，包子店的地方很偏僻，要穿过拥挤的早市。早市很热闹，各种卖菜、水果、海鲜的商贩。

有一个摊位坐落在其中，显得特别的突兀。他们不卖商品，反而还收东西给别人钱。相信多数人已经能猜到个大概。这个摊位就是：回收老酒、冬虫夏草、礼品卡等。

在不同的城市里，我们都能看到类似的一批“生意人”。
他们都有一个特点：在闹市区里摆个摊，专营礼品回收。
甚至在当前，回收老酒、礼品已经成为了一个相对完整的行当。

百度搜索了一下：回收老酒。首页几乎全是竞价广告。
竞价广告意味着什么，这个无需多说吧。
一次广告点击至少需要 3 毛钱，排名越靠前价格越高。
