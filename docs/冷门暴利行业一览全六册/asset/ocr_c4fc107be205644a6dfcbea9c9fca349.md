# 揭秘：同性恋的黑 se 产业链，轻松年入百万

在讲这个黑 se 产业链之前，先来讲讲一个很久之前的事情。

相信很多 90 后、80 后都听说过电击治疗网瘾这个事情，可能现在网瘾在日常生活中或者是各种新闻中已经不常见了，但是 80 后、90 后对于这个词并不陌生。

那个时候网络刚好是在中国普及的高速时期，很多很多的青少年对于网络这种神秘的东西抱有很大的好奇心，尤其是网络游戏，也就导致了大批的少年变成了网瘾少年。

于是突然社会上刮起了网瘾这个词，各大新闻的争先报道，导致了很 多的家长有很大的恐慌，害怕自己的孩子都沉沦虚拟的网络游戏不能自拔。

于是慢慢的兴起了各种打着教育的幌子，治疗网瘾的“教育”机构。

其中最有名的当属一“教授”杨永信。

无数家长看了有关于“电击治疗网瘾”的报道之后，纷纷把自己的孩子送往戒网瘾中心，即使是每个月高昂的学费，也在所不惜。

于是乎“教授”杨永信迅速获得社会上的名和利。

成功的入选了央视节目，一时风光无限，也受到无数家长的支持和追捧。
