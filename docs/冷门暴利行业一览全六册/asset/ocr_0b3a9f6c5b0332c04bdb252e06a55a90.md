# 暴力产品项目：英国卫裤

一说到英国卫裤，估计只要是接触网赚 3 年以上的估计很少没有听说过的。

在 4、5 年前英国卫裤跟绿瘦减肥胶囊一样都是标标准的互联网暴利产品，再加上当时有一些人在做暴利竞价的培训，当真是一窝蜂的人想在这个项目里面赚钱。

当小编今天再提到英国卫裤这个暴利产品的时候，估计很多人就会有疑问了，现在还能赚钱吗？

只要是流量类的网赚项目，赚不赚钱不在于产品，而是在于市场，只要有市场需求，那就一定有钱赚。

微商里面那么多的暴利产品，很多都没有市场需求的，但是依靠招代理让代理去消耗依然还能抢占一方市场呢，更别说这种有需求量的产品了。

而英国卫裤，就属于是用户需求决定市场永不死的一款产品。

全中国有多少男人想要增大增粗，我想有无数个，多到无法想象，就算是英国卫裤再没有效果，依然还是有大把的想去尝试一下。
