# 1、造型冰糖葫芦

在很多人印象里卖冰糖葫芦的人就是穿得破破烂烂，抗一个木头棒子，上面插一些冰糖葫芦，沿街叫卖的形象。这种方式其实早就成为过去的，而现在卖冰糖葫芦的，很多都开起了专卖店、分店还一家接一家的开。他们有什么诀窍，能把小小生意做这么大呢？

其实也非常简单，他们只是抓住现代人的心理:只要是好吃好看，或者是没有见过的，比较有新意的东西，再贵都有愿意买。因此现在卖的冰糖葫芦不再是过去那种简单的几个枣，裹点糖就完事的那种。而是利用好几种水果，做成各种可爱漂亮造型的&
新型冰糖葫芦，这种冰糖葫芦很能吸引人的眼球，卖15-30一串非常好卖，还有的就是普通冰糖葫芦，但是外面裹上一层葡萄干，也能卖10块钱一串，大家可以算算，这种生意赚不赚钱。

# 2、肉夹馍

肉夹馍是很多吃货都喜欢吃的一种小吃，这种小吃可以说既能解馋又能饱肚子。肉夹馍现在经过人们的改进以后，不再是仅仅只夹肉，还可以夹菜，夹鸡蛋、夹培根、夹火腿
