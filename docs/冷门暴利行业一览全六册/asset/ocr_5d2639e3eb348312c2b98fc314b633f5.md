# 暴利项目之翻新手机销售

翻新手机应该属于灰色项目产业链吧，我也不是很清楚，这个行业存在于很多很多年了。

小编以前对电子产品非常的感兴趣，尤其是手机，所以看过我的自传的人应该知道以前有一段时间我经常去收手机，玩手机然后顺便倒卖，一年也赚到不错的收入。

我最早的时候是在上海闸北火车站旁边的地平线通讯市场去收手机，5 楼是二手手机专卖市场，很多地方的偷过来的二手机都在这里二次销售出去或者发到华强北去翻新。

那个时候我就知道翻新机市场是一块巨大的蛋糕，不过我对销售手机这个行业没什么兴趣，或者说我本人并不是特别喜欢销售这个行业。

我去地平线收手机的原因是我有一个发小专门在里面修手机的，他高中没毕业就到上海去当修手机的学徒了，到现在为止修了 10 多年的手机，在上海买了一套房，在我们老家市里买了两套房，可见当时手机行业是非常赚钱的。

不过，这些年因为网购的发展，已经加入到手机阵营的品牌商越来越多，其实这个行业稍微有点日薄西山的意思了。
