# 穷人翻身唯一出路，后面隐藏的冷门暴利项目

# 1、网站广告

网站挂广告来变现应该是一个网站盈利的重要渠道之一。

而一个广告的流量大小直接关乎了广告费的多少，因此很多的站长都会在流量上面来下心思。

就比如前几年比较火的国外网赚 lead 就是利用虚假的点击来骗广告商的广告费的，就是现在在网上还有关于这一方面的培训。

# 2、百度指数

咱们回到正题，我们都知道一个百度指数的产生是因为有许多的用户不断地点击，才会在百度上产生一定搜索量的百度指数，如果一个特殊事件的突然发生，导致大量的人来搜索的话也会产生一定的搜索指数，例如当下最火的“绿地事件”，“张玉婷”等。

那么就可能会有站长利用百度这个特性来刷某一个词，以此来实现自己网站在爱占上面的虚假信息。
