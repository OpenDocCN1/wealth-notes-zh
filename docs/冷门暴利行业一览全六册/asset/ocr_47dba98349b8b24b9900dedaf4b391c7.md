# 适合小城镇或农村市场去做的冷门暴利小生意（小本创业）

从前，大家总是想着往大城市发展，这无可厚非，毕竟大城市就业机会多。但今时不同往日，农村发展得越来越好了，不少人开始留意到小城镇甚至是农村的商机。

今天给大家分享一个观点，那就是现在要想找生意、挖掘项目，其中一个很好的途径就是找下沉市场。

找到下沉市场的痛点，必会有所收获！这点从互联网巨头们为了农村市场争得头破血流就可以看出来。毕竟谁能聪 明得过资本呢？

下面我为大家总结 2 个适合小城镇或者农村市场去做的小生意，小本创业，早做早赚钱。

# 01 回收加工废旧骨头

回收废旧纸箱、书本、塑料、铜、铁、铝、不锈钢这些我们或许经常能看到，但是你知道吗？我们吃完扔掉的牛羊猪等动物废旧骨头也大有用处。

这绝不是空穴来风，山东临沂那边专门有一群做这类动物废骨头回收生意的人，大家可别紧张啊，这可是一正经买卖。

他们从大型屠宰场、餐馆、食品加工厂把扔了的骨头收回来加工之后，又以各种形式回到了咱们身边。
