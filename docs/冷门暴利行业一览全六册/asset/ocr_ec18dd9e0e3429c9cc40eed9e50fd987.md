# 石头彩绘不起眼又赚钱的冷门小生意（投资小）

不起眼又赚钱的冷门小生意，那必然是鲜为人知的生意。

比较少人知道不代表赚不到钱，我们一直强调“信息差”，很多小众的市场，是因为你不知道，而别人了解就能抢占商机。

今天小编说钱就再给大家分享一个基于信息差的小项目，是我从日常生活中观察到的，我认为实操性挺强的，一起来看看吧。

石头彩绘，成本低利润高。

“石头彩绘”听起来好像很高大上的感觉，实际上这东西不复杂，非常简单，做这个项目的最大好处就是大部分的人都没见过，图个新鲜。

小编也是偶然带着孩子逛街时，才发现有一个年轻小姑娘在卖这个东西。小姑娘卖的石头，圆的扁的，长短的，各类形状的鹅卵石。本身很普通，淘宝20块钱能买到几十公斤，都是用来铺路的。

但是，这个小姑娘她利用自己的手艺，进行了二次创作。她把小石头作画板，画上一些流行的卡通形象，非常可爱。路过的宝妈及孩子，还有一批批情侣看见了，都会纷纷围上前来把玩，爱不释手。
