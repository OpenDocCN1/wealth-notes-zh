# 暴利行业二：加油站

我有一个学员在一个普通的小县城有一家小型的加油站，但就是这样一家不起眼的加油站，每年能给他带来几十万的纯利润。

虽然近几年来的政策严了很多，但在一些经济欠发达地区的还是可有作为的！

# 暴利行业三：牙科

根据科学研究表明，一个成年人平均一年要洗两次牙！每次的花费都要 100 多远，成本只是一些消炎药水。

补牙、矫正、假牙的花费更是高的离谱。

成本几十块钱的材料，补一次牙却最少 500 起。

牙齿矫正一次的价格更贵，几千块钱的价格已经是很便宜了！
