# 3）算命培训

算命大师和算命大号们除了直接帮别人算命赚钱，还干起了培训生意。有文章指出，有的算命大师根本不是专业出身，而是批量速成的素人。

如今很多大学生都因为毕业后找不到工作，就加入了算命行业，作为素人，经过为期几天的入职培训后就能正式上岗给人算命，而且据说每月工资近万元。

授课的方式主要是网上教学，课目种类繁多，比如：《五行生克关系》、《五行象义》、《天干地支详解》、《八字排盘怎么看》、《八字大运流年断事》、《八字断事业工作》等课程，每个视频都有几千的播放量。

有趣的是，点开学员信息后就能发现，这些学员大多为80后和90后，他们原先从事的职业五花八门，有做汽修师傅的，有从事餐饮行业的还有做销售的……但都经过短期培训后上岗营业了，还号称不仅能预测未来，还能说出你的过去。
