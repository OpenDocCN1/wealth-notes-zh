# 02、灵活易操作、利润大，对店铺的要求并不高

租个店铺，不一定要很大面积，哪怕三、四十平方米都可以的，简单装修一下，主要是要干净卫生，就可以开业。

例如，练习书法的培训班，店铺里面就算只摆几张桌椅，也能开始教学，唯一要求是要把隔音效果做好。书法的练习和创作，需要一个安静的环境和墨香氛围。不用开在小区大门口附近的店铺，在稍微软离喧嚣的角落的店铺就行。
