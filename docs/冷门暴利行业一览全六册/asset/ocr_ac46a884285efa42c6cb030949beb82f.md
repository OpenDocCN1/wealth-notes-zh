# 二、农村回收废品

如果农村朋友不愿意去打工赚钱，也可以考虑下做农村回收生意的，例如到村内专业回收一些老旧窗门，旧屋梁，旧石块等，只要能转卖变现的物品都能够收回去，成本低回报高。

另外还可以回收一些能循环利用的废品，比如破铜烂铁、纸皮、废旧塑料、废旧泡沫、废旧家电等等。而且现在回去行业也已经更新换代了，像以前那种单一骑三轮车上门回收的早就行不通了，现在已经采用线上线下同时进行废品回收了。
