# 管住家长的钱包，暴利项目

大意是，某班主任在家长群里推广一款学习软件，杨先生只是提出了对价格的质疑，就被踢出了群，并被告知“传播负能量”。

据新闻报道，该软件正版一年最多 388 元，而学校卖给学生一年 600 元。

也难怪，一单 200 多利润的好买卖，学校怎么能不搞点非常手段。

问：一个 1000 人的小学学校，转化率是 50%，学校能赚多少？

```
1000×50%×200=100000 元
```

推广一款软件，便可赚十万。

其实这只是保底收入，若卖的是盗版软件呢？破解软件的成本并不高，花钱雇人即可。

再加个注册码，想卖多少卖多少，反正零成本。暴不暴利？若方法合适，实际的转化率必然远超 50%。
