# 农村赚钱门路有哪些？不起眼的小生意却很挣钱

农村有句老话说得好：“三十而立，四十不惑”，所以经常有粉丝朋友跟我吐槽，自己有四十多岁了，感觉自己老了，现在还没有事业基础，而且比较尴尬的是，去打工的话，一些地方都不要了，都嫌弃年龄大了。更加要命的是，随着年龄的增长，自己不仅身体各方面不如以前，就连想法也改变了很多，做事没有二十岁的冲劲了，为人处事没有三十岁那么淡然了，因为这个年龄上有老下有小，确实很无奈！

要我来说，不管是多大年龄，其实只要肯努力，愿意改变自己，任何时候都不晚。俗话说得好:“致富路上千千万，就看自己干不干”所以我认为农村人如果真的不想在城里打工了，那么我可以给大家介绍几种小生意，这也是非常不错的选择。

毕竟这人“不折腾不穷、不折腾不富”，如果安于现状还是以打工为佳，如果想要改变自己的命运，还是要接触一些生意为好，那么农村都有哪些小生意比较适合呢？
