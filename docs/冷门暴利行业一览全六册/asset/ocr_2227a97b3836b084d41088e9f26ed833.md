# 网上开店，选对产品就能轻松年入百万

随着现在的生活节奏越来越快，大部分人在工作中就已经占据了大部分精力，所以很多人下班回家后都想简单一点，再勤快的人回到家都想做一个“懒人”。

![](bbox=[0.15, 0.34, 0.57, 0.57])

今天小编想说的是选品，就如果你想在网络上开一家店卖产品，又没有货源，所以需要自己找产品，相信有经验的朋友都知道，选对了产品，可以达到事半功倍的效果，就连世界首富比尔盖茨也说：“巨大的需求空间，较少的竞争对手，做这样的市场，就意味着不战而胜！”这足以说明产品的重要性。
