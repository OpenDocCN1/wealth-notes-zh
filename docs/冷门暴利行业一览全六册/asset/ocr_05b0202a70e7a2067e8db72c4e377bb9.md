# 没人注意的暴利行业（身边不起眼的暴利小生意）

在现在很多人，只想选择看似体面、光鲜亮丽的工作，因为工作稳定、体面，但就在这种大环境之下，仍有不少高材生去选择一些看似不体面的工作利用劳动来赚钱的工作，令人啧啧。

如果换个角度考虑，体面工作稳定，但是拿到高薪的却是少之又少，看似利用劳动低学历的小餐馆，小吃摊收入不菲，现在这个社会物质条件是看你能赚多少钱，工作在体面不够果腹也是无用功。不妨看看一些小生意，在不需要太多劳动力的情况下，一个人月收入却能超过万元，甚至上万元。

# 1、特色小吃

当你外出购物时，你会发现有好多特色小吃。虽然有些连店都没有只有一个小推车，但客流量并不少，反而排起长队，不禁让人怀疑是不是找的托。否则，一个小吃摊怎么会有这么大的客流？事实上，只是img因为小吃摊口感太好，才受到大家热情追捧，其实有时候我们去饭店吃饭感觉口味不如路边小吃摊，与饭店沉闷、一尘不变的用餐环境相比，路边摊更加有生活气息，物美价廉、味道不错，因此成为大家追捧的对象。而且只要真材实料，味道好，月入过万不是梦。
