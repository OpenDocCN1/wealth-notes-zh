# 一锤子买卖的暴利项目日赚万元

人性本恶，现实中例子不胜枚举。

当然不乏各种好人好事之例，但若作恶毫无惩罚，没有任何代价，那么相信各种恶事的出现比例将会飙升。

换成经商赚钱也是一样，小商小贩想缺斤短两，但是怕被人抓到，怕被人揍。风险和收益不成正比，所以选择老老实实做生意，踏踏实实赚钱，赚的少了，但图个心安。

这些都是建立在有市场监管，法律覆盖的范围内才会存在。

为什么经常说，“穷山恶水出刁民”？本质上来讲就是法律监管覆盖不到，自然各种违法钻空子的人就多了。

为什么火车站附近的旅馆，饭店服务那么差，那么黑？因为做的好没有意义，这种人员流动性极大的地方，回头客太少了，基本都是一锤子买卖，做的再好也没人会再来，当然做的再差也不会有人来找麻烦。

所以商家只需要把追求利润作为唯一的标准，从而赚的盆满钵满。

上面说的这类没有监管，回头客极少的地方，对于消费者当然是极差的选择，但是对于商人却是天堂般的存在。

所以，有没有什么地方也是这样，并且捡个摊就能开始赚钱，无需各种租金的呢？
