# 2.提升排名

快排的作用，就是短时间内获取大量的词库，采集大量的文章，快速排名的一种技术。这个都是专业人士去做的，都是 SEO 这个行业人做转型服务做出来的产品。所以一般人也很难学会，只能花钱付费做快排。
