# 人靠衣装、马靠鞍，一个单笔利润上万的暴利项目！

如果有个人骑着自行车去和你谈业务，任凭他说的天花乱坠，你都不会认为他的项目能赚钱；但如果有人开着宝马去和你谈业务，他还没开口，你就相信了一半。

很多濒临破产的老板，都会表现的镇定自若。小编见过一个老板，账上没多少钱了，孤注一掷，拿着这些钱去买了辆豪车，结果很快就东山再起了。

为什么？因为身边所有的人都不相信一个换豪车的老板会破产。没了糊倒潮弥散、墙倒众人推，自然就缓过来气了。如果这位老板，不能保持这份淡定，他早就万劫不复了。

说这些，其实就隐含了一个很多“老板”都有的需求。那就是——包装！人都是只有两条胳膊两条腿一个脑袋。有能力的还好说，没能力想凸显自己和别人的与众不同只能包装。怎么包装？豪车、豪宅、大把的人民币、漂亮的女秘书等等等等。出了这些，还有一个至关重要的一一手机靓号！
