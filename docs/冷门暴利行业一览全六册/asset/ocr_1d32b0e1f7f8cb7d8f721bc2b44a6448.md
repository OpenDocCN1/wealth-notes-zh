# 四、风水师

看风水行业绝对是一个暴利行业，现在请人看风水，一般的师傅都是好几百块钱起，如果是有名的风水师傅，他们的收费就更贵。大家应该还记得曾经有一位冒充风水大师的人叫某林吧，听说请他看一次风水都需 十万块钱起，而且还需要预约，还要排队。由此可见看风水这行有多么赚钱了，不过看风水并不等于迷信啥，这点我们大家要搞清楚。

# 五、出售宠物物品以及宠物火化

现在人们生活好了，养宠物的人也越来越多了，很 多人都特别舍得在宠物身上花钱，一只宠物每个月开销几千块钱都很正常，因此如果我们开一家宠物用品店，专门出售一些宠物用品，肯定也能赚到不少的钱。另外，现在宠物火化行业也非常火爆，据我网上查资料显示，目前火化一只宠物需要收费 600-1000 元，这也是相当的暴利。
