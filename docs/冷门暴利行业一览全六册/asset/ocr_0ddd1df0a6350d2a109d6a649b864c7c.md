# 夜市摆地摊套圈暴利项目，轻松月入过万

最近做小视频的时候，在火山上无意中看到别人发的视频，就是一个别人摆摊，利用圈圈套玩具的视频，然后就去看了一下，基本上每个人都能套中很大一套玩具，10 元钱一个圈，套中哪个玩具，就可以拿走。

![](bbox=[0.15, 0.35, 0.65, 0.55])
