# 暴利的古玩创业项目实操，一单利润至少赚 500 元以上

想创业，没项目怎么办？
今天小编给大家分享一个暴利的行业——古玩。
古玩，又称文物、古董等，是古代遗存下来的文化遗产物质，包括传世品和地下出土品。

![](bbox=[0.15, 0.37, 0.74, 0.62])

这类东西价值不菲，专门做这个市场的人，就靠这个发财。

他们专门批量制作陶瓷、玉器等古董进行出售，1:1 的产品，让人分不清真假。

（1:1 的意思就是做的和正品一样）

且利润很可观，甚至还像线下实体店进行销售，买的都是有钱人，一单利润至少在 500 以上！
