# 三：二手书进货来源

下面要说的就是最关键的问题，我们需要进哪方面的二手书，从哪里能够获得二手书资源呢？

二手书类型方面，小编推荐各种教辅类书籍，各种小学初中高中的辅导书，练习册都是很好的选择。为什么这么选择呢？

小编再放一下上面的 一张图：

![](bbox=[0.08, 0.48, 0.96, 0.7])

这张指数图，可以看到每年非常明显的波峰，这些波峰的时间恰好与学生的寒暑假时间吻合。所以可以得出结论，学生对于教辅类书籍的需求是刚需，学生一届接一届，源源不断的生源就是我们的目标客户。

至于从什么渠道淘来二手书呢？

首先是各种旧书批发市场，里面按照书的成色论斤卖，根据自己的需求寻找成色不错的二手书收上来，价格非常便宜，然后再归类转卖，一倒手就是几倍的利润。
