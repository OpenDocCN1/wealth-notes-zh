# 看不见摸不着的生意都是暴利项目（推荐 3 个）

新手小白起步，小编一般都建议做一些虚拟类的生意，复制成本低，又能够无限复制的项目，或者是服务。

这类产品，能够轻装上阵，即使你赚不到钱，也不会损失太大。

我们总看到一些人每天都是灯红酒绿，出入各种场所，有花不完的钱，但是这些人之前却苦逼的日子，你可能从来没有见过。

新手，都是希望投入 1 元钱马上就有 10 元的利润，无异于痴人说梦。做项目都有一个过程，由起步期，到积累期，爆发期，稳定期，而很多人都恰恰死在了起步期。

# 一、版权项目

网上，有些公司专门搬运国外的免费图片，然后打上自己的 logo，全网发布，结果有些人不小心用了这些图片，收到律师函，说你有涉嫌图片侵权，这些流氓公司就是通过图片版权赚了很多钱。

还有，一些字体，你不小心用了，有时候会收到字体侵权的律师函，要你花几千元购买正版字体或者是撤销图片。

类似的这些公司数量还是很多的，我们做电商或者是自媒体，说不定哪天就会被这些流氓公司给盯上，一些流氓公司甚至会经常网络钓鱼。
