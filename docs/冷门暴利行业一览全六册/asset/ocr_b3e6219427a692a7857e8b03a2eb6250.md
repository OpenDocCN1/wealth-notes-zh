# 第三种，胶原蛋白肽。

主要是工业使用，用于一些细菌生物的培养基，它既可以制药，也可以用来治疗消化道疾病。

除此之外，这上等优质的牛骨骨粉用处也很多，有一些营养品里边，就用那牛骨骨粉做卖点，就那电视上经常播放的什么壮骨的广告。

因为这牛骨的钙和磷的配比和人相似，更好吸收，所以就叫吃它补什么。

这就是为什么这些制药公司也会花大价钱回收动物脆骨软骨的原因所在，像猪鼻骨和鸡胸骨这些，回收价格可以达到4到5万块钱一吨，也算是回收行业中一个高利润的存在了。
