# 回收黄金一个正规暴利的冷门生意

黄金回收，这个冷门的生意为什么会如此暴利？

因为市场大，国人婚嫁必不可少会购买黄金首饰，竞争相对其他行业比较小，金店卖出去的黄金基本只做置换不做回收。信息透明度不够，大众眼中回收黄金这个行业门槛比较高，所以暴利

为什么现在大多数生意都不在暴利了，

因为蛋糕有限，分蛋糕的人比较多，很容易形成恶性循环，所以利润相对来说就越来越少了。而回收黄金属于区域性服务，客户想到卖黄金都是急用钱，需要立刻变现的，一般来说没那么时间考虑直接就变现了。

我创业至今已经 6 年多了，从一名保安做起目前在从事回收黄金的行业，做黄金回收之前做过很多的项目的，摆地摊，手机贴膜等等都没赚到大钱，甚至来说有些都是亏钱的，刚开始做手机贴膜都是那种用刀片割的手机膜，后来出来了钢化膜，很多那种软膜直接没人要了，被市场淘汰了。

直到我接触回收黄金这个生意以后，才慢慢开始摸到了钱。他的利润相对来说还是比较可观的，单笔的利润基本都在 500 起，1000 一单左右是比较正常得单子。甚至有时候约到偏远一点的客户，一单利润上万偶尔也是有的，接下来我会用最简单易懂的方式讲这个生意的利润。
