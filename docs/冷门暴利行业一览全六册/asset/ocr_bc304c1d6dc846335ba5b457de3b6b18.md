# 买卖绝版旧书古书偏门不起眼的小生意

我在淘宝上做生意，
第一桶金是卖 9.9 包邮的飞机杯赚到的，这个没什么不好意思说的。
赚钱做生意嘛，不寒碜！

那个时候淘宝还处于比较早期，很多细分类目做的人少，而且当时淘宝针对下沉市场有点像现在的 pdd，千人前面的算法还没出来，只要价格有优势就一定能爆单。我就是这样跟着别人一路从 9.9 包邮的入口产品，一路升级做到 19.9、29.9、99......

大家都说，现在淘宝很拥挤了
对！
但也不全对！
只要找准细分市场，选好品，其实还是能赚钱的！
今天就和大家聊聊旧书、古书、绝版好书的买卖吧。

毛主席语录，你们觉得现在还有人看吗？毛主席诗词，你们觉得现在还有人看吗？可能很多人觉得这些东西过时了，其实不然。
