# 偏门赚钱行业手机租赁店每年赚 20 万

移动互联网时代，每个人居家旅行装备中都不能少一台手机。但随着手机行业的发展，手机迭代速度越来越快，不到一年就要更换机。手机频繁的迭代，促使手机租赁行业的出现。

手机租赁店能做什么？

手机租赁可以解决出差或旅游人群的困惑。出差在外地，手机不但要装本地 APP，还要担心漫游话费。通过租手机可以解决这些困惑。有些商务人士谈生意，需要拿一部时尚高端的手机，而租手机即可以降低成本，还能增加了谈判的成功率。

其实手机租赁也可以租功能。如果下载小说手机就是移动图书馆，如果下载考题就是题库，如果下载 APP 就是随身 MP3，如果下载电影就是移动电影院。如果下载商场 APP 就是本地商场 VIP 专业导购机。这时手机就功能发生改变，细分市场会增加，租赁人群也会随之变多。

目前手机租赁店客群主要是中小学生，租赁手机的目的是为中小学生打《王者荣耀》的游戏。这样做虽然短期能获利，但家长，学校、社会层面会产生负面影响。一旦老师，家长没收了学生手机，或将为手机损坏，将带来不必要的损失。所以租中小学生手机打游戏并非手机租赁店真正的需求，
