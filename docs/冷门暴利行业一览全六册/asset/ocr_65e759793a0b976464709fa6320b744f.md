# 隐藏不起眼的暴利行业（4 个冷门致富小生意项目）

对于市场上的小生意，基本都不存在什么暴利，都是一些普通老百姓在挣一些辛苦钱的，如果说每月能挣一万多，那也是天时地利人和。目前市场上，还有哪些不起眼的小生意，我这里推荐一些，仅供参考。

# 一、马桶疏通

这个小生意不仅仅是不起眼，很多人也看不上眼，但是确实很挣钱的。做这个小生意，设备投入也就千把块钱，但是上门服务一次收费都是 80—100 元，有时候就是 10 分钟就能搞定的事，你说这利润有多高？如果说把这个小生意做出头绪，形成自己的客户群体，那一个月说挣到一万多，是完全可以实现的事情。社会上哪个家庭没有马桶？有多少家庭的马桶没有被堵过？
