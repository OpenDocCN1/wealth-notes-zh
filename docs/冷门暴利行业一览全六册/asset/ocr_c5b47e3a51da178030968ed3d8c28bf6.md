# #济南身边事# 【济南街头“彩灯气球”成新宠 小伙日挣千元】

最近几天，在济南芙蓉街大门口，街头出现不少人叫卖“彩灯气球”。这种新潮玩意儿吸引众多路人的眼球。由于这种灯十分醒目吸引眼球，受年轻人追捧。在济南街头一般是叫价 30-35 元一个。成本却只有七八元。每卖一个气球能挣 20 多块钱，堪称暴利啊！一位卖波波球的小伙子说，一晚上能挣上千元。（综合齐鲁晚报、大众网）
