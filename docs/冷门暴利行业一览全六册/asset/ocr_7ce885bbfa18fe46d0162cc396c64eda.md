# 5、农村有机肥加工行业

有机肥一直以来都是一种比较高档的肥料，这些肥料卖价都非常贵，比如一些浇花用的有机肥，动不动就卖价好几块或者十多块钱一斤。但是这些有机肥料它们的成本是非常低的，而且制作有机肥料的原材料在农村是随手可得。也许大家会非常好奇，有机肥料是如何制作而成的，其实制作有机肥料真的不难，只是把一些动物的粪便收集起来，然后让他们自然发酵，在经过一些简单的处理方式就成了上好的有机肥料了。

而这些动物粪便在农村又非常容易获得，比如鸡粪、羊粪、兔子粪、牛粪、秸秆等等，这些普通人看似没有的东西，其实就是制作有机肥料的主要原材料。因此如果在农村能建立起一家有机肥制作厂，那前景肯定也会很不错的。
