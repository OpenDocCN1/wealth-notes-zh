# 快手上的暴力项目纳米香石，成本五毛卖五块到 10 块

有时候，你不得不佩服某些人的思路：把一些东西包装成某种噱头，就是一款暴力产品！

比如今天我们要介绍的纳米香石项目。

![](bbox=[0.22, 0.42, 0.62, 0.6])

所谓的纳米香石，并不是一种纯天然的石头，而是一种经过加工的木粒制品。这种东西颜色鲜艳，而且透出了一种悠长、浓郁的香味，是以被叫做香石。

至于名字前面的那两个字：纳米，写上总会让消费者更信服的不是？

所以，这款商品就被命名为了纳米香石。

认识这款产品应该要感谢快手。

某次在快手上刷视频的时候，看到了有主播拍的视频就是关于摆摊卖纳米香石的。

根据小编的经验，这是一款很不错的商品。

对于终端消费者，以及快手上那些想着勤着勤想赚钱的人，都有着强大的吸引力。
