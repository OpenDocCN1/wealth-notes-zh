# 2、如何进入行业

有一个简单逻辑，学什么做什么。既然要做这个行业，那么就需要必备这个相应行业的知识，不然和客户对话，你都说不出个所以然。

所以，成为收纳师的第 1 步，就是学习。简单的获取相应的知识，无非就是通过实体书，电子书和音频和视频。

书本类：《物室欲》、《打理生活》、《意外简单的收纳术》、《生活的基木》、《断舍离》
