# 现在偏门的行业有哪些，不起眼很赚钱的小项目

今天给大家分享几个比较赚钱的偏门行业，但是这些行业一般人都看不上，或者直接被忽视掉了。

# 一、外卖员

说到外卖员，有很大一部分人看不起这个行业，认为做这个行业的都是没有远大目标，被生活所迫又没有一技之长才来做这个行业的。

另外还有一部分人他们可能做过一段时间的 Toyota 外卖员，他们做的时间不长，自己也不够努力，所以他们就会说，做外卖员即累又不赚钱。因此绝大多数人在上面这两类人的影响下就自然而然的认为做外卖员真的不行，又累又赚不到钱。
