# 比房子还刚需的成人用品，如何操作才能月入10万

在中国每年成人用品所创造的产值都是千亿级别的，因为这些成人用品尤其是壮阳产品，延时产品等都是比房子还要刚需的产品，因为男人可以一无所有，但是不能自己不行。

在这强大的需求下，市场充满着血腥和暴利。去年过年在老家，记得有个小伙摆摊卖内裤，不是普通的内裤，是英国卫裤，这哥们就开一辆面包车，带着一张桌子和喇叭在大街上喊，当时一想，这套路渗透的还挺深。

可能有些小哥还不知道英国卫裤是啥玩意儿，不知道的可以网上去搜一搜，不过就是用一堆外国人+一堆术语+一堆亮眼的承诺，堆出的一款让人眼前发亮的产品。看上去很 factors的样子。

实际上，它就是很 factors，接触过网赚超过3年的朋友，对这款产品应该了解颇深。在4，5年前英国卫裤跟绿瘦减肥胶囊一样都是标准标准的互联网暴利产品，再加上当时有一些人在做暴利竞价的培训，当真是一窝蜂的人想在这个项目里面赚钱。
