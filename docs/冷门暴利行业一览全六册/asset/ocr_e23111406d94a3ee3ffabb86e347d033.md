# 二、氢气球销售

这个小生意也是暴力，3000 元的投资，也是完全可以做起来的。流动卖一些五颜六色的氢气球，这些都是小孩子看到就喜欢的东西，而且每次都是拉着大人硬要买，不给就哭。所以说孩子的钱好挣，也就是这个道理。

市场上的氢气球，成本都是非常低的，买些气球给气球充气一个也就几毛钱，成本连一块钱都不到。销售选择在一些儿童聚集地，像游乐园、小广场、幼儿园门口等，都是可以卖的，因为它是流动性的，并不需要有固定摊位，一个卖十块钱，一天卖几十个，坚持做下去，一年也会有二十多万的收入。

所以，这个小生意也是值得关注，小本钱，大收益。
