# 什么偏门行业赚钱快暴利，茶叶最不起眼的冷门行业

不知道什么时候开始，微信“茶叶女”风靡互联网，包括最近在爱情公寓 5 电视剧中都利用这一个梗来作为笑点，那么“茶叶女”骗局在被曝光之后，茶叶就赚不了钱了吗？当然这是不存在的，正是因为茶叶属于冷门的暴利产品，所以骗子才会骗人。

中国对于茶叶文化已经源远流长，尤其是南方地区对于茶文化都比较重视，如一些名茶：西湖龙井、洞庭碧螺春、武夷大红袍等等都产自南方地区。而福建人是茶文化的代表，不管是自己在家还是迎客都会选择喝茶作为首选的礼仪。那么在这样的茶文化中，茶叶自然是深得群众的喜爱。

我认识两个朋友，一个在福建，而另一个是广东的，福建的朋友跟我说，他们那边武夷大红袍一斤就卖三四百起，好一点的上千块，而且养殖成本不高，但是利润高的可怕。而广东的朋友说，他有一次去云南游玩时，跟一个当地的茶农购买野生茶叶，一斤上千元，ổng竟野生跟人工的口感是差很多的。
