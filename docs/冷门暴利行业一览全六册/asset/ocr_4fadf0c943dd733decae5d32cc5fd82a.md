# 偏门暴力项目：PUA 五步陷阱法近乎病态化

PUA 这个行业不知道有多少人听过，即使没听过，相信昨天那条刺眼的热点新闻“全国首例 PUA 情感操控案被查处”的消息很多人也都看到了。

但虽然是首例被查处的案件，受害者却并非业内第一人，在这之前被 PUA 所荼毒的女性没有一万，也有八千了吧。

而 PUA 这个行业本身是由国外引进过来的，全称为 Pick-up Artist，翻译成中文的意思大概就是搭讪艺术家、把妹达人。

早期只是作为一种分享男性如何通过技巧和心理学，去接触自己喜欢的人，但后来完全变了性质，演变成一种骗财、骗色的手段。

在引进国内市场以后，被总称为“泡学”，不仅发扬光大了，同时，进行了商业化包装，演出了各种各样的流派。
