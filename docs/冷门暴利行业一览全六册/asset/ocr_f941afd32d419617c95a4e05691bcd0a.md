# 一个人单干偏门暴利项目，短视频取名赚钱日赚1千

取名这个行业，是真的很赚钱很暴利。

前几天亲戚的孩子刚过满月，张罗着给孩子取名字，无奈的是，文化程度并不高，所以取得名字并不合心意。

据说现在取名讲究缺啥补啥。也就是说，金木水火土，看你属于那种命格，缺少那种属性，然后在名字上补上去，寓意圆满。

所以现在很多小孩子的名字里面，都是森，森，鑫，，燚等与金木水火土对应的属性。也是家长对于孩子的期盼。

街上找了一个取名的，问了一下生辰八字，然后一张白纸上比比划划，前后不过三分钟时间，取了三个名字，让家长自己挑选。然后收费500块。

我们走的时候，看到还有人带着小孩进来，也是准备取名。

突然感觉，有些行业的暴利程度，超出了我们的想象。按照这样算的话，最起码每天接待5个耗费，几个小时，收入轻松2500块。
