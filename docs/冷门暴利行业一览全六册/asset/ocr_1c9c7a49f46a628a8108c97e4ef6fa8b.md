# 人际关系交流群 (798)

通过他的群，我们可以看到目前成员人数是 798 人，就按照 400 一个人算，也是三十万左右的收入，每天就是为会员源源不断的提供资料，这个收入比单独卖群会员资料赚钱很多，其实这些资料网上也可以找部分，很多人想到是放在拼多多，或者是闲鱼上销售，但是这个哥们直接是把内容消化，创建属于细分领域的群，最后赚钱了。

其实这样的案例很多，在拼多多，闲鱼，淘宝上面这样的细分领域特别多，但是很多人只会倒卖盗版资料，就如很多人盗版别人的课程一样，其实你卖别人的东西与你没有多大关系，你也赚不了多少钱，但是你转换里面的东西，再去搭建自己的付费社群，或者是课程你会赚很多。
