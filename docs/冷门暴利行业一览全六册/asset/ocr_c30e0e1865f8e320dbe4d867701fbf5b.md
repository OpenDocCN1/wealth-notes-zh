# 一、眼镜行业

大家有没有发现，往往一条街上会有很多家眼镜店，他们真的能挣到钱吗？在眼镜界有这样一句话：20 元的成本，卖给你 200 元是人情，卖给你 300 块是交情，卖给你 400 块是行情。一副成本仅几十块钱的眼镜，销售给顾客时，摇身一变就成了几百甚至上千元。随着电子产品的普及，我国近视人群尤其是青少年近视人数在不断增长，眼镜也成为越来越多人的生活必需品，那么这个行业未来的发展是非常可观的，这中间的利润可想而知。
