# 二、获客

任何行业最重要的就是找客户，找客户的方式也有很多，获客本着一个原则：哪里有人，哪里就有意向客户，像我们之前就是在人流量大的地方放置广告，效果十分理想。

比如：人流很大的超市，特别是一些小区附近的超市，这种超市的客源都是有一定资产的，意向客户最多。做好一个写着黄金回收的广告牌，然后放置在超市较为显眼的地方，和老板商量一个月给 50 块钱，没有任何一个老板会拒绝，因为对他来说，这是稳赚的，没有一点成本。
