# 农村暴利赚钱项目，收购玉米芯一年能赚 30 多万

分享一个农村暴利赚钱项目，收购玉米芯。以前我们都是拿玉米芯生火做饭，现在呢？有人专门收这个东西，而且一年还赚了几十万。

我们这边是河南周口，10 月份左右我们地里的玉米基本上就收完了，最近 2 年，一到收玉米的时候就有人来收玉米芯。

![](bbox=[0.15, 0.48, 0.84, 0.72])

像以前这玉米芯就是烧火做饭用的，有的呢直接给扔掉了，没什么经济价值。我们这边秋作物都是玉米为主，这个玉米芯的数量非常大。

我认识这个老板呢，在我们这边连续收购玉米芯三年了，今年是第三年，他每年收购玉米芯只收三个月，我听说他这个项目非常赚钱，一年大概赚了几十万。
