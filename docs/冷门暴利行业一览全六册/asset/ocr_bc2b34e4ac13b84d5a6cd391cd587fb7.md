# （石膏彩绘的制作流程）

想要知道一个项目的收益怎么样，那么就要先算制作成本，制作石膏像的原材料就是当地建材市场卖的普通的石膏粉，价格低廉。

一般在 0.3 元一斤，一斤石膏粉大约可以制作 1 个石膏像，也就是说制作一个石膏像的成本只要几毛钱。

制作石膏白坯的模具：乳胶的、塑胶橡胶的、硅胶的、树脂的、玻璃钢的等等，根据石膏像模具的材质和大小的不同，价格也是不一样的。

其中用乳胶模具的会比较多，它的优点是好脱模，也耐用，可以反复使用 3 年以上。大小 15cm-60cm 的价格在 25-80 元，一般 30 块钱左右的模具就已经够用了。

简称 pvc 的树脂模具价格则会比较便宜，在十几元之间，但是由于 pvc 表面是很光滑的，导致模具的材质很硬，不容易脱模，各有优缺点吧。

还有一种摔不坏的石膏娃娃，因为是搪胶的材质，所以行业的人都叫“搪胶娃娃”，游乐场、儿童乐园都更喜欢搪胶的，而且摔不坏的特点也让人生操很多心。

这种娃娃要工厂机器生产，成本非常高，开一个模具大概 1500 多块，所以很少人做生产。大部分人都是直接找有实力的供货厂家拿货批发，再拿出去卖，这对擅长销售的人
