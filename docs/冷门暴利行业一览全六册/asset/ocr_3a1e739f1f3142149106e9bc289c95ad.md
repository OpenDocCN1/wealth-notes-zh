# 一两千的小成本生意，适合一个人单干的项目

现在社会上有很多处在困境中的人，都想利用自己手中一点有限的资金，去谋求一条可以让自己赚钱翻身的途径。投资小利润高的小生意，一年有可能收入 20 万以上呢？我这里推荐一些，仅供用于参考。

+   一、盒饭外卖

这个小生意 3000 元是肯定可以开始的，做好了收入也不低。现在做盒饭外卖，不需要厨师，不需要服务员，更不需要设施齐全的厨房和厨房设备，只需要一个人，就是你自己。还有就是你就是连一份醋溜土豆丝都不会做也没关系，只要你会用电饭锅煮米饭，只要你会用一口大锅热一下菜，当然了，销售也要靠你自己了。
