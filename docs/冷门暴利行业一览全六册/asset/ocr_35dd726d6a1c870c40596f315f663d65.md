# 一、盈利模式

单卖或者批发。批发单买都行，你可以弄两个号，一个单卖号，一个批发号。来什么人就往哪儿引，后期招代理也行，只要产品好，很多人都愿意帮你卖货，他赚你也赚呀。

如果做批发，只要你的产品看起来高大上，并且比古董市场的货源价格低，那么走量，依然会有不菲的收入，至于他们拿去怎么卖那是他们的事情。

为什么能比传统渠道的低呢？

传统渠道一般有固定的批发商，而且中间层层加价，但网络就不一样了，所有厂家都是公开透明的价格，存在竞争关系，选择空间很大。
