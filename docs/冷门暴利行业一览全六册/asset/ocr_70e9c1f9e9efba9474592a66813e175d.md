# 04 写在最后

石膏彩绘这个生意的好处就是投资小、易操作、利润可观，找个好地点，比如公园、广场、夜市等休闲区，或者儿童乐园、淘气堡旁边、电影院旁边，都会很好卖。

同样地，还可以把石膏彩绘这个玩法和石头彩绘相结合，石头和颜料的成本都很低，比石膏要低多了；再搭配一些儿童玩具、零食什么的一起卖，还能赚得更多。

石膏彩绘娃娃真正高品质的话，几百块一个也能卖得出去。稍微动下脑子，那么完全还可以做个性化定制的，提高客单价，那利润才是真正的暴利。

除此之外，石膏彩绘的价格、质量、款式我们都要照顾到，很多人容易犯的一个错误就是不管款式怎么样，一下子找很多供货商，分别问一下价格，然后直接找价格最低的商家下单进货。

这是生意人的大忌，因为只有好质量、好款式的石膏彩绘娃娃才能让我们的生意做得更持久，高价不一定买到好货，但低价是绝对买不到好货的。

所以建议找不同厂家分别拿一下样品比较一下质量，为了避免广告嫌疑，我就不推荐商家了。
