# 倒腾二手书月入几千的冷门项目

二手书商店我想不少人都曾经光顾过，小编也不例外。

从当年大学时就开始逛遍学校周边各种二手书商店，有时候借着看，很喜欢的书就买下来，因为都是二手的，所以价格非常便宜。

直到今天，每次经过那几个二手书商店竟然发现还是屹立不倒，这几个毫不起眼的门脸竟然直到今天还没倒闭，也是实在难得，可见二手书背后的利润确实相当惊人。

正好有个朋友最近在倒腾二手书，所以才有了今天的文章，小编琢磨着把这个二手书项目写出来，看看能不能给粉丝一点启发，毕竟市场这么大，根本无需担心市场问题。
