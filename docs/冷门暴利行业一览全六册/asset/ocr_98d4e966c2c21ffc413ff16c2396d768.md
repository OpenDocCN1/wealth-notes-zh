# 三、规范化养殖

传统的养殖业已经暴露出了很多弊端，所以想要现在开始干养殖业的朋友，要与现代化接轨，运用先进的技术进行科学规范的养殖，前期的投入虽然比较大，但前边投入的精力多点，后边就会越来越轻松，请几个相关领域的专业人员指导一下比较好。

# 四、农产品加工

从地里收获的农作物直接卖挣钱吗？挣钱是挣钱，只不过挣得太少了，大家有没有发现，只要是加工过的产品，价格就比回收价高出好几倍，比如红薯加工成红薯粉条，柿子加工成柿子饼，所以农产品附加值最高的不直接销售出去卖钱，而是进行深加工，加工自己当地盛产的农作物，原材料成本会大大降低，人力也好找，主要的就是机器和技术，做好了带动全村经济的发展不是梦。您对此怎么看呢？
