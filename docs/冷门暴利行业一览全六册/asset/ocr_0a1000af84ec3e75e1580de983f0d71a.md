实它的成本也是非常低的，毛利润就达到了 90%以上，而且每年去美容的人数也是非常多的，也难怪这是个暴利行业。

# 五、婴幼儿产品行业

我们国家的人口本身就多，每年出生的小孩也不在少数，自然需求上来说是非常大的，而且这个行业的成本也是非常低，商家的利润可以稳定在 40%以上，也难怪这么多人去卖母婴用品。

# 六、婚纱摄影行业

随着人们生活水平的上升，对于结婚这件大事自然是越来越重视，拍婚纱照也有着许许多多的创意，这个行业自然是应运而生，而且它的成本可以说是非常低的，前期只要付出人力和设备，就收获高额利润。

# 七、饮料行业

我们看到了卖两三块的瓶装饮料其实成本才不到 7 分，而易拉罐的就更便宜了才 5 分，每天去购买饮料的人也不在少数，可以说是暴利了。在看完这些行业之后，它们都在根据市场的走势而暴利的，其实这也需要它们不断调整成本，升级技术，才能维持这样的高利润。
