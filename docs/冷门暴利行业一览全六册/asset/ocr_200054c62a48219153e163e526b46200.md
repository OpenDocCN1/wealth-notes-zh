# 暴利项目：搭建玄学风水网站，持久运营可年赚千万

今天我们来聊一下一个“信则有不信则无”的玄学暴利项目——“网络风水”。

相对于“实地风水”，现在“网络风水”水更深更不易察觉。

排在前面的几个算命或者风水网站，年收入都是以千万计的，我们个人或者小团队虽然做不到这个地步，但想在中间转第一桶金，还是有一定可操作性的。

在这里和大家简单的从几个方面分析一下“风水站”是如何的套路营销的。

# 一、流量池：

在灌入流量之前，我们需要有一个流量的聚集地，也就是我们俗称的流量池。而我们通常用的流量池无非就那么几个：网站、自媒体账号。而自媒体账号主要以公众号和微博为主，这里我们暂且不提，我们讲讲网站。
