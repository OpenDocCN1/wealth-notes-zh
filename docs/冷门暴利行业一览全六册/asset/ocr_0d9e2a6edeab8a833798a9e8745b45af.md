# 每月赚 3-5 万的中医项目,可以跟人合作赚钱

首先还是先说一下，没有中医知识如何借力。可以从两个方面着手：

+   1: 线下可以在当地中医院，诊所找中医技术高的，找他谈合作，口碑要好，技术好，能解决问題；有些朋友又会问了，我不认识这方面的人，也很难找有高水平的人合作该如何？

+   2: 加一些中医群，花点时间互动，看看哪一个有水平。不要进群之后都不发言，不然别人都不认识你，又哪来的合作信任基础。

你可以从别的群里人家发的案例拿到群里让大家发表意见，问治疗思路，互相比较。如果碰到回答有水平的，加他私聊，看他擅长哪方面。混熟之后再谈合作，多加一些高手做人才储备。这一步完成了之后，接下来就是引流了。

有些朋友可能会问到中医有哪些可以操作的東西？养生，减肥，zhuang 阳，脱发等等，凡是用到中医解决的都可以操作。是不是相比风水项目可以操作的东西更多？接下来就以线上操作来讲解。
