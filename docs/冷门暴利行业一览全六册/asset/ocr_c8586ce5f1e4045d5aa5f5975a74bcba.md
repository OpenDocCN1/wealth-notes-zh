# 冷门暴利行业：不起眼的通下水道项目年赚几十万

暴利行业不只是热门行业，其实一些冷门的行业也是可以赚钱的，比如，小编接下来要说的比较冷门的项目——通下水道。

![](bbox=[0.19, 0.36, 0.78, 0.67])

说不起眼是因为大家都不知道它的暴利，也不知道怎么赚钱，其实，通下水道是非常赚钱的，拿通马桶来说吧，如果你堵了，没有 50 是下不来的，每天有多少家马桶被堵呢，数不过来，还有小区的下水道，一般一次收费一二百，其实，这是个大生意，你想想一个城市有多少个下水道呢？如果你承包了，你算算多少钱呢？

别说一个城市，你就算承包一个学校也赚钱，一般一个大学的下水道问题包年是三十万一年，就是一年之内，发生任何此类事故，你随叫随到，如果包五个大学，再加上几个单位，平时没事再接几个散户。那两百万轻松入账，至于投
