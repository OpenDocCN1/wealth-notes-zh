# 网络算命偏门暴利行业大师靠它年赚百万

中国有一种传统职业叫“算命”，能断阴阳、演八卦，给人看吉凶祸福、姻缘前程，是从业者的看家本事。上至达官显贵下至黎民百姓，都很受用。他们通常会跟你扯一通让人听不懂的玄学，然后告诉你逢凶化吉、遇难成祥的办法。

新时代的算命早已借助互联网的东风，走向高速发展的轨道，绝非像过去那样随便在路边支个摊儿，挂个八卦旗就能开张。在百度上搜索算命网站，数量绝不亚于莆田医院，而且还都是免费。你没看错，算命早已从路边摊发展到网络化运营了。
