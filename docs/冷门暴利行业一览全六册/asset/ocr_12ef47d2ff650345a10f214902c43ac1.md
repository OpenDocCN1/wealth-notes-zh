# 赚钱：变现的几种途径

+   变现 1.付费课程

听完一些女撩男课程后，自行拟个大纲。

听着课程，脑中拷贝，用自己的话翻录一遍课程。

课程定价后，放在荔枝，千聊，小鹅通等卖课平台。

+   变现 2.付费咨询

这个变现方法，建议项目操作了 3 个月以上后再使用。

课程质量不高没关系，但别给人乱指路，图钱不能坑人。

付费咨询，当你听课掌握了许多问题处理方案时，方可开始。

+   变现 3.开放式变现途径。

光听小编讲，丝毫不动脑子，那可没什么用。

变现方式很多，你能仅靠自己琢磨出一种吗？
