# 做二手空调生意赚钱吗？不会被淘汰的暴利行业

做二手空调生意赚钱吗？周日去朋友家去做客，朋友这几年真够拼的，两口子结婚也就三年的时间攒了一套房子的首付，这两天搬家，去了才知道，原来为了省钱，简装了一下，什么是简装呢？就是简单铺地板，做了厕所和厨房，其他什么装修也没弄！100平的房子，2万就搬进去住了~

![](bbox=[0.15, 0.38, 0.7, 0.63])

正好要买空调让我一起参谋，去了地才明白原来他是要买二手空调！会过日子的才会省钱，这一点也不假啊！原本要花五六千的空调，2000元就能买到八九成新的立式空调，再买的时候，看到好多人都在买空调，不由的和老板聊了一会，二手空调现在赚钱么？

其实二手空调这个生意市场真的非常的大，老板是一家人来干，老板和他父亲主要是出去跑收购空调，他老婆和他娘主要在家里面负责卖，我问老板，你做这生意一月能赚多少钱呢？
