# 暴力却没人愿意做，不起眼却赚钱的行业

据统计，在我国有 2 亿家庭有养宠物的习惯，这也意味着有 2 亿的市场。只要养过宠物的人，一定要深入体会，在一只狗狗身上所花费的钱财，每个月最少得 800~1000 块钱。并且呢，也是一种感情寄托，早已把狗狗当成家庭的一员了。所以当狗狗丢失的时候，我相信大家在现实生活中也经常能看到一些寻狗启事，那赏金从 5000 到几万都不等。

![](bbox=[0.09, 0.47, 0.8, 0.75])

于是就催生了一个极度冷门又暴利的寻狗项目，其实他们的装备也很简单，就是热成像，高级手电筒和高级望远镜，投资非常低。可能他们只接一单所有的成本就回来了，因为他们的起步价都是 5000 块钱起步，只要服务了，不管找没找到宠物，这个钱是不予退还的。是不是特别暴利？
