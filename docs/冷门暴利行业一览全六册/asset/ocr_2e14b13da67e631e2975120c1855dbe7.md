# 县城最赚钱的空白行业（利润最高的不起眼暴利行业）

县城最赚钱的空白行业？在不少人的眼里，暴利行业一般都在大城市中，小县城是比较落后的。实际上，县城也有不少发财的机会，只是很少有人能够把握熄了。

![](bbox=[0.15, 0.34, 0.85, 0.56])

在不少县城中，有几个生意是随处可见的，但没有多少人在意，经常被忽视。而有的人却把握住了机会，将这几个随处可见的生意变成了“暴利”行业，甚至年入几十万。

# 一、临期食品销售

临期食品因为快要临近保质期的原因常常会打折出售，而小县城的家庭对于临期食品也是十分欢迎的，毕竟能够让自己购买商品的成本降低不少。临期食品的进价也不贵，商家能够获得的利益也不少，完全可以称得上是一门“暴利”行业。
