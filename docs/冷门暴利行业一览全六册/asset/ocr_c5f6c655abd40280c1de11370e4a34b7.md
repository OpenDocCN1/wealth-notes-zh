源，收入的话也是有多有少。少的话就这个项目而言，一个月至少可以赚几千左右，多的时候2、3万也有。

# 03 老版人民币交易的 5 个渠道

说完旧币回收来源之后，小雪现在给大家推荐5个靠谱的旧币交易渠道。

# ①当地邮币卡市场

大部分城市都是有邮币卡收藏市场的，在那里往往集中着大批以搜集旧币为生的币商，像北京，上海也有马甸，卢工这种规模比较大的交易市场。

不过选择在这出售，需明确认识自身出售纸币的市场行情价，不然你不了解的话，很容易就被压价了。当然了，这里坑也很多，需谨慎出手。

如果稍微对行情了解一点，也可以在闲鱼之类的网上二手平台进行售卖，有时还是能卖到不错的价钱的。

# ②上收藏网站

近些年来，互联网高速发展，网上也出现了很多钱币收藏品线上交易网站，旧币收藏家会时不时地浏览这些收藏网站，大家可以将自己的纸币挂上去等待买家。

但是需要注意的是，在网上交易，存在一定的风险，大家无论是买还是卖旧币都一定要谨慎。

为了避免广告嫌疑，小雪就不过多推荐这类网站了。
