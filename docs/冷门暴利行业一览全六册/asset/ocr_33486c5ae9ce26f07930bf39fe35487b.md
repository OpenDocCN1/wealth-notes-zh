# 今年的 6 个冷门暴利行业项目

# 绿色食品

![](bbox=[0.16, 0.25, 0.58, 0.47])

随着生活质量的提高，人们对入口的东西的质量越来越看重，所以绿色食品这个项目可谓是应运而生。而且我国一直所坚持的都是可持续发展，所以国家也是支持绿色食品，绿色消费的。所以未来绿色食品的发展趋势是十分乐观的，虽然现在还只是在起步期，但是只要投资商肯投资，将来一定可以看到回报的。无水洗车该项目不需要高技能，大投入，也不浪费水资源，无任何污染，只需订购专门洗涤剂即可。主要方法：先用节水洗车机(可喷出气体，类似吹风机)将车上的泥土吹去，然后采用超洁无水洗车产品(特殊配置的液体)均匀喷射在车漆表面，用半湿的毛巾或海绵就可以把车擦净，再用抛光巾或干毛巾抛光，脏车很快就可光亮如新。对于较脏及较难清洗的底盘，发动机，轮胎等部位，可以用特制的汽车泡沫干洗机清洗。
