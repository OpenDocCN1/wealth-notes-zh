# 有没有什么暴利的行业（中国目前最暴利的十大行业）

+   1、修表行业

有个客户 120 万的表坏了，报价 11 万来修然后说返厂什么的，客户留下修了，打开一看就一颗螺丝松了，拧上放了一个月然后打电话给客户说返厂回来了。

当然这是技术活儿，这种大客户一般也比较少。
