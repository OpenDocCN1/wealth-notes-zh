# 一些不起眼但是很暴利的项目（很少人愿意做的工作）

说到现在创业赚钱，农村人首先想到的就是搞种植、搞养殖业，城里人就会首先想到开服装店，开饭店，我们不否认这些项目的确也能赚钱，但是这些项目做的人都非常多，竞争激烈，所以也不一定能赚钱。相反，那些看似不赚钱，很少有人做的冷门项目也許还更賺钱，在我们现实生活当中就经常见到这样的冷门项目，今天给大家分享 5 个很少人愿意做的工作。
