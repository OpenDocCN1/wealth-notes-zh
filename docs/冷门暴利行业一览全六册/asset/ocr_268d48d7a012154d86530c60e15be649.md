# 2、对好面子的玩家，激发虚荣心

如何让人心甘情愿地充值付费，最常规的做法就是以利相导。

比如说，他们会在群里吐槽下 XX 老游戏有多么坑人，

诸如：

新手过保护期后被老玩家狼<|message|> 噬，有些关卡上打几百遍也打不过，后期没了顶级装备根本升不了级等。

然后，用小号或利益相挰绑人的号来烘托气氛，将新玩家在游戏中的重大挫折拿出来狠狠晒一遍，激起群里大部分成员的共鸣，大家一起吐槽，获得初步信任后，再慢慢开始推自己的 cps 游戏。

方法就很简单了，直接告诉群友说这个游戏的暴利程度很高，我上手游到了极品装备。

然后晒自己在交易猫或 5173 游戏交易平台的收入截图，看得人心痒痒的。

这时候肯定能激起部分人的好奇，开始询问：这是什么游戏，是怎么玩的，充值送钱么？

然后又用大号配合小号，告诉他们赚钱很暴利：

首冲就送价值 5000 的大礼包；今天顶级武器正好甩卖，只要 2 折就入手；只要你充 XX，就是 vip 会员可以获得极品装备奖励...
