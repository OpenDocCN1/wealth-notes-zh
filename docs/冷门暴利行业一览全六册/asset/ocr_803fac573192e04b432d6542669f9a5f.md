会有强烈的消费欲望，所以会转而购买比较廉价的商品，而口红正是这种相对廉价的非必要物品，但是可以满足消费欲望，因此而有了这个有趣的名字。

前几年的“星辰”系列，再到后来火爆全网的“斩男色”等等，无不显示着年轻女性的消费能力，今天就从的海外口红代购入手，一起聊聊代购那些事。

先大概了解一下这些海外代购的一些黑心套路。由于所在地区以及相关法律问题会诞生出一大批黑心商家一般分为以下几个类型：

+   1、人在国内，货也在国内。

这种黑心代购是最初级的，通常都是拿广州货来充当正品去卖，买家基本上都是对奢侈品一知半解的，基本就懂个品牌，哪裏知道什么鉴定，所以，初级卖家基本对接初级买家。

+   2、人在国外，货在国内。

基本上一类代购以留学生以及海外打工的主为主，刚开始是真正想代购代点东西的，但是被假货市场挤压以及正品利润越来越少，才促使他们去真假混卖，基本上海外带进来的不会假，在国内的大多数为假货，他们的套路通常是：在海外的专卖店拍视频拍照给你，其实从国内的假货工厂发货，一系列的购买凭证及物流信息也是假的（现在都有相关的配套产业）。
