# 低成本投资项目二、菜市场的卤菜摊，投资万元左右，每月收入轻松过万。（稍微有点辛苦）

做卤菜摊，这个小生意特别赚钱，很多入干这行的人买车买房了，前期投资一万块钱基本就够了。做卤菜的投资大致如下:四千块钱买一辆三轮车，在花一千块钱在三轮车上面做一个玻璃罩，这样就可以直接在车上就卖了卤菜，再花一千块钱买冰柜，其他剩下四千块钱用来购买原材料，这样算下来刚好一万左右的投资。
