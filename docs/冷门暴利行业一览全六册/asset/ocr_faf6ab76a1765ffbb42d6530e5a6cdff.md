# 一年赚百万的生态付费小说行情

微信生态的小说付费，正在不断得成就一批一批的百万富豪。每一个暴发富的背后都有自己的一份心酸故事，只有努力才能给予自己、家人以及朋友过上优质的生活。

不管是大小公司，都能够在这个红利期当中赚的盘满钵满的不胜其数，大公司有实力购买大量小说版权，小公司则抓取网上各种没有署名的版权小说，开发分销系统，然后在微信上疯狂招收下线，用来分销，然后在按照比例分成分销小说，大的团队早就赚的不亦乐乎了。一年下来流水在千万以上也是正常。
