# 3

![](bbox=[0.07, 0.13, 0.47, 0.44])

模具用夹子整齐夹好后，将石膏浆倒进模具后转5至8圈，同时轻轻拍打震动模具避气孔，使每个细部都挂上石膏浆即可，不需要一直转到圈，多余的石膏浆留在模具里准备下一个石膏像使用，柱状状态如上图所示。

# 4

![](bbox=[0.53, 0.13, 0.93, 0.44])

待柱上的石膏浆凝固后，轻轻拿起模具柱第二...第二次石膏浆需要高出多到一些挂好后用平板或封底盘盖住底部立正摆放好让多余的浆自动流到平板或封底盘上形成封底，操作方式如上图所示。

# 5

![](bbox=[0.07, 0.67, 0.47, 0.86])

第二次石膏浆凝固后就可以卸掉夹子开始脱模了，优先脱模前半的位置，最后脱底部位置，轻松四个步骤就可以制作出精美的石膏像，可做摇摆娃，等高，烟灰缸，佛，瓢音，金童，大小工艺品，细节如上图所示。

# 6

![](bbox=[0.53, 0.67, 0.93, 0.86])

石膏公仔完成后就可以开始上色，顺序为浅色位置优先上色，深色位置最后上色，先上大面积彩绘，后描小面彩绘，上色乐趣主要体现DIY例如蓝色头髪可以换成红色让彩绘更富有想象力。公仔材料成本仅需3毛
