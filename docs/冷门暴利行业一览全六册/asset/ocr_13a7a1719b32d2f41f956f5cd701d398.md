# 几千元能做什么小生意（低成本投资暴利小项目）

目前市场上能赚钱的小生意特别多，想一个月赚几千块钱的项目真的很多，而且很多都不需要什么成本，这关键要看个人的能力如何了。那么假如投资几千到一万元，可以做市场上哪些生意，能赚到近万元呢？小编这里给大家推荐一些好的小项目，真心希望能给大 家起到一些帮助作用，也请大家仔细、认真的看完下面的内容。

低成本投资项目一、校园门口关东煮，投资八千元左右，每天收入好几百元。

在一些学生比较多的校园门口做流动关东煮生意，这也是很不错的选择，这个项目投资八千元左右就可以开始做了。主要投资资金有:买一辆小型电瓶三轮车四千块钱够了，还有花一千块钱定做一个不锈钢的关东煮锅炉，里面是分成一小格一小格的那种，如果图省事，直接买一个大圆桶替代锅具来使用也是可以了。接着再花一千多块钱买一个冰柜，其他就买点一次性餐具就可以了，再有买点原材料这就可以开工了。
