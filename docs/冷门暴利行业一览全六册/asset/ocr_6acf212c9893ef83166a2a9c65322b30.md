# 今年7个年赚10万的偏门暴利行业

今天分享几个暴利行业，让你1年至少能挣到10万。

暴利，是指生产者、经营者获取超过合理利润幅度的行为，有人认为超过50%、75%，甚至超过100%足以视为暴利，产品的利润超过50%的行业都可以看作是暴利，对这个定义有的朋友会说，烟草、通信、房地产都是暴利行业，但门槛太高，普通人知道了也没用！

今天小编的目的就是给大家介绍一些“大隐隐于市”的暴利行业！

暴利行业一：情趣用品店

2003年8月，国家食品药品监督局就发布了通知，仿真性用具不再是特殊商品。

低成本、高回报是这个行业的现状，有些比较特殊的商品甚至会产生10倍以上的差价。
