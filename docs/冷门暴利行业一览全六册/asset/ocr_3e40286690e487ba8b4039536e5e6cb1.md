# 【3】小结

内容不是问题，重点在于这些内容怎么输出，怎么变现？

下面提供几个思路：

我们可以做一个公众号，做揽汉教程的载体，公众号要每天坚持发内容，至于盈利那就是平台分成所得，还有就是付费的揽汉教程和揽汉需要的周边，其实就是送给男生的礼物比如钱包，围巾，手表等男性用品。

同时也可以在专门操作一个微信来卖教程，或者只操作私人为微信号来操作也是可以的。一份教程卖 59 或者 99 元，一天卖 10 份就可以净赚 1000 元了，再加上男性礼品的一些盈利，收入真的很可观了。

还有就是引流吸粉的方法就是做音频上传各大平台，可以增加自己公众号或者私人号的曝光度。
