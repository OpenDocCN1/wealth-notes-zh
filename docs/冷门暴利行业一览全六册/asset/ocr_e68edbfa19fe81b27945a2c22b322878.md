# 现在做早餐生意赚钱吗（一个人可以做的早餐生意）

我们小区门口每天早上都会有很多的卖早餐的小商贩，骑着三轮车来卖早餐，很多人都在好奇做早餐生意赚不赚钱呢？今天聊聊我所看到的！

其实你们不早起不知道，这些做早餐的也许半夜三四点钟已经起来了！五点钟的时候他们已经早早的等着了！现在基本每天早上五点钟起床上班的大有人在，一个是上班地方比较远，起来的早，还有很多的自由职业者，天亮就开工了！买个早餐是他们最好的选择！
