## 过年几个暴利小生意，日赚五百到一千不等

春节是中国最隆重的新春佳节，如果你想做点生意就不要错过这么重要的节日。过年的时候大家都会出去玩，每个好玩的地方都是人山人海，你就可以在人多的地方卖点东西了。

第一卖小饰品

卖小饰品本小利大，批发价格在一到二元可以卖五元，批发价格在三到四元的可以卖十元。

![](img/7c81332eb33ca507e9870affccee8e97_451_0.png)

第二卖糖画

糖画是小孩子最喜爱爱，如果你绘画功夫比较好，你可以买糖画工具现做现卖，也可以买一台糖画机器在家做好了，拿到街上去卖，卖五元一个，成本在一元内，如果你那边有别人在卖，你也可以跟老板打听一下看他的糖画能批发吗，如果能批发的话就可以直接去老板那里拿货卖，这样简单省

事。

![](img/7c81332eb33ca507e9870affccee8e97_452_0.png)

# 第三卖萝卜

相信大家在很多城市都见过推着车子卖萝卜的，不起眼的萝卜也是非常赚钱的，你可以去批发市场批发那种几乎都是一样大的萝卜，批发几毛钱一斤，一个萝卜成本也就一块钱左右，回家把萝卜洗一洗带个刀子到街上卖，把萝卜一切四瓣，可以卖一块钱到一块五一瓣，利润也是不错的。

# 第四卖儿童气球

氢气球比较好卖，小孩又特别喜欢，现在孩子都是父母的心肝宝贝，谁在乎十块八块的。
