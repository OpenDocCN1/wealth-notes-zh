# 不为人知的暴利行业“信用卡中介”月入数十万

相信很多朋友都在朋友圈或者其他地方看见过信用卡中介的广告，例如是无视黑白秒下信用卡等等之类的，今天小编就带大家了解一下信用卡中介的内幕，了解他们是如何获得银行放水信息以及如果给客户做单收费的。

首先金融中介做重要的就是要掌握银行的动向，了解什么时候在放水，什么卡种在放水，已经银行审批的喜好，然后针对性的为客户去包装。

![](bbox=[0.13, 0.49, 0.88, 0.71])

“银行的风控套路就那么几个”，银行厌恶高风险人群，信用卡中介就“投其所好”，讲客户包装陈在医院和事业单位工作，哪怕客户已经失业。“最好是将客户包装成非正式员工”，这样银行在查询公积金记录的时候就不会有破绽。

小编了解“很多银行对于当landing的明星企业，风控系统很有可能会开后门，如果操作客户综合评分足够高，那么就直接通过审核，都不会进行电话回访”
