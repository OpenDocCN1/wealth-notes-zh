正常的一个情感工作室，一个月应该有几十个这样的单子。

# 3、咨询的人群大概是什么人？

从 20 岁以上到 60 都有，女性客户比较多。

高付费的人群集中在明星和企业家。这些人外表是光鲜亮丽，但是其实自身情感有很多问题，他们有赚钱的能力，但处理感情的能力比较薄弱。

这些问题就会反映在他们的恋爱、生活、婚姻当中。

# 4、这些人是线上还是线下？

一般都是线上接单，这个行业还是存在私密性的。

客户不愿意把自己的感情公之于众，让大家去看，很多的时候是通过电话或者文字沟通的，这样他们会更有安全感。

很多的客户，只会把事情告知你，让你帮忙解决。

比如说，我是 A，他是 B，那我们怎么解决这个问题，只说事，不会告诉你，他是谁谁谁，私密性很强。

# 5、新人如何去做这行业？

首先需要学习，可以在网上找资料学习，其次是观摩和学习其他资深咨询师如何做咨询，多积累情感案例解决方法。

如果真的要吃这碗饭，证书是必须的，需要考个国家认可的心理咨询师证书。
