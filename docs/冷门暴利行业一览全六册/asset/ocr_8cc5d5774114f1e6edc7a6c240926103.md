# 给你推荐两个月入 10000 元的偏门暴利项目

同样的外界环境，不同的人注定有不同的结局。

同样的头条号取消新手期，有人开心可以拿平台广告分成，有人抢手里的头条账号以后难卖；同样的淘宝禁售产品，有人立马换产品做，有人立马换平台做。

今天介绍的两款偏门项目，一个黑，一个灰，一个客单价高，一个销量大，月入 10000 元就这么简单。

先说黑的，有车的朋友会经常遇到一个问题，那就是罚单。超速、压线、闯红灯、占用应急车道...稍不小心就要吃罚单，小编有个金融行业客户，年收入三四百万元的那种，他的宝马就经常吃罚单，有一次看到他发朋友圈，超速 50% 以上未达 70%，罚款 1500 元，扣 12 分，吊销驾驶证。

小编心里好奇，现在开车的一般都有电子狗，就算手机导航也有，怎么会超速这么多。一聊才知道，暴利产品！

原来他在网上买了车牌隐形喷雾剂，只要对着车牌喷一喷，电子眼拍出来就看不到车牌号，因为上面有一层特殊化学成分，可以反光，拍不到具体的号码。然后他在高速公路就大胆的超速和走应急车道，第一次被拍到走应急车道，交了罚款再找卖家，卖家说有可能产品过期，然后又卖给他一套最新产品。然后他油门踩到底走应急车道，直接被吊销驾驶证。再找卖家，发现好友列表里找不到了。
