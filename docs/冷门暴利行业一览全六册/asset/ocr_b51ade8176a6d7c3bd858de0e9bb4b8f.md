大师与你深入交流后，都能准确地说出你的性格、过往经历，这时你开始对大师深信不疑。紧接着大师会告诉你，近期你可能“事业不顺”、“身体抱恙”、“破财之兆”、“流年不利”等一系列负面情况。

他们善于放大人们内心的恐惧，告诉你，若不按照他们的建议“改命换运”，轻则诸事不顺、钱财不保，重则飞来横祸、家破人亡，求签者听到这里，基本上都吓得双腿发软，浑身哆嗦，而大师们也就开始了最后一步收割。

# 第三步：开光法器，破财消灾

刚开始花费的几十上百块测算费只是门槛，大师们根本看不上这点小钱。当你经过前两步的洗脑，担惊受怕之际，大师们会给你提供消灾解难的方案。这时候，大师们才真正露出狐狸尾巴。有乱七八糟的灵符，还有改运饰品、风水摆件等。

这些东西大师们都谎称开过光，所以价格也不低，一个风水摆件少则数百，多则上万，开光这种东西我们姑且不论真假，但是哪天你到义乌小商品市场走一趟，或者拿手机到淘宝上搜同款，就会发现这些“法器”只要几块钱就能买到。
