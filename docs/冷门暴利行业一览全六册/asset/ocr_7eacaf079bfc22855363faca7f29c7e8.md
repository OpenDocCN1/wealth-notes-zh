# 利润高不Sell眼的暴利小生意，九色优选努力 3 个月年赚 100 万

说到利润高不Sell眼的暴利小生意，很多人肯定想在实体生意中找点什么来做，但实体生意不好做，特别是在今年疫情的影响下，像昨天小编还在想，我经常去吃的哪家卖煎饼果子的杂样了，你还别说人家卖煎饼果子一个月至少赚个两三万，但这两个月肯定在屋头坐吃山空，心里着急。

我这样说并不是闲操心，而是想说其实网络上有很多小生意，暴利，门槛更低，还有受地域限制，做起来比实体生意赚钱多了。像我今天要推荐的，说努力 3 个月年赚 100 万，那绝对不是胡吹，而是真的能够赚到。

今天要说的不起的暴利小生意，就是信用卡刷卡取现与信用卡代还款市场，中国信用卡持有数量已经有 5 亿，这当中多少人每天想把里面的钱取出来用，又有多少人因为还不上信用卡而烦恼，相信不用我介绍，大家也应该明白这个市场有多大，而我们要做的就是推荐一款叫九色优选的 app，这款 app 具有 pos 机功能，能够让大家刷卡取现，同时也具有信用卡还款功能，在大家缺钱还不上信用卡的时候，可以通过软件代还。当然这两个操作都是需要手续费的，而我们要赚的就是这个手续费。
