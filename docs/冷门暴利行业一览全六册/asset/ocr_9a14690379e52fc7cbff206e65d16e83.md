# 天猫代入驻暴利项目，两个月搞一辆宝马五系

今天小编要说的这个业务，本来是我一哥哥的阿姨在做的，不过她属于代账公司，操作的是后方市场的业务，就是营业执头的输出。

想要了解这个业务，咱们首先就得熟悉天猫店铺的入住条件，详细的不说，最基本的几条大纲你得知道：

+   1)、开店公司注册资本高于 100 万人民币(包括 100 万)；
2)、开店公司依法成立并持续经营两年及以上；
3)、开店公司需具备一般纳税人资格。
4)、注册商标的时间要满两年以上，如果发现商标转或者卖的话，也要达到一年的时间。意思就是商标状态为 R 标，而且需注册满两年及以上，并在最近一年内未发生转让。
5)、店铺所经营的商品或服务必须符合法律法规、国家标准等质量要求，同时符合平台商品质量标准、天猫规则及商品发布规范等要求，详情请参见相关《平台质量标准》、《天猫抽检行为规范》、《天猫行业标准》及《天猫规则》
