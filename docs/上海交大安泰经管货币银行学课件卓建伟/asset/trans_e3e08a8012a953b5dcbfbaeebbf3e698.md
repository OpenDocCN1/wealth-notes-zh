
# 金融中介机构的功能：间接融资

- 信息不对称
  - （交易前）逆向选择：试图避免选择风险借款人。
    - 收集潜在借款人的信息。
  - （交易后）道德风险：确保借款人不会从事妨碍其偿还贷款的活动。
    - 签订具有限制性契约的合同。

对于金融市场的健康运行而言，逆向选择和道德风险会成为严重的障碍，而金融中介机构能够减少此类问题的发生。

## 2.6 金融中介机构的类型

- 存款机构
  - 商业银行
  - 储贷协会和互助储蓄银行
  - 信用社
- 契约型储蓄机构
  - 人寿保险公司
  - 火灾和意外伤害保险公司
  - 养老基金和政府退休基金
- 投资中介机构
- 财务公司
- 共同基金
- 货币市场共同基金
- 投资银行

## 2.7 金融体系的监管

- 帮助投资者获取更多的信息：
  - 降低逆向选择和道德风险的发生
  - 减少内部交易的发生 (SEC).

## 金融体系的监管

- 保障金融中介机构的稳定运行：
  - 准入限制（准入限制）（chartering process）。
  - 信息披露（信息披露）。
  - 对投资与业务活动的限制（对资产和活动的限制）（控制持有风险资产）。
  - 存款保险制度（避免银行挤兑）。
  - 有限竞争（Limits on Competition）（多在过去）：
    - 分支机构，美国独立行制度，禁止设分支机构，中国相反
    - 利率限制，利率有一定管制，中国严格管制。
