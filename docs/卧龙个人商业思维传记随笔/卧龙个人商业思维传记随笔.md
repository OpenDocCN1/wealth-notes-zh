# 煤气前端实施细化方案：

- 1. 主要是煤家挨户贴送煤气名片（贴广告） --目前也是以此为主目前可扩展；
- 2. 在每村招收一个家庭代理，直接用熟悉做事。这样效果最好（看情况而定）

# 渠道：

- 1. 直接电话送气
- 2. 后期直接铺设管道（每户没家一共用）。 --最好的方式，也要考虑实际情况和支出成本

# 对收破烂我怎么规划？

- 1. 线下渠道建立一个专门回收各种破烂的场地，为了突出竞争优势，当然回收价格比别人都要高些，这样我就靠收破烂为生，都会到我这里来。
- 2. 上网建一个收破烂网站（利用百度教育）可以精准定位，只需要在网注册一下，如果你家有破烂要出售，然后我们的业务员就会根据地址，上门服务）
- 3. 为了扩大我们的利润，在把本地物流代理过来，如果路上恰好路过，正好把物流产品送上。啊哈 先进吧。
- 4. 为什么收破烂物流物就到我了。因为物流和收破烂都是同转率大的，且有趋性 不过是一个是送，一个是收，另外收破烂的去的时候空车子，这资源不是浪费了么。物流如果顺路也花费不了多少时间。
- 5. 然后如果成了，后期就把贵金属的业务，开厂子，自己做钢材，或者其他模具，然后赚到端更多的利润。

后来在日志说上看到了一个俄罗斯小伙：”做了一个格子网，然后出售广告位，其实现在讲也就整合成一下资源，把广告都整合到这里了 以后采购，进货，出售都可以在这里做。”

然后当时最简单的想法是：“我也要做这么个东西，这个网站站广告网”

# 对于格子网我怎么规划？

- 1. 把一切能整合的商家都整合到上面，前期别人以为我没流量，先免费给一些大企业做格子图图片广告。 主要选择信誉度比较高的企业。
- 2. 然后在连胜，说这些大企业都和我们签约了，然后有些公司，会想把自己的公司也弄到上面去，我就收钱1000一个月。
- 3. 把这些商家分类，且细分城市，具体哪个城市，做什么的，都比较清晰，便于真正商家采购使用。
- 4. 然后如果有商家想要得到更多的订单，定然会找我把他们的广告放到前面，或者比较显眼的位置，然后这些又可以收钱了。
- 5. 然后把这个网站广告位卖完了，就招几个人好好管理维护一下，我就那钱走人，做其他项目，后期盈利率还是我的。啊哈  败了就败了

# 本地超市我是这么规划？

- 1、每个区域一个业务员负责，送货
- 2、另外选择能吃苦耐劳的员工，且家庭贫困的 因为有共同感受，对乡里乡亲的都有好处。
- 3、业务员服务范围，除了每天送新鲜牛奶，还要把本地物流代理起来，还有网上超市的购物产品，及时送到客户手中。
- 4、因为每天都会送牛奶，所以不会超过一天就能够到。

为什么有些人越活越顺当，就是他们遇到困难就笑笑啊地解决，老天爷送给他们的麻烦，他们都悄悄消化了。为什么有些年人越越大，越感到生存艰难，就是他们年轻时，遇到困难就逃，就做简单的事儿，结果也就只能过最卑贱的生活。用不着可怜他们，他们就是年轻时嗜麻瘾都没 有解决，所有年老了，才会有那么多磨难。没有两头甜的人生……

可怜人必有可恨之处！

现在很多 人，怕麻烦，不愿测试项目，觉得是浪费时间，我浪费钱还不怕呢？你还怕浪费时间。没有公司，没有团队的人，时间本来就该被其他人浪费，而不是自己跟着浪费浪费。自己浪费自己的时间没吃饭，让别人浪费就有饭吃了！都说穷人自由，我看不是，他们一天到晚都要为医疗和教育担心。我就不担心这事儿，生病了，直接让司机开车去医院就行了，孩子想读大学，直接给他买单就是了，反正也花不了几个钱……

前期做项目怕麻烦，急于赚钱的兄台，购买各种各样的项目，结果n多项目都没赚到钱，一个项目至少要做1个月或者3个月，而且每天全职做16个小时，对这样的人，我淡分为极其蔑视的人。有些傻逼，做几年网络创业，动不动还会说这些项目今天做，明天就保证100% SPO的广告变现，我只能说，他们永远都没有自己的公司，也不会有核心的团队，什么广告吸引什么人…… 真心想赚钱，不重复制他的模式，教程买了，跟他一样买广告位做。

## 【卧龙思维破解（1）】

物质决定意识，经济基础决定上层建筑。人的自信是建立在物质层面上，穷困潦倒，就算有满腹经纶，自信也会慢慢在冷冰冰的现实面前低下头来，逐渐褪释。一个生活在底层的人，很难有做梦天下的眼光与轩昂的精神气概……

## 【卧龙思维破解（2）】

一切与生产有关的知识，都是我们学习的对象，不是单纯有字的书本里面才含有智慧，凡是有人类，有红尘的地方，都有闪闪发光的智慧，我们在做项目的过程中，要了解各种各样的生活常识，接触各种各样的人，思路打开了，就会有很多赚钱的思路。如果再将所有的人脉与资源整合起来，这就说明我们具有卓越的领导能力与资本运作智慧！

## 【卧龙思维破解（3）】

如果我有100元钱，如果放地摊生意，我会打印100份广告，夜晚悄悄张贴贩，销售各种各样的偏方秘籍。如果是在网络上做生意，我会买100个XX账号，直接在某网站扒发各种各样的偏方秘籍，不出三天，我就能稳定在每天千元左右的收入。内功到了一定的火候，无论是在地面，还是在网络，赚钱都很轻松，内功不到，看啥都觉得是忽悠，是垃圾……

一般人呢？
手里有100元，要么存起来，要么喝酒泡妞姐，压根没有一点儿投资意识，更不用说怎么样深度研究经营资本和整合资源了，看不到资本的力量，只能在贫困面前做精神的睁眼瞎，这是一种深沉入骨髓地悲哀……

## 【卧龙思维破解（4）……】

以前，我说过一句话，如果大家每天养成花10元投资的习惯，一个月后，大家每个月都可能赚到1000元；如果大家养成每天花100元的习惯，一个月后，大家就可以赚到10000元。只是大家必须深刻领悟投资的艺术，花钱要比赚钱有深度多了，不细细研究，压根就看不到其中的玄机……

## 【卧龙思维破解（5）……】

男人必须有钱。缺钱就没有了事业的基础，缺钱就得不到良好的教育，缺钱就影响自己的心态和眼光，影响到自己为人处世的方式，甚至影响到人的整个前途。为什么穷人的眼光极其

有限？物质决定意识，物质贫穷，导致思维闭塞，不舍得投资，不敢冒险，只小心翼翼地过日子，真正能以自残，狗道者精神佛项目，玩创业的平台壕塞无几……

窃以为，人生最大的风险就是自己一辈子都是穷人，而不是在创业的过程中损失了几千几万块贪花钱……
