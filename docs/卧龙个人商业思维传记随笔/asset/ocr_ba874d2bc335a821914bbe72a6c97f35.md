# 5.职介

上一年马上过年了，然后看到一个广告，说是招收学生代理，不打工就赚上万，我看了一下 就是招收一个人，给500元提成，如果招收到30个人，就能挣到15000元。30个人，因为快过年很多人就为很多家庭不好，都选择挣点钱，然后我就到群里发布了这个信息，很快就有很多人员报考名，为了扩大宣传，我就打了一个横幅，名字为：我们一起组队去打工。 组织的 队人还不少，我说那是我哥在管理的厂子，信誉没问题，如果被欺负了打我电话。 因为之前说好的，进厂都是要签合同的，善田绿拇那公司我在网上查了一下 合同还不错，所以跟他们签订合同和合同。 然后我出很多合同报名学生的都被签约的。 最 后收录了76个学生，然后有2个来回说了。结果失败了。 然后我最后也没去。我才懒的去哪，最后说：”家里有事情，父母让我回去，有什么时间跟我打电话“一一因为先前调查好了，所以他们最后也没遇到难处，都平安拿到工资了，而且同学都感谢我那，请我吃饭 呵呵 。

现在职介我也是很看好的，其实用任何行业都有内幕，后来我才发现其实厂里面给他们劳务中介大概有1000大洋。一般介绍一个人1000左右，现在想想我真他妈的善良，还傻傻傻的非常高兴。 如果笔是乐是不错，但是被忽悠真觉得自己傻逼 我特意让V哥打个电话问了一下。结果省省省出800-900提成，想想难道我不谨慎 还是太善良了。 所以啊，下次要贵比三家。

分析现有市场职介：市场还是非常火爆 经营难，就业压力大， 且工资低 尤其是到了过年，年过了，然后很多农村的孩子都是从新找工作，因为工资高的，且比较稳定的还是电子厂，最后很多人还是会去电子厂工作。

认识了一个朋友：就是年前报名送年货 就是报名了， 拿着100元消费卷可以在你所在本地超市买100元的东西。 这样就能锁定了客户，不需要有超市渠道合作，需要和超市供应商合作当然最好。 因为他们都是有n年的合作关系，对于这个一般都会同意。 而且超市流量大，在超市做横幅广告，效果还是不错的。 如果年后，找不到工作，自然而然会有人主动报名。
