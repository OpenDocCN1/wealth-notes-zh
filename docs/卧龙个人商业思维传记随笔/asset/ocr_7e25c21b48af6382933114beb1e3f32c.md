竟然想当收破烂大王，在高二的生物课上走神想的是，毕业了，我回家搞养殖，种植一体化。因为当时我是喜欢看《生财有道》这类创业故事节目，然后看到各种种植，养殖都发家的人，心情澎湃的跳，跟自己做一下，就立刻能成功一样。竟然这节课上，规划了100年后龙的一生，毕业了，去搞养殖，种植，教育好孩子。顺便把煤炭产业链，鞋子产业链搞起来。最后赚钱够了，就回家把那个“动物食物链”改造成最大化搞起来，成不成功不是问题，自己想要尝试试试就好了，然后安老一生，陪我爸下象棋，喝喝茶，溜溜弯就好了。

# 对收破烂我怎么规划？

+   1. 线下渠道建立一个专门回收各种破烂的场地，为了突出竞争优势，当然回收价格比别人都要高些，这样我就靠收破烂为生，都会到我这里来。
2. 上网建一个收破烂网站（利用百度教育）可以精准定位，只需要在网注册一下，如果你家有破烂要出售，然后我们的业务员就会根据地址，上门服务）
3. 为了扩大我们的利润，在把本地物流代理过来，如果路上恰好路过，正好把物流产品送上。啊哈 先进吧。
4. 为什么收破烂物流物就到我了。因为物流和收破烂都是同转率大的，且有趋性 不过是一个是送，一个是收，另外收破烂的去的时候空车子，这资源不是浪费了么。物流如果顺路也花费不了多少时间。
5. 然后如果成了，后期就把贵金属的业务，开厂子，自己做钢材，或者其他模具，然后赚到端更多的利润。

后来在日志说上看到了一个俄罗斯小伙：”做了一个格子网，然后出售广告位，其实现在讲也就整合成一下资源，把广告都整合到这里了 以后采购，进货，出售都可以在这里做。”

然后当时最简单的想法是：“我也要做这么个东西，这个网站站广告网”

# 对于格子网我怎么规划？

+   1. 把一切能整合的商家都整合到上面，前期别人以为我没流量，先免费给一些大企业做格子图图片广告。 主要选择信誉度比较高的企业。
2. 然后在连胜，说这些大企业都和我们签约了，然后有些公司，会想把自己的公司也弄到上面去，我就收钱1000一个月。
3. 把这些商家分类，且细分城市，具体哪个城市，做什么的，都比较清晰，便于真正商家采购使用。
4. 然后如果有商家想要得到更多的订单，定然会找我把他们的广告放到前面，或者比较显眼的位置，然后这些又可以收钱了。
5. 然后把这个网站广告位卖完了，就招几个人好好管理维护一下，我就那钱走人，做其他项目，后期盈利率还是我的。啊哈  败了就败了

后来的思维扩展到了，见一个商业网站，商团啊啥网，中国生意网，中国旧书批发网，中国二手书批发网等。 一系列整合资源的网站。 现在及发现我整合思维还是比较强的。
