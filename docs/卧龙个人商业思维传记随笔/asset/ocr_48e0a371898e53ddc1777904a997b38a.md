# 4.就是好的商业模式和加强管理。

看到“煤炭这个燃料”，预测：随着工业化进程的发展，农村定然从传统以“烧锅做饭”转型到更方便、快捷的煤炭行业。随着煤炭行业在农村的成熟，定然会发展到管道输送。至今管道在农村发展还未大范围兴起，… 相信，在未来城镇化建设到农村，定然把传统煤炭运输直接“管道运输”，另外预调土地个人集约化承担责任制，也会不断升来。还有一个农村牧地更改制度，农村大田地里面，处处可见坟地占天的现象，可能国家领导都不在农村看，也可能是怕影响传统文化，或者实行过程矛盾重重，国家定然会在随着农田耕地的不断减少，定然会在未来 50 年改革。

如：坟地集体化，相坟转移固定点 甚至为了节约土地，弃几个百年的坟地大厦都有可能。

哈哈 卧龙已经超神了竟然能预测未来，越想越激动…………

这个之外，我还预测一个更给力的项目。 未来的不是老龄化严重么。 然后果断就大胆预测，是不是棺材会越来越好卖，虽然实行了火葬制度，但是仍然需要棺材入殓。老龄化严重也大带动了葬礼生意的火爆。卧龙是怎样的计划？

+   1. 做棺材  而且做概念观察（金 socket、银 socket、普通黑白棺材，因为对于死人，一般都是厚葬。利用这个原理，卧龙做出了这个概念——所谓皇家葬礼）
2. 葬礼也分模式（民间葬礼——官员葬礼——皇室葬礼（呵呵 很多人死了，话看不孝顺，死了到非常考量，都会奔这个皇室葬礼））  当时还不知道什么是人性。
3. 棺材分等级——区别就是颜色，和一些包装不一样，还有一些（姥子，扎花，这个最暴力。 呵呵 ）
4. 自己和加工厂合作，后期然后自己生产  葬礼的各种东西，如果在城市的话，墓地代售。

想都激动，然后跟一个同学讲了一下，就是在高二，他说我太早期天开，我到没觉得得，感觉就…… 因为非常喜欢诸葛亮，对诸葛亮很崇拜，3 中，我最看好诸葛亮完，后来我称之为他为策划高手。  因为能预测未来的状况，解决后而可能发生的问题。

现在吧，看见诸葛亮，就我走不动了，非要去个究竟  他的文章，我就深入研究。学习自强模式模仿。 在日志上看到《诸葛亮给儿子的十句话》然后果断转载到空间，复制当做我儿子的家训了。  以后吧，我的后辈，都依照这个为祖训。

貌似扯远了，扯到个人主义了。

继续讲葬礼带来的商业思维。

想了丁别，别人有坏事情找到我，我想有好事情也能找到我，于是结婚物品为一体的服务应运而生，当时的想法是：“弄两个门面，一个装修为全部为黑色的，另一个则装修为全部红”
