狗顿说：“老师以前提过风险控制问题，老师认为资金管理、止损和
卖出策略这些交易技巧是成功交易的保证，但没展开论述过。”

鸥夷子皮点头：“现在开始，我重点阐述这三个交易技巧。资金管理
是三者中最重要的技巧，是风险控制的最重要方式。”

鸥夷子皮认为，资金管理的重要性体现在以下几个方面：

+   1. 帮助交易者保障本金。

+   2. 帮助交易者控制亏损。

+   3. 帮助交易者明确知道何时退场。

+   4. 帮助交易者限制允许发生的最大亏损。

狗顿道：“仓位管理问题是交易中的一个难题，老股民都有认识，锄
禾日当午，不如交易苦；仓位补不补，心里多痛苦。”

鸥夷子皮讲道：“严格的资金管理，是所有成功交易者的共同点。资
金管理，通过调整仓位来保障本金安全和锁定亏损。仓位比例问题是资
管理的难点和重点，也是决定投资波动和收益率水平的最关键因素。交易
分析做得再好，即使一项交易的期望值为正，但是，如果资金管理有大问
题的话，也会出现大的交易损失。”

鸥夷子皮总结了资金管理的几大注意事项：

+   1. 在能力允许范围内交易。

+   2. 交易首先要考虑亏损，然后再考虑盈利。

+   3. 不得满仓买入，不能被动听从市场命运的安排。交易中不得动用
全部资本，要分批进入，观察市场走势是否符合自己的判断。

+   4. 任何单笔交易所承担的最大损失，不能超过本金的5%。

+   5. 明确自己的最大亏损额。

+   6. 加码的顺序应该是由大而小。也就是说，成本越低，数量越多；
