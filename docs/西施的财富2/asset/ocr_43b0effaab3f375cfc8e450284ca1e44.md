# 8. 投资丛林中的动物世界

猗顿大喜道：“学生以前初学炒股时，股民大都如此区分炒股方式，或投资、投机，或长线、中线、短线；而老师或包子、馒头，或各种投资生肖，定义通俗、深刻，还形象；两者相比，简直是云泥之别。老师对投资的讲授让学生豁然开朗，就像迷失方向的船看到了灯塔、丢失的孩子见到了爹娘一样。”

鸮夷子皮笑道：“你对我的吹捧也如滔滔江水，连绵不绝了是吗？说到动物，我们还可以用动物来比喻投资市场中的各种参与者，也可以比喻股市中各种个性不同的个股。股市变幻莫测，充满了危险和恐惧，正如神秘丛林一般，潜伏着各种猛兽和危险；如果我们将股市比做投资的丛林，那么，你们愿意做丛林中的那种猛兽吗？猗顿，你先回答。”

猗顿回答道：“我愿意当丛林中的老虎。”
