# 要：

有一个叫老彼得的犹太人，是一名优秀商人，他事业有成，但儿子却不成器，不学无术，整天只知道吃喝玩乐，不工作不结婚，让他很是担忧，于是，老彼得决定应用他的商业智慧，好好帮儿子运作一下。

他先去找儿子：“Hi！小约翰，我说你是不是该结婚了，我介绍一 位好女孩给你认识吧。”他的儿子小彼得很不乐意：“算了吧，我的事 您就别操心了，我女朋友好多的。”老彼得：“我说的这位小姐，可是比 尔·盖茨的女儿呀。”小彼得一听两眼放光：“噢？是真的吗？如果是这 样的话，我会马上结婚的。”

几天之后，在一个酒会上，经朋友介绍，老彼得见到了参加酒会的首 富比尔·盖茨。老彼得：“Hi！比尔，听说您的千金正在择婿，我介绍 一个优秀的小伙子给您认识吧。”比尔·盖茨不乐意：“孩子的事儿就让 她自己做主吧。”老彼得：“我说的这位小伙子，可是世界银行的副总 裁啊！”比尔·盖茨：“噢？是真的吗？如果是这样的话，那我一定考 虑。”

第二天，老彼得马上去见世界银行行长。老彼得：“听说贵行正在 重组高层管理人员，我介绍一位优秀的小伙子来做分管VIP客户的副总 裁吧。”行长不乐意：“对不起，我们已经有了考虑人选。分管这方面的副 总裁得有很好的人脉关系，才能帮助本行获得更多的存款，如果太年轻的 话，恐怕难以胜任。”老彼得：“我说的这个小伙子，马上要成为盖茨的 女婿，既然您这儿不缺人手，那我就推荐给别的行看看。反正盖茨手里的 钱存哪儿也是存。”行长：“噢？是真的吗？您看我刚才不是说了吗，我 们也仅仅有了可供参考的人选，如果有更优秀的人才，当然要择优录 用，欢迎您所说的这位优秀人才随时就任。”

于是，小彼得和比尔·盖茨的女儿结了婚，也成了世界银行的副总 裁。老彼得又运作了一门成功的生意。
