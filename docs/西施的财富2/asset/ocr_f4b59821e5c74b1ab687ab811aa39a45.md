# 6.  塑造你的投资交易系统

鸱夷子皮严肃地说：“咖啡派所用的这个案例是偷梁换柱，偷换概念，正好说明了咖啡派的眼高手低，证明他们对投资一知半解。投资仅仅是挑选个股吗？投资仅仅是做好投资分析吗？咖啡派太不了解投资了！”

鸱夷子皮解释道：“人猴投资比赛是将挑选股票作为投资的唯一。将猴子选择的股票和专家选择的股票，按同样份额平均配置，将所有资金满仓投入，这种投资方式，不考虑配置比例，不考虑资金管理，只看重所选的个股，完全是对投资的误解和扭曲。”

范道生问：“炒股，不就是找到黑马，然后骑上去吗？”

鸱夷子皮说：“大众的投资方式就是这种赌博式的，到处打探内幕消息，在打听到某只股票可能会成为黑马后，就投入全部资金买入，然后等待，期望高点卖出以后，桑塔纳进去，奔驰车出来，虽然确实有人是奔驰车出来，但那个人一定不是人，大部分人的结局都是桑塔纳进去，奔驰牌照
