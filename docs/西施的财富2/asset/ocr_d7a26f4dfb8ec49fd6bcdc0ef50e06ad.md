# ### 32. 涨停板背后的秘密

猇顿狡黠地眨眨眼，说：“市场上有一些游资，号称敢死队，全国大概有几百人，以宁波的游资声势最壮。他们短短几年间，就从几万元、几十万元的小散户，成长为在股市兴风作浪的大鳄，其一夜暴富的独门秘籍，正是这种坐短庄的方式。这种方式，看似每次的利润率不高，但通过资本的快速周转，从而使得年均收益率大幅提高。其实，这种交易方式，在实业投资中，也被充分应用，在投资管理理论中，有一个叫杜邦公式的，讲的就是这种原理。”

于是，猇顿又讲起了财务分析时惯用的杜邦公式：

```
投资收益率= 净利润÷股东权益
= 净利润×总资产÷股东权益×总资产
= (净利润÷总资产)×(总资产÷股东权益)
= (净利润÷总资产)×杠杆系数
```
