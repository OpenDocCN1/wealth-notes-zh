# 29. 鬼谷子的炒作秘籍

第二天，猗顿一早就来找西施和道生。

“老师安排我们各自独立进行投资演练，但我感觉我们的投资风格接近，可以搭伙一起投资，有疑难困惑可以共同商讨，你们意下如何？”

还没等西施开口，道生就满口答应：“猗顿大哥，我觉得你脑子反应最灵活，我也想跟着你多学习。”

西施瞪着道生，不吭声。

猗顿神秘地向四周张望，看见鸱夷子皮没在，就从怀里掏出一个包裹，小心翼翼地打开，里面包着一本看似很破的旧书。

猗顿压低了嗓门，小声说道：“这是一本致富奇书，叫《炒作秘籍》，为神秘策略大师鬼谷子先生所著，是世界难得以珍品，里面全是讲述如何通过炒作牟取暴利的高级技能和顶级操作手法，我最近真是走狗屎运了，运气太好了！既能碰到鸱夷子皮这样的名师，又能不花钱找到美女老婆，前几天又是机缘巧合，在地摊上发现了这本鬼谷子先生亲著的孤本
