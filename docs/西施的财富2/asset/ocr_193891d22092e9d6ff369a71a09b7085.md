# 37. 竹林对话：放弃是心灵的救赎

![](bbox=[0.06, 0.29, 0.08, 0.4])

西施去爬山时，鸥夷子皮如往常一样，出外钓鱼。

鸥夷子皮最近为了研究溪鱼，大都不去以往常去的水库、江边或海边，而多去人迹罕至的山涧。

这天，他来到梧桐山谷，寻得一清泉小溪，溪旁有竹林。丹霞蔽日，彩虹垂天；溪水潺潺，叶落翩翩。

有山风穿过竹林。竹林的风是一种清凉，是一种幽静，其声呜呜然，如怨如慕，如泣如诉，余音袅袅，不绝如缕，只让人感觉寂静得可怕。

鸥夷子皮静心钓鱼。不消一会儿，桶里已经有几条青鱼在游。

鸥夷子皮正要将一条上钩的鱼放进桶里时，忽然发现眼前有个黑影，仔细一看，原来是子宁。子宁手握一把剑，一言不发，立于鸥夷子皮身后的桶旁。

鸥夷子皮笑道：“在春日微醺的阳光照射下，你就这样飘然地从竹林中走出，好似从历史的帷幕中穿越而来，吓了我一跳。”
