鸥夷子皮正色道：“对于经商而言，天才和骗子之间，仅仅只有一张纸厚度的差别。一个创新的商业灵感，成功了就是商界精英，失败了就成为骗子。实际上，无论是经商，还是从政；无论是教书，还是管理，只要和人打交道，只要涉及竞争和合作，就会有经营，不同的人，经营水平高低不同，可分为几种不同的境界。”

鸥夷子皮将经营境界分为以下几种：

+   1. 一等人是神：他们贩卖价值观和思想，让他人为其舍命卖命、不计代价，他们被神化，拥有无数信徒和膜拜者。这类人包括：释迦牟尼、老庄、巴菲特，或许也包括我，呵呵。

+   2. 二等人是天才：他们贩卖标准，为个人、企业或其贩卖的商品和服务树立一个标杆，成为其他人或行业学习模仿的对象；他们也拥有无数的粉丝和拥趸，但尚没被神化。这些人包括：乔布斯、曾国藩、比尔·盖茨、韦尔奇等。

+   3. 三等人是鬼才：他们才华出众，经常灵感迸发，他们的灵感实现则为天才，灵感运作失败则为骗子。此类人有：牟其中、庞兹骗局中的庞兹、牛云、苏秦、张仪等。

+   4. 四等人贩卖质量，他们致力于提高商品或服务的质量，努力降低成本，以性价比在同行业胜出。优秀商人和管理者大都属此类。

+   5. 五等人贩卖商品本身，他们忙忙碌碌，但思想平庸；他们围绕商品本身而工作，让顾客为购买而购买。他们是各行各业最普遍最普通的人，绝大部分人都属此类型。

+   6. 六等人是骗子，他们打着贩卖优质商品和服务的旗号，但却提供虚假伪劣产品，或直接骗人钱财，在消费者看来，无论他们是主观行骗还是被动骗人，提供的产品远远满足不了消费者的期望，就是骗子。
