急性子（H）：急性子的人行为节奏快，目的导向性强，不重视过程而追求结果，效率高；一般思维敏捷、办事麻利，但是普遍缺乏耐心，宽容性差，易动怒。

慢性子（M）：慢性子的人一般脾气好，耐性好，待人接物能泰然处之、不急不躁、沉着稳重；一般时间观念性差，效率相对较低。

鸥夷子皮说：“以上5种不同的性格决定因素，构成了人类的32种不同性格，这些各不相同的性格类型，决定了各人具有不同的个性、不同的思想，也决定了各自不同的命运。如果人们能清楚自己的性格特点，扬长避短，在适合自我风格发展的领域和行业找到位置，就更容易取得成就。同样，这些各不相同的个性特征，也决定了人们在进行投资时必然具有不同的风格特点。”

鸥夷子皮开始简述不同的性格影响因素所具有的不同的投资特点：

+   1. 内向型的人一般在投资估值方面更敏感、更精确，对情绪控制力较强，不易受大众心理的影响，不易受羊群效应心理的影响；而外向型的人善于人际交往，善于获取信息，善于应对复杂的风险环境。

+   2. 幻想型的人对投资的期望值偏高，一般对投资结果偏于乐观，但善于掌控风险；而现实型的人重视现实的实际状况，容易挖掘估值过高或过低的投资品种。

+   3. 理性的人注重对投资的逻辑分析，倾向于价值投资；感性的人则喜欢跟随人类的情绪，喜欢顺应趋势，更适合技术分析。

+   4. 资本市场具有可测但测不准的规律，虽然变幻莫测，但仍有章可循。生活规律性差的人较易适应这种多变性，容易随波逐流，投资较易顺势而为；而生活规律性强的人投资执行力较强，止损会严格，纪律性较强。

+   5. 急性子的人侧重效率，通常对时间较敏感，投资周期偏中短期；而慢性子的人时间观念性不强，投资时间通常偏中长期。
