# ## 9. 投资心理学：人人都是朝三暮四者

西施的智慧

Ⅱ

陶朱之术

这天，鹅夷子皮准备上课前，发现郑旦埋头在看一本书，一边看，一边偷着乐，乐得终于忍不住了，就哈哈哈哈地放声大笑起来。

鹅夷子皮很好奇：“看什么书呢？有这么好笑吗？”

郑旦这才发现鹅夷子皮的出现，她说说话时仍然抑制不住笑声：“哈哈，我在看一本关于吝啬鬼的书，太好笑了！哈哈哈！我给大家讲一个吝啬鬼的笑话吧！”

郑旦于是讲了一个关于吝啬鬼的笑话：

吝啬鬼不小心掉进了河里。有一个好心人趴在岸边，伸手要救他：“快把你的手给我！”这吝啬鬼死活就是不肯伸出自己的手。这个好心人很纳闷，竟然还有宁愿死也不愿被救之人！路人提醒：落水的是闻名全国的吝啬鬼。好心人突然醒悟，就冲着即将没顶的吝啬鬼大喊：“我把我的手给你，你快抓住！”听了这话，吝啬鬼这才终于伸出手来，一下子就抓住了这个好心人的手。
