# 38. 财神的慈善

![](bbox=[0.04, 0.26, 0.1, 0.38])

日月如梭，时光飞逝。一晃十年过去了。

西施、骑顿和郑旦初期在股市大有斩获，然后通过收购上市公司股份，逐渐成为公司大股东。他们按照老师传授的投资技能，控股在管理、技术、服务等方面具有自然垄断优势的企业，也就是具有“护城墙”特征的高成长行业，取得巨大成功，成为齐国商界举足轻重的风云人物：西施五年后就进入福布斯齐国富豪排行榜，历经十年后，西施、骑顿和郑旦分别当年福布斯齐国富豪榜的前三位。

西施控股的上市公司所属行业为消费类的酿酒业和食品业，主打产品分别为西施酒和西施豆腐。西施酒分为高档的“西施美女酒”和中低档的“西施稠酒”。“西施美女酒”针对富裕阶层和商务人群，其主打广告语为：“成功了西施为你庆功，失败了西施陪你消愁！”一句蕴涵深情而情意绵绵的广告词，勾住了无数成功男士的魂，在高档酒宴上，要是喝其他品牌酒、而不喝“西施美女酒”的话，都不好意思说话；针对中低档市场
