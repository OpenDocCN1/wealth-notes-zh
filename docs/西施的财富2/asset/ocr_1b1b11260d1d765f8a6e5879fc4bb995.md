```
杠杆系数=总资产÷股东权益
投资收益率＝（净利润÷总资产）×杠杆系数
＝［（净利润×销售收入）÷（总资产×销售）］×杠杆系数
＝［（净利润×销售）×（销售÷总资产）］×杠杆系数
＝净利润率×总资产周转率×杠杆系数
```

翁顿说：“根据杜邦公式，很明显，提高投资收益率的方法只有三种，即要么提高净利率，要么提高总资产周转率，要么提高杠杆系数。在净利润率难以提高的情况下，可以通过适度借债，提高杠杆系数；但杠杆系数太大的话，风险就过高，只能通过加速资金周转，提高总资产周转率，所谓货如轮转，从而提高总的投资收益率，无论证券投资，还是实业投资，此原理都适用，这也是短庄操作好的话，收益比其他方式更惊人的道理。”

道生说：“听你这么说，用不多的资金可以进行坐短庄，但关键要有媒体平台推荐才行，我们缺乏媒体的配合，怎么进行炒作？”

翁顿笑道：“山人自有妙计。你有没有注意到，股市中每天总有一些个股涨停？”

西施说：“是啊！我看到股市每天总有一些股票莫名其妙地涨停，难道这里里蕴含着什么秘密吗？”

翁顿说：“涨停板的背后确实有秘密。有些游资，并不靠媒体推介吸引散户注意力，而是充分利用散户的羊群效应心理，将一些有题材的个股拉到涨停，吸引散户注意，在散户追涨时，再顺势出货，这种操作手法被称为拉涨停式炒作法。”
