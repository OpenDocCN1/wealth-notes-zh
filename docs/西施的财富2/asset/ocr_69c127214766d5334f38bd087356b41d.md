# 24. 止损：学习壁虎好榜样

鹅夷子皮说：“要想通过交易获取盈利，你只能被动接受市场愿意给的，而不是主动设定你想要的。在别的行业，付出了就会有回报；在进行投资交易时，你的回报和你的付出没有关系，投资回报率不是你设定多少就多少，而是要看市场愿意给你多少，你就得接受多少。同理，卖出并不必然就是获利了结，更多时候，是为了锁定亏损而主动卖出，这就是如何止损的问题。

“在热带丛林的湖泊沼泽里，出没着一种猛兽——鳄鱼。鳄鱼经常会悄悄袭击路过沼泽或湖泊的人，如果在你涉水时被鳄鱼咬住了脚，你会怎么办？”

郑旦叫道：“太可怕了。巴菲特说过，如果知道那里有危险，就永远不要去那儿。我永远不会去有鳄鱼出没的地方。”
