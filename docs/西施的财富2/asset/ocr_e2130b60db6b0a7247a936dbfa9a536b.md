# ## 28. 猗顿的女朋友

西施、猗顿和道生又回到了齐国青岛市。

道生和西施向鸱夷子皮汇报商业经营情况。

“我们这趟出差，有好消息，也有坏消息，你想先听哪个？”西施说。

鸱夷子皮说：“我是悲观主义者，坏消息放后面，先听好消息吧。”

“好消息是我们这趟经商获利比我们想象的还要好，扣除所有花费，净利润率在10倍以上，现在我们的资本已达到280多万了。”

“那坏消息呢？”

“坏消息是文种先生的命运让你说中了。我这次回去，得知文种两年前已被勾践处死，处死的原因是他意欲谋反，图谋作乱。听说文种是自杀的，当时，勾践赐给文种一把名叫属缕的宝剑，这样说道，‘当初是你帮我想出伐吴九计这样的妙计，我只用其中的5条，就打败了强大的吴王，还剩下4条在你那里，现在请你用这4条，去地下帮我老子的忙，继续打败……”
