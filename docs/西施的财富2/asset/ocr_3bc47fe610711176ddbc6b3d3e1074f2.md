# # 25. 像军人一样守纪律

鸥夷子皮开始讲述交易中的执行性问题。

“大道至简，知易行难。无论是交易、减肥或向着任何人人生目标的奋斗，最困难的并不是不知道怎么做，而是知道之后执行的毅力、行动的決心，也就是执行纪律的坚决性。即使你有适合的投资交易系统，但是如果不遵循它的规则，不守纪律，不严格执行，那么，交易的结果必然还是一团糟。因此，无论决策如何完美，只有被有效执行，才能得以实现。严格执行投资纪律，依照既定的交易计划行动，就是交易执行力的体现。”

鸥夷子皮接着讲道：“成功者与失败者的差别，不全在于智慧和知识的差别，更在于执行力的差别。纪律，是一种人生态度，是知行合一者依据的法则和原则。巴菲特关于交易的执行力方面也有见解，‘我之所以能有今天之成就，是依靠于自律和他人的愚蠢；我们没有必要比别人更聪明，但我们必须要比别人更有自制力。’”
