二是家学。很多时候，我看到的只是一个个人的成长结果，没人会告诉你他的培养成长过程。这就需要家学溯源了。小到说话，大到站队，事事皆学问。单位里，也都不都是领导亲戚子弟，总要有几个精明强干的心腹。你能不能进入圈子，就看你懂不懂事，有没有眼水了。这种事情，只可意会，不可言传。领导总不能说，我家老人住院了，你给我找个优秀保姆来。怎么办呢？想在头，记在心里，办在实处。

# （家学）结交朋友的思维。

现实中，95%的人喜欢结交权贵朋友。人家有钱的，指望找他借钱。人家有权的，指望找他开后门。为了这个虚幻的目的，你首先投入了巨大的精力和一定的交际费用。实际上，你的想法是不可能实现的。因为权贵身边有太太多这样多的人。权贵朋友也没有能力给所有的人解决麻烦，捞取利益。

正确的思路是，不看钱权，而是看人的水平。很多人并没有显赫的门弟，也没有大把的金钱，但有一定的水平。有的是技术领域，有的是人情世故，有的是消息灵通。这样的人，一般有二十年以上的工作经验，或许还是事业的失败者。你适当留意。如果有能，可以熟悉一下。

我以前大单位的老同事遇到我，经常会说一句话，有什么发财的路子，带我一挦。我心里觉得好笑。你是谁啊，一句话就让别人带你发财？人的成长主要靠自己，不可能有人给你铺好路，带你发财的。

正确的打法是，你找到合适的朋友，给你一些你不知道的经验，在这个基础上，主要靠自己闯出一个路子。这才是真正属于你自己的财富。

# （家学）怎么培养孩子走基层路线？

我家族的先辈们，在解放前也是这么玩的，文学，艺术，金融，企业，审美，外语，交响乐，样样精通，都是半专业水平。但是，这种模式培养出来的人，有个巨大的缺点，不接地气。他们的圈子就会越来越小，小到只有十几个人，自娱自乐。一旦遇到时代的变革，啥也不是了。

圈子小的后果是，无法赚钱了。赚大钱，主要是带领一窂穷人，去打市场。例如脑白金。你要是了解下穷人，你就不会赚穷人的钱，无法管理员工，无法处理基层矛盾。当年莫斯科东方大学毕业的二二十八个半人，很难适应中国农村实际，屡战屡败，带不了队伍。相反，只有在基层千锤百炼出来的人，才能做大事。这群所谓的精英，最后的结果，无非是当个985老师，自顾自怜，曲高和寡。或者在父辈的基础上，接个董重长位置，一旦遇到狂风暴雨，根本没用。现在，中国的高一代大富豪，也不知不觉的走上这条错误的路，以为学历越高越好，外语越熟越好，但他们忘记了根本。我们的根本在基层，在于熟悉国情。这些人在国外也就是个普通人，在国内又不接地气，没啥头头的。
