# 第77课·排队营销的套路

# 各行各业通用的八个让顾客排队的内幕

+   1、邀集大量客户，准时开闸放水
2、不雇民工排队，就请熟人帮忙。
3、事先做好培训，现场有模有样。
4、缩小现场面积，减少服务窗口。
5、媒体发布信息，限量优惠让利。
6、散布“路透”新闻，产品供应不足。
7、传播小道消息，产品即将涨价。
8、自造“xx节日”，诱导扎堆赶集……
