# 第 87 课 · 广告的终极套路

# 广告的最高境界就是比广告更广告的广告

尽量使广告(特别是软文)贴近报纸的风格、排版习惯和内容环境，让排斥广告的读者在不知不觉中阅读，并被说服。

不少中小企业的老板向一诺老师倾诉：生意不好，想花点钱打广告，但费用高不说，最怕的是这些钱打了水漂。

现在电视、报纸上的广告也多了，老百姓要么熟视无睹，要么看了也像是没看到。他们请一诺老师支个招，有没有什么好的宣传方法，花钱既少，效果又好？

这确实是一个共同的问题。

不做广告是不行的，但做广告风险太大。
