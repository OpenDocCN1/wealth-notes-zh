# 第74课：产品型号的套路

# 把同样的产品卖出不同花样的内幕

一诺老师的一个弟子做变压器的，说这个不好做。

一诺老师说，你要把同样的变压器卖出不同。他问那怎么办？一诺老师说，你要说你这个变压器要叫四个品牌：

第一个名字的变压器，它适合于北方严寒气候用，零下120摄氏度还能用；

第二个是防潮变压器，拿到潮湿的地方还能用；

第三个是矿区变压器；

第四个把价格放出去，跟跨国企业冲。

一诺老师以前讲过几种产品创新术，这是新的一种。

虽然麻烦一点，但消费者喜欢。你的产品是细分的，消费者就相信你是专业的。
