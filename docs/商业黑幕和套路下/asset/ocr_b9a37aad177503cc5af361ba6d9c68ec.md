# “神秘、惊喜”是神秘营销最好的诱饵

可口可乐的神秘配方，大家都知道吧？

当然具体配方你是不��知道的，只是知道有神秘配方这么回事。可口可乐刚推出时，它的创始人宣布，可口可乐含有一种叫“7X”的特殊物质，能起到不一样的提神醒脑作用。

2006 年，印度最高法院以杀虫剂含量严重超标为由，要求可口可乐和百事可乐公开配方细节，但他们死活不同意。这可是人家保守了 100 多年的秘密啊！

据说，这个配方锁在亚特兰大一家银行的保险柜里，全世界只有 7 个人知道是哪家银行，其中 5 个人持有保险柜的钥匙，另两个人知道密码，必须 5 把钥匙同时转动，并输入准确的密码，才能开启保险柜。嘴在你身上，爱咋说咋说！（捂脸吧）
