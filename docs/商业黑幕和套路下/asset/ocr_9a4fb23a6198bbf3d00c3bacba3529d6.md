# 限量套路二：部分品种紧缺

有一家饭店门口挂出一个招牌，写着：“有钱吃不到限量版，手快有，手慢无，限量供应。”

一诺老师进去一看，原来并不是所有的饭菜限量，而是只有几种菜限量供应，每天只卖多少份。

你别说，很多人就是冲这几个菜来的。
