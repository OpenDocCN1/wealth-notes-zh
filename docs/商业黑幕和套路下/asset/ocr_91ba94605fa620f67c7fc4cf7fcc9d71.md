# 第97课·盈利是企业家的天职

# 企业不能盈利就像人失去了造血功能

诸位有用过“大宝”的吗？别不好意思承认，一诺老师就用过。跟大家说实话，大宝的护肤润肤效果还挺不错，就跟广告里说的，“还真对得起咱这张脸”！

大宝也曾红火过几年，高峰时销售额占到了中国护肤品市场的近20%。但在外资品牌大量进入之后，大宝的销售量逐步下降，销售额下滑到只占1%的份额。

最要命的是，大宝的价格不到国际品牌平均价格的20%，利润率仅维持在2%~3%的水平。外资化妆品的利润率有多少？都在10%以上，有的甚至达到20%~30%。

大宝最终扛不住了，在2007年以23亿元人民币的价格卖给美国强生。很多人扼腕叹息，又一个民族品牌消失了。
