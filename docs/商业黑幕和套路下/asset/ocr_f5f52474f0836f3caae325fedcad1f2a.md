# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

州万历(1573-1619)老窖池还要早 108 年。

通过这一事件的传播，五粮液找到了扎根历史的依据，顺势推出了“600 珍品五粮液”，其中的逻辑是：“古老的窖池十五粮液传统的手工技术+陈年老酒(20 年以上)勾兑=600 珍品五粮液”。最早打出历史牌的水井坊不甘心果实被别人瓜分。

水井坊运作的超高端品牌——“公元 13”，悄然在局部市场铺货，五粮液也当然不甘示弱，新的广告语是：“五粮春，三千年”！高手过招，出手就是不一样啊！

一诺老师认为，故事就是要让人愿意听、愿意传，就得具体一点、细致一点，还得弄出点证据。水井坊、国窖 1573、600 珍品五粮液，这三种千年老酒，都是拿出了科学检验报告的。特别是国窖 1573，广告做得非常用心，把时间的价值充分挖掘出来了，仿佛人们喝的不是酒，而是几百年的历史。
