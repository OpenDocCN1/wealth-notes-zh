# 第98课·触发消费者心理的套路

# 如何投其所好,利用人性的弱点

一诺老师提醒各位，千万别相信消费者已经变精明、理智了之类的鬼话！消费者是人是人就会感情用事，是人就有心理的弱点，这些缺点不是一点点而是一大堆，比如贪婪、虚荣、爱占便宜、懒惰、健忘……

![](bbox=[0.13, 0.42, 0.88, 0.55])

第1个特点: 产品同质化程度愈高,消费者在选择品牌时,就会愈少运用理性思考。

第2个特点：有品牌的啤酒似乎味道更好，有品牌的汽车开起来更平稳，有品牌的银行排队也会短一点儿等等，都是因为品牌的缘故。

第3个特点：奢侈品就是为了看与被看。消费者购买可以被别人看见的高档商品，远远多于购买不能被别人看见的高档
