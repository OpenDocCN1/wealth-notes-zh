# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

1990年我们就已经申请了“来福”这个商标，但一直没有重点使用。后来我们考虑山西醋企业这么多，每个企业都有不同的文化，那么来福公司最大的财富是什么？

就是醋圣王来福。所以一诺老师就把王来福塑像搬了出来把企业文化重点放在了对王来福的宣传上。

王来福是明末清初人，山西介休人氏，从小以赶车为生。有一次从介休到太原，路过清徐，在我们荣家住，后来和荣家的姑娘相爱，最终结为连理。这就是王来福进入醋行业的一个故事，当时他的醋坊叫“来福醋坊”，后来改名叫“美和居”。当时还有个说法，美满和睦的家庭离不开醋，所以叫“美和居”。

受这个故事启发，一诺老师给醋做了一个定位。醋是什么？醋是爱神的天使，是爱的使者，因为没有爱就不会产生醋意，所以爱是建立在醋的基础上的……
