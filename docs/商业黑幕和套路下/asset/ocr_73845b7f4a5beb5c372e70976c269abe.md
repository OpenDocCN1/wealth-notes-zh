# 所有的看似偶然都是精心设计的必然

一诺老师认为，有了时间，有了地点，有了人物，最后还得干点什么事。有了事件，故事才生动，才能传得远。

茅台酒在中国有“国酒”之称，这个至尊地位是怎么来的？

来源于两则流传很广的故事。第一则故事大意是这样的：

1915 年，巴拿马万国博览会在旧金山开幕。中国北洋政府派团参展，其中贵州省以“茅台造酒公司”的名义，推荐了茅台镇两家作坊的样酒。茅台酒放在农业馆里，与棉、麻、食油等农产品杂陈在一起，加上是用土陶罐盛装，很不显眼。

眼看这届博览会就要结束，茅台酒却无人问津，参展的工作人员很着急，于是急中生智，拿起一坛酒朝地上 obchod 一摔，顿时酒香四溢，引来了很多观众，众人交口称赞。
