# 限量套路四：为每一个货品单独编号

奢侈品厂家大多会对每一件产品打上编号，相当于专门的“出身证明”。雅典奥运会之前，三星手机推出了两个系列的奥运黄金纪念版，全球只有 1000 部，每部都有标号。

这样不仅能让顾客相信确实是限产的，而且每一件商品都独一无二。
