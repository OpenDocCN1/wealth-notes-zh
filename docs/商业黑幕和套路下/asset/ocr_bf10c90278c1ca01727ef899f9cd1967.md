# 案例：名酒的“历史”内幕

一诺老师记得，当全兴酒厂的水井坊刚刚面世的时候，面对600元/瓶的超高零售价，很多经销商不约而同地问起同一个问题：“你们又不是茅台，不是五粮液，凭啥卖这么贵？

对此，水井坊打出的是“历史牌”——虽然茅台更有名气，但是我们更有悠久的历史！

水井坊的工作人员告诉经销商：“如果告诉我们的顾客，你享用的是中国最古老的酒坊酿出的美酒，里面有最独特的古菌群，客人会不会对这一答案感兴趣，几乎百分之百的经销商都充满了兴趣。
