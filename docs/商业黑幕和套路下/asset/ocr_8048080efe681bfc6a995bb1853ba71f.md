# 第80课·产品“畅销”的四个套路

# 做生意,就得这么虚虚实实,真真假假

+   1、排队抢购——最生动的人肉广告，最“可靠”的导购指南。
2、隐身长龙——消费者成千上万，都在身后隐藏。
3、媒体造势——销量进三强，订单过百万。
4、制造堆头——货架陈列越多，产品销量越好。

这两年电子商务兴起，消费者不用到销售场所购物，也就
不可能出现现场排队的景象，但是，电子商务中的从众与跟风
现象比实体商店更加明显。
