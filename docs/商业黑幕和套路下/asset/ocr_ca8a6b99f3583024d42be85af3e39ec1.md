# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

重点菜肴的做法与来历：这个鸭子是安徽某个村喂养的，全是放养的河鸭，全聚德也从那里进货；这道汤的食材是从云南来的，经过了七八道工序，厨师是从锦江大酒店挖来的大厨……有些特色餐厅则会告诉你，这道菜是宫廷里流传出来的，慈禧老佛爷最爱吃；这张桌子哪个明星曾经坐过，他后来把谁谁谁也带来了……听到这样的故事，你的食欲是不是大增，吃起来是不是觉得更有滋有味。

不仅如此，在与亲朋好友聚会时，你还会向他们隆重推荐这个餐厅。怎么推荐？

当然是复述一遍你所听到的这些动听的故事。有了好的故事，你才有介绍的理由与交流的谈资。
