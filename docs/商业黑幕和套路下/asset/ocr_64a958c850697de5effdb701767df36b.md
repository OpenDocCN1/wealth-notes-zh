# 鱼鳖丸的内幕

儿子上大学回家，买了一盒鱼鳖丸送给父亲。

父亲很不高兴地训斥他乱花钱。但晚上躺在床上时，却又禁不住想：“这儿子还真想着我。”

广告语：“当我还是小孩子的时候，每天都好像过生日一样。天底下所有的父亲都记得儿子的生日。但又有多少儿子记得父亲的生日呢？鱼鳖丸，帮助你表达对父亲的爱。
