# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

一诺老师曾经在弟子密训中讲到《傍老外》，特别强调了专业技术人员的工资都比较高，如果付不起，请几个外国人来打打杂也行；再退一步，临时租用一下也行。给他们挂个董事、投资人或者专家顾问的头衔，让他们在新闻发布会、产品展示会或者销售现场露露脸，国际化的形象就有了。

在北京的外籍社区的白人老外，经常会收到出席类似活动的邀请。2010 年，太原星河湾公寓举行 “全球开售盛典”，特地从北京请了几位外国人以投资者身份到场。

这些人的任务包括：在第一排的贵宾席上就座、参与剪彩、上台接受礼物、接受采访(问的问题仅仅是 “对山西印象如何”“山西有什么投资价值”)。
