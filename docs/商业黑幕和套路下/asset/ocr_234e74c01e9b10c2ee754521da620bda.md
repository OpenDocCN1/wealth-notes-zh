# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

比如现场的面积不能太大，服务窗口不能太多，确保能形成热闹的排队抢购场面。

有人不解，现在超市里都要尽量多开结账通道，减少服务窗口不是与潮流背道而驰吗？

一诺老师认为，这两者是有区别的：顾客在超市里排队，是拿了东西等着付款，当然是越快越好，否则有的人可能把推车里的东西又拿出来；我们这里说的排队，是诱导顾客排队买东西，欲速则不达，急不得。

看到有很多人在排队，一般人是舍不得走的；一旦排上了队，付出了成本，购买的可能性就更大了。

那么，应该让消费者排多长的队、等候多久呢？等到地老天荒、海枯石烂吗？这要看你产品与服务的魅力有多大。
