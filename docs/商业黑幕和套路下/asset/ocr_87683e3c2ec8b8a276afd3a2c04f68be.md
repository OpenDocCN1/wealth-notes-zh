# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

是又怎样呢？这样做不违法，更不违规，是企业家与购房者斗智斗勇的表现。

如果哪一位购房者事后后悔了，只能怪自己不理性、不成熟，脑子里净想着自己买后房价能涨多少。

一诺老师估计，开发商是很享受这些购房者在现场慌乱的表现的，没有他们之间的你争我抢、相互影响，房价能涨得起来吗？说起来，他们自己也是有过错的。俗话说得好，人多是个宝。买你的产品的人越多，消费者就会认为你的产品越好。

一诺老师研究发现，如果这些消费者是分散的，对其他人的激励作用就不明显——他可能要再考虑考虑、比较比较，这一考虑一比较，就不知是猴年马月的事情了。

一诺老师认为，只有把这些人聚集在一起，形成热烈的抢购气氛，让他们既相互激励又相互竞争，每个人都感到自己随时可能买不到，才能促成消费者的激情消费、即时成交。
