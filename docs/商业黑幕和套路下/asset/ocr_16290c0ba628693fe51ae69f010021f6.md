# 第120课·故事套路2：生产与销售地点

# 消费者认为哪里正宗,就把公司开到哪里

一件产品如果是在“原产地”出产的，那就说明它根红苗正，可以拿出来给消费者讲故事，这个道理我们专门讲过。

一诺老师发现，除了生产地点之外，产品的销售地点、使用地点、展示地点，都是故事的重要内容。

![](bbox=[0.13, 0.412, 0.88, 0.552])

什么种出什么苗，什么地方卖什么货，一诺老师认为，同样的 一件衣服，放在百货商场、专卖店里卖，与放在个体小店卖，给人的感觉完全两样。

法国产的 Kookai 女装，在巴黎街头小店里卖，只能卖到 25 欧元~30 欧元，相当于人民币二三百元；而在广州最昂贵的百货商场里，一条普通的裙子也能卖到上千元。销售环境高档、雅致，消费者就会觉得产品同样高档、雅致，向朋友介绍时脸
