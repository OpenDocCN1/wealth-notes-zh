# SK-II “神仙水” 传奇背后的内幕

在官方网站上，它被称为 “神仙水”。

是 SK-II。1975 年，一个日本僧人在北海道的酿酒厂遭遇奇迹：年迈的酿酒婆婆拥有一双少女般细嫩的手。实现奇迹的秘密，被 SK-II 公司称为 Pitera 来自上天慷慨而戏剧性的赐予。
