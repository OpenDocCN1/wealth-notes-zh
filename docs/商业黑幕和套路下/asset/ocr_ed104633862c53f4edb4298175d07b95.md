# 第83课·饥饿营销套路2：控制销售

# 销售的最高境界就是不卖

一诺老师前面讲的限量供应，主要是限制生产；而控制销售，主要是限制销量。东西生产出来了，有意压着不卖，跟消费者玩一回捉迷藏、躲猫猫。

且凡搞销售，只有手里有货，哪敢说不卖？

即使消费者提出什么苛刻的要求，都要赶紧答应，打折优惠可以，送货上门可以，买一赠一可以，为消费者揽背揉肩也可以，就是不能说一个“不”字。

这样做，企业家还能指望有什么地位？

只有当你敢于说“不”，让消费者、经销商都求着你了，企业家才有出头之日。
