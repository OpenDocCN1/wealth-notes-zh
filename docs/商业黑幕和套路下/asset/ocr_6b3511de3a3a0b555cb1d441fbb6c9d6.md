# 第93讲·广告套路3：消费者口碑

# 消费者最相信的,还是自己同类人说的话

一诺老师认为，金杯银杯，不如消费者的口碑！消费者最相信的，还是自己同类人说的话。但是，要等到消费者的口碑自然形成，时间太长，效果也不好把控。企业主动地制造话题，并通过特定人群有意识地进行引导，也能很快地形成口碑。

![](bbox=[0.135, 0.413, 0.884, 0.553])

一诺老师认为，最直接的方式是，请一些所谓的“内行人”“时尚领军人物”扮成消费者，为其他人进行口头宣传和示范，一传十十传百，最终产生有利于企业的口碑效应。

西方的快消品公司在这方面走在我们的前面。

一诺老师看过一个报道，宝洁公司为了宣传一个新品牌的清洁剂，聘请了一批临时演员，打扮成衣着很整洁的家庭主妇，在各大超市议论这款清洁剂如何好用，最后还在超市的过道里
