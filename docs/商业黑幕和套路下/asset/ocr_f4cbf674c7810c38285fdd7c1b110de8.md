# 第92课·广告套路2：科普体验

# 抢占科技制高点,教育并抢占客户心智

一诺老师认为，为了让消费者心甘情愿地接受自己的产品与服务，很多企业非常乐意以科普的方式进行推广，一方面淡化商业味道，一方面显示了自己的社会价值，给外界造成一种热心公益事业的印象。

![](bbox=[0.13, 0.41, 0.88, 0.55])

很多人问我说：请问一诺老师，科普推广怎么做呢？

一种方式是在媒体上刊发科普文章，一诺老师在前面已经讲另一种方式，是在现场进行“科普体验”，或者举办科学讲座，在向消费者传播相关的科学知识的同时，顺带介绍自己产品的特点与优势。
