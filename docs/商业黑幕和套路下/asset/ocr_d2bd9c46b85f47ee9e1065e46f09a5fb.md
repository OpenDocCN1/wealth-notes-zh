# 人们对历史悠久的东西有一种天然的崇拜

一诺老师发现，不论中外，人们对历史悠久的东西都有一种天然的崇拜。企业与产品的历史悠久，证明质量可靠、服务好，不然撑不了这么久；另外，还可以让消费者生正宗、正统、有涵养的感觉。所以，我们到处可以看到“百年老字号”“祖传秘方”“源自1897”“始于康熙五十二年”之类的招牌。
