# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

朦来，这楼书咋会不诱人呢？

针对不同的房子，楼书的文字基本可分为三大派系：

# 贵族派系

代表文字：君临(天下)、典藏(生活)、顶级(配置)、奢华(享受)、尊贵(身份)、绝版(地段)、永恒(品质)……恨不得就是洛可可风格的奢靡，嫁给了古罗马帝国的强盛。

# 中产派系

代表文字：白(领)骨(干)精(英)、CBD(商务区)、(高雅)气质、(悠闲)诗意、(现代)艺术、(异国)风情……其主要方式是楼盘标签化和商业化，再夹杂进三分无须品味就能感到的retention小资情调。
