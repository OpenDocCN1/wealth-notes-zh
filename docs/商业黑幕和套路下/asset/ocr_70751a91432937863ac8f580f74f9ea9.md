# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

来满足。算一算，这是多大的一笔生意！

赵本山曾经说过：“人生在世屈指一算，一共三万六千天，家有房屋千万间，睡觉就需三尺宽……”

意思是，人的实用性需要是有限的，总有满足的时候；而心理需求是无尽的，梦是永远做不完的。

消费者的心理需求怎么满足？产品的精神价值怎么体现出来？一诺老师认为，当然离不开产品本身的特点与实用功能，但主要的，还是靠广告，靠故事，靠包装。这正是我们企业家的强项。只要广告做得好，故事讲得动听，消费者得到了心理满足，心里舒服了，产品就有了附加值，价格就嚓嚓嚓地往上蹿。时间一长，就形成了品牌。

品牌这东西，很多人都没搞清楚，只知道它神奇，但不知道到底是啥玩意。一诺老师仔细研究了一下，研究来研究去，发现里面也有虚实之分。
