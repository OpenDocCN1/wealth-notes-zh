# 第114课·保健品的终极套路

# 情感套路的五大步骤

一诺老师的一位弟子，曾经辅导过保健品行业的顾问天宇老师（全世界最伟大的成交大师），告诉一诺老师，目前在福州市市场上做保健品推销的有 20 多家公司，通常他们所采取的推销方式有 3 种：会议营销、旅游营销和体验营销，但最流行的当属会议营销和体验营销，其推销的对象基本上都是老年人。

![](bbox=[0.13, 0.456, 0.88, 0.598])

天宇老师把推销保健品的过程分为 5 个步骤，这 5 个步骤环环相扣。

# 步骤 1：收集数据。

早期，在福州做保健品推销的商家数量较少，他们进入社区和退休老人比较集中的单位，开展科普宣传和为老人免费体检等活动，收集老人资料。
