# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

一诺老师早先买大宝的润肤露，还有王麻子菜刀、张小泉剪刀什么的，也认品牌，大宝、王麻子、张小泉都是品牌。

那个品牌，意味着质量的保证、售后服务、厂家的信誉。

但这种品牌太实在 了，质量、服务、信誉，都是要花银子一五一十做出来的，最后也产生不了多少附加值，别人的 一把刀卖两元，你的卖两元五角就到头了。

现在的企业做品牌，手段就大不一样了，讲的内容也换成了什么象征啊情感啊、信心啊、体验啊，不能吃不能用，但消费者开心，价格和利润都比前者高。

有的人说，一诺老师啊，这些东西是虚荣，是穷讲究！

一诺老师认为，但凡做企业的，不能管这些，只能顺着大多数消费者的心思来，如果像大宝那样，再吹喝什么“量足，价格又便宜”，就只有等着被别人收购的份儿。
