# 舍不得孩子套不到狼,舍不得老婆抓不到流氓

一诺老师在超市购物的时候，经常遇到这样的人：围着货架转过来转过去，手里拿着几件同类商品反复对比，又把营业员叫来问东问西。

按理说，他对这种商品已经非常了解了，自己也有这个需要，但走过来走过去，就是不买。

他的面色如此凝重，是在考虑“生存还是死亡”这样的哲学问题吗？肯定不是。那他在想什么呢？一诺老师推测，他一定是在琢磨：买，还是不买？买了，钱就不是自己的了；不买，钱还在自己口袋里，今后随时可以买。结果呢，很多顾客决定等一等、看一看再说。
