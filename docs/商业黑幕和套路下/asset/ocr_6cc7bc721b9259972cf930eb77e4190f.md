# 什么叫“解决”？

就是把复杂的问题简单化，让消费者一看就明白，一听就觉得有道理。

为什么要买这个洗发水？因为能保湿！为什么能保湿？因为里面含有保湿因子！是不是很简单？短短几个字，就把产品的好处和证据都搞定了！

顾客最喜欢这样的产品，所以它们卖得都特别好。

![](bbox=[0.13, 0.435, 0.88, 0.575])

最近，光明乳业开发了一款据称能够帮助睡眠的高档牛奶，名字叫“舒睡奶”。

凭什么说它比普通的牛奶更能改善睡眠？

舒睡奶的产品说明中说，这款产品含有独特的“舒睡因子”a-乳白蛋白，含量比普通牛奶高出 25%。

有了这个解释，消费者一下子就明白了。

因为舒睡因子含量高，所以它肯定能帮助人舒睡啦！
