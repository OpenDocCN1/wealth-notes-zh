# 全球最黑的《商业黑幕和套路 2》容易走火入隐！未满 18 禁读此书！

一诺老师认为，要造成排队抢购的效果，最重要的工作就是积蓄客源，好比一座水力发电站，要先蓄满水，再定时开闸，冲击力才足够大。

经过这样一番运作，老百姓就会在当晚的电视或者第二天的报纸上看到这样的新闻：某楼盘售楼处前排的长队，神龙见首不见尾，把临街的道路阻住了；交通瘫痪了 3 个小时，300 名警力维持秩序；售楼处的大玻璃门给挤破了；财务人员数钱数肿了手指，银行运钞车门前待命之类……

一个“热销”的楼盘就这样“炼”出来了。

![](bbox=[0.13, 0.52, 0.88, 0.66])

有的楼盘本身的吸引力不大，或是当时的行情不好，购房者持币观望，怎么办？也不能坐在售楼处等，场面冷清是销售的大忌，这时就需要拉人来捧场了。

一诺老师记得在早几年，有的开发商动辄请几十个建筑工人来排队，穿上体面的衣服一天 50 块钱，还管饭管烟。
