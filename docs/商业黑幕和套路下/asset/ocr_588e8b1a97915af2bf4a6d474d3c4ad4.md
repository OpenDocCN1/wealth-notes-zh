# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

水井坊的崛起，让同处四川的泸州老窖看在眼里，急在心里。2004 年，“国窖 1573”应势而出，而且打出的时间更具体、更明确:1573 年！

国窖 1573 的广告词是这样的：“1876 年留声机发明，你能听到的历史 124 年；1831 年照相术产生，你能看到的历史 170 年；1573 年泸州老窖国宝窖池开始兴建，你能品味的历史:431 年——国窖 1573。” 到了 2005 年，“你能品味的历史”改成了 432 年；2006 年，名正言顺地成了 433 年……
