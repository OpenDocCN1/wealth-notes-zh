# 霸王中药世家的内幕

顺治年间内大臣鄂硕之女———董鄂，幼时容貌出众，可惜肤色晦暗、头发稀疏且黄白相间，所见之人无不扼腕叹息。

所幸在董鄂 13 岁时，因机缘而巧遇粤西“悬壶药馆”掌门陈姓医道，该医道凭其对各类中草药药性的熟谙，运用中药祖方首乌、皂角、当归、人参等为其调养容颜、秀发。

两年后，在宫廷选秀女之时，因其“香姿、乌发、玉色，神韵天然”而被顺治皇帝惊为天人，极得顺治皇帝宠爱，并成为一段旷古佳话。(一诺老师差点都信了)
