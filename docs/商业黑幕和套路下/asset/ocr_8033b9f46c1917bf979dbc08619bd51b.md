# 全球最黑的《商业黑幕和套路 2》容易走火入魔！未满 18 禁读此书！

通过“酒香为媒”的蛊动效应，茅台酒成为博览会上的明星，被评委会直接授予荣誉勋章金奖。

在国运不济、饱受欺凌的旧中国，茅台酒的获奖大长了中国人的志气。

这个“怒掸酒坛振国威”、一掷成名的故事，据说有演绎的成分。有专家考证，当时的工作人员为了引起观众和评委的注意，准备将茅台酒移到人气比较旺的食品加工展示馆，在移动过程中，无意把一坛酒摔落，引起了众人的围参展人员趁机把酒倒出让人们品尝。

故事的原貌已难以完全还原。有意思的是，据史料记载，在那一届博览会上，中国参展的产品有上万件，共获得 1000 多个奖项，其中白酒、果酒获奖的就有几十种，而且奖项排在茅台之前，茅台的所谓勋章金奖，至多算得上二等奖或三等奖。
