# 要针对消费者心里制定营销方案

一诺老师从小就学过一句口号：“知识就是力量！” 一诺老师认为，这句口号的影响非常大，现在很多学校的作文竞赛、演讲比赛仍然以此为题目。现在一诺老师要给我们企业家出一道题：“如果消费者有了知识，后果将会怎样？”

很多人说，消费者肯定更有力量了；还有的人说，企业家将面临灾难。错！大错特错！正确答案是：“企业家更有力量！”
