# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

上就说“巨人联手打造 XX 航母”；竞争对手有大的行动，就向媒体发布“严正声明”；实在没有什么事，就“低调做事，苦练内功”……总之，要整出点事儿来，闹出点声响。

万一想不出什么新点子了，就让人找一些反面材料来攻击自己，再从正面进行反驳，也能吸引眼球。

很多大公司内部都有一个独特的新策划部，就是专门策划新闻事件、在媒体上发文章的。海尔的新闻部，每年发送给媒体的新闻稿有上千篇，只是能发出来的没有这么多。

![](bbox=[0.136, 0.478, 0.882, 0.618])

除了文章的内容，采取什么形式刊登也很重要。

有的房地产老板很强势，广告和软文都舍不得丢，还提出了所谓“软硬结合”“上软下硬”的理论：版面的上半部刊登软文，下半部刊登形象广告，还形象地称之为“一半是海水，一半是火焰”，一诺老师把这叫“新闻 1+1”营销。
