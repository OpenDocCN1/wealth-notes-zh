# 第99课·营销大师真正卖什么

# 把产品的实用功能和梦想.欲望搭在一起卖

近几年，特仑苏的宣传方式更加高端，把自己和高雅艺术捆绑在一起，轮流在全国 20 多个城市举办高雅音乐会。2012 年的主题是，“与郎朗同台，享受专属的拥有”。

这些活动的目标只有一个，告诉消费者：“拥有了特仑苏，人生所以不同。”从功能价值转到精神价值，让特仑苏从以前的 OMP 争议中解脱出来。

一诺老师认为，任何品的功能价值都是有限的，还可能被人抓住把柄、吹毛求疵；精神价值则是无限的，可以任由发挥，像特仑苏标榜自己是“高贵”的、“与众不同”的谁又能说一个不字？
