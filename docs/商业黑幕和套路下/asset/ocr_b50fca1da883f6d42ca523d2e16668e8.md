# 第 104 课 · 国际化套路 3：自创洋品牌

# 我是一切的根源,一切都是自己创造出来的

一诺老师上面的两种方法毕竟比较简单，只能应付一时一事，要一揽子地解决问题，实现企业的长远发展，还得创立品牌——国际化的品牌。

20 多年前，中国人就已经开始探索品牌的国际化之路了。做得最早、最成功的，当属丝宝集团。1989 年，港商梁胜亮在武汉街头做了个调查，发现大多数人都认为日本的护肤品最好。

![](bbox=[0.13, 0.499, 0.878, 0.639])

于是他给自己的产品取了个日本味道浓厚的名字——丽花丝宝，技术、配方、原料都从日本引进，连商品的条形码刚开始也是日本的；出现在电视上的广告形象，也是一位身穿和服的日本女子，讲一口流利的日语。
