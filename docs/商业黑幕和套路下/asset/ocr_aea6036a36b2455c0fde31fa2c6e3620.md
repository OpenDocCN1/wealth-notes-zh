# 瞬间拉升产品逼格的万能钥匙

当你在喝可口可乐的时候，并不只是单纯地去喝一种深色液体的碳酸饮料，那样的话喝什么饮料不是喝呢！

而只有可口可乐最能代表美国。

所以，一诺老师经常在课程中说：谁率先占据消费者心智，顺应“崇洋尚外”心理，谁就能受到高档卖场青睐，实现产品溢价。
