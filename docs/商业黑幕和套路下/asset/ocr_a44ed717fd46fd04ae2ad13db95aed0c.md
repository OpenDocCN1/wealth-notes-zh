# 第73课：产品细分的套路

# 市场是企业家一刀一刀的切出来的

+   1、分工越细，说明效果越好。
2、品种多少，说明实力大小。

一诺老师认为，你的产品分得越细，等于你的企业实力越强，产品的功能越好。在这方面，企业有很多的文章可做。

一种产品，针对不同性别的、针对不同年龄的针对不同体质的、针对不同症状的……

一路细分下去，好几十种货品就有了，摆放在货架上，琳琅满目，既抓住了消费者的视线，又让消费者感觉企业有实力、产品功能好，益处多多。
