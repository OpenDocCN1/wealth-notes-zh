# 全球最黑的《商业黑幕和套路2》容易走火入魔！未满18禁读此书！

召集老人开会的场所一般安排在酒楼，老人除了在酒楼里听讲座外，中午还有一顿免费的午餐，一次抽奖机会。

会场内老人座位的安排是十分讲究的，一誩是10个人坐一桌。每桌的新老顾客都有一定比例，一般是10个老人中，老顾客占3~4个。

这样安排的目的是通过老顾客来介绍产品的功效，增加产品的可信度，专员在关键时刻上前向新顾客推销产品，并不停地向老人暗示：既然已经来到现场，就不要空手而归，一定要有所收获；家中的老伴正等他(她)带着“健康”回家，如果空手而归，会让老伴失望。

俗话说，吃人的嘴软，加上专员一直劝说，老人会觉得不好意思，便会预订下产品，让专员送货上门，有的老人还会直接掏钱购买。
