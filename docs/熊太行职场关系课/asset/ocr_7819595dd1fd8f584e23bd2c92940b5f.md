# 第四，减员要润物无声

有句老话叫“新官上任三把火”，你可以裁员，但团队刚刚组建，人心最不齐，不要上来就大砍大杀。斩敌才能立威，不要斩自己人立威，斩自己人只能有一个理由，这人不再忠诚。

有的情况下，你有换掉大部分人的权力。不过在大多数公司，管理层也不会愿意你一上来就更换 1/5 以上的人手，公司也会面临补偿金压力。正确的做法是，在平时定期盘点一下部门有没有冗员。清理不合适的下属这件事，每个月都可以做。

# 本讲小结

总结一下，四类下属的分类法很有用，你可以用来分析自己的团队，也可以用来分析别人的团队，你会看得更明白。最后我要提醒你，配置团队不应该大刀阔斧，应该润物无声，一点点慢慢来。

# 思考题

作为领导，这四类角色中，哪些角色的任务是你可以兼任的，哪些角色是你不能做的呢？

# 参考答案

领导不可能兼任耳目喉舌，但是可以承担业务骨干和稳压剂的作用。

在规模极小，或者非常困难的时候，领导甚至也会扮演润滑剂的角色。

所以，如果你的领导平时不苟言笑，突然开始主动说笑话，逗大家开心，他十之八九是遇到了真正的困难。

因为领导自己不能兼任耳目喉舌，所以他的眼睛和耳朵都是不可缺少的。
