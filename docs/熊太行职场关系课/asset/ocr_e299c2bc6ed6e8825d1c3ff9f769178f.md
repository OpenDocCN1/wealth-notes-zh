# ## 思考题

如果曾经的领导在职场上吃了亏，成了你的平级同事，你会跟他称兄道弟、和他结盟吗？

# 参考答案

不要，应该尽可能让他像前辈和老师，避免太过亲近的自来熟。

尤其是领导如果刚刚经历了挫败，遇到一个自来熟的你，可能把一切负面情绪都放在你头上。

至于结盟，可以考虑，要盘点一下你们有没有共同目标、共同的对手。
