# 思考题

如果你是领导，需要从两个手下当中选择一个担任副职，你希望他们用什么样的风格和方式展开竞争呢？

# 参考答案

这是一道观察偏好的题目，没有标准答案。

有的领导希望两个人展示自己的实力，也希望两个人展示自己在部门中的人际关系。

还有一些领导希望手下提及自己拥有的上层关系。

无论如何，都不希望两个手下刺刀见红。
