# 思考题

给你留一道思考题，你盟友提醒妳，一位下属在背后对你评价刻薄，这个时候妳的做法是：

+   A. 盟友比下属重要，当时就去找下属对质。

B. 盟友可能是要离开我和下属，暂时不理他。

C. 向盟友背书，下属不会做这样的事。

D. 告诉盟友妳知道了，然后暗暗去调查和了解这件事是否存在。

欢迎在留言区写下妳的回答跟我交流。

# 参考答案

> D. 一件事要先弄清楚，确认了是不是误会，再作反应。不要冲动，也不要让冲突变得暴力起来。
