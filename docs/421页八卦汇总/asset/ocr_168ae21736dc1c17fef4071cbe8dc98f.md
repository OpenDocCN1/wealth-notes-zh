# 24、徐若瑄

许久未见的徐若瑄，最近在北京出席了“中国演出行业协会30周年庆典暨中国演艺品牌评选颁奖典礼”。活动间隙中，她接受了香港中评社的专访，在采访中，她大谈两岸演艺合作交流，并称“我是台湾土生土长，我是台湾人，我当然也是中国人。”

emmmmm， 这段报道出来后真是一石激起千层浪啊！抓屡不看都知道，大家又把之前徐若瑄说的那段“亲日”(待会说)言论拖了出来…..

估计很多年轻的小姨贝们还不知道徐若瑄这个人，来来来，又到抓屡的科普日了！

徐若瑄，原名徐淑娟，1975年出生于中国台湾省台中市，中国台湾女歌手、演员。徐若瑄儿时一直住在出租屋内，因为家里穷，父母不断更换职业，面店、洗车店、服装店都开过，但都屡开屡倒，为此他们前后搬过三十多次家。

抓屡从这件事看出一个真理，不是做生意的料还不如老老实实当个上班族。

徐若瑄五岁时父母便离婚了，五岁之前徐若瑄一直跟着父亲生活，母亲那段时间离开台湾出走日本生活。早年间徐若瑄接受采访时曾说过：“爸妈离婚的时候，我跟弟弟是分给爸爸，男人不会照顾小孩，原本只是接我们到台北聚聚的妈妈，发现我们有状况了，就坚持由她来照顾我们……”
