# 一入灵剑深似海，从此被窝是路人。

# 长安夜凉出工晚，大宋稳定第一坑。

这里面的“灵剑”、“长安”、“大宋”，都分别代表了一个剧组（大家可以猜猜看哦）。
而其中的“大宋”，讲的就是刘涛的那部剧了。为什么会叫“第一坑”呢？原来啊，别看刘涛在镜头前、节目上跟那些圈内的明星好友，那么的大方得体善解人意。在影视基地这边的口碑却是极差的，不仅相当的苛刻，还有着跟自己身价不匹配的吝啬。
前几天有场戏在开拍，当天的天气并不好，不仅下着连绵的小雨，气温更是降到5、6度。其他剧组都是早早就算收工了，可只有刘涛那一组，居然还有一大帮人在片场。过去一打听才知道，原来这些等在片场的群演的戏份其实早就拍完了，但等到喊收工的时候，助理发现比预定时间超出了十几分钟。
要知道，在影视基地这边，群演的酬劳是按小时支付的；超过一小时即使不满一小时，也是按照一小时给钱的。结果当天那个剧组的戏拍完后，原本工作人员喊了收工准备撤装备时，对讲机里却突然传来了刘涛的声音：“群演的时间超过十分钟的怎么算？”在得到了按照一小时计算后，刘涛直接来了一句：“哦，那就让他们在那等够一小时再收吧！”
“再收吧！！”
“收吧！！！”
……
要知道，虽然确实有一些剧组锱铢必较地为了那几十元每人的钱会争分夺秒；可面对着那种阴雨天，大多剧组都会很人性的体谅工作人员和群演的。结果那天，在所有剧组（包括刘涛那个组）的工作人员和群演都回去休息后，只有那组的几百个群演鸵在户外的基地里，一直干等了半个小时才回去，直接导致第二天很多人感冒了。
从此，“第一坑”的称号便在影视基地流传开来了。
对待不相识的群演如此，对待身边的的工作人员，刘涛也没有像镜头前那样温柔到哪里去。比如大家都知道，演员在拍戏时是要配备助理的。即使这个助理比不上自己平时工作时的助理和经纪人亲近，但由于负责的都是在剧组的日常，所以一般明星都会比较尊重、照顾。

结果，有一天当X老师录过刘涛的剧组，亲眼目睹了刘涛像训练孙子一样的斥责她的那位可怜的女助理。平时的训斥也就罢了，据说刘涛每天起床、吃饭后的“漱口水”，都是要吐在助理手心里的！
当然，如果说这些人品上的小问题，还不至于让X老师从前喜欢刘涛的心思“破灭”的话，（毕竟很多明星私下都是这样，X老师也算是见怪不怪了）那么真正让X老师对坊间那些“绯闻”深信不疑的，就属最近发生的那件事了：
刘涛这部剧的男主，是某个湾湾的花美男演员“累啊累”。本来所有人 suffered，以为，按照刘涛如今“每拍一部剧，就要换个剧组男友”的情况，累啊累这次肯定是跑不掉了。可谁承想，刘涛也是有“操守”的！
累啊累想当年虽然是名副其实的“全亚洲追捧”的花美男，但如今毕竟过气变成老腊肉了。前面X老师就说了，如今的刘涛身边，是根本不属于有超过30岁的“老”男人的！果然，累啊累根本就没被刘涛瞧上，倒是另外那位同样做累啊累的“文蔻替身”的特约演员，竟然入了刘涛的法眼！
大家也知道，“文替”一般就是露个背影、站位打光、帮演员搭戏用的，根本就上不了大台面。结果，自从刘涛跟这位文替看对眼了之后，不仅在片场就经常弃累啊累于不顾，跑去跟这位替身演员对词、打情骂俏；更是仰仗着自己的投资人身份（现在资料上没写，可不代表不是哟），好不避讳外人的眼光，经常将这位文替叫到自己的房车上“对戏”！还一“对”就是几个小时，而且还要把自己的工作人员和司机都赶下车…
