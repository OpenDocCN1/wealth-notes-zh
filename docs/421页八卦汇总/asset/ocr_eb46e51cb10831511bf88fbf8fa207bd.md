# 2、葛优

说到“老戏骨”三个字，估计有很多童鞋的第一反应都会认为那得是“德艺双馨”~毕竟能够在早年的圈子里凭真本事出道的那些演员或歌手，必然得是有真本事的。然鹅，相信这一“固有印象”，在宝贝们关注扒爷过后，应该都已经“破灭”了吧。毕竟，扒爷现在简直就是大家追星路上的“拔草小能手”呢~

虽说老戏骨中确实有不少人是凭真材实料上位的，但如前段时间爆出来的那种“长年包情妇”的渣男也确实是不少。而且，由于老戏骨经历过“大风大浪”、“起起伏伏”，所以他们可比那些战战兢兢的新人会“玩”、而且“玩”的更疯呢！比如，扒爷之前曾经提起过的某个性别男、爱好男的老艺术家六小龄童，在镜头前满口仁义道德，但私底下却“就喜欢玩刺激的”。

如今国内一线的某个男演员陆毅，在出道前就“被包养”过。要注意，这里说的包养可不是传统意义上的“拿钱办事”，而是“劳资出钱，那就想怎么玩就怎么玩”。据说该一线男演员到现在还“忧郁”，就是因为早年在“老艺术家”手下留下的阴影呢~

又比如，扒爷在“四旦双冰”系列里曾经提过的表面没有信仰、经常宣扬自己的“无神论者”的“直男老艺术家”陈建斌，其实私底下比谁都迷信！不仅每年都要带着自己的那位长得非常漂亮的女演员老婆蒋勤勤，一起去云南找某个隐士高僧为两人加持好运；还砸重金跟高僧合作成了“VIP客户”，即这位高僧只可以给这两⼈加持好运，不可以在接其他明星的活儿了。但不知道是高僧的法力太普通，还是这两位命中注定没有“大红大紫”的命，貌似这两 年也没见有什么起色；倒是今年他们夫妻二人参加了某部综艺有了点热度，可资源方面却仍然没见好转~

所以说啊，看过上面这些“老戏骨”大家就知道，“老戏骨”的行品跟“老”这个字可没多大关系。有的人或许能够藏得了一时，但藏得了一世就很难啦~就像接下来扒爷要说的这位老戏骨——冬叔“葛优，就是一位表里不一的典范呢~

葛优的演艺之路，代表了圈子里的另一个捷径——并不是长得漂亮帅气才能当演员！可别看葛优长得不怎么 样，名气那可绝对是家喻户晓，哪怕是宝贝们的父母都一定知道他的名字。葛优平时的为人倒也低调，由于不作妖、不炒作，所以很多人对他都是很敬重的。

但葛优表面上外露给大家的印象虽然是正人君子，可他在跟那些圈子里的兄弟朋友在一起时，那就原形毕露了。要知道，葛优在圈子里有个不少人都知道的癖好：口huo好不如手huo好！（没错，就是你们想的那个huo字）

都 知道葛优是有老婆的，早年还少靠着发自己跟老婆“恩爱多年，腕儿再大也不嫌弃糟糠之妻”的通稿，来给自己那些花边丑闻当烟雾弹。而且葛优对外一直有个标签，是“妻管严”，即老婆不准他拍吻戏，那他绝对不拍！看到这里，估计很多人都被迷惑以为葛优是真的很爱老婆吧？

可这世上哪有无缘无故的爱和恨啊？只要想一想就知道：他老婆一个家庭主妇，凭什么葛优要这么“怕”她呢？答案是老婆手里有他的把柄啊！

原来，当初葛优跟他老婆结婚后才发现，原来葛优不仅不能传宗接代，更是个“软男”啊！现实夫妻里还有不少因为房事不和谐而离婚的呢，这放在明星身上，对于女人来说，也是个很大的痛处啊。要是“病因”在老婆身上，估计葛优早就离婚了；可原因既然是出在葛优身上，他也只能是哄着老婆别张扬、答应把所有的钱都给老婆、爱她一个咯~
