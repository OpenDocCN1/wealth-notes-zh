# 燕燕的三大罪状之V绯闻不及心机多，爱踩友上位？

别看燕燕被爆出的那些亲密照略显非主流，她这两任男票却不是等闲之辈。这个流传甚广的陈先生，曾经参加过“加油好男儿”；而另一位鼎鼎大名的冯先生冯铭潮，虽然一直是圈子里的十八线不知名小生，可人家不仅是受受儿的富二代，更是娜扎的前任。有意思的是，后来当冯先生跟娜扎的亲密照被曝光时，燕燕还疑似被娜扎的团队拉出来挡枪。

紧接着燕燕步入娱乐圈后，她又在机缘巧合下结识了香港的吴小生吴卓羲。正愁自己没有门路没有人脉的燕燕，总算逮到了吴小生这个绝佳的上位机会。不仅把吴小生套得牢牢的，还总是非常“巧合”地被媒体拍到。而燕燕又非常善用圈子里的套路：坚决不承认恋情。于是，这段昭然天下的绯闻，就这样来来回回、翻来覆去地一会“承认”一会否认地报道。

仅仅靠着这一段恋情，就让燕燕吸足了关注与热度。可即便如此，燕燕却还是不满足。她先是各种宣示主权，暗讽当时跟吴小生传绯闻的徐子珊是“香肠嘴”。吴小生为了维护她，只好出面发言回应。结果粉丝直接从100万，掉到了60万。

这种状况对于刚刚转战内地的吴小生来说，意味着的是什么，估计所有人都能明白。但吴小生做到了这个程度，却仍然满足不了燕燕的野心。前脚吴小生刚跟媒体夸下海口，说自己绝不会重蹈林小生的覆辙（林峰潘霜霜事件）；后脚燕燕就非常“不小心”地发了一张介样的照片。
