# 10、赵丽娟

最近因为于正的新剧热播，使得与剧中女主令妃同样角色但不同年代的女星们都被挖出来对比了起来。从演技到角色人设不同各方面都引发了网友们的热烈讨论，大家对于令妃这一人物在真实历史中上位速度之快，位置之高深感佩服。

包衣 → 贵人 → 令娴
↓
令妃 ← 令贵妃 ← 皇贵妃
↓
令懿皇贵妃 → 孝仪皇后

扒爷也觉得，这种顺利的晋升之路完全是里出现玛丽苏小说里的女主路线！

借着这波热度，芒果台又双叒拿起了当年的镇台之作《还珠格格》开启暑期重播大法……很多网友在这次看过后，都纷纷发现剧中的令妃娘娘的心机之深令人细思极恐！

这次扒爷绝不是被姨太逼着陪着看芒果台重播的《还珠格格》，此事纯属个人行为！

下面扒爷就为小姨太们捋捋，有哪些你们当年错过的细节之处~

+   1、令妃讨好式
在小燕子受伤被抬进宫中时，令妃便一直在皇上面前不断夸赞小燕子的长相像极了乾隆。咱令妃娘娘就是跟别人不一样，其他人一般走指桑骂槐路线，她是指桑骂槐的对着乾隆来了一通花式恭维！
人家净是捡皇上爱听的说，姨太你快学学令妃娘娘！！

+   2、令妃甩锅式
皇后在受伤的小燕子进宫后，收到了1784【尺】底宫女传来的消息，赶去质问令妃听宫里人说这个来路不明的姑娘和皇上一个模子印出来，自己瞧着一点也不像。
然后…然后…令妃开始实力甩锅表示皇上自己说的。
6666当着几亿观众的面否认，扒爷怕是耳朵失聪了~

+   3、令妃反咬一口式
刚在皇后面前推完责任，晚上转头就在皇上面前为告状做推逇工作~然后钩皇上上钩后，装作柔弱反咬一口~ 
扒爷觉得姨太这点千万不要学习令妃啊！咱要告状就正大光明，别搞这些弯弯肠子，扒爷宁愿死的明白...

+   4、令妃安抚式
自己在皇上面前劝说他想开些，就当香妃真的变成蝴蝶了。
年轻的扒爷觉得令妃娘娘无比善良，现在扒爷再接上后面一琢磨……这明显是变着法儿说自己对乾隆才是真爱啊！
