# 1、关之琳

今天扒爷带大家见识一位从出生便拿着一手好牌，却被自己胡乱打废的女士，关之琳。作为香港一代美颜女星，那会儿的她可真是“持靓行凶”的代表性人物啊！怎样“行凶”咱们后面说，先来了解一下关之琳的一手好牌~

她的母亲张冰茜是长城、邵氏电影公司的演员。父亲关山在1958年荣获第11届瑞士洛迦诺国际电影节最佳男主角奖项，成为首位华人国际影帝！从小出生于演艺世家的她，19岁中学毕业后便加入丽的电视成为演员出道。之后，关之琳凭借美貌五年内参演了七十多部影视作品！

扒爷就挑几个当年男生眼中最惊艳的角色，用美图展示给小婊贝们看看~李连杰主演的电影《黄飞鸿》系列中的美艳十三姨、梁朝伟、梅艳芳主演的电影《新仙鹤神针》中蓝小蝶一角、刘德华、舒淇等共同主演的电影《卫斯理之蓝血人》中蓝血人方天涯……

因为关之琳女士主要以演花瓶角色为主，所以就算是合作的都是各个大牌，也没什么其它内容可说的，在演艺圈的她除了混日子就是谈恋爱。对了，关姑娘1994年还出过一次唱片，当时陪她做客节目宣传的有梁家辉、张国荣、成龙、黄霄、刘德华、梅艳芳……

这阵仗基本聚齐了那个年代娱乐圈的半边天啊！在这几位男士中当然免不了有对关之琳明显好感的人物，他就是说出“我犯了全天下男人都会犯的错”的男人，成龙。1985年，关之琳跟成龙合作拍摄电影《龙兄虎弟》，就有新闻爆出关之琳经常在成龙香港浅水湾的房子楼下等他，惹的林凤娇气得半死。龙嫂有没有气得半死扒爷是不知道，不过关于洪金宝因为关之琳跟成龙走得太近而跟成龙闹掰这事小爷倒是有些有所耳闻。

小婊贝可别误会洪金宝跟关之琳的关系，虽然洪金宝這人一身黑料，但在义气方面还是没话说的，他跟关之琳爸爸关山是好友。当初关之琳出演成龙的作品还是洪金宝从中牵线而成的，所以当新闻爆出自己现在的好友和老友的女儿有感倩绯闻时，不生气才有鬼。除了这段跟成龙似乎似无的感情线外，关之琳其他记者史可全是被盖了实锤章的，扒爷来一个跟小婊贝们慢慢说！1980年，18岁的关之琳跟男演员、模特兼皮草商人万彼得拍拖。那个啥不知道是否因为男方没啥名气还是当时网络不发达的原因，网上还木有两人准确的合照。扒爷在这儿就偷懒放个百度百科，小婊贝们抗议的一律驳回~两 人谈了没多久就分手了，因为关小姐一心只想嫁入豪门在恋爱期间就搭上了一位富商。然 后在与富商一起时，又结识了比自己大16岁的纱厂大亨王统元哥哥的婚外子王国雄，两人相恋两个月后就结婚了。对，人家在自己年轻最火的时候因为懒不想拍戏了，所以就决定直接闪婚。关之琳这个决定，把她爸爸关山气的以自杀威胁女儿不准出嫁。结果，关之琳胜出……然后，这两人结婚差不多五个月时男方就被爆出在外花天酒地，没过多久关之琳就闪离了。据说，关之琳在90年的一个访谈节目中曾说过：“我做的一切都是为了钱，包括我的第一段婚姻。”

之后，关之琳就开启了自己前半生的小三模式~第一段小三时光是在关之琳23岁，她搭上了香港60年代五大富豪马锦灿的长子，当年还处于已婚状态的香港地产大亨马清伟……这位先生的太太是香港女演员陈美琪，当年在《新白娘子传奇》中饰演小青一角，对她各位小婊贝应该都有印象吧。当年关之琳不仅插足别人家庭，还作妖骚扰陈美琪和她妈妈。陈美琪在做客节目时曾说过，当年每天家中都会接到辱骂电话，刚怀孕的陈美琪因此动了胎气孩子没保住，最后只好做手术拿掉孩子。
