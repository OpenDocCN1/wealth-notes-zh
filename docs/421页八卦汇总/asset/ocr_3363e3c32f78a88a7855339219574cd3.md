# 14、蔡少芬&张晋

自从蔡少芬跟张晋在一起后，就从以前的“女神”，变成了“狂爱秀恩爱”小女人。这样的做法有人受用，自然也难免会引起反感，认为蔡少芬太过心急带张晋上位了。

其实像蔡少芬跟张晋这样的“女强男弱”的姐弟恋组合，在娱乐圈里确实是有不少。比如之前才被爆出，跟“好姐妹”经纪人搞暧昧的张丹峰，当初就经常被网友跟张晋划进一组。

蔡少芬跟张晋在一起时，对比还属小透明的张晋，蔡少芬早已是红遍港台内地的演员了。但是相对于消息空间封闭的内地，对于香港观众来说，蔡少芬身上其实还有个标签——情妇。

估计有不少童鞋应该到现在都留有疑问，为什么同样是当过刘銮雄的小三、情妇，蔡少芬现在就能被网友接受，甚至心疼她、祝福她和张晋；而像是李嘉欣、关之琳那些同时期的女星，到现在还要挂着“补药莲姑引有妇之夫”的头衔。

其实这也跟蔡少芬的可怜身世有关。蔡少芬从少年时期就开始参加选美，这也是她妈妈的意思，希望女儿凭借自己的出众外貌在演艺圈发展赚钱。17岁那年，蔡少芬拿到了港姐第三。话说，那个时候的女星在没有滤镜、没有PS的镜头前都能没成介样，那真人得美到什么程度啊。就更别说还是这种有点老土的泳衣了，惊为天人啊有木有！

到现在还有不少人质疑蔡少芬那一年的港姐，认为冠军郭蔼明并不漂亮。但要知道，郭蔼明当时拿到冠军，其实是凭借她的知性美和高学历的（而且郭蔼明也算得上是娱乐圈里为数不多的清清白白的女明星之一了）。

拿到季军后，蔡少芬便正式签到了TVB开始演戏了。港真，蔡少芬的脸是真的适合古装啊。静若惊鸿动若游龙，再私心放张美照好了。在现代戏里的蔡少芬，虽然在当时的TVB还算不上大腕，但即使是配角，也能靠着出众的形象自带光环。到了20岁，蔡少芬开始挑大梁出演女主角，也是在此期间，有了那些众所周知的经典形象。比如“牛夫人”；比如“如烟”。

可随着知名度越来越高，戏约越来越多，蔡少芬的积蓄却还是越来越少。这就不得不提到，那个影响了蔡少芬前半生的烂赌鬼的妈了。不仅频繁被媒体拍到，蔡妈妈经常去澳门赌钱，后来还传出蔡妈妈曾经在赌场包下一个房间。这简直就是要住到赌场的节奏了好么？！

摊上这样一位好赌的母亲，蔡少芬在这段时间的经历，估计连电视剧都不敢这么拍。不仅仅赚的钱都要给妈妈拿去填坑还债，甚至还被逼着去拍了S级片：要知道，当时的香港影视圈，是有很多黑色背景的大佬的，一些没有欠债的当红明星都经常被迫拍片，就更不用说蔡蔡这种“有把柄”在别人手上的演员了。

当时蔡妈妈不仅输光了女儿拍戏十年间的所有积蓄，还倒欠了一大笔外债。最后黑道上门要债，蔡少芬就被逼着去拍了那些大尺度的电影。也正是因为这些，所以才有了“蔡少芬配不上张晋”的说法。

不过，凡事都有两面性。

蔡少芬并不是出于本意去拍那些电影，所以扒爷觉得这算不上黑历史，反而是真的很让人心疼（比起“没有好赌的妈”、“没有穷困潦倒”、就只是想赚钱的湾湾某性感大嘴女星舒淇，起码蔡蔡是更值得原谅的）。
