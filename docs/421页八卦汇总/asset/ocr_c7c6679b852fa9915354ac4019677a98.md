# 25、王艳

媳太今天重温了《武林外史》，到现在还是觉得，里面白飞飞超好看，角色设置也更吸引人~当然王艳之前演的《还珠格格》中的晴儿，也是人设非常吸粉。想想当初，身边可是很多人都喜欢王艳呢。不过令媳太没想的是，王艳在拍还珠的时候都已经结婚了。她的老公就是灰常有钱的富豪王志才。

得知老公是他时，媳太简直都不敢相信。帅不帅的先放一边，这老公一看就年龄很大啊。如果宝贝们去查百度能看到，王志才63年，王艳74年，那么只差11岁貌似也可以接受。然而沧萌真的相信只有11岁吗？

王志才的年龄是写小了，其实两人可是差着27岁的年龄呢。不过娱乐圈找年龄大的结婚对象，也不是新鲜事了。王艳当初也是经老师介绍，相亲认识的王志才。

回头一想，这老师也不靠谱啊。给一20岁姑娘介绍40多岁的男子相亲算怎么回事？而且当时王志才已经有一个和前妻生的儿子，也就是后来的京城四少之一，王烁。而王艳和王烁也就差个七八岁，完全可以姐弟相称。没成想却成了继母和继子的关系。

但王志才结这一次婚，一点也不吃亏。他能有这样的财力，也离不开前妻的资本支持。他的前妻靠着港商前夫，揽了一大笔钱，王志才也靠着前妻，一下子翻身成了有钱人。然后王志才移居澳大利亚，靠着炒房地产起了家。又瞄准风头，回国在北京继续干起地产生意。

好不容易有钱了，王志才对于第二段婚姻就很谨慎，也是相亲时觉得小姑娘单纯，才在后面有了更多接触。当初王艳说两人96年注册结婚了，其实那是在澳洲注册的。等到王艳越来越有名气，王志才也撑过了金融危机，两人才在2000年结婚办喜酒。王艳这才算真正嫁入了豪门，过上了豪门生活。别人家别墅推开门是大海是草坪，人家是瞭望紫禁城。

好日子没那么容易过，家家有本难念的经，泥萌不要以为像王志才这样的富豪，只有家花，没有野花。只不过相比来说，王艳形象好，而且乖巧懂事，性格温顺，所以才会被他家认可。

我们常常能看到新闻说王艳在家得跪着给婆婆洗脚。虽说现实中没到那么卑躬屈膝的地步，但媳妇在家肯定要懂点规矩。尤其是媳妇出身普通家庭，而婆婆又自持高贵的满族后裔。所以这堪比“老佛爷”的婆婆，估计也就还真的只有“晴格格”能hold住。婆婆的难伺候，其实就连王志才都盖不过章，说自己母亲脾气不好，而王艳特别能忍。

王艳确实很看重家庭，对于婆婆也特别孝顺。当初第一部还珠就曾找她来演金锁。不过为了照顾生病的婆婆，王艳没有接戏。等到第二部来找她演晴儿时，她就痛快接了。但等到她怀孕后，王艳也就立刻息影在家待产了。

王艳这孩子能生下来也不容易，结婚6年后才生，明明老公年纪大却不趁早生，一猜就知道和财产有关。也是因为王艳确实安分守己，做的不错。王志才才点头同意她生下这一胎，也就是后来的球球。

等孩子大了，王艳还带着球球上过一个真人秀。这个节目基本上就是让小少爷体验民间疾苦。很多网友也能从节目中看出，球球性格非常“小皇帝”，娇生惯养。对于王艳，似乎并未有尊重之心。似乎在球球的成长过程中，母亲王艳在家庭中并无话语权。

不过好在球球年龄大了，已经被送去上贵族学校。教育熊孩子的事就交给学校来弄吧~

现在王艳在家也比较清闲，所以近些年她也会去一些影视剧里打酱油。好多人都说王艳变plus版了，但说心里话，四十多岁还能有这样的状态，媳太已经很佩服了。
