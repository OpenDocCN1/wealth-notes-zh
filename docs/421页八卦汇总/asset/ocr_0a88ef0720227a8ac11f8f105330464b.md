# 怕了怕了

5、令妃洗脑式
在小燕子伤好后，令妃带她逛着皇宫时，小燕子脱口而出自己的假身份，令妃直接丢了个肯定句给小燕子。
令妃：从此以后你的荣华富贵是享用不尽的！
看到这儿，扒爷只想问令妃娘娘一句，还缺大腿挂件不！颜值很高，怎看都不腻的扒爷这种……
皇上既然认定了你是格格，你就是格格，你必须相信自己就是格格。这稍微换个像姨太那样脑子慢点的，估计整句话说完都还没反应过来，自己到底是不是~

6、令妃威逼式
当小燕子想要说出真相时，被令妃直接打断并表情骤变警告小燕子，说出下面的话就会立刻没了小命。
小姨贝们看完总结的这几个小细节，是不是立刻就能 discern 实有些不对劲了！
当年那个孩子眼中柔情万分，人见人爱的令妃娘娘，完全跟最近热播剧中同角色的心机girl魏璎珞对上了！
扒爷刚问姨太，还记得小时候看到小燕子跟紫薇遇到危机时，就喊着令妃娘娘快来解围的样子嘛~
