# 2、贾静雯

现在很多明星都扎堆上综艺。但是外界却认为这也是无可厚非，毕竟综艺节目的酬劳高，还可以为自己提高曝光率。如果一个不小心，综艺火了，自己的人气热度也上来，何乐而不为呀！不过，话说回来，上综艺虽然是好处多多，但是身为公众人物的一众明星，如果行为表现有什么不妥，都会被大众放大，陷入舆论的漩涡中。

话说回来，在这次小风波中，倒是网友说贾静雯在湾湾名声不好这件事，挑起了扒爷无止境的兴趣。（嘻嘻，扒爷可是八卦小能手！！）

想当年，贾静雯和前夫孙志浩那场离婚争女持久战中，孙志浩指责贾静雯出轨，行为不当，让人大跌眼镜。然而，对于孙志浩这一说法，当时的湾湾媒体倒是十分淡定，已是一副见怪不怪的样子了。

话说贾静雯年轻时，因拍戏和已有家室的男演员黄建群传出绯闻。黄建群的妻子是湾湾艺人王百瑜，当时她已经有了身孕。而多年后，王百瑜也在节目上大爆自己当年“捉奸”贾静雯黄建群的情形。她在节目中声称，当年她在临盆前，因为女人的第六感，于是决定跟踪老公，一查究竟。大腹便便的王百瑜跟车追黄建群到了一家酒店，谁料，她发现下车的女人就是贾静雯。

怒火冲天的她简直顾不上自己是孕妇，直接冲上去甩黄建群耳光，大声质问贾静雯为什么要破坏她的家庭。面对老公突然其来的出轨事实让王百瑜气坏了，还动了胎气，于是赶紧送医生产。在王百瑜平安产下后，她就提出和黄建群离婚。当时黄建群也出来道歉，承认自己道德缺失。

相比黄建群，贾静雯对于小三这件事情却是一直保持否认态度。

不过，多年后，黄建群在节目大爆，自己当初真的有外遇，而自己和贾静雯分手的原因，竟然是发现贾静雯骑马景涛。之后他还大爆自己去贾静雯家中，发现她家浴室竟然摆满了各式各样的娃娃和法器，怀疑她是在养小鬼。

和黄建群分道扬镳后，贾静雯又认了当时湾湾的制作人吴敦为干爹。当时让贾静雯在内地大爆的一系列影视剧，都是吴敦帮她接的。那段时间里，过从甚密的两人却引起了吴敦的正牌女友郑家榆的不满。

当时，吴敦还送了贾静雯价值5000万的房子，于是外界一致认为他们关系不简单。但是吴敦表示他和贾静雯关系十分纯洁，自己连她的小手，都没拉过。（写到这里，扒爷只想说一言不合送豪宅的干爹，请给我们来一打）

就当大众还对贾静雯和她干爹这段关系议论纷纷时。贾静雯一个华丽转身又搭上了孙志浩，两人还火速有了爱情结晶。于是，当时在事业巅峰的贾静雯和孙志浩只能先上车后补票了。正当众人羡慕贾静雯嫁入豪门当幸福少奶奶时，外界竟然扒出孙志浩是一个妈宝男而已，他只是在家中企业打工，靠薪水过日子而已。

然而，因为贾静雯要负担起娘家的开销，所以在婚后不得不出来拍戏挣钱。因此两夫妻也因聚少离多，导致婚姻亮起了红灯。之后还上演了一场离婚争女大战。孙志浩更是大爆贾静雯在婚内多次出轨，还给黄磊发暧昧信息。

虽然贾静雯坚决否认自己出轨，但是她承认自己的确是有给黄磊发过信息。然而贾静雯却解释，当初自己和孙志浩起了口角，于是为了要气孙志浩，就给黄磊发了信息。

但是，不管贾静雯的最初的想法是什么，作为一个已婚妇女，给一个有家室的男人发这样暧昧的信息，真是三观不正啊。但是黄磊作为一名正人君子，最后只回贾静雯信息说，你写什么，我看不懂。

所以黄磊被牵扯到这次事件来，真是无辜。
