# 7、张静初

姨太看到这个热搜还奇怪了一下，以为张静初怎么了呢。原来这事说的是 一段电影片段，上热搜也是肯定张静初的演技。这回她应该非常开心吧，毕 节这些年别说上热搜了，自己都快混得查无此人了。要知道现在的微博热搜榜常常被00后、90后占据大壁江山，其他年龄段的人想要冲上去，一般也都是高段位，比如大咖大花之类的。

其实张静初当年和章子怡她们也是一批的，甚至风头都有赶超她们的时候，没成想十年河东十年河西，娘娘都已经做评委了，张静初还在八九线混。为什么她混着混着走了下坡路呢？姨太接下来就讲一讲她的故事，先从张静初的百科说起吧。

她是80年生人，比章子怡还小一岁，毕业于中戏导演系。00年她20岁时拍了部电视剧的配角而正式入圈。是不是这段看起来也没什么问题？不过既然姨太单独提出 来写，自然是有猫腻在里面。

张静初出道时还有“小章子怡”之称，但她其实比章子怡大哦。她上学时叫“张静”，是福州师范艺术学校幼师美术班91级的学生，95年中专毕业。13岁考到美术班，那么她就是78年生人，可福州小学是6年制，加上美术班3年，那么推算下来张静初最多4岁就入小学了。神童？当然不是啦，所以张静初应该是76年或77年生人。改小年龄这事，圈内很常见，但是改小了还去碰瓷章子怡，娘娘估计内心已经开骂了！

张静初美术班毕业后就去北京混了一段日子，97年她考上了中戏导演系大专班。可这个大专班非常不正规，好几十个人其实都是胡噜进去的，并不受学校重视。但她还很爱提起这事，采访时都说自己考入中戏导演系的事，却不提是大专班，算是在混淆概念。

为什么这么干？估计就是所谓的“虚荣心”啦，毕竟正规导演系只收10人，这么对外一说，有些不清楚的路人可就会当真啦，以为张静初真是“才女”之流。不过大专班再怎么不正规，好歹还是在中戏里啊！张静初未来能走上影视路，也离不开中戏这块宝地。

00年她接拍第一部电视剧后，01年张静初在《三少爷的剑》中演了个N番，在02年的《爱情宝典》中当了个8番。虽然有戏拍，但却全都是小配角，在电视剧圈她也没混出什么名气。

不过到了03年就不一样了，接的戏简直像开了挂一样。
