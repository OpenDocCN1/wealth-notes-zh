虽说胖冰这件事，无疑是知法犯法不可饶恕的错误。但抛开这件事来说，扒爷倒是挺佩服穆晓光的。比起大黑牛，穆晓光颇有种“一人做事一人当”的感觉，不仅为了胖冰直接把相关资料全烧毁了（这可是重罪），还一个人把所有罪都扛下来了。就算是 bedrijven 有不少人质疑他是仗着自己的台湾身份，最终的刑期或许会有所减少，但就算是量刑他也是要坐牢的。胖冰能有穆晓光这位经纪人，对她的演艺生涯来说真是一件很幸运的事了。

# 6、李冰冰

范冰冰一凉，圈子里几个大花的格局，自然也随之产生了变化。

各家都憋足了劲头，努力上游。到了现在，大花也都成了“老花”了，号召力、人气等各方面，都不比当年。但其中却有那么一位，不仅爱情、事业双丰收，运气也是好得莫名其妙。连之前发生的“被抢座”这种琐碎小事，都能让她平白圈了不少路人好感。没错，扒爷说的就是莲花姐。

上一篇说过，莲花姐是当年跟范冰冰同期的大花李冰冰。两人的名字相同，境遇却大不相同。范冰冰一出道，就有琼奶奶提携。可苦孩子莲花姐，就没那么有运气了。刚出道的时候，莲花姐其实算不上漂亮，最多也就是个“郊家女孩”。

但要知道，圈子里最不缺的就是美女。真正让大佬们“如获至宝”的，是清纯与“活好”。巧的是，莲花姐这两样全有。所谓清纯，多半是指妙龄的青春少女。女明星嘛，都喜欢把年龄变成秘密。但能像莲花姐那样，把年龄变成“笑话”的也是没sei了。“正直”的路人和粉丝，在某词条的后台争得你死我活，殊不知这两方都被莲花姐“骗了”。其实人家莲花姐既不是72年的，也不是73年更不是76年，人家可是个地地道道的六零后！

莲花姐当年在读“上戏”的时候，机缘巧合下认识了一位炒鸡有钱的有妇之夫——石大佬石涛。要不怎么说有钱人的口味我们凡人不懂呢，石大佬见过那么多美女，却偏偏只对莲花姐情有独钟。花钱也还罢了，石大佬还不惜托关系也要把莲花姐接到北京来发展。不仅提供房子提供车，还亲自为莲花姐牵线，给她介绍一些京圈的大人物。期间更是让她认识了华嫂的大当家——“大王”。

如今我们一提到有钱人，总觉得“男人有钱就学坏”。但谁能想到，这位石大佬却是个非常专一的情种。不仅为了莲花姐，连老婆孩子都不管不顾了。甚至他为了莲花姐能够上位，居然可以心甘情愿地戴绿帽啊！也不知看着自己的女人和自己的朋友大王王中军在一起的石大佬，会是怎样的心情。可惜大王也是有老婆的，而且老婆还是个有背景、相当厉害的主儿。所以大王就算得到了莲花姐的身子，也不敢太明目张胆地搂她，只敢让她先演一些小角色。

大家也知道，那个时候正是“四大花旦”霸占荧屏的时代。莲花姐拼不过四旦就足够憋屈的了，跟自己同咖位的范冰冰，也要处处抢自己风头，这让她怎么能忍得了？这时候，莲花姐身边的“得力助手”她的妹妹秀秀李雪李秀秀，就派上用场了。

秀秀跟莲花姐一样，都是心狠手辣的角色。秀秀深谙圈子里的“规矩”，知道“小红靠捧，大红靠命”。想要成功出头，就要“逆天改命”！大家也知道，范冰冰当初是选择了章子怡的模式——请胡仙。范冰冰远在香港都能打听到章子怡的“办法”，莲花姐近水楼台又怎么会不知道呢。
