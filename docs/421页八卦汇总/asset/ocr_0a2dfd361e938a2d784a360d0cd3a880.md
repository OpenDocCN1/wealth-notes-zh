# 31、孙耀威

孙耀威在92年通过歌唱大赛出道，因为外型神似当时已经火遍两岸三地的林志颖，而被唱片公司一g相中跟他签下了经纪约。到了第二年，便为他发行了首支单曲《认识你真好》，孙耀威也因此一炮而红。外型帅气的孙耀威凭借超高人气，还被封为“香港四小天王”的称号，可见他的人气有多高。

到了94年，孙耀威从学校毕业，也开始正式踏入娱乐圈专心发展自己的歌唱事业。虽然外型像林志颖，也跟小志一样是年少成名，可孙耀威的演艺生涯对比林志颖可相差甚远了。当年孙耀威凭借多首热门歌曲在香港人气超高，但经纪公司对他的包装定位却太过拘泥于“阳光小生”这个形象了。不仅严格要求孙耀威要保持皮肤白皙，让酷爱运动的他直呼崩溃；甚至在音乐理念上，也跟团队存在着不小的分歧。团队只想快速消费孙耀威的人气，在短时间内就赚回最大的收益。超负荷的演出工作，原本身体一直锻炼得很好的孙耀威，越来越无法承受这样的压力，身体更是越来越虚弱。

当歌手有着自己的想法、想坚持做自己的音乐时，放在现在的“粉丝时代”或许还会好一些。放在“经纪公司主导一切”的90年代，可没少让很多优秀的歌手因为雪藏、封杀而销声匿迹。比如范晓萱，比如徐怀钰。但这个时g毕竟孙耀威正处于人气最旺的时候，所以即使他在公司眼中太过“叛逆”，经纪公司也并没有太过撕破脸，毕竟还需要靠他赚钱呢。由于当时的唱片行业竞争太大，所以公司便始终想将孙耀威往“唱跳歌手”的方向发展。为了提高孙耀威的舞蹈功底，还安排他去日本找专业的老师来指导他。
