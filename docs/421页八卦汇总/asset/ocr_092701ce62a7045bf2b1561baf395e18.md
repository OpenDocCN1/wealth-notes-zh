# 32、彭于晏

吃惊之余，也难免对彭于晏的“背景”产生了浓重的好奇心。这件事如果发生在了其他人身上，即使不被“封杀”，也得是“掀翻天”的结果，怎么偏偏发生在彭于晏身上，就能大事化小小事化无呢？

大家也知道，一直以来由于我们跟“弯弯”那边的某些敏感原因，导致很多立场不正确 的台湾艺人，都无法来大陆捞金。而之前网上不仅有很多关于彭于晏是“TD份子”的言论，还一度传出他要大牌、出柜的风声。可即使如此，彭于晏现在却依然能安然无恙地，在大陆发展得顺风顺水，各种大资源不断。现在更是能出演“京圈大导”姜文的电影。

要知道能被姜文看中，绝对不是一般人靠关系就能轻易得来的资源。至于这背后的原因，今天就让扒爷给大家八一八，彭于晏跟华谊之间的瓜好了。
