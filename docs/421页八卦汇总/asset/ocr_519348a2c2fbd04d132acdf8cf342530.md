# 9、陈慧珊

最近两年电视剧市场上格外青睐大女主戏，除了古装戏以外就是那些都市精英女性角色深受观众欢迎。像前两年《欢乐颂》中由刘涛饰演的安迪，撇开剧情和人设上的BUG~初期她高冷内敛的气质和理智高效率的女强人工作模式，还是很直击观众内心的。但小婶贝们要知道，其实这类角色演的最好的可是九十年代那批TVB港剧里的女星啊！

昨天小婶贝们跟着扒爷追忆林保怡，今天咱就来说说他的荧幕CP陈慧珊吧！这位可是当年TVB上位最快、最炙手可热的当家花旦，港剧知性御姐专业户~有一种人光从外表和气质， bezieht很多人，而陈慧珊就是这类人。

陈慧珊1971年出生在香港，1976年之前陈慧珊的父亲在香港电视台教舞蹈。同年为了提供给一双儿女更好的教育环境，所以这位父亲选择了全家移民美国波士顿。年仅5岁的陈慧珊跟随家人一起同行，从小在父亲辛苦工作的耳濡目染下，学习成绩优异的她大学考进了名校波士顿学院。大学期间攻读新闻专业的陈慧珊，毕业后便在波士顿电视台担任编导。但由于美国新闻界给华人的机会太少，陈慧珊决定回到香港发展，继续追求自己的主持梦~之后，陈慧珊通过投递简历进行面试，凭借自己扎实的英文基础和出众气质，成为香港无线电视台明珠台《城市追击》的主持人。

1996年，TVB监制邓特西相中了陈慧珊的形象与气质，特意安排她出演电视剧，从此陈慧珊正式转型成为一名演员。陈慧珊的演艺之路相对于其他演员而言算是十分顺遂的，初入演艺圈就参演了《壹号皇庭V》中的阿CAT一角。
