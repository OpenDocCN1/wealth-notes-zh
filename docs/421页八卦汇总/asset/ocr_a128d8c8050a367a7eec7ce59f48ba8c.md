# “插足”成瘾？

由于有着“女神光环”，所以陈妍希一来，就待遇颇高。不仅能有当年正当红的文章、刘诗诗，更有李连杰这样的国际巨星加持。虽然这部电影（不二神探）最终的票房不功不过，并不算大爆。可倒霉的是，这部并未让陈妍希再进一步的电影，却在上映后不到半年，男主角文章就被爆出了震惊众人的“周一见”事件。

随着文章的好男人形象崩塌，神通广大的网友也开始了“大家来找茬”的趣味活动，纷纷八起了那些年跟文章合作过的女演员，还有谁可能跟他有“不当”关系。然后，倒霉的陈姑娘和文同学那张著名的“摸臀”照，就被扒出来了。

虽说关于这件事，网友一直分成“摸了”和“没摸”两派，不能最终得到确切的答案。但陈妍希在明知道文章是有妇之夫的情况下，还这么不避嫌也是确实有问题的。虽然这件事在之后双方的辟谣澄清下，不了了之了。可紧接着被爆出“陈妍希要出演小龙女”的消息时，网上又双叒炸了锅。

陈妍希的娃娃脸，演现代剧的话还是比较有优势的。可一旦涉及到古装，尤其是那些非常“显脸型”的发型时，效果就会非常惨烈。果然，定妆照一出，网友就纷纷直呼辣眼睛、接受不了。

但彼时正是于妈最得意的时候，不仅放豪言表示“陈妍希就是我心目中的小龙女”，更称“定妆照不及正片的万分之一！”。结果，等正片出来以后大家才知道...这特喵的还不如p过的定妆照呢！！

这部剧没能有多高的收视，反倒是个小筐包，哦不，小龙女的表情包成了那些年网友的快乐源泉。
