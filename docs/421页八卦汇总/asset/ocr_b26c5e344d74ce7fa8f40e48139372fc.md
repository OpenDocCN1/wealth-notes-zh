# 2、秀公知人设

昆明火车站发生恶性恐怖事件时候，姚晨来了句“恶之花绽放的土地”。这是欺负抓爷读书少看不出这句子是纯贬义？？？哀悼就哀悼不能好好说话，非得咬文嚼字还来个错意，脸都要丢没了。

天津大悦城坠楼事件也一样，明明是家长照顾不周，姚公益表示需要商场和酒店提前防范这类安全隐患。

来，跟抓爷看看脑子清醒的网友的回复~

重点都没有弄清楚就化身发声之士，抓爷觉得姚晨出门自己带个栅栏会更合适些。

她还发过一个吐槽北京空气的微博，“谁能想到有生之年，作为一个公民还能失去拥有蓝天的权利”？多年后，我和儿子的对话估计是这样的。小土豆：妈妈，什么叫‘晴天’？我：历史课本上没有介绍过吗？

这段对话在抓爷看来简直是尬上加尬，作为一个在北京待过多年的过来人身份，抓爷也觉得雾霾问题确实很严重。但又不是只有北京有，韩国还有呢！这种看似很聪明的反讽方式真是让抓爷看着都心累……

对了，还有个更扯的引力波事件~

姚晨曾经转发过一个关于引力波被证实的微博，内容说的是一个下岗工人在电视上提出引力波，然后被嘉宾质疑的视频。她转发后评论了一句，“了不起的工人”。

抓爷承认虽然节目里的主持人和嘉宾都不咋地，但也比这胡说话的工人好多了。

有物理学不错的小婶贝们应该知道引力波到底是谁提出的吧~不知道的抓爷在这儿免费科普一波，引力波确实有，但是这玩意是100年前爱因斯坦提出出的！！而且，这哥们在节目里说的引力波跟爱因斯坦的引力波毫无关联，就是随口说了一句。节目里所说的那些所谓物理观点简直是乱七八糟、异想天开，连抓爷这种物理废都听的无语。结果，最后那个工人被证实脑子有点问题，经常闹出这些无聊的事情。

所以姚晨跟着屁股后面转发这玩意儿，是想表达自己比抓爷这种物理废还废的意思？抓爷觉得没有深厚的知识底蕴做基础，就别脱口而出无知话语了，以免让人笑掉大牙。

来小婶贝们看看今年姚晨的走秀照，如何~

看到这张又让抓爷想起她怀孕二胎时发的辣妈励志健身通稿……被全网支配的恐惧再度袭来~看了这些抓爷真心只想说一句，玻璃心和自大不变的人再怎么换不同人设也没用。

如今的姚晨想要封神，要么靠美，要么靠演技，要么靠观众缘……可惜在这三方面怎么看都有人明显能胜过于她，小婶贝们觉得她还有可能回到当年的巅峰时刻吗？
