# 6、导演海岩

这个赵宝刚导演虽然有老婆孩子，但早先和编剧一块合作时，可是没少“同流合污”。毕竟娱乐圈是个很容易让人“迷失本性”的地方。加上编剧还在旁边挑唆，所以以前赵宝刚导演有潜规则男演员的传闻，也不奇怪哈。但注意，他可不是“主动”的哟~（你们懂得）不过后来两个人因为利益冲突，撕破脸分道扬镳了。最后赵宝刚导演也就回归正轨了。所以请记住，在娱乐圈能屈能伸、能攻能受、男女通吃都不是什么新鲜事！
好了，现在扒爷要开始今天的故事了，还和昨天有点关系哦。海岩单看履历表，还是很传奇的。自己没上多少年学，但脑子特聪明，所以自己不仅成了高管赚大钱，还能抽出空来搞创作。而且海岩家里头还有点hong色背景，所以海岩势力不小，很有点爱情小说里牛逼总裁的意思。
但海岩能出演的不是BG文，而是BL文。没错，海岩是个基佬，资深的那种。当基佬成为牛气哄哄的基佬时，想往上爬的小伙子们，就纷纷献身于海岩。谁让海岩基本上来个人就能捧红呢？所以从海岩这头出道的小鲜肉，几乎全都是奉献过的。这个名单会灰常的长，全都是当年很帅的小鲜肉，海岩真的是艳福不浅。
不过有的人是主动求上位，有的人却是被逼无奈，比如男星“黄明”。因为黄明长得好，所以海岩就瞧上了黄明，甚至干出了酒后霸王硬上弓的事。这可让直男黄明崩溃了，一度想要揭发海岩。但海岩有势力有背景，黄明还只是个大学生，又哪里能对抗的了？所以海岩一通威胁之后，又给了黄明一个甜枣。下一部男主角就定下来黄明。黄明就靠着海岩的剧正式出道了。
可说到底黄明不是弯的，而且海岩爱好特殊，喜欢玩字母，所以陪海岩的那两年，黄明真的是身心摧残。不仅如此，海岩还特别霸道，他不允许黄明跟外人接触太长时间。女的不行，男的更不行。
这种变态的占有欲，和强大的背景让黄明没办法解脱出来。因为但凡黄明有要分手的想法，海岩就会让他尝到惩罚的滋味。但最后黄明还是脱离了海岩的掌控，这就得感谢一个圈外人L女士。两人是在一个饭局上认识的。
