# 1、胡兵

如果说圈子里，有谁每每被提起，就免不了让人惋惜“时运不济”，那胡兵绝对算得上一位。

胡兵本来是一名“赛艇运动员”，但因为身体超负荷所以早早退役了。之后因为形象亮眼，身高189cm的他被公司相中，正式入行成了模特。91年开始，模特胡兵就拿下了多个冠军，成绩也是很亮眼了。之后又演唱了白古的《神雕侠侣》主题曲《归去来》。随着这部剧在内地的热播，也让胡兵火出了一片天。

当然了，当歌手“只能算是‘玩票’”。胡兵真正想要成为的，是“演员”。有了名气之后，胡兵就直接进军了演艺界。还跟同时期的另一位当红模特翟颖，组成了内地最早一批的“荧屏情侣”。胡兵也凭借自己的人气和实力，被选为内地第一届“四小生”。

估计即使是很多年纪小的童鞋，应该也都看过那部“粉红女郎”。高颜值、大长腿的“王浩”，也让胡兵成为了一代人心中的“白马王子”。然鹅就在胡兵风头无两的大热势头中，却遭遇了自己演艺生涯中，最致命的一次打击。
