# 小花系列

# 1、安吉拉baby

经常扒女星和男星的关系，你们应该知道，有一些女星其实是没什么脑子的…真正厉害的其实是她们身后的那些人。

举个栗子，交公粮很积极的女星范冰冰。她能从一个小丫鬟到爆火，其实是她后背有高人在指点，这个高人穆晓光你们也知道了，已经帮她背锅了~其实高人的背后还有高人~台前搭架子唱戏，其实都是台后安排好的，但是出事了大家不都只骂台前么，这才是真正的agu高手呀。

再举个栗子吧，演戏演得好好的，国民度那么高的女艺人赵薇，她为什么突然开始走另外一条路线了呢，流量不要，热度不凑，这可不是一个女星该做的事呀？其实她背后也是傍上了郭富城，只不过她不是靠脸交易的，而是靠的她身上收集到的很多资源。

她是郭富城们中间牵线搭桥的人，跟着分一杯羹，出了事也找不到她的头上，她背后也是有人支招的。不过她自己有点脑子，不至于像上面那位一样，被玩得团团转，但她这onk一且出事，就是大事。

这两位你们都熟悉的，扒爷就不赘述了，来请说我们今天的主线吧，说说一个知名背后推手风尚国际周优根的鬼斧操作，如何帮助很多女星完成“梦想”。

说到女星们的梦想，其实不外乎两种，一是出名，二是有钱。

出名这个事，很大一部分是看运的，有的人就是没有红的命，演啥啥不火..有的人就是运气好，走了红毯都能火。但是这个背后风尚国际周优根就厉害了，她挖的都是些草根。

有多草根？让扒爷给你们数一数。她手下有搞运动出身的，有做设计出身的，还有做主持出身的…非常厉害的是，还有一位以前是混街区的，就是跟着人家爱玩的稍微有点才华的小伙子做骨肉皮.. 

这个推手风尚国际周优根就很厉害了，她的家境是很好的，但是她不满足，想要嫁豪门，她反思了一下自己，觉得自己是靠气质取胜的，女人都是要靠气质的，所以就加强了自己在文艺方面的种种，最后嫁了一个小豪门。借着嫁人，她就去了非常富饶的那片土地，通过丈夫的关系，接触到了一片新大陆。这片新大陆让她学到了新技能，比如看哪个女人能成功。

这也是可以理解的，因为她后来工作要接触到很多很多女孩子，看多了自然就知道哪一些人的野心可以得到满足，她这一辈子不用学会其他的，就这一手就够她吃一辈子了。

她本来不是靠着老公进入了一个新行业么，后来她接触到的女孩子越来越多，她就给人家画大饼，说我可以带你实现两个梦想。这两个梦想，就是女星们最想要的那两种，出名和搞钱。
