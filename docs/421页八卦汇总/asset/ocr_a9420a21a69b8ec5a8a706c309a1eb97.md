# 10、马景涛

马景涛学上的不多，也不是科班出身，但际遇却很好。出道后拍戏，那是一部接一部。 多年来，也留下了不少代表作。但是如果把作品、奖项、演技先放一边，单看人品、性格的话，马景涛是不及格的。

马景涛在感情方面比较混乱，常常跟女演员传出绯闻。而且跟他谈过的那么多对象里，没有几个说他好的。原因就是他脾气暴躁，尤其是爱酒后动手，这就把女人都吓跑了。比如他的某一任女友郑yq（来自度娘）就被喝多酒的马景涛打伤住进了医院，最后自然是以分手告终。比如他的第一任老婆唐蔚，两人结婚没几年就离婚了，还不就是因为他是现实版的“安嘉和”？

马景涛离婚后要是吸取了教训也好啊，但他不！离婚后的马景涛照样对新女友动手了。这个新女友，就是跟他合作的女演员的妹妹李婷芷（就是差点演小燕子的那个李婷宜的妹妹），因为妹妹过来探班姐姐，于是就和马景涛认识了。之后两个人也是谈了好多年恋爱，妹妹最后还是忍无可忍分手了。

不得不说，马景涛虽然品行不行，但女人缘是真好，对象是一个接一个的谈。

和妹妹李婷芷分手后，马景涛又在拍一部奇幻神话电视剧时，和合作的女星“吴佳妮”相恋了。吴佳妮的年纪都可以当马景涛的女儿了，家里头自然是反对的，没成想就这样，两个人谈了几个月还是走到了 一起。其实闪婚的原因不是什么看对眼了一分钟也等不了，而是吴佳妮在和前男友L赌气。转头随便找个人结婚，想气气L。

扒爷觉得吴佳妮脑子也有问题，这种斗气最后不还是自己遭罪吗？前男友L压根就不care啊！不过出乎意料的，吴佳妮竟然和马景涛保持了很多年的婚姻，还生了2个孩子。那是不是代表马景涛改过自新，对吴佳妮不一样，不会酒后打她了，所以婚姻才长久了？

当然不，宝贝们看过童年阴影《不要和陌生人说话》这部电视剧吗？马景涛就和剧里的安嘉和一样，打完就后悔，便动求吴佳妮原谅她。所以吴佳妮也是一次次原谅了他。

这么一看，吴佳妮是不是颇可怜？生了2个孩子还要被马景涛打，real心疼她。但吴佳妮也不傻啊！家里头没温暖，那就外面养一个呗~毕竟当初结婚就是为了赌气，她跟马景涛也没啥真感情。而且马景涛都能够当她爸了，那方面自然就跟不上她如狼似虎的需求。所以吴佳妮和马景涛早就各过各的了。

吴佳妮其实早就提离婚了，只不过马景涛一直不想离而已。但因为到后面确实没啥感情了，耗着也没意思，最后也就答应离婚了。吴佳妮离婚是淡常happy，毕 竟她家里有钱，几百万都能给小白脸花，所以吴佳妮离开马景涛，不愁钱。后来吴佳妮在这段婚姻里最后也收到点补偿。马景涛不知道是为了面子还是咋地，总之离婚时没说吴佳妮养男人的事。

吴佳妮呢，也没有写长文哭诉自己的被家暴史，两位互相留了面子，他日也好相见。离婚后的吴佳妮现在又出来拍戏了，路人缘似乎还不错~大家说她还是很好看，带孩子很辛苦，微博也让人有好感。

总之，比起前夫马景涛的风评来说，吴佳妮是很正面了。

所以这段姻缘算下来，也不知道到底是谁欠了谁？
