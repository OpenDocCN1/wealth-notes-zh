# 子不语怪力乱神

# 1、香港温莎大厦

之前扒爷在“四旦双冰”系列的文章里，曾经说过，龙儿的胡仙是在台湾求的，而胖冰的则是在香港求的。虽然两人的入门地点和引荐人不同，但她们的“胡仙师傅”却是同一个家族的。

相比于南方的童鞋，或许北方的童鞋对胡仙会更了解。简单概括北方的“五仙”：狐 黄 白 柳 灰。这五仙在很多北方家庭里，是作为“保家仙”受供奉的。可这保家仙听上去是很高大上的，但实际真要是指照严格的道家规矩来说，把这“仙”字改成“鬼”怕是会更合适些。

赵本山“家在东北”，东北这个地方，一直都有“萨满jiao”遗留下来的一些旧俗。比如在农村较为常见的“出马xian”，就是件很神奇的事情。按规定，“出马xian”得了“五大xian”其中之一的庇佑，是需要自身去做一些善事来帮助xian家修行的（比如给人看病、替人解难），而且做善事时是不能收取重酬的。因为出马弟子本来就是帮五xian积功德、助修行，收取贿赂是违反门规的事情，是会被xian家惩罚的。

赵本山的命格很好，当年就是被xian家挑中主动去找他的。xian家答应让他一路高升，但也需要他帮xian家完成修行的任务。一开始，赵本山严格按照xian家的要求去做，不敢有一丁点僭越。有了“指点”，星路当然一路畅通，直接成了“国宝级”艺人。可惜，随着赵本山的名气越来越大时，免不了有很多人想要巴结。一些知情人，就假借“算命”的理由去找他，明显是“占卜运势”，暗是他结交、拉拢。一来二去，他“出马”的酬金，就不只是“几十块”而是“几十w、几百w”了。

随着家底越来越厚，赵本山更是在一片恭维声中失了本心。不仅沾染了xian家多次警告他不能碰的“官场”之事，更是没少收受“不义之财”。扒爷昨天也说了，有些反噬是当下就会报应在蒸煮身上的；但如果这个人的命格硬、气数未尽，饶是xian家也暂时动不了他，只能等到运势衰败才能“下手”。

赵本山自己也是知道这些，所以他在发现自己有了反噬的迹象时（比如身体越来越差，梦魇、心悸等），就已经在筹谋退路了：把徒弟推出去，来保住自己的人脉。可惜啊，人要是没了运气，就真是干什么都不顺。尤其之前他那位xian家因为不满意他的所作所为，还故意在他需要做出某个重要决策时（zhengzhi立场），给了他一个错误的信息。这致命一击，终于在之后“东窗事发”时，连累他倾尽了家财才得以保命。

自上古的“ishga氏”传承下来的胡仙一派，只有龙虎山天师府所供奉的胡仙，是向天庭发文申奏过、经玉帝特许继续修行的“狐仙”。其他民间的那些胡仙庙以及北方家庭里供奉的，其实是不被“官方”认可的，就连供奉的牌位上，也只能写“大仙”或“胡仙”（胡非狐）。
