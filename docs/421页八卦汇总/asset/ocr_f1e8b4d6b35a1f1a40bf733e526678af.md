# 通稿艳压娱乐圈群花

张天爱团队的碰瓷能力是扒爷见过的女艺人中可以排进前五的，毕竞内容真是又敢又拼。从演技吊打、衣品艳压、年龄比小、惊艳主持界、古装第一美人，真是 一个都不落下。在扒爷看来，当时的流量大小花都被她压了一遍，也不知道那些花朵们本人是怎么看待这件事儿的。

# 自降身价撕资源

碰瓷蹭热度熟悉后，张天爱团队的操作升级一档，开始走上降价抢资源的路线。
2016年，张天爱去巴黎看了秀，结果回来就出现了张天爱顶替范冰冰拿下巴黎欧莱雅代言的通稿。当所有人都以为张天爱的团队牛逼到可以撕到范冰冰的大饼时，就有网友出来打脸张天爱表示，张天爱只是中国区代言人。范冰冰这边其实可以算是个乌龙抢资源，但接下来就是货真价实撕资源了！

+   1、张天爱与王大陆拍摄的《鲛珠传》，在它也叫《九州·华胥引》时原定的女主是古力娜扎。结果，官宣的时候变成了张天爱搭档王大陆。

+   2、赵丽颖在官方行程里已公布了要在无锡拍摄广告找替身时，张天爱这边自降身价截胡了赵丽颖在苏宁广告中的碧瑶一角。

来，小姨贝们看看这张海报，扒爷就问你们觉不觉得怪？明明是人家赵丽颖正在热播的《青云志》中女主角色造型，张天爱这顶着风一脚插进去硬抢，也不怪网友们对这波广告有反感。

那段时间张天爱好像跟赵丽颖杠上了一样，真是为了红急不可耐啊。

这些被抢资源的女星们，一直没有正面回应过这些事情。但在扒爷看来不回应也是正常的，毕竞为了这点资源出面确实显得小气又掉价。

不过当被抢的如果是女主资源那就另当别论了……

就像最近张天爱热播剧的女主角色，其实现本是金晨的饼。当时剧组官宣前就放出了各个主角的替身招募信息，其中就包括金晨的名字。结果等官宣后大家发现原定的金晨却不在海报中，取而代之的是张天爱，而原定张天爱的角色却落到了王丽坤头上。

随后，金晨自己在微博上发了一条疑似被抢角的信息，导致粉丝和网友们把王丽坤以抢角的名义推到了风口浪尖上！但没多久就有营销号曝光抢角的真实情况：张天爱方觉得应欢欢的人设更好，因此抢了这个角色挤走了金晨，而王丽坤只是被临时拉来救场的。

扒爷觉得，这部剧的主角资源被撕其实很正常……
谁让人家这是IP大剧+流量小生+著名导演张黎亲自坐镇，在当时的情形来看播出后想不火都难。一般能在这种剧中出演女主的必定自带流量并且背后有实力公司作为支撑，而金晨那时刚开始跟唐人闹解约。公司与艺人之间的关系已经变得非常紧张，当时出了这样的事情金晨根本指望不上公司。

相反张天爱这边就不一样了，当时悦凯跟喜天有合作关系。这部戏悦凯也有参与投资，所以推张天爱当女一还是没问题的。但扒爷真说，都是在圈里混的人，总 是这样频频抢资源艳压别人可是很败路人缘和招黑的！

这两年扒爷看着张天爱的人气一路flop到底……从当时被喜天翻出当一姐培养，到如今已被后来者宋祖儿代替了一姐位置。小姨贝们现在看看张天爱辛辛苦苦降酬败口碑抢来的这些资源，有几个爆了？

扒爷觉得，张天爱真的是无形中浪费了很多当年凭借《太子妃》积累起来的东西。倘若那时张天爱能踏实好好提升实力，而不是选择强刷热度越炒越过的话，现在的她绝对是另一番景象。

现如今张天爱这个境遇怪不得别人，有句话很适合这个情况：小火靠捧，大火靠命，强捧遭天谴。
