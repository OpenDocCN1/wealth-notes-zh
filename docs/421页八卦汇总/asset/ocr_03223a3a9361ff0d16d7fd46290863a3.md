# 5、张萌

姨太感觉现在每部剧，都有各种瓜可以吃。所以今天姨太就来说说正在热播的网剧，前几天爆出来女主张萌拍戏期间流产的事吧。流产一事是张萌的经纪人讲出来的，因为不忍心看到张萌一直被网友指责攻击。

很多人都佩服张萌的敬业精神到了这个地步，但姨太同样身为女人，还是要说：这么做虽然对剧组负责，对工作负责，但难免对未出世的宝宝、对自己的健康、对家庭不负责。毕竟也是37岁了，算得上是大龄孕妇。而流产后本就需要静养，张萌却只休息了一周就继续拍戏，后期还有下水戏、动作戏等，对身体的损伤真的很大！

张萌确实很拼，克服所有阻力也要演好这部戏。而且为了争取到这个角色，就连报价都不想报，一切全力配合剧组。这个对于张萌来说“可遇而不可求”的角色，也让她受到了质疑。因为有网友看了原作，发现这个角色是新加的，而且戏份很多，比原作中的女二还要多。加上宣传时一直番位靠前，所以还被怀疑是带资进组。

因为杨蓉饰演的角色，原本在书中是女一，而现在却变成了女二，杨蓉粉丝就坐不住了。针对“压番位”一说，还去@于妈，于是于妈下场与网友互动，话里算是承认张萌是带资进组。于妈说张萌的职称是老板娘，和大家不一样，而且加上之前合影，证实了张萌是耀客传媒的老板娘。

网上的传闻经于妈盖章后，似乎就是板上钉钉的事，不过张萌还是出来解释了。这条微博否认了带资进组，但对于耀客传媒老板娘一说并未否认。因为她不仅是老板娘，还是公司旗下艺人。耀客开发制作的剧大多也有张萌的参与。比如《宝贝》、《敢爱》、《离婚律师》、《三个奶爸》、《幻城》等。

耀客传媒的老板就是吕超。她和吕超从合作《神话》时就认识了，一开始只是工作关系，传闻是2014年她在拍《离婚律师》时与吕超结婚，婚礼上张国立还是证婚人。

张萌虽然拍戏多年，但绯闻其实很少。除了现在的老公，姨太搜到了很多类似的新闻，文中都提到某男与张萌在机场亲密，而这男子是圈外人，叫张海苍。姨太真的要问问各位撰稿人，注意看一下吕超特色的下巴，这明显就是吕老板，你们是怎么统一叫张海苍的？

除了上面不靠谱的新闻外，张萌和霍建华在拍摄《唐琅探案》还传出过绯闻，不过这十之八九是为了宣传新剧。姨太还能搜到的是她与黄海波的绯闻，而且有两人亲吻的照片为证。新闻都是写两人是在拍摄《心术》时认识的，但这两人最后都没出演啊，所以什么鬼新闻！

不过百科里两人倒是写明，要知道如果图片女子并不是张萌，那么他们自己的公司一定会去修改百科，这也侧面证实他俩确实是有过一段。
