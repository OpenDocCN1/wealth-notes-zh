# 31、孟子义

扒爷发现，最近的热播剧中总能找出翻红、大火、努力洗白的明星。无论是当年的古装小生葛远、刚爆火的朱一龙，还是被晒出家暴实锤的许凯，都纷纷涨粉不少。

在娱乐圈里，艺人成功靠剧翻身的例子数不胜数，但其中也不乏有半路翻车的。扒爷今天要说的就是下面这位刚上路就翻车的姑娘，孟子义。

1995年出生的孟子义，2014年刚出道第一部作品是《武神赵子龙》中，戏份重过女主的丫鬟石砾一角。随后在《人民检察官》《何所冬暖，何所夏凉》《凉生，我们可不可以不忧伤》等热门剧中，皆饰演戏份颇重的女二一角。

小娣贝们刚看到这些是不是觉得，这丫头演技一定很好。NO NO NO NO NO! 人家孟妹子是有钱带资进组，这也是她这次翻车的主要原因。

最近正在热拍的《陈情令》剧组，孟子义又被网友曝出带资进组。把剧中的女配“温情”一角加戏至八十场，直接顶替了原来双男主的剧情，剧名被网友戏称为《温情令》。

这部剧原本就是大IP改编，所以拥有大批粉丝。当加戏消息曝光后书粉们开启了手撕模式，直接抛出了整理好的细节证据。粉丝们齐心协力找到了剧本流出的部分截图，孟子义在里面饰演的角色硬生生跟其中一位男主组成了CP角色，还有很重的感情戏。

孟子义这位1995年出生的戏霸，出道没多久就开始这操作真是66666。不过这似乎也不算什么，毕竞人家在湖南卫视《一年级·毕业季》综艺上给扒爷留下的印象更为深刻。

扒爷先简单给小娣贝们介绍下这档节目，《一年级·毕业季》是湖南卫视联合上海戏剧学院推出的校园纪实节目。节目里有四位明星导师，陈建斌、娄艺潇、张智霖、袁咏仪，他们分别带领学员毕业班和明星预科班进行学习比拼。

在《一年级·毕业季》第一集的团队战中，孟子义被指定为女一号。但由于她本人一唱歌就会变成车祸现场，而女一号又是需要唱歌的，所以大家决定投票换人。

这一结果让人民币玩家孟子义的玻璃心碎成了渣......孟姑娘直言：“我没有说一定要争这个东西，因为，女一号本来就是我的。它是我的，如果要给别人，也是我给别人，我干嘛要把我的东西让出去。”

“我觉得特别委屈，我不高兴了！我不排了！”“孟巨婴”丢下话后就直径冲出教室持续暴走，导致所有学员无法继续排练。最后，全组都去呛“孟巨婴”，然并卵。“孟巨婴”在生气之余，还特地把自己隔离班正在彩排的闺蜜虞书欣叫去陪她。导致隔离全班都在等虞书欣彩排，把导师娄艺潇直接气哭了。

在扒爷看来，虞书欣和孟子义的闺蜜爱全靠“巨婴情”撑起，毕竞都不是省油的灯。

之后，孟子义还在节目中与导师袁咏仪“互抢”了一次。袁咏仪带领学员们一起客串群演，孟子义饰演小偷却不想弄脏自己。袁咏仪当面质问她为什么脸这么干净，孟子义反驳称：“我是小偷，又不是乞丐”。一番对话下来把袁咏仪气的发抖，直接恐问：“你是演员还是导演？你一点都不专业，你的态度是怎样的？”

换装期间，孟子义还偷偷换了件内衬被发现，袁咏仪告诉她这样会穿帮。孟子义直接反问:“会吗? 老师, 这样就不会是黄的了。”

一脸很无辜的孟子义表示，真的听不懂袁咏仪在说什么。

节目中，陈建斌作为导师在其他学员提出合理想法后，非常爽快的答应。到“孟巨婴”这儿，陈建斌再三强调：“不要跟原有角色有直接联系”（因为怕戏份不均匀）结果“孟巨婴”开始层层加戏不止......惹的陈建斌直接拒绝孟子义的加戏，并直言，“又来了，不要，不要（不要加戏）”。

这节目总共就四位导师，在“孟巨婴”一出手气倒了三位，扒爷真是佩服佩服！

不过，“孟巨婴”在节目中也有被真正扎心的时刻。
