# 1、许晴

许晴的坊间“花名”虽然叫“老公举”了，但早年间她其实有另一个外号，叫“三娘”，原因是“三”了太多人～

老公举许小姐，是绝对不会看上李亚鹏的～要知道，李亚鹏自从卷入了“基金”的财务问题后，他的状况就跟他的“发量”差不多——萧条零落了。许公举又是出了名的“非富豪不嫁”，她要真是能看上李亚鹏，早在当年两人合作《笑傲江湖》时就在一起不是更好？起码李亚鹏当年虽然没钱，但作为妥妥的“一线小生”，脸还是能打的～干嘛非要等到现在，李大叔没钱又没颜的跟他交往呢？

如今很多人一提起许晴，紧接着就要说起她的那个“外号”——行母。但这其中有多少人，实际上根本就不了解当年那件“某行行长包养情妇”的事情，只是在无脑跟风的？许晴多次否认自己是“行母”，还被粉丝找出了“她不是行母”的证据，这又是怎么回事？

坊间已经有很多关于这件事的文章了，但不论是澄清还是坐实，不过都是大同小异。但扒爷却在重新翻查资料时，发现了一些并没有被人注意到的细节…来吧，今天扒爷就带大家八一八这件事的来龙去脉！看看许晴被叫“行母”这么多年，到底冤不冤～

事情的起源，要追溯到02年。当时任职于国内建行行长的王雪冰落马了。从这时开始，坊间就有不少关于“许行母”的闲言闲语传出来了。也有不少人特意就这件事去相关部门核实过。但也只是得到了“王某冰承认了三名情妇”的事实，却并没透露这三个人的身份。就这样，谣言在“许晴的否认”和“网友的质疑”中，一直也没能得出确切的结果。

直到06年，国内的某家杂志刊登了一篇根据王某冰案情所撰写的文章——“情迷女影星”。网友根据文中的各种细节的描述，判定文章里提到的那位，跟王某冰“约会”的影星“宋菁菁”，就是许晴。

同样是在这一年，当时还是小报记者的卓伟卓 samo，也根据王某冰案件的卷宗文案、坊间传闻、采访资料等相关信息，写了一篇《许晴与前大款男友的秘密生活》。再加上许晴对这件事“懒得理”的暧昧态度，这些都让观众对于“许晴是王某冰情妇”的传闻，深信不疑。

虽然在之后到了14年时，事隔多年许晴又跑去接受了节目采访，并在访谈中正面回应了这件事。甚至主动提起自己在王某冰出狱后，还跟对方通过电话，希望借此来洗脱“情妇”的嫌疑。（△行长出来后第一时间就联系公举，这得多念念不忘啊～）但这条传闻毕竟已经传了那么久了，就算许晴现在公开回应，也难免会被质疑她是“反其道而行”的欲盖弥彰。

接下来，大家就跟扒爷一起来看一看，当年那篇“情迷女影星”的文章里，究竟有哪些线索与许晴有关联吧。

先来看一下，文章里的“宋菁菁”跟许晴“吻合”的的几 Kalman特征：许晴与宋菁菁，均有一部98年大热的作品来来往往上映；许晴和宋菁菁一样，喜欢吃西餐；以及许晴和宋菁菁都是童星出道的女演员、出身于军人家庭等等。

但话也说回来，毕竟这些相信过于“模糊两可”，并不能完全拿来当推测嫌疑人是许晴的证据。而且，文章里的其他“确切信息”，是有很多跟许晴对应不上的。其中一个一直被粉丝用来反驳谣言的信息，就是文章里明确提到，宋菁菁的生日是12月27日。而许晴不论是网上的词条资料里，还是曾经公开示人的身份证信息上，她的生日日期都是1969年1月22日。

扒爷也根据万年历，对比了1969年的农历、公立日期，但二者皆与12月27号无关。之后，扒爷又根据文章里的描述，推测出这段“送生日礼物”的时间，应该是再98年。但这一年的阳历12月27号和1月22号，也都不能跟另外一个条件吻合。
