# 2、广州荔湾广场

今天扒爷就给大家来讲一讲，为什么在我们的生活当中，会有如此“凶险”的地方好了。

要知道，在每个地方都会有一个“神秘的大门”。这扇门，平时只会在有“人”需要通过时才会打开。要么就是在那些“特殊日子”，会破例打开一天（比如我们常听到老人说的“七月十五鬼门开”，指的就是这件事）~一旦大门被破坏，就会造成两个世界的秩序混乱。轻则“闹鬼”，重则“索命”。这个大门，按照风水学来说，通常会在一个地方的“东北45度方位和西南45度方位”。

不过凡事也都有例外，某个地方的磁场要是混乱了，就容易发生事故。比如，国内就有很多“车祸高发区”。碰巧在某个地点，发生过很多相同原因造成的事故。这一类的情况，多半就是由于某个事故，致使“大门”在这里意外开启了，每隔一段时间就会出现“找替身”的情况的。不过上面这种“固定开启大门”的情况实属少见，更多的情况是仅有一次，碰巧在某个地点发生意外。比如当年胡歌出的那场车祸，就一直是圈子里的一件诡异事件。

事发后，胡歌的手机不仅发现有拨打过求救电话；司机也在过后采访中表示，自己当时非常确定前方是没有车的。可不知道为什么，一直到车子开到跟前，那辆卡车就像突然出现一样。庆幸的是，胡歌福大命大躲过一劫。可其他人，在面对这种“意外开启鬼门关，猛gui索命”的情况时，恐怕就没那么幸运了。

90年代初，全国人民都沐浴在改ge春风下，全国经济的大跃进也就此开启。广州作为国内经济最为发达的城市之一，在那些年更是领先于其他城市开始投建各式各样的高楼大厦。位于西关的一片“贫民窟”，就被开发的谢老板相中了。

虽然这个地方在开放前，是个让人闻风丧胆的“扛瘟岗”。直到70年代，才逐渐成了居民住宅区。但在“寸土寸金”的开发商看来，甭管是什么地方，只要有钱赚，就是好地方！原本，建设新城区这种事情，对于开发商和原住民都是有好处的事情。

可惜，这个谢老板根本就不是什么好人。就因为他私自挪用了公款，导致后期无法填补上拆迁费的费用，这才让他心头生了恶念，并引发了后续的一系列灾难。谢老板不仅强拆居民的住所，甚至在遇到“钉子户”的情况下，他竟然还鬼迷心窍地想到“用火炙把住户逼走”的方式。喜欢看90年代香港电影的童鞋，不知道有没有看过沈殿霞跟董骏当年曾经拍过的一部电影，叫《富贵黄金屋》。电影里，肥姐和骏叔就饰演了一对“钉子户”夫妻。要知道，那时候的香港电影，有很多都是取材于现实的。

93年8月，一场震惊全城的大火造成24人死亡，100多人无家可归！这个谢老板估计也是情急之下没了脑子，闹得这么大，正逢严打贪wu腐bai的时期，他自然很容易就被当局盯上了。没多久，谢老板还被查出了存在“行hui”的问题（要不然他那种人，怎么可能能拿到那块地的开发权呢~），就此谢老板锒铛入狱。
