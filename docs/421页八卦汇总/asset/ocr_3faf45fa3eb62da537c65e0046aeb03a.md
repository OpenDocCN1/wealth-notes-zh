# 19、柳岩

明星在娱乐圈打拼，很多都会找金主找靠山。厉害点的就能找到资本大佬或者hong背後的金主，比如景甜、董璇。差点的找了圈内娱乐大亨、投资方、导演这些也能捞不少。比如前几天提到的果果。

那要是一开始啥玩意也没有，草根出身咋办？一个词：努力！今天扒爷故事的女主 人公，“柳岩”就是这样一个一路拼上来的女星。柳岩入行时，其实没有什么特殊才艺，最后也就靠着一张嘴进了娱乐圈。都进圈子了，过去的那些事儿都要说拜拜。有些人入行会把以前认识的人都删掉。柳岩是直接把已经谈婚论嫁，快要结婚的男友给踹了。

可柳岩进圈子发现，进来容易混好难，圈内竞争那么大，想混出点名堂，自己可不能坐以待毙。于是柳岩改年龄、改容貌，并且小心做事低调做人，对同事对身边的人都很好。情商高的柳岩在公司即使和“谢楠”争番位内斗时，也会被人夸一句没心机好善良。所以柳岩能在网友眼里没什么大污点，靠的就是EQ在线。

这么多年来，柳岩也通过自己的努力，走到了今天。表面的努力大家自然是看得到，私下里柳岩其实也没少参加饭局。有些大佬饭局上喜欢叫一些明星，所以即使那些一线也陪过酒，何况是柳岩呢？不过柳岩参加这些饭局，也没白去，可是有不少捞钱。饭局上，柳岩也认识了不少人，还成了一个大佬的小情人。但大佬身边不会只有一个女人。

柳岩就曾和女星“李小璐”因为一个金主而打了起来。李小璐算是童星，长大后靠一部电影天浴一飞冲天。可能因为成名路太顺，家庭又不错，李小璐在演戏上并不是很上心。反而是年轻的时候没少和有钱人一块玩。年轻气盛的她看见柳岩和她抢金主，气得她直接和柳岩正面刚。柳岩也不是吃素的，背后还有金主在，所以上去就对李小璐不客气。最后还是金主出面协调，两边都哄好了之后就全甩了，反正有大把的女人往上贴。

当然，柳岩抢金主也不是都那么顺利，后来她还曾想和电影公司的大佬来点关系，蹭个上位来点资源。却被也不咋要脸的未来正房，点名喊话diss了，导致柳岩只能中途败退。

人嘛，一路上怎么可能总是成功？放轻松。柳岩其实运气也不算差，在一次饭局上她又和一位大佬太太认识了。也不知道用了什么招哄得太太开心，反正太太和她很投缘，于是也给她拉了不少资源。

现在的柳岩算是上岸了，毕竟钱也不少挣。加上现在自己也是多栖发展的艺人，来钱的途径多起来，就没那么辛苦自己了。可她积攒的钱，还曾经被前男友骗走过几千万。所以别看柳岩会做人，但她找对象是真不行，老是被踹。这事没把柳岩气死，于是咽不下这口气的她可是没少在节目里提这件事。当然她不会提到钱的事，只说是遇见了渣男，被劈腿了。

想想网上总有新闻说柳岩这么大年龄了，怎么还没嫁出去。嗯，可能恋爱脑想找一个对她真心的男人也不容易吧。总的来说，柳岩情路不顺，但其实她很聪明，知道自己的定位，所以不要大牌很努力，这点确实不错，自然这些年也博了不少路人好感。
