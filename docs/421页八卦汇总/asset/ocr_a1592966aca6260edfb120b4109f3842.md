# 19、吴佩慈

最近“吴太太”，哦不，“纪太太”最近麻烦事不断啊。先是之前被爆出，纪晓波出轨林允的消息！是的，不是林允儿，而是林允！新闻写的不仅有鼻子有眼，直指纪晓波出席豪门宴会，身边带的不 是吴佩慈而是“正宫范儿”十足的林允！然鹅随着新闻还未发酵，吃瓜群众的瓜还没拿稳，就被几位当事人出面回应了。先是林允的经纪人发声，称林允和纪晓波压根就不认识。随后，吴佩慈也发博回应，一句“替纪先生转达，林允是谁”这才 是霸气满满的正宫范儿呢~原以为事件到此结束，吴佩慈也可以回去继续当她的豪门阔太了。

可谁知道，前天晚上，微博上突然有博主爆料，称纪晓波由于“x钱”已经被正式批捕了！随后更有着更加具体的报道，称纪晓波是卷入了L小民案件，经手金额高达千亿美元！可万万没想到，就在大家都等着看好戏的时候，吴佩慈又双叒出面回应了，称自己刚与纪先生一起吃过饭，并且表示要对不实报道采取法律维权的手段。

毕竟，扒爷只是个小小的媒体人，对于这种钞票高达好几千个亿的“金融纠纷”并不了解。而且纪先生也不是娱乐圈的人，以前有新闻爆出也多半都是吴佩慈来出面回应，所以想要了解到事件真实性还是比较难的。不过，早在这次爆出消息之前，坊间就传出过纪先生因为涉及“L小民C峰”的案子而受到牵连被捕的消息。

对比来看，这两次的“证婚”倒是很相似的，所以这次说不定也只不过就是某方势力借纪晓波炒作而已。虽说“金融”方面扒爷不能说，但要说提起纪晓波如今的“正宫”吴佩慈，那可就有的聊了。

原本很多人都不能理解吴佩慈为什么会“下嫁”纪晓波，宁可无名无份、被路人嘲笑，也要死死保住这条“大腿”不放。可现在当纪晓波的财务“冰山一角”被曝光就是“上千亿”，相信也让很多人能够理解吴佩慈的决心了。

对于吴佩慈，扒爷其实一直是比较“佩服”的。毕竟，能够把“老娘就是想嫁豪门”的心思，丝毫不带遮掩的写在脸上的，也就是她了。要说女明星嫁豪门这种事，从有了“娱乐圈”的那天就有。

以前随着民风保守，还有很多人因此而唾骂、鄙视；但反而是到了这些年，大家的思想意识越来越开放，而认为这种事也没什么可丢人的了，倒是少嫁的不到的女明星，会博取不少路人的怜惜了呢。比如扒爷前几天写的颖儿，就有多少童鞋看完她婚后的“AA制”生活时，替她抱不平。

估计一些“八卦爱好者四级水平”的课代表，应该已经意识到扒爷提颖儿的用意了。没错，颖儿可是跟吴小姐颇有渊源的。遥想当年，吴佩慈刚刚搭上纪晓波的时候，前脚才生下女儿的她，后脚就传出了纪晓波“绯闻众多”的消息。

14年，吴佩慈2月份才生下女儿，随后就传出了她被纪晓波抛弃的消息。先是一位网红美女，被传已被纪晓波包养，且传出了二人的私下同游照和聊天记录；不过对于这个素人网红，吴佩慈明显是没有太大回 事的。那时候就已经娴熟地担当起纪先生的“官方发言人”的她，相当云淡风轻地在微博上回应了这件事是不实报道。可紧接着到了5月份，吴佩慈显然就没有之前那么淡定了。某周刊报道称，颖儿已跟纪晓波秘密交往半年，甚至传出了颖儿欲扶走吴佩慈拿下纪晓波的消息。

大家也知道颖儿的性子，简直就是一言不合就开撕。之前怼大霖帮都不带怕的，对付吴小姐就更是无所畏惧了。本来坊间就已经有一堆“吴佩慈感情出问题”的消息了，颖儿还不嫌事儿大地把纪晓波的合影po到了网上。这一来真是立刻引起一片哗然，各种“插足”传闻也是坐实直上。

可要知道，吴小姐能够有如今的地位，当然不是吃素的了。一个“全家福”甩到颖儿脸上，一句“我的幸福刚刚好”更是让这场撕x大戏，瞬间迎来了第二个爆点！显然，这里的“一家三口”，diss颖儿是补药碧莲的小三的意思也是不要太明显的了~
