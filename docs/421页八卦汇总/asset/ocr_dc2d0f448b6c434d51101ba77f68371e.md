# 15、张馨予

前几天扒爷提到了燕燕童鞋（这个梗取自于人家的本名张燕，应该都能懂吧？）靠“疑似怀孕”的消息，频繁上热搜疑似炒作。

说来也是肥肠巧合呢！燕燕童鞋居然第二天就回应了这件事，还坚决表示自己绝对木有炒作。燕燕介么轻松就连续两天上热搜，让我们的“头条哥”汪半壁先生怎么想？？除了 一众网友（or水军？）一如既往地在评论里尬捧，更多网友的态度倒是更像咱们家这位留言的宝贝一样，秉承着不认识，不关注，不care的“三不”态度。

要是统计一个今年的“娱乐圈大事件风云榜”，燕燕童鞋是毫无疑问能上榜的。自从前 两年她被前男友和前男友的现女友各种打压以来，18年简直就成了她扬眉吐气的一年。不 仅“天助我也”地盼来了胖冰跌入谷底，自己更是如愿以偿嫁给了爱情“何捷”。

可话也说回来，燕燕的通稿倒是写的煽煽穷人，可真正愿意无视过去、送上祝福的， 怕是没多多少吧？就像在她宣布结婚的当天，连扒爷都考虑“得饶人处且饶人”不想在大喜之 日聊她的那些黑料了。可仍是有不少宝贝在后台留言，表示坚决不允许燕燕“利用军嫂身 份”洗白呢！

那么接下来，就让我们一起来了解一下：靠结婚洗白的女星辣么多，为什么大家偏偏 不能原谅燕燕呢？

# 燕燕的三大罪状之V 出道前的黑料数不清？

张馨予这个女星就是典型的把一手烂牌打好了的人，以后出身不好的人想混圈，她的 套路就值得参考。

张馨予年轻的时候，私生活混乱，黑历史简直不要太多。张馨予也知道混“夜间青春 饭”（你们懂得），靠的就是较好的身材和外貌。所以张馨予把卖身挣来的钱，不少都拿去 改造自己了，胸变得超级大，脸变得超级尖。更牛掰的是，张馨予与时俱进，会根据当下 的审美趋势来调整自己。所以张馨予那些年长得都不是一个美女风格。

本来张馨予干这行也挺赚钱，但是当明星岂不是更赚钱？于是被金主一包装，张馨予 就靠着小角色出道了。那小角色自然是没什么水花，于是张馨予再想一招，靠着有料的身 材和背后的炒作，她终于有了点话题。之后张馨予就开始出演冯小刚的大制作，原来张馨 予早就在高人搭桥下，服侍了冯小刚。所以冯小刚就给了她几个资源，让她四处露露脸。

说起这个冯小刚，也是真色，涉猎面确实广。在张馨予之前，他还刚被拍到和美女主 持人一块睡的事。那件事闹得挺大，这种负面新闻竟还有人上赶着瞒，某个号称“哥”的已 婚已育女星，当初就是主动揽身上，爆料说是自己，然后一夜蹿红。可见冯小刚虽然人不 咋地，但是只要搭上边就是个机会。可张馨予搭上了冯小刚这条线，觉得怎么红得这么慢！ 张馨予不知道，挖资源要慢慢来，人脉都是这么积累来的。

虽然燕燕资料里写的是07年通过一部《大旗英雄传》正式出道。可大多数网友（or 宅男？）知道她，应该都是从当年那套非常爆...炸的“足宝贝”写真开始的吧？

凭借艳丽的脸蛋和魔鬼的身材，年仅22岁的燕燕在一夜间爆红网络。尤其在她代言了 某款游戏、紧接着又拍摄了一套“铜雀台”的火辣写真后，这个横空出世的网红突然出现在 所有人的视线里，并成为了焦点。

现在大家都已经知道，不少网红如奶茶mm、干露露甚至是凤姐，能凭借某个言论或 行为走红于网络，都是离不开他们在背后的那些“网红推手”的。燕燕当年的蹿红，显然就 是一场有预谋的“上位计划”。她背后的神秘力量，不仅将那些不忍直视的写真大肆发行， 随后更是趁着热度把燕燕打造成了“苏州第一美女”、“网络第一美女”、“华人第一人气美 女”！
