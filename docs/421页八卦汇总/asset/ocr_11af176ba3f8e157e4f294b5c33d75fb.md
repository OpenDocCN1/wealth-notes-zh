# 17、陈柏霖

娱乐圈最大的迷雾就是人设！很多人会因为一个角色或者营造打造的人设而喜欢上某个明星。但殊不知很多明星有时演技不咋地，维护自己人设倒是很在行。所以至今行走江湖还没有被大面积爆出真相的明星，大多都是公司和明星双方“努力”的结果。
今天要讲到的这个男演员“陈柏霖”，就是一个比较成功的案例。陈柏霖的长相属于各花入个眼的类型：有人说他帅，有人说他不帅。但是他有演技，还能用成绩说话拿了不少的奖。所以早先他就是靠着一个港台剧里的备胎角色而大大走红的，在网络上还掀起一阵备胎讨论风潮，好多迷妹都因为这个角色而爱上他成为忠实粉丝呢～
