# 7、周慧敏

不知道前几天的热搜榜大家有木有了解，51岁的周慧敏开演唱会了，舞台照简直瞎了扒爷的眼~当天气扒爷的朋友圈，都被周慧敏的现场照和视频刷屏了！

今年是周慧敏出道30周年，为了纪念这个时间，她在世界各地展开了《2018一万天荒爱未老周慧敏30周年巡回演唱会》。看看这位如今年过半百的80年代香港玉女派初代掌门人！依旧人美歌甜演技在线，完全不是现在娱乐圈里的小花们能比的。19出道清纯可人，51依旧惊艳迷人。

扒爷记得周慧敏还今年《见证入行三十周年》红馆演唱会现场，晒了与老公倪震的甜蜜照片。很多小小妹贝们应该只听过周慧敏这个名字，但对不上人。今天扒爷为大家好好普及下这位当年墙画、贴纸上的大美女常客~

1985年，19岁的周慧敏因参加香港新秀歌唱大赛、港台业余DJ大赛而进入娱乐圈。两年后周慧敏加入TVB做劲歌金曲主持，并出演了首部电影《三人世界》被顺利提名香港电影金像奖最佳新人奖。同年，她推出首张个人同名EP唱片《周慧敏》即获得白金唱片销量成绩。

+   1989年，与刘德华、张敏合作喜剧片《精装追女仔之3狼之一族》~
1991年，与张学友、张曼玉合作喜剧片《富贵吉祥》！
1992年，与张国荣合作拍摄警匪片《蓝江传之反飞组风云》！

这里面的名字随便拎一个出来，都是那时的当红一线流量小生小花级别的。更别提张国荣九零年代在香港娱乐圈的地位，扒爷不多说资源有多好，小妹贝们懂得吧！

作为初代玉女掌门人的周慧敏，出道至今只有两段感情放众人面前。第一段，是1986年她刚出道时与香港Radlers乐队主音陈德彰的恋情。两人相恋5年后因双方事业高度差异，产生距离后男方提出分手。

第二段，是跟香港作家、电台节目主持人倪震的恋情。1989年，倪震刚与李嘉欣分手后立即改追周慧敏，两人性格相差甚大但却一见钟情了。一提到倪震这名字扒爷不由自主动的为女神心痛！不过还得捂着心口为小妹贝介绍下这个男（hun）的（dan）。

倪震出身于真正的书香门第家族，他的父亲是香港著名科幻小说家倪匡。倪匡与金庸、黄霑和蔡澜被称为“香港四大才子”，他的密友是武侠小说名家古龙。倪匡的经典作品有《六指琴魔》《卫斯理系列》等，他还曾在金庸出国期间代写过《天龙八部》。那个啥，阿紫的眼晴就是他写瞎的，有小妹贝想寄刀片的可以行动起来了，扒爷已经给你们指名点姓了。不过在各位“寻仇”之前，扒爷还是要极力推荐一下倪匡的科幻系列小说《卫斯理》，值得一看！

说完倪震爸爸，扒爷再来说下倪震的姑姑亦舒，她的名字艺文女青应该都很耳熟。在这里为小妹贝们简单介绍下这位的影响力……她是除琼瑶外对女性婚恋观影响最深的女作家之一，去年的电视剧《我的前半生》就是拍自她的小说。

从这样一个书香家庭出生的倪震，却是当年香港兰桂坊出名的浪子兼泡妞高手！1989年，倪震刚与李嘉欣分手后就立即改追周慧敏。周慧敏与倪震虽个性大不相同，但却在相遇后一见钟情，倪震成功夺得芳心。

1994年，两人恋情遭遇挫折，倪震移情陈法蓉。但两年后，倪震又和周慧敏复合，由于倪震不希望女友在娱乐圈工作，女方亦顺从男方的意愿，宣布隐退。于是周慧敏在完成自己拉斯维加斯的演唱会后，正式告别娱乐圈与倪震离开香港，移居加拿大过平静的生活。
