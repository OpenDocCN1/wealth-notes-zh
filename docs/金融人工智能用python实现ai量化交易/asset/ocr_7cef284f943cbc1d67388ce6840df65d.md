以下 Python 代码通过线性估计（逼近）输出值来计算最优参数值，同时在样本数据上绘制线性回归线，如图 1-3 所示。通过较高的 MSE 值可以看出，线性回归方法在逼近函数关系时效果不佳。

```
In [22]: beta = np.cov(x, y, ddof=0)[0, 1] / np.var(x) <mark>①</mark>
       beta <mark>①</mark>
Out[22]: 1.0541666666666667
```

```
In [23]: alpha = y_.mean() - beta * x.mean() <mark>②</mark>
       alpha <mark>②</mark>
Out[23]: 3.8625000000000003
```

```
In [24]: y_ = alpha + beta * x <mark>③</mark>
```

```
In [25]: MSE = ((y - y_) ** 2).mean() <mark>④</mark>
       MSE <mark>④</mark>
Out[25]: 10.721953125
```

```
In [26]: plt.figure(figsize=(10, 6))
       plt.plot(x, y, 'ro', label='sample data')
       plt.plot(x, y_, lw=3.0, label='linear regression')
       plt.legend();
```

+   ① 计算 $\beta$ 的最优解。

+   ② 计算 $\alpha$ 的最优解。

+   ③ 计算估计输出值。

+   ④ 根据估计输出值计算 MSE。
