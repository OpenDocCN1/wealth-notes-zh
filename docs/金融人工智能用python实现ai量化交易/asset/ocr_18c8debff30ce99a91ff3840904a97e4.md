# ## 7.4  智退

智退 是指神经网络在训练阶段不应该使用所有隐藏单元。人类经常忘记先前学到的信息，这使人 的大脑保持“思想开放”。理想情况下，神经网络的行为应该类似：DNN 中的连接 不应变得太强，以避免过拟 合训练数据。

从技术上讲，Keras 模型在隐藏层间有额外的层管理智退，主要参数是层的隐藏单元被丢 弃的速率。这些丢弃通常以随机方式发生，可以通过固定种子 参数来避免这种随机性。在 样本内性能下降的同时，样本外性能也略有下降。但是，两种性能指标之间的差异较小， 这通常是一种理想的情况。
