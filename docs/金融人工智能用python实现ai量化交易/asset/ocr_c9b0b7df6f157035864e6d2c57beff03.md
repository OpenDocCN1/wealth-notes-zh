当设定止损（SL）单、跟踪止损（TSL）单或止盈（TP）单的目标水平时，通常的做法是将这些水平与 ATR 关联起来。1下面的 Python 代码会以绝对和相对的方式计算金融工具的 ATR，交易机器人会在该金融工具上进行训练和回测（欧元/美元汇率）。该计算依赖于来自学习环境的数据，并使用 14 天（条）这种典型窗口长度。图 11-8 显示了计算值，这些值随时间显著变化。
