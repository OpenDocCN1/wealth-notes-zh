## A.3 浅层神经网络

上一节的神经网络仅由一个输入层和一个输出层组成，换句话说，输入层和输出层是直接连接的。而**浅层神经网络**在输入层和输出层之间有一个隐藏层，鉴于这种结构，需要两组权重来连接神经网络中的这 3 层。本节会分析用于估计和分类的浅层神经网络。
