# # 交互式神经网络

本附录基于简单的浅层神经网络，使用基本的 Python 代码来探索神经网络的基本概念，目标是在使用标准机器学习包和深度学习包时，能够很好地理解和感知经常被忽略的高级抽象 API 背后的重要概念。

本附录由以下几节组成。

+   - A.1 节涵盖了张量的基础知识以及对它们实施的运算。
- A.2 节讨论了简单神经网络，即只有输入层和输出层的神经网络。
- A.3 节侧重于浅层神经网络，即具有一个隐藏层的神经网络。
