现在考虑一组随机数，它们具有相同的一阶矩值和二阶矩值，但分布与图 4-16 完全不同。如图 4-17 所示，虽然矩是相同的，但是这个分布只包含 3 个离散值。

```

        split = int(0.25 * N) ❷
        numbers[split:3 * split] = -1 ❸
        numbers[3 * split:4 * split] = 0 ❹
```

```

        numbers /= numbers.std() ❻
```
