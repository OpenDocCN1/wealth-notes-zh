# ## 12.1 Oanda账户

本章中的代码依赖于 Python 包 `tpqoa`。此软件包可通过 pip 安装。

要使用此软件包，拥有 Oanda 的演示账户就足够了。打开账户后，会在账户页面生成一个 **访问令牌**（登录后）。然后，访问令牌和 **账户 id**（也可在账户页面找到）会被存储在配置文件文本中，如下所示。

```
```   
[oanda]
account_id = XYZ-ABC-...
access_token = ZYXCA..
account_type = practice
```
```

如果配置文件的名称是 `aif.cfg`，并且被存储在当前工作目录中，那么 `tpqoa` 包可以以如下方式使用。

```
```   
import tpqoa
api = tpqoa.tpqoa('aif.cfg')
