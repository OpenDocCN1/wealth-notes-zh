# ### 3. 无差异曲线

可视化的分析可以说明经济主体的最优决策。固定经济主体的效用水平后，可以在风险 – 收益空间中绘制**无差异曲线**。当无差异曲线与 CML 相切时，就可以找到最优投资组合。任何其他无差异曲线（没有接触 CML 或与 CML 相交两次）都不能确定是最佳投资组合。
