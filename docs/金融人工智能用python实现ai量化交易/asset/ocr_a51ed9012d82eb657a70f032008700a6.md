# 简化的回测

![](bbox=[0.13, 0.43, 0.23, 0.5])

本节中对交易机器人的训练和回测是在不现实的假设下进行的。基于 30 秒 间隔数据的交易策略可能会在短时间内导致大量交易。假设存在典型的交易 成本（买卖价差），那么这样的策略在经济上通常是不可行的。较长的间隔 数据或交易较少的策略更为现实。然而，为了在下一节中进行“快速”部署 演示，我们有意在相对较短的 30 秒间隔数据中执行训练和回测。
