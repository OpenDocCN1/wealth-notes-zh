# 第二章 11 個戰略技巧，縱橫戰場輕而易舉

嶙，膽怯而逃避戰鬥的嶙峋峰，反而生存率較高。避免魯莽輕率的戰爭、充分保存體力、維護身體健康，這樣的嶙峋峰得以生存，可以緊緊抓住和雌性接觸的機會，因而能夠留下更多後代。
在爭奪勢力範圍或異性的戰場上，樂於戰鬥而不謹慎的生物，容易因好戰而使身體困乏。經常在戰場上受傷，更容易受到其他不帶傷、或較年輕的個體挑戰。此外，像黑猩猩這類高等生物的群體，也和人類世界相同，若有單一個體被認為礎眼，便有可能遭受集體暴力而被殺害。
在被認為激進分子較多的歐美國家，過於好戰的人都難以有良好聲譽。儘管好萊塢電影中，總在各行各業中活躍的主角和對手、上司發生激烈衝突，但這些都是因為在現實生活中相當罕見，才會成為電影和連續劇的情節。過度以自我的中、為心、過於情緒化的人，在商場上都容易被貼上「不成熟」的標籤。
身在這場稱為「人生」的生存遊戲中，避免貿然戰爭的人能夠擁有較好的發展。如此生存之道，無論在動物世界或人類世界中，都恰好不謀而合。
