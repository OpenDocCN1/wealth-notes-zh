# 推薦序 懂得「轉化」，敵人就能成為貴人

想。當別人提到你的做法不對、想法有錯時，先別急著自我保護、不予理會或加以反擊，而是仔細審視對方的話語中是否有值得參考的意見。說不定他們真的點出你看不到的盲點，當我們加以吸收及採用後，就能獲得更大的成功。
正確地應對批評謾罵，可以彰顯我的宏觀大度，為個人品牌形象加分。因為我永遠都很有禮貌、很正向地回應某些人的批評謾罵和酸言酸語，於是真的有許多讀者私下來信，佩戴我一直能保持如此正向的態度。但他們不知道的是，這整個過程，其實也是我刻意「利用」來打造個人品牌與形象的方法。如果別人攻擊我，我就攻擊回去，別人酸言酸語過來，我也氣急敗壞地揪揪回去，那就只是兩人之間的戰爭；當我懂得善用這些攻擊話語，不只能提高自己的位階，提供宏觀的視野，並且能像作者、田村一樣，著書立言，發揮更大的影響力。這豈不是舉多得的超級「好康」嗎？
