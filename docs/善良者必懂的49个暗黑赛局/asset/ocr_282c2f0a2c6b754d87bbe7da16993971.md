# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

道箇中理由為何，但總覺得這真是難能可貴。在我擔任內閣府大臣政務官時，負責研擬經濟財政政策和地方分權，和當時擔任總務大臣的菅先生有了第一次接觸。當時內閣為了「對日銀行金融政策產生影響力」而召開研討會，菅先生全力支持我擔任研討會會長一職。在自民黨內，有太多人喜歡把部下的功勞吃乾抹淨，菅先生卻會將自己的成就就當做部下的成果，這在永田町⑩簡直不可可能！他的政治態度令我深深感動。菅老師這樣的態度，讓他從世襲制度的名門議員，到身經百戰的黨人派⑨，都擁有相當聲望，我認為他的態度是最關鍵的原困。正是如此，儘管他進入政壇的時間並不算早，但觀察當選次數，可以發現菅先生一直以異於常人的速度爬升。他明吃苦卻不卑躬屈膝，對任何人都維持一貫的態度，這便是箇中緣由了。

⑱永田町位於東京都千代田區南端，是日本國家政治的中樞地區，包含國會議員堂等許多政治機關，均座落於此。⑲自民黨在初成立時，即有「官僚派」和「黨人派」兩派的分割對立，前者為文官體系出身的政治人物，後者則是戰前即隸屬於政黨的政治人物。
