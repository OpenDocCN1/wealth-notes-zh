# 第四章 要點小「心機」，營造你無可取代的身價

# 理性表達意見的技巧

日本人並不善於「和他人議論卻不流於人身攻擊」，這是因為從學生教育開始，就沒養成這樣的習慣。最典型的例子，便是政治人物之間的討論。國會如此，在我參與錄影的政論節目中，也時常有這類「由談話轉為人身攻擊」的情況。即使我和前輩、同事展開具有建設性的談話，對方卻對我說：「喂！我這麽照顧你，你卻是這種態度？」「欸，你要是否敢對我有意見，以後我就不管你了！」如果不是全體社會習慣成熟的討論，很難達到這樣的目標。在美國的商學院或法學院討論中，人們認為「若不能說出和他人相對的意見，就沒有存在的意義」，因此從學生時代開始，無論對象是誰，大家都必須學習在不流於人身攻擊的前提下，任性隨意地和對方討論。我在美國紐約證券交易所的上市企業擔任戰略顧問時，每當和公司幹部討論，無論對方是社長或副社長，要是不表達反對意見，就有種「幫不上忙」的感覺。我想，這是因為從求學階段到進入職場，我都是這樣和人討論的緣故。
