# 善良者必懂的 49 個暗黑賽局

> 勢者，因利而制權也。

《孫子兵法・計篇》

不要自亂陣腳。當勝敗結果能夠預期時，就算你向對方陣營袒<|message|> 展現自己的用處和忠誠度也無妨。要是自己確認對方是勝利組，自己也決心投效了，就徹底地支持下去！就這樣，展現自己「即使戰敗也要奮鬥」的意圖，就能贏得對方信賴。無論身在商業界、政治圈或杏壇，一旦被捲入權力爭奪戰，你只能想辦法獲得勝。為了這個目的，你應該提升自己能力，將焦點放在「達成自己想做且該做的」工作之上。比起自己的思想、信念或好惡，請更愛惜力量；同時貫徹現實主義的思想，專注自己的工作成果，再加入能在權力鬥爭中勝出的陣營——這便是接近權力核心的最高指導原則。
