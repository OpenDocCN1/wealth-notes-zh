# 善良者必懂的 49 個暗黑賽局

# 問題自己：我能接受怎樣的人生？

互動變得不再有趣，浪費的時間成本也無法回收，因此我也不太使用了。網路世界中，存在著形形色色的人，雖然有不少值得學習的內容，但同時也有許多不滿於現狀的人，因此在分享資訊時，你應該要特別留意。

時間是世界上唯一公平的東西，但不同的運用方式，也將為人生帶來截然不同的變化。為了善用時間，你應該掌握「自己和自己相處」的時間。當你找別人商量，只會把結論帶往自己期待的方向。既然如此，比較有效率的做法，還不如捫心自問：「為什麼我會這樣想呢？」尤其，「掌握自己判斷事物的準則」更是重要。人生在世能夠感到幸福，只有一個關鍵│─自己打從內心領略與接納，而這份接納，就是來自我最重要的人生準則。則。正是如此，你必須認真地面對自己、誠實地與自己對話，確認：「究竟當什麼被滿足了，我才能接受自己的人生？」
