# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

是特別重要，多少學生被企業搶著錄取。但在這樣的時代背景下，我卻逆向操作，延遲就業，為取得MBA學位到慶應義塾大學念書。念MBA的確不輕鬆，但最令我感到衝擊的，就是那些被一流企業派遣來學習商業知識的一流社員。我在校內成績吊車尾，不過幸虧有親切而優秀的前輩提攜，總算順利畢業了。在MBA的第二年，我還以交換學生的身分，前往法國商管學院留學。當時我不過在學校念了一點商管，就覺得「我已經都懂了！」接下來我要來大賺一筆！」仗著自己是泡沫經濟時期的天之驕子，根本就是個沒有自我隨波逐流者。在我留學的法國商管學院裡，也有許許多來自各國知名商管學校的學生，當然大家討論了彼此對未來的展望。有許多學生認為「取得MBA學位後，最能賺錢、也是最有趣的工作就是。」投資銀行（Investment Banking），其中更棒的，就是從事『企業併購』了。『他們的實際成續也不錯，一個都進入了這樣的公司。回國後，雖然我遲了很久才開始找工作，但當時也完全不覺得辛苦，很順利就被知名企業錄取了。如同前面所述，我選擇進入在曰本堪稱「企業併購領頭羊」
