# 19
善良的人懂得放低身段，自然吸引貴人聚集

姿態擺得太高，沒有絲毫好處。這樣的人有如對人狂吠的小狗，是個試圖隱藏自己狹小氣度的大草包，他們幾乎難以邁向成功。人類是情感的動物，為了使自己舒坦，而讓對方不愉快，樹立敵人，也交不到朋友，這樣還能成功嗎？以謙遜之姿友善待人，不但不會建立敵對關係，還能增加自己的後援。當然，態度和傲 الأش的經營者、政治人物或運動選手大有人在，但如果他們能將身段放得再低一些，不知道還能創造出怎樣的成功。有些人以強勢的個性獲得成功，雖然不能一概而論，但就算狂妄自大地成功了，通常也難以長久。有了挫敗，很少人會真心提供援助；要足他們到了這時，還是難改變個性、又對人出言不遜，便會陷入惡性循環中。
