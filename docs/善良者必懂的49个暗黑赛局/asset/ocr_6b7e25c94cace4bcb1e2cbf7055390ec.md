# 第五章 牽繫對手之前，你要先學會包裝自己

在從政時，我就有過一段不幸的時光。選舉前，我做的所有事都以「受到選民愛戴」為最高指導原則。為了討人喜愛，而煞費苦心，包含言行舉止、服裝儀容到選區活動，無不絞盡腦汁、費盡思量。在那段日子裡，我竟然將「討別人歡心」放在自己的 人生之前，認為信念沒有那麼重要。就某種意義而言，政治人物也必須「靠人氣吃飯」，但業績、收入並不見得會因人氣而有改變。直到某天我才發現：對我來說，最需要人氣的時候，只有在幾年舉辦一次的選舉時，但在選舉時間之外，卻是應該專心做好政治人物的 工作。
人很敏感，當你透露出「好希望被你喜歡」的訊息時，人們便會心存警戒、抓 住你的弱點，並且不會那麼輕易地喜歡你；當你懷著「想被當權者或公司員工仰慕」的心情來待人接物時，便會讓人感受不到你的領導實力，他們也不會追隨你。
受「想讓人愛戴、期待被景仰」的意念煽動、左右，被他人看穿你阿諛奉承的心思時，反倒會讓你陷入既不受喜愛、也不被仰慕的窘境。與其這樣，還不如努力專注於眼前的事物，那才是比較好的生存法則。 Cab結果而論，這樣的生存之道，反而比較可能受人喜愛。比起一味在乎好感度的人，我對能夠全神貫注、努力不懈的
