# 前言
別為了爭一時的勝負，選擇和笨蛋戰到底

透過本書，我想傳達給讀者的訊息和「別浪費有限資源」的經營戰略十分類。似。無論時間、精力及時機點等，都是有限的資產，它們都是為了盡情讚頌僅有一
次的人生而存在。和未經世事、單純、率直，而可說是愚昧不堪的夥伴無謂交戰，使自己費心耗
神，都是無法產生積極成果的行為。我希望你們都別再耗費時間和精力的在這些事情
上，而要讓僅有一次的珍貴人生，變得更加耀眼光彩。
換言之，本書是一本「反戰之書」。我有自信這麽說：全世界知名的《孫子兵法》，便是—本超越兩千五百年、堪稱現代真實社會版的反戰之書。該書最有名的
一段話是：「百戰百勝，非善之善者也；不戰而屈人之兵，善之善者也。」一意思
