# 第一章 4種容易被「黑」的狀態，你得避免交鋒！

無論在政治圈或商業界，讓旁人覺得容易失敗的人，其實都有共通點，這也是我本身的情況。
首先，成功人士的共同特徵是「不會輕易迷失自我」；相對地，失敗的人則總有「看不清自己」的問題。而讓自己迷失的根源，正是「無謂的自尊」。爬上高處而自尊心強的人，都懷著驕傲的心態看待事物，因此才會看不見自己。
照理來說，「洞悉自我、期待自己達到更高境界」，應該是正確的目標設定。
