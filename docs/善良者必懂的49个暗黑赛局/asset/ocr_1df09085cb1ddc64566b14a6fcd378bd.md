# 善良者必懂的 49 個暗黑賽局

雙方決裂的程度過重，讓彼此關係就此走向終點。即使你們在雙方決裂後仍然持續溝通，但到底該讓步到什麼程度，對方才會跟著讓步？要看穿這一點，其實也有相當難度。要是最初你投出的是否是壞球，卻飛到一半的高  度就落下，因而被對方猜透心思，那麼關係也可能更惡化。不過，善用期望值管理的優勢在於：只要能夠順利優化彼此的關係，那麼比起從下對上的方式，有可能更快地改善彼此關係。期望值管理成功與否，並不能單單仰賴你的努力，也要對方期待彼此關係往好的方向進展，才能夠發揮效果。要是對方根本就沒有心改善，這個方式就無用武之地。要改善你和敵方的關係，關鍵是要認真地在對方身上多花點時間，因此「增加共處時光」，就是這個方法的基本質。即使處事笨拙、不足夠圓滑，重點在真誠地和對方擁有「面對面相處」的時間。時間不僅是珍貴的資產，更是改善彼此關係的良藥。無論面對任何事，唯有勤奮耕耘才是貨真價實的人生法則。
