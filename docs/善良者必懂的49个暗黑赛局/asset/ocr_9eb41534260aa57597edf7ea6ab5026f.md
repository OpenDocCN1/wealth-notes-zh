# 常保身心健康，是善用人生的第一要素

接下來，我要具體說明「為了發揮人生極大值，我是怎麼做的？」首先，善用 人生的第一要素：常保身心健康。只要能夠保持身心健康，就能讓時間和能量的運用，都達到最高效率。我總是注重運動、營養攝取和心靈充電，進行完備的整頓和安排。
年輕時，我曾為了擁有完美體態及增加肌肉量而大量訓練，但那樣的身體在死亡火化成灰後，並無法帶到另一個世界去。因此，我不再過度拘泥於身體這個工具，而開始重視身體條件，以發揮更卓越的效益。
我不再專注把肌肉鍛鍊得多大，而是注重維持肌力和肌肉量，同時重視伸展、延伸身體的可動領域，因此也變得不容易受傷。伸展肌肉不僅給我精神上的鍛鍊，也給我放鬆的機會，如此適度讓身體感到疲勞，就能獲得深層而高品質的睡眠。
