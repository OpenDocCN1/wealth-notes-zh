# 善良者必懂的 49 個暗黑賽局

用電話、電子郵件和電視。這麼一來，從那些資訊逃開，而去跑步、游泳的時間，便相當珍貴了。
此外，出差途中搭電車或飛機時也是，特別是海外出差的機上時間，更是奢侈而難得。雖然航空公司總會提供無線網路服務，但只要不常連上網路，便能擁有專屬於自己的時間。通常飛機座位的前方，都有電視螢幕供乘客看電影、玩遊戲，你也可以選擇不要打開，讓螢幕成為眼前的鏡子，映照著自己——只有你和鏡中的自己，已，看著鏡中的表情，便能確認自己許多了。
還有一個別不錯的選項，就是洗手間和浴室。如果不會因為待得太久，而造成家人困擾，那也是一個能和自己對話的好地方。狹小的空間，你能更加赤裸裸地面對自己。飛機座位上螢幕鏡面能夠發揮的效果，洗手間和浴室的鏡子也可以。看見自己的表情，心底真實的聲音便會隨之湧現。
