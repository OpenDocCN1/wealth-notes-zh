# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

> 軍爭之難者，以迂為直，以患為利。

《孫子兵法·軍爭篇》

紀錄，即使缺乏男性力量，但是能夠迅速拓展事業，便是展現實力的最佳證明。
在希拉·馬賽洛創業後不久，便有許多知名投資家、哈佛MBA等優秀人才紛至沓來，共同成就這項良心事業。儘管忙於事業，希拉·馬賽洛也和美國呼聲頗高的下屆總統候選人希拉蕊·羅登·柯林頓（Hillary Diane Rodham Clinton）密切接觸，為其進入政治界而積極助選。她的觸角延伸寬廣，卻也沒忘記自己的初衷。
觸，希拉。馬賽洛換了一個角度，將老人和嬰兒照護帶來的「苦難」視為「商機」，進一步將事業推廣到全世界，這樣的女性，實在值得我們好好學習。
