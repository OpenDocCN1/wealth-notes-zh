# 前言 別為了爭一時的勝負，選擇和筏蛋戰到底

界，這樣的事總是層出不窮。這是因為——筏蛋都會支持筏蛋。如此這般，在握有權力的『工作夥伴』中，其實筏蛋為數不少。也就是說：筏蛋是相當難纏的敵人。讓這樣的敵人增加，絕對無法紓解負面情緒，我不希望你將僅有一BBQ次的寶貴人生，浪擲在這種事情上。在日本社會裡，輿論往往無法冷靜地擴散，而總會落入人身攻擊的巢臼。那麽
失去的便是時間和精力，使事情無法有效進展。成功者不迎無謂之戰，他們主動選擇迎戰的時刻及對手。我們可以這麼說：正因他們深知與筏蛋交戰有多麽浪費時間，才能够順利得勝。
