# 危機或轉機？看你用什麼心態來面對

現在開始，世界將會發生許多前所未見的巨大變化，而這些變化，同時將會帶來許多「以下犯上」的契機。在缺乏變化的時代，人們的職位時常固定而少有變動，使得勝利組與失敗組的位置也難以動搖；這不僅無法給予挑戰者機會，容易導致不公平的局面，更難有「以下犯上」的可能。然而，從今而後，這些固定的位置，將有機會重新洗牌，從零開始。

事實上，在英國《經濟學人》雜誌所推出的《經濟學人權威預測：二〇五〇》趨勢巨流《（天下雜誌出版）中便提及：「自一九五六年至一九八一年間，平均每年都有二十四家企業擠進《財富》雜誌公布的『世界五百大企業』排行榜中，但一九八二年起至二〇〇六年間，平均每年卻增加到四十家之多。」

然而從另一方面看，轉機和危機的到訪或許是一體兩面。要把變動當做轉機或危機，端看你怎麼思考。依判斷方式不同，它可能是危機，也可能是轉機。在你稍微嚐到成功滋味時，這個世界同時也在發生巨大變化，你的位置即將被人奪走了，此時你的心念如何轉動，會影響接下來的選項。好不容易累積到現在才站穩的位置，將要被 人奪走，你認為這是危機或轉機呢？你能把它當做歸零的契機，以截然不同的視野，創造下一個全新位置嗎？既然變化總是接踵而至，無論你截至目前有多少成就，勸你還是別太守成。要是不懂得適應變化，老是死守自己的位置，那麼要不了多久，你便會陷入危機。當中。面對無法避免的變化，你不該抗拒，而是要借力使力；不該拘泥於現在的位置，而是要有「變化一刻也不停歇」的自覺。它會轉變成危機或轉機，就在你如何看待這樣的變化。最重要的，要比任何人都早察覺變化的徵兆。如果能在變化還是「點」時先察覺，就能在它成為兩點、連成一線時，率先抓住未來的趨勢。可是 在那個時候，也有許多人會察覺到那條線，因此你更該在變化還是一點時就可以掌握，成為最快行動的那個人。

微乎其微。在寶貴人生中，能夠有所獲得的我們，又是何等幸運。因此，希望你能有計畫地準備、有意識地運用人生——我如此衷心地盼望著。別將可貴的人生浪擲在無聊的對戰上。每當「加倍奉還」、「我會復仇的」等這類詞彙開始流行，儘管有點多管閒事，我都忍不住希望大家別和那樣的人打交道。那一些在日劇裡被稱為「顏藝」⑧的演員表情，雖是一種表演藝術，但在一般社會中，那樣過度反應的人多半成了大事。為了那樣瑣碎的小事，而讓心情反覆不定，反而會讓我們因累積壓力而生病。情緒反覆無常會令人感到厭倦，那樣的人缺乏意志力、毫無安全感，也難以使對方信服，全都是些沒好處的壞事。為了盡情讚頌人生，你需要淡然的生活態度。雖是雲淡風輕，卻也以不同角度來看待世界的本質。希望你能善用尖酸刻薄的想法，策略性地生存下去。大腦是你全身上下唯一「愈用愈靈光」的器官，其他器官都會因長久使用而疲軟老化，容易成為疾病的肇因。別做坦率、單純而正直的人，要尖酸、刻薄又辛辣！可千萬別想以牙還牙，當你被擱了一道，更要讓那個人心情愉悅，為了自己而將他擊倒｜這才是真正的加倍奉還。別為小戰而情緒反覆，你該在大戰中獲勝，以淡然並具有策略性的態度生存。若能讚頌自己的人生，也就是思考生命的最後一瞬，現在你所經歷的好事、壞事，全都只是人生的過程片段｜「得意淡然，失意泰然」方為上策。只有擁有「讚頌人生、發揮極大值」的生命觀點，你就一定能夠拋棄那無聊至極的自尊心。你應該思考「如何能有自主性地度過人生難關」。為了人生而參考他人評價雖然有其意義，但被那些評價和自尊心要得團團轉，可就本末倒置了。在找到想做的事情之前，先在眼前的事物上確實努力、展現成果。因為現在你在眼前的事物，很有可能蘊含自己下意識選擇的「夢想」。若能熱中於此，就能看見許多不同的可能；比起兀自煩惱、硬要拿出拚勁，倒不如完全投身其中。而最重要的是，你必須瞭解：人生原本就是荒謬而毫無道理。與其說是「毫無道理」，不如說是「這世界本來就不會如你所願」。從今而後，過去未曾發生過的變動，可能會急遽產生，變得更加令人匪夷所思。只是，要是一開始認為某事荒謬，你也別大動肝火。在荒謬中仍能展現成果的人，很有可能都是在我們看不見之處勤奮、淡然地持續努力，因而累積驚人的成績。讓情緒輕易受他人影響實在沒有絲毫好處，比起這些雞毛蒜皮的小事，難道你不該平穩情緒、處事淡然，盡可能不輕易動怒且不隨意和榮蛋交戰，同時盡情發揮生命價值，好像珍惜如同一寶物一般的人生嗎？這僅是我淺見，若能將這份心思傳達一丁點給你，便是我莫大的快樂。最後，沒有生命中許多貴人，就沒有這本書誕生，儘管書中仍有一些我自己都還無法實踐的事，我仍要向許多人致上誠摯謝意｜包含儘管造成他們很多困擾，依然包容我、守護且養育我成長的家人，以及本書中提及的貴人，還有雖沒能在書中提及、卻教導我許多人生命道理的朋友，真的非常感謝你們！
