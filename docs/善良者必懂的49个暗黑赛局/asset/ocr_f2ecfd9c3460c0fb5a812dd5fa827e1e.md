# 善良者必懂的 49 個暗黑賽局

對於「慢熟」的日本人而言，公司聚餐是最能縮短社交時間的絕佳場合，也是將棘手對象或討厭的人，化為夥伴的絕佳時機。日本人一旦黃湯下肚，基本上警戒心和錢包都會同時鬆綁，成為一個老實的「好好先生」。因此，公司聚餐就是一個「獲得不能說的秘密」、「達成各類協議」的最佳機會。曾經，我非常厭惡參與政治人物的應酬，但後來就算逼迫自己，也一定會參加。因為在參加後，才發現那是有著諸多機會的場合。參與應酬、善用機會，組織內部的夥伴便會隨之增加，也能夠接觸到蘊含組織內外人際關係的重要情報。即使是口風再緊的人，只要和他在一起的時間多了，他也會敞開心胸和你談話。雖然這會讓你常常熬夜，可能有損你的健康，卻能讓你獲得相當充份的情報和人脈，這便足以彌補這個壞處了。只是酒品差的人，有可能會讓場面變得糟糕無比。明顯是千載難逢的場合，卻狂發酒瘋、吵鬧不休，簡直是賠了夫人又折兵。不能駕馭酒精的人，我想還是別出席比較好。但在酒酣耳熱之際，些許失言並無傷大雅，當然，事後彌補也很重要。
