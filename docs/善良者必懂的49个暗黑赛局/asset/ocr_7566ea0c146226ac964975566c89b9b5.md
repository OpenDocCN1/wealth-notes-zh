# 前言 別為了爭一時的勝負，選擇和笨蛋戰到底

曾於二〇一三年風靡一時的流行語「加倍奉還」①、日籍棒球選手松坂大輔在進入職棒後說的「Revenge」（復仇、雪恥）都曾造成話題②，這些語彙深獲支持，都是受到日本獨有「復仇文化」根深蒂固的影響。話雖如此，我畢竟是個貨真價實的日本人，對於這樣的詞彙，還是很 HRESULT。

不過，我同時也認為喜歡這類詞彙的日本還真危險啊。氣惱、憤怒、甚至加倍奉還，都是無謂而消極的情緒反應。一味拘泥於已經結束的事情上，更有可能陷入惡性循環。

笨蛋們所不能容許他人擁有的「責任感」或「正義感」，就某程度而言的確立意良善，但還是太過天真了。

①《半澤直樹》是日本TBS電視台於二〇一三年播出的電視連續劇，主角為銀行員半澤直樹，劇中有所謂「倍增返還」。

②松坂大輔外號「平成怪物」，一九九九年加入職棒西武獅隊。在同年四月二十一日賽事中，他對上千葉羅德海洋隊的投手黑木知宏而飲恨敗北，賽後即對外宣稱「我會雪恥的」，四月二十七日便如言贏回勝利。當時這句話在日本社會造成十足話題，更獲選為該年度「新語與流行語大賞」之一。
