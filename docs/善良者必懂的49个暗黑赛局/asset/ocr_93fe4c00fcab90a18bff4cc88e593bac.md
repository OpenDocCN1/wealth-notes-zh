# 第五章 擒絡對手之前，你要先學會包裝自己

此自民黨的黨內氣氛並不容許異議，也就是黨員無法向黨主席和幹部提出意見或要 求；然而若獲得支持率高的政黨公開支持，也很有機會順利當選。果然不出所料， 在我加入自民黨後，一旦提出和黨內幹部頃上的發言，就會影響接下來選舉能否受 到支持，在黨內自由發言的權利，也就因此受到阻礙。 然而，我的做法也很大缺失。雖然當選後加入了自民黨，我卻一直為了修復 敵對關係而苦惱。如我前面提到的，再有分量的政治人物，只要在選舉時和他對戰 過一次，就能感受到他強大的恨意。我明白敗選了，勝選那一方卻仍慳恨難平。而 我向來抱持「過去的事就讓它過去」的平民論調，因此也很難接受他們這樣的態 度。我曾受到黨部指派，前往拜訪地方上頗有成就的自民黨員。但有些人不接 受邀約、不跟我見面，更有人說：「下次選舉別說助選，我絕對會扯你後腿！」當 時的自民黨比現在更有威望，地方勢力比黨部更大，因此有些人根本不聽黨部的
