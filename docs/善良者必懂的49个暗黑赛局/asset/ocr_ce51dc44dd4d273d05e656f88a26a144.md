# 迅速改善關係的方法

再舉一個更具技巧性的做法，那就是「期望值管理」。首先，預設自己可能會與對方決裂，在對自己有利的條件下，投出一個「壞球」。由於雙方是從敵對關係出發，因此最原本就難以達成共識；接著，在不激怒對方的前提下，和對方決裂，之後再由你讓步。

如果我在本文開頭介紹的「從小小的贊同開始累積」是「從下對上」的（bottom-up）關係改善，那這裡所說的，就比較接近「由上對下」（top-down）的做 점유법。

最初由你投出壞球，目的是降低對方「達成共識」的期望值。要是對方要求高得令你難以接受，你就改變期望值。接著，因為你的讓步，就能夠提高彼此改善關係的期望值。而後，再營造出一種「因為你已經讓步，對方也不得不讓步」的氛圍，要是在此達成共識，敵方便能成為你的了。
