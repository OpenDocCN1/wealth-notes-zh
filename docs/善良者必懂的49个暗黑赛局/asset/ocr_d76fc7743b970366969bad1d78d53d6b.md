# 第二章 11 個戰略技巧，縱橫戰場輕而易舉

⑨ 《死亡筆記本》是二〇〇三年十二月於《少年Jump》週刊開始連載的心理懸疑推理漫畫，其「死亡筆記本」來目死神路克手中，只要依其規則書寫，名字被寫進筆記本的人就會死去。

絕對不該公開批評他人，但原本什麼都不懂的我，直到那時才真正明白這個道理。要控制怒氣，可以利用「對人訴說」或「寫下來」等方式讓自己舒服一點。只是有個附加條件：千萬別讓你的發言或郵件，傳到對方那裡去。我也有看過別人怎麼做：「看見無論如何也饒恕不了的行爲，就把它寫在『死之筆記本』裡」——將那些不可原諒的行爲和髒話都寫進本子，等待日後的復仇。嗯，雖然我並不建議復仇，但寫下來等到氣頭過了也可以。只要記得一個大前提：絕對別讓任何人看見那些文字，更別化為數位資料，一定要確實地保管才行。總之，當你怒髮衝冠之時，就像是用液態氮迅速將憤怒冷凍起來一般保存妥當，再堆著滿臉笑容，把那些情緒帶往遠處，一口氣讓它爆發！之後，再用你暢快不已的腦袋思考，接下來該如何面對這一 Ezért不要寫出不可原諒的行爲，寫在「死之筆記本」裡等日後復仇，雖然我並不建議復仇，但寫出來等到氣頭過了也可以。只要記得一個大前提：絕對別讓任何人看見那些文字，更別化為數位資料，一定要確實地保管才行。總之，當你怒髮衝冠之時，就像是用液態氮迅速將憤怒冷凍起來一般保存妥當，再堆著滿臉笑容，把那些情緒帶往遠處，一口氣讓它爆發！之後，再用你暢快不已的腦袋思考，接下來該如何面對這一切吧！
