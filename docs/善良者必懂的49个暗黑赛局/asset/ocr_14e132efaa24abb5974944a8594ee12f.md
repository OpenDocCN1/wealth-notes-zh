# 第四章 要點小「心機」，營造你無可取代的身價

通、預測主管有疑慮的部分，再將自己的分析結果和答案傳達給他—讓想開會的人覺得「那就不必開會了」，就是最重要 ait的關鍵。現在身處理想的環境，「但只要自己的組織裡，有喜歡開會的人，就算給他資料，他還是想開會」—會這樣認為的人，應該還是存在吧？像國會一樣，認為「花時間開會原本就是工作本分」的人，他們都非要開會不可，可，那可真有如地獄一般痛苦。遇到這類情況，與其和對方喧而被討厭，不如找出讓他能接受的理由，暫時離開辦公室。「因為我得去確認上次那個合約的內容，所以這一每天必須出差，無法參與。」—如此拒絕參與沒有意義的會議。或許在你身邊也有認為「那個會議浪費人生」的同事、前輩或後輩，你可以和那些人相互討論，阻止會議召開，製造讓與會者認為「少了這麽多人，那會議就開不成」的局面，也不失為一個好方法。倘若如此還是必須開會，就只能轉變你的態度，讓那個場合變得有意義。在我擔任議員時，有時我會謊稱「這些是會議資料」，將想看的書籍縮小影印攜入，或是為了提升語文能力，將英文報紙的複印本夾帶入場。若能在大型會議中隱身在角
