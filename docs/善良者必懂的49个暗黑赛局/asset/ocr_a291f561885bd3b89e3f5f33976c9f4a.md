# 第五章 攏絡對手之前，你要先學會包裝自己

一旦灰心喪志，就立刻下定決心休息。若用身體的苦痛來比喻，這和身體骨折的嚴重性並沒有不一樣。一旦心靈發出「快給我休息」的訊號，每個人的反應都不同。有些人會持續堅持，但會想要求助本書的人，這時還是不要堅持比較好。當你下定決心休息了，就該把它當做「重新出發」的契機。肌肉訓練中有句話這樣說：「休息是種勇氣，也是種練習。」當你的心靈感覺疲憊，也是相同道理。身體進行鍛鍊時，若在疲累時依然繼續堅持，不但容易造成傷害，就算沒有受傷也無法提升體能。當你的心已經精疲力盡，要是繼續努力，或許有可能造成心理疾病。所謂重新出發，就該從「徹底忘掉工作和責任」開始。為了忘卻這些煩擾，你病。
