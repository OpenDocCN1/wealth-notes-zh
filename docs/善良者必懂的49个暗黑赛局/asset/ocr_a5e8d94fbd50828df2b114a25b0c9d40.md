# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

# 人愈聰明，愈無法理解他人心情

透過這些經驗，我能夠自信斷言：世界上聰明的人多得數不清。雖然聰明有其價值，但並非絕對的價值。真正的睿智與出類拔萃的人生最高價值，並非單純的思維能力，也不限於記憶力和發想力。想要成就大事，無論你是經營者、學者、政治人物、行政官員，都必須具備「看穿對手的能力」。擁有這項能力的人，就是最有智慧的人；只要擁有它，你的人生便將如虎添翼。

這個世界上，充滿許多少趣的點子與想法，重要的是如何將它們付諸實行，給予世人衝擊。然而，無論再怎麼聰明，一個人終究成就不了大事。沒有走入人群、認真地鼓勵他們、思考規畫、甚至加以實行，那些點子和想法也終究只會淪為空想。為了將它們付諸實現，我們需要的是「理解對方心情的能力」，這正是聰明人
