# 第五章 攏絡對手之前，你要先學會包裝自己

家的教育體系中，也有許許多讓孩子在眾人面前演說的機會。孩子就這樣，逐漸習慣表達自我主張。要在他人面前伶俐地傳達自己的想法，實在需要相當的訓練，即使心裡緊張，也不能忘記想說的話。 不但得有條不紊、正確無誤地傳達，更要帶有語言張力，讓人容易聽得明白。我們都需要這樣的訓練，而最好的方法，就是在短時間內利用「TED⑨」或「Youtube⑩」點聽大量的演講內容。請先試著做一段這樣的演說—首先，利用輕鬆的笑話舒緩自己和聽眾的緊張感、抓住他們的注意力，再做一個簡單明瞭的結論；接著，條理分明、風趣詼諧且充滿親和力地，將箇中理由與根據傳達給聽眾。
