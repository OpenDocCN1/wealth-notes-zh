# 善良者必懂的 49 個暗黑賽局

再加上，他人的目光通常都是建立在不充分的資訊上，這樣的判斷不僅偏頗，也轉瞬即逝。它可能會往往好的方向誤解，也可能正好相反，往壞的方面發展。一旦你失去了外界關注，包含過去曾有的評價、後援及友好關係，都將轉而淡薄。你會改變，對方也會改變，整個世界都在變。備受期待的政黨，可能因為沒有明確政策而名譽掃地；另一方面，被嗤棄許久的政黨明顯沒有改變，卻能等到支持度大增的時代來臨；擁有超高人氣的政治明星，也會突然窮途潰倒，這些故事我們都時有所聞。一味追求瞬息萬變的事物，並沒有多大意義。與其被那些事情左右，不如專注在自己的目標上。

現在你在意「別人怎麼看我」，要是從長遠人生來看，不過都是過眼雲煙，被那樣雞毛蒜皮的小事牽動情緒，只是浪費你的時間和精力，無疑更是葬送自己的人生。做你人生的主角，讓自己能隨心所欲地過活，不是很好嗎？
