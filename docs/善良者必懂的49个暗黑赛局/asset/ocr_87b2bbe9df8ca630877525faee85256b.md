# 第四章 要點小「心機」，營造你無可取代的身價

其實，若在午餐或早餐時間，也能獲得同樣的情報並建立人脈，就再好也不過了，但觀察現今的日本人，那還是太耗費時間了。正因如此，為了在組織中完成你想做的事情，就絕對要出席晚間的內部應酬。明明你胸懷大志，卻不參加能夠獲得情報和人脈的聚餐，這個決定實在不太高明。近年也有這樣的趨勢：許多員工雖然即將離職，仍會參加公司聚餐。難得有機會同在一個公司工作，不如善用共同工作時光的夥伴，吸取他們手中的人脈和資訊，運用在下個工作上。若要將累積許久的連結給切斷，除非有特殊緣由，否則我都不建議你就這樣輕易地離開。話說回來，雖然應酬的確重要，但可不是為了要喝酒。你應該以真正的目的為考量，積極而徹底地善用良機。要是每次都參加二次會、三次會⑥，時間成本就會不合算。不僅可能因為喝醉而忘了珍貴的情報，在酒席上也有發生糾紛的風險，因...
