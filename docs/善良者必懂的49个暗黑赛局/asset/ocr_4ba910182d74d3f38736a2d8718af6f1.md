# 終章 不要小看自己，你就能成為「賽局」裡最強的操盤人！

「你心中最重要 Ix 和價值，究竟是什麼？」「現在真的有盡全力在做嗎？」「沒在偷懶嗎？」「真的喜歡那個工作嗎？
諸如此類的問題，透過鏡中的神色表情，你將能瞭解自己的內心。無論如何逞強，在不認真過日子 的時候，是無法直視自己表情的。
還有，寫日記也可以。每天寫的日記裡或許有一些偽裝或逞能之言，但當你用過
去的日記回顧人生，就能發現字裡行間存在著真實自我。真正想做的事、不想做的事，
自己排定的優先順序和選擇傾向，都寫在日記裡。因此，透過階段性回顧，就能有愈加清晰的斬獲。
如此反覆進行，你心中多餘的逞強及虛榮部分，便會剝落消失。自己究竟是誰？想做什麼？在意這些什麼事？這些問題都會逐漸明朗，讓你順利找到解答。
