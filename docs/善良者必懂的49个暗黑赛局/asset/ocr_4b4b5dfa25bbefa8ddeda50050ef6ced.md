# 第四章 要點小「心機」，營造你無可取代的身價

遽產生變化，而發生和預測截然不同的情況。這在政治界經常發生，商業界自然也是不勝枚舉。
在這時，你應該先預測「哪一邊是勝利組、哪一邊是失敗組」，即使和勝利組攀上關係，也要確實觀察局勢變化。只是，即使你判斷出局勢會改變，也不該輕易見風轉舵。基本上，一旦涉及某陣營，就該徹底效忠、全力戰鬥；如果認為局勢已經改變，而輕率地改變立場，將會被對方看輕，你也將失去自己的夥伴。
隨時掌握情勢，做好應變準備
然而，你也應該充分掌握勝敗結果，做好完善準備——這是我在自民黨內多次參與權力鬥爭有的經驗。我的政治大前輩青木幹雄老師，總是能夠立即看出哪一
個陣營能夠獲勝，並且冷靜掌握局勢變化，不只準備了計畫A，同時也預想了計畫B和C。
