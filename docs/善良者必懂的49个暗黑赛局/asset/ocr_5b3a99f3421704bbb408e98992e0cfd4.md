# 善良者必懂的 49 個暗黑賽局

像我這樣在三十多歲時從民間轉入政界的毛頭小子，在那段面對前輩和同事良莠不齊的日子裡，偶爾會感到相當嫌惡。由於認為政治人物是很了不起的職業，當初自己更是立下雄心壯志才來到這裡，因此當時我時常為了「轉型為政治人物」而感到後悔不已。因為那樣的嫌惡感，我將自己寄託於酒精，放任身體健康每況愈下，喝醉了就四處對人口出惡言、予以洩憤，導致風評更加低落不堪。

看著前輩、同事那些荒謬不當的發言和行動，別說尊敬了，我對他們只有輕視，更甚者偶爾還想制裁他們。在執政黨會議或聚餐席間，曾經反駁或挑戰他們，也曾經讓周遭的人感到害怕。當然，如此和他人正面衝突，我完全沒有遇上任何好事或成長的機會。

如今冷靜地思考，攀附權力的他或許是放諸四海皆準，那些作為都是為了努力往上爬而做的重要準備。儘管自己無可奈何，卻依舊有必須「好壞兼容，優劣並蓄」的覺悟，才得以走到今天。與其指責那些前輩或同事，也許不如稱讚他們來得好一些（換言之，面對你認為是笨蛋的人，絕不能忘記他們其實可能比誰都聰明。當然也可能真的是笨蛋，這一點也應該注意）
