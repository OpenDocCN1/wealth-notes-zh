# 第四章 要點小「心機」，營造你無可取代的身價

有人說：不捲入權力鬥爭、能夠淡然處事的人最強，但我卻不這麼認為。雖然裝做「不沾鍋」也無妨，但我勸你最好別真的像隱士一樣遠離權力鬥爭。雖然也有些由不沾鍋組成的高風險企業，其成長速度穩固而強健，然而在人口逐漸減少，也代表著市場大餅縮水的日本，基本上，這些公司並無法急速成長。因【不沾鍋】雖輕鬆，卻什麼事都做不了此在風險企業中，這樣的公司並不多見。那麽，不就幾乎所有組織團體中，都必須上演權力鬥爭？要是組織的進步存在限制，內部鬥爭就會變得激烈，在互相爭奪縮水大餅的過程中，再沒有比爭權奪利更慘的了。
