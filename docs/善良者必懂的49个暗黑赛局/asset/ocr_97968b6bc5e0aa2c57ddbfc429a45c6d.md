# 善良者必懂的 49 個暗黑賽局

# 「男性的嫉妒」是頭號大敵

此外，我還學到一件事：「男性的嫉妒」實在是令人恐懼萬分的東西。在我進入政治圈前，若提到「嫉妒」，馬上會聯想到這是女性的專利。但在這難以用數字分出勝負的政治界裡，聚集了許多熱愛掌權的男性，他們其實才是嫉妒社會的真正代表。
曾有人對我說過：「在這個世界裡，最容易招致嫉妒的就是『年輕』。要是你年輕，就得靜待機會來臨。只要等待，就不容易遭受嫉妒了。你這麽年輕就進入政

全相同，和人打招呼時，更完全不說廢話、也不自吹自擂，可謂是真正的實力派；即使有人中傷，我也未曾見到他的臉色有一絲變化。我沒有聽青木老師談過任何關於政策細節或日本走向的問題，也許他並不喜歡透過完全不瞭解自己的毛頭小子，披露給媒體心中的想法。在時代的權力攻防戰分出高下時，或許國家未來才能更加清晰可見。
