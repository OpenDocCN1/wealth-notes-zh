# 善良者必懂的 49 個暗黑賽局

> 明君賢將，所以動而勝人，成功出於衆者，先知也。
《孫子兵法．用間篇》

且對方的思考模式浮現了，你要做的，就只剩下將那個思考模式拋入當下的局面，如此就能看穿對方：「為什麼會採取那個行動？」「接著在局勢改變之後，他的行為又將有什麼不同？」
還有，當你可以看穿這一切，接下來就是最大的目標——到底該怎麼做，才能引導對方按照你的想法行動呢？屆時，相信你就能勝掌握箇中玄機了。
我自己也是耗時許久，累積一個個的思考模式，才能和許許多人和諧相處。只要，是，人是不停改變的動物，你必須時時更新資訊，因應環境和交往對象的不同來改變。由於人性容易急遽變好或變壞，因此一定要持續判斷、更新情報才行。
