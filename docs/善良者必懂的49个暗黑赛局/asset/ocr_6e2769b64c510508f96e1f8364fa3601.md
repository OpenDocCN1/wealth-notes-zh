# 終章 不要小看自己，你就能成為「賽局」裡最強的操盤人！

間，不僅能用於工作、也能和家人及朋友相處，人生因此變得更加豐富而多彩。我限制自己每天使用電腦、智慧型手機和平板電腦的時間，盡可能透過紙本印刷物，而不從螢幕獲取情報和知識。數位資訊雖然迅速便捷，但光靠它並不能充分量化，甚至包含氣味和髒汙等複合式情報，也和文字同時進入感官，而更容易吸收。化為自己的養分。閱讀報紙、書籍等紙本時，我能夠感覺紙張的觸感、厚度、重需要專注精神的時候，我也不使用智慧型手機、電腦和平板電腦等電子產品。同時，我實踐早睡早起的生活型態。與其在負面情緒容易滋生的夜晚思考，不如早點睡覺，隔日以清爽舒暢的心情迎接早晨，更能擁有積極正面的精神狀態，來面對生活的一切。要是你瞭解人生僅只一次，更是時間有限、資源稀少，自然不需要藉助這些訓練，來讓自己更有力量；但是這些強化身體的方法的確能給予你最好的協助，讓你的寶貴人生發揮最完美的價值。⑩勝海舟是日本幕府末期的開明政治人物，擔任江戶幕府的海軍負責人。在遇坂本龍馬行刺時，勝海舟說服了他，使他成為自己的門生。
