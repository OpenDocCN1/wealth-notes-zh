# 第一章 4 種容易被「黑」的狀態，你得避免交鋒！

去、不停追加資金，導致更深的缺口，簡直是愚蠢至極的行為。你不應該 such 泥過去、損耗未來！我也曾經因時代劇中，「孩子為了雙親莫名被殺，一心想著復仇而活到今天」的故事情節，而大受感動。如此美談佳話，是所有人共同的回憶。但如果換個角度想，或許被殺的雙親並不希望孩子將寶貴人生浪費在復仇上。與其期待他們藉由不知是否能獲勝的決鬥，來消除恨意，父母其實更盼望孩子獲...得成功，不是嗎？負面的執念，將使自己變得更加負面。這不僅完全無法為你和身邊的人帶來快樂，更會因為滿懷憎恨、一心想著加倍奉還，而浪費大量時間和精力。即使報復成...功了，對方又反而將你一軍，結果可能造成更加倍的痛苦。生活中難免會發生小爭執，最重要是「不要在意」。就算你反擊對方，對方也只會恨你，造成再次的復仇，這可能macht 你喪失更多機會。
