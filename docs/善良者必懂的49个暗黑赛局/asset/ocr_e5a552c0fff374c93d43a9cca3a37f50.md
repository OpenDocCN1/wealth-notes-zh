# 第四章 要點小「心機」，營造你無可取代的身價

「人生本來就毫無道理可言」— 如果你認識這個事實，無論到什麼職場，壓力都將能夠大幅減輕。我認為壓力沉重的人，就是因為總對事情擁有過多的期待。人生，_EXTERNAL_原本就不是所有人都能夠獲得公平的對待，只要回顧人類歷史，就能明白這個道理。殖民統治、種族歧視、兇殘虐殺、燒殺掠奪，都曾經在人類歷史上真實上演。儘管人生原本就是這樣荒謬，但如今我們的環境相當好，幾乎沒有「莫名其妙就被殺掉」的事情發生。

現今社會雖然並非全然機會平等，但也不到嚴重地不公平。任何人都可批判當權者；自由地在社群網站上發表文章；並能夠自由地選擇自己的工作和居所。即使進了黑心企業，要是真的討厭也還是能離職。不僅職場上如此，說到底，
