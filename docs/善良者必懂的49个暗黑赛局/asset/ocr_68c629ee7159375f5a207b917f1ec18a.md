# 第四章 要點小「心機」，營造你無可取代的身價

團隊為主的組織，卻很可能在協調開始時，就產生權力鬥爭。將「協調」換個說法，那就是「政治」。協調互有差異的利害關係，就是政治在運作的事。因此，在選擇「協調型經營團隊」的過程中，便很有可能發生角力。在透過數字理解工作成效、決定員工去留的組織裡，人們忙著工作，政治角力、權力鬥爭等事情一點都不重要；但在不以數字，而以協調決定一切的組織，在協調過程中，便會發生許多權力鬥爭。由於基層員工太優秀，讓高層能夠安心而有閒暇專心地投入權力爭奪戰。儘管如此，一個組織之所以不致衰敗，其關鍵因素都是基層員工的優秀和勤奮，但這様認真的人依然會被捲入權力鬥爭中。如前文所述，我目 前在美國上市風險企業擔任戰略顧問，公司內部的人，並不玩爭權奪利的遊戲。最重要原因是：企業急速成長，所有人都非 常忙碌。專注在權力鬥爭上需要耗費大量時間和精力，但在風險公司裡，根本沒有那樣的時間。無
