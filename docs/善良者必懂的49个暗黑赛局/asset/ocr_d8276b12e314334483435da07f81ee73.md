# 捨棄自尊，訓練自己「不迷失自我」

人生僅有一次，如同奇蹟一般美好，你卻要忘情地虛度——這種「百害而無一利」的無用之事，正是來自莫名的自尊。要斷絕這樣的自尊，就應該冷靜地看清楚實的自己，不輕易偏離前進的方向，全心全意地專注在目標之上。

擁有「神之子」美稱的日本投手田中將大，在加入美國職棒隊伍「紐約洋基」後，於大聯盟的第一次出賽就奪下首勝，教練和職棒界都對他讚譽有加。比起他那傲人的投球數據和棒球才華，田中將大的成功祕訣在於——即使面臨危機或旁人奉承，都能保有「絕不輕易迷失自我」的人生智慧。

為了達成目標，無謂的自尊是最大敵人。你不該懷著這樣的心情看輕對手、與其交戰，真正應該挑戰的，是那個擁有無謂自尊的自己。
