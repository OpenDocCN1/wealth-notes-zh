# 第一章 4 種容易被「黑」的狀態，你得避免交鋒！

容易產生錯覺。搭飛機時，可以享受VIP頂級禮遇；搭新幹線時，能夠免費升級商務車廂；明明根本稱不上功成名就，走 到哪裡，卻都有人稱我為「議員大人」；前輩帶我去的餐廳，也都是從來沒去過的好地方。
還有，被邀請上電視和名人對談，在攝影機前和那些過去只在電視上看過的名人，說些無關緊要的廢話，自己便陷 入了「我也是名人」的錯覺；到了國外，便有駐外館處的人員前來迎接，提供 經過適當彙整的資料；從調整會面行程，到安排健康檢查，都有優秀的秘書協助辦理，我甚至再也不需要自己買票了。
從此以後，要自己完成過去能夠親力親為的事，都變得非常耗費時間。當初能夠成為國會議員，或許我的確努力過，但那不過是託陣營夥伴的福，我才能有此成。我就。只因為當選了，便備受禮遇，莫名的自尊心就這 樣油然而生，因而迷失了自 我。
「成為議員」不過是個中途關卡，距離目標還有 一大段。然而，許多議員卻因為旁人帶來的錯覺，而莫名其妙地感到驕傲，再也看不清自己。這般羞恥的事，我也曾經歷過。
