# 善良者必懂的 49 個暗黑賽局

繁重業務的朋友，在生命走到一半時，就必須迎接死亡，在那瞬間他究竟領悟到什麼？只要想起這件事，我就能感受他們的悔恨；曾幾何時，只要閉上眼睛，曾跟我熱切對談的身影，就會一一浮現在我眼前。這並不是別人的事。說不定到了哪一天，疾病或意外會發生在我或我重要的人身上。我根本還不想走到人生終點，為了不走向死亡甚至什麼都願意做；而為了讓自己有動機，確認人生的意義和重要目標，我總是預想自己終有一天會面臨死亡。在死亡的那一瞬間，自己會想些什麼？能夠帶走什麼？死後又會如何？只要思考這些事，就能明白最重要的是什麼了。預想自己的死亡，就特別能夠感受到在人生中，有哪些事物最需要珍惜。反倒是那些不明白人生有限的人，錯認了「反正時間還很多」，也根本就不懂得生命的可貴。
只要想想那些英年早逝的人，在生命終點的瞬間感受，我就覺得想做的事，現在就該去做。而為了做那些事，無論誰說了什麼話，都能想著：「那干我屁事？」。同時明白在漫漫人生中，那些無聊的心思和自尊，其實一點意義都沒有。
