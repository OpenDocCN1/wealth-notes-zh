# 善良者必懂的 49 個暗黑賽局

提升的機會。要從政時也一樣。就某種程度來說，我也希望能被比自己優秀的人才所環繞。當然，這是為了立志將日本帶往更好的未來。而待人接物的目的，絕不是「非此即彼」，而是「保有彈性空間」。我嘗試走進聚集了日本最頂尖人才的霞關和永田町，那裡有許多聰慧、人脈豐沛且有魅力的實力派，因而使我備受磨練，大有斬獲。也多虧了成為政治人物的經驗，我有幸能與商業、綜藝、運動及學術文化等各界一流人士交流，不僅獲得了啟發，也使自己大幅成長。
接著我參與選戰，而後勝選進入執政黨，也加入執政黨的最大派系，正是因為這些經歷，讓我擁有許多難能又可貴的經驗。由於自己的從政經驗，以及在執政黨、政府機關裡擔任要職等資歷深受好評，使我又有幸獲得耶魯大學、哈佛大學及蘭德研究所等研究員的工作，並在新加披大學擔任教授一職。
這些林林總總，都帶領我和世界上更多元的卓越人才接觸，相互切磋琢磨，進而拓展了更寬闊的世界。正是因為我以「難以進入的環境」為目標、努力不懈地持續挑戰，才能在現的自己，因此，我能夠充滿自信地告訴你：請多方嘗試，「投」
