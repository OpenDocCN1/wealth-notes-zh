# 善用權力，到達你最有利的位置

人類的優異之處在於「組織力」。歷史上許多紀錄都說明，人類雖然無法以個體力量對付猛獸或與自然災害抗衡，但都懂得利用團體的力量及智慧獲取勝利。擁有足以構成組織的智慧，再將智慧和力量凝聚在組織中——這是人類的強大之處，即使在現今社會也是如此。雖然社會上並不是沒有「即使不打著公司招牌，也能活躍」的人才，但多數人

事實上，過去是「天真率直政治人物」的我，也曾親眼目睹許多政治權力鬥爭下的蠢動，那些人拍馬屁、信口開河，我實在非常討厭他們，因而想要成為明哲保身的不沾鍋。然而，我卻因為這樣，完全無法工作，而開始參與權力鬥爭。結果，我確實感受到一個道理：為了實現真正想做的事情，還是有必須策動整個組織，因為手中要有權力，就什麼事都做不成了。即使有些天才光靠自己也能發揮才能，程度好得驚人，但大部分情況下，一個人的成就還是相當有限。
