# 終章 不要小看自己，你就能成為「賽局」裡最強的操盤人！

於目前的事情；而哭著要糖吃、什麼事都不願意盡力，無論對時間或精力，都是最大的浪費。
我說過許多次，從浩瀚宇宙來看，所謂「僅此一次的人生」，是彷如奇蹟一般的存在，因此你非得珍惜手中的時間和精力不可。
當你老想著「我本來沒有那個打算……」，或是持續尋找夢想，但一日回過神來，才發現人生的寶貴光陰已經虛度一空，這不是很可惜嗎？
與其擁有這樣的遺憾，不如認為「擁有人生即是一大幸福」，如此心存感激還來得更好。當我愈是和生物學家、宇宙物理學家會面探討，愈能重新認識這個世界｜大爆炸推動了太陽系的誕生，太陽系中又誕生了適合生物居住的地球，地球又孕育了生命，接著我們又能以人類之姿存活至今｜於是我徹底明白了，人類身處於宇宙之中，是件多麼寶貴的事。
沒有人一生都值得羨慕。我見過許多「成功人士」，其中不乏有錢也過得相當不幸的人，從出生以來便活在鎂光燈底下，無法擁有自己的人生；為了喜歡的事任性妄為地追求，最後家道中落而淒清孤寂等。
