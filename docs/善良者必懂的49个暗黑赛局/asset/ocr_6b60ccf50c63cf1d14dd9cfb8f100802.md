# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

成為政治人物後，我便和許多稱為「日本最高智庫」的霞關⑩夥伴一同工作。由於一直身在執政黨，因此有機會和中樞行政官員共同探討經濟和財政政策。他們製作的文書資料豐富完整，在政治上的造詣精深自不必多言，但我也窺見他們在藝術和文學領域中的驚人才華，實在太令人震撼了。在美國占有領導地位的頂尖智庫公司「蘭德研究所」（RAND）中，有二十九名諾貝爾得獎者，是日本全國獲獎人數的近兩倍之多；在和我同層樓工作的 人中，也有好幾位諾貝爾獎得主。我曾經單手拿著漢堡或可樂，在咖啡廳裡和他們暢談他們的研究成果，或將成果投入國家政策進行的工作，深深覺得這些人都是貨真價實的頂尖人才。

歷經經濟、財政工作的洗禮後，我以專責金融領域的政務官身分進入政府，以設立「日本版主權基金」⑨為目標，促成議員聯盟，也讓自民黨的國家戰略本部成

⑪「霞關」是日本東京都千代區的地名，許多日本中央部會與政府機關的辦公地點均分佈於此。⑫主權基金又稱「主權財富基金」（Sovereign wealth fund - 簡稱 SWF），是由一些主權國家政府所建立及擁有，用於長期投資的金融資產或基金，主要來源是國家財政盈餘、外匯儲備及出口盈餘。
