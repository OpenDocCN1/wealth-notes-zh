# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

時，自己已經在那「空白兩年」後的兩年內，賺到全公司排名第一的超級高佣金，
成績斐然。
我從宇都宮先生那裡學到太多，但其中的關鍵還是，「從上方向下看事情」的
重要性。並不是要以部下的角度看主管，而是要透過主管的視線看著自己」—現在
的自己，能幫助主管嗎？能受到信賴嗎？對方在期待什麼？自己又能給予回應嗎？
透過這個方法，我穩定地展現績效、受到公司肯定，收穫滿滿；而後在競爭中
踏穩腳步，持續交出漂亮的成績單。為了業績，我應該時時站在對方的立場、揣測
對方想法，這也是我從宇都宮先生那裡學來的技巧。我是這麼認為的：社會新鮮人
在就職第一年，就進入「數字就是一切」的組織，絕對有其意義。
