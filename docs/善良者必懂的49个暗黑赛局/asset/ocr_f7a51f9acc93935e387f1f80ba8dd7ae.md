# 第一章 4種容易被「黑」的狀態，你得避免交鋒！

案例，不從心裡層面觀察，這和「不喜歡也不討厭、對你強烈關心」的情況相 同。當你認為對方是笨蛋，就無法認同他的實力，也可能影響到你的未來，因此請 不要忽視他們。在本書中，我們就以擁有這些特徵的人作為設定。 面對這樣的笨蛋，或許你早就明顯讓他感受到自己的厭惡了。明白對方是在關 心你，潛意識裡也可能喜歡你，但因為你發出了這樣的訊息，他的愛轉為憎恨。更 甚者，已經開始和你交戰。 我身邊也有這種類型的人，無論是在企業裡工作或是身處政治圈。在多數情 況下，我總因為不夠成熟而忍不住與其交鋒。 所謂的政治圈，總有些荒謬不堪的事。一位政治人物優秀與否，並不能以數字 公平公正地加以衡量，處理黨內人事、運用發言權時，又總是以不清不楚的基準做 決定。 無論從旁觀察，或是聽見政治人物在閣員人事及電視上的發言，或許你經常會 有「怎麼連這種人也能從政啊……」的想法；而實際投身政黨或政治後，我倒是親 眼見過不少前輩和同事，恣意地擅用各種手段，藉以取得權力和地位。
