# 第五章 攏絡對手之前，你要先學會包裝自己

極為深刻。布朗妮將自己在安寧病房中所見所聞記錄下來，整理成《病人死前的五大遺憾》（Top five regrets of the dying）①一書出版，而其中第一項遺憾便是：「我希望我有勇氣過自己真正想要的生活，而不是別人希望我過的生活。」當我讀到這段文字時，深深感嘆「人生好難，無論到哪裡都一樣」。當我們認識為人生活點還很遠時，要我們思考「究竟為了什麼而活」其實很困難，因為我們總可以說：「那種事到時再想就好了！」然而在自己瀕臨死亡邊緣，在僅存生命裡悟出「人生本來就輕如鴻毛」這個道理，就會忍不住反覆思量：「我到底為什麼活到現在呢？我應該繼續活著嗎？」這樣的遺憾實在值得我們反思自省。別人不並不會如你所想地追隨你。無論藝人、運動選手或政治人物，在事業達到人生巔峰時，或許有人會一天到晚尾隨在後，但也並非如同跟蹤狂一般窮追不捨；更何況你又不靠人氣吃飯，別人並不會如你想像地那麼關注你。

⑦ 台灣譯名為《你遇見的，都是貴人》，時報出版。
