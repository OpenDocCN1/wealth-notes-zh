# 第四章 要點小「心機」，營造你無可取代的身價

一個缺乏人生或職場經驗的人，也沒有能力判斷「自己期待的人事調動」，將來能產生怎樣的意義；而透過人事下達的命令，意義也將隨著時間改變。要讓調職的壓力降到最小，首先就是要「控制期望值」。你不需要完全捨棄希望或期待，而是不要有過多盼望，並預設最壞情況，那麼大多少事情就能在最好和最壞間取得平衡；而當你被告知非預期的人事調動時，也就不會太驚訝。因此面對包含人事安排、待遇等問題時，最重要的就是要控制期望值。和控制期望值一樣重要的，是「無論走到什麼地方、擔任什麼職務，都要獲得和成長」，這能讓人事負責人看見你和他的協調感。當他認為「喔！這傢伙說不定值值得鍛鍊一番」，或許你就有機會調派到想去的單位；或是認為「不如給他一點苦頭嚐嚐吧」，讓你前往能夠成長的艱苦環境。

「我只去想去的單位，其他都不想要」、「反正我這種人什麼都不能如願」——要是你這樣鬧脾扭，或是表現出絕望的模樣，只會讓人事心想：「你這傢伙真難搞！」而不再給你任何成長的機會。在不符合期待的人事安排中發現樂趣、尋找機會成長，再等待下個能夠發揮長
