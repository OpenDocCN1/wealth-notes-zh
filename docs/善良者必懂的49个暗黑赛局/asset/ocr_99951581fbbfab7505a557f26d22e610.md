# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

從秘書轉為政治人物的人，通常對時間和做法非常講究，他們都是從「放低身段、幕後協助的角色」轉為政治人物，因此行事作風成熟、強悍而滴水不漏；針對政治圈的人際關係、官員評價，也都能詳細地提供建議，可說是相當可靠。若是從地方議員轉為中央議員的人，由於他們曾經控管地方議會，不僅在地情感深厚、值得託付，也十分在意資歷的等級。比起政策、數字這類細微的事，他們更重視人際關係。從公務官僚系統轉為議員的人，則是頭腦聰明、富有數字概念，對政策或官僚組織自然相當熟悉，行事風格也光明磊落，不過這些人的情意淡薄，不太喜歡提攜後進。至於世襲而來的議員，因為沒吃過什麼苦，所以相對而言，「好人」的比例較多。他們在政治圈的人際關係，可以從兩個世代之前就開始追溯，由於有父母長期給予指導，因此非常瞭解這個圈子。他們從雙親那裡學習政治歷史，承接了官僚體系和當權人士等相關資源，所以交遊廣闊、人面也廣。然而，這類政治人物的金錢量，並不如由秘書轉為議員的人強大。這可說是好事、也可能是阻礙。
