# 善良者必懂的 49 個暗黑賽局

一旦對方怒髮衝冠，就送上一朵花，讓他有好心情。柬蛋正因為是柬蛋，都喜歡被 人喜愛，也隱約瞭解這個事實。他們臉皮厚得不異現實，卻期盼被所有人喜 歡、被所有人認同。因此，當我們面對慣怒的人，不如就擺張笑臉、湊身過去拜託 他們；即使對方是個經常發火、卻握有權力的人，不如就先給他們遞上一朵花吧。 為了騙過他們，你假裝被對方攻擊或欺負了也無妨。不讓對方窺見你有一丁點 要反擊的魄力，而是使他看見你未戰而悔的模樣，讓他感受你「被擺了一道」、 「這下子贏不了」的心情，即使你知道不會有什麼好後果，也無所謂。 想要報復對方，最有建設性的做法，就是運用對方的力道，使其成為己方的優 勢。比起白廢力氣地對戰，而使對方成為勁敵，甚至威脅你的下一步，更好的做法 是：讓敵方成為你的夥伴而加以利用，將對方當做自己的最佳夥伴，不僅心情痛 快，未來也將一片光明。 只要奮不顧身地專注在想做的事情上，即使對方是個柬蛋，你也能夠向對方低 頭。在我從政時，曾經有過面對無法原諒的人，如果不向對方低頭便無法成事的經 驗頭。也曾發生過因為血氣方剛，多次和他人衝突或是面紅耳赤威嚇他人的經驗。可
