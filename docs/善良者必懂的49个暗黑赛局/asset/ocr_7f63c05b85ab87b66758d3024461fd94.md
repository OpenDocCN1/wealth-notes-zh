# 終章 不要小看自己，你就能成為「巔局」裡最強的操盤人！

> 《孫子兵法・計篇》
夫未戰而廟算勝者，得算多也；未戰而廟算不勝者，得算少也。多算勝，少算不勝，而況於無算乎？

錢也好、地位也罷，追求權力有何妨？這些不僅對社會有貢獻，也能追求世界
的真實面貌。儘管本書並不是那麼推崇，但如果你將正義擺在最優先，其實也沒什
麼不好。這樣和自己對話，你就能確認自己的人生準則了。
最容易瞭解，但也最難參透的，就是自己。人生最重要之事，就是瞭解自己、
有意識地控制自己的意念。要是不能瞭解，你將無法獲得幸福。無論算命師擁有多少
特殊的V能力，與其讓他在短時間內為你解釋，不如由朝夕相處的自己，來幫你剖析
人生。這樣一來，不僅容易、正確，也會更有意義。
