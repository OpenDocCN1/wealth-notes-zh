# 結語 別執著於小戰，你該在大戰中獲勝

微乎其微。在寶貴人生中，能夠有所獲得的我們，又是何等幸運。因此，希望你能有計畫地準備、有意識地運用人生——我如此衷心地盼望著。別將可貴的人生浪擲在無聊的對戰上。每當「加倍奉還」、「我會復仇的」等這類詞彙開始流行，儘管有點多管閒事，我都忍不住希望大家別和那樣的人打交道。那一些在日劇裡被稱為「顏藝」⑧的演員表情，雖是一種表演藝術，但在一般社會中，那樣過度反應的人多半成了大事。為了那樣瑣碎的小事，而讓心情反覆不定，反而會讓我們因累積壓力而生病。情緒反覆無常會令人感到厭倦，那樣的人缺乏意志力、毫無安全感，也難以使對方信服，全都是些沒好處的壞事。為了盡情讚頌人生，你需要淡然的生活態度。雖是雲淡風輕，卻也以不同角度來看待世界的本質。希望你能善用尖酸刻薄的想法，策略性地生存下去。大腦是你全身上下唯一「愈用愈靈光」的器官，其他器官都會因長久使用而疲

35 意指以搞笑臉部表情逗人發笑的一種表演技巧。
