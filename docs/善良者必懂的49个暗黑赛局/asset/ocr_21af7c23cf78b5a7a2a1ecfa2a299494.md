# 善良者必懂的 49 個暗黑賽局

由自主地多管閒事了。有 些人感性處事，也有 些人懷著意圖待人。就是有人喜歡纏著我們、要我們做 出回應，在社群網站上追求受人矚目的快感，針對我們的言行舉止，極盡挑剔之能 事，認為這樣就是取得了勝利。 曾經，我為了那些人過於不講理、惹人厭的無禮言論和令人髮指的行為而大為 光火，和他們攪和成一團。但卻是大錯特錯！從中獲取的經驗，讓我有了決定： 應該徹底將那些人列為拒絕往來戶，或是從那些不懷好意的人身邊逃開。 和這類人交手，你幾乎得不到好處。要是你做出回應，那樣的態度也在網路上 被披露，無論你的反駁多麼合乎邏輯，也會給人幼稚無聊的印象；就算是顯露一 點點情緒，也是你氣量狹小的表現。 對方因為引出你的情緒而自鳴得意，要是想抓住你的小辮子，就會用許多方式 讓你失去理智，也更堅持他的謬論，使情勢演變得幼稚不堪。因此，即使你耗費時 間和對方糾纏，也不會有任何好處，只是喪失時間和聲望罷了。 曾經，有個如名部落客特別喜歡挑釁我，我也把他當一回事，讓朋友十分擔心
