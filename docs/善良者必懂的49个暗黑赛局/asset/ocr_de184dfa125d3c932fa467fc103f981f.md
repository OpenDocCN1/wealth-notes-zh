# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

他那些符合事實的理論分析。日本若再堅持所謂「唯日至上的純血主義」，不僅人口會減少、結構老化，整個國家也將變得貧窮萎縮。日本身處中國及朝鮮半島的周圍，持續不斷地貧窮萎縮，暗藏過高的風險。這種情況，我們也-lang 從無法持續扮演「世界警察」的美國身 上窺知二二。
即使年過九十，李前總理依然不斷提出建言、構築未來藍圖，這在世界領袖
界，早已是後繼無人。因為我實在太驚訝了，曾經問過他：「為什麼您總是那麼尖銳呢？」那時他露出活力充沛的笑容，告訴我：「耿直地依循他人所言、不經深思熟慮就輕信他人，都沒用大腦思考當然很輕鬆。不過，用刻薄的角度看事情對大腦很好，因為大腦可是你身上唯一『愈用愈靈光』的器官。」
自此以後，從媒體報道到專業人士意見，我都不時時抱以「那是真的嗎？」的懷疑。
在本書中，我的意見或許比一般人來得尖酸刻薄，其中也蘊含李前總理告訴我「常以刻薄角度看事，和活化大腦息息相關」的道理。
