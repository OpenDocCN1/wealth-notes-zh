# 第四章 要點小「心機」，營造你無可取代的身價

明明我的業績比較好，但升官的卻是他、獎金拿得多的也是他。拿自己跟某個
人比，就覺得「為什麼他比較受寵？」「明明我比較優秀！」心 Wales 了怒火—想必你也有這種經驗吧？實上，你不該憎恨人際關係處理得好的人，而應該將他們視為學習對象。在政治界中，我見過許多人際關係相當融洽的政治人物，所以特別有感覺。我自己在剛上任國會議員時，是個天真的小鬼頭，看見那些八面玲瓏、有時還向權力靠攏的人，常常打從心裡瞧不起他們。

向權貴靠攏，有錯嗎？
