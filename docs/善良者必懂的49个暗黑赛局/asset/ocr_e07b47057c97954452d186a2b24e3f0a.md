# 善良者必懂的 49 個暗黑賽局

> 《孫子兵法·謀攻篇》
知彼知己，百戰不殆；不知彼而知己，一勝一負；不知己，不知彼，每戰必殆。

藉由這樣的做法，雙方便能避免對彼此過度解讀。一旦落入過度解讀的迴圈，即使對方的舉動無心並毫無惡意，也很容易被過度理解成「惡意的行為」。那麼惡化的關係會變得更惡劣，最後便可能發生衝突。當和討厭的人關係愈加險惡，你雖然不用勉強自己和對方親密對談，也應該和對方溝通、避免關係繼續惡化。最差的情況，至少就先見個面吧。即便不必勉強自己說這些什麼，你也該讓對方看著自己並無敵意的神情和姿態。我瞭解你「連他臉都
不想看到」的心情，但是連臉都不贊上一眼，就深陷過度解讀的開端了。
