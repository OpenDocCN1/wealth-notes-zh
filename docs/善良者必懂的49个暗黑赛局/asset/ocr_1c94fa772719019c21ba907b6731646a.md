# 第四章 要點小「心機」，營造你無可取代的身價

主管為了排解"壓力，經常和人起爭執，因此被部下碎嘴、交換怨言，那麽就更容易累積不滿的情緒了。因為一個人要是底下有十個人，就會有十雙眼睛盯著自己。
但是，如果你親自當一次「擁有部下的主管」，同時面對好幾個下屬，你就能體會要一視同仁有多少困難。一旦成為主管，就要用一雙眼睛看管十個人，根本難以細微地逐一觀察。
「擁有部下」也意味著「掌握整個部門的命運，同時包含你的部下」。在大部份情況下，主管和部下都得同甘共苦、一同扛起業績數字；比起部下對自己的批評，重要的是主管能否在所屬部門交出漂亮的成績單，而他們又必須用「部下」來協助自己，進一歩呈現工作績效。因此，包含收集資訊、調整工作、和高層溝通協調等，全都是主管不可或缺的能力，更不能忽視那些一般根本勾不著邊的地位崇高之人。
就像這樣，擔任部下時對主管抱怨連連的人，一旦成了主管，就能瞭解箇中艱辛了。因為，當自己覺得不滿，你在批評前，就該試著站上主管的立場思考—這非常重要。
