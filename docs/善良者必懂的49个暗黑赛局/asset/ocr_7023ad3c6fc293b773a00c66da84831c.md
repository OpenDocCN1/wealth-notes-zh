# 第二章 11 個戰略技巧，縱橫戰場輕而易舉

# 06
所謂的「報仇」，
是把對手的力道變成自己的

我所見過的成功者，都擅長合氣道而非空手道。他們從不和對手正面交鋒，而
是懂得借力使力，藉以破壞對手的平衡，創造有利於己方的情勢。如此一來，便能
在雙方都不受傷的情況下，一較長短。

調整呼吸，不正面迎戰對手，因此不需要將自己鍛鍊成肌肉發達的模樣。他們
知道最重要 的秘訣：無論對方再強大，若能擊中其弱點，就能輕鬆掌握局面。

世界上任何一種防身術，在面對體力凌駕於自己的對手時，便是「利用對手的
力量」，才能保護自己全身而退。不和對方正面衝突，而是對方用力之處使力，
藉由對方的力量破壞其平衡；在現實社會中，若想要加倍奉還，我們都應該瞭解
「以合氣道決一勝負」的真義。
