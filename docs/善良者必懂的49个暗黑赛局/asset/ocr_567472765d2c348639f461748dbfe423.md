# 第一章 4種容易被「黑」的狀態，你得避免交鋒！

老天爺看著這一切；超人或鋼鐵人會從某個地方飛奔前來搭救；我是個大英雄；水戶黃門會帶著風車彌七來幫助我⑤；大岡裁會幫我鏟奸除惡⑥。
在學生時代，有這樣的想法或許還能被諒解，但出了社會，我想你還是重新思考一下會比較好。因為無論走到哪裡，總覺得「會有人英雄像超人一樣出現」、或
是「正義會為自己挺身而出」等這樣的事，似乎不太常見。
據說、在美國，只要擁有雇得起優秀律師的財力，就算滔天大罪也能獲得有利的判決。換言之，「正義」在某種程度上，可以說是金錢買得到的東西。若你到印度、印尼或俄羅斯等國家，至今也還看得見某些能利用職務之便而註銷交通違規罰單、協助取得簽證等情事的官僚，好像是要求小費一般地索求賄賂。
