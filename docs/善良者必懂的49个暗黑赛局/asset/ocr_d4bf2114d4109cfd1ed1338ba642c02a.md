# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

著支持者不放。每當這位總是打勝仗的前輩吶喊：「請幫助我！」「只差一步了！」支持者就會變得比前輩本人還要認真，連我這個助選員都感受得到。即使在壓倒性勝利的報導中，也要給支持者灌輸危機感，這樣的演技實在逼真得入木三分。
前輩本人也對我說：「不要說出會讓競選團隊鬆懈的話」、「來幫我製造一些危機感」，而看過選戰民調數據的我，為了製造危機感，也實在耗費了不少苦心。
和他相比，我打的選戰還真是幼稚。一旦優勢報導出來，就喜出望外，還對競選團隊宣示「這下贏定了」這種話，團隊成員也因此鬆懈，結果後來老是擔心被其他選手追上，戰戰兢兢、如履薄冰。
若候選人強勢地表態：「我差不多勝選啦！」那麼支持者一定會覺得：「那我不幫忙也行囉。」「那麽有自信啊，這個人還真是不可愛耶。」
我從這件事學到一個道理：我們必須收斂傲慢之心，正因為有自信、又刻意

⑩ 「不在籍投票」是日本文事前投票制度的規則之一，若選民無法在投票日當天前往投票所投票，可提前在投票日前完成投票。
