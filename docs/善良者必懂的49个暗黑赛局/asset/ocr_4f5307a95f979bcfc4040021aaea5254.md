# 第二章 11 個單骰技巧，縱橫戰場輕而易舉

想而知，那麽做的結果，簡直糟糕極了！不僅自己想要推動的政策因而腰斬，職位也失去了。我所獲得的，僅僅是那一瞬間的快感罷了。若以長遠眼光來看，那都是些無所謂、馬上就會消失的感覺。接下來，只剩下空虛和懊惱。如今回頭看，我想自己欠缺了「無論如何都要做」的堅定意念。就這樣，我吃足了苦頭、也反省過，變得能夠心平氣並向人低頭了。要是自己想做的事情認真且明確，那麼無論如何都能向人低頭。完全完全、心平氣和地低頭。而對方那個柒蛋，那個狂妄自大、對自己散發著一股討厭氣息的人，就會因為別人向他低頭而沾沾自喜。他洋洋得意著，因此變得傲慢忘形。那就這樣吧。柒蛋也是人，如此他便露出破綻、進一步被情感牽絆了。然在低頭時，若你不是發自內心、真心誠意地做，你會顯得充滿防備，而無法達成任何效果。反正都要低頭了，就認真地做、徹底地做！然後在柒蛋絕對不會發現的時候，偷偷吐個舌頭、罵一聲「你這混蛋！」來紓解壓力。你得記得一件事：背後說人壞話並不可取，那些話背定會被傳出去；寫在社群網站或部落格上也絕對禁止，那些都一定會讓你事跡敗露。
