# 終章 不要小看自己，你就能成為「箐局」裡最強的操作盤人！

氣溫或重力等因素，都適合生物生存的環境；即使生物能夠奇蹟生存，更要耗費數十億年光陰，才能讓「擁有人生意識的人類」，費盡千辛萬苦生存至今，這更是如
同奇蹟般不可思議。
而我們，就存在這彷如奇蹟的命運機緣中。拜醫療等科學技術發達所賜，從今而後人類將變得更長壽，但無論如何都有走到生命盡頭的那一天。（我一向尊崇的未來學家）雷蒙德·庫茨魏爾曾說：「人類可能永生不死」，但誰知道呢？
我有這些朋友和認識的人，明白還很年輕，卻因疾病或意外而喪失了性命，果然人生根本毫無道理可言。他們明明那麼認真、勤快地為他人活著，卻比我們早一步離開了。「為什麼那樣真誠老實的人先走了，老是不講理的自私老頭卻還活蹦亂跳？」想來就讓人感到悲痛不已。
那個懷抱著「要成為日本和世界橋樑」的崇高目標，即使病魔纏身仍不倖處理

⑩ 稀少性（Scarcity）又稱稀缺性，是指慾望總是超過能夠滿足慾望的資源，亦即「資源有限，但慾望無窮」。
⑪ 雷蒙德·庫茨魏爾（Ray Kurzweil）是美國作家、發明家和未來學家，現任Google工程總監。
