# 善良者必懂的 49 個暗黑賽局

> 軍無輜重則亡，無糧食則亡，無委積則亡。
《孫子兵法．軍爭篇》

論基層或高層，有太多人因為沒有產值而離開公司，不僅高層主管忙於工作，無能也將導致企業凋零，因此他們根本沒時間，用爭權奪利來決定人員去留。
在全球化和科技革新急速發展的現代社會，日本大企業也身處嚴峻的競爭，雖然不會發生權力鬥爭，但而今有餘力這麽做的組織，也不在少數。
然而，我並不是要完全否定「權力」這個東西。當我們面對某些情況，仍然需要權力的加持，你並不需要刻意勉強自己違逆或疏遠它，但是是完全依賴權力而受其左右，風險及代價就太高了。你必須鍛鍊，讓自己進化到「即使沒有權力也能做事」的境界。當你能夠完成別人做不到的工作時，權力反而會朝你靠攏。
