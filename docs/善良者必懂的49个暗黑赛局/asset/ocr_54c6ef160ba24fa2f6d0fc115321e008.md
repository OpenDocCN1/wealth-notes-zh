# 01
惹事生非！
有挑釁的坑就跳，不斷和築蛋交手

本書假設的「築蛋」，是怎樣的人呢？一言以蔽之，就是完全不值得你去交戰或為了他煩惱，及不講道理的人。對你而言，在見到他們的第一面就礙眼又麻煩。偶爾也有投機取巧的人，連個正當理由都沒有，就猛扯你後腿。他們想要和你接觸、攀上關係，藉以抬高身價。那些對你糾纏不清的築蛋，最大特徵便是「吃飽撑著」。除了太閒之外，還有一個你務必要掌握的特徵，就是「對你特別關心」。他們淨做些煩人的事、說些討厭的話，其實是對你有興趣，希望你能理理他們。換句話說，就是想要你回頭瞧一眼，他們才會淨說這些毫無道理的話。或許他們表面上並沒有察覺，但在心裡是喜歡你的。當然也有實際上是討厭的
