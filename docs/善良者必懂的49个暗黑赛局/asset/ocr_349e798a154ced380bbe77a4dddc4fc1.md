# 終章 不要小看自己，你就能成為「賽局」裡最強的操盤人！

你的 人生由你開創，無論他人怎麼想（當然受到他人好評還是比較好），結果 都不是那麼重要。每個人到生命盡頭時，都得自己一個人走；你能帶走的只有自己 的成 就感，不是嗎？如果要給人生一個粗略的意義，那就是「能否使自己滿足」。 然而在現代社會，特別是「非常在意別人目光」的社會中，我們總是過著受他人評價左右的人生。人類是容易受周遭環境影響的生物，因此創造一個「身邊圍繞 優秀人才」的環境固然重要，但你不能以此為滿足，「能否讓自己滿足」這種專屬 於你的人生基準才重要。正因如此，你才必須面對自己，並和自己相處。 而和自己對話時，你也需要使用「靈魂出竅」的方式。你必須暫時將自己從 當下抽離、客觀地看自己，才能和真正的自己產生對話，因此掌握獨處的時間很 重要。老是在人群中打轉，便無法面對自己；連獨處時光也看電視、用電腦、玩手 機，根本不能面對真實的自己。 當我要面對自己時，會選擇到外頭走走、輕鬆地慢跑，一面適度地活動筋骨， 一面和自己對話。我認為這麼做能讓心靈休息、排除雜念，更容易感受到真實的自 己。即使深愛家人，你也必須留一點時間給自己，暫時和他們相處；同時避免使
