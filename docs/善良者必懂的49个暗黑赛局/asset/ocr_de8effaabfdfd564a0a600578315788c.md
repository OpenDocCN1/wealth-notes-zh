# 結語
別執著於小戰，你該在大戰中獲勝

儘管令人感到遺憾，但日本從現在起，面臨嚴峻時代的最大問題，就是「人口減少」。日本會開始接受外國人口嗎？或是「貫徹」純血主義」，選擇通常在衰敗的道略？無論哪一種應對方式，日本都不再是那個「國人歌頌的愜意日本」了。科技進步、氣候變化，加諸東亞在地緣政治上的不穩定因素，我們的人生都將無法再像過去一般舒適愉快。為了傳達自己預見的世界觀，同時盡可能讓各位能勇於面對此後的將來，並且防患未然，我寫下了這本書。無論生在哪個時代，人生都是上天賜予的寶物。科學持續解開各種謎團，告訴我們生命在這浩瀚宇宙中誕生的機率極其稀少，而其中僅僅人類能夠意識到生命的寶貴、成為有智慧的生物。雖然我無法判斷這樣的能力是好是壞，但這機率簡單直是
