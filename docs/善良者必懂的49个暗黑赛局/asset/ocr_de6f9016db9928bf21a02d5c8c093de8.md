# 第五章  攏絡對手之前，你要先學會包裝自己

有些人總愛拿自己和別人比較，不斷地發愁煩惱，心中滿懷自卑。然而，我認為《世界唯一僅有的花》這首歌中提到「和他人較勁是浪費人生」的論點，也不會至於正確。如我先前所說，將意念放在自己身上，為確認自己的身分、位置，而和他人比較，才是有法的做法。

在他擔任議員時，為了瞭解前輩、同僚怎樣選舉、辦公室現狀如何，時常替其他議員助選。透過協助他們，我就能比較自己和他人做法的不同。
