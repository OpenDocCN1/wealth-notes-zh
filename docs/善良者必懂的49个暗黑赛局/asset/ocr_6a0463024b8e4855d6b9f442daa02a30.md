# 第五章 牽絡對手之前，你要先學會包裝自己

在有許多少西裝訂做店，價格和購買成衣其實沒有多大差別；再加上這是自己的東西，多半情況下，我們都該選擇品質較好的東西來使用，這樣一來，CP值（性能相對於價格的比值）反而比較高。襯衫也應該訂做。因為襯衫是直接穿在汗衫外側的衣服，穿上合身的款式，更能讓你感覺輕鬆與自在。此外，襯衫應該勤加送洗、整燙，即使訂做了一套好的西裝和襯衫，衣服皺巴巴的，還<|message|>可能給人壞印象。呈現整潔、清爽和適度質感的衣著，必然能夠大為增加別人對你的信任感。一 個人的穿搭方式如何，也會反應在待人接物的態度上，而搭配花俏的高價飾品，容 易造成反效果。倒不如選擇合乎身分、也適合自己體格的穿搭，不僅能獲得他人好 評，你的自信也將隨之提升。
