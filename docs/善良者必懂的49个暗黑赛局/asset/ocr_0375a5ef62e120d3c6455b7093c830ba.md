# 終章 不要小看自己，你就能成為「賽局」裡最強的操盤人！

他人身上移開那份顧忌，專注在自己的思想上。我有許多企業家好友，幾乎都不在社群網站上發言。理由很簡單，因為他們根本就沒有時間瀏覽及上傳內容，也無法輕易分享例行活動或手上的資訊，因為分享只會得到不好的影響；偶爾分享，也是設定成至親好友才能看見的私密留言。為了行銷自己或公司，而使用社群網站，也許能夠得到好處，但如果不是因為這種目的，要是你沉迷其中，不僅可能忘了如何主動思考，也可能喪失因有利人土直接接觸，而使自己成長的機會。瀏覽那些毫無意義的留言，不僅浪費時間，心情也會受到影響。過於在意他人，不但會讓你失去自主性，也會使你只想追蹤他人動態，因而陷入自我嫌惡的情緒中。追究根來說，自從有了許多免費社群網站，對社會而言，並沒有增加任何附加價值。或許偶爾會有些人在其中發揮創意並且付諸實行，將網路資源運用於商業模式上，但多數人都是將有限且寶貴的時間與精力，浪費在上頭。社群網站當然有其價值，我身邊的大人物們雖然曾使用過，但如今他們都極為忙碌，且被許多無法輕易分享的資訊圍繞，因而漸漸從網站上消失。而後，網站上的
