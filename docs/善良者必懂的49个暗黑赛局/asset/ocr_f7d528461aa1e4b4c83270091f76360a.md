# 善良者必懂的 49 個暗黑賽局

> 善戰者，求之於勢，不責於人，故能擇人而任勢。
《孫子兵法．虛實篇》

你想像的公平，環境只得由你自己來創造。只要積極主動、努力不懈地創造出「讓人事主管改變心意的成績」，就對了；如果真心想做腦中所描繪的事，也可以考慮自己從頭開始組成團隊。只是，和「自己從頭開始 tow 畫」相較，「在目前的團隊中做出成績，進而改變整個環境」，其實更加輕鬆愉快。
即使人事安排不如自己想像，在你沮喪離開團隊、表達不滿之前，都應該在這一個團隊中奮力一搏，努力完成任務，並展現實際成果，同時善用機會持續成長。只要是能做到這樣，一 télé 更加寬廣美好的康莊大道，就能在你眼前展現了。
