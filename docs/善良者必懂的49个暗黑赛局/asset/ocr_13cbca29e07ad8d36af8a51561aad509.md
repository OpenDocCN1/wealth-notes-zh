# 推薦序 懂得「轉化」，敵人就能成為貴人

暢銷書《我不是教你叛逆，而是要你勇敢》作者 鄭匡宇
田村耕太朗的《善良者必懂的49個暗黑賽局》，是一本非常常有意思的書，尤其在這個敵人往往「不知從何處冒出來」的網路時代，更可以提供許多遭受攻擊和批評的人，一些心理建設及聰明的應對方法。
我很訝異地發現，作為政治家的田村先生，其將多年經驗歸納出來的建議，竟然與我曾經出版過的《就是愛被罵：史上最強被罵應對心理學》中的思維和做法不謀而合。諸如強調讓敵人變貴人的方法、做自己的立命安身方式、不和敵人交戰而是向自己挑戰……等，都是我不斷拿來自我提醒的重要心態。
