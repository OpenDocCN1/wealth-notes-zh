# 善良者必懂的 49 個暗黑賽局

前輩認清了「其貫這個世界，並沒有如同倚義電影般的事情會發生」，他用的技巧就是「靈魂出竅」，也就是當自己生氣時，就脫離自己肉體、從上方看著自己，將意念集中在自己身上。當你突然像靈魂出竅一般將自己抽離，從上方端詳著「有對方、也有自己，雙方正要衝突」的畫面時，就能如同利用 3D 視角般，讓時間暫時停止。
於是，你將第一次體驗到「回歸自我」的感受。你瞬間看清「這下糟糕了」，會被對方討厭」、「眼下似乎要開戰了」的事實。從上方看著自己，便得以冷靜下來。
一旦怒火攻心，便將自己抽離、從上方有如 3D 動畫般客觀地審視自己。要練習就這樣的技巧雖然耗時，不過只要練成了，就非常有效。時時刻刻練習，一切就會變自然了。
而且，練成這個技能有不少好處，不只能用於「防止無謂之戰」，在需要「一決勝負」的時機，也能使用。
