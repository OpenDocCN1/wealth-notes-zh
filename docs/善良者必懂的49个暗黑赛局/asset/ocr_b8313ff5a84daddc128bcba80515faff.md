# 45
跳脫舒適圈，
往優秀人才群聚的地方前進

人類是容易受環境左右的動物，身在舒適圈裡，就容易變得安逸。 因此，你應該將自己擺進能夠自我砥礪的環境中。 無論是能給予刺激、讓你萌生奮發向上念頭的團體，或是較難進入的組織，都是十分適合的環境。 以每年成長一〇％來看，要讓能力翻倍，必須花費七年之久｜一個一十二歲初出社會的年輕人，要到三十歲左右才能擁有雙倍的能力，這是一個平均值。但若以每年二五％的成長率計算，只要三年左右，就能使能力翻倍；到了二十五歲左右，就能擁有雙倍的能力，三十歲時就有六倍之多了。 為了讓自己有效率地成長，你必須讓自己身處能夠成長的環境，屆時你也沒時間和笨蛋打交道了。 無論謀職或進修，我都不希望你選擇那種「誰都進得去」的地方。 你該選擇
