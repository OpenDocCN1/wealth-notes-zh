# 第四章 要點小「心機」，營造你無可取代的身價

公司聚餐，應該重視嗎？要我用一般論調來說，就是「把自己的寶貴時間，耗在白天也一起相處的人身上，實在太浪費時間」，或是「我們應該把時間用在有利於自己未來的進修，以及公司外部人際網路上」。然而，若是你рабаты在目前所屬的組織裡有想做的事情，就該積極地參與公司聚餐。我在一一般公司工作的那段日子，也曾經認為日本的「內部應酬文化」；總會導致家庭失和、健康受損及工作成效低落等不良影響，覺得根本就百害而無一利。但「好壞與否」和「好壞與否」，是完全不同的兩回事。為了達成你的目的，比起好壞，內部應酬的好壞，才是你該優先選擇的。只要你是組織內部的人，就該善用這樸的良機。
