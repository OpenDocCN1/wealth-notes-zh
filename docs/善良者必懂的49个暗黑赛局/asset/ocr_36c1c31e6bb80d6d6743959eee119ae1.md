# 第二章 11個戰略技巧，縱橫戰場輕而易舉

為「不夠成熟」，簡單來說，就是「不懂得謹慎思考」。
比方說，在相當重視留言回覆的「推特」（Twitter）上，也請你審慎思考後，再發表言論。一旦被別人說了什麼，可別馬上回覆對方：「為什麼？」「不是吧？」「你說的對。」「無論對方的意見或問題有多少陰險，你都應該立即接受，並先試著思考：「為什麼這個人會對我說這樣的話？」「是因為……的緣故嗎？」
在現實社會中，紛爭通常都是出現「立刻做出反應」時，這將使自己討厭對方的情緒一覽無遺，而讓情勢無法回歸原狀。
雖然這可能不太容易，但如果可以，希望你能帶著笑容說出「原來如此啊」之類的話。讓自己冷靜下來，接受對方的言論。要是無論如何都做不到，就擺個輕鬆自然的笑容、裝出客氣有禮的模樣，假惺惺地跟對方說：「我去一下洗手間」、
「我去抽根菸再回來」，迅速離開現場。
當身處於可能發生衝突的情況，儘速離開才是良策。更高段的戰術是——雖然離開現場，卻向對方表達了某種訊息，那就是：讓對方誤認為你受了傷。
