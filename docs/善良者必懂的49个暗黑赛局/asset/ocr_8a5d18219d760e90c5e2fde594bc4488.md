# 第三章 兵不厭詐，用「人性心理」讓對手為你抬轎！

我也從現任人氣內閣官房長官菅義偉那裡學到一個道理，那就是「身分地位不會使人改變」，他也正在實踐這個理念。我認為「身分地位會使人改變」這句話，有好的意思，也有壞的意思；而菅先生則是堅信好的部分應該維持，不好的部分則應該改變，要朝向好的地方前進。為了不讓自己「因身分地位不同而有不好的改變」，我們實在需要相當的努力

⑯內閣官房是日本內閣總理大臣的輔佐機構，相當於秘書處或辦公廳，其首長為內閣官房長官，兼任國務大臣並統括事務。
⑰菅義偉（一九四八年十一月六日出生），日本的政治人物，現任自民黨眾議院議員，自二〇一二年十二月二十六日起擔任內閣官房長官至今。
