# 責任感重

「責任感」也是一種正義感，但背後的理由並不是為自己伸張正義，而是為團體奉獻己力。比起自私任性的正義，段數還是高了一些。因為對團隊中的人事、業績和戰略都懷有責任感，才和他人對戰，若有這樣的人存在，對團體而言或許還能稱為奇蹟。為了團隊挺身而出、與團隊中的架蛋對抗，這樣的人通常相當少見。 然而，他們的行為方式可是大有問題。不管怎樣的理由，我認為你就是不該挑戰那些「你認為是架蛋」的做法。無論你是為了貫徹自己的信念，或是維護所屬的組織，當你用架蛋的角度看事情，就如同和他們打了交道。架蛋可不會那麼替組織 全體著想，因為他們根本就是架蛋而已！ 要是你有責任感，為了團體更不能挑起爭端，你應該取悅對方，誘使他對團體產生向心力。如同我先前說的，在這個「媳婦社會」裡，有能力而本該晉升的人，經常會被許多築蛋勾搭上，途中又被扯後腿、從工作崗位上一把換下。由於築蛋通常攀附權勢，因此他們擁有向權力中樞傳達訊息的能力。與這樣的人為敵、惹毛他
