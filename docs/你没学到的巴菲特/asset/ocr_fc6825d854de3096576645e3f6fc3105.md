# 給保險經紀人的你——
如何轉型為
專業理財顧問

謝謝，你好！

朋友傳來網路上的一則貼文：「如果你對美女說，我想和妳上床，那你就是色魔，但如果你說，我想和妳一起起床，那你就是徐志摩。」我回了一句，那我要努力當徐志摩。
