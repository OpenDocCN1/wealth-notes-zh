# 常態分配的規則

標準差要表達的是波動範圍的概念，常態分配（Normal distribution）有 3 個重要數字：68、95、99.7，這 3 個數字代表的意義是，有 68%（34.1% + 34.1%）數值會分布在 1 個標準差之內的範圍。約 95%（34.1% + 34.1% + 13.6% + 13.6%）數值會分布在 2 個標準差之內的範圍，以及約 99.7% 機會會分布在 3 個標準差之內的範圍。
