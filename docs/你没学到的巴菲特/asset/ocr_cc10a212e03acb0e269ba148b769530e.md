# 時間複利 微小落差可倍數成長

小型股年複利領先大型股 2%，長時間下來可以產生驚人的差距，更何況大型股比公債長期年複利多 5%，這可以產生 42 倍差距，現在大家了解巴菲特為什麼願意忍受他持有股票的劇烈震盪，因為得到的結果，值得他這樣做。

多數人可能沒有 89 年這麼長的投資期，但就算只計算 1976～2015 年，小型股每 1 美元可以變成 66 美元，大型股每 1 美元可以變成 57 美元，相差近 16%。
