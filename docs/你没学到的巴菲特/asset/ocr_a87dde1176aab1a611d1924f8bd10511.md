長期而言，股票這項資產的投資，報酬優於股債混合的資產配置，但重點是，不是每個人都可以承受股票的劇烈震動，在大跌時很多人會在谷底賣出。地球村時代資訊傳播快速，股市最大的缺點就是會在短期內劇烈震盪，長期投資股市反而安全，但是如果你承受不住在低點賣出，無法靠近股海，就失去了參與經濟成長的獲利機會。

從上面的分析看來，資產配置在投資領域最終可以獲得勝利，那麼資產配置會失敗的原因何在？這有幾點因素：

# 因素① 知道卻做不到
