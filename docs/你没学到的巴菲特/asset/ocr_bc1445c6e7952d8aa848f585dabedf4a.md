# Chapter
2-5 | 巴菲特vs現代投資理論
誰是正確的一方？

巴菲特認為投資要著重在企業的價值，價格波動、β值、標準差……這些都是「何處惹塵埃」沒必要的事，對他完全不適用。而構築現代投資理論（Modern Portfolio Theory）的3位大師，卻對股票的波動度大力探討，進而架構出投資最佳化的效率前緣曲線圖。

這兩者論點，誰比較正確呢？我 MAT 30年前赴美留學的經歷。1985年在美國念研究所時，有一門必修課是投資組合管理，這一門課相當重要，加上老師頗受好評，研究所以特地把這門課開在晚上，讓下了班的公司主管都有機會上課。

課程開在一間階梯式的大教室，屋頂是嵌燈，打出柔和的暖光，說實在，從事藝術表演和文藝座談非常適宜，我每次坐在舒適的椅子上，剛到美國英文又差，一大堆當代投資理論的數字，標準差、β值、變異數……經常引我到周公面前報到，下課後滿懷愧疚的
