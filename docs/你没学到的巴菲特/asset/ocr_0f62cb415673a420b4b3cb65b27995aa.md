# 認知③ 找到壓力點 讓彈簧可以再回彈

找到最適合自己的壓力承受區，這是一個非常重要的工作，能有專業人士如財務規畫師來協助最好，但不見得每個人都有機會碰到，所以前面壓力測試的個案，模擬過去 10 年股災的投資結果，可以借這個個案，找到一些參考座標，經過壓力測試找到自己風險的承受區，事先有了準備，股災來臨時，就有回防的實力和發動攻擊的資金。
