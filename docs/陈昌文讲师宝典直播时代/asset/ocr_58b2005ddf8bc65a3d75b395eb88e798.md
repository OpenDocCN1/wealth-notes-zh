# 16、说好话，做好事，循环正能量

所有话语体系，必须是彻底的正，没有任何问题，才能讲。建立任何一个社群，都有法律风险，不要乱建立社群，严格按照我讲的一切道德、法律范围内来做。所有能量都必须是正能量，否则，会涉及到犯罪问题、道德法律、各种纠纷问题。
