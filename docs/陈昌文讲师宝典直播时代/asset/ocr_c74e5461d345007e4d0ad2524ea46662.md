3、流量如何增加

媒体能把没脑子的人玩成弱智。情绪调动，能让流量爆增，大部分人都好奇、无脑，而且愿意跟随，所以，搞流量的本质，是调动情绪。所谓扎，就是扎他的痛点。富人、企业家、老板、牛人的痛点是什么？

企业家的痛点是什么？

+   1、损失钱财，不懂辨认；

+   2、心理有漏洞，情感有漏洞；

+   3、方向性漏洞；

+   4、男人、女人都会被恋爱对象渣，这个漏洞，也是可以扎出来一大把富人的。

讲直播，讲视频，只讲企业家、老板、富人最痛的那个点，什么最痛我们讲什么。依托我们的书籍，去讲最痛的点。
