# 7、复制、抄袭。

要绝对理智，理解真相，这样才能变成神仙。讲课，要讲绝对对大家有利的，能利用我们书籍去做营销的方法、模式。卖读书会赚钱、卖陈昌文老板社群赚钱，是采取这个模式赚钱的，是采取复制账号赚钱的。这也讲给大家，让有钱的老板加入高级群，抄袭，看看我们是怎么玩的。不差钱的，进来随便看看。差钱的，千万别来，不是老板企业家的千万别来，这是要反复强调的。
