# 第5节：产品借力战略

+   1，借自己的客户——打造自身产品品牌知名度。

如：英特尔制定一个策略，只要电脑厂商的外包装和说明书和广告上，加上“内有英特尔”，就在英特尔的合作电脑商销售额中给予5%广告补助。

比如：一个做纸箱的厂家。专业定制各种纸箱。只要在纸箱下面，留下某某厂家定制；+电话。那么就有一定优惠。这样做的目的，也是在做一 个广告。

+   2，借竞争对手一打造自身品牌战略

如：蒙牛·牛生成，在蒙牛牛奶上，标注：“向伊利老大学习！”——于是很多喝过伊利牛奶的，都想尝尝蒙牛牛奶如何。

于是，我们通过第二个案例，给一个做啤酒的企业老板做了这样一个案例

买2瓶清纯啤酒送青岛啤酒一瓶清纯是普通厂家的，青岛啤酒是知名品牌。

我们通过买清纯啤酒就赠送青品啤酒一瓶。捆绑销售。结果很多人认为，清纯啤酒是青岛出来的新产品。直接带来了不错的销量。

同样，有一个卖净水机的老板，跟中国农业银行合作举办了一个活动。

存定期5万元送价值价值3980元净水机一台.也是在借中国农业银行力，来做活动。相当于找一个公信力比较强，大家有认知的品牌做活动。效果会更加好一些。
