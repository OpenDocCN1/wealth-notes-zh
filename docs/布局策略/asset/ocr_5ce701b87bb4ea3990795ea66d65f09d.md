# 用法 3：同类对比

某公司推出烤面包机，销量平平。后给予补救方法：

再推出一款新型面包机，一个头比那款大一倍，价格却要高出 1 倍多。两款产品放在一起销售，顾客对比一下，觉得小面包机价格更实惠，于是小型号的脱销！

![](bbox=[0.2, 0.68, 0.87, 0.85])

> —— 记住：当顾客无法理解你的产品有多好时，通过对比，展示出来。价格高一点不是主要问题，但你至少得让消费者找到一种物有所值或超值的感觉。
