# ### 黑蒜功效

一、抗氧化、抗衰老

氧化是要衰老最大的威胁，而黑蒜具有极强的抗氧化、抗氧化功效，是很好的抗衰老食品。小贴士：发酵后的黑蒜，其活性抗氧化剂多酚比生蒜足足提高了39倍。

二、增强免疫功能

黑蒜中的蒜活性挥发油能显著提高巨噬细胞的吞噬机能，有增强免疫系统的作用。赖氨酸、丝氨酸都有提高免疫力的功能，维生素C也能增强人体的免疫力。黑蒜中含有的锌参与激素的合成，改善人体的免疫力。

三、调节便秘

通过消费者服用黑蒜反馈信息显示：便秘患者服用3-7天后，便祕症状明显得到缓解。

四、黑蒜的其他功效与作用

中医来看，黑蒜有补肾及调节肝脏的功能。而科学分析证明：黑蒜不但能增强人体免疫力，而且对于高血脂、高血朋、高血压、失眠、便秘等人群也有保健的作用。
