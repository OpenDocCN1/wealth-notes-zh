# 【产品项目融资】

项目融资，一切项目都必须具备融资优势，方能使得项目有序循环运作。

+   第一，传统方式可以找银行或金融机构(担保机构)，贷款机构，商业融资…。
第二，投资者，资本人。(朋友,私募，红杉资本,天使投资… )
第三，众筹平台。(点名时间，QQ 自众筹，微信自众筹…)

# 【众筹？】众筹只是可以筹钱吗？ 策钩 1000-10000 元资金，可以迅速获得 100-1000 个员工，

直接拉你干活，一起分钱。众筹筹钱是 1.0 玩法，

2.0 玩法就是不但筹钱，还可以快速获得大批免费打鸡血员工。
3.0 裂变众筹玩法：分股份，分机制，抱团，再次众筹二级众筹模式，合伙人模式。【内部课堂教学详细】

+   第四，找你的客户，即是你的消费者。(参股)
第五，同行老板(个人研究的思维模板)。

第六，构建资本估值融资(整合资源扩大资本的价值链，并购多家将要倒闭的店，联营参与上市公司进行估值融资)。

第七，借助上市融资。(借用别人公司已经登录 A 股，B 股进行借助上市)。还有与股份相关
