# 1，【产品宣传工具】

把产品信息通过各种途径（新闻，平面广告,电视台，广播电台…），工具（微博，微信，QQ，QQ群，论坛,其他 app…），传递出去，展现潜在顾客面前，潜在顾客看了内心自动得出一个结论，你可能有他问题的解决方案，然后主动来找你，比如：访问你的网站、朋友圈、公司，店铺，并搜索相关资料（百度百科，百度知道…），等等。

# 2，【产品推广文案】

定位的用户会在哪里出现（什么样的群，什么样的 app 平台，同行鱼塘（店面，渠道，社群…），哪里聚集的最多我们精准客户？）——用户心理分析——编纂文案（原创,复制，杂交，句子，文章…）-测试-发布-优化-大范围推广——死磕执行。
