# 【产品营销故事】

通过讲故事的形式，很容易将产品形象导入大脑，因为人类都是喜欢听故事。 我们为产品包装精彩的故事，能迎合消费者群爱听故事的需求。

一个好故事可以提高产品附加值，抬高职场人身价，为一切平庸打造传奇和亮点；

没有好故事，就没有好价格，就不会有高附加值。故事越精彩，产品越好卖。复制 LV 包，不然永远是淘宝同款。

一个好的营销都有一个好的故事，把故事通过某种方式转嫁给消费者？ 故事营销是千万种营销方式里的一种。 故事，怎么讲？

一个产品讲故事，至少，先布局，设计框架，准备三个故事 ：

（一）产品背景故事（产品历史，获得奖项，特色，由来（来自法国农场，加拿大奶牛···....））

（二）顾客故事（使用人数，带来的效果，客户真实见证对比，好评......）

（三）第三方的故事（代理商，新闻报道，国家访谈，名人，专家推荐，朋友介绍，意见领袖推荐，专业机构背书（清华研究院，红十字会.）......）。

三个故事+一个理念（包装的概念=品牌定位）=故事型产品策划的核心。

另外，大多数的故事营销，都只有情，没有色——什么是色？色就是心理引导。故事营销，就是“情色营销”！

一定要学会讲故事！ 讲故事=吹牛逼=骗人=造谣=创造情景生活； 不会讲故事的人，是永远不会发财的。
