# 卧龙营销咨询《布局策略》：内部资料

# 第 1 节：自然流量 36 种<|start|>略模型

【自然流量】：自然就来的，口碑，自动转介绍，好奇，尝鲜，从众，被吸引。

[流量=客户]新客户该如何找?---客户资源，得来其实很简单！

+   1. 分析客户，你的客户都是什么人？
2. 他们聚集在哪里，你的产品能给他们带来什么？你要从他们那里得到什么？
3. 制作诱惑。吸引客户主动留下联系方式。引导进入我们鱼塘。 
4. 不断提供价值，建立信任，激发起购买欲望并进行销售，并持续建立客户终身价值。 
5. 设计一套利益分配系统，让客户成为合伙人，代理商，微商，经销商，等进一步骑马圈地，获得更多客户。
