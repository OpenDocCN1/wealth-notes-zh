# 卧龙营销咨询《布局策略》：内部资料

# 2、再次消费的流量（老客户）

如何让已经购买的客户，经常来？
如何让咨询但未购买的潜在客户，下次来买？

+   1、策略：建立数据库(微信，QQ群，手机号(短信)，身份证...)，保持沟通和联系（所有潜在客户：购买，未购买客户进行管理...) 客户系统管理体系。

+   2、策略：培养习惯

+   3、策略：代金券模式

+   4、充值策略：现在办会员，即可免单 锁定客户。

....

8 个常用的再次消费策略。

# 1.终身服务；

如：终身免费干洗，终身免费维修，终身免费复训，终身免费....

# 2.生日送礼物；

比如：说你今天你生日。送你免费理发一次。
生日，送价值 20 元蛋糕一个。
生日当天买衣服，可以半价。

.....

这里一定要回访，问候，送上祝福。真情实意，把客户当朋友。而不是总想着赚人家多少钱。

+   3.举办客户答谢会；

+   4.组织会员旅游；

+   5.赠送节日礼物；

+   6.平时不定期的抽取顾客名给于奖励；

+   7.消费积分、返利；

+   8.购物后，及时发送感谢信息，服务反馈情况；

.....

对于新客户，我们要不断促销，谈判，促成第一单。而对于购买过一次的，我们之需要让其购买更多。是决定了我们事业是否长久的关键。

记住：这一核心基基就是我们能为他们提供更多超值，慷慨的回报。不说多少，比竞争对手多一点即可。
