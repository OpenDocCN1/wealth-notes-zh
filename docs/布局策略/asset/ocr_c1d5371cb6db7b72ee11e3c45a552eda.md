# 4，抓住市场细分空隙

不论产品价值大小，只要市场有一定价值，企业有相应能力，都可以考虑开发设计新产品包装，并传递一种独特细分价值。 这是一种非常可行，有效的包装开发思路。 通过产品包装定位进行细分，反馈给用户，进而避免激烈竞争打造畅销，并获得市场认可和支持。

# 5，给客户交代清楚

完善产品包装，标志和使用说明，让消费者买的放心，用的明白。

面对太多同质化产品，客户挑选过程，更加注重产品包装和标志说明开始了解产品。 特别关系到自身身体健康与食品安全，更是要设计识别和阅读方面的使用说明。

这点越来越不容忽视。
