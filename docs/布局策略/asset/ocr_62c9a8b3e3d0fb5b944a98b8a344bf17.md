# 卧龙营销咨询《布局策略》：内部资料

# 1,最明显她的锥位放肉的板，是纯白色的胶板。

使板上的肉看起来很新鲜很干净很清爽。满足了客户对健康的追求，规避了对风险卫生的担忧。其他放肉的板都是木板。看起来有点黯淡。他比别人多了几分让客户关注的理由。

# 2,整个肉的，骨头的摆放，比较有规律整洁

肉和骨头上板上没有残渣。整体看起来整洁

# 3,卖肉的是一个20岁左右的小女孩。皮肤很好。微笑很有亲和力，在他切肉的时候，还发现有两个男生偷偷的看着她。她本人，就具备了很大的吸引力，亲和力，和蔼和亲的一种小女孩魅力。

她的微笑很甜。自然真诚，真实的力量是强大的。不像旁边的两个大姐那种微笑有点尴尬。过去看肉的时候笑容转身离开的时候，脸又冷下来了。

微笑是什么，是不是服务？ 记住一句话，再小的生意，也可以用到营销策略。

麻雀虽小，五脏俱全。 任何生意的盈利，都需要从全局去思考。

就算一个卖水果的，他也需要考虑选产品，进产品，销售产品，现金流，回款率，滞缓率，以及陈列，话术，商圈等。

甚至还要求文案，个人形象，以及套餐的设计，等 还有就是商业模式设计，资本运营，等。

举一个例子：聪明的卖水果的，如果自己水果不多了，他会尽快低价销售出去。进而抽出更多时间去卖新的产品。

而一些固执的人，他们却总是想赚钱，就等这批剩货，卖完才干休。结果2-3天还没有卖完。 看似赚了一些利润，其实却损失了最贵的时间和现金流，以及周转回款等问题。
