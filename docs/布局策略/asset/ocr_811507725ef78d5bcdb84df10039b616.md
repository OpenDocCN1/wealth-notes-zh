# 价值策略 4：紧迫感

+   1, 把握营销本质，理解“人”
2, 通过策略“紧急性”来催化客户行动，一定也要把“行动所能带来的利益”表述清楚。

摆脱价格战，我们应该做什么？？

从价格中解放出来，让我们的商品独特卖点独一无二，让人们不管价格如何都想要购买。

这样我们就可以摆脱同质化价格竞争，高价销售。

核心：如何利用充分魅力的方式向顾客展示自己的商品，从而让他们以比较高额价格购买。

如：火车票请在 30 分钟内完成付费，否则自动取消订单！赠品共有 50 个，还有 20 个名额，抓紧预订！
