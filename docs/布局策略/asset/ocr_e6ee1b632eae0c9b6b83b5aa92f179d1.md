# 一， 类别定位

品类的一点解释，比如我们如果口渴 了（问题），我们“喝”什么，就有很多类别选择。 喝水，或者凉茶，或者雪碧，或者绿茶，啤酒都可以。 那么我们决定喝什么就形成了类别竞争。

再比如：我们回家，可以步行，骑自行车，搭车，火车，飞机。 决定用哪一类工具解决我们的问题？ 亦然形成竞争。

# 二， 品牌定位

必须有一个清晰，明确的一句话。如：“农夫山泉有点甜”，耐克“一切皆有可能”，飘柔“去屑海飞丝”， 红牛激发正能量”，“怕上火喝王老吉”，“今年过节不送礼，送礼就送脑白金”，“怕感冒，39 感康”...

“布局让你不一样！——《布局系统》”

一个明确，清晰在第一领域占领客户的信念。打造第一印象。

品牌问题：你创新的细分领域，就需要赶快占有（占领消费者心智），把自己打造成行业第一品牌。凡是品类定位模糊的企业在未来的竞争力都会下降，其次让你的品牌第一时间占领人的思想而不是市场。
