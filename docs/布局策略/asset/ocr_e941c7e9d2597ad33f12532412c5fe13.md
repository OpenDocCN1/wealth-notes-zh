# 第 14 节：产品渠道模型

【产品分销渠道设计】分销渠道：即公司用来接触消费者的各种途径。这里阐述了公司如何开拓市场，它涉及到公司的市场和分销策略。

不管是采取众募，还是三级分销，还是其他什么分销。

渠道设计九项目标

+   1. 顺畅（最基本的功能，以短渠道较为适合。如：厂家直销，线上直接购买） 渠道太多，维护成本高，企业控制程度低 缺点：覆盖面窄 最基本 3 渠道模式：生产商-代理商-批发商-零售商-终端用户；线上渠道）
2. 增大流量（广泛布局，多元化并进，追求捕获率）
3. 方便（最大限度贴近消费者，广泛布点，灵活经营。如：线下体验店，便利店取货）
4. 开拓市场（多着重为经销商，代理商，站稳之后，然后组建自己的网络。）
5. 提高市场占有率（渠道保养至关重要。）
6. 扩大品牌知名度（争取和维护客户对品牌信任和忠诚度。 互联网渠道，微信朋友圈）
7. 经济性（考虑渠道建设成本，维系成本，替代成本及收益）
8. 市场覆盖面积及密度（多家分销和密集分销）
