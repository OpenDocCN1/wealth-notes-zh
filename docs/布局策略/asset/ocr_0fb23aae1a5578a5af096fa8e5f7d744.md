# 价值策略 12：将结果具体化

举例：软件 比如，你是卖软件的，你可以向客户具象化描述结果：

![](bbox=[0.13, 0.21, 0.87, 0.48])

+   1、 使用我们的软件，你的公司可以节约 XX元人力成本、少聘用 XX 个员工，让所有员工有更多精力放在业务上；

+   2、 您公司节省的这笔钱，可以让您每年多一次国内度假，您可以去省外的任何一个地方旅游，并且这多出来的钱可以让你一定程度上尽情的购物。您还可以给您的夫人买一个奢侈品包包。

+   3、 您还可以 LSP 这笔钱，用于奖励公司业绩突出的员工，或者用于年终奖金，或者每年组织公司出去旅游。

将你的产品提供的好处，结果，尽可能的具体化！越具体越好。
