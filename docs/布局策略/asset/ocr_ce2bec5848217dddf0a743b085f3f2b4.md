# 真实案例：7 天卖出 17000 箱橙子，赚 35 万！

# 卖产品——卖渠道——卖故事；

实操谏言：其实不管多小的生意，只要找到合理的方法，都可以做成一个大生意！

# 第一轮：狂刷朋友圈 5 个人；

最早的开始，本来没有目标，因为这是个人的事情。通过朋友圈群发，影响了一批朋友有 124 箱子订单；

![](bbox=[0.18, 0.5, 0.55, 0.68])

第一阶段：一共卖出 200 箱子。【自发，没有任何组织和设想，普通人模式：200*10=2000 元利润】

# 第二个阶段：幼儿园渠道扩展，合作 40 家幼儿园 4826 箱子！

我们利用了家长和幼儿园老师之间的信任。让一个幼儿园家长，送学校 2 箱，然后给孩子吃。这样就不开担心水果安全问题？

引导老师在放学时候问孩子：“好吃不好吃！” 好吃可以让妈妈买哦”，刚放学，一个半个小时，家长只需要在老师那登记，交钱，货到付款就行，卖了 172 箱子。然后有了这点，我们发动朋友圈，放大成功模式，让大家找自己孩子在那个幼儿园，这样很快就接到了 40 家幼儿园。为免孩子购买一定让家长在那个幼儿园去谈，这样可以有效解决信息不对称，家长不至于孩子吃吗？ 绿色果园，这是否方法。园长不在乎几块钱的收益，送 2 箱橙子即可！（天天和老师打交道，有情感，老师一箱 5 元，有利益。利益+情感让生意更容易。）
