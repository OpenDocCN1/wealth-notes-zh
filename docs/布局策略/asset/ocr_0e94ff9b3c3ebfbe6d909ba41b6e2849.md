# 卧龙营销咨询《布局策略》：内部资料

关的就别说，这是企业老板不得已的融资方式！

第八，股权融资（内部员工股权投资，分配融资。）

案例 1：【内部融资银行】让员工融资送钱怎么办？

办信用卡，利用三期（期权、期股、期物）给员工做信用！成立公司把几个骨干员工每人 20% 在右股权，变成股东（个人信用融资《万能资本模式》里的内容）。

重要财产更名到员工名下，加上收入证明等，员工的身份和地位发生了改变。融到的钱，是老板在用，收入提高以后，员工的收入也会跟着提高。

内部银行融资用了公司信用（是员工为什么把钱给公司的原囚，相信了公司的信用和实力）。

内部银行——影子银行——储备银行！

一定要记住：世界上最牢固的共同体就是利益共同体！
