# 卧龙营销咨询《布局策略》：内部资料

解析：电影院正是从客户价值主张出发，挖掘其他产品资源，将客户体验与美食嫁接整合，形成自己的商业模式。

消费路径解析：许多人在看电影之前购买零食或者饮料，或去餐厅吃饭。

当发现这样一种客户价值需求之后，接下来我们就考虑，是不是可以在封闭的影院提供餐饮服务，并提供合适价格。

思想：低价引流，通过价值主张与客户资源，产品渠道封闭及客户支付能力结合，形成特定商业模式。

举例：腾讯 QQ “开们性产品”获得海量客户群，并保持极高的黏性和活跃度，然后通过 QQ 秀，QQ 会员服务，网络游戏等增值服务 “高利润产品” 获得超额利润。

同样：微信刚开始也是免费的。前期就是为了获取巨大，海量的客户基数。

而后：收取现金提现费，手机充值，理财，Q 币充值，腾讯公益，以及微信广告投放，以及京东，游戏，其他商家的嫁接流量返利赚钱。

看似免费，其实在变相对一部分人收费。

案例：广州有一家天天洗衣店，采用复合盈利模式。
