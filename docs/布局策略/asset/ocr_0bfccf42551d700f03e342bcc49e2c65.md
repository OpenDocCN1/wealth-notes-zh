# 卧龙销售咨询《布局策略》，内部资料

活动营销管理：活动计划——活动执行——活动分析反馈；

[活动计划]

+   1、确认采用那些营销活动方案：讲座/演讲；沙龙，行业高端论坛；展览会；付费软文发布；短期促销活动；会议营销，社群座sks；
2 预算+活动目标：目标客户在哪里？建立时间表，媒体，通讯，人员设备；谁可以参加？区域，地位；成本预算。
3，营销活动启动：新闻发布，媒体发布消息，社群发布预告

[活动执行]

+   1，确认来会名单和人数，活动宣传：物料，电话，新闻；
2，评估活动效果，确认预期效果。是否达到，成本计算。

[活动分析] 1，备案，效果评估。
