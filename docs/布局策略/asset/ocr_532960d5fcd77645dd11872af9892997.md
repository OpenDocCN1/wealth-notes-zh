# 5,【低价】低价策略-低价产品，引流用

比如：做一个宣传展架，写上超低价款。实际很多客单价不只是这点。

记住：现在实体店坐等顾客上门就是等死的行为！不如让利前端，进行后端成交。

利用预期目标利润设计引流，即设定好预期完成的利润，并计算好销售额，然后拿出部分利润前置，通过销售额与成交率计算出诱饵产品（获得新客户的成本）的成本。

还是以案例的方式来讲解，有一家海尔店的老板，每年要投入十几万的广告费，由于地理位置比较偏，加上市场竞争激烈，所以销售业绩一直都很不理想，为了提升业绩，早已想尽了各种方法，依旧无法摆脱现有的困境。
