# 【同样一个产品，不同的价格，更多利润。】

同样一个产品，针对不同的顾客，在不同的地点（超市 8 元，酒店 18 元..），不同时间，可以有不同的价格，即差别定位。

销售环境在变化，价格也随之变化，以追求预期利润目标和利润最大化。

具体问题具体分析，科学使用差别定价，获取最大利润的形式；

【解析：差别定价是指用两种或多种价格销售一种产品或者一项服务。】

# 1，顾客细分定价

同一款产品或服务，不同价格售给用户，如：博物馆对小孩和老人卷收费较低，或者免费。

# 2，产品形式定价

不同产品型号，而非成本采取不同定价。如：有家公司最贵的熨斗 380 元。同次熨斗还高 100 元，这高级型具有自动清洁功能，而这额外的功能只需要 100 元成本即可。

![](img/82a0b1ad286e84bf4928c6e6098d8b1b_85_0.png)

# 3, 地点定价

不同的地点，不同价格，如：演唱会不同的席位，不同的效果，不同定价。

豪华席位 3980 元/人。贵宾席位 1980 元/人。钻石席位 980 元/人。普通席位 260 元/人。

# 4, 时间定价

根据季节，月，日甚至小时，白天，周末，设置不同价格。如公园，在年前和年后门票价格不同。电影院白天免费，晚上收费。女生晚上免费，男士白天免费等。

# 5, 季节定价

针对一些季节性或者流行性比较强的商品，上市初期（流行期）高价，而后制定低价。

# 6，重复定价

处理或推销某种商品时常用的方法，以低于原来价格出售，原价划去，并留有痕迹，这样 重复的差别，来明显显示价格的差别。如：原价99元。 现价49元。

# 【 为自己购买高价寻找理由 】

我们的产品（如：手机）比同类 的产品高出 200 元，又能达到很好的销量。如何说服别人？

当用户上面，看到报价，一定会说，你们的为什么要高出那么多？

+   1200 元 是与竞争者同一型号的机器价格
+   50 元 是因产品更耐用而必须付出更多价格
+   50 元 是因为产品可靠性更好而多付价格
+   50 元 是本公司服务更佳而多付价格
+   50 元 是保修期更长多付的价格
+   200 元 是折扣（让利出来了）
+   1400 元手机，就是上述价格的总和。

通过账单，告诉客户，没多收一分钱，而是花了 1400 元买了价值 1600 元手机，是他占了便宜。 长远来看，这种手机成本更低 。

给客户植入思想，让其感觉所付价格物超所值。 就这样顾客心悦诚服的购买高价商品，俘虏我们的客户。

这里重点来了。价格随机定价，看人而来。

# 【价格核爆力思维】

产品价格从 3800——5800——8800，改变的知识形状、颜色，或者加个机顶盒而已。

同样一个产品，通过改变形状，颜色，功能。 个性定制等服务，加一些东西。 就可以采取不同定价。

比如：你买一辆车，属于裸车。 那么要不要加装座垫，皮套，方向盘套，洗车物品，车贴膜，倒车影像，行车记录仪，车内装饰，电子狗等……每加加一项都在增加价格，创造利润。

举例：手机换屏，同样品质屏幕，换不同包装，问顾客是要：普通的 300 元，钢化的 800 元，液晶屏钢化屏 1200 元。

满足了不同心理诉求，有想要价格低的，就买低的，有想要好的，就要最高的，瞬间引爆价格 4 倍。 这就是核爆思维。

10（定价）-成本（8 元）=2 元利润； 10+1 新定价-8=3 元 例如。 价格加 10%，利润提升 50%.（定价是全世界最大的利润杠杆）

涨价背后的心理逻辑：

1，高价=高品质（价格高，产品越好）；低价=低品质（底价格，残次品）；
2，顾客不是买便宜，而是想占便宜。 没有谁天生想买低价，人
都有尊严，但是都想获得附加的赠送。人性都喜欢买贵的，都想占便宜，即便是千亿富翁，也是如此。
几十亿一个产业园贵吗？ 其实一点也不贵，每年能多创造 2 亿的利润。 才是占便宜，的根本。
如：买一套西装 2 万元，送皮带，皮鞋，手表，衬衣。 但是不可以一套西装定价 200 或者 2000 元。
3，顾客追高，不追低，只能涨价，不能降价。 买涨不买跌。就是人性催化剂。
4，产品越少，越稀缺，越有价值。 想高价，就要制造稀缺。 唯一性，必须性）

这个世界上最贵的是空气和水。 为什么他们不值钱，因为太多了。

所以越少，越能体现他的价值。【涨价策略】最牛涨价策略应用。

当面临必须调价时，如何在涨价后仍然维持原来销量？

答案：想办法 “再加一个商品”

我们做过一个啤酒试验，开始 1 瓶 1.5 元普通啤酒与高级啤酒 2.5 元。有 66%人买高级，33%买基本啤酒。

然后在底部加入 1.0 元超低价啤酒，结果，普通啤酒购买率马上从 33%提升 47%。

同样一个试验：加上 3.5 元超级高价啤酒，而这次高级啤酒 2.5 元，购买率从 66%迅速提升为 90%。

由此，希望买较低的商品，就在下面加一个“钓饵商品”，让它变成“中间价位”，就会提升它的销量。

同样；如果希望买较高价商品，就加上一个超贵“钓饵商品”，让它便度变成“中间价位”，就会提升它的销量。

（人性喜欢追求平和，适中，更愿意不好不坏的价格，档次不是很低，价格不是很高。承受力更好。）

比如：有个卖新疆大盘鸡的饭店，我给他们建议，从大盘鸡 88 元，小盘鸡 48 元，不如再加一个中份大盘鸡 68 元。

结果以前很多买小盘鸡的，都买中份大盘鸡了。

【注意】最好的促销，不是砍价，而是”加商品！"

最好涨价，不是立刻调整价位，而是涨价铺好路，先”加商品”。

最妙的营销方法，不是一直行销，一直推广，一直想点子，而是”加商品”。妙在没人规定，这个新商品，一定得加在自己品牌下。

餐厅应用 2；原来就一个套餐：香鸡炒锅头 28 元。

于是改为：

麻辣香鸡锅 28 元，肉斯鸡五香虾 36 元，凤凰鸡香锅 54 元。

很快，都往消费中间的提，业绩直接翻倍。

# **1，目标客户定涨价法（因人而异）**

具体指客户是有钱人，我就定高价，客户是穷人，就定低价。【群体客户定制】

因为穷人对价格敏感，我们就可以多让利一些。让对方尽可能购买，产生利润。 不然他可能这辈子都不会买。

# **2，附加价值定涨价法**

如：卖大米，别人卖 1000，1100，1200，我就卖 1500，另赠送 2 箱价值 1000 元酒；
如：卖健身卡 8 千，赠送 1 万手表。

# **3，行业最贵定涨价法**

不管别人多贵，我永远比别人更贵。 如：爱马仕（就是比 LV 贵）

# **4，高开低走定涨价法**

如：定一个相对高的价格，从低折扣开始销售，随着销量提升，产品折扣随着提升，如 KTV 开业，包厢定价 5000 元，试营业 1 折起，500 元/晚

# **5，差异化定涨价法**

改变客户心智模式，创造新的产品形象。

如：一款酒卖 1000 元，涨价成 2000 元，没有人买了，核心是顾客已经认知了，所以必须改变客户心智认知模式。

如：蒙牛，原本 2.5 元/瓶，改包装，改名字，改数量，改喝法，就变成了特仑苏 5 元/瓶。然后打出一个广告：“不是所有牛奶都叫特仑苏”

# 一， 类别定位

品类的一点解释，比如我们如果口渴 了（问题），我们“喝”什么，就有很多类别选择。 喝水，或者凉茶，或者雪碧，或者绿茶，啤酒都可以。 那么我们决定喝什么就形成了类别竞争。

再比如：我们回家，可以步行，骑自行车，搭车，火车，飞机。 决定用哪一类工具解决我们的问题？ 亦然形成竞争。

# 二， 品牌定位

必须有一个清晰，明确的一句话。如：“农夫山泉有点甜”，耐克“一切皆有可能”，飘柔“去屑海飞丝”， 红牛激发正能量”，“怕上火喝王老吉”，“今年过节不送礼，送礼就送脑白金”，“怕感冒，39 感康”...

“布局让你不一样！——《布局系统》”

一个明确，清晰在第一领域占领客户的信念。打造第一印象。

品牌问题：你创新的细分领域，就需要赶快占有（占领消费者心智），把自己打造成行业第一品牌。凡是品类定位模糊的企业在未来的竞争力都会下降，其次让你的品牌第一时间占领人的思想而不是市场。

# 建立品牌印象：设置行业生活标准

建立标准的过程，无不扯到错觉，幻觉，心理暗示。

比如：饭后为何非要嚼 2 粒，一粒不行吗？ 结婚为何要拍婚纱照？ 护发素啥东西？

当建立标准，成为一种习惯常识，品牌就能一毛钱不花持续享受这种力量带来的回报。

如：双十一，元宵节，情人节，这些都是打造的一个节日。或者我们在当地打造的素食节日，或者广西玉林狗肉节…

如何利用错觉，幻觉，心理暗示，这就是建设品牌首先要考虑的。

为什么去电影院一定要买包爆米花？ 为何麦当劳，肯德基总是要搭配薯条？ 护发素真的有效？....

广告的要素，其实首先就是“建立标准”而标准会带来习惯。

习惯的力量很容易根深蒂固，最难以改变，最可怕的。而当这种习惯已经成为常识时，品牌不用花费 1 分钱，就能持续享受这种力量带来的回报。
