# 1, 通过对比展示差别 （与最高级别的产品作比较）

一个 "卖床垫" 的营销策略："对比"

市场上，80% 的床垫都存在甲醛超标、黑心棉等质量问题。所以，我们可以走 "环保健康" 定位。用环保材料生产，并给每位顾客送一个甲醛检测仪，顾客拿着检测仪测测我们的床垫，再测测别的家的床垫，即使我们价格再高也只会卖我们的产品。

![](bbox=[0.19, 0.36, 0.7, 0.61])

通过比较就让顾客感受其中的区别。

# 2, 将价格拆分  商品使用时间，按每月，每年，甚至天来设定价格。

Iphone6 手机，每月只需要分期付款 365 元即可拥有。（总额大，价格分割后展示，就给人比较便宜的感觉）

365 元一年，一天只要 1 块钱。少吸半月烟就可以拥有。替换成熟悉的物品，换同样价格的物品来说明。比较容易想象，并作出判断）

据胡销售：赠品，特惠或者同样的商品加量不加价，就可以展示此本商品更高的价值。
