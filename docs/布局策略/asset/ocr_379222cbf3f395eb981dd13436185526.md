# 郝龙营销咨询《布局策略》：内部资料

# 塑造价值策略 3：稀缺性-【怎么样能做到让顾客马上购买】

价值来源于稀缺，黄金之所以珍贵因为其非常稀有。如果一种稀缺物变得比较多，它就真的不值钱了。打造稀缺，才是塑造价值的黄金催化剂。

如：我们是布局 1 年班严谨教学，为保证授课质量，不可能毫不限制招人，因此本周只接受 5 个名额，非常抱歉！——布局总裁班

如果不限制，人会报名慢一些。但是我们是真的限制。

当然了，大多数是假限制。

一定要把“行动所能带来的好处”表达清楚。现在不买有啥损失。

如：加上“现在马上”行动的好处，则“马上”行动的动机就高涨了。如：前 100 名，免单。

> 【稀缺性，提升商品价值催化剂】

为何冲动购买？为何必须现在买？如果现在不买，以后就再也买不到了，给消费者一个冲动的理由。

+   1. 数量限定 打造稀缺性，而引发提前购买。
2. 销售地域限定 “天津大麻花”，只有在天津才能购到正宗的大麻花。到处都有的话，就没那么大的价值了。本地地方特产就是如此打造。如：本地特色特产
3. 时间限定 “截止 XXX” 造成稀缺性。特变进行稀缺性促销。

人都是感性的，感情被触动的时候，往往容易冲动购物。“稀缺性”就激发了人们这种欲望。

为什么苹果手机，不像其他手机一样，而是一定要限量呢？

因为只有限量，才能卖出高价。

如果说，有钱就可以买，什么时候都可以买，那么这个手机就不会影响人的情绪和心情了。 就不会说 XX 苹果手机抢不到这种新闻了。

这就是苹果的策略，之所以稀缺，就是故意营造这样一种氛围。进而卖出更多高价的产品。获得持续的利润。
