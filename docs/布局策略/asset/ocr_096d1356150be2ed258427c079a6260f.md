# 6.【免费】

前端布局，前端引流，后端成交。如：课程分为，初，中，高 3 类。

思维：定位人群—分析用户群—设计诱饵，人性喜欢免费——推送诱饵（一系列工具）— —收集流量（建立链接）。（贪小便宜，贪婪，喜欢免费…）——引导成交。

定位人群：那些人需求最大？在哪里出现？（什么样圈子，什么样机构，QQ 群，论坛，学校…）

分析用户群：这些人想追解决什么问题？最关注什么？所有吸引，从人性讲：利益（好处），情感（喜欢什么）。

设计诱饵：给他们最想要的低成本小东西，看起来高价值的东西（塑造后的电子书，视频，行业报告…），或者免费服务？得到本东西，需要什么条件。

推送诱饵：派谁去把这些诱饵传递给我们想要的人？怎么传递？（微信，文章，优惠券…）

收集流量：引导留下 QQ，QQ 群，微信，姓名，手机号，身份证，加入我们社群；线下活动，促销活动，QQ 群，微信群…，并做一个普通的调查问卷，以便更好的跟进流量，帮助解决问题。
