# 卧龙营销咨询《布局策略》：内部资料

你一定要想企业或项目如何从服务费到分成，再到代理，买断模式，最后投资公司的投资模式。

增加客户价值，最重要的就是成本。如何降低成本？

1，产业链和价值链再造，优化，提升效率。除去成本 20%+，但商品满意度和质量并不下降。

为何如家酒店只收 180 元房费，还能获得丰厚利润？

![](bbox=[0.15, 0.33, 0.85, 0.7])

因为采用了革命性主要成本消除机制。没有购物，商务会议，豪华大堂，这些都是目标客户不需要的。 如家目标客户：经济型商务差旅人士和自费旅游人士。

这些生活场景；白天在外办事，晚上回来 “睡觉，洗澡，上网” ，其他，基本不需要。

当如家酒店把这些不需要的功能彻底消除时：不仅没降低客户满意度，同时还大大降低自己成本，这就是革命性降低成本。

有时候，我们应该做减法系统。
