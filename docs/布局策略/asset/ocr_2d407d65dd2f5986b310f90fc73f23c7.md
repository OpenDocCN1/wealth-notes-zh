# 用法 5：质量对比

有个老板是做床垫的，然后用“对比法则”卖价值。市场上，80%的床垫都存在甲醛超标、黑心棉等质量问题。所以，我们可以去“环保健康”定位。用环保材料生产，定义一个行业最高标准。

并给每位顾客送一个甲醛检测仪，顾客拿着检测仪检测我们的床垫，再测测别家的床垫，即使我们价格再高也会买我们的产品。

> ——记住：对于有钱人而言，无非就是卖“怕”。怕麻烦、怕浪费时间、怕不安全、怕没档次、怕没面子、怕没别人好。所以，不管你用的是“甲醛检测仪”，还是其他的任何方式，只要我们能够把其他品牌的床垫，和我们的床垫形成清晰的对比，让顾客“怕”了，就不用担心销量问题。
