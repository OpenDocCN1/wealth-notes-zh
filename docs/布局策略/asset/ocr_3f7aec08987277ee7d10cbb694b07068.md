# 卧龙营销咨询《布局策略》：内部资料

4，企业自身竞争状况分析。自评。

竞争情报收集渠道：除了网络技术，电话采访技术，个人面谈技巧等。还有以下常用策略。

# 1，公开资料收集

行业报告，百度，百度百科，报纸杂志....人肉搜索

# 2,通过竞争对手关联机构

像有关咨询策划公司，会计师事务所，上下游关联企业，包括一些新闻每都是相当有效的情报来源。注意不要越过法律渠道和职业道德，以免不愉快。

# 3，情报人员通过实地考察与谈话进行搜集

对于某些企业与某些情报而言，直接到实体访谈，直接是最有效收集方式，只不过无法接触太实质性的问题。 所以需要一定素质。

# 4，建立全员调查制度而广泛开展人际网络收集

全体员工灌输情报收集意识，情报辨别，对功劳员工进行奖励。

5，通过其他一些特殊手段收集如：不合法手段，挖公司人员，给于利益。 黑客手段,间谍手段。

面对竞争对手情报：“去伪存真，去粗取精”的过程。
