# 卧龙营销咨询《布局策略》：内部资料

# 秘诀 6：降低风险

盲目扩张，风险太大。 要重新开店，装修，培训员工，要多长时间那。 不缺资金还好，一旦资金流断裂，所有盘子都被砸烂。

所以我们可以考虑找一家快要破产的公司。 或者某一家公司有一定业务量，但他们没有最大限度利用他们的机会和关系，资源等。 可以尝试与其合作，为他们提供一个能提高业绩且灵活多变的合作机会。

然后我们，在满足对方需求后就可以共享对方的资源。也可以叫做收购。

# 秘诀 7：获取新知识

+   1，随时随地加入营销领域的牛人圈子
2，随时随地加入投资人的圈子
3，随时随地获取商业最新的动态。
4，随时随地跟行业前 3 名学习+留意黑马；

# 秘诀 8：增加产品种类

简单举例：比如我们家族有个亲戚是卖烤鸭的，一天能赚 500-1000 元。 后来他说想提升利润。

我就建议：他加一个周黑鸭 现在周黑鸭同样也能有 700 多元的利润。增加产品种类，还是那么多客户，需求并没有因此减少。利润直接上升。

比如：卖服装的 加一个皮带，眼镜 等

卖男性保健品的 可以加打火机，毛片，一些有趣相关联的东西等。

# 秘诀 9：寻求营销或销售资源

你有很好的产品或服务，但没有营销和销售经验； 或你有一身本领，却苦没有拿的出手的产品或服务。
