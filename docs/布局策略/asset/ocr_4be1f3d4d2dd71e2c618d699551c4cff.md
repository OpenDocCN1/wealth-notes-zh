# 卧龙营销咨询《布局策略》：内部资料

目的在于成就更高深的课程。当然，我们这次《布局策略》其实也是体验课。

又比如：你做餐饮的，你做的砂锅很好吃，但是别人从来没体验过，肯定不会去，除非有人带他吃过一回。

但是你现在给他一个 50 元产品体验券，让他免费吃一小锅。那么他就会非常愿意去尝试。因为没有门槛，谁都想占便宜。

当他去体验了，发现真的不错。下一次她如果请客，一定会来这里。

要知道客户来这里，不可能只吃 50 元砂锅吧。他一定也会点其他东西吃。当然这个成本钱，也会赚回来。

如果你想着刚开始，刚开业就想赚大钱。就是因为不舍得，所以往往最后大钱没赚上，反而赔钱了。

# 2、明星主打产品

什么是明星主打产品。就是说你这个东西，是店里的招牌菜，卖的最好，最火。价格也适中。利润还可以。就属于爆款。比如：壹贫资本的 7900 元的《资本策略》这个销量是最大的。

# 3、公司利润产品

其次在升级到利润产品。就是说，这款产品利润更高。产品质量也有保证。更加差异化从明星产品客户中，再次筛选一批有实力购买的人。比如：《资本智慧》定价 39000 元。

# 4、核心能量产品

比如：弟子班，事业部，合伙人....这个就是建立利益共同再次筛选的过程。而不是单纯的看中利润了。
