# 卧龙营销咨询《布局策略》：内部资料

绿色：代表和平，稳定，和谐，健康等想象。

如：绿色食品通常绿色，结婚红色，葬礼一定是白色+黑色….每一种色彩都有固定的形象在大脑里面。不会轻易改变。他成了我们所有认知的基础。

所以，在包装广告，我们至少要选择相互协调的配色。不是为了限制，而是为了达到最低限度达到的目标。

+   红色：让人积极向上；促进肾上腺素分泌；感觉温暖；增进食欲；让人感觉时间过的很快
桔色：增进食欲；使人充满活力；给人一种温柔和放松的感觉；
黄色：让人精力集中；提高记忆力；心情变的愉快；
绿色：消除疲劳；让人镇静，缓和紧张情绪；让人心情平静；

+   蓝色：提高专注力；降血压；促使食欲减退。
紫色：促进睡眠；提高想象力；
粉色：让人变得温柔；消除紧张感；让人看起来年轻；
白色：让人清晰的印象；让人感觉比实际重量轻；
黑色：让人感觉压抑；让人心情沉重；让人感觉比实际重量重；
灰色：有品位，让人心安；平凡严谨的印象；

一点色彩学的利用：很多人喜欢黑色衣服，不耐脏。大错特错。

如果你去相亲，千万不要穿黑色西装的，一定要穿灰色西装的，成功几率立刻上升。不信试试。大凡成功人士搭配师都是这么建议。

对于女性，一定也不要穿黑色，穿粉色一定会让你更有女人魅力。试试看。别骗我说穿了没用。

举个例子，有个快餐厅，开始时候，是红色装修，结果很多人吃完，还不走。导致翻台率非常低，很慢。

于是我建议，装修为白色，很快就得到改善，都是吃了就走，没有停留。红色让人不自觉攀谈起来，而白色，则更清晰还有事情要做。

尤其是培训行业，善用色彩包装能量场。
