# 【成交话术的设计】

# 【顾问式销售最好的模板】

+   1, 问封闭式话题（专业的问题）

+   2, 下一个结论（专业的回答）

+   3, 给三个解决方案。（低，中，高。很多人会选中等。）

+   4, 案例搭销。（客户见证）
