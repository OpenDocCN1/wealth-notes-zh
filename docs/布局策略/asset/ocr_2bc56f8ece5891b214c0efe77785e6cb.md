# 4，【产品竞争策略】

思考：竞争情报-整理分析-企业决策

收集竞争对手的经营策略，销售趋向，新技术开发，市场占有率及资讯状况等情报的搜集和研究分析，为企业提供竞争情报服务。并拟定战胜竞争对手的战略策略，使得我们公司在市场竞争中立于不败之地。

竞争情报进行筛选，收集，阐释和传播。

+   1，为企业产品创新指明方向。
2，为企业的市场营销寻找恰当的切入点。
3，技术变革的动向。
4，提供预警机制。
5，锁定主要竞争对手。
6，实施模式管理的基础。
7，明确jack利的坐标，提供竞争动向。
8，维持盈利的优势地位。

情报规范：

市场的竞争，看似是产品的竞争，有时候，就是信息的竞争，谁能获得最新的讯息，谁就掌握了致胜的法宝。

+   1，以顾客为核心研究。
2，选取合适的类数据供应商。如：快递送货量，供货商... 
3，透过竞争情报制定具体的经营策略，而不是抽象的研究报告。
4，重视团体的集体智慧。运用头脑风暴，避免一叶障目，学会利用团体智慧。
5，注重情报人才的培育。
6，保证情报的时效。获取，加工，传递，利用整个过程，时效性很重要。指信息存在的价值是有时间性的，在有效时间发挥才有意义。
