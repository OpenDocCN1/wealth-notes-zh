
# 第 8 种卖法：实产品的包装价值，卖 39888 元/套绝对可能更火

如果把沙发做成三种包装：一种是实惠装（客厅+餐厅），29888 元/套；

第二种是精美装（客厅+餐厅+卧室），卖 39888 元/套；

第三种是豪华装（客厅+餐厅+卧室+过道+玄关），卖 49888 元/套。

可以肯定的是，最后卖得最火的肯定不是 29888 元/套的实惠装，而是 39888 元/套精美装，这就是产品的包装价值创新。

# 第 9 种卖法：卖产品的纪念价值，不卖 58000 元/套除非脑子进水

如果这个沙发也被某人正在使用，又被用在什么著名场所呢，这样的沙发，不卖 58000 元/套除非脑子进水了，这就是产品的纪念价值创新。

营销手法解读：

- 1、消费者在购买产品时，除了产品本身的使用价值外，更多的是购买一种感觉、文化、期望、面子、圈子、尊重、尊严、理解、地位等等象征性的意义。

而这些就是包装价值，文化价值，圈子价值，生态价值，感授权价值，等。一些制造的无形价值。

- 2、同样一套沙发，在沙发的世界——它的功能、结构、作用等依然如故，但随着沙发外面的世界变化，它的价格却在不断地发生变化。

这就是为何一个“悟”字，就能卖 10000 元的本质因素。因为会塑造价值。

- 3、同样的沙发，采用不同的价值创新策略，就产生不同的营销结果，如果能够深植意蕴策划的含义，你还会一头栽进“沙发里面的世界”而出不来吗？还会进入价格战，低价竞争？

# 塑造价值策略 3：稀缺性-【怎么样能做到让顾客马上购买】

价值来源于稀缺，黄金之所以珍贵因为其非常稀有。如果一种稀缺物变得比较多，它就真的不值钱了。打造稀缺，才是塑造价值的黄金催化剂。

如：我们是布局 1 年班严谨教学，为保证授课质量，不可能毫不限制招人，因此本周只接受 5 个名额，非常抱歉！——布局总裁班

如果不限制，人会报名慢一些。但是我们是真的限制。

当然了，大多数是假限制。

一定要把“行动所能带来的好处”表达清楚。现在不买有啥损失。

如：加上“现在马上”行动的好处，则“马上”行动的动机就高涨了。如：前 100 名，免单。

> 【稀缺性，提升商品价值催化剂】

为何冲动购买？为何必须现在买？如果现在不买，以后就再也买不到了，给消费者一个冲动的理由。

- 1. 数量限定 打造稀缺性，而引发提前购买。
- 2. 销售地域限定 “天津大麻花”，只有在天津才能购到正宗的大麻花。到处都有的话，就没那么大的价值了。本地地方特产就是如此打造。如：本地特色特产
- 3. 时间限定 “截止 XXX” 造成稀缺性。特变进行稀缺性促销。

人都是感性的，感情被触动的时候，往往容易冲动购物。“稀缺性”就激发了人们这种欲望。

为什么苹果手机，不像其他手机一样，而是一定要限量呢？

因为只有限量，才能卖出高价。

如果说，有钱就可以买，什么时候都可以买，那么这个手机就不会影响人的情绪和心情了。 就不会说 XX 苹果手机抢不到这种新闻了。

这就是苹果的策略，之所以稀缺，就是故意营造这样一种氛围。进而卖出更多高价的产品。获得持续的利润。

有个老板是做床垫的，然后用“对比法则”卖价值。市场上，80%的床垫都存在甲醛超标、黑心棉等质量问题。所以，我们可以去“环保健康”定位。用环保材料生产，定义一个行业最高标准。

并给每位顾客送一个甲醛检测仪，顾客拿着检测仪检测我们的床垫，再测测别家的床垫，即使我们价格再高也会买我们的产品。

> ——记住：对于有钱人而言，无非就是卖“怕”。怕麻烦、怕浪费时间、怕不安全、怕没档次、怕没面子、怕没别人好。所以，不管你用的是“甲醛检测仪”，还是其他的任何方式，只要我们能够把其他品牌的床垫，和我们的床垫形成清晰的对比，让顾客“怕”了，就不用担心销量问题。

# 第 2 节；立刻建立信任 81 个有效策略模型

# 信任的三个通道：视觉 听觉 感觉

建立信任的目的是降低用户购买风险

要就就是让用户了解产品，明白益处，信任我们，打消客户的疑虑，并要求客户作出决定。

【建立信任：来自接触的次数和深度】有了数据库，有 2 个非常重要因素，就是次数和深度。
1、接触指和客户的接触次数（广告接触，活动接触…）
2、深度指的是每次接触时关系的深浅(第一次购买接触，售后服务接触…)

有了这些，数据库差成提款机才成为可能。客户从你这里得到产品和服务，你得到了先于别人得到顾客的认可。

解读：人性都是趋利避害的；天下熙熙皆为利往，天下攘攘皆为利往。所以成交，因为你给予附加利益更多，人品好。

# 1 第三方见证（大量）

客户见证（最具攻心效果）——软化：让其感觉我们能够帮助他解决问题。

- （1）客户反馈
- （2）客户现场示范，做见证。

- （5）客户对比见证，实验，亲测现场。
