# 卧龙营销咨询《布局策略》：内部资料

竞争相关联信息：

+   1, 竞争环境情报主要关于政治, 经济, 技术, 自然情报。
2, 竞争对手的专项情报。

（1）企业基本情况：公司地址, 联系方式, 性质, 业务范围, 法人, 注册资本, 股权分布, 关联机构等。

（2）企业背景：关系, 股东资料, 重大事件, 政界支持等。

（3）公司核心产品的研发, 生产与销售情况：性能价格比, 功效, 技术领先性, 生产目标与现实生产能力, 销售额与销售政策。

（4）公司发展目标和战略选择：计划, 利润目标, 主战略模式, 成本领先, 还是技术领先。如：整体年全面促销计划, 新产品资料, 销售低价, 上市时间, 重点投放市场区域, 和促销策略等。

（5）市场销售：销售额, 销售区域, 重点市场, 库存情况, 客户类别, 数量及分布；营销管理政策与营销架构, 策略；呆死账管理等。

（6）重点岗位人员情况：姓名, 年龄, 职务, 文化程度, 个性性格和爱好；与主管关系, 家庭背景和联系, 是否明显懈怠和离职倾向等。 如：可以去智联招聘, 拉钩网, 找公司职务诉求。

（7）财务与资信状况：注册资本与实有资本, 开户行与开户日期, 评价存款余额与信用登记, 企业负债额与曾经获得最大的信用额, 是否有不正当理由拖欠客户应收账款的历史。

（8）是否有明显不良的公共记录：如：重大产品和服务事故, 不良诉讼, 判决记录, 是否有丑闻负面等。

（9）根据以上作出针对该目标企业的核心能力, 最短木板, 可能面临的机遇与风险综合分析判断。

3, 用户与中间商有关情报

潜在购买需求, 购买习惯与行为特征； 与竞争对手的业务往来, 金额, 结算方式以及自身的数量, 规模与区域分布等。
