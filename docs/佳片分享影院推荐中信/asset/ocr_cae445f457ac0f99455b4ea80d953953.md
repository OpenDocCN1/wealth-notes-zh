# 剧情简介：

树（王宝强饰）的父亲亲手杀死了树的大哥，后来父亲去世了，但两人影像却时常出现在他脑海。在汽修站工作中，他开始歇‎,后来出了工伤，住进医院，护士辛丰（何洁饰）给他拆线时，厂长将其转走，同时他家面临拆迁，只因村长兼戚要在此开矿，他感到十分无助，没事在村里闲逛，与朋友喝酒，没钱就向弟弟伸手。某天，他碰到了朋友的表妹张小梅（谭卓饰），一见钟情。但在相亲中，他发现小梅是个哑哑女孩，然而，这并没有阻隔他们的爱情。某日朋友结婚，他卖力张罗，却无意中得罪了村长兼戚，受到停哼。一气之下，他来到城里找朋友帮忙，却见证了朋友婚外情的事实。他通过短信跟小梅传情，最终决定与她结婚，然而，这场婚礼却进行得异常艰难。
