# 《三峡好人》

# 到底是有根的地方才是家，还是有亲人的才是家？

# 推荐理由：

+   - 片中三峡工程的建设代表着不同时期的中国，建设前是旧中国，那里有街道、城墙、蝉鸣、蛙叫、集市，以及萎蔫的行人和弥漫在空气中的尘埃，这些共同构成了“家乡”，建设后是新中国，泥泞与混乱交织在一起，本来的乡村成了县城，可那些移民而來的人在拥抱现代化时，成了又矛盾又协调的结合体，他们在恐惧失去一些乡土性的东西，如传统的伦理关系、人际交往与道德体系，也在迎接日益发展的时代，大时代的变化更速，小人物的颠沛流离，每个人都有所失去，又终得归属。
- 主演轲三明18岁初中毕业后就开始下煤矿当工，是在生活中经历过生死的人，同时作为非职业演员 fringe 有对真实生活非常深刻的了解，在片中属于本色出演。他目光如炬，目光里有憧憬，有无奈，有坚定，糅合了非常多的目光。这些精神也赋予了本片中轲三明的独特气质。
