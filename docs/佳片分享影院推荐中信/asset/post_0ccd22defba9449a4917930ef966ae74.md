### 《三峡好人》

### 每个人的故乡都正被“淹没”

![](img/16e27d3311896571578eb9c58c99d7fc_3_0.png)

### 基本信息：

+   - 中文名：三峡好人
- 类型：剧情、爱情
- 导演/编剧：贾樟柯
- 主演：赵涛、韩三明
- 片长：111 分钟
- 制片地区：中国大陆
- 上映时间：2006年12月14日(中国大陆)

### 剧情简介：

三峡建设工作正在进行中的重庆奉节县城，迎来一男一女两个山西人。男人韩三明（韩三明饰）来自汾阳，是名忠厚老实的煤矿工人，来奉节为寻十六年来未见的前妻，前妻是他当年用钱买来的，生完孩子后她回了奉节。寻找前妻的过程中波折不断，韩三明决定留下做苦力一直等到前妻出现。女人沈红（赵涛饰）来自太原，是名沉默寡言的护士，为寻多日不曾与自己联系的丈夫而来奉节，丈夫与她的夫妻关系早已有名无实，这点她虽然深知，仍想让丈夫当面给她个说法。赵红的寻找过程也并不一帆风顺，丈夫在有意无意地躲着她。韩三明和赵红虽不认识，却因为要在相对意义上的“拿起”与“舍开”中做出抉择，在寂寞之中有了某种神秘的联系。

### 《三峡好人》

### 到底是有根的地方才是家，还是有亲人的才是家？

### 推荐理由：

+   - 片中三峡工程的建设代表着不同时期的中国，建设前是旧中国，那里有街道、城墙、蝉鸣、蛙叫、集市，以及萎蔫的行人和弥漫在空气中的尘埃，这些共同构成了“家乡”，建设后是新中国，泥泞与混乱交织在一起，本来的乡村成了县城，可那些移民而来的人在拥抱现代化时，成了又矛盾又协调的结合体，他们在恐惧失去一些乡土性的东西，如传统的伦理关系、人际交往与道德体系，也在迎接日益发展的时代，大时代的变化更快，小人物的颠沛流离，每个人都有所失去，又终得归属。
- 主演韩三明18岁初中毕业后就开始下煤矿当工，是在生活中经历过生死的人，同时作为非职业演员也有对真实生活非常深刻的了解，在片中属于本色出演。他目光如炬，目光里有憧憬，有无奈，有坚定，糅合了非常多的目光。这些精神也赋予了本片中韩三明的独特气质。

### 《推拿》

### 看见的不一定真实，看不见的才都存在

![](img/16e27d3311896571578eb9c58c99d7fc_5_0.png)

### 基本信息:

+   - 中文名：推拿
- 类型：剧情
- 导演：娄烨
- 主演：郭晓东、秦昊等
- 片长：114 分钟
- 制片地区：中国大陆
- 上映时间：2014年11月28日（中国大陆）

### 剧情简介:

这是一个发生在盲人按摩中心男女技师们之间的爱情故事。这里有一个风流外向、能嗅闻跳舞的盲人老按摩师夏明（秦昊饰），也有经常被顾客赞叹其美貌的“会所之花”郝红（梅婷饰），还有整天沉浸于自己精神世界里的“小正太”小马（黄轩饰），以及热情忠心的刚从外地投奔沙老板而来的王大夫（郭晓东饰）与小孔（张磊饰），以及隔壁洗衣房美而温柔的发廊妹小姜（黄璐饰）等，生活各自精彩，人们彼此相安。然而正是“妞子”小孔身上特有的女人气味突然唤醒了小马对爱的渴望，不断念着“妞子”的他不经意转动了命运之轮，使得整个推拿中心各个盲男盲女技师之间的爱情与生活发生了激烈又动人的转弯。

### 《推拿》

### 我们有两只眼睛，一只在脸上，一只在心上

### 推荐理由：

+   - 本片讨论了盲人的“人性”与“非人性”。所谓人性，是盲人与健全人一样的七情六欲、一样的柴米油盐。电影借用人性使观众与片中盲人产生深深共鸣。但不仅是人性上的共鸣，同时还有“非人性”。这样说并非贬义，而是从“盲人与健全人是一样”的这种带有政治正确色彩的陈词滥调中跳出，真实但毫不妥协地道出这个群体与健全人之间的不平等。
- 本片的画外音极具特色，声源完全来自片外，语调也是几乎不带情感的播音腔。最独特的是，与一般影片不同，影片开场刚刚进行情节介绍的画外音随后却将片头字幕一并出现，这不仅与电影题材相契合，还对银幕下观众/健全人这双重身份进一步点醒，营造出奇妙的间离感。

### 《Hello!树先生》

### 无处安放的双手，以及无处安放的灵魂

![](img/16e27d3311896571578eb9c58c99d7fc_7_0.png)

### 基本信息：

+   - 中文名：Hello！树先生
- 类型：喜剧
- 导演/编剧：韩杰
- 主演：王宝强、谭卓、何洁
- 片长：88分钟
- 制片地区：中国大陆
- 上映时间：2011年11月4日（中国大陆）

### 剧情简介：

树（王宝强饰）的父亲亲手杀死了树的大哥，后来父亲去世了，但两人影像却时常出现在他脑海。在汽修站工作中，他开始歇斯底里，后来出了工伤，住进医院，护士辛丰（何洁饰）给他拆线时，厂长将其转走，同时他家面临拆迁，只因村长兼戚要在此开矿，他感到十分无助，没事在村里闲逛，与朋友喝酒，没钱就向弟弟伸手。某天，他碰到了朋友的表妹张小梅（谭卓饰），一见钟情。但在相亲中，他发现小梅是个哑巴女孩，然而，这并没有阻隔他们的爱情。某日朋友结婚，他卖力张罗，却无意中得罪了村长兼戚，受到停工。一气之下，他来到城里找朋友帮忙，却见证了朋友婚外情的事实。他通过短信跟小梅传情，最终决定与她结婚，然而，这场婚礼却进行得异常艰难。

### 《Hello!树先生》

### 逃避，似乎也成了我们不假思索的常态

### 推荐理由：

+   - 通过本片可以悟出很多人生道理，片中树先生的存在，不是绝无仅有的个例。我想我们的一生中或多或少都会有失意的时候，不论是出于我们自身的原困还是外界的影响，那一段段的无助、晦涩、颓废、反感或许都无限接近于树先生。当我们被生活的大山所压，站不直腰板的时候，又会怎么做？树先生选择了逃避，通过幻想面对拯救人生。但当他梦醒之时，这一切的一切都要归于现实，他还是他，无人给予尊重的树先生，希望我们可以以此为鉴，勇敢地面对困境，勇敢地做自己。
- 本片将各类荒诞奇手法应用自如，是国产电影中荒诞大成的典范之作，同时还为中国电影虚拟现实主义的衍生提供了样本。
- 主演王宝强凭借超高的发挥，完美演绎了影片主角“树先生”这一人物。此片的表演被公认为王宝强的演技巅峰，尤其是出神入化的抽烟片段，已被纳入北影教材。

### 《无间道》

### 香港影坛划时代的巅峰之作

![](img/16e27d3311896571578eb9c58c99d7fc_9_0.png)

### 基本信息：

+   - 中文名：无间道
- 类型：剧情、犯罪、警匪
- 导演：刘伟强、麦兆辉
- 主演：刘德华、梁朝伟、黄秋生、曾志伟
- 片长：101 分钟
- 制片地区：中国香港
- 上映时间：2002年12月12日(中国香港)

### 剧情简介：

1991年，18岁的三合会会员刘建明（刘德华饰）听从大哥韩琛（曾志伟饰）的指示进入警校学习，成为警方卧底。而同时警校中的另一名学生陈永仁（梁朝伟饰），受警方安排表面上将辍学学习，实际上则是让他进入三合会当卧底。刘建明从警校毕业后进入警局，成为刑事情报科的一员，在此期间他为韩琛提供大量的情报。而陈永仁在这些年以来已经得到了韩琛的初步信任，但由于韩琛的案件始终没有破，他永远只能待在黑帮，只有黄警督（黄秋生饰）与他单线联系。2002年的一个晚上，根据陈永仁卧底情报获知一批毒品即将交易，但由于刘建明及时将消息给了韩琛使其成功逃脱，因此双方发现各自的内部都有“内鬼”，于是 一场激烈的角斗由此展开。

### 《无间道》

> —— “对不起,我是警察！” —— “谁知道？”

### 推荐理由：

+   - 本片将黑暗与暴力与情感和友谊紧紧联系在一起，将各种元素混合在一起，构成了一个几乎无法预测的世界。电影中的角色没有一个是单一维度的，每个角色都有着自己的内心世界和动机，这些元素一直推动着整个故事的发展。这种多面性使得电影更具深度和吸引力，也使得观众更加投入其中。
- 演员阵容也是本片的一大亮点，刘德华、梁朝伟和黄秋生等香港电影界的顶尖演员都展现了自己非凡的表演能力，特别是梁朝伟所饰演的角色陈永仁，以及刘德华所饰演的角色刘建明，两个角色的对决也是整部电影最精彩的部分之一。
- 此外，本片不仅仅是一部刺激的动作电影，更是一部充满人物探索的电影。本片使人感动点并不是大人物的一举一动，而是小人物内心的挣扎——“想成为一个真正的好的，但是过去的一切并不能抹去”。

### 《大佛普拉斯》

### 黑白的真实人生，彩色的梦

![](img/16e27d3311896571578eb9c58c99d7fc_11_0.png)

### 基本信息:

+   - 中文名：大佛普拉斯
- 类型：剧情、喜剧
- 导演/编剧：黄信尧
- 主演：陈竹升、庄益增等
- 片长103 分钟
- 制片地区：中国台湾
- 上映时间：2017年10月13日（中国台湾）

### 剧情简介:

在佛像工厂担任夜间警卫的菜埔（庄益增饰），每天最重要的工作就是深夜帮董事长启文（戴立忍饰）开大门，他捡破烂的换帖兄弟肚财（陈竹升饰）平时没事就会来这里看电视。一天凌晨雨很大，肚财带着快要过期的咖啡饭来找菜埔，偏偏电视又坏掉，肚财听人家说有钱人的世界都是彩色的，于是怂恿菜埔拿出老板的行车纪录器看看有没有养眼的东西。但两人也从一个单纯享受色情广告的小确幸夜晚，更名卷入一个政治勾结、情欲横流、惊天动地的谋杀计划。1尊大佛、1间工厂、8个不同背景的小人物一同刻划出最荒谬的甘味人生。

### 《大佛普拉斯》

> “虽然人类早就可以坐太空船去月球，但是永远无法探索别人内心的宇宙”

### 推荐理由：

+   - 在这部电影中，我们可以具体看到市井小人物的卑微生活，以及乱象丛生的台湾社会。看似懒散荒诞的情节发展，无处不是对现实世界的反思和隐喻。同时本片在对应底层人民悲惨生活的描述中，没有夸天抢地的悲号，没有振臂高呼的呐喊，只是用最少语言的，最沉默的画面，来揭示现实。
- 在视觉效果方面，影片创新地采用了黑白和彩色混杂的影像呈现方式，富人的世界用彩色表示，穷人的世界用黑白呈现。透过具有隐喻性质的色彩，富人生活的缤纷华丽，以及穷人生活的黯淡感，给予人以直视和强烈的冲击。

### 无人知晓的孩子，如草芥般生长

![](img/16e27d3311896571578eb9c58c99d7fc_13_0.png)

### 基本信息:

+   - 中文名：无人知晓
- 类型：剧情

### 剧情简介:

这是一个拥有五位成员的大家庭，母亲惠子、大儿子明（柳乐优弥饰）、长女京子（北浦爱饰）、次子茂（木村飞影饰）以及次女雪（清水萌萌子饰）。母亲带着孩子搬家的时侯就父亲长期在海外工作，和长子两人生活，其实还有三个“黑户”孩子，四个孩子都是同母异父。为了不让别人发现几个孩子的存在，母亲只允许大儿子外出。母亲平时上班，照顾弟妹妹的责任就落到大儿子明的身上。慢慢地母亲回来越来越晚，突然有一天，母亲不知所踪，她留下20万日元现金和一封简短留言给明，告诉他以后这个家就靠他照顾了。于是，从这天起，四个“无人知晓”的孩子开始了流浪的生活。

### 《无人知晓》

### 现代化大都会下的社会关系原子化

### 推荐理由：

+   - 本片所讲述的故事并非虚构，而是根据真人真事改编，使人感到无奈。本片虽然没有交待结局，却依然触动人心，孩子们的天真、乐观和单纯更加折射出人世的炎凉和无奈，是一部拥有深刻思想内涵的成功的影片。
- 80年后的日本恰逢泡沫经济的巅峰，都市人在对物质生活的过分追求中体验着现代性的迷失与快乐，个人主义和功利主义急速膨胀。依赖于社会体系生活的人们，人际关系越发疏离，对公共利益漠不关心，道德制约被消解，每个人都活在自己的世界里，对不关己之人、事、物不闻不问，这种原子化的社会关系导致了“无人知晓”类似事件的发生。
- 电影在拍摄人物外景时巧妙采用长焦镜头拍摄全景。每一次人物穿行在街道上，影片都采用了高机位长焦镜头全景的处理方式，在适宜的地方观察着孩子们在社会里的活动，反映出人与社会的关系，形成一种象征性的表达。

### 比悲剧更可怕的是现实

![](img/16e27d3311896571578eb9c58c99d7fc_15_0.png)

- 中文名：熔炉
- 类型：剧情
- 导演：黄东赫
- 主演：孔刘、郑裕美、金贤秀

**剧情简介:**
来自首尔的哑语美术老师姜仁浩（孔刘饰）来到釜山市，应聘慈爱聋哑人学校。姜仁浩妻子早亡，8岁的女儿松儿患有先天性哮喘，由祖母照顾，所以他不辞辛苦谋求工作。然而，双胞胎的校长与教务主任竟违规收纳5千万韩元，并且美其名曰学校发展基金。同时，姜仁浩发现学校笼罩着一种紧张压抑的气氛，令人窒息。尤其有三个孩子引人关注：眨眼的金钟斗（金贤秀饰）和贪吃的陈宥利（郑仁奈饰）总是躲闪。全民秀（白承焕饰）的弟弟自杀身亡，他总是满脸沉默。下课后，仁浩还听到女厕中有人喊叫与哭泣，在门卫的阻拦下他未能深入。之后，他意外目睹了校长行贿警察，教导员毒打民秀，生活老师强奸妍珠的行径，一个惊天的秘密被慢慢揭开，真相令整个韩国震惊。

### 《熔炉》

### 我们一路奋战，不是为了改变世界，而是为了不让世界改变我们

### 推荐理由：

+   - 电影以韩国光州一所聋哑障碍人学校中性暴力真实事件为蓝本，将真实事件稍加改编。本片对这场令人心疯狂的丑恶几乎没有半点粉饰的意图，不论是性侵案件的残酷，还是法庭上的腐化，都毫不留情地给予最尖刻的刺破，像是用钢笔尖头刺破坚挺脆薄的窗纸，利落干净地形成窥洞，使人一窥在遮羞布之后不堪入目的丑恶与绝望。

+   - 本片在细节和台词上的精细考究与制作，增强了电影主题所要呈现的张力和渲染力。几乎没有不切题的废话或者欲盖弥彰的遮掩，而是秉持残酷的客观原则，将恶与善、强与弱、邪与正的较量与抗争全盘展示。
