# 《Hello!树先生》

# 逃避，似乎也成了我们不假思索的常态

# 推荐理由：

+   - 通过本片可以悟出很多人生道理，片中树先生的存在，不是绝无仅有的个例。我想我们的一生中或多或少都会有失意的时候，不论是出于我们自身的原困还是外界的影响，那一段段的无助、晦涩、颓废、反感或许都无极限接近于树先生。当我们被生活的大山所压，站不直腰板的时候，又会怎么处死？树先生选择了逃避，通过幻想面对拯救人生。但当他梦醒之时，这一切的一切都要归于现实，他还是他，无人给予尊重的树先生，希望我们可以以此为鉴，勇敢地面对困境，勇敢地做自己。
- 本片将各类寡太奇手法应用自如，是国产电影中装奇大成的典范之作，同时还为中国电影虚拟现实主义的衍生提供了样本。
- 主演王宝强凭借超高的发挥，完美演绎了影片主角“树先生”这一人物。此片的表演被公认为王宝强的演技巅峰，尤其是出神入化的抽烟片段，已被纳入北影教材。
