# | 今日关键词

Personality：个性。关于“个性”我们还学过一个词叫character。这两个词都是表示个性， character强调的是，一个人面对生活中重大问题时间态度，所以电影、小说里的角色都叫character，因为故事就是角色对于不同问题的选择。而personality 指的是，一个人在为人处事方面与众不同、让人印象深刻的特质。
