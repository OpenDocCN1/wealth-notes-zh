# | 每天都必须运动吗？

如果每周积累能做150分钟的中等强度的运动，就很了。不管是运动是一天做、两天做还是每天做，效果没什么大差别。

# | 推荐运动

《时代周刊》主要推荐了两个运动。

第一个是跑步，因为最容易，不需要什么设备。文章指出，很多对跑步都有误解，认为跑步伤膝盖，会引起关节疼痛、关节炎等问题。但最近的研究发现，对于健康的人群来说，短时间的跑步，不仅不会伤膝盖，反而可以缓解膝盖关节的发炎问题。

欧洲《应用生理学》期刊的文献介绍了一个实验，实验邀请了15位18到35岁的健康志愿者，研究者在他们跑步前采集了血液样本和膝关节滑液，让他们在跑步机上跑30分钟后，再次采取他们的血液样本和膝关节液体做对比。研究者发现，膝关节滑液的促进炎症因子，在跑步后不仅有升高，反而下降了。但这个实验没有弊端，研究样本太少，代表性不够。我们可以得知的是，对于一个健康的人，跑30分钟没有问题，对膝盖有好处，无需太紧张。

第二个推荐运动是力量运动。力量训练明显的好处是可以增加和增强骨密度。文章指出，很多人忽略了它的隐形好处。力量训练可以降低患二型糖尿病和心血管疾病的风险。

文章举例，与不做任何力量训练的女性相比，做力量训练的女性得二型糖尿病的几率要低30%，得心血管疾病的几率要低17%。

总结今天的内容，运动的好处简直太多了，不仅对身体运动的时候，心率加快，有更多的血液进入大脑，还帮助修复脑细胞，促进脑细胞生长。运动不是非得健身房才行，午的时候散步，回家的伸伸，每能积累150分钟中等强度的运动，无论是集中一两天完成，还是每天做，效果一样好。
