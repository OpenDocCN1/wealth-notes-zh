是欧盟委员会的会做。马克龙不但是法国的新总统，也是整个欧盟的权星。

而《新闻周刊》说，马克龙当选的另一个意义，是标志着全球政治势力正在新老交替，进行洗牌。其实无论是马克龙还是勒庞，代表的都是新的政治势力，而传统的政治势力，如社交党和共和党，都没能进入第二轮法国总统大选，一败涂地。

美国去年的总统大选，也是新老政治势力的交替。特朗普虽然代表共和党参选，不光他的对手民主党不喜欢他，共和党人也不喜欢他。他就是一般新的政治力量，这一点跟法国的情况几乎如出一辙。

而《时代周刊》认为，这种情况是因为在过去的20年里，年轻人不关心政治造成的。老政治家们吸引了年长者，因此，去年的美国大选和本次的法国大选，几乎就是一场政治上的革命，是新老政治势力的更迭。

所以，这次选举马克龙赢了，勒庞也输掉，真正的输家是传统的政治势力，所以接下来，他们要反击了。

# # 马克龙的短期考验

马克龙的考验，分为长期的和短期的。长期的考验是他必须兑现竞选时的承诺，而短期的考验是下个月的议会选举。

6月11日，法国要举行议会选举，也是两轮，选举将决定议会中的577个席位怎么分配。这对马克龙太重要了，如果他的党派不能取得至少289席的多数座位，就麻烦了。

与美国总统可以一个人决定国家行政事务不同，法国要总统与总理共同管理国家。如果总理跟总统不同，总统的政令将很难实施。法国总理就是由6月议会选举中占多数席位的党派推荐出来的。

而马克龙对于自己所在的党派，能否取得议会中的多数席位，心里没底。首先，他的党派都太年轻了，马克龙39岁，从政只有短短五年，在政坛上的根基太浅。他的党派也才组建一年，连底层动员投票的组织系统都没有。而法国议会，向来是两个传统政治势力社交党和共和党的天下。

社交党表示可以跟新总统合作，但共和党坚持总理的人选从自己这边出来，以限制马克龙的总统权力。

而民调显示，一半以上的选民，并不想让马克龙赢得议会中的多数席位，因为这些人的当初只是因为不喜欢勒庞才选的马克龙。

# # 马克龙的长期考验

就是他如何要实现自己的竞选承诺。

法国人没有多喜欢这位新总统呢，法国的三份很要的报纸《世界报》、《费加罗报》和《巴黎人报》，在马克龙当选后，第二天只有《世界报》在头版刊登了马克龙在卢浮宫的获胜演讲照片，另外两份报纸的报版都是恐怖袭击事件。

这说明马克龙的当选，更多的是精英阶层在狂欢，而普通民众还是更担心自己的切身利益。

马克龙承诺，要在2022年以前，把法国的失业率从10%降到7%以下，这是个艰巨的任务。稍有差池，就等于是给了勒庞新的政治资本和筹码。就像《新闻周刊》说的，勒庞距离登上总统的宝座，只差一次经济危机了。如果马克龙的竞选承诺没有兑现，那么下一次法国总统大选，勒庞获胜的几率就非常大了。
