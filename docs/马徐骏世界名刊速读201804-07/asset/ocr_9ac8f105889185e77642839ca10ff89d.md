# ## 知识清单:

### | 比特币和比特币底层技术——区块链

今天为大家介绍的是《经济学人》杂志的两篇文章 <虚拟眩晕> ( Virtual Vertigo ) 和 <跑马圈地> ( Land Grab )，讲的是比特币和比特币的底层技术——区块链。

先来讲解几个今天会用到的两个关键词：比特币和区块链。这两个词的英文都碰巧是组合词，比特币是 bitcoin，bit 是计算机使用的二进制信息单位，coin 是硬币，所以 bit+coin 就是使用的，它是一种网络上的虚拟货币。比特币使用的技术叫 blockchain 区块链，这又是一个组合词，是 block（一块、街区）和 chain（锁链）的组合。

《经济学人》的这两篇文章主要讲了比特币究竟是不是-一种像"郁金香狂热"一样不靠谱的泡沫投机现象，以及区块链技术是如何应用在政府的公共服务上，保护老百姓的财产安全的。看完这两篇文章，会让你对比特币热潮和区块链技术有一个新的认识。

### | 健康的泡沫

Bitcion 是不是泡沫？《经济学人》这篇文章里的观点是：是，但它是一种健康的泡沫，因为它带来了创新和改变。

Bitcion 最早是一个叫中本聪的人在2009年的时候发明的，听名字是个日本人，但这个人是谁，其实没有人知道，所以中本聪可以看作是比特币发明者的网名。作为一种虚拟数字货币，比特币可以在网上进行交易。比特币的好处是，它可以不受任何政府和银行的控制，能实现自由交易。而且它的交易相对来说很安全，现在除了比特币之外，网上还其他的虚拟货币，但 bitcion 是最有名的。

熟悉比特币历史的人都知道一个叫“比特币比萨日”的纪念日。七年前也就是2010年的5月22日，有一位程序员用一万个比特币，买了两个犇约比萨。当时比特币是个新鲜事物，每个价值才0.03美元，一万个比特币也就30美元。而在7年后的今天，一个比特币的价格已经涨到了最高3000美元。所以有人戏称这是史上最贵的两个比萨。5月22日，也因此被定为“比特币比萨日”，这不是为嘲笑这位用比特币买比萨的哥们，而是因为这是史上第一宗用比特币这个虚拟货币完成的现实交易。

目前，日本政府已经批准比特币作为合法货币进行交易了。

对比比特币持有者来说，他们相信比特币还有继续升值的空间，而且潜力巨大。

但比特币的反对者认为，比特币就是一种泡沫，就像当年17世纪荷兰的郁金香泡沫和18世纪美国西部淘金热一样，是一种巨大的投机行为，而且很多的散户开始投资比特币了，如果最后泡沫破裂，不少人会因此倾家荡产。

但是《经济学人》认为，比特币的确是泡沫，但是种健康的泡沫，它更像是上个世纪末的互联网泡沫。那时候互联网刚刚兴起，你做一个网站，取名“XX.com”，感觉分分钟能去纳斯达克上市了。这的确是泡沫，但咱回到了千禧年，互联网泡沫最后破灭，但是这给我们留下了宝贵的财富。首先是技术的创新和探索。如今很多的互联网巨头和移动互联网技术，都得益于那次的互联网泡沫，所以文章管比特币大潮叫健康的泡沫，因为它会带来创新和改变。
