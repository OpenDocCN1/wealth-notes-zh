# 来自未来的“苹果公园”

今天为大家介绍的是最新一期《连线》杂志的封面文章，介绍的是苹果新总部——苹果公园。

关于苹果新总部，很多人都看过图片，它是一个完美的圆形，充满了未来感和科幻感，就像一艘停在地球的宇宙战舰。

一般关于苹果新总部的报道，都是告诉你苹果有多土豪，像是共花费了50亿美金来打造这座苹果总部；又或是它的设计花了多出色，世界顶尖的设计团队投入了250人，花了七八年才完成；以及，苹果是多么地追求极致，新总部里用的木头都要求一定要是在1月份的时候砍下的，因为这个时候，木材的糖分最少、品质最好。

但是《连线》杂志的独家报道，却从另一个角度给我们讲述苹果新总部的故事。

文章的作者是科技媒体界大牛——史蒂芬·列维。史蒂芬·列维在美国媒体圈和科技界无人不知无人不晓。早在1984年，列维就提出了“黑客伦理”的概念。他还采访过比尔·盖茨、马克·扎克伯格等众多科技大流。而且报道，以及，史蒂芬·列维会在苹果设计总监J Jonathan Ive亲自陪同下，参观了还没完工的苹果新总部之后写就的。文章标题非常有感，叫One more thing，“还有一件事”，“还有一件事”也是苹果发布会上最常用的一个结尾方式，在发布会临近尾声，说完了前面的内容，等到要给大家张大招、带来惊喜的时候，苹果最喜欢用的句式就是“还有一件事”。

在史蒂芬·列维眼中，苹果新总部不仅仅是一个工作场所，从根本上来说，它也是苹果的一件产品，是乔布斯真正意义上的遗作。为了打造新总部，苹果使用了产品思维、倾注了心血，这件产品同时也反映出了苹果公司最核心的理念。

# 苹果公园的历史

苹果新总部的正式名称叫Apple Park，苹果公园。建造它的想法，最早是乔布斯跟乔纳森2004年在伦敦海德公园散步的时候产生的，而最初乔布斯的设计理想，并不是现在看到的圆形设计，乔布斯想要的是三叶草的形状，但为什么没用呢？根据在苹果传记作者华尔特·艾萨克森的说法，是因为乔布斯后来把三叶草的设计方案拿给自己儿子看的时候，乔布斯的儿子说：这幅图射脏的时候，很像男性生殖器。最后，三叶草被否定了。

2009年，苹果找到了诺曼·福斯特来主导设计。诺曼·福斯特是设计界大牛，他设计过的作品有德国国会大厦、香港机场，以及伦敦标志性建筑“小黄瓜”。乔布斯跟福斯特聊了一天，最后乔布斯口述，诺曼画出了草图。乔布斯对于苹果总部的设计的灵感，来自斯坦福大学的建筑师——教学楼隐藏在树木被里面。乔布斯强调的，是要做到内外平衡，他想在设计中体现出自己想象中的加州的样子来。

2011年，乔布斯亲自去说服市政规划员开始落实项目建造。在乔布斯生命的最后两年，他花了大量心血在新总部上。就像苹果现任CEO纳姆·库克说的：这个项目是苹果的“百年大计”——a hundred-year decision.
