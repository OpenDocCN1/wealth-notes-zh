# |今日关键词

False Memory：false 的意思是“虚假的，错误的”，memory是“记忆”的意思，合在一起——false memory——就是虚假记忆。
虚假记忆是一种心理现象，指的是人们回忆起了以前从来没有发生过的事情。

Recollection：即为回忆。Collect是“收集”的意思，“re-”是一个英语前缀，意思是“重新、再一次”，组合到一起就是回忆。recolletion和memory这两个词要注意区分：memory强调的是记忆，它是客观的。而recolletion强调的是“回忆，追忆”，是主观的。如果你想表达的是“根据我的回忆”，就可以说 according to my recollection，这比memory要更准确。

# |记忆真的可靠吗？

今天为大家介绍的文章来自最新一期的《连线》杂志，文章的标题叫做《记忆真的可靠吗？》，文章作者，科学记者艾玛·布莱斯主要引用了犯罪心理学家茉莉亚·肖（Julia Shaw）的理论。茉莉亚是伦敦南交叉大学法学与社会科学系的低级讲师，负责教授犯罪学和心理學课程，同时还是《科学美国人》杂志“记忆专栏”的主笔，该专栏讨论的内容，就是记忆是如何误导人们的。

先来讲一个真实案例。1989年，有一位叫做艾琳的女性起诉了自己的父亲，根据艾琳的描述，20年前，当时艾琳才八岁，她目睹父亲强奸并杀害了自己的好朋友，并把尸体埋在了树林里。当时父亲威胁她，“你要是敢告诉别人，我就杀了你”。艾琳因为当时自己太害怕了，就把这段记忆封存了起来。20年后，机缘巧合，她想起了这段回忆，果断地起诉父亲，要为自己的好朋友伸张正义，而他的父亲也真的因此被判了刑。

事情的转折发生在他父亲被判刑的五年后。艾琳的妹妹出庭作证，说艾琳在起诉这段回忆期间，在接受过催眠治疗。催眠师一直在告诉她，她的脑海当中一定有一段被压抑的记忆，催眠师还鼓励她去回想过往承受过的伤痛。在这种暗示下，加之艾琳的朋友在艾琳小时候确实被杀害，一直没有找到凶手，二者结合，就产生了艾琳所谓的“回忆”，但事实上，根本没有办法证明这段回忆是真的。

法官最后推翻了对艾琳父亲的判决，释放了他。艾琳的父亲，因为艾琳的这段虚假记忆，false memory，白白坐了五年的牢。

心理学家通过研究发现，人们如果被诱导性地提问，或者是在与其他人交谈的时候，有意无意地被灌输了错误的信息，就有可能产生扭曲的记忆，甚至会产生根本不曾存在过的记忆，也就是虚假记忆。

认知心理学家伊丽莎白·罗特斯（Elizabeth Loftus）做过一个实验，试图找出人们是否可以被灌输所谓的“虚假记忆”。

罗特斯共招募了24位志愿者，发给他们每人一本小册子，小册子上写有四件志愿者自己的童年经历——前三段经历是真的，第四段是假的。第四段经历说的是：志愿者小时候曾经在商场走丢过，最后一位陌生人把他送回了家。为了让故事看起来比较真实，罗特斯还将这些志愿者父母的商店的一些关于他们小时候生活的细节，比如说当地的购物中心的名字之类的。
