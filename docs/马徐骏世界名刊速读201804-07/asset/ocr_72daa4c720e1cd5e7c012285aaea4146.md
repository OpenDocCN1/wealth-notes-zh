# 合成生物学的应用

文章里说，合成生物学几乎可以解决人类目前面临的所有问题，因为它可以使我们从原来被动地接受自然选择，变成主动地参与人工设 计。比如说，现在我们已经能够在实验室直接造出肉了，这可以解决食品问题；还 可以通过改造细菌的DNA来让它们分泌出石油，这可以解决能源问题；另外合成生物 学还能让酵母产出青蒿素，这是对抗疟疾的特效药的主要成分，但是在自然界中，它的量是很少的，通过人工合成的方式，能解决这一间题。

微软在合成生物学领域也有投入。你可能会奇怪，微软不是科技公司吗？跟生物 学有什么关系？那是因为，基因的本质其实就是一个存储装置，DNA里有海量信息，微软认 为，DNA是比计算机硬盘更好的一种存贮装置。今天人类最高效的电子产品，都是基于硅 这种元素，但硅的整体存储容量跟DNA是没法比的。一段很小的DNA能带响所有的信息 是非佣人的。打个比方，现在全世界所有的数据，用计算机硬盘根本没有办法全部存 储下来的，但如果用DNA的方式，只需要一间屋子那么大就够了，所以微软在合成生物 学方面投资，是为了研发更有效的存储方式。

另外，美国军方还想利用植物的光合作用，把其中的关键因于基因信息提取出来，用在人 的身上。植物对于能量的利用率是人类的4.5 倍，如果士兵携带这样的基因，意味着他们 可以不用吃饭了，仅依靠光合作用就能获得 能量供给。如果再多想一步，这种应用还可 以帮助人类进行星际历练，因为不用吃饭就 意味着携带更少食物。听着很梦幻，但在合 成生物学家家的眼中，这些都是可以实现的。

你会发现，这里其实蕴含着巨大的商机。去年发布的“透明市场研究所”预计，合成生物学的市场规模会从2012年的资不过20亿美元，发展到2019年的130亿美元。很多硅谷大佬，像埃里克·施密特、彼得·蒂尔、马克·安德森都在往研究合成生物学的初创公司投巨资。甚至华尔街金融行业的巨头美孚石油公司，也花了62美筑合成生物学领域的公司共同研发可持续的生物燃料。

虽然现在人工合成生物的成本还比较高，但在电子行业有个“摩尔定律”——每过18个月，集成电路上的元器件数量会翻一倍，发展的速度也越来越块。合成生物学领域也有类似的规律，叫“卡尔森曲线”，就像人类刚开始做基因测序的时候，花了整整十年的时间、2万亿美元才把所有的基因给检测完，但是现在只需要一千美金，不到一天的时间就可以测定一个人全部的基因序列了。这 一个成本越来越低、时间越来越快的加速过程，就是“卡尔森曲线”。合成生物学的发展会越来越快，应用的领域也一定会越来越多。

# 合成生物学的争议

电子产品是一回事，设计和创造生命是另一回事，合成生物学是否存在着巨大的道德、伦理争议？

首先，很多人会担心有钱人可以利用合成生物学，创造出更优秀的后代，富人变得更强，无论是从智力水平，还是身体素质，都越来越好着，就好像尤瓦尔·赫拉利在《未来》里描述的那样，会出现富人，甚至出现像X战警一样的变种人。这会造成普通人跟有钱人的差别越来越大，造成社会的不公平。

其次，如果人工合成出来的生物，跟其他物种交配，那会不会造成混乱和破坏，甚至是带来不可挽回的后果？

目前看来，别说合成生物学创造生命了，很多人对于转基因食品，都觉得不安全。怎么能让大家接受合成生物学对人类社会的改变，怎么才能解决道德和伦理争议，现在还没有答案。但应该相信，科学永远走在大众的认知前面，合成生物学也不例外。
