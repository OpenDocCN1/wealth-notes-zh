# 今日关键词

Medium：意为中等的、中间的，名词形式是媒介、方法和中间物的意思。文章里提到的ACG，是动画（Animation）、漫画（Comic）和游戏（Game）的总称。加上文学（Literature）和电影（Film），这些都属于帮助人进入故事情境的媒介，也就是Medium。

# 游戏市场的现状

这篇文章作者，美国亚特兰大大学的写作老师乔恩·欧文提出了一个说法，相比小说和电影这样的媒介，游戏能够更好地塑造人、改变人。

作者说的游戏，指的不是像超级玛丽、古墓丽影这样的单机游戏，而是多人在线互动的游戏，比如英雄联盟、守望先锋，包括最近国内特别火爆的王者荣耀，以及虚拟的VR游戏。

文章指出，全世界每天玩游戏的人有一亿五千万。在美国，有97%的青少年每天要玩一个小时以上的游戏。而在中国，玩游戏的人群数量同样巨大。比如腾讯开发的游戏王者荣耀，注册用户达到了两亿，按照中国14亿的人口计算，平均每7个人里，就有1人在打王者荣耀。

# 游戏与电影、小说的核心区别

文章指出，小说和电影是讲述故事的工具，而游戏是创作故事的空间。

也就是说，在电影和小说里，所有情节都是设定好的，你没有什么自主权，不可能化身为电影和小说里的主角，只能跟随他们的决定，去看他们经历了什么。

但现在游戏有一个特点，就是只给主角的起源、人物的身世，但是接下来操纵人物做什么，完全由你决定，这就是故事创作的空间。游戏和你自己创造故事，讲述自己版本的经历在遭遇，这是一个小说和电影这种媒介（Medium），完全没有办法做到的。这种自由度和控制力，是游戏独有的。

# 游戏如何影响着我们的行动

现在的游戏，可能比电影和小说更容易影响一个人。

从行动上看，2012年斯坦福大学的虚拟现实实验室做过一个实验，研究玩游戏会不会让人变得更无私。实验者找了两组人，让他们戴上VR虚拟现实进入一个游戏场景，一组人扮演像超人一样会飞的角色，另一组扮演直升机上的乘客，没有特殊能力。这两组人的任务一样，就是一小时内救出地震中的一个小男孩。

但这个实验真正的测试其实是在游戏结束后。实验者摘下VR眼镜后，实验者安排一个志愿者不小心打翻一个笔筒，笔撒了一桌子。他们发现，凡是在游戏里扮演超人的玩家，在现实场景中也更倾向于主动提供帮助，比扮演直升机乘客的玩家要主动得多，且每组测试结果相同。

人的脑部有一个器官叫海马回，负责记忆的存储区域和空间定位。测试者发现，VR游戏中玩家脑部的海马回发生的反应，跟现实生活中海马回的反映基本一致。这种反应要比他们在看电影和小说时，海马回的反映大得多。因此VR游戏的确比小说和电影，更能影响人的现实行为，让你变得更乐于助人。
