# ### 今日关键词

False Memory：false的意思是“虚假的，错误的”，memory是“记忆”的意思，合在一起——false memory——就是虚假记忆。虚假记忆是一种心理学现象，指的是人们回忆起了以前从来没发生过的事情。

Recollection：即为回忆。collect是“收集”的意思，“re-”是一个英语前缀，意思是“重新、再一次”，组合到一起就是回忆。recollection和memory这两个词要注意区分，recollection强调的是回扫，它是实际扫
