# | 瑞士机械表的危机

瑞士表以高端机械表闻名于世。但是，它的出口量在2015年和2016年经历了两年连续下跌。2016年，瑞士表出口总量约为2500万件，2017年的前几个月，这种下跌趋势依旧。

与此反差明显的是，智能可穿戴设备的出货量却在2016年超过了一亿件。今年前十几个月的出货量又超过了去年同期。

似乎是智能可穿戴设备的崛起，将瑞士表推向了末路。其实不然。

瑞士表出货量急剧减少的背后，有金融危机、英国脱欧导致英镑下跌，以及中国的反腐败等一系列因素的影响。全球奢侈品需求都有所减少。加之近年来瑞士法郎上涨，让黄金表等奢侈表制作原料价格的上涨，让瑞士表对其他国家的买家而言变得更贵了。
