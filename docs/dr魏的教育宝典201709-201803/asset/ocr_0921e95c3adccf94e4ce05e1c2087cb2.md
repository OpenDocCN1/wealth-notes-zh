# 1.孩子过于善良，好不好？

我家女儿6岁半了，平常非常懂事、体贴，看到小区打扫卫生的阿姨都会主动说奶奶辛苦了，心软到会为一只小蚂蚁受伤而难过。
但是，前两天孩子半夜拉肚子，自己去上卫生间。我家是智能马桶，坐上去就会感应加热有声音发出，她上完卫生间回来后，我问她：拉完了吗？怎么没听到声音？孩子说马桶发出响声影响妈妈休息。
我听后感觉孩子太懂事了，不禁想到善良懂事没错，可过于善良会不会容易被人欺负，形成懦弱的性格？

Dr.魏

最近一些负面的新闻事件，让大家对善良这个词产生了怀疑。善良是让人类社会得以良性运作的基础之一，但如果“好人没好报”，的确令人心寒。
沃顿商学院的心理学教授亚当·格兰特发现企业组织中有三类人：付出者、互利者和获取者。付出者想的是：我能为你做什么？互利者是：我为你做什么，我就为你做什么？获取者是：你能为我做什么？
在业绩上，处于顶端的是付出者，而垫底的也是付出者。那些表现最好的付出者，他们懂得利人利己，对索取者说不；而垫底的付出者，只懂利人，不懂利己，光帮助别人忙，自己的活儿反而就撂了。
我的好朋友、清华大学积极心理学中心主任任卷[yu]鲲说，好人会武术，神仙挡不住！开玩笑哈，但是，我依旧希望你的孩子保持一颗善良之心，多结交付出者、互利者，好人抱团力量大；学会拒绝索取者不合理的要求。
当然，我觉得最重要的是，作为家长，你不要只是自己脑补，应该去问问孩子。比如，她平时是如何跟朋友相处的，她做这些事的时候，心中是怎么想的？或许，她有自己独特的交友之道呢。

# 2.身边的也小朋友不理孩子，我该如何引导？

我家宝宝一岁半，带他去游乐场玩，他特别喜欢小朋友，看到小朋友，就去摸人家，拉人家，然后还冲着人家笑，这是好还是不好？看他那么热情，小朋友也不理他，我心里也有点失落，怕养成交好别人的习惯，变得没有个性。

Dr.魏

一岁半的宝宝，对同龄人产生兴趣，愿意和他们互动，这是好事！但小小的脑袋，还没发展出如何有效社交的能力，这很正常。这个阶段，宝宝最重要的学习法宝是试错。他吃东西，可能把嘴巴塞得满满的，然后发现不好咬，慢慢地他才知道多大口比较合适；他学走路，可能要摔个成百上千次，才知道怎么保持平衡。他和小朋友互动，也需要试错的机会。
而且，在3岁前，宝宝和小伙伴之间，更多是平行游戏，也就是玩类似的玩具，都没有什么交流。他们更多的是观察、适应和同龄人一起的氛围。
避免让孩子一味讨好别人，而忽略自己的需求和感受，我们大人也需要注意言行。比如，不要否认孩子的感受，总是说“这是为你好”“妈妈觉得你冷”。
最后，借用台湾作家龙应台的一句话：孩子，你慢慢来！

# 3.孩子抗拒上幼儿园，怎么办？

孩子上幼儿园两个月了，每次提#起上幼儿园都很抗拒，早晨哭着去，边哭边说：“妈妈，我真的很害怕上幼儿园啊！没有妈妈陪很害怕。”
这是怎么回事？看老师的样子，也不是体罚孩子吧？

Dr.魏

孩子抗拒上幼儿园让你感到苦恼。你可试试：1.观察孩子回来后的状态是怎样的；2.跟班上的家长聊聊，他们孩子在幼儿园的情况；3.通过角色扮演的方式，了解孩子在幼儿园的情况。
比如，小松鼠去上幼儿园，幼儿园里有大马老师，还有小鸡、小狗、小熊同学，它们发生了什么事情呀。让孩子不知不觉代入，鼓励他说。当然不一定全是对的，因为孩子的记忆发展还不是很完善，也容易受大人误导，只是作为参考。4.和老师私下沟通，了解孩子在幼儿园的情况。

# 4.孩子在家说什么时候都懂，在外却说自己笨？

Dr.魏
批判性思维很重要的一步是，了解问题是什么。爱因斯坦说：如果给我1个小时解答一道决定我生死的问题，我会花55分钟思考清楚这道题到底是在问什么。一旦清楚了它到底在问什么，剩下的5分钟就足够回答这个问题了。
所以，你现在最需要做的是，先了解孩子为什么在外面会说自己笨，而在家里却说自己什么时候都懂。我给你两个思考的角度。
1.了解孩子在家里的表现。他为什么总是表现得自己什么都懂？这种情形是什么时候开始的？当孩子有这种表现时，家里人是如何回应的？
2.了解孩子在外面的表现。孩子为什么会对足球老师说自己笨？从你的描述看，这个老师挺负责任的，应该会愿意和你分享孩子的情况。孩子还有在其他情况下说自己笨吗？你是如何回应的？
希望看到你在留言区和我分享你调研这些问题后的发现。

# 5.孩子胆小内向，成因是什么？

我女儿今年四岁，感觉她自从上幼儿园，接受了老师的不能打同学的教导后，变得有点胆小内向。小朋友打她，不会还手。孩子一直是奶奶带著，是因为没有父母的陪伴，没有安全感造成的吗？

Dr.魏

教导孩子，了解问题是什么很重要。接下来，我会给你一些思考的角度：
1.幼儿园老师是如何告诉孩子不能打同学的？是强迫的，还是充分沟通解释呢？如果是强迫的，命令式的，那么孩子是顺从，害怕受到惩罚。
2.老师或家长是否有教孩子除了打人以外的自我保护方式？如果只是告诉孩子不要打人，但是孩子不懂大声制止、推开、逃离、向老师求助的技巧，那么她可能容易被欺负。
