# 1. 孩子总喜欢摸着我的耳朵才能睡觉，怎么办？

“<|start|>懂睡眠模式，让宝宝睡得好”这期内内容戳中了我的痛点，两岁半的女儿就是典型睡渣。她必须得摸着妈妈的耳朵才能入睡，而且必须要妈妈陪她睡觉，夜里醒来必须摸到妈妈的耳朵才能再次入睡。

根据你在“关于安全感，你或许有这些误会”这一课中，关于安全感的讲述，我判断她不是没有安全感的孩子。请问她这样的行为正常吗？我试图用玩偶替代帮她改掉这个习惯，但是没有成功，您有什么建议吗？

Dr. 魏

这是一种正常的安抚行为，就像有的孩子会抱着玩偶或吃安抚奶嘴睡觉一样。

# 2. 宝宝为什么经常说“怕怕”？

宝宝1岁5个月了，最近经常说“怕怕”，听到窗外的汽车引擎声会说“怕怕”，说完转眼就忘记了，也没在意；睡前听到楼上发出的细微响动也会说“怕怕”。我会安慰他，但他还是继续说怕怕，很久才能够入睡。

Dr. 魏

其实宝宝很早就有害怕这种情绪，比如6~8个月大时，宝宝会区分熟人和陌生人的脸，开始怕生。他现在开始学会说话，按照你的描述，他不一定理解“怕怕”这个词的意思，因为有时候他并没有表现出害怕的反应。这个词对他来说，可能有多层含义，就像是宝宝看到狗，你告诉他这是狗狗；后来他看到猫，他也可能说是狗狗。

# 3. 孩子犯错误却动手打自己的脑袋，怎么办？

宝宝最近有一个不好的倾向：如果他犯错误了，我们没有批评指责他，他却动手打自己的脑袋。而且脾气也变得越来越大，一不顺心就无休无止地嚎啕大哭。有没有什么方法能解决这两个问题呢？

Dr. 魏

孩子做错事情，却动手打自己脑袋，有可能是无意中发现这样做，大人会他爱的愿，或者不责备他。这些好处强化了孩子打自己的行为。而其他孩子则可能在地上打滚，这都算是正常的表现。

# 4. 自闭症最近十年为什么发病率很高？

尹建莉老师在作品《好妈妈胜过好老师2》里分析了自闭症的原因，她认为，父母的冷漠教育以及非专业机构的错误治疗加速了自闭症患儿的增长，不完全是生理和遗传造成的，这也是近十年来自闭症突发这么高的患病率的原因。Dr.魏，你怎么看？

Dr. 魏

中大三院的邹小兵教授对尹建莉的说法早有回应，你不妨去看看。尹建莉之前连续几年都发文揭露所謂的自闭症“真相”，但去<|message|>却没有，很大原因是自闭症相关从业者跟她进行了深入沟通，解答了她的疑惑。
