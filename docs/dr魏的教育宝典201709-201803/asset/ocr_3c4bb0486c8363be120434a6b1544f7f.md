# 【1】孩子曾经的“情绪脑”方面大问题

从前，我家孩子每每遇上什么不称他心意的事情，不会直接发脾气，而是会选择沉默，表面上，什么都没有发生，其实总是暗流涌动，将不满深刻在心，并不定 Gund 发。

映象深刻的一回，是我们在吃晚饭，吃着吃着，他忽然阴下脸来，对我说一声：“臭爸爸，我才不要你给我的蓝色小汽车呢，哼！”老实说，这话让我感觉有些莫名其妙，仔细回想，原来是他还在为前几天我批评他跟别的小朋友争小汽车而生气。

# 【2】我和孩子这一年的收获

# （1）三种养成—能控制，能分享，能反思

受老师启发，面对孩子的小情绪，我和宝妈首先不会责备孩子，而是接受孩子的情绪，尊重他、理解他、支持他，去分析他行为背后的原因，他为什么生气？是因为没有得到爸爸妈妈的及时解释？是因为自己受了委屈？还是纯粹就是为了引起爸妈的注意？
