# 137 | 你的孩子属于哪种气质？

Dr. 魏

下周我将与你一起讨论两个话题，一个是智力测验，另一个是兴趣班。

常常有家长问我，该不该给孩子做智力测验？智力测验的成绩到底说明了什么？其实，智商分数不能代表智力，面对新环境的强大适应力，才是人类智力的真正含义。下周我来谈谈，如何培养出适应现代社会的聪明大脑。

另一个话题是兴趣班。每个孩子快放假的这段时间，家长讨论最火的话题就是“兴趣班”。到底该不该给孩子报兴趣班？孩子报了兴趣班，却没了兴趣，该怎么办？你肯定有过类似的困惑，下周我就重点为你讲清楚“兴趣班”这件事。

# 1. 孩子老在课堂上捣蛋怎么办？

女儿4岁多，每次参加课外班，一开始表现不错，过一会儿就开始捣蛋了。比如，跳舞课上，不按老师的指做动作，或者上早教课不坐在椅子上，要坐在我身上；做完一个游戏，老师要收道具夹上去，她偏要留着。

我应该怎么办呢？是课后和她讲道理呢，还是非常严格地制止她？如果继续这样，是不是索性让她出去，不上课了？

Dr. 魏

孩子一开始表现不错，后来开始捣蛋，有可能是因为对环境熟悉之后，放飞自我。就像有的孩子窝里横外边乖，你家宝宝这是开始耍后“横”。
