# ——►智力脑◄——

# 1.智力“刺激”游戏

说起智力脑，你一定记得“大脑的可塑性”，也知道塑造大脑可以靠给孩子提供各种各样的“刺激”。你可以带孩子去博物馆、去大自然，甚至去新开的游乐场，感受从生活中来的新鲜刺激。

# 2.数学游戏

我 repres 日常生活中就很喜欢用游戏的方式来跟女儿做数学计算。比如说，她小的时候，我跟她用钞牌来算十以内的加减乘除，就是让她想想怎么用这几张牌算出个10来。更大一点后，就以 玩大人玩的算24，把数学嵌入到游戏中。我女儿特别喜欢玩，数学能力也提高得特别快。

# ——►情绪脑◄——

# 假装游戏

想帮助孩子整合情绪脑和理智脑，假装游戏就是一个好方法。在假装游戏里，孩子不再是关注自己的想法，而是要努力去想象，别人在这个情况下会怎么想、怎么说、怎么做，甚至别别人去感受其他人会怎么想，这对孩子的同理心和社交力都大有帮助。

# ——►语言脑◄——

# 亲子互动阅读

语言不能只拼语言数量，还要注意给孩子输入语言的质量。到底要怎么说呢？除了日常生活中跟孩子的对话，绘本是一个非常重要的工具！优秀的绘本语言朗朗上口有韵律，句子在重复中又有变化，故事扣人心弦，图画和文字配合巧妙，非常适合当语言学习材料。
