# 划重点

虽然计算能力和智商都影响孩子的数学成绩，但影响最大的是推理能力。可以通过推理技巧，教孩子加减乘除、分数、比例等概念，效果更好。并且，用实物、图像、数轴等具体的方法，帮助孩子理解，更重要。
