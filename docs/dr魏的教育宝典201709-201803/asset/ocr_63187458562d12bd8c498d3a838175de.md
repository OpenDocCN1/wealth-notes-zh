# 1. 家长在宝宝小时候短暂出差，会影响孩子成长？

借着Dr. 魏本周谈到的独立性话题，想请教下，我儿子1岁1个月，但公司准备派我到外地三个月，每个月只能回家一次。目前跟孩子处在亲子关系建立的关键阶段，这样的出差不会影响他成长？
我提出把孩子和外婆带到外地和我一起，遇到了家人的 Camellia 反对。不知您对这个问题怎么看？缺少这三个月的母亲陪伴，会对孩子的未来发展产生哪些潜在的影响？

Dr. 魏

离开1岁多的孩子3个月，对你来说是个艰难的决定。目前没有研究说，妈妈在孩子早期离开几个月，会对他造成长久的不良影响，除非离开期间，孩子受到的照顾质量很糟糕。如果爷爷奶奶、外公外婆照顾到位，你不必担心。

# 2. 孩子爱咬脐髻，是心理上没断奶的表现？

最近一直有个问题困扰着我，我家男宝快三岁了，有个吮吸脐髻的习惯，就像吃奶一样，经常吸脐髻，“我想孩子难道是吃奶没吃够？但他是一岁一个多月才断奶的！很担心，求指教。

Dr. 魏

这可能是孩子自我安抚的行为，就像是吃手指，或者有些大人思考问题感到焦虑时，会无意识地抓头发、�以外一样。孩子做这种行为，往往是无意识的。

# 3. 孩子总跟大人“唱反调”怎么办？

我女儿快三岁半了，很多事情都表现得很主观，比如幼儿园的创意美术课，她常常不采纳老师的建议，坚持自己的想法。我一直觉得这没什么不对，但近一年这种情况似乎逐渐超出了合理范围，孩子表现得很“叛逆”，有时即使清楚自己这样做不对，也要坚持和家长唱反调。

Dr. 魏

孩子比较“叛逆”，主要受自身个性和环境的教养两个因素影响。但具体到每一次“叛逆”，还得具体问题具体分析。比如你女儿拒绝洗手，是否是前面发生了不开心的事情，将情绪发泄在洗手上。所以，事后跟孩子回顾，了解她当时的想法，非常重要。

# 4. 为什么孩子拒绝尿尿和拉臭臭？

Dr. 魏，我家孩子两岁四个个月，他表现达到挺好的，但是最近有一件让我很头疼的事，就是拒绝尿尿和拉臭臭。

Dr. 魏

你可以从两个方面来分析这个问题，一是孩子的年龄段，二是是否发生了特定事情，让孩子对排便感到羞耻。

# 5. 打压了孩子的兴趣，怎么让他重新爱上画画？

孩子一岁多刚开始接触画笔时，很兴奋，拿着笔在纸上画，在沙发上画，大人受不了了把她家里面弄得乱七八糟，就没收了画笔。现在她两岁了，再把笔拿出来，让她画，她也只在纸上画两下，就不画了，似乎画画的兴趣被打压掉了，怎么才能让她重新爱上画画？
