# 085 | 读者问答：孩子被同学欺负怎么办？

下周我将帮你解决两个问题：抗压力、社会力的培养

每次在网络上看到年轻人面对压力自杀的新闻，你会不会有类似的担忧？面对巨大压力，有些人能克服困难，有些人终生走不出阴影。研究发现，能在困境中“逆袭”的人，都比较有“韧性”。那么如何培养孩子的韧性？下周一，我教你几个锻炼孩子抗压力的方法。

除了抗压力外，下周三我会与跟你聊聊“情商”。很多人认为情商比智商更重要，以为情商跟认知能力没关系，这是错的。那么，高情商的人是什么样的？有哪些表现？我从认知科学角度，教你一些培养孩子社会力的方法，欢迎你准时到专栏学习。

# 2.宝宝喜欢撕书怎么办？

我家宝宝十一个多月了，还不会说话，喜欢看立体书。但孩子有一个坏习惯哦～喜欢撕书。孩子这么小，我无法跟她讲道理，有时真的想打她，这种情况应该怎么处理？

# 3.孩子在学校被同学欺负怎么办？

我苦恼的问题是：孩子今年刚上一年级，由于不爱说话和胆小，总被同桌欺负。

# 4.该不该帮孩子筛选朋友？

孩子2岁8个月，喜欢跟比自己大的小朋友玩。我家附近有一个大他3岁的小朋友，儿子为了跟她玩，需要用吃的东西、玩具或者一些矫情的配合来讨好她。
