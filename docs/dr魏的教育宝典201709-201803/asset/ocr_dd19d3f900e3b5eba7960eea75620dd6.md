第72期金牌家长：@崇昊

上期的思考题是谈谈你对孩子发火之后你是怎么办情绪的，这期的金牌家长我颁给宝爸 @崇昊。

他说孩子从外婆家回来之后，晚上不愿意按习惯刷牙睡觉了。面对拖拖拉拉的孩子，宝爸终于忍不住，对孩子发火。不过，他冷静下来，认为打孩子也解决不了问题，于是先回避，让爷爷过来带孩子洗澡。

事后这位宝爸分析了自己发火的原因：

+   1. 孩子刚从外婆家回来，还没调整和适应好环境，但是他没有考虑这点，只是一味地让孩子恪守习惯。
2. 督促孩子洗澡的时候，使用的方法比较单一，没有调动孩子来解决问题。
3. 用“爸爸发起火来很可怕”来警告孩子，让他听话。
4. 孩子表现得不好的时候，对自己的温和教育方式产生了动摇。

他给出了对应的改进方法：

+   1. 首先认识到习惯的养成需要很久的时间，对孩子不听话的行为应该客观地分析情况。
2. 多学习育儿的新方法新手们，孩子遇到困难的时候，及时使用。
3. 要学习非暴力沟通的方法。对于孩子，不是用害怕让他听话，而是学习用孩子的方式与他沟通。
4. 自己要意识到人无完人，不是任何事情都可以立即解决的，实在拿孩子没办法，也可以先放一放，冷静一下。比如让孩子妈妈等别人来处理，不进不退，横着走一步也是一种方法。

我相信，如果你每次发火都能像这位宝爸一样分析一遍，你的情绪调节能力一定会更进一步的！
