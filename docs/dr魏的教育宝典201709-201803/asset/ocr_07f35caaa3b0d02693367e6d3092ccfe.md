# 培养孩子独立性的两个极端

我们当父母的知道，现在的养育，是为了孩子将来更好地独立生活。孩子的“独立性”体现在生活中的各个方面，比如生活独立，会自己穿衣吃饭；比如思考独立，对事情有自己的观点和喜好；做事独立，能自己解决问题，面对后果。

（1）第一个大坑是父母手伸的太长，太“爱”孩子

（2）第二个大坑是把孩子强推出去，自己的问题自己解决
