# 108 | 怎样培养孩子的批判性思维？

Dr. 魏

上周我讲了STEM教育是关于思维方式、学习方式的教育，提到了培养孩子的批判性思维。

说起这个，我想起有一次，我参加一个讲座，有一位小学老师分享教学经验时说：“批判性思维非常重要，我就特别有批判性思维。不管是哪个专家教授来讲学，我都能提出批评，反驳他说的话。所以，我们也要教我们的孩子批判性思维。”我当时开玩笑说：“你这不叫批判性思维，你这是在玩找茬游戏。”

# 批判性思维的两个误解

可能很多人像这位老师一样，对批判性思维有两个大的误解。第一，以为批判性思维就是去批判、去唾别别人。第二，以为我们可以“教会”孩子批判性思维。

先来说第一个误解。其实，批判性思维不算是一个严格科学的概念，它包括一系列认知能力的集合，比如推理、判断与决策、问题解决这三类思维过程。往更细了说，包括预测、猜想、逻辑推断、验证假设、判断因果关系、形成观点、反思等诸多技能。

所以，不是去反驳别人的观点就是批判性思维，它是我们对思维的思考，是一个更加综合的认知过程。

第二点，我们是教不会孩子批判性思维的。你可能以为，批判性思维跟我们学用筷子一样，一旦你学会了怎么使用它，你就永远掌握了它。数十年的认知科学研究表明，批判性思维不是一套你学了就可以把它应用于任何情况下的技能。

说容易也容易，没有做过思维训练的三四岁小孩子就有，比如因果推理能力、对条件概率的判断力等一部分批判性思维能力；说难也难，就算是成年人也会在上面栽跟头。我问你一道简单的数学题，请你思考下，然后第一时间告诉我，答案是什么：

球和球拍的总价是1.1美元，球拍比球贵1美元，请问球的价格是多少？

很多人的第一反应是，0.1美元。可是你只要稍微想想，就会出现这个答案不对，球拍比球贵1美元，难道说球拍是1.1美元，总价不就是1.2美元了？正确的答案，球是0.05美元。

+   1. 积累一定的领域知识和实践
2. 在日常生活中教孩子使用批判性思维

人能批判性地思考，不代表他们能一直做到，比如背景知识、实践经验都会影响批判性思维能力。

在日常生活中教孩子使用批判性思维，详细来说是在具体情景和具体内容中教孩子，随时随地教。你不需要给孩子报专门的批判性思维班级，日常生活中玩耍的时候，亲子阅读的时候，都可以顺带着教他批判性思维技巧。
