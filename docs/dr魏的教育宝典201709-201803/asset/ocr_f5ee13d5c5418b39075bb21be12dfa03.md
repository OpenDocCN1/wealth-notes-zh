# 116 | 读者问答：如何培养孩子的合作精神？

Dr.魏
下周我将集中帮你解决两个问题：怎样培养孩子的数学推理能力？以及，怎样做好家庭性教育？

下周，你将了解到，孩子有两种数学能力，数学计算能力和数学推理能力。很多家庭、学校更重视孩子的计算能力，却忽略了他们的推理能力。其实，推理能力非常重要，孩子可以靠数学推理更早地做出加减法、乘除法，怎么做？下周Dr.魏告诉你。

另一个主题是关于性教育，这不是我的强项。但我跟你一样，理解你的焦虑。孩子只有更了解自己的身体，才会更懂得保护自己。下周Dr.魏与你一起讨论家庭性教育这个主题。
