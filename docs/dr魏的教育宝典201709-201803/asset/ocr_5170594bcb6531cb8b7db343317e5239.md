# 小师弟,你好

亲爱的宝爸宝妈，我是魏坤琳。今天我们的全年专栏《Dr.魏的家庭教育宝典》终于打造完毕了。祝贺你成为育儿育己的聪明显家长！

2017年3月14日，我在「得到」App上推出了为期一年、基于脑与认知科学的育儿宝典。面向0~6岁孩子的父母，围绕智力、语言、情绪、运动和创意五大脑，讲大家“听得懂”的脑科学原理，给“有效果”的育儿方法，用“科学实验”去弃“经验谈”，用“最新研究成果”破除“伪旧科学”。

截至今晚我写这篇稿件的时候，已有92089位家长加入了宝典！感谢你这一年的陪伴和学习，很高兴跟你一起学习、成长。

过去一年，在繁忙的科研与教学之余，我之所以还能坚持育儿科普，正是来自你的支持。一年来，每每查看留言，我总会被各位感动。有努力为每篇专栏文章的心得都整理为思维导图的爸爸；有尚在孕期，却已经开始为自己宝宝做准备的准妈妈；还有那些终身学习的爷爷奶奶姥姥姥姥他们。
