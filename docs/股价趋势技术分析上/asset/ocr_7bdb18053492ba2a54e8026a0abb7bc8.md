# 第13章 支撐與壓力

賣出力量，其數量足在相當期間內，止住價格的上漲走勢。所以，支撐／壓力觀念非常類似需求／供給，雖然意義不完全相同。

支撐價位（support level）是指某股票價位，該處存在充分的需求，至少足以暫時止住下跌走勢，甚至讓股價向上反轉。同理，壓力區域（resistance zone）是指某股票價位，該處存在充分的供給，至少足以暫時止住上漲走勢，甚至讓股價向下反轉。（每個價位的供給／需求相對數量，取決於當時市況，並因此決定趨勢。）可是，支撐代表需求匯集區域，壓力代表供給匯集區域。

根據前述定義，水平狀密集交易型態（例如：矩形）的上限代表壓力，下限代表支撐；上升三角形的上限代表壓力，以及其它等等。可是，我們現在想知道支撐／壓力發生的理由，並預測它們將發生在什麼價格區間。我們可以預測這點，或起碼可以在某種彈性範圍內辦到這點，但要允許某種程度的例外。有些圖形分析家可以精確預測價格漲勢将在哪裡遭遇壓力（供給），或跌勢將在哪裡獲得支撐。

我們之所以能夠做這類預測（推演支撐／壓力理論的基本資料根據），是因為股票交易有集中於某些價位的傾向，這些價位經常是股票過去大量換手的位置。任何發生大成交量的價位，往往是股價趨勢反轉的位置（包括主要、次要與小型趨勢），這些反轉價位具有「重複發生」的傾向。可是，此處有一個非常重要、有趣的觀念，很多業餘圖形分析者似乎始終搞不懂：重要價位的功能經常互換，可以由支撐變成壓力，也可以由壓力變成支撐。舉例來說，某個頭部壓力一旦被突破，將成為後續走勢的下檔支撐；同理，某個底部一旦被貫穿，將成為後續走勢的上檔壓力。
