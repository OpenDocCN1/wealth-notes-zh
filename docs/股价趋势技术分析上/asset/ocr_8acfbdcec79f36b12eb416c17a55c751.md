# 第 15 章 主要趨勢線

如果自行登錄月線圖，當然可以選擇任何時間刻度。可是，多數技術分析者會購買現成的長期走勢圖，因為這類圖形涵蓋期間很長，涉及眾多股票，實在很難自行登錄。只要價格選算可以的月線圖，大概都採用算術刻度；不論個人偏好採用算術或對數刻度，恐怕都沒有多大選擇，基於成本考量，只能使用這類圖形。編者附註：現在的情況已經不是如此了，市面上有很多套裝軟體，也有很多網路資源可供運用，請參考附錄D。對於主要趨勢呈現加速或減速發展的股票，採用建築繪圖的曲線尺特別有用。

關於如何檢查主要趨勢線的技術性重要程度，基本上可以考慮前一章對於中期趨勢線的說明。評估主要趨勢線的貫穿現象，需要維持較大的彈性，其中當然涉及濃厚的主觀判斷成分，但我們要瞭解目前處理的資料性質，月線價格行為屬於長期擺動，資訊比較粗糙；月線走勢圖提供宏觀的看法。

繪製主要上升趨勢線，還有一點需要注意：最佳（最有用）的趨勢線，起點不應該是前一個空頭市場的絕對低點，應該是新多頭市場的第一個中期底部。多頭市場剛開始的承接階段，走勢通常非常沉悶、乏味。如果第一條趨勢線銜接絕對低點，傾斜角度通常會太平坦，不能代表多頭市場的真正上升趨勢。本章提供很多範例都可以說明這點。編者附註：尤其是圖177。這項評論也適用於區域排列完成之後的中期走勢。不妨考慮頭肩底排列：真正的中期趨勢線，應該起自「右肩」，不是「頭」。
