# 第 1 3 章 支撐與壓力

大而變得模糊，然後產生新的關卡價位。空頭市場發生的恐慌性跌勢，經常為後續發展創造新的壓力區。這類跌勢完全「不尊重」先前任何支撐。（當我們討論道氏理論的主要擺動時，恐慌性走勢被歸類為空頭市場發展的第二階段。）恐慌性急跌走勢中，所有先前的潛在支撐區似乎都被一筆勾消，直到發生實壓高潮為止。可是，這類實壓高潮不一定發生在先前顯著的支撐區。繼續引用美國鋼鐵的例子，在 1937 年的恐慌性跌勢中，股價穿越 93～96 區域，在 78～80 稍做停頓，然後又一腳穿越 69～72 與 55～58 等支撐，最後終止於 50。1946 年的恐慌性走勢，也同樣一舉跌破 78～80 與 69～72 的重要支撐，最後終止於 66。

如果恐慌性跌勢底部爆發巨量，相關價位將代表顯著的「既定利害關係」，並構成重大壓力而妨害後續漲勢（換言之，空頭行情發展過程，回升漲勢很難穿越稍早的恐慌性跌勢底部）。

談及恐慌性走勢，很自然引導我們回頭考慮主要趨勢其他階段的支撐與壓力，這也是本章開始的討論內容，此處還要補充幾點。請記住壓力與成交量的關係。當漫長的空頭擺動到達最後低點時，成交量會明顯萎縮，倒數第二個中期趨勢底部，其供給相對偏低，所以新的上升趨勢在此只會發生些微折返。主要跌勢的末期階段，買家大多會向下分批承接，投資人早就有心理準備，預期價格將繼續走低，所以手中籌碼在回升過程不易被洗出來。主要多頭市場初期階段，行情發展非常緩慢，主要原因在於買盤不積極，不在於實壓沈重。

空頭市場恐慌性跌勢結束，回升走勢通常都沒有辦法拉高到主要下降趨勢構成的壓力區（這通常是指循環絕對峰位發生之後第一個中期下降趨勢底部），因為在此之前經常會先遭逢前一個多頭市場的壓力區。因此，碰到這類情況時，應該回頭觀察先前循環的走勢。
