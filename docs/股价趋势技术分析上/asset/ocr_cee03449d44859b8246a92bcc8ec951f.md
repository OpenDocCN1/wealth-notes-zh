# 單日反轉

本書第6章曾經提到「單日反轉」（one—day—reversal）型態，這種反轉排列本身只有暫時性意義，或代表小型趨勢的反轉。沒錯，這種排列也可能發生在長期漲勢的峰位，例如：頭肩頂的頭部，隨後並展開長期跌勢；可是，請注意，隨後跌勢是來自於頭肩頂排列，單日反轉實際上只代表「頭部」完成。舉例來說，單日反轉可能發生在等腰三角形排列的第一個小峰位，隨後只出現整理走勢，沒有發生趨勢反轉。雖說如此，但這種技術型態還是可以警告我們，顯示多頭氣勢
