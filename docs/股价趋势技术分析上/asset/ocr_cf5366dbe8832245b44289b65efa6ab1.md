# 第17-B章 投資科技進展

讀者應該可以立即體會這種策略的效益。現貨投資組合可以繼續持有，不會引發稅金問題；另外，如果必須先結束現貨部位，稍後重新建立部位的話，勢必會發生滑移價差、失誤……等問題。長期投資部位最好還是不要亂動。透過對應的期貨空頭部位來規避風險，不只可以確保投資組合的未來價值，而且相關資本還可以賺取貨幣市場報酬。

如果預期的跌勢確實發生，那該如何呢？投資組合可以得到保障，相關資本可以賺取市場報酬率。可是，投資人要密切觀察行情的演變，一旦修正走勢結束時，就要沖銷期貨空頭部位。這個時候，期貨的資本利得當然有稅金問題。

追蹤避險操作的过程，必須考慮行情不跌反漲的情況。當初規劃期間，就應該考慮這種可能性，預先決定如何解除錯誤的避險部位。最糟的情況，是拿現貨部位的獲利，來彌補避險部位的損失。這當然沒有考慮現金流量的影響。

關於這種策略，或許值得強調（或特別強調），相關操作需要專業知識與研究分析。草率運用這類技巧，可能會讓業餘投資人陷入困境。所以，剛開始做這方面操作時，最好有專家指導，事先也要先做模擬交易。

精明投資人可以運用指數期貨契約來強化行情的暴露程度，但這種作法可能讓投資人變成受傷的投機客。由於期貨交易具備的信用擴張能力，所以只適合於有經驗的投機客運用。
