# 股價趨勢技術分析（上冊）

跌到4或$3 \frac { 1 } { 2 }$，雖然損失高達30%，但投資人或許不會很緊張，因為「股價點數」損失很少，他相信股價還是很容易回到6或7；所以，投資人願意等待。

關於跌幅距離的準則，還有一點需要考慮。繼續引用先前討論的PDQ例子，如果股價由20反彈到24之後，價格一路跌到12，不只在20買進的投資人覺得氣憤而希望解套出場，在12買進的人也希望在20獲利了結（66 $\frac { 2 } { 3 } \%$利潤）。然而，在18買進的投資人，還不會急著想在20賣出。

評估就有底部壓力動道的第三個準則，是考慮該底部發生之後的時間長度，以及這段期間內的整體市況。舉例來說，如果行情由堅實的主要底部回升，當既有漲勢遭遇4、5年前主要空頭市場趨勢的中期底部，此處的壓力應該不會太大。在某種程度內，這種說法確實有道理。發生在1、2年前的底部，其壓力應該大於4、5年前的底部，但我們也不能全然忽略後者的潛在威脅。事實上，某些發生在很久之前的底部，也可能夠成嚴重壓力，如果它們從來沒有被「測試」，而且股票發行公司資本結構也沒有變動而模糊投資人的持股成本。後者是指公司進行股票分割或分派大量股票股利，甚至是發放大額的現金股利。當然，我們不是說股票分割或發放股利之後，投資人就會忘記當初的持股成本，但他們的「怨恨」（以及解套慾望）多少還是會緩和一些人。

可是，如果壓力區曾經被「測試」（換言之，價格曾經回升，試圖攻擊，但無功而返），這會釋放一部份壓力。過去發生的攻勢，會驅散上檔的某些壓力。因此，第二波攻勢在此需要消化的籌碼比較少。同樣地，我们也可以透過成交量圖形，估計被消耗的買壓。無論如何，如果第三波攻勢再來過壓力區，成功貫穿的勝算總是較大一些。
