# 兩個或以上的逃逸缺口

在後文討論竭盡缺口的性質之後，比較容易區別逃逸缺口與竭盡缺口之間的差異。在此之前，我們還需要討論一種可能性：快速走勢過程夾雜著2個或3個缺口（後者很罕見），而且都屬於逃逸缺口。這類情況並不常見，尤其是那些交投熱絡的大型股，但小型股的飆漲走勢很可能發生3、4個逃逸缺口。碰到這種情況，具有實務重要性的問題只是：衡量中心究竟應該擺在哪裡？這個問題沒有明確的答案，也沒有可靠的法則可供運用，只能詳細研究走勢圖，尤其是成交量型態。請記住，中心點通常都是在走勢發展最順暢的地方（就價量關係而言）。如果有2個缺口，中點位置可能在2個缺口之間。仔細分析走勢圖，想辦法讓腦海浮現整個結構的「平均」狀態：觀察「稀薄成交量」的中心點，以此作為衡量基準。可是，請注意，每多出現一個缺口，該缺口就愈可能是竭盡缺口，所以判斷最好保守一點；不要對第2或第3個缺口抱太多期待。
