# 道氏理論的「訊號太遲」

首先，讓我們談論一種頗有根據的反對看法。這種意見往往透過很激烈的方式表達：「道氏理論確實很穩當，投資人必定會錯過每個主要趨勢最前面的三分之一行情，以及最後面的三分之一行情，有時候則根本沒有中問的三分之一行情。」或者，利用前一章的實際例子說明：主要多頭市場起始於1942年，當時的工業指數是92.92，行情結束於1946年，工業指數為212.50，總漲幅為119.56點；對於嚴格遵守道氏理論的投資人來說，唯有當工業指數上漲到125.88才肯買進，也只有等到指數跌到191.04才會賣出，頂多能夠掌握65點左右的漲幅，大約是整體走勢的一半。我們沒有辦法反駁這個例子。可是，就一般性的反對意見來說，我們的回答是：「有多少人可以在92.92買進股票（容許5點誤差），然後持有全部的股票，最後在212.50賣出（也容許5點誤差）。」我們相信，很少人可以辦到這點。事實上，很少投資人的表現可以勝過道氏理論。
