# 第 14 章 趨勢線與通道

續上漲。反之，平坦的趨勢線（接近水平狀的趨勢線）比較具有技術意義，一旦跌破之後，也較容易產生嚴重後果。

可是，所謂的「陡峭」，只有相對意義，尤其是個別股票；我們不能提供明確的定義。唯有透過長期觀察，深入研究衆多股票的實際走勢，分析股票在各種市況下的反應，才能累積足夠的經驗，直覺判斷何謂「太過陡峭而不能維持」，評估哪種發展角度比較合理，能夠維持到中期上升趨勢向下反轉為止。另外，每支股票的趨勢線斜率，也必須參考其特殊「股性」。除此之外，初級（主要）趨勢循環的不同階段，也可能構成不同背景，後期階段的趨勢線，通常比較陡峭。處理任何特定股票的時候，應該儘可能回顧過去的歷史，才能精確判斷目前的趨勢發展。

（最後補充一點，前一段有關趨勢線的評論，同樣也適用於多數其他技術型態與現象的解釋。）

如果走勢圖繪製在TEKNIPLAT的半對數方格紙（本書提供的走勢圖大多如此），我們可以提供趨勢線斜率的參考數據。對於價格位在10～50之間的股票，日線圖中期趨勢線張開的角度，大多保持在30度左右。有些會稍微陡峭，有些則會稍微平緩，但對於一般價格波動程度與正常流動性的股票來說，中期趨勢線大致上都維持30度的張角。高度投機性的小型股，或深具投資價值的大型股可能是例外，前者的趨勢線通常比較陡峭，後者則比較平緩。不論股價水準如何，半對數方格紙可以把股價走勢轉換為比率或百分率基準。如果採用算術刻度的方格紙，股價在50附近與15附近的趨勢線斜率顯然不同，前者比較陡峭，後者比較平坦。
