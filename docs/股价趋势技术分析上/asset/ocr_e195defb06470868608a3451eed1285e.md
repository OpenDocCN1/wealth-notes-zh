# # 第12章 跳空缺口

所謂的「跳空缺口」(gap)，是一段沒有交易發生的價格區間（線形發生當時）。這是很重要的觀念，因為有助於解釋隨後產生的某些技術性發展。

就個別股票日線圖來說，如果某天的最低價高於前一天的最高價，或某天的最高價低於前一天的最低價，走勢圖就會呈現跳空缺口。換言之，兩天的線形之間，有一部份沒有重疊，這個沒有重疊的部分，就是缺口。同理，如果某週最低價高於（最高價低於）前一週任何一天的最高價（最低價），週線圖就會產生缺口。週線圖雖然會出現缺口，但發生頻率低於日線圖，理由非常明顯。至於月線圖，交易活絡的個股，很少出現缺口；偶爾發生缺口，通常都是因為月底出現恐慌性下跌，而且跌勢持續到隔月初。
