# 道瓊指數期貨選擇權

這種工具的持有人，可以決定（或有權利決定）是否建立根本資產的部位。換言之，他有選擇權決定要不要這麼做（請注意，期貨契約持有人則有義務這麼做）。選擇權有兩種類型：買權（calls），持有人有權利買進根本資產）與賣權（puts，持有人有權利賣出根本資產）。目前討論的選擇權，其根本資產是道瓊指數期貨，所以持有人有權利買進或賣出（放空）期貨。

道瓊指數期貨的買權，其持有人有權利在選擇權到期之前，按照特定價格（稱為「執行價格」或「履約價格」）買進道瓊指數期貨。同理，賣權持有人有權利在選擇權到期之前，按照履約價格賣出道瓊指數期貨。舉例來說，如果買權的履約價格為10000，持有人有權利按照10000買進期貨。道瓊指數期貨的選擇權，履約價格的間隔為100點，交易者可以根據他認為恰當的履約價格建立選擇權部位。

買權或賣權的賣方，稱為銷售者（writer）。一般來說，買權銷售者希望根本資產行情下跌，賣權銷售者則希望根本資產行情上漲。選擇權賣方如果決定執行其買進或賣出根本資產的權利，選擇權賣方則有履行契約的義務（這與期貨空方的立場一樣）。如果你銷售買權，一旦買方執行買權而建立道瓊指數期貨的多頭部位，你就必須建立對應的空頭部位。反之，如果銷售賣權，則買方執行選擇權將建立期貨空頭部位，你就必須建立對應的多頭部位。
