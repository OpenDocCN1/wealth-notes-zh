# 股價趨勢技術分析(上冊)

般大眾過度擴張信用而融資買進股票，大量拋空可以讓股價暴跌。然後，經紀商會追繳保證金，許多投資人沒有能力或不願補繳現金，於是斷頭賣壓湧入市場，造成股價進一步下挫。這個時候，專業玩家可以獲利回補空頭部位，並低檔承接籌碼，等待隨後的股價反彈。雖然證管會已經禁止這類 的「空襲」行為，但只要繼續維持融資買進的管道，只要股票市場曾經飆漲而隨後大跌，追繳保證金與斷頭賣壓就會造成重大影響。
