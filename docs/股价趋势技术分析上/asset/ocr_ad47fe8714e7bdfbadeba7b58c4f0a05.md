# 選擇權

1973年，費雪·布莱克（Fisher Black）與其同事麥隆·薛里斯（Myron Scholes）共同發表選擇權訂價模型的相關論文，從此奠定了衍生性產品的訂價基準，也讓這個市場由一無所有，成長為數以兆計的規模。投資人如果不瞭解選擇權，等於是玩半副牌而已。可是，這個主題已經遠超過本書準備處理的範圍，此處只希望提供一些概略性的討論，指引有興趣的讀者做更深入的研究。

選擇權大約有30%或以上，最後會過期沒有價值。關於選擇權交易，這可能是最值得重視的一項事實。（選擇權有所謂的60－30－10準則：發行的所有選擇權之中，大約60%在到期之前平倉，10%會執行，剩下的30%則過期沒有價值。）另外還有一個事實需要注意：1987年崩盤期間，10月16日按照$0.625價格購買的價外賣權，到了10月19日，價格上漲到每股數百美元（如果你有辦法讓經紀人接電話的話）。（編者有位客戶，當時任職於選擇權研究股份有限公司[Options Research, Inc.]，3天之內虧損$5,700萬，差點讓芝加哥某家銀行因此倒閉，因為他裸露銷售太多賣權了。）

最精明的專業交易者，其生計（非常不錯的生計）是來自選擇權買賣。一些頗有根據的估計顯示，一般從事選擇權交易的散戶投資人，大約有90%發生虧損。另外，一般投資大眾只懂得購買選擇權，不懂得銷售。這兩個事實，似乎可以說明那些選擇權專業交易者為何能夠賺大錢。
