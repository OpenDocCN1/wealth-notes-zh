# 股價趨勢技術分析（上冊）

多深才算深？多長才算長？這都是很合理的問題；不幸地，這個問題沒有簡單、明確的答案。可是，我們可以做些嘗試。如果兩個價格峰位相隔一個月以上，屬於相同整理排列或交易區間的 possibility 相對很小。另外，第一個與第二個峰位所夾的價格折返走勢，其幅度如果超過峰位的20%，雙重頂發生的機率就很高。當然，這兩個準則都不免有武斷成份，顯然不適用於每種情況。某些雙重頂排列的兩個峰位，可能只相隔2、3個星期，谷底的深度只有15%。可是，多數有效的雙重頂排列，兩個峰位的相隔期間，經常是2、3個月或更長。一般來說，峰位相隔的時間長度，其重要性超過折返深度。兩個峰位相隔的時間愈久，中間的折返深度也可以愈淺。

總之，在下列條件下，我們有理由懷疑雙重頂排列。兩個頭部發生在約略相同價位，時間相隔一個月以上，第二個峰位的漲勢成交量，不如第一個峰位的漲勢，中間折返走勢相當沈悶，成交量型態不規則，價格折返呈現弧狀。如果第二個峰位是由小型頭肩頂或下降三角形形成（經常如此），更必須提高警覺，多頭部位應該調整停止價位，或換股操作。

可是，即使前述條件都完全具備，也不一定代表最後結論。情況可能還有轉機，而且經常是如此。我們不妨觀察前述價格走勢發生的原因。第一個頭部出現偏高的成交量，這是很正常的現象，顯示「需求遭遇龐大供給，價格停止上漲，並且回檔」，除此之外，沒有特殊意義。上檔供給籌碼，可能只代表短線交易的獲利回吐實壓；若是如此，價格稍做回檔之後，還會繼續上漲。可是，如果回檔的價格愈盤愈低，幅度超過峰位價格的15%以上，然後逐漸走平而沒有強力反彈，這代表前一波漲勢的需求已經獲得滿足，或供給籌碼不只是獲利回吐的短線實壓。現在的問題是：第一個頭部是否有明顯的出貨徵
