# 股價趨勢技術分析(上冊)

除了「勁道」之外，突破缺口並沒有特殊衡量意義，也沒有其他預測功能。接下來，另一個問題是：我們是否應該預期突破缺口在短期內被填補？或者，把話講白一點：我們是否應該延遲進場，因為重大走勢應該發生在缺口被填補之後？

![](bbox=[0.11, 0.27, 0.86, 0.68])

為了提供合理答案，我們必須深入觀察缺口發生之前與之後的成交量情況。如果缺口之前發生大量，而缺口之後的成交量相對萎縮，則隨後發生的小型折返，大約有一半機會回到型態邊緣而封閉缺口。反之，如果缺口之後爆出大量，價格夾著大量遠離缺口，則短期內填補缺口的可能性就不大。這種情況下，折返走勢通常只會觸及缺口的外側。

（關於技術分析的結論，大家都希望採用「必定」、「絕對不會」
