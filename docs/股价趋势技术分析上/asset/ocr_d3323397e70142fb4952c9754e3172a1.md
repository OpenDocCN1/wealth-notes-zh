# 股價趨勢技術分析（上冊）

前文討論三重頂時，曾經提到某種透過經驗累積的直覺，可以讓圖形分析者在排列進入結論性階段之前，察覺圖形可能出現的進展。這不是什麼罕見的能力，但需要經過深入研究與長期培養（甚至還包括代價昂貴的嘗試錯誤）。本書讀者也可以取得這種「判讀能力」，而且不需要支付不必要的代價，只要專心研究、觀察、核對與再核對發展中的走勢，並記錄自己的心得。

圖形判讀經常被認定為一種藝術，不是科學。圖形分析顯然不是精確的科學，因為任何法則都有例外；真正微妙之處，甚至不能歸納為法則或教條。圖形判讀通常需要根據許多因素進行評估與判斷，而且這些因素代表的意義，可能彼此衝突。可是，把圖形分析視為藝術也不太恰當，因為藝術往往蘊含「天生才能」，或至少涉及某種天生才華。事實上，圖形分析只需要一些技巧，而且任何具有正常心智的人，都可取得這方面的必要技巧。
