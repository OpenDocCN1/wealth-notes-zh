# 股價趨勢技術分析（上冊）

價格不只是反映眾多正統分析師的價值看法，還包括無數潛在買方與賣方的期待、恐懼、猜測，以及不理性或非理性的情緒，還有他們的需要、智慧與財力。這些因素未必會認同正統分析師對於價值的看法，我們也無法取得這些因素的任何統計數據，但它們整體將會互相結合與加權，最後彙整為單一數據，這也是買、賣雙方（透過其代理或股票經紀人）完成交易的價格。而且，這也視為一實數的結論。

另外，技術分析者還有一項合理主張。基本分析者考慮的絕大部分統計數據，都屬於歷史資料，已經過時而不再有影響力，因為市場不關心過去，甚至不在意目前！市場永遠向前展望，試圖反映未來的發展；無數投資人各由不同角度與立場觀察未來，他們的估計與猜測，將透過市場機制而整合。總之，市場本身所認定的價格，將涵蓋所有基本分析的資訊，這也是統計分析者研究的對象（再加上基本分析者不知道的內線消息），以及無數其他統等重要或更重要的資訊。

任何有經驗的玩家，都不能否定一項事實：價格變動具有趨勢，而且該趨勢將繼續發展，直到某些事故改變供需之間的均衡。這類變動通常都可以由市場本身的行為中觀察。圖形上存在一些具有意義的形態或排列、水準或區域，它們可以被解釋，然後評估未來趨勢的可能發展。請注意，這並不是萬無一失的方法，但具有顯著的勝算。透過時間與經驗的證明，這些技術的預測功能，遠超過最精明、資料最完整的統計分析。
