# 整數價位

某些價位即使過去沒有發生「既定利害關係」，也同樣會產生明顯的壓力／支撐。我們需要特別注意某些整數價位，例如：20、30、50、75、100……等。買進股票的時候，我們往往很自然地把獲利目標設定在整數價位。如果某支股票由10上漲，20通常會發生相當可觀的獲利了結賣壓，尤其是相關整數價位也代表多年來高價的話。事實上，任何股票只要創歷史新高價，上檔就是海闊天空；碰到這種情況，整數價位都代表顯著賣壓。對於一些老牌而交易活絡的股票，整數價位相對上比較不重要，例如：美國鋼鐵（編者附註：IBM或奇異電器）。

# 重複發生的歷史價位

重要的支撐／壓力一旦形成，通常會長期發揮作用；在不同的多、空循環過程，我們發現中期趨勢的頭部與底部，經常重複發生在相同價格區間。事實上，許多老牌大型股，都具有很明顯的這類現象。舉例來說，奇異電器在整個1920年代到1950年代之間，下列價位經常爆出巨量：22～24、34～35、40～42與48～50；因此，中期趨勢反轉也經常發生在這些區域。同樣，南太平洋（Southern Pacific）在下列價位也有明確支撐／壓力：21～22、28～30、38～40與55～56。美國鋼鐵的重要反轉也經常發生在42～45、55～58、69～72、78～80與93～96等區間。第9版附註：某些個股或許已經不存在，但相關原理仍然有效。
