# 第15章 主要趨勢線

前一章討論中期趨勢線的過程，曾經提到算術刻度與半對數刻度造成的差異，但這些差異對於一般時間長度的小型或中期趨勢線，不會造成太大影響。可是，對於主要趨勢來說，這些差異就很顯著了。

觀察算術刻度的月線圖，如果涵蓋期間在10年以上，則多數交投熱絡而多少帶點投機成份的個股，多頭趨勢都有加速發展的傾向。上漲趨勢最初很平緩，但愈接近主要頭部，漲勢就愈來愈陡峭。這種開口向上的曲線狀走勢，使得價格軌跡愈來愈遠離最初上漲階段繪製的趨勢線。因此，當主要趨勢做頭之後，需要經過一段相當大的跌幅，才會觸及上升趨勢線。

許多股票的主要漲勢，在算術刻度圖形紙上，呈現典型的加速狀曲線，如果繪製在半對數圖形紙上，則顯示直線狀趨勢。因此，當漲勢在偏高價位做頭而下跌之後，將提早跌破對數圖形紙的主要趨勢線。對於這類股票來說，採用對數刻度圖形紙，可以提供比較理想的訊號。
