# 股價趨勢技術分析(上冊)

突破之後的立即折返走勢。這類型態一旦發生有效突破，強勁的壓力就已經形成。

![](bbox=[0.13, 0.19, 0.88, 0.54])

圖144. 這是1945年的日線圖，顯示幾個等腰三角形支撐的例子。2月5日，價格突破第一個等腰三角形排列，時間明顯落後（太接近三角形頂點），隨後的整理走勢是以1月中旬的頭部為支撐，比較嚴重的折返走勢發生在2月26日，價格退回三角形頂點水準。這是關鍵時刻，三角形頂點本身即是重要支撐（壓力），其功能將因時間經過而減弱。目前，整個盤勢可能發展為「收場」走勢，多頭部位應該在三角形頂點下方設定停損（參考第27章）。可是，就目前這個例子來說，價格並沒有跌破支撐，繼續形成另一個「螺旋」，並在3月10日向上突破。正如同預期的，這個三角形的上限變成隨後走勢的下檔支撐。3月中旬到4月底之間，形成上升三角形排列，上限成為6月份走勢的支撐，但7月份跌破支撐。請回頭對照圖120。
