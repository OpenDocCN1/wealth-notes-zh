# 突破缺口

突破缺口與價格密集交易區之間也有關連，這類缺口經常發生在排列完成的價格突破過程。當價格突破水平狀態邊界（例如：上升三角形的上限），很可能是以缺口方式進行。對於上限水平狀的價格排列，我們如果稍微考慮型態發生的背景，就不難理解突破缺口產生的原因。舉例來說，上升三角形之所以產生，是因為持續性需求遭逢某固定價位的賣壓。假定賣壓發生在40，其他原本希望在$40 \frac{1}{2}$或41賣出股票的人，見到價格每上漲到40就折返，經過幾次來回之後，可能也改變主意，把賣價調整到40，或乾脆調高賣價。結果，40的稍上方將形成「真空」地帶。所以，只要上升三角形在40的賣壓被消化完畢，型態緊上方可能沒有任何賣壓；換言之，沒有任何賣盤掛在$40 \frac{1}{8}$或$40 \frac{1}{4}$。如果買方希望取得股票，就必須提高買價，於是產生突破缺口。

本章稍早曾經提到，這類缺口經常發生在水平狀密集交易區的有效突破過程，但缺口經常沒有顯示在日線圖上，因為它們發生在盤中，而不是某天收盤與隔天開盤之間。另外，突破缺口也經常發生在其他反轉或整理型態的穿越過程；舉例來說，頭肩排列就經常以缺口方式突破頸線，趨勢線貫穿也經常透過突破缺口完成（我們稍後會討論趨勢線的問題）。
