# 股價趨勢技術分析（上册）

相反地，修正擺動可能發展為很規律的直線狀折返，斜率中庸，朝最近的中期支撐或壓力區移動，折返幅度可能是前一個主要擺動的三分之一或一半。這些折返走勢會呈現不錯的趨勢線，最後進行穿越而發出理想的技術反轉訊號。可是，我們必須強調一點，如此規律的中期修正走勢相當罕見。

中期修正還有第三種發展方式，其普遍程度類似第一種（整理型態），發生頻率高於第二種。行情處在多頭市場，首先發生幾天或長達2個星期的急跌走勢，出現很陡峭的小型趨勢線。接著，一個快速的小型漲勢向上突破趨勢線，然後價格再度拉回，但跌勢不如先前猛烈。這個時候，我們可以繪製第二條小型趨勢線，銜接最高高點與價格突破第一條趨勢線的漲勢峰位。不久之後，又產生另一波小型漲勢而突破第二條趨勢線，然後價格還是拉回，出現更緩和的跌勢。於是，我們可以繪製第三條小型趨勢線，銜接最高高點與價格突破第二條趨勢線的漲勢峰位。整個修正走勢呈現相當不規則的連續弧狀漲勢。由修正走勢開始的最初反轉高點，我們所繪製的三條趨勢線愈來愈平坦，這即是所謂的「扇形線」（fan lines）。就技術法則而言，當第三條扇形線被向上突破時，中期修正走勢已經見底。

如同任何技術分析法則一樣，這個法則也有例外。在某些罕見的情況下，前述修正走勢可能出現另一波下跌，然後才開始向上發展。然而，一般來說，三條扇形線的法則通常適用。另外，交易者利用這種機會建立的部位，可以採用非常緊密的停損，防範法則失敗。
