# 1/8美元與12.5美分

本版發行的時候，金融界又揚言要改採十進位計算的小數計算股價。過去，股價採用1/8為一檔，因為這種計價方式對於業者比較有利，允許經紀人與專業報價商賺取較大的報價碼差。對於本書與股票交易來說，改採十進位小數報價自然有其重要性。馬基建議停損應該設定在高價或低價外緣的1/8處，追蹤性停單也採用1/8間隔。改採十進位小數報價之後，究竟會造成什麼影響，我們還不太清楚，心理上的計價單位將是12.5美分、10美分或其他的9美分或11美分，還有待進一步觀察。至於本書的走勢圖，則仍然引用過去版本的計價單位。

# 編者代名詞「我」

讀者將發現，馬基與愛德華都自稱「我們」，而本人則自稱「我」，這應該不會造成混淆，因為他們兩位採用複數的「我們」，本人則採用單數的「我」。至於用「我」來強調「自我」，讀者可以放心，因為在金融市場混了40年，已經沒有剩下多少「自我」了。有關編輯的立場，或許可以引用強森博士（Dr. Johnson）對於字典編輯者的定義。有些人認為，強森博士的重要性，完全來自於他編輯的字典。「字典編輯者，就是字典的作者。是一份無害而沈悶的工作。」我扮演的角色大概如此。
