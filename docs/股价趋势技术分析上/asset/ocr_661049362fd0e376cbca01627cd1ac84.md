# 股價趨勢技術分析 (上冊)

上，將是一條斜率愈來愈陡峭的曲線。

前述考量，對於小型趨勢來說，並不會造成太大影響，因為小型趨勢涵蓋的期間很短，不足以凸顯兩種刻度產生的差異。這種說法也適用於正常斜率的一般中期走勢。可是，如果中期走勢非常強勁，涵蓋期間很長，則在兩種不同刻度之下，趨勢線突破的時間與價位，將有顯著的差異。這也是為什麼我們建議技術分析應該採用半對數方格紙繪製價格走勢圖的原因所在。關於這方面的差異，我們準備延遲到主要趨勢中討論，目前暫時假定這兩種刻度對於中期趨勢不至於造成影響。另外，目前是以中期上升趨勢為討論重點。（我們強調中期趨勢而不是小型趨勢，理由很明顯，因為小型趨勢不論在交易或投資實務上，都沒有深入研究的意义。）

如果價格漲勢呈現直線狀趨勢，我們可以繪製直線來界定相關的趨勢，如此將具有下列兩種功能：

+   1. 趨勢線一旦被貫穿（換言之，價格有效跌破趨勢線），代表漲勢結束的訊號，中期交易者應該換股操作。

+   2. 價格走勢如果出現小規模頭部反轉排列，但與中期上升趨勢線還有一段距離，反轉走勢暫時不會威脅趨勢線，中期交易者可決定不理會這類小型反轉排列。只要趨勢線沒有跌破，就可以繼續持有多頭部位。

前述第一點效益很明顯；至於第二點，沒有經驗的交易者或許不能體會其功能，但實務操作上對於投資人很重要，如果某支股票還具有中期上漲潛能，只因為小型回檔而換股操作，所涉及的交易成本往往太高。
