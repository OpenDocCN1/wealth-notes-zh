# 股價趨勢技術分析 (上冊)

![](bbox=[0.12, 0.1, 0.88, 0.65])

圖112．多頭市場第三階段的漲勢過程，出現一系列旗形整理。1936年的6個月期間內，股價由15上漲到39，然後回跌到31，接著在1937年3月重新站上先前高價，主要趨勢演變為雙重頂。（1937年進行股票分割，1股分割為2股）。7月份到8月份之間的旗形排列，期間涵蓋5個星期，整理時間太長，除非有其他技術面配合，否則不足採信（請參考「可靠性」一節內的第3點）。這些拖延過久的整理排列，通常不可靠，往往突破之後缺乏跟進力量，甚至不能進行突破而價格愈盤愈低，直接下滑。就目前案例來說，當價格向上突破時（8月25日），旗形看起來已經發霉，但價格向上穿越排列高價時（8月27日），成交量開始漂亮放大，進場買進相當安全。
