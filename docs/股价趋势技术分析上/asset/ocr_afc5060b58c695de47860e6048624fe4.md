# ### 矩形、雙重頂與三重頂

如同第8章說明的，三角形排列可能是反轉型態，也可能是整理（連續）型態。對於直角三角形來說，一旦排列形狀明朗化之後，我們就知道趨勢將（或應該）朝哪個方向突破。至於等腰三角形排列，在實際發生突破之前，我們不知道突破的方向（不過多數情況會朝排列發生之前的趨勢方向進行突破）。就突破方向與其他性質來說，矩形（rectangles）排列非常類似三角形。事實上，由於兩者之間的性質很類似，我們沒有必要詳細解釋矩形排列。

矩形是由一系列橫向價格波動構成（通常也稱為「交易區間」，trading area），波動轉折峰位與谷底都可以分別銜接為水平狀直線，用以界定矩形排列的上限與下限。讀者只要隨意瀏覽本章的範例，就可以瞭解其名稱由來。某些情況下，矩形排列的上限與下限，可能稍微向上或向下傾斜，即使上限與下限看起來有彼此收斂的傾向，因此很難斷定型態究竟屬於矩形或等腰三角形，那也無關緊要，因為兩者
