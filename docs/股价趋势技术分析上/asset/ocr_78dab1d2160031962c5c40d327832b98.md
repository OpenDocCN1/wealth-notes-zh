# 股價趨勢技術分析(上冊)

則11月份發生的重挫走勢，理當代表空頭市場的訊號。可是，根據我們的瞭解，沒有任何道氏理論專家認真考慮這種可能性。如同前文說明的，7月份跌勢本身並不足以構成中期走勢，不論就發展期間或回檔點數來考量，結論都相同；由1943年7月到11月的整體走勢，應該代表單一的次級折返。主要趨勢的真正測試，將來自次一波漲勢（不論何時發生）；如果這波漲勢不能向上穿越7月份的峰位，而且價格回檔創新低，則行情將近入空頭市場。

相關結論的發展步調很緩慢。價格又開始回升，但工業指數的漲勢相當蹣跚。鐵路指數的延遲速度稍快一些；1944年2月17日，價格向上突破7月份高點，3月21日在40.48形成小峰位。3月13日，工業指數攀升到141，但距離「訊號」水準還差5點，價格又拉回。這又是另一個「缺乏確認」的例子。如果技術分析者重視背離，這種現象往往可以被解讀為非常明顯的空頭意涵。可是，背離代表的意義，實際上很單純：主要多頭市場的連續走勢還沒有得到確認。唯有當兩個指數都下跌，收盤價分別跌破11月30日的底部，如此一來，鐵路指數在2月份單獨所創的新高才失去意義，行情也正式進入空頭市場。總之，3月底的情況，無異於1月初鐵路指數還沒有突破7月份高點之前的情況，至少就主要趨勢而言是如此。
