# 下降三角形

下降三角形（descending triangles）具有水準狀的下限（需求線）與向下傾斜的上限（供給線）。這種排列的發生背景，剛好與上升三角形相反。兩種三角形排列同樣具有重要的技術意涵，失敗情況也同樣少見。排列發展過程中，某個集團或機構（經常是投資信託基金。第九版附註：共同基金或購併集團）試圖在市價之下某特定水準取得大量股票，如果這些買盤引發的漲勢，在上檔遭遇壓力的價位愈來愈低；股價走勢圖就可能呈現下降三角形排列；一旦該特定價位的買單被耗盡，下降三角形排列就會向下突破。由於這個特定價位被市場視為長期支撐，當該價位被突破之後，勢必嚴重影響持股者信心，原本不打算賣出的人，也開始加入追殺股票的行列，終於導致行情加速下跌。

# 成交量性質類似等腰三角形

直角三角形的成交量型態，基本上類似等腰三角形，所以不需另做評論。價格朝三角形頂點發展的過程，成交量將萎縮。上升三角形通常會呈現價漲量增、價跌量縮的傾向；下降三角形的情況則相反，但經常不是很明顯。可是，排列突破之前，這類價量關係不會影響成交量萎縮的整體傾向。
