# 第 14 章 趨勢線與通道

筆直的直線上。

前述這兩條直線（上升趨勢一系列連續波浪底部銜接而成的向上傾斜直線，以及下降趨勢一系列連續波浪峰位銜接而成的向下傾斜直線），稱為基本趨勢線（basic trendlines）。

不幸地，我們沒能找到一個更具特色的字眼，而被迫採用這個陳腔濫調的「線」（「線」還有許多其他用法與意涵）。某些分析家稱其為「切線」（tangents），雖然頗具創意，但此處的用法顯然不符切線的原意，所以也可能造成混淆。「切線」或許會逐漸成為這方面的專有名詞。可是，我們暫時恐怕還需要採用這個遭到濫用的「線」，但不妨在前面冠上「趨勢」而成為「趨勢線」，如此或許有助於區別。

各位或許聽過一種說法：「趨勢線是專供被跌破的」，這種描繪太過誇張，完全沒有正面意義。趨勢線當然會被跌破，趨勢線最終都會被跌破，某些的壽命甚至非常短暫。問題是：如何判定哪些趨勢線突破具有重大技術性意義？哪些不至於構成重大影響，只需要稍微修改原先繪製的趨勢線即可？這些問題沒有明確而單純的答案；某些趨勢線貫穿，當時沒有辦法判斷其意義，必須等待後續發展提供確認。可是，多數情況下，我們很容易辨識重要的突破，立即取得相關資訊，進而調整交易策略。
