# 指數或期貨選擇權

選擇權可以用來投機或避險。舉例來說，在一段突兀漲勢之後，某投資人認為他做多的S&P 500或S&P存託憑證（SPDRs）進入超買狀態。於是，他可以購買S&P的指數權權，防範預期中最可能發生的跌勢。如果股價真的下跌，選擇權部位可以獲利，而原先持有的S&P部位繼續存在。反之，如果股價指數繼續挺進，他將損失選擇權的權利金，這等於是為了防範股票投資組合發生損失而支付的保險費。

附註：前述策略只是提供給讀者參考的概念。實際採取這類策略或任何陌生程序之前，投資人務必要徹底瞭解相關資訊，透過模擬操作重複演練，測試各種可能發生的結果，然後才可以實際投入資本。總之，投資人必須搞清楚可能發生哪樣的損失。很多網站提供這類服務，投資人也應該在電腦中另外建立模擬投資組合，不要與實際交易混在一起。
