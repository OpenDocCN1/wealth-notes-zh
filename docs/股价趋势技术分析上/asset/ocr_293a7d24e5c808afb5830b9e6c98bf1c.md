# 股價趨勢技術分析(上冊)

當然，整個發展的關鍵，在於前一段的兩句話。需求推升的價格必須愈來愈高，否則相關排列將不是上升三角形。另外，上檔籌碼最後必須被消化，造成向上突破。在供給線（水平牀上限）被突破之前，如果需求開始減退，折返走勢的低點將愈來愈低而「破壞既有型態」，技術分析者當然需要重新繪製與評估走勢圖。讀者或許認為，這種違背先前兩個前提的發展可能經常發生；可是，根據經驗顯示，這類情況少得令人覺得訝異。我們說「令人覺得訝異」，因為在上升三角形排列過程，上檔造成供給線（排列上限）的賣方，他們很有把握該水準是合理的賣價。手中持有大量籌碼的重要玩家，他們可以影響行情數個星期或數個月，其判斷就不可以被忽略。所以，一旦需求線（排列下限）向上傾斜，上升三角形十之八、九得以完成。

某些情況下，上升三角形排列的第3或第4個折返走勢，可能跌破向上傾斜的需求線（排列下限），但不會穿越先前的折返低點。若是如此，型態可能演變為矩形排列（rectangle，下一章討論）。碰到這種情況，就應該按照矩形排列的方式處理。（關於上升三角形與下降三角形的戰術處理方式，以及如何防範型態被破壞，請參考本書下冊第II篇。）
