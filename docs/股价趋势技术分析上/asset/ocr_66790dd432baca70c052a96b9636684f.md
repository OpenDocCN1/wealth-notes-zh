# 第10章 重要的反轉型態V：其他

圖96.1 技術分析者將來回顧1990年多頭行情，應該會充滿驚嘆。最神奇之處，應該是當時發生的可資辨識、可供分析之徵兆（參考附錄D）。進一步分析可以發現，宴會已經結束了（或少胖女人已經開始唱歌）。如同愛德華指出的，具有其本身意涵的擴張頂排列，轉變為菱形排列，後者發出假訊號，結果向上突破，並發展為另一個三角形結構的排列（可以視為不規則或上升三角形，此處只顯示排列下限）。這個三角形排列隨後向下突破，然後呈現V型反轉。價格快速回升，到達一個巨大矩形排列的上限，後者是繪製於2000年8月，2001年的漲勢終止於此，然後行情開始下滑到2001年9月11日的悲劇。投資人顯然沒有做多的理由。當時，是否有任何徵兆顯示行情將呈現橫向發展？全然沒有。這一切都是後見之明嗎？讀者可以參考本書附錄D，查詢約翰·馬基投資通訊（John Magee Investment Newsletter）當時對於行情的分析。

我們只需要用幾句話，就可以點出上升楔形的基本特質。這種排列可能發生在上升趨勢末端而成為頭部型態，也可能發生在下降趨勢過程而成為連進型態。楔形排列通常至少需要3個星期的時間來完
