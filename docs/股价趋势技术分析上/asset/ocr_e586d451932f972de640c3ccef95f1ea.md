# 股價趨勢技術分析（上冊）

![](bbox=[0.14, 0.11, 0.86, 0.47])

圖27. 2月份，DEC完成頭肩頂排列之後，出現一波跌勢，持續到6月中旬。整個下跌幅度，大約是1983～1985年漲勢的三分之二。可是，夏天的低點演變為複雜頭肩底的頭部，最後在9月初夾著大量向上突破頭線，後者代表買進機會。

圓形底（rounding bottoms）經常又稱為「碗形」（bowl）或「碟形」（saucer）排列。圓形頂（rounding tops）有時候也稱為「逆向碗形」（inverted bowls）。結構雖然很合理，但這類頭部或底部排列的發生頻率，低於頭肩排列。圓形底經常發生在低價股，形成长期而很平坦的走勢，醞釀期間往往要花好幾個月。1942年與1943年期間，很多價格不到$10的股票呈現這類發展。（另外，請注意，在低價股的延伸性漲勢過程，經常連續出現為期2、3個月的「碟形」底。這類走勢的性質與意涵，後文討論整理 [consolidation] 型態時，會詳細解釋。）

圓形頂很少出現在中、低價位股票，但偶爾會發生在高價績優股，這類股票比較能夠吸引富有投資人，一般投資大衆的興趣不高。
