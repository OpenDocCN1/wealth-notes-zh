# 股價趨勢技術分析(上冊)

圖軟體也很容易做這類的調整。可是，這類變更過程中，還是要保持適當的判讀角度。涵蓋期間長達數年的對數走勢圖，圖形上端的區間會縮小。為了避免這類的視覺扭曲，可以把整份走勢圖分割為幾個較短期間的圖形。譬如說，5年期的走勢圖，價格區間可能介於10到200之間；對於這類圖形，我們可以採用5份1年期的走勢圖，5份圖形合併之後，也等於5年期走勢圖。

# 註釋

+   1. 艾德華認為開盤價不重要。可是，某些技術分析家（包括本人在內）則認為開盤價也有用處。對於某些繪圖系統來說，開盤價是不可或缺的，譬如：東方人習慣使用的K線圖（陰陽線）。

+   2. 譯按：所謂的「半」對數，是指一半採用算術刻度，一半採用對數刻度。換言之，時間採用算術刻度，價格採用對數刻度。
