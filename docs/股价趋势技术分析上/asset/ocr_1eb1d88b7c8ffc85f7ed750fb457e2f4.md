# 擴張排列

第8章討論三角形排列的過程中，曾經提到「逆向三角形」密集交易區間，價格排列的震幅愈來愈大，上限與下限彼此發散而不收斂。我們決定把這種排列稱為「擴張型態」（broadening patterns），因為排列雖然具有三角形的形狀，但性質與趨勢意涵都明顯不同。
