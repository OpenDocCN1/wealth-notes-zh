# 主要下降趨勢線

由技術分析觀點來看，個別股票在空頭市場呈現的主要趨勢線，幾乎沒有實務運用價值。1929—32年的漫長空頭市場則屬於顯著例外，許多個股的算術刻度趨勢線都呈現直線狀（股價指數也是如此，稍後討論）。可是，其他情況下，空頭市場的趨勢線幾乎都沒有預測價值，不論採用算術或對數刻度都是一樣。

正常情況下，空頭市場主要趨勢不只較多頭市場主要趨勢陡峭（空頭市場的涵蓋期間，平均是多頭市場的一半），而且呈現加速向下發展（價格軌跡呈現開口向下的曲線）。在半對數圖形紙上，這種傾向尤其明顯，所以更難有效預測。

總之，在空頭市場轉變為多頭市場的關鍵時刻，技術分析者恐怕很難由主要趨勢線方面獲得重要資訊。可是，這並不是說完全不需繪製空頭市場的主要趨勢線，或完全不理会顯然具有重要意義的趨勢線。如果期待不高，往往就可以獲得一些可供運用的線索，藉以判斷行情轉折。

如果技術分析不很「斤斤計較」，對於研究結論不太「吹毛求疵」，往往可以由空頭市場趨勢線取得奇妙的資訊。雖然這些趨勢線不能預測主要行情轉折，其延伸線也經常偏離實際價格軌跡；可是，經過幾個月或幾年之後，當價格逐漸向趨勢線靠攏，趨勢線經常可以提供奇妙的線索（這些現象只能由趨勢線解釋，否則顯得不可理解）。雖然很有趣，但就我們所能夠掌握的知識程度來說，這類現象充滿不確定性，不可預期。編者附註：這個事實可能永遠持續下去，就如同費馬最後定理（Fermat's Last Theorem）始終無法被證明。現在雖然邁入第21世紀，但我們擁有的知識程度並不顯然勝過馬基時代。
