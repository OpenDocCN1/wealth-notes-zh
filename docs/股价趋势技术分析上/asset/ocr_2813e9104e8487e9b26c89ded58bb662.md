# 連續或逃逸缺口

連續（逃逸）缺口的發生頻率，低於前述兩類缺口，但具有重要的技術意涵，可以大略顯示走勢的可能幅度。基於這個理由，這類缺口也稱為「衡量缺口」（measuring gaps）。

普通缺口與突破缺口都和價格型態有關，前者是發生在排列發展過程內，後者是發生在排列完成的突破過程中。另一方面，逃逸缺口與稍後將討論的竭盡缺口，則和價格型態無直接關係，是發生在直線狀快速漲勢或跌勢中。

動態性漲勢由承接區發動之後，最初幾天或一個星期內，通常會加速發展，然後因為漲幅過大而引發獲利回吐賣壓，漲勢開始失去動能。就成交量來說，最初突破通常會爆出大量，漲勢中段則稍微縮小，然後再發生巨量而止住漲勢。這類漲勢過程（或對等的跌勢），很可能出現寬大的缺口，代表大成交量的行進間換手完成。這類缺口
