# 第6章 重要的反轉型態 I

圖20.1 S&P指數呈現巨大的頭肩頂排列，即使理查．羅素沒有特別指出，我們也可以察覺。圖形內標示為複雜頭部。複雜頭部本身引發2001～2002年的空頭市場。2000年底，股票跌破長期上升趨勢線，顯示狂歡已經結束。更不要提過程中出現很多基準點與持續下降的低點。隨後發生的多頭行情（2004年的空頭市場大反彈）造成一些解釋上的問題。這波延伸性的漲勢，是否勾消先前出現的巨大頭肩頂排列？這波漲勢大幅穿越頸線，似乎意味著我們誤判價格型態。2005年，該漲勢遭逢先前1999～2000年形成的巨大頭肩部壓力，技術分析者被迫認定股票市場需要花費很多年的時間，才可能克服這個頭部壓力區。可是，請記住，身為技術分析者，如果過去的高價被突破，我們需要根據新的情況發展而改變我們的分析。
