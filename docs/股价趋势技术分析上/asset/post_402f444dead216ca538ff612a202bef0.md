
然而，如果複雜型態是發生在主要趨勢的轉折點，價格通常還會了進一步發展；可是，即使在這種情況下，在最小衡量目標價位附近，通常也會出現一波強烈反彈（如果是底部排列，則會有明顯回檔）。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_143_0.png)

這是發生在2001-2002空頭市場（第一階段）結束的基洛伊底部（頸肩底）排列。經過7 1/2個月的糾纏整理，到了2003年3月，情況看起來像是空頭市場的反彈。可是，一旦頸線被突破之後，就沒有什麼好爭論的了：確實是底部排列。在頸線附近，走勢停頓了1、2個月，然後才毅然決定上攻。當時的經濟與政治情況相當詭譎，影響了盤勢發展。2001年9月11日的恐怖攻擊，等於是讓90年代的飆漲走勢澆了一大盆冷水，布希總統（第二任）的不當稅務政策也是影響因素。運用雷根總統的減稅政策，增加政府支出，發動戰爭，顯然足以刺激大盤走高。此处雖然沒有標示趨勢線，但讀者不難看出漲勢如何突破長期下降趨勢線，以及基洛伊底部如何將空頭扭轉為多頭。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_144_0.png)

圖24. MCA呈現長達5年的漲勢。可是，進入1986年之後，當股價向上挑戰1985年的高點，情況似乎變得困難。4月份雖然曾經創新高，但隨後走勢卻疲態盡露，構成一個大型的頭肩頂。7月中旬，價格頂下突破主要頸線。等到44 5/8的3%突破確認，可以考慮隨後第一個向上擺動放空股票。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_145_0.png)

圖25. BF在1946年完成很典型的多重頭肩頂排列，頭部有兩個。請注意成交量發展。相對於單純的頭肩排列而言，複雜排列完成之後，價格通常比較不容易出現突兀走勢（請參考本章正文說明）。3月底，回升走勢曾經明顯穿越頭線，表現相當強勁，主要是因為大盤在這個時候創新高。反向買穿頭線的行爲，並不足以勾消反轉排列的空頭意涵。

## 鬆散的型態

多重頭肩排列的成交量型態，大體上也遵守簡單頭肩排列的「法則」。早期發展過程中，成交量很不規則，沒有可資辨認的清楚型態，但後半段將呈現頭肩排列的典型結構。

多重頭肩排列具有的性质，特別適合技術操作者運用。由於存在相對明顯的對稱傾向，交易者很容易預測排列的後續發展。可是，一旦排列完成之後，就要考驗交易者的耐心了。這些走勢似乎非常不願亦「配合」新趨勢的發展。就這方面來說，分析者經常誤以為自己碰到假訊號而被「耍」了。事實上，除了前文談到的走勢「幅度」之外，複雜排列的可靠性絕對不輸給對應的簡單排列。不論哪種頭肩型態，假走勢都相對罕見。即使是在罕見的情況下，複雜型態沒有真的發展達反轉排列，然仍代表一種警訊——就如同簡單頭部型態一樣——最後的反轉已經為期不遠了。

# 圓形頂與圓形底

前文討論的多重排列，是由普通頭肩排列延伸與演變而來，如果複雜排列進一步延伸與發展，將形成另一類別的反轉型態：圓形轉折（rounding turn）。

前文說明反轉型態的理論時，曾經談到價格趨勢發展何以需要經過一段時間醞釀與成交量配合，然後才能由上往下或由下往上反轉。頭肩反轉排列的發展過程，趨勢原本充分發揮勁道，然後受到壓抑而抗拒，隨後又再度掌握主動而攻擊，最後才放棄而退卻。整個掙扎過程中，供需雙方的勢力起伏不定，經常造成行情劇烈波動，最後才由某一方取得壓倒性勝利。多重排列也進行類似程序，但過程相對緩和，時間拖得比較久，多空雙方的勢力替換相對明顯。

圓形轉折呈現的這種技術現象，更單純而合理。走勢圖呈現的趨勢變動很緩和、清楚、對稱，買賣雙方的力量消長很平和。

舉例來說，過去一段期間內，如果買方力道始終強於賣方，股價將呈現上升趨勢，並反映在股價走勢圖上。只要買方仍然急著買進、人數仍然較多、態度更積極、力量更強大，則前述上升趨勢就會繼續發展。可是，如果賣方力量轉強，而買方力道維持不變或轉弱，則雙方的勢力消長就會顯示在股價行為上，先前的漲勢可能放緩。如果賣方持續展現功能，終於能夠與買方抗衡，價格走勢可能陷入僵局，難有顯著的漲跌（除了小型而無意義的波動）。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_147_0.png)

圖26. 1946年4月到7月之間，LA形成相當寬廣的多重頭肩頂排列，成交量呈現典型的不規則發展，但後半段具有相當明確的空頭意涵。8月份出現圓形頂空頭排列（請留意價格與成交量的趨勢），其中的漲勢不能拉升到頸線，在先前底部水準遭遇壓力（標示為RL，請參考第13章）。兩個標示為G的跳空缺口，都屬於突破缺口，而且沒有被填補（請參考第12章）。

假定這種情況繼續發展，賣方力量最終將超過買方。現在，主導權將由買方轉到賣方。賣方的力量大於買方，結果將反映在走勢圖，股價逐漸下滑。在這種演變狀況下，即使沒有股價走勢圖，我們也不難推算合理的結局：首先是一波長期漲勢，然後漲勢開始走緩而逐漸陷入僵局，當賣方取得主導權之後，價格開始下滑，最後加速向下發展。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_148_0.png)

圖27. 2月份，DEC完成頭肩頂排列之後，出現一波跌勢，持續到6月中旬。整個下跌幅度，大約是1983～1985年漲勢的三分之二。可是，夏天的低點演變為複雜頭肩底的頭部，最後在9月初夾著大量向上突破頭線，後者代表買進機會。

圓形底（rounding bottoms）經常又稱為「碗形」（bowl）或「碟形」（saucer）排列。圓形頂（rounding tops）有時候也稱為「逆向碗形」（inverted bowls）。結構雖然很合理，但這類頭部或底部排列的發生頻率，低於頭肩排列。圓形底經常發生在低價股，形成长期而很平坦的走勢，醞釀期間往往要花好幾個月。1942年與1943年期間，很多價格不到$10的股票呈現這類發展。（另外，請注意，在低價股的延伸性漲勢過程，經常連續出現為期2、3個月的「碟形」底。這類走勢的性質與意涵，後文討論整理 [consolidation] 型態時，會詳細解釋。）

圓形頂很少出現在中、低價位股票，但偶爾會發生在高價績優股，這類股票比較能夠吸引富有投資人，一般投資大衆的興趣不高。

# 第 7 章 重要的反轉型態Ⅱ

另外，圓形頂也經常出現在高級績優股，這是理所當然的，因為這類股票的價格變動主要反映兩項因素：保守投資者的資金供給與利率水準。這兩個因素的變動都相對緩和。這類股票不容易出現投機性大幅波動。由相反角度思考，則可以解釋圓形頂何以很少發生在低價投機股。多頭市場的末期階段，投機股經常引發狂熱買進，交易者通常不考慮股票的長期投資價值。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_149_0.png)

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_150_0.png)

圖29. 這是中期趨勢的複雜頭肩底，雖然缺乏一般具備的對稱性，還是不難辨識。頭部完成之後的折返走勢，成交量明顯縮小，這是典型、必要的多頭確認。價格突破頸線之後，呈現「不甘不願」的新趨勢，這也是多頭肩反轉排列的正常現象。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_150_1.png)

圖30. 3月份到6月份之間，AMH呈現空頭走勢，直到6月底、7月初發生大幅反彈，才顯示多頭氣勢仍在。由這個時候開始，價格呈現橫向發展，底部支撐大約對應上半年的低點。整體來說，圖形保持完美的對稱性，包括成交量型態在內，顯示3月份到9月份之間的發展，是一個複雜頭肩底排列。如果價格向上突破頸線，而且貫穿程度超過股價的3%，可以考慮買進，最低目標價位設定在$19\frac{3}{4}$。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_151_0.png)

圖31. 這是主要趨勢反轉的另一個頭肩底變形。小型頭肩底排列很容易在日線圖上被忽略。另外，這個小型排列雖然涵蓋6個月期間，但其本身未必代表主要趨勢反轉。然而，10月份，當價格向上穿越前一年的主要壓力區12～13，顯示整個發展不該屬於次級走勢。可是，真正的多頭訊號一直拖延到1943年2月才發生，價格有效貫穿位在14的頸線。1943年11月，PJ價格一度被壓回12（恰好在頸線延伸線），然後穩定上漲到30。當各位閱讀第13章「支撐與壓力」時，請回頭參考這份圖形。這份圖形有個重點，雖然頭部排列經常在很短時間完成，但底部排列往往需要較長時間經營，交易者需要有高度耐心。撇開時間長短不談，大部分頭部型態都具有對應的底部型態。

### 圓形轉折的成交量型態

截至目前為止，我們還沒有討論圓形轉折的成交量型態。這方面的討論很有趣，也很有意義。就圓形底來說，價格型態清楚、明確。首先是需求逐漸吸納供給，舒緩賣壓而開始圓形底的走勢。成交量仍然很大，但有逐漸縮小的傾向。買方還是小心翼翼，但已經足以減緩賣壓，使得股價跌勢趨緩，價格軌跡愈來愈接近水平狀。發展到谷底部位，買賣雙方勢均力敵，成交量相對萎縮。然後，需求增加，價格走勢向上畫出弧線，交投轉趨熱絡。隨著價格上漲，成交量也持續放大，直到行情發展為某種程度的買進高潮為止，價格在幾天之內呈現筆直狀漲勢。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_152_0.png)

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_153_0.png)

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_153_1.png)

對照觀察走勢圖的價格與成交量發展，可以發現兩者都呈現開口向上的弧形，而且兩個弧形大致上相互平行。如果圓形底是發生在一波延伸性跌勢之後，通常具有重大意義，通常代表主要趨勢反轉，預示著即將發生一波延伸性漲勢。可是，這種底部型態很少演變為「一飛沖天」的盤勢，不至於在短短幾個星期之內完成主要趨勢。相反地，圓形底排列完成之後，上升趨勢很緩慢，經常發生修正，讓一些缺乏耐心的交易者不堪折磨，但最終還是會帶來顯著獲利。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_154_0.png)

圖35. 這是算術刻度的月線圖，1932年的主要底部是由頭肩排列構成，1936年的主要頭部也是頭肩型態。由1942年到1946年的主要多頭市場，則是由圓形底開始發動，圓形底涵蓋期間長達2年半左右！研究月線圖往往較具效益。

圖36. 這份圖形屬於月線圖，1942年出現沈悶的碟形底走勢，屬於主要趨勢的反轉型態。1942年，股價低於3；1946年，股價高於46。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_155_1.png)

圖37. 這份圖形也呈現圖36的類似走勢，1942年的股價不足2，1946年的股價超過25。請注意1940年到1945年之間的成交量發展。第15章將回頭探討這些圖形呈現的弧狀主要多頭趨勢。

容我們重複強調一點，如果碗狀底的型態確實可信，底部成交量必須顯著萎縮。可是，當型態發展經過中心點之後，初期漲勢的成交量會稍微擴大，然後發生某種「早產的」向上突破。預先毫無徵兆，成交量突然放大，價格呈現1、2天的直線發展。這種現象雖然稱不上罕見，但最後幾乎一定會回到原來發展的軌跡，此時進場並沒有特殊風險，但必須瞭解耐心等待的必要性。請觀察我們提供的走勢圖，其中包括這類過早的突破（圖38）。

### 潛伏底變形

潛伏底（dormant bottom）頗似圓形底，屬於主要底部型態；事實上，這是一種極端「長期、平坦」的圓形底。這種型態通常發生在成交量很少的個股；換言之，股票發行數量或流通籌碼很有限。即使是在上漲過程，每天成交量也可能只有200、300股。最後，經過幾個星期或幾個月的發展，過程幾乎沒有什麼成交量可言，只是偶爾出現1、2筆交易，價格波動幅度很小。這類走勢圖就像是由「小斑點」銜接而成。

最後，在沒有明顯理由的情況下，交投突然轉趨熱絡。每天成交量為幾百股，價格急漲。就如同圓形底的情況一樣，潛伏過程突然「驚醒」的走勢，通常是「早產」的突破。隨後幾個星期的成交量，可能再度萎縮，或呈現具來愈來愈短的階梯狀走勢，最後才發展為連續性漲勢。總之，整個過程代表重要的承接模式。

我們不難理解潛伏底的發展過程。由於股票數量很有限，只有在很罕見的情況下，才能看到「市價」賣出的籌碼。如果特定人士（或許是與公司經營者有關的內線集團）想要拉高吃貨，股價就會一飛沖天。所以，買家只能「拿著籃子在樹下等」，被動承接任何賣出的股票，但不主動抬高價格，直到樹上熟透的果實都掉光為止。然後，買家稍微抬高價格，希望能夠進一步吸引籌碼賣出。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_158_0.png)

### 頭部呈現的成交量型態

相較於底部，圓形頂的成交量缺乏明顯型態。事實上，在頭部的整個發展過程，成交量通常都偏高而沒有規則。主要峰位完成之後，如果仔細觀察，或許可以在小型波動上察覺到多、空徵兆的細微變化，但成交量顯示的警訊，通常不明顯，除非下降趨勢已經發展到急跌階段。

沒有任何可靠方法，可以衡量圓形轉折的目標價位（但稍早頭肩排列的一些評論也適用於此：如果先前的價格走勢不大，則反轉型態完成之後，反向走勢的幅度通常也不會太大）。可是，圓形轉折幾乎都不會「無疾而終」。一般來說，我們可以根據先前的趨勢大小，以及排列過程花費的時間長短，藉以評估反轉型態的可能影響。圓形轉折經常發生在週線圖或月線圖；所以，這類型態具有重大意義。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_159_0.png)

圖40. 1935年的折返走勢，讓很多個股產生圓形底走勢。目前這個例子，幾乎已經處於潛伏型態。5月初，價格以跳空缺口（標示為G）方式向上突破壓力，這個缺口一直到1937年才被填補（相關說明，請參考第12章）。

行文至此，似乎應該針對週線圖與月線圖上的型態，提出些許一般性的評論。截至目前為止，我們只深入討論日線圖上的型態發展，但日線圖的排列與大幅價格擺動，通常都會經過濃縮而反映在週線圖與月線圖，這類走勢也具有相同意義。成交量方面，週線圖與月線圖比較不容易觀察，但也比較不重要，甚至可以完全忽略（顯著的交易可能只發生在一週內的某一天，其餘幾天的成交量可能沒有異常表現，所以「週」的整體數據經常不能凸顯成交量的重要變化）。月線圖經常出現頭肩頂型態，應該給予適當重視。事實上，週線圖或月線圖上呈現的任何明確排列，其重要性都與時間單位成正比例關係（務必記住，「任何反轉都需要有『本錢』可供反轉」）。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_160_0.png)

圖41．股價在1988年夏天遭受壓力而拉回，下半年形成相當寬廣的交易區間（11～17 1/2）。可是，價格折返走勢發展得很緩慢，7月份到11月份之間出現碟狀排列，價量配合大體上呈現多頭型態。請注意，碟形底部高於2月份低點；換言之，底部有墊高的趨勢。12月中旬，價格夾著大量突破短期下降趨勢線（標示為SDT），代表上升趨勢的第一隻腳。如果整個走勢確實由橫向演變為上升，次一波漲勢將測試1987年高點。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_161_0.png)

圖42. 過去10年來，CYR是市場的飆漲股之一。1976年，股價還不到$1；1987年卻曾經創135 3/4高價，然後在4月份出現跳空缺口，跌破7個星期的菱形排列下線，並展開目前圖形顯現的跌勢。事實上，自從1月中旬夾著大量上漲以來，股價形成大型的圓形頂。當價格跌破菱形排列下線支撐而爆出大量之後，成交量也呈現向下凹的弧狀，使得圓形頂更具意義。目前，價格夾著小量向上反彈到先前排列的頸線，112附近可以考慮建立空頭部位。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_162_0.png)

圖43. 我們非常喜歡NI在1984年呈現的弧形底。這種型態雖然不具大漲潛力，但整個技術結構很理想，尤其是星期五夾著大量向上突破壓力區。

# 第8章 重要的反轉型態Ⅲ：三角形

本章準備討論另一種全然不同的技術型態：三角形（triangles）。相較於20年代與30年代初期，三角形排列近10年來比較罕見，這種發展令人覺得遺憾，因為三角形是深具獲利潛能的排列。（編者附註：請觀察圖269與圖269.1，比較1920年代與2000年代的三角形排列。）深入討論相關細節之前，我們或許應該回顧一些技術分析的基本理論。摘要內容列示如下：

1. 證券市場價值只取決於供需互動。
2. 任何時刻，供需力量是由無數因子共同決定，包括理性與非理性因子。關於未來的資訊、看法、情緒與猜測（不論明智與否），都與其他因子結合，共同決定供需之間的均衡價格。任何人都無法充分掌握這些因子，但市場能夠自動處理。
3. 撇開小型波動不談，股票價格是呈現趨勢性發展，通常會持續相當長一段時間。
4. 趨勢變動代表供需均衡的重要更替，這項事實遲早會反映在市場行為本身，而且可以被觀察。

![](img/899bfe361f2e586eb5ba6fae0e5c5ec0_164_0.png)

第4點陳述內的「遲早」，可能會讓某些讀者覺得失望。我們稍早已經提到，道氏理論訊號經常太遲。前兩章討論的反轉型態，訊號都發生在趨勢已經反轉之後，雖然通常還是「早於」道氏理論，但絕對不可能剛好發生在頭部或底部價位。某人如果根據頭頂確認訊號放空股票，頂多只能賺取先前峰位到隨後谷底之間的半數跌勢，因為就衡量公式計算，當頭部反轉排列最後被確認的時候，頭肩頂的整個跌勢已經完成一半。

各位最好趁早打定主意，技術分析沒辦法讓各位賣在最高點或買在最低點。當然，還是有些人可以在峰位端點賣出股票（而某些可憐傢伙買進），但這就是純粹的運氣！這種運氣相當於高爾夫球的「一桿進洞」。即使是運動白癡，偶爾也會有這種境遇，並享受其中快感。可是，對於有經驗的玩家來說，他們寧可擲槊擲打，只希望先把球送到洞邊。同樣的道理，有經驗的投資者也不會強求最後1點獲利，甚至願意放棄最後10點獲利潜能。

賣出股票的時候，沒有人可以確定當時是賣在最高點。重複強調一次，目前還沒有任何方法或技巧，可以讓我們賣在最高點或買在最低點——將來也不會有。當然，如果財力足夠雄厚，確實可能賣在最低點；換言之，在特定價位無限量化买进股票，甚至抱著準備買進所有流通股票的心理。譬如說，如果打算在70（編者附註：這是1950年代的價位）「通吃」美國鋼鐵（U.S.Steel），大概需要準備$3,743,000,000。這個數字只供參考——如果你真的想試試看的話。
