# ## 第 2 章
# 股票走勢圖

走勢圖是技術分析者的主要運用工具。走勢突有多種不同的格式，透過不同圖形來反映市場發生的一切，或繪製衍生的「股價指數」。我們可以採用月線圖，把整個月份的交易紀錄濃縮為單一登錄值，或採用週線圖、日線圖、小時走勢圖、成交量圖形、圖叉圖（point— and — figure）、陰陽K線……。圖形座標可以採用算術、對數（logarithmic）或平方根刻度，或繪製為「擺盪指標」（oscillators）。另外，我們也可以繪製移動平均、成交量對價格變動的比例關係圖、「交投最活絡」股票的平均價格、畸零股交易、融券餘額……等無數的關係、比率與指數。就技術層面來說，這些圖形都是直接或間接由集中市場的實際交易資料推演而來。
