# 神奇的投資科技

金融與投資理論還有哪些新發展，是一般投資人應該知道的？（請參考第42章討論的VAR）。原則上，當然是愈多愈好，但最頂尖的玩家不僅知道所有的相關發展，而且還不斷追尋各方面的可能運用。可是，如同馬基所說的，究竟什麼是充分而必要知道的（請參考《華爾街心理戰》）？除非心智狀態很幼稚，或具備宗教般的極端信念（這些人根本不知道己不知道），否則沒有什麼是絕對明確的。所以，我只能說，本書或許已經提供一般投資人所需要知道的，而且知道這些也就夠了。

請注意，只要閱讀本書，準備好相關的走勢圖，任何老太太都能擊敗那些擁有超級電腦、現代投資組合理論、取得諾貝爾獎或其他等等專業玩家。我熟悉的一些投資團體，它們投資無數資源來發展即時交易系統，實驗過程顯示相關系統可以徹底擊敗市場。可是，一旦拿到市場上實際運用，卻發現系統過於龐大，電腦運算速度跟不上行情變動，所以不能做即時交易。這就是哲學家提供不切實際的解答。
