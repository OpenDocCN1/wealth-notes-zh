# 第一個嚴格考驗

隨後幾個月的行情發展特別值得觀察，因為道氏理論面臨重大考驗。請參考圖3，該圖顯示1941年2月1日到8月31日之間的7個月走勢，包括兩個指數的每天價格區間、收盤價與成交量。進一步討論之前，首先讓我們回顧2月14日當時的情況。空頭市場低點發生在1940年5、6月份，隨後出現一波延伸性中期回升走勢，工業指數上漲26.28點，鐵路指數上漲8.15點。接著發生一波長達3個月的跌勢，兩個指數的跌幅分別為20.46點與3.75點；順便提一點，這波跌勢是由3個明確的小型波浪構成。就整個發展的期間長度與相對於前一段攔動的幅度變動（道瓊工業指數為78%，鐵路指數為46%）來說，這段走勢可以歸類為中期趨勢；現在（2月14日），價格再度回升。道氏理論的信徒應該留心觀察，如果兩個指數繼續上漲而超過先前11月份的高點（138.12與30.29），將產生反轉訊號，代表新的主要多頭市場。若是如此，當初在1940年5月抽離市場的資金可以重新進場。另外，我們也必須把1940年5、6月份的低點，視為空頭市場的結束，而由該低點到11月份的漲勢，則代表新多頭市場的第一波主要攔動，由1月份高點到2月份低點的跌勢，則代表多頭市場的第一個次級折返。可是，前一章談到的第12點法則仍然適用於此：除非得到明確的反轉證據，否則應該繼續假定目前為空頭市場。
