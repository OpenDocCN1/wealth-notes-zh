# 股價趨勢技術分析 (上冊)

除了技術上的有效性之外，道氏理論現在蒙上一層神秘面紗。就當初設計的目的來說，道氏理論現在具有象徵性的功能。道氏與漢彌爾頓當初把道氏理論視為衡量整體經濟狀況的工具。至於股票市場的投資運用，則是後來的發展。

由本書編輯的立場來看，道瓊理論已經不足以扮演其當初設計的角色，甚至也沒有辦法執其次要功能。這是在過去單純時代，所提出來的一套單純理論。增添鐵路指數（現在的運輸指數）與公用事業指數之後，道氏理論的倡導者隱含體會到相關原理需要做革命性的調整。相較於最初的情況，30支成份股已經不足以代表美國經濟。當整個經濟結構變得複雜，應該沒有人會反對簡單的解釋模型也應該做對應的調整。跨進第21世紀之後，美國與全球經濟需要採用更周詳的計量經濟方法。

基於這個理由，為了讓道氏理論發揮應有的功能，我認為，現在需要透過各種指數來衡量股票市場，更不要提整體經濟狀況，後者是另一個問題，隨然不是全然不同的問題，但確實屬於另一層面的問題。馬基似乎預視這種情況，所以在其著述提到一些有用的工具，尤其是馬基評估指數（Magee Evaluative Index，參考本書第38章），可以用來處理整體市場，不只是摘要性的股價指數而已。這項工具似乎還鮮有人運用，也很少数人瞭解其價值。

對於21世紀的股票市場，已經不同於馬基的鱷魚角，不只存在著整體性浪潮與行情流向。反之，各種各樣的潮流，如同美國經濟一樣，朝西發展。有著舊金山灣外的奔騰太平洋。道瓊指數雖然處在次級下降趨勢，涵蓋面更廣的S&P 500指數卻正在創新高，當此兩者都呈現橫向走勢時，那斯達克行情卻飆漲著。所以，我相信，只有這三種指數構成的綜合指數，才可以充分顯示美國股票市場的真正狀況。
