# 股價趨勢技術分析(上册)

第4點陳述內的「遲早」，可能會讓某些讀者覺得失望。我們稍早已經提到，道氏理論訊號經常太遲。前兩章討論的反轉型態，訊號都發生在趨勢已經反轉之後，雖然通常還是「早於」道氏理論，但絕對不可能剛好發生在頭部或底部價位。某人如果根據頭頂確認訊號放空股票，頂多只能賺取先前峰位到隨後谷底之間的半數跌勢，因為就衡量公式計算，當頭部反轉排列最後被確認的時候，頭肩頂的整個跌勢已經完成一半。

各位最好趁早打定主意，技術分析沒辦法讓各位賣在最高點或買在最低點。當然，還是有些人可以在峰位端點賣出股票（而某些可憐傢伙買進），但這就是純粹的運氣！這種運氣相當於高爾夫球的「一桿進洞」。即使是運動白癡，偶爾也會有這種境遇，並享受其中快感。可是，對於有經驗的玩家來說，他們寧可擲槊擲打，只希望先把球送到洞邊。同樣的道理，有經驗的投資者也不會強求最後1點獲利，甚至願意放棄最後10點獲利潜能。

賣出股票的時候，沒有人可以確定當時是賣在最高點。重複強調一次，目前還沒有任何方法或技巧，可以讓我們賣在最高點或買在最低點——將來也不會有。當然，如果財力足夠雄厚，確實可能賣在最低點；換言之，在特定價位無限量化买进股票，甚至抱著準備買進所有流通股票的心理。譬如說，如果打算在70（編者附註：這是1950年代的價位）「通吃」美國鋼鐵（U.S.Steel），大概需要準備$3,743,000,000。這個數字只供參考——如果你真的想試試看的話。
