# 第 17-B 章 投資科技進展

有道理銷售其買權，除非該股票陷入狹幅盤整區間，而且在選擇權到期之前不會突破。如果股票處在下降趨勢，投資人就應該賣掉股票，而不是銷售其買權。反之，如果銷售上升趨勢之股票的買權，這會被經紀人視為最佳客戶，協助經紀人賺取佣金。如果股票處於漲勢，銷售買權的後果很明顯：銷售者（也就是讀者「您」）會按照選擇權履約價格賣掉股票，喪失股票多頭部位與其未來升值潛能。至於銷售選擇權的權利金收益，雖然不無小補，不過只是「苦中作樂」而已。

# 計量分析

投資人還需要知道另一個有關電腦與投資科技的領域，這是一個績效差異更明確、更具獲利潛能的領域，但也是由模型主導的市場：選擇權市場。從事選擇權研究與交易的計量分析者，他們不同於一般的技術分析者。很有趣的，選擇權基本上是透過運算模型決定的市場，但這種衍生性產品的根本資產，卻屬於行為市場的股票。目前有關選擇權交易的訂價模型，都是由布萊克－薛里斯訂價模型演變來的，後者根據 5 個變數決定股票選擇權的理論價值，這 5 個變數分別為：選擇權履約價格、股票價格、「無風險」利率、選擇權到期期間，以及股票價格波動率。

目前的衍生性交易產業，都已經普遍接受布萊克－薛里斯訂價模型。本書不準備列舉目前可供交易的衍生性產品種類，因為它們並不是本書想要處理的對象。本節的主要目的，是要警告那些想要「擊敗衍生性市場」的投資人，務必要先做徹底的研究，否則可能會付出慘重代價。

最初，首先體會選擇權訂價模型之重要性的交易者，徹底擊敗老式交易者，後者是指那些憑著直覺或單純信念（換言之，人類情緒）
