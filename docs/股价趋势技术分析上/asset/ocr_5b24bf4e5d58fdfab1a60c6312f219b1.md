# 竭盡缺口

突破缺口代表顯著走勢的起點；逃逸缺口代表快速走勢的中點；竭盡缺口代表走勢的末端。前兩者之間，很容易區別，只需要觀察缺口發生位置與先前價格型態之間的關係，但後兩者之間，往往很難辨別。

如同逃逸缺口一樣，竭盡缺口也是發生在快速走勢的延伸性漲勢或跌勢過程。我們稍早曾經解釋逃逸缺口的發生原因：快速走勢過程，加速度由盛轉衰（動能減緩），最後受制於買壓而走勢停頓。可是，某些飆漲走勢過程並不會顯示買壓轉強，動能完全沒有轉弱的跡象，發展速度持續加快；然後，走勢突然遭逢龐大賣壓（或跌勢突然呈現強烈買盤），成交量暴增而走勢停頓。對於這類走勢，末端可能發生巨大的缺口；換言之，缺口發生在既有趨勢的最後一天或前一天線形之間。由於這種缺口代表迴光反照的勁道，所以稱為「竭盡缺口」。

對於直線狀快速漲勢或跌勢過程發生的缺口，判斷其屬於連續缺口或竭盡缺口的最好辦法，是觀察缺口發生當天的成交量，但先前走勢也可以提供其他有用線索。如果缺口發生當天，爆出極不尋常的大量，尤其是先前價格走勢步調與當天成交量之間不對稱，很可能就是竭盡缺口。事實上，如果缺口當天發生單日反轉的線形（參考第10章），而且收盤價接近缺口邊緣，幾乎就可以確定前述的解釋。
