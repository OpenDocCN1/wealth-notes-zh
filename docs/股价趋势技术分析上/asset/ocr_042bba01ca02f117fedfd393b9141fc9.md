# 第13章 支撐與壓力

先前底部將存在既定利害關係結構，並產生實壓（壓力），造成新的頭部；先前頭部則產生實盤（支撐）、造成新的底部。

這個觀念很重要。深入分析股價走勢圖，不難發現上升趨勢相對容易穿越先前的峰位，必較不容易克服先前的大量底部。（對於下降走勢來說，情況當然相反。）先前高點的實壓不大，通常只足以造成漲勢的暫時停頓，而不像先前底部一樣構成顯著壓力，迫使價格大幅折返或陷入長期橫向整理。
