# 第 17 章
內容摘要 & 結論

本書第1章曾經提到，如何透過技術方法處理交易與投資的問題，並說明相關的原理，以此做為股票圖形技術分析的研究開端。現在，讀者可以回頭複習相關內容，因為經過相當繁雜的閱讀之後，先前的主題可能變得模糊。

深入研究許多股價走勢圖所展現的迷人現象之後，讀者或許會忽略一項基本事實：我們只運用一種非常不完美的工具，而試圖衡量供需相對力量，並藉此決定股票價格將如何發展（包括其速度與幅度）。

請記住，技術分析並不關心供給與需求力量是如何產生的；重點在於這些力量確實存在，而且供、需互動會產生均衡點。沒有任何人或任何組織，能夠掌握或精確評估無數的資料、群眾情緒、個人需要、期待、恐懼、估計與猜測，這些因素將結合整體經濟不斷變動的架構，共決定供需力量。可是，所有這些因素造成的影響，都會立即反映在市場。
