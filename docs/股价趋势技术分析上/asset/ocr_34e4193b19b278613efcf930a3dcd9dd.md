# 第15章 主要趨勢線

![](bbox=[0.2, 0.13, 0.82, 0.55])

圖178. 這是西屋電器的迴線圖。價格一旦跌破非常陡峭的上升趨勢線，反彈走勢經常會創新高，這種情況發生在1936年8月。第二條比較平坦的直線，才是主要多頭市場的真正上升趨勢線。請注意，1936年2月到4月之間的價格走勢，這不該被視為主要趨勢的雙重頂，因為兩個頭部中間所夾的折返走勢幅度，還不到峰值股價（122）的10%。請對照圖64，該份日線圖顯示股價在1937年形成最後一個頭部的反轉排列。

1937年4月到6月之間，這份迴線圖呈現大規模矩形排列，但向上突破的成交量配合不好，對於主要趨勢來說，絕對具有空頭意涵。8月，價格完成矩形排列的上檔目標價位，但主要上升趨勢也因此結束。

如同一般狀況一樣，當行情進入空頭市場，所繪製的主要下降趨勢線通常不具預測功能。1929—32的主要空頭市場發展過程，曾經出現完美的主要下降趨勢線，這讓許多技術分析者誤以為每個空頭市場都應該有類似狀況。事實上，就這方面來說，1929—32期間反而是例外。
