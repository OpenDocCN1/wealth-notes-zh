# 股價趨勢技術分析（上冊）

順便提一點，西屋股價在1937年4月繼續下跌到130，出現矩形底部排列之後，8月份向上反彈到158（前述下降三角形的下限之上），然後11月份又跌到88。請比較這份日線圖與第15章的西屋月線圖（1935年～1938年）。

圖66. 1941～1943年期間形成一個很詭異的主要底部排列，初期階段尤其令人覺得困惑。當價格由1941年倫璼珍珠港的恐慌性低點回升之後，出現等腰三角形排列，1942年4月向下突破。隨後的跌勢雖然完成下檔目標價位，但沒有跌破前一年12月份低點。6月份的漲勢，以及隨後8～9月的跌勢，使得去年12月以來的整個走勢，演變為更大型的等腰三角形，而且該排列在9月份向上突破。突破之後，價格在1942年12月拉回三角形頂點。配合隨後的漲勢，整個走勢又演變為長達15個月的上升三角形，這個主要底部排列最後促使價格在1946年上漲到42。請注意，6月份的漲勢與8～9月份的跌勢，成交量都很低；另外，9月份的向上突破、1943年1月份的漲勢，以及2月份突破上升三角形，都曾經爆出大量，充分顯示主要多頭趨勢的意涵。務必記住，多頭市場需要透過時間醞釀來建立底部。
