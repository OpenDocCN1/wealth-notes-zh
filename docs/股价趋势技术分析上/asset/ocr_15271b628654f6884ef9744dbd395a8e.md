# 普通或區域缺口

顧名思義，這些缺口通常都發生在交易區間或密集成交區。前幾章討論的所有密集成交區（包括反轉與連續型態在內），通常都會伴隨著成交量萎縮的現象。在緊密的排列中，這種現象更明顯，例如：三角形與矩形。另外，成交量通常會集中在排列上限與下限，因此供給線與需求線之間就成為「不毛之地」。所以，我們很容易理解這些成交量稀少區域何以會發生缺口的原因。第8章與第9章提供的許多範例，都包含這類缺口。

在密集交易排列完成或突破之前，這類缺口通常都會在幾天之內被填補，理由很明顯。某些情況下，缺口可能發生在價格最後一次跨越型態區間過程，接著排列就發生突破；若是如此，缺口可能在短期之內不會被填補，也沒有理由被填補。

普通或型態缺口幾乎完全沒有價格預測上的意義，但還是有些技術分析上的功能，可以協助辨識區域型態；換言之，由於缺口的出現，代表密集交易型態正在形成中。舉例來說，假定某支股票由10上漲到20，然後折返到17，再回升到20，如果回升過程出現缺口，我們可以合理推測價格將在17到20之間出現某種型態。這類推測往往有助於短線交易。

相對上來說，型態缺口發生在整理排列過程的可能性，高於反轉排列。所以，如果某個矩形或等腰三角形排列出現很多缺口，該型態比較可能是連續排列，不是反轉排列。
