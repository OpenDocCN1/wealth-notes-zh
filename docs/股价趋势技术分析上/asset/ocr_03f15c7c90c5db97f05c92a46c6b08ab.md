# 連續弧狀排列

接下來準備處理的排列，不同於先前討論的連續型態，因為這些排列沒有明確的密集交易區，價格波動不能由邊緣來界定。我們原本可以在後文某章另闢一節「正常趨勢行為」（normal trend action）來討論。可是，這種型態經常發生在某類股票或某類行情，而且與整理型態的連續發展之間，有著密切關係，所以我們還是決定在此處理。

對於流通籌碼很多、交投很熱絡的股票，如果剛脫離長期底部，經常會出現一系列碟狀排列，構成長期主要漲勢。在這些連續發生的型態中，每個碟形排列都類似第7章討論的圓形底（包括價格與成交量在內），但稍微往上翹。換言之，每個碟形排列末端，價格都稍高於起點。每個碟形造成的價格淨漲幅，將因個股而有差異，但通常是股價的 10～15%。由碟形起點到底部的幅度稍大，約略是 20～30%。每個碟形排列的涵蓋期間，大約是 5～7 個星期，很少短於 3 個星期。所以，整個漲勢的發展步調緩慢而穩定，就像某人攀爬滑溜的斜坡，前進 3 步，後退 2 步。

如果股價出現這類走勢，形狀很像連續弧狀（scallops），一個緊接著一個，幾乎完全沒有間斷。每個弧形排列的末期階段，由於價格接近前一個弧形高價，成交量開始放大；在次一個弧形的下跌與打底階段，成交量則持續萎縮到很沉悶的地步，唯有當價格開始攀升，成交量才會出現。
