# 股價趨勢技術分析 (上冊)

好幾層皮，最後才落得更精明一些。

對於一般頭腦清楚的投資人，這些服務與產品之中，哪些是具有重要性呢？哪些是需要的呢？投資人需要資料、圖形與交易管道。滑鼠點一下，就可以取得資料。再點一下，圖形就顯示在電腦螢幕上。最後再點一下，交易就完成了。處在網際網路時代，描述這些程序，就像實際在桌上型電腦與網路連線 上執行這些動作。這種非常簡單的程序（不加思考地說起來比較簡單），其展示可以參考本書附錄D提供的連結。交易需要透過某種型態的經紀人進行，或許是電子虛擬經紀人，也可能透過電話聯絡實體經紀人。透過電腦，电子化交易场所不久將（或已經）取代造市者或專業報價商。

經紀人還能夠存在多久，答案會在本世紀揭曉。（經紀人這個行業會繼續存在，而且也繼續受到歡迎。）那些不需經紀人或專業報價員的電子市場，目前已經逐漸普遍化（參考附錄D）；對於一般投資人來說，這類電子市場顯然優於傳統交易大廳，後者讓專業交易員享有顯著的優勢。就整個初步發展判斷，在相關問題逐步獲得解決之前，情況還會很混亂，充滿風險與機會。

採用電子交易指令，不論是傳遞到電子交易所或紐約證券交易所，顯然都勝過口頭交易指令。對於登錄有案的電子形式指令，內容通常不會引起爭議，口頭交易指令的情況則不同，經紀人與客戶的解釋可能存在差異。另外，交易者只處理一次資料（而不是進行分析，打電話給經紀人，登錄交易，然後把交易轉到投資組合內）。如果只是敲個按鍵，整筆交易就透過套裝軟體進行；這種情況下，如果發生錯誤，很容易追蹤。採用人工方式，每個步驟都可能出差錯。萬一發生錯誤，損失可能非常嚴重。
