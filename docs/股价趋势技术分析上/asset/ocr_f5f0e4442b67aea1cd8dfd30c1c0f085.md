心的延長線折返，這時候必須嚴密觀察。（停損單可以設定在這個位置。）如果軸心不能發揮支撐功能，一旦價格穿越軸心而加速發展，稱為「軸心的收場走勢」（end run around the line）。

# ## 穿越支撐的成交量

價格走勢到達壓力區（支撐區），可能不折返而在該處盤旋幾天，然後穿越，並且繼續挺進；這種情況下，走勢幾乎一定會加速發展，而且成交量也會跟著放大。這種現象可以視為有效突破的確認證據，顯示價格將繼續朝突破方向發展。成交量為何會放大？理由並不明顯。有人說：「走勢必須透過成交量來消化買壓。」這種說法完全沒錯，但成交量通常是發生在壓力被貫穿之後。因此，又有人說：「成交量是因為技術分析者察覺壓力被貫穿而紛紛搶進的結果。」可是，就我們的觀察，這種說法缺乏根據。（技術分析者對於趨勢的影響程度非常值得懷疑：關於這點，稍後還會討論。）價量變動之間的許多關係，都類似「雞生蛋／蛋生雞」的論證。總之，許多技術現象的發生原因（例如目前這個），不妨留給學術界操心，我們所在意的只是實務運用上的明確意涵。
