# # 第3章 道氏理論

道氏理論（Dow Theory）可以說是所有技術分析研究的老祖宗。這套理論雖然經常被批評為「訊號太遲」，相關判斷也常被反對者嘲弄（尤其是在空頭行情的初期階段），但任何與股票市場有點關係的人，都非常熟悉這個名稱，更受到多數人的敬重。很多投資決策多少都受其影響，但人們往往不清楚這是純粹的技術分析。這套理論的根基與處理對象，都只是股票市場本身的行为（或稱為「大盤指數」），完全沒有引用基本分析者仰賴的經濟統計數據。
