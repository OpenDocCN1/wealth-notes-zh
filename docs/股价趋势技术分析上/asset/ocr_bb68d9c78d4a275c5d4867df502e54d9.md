# 第8章 重要的反轉型態Ⅲ：三角形

結束這個例子之前，或許應該討論價格突破之後的折返或拉回走勢。如同頭肩排列的情況一樣，等腰三角形最初突破之後，價格可能不會立即發動重大走勢，而會重新折返到三角形排列的邊界，這種折返走勢通常會持續2、3天。所以，就稍早討論的例子來說，價格向上突破而在39 1/8收盤，隔天可能進一步上漲到40。接著，隨後1、2天內，價格可能夾著小量退回到37 1/2或38。稍做整理之後，才開始正式向上挺進。向下突破也有類似狀況；突破之後，價格可能向上反彈到排列下限，然後才夾著大量正式向下發展。可是，就三角形排列而言，突破之後出現折返走勢的發生頻率，明顯低於頭肩排列。繼續討
