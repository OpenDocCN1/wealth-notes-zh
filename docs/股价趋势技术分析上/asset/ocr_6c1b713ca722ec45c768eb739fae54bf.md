# 第 10 章 重要的反轉型態Ⅴ：其他

# 範例

前一段說明看起來似乎很複雜，讓我們透過實際數據做說明，或許有助於釐清「失敗」訊號的觀念。如果在白紙上繪製下列過程，或許會更清楚一些。假定XYZ股票夾著逐漸擴大的成交量上漲大約30點之後，在62遭逢賣壓，折返到58。可是，當時交投還是很熱絡，跌勢終於於58而向上反彈，創新高價63。經過一、兩天的「攪拌」之後，價格又拉回，這次跌到56 1/2，然後買盤再度推升股價走高。第二波漲勢拉高到62，稍做盤旋又跌回59，但立即又彈升到65。（這個時候，走勢圖已經可以清楚看出擴張排列。）在新高價65，成交量很大，接著價格拉回到60附近；此處有明顯支撐，價格在60到62之間波動兩、三天，但最後還是下跌到56，這個階段的成交量顯著放大。接著，展開第四波漲勢，但當時在60附近買進的交易者開始覺得害怕，只求「全身而退」，解套賣壓讓第四波漲勢受阻。價格很快滑落到55，低於先前的折返低點。一旦發生這種情況，前一波漲勢的「失敗走勢」獲得確認；所謂「失敗」，是指價格不能回升到65之上而繼續高價不斷墊高的程序。根據這個失敗走勢判斷，當價格跌破56就可以視為突破。

如果留意這個例子的發展，可以發現型態之內可能發生很多小波動而不至於影響最後結果。價格由56 1/2到65，是由三波段構成，首先是由56 1/2到62，其次是由62到59，最後是由59到65。價格由62跌到59並不重要，只要回落位置高於56 1/2就可以，然後展開另一波漲勢而高於型態先前的峰位（換言之，63）。

這個例子代表比較常見的發展型態，在漲勢之後發生擴張排列，然後出現失敗走勢而價格向下突破。可是，我們也可以由另一個角度考慮，假定這個例子是發生在長期跌勢之後，如果價格沒有在60到62
