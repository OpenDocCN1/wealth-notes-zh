# 股價趨勢技術分析 (上冊)

![](bbox=[0.13, 0.12, 0.86, 0.49])

圖179.5.4. 財政部公債日線圖。其就如同信用擴張程度一樣，期貨市場的恐懼與貪婪也要乘以10倍。此處的2004年9月份長期公債契約，則說明圖形分析是多麼簡單。3月份開始的下降趨勢，可以由簡單的趨勢線與趨勢分析說明。下降趨勢終於於5月份，當時出現兩隻向上的長線形。如果採用基準點之類的分析，空頭部位停止點最起碼在5月1日就會引發。如果交易者打算立即翻空為多，只能搶個帽子（因為我們不知道底部是否已經浮現）。當下降趨勢線在點2遭到明確突破之後，可以建立多頭部位。上升趨勢線到了7月底才被跌破。這個時候，交易者又由多翻空。顯然地，當時應該採用很緊密的短期趨勢線，以及長線形作為訊號。我個人與很多其他交易者，都經常採用長線形（配合其他指標）作為訊號。
