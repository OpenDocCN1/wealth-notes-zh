# 行情上漲的獲利機會

8月份，道瓊指數為10,000，9月份道瓊期貨價格為10,050。你預期目前的多頭行情會持續發展，希望建立順勢多頭部位，但不願投入更多資金，而且只願意承擔有限風險。

於是，你買進9月份期投資權，該買權與9月份根本期貨同時到期，期貨到期價格會收斂到現貨價格。

你的看法偏多，所以履約價格10,500的買權（目前處於價外狀態）是不錯的對象，目前價格為10.10。所以，你總共支付 \$ 1,010的權利金（\$ 100×10.10），取得1口買權。

盈虧結果：9月份契約到期時，道瓊期貨價格為10,610。你的買權處於價內狀態，內含價值為110點，相當於\$ 1100。扣除當初支付的權利金 \$ 1,010，淨獲利為\$ 90。如果到期當時的期貨價格為10,500或更低，則買權將過期而沒有價值，你的淨損失相當於當初支付的權利金 \$ 1,010。如果道瓊期貨到期價格較買權履約價格高出101點，則剛好不賺不賠。

如果不採用買權，可以投資\$ 100,500直接購買道瓊指數成分股。如果9月份期貨到期價格為10,110，則股票投資組合的獲利大約是\$ 3,030。可是，如果直接投資股票，萬一行情不漲反跌，損失可能非常嚴重。
