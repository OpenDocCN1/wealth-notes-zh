大，因為選擇權執行獲利的可能性愈高。選擇權到期時，時間價值為零；換言之，選擇權價值等於內含價值。

# 價格波動率

所謂的價格波動率（volatility），是指選擇權根本資產的價格波動程度（計算公式請參考附錄D）。就目前考慮的道瓊工業指數期貨選擇權來說，選擇權根本資產當然就是期貨契約。期貨價格波動愈劇烈，選擇權權利金愈高。期權（期貨選擇權）價格是下列變數的函數：期貨價格、履約價格、剩餘到期期間、貨幣市場利率與期貨價格波動率。對於這些訂價變數，只有價格波動率沒有辦法直接由市場觀察。由於其他變數都是已知數（包括選擇權價格在內），所以可以由選擇權價格倒推市場認定的價格波動率，如此計算的價格波動率，稱為。選擇權的「隱含價格波動率」（implied volatility）。這代表市場對於根本期貨在選擇權到期之前的預期報酬率平均看法。隱含價格波動率通常表示為年度化數據。隱含價格波動率是停損計算建議採用的參考變數（第27章）。關於隱含價格波動率的意義與用途，一般投資大眾經常搞不清楚，這也是專業玩家所能掌握的優惠。可是，如果願意深入研究的話，一般投資人也可以享有這種優勢。

# 執行選擇權

選擇權到期究竟是否應該執行，應該是很清楚的。如果選擇權履約價格低於根本期貨價格，持有人應該執行買權。執行買權的價值，是期貨價格高於履約價格的差價。反之，如果履約價格高於期貨價格，持有人應該執行賣權。執行賣權的價值，是履約價格高於期貨價格的差價。
