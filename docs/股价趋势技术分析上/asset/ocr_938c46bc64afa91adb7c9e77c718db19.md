# 修正走勢的趨勢：扇形法則

前文談論的中期趨勢，並沒有論及次級或修正走勢的趨勢。所謂的修正走勢，是指多頭市場發展過程，夾在主要漲勢之間的中期跌勢，以及空頭市場發展過程，夾在主要跌勢之間的中期漲勢。

逆著主要趨勢方向的中期折返走勢，其發展可能採取數種不同方式。有時候，中期折返走勢可能發展為整理排列，例如：三角形或矩形，價格折返幅度很有限，但花費很多時間。這種情況下，當然沒以必要繪製中期趨勢線，即使繪製的話，恐怕也沒有實務用途。
