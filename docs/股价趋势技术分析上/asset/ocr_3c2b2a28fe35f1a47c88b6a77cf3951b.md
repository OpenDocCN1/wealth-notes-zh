# 股價趨勢技術分析 (上冊)

處於中期下降趨勢。反之，鐵路指數的表現則全然不同；由4月3日的高點開始，經過2個星期的回檔，指數止於27.72（沒有跌破2月份低點26.54），然後向上反彈，稍後又被壓回，5月31日的收盤價為27.43。整個情況似乎變得更有意思了。兩個指數之間呈現背離（divergence，彼此不能相互確認）；鐵路指數的2次回檔都沒有跌破2月份低點，拒絕確認工業指數的下降趨勢。
