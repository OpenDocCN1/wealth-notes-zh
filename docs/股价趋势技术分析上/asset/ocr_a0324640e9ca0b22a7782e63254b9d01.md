讓我們舉例說明。選擇權到期時，如果期貨價格為7,600，則履約價格為7,500的買權應該執行，相同或履約價格更低的賣權，則不該執行。前述買權的執行價值為$ 1,000。前述賣權則沒有任何價值。反之，如果期貨價格為7,500，則履約價格為7600的賣權應該執行，相同或履約價格更高的買權，則不該執行。前述賣權的執行價值為$ 1,000。前述買權則沒有任何價值。

選擇權多頭部位（買家）的獲利，等於到期價值扣除選擇權權利金。同理，選擇權空頭部位（銷售者）的獲利，等於到期價值加上權利金。買權與賣權的到期價值和獲利，經常是重要的投資策略工具。這些報酬型態與風險參數，使得選擇權的功用顯著不同於期貨。選擇權在這方面具備的彈性，使其成為理想的調整工具，讓投資組合可以根據各種市況進行調整。另外，前述所謂的市況，可以是一般的漲跌，也可以是性質非常明確的狀況。總之，對於各種可能發生的市況，幾乎都有適用的選擇權策略可供運用作。

# 運用期權參與行情走勢

對於行情的各種變化與意外狀況，交易者往往需要立即採取因應行動。可是，在短時間內決定買賣整個投資組合的股票，經常涉及可觀的交易成本，而且也很容易产生重大價格盈虧，使得很多投資人不願針對短期價格波動採取行動。談到放空股票，更是很多投資人的忌諱，除了保證金與相關風險之外，放空行為本身似乎也投合投資的意義。

選擇權具備的彈性，方便投資人針對行情波動採取快速行動。任何的買權多頭部位，只要履約價格低於道瓊指數期貨價格，就可以獲利。同樣地，任何的賣權多頭部位，只要履約價格高於道瓊指數期貨價格，就可以獲利。讓我們簡單介紹這兩種策略。
