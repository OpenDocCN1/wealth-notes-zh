# 典型的擴張頂

擴張排列有一種特殊型態，這也是數學家所謂的特例，其性質基本上符合前一節的描述。1929年，這種特定型態經常發生在交投熱絡的个股，但自從1929年以來，就少見於多頭市場峰位，也很少發生在中期跌勢之前的大成交量頭部（例如：1933年與1934年的情況）。這是技術分析者所謂的「擴張頂」（broadening top），雖然符合等腰格式的擴張排列性質，但型態非常明確而值得花點時間研究。

典型的擴張頂，是由三個持續墊高的峰位構成，三個峰位所夾的兩個谷底，第二個底部低於第一個底部。一般來說，當價格由第三個峰位拉回而跌破第二個谷底的支撐，型態就被視為完成而構成重要的反轉排列。

關於這種型態的發展，讓我們引用1929年的例子來說明。圖87代表該股票發生在7月1日到12月31日之間的日線圖。擴張頂完成於10月份，圖形分別以1—5標示型態的重要轉折點。當然，唯有當價格由第二個小型低點（點4）向上反彈之後，我們才能判定擴張頂排列的可能性；這個時候，點3高於點1，點4低於點2。價格在點5（a與b）創新高，然後拉回而在B點跌破點4低價（收盤價的貫穿幅度大約是6%），型態完成而發出主要趨勢反轉訊號。就這個例子來說，反轉訊號的重要性無庸置疑；請觀察圖87，10月18日的股價為220，只不過經過4個星期時間，11月14日的股價為80，而且最後底部拖延到1932年才出現！
