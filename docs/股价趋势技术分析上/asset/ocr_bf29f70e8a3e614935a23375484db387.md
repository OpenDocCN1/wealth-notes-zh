# 第10章 重要的反轉型態Ⅴ：其他

範的失控現象：投資大眾受到激情慫恿或謠言影響，瘋狂殺進殺出。請注意，我們只說擴張排列意味著這種心理狀態；換言之，擴張排列有時候確實反映這種情緒狀態，另一些時候則沒有明顯理由，無法判斷型態發生的原因。總之，這種排列幾乎一定是發生在長期多頭市場的末端或最後階段，使我們對於排列的性質具有信心。

根據20多年的研究心得顯示，擴張排列具有很明確的空頭意涵，雖然不能排除價格進一步上漲的可能性，但股價發展顯然已經進入危險階段。投資人不應該繼續做新的買進，已經建立的多頭部位最好換股操作，或在第一個反轉徵兆中出場。

擴張排列可能出現三種格式，分別對應等腰三角形、上升三角形與下降三角形。就等腰格式來說，擴張排列的價格震幅愈來愈大，一系列的小型峰位愈墊愈高，小型底部則不斷下滑。排列上限朝右上方傾斜，下限則朝右下方傾斜；換言之，兩個邊界彼此對稱而向外發散。雖說如此，但擴張型態的結構通常都比較鬆散而不規則，對應的等腰三角形則存在相對緊密的結構。等腰三角形的邊界很清楚，排列過程的價格轉折峰位與谷底都會很精確落在邊界附近。至於對應的擴張排列，漲勢與跌勢的轉折點都不會剛好落在邊界附近，所以上限與下限的界定相對不明確。
