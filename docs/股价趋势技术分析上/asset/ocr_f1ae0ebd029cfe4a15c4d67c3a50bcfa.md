# 第 14 章 趨勢線與通道

如果趨勢線非常陡峭，我們當然不能期待隨後的拉回走勢會一路挺進到趨勢線附近，因為這可能意味著價格將創中期上升趨勢的新高；可是，這類情況還是可能發生。我們比較能夠確定的是，一般上升趨勢線被跌破之後，隨後經常會出現拉回漲勢，帶動價格回到原來的趨勢線附近，這可能在幾天之內完成，或透過一系列小型波動走勢完成。
