# 第 $14$ 章  趨勢線與通道

股價走勢呈現趨勢，這是技術分析的最重要前提之一；事實上，任何人都可以去翻閱任何時間架構的走勢圖，藉以驗證這個前提的有效性。不論是股票市場大盤指數，或是其構成個股，價格走勢不會呈現隨機跳動；恰好相反，價格發展通常具有明確的組織與型態。

價格會呈現趨勢性發展；所謂趨勢，可能是向上、向下或橫向（水平）的價格發展。趨勢的涵蓋期間有長、有短；根據道氏理論的分類，趨勢可以劃分為主要（初期）、中期（次級）與小型趨勢，或者是水平狀狹幅整理（line）。相對於股價指數來說，個股的短暫中期趨勢與延伸性小型趨勢，兩者之間或許很難區別，但這方面的區別並不特別重要。趨勢遲早都會發生變化，或是由上升趨勢反轉為下降趨勢，或是由下降趨勢反轉為上升趨勢，但趨勢也可能沒有經過反轉而改變方向，譬如說，上升趨勢也可能轉變為橫向發展，隨後又恢復原來的上升趨勢，上升趨勢的發展速度也可能發生變化，由緩慢變為快速。
