# 如何繪製趨勢線？

可是，趨勢線應該如何繪製呢？就數學上來說，兩點決定一直線。因此，為了繪製趨勢線，我們需要兩個點：兩個峰位反轉點來決定下降趨勢線，兩個谷底反轉點來決定上升趨勢線。第8章曾經說明如何繪製三角形排列的邊界，其原理也適用於此。事實上，三角形與矩形的邊界，以及頭肩排列的頸線，都屬於特殊型態的趨勢線。

讓我們舉例說明趨勢線繪製方法。假定目前處在主要趨勢底部，希望由此繪製一條向上傾斜的趨勢線。為了方便起見，假定空頭市場底部是由矩形排列構成，上限與下限分別為8與6 1/2，排列最後一波走勢是由6 1/2上漲，漲勢穿越排列上限8，並繼續挺進到9。然後，價格由回撤到8，收復又攀升。一旦最後這波漲勢發展一段距離之後，前述回撤低點8就構成小型谷底，我們可以銜接兩個點（最近連續發生的兩個谷底），繪製第一條上升趨勢線，第二個點（8）為在第一個點（6 1/2）的右上方，所以趨勢線向上傾斜。這屬於小型上升趨勢線。我們可以拿著鉛筆，在走勢圖上畫出一條淡淡的直線，向右延伸一個星期左右。（讀者如果在白紙上實際根據前述價格變動過程繪製，或許比較容易瞭解。）

假定價格推升到10，接著發生幾天的橫向整理，甚至稍微回檔。當走勢觸及小型趨勢線（直線可以無限延伸），價格又向上反彈，出現第三波漲勢。可是，這波漲勢立即遭逢賣壓，沒有多大進展，很快就第4度觸及趨勢線，稍做盤整之後，價格向下突破。如果收盤價顯著低於趨勢線，而且買穿過程爆出大量，可以判定第一條小型趨勢線已經完成（跌破），在次一波漲勢發生之前，價格可能出現某種整理型態，或出現比較嚴重的「修正走勢」，價格下跌幅度可能超過第一
