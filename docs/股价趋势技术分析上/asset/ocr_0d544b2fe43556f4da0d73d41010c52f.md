# 反轉？整理？

本章把等腰三角形歸類為反轉型態，但範例卻出現一些整理 (consolidation) 型態；換言之，既有趨勢藉由三角形排列做整理，稍做停頓之後，繼續原來的趨勢發展。事實上，大約有四分之三的等腰三角形是屬於連續（整理）型態，但剩下的四分之一卻很可怕（如果我們持有股票的話）。如何分辨呢？
