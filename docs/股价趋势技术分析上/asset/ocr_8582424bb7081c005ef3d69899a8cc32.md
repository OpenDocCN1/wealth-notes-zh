# 股價趨勢技術分析（上冊）

![](bbox=[0.15, 0.12, 0.87, 0.51])

圖163．整個下跌走勢的前半段，約略吐回1983年的大部分漲幅，但守住1982年低點，使得空頭氣焰不至於太囂張。股價折返走勢呈現漂亮的扇形線。9月中旬首先夾著大量突破F1。漲勢很快喪失動能，受阻於先前高點壓力，後續整理形成F2。11月中旬，價格又夾量突破F2。經過5個星期的修正之後，最後夾著顯著大量突破F3。

下一章準備處理主要趨勢線，但在結束中期趨勢的相關討論之前，我們希望重複強調一點：唯有透過經驗累積與合理判斷，才能夠在實務交易過程有效運用趨勢線。某些技術分析者非常仰賴趨勢線，甚至實際交易只採用趨勢線；可是，對於大部分玩家來說，除了趨勢線之外，還會參考其他技術資料。

股票技術分析有些類似拼圖遊戲。我們必須拼湊很多因素，包括：成交量、型態，以及相關衡量，還有支撐、壓力、趨勢線與大盤展望，如此才能掌握整體結構。
