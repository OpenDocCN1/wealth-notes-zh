# 辨識特質

關於前述問題，我們不能提供一個完全沒有例外的鐵則，因為每支股票都有不同的習性與行為特質；可是，如果研究各種圖形排列，還是很容易體會相對差異。如果兩個峰位發生在相同價格，相隔的時間很短暫，中間的折返走勢幅度很有限，這很可能屬於整理區域的一部份；換言之，如果該排列隨後發生趨勢反轉，應該是其他排列造成的結果（除了兩個價格峰位之外，應該還有一些「工作」要做）。反之，如果第一個峰位發生之後，出現一波很漫長、很沈悶、跌幅很深而接近於圓弧狀的折返走勢，顯示股價走勢缺乏活力，當價格再度上漲到先前高價，我們至少有理由懷疑是雙重頂。
