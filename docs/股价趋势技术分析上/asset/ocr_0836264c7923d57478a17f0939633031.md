# 第4章 道氏理論實務

顯的實壓，價格只是沈悶地下滑。但願這個次級回升將代表主要上升趨勢的開始；12個月之前，這種期盼也曾經在類似情況下幻滅，但這次的價格更低，而且市場呈現的「感覺」大不相同。消息面的整體情況並不樂觀，但道氏理論並不在意市場之外的消息面（市場將反映所有的資訊）。總之，我們不能做什麼，只有等待，讓市場在適當時機，透過自己的方式呈現實際的發展。

7月初，工業指數開始「原地踏步」；隨後11個月之內，指數波動於5點區間範圍，構成典型的狹幅整理（line），最終於9月底向上突破。同時，鐵路指數也向上推升而創新高；11月2日，兩個指數都穿越先前1月份的反彈頭部。這個時候，某些道氏理論專家宣布，新的多頭市場訊號已經呈現。他們所持的論點如下（撇開與道氏理論或技術分析無關的論點不談）：

+   1. 4月份到6月份底部的成交量很小，屬於空頭市場結束的典型徵兆。（沒錯，但缺乏說服力。）

+   2. 當時，鐵路指數能夠穩住而沒有隨著工業指數創主要新低點。鐵路指數始終沒有跌破1940年5月份的收盤低點。（沒錯，但所代表的意義，頗值得懷疑。稍後再詳細討論這點。）

+   3. 工業指數形成狹幅盤整，並且向上突破。（還是沒錯，但狹幅盤整的期間稍嫌太短，不具備主要的支撐功能。）

+   4. 近4個月以來，鐵路指數的小型頭部與底部，位置不斷墊高。（這也沒錯，但不足以明確顯示這不是空頭市場的次級回升。）

態度比較保守的道氏理論家，還是不能接受行情已經反轉的看法。他們認為，上升趨勢還必須接受次級折返的測試，遲遲早都會發生。他們承認，目前情況相對樂觀，但也指出一項事實：除了上述第1點之外，市況沒有明顯優於1940年11月之處。不妨讓我們追蹤隨後5
