# 確認之後的價格行為：衡量公式

頭肩排列完成的最後階段（價格貫穿頸線），成交量可能放大，但通常不會在第一次突破過程放大。如果第一次跌破頸線的過程中，成交量沒有放大，價格往往會重新折返頸線附近（但很少會真的向上穿越）。原則上，這屬於「迴光反照」的走勢，價格隨後會夾著大量下跌。頭肩排列完成之後（貫穿頸線），價格究竟是否會出現折返走勢，基本上取決於當時的整體市況。如果大盤也完成頭部排列，則個
