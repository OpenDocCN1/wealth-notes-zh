# 股價趨勢技術分析（上冊）

![](bbox=[0.14, 0.11, 0.88, 0.55])

圖 118. 這是上升趨勢連續弧狀排列的一部分，此處特別挑選發生在10月份的碟形排列，因為其涵蓋期間特別短、跌幅特別淺。次一個弧狀起始於12月，1月份價格曾經跌到12 1/2，2月份高點為18 1/2。此處顯示的排列之前，還有一個為期4個月的弧形（發生在1945年2月到6月之間）。請注意6月份「價漲量增」的高點，部位交易者可能在9買進。

對於這類明顯呈現碟形價性的股票，其代表的交易機會幾乎不需多加評諭（雖說如此，本書第II篇還是會討論這方面的一些細節）。透過價格與成交量發展趨勢，我們很容易判斷底部位置，碟狀端點的情況也是如此。可是，很奇怪，大部分在號子裡看盤的散戶，經常是以「看熱鬧」的心態處理這類股票，在價漲量增的階段積極買進，在沈悶的打底階段反而不加理會。
