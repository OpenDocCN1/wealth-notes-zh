自然系統，龜族系統與道氏理論也是如此。就自然系統來說，分析者與資料之間不會橫互著數學運算方法。任何機械性方法的最大缺失，就是其盲目性質，沒有辦法判別森林與樹木。有經驗的圖形分析者，可以看到（聽到）市場脈動的變化，然後做出回應；這些回應往往很微妙（甚至是潛意識的），根本不可能透過電腦程式執行。可是，即便是龜族系統之類的自然系統，也會產生這方面的問題。如果市場知道有很多資金在20天高價等著，就會就此設立陷阱。此處所謂的「市場」，讀者可以稱其為「他們」。如果引用本書提供的知識，或許就可以避開這類陷阱。

# # 交易期貨所需要知道的一切
