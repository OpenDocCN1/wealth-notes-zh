# 第5章
道氏理論的缺失

第4章結束之後，讀者可能有鬆一口氣的感覺，因為這部分內容確實有些困難、繁瑣、混淆。某些讀者甚至希望道氏理論根本不存在。另一些讀者或許會察覺一些實際或潛在的缺失，希望提出問題。進一步討論股價形態與排列之前，我們或許應該釐清這方面的一些問題。

首先，讓我們處理「亂猜」的問題，這是道氏理論家经常受到的責難。在行情發展的關鍵時刻，只要道氏理論家的看法不一致，就難免產生這類責難。即使是最有經驗、最謹慎的道氏理論家，也可能因為市場的後續發展而改變當初的看法。他們並不否認這點；可是，他們認為，就長期來說，這類暫時性解釋發生錯誤，並不會構成重大影響。某些專家定期發表評論，我們可以去檢驗他們事前的預測、提供的建議，以及事後的看法。就本書前一章為例，如果讀者查驗相關的紀錄，將發現其中的解釋（撇開事後回顧的評論不談）與當時正統道氏理論家的解釋大致相同。第9版附註：目前，最著名的道氏理論專家，可能是理查．羅素（Richard Russell，dowtheoryletters.com），但
