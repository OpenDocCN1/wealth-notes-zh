# 第 1 2 章 跳空缺口

![](bbox=[0.1, 0.13, 0.98, 0.48])

圖132. 交投冷清的股票偶爾會發生「震盪」島狀反轉排列。雖然很難解釋發生的原因，但其預測上的意義很明顯。

竭盡缺口本身不該被視為主要反轉訊號，甚至不一定代表反轉。竭盡缺口代表「停頓」，但停頓之後通常會發生某種區域型態，然後進一步發展為反轉或連續排列。可是，在實務操作上，當竭盡缺口發生而新趨勢還沒有明朗化之前，很可能發生小型折返或延遲，所以還是應該立即結束當時的部位。（如果隨後走勢證明先前的趨勢還繼續發展，可以考虑重新進場。）
