# 股價趨勢技術分析（上冊）

![](bbox=[0.15, 0.11, 0.84, 0.48])

圖96. 相對於日線圖來說，週線圖上的菱形反轉排列更容易觀察。請注意1946年5月份與6月份的價格搖動與成交量型態。另外，1946年9月到1947年2月之間，也發生明確的下降三角形，排列突破之後，價格曾經在3月份拉高到三角形頂點附近，代表理想的放空機會。

當然，我们也可以辯稱，任何價格漲勢（不論其形狀如何）都代表市場技術面轉弱。潛在買盤將因為價格走高而降低買進意願，潛在賣盤也將因為價格走高而強化賣出意願；換言之，任何上升趨勢都會造成供給增加、需求減少。這種說法在理論上雖然站得住腳，但價格上漲往往反而會吸引買氣，讓賣方期待將來有更高價格可賣。上升楔形不同於一般上升趨勢通道（後文將說明），兩者之間存在差異，楔形設定漲勢的某種限制。兩條邊界相互收斂，其頂點代表漲勢端點，也是反轉發生的位置。
