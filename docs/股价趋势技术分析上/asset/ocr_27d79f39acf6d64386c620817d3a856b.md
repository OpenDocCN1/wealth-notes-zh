# 第１３章 支撐與壓力

等腰三角形具有不同性質的支撐／壓力。我們知道，等腰三角形排列內第一個反轉點（上升趨勢的峰位，或下降趨勢的谷底），通常伴隨著大量，隨後排列過程的成交量則慢慢減少。所以，價格一旦突破三角形，而且遠超過前述第一個反轉點，該反轉點（由於成交量很大）將成為後續走勢的支撐（或壓力）。可是，如果價格突破三角形排列而不能有效穿越前述反轉點，則隨後折返走勢可能回到三角形邊緣；另外，如果折返走勢的發生時間，位在三角形頂點位置或之後，折返走勢的支撐（或壓力）將是三角形頂點。總之，三角形頂點代表支撐／壓力匯集點或軸心。
