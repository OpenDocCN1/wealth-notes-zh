# 股價趨勢技術分析（上冊）

圖7涵蓋1945年5月1日到11月30日之間的7個月走勢。工業指數在高檔維持4個星期的穩定走勢，鐵路指數則由6月26日的頭部反轉而下。6月28日，報紙上完全看不到任何可以解釋趨勢突然反轉的原因，價格暴跌，成交量也急增到300萬股，這是多頭市場截至當時為止的最大單日成交量。可是，工業指數展現頑強的抗跌姿態，7月26日的指數水準為160.91，由頭部起算的跌幅為5%。另一方面，鐵路指數則快速南下。8月5日，聯軍在日本廣島投下原子彈；8月14日，日本宣布投降。當時，工業指數已經由7月26日的低點回升，但鐵路指數無法守住7月份低點，再度重挫，最後在8月20日見底（51.48），由6月份峰位起算的跌幅為18%。

# 鐵路指數動搖

繼續討論行情發展之前，或許值得特別強調一點：截至目前為止，鐵路指數一直扮演故事的「主角」。自從1942年6月拒絕創空頭市場的新低點以來，鐵路類股始終是每波漲勢的先鋒部隊，整體表現相當亮麗，漲幅高達170%，相較於工業指數的82%。事後回顧，理由非常明顯：鐵路行業是戰爭的最大受益者。整個行業的獲利暴增，清償大量債務，固定費用出現史無前例的刪減（將來不可能再發生）。雖然「投資大眾」的關愛眼神，始終聚焦於曝光率較高的傳統「戰爭產業」，但早在珍珠港事件爆發之前，市場就開始評估與反映鐵路產業的大豐收。然而，從現在開始，又是另一番光景了，鐵路產業將成為落後類股。由當時角度回顧，情況也很明顯，股票市場在1945年7月已經開始預先反映未來的發展，道氏理論的第1個論點很清楚顯示這點。
