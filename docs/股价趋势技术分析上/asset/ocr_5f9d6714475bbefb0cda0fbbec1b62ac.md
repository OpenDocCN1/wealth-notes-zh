# 指數期貨

期貨就如同選擇權一樣，能夠提供投機性的信用擴張；換言之，所投入的資本遠少於直接購買根本商品或指數，就能控制相對龐大的部位。期貨推銷員很喜歡強調，你存入的保證金額度只是契約價值的5%或10%，如果契約價格呈現類似幅度的走勢，你就可以獲取一倍的報酬。可是，這些推銷員卻不願談論相反的可能性，萬一價格出現反向走勢，就可能勾消你的保證金。從事期貨交易不同於購買選擇權，市場走勢造成的損失，可能超過保證金。期貨交易帳戶可能出現赤字，你會欠經紀商錢；換言之，期貨交易損失可能超過100%。基於這個原因與其他考量，在沒有充分準備之前，千萬不要從事期貨交易。

讀者如果想要做這方面的準備，不妨閱讀目前最棒的一本相關書籍，史瓦格的《史瓦格期貨技術分析》（Technical Analysis，Schwager on Futures，中文版，請參閱寰宇出版公司）。
