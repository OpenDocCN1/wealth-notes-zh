# 股價趨勢技術分析(上冊)

反映的供、需互動關係。就這方面來說，股價走勢圖是截至目前為止最有效的分析工具。可是，為了避免沈迷於圖形機制而產生「見樹不見林」的副作用（只看到每天的細微變化），我們應該隨時問心自問：「這些行為所代表的供需意義究竟是什麼？」

我們必須具備判斷力與宏觀視野，持續回歸最基本的原理。如同本書不斷強調、而各位也必須永遠記住的，圖形分析並不是一種完美的工具，不是一成不變的機器人，沒有辦法提供簡單、明確而任何人都瞭解的答案，也沒有辦法立即轉換為實際獲利。

我們也曾經深入觀察與測試無數其他技術性理論、系統、指標與方法，這些內容都沒有被納入本書，主要是因為它們藐視人類判斷力的重要性，試圖透過純機械性方法處理全然不屬於機械性的問題。本出倡導的圖形分析方法，都具備最高實用性，因為其內容相對單純，大體上很容易由直覺角度解釋；因為這些內容遵守最根本的市場原理，代表自然現象與力量，不至於讓我們期待過多；因為這些內容相輔相成。

簡略回顧這些方法，其內容大體上可以歸類為四個範疇。

+   1. 價格波動構成的區域型態或排列，配合成交量發展，可以顯示供、需均衡的重要變化。價格排列可以是整理型態（連續型態），藉以恢復或蓄積力量，推動價格朝原先趨勢的相同方向發展。反之，價格排列也可以是反轉型態，消耗先前趨勢的力量，讓對立力量取得優勢，推動價格朝先前趨勢的相反方向發展。不論是那種型態，價格排列都代表力量的一段醞釀期間，蓄勢勃道，推動價格走勢（向上或向下），並讓這些走勢轉化為獲利。某些型態可以顯示其力量將推動價格到達遠遠的價位。這些圖形排列（配合成交量型態）將提供技術分析者大多數的「進場」與「出場」訊號。
