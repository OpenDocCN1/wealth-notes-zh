# 第6章
# 重要的反轉型態 I

第5章討論道氏理論在實務操作上的缺失時，曾經提到該理論不能告訴我們如何從事特定股票的交易。可是，我們又不能買賣指數。（第9版附註：現在顯然不是問題，因為投資人可以直接購買道瓊工業指數，就如同個別股票一樣，交易大盤指數。）對於保守而富有的投資人，如果安全性考量大於獲利，他可以透過分散投資的原則解決這個問題，列出一張清單，涵蓋許多老牌而健全的「藍籌股」，每當道氏理論發出多頭趨勢的訊號，就把這張清單交給經紀人，買進清單上所有的股票。某些股票會有相對不錯的表現，有些則會「泡湯」，但分散投資可以確保合理的平均績效。可是，如果我們可以找到某種方法來挑選適合買進的股票，並在買進理由充分反映到價格之後，立即賣出而換股操作，如此進行投資的績效，應該會比較理想才對。

還有另一種提升投資報酬的辦法。如果我們能夠在道氏理論發出多頭訊號之前，找到相對安全的買點，在更低價格提早買進；然後，在行情大幅折返而引發道氏理論空頭訊號之前，試圖在更高價位提早賣出。
