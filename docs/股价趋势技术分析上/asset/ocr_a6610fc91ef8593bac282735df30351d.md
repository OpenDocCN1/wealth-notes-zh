# 股價趨勢技術分析,(上冊)

價格上漲到30之後，開始吸引跟進的玩家，成交量增加到每天1,000股左右。當股價接近40，成交量擴大為2,000股，價格先在39、40附近「搅拌机」，然後開始下跌。股價下跌過程，各位很關心後續發展（尤其是實際擁有股票的話），即使知道價格不太可能直接跌回20（這不是股價發展的應有行為 [編者附註：處在第21世紀的今天，某些股票往往會如此]），但還是會擔心。假定這支股票的趨勢已經反轉，價格應該會在頭部附近盤旋一陣子，出現某種出貨的型態。
