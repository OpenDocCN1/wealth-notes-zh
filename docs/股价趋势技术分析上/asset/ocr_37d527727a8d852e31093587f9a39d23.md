# 股價趨勢技術分析(上冊)

![](bbox=[0.135, 0.13, 0.865, 0.6])

圖20. 1929年的大多頭市場末期，產生許多頭肩頂排列，UK是其中之一。請注意9月份的頭肩頂排列，其本身是另一個更大型頭肩頂排列的頭部。當9月份的頭肩頂排列完成之後（9月28日跌破頸線），價格曾經拉回到頸線附近，構成更大型頭肩頂的右肩，這代表一個不錯的放空機會。右肩的下跌走勢在10月19日跌破較大型排列的頸線，隨後在10月22日出現拉回走勢，曾經連續兩天向上突破頸線，但最後還是不免大跌的下場。在不到1個月的期間內，UK股價幾乎腰斬，1932年的低點為15 ½。類似如1927～1932年的行情，將來或許不會重演，但目前這個例子代表很好的教訓：不要忽略頭肩排列的重要性。
