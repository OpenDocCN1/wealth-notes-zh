# 第17章 內容摘要 & 結論

本書始終是把成交量擺在價格行為架構內討論，成交量本身不能做為技術指標。請記住，成交量是一種相對概念，多頭市場峰值附近會自然產生偏高的成交量，空頭市場底部的成交量則偏低。成交量會配合價格趨勢；換言之，如果價格呈現向上趨勢，則「價漲量增——價跌量縮」，反之亦然。可是，此項法則的運用，必須保持彈性；不要過份執著於某幾天的成交量，即使在空頭市場（除非發生恐慌性跌勢）也多少會呈現「價漲量增」的傾向。（「價格可以因為本身重量而下跌，但需要買盤力量推高。」）相對於先前幾天或幾星期來說，如果成交量放大，可能代表某個走勢開始（突破）或結束（高潮），而且這些走勢可能具備暫時或長久的意義。（當然，這也可能是「震盪洗盤」，但這種情況很罕見。）任何走勢都應該擺在「價量關係」的架構內觀察。
