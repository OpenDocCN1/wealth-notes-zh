# 第8章 重要的反轉型態 Ⅲ：三角形

然，價格下跌之後，賣出慾望將減退。些準備接手的買盤早就在旁「虎視眈眈」，他們來不及在30或更低價位「上轍」。這些人雖然不願向上「追價」到40，但很樂意在拉回走勢中逢低買進。當價格下跌到33，接手買盤已經足以讓供需之間的力量重新恢復均衡。

可是，在價格回升過程，先前來不及在40附近獲利了結的投資人，這次決定不要太貪心，準備在「合理」價位出局。所以，當價格向上穿越37之後，賣壓開始浮現，並在39附近有效遏止漲勢。於是，價格又開始回撤。我們可以推想這類情況如何週而復始地重複發展，新資金持續進場，持股者也愈來愈急著想獲利了結。最後，潛在的賣壓都被消化或改變心意，專業玩家與充滿期待的投資人赫然發現上檔已經沒有賣壓了，於是紛紛搶進。
