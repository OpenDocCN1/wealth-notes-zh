# 股値趨勢技術分析（上冊。）

![](bbox=[0.17, 0.11, 0.82, 0.37])

圖29. 這是中期趨勢的複雜頭肩底，雖然缺乏一般具備的對稱性，還是不難辨識。頭部完成之後的折返走勢，成交量明顯縮小，這是典型、必要的多頭確認。價格突破頸線之後，呈現「不甘不願」的新趨勢，這也是多頭肩反轉排列的正常現象。

![](bbox=[0.15, 0.49, 0.81, 0.76])

圖30. 3月份到6月份之間，AMH呈現空頭走勢，直到6月底、7月初發生大幅反彈，才顯示多頭氣勢仍在。由這個時候開始，價格呈現橫向發展，底部支撐大約對應上半年的低點。整體來說，圖形保持完美的對稱性，包括成交量型態在內，顯示3月份到9月份之間的發展，是一個複雜頭肩底排列。如果價格向上突破頸線，而且貫穿程度超過股價的3%，可以考慮買進，最低目標價位設定在$19\frac{3}{4}$。
