# 下降楔形

除了排列邊界的傾斜角度之外，下降楔形在各方面都類似上升楔形。可是，排列完成之後的價格走勢方向，則截然不同。上升楔形突破之後，價格通常會快速挫跌。可是，下降楔形突破之後，價格經常演變為橫向走勢，或沈悶的碟形排列，最後才向上發展。所以，對於上升楔形，型態判斷與手腳反應速度要很俐落，否則沒有辦法即時掌握機會。至於下降楔形，交易者通常可以慢慢思考如何因應後續的漲勢。

這兩種型態都需要有明確的結構。除非價格波動非常緊密，排列邊界由兩條相互收斂的直線清楚界定，而且兩條直線的都明顯朝上或朝下，否則楔形結構就值得懷疑。如果排列的某條邊界接近於水平狀而類似直角三角形排列，則型態蘊含的可能後續發展，就可能截然不同。我們很難提出簡單明瞭的法則，藉以區別楔形與直角三角形。如果某條邊界幾乎是水平狀（該處轉折點收盤價都大約落在相同價位），則排列應該屬於直角三角形。總之，讀者不需過份擔心這方面
