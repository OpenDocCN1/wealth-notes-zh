# 第10章 重要的反轉型態Ⅴ：其他

真正的賣壓高潮，大多來自前一段所說的恐慌性賣出。這種現象通常發生在快速而重大的跌勢之後，許多投機客沒有多於資金可以補繳保證金，股票被迫斷頭，不計成本在市場拋售。這是一種惡性循環，每波斷頭賣壓都可能導致股價重挫，然後每波股價重挫又引發另一波斷頭賣壓；因此，數以百萬計的股票在短時間內倒入市場，展現血淋淋的跳樓大拍賣。這類賣壓高潮往往爆出天量，遠超過先前漲勢過程的任何單日成交量。對於保持空手的交易者來說，這是撿便宜貨的大好時機。

這種「清倉大拍賣」或賣壓高潮，顯然會快速改變市場的技術結構。整個發展過程內，股票會由散戶手中，低價轉移到實力雄厚的玩家。籠罩市場的高氣壓，轉化为一場傾盆大雨，然後雨過天晴。另外，市場一旦發生恐慌性賣出，股價會顯著下跌，甚至跌到任何保守估計的合理買進水準。

賣壓高潮進行的時間，可能不足一天；當天尾盤可能就會向上反轉。這就是發生在底部的單日反轉。可是，某些情況下，賣壓可能持續到尾盤才慢慢緩解，當天沒有足夠時間向上反轉。隔天，價格可能直接開高，恐慌性賣壓不復存在。
