# 第14章 趨勢線與通道

![](bbox=[0.13, 0.14, 0.87, 0.42])

圖149. 此處繪製的趨勢線，可以界定1945年的小型擺動。請注意，第一條上升趨勢線是由3個底部的點構成，如果利用直線銜接價格波動的峰值，就可以繪製一條與上升趨勢線相互平行的「折返線」，我們發現第三波漲勢（2月底）沒有上漲到折返線，這通常是行情即將跌破趨勢線的前兆。第二條上升趨勢線也有類似情況（5月底）。本章稍後會討論「折返線」的運用與「失敗」的意義。

3月份的下降趨勢構成楔形排列。請注意，4月6日的折返走勢在先前排列上限獲得支撐。另外，6月份，反彈走勢在先前的上升趨勢線遭遇壓力，我們經常見到這類跌破趨勢線而在拉高重新測試的走勢。6月份的小型頭肩頂排列從來沒有完成，因為價格並未有突破頭線。

為了實現這兩方面的效益，我們繪製的趨勢線，必須相當精確反映中期趨勢，而且投資人也必須能夠正確判斷趨勢線在什麼情況下，才算有效突破。前文談論趨勢線繪製方法時，我們沒有深入討論這些細節。
