# 選擇權訂價模型與其重要性

自從布萊克—薛里斯模型（適用於個別股票）問世之後，跟著出現許多其他模型，包括：考克斯—羅斯—魯賓斯坦模型（Cox—Ross—Rubinstein）與布萊克期貨選擇權訂價模型。對於一般投資大衆來說，前述訊息代表：如果想要交易選擇權，就必須熟悉這些模型，瞭解其功能。請記住，這些模型可以計算選擇權的「理論價值」。專業玩家經常銷售訂價偏高的選擇權，然後購買訂價偏低的對應選擇權，賺取幾乎沒有風險的差價利潤。一般投資人如果搞不清楚選擇權的合理價值，等於是不知道股票的交易價格。對於這類無知的投資人，專業玩家會向他們收取學費。不幸地，很多散戶投資人雖然不斷繳學費，但始終沒以學得教訓。

科技與知識來自創新者與發明者，最先被專業玩家運用；但最後還是會慢慢普及化。可是，等到一般大眾都瞭解某項發明時，又有一些新玩意兒出現了。雖說專業玩家基本上都擁有相對先進的工具，但一般投資人如果要使用選擇權，還是要想辦法徹底教育自己。由於本書並非討論選擇權的書籍，讀者如果需要這方面的進一步資料，請參考附錄D。
