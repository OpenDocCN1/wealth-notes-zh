# 具潛在重要性的短期現象

極短期（一天或幾天）現象，未必只具備短期走勢涵意，甚至也可能透露較長期的行為。第12章將討論的跳空缺口，以及本章討論的單日反轉，都屬於這類例子。其他值得留意的短期型態，包括：突兀線形（Spikes）、關鍵反轉（Key Reversal Days，又稱為Reversal Days）與逃逸排列（Runaway Days，又稱為Wide—Ranging Days）。

# 突兀線形

突兀線形發生當時，未必能夠辨識。顧名思義，相較於周邊的線形，突兀線形明顯突出。換言之，頭部的突兀線形，明顯高於附近排列；底部的突兀線形，則明顯低於附近排列。所以，當某天出現非比尋常的長線形，還需要觀察後續走勢，才可以判定當天不是逃逸線形（runaway day）。這兩種線形都顯示多、空雙方的激烈交戰，收盤價顯示哪方獲勝。突兀線形重要性的考量因子包括：
