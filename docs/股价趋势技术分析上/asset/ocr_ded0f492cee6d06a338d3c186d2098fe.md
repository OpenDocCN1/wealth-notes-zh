# 第16-A章 21世紀的觀點

圖179.5.1. 1997~2004年期間的黃金週線圖，圓形底。羅伯．愛德華在本書第7章曾經說過：「如果圓形底是發生在一波延伸性跌勢之後，通常具有重大意義，通常代表主要趨勢反轉，預示著即將發生一波延伸性漲勢。可是，這種底部形態很少演變為『一飛沖天』的盤勢，不至於在短短幾個星期之內完成主要趨勢。相反地，圓形底排列完成之後，上上升趨勢很緩慢，經常發生修正，讓一些缺乏耐心的交易者不堪折磨，但最終還是會帶來顯著獲利。」如同各位看到的，這個圓形底包含個重大跌勢，然後出現雙重底完成的假訊號（交易者的手腳夠快的話，或許有小賺一筆的機會），最後出現重大漲勢。
