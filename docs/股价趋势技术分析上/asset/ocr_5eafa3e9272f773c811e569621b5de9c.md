# 雙重頂（底）與三重頂（底）

對於某些市場老手而言，我們把雙重頂（double tops，M頭）歸類為反轉排列的次要型態，幾乎是一種癈瀆。有些交易者對於技術分析缺乏完整的知識，只知道一些皮毛的「術語」，經常像鸚鵡學口一樣唸著「雙重頂」。真正的雙重頂或雙重底並不多見，三重頂（底）就更罕見了。對於這類真正的型態來說（相對於某些經常被誤認而應該歸類為其他反轉排列的型態），唯有當型態完成很久之後，我們才能有效判定相關排列。根據圖形本身的資料，我們絕對不可能在這類型態發生的當時，就判定或辨識它們。
