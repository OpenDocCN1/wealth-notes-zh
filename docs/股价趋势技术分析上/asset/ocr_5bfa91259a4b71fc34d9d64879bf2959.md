# 估計支撐／壓力的潛在重要性

上漲走勢在某個價位可能遭遇的賣壓究竟有多大，將取決於該處的解套賣壓，也就是先前在該處買進而希望持平脫身的潛在賣盤。所以，估計壓力大小的第一個準則是成交量。對於後續漲勢來說，只有數百股成交量的先前小型底部，其構成的壓力，當然不能與成交量高達數萬股的先前賣壓高潮底部相提並論。

矩形或下降三角形長期排列，其下限是由許多小型波動底部構成。我們可以加總這些底部的成交量，藉以約估壓力的程度，但這些總成交量需要打些折扣，因為某些在早期底部買進的股票，可能在排列完成之前已經在頭部賣出。所以，如果代表壓力的成交量，是分散在一系列相同水準的底部，而這些底部曾經發生反彈，則一系列底部的加總壓力，其勁道將不如相同成交量構成的單一底部。
