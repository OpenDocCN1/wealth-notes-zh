# 上升楔形將常發生在空頭市場回升走勢

最後補充一點，上升楔形是空頭市場回升走勢的典型現象。所以，長期下跌走勢如果發生上升楔形，幾乎就可以確定主要趨勢仍然向下，而不是多頭市場的第一段主升波。舉例來說，假定某個空頭市場最後是以頭肩底排列結束，上升楔形將常發生在左肩完成之後的反彈走勢，價格隨後還會向下創新低（頭肩底的「頭」）。對於算術刻度
