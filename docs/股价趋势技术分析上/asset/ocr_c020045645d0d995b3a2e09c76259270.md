# 第14章 趨勢線與通道

![](bbox=[0.12, 0.13, 0.87, 0.4])

圖162。處在多頭市場裡，當價格向下突破等腰三角形而展開中期折返走勢，請讀者嘗試繪製3條扇形線。F1應該銜接8月30日高點與9月12日收盤價。F2已經繪製於圖形上，但沒有標示。F3應該銜接8月30日高點與11月9日峰位。11月21日，價格夾著大量突破F3。由9月中旬到11月之間，價格型態看起來像是下降三角形，但成交量由10月份開始擴大。

每經過一次突兀狀漲勢，價格總是會折返先前的扇形線，這是很有趣的現象。一旦修正走勢經過低點之後，新的主要攔動通常都會緩慢地向上攀升，呈現碟形走勢。三條扇形線法則也適用於空頭市場的期中回升走勢，因為這類回升走勢大多呈現連續的圓形頂。可是，請注意，扇形法則通常只適用於修正走勢；換言之，用以評估多頭市場的期中跌勢，以及空頭市場的期中漲勢。
