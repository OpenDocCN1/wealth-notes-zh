# 股價趨勢技術分析（上冊）

現獲利回吐的賣壓，買方力量不足以立即消化賣壓，價格會先折返。由於股價下跌，某些持股者可能追殺；可是，當價格下跌到34（舉例來說），追殺賣壓後繼無力，買盤又開始推升價格。當漲勢拉高到40，買方還是不能消化此處的賣壓，於是價格第二次折返，但殺低力道已經不如前一波跌勢，而且買方承接的態度也更積極，所以這次回撤只跌到36。當價格再度上攻40，此處或許還有殘存賣壓，漲勢也許還又經過幾次重複折騰，才能完全消化上檔的賣壓，然後向上突破。
