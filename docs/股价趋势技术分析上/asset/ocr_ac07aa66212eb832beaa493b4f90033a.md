# 股價趨勢技術分析(上冊.)

馬基認為，對於股價指數交易來說，只要價格跌破趨勢線的2%，就視為有效突破。以下幾個例子，將檢視這個假設。

第9版附註：關於趨勢線突破（2%或5%），我要強調一點，趨勢線突破除了代表採取行動的訊號之外，也代表警訊：趨勢即使沒有反轉，也可能轉變為橫向發展，然後再演變成為反轉或連續型態。

![](bbox=[0.13, 0.29, 0.87, 0.62])

圖179.1. S&P走勢圖，1987年崩盤。崩盤之前，出現很多明確的警訊，首先是8月底跌破主要趨勢線，貫穿幅度超過2%。這個訊號一旦出现，交易者就應該非常謹慎、小心。「精明賣出」讓市況愈來愈糟，一直維持到最後（10月10日到20日）。4月份的趨勢線遭到跌破（幅度超過%），使得趨勢交易者退場，但又在6月份重新進場做多。採納趨勢線跌破2~3%的法則，或採用基準點與逐次停止單（參考第27章與28章）可以避免無謂的災難。
