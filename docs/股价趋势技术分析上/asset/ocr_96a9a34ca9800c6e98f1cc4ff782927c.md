3280 = $100 \times (18.90 + 13.90)$。這也是該部位可能發生的最大損失。

只要道瓊期貨價格出現足夠大的走勢，多頭跨形交易就能夠獲利；換言之，期貨價格低於$7472 = 7800 - 328$或高於$8128 = 7800 + 328$。上檔獲利潛能無限，下檔的最大獲利潛能為$\$10 \times (7800 - 328) = \$74,720$（如果道瓊期貨價格跌到$0$，雖然實際上不太可能發生，但理論上還是可能）。

# 狀況4.

8月份，投資人發現選擇權市場的行情明顯高估；換言之，隱合價格波動率明顯高於理論價格波動率。根據判斷，夏天結束之前，股票市場的走勢會趨於和緩。於是，這位投資人決定分別銷售1口9月份買權與賣權，履約價格都是$7800$，權利金收益總共為$\$3280$。如果9月份期貨到期價格低於$7472$或高於$8128$，前述空頭跨形交易就會發生虧損。下檔可能發生的最大損失為$\$10 \times (7800 - 328) = \$74,720$，上檔可能發生的損失為無限。可是，這位投資人認為，風險實際上並不大，因為指數在選擇權到期之前不太可能出現重大走勢。當然，縱使是如此，銷售者還是要考慮災難性風險（舉例來說，編者的客戶在1987年崩盤期間銷售賣權而發生$\$5,700$萬損失）。
