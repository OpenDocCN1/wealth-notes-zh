# 趨勢線

前一節有關趨勢的種種描述，都明白表示或隱含顯示於先前各章內容。現在，我們希望更深入分析這些趨勢，尋找更有效的方法，把趨勢繪製於圖形上，觀察這些趨勢如何強化或協助我們先前由圖形排列與支撐／壓力分析所推演的技術預測結論，如此往往可以更早察覺趨勢的變動。

幾乎所有的小型趨勢，以及大多數的中期趨勢，都遵循直線狀走勢，這很可能是初學者開始鑽研股價走勢圖的初期重要發現之一。某些讀者或許認為，這是自然現象，甚至視為理所當然。可是，對於絕大部分讀者而言，很可能是一段充滿訝異的歷程，每深入一層研究，就會帶來另一份驚奇。不只是小型價格波動而已，甚至涵蓋數年的主要價格擺動，也是呈現直線狀走勢。事實上，這正是股價走勢圖最神秘、最迷人的特質之一。

如果實際拿把尺來衡量，將發現走勢圖呈現的直線狀上升趨勢，其遵循的直線經常是銜接小型走勢的折返低點。換言之，股票市場的上升波瀾，是由一系列漣漪構成，這些漣漪的底部可以銜接為一條近乎筆直的向上傾斜直線。至於一系列漣漪的頭部，則比較不規則；有時候可以銜接為直線狀，但通常都不太平滑。
