# 運用道瓊指數期貨進行投資

下列例子將討論道瓊期貨契約的基本運用。這種契約可以根據預期的行情發展，調整股票投資組合的風險暴露程度，也可以用做為資產配置工具，藉以調整各種資產類別之間的比例。當然，道瓊指數期貨的實際用途，絕對不僅限於此處討論的範圍。下文討論的例子，只強調這種契約的可能運用，沒有強調實際運用上需要注意的細節。另外，為了單純起見，此處也不考慮持有成本或「按照市價進行結算」的保證金付款。

# 1. 投資組合保障

假定你是一位馬基型投資人，擁有一個歷史相當悠久、續效表現很不錯的股票投資組合。現在，你看到道瓊工業指數出現擴張頂排列（如同2000左右的情況），而且時序接近10月，恐怕會有「血光之災」。目前，你所持有之股票投資組合，價值大約是 $400,000，另外持有$100,000的貨幣市場交易工具。你想要讓兩者之間的比率對調，但又不想實際賣掉股票投資組合，因為道瓊工業指數主要趨勢並沒有明確向下反轉的跡象，只是可能向下修正而已。所以，你放空價值 $300,000的指數期貨，只留下價值$100,000的淨部位，防範股票行情不跌反漲。當時，道瓊指數為10000，期貨價格為10500，持有成本大約是0.5%（10500/10000－1）。

你放空3口期貨契約（$300,000/($10・10,000))。現在，整個資產配置結構已經對調過來：做多 $100,000道瓊成分股，做多 $400,000貨幣市場交易工具。
