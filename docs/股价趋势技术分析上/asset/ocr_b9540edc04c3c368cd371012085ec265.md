# 粗糙

聊天室、網路推銷、新聞、預測、解盤、經紀商提供的買進一賣出一持有有強烈持有一小買一大買一或任何其他推薦，都屬於不可取的粗糙。千萬不要忘記，經紀商是透過證券交易賺取收入的；客戶買賣股票，證券商才有收入。事實上，經紀商的最主要客戶是法人機構，經紀商經常幫這些法人客戶銷售股票，轉賣給一般散戶，收取鉅額的服務費用。這是赤裸裸的利益衝突，問題也在2000年初爆發，很多人遭受鉅額罰款，甚至關入監牢。在柯林頓擔任總統的1990年代大多頭市場，這一切都進行得很平順。可是，一旦進入空頭市場，問題全部爆發了，各種旁門左道的花招全部失靈。（第9版附註：2000年初出現一波嚴厲的空頭市場，任何人只要閱讀edwards—magee.com網站發行的約翰·馬基投資通訊，就知道馬基圖形分析精準判斷這段行情。）
