# 第 16-A 章 
21 世紀的觀點

為了追求明確的勝算，人們在商品期貨領域內投入的時間與精力，絕對超過證券投資。為什麼？理由很簡單。相較於證券，期貨交易的輸贏更大、更快。期貨市場經常發生膽炙人口的故事，例如：韓特兄弟炒作白銀、索羅斯與英格蘭銀行之間的對做，以及飆漲到每盎司 $1000 的黃金走勢；可是，這類故事在股票市場就很少見了。我們相信，期貨市場將來還會繼續如此，譬如：石油每桶 $50、$60、$70 或 $100 的行情？在經濟或心理層面上，這些事件都造成重大影響。不論是在陰暗的小房間，或在燈火通明的電腦化研究室，數以千萬計的分析者都忙著撥弄玉米、大豆、白銀、銅……等系統。
