# 第15-A章 21世紀的股價指數交易

如同我在第8版或本版其餘新章節提到的，除了個別股票之外，我們還可以針對股價指數進行交易，這是現代市場提供的彈性。馬基認爲，股價指數具有個別股票所缺乏的技術性平滑效果。這種說法聽起來頗有理所當然的意味。事實上，就如同移動平均可以提供更平滑的資料一樣，股價指數是由許多成分股構成，應該會降低價格波動程度。當然，如同孟德布洛特（Mandelbrot）指出的，價格波動劇烈的風暴則無堅不摧。

根據馬基建議的股價指數交易方式，本章準備詳細說明幾個例子。我嘗試凸顯兩個觀點。第一，當下的恐懼，換言之，崩盤與恐慌發生當時的狀況；第二，由事後角度回顧崩盤與恐慌。當然，我們都活在當下，除了那些億萬富豪之外，誰都禁不起空頭市場的折騰。2000年初，比爾·蓋茲的財富淨值縮水$160億或$170億，這足以讓一般投資人徹底完蛋。

所以，身為一般投資人的你與我，必須特別留意空頭市場。我們必須及早退出場外，讓空頭吞噬那些傻瓜。
