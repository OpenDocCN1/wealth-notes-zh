
# 股價趨勢技術分析（上冊）

圖129. 這是1944年6月發生的飆漲走勢，過程出現許多小缺口。最初兩個的寬度很小，不具備技術分析意義。6月16日發生巨大缺口的當天，線形很短，代表竭盡走勢。隨後出現小規模的旗形整理。6月27日的缺口，看起來也像竭盡缺口，至少就價格行為判斷是如此，但成交量不增反減。隔天，6月28日，價格又向上大幅挺進，所以6月27日的缺口，應該被視為逃逸缺口，上檔衡量目標價位為18 1/2或更高，結果隔天（6月28日）就完成目標價位。請注意接下來出現的頭頂頂反轉排列，隨後演變為中期折返走勢。

關於缺口發生之前的走勢，有幾點值得觀察。如果先前走勢已經完成最初價格排列或密集交易區的衡量目標，則竭盡缺口的可能性大於連續缺口。同理，如果缺口位置距離價格形態之目標價位還有一大段，連續缺口的可能性就很高。一般來說，快速走勢過程發生的第一個缺口，很少是竭盡缺口；換言之，竭盡缺口發生之前，通常至少會出現一個連續缺口。所以，我們可以合理假定快速漲勢或跌勢過程的第一個缺口是連續缺口，除非有顯著的相反證據或其他考量。可是，每多發生一個缺口，竭盡缺口的可能性就會提高，尤其是缺口寬度大於前一個缺口的話。

圖130. 這是一支交投相當冷清的股票，日線圖經常出現「漏洞」。1946年9月，週線圖出現巨大缺口，顯然應該具有重大意義。暫時將其視為逃逸缺口，利用上檔8週的密集交易區下線68做為基準，向下衡量目標價位為44，隨後走勢確實完成衡量目標。

圖132. 交投冷清的股票偶爾會發生「震盪」島狀反轉排列。雖然很難解釋發生的原因，但其預測上的意義很明顯。

竭盡缺口屬於寬大缺口。所謂「寬大」，當然是就相對意義而言；我們不能提出明確的數據做為判斷「寬」或「窄」的基準。可是，這應該不至於造成困擾，只要累積一些圖形分析經驗，這方面的問題應該可以迎刃而解。

逃逸缺口通常要經過很長一段時間才會被填補；換言之，直到發生重要的次級折返，或反向的主要擺脫。可是，竭盡缺口很快就會被填補，通常都在2天到5天之內，這可以做為竭盡缺口與連續缺口之間的最後判別依據（如果需要等待那麼久的話）。（順便提一點，這與一般迷信剛好相反：所有的缺口都必須被填補，然後才可能發生重大走勢。就逃逸缺口來說，缺口沒有被填補，但走勢卻得以繼續發展，而且幅度往往很大。就竭盡缺口來說，封閉缺口實際上代表趨勢結束的訊號。）

## 第12章 跳空缺口

竭盡缺口本身不該被視為主要反轉訊號，甚至不一定代表反轉。竭盡缺口代表「停頓」，但停頓之後通常會發生某種區域型態，然後進一步發展為反轉或連續排列。可是，在實務操作上，當竭盡缺口發生而新趨勢還沒有明朗化之前，很可能發生小型折返或延遲，所以還是應該立即結束當時的部位。（如果隨後走勢證明先前的趨勢還繼續發展，可以考虑重新進場。）

### 島狀反轉

第10章曾經提到島狀反轉（island reversal），由於其中涉及跳空缺口，所以安排在此討論。島狀反轉不屬於常見型態，也不具備主要趨勢意義；換言之，島狀反轉不會界定長期頭部或底部，但通常足以造成先前小型趨勢的全部折返。

島狀反轉是一個緊密價格交易區域，與其他價格走勢之間，被兩個跳空缺口隔開，第一個缺口屬於竭盡缺口（先前曾經發生快速走勢），第二個缺口屬於突破缺口（隨後將發生反向的快速走勢）。所謂的「緊密價格交易區域」，可以是單一條形（單日反轉），也可以是由幾天到一星期左右的線形構成，也就是緊密區內的小型波動。島狀區域內的成交量相對偏高。兩個缺口的價位大致相當（至少有一部份重疊），使得密集交易區看起來像一座「孤島」，脫離其他價格走勢。

前文提到，島狀反轉本身並不屬於主要反轉排列，但經常是主要反轉或重要中期反轉排列的轉折點；舉例來說，主要趨勢的反轉排列是頭肩頂型態，但頭肩頂型態的「頭」可能是由島狀反轉構成。同理，島狀也經常發生在三角形或矩形排列內部而成爲小型反轉的端點（這種情況下，島狀的兩個缺口，將是普通或型態缺口）。

稍後，當我們處理「支撐與壓力」的一般議題之後，或許比較容易理解島狀之所以發生的理由（換言之，為何在約略相同的價位會產生兩個跳空缺口）。我們可以先暫時這麼說，對於一個過去沒有進行顯著換手的交易區間，該處就沒有「既得利益」持股者，價格很容易快速通過。

圖133. 1937年，主要頭部出現典型的島狀反轉，但隨後在3月30日出現很奇怪而強勁的反彈。投資人如果在3月19日或20日的島狀反轉賣出股票，甚至在95附近放空股票，結果發現股價在一個星期之後，竟然向上穿越缺口，想必非常緊張。雖說如此，但走勢最後還是按照我們談論的劇本演出。

這個案例可以說明一項普遍原則：如果股價走勢圖發生某種明確的技術型型態，千萬不要讓隨後產生的枝節矛盾發展影響當初的判斷。耐心等待明確技術型態的運作。

稍早討論的圖123，即是上圖的後續發展。圖123也有一個島狀反轉，請比較成交量型態。

島狀反轉的第二個缺口（換言之，造成排列完成的突破缺口），有時候會在幾天之內被折返走勢填補，但這不是常態。造成島狀的第一個缺口（竭盡缺口）很少會在第二個缺口發生之前被填補，萬一發生這種情況，島狀密集交易區將成為Λ狀（頭部）或V狀（底部），島狀與其他價格走勢之間也沒有水平狀間隔。可是，不論發生哪種變形，基本的解釋意義都相同：先前的小型趨勢應該反轉。

10月份到11月份的走勢，看起來像是被兩個缺口隔開的孤島。事實上，11月20日的缺口是除息缺口，該公司當天發放50美分的股息，所以前述排列在技術上不能解釋為島狀排列。由於除息的緣故，原本為在40的支撐（參考第13章）應該向下調整半點，所以12月份的走勢並沒有跌破支撐。隨後在3月份，股價上漲超過50。

島狀反轉並不容易進行交易，除非是短線「搶帽子」，因為島狀反轉被確認時，折返走勢已經進行相當程度了。當然，如果可以立即判定第一個缺口屬於竭盡缺口，手腳俐落的交易者可能在第二個缺口出現之前就已經採取行動了。事實上，島狀反轉的最主要功能，或許只是提出警告，讓圖形分析者留意後續的可能發展。

### 股價指數的缺口

任何股價指數大概都不免偶爾出現跳空缺口，但發生頻率小於個股，理由很明顯。股價指數一旦發生跳空缺口，雖然不見得每支成份股都必須發生缺口，但至少有一大部分成份股必須如此。因此，根據常理判斷，股價指數很少發生普通或型態缺口，但突破缺口與逃逸缺口則未必很罕見，雖然缺口的寬度可能遠不及個股。竭盡缺口也很罕見，因此島狀反轉也不常見。發生竭盡缺口的條件，很難同時發生在足夠數量的成份股而讓股價指數產生對應的缺口。

就技術分析角度來看，股價指數的缺口，無異於個別股票的缺口。沒有任何證據顯示，股價指數的缺口具有特殊潛能，或明顯不同於交投活絡個股的缺口。

成份股眾多而具有代表性的股價指數很少發生缺口，即使發生，缺口也很小。

## 第13章 支撐與壓力

本章準備處理的對象，性質上截然不同於先前各章討論的內容。我們將由嶄新的角度觀察股票市場，發展非常具有實用價值的法則，指引我們如何買進或賣出股票，估計走勢的發展潛能，預測走勢可能在哪裡「遭遇麻煩」。事實上，有經驗的交易者可以完全仰賴此處所謂的支撐 (support) 與壓力 (resistance) 建立「系統」，不需要會前文討論的價格型態與成交量行為。

可是，支撐與壓力並不是孤立的觀念，它們與先前討論的各種型態、排列之間還是存在關連。前文談到跳空缺口時，隱約提到支撐／壓力的基本原理，各位如果繼續閱讀，將發現很多價格行為都可以在後文得到解釋，或起碼也變得更容易瞭解。

我們經常在市場上聽到人們提到「支撐」，相信讀者也多少瞭解其中的意涵。舉例來說，我們可能聽到某人表示，XYZ股票在50有支撐，或準備在XYZ的下檔5點處大量買進股票，藉以支撐股價。此處把「支撐」定義為實際或潛在買進力量，其數量足以在相當期間內，止住價格的下跌走勢。「壓力」是支撐的相反觀念，代表實際或潛在賣出力量，其數量足在相當期間內，止住價格的上漲走勢。所以，支撐／壓力觀念非常類似需求／供給，雖然意義不完全相同。

支撐價位（support level）是指某股票價位，該處存在充分的需求，至少足以暫時止住下跌走勢，甚至讓股價向上反轉。同理，壓力區域（resistance zone）是指某股票價位，該處存在充分的供給，至少足以暫時止住上漲走勢，甚至讓股價向下反轉。（每個價位的供給／需求相對數量，取決於當時市況，並因此決定趨勢。）可是，支撐代表需求匯集區域，壓力代表供給匯集區域。

根據前述定義，水平狀密集交易型態（例如：矩形）的上限代表壓力，下限代表支撐；上升三角形的上限代表壓力，以及其它等等。可是，我們現在想知道支撐／壓力發生的理由，並預測它們將發生在什麼價格區間。我們可以預測這點，或起碼可以在某種彈性範圍內辦到這點，但要允許某種程度的例外。有些圖形分析家可以精確預測價格漲勢将在哪裡遭遇壓力（供給），或跌勢將在哪裡獲得支撐。

我們之所以能夠做這類預測（推演支撐／壓力理論的基本資料根據），是因為股票交易有集中於某些價位的傾向，這些價位經常是股票過去大量換手的位置。任何發生大成交量的價位，往往是股價趨勢反轉的位置（包括主要、次要與小型趨勢），這些反轉價位具有「重複發生」的傾向。可是，此處有一個非常重要、有趣的觀念，很多業餘圖形分析者似乎始終搞不懂：重要價位的功能經常互換，可以由支撐變成壓力，也可以由壓力變成支撐。舉例來說，某個頭部壓力一旦被突破，將成為後續走勢的下檔支撐；同理，某個底部一旦被貫穿，將成為後續走勢的上檔壓力。

### 正常趨勢發展

透過正常的趨勢發展案例做說明，或許比較容易瞭解支撐／壓力觀念。假定某支股票正處於主要多頭趨勢，價格由12上漲到24，在此遭逢龐大賣壓。修正過程可能發生次級折返，股價下跌到18，也可能在24–21之間藉由小型價格波動做整理。總之，經過折返走勢或整理排列修正之後，價格再度上漲，隨後在30又遭遇集中性供給籌碼。現在，價格顯然又要做修正。同樣地，修正方式可能是橫向整理或次級折返。如果發生次級折返，我們希望預先知道折返低點的可能位置；換言之，下跌走勢可能在哪裡獲得支撐？答案是24，上升趨勢的前一個頭部位置。此處（位在目前價格的下方）過去曾經發生大成交量。前一波漲勢過程，24代表壓力而造成走勢停頓或反轉；對於目前跌勢來說，該價位代表支撐，應該可以止住跌勢而讓價格向上反轉，至少是小型反轉。

為什麼應該是如此？讓我們由典型的下跌走勢來探討另一個類似案例，或許更容易回答這個問題。現在，假定某支股票完成主要頭部，價格由70跌到50；後者曾經發生暫時性的賣壓高潮；然後，成交量暴增，行情向上反彈，或許一度向下「測試」50的支撐，接著就拉高到60。60附近，買盤後續乏力，趨勢又開始下滑，而且跌勢加速，價格創新低42。不久，買盤進場，展開第二波回升走勢。我們預料這波回升走勢（由42開始）將在50遭逢龐大賣壓。這個價位50曾經是第一波跌勢的支撐，但支撐一旦被跌破，將成為第二波回升走勢的壓力。先前的底部，將成為現在的頭部。

此處也可以提出相同問題：為什麼應該是如此？現在，我們可以嘗試提供答案。對於前一段的例子，價格先下跌到50，爆出大量，然後趨勢反轉而回到60，回升過程成交量縮小。50有大量股票換手，每個賣方都對應著買方。某些買方可能是回補空頭部位，沒有繼續做多。另一些短線交易者與專業玩家之所以買進股票，可能只是因為股價跌深而準備搶幾點反彈；他們（至少有一部分）在價格再度下跌之前已經獲利了結。可是，在50買進股票的人，絕大部分認為股價已經很便宜。僅僅在幾個月之前，股價還曾經高達70；所以50當然很便宜，似乎很適合逢低承接做「長期」投資。

### 解釋

讀者不妨設想自己是那些在50買進便宜股票的投資人。看著股價回升到55、58、60，覺得自己的判斷似乎正確無誤，於是決定繼續抱牢股票。當回升走勢結束，股價再度回軟，下跌到57、55、52，最後觸及50。雖然有點擔心，但仍然相信50是很便宜的。他們或許考慮在50賣出，但因為猶豫不決而來不及採取行動。當股價跌破50之後，他們期盼這只是震盪洗盤，價格很快就會回升，但這種期待很快就落空，股價繼續下跌。現在，這些新買家開始擔心。可能出了什麼差錯。當股價跌破45，先前看起來便宜的股價，似乎再也不便宜了。「嗯，我可能撿到燙手山芋，但我絕不認賠。股價總有一天會漲回50，然後我就可以解套了（除了佣金之外）。」聽起來有些耳熟，不是嗎？

讓我們考慮上升趨勢的情況。你和許多其他人一樣，在12買進XYZ，抱著股票上漲到24，認為股價已經夠高而獲利了結。然後，XYZ折返到21，你拍拍自己的背，恭喜自己的英明。可是，很意外地，股價又回升而上漲到30。現在，你再也不認為自己英明了；市場認為的合理股價，顯然超過你認定的水準。你希望重新擁有股票，但不願以更高價格買進，但股價如果回跌到當初的賣價24，你願意重新買進。

圖135. 1945年的年中，走勢圖為何要花費很多功夫遊走於33~34之間呢？雖然不能由這份圖形觀察，但33~34正是1939年底與1940年底密集交易區的下檔支撐。這些過去的下檔支撐，在5年之後卻成為漲勢的壓力。可是，價格一旦穿越這個供給區之後，立即攀升到44，而且隨後的折返走勢（正如同預期地）在33~34獲得支撐。所以，支撐變成壓力，壓力又便為支撐。

我們可以忽略隨後一些發展，因為這些行情基本上是「按規矩辦事」，直接觀察1946年初價格違背下檔支撐的情況。1946年2月1日，價格推進到54附近，遠高於前一年11月份的峰位46。2月底發生的折返走勢，照道理應該在46獲得支撐，但實際上沒有；價格一路挫跌到整數價位40。這顯然是不祥的徵兆（但還不足以致命）。隨後發生一個很大的等腰三角形，9月份向下突破。

空頭市場的第一波恐慌性跌勢，通常不會「尊重」下檔支撐。目前走勢也不例外，雖然價格在33～34的重要支撐數度的向上反彈。11月份，上檔等腰三角形的頭部衡量目標已經完成。

當各位閱讀隨後十幾頁之後，應該回頭研究這個例子。

你本人或許不處在這種情況下，你個人的反應也可能不符合此處的描述。可是，各位對於股票市場如果有足夠經驗，應該能夠瞭解一般投資大眾的心理，或許就能同意前一段描述是很典型的現象。

現在，各位或許仍然不滿意我們對於支撐／壓力原理的解釋。可是，請注意，市場供需之間，通常都只是維持微妙均衡而已。對於任何價位，供給稍多就足以遏止漲勢，需求稍多就足以頂住跌勢。另外，多數交易者都會密切注意盤勢變動，只要察覺某種趨勢正在形成之中，他們就可能採取行動。因此，幾百股的買單或賣單，可能就引起數千股的換手。

還有一點值得注意，造成支撐／壓力的交易者或投資人（由於先前過早買進或賣出），他們未必無知或缺乏經驗。事實上，可能剛好相反，他們或許是市場上比較精明的一群。讓我們繼續引用先前下降趨勢的案例，那些在50買進的人，其精明程度自然超過那些在頭部（70）或回跌到50過程買進的人，雖然50最後也跌破。如果這些人具有相對高明的判斷力，在隨後發展中，他們的態度會更謹慎、保持更大的彈性。股價如果回升，他們或許不會堅持「解套」。所以，空頭趨勢過程，會發生上檔賣壓；換言之，高檔買進而等待賣出的籌碼，可能往下移動而低於理論壓力價位。精明的持股者，願意犧牲部分股價，避免損失擴大。

同理，對於主要的上升趨勢，過早賣出的多頭，或許願意多付幾點代價，在股價折返到理論支撐水準之前，提早買回股票。所以，在明確的多頭趨勢發展過程（第二階段），折返走勢往往頂多拉回到支撐區域的最上緣（反之，空頭市場的回升走勢，頂多攀升到壓力區域最下緣），甚至留下很大的差距。稍後，我們還會繼續討論這方面的問題，但首先需要處理另外兩個主題：如何估計支撐／壓力區的潛在重要性？如何界定這些支撐／壓力的位置，中心點位在哪處？

### 估計支撐／壓力的潛在重要性

上漲走勢在某個價位可能遭遇的賣壓究竟有多大，將取決於該處的解套賣壓，也就是先前在該處買進而希望持平脫身的潛在賣盤。所以，估計壓力大小的第一個準則是成交量。對於後續漲勢來說，只有數百股成交量的先前小型底部，其構成的壓力，當然不能與成交量高達數萬股的先前賣壓高潮底部相提並論。

矩形或下降三角形長期排列，其下限是由許多小型波動底部構成。我們可以加總這些底部的成交量，藉以約估壓力的程度，但這些總成交量需要打些折扣，因為某些在早期底部買進的股票，可能在排列完成之前已經在頭部賣出。所以，如果代表壓力的成交量，是分散在一系列相同水準的底部，而這些底部曾經發生反彈，則一系列底部的加總壓力，其勁道將不如相同成交量構成的單一底部。

判斷壓力勁道的另一項準則，是衡量後續跌勢的幅度。換言之，價格必須攀升多大距離，才會遭逢上檔壓力。原則上，假定其他條件相同，前述距離愈大，壓力就愈大。舉例來說，假定PDQ股票由30一路下跌到20，盤旋幾天之後，價格反彈到24，然後又下跌到19。如果投資人的持股成本是20，目前還不會特別緊張。如果價格由19回升，在20應該不會遭遇太大的壓力。如果價格是下跌到18才回升，則20附近的賣壓可能大些，但還不至於很嚴重。如果價格是由17開始反彈，則20的賣壓將很明顯。總之，如果價格下跌而低於當初買進價位愈遠，投資人愈認為自己當初的買進決策錯誤，「少輸為贏」的念頭也就愈強烈。
