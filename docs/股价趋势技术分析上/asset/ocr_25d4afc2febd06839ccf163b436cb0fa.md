# 股價趨勢技術分析（上冊）

![](bbox=[0.12, 0.12, 0.89, 0.52])

圖151．趨勢線遭到有效貫穿之後，通常都會出現正常的後續發展，或是折返，或是整理，這可以由本章諸多走勢圖或本書其他範例獲得驗證。可是，目前這份週線圖顯然是例外。1937年5月，價格向下跌破1936年9月份以來的中期上升趨勢線（銜接1936年10月與11月的低點）。另外，1937年2月份以來就形成一個多頭頭肩頂排列，頸線位置在52。當時，多頭市場已經進行4年，股價起漲於2！如果把1937年月1日之後的走勢圖遮蓋起來，讀者大概會同意立即賣出股票，不需等待股價跌破頸線52。可是，正如同我們稍早說的，這支股票是一朵「奇葩」，顯然違背技術分析法則。股價跌破趨勢線之後，接著大幅挺進到64才做頭。雖說如此，但先前發展也代表一種警訊，除非主要趨勢即將放盡力氣，否則不該出現這種走勢；繼續追高的風險太大。
