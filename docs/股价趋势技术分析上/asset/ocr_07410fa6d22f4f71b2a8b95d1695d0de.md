# 股價趨勢技術分析（上、冊）

經可以徹底、有效監督投資顧問業者。目前，大型顧問業者原則上已經不會從事詐欺或不法行為，即使這些行為能夠帶來豐厚利潤也是如此。所以，絕大部分的投資顧問業者，態度都很謹慎，非常不願沾染任何可能引起懷疑的事件，不論這些事件看起來多麼無辜或誘人。

那些惡意炒作者，並沒有完全消失，但降低融資成數與相關規範，使得「空襲」操作變得更困難、不容易獲利。同樣地，那些賭性堅強的投機客，還是持續留在場內，雖然融資成數調降使得他們不能縱情狂賭（編者附註：當日沖銷行為盛行，可能造成股價波動更劇烈）。近年來，他們只出現在多頭市場最後階段。編者附註：請留意1990年代末期以來盛行的當日沖銷行為。當然，前述行為都不會實際影響股價走勢圖，頂多只是讓成交量稍微提高。

另一方面，調高稅金與嚴格管制，顯然沒有讓小額投資人享有更安全、更直接、更穩定的市場。降低融資成數不能防止恐慌性崩跌。如果現代化管制具備任何功能的話，只是讓市場下檔變得「比較稀薄」、比較容易發生急跌走勢。相較於50年前，現在仍然存在相同的多頭、空頭市場，相同的行情趨勢發展。可是，很奇怪地，雖然過去缺乏管制年代經常出現的某些型態變得比較少見，但絕大部分技術現象幾乎完全沒有改變。1907年的圖形分析者，仍然可以輕鬆分析1966年的走勢圖。編者附註：這些知識也同樣適用於2000年，這也是為什麼愛德華整理的技術分析方法不需要做重大修正的理由。第9版附註：炒作者與操縱集團雖然消失了，但取而代之的是另一種形式的「詐欺」。很多專業報價員（specialists）與造市者（market makers）因為詐欺而被起訴。到了21世紀，避險基金就像雨後春筍一樣到處萌芽。可是，這些發展如果導致價格波動更劇烈，最起码也帶來一些市場流動性的正面效益。即使到了電腦時代，市場上還是呈現著相同的
