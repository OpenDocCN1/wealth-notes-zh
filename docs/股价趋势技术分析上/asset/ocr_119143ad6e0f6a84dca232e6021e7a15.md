# 直角三角形演變而成的矩形

前一章曾經提到，直角三角形有時候會「失敗」，使得相關排列需要重新歸類為矩形。由於我們已經知道矩形的結構，所以不需再討論前述現象，但必須強調一點：如此構成的矩形排列，更可能順著三角形發生之前的趨勢方向進行突破。可是，這只是就發生機率而言，不可以因此而排除矩形朝另一方向突破的可能性。
