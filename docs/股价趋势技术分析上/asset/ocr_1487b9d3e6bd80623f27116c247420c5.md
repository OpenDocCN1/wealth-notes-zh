# 技術分析 & 21 世紀科技

# ## 電腦與網路，投資工具／資訊革命

本章是要把電腦與資訊科技的最近發展，擺在圖形導向的技術分析領域裡。在約翰・馬基活躍於市場的日子裡，他位在麻省春田市的辦公室，設有一間專門處理圖形的房間。繪圖員有年長者，也有年輕人，他們花了很多時間整理、登錄圖形，協助馬基解釋各種股價走勢圖。他們都是學有專精的人，對於親手繪製的走勢圖有著特殊的感覺。本書採用的圖形，很多都是他們親手繪製的。

目前，這些技術人員的工作，已經被我們桌上的米黃色(或灰色)方盒子取代了。這些方盒子具備的見解與智慧，還經常得到人們的崇拜：「電腦啊！請分析我的股票。」

不幸地，電腦不具備繪圖人員特有的價格型態判别能力。可是，人們不願受制於電腦科技的這方面缺失，交易者與投資人花費大量的金錢與精力，從事電腦化行情分析，試圖藉此取得真正的成功。事實上，投入在這方面研究的資金，可能超過其他方面的知識追求。然
