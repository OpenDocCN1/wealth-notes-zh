乃至於隨身攜帶的交易警訊工具（呼叫器、手持PDA或其他等等）。

某些隨身攜帶器材，甚至可以提供即時報價資訊，讓一些搞不清楚狀況的投資人，可以「即時」破產。

我們也可以在網際網路上找到各種分析，由可敬的技術分析（經常太過複雜），乃至於「通靈」。

網路聊天室可以提供各種即時的推銷或謠言，傳遞各種令人印象深刻的花招。可是，如同我們預期的，對於本書讀者來說，全然無用。

最重要者，資訊革命與電腦可以提供：

+   1. 分析者不需從事一些重複性的工作，加速分析程序：資料收集、繪製圖形、投資組合帳務處理、分析與報稅。

+   2. 讓分析者能夠輕鬆處理投資組合帳務，每天按照市價結算帳戶淨值。如同馬基說的，避免投資人把現金與應計帳務弄混淆。

+   3. 從事一些過去難以想像的工作。分析的股票數量幾乎完全不受限制。至於如何透過電腦篩選交易對象，請參考第21章「圖形選股策略」。

+   4. 允許投資人透過ECNs或電子市場進行交易，這些管道沒有實際的交易大廳，也沒有專業交易員玩弄報價。
