# 趨勢線測試

以下列出一些測試方法，藉以評估上升趨勢線的技術性功能與重要性：

+   A. 由一系列小型波段構成的漲勢，如果有愈多谷底處及趨勢線（或非常接近趨勢線），該趨勢線就愈重要。每經過一次成功的「測試」，就愈能增添趨勢線的可靠性。最初，我們是根據兩個谷底繪製暫時的趨勢線；隨後，如果價格折返而第三度觸及趨勢線，並形成第三個谷底而彈升，這意味著該趨勢線已經受到隨後走勢的確認。如果價格第四次觸及趨勢線，並立即彈升，這又進一步提升該趨勢線的重要性，其他依此類推。

+   B. 趨勢線維持的時間愈長（換言之，未被有效跌破），技術意義愈顯著。可是，這種說法還需要一些條件配合。如果構成趨勢線最初的兩個谷底很接近（譬如說，相隔一個星期），所繪製的趨勢線經常不恰當，斜率可能太陡峭或太平坦。如果趨勢線斜率太小（經常如此），隨後的價格活動可能遠離這條趨勢線，即使發生重大的次級修正，可能也不會碰到這條趨勢線。反之，如果趨勢線銜接的兩個谷底相隔很遠，可能屬於兩個不同的中期攔動，中間夾雜著許多漲勢與跌勢，如此定義的趨勢線比較具有意義。

原則上，A（谷底個數）的重要性高於B（時間長度）。

+   C. 某種程度內，趨勢線張開的角度（趨勢線與水平線之間的夾角）也是決定中期趨勢線重要程度的依據之一。趨勢線如果很陡峭，即使是橫向整理走勢——譬如說，掛在旗桿中央的旗形排列——也可能貫穿趨勢線，結果走勢整理完畢之後，價格又繼
