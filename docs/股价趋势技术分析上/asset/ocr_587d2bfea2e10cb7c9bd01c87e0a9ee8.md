# 型態壓力

現在，我們可以回頭考慮先前談論的反轉與整理型態，觀察其中一些現象。舉例來說，我們現在很容易理解折返走勢為何會填補先前的跳空缺口。缺口發生當時，代表該價格區間沒有「既定利害關係」。另外，如果缺口即將出現之前曾經發生大量，當折返走勢填補缺口之後，走勢經常很快發生轉折。突破缺口就經常發生這類情況。

因此，對於任何缺口，只要隨後發生折返走勢，如果缺口距離不遠，而且中間不存在折返走勢的阻力，缺口很容易救被填補。就逃逸缺口來說，一旦被填補之後，折返走勢沒有什麼理由應該停頓，走勢可能繼續穿越缺口之前的「小量」線形。

頭肩排列或其他區域型態，突破之後的折返走勢也充分反映支撐/壓力原理。舉例來說，下降三角形突破之後，原本扮演支撐功能的水平下限，將轉換為壓力區。隨後折返走勢向上拉高時，很可能在三角形下限附近遭逢壓力而難以穿越。同理，頭肩頂頸線在突破之前為支撐，突破之後將轉換後續走勢的壓力。價格有效向上突破矩形排列
