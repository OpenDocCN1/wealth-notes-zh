# 第 5 章 道氏理論的缺失

始投資金額為 $100，1956 年的帳戶金額累積為$11,236.65。整個過程中，投資人買進15次，賣出15次，平均大約每2年進行一筆交易。

前述紀錄並不完美，有一筆虧損交易，有三筆交易的買進價格，高於先前的賣出價格。可是，我們相信不需要為這幾筆交易做辯護！另外，前述計算沒有考慮交易佣金與稅金，但也沒有考慮股票持有期間的股利，後者當然會讓績效表現看起來更亮麗。

反之，如果投資人相信「買進——持有」策略，我們不妨考慮其中有利的狀況：假定投資人在整個60年的最低價位買進，然後按照最高價位賣出。換言之，1896年8月10日，投資人在最低點29.64買進價值$100的工業指數，然後在60年之後的1956年6月6日，賣在工業指數的最高點521.05，投資帳戶餘額將是$1,757.93，相較於道氏理論的操作結果$11,236.65。

# 道氏理論絕非萬無一失

道氏理論絕非萬無一失。實際結果取決於理論的解釋角度，還有個人的解釋能力。可是，實際紀錄將說明一切。
