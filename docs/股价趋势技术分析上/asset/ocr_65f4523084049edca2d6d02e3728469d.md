# 第 15-A 章 21 世紀的股價指數交易

![](bbox=[0.12, 0.12, 0.88, 0.47])

圖179.3.1. 相較於道瓊指數，S＆P指數更能清楚顯示1990年代末期的多頭市場頭部，跌破趨勢線的現象非常重要。某些死多頭看著道瓊指數，相信指數可以攀升到36,000點，但S＆P指數跌破趨勢線，並展開嚴重、漫長的跌勢。整個頭部發展，剛開始看起來像是圓形頂，然後變成複雜型態的頭部，甚至可以看到頭肩頂的輪廓。我們相信，這世代可能再也沒有機會看到如此規模的頭部。在貪婪心理的慫恿下，那些外行人（甚至包括擦鞋童在內；現在還是一樣，不是嗎？）都迫不及待地搶搭最後一班車。百年難得一見的榮景。碰到這種情況，只要拿著一把尺，老太太也可以全身而退。重點是不要被市場氣氛迷昏了（尤其是那些高唱道瓊指數36,000點的人！），不要做情緒性的投資決策，採納適當的停止策略。
