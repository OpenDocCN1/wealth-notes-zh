# # 摘要結論1

電腦是一種工具，雖然功能非常強大，但仍然是一種工具。電腦不具備解決問題或擬定決策的智慧。我們可以用怪手來挖土，但怪手本身不能決定在哪裡挖土。

我們應該以懷疑的態度看待這些無奇不有的指標與系統，把它們擺在圖形分析的架構內評估。對於發明者或其他使用者，這些指標或許很適用，但對於你或我，可能只是徒增困擾，即使我們曾經深入研究其歷史績效紀錄也一樣。

所以，對於所採用的分析方法，有經驗的投資人都會儘量保持單純，直到他確實瞭解某種技巧、方法或指標，才會將其納入運用。更重要者，關於哪種方法或指標適用，每個人都必須根據自身的條件做評估。
