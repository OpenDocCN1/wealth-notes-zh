# 股價趨勢技術分析(上冊)

![](bbox=[0.15, 0.12, 0.91, 0.57])

圖 127. 這份走勢圖提供一個「謹守本分」的逃逸缺口。1936年底，股價由26 1/2拉回而形成頭肩底排列（左肩是等腰三角形），1937年2月6日向上突破。突破之後，立即出現旗形整理，上檔衡量目標是28。當價格到達該目標價位，又出現另一個旗形整理，上檔最低衡量目標是30 1/2。可是，當價格完成目標，發生巨量的跳空缺口（3月3日）。隨後兩天的走勢，可以確認這是逃逸缺口。所以，這意味著價格將繼續上漲到37以上（由頭肩底頸線開始衡量）。結果，3月17日，股價創多頭市場的高點40 1/2。

衡量缺口的法則，是用來「出場」，不是「進場」。價格不一定可以到達目標，但價格如果完成目標價位，走勢大約已經告一段落。
