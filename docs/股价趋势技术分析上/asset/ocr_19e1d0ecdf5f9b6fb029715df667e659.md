# 股價趨勢技術分析(上册)

# 主要趨勢階段

6. 多頭市場（The Bull Market）：主要上升趨勢通常（但不必然）可以分為三個階段。第一階段是承接（accumulation），這個階段中，有遠見的投資人察覺經濟狀況雖然還處在谷底，但可能即將復甦，所以願意低檔承接賣方拋售的股票，並在賣壓轉輕的情況下，逐漸推升股價。當時，經濟方面的報導仍然很不理想（甚至可能是最令人悲觀的階段）。一般投資大眾對於股票市場深惡痛絕、敬鬼神而遠之。市場交投冷清，但反彈走勢（小型漲勢）開始出現成交量放大的現象。到了第二階段，經濟景氣好轉，企業盈餘也重新回到上升趨勢，股價呈現穩定的漲勢，成交量配合放大。這通常是技術交易者收穫最豐碩的階段。最後邁入血脈沸騰的第三階段，阿貓阿狗都被吸引到股票市場。報紙的經濟版面，佈滿利多消息，股票飆漲也經常成為報紙的頭版新聞。新上市與增資股票不斷出籠。朋友聚會也經常談到股票：「嘿！我看股票還會長，有沒有明牌？」事實上，股價漲勢可能已經持續了兩年，漲幅已經很大，更適當的問題或許應該是：「哪裡是好的賣點？」股票市場的未升階段，到處充滿投機氣息，成交量繼續放大，經常看到「泡沫股」，很多全沒有投資價值的低價股也跟著雞犬升天，但愈來愈多的績優股卻不願跟進。
