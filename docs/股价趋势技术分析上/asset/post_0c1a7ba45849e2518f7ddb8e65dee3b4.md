# 選擇權訂價模型與其重要性

自從布萊克—薛里斯模型（適用於個別股票）問世之後，跟著出現許多其他模型，包括：考克斯—羅斯—魯賓斯坦模型（Cox—Ross—Rubinstein）與布萊克期貨選擇權訂價模型。對於一般投資大眾來說，前述訊息代表：如果想要交易選擇權，就必須熟悉這些模型，瞭解其功能。請記住，這些模型可以計算選擇權的「理論價值」。專業玩家經常銷售訂價偏高的選擇權，然後購買訂價偏低的對應選擇權，賺取幾乎沒有風險的差價利潤。一般投資人如果搞不清楚選擇權的合理價值，等於是不知道股票的交易價格。對於這類無知的投資人，專業玩家會向他們收取學費。不幸地，很多散戶投資人雖然不斷繳學費，但始終沒以學得教訓。

科技與知識來自創新者與發明者，最先被專業玩家運用；但最後還是會慢慢普及化。可是，等到一般大眾都瞭解某項發明時，又有一些新玩意兒出現了。雖說專業玩家基本上都擁有相對先進的工具，但一般投資人如果要使用選擇權，還是要想辦法徹底教育自己。由於本書並非討論選擇權的書籍，讀者如果需要這方面的進一步資料，請參考附錄D。

此處想要介紹一本不錯的選擇權交易者必備書籍：勞倫斯·麥克米倫（Lawrence McMillan）的《選擇權投資策略》（Options as a Strategic Investment，寰宇出版公司）。另外，初學者可以跟芝加哥選擇權交易所（CBOE）聯絡，其網站 www.cboe.com 也提供一些教學軟體。

# 指數期貨

期貨就如同選擇權一樣，能夠提供投機性的信用擴張；換言之，所投入的資本遠少於直接購買根本商品或指數，就能控制相對龐大的部位。期貨推銷員很喜歡強調，你存入的保證金額度只是契約價值的5%或10%，如果契約價格呈現類似幅度的走勢，你就可以獲取一倍的報酬。可是，這些推銷員卻不願談論相反的可能性，萬一價格出現反向走勢，就可能勾消你的保證金。從事期貨交易不同於購買選擇權，市場走勢造成的損失，可能超過保證金。期貨交易帳戶可能出現赤字，你會欠經紀商錢；換言之，期貨交易損失可能超過100%。基於這個原因與其他考量，在沒有充分準備之前，千萬不要從事期貨交易。

讀者如果想要做這方面的準備，不妨閱讀目前最棒的一本相關書籍，史瓦格的《史瓦格期貨技術分析》（Technical Analysis, Schwager on Futures，中文版，請參閱寰宇出版公司）。

假定我們不打算利用期貨契約進行投機，而是要針對道瓊鑽石成分股或道瓊指數成分股的投資組合進行避險。換言之，我們要買保險，不是投機。作爲一個非常簡化的例子，投資人發現道瓊指數不能突破某個頭部而開始進入區間整理（可能是連續或反轉型態）。碰到這種情況，他可以放空道瓊指數期貨作為避險。現在，他同時持有多頭與空頭部位：做多現貨，放空期貨。期貨部位的停損，設定在賣價的稍上方，萬一價格持續上漲，就平倉出場。反之，如果價格下跌，他將繼續持有期貨部位，直到修正走勢見底，或直到他判定行情已經向上反轉為止。這個時候，期貨部位將獲利了結（需要課稅），但他仍然持有現貨部位，整體獲利應該可以彌補稅金，也應該可以彌補如果賣掉現股而重新建立部位的困難與滑移價差。

# 指數或期貨選擇權

選擇權可以用來投機或避險。舉例來說，在一段突兀漲勢之後，某投資人認為他做多的S&P 500或S&P存託憑證（SPDRs）進入超買狀態。於是，他可以購買S&P的指數選擇權，防範預期中最可能發生的跌勢。如果股價真的下跌，選擇權部位可以獲利，而原先持有的S&P部位繼續存在。反之，如果股價指數繼續挺進，他將損失選擇權的權利金，這等於是為了防範股票投資組合發生損失而支付的保險費。

附註：前述策略只是提供給讀者參考的概念。實際採取這類策略或任何陌生程序之前，投資人務必要徹底瞭解相關資訊，透過模擬操作重複演練，測試各種可能發生的結果，然後才可以實際投入資本。總之，投資人必須搞清楚可能發生哪樣的損失。很多網站提供這類服務，投資人也應該在電腦中另外建立模擬投資組合，不要與實際交易混在一起。

交易者也可以操作期貨選擇權（期權）。芝加哥期貨交易所（CBOT）同時提供道瓊工業指數的期貨與選擇權。期權操作與前述的現貨選擇權很類似，可以用於投機或避險，唯一的差別是期權的根本資產是期貨契約，不是現股或股價指數本身。如果投資人對於期貨操作不熟悉的話，可能會覺得很不自在，尤其是期貨價格與現貨價格之間如果有很大差距的話，這種情況發生在1987年與1989年，當時的期貨價格曾經遠低於現貨。信用擴張程度是採用期貨契約的主要理由之一。採用期權的主要理由，是對於未來走勢的不確定，只願意花費選擇權的權利金。

對於投機客來說，他當然可以把股票與期貨完全擺到一旁，只針對選擇權進行交易。可是，實際採取這項措施之前，交易者或許需要到大學研究所上課。請注意，成功的選擇權交易者之中，業餘與專業玩家之間的人數是不成比例的。事實上，我們甚至可以说，成功的選擇權交易者都是專業玩家。

# 現代投資組合理論

現代投資組合理論（Modern Portfolio Theory，簡稱MPT）是投資組合經理人為了嚴格控制風險與報酬，而對於投資組合之成分所做的分類與分析。這類程序希望在風險與報酬之間找到量化關係。不只是分析投資組合的個別成分，MPT試圖決定投資組合構成部分彼此之間的統計關係，以及它們與市場之間的關係。

MPT的分析程序包括：
- 投資組合價值評估，透過期望風險與期望報酬來描述投資組合；
- 資產配置，決定資本如何配置到各種不同的資產類別或交易工具（債券、股票……等）；
- 最佳化，透過投資組合成分選擇來調整風險/報酬之間的得失關係；
- 績效衡量，根據個別股票的風險做系統性或證券相關的分類。

對於一般投資人來說，MPT有什麼重要性？不多。事實上，對於專業分析師（例如：本人）與專業玩家，MPT是否具有實用價值也是很大的問題，雖然大家都把MPT看成是發生船難狀況的救生圈。孟德爾布洛特（Mandelbrot）曾經在論文（「華爾街多重碎形漫步」，A Multifractal Walk Down Wall Street）與《科學美國人》（Scientific American，1999年2月與1999年6月）表示，MPT捨棄大約5%的統計經驗，就如同資料不存在一樣（實際上是存在的）。他發現，所忽略的經驗包括市場的「10級」超級風暴，但這導致投資組合失敗的原因，卻歸咎於資料錯誤，而不是程序錯誤。

# 神奇的投資科技

金融與投資理論還有哪些新發展，是一般投資人應該知道的？（請參考第42章討論的VAR）。原則上，當然是愈多愈好，但最頂尖的玩家不僅知道所有的相關發展，而且還不斷追尋各方面的可能運用。可是，如同馬基所說的，究竟什麼是充分而必要知道的（請參考《華爾街心理戰》）？除非心智狀態很幼稚，或具備宗教般的極端信念（這些人根本不知道己不知道），否則沒有什麼是絕對明確的。所以，我只能說，本書或許已經提供一般投資人所需要知道的，而且知道這些也就夠了。

# 芝加哥期貨交易所
## 道瓊指數期貨的投資與避險策略

期貨契約是同意在未來某日期，買進或賣出特定商品的契約。舉例來說，如果做多玉米期貨，除非在結算日之前賣掉期貨契約，否則就必須在未來某日期、接受玉米交割。反之，如果放空期貨的話，除非回補（沖銷）該部位，否則將來某日期必須交割玉米。就此處討論的主題來說，所謂的「商品」，是指道瓊工業指數成分股。所有的期貨契約，都規定相關交易必須終止的日期，也就是「結算日」（settlement date），並說明結算的交易方式，也就是「交割」（delivery）。道瓊工業指數期貨契約的價格，基本上完全反映其成分股的價格。

期貨價值等於指數價格乘以 $10。舉例來說，如果期貨指數價格為 10000，契約價值為 $10 \times 10000 = \$100,000$。所以，這種契約的買賣雙方，其交易代表的股票價值大約是 $\$100,000$。實際價值可能稍高或稍低，可能造成影響的因素有幾項，包括下文將討論的持有成本。

# 期貨契約結算

所有的期貨契約都必須結算。某些期貨是透過「交割」方式進行結算。這也是我們經常聽說的夢魘：一早醒來，發現院子裡堆滿 5000 蒲式耳黃豆。道瓊指數期貨是採用現金結算（交割）。空方沒有必要實際運送一大堆道瓊工業指數成分股，倒在多方的家門口。換言之，在契約結算日，結算價格等於 $10 乘以所謂的「特別開盤價」（Special Opening Quotation），後者是在道瓊指數期貨最後交易日隔天，根據成分股開盤價而計算出來的數值。這項數值將與契約建立當時的價格做比較。舉例來說，如果道瓊期貨到期水準為 10000，當初買進的指數水準為 9000，則多方將取得 $10,000 ($10 \times 1000)$，空方支付對應金額。

### 按照市價進行結算

可是，前述的$10,000並不是在契約到期一次支付，而是按照市價變動每天支付。這些付款每天都由「保證金」扣減。這些保證金並不是交易價款的一部份，而是「定金」或「履約擔保金」。每天交易結束之後，所有未平倉期貨部位都必須根據最新的市場價格結算價值。然後，依據最新結算價格與前一天結算價格的差價，某方必須支付給另一方相關金額。

舉例來說，由5月17日到5月18日，道瓊期貨指數由9800上揚到9840。當天結算的時候，空方必須支付 $400 ($10 \times 40)$，多方則會取得$400。隔天，如果期貨指數下跌10點，多方必須支付$100給空方。所以，在期貨契約到期之前，未平倉部位每天都必須根據最新期貨指數進行結算。

只要在開盤時段內，期貨部位隨時可以透過反向交易沖銷既有部位；多頭部位可以賣掉契約，空頭部位可以回補契約而結束既有部位。在契約到期日，所有未平倉部位則根據最後結算價格進行現金結算。

### 可取代性

類似如芝加哥期貨交易所或芝加哥商業交易所等集中市場，其最大貢獻之一，就是提供標準化的契約。這包括可取代性（fungibility）的功能在內。不論是玉米、股價指數或任何商品，期貨契約的根本資產只要相同，就可以彼此充分取代。另外，交易所也指定清算公司取代交易對手的地位，使得每位交易者的往來對手都是清算公司，不需承擔交易對手可能不履行契約義務的風險。換言之，如果有任何交易對手不履行契約義務，相關損失是由清算公司承擔。還有，由於未平倉部位每天根據市價進行結算，輸贏雙方每天都會結清帳目，如此可以顯著減少不履約的風險。

未平倉期貨部位都必須存放保證金（履約擔保金）在經紀商處。對於股票交易者來說，保證金創造的信用擴張程度是很可觀的。起始保證金經常是契約總價值的 3～5%。往後，每天必須繳納或收取的變動保證金，則取決於每天按照市場價格進行結算的金額。

讀者應該很容易瞭解，買賣道瓊指數期貨，等於是買賣一個相當龐大的股票投資組合，但期貨部位在未來某特定日期之前必須結束，這不同於現貨股票幾乎可以無限期持有。

# 現貨與期貨的差異

現貨與期貨交易的最主要兩項差異為：
- 現貨部位，投資組合價值必須先付價款，或透過股票融資帳戶借款。
- 現貨部位持有人可以收取現金股息。

當然，兩者之間的差別不僅止於此。期貨交易具備顯著的信用擴張能力，但這是兩面開鋒的利刀。如果交易者毫不保留，些許行情波動就可能勾消帳戶。對於現貨部位持有人來說，前述些許行情波動造成的影響，甚至很難被察覺。

# 道瓊指數期貨

期貨價格與指數價格之間，存在密切的關連（請參考圖 199.1）。兩種價格如果出現不正常的背離，就會立即引發套利交易：套利者會買進價格低估者，同時放空價格高估者，直到不正常的背離現象消失為止。這兩種價格不會剛好相同，因為期貨價格還會反映放空股票的短期融通成本，以及指數成分股發放的股息。這也是所謂的「持有成本」（cost of carry）。期貨的「理論價格」，應該等於指數價格加上持有成本。這也就是所謂的「公平」或「理論」價值。

# 運用股價指數期貨控制行情暴露程度

道瓊工業指數成分股投資組合或鑽石組合持有人，可以運用期貨進行避險，藉以控制風險與行情暴露程度。舉例來說，假定投資人對於行情後市看法悲觀，更明確來說，由於上升趨勢線被貫穿，技術面轉差，他可以放空期貨契約，數量約略等於現貨部位，使得行情暴露程度大約降到零。

# 第17-B章 投資科技進展

讀者應該可以立即體會這種策略的效益。現貨投資組合可以繼續持有，不會引發稅金問題；另外，如果必須先結束現貨部位，稍後重新建立部位的話，勢必會發生滑移價差、失誤……等問題。長期投資部位最好還是不要亂動。透過對應的期貨空頭部位來規避風險，不只可以確保投資組合的未來價值，而且相關資本還可以賺取貨幣市場報酬。

如果預期的跌勢確實發生，那該如何呢？投資組合可以得到保障，相關資本可以賺取市場報酬率。可是，投資人要密切觀察行情的演變，一旦修正走勢結束時，就要沖銷期貨空頭部位。這個時候，期貨的資本利得當然有稅金問題。

追蹤避險操作的过程，必須考慮行情不跌反漲的情況。當初規劃期間，就應該考慮這種可能性，預先決定如何解除錯誤的避險部位。最糟的情況，是拿現貨部位的獲利，來彌補避險部位的損失。這當然沒有考慮現金流量的影響。

關於這種策略，或許值得強調（或特別強調），相關操作需要專業知識與研究分析。草率運用這類技巧，可能會讓業餘投資人陷入困境。所以，剛開始做這方面操作時，最好有專家指導，事先也要先做模擬交易。

精明投資人可以運用指數期貨契約來強化行情的暴露程度，但這種作法可能讓投資人變成受傷的投機客。由於期貨交易具備的信用擴張能力，所以只適合於有經驗的投機客運用。

相對於買賣整籃股票，道瓊期貨交易的成本顯著較低。專業基金經理人或其他專業玩家，經常採用期貨契約做為資產配置或調度的工具。在可能範圍內，這些專業交易者都會充分運用期貨契約提供的財務槓桿。換言之，如果他們擁有價值$100萬的現貨部位，就不會只買進價值$10萬的期貨。他們真正關心的，不是期貨交易的財務槓桿，而是在短線運用上的靈活性。透過期貨契約，幾乎可以在瞬間之內進、出市場，而且完全不會干擾既有的現貨部位，這是期貨交易重要的優勢。

# 運用道瓊指數期貨進行投資

下列例子將討論道瓊期貨契約的基本運用。這種契約可以根據預期的行情發展，調整股票投資組合的風險暴露程度，也可以用做為資產配置工具，藉以調整各種資產類別之間的比例。當然，道瓊指數期貨的實際用途，絕對不僅限於此處討論的範圍。下文討論的例子，只強調這種契約的可能運用，沒有強調實際運用上需要注意的細節。另外，為了單純起見，此處也不考慮持有成本或「按照市價進行結算」的保證金付款。

假定你是一位馬基型投資人，擁有一個歷史相當悠久、續效表現很不錯的股票投資組合。現在，你看到道瓊工業指數出現擴張頂排列（如同2000左右的情況），而且時序接近10月，恐怕會有「血光之災」。目前，你所持有之股票投資組合，價值大約是 $400,000，另外持有$100,000的貨幣市場交易工具。你想要讓兩者之間的比率對調，但又不想實際賣掉股票投資組合，因為道瓊工業指數主要趨勢並沒有明確向下反轉的跡象，只是可能向下修正而已。所以，你放空價值 $300,000的指數期貨，只留下價值$100,000的淨部位，防範股票行情不跌反漲。當時，道瓊指數為10000，期貨價格為10500，持有成本大約是0.5%（10500/10000－1）。
