# 潛伏底變形

潛伏底（dormant bottom）頗似圓形底，屬於主要底部型態；事實上，這是一種極端「長期、平坦」的圓形底。這種型態通常發生在成交量很少的個股；換言之，股票發行數量或流通籌碼很有限。即使是在上漲過程，每天成交量也可能只有200、300股。最後，經過幾個星期或幾個月的發展，過程幾乎沒有什麼成交量可言，只是偶爾出現1、2筆交易，價格波動幅度很小。這類走勢圖就像是由「小斑點」銜接而成。

最後，在沒有明顯理由的情況下，交投突然轉趨熱絡。每天成交量為幾百股，價格急漲。就如同圓形底的情況一樣，潛伏過程突然「驚醒」的走勢，通常是「早產」的突破。隨後幾個星期的成交量，可能再度萎縮，或呈現具來愈來愈短的階梯狀走勢，最後才發展為連續性漲勢。總之，整個過程代表重要的承接模式。

我們不難理解潛伏底的發展過程。由於股票數量很有限，只有在很罕見的情況下，才能看到「市價」賣出的籌碼。如果特定人士（或許是與公司經營者有關的內線集團）想要拉高吃貨，股價就會一飛沖天。所以，買家只能「拿著籃子在樹下等」，被動承接任何賣出的股票，但不主動抬高價格，直到樹上熟透的果實都掉光為止。然後，買家稍微抬高價格，希望能夠進一步吸引籌碼賣出。
