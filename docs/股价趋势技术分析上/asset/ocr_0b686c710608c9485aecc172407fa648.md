# 第12章 跳空缺口

![](bbox=[0.13, 0.12, 0.88, 0.41])

圖126. 這份1946年早的日線圖，包含很多有趣的技术現象。1945年12月，股價由19上漲到25，然後進行9個星期的矩形整理（上圖顯示相關排列的末期階段）。2月11日，股價透過典型的突破缺口，向上穿越矩形排列。4天之後，出現另一個成交量更大的跳空缺口，當天幾乎是以最高價收盤。這看起來向是逃逸缺口；若是如此，根據衡量法則估計，上檔目標價位應該在32。（請注意，矩形排列的衡量目標在31。）可是，隔天出現單日反轉，高價在31，收盤價為30；然後，次一天走勢封閉2月15日的跳空缺口，所以這個缺口必須重新定義為竭盡缺口。隨後，價格下跌到9個星期矩形排列的支撐區，並沿著中期上升趨勢線緩慢攀升。4月24日，價格跌破趨勢線，再度拉回到矩形支撐區25。5月份，展開另一波漲勢，價格上攻到30附近，但遭遇先前趨勢線延伸的壓力。這是最後一波向上嘗試；7月底，當價格跌破兩個峰位所夾的「谷底」25，完成主要雙重頂排列。

讓我們回頭觀察2月15日的跳空缺口，唯有在缺口完成之後的2、3天，才能判定該缺口究竟是逃逸缺口或竭盡缺口，此處是相當典型的案例。
