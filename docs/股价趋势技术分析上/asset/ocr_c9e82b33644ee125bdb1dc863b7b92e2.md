# ## 其他三角形排列

我們還可以見到其他整理或密集交易的型態，這些排列也是由相互收斂的邊緣界定，因此也稱得上是三角形。可是，這些排列在某些方面，迥然不同於本章討論的型態性質，所以應該歸屬另一類別，例如：旗形（flags）、三角旗形（pennants）與楔形（wedges）。還有另一類型態，其邊界呈現發散狀（diverging），這類排列也可以稱為「顛倒三角形」。可是，由於其發生原因、排列性質與預測意涵等，全然不同於三角形排列，所以我們稱其為擴張頂排列（broadening formation），後文將討論。

本書所做的評論，經常採用「通常」、「一般」或其他類似修飾詞，讀者或許會覺得失望。可是，如果我們想呈現實際情況，這些修飾語的限制往往是不可避免的。沒有任何兩份走勢圖會完全相同，沒有任何兩個市場的發展會完全一致。股票市場的歷史雖然會不斷重演，但實際劇本還是有些差異。雖說如此，但投資人如果熟悉這些歷史發展型態，假定未來行情將依照正常途徑發展，不要認為「這次將不一樣」，操作績效應該可以超過那些追求「例外」的對手。
