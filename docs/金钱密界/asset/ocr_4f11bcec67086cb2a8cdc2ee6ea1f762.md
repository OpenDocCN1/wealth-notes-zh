# 川普的俄國生意夥伴

二〇一三年十一月，川普走在莫斯科環球小姐選美會紅毯上，滿面春風。他的俄國行程格外順利，即便普丁並沒現身。前一年六月，川普在推特發文推測普丁是否會參加時，口吻聽來簡直像普丁的大粉絲。川普問道：「你認為普丁會來十一月在莫斯科的環球小姐選美賽嗎？21 如果來，他會成為我最新好友嗎？」普丁沒來，而送上一只噴漆的裝飾盒及個人便箋。22

然而，真正的示好求愛，發生在選美會的邊廂。俄羅斯生意夥伴支持川普那次選美會，是阿拉斯及葉甫·阿加拉羅夫（Aras and Emiri Agharov）這對父子檔億萬房地產開發商。阿拉斯·阿加拉羅夫是普丁的密友，一個月前曾由普丁本人頒授俄國榮譽勳章給他。23 這趟行程中，阿加拉羅夫父子與川普討論在莫斯科興建組合式公寓大廈。

在一場與阿拉斯·阿加拉羅夫共同作東的會議上，川普與一羣俄羅斯寡頭精英見面，包括普丁的前經濟部長、當時主掌俄羅斯聯邦儲蓄銀行（Sberbank）的葛列夫（Herman Grc）。俄國行之後，川普向《房地產週刊》（Real Estate Weekly）誇口說：「我跟很多俄國人關係很好，24 當時所有寡頭幾乎都到會場了。」
