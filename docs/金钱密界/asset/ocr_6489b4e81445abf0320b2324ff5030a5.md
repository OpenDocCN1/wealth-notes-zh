# 巴拿馬文件

「總理先生，您以往或現在與離岸公司有任何牽連嗎？」

賈勞格松首度緊張起來，結結巴巴，前言不搭後語地回答說：「這個問題很不尋常……冰島政治人物被這麼問。感覺上好像被指控制什麼似的……但……我可以肯定，自己從未隱藏任何資產。」

燮曼接下來問道：「總理先生，您能跟我談談一問叫溫翠斯的公司嗎？」

一抹驚恐神色拂過賈勞格松的臉龐。他接下來講了更多語無倫次的話：「我開始覺得這個問題有點奇怪了。」

燮曼對賈勞格森說，他的冰島夥伴有細節，想進一步問他。克里斯蒂安松接下來用冰島語，連珠砲般地問問題。

生命中很少出現瞬間就此注定一個人或國家命運的時刻。賈勞格森本可以保持平靜，試著用口才擺脫那次採訪的。但他沒那麼做，而是突然由椅子站起來，向記者們反罵幾句，便從他能看到的第一道門逃出房間，而門是通往廚房的。克里斯蒂安松及燮曼隔著緊閉的門，要求他出來完成訪談，但沒有用。

時間倒推回九月，國際調查記者同盟高層在慕尼黑談論該替專案取什麼名字。格拉瓦請
