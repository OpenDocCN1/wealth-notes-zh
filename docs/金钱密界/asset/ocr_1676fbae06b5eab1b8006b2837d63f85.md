# 國際調查記者同盟的勝利

瓦絲奎茲（Rita Vasquez）按捺不下不祥預感，，因此二〇一五年九月初搭夜間班機從巴拿馬飛到慕尼黑，旅程中都沒睡著。瓦絲奎茲緊張的時候，往往會神經質地咯咯笑或微笑。巴拿馬《新聞報》（La Prensa）調查部主任羅德里格茲（Rolando Rodriguez）向她報告過普羅米修斯專案後，她無法控制地笑了起來。羅德里格茲接下來要她發誓保密，叫她簽署國際調查記者同盟的守密協議。

格瓦拉接洽過羅德里格茲，邀請他跟《新聞報》加入專案。邀請避稅天堂的當地報紙，真是很微妙的事，不過，羅德里格茲備受推崇，而《新聞報》大有來頭。該報創辦於一九八〇年，正值托里霍斯獨裁淫威最盛的時候，一群歸國流亡人士創辦《新聞報》。獨裁期間，政府強迫《新聞報》關門三次。犀利的報導，讓許多記者流亡海外。
