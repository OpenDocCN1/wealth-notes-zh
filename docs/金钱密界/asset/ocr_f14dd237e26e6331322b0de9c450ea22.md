# 尖文學獎。

馮賽卡幻想自己回歸筆耕生涯，打算蓋間寧靜的寫作房，成日寫作。二〇一三年，他在貝拉瓜斯省柳橙種植場買了塊地；賈耶哥神父曾在那裡服務。馮賽卡把柳橙樹送給當地農人，換來把水果實體還給他加工的協議；另外在離種植場不遠的地方，標示出他的寫作用房用地。

馮賽卡還進入政界，致力復興他外祖父的巴拿馬主義黨。二〇〇九年，巴拿馬主義黨與馬蒂內利（Rufato Martinez）的民主變革黨（Carto Democratico Party）組成聯盟。馮賽卡與馬蒂內利是國小同班同學，這又是孩提關係可以伴隨人的一生的例子。馬蒂內利二〇〇九年當選總統，任命馮賽卡為部長級顧問。只是兩年後，兩位老朋友關係變差。馮賽卡上電視節目，說總統是獨裁者。$^{14}$馬蒂內利則發推特炒了馮賽卡魷魚。

馬蒂內利治下，巴拿馬貪腐橫行。他下台後，二〇一七年大多待在邁阿密，對抗巴拿馬的引渡要求；他在巴拿馬面臨濫用公餡等刑事起訴。$^{15}$諸多指控當中，有一條款他撥款給龐大的偵監行動，私下監視一百五十多位巴拿馬商人、記者及政治人物。馬蒂內利任期結束，巴拿馬主義黨魁瓦雷拉（Mar Carlos Valera）當選總統，他是馮賽卡的密友，馮賽卡返回政府。瓦雷拉任命馮賽卡擔任他私人智囊團的成員，而且請他主管該黨。

同一時間，莫薩克娶到第三任妻子，也滿意了，與她成立新家庭。週末時候，夫妻兩人會去看女兒參加的馬術障礙比賽。莫薩克也積極參與當地扶輪社，任職於巴拿馬對外關係委員。
