# 在香港大學的祕密會議

國共產黨政治精英的子女，他們屬於現稱「紅色貴族」的成員；紅色貴族指過去、現在與中國高層有血緣或親的人士。中國並不要求官員公開申報資產。國家領導層的活動，非到記者们——先是外國人，接下來才是當地人——開始抽絲剝繭，不大致成謎。

二〇一二年，《彭博新聞》(Bloomberg News) 及《紐約時報》刊登一系列報導，揭露中國高階領導家族隱藏的財富，包括時任國家副主席的習近平及總理溫家寶。記者們切穿層層的結盟合夥及晦澀的投資工具，顯示出政權掛勾人物如何從國營企業瘋狂吃錢，向尋求好處的富商索取現金。中國的威權政體很快就用檢查封擋機制「防火長城」，斷斷中國互聯網與那兩個媒體的連結。參與在內的一位記者簽證到期了，中國高層也不准他續簽。

此時，國際調查記者同盟握有扎實資料，可以在這些新聞踢爆上深入耕耘了。沒人見過這麼廣泛的中國離岸活動。也沒沒有中國本地記者帶頭與外國同事合作，有系統地探究這麼敏感的主題。

位在香港大學內的儀禮堂巍峨龐大，是英國殖民時代所建，來自美國、德國、西班牙、台灣、香港及中國的記者們一起擠在儀禮堂二樓。這次會議刻意低調祕密。負責召集大家的香港新聞學教授陳婉瑩身形枯瘦，卡布拉把她稱為「國際調查記者同盟的尤達」；陳婉瑩並
