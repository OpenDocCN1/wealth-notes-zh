# CHAPTER

逃稅名單洩漏，引發全球追捕

離岸解密發布之後，全球稅務機關、檢察官爭搶。名字出現在資料的政客們則找理由說明，有公務員辭職，多國政府則保證未來將更加透明。盧森堡甚至宣布，將自動與美國稅務當局分享銀行帳戶資訊。同一時間，離岸服務提供者則哀嘆，解密的結果，讓業界陷入嚴重的「信任危機」。

離岸解密證明，來自不同國家、文化的調查記者能通力合作。國際調查記者同盟造出新式新聞機器，話雖如此，機器的結構依然鬆軟。跨境合作的記者們組成機器零件，但動力還是來自資訊——以本案來說，就是洩露出來的資料。只有高級資料才起得了效用，資料必須廣泛並涵蓋多個國家。國際調查記者同盟要求報導的基本理由得強力符合公共利益——主題內容攸關社會福祉。國際調查記者同盟主任賴爾希望的報導，既要吸引讀者注意，對出色的國際調查記者團隊又稱得上是挑戰；對最後這兩點，離岸世界再合適不過了。

賴爾一直是杞人憂天的人，預見來自離岸解密的動力會流失。單單一次合作成功，驗證概念的性質，要遠大於造就一台火力全開的機器。沒有新的專案，夥伴們免不了做鳥獸散。
