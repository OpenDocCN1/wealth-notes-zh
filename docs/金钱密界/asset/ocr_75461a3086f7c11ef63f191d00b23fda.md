異域浴血作戰。管家通常是男性成年親戚或朋友，監管著那些資產。信託對地主們也是很清楚的做法，可以逃避稅賦及繼承的糾葛。那個時代，遺產的法律基礎還不穩固，附有死後指示的信託，讓有錢人能把資產遺留給情婦，或者較疼愛的子女，就能規避不得讓女性取得遺產的禁令。信託確保家族生意，能交給聰慧的女兒，而非白癡兒子。

此時管家稱為受託人（Trustee），交付資產的人稱為委託人（Settlor）。政府既不登記也不認可這種受託人關係，由契約闡明雙方關係，它屬私人契約，以低成本的方式，就造出一層穿不透的隱密高牆。把資產以信託方式，交付受託人，可以享受擁有人的各項好處，又免掉稅捐及法律義務。嚴格說來，資產交付信託，就不再歸委託人所有，而歸受託人。課稅依信託所設地點而定，這樣讓英國人造出的避稅天堂興旺起來。信託法規定，違反守密將重重責罰。在巴拿馬，任何人違反信託守密，得處以五萬美元的罰金，或處有期徒刑達六個月。$ ^ { 27 } $

然而對莫馮的銷售團隊來說，信託有個大瑕疵：客戶並不信任受託人。在英美兩國，排名在前的信託機構都是老招牌。談到保護資產，它們聲譽卓著。此外，《信託衡平法》（Trustee's Law）行之有年，法院承認並了解信託行為。這些制度上的保護，在新興市場如拉丁美洲、中國及東歐付諸闕如——而莫馮追求在那些地區有所成長。

在那些地區，貪腐不受處罰，驅使人們前來莫馮挑買匿名公司。他們不僅不指望自己政府及司法系統能保護他們的財富，反而害怕政府官員想偷走他們的錢——如果他們自己並非小偷這一行。他們對自己國家機構欠缺信任，連帶對外國的也一樣，而且有時還大有道理。
