# 史上最大跨媒體合作

二〇一五年九月八日，超過一百名記者來到慕尼黑市郊，集會於《南德日報》的現代玻璃外牆大樓二十六樓「天空躺椅」（Sky Lounge）會議室。除開南極洲，各大陸都有人來。德國人本想把會議人數限制在八十，也就是會議室最大容量，只是隨著格瓦拉及國際調查記者同盟團隊挑選與會者，名單不斷增長。卡布拉回憶，就好像籌備婚禮，有些家族成員不邀，接下來在不經意之間，婚禮人數就破百了。

這場特殊的「婚禮」設有限制。以往國際調查記者同盟專案會議上，攝影師可以隨意走動，拍下會議進展，供記錄片之用，而與新聞同時發布。格瓦拉要求這次要有節制。她要夥伴們謹記在心，有些同仁居住、工作在環境艱辛的地方，出現在鏡頭裡就有危險。沒錯，會議室裡，有些記者調查撰稿的國家，其領袖或其他精英可以在資料裡找到，比如俄羅斯、埃及與委內瑞拉。因此攝影限制在某些議程，而在策略或個案討論時則應避免。主辦方請不願出現在鏡頭裡的人先行告知。
