# 離岸解密

徒勞無功。賴爾最後一刻再試一下，聯絡蒙古駐華府大使館。結果發現副議長正在華府開會。桑嘎扎布接獲狀況通知，匆匆趕往國際調查記者同盟辦公室。

賴爾及格瓦拉在會議室接待他。桑嘎扎布心慌意亂。他說，如果國際調查記者同盟發表新聞，談他的祕密離岸公司，那麼會毀掉他的名聲，讓他家族蒙羞。桑嘎扎布答應，如果國際調查記者同盟讓這件事保密，他返回蒙古後就辭職。他開始哭起來，對賴爾及格瓦拉說，那家公司銀行帳戶裡只有一百萬美元。這對國際調查記者同盟是新鮮事。賴爾試著對快抓狂的這位蒙古人表示同情。而格瓦拉想到還有一長串代辦事項，就比較粗魯了。最後他們說服他，請他離開，但沒做什麼保證。國際調查記者同盟最後刊載有關他的報導，連同他公司有多少錢，在他們資料密集的專案裡，增添人性化的元素。

報導見刊前幾天，竟出現最後一次「癌症驚嚇」。國際調查記者同盟摺出禁止外洩的新聞稿給網絡裡沒參與這次通力合作的成員，以便在這次深度報導刊登後，他們也能寫新聞。有位巴西成員誤以為新聞稿就是見刊內容，興奮之餘把專案的消息放上推特。國際調查記者同盟在推文還沒有瘋傳前，趕緊打電話到巴西，請他刪除推文。

這個專案很快就以「離岸解密」（Offshore Leaks）聞名。二〇一三年四月三日星期二見
