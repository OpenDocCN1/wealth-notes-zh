# 貪汙腐敗的指控

早在二○一三年，莫馮就曉得阿納爾·馬馬多夫（Anar Mammadov）這位三十三歲亞塞拜然商人的重要細節。莫馮的法務處將馬馬多夫的姓名，輸入「世界查核」查詢。「世界查核」是付費資料庫，莫馮憑這個資料庫判斷一些客戶有沒有被世界刑警組織通緝，或者深陷媒體負面報導。事務所取得他護照的影本。馬馬多夫還提供簽了字的財產來源聲明，文件顯示他是政治敏感人物，有位親戚是亞塞拜然政府官員。馬馬多夫甚至講明自己的離岸公司要做什麼商業用途，即保管資產與投資。

莫馮的盡職調查指出，阿納爾的父親是亞塞拜然的運輸部長齊亞·馬馬多夫（Ziya Mammadov），還挖出不怎麼討喜的新聞報導。阿納爾·馬馬多夫是靠運輸特許權、公共營造專案及石油勘探，變成億萬富豪的。他宣稱，自己創辦該國最成功的商業開發公司之一，而當時他還沒滿二十二歲。那家公司可能只是他父親的幌子，阿納爾還在倫敦大學當全職學生，公司就經歷爆炸性成長。馬馬多夫家族专精於不招標的國家發包案及專賣權，而且擁有亞塞拜然最大計程車及客運公司。$^{50}$
