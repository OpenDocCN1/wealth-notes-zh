# 史上最大的離岸資料庫

離岸公司開戶的客戶，該索取多少資訊。但官署的舉措，沒能跟得上總統崇高的演說。那些新法規，因為銀行業游說反對，本已被擱置達兩年。稅改志士抨擊，此時由雙方相門過程序現出來的法規，實在退讓太多。

在此之前，美國銀行經常努力想找出公司實際的所有人，原因在它們害怕萬一受益人是恐佈或犯罪分子，那麼負面影響令人擔憂。它們或許沒把那些資訊寫下來，但還算知道。此時，財政部允許它們不必知道。只有公司藏鏡人持有二五%以上，銀行才必須調查。財政部還允准銀行調查到設公司的律師或中間商就好。

首度突襲莫馮總部一星期後，卡拉巴羅針對該事務所所貯放實體文件的貨棧，進行類似行動。調查員帶回好多袋碎紙處理的文件紙本$^{34}$，事務所發言人說，那些都是垃圾，等著回收。袋子被允充之後，堆在沒頂篷的平板卡車上頭。隨著卡車加速轉彎過貨棧附近鄰里，有幾個袋子飛出車外，袋口爆裂，灑得街道都是機密文件的紙屑。當天稍晚，《新聞報》記者們沿門挨戶拜訪該區鄉親，蒐集紙屑，看看袋子裡裝的是什麼。他們找到的內容，已經存在檔案庫裡了。
