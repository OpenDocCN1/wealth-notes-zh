# CHAPTER 6

稅則規定愈多，避稅天堂就愈賺錢

二〇〇三年三月號的《莫馮公司時事通訊》讀得出勝利的喜悅。OECD儘管威脅到「我們客戶的金融隱私」，但離岸世界已經將其逼退。

OECD 要求各避稅天堂消除低稅率，並提供能接觸到祕密金融與企業資訊的訊息管道。巴拿馬帶頭抗拒，譴責 OECD 強人所難，這些要求違自己的會員國都拒絕接受，竟然要避稅天堂去做。後來出現一個突顯西方國家偽善的契機，當時歐盟宣布被為稱「儲蓄指令」（Savings Directive）的條款，要求歐盟會員國向歐盟公民持有的外國銀行帳戶孳息收稅，並分享資訊。盧森堡以國家經濟需靠金融保密為由，拒絕參加，卻也沒有因此受罰。巴拿馬便大喊不公平

避稅天堂在華府例是有意識型態方面的強大盟友。國會共和黨籍議員及小布希政府大肆批評儲蓄指令，拒絕與 OECD 合作。雖說美國就捕恐怖分子樂於提倡國際合作，小布希政府倒不喜歡逼人民繳稅。資金充裕的智庫遊說國會，想完全取消化 OECD 的捐贈——占其預算約二成五。這股壓力逼迫 OECD 差一點放棄其黑名单以及稅改行動。
