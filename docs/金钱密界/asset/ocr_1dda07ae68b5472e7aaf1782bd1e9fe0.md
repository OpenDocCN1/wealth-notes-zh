# 現代版維京海盜：冰島破產危機

二〇〇九年三月，冰島一家電視台邀請法國前法官兼反貪腐鬥士伊娃·喬里（Eva Joly）上週日談話節目，談論冰島的危險處境。四個月前冰島面臨金融危機，是二〇〇八年金融海嘯最早的受害者之一。前三大銀行的資產總額達國內生產毛額的十倍1。國債總額使得冰島這個小島國的每個國民都背負四十三千美元程度的負債2，資本流動性極低，冰島貨幣克朗價值劇貶。一夜之間，冰島人民無法償還貸款，島國必須的進口品價格格飆。窮困、迷惘又生氣，冰島人民來到首都雷克雅未克街頭，想找到怪罪對象。

出生在挪威的喬里長久以來敬重堅毅的冰島人。儘管幾百年來冰島人作為貧窮的漁民，與惡劣的生活環境搏鬥，但就保留維京人文化方面，冰島要比挪威做得更好。喬里獨自回到挪威，在此之前，他在法國偵辦億而富（Elf）石油公司，這間公司陷入醜聞而成為貪腐、行賄、與洗錢網絡的中心。多年審訊下來，法國大眾對這起醜聞，以及承審本案奮戰不已的法官，已經厭倦了。二〇〇二年，她受挪威司法部的邀請，在「國際開發署」（Agency for International Development）擔任特別顧問3，參與組織對抗全球貪腐的行動。
