# CHAPTER 3

# 販售隱密的王國：建立經銷網絡

加上英屬維京群島、巴哈馬與紐埃，莫馮已替它的空殼空司找好避稅天堂的據點。下一步該做的，便是設法把產品，賣到更多客戶手上──更多更多的客戶。莫薩克及馮賽卡從麥當勞的營運模式中得到靈感，認定達成目的的方法，便是特許經銷。他們想找出擅於銷售的人，把他們變成莫馮的經銷商。為了取得自己區域內獨家經銷莫馮產品的權利，經銷商以很差的折扣拿到那些匿名空殼公司。莫薩克認定，事務所這麼做，可以用最少開銷擴大市場。

除開經銷舊，透過經銷商賣出公司還有另一個好處，那就是在莫馮業務與產品的終端客戶（也就是公司的受益人）之間，又添增一層阻隔。莫馮可以仰仗經銷商，確保公司合法使用。如果受益人經證實有不良行為，莫馮就可以宣稱，是經銷商（或者律師、會計師、銀行家）未能妥善過濾買方。此道精髄就在卸責。話雖如此，想把責任推卸給經銷商，事實上很困難。做惡很難遮掩，要掩埋罪行十分麻煩。雪上加霜的是，當合夥人認為獲利大於風險時，莫馮是甘願賭一把，直接參與可疑活動的。
