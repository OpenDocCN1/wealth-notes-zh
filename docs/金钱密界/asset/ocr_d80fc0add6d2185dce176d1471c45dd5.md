# 受邀參與調查

克里斯蒂安松（Johannes Kristiansson）沒能及時趕回雷克雅未克自己的公寓，跟國際調查記者同盟的格瓦拉用 Skype 視訊通話。他開到加油站，停在洗車機附近，用手機接聽電話。時間是二〇一五年五月二十八日。這位魁梧蓄鬚的冰島男子對格瓦拉要做什麼，茫無頭緒。

克里斯蒂安松是冰島最出名的調查記者之一，他累積的勝利與失敗，數量可以讓一般人記過好幾輩子。他好奇心太重，又愛內省，所以不適合拖網漁船工作，年輕時便深受新聞業吸引，先從雷克雅未克市郊一間週刊當在地記者。接下來他到冰島電視報新聞的第二頻道找工作，很快就察覺出電視報新聞栩栩如生。他的小記者單調的工作並不滿意，纏著上司讓他去調查冰島販毒生意裡，影響力日增的「地獄天使」（Hells Angels）。上級准他用自己的時間去做這條新聞。就這則主題，克里斯蒂安松產出五則報導。節目的品質說服第二頻道，讓克里斯蒂安松主持新聞雜誌性節目，後來節目叫《羅盤》（Kompas），勇獲大獎，並因犀利調查而廣獲讚譽。它最大一條獨家，是揭露一名冰島最受愛戴、知名路德派神父，其實在金錢方面很腐敗，還是戀童癖。那名神父拿公帑替青少年辦戒毒機構。新聞播出而衍生的壓力，也是克里斯蒂安松第一次婚姻破裂的原因。
