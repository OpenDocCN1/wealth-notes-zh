# 致謝

二〇一五年五月，國際調查記者同盟資深編輯哈德森對我說，他們已推出一項專案，可
能很適合我。他沒在電話裡透露細節，反而是鼓勵我前往華府，與國際調查記者同盟主任賴
爾、副主任渥克會面。
賴爾與我走路去吃午飯，他跟我談到普羅米修斯專案，那項龐大的資料外洩，國際調查
記者同盟還在接收過程中。那批素材提供前所未見的視野，看透隱密世界，有潛力傾覆好些
政府。吃完飯的時候，我已經參加了，而不曉得這項命題會耗盡我兩年多的歲月。
接下來的職場經驗，是我擔任記者二十五年來最愉快之一。素材之迷人無窮無盡。對一
個好奇心大於一切的人，幾乎每一個轉折都有新發現等著去耕耘。但是，讓這起工作不止像
挖到報導金礦的，乃是在大家通力合作。
我很快發現，自己與來自全球最頂尖的調查記者共事。大多數人透過國際調查記者同盟
更早就專案合作，已彼此認識。他們很開放，樂於助人，對那批素材跟我一樣興奮。我們因
