# 對記者宣戰

選舉之夜，川普與土耳其總統艾爾多安通電話時，替伊凡卡做了宣傳。川普告訴艾爾多安，她是他的粉絲兼支持者。電話裡，他推崇自己女兒是川普土耳其建設案的成功關鍵，他已授權該酒店使用自己姓氏。

二〇一二（2012）年四月，伊斯坦堡川普大廈落成典禮上，伊凡卡就在川普身旁。前一天，艾爾多安才替大廈開幕典禮剪彩。那些四十樓高而連結起來的住商大廈主打公寓、高級店面、健身房、游泳池及電影院。當時，伊凡卡向土耳其媒體說：「四年前我與雅爾琴達見面，開始討論本案時，非常興奮。雅爾琴達與道昂家族結成姻親；川普描述道昂家族時說他們超越生意夥伴。還變成要好朋友。」

美國總統競選時，艾爾多安說，自己很後悔前往該建築物的開幕典禮，而且要求把川普的姓，由大樓群除掉，原在川普說「不能容忍在美國的穆斯林」。那番談話是另個例子，顯示土耳其總統與道昂家族的關係陷入緊張。
