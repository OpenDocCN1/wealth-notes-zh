# 別讓愛爭財產的親戚發現

高更一九九二年在毛利島繪下《從前》(Mata Mua)，當地語的意思是「古時候」。這幅色彩豐富的油畫描繪著一處山巒周遭的風景，裸肩的棕色女子沿著一個巨大的藍色神像跳舞，神像為月亮女神。據馬德里市提森-波涅米薩博博物館（Tyzsen-Bornemisaiza Museum）描述，畫作內容為「敬輓消失的黃金時代」$^{27}$，《從前》目前展示於該館。

那幅畫作現在是由暱稱「蒂坦」（Tia）的卡門·提森-波涅米薩（Carmen Tyssen- Bornemisaiza）借給博物館展覽的；她是西班牙前選美皇后，繼承祖上豐厚遺產，個人藝術品收藏大約七百名名畫，價值逾五億美元。她已過世的丈夫提森-波涅米薩男爵（Baron Hans Heirich von Tyssen Bornemisaiza）是世界上藏品最多的藏家之一。他還善加使用避稅及離岸隱密的黃金時代，這項遺產，碰到祕密外洩及加強管制的現在，他的遺孀想要維持就頗為費力。
