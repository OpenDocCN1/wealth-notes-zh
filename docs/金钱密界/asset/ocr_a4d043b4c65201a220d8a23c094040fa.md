# 藏在自由港內的超高價名畫，免税！

正如瑞士替外國人藏錢在銀行的技術高人一等，這個阿爾卑斯山國家也替藝術品做類似服務。藝術品交易在瑞士可達數十億美元¹。交易中心是日內瓦自由港（Geneva Freeport），它在市區西邊的工業區裡，儲存空間逾六十萬平方英尺（約一萬六千八百多坪）²。當地的主要建築群躲在安全圍籬牆背後，裡頭有一排多樓層的紅灰色貨棧。貨棧裡收藏近一百二十萬件藝術品³，從古羅馬古董到估計一千件畢卡索作品，琳琅满目⁴。總計起來，放在日內瓦自由港的藝術商品，保守估值在一千億美元以上⁵。它跟博物館不同，沒人能源見這些珍寶擺在一塊。藝術品鎖在保險櫃，很多案例顯示，櫃中物品只有物主知道。如果有人想隱姓埋名的話，一如很多自由港顧客，創立一間設在英屬維京群島或類似離岸轄區的公司裡，再用公司名義承租保險櫃。在瑞士，沒有規定離岸公司的受益人必須公開，因此自由港不會索取公司背後受益人的身分。然而，能吸引人到這個很有趣、看來很不顯眼的自由港，原因與其說是隱密，不如說是金融上的好處。只要藝術品待在自由港，它就免税。一個有錢人可以在紐約的拍賣會上買下畫作，把它送往日內瓦自由港，接下來除非它
