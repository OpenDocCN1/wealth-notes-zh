# 他們在找代罪羔羊

二〇一七年二月九日上午，司法部官員搜查莫薩克與馮賽卡的住宅。兩名合夥人接下來被傳訊。來到司法部外頭，沒剃鬍子而氣到臉孔扭曲的馮賽卡隨即召開記者會。

他表示：「我們一直默不作聲，但奧德布雷赫特這件案子太過分了。」

馮賽卡替事務所辯護，認為該怪罪的應該是賣出公司的銀行家及律師。馮賽卡繼續說，事務所很多生意是跟跨國大銀行如匯豐做的，接下來添一句說，匯豐給莫馮找了很多麻煩。

他評論，涉及洗錢行動的離岸公司一萬多家，他問道，檢方為什麼只挑我們？

有位記者打岔，馮賽卡請她稍待，他才能講到好戲。

他接下來透露，任職於瓦雷拉政府，他耳聞到一些事情，讓他相信政府貪腐。瓦雷拉自己就從奧德布雷赫特收到競選捐獻——只是都合法。此事後來遭總統反駁。奧德布雷赫特在巴拿馬也有強大的賄賂行動。巴拿馬檢方為什麼鎖定莫馮，而不去找那些直接與奧德布雷赫特共事的律師？

馮賽卡誇張地說：「我若撒謊，就遭天打雷劈。他們是在找代罪羔羊。」

他譴責瓦雷拉沒能保衛巴拿馬的金融制度。馮賽卡輕蔑地說：「我們等於在國際機構前脫掉褲子。」
