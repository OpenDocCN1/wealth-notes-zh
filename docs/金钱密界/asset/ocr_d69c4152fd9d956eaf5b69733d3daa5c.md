# 莫馮事務所進駐中國

莫馮名列到中國販賣匿名公司的先鋒之一。一八九七年，事務所便到香港開設辦事處，當時那座城市還屬英國管轄。長久以來，香港政商名流最愛藏錢的地方，便是巴拿馬及賴比瑞亞，但等到巴拿馬的諸瑞加及賴比瑞亞的多伊（Samuel Doe）分別蹂躪自己的國家，大家對這兩國生產的公司就沒什麼興趣了。

莫馮在香港設點，推銷新的離岸轄區英屬維京群島，當地沒有亂七八糟的政治問題。馮賽卡花了一個月住在香港飯店裡。他挑選滿是律師事務所的不同大樓，沿門挨戶投送莫馮的小冊子，只要有人願意聽，他就攀談閒聊。

莫馮香港辦事處最早是由一位印度女性經營的，但隨著一九九七年香港移交給中國的時間逼近，事態很清楚，莫馮得找一個說普通話的本地人來主持業務。莫馮在巴拿馬便用過奧斯丁·張（Austin Zhang）的翻譯服務。這個人出生在陝西省，漢名張曉東。他曾遊歷世界，最後落腳於巴拿馬，當地有不少華裔人口。莫馮雇他擔任譯者的時候，他正替當地華文報紙工作。張曉東接受離岸業務的短期密集課程，同時花一年翻譯文件及小冊子。最後他用中文寫了本小書，談論如何設立離岸公司。
