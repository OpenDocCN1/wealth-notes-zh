# 我們不是天使，可也不是魔鬼

馮賽卡坐在巴拿馬市莫馮大樓的角落辦公室。時間是二〇一六年十二月初，離巴拿馬文件公布有已八個月。事務所衰敗的跡象包圍著他——整個建築物如兔子窩般的辦公室空空蕩蕩，自己辦公間零亂擱著打包紙箱。建物門口的莫馮招牌曾吸引數百電視新聞報導，如今已經拆下。成立數十年後，莫馮快要關門大吉了。

文件流出之後，合夥人原先的計畫，是把事務所賣給員工。但是到了年底，剩下來的事務量已不足以讓出售後的事務所存活下去。事務所關閉資產管理MANSA公司。政府在調查，營收又下跌，逼事務所從澤西、直布羅陀、懷俄明起，關閉全球各地辦公室，另裁員逾一百人。
