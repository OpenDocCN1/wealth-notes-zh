# # 祕密交易

除畢卡索家族以外，私人手上最大量的畢卡索作品收藏，一般相信就在日內瓦自由港裡。那批畫作屬納瑪德（Zanmad）家族所有，他們是敘利亞籍猶太人，率先將美術作品商品化，買下畫作，保管在日內瓦自由港，直到它們在市場上的價格來到很誘人的地步為止。

該家族也是莫馮的老客戶，歷史可追溯到一九九〇年代，哥瑞羅的日內瓦辦公室那時。

納瑪德家族靠炒匯賺到第一桶金。一九五〇年代開始改投資藝術品，帶頭的是裘寶佩·納瑪德（Griseppe Zanmad），三兄弟裡的大哥。裘寶佩以英文的喬（Joe）這個名而著稱，在羅馬、米蘭、菲諾港及倫敦都有公寓，而且 在公寓牆壁上掛滿美術作品。這種奢侈的生活方式，讓他的朋友們戲稱他為「法魯克」（Fawork），¹¹ 比喻他為那個愛炫富的埃及統治者：¹²法魯克的收藏品從珍罕錢幣到名車無所不包，令人稱奇。
