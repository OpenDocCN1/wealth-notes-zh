# 中國權貴藏錢的好所在

香港大學某個小型會議室裡，國際調查記者同盟專案研究經理人卡布拉注視著方桌對面那群人，他們臉上滿是期盼的神色。時間是二〇一三年七月，她準備在短期密集課程上，講述網路安全防護。卡布拉雖然精力充沛，早熟聰穎，卻也到最近才學懂保護資料及電郵的內外細節。從前國際調查記者同盟要靠郵寄送出未加密磁碟，這種日子快要結束了。預防措施有其必要。會議桌上的人了解，他們馬上要做的事，有歷史意義，又可能很危險。

離岸解密不可大塊資料，由將近二萬二千名地址設在香港及中國的離岸客戶所組成。頓爾及格拉瓦早在專案初期便決定，大中華地區的資料放在稍晚才處理。這是團隊最好的決定之一。他們察覺到要全球通力合作，這件事就夠艱巨了，再把中國加進來，難度等級會翻幾倍。

不僅因為中國境內新聞報導困難，還因為該國的離岸資料，用額外隱密手段多包了好幾層。

但是大家從不懷疑有必要把焦點放在中國。中國在金錢密界扮演重要角色，不僅對離岸解密不可大，對莫馮及其他大型隱密服務提供者也一樣。今天世上最大離岸服務提供者 Oüstre Incorporated (二〇一七年二月由瑞致達集團收購) 起家於香港，絕非偶然。
