# 三本精密電子

雖然我一直在提到小道消息，但是公司重要的未公開情報，能傳到各位耳裡的機率幾近於零（這也違反了資本市場法則）。即使根本不可能有高級情報傳來，耳根子軟的人卻還是會上當而買進股票。這真的會造成鉅額的虧損，因此我才再三囑咐，買股票之前務必要確認線圖與成交量。

股票賺了幾次卻一次賠光的故事，談的正是那些聽信小道消息，結果載贓又覆舟的人。請一定要小心謹慎！我可以非常肯定的告訴大家：傳到各位耳裡的小道消息，就是全國股民都已經知道的消息了。讓我們再一起賠一次吧。

所有人都知道的消息是什麼？壞消息！
