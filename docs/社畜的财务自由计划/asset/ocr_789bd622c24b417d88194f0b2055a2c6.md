# 不受時間限制的
交易方法

針對早上九點到十點都擠不出時間，但是又想投資股票的話，這個章節會推薦給各位一個交易方法。這個方法就是先經過幾天的時間讓買進後，再抽出一分鐘的時間冒出賺取報酬。這也是一個打破刻板印象的方法，因為一般而而言，這是傳出售出重大不利消息時，股票配股增資、無償減資中延伸出來的買進策略。這個技術是運用一本書都難以闡述的複雜又龐大的技術，但在這裡我會向各位簡略做個介紹。

# 現金增資

什麼是現金增資？用一句話總結，就是將除權後產生的面額損失，透過發行新股的方式恢復股權的買賣法。聽起來很複雜吧？實際上也真的很複雜，是一種必須透過實際操作過才能體會到的買賣方法。這個方法可以獲得高額報酬，但是沒有實際操作的經驗很難加以體會。要解釋這個買賣法寫一百頁都不夠，是非常專業的領域，因此這個章節我們會透過案例來了解整體框架，希望以後各位都能親自嘗試看看。一般在市場上，如果公司宣布進行股東配股增資，股價幾乎會落
