# 能做的都做了

我們最後能做的就只有「新祕交易法」。這部分雖然有點半开玩笑，但也不是完全沒有根據。雖然這種情況非常罕見、但是持有的股票如果已經漲到漲停板，而且漲停板交易餘量還很多，看以隔天還能再賺一筆的時候，果斷脫手就變得不太容易。這個時候我就會虔誠的新禱，「拜託明天也上張漲停板吧」。

我能做的就已經做了，剩下的只能交給老天爺了，所以我稱之為「新祕交易法」。

# 最後的原則——
相信自已

遊牧民股票投資三大原則最後一點就是「遊牧民」。

聽不懂嗎？我的意思是，投資股票的這時候最重要的就是相信自己。日後等各位建立起對自己的信任、培養出實力以後，這裡就可以替換成各位的名字。
