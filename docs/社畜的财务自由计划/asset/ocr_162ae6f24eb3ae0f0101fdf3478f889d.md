# 碰到歷史低點

前ㄧ天25 日的時候，所有負面消息都爆噴而出（所有人都知道的壞消息是什麼？就是好消息！）

前ㄧ天25 日的成交量急速下滑（代表所有買超賣超勢力通通消失，因此表示方向很有可能逆轉）

在十個交易日裡股價就從5,000 元下滑至2,000 元，總共下降了60%（下降幅度過大）

我實在沒有不買的理由。我在初始價格的時候就大量買進，結果當天就透過Alim High 賺取了2,000 萬的報酬。

這裡我再告訴大家一個小祕訣。我在6 月5 日正在寫這段話，以這個時間點為基準，回頭看前面的綠圈，可以看見Alim High 一直微微觸碰到2,900 元的線，這種時候哪怕只要一點點正面消息傳出，股價也可以一舉翻升到4,000 元。你問我怎麼知道？這是支撐與壓力線告訴我的。你問什麼時候會漲？答案就藏在成交量裡。接下來我們會討論到成交量，就請各位一步一步看下去。

現在請大家先記得，

> 「賣得操作股票的人，就會在「支撐線附近買進，在壓力線賣出」，不僅操作股票的人，就會在「支撐線附近賣出，在壓力線買進」。
