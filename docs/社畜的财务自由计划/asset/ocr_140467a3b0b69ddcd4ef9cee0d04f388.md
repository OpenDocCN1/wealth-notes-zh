# Oriant Bio－七日移動平均線（黃色）

日線的強力支撐，接著就沿著二十二日線（生命線）一路上漲。

但是當主力出現的時候，有時候甚至連八日線上揚的跡地都沒有，這種時候就要使用七日線。不過適用於七日線的股票，因為股價上漲的速度過快，往往已經漲到高價，所以一般很難有這麼天賜的心態進場。

各位只需要知道，這些各式各樣的均線都是從傳統的五日、十日、二十日、六十日、一百二十二日線所延伸而出。其他這些均線，是各位在進行短線操作的時候，用來判斷支撐與壓力的依據。

股票需要的是什麼？「應對進退」。我想跟各位說，股市裡『沒有絕對的知識』，但是當各位把這些所有知識都學起來之後「就可以擁有絕對的知識」。
