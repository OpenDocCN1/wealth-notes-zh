# # 008



韓國獨特的租屋制度，房客在簽約入住時，付給房東一定額度的押金，租約結束後房東需全額退還，一般而言這筆押金費用為房屋價格的六成），我認爲除了股票沒有其他辦法了。

所以2015年，我湊齊了自己全部的財產總共480萬元，重新投入股票市場。接者用兩年半的時間獲利10億元，第三年報酬率超過了20億，連我自己都不敢置信，身邊友人當然也嚇了一大跳，紛紛來問我投資的祕訣。大家除了被我報報酬率嚇到以外，也覺得一個每天工作十二小時的血汗上班族，竟然有時間能夠投資，非常神奇。

我目前已維持續投資四年了，我不是一位投資高手，也不是有名的投資人，更沒有所謂的獨家或特別投資技巧，只是運氣很好。我認識的厲害的股票投資老師，溢益良多，而且又剛好搭上股市上漲的順風車。

而我也因此培養出屬於自己的原則與眼光，開始與身邊的人分享我的方法，以及我有興趣的股票。大部分的人都有不錯的結果，其中也有人獲得了高報酬。看到大家能夠更有活力的繼續過著職場生活，我開始認爲，我的投資經驗應該是 يمكن 分享給大家的。

其實我要分享的並不是什麼天大的祕訣。
