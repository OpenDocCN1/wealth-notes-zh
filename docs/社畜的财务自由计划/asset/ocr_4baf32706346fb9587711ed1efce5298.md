+   2. 透過向僅有股東以外之第三方發行股票進行增資，得以獲得新資金注入。

住在首爾的趙惠昇（假名）偶然透過同事得知，「一間名為三三精密的上市公司，要進行規模數百亿的第三方配股」。認為自己獲得高級情報的趙惠昇，把大部分的閒餘資金都拿去買了三三精密的股票。

散戶們的情報都有一種特性，就是隨時都可能會變成送錢給別人賺。自己所得知的基本只是「小道消息」，但由於缺乏判斷情報品質的素養，所以出於想「在股票漲更多之前快入手」的心態，先買了再說。

這就是散戶買進的起點。

在股價上漲間買進，接著股價逐漸走下坡。抱持著忐忑不安的心情，好比大發茲張般的眼關係比較好的同事、家人說這是個「高級情報」，到處散播三三精密的好消息。會傳到散戶手上的情報，大多都是經歷這樣的過程之後，才在所有散戶之間傳開，結果這項情報變成衆所皆知的情報。

等你得知這個消息後已經過了一個月，開盤前消息真的公告了，總市值1,000億的公司進行了規模高達800億的第三方配股，大股東換了人，買進上一場增發上市，真的是絶佳的好消息。
