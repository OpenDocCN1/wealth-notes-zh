# 2017年11月17日開始在HITV上播出

川普當選後，宣布要將1美金元投入SOC（社會間接資本）。SOC 的對象不是企業而是將錢回歸人民。如果利息上漲，因為人民是以薪資過活，如果在租金、房子、貸款……這些部分上支付利息，再加上通貨，薪資所剩無幾，因此無法進行消費。

為了遏止這種消費萎縮的情況發生，所以之前才會推出無息。但是川普把1兆美金撥向人民，會發生什麼事呢？

錢流進來之後，人們就會開始進行消費，美國是一個消費的國家，當消費開始運作，經濟就會復甦。

股票市場及其他方面都會開始上漲，這就是美國現在股票上升的基礎，而這也就是泡沫。

川普在做的不是別的事，就是在製造泡沫。

他所有的政策都不是四年，而是以八年高單位來看（為了連任），這段時間內，美國的經濟會產生巨大的泡沫。

在這個泡沫下，有錢的人會賺得更多，沒錢的人也會賺到錢，但大概第七年左右末的時候，就會後繼無力，導致經濟泡沫化。

這個時候，就會像韓國這種依賴美國的國家開始泡沫化。
