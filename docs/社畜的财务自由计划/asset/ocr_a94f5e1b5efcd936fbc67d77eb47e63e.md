# NepTune

讓我們再來看另一個成交量的例子吧，這次的案例是 NapTune。NapTune 上市後從 Kahoo-Talk 獲得第三方增資等，是一支非常熱門的股票，最近因股票合併，導致股價急速下滑，後來又迅速攀升。

不久前 NapTune 跌落到低點約 8,000 元左右（第一個紅圈處），令人驚訝的是，股價竟然沒有停在支撐線，而是直接跌破低點（第二個紅圈處）。對於一張打破上一個低點的線圖而言，最重要的就是要「確認跌破」。
