# 看人臉色上班族的好朋友

![](bbox=[0.32, 0.13, 0.44, 0.25])

上班族往往在腦中都想盤打盤，對我而言這部分也是最困難的一點。所以我使用了兩種方法，一個是「培育閃電」，另一個是運動「Telegrams」。Telegram 的部分我會在另外的章節做解釋，這裡我們先介紹所有人都能輕易上手的培育閃電。

培育閃電最自豪的就是迷你用戶介面，因為介面非常小，看起來並不像股票視窗，只要連點兩下半部分，培育閃電的介面就會縮小成迷你尺寸，除非仔細看，不然誰都想不到這是股票畫面，只會以為他也是一個小icon。培育閃電的部分，可以從培育股票官方網站中的 HTS 一欄中進行下載。

![](bbox=[0.43, 0.17, 0.53, 0.44])

上班族必須要看完人臉色做交易，雖然辛苦也是無可奈何，我們不是老闆。請把這個能夠一面用心工作，一面打通電話的技巧學起來吧。

如果能夠活用這個方法，就能夠無正盡的把資訊與股票串聯在一起。當然，透過這裡所說的理論並不是一定就會賺到錢，我的想法也有很多時候是錯誤的，請記得這個世界上沒有所謂的百分之百。我們現在最重要的事就是進行基礎體驗訓練，請不要著急，在股票市場裡
