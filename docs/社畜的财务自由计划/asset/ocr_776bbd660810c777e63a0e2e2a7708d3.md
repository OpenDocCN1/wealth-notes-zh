# 認識到底層的過去，是我努力的动力

大家想聽聽我以前的故事嗎？

如果是七十、八十年代的人，應該都記得「IMF 外匯危機，這個可怕的經歷吧？我們家就是在這時候支離破碎的。我的父母在鄉下地方經營自營企業，為了抵抗IMF接二連三的衝擊，他們成為卡奴，持續靠貸款維持，結果還是走到了破產。當時我正在就讀大學四年級，我的弟弟正在準備第三次重考，妹妹則正在就讀大學一年級。
