# ### 基本分析 vs. 技術分析

證券分析大致可以分爲基本分析與技術分析。基本分析（fundamental analysis）是透過分析企業的內部價值，進而挑選股票的方法，先掌握宏觀經濟或該企業的現況與報載率，再以此做爲根據進行買賣。技術分析（technical analysis）是利用過去股票市場發生的現象爲依據，來預測未來的股價，要學最實費的時機點，經常被稱爲「股票綠圖分析」。

企業是組成股票市場的基本。如果說基本分析是用來確切掌握企業現況，那麼技術分析則是能讓我們確實了解因人類心理而動盪的股票市場。如果可以保持兩者均衡的觀點時，就能掌握賺錢的機會與不賠錢的風險管理。
