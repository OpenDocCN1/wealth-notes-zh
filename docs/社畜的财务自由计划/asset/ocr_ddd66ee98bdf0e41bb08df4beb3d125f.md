# 股票基礎用語

+   1. 開盤價、收盤價：開盤價是當天股票開盤時最開始決定出來的價格，收盤價則是收盤時最後決定出來的價格。
2. 最高價、最低價：當天場內的最高價格與當天的最低價格。
3. 價格上限、價格下限：股票市場中，個別股票每天漲到上漲的最高價格被稱爲價格上限，反之下跌的最低價格稱爲價格下限。
2015年韓國的股票市場價格漲幅限制（KOSPI 和 KOSDAQ 都是上下 30%。
4. 飆鏈生：牛市場引頭上漲的股票。
HTS (Home Trading System)：讓投資人能夠在家或辦公室進行交易的系統。
5. 現金增資：企業發行新股，賣給既存股東或新股東，是確保資金的其中一個方法。
6. 無償配股：將盈餘公積轉爲資本淨額增加股票資本，再將增值的股票發行爲新股，無償分配給所有股東。
7. 減資：增資的相反概念。指企業將股票價格或數量減少，使股本減少的行爲。減資分爲兩種，一種是爲了減少相對於公司規模而言過大的股本，稀釋現金減資（會補償給股東）；另一種則是爲了清償虧損，在名義上將股本減少，稀薄紅銷股本減資（不會補償給股東）。
