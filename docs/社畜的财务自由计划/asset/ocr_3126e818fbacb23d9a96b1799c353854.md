只想要賺得比銀行利率高一點？這麼想可不行。用這種軟弱的思維來投資股票的話，不如專注在自己的工作上，獲得公司認可進而升遷還比較快。

假如你是擁有 100 萬的人的話，
1. 你的投資目標金額是多少？（例：1 億）
2. 你要花多長時間達成目標？（例：三年）
3. 每年要賺多少錢？（例：一年 500%，一年內要從 100 萬變成 500 萬，第二年要從 500 萬變成 2,500 萬，第三年要從 2,500 萬賺到 1.25 億）
4. 每個月要賺多少錢？（例：考慮復利大約每個月 30%）

理財前請明確設定好自己的目標。使盡自己的力量去做，不要只是幻想跟做夢，不要只是望著那邊不可及的報酬率，從調整自己的心態開始出發，搞不好才是真正的致富捷徑。
