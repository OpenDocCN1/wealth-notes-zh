# PER 越低越好

除了目前為上我們了解過的项目以外，如果還能了解 PER（本益比）是什麼的話會更好，這個指標可以讓我們知道目前的股價是相對於「淨收入」的幾倍。每股盈餘是淨收入除以股票發行總數所得到的值，這部分比較複雜，沒必要深入了解，指懂只要從 HTS 上就可以看到了。這部分的核心是，PER 越高代表現在的股價相對於每股盈餘而來說「太過昂貴」。PER 越高表示公司的股價相對於公司的盈利能力而言，獲得過高評價；PER 越低則是評價越低。也就是說 PER 越低越好，大家應該聽過「高評價」跟「低評價」的說法吧？這指的就是本益比。

當然，這個不是絕對原則。就算公司持續有足刻的報酬，但是也有情況是投資人對公司前景評價較低，導致該公司成為本益比較低的股票。
