# Case Study Kuk Young G&M

這支股票我也運用支撐與壓力和成交量等指標，成功獲利，讓我們一起來看作分析決定買進股票的過程吧。首先讓我們試著分析支撐與壓力吧？請看下面的線圖。

紅色圈圈的部分，是強力的支撐點；綠色箭頭的部分，則是支撐與壓力相互交替的地方。首先（看紅色圈圈的部分），我們可以確定這支股票已經有一條約三年都沒跌破過的支撐線，價格落在 1,150 元左右。

接著（看綠色箭頭的部分），我們可以看出 1,650 元左右的位置，形成了一條強勁的壓力線，某支股票突破壓力線後股價大幅上漲，但是到 2017 年 5 月底為止（我寫書的時間點），沒有任何反轉的跡象，股價持續下跌。

以價格而言，1,150 元就是這支股票的強勁支撐線，1,650 元則是強勁的壓力線，近期雖然股價大幅上漲，但也沒能強勁突破壓力線，一旦碰到這條線股價就會回跌。（日後的漲跌非常重要，如果股價「強勁」突破 1,650 元，就可以上漲到 2,700 元。）
