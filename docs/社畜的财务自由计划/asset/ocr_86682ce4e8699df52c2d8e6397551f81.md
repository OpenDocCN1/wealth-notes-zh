在股票裡總是這麼左手，是在特定情況下你能夠下注的賣手，但絕對不能成為漫畫的主角。

# 資料等剝層後再篩選

最後階段才是查看資料。

所謂的資料可能是情報、也可能是題材。除此之外，新聞、公告或該公司的官網等，「能夠讓你便宜進股票」的所有ㄧ切，都可以被歸類為資料。比起寫千字長文，我舉幾個實際案例應該可以幫助各位更快理解。

看看下述幾個頭條，決定你想買哪支股票吧。

+   2.  與中國騰訊簽下全新手遊合約

+   3.  三星電子進行價值10億元的第三方增資

+   4.  社區超市老闆 A 先生進行價值 100 億之第三方增資

+   5.  文世代抗癌藥物通過 FDA 檢驗

+   6.  文世代抗癌藥物預計提出第一期臨床實驗

+   7.  對北仨宅配股受惠，每年 10 億規模散钢板供給需求
