成交量下降且出現陰線（黑K，我簡稱為「交減陰線」）。

不要把綠圖想得太過於環節，當我失去純粹，把綠圖複雜化的時候，獲利就會下跌。

我看綠圖的方式非常簡單。

+   。「前一天」的成交量有沒有減少

+   。減少的話股價是不是變慢（黑K）

+   。現在的股價是不是在低點

+   。就算位在低點，會不會也是處在短期高點上

+   。股價有沒有維持在短期均線上（是否是逆向操作）

+   。支撐線有沒有發揮作用

+   。壓力線位在哪裡

+   。如果要趁跌買進的話，股價是在三到八日線上，還是在五到二十日線上

放眼望去感覺好像要看很多東西，但其實我們看的東西只有一個：

現在是不是買點。

為什麼我總是賺得不夠多？我想過，那是因為你不够肯定。我們從綠圖上能獲得的就只有一件事，也就是增加自己的信念。綠圖不過只是個修行指環而已。
