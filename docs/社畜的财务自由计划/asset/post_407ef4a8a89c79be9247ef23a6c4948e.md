
# 提供概念股的分類。

隨著當天波動的概念進行投資也是好的投資方法，但是這種方法比較適合初學者，而且就算是中階或高手也很容易失誤。為什麼？因為所有人都知道的消息，不是好消息的可能性比較高。

# 多看精選新聞，培養去蕪存菁的能力

概念波到來之前，要先具有預測的能力。但是應該要如何才能培養觀察市場與國際情勢的眼光呢？

就是「閱讀報紙」。從現在開始不要閱讀網路新聞，希望各位能開始播報質報紙（編按：現在氣質報紙較少，建議訂閱付費型的電子報）。以我為例，我每天晚上回家之後除了看新聞網頁，也會看日報的頭版，隔天再把訂來的日報打開閱讀。我一般來說會看朝辭日報、中央日報、東立日報、每日經濟、韓國經濟、EDAILY、ETODAY的報紙。

為什麼一定要看報紙呢？

你們覺得每天在傾巢而出的網路新聞大概有幾則呢？大概估計也有十萬則以上。登記為網路媒體的公司有一萬間，每一間一天就大概只有十則新聞，一天也有十萬則新聞。實際上，有些公司每天會發布一百則新聞以上，也就是說網路新聞的數量在我們的預估之上。

相反的，紙質新聞呢？因為頁面的限制，所以比起網路新聞更加簡潔，編輯時必須盡可能納入核心的部分。在無數位新聞中，只有最重要的幾個主題，才能在報紙上佔住一個版位。也就是說，報紙上收錄的政治主題、經濟主題、文化主題等，都是從當天發布的數千則新聞中，最重要的部分。

閱讀報紙跟我們看著螢幕的時候不同，可以培養我們的思維能力。在井然有序又簡潔的報導中，培養掌握每個字句間意義的能力。一開始先從頭版到論述，全部都要仔細閱讀，你會發現閱讀三四份報紙要花許多時間，但是等習慣了之後，看一份報紙只要花大概十到二十分鐘的時間，因為你已經培養了只看標題就能夠對內容略知一二的能力。

# 為什麼我每天都記錄漲停股和爆量股？

習慣每天閱讀報紙之後，就會培養出找概念股的能力，知道下一步該怎麼做。我本來想要說「這件事沒有所謂的正確解答……」，但是其實這件事應該是有一個正確解答的。

我在相聲頻道裡出過一個作業，叫大家記錄每天的漲停股，並整理出成交量一千萬股以上的股票。

這件事我從 2015 年開始到 2018 年的上半年為止，基本上每天都在做，並不是誰要求我應該這麼做，而是我自己覺得有必要這麼做。

一開始雖然要花很多時間，但是後來習慣之後，不用三十分鐘就能完成，有時候可能只要花十分鐘就能做完。

但是重要的並不是整理資料這件事，「找出『為什麼』這支股票漲停、為什麼成交量會破千萬的原因」才是重點，因為這些「為什麼」最終就會成為概念股。

一開始調查的時候，會感覺自己是霧裡看花，不太了解其中緣由。但是這個動作，就是你現在的問題。點滴，等這些點滴連通成線，最後成為面，所以這個累積的動作很重要。

很簡單吧？但是人類就是這麼奇怪，就是不想動作。不只是股票，不管是運動還是演奏樂器，大家只憑學到討人歡喜的技巧，卻不想真正面對必備的基礎訓練。

所有人都知道，那些在基礎訓練下了功夫的選手，最終就能細水長流。但是人們卻都覺得自己像是武俠小說的主角，夢想著自己哪天找到特殊秘笈，或是因為一場特別的因緣，一夜之間就成為武林高手，這在現實世界中是不可能發生的。

# 從迷宮裡逃脫的方法

各位知道迷宮吧？字典裡說「迷宮是拐彎抹角，一旦進去便難以脫身的地方」。

![](img/28e73127539f4de4c136d9605847a1f7_112_0.png)

很熟悉的迷宮吧？我們小時候不都解了很多迷宮的謎題嗎？這種迷宮只要花時間，誰都可以找到出路。但是，為什麼呢？請花五秒鐘想想看，為什麼所有人都能解開這個迷宮？

答案就是，因為各位是由上而下俯瞰這個迷宮。這是因為我們以 2D 的方式看著這個迷宮，所以才能解開這個謎題。但假設各位是以 3D 的角度站在同一個迷宮裡，你們真的能逃脫出去嗎？

在 3D 的迷宮與用 2D 的角度看迷宮，是完全不同次元的東西。如果想從 3D 迷宮逃脫出去，就必須轉換觀點，慢慢地角度往上抬高，就會漸漸看見全貌。最後就會看見 2D 平面圖，就算要花很多時間，但還是能把迷宮解開。

現在正在累積相關知識的我們，是站在 3D 的迷宮裡，但是等迷宮的資訊漸漸在腦海裡融會貫通，你就會看見地圖，也就會轉換成為 2D 迷宮。

股票也是一樣的道理不是嗎？各位現在站在 3D 的迷宮裡，所以覺得股票很難，又有點恐懼。但如果能在這場遊戲裡，由上而下俯瞰，那麼眼前看見的便不是恐懼，只不過是像走在熟悉的街道上，就能解開迷宮。

![](img/28e73127539f4de4c136d9605847a1f7_113_0.png)

關鍵題。

其實這個迷宮觀點也能套用在職場生活上，我們能夠掌握自己所屬的組織、社會、同事之間的角力關係，真的是件很重要的事。其實前五十上班族的立場，就如同被困在3D的迷宮裡，而公司所有人與管理階層則是在俯瞰著2D的迷宮，然後再繼續幫這個迷宮增加困難度。如果有一天，當自己的視線能夠上抬，看見整個結構的話，就能夠輕鬆從迷宮中脫逃。

這一點我不知道算是韓國的優點還是缺點，但是在韓國劃分2D與3D的那道牆只有一個，就是「金錢」。有錢人就能看見結構，窮人就看不見。換句話來說，從新管理自立出來、財務自由的人就能看見結構，而不自立的人則看不見。特別是等到你財務自由後，就會發現這種結構不僅局限於股票，更能適用於政治、經濟、社會、文化、藝能等所有地方。

結果你就望著那個永遠無法接近的幸福得分裂，認認真真的迷失在3D的迷宮裡，然後從2D俯瞰的人又不斷提高迷宮的難度。我一直都有強調吧？說要轉換觀點，不要執著於小事情之上，真正的世界，取決於你眼光的高低。

我也是在投資股票的同時，每天想著各種可能發生的情境，首先改變了眼光高低，最後才獲得了2D的觀點。這也是為什麼我教大家不要怕，先投資就對了，如果自己沒有領悟的話，就算一開始看起來離譜也很正常。到錢，也只是新手運而已。能夠先掌握整個結構的人，才能爭取到不同次元的勝利。

在股票裡阻礙我們掌握全盤結構的東西，就是既住的體驗刻板印象。初試股票的人，如果運氣好遇到好老師，能夠快速學習的原因，是因為老師就是在一張白紙上幫你畫出了結構。

現在，讓我們來看見真實的世界吧。

# 6. 投資人必懂的三大指標

不會英文的人總是買一本厚厚的文法書，以為自己英文不好是因為沒學文法。股票也是一樣，越是股市新手，明明對於均線、RSI、MACD 等指標不太熟悉，卻又很關心這些輔助指標的趨勢，然後誤以為要找出藏在其中的機密，才能夠成為股市高手。但是這些都是錯覺，股市上所有的指標都不過只是後行情態與輔助指標，只是用來作為預測的參考資料而已。

讀圖分析非常重要，但也不能把一切都賭在讀圖上。雖然不知道這個階段各位能不能理解，但是其中我們最主要看的：第一是成交量，第二是讀圖，最後才是資料。教導我股票的老師，他的實力在股票界裡備受肯定，包括他以及其他股票高手們，會看的股票指標只有兩項，就是均線（移動平均線）與成交量。

把其他指標當作是主要指標的人裡，應該沒有人敢公開自己的帳戶明細，他們只不過是要耍嘴皮子的「嘴上高手」而已。要迷惑新手最好的方法，就是大量使用他們從來沒聽過的專業術語；再告訴他們「只要你看某指標，你也能成為股市高手！」藉此騙取高額的會員費。千萬不要被這些人騙了，這些技術分析的部分，等到我們完成基礎建設訓練後再學也不遲。我為了使本書更加簡潔，所以盡可能避免寫網路上搜尋得到或是市面上書籍已經收錄的內容。也就是說，我認為基礎建設，也就是做好心理建設這件事，是對未來而言最重要的事，所以到目前為止請各位先不要著急。

我希望各位不要心急意亂，一直記掛著操盤與輔助指標，但也不是說就可以完全不去了解它們。在這個章節裡，我們會學習各種指標中務必了解的其中三項指標，也就是支撐和壓力、成交量以及均線。

# 第一個指標：支撐與壓力

支撐與壓力是強化基礎建設最重要的知識，也是一定要搞懂的部分。99%的股票都可以套用在支撐與壓力之上，所以請務必熟悉這個指標，將其應用在每一支股票上面。

# CASE STUDY HamblisSoft

我們將透過 HamblisSoft 的實際案例來了解支撐與壓力。下圖一號與二號的地方可以看出，股價大約到 5,900 元的時候都獲得強力的支撐，然後重新反彈，扮演了支撐前一個低點的角色。一旦股價跌破支撐線，這條線就會成為強大的阻力，也就是說，當股價跌破了難以跌破的支撐線時，這條支撐線日後就會變身為阻擋股票上漲的壓力線。

讓我們再繼續看下去。雖然先前在一號與二號的時候，5,900 元是最後的支撐線，但是自從股票跌至 4,000 元後，就無法再度突破 5,900 元的壓力線。請看三四五號，股票在 5,900 元的線上連續幾次被阻擋，

![](img/28e73127539f4de4c136d9605847a1f7_120_0.png)

這條線分擔著強大的壓力線，成為了一套 HabisSoft 跌破無法上漲的原因。

PS. 2018年2月畫新回來複習 HabisSoft，發現即便 HabisSoft 搭上強勢的虛擬貨幣概念股，但仍然無法突破此壓力線。

我除了看到六號點位的橫向線以外，也會看最高價與最低價碰到的線，最神奇的是支撐與壓力這兩個作用會不斷輪替，一旦形成了支撐線就很難跌破。但假如一旦跌破，成為壓力線後就很難再突破。

請大家交易時，務必要銘記在心。

- 買進時要先確認股價不會跌破支撐線
- 賣出的時候，要在股價無法突破壓力線後跌破
- 這兩句話要當作咒語般烙印在腦海裡，如此一來才能大致估算買進與賣出的時間點。但除了上述這兩個原則以外，還有另一點需要注意。

④ 強力突破壓力線時的買進點

當股價強力突破壓力線時，股價可以說會很容易漲到下一個壓力點。不要害怕，我們並非在賭博，而是透過正確的分析來進行股票買賣。我們在這裡所指的「強力」，意味著伴隨高成交量的強力買進趨勢，如果沒有成交量的話，就不能成立（也被稱為突破買入法）。
如果出現這種幾乎像漲停板的紅長線，就要在股價強力突破壓力線的同時，買進股票。

支撐與壓力是能讓我們知道買賣與賣出時機點的重要指標，請應用在其他股票上多加練習。看著 HTS 系統上已經畫好的支撐線，去分析其中的原因，持續練習直到自己可以畫出這條線為止。

# K 線 (蠟燭圖)

![](img/28e73127539f4de4c136d9605847a1f7_123_0.png)

K 線 (蠟燭圖)，把一定期間內的股價，用柱狀條呈現的線圖，稱作 K 線圖。標示一天股價的稱為日 K，一週的則為週 K，一個月稱為月 K。當然也還有分 K、以一、三、五、十五分鐘為單位、六十分鐘的分時 K 線則能看出一小時內的股價變化。

陽線 (黑 K 線) 與陰線 (紅 K 線)

陰線是收盤價高於開盤價，會以紅色（上漲）作高警示；陽線則是收盤價低於開盤價，會以藍色（下跌）做為警示。上下突出的線則會展示出當天的最高價與最低價。

# 要找出好買的商品，你就得學會看價格

要在股票「強勁」突破強力的壓力線時再同時買進，我這邊所指的「強勁」指的是，至少高於壓力線 10 ~ 15% 以上。

線圖臨臨的部分，可以看到 Clean & Science 在創下前所未見的股票後，又慢慢回跌。那麼 Clean & Science 會從支撐線上重新反彈回 7,900 元嗎？

機率一半一半。支撐與壓力最好拿下的時機點，就是「第一次」發生支撐與壓力的時候。首次突破壓力線的情況下，幾乎 99% 的支撐線進攻都會奏效。

![](img/28e73127539f4de4c136d9605847a1f7_125_0.png)

不知道這本書什麼時候會出版，但我們這次來試著把理論套用在網路上來查看盤訊息而受到股民追捧的網友，在他不再發文後，突然有人以有錢爸爸的名義，大量寄送推薦股票簡訊給股民，至今仍無法查出此人真實身份為何）而聲名大噪（如果不知道這件事的人，也沒有必要了解的必要）的 S-MARK 上吧。
