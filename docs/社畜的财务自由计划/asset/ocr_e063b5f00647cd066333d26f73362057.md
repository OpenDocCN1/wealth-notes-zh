# 股票被套牢怎麼辦？
記得先分清楚

前面的部分我提過，我的股票帳戶有好幾個，但我並不是吃飯太閒才這麼做。而是為了長線投資，會需要辦理股投資目的相左的帳戶。

不管以什麼方式，都請將長線投資的股票另外集中在庫線投資的帳戶中。假設股票已經超出停損點，就算現在賣出也沒有任何意義的話，就會變成「非自願性」長線投資，也就是所謂被套牢的股票。

如果在主要用來進行短線的帳戶中，不斷看到虧損的股票，很容易會對心態造成影響。如果哪天心理崩盤，可能會狂下一股氣把所有股票停損賣出的錯誤。

為了提前防止這樣的惡性影響，長線投資的股票請一定要放在用於長線投資的證券公司中。每間證券公司雖然多少有些不同，但是HTS可以使用「股票匯簽」的服務，將股票移動到其他帳戶，接著再透過設定「HTS自動買賣」，只要當月有達到目標金額，就讓股票自動賣出。

還有，主要使用的證券帳戶裡，一定只有三到五支以下的股票。身為上班族一定需要使用手機進行交易，但要注意：在手機的頁面上，單頁只能容納三到五支股票，其他股票就必須向下滑動頁面才看得到，這種時候稍稍不留神就很容易錯過時機。股票買賣本身，手機就可能會比...  （註：此處文字因排版斷行，後接至左側）
