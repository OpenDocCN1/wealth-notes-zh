# 症狀四：

# 覺得「就算大家都在賠錢，但我一定會賺」

最壞的結局一定輪不到自己？這是最傻的賭氣。投資股票的散戶們，往往總是抱有一種自己一定會賺錢的信仰，但事實是很殘酷的。

2017年玫瑰大選（編按：韓國總統大選原定於12月20日舉行，但由於前總統朴槿惠涉及弊案下台，導致當年大選提前於5月9日舉行，被媒體稱為玫瑰大選）的時候，大選概念股強勢上漲，但是統計報告卻指出其中83%的散戶投資人都賠了錢。怎麼會這樣呢？原因雖然很多，但我認為問題出在人們相信自己一定會賺到錢。

買進之前幻想著這支股票一定能為自己賺大錢，但是你要知道的是，會這麼想的人不是只有你一個。

股票是心理遊戲，大部分的情況下，我所想的別人也想得到，對於情報較少的散戶而言更是如此。
