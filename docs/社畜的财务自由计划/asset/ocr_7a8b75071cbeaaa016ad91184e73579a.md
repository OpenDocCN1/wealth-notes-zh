# 6. 投資人必懂的
三大指標

不會英文的人總是買一本厚厚的文法書，以為自己英文不好是因為學會文法。股票也是一樣，越是股市新手，明明對於均線、RSI、MACD 等指標不太熟悉，卻又很關心這些輔助指標的趨勢，然後誤以為要找出藏在其中的機密，才能夠成為股市高手。但是這些都是錯覺，股市上所有的指標都不過只是後行情態與輔助指標，只是用來做爲預測的參考資料而已。

獵圖分析非常重要，但也不能把一切都賭在獵圖上。雖然不知道這個階段各位能不能理解，但是其中我們最主要看的：第一是成交量，第二是獵圖，最後才是資料。教導我股票的老師，他的實力在股票界裡備受肯定，包括他以及其他股票高手們，會看的股票指標只有兩項，就是均線（移動平均線）與成交量。
