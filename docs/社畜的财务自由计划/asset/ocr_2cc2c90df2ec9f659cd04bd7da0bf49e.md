# 五日線

呈現出五日內平均價格的線，可以看出排除星期六日以外，一週內內的平均走勢。沿著五日線上長的股票，一般來說股價會快速上漲，前面我們在看的成交量銳減的線圈時，就經常會使用到五日線。

如果是想要操作波段投資人，看到股價在五日線下跌走，接著爬上五日線時，就要開始買進股票。但如果是急劇超越五日線的股票，要等陰線（黑K）踩到五日線時再買進比較安全。

請看Acon Square的線圈。看到第一個綠色箭頭的地方，3月31日時出現陽線（紅K）超越了五日線（粉紅色的線），這天就是買入的時機點。接著股價沿著五日線進走，在第二個箭頭處出現了陰線（黑K），同時突破了五日線與十日線，接著股價就開始下跌。就算是這種成交量輕如灰灰機的股票，也能依據五日線進行波段買賣。

再下一張表是Aim High的五日線圈。長線下跌後，連續幾天的交易都維持在五日線之上，我在6月14日，股價打破五日線的那天（綠框部分）大量買進股票。接著公司在15日的時候發出利多公告，大賺了一筆。
