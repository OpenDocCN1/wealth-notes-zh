
到接近跌停。接著公司在這個時候增發股票，所謂的現金增資就意味著公司需要錢，為了得到這筆錢，只好向股東伸手的意思。現金增資因為股數的增加，股價自然就會被稀釋。

但是這種不利消息，只能適用於既有股東身上，不適用於後纔才購入的新買家，這反而是否能以非常便宜的價格購入股票的機會。除權的當天股價幾乎都會上漲，除權的時候，如果能將優先股股票賣出的話，就可以賺取高額利益。

這個時候各位應該被什麼是除權、什麼是優先股股票搞得很頭轉向吧。簡單來說，除權就是以使的方式，把股價按照減幅進行股價調降。雖然股東可以獲得以便宜價格購入新股的機會，但同時也必須面臨除權（以前一天收盤價為主下調股價）。這是為了舊股東與新股東間保持公平所採取的措施。除權之後進場的新股東，以及現有股東以便宜價格購入新股時，都會面臨相對的損失，讓其相互抵銷。

但公司也必須要確認誰能獲得優先配股權對吧？而標準就是配發新股的那天。配發的前一天就會進行除權，必須在除權前一天持有股票才能取得優先配股權。如果想要參與增資的話，只要將優先配股權賣出即可。我是那種「見好就收」的類型，所以基本上都會直接賣掉，讓我們來看一下實際買賣。

我們來看看世宗電信吧。當公司宣布要進行股東配股現金增資時股價跌了30%（綠框部分）。6月28日的時候，我們可以看到股價大幅上漲再次回跌，這天整整漲了15%後又再次回跌，而我則是在當天就把股票賣出了。

假如有人以6月27日當天的收盤價買進世宗電信，6月28日就會因為除權而損失15.54%。

# 世宗電信 - 有權增资與除權之間的漲跌

這是隔天28日的交易紀錄，我們可以看到世宗電信虧損了大約662萬（5.98%），這裡就藏著現金增資的脈絡。

但仔細看世宗電信的公告，會發現這天每一股會配發0.94股，也就等於持有一股就配發一股，而且每一股的價格是612元，等於獲得了比目前的股價整整便宜50%的購股權。

### 社長的財務自由計畫

雖然已經持有的股票在 28 日開盤時就會直接虧損 15%，但是日後重新回漲的機率很高。因此 27 日除權的時候我買進了股票，28 日開盤時雖然虧損 15%，但又因為低點產生的購買潮導致股價上漲，如果 在 28 日最高點漲 15% 的時候賣出，那麼不僅能保留有權增资的權利，也不 會發生除權所帶來的虧損。 以我為例，雖然股價下跌的那天我也大概損失了約 6%，但是日後的預期報酬卻是15%以上。以數學呈現的虧損只不過是看起來像是虧損，但卻並非真的虧損。而是為了保障日後權益的一種虧損。遇到這種強勢有償增資，我們可以賺到少則5%，多則15～30%的報酬。

有償增資的好處就是會公告明確的日期，股票买进可以按照除權日慢慢買進。賣出時只要除權當天一次賣掉即可。因為參與了除權，所以優先配股權還能另外交易，也可以繳納現金增資額獲得新股，是一個選擇性很多元的方法。

# 減資交易

減資是上市公司中最負面的消息之一，因為資本額不足，所以也是被用來避免股票下市的方法。但是減資有時候也能被看作是好消息，因為減資已經是所有負面消息中的最後一步棋了。

經過確切的企業分析，確認所有得不利都已透露出，減資已是最後一步棋的時候，最好可以在暫停交易的最後一天買進股票確保數量。減資買賣如果仔細說明起來也很複雜，我們就以實際案例來代表吧。下方是 C Columned 的線圖，在底部減資後，股價上升了約三倍之多。

下圖則是 Cubes 的表單，也是在底部減資後股價上漲約 30%。減資很危險，但是減資有很高的可能性是該公司的「最後一步棋」。原本的潛力股因為業績惡化＋股東配股現金增资，最後才會進行減資。因此：
- ①要確認股價已經在底部，
- ②不利消息已經全部釋出，
- ③在審計報告書沒有異常的月份（二到三月除外），才能進行減資交易。

# 讓人心動的小道消息
該怎麼應對？

收購、合併、投資、臨床實驗、對外授權（License out），諸如此類的小道消息確實很吸引人，但是這些消息傳到各位耳裡前，已經不知道經過多少手了。正在閱讀這本書的上班族們，說難聽一點都是拿到的都是垃圾水準般的消息，如果被誘惑的話，十之八九只會淪為他人的提款機。

但是這些聽來的小道消息確實已經令人心搖擺不安，我們該怎麼辦呢？所以這個部分，我要簡單告訴各位一個「可以幫助你們決定要買還是不買」的小祕訣。

對於新手而言，聽到「小道消息」的時候內心肯定激動不已，腦海裡只會想著要快點進場才行，不知不覺滑鼠就移了上去，把這支股票收藏到我的最愛，然後點下買進的按鈕。但是股票高手們聽到小道消息的時候，卻會把消息假設為「負面消息」，然後開始看盤圖。

首先，我們要做的是深呼吸。不管是多麼讓你心動的小道消息，股價也絕對不會在隔天立刻上漲，所以請不要太過急躁。如果是那種還沒發通告出去的 A 級消息，至少也要花上幾週跟幾個月的時間才能實現，所以股價也不可能立刻上漲。也就是說，我們沒有理由要著急，請慢慢觀察盤圖。
