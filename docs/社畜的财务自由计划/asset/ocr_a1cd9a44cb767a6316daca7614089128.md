# PART 1 社會們，從今天開始做組織投資吧

來的所不圖。如果你讀著這本書是為了想要獲得這種啟談，倒抱歉這本書裡「沒有」。

那些被稱為專家的人，用著祕訣、祕技、祕術、高級情報來誘惑我們。但是如果真的有這種東西，這世界上哪裡還有人在股票上賠錢呢？這些不過是誘餌，用來迷惑天真的人罷已。

股票裡絕對沒有所謂的啟談，只有所謂的「應對進達」。這個應對進達的方法，其實你們都已經會了，只不過因為層層刻板印象，以及從那些所謂的藏款中學到錯誤知談，導致你們用著不對的方式應對而已。

雖然我在三年內累積超過了30億元的報酬，但是有時候我也會不敢自信這一切，覺得只是運氣好而已。我沒有獨門祕訣與祕技，說起來對股市也不是太了解。我並不是在謙虛，構成股市的多個領域當中，也就是所謂的概念股、綠圖、成交量、基本面分析、技術分析，不管哪一個我都不太擅長，而且還差得恨遠。

但是思考一下，了解綠圖、我會分析的人就一定能賺不賠嗎？我換句話問吧，各位是想要很會投資股票，還是想要從中賺取報酬呢？我説想要很會投資股票，卻糾結在細枝末節的方法、綠圖、情報等層面，就算成為了綠圖專家，沒有獲利也只是紙上談兵。
