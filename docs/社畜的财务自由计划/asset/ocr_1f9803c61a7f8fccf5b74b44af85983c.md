為什麼找上散戶的情報都是垃圾呢？

大事件都是由公司的核心職員負責決策，我們稱之為C等級的CEO和CFO，但是還有比他們更高階的人，也就是所謂的「上層人士」，像是主席和老闆這個階層。

上層人士之間創造工作後，會將其交付給各義上的老闆（CEO），然後他會與CFO討論，接著在高管會議上進行決策（與其他C級的人），經過了這些過程後，訊息才會傳到本部長、室長、組長耳裡。

這個過程中，訊息會大量擴散。保密政策在社群數量大眾化的年代非常困難，把這個社會看作沒有祕密的社会，心裡會好過一點。

+   * A級情報：上層人士所獲得的情報，最確實而可以在股價低點買入。

+   * B級情報：CEO和CFO所獲得的情報，還是可以在股價低點內買入。

+   * C級情報：其他C級人士所獲得的情報，這個階段開始訊息就會大量擴散出去。
