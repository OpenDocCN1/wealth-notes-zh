# ## 我邊上班邊操盤，三年賺到三十億

三十歲那年我以工讀生的身分，展開了人生第一次的職場生活。當時的薪水是稅前30萬元（編號：本書中的幣值皆為美元，1美元約等於0.025新台幣，若出現其他幣值，會特別標示），雖然每年調薪，但對於與同齡人相比，資歷和畢業進度落後太多的我而言，更能清楚感受到薪資的極限。就算成為僅占全公司1％的高階管理層，光靠薪水我也無法成為有錢人，所以即便不是鐵飯碗，經常擔憂不知會不會被炒魷魚，也只能選擇咬牙苦撐。那該如何成為有錢人呢？我期望能透過工作證明自我價值，又能擺脫薪資走上自由的人生，因而選擇了股票。
