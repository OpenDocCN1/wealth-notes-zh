# Dressing Fine Tcc - 財務相關內容

資產扣除負債所剩的錢就是資本，如果資本虧損的話，就會被稱為「資本耗蝕」，這種股票千萬不要碰，這不是初學者可以碰的股票。營收是銷售商品或提供服務後賺取的錢，營收當然增加是最好的，但是只算營收的話意義不大。即使營收增加，但是營業利潤或淨收入過低，甚至是發生虧損時，代表公司只是耗費功力在一個賠本生意上。所謂的營業利潤，就是從營收中扣除銷售成本、一般營業費用等
