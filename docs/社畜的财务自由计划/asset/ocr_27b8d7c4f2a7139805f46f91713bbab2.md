# CASE STUDY HamblisSoft

我們將透過 HamblisSoft 的實際案例來了解支撐與壓力。下圖一號與二號的地方可以看出，股價大約到 5,900 元的時候都獲得強力的支撐，然後重新反彈，扮演了支撐前一個低點的角色。一旦股價跌破支撐線，這條線就會成為強大的阻力，也就是說，當股價跌破了難以跌破的支撐線時，這條支撐線日後就會變身為阻擋股票上漲的壓力線。

讓我們再繼續看下去。雖然先前在一號與二號的時候，5,900 元是最後的支撐線，但是自從股票跌至 4,000 元後，就無法再度突破 5,900 元的壓力線。請看三四五號，股票在 5,900 元的線上連續幾次被阻擋，
