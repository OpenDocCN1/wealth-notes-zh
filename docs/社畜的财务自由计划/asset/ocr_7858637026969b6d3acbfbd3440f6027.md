受到四十五日線支撐時再考慮買進（但最近處於牛市，所以四十五日線成交量小幅增長時也適用該理論。請務必小心應對）。

接著讓我們來整理一下使用四十五日線的交易法則吧。

# 圖 四十五日線買賣法則

+   * 一天之內股價上升 20% 之後。

+   * 股價第一次碰到四十五日線時（除了第一次碰到四十五日線以外，上漲的機率都很低，可以 directly 無視）。

+   * 如果一百二十日線以上的長期均線位於高點時請小心注意。

+   * 四十五日線會發生股價反彈。

+   * 但是如果股價碰到四十五日線時成交量上漲，就不包括在股價況內（但如果中午時成交量小幅上升便無妨）。

+   * 四十五日線屬於跌趨勢股的一種。
