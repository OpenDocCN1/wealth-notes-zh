## 8. 確立停損的標準

### 買股的條件，決定停損的標準

「股票跌了耶……該怎麼辦？」

「現在該不該出場停損？」

如果你會問這種問題，就代表你還沒準備好該如何投資股票。只要擁有清楚明確定停損標準，就能把虧損最小化。真正的股票高手是很少會停損的。我也有過幾次很掙扎的停損經驗，所以這個章節就讓我們來談談停損這件事吧。

「買股票首先第一個要決定的，就是停損標準。」

這句話裡頭含了很多道理。

一般我們購買股票的時候，會依據下列三個條件來選擇要買進的股票。

- ① 終圓
- ② 概念股
- ③ 情報（他人推薦）

在三個條件下都有不同的停損標準，所以我們必須要先行歸到購買這個股票的原因。

首先，如果以終圓來選股的話，停損的標準會非常明確，前面我們長篇大論的支持與壓力線，就會成為停損與停利的標準。當股票的支撐線無法發揮功能，就會變成停損線。

接下來是以概念股購買的情況，會以題材來選股的人，一般是認為自己的投資能力已經到一定水準的人，如果你對概念股不了解，是因爲別人說這個題材好才買進，那就是適用於第三個情況，也就是透過情報（他人推薦）而購買。如果你是非常了解概念股而購入股票，那麼就要有能力確認概念股的持續性，當概念股失去持續性時，就是停損的時候。

舉例來說，2017年玫瑰大漲的時候，買進安哲芳（編按：該股終點是參考進之一）概念股的股民，如果在大漲結束後沒把股票賣出，還一直持有股票想等到下一次大漲的話，就是一種愚蠢的行為。當概念股的持續性消失時，一定要將股票賣出，請記得「股票沒有所謂一定會回彈」這句話。

當然，股價還會在六十日線跟一百二十日線上回升，但是如果投資人連概念股持續性消失後都無法停損，基本上有能力在六十日線跟一百二十日線上順風車，順利脫身的機率也趨近於零。

最後一項，根據情報（他人推薦）買賣股票的風險是最高的。我的股票生涯中虧損最慘的時候，就是聽從來路不明的情報與因為他人推薦而購買股票的時候。

情報總是從他人推薦，通常都是基於強烈的信任之上而選擇這支股票，因此很難做出理性冷靜的判斷。透過這個超過佳好情報賺到錢的期待，會讓你誤以為「現在賠點錢，接下來股票漲就會賺回來了」，而隨著這期間待心理越高昂，多數情況下就越容易對停損這件事造成妨礙，這種時候虧損的金額就會如雪球般越滾越大。透過他人推薦購買的情況下，通常你對股票的信任程度就等同於你相信對方的程度，所以就不容易因為虧損而被動搖，因為你會相信「股價總有一天會漲回來」。

所以第三種交易條件，壓根就沒辦法決定出停損點，連我自己也因為這種交易方式，經歷過重大的虧損。

最好的選擇就是不要透過情報進行股票交易，就像我前面所提到給各位耳提的面報很有可能已經是未日股票了。如果你還是覺得這個情報太好，不覺得可惜的話怎麼辦？那就回到原點，回頭看綠圖上的支撐與壓力是不是值得買進的股票，如果股票已經在高點，或是與支撐線的距離過遠，那就不應該買進。不管是多少令人垂涎三尺的情報，如果沒辦法像綠圖買賣一樣，決定好停損點，那就最好不要買，但如果經過百般糾結最後買進的股票，此時還是開始下跌怎麼辦？

如果在經過綠圖分析後，這支股票仍然具有未來性的話，那就值得繼續抱下去。但如果是中國的公司，或是你無法進行綠圖分析，尤其是連推薦你這支股票的人都已經出場的話，那就請無條件停損。就算停損後股價上升，那也是沒辦法的事，只能埋怨自己在還沒準備好的狀態下就買了股票。

情報買賣法必須小心的情況，就是推薦的當事人曾經任職在那間公司，因為他已經離開公司了，所以到手的情報可能已经不是第一手情報，如果遇到這種情況請無條件停損。

還有，請銘記一件事。

傳出好消息的公司，絕對不會在一天暴跌 5% 以上，好消息會以各種方式四處散播。一有人都會考慮此時或者保險出現時進場，因此股價絕對不會跌到 5% 以上。萬一這支股票一天內跌超過 5%，請無條件減少一半的持有比重。

## 神經緊繃的 3 月

萬一遇到審計報告延遲的公司，請不要留戀直接脫手。

散戶最痛心的事，就是遇到股票被下市或是禁止交易，而 3 月正好就是最常發生這種情況的時候。上市公司每一季都必須要提交審計報告，截止日就是 3 月。一旦沒有準時繳交，不僅公司可能被扣分，萬一無法繳交的話就會進入下市審查的階段。

一般來說，假如發生延遲的時候，我們就可以推測該公司可能難以獲得「適當」的審計報告。假如發生部分拒絕或拒絕表達審計意見的情況，各位的股票價值可能會連現在的一半都不剩。

最好的方法就是，3 月的時候不要買進沒有審計報告的股票。千萬不要只想著賺錢，風險管理才是最重要的。

## 停損速度越快，越能捍衛你的資產

我寫這本書的初衷是想要打破錯誤的投資刻板觀念。前面我們已經阐述過停損的標準，但是我還是想要再強調一次。雖然「報酬」能夠促使我們持續投資股票，但是「停損」可能會成為壓倒自己的最後一根稻草。雖然這件事對投資人而言很稀鬆平常，但是停損並不像獲利那麼簡單，而是賠錢後需要轉換投資標的，是非常痛心境直的。

說要在幾個百分點上停損是非常容易的事，但是事實上對於當事人而言，是非常困難的一件事。不過，停損要越快越好。如果每次都以 10% 為單位來進行停損的話，戶頭很快就會有一半都不剩。

所以請各位一定要銘記下列事項。

- 第一點：停損越快越好。
- 第二點：假如股價已經對於你的均價產生威脅，就要立刻賣出。
- 第三點：在已經虧損的狀態下，如果沒辦法當日清倉要拖到下一個工作日，要先減少持有比重。
- 第四點：基於第三點的下一個交易日，如果股價調低，就一定要在上午前全數清倉。

不要對已經沒有希望的股票抱太多希望。

快速清倉才能保護你的明天。

## 9. 為上班族量身訂做的交易方法

### 善用自動化的投資工具

如果有人可以在股票發生劇變時即時通知我，或是在我理想的線圈出現時立刻告訴我該有多方便？這麼一來，如果出現漲停股就可以馬上看到；如果出現我偏好的線圖也能即時買進，光是想後就覺得很棒，這麼一來股票投資好像就變得方便。不用每天都查看、看表，透過自動搜尋就可以有人直接通知我，能夠省下好多時間。

但是你知道嗎？這些事情現在都已能夠實現了。

擁有世界最佳的保安系統 Telegram（編按：跨平台的即時通訊軟體，以絕佳的保密性聞名），已經與智青證券、大信證券、EBST 證券利用公開 API 串接的方式實現了這個夢幻功能。我也已經成為這個系統的使用者了，對於時間緊迫的上班族而言真的是助益良多。

一起來看一下我的 Telegram 吧。

我已經設定好，只要出現跟我的預設條件符合的股票時，Telegram 就會發送即時通知。

「漲停股通知，列入概念股追蹤清單」，是為了追蹤比前一天漲了 20% 以上的股票，因為這種股票很可能成為當天的主力概念股。「列入七、八日股票追蹤清單」，則是在出現符合八日線條件的股票出現時就會通知我。

讓我們來看 HLB, 這是 Telegram 通知我的股票之一。

Telegram 發資訊給我的時候是下午, 如果我在當時於八日線附近買進, 就能獲得不錯的報酬。

透過與 Telegram 連動不僅非常有效率, 還能體會到什麼叫做真正的上班族買賣法。但是重點是在於, 你能不能夠自己打造出一個系統。現在我所使用的系統, 因為是我自己設定的, 所以我也是唯一一位使用者。我之所以沒辦法把這個系統商業化的原因, 是因為我不是專業技術人員, 沒有自信能夠做到系統的除蟲與更新。

但是打造這個系統的方法，只要在網路搜尋「股票自動買賣 API」，與「股票 Telegram API」就可以找到很多人的研究結果，因為有很多人也跟我有同樣的想法，推薦各位也研究一下這個系統。

但我想也許有人不知道什麼是 Telegram，這個通訊軟體聽平凡投資股票的人都會知道。就算是沒有接觸股票的人，在當初 KakaoTalk 傳出監聽事件（編按：韓國最多人數用的 SNS 服務，在 2014 年左右曾經爆出，KakaoTalk 官方將通訊內容提供給檢查機關的爭議。2016 年，由韓國最高法院宣布這一行為違法）時，應該也聽聞過媒體都充滿著「我要移民去 Telegram」這句話吧。Telegram 不會被駭客入侵也無法被監聽，除非是本人自己把手機交出去，而 Telegram 也像 KakaoTalk 一样有電腦版。

所謂的 API 則是 Application Programming Interface 的縮寫，指的是被使用在操作系統和應用程式之間的語言或訊息的協定。簡單來說，都屬於應用程式，而所謂的公開 API，意思是允許應用程式的使用者可以按照各自的需求，將其程式重新撰寫。

而我就是利用這個公開 API 的方式，結合證券公司提供的強大搜尋引擎與 Telegram，打造出了這個通知系統。下方就是驅動程式的畫面，因為我是在週末的時候構圖的，所以股票搜尋後面沒有出現相關資料。如果這個能夠拿到專利權，我倒是真的很想把這個程式商用化。

至於我想分享這個 Telegram 程式的原因，是想給這本書的讀者多一點的想法，也許有人可以開發出比這個更棒的程式。我只是一個忙碌的上班族，能做到的不多，也許會有人可以真的開發出一個非常好用的軟體。

我也期盼著自動交易這件事真的能夠實現。我使用過現存的大部分自動交易程式，但是這些程式都是由專業的軟體工程師所開發，並不是由股市專家開發而成的。裡面沒有股票買賣必備的設定，使用起來也很複雜。我真正期待的，是一個由專業的股票投資人所開發而成的自動交易程式。

## 不受時間限制的交易方法

針對早上九點到十點都擠不出時間，但是又想投資股票的話，這個章節會推薦給各位一個交易方法。這個方法就是先經過幾天的時間讓買進後，再抽出一分鐘的時間冒出賺取報酬。這也是一個打破刻板印象的方法，因為一般而而言，這是傳出售出重大不利消息時，股票配股增資、無償減資中延伸出來的買進策略。這個技術是運用一本書都難以闡述的複雜又龐大的技術，但在這裡我會向各位簡略做個介紹。

### 現金增資

什麼是現金增資？用一句話總結，就是將除權後產生的面額損失，透過發行新股的方式恢復股權的買賣法。聽起來很複雜吧？實際上也真的很複雜，是一種必須透過實際操作過才能體會到的買賣方法。這個方法可以獲得高額報酬，但是沒有實際操作的經驗很難加以體會。要解釋這個買賣法寫一百頁都不夠，是非常專業的領域，因此這個章節我們會透過案例來了解整體框架，希望以後各位都能親自嘗試看看。一般在市場上，如果公司宣布進行股東配股增資，股價幾乎會落
