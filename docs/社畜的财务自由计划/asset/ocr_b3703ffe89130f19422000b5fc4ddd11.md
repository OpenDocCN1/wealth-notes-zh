# 用八日線
找出暴跌後回流股買點

這章節是八日線，這邊也與心理因素脫不了關係。為了買到暴涨股，無數的投資人都對五日線虎視眈眈。買在高點的短期投資人，大概也會把五日線看作是停損線。

但萬一賣出力道過強，瞬間跌破五日線的時候怎麼辦呢？也就是說，如果五日線的買進力道，小於把五日線當作停損線的賣出力道怎麼辦？

萬一這時候有主力出現（我這裡所謂的主力，指的是具有一定資本金額，能夠影響股價波動的「大戶」，並非意指籌碼操作的主力），他們會把在五日線停損的股票全數買進。但是如果股價跌破十日線，會打擊到投資者的信心，所以為了能讓股票快速上漲，他們不會讓股票跌破十日線，這時候我們要看的的就是八日線。
