# 成交量一千万股以上

首先是成交量。

對於新手而言，應該會很好奇平均應該落在多少以上才行，而我的標準就是「一千万股」。當然，我所指的不是日常成交量，而是有事件發生或是消息傳出時，成交量能夠破一千万股（編按：韓國的股票是以一股為基本單位，與台灣基本以整張一千股為單位進行買賣不同）以上的股票。「一千万股」意味著不管是買股票還是賣股票都很容易，可以快速的進行交易，這對初級而言是再適合不過了。
