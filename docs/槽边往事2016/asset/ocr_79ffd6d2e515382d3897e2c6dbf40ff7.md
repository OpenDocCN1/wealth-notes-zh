# 升级你的操作系统

以前一直以为只有上了年纪的人，才会被朋友圈里的各种养生文、鸡汤文、健康文包围，整天子女大龄未婚焦虑垃圾分类，一度还认真思考过如何减少这样的垃圾，向微信朋友圈进行付费转移。但是经历了许多朋友愿意轰轰烈烈的刷屏运动—几乎每五分钟就有一个转发BBC关于脑干肿瘤的新闻，或者某篇标题：迪伦拒绝诺贝尔文学奖的声明——之后，突然发现身边社会中最和主流声音的“他们”，在面对资讯的时候，表现并不比那些老人家强。因此，我改变了自己的看法。

我在自己的微信公众号里写了一篇名为《一个思考：你中招了吗？》的文章，提出了自己的一系列问题：

+   1、你中招了吗？
2、如果你中招了，你会转发辟谣的文章吗？
3、为什么你的教育程度、知识结构、分析能力、逻辑思维比老人家强那么多，你还是会中招了？
4、回想一下五年前的自己，你觉得你中文互联网环境下，阅读了五年之后，你的分析能力是整体上升，还是下降了，这是保持不变？
5、你到现在还相信的信息来源是什么？你相信的理由是什么？
6、你是否有随手检查信息源的习惯？你检查的方法是什么？中文互联网上可信的信息源是什么？
7、现在来回答“为什么老人家总是转发营销文章呢”，你的答案有什么不同？
8、毕业之后，你自学的途径是什么？你应对外部世界各种变化情况的传统经验没有进行升级？还是凭经验系统？
9、如果你的最后一问你的答案是肯定的，那么，你觉得当问答案之后，会和今天作为营销文控制的老家人有什么不同？

不用现在就急于回答这些问题，多一会儿有得是时间。

鲍勃·迪伦拒绝诺贝尔文学奖的假消息来洋葱新闻，对于我而言，看到“洋葱新闻”四个字的时刻，就立即明白这是互联网最猎魔文的一部分，从十多年前王小明的“黑通社新闻”，到今天的洋葱新闻，网友利用戏仿的方式进行创作，已经成为一种互联网风格，但年高者高流量中的“零分作文”一样。但是，对于那些我一个世代，甚至是为年轻的新时代来说，不太天然知道洋葱新闻是什么。可能在许多人眼里，洋葱新闻并没有特别的意义，和土豆网、豆瓣网同属某某网站。它属于对网络文化的认知的缺失，也不属于这种认知是人都必须了解的常识。所以，下一个洋葱新闻述是能够戏中理想，有文化、有知识、有视野的年轻人。

BBC的纪录片则更为精巧一些，纪录片是真正的纪实片，但是这论文巧妙地加入了很多细节。因为没有多少人愿意从读到尾看全部纪录片，所以文字加粗解方方的文章要90%的人可以及影片保持一致，但人们就不会注意到10%背离的雷同内容。要标准是题面劲爆，文内足够浅显，BBC还有足够的可信度，那么他们就能看着那么一点营销内容在短时间内传播整个互联网。而等到有心的人发现不对的时候，想要提出问题已经为时太晚了—人们总是倾向于自己是早先才自信的结论，一旦判断下达，人很难翻自己的认定。这一点，无论是否有学识、眼界，头脑都是改变，因为说变从来是一种稀缺的品质。

因此，我得到了第一个结论：我们和老人家一样，都在遭受垃圾信息的侵扰。之所以觉得自己不会被信息吞没的垃圾消费文章，只不过是针对于他们这个人群只需要做到那个程度足够了，而我们现在陷在极端为精巧，也更为狡诈的垃圾信息中所裹骗，但我们极少认识到这一点。甚至，正如以上两个例子所看到的那样，我们以缺乏必要的辨识力，更缺乏辨识能力。于是就有了一个悲哀的推论：从长远看，人们总是会变成自己父母的模样。我们的子女可能会使用今天我们看作父母的粗浅看待我们：你们怎么会将那些蠢得如此明显的文章？

当我重新思考我父母辈对待各种朋友圈的洗脑文章的态度时，对待“洋葱新闻”四个字的同一态同给了新的启示：人们一眼看去，只要看到某种粗体大字各种颜色的内容，那种既去、GIF图，以及各项顶级标题的诉求关注和转发的条件，在一秒钟中就能判定现既是一个垃圾营销号垃圾文章。为什么老人家们完全意识不到这一点？反而一个个起劲勒们追下去，并且转得整个朋友圈都是？因为他们完全没有学习过应该如何应对这种事情，连基本的审美经验都没有，更不用说运用自己的分析能力。

每个人活在这个世界里，每天应对繁杂的事务，所以总是试图建起一套内在的标准，可以不用很费力处理那种复杂情况。如果把人比喻为一台机器，那么应对事务的准备准也备好，经验集成也要，就相当于内置操作系统。上一辈人的操作系统和电视、报，每天上班就有的新闻栏发节目的晚报报，下班有电视台的广播台道，晚上有报纸的新闻节目，所有的媒体都经过仔细的选，保证人都权威和可信度。而今天，所有人才可以做，任何个人都可以在微信里开个公众号。对于上一辈人来说这种系统对他们并不天然知道应如何对这种有无限多选择，无限多声音的新情况。所以，只要在文章标题写上：专家中医、老专家说、央视、中科院院士们，人们报说：—就可以立刻控制他们的操作系统，让他们屈服。因为在当年，他们就是靠这些明显的标识信息来信任的。

我们的操作系统是为了今天而生的。我们凭借上网的经验天然地知道，一个网页如果Flash越多、弹越多、体越多，内容越多，那也就越烂。我们也凭借多年上网的经验能地知道，虽然网上有无数字个选择，以及应用如何使用。同样是网站，我们去到贴站看到天涯，和去知乎，对于它们的信任程度是完全是不同的。它们是如此深入地写入了我们的操作系统，以至于我们几乎忘记了它们当初是如何一点点累积而成。我们并不是天然地认为网络游戏是一种潮流，不应该沉溺者读电视，也许我们也不是天然认为结婚是自己的事情，离婚是时代的趋势，母亲都不该过多干涉子女的婚姻——在这个时代当成起来的人，接受了个人价值的肯定的价值观，这种价值观在数案例，无数的讨论中新进在人们的操作系统，变成了判断事物的本能。

因此，我得到了第二个推论：拥有最新操作系统的人最适合当前的社会，而所有人的操作系统都随着时代流老变化，要不断地更新当前的模式。如果你离开家乡，去到大城市，从事制作的工作，利用他的能力在自由市场站稳脚。那么，不用5年时间，你就会发现你和在家乡的父母朋友回忆往昔之外，已经有多少共同话题了。需要不断进行自我升级。
