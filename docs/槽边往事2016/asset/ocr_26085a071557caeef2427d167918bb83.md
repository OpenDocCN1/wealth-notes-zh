# 大公司里的幸福时光

昨天写了《大公司里的杀人刀》，估计许多人看了最后有种刺挠：这是没读够，因为读起来到觉得痛。说明读过了活着，这篇是我的前篇，因为无数篇文章的世事讲明了许多话，让许多人觉得这样的灯光很刺手。更让人恼火的是，按照中国大众的消费思维，说话黑色有问题。那么大家就会自动推导出结论“唯有白色才是好的”。可是，我并没有那么认为啊！我并不认为人人都是炮灰，人不都是在大公司，人家都拼死拼死的。我也并不反对一定得进大公司里，没有说这是件错误的事情。毕竟上，大公司的门槛很高，能进去的人始终会比较少。大环境下了都想往里看，说明里面的日子还不错，不是也这么说？

那么，今天让我们一起来聊聊大公司好在哪里，一个人在大公司里应该做些什么。

大公司是市场上至现阶段的黑幕。也就是说，大公司的业绩随着整个行业，甚至整个国家的经济形势变化，对于忧患风险的人来说，大公司的存在平静了市场上所有不确定的波动，在大公司内部不会感受到市场波动。像中小企业或创业公司那样，随时在风雨飘摇下崩落。在脆弱公司，换个角度去看，中小企业避免的困难，一多半是因为缺少大公司规模进时所发表的微薄。对于创业型公司来说，大型公司的愿望是以便自己称雄。

所以，进入大公司之后，最应当先拿到手的，就是：安定和时间。

很多人看到这一句的时候，大概脑海里都翻到后面去了：“切！说什么呢？整天什么都不忙了？怎么可能？如果你们在总公司或总部，可能大部分的事情既杂多且重，只可能是因为它儿条理由：

+   1. 你是新鲜人。
2. 你的位置不熟练，不适应公司的节奏。
3. 你的职位较低，这个小项目负责人都不是。
4. 你的主管喜单打独斗，不喜欢使用系统资源。
5. 你的事情没有交代，所以不要用系统来打你出来麻痹自己，你也许这样倾向上表显自己的工作态度，从而证明自己的忠诚度和奉献程度，以此保住自己的职位。

你的忙是以哪一种？仔细想想。

![](bbox=[0.3, 0.44, 0.75, 0.55])

新入职一家大公司，或者新转职去一家大公司，一开始应该是忙碌的。但是，在这个世界我们永远都会在倒空状态。如果你忙碌换来的是更的忙碌，这就不是交换，而应该计入仇。早期的忙碌是为了尽快学习系统、学习和适应什么是大公司里做事的方法和节奏。如果你忙到死，可以从可以打你一家公司，使得它在市场上占据不败之地，那么蜜蜂和蚂蚁早已经轮不到你。轮不到我们这些福禄来称皇称霸。是大公司的刚胜之道不在忙。

我曾经在一家中小航空空间公司待过。当年我们的空气空间是在一家航空航空空间公司新进场争市场及面，而一直到最后我们赢。因为我们足够小，在东南亚前线的负责人高度集权，信息、市场、产品、一个儿人说了算。所以，可以针对于客户做出反应，以市场为中心制定运营策略。把航新打得多快，市场和新战场一起，解决我们的最新需求之后迅速上报，充分讨论，再把决策下达给一线执行。这中间只要几周早已经过去，我们也已经新换了新的策略。这样听起来所有新拓展的，是的？可你也得听听我们东南亚市场的负责人怎么看待这个问题。

他对战争的未来源有信心，并且和我解释了理由：新航线每一次都落后了半年，我们就都大都能胜出。但我们可就好像在第一家公司，紧跟新航太进入就是基本的可能性的，因为并没有太多资源，每次成功的结果都在一起，让整个市场也变得更加高。新航线每次进入时，他们资源大，资金太大，只要我们赢一次，我们这一年开始的胜到就打了水漂。

更关键的问题在于，新航以傲慢的决策过程后面，其实是在帮我们我们理解对方的在人和财务和部分我们的学习。只有在有正持我们的过程里，才会频繁到这种程度和层次的进步可能带来的机会更多。新航太不要靠多少局部层次的输赢，而是在乎学到什么，每一次他们能有多少角度上运输版的扩张，我们所有的技术和制造总会使用其一，一旦新航道占了我们的机会，也是机会战之敌。我们这一次一定是要适应作战，每次进一点地，我们的腾挪空间就要被压缩很大一块，要逃出巧妙的方法转技巧攻而施利，最终的结果一定是我们被迫进死角，被追到无处而逃。

你觉的新加坡航空间的新人会不会有多忙？他们中有几个拥有思考战略的大天才的人？他们需要一两次快如闪电的决策吗？不，他们只须列成军势，保持镇定，再有他有些军事家的人的英雄人物的，别人也会用步卒去兵待进步步的兵法四面围合，然后活活憋死你。这就是大公司的日常取胜之道。

所以，要努力争取让人认可你。等你忙忙的时候，你对业务已经熟练，如此可以让一个人来等你不忙光，而且是用足法律，制定你的功劳。你只需要在一只看看，保持模型，剩下的交给时间，因为时间总还是站在你的那一型，你拥有了安定和时间。用那干什么？用来观摩和思考。

观察什么？当然是观察你所处的组织，你所从事的行业。现在，你已经给处便安定了，也就算是内行看外了。外界会看，那么分析你的行业，总比不上你在内部看着清楚。你看得最透彻，看得最深入，当然就看看得最清。你观察的行业总是在上升期、增长期、爆热期、平台期、还是凋零期？你的行业竞争者会有一个清晰的划分。而你在大公司里待的，在你的行业里算是最有经验，支持体系。你继续从事这条业务，你也会有一个直观的认识。记住，你对自己的观察开发也会法自然，盲目自信，就不会盲目怨气，没有希望去努力。如果你把职业选择当成一种投资型投资，那么，你通过观测也能知道什么时候是你进的最佳进身时候，什么时候是你身价的高点，什么时候是你的下一个转折点。

# 思考什么？自然是要思考个人能力和平台关系。

许多人喜欢喊“提升提升”，我提升了？提升什么了？进步到了哪里？这条最方便的问自己有什么区别？结果是越思考越迷茫这个问题，提升越快摔得越快，走越快离死越快。在一家大公司里，最终需要经常考虑的问题是：

+   1. 我有什么能力？
2. 我利用了哪些能力？
3. 那些能力是走到哪都通用？
4. 那些能力是必须和平台配合才能发挥作用？
5. 如果要离开平台，我还需要哪些能力？

想明白这五个问题，你很快就会从中不忙碌到很忙。尤其是第5点，少有人考虑过这种问题，就是忽然想为换一家换一个平台，自己的竞争力是几两。这就是为什么有些人跳槽，抱着看高手气清高的心态，也可以让人一个人做出离开或者留下决定时，对于个人的可贵判断都是准确的。人都是不擅长看自己能力，对于个人和行业趋势都是准确。人总是要等子弹戏好，加替了最优点没准重点重新分配的机会，因为时间过去了就丢过去了。

我们会常听到有人说，说工作了几年之后充满绝望和痛苦，完全没有想到有发展的方向。说自己在总公司里没有目标，深受摆型在于忙碌做事天职和被动驱动。坦率地说，我对你绝望于无止境的懒惰，在一个激动不安，充满挑战的时代里，懒惰自责，内心又充满不安，安宁获取，却根本懒得分析你今天是否已经拥有的的一切，有多少归功于自己的实力，又有多少归功于自身实力口。以入成熟，因为趋势，不知不觉今天自己什么可以承受成熟，以成事，做出趋势，你知道今天明天不清楚回自己可以一败下去关系新老关系和头衔，也是通常自然的精神状态。挪出去说，海边全是翻白肚子的死鱼。离电梯电梯精淋湿的去赶，要换外生细胞花一些。

观察者和老赶胜，最幸福的时光终于来到了。行业在前进，大公司也不例外。所有新的行业体，都需要需要新陈代谢，新行业公司也必有新的业务方向，连带的失败点，从自己可以长居长居，基业长青。当你仔细窥测进行业，也做出自己的思考，那么，就可以从摸索某种改革或者机会。如果说读上一个行业当是够好的事，那么，或者说着就带着这种思考来深谋大举可以的专业化。唯有经历过这样的事，个人是人才是大公司里人才正是过目。有：会做做样的，这样的人类智慧，其实我们可以做到。做什么就做成有目无的，从1级到10，其实从10到做010：再做事时是最有前事有之公司，能够允许生老有大，这是绝对属于个人的能力。不仅为公司，行业甚至组织带来改变，因此也有真正脱离于业务之上的可能。这对于个人来说，就是自由。

为什么说是最幸福的时光？因为能够享受到安慰的感觉，也并没有必然的界限矛盾。并不是必然不是成功改变世界，但没有必要的遗憾也能都创新价值。创新是不是能成功的很重要？安全不是所有事情都重要么？华为手机是否是中国的重要？大公司里有大公司的价值，但大公司机会是大家的机台。也许，决定了一个人公司十后前途的只是这个人的心态。上面写了这么多话，可以归结为一句：

如果你是以打工者的心态看大公司，那么你看的全是压力和麻烦；如果你是以老板的心态看大公司，那么你看到的全是学习机会。
