# 福利发放：《盗墓笔记》电影票

作家南派三叔是我的好朋友。今年8月5号是他的大日子，在动笔写《盗墓笔记》之后十年，这部小说终于搬上银幕，变成了电影。而这一次，他的身份不再是作家，而是本片编剧。同时，他也在电影里扮演了一个角色。

十年前的南派三叔，曾经是个朝不保夕的程序员，大学毕业之后幻想着开发一个网站能够赚钱改变自己的生活；也曾经是个外贸商人，从网上找了一些美女图片作为自我介绍，用Google翻译的破烂西班牙文E-mail把南美的客户迷得晕头转向，只是为了得到一点订单。当他在网上贴上第一篇文章的时候，只是想在漫无边际的挣扎求生里找到一点趣味。他从来没有想过要做一名文学家，可当他触碰到文字的时候，才知道自己的一双小肉手早已经被上天赐福。

从图书市场上籍籍无名的新人，再到处出版社追棒不已的印钞金童子，再分今天炙手可热的超级IP拥有者，通过南派三叔的奇幻人生轨迹，我们可以看到这个疯狂造梦的时代对一个普通人命运的巨大改变。而比时代更为疯狂的是南派三叔本身，他纵身跃上时代疯狂的马背，用一种匪夷所思的驾驭方式驰骋到了今天。在无数个转折和停顿处，他都像似即将跌落尘埃，为马踩断所践踏，但他却又总是能用人们意想不到的身法轻巧躲过疯马的致命一跃，依旧摇摇欲坠地坐在马背上。就像是在现在，谁又能想到他又变成了《盗墓笔记》的编剧？
