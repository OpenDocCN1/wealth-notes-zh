# # 夏季乘飞机的正确姿势

看了标题也许你会问：为什么是我？因为我有19年的民航旅客经验，外加11年的航空公司工作经验。在航空公司期间，我预报过天气，放行过飞机，参加过日常现场运营和管理，从一线岗位到管理岗位都做过的；在旅客飞行期间，我经历过误机、延误、取消、备降、返航、复习等状况，而我一般都能在“不知道前坐什么”的前置条件下，先想办法脱离困境、在飞行延误的问题上，我曾是《低落小说》里的“狼先生”。所以，现在我可以接着说了么？

夏季乘坐飞机经常遇见延误，原因有两点。一、和其他季节相比，人们更容易在夏天出行，因为冬天穿衣服多，用自拍朋友圈发黑白，没有人会点赞的；二、夏季经常发生强对流天气，即使是雷暴、冰雹、垂直降雨、大雨，造成机场或着航路关闭。人们密集出行，同时天气不公开，于是就会在夏季出行时频频遇见延误。大众轮渡经常运输国际东航高海南航，不过驾气了也没有什人。中国民航令人遗憾地失去了我，否则延误原因一定会增加一项：水患。处置方式是：在候机楼平静地反省。

![](bbox=[0.2, 0.34, 0.8, 0.48])

为了最大程度上避免航班延误，我建议你：

# 1、 选择好出行时间

尽量选择早晨航班，不要幻想自己睡着了才起床，收拾行李从容登机。这是航空公司飞机从早飞到晚，执行一个航班后立刻转场继续飞，不插称为“航班接”。当一个航班发生延误时，延长会向后续航班传递，有时连续的航班或着连续延误可能形成雷暴。所以，最终选择首班航班的优势，也就是每天最早的那几班。早班飞机还有另外一个好处：雷暴一般在中午以后产生，早上可以最大幅度避开天气原因造成的延误。

# 2、 选择好航空公司

买机票之前，查看一下出发机场有什么“基地航空公司”，尽量从基地航空公司里选择一家购票。所谓基地航空公司，就是说航空公司把某个机场设为运行基地，相当于是一个分公司，有飞机有乘务员有地面保障人员。也正因为这样，基地航空公司往往有备用运力，一架飞机临时不坏，还有其他备用的飞机。或者因为涉及几个基地时，总部才能调配一架飞机过来。以下是国内太航空旗下的基地名称，其它的航空公司请自行上网查询：

+   * 中国国际航空：北京、成都、重庆、杭州、上海、天津、内蒙古、武汉、贵州、大连；
* 中国东方航空：上海、北京、石家庄、青岛、合肥、南昌、太原、宁波、兰州、江苏、成都、武汉、昆明、西安；
* 中国南方航空：广州、北京、郑州、重庆、深圳、厦门、沈阳、乌鲁木齐、宁波、长沙、大连、哈尔滨、贵阳、福州、青岛、南宁、桂林；
* 海南航空：北京、西安、太原、乌鲁木齐、广州、大连、深圳、海口。

即便你选择了早班飞机，选择了基地航空公司，还是可能遇见延误，正如我们明知了所有的道理，却依然无法度过幸福的一生。当延误已经无法避免，唯一你能做的更就是尽快从延误里逃走。按照优先级别从高到低，你可以：

# 1、 找信机

信机就是登机口穿着航空公司制服的地面服务人员和各种航空APP，机场准备相比，他们更接近真相。所以，任何时候要是发生延误，请你去找信机。客暑客气询问一下延误原因，看看是否还能正常起飞、或是否已调下航班。
