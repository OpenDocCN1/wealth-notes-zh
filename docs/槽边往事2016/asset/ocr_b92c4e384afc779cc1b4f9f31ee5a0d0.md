# ## 假期电影看什么？

如果你假期里左左右右，又懒得出门，却依然想在看杀秋风雨里找到一点温暖的知觉，那么请允许我向你推荐电影《追捕野蚕人》（Hunt for the Wilderpeople）。

+   给一点提示：别被片名骗了，没有野人，没有怪人，也没有大烂脑，它根本就没有是一部探险电影。别被看着的心态，一部想要从中寻回刺激的感觉，别在出发点上就选错了方向，许多人太过轻易放弃一部电影，和一部佳作失之交臂就是为这样的原因。

好了，你可以去了。

以下内容因为可能涉及剧透，请在看完电影之后再来接着看：

《追捕野蚕人》拍得清丽脱俗，原因是故事本身强大。情感形成于千万部，但故事类型本身是有限的。在《追捕野蚕人》之前，类似的电影还有法国电影《蝴蝶》，美国电影《冒牌家庭》，甚至是中国电影《漂亮的小溪》、《孙子从美国来》。从故事的角度分析，它们都有共同的特点：

+   1.  一人，一人，一人。
2.  他们双方都受到某种无法解脫的困境中，必须待在一起。要么携手对抗外部力量。
3.  经过一段时间之后，由于不断的冲突和矛盾，增进了双方的理解，最后改变了两者之间的关系

这种人际关系逆转的故事，从来都是好故事。从最底层的情感来说，我们所有人内心深处都存在着两重隐患，一是担忧自己永远不被理解，永远不被别人接纳；另一重是担忧自己对别人的时候也有相同的问题，太在意他人的表象，以至于错过了了解他人内心的机会。所以这一类型从厌恶到喜欢，从拒绝到接纳的故事，总是能击中我们的内心深处。

附带一句，如果你对本书不喜某些人，说一种感情后多半会被证实是正确的，而错误一个好好的机会做微其微——如果我们没有这种“坏人雷达”，估计人类早就灭绝了。

从我们理性的角度来说，我们在可能或多或少地寄想一下，唯有在极为恶劣的情形之下，我们才能够更深入地认识一个人。尤其是在这个过程中，如果我们的个性发生了无可避免的冲突，那么这种冲突能够非常明显地暴露出来的人性，于是我们可以推测出对方何以变成今天的这个样子。尽管每个人都认自己的经历是独特的，每个人都认为自己的阅历是唯一的，但是当懂得对方的变化路径，会不得不承认许多心路历程是类似的，人和人之间的区别并没有想象得和那么强。这是一切之间不存在解和共识的基础。一旦达成这种基础，即便原本极端敌对的人也会被彼此拥抱宽容，精彩之处就在这里。每当看这种故事，都会增强我们对人性的信心，每一次都会和第一次看到一样，觉得发现了生命中了不起的真相。

这就是看完全会感到温暖的原因。

如果你喜欢看电影，那么迟早你也能写出上述的分析文字，写得头头是道。甚至可能会为自己写不懂了讲述故事，更妙，还写出无法于原作来。相信他，这是没有希望的。你可以分析一百家公司的兴起和衰亡，得出普遍的规律，运用与自己的企业上，同样获得商业上的成功，但是这一套招数在文化创意产业上是行不通的。哪怕你分析出所有的规律和技巧，甚至写着抄录情节套索，往往一模一样的剧情架构里，也不能保证最终能产出优秀的作品。不信的话，请你再看一遍《追捕野蚕人》。

为了塑造那个内心崩溃的胖小子主人公，导演只几个镜头、几个镜头、几个事件？开场最重要的、一场戏，描写养母一下子扭转了胖孩子的心，用了几次戏？设计了一节电影，你仔细观察一下就能明白。一般剧情一百多分钟，每一秒都珍贵异常。要让观众接纳一个角色，觉得他真实可信，最终可能给到角色身上，编剧导演只能极其有限的镜头里去努力塑造一个人物。但是，优秀的影片的分辨率有那么高，寥寥几句对白，几个镜头，就能把一个人交代清楚，让观众觉得角色非常具体，可以自行丰富人物的背景。这就是属于创作的部分，在同样的故事架构下，如何填充就着各人的本事了。各种电影里的问题人很多，在《追捕野蚕人》里渴望着成为黑帮分子的问题少年让人难以忘记，不是一场追车戏和一对白的事情，也是我选择了黑帮生活，而是黑帮生活选择了我。

除了效率，还有一样东西是抄不出来的——《追捕野蚕人》自始至终轻快的节奏。有些电影看下来的感受就是枯燥无比，有一些电影之间的衔接都自然顺流，而有些电影看来下来都能感到导演的痛苦，知道电影就是一个七拼八凑而成的弗兰肯斯坦。什么是节奏？它根本不是对所谓的轻重缓急变化，而是创作者对作品的控制力。当创作者非常清晰地知道自己要什么，而且知道如何做到这样的效果，那么，在他心中千锤百炼的故事会按照最合适的形式表达出来，该快的地方快，该慢的地方慢，在别人的看来就是节奏良好，浑然天成。哪怕《追捕野蚕人》的新西兰导演在部分情节的明显异于常见的电影叙事模式，因为这种对作品的控制力，也会让人觉得那是导演的个性特点，值得赞赏。

每次写这样的文章，都会有人留言说，看电影至于么？你不累吗？嗯，我觉得只有这么写完，才能说自己看完了一部电影。否则，看一百部电影和看一部电影又有什么区别呢？
