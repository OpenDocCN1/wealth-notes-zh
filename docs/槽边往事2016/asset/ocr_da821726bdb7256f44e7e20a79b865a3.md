# 下｜公众号创作指南（脱水版）

不是单是写作，在我们认为竞争激烈的所有领域之中，类似的方法都在起作用。真正意义上的竞争并没有那么多，真正意义上的竞争对长远没有想象得那么多。能够穿越时光的浪潮，站在你面前，值得与你相对的人，很可能不超过一掌之数。如果你觉得人多，那只不过是因为你做得还不够多，都根本不用谈你做得好不好。

我鼓励写作，鼓励原创，原因就是希望你能体会一下这种时光冲刷的感觉，体会一下领先者的孤独感。当你目睹周围的人一个个放弃，一个个消失，对“做事”这两个字的理解就会和之前完全不一样，你对“成功”两个字的感觉也变变得有重量和质量。

和其他的方式相比，写作的成本低，不用付出多少金钱、时间、感情上的代价，你就能体会到这一切。

这是我想和你谈的第一点：持续创作，时光会帮你消灭99%的对手。

如果你是从第一篇写作指南读起，一直读到现在这一篇，那么我想你应该承认一点是：虽然我完全可以在谈写作的时候谈些写作以外的领域。我也可以承认，这个系列文章所提供的价值可能超过之前所有文章的总和。但是我想告诉大家，很多人为了一篇文章，认为内文写了很多无关的，其实只是匆匆看了一眼，拖到末尾看评论，根本就没有发现内文中有价值的部分。

这个事实告诉我们两件事：一、你没有你认为的那么重要，即便我写了那么多，写了不少关于写作的文章，但大多数人也不会专门来看，也并不会认真地读。而且，你写的越是认真，读的人也就越少，文字也好，其他任何人做别人认为有意义的事也一样，只要他们还在面对无效率的人当中罢了。二、不必在自己身上集中太多的心力。太过在意自己的行为所能取得的回报，每做一件事都问为什么还在做，因为我觉得这是有价值的事情，不需要任何人的认可，只需要我自己的认可。所以，我写我的，并不奢望所有人都看。

二、大部分的时候，你所做的事情价值都很低，你的行事方式都不被认同，这在太正常不过的事情了，人们对你做一判断只需要几秒钟，你写的再容易的事，5秒钟已经是非常不容易的事情，人们不会停下来思考你的意义，只是随手划一张图片，一个不超过10个字的标题，它们加起来不过让别人的停留2秒，决定是要打开文章去看。二开开，你还有3秒钟时间，别人会扫一眼就过去了判断所以，在技术上应该去考虑如何制定一个吸引人的标题，一张能够抓住眼球的照片，但在价值上能够服务于你，并且尽可能减少你的时间消耗，所以只有真正认可你价值的人，最终才会成为你价值的一部分。这句话有点绕，希望你能明白。

这就是我想和你谈的第二点：创作时应该忘我，忘我时应该爱人。

在这个系列的文章中，其实我已经向你展示了“序话”。写作之所以一件大多数人感兴趣的事情，所以，一篇文章写下来就可以杀掉75%的人，剩下的人要么对写作有兴趣，要么真的对于我感兴趣。许多人非常在意流量和数字，比如想做到公众号10万+，像商家天天打折促销，恨不得店里天天挤死人，可是在我看来，创造10万+只是一个纯技术问题的概念。任何时候，只要你想去做到10万+这个数，是一定能够找到的，并不是一件非常困难的事情。人群聚集的节点来去无外乎那几种，民众的方法也就那么几种，总能让大多数人跳起来。

但是，真正难得的是筛选出来的25%，那些漂亮的数字如同浮云来去，也如同浮云一样毫不留连，说消失就消失了。但是，筛选出来的那25%却如常陪伴着，所拥有的口碑，所谓的人气，所谓的影响力，都需要依据这些人。而那75%的人，当你急起时，会依据你这个群体来看待你的，会依据你这个群体的态度来看待你。

这是我想和你谈的第三点：除了自己之外，想清楚你为了谁写作？人致和人效并不相同，要坚持筛法。
