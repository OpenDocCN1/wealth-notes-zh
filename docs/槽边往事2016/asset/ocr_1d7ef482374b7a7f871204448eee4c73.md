# 中秋之约

还有一点是中秋晚会，会送游戏，会唱歌曲，会吃月饼，等等，月饼是圆滚滚，圆乎乎的，圆中又包了馅儿，月饼又圆又甜。月饼的形状是圆形的。月饼里包裹着馅料，月饼是圆的，圆的形状。

中秋晚会就是，大家聚在一起，吃饭，唱歌，看电影，玩游戏，玩的不亦乐乎。

中秋节，是中国的传统节日，也是一年中最美好的节日之一。在这个美好的节日里，一家人团聚在一起，吃月饼，赏花灯，玩灯笼，猜灯谜，感受浓浓的节日氛围。

中秋节是全家团聚的日子，也是赏月的日子。中秋的晚上，月亮是最圆最亮的，一家人围坐在院子里，一边吃月饼，一边赏月。

月饼是中秋节的传统食品，月饼圆圆的，象征着团圆。月饼的种类很多，有五仁、豆沙、莲蓉、蛋黄、鲜肉等等。

中秋节还有一个习俗，就是挂灯笼。红红的灯笼挂在树上，挂在屋檐下，挂在街道旁，给中秋节增添了浓浓的节日氛围。

中秋节晚上，人们还会玩猜灯谜的游戏。灯谜就挂在灯笼上，猜中的人就可以得到小礼物。

中秋节是一个充满欢乐和团圆气氛的节日，是一个美好的节日。
