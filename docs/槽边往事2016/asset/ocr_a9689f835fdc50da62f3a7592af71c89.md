# 另一种人生的答案

另一种人生的答案。和菜头

1997年深夏，汉口路，南京。

母校门口，梧桐树下是一溜饭摊，知了在树上疯狂歌唱着最后的夏日。我站在一个报摊栏前，翻阅着最新的原版《国家地理杂志》和《时代周刊》。临近毕业，我不得不时不

在那种时刻，人就容易产生幻觉：觉得在世界的某一个角落里，存在着一个和自己一模一样的人，甚至和他有一样的情感和想法，他更是自己失散多年的孪生兄弟。在每个人生选择的关口，他都会选择另外一条道路，过上你错过了的那种人生。在许多年里，你不断地听据你的们邻居，告诉你们在另外一个城市，另外一些街道见过他。你们冲着他大喊他的名字，但是，没有一些回应，急匆匆带着你的另外一个人消失在人海。于是，你渴望有一天能通见他，你不是对他有什么兴趣，你只是想知道自己另外一种人生究竟是什么样的。

2008年我离开家乡开始北漂。在这些年里，我一直想找到他，让他告诉我，如果我当初选择留在家乡，现在会是怎样一种人生？我是也会创造，我能创造出来的会是什么？当我们同时站在世界里面，各自会提出怎样的答案？

在这个世界上，有些问题大概永远不会会有答案。你追寻得越久，答案也就距离你越远。唯一的办法是耐心等待，等待有那么一天，答案自己跑过来敲门。我想，我现在已经得到了答案，答案就在电影《路边野餐》里。
