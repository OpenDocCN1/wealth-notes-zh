# 王菲怎样才能把演唱会门票卖到一万元一张

+   - 公众号：娱乐资本论

王菲2016演唱会门票砸手里了。但圣诞节应该开心一点，所以我不得不起那么长的一个标题，重点放在如何做成一件事，而不是为什么会搞砸一件事情。

有人说，之所以王菲演唱会门票全砸在手里是因为票价太高，过度消费粉丝，伤害了二级渠道的利益。甚至有传闻称王菲本来想把门票卖到一万元一张，结果物价局干涉，最终不得不改成7600元一张。

我的问题是：一万元一张门票真卖不动么？

王菲成名很早，是中国歌坛当仁不让的天后。不是三年五年天后，而是一直都是天后。她的粉丝群体大多是70后和80后，如今正是中国社会消费能力最强的阶层。他们动辄飞往欧洲品酒，飞往美国自驾，在奢侈品店扫货，不知道一年要买多少个包，也不知道每个包能用几次。相对而言，花一万块钱任性一下对于他们来说并不是过分的事情。而在14亿国民里，有这种消费能力的粉丝在人数上也应该远远超出两万人。

那为什么砸手里了呢？我认为这是因为王菲和她的经纪人陈洁瑛粉丝经济学不及格，需要重修。整件事情只有两个难点：

+   1、如何从14亿人里找出那20000个人？
2、消费能力如何转化为购买意愿？

但是，王菲她们并没有解决好。甚至可以说，根本没打算解决。而是极度自信地上手直接就是卖，想用800张票作为一个引子，造成饥饿营销的态势，然后所有剩余的票自然一抢而空。天底下哪儿有那么自然的事情？

14亿人里找出20000个符合要求的人是非常困难的事情，每70000人里才有一个。换句话说，王菲他们得对70000个国民宣传一次演唱会的事情，才能找到一个有可能购买10000元门票的粉丝。北京2125万人，潜在的购票人群也只有307人，就算北京富裕人口较多，乘以十倍也不过3070，连演唱会的每一个角落都坐不满。而要通过到北京城里的每一个人，王菲要开演唱会的消息，花费多少广告预算，得动用多少媒体渠道，又得以多大的频率反复轰炸？如果要在全国找到20000人呢？成本又是多少？

即便找到了20000个人，他们只是有这个消费能力，并不等于他们就一定会计去投票。因为对于拥有这样消费能力的人群来说，他们在娱乐上的选择非常丰富，演唱会未必是他们的必选项，甚至也不会是首选项。因此，要让他们掏钱投票，就需要提供他们一个行动动机。而王菲2016演唱会从筹划到现在，能拿到台面上说的理由只有3个：

+   1、从2010年以后，王菲没有开任何演唱会了；
2、这是今年唯一的一场，下一次不知道是什么时候；
3、使用了最新的VR技术，舞台效果和以往所有演唱会都不同。

这些理由站在票务方，会理解为是这场演唱会稀缺的理由，是粉丝掏钱购票的动力。但是，站在旁观者的角度看，这说明王菲从自己粉丝群体的视野里消失了太久。在长达六年的时间里，除了偶尔唱几首电影配乐歌曲，王菲一直没有对自己的粉丝群体有效输出任何内容。从2015年开始，她甚至停止了更新微博，更是把她和粉丝唯一的联系渠道中断了。

在娱乐圈里，一个人就算是天皇巨星，长期没有任何消息，不和粉丝互动，结局也只能是被他人遗忘。你关照粉丝，粉丝自然也关照你。陈慧娴当年如日中天的时候，说是要去英国念书。念书的意思对于粉丝来说，就是不再和粉丝发生任何关系，也不提供任何服务。等陈慧娴读书回来，一切都已经时过境迁，长时间会消耗许多事情，包括粉丝的热情和忠诚。

事实上，粉丝的忠诚并不需要王菲年年出新专辑来维护。王菲之所以能赢得如此之多的人心，是因为她的偶像气质。偶像气质是一个比较虚幻的概念，具体说起来就是粉丝可以在她身上投射自己的情感和欲望，王菲的歌词，王菲的行事，代表了他们心中的隐秘欲望，是他们的心声代言人。所以，六年没动静也无所谓，但是在粉丝心目中的个人形象要维护好。之前她特立独行、我行我素的强烈个人风格，必须持续释放，供粉丝消费。于是，她才能继续保持粉丝心目中神的地位。如果能做到这样的水准，一场演唱会不过是一场对神的供养，一次对信仰的充值罢了。
