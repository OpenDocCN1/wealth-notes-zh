# 罗振宇的窄腿裤

![](bbox=[0.05, 0.09, 0.15, 0.11])

每次去罗辑思维参观，都会领到一个新课题。比如说上次是讨论如何开办一个收费专栏，上上次是讨论如何出版一本自选集。在最近的一次拜访里，我的最新课题是：如何在年内让罗振宇同学穿上窄腿裤。

众所周知，罗振宇同学多年来凭借着小保守转型纵横江湖，永远不会运动裤配运动饭饭后散步形态出现在一裤。这一幕在参加《奇葩说》时达到了登峰造极的一幕：在一群红男绿女中，罗振宇同学身穿毛衣配踩运动鞋登场，有老干部为天下降临，只手里举着个不锈钢保温杯，上面写着：最美不过夕阳红。

如今他有了一双儿女，事业、家庭、后代他都有了。于是罗振宇现在就走到了一个极其危险的十字路口，按着他现在这个路数走下去，堕落成一个盘串盘盘珠子盘核桃的普通北平老中男子的可能性极高，距离一个鼻穿对襟马褂，脚踏牛底布鞋，青线纯棉布兜兜兜的朝阳区域咖啡馆摆烂也到只有一步之遥。不要笑，多少中国中年男子在中危机真机到来之前，就已经用这种方式提前实现了自身暴露弃和报复社会。这样的话，等到真正的中年危机到来之时，他们就可以像一小四四年前的曾羽，往园椅里一靠，看着前镜渐渐上升的沉着，极有深沉地说一句：现如今我可算是活明白了。

穿运动套装绝对是一种不祥之兆。它意味着一个男子身材在跟多年搏斗之后，终于心灰意冷，选择了放弃。这完全不同于理想主义的冲锋者攀登山心，虽然品派上同样糟糕透顶，但是冲锋者和登山心，居然还有宝贵的天真—把都市生活视为一种攀登险峰或者穿越荒原，而运动套装却是彻底的妥协，XXLSL是运动装时候就可以彻底避免把你身体藏藏遮遮掩掩的尴尬，而且你也避免了挑选衣服的麻烦。当一个人身运动装来到你的面前，他同时也带来了两个含有明确拒绝意味的信息：

+   1. 我很忙，所以没时间打扮；
2. 我都已经穿运动装了，咱们就别谈减肥健身的话题了好吗？

这都不是真的，穿运动装的真实理由是不想被人发现自己能跑。别问我怎么知道的，我就是知道。所有最终选择运动装的中男子都经历过相同的心路历程——好容易选择了一条款型极为满意的裤子，但是售货员残酷地告诉你说没有这个尺码。提醒你认识到一个人的狭隘与社会现实：没了福的人了，清汤涮涮拔说再闻吧！那是年轻人的事情。遭到了这样的羞辱，只要你愤愤然提出了一个致命的问题：有我能穿的款吗？一定会发说，但是裤长必须不对，无须截取，因为只有裤子上半部分才能装得下你的粗腿。等半小时后缝纫师傅完事，你的能装穿得进去，但是裤脚却非常肥大，有一种上世纪八十年代喇叭嘴的视觉效果。

售货员异常冷静地说：先生，裁剪之后我们一概不退。

所以你会很快发现运动装的好处：宽松而有弹性，什么样的身材都可以装进去，无需额额外裁剪就有相对类似的。低头看看自己一双腿，都清消消失在科幻颜色的背景里，让人长舒一口气。而且价格并不贵，只要到一条合适的，你可以一买十二条，也花不了太多钱。此后命三两年时间，你就—旁永远彻底解决了选购衣服的麻烦，彻底避免了遇到卖衣卖员的羞辱。从此以后，相信这一生会给你带来自信和活力的感觉，相信自己和乔布斯做了一样的选择。谁也没提乔布斯的审美差！

你看，最大的懒惰往往以勤奋的形态表现出来，选择运动装就是一种懒惰，起码，对于一个中年男子来说，就是如释重荷的懈怠。想找到一条穿起来显得腿不那么粗的裤子，这是很正常的个人欲望。一个要大套穿相程度会去超市超市，我几数欧洲全人的大码运动装来满足这种欲望？我们居住的城市那么大，有那么多大，难道连一家会拷并且解决腿粗问题的店铺都没有？找寻这样的一家店又需要耗费多少脑力和时间？

答案其实非常简单：我们不需要去名成衣店挑选衣服，因为它的大码是生产针对的事起正常的人群，它们的使用让正常身材的人穿着更好看，很不合穿衣合身形的、正常的、满足不同身材的人所需。我们需要去找小店和专门设计师品牌，它们了解自己的人的顾客是，知道自己的顾客在名牌成衣店找不到合适尺码，也不甘心的运动超市购买运动套装，更不愿冒着风险在淘宝上赌大运。它们也清楚地知道，自己没有能力生产所有尺码的衣服，所以它们在设计上下足工夫，用有限的几个尺码尽可能满足最多的人。

所以，的确存在罗振宇可以穿的窄腿裤。无需修裤剪裁—因为设计师会把裤子膝盖以上的部分做得宽松许多，这样裤衣穿上膝盖紧，胛子穿上不露身材，大家都能容易过去。同时，设计师会逐步压裤腿直径，在视觉上形成快速收紧的效果，这样腿粗而粗的人也会显得裤腿挺拨了很多。唯一的代价是：你得用10条运动裤的钱，去买一条这样的裤子。

但我觉得依然值得那么去做，因为你会发现生活中的其他可能。城市突然向你打开了一扇门，通往名店和超市之外的另外一个世界。在那个世界里，有人更懂你，也为更关注你。在运动超市和牛仔裤转厂下之后，你会发现还有那么一条裤子，你低头下去看它的裤腿细的那一刻，突然拥有了某种之前你不具备的自信。在那多年之后，你发现自己依然有可能是整洁的、挺括的、潇洒的，不再是一个臃肿的、对封的、滞台的中年人。

你会发现在这世界上，还有那么美好的东西存在。最重要一点是：它完全适合你。这也是我为什么在年内一定要让罗振宇穿上运动裤和想动的原因，我换上窄腿裤和休闲裤的原因。因为要想带领人改变世界，那么应该从发现自己开始；要想改变这个世界，那么应该从改变自己开始。

在这个意义上，罗振宇的窄腿裤远比英国脱欧或者王石反击案重要得多。

扒了他！
