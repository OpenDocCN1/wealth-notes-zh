# 聊聊咪蒙

今年每过一段时间，网上就要讨论一次咪蒙，有过瀚话。有人做过统计，今年这样的咪蒙潮已经泛滥了6次，差不多2个月就一次。这么说起来，咪蒙的存在已经算是一种现象级。哪怕某个具体人物意义不大，那无非是制造情绪和激情传播，但是剖析一个互联网现象可能可以给我们带来一些思考。那么，拿刀来，让我们动手吧！

首先我问一个问题：你知道“咪蒙”这个名字吗？我在《得到》有接近2万订阅读者，相信有相当一部分人都不知道咪蒙是谁。既然说咪蒙是一个现象，那么我们应该评估一下这个现象的等级。究竟是国民级，还是省级，或最高是乡镇级。根据报道，咪蒙点击量最高的一篇文章是《致贱人》，三天内获得350万阅读。那么，这个体量和微信相比如何呢？

在今年11月16日发布的腾讯三度财报披露，微信的月活跃用户达到了8.46亿。350万比起14亿中国人有6.9亿人次收看。现在你应该对咪蒙的流行程度有了一个粗略的估计，这也是为什么我一开始要介绍这个问题的原因。你可能觉得周围的人都在谈咪蒙，但并不等于人人都在谈她，微信的绝大多数用户甚至不知道这个人是谁。

为什么你会觉得确有人在讨论咪蒙？两个原因：一、的确有人在讨论咪蒙，围绕咪蒙抛出的争议性话题，每次都会有几十篇超过10万阅读的评论文章，这等于放大了咪蒙的声音，你未必关注她的账号，甚至都没有读过她文章，但是你很可能会看到关于她的讨论。

二、微信是一个去中心化的产品，也就是说，微信并没有一个人看得到的热文榜，或者微信会把一篇文章推送给所有用户。例如是《新闻联播》，它是严格中心化的产品，以至于段子手中国所有的电视机到了每晚19:00就会故障，没什，息息相传的内容透过一个个圈子里进行，所以，如果你的人际圈子如果有几个咪蒙的读者，那么，当她们用咪蒙的热文朋友圈互动的时候，你就会觉得咪蒙无处不在，那不正是她的错觉么。

微信有8亿月活用户，但订阅数量最多的公众号也远没有8000万读者。我们从中可以推断出来，并没有那么多人愿意阅读。哪怕是在微信里。然而，人际关系网并不像你们想象得那样联系紧密，信息可以无限地从一个圈子传导到下一个圈子。传播只是在热爱传播的人之间水平向传递，当信息向人群纵深方向传递时，会迅速衰减。所以，迄今为止还没有出现任何一个可以从一线城市垂直击穿到四线五线城市的人群的公众号。公众号里的那点风泼，依然是茶杯里的风浪。

那么，真有那么多人讨厌咪蒙吗？如果你对号批评论文章都看一遍，会发现批评的理由千奇百怪，各个角度都有。但是，涉及的事实却是相同的几条：

+   1. 咪蒙每篇文章的阅读量都在10万以上；
2. 咪蒙的广告费单篇文章超过25万，甚至达到50万以上；
3. 广告商测，咪蒙的公众号的广告转化率是最高的。

还有提及：每一条大规模批评咪蒙的文章，会有数十篇文章获得10万以上的阅读量。也就是说，咪蒙的读者喜欢她、广告商喜欢她、人家喜欢她，甚至是批评她写作的人也喜欢她，因为她流量是漂亮的。写好咪蒙每周都能引发一轮争论，这样所有人都可以雨露均沾，大家一起心照不宣地完成这个默契的游戏。

面对如此密集的批评，咪蒙会受到伤害吗？如果有心情，可以看看一下每场争议爆发之后，咪蒙新发表文章的点赞数。只要咪蒙遭到密集攻击，点赞数就会暴增。这中间的道理就像国家发生边境战争，会迅速激发爱国热情一样。在遭受攻击的时候，咪蒙的读者找到了归属感和认同感，会更努力地去维护咪蒙，这就巩固了咪蒙在核心读者群中的地位。

另外，记得刚刚说到的微信传播机制吗？透过人际关系的传播会很快衰减，所以，每次争议发生的时候，批评文章越多，批评人和咪蒙之间读者的交集越少，意味着咪蒙在更多人际圈里赢得了更多次传播。于是，透过批评，咪蒙进入了新的人际圈子进行传播，当初她怎样赢得读者，那么她现在也会怎样继续赢得新读者，这就为她扩大了读者群。

最后，有批评咪蒙的人都落入了相同的陷阱——觉得讨厌一个人是最容易的事，最极端的是极不容易的，却因此忘记了整件事叫“议题设置”。咪蒙说了什么，大家就说什么，无论支持她还是反对她，都在这话题的这个立场上讨论了。所以，反对者获得了一定关注，但是咪蒙赢得了在传播上最终得不利的控制。因为有了这个控制，人们就不得不承认她会有影响力。而影响力决定了咪蒙会有更多10万上阅读量的文章、更高的广告费以及更多的读者。

现在，还觉得批评能对咪蒙造成任何伤害么？

当大家在讨论咪蒙的“毒鸡汤”的时候，却没有发现她已经建立了自己的正向循环。所有的批评者和指，都变成了她发展壮大的养料。而每一轮的批评，她也会把她送上下一个高峰，因为太多人听她鸡汤有毒之后中的一个想法就是一条武断。所以，咪蒙说要批评她的目的，倒不一定是反话，很可能是她发自内心的真情流露。因为她从千分之一上升到百分之一，还要靠更多人的努力。

好了，现在你觉得你的刀法如何？
