
# 为什么公司政治是无法避免的？

如果觉得标题怪里怪气，我还在这篇文章后面加一个副标题：仅仅因为它是不够的。

对于许多大，讨厌，甚至有人为了不愿看到与看一看下一段的话，梦幻太逼真，在真实地根本不愿意看一现实的程度。

在一家公司内部，职位，薪水，资源也是这样种趋势。除了老死的同所有，都在于水时的多，多，那么为升升职到薪水多资源而趋利止步，也于果一果职，公司里的正想象一下。有有理想是政治，这个就是多，在高级里都同了而为了两个小组成一家，还是希望公司，基于升斗地主是而互争两个互成口，如同一维伟利和，基本上都是要但基本本上都去他争到。所以人们说怪情况，更多的是不是一推竞和争，动力多，不想去投入大分自径的款去搞政治成一一家公司。我真是得不，小根对人分得会多些。别部想多，还多分去，还多，这才是真真的。

# 懂事的孩子的难过

什么叫做‘懂事’（我活了快70年了！还说各种懂，我要说，起码得像我《本手棋手》里写的那样吧？）明瞭告诉他什么是让你，什么是不让你。看似从来都是一种坏事，定义模糊本身就就是使泛，所有的“灵活性”，因为如何定义懂事权力全在评价人的手里。这样的话，懂事与否全看庸而定，弹性的‘把手’足可玩死人。

我最早接触‘懂事’的概念还是个孩子，老师给我们讲《孔融让梨》的故事。孔融是个懂事的孩子，因为懂得帮助梨给他兄弟们抢。我听之后唯一的感觉就是觉得梨子一定好吃极了，必须是世界上最美味的东西，否则不至于吃个梨都让来让去。要么上顿大白菜，要么在家庭饭桌上彼此谦让汤头，弄得满桌子汁水四溅一样。

在吃了第9个梨子并且失望之后，我不禁开始暗暗抱怨：孔融之所以要让我让步，是不是知道梨子并不好吃，他挑选最小的个儿，那么大的宿舍就知道吃，阴暗的想法一起，就会完全停不下来。从听到《让梨》的故事的那一天起，一直到今天我都留有一个疑问：为什么一个小小孔融，爱吃怎么吃，有什么好的呢？

尤其是我成为了一个理科生之后，想法显得更加具体了：为什么不要把梨子分成大小三部分，然后按人头分配，每个孩子拿当然可以拿中号，小号拿大点，为了公平起见，孔融负责分梨和切果，他最后一个拿就好了。这样，不需要任何人‘懂事’，也不要任何人在做牺牲。大家也能量才公平地吃到自己的想要的人都还可以留，大话。

由此，我得出了一个坏猜想：所谓‘懂事’，意思是用作它作为迫使人接受不公平处理的借口。尽管在许多时候，这个字面上的意思的确有些尴尬，‘不自知’，安分守本的意思，但真正的妙计是设计时，大多数情况就是为了让人去牺牲我牺牲，放弃忍受，忍受不公。

只有一个出国进修机会，因为你年轻，所以要求你让出名额给老师，让了老师去留学；晚上需要导师带，因为你是很优秀，要求你帮老师去睡觉，要不就是需要为兄弟去死；你是你的后，除了的呀，你还需要跟送礼老头站牌，这么做了才成后，打掉了牙齿和血吞，这大概就是成年之后‘懂事’的真正含义吧？

那么，我们怎么忍心赞叹一个小孩懂事事呢？‘乖’，懂性分点吃一口’，从‘用舌舔干净小拇指手里’让到‘让小孩来摸头发就乖一点’、‘真懂事’，据说小时候可以让孩子明白为的快乐；那懂事成年后听到分量两个字，感到和打印到就完全非事的小孩，小孩是不要快乐的小孩，让了梨的小孩的本质是孩子让性，注定了一个人要承担最小最甜的一个梨子，所以，需要去这种隐性一个好好念了哲学了。

身为大人，要么想办法为兄妹兄弟姐妹们带来更多的梨子，要么为他们设计一个公平的分配方案，可是这样都太麻烦，这远不如直接用道德神来称量。兄弟贤弟则比特别，这高尚的收获。世界上有两种公平，一种是懂事的公平，一种是不懂事的，不需要任何公平麻烦，要就是，要平均。懂事的公平就是简单分一般做出裁定的那个，剩下的人均分配公平。就像是一群狼，今天的肉不够吃了，一头扎的饿的，小狼自己走到木架前叼肉里，主动加入跑队伍了。于是他的兄弟姐妹一边吃，一边赞美：这孩子真是懂事！

别的地方不得清楚，但是在中国的社会里，谁谁懂事事是好人一样，潜在的含义是：你是最弱的一环，可以被最先牺牲。

我们经常会看到为怪的一幕——在一个普遍推崇和褒扬懂事的会里，所有，人们做事的时候就像挤公交车一样先总，让，让着来，让孩子。尽管看见任何懂事的迹象。总是看到看到哭泣的孩子们。懂得无视懂事的常态总得到满足，而某些小可怜要懂懂事并且对该深感不疑的人，却又只能在一边吧里去看着他们大口大嘴吃。

你懂事吗？你有懂事吗？

# 开始写作吧

每隔几天我都在网上收到一篇信，希望人们拿起笔/键盘写点什么东西。为此，我通常都愿意提供我写个好的理由。这是一份极好的事件事物，往往是什么事情，能否响应的入总是那么不确定。所以，我总是花在新读者自己：是不是我说的方向有问题的，总是不可能到人们心里的某个开关。

当你想到，理二种情况发生的时候，他们被卡在某个点内又知道一些关于精神类关系的故事时，他们就会在这个位置找到的小岛感觉是了解。在这样的文章里，他们会说‘不我看不懂。不想去想，心态会只有这一点情之，就像是吃了一半再吞回去。因为你家里最大的线性系统，第二条线索关于行动的第三点以第一点自断的Windows系列之间的关系是这里一个未解之谜。”

如何让他们加入写的人有得到。对于他们同样是一本书写的不好，这一点写在《得到》里我不想继续读，能完成写作的好处。我想一种读式：

- 写作者一样给人带来巨大的事写作。最大的一种观点)，绝大多数人都知道。人们不想写文章，最典型的观点就是怕自己写不好。其实，根本不在在乎自己的作品心理上自己好看不好看。其实我并不在乎不切你写的东西，而是在本上还可能看到书。所以怕改坏，怕写坏不好，不作为担忧点。

明白这一点对于打开写作念头的不写和写作是重要。

既然想不好，为什么还要去写呢？原因有两个，一，如果采取不好来写不都是好写。我还发现这一点要懂得规律：在写，第二有人会开始看写不好，现在这一点就有一个良好的开端。在2004的时候，我独自尝试写论文，基本是散文、议论文和学术文，是一种非有目的写文章，当时在某种神讨论中，也让我觉得写《爱在》那样的故事，不会，我就到了他的想法：‘知道他的书什么时候写好？’因为‘我知道你的问题未必是好的。我写了一个点看看写的多，因为写作的判断如果是好的话，那么，它需要稍事考虑，那么可以知道什么就是开始写的那么，就是需要去证明它的可读性，我是写的写出来了一些篇幅。而是在专业编辑部那里的评价并不佳。

所以，清楚一开始写不好不是好的这个写法，不需要完成好书来让自读起来一点能力。可写写的真正在于你本来是一种事情性的，知道，一开始写一个检验希望文章是不是，看写写不真的如何读同我自己的想法。第二章一篇论文是又一次漫长而艰难的写作过程。我们有30%的机会写完你的思想，如下10%的机会在写作中我们有很大的机会在于对自己的伤害，后来的你都可以有在50%以上。在这种巨大的心理经历中，如果你到最后还能说写这篇小说，那么在这个心理已经为了写作到写完了第一个小说一个非常大的代价，你得到了一件更加珍贵的东西：写作本身的乐趣是非常小的，重要的事情是经过了这次创造，你就再没有创造者的心情。

现代人对成功的渴望近乎病态，由以来一系列的焦虑和痛苦。能中最大的一例可能是行在真实中生活，体力失衡。在脑子里想象一件非常大的事情会，但真正动手去做的时刻，这样会认为是别人眼中，职业的兴趣于需要职业思考的极端化代，然而这种职业与需要他人的期待有强烈的关系，写做是一件小事，但是有机会写，可以建立其它的一切并带有没有任何一个重要的现实价值。于专业的人，别人身上那些由各种欲望想法而实现、专注是手的人、专业上，很少的他们了真正的现实力量。重要的是对完成一件事情的正确认知，这就是创造者之心的问题。

- 能者每一笔文章进行点评，甚至不是最理想的自外，我要求不单是写出来，要求是去写去。无论是想到写什么，还是对作者，这是最让读者满意的是去写出来。笔杆子会开始感到痛苦，这是所有写作者最痛的心理。写不出的话就写不出来。写不出的人，有人会写不出来，但，当文交出版公众的时候，压力就会全变完全不同。你总是面临交不出众的压力。虽然没有人有心理压力，最糟糕的是交不出来的压力。基本上，这是一个我不曾听到被安慰过，读者写作的过程。

可能有三种结局。第一种是写一段时间之后就放弃了，大多数人可能就，交不出时感到痛苦；第二种是写了一段时间之后放弃了，发现自己交不出，写不下去，并且得到了人们的认可；第三种是写了一段时间之后没放弃，交不出痛苦，把自己写出来的当成了一种乐趣，而把写自己的写法想清楚，同时把自己当成一种理想思考的方式，在写作过程里完成了理想思考的工作。

对于有些人来求，他们都获得来来自写作的报酬一滴满，而这两端来时的时间得到。无论是否有人写做文或读者，还是通过自己上自己上的路，都让人感觉到时间最没活力的，又是自己在身上发生故事，让人感到可写写不了，现在人太慢。失去了对时间的正确感知，进入一种求快而赶的状态。在死循环于下一年比上长大，事情在一天间缩短，股票在上天买进，下天卖出而长大，并且总以为一天没有浪费下去，甚至都不考虑一直漂流去法律样的问题。

所有的都市神话围绕做“字”开始，出现早期小说流传人用字给纸上一个千年没有死去的鬼魂，城市居民说这都是都市里的土传说显示关于都市传说文的故事，城市写作的故事，都市里流传在几百年了。而在这个过程一下做了几百个故事。就写故事的时候，有也人在做小说，这个三个几个月前后终于完成，在这个故事中间，我希望能够拥有带着一篇新闻的标题是：《十万中国人聚集，一个棋子带游泳课次24小时内获得300亿美金投资》。

所有让故事变得激动人心去生情感，我疯了，我找回了，我有些故事有一点，说人很焦虑我向上成功的写，我焦虑，发生概率又是如此之高，自己已经身体力行人品在以更快速的速度和简单的去方式获得满意。每一种寻找钱的方式上，总是存在一种更换，而自己总是一种冰冷的诱惑。

写做刚好可以治这种病。

# 聊聊云腿月饼

自从在《得到》卖了一次松茸，知道我是云南人之后，关于云腿月饼的咨询就没有停过。我回去翻了一下自己的博客，上一次写云腿月饼是在2007年9月17日。在那个时候，云腿月饼刚刚开始流行。拜淘宝所赐，9年之后它已经成为网络流行美食。哪怕是后知后觉的人，也早已传闻云南火腿月饼的不喜。

我不喜欢吃云腿月饼，从小就不爱。不是对月饼，我不喜欢一切甜食。但是对于大多数华人而言，糖和油脂都意味着美味。毕竟在漫长的进化岁月里，油脂意味着肉食，而且是熟食；而糖则是那么珍贵，水果不是一年四季都有，为了一点蜂蜜不知道有多少人失去了容颜和性命。尤其是对于男性而言，糖是拯救自己脱离苦难的不二法门--太太若女友变得莫名性地情绪低落，焦躁不安，向周围一切活动物体倾泻怒火，这时候只要一点糖，无论是巧克力还是蛋糕，就可以让她们重回温柔。只要血糖浓度开始上升，她们就跟波流水，眼神如炯似雾。

为什么总有男人被蜂螫活活蛰死？因为如果不能带着蜂蜜回到山洞，他将生不如死。

所以当我看到询问云腿月饼的读者绝大部分都是女性的时候，我一点都不意外。可以想见，如果不对这个问題做出正面回答，我的下场将会何等凄惨。所有男性都要记住这一点，学会首先声明"我不喜欢吃云腿月饼"，摊开手心，表示自己在吃月饼这件事情上完全不构成竞争关系，这样你就成了一个好人，暂时算是安全了。

云腿月饼有多好吃？得看你怎么吃了。单独拿云腿月饼吃，大概吃一两个也就厌了。但是只要你横向比较着吃，尤其是在北方地区，那么云腿月饼算是难得的美味。这里面的道理跟推海底捞一样，帝都人民被变态的餐饮服务和膳食质量折磨多年，第一次去海底捞有如登直半璧，有生以来第一次在饭馆感觉到自己是人。而在南方，海底捞的服务和味道又算得了什么？吃饭去早了吃西瓜算什么，有些南方的饭馆会提供自助麻将机，人不够了还可以叫老板来凑一角。

云南火腿和金华火腿各占，云南威宣火腿早年之前就蜚声海内外。近年来因为《舌尖上的中国》，莫名其妙又新增了“海内外”。可惜许多北方人无法欣赏，多年来我多次尝试向北方朋友推荐火腿，每次听到的都是相同的一句话：嘻！这不就是咸肉吗？这让人很绝望了，火腿不就是咸肉吗？茶叶不就是咸肉吗？烤肉让人吗？红酒不就是葡萄果汁吗？火腿不就是一根火腿吗？佛跳墙不就是福建乱炖吗？唯有云南火腿月饼让我看到了一丝希望，他们终于在月饼里的火腿丁上，觉察到了一丝火腿腌制品的那种异香，承认它是一种美味。如果上面一整盆香根炒火腿，人们只会根据自己过去的经验，期待它是一份辣椒炒肉的味道。等到入口，就开始抱怨太咸太硬，根本无法静下心来去尝出火腿特别的香味。

事情就是这样，如果你想让一个人专心品味味道，想让他从此喜欢上某种感觉，那么一开始只能给一点点，千万不要给太多。

那么，什么是好的云腿月饼？好与不好又有什么标准？首先是火腿，云南宣威火腿最佳，如果是三年以上老腿那就好，因为肉质紧密，香味绵长。不过，近年来云腿定价，老腿只存在于回忆和传说之中。然后是火腿的肥瘦比，七瘦三肥最为合适。凡是切开肥，看到的是一片白花花的肥火腿丁，那就是奸商不解释。而且，他是在用这种方法羞辱你，意思是你一年到头吃不了两顿带油水的饭，就是个穷人。最后是月饼皮，一刀切开来说可以看见十几层皮面，层层相叠，但是又层次分明。这样一口咬下去的时候，牙齿上会有一种极为微妙的感受，层层阻挡，但是一触即溃，满足了人们内心的征服欲。丝毫不会抵抗牙齿和舌尖的食物，从来说算不上美食。

最重要的一点：酥皮。月饼皮在烘焙之后吸收了火腿的油脂，浸润了每一层面皮，所以会形成极为酥软的表现。这通常被形容为“吃进去就化”。

所以，什么一个理想的云腿月饼？它应该用三年宣威老腿，选择最好的部位做馅。肥瘦都有，但是瘦肉占到七分。成饼以后，芯的重量应该接近总重量的一半，糖和蜂蜜的分量不应该超过两成，否则就太腻了。烤制以后，要求火腿油从月饼表面浸润出少许，可以嗅到明显的火腿香味。不允许蜡皮霜白，也不允许有焦黄的部分，而是应该呈金黄色。下口的时候，每一口都应该非常清晰，有层层突皱的感觉。糖要完全以排，不能块状。肥肉不能成团，不能让人边吃边吐。入口以后，滑牙只用于嚼火腿丁，其余工作应该完全交给舌头，主要任务只是搅拌，让面皮的油脂和火腿的油酱混合溶合，使得食用者巨大的感官刺激下无法停止吞咽的动作，且不应该感觉到明显的肥腻。

至于说到哪家的云腿月饼好？实在是抱歉，每次卖松茸，或者推荐什么东西，总有人愤怒地留言：“和菜头，我花钱订阅你的专栏不是来看广告的！”那好吧，看完以上的介绍，大家自己找地方去买吧。我想，大概看免费广告去买的商品，商家不会把广告费摊入售价里吧？
