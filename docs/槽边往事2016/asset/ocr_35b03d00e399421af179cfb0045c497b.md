# 你家客厅正中是什么

搜狗拼音输入法之父马占凯经常抱怨说：“为什么我和别人一样聪明，却并没有成为第一流的人才？”我觉得这是他的自谦之辞，作为亿级用户的产品经理，他这样的人在中国屈指可数。不过我明白他的意思，他认为自己的智商和他所倾慕的一流人才中没有区别，但总感觉自己哪里差了口气，没有在竞争中获得相同的成绩，比如说：没有考上北大或者清华。

后来他告诉我说，他把自己的成长环境和自身禀素质做了非常细致的分项，然后和其它人做了对比——有时候真的很难理解工科学生，虽然我也是一一最终，他终于找到了妨碍自己成为一流人才的根本原因：小时候，家里没有书柜，也没有可以阅读的图书。马占凯说，空有智商和课本，而没有图书可以开拓视野、启迪思考，这就造成了他和其他人之间的差距。

我觉得马占凯在一定程度上是对的，这么多年来因为写字的缘故，经常有读者留言问我：

+   *   孩子不爱学习怎么办？
*   孩子不喜欢阅读怎么办？
*   孩子写不好作文怎么办？
*   孩子懒得动脑懒得思考怎么办？
*   我一看书就犯困怎么办？
*   如何提高阅读能力？
*   如何培养自己对学习的兴趣？

我在回答的时候很喜欢反问一个问题：那么，你们家有书柜么？如果回答有，我还会追问一句：是书多，还是杂志多？如果回答书多，那么还有最后一问：是专业书多，还是闲书多？这一套龙头追命三问下来，能通过的人不超过5%。

因为相当数量的家庭里根本没有书柜，甚至简单的书架都没有。对外宣称有书的时候，事实上指的是各种报刊杂志。排除了杂志之后，又大多是考级考证书用的专业书，或者菜谱、流年算命、养生偏方、励志文学、名人传记、炒股秘笈、工具手册一类的“实用类”书籍。

那么，十年前你下班就爱躺在沙发上看电视，或者叫一群人客厅里打麻将，希望孩子把这一切看在眼里，却不想跟你一起看电视、扔骰子，而是默默转身去认真学习、主动阅读，你不觉得这种想法很怪吗？十年后你下班就爱躺在沙发上刷微博、刷朋友圈、美颜自拍发雪格，追星造谣追同人，希望孩子把这一切看在眼里，却不想和你一样玩手机玩iPad，而是拿起一本《世界美术史二十讲》来看，你不觉得这种想法很诡异吗？

要孩子真那做了，你觉得那真是你亲生的？就不担心心曲墨附灰一类的事情？

其实，我要给出的答案很简单：你如果在家里每天都要阅读，那么你的孩子自然会阅读；你如果在家里每天都要学习一个钟点，那么你的孩子自然会学习；你如果每天在家里和孩子找个话题辩论半小时，那么你的孩子自然会思考。小孩子就跟猴子一样，你做什么，他们跟着做什么。三五下来，一个人中的习惯也就自然形成了。但那些向我提问的人里，有几个不是把电视机、手机、iPad当作是保姆，只求孩子别烦自己，待在一边安安静看看、玩着就好？那么，你怎么会希望你的孩子过上你自己根本不过的生活？拥有你自己都没有的生活方式？

是的，别人家父母自不识丁打麻将喝大酒玩手机，孩子照样考上了北大清华哈佛耶鲁。不过，那是别家孩子，不是什么？世界上的确有天才，但是刚好落在你家的概率并不大。
