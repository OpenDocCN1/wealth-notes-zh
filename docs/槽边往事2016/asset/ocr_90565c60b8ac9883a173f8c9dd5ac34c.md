# 重读《傅雷家书》一和菜头

我家有一本《傅雷家书》，一连搁了5次家都还在。每年春节期间，我都会找出来重新翻阅一下。从傅雷先生孩提时代这些信的年代开始读这本书，一直到傅雷先生写这些信的年代重读，每一次的感受都不一样。其中，有一些内容我们几乎都能背下来。所以，有人在语言问答里向我问推荐标准的问题，我不假思索地就引入到《傅雷家书》里的内容。在《傅雷家书》出版了三十五年之后，傅雷先生的想法依然能够带给我们启发，这就是一本书的标准——和时间之流抗衡，并且坚强地留存下来。

傅雷先生在1966年9月3日不幸辞世，到今年9月3日刚好是五十周年。《傅雷家书》在1981年首次印刷出版，到今年是三十周年。也就是说，到了今年的9月3日，傅雷先生逝世五十周年的时候，根据著作权相关法律，《傅雷家书》会失去版权保护成为一本公版书，所有出版商都可以出版这本，每家出版社也许在一夜之间就会看到不同的版本。届时，各家出版社为了重新建立版权保护，会往自己的版本里添加各种手稿照片，增补信件内容，宣称只有自社这里才有最完整的版本。

但这一切根本都不重要。

重点是你应该去买一本，从头到尾通读一遍，然后我们可以一起讨论一下这本书。

哪怕读不完也不要紧，我希望你能拿起这本书，感受一下它的厚度和重量。如果里面有手写的图片，我希望你能仔细看看傅雷先生的手写字体，是怎么做的？因为这太像极了《傅雷家书》在我们这个时代里加大功用提醒我们父母和孩子之间的联系。我们看到太多父母，给予孩子的是一部手机，或者是一部iPad，与机器程序和解决方案任何问题孩子的问题。我也见过太多父母，他们对于子女的美育是微信“叮”的一声，为过去一篇类纸（避免肥胖等吃七种水果就够了）这样的文章。

我的意见并不是每家父母必须尝试书信手作，而是希望大家体会一下在这些年书信面疏远的时间和精力。在所有的人际关系里，需要的都不是效率，而是投入的时间。哪怕父母和子女的关系，同样需要大量的时间。而不是由移动设备构成的铁丝网，以及APP和机制保持的同步通知和已读状态来解决的家庭问题。工具是一无所有的，它唯一的功效是谋杀那些本身并没有多少价值的时间。而时间的价值，需要使用者去赋予意义。

在这个时代里，我们经常听说“陪伴”这个词。个人觉得这是一个相当糟糕的说法，因为它是描述的状态，是外部，却根本没有实质性的内容。陪伴什么？如何陪伴？陪伴所消耗的部分才构成真正的陪伴，但人们都只有在无意或故意回避这种现实，陪伴缺乏一些视角，一起去探索，或者是一起读一本书，并不是单纯地为了在一起消磨时光。陪伴孩子是向它为其展示世界，成为其美世界，成为其美世界，自由向 其展示世界，成为其美世界，成为其美世界，自由向 程，以及打开这个世界的钥匙，这才是陪伴的应有之意。

《傅雷家书》的珍异并不在于傅雷先生的蝇头小楷，也不在于他写了多少万字的书信。而是他透过书信的方式，不断地告诉孩子美是什么，人生是什么，什么样的人值得追求，什么样的人值得追去。在今天这个时代里，未必需要书信这种古老的载体。更可怕的是现实是：不单单没有了，连读书信旧那些和孩子之间认真严肃的讨论也没有了。我不相信今天的父母还有那种底气，可以直视着孩子的眼睛告诉他：孩子，这是一种美。

在另外一方面，许多人家把《傅雷家书》当作是《曾国藩家书》一样，买来在书房把把端为洞见而理解。所以我们推荐重读《傅雷家书》，是因为这本书在今天同样需要以崭新的审视。如果你认真读过《傅雷家书》，那么你应该像我一样承认一点，对于傅雷们可一点都不轻松。傅雷的一个个性之险言深，对于其子而言可以用刺骨形容。他们那个代父母，对于自己子女的态度，犹如造物主对待造物神。傅聪作为世界级钢琴家所赢，赢得了声家、财富和长寿，但是他也知道，你是否愿意去过上这样的童年呢？试着在傅雷暴风骤雨式的体罚下学习一下时间钢琴？

《傅雷家书》里不会告诉我们，傅雷先生的次子傅敏也想学琴。但是傅雷先生认为他初中才开始学，起步太晚；同时，家里没有钱再养第二个音乐家。因此非常坚决地拒绝了傅敏的要求，直接告诉他：你更适合教书。于是，傅敏走上了另外一条人生道路，最后在高教级英语教师任上退休。而在很多年后，身为钢琴家的傅聪先生承认，和傅雷相比，弟弟的手更宽更大，更适合去学钢琴。傅雷先生作为家长的决断，对两个孩子来说，当真算得上是公平么？身为父母，如此深入地干涉孩子的人生，如诸葛诸之子一样操弄两个小孩子的命运，我真说不上这是对还是错。

通读整部《傅雷家书》，你可以发现一个酷烈的父亲在孩子远离自己之后，你看得见如关切之文，几乎是在用乞讨的方式渴望博得孩子的一点回应。这种情绪如此强烈，以至于傅雷千言万语，事无巨细，千叮万嘱，连如何穿衣吃饭都要过问，这是一个唠叨的老父亲。事实和慈心从来都是一枚硬币的一体两面，在《傅雷家书》里看到傅雷有多么慈爱，在过去就有多么残酷。所以，不禁要问一句：傅雷先生是一名成功的父亲么？他家的父子关系是一种值得称颂或者赞许的关系么？或者我们可以继续追问一句：傅雷先生的父子相处方式，还有多少适合今天？又有多少需要扬弃？

在读书这件事上，往往存在两种感受。一种是在有好书但是缺钱错过，另一种是读好书却没有思想。我相信在今年9月份之后，《傅雷家书》会频繁地见到这两个问题。即便成为公版书，还是有很多当量的不会去卖书，买书也不会去读；读的人不容易指望思想完全盘接受，沿袭傅雷的家长作风，还把这当作是家教和家风的一部分。于是，在这个世界总有一部分小孩子在接受手机、iPad的放养之亲，也总有另外一部分小孩子在遭受家长铁腕的割爱。

所以，各位，我只能写读《傅雷家书》，拜托作为家长，即将傅家家长的角色，认真阅读一些文章。傅雷先生说过，在能够成人之后，他为自己终于和儿子成为朋友关系而感到高兴。我知道，在一个中国式家庭里，父子是母子活子的代称，要么是权威要么是代付之后权力，孩子总是被活子的代称要么是权威要么是代付之后权力。想要一开始就能和孩子建立起对等的关系，彼此尊重，并非人亦能办到。那么不妨当作教材，把《傅雷家书》里的那种亦师亦友的父亲关系当作参照来读，那么，也许你才是傅雷先生当初写信时真正的想法——一起在铅笔下，他是一名合格的慈父。
