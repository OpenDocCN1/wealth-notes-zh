# 三叔十年

南派三叔是徐磊的笔名，他用这个笔名写过许多作品，其中 最著名的是《盗墓笔记》。

十年零六天之前的2006年6月26日，南派三叔开始在网上贴《盗墓笔记》的内容。在此后的八年里，他写了九本《盗墓 笔记》系列小说，总销量超过一千两百万册，是名副其实 的超级畅销书作家。今年8月5日，《盗墓笔记》电影正式上 映。这样，南派三叔就完成了所有通俗作家的全部梦想：写 一本畅销书、收税税买房买房子、作品改编为电影。

严格算起来，南派三叔并不是传统作家，他的作品也不属于 严肃文学。也正因为如此，他的作品虽然脸炙人口，但是许多 人却羞于公开承认是他的读者，也不敢公然夸赞他的作品。 幸好我是他的朋友，可以完全不用顾虑客观公正，可以 彻底站在纯粹私人的立场上，当众讲几句不公道的话。如 此，这个世界上大概会多出一点公道来。

我看严肃文学作品，也看网络文学作品。承认前者，会让人 觉得我有文化一事上是的确如此，多年来我有过许多书 证，于是变成了许多人心目中的文化人，经常需要求帮忙 给小孩取名或者给新居起名；承认后者，会让许多人对我 失望，认为我的品位很低。但是，一时之间又找不到比我 有证的人，所以只能痛苦地装作没看见。或者自我宽慰说：菜 头只是想打发一下时间，何况这个人经常性地掉风。

不，我现在就可以明确地说：我更喜欢网络文学作品。原因 之一是网络文学比严肃文学更有活力，进化速度更快，变化 更为丰富。许多人一谈起网络文学，就会皱着嘴说“太多垃圾”。这个判断是对的，然而对于创意产业来说，有足够多 的垃圾其实是好事。创造永远是残酷的金字塔结构，大多数 创造者在金字塔的底部做无用功，无声无息地生产垃圾，然 后无声无息地消失。只有少部分人可以上升到金字塔的顶 端，创造出光彩夺目的作品，并且为世人所见。

垃圾越多，说明金字塔底座越庞大，参与创造的人越多，竞 争也越残酷，于是塔尖越可能越高。如果你在北京呆过一 段时间，流连于各处小剧场，那你会发现绝大多数的新创都 乏善可陈。如果你在798艺术区里消磨过几个下午，那么 你会发现大部分展出既无艺术，也无趣味。最棒的戏剧 总是出自北京，南下可以横扫全国各个行业。最棒的当代艺 术家同样都是北京，他们的作品经常超乎想象，给人以新的 启发。没有一个人可以直接在虚空中建造金字塔尖，所以，我们 没有必要看一眼金字塔底座就彻底放弃。

第二个原因是网络文学是自己的审美。在我们之前，没有 网络，也没有网络社会，更没 有所谓网民。等这一切出现 了，网络文学是专门为了这一批人而创造出来的内容。茅盾文 学奖不需要有专门的审美偏好，评选出来大家去接受就好了 。《十月》、《收获》上发表什么内容，是编辑们决定的 事情，印出来大家去买就好了。这不是单纯的被动，而是自 上而下灌输审美标准。也就是说，十几个人的一审 委会或者编委会，就决定了你读什么，决定了什么值得看。这不是 人多少的问题，而是你根本没有选择的余地。

但你可以从几十万字网络作家和数百万部网络作品中选择你 喜欢的题材，不仅如此，因为你的喜欢会促进同一类题材作品 的出现，彼此残酷竞争，最后能进入你视野中的，一定是这 个分类题材下最强的作者和最强的作品，就像是盗墓题材最 终出现在你眼前的是南派三叔的《盗墓笔记》和天下霸唱 的《鬼吹灯》。不要小“看”我喜欢”三个字，因为这三个字代表 了一种新的个人审美。

用什么方式讲故事，用什么方式塑造人物，用什么方式表现 人和人之间的情感？你喜欢什么方式和不喜欢什么方式之 间，就是你的审美上做的取舍。就我而言，我最喜欢同样 在网络上的作家、与友友创作的作品。因为他们的方式，更 容易让我产生自己的共鸣。

南派三叔在网上写了十年时间，除了《盗墓笔记》系列，还 有《藏海花》、《沙海》系列，直到今天都没有停笔，还在 他的微信公众号里更新短篇。很少有传统作家能够做到这种 程度，让自己的作品伴随着读者一起成长，成为他们生命中 一部分。经典著作属于过去，属于死去了的世界，是一张缓慢 变化的列表。我们自已是否还能活在当下，并不知道南派三叔 还会写出怎样的作品，是否能突破自己进入新的境界？也不 知道他的作品未来在时光之流的冲刷下，是否有可能进入经 典的行列？但这些都不重要，重要的是我们正在目睹变化， 而且身在同样的变化之中。

要知道，所有的经典在最早，都不是为了成为经典而写成 的。大师们当初只是想要讲一个好故事，用和别人不一样的 方式，得到比别人更多的掌声。

# 和菜头

> 请你相信我：
我所说的每一句话，
都是对的。

捍卫你的头脑，从捍卫你的审美开始。
