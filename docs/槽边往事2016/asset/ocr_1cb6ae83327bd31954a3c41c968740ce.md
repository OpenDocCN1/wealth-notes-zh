# 写在20000人订阅达成

昨天，我在《得到》的专栏《槽边往事》在历经半年之后，终于达到了20000订阅。说不花第一时间在微信上发条祝贺，这让我感到非常惭愧。李笑来开设专栏的时间比我晚得多，但是已经接近100000订阅，剑数有了，是十为，和我几乎同期的樊登，也已经达到28000订阅。所以，当说不花祝贺我的时候，我还是挺不好意思的。罗振宇一次在节目中推荐，说不花一次在演讲中宣传，但他推荐我文章并没有那么大吸引力，颇有一种牵责他人好意的感觉。

到这一篇专栏为止，我已经在《得到》写了100篇文章。按照此前的约定，大概远不需要到明年6月份，我就应当完成156篇专栏的定额。相比较而言，我在自己的微信公众号写了4年时间，不过是740篇文章而已。在《得到》半年的时间，写作的速度已经超过了微信。

相对《得到》的专栏，《槽边往事》没有主题，又没有实用价值，能获得20000订阅其实已经非常不容易了。罗振宇在介绍我的时候说，我负责人生另外一种可能性，负责人生另外一条道路上的风景。心灵鸡汤里总是告诉我们，要坚持自我，要遵循内心心的指引，努力活出用自己的自人生。那么，我的价值观是用自己亲自服一碗鸡汤汤作为代价，告诉大家坚持自我会有怎样的代价，做一个有趣的人会有怎样的结果。也能够让人们更加清晰地看到，无论言场上如何表述，人们的真实选择会是什么，生活的真实又是怎样的面目。

你是否记得前阵子网上关于《有趣才是人生最好的春药》的大讨论？我当时的观点都在自己文章中的有趣。有有趣是人生最后的春药）。在有趣和有用性之间，人们大多数只会果断选择后者。这就是为什么新华书店里销量最高的是教辅和工具书，《槽边往事》这样的书如果不是罗辑思维在自己的平台上专栏半年，大概连放到柜台倒数第二层的机会都没有。这是我很早就知道的人生真相——同样的智力与同样的付出，在另一条路上能获得的更多，但是，我还是任性选择了自己这一条。的确很难很多，可我乐意。

开设这个专栏的第一个月里，在我内心中也有几个刻那充满了犹豫。我上网写字以来，还是第一次特意希望读者没有看到读者有读，认为写的文章里“没什花用”。有读者甚至直接说“简直不知道你整天在写些什么”。我当然知道要扭转这样的局面需要做些什么，这么多年在上写文字，我尝试过除小说之外的所有文体，在无数次实验中我知道人们喜欢什么，认为什么才是有价值的文字。对于我这样的写作者，想要讨好读者简直是再容易不过的事情了。

而且，《得到》这样的平台，大概是最近五年里，网络写作者们最大的一次机会了。在这个短暂的窗口期里，写作一年所能达到的社会名望和经济收入，大概是以前二十年的总和。你有些犹豫：那么年性下去？和菜头，你是不是不想那么任性下去？你就做出一点点改变怎么了？那样的事情对你来说，根本就不是什么困难的事。认进过人生和的真相之后，做一点人认识这根本不是问题，那是一种男人的成熟。

这种摇摆的念头我很快就打消了。在过去的十多年里，它的声音不止一次在我耳边低鸣，劝说我换一种人生态度，换一条人生道路。可每次我停下来，扪问自己一个问题之后，就还是走回了老路上。“我之前所做的的一切，究竟是为了什么？”，每次只要认真发问，答案从来都清晰无比。我当然在变，多年来我从技术官僚做到管理人员，的确不是很困难，而且前途光明。我在《南方都市报》开专栏，一整年的时间围绕一本《梁静真传》写52篇文章，到今天都还有人对那些文章念念不忘。但我不想吃，我在里面感觉不到任何快乐。相反的，它们带给我的诸多束缚却让我时时感到痛苦。

《得到》平台给我带来前所未有的媒体曝光，也带来了写作以来最高的收益。扪心自问，之所以罗振宇、说不花会邀请我开通专栏，原因就是我足够花会，也坚持了足够长的时间。如果我一早就“成熟”了，熟练地妥协，退让，用文字技巧取悦读者，那么也会有今天的例子。人不是一天之内成为自己现在这个样子，使自己成为自己的那种力量，可能是人生中最强大的支持。如果抛弃这种力量，就像是盐失去了咸味，彩虹失去了颜色，我不再是我自己，也变得毫无价值。更何沉，要妥协要退让要求变，我早就那么做了，又何必等到今天呢？

所以在现实生活中，柜子上只有很少的基本书，房间里只有很少的一点物品，和我交往的只有很少的几个朋友也是我的天性，所以，我大概永远也不可能成为你的好朋友南派三叔那样的人，会有数千万的读者喜欢自己的作品。我永远只能写主题无法确定的文章，用下笔之前完全不知道写成什么样子的工作方式创作，我也永远只能拥有人群中很少的一群人为读者。因为想要欣赏我的文章，乃至欣赏我这个人的读者，需要极大的耐心和勇气——和他们自己也不会有那么多人。

所以，当我看到订阅数达到20000的时候，作为一个乐观的悲观主义者，再一次觉得这个世界其实很美好。在人生的每一条道路上，原来都有那么多的人。

谢谢你们！

> 和菜头
