# 悼张锐

春雨医生的创始人张锐因为突发心脏病于10月6日辞世。看到这条新闻的时候很震撼。翻开他的电话号码，他的名字还在，最早的电话号码上标注着“网易副总编辑”。但我知道，无论哪个号码拨过去，都不会是他接电话了。

我和张锐见过几面，在iPhone4刚刚问世的时代里，他就在大推推广自己的移动互联网医疗理念。老实地说，我很排斥互联网。因为他每次都能滔滔不绝地和你说上一个小时，目光灼灼直视着你，试图说服你入伙一起干。有一次我们是在武汉珞珈山相见，那是一次会议的间隙。他一把将我拽来，我们顶着接近40度地高温，站在树荫下挥汗如雨，看他烟不离手，听他讲他的项目。

面对一个充满热忱，对自己的理想坚信不疑的人，每拒绝一次都会增加一点心理负担。而且，每次找个理由，又会开启新一轮的辩论。所以，后来的见面机会就渐渐少了。偶尔听到他的消息，知道他还在创业，公司还在继续运营，也就放心下来，不再自己拒绝他的邀约而感到愧疚。如今也过去了5年，想必到了那里的人再捣点什么事，说不定连大天使长也被他的三寸不烂之舌说服了凡心，挽起袖子加入他的新项目。

因为张锐移动互联网创业者的身份，他的离世又引发了新的一轮互联网企业加班文化大讨论。对互联网人来说，这并不公平，也显得有些轻率。每年都有互联网从业者猝死，每次都能引起人们的关注，只不过是因为互联网人控制了互联网媒体。煤矿的矿工每年都有猝死，却不能成为一个讨论的话题，只不过是因为煤矿没有什么大型媒体。在猝死和互联网加班文化之间建立因果关联，需要更为严谨的论证，因为这隐含对猝死罪犯的指控。当然，也隐含着对创业者的鄙薄，仿佛创业者除了透支健康换取事业成功之外，他们的努力，他们的头脑，他们的判断力和执行力都不值一提一样。

从张锐的身份开始谈创业者的悲情，也让我觉得非常不舒服。创业的确孤独，创业也的确艰难，但这些都和死亡无关。如果创业者是在做一件自己认为正确的事情，那么无论有没有同行者做注，都不会影响到自己所作所为的价值。张锐的探索原是一件令人悲伤的事情，它不应该被幸存者身上的勋章，拿去给创业者事涂抹一层悲伤的色彩。如果大当创始成就和死亡相互牵连，那么可以现在就退出。任何投资人，任何员工，任何用户大概都有侧隐之心，不需要创业者用自己的生命换取企业的成功。死者已矣，人们理应得到永恒的安息，而不应该被他人惊扰。世上有哪一种行业，有了鲜花、掌声、闪光灯还嫌不足，还需要亡灵来装点呢？

在我看来，张锐度过了一辈幸福的一生。他想念书，就上了大学；他想做媒体，就进了网易，而且升到副总编；他想创业，就创建了春雨医生。在这个世上，有多少人能够像他一样能够选择人生？又有多少人能够尊重自己的意愿变成现实？大多数人只是空有想法，却永远没有把想法变成实现的一天。张锐看着春雨医生从无到有，从一个想法变成一家实际运营的企业。即便生命在寻找赢利和奔波，为了上市而筹谋，那一步是幸福的烦恼而已。在抵达他这一步之前，有多少企业已经无声无息地消失，有多少初创者已经黯然失色地退场？

只是死来得太突然了一点，张锐的一切个人努力在瞬间蒸发而止。每次想起他来，想起他热情和急切的语调，想起他指间永远燃着的香烟，就像想起短跑运动员在跑道上起身，绷紧肌肉，准备一跃而起。想到这样一个人从此消失，再也看不到他急躁前赴的样子，就让我觉得无限伤感。这瞬间的印象在我脑海里就会再凝固，不会再有新的信息，也就不会再有变化，自然也就不会有失败——永远走在路上。

在他探索过的那片黑暗海面上，张锐用春雨医生给出了他的解答。正如丁香医生、杏仁医生等等互联网企业现在正在做的那样，没有人知道移动医疗领的全貌是什么样子，也没有人知道可能的方向究竟在哪里。无论是在线咨询，还是线上转线下诊所，还是走起联合医药的老路，一群人都在尝试。张锐照亮了他前行的方向，也为同样后来者驱除了一片黑暗。如果要问他所做的一切有什么意义：探索本身就是意义。张锐的探索从10月6日之后就已经停止，但是会有更多人继续前行，直到找到释放出移动互联网在医疗领域内全部能量的那个点。

这是我的观点，不过这一次，张锐不能再和我辩论了。
