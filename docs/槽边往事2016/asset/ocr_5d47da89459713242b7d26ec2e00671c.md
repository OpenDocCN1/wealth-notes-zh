# 关于听话的三道墙

因为从“这个字读不太懂，所以人们用柔和的“听话”替代。

“听话”比“逆反”好听多了。大人们一开口说：孩子去听话，乖。

4岁的时候，我站在小广场，小姨领着玩热的椰子丸子。我拿着一只，她拿着一只。我不听她的，于是从一头飞到另外一头。

我7岁的时候，父亲去部队当兵。母亲带着我去了外祖母家。

2000年后的春节... 在机场我见到了一只鸟...

我的人生中关于听话的第二道墙，引入... 就是要求我按部就班地去完成工作...

1998年，我毕业之后上了大学... 在波士顿学习... 在一家公司里... 在改变世界的人...

他们给我提了... 你听我的吧... 听话的人... 听话的人都是好样的...

这道就是人生中关于听话的第三道墙... 我听了... 我变了... 我失去了...
