# # 《巨婴国》读后

在任何一个时代里，总有人试图找出“我们何以如此”的答案，找寻驱动亿万民众形成一个社会、一个国家乃至一个文明的潜在力量。所以每过一段时间，就会有一本所谓“分析国民性”的书籍问世。今年，这本书就是心理学家武志红的《巨婴国》。

不要被《巨婴国》长达500页的篇幅所震慑，相信我，除非是心理学专业书籍，否则心理学家专家谈社会问题的时候，无论再长的篇幅你都不用担忧，因为里面会有相当一部分的内容是具体案例，你完全可以毫无忧地当作故事来看。坦白说，我甚至不觉得《巨婴国》和心理学有多大关系，它更像是武志红借用心理分析的壳，灌进他对中国人的私人理解，完全是一种方便法门。

台湾作家柏杨做过类似的事情，一本《丑陋的中国人》引起两岸三地的轩然大波，作者本人因此蒙受了骂名。从那时候开始，中国作家就学会了一件事情：不要直接批评国民，尤其不要带上形容词批评。武志红的观点其实一句话就能说清楚：大多数的国民其心理状态和婴儿没有任何区别，这是一个由长不大的婴儿们组成的社会，这是一个由渴望爱和关注的巨大婴儿们组成的国家。但武志红不指着鼻子说《巨婴中国人》，而是虚指一下《巨婴国》，这样显得比较有礼貌，自己也就相对安全一些。

你看，文学家的工作就是一次换一种表达方式，重新把相同问题用自己的方式表达一遍。《巨婴国》说的是个老问题：为什么中国人缺乏个性，在人际关系中总是体现出更多的自我奴性？同时，也提出了一个新问题：为什么总有那么多中国人自我认知失调？用大白话翻译过来就是：

+   1. 天下为何有如此之多的贱婢？
2. 为何我竟为贱婢所困？

武志红的回答是：皇上，因为您也是一头贱婢呀！在我看来，这两个问题其实是一个问题。说中国人缺乏个性这件事已经说了许多年，现在中国人终于试着表现出一点个性来，因为缺乏经验的缘故，这种个性表达往往显得可笑。武志红换了一种说法，认为这些都是巨婴的不同症状而已，本质都是心理不成熟。至于为什么不成熟，他那里并没有答案，或许是他根本不关心。他所关心的是分析巨婴的种种症状，然后给出一些个人建议。

说到这里，我觉得你应该明白了——武志红所用的那一套心理学分析方法，大概是做不得准的。他自己建立的那一套心理学框架，试图把大多数国民的行为塞进去，也不见得是合理的。这只是一种权宜之计，目的只是为了方便他讲道理。去掉他整套心理学的说辞，你会发现《巨婴国》里描写的社会现象是真实广泛存在的，因此引发的共鸣也是真实不虚的。一定程度上，顺着他“巨婴”的设定，能够帮助你理解一些日常生活中的困惑，尤其是发生在爱人亲友之间那些重复而毫无必要的苦楚。

问题始终在那个地方，武志红提出“巨婴”这个概念，依然是一个比喻。比喻能降低问题的难度，但是便于我们去理解。同时，比喻在传播上更有生命力。一个生动的字眼比一套复杂的理念更容易传播，也更容易引发人们的关注。更重要的是，一旦“巨婴”这个字眼被广泛接受，那么，它就会作为一个术语出现在我们的生活之中。当我们再去讨论的时候，这两个字能帮我们节省不少论述的时间，也更容易达成共识。

最后，我这里有一个完全不用比喻的说法，不知道你能否理解：对于孩子拥有无限权力和义务的父母，会养出永远无法长大、永远不愿负伤、永远情绪激烈的孩子；政府和民众也是同理。
