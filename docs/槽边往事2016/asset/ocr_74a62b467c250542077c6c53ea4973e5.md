# 坦坦荡荡聊聊钱

从我1999年混BBS开始，人们就已经开始讨论创作换钱的事情。但是藏着掖着，说起Qian, Q-i-an，钱，都会很不好意思。写作者不禁瞪个字，仿佛它就是肤浅地，那个名字是了不得的禁忌。文字和知识分文于谈钱，这是多么怪异景象，仿佛平日里吃的米面是 用内力或者霸水换米的一样。算了罢，让我和你说说大白话好了：

在没有「得到」之前，文章变成钱只有两种可能：

+   1、读者赞助；
2、做广告。

我的微信公众号每篇文章都有许多赞赏，原因不是我可爱，只不过是是因为我和传统的文人和知识分子不同，会直接在文章里告诉读者应该对我的创作付费。同时，也归功于我在评论区残酷地拉黑读者，凡是没有赞赏过一次却还要对我唧唧歪歪的家伙，一概当众拖进黑名单一了百了。

我几乎没有做过广告。不是我不爱钱，而是广告投放有碍我的原则。在十多年的上网历程里，我不是没有推荐过产品和服务，但我始终把握一点：我亲自使用过，而且觉得不错。或者，这是我朋友家的产品，有朋友用我的全部信誉做背书。否则，我写一百篇文章积累下来的信用，可能一次广告就能消耗殆尽。当我成为商人的朋友，一切狗屁倒灶的事情都可能发生。读者是我的朋友，绝对不应该成为消耗品。这个道理，我很早就懂。

所以，在很长一段时间里，我个人一直在呼吁微信公众 号应该收费订阅。不单是收费订阅，而且应该强制收费订阅。当读者为内容付费的时候，他们才会停下来仔细考虑一下，要不要转发某篇微章。欢欢喜喜转发垃圾公众号发布的养生、健身、时政、心灵鸡汤文章的时候，每篇要缴纳1块钱或是免费，其间的差别会极大。收费会让真正优质的内容浮现，减少文字垃圾的泛滥。转发垃圾文章的人并不是知道那些文章价值为零，而是那些东西天然带着某种关怀别人的善意，而且是免费的。

> 唯有收费，才能真正衡量一样事物的真正价值。

在这个社会里，水要收费，蔬菜要收费，甚至是为了得到好的空气，也得付出迁居和旅行的费用。为什么文章是免费的，甚至为何的文章反而是免费的，被大抄特抄，而且大多数人之视为天经地义呢？没有对一篇文章的尊重，自然不会有对设计，一个专利，一个产品的尊重。于是，结果是整个社会都停留在低质量的相互抄袭上，永远无法创建优质的产品和服务。

我在「得到」开设《槽边往事》，目的就是为了打破互联网一切免费的这个魔咒。在过去，互联网发展的规律是用免费吸引海量用户，然后对其中部分用户提供额外的服务，从而收取部分费用。实质上，这变成了付费用户不断补贴盗版用户和免费用户，内容创造者在其中只是得到了一小部分利益，甚至几近于无。而我们只需要考虑一个很简单的题，就可以发现其中的荒谬之处：

读者拿了工资换了流量费上网看文章，那么，产出免费文章的作者为何为生呢？是的，不收钱，不做广告，你会有最大数量的读者赞美你。但是也不要忘了，当你饿死的时候，也同样是在网上蛤蟆，写悼文，宣布“一个时代结束了”。这个时代本不用结束的，不是吗？只要大家都愿意为消费内容而付费，本不会 有那么多“时代”很快结束的。

何其虚伪！

所以，我要感谢所有能够看到这篇文章的人。之所以你能够看到，原因是你为这份内容付出了相应的费用。虽然和满坑满谷的免费人群相比，大家在人数上并不多。但是，我们已经走出了非常可贵的步。在一个以抄袭和复制为乐的网络环境里，用实际行动投下了宝贵的一票。这比什么都重要。当为内容付费的行为开始的时候，我们终究会因为个人行为改变整个网络 世界。并且，为创造更多优质内容和服务，奠定 了珍贵的基础。

这将是一个新的世界，会有更多优质的内容值得阅读，也会有更多优质的产品和服务值得使用。在不远的未来，整个社会将会因此而聚爱息恩，向前进化极大的一步，所有人都将因此而受益。为此，我要感谢你，感谢“得到”这个平台。无论最终成败如何，我们可以在白发苍苍之际，对膝头的孙辈说：

当年你菜头爷就是那么坦坦荡荡赚的钱，而我也就 那么坦坦荡荡的给了。而，今天你有放心阅读的书 籍，安心睡觉的小床，毫不犹豫大口咀嚼的食物， 和没有任何顾虑玩耍的玩具。我们为了能把最好的东西给你，把一个更加美好的世界交付给你，我们尽到了所有努力。

那一天并不遥远，此刻，你已经抵达这里，祝我们能够走得更远，更坚定！
