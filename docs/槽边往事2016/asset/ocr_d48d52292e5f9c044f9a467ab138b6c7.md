# 习惯戒烟

+   ·  泰莱头

此刻，我正处于第N+1次戒烟过程之中。之所以说是“N+1”而非“N”，乃是因为前者有一种慷慨悲壮之慨：哪怕有N次吸烟，也会有第N+1次戒烟。相比之下，肉体总是软弱而又无奈的，总是倾向于放弃和投降。唯有精神能驱使我们向前再迈出一步。哪怕接下去还是要再次跌倒，但是那前进的一小步还是值得赞美。

戒烟本身非常困难，但很少有媒体会公开提及这一点。每次谈戒烟失败，所能听到的就是讨论意志力薄弱问题。这样一谈戒烟失败，就可以归结为当事人自身的原因。而我最近两年一直在观察一款戒烟App，里面的数据非常有意思：

这些年里，通过这个App试图戒烟的人超过52万。戒烟24小时之后的人数是45万，高达87%，情况很乐观吧？72小时之后，这个数字急剧下跌到7万2，不到14%的人坚持了下来。30天之后，还有8500人幸存，占总人数的1.6%。120天之后，这个数字相对稳定了下来，6900人坚持满了一个季度。

看完这些数字，是不是很想抽口烟压压惊？

能戒烟超过30天的人，不到试图戒烟总人数的2%，都这样了我们还说什么意志力不意志力呢？当然，如果要严格说起来，上面的数据说明的是吸烟人群，也就是已经被认为是意志上薄弱的一群人的戒烟成功率，自然就会偏低些；甚至再具体一点，上面说的是吸烟人群里需要借助工具戒烟的人，他们的意志力要比无需任何外力帮助戒烟的人更弱。不过，中国总药量至2015年达常的31.6亿支。如果有人要再三之——中国意志薄弱，我个人觉得不如探讨一下烟草可以让人如此成瘾。

这就是原因，我们无需再回避什么，也无需再装作香烟是一种正常的消遣——看电影开会有点衣服很洗浮，看山俗丽。关于香烟成瘾的报告在网土有很多，你可以很轻松地找到一堆。医学科学家甚至告你，香烟的成瘾性甚至要比部分毒品还要高，更难以戒除。批评吸烟者意志力薄弱，就像是批评胖子自控力薄弱一样，除了让他们心理压力更大，负感更强，抽更多吃更多食物之外，没有一分钱正向的助。

虽然世间的所有事物最终都会走向“不过如此”的境地，但相对于恋爱的全程来说，起码初恋期是美好的；相对于婚姻的全程来说，起码蜜月期是美好的。香烟什么都没有，世界上最下流无耻的东西就是香烟，自始至终不会提供给吸民任何人一点点甜头。第一次抽烟的时候，人会咳噶甚至头晕流泪，这源于尼古丁中毒，并不让人愉悦。等抽几次上瘾之后，血液中尼古丁浓度只要不变，人就会状态如常态，需要立即来上一只再平复心情。瞧见没有？在这个过程中，人并没有得到任何愉悦。香烟的功效就是让你产生想头，而想头是一种纯粹的折耗，为了让这种折耗暂停，你必须持续抽烟。
