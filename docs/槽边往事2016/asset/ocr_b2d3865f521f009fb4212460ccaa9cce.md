# 放下你的瓶啤

今天夏至，应该喝杯啤酒，为什么，因为这是我说的。

![](bbox=[0.05, 0.11, 0.95, 0.16])

白洒和啤酒完全不同，喝的是次序和阶级。谁歌、谁尊、怎么喝，和酒本身没多大关系，重点在于确认谁是尊位。红酒是纯粹的私人关系，无次序而无阶级。喝什么，和喝几杯是啤酒的原序，核心在于只允许许多人参加。唯有小酒壶是全序是开放的，邀请你喝啤酒。也许大家可以喝到半醉，谁也分不清谁是主人，谁也不比谁低。所以，电报、丹商式的欢歌，里奇门有一段在楼顶喝酒的她，灿烂的日光洒在每一处凹陷和皱褶的笑脸上，那一秒，‘感觉自己仿佛是个自由人。' 此刻只要喝啤酒，换了的清精饮料味道全都会不对。

因为那便是你手里的啤酒，不用看了，赶紧扔了吧。

作家冯晨在他的小说里，不厌其烦的描述了一种绿色的瓶啤。他写着冰镇啤酒罐拿出来，夏末北京的热闹在绿色的玻璃面凝成水珠缓缓下来，而啤酒瓶入口中的时候，甚至会感觉到细小的气泡子钻进味蕾。事实上并不好笑，只有来版无味的啤酒，喝进去全是来味道相差无几。所有的瓶啤中，它最大的优点也价格便宜，份量充足，可以打完一整桶的胃塞，却并不让人想吐打嗝，往罐喝喝看也就清醒了。过来，这时才算读懂满眼都是歪。

啤酒不应该是这个样子的。

我甚至觉得喝这个所以都是彩色，乃是因为它们邪恶的本性。你品初中看者有七色，第一因为，它就锁定了你味酱，让你最后很后的时日里慢慢将就的过意下去味道。从最初的五色和无系，卷得卷过无有滋。‘喝之彩色，’可以至让你无法再看见啤酒的酒泡沫。也让接受啤酒需要蒙受其一的设置。可是，啤酒从来就如此简单至白的一种饮料啊。

或也许你会议，说你毕竟也看见过甚青、古威，也在科罗娜、太阳西酒都深及淡色。说起来了，它们除了棍子小了，恰个两公三分，而瓶啤并没有大区别。但至而实说，你也曾经尝试过喝罐啤酒吧，黑洞向啤酒，装玻璃或者铁铝皮试过，忍着有头发的修士和没头发的修士，无非味道不同，无非滋味苦点，无非棒棒有，并无任何有人的样子。可是，它们然也不是一样没有啤酒该有该有的样子。

一杯美好的啤酒应该有柔和细腻的泡沫，唇尖沾上一丁点儿，感觉就像睡在婴儿被中，在似有似无之间，又微香醉人。它应该有亮湛湛的颜色，并非瓶啤啤酒，绝对沉闷，因为那是物性在时间之流里的呼吸声。在混沌无定形别刚睁开看世界，而你的瓶瓶水绿。喝一口酒，你的啤酒是果绿色的，你的啤酒是淡绿色的，啤酒是黄绿色的，巧克力味道的黑色的，葡萄酒味道的红色的，它们的罐升起，在爽神清口的苦口里一泛发，你可以看到有异界的光线从顶层散近四飞散，映射着这处白茫茫的发光。然而一切又瞬间重新陷入黑暗，只有泡沫闷起在静默与伤感之中。此时你惟一想做的事情，就是再乘一口，让星空再次亮起来！

且容许你瓶瓶酒自己不说，不需啤酒，你不需要去管什么不是七味啤酒，什么是精酿啤酒，什么是修道院啤酒，你不需要知道马登梯和艾芬丁间的区别，更不要忙着去看知识克拉帕、艾尔、皮尔森的知识。因为你的舌头并不需要参加啤酒比赛，也不需要去考啤酒证书。它最需要的，间识学累，不过是想在饿的时候，书上不要在啤酒里。你只需要过一件事：你多来一瓶至而喝的青酒、灰酒、绿豆，山泉、雪水、地中海水等不同的子，只是啤酒上五注的一个，一个美丽法拉，也就是说，所有你以为啤酒的东西，只是啤酒里世界里不是满足你的一个角落，还有一个广袤无边的世界在等待着你去探索。

如果一种食品或者一种饮料，有上百种分类，数百种子类，而且喝记了不同的子种，那么，它就得你花一点时间去研究了。因为，按这样的细分和命名，说嘴时已经探索到了极限的地平线，把美食上升为了艺术。那么你怎么忍对其一无所知？

我原希望从比利时啤酒中非啤酒语序开始你的探索之旅。但是这里国一度通了白啤文化，开始喝到各啤酒的几种饮料，所以更至实说，容易让人泛尝尝试。唯有伟大的比利时人，敢于往啤酒里加入各种调料而会让它们，因此他们也是文学、开野杉系，也可能是让和啤酒清发出一段恶感来。

在白啤和黑精白啤里选一个吧，在我我俩朋友没在啤酒而的旅程里，它们是功能最强的深入。对于女生来就是好喝，只要很少喝一口，你就能立即察觉到什么。我甚至什么，什么是喝的小瓶，自然黑精酒是有一些醒醉的甜酸青木果味，口感带给，你若是第一间住到白啤里至实去探索，准备让你喝去黑水精精白啤黑精酒了度。福富白啤就是四白啤，味道比白啤酒要更甜一些，所以更有人情味，有一种因为热烈而忘起的东西，会让你的心情做或者着痛。但你却起不这热烈的味道究竟是什们对，那是香菜。

接下来我推荐两个系列：罗斯福和智美，理由是瓶子很漂亮。罗斯福精滴分为 6号、8号、10号三种，酿造时间和烈度逐步上升。瓶子是深绿系的，难有瓶盖的色在数字上相同。如果没感觉下一啤酒味道达到非常，这就需精请找德玛修一样拿一根，从6号一直喝到10号，10号是最近烈和的，你需要是山神的大智慧，10号是为最近烈性者。你需要一个大约一个小时的时间，然后是味觉注型，各种味道如同旋风一样卷着我们疯狂转。

![](bbox=[0.05, 0.75, 0.95, 0.8])

智美分为红颜、白啤、蓝智精，瓶子致实可爱。三智色不同的酒对应在三个不同阶层的酒标。如果要说罗斯福系列酒者中人们稍作自决的，那么智美就是都市生活工作者。红颜智精清凉清爽，非常适合在夏，适合和朋友共作，解灼的夏日，白啤清淡些，带有椰子肉的香甜。白啤是混合果的，适合一两两位，小说的一种，常解人和解馋。蓝智精比较深，味稍新刺，适合一人深夜淡话。在智精的如饮子系列里，可以让你给热流智精，全无至实说。强烈建这一种同时饮用，因为两酒等同干女性专用的长形啤酒，有分身无身。

![](bbox=[0.05, 0.85, 0.95, 0.9])

如果可能的话，你一定要试一试 Westvleteren 12号啤酒，可能是世界上最好的啤酒。修道院生产，严格数量供应，却增加了神仙妙意。而且，它可能是最早的啤酒—330毫升一瓶最早 300 多块，一瓶钱一毫升。不值得喝吗的性子，在国内喝精精酒找不着地窖的几瓶卖下去，去年还买在网上销售的时候已经为了三四十。你可能觉得我疯了：花那三毛钱买瓶子呢？没，买，我就是为了，而且得酒去：世界上最好的啤酒，你一生都不全有机会去一次；世界上最好的红酒，你最好听有也买不到；世界是最好的人酒，你可以买到，但世界上最好的啤酒，你可以拥有，现在就可以。

离开此时，你可以向看看美国、德国、日本甚至是南美出发，一列火车开往各地。在这个过程里，需要有一种想法的心态，乐于尝新的态度。你会发现许多人想法的心态，就是喜欢新的。生活不应涵满于是非喝生大水杯，还会因为利用精精酒的方芽。已经登上这旅程的人会有者：我们再也回不去了。一旦领略过那些丰富繁复的味觉，喝啤酒将变得无以复加。因此你会发现最美的风景，是味觉带来人不醒目的目光。但又有什么紧要呢？毕竟你已经到了那里，就无需再向世人证明。

在一年最短的一夜夜，放下你的瓶啤，跟我走吧！
