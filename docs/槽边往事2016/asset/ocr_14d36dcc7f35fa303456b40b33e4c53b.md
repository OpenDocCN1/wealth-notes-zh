# 野高粱川普

唐纳德·J·川普当选美国新一任总统，就像是麦田里冒出的一棵野高粱。我从小喜爱直播节目，完全是出于娱乐的心态，一直跟着关注的每一步进展。从2016年3月2日开始，一直到11月9日，我前前后后写了4篇关于川普的文章。其中，《破布亦可乱流》还被罗振宇选中，做了几天的得到闻闻内容。关于野高粱，一篇都没有，我对此没有一点兴趣。

为什么我只关心川普？因为娱乐。在美国大选的问题上，我同大多数人一样并不那么关心。但是今年不同，因为今年有了川普。起码有半年的时候，那些爱听新闻、看杂志的观众都会向我兴奋地表示，在那段时间里，我都已经无法不承认：每天在微博上搜索关键字“川普”，看今天又有什么区别，那是我晚间固定的娱乐项目，想一想，那是我觉得太取效学校的辩论，而且是在当选第一天。他还打几项枪案，于是，很多他的家人一起掌声。对了，他当选后也要求人家炸石油管，把中东的石油都给回来。

直到今天，回过头去看这个“今天川普说了什么蠢话”节目，你也会和我一样感到乐。但是，请听，现在还回想不起来？一听到川普这个名字，你现在听起来大概和他那重复了一万遍的口号：让美国再次伟大起来！对他的政治观点，你最最熟悉的大概是在修建高墙、驱逐非法移民，以及禁止穆斯林入境、废除奥巴马医改。说好的推翻哈桑呢？说好的你孙子连惨吗？说好的撒在罗斯石油？你看，早已忘记了。

这就是川普的伎巧。当他每天发表各种高论的时候，他正在参加共和党内部初选，需要在十几个竞争对手中脱身出来。作为一名政治初学者，没有任何从政经验可言，川普的策略就是不使用语言刺激媒体和公众。因为他的观点足够偏，也足够怪，为他提供话题无数的人迅速提供了大量新闻素材，为我这样的普通民众提供了大量娱乐话题。所以我用单一一张嘴，就在全电视台为自己省下了一大笔的免费报道时间。他都不用去约媒体专访，媒体会主动找他。给他话筒，俩镜头对准他的一张脸大，让他在观众面前丢丑，刺激节目的收视率。

对于大众而言，谁的报道最多，意味着谁是最需要的人。借道媒体，意味着自己的机会，川普从几十个竞争对手中迅速脱颖而出，赢得了最多的社会公众关注度。对他的远距离形象，人们肯定会反感他的部分言论，但是更乐于看着他在舞台上继续蹦跶。到了这个时候，川普的策略反而开始接受了较为温和，他拿个逗子的接一个家伙收拾自己的竞争对手，给他们起美“软蛋”、“迷嘴嘴”这样的绰号，在公开辩论中一边暴躁地侮辱对手，是全面的狂欢开始了。民众乐于看到一个政治门外汉单枪匹马地看着这些政治精英，让他们不太适应。在这个阶段，川普完全不在乎对谁的支持，在他的访谈里，他仿佛根本不讲事情；主持人的问题，永远会被调调两件精明：1、我的支持率，2、我的民调支持率是最高的！于是，这两件事情都发生了。在初选阶段，川普一枪一枪，稳定地缩小了其它竞争者，一枪一枪地必杀，与此同时，民调也一路走高，共和党的选民民意看到这一次野高粱竞选者有些出类拔萃的状态，这其实是精英选民，别人是纷纷表态，老川普，非常中吃老吃，策略精准，太厉害。非常中吃老吃。

接下来共和党人内初选的时候，川普深知，这一次他要争取全国选民，不再是共和党人下层的忠实拥趸。他，他之前各种离谱的话全都没用了，自己地位不输了。同时，他的第一级别民众注意力的方式也到了，在级选和竞选的过程中，都是由他来设置议题，唯有他提出的议题，媒体和民众才会关注谁谁，希拉里必须做出回应，否则会被老看客。为了实现这一点，川普非常聪明地做了几件事情：

+   1、反复自我包装。用脚趾头都能想得出来的希拉里会用来攻击你的弱点为打击重点。本来是是非常难的局限，但是在川普这里，他就有本事用非常粗暴和直接的方式进行转折，而且反过来！。1.川普大声地喊：我们有钱！我有钱！爸都是有！民众当然承认这一点，他是从普通的地产大户，川普下一句话就变成非常凶狠了，他说：曾由我说的竞选，谁也挡不住我！听到这句话，群众就开始鼓掌了。一个独立坚强不为别人绑架的硬汉川普已经立起来了，到了这个时候，川普也不是正面回答政治问题的形式，他只是一个看着关于面对媒体的希拉里：“我是，30个，但我不起来，实现了美国梦，但是谁帮帮你？那你今年了30岁，国家就帮你看成了这个。你到了多少才什么？还想借几个8年？”

+   2、形象化自己的政策。希拉里被数据流、阐述政策，赢得知识分子和中产精英们的心。这意味，老百姓根本不知道她说什么，知道她怎么，也根本不会。谁会关心8-系列数字和百分点？川普最关心的，是无力的打过交道，知道如何说服人的艺术。奥巴马执政8年间，美国人平均17倍，川普最要说明什么？就是他的移民政策，没有百分百，没有中，就是要搞，简单到不能再简单。简单到让川普直接说，我连工作机会可以夺走。美国便让外国人，都待在美国本土，来美国工作的机器是不能够的，讲清楚这件事需要多少时间精力？川普的做法是粗最粗野，但是最简单最通俗，也最符合自己的理解。

+   3、接触选民。如果美国总统竞选就两年大，估计最大的一个定见，就在为不几上年他老到死光布选州。随便找一下州在竞选的日程表，就可以看到什么叫做精兵本色。一天内，川普会跑五个不同的州，竞选民大发表演说。而他成功当政一种摇旗选语的狂飙，动用粗俗和煽动在各地，上万亩发自内心。尤其是现在美国中部州，地居民众对你已经极度遗忘，通过小范围的集会，他们个人的心中，可以口头发挥的媒体所托绝表达的恶气，觉察到和自己有相同观念的人有那么多，而不是有人站在政治立场的一边，不找到了归属，群聚效应就会产生。民众就越来越支持川普，对他的支持率就投入了力量，最终，选民在日大选时投票回报了川普对他们的信任。

就这样，川普从一个小丑开始，一点一点蚕食了希拉里的优势。他从他把自己打造成一个行走的美国梦，成功地他希拉里变成为政的奥巴马的像，最后，那个真正的美国梦，击垮了希拉里，漂亮地赢得了大选。我知道，许多太关注“术”的层面上川普如何取得成功，对于“道”的层面以上世界所以成功的样子毫无发现。那么，这篇文章相信可以帮助你理解川普作为一名商人，如何成功地战胜老政治家，取得了令人难以置信的胜利。除了个人的聪明之外，更重要的是，不能接受川普当选的人，忘记了世界真实的图景——不是麦田里突然长出了一棵野高粱，而是所有的麦田为了一架的麦地所包围。这一次，野高粱长到了麦田里。
