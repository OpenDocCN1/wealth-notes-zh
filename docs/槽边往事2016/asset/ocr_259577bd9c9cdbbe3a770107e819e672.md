# 第50000本

今天下午，罗辑思维的李倩同学通知我：第50000本《尴尬往事》已经卖出去了。就这样，我一只脚终于跨入了中国畅销书作家要求的行列（说10万本才算及格的那位，你出去！）。想一想，这可是5万本啊，那是什概念？5万，差不多就是一个亿了。如果父亲还在世，如果我父亲还和十年前一样健听，听到这个消息大概会放下报纸，很冷静地说一句：“哦，还不错”，然后继续去看翻他的报纸。但我知道，报纸后面的他，心里一定得极了。

在罗辑和脫不花找到我之**，已经有许多出版社联系过我。每次我都和他们说，请从我的博客里挑选文章吧！但是每次他们看完我的博客文章数量，就会从此消失不见。我以为我已经够够的了，没有想到出版社比我还饿。所以，当李**和**不花和我聊出书的事情的时候，我根本没有仔细听，只是点点头，忙着往嘴里塞食物一反正最后未必会成，但他们现在请我的这顿饭还不错，我先吃开心了再说。

没有想到，他们做起事情来就像推土机一样生逼迅捷。罗辑思维的李倩同学花了一个月时间，生从未数百万字的博弯文字里挑出了一批文章，让我从中挑选最满意的。于是，就有了这本《尴尬往事》，和菜头自选集》。封面是我强烈要求的结果，我要一只驴子，因为尴尬往事讲述的是一头驴在拉完磨的夜晚，静静站在**棵河边，看着星星时心里想到的那些事情。我还给那头驴加了长长的睫毛，说是可爱才最为符合我本人的气质。

如今半年过去，5万头驴涌出驴圈，奔向世界各地，消失在各个洗手间和床头柜。我不知道这5万人一是谁，但我希望他们能每天随手翻阅一两篇，然后像笑一笑。我去说过许多次类似的话，现在在我依然如此希望。我提供了那些宏大的、深刻的、引人深思的话题，对于一些小小的生活情境，简单单纯的 个人感悟。对于那些和我关系密切，以寄生共呜的人，这些文字也许会让他们觉得自己不再时是孤零零活在这个世间。因此，当有人买了书之后质问我说：“翻了几篇，觉得很一般，和菜头，请问你的哪篇文章让**人喜欢上你的，我去看”，我立即回答他：哪一**你会喜欢，我去改。

像我那么龟毛、暴躁而又刻薄的人，能有5万人愿意买我的书，这也让我自己很吃惊。我觉得这一切还是因为时代变迁。当我们发现世界上有那么多不同的人，有那么多不同的想法的时候，会很自然地明白一个道理：我可能取悦每一个人。当我判断一个**和我并不相投的**道上时，我换个**机的速度比谁都快，甚至极少考虑礼貌这种问题。在我看来，无论是一**和气的**还是徒劳无益的屈**变**，都是一种真正的**尊。人人生如草**，如果在讨**的人身上花费那么多时间精力的话，我又再什么去对待我真正喜欢的人呢？

我觉得自己挺得意的。还有那么多人愿意纵容我，让我按照自己的心意行事。

哪怕用最宽泛的标准来要求，我*不是一个好的作家。太懒惰，太随性，只写自己想感写的东西，哪怕因此成文驳杂不堪，难于形成一本有统一主题的出版物。李倩在做好的书的时候就很难为情，这么一本小书，最后在要出成好几**时候，因为我的文章像驴群一样，从一个主题漂到另外一个主题，不愿意乖乖呆在—个地方。我想，这是因为热爱而产生的贪婪。终我一生我都会起终睁大眼睛，在这个世界上到处去看，去尝试没做过的事情。哪怕因此而遭受惩罚，甚至不被世界所接受。

惩罚早已降临。我***四十岁时出了第二本书，有的人三十**经著作等身。我过了四十岁依然漂泊无所欲，**们想要在凌晨**电话给我的话，永远第一**间想起的是我，我写到现在，也没有办法确**究竟是个写什么内容的作家。甚至，我是不是作**也仍是**疑问。我**究竟是什什的，最擅长做什么，**了**生也没有想清楚。我只知道，我**情是太多了，能够做**事情太多了，想做**事情更多。但是，既然非**么事情钻进去**，自然就不**有来自框框的**利，甚至时**要被打两**屁股。

如果说我这样的人存在看对于社会还有什么价值的话，那就是让你觉得安心，觉**人也**么令人**怖。一个人没有确定**的**明天，没有稳定的职业，没有可靠的单位，*然可以*在这个世界上**活。**性妄为，却**能够**得世界**容**待，并没有**太多的**障。每个**都**生活充满**，像一**小**一样**鼻子**出**，**索一**的**可，但很快**可能逃**理**人**越**大，**子就**小，**里的**规越越多越**围**。**我到**还没有成为**电**淘**，**么，你是不是**可以**一下人生**任性一回？
