# 有生之年应该去一次卢浮宫

在我接受的教育里，并没有多少美学训练存在。有美术课，但美术老师教授的美术课，很难说和美学有什么关系。缺乏美学教育看起来也没什么关系的，除了数学之外，人们并不关心心之类的东西是数字体系。只是这样下来，我们迟早会发现自己生活在一个极端粗糙的生活环境中去，当你真的想要找到一点点精美的东西，真的让自己的生活品质有所提升的时候，很可能连什么是好的标准都没有。

有人会反驳说：买贵的不就得了吗？是的，这些年里人们都在追逐财富，追求世俗意义上的成功，于是一切不如意、于是一切内心有不得来的欲望都源于贫困。那我们不妨看看精神世界的一对照导师：请上网搜索一下中国相声界的视觉之郭德纲先生，翻一翻他相声里的说笑记录，然后再去采访郭德纲那个样子是不是因为缺钱，请读读余华老师刚写的书，看看去云南他写到，在他刚登临后的照片，感受一下黑而堂皇的欧陆风情。然后思考一个问题，为什么那么多人说那是把KTV搬到了家里？是因为黑金贫穷吗？

《得到》APP出来，留言里就再有人抱怨，说字体不好看。《得到》换了黑体，字体还是有人不断在投诉。抱怨的人可能永远也理解不了一个简单事实，世界上漂亮的APP有许多，拥有漂亮字体的APP也不是少数。但是，只要是100%克隆某一个这样的APP过，就是能把字体从英文、日文切换为中文，整个视觉效果就像在一顿糊弄事，道理不复杂，别人在研究如何设计字体好，如何排版才悦目，耗费了大量的时间和人力。美并不偶像，需要今人不断出新的，才会有今天的。中文体有几个字好上，有几家公司愿意花时间研究下排版？即便愿意，所谓“漂亮的中文排版”标准又是什么？靠一家黑金是欧陆风情KTV包间的老板吗？

还问题的关键，互联网上也曾有唐亮这样的公司，专门去研究字体怎么字才好看，研究一行里怎么排印中文才好看，一段文章里怎么分布才能优美又不伤目。更有造字工坊这样的机构，耗费大量时间人力，每年推出新的中文字体。但它们的景象是持悲观态度，因为为它创造出来的美还需要足够多懂得欣赏的人来理解。你创造出来的中文字体后，对上一件衣服，它要名牌呢，自己穿上这一件认知里的人会有何意义？他们能够欣赏到吗？如果大多数人甚至根本不识不同字体所带来的美感，价值，人们就不会为这样的努力支付任何价格，这样体公司就无法生存下去，整个社会也就没有审美美存在的基础。

我们的生活总是缺乏粗制滥造的产品？得到过的服务？互联网上有三个着名的，叫做“山”。国际市场上什么产品，好的设计，网上潜在的消费者都会发出号召：山！！意思是请三个，样子几乎一模一样，价格也许只有人的十分之一。同样的，国内生产商家只设计一个新产品，只要刚造得心里一上去，一开工就立即跟进“山”品，用价格战吃掉原厂。于是，没有人愿意再去做原创，是那些看着别人好不容易寄望自己能够达到一流产品的人，当然只有三流货，审美最后也感受不到其中间的好。反正大家的审美也感受不到其间的差异。

重审美，当然也就不重视创造。不重审美，也就没有人愿意创造美。最后的结果，就是我们生活在一个巨大的垃圾堆里。在这个垃圾堆里，要么只有各种丑陋垃圾的残破，要么就只有毫无根据的奢侈品堆砌。我们审美，到头来决定我们的生活质量。

而每次我们谈到审美，大多数人张嘴就是书法国画，就是或去大千齐白石，就是五千年文明源远流长等等，绘画雕塑，太多人到今天的标准还是不以欧陆美学为标准。所以，如果有机会出国话，我建过要去一欧洲，如果去欧洲的话，一定不要去巴黎。如果去巴黎的话，在位于宾馆和老爷们商之间的，尽可能走出去多几个街区，去卢浮宫看看。

我觉得去卢浮宫是开始个人美学之旅的一个好地方。一方面你可以在这里看到各种文明在古代创造出美艺术品，明白源远流长的不中华文明，世界之大，超乎自己的想象，美并就是书法、唐三彩和山水画就能完全涵盖，另一方面，觉到沉沉浸就不了，张大的一个外画而变得活生生，那么卢浮宫里的绘画和雕塑会给你带来另一种冲击。当你看到大理石雕塑的肌肉纹理的时候，看一看雕塑的制作时间；当你看到人物肖像里皮肤的肌理，风景里面清晰透的树木的时候，请看一看画作制作的时间。到从在多个世纪以前就做到了这样的水准，那么这样的标准还有什么意义呢？

带着这样的问题，离开卢浮宫，可以接着前往奥塞美术馆或浪漫代艺术中，依次看完古典美术、现代艺术和当代艺术，或者，也许会因为挑换一个家庭的装饰，减少一个夜总会间，并开始正确怀疑和央视体当年那身官裙来到哪里不对。

每一次去卢浮宫，我都会看到许多来中国的小朋友，成行结对，或者来寻访中国的朋友，这有小小的老师现场或打开放开开始临摹。每次看到这样的景象，我内心都会羡慕。因为一个人在小时候能看到多少美的东西，很大程度上决定了他未来审美的广度。而我即使到了今天，如果要看一张图，还是只能看看太阳，下面两个气球吊着两条标语，红底白字，那字用的依然丑。

去一次卢浮宫吧，在这短暂的一生之中。美这件事情永远也指望不了别人，只能靠我们自己。
