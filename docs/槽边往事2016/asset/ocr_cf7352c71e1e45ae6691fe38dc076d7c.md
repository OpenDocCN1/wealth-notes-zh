# 关心则乱：人为什么会营销？

长久以来，我都在追问一个问题的答案：为什么人们对“简明扼要的智慧”文章里里外外毫无抵抗力？十几种标题，配上各种GIF图、问答形式，外加各种噱头和引经据典，那种强烈的垃圾信息气息已经达到让绝大多数刷到它引起强烈共鸣的程度，但人们还是会去看，而且感到倒霉的是：看完就转发。如果一个人走在街上看到这个，七秒前他会皱着眉头想，但一旦他点开，立刻会有一堆人愿意往自己的群和朋友群里里转发。

为什么？（此处应有黑人脸问号.gif）

以前我相信一种说法，所谓“谣言止于智者”。中国人说去喜欢听，把得道人的后半句省掉了。既然谣言止于智者，那么一定能迅速退去于群里。它念会了所有人：大多数人的意愿：数量众多且执行力强大的是大众信息的传播。然而，听过这句话的人，都默默把自己当成引经据典者那一环的辟谣，在戳破了一个愚蠢的大众之后，这件事也就那么高高兴兴地过去了。真是这样的话，最近的一些经历让我越来越怀疑着着对于谣言的免疫力。

前天，我的一位老哥转发了一篇关于遗产税的文章给我。文章寄给学院马上就要开始征收了，而且说明了预税的阶梯，甚至还会说漏掉这笔资产不能从遗产里扣除，如果三个月内无法缴纳，遗产会被收回国有。在这篇有线索里，各国学者飞来飞去的文章最后，很自然地做起了广告：现在，我们有一种可以规避遗产税的理财产品，您想来试水的财富可以复投给我吗？那么，您就这么试试。我替我们老哥问：什么时候连这种东西都要转了？

他的智力分有140也有130，具备高等教育，见识广博，经历了无数的事，见识的骗子比你见过的还多。在网络上也有几十年时间，从QQ刚刚崛起的时代开始上网，到不让大家在电脑使用各种即时通讯工具，再到今天的微信。在B站时代他都能见过也转发过这类垃圾营销文章，为什么到了移动互联网时代他就变得无分辨能力了？

今天，我认识的一位资深媒体人、国际政治学者者，在朋友圈里转一篇关于川普上台后族歧视现象调查的文章。这篇文章来自于一个很小的网站，内容大多是摘抖拼凑和名家留言，大概引用美国各方八卦的“新闻”和奇闻异事，满足那种对于遥远的不断别以及向西方设定的想法。我摇“扇子”了，在这个网站提到，因为她的供许文章明尼苏达州不得不数次发出声明，并未接到任何来自学者的投诉。随后，这位Tu也删除了自己在Facebook上的文章。在这里，依然是希望之地为种族歧视案例在讲。

如果是别人转载这种文章，我绝对不会像现在这么焦虑，要知道，我这位朋友不可能是写过一系列给新闻学系生的教程，教他们“如何在网络上获得可信的新信息源”，用方法去确认新闻的真实性，并且凭借这教程一度定义中文互联网，那些媒体知道被转载了多少次，在多少学校做过讲座。要是你去过去，这种学术机构和编程账号的内容，别说转载，连他们这是张的卷子他的专业知识和专业判断发生了什么变化？

为什么？（此处应有成爪抓头发.jpg）

我给出的答案是四个字：关心则乱。我的老哥非常得意着各种转变，无论遗遗产税、房价税都会让他神经紧张，因为他担心自己的资产缩水。对于任何一个做了半辈子生意的中国商人而言，像听到狼几声，无论是狼。都会非常惊慌，这是被刻出来的经验。所以，当他看到标题是出于遗不的经验时，所有关于分布歧视的经验都消失了。他看花见花绿绿的字体，都丢丢丢的动图，他只牢牢固地“逃税”和“即将征收”几个字。对他来说，看见这几个字的瞬间，整个世界观已经发生了变动，他的心志立刻看着着内容，按照佛教的说法，他在那一瞬间陷入了遗产税现中。

我的学圈朋友一直支持希拉里。希望希拉里是美国选民的态度。对他来说，希望希拉里当选不是单纯的政治和胜败的问题，而是他对这个世界判断的基石，希望她的当选。在他理解的那个世界里，希拉里当选是历史潮流，无论对于女权还是平权运动，几乎都是必然的结果。所以，可以想见川普当选对他的打击。哪怕像麦德兰说，他也感到过去的一年，万恶的川普当选，意味着他对世界的理解完全无方但川普当选，在这样情况下，看不到一篇特朗普当选之美国种族歧视现象调查的文章而瞬间就选中了他的心。他要这样的文章，因为这样的文章说明他当初的判断是对的，至于是否可信，是否要做事实核查，去他的。

你看，这就是我悲恸的答案。无论是智识、阅历、地位、财富，还是主义，都敌不过人性。在涉及切切身心的事情上，人们的判断很容易失实。对你的事，他是再显而易见的事实，对于他人而言可能全看不出那么回事。同样的景象，你我都看到的是完整的一种黑盒，做出的是两种完全不同的判断。当你内心升起对自己的保护意识的时，你会自动丢弃接受任何对你有利信息的，彻底放弃了自己的理性，而理性告诉我们说：我们可能是错的。这也是为什么我会在每一篇文章的签名栏里写上“请你们信我，我所说的每一句话，都是。这句话，许多人因此恨我矫情，或是故弄玄虚。不，我不过是对着我自己说。

从长远的角度考虑，你迟早早都会跳进某种垃圾桶文章。那些花枝招展的页面，那些东边朝圣文就从来都和我们，而更多的都有幸运可以从那里来源立即笃定地痛击它们极夜。它们带，积极者，自心机，它们自一年一年，日复一日信息内容，而且无比坚定相信：总有一天，人们会被原里的一个为们打中心灵魂深处，由此被拉下幻理，为了自己的相信而去相信，落入它们的怀抱。

我是一块混乱的记忆合金。我们如此努力的锻炼着身，不间断地自我抹除，无非是期望理性击退这记念也住，它可以触成某种合适的形状，刻下某种样式的纹理，于是得以将台前进或大，只不过们稍松神，这块记忆合金就会抹去我们在其上的任何日后努力的纹样，悄然回到原来的模样，任世界从我们身边经过，将我们忘记远地。

禅宗的石巩慧藏师从马祖道一禅师，慧藏悟道前，牧牛和马祖只是马对话，虽然悟了悟，下一记棒喝只是，在那之后不久的某一天，马祖经过厨房，看见正在帮厨慧藏慧，就问他：“在干嘛呢？”慧藏也不忘地回他：“在吹牛。”马祖问他：“怎么个吹法？”慧藏答：“只要跑进草丛里，一把牵看牛鼻子就拽回来。”马祖称赞：“你还真懂吹牛。

愿你做一个一辈子不倒的吹牛。
