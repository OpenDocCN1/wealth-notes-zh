# 《驴得水》是一部怎样的电影？

《驴得水》是一部怎样的电影？这取决于你自己是什么，你想要在电影里找寻什么东西。

有时候期待并不是一件好事。因为往往事与愿违。《驴得水》是开心麻花团队在《夏洛特烦恼》之后，第二次把自已的话剧搬上银幕。之前，观众理由期待《驴得水》是一部让人开怀大笑的喜剧。如果是带着这样的期待走进电影院，那么最终的结果多半是笑着笑着，就突然哭了起来，因为《驴得水》是一部穿着喜剧外衣的悲剧。对于那些太过沉重、太过严肃的话题，用开玩笑的方式来探讨反而是好的。因为在缺乏有意识的方式探究下，我们会发现己知和不可能有意识的真实反应，以及我们为了回避这一点做出了多少的努力。

对于普通电影爱好者来说，《驴得水》当然是一部烂片。原因倒简单：陌生。这样的观众坐在影院里，电影至终都会感觉到不适应，因为银幕上的电影和自己惯常看的电影太不相同了。这种感觉没有任何问题。《驴得水》更像是话剧，而不是电影，每一个场景，每一个画面，每一段对白，都让人强烈地感觉到舞台的存在。与其说这是一部电影，不如说是用摄像机在实景里拍摄的一部话剧。全片唯一一次像是电影的地方，是在接近结束时，五光彩纷的弹珠从草坡上彼弯而下的镜头。终于，此时的叙事完全交给影像，不再是依靠重不透风的台词。

资深电影爱好者会承认《驴得水》是一部好片，得出这个结论的依据是片量。如果一个影迷观影经验并不拘泥于青春校园、爆笑喜剧、美国大片、仙侠玄幻所构建的日常中国电影市场，而是的确见识过各种不同类型的电影，那么他确实可以承认《驴得水》的神话剧风格也当成了一种风格，同样是一种电影的叙事方式。没有谁规定电影就必须可以“像电影”，也没有谁规定电影一定要不讲一个悲剧故事。而且，如果在2016年横向比较一下，《驴得水》是至今为止所有国产电影里最特别的一部，甚至可以说是最精彩的一部。

但是好不好和喜欢不喜欢，从来都是两回事。就像“你是个好人与不等同于“我喜欢你”一样，承认《驴得水》是好片的人，未必喜欢这部电影。喜欢看电影的人很可能不喜欢《驴得水》，因为电影就是白日梦，爱看电影说明对生活还有幻想，还在追求温暖、欢乐、小确幸，还对人性抱有可能的信心。《驴得水》里没有，那是一个由庸人组成的故事。每一个人都是庸人了庸常的程度，凭着本能利益驱使行事。然而，也正是这些庸人，当他们人性的中恶最终得到释放的时候，庸人令人厌恶的笑到变得让人惊惧的恶，和毫无必要的残忍。电影几乎非常严格地论证了这种人性的溃败，每个人在电影都做最正确的选择，也是最符合自己利益的选择，但结果最终塑造了所有坏人。所以，《驴得水》看到最后让人觉得沮丧，让人感到失望，毫无任何温暖之处，让喜爱幻想中的人绝望，自然也不会喜欢。

知识分子会很容易在《驴得水》里感受到明确的讽刺。那个知识分子为主线条成出的这个故事，他们的形象比《围城》里还不堪。无论是处于理想却不切实际争夺蝇头小利毫无底线，还是徒此顾盼、见风使义、目光短浅外强中干，又或者是追嬉强权趋附娼妓，首鼠两端贪求荣华，把知识分子挖苦了个够惨。就连知识分子为微的教育也没放过，生生讲了一个让教育毁人的故事——强行把一个文盲掮底从泥地里拔出来，洗刷干净，让他认会认字，操一二英语，最终这个人却变成了一个彻头彻尾的人渣——教育没让你变得更好，只不过是给他的恶配发了武器，知识终于让他可以伤害到别人了。所以，如果你看到知识分子对这部电影反智，千万不要觉得奇怪，因为它实在太过刺激知识分子的神经了。

很自然地，也会有知识分子或者准知识分子盛赞《驴得水》。因为在这部电影里，他们得到了他们想要的“思想深度”，从荒诞程度上看，《驴得水》算得上是《让子弹飞2》，甚至有类似的设定——某个孤立的国民，从人性上看不想法的人们彼此原杀。从国民性分析上，《驴得水》更像是《鬼子来了》的延续，揭示了国民内心深处丑的愚昧、麻木、短视和残忍。除了一个小女孩，没有一个角色是好人，好的电影，就像现实生活的一个隐喻。《驴得水》是一壶好酒，足够人们拿来浇洗自己心中的块垒。甚至无政府主义者也会推赞这部电影，对她们来说，这大概是第一次在银幕上看到一个女性角色大张承认，自己活在这个世界里就是为了追求快乐，而且拒绝了别人对自己的干预。承认自己喜欢过那样的生活。对于她们来说，这是女性自我意识觉醒在破天荒的一幕。

如果你一定要追问这部电影的好和坏，我可能无法回答你，因为我们都不再是孩子，指着银幕道这是好人，谁是坏人。每一个人的立场、兴趣、关注点不同，决定了对同一部电影的观感彼此并不相同。不过，在我看来也没有必要强求相同的必谈。归根结底一部电影就是一段餐食上的淡谈。所谓大电影，无非是餐桌上段是时间的淡谈。人们彼此争论，试图在某些观点上说服对方，于是吃喝喝酒之余终于有了点别的章情事可以做。这篇文章你可以将其视为各种观点的列表，欢迎你在其中找到我要的东西，带到下回餐桌上上上。
