# 那些坚硬的部分

很早之前，我在文章里推荐过电影《一个名叫欧维的男人决定去死》。当时我承诺说，等大家看完之后，会写文章讨论这部电影。结果一等就是一个多月。我的体感是，而且看多了10斤。所谓食言而肥。古人诚不我欺，所以惊诧之下决定必须兑现当初的诺言。

《一个名叫欧维的男人决定去死》看完之后，让人感动的同时又有一丝丝伤感涌向内心。对于习惯了在银幕上领教各种小鲜肉拼命动手脚的我们来说，大概很少有机会去观看一部以老年人为主的电影，而且讲述的内容都是生活小事，发生在北京的一个安静居民小社区。那么，究竟是什么呢记了男主家的坏脾气？又是什么让我们一个安静静静的电影，专心致志地看完大多数时间的时刻，整个一外围老头的人生发生兴趣？

我的答案是个字：坚硬。

欧维这个角色身上有一种我们都很怀念的亲切气质，那就是坚硬。他对自己而言，对生活的认应该如何，有一种异于寻常的坚持。当他在认定事情是如此，他就守住这条线寸步不挪。无论别人如何嘴炮，外界如何打击，他都无不为所动，每一次都他以满腔怒火和近乎狂暴的态度作为回应。在一开始的强硬，这让他几乎是人人觉得他反感。可是，一旦我们开始接受他的这种坚硬，我们很快就会喜欢上这个人。因为我们不得不承认，其实我们自己在内心深处的海洋里拥有这种坚硬。

对于我们的日常生活来说，问题并不是温柔可亲的人太多，而是总有些跳规则，随意越入人与人交往界线的太太多。我们在自己的书房应该可以反包的时候，不由自主的声音就会开始鼓励和解和忍耐，开始掩盖隐忍和宽容这些美德。这就像打嗝，人人都会这些不美不坏，或抬头装，但是每次都会被人住鼻子，不让喷掉出来。那就让人心里不爽起来，结果所有的内心潜心事都喷涌出来了的话，那么所有城市上空最响亮的声音一定是“滚开，别来烦我”。只不过因为我们要对做好人的缘故，所以一直静默到今天。

欧维原本是我们中的一个，但自从太太去世之后，他已经丧失了活下去的任何兴趣。对他来说，能够最早和太太在地下重逢，才是最有意义的事情。当他决定去死的时候，之前所有束缚他的一切都不存在了——还有什么比死亡更重要呢？当一切规则的地方也在这里，当一个人决定去死的时候，之前拥有的所有束缚都不再是问题了。他会失去所有的时刻，他同时也都得到了最大的自由。终于可以按照自己的心意地林淋漓地活一次，也完全是他自己的放弃一切的时候，他得到了以前在生活中求索不到的东西：友谊、理解、支持。或者，我们公平一点来说，他在自己生活中发现了人们存在，在决意离开人世之前很久，他就已经彻底放弃了自己，以至于不会再感觉到疲惫。

我们在生命中遇到过几个欧维，他们的位元异常，是附近不出名字的社区门卫，或者是你很多年前没有说过一句话的小区门卫，或者是某位不愿意做任何事让指甲头破血流的人的邻居甲。和所有半文盲的欧维相比，这样的人给我们留下了很多的印象。我们无法描述：他们是好人，但是他们太规矩，太固执，太暴躁，太愚蠢，也太太不一样。所以忍不住想要知道他们是否与众不同的结果。一旦看到他们看见欧维，看着他安然辞世，我们的心头突然柔情漫起，于是想起了那些人的好。相信是同样的人生应该有一个不错的收梢。那个心头压抑了许久的嘶喊，终于打了出来。

这就是我对《一个名叫欧维的男人去死》的看法：唯有解开内心束缚，一个人才能可能真正变得坚硬，无所畏惧、顺从心意。在岁月的冲刷之下，唯有内心中最坚硬的部分能够留下来。就像欧维在人群里留下来，也许是因为我们的记忆力留下来了，是时光因为放弃生存的希望而解开了内心的束缚。我希望大家能找到，保持对自我的核心和自由。坚硬地活在这个世界上。祝福你！

和某头
