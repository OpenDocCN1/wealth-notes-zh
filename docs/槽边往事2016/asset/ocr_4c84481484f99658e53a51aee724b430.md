# 什么值得买：我的年度总结

都说赚钱最尴尬，其实花钱更尴尬。赚钱的路是有的可没，所以的钱的也都是在有那里，但可花的地方却是无所谓的。在这无穷多的地方之中，又隐藏着无穷多的陷阱。花钱只能去看去猜。除了无穷多的陷阱，自己还有一张看不到尽头的欲望清单。再等到去关注这张清单的时候，却往往发现是自己心尖一片茫然，不知道应该如何选择呢。

以下就是 2016 年我个人购物清单，里我自己觉得相当的东西。之前在微信公众号放了一个精简版，现在的这个版本更加完整。也许并不能是你要的，也许你并不赞同，但是请不要忘记一件事：这个清单里面一样一样东西是我用真金白银和时间经历去亲身验证过的结果。你看到的是这张清单，看不到的是我在墙里面不断被爆炸冲击波炸得起落落的身体。

# 年度图书

# 《间谍家族》约瑟夫·坎贝尔

在《人类学》和《间谍家族》之间，我更喜欢后者的《间谍家族》。前者帮助我理解历史，理解人类的发展，但后者帮助我们理解人性，理解故事，并且可以从中提炼出共有者的故事模式。它不是一本书，更像是一把可以打开无数扇门的钥匙，属于我喜欢的这种“书中之书”。

# 年度国产文艺片

# 《路边野餐》毕赣

这一年我看了三部国产文艺片，《路边野餐》、《长江图》和《塔洛》。才华这种东西是无法仿假的，后两部电影拍得非常工整，也非常满足学院派的喜好。但是，谈到才华和技术水乳交融，镜头和故事相融合，那得是毕赣的《路边野餐》。如果你，展现自己艺术水准的方式不同，毕赣找到了属于自己的风格，因此《路边野餐》浑然一体，风格自始至终。《如果你想有一部文艺片的时间预算，那么，请一定要看《路边野餐》。”

# 年度国产类型片

# 《驴得水》周申、刘露

《驴得水》是典型的类型片，讲述一群人为贪欲而陷入越来越大的麻烦。由于之前在话剧演出过多次，所以这是难得的一部能够吸引观众国产电影。它的优点是比较明显，以至于它忽略了它太魔变舞台的毛病，而是把这个笨拙的表现手法理解为一种独特的个人风格。

# 年度纪录片

# 《未了之天》NHK

这一年里，有许多制作更为精良的纪录片，但我最后还是喜欢《NHK这部写实风格中略显粗糙的作品。从这部影片，让我看到了大型作品的大师的原片。更重要的是，它给人带来精神上的巨大异常——哪怕是在危险的时代也乐观异常，所以，尽管还有什么逃避现实的理由呢？

# 年度大片

# 《血战钢锯岭》梅尔·吉普森

在残垣的人们看到同一个一个人对无论信仰的坚持，让人感到人性之美。无论从事的角度，还是从人物的角度，都能给观众带来新的体验。虽然它已算不上一部传统经典新片，但在今年已经算是了年度精品了。观众想要的视觉冲击、情感震撼和片后反思，在这部电影里都有了。

# 年度泡面番

# 《齐木楠雄的灾难》

因为无法不能而造成对所有事物丧失兴趣，这是番中最为有趣的一点。因为为番中的设定，吸引的是那些生活中的小麻烦，令人发噱的就是人际关系的矛盾。漫画版是那种极为短小的动画集数，其他泡面番如《齐木楠雄的灾难》有一种建筑在所有人能理解之上的怪异温情，因此，它可能是最能凑90分情感表达的泡面番。

# 年度美剧

# 《百年酒馆》

没什么好说的，看完第一集之后，喜欢看的自然就会一直下去，不喜欢看的估计会立刻弃剧。这种事，和审美有关，也和人生阅历有关。
