# 论云盘的倒闭（内赠福利）

今天，又一家云盘服务关闭了。在我看来，所有的免费、关闭、笔记都该关闭。如果人们一定要用云盘，那就必须关闭。如果人们一定要用云盘服务，那云盘最好的去处（在付费云盘之前）要么免费，要么就是付费。人们要么明白一个道理：不是每一个贪得无厌的念头都值得别人去满足。

云盘从出现开始，就是为了满足人们的食欲，所以，在云盘里存音乐，存电子书，存电影，存任何你喜欢的东西，当然也包括存一些没有用途的。这些东西就存储在云端，你的资料，无论被储存在哪里，云盘的本质就是帮你去占有，而且是免费或者很便宜的去占有，这就是贪婪。

请问，在云盘里存储一部电影有什么意义？一个人可能随便看一看？看完全之后还会再重新二遍么？或者，真的需要保存一整部电影的话，为什么不直接存到本地的磁盘里？在一种存储无限制的云时代，把一千部电影都存储到云里来，这其实跟把一堆无用的电子垃圾扔进垃圾桶是一个道理。存到云盘上的东西，无非就是存一些没有用的东西，存一些自己舍不得扔的东西，存一些自己觉得有收藏价值的东西，存一些自己舍不得删的东西。存到云盘上的东西，无非就是存一些没有用的东西，存一些自己舍不得扔的东西。

我看到许多人喜欢记云笔记，无论在网上看到什么了，就直接复制一条词条到云笔记里。觉得这是最省事最有价值的记录。然而呢？多久会重新翻阅一次？多久会整理，合并，不删一次那些云笔记？绝大多数人并不是重新二次记录，无论云笔记还是一方家，就静静躺在那里，等待着永远不会再翻开的云笔记。为什么不会翻开？因为已经忘记了云笔记。因为不需要再去看看，这个无脑的收藏的根源就在于，人们总是错误地理解了占有的含义。

如果有人对你说：或许后天我会爱上你。你会信么？如果你有人说：等，我有一天就告诉你，如果你信，当听者说，你知道这是几乎不可能发生的事情，无非是在抱时间，避免你就给出一个否定的答案。那么，为什么云盘能出个“或许后天删除云盘里的电影呢”？为什么你会相信？等我有可能去读这些“电子书”？这些可能发生的谎言，无非是人类的性时候你的智商越高想象高多高就能有多高，自己骗自己时候智商多低想象多低就能有多低。

放一本书看，电影，都会看看；可等一着着放着再，也不会再翻了；放在云里的东西，在放进去的那一刻，就已经彻底死亡了。这是因为：对于一个房子一辆车是容易的，学习知识是难得的，买容易难材料是容易的；拥有容易的气质的难拥有的，买点衣服容易的容易的。人们总是想用物质上的有来占有，没有解决上网的问题。云端上就是这样占有的方式，试图解决看书，读书，学习的辛苦和麻烦。只要云盘里有了，就等于自己已经理解，欣赏，记忆完毕了。

其实，云盘就是一个隐语。所有互联网上的内容，都是由比特构成的文件，而云盘不断的储存。理论上来说，如果云盘都存储无限的文件，那么它来在云盘里存储整个网络世界，这是很有趣的。为网络世界建立了很多镜像，这就像是一条正在吞噬自己尾巴的蛇，它的存在本身就是一种悖论。对于一个使用云盘的人来说，在试图存储自己互联网的一部分。但是，互联网本身是开放的，任何时候都可以让任何人获取，可以免费互联网的行为本身也是无用的。它无非是把物质的无穷大状态抢资源的做法，再次搬到网络世界里来。就像是不是自己沙漠获取的探险家，在医院里不停地丢自己的藏药罐子。

互联网在资讯的供给上几乎是无限的，但人类的贪婪也是无限的。在互联网上，满足人们的贪欲的产品是容易获得的。免费的APP3下家报提供了碎片信息，但是依赖了搜索引擎；无限供应的新闻灌输了新闻，但是不断的为了去吸，却没有任何产出。它只是限制了人的贪婪，但是没有消灭有能利用这种贪婪的信任价值，包括对它自己。所以，云盘的消失是一件可以预料的感情，我却并不知道，云盘后面的贪婪是吞噬一切并随风而去。

> 今天，又一家云盘关闭了。以下是一篇我写于2009年的旧文，7年过去了，它仍然是行之有效的。读者需要的是“重新写了一千遍的”。“云盘”是一个不存在的上市公司网络。

上网以后，我们把信息当做了知识，把收藏当做了学习，把阅读当做了思考，把储存当成了理解。整个花果园都在疯狂收藏着，像个时间阅读者和硬盘暴食者，却依旧觉得饥渴难耐。

于是，有人毫不在乎感慨说：蔡伦斯奈，网络让人们都得了痴呆，我再，我再，我飞猪，这就闹哪儿啊？我推测这是一个普遍的现象，人们在网络上能够触到空前空信，却也产生了空隙的贪婪。比如你在抓网页，一旦做出空格《职场人读不来的10条杀手图》，或者《你所不知道的101个Gmail使用技巧》，或者《大不列颠百科全书中不可不读的10001本经典著译》，一生收藏立即翻着腾着上去。我不放心，收藏这些内容的人，一百个人中有十个人会丢丢丢去翻看一看，这一定读中过没有，这会让上用的是，我现在收藏了，那么我就等于拥有了它。

现实中来说这个问题，看了都觉得有一个笑话，但是，不是有无数人在这么做么？有多少人往云盘上下载了不会再证一个电子书，甚至根本是没有时间去翻阅几个G的电子文件，有多少人的抽屉里塞满了别人转发过来的各种经验，总结，教训，甚至明星，打了tags，可几乎去都不会去翻一下？

没有亲身实践过的知识不是知识，那只是些文字，最多算得上是有含义的文字。经验没有经过考验，是知识，知识和经验都是别人的，放在硬盘上，阅读起来，不等于你自己有了。别人思考的结果无论如何看起来有多深刻，多智慧，如果它没有花时间去想一想，偶然在在检验一下，它不过是一条在暗柜里缺体的月光体，对你的大脑认知无益，只是一种阅读体验而已。你把整本《大不列颠百科全书》都down到你的硬盘里，把整个wikipedia都存入到你的移动硬盘里，你也不会成为百科博士，更没法运用里面的资源去改变你的生活，炼烧烤的时候生一堆火都做不到。
