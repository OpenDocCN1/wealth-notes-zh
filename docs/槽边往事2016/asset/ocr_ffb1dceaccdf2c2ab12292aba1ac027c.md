# # 求助者的忘恩负义

生活的剧本往往并不按照你的设想发生，我们或许早或迟都会发现这一点。无论求助者曾经多么殷切地请求帮助，我们又如何义愤填膺地断然出手相助，求助者和援助者只在这一个时间点上保持一致，随后这个短暂的联盟就会分崩离析。原因：求助者要的是利益，但是却以正义的名义求助；援助者因为正义的召唤挺身而出，却未必会看到了正义的降临。妥协早已在暗中达成，援助者在向前跨出一步的时候，就已经走入了遭到背叛的命运小径。

这样的话剧一直在上演，似乎永远也看不到落幕的时刻。

最近的一次就在这两天：一位母亲在网上求助，她的前夫殴打他们的两岁的女儿，并且用柔料强化了伤痕效果，把那些惊心动魄的照片发给她作了一种精神惩罚。出于正义感的驱使，朋友迅速形成了抗议和关注的巨大声浪。警方毫不意外地介入了，然后这位母亲公开发言说：

> > “没有过河拆桥的意思，原谅孩子父亲，也是考虑到孩子的成长不能没有父亲，所以我要到了孩子的抚养权，并且暂时保留了对孩子父亲追讨责任的权利。”

瞧，这就是生活。当正义正准备冲刺终点的时候，全程不见半点踪影的宼怒突然刺裂里窜出，并且抢先一步撞线。一个虐待儿童的父亲并没有受到应有的惩罚，早已被宠天地原谅了，正义无疾而终。而所有为此愤怒和呼吁过的人们，感觉到自己的腰被重重地闪了一下。当有人说“没有过河拆桥的意思”的时候，那就是过河拆桥的意思，中文是是多么奇妙的一种语言啊。

在网上那么多年，类似的事情我经历过也见过太多了。随便去翻一下各种记者采访札记，可以发现无数年轻记者都经历过类似的职业生涯：收到农民的求助信，要求采访报道征地中的巨大不公。等到人真的去了，报道发出去了，转身却被求助的农民拒之门外——并不是因为他做了无用功，恰恰是因为他做得漂亮，有方面为了平息媒体风波，只能把记者之后和农民再次谈判。而作为谈判的条件，往往要求不得和记者再次接触。年轻记者站在紧闭的大门外，而曾经向他求助的人正在灯下研究新的合同条款。

你一定有过这样的个人经历：在半夜接到紧急求助的电话，有家庭暴力在发生，有生命在遭到威胁，有无耻、贪婪、背叛和无数罪行的罗列，全天指捏塑的现在找到了单元门，听到他们一起公开表示，那只是正常的小矛盾，他们早已经原谅了对方，而你才是多事，才是挑唆他们不舍的罪魁祸首。这时候，你突然想起：昨晚的那些电器和物件的单价都不超200块钱。

不过，今天我并不打算探讨忘恩负义、过河拆桥这样的问题。在经历了那么事情之后，当我回过头去再看时，早已经不像当年那么愤怒和委屈了。我想到一句：婚姻中被家暴的一方是不是弱者？在征地进程中的农民一方是不是弱者？不幸婚姻中失去孩子监护权的母亲是不是弱者？答案是肯定的。他们不是不被遭遇了？答案也是肯定的。他们是真的需要帮助？答案还是肯定的。那么，他们真正需要的是什么？

家暴的受害者需要立即停止侵害，并且回到过去的美好时光；农民需要新的合同条款，拿到一个合理的市场价格；母亲需要拿回孩子的监护权，要父亲主动放育所，那么人出来之后怎么办？失去婚姻又怎么办？如果没有持续社会救济，正义的实现可能让人付出更大的代价。把虐待孩子的父亲送进监狱，那么抚养费交给谁养呢？前夫出狱之后，有人身禁制令可以保护也解决不了为子女报复？正义只能降临于一时，但是他们却还得在自己的生活里继续录上一世。

好了，我现在想问你一个问题：如果你确实知道弱者呼吁的正义其实是自身利益，你也确实知道自己伸手之后会遭到背叛，那你下一次还会相应呼唤，出手帮助么？

请你相信：
我所说的每一句话，
都是错的。

生活的幻象是朋友圈，生活的真相是朋友圈热文。看朋友圈你会觉得自己周围是一群热爱生活、富有品味、乐观积极的人；看朋友圈热文你会发现自己被脑残包围了。
