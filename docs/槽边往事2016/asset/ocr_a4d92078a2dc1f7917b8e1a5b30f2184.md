# 防弹咖啡初体验

周日起了个大早，专程跑去体验了一次传说中的“防弹咖啡”。之前就已早有耳闻，它说是能防癌防流行事物，无数科技迷迷的宠爱。

为了不至于第一次捧弹咖啡就翻车，我特意专门去查了资料，一路上反复背背，这份点心都不错——每份防弹咖啡有500大卡热量，它的定义是早餐，而不是饮料。

咖啡主持人是授奶拼盘之父马占凯来串了。已经是大名在北京科技圈的首席防弹咖啡师了。在个人本职务分内之后，他过着一种理想反思维中的生活——完全按照个人喜好良好随心所欲地活着。最近他最看好的是谷仓生意家和初创公司起名，因为可以引发他脑海中的联想风暴。每杯咖啡也有一个名称，免费、先占先得。防弹咖啡是马占凯的新宠，因为它满足了极客男对食品的想象：

防弹咖啡建立在新的饮食观念之上，不多喝（谷谷和大脑）中的说法一致：人类需要太多碳水化合物、脂肪利于大脑工作，以及生酮饮食和断食减肥。马占凯拿出了一套黄工作来制作，其中包括：

+   - 一份黑咖啡
- 一块无盐黄油
- 一些椰子油
- 一个搅拌机

方法是用30克黄油加上30克椰子油，冲入250毫升黑咖啡，然后用搅拌机高速搅拌60秒。于是，便得到了一杯黄美油类的防弹咖啡。根据马占凯的讲解，黄油的目的旨在提供大脑运行所必需的脂肪，可以增记忆且令人思考更加敏锐快速；黑咖啡不必糖的目的是为了提供足量的咖啡因，可以让人保持高度的清醒，同时因为其中的利拉妙油，能够减轻体重；椰子油是其中最神奇的部分，这是杜谷生植物黑官们研究成果，它可以将肠道中的长链脂肪酸变成中链，人就不必因此再发胖，总之，喝了一杯防弹咖啡下去，会让人更聪明也更苗条。

其实，马占凯的做法已经很简单了。按照防弹咖啡教程教主马德的要求，配好咖啡要一个咖啡杯，一个咖啡壶。要求防弹咖啡不可以选用市面上的咖啡豆，因为可能上面含有毒素，需要专门找毒咖啡咖啡，然后，黄油必须是黄纯黄油，也就说，生产黄油的牛必须散养，而不仅是饲料或者别的，这样才能够绝对有机。

马占凯演示了一遍，然后要求我们亲自动手去一杯，说是形成肌肉记忆，以后也能够保持整个流程最深最中的印象。5分钟之后，我得到了一杯新的第一杯防弹咖啡。怎么办，看起来就就像是一份咖啡色脂肪咖啡：

黄油和椰子油在搅拌机里经过充分搅拌之后，变到了咖啡里的一层泡沫浮在表面。我轻吸一口，马占凯一副紧张样子：“口感怎么样？”口感当然好，放了黄油怎么可能味道会不好？如果面包片里没有黄油，那就是面粉，面包片里没有黄油奶油，那就是糖份而已。从食品的角度来说，油脂、糖分会会让人心感。正当我一口下去就觉得世界太美好了起来。正如果烘焙的角度，能使用纯油的食物的只要奶糖和牛舌头，总能准几人对食物只要口感，油炸空气味道都会更好一些。

咖啡还是咖啡，但是有一般浓厚的黄油香。我入口的第一个感觉是：喝？这难道不是酥油茶是茶吗？说实在，防弹咖啡喝起来就是酥油茶，不同之处在于有了咖啡因而不是茶叶，另外，里面也没有各种糖粉粉末和咸盐。事实上，子弹咖啡的创始人正在西去印度的途中，吃到油茶的启发，回到的英国后一番改良了防弹咖啡。根据自己的说法，一番改良的瞬间就解决了他的剧烈高反应，而且让他一整天都保持清醒，连智力都得到了提升。

喝完一杯，我想我弄明白了自己的一个困惑：为什么防弹咖啡没有推广开来，成为一种流行？因为它的味道太像酥油茶了。我在西雅图时会冲一整天，其中就我。但是对于我每天要去调整一下来换换味道。但是，所有我接过的内部朋友，十个人里能有一半接受酥油茶不错了。对于其他能得，酥油的味道太太重了。而且，酥油茶能为了谁，谁会习惯一杯放了盐的苏式咖啡？防弹咖啡也同理，为了这样浓黄油味道的人来说，怎么做都是美味，无论搭配茶叶或是咖啡都不可。可对于其他人来说，就未必能如此了。

另外，对于女孩子来说，一杯含有500大卡热量的防弹咖啡，单是想一想这个概念，就让她们望而生畏了。那不是一杯咖啡，而是一杯回到古代到西方的食物。防弹咖啡2009年问世，到2012进入中国，但是到了现在2016年到来，也未能成为一种流行，只是小圈子里的一种乐思，大概也就因为这些原因吧。

至于说它是不是有那些神效？能不能真的提升智商减轻体重？我这么说吧，到今天为止《谷物大脑》的理论和依据存在很大争议，许多健康和营养论不出同样有争议。每次提到《谷物大脑》和生酮饮食的一些事情，很容易就引发发热，对，功效问题就自然而然的有了。我个人是从另外一个角度来对待防弹咖啡这件事情：

相信防弹咖啡的人，往往对科技感兴趣，愿意尝试新鲜事物。最重要的一点：他们大多数人都是全职工作，而这些人都在一起聊天、交换想法，是一件非常有趣的事情。

我不喝完咖啡的时候，在上午时间已经结束不忘了出东西来。在这一个小时内，大家变换了对话技术的看法，对互联网的个人判断，每个人从别人那里获得了一点什么，但都来自与新的人。那么，就像印群第一次开会的时候，会给陌生人烟管。或者说它咖啡，它是相当于大学兄弟的一个仪式，大家总得有个聚一聚的头吧？

至于为什么叫做防弹咖啡？当初取这个名字不过是为了营销方便，和子弹头关系都没有。此后的一整天，我并没有感觉到任何神奇的地方。如果真要静起来，我倒是有莫名其妙地产生了一种冲动，想去喝一壶正宗的酥油茶。
