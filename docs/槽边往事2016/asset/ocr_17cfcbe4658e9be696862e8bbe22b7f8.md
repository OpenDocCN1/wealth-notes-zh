# # 再见，松茸季

![](bbox=[0.05, 0.09, 0.12, 0.12])

雨水已经转凉，等最后几场雨来过，云南长达半年的雨季即将开始，而2016年的松茸季也将宣告结束。

在7月中旬的时候，松茸正好。我在《得到》的专栏和自己的微信公众号里卖了两期松茸，在整个过程里内心受到了极大的冲击。上网那么多年，写过那么多文章，第一次目睹留言里除了赞美就只有赞美，网友除了友善就只有友善。

有一位《得到》专栏的读者，由于信息交接上的疏失，她的松茸在上海和北京之间往返了三灰。当她向我表示歉意，并且准备做出赔偿的时候，她却反而安慰我说，谁不是为了得到赔偿，投诉只是因为她知道生鲜难做，希望引起我的关注，不要让人们失去对我的信任。

写那么多篇文章，无论什么观点，什么立意，总有人在留言里骂我。而当我卖松茸的时候，我收了钱，甚至寄错了货，却收获了最多的赞美和感谢。一度开始怀疑人生，为什么要写字感言？卖松茸要快乐多了，许多读者因为他们在周末有了一顿别致的晚餐而向我道谢，有些人甚至以松茸为由头全家团聚了一次。这是文章所做不到的事情，而自家乡的松茸却轻而易举地做到了。写那么多字多，却不如几头松茸，我觉得自己的世界观都要崩塌了。

转眼到了9月份，云南雨水陡然下降，当初看不上的低档松茸也炒到了一斤一千块钱以上，比鸡公的价格还要贵。读者不断在问：什么时候会有下一期？而我每次只能回答：等雨落下来。现在，雨水终于落下了，但是今年的松茸季也到了尾声。

我问过云南的朋友，他们告诉我今年的松茸季大概还能维持一周左右的时间。由于产量有限，而且是今年最后一批，价格要比7、8月时候高了不少。之前的精品松茸即便我去刷脸，也无法按照过去的价格提供。喜欢精品松茸的朋友，你们只能带着美好的回忆，期待明年雨季早些到来。

9CM以上的顶级松茸价格虽然上涨，但按照过往的价格还够接受，只是每日能够采集的数量不定。所以，这一次只能提供顶级松茸。在未来的7天里，会尽最大可能从全省调货。但也不要指望会有太多，因为以目前的产量，每天50公斤已经是极限了，只会更少，不会更多。7天过后，松茸就很成成为明年的事情了，希望这一次你的手够快。

松茸季短暂，而冬日漫长。作为今年松茸季的最后一季，我想向你介绍一位可以陪伴你度过漫长冬季的朋友，可以称之为“主食灵魂伴侣”的云南特产——油漫鸡枞菌。无论是米饭还是面条，加一筷子油漫鸡枞菌进去，甚至只是加一点油漫鸡枞菌的油，味觉上会有跨进境界的提升。所谓“好吃到呻吟”，说的就是油漫鸡枞菌这样的东西，它可以让你最平常的米饭也能在寒冷的冬夜里，放声歌唱曾经落在它们身上的灿烂阳光。

这批私家私家制作的油漫鸡枞菌最大的特点只有四个字：没有迁菇。

因为鸡枞菌的价格日渐高企，而油漫鸡枞菌需要晒晾新鲜鸡枞菌后过油，一斤新鲜鸡枞菌最后做成了几两鸡枞菌。所以市面之上的油漫鸡枞菌掺入廉价油是常事。打开瓶子之后，是一罐黑褐色的油，油底是一团可疑的菌丝。这次提供的油漫鸡枞菌和其它品类做一下对比，方法如下：

+   1. 开盖之后看一下油色，是不是清澄透亮的菜籽油？
2. 看一下鸡枞菌丝是不是很根可见，而且都是同样外观？
3. 抓一个云南人来，请他尝一口，看是否会落泪？

朋友做这批油漫鸡枞菌是因为受够了市场上的同类产品，无法容忍干菇在鸡枞菌油里洗一个澡，就敢跳出来自称云南山珍。所以他不惜工本，自行做了一批纯鸡枞菌做成的油漫鸡枞菌。

需要说明的是，他在里面放了云南丘北辣椒，所以略带辣味。同时，他还放了一点川花椒，所以略带麻味。为了保留鸡枞菌过油之后能保持鲜辣的味，他专门选用了火把鸡枞菌，所以除了香之外，还带甜。请根据自己的口味决定是否购买，如果不能接受任何一点辣味和麻味，请把机会让给别人。

油漫鸡枞菌一共500瓶，是我能搜罗到的最后一点存货。卖完之后，请继续期待明年。希望松茸季过去之后，它能在寒冷的日子里多陪伴你一点时间。无论是热腾腾的米饭、馒头或是面条，来一点油漫鸡枞菌，你都会看到世界的光。
