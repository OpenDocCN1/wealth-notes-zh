# 请假条

如果在这个小长假里，你的脑袋像衣服不洗、洗碗不洗、孩子不打，想方设法地想要单独溜出去3个小时，请不要问为什么。也许我知道原因，在这里我愿意为这个人专门写一张请假条，希望能够获得你的批准。

电影《魔兽》上映了，事情就那么简单。

不忙擦嘴，也不忙翻白眼。我没有和你开玩笑，事实上，我觉得这是一件非常严肃的事情。电影《魔兽》改变自暴雪公司的经典游戏《魔兽世界》，有人叫WOW，或者叫山口山。但是，对于我这样的人来说，那不仅仅是个游戏，它曾经是整个**世界**。而你也很可能很难理解，我们为什么把暴雪公司称为“暴雪爸爸”。

不过我没有打算和你聊情怀，请给我5分钟时间，让我把事情讲清楚：

游戏并不都是打打杀杀，或者挂在线上刷金币，起码《魔兽世界》不是这样的。记得我第一次玩这个游戏，才升到10多级，完全是个菜鸟，但是我没有打怪，没有升级，花了整整一个星期时间，在游戏里除了跑步什么都**没有做**。从游戏里的大陆东南角，一路跑到了西北角。

那是一张巨大的地图，按着前进箭头5分钟不动，也只能前进一小点距离。因为我，是个菜鸟，沿途会被各种等级高到听不到的怪物袭击，往往对方轻轻锤我一下，我就立刻倒地身亡。然后我会在最近的一个复活点重生，重新再跑一遍，边跑边祈祷：不要看见我，不要看见我，不要看见我。因为这么往复奔跑，向死而生，我花了一周时间，夜夜上线，夜夜跑步，才终于抵达了我的目的地。

一路上我看见了各种壮丽奇诡的景色，经过山林、雪峰、沼泽和荒原，看见过无数次日落月升，目睹身边的无数次杀戳，就像是在一个真实的奇幻世界里奔跑，根本听不见电脑的嗡嗡声和窗外的汽车喇叭。你问我跑那么远的干什么？因为我是听说，在大陆东北地区，有一片海滩，那里的日落是整个大陆最美的，我**想去哪里看看**。当我到了那里，真的看到了金色的光芒倾泻而下，人鱼群洋洋洒在沙滩上。在那一刻，看着眼前的景色，想着这一路的艰辛，我想哭。

是的，你没有看错，的确有那么个神经病，烧着游戏点卡的钱，什么都不干，在一个游戏里跑了一个星期，就为了在**低级别**的时候，看一眼高等级玩家才能欣赏得到的日落。这就是暴雪的魅力，它的游戏让人为之疯狂，而且会对它愉悦自己的方式上瘾，再难以接受其他的大型游戏。

**我不是试图让你理解游戏**，我是想让你理解游戏里的人。
也是所有有游戏都是韩国的泡菜游戏，从到尾砍砍砍，也不是所有玩游戏的人都是为**了**在游戏里虚幻的满足感。我**喜欢《魔兽世界》**，是因为喜欢它的想象力，和在这个游戏里无穷无尽的可能性。你知道吗，在这个游戏里，**你甚至可以不用升级打怪，完全可以钓鱼为乐**。别人在你周围打打杀杀，而你手持钓竿，试图钓出地图里每一种鱼，成为钓鱼大师。

在那个暴玩家耳熟能详的“鱼别丢”故事里，一位玩家突然被一个才1级的陌生玩家拦住，对方要求交易，送过来钱、各种杂物和一条鱼。这人很奇怪，不明白发生了什么。那个1级的玩家用拼音发来两句话，然后转身就走了：

--Songnide（送你的）
--Yubiediu（鱼别丢）

那条鱼有22磅重，这个1级的玩家一定花了很长时间钓鱼，才终于钓上了一条大鱼，一直珍藏在身上。在游戏里，一个人把身上所有的东西都送人，意味着他会退出游戏不再玩了。这个要离开的玩家，之所以把鱼拿出来送人，而且叮嘱不要丢掉，是因为那条鱼是他的珍爱之物，曾经给他带来了无限欢乐。如今他离开了，但是他把这份欢乐送给别人，希望对方能够体会。

所以，喜欢《魔兽世界》的人，也许更多的是喜欢游戏里的这种人际关系。它不同于我们日常的社交，但也有现实生活所没有的那种真挚。起初，人们是爱上了这个游戏，到最后一定是爱上了游戏里的人。一直到今天，“**yubiediu**”都依然是《魔兽世界》玩家的接头暗号，你可以试着在网上说一下，看看会发生什么事情。

昨晚《魔兽世界》在中国首映，凌晨1点，票房就已经突破了1.5亿。没有女神，没有小鲜肉，没有韩国人，是谁撑起的票房？这部电影在欧美票房一塌糊涂，但是在中国看完首映之后，有一个人说“就算是PPT也死而无憾了”，猜猜他们是谁？

他们中最为年长的人已经进入中年，最年幼的也不再年轻。谈及游戏会让一个成年人很局促不安，他可能不愿意和别人谈这件事情，也不会谈他对魔兽的情感，因为那是过去，太太私秘，也无法希望过别人能理解。但是，当“LokTaro Ogat”的呼喊声响起，他就会情不自禁地长身而起，热血奔腾，转身提起战斧奔向荒原。

这个人可能就在你的身边。请慷慨地给予3个小时的假期，让这个人去一次电影院，能够平息内心的躁动。相信我，你会因此而收到发自内心的感谢，对理解的感谢要比其它谢意更为粘稠一些，足以把人牢牢粘在一起。

我再一次恳求，请您批准。
