# 社会是最好的商学院

这两天发生了一件很好玩的事情：在我长期关注的中国漫画圈里，一群画师突然集体爆发地控诉自己在的公司，并且要和公司对簿公堂。原因是他们认为多年来公司完全交由公司控股说，公司从作品包装能力上也告吹，造成自己作品影视化过程受阻，影响到了个人利益。

漫画迄今为止在中国还处在亚文化的位置上，拥至多为85后、90后。所以，虽然事件在漫画圈里闹得很大，但是在圈外却显得波澜不惊。我相信这里的多数人对漫画并不没有太多兴趣，不过，这个事件从商业的角度去分析，却是非常有趣。不信的话，我来拆解一下给你看看：

漫画家的合同一签是五年，为什么五年后漫画家们不愤怒？为什么现在漫画家们愤怒了呢？为什么五年前漫画家们不发通告，宣称要维护个人尊严？为什么五年之后他们的个人尊严突然孵化成功，从天而落了？因为热钱在不断涌入漫画圈。

为什么热钱在不断涌入漫画圈？因为热钱已经横扫网络小说领域，但只有著名的作家作品，早已星已被瓜板殆尽，而且版价格已经高到了离谱的程度。我认识的一位女作家，她的作品主要是写给初高中的女生看，有庞大的读者基础。

这样一位作家的作品报价是多少呢？最新消息说，她的一本小说加十四集电视剧剧本外加一部电影的改编，市场上给出的价格是4000万人民币。正因为小说版权已经卖完，所以热钱的下一个目标就对了国产漫画。

在过去，漫画家的工作非常辛苦，但是收入却不稳定。能否赚钱，取决于漫画杂志能否刊载他们的作品。因此，在那个时代里，有公司愿意和他们签约，帮助他们联系杂志发表漫画，再给予一定的佣金，都是令人艳羡的事情。为此，漫画家签约了，把签约期间的作品版权留在公司，换取安定的创作环境和相对稳定的收入，这是非常正常合理的交易。现在情况变了，一旦热钱涌入，开始争夺漫画版权，漫画家的身份顿时就涨上去了。而且，看到小说作者的收入，漫画家对自己的收益也有了新的预期。

因此，曾经被视为盟友和帮助者的公司，如今看来就是个障碍。甚至要比障碍更糟，因为作品版权签给了公司，这就意味着影视改编、游戏改编权和周边产品授权产生的收益，自一开始就拿到，不专归属于公司。如果转到自己公司，或者自己独立做工作室，又不能继续使用原来漫画题材，必须从零开始，重新自己的新作。漫画家当然很愤怒，当然坚持网络上向粉丝发出呼吁，要求大家支持自己。

人还是那些人，公司还是那家公司，合约还是当年的合约，商业模式还是那个商业模式，什么变了？整个大环境变了，人心也就变了。当年成立一家公司，为漫画家打理事务性工作，充当经纪人的角色，那时候对于漫画家是好事。现在做同样的事情，在漫画家那里看来，就是阻碍他们赚钱，而且占了他们的大便宜，需要全社会共同声讨。

在资本的眼里，一方面感谢漫画公司在多年来开拓市场，培养漫画家和读者；另一方面则认为这种公司的存在提高了谈判的门槛，阻碍了资本的快速流动和增值，它的存在不是资本的助力，而是一种障碍。

谁错了？谁都没有错。谁都没有错，为什么会打起来？因为现在到了分蛋糕的时候，人越少越好，自己离蛋糕越近越好，最好是自己操刀亲自切。
