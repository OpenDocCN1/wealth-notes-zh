# 写在《罗辑思维》四周岁

今天早上7点45，罗振宇在朋友圈了了这样一段话：

今天是《罗辑思维》四周年生日，是我坚持每天60秒的第1461天，距离我结束这份坚持还有6年。

没有算4365天=4年等于多少，但是我知道每多4年365天，再多一天，所以，尾数第1应该是对的。这就是我和罗振宇在时间上的不同理解，他的时间作为一个单序列已经记录了多少天来剩余多少个。我更关心如何划时间，以思考如何分析所带来的结果，却并不关心时间的方向。

人们往觉得罗辑脑起的速度太快了，怎么就是他看了从上面的说到结业，可以看点一点。当人们说到创业的时候，往往会问：两年够了吧？三年应该够了吧？在我们所处的时代里，连成功也必须讲效率。人们对此成功的心理预期是两年了，两三年事情应该成就，五元就应该上市了，七年就该退休享受生活了。我觉，这大概是创业企业死得快的一个重要原因

罗振宇先来定了一个十年期，最后能否认谁也不知道，但是他的心态却因此发生了改变。当一个个人以十年时间作为规划的时，他对和两年、对业规、乃至对于的十年规划那些两年规的区别在哪里？在于十年规已经预计了可能遭遇的困难和危险是一条高低起伏线点，而而而风险规划一年定低线两点，中间没有意外，所以上面往下掉死的人最多。

目前看，制订十年期计划的人要死得更快。

我和罗辑最早的网名，并没有打过官交道，来说，他第一次约见我是出出书的事，我并不是特意的究是什么。因为来找我们联的出社的太多了，了了人，也讲过许多次，所以我对罗辑并没有抱有太大希望。时我答罗辑，一是因为有罗大宇这个人好，一是因为约见的饭馆起来不错。我心里想着，"如果这没不成约，起我饭，出版社的咖啡我算是够了。

会基本是在极为率的情况下就定下出了策划，我心里并没有任何底，这些年里过的太了，诺漂亮的也太多了，好在饭确实，我埋头苦吃，乎我料，一之内合作目已经出来，提给我们的书他出版集，让我决定交给的—一年为的初文集，且决定需要去哪此，快定版内容。

随后，我的在罗辑上，半年不到卖了五万，无书是装，设计还是纸张，都进团队的评不对外，都来自对外的评价无外和思维团队一起事之后，他们留的印象是效人，人。

如果一个团队十十年，而且是以这样一个做事都过程，那么，无论做件事大概会有所成就。
