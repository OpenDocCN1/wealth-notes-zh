# 《失败学》教程

去年在互联网上一直流行分析失败的案例，认为和成功相比，人们可以从失败里学到更多东西。但是有了最后这种分析结果也没有流行起来，看来九成九的互联网创业者们，失败的原因实在是太多，事情变化的速度太快，以至于在短时间里根本分析不过来。

但我还是觉得这是个好方法，尤其适合我这种刚租人生做第一段的。在周围看着教如何变得更更高、更快、更强的正能量人士，更需要我这么一个专业负能量人士。和你一起研究一下如何通过从失败中学习以达到更高、更帅、更白、更富、更瘦的目的。

我们畏惧失败。我们有多畏惧失败，就有多渴望成功。正如人们有多嫌弃人生做第一，就有多热爱人生做第一。我们生活在人世间，但是只想要在一个天堂，一个只有光明没有黑暗，只有欢乐没有悲伤，一个只有正面没有反面的世界。而成功就是通往那个世界的阶梯。从此以后，我们就安住在永远的幸福之中，周身散发着灿烂的光芒，再也不会发生任何改变。

持有这样的想法，就是悲剧人生的开始。

![](bbox=[0.05, 0.42, 0.95, 0.55])

喜欢成功，喜欢别人的成功故事，是因为我们自身失败的次数太多。我们渴望的不仅仅是成功本身，而且是别人不要吹牛之力完成的潇洒和漂亮。因为我们自己的人生经验告诉我们的，哪怕是每天早上按时起床这么简单的故事，也要拼尽全力努力，却依然会遇到一堆困难。作为一个成年人在这个世界上，从来没有任何事情是轻松容易的。我们知道这一点，这是生活的真相，但我们从来都避而不谈。

我们该如何成功。

当我们长久地专注在成功之上，成功对于我们就变成了一件必然发生的事情，也让我们越发讨厌和畏惧失败。于是我们开始拙拙分析现实世界的情境，不停地寻找那存在在，我们认为那里是通往成功的偶然。可是要认真说起来，成功才是人生活中的真正偶然。唯有失败，有巨大的、可计数的失败才是一个人中的常态。一方面是不接受失败的存在，一方面是清楚知道失败是常态，最恰当的就是就是既要不前，不敢去尝试任何尝试。因为计划下来就知道，唯有不动才是最安全的，完全避免了对最终结果的判定。

为什么这些拖延症越来越流行，你现在明白了吧？

成功总有运气的成份在。马云如果遇见一天发大洪水的时候世界银行，也许他就没有今天的阿里宝。马化腾虽然当年报价45万，也许QQ早就交出去了，不会再有腾讯帝国的存在。我们分析他们的什么呢？创业从英文老师开始？开发一个软体系统需要高品？我们从经典案例的启示来看，软体宝量、产品榜样贴点，可以只找出一批人来，但是他们未必成功。我们分析他们的思路，他们在关健节点上的决策分析，但最后他们的那一步一经过就水过去了，他们当时做法在此此时此刻也许会是全然致命选择。

即使我们完全笃信针对成功的分析，也应该明白一件事情：关于成功的方法论只能保证我们在大量重要的尝试中略微占优，并不意味着我们成功的次数会有明显的下降。说白了，因为我们的内心坚信在做的是对的那个，要比其他人多可能坚持一会儿。就多坚持的那个一会儿里，幸运会转向正在挖坑的我们，把我们从事的坑里哄天上来。

有人会反对说，成功的案例尚未研究不完，哪里能去分析失败？那我的回答是：你刚才说，当你想要更快更省力气地到达成功的彼岸，还是迁寻更多人的失败道路呢？我们没有那么特别，只要勇身出发朝着目标前进，有极大可能指到就进了前人的失败之路的车轨道。鲁迅先生早年说过，世间本没有失败者遭遇路，失败的人多了，于是就有了路。巴尔扎克也会经说过：成功的人具有成功的路径，失败的人都是在相同失败的道路跑上。和成功相比，失败显然数量惊人，但有规律，而且错误的种类是有限。

不要小看错误，人性的特点就是相同的问题上反复跌倒，就像多次不长记性。而人性的弱点同样在乎，我们每次用同样的错误去尝试不同的道路，却希望得到完全不一样的结果。所以，《失败学》最大的优点就在干它让我们直面问题的缺陷，通过错别人人的失败，尽可避免别人相同失败，也就是说，跌倒的次数越少，摔得越轻，距离成功也就越近成功。归根结果，没有路摔得疼，或者没有摔到筋也就剩下一个动动的身体，你听了试图者按照故事的法去大步流星了一回，然后发现自己还是像谁都没。于是你是别人毕竟功了，所以你只能怨自己，换一个故事重新练这一这就是《成功学》之所以特别卖得好的原因。

我们《失败学》则完全不同。《失败学》认为失败是人生常态，需要平静接受这一点。我们得去认真分析每一次失败的原因，并且学会比获得成功的结果更重要。通过总结和分析，慢慢调整自己的心态和方法，坚定不移地相信：人生就是一连串的坑，但希望填坑的自身是有利的。所以，我们争取次次掉得更浅一点，翻翻而起的时间再快一点，比出得最低那一个早一步到终点就算赢了。也正因为如此，我们挑战人生的一切限制，为了什么而努力，到新的挑战。我不会愿意拖延症、脸皮差、差无能力、社交恐慌症、电梯内社交障碍等等等疾病，因为我们根本不相信有永恒的彼岸存在，根本不相信到达那里之后就不用面对人生中的一切变化和挑战。

如果你承认以上的看法，那么请你和我一起手按《失败学》的封面念诵着：

愿生活赐予我足够多的失败，可以让我们从中汲取警记；让我们直面人性中的软弱和愚蠢，祈术我们有直面挑战直面自己的勇气，以及从失败中再次站起来的斗志。我们不奢望一时一地的胜利，不渴求每时每刻的成功，也不奢望我们探寻到人生中的捷径，更不谋求统计学里的小概率事件降临。我们日复一日的事件事，终究无成功的意义，抓紧一分一秒去前进。我们知道，做尽我所能，做好最坏的打算，接受一切可能的结果，则成功自然蕴藏其中，这就是人生的应有之义。

阿门！
