# # 中年与重生

![](bbox=[0.03, 0.1, 0.09, 0.14])

前几天看了一部小成本文艺片《黑处有什么》，导演讲故事的点很巧妙，在讲述一个女孩子的青春期时，一直伴随着连环强奸杀人案作为背景。青春期是人生中第一个危险阶段，和我同年龄的小伙伴第一次发生大规模凋零就在这个时期。要么是生命无征兆地结束，要么是人生从此就开始躺平。青春期的少男少女和儿童时期的最大不同，就在于认识到了性的神秘欢愉，为它深深吸引却又心怀畏惧。

而在这种对神秘、却又知晓了死亡的生存。在这种残酷的背景下，青春的花朵盛开得极为绚烂妖异。所以，王小波才会 在《舅舅情人》这部小说里借着终南山来的神秘少女之口，道出了她从白色骸骨上领悟到爱情真相：爱情从最纯粹的恐惧中生出来。

青春期之后，第二个危险阶段是中年。中文里的“老男人”这三个字，在老男人嘴里说出来有一种含蓄的自矜自夸之意，但是在其他人中却越来越带有讥讽讽刺之情。原因是中年人抑制不住地吹嘘对自己目前生活的沾沾自喜，丝毫没有觉察到在这种沾沾自喜中隐藏着随后接踵而来无可避免的衰败。但是，在旁人眼中这种下滑的趋势再明显不过，因此所有的沾沾自喜都带着一种喜剧里小丑扭曲的效果。越是矜夸，越是严肃，越是当莫，也就越发让人发噱。

在这种喜剧氛围里，人们很容易忽略中年里潜伏着的威胁，许多人的生命从这个阶段开始就事实上结束了。也许是某个下午开始，人就活在安逸的重复里。不再有变化，也不再有任何挑战。用一种极为缓慢的爆点下降方式，逐步和现实脱开距离，一点点下坠到无足的地步。这个过程持续而稳定，不会像青春期的危机那样酷烈，反而让人误以为是幸福的正常表征。

另一部分人很清醒地知道衰败已经开始，却早已经失去了青年时的求变勇气。就像是作战时旧久长的士兵，已经完全失去了战斗的能力，倚在战壕上眼睁睁看着敌方的炮火朝着自己推进，却根本起没有起躲避的欲望。你很难从外表区分出这种中年人，我是说，你无法从表象分辨——是否已经从心里开始逐步丢掉了，因为他们有时候甚至表现得非常积极投入。

当一个人否定了自己的将来，也就同时否定了自己的过去。在已有的和有的大人生和生活里搜寻不到任何意义，那么，人很容易变成那种通过控制别人的人生和生活来找寻自我价值的人。不是这样么？观察一下你周围试图控制子女和总是请求改变他人想法的人，他们自己有任何称得上是值得过的人么？如果他们 在别人身上投入的精力和时间，如果花在自己身上又会带来怎样的不同？但是他们拒绝那么去做，不是这样么？

人要熬过青春期的凶险，才有进入成人世界的幸运。而成年人同样要熬过中年，才可能见到晚年的风景。站在人生的高点上，无论是想当然认为自己会这样永久地生活下去，熟悉一切，掌控一切，只需要静候待到岁月流逝，还是悲恐地认为从此之后只有无尽的下坡路，一切都将在丧失，一切都在破碎，任何努力都无法阻遏自己滑向终点，这是绝大多数人的两种选择。我们在网上，在生活中，看到的那种老男人的不堪，都是因为这样的选择。

但是，还存在第三种可能。某些伟大的艺术大师甚至还能有“晚年变法”——在所有人以为他已经穷尽了一切变化的可能，耗尽于所有的创造力和想象的时候，却还能从往昔的灰烬里奋力挣脱出来，重又绽放在世人面前。马蒂斯在无法拿起画笔之后，并没有就此销声匿迹，而是拿起了剪刀，用剪纸的方式延续了多年的艺术生命。直到生命的暮年，他还再次转变，尝试建筑设计，建造出了也许世界上最独特也最美的罗朗里奥礼拜堂。

因此对我来说，当我开始步入人生的中年阶段，目睹了种种同龄人的表现之后，我强烈地意识到自己需要一次重生。彻底摆脱过去的经验，过去的见地，甚至是过去最娴熟的技巧，仿佛过去的岁月突然宣告终结。然后，能再次用儿童的眼光重新看待这个世界，寻找到点燃生活激情的方法，勇敢去探索未知的领域。当初我走上了少有人生的一条小径，因此得以看到了一些别样的风景。我希望这条路还能延伸下去，带我继续向前，而不是从此止步，更不是安于现状。我希望我能有这样的勇气，希望我能打赢得过时光。
