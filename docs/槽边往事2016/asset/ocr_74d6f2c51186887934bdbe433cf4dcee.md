# 封神前夜--《人类简史》读后

以色列70后历史学家尤瓦尔·赫拉利的《人类简史》是一本学术著作，但是它现在正在享受通俗文学的待遇——麻烦别打断我，我知道你已经看过了，现在的重点是我刚看完，而不是你读没读——2012年在希伯来文出版，2年以后的2014年11月中文化发布。到了今年的4月，《人类简史》中文版第23次印刷。全书连注释一共430页，售价高达68元。

我是因为受到互联网圈的影响而接触到的这本书。一位我非常尊敬的互联网产品经理在微信群里做了推荐，于是我在没有看到任何书评或者推荐的情况下立刻掏出手机订购。

看完之后，我查阅了一下资料。发现《人类简史》进入中国互联网圈，是因为在2015年1月，Facebook的总裁扎克伯格在自己的新闻阅读计划里专门推荐了这本书。周鸿祎的冤家傅盛甚至为此在今年3月亲自奔赴以色列，只求见作者一面。

《人类简史》受到中国互联网人士的追捧并不奇怪，并非只是因为它的受到了扎克伯格仁波切的开光加持。此前，它已经自曝过它对KIK的狂热，一本《失控》卖到洛阳纸贵。KK是未来学家，负责预言人类社会发展的未来，赫拉利是历史学家，用一本书的篇幅浓缩了人类200多万年的历史，最后同样做出了对人类的预言——**从动物到神**。

互联网世界处于极速变化之中，今日的弄潮儿随时可能成为昨日的泡沫，在这种焦灼的情绪驱使下，对业者关于一切关于未来发展的预言都趋之若鹜。如果可以，我还想加上一句：

这个行里面的人，从未像今天那么笃定，相信人类科技爆发的奇点即将到来。而这次大爆发到未之来，互联网一定处于最前沿。从人类文明开始以来，从未有过类似今天这样的时刻，你的第一次选择，可能永久性地震响你自己的子孙后代，决定了他们在未来是控制机器的大脑，还是为机器所役的大多数。或者，他们可能是DNA的水平面，永久地获得属性增长，成为超级人类，进入世界的控制阶级而非被控阶级。最紧迫的问题是，这一切并不会出现在遥远的时间长河里，现在数年内就可能看到变化的端倪——他们已经在讨论50年内人类实现永生技术的可能。

当某种未来即将到来时，因为太过迫切反而会让人对此产生动摇，于是需要从过去寻找自己可以抵达未来的理论支撑。《人类简史》适时出现，历史学只是它的包装，未来学才是它的根底。作者利用自己的博学啊和笔力，把人类200万年的进化发展过程归纳而清晰地整理出一条线索。在这条线索上雄辩地论证了三次革命把我们送至今日：

+   - 认知革命让我们从普通动物变成行星霸主；
- 农业革命让我们定居，并且发展出国家、族群这样的想象共同体；
- 科学革命让我们定下马力发展，把所有赌注都下在明天的求新增长；

而在三次革命之外，金钱和资本主义把整个大陆黏合在一起，所有人的命运从此密不可分，成为整个世界的一部分。

建筑了这样的历史框架，那么作者究竟有何魅力可以让人手不释卷，一口气读完？答案是颠覆认知。从开头到结尾的每一个章节，赫拉利都保持一种略略嘲讽的口吻，对业者耳熟能详的历史事实全部推翻和判了一审。他毫不留情地剥掉了人类自以为中心的想法，揭示了人类不过是一种普通动物，而且我拥有少量认同的类似生物，只不过人类作为智人，冥灭了所有兄弟姐妹。它攻破了自由市场资本主义，把现代社会的生活方式归结为消费主义，几乎所有中产阶级都得罪了个干净。

他甚至把人类文明早期的农业革命翻转过来，宣称不是人类驯化了小麦，而是小麦驯化了人类，永久性地改变了人类的行为，使得人类从狩猎采集生活中脱离出来，彻底束缚在麦田里过上了农耕生活。而且，在他的分析里，人类在农业时代反而比之前更加悲惨，完全是陷入了一个巨大的骗局……

在这本书的最后，赫拉利对人类的未来表达出了相当程度的悲观。科技和资本主义的结合，使得人类对自身改造变得势不可当，于是，耗费上千年时光，虚掷了无数生命换来的平等观念受到了严重的挑战。当人类可以动物物生一样“改造”自身甚至“创造生命”，那么，人类之中平等可能会在未来之前，而DNA层面就已经先作决定。与此同时，人类如何定义“人”，也将成为未来最大的问题——我们可能亲手杀害自我灭了人类这个物种。

这就像是一个寓言：为造物主所造的造物最终成为了神，而代替却是毁灭了自身。你永远也别看不到神给出的解决方案：向佛求教，认清自己，正确认知，正确认识。然而，当你读到佛家说，这世界本就是一具神佛菩萨开的手腕的时候，可能会和我一样觉得被闪了腰。哪怕我本身是一名佛教业余爱好者，也觉得这种宗教主义，以至于使得前面的所有论述有了一丝漂浮。因为《人类简史》的结论，大致根本不关心人族的生死——按照佛教的说法，最深刻的佛法则保存在大海深处的龙族那里——早就看好了你们人族能唱最深的歌法。

《人类简史》在中国的流行，无关历史的真相，也无关未来的方向。它更像是当代中国人，尤其是中产阶级内心焦虑的外显。这种焦虑不但使得《人类简史》、《失控》成为热门书籍，也使得针对历史的宏大叙事在沉寂多年后再次流行，正如刘仲敬在历史爱好者中的突然翻起。但讽刺的是：

+   1. 和《人类简史》类似，但都是深刻而专业的《人性中的天使》，并没有在中国获得多少读者，哪怕阅读后看对人类社会以及人性产生更为深入的见解。流行自有流行的道理，但是读者关心的从来不是书中讨论的议题；
2. 即便在资讯最为发达，信息交换最为便捷的互联网界，一本书的流行也耗费了两三年。我们并没有如同《人类简史》中那样，或者两种非人的方向迅速发展。这本书的流行，依旧靠的仍然是古老已俗的口耳相传。

如果作者的预言是真的，那么我们今天分明就处在成神的关口。也许就在明天，我们终究成为造物者，成为神。现在，我们正处在封神前夜。所以，各位预备省悟，有一句话可以找这本书来读一下。它足够有趣，最低限度比综艺节目更有趣，也值得在餐桌上和朋友一起就着啤酒讨论。

祝你周末愉快！
