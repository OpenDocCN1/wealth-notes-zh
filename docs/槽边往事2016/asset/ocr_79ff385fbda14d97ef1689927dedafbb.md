# 站在人的立场上

美国佛罗里达州奥兰多同性恋酒吧枪击事件，迄今为止造成了50死53人受伤。我看了一整天的中文互联网，发现大家保持着一种相当暧昧的沉默。以往为了拼10万+而第一时间抢抢热点的媒体、自媒体，最多讨论一下唐川普是否因此而增加当选机会，或者隔着太平洋讨论一下美国宪法第二修正案的存在。这是我上网那么多年以来，所见过的最诡异的景象。

不就是因为涉及到了同性恋恋情么？不就是涉及了穆斯林极端主义么？所以，发现自己站位困难，没有办法在此时表达自己的看法？担忧无论什么话，都要冒着失去粉丝的风险，所以干脆一声不发？

我越靠近中年，也就越偏向保守。我对于婚姻、家庭乃至宗教的态度，也逐渐偏向保守。虽然我知道，随着私有制而兴起的婚姻和家庭制度，随着时代的前进正在趋于解体。人们普遍倾向于晚婚甚至不婚，对于两性关系的理解也日益宽容。但理解和尊重大多数人目前对婚姻家庭的看法，我知道人们恐惧太过快速的变化，抗拒一切他们觉得可能危害稳定和婚恋的因素。因为观念成熟需要许多世代的累积，但是摧毁知在一夜之间，而且在摧毁之后人们会无所从。哪怕我们明知知道娃娃不是生命，但也不会轻易把它从孩子的手里抢走，然后扔在地上，证明给他们看——这就是一团布头和线。

但是，在奥兰多发生的是另一回事。

在这个世界上最，可能会 有一个男子亲吻一个女子，也会有一个男子亲吻另一个男子，还会有一个女子亲吻女子。对于这三种情况，我们可能会有不同的观感，会有不同的价值判断。无论我们赞同或反对，这都是文明人的尺度之内进行讨论。但是，因为看到一个男子亲吻一个男子，或者一个女子亲吻另一个女子，就用枪举去发表自己的意见，这是赤裸裸的谋杀，更是纯粹的是恶。当有人用肉团毁灭的方式代替讨论和对话，无论我们自己对亲吻者持有怎样的价值判断，我们都该明确地表示反对。

即便像我这样持有保守价值观的人，有时候也不得不诚实地面对一些两难问题：如果我的孩子是个同性恋，我是否支持他/她？都说父母之爱是无私的，那么这种无私是否涵盖孩子的选择？尤其是这种选择和自己的价值观相抵触的时候，我是应该去“改造”孩子，还是修正自己的价值观？我们婚姻和家庭的价值之上，那么我是否因此就可以否认在同性之间也存在同样真挚的爱情，是否因此就可以否认一对同性爱人之间彼此的承诺是神圣的？进而永远不考虑他/她们的关系受到《婚姻法》保护的可能？

在奥兰多的屠杀之夜，一位叫做Edward Sotomayor Jr.的34岁男子，为了保护他的同性恋恋人，用背部遮挡凶手射来的子弹，不幸罹难。当子弹迎面而来的时候，他选择让自己所爱的人多活一秒。即便是世界上最为坚定的异性恋者，大概也不能比他做得更好，能够做出更为勇敢的选择。即便是在最保守的立场上，我也没有任何理由怀疑他不是为了真正的爱情而慷慨赴死。当一个男子吻上一个男子时，当一个女子吻上一个女子时，同样那是一个吻，同样是一种体温，同样值得我们尊重。

如果是50个平民遭到屠杀，人们会愤怒谴责；如果是50个无辜的孩子遭到屠杀，人们会哀嚎狂怒。但是，如果是50个同性恋者遭到冷酷无情的杀戮，我们却还要扭去讨论条规的必要性，讨论这一夜对川普是否希拉里有利，装作看不见满地的鲜血。

在所有的价值之上，是人的价值；在所有的立场之上，是人的立场。人不应该因为自身持有的性向或者宗教而遭受杀害，这应该是所有人的共识。如果我们还对这个人类文明社会保留某种信心的话，此时此刻我们应该去检讨这种暧昧的沉默背后究竟是什么。这关系到我们如何看待自身，如何看待世界。以及我们会把怎样的一个社会交给我们的下一代。
