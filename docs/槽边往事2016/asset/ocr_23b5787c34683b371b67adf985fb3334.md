# 当然是霍洛维茨

在上周的周末福利里，我提供了20张《雪枫音乐会》的门票。考虑到人们见到免费的东西总是会第一时间去抢，但是等抢来了又不知道有什么用，所以我设置了一个门槛，要求抢票的读者要先回答一个问题：

有一位俄罗斯裔的钢琴家，他弹钢琴的姿势与众不同，手重在演奏时似乎是平摊开来，用指腹按压琴键。但是，他的左手力度几乎成了他人演奏风格的标识。请问他的名字是？

答案是霍洛维茨，当然是霍洛维茨。

回复里有各种“诺夫”，各种“斯基”，大概半小时之后，才有第一个人答对。早在2014年的时候，我和南派三叔一起制作了一个微信群里的解谜游戏，当时我们在一段就开始定制了一个制作谜题的硬标准：答案要没法直接搜索到答案。许多人大概是直接搜索“俄罗斯钢琴家”，甚至都不知道加上另外一个关键词“手掌平摊”。

现在情况变得有一点不一样了，相信看完这篇文章之后，你会对霍洛维茨留下深刻的印象。知道和钢琴课上的教学不一样，霍洛维茨演奏钢琴的时候绝对不可能掌心握得下一个鸡蛋，而是用一种平摊手掌的平行触键演奏方式。你还会想到，即便用如此怪异的方式演奏，他左手的力度也让听众目瞪口呆，被誉为“富弹左手”。

从雷德左手出发，你会想去了解一下他的生平。在百科里看到他的出生、教育、成长、成名，然后在婚姻栏这里突然停了下来——什么？霍洛维茨竟然是托斯卡尼尼的女婿！神一样的指挥家托斯卡尼尼，全凭记忆就可以指挥乐队演奏的大师托斯卡尼尼！八卦之心不可抑制，霍洛维茨和万达从新婚时的从封到故纸堆里重新来到你的面前。你看到两个被宠坏的年轻人曾经如何相遇，又是如何冰炭不容，在漫长的婚姻岁月里如何彼此伤害，爱情的火焰燃烧的地火与沸腾的岩浆，却需要而无法离开对方。

大师从云端回到人间。你发现霍洛维茨是一个极度自私和冷漠的人，和所有的天才一样，世人在远处观望时为他们身上绚烂的光影所吸引。但是，所有试图靠近天才的人，都会迎面遭遇他们的冷酷和残忍，陷入他们完全围绕自我中心的私人世界。在那个荒无人烟的世界里，除了行善就只有背叛和遗忘。寻常人都有的温情和关怀，在天才身边难觅踪影。大师不单从云端落地，而且穿过地表直插而下，身边都是硫磺的火焰和沸腾的岩浆，空气里充满了硫磺的味道。

这时，你看下面的这张二维码。你点击一下图片（不是最新版本的可以截取），下载到手机相册，然后打开微信，从相册扫描二维码，第一次看到霍洛维茨的演奏——舒曼的《童年即景》。并没有可怕的轰鸣声，也没有想象中狂暴的指法，那只是一个垂暮之年的老人，极为轻柔地抚摸黑白琴键，钢琴发出了如同梦幻一般甜蜜而又虚幻的声音。那些曼妙的弱音在你的回忆里激起无数涟漪，也许要听到第三次乃至第十次，你才会注意到他的手法与众不同、恍然大悟一般发现他确是平摊手掌，可是，转瞬之间的注意力就会集中在他的手指尖上，那指尖似乎异常柔软而富有弹性，在键盘上徐徐地伸展，就像是鸟儿在阳光下舒展双翼上的羽毛。

你会顺着《童年即景》，一路找到《拉赫玛尼诺夫第三钢琴协奏曲》，找到《卡门主题变奏曲》，找到所有你能找到的霍洛维茨唱片，你终将明白一件事情：别人只是能够按照乐谱正确演奏，而霍洛维茨永远有一个单独属于他自己的版本，而且只要一次你就能听出来。当你听过一遍，你就再也不能忘记。甚至，你完全可以原谅他是那样一个人，原谅他的无礼，他的暴虐，甚至他为了吸引观众而做的那些小花招。毕竟，他是霍洛维茨啊。

事情就是这样，如果你足够喜欢一个人，那么你就可以提出一个百度搜不到答案的问题，从而在人群中找到合适的人选，请他们去参加音乐会。这样，无论对于他们还是对于音乐会来说，都是恰如其分的。人们把他的这种爱好称为古典音乐爱好家。不，他们只不过是热爱生活的。唯有热爱生活的人，才能找到搜索引擎查不到的答案。
