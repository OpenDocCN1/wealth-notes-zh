# 写在一次万订页网上

今天下午，《槽边往事》在《得到》的付费专栏订阅数达到了一万。

6月8日，上线日。早上9点我看到订阅数将近两千的时候，没有想到今天会来得那么快。在我的想象里，这一天还在遥远的未来。也许，我还要连续更新一年，才能勉力达到这个数字。毕竟，人们还是对于教你如何赚钱、如何提升赚钱能力的文章更有兴趣。看看书店就知道了，卖得最好的书还是教辅和考试专用书，连菜谱和黄历都比文艺书卖得要好。

有人说，如果我开设免费专栏，那么我的订户会是商业专栏作者的十倍；但是如果开收费专栏，那么别人的付费订户会是我的十倍。我猜想这是真的，在通往美好明天的实用阶梯上，我这样的写作者站在最下一级。人们可能会欣赏无用之用，却是用非钱之钱。免费吸引流量，流量变为现金，互联网似乎一直都是如此的。

所以，你可以想见我看到一万这个数字的时候，内心的惑念之情。

我在互联网上做过各种实验，玩过不同的小把戏，这一次大概是历次游戏里最心跳的一回。在我的微信后台，批评我的留言有数百条。在各种群里，针对我的怀疑和订单就没有停止过。此种盛况，只有小时候看马蜂窝的情形堪可比拟。所以在6月8日之后的一个星期里，我都在心头默念：最好蜂蛹要美味，否则就白被蜇了。

第一个吃螃蟹的人是勇士，那不过是因为前100个掏马蜂窝的家伙都被蛰死了，没能活着留下名字。

当我开始更新这个专栏之后，刺耳难听的留言无论在数量还是质量上都比以前提升了一个档次。我还没有开过任何淘宝店，但我已经享受到淘宝卖家的待遇，充分感受到了中评和差评买家的气势。一会儿有付费订阅用户说：和菜头，我可是花了钱订阅的哟，你最好给老子天天更稿。一会儿又有付费订阅用户说：你要不要为我收了钱就可以任性啊，每天你更新能保质保量吗？你这是灌水！最好每篇都得对得起我的钱。
