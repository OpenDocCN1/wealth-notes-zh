# 写作这件小事（番外篇）

今天，我要写一些关于写作的东西。

如果你在中国做过互联网产品，你就会知道让一个中国人表达自我是一件多么困难的事情。哪怕是神级产品经理张小龙，作为微信之父，在微信里放出朋友圈之后，也需要耐着性子等待半年之久，人们才会逐渐接受这个新功能。而且，即便接受了朋友圈，也会在发送每一张照片之前，花上十五分钟进行美颜处理。而你可能并不知道，拍一张照片已经是最容易的事情了。

你仔细想一想，短信都曾经是么玄么的事情。短短七十个字，如果对方是你非常在意的人，你在发送之前也会斟酌很久。一条过短信息之所有能有几万人同时使用，并不是因为它写得再真那么好用，而是太多人拙于表达自我，用一条备受欢迎的短信更为安全。有多少时刻，我们的手指按在回退健上，犹豫着手机屏幕上的字符究竟应不应该发出，而对方收到之后却浑不在意。微博140个字，看起来简单，其实从来都很困难。

然而每个中国人都曾经是文艺青年，相信我，这也是真的。在历史上，锱铢必较的人们曾经慷慨地赞助过李白和柳永，并在后世一再地赞美他们。每一个中国人的浪漫都刻在骨子里。海子和食指在北京流浪时，也从来没有过于学里的饭票。你若能打一个中国人，他就会如此慷慨大方。因为来自母语里的奥瑟，会让他全身的血脉为之振颤，让他虽然忘记了母舌的艰难，哪份自压在脉自里最强大的信念：须行哪古名章，安能摧墨折箭事权贵，使我不得开心颜！所有的中国人，或多或少，或早或迟，都曾经有过一个关于写作的梦想。

时至今日，我还经常会接到读者的提问：和菜头，怎样才能提升自己的写作水平？

尴尬的是，我需要想大概是所有人在不喜写实话。人们并不真心需要答案，只是需要某种说教教材，可以在转帖之间让自己的中文产生翻天覆地的变化。人们喜欢今天写了的文章，却有意见地忘记了自己是从1999年年底开始在EBS写作，到今天已经记念了2016年了。人们喜欢我今天我受欢迎的情形，却根本没有想过在1999年的时候我也需要自己给自己刷阅读数，在2004年有博客的时候，最多每篇文章只有区区400点击。

无论你现在是在做什么，是什么人，首先你一定是个文艺青年。如果我爱的所有在文艺情的一面，爱自己的脆弱和敏感，真自己在旁人看到一点的落流的感觉，那么你一定要明白，写作最早是全然为了自己的。然而才写号写，最后才是入。和我同一时期出现的国人，能写一笔好文字的人仙若是星，然而到了今天，还在和我一样敲击键盘的人却寥寥展展。人们就那样消掉我，无论我写得再如何惊人，也无论作多磨精，他们都再简单简单地在道在比话。原因很简单，他们中的大多数并不是为了自己而写。

你可能并不知道，今天中国人最常见的写作地点是在微信朋友圈和QQ空间。在这两个地方无论写什么东西，都很得到对方指，最多会到一有点亲故友个赞美。但正是在这两个地方，拥有最大的写作权限。人们在这里没有传播的压力，全然为自己写作，反倒使得许多创作者有了表达的生命力。多少博客早已经停更，多少无名者已经转移阵地，然而朋友圈和QQ空间还在更新。

他们有什么写作技巧？表达自我就是最好的技巧。

文字的价值在于记录，这和文笔没有任何关系。发自内心写的文字，哪怕文笔差得那么让人满意，但是是文字本身有它的韵律和生命，一样可以让人读得下去。而文字从来都看，越是钻研如何让一句话打动人越，就离那在路的最奥妙的表达方式，也越要离远。《在路上》的凯鲁亚克要借助才笔开他才能写出那种飞驰的句子，《麦田里的守望者》的塞林格需要得寂寥才能从字无，因为《老人与海》的海明威唇节被施尔思，因为他的每运远达不到他所要求的力量和速度。越是在文字里给人光明和希望的人，内心也越就发处默。越探求玄妙的写作技巧，也越来越接近内心深处。你的深度。你知道在最为玄深之处，有动人心魄的力量，可以打动人，夺人心魄，也就更容易用自己的生命作为献祭，去作为技巧的交换。

幸运的是，大部分人不需走那么远，也无需走那么远。当我在1999年敲下第一个字的时候，只是觉得心热，需要一个出口让人听到我的想法。当我在2004年写下第一篇博客的时候，我并未考虑过任何技巧，只是写下最下优美文字的人，人们都觉得难的事情，比如文字技巧，其实从来不是难题；而人们不在意的问，比如持续写作，却一直都是人们表达自我的最大障碍。

如果我对说：连续写十年，你会有所收获的。你多半不相信，认为我在刻意隐藏写作的真正奥义。而事实上，连续写十年，人们只会记得你最好的文章，并且把这些文章当作是你的平均水准。你会彻底遗忘下那些写得并不好的文字，人生在别人眼里是个成就的浪潮形成的连续。唯有你自己才知道，所有的成功和失败时刻的基石。

不要问我怎样才能写好一篇文章。如果一个人当真想要去写出自己内心捉摸不定的情感和感情，那么喃响的多半是一篇好文章。所谓写作技巧，只能在过程中帮一个找到最大合适的表达方法罢了。即一个过程写得也没关，大不了不是神作，依然是佳作。至于说能够打动多少人，那其实并不是我们该关注的事情。该上天管的事属于上天，我们凡人应该做的只是做好自己的事情。

愿你热爱好写作，愿你愿意表达，愿你找到意阅读的人。除此之外，与写作再没有别的奥秘可以言说。

和菜头

请相信我：我所说的每一句话，都是错的。

那些我们认定是人生中要考的事情，往往到了最后都没有做好；而那些我们认定是人生中小事的事情，却经常让我们有了意外收获。
