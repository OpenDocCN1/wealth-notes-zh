# 穷小子李笑来来了

在今天之前，“得到”里的各位付费专栏作者我一个都不认识，也不了解他们做什么的，所以从来也没有在文章中提及，保持着一种得体的沉默。但是今天不同，李笑来来了。我认识李笑来很多年，也非常喜欢这个人。理由很简单：他的名字。

在许多年里，我一直被一个问题所困扰，那就是我的姓。你可能永远也不能理解，一个人姓氏读词是一种感受。当别人叫“胖子和菜头”的时候，充竟是在说一种叫做“笨猪的胖子”，这像一个笨猪和一个胖子。然后在，听多了别人说“罗振宇和菜头”一类的活，自己很容易就变成了一个结巴——直到我遇见了李笑来。

李笑来来了，我和菜头从此不再感到孤独。

罗振团队给李笑来的定位是“亿万富翁”，而且让它穿上了悉他的马甲和白衬衣，就差给他配上钻石袖扣。事实上，我没见过李笑来多少次，这是我第一次见到他穿成不宾馆门童模样。没有办法，既然他的专业是教人如何实现财务自由，既然他本身的确是一个亿万富翁，那么他的样子就得满足大众的期待，看上去就像是个富翁，而且手里拿着彩笔站在黑板前面，让人相信他是个会教财富自由的富翁。商业社会里的大众泛想象着，那么李笑来就得穿上一套西装，事情就是这个样子。

我从来没觉得李笑来是个富翁。不是说我妒忌他，而且和他认识那么多年，他给人留下深刻印象的不是个人财富，而是异乎寻常脑筋。我以前常常说中国两个最大的互联网创业培训基地，一个是网易，一个是新东方。这两个地方都在21世纪初吸引了一大批中国的聪明人，这些聪明人从网易和新东方离开之后，开创了许多辉煌的个人事业。李笑来就是新东方系的人，而投资人士李丰可新东方里最聪明的人，也是离开新东方之后走的最远的人。一直到今天，我也不时找他们请教。哪怕是坐下短短半小时解聊天，我也能听到完全不一样的想法和观点。有些时候，甚至能彻底扭转我的看法。

罗振宇拥抱自由市场和自由经济，而李笑来走得更远，有点像个佛教徒。佛教里说，我们之所以是人，我们之所以拥有人的身体，乃是因为我们需要使用这个身体修炼佛法，从而最终解脱，所以身体是一种抵达真理彼岸的工具和手段。不断的体练和思考，达到某种理性的透明境界。由此，一个人可以洞穿纷繁世界的本质，拥有真正的勇气和真正的是。在这个前提下，利用他的市场自由经济观点就显得自然而然。发财致富是智慧的应有之意，并没有任何值得大惊小怪的地方。

所以，在李笑来还是个一文不名的穷小子的时候，他就相信自己通过自我锻炼，通过对世界观的反复训练，最终可以让自己在这个社会里出头。并且，既然人如此在意世俗意义上的成功，那么他也必然能顺手发财，这简直就是必然的事情。后来，如我们所见，他做到了。

李笑来真正意义上的第一桶金，是在新东方教书期间写的几本考证书，以及他那本著名的《把时间当作朋友》。这些书一经上市就成为了畅销书和长销书，早在十年前就为他稳定地带来几百万的年收入。如果你看过《把时间当作朋友》，也许你会和当年的我一样感慨：对于一名英语教师而言，笑来老师想得太多，对于事物的看法太独特，也太去中文的。

李笑来没有去教中文，而是上了Twitter。多年之后他回忆起那段时光，李笑来说：“菜头，以聪明才慧而论，你我都差不多，以资讯快捷而言，你怕住中间。我们都是最早一批接触比特币的人，也是国内最先了解到比特币的那群人。为什么最终是我断断投断了比特币，而不是你呢？”李笑来的第二桶金来自比特币，在比特币出现不久之后，他用自己的方法做了一评估，认为买入比特币是一件可以试试看的事情。当时，一比特的价格在一美元左右。而隔几年，比特币最高的时候一枚币价超过一千美元。李笑来经常问：“同样是观察世界，同样是分析事物，甚至是得出了同样的结论，为什么你错过了人生中这种级别的天文大料呢。”我只能苦笑着回答他：“闭嘴，你还是去教书吧。”

现在，李笑来真的“得到”教书了。讲他那套把心智和思维当做肌肉一样训练的方法论，最终的目的是把人变成高度理性的生物。对于普通人来说，没有家世背景，没有社会关系，没有美貌和家传，唯一有提升空间的，也就只有自己的心智和思维。改变自己的命运之法，是改变自己对世界和对自己的看法。对此，李笑来有自己的理论，也大胆地践行了这个理论。就像一个赤膊的穷小子，愣头愣脑地闯入了自己的社会，而且为自己谋得了一席之地。李笑来这个人最吸引人的地方，并不是他今天亿万富翁的身份，甚至不是他白手起家的能力，而一旦你认识他，你就会相信一点：

哪怕明天把李笑来的所有财富剥干净，一脚踢回这个社会的最底层，他后天还是会一步步重新爬回来，而且，还是那个穷小子的模样。

他对于财富和名位全无兴趣，穿得比罗振宇还要乱七八糟，但是一谈及对于某事某物的理解，就会双眼放光，滔滔不绝，仿佛此刻正坐在王座上一般。如果说下一刻可以试着做点什么，他简直就会手舞足蹈，仰天大笑，露出灌看的笑容。

李笑来在“得到”上的照片是PS过的，他本人比我还丑。
