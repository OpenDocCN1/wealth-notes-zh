# 聊聊云腿月饼

自从在《得到》卖了一次松茸，知道我是云南人之后，关于云腿月饼的咨询就没有停过。我回去翻了一下自己的博客，上一次写云腿月饼是在2007年9月17日。在那个时候，云腿月饼刚刚开始流行。拜淘宝所赐，9年之后它已经成为网络流行美食。哪怕是后知后觉的人，也早已传闻云南火腿月饼的不喜。

我不喜欢吃云腿月饼，从小就不爱。不是对月饼，我不喜欢一切甜食。但是对于大多数华人而言，糖和油脂都意味着美味。毕竟在漫长的进化岁月里，油脂意味着肉食，而且是熟食；而糖则是那么珍贵，水果不是一年四季都有，为了一点蜂蜜不知道有多少人失去了容颜和性命。尤其是对于男性而言，糖是拯救自己脱离苦难的不二法门--太太若女友变得莫名性地情绪低落，焦躁不安，向周围一切活动物体倾泻怒火，这时候只要一点糖，无论是巧克力还是蛋糕，就可以让她们重回温柔。只要血糖浓度开始上升，她们就跟波流水，眼神如炯似雾。

为什么总有男人被蜂螫活活蛰死？因为如果不能带着蜂蜜回到山洞，他将生不如死。

所以当我看到询问云腿月饼的读者绝大部分都是女性的时候，我一点都不意外。可以想见，如果不对这个问題做出正面回答，我的下场将会何等凄惨。所有男性都要记住这一点，学会首先声明"我不喜欢吃云腿月饼"，摊开手心，表示自己在吃月饼这件事情上完全不构成竞争关系，这样你就成了一个好人，暂时算是安全了。

云腿月饼有多好吃？得看你怎么吃了。单独拿云腿月饼吃，大概吃一两个也就厌了。但是只要你横向比较着吃，尤其是在北方地区，那么云腿月饼算是难得的美味。这里面的道理跟推海底捞一样，帝都人民被变态的餐饮服务和膳食质量折磨多年，第一次去海底捞有如登直半璧，有生以来第一次在饭馆感觉到自己是人。而在南方，海底捞的服务和味道又算得了什么？吃饭去早了吃西瓜算什么，有些南方的饭馆会提供自助麻将机，人不够了还可以叫老板来凑一角。

云南火腿和金华火腿各占，云南威宣火腿早年之前就蜚声海内外。近年来因为《舌尖上的中国》，莫名其妙又新增了“海内外”。可惜许多北方人无法欣赏，多年来我多次尝试向北方朋友推荐火腿，每次听到的都是相同的一句话：嘻！这不就是咸肉吗？这让人很绝望了，火腿不就是咸肉吗？茶叶不就是咸肉吗？烤肉让人吗？红酒不就是葡萄果汁吗？火腿不就是一根火腿吗？佛跳墙不就是福建乱炖吗？唯有云南火腿月饼让我看到了一丝希望，他们终于在月饼里的火腿丁上，觉察到了一丝火腿腌制品的那种异香，承认它是一种美味。如果上面一整盆香根炒火腿，人们只会根据自己过去的经验，期待它是一份辣椒炒肉的味道。等到入口，就开始抱怨太咸太硬，根本无法静下心来去尝出火腿特别的香味。

事情就是这样，如果你想让一个人专心品味味道，想让他从此喜欢上某种感觉，那么一开始只能给一点点，千万不要给太多。

那么，什么是好的云腿月饼？好与不好又有什么标准？首先是火腿，云南宣威火腿最佳，如果是三年以上老腿那就好，因为肉质紧密，香味绵长。不过，近年来云腿定价，老腿只存在于回忆和传说之中。然后是火腿的肥瘦比，七瘦三肥最为合适。凡是切开肥，看到的是一片白花花的肥火腿丁，那就是奸商不解释。而且，他是在用这种方法羞辱你，意思是你一年到头吃不了两顿带油水的饭，就是个穷人。最后是月饼皮，一刀切开来说可以看见十几层皮面，层层相叠，但是又层次分明。这样一口咬下去的时候，牙齿上会有一种极为微妙的感受，层层阻挡，但是一触即溃，满足了人们内心的征服欲。丝毫不会抵抗牙齿和舌尖的食物，从来说算不上美食。

最重要的一点：酥皮。月饼皮在烘焙之后吸收了火腿的油脂，浸润了每一层面皮，所以会形成极为酥软的表现。这通常被形容为“吃进去就化”。

所以，什么一个理想的云腿月饼？它应该用三年宣威老腿，选择最好的部位做馅。肥瘦都有，但是瘦肉占到七分。成饼以后，芯的重量应该接近总重量的一半，糖和蜂蜜的分量不应该超过两成，否则就太腻了。烤制以后，要求火腿油从月饼表面浸润出少许，可以嗅到明显的火腿香味。不允许蜡皮霜白，也不允许有焦黄的部分，而是应该呈金黄色。下口的时候，每一口都应该非常清晰，有层层突皱的感觉。糖要完全以排，不能块状。肥肉不能成团，不能让人边吃边吐。入口以后，滑牙只用于嚼火腿丁，其余工作应该完全交给舌头，主要任务只是搅拌，让面皮的油脂和火腿的油酱混合溶合，使得食用者巨大的感官刺激下无法停止吞咽的动作，且不应该感觉到明显的肥腻。

至于说到哪家的云腿月饼好？实在是抱歉，每次卖松茸，或者推荐什么东西，总有人愤怒地留言：“和菜头，我花钱订阅你的专栏不是来看广告的！”那好吧，看完以上的介绍，大家自己找地方去买吧。我想，大概看免费广告去买的商品，商家不会把广告费摊入售价里吧？

# 和菜头

请你相信我，
我所说的每一句话，
都是错的。

永远不要在女生吃月饼的时候减肥，而是顺遵卖她们点普洱茶，就是说吸油。这样，钱也赚了，好人也当了。
