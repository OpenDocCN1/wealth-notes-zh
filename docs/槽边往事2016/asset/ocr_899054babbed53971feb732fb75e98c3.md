# **7秒**

前言：在《习惯和戒烟》一文发布之后，许多读者留言索取我以前写的戒烟烟贴《7秒》，说是有人凭借它曾经成功戒烟。好吧，如你们所愿，在这里再贴一次。同样的，这并不在每周的三篇文章之内。

C10
H14
N2
7秒

有如神迹，只需要点燃烟草，深吸一口，从1数到7，所有因为戒断而产生的不适感就会彻底消失。7秒钟，尼古丁就能透过口腔和肺部的粘膜进入血液，最终作用于脑部。就像插上了一个阀门，多巴胺就涌而出，心跳加速，血压升高，世界突然变得温暖而明亮，你变得警觉而又充满自信，在云端里漂浮，在流沙里下陷，在温泉里悬停。

你想停在那里哪里都去不成了。

尼古丁可以维持多巴胺在分钟级别上持续产出，这是所有故事的核心。因为最美好的一刻从此全部过去，之后只有冰冷残暴的重置篇章。当尼古丁在血液中的浓度开始下降，戒断反应也就随之产生。它让你感觉紧张、焦虑、呼吸不畅，再来一支烟，所有这些症状会随即消失。于是，你认为烟草让人放松，愉悦。

这是我听过的最好笑的故事：一个人花钱买烟抽，让尼古丁进入身体，于是形成了戒断反应。然后，花更多的钱购买烟草，来治疗这种戒断反应。而每多花一分钱在烟草上，也就加强了之后戒断反应的烈度，结果你必须要买更多的烟草！更强的戒断反应……所以，尼古丁的成瘾性要强于可卡因和海洛英，并且可以在商店里合法购买。

而在本质上，你的身体根本不需要带着尼古丁工作啊！在一开始的时候，根本不摄入尼古丁，也就没有治疗戒断反应的需要啊！

No Zuo, No Die.

思辨胜于行动。统计数据显示，只有7%的戒烟能够超过一年以上，剩下的全部复吸，原因就是没有充分思辨就开始行动了。从上面的分析可以看出，烟瘾的本质是尼古丁成瘾，尼古丁比毒品更容易成瘾，也更难以戒除。所以，任何一个半夜里穿着裤衩疯到街狂蜂小店的男人，他要么是为了买避孕套，要么就是为了买烟。

![](bbox=[0.1, 0.66, 0.9, 0.76])

我们的身体并不需要烟草，也不需要尼古丁。我们吸烟的目的，是为了舒缓尼古丁产生出的戒断反应。这是非常重要的一个观念，戒烟的成败取决于你是否全盘接纳这个观点。

戒烟不会让人焦虑、恶心、头晕、失眠、咳嗽、体重增加，抽烟也从来不能治愈这些问题。事实上，正是因为戒断，一个人才会有这些症状，这些症状存在的唯一理由是人类让烟草吸烟。尼古丁类似一条洁清，寄生在你的身体里，通过控制你感受的方式，让你持续购买烟草，维系它自己的永续存在。

所以，所谓控制烟量的做法本身就是错误的。以前每天一包，现在每小时一根。结果，烟草就变成了少年的小红花，一种肯定，一种奖励，需要努力才能获取的礼物。既然烟草那么好，那么难得，怎么能通过控制烟量的方法戒除呢？哪怕一天只1根，你在那8个小时里，分分秒秒、心心念念的无非就是一根烟啊！

所谓准备好了再戒烟的想法也是错误的。因为你现在压力大，太焦虑，所以暂时先不戒烟。那么，假设你在一般压力水平下成功戒烟，而你总有非常焦虑、压力极大的情况，届时你怎样抵御呢？哦，历史经验告诉你：可以通过吸烟。这就是复吸的未来，太多人因为心情不好或者压力大而复吸，在他们那里，永远相信烟草可以提振心情、舒缓压力，永远也不明白焦虑、压力、沮丧的感受本身就是由烟草而引起。

三观就有那么重要。发自内心的认同：

+   1.身体并不需要尼古丁，要努力恢复身体原来的运作模式。
2.尼古丁没有解决过任何问题，你认为它可以解决的问题，都是它亲自制造的。

那么，最直接的后果就是戒断反应的强弱。没有以上的认同，烟草就成了为可以结束一切苦难的良药，但就是不给，于是你感到加倍的痛苦；拥有以上的认同，烟草就为加剧或维系目前苦难的原因，坚决不再摄取，就可以逐步减弱它的威力，一切变得可以忍受。

这就是相信的力量，它能让人能握，知道为什么而握。
