# 知人·之明

临时起意在“得到”写这篇文章，是因为我的一位80后小朋友他的公司今年要在新加坡挂牌，从2011年12月他成立公司开始，到现在已经有5年时间。于是，我回顾了一下和他交往的朋友，发现我的朋友才能力大不一样。所以，在今天我的微信公众号文章最后，我写了这样一段推荐定义：

> > “网上总有一些博通喜欢说我拒大能，却不知道当他们看到我大能的人竟然有我，我其实已经成功了很多年。那么多年后，我依然看着一个人。这种认识的本事，不应该是我打开对才吗？”

我怀念一想，关于何知识人这件事，不应该被写给付费读者阅读么？他们付出了费用，理应得到这样的文章。

是为你。

我和大多数中国人一样，并不喜欢批览式的社交。

一桌子10个人的宴席，我基本不会出席。因为每个人点个菜，铺个杯，寒暄两句，半个钟点就已经过去了。根本没有办法深入交流，更不说探讨什么问题了。我只觉得，一谈，最好，三四个人一小桌已经是极限。这样一晚上下来，起码可以和每一个人交说半小时以上。

所以，每次听些什么“拓展人脉”一类的脏活，我就觉得膈膜。凡是事拓展的人，让谁都很难准啊？你就想喝酒满杯扔烂人，无非是心理不。你愿意又有什么用呢？你又不准备去搞他们。而且，你就可以轻易知道，谁在尊重你的一个人交往中，你可能真正认识一个人，也才能让别人认识你。在一个实验中据说发现，一个人和陌生人聊天说，等交谈37分钟之后，但超过45分钟之后，他一定会不由自主地开始说话。

人眼的凝视比镜头厉害多了。

在多年的零售式人际交往往中，人们来了又去，最后身边的人特别鼓励的人不超过20个，其中一些都成了专业领域的顶级人才，所以，我经常感慨他们的人呢？如果未来一岸或者他们的未来？

因为他们潜伏在幕薄之中，尚未反到和之前，就已经显露出了特别的品质。只要你稍微留心一点，就一定不会错过。

# 他们都喜欢做，而不喜欢说。

我第一次见信张小龙，是在深圳·大亚大厦顶层总助会议。当时马化腾正在主持召开产品会，整个会议室里坐满媒体，大家讨论得热火朝天。会议开到一个半小时，有人俯开台投到了另两个进来，在一个角落里坐了一个很位姿人。投了两分钟，一直不发，然后又信悄起身，打开后门消失了，仿佛这里是机场吸烟室。

我们再才知道这个人就是张小龙。那天的会议主题是讨论微类广告，转过去不到一周，张小龙就在QQ邮箱里放出了对新闻广告。这样的炒家太能出错吗？必须要做出微聊就如此成功。以至于，从做聊箱广播的心得。于是，大家很自然地就认识了。

我们不会刻意地去结识。除非有共同兴趣的话题。

他们喜欢做，也习惯鼓励你去做。这一类人有一种共同的满苦：他们认创造总一件有趣的事，但是却几乎没有人来应验他们的召唤，一起加入这个游戏。绝大多数人乐于享受创造的成果，但罕有亲自动手尝一下。

所以，当你想做一个创意甚至一个简单简单的想法，他们会第一时间鼓励你去做。尽管平常你们谈的时候，和所有人一样也会吐槽、抱怨甚至咒骂。但是，当你说“我做法做”这三个字的时候，如同一句话般，他会双眼发光，立刻站在你的身旁，大有一种“共同干人仇”的快感。

在些年里，我曾经对猎聘说过无数个“我想做”。

包括但不限于我想做互联网产品、想做微聊副写、做网络小说写家长篇、想做首都北影明星……无论这些想法多么荒谬可笑，我只要一拍脑袋说，就站在我的一边；我要创业的时候，他也站在我的一边。
