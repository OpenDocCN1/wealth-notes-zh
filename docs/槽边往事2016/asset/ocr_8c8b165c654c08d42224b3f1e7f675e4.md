# # 第一次网上发帖

我第一次上发网发帖是在1999年年底，地点是在香格里拉的外派技术人员宿舍。那时候上 web的人不多，能够发帖的地方也很少。我因为身在云南的缘故，信息并不灵通，所以第一站去的地方是云南信息港的彩云之南社区，到现在我都还记得它那个冗长的域名：yn.cninfo.net.

从域名看就能看出，当时人的雄心。除了云南信息港之外，全国还有一系列 xx.cninfo.net，试图自上而下“规划”出中国的互联网。但是很快的，互联网就开始按照自己的方式生长，那些奇奇怪怪的.com后缀网站大规模出现，而我也离开了云南信息港，开始了网上漫卷漂流。

当时我需要在香格里拉执勤一整年。作为一名刚满24岁的年轻人，待在一个只有两条街的中小县，想来想去只有上网，因为只有那里才有近乎海量的信息和许多能和我聊得来的人，可以同外部世界保持同步联系。尤其是因为云南信息港是最早提供免费邮箱的缘故，流量一度很大，上面有来自全国各地的人，让我感觉那里的天地要比周围的生活广阔得多，唯有上网才能够畅呼吸。在冲淡、聊天、发帖之中，发帖是最容易展示自我，找到同类的方式。

所以，我在云南信息港彩云之南社区发了生平第一个帖子。是一篇散文，篇幅并不长，但自己没有做任何修改，调整了一下格式就发了出去。然后我就盯着屏幕，不断按着F5键，希望看到有人回复。然而并没有，后来我抱就算是换了我自己，看见一篇明显是散文的标题，后面缀着一个类似蔬菜的名字“和菜头”，多半也不会打开。不享受有人回复，连点头人都没有。帖子发上去一个多小时，点击量还是零，这就有点伤自尊了。

我担心是因为拨号上网的网速太慢，其实已经有人点过了，但是数据并没有返回。于是，我自已点开放帖子，看着看有没有回复。依然没有，但是我敏锐地发现，我的这次访问给帖子增加了一个点击数。当时我就觉得一道大门在脑海里豁然打开——我可以自己点击的文章，让它看起来人气很旺的样子，这样别人看到了，就可能有点进来看看。就这样，我认当真，一丝不苟地刷新了三两次，手腕都快要断了。终于，奇迹出现！在文章标题后面，标注为回复的地方，突然多了一个“1”！虽然点进来评价你说这篇文章写得不错，尽管人很只，我读到这里，让我感到体内多巴胺奔涌，整个宿舍都泛起了明亮的暖黄色。

好景不长，我发现很快再没有其他人回复，点击数增长宣告中止。我翻看了一下页面，发现尚有不少帖子发新帖，我的那个帖子很快就被冲到了第二页、第三页......再一次，我的脑海里又开了一扇门，我开始回复自己的帖子。于是，一次一次把自己的帖子顶到了第一页。可以想见，任何人只要打开论坛，总能看到我那篇点击量醒目，回复量惊人的帖子。于是，帖子的访问量持续上升，真的开始有人留言回复，和我在留言里讨论起来。最后，我的第一个帖子收获了上千次阅读，近百条回复。

当我发第二帖的时候，就已经有人等着我发帖，迅速点开来看留言。从第二个帖子开始，我再也不用自己刷点击了--社区里的人开始认识我，知道了“和菜头”这个ID的存在。也是那个时候，我得到了上网以来的第一个数据分析结果：如果每个留言都回复的话，帖子的总体阅读量会额外高出30%左右。并且，得到了我的第一个认识：和只写帖子相比，在每一个别人的帖子下面留言，自己帖子的阅读量增长更快。所以，我心头就冒出了一个模糊的猜想：互联网的根本运行机制不是信息交换，而是人际关系。

人们发布帖子，并不是为了传播信息，而是为了释放信息。人们发布帖子，不是为了讨论信息，不是为了找到同类，构筑人际网络。因此，重点不是文章的好坏，而是是否释放出了正确的信息，让拥有相同想法、趣味、见地的人尽快找到我。而所谓话题越热烈，说的是可以是一篇文章的标题，一张选取好的图片，甚至是一次网络辩论。总之，如果你的信息可以使得别人心里产生涟漪，那么这个涟漪就会不断扩大，吸引更多的人前来。甚至在未来之后，依然会有人偏着当初的涟漪而来找到你，因为他准确地接收到了你的信息。

到了今天，回过头去再想我的第一篇帖子，连我自己都不记得它的内容是什么了。但是，我很幸运地一早明白了发帖靠回复量刷评论的方式初现道了。事实上，当时我更需要的是找人交流，而不是获取关注。只不过要想找到合适的人，必须首先引起足够关注。一年之后，我在西南论坛中在金庸客栈践行了一年自己的想法。在不认识任何一个的人，没有任何人际网络，自己不刷点击的情况下，新注册ID发了一篇评论张纪中的电视剧《笑傲江湖》，那个帖子上了金庸客栈的年度十大，并且我自己从此开始了媒体不断升级的道路。

一直到现在都还有人和我说论文笔，说我不懂文学。而我的回答是：不，你不懂网络。
