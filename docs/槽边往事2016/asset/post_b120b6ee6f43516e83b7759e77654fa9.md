
# 社会是最好的商学院

这两天发生了一件很好玩的事情：在我长期关注的中国漫画圈里，一群画师突然集体爆发地控诉自己在的公司，并且要和公司对簿公堂。原因是他们认为多年来公司完全交由公司控股说，公司从作品包装能力上也告吹，造成自己作品影视化过程受阻，影响到了个人利益。

漫画迄今为止在中国还处在亚文化的位置上，拥至多为85后、90后。所以，虽然事件在漫画圈里闹得很大，但是在圈外却显得波澜不惊。我相信这里的多数人对漫画并不没有太多兴趣，不过，这个事件从商业的角度去分析，却是非常有趣。不信的话，我来拆解一下给你看看：

漫画家的合同一签是五年，为什么五年后漫画家们不愤怒？为什么现在漫画家们愤怒了呢？为什么五年前漫画家们不发通告，宣称要维护个人尊严？为什么五年之后他们的个人尊严突然孵化成功，从天而落了？因为热钱在不断涌入漫画圈。

为什么热钱在不断涌入漫画圈？因为热钱已经横扫网络小说领域，但只有著名的作家作品，早已星已被瓜板殆尽，而且版价格已经高到了离谱的程度。我认识的一位女作家，她的作品主要是写给初高中的女生看，有庞大的读者基础。

这样一位作家的作品报价是多少呢？最新消息说，她的一本小说加十四集电视剧剧本外加一部电影的改编，市场上给出的价格是4000万人民币。正因为小说版权已经卖完，所以热钱的下一个目标就对了国产漫画。

在过去，漫画家的工作非常辛苦，但是收入却不稳定。能否赚钱，取决于漫画杂志能否刊载他们的作品。因此，在那个时代里，有公司愿意和他们签约，帮助他们联系杂志发表漫画，再给予一定的佣金，都是令人艳羡的事情。为此，漫画家签约了，把签约期间的作品版权留在公司，换取安定的创作环境和相对稳定的收入，这是非常正常合理的交易。现在情况变了，一旦热钱涌入，开始争夺漫画版权，漫画家的身份顿时就涨上去了。而且，看到小说作者的收入，漫画家对自己的收益也有了新的预期。

因此，曾经被视为盟友和帮助者的公司，如今看来就是个障碍。甚至要比障碍更糟，因为作品版权签给了公司，这就意味着影视改编、游戏改编权和周边产品授权产生的收益，自一开始就拿到，不专归属于公司。如果转到自己公司，或者自己独立做工作室，又不能继续使用原来漫画题材，必须从零开始，重新自己的新作。漫画家当然很愤怒，当然坚持网络上向粉丝发出呼吁，要求大家支持自己。

人还是那些人，公司还是那家公司，合约还是当年的合约，商业模式还是那个商业模式，什么变了？整个大环境变了，人心也就变了。当年成立一家公司，为漫画家打理事务性工作，充当经纪人的角色，那时候对于漫画家是好事。现在做同样的事情，在漫画家那里看来，就是阻碍他们赚钱，而且占了他们的大便宜，需要全社会共同声讨。

在资本的眼里，一方面感谢漫画公司在多年来开拓市场，培养漫画家和读者；另一方面则认为这种公司的存在提高了谈判的门槛，阻碍了资本的快速流动和增值，它的存在不是资本的助力，而是一种障碍。

谁错了？谁都没有错。谁都没有错，为什么会打起来？因为现在到了分蛋糕的时候，人越少越好，自己离蛋糕越近越好，最好是自己操刀亲自切。

为什么自我革命那么重要？这是因为游戏**本身是异常残酷。如果站在互联网的角度来看，大多数商家试图都是一个流量游戏。所有的商人都在试图争取流量——在现实世界里，流量**是人脉，而获得流量需要成本。当一个领域的内部获取流量的成本太高时，那么只有巨头玩家才能存活，小玩家就要退场。退到哪里呢？你还没没有分类型的流量山腰的争夺，在那里新玩家还在想要做业务，从零开始吸引流量，并且在想把流量做大之后，自己成为大玩家。

为什么说是残酷呢？因为在流量平原上从零耕作非常辛苦，需要经年累月地努力，才能吸引一点点人进来。等到真的开始爆发，流量快速增长，别处的大玩家一定全会发现，转移过来收割胜利果实。一玩家转移过来的时候，带来的不仅仅是资金，还有新的模式和技术，用最有效的方式在新市场上收割利润。起点中文做了多少年？最后真正的收获者是腾讯，腾讯有能力把起点的作者、读者挖掘出更多利润来。大众点评做了多少年？最后真正收割的是美团，美团有的是办法从大众点评里爆出油来。看看现在的搜索结果就知道了，第一展开回去的结果全是跟广告。之所以敢于这么做广告，原因是大众点评做得足够好，用户足够多，渗透率足够高，市场上没有一家愿意花一样多的时间和精力去做它的竞争对手。

为什么起点中文做不过腾讯？因为腾讯是一家全方位的娱乐公司，自带惊人的流量。起点中文要做一个网站，需要自己买流量，需要自己造一个游戏，而所有这一切，在腾讯这里根本不是问题。腾讯有自己的媒体、有自己的游戏开发团队、有自己的流量大海QQ，有每年创造数百亿利润的后盾，所以，腾讯自行开办创世中文之后不久，干脆就买掉了整个起点中文，连打一仗的兴趣都没有了。为什么大众点评做不过美团？因为美团打生下来第一天就对做点评没有兴趣，它的兴趣在于团购和电商。美团在历经千大战成为幸存者之后，大众点评是餐饮领域内唯一的大型网站。在美团的眼里，大众点评就是**最好的外卖和团购导流入口。而两家之间的竞争在投资人那里看来，纯属没有必要的浪费。所以，最终大众点评成为了美团的导流入口，因为美团赚钱更有效率。

事情就是这样：因为勇于终结无人问津的领域去开拓，死中求活，终于赢得尺寸之地。但是，往往市场培育成熟之日，也就是自身终结之时——这就是社会这所商学院，通过漫画圈的纷争告诉我们的道理。它都没有教科，只有几条新闻，几条微博，但是却比所有商学院的课程都要生动真实。

# 写在《罗辑思维》四周岁

今天早上7点45，罗振宇在朋友圈了了这样一段话：

今天是《罗辑思维》四周年生日，是我坚持每天60秒的第1461天，距离我结束这份坚持还有6年。

没有算4365天=4年等于多少，但是我知道每多4年365天，再多一天，所以，尾数第1应该是对的。这就是我和罗振宇在时间上的不同理解，他的时间作为一个单序列已经记录了多少天来剩余多少个。我更关心如何划时间，以思考如何分析所带来的结果，却并不关心时间的方向。

人们往觉得罗辑脑起的速度太快了，怎么就是他看了从上面的说到结业，可以看点一点。当人们说到创业的时候，往往会问：两年够了吧？三年应该够了吧？在我们所处的时代里，连成功也必须讲效率。人们对此成功的心理预期是两年了，两三年事情应该成就，五元就应该上市了，七年就该退休享受生活了。我觉，这大概是创业企业死得快的一个重要原因

罗振宇先来定了一个十年期，最后能否认谁也不知道，但是他的心态却因此发生了改变。当一个个人以十年时间作为规划的时，他对和两年、对业规、乃至对于的十年规划那些两年规的区别在哪里？在于十年规已经预计了可能遭遇的困难和危险是一条高低起伏线点，而而而风险规划一年定低线两点，中间没有意外，所以上面往下掉死的人最多。

目前看，制订十年期计划的人要死得更快。

我和罗辑最早的网名，并没有打过官交道，来说，他第一次约见我是出出书的事，我并不是特意的究是什么。因为来找我们联的出社的太多了，了了人，也讲过许多次，所以我对罗辑并没有抱有太大希望。时我答罗辑，一是因为有罗大宇这个人好，一是因为约见的饭馆起来不错。我心里想着，"如果这没不成约，起我饭，出版社的咖啡我算是够了。

会基本是在极为率的情况下就定下出了策划，我心里并没有任何底，这些年里过的太了，诺漂亮的也太多了，好在饭确实，我埋头苦吃，乎我料，一之内合作目已经出来，提给我们的书他出版集，让我决定交给的—一年为的初文集，且决定需要去哪此，快定版内容。

随后，我的在罗辑上，半年不到卖了五万，无书是装，设计还是纸张，都进团队的评不对外，都来自对外的评价无外和思维团队一起事之后，他们留的印象是效人，人。

如果一个团队十十年，而且是以这样一个做事都过程，那么，无论做件事大概会有所成就。

# 王菲怎样才能把演唱会门票卖到一万元一张

- 公众号：娱乐资本论

王菲2016演唱会门票砸手里了。但圣诞节应该开心一点，所以我不得不起那么长的一个标题，重点放在如何做成一件事，而不是为什么会搞砸一件事情。

有人说，之所以王菲演唱会门票全砸在手里是因为票价太高，过度消费粉丝，伤害了二级渠道的利益。甚至有传闻称王菲本来想把门票卖到一万元一张，结果物价局干涉，最终不得不改成7600元一张。

我的问题是：一万元一张门票真卖不动么？

王菲成名很早，是中国歌坛当仁不让的天后。不是三年五年天后，而是一直都是天后。她的粉丝群体大多是70后和80后，如今正是中国社会消费能力最强的阶层。他们动辄飞往欧洲品酒，飞往美国自驾，在奢侈品店扫货，不知道一年要买多少个包，也不知道每个包能用几次。相对而言，花一万块钱任性一下对于他们来说并不是过分的事情。而在14亿国民里，有这种消费能力的粉丝在人数上也应该远远超出两万人。

那为什么砸手里了呢？我认为这是因为王菲和她的经纪人陈洁瑛粉丝经济学不及格，需要重修。整件事情只有两个难点：

- 1、如何从14亿人里找出那20000个人？
- 2、消费能力如何转化为购买意愿？

但是，王菲她们并没有解决好。甚至可以说，根本没打算解决。而是极度自信地上手直接就是卖，想用800张票作为一个引子，造成饥饿营销的态势，然后所有剩余的票自然一抢而空。天底下哪儿有那么自然的事情？

14亿人里找出20000个符合要求的人是非常困难的事情，每70000人里才有一个。换句话说，王菲他们得对70000个国民宣传一次演唱会的事情，才能找到一个有可能购买10000元门票的粉丝。北京2125万人，潜在的购票人群也只有307人，就算北京富裕人口较多，乘以十倍也不过3070，连演唱会的每一个角落都坐不满。而要通过到北京城里的每一个人，王菲要开演唱会的消息，花费多少广告预算，得动用多少媒体渠道，又得以多大的频率反复轰炸？如果要在全国找到20000人呢？成本又是多少？

即便找到了20000个人，他们只是有这个消费能力，并不等于他们就一定会计去投票。因为对于拥有这样消费能力的人群来说，他们在娱乐上的选择非常丰富，演唱会未必是他们的必选项，甚至也不会是首选项。因此，要让他们掏钱投票，就需要提供他们一个行动动机。而王菲2016演唱会从筹划到现在，能拿到台面上说的理由只有3个：

- 1、从2010年以后，王菲没有开任何演唱会了；
- 2、这是今年唯一的一场，下一次不知道是什么时候；
- 3、使用了最新的VR技术，舞台效果和以往所有演唱会都不同。

这些理由站在票务方，会理解为是这场演唱会稀缺的理由，是粉丝掏钱购票的动力。但是，站在旁观者的角度看，这说明王菲从自己粉丝群体的视野里消失了太久。在长达六年的时间里，除了偶尔唱几首电影配乐歌曲，王菲一直没有对自己的粉丝群体有效输出任何内容。从2015年开始，她甚至停止了更新微博，更是把她和粉丝唯一的联系渠道中断了。

在娱乐圈里，一个人就算是天皇巨星，长期没有任何消息，不和粉丝互动，结局也只能是被他人遗忘。你关照粉丝，粉丝自然也关照你。陈慧娴当年如日中天的时候，说是要去英国念书。念书的意思对于粉丝来说，就是不再和粉丝发生任何关系，也不提供任何服务。等陈慧娴读书回来，一切都已经时过境迁，长时间会消耗许多事情，包括粉丝的热情和忠诚。

事实上，粉丝的忠诚并不需要王菲年年出新专辑来维护。王菲之所以能赢得如此之多的人心，是因为她的偶像气质。偶像气质是一个比较虚幻的概念，具体说起来就是粉丝可以在她身上投射自己的情感和欲望，王菲的歌词，王菲的行事，代表了他们心中的隐秘欲望，是他们的心声代言人。所以，六年没动静也无所谓，但是在粉丝心目中的个人形象要维护好。之前她特立独行、我行我素的强烈个人风格，必须持续释放，供粉丝消费。于是，她才能继续保持粉丝心目中神的地位。如果能做到这样的水准，一场演唱会不过是一场对神的供养，一次对信仰的充值罢了。

![](img/86bf7d26156954fc1596fd15fb33ddf6_115_0.png)

那么，这些年王菲做了什么特立独行的事情了呢？除了打麻将、闹婚变之外，她早已经没有什么是个人新闻，也不再是这个 societal 里的前卫和先锋人物。屡次因为前夫窦唯的潦倒落拓而被媒体提及，这是王菲的不祥之兆。因为从维护个人形象的角度来看，王菲在媒体上牢固绑定窦唯并不任务是好事，有多少多少人会喜欢这种社会缘人，更没有什么人认同这种人的价值观。对于粉丝来说，她也早就不是自己的精神寄托，只是代表着一段过往的回忆。也就是说，作为偶像王菲已然褪色。褪色的偶像 无法激发粉丝心中的激情和狂热，她的行为不能让人产生奋不顾身的冲动——她的活法不让人期盼，那么，她凭什么能卖10000一张的门票呢？
