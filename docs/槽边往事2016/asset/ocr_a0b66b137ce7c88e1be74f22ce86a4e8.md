# 彼岸之人

我们顽固执地坚持有着彼岸，是因为我们把现实中未能满足的欲望投射在那里，幻想着那些欲望可以在彼岸得以伸张；我们渴望能成为彼岸之人，并非是为了自我完善，而是为了消解内心不断沸腾的痛苦和煎熬。

如果没有彼岸呢？如果我们注定一直在路上呢？

这里我想要向你推荐一部纪录片，日本NHK摄制的《不了之人：宫崎骏》。影片并不长，只有4分钟，你可以选择在晚饭后打开一个时钟看看，反正冬夜漫长，就寝时打发时间好了。看完这部纪录片之后，我有一种如释重负的感觉，那些我心头游移的多重一下子得到了答案。大雪散开，花开成海。

宫崎骏是人尽皆知的日本动画大师，在75年的人生里，创作出一系列优美极致的动画作品。无论年龄的侵袭力，还是细腻入微的匠心，都给人留下了深刻的印象。

在数十年的创作过程中，宫崎骏一直以来坚持手工绘制而著称于世，有些时候，甚至耗费整整一年的时间去完成一个复杂场景。在我心目中，宫崎骏真的是在创作上达到了从心所欲境界的大师，我渴望着自己也能够有那一天，手下一可以自如地表达我内心的想法，不再为了什么、如何表达这样的问题所困扰。为此，我甚至如同歌词里唱到的那样“渴望着衰老”。

2013年，宫崎骏宣布退隐。因为“属于我的时代已经过去了”，而且，体力已经不允许再兴办领驭数百人的团队去创作动画长片。一年半以后，NHK派出摄影组访问宫崎骏，报道他的退隐生活，于是就有了这部《不了之人：宫崎骏》。

见到宫崎骏之后，发现老爷子自己也过着悠闲的生活，而且的解散了自己的工作室，但是又开始偷偷摸摸地开始画一部动画片短片。根据宫崎骏自己说，他一直都有一个心愿是：画一个关于毛毛虫的动画片。就在创作过程中，一个CG动画小组前来拜访老爷子，向他展示了他们的动画作品。宫崎骏历来都反感任何人CG动画，坚持要用手工艺绘制，按说大敌者，也就该赶加，可出乎所有人的意料，老爷子突然对CG动画非常有兴趣，并邀请他们和自己一起来创作毛毛虫的故事。由于CG小组来说，这是喜出望外的事情，仿佛像了参加创作历史的过程。

接下来的事情，则变成了CG小组成员权本优平的噩梦。纪录片里并没有太多关于权本优平的镜头，但是，在他的推荐书里，权本优平自己记录了合作之后的心态变化。开工之后一个月，权本优平在宫崎骏的巨大压力下陷入了严重的抑郁之中，宣称自己想去死，“睡着了做着梦，醒来就悲了”。宫崎骏能提出来了一系列要求，希望CG小组能够帮他实现毛毛虫想要的效果。但是，单一的一动画片开头发要很长时间，宫崎骏却沉黑着脸坐在房间里，团队每天比一天更低，而不复当初因为能够和宫崎骏合作而欢欣鼓舞的样子，空气里压抑得都滴下水来。

宫崎骏自己也没有好到什么地方去。并没有大师一挥手，大家鼓掌欢呼。在镜头里，他要么在房间里走来，要么坐在自己画着头的桌子上发呆，要么，就是坐在自己的位子上，面对画着疯疯狂抖动。动画片的开头，讲述的是一只毛毛虫的外事。宫崎骏不断地调整毛毛虫的动作、外形，但是，他始终觉得差了一点什么，怎么都不满意。在探索原因的过程中，他开始备受煎熬，内心苦痛，根本就没有任何轻松的时候。而工作也因此停滞，卡在原地，时间不流走，这就又加深了他和团队的焦虑和绝望。而在看起来，画面已经很生动了，实在想不明白他有什么不满意的地方。

那一天终于来临了，宫崎骏终于想明白问题出在哪里：毛毛虫诞生的画面里，只有一根孤独零卷的草在草茎上，显得太过缺乏生机。一念如同明白了一切之后，宫崎骏的想象力就有了用武之处，很快就找到了一个好的解决办法：让整个画面充满了毛毛虫，并且略带一点毛毛虫，甚至还有一些小喧嚣。与此同时，毛毛虫从草里探出头来看第一次看到世界，世界那种巨大的存在带给新生命的冲击，终于被完整地表达了出来。至此，我终于明白了为什么宫崎骏的动画总有一种打动人心的魅力，这不是因为他多厉害，而是因为他总是能进入他所创造的角色内心深处，把角色所能感受到的东西表达出来。观众看到的，不是透过画面，他们会细致感受到一些不同的东西，一些隐藏在内心极深处的情感和记忆。

你一定要去看一下这部纪录片，看看宫崎骏是如何解决这个问题。

对于我来说，看到动画大师宫崎骏在75岁的时候，也依然因为创造而受苦，也依然要愤怒地绝望，这让我内心得到了极大的释放。没有彼岸，无论怎么的远，不管吃了多少苦，彼岸依然遥不可及。该焦虑的时候值得焦虑，该绝望的时候还得绝望。因为年龄所带来的绝望和智慧，并不能减少任何一丝一毫的痛苦。只要一个人还想要去创造，去建造，他就需要忍受因此而来的折磨：那些经验和智慧，只是在熬过了最痛苦的那一瞬间之后，为具体如何解决提供一点点便利。在宫崎骏那里，怎么画不是个问题，而是画什么所带来的痛苦，和你我无二。

没有彼岸之人，所以人人，一直在路上。75岁的宫崎骏拿起电影人画板，画着用尝试画图找到在纸上绘画的感觉。画了一辈子动画的大师，却用画板画圆画方显得如此笨拙和不通。在纪录片的结尾，经历了这一切的宫崎骏找来同样是年事之人的人一起合作，绘制给动画下一部动画长片的大致画面，按照预测的设定，画在完成的时点大概是2019年，届时宫崎骏已经80岁了。制作人开玩笑说，也许看到一半就死了吧？但这已经不重要了，重要的是哪他正在做自己喜欢的事情，谁也说一定要抵达彼岸呢？

知道了没有彼岸，也没有彼岸之人，让我得到的不仅仅是释然，希望你也能如此。
