# 厨房里的迷宫

18世纪某年，休斯敦饭店，今天这里叫大东方饭店，8个以上的15号冷柜里，就住在这里，记得那边是冷菜柜，都是全白霜冻在上面的。厨房柜的木头，都贴了白色的瓷砖，我站在小凳子上，看着冰块被搬下来，刮到脸上会凉半天的，时间凝固了。

下午3点起了个大早来帮忙，一边走一边数，一共8个冷菜柜，左边是海鲜，右边是牛肉和羊肉，史提芬在煮什么汤，热气腾腾的，厨房的瓷砖是白色的，像雪一样的白，还有一块是黄色的，是油渍。

从3点到4点，4点到5点半，我不确定是：这里的冰块是白色的，还是冷掉的，砂砾是黑色的，是从意大利来的，他们叫它大理石，冰块是从冰水里面来的，史提芬在切洋葱，切着切着就哭了，我也哭，厨房的灯是白色的，像雪一样的白，还有一块是黄色的，是油渍。

喝了口汤，汤是白色的，像雪一样的白，还有一块是黄色的，是油渍。喝了一口，汤是咸的，汤是热的，汤是烫的，汤是滑的，汤是稠的，汤是香的。

记得我爸爸写过一篇文章，叫做《海边的曼彻斯特》，里面提到了一个叫做“厨房”的地方，厨房里的瓷砖是白色的，像雪一样的白，还有一块是黄色的，是油渍。厨房里的人都是高大的，他们是男人，厨房里的灯是白色的，像雪一样的白，还有一块是黄色的，是油渍。

第二天晚上的鲁菜就失败了，边做边唱，一顿酒。

厨房里面，我打了一个碗，从厨房绕道到了一家馆子，叫得好，菜很硬，用的是竹筷子，从厨房到桌子，中间要经过一个通道，通道的两边是墙，墙的中间是玻璃，玻璃的另一边是另一个厨房，那个厨房比这个大，人更多，更吵。

这一顿，我觉得我和厨房之间的关系变得更加微妙了。厨房不只是做饭的地方，它还是一种情感的寄托。

事实上，我现在的任何回忆都是以模糊的表面为基础的。我坐在厨房里，看着那些碗碟，看着那些蒸汽，看着那些油渍，看着那些火光，看着那些时间，看着那些空间，看着那些情感。

我想起的是厨房，和吃饭的桌子。但是今天并没有那么大意义。

雨下了好一阵，我的心在跳还是不确定。我坐在书桌前，一边看着外面的雨，一边想着。

厨房里没站着头，也没有神奇的味道。

这里的空间很大，所有事物都有存在的意义。

我记得有个多义词表里写着“喜欢做饭”。

任何时刻，我都是从厨房里的角度，看着自己。

# 附录一：《一碗腌面汤》

鸡蛋粥。

早餐的时候，妈妈的唠叨，爸爸的味道，外婆的味道。

我想起一碗鸡蛋粥：它的质地是如此简单，味道也是单一，但它的口感和口感都很好。

一碗鸡蛋粥，加上一个白馒头，就会让人觉得自己吃饱了。

我不太会说英语，但是这个字对于生活来说太沉重了。

正因为是人间才为食，我们会一直在追求那一碗汤。

猪头面汤，我喜欢。

鸡蛋粥被称为“蛋花汤”，这是因为水不能沸腾，完全煮沸后，会起一些小泡泡。

在冬天吹过风，我是否记起了厨房的鸡味。

猪面汤里的所有秘密都在于沸煮水，比如猪水太少的话，猪面就会变成一坨，太水的话，就是一碗猪面汤。
