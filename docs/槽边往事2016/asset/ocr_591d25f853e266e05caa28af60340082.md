# 游戏与三观

假期躲在房间里逃避 先来无事下载了一款最近极为火爆的手机游戏玩具。结果一早一晚必得准时上线刷刷道具，相同的关卡要刷八百遍，玩了两天之后我忽然醒悟，这哪里是在打游戏，简直像是在游戏里打工赚钱。好不容易有个假期，用私人的假期在游戏里打工，我这不是有病还能是什么？遂怒而删之。

所有的游戏都是对现实的映射，因此，游戏里天然就带有世界观、价值观和人生观。这一点都不好笑，正因为游戏的本质是利用人们的贪痴痴慢疑形成游戏欲，依靠游戏贪实现暴利，所以在游戏里的三观要比现实生活中更为鲜明。可以这么说，一个人选择什么游戏，其实并不是在选择不同的娱乐方式，而是在选择游戏背后的三观。

我从来不喜欢韩国游戏和国产游戏，并且把韩国游戏蔑称为“泡菜游戏”，原因就是这些游戏里的三观散发出一股让人作呕的味道。在世界观的设定上，优秀的游戏会探索地图里的世界观作为重点，它会在地形上蒙上一层黑色，只有一人走过，黑色才会一片片消散，露出被遮盖住的山川河流城镇农场矿井，这叫做“开地图”；而泡菜游戏的重点是，作为玩家重复刷经验刷金线的世界，每一处都大小小异，无非是换一下装修。探索未知从来不是它们的重点，给玩家一个工地然是核心诉求，在一个工地挖完坑，然后再换一处以相同姿势继续挖下去，这叫做“推地图”——玩家都是蓝斑纹校接主机专业毕业生。

这不是游戏设计的差异，而是在文明层面上的差异。那些地图背后对世界的思考，源自古陆的冒险者帆船跨越大洋，找到新大陆去冒险者；源干那些一寸寸走过地球表面，标记每一种动植物的博物学家；源干南北冒着生命危险爬上珠峰或前往南北极点的探险家。推地图背后则是完全不同的一套看法：世界是用于种地的田地，是用户挖矿的矿坑，是用于砍伐的森林。探索根本不重要，重要的是发现资源之后迅速榨取，榨取完毕之后换个地方接着再来。

在游戏的玩法上，优秀的游戏会尽最大可能提供给玩家各种选择，鼓励玩家挖掘出更多有创意的玩法，胜利并没有唯一的标准。游戏本身不会限制玩家具体要做什么，几时就去。它只是制定了好简单的几条规则，玩家可以遵循这些规则，可以自行发展出极为复杂的玩法。也就是说，游戏制作方并不多干预玩家的行为，强制要求玩家必须按照我的玩法去限制玩家的行为，一定以战胜其他玩家作为唯一标准，一定会规定玩家每天上线之后所有规定动作。唯有事有能挤玩家按照设计好的路线行走，才能挤压出最大的利润。哪怕因此整个游戏会变得越来越工业流水线一样，玩家在游戏中只是重复相同的动作。

这不是游戏乐趣上的差异，而是游戏公司价值观上的差异。认为每一个人都有所不同，那么游戏的自我价值就实实不一，那么追求游戏者追求满足人的多样性，尊重不同的选择，尊重每一个个体，并且相信他们都有自己的选择和判断，那么游戏就会鼓励每个玩家用自己的方式从中获得乐趣。而一旦把玩家视为提款机，依靠本能驱动的盲目大众，那就要抹杀所有令人之间的差异，禁止别出心裁的玩法，逼迫用户沿着实现利最大的唯一途径玩游戏——成为唯一的强者。除了最强者，其余的人不值得一去活，这就是后者的价值观。

为什么我在假期里玩了两天游戏就热心四起？因为泡莱游戏里的那个世界，玩家能做的事情非常少。游戏里要的一点乐趣，战怪别人打，打则经验，不断地在同一个游戏场景下做无数次重复操作。这隐藏着两点让我非常不喜欢的人生设定：1.人只有一条路可以走，除了胜利瞬间，别无什么乐趣；2.成功的秘诀在于重复做些个简单的动作。前者的眼光之狭隘，让我怀疑是不是活在当代游戏；是在用互联网在玩一个现代游戏；后者是一种智力上的偏惰，在认为秘诀存在的同事，坚信秘诀极度简单，需要的不是头脑，而是体力。一想到整个游戏里充斥的全是这这样的人，就让人不甚高兴，完全失去了玩耍下去的动力。

无论是好游戏还是烂游戏都让人成瘾。时至今日，我都还经常翻出《纪念碑谷》、《魔兽世界》重温一遍。但是，成瘾的原因并不相同。重温《纪念碑谷》是因为喜欢和游戏设计者着力对抗的感觉，更因为为它所提供的那种独特而忧伤的美感。返回《魔兽世界》是因为怀念那个广袤无边的世界，和里面各种各样的可能性。干这样的东西上瘾，而如果像是训练一条狗一样，用规定时间规定动作，让我不用任何脑子，重复操作某些动作，那看获得战利品的那种感觉，那我认为这种概念大脑是一种伤害。它不能称之为一种娱乐，而是一种驯化。

如果这个世界上有所谓病，那它说的应该是游戏对大脑的控制。一个空空如也的大脑，最需要的是不是有所选择，而是有人每天为它安排事情去重复执行，因为思考对大脑的大脑来说，实在是一件太重不过的负担。
