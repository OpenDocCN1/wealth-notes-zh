# 代罗振宇：致女儿书

![](bbox=[0.0, 0.15, 1.0, 0.28])

罗思思、罗维维两位小朋友，

欢迎你们来到这个世界！

我是和菜头叔叔，你们落后生第一个用文字迎接你的人。

你们也许会好奇：为什么不是爸爸罗振宇亲自写呢？因为他刚刚得到你们这对双胞胎小妹妹，一会儿全身酥软，一会儿热泪盈眶，正在书房里下窜上窜、抓耳挠腮，完全放弃了一个成熟、稳重的中年人应有的矜持。

他的手指因为颤抖得太厉害，连手机上打字都做不到，更舍不得把视线从你们身上移走，所以，他只能委托菜头叔叔来写这篇文章。

另外，我自己还有一个很特别的理由：

许多年来，菜头叔叔一直都想要一个女儿。甚至从二十多岁开始，就经常在梦里非常清晰地见到她。那些梦境都一样一样，而且在那么多多年里一再重复：

在梦里，那是一个雨天。我打着雨伞去幼儿园门口接他，隔了老远，我一眼就看见了那个穿着黄色儿童雨衣的小女孩一直等着我。在雨衣的透明帽檐上，又细看他的发往下滴。她伸着小手不断擦去额上的雨水，看着我走近，抬起头来奶声奶气地对我说：“爸爸，你怎么才来啊？”

但是现在看起来，这一幕不大可能在我生命中发生了。

在我的梦境中，在另外一个平行的世界，那个穿黄雨衣的小女孩一直在等着我。在我身处的现实世界里，我打着伞无论怎么走也不近她。

不过，叔叔现在有了你们。有天我也会机会去到幼儿园门口等着，一边捋一手，仿佛两只小鸟轻轻巧落在我的臂弯里，共同感受到不到重量的。这样一来，你们同时一起左右在我耳边喊我“菜头叔叔”的时候，会有一种立体声的效果。

原谅我说了那么多无关系的话。菜头叔叔是个内向又羞涩的人，不善于表达自己，张不开嘴说“我爱你们”。

所以，以上就是我“我爱你们”的方式。

很土，是吧？

对了，我应该先向你们介绍一下你们的老爸罗振宇。

罗脾曾经有过衣食无忧的体面工作，本可以一直到退休的文抄职业。但是一夜之间，他居然放弃了一切。连学生会都不带，径直跌入为了生活的刺激，干脆利落地走了另一条人生路。

所以，你们的爸爸是一个勇敢的人。

更厉害的是，有一大批人，有头脑有眼光的人，跟随他同样跌入激流，为自己博一个不一样的明天，彻底放弃随波逐流的生命，把生活牢牢掌控在自己手里，做一个顶天立地的大写的人。

更勇敢的是你们的妈妈。

你爸爸的这种做法换一种说法叫“折腾”；在某些不喜欢他的人群里，那叫“作死”。而妈妈意思和他一起直面人生风风雨雨，共同玩在潮头浪尾，激流涌动的大生活，甚至还把你们两个小也带到了这个躁动不安的世界上——妈妈真勇敢，妈妈最伟大！

你们的到来，彻底改变了你们爸爸妈妈的生活。

在他们面前，又不是崭新的岔路出现了。从你们降生的一刻起，他们就不夫夫妻，而是父母。

在此之前，爸爸妈妈已经在人生路上做过一次选择，选择了少有人走的那条路。在这条少有人走的路上，菜头叔叔是爸爸妈妈的老同路人。而现在，因为你们出现，爸爸妈妈跟和菜头叔叔就要分开了。

你们爸爸妈妈的新路线路上，在未来的岁月里，你们会带着你们同行，一路上带领你们欣赏沿途的风景；而菜头叔叔也会在自己新路线上继续前进，由我负责给你们介绍我这条路上的景色和奇观。

爸爸请我代欢迎你们，正是因为这个缘故，因为他不想你们错过。

菜头叔叔我是那种永远走在另外一条路上的人。

+   * 我是白族，但是我的中文比许多汉族要好；
* 我是理工生，但是我的文章比大多数女生要好；
* 我文章不错，但是我的厨艺更棒，是朋友聚会时必请的大厨；
* 我在现实生活中过得很舒，但是我在网络上的人生更为精彩；
* 在每一次变化到来时，我总能找到更好玩的方式，创造不一样的精彩。

和叔叔就像是一个魔法师，从他的帽子里永远变不完戏法，放不完烟花，抓不尽小兔子。你们永远也猜不到下一步叔叔会变什么出来。

所以，现在，你们就坐好，睁开眼睛看着我。这是我给你们的人生第一课：

你们的爸爸罗振宇是个臭屁精，有一种任何时候都想着贩卖知识的毛病。所以，任何他写的文章或者跟他有关的文字，在最后你们一定会看到一段广告，这次也不会例外。

前面说了，和叔叔是个魔法师，但是叔叔也是个暴躁的魔法师，因为多年以来叔叔在网上创造精彩和惊喜，却挣不到一文钱，所以，那些一丝不苟的大人们，在消费完叔叔创造的东西之后，还要在脑海里指手画脚，丝毫不尊重叔叔的付出。

于是，叔叔就变得很暴躁。

让人们承认我的价值，这是叔叔的梦想，但是我也不给什么好办法。不过幸好你们爸爸这个朋友，他凭着脑袋、手不脚、心肠厚三大优势，为我这样的网络魔法师找到了体现价值的方式，那就是：直接向读者要钱！

说出这句话的时候，菜头叔叔在屏幕前面都觉得心里老大畅快。Yeah，我有那么讨厌！所以，从这篇文章开始，我就会在你爸爸设计的“得到”App上开设付费专栏《随谈往事》。

从此，只有那些真心欣赏叔叔，也真正愿意支持叔叔的人，才能和你们两个小一起共享我在那些新路上的风景。我也愿意为这样的人群，提供更丰富更为精彩的内容。

在每个人生岔口上，只能选择其中一条。我负责生另外那条，然后大家彼此碰撞，一起相携相伴过完一生。

想不想要更多玩具和更多生日礼物？那请你们眨眨眼睛，支持和菜头叔叔吧！支持叔叔和你们爸爸这次全新的网络尝试，我们也许能够颠覆网络一切免费的魔咒呢。

让信风吹吹，让船帆升升，让我们启航前往新世界。

你们才刚刚出生，就能够一起见证这个时刻，有没有觉得这是最酷的欢迎仪式？

来，跟我走吧！
