# 有趣，是一辈子最后的春药

![](bbox=[0.05, 0.1, 0.12, 0.14])

前言：这篇文章属于每周的N篇之一，同步在微信公众号发布。在我的微信公众号上写文章里，有读者留言，建议我好好在咪蒙公众号学习一下如何写文章。这就是我的学习成果，学得不好就学，还请多多包涵。

王小波害人不说。他有一句话在文艺青年里流传甚广：

> “一辈子很长，要跟一个有趣的人在一起。”

所以这些年里我不断听到读者提问：“菜头，怎样才能做一个有趣的人？”正如确切知道用户需要的不是一匹更快的马，而是一辆汽车一样，我深深地知道他们并不是在真心如何变得有趣，他们问的是如何去教会人和自己在了一起。一个人喜欢上自己，可能有许多原因。性格魅力踪影难觅，一见钟情全靠运气。相对而言，他们觉得自己做到有趣要么困难，因为一个虎头大肚子的中年胖子都能做到的事情，想来应该非常轻松。是啊，什么比不用付出多少就能得到的事情更让人向往呢？

于是，在这多里我也不一直被为慈祥地告诉他们生活的全部真相：别一做一竿哈！

为什么我如此高冷残酷？因为王小波那流传甚广的语录并非他的原话，这句话出现在小说《三十而立》里，当时王小波是这么说的：

> “我妈妈始终爱我。她对小铃铃说，人生是一条寂寞的路，要有一本有趣的书来消磨旅途。我爸爸这本书无趣至极，叫她觉得当初怎么夹了这么一本书。她羡慕铃子有了一本好书，这种书只有象征性做做聪明才能打开。”

明白了吧？向我提问的人最大的问题在于，连话题都没找到，却老想开药。我能提供开药。最难的事是，连钥匙都弄错了。王小波的原话说的是如何一起虚度光阴才不寂寞，找个有趣的人，做点有趣的事，算是老方法的一种。但是，读者往往把我带入歧途，径直给己套上了主角光环，觉得只要自己是个有趣的人，就会有人和自己共度一生，所以有趣就是孤独者告别寂冷者的春药。对于那些都感觉到人生寂寞如雪的独子来说，站在海潮一般的长发下面，用钝夹着稻草看，是一团巨大的忧伤。王小波的话，让他们觉得有趣是寂寞人士的解药。

后面的朋友，请挥舞你们的手：我们一起来！再一次：别一一做一竿哈！

世间所有的事情，所有的得到，如果不谈代价那就是在耍流氓。做一个有趣的人的确很好，但是代价也非常高昂。美国著名知识分子默多库德伦·艾伦曾经用非常生动形象的方式讲过有趣的代价，他说：

> “以蚂蚁和蜂螫为例。针螫整个夏天都在酿蜜，蚂蚁则工作并储存食物。到了冬天，针螫一可无有，可是蚂蚁却暖阁穴。”

针螫忙于游戏娱乐，属于有趣的那一类；蚂蚁低头劳作，属于无聊的那一类。成为有趣的代价是快乐而最终一无所有，针螫不果腹，在严冬到来时冻死而饿死无声；成为蚂蚁的价是过着安逸而乏善可陈的生活，北风呼啸之声里在自己暖洋洋的洞穴深处大食大饮，却因在麦秋时的劳作而挨受肉体上的痛苦。但蚂蚁总会羡慕针螫的夏天，不是吗？
