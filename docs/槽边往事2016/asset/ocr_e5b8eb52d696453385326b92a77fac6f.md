# 当罗胖穿上了窄腿裤

在今年6月27日，我写下了一篇文章《罗振宇的窄腿裤》，恳切地敦促罗胖放弃运动裤，试着穿一下设计师品牌的衣服，尤其是窄腿裤。在文章的最后，我发出了最强烈的呼吁：扒了他！7月14日，罗振宇对此回复说：

> “我深知那是一个深不见底的坑——穿上窄脚裤（原文如此，未修正），就得穿休闲皮鞋。然后就得系上裤腰带。然后你就会在乎这一切的品牌。偶尔还会追求一下设计。配饰也得该减则减。讲究是：活得不凑合。代价是：永远很焦虑。我的窄裤脚，只是通向那一系列焦虑的入口。正如一个女子的名牌包。”

11月4日，在我生日前一天的早晨8点20，罗振宇发来了四张照片，照片里是三条窄腿裤——在一个月零一周的思考之后，罗胖最终还是穿上了窄腿裤。下午从上海现场发来的照片显示，罗胖正换上了窄腿裤，甚至还换了一件极有设计感的长袖衬衫。那件衬衫裁剪得当，相当贴身，而且还略微收了一点腰，让罗振宇看起来有一种正在向上跃起的感觉，完全没有了退休老干部的底盘沉重感。

罗振宇是一个互联网知识供应商，致力于为人们的思想和提供学习方式的终身学习服务。既然如此，个人能力提升意味着经济条件的改善，在现实中的落点就是提升生活品质乃至个人品位，那么穿窄脚裤对于罗胖来说，就是对他自己理念的一次最简单践行。所以，我每一次和罗振宇聊起这个话题，他也赞同我的观点，认为应该尝试一下窄腿裤。

但人性的复杂之处就在于这里：在理性上罗振宇认同我的观点，但是在感性的层面上，他却一直在抗拒和回避。买一条裤子是多大的事情？4个月的回间。别人的火箭都回收两次了，罗胖才好不容易克服心理障碍，脱下他的万年运动裤，拥抱了一次变化。在这4个月时间里，每次见面我都会劝他试一下。直到10月27大的大雨之夜，我还指着他的运动裤提醒他说：这一年都快过去了，你不会要拖到明年了吧？

一两周后，他总算是脱了。

如果你想改变世界，改变社会，改变他人，在你开始动手之前，请再想想罗胖穿窄腿裤这个故事。即便是罗胖，即便罗胖也赞同，在我反复劝说敦促之下，也需要耗费4个月之久才能看到一次尝试。想要世界回应你，想要社会响动你，想要人跟随你，所要耗费的心力远远不止几次聊天，所需要的时间也远不止14个月。到了最后，做决定的还是罗胖自己。人们内心深处没有改变的冲动，那么今天我们就没有这个故事，而是看着这个故事变成事故。就像是上面罗振宇回应的那种话一生哲学了，转身就可能变成运动裤的坚定捍卫者。就像那个笑话里说的那样：病人在拔牙前极度恐惧，不得已买了一瓶白洒喝下去壮胆。放下酒瓶，他红着眼睛，嚷着骂酒，大喊：“谁他妈敢动老子门牙试试？！”

对于我自己来说，这件事再次验证了我劝说他人的技巧。第一次和罗胖在理论高度探讨完窄腿裤之后，第二次见面时我发现他没有任何变化。而且，从第二次见面开始，他开始不断拿我的窄腿裤打趣、调侃。于是，我从第二次见面开始，就再也没有劝说过他。因为我知道，这时候只要我再执拖压，他的抗拒心理会变得更加强。面对他的打击嘲笑，我每次笑得比自然得体地褪起二郎腿，指着我的裤脚给他看：“瞧瞧，瞧瞧，什么叫过计感，什么叫个人品位，什么叫生活？”有时候见他人没没有开发，我却已经提前秒杀：“罗胖，你说为什么我比你胖那么多，但是我的腿看起来比你修长得多，身材也比例地感谢？”“你说你整天那么辛苦干嘛呢？想穿运动裤运动裤，你在央视待着就能买啊，保不齐还有人送呢，何必出来呢？”

我相信，最早在罗振宇眼里的我是可笑的。这种真勇思路我也非常熟悉：我们有那么大的能力，我们有那么强的头脑，本可以投入到更伟大更重要的事情中去，何必浪费在穿衣服戴帽这样的鸡毛蒜皮上？但我也相信，和观点比拼相比，气质比拼更为重要。每次我看到罗胖的时候，发现自己的打击嘲笑不能对他产生任何影响，反而是我每次笃定伸脚，仿佛一条裤子真的为我带来了某种自信心，甚至都可以作为反击我的武器。那么，好笑的事情也变得越来越严肃，越想越觉得好奇，最终，罗胖自己走了过来。

回到当初7月14日罗振宇回答我那段话，想必穿上了窄腿裤的罗胖已经想明白了一个事：焦虑就是焦虑，人人都焦虑，而且很可能要永远焦虑下去。躲避对外物的追求，并不会减少任何焦虑。相反的，从裤子到皮鞋，从皮鞋到裤带，从裤带到配饰，当我们去追寻它们的时候，在那个过程中我们实现在好奇怪中发现生活，根本不会造成任何焦虑，反而是一件极为有趣的事情。理解了这一点，许多人也就能因此避免了孤独终老的命运。

都是错的。

在物质匮乏时代里成长起来的一批人，很少考虑了克制自己的欲望、节俭地抵制物质的诱惑，并且把耐心、节省、忍让化为一种美德。但是，从来没有过得的苦，何谈什么苦着呢？那种舍义有什么好处？
