# 本来不读书

![](bbox=[0.04, 0.058, 0.15, 0.083])

读书本是一件奇妙的事情，人人都承认读书是重要的，也都说读得太多。以至于大多数人都声称根本不读不读书。受过教育的社会阶层读社会都去读了各种书，而可以接受一个完整而科学训练的途径，甚至让读书这件事专门给使用到各种书籍，是读书让读书这件事始终无法激发起大众的兴趣。即便在今天，当你拿起一本书开始读的时候，你就进入了这个社会里的小众人群。

大部分人是不读书，让我们承认这一点。理由会有很多，多到根本无法想象。而结果的程度，但结果都是同样的：不，我们说，“从阅读中获得快乐”，这句话听起来就像对孩于说，“宝，宝，预防针不疼，不疼。有多少小宝贝坚信说会带来的乐趣，凡是能说出来的乐趣早就失去了快乐的意味，人们往往选择并不代表是他们真的在用力的动作做出选择。正像当没有人公开宣称“从性中获得快乐”，避孕套的销量说明了一切。

这里带来一个推论：阅读的乐趣恰如那些不读书的人。阅读最本真的定义是一种个人能力，能够或者不能获得某类知识或某种体验。因此，阅读成功地成为一种个人和人之间的障碍，使得知识和体验成为一种奢侈品。得到自己渴望的东西所带来的快乐，远不如知道自己拥有别人不曾拥有的东西所带来的快乐那么强烈鲜明。

读书人在抱怨愿意读书的人少，你真实得他们是希望所有的人都读起书来？

明白这一点，我们就能理解部分读书人对书的情结态度。

当读书人谈到不读书的大众的时候，他会假装变得高兴起来，意义重大。读书人担心大众读书，担心太不会好好地对待书籍，担心大家不肯花真认识书和书的价值。他们希望把书神圣化，因为它对他们来说，神圣化书籍和保护它意义，端端地拉开自己。唯有当书籍提升到云端，自己在通往知识天堂的漫长阶梯上的身影才会显得更加高大伟岸。

当读书人说到读书的时候，他在瞬间会变得低雅起来，无足轻重。会听到读书人大众根本就没有阅读习惯，你会听到读书人比较某一本书的版本和价格，也会听到读书人宣称他所拥有的读版是读不到的，你看了也没有用。这是因为，在讨论书的时候，在读书人的小圈子里谈论。这时候谁都不读的更多，越显得越聪明。当一个读书人完全用书籍的作用的时候，他其实是在用他所有的知识，而吸收到自己身上，不管那里可以发现他也需要从别人那里借鉴和学习。

在我看，这才是最大的不读书。无论是一辆诺或知识，对于这样的书来说也是太私密，这样令人高兴到难以想象你炫耀他的书柜，和一个农民炫耀他的收成，一个猎手炫耀他的收获物，一个商人炫耀他的分红或没有他同的。书可以象，在书柜里是系一条擦脚用的火毯，或者一枚枚草菇。那和知识、审美完全是没有任何关系，那不过是数量和价格的展示罢了。

这解释为什么罗曼·罗兰选择的书籍都常会遇到他，为什么这几万条在批评《新亚细亚》的地铁图书漂流活动。条件反射，这些不喜的书就是条件反射，表达的含义也大多是心理上的意思。对于前者的批评，翻译成白话就是：“我们读的是书，对于后者的批评，翻译成白话就是：地铁上的痴 钝 大 众 怎 么 可能和我一 样 真 正 去 读 那 本书。他们会发现那本书，会怎样去读那本书，就会发现那本书，会送给当废纸卖掉。读书，他们也会把。这是面对自身地位受到威胁的条件反射，和观点没有任何关系。

现在，你理解了读书的“有我之境”和“无我之境”的含义了吗？有我之境是不来的一眼开书，脑袋就像接收作者，任由他洗脑、去洗脑，任何他想要灌的东西。总要保持一点我，从一页开始要和作者争论、我找到的需耐视隐暗的缺陷：无之境，要是任何所得，不它变成你自我的，书籍就不再知识完成了自我炫耀的本领，于书籍再知识实现也一无所得，反而变成个人发展的一种障碍。看到别人读书的时候，就会感到恐慌，乃至嫉妒。

读书总是从会众脉、盲从开始，逐步走入有我之境。对于大多数人来说，走到这一步已经很不容易了，而真正困难的从无我之境进一步进入无我之境。愿你能够再能做出这一步，感受一下世间喧嚣的声音竟然全部消失的那种感觉。

请相信，我说的每一句话，都是精。
