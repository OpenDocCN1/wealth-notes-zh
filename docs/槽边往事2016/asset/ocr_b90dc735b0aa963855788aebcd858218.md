# # 和虚无感对抗

唯有孩童才会每天睡前都盼望着新的一天到来，因为长大成人之后我们都知道，想要一整项满意是一件多么不容易的事情。几乎没有人会敢于大声宣称自己每天都过得充实而满足，无聊和空虚随时都会突然出现啃噬我们的心灵。如果我们仔细观察的话，会发现周围的人经常周期性陷入茫然，极度想要做点什么但是又不知道该去做什么。

现代科技最伟大的发明是手机，手机上最伟大的技术是APP通知机制。手机24小时随身，APP上的小红点随时准备诱惑我们于空虚之处燃烧的无聊之焰。通知机制诱导我们可以“实时”地获取最新的消息，为此，我们平均每天打开朋友圈超过50次，在今日头条上平均停留70分钟以上。在乘车时，在等电梯时，在上班的间隙、在蹲在马桶上时，小红点都可能成功地勾上人生中无法消遣的虚无感。只要还有手机和大拇指，我们就有事做，就可以避免停下来想，就可以保持一直有事做。

我们甚至因此改变了大脑的工作方式。我们不再像传统的人类那样，用串行的方式思考，而是如同电脑一样，大脑变成了并行处理器。我们听着音乐读文章，中途不断被微信聊天信息打断，需要一次次切出去回复，然后再一次次切回上次读到的那段话继续下去。我们同时处理手机上的各种通知，从更新消息到垃圾短信，从快递通知到朋友圈回复，于是我们也逐步习惯了自己大脑出现的快速遗忘现象。我们心里明明记得有一件事情要处理，而且那件事想不想发生在几秒钟前，但我们就是死活想不起来——在过去，这是70岁以上老年人才会出现的生理现象。

并行处理的方式，几乎是用一种刻意训练的方式让我们分散注意力，从一个点迅速跳到另一个点，让我们无法长地去专注于一件什么事情。我很多时候一个事实，那就是现在吃饭的时候不要做任何重要的事情，因为玩手机时随口说出的“好的”并非是明确的肯定，更不用说是严肃的承诺，它是表示“我在此”，“我对你保持了礼貌”而已。由此，我们得以逃避因为专注所带来的痛苦。

只要需要我们集中注意力，花五分钟思考一下当下的生活，思考一下手头的工作，多半会立即跳起来。因为我们会迅速发现人生的真相：生活之下是看不到底的虚无，我们小心翼翼地所作为有什么意义的时候，这种巨大的虚无感就会从五光十色的生活之下泛起，转眼间就把我们吞噬——因为最终糊的结局都在那里等待着我们要，把一切努力全部归零。我们一次把目光强行从终点转回来，努力激发心底里对生活的热情，否则简直都无法继续下去。

大部分时候，我们并没有找到热情的那种幸运，所以我们宁可陷于琐碎。人们说手机是为了满足碎片时间而生，事实上是我们主动打碎了时间，把一整天切割成无数碎片；我们更乐于在碎片里待着，而不是面对大段大段完整的时光，一不留神就被虚无抓住。同样的，所有忙忙碌碌的人里面，多数人其实无实无虚，只是忙到本能会占用思考的时间，从而避免了感受虚无的可能。忙人要说他闲下来不杀了他还难受，让人难受的不是无所事事，而是内心空荡于自己不断的一切有何意义的疑问。这种疑问一旦升起，心里原本以为坚不可摧的依仗就会彻底崩塌。

在我看来，人生的本质就是一个不断和虚无感对抗的过程。逃避并不能解决任何问题。如果专注在事物本身让我们觉得痛苦，那么就应该让这种痛苦来得更猛烈一些，和浅尝的欢乐和琐碎的空荒相比，充满活力的痛苦让我们更深入地进入到生活中去。或早或迟，我们会发现对抗虚无的唯一武器是创造。虚无感吞噬一切断，粉碎一切存在，但是创造却不断带来新生，重新为生活、为人生赋予意义，制造出新的存在来。哪怕是一张照片，一篇文章，从无到在这个过程中也能大大消解虚无感。对于许多人来说，一生中第一次意识到自己如此强有过的存在，只是因为自己做为父母。孩子同样也是创造物，当孩子躺在自己的怀抱中沉沉睡去，因为手臂上传来重量，因为它全部保留的信任，甚至它可以把虎气的阴影尽数驱散，在这一刻感到内心里比充盈。

这些年网上，人们最喜欢问我一组问题是：如何解决我内心的空虚和无聊？如何能激发我对生活的兴趣？如何不让自已再感到迷茫？我的答案永远在：去远点点什么吧！刷手机、看电影、读小说、履及五洲四海、用物品把自己家填满……人们都在做这些事情，但其中没有一样是有用的。它们最多可以逃避虚无感于一时，唯有创造才能谦虚地做无垢，创造一点你之前不曾想过的事物，你从来不敢去尝试的事物，一样尚未在世界上出现过的事物。

你在春天里放飞一只你做的风筝，真以为快乐只是因为那天的风么？
