# 聊聊工匠精神

![](bbox=[0.08, 0.04, 0.15, 0.07])

什么是工匠精神，我到现在都没弄懂。就我的观察而言，在这个时代里，任何人只要进入某个领域超过三个月，就可以对外宣称自己拥有了工匠精神，而且已经开始着手创新甚至是颠覆全行业了。所以我猜“工匠精神”这四个字，大概是某种速成学校的毕业证书，方便梗在自己家门口，作为给自己挡风的门神神用的。

作为一种自目标，工匠精神针对的是所谓“浮躁”的这种毛病。不过是另外一 个话题，因为在我看来，任何一个时代都 很浮躁，若是有什么时代真的很深沉，那么绝大多数人是熬不过几个月的。否则，寺庙里的短期出家修禅位应该人满为患才对。提出工匠精神这四个字的人，主动站在了浮躁的对立面。然后期待大众看不出 这其实是一体两面，结果大众竟然真的就 没有看出来，简直让人震惊极了。

浮躁不好，为什么？因为总是想走捷径， 总是以成败作为唯一标准，是廉价成功学最恶劣的人工果。那么，工匠精神为什么 好？因为工匠精神鼓励人认定真做事，鼓 励坐穿冷板凳的精神，因为工匠精神注重 手艺和质量，因为……然后呢？做完这一 切之后，指向哪里？认认真真做事，做到 一切之后却不管后果？认认真真做事。然 后再喝点酒不害怕丢脸。坐穿冷板凳， 然后呢？然后一船名动天下闻。如果一开 始就告诉你：认认真真做事，做到死都没 有任何人留意：一辈子坐冷板凳，坐穿了 所有板凳都没有任何人关注。那么，还有 多少人愿意相信工匠精神？

说到底，工匠精神还是成功学的另外一种表现形式。如果没有成功作为未来的背 书，大概没多少人愿意去尝试一下。而且， 它的巧妙之处在于它是一种上妙的恭维。在这个世界上，每天有太多人做出了努 力却得不到自己期待的結果，工匠精神四 个字是一种强有力的心理安慰—我不是 失败，只不过是我为了秉承工匠精神而不 得不在此刻忍耐生活的不公而已。但无限 有了工匠精神，所以我的明天依然是充满 光明的。对于真正的成功者而言，在自己 身上贴上工匠精神的标签也是一种需要。因为这样一来，别人获得的成功是因为时 代的浮躁，是一种让人鄙夷的成功，而自 己的成功则是一种为世人所尊重的成功。

我觉得一个人最重要的特质之一，就是保持头脑清醒，不要自我催眠和自我欺骗。否则，自己很可能会变成一个极度虚伪的人。想一想看，我们自己生活在一个怎样的时代里？15年前，我买了自己手第一部手机。现在我所有的家里都没有了座机，而我的手机的主要用途已经不是打 电话了。19年前我第一次上网的时候，互 联网主要用在少数科研机构使用，而互 联网现在每日生活的基底。如果我们每活 一年，所经历的变化前人可能要花几十上 百年时间。

在这样一个疯狂变动的时代里，每个人都 坐在一辆零件不全的车子上向前飞跑。这辆车车子一路颠簸，不断掉落零件，而我 们每个人的脑袋一样的边缘车一边往车上 安装新的零件，测试新的功能。一方面要极力维系车子，让它不至于中途散架；另 一方面还想想尽办法让车子跑得快一点，再快一点—因为不知道下一站会发生什 么事情，而我们要都相信到了一站有可 能拿到新的零件，可以组装出更强大的引擎。而在这一路上，车子的舒适性和外观，在我们思考的优先级上基本排不上号。我们不是靠工匠精神走到今天，我们是靠冒险精神和拼手速、拼人品走到的今天。

现在，拿在你手上的这个“得到”APP按照工匠精神的标准，你觉得可以打几分？三个月之前呢？来，我帮你回忆一下：三 个月之前，“得到”APP没有好友分享，没有字调调节，没有拉黑功能，没有大量音频节目，没有语音文件连续播放功能。如果我们真要说谈什么工匠精神的话，这个APP一开始根本不能跑起来。但是，它还是上线了，而且一路疯跑到现在，每一周都在不断迭代升级。不但撑住了越来越多的专栏作家和他们的读者，而且在不断自我完善和升级。如果我们一开始就要求工匠精神的道路的话，那么它们到现在都不必能用得着，因为它还欠缺太多打磨，不可以直接交付到用户手上。

在一个高速变化的时代里，最重要的问题是0和1的问题，也就是有和无的问题。对于三个月前的罗辑思维团队，有“得到”APP和没有“得到”APP，那是天差地别的差异。而工匠精神所要解决的是75和80分之间差别，在有和无的问题面前，那5分什么都不是。但为了多这5分所需要付出的代价，会让1变成0，就是任何人均承受不起的。哪怕你认为10分，甚至20分，这样的代价同样让人无法接受。因为解决这10分、20分的差距，可能会错过聚拢上百万用户的机会。
