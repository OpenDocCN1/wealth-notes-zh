# 如果世界重又残酷起来

年末就是个数字游戏，各种各样的泡泡飞满天空，大家努力找个发奖金的理由。这不是第一天，如此，也是很多年末一直都这样。昨天，我认识的技术鸟冯大辉表示说，其实在互联网这个行当里思后吃饭并不是太困难的事情。我承认他说的没错，而且担心也没正是因为——日子过得太容易，太轻松，简直不像是真的。

说这话大概很多人不那么爱听，又会拿自己供房养孩子何等艰难来反驳我，证明自己活在巨大的压力之下。不过在我看来，这世界上绝大多数概念都是通过比较得出来的，看和谁比、看怎么比。在我的童年时代，一周只有一天休息。在唯一的童年休息里，如果我想要吃一根冰棍，需要步行一个小时，才能从我家乡到服务社。只有冰棍，没有雪糕。更为没有的是，即便有，我没有钱去买。因为那时候除了领工资之外就没有什么赚钱的方法。生活就像厕所的地板，人就像是镶嵌其中的瓷砖，一动能不能动，哪里都去不了。

在我的青年时代，曾经在云南西北部的藏区呆过一段时间。因为和当地人有些交情，所以在其后多年里我还常会往来走动。每次当我重逢的时候，都会去问一下旧藏区旧识的近况。几乎每一次都有人死去，因为喝毒，因为打死的活、生病，甚至是因为磕石头。如果没有死，人也总是因打死了别人翻山越岭逃到尼泊尔去了。想象一下这样的生活：命运就在不远处巡视，随时像征兆地笼罩下去，杀死你周围的某个事。银行和幼儿园不会那么吧，你觉得自己压力很大，说明你起码还活着。

稍微再往远一点说，官方统计的数据称抗日战争中国军民死伤3500万人，当时号称“四万同胞”，也就是说十个人里就有一个因为战争而死亡或者致残。那是一个什么样的世界？活在那样的一个时代又会是什么样？那时候的中国人压力大么？活得不容易么？1940年代距离我们今天又有多遥远？不到80年。

有人大概又要反驳：为什么总要和过去比？那么，我要反问一句：被告你这个世界会一天比一天变得更好么？谁保证过我们会始终处在稳定的增长之中？谁保证你今天的子日可以永远继续下去？这个世界曾经如此残酷，战争、饥馑、瘟疫接踵而至，一个人需要非常思维和极端努力才能幸运地存活，随时准备迎接自己的严厉惩罚和考验。每过一天都感觉像是命运的恩赐——它曾经是如此的不可不同，以至于相比下来它今天样子简直可以称之为温和和慈祥。

之所以我们觉得一日胜过一日，是因为世界正以某种特定形式运行。如果世界的运行方式发生了变化了呢？1910年的人们，怎么会想到4年之后世界就会陷入战火？1919年的人们，怎么会料到仅仅20年后世界就重开战端？从历史上看，这个世界总是动荡不安的时候居多，对人们更多呈现出严厉残忍的一面。这几十年来我们没有容易过什么，也没有做错什么，过得相对有容易，无非是世界的性情比较好罢了，并没有谁能保证它会这样继续下去。如果世界重又残酷起来呢？

年末就是个数字游戏，各种各样的泡泡飞满天空，大家努力找个欢乐起来的理由。说服自己日子已经这样，也必然这样下去，仿佛建就在泡泡上的世界不如此突然坍塌破碎一般，其他泡泡从来不会温和慈祥，不曾盖过另外一面一样。然而，那种深深的震撼感和无力感提醒着我们，变化在极为微妙处细微地发生着，世界不会这样一成不变地继续下去。

祝你新年快乐！
