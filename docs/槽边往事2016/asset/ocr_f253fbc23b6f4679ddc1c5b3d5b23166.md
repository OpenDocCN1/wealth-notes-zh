# # 自行车大战

![](bbox=[0.08, 0.04, 0.13, 0.05])

今天早上限行，尝试了一次摩拜单车，觉得这种模式挺有趣的。回想我当年住在地铁站附近的时刻：经常发现地铁站圆周的自行车有潮汐现象，早上人们拖走地铁的到来，骑上自行车完成从地铁站到公司的最后1.5公里；傍晚人们骑车回来，存好自行车下地铁回家。当时我就在想，如果住的地方也比较偏僻的话，一个人岂不是要两辆自行车了？

现在看来，一些互联网公司正在试图解决这个问题。它们的方式大同小异，都是公司主动在城市投放一批自行车，用户用手机APP找寻离自己最近的车辆，用APP开锁然后骑行，按时间收费。到达地点之后，锁车就可以走人，自有其他需要用车的人来把车子骑走。就像我在今天早上那样，在住处附近走了100多米找到了一辆车。我花72分钟骑了3公里，为此支付了1元钱。骑到公司之后不到半小时，车子就被一个需要的人骑走了。

摩拜单车骑起来太累太颠，于是我就在它们的体验馆里吐了一番。结果許多人回头推荐我OFO共享单车，说这一款体验更佳。随后我做了一点研究，才发现摩拜单车和OFO共享单车之间的战争早已经开演。而且，这场战争本身非常有趣，可以说是次大型创业实践，面对相同的问题，两家公司用类似的方法试图加以解决。但是由于双方在出发点上的差异，和对中国社会不同的看法，造成他们在做法上的巨大差别。

为什么摩拜单车又重又颠？因为摩拜单车一开始就认定了两件事情：

+   1. 尽量不要自己去维修车子。
2. 假定这个社会上的坏人多。

为了尽量不要自己去维修，那么车子就要做得尽量简单和坚固。不想随时补胎，那么就用实心胎；不想修链条，那么就用轴传动；不想跟工人为GPS和电子锁更换电池，那么用骑自行车充电。做了这样的考虑和设计，自然车子骑起来比较费劲，而且硬邦邦缺乏弹性。可是，对于运营方来说，减少了很多运营和维护上的麻烦，据说每辆车按照设计可以运行3-4年。

又因为假设这个社会上的坏人，所以摩拜单车是专门定制的自行车，造价高达每辆3000元。定制的意思就是四个字：给了没用。所有的零配件拆下来，也只能用在摩拜单车上，最大限度杜绝了盗窃。GPS可以追踪车子的位置，如果变成私人使用，摩拜单车的工作人员一定可以追到府上，3000元的单价已经足够警方立案了。

OFO的想法则完全不同，它最早在大学校园里展开，解决师生在校园内的短距离交通问题，减少校园自行车盗窃事件。可以，OFO的自行车来得不低，一部分来自校园旧车改装和废旧车回收，一部分来自学生自愿共享。对于愿意分享自行车的学生来说，OFO会提供他们免费租车的优惠。所有的自行车收上来之后，统一涂装，然后对外租售。这样一来，OFO用车的成本降低至多有200元人民币。

因为一开始就在校园内部运营，所以OFO共享单车不存在在园内更加简单。同样是停车之后，摩拜单车会提供车辆的GPS实时定位消息。而OFO共享单车的定位依靠最后一位骑乘车锁车时的手机定位，如果有人推车，或者忘记锁车，那么很可能按照手机APP定位找不到车子。但是，OFO共享单车并不太担心这样的事情——车子一般都在校园内，而且成本足够低。所以，OFO共享单车是一个好的人的世界里面运转，而且骑起来和其它自行车没有多少不同，为此，哪怕需要支付维修费用也在所不惜。

现在，最新的消息是OFO共享单车开始走出象牙塔，进入到社会生活中去，开始向社会投放自行车；而摩拜单车开始提供新版自行车，镂空轮盘以减轻车重，恢复链条传动以提升体验，甚至连车轮还加了一个菜篮。在北京、上海、广州、深圳，随着两家不断投入兵力，大战一触即发。对于我们来说，最多不超过半年，就会看到两种不同的想法最后谁能胜出。

究竟是默认大家都是坏人，运用产品的科技含量提升厌恶大家，降低运维成本大获全胜呢？还是默认大家有好奇心，通过满足用户需求办法逐步提升技术水平，用车海战术占领市场、克服损耗，最终一统天下呢？我也不知道答案，但是，两家公司分别代表了面对中国现实问题时候的两种典型的思考方式，这一次的胜负无论对于企业主还是员工来说，都该很有借鉴意义。

这里，我想提交一个私人的想法供你参考：自行车大战能打得起来，依仗的是两家公司身后的风投的资金。而风投不是雷锋，总是希望能看到投资收回。我不认为自行车项目在短期内有任何盈利的希望，所以，风投看中的应该是每天平均每人打开两次的租车APP本身。在这个时代里，已经很少有高频使用的大家APP。所以，无论是OFO共享单车还是摩拜单车，最值钱的都是一群每天打开两次APP的用户。最后的问题就是转化为：每辆车能买几个这样的用户，每个用户购买成本是多少？
