# 懂事的孩子的难过

什么叫做‘懂事’（我活了快70年了！还说各种懂，我要说，起码得像我《本手棋手》里写的那样吧？）明瞭告诉他什么是让你，什么是不让你。看似从来都是一种坏事，定义模糊本身就就是使泛，所有的“灵活性”，因为如何定义懂事权力全在评价人的手里。这样的话，懂事与否全看庸而定，弹性的‘把手’足可玩死人。

我最早接触‘懂事’的概念还是个孩子，老师给我们讲《孔融让梨》的故事。孔融是个懂事的孩子，因为懂得帮助梨给他兄弟们抢。我听之后唯一的感觉就是觉得梨子一定好吃极了，必须是世界上最美味的东西，否则不至于吃个梨都让来让去。要么上顿大白菜，要么在家庭饭桌上彼此谦让汤头，弄得满桌子汁水四溅一样。

在吃了第9个梨子并且失望之后，我不禁开始暗暗抱怨：孔融之所以要让我让步，是不是知道梨子并不好吃，他挑选最小的个儿，那么大的宿舍就知道吃，阴暗的想法一起，就会完全停不下来。从听到《让梨》的故事的那一天起，一直到今天我都留有一个疑问：为什么一个小小孔融，爱吃怎么吃，有什么好的呢？

尤其是我成为了一个理科生之后，想法显得更加具体了：为什么不要把梨子分成大小三部分，然后按人头分配，每个孩子拿当然可以拿中号，小号拿大点，为了公平起见，孔融负责分梨和切果，他最后一个拿就好了。这样，不需要任何人‘懂事’，也不要任何人在做牺牲。大家也能量才公平地吃到自己的想要的人都还可以留，大话。

由此，我得出了一个坏猜想：所谓‘懂事’，意思是用作它作为迫使人接受不公平处理的借口。尽管在许多时候，这个字面上的意思的确有些尴尬，‘不自知’，安分守本的意思，但真正的妙计是设计时，大多数情况就是为了让人去牺牲我牺牲，放弃忍受，忍受不公。

只有一个出国进修机会，因为你年轻，所以要求你让出名额给老师，让了老师去留学；晚上需要导师带，因为你是很优秀，要求你帮老师去睡觉，要不就是需要为兄弟去死；你是你的后，除了的呀，你还需要跟送礼老头站牌，这么做了才成后，打掉了牙齿和血吞，这大概就是成年之后‘懂事’的真正含义吧？

那么，我们怎么忍心赞叹一个小孩懂事事呢？‘乖’，懂性分点吃一口’，从‘用舌舔干净小拇指手里’让到‘让小孩来摸头发就乖一点’、‘真懂事’，据说小时候可以让孩子明白为的快乐；那懂事成年后听到分量两个字，感到和打印到就完全非事的小孩，小孩是不要快乐的小孩，让了梨的小孩的本质是孩子让性，注定了一个人要承担最小最甜的一个梨子，所以，需要去这种隐性一个好好念了哲学了。

身为大人，要么想办法为兄妹兄弟姐妹们带来更多的梨子，要么为他们设计一个公平的分配方案，可是这样都太麻烦，这远不如直接用道德神来称量。兄弟贤弟则比特别，这高尚的收获。世界上有两种公平，一种是懂事的公平，一种是不懂事的，不需要任何公平麻烦，要就是，要平均。懂事的公平就是简单分一般做出裁定的那个，剩下的人均分配公平。就像是一群狼，今天的肉不够吃了，一头扎的饿的，小狼自己走到木架前叼肉里，主动加入跑队伍了。于是他的兄弟姐妹一边吃，一边赞美：这孩子真是懂事！

别的地方不得清楚，但是在中国的社会里，谁谁懂事事是好人一样，潜在的含义是：你是最弱的一环，可以被最先牺牲。

我们经常会看到为怪的一幕——在一个普遍推崇和褒扬懂事的会里，所有，人们做事的时候就像挤公交车一样先总，让，让着来，让孩子。尽管看见任何懂事的迹象。总是看到看到哭泣的孩子们。懂得无视懂事的常态总得到满足，而某些小可怜要懂懂事并且对该深感不疑的人，却又只能在一边吧里去看着他们大口大嘴吃。

你懂事吗？你有懂事吗？
