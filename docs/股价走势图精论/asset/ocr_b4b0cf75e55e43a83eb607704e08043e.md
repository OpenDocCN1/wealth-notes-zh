# 跳空缺口

股價開盤偶爾會高於前一天的最高價，然後繼續走高。當然，股價開盤也可能低於前一天的最低價，然後繼續走低。這種發展稱為跳空缺口（Gap），具有不尋常的意義，因為正常的情況下，任何一天的價格交易區間，應該會與前一天／後一天的交易區間重疊。跳空缺口可能提供資訊，前提是分析者首先必須判斷缺口的類型，以及股價走勢的狀況。
