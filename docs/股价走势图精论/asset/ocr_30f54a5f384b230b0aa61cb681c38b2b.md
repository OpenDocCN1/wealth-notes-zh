# 陷阱——與獲利

圖形判讀是一種藝術，不是嚴格的科學，如果忘掉這
點，將有很多陷阱等著你。以下讓我們討論一些圖形判讀的
限制：

突發事件：一些毫無徵兆的突發事件，往往會讓價格趨
勢忽然反轉，例如：戰爭的恐懼、「和平的恐懼」、政府對
於股票市場採取的意外行動，以及足以影響個別公司或產業
的重大災難或事件。投資人或許還記得，當艾森豪總統在
1956年心臟病突發時，股票市場在幾個小時之內就減少數十
億的市值。股權戰爭、反獨占行動、新產品、企業合併等事
件，都可能讓既有趨勢急劇反轉。圖形分析根據的是市場心
理，不是神奇法術；但還是有些圖形分析的「基本救義派信
徒」堅持，所有的事件在發生之前，都會先顯示在股價走勢
圖上。總之，圖形分析不是碟仙。
