# 反轉日、跳空缺口與島狀排列

經過多年的發展之後，圖形分析累積了許多相關術語，其中有四種是投資人應該熟悉的型態，它們都代表突然發生的反轉走勢：關鍵反轉日（Key Reversal Days）、大量換手日（High Activity Days）、跳空缺口（Gaps）與島狀排列（Islands）。做為價格趨勢的預測型態，它們的靠性雖然頗有限，但確實經常出現在走勢圖上，偶爾會導致主要趨勢反轉。所以，如果遇上這些型態，圖形分析者還是謹慎為宜。
