# 走勢圖3

7、8月份開始的上升趨勢發動之前，先是一段長達幾 個月的橫向盤整。1961年1月，科維特股價開始加速上揚，趨 勢線也向上彎曲，3月底進入飆漲的「爆發性」階段，股價 直線上升，意味著上升行情即將告一段落，甚至出現重大反 轉。如同第2章解釋的，向上彎曲的趨勢線，通常都發生在 多頭行情末端，但很難精確預測這段飆漲走勢將結束於何 處，因為股價很可能在短時間內出現重大漲幅。就目前這個 案例來說，圖形上標示的最高價（68½）也就是短期頭部。 1961年6月，價格回檔到47½，然後又恢復漲勢，1961年的最 高價為$129。

# 走勢圖4

向下彎曲的趨勢線，情況類似對應的上升趨勢線。剛開 始的階段，曲線的彎曲程度很緩和，然後愈來愈陡峭。如同 這份走勢圖顯示的，成交量原本很穩定，直到跌勢發展一段 期間之後，成交量才慢慢放大，高潮階段的成交量則顯著放 大。讀者不妨參考科維特的向上彎曲趨勢線（走勢圖3），高 潮階段並沒有伴隨出現不尋常的大量。可是，在福林科特的 案例中，高潮階段的成交量很大，但每天的價格變化並沒有 不尋常之處。高潮階段通常都會發生激烈的價格波動，或是 顯著的大量，也可能兩者同時發生。
