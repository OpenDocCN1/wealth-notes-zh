# 走勢圖49

在這份走勢圖的涵蓋期間之前，股價由1960年10月份的
23½起漲。2、3月份的兩波大量漲勢都停頓於30，但4月3日
與4日則夾量向上突破（前一份走勢圖也在同一天向上突
破）。這時一般圖形分析者應該會認爲，這是另一波漲勢的
開端。可是，上漲動力很快就消失了，兩個星期之後，價格
跌破4月3日向上突破線形的低點，重新進入28~30支撐區。
這波跌勢等於「關上」陷阱的大門，而當價格跌破28的有效
支撐，則是把大門「鎖上」。多頭陷阱引發的跌勢，只把價
格帶到24附近，但先前的支撐28轉變爲上檔壓力之後，有效
壓回7月份到11月份之間的四波反彈走勢。

# 走勢圖50

空頭陷阱與其他底部反轉排列之間的差異，在於價格跌
到低點之前發生的密集交易型態。如同這份走勢圖顯示
的，在空頭陷阱出現之前，價格曾經做幾個月的橫向盤整。
空頭陷阱的結構與多頭陷阱類似，但價格向下突破的過程
中，通常不會出現大量。這種差異之所以會發生，或許是因
爲市場的空頭（放空者）人數顯著少於多頭，而且放空者通
常都是很老練的玩家。本章討論的四個案例，其中有三個屬
於多頭陷阱；事實上，多頭陷阱的發生頻率遠超過空頭陷
阱。
