# 兩百天移動平均

股票市場技術分析研究者經過多年努力，嘗試找到某種方法偵測或衡量趨勢。很多人採用所謂的**移動平均**，藉以平滑每天的價格波動，並因此而突顯真正的趨勢。如果經濟學家準備採用某種月份數據，就必須想辦法減緩單月份的數據波動，這可以藉由移動平均方法處理。舉例來說，對於3月份的運用數據，可以計算2月份、3月份與4月份實際數據的平均值；同理，4月份的運用數據，則計算3月份、4月份與5月份實際數據的平均值。把三個月期的移動平均值繪製為圖形，就能相當可靠的反映趨勢。股票分析也可以採用相同的技巧。前一章討論的膽洛線，就屬於移動平均的一種。
