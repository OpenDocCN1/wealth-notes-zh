# 走勢圖35

本章討論的四種三角形，這份走勢圖內出現兩種，總共
有四個排列，分別標示為A、B、C與D。A屬於上升三角
形，相較於其他三種類型，這是最可能成為連續型態的三角
形排列。B與C都是一般大小的等腰三角形。就目前這個例子
來說，B位在整段漲勢的中點位置，屬於連續排列，C則是反
轉排列。請注意，價格向下突破三角形C之後，上升趨勢線
曾經發揮支撐功能。不久，價格夾著大量突破趨勢線，主要
趨勢正式向下反轉。D是一個相當大規模的等腰三角形，屬
於連續排列。

# 走勢圖36

1961年多頭行情內，比較顯著的型態都屬於三角形排列
(分別標示為A、B與C)，而且規模都很大。三角形排列陸續
出現，當時可能造成圖形分析者的困擾，但它們實際上都是
連續排列。年初，股價大約在88；年底，股價上漲到166。A
與B是相當完美的等腰三角形，C則是罕見的顛倒三角形。請
注意，C曾經向下假突破，不過這對於圖形分析者應該不至
於造成嚴重困擾，因為這類三角形經常出現假突破。話說回
來，顛倒三角形顯示買、賣雙方都高度不確定，而且發生在
歷史高價區，很可能發展為頭部。就這份走勢圖的資料顯
示，C向下突破並沒有跌破主要支撐。另外，A與B可以視爲
失敗頭肩頂排列的兩肩。
