# 走勢圖1

這份走勢圖顯示，柯爾-馬基公司股票在不到七個月的時間內，價格成長兩倍。最初七個月內，價格沿著上升趨勢線（實線）發展，整個股價波動大致上都落在上升通道內（上升通道是由趨勢線與其平行虛線界定）。進一步分析可以發現，在漲勢發動的第一個月內，上升趨勢線就存在了。1961年4月，價格向上突破通道上線，展開加速的爆發性漲勢或高潮行情。這種爆發性漲勢結束之後，通常會出現暫時性或主要頭部。這段飆漲行情是由1股分割為2股的消息驅動，實際分割時間為5月1日。截至1962年初為止，股價仍然遠低於這份走勢圖顯示的歷史高價。

# 走勢圖2

4月底，價格向上穿越通道上限，情況與前一頁的柯爾-馬基很類似，這種爆發性飆漲走勢通常都發生在上升趨勢的末端。至於隨後的下降趨勢，價格基本上是沿著下降趨勢線發展，除了偶爾出現的劇烈反彈，反彈高點銜接為通道上限。這種行情很適合來回操作；換言之，在下降趨勢線附近買進，在通道上限附近賣出。經過漫長的跌勢之後，價格終於在11月份的第一個星期突破通道上限。11月底，價格重新拉回到通道上限附近。另外，從11月份開始，成交量型態也發生變化——價漲量增，價跌量縮。
