# 支撐與壓力

你是否有過類似的經驗：股票買進來之後，價格就下跌，心中只想著——但願有解套的機會？同樣的，當你賣出股票之後，股價就一路走高，你希望自己還有機會根據當初的賣價重新買回股票？事實上，這都是人性的自然反應，而且也會顯示在股價走勢圖上，構成所謂的**支撐與壓力**。

支撐水準就是股票需求將顯著增加的價位。反之，壓力水準就是股價供給將顯著增加的價位。這類的區域並不難判定，舉例來說，股票曾經在此大量換手的價位，就屬於支撐／壓力（兩者的角色會變換，我們稍後會討論這點）。股票交投非常熱絡的價格區間，也是分析師在走勢圖上所稱呼的密集交易區間，請參考圖11。
