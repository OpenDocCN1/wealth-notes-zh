# 大盤指數

截至目前為止，我們討論的主題都是個股。可是，對於每個人都談論的「市場」又如何呢？

事實上，沒有人會針對「市場本身」投資，就好比沒有人會針對賽馬場上的所有馬匹下注一樣：投資人選擇的對象是個別股票，不是大盤指數。雖說如此，投資大眾仍然很關心大盤指數所代表的整體「市場」表現。如果「市場」上漲，一般投資人的心理都會受到鼓舞，即使他們持有的股票價格下跌。這種現象是可以理解的。就如同華爾街諺語所說的：「當他們打劫妓女戶時，不只會搶走所有的女人，甚至連鋼琴手也不放過。」換言之，如果市場呈現強勁的上升或下降趨勢，遲早會帶動所有的股票，雖然這些股票在任何特定時間的表現都截然不同。這是很合理的說法；大眾對於投資市場與整體經濟的普遍看法，顯然會影響個別股票。我們經常看到，當整體市場的情況很不理想時，一些個別股票所呈現的多頭排列也免不了瓦解。通常這都發生在行情轉折時。沒錯，很多股票的表現往往能夠抗拒大盤，但就任何一支股票而言，展現這種逆勢演出的機率總是低。因此，不
