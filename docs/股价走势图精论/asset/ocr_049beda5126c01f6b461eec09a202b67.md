# 真正的顛倒V形反轉

真正的顛倒V形反轉頭部，其結構基本上是與V形底部排列相反。多數情況下，頭部樞紐點的成交量會很大，成交量型態也呈現顛倒V形。可是，某些情況下，樞紐點的成交量沒有明顯變化，甚至不尋常的少。

# 延伸性V形排列

延伸性V形（Extended V，請參考圖32）的力量不輸給真正的V形反轉，但其結構稍有不同，因此也比較容易精確預測與分析。在樞紐點之後，當價格突破先前的下降趨勢線，隨後的發展稍有差異。真正的V形反轉，上漲行情幾乎是立即啟動。延伸性V形排列則會出現相當大規模的橫向盤
