來說，假定你擁有某股票，價格上漲一段幅度，就在你準備獲利了結時，股價突然回檔。在這種情況下，你是否會覺得自己錯失了「在頭部賣出」的大好機會？若是如此，當你正在懊惱時，假定股價又漲回先前的高點，你是否會有出場的念头呢？如果夠多的持股者都有這種感覺，這個高點就會成為潛在的壓力，即使該高點第一次出現的成交量並不大小。

# # 50%法則

不論是個股或大盤指數，如果價格出現劇烈走勢，專業玩家都會預期某種程度的「技術性反彈」或「技術性修正」。換言之，在一段急漲（急跌）走勢之後，股價隨後應該出現快速拉回（反彈），折返幅度往往是先前走勢幅度的三分之一或三分之二。如果股價急漲，某些短線玩家就會立刻獲利了結；如果股價大跌，某些「撿便宜貨的人」就會進場。可是折返走勢發生之後，股票通常會很快又恢復先前的趨勢。對於比較大幅的價格搖動而言，每當股價折返到先前走勢幅度的二分之一處，就會逢到明顯的支撐或壓力。（圖
