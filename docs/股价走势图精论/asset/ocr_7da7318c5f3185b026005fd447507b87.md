# 變形

除了直線狀的趨勢之外，也有曲線狀的趨勢。某些情況下，如果上漲（下跌）動能加速發展，經常會讓直線趨勢線演變為曲線狀（本書稍早提到的XYZ公司例子，其股價發展就很可能呈現曲線狀上升趨勢）。圖8顯示向上彎曲與向下彎曲的趨勢線。這種曲線狀的加速發展，如果發生在延伸性走勢末端，經常會演變為價格峰位或谷底的高潮行情。高潮行情（climactic action）是指瘋狂的買進或賣出。在這類瘋狂的走勢中，價格會呈現飆漲或暴跌，成交量也會異常放大。這種趨勢線可以利用「法國曲線尺」①（French Curve）繪製，其效果與直線狀趨勢相同。請注意，除非整理階段開始，否則很難預先判斷高潮行情將結束於何時。這種「爆發性」走勢所帶動的漲勢往往很可觀。
