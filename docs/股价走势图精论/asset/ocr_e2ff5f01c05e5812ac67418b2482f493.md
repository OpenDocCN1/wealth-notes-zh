# 走勢圖21

我們利用這個例子說明長期狹幅整理底部排列，發展過程中，成交量始終很小。整個底部排列實際上可以回溯到數年之前（換言之，這份圖形沒有完全顯示）。1960年底，價格與成交量同時呈現曲線狀走勢。有個說法：「底部涵蓋的期間愈長，隨後的走勢愈大。」這個說法顯然適用於目前的例子。11月份，行情還沒有啓動之前，價格大約落在13附近；四個月之後，也就是隔年的3月31日（這份走勢圖的最右端），股價暴漲到44，同年5月份，價格上漲到64。請注意，在整個上升階段，價格從來沒有跌破下檔任何有效支撐（標示爲水平狀線段）。

# 走勢圖22

雖然這個大底部是等到2月底價格夾著大量創新高之後才完成的，但12月份的大成交量彈升已經預先透露多頭訊號。如果研究過去十年來的案例，我們發現很多大漲勢都會經出現類似的預先訊號。股價盤整階段，成交量基本上都很小，每當成交量顯著放大，就意味著股價醞釀突破的契機；如果沒有出現跟進的漲勢，就代表還沒有醞釀成熟。對於大行情來說，等待二個月到六個月是很正常的。按照第3章的解釋，圖形中標示爲「大成交量區域」的價位也是壓力區，一旦克服，往後的漲勢就頗可期待。（5月初的頭部爲「兩日反轉」，請參考第11章的說明。）
