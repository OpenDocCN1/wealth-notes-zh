# 螺旋型態（三角形排列）

如果股價波動的上下幅度愈來愈小，結構就會如同螺旋彈簧狀。彈簧經過壓縮，一旦鬆開，就會產生推動力量。彈簧壓縮所產生的是機械力量，運用到股票市場上，則是買、賣雙方對於行情不確定所累積的力量。標準的螺旋型態或三角形排列，結構如圖36：
