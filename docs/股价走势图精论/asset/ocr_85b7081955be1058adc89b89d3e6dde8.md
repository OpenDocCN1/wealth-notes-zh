# 走勢圖32

這段衡量走勢幾乎精準命中目標。A到B的距離（219－165 = 54），理論上應該等於C到D的距離。C點為201，加上54，所以上檔目標價位為255。該波段的實際高點是2561/2，誤差為11/2點。下跌過程，D到E的距離（256－208 = 48），應該等於F到G的距離。F為232，扣減48，下檔目標價應該是184。衡量跌勢的實際低點為172，後來又下滑到149。非常有趣的，實際G點雖然明顯低於預估目標，但隨後卻反彈到預估目標附近。請注意，B-D-F分別是頭肩頂排列的「左肩」－「頭」－「右肩」。

# 走勢圖33

這個例子說明衡量走勢也適用於「圓性」不佳的個股（麥洛瓦股價波動相當不規則，經常出現跳空缺口，價格排列的形狀不明確）。衡量走勢的起漲點在2月份的低點A（311/2），修正走勢發生在4月份的B（451/2）到C（411/2）之間。第一支腳（A～B）的長度為131/2（=451/2－311/2）。由C（411/2）向上衡量131/2的距離，目標價位為541/2。漲勢的實際高點為55，誤差只有1/2點。當然，絕大部分衡量走勢的預估目標與實際數據都不會如此接近，誤差通常都有好幾點。
