# 狹幅整理與碟形排列

狹幅整理（Lines）與碟形排列（Saucers），是圖形分析 者的夢幻型態，它們非常容易辨識、非常可靠，蓄積的動能 經常很可觀，足以驅動大行情，而且——最重要的——圖形 分析者有充分的時間準備，能夠慢條斯理的在頭部或底部建 立部位。這類排列只有一個很難克服的缺點：很少出現在交 投熱絡的股票。

狹幅整理排列一旦演變爲主要底部，通常都稱爲「長期 底部」(long base)。在價格走勢圖上，呈現細長的橫向整 理，價格波動區間很狹窄，然後突然向上跳動，大幅穿越先 前的價格區間。狹幅整理也可能成爲**主要頭部**，雖然很罕 見，在這種情況下，其形狀就像是平台。
