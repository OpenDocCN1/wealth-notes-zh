歸類為**陷阱**，實際上也是一種**機會**。投資人熟悉某支股票的長期行為之後，操作上通常也會愈來愈有信心。

**載動所有船隻的潮水**：稍早曾經提到，個別股票的型態，可能受到大盤影響而突然瓦解。因此，分析者必須隨時留意大盤的狀況——包括技術面與基本面的狀況。

# # 結論

如果讀者覺得我們特別強調圖形分析的限制，因為一方面是因為我們對於1929年股市大崩盤的記憶猶新。某些專業分析師往往會把走勢圖藏起來，因爲擔心別人嘲笑或責怪他們使用「無稽」的工具。當然，現在的情況已經大不相同。不論是銀行、投資顧問公司、共同基金、保險公司、退休基金或證券商，幾乎大家都會研究圖形走勢。不只是專業人士如此，甚至投資大眾也愈來愈強調技術分析。我看過《股票基本日線圖》訂戶數以百計的信函，把他們的投資勝利歸功於走勢圖。該出版公司並沒有推薦任何股票，只是單純的提供圖形而已，但投資人覺得這些走勢圖讓他們享有競爭的優勢。
