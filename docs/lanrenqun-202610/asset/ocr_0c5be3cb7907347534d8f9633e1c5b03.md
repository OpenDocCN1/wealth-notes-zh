离柏林危机爆发刚刚一年。

报告对苏联及美苏竞争做了以下几点判断：

+   1）美国在两次世界大战、两场重大革命（俄国与中国）、五个帝国瓦解（奥斯曼、奥匈、德意志、意大利及日本）以及两大帝国体系急剧衰落（英国与法国）的历史背景下与苏联展开这场终极博弈。
+   2）苏联是一个被狂热信念所驱动的政权，奉行军事修正主义，无法放松对内动员状态，美国必须实现对其制度的根本性变革（即推翻苏联），并辅以大规模军事部署来应对其征服企图。
+   3）与以往谋求霸权的国家不同，苏联力图对世界其他地区施加绝对权威，用一套听命于克里姆林宫的体制取而代之，“没有任何其他价值体系能与美国的价值体系如此水火不容”。
+   4）因核武器的出现使战争成本不可接受，美苏竞争归根结底是社会经济与政治制度的较量，旨在比拼哪种制度能够带来更好的生活与更具活力的社会，在此过程中会对其他国家产生一种引力效应。
+   5）苏联体制显然不具备西方那样的活力，美国应对“制度比拼”充满信心；1950年美国的整体经济实力约为苏联四倍，若形势不得不演变为工业实力的较量，美国终将压倒苏联。
