一共两条路，你自己挑。

# a. 自己注册（推荐新手走这条）

用谷歌浏览器注册，是当前最稳的。

原因是谷歌浏览器的环境最干净，不容易被平台当成批量注册的号。

具体几步：

+   1. 准备一个干净的邮箱，Gmail 最好，跟你的推特绑一起。
+   2. 用谷歌浏览器打开推特注册页，直接选"用 Google 账号登录"，比填手机号顺，也少掉一层验证。
+   3. 节点要固定。今天是美国，明天是日本，后天又换回来，平台会直接把你标成可疑账号。挑一个就一直用。
+   4. 注册完当场把资料填完，不要空着放几天。

这条路的好处是干净、安全、以后不容易出事。坏处是慢，新号有养号期，急不来。

# b. 买成品号（想省时间的人走这条）

什么时候适合买？

+   - 你等不了养号那几天，想注册完当天就开始发；
+   - 你要做矩阵，一个号不够用。
