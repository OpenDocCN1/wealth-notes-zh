# 2. 优化版【发前八项风控自查打钩清单】（可直接复制存进手机备忘录）

每次发表前，我会逐项检查。清单用于减少遗漏，不能保证没有风险；碰到后台提示或不确定的素材，应先解决具体问题。

+   - 1. AI 来源与真实性： AI 生成图按当前平台要求标注；不伪造现实人物、事件或现场照片。 
+   - 2. 事实与表达：核实知识增量和来源，删掉机器套话；不编造亲历、身份、情绪和对话。 
+   - 3. 素材权利与隐私：确认图片、肖像、影视截图、表情包等的使用权限制；隐藏 UID、token 和个人隐私。 
+   - 4. 避免重复：检查标题、开头和结尾，多篇稿件不机械共用整套句式。 
+   - 5. 内容与互动：不靠无信息量的悬念套取评论，不含诱导导流、私域招揽或夸张营销。 
+   - 6. 图片元信息：不篡改、伪造拍摄设备与 EXIF，不剥离或规避 AI 来源标识。
