# 步骤 4：手机装 Expo Go。

Expo 是一套帮你用 JavaScript 做手机 App 的工具。Expo Go 是它配套的手机 App：电脑上改代码，手机上用 Expo Go 扫码就能看到效果，不用先打包安装。

+   - iPhone：在 App Store 搜 “Expo Go” 安装。\n- 有 Google Play 的安卓手机：在 Google Play 搜 “Expo Go” 安装。\n- 国内安卓手机（华为、小米、OPPO、vivo 等）一般没有 Google Play，官网 expo.dev/go 上 Android 那一行的「 Install 」会跳到 Google Play，用不了。换这样装：

+   1. 用手机浏览器打开 Expo 官方在 GitHub 的 expo-go-releases 发布页，那里放着 Android 安装包（.apk 文件）。\n1. 下载和你要用的 SDK 对得上的那一个。文件名里带版本号，比如 SDK 57 对应 Expo-Go-57.x.x.apk。\n1. 点开安装；手机弹出安全
