# # 十一、违规与避坑大全

# ## 1、违规提示为什么不可信

平台给出的违规提示，90%都不是真实的违规原因，都是"幌子理由"。常见的幌子理由：行文生硬、啰嗦、口水话、注水、文言文、内容质量低等。真实原因90%都是题材问题、内容隐性违规、踩了敏感红线，和文笔没有关系。

平台为什么不说真话？这是反逆向策略。如果明确告诉你具体哪里违规违反了哪条规则，就会有人专门研究规则漏洞批量生产擦边内容。所以用模糊的违规理由让创作者没法精准钻空子。

**正确应对方式：** 不要纠结提示里的理由不要去改文笔，去检查你的题材、选题、敏感点，从内容方向上找问题。

# ## 2、低质量账号标签

**触发标准：** 账号整体60%以上的文章同时不满足这两个指标——文章阅读时长低于1分钟，长文章完读率低于40%、短文章完读率低于60%。是整个账号的整体统计不是单篇。

**后果：** 被打上低质量标签后推荐量直接砍掉90%，属于比较严重的降权。

**怎么恢复：** 先进行申诉处理，如果不申诉去掉这个低创作的违规，之后无论写什么哪怕是优质也容易被冠上低质量标签，申诉不成只能注销。然后提升每一篇文章的内容质量拉长完读时长，删除历史低质量
