| 数据不好，不知道改哪里 | 按“推荐→点击→阅读→互动→赞赏”逐层排查，一次只改一两个变量，不一篇数据不好就换赛道。 |

这套流程的核心不是“让 AI 自己写”，而是把每个容易出错的地方提前设成一道关口：
选题判断 → 样本拆解 → 补齐素材 → 读取人设 → 输出写作说明 → 人工确认 → 生成初稿 → 事实与表达质检 → 发布 → 用数据调整下一轮。

Codex 带来的改变，是让我更清楚地看见：什么可以固定执行，什么必须由创作者自己做决定。它能减少我对着空白文档发呆的时间，能在正文出来前提醒我哪里没有
