# A 股存储为什么和海外存储完全相反走势？

提问：牛牛怎么看待 A 股存储和海外存储完全相反走势？

很正常，其实今年 4、5、6 月份的文章你可以回顾一下，我强烈看空科技，主要理由什么？就是因为很多存储股我算出来是明显的泡沫。当然情绪非常好的时候，股价是可以随便涨的，但最终都会回归价值。

这一段时间为什么美股那边还能涨？因为人家是真有护城河，而且估值也不高。简单点说，你可以想成是石油化工行业：

+   1. 美股那边相当于卖沙特的油：石油成本很低，只要油价涨，利润就暴涨。再加上估值不高，利润超预期，包括对方本身也在签一些长协。
