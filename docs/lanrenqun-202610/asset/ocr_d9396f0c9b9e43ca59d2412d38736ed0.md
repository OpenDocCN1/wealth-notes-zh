# 赛道 Agent 运行时是怎样学习和调用的？

+   - 发稿前调用：当生活奇闻赛道 Agent 准备写稿时，Harness 会自动读取该赛道专属知识库中的《三类常用选题模板卡》、《选图军规》与《合规门禁》，将其作为 System Prompt 注入模型上下文。这样写出来的文案，从第一句开始就带着一线的实战血肉，仍需人工检查事实和语气，知识库也可能过期或录错；
+   - 发稿后回填与自进化飞轮：每天发布后，结合真实的数据复盘（阅读量、流量主收益、微信后台健康度）以及前文提到的有权使用并经人工核实的案例与规则线索，一旦发现新的平台风向或违规苗头，确认适用范围后，调用方法论提炼 Skill 更新知识库里的方法卡，并保留日期和依据。

通过这套闭环，你的知识库不是躺在网盘里吃灰的静态笔记，而是一个每天都在吸收一线炮火、不断自我进化的“动态数字大脑”！
