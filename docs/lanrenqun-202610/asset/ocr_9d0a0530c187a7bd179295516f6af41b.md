# ## 2. 为什么产生如此差距

# ### (1) 开枝散叶有利于踩中风口

我们翻开汇川技术的年报，在其业务栏可以看到，按行业分类，汇川可分为三大类：智能制造、新能源汽车、其他。埃斯顿按行业分类，只有一类，是仪器仪表制造业。

按产品分类，汇川技术可分为工业自动化与数字化、新能源汽车动力系统、新兴产业、其他。埃斯顿按产品分类，是自动化核心部件及运动控制系统、工业机器人及智能制造系统。

两相对比，就是汇川技术和埃斯顿的发展路径差别。汇川是以电力电子、电机驱动、运动控制、工业实时通信、嵌入式软件为基础，向不同行业开枝散叶，形成了收入的开源。

它的业务很广，形成了电梯行业的国产替代，还踩上了新能源汽车这个超级风口，并且电机、电控等产品成为了新能源车第三方供应商的龙头，这才有如此之快的增长。

而埃斯顿一直以来都是垂直深耕，只做工业自动化的上下游，所以虽然做到了连续 8 年位列国产机器人市场第一，连汇川也做不过它，但业务上没有开源，所以营收增速就不如汇川技术。
