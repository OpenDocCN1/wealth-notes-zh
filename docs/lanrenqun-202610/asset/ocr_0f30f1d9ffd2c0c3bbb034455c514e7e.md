# 猫哥原创

今天给大家讲一个知识点，这个知识点叫做购买力平价指数，这个购买力平价指数一般是世界银行在做，因为翻译原因有时又被称为全球各国物价水平指数。

这个知识点看起来很简单，但是绝大多数人经常是搞不清楚的，甚至以讹传讹。举个例子，2021 年世界银行就发布了全球各国物价水平指数，其中中国大陆物价指数大致是香港的 80%，是台湾的 1.2 倍。

很多人看到这个数据第一时间就跳起来，怎么可能？香港的物价明明是大陆的 4-5 倍好不好？台湾的物价明明比大陆高得多好不好？怎么可能大陆物价指数是香港 80%，是台湾的 1.2 倍？
