# 销售：针对 3 个不同客户，截然不同的 3 种卖入过程

后来复盘时，飞鱼哥说：“销售有 10 多种模式，但 99% 的人只会两种。”

一种是产品型销售，介绍产品的功能、特征和优势；另一种是菜单式销售，把自己有的东西列出来，供客户选择。
