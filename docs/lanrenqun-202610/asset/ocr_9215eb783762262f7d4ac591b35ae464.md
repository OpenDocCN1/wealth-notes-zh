# 2. 群聊避坑与爆款情报提炼思维：如何从大群捞出“防雷”与“母题”？

在参加航海或加入各种实战社群时，大群每天都有几百上千条消息在刷屏。绝大多数人面对海量信息要么选择“消息免打扰”彻底不看，要么被动刷屏浪费时间。

但在一线实操中，同行遇到的问题和拿到的反馈，往往能提醒我检查自己忽略的环节。但群聊消息仍要核实，不能因为传得快就当成事实。

我的做法是先手工留下三类线索，技术工具只是帮忙归档：

+   1. 避坑案例：记下当事人遇到的问题、后台提示、做过什么和后续结果；仅有一句“被限流了”还不足以归因。
+   2. 选题样本：保存标题、画面、统计时点与公开数据，再看内容有哪些值得学习的细节。
+   3. 规则与建议：平台公告保存原链接；教练经验与群友猜测单独标注，不能把转述写成官方规则。

只整理自己的素材群或有权使用的内容。涉及他人聊天、账号和截图，先取得许可并去掉隐私信息。脚本和关键词分类示例放在第五章技术部分，普通读者手动建三列笔记就能开始。
