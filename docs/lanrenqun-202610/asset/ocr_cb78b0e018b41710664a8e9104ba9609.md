# 五、公司与友商

# 1. 公司和最大竞争对手的差距

前面讲的是公司的优势，现在讲讲公司存在的客观问题。做工业自动化这一块，埃斯顿在国内有一个竞争对手，就是汇川技术。但与其说是竞对不如说汇川技术是埃斯顿的追赶目标。

营收的复合增长率只有 14.26%，还不到汇川的一半，股东净利润更刚刚转正，在公司历史上只比 2014 和 2024 年高。并且埃斯顿的归母净利润占汇川技术归母净利润的比例，也匹配不上两者在营收上的比值，埃斯顿的占比越来越低。出现这样的情况，要从三个方面讨论。
