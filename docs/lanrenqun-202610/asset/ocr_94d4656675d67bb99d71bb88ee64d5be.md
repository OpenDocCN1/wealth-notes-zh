# 有哪些话想了很久，却没有人替他说出来？

这篇文章想要带给大家的，不是“AI 怎么写青年文”，也不只是“老年赛道还能不能做”。我更想讲清楚：一个 03 年的年轻创作者，怎么从模仿、煽情和试错里，一点点学会理解一群比自己大三四十岁的读者，再把验证过的经验交给 Codex 稳定执行。

回头看，我的成长路线其实很清楚：先模仿有流量的形式 → 开始看评论、看用户和生活场景 → 从煽情内容转向具体问题 → 用阅读、留言和赞赏验证判断 → 最后才把这套经验放进 Codex，做成可以反复执行的内容流程。

# 第一段成长：先承认自己其实不懂

我从 2022 年开始做公众号。一开始我什么都写，爆过一些文章，也做过一堆写着写着就停掉的方向。做久了才会承认：偶尔爆一篇，和真正跑通一个赛道，完全是两件事。

前者可能是蹭到了热点，标题刚好戳中人，甚至就是运气好。后者则需要你对同一类人的问题有足够长时间的观察，知道什么能写、什么不能碰，还得让内容持续产生阅读、互动或收入。
