# ### 11.稀缺定义价值：价值不取决于有用，而取决于“稀缺且有用”。

空气对人极其有用，可它不值钱，因为它不稀缺。钻石用处不大，却很贵，因为它稀缺。

这条规则用在自己身上，就是一句很扎心的话。你能不能涨工资、有没有议价权，不取决于你有多努力、多重要，而取决于你有多难以被替代。

如果你做的事，换一个人、甚至 AI 也能轻松做到，那无论你多拼命，你的价值都会被压得很低。

所以，与其在可替代的赛道上卷强度，不如想办法让自己变得稀缺。

# ### 12.信任是最高效的货币：它能降低一切协作的摩擦成本。

两个互相信任的人合作，一句话就能定下来的事，对于两个互相提防的人来说，签一百页合同都未必放心。

信任，本质上是在替你省掉无数核对、监督、防备的成本。但它有个致命的特性：建立得极慢，崩塌得极快，且一旦破裂，几乎无法复原。

你要用很多次靠谱，才能攒起一点信任，但也只需要一次失信，就能把它清零。把值得信任当成长期资产去经营，是这个世界上回报率最高、也最容易被低估的投资之一。
