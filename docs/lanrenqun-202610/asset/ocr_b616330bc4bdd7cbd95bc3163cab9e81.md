# 第一步，工作台帮我把材料整理成可以判断的问题。

工作台把分散的服务资料、项目记录和客户提问整理到一起，列出已有依据的业务事实，以及客户还没弄明白的问题。

比如有人问“多少钱、怎么服务”，它可以找到相关的价格范围、服务说明和原始出处。具体到这位客户的来源、渠道，比如是刚认识我们，还是已经了解服务、正在做最后决定，仍需要我们结合沟通情况判断。

有了这一步之后，我们在进行下一步选题输出或准备回复时，哪怕我不在场，团队伙伴也知道该回答什么、依据在哪里，也知道哪些信息还要找负责人确认，避免把不确定的内容说成对外承诺。
