# 2

发展到现在，整个佤邦已经形成了几大独立的山头。

第一个山头，太子党。

鲍有祥的前妻给鲍有祥一口气生了 8 个女儿，可在鲍有祥看来，女儿怎么继承家业？非要儿子不可！

所以鲍有祥只能再娶，最后喜迎两个儿子，鲍艾康（也叫鲍岩康）和鲍尼搞。

毫无疑问，鲍艾康作为嫡长子，肯定要继承大位的。

在佤邦最新的人事任命中，鲍艾康被火箭提拔为佤邦联合党中央政治局常委、政府副主席兼军委副总司令。

这一连串的头衔，意味着他在党、政、军三条线上全拿到了接班的合法性。

鲍有祥甚至让鲍艾康直接掌管了中央警卫部队和邦康的城防重炮营，相当于把禁军都交给他了。

但问题在于，鲍艾康是 1991 年生，现在才 30 多岁，履历太单薄了。

他没参加过缅共斗争，也没跟坤沙血拼过，大部分时间都生活在稳定的中国，虽然受到了良好的教育，行事风格相对沉稳克制，但总是缺少一种能镇得住人的霸气。
