# 逻辑永远第一优先是靠谱，第二才是能力。

首先是做人可靠、绝对服从。这类岗位必须做到立场一致、心思纯粹，坚决服从领导安排，能够精准领会领导意图，不折不扣落实各项部署，成为领导意志的延伸，帮领导稳固管理格局、把控内部节奏。绝对不会选用有自己想法、个性太强、不听调度、站队模糊的干部，避免关键岗位出现不可控风险。

其次是能够够用、用着顺手。不需要做到全系统顶尖专家级别，但必须具备独当一面的业务能力、协调能力、应急处置能力，能够扛得起担子、守得住底线、办得好事情，不用领导事事操心、时时兜底，日常工作能平稳落地，突发情况能妥善处置。

最后是通透懂事、规避风险。关键岗位的人选，必须是情商在线、心思缜密的聪明人，懂得职场规矩、懂得分寸边界、懂得避嫌守底线，能帮领导处理各类繁杂琐事、协调各方人际关系，还能主动规避工作中的纪律风险、舆情风险、人际风险，帮领导省去后顾之忧。

这类岗位，基本不会单纯提拔埋头苦干的老实人，往往都是留给领导信得过、靠得住、懂规矩、能贴心的自己人，这是所有单位职场领导用人的第一铁律。
