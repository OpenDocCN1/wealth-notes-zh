# 常见问题

# 1 启动后一直“等待直播”

可能原因：

+   - 源直播间没有开播。
+   - 直播间开播了，但 VPS 直连被验证码或风控阻断。
+   - 抖音 Cookie 失效。
+   - 旧脚本没有同步到 VPS。
+   - 源链接填错或不是直播间链接。

处理方式：

+   1. 打开源直播间，确认真的在直播。
+   1. 打开任务日志，看是否提示“未找到可用的流”。
+   1. 点击“修复”，同步脚本并检查 VPS 环境。
+   1. 若仍失败，更新 VPS 的抖音 Cookie。
+   1. 需要时填写备用源 URL 或切换到断播切换文件模式。
