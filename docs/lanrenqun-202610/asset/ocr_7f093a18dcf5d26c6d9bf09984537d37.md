鼓励我编造亲历。它是一条表达边界：这个人担心什么，哪些经历能支撑他的判断，什么话说出来会像年轻人硬模仿老人。只有这层约束在，后面的提示词才不会频繁更换。

# Codex 的第一个角色：资料整理员，把一堆对标变成可用素材

我不会把一篇对标文章丢给 Codex，然后说“帮我模仿一篇”。这样最容易得到一篇结构很像、但没有自己判断的文章。

我会给它的原料包括：对标标题与正文、评论区真实表达、文章大概数据、我看完后的判断，以及能够支撑这篇内容的生活场景。然后让它分开整理：这篇写给谁，读者为什么点击，核心冲突是什么，什么只能参考、不能照搬，还缺哪些信息。

比如我想写“60 岁后子女再来借钱”，我会先放进 3—5 篇相关内容和一批评论。此时 Codex 不负责写正文，它先帮我把评论里反复出现的顾虑分出来：有人怕拒绝后伤亲情，有人怕自己将来着病缺钱，还有人根本不知道应该留多少。问题分开后，文章才知道应该详细写哪一个。
