# 第二，把父母、亲戚和后台读者当作样本，不把他们当作一个抽象人群。

我会看他们反复聊的是钱、身体、子女，还是夫妻关系；他们真正难受的地方，是问题本身，还是那种“我不知道该怎么开口”的别扭。只有这些细小的差别，才能看出文章是像一个人在说话，还是像年轻人站在外面教老人过日子。切记不要写成说教的语气。

# 第三段成长：一轮轮测试，用数据结果来下定论

# 第三，小批量测试，不靠一篇爆文给自己下结论。

我先测夫妻陪伴、晚年生活、人生感悟几个方向。同一个需求会换标题、换场景再试，至少连续测三次，再和账号近期文章的中位数比。这样才能分清，到底是需求不成立，还是标题和表达没有写对。

我还有一个很实用的检查：把文章里“退休、养老、晚年”这些词全删掉，剩下的人物、顾虑和动作，还像不像一个五六十岁的人？如果删完只剩“珍惜当下、活出自己、善待自己”，那这篇文章看似温柔，其实根本没有写到他们的生活里。
