也就是说，并非所有的努力都等价。有些事做了一百件，不如一件做对了顶用。高手和普通人的区别，常常不在于更勤奋，而在于能否在动手之前，先识别出那个关键的少数，然后把所有力气和时间都 all in 在上面。

# 第二层·博弈层：人与人如何争夺？

# 7.没有免费的午餐：你得到的每一樣东西，背后都标着一个隐形的价签。

你免费用的 App，代价是你的时间和数据。商家“亏本”送你的赠品，成本早就算进了别的地方。

那个看起来很轻松就能拿到高薪水的工作，背后多半是你暂时没看到的风险或代价。经济学把它叫做机会成本，你选择做一件事，真正付出的，不只是花掉的钱和时间，还有你因此放弃掉的、那个本可以拥有的最好选择。

当某样东西好得不像话的时候，正确的反应不是窃喜，而是去找代价到底藏在哪儿。记住，反常的高收益，风险一定躲在你看不见的角落里。

# 8.激励决定行为：想预测一个人怎么做，先看他靠什么得到奖励。

不要听一个人怎么说，要看是什么在奖励他。一个销售拼命推荐某款产品，可能不是因为它最好，而是因为它提成最高。

一家平台不断给你推送让你愤怒的内容，不是因为它想让你生气，而是因为愤怒最能留住你的停留时长。正如那句老话：永远不要问理发师，你是否需要理发。
