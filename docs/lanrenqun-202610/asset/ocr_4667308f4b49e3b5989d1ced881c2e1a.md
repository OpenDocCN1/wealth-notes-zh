你兜底固定成本，自由职业是自己承担所有盈亏。所以我一直坚持不签长期固定合约、不背固定人力成本、不承担闲置损耗。让成本跟着需求流动，绝不被固定负债锁住现金流。

# 别忘了一件最容易忽视的成本：五险一金

自由职业有个特别容易踩的坑——五险一金被默认放弃了。刚辞职那阵我完全没感觉，反正年轻、身体好、也不买房。可后来一想到自己的医疗、还有房贷，心里就开始发虚了。自由职业看起来自由，其实是把公司原本替你承担的那部分风险，全部转移到了你自己身上。所以我开始一个个补：

+   - 医保：先交上了，这是最基础的兜底。
+   - 百万医疗险：作为医保之外的补充，防止一场病把几年积蓄清零。
+   - 公积金：这是我最意外的一块——我原以为自由职业者没戏，后来去查，发现灵活就业人员也可以自己交公积金，并且还能用它申请公积金贷款。我最后真的办下来了。

各地政策不一样，大家务必去查一下自己当地的具体规定，有的城市支持灵活就业缴存，有的还有缴存比例和贷款的细则要求。这件事值得花半天去搞清楚，因为它是几十年的复利问题。

自由职业不是"不要保障"，是"自己给自己发保障"。没人替你交，你就得自己惦记着这件事。
