# 极简主义风，学霸笔记风，3D 效果等等

将标准化的流程封装在提示词中，让用户点击即用，直接就能看到效果

哪怕是自定义提示词，也可以直接用现成的流程

看到任何图片，直接用豆包把喜欢的图片发上去，让它总结生图提示词，然后再将提示词放置到提示词管理里，让它批量为我们生成这类图片

整个资料生成流程，就是复制粘贴知识文字、选择提示词和图片尺寸、点击生成预览，就可以把资料变成统一的手绘风

功能上面要聚焦，就是为了让任何知识变成手绘图

流程上面要简单：文字复制粘贴、选择、点击生成

无论多少个用户使用这个软件都不需要去思考，不需要去配置环境，不需要想怎么去写提示词，也不需要再根据生成结果反推纠正

这些不必要的流程，每增加一步，都会让用户觉得这个软件不太适合自己

所以简单才是工作台的目的，功能简单，使用简单
