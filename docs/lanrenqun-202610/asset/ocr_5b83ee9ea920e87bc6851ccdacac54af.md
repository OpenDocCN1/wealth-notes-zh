# 七、电话一直谈不下来以后，我开始把事情往投诉、书面催告和总部推进

到了8月，继续靠物业、保险之间反复打电话、发微信，已经很难再往前走（因单靠业主的投诉是无法形成有效施压，也没有任何法律上的强制性）。前面几个月积累下来的时间线、报价、Excel、照片和争议点已经整理出来，我开始把这些材料直接送进投诉和书面催告渠道。

8月1日，我第一次拨打12378，电话被转到了人保内部投诉通道，这一次没有形成监管工单。8月7日，我再次拨打12378，正式登记了针对人保财险广东省分公司的投诉。当天，保险理赔人员开始直接跟我通电话，重新谈折旧、赔偿范围这些问题。

就在当天的后续电话里，保险员来电回复“原来报损清单只有17,000多元的金额，开始出现了“3万多、约五折”这一档新的口头金额。”尽管已经有不少进展我还是没有接受。多个月来的持久战有了第一个松口，让我更加坚定这次维权的胜利一定会属于我！

8月13日，我又通过广州12345投诉物业。到了8月28日，我收到洛浦街的书面回复。里面有一句：

> “经我办初步核实，基本属实。”
