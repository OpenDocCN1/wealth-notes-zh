|  | 标准 | 果，再写标准 |
| --- | --- | --- |
| 复查到一半，被查的代码又被改了 | 一直查的是同一个版本 | 复查前先锁定版本，新改动重新查 |
| 清理脚本被执行两次，约 40 份备份被覆盖 | 用户只会执行一次 | 脚本重复执行也不出事，备份永不覆盖 |
| 请教外部专家时，凭记忆把语音服务商写错 | 我记得用的是哪家 | 从当前代码和配置里查，查的时候不打印密钥 |

这 16 条可以归成四句话：

+   184. **能用成熟方案，就别自己写**（第 7 章步骤 5）。
+   185. **「我这边好了」不等于「用户那边好了」。** 合并、发布、安装、使用，每一层单独确认。
+   186. **检查工具本身也会错。** 先用已知结果校准它，再相信它。
+   187. **一切操作都要能重复做。** 小白复制粘贴执行两遍是常事，脚本要扛得住。
