# 敢跑步的理由，成立么？

真的是因为昨天摔跤了导致今天不跑步么？
不，不是的。

是我今天根本不想跑，我自己主动在过去的时间碎片垃圾堆里面，翻出来一件事，当成了理由。

are you ok?

下面这番话，我跟读者们讲过很多次的，就是前文那个某省第三名的同学。

当年我和他一样，都因为打游戏，挂了太多科，毕不了业。

到大四，他选择退学，我试图阻止。

我跟他讲，咱们可以去考研，那年代考研可简单了，分比如今低得多。

政治，数学，英语，咱们这种人，用高三的底子，不复习分也够了。

至于专业课，一共就只考两本书，你是重修十几门容易呢？还是复习两本书容易呢？

等拿到录取通知书，再跟教授们求情，求重修的时候开根号乘以十，把自己当个P给放了，反正跑得了和尚跑不了庙，不还得读研么。

这就是我出的主意，我打算拉他一起干。

他拒绝了，理由居然是他高三能考全省第三，是因为初中成绩好，初中成绩好，是因为小学成绩好。
