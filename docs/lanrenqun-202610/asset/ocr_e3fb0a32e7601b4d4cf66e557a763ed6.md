另一种操作呢，他在用 AI 扩大自己的机会地图。这个建议，他也推给邵艾伦代表的年轻人了。

聊到这个话题的时候，孙宇晨讲了个金句。他说，商机是全球性的，千万不要局限于我在家门口开个小卖部，挣楼底下老奶奶的钱，而是要把尼日利亚人、土耳其人、阿根廷人都看成潜在客户，去往全球赚钱，反正今天有 AI 嘛，视野和语言都不成问题。

他举了个例子，叫 Token 中转。现在全世界最顶级的那几个 AI 大模型，比如 OpenAI，在不同国家的 API 订阅费用有高有低。阿根廷、土耳其、尼日利亚的包月价格就远远低于美国。那在低价地区买 API 资源，供应给高价地区的用户，差价就稳定赚到了。

你看，跟十年前那个 30 岁前不买房不买车不结婚、保持个人流动性的逻辑，又连上了，要到处去，往有钱、有机会的地方去。

但这说得容易，普通年轻人，哪能拥有这种现成的世界级信息差和视野呢？

孙宇晨又举例子了：虽然他不推荐年轻人买，但实在要买房的话，在买之前先看 100 套房，一手房、二手房、各种地段都看，听不同的人介绍、开价，就能基本形成对房地产的认知框架。类似的，年轻人择业，也可以让 AI 帮忙，推演 100 个专业未来 10 年的就业前景。
