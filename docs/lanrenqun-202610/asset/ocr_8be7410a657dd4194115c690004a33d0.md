# ### 3、定时发布：我亲眼见过无数人栽在这上面

**先说结论：新号、起号期绝对不要用定时发布。**大多数人有个误解，觉得定时发布就是"到点了系统自动发出去"，和即时发布没区别。实际机制完全不同。

对你来说，定时发布是到时间才上线。但对平台系统来说，你设置好定时的那一刻，内容就已经进入系统后台了。定时发布的内容会提前推给内容品鉴官和一小部分灰度测试用户，做冷启动的质量标注和测试——等于比即时发布多了一轮前置的质量审核。

结果就是：审核标准更严格，前置测试数据直接影响正式发布后的推荐量。内容质量一般的话，前置测试数据不好，正式发布后基本就不给流量了。新号本身内容竞争力就不强，再经过一轮前置筛选，基本死在冷启动。

**还有一个很多人不注意的点：**在哪里设置定时发布，就算在哪里发布。比如在电脑上设置定时发布，就算电脑发布，不享受手机发布的权重加成。起号阶段优先用手机端发布，电脑发布更容易卡流量，这是大量实测的结论。标准操作：电脑端排版做素材存草稿，用手机端公众号助手连手机流量发布。
