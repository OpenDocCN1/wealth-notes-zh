| 主要动作 | 新增事项、查看事项、标记完成 |
| 输入 | 标题、日期、可选备注 |
| 输出 | 待办列表和完成状态 |
| 数据放哪里 | 当前手机本地 |
| 第一次打开 | 显示空态与新增入口 |
| 输入不正确 | 提示原因，保留已填内容 |
| 暂时不做 | 登录、云同步、AI、支付、录音、蓝牙、推送 |

“空态”就是还没有任何数据时页面显示什么，比如一句“还没有事项，点这里新增一条”。
