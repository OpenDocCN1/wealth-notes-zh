收到的所谓"反馈"，其实差别巨大，大致可以分成四级。

第 0 级：情绪反馈。厉害、牛 X、喜欢、点赞、鼓掌。这种反馈的信息量是零，它只告诉你对方不讨厌你，并不告诉你任何关于作品本身的事。

第 1 级：模糊评价。"整体不错，就是感觉有点散""挺好的，可能还能再打磨一下"。这种评价的信息量很低，它会告诉你有问题，但没告诉你问题在哪。它唯一的用处，是提示你去追问。

第 2 级：定位反馈。"你第三段的逻辑跳了一步""这个方案的成本假设有问题，你按理想产能算了"。这些才是真正有价值的反馈，它指向一个具体的、可以修改的位置。

还有更高的第 3 级：真实世界的裁决。有人愿意为它付费，付了费的人第二次还来；这一级也包括真正被解决掉的问题、可复现的结果。这一级的反馈来得最慢，但它完全不会说谎，也不会给你面子。

现在你可以回头数一数，过去一年里你收到的反馈，绝大部分落在哪一级？绝大多数人的停滞，就是因为他们长期生活在 0 级和 1 级里，却以为自己在接受反馈。
