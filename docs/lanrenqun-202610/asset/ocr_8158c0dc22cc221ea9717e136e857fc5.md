# 二、四个项目让我们重新理解获客

考研自习室让我们看到免费和付费可以一起做

考研自习室这个项目，大约一个星期就测到了比较合适的素材和获客成本。之后持续投放，四个月左右，床位基本招满。

当时汇总的项目结果是 3000 多条精准线索、1600 多人加微信、200 多人成交，四个月总营收超过 260 万元。

![](bbox=[0.063, 0.333, 0.936, 0.521])

这里有个口径必须讲清楚：这组数字是整个项目的结果。免费流和付费流在当时都贡献了相当一部分业绩，不能把全部营收除以广告费，就说成付费广告单独创造的回报。

这个案例对我们最大的影响，是看到了经营上的主动性。有效素材测出来以后，可以继续投入预算获取客户，销售和场地安排也就有了更明确的依据。

从 2025 年开始，我们做新项目时，会更认真地评估企业号投放。免费流有机会就用，但涉及持续获客的业务，我们希望至少有一条能够测试、能够调节的付费路径。
