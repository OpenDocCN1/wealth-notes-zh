# 步骤6：提前想好「盖章还是签字」。

个体户可以不刻章。但电子版权证书、部分商店的资质页，会要一页「签章」。我不刻章、交手写签名，被电子版权平台退回要求盖章，白等了一轮。要办电子版权证书的，建议开工前就把章刻好。签章页用 iPhone 备忘录的「扫描文稿」扫成 PDF，别用相机随手拍。
