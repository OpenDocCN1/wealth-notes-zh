# 再往前一步：

它最近是在加速，还是已经开始降温？我
本身会一点影刀，所以最早没有自己开发
系统，就是拿影刀做了一个很简陋的版本。

逻辑特别简单：每天自动打开一次，拿到
销量，记录下来，第二天再拿一次，两个
数字做减法。

单品和店铺都是每天一次。

虽然简陋，但已经能看个大概。

![](bbox=[0.063, 0.356, 0.936, 0.466])

至少以前我只能看到“总销量 3000”，现在
能知道“昨天 2980，今天 3000，24 小时大
概增加了 20”。

后来我想盯的东西越来越多，又觉得一天
一次对重点单品来说有点粗，再加上现在
Codex 写代码方便，我就想干脆按自己的
习惯重新做。

于是才有了现在这两个系统
