# 重新定义机会

展开之前，我想先和你一起，把“机会”这个词，重新定义一下。大多数人对机会的理解是有偏差的。很多人认为，机会就是“一件好事发生了”。比如升职了、加薪了、被领导看中了，谈成了一个大单子。

这些当然是好事，但严格意义上，它们并不是改变命运的机会，它们只是在原有轨道上的奖励。奖励可以让你跑得更稳，但不会换轨道。

那什么才叫改变命运的机会？我自己摸索出了一个判断标准，分享给你：如果五年之后回头看，当时如果换一个选择，或者抓住这个机会，今天的我会是一个完全不同的人。
