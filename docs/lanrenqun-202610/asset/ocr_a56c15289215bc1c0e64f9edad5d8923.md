# 域名注册

# 步骤5 决定要不要注册商标 我的建议很简单：

+   - 只是练手、做着试试 → 先只查重，不注册。
+   - 打算长期做、要做成品牌 → 尽早注册。商标周期很长，越早报越早受保护。

谁能申请，个体户和公司不一样：

| 你的身份 | 能不能申请商标 | 用什么材料 |
|---|---|---|
| 公司 | 能 | 营业执照 |
| 个体工商户 | 能 | 个体户营业执照 + 经营者身份证 |
| 没有执照的个人 | 不能 | 商标局答复：自然人要有个体户营业执照（或农村土地承包合同） |

在哪办、花多少：

+   - 入口：国家知识产权局「商标网上服务系统」，从中国商标网首页进入。也可以找代理，代理费另算。
+   - 官费（核对于 2026 年 10 月，以官方最新为准）：网上申请 270 元/类，含 10 个
