起因挺简单，我不太想继续听网易云里的歌了，就想着，能不能根据自己现在所处的环境，生成一首歌来听？

于是，我把 Claude 和 MiniMax 接到了一起。让 Claude 根据当下的场景写歌词，再用 MiniMax 唱出来，做成了一个自己可以用的小工具。

![](bbox=[0.073, 0.251, 0.935, 0.543])

做过这些尝试，我对做产品的理解也具体了一些。现在想来，可以有三个出发点。

+   1. 服务自己的业务，把业务里反复要做的事情整理出来，看看哪些可以交给产品完成，让自己做事更方便。
+   2. 解决别人的问题，了解别人有什么需求，再去做一个他们用得上的东西。
+   3. 满足自己的需要和兴趣，自己想用，也觉得好玩，就动手做出来。这几种出发点也会重合。比如 matlab.ai，我希望它既能帮自己的核心业务，也能让用户更方便地提出需求、拿到结果。
