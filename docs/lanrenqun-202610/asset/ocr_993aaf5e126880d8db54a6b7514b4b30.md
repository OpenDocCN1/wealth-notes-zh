# 有效观看时长

以下情况属于有效观看时长：

+   - 您设为“公开”的长视频获得的有效观看时长

在评定是否达到加入 YouTube 合作伙伴计划的最低要求时，我们不会考虑通过以下类型的视频获得的观看时长：

+   - 私享视频
+   - 不公开列出的视频
+   - 删除的视频
+   - 广告系列
+   - YouTube Shorts 短视频
+   - 不公开列出、已删除或未转换为视频点播的直播

而去年春节时，经过我们测试，发现直播的时长，确实是计入有效观看时长的，但并非所有情况都计入，总结出来的规则如下：

1.直播必须设为公开，有些账号直播时会默认设置直播为私享，需要手动修改。 2.直播不得超过 12 个小时，超过 12 小时则整场直播不计入开通 ypp 的时长统计。 3.直播间放版权音乐导致社区准则警告等违规情形的直播不计入时长。 了解了规则，那我相信大家能够自然而然地想到第二个问题。
