为什么我会说这是一次机会？因为人不是从成功里，而是从失败里长出骨头的。成功会让你以为自己什么都对。失败会逼你重新审视，哪些是我真正的能 力，哪些只是平台借给我的。

哪些朋友是真的，哪些只是利益相关者。哪些方法是真的有效，哪些只是运气好恰好赶上了。

这种审视，你一帆风顺的时候是做不出来的。因为人在顺境里，没有动力反思自己。心理学上有一个概念，叫创伤后成长。就是说，在经历重大挫折之后，相当比例的人不仅没有被打垮，反而会在五个维度上发生明显的成长：

+   - 对生命的欣赏感增强；
+   - 人际关系变得更深；
+   - 发现了自己未曾意识到的内在力量；
+   - 开拓了新的 人生可能性；
+   - 形成了更深的精神或哲学认知。

简单说，一场彻底的失败，常常是一个人真正成熟的开始。我把一次彻底的失败分成两种。

第一种是事业上的彻底失败。创业失败、投资失败、被裁员、被否定。

这种失败的好处，是它给你一次清零的机会。你被迫从头审视自己，重新理解什么叫做风险，什么叫做运气，什么叫做边界。我见过的所有真正厉害的人，几乎都有过一次甚至几次这样的失败。
