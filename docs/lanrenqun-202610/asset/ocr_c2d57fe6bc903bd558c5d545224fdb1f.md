# 第四块，发布和复盘。

发布我用的工具叫 Typefully，一个月 8 美元，接推特接口，可以定时排期。我每天只要在系统里输入几个字，当天的内容就自动排好、自动发出去。发完之后每周看一次数据，哪条好、哪条差、跟上周比怎么样，把结论喂回素材库，下一周的内容就更好一点。

采集、调度、发布、复盘，一圈转完，再喂回去。号就自己转起来了。

# c. 但有一条，我得说实话

自动化再好，它也只是个手段。

它帮你把内容铺出去、帮你按时出摊，但它写不出你的真诚。

真正让人点进来之后留下来、愿意信你、愿意跟着你走的，从来不是流量。是你这个人——你真实踩过的坑、真实拿到的结果、真实说出口的话。
