+   4. 每个重要情节至少承担一项功能：推进目标、揭示信息、改变关系、抬高代价、制造合理反转或回收伏笔。
+   5. 情节之间必须有因果联系；上一场事件应改变下一场事件发生的条件。

# 三、解决重复：比较“场景功能”，而不只是比较字面情节

短篇重复通常体现为：连续几场争吵、几次相似的误会、反复出现“反派挑衅——主角打脸——旁人震惊”。场景地点不同，不代表剧情有变化。

但也不能机械禁止重复。有意重复可以用于形成对照、递进或最后的反转，只要每次重复都带来新的信息、关系或结果。
