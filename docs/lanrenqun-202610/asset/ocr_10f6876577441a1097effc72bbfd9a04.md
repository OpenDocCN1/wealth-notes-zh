收到定金后，我们开始接手具体落地，我更多地沟通客户需求和交付要求，Link 教练负责开发功能。

不过，当时确认的是开发的大致范围，具体需求还要继续细化。收到定金之后，才开始遇到考验我们配合的问题。

# 交付：做哪些功能、做到什么程度，要一起确认

# 第一个坑：听到了功能名，还没问清实际怎么用

客户说想做视频、做内容、管理客户，我就跟着这些功能往下聊，没有问清楚她每天到底怎么做这些事。

比如视频，继续沟通后才知道，她用开拍做真人口播已经很快，不想换一个工具反而更麻烦。她还希望做一些不需要口播的视频，放一张照片、配上文案，就能出成片。

同样是“视频功能”，这里面至少有已有的口播方式、文案和非口播成片几个不同的问题。客户已经做得顺的部分，没必要为了放进工作台再折腾一遍。

如果重新聊一次，我会先请她拿一条最近发过的内容，讲讲选题怎么来、文案怎么写、在哪一步反复改，比只记下“需要视频功能”具体得多。

# 第二个坑：功能已经做了，才发现不用这么早做
