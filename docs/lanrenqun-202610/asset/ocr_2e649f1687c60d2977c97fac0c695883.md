# ## 写在最后

我知道很多人对推特是有顾虑的：翻墙麻烦、英文看不懂、觉得那是别人的场子。

但我想说，正因为大部分人嫌麻烦，所以这里的人均质量才高。**门槛本身就是筛选。**而且现在这个时间点，推特上的中文圈正处在一个很特别的阶段：真正有实战结果的人还不多，好内容还稀缺。你在生财学到的那些东西，搬过去，很容易被看见。

最后，跟大家说句掏心窝的话。

这篇文章写出来，不光是为了分享。**我其实也是在给自己起号。**这篇文章如果爆了，我这个号基本上就算起来了。所以这一波，真的需要圈友们帮我搭把手：

+   - 如果这篇里有哪一句对你有用，**帮忙转发一下**，或者点个赞；
+   - 如果你也在玩推特，**评论区留个号，我去关注你**；
