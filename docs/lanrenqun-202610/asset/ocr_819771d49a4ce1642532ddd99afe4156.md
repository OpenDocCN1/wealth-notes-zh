# 问题。

怡红院里的丫鬟小红，趁大丫鬟们不在，跑到宝玉房里贴身伺候，给他倒茶，想要赢得宝玉的关注。

这是能够理解的。

好比我是一个底层员工，升迁无望，莫说什么高管，组长都轮不到我。

今天董事会成员来了，我去摇首弄姿，万一被宝董看上了，收做小三，是不是脱离困境了？

我博这把牌，输的很少，赢的很大，那值得博一博，看看能否单车变摩托。

金钏儿是什么情况？

她本身就是开摩托的。

你去看她那个位置上的前辈，王夫人的陪房，周瑞家的，前任的大丫鬟。

周瑞家的，是有产业，甚至有权力的。

刘姥姥跟周瑞家的对话过，刘姥姥的亲家老爷，当年在任的时候，帮周瑞家的打过官司，夺取过他人的田产。

看到了么？

周瑞家的，实际上是有自己的生意，自己的产业的，她借助自己是王夫人陪房的身份，可以拉大旗，扯虎皮。

打着王夫人的旗号，在外面拉关系，为自己谋利，为自己置办产业，侵吞他人田地。
