# 1.

中国的影响力并非源于意识形态扩张，而是经济发展、在国际机构中日益增长的参与度，以及在科技领域日益强大的地位。中国没有试图重建当今国际体系，其目标是改变国际体系中对自身利益构成制约的要素，包括西方主导的制度架构、同盟关系、技术标准、经济规范以及部分底层价值观。

1950年，苏联从陆上入侵欧洲的前景十分现实，而如今的中国未对美国及其条约盟友构成全面军事征服的威胁，对建立庞大的全球军事存在、对其他国家施加“帝国式控制”几乎不感兴趣。

中国给美国施加的地缘政治压力主要是“限制海外行动的自由”，尤其是在中国周边地区，以前美海军可以在东海、南海，甚至台湾海峡和北部湾“自由自在地行动”，现在不可以了。

另外，还有一股更深层次的压力，那就是威胁到美国的“国家神话”。美国的对内凝聚力与对外霸权信仰始终建立在“世界第一”的概念之上，而中国崛起威胁到了整套神话的根基。
