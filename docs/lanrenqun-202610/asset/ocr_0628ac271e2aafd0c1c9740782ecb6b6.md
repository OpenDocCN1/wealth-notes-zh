+   - □ 前2小时：先确认发布与显示正常，记下初始读数，不急着下结论。

+   - □ 12～24小时：对比阅读、分享和留言变化，看内容是否继续有人阅读。

+   - □ 36～48小时：继续观察长尾。可能起量，也可能一直没有明显变化，不能把等待等同于必然推荐。

有的内容在更晚时点才继续获得阅读，但这也不代表每篇都有后续爆发。我的“种地心态”是给观察留时间，同时继续做下一篇。
