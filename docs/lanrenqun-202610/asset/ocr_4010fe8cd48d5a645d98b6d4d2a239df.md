从 4 月份到现在，我一直在跑这套流程。随着 GPT 的出图能力越来越强，我自用的 Skill 也越调越稳，整个做单过程已经基本 SOP 化了。

现在简单到什么程度？

我可以一边看着视频，一边把单子做了。流程顺起来的时候，真的会让我冒出一句：这就是传说中的点击即送吗但之前，这套东西我一直藏着掖着。

最近受“开源”精神的启发，我也想把自己真正做过、赚到过钱的东西拿出来。自媒体说到底是“他媒体”，得给看你的人带来点实际价值。

所以这次，我准备把这些全部摊开：

+   - **怎么做**：AI PPT 制作流程、自用且还在打磨的可编辑 Skill。

+   - **怎么沟通**：跟客户对接、确认需求和交付的话术模板。

+   - **怎么接单**：去哪找单、按什么标准交付、最后能拿到多少钱。

从工具到交付，一路讲到底。

+   - **想跑通第一笔收入**：AI 用了很多，一直想变现，却还没真正赚到钱。
