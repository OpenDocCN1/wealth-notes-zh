# 四、公司的核心竞争力

+   1. 全产业链之间，也有不同

公司有一句口号，叫“All Made By Estun”，翻译过来是“一切都由埃斯顿制造”，再翻译翻译，就是四个字，全产业链。

这几年，随着以比亚迪为代表的龙头制造业企业腾飞，市场上一大票公司都在强调自己具有“全产业链”属性。但同为全产业链，为什么比亚迪只有一个呢？

因为产业链长度不同。全产业链的好处，在于上游供应链自主可控、研产协同、成本稳定、壁垒较高等等。

但是这种优势是一点点累加出来的，需要通过产业链的长度发挥出来，产业链越长，全产业链的优势越大。如果某产业链有一百个环节，那对它做全产业链的深耕，就是每个环节的优势乘以一百，效果肯定比只有十个环节的产业链好。
