# 那么，诺贝尔文学奖为什么要选一个“难读”的作者？它选人的标准到底是什么？

注意，诺贝尔文学奖从来没有公布过任何官方的“打分标准”。我们接下来谈的，只是读者们基于诺奖的获奖脉络，得出的观察。

简单说，在很多人看来，诺贝尔文学奖，最在意的不只是通常意义上的“好看”，更是这个作者“对文学本身作了什么贡献”。打个比方。你去一家餐厅吃饭，觉得特别好吃，这是“审美经验”。但米其林评星的时候，它不只看好不好吃，还要看厨师有没有创造新的技法，有没有用前人没用过的食材组合，有没有对“烹饪技艺”本身产生影响。你在家做的红烧肉可能比某些米其林三星好吃，但它不会得星，因为它没有“推动烹饪的边界”。

所以当你“看不懂”的时候，不是你的问题。这个奖本来在某种程度上，就不是为普通读者的阅读体验设计的。

而且既然不是为普通读者设计，评选方式自然就不依托于普通读者。诺贝尔文学奖的评委，来自瑞典学院的文学和语言领域的学者。这批人加在一起，一共只有18个人，而且理论上是终身任职的。这18个人之下，设有一个5人的文学奖委员会，负责具体的筛选工作。
