建议选题材相近、篇幅相当、面向类似读者的作品或摘要。观察它们怎么实现某种效果，而不是照抄其人物与桥段；市场热点可参考，但不能用“追热点”替代逻辑。

# 提示词 6：短篇对标拆解

请拆解以下优秀短篇小说或章节摘要的结构性写法，重点分析：

+   1. 开篇如何快速建立人物处境、矛盾和阅读期待？
+   2. 核心冲突如何升级，哪些场景真正改变了局势？
+   3. 情绪节奏如何安排，哪里压抑、哪里释放、哪里反转？
+   4. 反派或对手的行为为什么成立？
+   5. 重要信息与伏笔在何处释放、何处回收？
+   6. 结局如何回应开篇的核心问题？

# 七、把修改经验沉淀成自己的细纲规则

不要每篇稿子都从头摸索。可以建一个简单的“细纲问题记录表”，记下：原问题—具体场景—修改规则—修改后效果。如果某种调整反复有效，就把它加入常用提示词；如果某条规则让剧情变僵硬，就删掉或改写。

尤其注意区分：有些问题是提示词不够明确，有些是大纲结构薄弱，有些则是正文执行没达到细纲预期。不能把所有问题都归结为“AI 没调教好”。
