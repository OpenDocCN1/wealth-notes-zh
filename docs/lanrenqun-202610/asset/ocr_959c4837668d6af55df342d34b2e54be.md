# 4. 破圈的前提：你得有一篇"值得转"的东西

这一步我要单独拎出来讲。

很多人找人转发，结果人家点进去一看，主页空空，或者内容干巴巴的，人家想帮也无从下手。

所以在开口求人之前，先问自己一句：我这条内容，讲清楚了什么？它能给看的人带来什么？说不清楚，就先别开口。说不清楚，就算是人家帮你转了，流量来了你也留不住。

# 六、起号成功之后，靠什么稳住

破圈只是那一下。真正让号活下来的，是后面天天出堆。

# a. 起号之后，连着两三天发干货

这两天非常关键。

前面靠大 V 帮你转，来了一批陌生人。这批人为什么留下来？取决于他点进你主页之后看到什么。

所以这两天你要连着发干货，把自己的价值立住。别发广告，别发无关的东西。
