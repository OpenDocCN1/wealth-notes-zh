# 二、解决故事线单一：让短篇的每个阶段都有不同任务

短篇的篇幅有限，不适合为了“丰富”而无节制增加人物和支线。更稳妥的方法，是围绕一个核心矛盾设计数次性质不同的推进：让主角对局势的认识、可采取的行动和必须付出的代价不断改变。

例如同样是复仇题材，不能从头到尾只是“发现仇人—打脸仇人—寻找下一个仇人”。可以依次安排：发现疑点、调查取证、利益交换、错误判断、立场反转、最终选择。这些环节必须相互推动，不能机械凑齐。
