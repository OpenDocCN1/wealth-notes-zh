作，换了个城市。

从一个做媒体服务器的外企，进入了一家做芯片的国内公司，去负责 OS。

我进去的第一周，正好那个系统软件部门的经理，引入了一个可以自由编辑的 WIKI。

大家把周报，BUG，都写在上面，别人也能看到。

当时为了让大家尽快熟悉，经理就说，那咱们写日报吧，每天的工作内容都写上去。

有个和我一同进公司的，一个校招的应届硕士，当时他负责 bootloader。

他第一次写的日报是两句话，该做的都做了，不该做的都没做。

别人看到了，都笑，他在耍宝嘛。

而我写的也很有趣，我编辑了四个类型，重要且紧急，重要不紧急，紧急不重要，不重要也不紧急。

然后我每天做了什么，就分门别类往里面填。

其他码农看了就喷喷称奇，他们对管理学也没了解过，没想过还能这样四象限分类。

那个时间段，我做的事情基本上都是重要且紧急的。

因为公司此前的芯片上，没有跑过 linux 这么复杂的 OS，这是公司新开的线，也是最重要的战略方向。
