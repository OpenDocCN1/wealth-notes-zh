# ## 第五次机会：国运/大势的转折

这是第五次机会，也是最大、最不可抗、最不可控的一次。它叫国运。如果说时代红利是浪，那国运就是潮汐本身。浪每隔几年来一次，你只要愿意冲，就有可能赶上。但潮汐是几十年才有一次的大转向。它一来，整个海岸线都会变。

我们这一代人，有幸（或者说幸）正在亲眼见证一次潮汐的转向。在过去的几十年里，中国经历过几次明显的国运转折，每一次都重新洗牌了一次社会阶层：1978 年的改革开放，把一代人从统购统销的计划体系里，放进了一个有市场的世界。

一批人因此积累了第一桶金。2001 年加入 WTO。把中国接入了全球分工的大网络，沿海一批工厂、外贸公司因此崛起。2000 年代到 2010 年代的城镇化，几亿人从农村到城市，这次大迁移本身，重新定义了什么叫做中国家庭。

2020 年代的人口拐点和产业升级，这是我们正在经历的这一次。每一次国运的转向，都不只是经济形势变了这么简单。
