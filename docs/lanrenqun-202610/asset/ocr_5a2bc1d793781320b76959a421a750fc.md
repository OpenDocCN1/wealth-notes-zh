# 目标与代价：新一轮经济转型的核心矛盾

最近，李录在哥伦比亚大学商学院的一场演讲中，提出了一个值得反复思考的观察：回顾中国过去几十年的经济发展，似乎存在一种以十年左右为周期的"目标与代价"交替现象。每一个发展阶段，都有其特定的时代目标，而为了实现这些目标，往往需要集中资源、调整政策并由不同的产业和群体承担相应的成本。随着经济进入下一个阶段，原有的发展目标不再是政策的优先方向，资源配置和利益分配也会随之改变。那些曾经受到重点扶持、享受时代红利的产业和群体，也会随着发展方向的转变，逐渐失去原有的优势。

这背后其实是一个很简单的道理：时代赋予的机遇往往具有阶段性，而建立在特定时代条件之上的成功，注定不能持续。对于身处其中的企业和个人而言，过去的成功不仅取决于自身的努力和能力，更离不开特定阶段的政策环境、资源倾斜与发展机遇。一旦这些外部条件发生变化，过去的优势就可能逐渐转化为新的约束。因此，理解经济周期，不仅要看哪些产业正在崛起，更要思考它们为什么受到支持，以及支撑其发展的时代条件能否持续。归根结底，上 一轮的受益者，可能就是下一轮的代价承担者。一切，都是周期。
