看似主观随意，实则有一套固定的心理逻辑和考量标准，看似是个人决策，实则是长线考察、全局平衡、个人风格三重因素叠加的结果。只要摸清领导的真实心理，就能提前对标、精准适配，不用盲目瞎努力。

# 一是干部提拔都是长线考察，绝非一时一事定胜负。

很多年轻干部有一个误区，就是觉得自己干成一件大事、做出一次亮点工作，就能被领导记住、快速提拔，或者觉得平时表现再好，只要没关键时刻出彩，就没有机会。事实上，对于没有特殊背景的普通干部来说，尤其是部门中层正职这类承上启下、独当一面的关键职务，领导从来不会草率定论，都会进行长达数年的暗中长线考察。

之所以要长线考察，核心是维护组织权威和队伍公信力。中层干部是单位的中坚力量，对上承接领导部署，对下管理基层员工，一旦选人失察，容易引发内部不满、工作混乱、口碑崩塌。领导必须确保提拔的人工作上立得住、心理上靠得住、群众中服得住，经得起时间考验、经得起众人打量。更何况提拔你，就意味着你是领导看中、领导认可的人，后续你出问题，人家就会骂领导无能，看领导提拔的都是什么鸟人。所以领导必须慎重，这个大家也要完全理解。那些看似突然被提拔的同事，并不是运气爆棚，而是早已在多年日常中通过了领导的层层考察，只是你没有察觉而已。
