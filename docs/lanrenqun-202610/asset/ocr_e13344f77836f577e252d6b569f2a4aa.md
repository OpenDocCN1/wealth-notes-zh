# 嘉宾供稿

当我们还在欢度国庆长假时，法国那边又烧起来了。

只不过这次上街闹事的，不是工人，不是农民，更不是黄马甲，而是一群十五六岁的高中生。他们干的事简直颠覆三观，把自己的学校给封了，有的还点了。

看到新闻我第一反应是这帮学生不想上学，找个借口闹事。但深入了解才晓得，其实还真不是。

事情从9月中旬开始，起先是巴黎郊区一所高中，开学一段时间了，数学老师没来，法语老师没来，校医岗位空着，厕所没纸，天花板滴水。为啥？
