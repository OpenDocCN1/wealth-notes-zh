# 步骤3：修好一个阶段，留一个存档

第一次用 Git：Mac 在终端输入 git --version，弹窗让你安装开发者工具就点「安装」；Windows 去 Git 官网下载安装包。装好后 git --version 能显示版本号再继续。

Git，是记录文件每次变化的工具。把它想成游戏存档点：每"提交"一次，就存一次档；"提交编号"就是这个存档的编号，以后凭它能找回这一刻的工程。（Git 官方中文教程）
