# 48 小时啊，对不对？

哦，对了，这位 UP 主同时还保持视频日更，日更啊，还是视频这种需要脚本、需要剪辑、需要保持流利的中文口条的工作，他应该能把一天时间变出 72 小时来才够用。

再看牢 A 在视频中举的那些案例，什么美国顶级 IT 企业的前精英白领，一朝被公司解雇之后住下水道，发洪水被冲走淹死饿命……这种新闻如果真的发生过，而美国当地媒体居然没有报道（至少现如今在网上怎么差也查证不到），那我只能说美国媒体都是吃白饭的，或者真的全体被深层政府搞定了。

而在自由市场竞争的环境下，牢 A 真有挖如此猛料和制作新闻成品的才能，他靠在美国给媒体爆料怕也早发了吧？再不济也能在油管上当个英文顶级网红，挣钱挣到手软，还用去兼职当收尸人，还用回简中圈在 B 站上日更视频，来赚这个流量？

所以综上，只要你但凡有点基本常识和逻辑思维力，就会发现这个故事，在时间管理、法律身份、动机逻辑和证据链条都无法自洽，且漏洞百出到了骇人听闻的程度。

时间上他分身乏术，法律上他法外狂徒，证据上他空口无凭。你来告诉我这怎么可能？但为什么那么多人愿意信？但为什么居然有那么多人愿意信这个几乎一眼假的段子呢？
