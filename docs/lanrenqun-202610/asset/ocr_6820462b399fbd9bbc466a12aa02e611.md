第一条，自己开局。找一个你刚验证过的结果，第一句写结果，配一张真图，结尾给路径。

第二条，蹭一个局。找一条阅读已经起来、和你有关的帖。回复里写身份，加一条原帖没有的信息。

第三条，把一条主帖养着。发出后两小时内回评论，把新问题补成新内容。

别先做互关。互关解决不了「别人为什么要看你下一条」。

# 常见问题

+   1. **没有粉丝基础能不能开局** 我认为是能的。我礼品卡、飞书 CLI、流量标签那几条，靠的是第一句和证据，不是老粉。

+   2. **只发干货会不会没人看** 干货要有钩子。第一句负责停住，后面的步骤负责收藏。

+   3. **转帖算不算原创**
+   
+   转帖加了新判断，就是你的内容。只写感谢，就是路过。

+   4. **文章和短帖怎么配** 短帖拿时效，文章拿收藏。Jev 那篇就是我先自己走进去，再写成能跟着做的教程。

+   5. **这套方法会不会过时。** 入口会变，派对不会变。谁能持续办一场别人愿意进来的局，谁就还在涨。
