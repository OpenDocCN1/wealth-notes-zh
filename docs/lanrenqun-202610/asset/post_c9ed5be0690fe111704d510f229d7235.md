可就是这么本该同舟共济的一船人，几千年来，无休止的厮杀，内斗，破坏这艘船。

为的也不过是些小孩子过家家式的称王称霸。

宇航员们，身临其境的换了个视角看待地球和地球上曾经发生过的一切，正在发生的一切。

就觉得很魔幻。

简直像一粒沙子上的一群细菌，在打架，而从来不知道自己危之将至。

这就是一种自上而下的视角。

你自下而上，很多东西，也许只是你自己YY出来的。

而你自上往下看，你会发现，自己YY的东西，那个依赖的基石本身，也许都不存在。

就像你以为你在建立王朝霸业，实际上你只是在沙滩上堆沙子。

尼采当年，疯之前，讲过一番话。

他说，如果时间不是无限的，那它就必然有终点。

到了那个终点，人类一切的文明，多少代人的悲欢离合，艺术文明，都会化为乌有。

反之，如果时间是无限的，那自己永远都活在轮回的牢笼中，一切都是注定的，一切都是会重来的，无法结束。

他讲的什么意思呢。

就是说，你把一切都想象成四个人打麻将，假如麻将是无限的。

不停的重新摸牌重新来过，那必然会出现第 N 局，全程你摸到的每一张牌，另外三家摸到的每一张牌，你打出的每一张牌，另外三家打出的每一张牌，和第一局的过程，是一模一样的。

你把第一局看成是你活了，死了，你把第 N 局看成是你活了，死了。

这个过程完全一样，中间你自己的每一个决策都一样，周围人的每一个反应都一样。

1 到 N， N 到 2N， 2N 到 MN。

这个 N 就叫庞加莱时间，和尼采同一时期的法国数学家给出的重复周期。

那么对尼采来说，就非常痛苦。

圣经里的原话，已有的，后必再有，已行的，后必再行。

一切都是注定的，而我们每个人，就像小丑一样，一遍遍的根据注定的脚本，去出牌。

1 对应着 N，对应着 2N；2 对应着 N+1，2N+1，......，于是 i 对应着 N+i，对应着 2N+i。

那我活个什么劲？

于是尼采崩溃了。

就像三体里面杨冬讲，物理学不存在了，然后自杀了。

其实如果尼采能多活五年，活到爱因斯坦发表论文之后，他还会崩溃第二次的。

他第一次崩溃是因为察觉到，我们人类活在时间的牢笼里。

但实际上，爱因斯坦之后的科学界，还告诉你，我们活在空间的牢笼里。

你想把飞船加速到光速，你需要无穷大的能量，也就是你做不到。

可人类观察，宇宙在加速膨胀，也就是说，我们看到的星系，它们在加速远离我们而去。

我们无论如何都追不上，只能眼睁睁看着它们越走越远，直到周围变成一片黑漆漆的永恒的寂寞。

这个处境，非常像柏拉图理想国里，对带着镣铐的洞穴人的描述。

洞穴人看不到真实的世界，他们被锁在洞里，面壁。

他们能看到的，只有身后的火把，投射到墙壁上的影子。

而光速的限制，等于告诉我们，我们看到的，无非是宇宙各个星系的光，投射过来的影子。

我们想要摸，对不起，永远摸不到，它们加速远离我们而去。

宇宙就像个洞穴，我们就是那群被锁着的，面壁人。

我们活在一个被放逐的，牢笼中。

时间上如此，空间上亦如此。
