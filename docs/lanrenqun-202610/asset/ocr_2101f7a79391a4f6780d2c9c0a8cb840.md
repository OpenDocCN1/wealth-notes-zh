# 47. 用 g 组合键跳转页面

先按 g 松开，再按后面的字母：

+   - g + h 回首页， g + n 看通知；
+   - g + p 进个人资料， g + b 看书签；
+   - g + i 看列表， g + m 进聊天， g + s 进设置。

# 48. 用浏览器书签保存主页标签页

主页下的帖子、回复、媒体、长文、精选等标签页，各有独立网址。不用记后缀，点进常看的标签页（比如某个账号的「长文」栏）存成浏览器书签即可。

# 49. 清理分享链接，只删问号后的参数

复制出来的帖子链接，？后面常带 s=20、t=xxxxx 这类追踪参数。清理时只删？及后面的部分，不要删掉前面的用户名和 status/ 后面的数字 ID。删完先在浏览器打开一次，确认能回到原帖再发。
