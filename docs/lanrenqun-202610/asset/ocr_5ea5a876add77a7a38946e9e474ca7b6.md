# 第五个阶段：从“每篇重新想”，到把经验固定成流程

以前这些标准都散在我的脑子里。状态好时，我记得先找场景，也记得删掉套话；赶稿或同时处理很多事时，就可能一上来先写正文，写了几百字才发现方向根本没想清楚。

我用 Codex 解决的第一个问题，就是不让内容质量跟着我当天的状态一起波动。现在的顺序是：先定人，再补素材；先把文革想清楚，再出初稿；最后由我修改、核实并决定是否发布。

# 在五个 AI 角色之前，先把账号里那个“说话的人”固定下来

我在 Obsidian 里单独建了一份老年赛道人设文件。核心是一位 70 后准退休生活观察者：他从物流、工厂、供应链、基层管理或实体行业走来，父母正在变老，孩子逐渐独立，夫妻共同生活多年。他正在处理身体劳损、退休金安排、父母养老、子女成家和退休生活规划。

我会把年龄阶段、工作经历、家庭状态、经济状态、身体感受、核心需求、说话方式和内容底线这 8 项写清楚。比如他有退休金、存款或房产，但不是富豪；他会算账，却不会只谈省钱；他关心身体，但不用疾病恐吓读者；他说话慢、实在、克制，喜欢用具体账本和生活选择说明问题。
