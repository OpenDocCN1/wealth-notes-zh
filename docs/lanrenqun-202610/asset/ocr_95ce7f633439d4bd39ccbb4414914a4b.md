# 三、自建接单群：熟悉链路、说干就干

对了，大一的时候，我们还要上早自习、晚自习和早操。虽然辛苦，但我还是很感谢当时的自己凭着兴趣坚持了下来。

就这样，我花了三天时间，完成了人生中的第一笔大单。当时特别高兴，还打电话告诉了父母，给他们转了 200 元——那是我人生中赚到的第一笔“巨款”。

给父母转账的时候，我的手都是抖的。200 元对很多人来说不算什么，但对我来说，它意味着我不再完全依赖家里，也意味着这条路真的走得通。那天晚上，我激动到很晚才睡着。
