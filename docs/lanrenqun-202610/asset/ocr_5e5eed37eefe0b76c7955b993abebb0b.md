# 2.后提问

拿到几个问题后，另开一个窗口，去一个一个问 AI 这些问题，每一个问题，你看看他是如何思考的，如何拆解问题的，如何拆分搜索关键词的，抓取了哪些网页，这些网页的标题是什么。

# 3.再总结

第二步得到的结果，再拿去给 AI 分析，让 AI 告诉你，如何写文章，发到哪些地方去。

# 有流量的后续
