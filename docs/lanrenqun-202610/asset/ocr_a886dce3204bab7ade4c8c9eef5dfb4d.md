# ## 二、规则比预测靠谱

由于是极少数的公司贡献了指数最大的收益，那么对于指数来说，它并不怕选错公司，而是怕漏掉了那几个最牛的公司！这就有点像公司招聘新员工。

重要的不是混进了差员工，而是错过了好员工。真正创造大价值的员工只有 20%！

所以，好的公司应该是有一套好的筛选机制。不断的优胜劣汰。

也就是，尽可能让招进来的人员里面有好的员工。

再通过考核把好员工突出出来，委以重任，把差员工淘汰出局。

指数的规则就是基于这个原则。

只不过吧，每个人都会带着自己的主观判断，去评价刚进入指数的公司。

现在指数里面的那些权重股，当初不也是这样进入指数的吗？都是指数追涨追进来的。如果眼睛里容不下沙子，就必然会错过真正的好公司。
