# 福利姬有 AI 短剧的女主漂亮吗？

我的朋友毫不客气地预言，除了一些已经建立粉丝粘性的顶级福利姬之外，绝大部分福利姬，都会在一两年内彻底丢掉市场。

可是问题来了，这些失业福利姬，会不会乖乖回学校念书、回归正常生活呢？

答案可能是残酷的。

那些早习惯了躺着赚快钱的女孩，根本不可能回到一个月挣三四千块的生活。

当线上变现的渠道被 AI 挤死的时候，她们手里唯一剩下的、AI 暂时还无法替代的，可能就只剩一样东西了。

她们可怜吗？也许很可怜，也许不可怜。

所有命运馈赠的礼物，都已在暗中标好了价格。

享受了轻松赚钱的生活，就要承担相应的代价。

技术的车轮滚滚向前，它碾碎虚荣，也碾碎幻想。

——分割线——

绝大多数人只盯着眼前的工资，却不知道一次远在中东的冲突、一次降息的决议，就能在一夜之间洗牌普通人的财富。

看懂宏观，是为了在周期切换时，不被当作代价。
