# 第三个阶段：从写一封情书，变成解决一个具体问题

以前我可能会写“老伴，谢谢你陪了我这么多年”。现在我会再问一层：“老两口退休后天天待在一起，为什么反而更容易吵架？”前一句是对的，但它可以放在任何账号。后一个问题里面，有具体的生活阶段，有相处方式突然变化以后的冲突，也有机

“晚年要学会爱自己”也是一样。这句话没有错，可它对一个正在被子女借钱、又担心自己生病的人来说，太轻了。如果把它改成：子女提出大额用钱需求时，先把自己的医疗备用金和至少一年的生活费单独留下，再讨论能帮多少。这时候，“爱自己”才从口号变成一个真正能执行的选择。

我现在主要围绕几条线来写：退休金、存款、医保和旅行预算这类“退休账本”；慢旅行、兴趣、学习和日常秩序这类“退休生活”；睡眠、劳损、体检和就医准备；夫妻、子女、父母照护和隔代育儿的边界。
