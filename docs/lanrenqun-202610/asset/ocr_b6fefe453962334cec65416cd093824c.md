# 1、名称和头像，很多人第一步就踩雷

公众号名称官方规则是一年改 1 次。但实际操作中，还没进入推荐流量池的新号，一周内改两次名字头像，基本没影响。已经稳定入池的号，就别动了，改了会短暂影响账号标签。

**头像千万不要用美女照片，也不要用纯 AI 生成的头像。** 为什么？因为这类头像是营销号、引流号的典型特征，系统的图像识别模型会直接给你打上“营销号”标签，初始风控等级拉高，起号难度直接翻倍。

名称和简介也可能踩隐性违规，比如带敏感词、夸大宣传、引流暗示。拿不准的话就用稳妥中性的表述，别在这种地方冒险。
