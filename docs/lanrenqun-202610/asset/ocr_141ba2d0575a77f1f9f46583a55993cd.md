面对教练动轴两三万字的直播转写稿，我们直接调用本地配置的逐字稿精读笔记 Skill（progressive-transcript-notes）。该 Skill 严格遵循“渐进精读法”，按三层递进整理长文；耗时取决于篇幅、模型与人工核对：

+   • Layer 1（全局脉络骨架）：第一层用 500 字直接提炼该场直播的核心论点与推导脉络，快速锁定整场分享的底层逻辑；

+   • Layer 2（因果推理链与边界反例还原）：这是最值钱的一步！普通总结只会留下“要做 A”，而渐进精读 Skill 会极其严格地保留讲者“为什么做 A”的完整论证链条、真实学员正反案例，以及最重要的【适用边界与反例】。
