# 一个人适不适合干大事

# 其实观察的维度很多

整体来讲，至少有四个维度的角度需要去审视。

# 首先，他想不想要去干大事：

如果一个人本身就不想做大事儿，或者说没有这样的自驱力和愿望，那么即便很好的资源其实也不会怎么成大事。

> （不过从圆方的观察而言，真正要做大事的人，命运会主动或被动地让他走上这条道路）

# 其次，他有没有机会干大事

不是所有人都能赶上做大事的机会的，基本上每一波大的机遇周期大概是 30 年，而往往只有前十年有机会干大事。

在这个时候出生的年代往往就已经决定了很多问题，太早或者太晚都不行。

# 然后，他有没有资源干大事

做大事也需要大的资源，这种资源不一定是祖辈的阴德，也可以是同学师长的扶持，又或者很早到了关键的位置，而这些都是获得资源的必要条件。
