受牵连，而且你既无法控制别人的行为，也没法排查问题出在哪。

**结论：发文务必用自己的手机流量，不要连公司、商场、咖啡厅、共享 WiFi等任何公共网络。怎么判断 IP 被污染了？**前提是你的内容合规、操作正确。如果连续 7 天所有内容都是 0 曝光，且公网 IP 地址一直固定不变，90%的概率就是 IP 被污染了。验证方法很简单：换一个设备、换一个网络发一篇测试内容，如果有曝光了，就可以确认。可以用 ip138.com 或 iping.cc 查看自己的公网 IP。

# **IP 污染怎么解决？**

+   - 手机开关一下飞行模式，或者重新插拔电话卡，运营商大概率会重新分配一个新的公网 IP。

+   - 长期方案：买个独立随身 WiFi，每个号对应一个专属网络。淘宝上随身 WiFi 设备大概 29 块，月费 9.9 元左右，成本很低。

+   - 补充一下：河南、广州、江西部分地区，存在区域性的限流现象，这些地区的 IP 整体风控等级更高，起号难度相对大一些。

**IP 数量限制：**个人主体账号，一个公网 IP 下最多做 2 个同平台账号，超过容易被判矩阵。企业主体账号，不同企业主体的公众号，一个 IP 最多对应 1 个。
