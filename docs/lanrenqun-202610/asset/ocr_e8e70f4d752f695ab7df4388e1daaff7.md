# 1、天选号 vs 考核号

天选号（约20%）：新号注册就自带流量buff，起步就有曝光，很容易起量。本质是平台的新号奖励机制，随机分配给一部分新号。特点是起号快但不代表后期一定稳，很多天选号爆一波就掉池了。

考核号（约80%）：绝大多数账号都属于这一类，需要经历1到3个月的合规试用期。试用期内平稳更新不违规不踩线，平稳度过之后系统才会稳定给流量。前期慢起号难，但熬过去之后流量更稳定，生命周期更长。
