# ### 年度产品发布计划（2025）

| Atlas Core | Q2 | 公开预览 | 张伟 |
| Atlas Core | Q3 | 正式发布 | 李娜 |
| Nova Search | Q2 | 内部测试 | 王强 |
| Nova Search | Q3 | 公开预览 | 王强 |
| Nova Search | Q4 | 正式发布 | 赵敏 |
| Pulse Analytics | Q3 | 内部测试 | 陈杰 |
| Pulse Analytics | Q4 | 公开预览 | 陈杰 |

+   - 第三季度：Atlas Core 正式发布，Nova Search 公开预览，Pulse Analytics 启动。
+   - 第四季度：Nova Search 正式发布，Pulse Analytics 公开预览。
