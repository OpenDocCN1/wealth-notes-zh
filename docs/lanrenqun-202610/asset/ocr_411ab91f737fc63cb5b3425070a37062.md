# 这种窄，不是受众变少，而是你开始和一个具体场景说话。

再比如，你要找一个爆款话题，那么之前你需要去详细地拆解一条爆款视频，或者说你的行业对标视频的共性问题，从中找出来你适合的切入点和选题，是比较耗时耗力的。

但是现在我们接入了我们的 AI 自媒体热点分析工作台，我们可以按需进行检索目标平台，然后排序，一键从对标爆款视频当中找出共性问题啊，直接进入下一步进行选题创作的环节。

![](bbox=[0.06, 0.35, 0.93, 0.5])

更进一步，我的 AI 工作台是如何 10 倍提效我们进行 IP 内容创作的，我们会把 IP 内容拆成三种工作，然后再根据我们每条视频的目标去具体的选择。

有些内容负责让人认识你，可能讲趋势、展示新机会；有些负责建立信任，讲你为什么这样判断，遇到过什么错；还有些负责让明确有需求的人知道怎样继续沟通。

三种内容可以相互连接，但不要要求一条内容同时完成流量、信任、成交三个任务。

否则播放量高的时候你失望于没有成交，讲得很深的时候又失望于没有爆款。
