# ### 写在最后

一个人的一生中，到底有几次真正能改变命运的机会？我的答案是，五次。一次来自“人”，结婚和生孩子的决定；一次来自“事”，一次彻底的失败；一次来自“地理”，第一次离开舒适区的迁徙；一次来自“时代”，时代红利的窗口；一次来自“大势”，国运的转折。

这五次机会，有的来自外部，有的来自内部；有的看起来像好事，有的看起来像坏事；有的需要你主动出击，有的只需要你不躲开。它们的共同点是，一旦你做出了选择，人生就被切开了。

之前的你和之后的你，会变成两个不太一样的人。还记得文章开头我说的那句话吗？

这五次机会，每一次出现的时候，都不会带着机会两个字。读到这里，你应该已经明白这句话的分量了。它们都伪装成日常，一次普通的相亲、一次平凡的搬家、一次失败的痛苦经历、一个听起来不太靠谱的新趋势、一段好像有点不一样的时代。

真正的机会，从来不会大声宣布自己的到来。它就是某个普通的时刻里，你身边的某一道门，悄悄地打开了一条缝。你愿不愿意走过去看一眼，动一动，决定了你接下来十年的样子。最后，我想留下一句话，作为这篇文章的结束。
