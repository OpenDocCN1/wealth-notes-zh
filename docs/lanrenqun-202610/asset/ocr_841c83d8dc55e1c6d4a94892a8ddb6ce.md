# ## 第一，为什么有些奇葩领导长期存在？

我文章开头第一段说虽然总体来说大多数领导是有水平的，这句话完全是场面话，其实事实情况大家都清楚，但凡你在体制内超过三年，你就会发现绝大多数领导都并不胜任自己的工作，这不是负能量，而是管理学层面的必然，连美国也如此。

美国管理学者劳伦斯·彼得提出过一个著名的彼得原理：“在一个等级制度中，每个职工趋向于上升到他所不能胜任的地位”。这种现象在现实生活中无处不在，例如一名称职的教授被提升为大学校长后，却无法胜任；一个优秀的运动员被提升为主管体育的官员，而无所作为。

由此导出的彼得推论是：“每一个职位最终都将被一个不能胜任其工作的职工所占据。层级组织的工作任务多半是由尚未达到职务能力要求的员工完成的”。

所以，当你看到大量并不称职的领导占据了大多数领导岗位，许多组织人浮于事，效率低下，平庸者出人头地，事业发展缓慢，千万不要愤世嫉俗，一定要习惯就好，因为这是管理学揭示的人类社会基本规律，几千年都是这么过来的，要不怎么会有“草台班子”一说？这不是我们哪个渺小的个体能够解决的，千万要平心静气。
