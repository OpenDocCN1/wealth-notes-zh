# 更奇怪的是，媒体说她是投资了上亿资产，
可她连大学都没上过，哪有本事做投资？
做投资不需要脑子，不需要本钱吗？

就在遇害前7天，她刚刚参加了巴黎时装
周，而且坐的还是头排，到底是哪儿来的
钱在支撑？

再看看她混的圈子，她最好的闺蜜，就是
郭富城的老婆方媛。

方媛我们就很熟悉了，天王嫂培训班出来
的嘛，当年王思聪就说过：“Amy姐还是厉
害，身边两名大将，一位嫁给天王郭富城，
一位嫁给潘帅。”

物以类聚人以群分，和方媛混在一起，蔡
天凤的名媛身份，恐怕也很值得怀疑了。

也许，她需要这个“名媛”的光环，或者说，
有人需要她顶着这个“名媛”的光环，去掩
盖一个不能被外界窥探的真相。

# 第二个疑点，谭方骏。

谭方骏作为一个富二代，娶一个离异有孩
子的女人，本身就已经很奇怪了，更奇怪
的是，他对卢家的态度，好到了甚至超出
正常人类理解的范畴。

大家可能还记得，蔡天凤和谭方骏，并没
有登记结婚。

为什么不登记？

豪门不领证，通常只有一种解释：防着对
方分家产。
