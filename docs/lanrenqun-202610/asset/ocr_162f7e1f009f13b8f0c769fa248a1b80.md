# （3）市场驱动：先跟品，不断尝试

这是我9月份也跟着做了一下开学季 ppt 的心得，当我也想吃教育课件这个大蛋糕中是，我先跟着市场去做小实验当时看到大家开学季都挣了不少，我也跟着用一个账号试试看。选品的过程也很简单，就是看到什么品爆了我就是跟着做。直到某个品小有成交为止。

因为用个人售卖等于自然流的流量，如果某篇笔记有比较高的阅读，平台把这一内容分发给了一批用户，而且这个主题有一定内容反馈。可以作为一个深耕的方向去测试；当然，阅读高只能说明内容方向有反馈，不能直接等于商品方向成立。后续还要继续看商品点击、成交，或者至少连续几篇同类内容的反馈，再决定要不要往这个方向靠。

不熟悉的赛道，我不会一开始做复杂调研和重产品，而是先跟市场上已经验证过的需求做几个小测试，再从数据里收窄方向；

> 拿教育课件来说，我当时测试了不同年级开学季班会、心理开学第一课两个方向，其中初一心理开学第一课的销量和笔记阅读都表现不错，所以后续就不再平均铺品，而是围绕“初中心理课”继续横向拓展到初二，或者纵向细分到具体心理主题。
