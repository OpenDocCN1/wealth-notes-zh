# 中国显然不能这么做，那么是不是可以搞一个更加清晰、公开、透明的分级合作清单体系？

目前中国与他国建立的外交关系定位太含蓄了，就算熟悉中国政策语言的也不容易区分各种战略伙伴关系之间的优先级，也难以判断中国到底怎么想的。

我们应该更加具体化，比如把对外深度合作划分为几个层面：

注重外交承认、经贸和人员往来正常化的基础层；注重经贸、投资、技术协作的发展层；加强反恐、反海盗、救灾维和、联合演习、军售和军事安全培训的安全层；还有更深层次的诸如自贸区、货币互换、数字规则、AI治理、供应链协定等的制度层；以及最核心的战略层，代表的是长期合作规划和命运共同体。

把这些层次形成体系，当然也会带来弊端，比如一些国家能够清楚地了解纸面上哪个国家与中国的合作更深入，在无法对中国形成有效威胁的情况下，选择针对这些国家，逼中国下场。

但有弊必有利、利大于弊，中国已经很强大了，莽丛藏不住巨龙，就不可能再搞“韬光养晦”；中国未来必须加强全球布局，就不可能不公开中国与他国的合作深度与倾向，还是要正大光明、打明牌。

只不过，中国的这一新模式，不是与任何一个国家捆绑，而是与中国的海外利益捆绑，中国只对具体合作议题在制度框架内
