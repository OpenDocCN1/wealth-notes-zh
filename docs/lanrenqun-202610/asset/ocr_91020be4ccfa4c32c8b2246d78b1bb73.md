# ## 5、人性推人事。

人事就叫生态位，发散一下..

咱看个最简单的呀，和上面的图结合。儒家分成小人和君子，啥叫君子？

这是个生态位，不是单纯的道德高尚的人，高尚不也为了过好日子嘛..所以君子生态位就是既济卦，就是得人心、行地道，或者叫行水道。

大白话就是要牢牢站在小动物这一方，这才能立于不败之地！当然反过来你叫它伪装大法也行，因为水是运行的根本，所以这才是最有力的筹码，只要你傍住这块就不怕没发展，虽然发展要相对慢，但主打一个稳定踏实。

你要能装一辈子，你就是真君子，这玩意就怕半途而废，装一半拉倒就要出大问题..当然有不少装一半出事的，最后跑路鹰那去了，是不老多了？很多人为啥发展不起来？因为左右徘徊，没有准确的路线定位。

所以有个词叫——定性！说这孩子真有定性，就是说人家路线非常明确，就那么雷打不动的一直走，这样的人早早晚晚都能走得通。昨天还回答啥叫“毅力”呢？

毅力不是硬干，只要是人类，谁硬干也坚持不住的.毅力换个词叫坚毅，啥叫坚？你看里面不带个“土”字旁嘛，这就要和五行结合思考了。
