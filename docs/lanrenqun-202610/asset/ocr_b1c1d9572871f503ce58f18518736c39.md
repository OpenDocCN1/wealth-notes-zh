# A 客户 | 跨境公司：顾问式销售

第二天上午，飞鱼哥给跨境客户讲了一整套系统平台。平台能做的事情很多，但老板听完，更着急的是旺季前的 POD 产量问题，希望先做一个 POD 工作台。

![](bbox=[0.07, 0.24, 0.9, 0.41])

准备好的方案没有一下子打中客户最想解决的事，我们就要调整接下来做什么。飞鱼哥当即和团队确认能不能往这个方向做，中午借客户的会议室讨论，下楼吃饭还在聊，下午花了两个小时补出了工作台的简单界面演示。

这次我们没有因为上午的方案没打中客户，就把整个平台推倒重来。下午补出 POD 工作台的演示，焦波哥同时继续准备平台计划的演示，眼前的需求和后续建设都有了对应的方案。客户明显被说动了，但还需要时间考虑，目前暂时没有成交结果。

我从这里学到，客户提出一个更急的问题时，要先判断它会怎样影响我们原来的方案。哪些需要马上调整，哪些可以留到后面，团队得把这两件事想清楚。
