# • VPS SSH 连接异常。

处理方式：

+   1. 到媒体库查看 VPS 磁盘占用。\n1. 大文件改用 SFTP 上传到 /root/douyin2youtube/uploads/。\n1. 上传完成后点击“扫描导入 VPS 文件”。\n1. 创建任务时选择已有文件。

# 5 任务显示错误但实际还在推流

处理方式：

+   1. 点击“校准”，让系统重新检测 VPS 上的进程。\n1. 打开 YouTube 直播间确认是否有画面。\n1. 查看任务日志确认是否有脚本报错。\n1. 若校准后仍异常，点击“修复”。

排查时优先看任务日志，其次看 VPS 状态，再看是否需要同步脚本、更新 Cookie 或切换播放模式。
