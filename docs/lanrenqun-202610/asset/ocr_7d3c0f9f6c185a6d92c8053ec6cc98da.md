但我不太想让它们把大家带离眼前这一步。

一个新手今天连首图都没挑出来，你给他看再花哨的量产流程，他也不知道该从哪儿下手。

先把第一条做出来。等他回过头再看这些工具，他才清楚：每一个功能，替他省的到底是哪一段麻烦。

# 为什么拿贴图来走这一遍

我一开始选贴图，想法很现实。长文章一篇要磨很久，视频还要拍、剪、配音，贴图只需要一个具体的题、一到几张看得懂的图，再配一段人话，就能先发出去。

但真的做了以后，我才知道，“简单”跟“随便”是两回事。

一张猫突然愣住的照片、一种只有本地人才认得的食材、一位中年人重新戴上工牌的瞬间，看起来都很普通。可你得判断：这张图有没有让人停一下的东西？它能勾出一个具体问题？你手上的材料够不够把这个问题说清？

我在群里经常让新手先看四个字：题、图、话、真。

+   - 题要小。别一上来写“中年人如何重新开始”，太大，谁都能说两句；“中年失业、降薪、离职、被裁员”才有画面。
+   - 图要一眼能看懂。图片有没有反常？能不能一下子引发好奇和重点？
+   - 话要吃进这组素材。把图片换掉，正文
