# 剩余课时，一笔一笔查清楚。

从排课、消课到核对余额，跟着小朱走一遍。

+   - 01 买课，先记录来源
+     9月1日买入10课时，购买记录保存在财务记录里。
+   - 02 上课，从课表确认
+     安排课排，再确认消课，两次到课核对1课时。
+   - 03 请假，按约定处理
+     9月12日请假不扣课，对应的课时记录也撤销。

![](bbox=[0.3, 0.6, 0.52, 0.75])

独立老师，剩余课时的来龙去脉要能查
“老师，我家还剩几节课？”
如果你是自己排课、按课包收费的独立老师，这个问题，不只是查一下余额。
剩余课时能回答“还有多少”，但要解释这个数字，还得知道：什么时候买的课，啥时候扣了课，请假时怎么处理。
如果这些信息分散在备忘录、聊天记录和纸质本子里，核对一次，就得来回翻几处。遇到调课、请假、补课，记录之间更要能对应得上。
我想把这些日常记录整理清楚，让老师查看余额时，也能看到它的来龙去脉。
所以开发了课时清这个小程序，在课时清里，可以分别查看：
课程记录
哪天安排了课，实际出勤怎样，这节课如何处理。
课时流水
什么时候购买或增加了课时，啥次消课扣了多少，以及对对应的变动后余额。
