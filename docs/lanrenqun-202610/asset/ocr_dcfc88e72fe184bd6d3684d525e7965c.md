# 总经理杨雨松

一个刚从重庆农商行过来。一个刚从西南证券回来。两个人正好站到了渝富这座资本平台的最高管理层。三个月以后，8月，谢文辉被免去党委书记、董事长。

9月12日，被查。9月30日。吴坚被查。一个细节很有意思。吴坚退休的时间是2024年8月31日。谢文辉到渝富的时间是2024年9月。

前后几乎只差几天。两个人甚至没有形成长期的“渝富董事长—西南证券董事长”搭班关系。吴坚刚从西南证券离开，谢文辉才走进渝富。

但在他们之前、之间和之后，那些机构始终在那里。渝富。重庆银行。西南证券。人员不断换。资本关系却很稳定。早年的廖庆轩，从重庆银行走到国资委、渝富，再到西南证券。

吴坚，从重庆证监局走进渝富，再走到西南证券。杨雨松，从证券行业进入渝富，又到西南证券，最后再回渝富。谢文辉，从重庆农商行进入渝富。

冉海陵，在西南证券短暂停留之后，去了重庆银行，一做就是二十年。隋军，从农商行去汽车金融，再去重庆银行，最后又回到农商行。

高嵩，又从农商行去了重庆银行。如果只看每一次任命，它们都是独立的人事变动。如果把二十年放在一起，它更像一张不断循环的人事网络。
