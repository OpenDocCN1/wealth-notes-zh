# ### 1. 极客陷阱：技术自嗨与盲目全自动化的代价

作为技术动手派，进场的第一件事，我毫不犹豫地选择了“先搭系统”。

在我的设想里，既然贴图号流程这么简单，为什么不让 AI 全部接管？我一口气搭建了一套多 Agent 协作体系：

+   - 总调度 Agent：统筹每天的生产节拍与各赛道发文计划；
+   - 垂直赛道 Agent：设立了三大赛道生产线（老物件怀旧、婚姻家庭、生活奇闻）；
+   - 公共专项 Agent：设立对标采集 Agent、每日复盘 Agent，以及合规审核 Agent；
+   - 底层中枢：所有 Agent 共享统一的词库、知识库与调优提示词包。
