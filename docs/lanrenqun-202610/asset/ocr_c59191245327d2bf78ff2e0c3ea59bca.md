马上就要出了，我才在开始急急忙忙做面试题，上架、发布笔记。虽然该做的都做了，但是因为为进入的时间太晚了，只是零零星星地除了几单。

从这件事情，可以得出：强节点类的生意，如果等用户已经开始集中搜索的时候才做产品，其实留给内容铺设和搜索承接的时间已经很少。

所以在保研高峰期的时候，我就会提前铺设笔记、更早一点去做产品。如果看中了一个赛道或者商品，最好是提前 1-2 个月，就要开始发布一些干货来获取目标用户的关注和阅读，而不是等到需求已经爆发再去追铺笔记。

# 在节点之前做三件事：

提前理解需求 → 提前把商品准备好 → 提前把能承接搜索的内容铺出去。

# 二，自嗨做产品，折腾了半个月的知识库，一单也没有：把“做产品”放在了“验证需求”前面

在做求职赛道的时候，我当时想解决两个问题：一是提升客单价，二是把人群从“四大面试”继续往其他求职场景拓展。

当时参考了一些圈友的建议，我决定从不同岗位的面试精讲入手，做一个求职知识库。这个方向本身不能说没有需求——求职面试当然有人需要准备。
