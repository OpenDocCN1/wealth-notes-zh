# 现在参选大致有三个阵营；

内塔尼亚胡阵营（利库德+极右+传统派）；48—50席埃森科特阵营（正直党+中间派+利伯曼等）；52—54席阿拉伯政党；约13席浮动另外一些小党；大致能拿到4—8席；埃森科特阵营目前微弱领先（43%~46%vs内塔34%~36%），但两个阵营都过不了61。

所以未来大致会出现三种局面；

埃森科特获授权组阁（拉拢一些小党，或者获得阿拉伯政党支持），这种可能性最大。埃森科特因为内部矛盾，无法拉拢一些小党组阁，凑不齐61个席位，那么内塔尼亚胡就可以以看守总理身份赖在位置上不走，这是最麻烦的。

内塔拉拢小党凑齐61个席位，那么就是内塔连任，中东局势就会有更多变数。下面谈谈如果埃森科特成功组阁的影响。

首先必须要明确的是，埃森科特上位不代表以色列基本国策会出现翻天覆地变化，埃森科特执政还是要立足于以色列跨党派政治共识，这些政治共识包括：反伊朗、也反哈马斯、不认巴勒斯坦国。

但是，埃森科特属于务实派，他如果上位，对外政策不会如同内塔那么激进。中东地缘政治冲突大概率会降温。对伊朗不会追求颠覆现政权，而是会回到比较务实的立场，包括把浓缩铀运出伊朗，伊朗减少对代理人武装的支持。
