# ## 一、先找到问题，再修改提示词

写短篇时，常见的无效指令是：“剧情丰富一点”“反派聪明一点”“权谋高级一点”“减少重复”。这些词太笼统，AI 很难判断应该改动哪些情节。

更有效的做法是把感受转化为可执行的检查项：

| 表现 | 需要检查什么 | 优先调整什么 |
|---|---|---|
| 故事线单一 | 全篇是否只靠同一种冲突推动 | 大纲的核心矛盾、阶段目标与情节功能 |
| 情节重复 | 多个场景是否换了人物却重复同一套打脸、误会或争吵 | 场景的冲突起因、解决方式和后果 |
| 反派降智 | 对手是否无视已知信息，反复给主角送机会 | 人物目标、情报、筹码、风险与备选方案 |
| 权谋不在线 | 是否靠主角全知、反派泄密、巧合取胜 | 利益关系、信息差、策略与代价 |
| 反转生硬 | 关键线索是否临时出现，结局是否强行翻盘 | 伏笔铺设、误导与回收 |

**先问一句：问题究竟出在大纲、细纲，还是正文？** 如果大纲本身缺少有效矛盾和人物动机，仅修改细纲提示词无法彻底解决。
