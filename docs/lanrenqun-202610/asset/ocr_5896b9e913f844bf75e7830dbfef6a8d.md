# 臆想他人生活的种种经历，得出美国社会真黑暗的结论。

从这篇雄文里，我们看到了丁玲奶奶此刻虽然刚在北大荒养了几十年的鸡，刚在落实政策下过回了人上人的生活，但依然能保持了她当年在上海十里洋场当沙龙贵妇时的娇气高贵，仅凭一面之缘后的臆想，就脑补出了一个美国流浪汉的全部身世。着实是巨笔如椽。

![](bbox=[0.083, 0.307, 0.934, 0.554])

不过后来的事情我们也都知道，虽然丁玲老师把美国人民生活说的真么惨，却也挡不住上世纪八十年代大批中国精英跑去美国体验她一点也不留恋的美国生活，最后不少人还把房子、票子甚至自己的人生都彻底钉定在那个大洋彼岸。

所以回头想来，我们不得不追问一个问题：
丁奶奶的这一通吓唬，到底在吓唬谁呢？
它其实是高度特供给这辈子没什么机会去美国体验生活的社会中下层老百姓的童话。

那个年代，有些人相信了丁奶奶的《曼哈顿街头夜景》，有些人则在上演真实的《北京人在纽约》。
