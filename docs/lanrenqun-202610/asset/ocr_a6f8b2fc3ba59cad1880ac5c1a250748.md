# 3、优质文章三指标

+   - 点击率>8%：由标题和封面决定。
+   - 阅读时长>1分钟：由内容长度和吸引力决定。
+   - 长文完成率>40%、短文>60%：由内容质量和节奏决定。

这三个指标不仅影响单篇流量层级，还影响整个账号权重评级。如果账号里70%以上的文章都达不到这三个标准，账号就会整体降权被标记为低价值账号。

# 4、助推/流量激励特别说明

新号绝对不要用，是巨坑，十个用九个废。

用了助推之后文章会进入最严格的审核流程，一点小问题都会被放大。很多人用了流量券之后账号流量直接崩盘基本救不回来。

助推的正确使用场景：账号稳定、内容100%合规、已经是爆款了想再加一把火冲更高流量的時候谨慎使用。限制条件：只支持发布3天内、平台内首发、开启了推荐、非转载的原创内容。
