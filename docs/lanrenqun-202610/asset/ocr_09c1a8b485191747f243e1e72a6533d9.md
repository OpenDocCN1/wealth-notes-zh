# 人一看就明白：收益高到反常，风险就一定藏在你看不见的地方。

不懂规则的人，则会兴奋地冲进去，然后成为别人收益的来源。按照这个逻辑往下推，我们会得到一个有点残酷、但很真实的结论：如果不懂规则也能一直安然无恙这件事成立，那么这个世界上就不该有人被骗、不该有人踩坑、不该有人在同一个坑里反复跌倒。但事实显然不是这样。

所以，规则从不缺席，它只是沉默。而沉默的规则，一定会让不知道它存在的人买单，而让知道并利用规则的人获利。

这就是我想说的，这个时代最隐蔽的一种分化。它不再仅仅是钱的分化、学历的分化，而是理解世界方式的分化。那么，我们到底该怎么用这张地图？我们不需要把二十条全部背下来。

这张规则地图真正的用法，是化成几个可以随身携带的思考动作。我自己摸索下来，有这样四个动作，分享给你。
