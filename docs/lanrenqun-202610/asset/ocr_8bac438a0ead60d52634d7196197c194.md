# 抖音时间线（对比刚才页游的逻辑）

+   - 上线：2016年9月，一开始是小众音乐短视频，只有年轻人玩，没出圈
+   - 小范围起量：2017年，尬舞机、几首BGM爆火，App Store登顶，但还没全民普及，属于圈内火
+   - 真正起飞 (破圈)：2018年春节 (关键节点) 砸春晚广告、明星红包、挑战赛，春节短短十几天，日活直接翻倍，从三四千万冲到近7000万；2018年6月日活破1.5亿，正式全民化，完成逆袭，从年轻人APP变成国民应用 人民网

# 火爆阶段划分

+   1. 爆发期：2018～2020年（黄金红利期） 流量红利最大，普通人随便拍视频都容易起号；直播、电商开始进场，商家、达人涌入，是抖音最赚钱的流量时代。
+   2. 成熟期：2021～至今 流量不再是无脑推荐，算法变严、竞争白热化，买量成本上涨；但抖音没有“结束”，依然是国民级平台，只是草根自然流量红利消失。

> > 一句话总结：
> > 2018春节正式起飞， 自然流量红利大概持续2年 (2018 2020) 2021...

淘宝爆款截流业务在20-21年期间达到高峰，但是由于当时的业务逻辑和框架问题，导致自己培养了很多优秀竞对。当时几乎是把从供应链、选品、运营、客服等全链路的技能全部输出给每个运营成员，这就导致原本能做的4-5年的项目，做了3年不到就被自己一手带出来的兵卷死了。好不容易半年带个熟手出来，结果一年一流失，反复更新迭代玩法，来回拉扯团队，来回好几次，心累了，22年就结束整个业务和团队。
