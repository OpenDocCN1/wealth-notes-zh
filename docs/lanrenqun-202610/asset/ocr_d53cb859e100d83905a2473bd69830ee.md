# 一、百万阶段：第一桶金之后，要看清自己究竟靠什么赚到了钱

创业前，我在十点读书做过知识付费相关工作。2019 年出来创业时，身边已经有朋友在做知识付费 MCN，我能看到他们的业务和数据，知道这件事有人做成了。

更关键的是，这也是我的专业。我懂课程策划，认识一些老师，也了解平台需要什么产品。看到机会之后，我判断自己有条件做，看好对标、操作难度、投产比，就开始行动了。

当时最重要的工作是商务。先找过去认识的老师，再通过老师介绍老师、同事推荐老师。我帮老师做选题、打磨课程、做人设和宣发，再对接十点读书、喜马拉雅等渠道销售。自己加两位兼职，把这门生意做到了百万级的项目年营收。

现在翻回 2019 年的创业日记，第四周我写下的目标是：“到 2019 年底，月营收破 100 万。”往下翻，每天记录的事情很具体：修改课程逐字稿、打磨发刊词和详情页、跟老师沟通选题、跟进合同。
