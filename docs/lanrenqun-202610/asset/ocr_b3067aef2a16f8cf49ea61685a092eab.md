# 几点 AI 相关的感悟

+   1. **尽量找现成的、合适的工具：** 我在这几个月 的过程中也做过一些尝试，虽然这些对我的 AI 能力和认知有帮助和启发，但是从项目结果上来说是“多余的”（比如我曾经尝试多想要去所一些自动化抓取笔记的工具，结果折腾半天就放弃了）不如去使用现有工具，花点小钱，拿大结果 □□
+   2. **写作部分尽量使用 ChatGPT 网页版本 chat 部分：** 不用 work 和应用，写出来的东西人机感很重。我个人感觉：自动化批量写作消耗的时间和精力＞ 网页版写作自己复制，所以至少在我的写作场景里，网页版 Chat 对话反复修改，比整套自动化写作更容易控制表达风格，也更省去后期返工。
+   3. **先有成熟流程，再考虑自动化：** 自动化很牛，但是为了使用 AI， token 有消耗就去自动化，等跑通了，再确定应该把哪些步骤交给 AI，如果只需要做一次，或者用现成工具 10 分钟就能解决，其实没必要专门开发
