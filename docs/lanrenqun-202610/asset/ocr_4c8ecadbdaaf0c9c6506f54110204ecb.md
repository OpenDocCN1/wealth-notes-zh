# # Codex 的第二个角色：内容策划，先把文章想清楚

整理完素材后，我还是不让它立刻写全文。第二轮只做一份写作说明：目标读者是谁，这一篇只解决什么问题，文章最想说清哪一个判断，开头用哪个场景，中间靠什么素材支撑，结尾让读者做什么。

比如只知道“子女借钱要慎重”，却没有人物、借钱用途、家庭关系和可核实的资金安排办法，它就只能提醒我缺什么，不能自己补一个“真实案例”出来。

# # Codex 的第三个角色：初稿执行者，但要先把上下文给齐

到这一步，我才让 Codex 写正文。它拿到的不会只有一个题目，而是五样东西：固定人设、本次素材、已经确定的选题角度、我自己的判断，以及篇幅、语气和事实边界。

这里最容易被忽略的，是“我自己的判断”。如果这一项是空的，AI 会很自然地填入那些最安全、最常见的正确话，文章就又回到“要爱自己、要重视亲情、要留好退路”。我会先把自己的态度写成一句直白的话，再让它帮我展开。
