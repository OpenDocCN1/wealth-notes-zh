2分，总分10分。这张表不追求看起来专业，它只负责逼我不要用情绪代替判断。

| 检查项 | 我会先问清楚的问题 |
|---|---|
| 人群 | 到底写给刚退休、独居、夫妻同住，还是有一定积蓄的准退休人群？ |
| 问题 | 他此刻卡在钱、身体、子女边界、夫妻相处，还是无效社交？ |
| 验证 | 同类需求或标题过去是否出现过稳定的高阅读、转发、留言或赞赏？ |
| 人设 | 当前账号的讲述者有没有对应的经历、观察和表达边界？ |
| 素材 | 有没有人物、生活场景、冲突、数字、评论或可以核实的信息？ |

8—10分，我会进入写作；6—7分，先补素材或调整角度；低于6分，就先不写。这个分数不代表它发出去一定会爆，它只是帮我提前发现“根本没有东西可写”的选题。

真正能带来流量的题，一般还要同时做到几件事：读者一眼能判断和自己有关；具体到他能在脑子里想象出一个画面；事情不解决会有什么现实代价，解决后又能多得到什么。还有一点很重要：这件事最好是他熟悉的，却从来没有人替他说透。

比如“晚年学会爱自己”，范围太大，读者不知道和自己当下有什么关系。“60岁后，子女再开口要一笔大钱，这三笔钱别急着拿出去”，人群、冲突和利益就都出来了。
