# 把水道给联合上，这就是口：

自发的联合哟，老马说的“自由人联合体”了..这是不是就是水道、河道了？君子借助的就是这个自动联合的水力，虽然不暴利，但是稳当呀。再联系前面《朋友义利》那篇，义字是不是也一横搞串联的？

所以儒家的生存法则是仁义嘛..不要把仁义当做某种道德，再说道家的道德也不是俗话说的道德，总之这些都是物理运力，更深一层就是人性运力。反过来小人生态位呢？当然就是翻转过来了，把水给空掉。

那为啥没有一横在里面联合呢？同忧能相亲，水能联合，但同欲是相憎，咋能联合？小人之交表面看甘若醴，表面和内里是反的呀，内里才不和睦呢，必须互相拆台呀.所以小人的行为模式必然是——渐行渐远！

然后长老在哪呀？要干嘛呀？当然就是合：中文是不是和五行配套的？复杂中文其实就是六十四卦演绎，只不过一个画的规矩（数），而中文画出直观的运动（象），所以叫象数合参。

所以管你是君子还是小人，都要往长老上面合，这仁角色没有谁大谁小其实，是彼此依存的关系。

所以进入《五行八识图》后，人就别老固执，别老讨厌这个排斥那个的，都是角色扮演而已，要观察到一气周流变动不居才行。要是八识的话，那就是训练无我了，只有破我才能逐步智商占领高地.八识、五行、经济这都一回事，先有个基本纠缠运
