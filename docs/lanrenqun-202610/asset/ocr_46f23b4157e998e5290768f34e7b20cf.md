# 慢慢走下悬崖

其实，在一些人看来，仅仅减速是远远不够的。

Ezra Klein 就提出：“快步走下悬崖，只比冲刺跑下悬崖好那么一点点。”他主张直接叫停 RSI，并且把默认规则翻过来：先由实验室证明自己的做法是安全的，再和国会商量哪些情况可以例外。他对比说，在这些实验室所在的地方，盖一栋八层公寓楼要经过漫长的公众审查，OpenAI 给停车场装太阳能板都需要许可，却可以随时开始递归自我改进，“连一场听证会都没有”。

上周，OpenAI 安全团队的 David Robinson 辞职。他在 OpenAI 工作了三年半，领导撰写了 12 次前沿模型发布的安全报告，包括 GPT-6 Astra 的系统卡（system card，AI 公司随新模型发布的安全技术文档）。他并非出身硅谷：罗德学者，耶鲁法学院毕业，创办过民权组织，在拜登政府的白宫科技政策办公室工作过。2023 年加入 OpenAI 时，他觉得那些担心 AI 毁灭人类的科学家“有些天真”。
