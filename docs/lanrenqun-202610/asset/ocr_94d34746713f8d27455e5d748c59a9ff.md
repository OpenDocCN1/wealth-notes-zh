这些东西没有哪一个是仅靠一句煽情的话就能写透的。但也正因为难，它才有可能从一次性的热闹，变成一个读者愿意反复回来的账号。

# 三、赞赏超过2万以后，我才真正理解读者为什么愿意付钱

# 第四个阶段：我开始用赞赏，区分“感动”和“信任”

刚开始做时，我以为文章只要足够感人，用户就会赞赏。后来数据看多了，我才发现不是这样。

有些文章阅读量不错，留言也很热闹，赞赏却不高。它把人的情绪调动起来了，但没有建立更深的关系。也有些文章阅读没有那么夸张，赞赏却更集中。这往往意味着，它不一定打中了最大范围的人，但打中了一群处境非常具体的人。

我后来把这种差别想明白了：感动只是触发情绪，赞赏更常发生在读者确认“你真的理解了我，还替我说出了一直不知道怎么说的话”以后。

# 读者愿意赞赏，往往经过了三层感受

第一步是看见他。不要只写“老年人很孤独”，要让读者看到一个人傍晚自己吃饭，看到孩子打电话总说忙，看到老伴不在以后，屋里连一点声音都显得太大。我写完开头会回头看一遍：前300字里，到底有没有一个能被看见的人？如果只有道理，那么文章还没有真正开始。
