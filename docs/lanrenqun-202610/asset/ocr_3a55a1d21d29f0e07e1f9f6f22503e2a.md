# 账号安全

114. 怀疑点了钓鱼链接，自己打开官方 App 改密码 在私信或邮件里点进可疑页面后，不要在那个页面填密码或验证码。关掉网页，自己打开 X 官方 App（或在地址栏手动输入 x.com），进设置改密码。

115. 在「会话（Sessions）」里踢掉陌生设备 改完密码后，按「设置和隐私 → 安全性和账号访问权限 → 应用和会话 → 会话」进去，这里列着所有登录你账号的设备。看到陌生型号或异地登录，点进去退出，或选「注销所有其他会话」，再确认只剩自己的设备。踢掉会话不会解绑已授权的第三方应用，第三方授权要在同一菜单的「已连接的应用（Connected apps）」里单独撤销。

116. 检查「已连接的应用」，撤销不用的授权 在「应用和会话」里进「已连接的应用（Connected apps）」，逐个看有哪些第三方网站或工具，点进去看它拿的是「只读」还是「读写+发私信」的高风险权限。现在不用的、不记得什么时候授权的应用，点「撤销应用权限」。改密码和撤销授权是两道门，不能互相替代。

117. 打开「密码重设保护」 在安全设置里检查「密码重设保护（Password reset protection）」。开启后，重设密码需要额外账号信息，可增加一道核对。它不能替代两步验证；绑定邮箱本身的安全也要单独保护。
