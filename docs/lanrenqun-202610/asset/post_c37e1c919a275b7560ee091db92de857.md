## 什么是 SEO

SEO 的全称是「Search Engine Optimization」，就是搜索引擎优化。

## 怎么做 SEO

学习中，今天主要分享我自己做的 2 个动作

### 2.1 做内页 | 首页

做内页，就是做 TDH

- **T，就是标题**

> 网页标题。就是谷歌搜索结果里那个蓝色大字，也是浏览器标签页上显示的文字。这是谷歌判断你的页面讲什么的最重要依据——写好了，排名才能上去。
> 
> 10~30 字符，核心词放最前面，别啰嗦。

```
✔Free QR Code Generator - Create & Download
Instantly | ToolHub
✔Best Image Compressor - Reduce Size by 80%
Without Quality Loss
✘Welcome to my website
✘QR code generator online free tool (堆砌，没
卖点)
```

- **D，就是描述**

> 页面描述。搜索结果里标题下面那两行灰色小字。谷歌不一定照搬你写的，但写好了能提高用户点击的概率。
> 
> 150~160 字符，说清「你能解决什么 + 为什么选你 + 行动号召」，用户看了想点。

```
✔Generate QR codes instantly for free.
Support URL, text, WiFi, and vCard.
    Download in PNG or SVG. No sign-up
required. Try now!
✘This is a QR code generator website.
```

- **H：可以理解成 markdown 的层级**

> 各级标题（H1 到 H6）。H1 是一个页面的大标题——通常跟 Title 保持一致或密切相关。H2、H3...是下面的小标题，就像文章的章节骨架，谷歌靠它们理解你的内容结构。

```
H1（主标题，一页只准有一个） = 主关键词
├ H2（3~5 个） = 相关关键词
│ ├ H3 = 长尾关键词
```

### 一句话总结

- **T（标题）** —— 告诉谷歌和用户“这页讲什么”；
- **D（描述）** —— 吸引用户点进来；
- **H（标题层级）** —— 把页面内容搭成清晰骨架，让谷歌读懂。

另外需要注意的点：一个页面只能有一个 H1。

这是硬规矩。谷歌用 H1 来判断“这一页到底讲什么”，你写两个 H1，谷歌就不知道哪个是大主题了。

**H2~H6：没有固定数量，但要有“骨架感”**

H2 到 H6 是小标题层级，用来搭页面内容的骨架。没有“一个页面必须有 3 个 H2、5 个 H3”这种硬性规定。

关键看内容：你的内容分了几个大块，就写几个 H2；每个大块下面需要再细分的，就用 H3；再往下就是 H4。

写页面之前，先想清楚内容大纲！

上面是一般的写法，也是业内标准写法。但是你如果想要出单，还要更进一步。

## 什么是 GEO

GEO 的全称是 Generative Engine Optimization，就是生成式引擎优化，做 GEO 的目的就是让你的网站内容被大模型、AI 搜索（Google SGE、Perplexity 等）引用、摘录进 AI 回答里，不一定带来点击，重点是在 AI 答案中获得曝光。

## 怎么做 GEO

先看下 GEO 效果

### GEO 主要分为五部分

下面简单介绍 GEO 的五个部分，但是你也可以完全不用知道，让 AI 来做，在这一部分的末尾，我会介绍下，怎么让 AI 做 GEO，把你的 SaaS 推荐给用户

- **第一部分：AI 爬虫访问**

这一部分主要检测 5 个点，AI 训练爬虫能否访问、AI 搜索爬虫能否访问、ChatGPT-User 等用户触发的抓取能否读取真实内容、页面有没有 noindex，以及 nosnippet 等设置是否限制 AI 引用网页内容。

可以检查网站的 robots.txt、页面 robots meta 和响应头，确认需要的 AI 爬虫可以正常访问，同时页面没有误加 noindex 或 nosnippet，避免网页可以访问，却不能进入搜索或被引用。

```
OpenAI 文档地址
https://developers.openai.com/api/docs/bots
```

- **第二部分：机器可读性**

检查主要内容是否直接存在于 HTML 中，title、H1、description 是否完整，以及网站有没有 sitemap、canonical，URL 是否清晰稳定。这些原本就是 SEO 的基础，在 GEO 里同样重要。

> 有点像给 AI 准备的网站说明书，用 Markdown 告诉 AI 网站是谁、有哪些重要内容，以及对应页面的地址。

- **第三部分：结构化数据**

结构化数据可以帮助机器更明确地识别网站、作者、发布时间和内容类型。大家可以根据页面类型添加 FAQPage、HowTo、BreadcrumbList 等内容结构，再用 Organization、Person 或 WebSite 说明网站和作者是谁。

```
Google 文档地址：
https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data?hl=zh-cn
```

写文章最好也关注下结构化数据，下面举个例子

![](img/2f83509442ad105ae08a02b5eda1d737_11_0.png)

> [https://www.gatsbyjs.com/docs/glossary/headless-wordpress/](https://www.gatsbyjs.com/docs/glossary/headless-wordpress/)
> 
> 跟着谷歌 AI Overview 学习谷歌是怎么满足用户需求的。
> 
> 谷歌有最多的数据，知道用户搜索这个词想要什么，于是就在 AI Overview 里尽量的去满足用户。
> 
> 所以分析 AI Overview 的行文结构，可以一窥谷歌是如何理解用户需求，如何满足用户需求的。
> 
> 我们梳理一下大概的结构：
> 
> 术语解释：Headless WordPress is xxx；
> 
> 架构原理：How the Architecture Works；
> 
> 列出优点：Why Go Headless? (The Pros)；
> 
> 列出缺点：The Big Trade-Offs (The Cons)；
> 
> 适合与不适合：Who Should (and Shouldn't) Use It?

如果我们要写一篇术语解释文章，最好也是类似的结构。

因为这样写文章，是为了更容易被谷歌收录。

- **第四部分：内容可引用性**

清晰的标题层级、列表、表格，以及开头先给答案，都方便 AI 提取内容。写文章时，可以把部分 H2 改成用户会搜索的问题，然后在段落开头直接回答，再补充数据和来源。这样既方便用户阅读，也是在给 AI 提供可以直接使用的答案片段。

GEO 论文在 1 万条查询的实验中发现，给内容增加可靠来源、相关数据和权威引用，可以让内容在生成式回答中的可见性最高提升约 40%；单纯堆关键词则没有明显帮助。当然，这是特定实验结果，并不代表改完一定会被 AI 推荐。

文档地址： https://arxiv.org/abs/2311.09735

- **第五部分：信任与 E-E-A-T**

最后一部分是 Trust 与 E-E-A-T，主要关注作者、发布时间、About、Contact、隐私政策，以及品牌信息是否一致。大家可以给文章增加真实作者和更新时间，并在网站导航或底部放好 About、Contact、Privacy、Terms 等页面。

Google 的实用内容指南也给出了相同方向：内容要有第一手经验、明确来源和作者信息，并真正帮助用户解决问题，而不只是为了排名。对 AI 来说，能读懂内容只是第一步，是否愿意引用，还要看内容是否可信。

```
Google 文档地址:
https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=zh-cn
```

## 有流量的后续

当你的站 UV 达到 3000 以上，PV 达到 300 以上，你此时应该考虑的事，就不是一直发外链了，而是要回到站内，看下为啥不出单，这比发外链重要一千倍，一万倍!!! 关于为啥不出单，这个问题比发外链还重要，在这分享一个比较实用的方法，就是做埋点，分析埋点！

如果你是产品经理，程序员，或者做过研发相关工作，一般都会知道埋点，用大白话说，埋点就是，记录用户的行为，看下用户点击了什么按钮，在哪个页面停留了多久，从哪个页面离开了，这个听起来和 Clarity 功能很像，但是你可以通过记录用户行为到数据库，能更好的分析用户行为。

那么怎么把你的站做成专业的 SaaS，那就是你要用心做，花时间做，一步一步做！

另外你要看过足够多的优秀的 SaaS，你才能知道优秀的站长什么样。

### 专业感 硬件清单（自检用）

对照检查，缺哪个补哪个：

- **Pricing 定价页**——90% 的新人站没有这页，这是最明显的「业余信号」；
- FAQ 页、Docs / 教程页、隐私政策 + 条款页；
- 全站导航条 + 页脚——顺便说，这还关系到谷歌的 Sitelinks（搜索结果里你名下的那一排小链接），导航条里的链接更容易被谷歌选中展示；
- 工具页配 **4-6 张图** + 可嵌入的 YouTube 视频。真工具站配图配视频，信任感完全不一样。

## 如何找到真需求

如果你是新人，我建议直接抄；如果你是高手，那方法有很多。今天我只针对还没出单的圈友分享。当然，如果可以从自己的痛点找到真需求，那真是太好了！

### 关于怎么抄？

分享一个全自动找需求词的方法，不可能找不到词，找到需求词，就可以做一个 AI 产品。

Product Hunt 有一个免费 API 接口，可以根据日期拿到产品 list，https://api.producthunt.com/v2/docs ，那就不能第二天就要看到开花结果一样，上站也有几个阶段，我先用一张图来总结下

![](img/2f83509442ad105ae08a02b5eda1d737_19_0.png)

### 阶段一：网站刚上线（0 流量期）

关注点：产品功能与网站内页

这个时候不要去盯流量，因为注定没有。只关注网站本身的功能完善。同时把网站提交到 Google Search Console (GSC) 和 Bing Webmaster，开始脚踏实地做好网站内页、加外链、写文章推广，做基础播种。

### 阶段二：外链开始被收录

关注点：收录数量

当你播下的种子开始发芽，就可以把注意力转移到外链页面的收录数量上，看到生效的外链逐渐增多，也会有一些成就感。在这个基础上，继续保持节奏，完善网站内页、加外链、写文章。

### 阶段三：GSC 后台开始有数据

关注点：展示数、点击数

坚持一段时间后，Bing Webmaster 和 GSC 后台应该能看到一些关键词查询出现了，并且有了初步的展示数和点击数（哪怕是个位数）。

这个时候情绪价值极其重要！找一个会提供情绪价值（绝对不会给你泼冷水）的好朋友，每天给对方发你的网站展示数和点击数截图。这不仅是分享喜悦，更是为了给自己打鸡血，积攒继续做下去的动力。

### 阶段四：关键词有了排名

关注点：资源倾斜与排名优化

当 GSC 后台的关键词积累到一定数量，并且开始有排名后，策略就要发生转变了。接下来需要重点关注那些已经冒头的关键词，把手头的外链和内容资源精准倾斜给这些已经有排名的关键词和页面，集中资源提高重点关键词的排名和点击量。

### 阶段五：日均访问量突破 100

关注点：订单量与转化率

当网站的自然访问量稳定超过 100 以后，通常就会陆陆续续出现一些付费用户了。直到这一步，你的关注点才可以顺理成章地转移到订单量和收入上，可以开始考虑提高转化率了。

克服焦虑最好的办法，就是把宏大的目标拆解成每天可见的微小正反馈。不看终点的遥远，只看脚下下一步的扎实，不知不觉，你就走过了最难熬的阶段。最后想特别建议一点：多交流多沟通，千万不要自己闷头干。独立开发者做网站往往是一场孤独的单人游戏，闭门造车很容易将焦虑无限放大。偶尔跳出自己的代码世界，去线下和同行聊聊，找朋友互相测试一下对方的新网站，或者只是找个搭子互相打个气。当你开始和外界建立真实的连接，不再一个人死磕的时候，你会发现，往往就在这些不经意的交流中，解不开的心结自然化解了，卡住你的难题也迎刃而解了。

## 总结

如果你做了上面说的动作，只要没有违规，你的网站流量就会慢慢多起来，SEO 可能要 3-6 个月，但是外链一般 2 周就会有效果。有流量之后，你要做的就是查看用户行为，分析用户行为，为什么有的用户会出单，有的不会，出单的用户从哪来的，做了哪些动作，最后进行订阅；没出单，就要分析，来源，停留时长，用户行为，跳出的页面等！
