# 蓝 V 自然流

企业认证账号也会有自然流量。我们也陪跑过一家本地财税公司，用多个企业号持续覆盖本地需求和搜索内容，同时配置少量账号做付费投放。

它能做起来，与本地化业务、已有服务基础和长期内容投入有关。不能只看到别人铺了很多账号，就认为多注册几个号一定有效。账号、人员和更新量都需要算成本。

如果你还在验证小红书这个渠道，自然流可以作为一种起步方式。但要给自己设置验证目标，别把“每天都在发”当成项目在前进。

# 聚光和千帆投放

在我们这些项目里，聚光主要用来测试咨询、线索获取，千帆则出现在商品成交入口的测试里。具体选择，要看业务能使用的产品能力、推广目标和账户条件。

付费的优势，是当内容和转化逐渐稳定后，可以围绕预算、成本和获客量做调节。销售接不住时少投一些，有余力时再扩大测试。

我在现场把它比喻成“水龙头”。这个比喻说的是可调节性，不是说扩大预算，客户就一定等比例增加。竞争、人群、素材衰减和销售承接，都会影响放量后的实际结果。
