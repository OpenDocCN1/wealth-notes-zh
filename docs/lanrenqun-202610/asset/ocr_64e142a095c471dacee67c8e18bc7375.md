作量，再结合难度报一个双方都能接受的价格。定价这件事，做多了就有感觉了。

那我当时怎么敢接呢？因为我有师傅啊——实力不都是从项目里锻炼出来的吗？我 就硬着头皮去找老师请教，问 Web 前端展示该怎么做。好在老师人很好，一直帮我 解决问题、出方案。

那单前后花了三天：前两天几乎都耗在 Web 展示上，查资料、问老师、一遍遍试，真正写代码的时间反而没多少。交付的那 一刻我长舒了一口气——原来咬咬牙，真 的没有过不去的坎。

第一单 600 元到手后，我给自己定了个规 矩：每做完一单，都把遇到的技术难点、 沟通话术、报价经验记到备忘录里。这个 习惯一直保留到现在，很多后来派单时用 得上的经验，都是从这些记录里慢慢长出 来的。
