# 不就直接变成1万了吗？

抱着这个朴素的想法，我就把价格涨上去了，很明显我这里默认涨价以后，销量完全不变。

但是定价也是营收的一环，它会影响用户看到商品后的购买意愿，也会改变产品在整个赛道价格带里的位置。尤其当竞品价格、用户预期都在变化的时候，不是我把5块改成10块，GMV就会自动翻倍。

所以GMV应该拆开来看：GMV = 商品访客 × 支付转化率 × 客单价这三个指标是一起作用的：

+   - 如果缺的是流量，单纯涨价解决不了问题；
+   - 如果缺的是转化，涨价甚至可能让转化进一步下降；
+   - 只有当需求足够强、转化已经比较稳定时，提升客单价才可能真正成为增长杠杆。

# 三，做对的地方：流水不争先，争的是滔滔不绝

聊聊我在今年做得比较好的事情：在今年的店铺运营过程当中我形成了一套不停地小成本拓展新品-测试效果-放大的新品上架策略，一方面是希望利用新品吸引更广的客群，另外一方面也希望可以跑出新的“爆品”，提升GMV。
