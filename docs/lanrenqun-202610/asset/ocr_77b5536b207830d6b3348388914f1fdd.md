范围铺设内容，选题、素材、账号合作和沟通都会带来成本。

在我们接触的部分竞争激烈的行业里，商家只靠自己的企业号介绍产品还不够。用户搜索时看到的体验内容，也会参与决策。因此，种草可以和直接获客一起做。对外沟通时，应当把真实体验和商业合作讲清楚，避免把虚构体验当成消费者证言。

# 截流打粉

所谓截流，是在相关内容和需求场景中寻找潜在客户，再尝试建立联系。它看起来离需求很近，但用户对原内容或原商家的信任，不会自动转移到新出现的商家身上。

所以即使拿到了接触机会，销售仍然要重新解释自己是谁、能提供什么。对需要较强信任的服务，这个成本尤其明显。未经邀请的反复私信也容易造成反感，不能把它当成持续获客的基础。

# 短视频 IP

IP 内容的优势很直接：用户持续看你，了解你的判断、表达和做事方式，最后可能就是因为信任你而付费。

代价是它需要持续投入。本人要出镜，内容要有观点，脚本、拍摄和剪辑也要跟上。即使积累了信任，自然流量的规模仍会波动。

我们接触到越来越多已经有个人影响力的客户，开始考虑付费投放。他们有内容和信任基础，还希望获客数量能更贴近公司
