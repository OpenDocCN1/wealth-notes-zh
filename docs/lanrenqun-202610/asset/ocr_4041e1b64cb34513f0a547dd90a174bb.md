# 有点懒。

但他们做的每一个选择，似乎都恰好踩在了点上。他们不慌不忙，但是路越走越宽。

我们常常把这种差距归因于运气，或者归因于“人家有资源”。但真的是这样吗？

其实，在运气和资源的背后，藏着一个更隐蔽、也更根本的东西，那就是有些人懂得世界是按什么规则运行的，但是有些人不懂。懂的人，是在顺着规则发力。做事首先抓住第一性，认清规则、理解规则、顺应规则。不用蛮力，而是借力打力。

所以往往一通百通，一顺百顺。不懂规则的人，一辈子都在跟规则死磕。

这篇文章，我想认真聊聊这件事。文章会涉及到 20 条我提炼的世界运行的基本规则，以及我对这些规则的拆解说明。文章 8000 多字，更像是一份规则手册，适合在迷茫时或者想成事时，翻翻看，常读常新，必有收获。

我们现在开始吧。

# 一个人失败的根本原因，是在跟规则较劲

我们先来看一个很常见的场景。一个人想要变得更好，所以他就给自己定了一堆目标：每天背 50 个单词，跑五公里，读 30 页书，早睡早起。

他靠着一股蛮劲儿，咬牙坚持了两个星期。然后，在某个加班到深夜的晚上，计划中断了，他好像也泄气了，再也没继续下去。
