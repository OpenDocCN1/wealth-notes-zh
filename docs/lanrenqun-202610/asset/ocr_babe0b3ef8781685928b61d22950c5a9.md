# 2. 关键沟通前预演 Prompt

我马上要和一个关键人物进行电话沟通。

请重点整理：

+   1. 这个人的身份、机构、目前已知职责和权限；
+   2. 他以前明确说过什么，哪些事情已经承诺过；
+   3. 我这次电话最需要确认的 3～5 个问题；
+   4. 对方可能出现的几种典型回应；
+   5. 每一 种回应以后，我下一句应该继续追什么；
+   6. 哪些问题最容易被模糊回答或带偏；

+   8. 如果他说自己没有权限，我应该继续确认谁有权限、由谁转交、什么时候回复；
+   9. 这通电话结束前，最低必须确认哪些信息；
+   10. 哪些金额、责任、和解条件或权利放弃内容，我不应该在信息不完整时提前承诺。
+   10. 最后给我一份简短电话提纲。
