# □ 图片处理与发布检查

+   1. 留原件：保存原图、生成记录或拍摄来源，便于回溯。
+   2. 核实授权：确认图片、人物肖像、商标及引用范围。
+   3. 做质量调整：裁切、尺寸和清晰度服务于阅读，不改变事实含义。
+   4. 如实标注：按发布时平台要求设置 AI 来源标识，不冒充实拍。
+   5. 核对元信息：不伪造设备、地点、时间，不规避来源标识。
+   6. 隐私检查：截图隐藏 UID、token、联系方式和无关个人信息。
+   7. 图文一致：示意漫画写明示意；不能把生成图当成现实事件的证据。
