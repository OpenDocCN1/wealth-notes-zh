# 步骤5：每个小任务开工前，先问五句。

动手写代码前，按顺序问：

+   96. 这个功能这一版真的要做吗？
+   97. 项目里有没有已经能用的？
+   98. 手机系统或平台自带的能力够不够？
+   99. 已经装好的工具包能不能做到？
+   100. 前四个都不行，才写一段最小的新代码。

如果有意先做简化版，就在说明里补两句：它最多能撑到什么情况，出现什么信号就必须升级。
