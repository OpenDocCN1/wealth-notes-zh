+   - **算法检测的最关键指标是停留时长。** 点开目标文章后，在页面停留 15~30 秒以上，把组图从第一张滑到最后一张，翻看评论区。

+   - **切忌：** 点开 2 秒立刻退出，系统会判定为“低质误点”，不再推荐同类。

+   - **第 3 步：给算法喂正向反馈（点赞/收藏）**

+   - 每刷到 3~5 篇非常垂直的优质同行，点一次赞或收藏，并在评论区浏览真实读者发言。

+   - **第 4 步：推荐流闭环检验**
