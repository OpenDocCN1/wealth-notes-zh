反馈不太一样。下面是选题时的个人观察，不是平台整体用户画像。

+   - **小红书**的核心人群看重“审美质感”与“实用消费攻略”；
+   - **抖音**的用户追求“强视觉刺激”与“即时情绪快感”；
+   - **微信公众号**上，我这类怀旧和生活题材常收到成熟读者的反馈；35～55 岁是我设想的部分目标读者，不能泛指公众号全体用户。他们人生阅历丰富，不爱看轻浮的搞怪与空洞的嚎头，他们最在乎两件事：“这事跟我有什么关系（生活共鸣）”，以及“把这篇文章随手转发到家族群、老友群里，能不能体现我的阅历和见识（社交货币）”。

如果你的内容能让一个四五十岁的人看完后心里微微一动，感叹一句“这说的不就是我们当年吗”，或者让他学到一个能拿去跟朋友吹牛的冷知识，那至少说明选题有机会引起目标读者兴趣，还要看具体发布后的反馈。
