# 但只要把时间拉长，绝大部分股票的回报都不好，只有极少数的公司创造了巨额财富。

1900年到2025年，美股市值加权的指数回报率是1.5万倍，年化接近10%！而美国国债的回报率是25倍，年化仅仅3.3%！

有趣的是，所有近3万只股票的平均回报率是306倍，中位数甚至是-6.87%！

对比这些数据，你就知道股市回报的分布有多大的差距了。

3万只股票中，能产生正收益的只有48.22%！

美股如此，A股也一样。同样是少数公司贡献了绝大多数收益。

那些少数成功的公司，存活的时间也更长。宽基指数的目的是要选出这些少数公司。怎么选呢？

由于市场长期是有效的，那些长时间能成功的公司，市值必然就会越来越大。

所以指数往往都采用市值加权法来进行筛选！指数甚至不理会财务数据！只看市值！

最终，优秀的公司，会自己跑出来。

通过这种方式，肯定可以选出贡献最大的公司。

如果让我们自己去选，你有把握选出这些公司吗？

恐怕几乎是不可能的。
