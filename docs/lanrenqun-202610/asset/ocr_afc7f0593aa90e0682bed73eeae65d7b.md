# 当然紧急。

但真的重要么？

我不觉得有任何重要。

我完全可以像骆驼一样，把脑袋埋沙子里。

我知道自己每天只是在空耗时间，但无视这个问题，继续在那家公司干十年的架构师，每天当救火队长，也不是不行。

但这么做，对我个人而言，究竟是一种进步呢？还是一种消耗呢？

显然是后者。

唐僧去西天取经，走了十万八千里，得了正果。

驴子拉磨盘，走了不止十万八千里，却变成了阿胶。

驴子很不满，问如来，why？

> 如来告诉它，前者叫进步，后者叫消耗。

你一直在做紧急不重要的事情，那不是消耗是什么？

所以我跳槽了。

不是无目的的乱跳，而是把前期积累的业绩，可以当成台阶用的，有针对性的跳槽。

于是 11 年，我在甲方集团，半年内连升三级。

连升三级之后，我又进入了平稳期，又开始发现自己的工作变得紧急不重要。
