# 开

做着做着，内容就不只是奖励了。

想开一张卡、办一个海外账户，常常又要先准备手机号、地址或者其他材料。前面的基础没做好，后面看到喜欢的卡，或者有适合自己的活动，也不一定能马上参与。

我自己做海外地址和信用卡那段时间，筛过300多个地址，跑过视频公证，也经历过预审批失败、补材料，最后才获批。

这些东西写在一份教程里，可能就是几步，真做的时候每一步都得处理。把它们记下来，就能写成比一张奖励截图更完整的内容。

后来我有一篇海外银行实操长文，浏览已经到了26万多。它带来的反馈，让我更愿意继续写这类东西。
