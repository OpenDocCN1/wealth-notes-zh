所以从上面内容类型出发，可以用三种方式来做直播：

+   1. 录屏、实拍、手搓等方式产出视频，直播时循环播放视频文件。适用于任何场景。
+   2. 实时转播，直接通过直播间链接对原直播间的内容进行实时转播。适用于拿到原博主转播授权，或者你不怕原博主找你麻烦的场景。
+   3. 真直播。适用于你想自己在 YouTube 做真人 IP 的场景。
