# 11 月趋势分析

今天这票文章主要是系统性的把这次下跌的低点，接下来的高点，以及后期反弹后市场的走势，还有这轮熊市的最终低点在哪里？等着一系列的问题，全部都准确的表述一番，这样大家也好心里有数。

首先就是这次调整最终的低点 2，我计算的点位用平均股价来看是 22.7 附近，目前最低 23.05，那么如果 23.05 是低点 2，那么反弹的高点 3 大概可以到 28.16 附近。

如果近期平均股价再次跌破 23.05，那么反弹的高点 3 就需要重新计算，大概大家要明白一点，就是反弹的高点 3，不会超过前面的高点 1，就是平均股价 8 月 18 号的最高点 29.62。
