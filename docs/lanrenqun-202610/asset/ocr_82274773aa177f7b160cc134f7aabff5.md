这些我们还在确认。我准备拿客户真实的一份素材和一篇参考稿，把流程走一遍，逐处讨论她需要什么，减少双方各自理解“做一个内容工作台”带来的偏差。

# 客户出钱跟我们开发同一款产品。

飞鱼哥这个说法，让我开始重新看待正在做的事情。

我自己也做自媒体，同样需要找选题、拆结构、写文案。护肤客户和疗愈客户的需求，也有相通的部分。如果把这些做好，客户能用，我自己也能用，之后还有机会服务有相似需求的人。这样看，我们这次花的时间，就有机会在后面的项目里继续发挥作用。

# 客户相当于我们的产品经理。

她会告诉我们平时怎么工作，哪些地方麻烦，已有的工具哪里好用、哪里还不够。这些具体的需求，能帮助我们判断产品该做成什么样，比自己关起门来猜有用得多。

我后续还负责产品的市场化推广，所以这段经历对我也很重要。我需要知道，我们做出来的东西具体能帮到谁、解决什么问题，才能把它介绍给下一个客户。眼下先把这款产品打磨到自己也用得顺，后面再去验证它能服务多少有相似需求的人。
