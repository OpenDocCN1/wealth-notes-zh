# ### 测试阶段：

和「节点驱动」类型的产品不同，「用户驱动」相关的笔记，最好是商品笔记+普通笔记为主，普通笔记拿阅读、提升内容互动数据，普通笔记主要负责积累关注和信任，为后续商品成交创造机会。

# ### 数据反馈-优化阶段：

在发了一周左右的时间，就可以看下具体数据反馈，普通笔记看创作者中心的笔记曝光阅读数据、商品笔记看商品点击率和成交金额。

# ### 市场驱动：

市场驱动主要引用在还没有跑通的情况下，跟着市场反馈快速制作商品，缩短「制品-测试-反馈」的周期。比较常见的例子是就是做课件目前我把课件制作中重复的规划步骤做成了网页工具：输入素材后，自动生成课程规划、逐页文案和生图提示词，生图、最终制作和质量检查仍由我完成（虽然这个工具还经常报错）

# ### 课件制作流程

我制作 PPT 的流程主要分成 4 个阶段

+   - 找素材：爆款参考、教材、知识点、用户场景
+   - AI 规划：课程目标、页面结构、逐页文案、视觉规范
+   - 人工交付：根据提示词生图、完成 PPT、检查内容质量
