# 八、推荐的实际操作流程

+   1. 准备资料：短篇的大纲、主要人物设定、目标字数、现有细纲、希望保留的关键情节。

+   2. 先诊断：用提示词 1 判断问题在哪里，不要一上来就让 AI 全篇重写。

+   3. 针对修改：故事线单一用提示词 2；情节重复用 3；反派降智用 4；权谋薄弱用 5。
