# 把反复出现的问题补回教程。

同一个问题解释一次是答疑，整理好之后，后面的人可以直接看。群里不可能永远靠我一个人一对一重复讲。

这些做法不用等几千人的群才开始。第一个跟着做的人在哪里卡住了，就已经是在告诉你，教程哪里还缺一块。

我想通过 TG 放大的，正是这部分指导：让后面来的人，可以用上前面已经讲清楚的东西。

有了实际奖励之后，下一步就是把已经讲清楚的内容整理好，让后面来的人更容易独立完成。否则每来一个人都从头教，自己很快就忙不过来了。

粉丝数当然会影响有多少人看到你，但从“看到”到“完成”，还有很长一段可以做。
