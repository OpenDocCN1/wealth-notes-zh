写浅一点生活化一点就没事。

+   1. **黄金/投资类**：一般不会强制要求资质认证，可以正常写。
+   2. **洗稿投诉**：收到洗稿通知就删文不要硬刚，删了就基本就没事了不会进一步处罚整号。
+   3. **大量截图内容**：整篇评论截图文章截图，被判整合垃圾内容直接降权。
+   4. **删文重发**：把高流量文章删掉重发，系统会检测出来反而不会再给流量。
+   5. **跨平台引流**：图片带其他平台水印正文留联系方式都有风险，等账号稳定后再谨慎操作。
