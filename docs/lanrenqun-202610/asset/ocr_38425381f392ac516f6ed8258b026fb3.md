# 第二就是进阶商品：原味。

单纯看照片，粉丝们很快就会疲劳，为了解决这个问题，福利姬很快推出“买原味送图包”的业务。

什么是“原味”？就是女孩在拍摄过程中穿过的丝袜、贴身内衣、制服等等。

有时候，一条成本两块钱的普通丝袜，只要备注“本人穿过三天、没洗过”，转手就能卖几百块。

当然，由于交易过程不透明，这个环节往往假货泛滥。

一些福利姬会在杯子中加入 150mL 去离子水，再加入 1 克氯化钠和 0.2 克尿素，搅拌至完全溶解，然后再加入 0.2 克乳酸，密封发酵 24 小时后，装入喷壶喷洒在新丝袜上，就可以完美还原出被穿过的味道。
