# 二、把五六万元粗报价拆成 17 项正式索赔清单

现场处理以后，接下来要解决的就是修复问题。当时找熟人装修队粗略看过+打过价，房子要恢复下来，大概需要五六万元。

![](bbox=[0.07, 0.24, 0.92, 0.38])

粗略报价截图

根据我做过的超过 400 场的宴会项目的经验告诉我，不能真拿这张草稿纸去跟物业和保险谈，肯定不能只说一句：“修房子大概要 6 万。”对方只要问一句“这 6 万是怎么算出来的”，后面就很难继续。

如果一场宴会最后总价就算 是 5 万元，肯定不会只写：“宴会：50,000 元。”正常都会继续往下拆分为多个小项：

+   菜品多少钱，
+   桌椅多少钱，
+   灯光多少钱，
+   布置多少钱，
+   人工多少钱。

最后这些项目加起来，才是总价。
