这不是让你自欺欺人，而是提醒你：在“发生了什么”和“我怎么感受”之间，永远隔着一个你自己讲的故事，而这个故事，是可以被你重新改写的。

换一个更有建设性的故事，你就换了一种活法。

# 20.知道不等于做到：认知和行动之间，隔着一条巨大的鸿沟。

这可能是整张地图里，最朴素的一条。道理我们都懂：要早睡、要锻炼、要长期主义、要管住嘴。可懂了这么多，生活还是老样子。因为知道只发生在大脑里，几乎不费什么力。

而做到，要对抗惰性、要重复、要熬过不适，代价大得多。绝大多数改变之所以失败，不是因为不懂道理，而是低估了把道理变成习惯要付出的代价。

# 为什么懂规则的人，正在收割不懂的人？

知道一句话，和真正理解一条规则，是两件完全不同的事。

为什么有那么多看似精明的人，会一头扎进各种“稳赚不赔”的局里？

为什么七天暴富、轻松躺赢的话术，总能收割一茬又一茬的人？不是因为这些人笨。恰恰相反，他们中很多人智商很高、学历很好。真正的原因在于，他们违背了地图里的第7条：没有免费的午餐。
