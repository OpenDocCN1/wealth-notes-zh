# 第一张观察表，先记这些

让每一个字段，服务于一个判断。

**商品 / 店铺 / 规格**
一直比较的是不是同一个对象

**目标人群 / 使用场景**
谁在什么时候，需要它

**标签 / 标签采集时间**
看到的是历史信号还是新观察

**展示销量 / 实际采集时间**
是否持续变化，有无缺失或异常

**交付 / 评价里的问题**
还要核实哪些改进空间

**自己的差异 / 小样计划**
是否值得亲手验证一次

**连续 8 天有效端点 → 7 个日间隔**
**比较前后两周 → 需要 15 天端点**
异常留空、解释原因；不要用零代替。

固定每日样本规则，并保留实际采集时间。
不足够的历史，只报告已观察到的部分。

把同一个商品连续观察下去的记录字段表里除了数据，留两列自己的判断：“为什么值得继续看”和“下一步查什么”。例如，课堂游戏增长了，下一步可以看演示是否方便教师直接上手；设计素材仍在增长但速度回落，下一步可以检查风格和内容更新节奏。

一周结束时，让名单产生变化：留下理解更清楚的商品，继续观察数据还不完整的商品，把暂时无法交付的方向放后面。这样，每次打开选品库，都有一个具体问题要解决。
