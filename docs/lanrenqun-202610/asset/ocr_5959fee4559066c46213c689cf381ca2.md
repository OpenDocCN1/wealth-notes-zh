> 你在推特上遇到的不是流量，是能付钱的人。

# 理由二：推特的变现路径，比你想的多

我数一下我自己或者圈友跑通过的路子：

+   a. **卖服务、卖产品、卖代理。** 这是来钱最快的一条。你在生财学到的任何一门手艺，搬到推特上都有人买单——这里的人本来就习惯花钱解决问题，你不用花大半篇内容去教育他"为什么要付费"。
+   b. **做付费社群。** 这条的价值在复利。推特适合立人设，能让一批人长期看着你。看三个月、看半年，你再开个社群，进来的人都是被你的内容养熟的，比冷流量好谈太多。
+   c. **接海外客户、做出海。** 这条是国内平台给不了你的。推特是英文世界和华人世界的交叉口，想接海外单、想知道外面在流行什么、想做出海生意，这里最顺。信息差本身就是钱。
+   d. **平台自己的分成。** 这条属于顺带，不用为它单独设计内容，做了就有，相当于平台给你发的那份底薪。
