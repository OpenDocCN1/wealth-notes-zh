目前法国的公共支出到了可怕的程度，高达 57.2% 的 GDP 扔进了“公共开支”，而普通底层得到的公共服务差劲到了完全不相等，稀烂的基础、失败的公共服务、恶劣的治安，就是高达 43.6% 的平均税负换来的所谓“公共产品”，等于花着全球最贵的钱、换来世界最烂的服务。一句话：钱去哪儿了？

# 3、失败的分配制度。

说法国的分配制度到了“杀鸡取卵”的程度一点都不为过，有些人只看到表面的高福利，看不到背后到底是谁来掏钱，没人掏钱哪儿来的福利？

这是个简单到了极致的道理。失败的分配制度导致社会分配极度不公，“能者多劳”代替了“多劳多得”，无限制的剥削生产力中坚导致懒人反而活得更好。

# 4、愈演愈烈的难民问题。

非法移民问题已经摆在了明面上，难免带来的社会治安崩溃当然也会引发广泛的不满，这些非法移民本身也是骚乱的一大源头。
