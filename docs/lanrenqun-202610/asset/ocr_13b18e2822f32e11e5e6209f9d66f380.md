# ✓ 第二步：责任认定（核心关键）

# 1. 常见责任方与判定标准

| 责任方 | 承担责任情形 | 法律依据 |
|---|---|---|
| 物业 | • 未按合同的定期疏通管道
• 发现堵塞未及时处理
• 管道维护不当导致破裂 | 《民法典》第 942 条：物业服务人应维护物业服务区域内的基本秩序，采取合理措施保护业主的人身、财产安全 |
| 楼上业主 | • 不当使用管道（丢弃纸巾、抹布、猫砂）
• 私改管道导致排水不畅
• 无法确定具体侵权人时，已入住业主共担责任 | 《民法典》第 1165 条：行为人因过错侵害他人民事权益...应承担侵权责任 |
| 开发商 | • 房屋在保修期内（通常 5 年）
• 管道设计/施工缺陷导致破裂 | 《建筑工程质量管理条例》第四十条：给排水管道保修期为 2 年 |
