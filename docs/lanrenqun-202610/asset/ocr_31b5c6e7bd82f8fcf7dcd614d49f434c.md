# 五、我希望和怎样的增长操盘手一起做事

从知识付费 MCN、心理 IP 全链路经营，到私域、会销和组织搭建，这几段经历构成了我现在的业务基础。接下来，我希望在杭州找到擅长短视频、直播或投放，愿意驻场协作、逐步全职负责增长的伙伴。

你不必一开始就擅长所有环节，但我希望你已经在某个流量方向有真实实践，并且愿意进一步理解产品、成交和交付。

我也很看重一个人怎样复盘自己的成绩：能说清楚自己做对了什么、借助了哪些条件、还有哪些不会。因为我自己就是这样一段段补能力过来的，也希望和愿意扎进业务、一起补齐短板的人合作。

我想一起做的事情很具体：围绕一个真实项目，把前端获得什么样的用户、后端如何承接、最终业务结果如何连起来，找到下一步值得验证的增长动作。你带来自己的增长经验，我把过去在产品、私域、会销和团队建设里的经验拿出来，一起判断哪些能用、哪些需要重做。

对已经能做流量、希望进一步承担完整业务责任的朋友，这可能是一个值得交流的方向。合作中需要明确的资源、职责和目标，也应该放在具体项目里谈清楚。

如果你做过相关项目，欢迎在评论里聊一个真实案例：你负责哪一段，做过哪个关键改动，结果怎样，后来卡在哪里。
