# 何解呢？

我给大家讲个故事，一个我儿子很小的时候，我跟他的对话。

这个故事本身，我跟读者们讲过很多遍，我跟我儿子之间，在他不同岁数，不同时期，也讲过很多遍。

我儿子很小的时候，刚上小学的时候，少年宫回来路上，就很不开心。

他很反感他的妈妈，总是拿他和别的孩子比较。

比完这门课比那门课，攀比永无止境。

他想表达的意思就是，他是他，我是我，每个人都是独一无二的，为啥要拿来比较。

这不是刺激我么？

进而，小小年纪的他，得出一个结论，是不是说，只有考得好，我才是妈妈的宝贝，考不好，就不是亲生的了？

……

我第一次听到孩子讲这番话，我没有跟他讲道理，而是给他吃了一颗定心丸。

我跟他讲，三体的伊文斯，知道吧。
