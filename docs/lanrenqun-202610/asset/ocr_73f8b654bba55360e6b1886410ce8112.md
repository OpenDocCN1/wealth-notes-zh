# ## 2.1 做内页 | 首页

做内页，就是做 TDH

+   • T，就是标题

> 网页标题。就是谷歌搜索结果里那个蓝色大字，也是浏览器标签页上显示的文字。这是谷歌判断你的页面讲什么的最重要依据——写好了，排名才能上去。
> 
> 10~30 字符，核心词放最前面，别啰嗦。

```
✔Free QR Code Generator - Create & Download
Instantly | ToolHub
✔Best Image Compressor - Reduce Size by 80%
Without Quality Loss
✘Welcome to my website
✘QR code generator online free tool (堆砌，没
卖点)
```

+   • D，就是描述

> 页面描述。搜索结果里标题下面那两行灰色小字。谷歌不一定照搬你写的，但写好了能提高用户点击的概率。
> 
> 150~160 字符，说清「你能解决什么 + 为什么选你 + 行动号召」，用户看了想点。

```
✔Generate QR codes instantly for free.
Support URL, text, WiFi, and vCard.
    Download in PNG or SVG. No sign-up
required. Try now!
✘This is a QR code generator website.
```
