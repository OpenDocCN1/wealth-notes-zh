# # 买号之前你先想清楚三件事：

+   1. **有被找回、被封的风险。** 这是最大的坑，别贪便宜。

+   2. **粉丝不精准。** 成品号上那点粉，大概率是死的、或者跟你完全不搭。别指望它给你带流量，你要的是“号本身不是白板”。

+   3. **买回来第一件事是改密码、换绑邮箱。** 做完这步，先当正常号用一周，再开始发内容。

渠道和价格我就不在这里展开了，圈里问一句就有。但我的建议是：第一个号，自己注册。你自己的号，你才心疼。

# ## 三、第二步：设置与养号

账号到手，先别急着发内容。

# ### 先把门面收拾干净

**头像。** 真人照片。别用 logo，别用网图。推特是认人的地方，一张真人脸就是最基础的信任。

**昵称。** 用你真名或者平时被叫的名字。我用的就是“阿乐”。

**ID（@后面那串）。** 能改，但只建议改一次，想清楚再定。最好是名字的拼音或者英文名，好记、好念、好被人 @。

**简介（Bio）。** 一句话说清楚：你是谁、帮谁解决什么问题。
