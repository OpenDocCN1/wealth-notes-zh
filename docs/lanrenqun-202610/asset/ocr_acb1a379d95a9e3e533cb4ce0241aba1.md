# 内容工作台（content-workbench）

把你每天说过的话、开过的会、写过的文档，变成能发的稿子：AI 只摘你自己的原话提炼选题，照你的写法起底稿，你在一个页面里看图、批注、改完，一键推公众号草稿箱、X 长文草稿、知识星球草稿箱，再一键做成小红书图文。每篇稿子在飞书里对应一个文档，原地更新留档。它还会记录下你每次怎么改 AI 的底稿，总结成你的改稿习惯，下次起稿就照着来。

所有东西都跑在你自己的电脑上，数据只存在本地的私密目录里。它只把稿子放进各平台的草稿箱，最后点发表的永远是你自己。
