+   - 检查重要提及的位置、回复范围、投票选项和视频下载设置。

+   - 检查图片 ALT、视频字幕、长文封面和手机阅读效果。

+   - 确认排期日期、时间、时区和长文受众。

# 写在最后

很多时候，阻碍我们的不是算法多复杂，而是迟迟不肯按下发送键。

如果你还没开始，就从记录自己今天解决的一个小问题、或者踩过的一个坑开始。把遇到的问题、处理过程、结果和拿不准的地方写下来——发出去，然后在实操中边看边补。
