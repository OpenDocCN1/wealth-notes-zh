# 统计数据怎么说

当然在社会学上，想要搞大样本双盲对照试验有点困难，但我们还可以看统计数据。而一看统计数据你就能知道这种故事有多么扯。

比如说美国有许多中产“拿不出 400 美元应急，一遇意外就触发斩杀线”。但事实上摩根大通研究院调查全美 590 万户家庭的真实收支数据表明：美国 92%的家庭是可以应对 400 美元的应急支出的，其中 77%的最低收入群体（年薪低于 3 万美元）也能做到。

再比如他说“美国流浪汉平均只能活四年，然后冻死、饿死、病死”。
