# 跟进记录草案

这样，下一次我就是不对着空白页面再让 AI 写十个标题。

我可以从这条视频、原来的产品资料和新的用户提问出发，继续做一个更具体的选题，比如“如果你已经在发内容，也有人来咨询，第一步该先检查哪一段？”

如果有人带着自己的业务来问，同一组资料也能帮助我先澄清问题，再决定是否进入咨询。不能因为他留了一条评论，就把他算成客户或成交。

所以工作台带来的提效，并不是按一下按钮，多出十篇稿。它减少的是每一轮重新找资料、重新解释产品、重新回想上次为什么这样选题的成本。一条内容做完，事实、选题理由、定稿边界和用户追问都留下；下一条内容从这里接着做。这3张图片，是我自己用我的AI工作台拿到的一些结果，9月份的服务周期内，大概是收入六位数左右的利润，其他的我就不过多展示了，对比其他AI大佬来说，还需要继续努力。所以放出来，是想要跟大家说一下，在当下服务AI工作台，尤其是细分赛道的，还是有一定的前景可言的。
