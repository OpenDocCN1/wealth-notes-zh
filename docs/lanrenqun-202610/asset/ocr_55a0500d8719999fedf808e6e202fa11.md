让你更成功，恰恰相反，它们的作用是提醒你：哪怕这件事全部失去，你，依然还在。

# 把这一切压成四条原则

五个结构讲完了，我想总结一下。四条建议，它们比具体方法更耐用，因为无论你换到哪个领域，它们都成立。

# 原则一：区分“要更用力”和“要换打法”。

这是全文的总纲。当你感到停滞时，第一反应不应该是更努力，而应该是“我这套打法是不是过期了”。那套让你走到前 10% 的方法，是把你送到这里的主要原因，但它一定不是把你送到前 1% 的那一套。

# 原则二：优先改回路，而不是改行为。

行为是“我今天多练两小时”，而回路是“我练完之后，谁会给我真实的反馈”。改一次回路的效果，胜过改一百次行为。因为回路会自动、持续地改造你的行为，而行为改不了回路。可怕的是，绝大多数人一生都在改行为。

# 原则三：一切拉不开差距的努力，都发生在看得见的层面。

标题、话术、格式、模板，这些是表层，它们能被模仿，所以也就不构成差距。而判断、取舍、时机、为什么这里要这样处理，这些是底层，它们必须靠表征去看见，也只能靠反馈去校准。只在表层用功的人，会越来越快；而在底层用功的人，会越来越好。
