# 配合低价的 5 种惯常配套手段

为了让这个低价看起来“合理”、让你妥协，对方一定会配套一系列操作，你之前遇到的全部命中：

+   1. **拖延术**：不回复、慢回复、“走流程”“上报审批”，用时间消耗你的耐心，让你觉得“为这点钱折腾不值”；
+   2. **踢皮球**：物业推保险，保险推公估，公估推物业，永远找不到能拍板的人，抬高你的沟通成本；
+   3. **专业话术包装**：张口就是“保险理赔规则”“公估行业标准”“折旧规定”，用你听不懂的术语营造权威感，让你觉得“本来就是这样”；
+   4. **冷处理**：群里装死、电话不接，摆出“就只能出这么多，你爱要不要”的姿态，逼你主动降价；
+   5. **共识暗示**：暗示“别的业主都是这个价赔的”“打官司也拿不到更多”，用虚假的共识让你怀疑自己的主张。
