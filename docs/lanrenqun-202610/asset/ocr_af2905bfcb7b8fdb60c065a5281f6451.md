打工时期那种"今天太累了，买点好的犒劳自己"的心理，到这里并没有消失，只是换了件衣服：

+   - 看到新款雪服好看，明知道旧的没坏，还是下单了；
+   - 为了颜值换了双新雪鞋，结果新鞋磨脚，忍痛穿不了，还得再花钱换回去，一笔支出变成了两笔；
+   - 每天一杯 20 块的奶茶，加上频繁的社交吃饭，"几百块钱算什么"。

当时我总能给自己找到理由：雪季这么累，对自己好一点很正常。

真正的暴击永远发生在淡季。雪季结束，订单清零，连着几个月没有进项。看着卡里的钱一点点变少，我甚至看不上"一天三五百一天不差"的小单了——胃口被旺季养大了，面对淡季那些小业务时反而提不起劲、动作变形。

那个雪季算总账，我赫然发现：我明明赚了比以前多得多的钱，但留下来的结余，远低于预期。也是在一次次这样的淡季里，我彻底钉死了一个判断：

"对自己好一点"这句话没错，但要能分清是真的帮自己成长，还是满足消费欲望的陷阱。旺季那笔钱，不是全给你花在当下的，其中一大部份，是你借给淡季那个零收入的自己的。
