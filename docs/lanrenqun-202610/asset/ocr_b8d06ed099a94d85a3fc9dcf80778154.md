只不过在团省委时代，她做的是另一种资源整合。

比如农村青年创业。

2014年，团贵州省委和省科技厅联合培养“青年科技特派员”；又联合省委组织部、省人社厅、省农委等7个部门，共同推进农村青年创业致富。

金融怎么解决？

团省委找到邮储银行贵州省分行，专门设计了一款叫“邮青时贷”的金融产品。

+   - 联保贷款。
+   - 抵押贷款。
+   - 信用贷款。

青年创业园区、创业带头人、创业基地都可以进入支持范围。

仅2014年，就已经给上百名创业青年发放贷款。涂姗当时公开讲得很直接：团组织自身资源有限，必须协调其他部门，把市场、智力和金融资源一起调进来。

到了2016年，团贵州省委又开始做“黔青梦工厂”创业孵化器，推动农村电商、大数据创业和互联网青年项目。涂姗在团省委全委会上强调“互联网+共青团”，要求把青年创业平台做起来。

另一条资源线，是贵州最有分量的国有企业。
