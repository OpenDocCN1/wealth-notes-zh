# Tool

在最开始做的教辅工具是聚合类,比如资料类的一些分割、拼接、作图、排版、仿实拍等等，这些功能在教辅资料生成中多多少少都会用到

文档分割、文档图片拼接、作图，甚至资料文档内容的排版，以及整个的仿实拍等

![](bbox=[0.06, 0.26, 0.935, 0.46])

特别是原创和排版这两个需求，仍然是做教辅所需的

当时这个软件涉及的功能点，第一个功能：AI 试卷克隆，第二个功能：教辅 AI 生成，第三个功能：AI 手绘，第四个功能：文档批量分割，第五个功能：模板贴图，第六个功能：AI 排版

面向教辅的系列的工作台，为什么舍弃了如此多的功能，明明是有需求的点，通过那一段时间的市场上的使用以及反馈，决定只保留了 AI 作图功能，并且把这个点做完善

简单讲一下每个功能解决的问题，以及舍弃的原因

# 1.1 AI 试卷克隆功能
