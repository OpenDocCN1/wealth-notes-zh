# 第 2 题：谁承担实际记账和报税的法定义务？

+   A. 已有代理记账许可证，并有合资格的负责人/会计。\nB. 目前没有许可证，先做内部辅助工具，实际记账、申报和最终核签由持证机构或合资格会计承担（推荐）。\nC. 目前没有许可证，但准备直接以自己的名义承担记账报税。
