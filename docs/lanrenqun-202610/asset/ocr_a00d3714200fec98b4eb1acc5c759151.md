容缺口逐渐补全，各赛道开始被内容填满，而渐渐的回归平稳，最终单价也会回归到正常的数值，推荐的数据也会慢慢回温。

这样的话，这个赛道留给我们的空间和机会也就不了，那这又能够给我们什么样的启发？

贴图还能做吗？如果不能的话，我们未来的路径和变化是什么？

# 七、武汉沙龙复盘，我希望大家先把第一条贴图发出去

前阵子七天教练喊我去武汉做一场项目沙龙。

主题是贴图从 0 到 1。我们辨得很细：为什么选这个项目，怎么找一个适合自己的方向，素材去哪儿搜，一张图加一个想法怎么变成一条内容，最后发到哪里、后台怎么看。

设计分享的时候，我们特意把"赛道选择"这件事往前挪了挪。

先不讲道理，先放三个案例：中年实拍、水果、奇葩动物。让大家先看见一条作品长什么样，再回过头来聊——他们的爆款理由、情绪痛点、选题原因到底是什么？

中年实拍，看的是生活里一个很小的动作，能不能勾起别人相似的那段记忆；水果呢，画面里得有地域、有季节、有生活味儿，不然就是一张图；奇葩动物更直接，第一眼就得有一个让人想多看两秒的真实特征。
