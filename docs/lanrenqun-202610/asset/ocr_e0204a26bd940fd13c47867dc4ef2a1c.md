# 我的核算单元：把"一个月"当成"一单"来算

我用的是一个更原始的口径——**我的核算单元，就是每个月的每一单**。一单一行，记清楚：这单收了多少、雪票花了多少、路费住宿花了多少，最后落到这单的净利润。这样月底一拉，我这个月有几单、总收入多少、总成本多少、净利润多少，一目了然。

**为什么要细到"一单"这一层？**因为只有细到这一层，你才知道哪一单在赚钱、哪一单在赔时间。汇总数字是结果，单笔才是原因。
