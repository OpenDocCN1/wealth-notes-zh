来的大回报（即时满足）。

这些偏差不是 bug，而是进化留下的默认设置。在那个要随时逃命的远古，省力模式很有用，可放到今天，却常常把我们带沟里。

也就是说，你的很多直觉判断，其实是几万年前的大脑在替你做决定。知道它们存在，并在关键时刻多想一秒、刻意反着来，就是一种清醒。

# 18.注意力即命运：你长期关注什么，就会慢慢成为什么。

注意力是你最宝贵、却最容易被偷走的资源。你刷什么、看什么、想什么，日积月累，就塑造了你是一个什么样的人。

这也是为什么，这个时代有那么多产品，挖空心思要抢夺你的注意力。因为它们很清楚，控制了一个人的注意力，就等于控制了他人生。

所以请像守护财产一样守护你的注意力。少喂给它廉价的刺激，多喂给它真正重要的东西。因为你的注意力流向哪里，你的人生，最终就长向哪里。

# 19.叙事支配感受：决定你情绪的，往往不是事情本身，而是你给它讲的故事。

同样是被裁员，一个人讲的故事是“我被抛弃了，我很失败”，另一个人讲的故事是“这是逼我换条路走的契机”。

事情完全一样，体验却天差地别。很多时候，让我们崩溃的不是事件，而是我们对事件的解释。
