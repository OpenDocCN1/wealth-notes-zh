# 迅速进入提拔快车道？

看懂了领导用人思路、摸清了领导心理、研判清了自身形势，最后就要落地实操，遵循单位职场晋升规律，调整自身做事方式、思维模式、处世格局，稳步获得领导赏识，跨身晋升快车道，不用再熬资历、耗青春。结合多年职场实操经验，总结出五条普通人可直接落地执行的核心方法。

# 一是业务能力守住 70-80 分即可，不必追求极致完美。

很多年轻人陷入一种思维误区，就是以为想要晋升，就必须把业务做到极致，争当系统内标杆、行业内专家，花费大量时间深耕专业、钻研业务，天天加班啃硬骨头，把所有精力都耗在业务长板上。

其实这是最大的职场误区。单位职场晋升，业务能力只是基础门槛，不是核心竞争力。对于普通人来说，业务能力做到本单位中上游、70 到 80 分就完全足够，能够胜任本职工作、独当一面、不出差错、能扛任务，在本单位同龄人中处于靠前水平，就已经满足晋升的业务要求。

完全没必要耗费巨大精力追求全市、全省顶尖级别，把自己练成纯业务型干部。人的时间和精力是有限的，你把全部心思都用来打磨业务长板，就没有多余时间去修炼情商、学习沟通、维系人脉之类更重要的事情了。
