
- 1. 让 Codex 只拆用户、冲突、点击理由和评论区高频顾虑，先不写正文。
- 2. 从“怕伤亲情”“怕未来看病缺钱”“不知道应该留多少”里，由我选定这篇只讲的一个问题。
- 3. 补上能支撑它的人物、生活场景、资金安排方式和需要核实的信息。素材不够就停。
- 4. 让 Codex 先交写作说明和 3—5 个标题，我确认读者、角度和判断。
- 5. 生成初稿后，检查标题是否被前 150 字接住，每个判断后面有没有具体素材，结尾有没有可执行动作。
- 6. 发布后在 24 小时和 7 天回看数据，将有效的标题词、评论表达、失败原因和修正办法写回样本库。

我现在会反复检查的最小结构：场景—冲突—判断—提醒

## 再分享一下我最常遇到的卡点，以及对应处理方式

| 具体卡点 | 我会怎么处理 |
|---|---|
| 选题很大，但不知道在帮谁 | 先用一句话写清“哪类人 + 正在经历什么 + 这篇要帮他解决什么”，写不出来就不开稿。 |
| AI 开始自己补故事 | 立即停止生成，要求只列素材缺口。没有人物、场景或证据，就回去收集，不让它继续圆。 |
| 标题很猛，正文接不住 | 单独取出标题和前 150 字检查。标题提到的人群、冲突和利益，开头必须至少出现一项。 |
| 文章很顺，但一眼像 AI | 删除对仗排比、万能转折和每段最后的总结句；补人物的动作、犹豫、细小顾虑和不那么完整的真实表达。 |
| 看起来像年轻人教老人生活 | 删除“退休、养老、晚年”后再看，剩下的金钱、身体、夫妻和子女顾虑还像不像五六十岁的人。 |
| 政策、医疗或金额无法确认 | 标记待核实，再找官方来源。确实查不到就删，不用“大概、可能”把事实风险糊过去。 |
| 数据不好，不知道改哪里 | 按“推荐→点击→阅读→互动→赞赏”逐层排查，一次只改一两个变量，不要一篇数据不好就换赛道。 |

这套流程的核心不是“让 AI 自己写”，而是把每个容易出错的地方提前设成一道关口：

选题判断 → 样本拆解 → 补齐素材 → 读取人设 → 输出写作说明 → 人工确认 → 生成初稿 → 事实与表达质检 → 发布 → 用数据调整下一轮。

Codex 带来的改变，是让我更清楚地看见：什么可以固定执行，什么必须由创作者自己做决定。它能减少我对着空白文档发呆的时间，能在正文出来前提醒我哪里没有素材，也能记住上一轮试错得到的规则。但它不能替我承担对用户、事实和最终发布的责任。

### 六、老年赛道还能不能做？我现在的答案

我的答案依然是：能做。

但如果还是想靠一批情话模板、一个假通知样式、一套一键生成的文章去长期做，我越来越不看好。因为 AI 让内容供给变得更便宜以后，套话也变得更便宜了。以前一篇结构完整的文章可能就能和别人拉开差距，现在它只是最基本的入场券。

真正会留下来的，是那些愿意把人看具体、把问题写清楚、把自己的判断放进内容里的账号。工具可以让这件事做得更快、更稳，但它无法替代创作者对一群人的长期关心。

我也是在生财里慢慢把这件事想清楚的。2024年，我通过辰风老师建立的交流群开始了解生财。当时我已经做了一段时间自媒体，但大部分时候都在单打独斗。数据不好时，很难判断是赛道、选题、标题还是正文出了问题。

那时候 3000 多元会费对还在上大学的我来说，不是一个可以随手做出的决定。我先在群里学习，也帮辰风老师做过生财拉新。后来用群里学到的信息赚到了一部分钱，有了预算，才正式加入。

参加航海、航海家大会和线下交流以后，我不再看到别人做什么就马上照抄。我会先看项目里的用户需求是不是持续存在，

我给自己留了几条底线：不通过虚假通知和误导性设计骗点击；不利用疾病、衰老和亲情制造过度恐惧；不为了数据故意制造对立，不因为用户信任，就推荐自己不认可的东西。

最后我还会问自己一句：**如果把这篇文章给自己的父母看，他们会觉得被尊重、被帮助，还是被恐吓、被利用？**只要答案偏向后者，这篇内容我就不会发。

一个年轻人不会因为会用 AI，就突然懂了老年人。他只能先放下自己的想象，对一群人的真实生活保持好奇，去听、去看、去测试、去修正。等这些判断已经在人的脑中建立，工具才有可能把它们放大。

这是我从老年情感走到老年感悟，再到用 Codex 稳定内容流程后，现在最真实的体会。

它不是标准答案，但都是我实际写过、走错过、调整过，也从数据和读者反馈里一次次验证过的东西。

我是都一妮。
