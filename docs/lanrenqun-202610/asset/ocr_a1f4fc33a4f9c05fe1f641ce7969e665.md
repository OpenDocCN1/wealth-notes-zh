# 1. 企业 AI 落地的六个阶段

为什么今年能听到企业 AI 服务 和 FDE 的声音越来越响，他是一个新出现的产物吗？肯定不是，之前的 n8n、AI 工作流、企业培训 这些需求早就存在了，也有非常多的圈友拿到了很好的结果。

真正让这件事情更广泛的让我们知道的核心原因还是，AI 越来越强，从个人提效到组织提效的案例越来越多。
