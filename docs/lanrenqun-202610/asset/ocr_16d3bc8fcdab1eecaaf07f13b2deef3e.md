# 2.复利：微小但能持续的优势，会在时间里指数放大。

我反复讲过复利这个概念，我想关注缸中之脑的大多数读者已经耳濡目染。

但它的反方面同样成立，而且更可怕：一个微小的坏习惯，也会经过复利，变成一场灾难。每天进步 1%，一年后是原来的 37 倍；每天退步 1%，一年后只剩下 0.03。

差距就藏在这两个看起来差不多的小数里。真正决定结果的，往往不是强度，而是方向×时间。方向错了，越使劲亏得越多。方向对了，哪怕慢，时间也会替你把它撑大。

# 3.临界点：世界不是匀速前进的，质变往往发生在最后一刻。

水加热到 99 度，看上去和凉水是没什么两样的，因为它就是不沸腾。直到 100 度，才会一下子轰然汽化。

人生里大部分有价值的事，回报曲线也都长这样：先平后陡。前面很长一段时间，你付出了，几乎看不到任何动静。于是，绝大多数人，恰恰是在那个即将到来的临界点之前，因为看不到什么希望，就放弃了。

他们不是输给了困难，而是输给了那段必须熬过去的、毫无反馈的平台期。
