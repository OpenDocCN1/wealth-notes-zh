# e.跟着平台往深处走

9月20日开放日，一位做贴图号工具和培训的圈友问我：下一步是继续教小白做项目，还是去服务企业老板？

我说往B端去做，往结果交付去做，「我觉得这是大钱」。

小白现在能拿到钱，是因为平台正处在流量释放期，「这是唯一的一个原因」。

「平台到了 一定阶段之后，它必然要深入，你要跟着它一起去深入」：要投钱，要投供应链，要组团队，要做专业内容，要投流，这些个人很难跟上。

跟着企业、跟着有资源的人一起走，就是和平台一起把这件事做深。

起步的时候先做C端、把势能和品牌建起来，没问题，「过渡性的做toC是OK的」；有机会、有能力，再往B端走。
