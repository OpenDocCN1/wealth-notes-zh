# # 不要浪费钱

这一节只算钱：能省下多少，每年收益差多少，一笔钱长期平均下来能拿回多少。这些不换算成寿命或时间。涉及投资的条目只讲怎么算账，只用核实过的历史数据，都不构成投资建议。

# ### 把清单放到手机桌面

像 App 一样一点就开，打勾、看进度、做每日任务都更顺手。

点 Safari 的分享按钮（方框加向上箭头，新版 iOS 在 … 菜单里），再选「添加到主屏幕」。
