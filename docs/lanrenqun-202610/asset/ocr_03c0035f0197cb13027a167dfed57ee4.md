# 国内商业网页游戏（页游，传奇/神仙道这类大型 MMO/SLG 页游）

# 爆发起点：2007-2008年

2007《部落战争》国服进入国内；2008《热血三国》爆火，联运模式跑通，正式开启页游大时代；同年开心网《开心农场》社交页游全民出圈。

# 巅峰期：2010～2015年

+   - 2011《神仙道》，2015《传奇霸业》（林子聪广告，“是兄弟就来砍我”），**2015年市场收入达到历史峰值219亿**。

# 开始下滑：2016年起

手游全面崛起，玩家大量转移；Flash技术隐患、买量成本飙升、传奇IP版权纠纷，收入逐年萎缩。**2018年后，页游不再是主流大盘，市场规模大幅缩水。**

> > 页游并没有彻底“死掉”，少量传奇类页游至今还在运营，但已经不是大众主流产品。
