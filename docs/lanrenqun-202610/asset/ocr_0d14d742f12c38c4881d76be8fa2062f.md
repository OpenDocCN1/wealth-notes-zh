但现在回头看，这恰恰是我最容易陷入的技术自嗨。

其实类似的亏，我之前就狠狠栽过。今年给美业客户做获客系统，我也曾以为自己搭的 Agent 架构和自动化脚本有多厉害。但客户根本不在乎代码结构写得多漂亮，他们真正在乎的只有两件事：每天能不能稳定推过来几十条精准潜客线索？销售手里的破冰话术能不能把人聊进私域？直到我彻底放下对工具的执念，去帮他们死磕业务细节，解决了一线销售的真实卡点，那笔单子才顺畅结清。

可一到了贴图号，我老毛病又犯了：以为只要把脚本跑顺、一键生成几十篇图文，就等于把事情做成了。说白了，我只是下意识地想逃回自己熟悉的技术舒适区，用写代码的勤奋，去掩盖自己对内容和读者的偷懒。

现实很快就让我付出了代价。
