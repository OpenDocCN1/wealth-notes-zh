买下“勋爵”头衔后，邓丕兵彻底完成了身份洗白。他不再是一个搞灰产的 IT 男，而是可以堂而皇之拜会柬埔寨高层（包括前首相洪森）的“爱国华商”。

有了这些特权，邓丕兵开始接手真正的“大项目”。

2017 年，他成立正恒集团，拿下了国公省七星海特区一块 200 公顷（含 1.9 公里海岸线）的黄金地皮。

这个七星海特区大有来头，一级开发商是中国的天津优联集团（UDG），这里本是“一带一路”的重点工程，承载着建设国际机场、深水港口的大项目。

邓丕兵极其鸡贼地借用了“一带一路”的国家级光环，将自己的“七星海·长湾”项目包装成集五星级酒店、免税店、游艇码头于一体的“世界级滨海文旅度假区”。

为了装得更像，他甚至雇佣了中国中铁等大型国企来承建部分工程。

但房子盖好后，他根本没打算搞旅游业。

赚惯了快钱的邓丕兵哪受得了这种回报率又低、投资周期又长的项目。
