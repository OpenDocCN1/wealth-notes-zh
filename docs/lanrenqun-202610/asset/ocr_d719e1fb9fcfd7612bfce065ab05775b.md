# 4、残羹剩饭与第二顿

前几天我还重复提醒过：野兽在吃完猎物后，会故意留一点残羹剩饭，吸引一些愚蠢的小动物过去，等小动物集中起来，那些野兽又会过来吃第二顿。看着吧，我就算这样反复提醒，照样会有不长脑子的接着往上赶。

# 5、嚼干净的甘蔗不会再甜

不要指望一根已经被嚼干净的甘蔗，时间久了放在那里，会重新自己恢复甜味，它只会发酸发酵。就是聪明的投机者，也是承认这次选错了甘蔗，检讨一下自己的错误，然后过段时间等新的甘蔗来了后，尽早去啃新的甘蔗。

# 6、机会像潮汐，保护本金等复利

永远不要怕没机会，尤其不要听有些人说"这个机会错了就再也没有了"这种鬼话。机会就像潮汐，起起伏伏，涨涨退退，三四年都会有一次大机会出现的。只要你保护好自己的本金，能让本金持续通过红利龙头产生复利，你就永远能有机会。
