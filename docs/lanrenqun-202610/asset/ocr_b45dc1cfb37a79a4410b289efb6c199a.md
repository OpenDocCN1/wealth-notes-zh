# 操作时看清四处：

+   1. 格式选图片。这里不选“输出为 PDF”。
+   1. 保留水印。没有会员，就用当前版本可用的默认水印。
+   1. 尺寸选“普通”。这一步先给客户确认风格、排版。
+   1. 只导出样稿页。通常 3～5 页；按我演示的版本，一次最多输出 25 页，超出就分批。

导出的文件夹可以直接命名为“样稿_水印确认版”，自己也不容易拿错。
