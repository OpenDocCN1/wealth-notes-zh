按这个标准过滤一遍，你会发现，人这一生中真正能称得上可以改变命运的机会，其实少得惊人。

它们会有这么几个共同特点：

+   - 它不是你能主动创造的，而是某一个时刻被递到你面前；
+   - 你做和不做，都是一种选择，拒绝也是选择，沉默也是选择；
+   - 一旦选了，就回不去了。

它会像一把刀一样，把你人生切成之前和之后；我开头说，很多人觉得自己这一辈子都没什么机会，不是没有，是没认出来。心理学上有一个经典实验。

1990年代，英国心理学家 Richard Wiseman 做过一个长达十年的实验。他追踪了上千个自认为幸运和不幸的人，想弄清楚，这两类人，到底有什么区别。他发现了一件很让人意外的事，那些自认为幸运的人，不是真的运气更好，而是他们更善于识别身边出现的机会，并且愿意去做出反应。

而那些自认为不幸的人，机会其实同样从他们身边经过，他们要么没看见，要么看见了，但选择不动。

所以，机会的真相就是：它不是从天而降的礼物，而是一个伪装成日常的考题。答得对，命运就翻一页，答错了或者不答，它就静静走了，再也不会回来。
