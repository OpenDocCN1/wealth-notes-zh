# 5.独门方法论与实战小技巧

# 小技巧1：“爆款必须反复爆”定律（反常识认知）

“爆款的内容，一定是反复可以成为爆款的！很多人觉得‘这个内容好多人都写过了，我是不是就不能写了？’——错！大家都在写的内容，你一定要挤进去写！甚至半年、一年前别人爆过的内容，换个切口、换一套图片，拿出来依然是大爆款！因为微信推荐池极其庞大，每天都有大量新读者进池，永远不要害怕同质选题，撞车证明它是真爆款母体。”

# 小技巧2：3~5篇爆文“观点拼装术”（从搬运到原创的捷径）

“不需要你凭空憋出一篇大作。最简单的方法：同个话题找3~4篇同行爆款文章。比如写《年轻人为什么断亲？》：

+   - 从第1篇提取观点：老年人与年轻人两代人的代际观念冲突；
+   - 从第2篇提取观点：现代城市生活与工作压力导致的精力枯竭；
+   - 从第3篇提取观点：年轻一代对无效亲戚人情绑架的精神断奶。把这3个分论点拎出来，用你自己的口语大白话，结合你身边的一个真实例子串联起来。这就是一篇血统纯正、结构扎实的原创爆款！
