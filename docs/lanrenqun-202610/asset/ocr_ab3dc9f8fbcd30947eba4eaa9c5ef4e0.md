确可承受的测试投入和复盘节点，比投出去以后每天焦虑更有用。

# 五、开始投放前把生意的账算清楚

# 把平台数据和销售数据接起来

一旦开始持续付费，我就会要求团队每天更新数据。除了广告消耗和点击表现，还要记录进线、开口、留资、实际加微，以及后面的成交。

在我们这些项目的常用统计口径里，进线是用户进入咨询页面，开口是产生进一步互动，留资是完成相应的联系方式动作。具体指标定义要以账户后台为准；平台留资之后，是否实际加上微信、是否有真实需求，还要通过私域记录核对。

如果业务需要到店、预约或试听，就把这些环节也加进去。这样你才能知道，用户到底在哪一步流失了。

流量端和销售端还要对“有效客资”有同一套定义。例如，需求是否属于服务范围，地域是否能承接，联系方式是否有效。否则前端说来了很多客户，销售说一个都不好，最后只能互相讲感觉。

# 至少算清楚三层成本

平台留资成本，等于广告消耗除以平台留资数。它能帮助判断投放表现，但只是链路中的一个位置。

有效客资成本，等于广告消耗除以确认有效的客资数。它更接近销售真正能够跟进的人群。
