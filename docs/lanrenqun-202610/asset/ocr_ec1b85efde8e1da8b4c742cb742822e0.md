# 步骤 3：先让 AI 推荐成熟方案，别急着买服务器

不用一上来就租一台大服务器。先让 AI 把方案讲清楚：

> 我现在需要增加【具体的云端能力】。
> 先不要购买或部署。
> 
> 请根据目标地区、预计有多少人用、数据类型和预算，推荐一套成熟方案。
> 说明数据库保存哪些字段，哪些人能读取和修改。
> 说明本地版如何迁移，以及迁移失败怎样恢复。
> 列出开发环境与正式环境的区别、费用项目和退出方案。
> API 密钥只能留在合适的服务端环境，不能写进手机应用。
> 信息不够时先问我，不要替我开通服务。
