# ## 附录 A 卡住时查哪个工具

不用第一天就把这些工具装齐。先判断自己卡在哪一步，再拿能回答这个问题的工具。工具最后要帮你找到一个事实，而不是多一份看起来很忙的日志。

# ### A.1 一张总表

| 你卡住的地方 | 先用什么 | 要拿到什么结果 |
| --- | --- | --- |
| 需求越聊越多 | 一页需求单、产品逻辑图 | 这一轮只改什么、什么算完成 |
| AI 总写错某个库的用法 | Context7 或该库当前官方文档 | 你这个版本的准确用法 |

| 改完代码旧功能坏了 | 类型检查、代码检查、自动测试 | 哪条测试失败、真实报错是什么 |
