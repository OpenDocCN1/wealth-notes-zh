己平时就喜欢用这种桌面工具。

它负责采集。

我自己常用的采集方式其实就几个：

+   - 通过关键词搜索商品；
+   - 通过店铺名称或者账号 ID 进店；
+   - 整店采集商品；
+   - 只采有销量的商品；
+   - 只采最近上新的商品。

再配合最低销量、价格区间、每个关键词采集多少店铺、单店采集多少商品这些条件，基本已经够我用了。
