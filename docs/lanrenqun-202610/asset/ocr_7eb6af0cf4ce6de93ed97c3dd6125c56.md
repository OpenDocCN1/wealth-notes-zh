而是样品。」

今年3月，超级标16讲企业AI学习与服务，我写过：「一个行业，至少有一家专属的垂直的AI咨询服务公司。」

不到一年，样品长成了工作台。那家垂直的AI服务公司，很多时候就是一个懂行的圈友，加一个工作台。

补充几个具体的观察和判断：

# 1. 每个岗位，都在长出自己的工作台。

在生财站内搜「工作台」，标题或正文里有这个词的帖子，今年5月只有7条左右，8月有51条左右，9月也有46条左右。

圈友已经在卖的，数字都来自他们自己的复盘：

+   a. 小红书运营：求索的木子的「深小白」，给个体户、小店和创作者用。6月底开卖，7月成交100多单
+   b. 电商出图：晓海云创的主图详情网站，上传产品图就能出图。上线四个半月变现10万多，今年6月收款4.4万
+   c. AI视频：嘟嘟MD的Storybound，从一段文案到剪映草稿，七步自动跑完。公测前就有73个付费用户
+   d. 出海选品：秀才的「哥伦布」，从14万多个AI产品里，筛出值得做的。8月开始收费，第7天日入千刀，之后日常在200到500美元一天
