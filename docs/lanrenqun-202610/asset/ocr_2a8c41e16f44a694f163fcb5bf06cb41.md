我感兴趣的是它的表达方式：把日常育儿里的微小动作画成连续故事，用短句串起来。下面讨论的是内容和制作方法，效果仍需自己测试。

# 1. 育儿漫画值得拆解的三个内容特点

# 1. 选题极其具体，死磕微小瞬间：

它坚决不讲那种大而无当、教人做事的宽泛育儿大道理，而是专门抓妈妈和宝宝相处中的一个微小瞬间与动作特征。 比如：

+   - 《小婴儿一天没见到妈妈会怎么样》
+   - 《宝宝身上的“婴儿感”是怎么慢慢消失的》
+   - 《小婴儿是怎么确认妈妈还在的》

这种选题切口极小，宝妈看到标题的瞬间就会本能地代入自己的孩子。
