# 比啥呢？

人的生活就是如此，自己给自己找点负担，然后再把负担给解除喽。又好比自己给自己缠上一个结，然后再把结给打开.比如说打游戏吧，说一上来就 999 级，咔嚓一下就通关，你还玩吗？

所以好的游戏设计在于度，得弄一层层关卡，然后再一关关过，人们就觉得特别有存在感。存在感的体验是为了啥？为了——成就感！

那么从游戏这个小例子跳出来，看生命和宇宙，从存在体验到成就感是啥呀？就是通过“火烧水”的过程，最终想要证悟出“大圆”呀..也就是说，所谓“修行”是個刚需，每个人都在修行，只不过自己不知道，没有拿这些破词咔咔说出来而已，没有那么强的逻辑性罢了而且呢，我们被小游戏的成就感给障碍住了，就不停地陷入小游戏当中这就是庄子说的：道隐于小成！世界观=大游戏。人生观=中游戏。价值观=小游戏佛道就是让我们认识到游戏，即所谓游戏三昧嘛，活着要有一个打游戏的心态..整体了解了虚拟和识现，然后再慢慢细抠五行八识的机制。
