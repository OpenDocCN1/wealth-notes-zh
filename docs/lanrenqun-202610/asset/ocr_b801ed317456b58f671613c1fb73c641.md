# 例，锚定内容功能属性

# 1. 对标观察：从【转发/点赞】提出问题

很多人只看点赞高不高，这是典型的新手误区。点赞和转发能提供不同线索，但不能只凭一个比例判断读者心理：

+   □ 若【转发/点赞 > 2 ~ 4 倍】（嘴替裂变属性）： 我会优先检查它是否涉及现实共情或代际关系；2~4倍只是筛选时的观察范围，不是通用阈值。读者把文章当成了自己的“嘴替发声工具”。比如中年人的夫妻矛盾、养老焦虑、子女教育。读者看完心有戚戚，自己不好意思当面说，就随手转发到家族群、夫妻群或朋友圈借题发挥。做婚姻家庭、情感共鸣赛道，必须死磕高转发率！

+   □ 若【点赞高、评论高，但转发极低】（猎奇参与属性）： 属于“强视觉反差或解题互动”。读者觉得新奇、好玩、长见识，或者在评论区显摆自己的眼力与知识（如“我知道这个叫什么”、“这是古代的卡尺”）。这类内容也可能被转发，具体仍要看读者的使用场景。做生活奇闻、古代黑科技赛道，奔着极高的评论停留与解题参与去设计！
