还有合作伙伴之间的信息交流也很重要。
做视频的、做知识库的、熟悉某个行业的，
经验不同，彼此可以分享真实使用情况，
也可以按项目需要合作。

我希望这种合作里，大家愿意把实际问题
讲出来，哪里做成了，哪里失败了，哪个
条件缺失。资源介绍和收益分配可以谈清
楚，客户资料的使用范围也要明确。共享
经验不代表把客户的原始信息随意传播，
会丢失信任。

但这些都是第二个客户之后的事情。你还
没开始时，先不必给自己设计一个很庞大
的业务版图。

# 4. 从一个场景开始，把讨论变成一次试用

最后，留给大家一个小练习。先写下这四
项：

+   - 一个自己熟悉的行业。
+   - 一项反复发生的工作。
+   - 希望改善、能够观察的结果。
+   - 愿意提供材料和配合试用的人。

去跟这个人聊最近一次具体任务。材料从
哪里来，怎么处理，哪里最费时间，什么
地方最怕出错，拿到一份经过许可的真实
样本。

聊完之后，挑一个自己有把握验证的部分，
做出来给他试。下次见面，你们就有一件
具体的东西可以继续讨论了。
