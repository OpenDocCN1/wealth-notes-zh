# 持有全天候组合的人，如何合理利用杠杆（场内融资）放大收益？ 王康提问：

持有全天候组合的人，如何合理的利用杠杆（场内融资）去放大收益。

不好意思，回答晚了。但我理解你所谓的"全天候组合"，指的是以场内为主的全天候组合，不然你如何去利用场内的融资呢。

其实对于全天候策略来说，整体是不适合上杠杆的。因为所谓的全天候通常就是股票、债券、商品和现金：

+   1. 商品和现金：是没有现金流的。
+   2. 债券：现在国内利率很低，2%都不到；

但是你的杠杆利率是多少？怎么也得 3%~4%吧（具体取决于你的资金量大小）。换言之，商品、现金和债券这三类是包不住杠杆的。本质上都是赌方向。

最后剩下的就是股票，我觉得还是能包住杠杆利率的。

所以说，你要上杠杆，那最多也就是股票或者 ETF 通过融资的方式，买入后持仓占比保持原来的占比就可以了，也算是上了杠杆。

看完这篇 SOP，你觉得你懂了。但 90% 的人一到实操就会卡在第一步。
