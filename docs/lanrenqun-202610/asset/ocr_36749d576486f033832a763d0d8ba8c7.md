# 给 Agent？

如果一件事的条件和动作都已经明确，比如按固定字段归档、提醒负责人、把审核通过的结果送到指定位置，普通规则 SKILL 就能完成。让 Agent 来做，未必更稳。

# Agent 更适合介入需要理解上下文的地方：

材料不完整时指出缺项；几个信息相互矛盾时标出依据；收到不同类型的任务时，建议它该走哪条路径；执行中遇到预设规则覆盖不了的情况，整理问题并交给负责人。

它可以准备判断，也可以在明确授权的范围内继续执行，但不能把自己的推测直接当成已确认事实。

所以分工时，我不会按“这项工作重复不重复”划线，而会看它究竟需要照规则执行、结合材料作判断，还是承担商业责任。同一段流程里，这三种工作往往同时存在。
