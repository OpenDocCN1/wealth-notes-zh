# ## 一、我们中国就是市场化形成的汇率，人民币汇率挺市场化的。

但如果有单边的、剧烈的波动，央行还是有义务下场干预的，这种道理你们洋人应该懂，不然你们前几个月，美日不就在联合干预日元汇率嘛。

你们08年金融危机时更是没少干预，这不是大家都这么搞的嘛。

中国干预汇率的时候，也只在特殊时期做过，比如疫情时期，比如贸易战时期，不是特殊时期的话，我们央行也是不干预的，纯靠市场。

# ## 二、汇率和出口的关系没那么大，

比如今年，除美元外的其他货币都在贬值，我们人民币真想促出口，完全可以顺势贬值一圈啊，但我们没有。因为汇率对出口已经不重要了。

我们国家出口现在这么牛，是因为产业升级了，以前大头是服装鞋帽塑料制品玩具袜子的年代，确实汇率影响很大，现在嘛，你们哪个国家的产业竞争力比得上我们，根本无需靠价格（汇率）竞争。

看历史数据也能看出来，

2010-2014年，2020-2021年，都是人民币升值的时候，结果出口份额还上升呢，2016年、2022年都是人民币贬值的时候，结果出口份额还下降呢。
