# 以阿米巴经营角度分析个人时间收入、人工成本与总劳动时间

阿米巴经营（稻盛和夫）的核心是把组织拆成最小经营单元，让每个单元像独立小公司一样核算。最关键的指标是单位时间附加值（也叫“单位时间核算”或“每小时附加价值”）。

# **书中核心计算公式**

单位时间附加值 = （销售额 - 除劳务费外的所有经费） ÷ 总劳动时间

对应到个人层面（把“你自己”当成一个最小阿米巴）：

| 概念 | 阿米巴原意 | 个人对应计算 |
| --- | --- | --- |
| 销售额 / 收入 | 阿米巴对外销售 + 内部交易收入 | 你实际创造的收入（工资、提成、项目收益、副业收入等） |
| 经费（费用） | 材料费、设备折旧、水电、外包等（不含人工成本） | 你为创造收入产生的可控费用（交通、工具、培训、材料等，不含自己的工资） |
| 附加价值 | 销售额 - 经费 | 收入 - 可控费用 |
| 总劳动时间 | 正常工作时间 + 加班 + 转移时间 + 公共时间 | 你投入的总工时（正常上班 + 加班 + 学习/准备相关时间等） |
| 单位时间附加值（时 | 附加价值 ÷ 总劳动时间 | 每小时创造的净价值 |

# 把每一小时劳动创造的价值算出来，把时间直接当成成本去衡量。公式就一行：

单位时间附加值 = （销售额 - 各项经费） ÷ 总劳动时间
翻译成大白话：我每干一小时，到底赚了多少钱？为什么这套东西对我这么重要？因为自由职业的收入是按单、按天算的，你很容易只看"这单多少钱"，却忽略了"这单我花了多少小时"。同样是赚2000块，花4小时和花40小时，是两门完全不同的生意。

现在我会把我的时间成本专门算进去，看自己的时薪。它帮我做了三个判断：

第一，这个活值不值得接。时薪明显低于我阈值的活，即使总价看着还行，我也会慎重。
