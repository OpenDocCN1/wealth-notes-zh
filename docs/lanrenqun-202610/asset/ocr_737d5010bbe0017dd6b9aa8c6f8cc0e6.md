# 五、解决权谋不在线：设计“小而完整”的利益博弈

短篇权谋尤其忌讳把“复杂”理解为“势力越多越好”。通常先理清主角、主要对手、关键第三方的立场，就能搭出一段完整博弈；是否需要第三方取决于故事本身。

重点不是计谋名字多漂亮，而是每一步行动有没有目的——条件——代价——对手反应——结果。例如，主角拿到证据也不等于可以直接公开，还要考虑谁有权确认、公开后谁会受损、谁会因此被迫站队。
