# 七、我把这套采集和监控能力，整理成了一个开放平台

上面就是我这次使用的完整选品流程。为了让大家能围绕自己的方向复用，我又把其中的采集和监控能力整理到了开放平台，准备以限时免费试用的方式开放给圈友。

如果手里只有一个方向，可以通过关键词采集找第一批商品；已经看到具体商品，可以补充商品信息；遇到值得研究的店铺，可以采集店铺商品，了解它围绕同一人群还做了哪些交付。

当问题变成“买家究竟在意什么”，就去看商品评论；当问题变成“这个方向是否还在变化”，就继续跟踪销量、店铺上新和新增评论。每一种数据，都应当对应一个准备做的判断。

开放平台的用处，是把这些能力接进自己的表格、脚本或工作流。现在已有一套选品方法的朋友，可以保留自己的判断方式，把重复取数的部分接起来。
