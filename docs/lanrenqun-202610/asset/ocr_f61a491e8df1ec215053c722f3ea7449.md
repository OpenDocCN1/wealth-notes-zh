# 选题、内容和视频制作接起来。

它先根据项目资料和客户问题整理选题与文案候选，我在成果审核里确定这条视频要讲什么、哪些事实能说。原来，如果说以前我有一个想法或者一个选题，我还要单独地给每个 Agent 下命令，现在可以省掉来回复制的时间，可以直接进入下一步，最后输出成片，发布即可。

定稿后，文案进入视频制作任务，配合录音、画面和字幕完成剪辑。右边的时间线就是这条视频的成片过程。这样提效的关键，是前面确认过的资料和判断能直接进入后续制作，少了反复找材料、重新解释需求的时间。

选题、对外表述和最终成片仍由我逐步把关。
