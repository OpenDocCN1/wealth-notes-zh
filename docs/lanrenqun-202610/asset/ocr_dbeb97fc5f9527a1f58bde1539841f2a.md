# 什么是 IP 污染？

平台不会直接"封 IP"，但会给每个 IP 地址打风险标签。如果同一个公网 IP 下，有账号做过违规操作、批量发文、频繁注销注册，这个 IP 就会被标记为 "高风险 IP"。

在高风险 IP 下发文，哪怕你的账号本身完全合规，也会受到 IP 标签的牵连——系统提高审核等级，降低初始推荐权重，表现就是 0 曝光、不起量。
