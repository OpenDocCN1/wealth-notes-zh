# ### 第 1 步 把用户反馈分成三类，只先修一个

收到反馈后，先分类，不急着改：

| 类别 | 怎么认 | 怎么处理 |
|---|---|---|
| 使用障碍 | 想做的事做不下去：卡住、报错、找不到入口、等太久 | 最先修，一次只修一个 |
| 功能缺失 | 用户需要，但 App 本来就没有 | 放进待讨论列表，攒证据 |
| 个人偏好 | 换颜色、换说法，不影响完成任务 | 记下来，不急着动 |
