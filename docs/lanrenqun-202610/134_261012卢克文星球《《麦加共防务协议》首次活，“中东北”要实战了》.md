


# 《麦加共同防务协议》首次激活，“中东北约”要实战了？

小懒判断｜适合被“中东北约实战了”这类标题带情绪、想看懂沙特巴土三方各自算盘的人。最值得关注的一层：沙特军队一分为三的架构（厢军/八旗/外戚禁卫军），才是它战斗力拉胯的真正根源——防自己人甚于防外敌。坑在于：三国连敌我识别码都没对齐就谈“实战”，这个协议形式大于实质，更像小萨勒曼给外戚贵族看的威慑底牌。

10月5日，沙特、土耳其、巴基斯坦三国在利雅得召开紧急会议，正式宣布启动《麦加共同防务协议》集体防御机制，向沙特部署联合军事力量。

消息传出后，很多人激动地说，这意味着“中东北约”首次进入实战状态！

事情的导火索，是过去几日，胡塞不但把沙特扶持的也门政府军打得满头包，而且盯着沙特的石油运输命脉猛打。

10月3日至4日，胡塞武装接连发射多枚弹道导弹与无人机，对沙特阿美石油两座关键加工厂和贯穿沙特的“东西输油管道”关键泵站进行了袭击。

紧接着在10月5日夜间，胡塞武装再次动用巡航导弹与无人机对红海沿岸的拉比格炼油厂实施定点打击，精准引爆核心设施，造成大面积火灾。

在袭击中被瘫痪的“东西输油管道”，是沙特为防范伊朗彻底封锁霍尔木兹海峡而专门打造的战略生命线，在霍尔木兹海峡通行受阻后，沙特超过70%的原油出口都依赖该管道，日运量飙升至400万桶以上。遭到轰炸的拉比格阿美炼油厂，也正好是沙特在红海沿岸构建“绕开霍尔木兹战略”的核心枢纽。

只能说，胡塞太会挑打击目标了，个个都让沙特肉疼得要死。

现在沙特除了摇人，没有第二个选择，这才找上巴基斯坦和土耳其，激活了刚刚签完的麦加协议。

不过，你可能会发现，这次除了沙特比较激动以外，土耳其与巴基斯坦都比较低调。

无论是土耳其还是巴基斯坦，国会都没有通过对外派兵的正式法案。

土耳其只能提供部分装备援助，巴基斯坦倒是给了16架“枭龙”战机，但这些战机早就进驻了沙特的军事基地。

那么请问什么条件下，一个组织才能被视为军事同盟？

军事同盟最基本的一点，就是必须依托统一的指挥协调中枢与标准化的后勤接口。

冷战时期的北约、华约，为了实现跨国协同作战，大到弹药口径、防空识别码和数据链协议，小到坦克的燃油标号与电台通讯频段，都经历了数十年极其严苛的标准化打磨。

现在这哥仨呢？沙特空军飞的是美制F-15与欧制“台风”，巴基斯坦开来的是中巴联合研制的“枭龙”与挂载的中式航电；地面上，沙特的“爱国者”雷达，甚至无法直接与巴基斯坦的“红旗”防空导弹系统进行底层数据互联互通。

巴基斯坦的全中械师，跟沙特的美式装备搞军事合作和数据共享，可能吗？

土耳其虽然也是美械武器，但自从2016年跟美国闹掰后，就自己建设被称为KMC的国家战术数据链，能不能跟沙特接上还是个未知数。

可能是事发过于突然，沙特启动协议时，明显没有考虑到这些问题。

这也说得过去，毕竟沙特所有的雷达、武器装备，都是承包商驻扎维护，技战术细节、频段、数据链，沙特人是一问三不知。

根据目前的消息来看，各方连敌我识别码都没有沟通好，别说联合作战了，混在一起打真的会出事的。

麦加协议从签订开始就埋下了各种问题，每方都有自己的目的，而下一阶段麦加协议会走向何处，也要看手段是否服务于各自目的，我们逐一分析。

首先是沙特。

沙特的战斗力极其拉胯，在键政圈尽人皆知。

这背后的根源，主要是沙特为了防止内部生变，硬是把国家武装力量一分为三，搞成了类似于厢军、八旗与马穆鲁克禁卫军的奇葩大杂烩。

沙特的武装力量主要是三支：国防军、国民警卫队与皇室特种部队。

沙特国防军，忠诚度最高，但战斗力最弱。

它类似于宋朝厢军，本质上是给底层民众发的低保福利。国家通过招兵，给底层人提供一个吃上铁饭碗的打拼通道，更多是解决沙特内部的就业和维稳需求。

国防军的军官，都由沙特权贵二代把持，底层人只能当兵。这些二代没什么志气，打仗不行，但好在都是萨勒曼的人。

沙特国民警卫队，战斗力最强，但它根子是属于阿卜杜拉王子派系，萨勒曼和阿卜杜拉的关系，就跟李世民和李建成类似，兄友弟恭，懂的都懂。

自1960年代起，老阿卜杜拉便利用其兼任司令的特权，在军中大量安插其母族沙马尔部落的人马，后安排儿子小阿卜杜拉继承。

萨勒曼惹不起这帮外戚，向来高额薪水、福利住房、免费医疗、丰厚退休金好生伺候着。

直到2017年11月，小萨勒曼以“最高反腐委员会”之名，在利雅得丽思卡尔顿酒店，直接把小阿卜杜拉等数十名王室显贵给扣了，随后夺取了小阿卜杜拉对国民警卫队的控制权，疯狂清洗阿卜杜拉旧部，试图把国民警卫队打造成完全忠诚于自己的沙特八旗。

至于皇室特种部队，也不是小萨勒曼全控制的，它又由另一支王爷派系纳伊夫系控制。

国防军可用不能打，国民警卫队可打不可用。国家安全体系纯粹是对内保卫，不具备对外作战能力。

沙特复杂的政治局势，使小萨勒曼无可用可信之兵。

承平之世，小萨勒曼还能勉强维系这套奇奇怪怪的军队系统，但一旦发生真正的战争危机，BUG会瞬间暴露，这才是沙特军队如此拉胯的真正根源。

沙特自己解决不了问题，只能喊外援，也就是土耳其和巴基斯坦。

不过，巴基斯坦也非常抠巴。

说起来，巴基斯坦和沙特关系是非常好的。

在过去几十年里，沙特国内但凡有点风吹草动，第一时间想到的就是从巴基斯坦成建制调集精锐陆战力量。

巴基斯坦的第44装甲旅、陆军特勤大队（SSG），都曾多次前往沙特执行最核心的政治保卫任务。

时至今日，依然有成百上千名巴基斯坦军人常驻沙特，名义上是“负责训练”，实则充当沙特军队的监军和防务骨干。

沙特给巴基斯坦啥呢？当然是直接给钱，简单粗暴。

哥俩看似是天作之合，但其实在胡塞的问题上，双方已多次爆发矛盾。

比如2015年，沙特被胡塞打懵后，要求巴基斯坦成建制前往沙特，与胡塞武装作战。但是巴基斯坦非常清楚，胡塞背后是伊朗，它打胡塞就会得罪伊朗。

巴基斯坦面临的地缘痛苦是，自身地处南亚要冲，战略纵深极狭窄。

巴军主力部队，长年钉死在东线的克什米尔与印巴边境，用以防御印度；而它的西线，是与伊朗接壤的上千公里边境荒漠与俾路支省动荡带，根本没有余力再重兵设防，只能顾一头。

如果巴基斯坦激怒伊朗，不排除伊朗跟印度联手，在巴基斯坦东西两线同时放血。

这也是为什么2015年，哪怕知道会得罪沙特，巴基斯坦议会依旧全票通过了也门中立法案，不允许巴基斯坦卷入也门事务。

现在巴基斯坦的困难是，还外债、买石油、未来引进歼-35，都离不开沙特这个金主。但国家安全红线，又决定了巴基斯坦不可能真的为了沙特，去跟胡塞武装和伊朗拼命。

对巴基斯坦来说，沙特跟胡塞斗而不破，是最好的局面。毕竟，“倭寇不可不剿，但又不可全剿”嘛。

所以巴基斯坦在今年初，调集精锐，派遣“枭龙”战机与“红旗”防空导弹分队赴沙助阵，摆出保卫盟友的姿态，尽力维持一二，希望控制局势。

如果未来局势激化，巴基斯坦一定以自己的国家安全利益为重，毕竟外汇少了还能想办法再借点钱，到时候大概率还是只能苦一苦小沙了。

至于土耳其，沙特恐怕更指望不上了。

虽然借沙特之手，清剿胡塞、削弱伊朗，完全符合土耳其的利益，但土耳其并不急着现在出手。

土耳其的大国战略，是东扩和南下。

东扩，就是通过突厥国家组织，让土耳其的力量渗透阿塞拜疆，乃至中亚各国。2023年阿塞拜疆的纳卡战争，就是土耳其东扩的重要节点。

南下，是重新渗透回阿拉伯地区。2024年底朱拉尼的崛起，意味着土耳其势力重回叙利亚。

东扩和南下结合在一起，就是埃尔多安口中的“新奥斯曼”大国梦。

但无论土耳其要东扩还是南下，伊朗都是绕不开的绊脚石。

在东扩上，伊朗和土耳其都在争夺高加索地区，在南下上，土耳其和伊朗都要争夺叙利亚。

在这两场战争中，以色列情报机构摩萨德，都与土耳其国家情报局保持了密切联系。

所以中东的格局，不是以色列和伊朗对抗，是伊朗、以色列、土耳其的三足鼎立。（沙特一边凉快去）

这次土耳其以国会未通过为由，一兵一卒都不给沙特，是因为土耳其不准备现在就动手，要等伊朗和沙特、以色列消耗到筋疲力尽，它才可能“帮”沙特，那时候才是摘桃的成熟时机。

不要低估土耳其的胃口，从地缘野心来看，土耳其甚至比伊朗让沙特更加不安。

但是，以小萨勒曼的精明程度，他会看不透土耳其的野心、巴基斯坦的退缩吗？

我认为无法排除的一种可能是，小萨勒曼知道胡塞问题是解决不了的，所以这份防务协议，并不是给外人看的，就是给外戚贵族们看的。

沙特财政收入近七成靠石油出口，现在胡塞武装与伊拉克北方民兵，对输油管线和炼化厂的持续破袭，伊朗又封锁霍尔木兹海峡，对沙特财政造成了毁灭性打击。

上文说过，国防军是“厢军”，国民警卫队是不够忠诚的“八旗”，皇室特种部队是外戚掌握的情报部门，都要靠撒钱来招安。
