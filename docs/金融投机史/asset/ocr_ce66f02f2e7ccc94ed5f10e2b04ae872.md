# 偏見轉為執迷

智力劣化的群體，則代表了人們有意識地過濾並操控資訊，讓新資訊符合既有的信仰。心理學家將此行為命名為「認知失調」（cognitive dissonance）。與既存幻想產生矛盾的不協調資訊，會使人不舒服，因而被刻意避免。人們對此類訊息的反應，一是撲殺訊息傳遞者，二是改變他人想法，使其歸於自己的群體。費斯汀格（Leon Festinger）則在《認知失調論》（Theory of Cognitive Dissonance）中指出，只要給予充分的誘惑獎勵，就可以讓人們慢慢接受不斷增強的不協調資訊。在金融市場裡，你或許可以說人們是故意忽視所有壞消息，因為他們對自己從投機中立即賺得的收穫還不满意。1860年代，福勒曾為身邊的投機者留下一段描述，完整體現此一論點。福勒寫他們「正忙著互相加油打氣，但不是為了錢，因為我們自認為在此方面可謂堅不可破，而是為了應付崛起的另一派言論。我們知道
