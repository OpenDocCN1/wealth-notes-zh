# 資訊本位取代黃金本位

有個人迅速抓住此波改變背後的重大意涵，他就是花旗銀行總裁里斯頓（Walter Wriston），曾說出「資訊本位將取代黃金本位，成為全球金融體系基礎」。* 為了適應此一重大變革，需要新的金融革新，而資訊技術的進步成就了革新。從1969年開始，美聯社（Telerate）開始提供所有銀行的債券交易明細，並成為美國公債的電子交易場。四年後，英國新聞媒體路透社（Reuters）推出了貨幣匯率監控服務，為外幣建立一個二十四小時全天候的電子市場。未來幾年，金融市場的電腦化勢必會繼續尖飛猛進。†
