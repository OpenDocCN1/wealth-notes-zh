# 能

彼得寫道，「創新是資本主義社會經濟史上的卓越事實。」

投機者則是資本主義發展的先鋒。當創新成功樹立，並產生穩定的報酬後，投機就會被投資所取代。與重視資本利得的投機客不同，投資者更重視資本的安全與收益的穩定，並重視事件當下的狀態；在某種程度上，投資者對未來的預期建立在當前狀態的延續。

發明與創新總是讓投機者無比興奮。1690 年代大量成立的潛水器械、消防車和防盜警報器公司，及 1720 年代的機關槍和「永動輪」，在在顯示早期投機者對於科技革新的熱情。然而，在工業革命發生以前，那些深深吸引投機者的創新發明往往進步有限，或僅只是熱潮中的一樁騙局而已。直到 18 世紀晚期，在交通工具上出現多起重大革命性發明，並對社會產生全面性的影響。最先是開鑿運河的技術，緊接著是各種發明：鐵路、汽車、收音機、飛機、電腦，直到更晚近的網際網路。交通運輸方面的進步，吸引了投機者熱切的目光，而這些建設也因為投機者的資金而順利成長茁壯。
