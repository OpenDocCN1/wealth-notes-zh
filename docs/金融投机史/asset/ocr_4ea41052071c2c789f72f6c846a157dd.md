# 中世紀時期

不管是實務面與觀念上，中世紀歐洲的文化背景極不利於金融投機。封建體制摒棄了許多羅馬時期的金融交易法，改以實貨支付取代現金交易。中世紀學者重振了亞里斯多德學派的「公道價格」（just price）理想，追隨聖多馬斯·阿奎納（St. Thomas Aquinas）的教誨，認為「以不符合物品價值的買低、賣高之舉」，都是不正義且非法的行為。*高利貸也同樣被譴責。追求利益的行為被視為墮落之舉，更會危害國家安定。聖奧古斯都（St. Augustine）將不知節制地追求財富、貪權和戀色，視為三大罪。投機者不能進入他心中的「上帝之城」。飢荒降臨時，城邦介入食物的供應，而出於投機心態的囤積行為，被視為違法。對牟取暴利與投機行為的確轟，綿延了數個世紀。當近代政治家大肆抨擊投機者的所作所為之時，無意間讓中世紀僧侶的偏見再度復活。

中世紀後期，數個義大利城邦開始發行可交易的政府債券。威尼斯的里阿爾托（Rialto）從13世紀中葉起，就開始交易政府債券。投機也似乎乘勢而起：1351年頒佈一項法令，禁止利用謠言壓低政府基金價格；1390年、1404年和1410年，政府延期付款債券（即債券期貨）的買賣數度受阻；總督與大公共會議的成員也試圖阻止「內線交易」。14世紀的佛羅倫斯、比薩、威洛納和熱內亞，也出現了公債的交易。義大利的城邦政府將收稅事務外包給被稱為「monti」的公司，而這些公司的資本被
