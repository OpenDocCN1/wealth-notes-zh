# 虛空與捕風的象徵

除此之外，投機讓某些人一夕致富，又讓某些人傾家蕩產，因而打亂了社會階級。根據「貪財」的說法，「（投機者）一個比一個驕傲」。\*恰好成為金融投機操作核心的鬱金香，成為奢華、脆弱的表徵，和骷髏、沙漏及書本一同化身為荷蘭虛空派畫家筆下的寓言表徵。

在維瑟的徽章作品中，鬱金香成為愚昧的象徵，它那短暫的美麗成為傻子眼中的誘人幻象。另一個常見的虛空派象徵物，就是泡泡，暗示著人生轉瞬即逝：人生就如泡沫，羅馬歷史學家瓦羅（Varro）如是說。泡泡瞬間膨脹，目眩神迷的光彩讓旁人醉心，卻也能在瞬間幻滅。泡泡是由風或空氣組成，17世紀的荷蘭利用此一象徵意義，將期貨交易形容為「風中交易」，在現代一幅關於鬱金香狂熱的畫作中，畫了一輛迎風奔馳的戰車，上面站著具有象徵意義的花神，後人也用此意象來形容股票仲介「哄抬價格」的邪惡手段。†
