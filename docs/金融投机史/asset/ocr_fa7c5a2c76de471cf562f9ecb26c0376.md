# ## 股票選美

不斷上漲的牛市，完美地迎合了投資者對新科技的痴迷。汽車取代鐵路，成為刺激經濟景氣的發動機，化身為投機客的心頭好。汽車顛覆了美國的文化和地理；不斷鋪設的道路，新建的高速公路，為了應付在1920年代從700萬輛增長到2,300萬輛的汽車成長率，大量的車廠跟著出現。有將近一百萬人擠進福特汽車位於紐約的總部，只為一睹Model A的模樣。此種興奮之情同樣反映在股市之中，1925年至1928年間，通用汽車的股價漲到10倍以上。劇烈的漲幅也讓股市成為新聞報紙的頭條。拉斯科布於1929年8月提出人人都能富有的論述，指出如果十年前投資1萬美元在通用汽車上，現在這筆錢已經漲到了150萬美元。°

> * 由於控制通用公司的杜邦（Du Pont）家族利用公司股票作為獎勵，因此所有高層管理人員都極端渴求股票可以不斷上漲。到了1930年，八名高層執行長平均每人擁有價值300萬美元的通用股票。
