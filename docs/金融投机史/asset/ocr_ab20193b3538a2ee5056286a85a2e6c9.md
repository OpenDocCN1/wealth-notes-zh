像是與政府作對。投機的本質就是短視近利，尋求最大獲利，然而日本體制宣稱自己為長期主義者，相較於利益，更關注其他層面，如扶植重點產業等。投機也牽涉風險轉移，但在1920與1930年代經歷了股市崩盤與無數銀行破產後，日本當局表示再也不會容忍這樣的事情發生。因此比起西方，日本社會對風險的敵意更重。儘管如此，1980年代時，投機風潮依舊蔓延到日本。它的影響深遠，以茲在投機潮消退的五後，日本經濟體系依舊殘破不堪。官員企圖重振旗鼓，恢復過往秩序，卻徒勞無功。日本籠罩在泡沫經濟最嚴重的餘威中。

# # 日本的商業霸權

投機狂熱經常是自信心膨脹的一種症狀。正因如此，當經濟強權的均衡點從一國移動到另一國時，投機狂熱往往就此出現。舉例來說，在荷蘭發生「經濟奇蹟」後不久，阿姆斯特丹成為通往全世界的海上樞紐，而鬱金香熱潮也隨之爆發。同樣地，20世紀初，美國取代英國成為產業界的霸主，不久後紐約爆發了股市狂熱。\*在接下來將近七十五年的日子裡，美國穩坐
