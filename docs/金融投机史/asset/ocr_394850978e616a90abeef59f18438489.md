# 衍生金融商品紛紛出籠

1980 年代，這場金融革新又向前跨出一大步：受顧於投資銀行索羅門兄弟的聰明債券專家荷瑪（Sidney Homer），想到了將債券與債息分開（技術性用語稱「分割」）的做法，將其拆成兩張證券分開交易。此重大發明讓銀行可將流動性不足的資產轉換成可交易的證券（此步驟稱為「證券化」）。荷瑪的遠見大量應用到美國聯邦政府擔保的貸款市場上，並引發了「合成」貸款債券的誕生，此債券是将利息與本金拆開，各自做爲單一債券買賣。其中，分割本金證券（Prinicipal Only Bonds）又依還款優先性被分成數個等級。最低的等級稱零息債券（Z-bonds），是最後一個得到償還的債券，價格相當不穩定，交易員往往稱其為「有毒廢料」。這些產品被稱為「美國投資者有史以來遇過最投機的投資工具」。
