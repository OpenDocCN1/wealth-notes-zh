# 誘人的財務槓桿

1920 年代股市的最大特徵，不是瘋狂追求投機性的創新發明，而是為了提高利潤而瘋狂堆疊債務。在通知貸款的幫助下，投機者可任意購買任何股票。當時，曾以個人名義借了超過 25 萬美金來買股票的格魯喬·馬克思，回憶起當時的牛市，說那時根本不需要任何理財專家來告訴你該買哪支股票，「你只需閉上眼睛，朝著行情牌隨便一指，指到哪支就買進，那支股票就會開始上漲。」

# 槓桿進入企業財務

使用槓桿的情況並不局限在個人投機者的通知貸款上；此系統更漸漸深植於美國企業的財務體系中。公共事業與鐵路公司進行各種合併，將層層債務堆疊，成為巨型控股公司，有時也被稱為「體制」（使人不自覺聯想到約翰·羅的密西西比體制）。曾擔任愛迪生（Thomas Edison）秘書的英索（Samuel Insull），在美國中西部建立了一個龐大的公用事業網絡，其多元化的經營項目下，還包括輪胎製造廠、鞋廠和不動產商。投資業的托拉斯——英索公共事業投資公司（Insull Utility Investments），以交叉持股的方式擁有許多公用事業公司，而每間公司又以債務累積出極高的財務槓桿，因此只要某間公司的營收上升一點點，就能為控股公司帶來不成比例的超高收益。*此外，子公司間又以哄
