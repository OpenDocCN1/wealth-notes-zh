# 投機的歷史翻案

數本歷史與金融著作記述的鬱金香傳說，如麥考萊（Thomas Babington Macaulay）的《英國史》（*History of England*）、白芝浩（Walter Bagehot）的《倫巴底街》（*Lombard Street*）和麥凱極暢銷的投機狂熱史《異常流行幻象與群眾瘋狂》，讓世人開始懷疑鬱金香狂熱是否真的發生過。

# 不是愚行，是理性預期？

美國經濟學家蓋博（Peter Garber）認為那些虛假的鬱金香傳說故事，破壞了狂熱的可信度。他更表示當時的史料（包括「貪財」與「真心話」的「對話錄」）應被視為政府的宣傳手段，常持保留態度看待。他認為鬱金香投機是理性的，而非狂熱。他的主張是，就算日後花價下跌，由於母株可長出更多子株來彌補損失，因此罕見花種的球莖價格自然還是會比較高。

他還發現，鬱金香的價格變化與其他高價花卉球莖的價格模式並無二致：時髦新品種的球莖可賣得較高的價格，但隨著該品種愈來愈普及，或市場上出現新品種競爭，此花卉的價格將大幅下跌。在18世紀的荷蘭，風信子也曾一度風光，當時它們的價格也相當驚人。根據此一論點，所謂的鬱金香狂熱，也不過就是人們追求價格本就不穩定的時髦商品，導致需求出現瞬間偏差罷了。

然而此一大膽的歷史翻案論點，卻經不起驗證。蓋博的目的是支持「效率市場」經濟學說，該理論認為市場價格會反映最真實的價值，因此無論是股票或鬱金香泡沫、熱潮，皆不可
