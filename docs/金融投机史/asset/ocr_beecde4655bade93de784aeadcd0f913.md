# 狂熱的巔峰

當時，荷蘭的個人平均年收入約為200荷蘭盾至400荷蘭盾。至於一幢小房子，要價約300荷蘭盾，而一流的花卉畫作價格不超過1,000荷蘭盾。*根據這些數據，我們得以衡量鬱金香價格的荒唐程度。

根據「對話錄」的記載，一株重4艾斯的「高達」(Gouda) 球莖價格，從20荷蘭盾漲到225荷蘭盾；10艾斯的「大元帥」(Generalissimo) 從95荷蘭盾，暴漲成900荷蘭盾；幾個禮拜前，一磅的素黃色「格勒嫩」(Groenen) 原本才賣20荷蘭盾，轉眼間就飆到1,200荷蘭盾（從等同於月薪飆漲到五年新水的總和）。「貪財」承認：「沒錯，由於價格實在太棒了，因此過去被嫌棄、整籃往糞土裡倒的貨色，現在也能賣得好價格。」「永遠的奧古斯都」依舊穩坐鬱金香球莖的寶座。「貪財」說：「大約三年前，一株就可以賣到2,000荷蘭盾，而且是銀行立刻進帳，」但在最瘋狂的時候，一株可以賣到「6,000荷蘭盾甚至更多，即便重量只有200艾斯。」過去一株賣3,000荷蘭盾的「總督」，現在價格翻倍。

根據當時一名小冊子作家的紀錄，用來買一株球莖的2,500荷蘭盾，可以購買二十七噸的小麥、五十噸黑麥、四頭健壯的公牛、八隻肥豬、十二隻肥羊、兩大桶葡萄酒、四大桶啤酒、兩噸牛油、三噸起司、床和床織品，再加上一櫃的衣服和一個銀製杯子。†

*泰勒 (Taylor) 曾在《荷蘭花卉畫》(Dutch Flower Painting) 一書中提及，由於用於靜物繪畫中的花卉裝飾變得過分昂貴，導致畫家們不得不一起共用花朵。
