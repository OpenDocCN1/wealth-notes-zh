# 南美洲債券

在英國人購買的外國債券中，出現一支格外浪漫的債券：南美洲債券（South American bond）。在玻利瓦極具感染力的領導下，南美洲數個殖民地起身為獨立奮鬥，進行了數年的戰爭。出於長久以來對西班牙此一天主教宿敵的怨恨，以及追求獨立的現代自由主義，英國人熱烈支持解放運動。在驅逐了西班牙人後，人們預期該南美大陸的經濟將快速發展：「我們將沐浴在南美共和國的光明希望下。」《新時代》（New Times）如此報導。「他們踏上了永無止境的進步之路。很快就能和歐洲最幸福的國度一樣，獲得知識、自由與文明。」英國的科技與藝術將協助南美的人民邁入現代化。此一提案聽上去如此動人，再加上政府發行的公債愈來愈少，讓投資民衆迫不及待地跳入第一個「新興市場」的熱烈懷抱中。
