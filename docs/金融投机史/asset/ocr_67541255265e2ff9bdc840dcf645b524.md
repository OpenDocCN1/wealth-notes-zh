# 泡泡裡的狂歡

城市的女子成為股票經紀人；男侍、僕役和門房（還有商人、店主及扒手）乘著馬車，走進交易巷；某些富裕的男士反而開始放棄這些行頭；創業家成功地利用各種計畫矇騙大眾；騙徒離開柯芬園的賭桌，到強納森咖啡廳進行利潤更高的勾當；連詩人也開始進行股票投機買賣。看到這種種異常現象，我們就知道，宣佈交易巷鬧劇開演的時候到了。

投機交易打破社會階層的藩籬。「我們可以看到，」斯威福特悲痛地表示，「國內極大部分的金錢流入了那些論其出身、教育及品德只配充當男僕的人手裡。」在南海狂熱的這一年裡，如達波之輩都將捲土重來。這些史提爾所謂的「廢人」，厚顏無恥地炫耀新入手的財富：買房、買馬車、為自己添購刺繡大衣、為妻子及情婦購買金錶。購買房屋的熱潮，將地價推到租金的五十倍。「每天都激增了許多南海暴發戶，」《蘋果蜂期刊》在8月時報導道，「城市中的仕女購買南海珠寶；雇用南海女僕；添購新的南海鄉間宅邸；男士購買南海馬車、南海房產……」
