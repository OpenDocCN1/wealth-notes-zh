# 衍生金融商品革命

紙幣、經濟自由主義和資訊技術的革新，引發了新時代的金融創新成果，其影響力的深遠，不亞於18世紀的金融革命，而且在衍生性金融商品領域尤其亮眼。如我們所見，衍生性金融商品單純是一種利用契約所創造出來的有價證券，其價值衍生自某一標的資產，如股票或債券。以期貨及選擇權來說，這些衍生商品以股票或商品為標的，歷史就跟資本主義一樣古老。由於購買衍生商品如股票的選擇權等，所需支付的保證金（三個月的股票選擇權只需付5%的首款）低於購買「實際」資產，因此被視作鼓勵投機的機制。而此一偏見也體現在政府對衍生金融商品的禁止上，如1609年荷蘭禁止期貨買賣，以及1734年英國議會通過的《巴納德爵士法案》。儘管如此，在這個新時代裡，衍生金融商品已洗刷污名，成為金融革新的前鋒。
