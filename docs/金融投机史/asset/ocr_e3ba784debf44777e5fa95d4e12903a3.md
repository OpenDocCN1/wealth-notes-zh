# 掠奪者與套利員聯手操縱企業

槓桿併購的熱潮，是推動1980年代中期牛市的最大力量。被稱為「私有市場價值」的LBO估值成為主流，取代傳統估價法，用以估算一間公司的現金流量）和償債能力。尋找併購目標的專業「風險套利員」，成為確立股市內私有市場價值的中介。套利員會根據私下的串通，找出脆弱的公司並奪取大量股票，迫使該公司進入「遊戲」。其他成員則會配合並模仿套利員，正如同1920年代追著投機基金的先祖輩一樣。由於這些套利員和追隨者對於該公司沒有絲毫忠誠度，因此企業掠奪者更容易恣意妄為。當併購案提出後，這些掠奪者只需向套利員俱樂部示意，就能得到該公司的掌握權。此種被稱為「掃街」行動的過程，在坎波（Robert Campeau）併吞聯合百貨（Allied Stores）的過程尤為經典。當時坎波不過打了一通電話，洛杉磯的經紀人傑弗里斯（BoyD Jefferies）就取得了3,200萬股，占流通股的半數以上，坎波因而獲得這間價值40億美元公司的控制權。

但如果併購沒有實行或計畫落空，風險套利員也會蒙受極大的損失。舉例來說，1982年5月，海灣石油併購城市服務（Cities Services）的提案失敗，波斯基損失了2,400萬美元。而顯然正是因為這場失敗，讓波斯基決心建立秘密的投資銀行家人脈網絡，名單上也包括了吉德皮巴迪公司（Kiddler Peabody）的西格爾和德崇的萊文（Dennis Levine）。1984年，
