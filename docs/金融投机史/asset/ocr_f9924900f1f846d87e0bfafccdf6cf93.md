# 金融改革

1971年8月15日，尼克森總統暫緩美元兌換黃金的措施，為施行長達二十五年的布列敦森林制度畫下句點，迎來新一波的投機。*儘管17世紀末的金融改革引發了信用票據的氾濫，但所有價值最終總會和黃金掛鉤。黃金就像是投機的對立面。每當投機失控，金融危機發生，所有人都会企圖從黃金屬身上尋求安定。只有土地銀行創辦人、密西西比泡沫發起人約翰．羅明白，所有金錢（包括黃金）的價值，都建立在社會共識之上。當羅於1720年代將紙幣引進法國時，英國駐巴黎大使史特爾勳爵（Lord Stair）對於約翰．羅最近改信天主教一事（為了得以正式擔任法國主計長），發表了充滿嘲諷的評論：「我們無須質疑約翰．羅對於天主教的信念，因為……他連紙都能變成錢。」對於史特爾和當時的人們來說，約翰．羅的紙幣就像是一種信仰，如同相信聖餐奇蹟般。1971年、也恰巧是約翰．羅的三百週年誕辰日，他的願望終於實現。信念（credo）轉換成信貸已然成真。
