# 黃金陣容，落漆績效

LTCM不但集合了一流的交易員與最傑出的理論學家，還吸引了大批華爾街鉅富，像是美林證券總裁柯曼斯基（David Komansky），他和122名美林同事共投資了2,200萬美金；普惠公司（Paine Webber）的執行長馬隆（Donald Marron）；貝爾斯登公司（Bear Stearns）的執行長凱恩（James Cayne）。其他投資者還有中國銀行、瑞士寶盛私人銀行（Banque Julius Baer）、前好萊塢經紀人歐維茲（Michael Ovitz）和好幾名麥肯錫的合夥人。這份金光閃閃的投資者名單，讓LTCM成為避險基金界的勞斯萊斯。
