# 煞不住的鐵路投資

儘管《解散法案》（Dissolution Act）通過，股價跌跌不休，鐵路依舊以相當狂熱的步調進行著。在1846年期間，有超過一百間公司進行合併，議會也通過了二百七十件鐵路興建案，授權興建需耗費1億3,000萬英鎊、全長超過五千英里的鐵路。與前年相比，該年通過的興建案數量激增為兩倍多，哩程數也增加超過二千米里。此景讓許多評論家認為，在1845年10月的恐慌過後，鐵路狂熱並未休止。但事實上，多數於1846年收到授權的公司，皆於前一年成立，其中的大北部鐵路公司（Great Northern）更是於1844年就提出計畫申請。而多數計畫也是由已完工的鐵路公司所提出，企圖利用興建支線的方法來抵抗新鐵路公司的競爭。5月中，哈德遜奔波了三天，取得自己手中三間鐵路公司的股東同意，好提交四十件、總開發金額為1,000萬英鎊的提案。
