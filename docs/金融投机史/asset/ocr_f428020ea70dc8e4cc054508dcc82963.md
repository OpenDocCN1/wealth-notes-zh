# 黑色鬱金香傳說

鬱金香狂熱也製造了許多傳說。其中一個最知名的傳說，更成為文學家大仲馬（Alexandre Dumas）小說《黑色鬱金香》（The Black Tulip）的靈感素材：

哈倫區的花商聯合組織聽說，海牙有一名鞋匠，成功培育出黑色鬱金香，便趕緊去拜訪對方，在一番討價還價後，以一千五百佛羅林的價格收購一株球莖。但當球莖入手後，他們卻把它丟在地上，踩踏個稀爛。鞋匠驚訝之餘表示抗議，花商組織有個人罵道：「笨蛋！我們也有一顆黑色鬱金香。現在，幸運女神不再眷顧你了。其實，即使你之前開價一萬佛羅林，我們也會照付的！」可憐的鞋匠，一想到財富這樣溜走，滿心憂愁，倒在床上再也沒起來過。

儘管世界上根本沒有黑色鬱金香，最接近的顏色是深咖啡色，但透過這則傳說，我們得以看見鬱金香狂熱所激發的腐敗與貪婪。《黑色鬱金香》與日後的幾則傳說，也成為投機史上的一頁。在密西西比泡沫發生後，也曾傳出許多關於男僕的故事。這些一夕致富的僕人們，經常在一個恍神後，爬到自己新買的馬車駕駛座，完全忘了自己的新身分。另一則傳說則描述了一名醫生，在替一個上了年紀的女士把脈時，嘴裡不住地嘟囔著：「噢，我的老天，掉下去了，掉下去了，」在那位女士驚魂未定之中，眾人才發現原來醫生口中叨念著的是密西西比
