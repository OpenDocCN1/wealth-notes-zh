# 可惜，泡沫虛多於實

近代研究南海泡沫的歷史學家則同情地認為，這些泡沫公司只是企圖實現物質與科技進步的跨時代狂想罷了。不管如何，機關槍的設計更完善了，人類也發現了澳洲。不可否認，部分泡沫公司如史堤爾的魚池設計確實很聰明，但絕大多數的計畫只是企圖從這陣投機熱潮中賺取暴利的騙局。這些創辦人根本不想創建合法的企業。1720年代出現的泡沫公司中，僅有四間存活下來，其中兩間為保險公司（皇家交易與倫敦保險），後來也逐漸興旺。多數的創業家則以那些易騙、唯利是圖的人為獵物。投機者購買泡沫股票的目的並不是長期投資，而是企圖將這些股票轉手賣給更傻的傻瓜。儘管如此，他們很快就發現，市場上已經沒有比自己傻的傻瓜了。
