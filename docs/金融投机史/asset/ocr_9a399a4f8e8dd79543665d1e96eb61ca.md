# 政客變身商業搗客

股票也被用來換取政治勢力。在東印度公司一樁知名的醜聞案中，古老的政治貪腐勾結新興的金融投機勢力。該醜聞案爆發的源頭，在於東印度公司未能在1693年替其股價支付一筆特別稅。於是，該公司的特許權被暫停，而當時正好有間新崛起的聯合組織，企圖從東印度公司手中奪取東方貿易的壟斷權。爲了確保取得特許權，雙方開始大手筆地賄賂法院與國會內部人士。東印度公司在花了超過20萬英鎊的「秘密服務費」後，確保了自己的利益。
