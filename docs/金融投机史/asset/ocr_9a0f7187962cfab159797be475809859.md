# 英國本土的商品投機風潮興起

1824 年，在發生採礦熱的同時，英國的經濟也達到了巔峰。「在經歷了 1821 至 1824 年間的發展後，」圖克回憶道，「該國的貿易與工業進入了井然有序、健全且讓人滿意的巔峰狀態。」根據《社科年鑑》（*Annual Register*），英國全國上下的幸福指數大幅提高，「連最愛發牢騷的鄉村仕紳們……也無話可怨。」商品市場也開始出現投機客的身影：一開始，先是棉花與絲綢的價格飆高，讓門外漢也忍不住進場；接著，其他商品如染料、米、橡膠、肉豆蔻、咖啡和胡椒，也開始漲價。根據圖卡的紀錄，到了該年底，「那些在早期取得成功的投機先例，漸漸在社會上蔓延開來。」
