# 鐵路大亨

此時，有個人特別懂得利用大眾的熱情，達成自己的目標。約克與中北部鐵路公司（York and North Midland Railway）的董事長哈德遜，是個精力充沛、個性粗獷、身形肥胖的約克郡人。他是農人之子，出生在約克郡的東瑞丁，曾經是亞麻布商，後來繼承叔公大筆遺產，因此發跡，還當上約克市的市長。哈德遜對鐵路的興趣開始於1834年，當時他首次會見了「鐵道之父」史蒂芬生。據傳，史蒂芬生在哈德遜的說服下，將約克市打造成東北部鐵路系統的中心樞紐；或如哈德森納所說，「讓所有火車都開到約克。」

1842年，當約克與中北部鐵路公司成立後，哈德遜開始計畫新的路線與支線，收購或租下現有的公司。他設計了一條從約克通往愛丁堡的鐵路。在經過重重的結合（或如大家所稱的「合併」）後，他的鐵路系統遠達伯明罕、布里斯托，最終更接到了倫敦。1844年，他控制的鐵路超過一千英里，占當時運行鐵路全長的三分之一以上。同年，他獲得了「鐵路大亨」的綽號，此號來自於當時最風趣幽默的牧師史密斯（Sydney Smith）。此外，由於他極其貪吃，腰圍異常驚人，因此也有人戲稱他是「約克郡氣球」。但是，最適合哈德遜的稱號莫過於「鐵路拿破崙」，因為此人成功地搭上（鐵路）時代的潮流。
