# 鐵路熱

儘管運河的開鑿確實可以連接鄉村及城市、工廠與市場，在當地帶來一陣旋風，但開鑿運河本身卻沒有任何創新之處（畢竟羅馬時期的人就已經懂得開鑿運河）。運河的開發只是單純地讓人們享受到水路的好處，而這是之前未能做到的。然而，鐵路時代的來臨，卻徹底顛覆了人類的的生活方式。鐵路所帶來的影響是如此廣大，但當第一輛蒸汽火車頭在 1820 年誕生時，民眾的反應卻是無比驚恐與懷疑。人們甚至認為火車頭會讓牛不吃草、雞不生蛋；那有毒的霧氣將殺死天上的鳥，污染羊身上的毛；而高達十五英里的時速，更可能讓乘客被分解成原子。此外，鐵路還面臨運河擁有者、提供馬車服務者，以及擔心居住環境安寧和深怕獵狐活動會受影響的地主們的反對。當時，有人提議建造一條連接起倫敦與英格蘭西部的大西部鐵路，但牛津大學與伊頓公學卻在第一時間表態反對。

儘管大眾對於鐵路有種種誤解，鐵路早期的發展史卻引發了兩場投機熱潮。第一場「鐵路熱潮」發生在 1825 年，也是第一條蒸汽鐵路（連接斯托頓及達靈頓）落成的日子。很快地，議會通過六條鐵路法案。然而這場短暫的投機熱潮，因為年底的經濟危機，而消失匿跡。六年後，連接利物浦與曼徹斯特的鐵路開通，終於證明蒸汽火車頭的能力大勝固定式蒸汽引擎及馬匹拖拉，更足以取代馬匹。利物浦與曼徹斯特也立即支付 10% 的股利，股票的價格直接翻倍。他們的成功，引發了第二次「鐵路熱潮」，而這股熱潮也成為 1825 年經濟危機後出現的週期性投機的其中一波。當時的人們，正熱衷於西班牙債券與
