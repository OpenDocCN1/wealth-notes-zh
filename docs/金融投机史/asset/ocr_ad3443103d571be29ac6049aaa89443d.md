# 兩類潛水撈寶公司

費普斯的成功，引發兩種「潛水」公司的誕生。第一種專門向政府取得在某特定區域進行打撈作業的「專利」。鑄幣局局長倪爾（Thomas Neale）、也是當時獨領風騷的創辦者，參與了三間分別於牙買家、百慕達和葡萄牙進行打撈作業的專利公司。多巴哥公司（Tobago Company）的船長波因茨（John Poyntz）請求獲得在西印度群島將沉船打撈上岸、進行珍珠與龍涎香採集作業的專利。

第二種則是握有新近潛水機械技術的專利。隨著各種機械技術與計畫前仆後繼地誕生，新式潛水技術公司立刻增加了十多間，其中也包括了英格蘭沉船打撈公司（Company for Raising Wrecks in England），他們從皇家天文學家哈雷（Emund Halley）的手中，取得「潛水鐘」專利（該公司股票上市之初，就稱為「潛水哈雷」）*。《魯賓遜漂流記》（Robinson Crusoe）的作者狄福也曾擔任另一間潛水鐘公司的財務管理員，該公司的創辦人為來自康瓦爾的威廉斯（Joseph Williams）。
