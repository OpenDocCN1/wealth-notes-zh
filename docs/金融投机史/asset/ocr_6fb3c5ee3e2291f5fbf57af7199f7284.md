# 富豪的排場

被到手的巨大財富沖昏了頭，這些被作家稱為「垃圾債券富豪」之輩，與獲得豐厚報酬的金融顧問們，共同譜出一場在美國戰後許久未見的奢靡排場。1981年1月，雷根總統的就職大典共花了600萬美元，為這個時代奠定了基調，而引人注目的炫富行為也成為美國夢的活力表徵。紐約的文化紀念建物內，開起一場場紙醉金迷的派對。被當時八卦雜誌稱為「俱樂部」的紐約大都會博物館為了慶祝掠奪者索爾·斯坦伯格的孩子和洛茲集團的蒂西（Larry Tisch）成婚，用了1萬2,000朵鬱金香和5萬朵法國玫瑰來妝點，「其富麗堂皇的程度就跟15世紀西班牙的卡斯提亞與亞拉崗一般，」《浮華世界》(Vanity Fair) 的編輯蒂納·布朗（Tina Brown）如此讚嘆。
