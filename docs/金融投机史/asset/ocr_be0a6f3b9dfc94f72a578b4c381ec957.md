# 庫克的黑色星期四

瘋狂的黑色星期五並未畫下投機時代的句點。其中，鐵路又陸續吸引了龐大的資本。在1865年至1873年間，有將近三萬英里的鐵軌興建完成，總耗費為十五億美元，鐵路系統的規模更擴升至將近兩倍。由於人們預期新的鐵路將為罕無人跡的西部帶來大量的定居人口，因此鐵路四周的房價開始大幅上漲，投資行為也變得更加火熱。當聯合太平洋刊登廣告，推銷哥倫布、內布拉斯加的開發計畫時，利用「讓50元的房子成為5,000元的投資」之類的美好遠景來誘惑潛在投資者，並問他們，「想要輕鬆致富嗎？快到有潛力在未來發展成繁華城市的精華地點買農場！有多少人因為當初沒有在紐約、水牛城、芝加哥或奧馬哈置產而抱憾終身。」

1869年，曾在戰爭期間發行政府公債而賺得名聲與財富的銀行家杰·庫克（Jay Cooke），接管了北太平洋鐵路（Northern Pacific Railroad）公司，該公司在西北部擁有近五千萬畝的土地，比整個新英格蘭還大。庫克決定透過經紀公司的人脈，好好地炒作那塊地。他的首席公關是一名記者，名為威爾金森（Sam Wilkerson），此人將土地形容為「一片廣闊的原野，猶如富有的女繼承人，等著別人占有與享用。」北太平洋在杜魯斯設有火車終點站，而此地更被形容為「淡水海域中的聖城」。不幸的是，儘管經紀公司與公關傾盡全力，此地卻被戲稱為「杰·庫克的避寒勝地」，完全無法吸引投資者。當時，庫克的銀行負責發行價值一億美元的北太平洋債券，而此任務在普法戰爭爆發、歐洲資金停止流向美國後，益發艱鉅。
