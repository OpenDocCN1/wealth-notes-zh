# 方式嬉鬧：

交易所的一名成員張開他的手，另一人握住，如果兩人進行第二次握手，就代表他們將以固定價格成交一定數量的股票。新的握手，代表新的商品出現，中意者跟著出價。手掌因為不停的拍打，而變得通紅（我相信即便是德高望重的人，如果以此種粗鄙的方式行事，也會感到害羞）。握手後接著是嘶吼，再接著是辱罵，辱罵又引發更粗魯的行為與更多的辱罵、嘶吼、推擠和握手，直到所有生意都談定。*

在詩人科頓（Charles Cotron）於1674年在倫敦出版的《賭術典籍》（Compleat Gamester）一書中，賭博被形容為「使人陶醉的魔法，游移在散漫與邪惡之間；一種搖攤難耐的疾病，有些人會抓頭，有些人卻好像被大蜘蛛咬到般，笑到無法自己直至死亡；還有的就像是癱瘓性犬瘟熱，手臂受到牽制，雙手不聽使喚，手肘不住顫抖……讓人無法進行任何動作，更讓當事者對自己的狀況感到由衷地不滿；他要不是為著成功显露欣喜若狂的笑容，就是為著失敗呼天搶地；他的情緒高低迴盪，如暴風般猛躁……隨著輸贏往返交替，滿溢的情緒翻攪激昂，最終喪失心理理智。']
