# 大蕭條降臨

面對殘酷的股市崩盤，美國人倒是沒有失去幽默感。黑色星期二的隔天，老約翰·洛克斐勒宣布他和兒子正在購買「健全的股票」，消息一出，股市穩定了下來。「當然啦，」站在百老匯舞台上的康托爾如此回答，「不然我們誰還有錢買？」據傳康托爾本人也賠了上百萬。康托爾也講了一些自殺故事，他說有兩名投機客手牽著手，從橋上一躍而下，因為他們兩人共用一個聯名帳戶；一間旅館的櫃檯問著前來投宿的旅客，是來睡覺還是來跳樓的。*此外，他也注意到在股市崩盤後，女性的裙擺又再度變長。根據費茲傑羅的說法，「爵士時代結束在戲劇性的毀滅中。」然而，真正的苦果還沒顯現。

# 政府及企業出手救市

儘管股市的跌勢一直到11月中才歇停，但胡佛政府在事件發生的當下，立即嘗試挽救崩盤危機。總統府的公開聲明總是樂觀而開朗。胡佛召來商業領袖，力勸他們維持薪資發放水平，以穩定國內市場的需求；民營與私營組織被要求提出建設計畫；11月，財政部長梅隆宣布小幅調降稅金。銀行方面也立即展開行動。10月31日，聯準會將貼現率調降為5%（兩週後，又調降了0.5%）。過去相當繁忙的通知貸款市場在9月至11月間，掉了五成的量，紐約聯邦準備銀行密切地關注著該市

* 高伯瑞宣稱那些因股市崩盤而傳出來的自殺消息，都只是謠言。然而就在黑色星期四之後，邱吉爾寫道：「在我的窗戶底下，一名男子從十五層樓一躍而下，粉身碎骨，引發了一陣騷動，消防車趕到現場。」馬汀·吉伯特（Martin Gilbert）、《邱吉爾》。
