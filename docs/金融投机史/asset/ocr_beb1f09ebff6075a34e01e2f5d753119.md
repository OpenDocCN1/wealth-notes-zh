# 上有政策，下有對策

在政治人物與經濟學家思考投機行為不受制約所引發的問題時，勢必再次落入一個窘境。如同霸菱（被李森所拖垮的家族銀行總裁）於1825年所言，任何企圖遏阻投機的行動都有可能引發反效果：「解藥自身可能比疾病更危險，如果貿然阻斷一切邪惡，將同時摧毀冒險進取的精神。」

為了制約投機，政府總是利用法律排除投機的工具與操作手法。*然而，投機客往往可以找到規避的對策。對於法律的禁止，投機客僅僅將其視為政府的示弱之舉，行為更因此變本加厲。凱因斯曾突發奇想地提出，如果逼迫人們進行一生的投資（如結婚），如果終其一生都必须為最初的錯誤決策，承擔苦果，或許就可以抑制人們進行投機。他也曾認真地想過，針對短期持有所獲得的資本利得，課徵懲罰性稅金。然而，日本確實曾針對短期房產投資課徵高額的資本利得稅，卻導致市場流動性降低，讓1980年代的東京房價大漲。然而資本利得稅是否會助長股市泡沫，還有待討論，因為股票持有者即便認為股價過高，面對豐厚的獲利，也會寧可抱著股票，不願賣掉。凱因斯也認為應針對美國股票購買課徵交易稅，因「基於公共利益考量，應提高賭博的成本與不可觸及性。」

部分經濟學者認為央行在制定通膨對策時，除了顧慮消費物價，也應將資產價格納入考量。此建議的難處在於沒有人可以明確地確定股價上揚是因為投機活動，而非公司前景看好。

* 儘管人們總是將股市崩盤的責任推給做空者，但過往發生的牛市崩盤事件，多肇因於多頭將股價拉抬至無法維持的水平。然而，從未有政府在股市泡沫期間禁止買進股票。
