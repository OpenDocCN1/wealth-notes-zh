# 不是愚行，是看好產業前景？

奧地利經濟學家熊彼得觀察到，投機狂熱經常發生在新工業或技術出現時，由於人們過分預期獲利成果，因此導致大筆資金流入。或許那些於1630年受鬱金香新潮流所吸引的投機者，確實預期到荷蘭花卉產業的發展（此一市場規模確實堪稱世界第一）。如果真是如此，那麼這些人和後來的投機客一樣，其遠見並沒有得到金錢上的回報。正如詹姆士·巴克（James Buchan）所觀察到的，投機客的遠大理想被自己虛假的時間觀所貶低：「股市大多頭企圖將未來濃縮為短短數天，忽視歷史漫長的進程軌跡，企圖在今日兌現未來的價值。」結果證明，未來往往比投機客所想的難以掌控。
