# 四、小红书批量引流

我把我做私域的思路搬过来做小红书店铺

找兼职来发笔记然后往店铺导流实现店铺的曝光和关键词的优化

只要用户搜索某个关键词看到的都是在推荐我的店铺

每天文案兼职产出文案通过助理分发给代发兼职并在笔记当中推荐店铺评论引导

另外在成交之后会做一个动作就是往自己的私域去导流做售后，因为平台的流量如果不能做到私域

复购的几率很低，所以这也是我做小红书店铺的原因通过更大的曝光来壮大我的私域流量池
