# 7.当出现售后纠纷时，如何妥善解决，将损失最小化？

过来人都知道，电商本身就是一个不容易的行业，有出单，有爆单，就有退货退款，商品不可能每一件都是完美无缺的，当出现售后问题，怎么处理，才能够将损失降到最小呢？一般有售后的情况，我们要按照承诺给买家售后，同时也要及时跟上家沟通，了解上家的退货退款流程，跟上家说明了缘由之后，上家提供退货地址，我们这边再发给客户，客户按照地址退回之后，有了退货单号，我们再补充填到上家那边，这样两边都退，我们也没有什么损失。如果上家有运费险，那就更加方便。
