# 牛奶商已经不满足于牛奶了！

如今，数千万人们都享受着大自然无法带给他们的健康，因为…

一群来自加利福尼亚史密斯河的牛奶科学家，创造了一个牛奶奇迹，他们为美国 6000 万超重者发明了一种比“最完美”的天然牛奶还好的奶！

医学数据表明，由于高卡路里，高脂肪饮食，引发严重肥胖，超重，以及损害健康的美国人越来越多。保险记录表明，换有心血管疾病的年轻人数量十分惊人……原因很简单，他们太胖。

在收集到大量信息后，乳制品行业领袖大卫·d·皮布尔斯带头进行了近 40 年的实验。他们的目标是：发明更方便，更经济的奶粉……一种非常美味的天然牛奶……不过是脱脂形式！

皮布尔斯和他的专家想办法减掉了全脂牛奶里面的脂肪……为的是制作一种全新的脱脂奶粉，能为美国三分之一的超重患者带去健康。37 年后，他们终于成功了——以一种戏剧化的形式。这种奶粉，让科学家都感到惊讶，于是这种奶粉有了一个神奇的名字“魔法水晶”。皮伯斯和它的相关产品，以一种新的形式保留了全脂牛奶中所有的蛋白质，维生素 b 和钙——没有添加任何添加物！这种天然“魔法水晶”与水混合，饮用起来非常美味。最重要的是，“魔法水晶”是脱脂的！“魔法水晶”是现在被称为三花即食脱脂奶粉。

这种新的牛奶奇迹在其他方面也优于普通牛奶——它成本低，而且方便。它能快速溶解，方便存放于橱柜内，所以不用担心放冰箱里太挤。这种新型牛奶可以用于饮用、烹饪、烘焙，快去到你附近的超市购买那种最常见的红色，以及白色三花包包装的“魔法水晶”脱脂奶粉吧。对“最完美”的天然奶都不满意的牛奶商，却对三花即食脱脂奶粉青睐有加，今天就试试吧！（617）
