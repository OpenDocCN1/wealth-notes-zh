# 这款车是我的巅峰之作

R. E. 奥兹设计

对于那些想要更多性能，或更少性能的车主，我无可厚非。我只想说，经过25年——设计24款车型，制造了数千辆车之后——这辆车是我认为最好的。我把它称为我的告别车。

雷奥五代并不是什么特别了不起的创新。

它唯一让你心动的就是它的价格。

它只是展示了汽车的每个细节中，迄今为止最好的。

它展示了通过25年来不断的奋斗，我所能给予的最好的。

这款车没有任何保留。每个细节的处理都是最好的。

中心控制是全新，独有的一个性能。脚踏板刹车——取代了侧杆——左侧驾驶性能，这都是未来的潮流。

我认为这是接近终极的一款车。
