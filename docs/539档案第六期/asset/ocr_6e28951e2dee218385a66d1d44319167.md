# 制造立可舒需要 336 个小时

# ——但是，第一瓶免费

为了研发立可舒独特的功能，我们花了 14 个昼夜。在这期间，我们投入了巨大的设备，技术和人力。两个星期后，我们从 1250 立方英尺的气体中提取出了 1 立方英寸的立可舒。

制作立可舒，一直是科学家和化学家 20 多年的研究主题。目的是从气体中提取出杀菌，滋补，营养神经和血液的物质，并把它们转化成稳定的液体形式。

最主要的结果就是先溶解在液体中，然后进入血液，这是一种强有力，却不会造成任何伤害的杀菌剂。并且这种产品对于任何状况下的人都有帮助，甚至一个身体健康的人都能立刻感觉到它的效用。

立可舒并不像药物那样通过酸性物质和药物混合而成，也不含任何酒精。立可舒的优点完全来源于气体，大部分由最好的氧气生产商制造。里面除了气体，什么都没有。
