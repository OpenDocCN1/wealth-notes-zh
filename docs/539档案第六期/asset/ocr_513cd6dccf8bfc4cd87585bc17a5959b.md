# “送我一个爱阅读的人！”

一个在午餐时间捧着书看的电话线路工人，不会做电话线路工人太久。

他早晚会成为公司的管理层。每次他拿起一本书，他离自己的目标就会越近一步。

国际纸业最新研究显示，读书是通向成功之路。我们研究了 100 位曾经是电话接线员，电话转接员，或程序安装员，这些人现在都成了电话公司高管。

这些人，每个月都会抽时间阅读平均 1½ 本书。而且 1 周会读 3 本杂志，14 份报纸，结论不言而喻：

阅读更多的人成就更大

这些人在坐到今天的位置之前很早，就开始利用业余时间阅读了。而且，在大多数情况下，这是一个漫长的道路。某公司的董事会主席，就是以一把锄头和一个铲子开始的职业生涯。

一个星期读一本书，可能无法让你成为董事会主席。但是，它会让你朝着那个方向努力。而且，你在一个月的时间内，能做到的事情，肯定会让你自己也感到惊讶。

下次，你有几分钟业余时间时，把它用来投资吧。步行到最近的书店或图书馆。这可能将是走过的最好的路。
