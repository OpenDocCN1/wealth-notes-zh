# 塞维尔故事：
对抗 42 年的气候战争
科学最终取得胜利

一个在美国任何气候下，都能持久耐用数年的外墙涂料的研发故事！

在纽约塞维尔附近，有一片荒凉，安静的草地。在草地中心，有一排排上好涂料，像栅栏一样的隔板，仅此而已。

但在这个安静的草地上，一场激烈的角逐持续了 42 年。最后分出胜负。或许在那片草地上发生的事情不值得在你们当地报纸上刊登。但是每一位在乎房屋保养的人，都和那里发生的事情休戚相关。

这场战争中，敌对双方分别是涂料和天气。天气似乎很占优势，因为这些测试“栅栏”上的涂料，几乎只有 2/1000 英寸厚，而天气却千变万化，从冻雨天气，到寒冬，到酷暑。温度和湿度的变化非常频繁，而且突然。

最糟糕的天气状况，带来了科学最大的进步——国家领导公司的科学团队，制造出了“荷兰小子”外墙涂料。

天气会对外墙涂料产生什么影响呢？为什么外墙涂料会褪色、起泡、起白斑、或落皮呢？水汽，干燥，炎热或严寒，会对涂料产生什么影响？粉刷一次涂料，能坚持多久？“栅栏”必须回答所有这些问题，科学家在露天环境下，每天会做超过 25000 次“测试”。根据测试反馈，他们开始在“荷兰小子”实验室进行研究。很快，他们会制造出新的涂料，刷在“栅栏”上，继续和天气战斗。
