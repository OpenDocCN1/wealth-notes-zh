# “年轻之城” 帮助西尔斯 研发出了孩子耐穿的鞋

西尔斯·罗巴克公司在最现代化的设备上测试它的产品。但是，为了测试童鞋，西尔斯还增加了一个条件：让孩子们亲自试穿。看这些孩子是如何帮助西尔斯研发出了不起的新鞋。

伊利诺斯州，德斯普兰斯玛丽维尔大学西尔斯实验室，有超过 600 位调研助手。西尔斯请“年轻之城”的儿童试穿他们的鞋，一年试穿 1000 双。西尔斯从这项测试中学到了什么？如何制作出更好的童鞋。就拿 X-15 童鞋来说吧。

玛丽维尔的儿童穿上了 X-15 童鞋。这些儿童穿鞋经常刮坏鞋底，磨损鞋面。但是，X-15 的耐穿时间，比西尔斯知道的其他任何鞋的耐穿时间都长。X-15 童鞋的品质给西尔斯实验室留下了深刻印象，他们把它称为西尔斯四星级产品。

现在，你在西尔斯能买到 5 种风格的 X-15 童鞋——全在 7 美元以下。每双鞋都享受以下保证：鞋底和鞋跟保证比鞋面耐穿时间长，否则会免费为您更换一双新鞋。

X-15 童鞋是去年在西尔斯实验室测试过的超过 20000 件产品之一。这个实验室对任何不符合标准的产品都有绝对的否定权。被否定过的产品，西尔斯会拒绝出售。

西尔斯的产品都物超所值。你购买的产品价值会让你惊讶。由于西尔斯科学家的不断努力，以及像玛丽维尔的这些孩子们的帮助，西尔斯的产品一直拥有很高的价值。

玛丽维尔的孩子们一年都在测试西尔斯童鞋。他们测试的耐穿童鞋 X-15，在西尔斯商店及目录册中都能找到。记住，你可以用账户购买。
