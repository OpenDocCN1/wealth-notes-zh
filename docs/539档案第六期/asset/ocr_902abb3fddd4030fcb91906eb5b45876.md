# 关于膨化谷物的童话故事

当你为家人准备一顿加牛奶的膨化谷物时，它就成了你的故事。
美得像童话。

每个谷物泡泡，都由小麦内核膨化到正常大小的 8 倍而成。这些轻而薄的谷物泡泡，都是通过蒸汽膨化，并从枪里射击出来的。

# 1 亿次爆炸

每粒谷物，随着它的生长，都会包含超过 1 亿个食物细胞。每个食物细胞都是坚硬，中空的。并且包含少量水分。每个细胞都必须破碎，才能被人消化。

其他烹饪方式，可以打破部分食物细胞，但数量不会超过总量的 一半。所以，安德森专家，一位著名的食物专家，想到了一个把所有食物细胞全部打破的方法。

膨化谷物就是采用他的 方法制作而成。将谷物颗粒密封在枪支中，高温中旋转数小时。这样，每个谷物细胞中的水分，就会转化成蒸汽。

然后，开枪。所有谷物细胞都爆炸了。所有谷物都成了你看到的泡泡状。

这种方法，可以使整个谷物都非常容易被消化。每个元素中的每个原子都是食物。这就是为什么许许多多的妈妈们，每个早晨和晚上都会给孩子准备这种谷物。
