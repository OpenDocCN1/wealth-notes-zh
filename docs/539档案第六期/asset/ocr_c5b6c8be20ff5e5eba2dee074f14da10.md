# 你的家庭早餐存在这些问题吗？

你一天的成功或失败通常取决于你的早餐。早晨，你需要一顿营养均衡的早餐，唤醒身体。

否则，你上午肯定会感到疲惫或烦躁。

那么，早餐应该吃多少？它应该提供占全天至少四分之一的身体必需营养物质。你的早餐应该包括各种水果；全麦面包或由麸皮面粉制成的面包；麦片；鸡蛋，肉或鱼；牛奶，直接喝或加入麦片中吃。

家里的每个人，都应该享用这样的早餐（还可以加入一些自己喜欢的东西，比如咖啡或茶）。

试一段时间。你很可能会注意到自己精力更好了，而且；上午十一点左右，你会感觉比以前精神更好。

即使你在减肥，也不要不吃早餐。没有早餐，你中午或晚餐可能会吃的过多。这会破坏你的减肥计划。

我们所有人，不管是肥胖者或正常体型的人，都应该花时间吃一顿营养丰富，悠闲自在的早餐。这是让家人更健康的一个好方法。
