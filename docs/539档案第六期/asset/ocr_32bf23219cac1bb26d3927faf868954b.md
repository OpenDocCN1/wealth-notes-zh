# 一匙就白

# 家庭主妇的新福利

# 来自：杰·C·哈里斯

你知道吗？每 10 个美国家庭主妇中，只有 2 个人会遵循或阅读包装上的指示。如果你觉得难以置信，请回忆一下……上次你用自动洗衣机洗衣服时，直接倒的洗衣液，还是量好后才倒的？

失之毫厘差以千里。比如，如果你是一个 5 个孩子的妈妈，严格遵循“全力”包装背面上的指示，就像你遵循蛋糕粉后面的分量指示一样，一年下来，你节省的钱，够你度假时支付 300 英里的汽油钱了！

很惊讶吧……但这是真的！因为“全力”可以让你用一匙的洗衣液，就把衣服洗得干净，洁白！“全力”是一款超浓缩，易冲洗，“低泡沫”洗衣液——专为自动洗衣机设计，力求最佳清洁效果。

这种制造“低泡沫”的创造性化学物质中，现在还加入了 AE-160，解决了洗衣日最大的抱怨问题：白衣服总洗不白。

代顿孟山都实验室证明了衣服亮白新发现，AE-160 的效果。在这里，棉花，亚麻，甚至尼龙——因为肥皂水或穿着多年而变黄——不用漂白，就能直接清洗的和新的 meint 一样洁白！当遇到顽固的污渍，或严重被染了色的白色衣服时，用家用漂白剂，配合全力洗衣液，衣服会更加洁白。

现在，有了加入 AE-160 的全力洗衣液，你不用漂白，就把发黄的纯棉，亚麻制品，尼龙长袜，甚至可洗的祖传面料，洗回洁白的颜色。
