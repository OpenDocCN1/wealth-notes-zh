# 为什么没人能否定西尔斯实验室？

西尔斯·罗巴克公司通过建立世界上最大的私人实验室测试产品，为你提供更物超所值的商品。在这个实验室，西尔斯检测他们的产品质量；改进旧产品；开发新产品。

西尔斯欢迎顾客提出问题。

但是，在他们问的问题中，很少有像西尔斯在产品上架前，问自己的测试实验室的问题那么透彻。

这种面料真的不褪色，不缩水吗？这款自动换片装置能用多久？哪种洗碗机更有效，“A”或“B”？

每年西尔斯实验室都会回答上千个类似的问题。它根据科学测试，提供客观的事实。

西尔斯超过三分之二的员工都是化学专业，物理专业和工程专业毕业。他们提供的信息，常常会帮助公司改进产品——这就意味着你花同样的钱，能得到更好，更有价值的服务。

更重要的是，西尔斯实验室对任何不符合公司高质量标准要求的产品，都有绝对的否决权。所以，假冒伪劣产品几乎不可能进入西尔斯商店，或西尔斯目录册。

西尔斯实验室自 1911 年成立以来，已经耗费了 50000000 美元的成本。但是，西尔斯的这个投资获得的是最大的回报——客户的满意。
