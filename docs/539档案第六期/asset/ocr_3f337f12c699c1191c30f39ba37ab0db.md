# "送我一个爱阅读的人！"

国际纸业在时速 600 英里下，对培训泛美飞行员的决策人的访问

首席飞行员山姆·米勒告诉，想成为航空公司机长需要什么品质——为什么阅读对成为航空机长有帮助。

快速起跑，短跑道，交通干扰——房间左侧的飞机模拟器，可以让他们不离开地面，就面临在飞行中可能遇到的所有问题。

这就是山姆·米勒的“教室”——波音 707 客机的驾驶舱的真实复制品，246 种仪器一应俱全。

# 飞行员怎么做家庭作业

他们阅读。米勒的学员必须阅读并学习气象特征和 250 种机场着陆的方法。他们必须阅读一套超过 800 页的手册，并不断了解新信息。

米勒说：“这个行业千变万化，发展很迅速。只有一个方法能让你跟上时代变化：阅读。”

# 语言和法律

“在短短一天时间中，我的一个学员可能会在多达 5 个不同的国家的土地着陆。为了应对在不同国家可能遇到的一切法律、政治和技术问题，飞行员需要有丰富的经验，广泛的阅读——不停地涉猎各类信息。”

怎样才能成为航空公司的机长呢？“这个很难用一两句话说明白，”米勒说道，“但是我发现他们有一个共同点，那就是通过培训，实际飞行，阅读，不断学习的能力。”
