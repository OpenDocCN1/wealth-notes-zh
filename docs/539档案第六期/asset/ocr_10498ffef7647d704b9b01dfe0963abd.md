# 临床研究发现，大多数超重的人都缺乏这 8 种能燃烧脂肪的营养

# 现在一种能为你提供 8 种燃烧脂肪的营养元素的药片出现了

来自：约翰·怀特黑德 媒体服务

（坎顿，俄亥俄州）你有没有感觉到，你明明没有吃很多食物，但是体重还是莫名其妙地上升？新的研究发现，这并不是你的错觉。

临床研究表明，很多超重的人缺乏特有的营养素来有效地燃烧脂肪。这些研究，曾被很多知名医学期刊引用，包括《美国临床营养学杂志》，《国际生物化学杂志》，《新英格兰医学杂志》，以及《当前疗法研究》和《国际肥胖杂志》。知名大公司，生物技术研究公司，也对一些人群进行了研究测试，这是其中一些研究照片。

这些研究发现，大多数超重的人摄入的卡路里，并不比那些不超重的人多。大多数超重者都缺乏以下 8 种使身体燃烧脂肪的营养。左卡尼汀，吡啶甲酸铬，胆碱，肌醇，生物素，胰液素，甜菜碱酶，和维生素 B6。这些营养物质只存在于某些食物中，你必须摄入足够的这类营养物质，来充分燃烧脂肪。

进行充分研究后，生物技术研究公司制造了一种，能为你提供这 8 种燃烧脂肪的营养元素的药片。
