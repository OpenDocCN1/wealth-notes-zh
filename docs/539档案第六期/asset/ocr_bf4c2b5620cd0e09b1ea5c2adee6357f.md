# 6000 万超重的美国人，是不是错过了最简单，最安全的减肥计划？

# "事实" 减肥法成功了，
而 "流行" 减肥法失败了！

# 来自：罗伯特·S·克莱克纳

据保险表显示，我国成人群体中，将近一半的人都超重，这个事实令人忧心。然而，从医学的角度来看，大多数超重的人，想减肥都很容易……而且轻松，不反弹。

在减肥之战中，我们要面对一个基本事实，那就是大多数情况下，超重是暴饮暴食的直接结果，这是一个不争的医学观点。“减肥”已成为很多人的习惯。任何时候，估计都会有 1600 至 1700 万减肥的人。难怪，一些时尚或奇迹的减肥方法，总能吸引一大批人。

当然，另一个无可争辩的事实是，要减去多余的脂肪，并保持身材，你必须减少每天的卡路里摄入量。更少的热量，更轻的体重……就这么简单。因为，当你一天的摄入超过你身体每天能消耗的卡路里时，脂肪就会开始堆积。

但是，如果摄入量在基础代谢范围内，你就能保持体重，还能享受美食。你真正喜欢吃的食物，能为你提供身体所需的营养和能量。当然，一顿太餐就吃掉你身体一天能消耗的卡路里，不是一个明智的做法。特别是，不好好吃早餐。

事实上，营养专家一直建议，减肥者每天都要吃营养的早餐。这就催生了高蛋白燕麦片早餐。因为，一般一顿加了糖和牛奶的热腾腾的美味燕麦片早餐，热量只有 210 卡路里……它包含了 9 克高质量的蛋白质。
