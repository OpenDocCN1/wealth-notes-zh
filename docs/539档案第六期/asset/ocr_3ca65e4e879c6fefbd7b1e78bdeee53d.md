# 你拥有汽车……还是汽车拥有你？

来自：乔治·罗姆尼
美国汽车公司总裁

如果你生活预算总是超支，罪魁祸首可能是你的汽车。

据调查显示，一般家庭会花税后收入的 10%，来维持这个家庭“大巴”的开销。有些家庭耗油量大的车，可能会占到家庭开销的一半。超重，昂贵的汽车，让数百万家庭“破产”，因为这些汽车拥有家庭，而不是家庭拥有汽车。
