# 灰衣女士

在做完一整天的例行工作后，还要精神抖擞，为他人缓解忧郁，并不是一件容易的事情。然而，我们宾夕法尼亚州阿伦敦工厂的伊莱恩·杰雷格，作为美国红十字会的灰衣女士，却已经坚持做这件事情很久了。

日复一日，作为红十字会的志愿者，伊莱恩每周都会去阿伦敦医院……兼职照顾儿童病房的孩子，陪伴没有朋友的病人，宽慰孤独的人……不管她到哪里，都能为人赶走孤独，缓解思乡之苦。

她得到的回报是什么？孩子的笑……病人开心的眼神，以及她为自己生活和工作的社区做出贡献的成就感。

像伊莱恩这样的社区志愿者，在我们西电气公司全国各地的工厂，配送中心以及安装中心 120000 名员工当中有很多。

比如，杉矶配送中心的拉尔夫·劳森洛，17 年来，他一直是童子军的活跃分子，获得了最高荣誉———等功勋章。

或是芝加哥工厂的阿尔贝里，多年来一直担任他的家乡俄亥俄州，内伯威尔市基督教青年会的董事会成员，同时也是教育委员会的成员。

或是纽约工厂的海伦·沙利文，她帮助残疾人研究所策划各种娱乐项目，帮助那里的学生编辑报纸。

许许多多的人，都在无私地奉献着：丹佛安装集团的阿特·奥顿，活跃在科罗拉多州阿瓦达的社区生活中，在那里他担任着市议会议员和商会的成员；或去年为了筹到对抗肌肉萎缩症的资金，去 了马里兰的切特·菲利普斯。
