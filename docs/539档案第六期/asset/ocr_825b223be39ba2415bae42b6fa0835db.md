# 癌症......就像星星之火......

# 需要立刻采取行动

当你发现问题——癌症通常会有一些早期预警征兆——请立刻去看医生。

早看医生，治愈的几率就会大大提升。事实上，据估计，如果所有癌症病人尽早进行充分地治疗，一般都能被治愈。

立即采取行动，是你个人预防癌症最重要的措施。幸运的是，医学还为我们提供了其他对抗癌症的方法。

一个明显的例子就是，一次简单的检测——我们常说的“子宫颈抹片检查”——通过这个检测，常见的一种女性癌症就可以早发现，甚至在症状出现之前就能发现。如果每个成年女性每年做一次这种检查，检查出来的这种癌症，几乎都可以被治愈。

此外，你的医生经常会检测到其他形式的癌症——包括男性和女性——这种疾病一般都是局部的。在早期阶段，通过手术治疗，x射线和其他形式的辐射治疗，就有可能成功治愈。

因为，早期检测是发现癌症的一个重要途径，所有成年人都应该定期健康检查，在两次检查之间，要观察这7个癌症征兆：

+   1. 不正常的流血或膜泻

+   2. 乳房或其他部位有肿块儿或增厚

+   3. 莫名疼痛，无法治愈

+   4. 肠道或膀胱有改变

+   5. 声音嘶哑或咳嗽
