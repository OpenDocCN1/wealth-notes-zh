# 眼镜：新身份的象征？

社会对洞察力和智慧的尊重，带来了很多事物的繁荣，其中一个就是眼镜。它们不仅是身份的象征。继续往下读，看看为什么越来越多的人在未来12个月内，去做了眼睛检查。

事实：3年前，一个迷人的年轻女演员因为没戴眼镜拒绝电视采访，让专家们目瞪口呆。今天，她成了电视名人。她的—个特色就是——她的眼镜。

事实：一位崛起的纽约高管，前途无量，他的视力特别好——但是，在重要会议上，他总是戴着眼镜。他说，眼镜让他感觉更安全，让他的发言更有分量。

事实：来自4个不同社区的报道说——年轻女孩子“热捧”眼镜。并不是她们所有人都需要眼镜，而是她们觉得眼睛让自己看起来更成熟，能给朋友们留下深刻印象。

这些是1863年视力表出现后，眼镜最繁荣的许多事实中的3个小例子。令人吃惊的事实：现在83000000美国人都戴眼镜。

繁荣的背后是什么？一位著名心理学家给出了如下解释。

# “眼睛归属感”
