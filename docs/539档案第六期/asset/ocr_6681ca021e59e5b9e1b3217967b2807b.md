# 安家的快速方法

“去年，我们也是3200万背井离乡，到别处安家的美国家庭之一。因为我们公司新开了一家分公司。我们不仅搬了家，还转遍了大半个国家。

“实际上，我们当时也没遇到什么困难。在搬家之前，我们就学会了快速安家的方法，就是通过我们的教会和社区活动交朋友，经济上，则通过和银行的人交朋友来解决。

“安家时，我们的银行给了我们很大的帮助。我们首先开了支票和其他一些省钱账户。之后，我们得到了贷款和其他家庭银行服务。我们再次发现，通过这些方法，我们在社区建立了诚信，成功立足，这是任何别的方法都做不到的。

“我们似乎因很多事情聚在了一起，现在‘家庭银行’像‘家庭医生’一样，对我们都给予温馨帮助。”

通过家庭银行的很多服务，你可以用你的钱做更多的事请：

+   1. 确保你获得存款利息，任何时候你都可以随时取出。
2. 节省时间和金钱——当你通过支票支付账单时——可以获得永久的记录。
3. 用最低利率的贷款，建造，购买或装修房屋。
4. 通过个人信贷，满足其他家庭需求——新车，大学学费，突发状况。
5. 帮助企业发展——不管是农场，工厂，商业或专业研究——通过轻松贷，以及经验丰富的顾问的帮助，都能帮助你的企业成长。
