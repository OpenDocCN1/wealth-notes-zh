# 在大脑里带一本电话簿

这个课程将教你如何把你想记忆的任何数据转换成图形——然后，把这个数字图形永远刻在你的脑海里。

比如，用这个简单的方法，你就能在短短 30 秒内，记住任何一个电话号码（包括区号），而且永远不会忘记（即使你脑海里已经记忆了多达 100 个电话号码）。

或者，如果你稍微灵活应用一下，就可以把这个 “图形数据记忆法” 应用于扑克牌上，你的朋友们肯定会拒绝再和你用钱下赌注玩牌了。比如，在桥牌中，叫人任意隐藏 47 张牌，你都能轻松立即说出任意 5 张隐藏的牌数。

或者，你可以记住整个价目表，通过在客户办公室快速引用一系列数据，赢得一笔又一笔的订单。
