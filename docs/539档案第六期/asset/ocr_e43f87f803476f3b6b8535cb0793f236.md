# 在短短 4 周内

# 培养你做梦都想不到的超强记忆力！

坦白地说，这是一个几乎令人难以置信的广告，内容是“有史以来，最具爆炸性的记忆课程。”

它由哈瑞·洛拉，世界上最伟大的记忆专家创造。它——有史以来第一次——为培养普通人令人难以置信的超强记忆力而设计。具体表现如下：

# 永远不会再忘记任何人的名字！

首先，一旦你学完这个具有革命性的新记忆课程，你就永远不会再忘记任何一个，对你来说重要的人的名字或相貌。即使你已经 5 年……10 年……甚至 20 年没有见这个人了，但是你见到他之后，依旧可以叫出他的全名，和他打招呼。你能清楚地记得他的妻子，孩子的名字。你能清楚地记得他在公司的职位，他最大的兴趣爱好，如果你想给他留下印象，你甚至能记得他的生日。

（让我们再重复一次：我们意识到这么超强的记忆力，对现在的你来说，肯定不可能。但是，我们还意识到，如果你用完全错误的方式，试图记住这些信息，也是不可能的。一旦你知道了正确的方式，不可能就会变得可能，变得司空见惯。现在，你可以零风险去证明它们！

现在，让我们再说一个你能拥有的“看似不可能的”超强记忆力：

# 读一遍，就记住整本杂志！
