# 汽车的引擎

# 应该在前面，还是在后面？

发动机前置和后置的区别很大。驾驶发动机前置的汽车，和驾驶发动机后置的汽车也完全不同。经过汽车工程师们最近对许多汽车的测试，得出了以下结果。这些测试结果对美国的每位驾驶员都非常重要。

首先，测试中，发动机后置的汽车后部都明显沉重。这样不平衡的设计，会产生一种危险的驾驶特性，被称为“转向过度”，可能会放大横风，甚至减速带对汽车的影响。在畅通无阻的现代化高速公路上，汽车通常会受到强烈的横风冲击，发动机后置的汽车会变得难以控制。

另一方面，西姆卡这样的前置引擎汽车则正好相反。它们能够抵消减速带带来的颠簸，能对抗横风的冲击。这两种汽车产生这种差异的原因在于，它们自身重量分布的不同。

因为前置引擎汽车更容易控制，所以和后置引擎的汽车相比，它们带给驾驶员的疲劳感更少。

进口的后置引擎汽车和西姆卡相比，还有很多需要改进的地方。西姆卡以压倒性优势超过它们。西姆卡更长、更宽、更强大。西姆卡内部空间大，即使售价最低的款型，内部空间也能容纳下 5 个人。（东部及墨西哥湾进口港售价 1698 美元。内陆运费和地方税收额外计算）。

整体性能上根本没有可比性。《速度时代》杂志说，“西姆卡出色的抓地能力首屈一指。”《汽车生活》杂志说，“西姆卡在拐弯时十分平稳，就像在轨道上一样。”《跑车说明》杂志说，“西姆卡的性能完胜同价位其他车。”
