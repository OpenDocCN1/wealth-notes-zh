# 一位纽约医生在治愈肥胖上，取得了引人注目的新突破

# 10000 名患者成功快速减重，从未挨饿！

# 我在短短的 2 个月内

# 甩掉了 85 磅的丑陋脂肪

是的，这是我的惊人故事。在短短 60 天内…我没有节食…没有计算卡路里…从未挨饿…绝对安全地减掉了多余的 85 磅。

1967 年夏天，我无意中看到一位纽约内科医生的报告。他在报告中说，他曾帮助 10000 名超重的男性和女性，成功地减掉了他们想减的体重。这些人包括医生、护士、营养师、人寿保险专家、演员、棋特，和其他不论如何努力，都从未成功减肥的人。

然而，在减肥期间，这些人可以想吃多少就吃多少——不用计算卡路里。他们可以和以前吃的一样多，甚至可以比以前吃的都多。他们从来没有挨饿。根据这个方法，在第一个 3 天里，他们就看到了惊人的效果，下降的体重，让每个人都觉得难以置信。有些人，第一周就减掉了 25 磅。在仔细研究完这个医疗报告后，我决定试一试这位医生的方法。

我开始遵循这个医生的 foster 计划，结果令我大吃一惊，我前 3 天，减去的重量，比我之前几乎不吃任何东西，减去的重量都多。在看到 3 天中这样惊人的结果后，我继续按照这个方法减肥——从来没有挨饿过一次——在短短 2 个月内，我一共减了 85 磅。

这个快速，显著的减肥方法，没有给我带来任何不良影响。我试过很多次通过节食挨饿的方法减肥，但是这个方法——不用计算卡路里，第一周就减去那么多，给了我坚持下去的信心。

现在我可以想减多少减多少，我希望你也可以。是的！我吃的越能满足我的身体，我减去的体重就越多。
