# 婴儿死亡，一个令人担忧的问题

来自：盖恩·威尔伯恩，医疗新闻作家，《休斯顿纪事报》

在德克萨斯州乘一种新的威胁到来之前，已有 16 个婴儿被夺走了生命。

如今，一篇又一篇关于医学与致命的葡萄球菌的战斗文章陆续被发表。新生婴儿和母亲受金色葡萄球菌感染的威胁最大。还有一个严重的情形，就是医学人员发现新的耐抗生素葡萄球菌越来越多。

最近，一篇医学杂志指出，医生注意到，金色葡萄球菌引起的导致婴幼儿死亡的皮肤感染，胃肠道和肺部疾病有显著的复苏迹象。

葡萄球菌感染，可能由直接接触或通过污染的日常用品而引发。仔细清洁，尤其双手，是防止直接接触感染的一个重要方法。

任何人，不管健康与否，都可能携带金色葡萄球菌，并把它沾染到最干净的物体表面。你可能通过接触污染的水龙头，碗，盆或浴缸而感染到它。浴室里已经成为一个传播感染的危险地区。

所以真正的消毒液，应该能用作浴室清洁剂。和其它所谓“消毒液”相比，来苏尔能够杀死它所接触到的所有病菌，包括葡萄球菌。

通过实验室的测试，使用来苏儿消毒液消毒 7 天后，它依旧有抗病菌效果。这就是为什么来苏尔在每周打扫洗手间显得如此重要。在你的清洁剂中，滴几滴来苏尔，消毒效果能持续到下周。
