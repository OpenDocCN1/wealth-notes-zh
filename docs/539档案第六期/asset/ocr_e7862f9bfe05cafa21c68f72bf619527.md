# "他下一步会遇到什么？"

# （关于儿童的最大敌人——事故）

对小男孩和小女孩来说，世界上的 一切都非常有趣。但是，在他们探寻“十万个为什么”的过程中，有很多小孩子都会因此受伤，残 疾，或发生意外死亡。

研究证明，绝大多数儿童事故本来都可以避免。比如，因为误食中毒而意外死亡的，通过采取下列简单的防范措施，就可以避免：

+   把所有药物放到上锁的抽屉或箱子里。

+   销毁所有临时使用后剩下的处方药，不要把它们随便扔进孩子可能会触及的废纸篓里。

+   把所有消毒剂、杀虫剂、家具清洁剂、漂白剂、金属清洁剂、碱液、氨和酸等，都放在孩子接触不到的地方。

+   把所有有潜在危险的有害物质放在他们原来的包装盒中。不要把它们放在没有标签的容器中，尤其是那些可能会放置食物或饮料的容器。

+   仔细阅读所有标签，谨遵上面的危险提示。

+   找找你附近是否有毒品控制中心。这些中心会帮助医生快速识别有毒成分，并给出应急方法和治疗，从而拯救生命。
