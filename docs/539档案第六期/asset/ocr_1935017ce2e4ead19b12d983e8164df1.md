# 谁拥有西尔斯？

西尔斯·罗巴克公司有超过 158000 位股东。到目前为止，西尔斯的最大股东——持有西尔斯 1500000000 股——西尔斯员工利润股份基金会。这种员工和公司利害相关关系，正是西尔斯人会竭诚为你服务的原因。

如今，超过四分之一的西尔斯股份——约 20000000 股——为西尔斯员工储蓄和利润股份养老基金会所有。

超过 99%符合条件的西尔斯员工（在西尔斯服务一年），都是该基金的成员。他们从退休基金得到的养老好处，可以带给他们退休后经济上极大的安全感。

利润股份，给西尔斯人不仅带来了工作上的自豪感：而且还有所有权的自豪感。公司取得成功，他们获得股份，能让他们的责任感更强。

这种自豪感和责任感体现在了西尔斯人竭诚为顾客服务上。体现在了西尔斯人的友好，乐于助人的态度上。体现在了西尔斯快速，准确地为顾客投递商品上。体现在了西尔斯测试实验室科学家们谨慎的态度上。

当然，个人利益，绝不是西尔斯人愉快地为你服务的唯一原因。但，它确实给了西尔斯人一个强大的诱因。

他们知道——通过满足你——他们就能过的更好，得到更多的养老金。
