# 怎么做检查

如果你想检查下你的眼睛，那现在是最好的时机。你只要打电话预约任何一位著名的眼科医生。所用时间，不会超过一次牙齿检查，而且成本很少。

越来越多的各种领域的高层人士，从女演员到运动员，都有定期做眼睛检查的习惯。他们像体检和牙齿检查一样，定期检查眼睛。很容易记住。

# 眼睛应该多久检查一次？

遵循眼科医生的建议。权威专家说：

儿童：在开始上学前，一年检查一次。（学校例行的眼睛检查，没有那么全面。）

成人：40 岁以下的人，至少两年检查一次。40 岁以上的人，至少一年一次。
