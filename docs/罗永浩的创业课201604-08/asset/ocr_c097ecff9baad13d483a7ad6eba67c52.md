从昨天天的媒体课里，我一句话摘，大家喜欢这个东西，因为，“我们的头脑就是被设计成这个样子”的，这是什么意思呢？下面我从三个方面来解释一下：

内啡肽就是一种为我们提供舒适、快乐和美好感觉的神经递质，除了产生愉悦感，它甚至还有止痛的作用。这一一定程度上也解释了为什么小孩子摔得擦破哭号啼时，大人会去逗孩子笑，孩子被逗笑了，笑上一会儿，就也没那么疼了。而且相比较而言，通过笑获取内啡肽的分泌，要更胜高效和经济；你笑上一会儿，要比起跑步上半天风，按摩师捏上个把小时，或是吃四四川火锅吃得满嘴起泡得多。

现代的进化心理学认为，有趣好笑的事物常常伴随着某些不协调的、新奇的、或是独特视角的东西。一般说来，没有受到启发，自己却能发现这事物的的人，通常要更高的认知水平，进化会激励这种更正当的能力。比如，老师在黑板上画了两座山头，小学生照着画，大部分孩子会老老实实的画。有些早慧的孩子会从山头的曲线，联想到乌龟壳、甲虫壳、女人胸和屁股等，于是就没啥嘻嘻哈哈画成了这些东西，并且拿给小伙伴们看，一起高兴了半天。具有这种特质的孩子，貌似也没什么意思，无非也就是被别人认为有“有意思”、“好玩儿”、“调皮”等等。但是从概率上，他们在长大后，比起那些不具有这种特质的孩子，更容易从某种非线性的曲线里受到启发，发现流体力学、空气动力学最开始的原理之类的，因为这种人通常具备直觉性的才能和更高的认知水平。当然，这种结果有时候是不可控的。他们也可能长大后，成为色情漫画的画家。

能够理解笑话，也是脑力健全的一个重要表现。听到理解笑话后，大脑的活动会更加活跃。有些智障的病人，比如阿斯伯格综合症状的患者，常常是无法理解笑话和双关语的。

# 2. 为什么不建议那些原本缺乏幽默感的人去努力锻炼讲笑话的能力？

所以教你演讲的培训机构，要远多于教你讲笑话或培养幽默感的培训机构。

所以演讲培训班招生的时候不挑学生，但是演讲培训职业的表演培训机构，也不像演讲培训职业的表演训练那样，对入学的学员筛选得那么严格苛刻。而且受过专业训练的演讲者上台演讲，获得一个基本的能力可通通常是没问题的；一个受过幽默感能力提升训练的人上台讲笑话，下酒却感到冷场，是时有发生的。对于幽默感的训练，马克·吐温有一看法，他说：“研究分析幽默，就像解剖一只青蛙，也许你能收获很多东西，但最后得到的只是一具青蛙的尸体，而不是青蛙。”这句话供你参考。

提升生存能力的学习和训练，整体上要合理的权衡自身的优势和劣势。一般说来，一个天生幽默感欠缺的人，我们不建议他/她投入大量的精力去尝试提升讲笑话或表演喜剧的能力。就像对一个长得又胖又丑的男演员，你通常不会建议他去性感、冷峻的路线。我们的时代，心灵鸡汤和骗子精神导师泛滥的结果是，很多人都喜欢非理性地去求一米六零的NBA球星某某来说事。对此，我的看法是，如果讲好笑话是你无论如何都要实现的梦想，那就去做，不要管别人怎么说，甚至不用管结果。如果没到那个程度，那你去看看NBA历史上，有几个低于一米八的球星。

# 3. 一个天生幽默感欠缺的人如何在演讲中解决这个问题？

讲的难度比创作难度要低得多。如果一个讲者上台引起哄堂大笑的笑语，你听了那没人在，那肯定是不行的。如果你跟朋友们讲一个听来的笑话时，大家都能笑起来，但你上台讲时观众没笑起来，那只能说明你讲得太机械了，导致观众从某笑笑的感受，变为分享能力的作用，转希望尽早结束尴尬的方向上去了。这种情况是有办法解决的，你只要反复练习当众演讲，直到演讲时你听放松，一旦放松了，你本来就能让大家听了笑话笑起来，也就能让演讲的观众大笑起来。

那如何才能为一场演讲，去找高品质的笑话呢？你肯定不能像春晚相声演员一样，去炒网络上的流行热门段子，这太蠢了。大家可能听过的笑话都不好笑，这道理谁都知道。那怎么办呢？最常见的方法是：

+   1. 找英文世界里面非常流行的热门笑话，但还没有传到中国来的，如果你英语没问题。用谷歌搜一下相应的关键词就好了。

+   2. 谷歌里设置搜索的时间限制，比如指定搜索2000年到2001年之间的中文网页内容，然后输入“十年笑话”之类的关键词，你会找到中文世界将近二十年前流行的热门笑话，试试将它给你的同龄人听，你会发现很多都是他们从来听说过。

其次，可以试试作家大卫·尼希尔提提供的方法，他采访了几十个喜剧演员，问他们对那些幽默感欠缺的人有什么建议。多数喜剧演员的建议是，如果幽默感欠缺，不要讲笑话。

如果你缺乏幽默感，那些幽默元素不会让观众笑起来，那也谈不上什么了；观众还是得到了一个含义深刻的故事，如果他们的故事的时候，因为故事本身的幽默元素，竟然同时笑，那你就赔了。我觉得这是个同题，这是你听过最有智慧的建议了。那如何讲一个这样的故事呢？我会在后面专门讨论讲故事的课程中和你谈过。
