第二个问题说：一个创业公司怎么去选择自己的消费人群。这个问题其实太大了，简单讲的话就是说：

+   1、不要选特别小众的这么一个项目，除非你的热情和兴趣全都在这儿。

+   2、选择消费人群的时候一定不是想着把一个特别庞大的人群当成自己的初期选择，也就是说你要影响一个足够大的群体的时候，必须要在这个足够大的群体里找到你的小群体的或者你的产品适合去影响的这个大众群体里的的小人群。假定这个人群以后，从它扩散至这个人群。所有的产品检验和服务，把一个大多数人数作为自己的起始的直接目标人群的时候，几乎是注定失败的。

第二个是创业公司会看重求职者哪些方面的特点和能力。这个就比较简单了，一般说来创业公司和那些已经成功的大公司，去考求职者的时候基本上肯定第一是看业务能力；第二，人品或多或少是要考虑的。有些人价值方面要求高一些有些低一些，但或多或少也会考虑人品方面。

但是，本质上创业公司跟已经成功的大公司之间核心的区别就是，同时大公司希望你的能力没有问题，同时它会给你一些保障，福利、薪资这些。创业公司跟这些大公司唯一区别就是它对你们的要求是一样，甚至是更高的，但是它希望你少拿钱，少拿钱不是不想着钱，是希望我不要短期回报，要有一个长期回报。然后在长期回报上它是你是站在同一立场上的，大概是这样。所以它可能会希望你跟你们一些股份，股权激励这些东西，但希望我不要斤斤计较眼前的工资，或者是每个月的福利这样的东西。

除了这一点，其实本质上创业公司和成功的大公司之间对人才的要求没有什么大的区别。

如果一个创业者很有创意，也有可行性，最后却没有做出来，最大的因素是什么？

这是一个比较复杂的问题，它的原因有很多，但是也可以说的很简单，就是说你可以把这八个原因笼统地归纳成一个原因，就是能力问题。如果你这个点子很有创意，也很有可行性，最后没有做出来，简单地说一就是能力问题。

如果要掰开揉碎分析的话，这个能力涉及到比如说：

+   1、可能一到两个主体的个人能力。或者个体和一个群体里的所有个体能力都没有问题，但它需要一个很好的合作性、协同性，需要团队协作性，但是由各种原因导致群体之间的协作性，这时候也会出现这个问题。但是这个东，你归根结底也可以解释为是一个团队的能力问题。

+   2、效率问题。比如说这个项目如果在6个月或12个月内做行出来就是一个很好的东西，但是你拖到了两年，有的时机错过了。所以起创意有创意，有可行的，最后因为晚了半年甚至一年最后变成做行出来也没有用。这个时候，我们也可以把它理解成是没有做出来。这个问题出现在效率上，但这个效率最终也是一个能力。

+   3、综合素质。还有一个，这个项目可能需要大家非常快地做12个月，结果做到6个月的时候很多人扛不住去崩溃了，没有坚持下去，导致失败，这个本质上也可以认为是一个综合素质和能力。
