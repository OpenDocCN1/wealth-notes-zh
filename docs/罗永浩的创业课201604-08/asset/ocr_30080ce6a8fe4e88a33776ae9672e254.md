# 2.实践中提炼与升华如何操作？

其实很简单，比如讲完狼羊和狼来了的故事，讲故事的人就开始提炼了：小朋友们，从这个故事里我们学会了什么呢？学会的当然就是，人不能撒谎，否则会死得很难看。这就是提炼，也是从特定的经验故事里提炼出更具普遍意义的东西，来指导我们如何面对类似的全新状况。

再讲个例子，2013年，锤子科技成立一周年，终于能够发布手机操作系统的测试版了，那是在我们过去五年来，走得最艰难的一段时期，几乎所有人都不看好我们，能不能拿到下一轮的融资也是未可知。

讲完了这个故事，先提炼一下：罗伯特·富尔顿的经历告诉我们，当你跨界创业，做一番事业的人，难免被围观的群众泼冷水，说三道四，创业者不应该被这些东西干扰，只管埋头做好该做的事情就是了。

然后再升华一下，那次我主要就是为了给同事们和支持者们打气，所以给演讲的准备下了这样的功夫，也没有非要在更高的认识水平上去做文章。我只是跟现场的观众传递了这样一个信息：虽然创业者们继续咬紧牙关做事，不是为自己想做做的事情做好，改变一些东西，实现梦想和愿望，不是为了跟这些吃饱了撑的给创业者泼冷水的笨蛋们较劲，但过程中随手就气死这些笨蛋，也是我们的宿命。

# 3.我的演讲生涯中，最好的一次“提炼与升华”的案例

这世上绝大多数普通人，都不会成为所谓“改变世界”的大事业家，这本来没什么。但成年后的挫折和失败，会使很多人因此变得非常虚无主义甚至堕落。为了尝试说好一点，他们在生存过程中也经常做一做缺乏的事，并劝说自已这没什么，反正自己坚持信念，努力奋斗也改变不了世界，做点缺德的事儿，也改变不了世界，所以无所谓。

有感于这种观念的流行，我在2009年的一次高校演讲中，那时候我是做罗英语培训，在那次演讲中，我讲了我们如何一步一个脚印，如何通过努力与坚持，在一个被普遍认为必须漂漂才能赚到钱的行业里，干干净净的赚到了钱。
