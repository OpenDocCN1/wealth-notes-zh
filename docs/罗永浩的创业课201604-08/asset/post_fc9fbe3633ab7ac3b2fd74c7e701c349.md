
# 1. 文化差异与比较广告

首先从法律上，如果是在广告中，指名道姓地在竞争者的产品做比较，这样的广告在中国是违法的，所以一定不能够；在发布会这样的场合，拿着自己的产品跟竞争对手的产品做比较，理论上是可以的，但是在很多领域文化的地区，包括中国，如果你跟竞争对手做这样的比较，即便你采用的是一些比较含蓄，比较幽默、卖萌的手法，仍然可能会引起反感。

在西方国家，不但广告法允许这么做，并且一般公众对于这种比较广告也是通常是能接受的。特别是如果广告采用的是去恶意攻击对手的形式的，而是一种幽默的方式去调侃竞争对手的话，甚至是很受欢迎的。

比如当年乔布斯做了很多 Mac 和 PC 比较的广告，在这些阶段一样的广告里，他把 PC 描绘成一个笨拙的、落后的、漏洞百出的糟糕产品，而 Mac 永远是何比聪明、特别酷、特别有力量的这种气质。这广告收了很多回应的电视拿到过很多地方播放，一直都很受欢迎，但像拿到过亚洲国家播放，尤其是在日本，就引起了公众很大的反感。所以苹果公司最后在日本不得不另外拍了一套不同的广告播放。

其次，考虑到亚洲的这种文化特征，结合我们锤子科技过去几年的经验教训，我个人的建议是，在中国，要尽可能避免做跟竞争对手做比较的这种演讲，即便你完全没对人家恶意，即便你列举的事实全都经得起推敲，即便你的广告创意很优秀很幽默很可爱，依然不建议这么做。如果某些时候你必须做一个横向比较才能显示你的产品的差异性，可以含糊的，不点名的跟整个行业的通行做法相比较，但分寸感上仍然要非常小心。

## 2. 如何看待创业团队的成长背景？

创业团队的成员都来自同一个地方，成长背景大致相同，对于公司来说，这是好事吗？如何看待？

整个创业团队如果全部来自同一个地方，并且成长经历大致相同，通常来讲不一定是特别好的状态。因为每一个个体的成长经历和认知领域都有局限性，来自同一种经历的团队，能在一定程度上改善这种局限性。但如果团队里的大部分人都来自同一个地方，成长背景也类似，那么这个团队，作为整体的视野和认识水平，可能仍然有较大的局限性。

基于类似的道理，核心创业团队的成员里，性别上最好也不要过分单一。比如一个创业团队，如果全是男性（这比较常见），就很可能都会容易从男性视角看问题，在某些情况下，这很容性思维局限在，反过来也是一样，如果全是女性，也会在很多时候考虑问题不全面。再比如，创业团队如果是全是理工科，很可能会有这样的问题，因为是缺乏文先生的智商和见识；当然，如果全是文科生，道理也差不多。

大家看问题的方式不一样，虽然可能讨论问题更容易产生矛盾和争执，但正是解决这种矛盾的过程，才让我们学会更宽容，更开放，更全面地考虑问题。而且争执过程中碰撞出的火花，对创新思维来讲，也是利好因素。

## 3. 如何寻找和面对“技术大牛”？

一个不懂技术的创业者，在有限的时间里怎么去寻找寻找那个懂技术的大牛？怎么去判断他是真的是懂技术，而且在这个行业具有一定的影响力的？假如在最后段某个工作的时刻和创业者和他观点不一致，性格不投机时，会不会担心他跳槽，并带走他的一批技术骨干？有这样的事故发生时你是怎么面对的？假如你在有限的时间你真的找不到合适的，会不会考虑去其他公司用重金去挖人？谢谢！

没有什么特别好的办法，这就是为什么创业是九死一生，跨界创业更是凶险到九十死一生的原因。

除非有奇迹，这是不可能的。你要调整心态和认识，先找到两个小牛就很好。

首先，作为一个外行，要找到这种小牛，判断他是否真的懂技术等等，基本上是要依赖朋友或朋友的朋友来介绍的。如果你能接触到的人际关系网络够宽，完全解决不了对这种人发现和调查了解（这对跨界创业者来说很常见），那通常也就是通过猎头公司来帮忙了。到各种行业的技术分享会上去挖掘人才，或者到那些技术论坛和社群上结交也是常见的办法，但时间上的投入产出比都都非常差。

如果你自己和已有的团队这方面比较外行，那通过猎头找到刚合适的人人才的概率也很低，因为对方推荐了几个履历上看似都还不错的人，你自己也没有判断能力区分谁才是最合适的。

另外，接触过程中，如果你自己没有特别与众不同的地方，你找到的备选人才里，最愿意和你一起干的，较大可能也是综合能力相对较差的人，因为一个懂技术的真正大牛，不太可能跟一个什么都不懂的跨界创业者走到一起，真正的大牛，一定要有更好更大的选择。

只有你成了最厉害的老板，或着看起来要成了最厉害的老板，最厉害的人才会帮你做事。如果你不能提前说多了一个跟你完全不匹配的创始人，多半也留不住他，公司发展过程中有什幺波折的时候，竞争对手马上就来把你找的大牛挖走了。花重金挖人也是一样，如果花一亿重金，能挖来一个大牛，或两三个小牛，建议你选择后者。

### 2. 一个好的演讲，不能光强调要演讲者有感情

为什么有些感情表达方式，不用听完内容，你光听声音首先就会生理反应？我们知道，人是社会化程度最高的动物，无论是逃避危险还是分工协作，都需要发达的情感感知能力和识别能力，所以人依赖从声音、表情的细节里感受情绪的真伪。

所以，一个人表达感情的方式让你觉得很虚假，你甚至没注意听它的内容，光听声音就会让你产生不适的生理反应。

### 3. 区分恰当真实的感情和不恰当虚假的感情表达

中国娱乐综艺节目，有段时间非常流行主持人讲港腔。到了今天，我估计听我专栏的很多人，特别是年轻一些的，都不会觉得有什么让人反感的，除非是某个东北主持人突然往外冒东北味儿特别浓重的港台口音。

但是我们的很多长辈，很多退休老同志，听到港腔，即便是非常纯正的港台腔，即便听到港味的主持人说话台腔，也会觉得特别矫揉造作，特别反感。这些反感港腔的老同志们，却又非常喜欢中国大陆特有的那种抒情范儿，中央人民广播电台，或是中央电视台里，某些节目的主持人的那种抒情风格。今天的年轻人听了，恨不得原地爆炸，但很多退休老同志听了却觉得这种腔调特别真诚。

### 4. 光有感情还不够，要用激情把感情传递出去

一个经验丰富的职业演讲者，即便是在同样的内容重复几十上、上百次的演讲时，也能保持激情澎湃的表现，这会让大多数只讲了几次同样的内容就感到演讲时提不起精神的人非常绝望，不知道这些职业演讲者是吃了什么药才能做到这样。

大多数正常的人，显然都不具备能随时调动激情天赋。如果你也是这样的人，不用灰心，因为演讲时激情饱满并不需要一定有这种的天赋或或是吃药，它是可以通过技术方法实现的。

大家应该注意到这样一个现象。餐馆、保险公司、房地产公司这类高度依赖销售人员情感的作业，往往都会在开始营业前有个集体的情绪波动仪式，要就是一起大声唱什么《真心英雄》、《感恩的心》这种可热的歌，要么就是一起大声朗诵顾客就是上帝之类的口号或者其他短篇的鸡汤。

我们在旁观时，往往会觉得这是一种很傻的洗脑教育。但实际上，类似的行为，对于服务人员开工前的情绪调动、尽快进入状态，从中提高服务水平，几乎是不可缺少的。只是因为，你感觉情绪很消沉，意识感受到的少。只是因为你企业化、服务不同的阶段，以及从业人员素质的差异，表现出来的方式有很大的不同而已。

## 如何识别团队中的管理人才？

> 你好罗老师，想问如果基层的员工做得不错的情况下，哪一种人适合做管理，哪一种人不适合做管理，希望得到您的回答。这个现在特别难找。

一般说来，在基层员工当中选拔管理人才是很常见的做法，特别在创业公司里。那么个东西需要人力资源和基层员工是直接上司或直属主管，提前有一个长期的规划，要做和他们定期地沟通，了解他们是否是想管理工作的意愿，以及他们理想中不想做很重要，主观意愿上想做管理工作的优先考虑，不想做的不要勉强。

管理工作只是运营企业的一部分，不一定就是最重要的部分，有一些能力极强的技术人才转去做管理之后，很可能是对企业的一门巨大损失。当然了，这种人也会随着时间的推移发生变化，不是固定的。比如说有些人一心心想做技术，你劝他去做管理他因为不愿意，但是过了一两年，由于某些原因不愿意或是不想放弃的转变，他又想做管理工作了，这也是很常见的。除了个人意愿意外，

1. **在日常工作中表现出更明显的责任感和大局观的人，我们要优先考虑。**

有些人忙完自己分内的工作，他就认为工作结束，当然他完成的也非常好，所以他理所当然地就结束了。而有些人会把其他人分内的工作也做了，跟其他同事、其他业务版块和自己完成的版块，结合起来看总的结果，确认总的结果让人满意后，他才会认为是结束。你不需要去教育他，他本身就有这种观念的人，显然相对来说是非常适合做管理工作的。因为他有大局观，有全局的意识，不用你就有这种全局的意识。

这种全局观上表现形式还很多：比如说有些人在整体上做得一般，但是细节打的特别好，或者说部分细节打的特别好，这个人很适合做专家，但不一定适合做管理工作；而另外一种人，他每个细节都做好，不是突出色，但整体把得非常好，这种人一般说是要具有大局观的人，这种人更适合做管理工作。

2. **什么都会一些的人格上适合管理工作，这是辅助性的判断标准。**

第二种听起来会比较滑稽，在企业里大家都在开玩笑说：某某什么活都不灵，什么都做不好，但又什么都懂一点，很适合做管理工作。说完这话之后大家就哈哈大笑。其实，这是一个挺严肃的课题，一个人什么都不会，但什么都不精通的，人格上往往是适合做管理工作的。当然你从这一条来判断是不够的，但是这一条可以成为一个辅助性的判断标准。

3. **能换位思考能体谅和理解别人处境的人**

性格上有这种优势和特征的人，你要优先考虑。有些人只盯着自己部门的利益诉求，有些人会考虑对方部门的立场，后者明显更适合管理工作的。

4. **认识大部分公司同事，而且跨部门同事相处得好。**

有些人的性格特征是这样的：他没有花很多时间去跟公司交流，因为大家都忙得不得了，也没时间跟多同事多出去吃饭、交朋友，没有做这些事，但是他几乎公司各部门的大部分同事都认识，并且部门的人很多同事间联系有限，但也相处得非常好。而另外一些人连自己部门的同事都不认识，那么这种没有花很多时间出去社交、吃饭、打球、看电影，但是认识大部分公司同事，并且跨部门的人都相处得很好的，一般说是更适合做管理工作的人。

5. **关心他人，乐于助人。**

6. **日常跟同事的相处中，能够表现出人格力量，要优先考虑。**

这个很重要的人，什么叫表现出人格力量呢？比如说我们一起工作朝夕相处，难免发生摩擦，有时候出了事故，上面追究来就会发现，到底起得更多是工作，总是会涉及到职责的边界说不清楚。出现这种摩擦，出现这种说不清谁的职责边界的时候，一个人是主动往上身上揽事还是在推卸责任？这个很大程度上在同事都看在眼里，大家不是看看完了，他一定是在这种观察中看出谁是更有人格力量，谁相对而言就是善，就是更专业，甚至更卓越，如果能够表现出那种令人尊敬的某种品质和人格力量的话，一定要优先考虑，他是天然的领导着。

7. **同事日常相处中喜欢抢着买单的人是天然的领导着。**

虽然这个听着可能不太严肃，像玩笑，但实际上是一个很重要，一个环境下，你要当回事来考虑的一件事。在同事间这种相处里头去看到一些习惯，抢着买单，优先考虑这些人从性格上是天然的领导者。

8. **借助测试系统识别团队成员的性格和能力优势。**

如果以上的这些基本本基本做法还不够，其实也有一些专业性的工作做法，只是很少有人在创业初期会考虑。如果你在这方面有所困扰的话，可以考虑去花钱做一个测试，叫“盖洛普优势识测试”。这种测试你要花钱买他们的测试，然后给你提供来做管理岗位的这些人的一个做一下优势测试，从优势测试的这个结果，看谁是不是适合管理工作以及适合什么样性质的管理工作。

## 演讲中的类比与逻辑

自古以来，讲道理的高手就善于使用类比。大家可以在回忆一下我们当年课本春秋战国时期，那些游说国王的，动不动就是：“大王啊，山里有只鸟，三年不飞也不叫，您看这是什么回事？”这一听就是要玩类比赛。然后大王就很呆萌的乖乖听这个人说话了。中国古代讲道理的文案，很大一部分都是使用用这种类比的方式。

耶稣传教也特别善于用类比：

> 比如让他的门徒去做“世上的盐”，去影响他人。再比如，富人想要进天堂比骆驼穿过针眼还难。这一句话就胜过了长篇大论讲人为啥不该贪婪爱财。

很多大政治家都是运用类比的高手。

> 比如，什么是改革，可能没有一个人能马上想出来一个定义，但邓小平那几句“改革是摸着石头过河”，每个人都听得懂。

邓小平还有一个类比特别著名，就是“不管黑猫白猫，捉到老鼠就是好猫”。这句话甚至输出到国外去了，马来西亚总理马哈蒂尔2001年，在APEC峰演说讲时，就用这句话做了开场白。

但是，“白猫黑猫”这个类比，其实邓小平的原话不是这么说的，他这段话是1962年说的，当时的原话是：刘伯承同志经常讲一句四川话：“黄猫、黑猫，只要捉住老鼠就是好猫。

那么，黄猫、黑猫是什么时候变成黑猫白猫的呢？是1976年毛泽东亲批的，当时经手人毛远新回忆说，他汇报上去的材料里有这句话，毛泽东只改了一个字，把黄猫改成了白猫。

黄猫、黑猫这个类比，原本是没有褒贬色彩的，但是改成白猫、黑猫，一下就有了好猫、坏猫的意思。

再比如二战美国一开始还没有和德国日本开打，美国要不要物质援助英国的问题上，美国主流民意觉得可不该我们的事，甚至美国人还打着赚钱了，没线购买美国物资，罗斯福就在接受记者采访时用了一个类比，把援助类比作水管，说你看着人家家里都着火了，你做个个水管公管考虑收钱么？这个类比激发了美国公众的同情心，效果上，比一堆大道理加分析管用多了。

最后，说我们科技界的例子：中国的公司去美国上市时，要美国的投资者弄明白这些公司是怎么回事，直接解释起来是比较疲劳的，但是类比一下简单就多了。

> 比如优酷去美国上市时，就告诉美国投资者，这是我们的Youtube、加上Hulu加NetFlix，他们一下就听懂了。微博去美国上市的时候，也是跟美国人一说是中国的Twitter，他们全部懂了。

这就是类比的效率和力量。

### 2. 要有逻辑

首先要特别说明的是，如果仅仅是想要在演讲中达到说服普通大众的目的，讲逻辑未必是最好的选择。因为人们很难用听觉处理逻辑观点，反倒是很容易记住故事和例子的。

一般来讲，当演讲者试图说服普通大众，给他们洗脑时，最有用的手段是断言和重复，再讲几个故事和类比就全活儿了。历史上很多擅长洗脑的大人物，手法上都是这么简单粗暴直接有效的。
