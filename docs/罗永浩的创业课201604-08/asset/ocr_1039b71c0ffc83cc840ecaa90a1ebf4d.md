# 如果你不是第一名，那么你又该怎么办？

听起来很绝望是吧？那我们还创业呢？

那就说一些让人高兴的消息吧：‘佳得乐’是美国著名的运动饮料品牌，它没有去跟可口可乐去拼可乐这种品类的饮料，而是在全新的运动饮料品类里抢先为了一第一名。运动饮料被佳得乐带起先风潮之后，全球最大的饮料制造商可口可乐看着运动饮料市场眼红，也做了一个‘动乐’的运动饮料。但直到今天，动乐的销量也只是佳得乐的一个零头。可口可乐的牛也没用，因为佳得乐已经抢先成为运动饮料品类里的第一名了。再后来，佳得乐被百事可乐收购了。如果没有意外，百事可乐永远都打不过可口可乐，同样，如果没有意外，可口可乐旗下的动乐也永远都打不过百事可乐旗下的佳得乐。
