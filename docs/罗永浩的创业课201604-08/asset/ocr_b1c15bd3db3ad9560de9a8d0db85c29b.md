基本上就是看两件事，第一个是看这个人，这个团队是怎么看待，第二个是这个团队决定这个创业的项目是不是足够好，基本上就是基于这两点判断。

# 必备动作1：对投资计划书务必要如下指导

我们首先第一点，就是说这个人和团队是否靠谱，你作为一个创业者想给投资方造成一个团队靠谱的印象，其实如果你求职的时候也是一样的道理。首先如果你有一个漂亮的履历很可能解决了一大半，但是对于那些年轻的创业者来讲，这个通常是可望不可及的。你要在经历没有非常漂亮的情况下给投资方造成信心，无非也就是让他感觉到你和这个团队整体上是一个聪明的、脑子清楚的、对于要做的的事情业务是自然熟悉和专业的，对未就是是有理想、有追求、有激情的，无非也就是表现成这样几点。

很多人认为就是在这种沟通过程中口才特别重要，他们假定我是因为口才出众，所以才能考上得得了很小的好的，其实这也是完全错误的说法。实际上因为口才出众去常常给投资人造成做事靠不着谱的印象，这也是我们国有的一种传统偏见。

极少数古怪的投资者有时候还会做一些古怪的测试，比如说心里测试、优势劣势的测试，甚至要求你在这个办公室办公或者等等，但这一般来说是比较少见的，多数情况下都是跟面试差不多，就是给对方造成脑子清楚、足够聪明、对业务熟练、有理想、有追求、有激情。

其实都围绕着你这个计划书去做准备工作就可以的了。我们做的任何商业计划书都不可避免地带有大量的数据分析、行业分析、前景分析等等这些数据。一个准备充分的创业者去见投资人之前，要对这些数据了如指掌。

比如说你告诉他过去的七年计划期都是在高速增长，但是我们曲线图可以看到中间有一个年份有回显的回滑，而恰巧那一年又是污染很严重的时候。这个时候很有可能是随意问一下，为什么在高速增长中的七年中间还有一个污染严重的年份反到回升了一些。如果你能告诉他，刚好那一年出现的问题是有一个国际方面的政策改变，导致很多不符合新产品的产品，虽然有市场需求但是不能去销售，所以这一年有一个明显的回滑。如果你能把这些东西回显的清清楚楚，很容易一搭子就造成一个完整的印象，也就是这个个人聪明、脑子清楚、业务熟练。

# 必备动作2：见投资人时一定要表现出你的激情

即便是那些不擅长表达或者不擅长情感外露的创业者也要牢牢记住，就是说当你拿着项目计划书去见投资方的时候，在有限的能够表达的时内，一定要在谈你那个热爱的这个东西或者这个项目的时候充分表现出你的激情、表现出你的活力。

很可能因为你性格上不是这种人，当你尝试做这样表达的时候，别人看起来会感到很尴尬，甚至起鸡皮疙瘩，你会这样副作用可能一定起不到表达这个东西。因为从投资者来讲，他更在意创始团队的创始人是否对他所做的项目有激情、有热情。如果你擅长表达、激情外露、并且感性极强，固然加分，但如果你想干表达，性上比较柔和，硬着去做这种激情表达，也是严重负面的。你不擅长表达和激情表达诱导的的那种烂话巴、笨嘴笨舌的东西，更能让他感到质朴的力量。

无论任何时候，面对工作、面对消费者、面对投资者，面对你可能爱谈的合作伙伴和你应拉进的人，创业者一定要记得任何时候都对自己做的事情表现出激情。

如果说仔细研究过苹果现任CEO蒂姆·库克，你面对公众演讲的视频，你一定会发现在乔布斯活着的时候，他作为公司的CEO在公开情况下都是本色出演，他本身性格是偏内敛、偏深沉，在公开的时候也是非常公众演讲，但是，表现出来的也是在不严肃、内敛的状态。但是乔布斯去世之后，他从COO的位置做到CEO的位置，在这之后，他完全放开，任何时候可以进反他的性格和他本色的这种形式，表现出非常强烈的热情和激情。

由于他的性格在这方面不占优势，所以他表现出的那种激情时不时的会让人感到有一点难或者有点别扭。但即便如此，你仍然能从一个企业的人魅力方面表现出那种激情状态当中，感受到一些让人感动的一些力量有力量东的东西。

# 必备动作3：秀团队比秀个人更有用

还有一点是想给那些优秀年轻人的一个忠告，就是说当一个年轻人他比自己同龄人优秀的时候，他很容出现的一个错误就是，他能够自以身价非常高的秀带着一帮小弟年轻能够做事的情况。可是对于一个见世面的成年投资者来看，一个年轻人再优秀也远不如一个优秀的团队。所以你最好在创业的时候清楚一点，不要过分迷恋个人，虽然非常讨厌这种态度，而是说几个跟自己分量差不多的年轻人一起创业，这样的话成功的概率会很高。

如果在同龄人当中，你是一个90分的优秀年轻人，这时你再找两个90分的，在投资者的眼中你们就是一个270的半人。可是如果你是一个90分的优秀年轻人，然后带着一个堆小弟，在他看来你这个团队只有90分。所以如果你的团队中已经有两个人足够秀的合伙人，你去见投资人的时候一定要把他们都带上，不要因为他们不愿意融资你就一个人去见投资人。
