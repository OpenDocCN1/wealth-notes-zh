如果这个东西坏掉了，或者怎么样了，就损失很大，这是一个常态性的问题。

我相信绝大多数人不会比我脾气更糟糕，但即如此，我们请来高智以后，要在我们确保搞清楚了，以至于不得不跟他撕掉为了结这个关系之前，绝大多数情况下我都是忍得住的。我是一个非常糟糕脾气的人，但我绝大多数情况下都忍不住，这是每一个创业者都要强迫自己修炼的东西。

> 你曾经说过“大部分人的问题都是智商问题”。那么这些年过去了，有没有那么一次或者几次，让你突然感觉到，智商问题才是人生的关键，以及你如何看待情商和智商的关系？

有时候，我们会因为连续遭遇了一系列跟某个课题相关的问题，所以在那个时候，会把这个问题分析得格外严重。我过去出发来感慨，比如我之说说过大部分人的问题都是智商问题，不可避免有情绪因素掺杂在里面。如果过了那个时期回头去看的话，这件事其实也没有那么严重。

说回这个问题，有没有的一刻会感觉到情商问题才是人生的关键？我肯定也有过这样的时刻，但整体上我不觉得智商问题和情商问题有那么严重。有一句名言我忘了是谁说的，供你参考：只有那些智商不够的人，情商才重要。这句话听起来也是挺让人沮丧的。所以我想就是个观点，跟你说一个好的消息和一个坏的消息。

坏消息是，绝大多数人的智商和情商基本上是先天决定的，后天能够略有改善，但是能改变的幅非常小。好消息是智商和情商对人生的影响和后果可能没有你想象的那么严重。

我讲一个智商方面的典型例子，九十年代的时候，美国全美智商排名第一个人，我忘记这个人名字了，好像叫霍布斯托马斯·格兰德是什么。他是全美智商最高的人，但是他的命运，不好说是悲惨还是怎样，反正我相信对于绝大多数人是没有吸引力的人生。他的工作是白天在家里写一本绝大多数人看不懂、即使是学者和知识分子也看不懂的科学哲学。晚上，因为他脑大开眼，并且他好像是过了几个星期的时间学会了将卡，然后在夜总会里做领牌，是这样一个诡异的人生。

然后全美排名第二的智商的人，他的工作是给智商测试机构智力做测试题，收入也很微薄。他这个人比较奇迹的是，败入很狼狈的情况下一直住在曼彻斯特。他跟媒体承认，他智商的大部分是用来解决如何在曼哈顿用那么低廉的收入维持生活。除了，多像是这类，并没有悲惨吧，肯定对绝大多数人来讲并没有吸引力的人生。所以，希望你明白，就是说我们先天的这部分可能对人生的影响没有那么严重。



过去这些年你除了是一个产品的生产者之外，还是一个消费者。请你列出最近值得购买的五件物品是什么？以及为什么？

过去的五年虽然我是一个非常忙碌的创业者，但是，消费这件事上，我什么也没耽误。因为我和很多女人一样，压力大的时候就会买东西来化解。所以我现在买了很多有用和无用的东西。

我过去和五年买东西其实非常多，如果你突然问的话，我就先说一下我能想到的几个吧。

+   1. 苹果的笔记本电脑。我每次用苹果的笔记本电脑的时候都有一个由衷感慨，如果这个世界上没有这家公司的话，我们无论如何要付出的代价、多少的钱都只能得到比它差很多很多的笔记本电脑。所以从这个意义上，我每次用苹果的笔记本电脑的时候甚至是怀有感激之情的。

+   2. 90分铝合金箱包。我最近一两年出差变得特别频繁。我会很想在意情中试试得到各种各样的名牌箱包，但是现在用的最多、也最喜欢的是小米生态链企业90分出的一个箱包。它的铝合金箱包只要1750块钱，但我可以用价格评价，以我非常挑剔、非常挑剔的用户标准去看的话，在绝大多数选项的比较里，我认为90分的箱包都是要过好市面上很多昂贵的奢侈品的箱包，比如rinowa的6000多块钱的箱包。

+   3. BOSE的降噪耳机。我每次用的时候心里都充满了感激，因为对于一个经常出差，而且要长时间忍受飞行噪音的人来说，这个产品其实是挺重要的，好像是2600多块钱。它如果如你试过了的效果，会觉得要6200块钱可能都是非常多值的。特别是，所有的名牌耳机现在都推出了降噪功能，但是你是横向比较的话会发现它跟BOSE的降噪效果比，就是那一点差距永远追不上了。

+   4. B&W的805音箱。说到耳机以后，我想起的一个音箱。我自己使用了这么多的音响器材，B&W是一个最伟大的音响品牌。我在办公室里面使用的是B&W的805音箱，差不多3万块钱左右一对，拿他横向去比10万多、20万、30万、甚至50万一些的设备，都没有听出明显的差距，那些大音响只是增加和改善了低频，而在中频和高频这些方面，相对于一个3万多的音箱来讲，没有太多改善。所以从这个意义上，你可以认为这个3万多的B&W805可能是全世界最超值的音箱了。

+   5. 日本品牌的功率放大器。说完了音箱之后，再说一下功率放大器。你去买一个跟B&W805能够搭配的任何一个日本品牌的功率放大器，几乎都是全赢。虽然在音响界有一个概念，大家都在鄙视日本的音响产品，但是我个人实际使用的体验和给很多朋友做推荐，只要是同价位的、任何一个主流的日本品牌的功率放大器是全面胜过同价位的欧美的名牌的功放。所以希望大家明白，如果你要给B&W805音箱配一个与之匹配的话功放，并且价格合理的话，选择任何任何日本品牌的，几乎不会出失望。
