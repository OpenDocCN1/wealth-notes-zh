其实百分之八九十的企业家也是不懂产品的，但这也不影响他们成为成功的企业家，因为这在这个世界上产品品型这个企业家者是极少数。如果你是产品驱动型企业，产品理想型的老板，在实现一个漂亮的财务报表之前，孤独和不被理解是常态。不要说服外部的人，就是公司内部的人你也不要指望多数人能懂产品。这方面一定要有足够的心理准备，因为产品驱动型的创业者早期最容易犯的错就是误以为自己有好了好产品，投资者就该在他取得商业上的成功之前就充分认识到他的潜力，这种机会是可遇不可求的。

我过去找投资的时候，总是跟投资人花很大的篇幅去谈产品，结果完全是牛对弹马。今天我们福子科技的投资者也有几十个人了，当然他们整体中都非常支持我们，不过这里里说到懂我们的产品，也知道我们这家公司这个团队品质上是怎么一回事的人可能只会超过10%。所以既然多数的投资者只懂这两个半，我们今天本来就应该说的就是这两个半。

# 2、跟着一个大趋势和大方向创业，更容易融到钱

早期的天使投资者基本上全是看大的趋势和方向，所以

> 如果你做的不是热门的方向，又没有特殊的或者明显异于常人的长处，融资就会变得非常难。

在一个大趋势方向上，又分为持续多年的大趋势、大年，比如移动互联网到现在差不多快十年了还没有完全退潮下来；还有一两年、两三年就凉下来的小风口，比如O2O或者是跟时下计算平台相关的比如VR，就是虚位现实的那种眼睛。O2O最火的时候，望京这一代号就是叫宇宙O2O中心，满大街都是扫码的，那些脑子活一点、动作又快的年轻人，去做O2O的都拿到投资了。

当时我们公司也跑出去好几拨人创业，去给我们摸美式、送外卖类等的投资项目，基本上也都拿到了投资。有些人犹犹豫豫了半年，商业计划书又磨磨叽叽地推敲了半年，活活泡沫一眨眼就过去了，接下来你出去见投资人干脆O2O，投资人直接吓跑了，就算有好的项目也很难拿到钱，这时候时机已经过去了。

VR也是差不多的情况，去年再往前有一年多火爆一场泡沫的时候，身边到处都是拿着VR戴在脸上的人，看起来很滑稽。甚至这还出来了一个专有名词“VR脸”，因为戴的时间长了，会在脸上勒出两道痕，被圈里人称为VR脸。但另一个角度，当时VR的项目要独立融资确实非常非常容易，当时我们种子内部商量了一下，决定支持我们的VR团队负责人罗子出去创业，子雄是那种做事很、动作又特别迅速的年轻人，不管是我想跟他商量，还没来得做什么，他已经谈成了投资，做了一家叫所所科技的VR公司。所所科技找之后只过了短短几个月，VR就和这些年轻人避之唯恐不及的领域，再什么人想出去在VR领域拿到投资，就变得非常非常困难了。

# 3、确定方向之后，融资安排的速度一定要快

所以你看，2010年-2012年最火的是团购还有社交智能，然后2012年-2014年最火的是智能硬件，2015年-2016年最火的是VR无人机还有O2O，现在最火的是什么呢？一个是疯狂赶热的这种共享经济，还有就是普识别加人工智能的智能音箱。当然如果没有什么意外，这两个风口可能很快也就过去了。

共享单车半年前可能还好，现在已经没有机会了。这几个月共享充电宝突然又火起来了，3月底到4月中，十家左右的公司有五家成功融资的共享充电宝的公司。参与进去的机构有20多家，总融资金额3个多亿，5月1号到8月9号三家共享充电宝的公司又上市获得了共计7.5亿的融资。接下来宣布得钱的就是共享球项目成功拿到了投资，这个听起来说已经够诡异了，更诡异的是共享雨伞和共享打火机项目也出现了，而且居然也都拿到了融资。

对一个毫无资源人脉，然后只有聪明、勤奋、野心这样的创业团队来说，选择一个热门的大风口方向上的项目，尽早拿到钱是至关重要的。但是拿了钱只是万里长征的第一步。这种泡泡沫的窗口期，相关领域的大部分创业公司就会迅速地死掉。

举例来说，2015年-2016年，70%的VR硬件创业公司都已经倒下了，还有2014年国内有200多家做VR头盔，就是头戴式VR显示器的这些企业，到2016年多的时候只到50多家，再过几年绝大多数都死掉，或者是被兼并了。

所以你拿到了钱之后你可能几乎没庆祝的时间都没有，就要带着整个团队赶在第一个可能死神降的期限来临之前，为了出现转机活下去而没日没夜的奋斗，大概就是这样的。

最后我们想说的是什么呢？就是怎么有什么就做什么，什么赚钱就做什么，还有能做什么就做到什么就做什么的一个团队，理论上融资就要看得很多，你就集中精力研究这个风口，看哪个最热，然后这个越快越好拿到钱。如果一个是一个认定自己喜欢或者相信的大方向去做，有一个明确的方刚和坚定的信念这么一个团队，让整个创业过程和融资过程就会困难很多，我们团队自身就是这样一种情况。

问题来了，我们到底应该找真正要做的项目去融资，还是先找容易融资的方向去谈，然后拿到了钱之后再逐步慢慢地调整去做自己真正做的项目呢？我不知道答案，我想每一个创业者可能都会有自己的答案。

# | 今日得到：

+   1、不要指望投资人懂你的产品、懂你的业务、懂你的团队，要假定他们很针对你做的事情一无所知，这个心态一定要提前拿好。

+   2、为了顺利地完成第一轮的融资，要看大趋势、大方向，在这个大致的方向上要盯紧那些具体的领域目前在比较火的状态。

+   3、认准了这个领域、这个方向之后，做调查、做计划书、见投资人等，要安排得尽可能快，速度至关重要，机会的风口稍纵即逝。
