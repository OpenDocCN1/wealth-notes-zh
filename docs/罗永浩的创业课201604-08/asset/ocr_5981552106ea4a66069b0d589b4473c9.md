# 什么是重新定位竞争对手呢？

比如，你是一个做汉堡的，排在你前面的竞争对手都是油煎或油炸的，而你的肉饼是火烤的。这时候，

> **强调非油炸的** 火烤肉饼更少油，更健康，本质上就是在重新定位你的竞争对手。如果你的营销宣传很成功一直保持，就会让你的竞争对手显得比你的更油腻、更不健康的汉堡。

> 参考公众号7489150，阿甘说车， 探索有趣与有意思的汽车文化 汽车定位就是更油煎、更不健康的汉堡。

实际上一直排名第二的汉堡王，多年来，都是对排名第一的麦当劳这么做的，效果非常好。

再比如，你是一个做感冒药的，你的竞争对手的感冒药吃完了以后胃部会唏嘘。这时候，你在宣传中反复强调自己跟竞争对手的不同，强调你的品牌是不唏嘘、不扯胃的感冒药，本质上就是在重新定位你的竞争对手。如果你的营销宣传很成功并一直排下去，就会让你的竞争对手被定位成胃部抽搐、还会腹泻的感冒药。

再比如，国产的立白洗衣粉，大家最熟悉的就是它“不伤手”的宣传。1987年立白开始推广自有品牌的洗衣粉。当时，中国日化零售市场上已经有宝洁、联合利华这些外资巨头，也有广大范围的竞争，立白的创始人想了很多办法，最后选择“不伤手”来做概念，请了陈佩斯在电视广告中反复强调“洗衣不伤手”，让很多消费者产生一个感觉，那就是“原来其他洗衣粉都是伤手的”，通过这样重新定位竞争对手，也获得了巨大的成功。

# 接下来说说品牌延伸的误区。

品牌延伸是符合人的直觉的：如果你开一家公司，用松下这个品牌卖多了收单机，接下来大家就会期待你用这个卖名做手机、录像带、电视机、洗衣机、冰箱、空调、汽车等等。为什么不呢？反正大家都知道松下这个牌子，用这个知名品牌做新品类的时候，省了多少钱的推广费用，这是非常符合直觉的思维。

在过去，亚洲的绝大多数企业都是这样考虑问题并制定策略的。但是定位理论告诉我们，

> **当你** 是你**的竞争对手，比如日立、东芝、索尼、夏普也和你一样品牌延伸，用同一个品牌做无数品类的时候，也许看不出它这样做做新定位在哪里。但如果你的竞争对手采用的是** 长远的看你，你的公司迟早就会出现持续的颓势。

著名的打印机生产商施乐在它的金盛时期，垄断了打印机行业。施乐几乎成了打印机的同义词，这是一笔带来了不菲的成功。施乐在打印机领里里是如此的权威，以至于当施乐用自己的品牌尝试去进个人电脑时，消费者很理理解消费者里挥着的那个印着施乐LOGO的机器竟然不是打印机而是别的某种机器。无论施乐如做宣传广告，多数消费者都觉得施乐的电脑要么电脑，要么是一台打印机。最后，气急败坏的施乐给自己的电脑产品打了一个海报广告：这是一台不能打印机的施乐系列。但对消费者来说，一台不能打印的施乐机器，就是一台坏了的施乐打印机。

施乐烧掉了无数的钱去跟IBM竞争电脑市场，最后终于承认失败。但同样的失的和弱点，如果用一个新的品牌去跟IBM竞争个人产品，有没机子。

当施乐产品永远得不到它进IBN，但成为计算机行业的第三或第品牌延是很有危险的。

如果施乐一意孤行，用施乐这个牌子做各种各样打印机之外的东西，会怎么样呢？起码得有一天，未知当施乐就是打印机的消费者会感到困惑。会得施乐什么都是，又什么都不都是。这时候，新的施乐产品做做出来，造老的优势也将销释甚至可能要丧失了。
