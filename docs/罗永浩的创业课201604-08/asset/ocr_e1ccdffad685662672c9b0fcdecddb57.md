# 3. 创业以后还会回公司上班吗？

是不是自己创业了，无论结果如何，都很难再回公司上班了？

倒也不至于，创业公司三年内倒闭的几率是百分之九十左右，但从二次、三次创业的人却没有那么多。那些人都到哪里去了呢？肯还是上班去了，就不甘心的。

但同时，很多创业过的人也确实深刻的感受到，创业这东西，就像抽烟或吸毒品，要真正戒掉是非常困难的。就算被迫戒掉了，但总有复吸的机会，还是合蠢过程，心痒难吸。所以最好想办法，创业不管多艰难，咬牙坚持，不要放弃，就过去了就好了，免得将来天天都是找人交战。

# 4. 该不该倾囊相授培养新人？

倾囊相授地培养了一位新人，可对方学到东西就要走人，该怎么办？难道下次面对新人，还要刻意保留？非常纠结。

不至于吧，21世纪了，大家能有什么独门秘笈，到了要刻意保留，传子不传女的程度上，我想无非就是以下几种情况和对应思路吧：

+   1. 如果这种情况偶尔发生，我倒意是，不至于因此就不教新人了。如果不教新人，你时间不够用又事事亲力亲为，累死了也是很难省自己。如果是复制发生，就可以考虑推给自己了。为什么倾囊相授的人总也留不住？是不是自己待人的方式有问题之类似的。

+   2. 对方狼心狗肺，天性凉薄，人品有严重问题等等，但一般说来，这是小概率事件，不至于因此就不教新人了，因噎废食，因小失大，都是不明智的做法。

+   3. 对方有某种不得的难处才被迫走，所以看起来就像是“学到东西就要走人”，但其实有可以理解的原因。亚洲人辞职的时候，很少会对公司说真正的辞职原因，所以也不能强求对方告知真正的原因，只能互相理解理解。

最后，我以前也讲过类似的内容，我再次再喂一遍，那就是，留不住人才，一定要留点香火情，千万不要因为留不住而恼羞成怒，撕破脸皮，说伤感情话之类。锤子科技创业五年，有些过程中留不住的优者，又重回来发挥重要甚至关键作用的，有好几个。创业者的心胸和度量，要能撑船，能撑航母，能开无人驾驶汽车，不能自己带出来的徒弟伤。
