# 最难搞定的人？

第8篇 | 我是如何挖到那...

欢迎来到我的干货日记，你好，我是老罗，罗永浩。

今天和你分享的 topics 是，在招聘当中最难搞定的几种情况，和我个人对应这些情况的三种招数。

第一种比较难搞定的人，是那种对创业打天下、还有改变世界、热血这些东西完全无感的，这帮家伙你说起米特别吃力，你使尽浑身解数在他眼里看着就像个小丑，特别疲劳。

第二种情况是特别优柔寡断的，这种人也是让人最头疼的一种，就是你今天跟他谈完他非常激动的同意了，明天他的主管跟他谈一谈他又说不能了，后头你再说他又不来了，大后天他的主管挽留他，又说不来了，这种特人特别精疲力尽，而且常常结果都是很糟糕的。

第三种也是比较烦人的，就是长期不表态，自始至终都没说过同意，你约他就出来，每次聊都很热乎，接着给他一个时间要他做一个决断，就没有下文了，这些都是属于最难的情况。

做过人力资源的，都对这三种情况感到比较头疼，那我们就要针对性地讲一讲我们这些年积累下来的一些方法。

# 1、对创业无感型：设计具体场景

第一种就是那些对创业、打天下完全无感的人，热血燃不起来的人。这些人沟通时候燃不起来，很重要的一个原因就是他的燃点比别人低。低燃点的人，你要设计一个场景，能令这个人激动起来的地方，肯定不是一个黑乎乎的、开到很晚的酒吧、夜总会或者咖啡厅，而是那种特别能让人激动起来，或者你讲去什么打天下、创业、改变世界，听起场景都是与之匹配的。

比如说，典型的例子就是那些特别高层的摩天堂，以北京为例，比较好的场所就是丽泽中心，丽泽中心那个楼足够高，下边对着的是长安街，无论是晚上还是下边车流人流永远川流不息的。

你把这种燃不起来的人（拉到这样的地方去，坐在一些酒一面对窗子看的就是下边汹涌的人流、车流和灯光，你在这个几十层的高楼上再跟他讲一些创业、打天下的东西，听起来整个气氛就全对了。最无感的人到这样地方，最后眼睛也会亮起来，特别是你再请一些很贵的酒，比如一瓶两千多块钱、三千多块钱的酒，你喝着这样的酒跟你在那样的场景下，你再一忽悠，燃点再低的人也会产生一些眼前发亮的东西。

这招其实不是我自已想出来的，这是我创业初期跟我们的老朋友，也是我们的天使投资人，陌陌科技的老板唐岩，聊到我说我出去挖人的时候碰到最难的一种情况，我像变猴一样讲了半天很激动、很热血沸腾的东西，结果对方等于无动于衷。后来唐岩就说他自己的实践摸索中，这种人就要找一些场景，去摩天大楼、高档酒店的大堂吧喝点酒，然后再讲的话，气氛就全对了。

# 2、优柔寡断型：破罐子破碎，刺激他一下

第二种情况也是比较讨厌的，就是特别优柔寡断型的人物，我个人的经历里边如果出去谈人的话，这种概率大概是20%，是非常非常难以搞定的一种情况。
