# 要“拿到钱比什么都重要”。

+   1.任何时候，有钱就拿一定马上拿

除非给其他的投资机构的条款极度荒唐离谱（一般也不会发生这种事情），否则，谁给钱就拿谁的，一定要记住，只有到账的钱才是钱，其他的都不是钱。口头承诺的钱都不是钱，响当当的投资大佬口头承诺的钱也不是钱，甚至是响当当的投资大佬书面承诺的钱也不是钱，全球知名的行业巨头签署协议承诺给你的钱也不是钱。那什么是钱呢？

回顾中国这些年热火朝天的创业大潮，投资机构签完了投资协议后最后一刻出现意外、没打款，导致创业公司死掉的例子比比皆是。所以任何时候，只有银行到账才算是融资成功，其他的不管过程和细节看起来多栩栩如生，多逼真，都不能当真。

我们在2016年也经历过一次非常非常逼真的融资，对方签署协议后拖了很久，既没说取消，也没说继续。对方的影响很大，他们不打算签导致投钱的机构都不敢贷款新链快现了，足足半年后，我们资金链快见底了，一定计划把公司贱卖掉，为了操办变掉的流程，只好主动提出取消协议。

为什么会有这样的情况呢？其实原因不重要，反正能肯定的是，对方肯定不是故意伤害，大家都想做生意，他们这样做一定有他们的理由或者经历，重要的是这样使不备防，因此死掉。这其间另一个行业大佬要找我们，他更希望拿前面说的某家的钱，所以一开始虽然投没有拒绝另一家，但中间确实故意拖了一段时间，结果发现苗头不对的时候，另一家也心思不在这了，也没戏了。所以，记住这个血泪的教训，任何时候，有钱拿就一定马上拿。

+   2.不要太在意公司的估值

你最好拿的是一个所谓公允合理的估值价格。太便宜了你吃亏，这不是说你都知道，贵了，你可能觉得占了便宜。

其实估值肯定是件好事。创业者融资期最容易肯定就是总希望估值再高一些，再高一些，这样自己开心，团队士气也高，出去跟朋友吹牛逼也挺提，但其实估值高了隐患很多。

如果下一轮大家都爆贵，你就融不到钱，如果你觉得不好融资，主动在下一轮愿意便宜一点，大家又会觉得你经营出了问题或者是没了信心。

另外，同一轮的投资者里，

所以你拿了最高估值机构的钱，通常意味着你要承受最大的压力，这也不利于创业公司正常发展。

再强调一遍，拿钱的时候，估值不重要，钱拿到手最重要。除非是荒唐离谱的价格和条件，否则，同一轮融资过程中，估值最低的那家如果马上就可以，那就一定拿他家的钱，不要犹豫。记住这个无数前辈的血泪教训：只有银行通知到账的钱，才是真的钱。

+   3.不要过分在意稀释股权

只要没严重威胁到将来的控制权，钱拿得越多越好。即使威胁到了将来的控制权，它跟公司因为缺钱而死掉相比，也是微不足道的。

+   4.除了不要在意估值之外，也不要在意融资金额少

形势不好的时候，比如动不动就未到的所谓“资本寒冬”，这时候资是资也是问，千万不要嫌少。早期融资是投资机构，反正后面还会有B轮、C轮、D轮。无论机构牛不牛逼也没关系，反正给了钱，能让公司活着发展下去，就没什么可犹豫的。再强调一遍，拿钱的时候，不要在意融资金额多少，钱拿到手最重要。

+   5. 拿行业巨头的战略投资时，不要怕站队

“怕站队”，这是在创业公司当中流传很的一句傻话，它的意思是，如果你拿了腾讯的钱，可选某些生意家不方便跟阿里合作，如果你拿了阿里的钱，有些业务跟百度合作，阿里可能就不高兴之类的。

其实，

比如你拿了A的钱，如果接下来发展的非常好，有出息，估值翻了好多倍，然后跟B有些合作，A会不会多不高兴，就算不高兴他也会忍，反正你都给他投了那么多的钱，他还能拿你怎么样呢？业绩好就不需要被迫站队，如果你接下来发展得不好的又怎么样呢？你很可能因此爆三发五要A家会求也求不了你，这时候你哪里是被迫站队的啊？这明明是感激都来不及的情况嘛。

所以呢，再强调一遍，拿钱的时候，不要在意站不站队，钱拿到手最重要。

创业融资的过程里，还会有各种各样的情况，有些事情不清楚的时候，牢牢记得参考这个版块的第一个：任何时候，有钱拿就一定拿，其他的都是小事。
