
## 如果这个东西坏掉了，或者怎么样了，就损失很大，这是一个常态性的问题。

我相信绝大多数人不会比我脾气更糟糕，但即如此，我们请来高智以后，要在我们确保搞清楚了，以至于不得不跟他撕掉为了结这个关系之前，绝大多数情况下我都是忍得住的。我是一个非常糟糕脾气的人，但我绝大多数情况下都忍不住，这是每一个创业者都要强迫自己修炼的东西。

> 你曾经说过“大部分人的问题都是智商问题”。那么这些年过去了，有没有那么一次或者几次，让你突然感觉到，智商问题才是人生的关键，以及你如何看待情商和智商的关系？

有时候，我们会因为连续遭遇了一系列跟某个课题相关的问题，所以在那个时候，会把这个问题分析得格外严重。我过去出发来感慨，比如我之说说过大部分人的问题都是智商问题，不可避免有情绪因素掺杂在里面。如果过了那个时期回头去看的话，这件事其实也没有那么严重。

说回这个问题，有没有的一刻会感觉到情商问题才是人生的关键？我肯定也有过这样的时刻，但整体上我不觉得智商问题和情商问题有那么严重。有一句名言我忘了是谁说的，供你参考：只有那些智商不够的人，情商才重要。这句话听起来也是挺让人沮丧的。所以我想就是个观点，跟你说一个好的消息和一个坏的消息。

坏消息是，绝大多数人的智商和情商基本上是先天决定的，后天能够略有改善，但是能改变的幅非常小。好消息是智商和情商对人生的影响和后果可能没有你想象的那么严重。

我讲一个智商方面的典型例子，九十年代的时候，美国全美智商排名第一个人，我忘记这个人名字了，好像叫霍布斯托马斯·格兰德是什么。他是全美智商最高的人，但是他的命运，不好说是悲惨还是怎样，反正我相信对于绝大多数人是没有吸引力的人生。他的工作是白天在家里写一本绝大多数人看不懂、即使是学者和知识分子也看不懂的科学哲学。晚上，因为他脑大开眼，并且他好像是过了几个星期的时间学会了将卡，然后在夜总会里做领牌，是这样一个诡异的人生。

然后全美排名第二的智商的人，他的工作是给智商测试机构智力做测试题，收入也很微薄。他这个人比较奇迹的是，败入很狼狈的情况下一直住在曼彻斯特。他跟媒体承认，他智商的大部分是用来解决如何在曼哈顿用那么低廉的收入维持生活。除了，多像是这类，并没有悲惨吧，肯定对绝大多数人来讲并没有吸引力的人生。所以，希望你明白，就是说我们先天的这部分可能对人生的影响没有那么严重。

过去这些年你除了是一个产品的生产者之外，还是一个消费者。请你列出最近值得购买的五件物品是什么？以及为什么？

过去的五年虽然我是一个非常忙碌的创业者，但是，消费这件事上，我什么也没耽误。因为我和很多女人一样，压力大的时候就会买东西来化解。所以我现在买了很多有用和无用的东西。

我过去和五年买东西其实非常多，如果你突然问的话，我就先说一下我能想到的几个吧。

- 1. 苹果的笔记本电脑。我每次用苹果的笔记本电脑的时候都有一个由衷感慨，如果这个世界上没有这家公司的话，我们无论如何要付出的代价、多少的钱都只能得到比它差很多很多的笔记本电脑。所以从这个意义上，我每次用苹果的笔记本电脑的时候甚至是怀有感激之情的。

- 2. 90分铝合金箱包。我最近一两年出差变得特别频繁。我会很想在意情中试试得到各种各样的名牌箱包，但是现在用的最多、也最喜欢的是小米生态链企业90分出的一个箱包。它的铝合金箱包只要1750块钱，但我可以用价格评价，以我非常挑剔、非常挑剔的用户标准去看的话，在绝大多数选项的比较里，我认为90分的箱包都是要过好市面上很多昂贵的奢侈品的箱包，比如rinowa的6000多块钱的箱包。

- 3. BOSE的降噪耳机。我每次用的时候心里都充满了感激，因为对于一个经常出差，而且要长时间忍受飞行噪音的人来说，这个产品其实是挺重要的，好像是2600多块钱。它如果如你试过了的效果，会觉得要6200块钱可能都是非常多值的。特别是，所有的名牌耳机现在都推出了降噪功能，但是你是横向比较的话会发现它跟BOSE的降噪效果比，就是那一点差距永远追不上了。

- 4. B&W的805音箱。说到耳机以后，我想起的一个音箱。我自己使用了这么多的音响器材，B&W是一个最伟大的音响品牌。我在办公室里面使用的是B&W的805音箱，差不多3万块钱左右一对，拿他横向去比10万多、20万、30万、甚至50万一些的设备，都没有听出明显的差距，那些大音响只是增加和改善了低频，而在中频和高频这些方面，相对于一个3万多的音箱来讲，没有太多改善。所以从这个意义上，你可以认为这个3万多的B&W805可能是全世界最超值的音箱了。

- 5. 日本品牌的功率放大器。说完了音箱之后，再说一下功率放大器。你去买一个跟B&W805能够搭配的任何一个日本品牌的功率放大器，几乎都是全赢。虽然在音响界有一个概念，大家都在鄙视日本的音响产品，但是我个人实际使用的体验和给很多朋友做推荐，只要是同价位的、任何一个主流的日本品牌的功率放大器是全面胜过同价位的欧美的名牌的功放。所以希望大家明白，如果你要给B&W805音箱配一个与之匹配的话功放，并且价格合理的话，选择任何任何日本品牌的，几乎不会出失望。

# 要“拿到钱比什么都重要”。

- 1. 任何时候，有钱就拿一定马上拿

除非给其他的投资机构的条款极度荒唐离谱（一般也不会发生这种事情），否则，谁给钱就拿谁的，一定要记住，只有到账的钱才是钱，其他的都不是钱。口头承诺的钱都不是钱，响当当的投资大佬口头承诺的钱也不是钱，甚至是响当当的投资大佬书面承诺的钱也不是钱，全球知名的行业巨头签署协议承诺给你的钱也不是钱。那什么是钱呢？

回顾中国这些年热火朝天的创业大潮，投资机构签完了投资协议后最后一刻出现意外、没打款，导致创业公司死掉的例子比比皆是。所以任何时候，只有银行到账才算是融资成功，其他的不管过程和细节看起来多栩栩如生，多逼真，都不能当真。

我们在2016年也经历过一次非常非常逼真的融资，对方签署协议后拖了很久，既没说取消，也没说继续。对方的影响很大，他们不打算签导致投钱的机构都不敢贷款新链快现了，足足半年后，我们资金链快见底了，一定计划把公司贱卖掉，为了操办变掉的流程，只好主动提出取消协议。

为什么会有这样的情况呢？其实原因不重要，反正能肯定的是，对方肯定不是故意伤害，大家都想做生意，他们这样做一定有他们的理由或者经历，重要的是这样使不备防，因此死掉。这其间另一个行业大佬要找我们，他更希望拿前面说的某家的钱，所以一开始虽然投没有拒绝另一家，但中间确实故意拖了一段时间，结果发现苗头不对的时候，另一家也心思不在这了，也没戏了。所以，记住这个血泪的教训，任何时候，有钱拿就一定马上拿。

- 2. 不要太在意公司的估值

你最好拿的是一个所谓公允合理的估值价格。太便宜了你吃亏，这不是说你都知道，贵了，你可能觉得占了便宜。

其实估值肯定是件好事。创业者融资期最容易肯定就是总希望估值再高一些，再高一些，这样自己开心，团队士气也高，出去跟朋友吹牛逼也挺提，但其实估值高了隐患很多。

如果下一轮大家都爆贵，你就融不到钱，如果你觉得不好融资，主动在下一轮愿意便宜一点，大家又会觉得你经营出了问题或者是没了信心。

所以你拿了最高估值机构的钱，通常意味着你要承受最大的压力，这也不利于创业公司正常发展。

再强调一遍，拿钱的时候，估值不重要，钱拿到手最重要。除非是荒唐离谱的价格和条件，否则，同一轮融资过程中，估值最低的那家如果马上就可以，那就一定拿他家的钱，不要犹豫。记住这个无数前辈的血泪教训：只有银行通知到账的钱，才是真的钱。

- 3. 不要过分在意稀释股权

只要没严重威胁到将来的控制权，钱拿得越多越好。即使威胁到了将来的控制权，它跟公司因为缺钱而死掉相比，也是微不足道的。

- 4. 除了不要在意估值之外，也不要在意融资金额少

形势不好的时候，比如动不动就未到的所谓“资本寒冬”，这时候资是资也是问，千万不要嫌少。早期融资是投资机构，反正后面还会有B轮、C轮、D轮。无论机构牛不牛逼也没关系，反正给了钱，能让公司活着发展下去，就没什么可犹豫的。再强调一遍，拿钱的时候，不要在意融资金额多少，钱拿到手最重要。

- 5. 拿行业巨头的战略投资时，不要怕站队

“怕站队”，这是在创业公司当中流传很的一句傻话，它的意思是，如果你拿了腾讯的钱，可选某些生意家不方便跟阿里合作，如果你拿了阿里的钱，有些业务跟百度合作，阿里可能就不高兴之类的。

其实，

比如你拿了A的钱，如果接下来发展的非常好，有出息，估值翻了好多倍，然后跟B有些合作，A会不会多不高兴，就算不高兴他也会忍，反正你都给他投了那么多的钱，他还能拿你怎么样呢？业绩好就不需要被迫站队，如果你接下来发展得不好的又怎么样呢？你很可能因此爆三发五要A家会求也求不了你，这时候你哪里是被迫站队的啊？这明明是感激都来不及的情况嘛。

所以呢，再强调一遍，拿钱的时候，不要在意站不站队，钱拿到手最重要。

创业融资的过程里，还会有各种各样的情况，有些事情不清楚的时候，牢牢记得参考这个版块的第一个：任何时候，有钱拿就一定拿，其他的都是小事。

在这个版块里，我们要讲的一共有三个部分：

- 1. 在成功地完成一轮融资后，应该过多

久就启动下一轮的融资？

创业初期，经常听到前辈们讨论这个著名的问题，这个题目配给出的备选答案分别是：“1. 一个月后；2. 三个月后；3. 六个月后”。其实，正确答案是：第二天。就是说，那时候我总觉得这是为了强调一件事情的重要性所做的戏剧性夸张表达，现在，经历了五年多的创业过程中的三次生死关头后，我觉得这个正确答案一点都不夸张都没有了。大多数的创始人，尤其是在业务本身投入精力较多的创始人，都会或多或少地会为公司钱本的事，而导致在找人、找钱的工作上投入严重不足，我自己就是非常典型的例子。之前我每一次启动融资都是一轮融资结束半年后才开始，结果每一次都得冒着风险上市。

- 2. 永远保证账上有一年以上现金。

即使你的公司已经是正现金流了，甚至是已经开始盈利了，脑子里的弦也要绷紧，不能放松。

微软天大教育员工说：微软永远离倒闭只有 18 个月；华为天大教育员工说：下一个倒下的是不是华为？你可能觉得这些企业都是状态好，其实是这些企业经历过残酷无比的生死关头，才会形成这样的危机意识。

其实，创业公司受限于融资能力，受限于观念意识，受限于是否那么多时间精力去找钱等等这些因素，永远保证账上有一年以上的钱这一点很难做到，或者说大多数创业公司都做不到，但创业时刻保持警惕，把这句话放在桌面壁纸上，每天呼喊一下自己，效果很好。

根据风险投资公司 CB Insights 的调研，29% 的创业公司倒闭是因为资金链倒的，这在创业公司倒闭的所有原因中排名第二。所以时刻绷紧这么一根弦，使自己每年保持适度焦虑最有益于健康，实际上，现代医学研究表明，保持适度焦虑，甚至是有益于身体健康的。

- 3. 创始人要用超过一半的精力去找人、找钱。

你花了一年的时间，亲自带着十几个全力整顿改造一个表现欠佳的业务部门，结果收获还不错；然后因为机缘巧合，招来了一个靠谱的主管，他只用了两个月的时间，就让这个业务部门成了公司的典范部门。接下来你用一年的时间亲自带队搞下一个你不满意的部门，还是用几个月的时间精力为这个部门招一个靠谱的、胜任的新主管呢？答案很简单：

你咬咬牙，招了一个年薪高达一百多万的、比你的工资还高的企业高管，心里一直嫌贵；结果他上班第一个月，就给公司免费带来了价值六七百万的资源。这时候你怎么看待他的所谓高工资呢？你可能会觉得他甚至是倒贴的。

公司找钱上，你亲自带队开源节流，带着一队人马，折腾了两个月，省下了两百多万支出来，你为此感到骄傲，感到得劲；接下来的两个月，你到算能感受到集中精力投资了，结果因为这两个月投入时间较多，多接触了两家，最后比原定的计划多融了三千万。这时候你该如何计算你前面的那两个月用于开源节流投入的时间和精力的价值呢？一边是用你两个月的精力省了两百多万，一边是你用两个月的精力多融了三千万，这个比较让人很崩溃。

## 第23篇 | 融资“三板斧”：和投资人相处的技巧 (3/3)

欢迎来到我的干货日记，你好，我是老罗，罗永浩。

本周的前三天，和你分享的是，“融资过程中普遍通用的注意事项”。

今天要说的是其中的第三个版块，也就是“如何跟投资机构投资人相处”。

- 1. 第一次启动融资时，你最希望接搞定的那一个或那几家目标投资人，最好先不要去见，先听人家来见你，练练手。多了跟投资人聊自己项目的普遍看法。了解的越多，准备得越好；最后去见目标投资人的时候，你已经不是几个星期前或几个月前那个完全没有经验的你了。

- 2. 如果要同时谈一批投资机构，最好提前对潜在投资机构的决策程序有个了解，必要时最后从决策最简单的机构开始谈，得到最后要决定的时候，有些家已经有结论了，有些家还没走完流程。但这么做的前提是你用于融资的时间比较充裕，否则还是像之前说的那样：谁决策快，就推谁谁；谁给钱快，就听谁。

- 3. 注意个人信用，一定要向投资人提供真实信息。履厉，数据、财务状况这些，可能谁都会做适度的美化，但一定不能造假。别指望尽职调查查不出来。也许你刚好在这方面没有道德和心理问题，不介意造假；即便如此，从技术层面上讲，造假也是很糟糕很不明智的选择。反正这个圈子就这么大，你想很窄的话，很可能大家都知道。虽然投资人还是优先的，国内创业公司创立者中的数据基本上都是造假的。问题是你在外面，永远不知道哪个创始人跟投资人联手对你造假：哪个创始人自己造假在投资人也坐监的，创始人和投资人联合造假的，投资圈里的人都造监能理解，创始人骗投资人的，投资圈里的同志们都造表示很愤怒，这听着来滑稽，很你合人性。你以为大家都是骗投资人，自己也高兴开心地骗，结果看穿后，投资人都躲着你，后面就没得玩了。

- 4. 如果创业团队里没有懂融资的合伙人或是主管，可以请金融顾问公司帮忙。虽然融资后要付手续费，但有执行力的金融顾问确实节省你大量的时间，让你少走弯路。金融顾问这几年，在两轮轮融资中都找到金融顾问，还是帮助我们解决了一部分问题的。但一般说来，如果你的项目到到处难以融资到钱，找金融顾问也不会改变本质。

- 5. 轻易不要签对赌协议，除非非水尽求。当然，确认山穷水尽的时候，把自己卖了也是正常的。美元基金通常没有对赌的毛病，对赌一般是人民币基金的口条。虽然存在个体差异，但整体上来说，美元基金会习惯看长期回报，人民币基金通常会制定限期目标。签对赌协议，会使得创业团队更迫于压力和决策时动作变形，比如有时候明明有更好的、更有利于长期发展的计划，但发现财务上可能因无法完成短期的任务，就只好放弃对长期发展更有利的选择，全力去达成短期收入，这样的结果，就等完成了任务，也很可能为将来的发展埋下了隐患。

还有就是，没有背景，没有后台，也没有经验的年轻创业者，如果那些名声不好的、老奸巨猾的投资者签了对赌协议（这类条款经常是违反法律规定的），很可能最后完成了业绩任务后，还是会吃大亏。

- 6. 尽可能多接触一些投资人，听听不同的投资者对项目的意见。

就算没拿到钱，通过交流学到东西也是有价值的。无论别人从别人那里听多少靠谱的忠告和建议，都不能替代直接跟投资人打交道。创业者常犯的一个错误是，拿到钱就赶紧去干活儿，钱快花光了再去接触一轮投资者，这种做法说明他从观念上就有问题。对一个企业家来说，

所以即便不着急融资，也要抽空跟资本市场的人多交朋友。多些投资人朋友，除了找钱方便，其他方面的好处也很多。比如，每天忙着做事的创业者，在科技前沿领域嗅觉敏锐。一半或至少会在每天听友的投资信息里面看到更多的相关信息。投资人掌握的科技前沿领域的信息，常常还是走进媒体或公众视野的，这类信息，对科性创业投资者来说，是非常宝贵非常多的。多数投资者更喜欢从自己的生意逻辑上，也喜欢给自己投的公司和自己熟悉的公司之间牵桥搭线，促成一合作，所以他的投资人朋友多起来之后，这类信息会主动来找他。

最后，千万不要总想着有一天能碰到一个特别有钱，特别懂你的投资人，和你成为知己，和你像灌满，我支走向辉煌的明天，年轻的创业者在成企业家传记里看到这种感人故事，总希望自己能碰到这种人物。一般说来，总希望能自己既碰到什么，而自己努力才创造奇谈获得成功的，最后醉酥都缺阵，全都被上有慧眼的投资人发现了，你干完请是什么意思呢？那些写成企业家传记的人到到知道成功的，是因为成功，所以和投资人成为了知己。

## 今日得到

- 1. 第一次融资时，先多听几家没多那么看重的机构练练手，然后再去你着重的机构；
2. 提前了解一下准备融的投资机构的决策进度，这样可以合理安排接触的时间表；
3. 注意个人信用，不要造假；
4. 必要时可以请金融顾问公司帮忙；
5. 轻易不要签对赌协议；
6. 尽可能多接触一些投资人并保持良好的来往。
