有些企业的发布会请明星来，目的是为了拉人气，保证现场的入座率。如果是为了这个，那请明星还不如直接把来现场的人送礼物，利诱他们出席。比如某手机公司就直接给来现场的全部所谓“粉丝”每人送一部公司的手机，现场感谢彻底爆满。当该公司CEO宣布活动结束时，大家可以去排队领手机的时候，全场对CEO发出雷鸣般的欢呼。但这显然看起来未必有多高大上，想要过好明星发布会就得，全会对着明星发出雷鸣般的欢呼，轮到CEO上台的时候，大家都在低头玩手机。

当然，有些公司一场发布会请几十个大明星，常常是为了对竞争对手秀肌肉、给合作方秀实力、对公众制造跟企业实力相关的话题等等，这是另外的商业逻辑，不在这里讨论。

# 3.细节决定企业形象是否派体面。

直播流行起来后，有些大众消费品的发布会会按照自身产品异常亲民的定位，现场会邀请大批瓜子脸主播来做现场直播，这无可厚非。但就怕你们不生气的是“狂妄者无比”的产品，只要不是情用品或给公司比这些特殊类目的，就需让用对经店说明细要求：要求出席现场的主播们穿着端庄得体，不要过于暴露。

很多企业高管，早年为了创业，都没没有时间谈，所以虽然人可能很体，但

现场有时候也会需要用到礼仪小姐，些可以找专业公司付费帮忙解决。但也要注意，最好提前跟对方沟通些细节，比如礼仪小姐的着装打扮风格之类，最好对对方一个具体要求，否则多可怕的事情都有可能发生。我一个好朋友的互联网融资公司在丽都（北京的一个商务中心）附近的酒店酒店开了一个大型的发布会，他们预算充足，所以发布会打包给了一家公关公司操盘，公关公司当天的安排和服务整体上几乎无懈可击，但由于某些未知的原因，现场十几个礼仪小姐全都穿着无比露肉的肉色的一件套式的小短裙，远远地看过去，就像……反正大家都很崩溃。

# 4. 要提前做好突发状况的应急预案。

，或多或少都会出现些问题，只是有些情况处理得好，所以观众甚至不知道后台出了事故似的。

KeYnote或PPT做的幻灯片出问题是常见的状况，通常最好的方式是准备至少一台应急的备用电电脑，并且连接到专业的切换台上，现场出现问题时，观众甚至来不及反应，就无缝切换到另一台备用电脑上了。

麦克风故障是另一种常见状况，应对方式上上的演讲会在胸前别至少两个无线的胸麦，这样如果中途出现异常时，负责工程的工作人员会关掉掉其中一个胸麦的声音讯道，打开第二个备用胸麦讯道。

为了镇定自若地消除这种可能的危机，给现场工作人员应急培训做培训，演讲者提前准备几个应急笑话是小道故事，是比较有效的方方。虽然这种临场应变能力跟运作企业的能力没什么关系，但普通观众下意识地会觉得：一个在这种急情况下，轻易淡定地把危机化解掉的人，看起多像是无论如何都能把麻烦变成把公司运转好的企业领袖，而那些在方面欠缺训练，但其更重要的是方面非常优秀的企业管理者，在事故现场的公众眼里，通常会显得笨拙和无能。

另外，由于现场情况很复杂，而且不能提前预测所有可能发生的状况，所以仍然可能需要专业的主持人在旁边用各种方式帮忙救场，这个最好和主持人事先也彩排一下。

# 6.做企业的人，要想尽一切办法解决问题。

最后，我对于那些性格比较细腻敏感的创业者我想说的是，多数情况下，企业的发布会作为一种仪式，都会显得比较假，比较无趣，甚至比较没劲。但时不时地完成一个仪式性的东西，是一个成年人的责任。对创业年的成年人来说，更是一种必要的工作和义务。

那些年轻时对很假、很无趣的、很劲的婚纱照摄影嗤笑不已的男人，最后结婚的时候，几乎都无一例外的，为了让老婆高兴，去拍了一本厚厚的、很假的、很无趣的、很劲的婚纱摄影集。这是人类的婚姻，最让我感动的部分之一。
