对于他仍然是一个超过60分的表现。但实际上并不是这样，这会给后来的工作带来很多很多的问题。

比如另外一个人人品是80分，工作能力表现是100分，企业往往发现，比如说出现资金短缺的时候，要寻求恋人关系不是多了。

多了的时候，一个比较清醒的判断就是说，那个人品分数特别高，但是工作表现不及格，应该毫不犹豫的裁掉他，要不然你企业没办法正常去运转。你裁掉这种人，你又发现危害也非常大，因为很多人因为他人特别好，跟他结下了很深的感情，裁掉这种人的话，对内企业讲也会造成非常不良的影响。所以，一个企业的人力资源一定要想清楚，就是说一个人人品好，过了及格线就可以了，在判断一个人的综合素质和能力的时侯，它不应该成为加分项。

这个还带来另外一个问题，就是说一个社会上人品特别正、道德感特别强的这种人，他下意识地在这些方面是有优越感的。因此，我发现一个企业格外强调他价值观和理想主义的时候，他自身追求这个东西来，不可避免他自己也认为这是一个加分项，这个心态也导致了后期他工作表现没有那么好也导致，但他认为自己在那些方面是加一些分，这方面是减一些分的，那你说来就问题不大了。因此，在一个注重理想主义价值观的企业里，理想应当地享受到更多尊重。这是非常不好的一种判断。这是第1点。

# 2、性格差异不应该成为判断一个人表现好坏的角度

有些人因为性格上的问题，可能跟我们的沟通方式不太一样。比如说我们初期的时候，无论人力资源主管是我，还是其他的高管，还有普通同事，我们会看着一个人跟我们是不是是一类人。这一类人其实我觉得更侧重的应该强调的，比如说他是不是有事业上的追求、跟我们的理念是否大方向一致、愿意去更多的东西、愿意去要求更严等等，基于这样的方向去判断，而不是性格上的差异。

比如说，有些人就是不爱说话，那我们相处沟通的时候有些同事说他是个人，但从不合理他会跟我们是这一类人。我们不愿意、价值观和大方向追求上可能是一样的，只是性格导致不一样。还有些人有一些想法他不愿意说，有些事就觉得自己不真诚，觉得他威胁感、容易吵也不知道，在我们的初期都会容易把这些人理解成跟我们不是一类人，就觉得他可能不好，但实际上工作和上的表现可能比别人的多，而且人品也没有问题。我们因上有个体差异，但这个不应该成为判断一个人表现好坏，甚至是上升到不是人品有问题的角度。

所以我们早期，我自身也犯过这样判断上的错误，后来实践证明，很多进来的时候他不太愿意表达他真实想法，我们有一点犯嘀咕的人，后来工作表现有一些是非常非常好的。并且，我们需要相处一个星期就能够敞开仓库，这个有没有跟伙伴半年相处才敞开心扉，这个人就是是对错的。所以不要因为有些人跟你性格不一样，或者说他愿意坦诚交流就判断他，可能是说在人品上是比较容易误判的一些事情。但是，你也可以从另一个角度认，是那些人才性格上比较吃亏的地方，他不愿意跟你交流，你可能会认为他有问 题。这是第2点。

# 3、为赚钱而来是正当理由

第3个想说的是说，有些人来的时候其实还很诚的说跟咱们人力资源说，他来这个企业最主要的目的就是为了赚钱，而且他觉得我们可能能发大财，是这么来的。早期的时候，我们人力资源的很多同事很不喜欢这种，觉得人是这么的有理想有追求，然后打着理想主义旗帜的这么一个企业，你什么是完全冲着钱来的，就觉得这人特没劲。

我觉得这个也是非常有不得的，其实是很早就看清了这一点，跟人力资源有过很多的沟通，就是我想让他们明白，不管我们多有理想，多有追求，我们本质上还是有个商业机构。如果一个人就是为了赚钱来我们这儿，我们非常欢迎，只要人品没有问题，非常欢迎。如果有能力、有追求、能够在这儿赚钱，把事情做好，又想在这儿发大财，共同跟随在理想主义和追求上有一些共识的东西，从一个企业的角度，这是你额外赚的，不是你应当从一个求职者身上去取的。甚至某种程度上，他特别早期、特别激进的时候还更感谢，他很为了赚钱，他为什么看不上你，没看不上别人呢？其实是很好的事情。

所以，我觉得一个人人品没有问题的大前提下，来你这儿就是为了赚钱，很好，这是非常难的。如果你在理想主义和追求、价值观这跟你有深层次的共鸣，并且愿意牺牲一些自己的时间也好，额外付出也好，跟你去尝试共同实现这个东西，那你看从企业创始人的角度这是他额外赚的。这是我想说的第3点。

# 4、聪明人更倾向选择公平正义

最后一条是我的一些感想，就是说为什么一个企业选择人品这件事，撇开你的价值观，敞开你的理性主义，撇开这些东西，它仍然是一个理性的选择。因为从概率上，很多人品好的，多数情况下是因为他们智商高，一个人选择要讲骗讲设计，耍那些小伎俩，来谋自己事业上的进步也好，人生的的一些好处也好，是因为他傻。聪明的人不会去选择这样的选择。

所以，就这一点，我想跟你分享的是我之前，大概是2014年的时候在微博上写过的一段话，这句话是说：

> 最后，郭建斌的问题还问到，人品和你对价值观的定义是不是一个意思？从我个人的理解来讲，我觉得就是一个意思。

一家公司快倒闭的时候，其他公司会过来吸纳优秀员工，可是这种情况如何知道哪些是比较优秀的员工。看起之前的职务吗？毕竟公司内部绩效考核其他人公司也没法清楚。

其次，很多公司会用内部推荐奖励吸引人才，转公司再推荐推荐另一个人进公司，转手之后会给你推荐的人一部分奖金，如果推荐的人能力很秀就会获得更高的奖金。这样做是ok的吗？还有其他什么方法吗？
