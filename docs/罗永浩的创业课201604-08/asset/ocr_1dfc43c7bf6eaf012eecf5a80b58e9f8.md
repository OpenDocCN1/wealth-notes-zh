用户的费劲放在那里。一般来说，这种活动如果有那些老用户的大的厂商的赞助，实际上不如产生更多的收入和更大的影响，对这个活动本身是一个综合的加分项。我们以前由于缺乏这方面的意识，完全没有去做这样的事情。

# ## 2、从来没想到过：公关部是不可或缺的部门

我们过去创业过程中，盲区导致了一些非常可笑的事情。比如作为一个创业公司，我们早期的那十几二十个人的草台班子，走到公司有一两百人规模的时候，人力资源的主管有几次为我说公司应该有一个公关的公关团队，至少有一两个全职责公关的人员。

当时由于我对运作企业这种事情还是比较幼稚，了解得很少，所以我一直自以为是，固执地认为企业里面的公关都是因为企业的负责人出去做了丢人现眼的事情，需要一个专职的要帮他处理。在我的认知里，一个企业只要用得正、没有什么缺德的事情，完全不需要一个专职腰服的这么一个团队。等到公司出现了一个严重的公关危机之后，我才意识到这是一个非常专业的工种，对于一个成熟的商业公司来讲它绝对是一个不可或缺的一个部门。

# ## 3、从来没想到过：自带流量和全年流量是有重大区别的

我们在早期运作企业的时候一个认知上的重大盲区是，对于所谓的网红人物能够自带流量这个概念的认知。

早期很多我们的合作伙伴，包括我们团队的很多人，就说我们跟的公司有一个重大的区别，就是一般的公司要购买电商销售所需要的流量，一定要花很大的代价花钱去买流量、引流量才能实现，但是它由于是一个知名的网红创业的公司，它有流量，这个使得它能够去做到电商，比其他试点在电商渠道销售的手机公司具有天然的优势。

但是那个时期我们不知道的是，

，而全年流量，我在那个时期是完全没有概念的。

很多人可能不知道，即便是全世界最知名的一些科技公司，比如说谷歌，它每年收入的一大块都是用花钱去购买流量的。如果你明白了一个这个一个基本概念，你就会认识到一个网红所攒得的基础流量足以支撑一个电商的运作，是多么荒唐的一个认知。但是在初期由于我们缺乏这方面的常识，可能会出现极其可怕的偏差。

还有，我们刚开始启动自在线上销售的时候，由于无知，不会自信在电商领域这种优势，我们没有跟京东、天猫、淘宝或者任何一个主流的电商合作。我们的第一代产品11发布前前夕，京东的3C业务负责人、京东的副总裁王笑松亲自来电拜访，要求在京东平台上售卖我们的手机，当时我们非常礼貌地拒绝了；然后天猫的团队也跟我们沟通过，也是被我们礼貌地拒绝了；还有中国的最大国美来找我们谈线下的销售，也被我们礼貌地拒绝了，因为当时我们坚信自带流量，完全不需要跟这些合作平台合作，自身就可以活得很好，就是这么一个荒唐的认识。

# ## 4、从来没想到过：需要专业的销售团队

当京东3C业务负责人王笑松要求跟我们的销售团队对接的时候，我非常坦然地告诉他我们没有销售团队，他当时感到非常震惊，因为他来成了好朋友之后他告诉我，当时他离开我们公司的接待，跟他同来的几个同事，不知道老罗葫芦里卖的什么药，他们猜想可能会搞什么很厉害的措施和很变态的招数，他们猜来半天觉得以自己的情况完全猜不出老罗半句的话究竟是什么意思。等到后来我们变得非常熟悉以后他才知道，我们采取了一系列起来非常神奇的一些举措，背后的逻辑是无知甚至是傻。

作为一个连销售团队都没有的手机公司，我们开卖之后又成个什么样子呢？幸亏当时市场部有一个年轻的同事，他在读书期间开发过淘宝店，他就给我们写了一个数字，按照平均水准来推测，引来的客流量里转化3%~4%是一个比较正常的数字，有一些运营得比较好的公司，可以做到4%~5%这个样子。我们这种电商只有百分之二点几，显然是因为整个电商销售的服务团队、销售团队是完全不及格、不称职的。
