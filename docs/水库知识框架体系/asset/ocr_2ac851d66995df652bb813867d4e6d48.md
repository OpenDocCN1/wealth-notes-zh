# 352

答：真正的 T-1，应该是简单清晰，而不是复杂繁琐。只有父母自己掌握 T-1，父母才能传授给子女啊。

# 353

问：我对如何教养小孩产生了极大的怀疑。买学区房学钢琴考一本，然后五千块一个月，都是歧途。甚至多陪伴小孩，似乎也是歧途。应该赚钱，爬阶，用自己积累的优势，给孩子铺好路，然而有的工作对孩子并无帮助，否则祖帅爷的先辈也不会留下“不当穷教书匠”的祖训了。所以要么跳出舒适区重新出发，要么教会孩子用 t-1 思考，才是最重要的财富吧？

答：每个人的学习能力都是有限的。越是 T-1 的规则，越是精简。则学生单位时间学到的东西越多。
