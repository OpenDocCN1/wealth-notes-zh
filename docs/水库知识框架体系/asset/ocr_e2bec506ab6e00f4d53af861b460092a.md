# 第一部分
历史类书单

# 01

问：你为什么那么喜欢读历史？t-1是？不过确实挺有趣的。

答：历史是最高文化，远超过一切知识。只不过屠龙技，等级低用不上。

# 02

问：最近拜读了下水库香番外篇部分关于《论儒·法·禅宗·基督自治及道教的复兴#F10》以及后面的《三代之治#F129》系列7篇，实在大开眼界，醍醐灌顶，想问下您关于哲学和历史这部分认知是通过什么渠道学习的？另外，有没有对你触动很大书籍或人推荐？

答：在这个世上，有资格做我老师的人，不多了。《资治通鉴》，吴思，冬川豆。

# 03

问：印象中您以前推荐过柏杨版的资治通鉴，近期看您对这一版本评价又不高，要看的话到底哪个版本好？您有其他史书推荐吗？

答：《资治通鉴》，能翻译成白话文就不错了。夹在中间的“柏杨说”，可以不看。
