# 主题二
## 关于孩子的T-1

### 486

问：“重视智力成长”，能具体举例说明一下吗？该如何操作？

答：反应力，理解力，T-1的领悟力。譬如自己想出 16*16该怎么算。

### 487

问：我是一名老师，我理解你说的T-1在应试方面的应用是要帮学生对每门课建立知识结构，然后以知识结构应对万变的题目。这样理解对吗？

答：有些人看见的是橱柜，有些人看见的是三角形，有些人看见的是直线和角。（王马丁：有些人死记认字，有些人记住声旁形旁理解了造字）

### 488

答：T-1不是一二句话的。譬如《老爹给你的教育》中的，老师会不会看你的家庭作业。

### 489

问：如何看清华附小学生从小就开始培养这样类似研究苏轼的功能？这样教育后果是啥，培养S币？您看小孩是否有必要这样教？那么小学幼儿园阶段如何教正确？

答：这个完全教歪掉了。小孩子应该学T-1的原理，例如好奇，思辩，怀疑。你学这种“匠人之术”干什么。
