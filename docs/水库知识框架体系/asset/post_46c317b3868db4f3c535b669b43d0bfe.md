# 丑房焕新 “房住不炒” 新形势下新房东的第一堂课

于是季老湿发了 50 页的大纲内容给我，我认真地看了两个下午。

概括来说，季老湿的逻辑流程是这样的：

（1）确定目标客户。市场上存在一群客户，追求更好、更有品质的生活。客户的需求是整个市场存在的基础。

（2）确定经营区域、板块和户型。

（3）确立合伙人体制，产品才有灵魂。

（4）确定套路和套餐。“业余”和“专业”的区别，最关键在于套路。专业的公司大都是有一整套打法的，大都有几种固定的套餐搭配。

（5）出租增值业务，出售增值业务，合伙人加盟模式。

（6）实操。

季老湿讲的几种手法，确实让人耳目一新。

例如员工带客户看房进门，会邀请客户洗一下手，让他感受三秒流出热水的温度和水量。

水系统的领先还是次要的。关键在于“温水洗手”，这在心理上是强大的暗示，让客户感觉欠了你一份人情（水的消耗），可以极大地提高签约率。

这是非常重要的一手资料，只有奋斗在最前线的工作人员才有的智慧。这也是这本书的价值。

再譬如说，细节决定成败。

丑房焕新最重要的细节是什么？竟然是开关面板。

品牌开关面板很贵，动辄几十元一个。很多庸作，做完之后，从人员总觉得差一口气，自己装的就是没有设计师好看。

为什么？匠人和大师差在哪里？差的可能就是一个“诀窍”。神之一手，画龙点睛。“所有的开关面板，必须全部换新。”这一句话就价值千金。

迫不及待，我已经想要买这本书看了。
