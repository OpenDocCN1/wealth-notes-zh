# 要点总结

每个行业都说我们很特殊。但是，我们常常高估自己的特殊性，低估共性。

在商业本质面前，行业与行业的差异，其实很小；在基础模型面前，历史总是一再重演。

没有人是神，可以准确地看到未来。但是我们可以通过模型，看到影响未来的力量。你，是否也从模型的力量中，看到了未来呢？
