# 第三，多打比方

打好一个比方，通常有三个步骤：

+   1. 找到你所描述的这个陌生事物的本质；
2. 然后在你的模型库里，匹配有相同本质的，大家熟悉的事物；
3. 然后用这个熟悉的事物，解释那个陌生事物。
