# 要点总结

这一讲，我们学习了“如果”一个增强回路，遇到一个调节回路，“就”会怎样的“受阻模型组”，并练习用它预测未来。

受阻模型组里，可以用来预测未来的模式有三个：

+   1. 公地悲剧。它的本质是：一组多吃多占的增强回路，遇到一条资源有限的调节回路。投资期的后面，必然是崩溃期；
2. 成长上限。它的本质是：一条高歌猛进的增强回路，遇到一条高处不胜寒的调节回路。平原期、爬升期之后，必然是高原期；
