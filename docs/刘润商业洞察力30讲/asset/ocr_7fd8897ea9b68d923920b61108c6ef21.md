# 5. 滞后效应

滞后

有一位80后企业家，打算二次创业，踏踏实实地开一家日用百货连锁店，
卖眉笔、耳机、充电线、收纳盒等等。他考察了很多选址，逐个排除，最终
在两个地方举棋不定：

+   1）地铁站，2）购物中心。

选哪个？

这还用选？必须是地铁站啊！地铁站熙熙攘攘都是人，租金也比购物中心便宜。“顾客”在哪里，我们就应该去哪里。当然选地铁站。

真的是这样吗？这位企业家决定，让真实的经营数据来作选择。于是，他在地铁站和购物中心，各开了一家店。

结果怎样？结果人来人往的地铁站，亏损严重；而顾客明显少的购物中心，
非常赚钱。

唉？为什么会这样？这不符合“常识”啊！

常识，常常只是对表象的认识。要理解这个问题，我们必须要透彻理解“顾客”
这个“变量”。
