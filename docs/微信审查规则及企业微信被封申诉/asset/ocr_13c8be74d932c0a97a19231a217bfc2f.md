另外，如果在短时间需要添加比较多客户，可优先考虑使用“多人联系我二维码”，避免短时间

很多客户添加到一个帐号里。谨慎进行大规模主动添加客户的微信，比如集中通过手机号在线

搜索添加客户，给微信客户造成骚扰。

+   2. 企业里有员工帐号被封禁，会影响整个企业吗？

会根据影响恶劣程度以及企业的实际使用情况进行处理，详细可参考上文的违规处罚规则。

被封禁。

+   3. 企业微信如何养号？

+   1）企业开通企业微信后，建议每个企业微信号绑定一个个人微信，不要多线操作；否则在添

加微信好友的时候很可能会被提示账号异常；

+   2）企业微信必须有内部正常的使用行为，比如说内部成员聊天讨论、工作上沟通、上下班

打

开、朋友圈内容、邀入驻企业微信等等；也就是说，如果你开通企业微信后就疯狂开始加人，

基本上不太可能实现。企业微信的部分功能可能会受到限制，尽管目前的门槛级没有明确

规

概

率上可能是受到权重影响。

号，
