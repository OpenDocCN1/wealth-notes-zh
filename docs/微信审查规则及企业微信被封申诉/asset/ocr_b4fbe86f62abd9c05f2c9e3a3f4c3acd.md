# 微信审查规则及企业微信被封号常见问题及解决方案

最近微信、企业微信，监管特别严，我们自己好多微信号都被限制的莫名其妙。但是没办法，微信是最适合做生意的社交平台，必须适应。

所以花爷找了腾讯上班的朋友，聊了下微信审查规则到底是怎么设计的。

1. 微信审查的思路。

具体的算法如何，肯定是一直在调整的，但微信审查的思路，在腾讯内部论坛是有讨论的。

微信大致把账号分成四类：正常号、重启号、恶意号、惯犯号。

如图一所示。

正常号：你被封号过，没关系，只要你申诉解封，然后距离下次封号之间的间隔够长，仍然算是正常号。

重启号：被封号后，等熬过了微信的封号期限后解封，后续继续正常使用。

恶意号：同时被多个策略处罚封号（比如你又恶意营销、又涉及侵权、又涉嫌欺诈）。

惯犯号：连续多次被同一个处罚策略封号。

后两者的账号会被极大降权，基本上很难恢复权重了。

2. 微信审查的关联性。

当我们微信号被封，申诉时需要邀请好友的微信帮忙。

以前，有专门的团队做这个帮忙申诉的生意。你违规了，我有一批号可以帮你申诉，付钱吧我帮你搞定。

但现在不行了。

首先每个号，帮助申诉的次数是有限制的。

其次，申诉的时候，申诉是否成功，跟帮忙申诉的微信有直接关系。

记好了，当你请好友帮忙申诉解封时，如果你的好友账号权重低，申诉不仅不成功，你和好友两个人的账号权限还会被进一步降低！

直接进入恶性循环。
