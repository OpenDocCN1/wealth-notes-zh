# 西贝超级符号的来源

在2013年接到西贝莜面村这个客户的时候，我发观有一个问题，就是这个西贝莜面村的“夜” 字我不认识，我还没有为读xiāo呢。你想我搞这肯定是属于以多识多的，我不认识的话，全国可能好多朋友都不认识了。

再看那个店面形象，当时西贝的定位是西北菜，整个店面到处都是西北，纸糊的窗格子，炕头、窑洞，一串一串的辣椒、一串串的玉米，带着浓浓的西北的乡土风情。

![](bbox=[0.05, 0.63, 0.95, 0.78])

那么，咱们第一讲就讲了文化母体，品牌寄生、超级符号的华与方法，对不对？那西贝之前也不认识华与华，也不知道这套理论，但是，你看它是不是也本能地用了这套方法？

纸糊的窗格子，热炕头、窑洞，挂起来晒烤的-串串的辣椒，玉米一 一这不就是西北乡村的符号系统吗？它之前定位是西北，不就是以西北为文化母体的吗？西北这个母体具体地，因为符母体的西北是新疆、陕西、甘肃、宁夏和内蒙的西部，但是内蒙古的企业，老板是内蒙人，但它是使用这个符号，在我内地人看来，倒好像是陕甘边区的汉族乡村的文化，感觉到延安了。

所以，用我小说，品牌是企业的文化资产，是一套符号系统。那我们要不要给这个西北乡村文化母体，要不要老陕乡下热炕头，辣椒玉米炕游天游的这个文化符号系统呢？
