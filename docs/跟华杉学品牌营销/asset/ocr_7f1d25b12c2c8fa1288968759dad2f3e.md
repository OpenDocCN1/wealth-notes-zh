# 03 | 超级符号：怎么让人快速接受你的品牌？

你好，我是华杉。欢迎你来到我的得到课程《华杉品牌课》。

前两讲，我讲了人文主义是符号文明，一切都是符号。物品是符号，品牌也是符号。品牌的作用是传播，而传播又是什么呢？传播就是对符号的编码和破码。

# 编码目的是让人行动

我在这讲的这门课，就是用中文的语音符号来进行编码。你收听的过程是理解符号的过程。如果你不懂中文，你就不能完成解码的过程，那你也就不知道我在讲什么了。

所有的品牌设计、包装设计、电子商务的页面设计、店面的设计、橱窗的设计、广告的设计，都是符号编码的过程。

那么，怎么来编码呢？怎样的编码才能让人去解码的效率最高，对它们动作的影响力最强烈？那就是用超级符号来编码了。

前面我们也讲了，超级符号就是人人都识得的符号，如果你用了人不认识的符号来编码，那么他就没法解码了。

比如说我用在突然讲俄语，如果你不懂俄语，那你就没法解码。

如果用人人都熟悉、都喜爱的符号，而且这个符号让他感觉到愉悦，那他就能够解码。并且人人都能很快的在他的指令下的符号，如果他看了这个符号就有动作，就有行动，就有一个行动之前都未听说过的新品牌，会在 一夜之间忽然成为他的老朋友，他会有动作会为你有强烈动作。我们喜欢，然后消费者做出购买的动作。这就是我们需要超级符号来给我们发挥的作用的，就是我们讲到的像红绿灯，男女厕所标志那样的符号，直接让人行动。

有没有人用过的红绿灯的符号做产品的设计？有，就是大名鼎鼎计算机公司的乔布斯，如果你的电脑是苹果的系统的话，那么你看它的视窗，左上角的就三个符号，是不是一个是红色的，一个是黄色的，一个是绿色的，红色的就是关闭窗口，绿色的就是打开全屏，黄色的就是隐藏。

所以，你不看到一个那个叉，是一个叉加一个减号，不需要是一个加号，你能够技术能来操作。这三个颜色是不是比微软的那个窗口更感觉简易？而你是绝对不会有思考的，你不需要经过思考，不需要思考，直接就可以行动。这就是用了超级符号的符号，寄生在了红绿这种大家熟悉的符号上文化在体上。所以，每个人有共识，每个人有它的指令来行动。

乔布斯是怎么想出这样的方法的？我看了《乔布斯传》，里面说在他也年轻的时候，有一次他的父亲带他回家乡——威斯康辛州。他父亲家有一个原奶牛的农场，乔布斯就去小看了，正好看有一头奶牛生下一头小牛。他说，这个小牛一下生下来，自己落在地上站起来了，没有人在赶它，它就没有走过去，就是小牛肚子里面好像有全部的电路。乔布斯觉得所有的产品都应该这样设计，让消费者没有去就会做。

所以，我们不是编码和解码吗？这个解码并不是只是让他识别或者能够记忆，最重要的，或者我们最重要的目的是要让他的行动，或者符号所要的行动就是让他购买。

所以，你要记住这一点，让消费者购买是我们的目的目的，不要什么都想想，也可惜说了，但没有行动不是想法。那样也不行，不是我们品牌符号的目的。
