在前两讲，我们分别讨论了参与者和购买者，在这里，我们讲体验者和传播者。

我先讲体验者，体验者实际上就是使用者，因为他们开始使用我的产品或者服务了，那么使用体验感，所以，我们设计一个产品，往往有两个设计，一是购买路径设计，一个用户体验设计。

如何设计购买路径，以及通过购买路径来创收讲师们讲，以上一讲已经讲了。这一讲我们讲如何设计用户体验。

用户体验的设计主要从三个阶段入手：来之前，来之中，走之后。“走之后”就入到我们的消费传播第四个角色，传播者。这也是为什么我把体验者和传播者合在一起里面来。

# 来之前：让他带着期待来

“来之前”是让他带着期待来，这是让我们在买商品或服务的时候，提供信息服务，让他们有所期待起来，比如说提供“房子”这个，他就有对干净有期待，有期待来了吗？你一定会得到干净的身体，甚至超出预期的干净体验。

# 来之中：让他有惊喜

那“来之中”呢，就是要比他期待得再多一点点。“来之中”顾客满意吗？顾客满意不是一个绝对概念，是一个相对概念。如果他期待值很低，那么来了之后如果不差，他觉得满意满意；如他的期望值别的的高，甚至已经高到超出了你的服务能力，那他觉得再好，也不满意。

这个体验的设计很典型，我觉得就是360体验器。因为周鸿祎是用户体验设计大师，360浏览器能够很明显的开始时间少，然后他的功能描述语言已经获取了全国多少的伙伴。这就是设计了一个用户体验，让你确认它的价值。

还有洗衣服的这个产品的设计，它说它含有速进因子，然后就把它颗粒染成蓝色。这是让用户体验的设计上，让你去确认它宣传给你的价值。

确认之后还得满意，什么是满意呢？就是超出期望。有一句古话，好事原则，叫做无尖不商。又叫无商不奸。

你可能会奇怪，那么奸商是顾客满意吗？我常讲这个奸商的“奸”字本来是尖的头，是一个尖头的商。尖头尖就是不合群，不合群。这个大尖是什么意思呢？就是人以人开价来买，顾客要买一头牛，那么商家就说一头牛，把它装，装到牛，堆起来不超过一头了。这时候，买家一量一下，把它的部分把它切，那么切到，就让你确认这是一头了，对不对？但是，你不一定呢，可能你割掉了他看了着看看有小，就让我割到那个地方再量一下。怎么办？商人为了解决这个问题，拿一个小桶，倒进一头，在这个桶中的小桶里有一头，这就是让你确认百分之百地超过一头了，你肯定是占了他的便宜了。这就叫无奸。

所谓无尖不商，就是说如果你不给顾客一个尖头，让顾客占据一个尖头的位置，你就不是个合格的商人，这是他们中国古代优秀的商业文化，可惜慢慢地就演化为说法，就传成了奸商。

顾客满意就是要你超出期望，让顾客能占一个尖的位置。这个无论是2C的还是2B的意思，都请仔细想想自己，自设计，你事先就设好让顾客到底能占你什么便宜。即便你能让顾客占的便宜，至少你设计，要顾客确保他绝对不会吃亏。

比如西贝说：“跟着狼点，进道都好的”，不是给顾客一个很大的那期望，进道，狼点，进道都好吃。那狼怎么吃。那不吃怎么办？不吃好，不好吃怎么办？那就叫“不好吃不要钱”，所以，你在去见狼，你不要狼费，进道菜不好吃，马上给你取消，免得你一直说进道菜不好吃进道，你马上会观察，你另外的菜品也剩了多少，你给我问：“请问这个你是不是不好吃，会给到你？”

这样一来，至少让你不至于吃亏了，是让他这个让顾客不亏亏，结果也让顾客满意了，为什么呢？因为顾客亏到亏吃亏，为了什么？因为太坏了，别的地方去说不好吃，从没有人端进进，还要你赔钱，太坏了，要半碗亏，所以，坏人太少了，正常人都成了好人了。

其实这样的顾客满意体系，它也不完全是精明的营销算计，它其实是一种经营的诚意，种商人商家顾客之间相宜的一种信任，一种心，一种文化。比如说海底捞，大家说海底捞的服务不得了。海底捞的事说，大家说我服务好这个事你，你吃吗，总说那服务好，我，也不知道海底捞的什么，人家来你海底捞吃，还要招待，你总得招待一下。那家客人来不呼，也我是不是招待一下，又说服务好，那我们自然不好意思，就说我们的顾客满意，然而不多多少成本，于有人专为你指指甲来，那来了个活就怎么？人家都是，你怕人家不吃就不来了吗？这就像是一个人心，你说多少成本，往里面去，排里面坐了一点点其他的其他的服务。那里面都是你坐满了，你的公成本都撑死了，我们已经边的利润空间本来就很大了，你再给他涂下指甲又算成本吗？他说，就是这么多一点点做人做商的心意，海底捞就赚“吃到为止”的心意，我看海底捞实际上就是种最朴实的中国民间的善民而已。

# 走之后：让他带走物品，乐于谈论

在“来之中”，让他有惊喜，设计好让顾客带走走的，使他的满意，考虑好让顾客带走走的物品。“走之后”是什么？走之后，顾客就变成了传播者。高离开我们，他满意了口碑，所以，“来之中”是价值确认和体验惊喜。

“走之后”呢？12个字，值得回忆，乐于谈论，带走物品。

“值得回忆”是有他记得的东西，“乐于谈论”是您愿意去处理别人，“带走物品”，这也是您去处理让别人，这就是传播者。“带走物品”就是最后还能带走一些东西，成为证据，还可以拿去展示给别人看。

我举个，你理解我了。十几年前，那个时候坐机去他回来，那比如说有一个入去二进巴尼亚，那么见到了所有朋友，他，哎，我这去巴尼亚就像一样，你们，那你都是，那我们在巴黎的时候怎么怎么说，就是不是我们在很享受回忆，乐于谈论的事情告诉同。然后你的东西里面去，我看见他在客厅里面，到地方，去一个埃菲尔铁塔的小模型，他给我介绍，这是他在巴黎购得的广告，那么埃菲尔铁塔的钥匙是什么？就是巴黎旅游局是在他的旅游广告，而二旅游局，巴黎市旅游没有花一分钱，还掉了他的。

所以，你要有一些事情，有一些故事，让人家值得回忆，乐于谈论，到处去说，最好让他能带走一个传播信来讲述，你看，人见证俱在，那顾客不就来了吗？

那么，西贝的这个“love 夜”，我们也做了一个个性的，就是给小孩用了小围。顾客非常喜欢这个小围，那他吃东西，可以带走的。带走之后呢，他吃的的时候的时候，那这围了没有提供这个小围，又要带小孩的把他的这个围放到，小孩喜欢西贝的小围，其他如没有没有看，也说是说有这样一个小围，我们把我看到做到围的到围里面了。我们不这样靠例举，是消费行为，他自己就变成了这样。

海底捞你人去海底捞吃饭的，服务员帮你一下，去吃饭的，哎，呼，你这直，他一个娃娃娃、一个小姐孩你去，的，你看，哎，啊，这是真是人类体验了你。你看，然后你赶紧拍个照，发朋友圈，说到微博，然后大家都转了。
