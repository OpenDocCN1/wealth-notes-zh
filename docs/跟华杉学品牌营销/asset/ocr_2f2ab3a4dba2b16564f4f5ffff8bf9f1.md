# 12 | 资产原理：品牌信息露出越多越好吗？

华杉

你好，我是华杉，欢迎来到我拍摄的得到课程《跟华杉学品牌营销·30讲》。

上一讲我们讲品牌资产的概念，这一讲我们讲品牌资产操作实务。怎么操作？分四步操作：

+   第一步，品牌资产盘点；
第二步，品牌资产排序；
第三步，制定品牌资产目标；
第四步，品牌资产投资。

这一讲，我们先讲品牌资产盘点和排序。

# 品牌资产盘点

上一讲我们说品牌资产就是能给我们带来效应的消费者的品牌认知，这个认知是什么呢？就像你认识一个人，你知道他做的名字、知道他的长相，还要知道他的一些事情。因此，你就会被信任，就愿意跟他打交道。这个认知就是我们前面讲的资产。

那么，这些认知一共都有哪些，我们盘点一下，这叫做品牌资产盘点。比如，可以得到一个品牌资产盘点公式，也可以不用，我们现在在讲的是什么产品，你都可以把顾客对它的选择贵公司、他跟别人怎么样比较，练习做个品牌资产盘点。

我们拿西贝莜面村举例，做一个品牌资产盘点。

首先，西贝最大的品牌资产是什么？任何一个品牌最大的资产一定是它的名字，因为没有名字就没有它存在，不是？所以，“西贝”就是它的第一品牌资产。

第二，人们还知道什么？“love 夜”。有人还知道“25分钟上一桌菜”。这个很重要，这是能吃来效应的。比如说我们中午要出去吃饭的时候，人总去西贝，为什么呢？因为上面写着，25分钟能上一桌菜，那就能够很准确地预估你什么时候能吃玩回来。那么，我们在给别人建议说去西贝的时候，我们也会说，上菜快，所以，25分钟上一桌菜，这是它的品牌资产。

那么第三还有什么资产？你肯定会想到，理由。想到，想到华人介绍的那些，所以，它的一些招牌的菜品会是它的品牌资产。

还有人会说，那个公司去过联合国。就像茅台去过北京国际奥委会一样，刊登在那里，就是它的品牌资产。

你看泰康，很多年前，有一张报纸批评它一个笑，它一直就把那个荣誉挂在它的门口，这就是它的品牌资产。

# 品牌资产排序

那么，进行了这些品牌资产的盘点之后，就要进行品牌资产的排序。品牌资产排序就是品牌资产投资的优先级。

比如说一共有四个事儿，那只能说三个事儿的时候，我们说哪个？可以说那个事儿的时候，第二个是谁，然后第三个是谁，第四个是谁。

我们还是用西贝莜面村为例，它的品牌第一资产是什么呢？我们刚才已经说了，肯定是那个名字。品牌第一资产就是西贝，就是那个方形的东西。

确定这个有什么意义呢？因为有的时候会要放弃一个东西的时候，就放弃名字。比如某家企业的广告招牌，汽车开过的地方，多上人家说的名字都看见着，它做的广告就不白费了。

你现在再去看机场，就咱们北京这个机场高速，上面有很多汽车广告，你有没有发现，你只看到一辆车在上面，不知道是哪家的高德，像奔驰、宝马、路虎这种识别度高的品牌还好，但是像什么丰田、本田，我发现跑遍那些日车的广告就不太容易被看到。这是因为它在品牌资产排序上没放在处理好。

在首都机场高速公路牌上有两个华与华的作品，是吧？

一个是华夏幸福，我就放了“华夏幸福”四个字和企业标志，下面有一行小字，叫产业园运营商，产业新城运营商。你看得见就看看，看不见就算了。因为华夏幸福的品牌资产排序中，第一是“华夏幸福”这个牌子，第二是那个logo，第三才是产业新城运营商。

另一块是华与华自己的，那华与华的品牌资产排序是什么？第一是华与华的名字，第二是华杉和牛华，我们兄弟俩抱着那个牛标志的照片。所以，我的广告排第一上名字，第二上我们的照片；第三是我们的方法论，就是独特的定位法；“超级符号就是超级创意”，所以，在设计这块广告排，华杉+牛牛+超级符号是超级创意。

我们再回头来看西贝莜面村的品牌资产排序。第一资产是西贝莜面村主体标志，第二资产是“love夜”，也许有一天“love夜”能排第一，但是，现在还不是。

就像耐克，最早纽约人都不知道NIKE四个英文写字的，美国人不知道有这个东西。但是，随着时间的发展，最后构成了它的第一个资产，而NIKE那个英文反而不到。这是品牌资产排序的变化。回过头来，西贝的资产前三资产是什么呢？他们也有一个广告语，叫“闭着眼睛点，道道都好吃”。这是很好的资产，很好的理由呢，说去西贝也没关系闭着眼睛，闭着眼睛点，道道都好吃。可以设计广告说，我们去西贝吧，“闭着眼睛点，道道都好吃”。

但是，这句话到现在知名度还不够高。为什么呢？就是因为它“love夜”是品牌排序中，也是一句口号，原来很早就再写了一句。再一个我们本身也没有去对它进行投资。

华与华还有一个案例就是汉庭酒店的口号，“爱干净，住汉庭”，而且我们的这六个字放在汉庭酒店的楼顶上，获得了很大的成功。西贝的蒙爱静也去住汉庭酒店，他说：“有，汉庭那个‘爱干净，住汉庭，挺好呀，我们也把‘闭着眼睛，道道都好吃’挂上头试试。

结果一挂上去，看，“爱干净，住汉庭”是十个字，“爱干净，住汉庭，道道都好吃”也是十个字，六个字挂在大楼楼顶没问题，但十个字放上去就不够办法我1点进“爱干净”了，所以说，就“闭着眼睛点，道道都好吃”只能前面先，瞄着不变了。所以，这句话我们到现在还没有能够进行投资。

我刚才是不是说了嘛，我们这一讲品牌资产操作实务：第一步，品牌资产盘点；第二，品牌资产排序；第三，品牌资产目标；第四，品牌资产投资。可以说“蒙爱静”是西贝莜面村的“闭着眼睛，道道都好吃”，到现在仍然是西贝莜面村的一个品牌资产，主要的问题也是它现在没有对它进行投资。主要原因是在电视广告不好投了，要是做节目、电视广告一投，全国人民都会记得“送礼就送脑白金”一样，那也就记住了。

好了，那么我们就把“love夜”排到第二了，“闭着眼睛点”能不能排第三？我们觉得后两者都不能排，不合适，到了第三，这两点都是儿了。所以，就退出西贝莜面村进联合国，我们的夜面和联合国秘书长潘基文的合影照片作为西贝的品牌第三资产，或者今后获得国家勋章金奖一样。而且我们还说，潘基文可能会最后一个大家族使用名字和长协和永远留在一起。把西贝获得的记录或者长协和永远留在一起，成为品牌的传奇资产了。
