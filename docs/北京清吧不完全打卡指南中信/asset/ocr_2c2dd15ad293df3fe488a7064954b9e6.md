# 2.北京清吧推荐清单（续）

# Valut 102

![](bbox=[0.05, 0.24, 0.4, 0.54])

+   - 地理位置：中关村东路16号院龙湖唐宁ONE2号楼A102
- 推荐原因：隐藏在原创香水店里的酒吧，需要通过一道隐藏门进入，极具特色；有威士忌品鉴套餐，可以一次性体验不同风味的威士忌
- 人均消费：153元/人
