# 2.北京清吧推荐清单（续）

# MO Bar

![](bbox=[0.05, 0.22, 0.38, 0.52])

+   - 地理位置：王府井文华东方酒店五层
- 推荐原因：具有极富特色的北京元素冰雕特调酒，同时地理位置极佳，室外阳台观景位可远观故宫；但户外观景位置有低消
- 人均消费：298元/人

# CHURCH 教堂·酒吧

![](bbox=[0.05, 0.62, 0.38, 0.9])

+   - 地理位置：永生巷咏国内教堂楼一层
- 推荐原因：欧式教堂风格，环境极具特色，在露台位置可见南芜子大教堂，拥有极具教堂风格的特调；但位置较为隐藏
- 人均消费：157元/人
