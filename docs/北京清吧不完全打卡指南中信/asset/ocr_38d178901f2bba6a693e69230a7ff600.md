# 1.北京清吧分布概览（续）

东城区

+   - 东城区清吧主要为胡同清吧，极具北京特色和历史韵味，但由于部分胡同通车不便且部分清吧隐藏在胡同深处，东城区胡同内清吧不容易找到
- 东城区清吧主要集中于南锣鼓巷、五道营胡同、东直门及安定门等区域。若选择南锣鼓巷片区清吧，要注意避开南锣鼓巷核心景区区域，该区域内清吧溢价高、品质低；推荐选择南锣鼓巷周边未进行商业化开发的胡同内清吧以及鼓楼周边清吧

西城区

+   - 西城区清吧除去同东城区的胡同清吧外，在金融街片区还有较多的高品质清吧，金融街片区清吧多为酒店配套酒吧，室内环境较为商务，但酒水品质较好
- 西城区清吧虽然在后海一带高度聚集，但尽量避免后海沿线酒吧，该片区清吧溢价高、品质差，且存在较大概率的假酒风险
