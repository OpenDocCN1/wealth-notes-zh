# 3.Tips

# 清吧选择Tips

+   - 尽量避免选择位置位于商住一体楼中的酒吧，该类清吧较容易出现环境较差、酒水品质无保障的情况
- 主题风格极为明确的酒吧（如哈利波特等）建议慎重，该类酒吧可能仅是主打概念，在软硬件服务上都较差
- 预定清吧三人及三人以上位置时注意提前询问是否存在低消，同时观景位置即使为两人位也可能存在低消，建议提前询问
- 选择面积较大的清吧一般是稳妥之举但难有亮点，很多具有特点的酒吧都是隐藏较深的小酒吧

# 清吧选酒Tips

+   - 在餐酒吧或超市型酒吧中不建议选择鸡尾酒以及单一麦芽威士忌、白兰地等纯饮洋酒，建议选择精酿啤酒或可与可乐等进行调配的威士忌或伏特加（较为高端的西餐餐酒吧除外）
- 鸡尾酒可通过酸口、甜口以及酒精度进行简单分类，若不熟悉鸡尾酒可以简单说明要求由服务员推荐，如需要偏甜的高度数鸡尾酒。但鸡尾酒不能单纯从度数评估其酒精烈度，如一款鸡尾酒存在多个基酒，即使度数较低也可能容易导致醉酒
- 清吧常点的纯酒一般以威士忌居多，其中苏格兰威士忌具有特殊的泥煤味，可能部分人会不适应；若在场有较多人为第一次尝试威士忌建议先从日本威士忌或美国威士忌开始
