# 2.北京清吧推荐清单（续）

# D Lounge

![](bbox=[0.05, 0.24, 0.38, 0.49])

+   - 地理位置：工体北路4号院80office对面
- 推荐原因：苏联厂房改造，复古工业风十足；黑白电影投影，复古风格浓郁；特调鸡尾酒非常有特点；但周末卡座低消较高
- 人均消费：206元/人

# 云·馥Atomsphere

![](bbox=[0.05, 0.6, 0.38, 0.86])

+   - 地理位置：建国门外大街1号国贸大酒店80层
- 推荐原因：北京知名高空清吧，临窗位置可俯瞰北京全景，风景绝佳，同时有乐队驻唱；但周末靠窗位置低消较高
- 人均消费：309元/人
