# 2.北京清吧推荐清单

# 49 Bar&Coffee

![](bbox=[0.05, 0.25, 0.37, 0.52])

+   - 地理位置：麦子店街39号附房一层西侧河边123室
- 推荐原因：距离公司距离较近，适合周五晚小酌放松；有河边户外座位，环境较好；酒水品质较好，苏格兰威士忌种类丰富
- 人均消费：122元/人（因该清吧白天为咖啡吧，拉低了人均消费，故喝酒的人均高于其大众点评显示的人均消费）

# ECHO&AMIGO

![](bbox=[0.05, 0.6, 0.38, 0.89])

+   - 地理位置：麦子店西街39号富驿时尚酒店背面（临河）
- 推荐原因：距离公司距离较近，适合周五晚小酌放松；调酒师水平较高，威士忌酸等经典鸡尾酒极具特色；威士忌种类丰富，有重泥煤味威士忌；周五及周六晚上有驻唱表演
- 人均消费：194元/人
