# 2.北京清吧推荐清单（续）

# Dandy Room

![](bbox=[0.06, 0.23, 0.37, 0.48])

+   - 地理位置：新源街63号1号楼底商103号
- 推荐原因：为MR. Dandy定制西装的清吧，白天为定制西服店，晚间为酒吧，环境及私密性较好；创意酒较多（如旺仔牛奶），调酒水平较好
- 人均消费：235元/人

# Rong Bar

![](bbox=[0.05, 0.57, 0.39, 0.83])

+   - 地理位置：三里屯东三街4-5号
- 推荐原因：有户外阳台，适合朋友聚会小酌；酒吧整体环境好，较为出片；小吃品质较高
- 人均消费：227元/人
