撩，只是第二部分当中的紧要一环。

# 1.激情：电の技

激情指的是性的吸引力，许多人的吸引环节都无需言语，而是通过视觉（好看的脸），听觉（怎么有这么好听的声音！）触觉以及嗅觉（从脑的发育看，嗅觉部分比负责视听的部分都要古老）来实现。

# 2.亲密：撩の策

亲密指的是双方能彼此分享感情和信心，这意味着亲密是爱情里一个细水长流的部分。我们经常说谈恋爱谈恋爱，指的其实就是增加亲密的过程。
