# 你总得认识到自己不能拯救世界

065|你总得认识到自己不...

# | 知识点

> “帮过我的人，我应该帮助他们而不是伤害。” ——超过民族国家界限的“互惠原则”

# | 应用范围

适用于朋友间要互相帮助、如何帮助别人让自己得到好处。

我刚上大学的时候，我爸爸送我去学校。

分别时我突然想问问老务子，有没有什么至理名言送给我，要我记得的。

我老爸想了想，说了一句：“管好自己的事，有余力了要去帮助别人。”

后来的生活中琢磨这句话，越琢磨越对。

通过“成长”和“助人”两个维度，能把人分成好几种。

+   只成长不助人的人，是个精明人。
先成长后助人的人，是个善人。
不成长也不助人的人，是废人。

但是我们也会发现一些问题：

# | 帮人让我得到很多好处

# 1.助人行为，尤其是拯救行为能够提高自己的社会地位

# 2.帮人能让人感受到自我价值

# 3.捐赠行为会激活幸福的那部分脑区

# 4.他再乐于助人你也应该称赞他

# | 帮人会让我内心好受些

# 1.帮人能够解内疚感

# 2.帮人能够解悲伤

# 3.心情好的人会特别乐于助人

从担忧转为轻松的人，特别容易去帮助别人。

# | 活学活用

你现在明白为什么针对老年人卖保险、理财、保健品的推销员去见老太太的时候会携着水果出现了吧。当他们心情愉快的时候，你不说让他们买东西，而说自己的业绩不足，他们会放松警惕，帮你完成业绩。

# | 帮人是投资、帮人是借贷

> “帮过我的人，我应该帮助他们而不是伤害。”

尽管我会跟大家说，尽量调低对别人的期待，不过大多数时候，我们在人际交往中也会投资：

> “我这次帮了你，你下次也要帮我。”
