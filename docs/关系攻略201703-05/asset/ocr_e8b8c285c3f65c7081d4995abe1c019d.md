# | 还做朋友是一种妄念

在这里，我得纠正一下世界上的有些流毒和谬误了。Y同学的家庭比较特殊，但是有些人在离婚的时候，会希望和前夫、前妻继续做朋友。

# | 人际交往当中的黄金法则

心理咨询师一般都会用这样一句话劝求助者（对，我们不叫他们病人）：“你想别人怎样待你，你也要怎样待他。”

这个被称为“人际交往中的黄金法则”。

大多数人是正好相反的：“我都这样待你了，你也要这样待我。”这是许多关系恶化和破裂的开始。

这种投桃报李的良性互动要尽早形成。
