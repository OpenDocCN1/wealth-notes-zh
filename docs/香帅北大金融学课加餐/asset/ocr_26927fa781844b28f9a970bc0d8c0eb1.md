# 宏观金融时事分析4 | 中国的金融开放会引 起金融危机吗？（下）

你好，欢迎来到青帅的北大金融学课。

昨天我们的讲到了2019年3-4月度全球最惹人注目的金融事件——中国的“金融开放”。我告诉你这个金融开放是指要加快金融服务业的开放，给外资金融机构以公平竞争的场地环境，同时向世界释放一个中国市场化方向不变的信号。

但是文献中关于金融开放，其实还有一层意思，就是经常常说的跨境“自由项目开放”——放松资本管制，所有人都可以不受约束地做跨境投资，进行跨境交易，实现货币自由兑换——换句话说，现在什么“一个人换50美元的额度限制”，不能自由买卖跨境股票、房子，企业跨境交易的资金进出要申报审批……这些限制都没有了。

听上去特别美好，对不对？但是我昨天还给了你关于中国“金融开放”的一句总结：

> 在“金融账户（资本账户）”的开放方面，我们要谨慎，切忌操之过急。

这句话听起来比较抽象，我们不妨用个形象的来说法。

昨天我跟你，资金是水，中国是个巨大水库——你不妨这么想，金融机构，就像水库的各级各类供给商（轮船、航运、桥梁建设等等），服务自然是放开竞争，越多营益。也就是“金融服务业开放”。但水库里有各种各样的水利调节机制，大坝多多，也会架水泵站做，影响水势，但要是没有大坝，又稍微有点吹浪打，就最容易形成各种翻船事件。

事实上，全世界，即使最“开放”的国家，这些资本管制的大坝也全不会拆除。国际货币基金组织（IMF）2017年的报告中告诉我们，189个成员国当中，约80%的国家对资本流动有管制。针对商业银行机构投资者持有特殊条款，还有约60%的国家对货币工具和金融信贷施加管制。

# 1. 资本账户过早过大放开的历史教训

可能有人会好奇，听上去“管制”不是没什么好处，为什么还会有管控的图象存在呢？这会不会和“自由市场”的理念相违背？

其实对这个问题的思考上全球多个国家走了很多弯路。90年代末的亚洲金融危机中，泰国、韩国这些地区，国家都曾经过快过过过猛的“金融开放”付出过高代价。

比如泰国就是在90年代初将资本账户户大开，海外相对便宜的资金（尤其是短期热钱）大量涌入。短短几年间，外币流入量暴增——刚开始大家感觉很好，资金大量涌入，一切一片繁荣，直到1996年，泰国短期外汇和外资占银行的1/2在1994年之前，换句话说，整个国家的外汇储备不足以覆盖短期外币债。

可能同学们记得前两年流行的一个词，“热钱”，其实就是指这种迅速来，快进快出的短期资本——这种外资的短期资金的波动性非常高，一有风吹草动它就迅速撤离，所以如果一个国家对外币短期资本高度敞口，只要自己经济稍存波动，现金流马上“火上浇油”或“釜底抽薪”，经营的话，很容易就会踩踏出逃，造成多行业链条的信用负债。

到1997年，在外资的持续流出之下，泰国的经济泡沫化已经十分严重，后来的故事我们都熟知了：素万那普机场的咖啡厅里都充斥着：泰铢贬值，外资纷纷出逃——面对这么个门户大开的局面，泰国政府基本上没有抵抗力，经济急剧下滑。

韩国也有类似的过程——对短期海外资本的低开放使得该经济产生了内在的波动性，一点风吹草动都可能引起金融动荡。

除此之外，韩国跟我们国家的金融体系有很像的地方——之前都是金融高度管制的国家，利率、汇率、韩币市场放开，银行、汇存利息手段都有限，换句话说，韩国的汇率、利率、银行、贷款等金融市场的开放，金融监管的配套也非常滞后的局面——这种情况之下，资本账户大开，金融高度一放开就产生产生一个账户外开，金融监管配套严重不周，风险叠加——就像问题暴露出来的蚁穴，一旦洪水，立马溃不成军。

对亚洲金融危机的反思中，有几条经验教训逐渐形成共识：

+   1. **资本账户的开放必须稳健，有序，尤其是对短期资本的开放，要审慎，不可过急、过猛，避免金融资本对国内经济的冲击；**

+   2. **国内的金融改革（包括有弹性的汇率制度、利率市场化、银行等金融机构的市场化改革）都必须先于资本账户的开放，避免大规模的跨境资本账户流动，积累风险。**

换句话说，资本账户的开放是个“水到渠成”的事。更明白地说，资本账户开放应该是金融开放的结果，而不是手段。

举个例子：像个人换美元、企业结汇上的限制是更严格在当时应对贬值压力？但换个角度讲，在当前的中国金融市场仍然存诸多扭曲，薄弱环节暴露的情况下，如果突然结果资本账户开放使用的普遍“金融开放”，可能会招致更多的风险，稍有不慎甚至能引爆金融性。

# 2. 资本账户开放的原则

其实资本从长期的时间来看，中国对跨境资金流动的门槛一直在逐步放松，但每一步都得走得比较谨慎，希望能尽量避免像国家走过的弯路。

+   1. **支持直接投资实体经济的长期跨境资本流动，限制货币、证券市场的短期资本流动。**

所以你去看，各地都要吸引“外资”投资建设项目，在企业进行上市中，资金进出的门槛是很高的，最近几年开放是“滴水灌溉”，比如允许少数机构投资者进来（QFII），允许中资跨境资金出去（QDII），设立资金双向流通，比如沪港通和准入国际金融主流指数等等。

+   2. **国内金融改革需两年新近于2000年之后，商业银行改革，离岸人民币市场设立；2012年之后，利率市场、汇率改革，人民币国际化都开放进入快车道——回头看，要实施更大规模的金融开放，这些基础条件都必须先满足。**

一旦资本账户户全开，中国的资金水化之与其他的钱都全部汇入，我们可以想象，任何风吹草动带来的波动都会对大的水体形成更大的冲击力。

比如说现在汇市制度是做什么事呢？把水龙头管在出水量固定，就像什么呢？两个海洋面积不一样的地方，水流成了以后会怎么样？肯定是更大的海洋流动，加上海岸线起伏，人类在自然的影响中，水是一种奇怪的存在：看似轻若无物，实际上——人类可以碎石开山，重锤地，但是水这种状态还可以留下水处最原始的形态——这也说明了金融资本是最复杂也最难以控制的市场。

# 总结

**划重点**

+   1. **金融服务业的开放就是开放资金水，给金融提供服务商的竞争，而资本账户开放，就是拆除各调控制资金流动的大坝，两者性质不同，需要区别对待。**

+   2. **资本账户，尤其是短期资本的放开，容易形成大规模短期投资套利流动，累积风险，的确不是非常谨慎。国内金融的改革推进，是资本项目进一步稳健放开的前提。**

+   3. **从某种意义上讲，资本账户的放开应该是结果，而不是手段。**
