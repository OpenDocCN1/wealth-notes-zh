# 3月问答 | 货币基金的兴起，会影响中国经济增长吗？

青帅的北大金融课

你好，欢迎来到青帅的北大金融课。

到了我们集中回答“银行”的这个板块的时候了，这个板块的问题很多，也挺得很有意思。综合选取了一些同学的提问，集中给你讲三个问题：

+   1. 美联储是否制定市场基准利率？
2. 货币基金的兴起会不会造成银行存款下降，进而影响到中国未来的经济增长？
3. 75%的存贷比限制，会不会影响中国的货币创造过程？

大家能说，美国是自由市场的代表，那它的央行美联储是不是就不去制定和操控利率呢？

青帅

这是个很有意的问题，我给你两句话：

**一，美联储不直接决定市场基准利率。**

**二，美联储通过影响商业银行的资金成本，实际上会形成对市场利率的强有力调控。**

先看第一句话，美联储不直接决定市场基准利率。它只决定对商业银行的拆借利率，而市场基准利率是同业拆借利率。因为这种机制的变动，才影响反映银行间资金的余缺，然后影响银行的资金成本，进而通过银行传导到消费和投资这些实体经济上面。

那这句话的意思是不是意味着美联储不能够控制市场利率呢？当然不是，这就是第二句话了，美联储通过影响商业银行的资金成本，实际上形成了对联和基准利率的强有力调控。

那么具体路径是这样的：如果美联储降低拆借利率，商业银行就会向美联储借更多的钱，因为资金成本更低嘛。这样一来，银行同业市场上的资金就多松了，那利率不是就降下来了，就刺激消费和投资了。同样的逻辑，如果美联储调高拆借利率，那同业市场上的资金就会变紧张，然后引起利率上升，抑制投资和投资。

说到这儿的时候，有宏观基础的同学可能会问了：

如果市场上资金本来就很宽，美联储提高拆借利率，银行完全可以自己搞，互相拆借，就不会去找美联储来增加本币负债了，不就成了美联储的拆借利率孤零零地在那里了嘛？

如果在一般情况下，确实会如此。但是你别忘了，美联储还有很多的武器来帮助实施货币政策。

比如在公开市场上，向很多人你的价格出售债券，然后吸走大量的资金，造成同业市场上资金紧张，迫使和基金利率和美国联储的拆借利率同步上升。

所以，这一套干预市场利率的操作方法，经过长循环多年、多次重复的操作，就逐渐形成了一种市场预期，以后只要美联储调整它的拆借利率，整个市场就同步跟。渐渐地，就类似于美联储直接宣布联邦基金利率变动了。

所以，给你非常完整的案：理论上美联储可以不决定市场基准利率，但是，它可以定目标利率，然后通过公开市场的操作如期管理的途径，达到这个目标。

所以，从实践上看，美联储是完全可以实现对利率的调控的。

这里多说一句，不管是中央银行还是国家，都会对利率进行调控，这就是代国家正在对经济的政策制定和实施。所以，我们一般在的情况下，不要不好意思用“操控”这种带情绪的字眼。

这是第一道题目。通过这样的讲解，希望你能理解题目中一个非常有意思的现象：全球都对美联储不加意见，那不难感觉到非常紧密。其中的逻辑就是今天跟你到讲解，美联储可以决定市场利率，进而影响到整个经济体的变动。

路边的提醒

货币基金的兴起，会不会导致中国的银行存款下降呀？

青帅

其实这个事情也有很多同学问过我，大家受到网上很多不靠谱文章的影响，老是担心存款下降，中国就没投资了，那影响呢？原有的经济体系，不是不是这样的呢？这是一个特别容易引起误解的问题。所以，今天我要重点跟你们澄清一下。

首先，绝对数目上看，中国的居民银行存款与其说是增加。像2012年的时候，居民的存款余额是14万亿，你知道到2017年这个数字是多少吗？是62万亿，平均增长速度差不多在10%左右，都超过了GDP的增长。

那为什么平时我们会听到一个货币基金兴起，银行存款下降的印象呢？

这里其实是一个说法的问题。就是，银行的存款相对数是上升的，但是，从2012年到2018年，每年居民存款增速是下降的。2018年，前两个月的增速差不多创了改革开放以来的最低。

为什么出现这种情况呢？很多人说，是货币基金兴起。我觉得这个说法不对，货币基金其实是又一个表象。

根本原因是什么呢？是因为这些年中国老百姓对财富管理的意识复苏了，而银行存款是被曲高遭通货膨胀的。中国一定期利率始终跑不跑通货膨胀。你会发现，我们存的这点财富，是缩水了。到了2012年以后，中产阶级也兴起给了自己的资产升值保值的需求。

另外一个方面，就是2012年以后，中国的资本市场交易创新高，尤其是各种科技挂钩的互联网金融创新，更容易被认可。

比如说支付宝推出的天天的货币基金，本产品没设计没有什么很革命性的创意，但是，它长在支付上身上，具有超强的扩张能力。一付一下子就对现有的金融机构的观念造成了很大的冲击。

其实截至2017年底，货币基金的总额也不过7万亿元，和银行存款相比，这个数字不大。但问题是，它是在几年之内快速增长出来的。这种速度和模式，给讲究时间累积的传统金融业带来全新冲击。

当时还有一个事儿，就是利率市场化，它有种还金融改革。所以，那么几年开始，中国的金融市场出现了很多变，很多变的局面，自身方金融方管理产品也是层出不穷。所以，老百一方者管理需求不露，一方面又有了理财频道。

所以，我看到存款增速下降并不奇怪，本质上也是老百姓财富管理需求出现，金融市场逐步走向完善。
