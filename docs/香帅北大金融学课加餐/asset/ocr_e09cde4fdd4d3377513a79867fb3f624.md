# 课程结构及内容简介：

“城市”是现代经济的细胞核。现代国家经济增长就是城市化的进程。到今天为止，你会发现，中国家庭的财富状况基本上是城市化进程的一面镜子。

中国的城市化到底在什么水平？下个阶段中国的“城市化”以怎样的速度、方式进行——这些都将直接决定你我（以及下一代）的财富累积和社会状况。

要正确地“择城而居，择城而投”，我们需要在底层逻辑上理解，城市是一种最复杂的人造生物体，它不但遵循着生物体消耗产出的一些基本规律，同时也遵循着一些地球历史上古老的法则；在中国这么一个幅员辽阔的大国，这些规律和法则会让我们的城市的发展潜力呈现出一定的趋势和规律。具体落到我们的微观决策来说：

+   就业机会在哪些城市更好？

哪些城市的收入水平更高？

什么行业在什么城市更有前景？

哪些城市的社会保障、福利水平、医疗教育条件更好？

......

本次“城市篇”的课程中，我将要带你一起探寻这些问题的答案。

我们要围绕着“城市”，形成从理论-工具-实战的整体知识逻辑框架，最后深化为对区域经济增长力和投资机会的研判框架和决策方法论，让城市的经济增长成为你财富的朋友。

+   1. 理论——城市与经济增长的内生逻辑关系。

带你理解城市的本质，理解集聚与人类社会消耗/产出之间的规律，初步理解城市为核心的现代经济增长理论框架。

+   2. 工具——分析城市经济增长潜力的两个维度：地理与人口。

带你从地理历史角度理解东西南北差异对中国经济的巨大影响；学会用人口分布的动态模型来理解中国区域经济的格局，形成对城市潜力的判断分析框架，拆解各个城市的就业前景、收入水平、社会福利和增长潜力。

+   3. 实战——从城市经济增长角度切换到个体决策角度。

在理论框架下，用实际案例理解城市发展的周期和模式，理解地域人口特征对财富的影响，指导企业和个人投资决策。

各个城市，以及重点城市的区县的房价水平分析。

各个城市劳动力水平和劳动力结构。

财政水平和央地博弈下的生存空间。

+   4. 热点解析——用“城市”的知识框架新解最新热点时事

让你学会将知识点转换空间和维度进行底层思考，从而指导自己的长期投资策略。
