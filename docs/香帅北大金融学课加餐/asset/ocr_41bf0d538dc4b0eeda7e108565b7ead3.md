# 1. 汇率怎么定？

讨论中国被列为汇率操纵国，是不是会引起人民币贬值，首先我们要弄清楚，人民币汇率制定到底是这么解决的。

很多同学都知道，汇率是两种货币的相对价格，人民币兑美元汇率是指人民币和美元，还有美兑人民币的交换比。我们可知，一国的货币价值取决于该国经济基本面，国家对国家的经济基本面的认识，人民币兑美元的汇率根本上就是由两国的经济基本面决定的。

因为美元是当今世界的支货币，所以主要大国的强和全球经济的基本面又是息息相关的。

长期来看，人民币兑美元汇率取由三个因素：第一，中国经济；第二，美国经济的基本面；第三，全球经济的相对状况。汇率的短期波动和情绪状态，还有各国央行们的态度，动作有关。对，现在人民币了汇率是怎么决定的，接下来我们看一下近十年人民币兑美元的走势。

# 近几年人民币兑美元走势

2003年到2014年，中国的经济是全球一枝独秀，平均增速是10.5%，人民币兑美元的汇率就一路走强。从美元兑8.28人民币，到1美元兑6.04人民币。

2015年，中国的经济增速放行了，尤其是经历了“8·11汇改”，人民币进入一个贬值时期，汇率从6.21贬到2016年12月的6.95。所以，当时就引起了很大的市场恐慌，资本外逃的现象也开始出现。

那时候，为了平复市场情绪，我们的央行就加强了资本管制，去打击市场空白，市场失控的底线，人民币又一度回到了6.3左右的水平，然后在6.6左右水平徘徊。

2018年下半年开始到2019年上半年，人民币兑美元汇率的走势是比较奇怪的，因为这一年，中国经济下行比较厉害，而同期，美国经济数据比较强，而同期，美国的经济数据又是比较强的，所以你去看汇率的话却最终维持在7以上。

从这里我们可以看到什么？我们看到，第一，监管层对对于外汇汇率波动是持比较小的。另外，中国政府在中美贸易谈判中有一个维持相对姿态考量。

如果是一直听我们课程的同学可能要知道，美国前总统特朗普在诉求中，最重要的一条就是减少美国对华的赤字，人民币一贬，就会让中国出口产品的美元价格更低，更有竞争力，是不利于美国减少对华赤字的。对，说白了，长期人民币汇率的反映就是经济增长速度，在短期的变动中，国家基本面的一些这些考量可能会变得更加重要，但，这些基本面的考量可以看作是转移的，或者说人民币汇率的决定就是中国经济增长的速度和质量，以及相对于美国经济增长的水平。

那中国经济增长的情况又呢？

# 中国经济增长情况

就像我们所说，2015年开始，中国的国内经济增长率就放缓了。因为金融危机和杠杆等结构性的调整因素，经济增速是高位下行，从两位数降到了6%左右的水平。

但是，在全球来看，6%的增速依然是高的。因为从全球的来看，最近五年的经济增长是一个下行趋势，2010年以来，美国的增速是2%、欧洲、印度大概1%到2%之间，日本和英国只有1%多一点，到2%快一点，7点左右。但是，印度经济是很大的，所以，对主要货币汇率的影响是有限的。

所以，按照北京大学经法教授的说法，这种现象表明，现在的全球经济是“比丑时代”，中国经济有6%的增长率，甚至更低一点。到5年左右，就是矮子里挑高个子，因，只要中国的经济保持一个平稳、保持内生动力，社会稳定，人民币汇率就是相对处于一个稳定的水平。

换句话说，社会安于稳定，经济持续增长，世界基本和平的正常情况下，人民币自己不会出现大幅度贬值的，除非是我们自己出现经济波动，社会动荡。

# 2. 被列为汇率操纵国是什么意思？

刚才说了汇率决定的因素以后，我们再来说被列为汇率操纵国意味着什么。

刚才我说了，汇率贬值会使一国货币对价格上涨显得便宜。比如，一个标价65元人民币的商品出口到美国，6.55元人民币的标价为10美元，而现在人民币贬值到了7.2美元，美元的价格变成了多少呢？9.0。

这样一来，就会使得出口国家出口竞争力增强，所以，如果一个国家试图通过压低自己的汇率来促进出口，可能会引起全球各组织的货币或货币国际秩序。不管是世界银行（WTO）、还是国际货币基金组织（IMF），都反对其操纵行为，所以，一旦一个国家的被认定为是汇率操纵，就会受到其他国家的报复和国际社会的反弹。

那中国不是操纵汇率呢？好，我们先看看美国自己设立的标准。

根据美国2015年的法案，一个国家要被认定为汇率操纵国，需要同时满足三项标准：

+   第一，对美贸易盈余超过200亿美元；

+   第二，经常项目盈余占GDP的比重超过3%；

+   第三，过去12个月中8个月通过买入外汇干预本币贬值，买入量超过GDP的2%。

这三条中你怎么看，怎么看，中国也只满足第一条。

2018年，对美盈余是419.6亿美元，但是，我们的经常项目盈余占GDP只有0.4%，是远小于3%的标准的。而且，在8月的中国，国际货币基金组织进行调查以后发表了报告，认定没有证据表明中国大规模干预外汇市场，人民币汇率水平与基本面基本相符。

其实还有一个很有意思的细节，美国的财政部在宣布中国为汇率操纵国的公告中加了一句话，叫“under the auspices of the president”，意思是这是总统让我干的，就是提了一句一刷脸领锅的梗。

换句话说，在美国，经济是经济基本面和预期市场的反映，而不是政治结果。美国这次的举措就是有无理搅浑嫌疑。

这并不只局限于我国的看法，从美国的国内和国际，其实这次反对美国的声音都很大，像8月5号5日12号，国务院位置有影响力的政客和学者，财政部前部长萨勒斯坦、诺亚德马罗查鲁普，他们都公开发声，反对将中国列为汇率操纵国。再加上，像IMF的前首席经济学家，德国内政部长，公开反对美国的做法。这意味着从金融全球化的格来看，是不支持美国将中国列为汇率操纵国的认定的。
