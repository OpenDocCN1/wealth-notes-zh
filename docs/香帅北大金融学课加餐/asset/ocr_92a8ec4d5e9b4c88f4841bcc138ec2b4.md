2019年每个月的双号，我都会在课程里带给你们一篇金融思维方法论。今天要讲的是第四篇，风险思维。

“风险”可能是金融里最重要的词语。我们专门做370多篇文章，谈到风险的有235篇。从某种程度上，金融思维就是风险思维：怎么定量风险，怎么给风险定价，怎么让这些风险产品创造出市场流动性，怎么在流通中实现对风险在时间维度上的转嫁和社会维度上的重新配置。金融市场的本质其实就是关于“风险”这个虚拟商品的市场。

那么金融学在面对风险的时候是如何处理的？这种思维对我们普通人来说有什么用？这一篇金融思维方法论就来讲这个问题。

# 1. 风险思维是一种底线思维

说金融风险，你最熟悉的可能是波动率。下面有一张图，表示的是某个金融资产一段时间内的收益率，中间那根直线是均值，曲线里最大收益率的上下波动。当表示金融里“最不利因素”的时候，通常是利用分散化，将波动变小，也就是让这根曲线变得更平滑一些。

![](bbox=[0.2, 0.35, 0.8, 0.39])

问题是——作为投资者，你会介意哪个向的波动吗？我猜很少有人会介意的，人性决定了我们真正重视的是向下的部分波动。所以在真实投资世界里，我们经常听到一个词：最大回撤。当一个基金经理告诉你，他的产品如何的时候，通常会说“市场下行的时候回撤非常小，最大回撤只有5%”。

这个话的意思是，在下一个特定的时间点，比如这一年，从全年最高价跌到最低点的幅度仅仅有5%。这个指标来描述情况下一个产品可能出现的最糟糕的情况——数值越大，表示可能遇到的糟糕情况越糟糕。

这个风险指标甚至比波动率更重要，因为控制最大回撤，本质上控制风险的下限——对风险的过度理解，我们并不能消除向上的波动，而是希望向下的那个底部能够被控制住。

这意味着，风险思维本质上还有一种“底线”思维——我们专栏里还有两篇课程，《投资是一场输家的游戏》的这篇文章里，活得久才是王道。其实讲的就是类似的道理：决定投资结果的，不是赢是输，输得少的话，能够跨过最难的时期，活得下来，活得久的就是赢家。

江浙一带民营企业家，有不少穿越了90年代以来大大小小的调控和经济周期，积累了极为丰厚的投资理念，可以说，就是：无论什么时候都控制负债率，一旦经济下行，快速降杠杆。

听上去很容易，做过企业的人可能都知道，经济上行创造贪婪的时候都要控制住杠杆的欲，经济下行时使士气崩毁，都是很难的事情。

# 2. 风险思维还是一种突破思维

底线思维在风险思维中比较容易理解的一部分，但是很少有人意识到，风险思维的另一面其实是突破思维。

最近《郭老师头条》里说了一个有趣的现象——近10多年，优质的淡水资源以及相当人群开始做投资交易，其本质是准银行人员的原始收入。投资里举了一个例子，美国有个叫Unveco的基金公司，旗下有三只美国水相关ETF股票，它们分别投资于水相关技术、水相关设备，三只基金的回报都在8%-11%之间。换句话说，如果一个25年的基金上，你现在投资100万在这个基金上，10年后你的财富大概是215万到255万。

很多人能理解黄金具有升值，但很少有人想到，水也可能会是商品。最确定的“水”，自然率，确实有些匪夷所思。

这就是我所说的“突破思维”。绝大部分人不考虑（风险）的接受者，理所当然地认为“现在的不确定性”是一个模糊的概念，但实际上，人类面临“不确定性”的风险，是一个不断变化的过程。如果你不能突破“当下”，就无法去接受未来。

比如3个世纪，全球谷物产量是5亿吨。2018年，这个数字是26亿，增加了4.2倍。中国的的产量更是翻倍，上个世纪70年代不到100公斤的谷物收入，现在是550公斤左右，同期全球人口只增长了2.3倍。换句话说，直到20世纪早期，粮食短缺是人类社会里最可怕的最常见的风险之一。而今天，全球社会最大的风险是通胀和农产品，期货交易所的粮食交易活跃，芝加哥农产品期货交易所也是世界上最大最活跃的交易所之一。

但是，随着科技进步带来的粮食产量飞跃，人口持续增长，人均粮食占有量却不断上升。粮食价格也在下降趋势。曾经被视为社会最大风险的粮食风险已经不再成为社会最大的主要风险。

但是，随着全球人口的快速增长和环境的恶化，越来越多的自然灾害因厄变得“短缺”，所以70年代开始，绿色金融兴起，以清洁能源、碳排放为标的金融产品开始被森林也开始被纳入，90年代之后，淡水、森林等资源也开始进入人们的视野，变成金融产品，而且都获得不错的回报。

这样的产品开发，就是基于“突破思维”——风险是对概念，会随着时间、地点、甚至人物的变化而变化。当风险变到一定范围不能仅仅着眼于当下，而应该向前看，寻找未来风险变动的可能性。

现在。动态思考，未来风险变动可能性是完成“帮风险定价，实现风险的转移和配置”，和“帮助人类社会去抵御风险”思想的延伸。

所以，风险思维是个非常二元对立的思维。一方面是要守住安全下限，另一方面则是要大胆突破当下既有的约束。用这种思维模式的人，通常都非常容易成功，他们既能对风险作出清晰认知，但也能积极采取行动，认识并将认知付诸行动。

# 划重点

+   1. 风险思维的本质是一种底线思维，因为决定投资结果的不是赢，而是输，输得少的话，能够跨过最难的时期，活得久的就是赢家。  
2. 风险思维还是一种突破思维，因为人类面临的风险是一个不断变化的过程。如果不能突破当下，就没有方法预测未来。  
3. 风险思维是一个非二元对立的思维，一方面要守住安全下限，另一方面要大胆突破当下既有的约束，所以，具有这种思维模式的人通常都更容易成功。
