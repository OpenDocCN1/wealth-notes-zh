# 优秀学习计划

DB、宝：

2019年，我在金融学这门课程里的计划，是这样的：

+   1. 由身边的同学，返回到课程中相关的课程学习，遇到习题复述，经过一年持续学习，已经有小伙伴相互关注，经常会问我一些问题，我会把这些作为刻意练习的引子，回到课堂里来。

+   2. 系统复习课程，尤其注重新加入的留言。这个是我长期来做的，因为同学们是不断加入的，并且已经加入的同学，也会不断地复习，获得新知都会发在留言区，这也是我时刻跟踪学习的，而且我也会加一些同学的微信，一起交流，学习。

+   3. 老师推荐的書，我们几乎被类成八个书。这本书本是老师推荐的部分普遍大众型、普及型的，我会把它分为8个类，每个下面一本，每本书就当做摘读，写摘卡，每读一本书的同时就复习相关课程，为以后向专业知识做铺垫。
