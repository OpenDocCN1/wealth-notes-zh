# 第十七本（投资）：《巴菲特致股东的信》

我觉得所有金融学的人非读不可的一本书是《巴菲特致股东的信》，这本书的很多言浅意深，但内涵的深度完爆绝大多数商学院使用的金融教材。

我在上周的复盘里给你强调过，公司决策和投资者决策其实是一个硬币的两面，这句话其实本来是巴菲特的，巴菲特的表述特别地精辟。我是一个不错的投资者，因为我是一个不错的企业家；我是一个不错的企业家，因为我不止是一个投资者。所以，这本书的结构非常地清晰。

他是站在投资者的视角，介绍怎么去投资一个企业。这本一一书开始讲的是企业的原则，接下来用章节开始普及公司的各方面，公司治理、对外投资、兼并收购、估值、保险、财务都一一有所涉及，而且充满智慧的实例，如果没有原版金融学为正，听完我们的课程之后，你可以用这本书好好地读到一两遍，我相信相对于如何理解和如何找到好企业，你特别大的帮助。

# 第十八本（投资）：《金融投资400年》

实际上是这两本古典金融史的合辑，一本是19世纪马凯的《伦敦：伦敦 和大众的疯狂》，另外一本是《17世纪荷兰的泡沫（困惑交易》），这两本金融史被评为历史上最优秀的一部金融史著作，排在前面两位。所以，市场上几乎所有的投资大师，都吃过自己看过这两本书的故事。《惊人的幻灭和大众的疯狂》，它记载的是历史上最著名的三次大泡沫，密西西泡沫、南海泡沫、郁金香泡沫。《困惑交易》百年里面，记载的是荷兰股票市场的开始的一百年里，股票市场里的各种机构投资者说交易策略。

这本书我在看的时候就想，我们自己所经历的各种危机，比如亚闻金融危机，次贷金融危机，17、18世纪投资市场上所有人的观点和，今天看到的世界二无二。太阳底下从来没有新事物”。所以说，人类这么久能免重复覆盖，真的是一个千古的难题。

当然了，这个板块里内容相当丰富，值得读的书有还很多。但我觉觉得，如果这几本能够好好地、安静地读完，再集中你的一个综合的消化，那你对整个投资的理得解会上一个大台阶。

# 第十九本（投资）：《学会估值，轻松投资》

《学会估值，轻松投资》（The Little Book of Valuation）是美国哥伦比亚大学的教授斯达法斯·达蒙写的书。达蒙在兰德尔的斯达法斯·达蒙写的是兰德尔的达蒙斯达法斯·达蒙是兰德尔的达蒙斯达法斯·达蒙是兰德尔的达蒙，在华尔街人士中和非常口碑。所以这本书特别适合读MBA和金融学硕士，以及高阶学员的选学教材，简单易懂、技术化但也不失精。估值的意思是什么？怎么对估公司的价值？这本书都是些什有非常详细的答案，他是一个充满的一本。而且很多章节即使不作为教材，它的可读性也是一流的。

# 第二 0 本（投资）：《公司金融理论》

2014年的诺奖得主梅哲若的公司金融论 （ The Theory of Corporate Finance），这本教材耗时十年，一个诺奖得主的时间，你可以想象其深度。所以，我有一次读的时候，真的有惊为天人。

公司金融其实是一门很精的学科，因为涉及到公司的各方面融资，不仅只是资、制度、组织、融资、管理、现金流，会产生影响，都和一个企业息息相关。所以，一个只懂销售的公司，是没有办法驾驭一本有深度的、系统的公司金融教材的。恰好格诺尔是这方面的集成者，他想从全方位的角度，把公司领度的各个角度统一在个一个框架，简明而系统，这是一个绝对的杰作。当然，诺尔做理论出身，因为他的理论背景高，这本书的深度难度相对与高也会比较高。里面涉及比较多的数学推导，语言也相对比较学术，如果没有金融和经济学基础，你只能只有对数字比较敏道，对抽象语言比较熟悉的同学，才值得花时间去读。

总之，作为一个科班生，我对这本书只有四个字，强烈推重。

# 第二十一本（科技金融）：《在线》

你要理解科技金融，首先你就得理解数字化、在线化，以及它们带来的改变。这应该是你在这个模块应该打到的基础。所以，第一本书，我觉得你要花大量的时间。我在课程里提到的《在线》，这本书是阿里网的CTO王坚写的，和一个知名的首席技术官不太一样，王坚是一个心理学家，所以，他习惯从人的角度去思考技术。所以，你会发现他的书风格完全不同，技术书，他基本上可以当互联网发展史来读，但是，是有一个核心。他是始终围绕着“在线”，在“线“就是人的线上生活空间数字化虚拟空间有了一个交集，一切被线以后，我们在概念，对当下我们熟悉的三根概念可能会有改变。即然地，商业形态、社会形态都会发生改变。
