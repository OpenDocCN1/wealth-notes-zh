# 1. 第三方要求的是独立

要理解为什金融理财的财富管理公司这两年频频爆雷，我们首先要理解第三方财富管理这个概念。

你先想一个最简化的框架，在这个简化的框架里面，金融市场无非就两端——资产端和资金端。

资产端，像银行、信托、基金的产品；资金端，像我们个人和机构的资金。而所谓第三方，就是站在独立位置，去帮助个人、机构、客户进行财富管理。比如说去分析客户的资产偏好、理财需求，然后帮助他们选择投资产品，进行投资规划等等。

这个行业实际上兴起于美国上个世纪的70年代，当时有一个背景就是美国的中等全面崛起，而当时金融投资工具变得特别丰富。再加上一个事件就是1974年，美国个人养老改革法案，而养老金的投资收益是免税的。所以，这样一来，美国的资本市场，资产端和资产端两端都变得特别丰富。这样一来就诞生了以中介服务为核心的第三方财富管理。

这里第三方起到的作用，就是帮助金融机构那种手买卖，自卖自夸，完善自己高风险管理的道德风险。

第三方财富管理能起步有几个前提：

+   1.  你的资产端、资金端都要足够丰富，投资者要有钱，触碰方要有好的投资的。只有在这两个资产和资金端都很丰富的情况下，这个市场才需要中介服务去完成搜寻和匹配的工作。
2.  这个第三方需要有很强的专业能力，能够完成这个搜寻和优化匹配的工作。
3.  你一定要有保证第三方权利义务界限清楚的契约和保证系统，否则第三方就容易灰色地带。

# 2. 中国变形的第三方财富管理

我们再来看下，中国的第三方财富管理是不是满足这些条件？

中国开始出现财富管理这个概念大概在2008年，然后从2012年到2015年期间变得很炙手。2013年这个年出现这个上，其实是有历史背景的。

你看，中国经历了几十年的高速增长以后，就形成了可观的民间财富，然后资金端变得很充沛。然后到2008年，宽松政策一方面给资金端加水，一方面让市场上的投资机会变多。再2012年之后，金融监管全面放松——2007年的资产化规范规的2012年开始，公募的银行机构下就进入了群雄逐鹿的局面。市场上的资源变多得也丰，所以说，财富长效应、宏观金融、金融脱实向虚拟的趋势让资金端都变得充沛。

这样就为第三方理财创造创新提供了前置条件，很多房地产开发这样的项目就都被打包源源不断地送到市场上。

所以，这个时候是金融产品的销售需求大涨，第三方理财机构最初作为金融机构的零售端进入了市场。它们是机构把这些产品，然后去展客户面前放，把产品后销售，自己从中抽取佣金。

你去一下看，诺亚财富管理限制的营销要求，5年以上的销售经历，奢侈品、高档车、房地产销售经验优先。

你在很早以前就清楚第三方财富管理这个模式，从银行来看，银行是一个对专业，对经验都要很高的行业。不说话的，我们的部家金融管理博士，现在我给自己家人放一点金士达都没有什么翼翼，不敢投入。一个卖房子的和奢侈品行业经验的人，就搞分金融上的专业、专业，年轻人，几万、基于上千万、上的资金都管呢？我开过一句玩笑说，就是卖静动的暖气啊？

而且，你会发现，这个方向、诺亚根本不独立的，大、大发、方面，都是在这个模式建起的。这说明什么呢？这说明中国的第三方财富管理，从一开始就不是第三方专业型中心，而是一个销售机构的身份，它是第三个为盈利模式的。

所以，这个模式就决定了中国的第三方财富管理在金融的风控上很难独立，也很难专业。

美国是直接投资为主，各大金融机构是一个完美的竞争态势。中国因为这个背景不一样，中国的金融市场里只有一个独立，其他的机构大如都是做基金通道业务。第三方财富管理是处于这个生态位的尾端。

那些第三方理财你就可以想象了，一方面，他们是拿不到最优质资产的，另一方面，他们对市场波动的反应也更迟，那自然风险就更高。

另外，和美国的这种金融立法特别完备的情况也不不同。

中国的现代金融市场，仅仅过了二十二多年的历程，监管立法的储备是相当滞后的，所以，对于这些金融业务模式的监管、立法、执法都处于摸索阶段。你会发现，中国金融市场站在金字塔是相对较大的空间。

所以，截至今天为止，我可以这么说，中国的第三方财富管理市场是一个良莠不齐，信息不对称的市场，也是一个产质量相对差的市场。要知道诺瓦呢，就是级投资产品，这种情况可能会在未来慢慢改善。但是到今为止，就是这个样子了。
