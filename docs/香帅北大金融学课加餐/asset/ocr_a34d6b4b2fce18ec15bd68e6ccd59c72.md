# 一、经济周期的背后逻辑：信贷周期与宏观调控

首先，要怎么看理解经济周期，其实你只需要理解人得生长性循环，你就可以能够理解经济的增长轨迹。这，这话是讲呢？

举个例子，如果我们把国家的经济发展比作人的生长的话，美国这种发达国家就是壮年，各种指标都处于巅峰的壮态。但是，生长速率并不很快。而七十到八十年代，欧洲四小龙，九十年代以来的中国，即都是属于青少年，生长速度很快。但是，生长的发展过程中，它不可能没有低高峰和低谷状态，这就是“经济周期”。如果说，身体生发烧了，那就是“经济危机”了。

所以，一个人难免会感到很多的状态起伏。同样地，经济体也会“高起低伏”。那这种高起低伏有没有客观的规律可循呢？

其实，每个国家，在每个阶段的规律都会有很大差异。但是，综合来看，本质来说，经济发展就是资本生息，资本积累的过程。在资本循环中，存在着一个很重要的内生长因素，也就是说，信贷是决定经济周期的关键变量。想看清经济周期，其实可以从信贷周期入手。

好，那信贷周期怎么看呢？这里边的逻辑并不复杂。

你生产出来明白，工业生产是依靠规模化生产降低成本，提高产能的。而规模化生产，就必然要求大规模资金的投入。这种情况下，光靠你的自有资金，原就资金就很少，所以，必须依赖大规模的资本借债周转。换句话说，信贷的规模会决定社会生产的规模。

那么信贷规模又是怎么确定呢？在一个理想的状态下，靠“预期”。

如果你们都大家预期现在经济状态比较好，多生产能赚更多的利润，那企业就想干什么呢？企业就一定会去借债，扩大生产。而银行呢？也会愿意贷款给企业，因为觉得钱要安全回报率不高。

这样，一方面借钱，一方面投资，一拍合了，信贷的规模就迅速上升，生产也起来了，然后繁荣就也起来了，整个社会就进入了经济繁荣的阶段。

然后，“预期”就变得越来越乐观，对不对？开始作了更多加杠杆的行为，希望足够利用杠杆将经济繁荣的成果加倍再取。

所以，随着经济、繁荣，整个高的杠杆率会越加高，而杠杆率的升高就意味风险在加大。随着风险加大，这个时候，社会的预期又会逐渐发生变化，开始从乐观转向悲观。

那么，这么一来，由乐观预期所支撑的高杠杆，就转不住了，银行开始急着撤贷（将资金回收保证资金安全），企业也忙着收缩生产，整个经济就转入萧条，甚至衰退。

你看，这就是在一个资本驱动的经济体中，信贷与融和银行在周期中合纵横的态势变化。但是你发现没有？咱们缺了一个非常重要的因素——货币政策。

在现代国家的运作体系里边，政府的调控也是信贷周期的一个重要决定因素。

一般来说，政府不能容忍经济过热，因为它担心生产失业问。但是，经济过热不好，因为资产价格高，会把钱变富裕起来。所以，为了避免这种过热的波动，现代国家就会进行一些“逆周期”的调节。

比如说经济过热了，咱们就压一压，怎么压呢？主要有两条途径。一个是提高借贷价格下，就是提高利率，就是减少一点资金的数量，去控一控水。

反过来，如果现在觉得经济太冷了，咱们就向热操作，降低资金价，加大资金投放的数量。

每个国家虽然具体的举措上有很多不同，但是，思路和方式都是大同小异的，都是通过加息和放水来做逆周期调节，保证一个经济体以更稳定和健康的步向前迈进。调节得好，就叫做成功的宏观调控。而反之，也可能造经济的大波动。

所以，从这里看，其实你会发现现代经济的一个主要特征——和很多人知道，政府的宏观政策状态和因素，对宏观经济的运行中，政府（government）是市场的一部分，而且非常市场的部分。

美国华尔街有一句谚语，叫做Never fight against the FED（永远不要和美联储作对），这句话其实就充分说明了，即使在高度发达的资本市场，政府的宏观调控也是非常重要的因素，就不需要谈咱们中国这么一个转型的经济体了。

所以说，政府的宏观调控和市场的信贷规则应该是我们观察和判断经济周期最主要的考量因素。那么在这个框架下，我们一起来对中国2019年的宏观形势作分析。

# 二、2019年的宏观大势分析

按照刚才说的逻辑，我们首先判断，现在，也就是2019年的1月份，到底是处于经济的哪一个阶段？信贷规模怎么样呢？

从直观感受上你就能看到，这是一个很冷冷的经济状态，每天听到的都是消费低迷、失业裁员，股权质押爆仓，股市下跌的信息。

好，咱们再来着具体数据。2018年，全年的GDP增速预测在6.6%，比前几年下降了0.3%（2017年为6.9%）。看上去只是0.3%，但是对于我们这样一个庞大的经济体，这个降幅带来的负面效应是非常明显的。

除此以外，我们还知道，中国是一个投资驱动的大国，投资是增长的主要动力，也是经济流动的主要来源。2018年来，国家整个的投资固定下来，除了1999年来的最低点，全社会的信贷规也在持续下调，到达了谷底。
