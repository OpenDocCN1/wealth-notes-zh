为什么有这么大的关注呢？上一次人民币汇率低于7，还要追溯到金融危机之前的2008年，也就是漫长的11年之后，人民币汇率先升后跌，又回到了7以下的水位。这时候市场就会有很多担心，中国经济是不是不行？人民币汇率会不会一路跌下去？底部在哪儿？我们该怎么办？今天呢，我就来回答这些问题。

# 1. 人民币汇率为什么破7？

首先，我们来看第一个问题，人民币汇率为什么破7？

人民币破7，体现了政策思路的一个重要变化，就是不再坚守7的整数关口。这方面有深远的影响，要从短期和长期两方面来看。

短期看，这次汇率贬值两个重要背景：国际摩擦和内部周期。国际摩擦方面，中美贸易摩擦加剧，上周特朗普单方面继续对其来自中国的3000亿美元商品加税，削弱中国商品的出口竞争力，中国出口商将面临更大。国内市场，今年以来经济下行压力加大，客观上需要一定的政策对冲，汇率适度贬值有利于经济企稳。

长期来看，加大汇率波动幅度，允许汇率波动范围扩大，逐步实现人民币汇率的自由，有管理浮动，是汇率改革的大方向。所以，这次破7，允许波动的幅度加大，既符合短期与美联储利率周期的需要，也符合汇率市场化改革的长期方向。

# 2. 人民币汇率破7意味着什么？

刚才才是第一个问题，我们的政策思路发生了变化，不再坚守7的整数关口。现在我们来多提一层，为什么会有这种政策思路的变化？有什么深层的含义？

是的。

人民币汇率破7，有一个深层的含义，就是人民币汇率更加独立自主。从曲面上看，过去3.9就是下跌的，美元指数从98.6点下跌到97.8点左右，下跌约0.8%，短短3天，这个降幅算是很大的。但是，人民币并没有因美元下跌而下跌，不仅没有下跌，还涨了，破了7。这说明，人民币破7，并不是跟随美元的被动变化，而是脱离美元的独立变化。

为了说明这个独立性，我再给你一个证据。

人民币对一篮子货市区的汇率，并没有下跌，而是有微幅上涨的，用中国人民银行的CFETS指数，国际清算银行的BI指数，IMF的SDR指数，这三个衡量人民币对一篮子货币的指数来看量，人民币这几天都是涨的，不是跌的。

你看，美元是跌的，人民币对美元也是跌的，但人民币对其他货币是涨的。这就进一步说明，人民币有了自主的变化。

把这些信息放在一起，说明人民币慢慢脱离了美元的阴影，开始自主波动，不再是美元的应声虫。长期以来，对美元的定位，是一种制衡。脱离了美元的阴影之后，人民币地位才会慢慢增强。千里之行，始于足下，这一点，终于还是迈出中。从长期战略的角度讲，这一步很重要。虽然跌了一点，但是比远不出来说。

# 3. 人民币汇率未来走势如何？

我们说了人民币汇率破7的底层逻辑。在此基础上，我们来分析一个大家都关心的实际问题，就是怎样来看未来人民币汇率的走势。

现实中，很多人担心汇率贬值会引发大规模的资本外流，引起汇率的汇率贬值，形成恶性循环，这里的误解，在于混淆了汇率贬值和贬值预期两个不同的概念，贬值是已经发生的汇率变化，贬值预期是对未来汇率变化的估计。

目前的情况，并不支持人民币大幅贬值的预期。

从内部环境上看，中国经济出现周期性下行，但是并没有出现软着陆。而政策范围内的，能应对比较大，而且，预判周期的稳增长政策会接续出台，短期国内经济形势是企稳回升的。

外部环境上看，美联储进入加息周期，经济逐步见顶，美元进一步升值空间也不大，其他国家，包括欧洲、日本的经济形势，也都在下滑当中。

综合国内、国际情况，人民币并不存在大幅贬值的基础。

预计短期人民币是波动的态势。既波动大，没有整数关口可守，应该会继续保持波动。波动的幅度可能加大。除非波动的幅度特别大，央行会入市干预的，即使干预，程度也会很小。

中长期看，随着国内经济企稳，中美经贸摩擦的局势逐步清晰，人民币大概率是触底反弹。反弹的时间和幅度要根据政策出台和经济修复情况，进一步做判断。

# 4. 人民币汇率破7对你有何影响？

现在我们来回答最后一个问题，人民币汇率破7对你有何影响？

这个问题，要区分不同的人，人民币汇率破7对于不同的人的影响是不同的。

对于有短期美元需求的人来说，比如进口商，比如要出国留学的人，比如赴美留学生，人民币破7当然能够顺利买到，因为要花更多人民币才能换到需要的美元。

对于短期有美元进账的人，比如出口商，这当然是好消息，因为他们这些美元可以换到更多的人民币。这些都是短期波动，预计持续的时间不太长。

中长期看，因为人民币很可能会触底反弹，所以短期内不需要美元的居民，大可不必因为这次破7而在卖出人民币，买入美元。这样恐慌性的买入卖出，完全没有必要。

这次破7，其实是在提示所有有外币资产和负债的人（包括有潜在外币资产和负债的人），应当更多地关注汇率波动风险，适当分散外币资产和负债，尽量减少汇率风险。规范汇率波动风险。随着中国进一步强化对外开放，这是必须要面对的课题。
