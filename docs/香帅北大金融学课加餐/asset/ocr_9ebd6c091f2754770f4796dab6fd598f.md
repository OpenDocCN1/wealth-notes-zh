# 金融思维方法论 6| 信用思维

2018年12月结课的时候，我承诺所有同学：在2019年的4月、5月各带来一篇《金融思维论》。在2月、4月、6月、8月、10月和12月，我为你分析讲解了五种重要的金融思维：预期思维、贴现思维、复式思维、风险思维和杠杆思维。今天是12月1日，也是我们金融思维的最后的一篇，信用思维。

不止这次金融思维，因为这个词很重要。它不仅反映金融行业的灵魂，也是人类社会关系的灵魂。

要理解这句话，我们首先从“信用”这个词开始梳理。

# 1.信用、金融、货币和社会

“信用”的英文词叫Credit，拉丁语词源就是“相信”的意思。一个个体（机构）的承诺是否可靠，就是“信用”。

信用可以用在什么地方呢？

在非货币化的环境，信用意味着更强连接的关系网络，更强大获取资源的能力。比如说一个小孩，信用好的小孩子更容易上媳妇、租个粮食，或者着看佛珠佛高的人，信用额度较高。

**到了货币化的环境中，信用就是钱。**

比如古代中国官员的“买官”，就是拿大皮箱装着不值钱的西到，送到当铺里，承当到额到价额，一股形商单，或者着看佛珠佛高的人，信用额度较高。

现代或者银行领域，信用更多是卡石头、白金卡，也是普遍说“意味着你信用越好等级不同，可以获得的“授信额度”也大得径庭。

顺看人类历史演化的路径看，就会觉得很有意思：

信用本来是“信任”，是人际和社会关系网络构建粘台剂，这种信任是通过血缘、婚姻和亲密结构等容器传播信传内容构建在时间轴上。货币的产生使得多类型的“信任”变成了标准化的、可量化、可交换的资产。

更深层次讲，货币产生之后，个体之间的信任才可以被标准化和量化，才产生了流动性，有了“市场交易”，也才可以“使用”，被转化成了“信用”。

先有“信”，通过货币化，才能“用”。

这就是我管说过过的，**货币是一种塑性的信用，信用是隐性的货币**，像包包莫装，背元人民币在银行中的“现代货币”的支撑是背后主权国家的信用。

再想想各种货币的产生，各种金融工具的出现意味着什么呢？

意味着更多的个体（包括个人、国家、企业、机构）可以将自己的“信用”转化成为金钱——债券的等级，股票的多份，其实就是你在评估这一机构在价值多少倍。

所谓“金融深化”，就是更多体的信用可以跨越更大的地理空间和更多的时间维度进行转化、转化流动的资金。换句话说，金融就是“货币化信用”的交易市场，整个金融业就是一个如何建立“信用”，如何衡量“信用”，并使其产生流动性的行业。

**一个高度金融化的社会，必然是一个货币化信用非常发达的社会。**

我非常举发个例，公认金融发达的美国，在信用等于资金（资本）这个问题上，体现得淋漓尽致。

公司雇佣员工的时候要查个人信用得分，个人可能因为水上电煤水小事上的“失信”导致失去好的工作机会。当然，对于信用得分高的个体，也会有相应的奖赏机制——更便捷的贷款通道，更低的融资成本，更多的资源获取能力。

所以，当我们经常说相比中国，美国是信用社会时，其实意思是说，美国是一个更加货币化的社会。而货币化所代表的“标准化”和“数量化”使得“信用”更容易下沉到个体，也容易产生流动性，形成市场。

形成这样的社会化好？最容易理解的资源原理告诉我们，市场就是最为让有让有价格资源最置配置市场，市场价格是最有效信息信号，信用社会促进信用社会上走良性的循环。

顺着这思维思考下去，我们就会得到结论：

**数字化时代其实是金融化的时代，是金融从机构信用下沉到个体信用的时代，也是个体信用资本化的时代。**

一是因为个人生活场景不断被数字化，形成了多维度信用积分（信用积分），比如芝麻信用分、微信分支付，还有官方基于银行数据形成的个人征信分数——这些产品都直指着个体和资产相连。

二是随着数字技术的成熟，信用奖惩制度执行成本低极低，货币化信用市场也就其有了法律基础。

# 2.信用思维的2个层次

理解了上面这些逻辑后，信用思维其实就不难了：

一个人具有信用思维，意味着他（她）能够更快速“立信”并且更高效“用信”。即：信用思维是一种将“信任”转化为资本的方式。

举个现在大家都熟悉的例子，直播的顶流流量李佳娟。

一个人年销售上百亿，一个大市场，他“立信”于“亲效有效”和“全网最低价”，然后通过直播这种公开逻辑，将粉丝的信任转化为了在这种大规模电商销售中的资产。

报道中有两个小故事很触动我。一个是家乡同学的妈李维过李佳推的妈妈来了“打招呼”，一向严格的李维佳推送下口气，坚持说；另一个是一旦发现对于，比如说直播中的价格比别低，他就非常关注——这两个小细节说明，李佳推非常明白自己的“资本”和“估价”都建立“信任”基础上，而信任，正是反应很强的情形，说得大特别强大，一旦弱，可以变得非常脆弱。

你别看在网红经济炒得很火热，其实它的本质和之前品牌信理，通过信任快速——都是围绕着一个核心：存点，市场交换：规模化转换成本率，只不过网红经济中，更多的个人取代了品牌品牌而已。

多琢磨一点，你会得到抽象更深层的，再讲讲是“信用飞论”和对冲老师提的“增强回路”，其实也是这个思维模式在不同维度的诠释和应用。

说到这里，我觉得“信用思维”的搭建框架也就出来了：

**比如说，一个人要怎么立信，怎么使用？怎么化成资产？最简答的答案就是把自己当做一个品牌来位经营。评价这个品牌在所处社会网络中的位置，判断其信用，然后找最容易形成“增强回路”的点来快速突破，获取市场，从而扩大信用优势。**

幸运的，现在面临挑战的时代，整个社会的技术和商业基础设施都够完备，而且还在不断地变化中，个体信用资本创造利有红利，也让信用思维更有了用武之地。
