# 提问描述：

老师，我跟着第一学期的学习进度已经完成了第一轮的复习。现在在复习阶段，说实话，看原来的内容，会有很不一样的感觉，感觉自己确实上了一个维度。现在就是请教老师，像您这样已经有基础的学员，老师有没有推荐的一个更好的学习方式，比如讲不一样的模块复习的顺序，或者其他地注意事项？

# 吉帅

其实，这也是很多同学的共同问题，你可能已经看到问题了，从整体上而言，金融学是一门特别枯燥的课程，所以很多人感到，在原来碎片化的学习上，需要再次地进行体系化学习，或者说进行一个更深度的思考，这一步我觉得对于培养我们的金融思维是非常重要的。所以，我的建议是，第一次咱们是跟着老师扫着看书学的，那么，第二次看到的时候，抽象学，就像是通读关键字，把课程的前后内容融会贯通地理解。

好，那么我的答疑也会跟着关键词这个逻辑来进行。

比如说，“股票”这个关键词，其实它出现在很多模块里，对吧？金融工具、资产定价、公司决策，那这个两个问，最高频的出现在很银行这个模块，但是，它也经常出现在周末问答，还有科技金融模块。

你要知道，所有的金融概念都不是从天而降，是因为有因有后果的，所以，一旦你将这个前面因素弄清楚，对相关内内容就会有更深的理解了。

所以从下个月，也就是2月份开始，到11月，我按照金融知识和金融场景给你分线索，给出10个模块，这10个关键词分别是：货币、股、债、衍生品、资产定价、银行、资产、基金、公司、制度。每个回答都会针对一个关键词进行相关的答疑。
