作者：鲁伟的北大金融学院

你好，欢迎来到《鲁伟的北大金融课》。

11月发布的宏观金融时事很多。比如10月24日，中共中央政治局集体学习区块链，这意味看中国科技及金融行业的布局有更加深入的目和目标；11月初，金融机构的准入门槛放得更宽，外资银保险机构的服务限制又被缩减。这些消息都意味着，中国的金融开放进入一个新阶段。

这些事都很重要，但是我今天想和你分享的是一个不那么宏大但是很重要的，也挺奇怪的事情：**猪肉价格的飞涨对于金融市场的影响**。

可能你会觉得很奇怪：猪肉价格上涨和金融有什么关系呢？

不但有关系，而且关系很密切。

猪肉价格的一个小波动在中国对宏观货币政策的制定上，不仅很难避免，也会直接影响到四季度、甚至明年的金融资产管理，都造成影响。

# 货币政策的目标

要弄清晰一个逻辑，首先我们要知道宏观经济政策的自标到底是什么。

一般来说，央行的货币政策既要促增长，也需要稳物价，所以，价格指数就是一个重要的调控目标。如果价格指数放点，意味着经济增长，那货币政策就放点，进行刺激；反之，如果价格指数偏高，就意味着经济过热，货币政策就会收紧。

价格指数一般包括两个方面：生产者价格指数PPI，和消费者价格指数CPI，因为CPI是民生、消费，它也会被市场和央行关注。在传统意义上来说，央行的货币政策受CPI的影响也会更大。

一般情况下，生产者价格指数PPI和消费者价格指数CPI是大致相同的，因为生产过程中的价格变化会传导到消费市向。当然，PPI的波动会引起CPI的同步方向变动，但是，CPI的波动也会反过来对PPI造成反推作用。

所以，当这两个价格指数不背离的时候，货币政策的方向会很清晰的，**经济偏差，货币政策放松**；**经济偏热，那货币政策就收紧**。

# CPI和PPI大背离，货币政策怎么办？

但是，2018年12月以来，中国的PPI和CPI就出现了方向上的大背离。

2019年10月份，CPI是3.8%，而PPI是负数。虽然说这两个指数的背离也不是罕见的，但是像这种方向上相反，而且分叉走势越来越大的情况，在历史上也是很少见的。

而且，现在的CPI的预测看，CPI还会继续走高，10月份的市场有可能是今年最高的可能率，那也就是说PPI更加下行，这种情况就会产生对我们的货币政策造成很大挑战了。

在课程里我跟同学们说过，各国央行都管自己货币的通货膨胀总目标，比如美国要求CPI维持在2%以下的水平。而中国要求经济增速高一点，这个指标大约是在3%。也就是说，当中国的CIP超过3%的时候，货币政策就要管一管了，超过2%的时候，货币政策就要管一管了，超过2%的话，货币政策就要收紧，通胀压力就会更大。

从2019年下半年一直到10月份的情况来看，CPI一路走高，明显地超过了3%的警戒线。所以说，理论上去，货币政策应该收紧，对于PPI理论上问题不在此，PPI是负数，意味着工业生产的状态是相当地不乐观。

除此之外，还有几个重要的宏观指标也处在这一价位，比如GDP增速的增速处在6%，是近年来的低位；还有课程里曾经重点讲过的广义社会融资总量，也是在全球著名的广义融资量，它下降得很快，意味着全社会的消费、投资欲望很低，银行的贷款支出去；还有一个，工业增加值也是不断地下滑，意味着整个第二产业的增长也都不乐观。

所以，从工业生产这个角度看，现在中国正处于一个周期性的低点，宏观政策要求宽松经济，货币政策要求更加宽松一点。

# 猪肉和CPI

那问题来了：一方面，消费者价格指数告诉我们，货币政策应该偏紧；而另一方面，生产者的价格指数又告诉我们，货币政策应该偏松。CIP这么高的情况下，货币政策偏松，会不会导致物价继续上涨，影响人们的生产呢？但是物价在货币宽松政策推动下，经济下滑的势头正不止，到时候经济下滑又怎么办？
