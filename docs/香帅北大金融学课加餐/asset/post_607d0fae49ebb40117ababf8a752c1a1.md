要回答这些问题，我们首先就要弄清楚，注册制目前A股实行的核准制之间到底有什么差别。

其实注册制也好，核准制也好，都是一种股票上市的准入机制说白了，一个企业想要上市融资，我们就要监管着部门必须出的各种规则，像盈利要求，企业规模，信息披露程度，然后等监管部门批复，是不是允许你上上市融资。所以它们之间最大的区别是什么呢？是监管部门在这个过程中到底发挥什么作用。

你从名字其实就可以看出来，注册制排除的主题是企业，核准制排除的主题其实是监管部门。

是什么意思呢？一个企业上市的话，在实行注册制的市场上，是企业的选择，企业到监管部门去进行注册登记。监管部门负责的是什么事情？事前政府部门审核材料，事后就是监管机构是否符合中国守了这些规则，比如说信息披露，一个企业能不能成功地上市融资，基本上是上市企业到底有多少，基本上是市场的决定。

而在像我们这样实行核准制的市场上，监管部门除了颁布规则，审核材料，监管企业的工况下，在市场的准入上，它其实是有非常大权力的。比如说中国A股市场，一个企业能不能上市企业还要监管进行审批和备案，所以上市企业的数目，市场深度，监管部门都是可以进行调控的。所以我们也会告诉，注册制的主题是企业的，核准制的主题是监管部门。

总结起来说，注册制更多是企业选择，而核准制更多是监管选择，所以它呈现的现象，就是很多人说没有一个很有意思的现象，就是很多好企业都没有在A股市场上市。

90年代末，中国有一波互联网的浪潮，但要知道当互联网企业的长周期做，商业模式，和传统企业有很大不同，对不对？所以它们初期的业绩是负盈利。盈利，我们A股市场这个上市主要的是靠利润方不重要很高，所以当时中国有很有很多的互联网公司，基本上市都是在美国或者是香港市场上市，你看新浪，百度，携程，阿里，腾讯，京东，拼多多。

所以很多同学就听说了，我们A股的股民没有分享到这些最优秀中国企业资本上的高成长。就因为在核准制的这种毛病，导致了很多人这几年一直在讨论，A股市场要比较推多注册制改革，就是希望这种股权融资的市场能够更加地市场导向。

那可能有同学就会问了，说了这么多年，为什么暂时还没不能推呢？这里最主要的因素就是，市场导向不是一个割裂的设计，它必须是一套完整的市场机制设计。

在市场准入上我们要市场导向，同时就要求在市场的筛选和退出上也要市场导向，所以就像推着着让A股市场制度变得严格，真正推什么注册制就涉及到，同时我们的其他配套也非常复杂，企业的信息披露、审计，企业的信用评级，完备的法律法规都要求完善。如果这些监管不完善的话，就会发生上市公司良莠不齐，甚至市场崩溃的局面。

好，说到了这里的时候，我想刚才那些问题，你就很容易地得到答案了。比如说在A股市场的整体市场机制还不完善的状况下，如果我们贸然地推行完全准入的注册制，就很有可能发生崩盘的事件，所以我们这就是为什么注册制推了这么多年，我们还没有很大幅度地推进的原因。

目前，国家在推科创板，就是想把科创板作为试验田，希望在这么一个小型的试验场里面，检验把整套市场所有的制度都设定好，保证所有的制度配套都能够协调前进，在这种情况下，可能就容易更顺利注册制推行完毕。

另外一点就是对投行，也就是我们平时讲的券商来说，上市要融资的企业多了，投行的发行成交业务更多了，所以注册制的实行不一定会导致投投行不挣钱，反而可能多挣钱。

但是要注意的，在核准制下，与监管层的关系，对监管政策的把握是券商的核心竞争力；到了注册制下呢，可能是就要花更多的心理在理解定价和投行业务上。所以投行不一定挣钱，券商业务的周期性我觉得不会有多大的改变，整个投行的经营思路会有一个方向性的改变。

春师

要回答这些问题，我们首先就要弄清楚，注册制和目前A股实行的核准制之间到底有什么区别。

其实注册制也好，核准制也好，都是一类资本市场业务的准入机制，比如说一个企业要来上市敲钟，像以就要向监管部门提交各种资料，像营业报表、企业规模、信息披露等等，然后等监管部门批复，是不是允许你到市场上融资，所以在他们最大的区别是什么呢？是监管部门在这个过程中所扮演的角色。

你从名字其实就可以看出来，**注册制撤去的主语是企业，核准制撤去的主语是监管部门**。

这有什么意思呢？一个企业要上市的话，在实行注册制的市场上，是企业的选择，企业到监管部门进行注册报备。监管部门主要做什么呢？审核你的资料。事中审查材料，事后监督企业是不是符合或者守了这些规则。比如说美国市场，一个企业到底能够在比上市融资，最终上市市值到底有多少，基本上是市场决定的。

而在像我们这样实行核准制的市场上，监管部门除了审阅规则、审核材料、监督企业的工作外，在市场的准入上，其实是有生杀予夺的权力的。比如说中国A股市场上，一个企业能不能成为上市融资进审核和标准，所以上市企业的数目、市场热度、监管部门的可以进行调控的。

所以你会发现，注册是主语的，核准制的主语是监管部门。

总结起来说，注册制更多地是市场选择，而核准制更多的是监管选择，这个是核心差异。这就导致了一个很有意思的现象，就是很多好企业都没有在A股市场上市。

90年代末，中国有一波互联网的浪潮，但你要知道互联网企业的成长路径、商业模式，和传统产业有很大不同，对不对？所以初创时企业重视流量，互联网A股市场对企业在上市上的有盈利的手腕要求很高，所以我们中国上市的互联网大公司，基本上都是在美国或者香港市场上市的，你看腾讯、百度、携程、阿里、腾讯、京东、拼多多。

所以很多人都会抱怨说，咱们A股的股民没有分享到这些最优秀的中国企业去资本上的高成长。就因为核准制的审核门槛，导致了很多人这几年一直在讨论，A股市场要把核准制改成注册制，就是希望这种股权融资的模式能够更加地市场导向。

那何可能行就会问了，说了这么多年，为什么注册制迟迟不能落地？这里最主要的因素就是，市场导向不是一个零散的机制，它必须是一套完整的市场机制设计。

在市场准入上我们要市场导向，那时就要看在市场的筛选退出呢？要么市场导向，所以这就要靠什么去呢？就是要监管很严格，要真正地让市场进行优胜劣汰，同时它的其他配套也要非常丰富、配套的监管体系、审计、企业的信用评级、股票的法律制度都完善完善。如果这些配套不完整的，就会走上企业服务质量不齐，甚至劣币驱逐良币的局面。

好，说到这里的时候，我想刚才我提的问题，就很容易出现倒错了。比如说在A股市场完善的整套机制制还不完善的情况下，如果我们贸然地推行市场准入上的注册制，就是有些企业赚钱进多了，所以这些就是为什么注册制推了这么多年，我们迟迟不敢大规模推行的原因。

目前，国家在推创新板，就是想把科创板来为试验田，希望在这个小范围的试验田里面，去把整套市场机制的配套设施进行，在保留有有的制度改革能够协调前进，这种情况下，可能更容易限制这种圈钱行为的发生。

另外一点就是我对投行，也就是我们平时的券商来说，上市要鼓励的企业加多了，投行的发行收入业务更多了，但是注册制的实行不一定就会导致投行不挣钱，反而可能多挣钱。

但是要注意，在核准制度下，与监管部门的关系，对监管政策的把握定券商的核心竞争力；那到了注册制底下，可能投行就要花更多的心思去理解企业和发展上市。所以对投行不一定不挣钱，券商业务的周期性表现觉得不会有太大的改变，整个投行的经营思路会有一个方向性的改变。

其实这是个挺有趣的问题，中国住房抵押贷款的资产证券化程度是非常低的。那原 因是什么呢？就是因为房子质量好的。

我想一下，资产证券化是什么意思？资产证券化是将缺乏流动性的资产进行证券化，然后通过信用增级等各种方法到市场上去进行融资。所以美国的房地产抵押贷款的资产证券化就是在这种情形下发展起来的，房地产抵押贷款是流动性差，对于银行的资产负债表会形成压力，所以利用资产证券化进行出表，就同时解决了融资和流动性两个问题。

那中国的房地产抵押贷款不一样，它是绝对的优质资产。一来，咱们中国房贷的首付高，杠杆率是偏低的，而且前些年中国的房价上涨很快。所以，对于中国银行体系来说，房贷是高收益的安全资产，既没有流动性问题，也没有安全问题。换句话说，银行根本就没有将房地产证券化出来的意愿，都希望把它放在自己的表上，放在自己账上，当下金蛋的母鸡。所以，我们的银行把房贷进行证券化的欲望很低，这是过去的一个现象。

随着中国房市普涨时期的结束，随着家庭杠杆率的升高，房贷的安全性和流动性不一定能够保持现在这么一个特殊的状态，所以2017年开始就出现了若干城市公积金的证券化。所以我猜，未来中国房地产抵押贷款的证券化市场应该是有很大的潜力。

# 总结

+   - 划重点

1. 注册制和核准制都是企业上市的准入制度，只不过注册制更多是市场选择，而核准制更多地倾向于监管选择。
2. 上市企业和融资市场是一个生态系统，它们之间是相互影响、相互促进的。好的市场容量大、流动性好，能够为企业提供强大的金融助力；反过来，优秀的企业也会反哺市场，让投资者分享企业的成长。
3. 过去中国房子抵押贷款流动性好，信用等级高，对资产证券化的需求比较小，未来这个局面可能会有改变。

# 6月问答丨为什么蚂蚁借呗要限制我们贷款的使用场景？

青柠的北大学课

这个月我们的问题是围绕着“债”这个人类最古老的金融关系展开的。

债是信用关系的基础，不管是银行、债券，还是红色形态的，包括很多金融工具，本质上就是债务关系。

今天的问题集中在网贷行业和中小企业融资难的问题上，具体是：

- 1. 为什么蚂蚁借呗要限制贷款的使用场景？怎么监控我们贷款的最终用途？
- 2. 互联网金融会消除信息不对称吗，这对大家是好事吗？
- 3. 四五线城市幼儿园能通过债券融资吗？

# **强总**

听完今天的课程，我去蚂蚁借呗看了一下，自己的额度可以到5万元的信用贷款，而且2小时就能到账。想起了刚一期课程中提到的：“你的个人信用值钱吗？”不过我注意到，这笔贷款的使用范围是有一定限制的，只能用于“个人日常消费，装修、旅游、教育、医疗”，不能用于“购房、投资及各种消费场景”，不知道这是什么？蚂蚁金服又是如何监控这笔贷款的最终用途的呢？

# **青师**

这个问题我猜是很多90后的同学很关心的，因为很多同学都会使用支付宝上的两款产品，蚂蚁借呗和蚂蚁花呗，很多人搞不清楚花呗和借呗到底有什么区别。这里要说清楚一下。

蚂蚁花呗依托于淘宝和天猫的线上消费平台，它有自己的固定使用场景的，也不能取现，而且借款额度低，可以按时还款的话就不收任何利息，有点类似信用卡，它是一种消费的形式。

而蚂蚁借呗的基础功能是网络小额信用贷，借款额度从1000块找到30万不等，这个额度根据人脸识别、芝麻信用分等，支付、信贷、保险数据，结合模型授予你的。而且还有一点，借呗是取现的，所以它和具体使用场景的关联性不高。

换句话说，花呗给你的钱都是有明确消费场景的，钱仿佛没有离开，不管买的是放钱方还是借款方，都比较安心，借呗不一样，它是一种纯粹的，基于信用评估的现金贷，使用不趋于，更加类似于现金贷，当然风险也就比较高了。

咱们知道消费贷和现金贷，它们在风险和监管方面的要求存在很大的不同的。

**首先，消费贷风险比较低，现金贷风险比较高。** 因为消费贷的应用场景被决定于贷款方有实际用途，这笔贷款就会被严格限定在这种特定的消费领域，它不容易被挪用。而做现金贷的信贷群体是那些较难申请到银行贷款和信用卡，但又具有借款需求的客户，他们的资信水平相对比较低，而在没有抵押品，无机构、无贷款的成本很低，所以现金贷的坏账风险是很高的。

消费贷的预期坏账率一般是1%~5%之间，而现金贷的坏账率偏高，我们国家的数据显示，现金贷坏账率普遍在20%以上。

正因为此，监管对现金贷的关注度非常高。像2017年管监会红头文件，对现金贷的整治和监管是主流，而且监管是相对强调，要暂时发放无特定消费债权，无指定用途的网络小额贷款。最怕是做这些贷款到不知名的地方，甚至被用作非法用途。

说到这里的时候，我想就明白了，从蚂蚁金服这个角度看是，蚂蚁花呗和蚂蚁借呗这两个产品的属性是很不一样的，花呗属于消费贷，是受到国家政策支持，借呗的小红点较近，所以蚂蚁金服更尽力地与现金贷区别开来，转向消费贷，才出台了借呗贷款用途的政策，更是引导用户把贷款用于个人消费场景。

除了引导之外，就是第二个问题，如何监控贷款的最终去向问题。

在明借呗的时候，你可以选择放款到支付宝里或者绑定你的银行卡里面，如果你放入支付宝卡里，那借呗用户很容易被蚂蚁金服观察到。

那如果放到银行卡呢？尽管蚂蚁金服看不到你的重新用途，但它可以通过打电话，查信贷、查账单、查询交易等方式，查到你这笔借款的用途，如果你违规，就会迅速地被关闭平台降低额度，甚至关闭借呗。

这意味着什么呢？这意味着这种监控不可能是百分之百的，但是给定阿里巴巴、腾讯这样的大平台，它们确实具有能够监控贷款去向的可能性。

比如新申请信用付，某笔用户将信用贷投放用于诸如买房、卖房、理财产品等用途，但其绝大部分用户是守规矩的。蚂蚁金服的数据信息显示，蚂蚁花呗中70%的资金是用于消费场景的日常消费，其不良贷款率低于1%。

因为阿里自己的平台场景是足够丰富的，所以很难限制贷的用途，然后蚂蚁金服的去向，提供现在已经是很便捷，转变成为消费信贷的产品，这也是蚂蚁金服自身平台需要。

换一个与互联网平台，没有阿里、腾讯，或类似的平台的，这种丰富场景的，你再去监控贷款的去向，难度其实就会高很多很多。
