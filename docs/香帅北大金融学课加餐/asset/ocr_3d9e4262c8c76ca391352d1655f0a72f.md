# 未来中国哪个地方潜力大？一份你没见过的城市清单

今天的分析分为两个部分：第一部分，哪些城市的投资价值更大？我会给你一个城市清单。第二部分，怎么看中小城市投资价值？

# 1. 城市价值清单

先来第一个问题，哪些城市有较大的投资价值，这个问题比较简单。这几年我们团队做了详细的分析，下面是一些主要结论：

我们把潜力大的城市分为三类，分别是一线城市，区域核心二三线城市，和都市圈次中心城市。

第一类，一线城市，就是北京、上海、广州、深圳。

这四个一线城市不管是经济规模、基础设施，还是就业机会、人口吸引力，都已经是国际性的大都市，在未来的竞争不言而望，其投资潜力也不言而喻。对于这几个城市而言，不是买不买的问题，而是限购政策之下，很多人没法买，想方法送买的问题。

第二类，区域核心城市。

我按从南到北的顺序，给你列一下，分别是厦门、福州、长沙、武汉、重庆、成都、杭州、南京、济南、青岛，一共10个城市。这10个城市，都是大家熟悉的核心区域核心城市，位于东南沿海或者中部地区，基础条件好，经济腹地大，也都在吸引人口流入，有大的发展空间。

第三类，都市圈次中心城市。

有四个城市，从南到北依次是东莞、佛山、苏州、天津。这四个城市的共同点，是处于都市圈的核心地带，离核心城市很近，加上本身的基础也比较好，未来很容易承接核心城市转移出来的资源，未来很可能形成都市圈次中心城市。

| 一线核心 | 北京、上海、广州、深圳 |
| 区域核心 | 厦门、福州、长沙、武汉、成都、杭州、南京、济南、青岛、重庆 |
| 都市圈次中心 | 东莞、佛山、苏州、天津 |

比如说东莞，离深圳很近，工业基础也非常好，很容易形成深圳东莞一体化格局，再由原先“形”也很容易，来广州附近的佛山基础也非常好。这样就很容易形成“广州-深圳-东莞-佛山”城市发展超大城市群，发展东莞起连带责任。发展的东莞、佛山目前主要还是东莞的，但是以占有全国人口的潜力。上位处长三岛的苏州也是类似的道理，本身实力很强，位置上海、南京两大都市中间，很容易形成联动发展的格局。

讲到这里，你可能发现了，怎么这个名单上都是东南部和中部的大城市。难道西北、东北的城市就没有潜力吗？

回答这个问题之前，我先给你介绍一个概念，胡焕庸线。

![](bbox=[0.0, 0.8, 1.0, 0.9])

胡焕庸线是中国地理上的一条分割线，大致是从黑龙江黑河到云南腾冲这条大东北到西南的45度斜线。这条线的一侧从东南，人口密度大，降水充沛，而这条线的西北侧，人口密度大，降水干。奇怪的是，从1935年胡焕庸提出这个地理分割线以来，线两侧的人口比例几乎不变。东南半壁土地面积占36%，人口占96%。西北半壁土地面积占64%，人口占4%。东南侧的人口密度，是西北侧的42倍。

这么多年过去了，这条线两侧的人口比例这么稳定，说明背后的人口分布规律是稳定的。那在将来，东南侧还是人口密集的城市，西北侧还是人口大，所以西北部的城市，投资潜力不会太大。如果你在西北的城市，在这条线的西北侧，买房投资要三思的时候就要仔细斟酌一下。

你可能还有疑问，老师，胡焕庸线的西北侧潜力不大，可是东南侧也有很多大城市啊，比如郑州、西安、合肥、昆明等等，这些城市也很好啊，为什么不在这份城市名单上？

城市是这样的。这些城市作为传统的区域中心城市，潜力应该是不错的。但是这份清单是一个比较短的清单，我只列出了比较确定的有18个城市。其他城市潜力也不错，但毕竟和中国南方城市，只有14亿人自己，但是目前来看，有些地方长期的潜力不是非常明显，所以就暂时没有列出来。

城市发展是动态的过程，随着情况的变化，政策的变化，这个名单可能会调整。这个我们也会在来开不断更新。
