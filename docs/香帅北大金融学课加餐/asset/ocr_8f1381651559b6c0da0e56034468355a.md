特色，经营也非常本土化。所以这些内容要让海外的投资者真正明白，不是那么容易的事情，给企业定价的时候很可能要打折扣的。

另外，部分的中国企业在信息披露方面经常有一些不良记录，以及现在比较激烈的中美博弈，所以中概股在美国市场上这几年日子挺难受，很多企业都是“蠢蠢欲动”地想要回流A股。

也正是这些原因，所以中国政府在力推科创板，就像我刚才说的，它希望把科创板作为一个试验田，中概股上市需要一个全方面的改造，希望能够留住那些具有未来增长潜力的企业，让中国的A股市场也能培养出下一代的腾讯、阿里，形成一个更好的企业融资生态。



唐老师，可以谈一谈为何我国住房抵押贷款资产证券化程度这么低呢？我觉得我们国家的房贷挺优质的，发放房贷时银行把控得很严格的。

+   - 香帅

其实这是个挺有趣的问题，中国住房抵押贷款的资产证券化程度是非常低的。那原 因是什么呢？就是因为房子质量好的。

我想一下，资产证券化是什么意思？资产证券化是将缺乏流动性的资产进行证券化，然后通过信用增级等各种方法到市场上去进行融资。所以美国的房地产抵押贷款的资产证券化就是在这种情形下发展起来的，房地产抵押贷款是流动性差，对于银行的资产负债表会形成压力，所以利用资产证券化进行出表，就同时解决了融资和流动性两个问题。

那中国的房地产抵押贷款不一样，它是绝对的优质资产。一来，咱们中国房贷的首付高，杠杆率是偏低的，而且前些年中国的房价上涨很快。所以，对于中国银行体系来说，房贷是高收益的安全资产，既没有流动性问题，也没有安全问题。换句话说，银行根本就没有将房地产证券化出来的意愿，都希望把它放在自己的表上，放在自己账上，当下金蛋的母鸡。所以，我们的银行把房贷进行证券化的欲望很低，这是过去的一个现象。

随着中国房市普涨时期的结束，随着家庭杠杆率的升高，房贷的安全性和流动性不一定能够保持现在这么一个特殊的状态，所以2017年开始就出现了若干城市公积金的证券化。所以我猜，未来中国房地产抵押贷款的证券化市场应该是有很大的潜力。

# 总结

+   - 划重点

1. 注册制和核准制都是企业上市的准入制度，只不过注册制更多是市场选择，而核准制更多地倾向于监管选择。

2. 上市企业和融资市场是一个生态系统，它们之间是相互影响、相互促进的。好的市场容量大、流动性好，能够为企业提供强大的金融助力；反过来，优秀的企业也会反哺市场，让投资者分享企业的成长。

3. 过去中国房子抵押贷款流动性好，信用等级高，对资产证券化的需求比较小，未来这个局面可能会有改变。

+   - 香帅
