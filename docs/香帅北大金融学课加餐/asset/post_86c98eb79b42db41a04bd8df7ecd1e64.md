# 宏观金融时事分析6｜包商银行事件是不是打开了潘多拉的魔盒？

《香帅的北大金融学课》

你好，欢迎来到《香帅的北大金融学课》。又到了我们每个月中旬的金融时事解读课程。

2019年的5到6月是咱们金融市场的多事之夏。先看中美贸易摩擦不断升级，不确定性增加；到5月20号，4月行的宏观数据出来了；证监经济下行趋势并没有出现明显扭转；这还不算完，5月24号，金融市场炸出了一个大雷，人民银行和银保监会联合发布公告宣称，包商银行由于出现严重的信用风险，依法进行接管，接管期限为一年。

除了内蒙人，普通百姓可能对包商银行没有什么感觉。但是，对于金融圈来说，这真的是颗炸弹。很多人认为这好算是潘多拉的魔盒被打开了，这是过去二十年来第一个银行接管。

我们在课程里曾经提到过，新中国以来，在很多老百姓的潜意识里，银行信用就等于国家信用，即便银行出了什么幺子，最后国家会兜底，也总是俗称的“刚兑”。

以一种很官僚的方式告知天下，包商银行严重信用风险而被接管，看起来需要把“刚兑”这个盒子打开。

我们都知道，经过几年的经济下行和金融去杠杆，可以想见，这个盒子里有一大堆的东西，所以，市场很担心盒子一开，后面会被萝卜带泥出来，把整个银行系统的信用风险拉高。

这不是空穴来风的猜测，实际上像锦州银行、恒丰银行，早在银行有比较银行有大批的不良、早就被央行有较强信用风险的中小银行名单里，只是不知道这风暴哪一天会降落到自己身上。

那么包商银行到底是不是打开了金融市场潘多拉的魔盒，我有两个判断：

**判断一：包商银行事件是过去十年中国金融市场一些乱象的缩影和折射，而接管是监管层目前设计的一种纠错机制。**

**判断二：短期来看包商银行事件会对市场的波动性形成一定的压力，而中长期来看，这是中国金融发展模式的一个转折点。**

这两个判断听起来都会比较专业，所以，我一个一个地帮你分析。

## 1. 接管不等于破产

首先，我们要先搞清楚包商银行行接管对金融市场的冲击。这里要搞清楚包商银行接管是什么意思。

网上有很多长篇累牍的解释，我觉得看了以后还是无法理解。给你形象一下：

像包商银行这种小型的城商行，在央行和银监会爸爸眼里都算是第三梯队，平时是有事的自己去找找爹去吃，但，现在周末出事儿了，央妈没办法，不放弃，直接的回来起来，说不定还是急身急案。但是呢，外面闹的债还是想办法帮它还掉。

![](img/783c4672cb71918524489272291477ee_47_0.png)

比如说在现在的兑付的接管方案中，对个人储户，那严格保护自己的。个人的存款会全额兑付，其他个人的业务也是正常兑付。

而且对于5000万以下的对公存款和金融同业也有全额保护，这是去保护那些最基础信用，储户信用，不能让整个市场风波蔓延到社会上，变成社会上的风险。

那对于包商银行的这个间业负债部分，那就是一个简单的债务规模部分。按照负债是性质的多少，分别以100%、90%、80%到70%的比例来兑付。承兑汇票也是一样的思路，按照金额进行部分承兑。

这是一个典型的行业咱们内共克时艰，做实家有点难，央妈来承担大部分风险，但大儿也一块儿来分担这些风险。

所以，截至目前来看，接管方案的一个原则就是个别家对内处理的形式，它的目标是消化债务，缩小社会影响，尽量把这个烂尾的影响限制在行业内。

## 2. 包商银行事件不是孤立事件，是过去十年金融乱象的折射

清楚接管到底是什么意思之后，接下来我们看看包商银行的严重信用风险到底来自哪里。

根据央行的公告，大股东掏空包商银行的信用风险来公示，已经被调查过的高管图通过复杂的交叉持股，实际控制了包商银行，然后大量挪用有包银的资金，然后导致包银的信用危机。

但是，拆开了包银，我们稍微专业一点，聚焦一下包银的经营数据，你就会发现，这家银行和我们想象中稳健经营根本上边。

在前面我们的课程里说过，银行资金主要靠什么？靠储民、企业的储蓄。另外一些短期资金就是来自于银行间的同业市场进行互相拆借。同业资金主要是一个补充流动性的工具，期限短，利率高。一个银行如果大量依赖同业资金，就很容易形成这类严重的期限错配，为什么呢？因为长期的贷款去匹配短期的借款。

另外，经济只要稍微波动下行，就容易形成最后负债问题的局面。即使那张担保表截止至九2月的时候，那它已经是2017年第三季度末了。就在那个时候，它的一年来由于这种高负债的同业资金，同业的负债率达到48.2%，而同期，中国银行业同业负债率的平均值是19.4%，包银是行业平均负债的2倍多。

包银规模相近的城商行，像长沙银行、成都银行、兴业天津行不超过23%左右。换句话说，包商银行是一个撬动能力非常强，资金成本非常高，而且资金稳定性很差的银行。

这样的资金滚来源结构，那就会当然会使着银行，在资产运营方面更加激进。你的资金来源是很高的，可以吧，你吧你的这些投资投向那些高收益，也要高风险的项目，比如像多头投资的各种非标产品。

所以，你看，高成本、低稳定性的资金来源，必须去追逐高收益、高风险的资产。同时还要不断地进行期限匹配的管理。再加上明年这样大的宏观在背后一推推助，那么，只要宏观经济稍微出一点波折，或者哪天系出一点风波，包商银行的命运早就注定了。

你看，2017年4月，金融去杠杆，同年，明天的实际控制人肖维夫失联，紧接着就是2017年第三季度，包商银行就停止发布经营数据了。

应该说，包商银行的这个信用风险，其实是典型的信用经营风险，也早就在市场预期之中，到最后是接管还是破产，或者是兼并，其实是一个技术层面处理的问题。所以说，股东治理技术和金融和银行经营的经营风险叠加，就演变成了这二十年来第一个银行接管事件。

对我们这个市场来说，更复杂的问题是，包商银行的金融模式，是一个个案，还是普遍性的？很不幸，答案是具有相当的普遍性。

这其实和过去十多年中国的金融政策也有比较大的关系。过去十多年里，咱们的金融是以银行为主导，银行牌照稀缺，在地方行政权下的，地方的银行政策收紧。2000年代初期的时候，我国的银行数目大概是40多个，到了2018年是4000多个。

虽然金融资产的规模增长也很快，但是难免会生出很多大大小小的问题。所以，地方小银行对于当地的小微企业融资可是有积极作用的。但是，你看小微企业的贷数据着高风险，经营下的时候会连带着银行。而且，在发达地区的地区性银行，投搞能力低下，到最后就只能依靠同业市场。

所以，大部分的这个中小型的地方银行，实际上面临着和包商银行同样的经营风险。

更何况2012到2016年，还是中国金融创新走得最快的几年，利率市场化，银行混业经营，银行持股，结构变动，科技金融创新，这样一来就形成了金融市场的产品创新远远走在金融监管之前的这么一个局面。

市场上呢，复杂性的结构性产品层出不穷，通过层层嵌套，然后底层资产就变得非常地不清晰。这也是中国影子银行的根源之一。2017年以来的金融去杠杆就是针对这种局面的，希望能将这些影子打破，免得以后资产规模越来越大，影子里面杠杆越来越高，最后发生风险，到不可收拾的境地。

2017年去杠杆这个时间点的选择，到现在为止也是是有争议的，因为当时经济下行的态势已经比较明显了，加上金融去杠杆以后，形成一个正向螺旋，使得更多的企业陷入困境，导致银行的坏账更多。

但是，不管怎么说，这一举措是有一个很大的政策含义的。它意味着中国金融政策的转向。前些年以放为主的金融思路出现了变化，稳健和监管被提到更重要的位置上。部分高风险的中小银行，迟早是要处置的，只是以什么方式处置，既能保持市场稳定，又能改变市场预期。

所以，这一次包商银行的接管，大概就是在这么一个思路下的产物。用接管，而不是破产，表明是家事，中央有注入资金解决问题的能力和意愿，但这样公开地解决又是释放了一个强烈的信号，杀鸡儆猴，告诉市场政策转向的决心和力度。

现在，中小型的银行已经占到银行总资产的50%左右了，对整个社会的信用扩张其实是起到一个很重要的作用的。所以，在这么一个情况下，包商银行事件本身即使不是大事，但是，它也会影响到整个市场的预期和引起部分银行的惶惑。所以呢，市场上出现短暂流动性风险的可能性是比较大的。

从理论上而言，在短期内这些风险的影响是完全在可控范围内。但是，具体影响多大、多久，其实是取决于央行动作的频率和力度。如果央行现在是及时出手补充流动性，影响就会比较小。如果央行出于其他的考虑，去静观其变，市场波动的时间就会更长一点。

从中长期来看，金融业，尤其是银行业从放到收是个必然趋势。这些年银行扩张很快，中小银行是希望解决中小企业融资难的问题，最后发现，中小企业融资难的问题没有得到完全的解决，但却搞出了影子银行这样的问题，导致监管无法穿透。而金融风险的不可控，这是中央最担心的事情。

所以，未来五年到十年的中国的金融市场一定会朝着更透明的直接融资市场发展。

## 划重点

- 包商银行是近二十年来第一个被接管的银行，以官宣的方式宣布出来，看起来是一个惩戒警告，但实际上它是以家庭内部处理的方式去消化债务，希望把风险限制在可控范围内，同时也表明纠正中国金融市场乱象的一个决心。
- 接管包商银行不是一个独立事件，从短期来看，它会对市场的流动性造成一定的压力；从中长期来看，则是中国过去十年金融市场从放到收的这么一个转变，也会是中国的间接融资市场下决心转向

# 宏观金融时事分析7丨为什么财富管理公司会爆雷？

你好，欢迎来到《香帅的北大金融学课》。

今天是7月15号，照例是我们解读2019年月度宏观金融时事的时候。

前几个月，我在每个月的重要时事里面选择了6个话题，都是跟我们投资决策相关度最高的宏观金融知识点，像经济周期拐点、货币政策、政府工作、银开开放等等。在这些篇课程里，我帮你把这些金融知识都进行了讲解，希望这些知识能帮助你从一个更高的维度与更深的层次理解财富、做好财富决策。

这个月我要分析的事件是一个跟我们百姓财富关系紧密的事件。7月8号，被称为富豪在美国上市的财富管理公司德弘公司，爆出了踩雷34亿的丑闻。

诺亚旗下有一个叫资产，然后它发行了一只私募基金，收益率大概是是7.7%左右。这个私募基金是一是一家叫东兴财富的公司提供了34亿的供应链融资，结果承租的实际控制人也涉嫌诈骗被拘捕。

那这个现在想想呢，如果你家里买了诺亚个产品的投资人，就等于手摔到了这个雷地里，能赔回多少资产残值，那是个大大的问号。

那这张不算小，最大的是什么呢？是在那这张发说明书里面，这个基金的资产标的写的是东兴和东东之间的应收账款业务，结果雷雷以后，京东表示说呢，这些业务跟京东没关系，我就是跟兴通德创和东东的之间，换句话说，诺亚这个基金的投资者对大概会欠七的猫，34亿的应收账款大概会七九头，也不知道了多少家庭会因此陷入贫困。

那这方面的事在网络上很多，今天要跟大家讲的是诺亚这个事儿本身，以及跟这个事件相关的，大家非常关心的爆雷的现场。

我们前做了一点不完全统计，从2017年开始，中国一家的独立第三方独立在产公司中，有大概20多个产品踩雷，涉及的金会达到百亿以上。文末有张表，你可以一直滚动后看到看哪些公司出了哪些问题。

所以，通俗一点讲，就是一度曾经被炒热捧的独立第三方财富管理，截至2019年，已经进入了违约爆雷的泥潭，而多产家庭财富就此被消灭掉了。

## 1. 第三方要求的是独立

要理解为什金融理财的财富管理公司这两年频频爆雷，我们首先要理解第三方财富管理这个概念。

你先想一个最简化的框架，在这个简化的框架里面，金融市场无非就两端——资产端和资金端。

资产端，像银行、信托、基金的产品；资金端，像我们个人和机构的资金。而所谓第三方，就是站在独立位置，去帮助个人、机构、客户进行财富管理。比如说去分析客户的资产偏好、理财需求，然后帮助他们选择投资产品，进行投资规划等等。

这个行业实际上兴起于美国上个世纪的70年代，当时有一个背景就是美国的中等全面崛起，而当时金融投资工具变得特别丰富。再加上一个事件就是1974年，美国个人养老改革法案，而养老金的投资收益是免税的。所以，这样一来，美国的资本市场，资产端和资产端两端都变得特别丰富。这样一来就诞生了以中介服务为核心的第三方财富管理。

这里第三方起到的作用，就是帮助金融机构那种手买卖，自卖自夸，完善自己高风险管理的道德风险。

第三方财富管理能起步有几个前提：

- 你的资产端、资金端都要足够丰富，投资者要有钱，触碰方要有好的投资的。只有在这两个资产和资金端都很丰富的情况下，这个市场才需要中介服务去完成搜寻和匹配的工作。
- 这个第三方需要有很强的专业能力，能够完成这个搜寻和优化匹配的工作。
- 你一定要有保证第三方权利义务界限清楚的契约和保证系统，否则第三方就容易灰色地带。

## 2. 中国变形的第三方财富管理

我们再来看下，中国的第三方财富管理是不是满足这些条件？

中国开始出现财富管理这个概念大概在2008年，然后从2012年到2015年期间变得很炙手。2013年这个年出现这个上，其实是有历史背景的。

你看，中国经历了几十年的高速增长以后，就形成了可观的民间财富，然后资金端变得很充沛。然后到2008年，宽松政策一方面给资金端加水，一方面让市场上的投资机会变多。再2012年之后，金融监管全面放松——2007年的资产化规范规的2012年开始，公募的银行机构下就进入了群雄逐鹿的局面。市场上的资源变多得也丰，所以说，财富长效应、宏观金融、金融脱实向虚拟的趋势让资金端都变得充沛。

这样就为第三方理财创造创新提供了前置条件，很多房地产开发这样的项目就都被打包源源不断地送到市场上。

所以，这个时候是金融产品的销售需求大涨，第三方理财机构最初作为金融机构的零售端进入了市场。它们是机构把这些产品，然后去展客户面前放，把产品后销售，自己从中抽取佣金。

你去一下看，诺亚财富管理限制的营销要求，5年以上的销售经历，奢侈品、高档车、房地产销售经验优先。

你在很早以前就清楚第三方财富管理这个模式，从银行来看，银行是一个对专业，对经验都要很高的行业。不说话的，我们的部家金融管理博士，现在我给自己家人放一点金士达都没有什么翼翼，不敢投入。一个卖房子的和奢侈品行业经验的人，就搞分金融上的专业、专业，年轻人，几万、基于上千万、上的资金都管呢？我开过一句玩笑说，就是卖静动的暖气啊？

而且，你会发现，这个方向、诺亚根本不独立的，大、大发、方面，都是在这个模式建起的。这说明什么呢？这说明中国的第三方财富管理，从一开始就不是第三方专业型中心，而是一个销售机构的身份，它是第三个为盈利模式的。

所以，这个模式就决定了中国的第三方财富管理在金融的风控上很难独立，也很难专业。

美国是直接投资为主，各大金融机构是一个完美的竞争态势。中国因为这个背景不一样，中国的金融市场里只有一个独立，其他的机构大如都是做基金通道业务。第三方财富管理是处于这个生态位的尾端。

那些第三方理财你就可以想象了，一方面，他们是拿不到最优质资产的，另一方面，他们对市场波动的反应也更迟，那自然风险就更高。

另外，和美国的这种金融立法特别完备的情况也不不同。

中国的现代金融市场，仅仅过了二十二多年的历程，监管立法的储备是相当滞后的，所以，对于这些金融业务模式的监管、立法、执法都处于摸索阶段。你会发现，中国金融市场站在金字塔是相对较大的空间。

所以，截至今天为止，我可以这么说，中国的第三方财富管理市场是一个良莠不齐，信息不对称的市场，也是一个产质量相对差的市场。要知道诺瓦呢，就是级投资产品，这种情况可能会在未来慢慢改善。但是到今为止，就是这个样子了。

那些爆雷的财富管理公司，我们也知道它们底层逻辑是非常薄弱的，所以，大点的机构，比如像诺亚，就开始做投资产品的机构，比如像诺亚，就开始转型做资产管理。比如这一次出事的这个产品，就是它旗下歌斐资产发行的。这么一个财富管理公司一只手做资产管理，一只手去卖自己的资产，那就等于就是卖自家的货，那就谈不上什么第三方。

## 3. 金融去杠杆：压倒第三方财富管理的稻草

刚才讲的就是第三方财富管理的中国特色。现在你大概知道了，我们市场的制度环境、法律基础，还有专业能力，都让这个行业目前处于一个高风险、强投机的阶段。所以，只要碰到经济波动的话，这个行业就会出问题。

而2015年以来，中国式经济转型，这种投资拉动的模式被限制，同时，为了防止前期过快的金融自由化累积下来的风险，中央开始实施金融去杠杆。所以，这些宏观和监管上的转向，就使得这个行业的内在风险被快速地暴露出来。

投资项目少，信贷萎缩，就意味着资产端收缩。在资产端收缩的这种情况下，第三方财富管理为了维持盈利，维持规模，只能转向质量更低、风险更高的产品，而经济越下行，监管越紧，第三方财富管理销售的产品质量就越差，市场乱象就越多。

这就是为什么2018年以来，经济形势越来越严峻以后，财富管理公司就开始频频地爆雷了。

这么梳理下来以后，我想你就明白了，在中国目前的环境底下，是很难有所谓的独立的第三方的，市场上也缺乏真正的财富管理机构。现在你要投这些项目都非常非常谨慎，就跟2017年的时候我跟你说的，投P2P的项目要非常谨慎，最好是能够尽快抽身。

那当然可能有同学就会问，这也 不能投，那也不能投，那咱们中产阶级怎么办呢？中产阶级要怎么保护自己的财富？我们这个课程在未来还会再继续给你讲解。

## 总结

## 划重点

- 理论上，第三方财富管理以独立身份为资产端和资金端提供客观、专业的中介服务。
- 由于中国金融市场的制度环境、法律体系的特征，以及专业能力的欠缺，中国第三方财富本质上是“金融零售商”，并不是严格意义上的独立第三方。
- 2015年之后，中国经济下行，监管收紧，积患已久的第三方财富管理就开始纷纷爆雷了。
