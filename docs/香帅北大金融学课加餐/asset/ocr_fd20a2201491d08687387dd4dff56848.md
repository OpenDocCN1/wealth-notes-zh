# 工作会议带来了什么？

香帅的北大金融学堂

你好，欢迎回来《香帅的北大金融学堂》。今天是2019年最后一次“宏观金融时事”讲解。

从11月中旬以来，中美经贸摩擦和国内经济增速压力下的“不确定性”并没有消失，但也没有恶化，市场还是处于“摇摆”的状态中。12月初有两个会议，先是宏观政策定了调，让“摇摆”逐渐转向“企稳”。

这两个会议，一个是12月6号的“中央政治局会议”，其重要主题是“分析研判2020年经济工作”；另一个则是是12月10日到12号的“中央经济工作会议”，现在很受大家关注，因为市面上普遍认为是这是给2020年的宏观政策定调。

但其实我并不然——严格地说，2020年宏观政策的基本方针在之前已经确定不下，而这次会议重点在“肯定通过”，强调方向，**中央经济工作会议则侧重在“部署操作”，会更具体**。

那么，通过这两次会议我们能读出什么呢？能否看出接下来一年的宏观经济走势呢？

我在把两份文件放在一起之后反复地、自然的阅读和对比发现，**这两者都高度一致**。你仔细对比了几年，发现两份文件都多次强调了“稳”，同时也使用了一个很有意思的词叫做“逆周期调节”。

所以，“稳”和“逆周期调节”是接下来宏观大势的关键词。下面我一个一个来帮你解读。

# 1. 稳经济

“稳”字的频繁出现，给你的信号是：我之前的几篇文章讲到过，2020年中国人面临着经济层面的任务。市面上总说是有人强调“不确定性要管理”，**稳经济是经济工作当前和今后一个时期的重要目标**。我们要确保经济平稳运行。

所以之前我们在线下课程同学做2020年资产配置分析的时候，是把“**稳**”作为一个重要的条件来构建宏觀的沙盘推演。在分析市场政策和博弈方面的资产分布。

12月份这两份文件里大概有几十次提到经济的“稳”，其实也验证了我对部分自己承担的目标一致，**其成果需要调整**，目标是**更多强调“经济结构转型”和“环境变化”**。

换句话说，这个“稳经济”的表达有两个含义，一是表示经济长期增长的稳定，二是**经济从“高速粗放增长”向“高质量增长”转型**，需要一些措施进行“企稳”。

这种抽象的表达不是很大人认为的“官话套话”，它是一种“预期管理”——让**市场预知政策方向从而采取积极的行动**。

这里多说一句，美联储在这种预期管理上特别有心得，尤其是鲍威尔的美联储主席鲍威尔，更是这种“特别有意义的废话”的高手。

# 2. 逆周期调节

既然要稳经济，那措施是什么呢？中央经济工作会议会比较强调积极财政政策（比如稳健的货币政策、积极的财政政策、就业、房地产、基建、就业等等）。但是两个会议都强调了一个词，即“**逆周期调节**。

逆周期调节（**逆周期调节**）是一个典型的现代宏观经济学术语，**也被称为“逆周期调节”（Counter-cyclical policy）**，其核心思想是在经济周期波动中**通过政策手段反向调节经济**。

1936年，英国经济学家凯恩斯（John Maynard Keynes）在《就业、利息和货币通论》中提出了这个概念。他主张政府应该通过财政政策（增加政府支出或减税）和货币政策（降低利率或增加货币供给）来**弥补市场失灵，稳定经济**。

+   1. **（1）它是带杠杆的，即通过政策放大经济效应的程度；**
2. **（2）预期会强化杠杆效应，即市场会根据政策预期反向调整行为，从而放大政策效果。**

所以英国在资本市场早期，虽然经历了长期的增长，但其中大中小非常频繁，不到100年发生了大大小小20次危机。一繁荣到预期转好，扩大信贷规模，加大投资，加杠杆，经济繁荣；经济过热，出现泡沫，泡沫破裂，经济衰退，资本过剩，失业增加，消费低迷，进一步加剧繁荣衰退预期，市场陷入衰退，直至危机来临。这种周期的繁荣和衰退是**经济常态**。

因为有预期强化的经济杠杆，所以周期会有**剧烈波动**，每次波动，一方面会产生很多新创财富的暴富，另一方面会导致**财富的剧烈转移，贫富差距扩大，社会不稳定**。

这个周期，自然产生了很多关于“资本主义”的质疑，和“社会主义改良主义”的研究实践。比如有的**人认为这是“看不见的手”的失灵**，也有的人认为资本主义的内在非理性，**希望通过政策干预来纠正市场失灵**。

但是经过全球19到20世纪的实践后，很多国家对周期有更深的认识，国家开始**主动利用政策工具调节经济**，避免周期过度放大，**通过逆周期调节实现经济稳定**。

比如美国在2000年科技泡沫破裂，2001年“911”事件后，经济出现衰退趋势，**美联储连续降息，扩大货币供给，刺激经济**。同时**财政上也增加政府支出，减税**，帮助经济走出低谷。

通过“逆周期调节”，现代经济体防止了周期的过度波动，**避免了大萧条式的崩溃**，让经济**在可控范围内波动**。

中国到90年代以后才逐渐建立了现代意义上的资本市场，经济的周期波动也开始显现。过去没有经济周期波动概念，**现在政府也明确使用“逆周期调节”来稳定经济**。除了货币政策外，**财政政策也是一个重要的政策工具**。

政府通过**发行国债、增加政府支出、减税、投资基础设施**等手段来调节经济。在逆周期调节下，政府的支出和税收变化直接影响总需求，**起到“稳定器”的作用**。

当然，作为一个强势政府的经济体，我们的**政策工具箱比西方更丰富**，比如**财政、货币、产业政策、结构性政策**等。政府可以在政策组合中**灵活选择**，但**成本也更高**，需要**精准操作**，避免副作用。

换句话说，**逆周期调节不只是简单的“稳”**，它包括**政策组合、预期管理、结构调整**等多方面内容。

所以当两个最具有影响力的经济工作会议都在2019年底提出“逆周期调节”时，**其实施的政府主要一直在逆周期的状态中**。我们想强调的稳是指**逆周期的状态，包括前期到了逆周期的后期**。这时候如果大幅度“逆周期”，担心市场不稳定。所以**逆周期调节是动态的，有度量的**。

2019年第四季度的经济数据已经显现回暖迹象，所以**“稳”的目标已经基本实现**。接下来的“逆周期调节”**力度会逐渐减弱，转向结构调整和高质量发展**。

稳是目标，**逆周期调节则是选择和工具**。

你如果明白了“稳”和“逆周期”就是接下来宏观经济的关键词，经济定价就更容易了，这种动态会对后面的资产价格稳定起什么作用，其实我在前面的课程里面也讲过。

所以最后，我也希望你思考一下，在2019年底的**稳经济**和**逆周期调节**的情况下，明年整体是什么样的？希望你结合自己的思维或经验，**从图中这个问题**，以便更真实地消化和会金融知识，做出更好的财富决策。
