# 课程结构及内容简介

我一直觉得，财富管理和经营人生本质 上是一回事，都是一种“投资”——找 来最能增值的资产，投入大笔资金，长期 持续经营，创造更大价值。

这句话听上去简单，但如果“什么时 候投？投什么？在哪儿持续经营？” 这个核心问题没有想清楚，就容易陷入“盲 赌”的状态。

那么怎样能将投资决策上的明眼人呢？ 我们不妨先将投资分为“狭义”和“广 义”两种：

直接的财富（资产投资）牵扯到很多决 策：

该买房吗？买在哪个城市、哪个区？ 资产应该配置在股票、债券，或其他 投资？股票、房子、存款的比例应该 在什么位置才安全？散户究竟该在 种金融资产“入场”和“退场”的节 奏，免得各种被“割韭菜”？

另一类是更广义的“投资”，它包括 对“未来”的所有时间、金钱、精力的投 入：大学毕业是创业还是先打工？是公 务员还是进民营企业？是冲入北上广 还是回到家乡？想转行转到什么行业 最好？孩子读大学是选专业还是先选 先选？该读出国吗？

这些决策看似纷繁复杂，但如果我们将 它们拆解开会发现，所有决策都是三个 维度上的优化：

第一个是宏观维度的择时优化；

第二个是中观维度的选址优化；

第三个是微观维度的配置优化。

这三个维度的决策优化，我为你提炼出 三个关键词，分别是“周期”、“城 市”和“资产”：理解经济周期的波动 规律，才能准确择时，趋利避害；理解 外部环境的利弊优劣，才能挖掘潜力， 实现长期增值；而理解个体和资产的特 征，才能精准匹配，扩大收益，降低风险。

今年，我的线下大课也将分别从“周 期”、“城市”和“资产”这三个关键 入手。

分成这三大主题篇章进行讲解：

1. 周期篇：经济周期波动与个体财富变迁 的关系

2. 城市篇：区域城市潜力与代际阶层流 的问题

3. 资产篇：个体特征与最优资产配置策略 我在每个主题下都设置了“理论 模型”、“市场工具”、“实践 案例”和“热点解析”四个层层递进 的模块：

理论-工具-实践三个模块中，我会逐 渐帮你将货币政策、经济周期这些艰深 的宏观经济，还原成“投资时点”的工 具；将城市化、地方政府这些宏大 的议题，还原成家庭“择城而 居”的决策；将风险定价、债券股 票这些眼花缭乱的金科术语， 还原成个体财富管理的具体 应用。

在最后一个热点模块，我会聚焦到现 实热点，比如“货币政策走向、资产 价格、国际局势”等，用前面三个模 块的知识点对当期市场焦点进行 分析，告诉你怎样打通宏观、中观、微观 的底层逻辑，将抽象的“宏观金融学理论”， 落 地到切实的“财富投资实践原则”。
