# 政府工作报告 = 《当年》中国宏观政策的信号灯

首先，我对政府工作报告有一个比喻，对于中国宏观的观察者来说，这份报告就相当于年度宏观经济政策的信号灯，红灯意味着紧缩，黄灯意味着中性，绿灯意味着放松。

比如说宽货币、宽财政就会让市面上资金比较多、项目变多，这对于企业经营者来说就意味着贷款项目也容易，银行放贷的意愿也更强，资金的成本在压力下降低，然后投资和借贷会出现相互承压，相互加强，刺激着市场升温，利好各种资产价格。

比如说你的房子、股票、债券，比如说你找工作，或者项目、融资难易程度，比如你放款的效率和、资金利率，甚至你平时感受到的生活用品的价格，都跟这个信号灯有关。

所以，即使是普通人如你我，如果能够清楚这个报告，给出了哪个颜色的信号灯，也能帮助我们在财富的保护战当中领先一步。

那如果你是金融圈人士或者企业家，真正读懂这个报告就能够提前对今年的资产配置、生产经营做出正确的决策。

# 我是怎么从报告里解读财富信号的？

但问题是，这个信号对于并不是像路口的那种灯那么明显，由于报告的意思是什么？都规定那么严，所以，很多意思，你光从字面上理解的话，就会觉得它太宽泛了，而且太谨慎、不听话的把你，所以，下面我就从专业的角度跟你讲讲我怎么从政府工作报告里解读出政策信号。

在刚才的课程里，我跟你说过，现代市场经济对经济的管理主要通过货币政策和财政政策来发力。

货币政策其实是供给端发力，调节水库的水量，调整货币、货币的投放量，主要是通过银行体系来实施的发力。

而财政政策是需求端的发力，调节田里的用水量，调整政府的财政支出的数量、项目的审批、统筹，主要是发改委、财政部各个部门来完成的发力。

弄清了这些概念以后，我用2015年到2019年这几年的政府工作报告，把货币政策和财政政策的表达作为例子，告诉你我是怎么来解读的。

从下表格中你会发现表达上有非常细微和微妙的差异。在我看来，这些差异才是辨明信号和颜色的关键。

| 2015 | 稳健的货币政策和宽松适度 |
| --- | --- |
| 2016 | 稳健的货币政策要松紧适度 |
| 2017 | 稳健的货币政策要松紧适度 |
| 2018 | 稳健的货币政策要松紧适度，保持货币政策稳中有调 |
| 2019 | 稳健的货币政策要松紧适度，满足经济运行保持在合理区间需要 |

货币政策看看两点：第一，看用词；第二，看每年的变化。

要看不是字的话，你会觉得，货币政策没啥不同，反正不是稳健就是中性，但是，注意一下用词的不同。

比如说2015年和2016年都是“稳健的货币政策”，但一个是“宽松适度”，一个是“松紧适度”，这就显示出不同了，即是2016年的灵活比2015年的调子就要偏松。

那同理，2018年是要求“稳健的货币政策”，保中性，2019年就是“松紧适度”，所以，2019年的调子比2018年要更松。

除了用词之外，变化的是变化项是非常非常重要的。还是2018和2019为例，你看他们的表述之中，2018年加了一句“”，可以“保持政策稳中有调”，而2019年把这句话说掉了，加上了另一句“”，叫“要满足经济运行保持在合理区间需要”。你自己念念三遍，体会一下。

我念了三遍，我的感觉是，2018年的表述在“稳”上，而2019则强调要满足需求，这是一个弹性很大的表述，为很多后续的政策都留下了空间。热乎乎的，那么现在在明白了一点。

所以，在我读来，2019年的货币政策是偏宽松的，这个信号灯的变黄色也是绿色信号。2018年底的各项数据就显示已经有迹象。我之前的课程里面都给你做过讲解。

但是，今年的《政府工作报告》的这个基调相当于上整体货币货币政策的一个基调，除非中间有什么大变量。所以，我认为今年资金的放量相对地充足。

# 2. 财政政策

再跟着几年的工作报告看下来，你会发现财政的表述上，每个年都是“积极的财政政策”，到底啥意思啊？

确实，要读懂财政政策是最难的，市面上其实我也没看到过特别中肯的专业的解读。我综合了两位我最喜欢的中美宏观经济学者，社科院张斌教授和北京大学徐连的教授给我的思路总结出了两个要点和一条原则。

+   两个要点

第一，过去五年，“积极”确实是中国财政政策的定调，积极的字数一直在逐步提高，只是每年“积极”的程度不太一样。所以，在这个词是替换中，中国的财政政策不说是激进或者不是踩油门的区别，不是转向的问题。

第二，在这个语境下，“积极”有各种意义，这有点像年夜饭？平时会跟你客气，下次来我家吃饭吧，但是，具体的时间和地点就不细说，因为接下来的发可以有很多中可能性。

这是在读报告的时候对财政政策要掌握的三个要点。

然后再来，怎么具体辨明信号的，这个原则：“积极”这个词没有太大的实际含义了，那信号要点怎么辨别呢？

一个原则：要看财政支出和财政赤字率的增幅。

嘴上说积极没用，要看具体做，因为这个积极打多少成，形象点说，就是政府打算开足多少火力，做多少功课，做多少，所以，在这个原则下，我读这几年的报告里面边关于财政的描述也作了归纳了。

比如说，从2015年到2016年，赤字率要从2.3%增加到3%，而且，这个赤字水平维持了两年，然而在2018又降到2.6%。

很明显了，过去几年虽然都是积极财政，但是，2016年是最积极的，2018年是踩了半程的油门。这种大家对经济的实际感受是不是也一样的？2016年是不是我的小阳春，而2018年是冷风嗖嗖地吹。

我再来看看大家最关心的2019年，赤字率从2.6%提高到2.8%，财政赤字从2.03万亿增加到2.3万亿。这组数字比较好玩。你可以得到两个推论：

1. 2019年的财政政策要比2018年宽松，不管是赤字率还是财政支出都是往宽里面走。

2. 你看赤字率2.8%还没有达到2016年和2017年的水平呢，综合下来，如果2018年算是就搞黄灯的话，那不算，2019年以偏绿色，但是，还算不上特别亮的绿灯。

掌握了这些知识以后，你再来看政府工作报告，就会发现，厚厚的一层报告变薄了。

我读起来，2019年宏观政策的信号灯颜色是非常积极的，货币给出的偏松的淡绿色信号，而财政比较中性，而货币的淡绿色，财政的积极态度显比得略微或者说不够积极。

知道了信号灯的顏色之后，根据前面课程的很多颜色，你就可以得到一些有用的推论了。

推论一：如果货币和财政政策同步的话，那它们就有一个相互加强的效果。
