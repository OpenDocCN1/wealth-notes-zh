为汇率操纵国的认定的。

# 3. 这件事会对中国产生什么影响？

现在你明白了，美国这次将中国列为汇率操纵国，既缺乏事实基础，也没有得到国际国内的支持和认定。

但是，一旦被美国列为汇率操纵国，美国是可以对于这个国家采取一定的制裁措施的，主要是四条：

+   第一，禁止海外私人投资公司批准对该国的融资，包括保险、再保险和担保；

+   第二，禁止联邦政府采购或者订购来源于该国的货币或者服务采购合同；

+   第三是指示美国的IMF的审查发起对该国宏观汇率政策的额外审查；

+   第四是指示美国贸易代表办公室与财政部磋商，考虑是否与该国签订双边或者区域贸易协定，或者发起相关裁判。

那么这些措施对我们国家的具体影响会在什么地方呢？

你仔细分析一下就知道了，现在中美经贸摩擦已经进入白热化的阶段了，所以，第一条、第二条已经不存在什么实质性的威胁了，关税加了，华为还有相关的企业也加入了实体名单，说白了就是死猪不怕开水烫了，都这样了，你还能怎样呢？而且，第三条也很难实现，因为IMF已经公开地不支持美国的汇率操纵认定。第四条，可能的成为特朗普的抓手，然后利用这一条把经贸摩擦进一步升级。

但是，话说回来，在全球一体化和多边主义的趋势下，所有国家的利益是一荣俱荣，一损俱损的，中美掰手腕，很多池鱼会遭殃。你看，最近很多投行就开始发言说，认为中美冲突可能会导致全球性的萧条。

所以，换句话说，截至今天为止，被列为汇率操纵国对中国的影响实际影响是不大的，但是，由于它可能成为特朗普进一步升级冲突的抓手，所以，引起了比较大的市场情绪反应。你看，全球的 markets 大跌，避险资产黄金的价格猛翻，而这些短期的情绪波动都是会反映在短期资产价格里面。

但是，实际上它对汇率的直接影响并没有那么大，人民币既不会因为被称为汇率操纵国而贬值，以后也不会因为这个指标取消而升值。还是那句话，人民币的价值是人民币汇率真正的矛，而人民币汇率真正的决定性因素仍然是中国经济增长的韧性和潜力。

所以，归结到底一句话，干好我们国内的事情是最重要的。

# 总结

+   1. 人民币兑美元的汇率取决于两国基本面以及全球经济的相对状况。在正常情况下，人民币不会大幅贬值。

2. 汇率操纵是一种不公平的贸易竞争手段，可能会引起全球范围内的贸易或货币秩序失衡，从而遭受他国的报复和国际社会的反弹。

3. 中国被美国指责为汇率操纵国的理由是不充分的，从美国国内到国际都不支持这种认定。

4. 目前被列为汇率操纵国，对中国的经济基本面没有实际的影响，但是会引起市场短期波动。
