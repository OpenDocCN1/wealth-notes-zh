# 一、股票交易所: 重塑国家开放形象的需要

现在我们都会觉得“股票可以交易”是天地地义的。但在三十年前, 从“设想”到“股票交易”, 这三个字的演进过程比你想的要困难和漫长得多。比如当1994年和1985年的上海, 上海的飞乐音响和延中公司都分别发行了股票, 当时有很多上海市民认购了。但是在这些股票交易上没有交易场所的, 所以一年之后, 很多人在上海交易所发现, 当年的这些想象当中的“活投资”变成了“死植物”, 根本没有市场。我看了一下当时上海老百姓的自助, 股民拿股票不能卖, 就像当女儿嫁不出去, 有了儿子不能娶媳妇, 一个子就悬在手里。随着时间的推移, 这个矛盾就越来越深, 但是一直没有很好的解决办法。

直到有一个事件出现, 1986年的时候, 中美关系出现了重大的进展, 在年的时候, 包括纽交所董事长在内的华尔街一行20人到中国进行了一场非常高级别的交流, 甚至涉及到刘小骥的操作。当时为了加强和美方友好的筹码, 作为金融中心的上海就需要有一些拿得出手的内容。那么, 所谓交易所一定要是一个非常重要的机构, 所以就在当时的上海市长的督促下, 第一个股票交易的柜台就正式被设立起来了。那时候开始, 中国的股票交易就开始流动了。

但是, 从股票交易所柜台到股票交易所, 中间我们又花了4年的时间, 这一次大手笔的“试水”和上一次一样, 仍然不是一个市场需求驱动, 而是和国家当时的政治需求是一致的。

90年代初, 我们需要重塑改革开放的国际形象, 所以中国需要做出了一系列的国际动作。1990年春天, 时任上海市委书记的朱镕基在外访, 他在香港就公开表示, 上海证券交易所将于1990年底正式建立, 这个举动就反映了国际媒体极大的正面影响, 认为这“标志着中国经济改革的自标不会变”。在这样的背景下, 上海交易所只经过了大半年的筹备时间, 1990年底就正式成立了。第一批上市的股票只有8只, 俗称“老八股”。

所以说, 中国股票交易所的启动, 和我们看到的欧美股票交易所的启动是完全不一样的, 我们是出于国家的需求自上而下推动的。

# 二、1992年股份制改革: 14大的巨大转折

尽管1990年上交所和深交所都先后开业, 但是其实一直到1992年的时候, 资本市场的进展非常缓慢, 可交易的股票一共就50多只, 实不足谈不是一个成型的市场。但是, 在接下来的几年里, 中国的资本市场经历了原本非常快速的发展, 而这一次的发展和原来一样, 又是和国家需求联系在一起的。

这个时期在市场的压力下, 机制僵化的国营企业普遍亏损严重, 以前有大笔的坏账堆积在国有银行的资产负债表上, 中国的金融和工体系共同面临着“借台高筑”的状况, 吸收长期的廉价资金, 为国有企业输血的这个要求就被提上了议事日程。

那么来吸收股价的长期资金呢? 股价交易无疑是最佳选择。但彼时, 绝大多数企业都是完完全全的股份制改造, 产权不清晰, 股价的融资和交易都不实现的。

1992年, 小平的南巡对这种转型形态做出了巨大的贡献。之后, 党的十四大就提出了要建设社会主义市场经济体制, 确立了私营企业合法的合法地位。在80年代, 我们对“产权”进行了重新认识之后, 90年代初, 对于“私有产权”开始了重新认识的过程。这次重新认识是以“股份”和“投资”为切口的。

到1992年的时候, 我们成立了三个证券交易所, 华, 国, 南。之后股权成为当时社会最时髦的词汇。全国, 尤其是深圳和上海, 陷入了全民的“炒股”之中。中国的企业家在这个候敏锐地意识到, 这是一种利益共享, 风险共担的融资模式。

这一年, 辞职下海的公务员超过了12万人, 包括小平、潘石屹在内的“万通六君子”, 都在这个时候发起的。

在上一节课程里面, 我们给你们讲过的乡镇企业、集体所有制企业, 这个时候都开始进行了更加彻底的股份制度改造, 转型成了私营企业。像万达、美的等一大批我们熟悉的明星企业, 都是这次改制的产物。

另外, 全国出现了前所未有的办公司热潮, 像深圳那样的国际交易中, 大楼内, 一层楼里面就挤着300多家公司, 珠三角出现了大大小小的私营企业, 全国各地的农民都开始了打工人。这样以股份制为契机, 揭开了“Made in China”的序幕。

所以, 如果我们打开很多细微细节, 从大格局上看的话, 1992年的这次变化是世界进入中国历史的几个转折点, 这次转折被称为很多人经常说有什么不一样呢? 在中国这么一个漫长的历史上, 中国政府第一次尝试着从财政计划转向金融管理。也就是说中国政府第一次学会了用金融工具作为国家治理的工具。

其实有时候, 你在历史的细节里可以抓到这种端倪, 比如潘石屹在90年的上就说过, 他觉, 上海金融区, 想对财政突破口, 没有看到, 所以希望国有企业大力的进行股份制改革, 发展资本市, 然后和金融上找到突破口。

所以说, 股份制已经在中国基本上生根发芽了, 而中国的资本市场以一种非常奇特的方式开始了它漫长的跋涉之路。

从乡镇企业、集体所有制企业, 到国有企业股份制改造, 中国的资本市到第一步形成, 然后一步一步地侵蚀了计划经济的“垒垒”, 改变中国社会的面貌, 包括所有人的认知。

所以你会看到, 中国股份制的演化, 资本市场的演化, 并不是主流经济学中所说的那样, 是一种经济自然演化的姿态。它每次的路径都是非经济和主导的。而是根植当时的时代背景, 被政治目标驱动, 这种驱动也使得中国资本市场形成了非常独特的逻辑。

中国资本市场经历了这有几个阶段, 八十年代, 股份制萌芽; 九十年代, 资本市起步; 在九十年代中后期的, 在国家政策的推动下, 中国资本市场进入了一个高速发展的高涨。正是因为这些资本的历史沿革和历史使命, 中国的资本市场形成了一种非常独特的生命力勃, 但是充满曲折的特点。而这种曲折, 一直直到世纪初获得了一次修正的机会, 这就是下节我要跟你讲的中国资本市场的股权分置改革。

# 今日摘要:

# — 划重点

+   1. 一般来说, 市场是从底层演化, 逐渐自然形成的。但是中国资本市场的形成走了一条和其他国家不太同的路, 它是从顶层设计开始, 自上而下推进的;

2. 中国股票交易所的启动是出于塑造国家开放形象的需要。在这样的背景下, 上海证券交易所于1990年就“匆忙”成立了;

3. 九十年代对国有企业大力地进行股份制改革, 对私有产权进行重新认识, 也是自上而下驱动。为解决国有企业普遍亏损问题, 政府必须以股权和资本为切口。
