和“坑”

讲到这里的时候，你会发现，这节课我们“一波三折”。

首先说要是市盈率低的股票，接着又告诉你们市盈率高的反而可能是划算的，然后又说，超高的市盈率意味着着未来，最后还说，超高的市盈率不可能有泡沫。

为什么是这样子呢？其实这就牵涉到市盈率的计算里面的一个重大问题。

市盈率计算中最大的难点，就是对盈利的增长，也就是分母的计算。如果一个企业能够持续地维持高盈利增长，像茅台、苹果，市盈率高一点，没关系。但如果这种高增长维持不了，或者盈利实现不了，高市盈率可能就是 “海市屋楼”。

比如像京东，它至今的市盈率维持着高位，是因为没有什么盈利。如果京东未来真正赚钱了，市盈率就会慢慢降下来。如果它始终不盈利，可能就是一个泡沫。

归结起来，市盈率是一个非常简单，而且容易看、容易操作的选股指标，是一个最流行的相对估值方法。

再跟你强调一下，用市盈率来做估值的几个原则：

+   1. 在其它条件都一样的情况下，尤其是盈利增速相当的情况下，选市盈率比较低的股票；
2. 如果一个企业的盈利增长特别快，市盈率高一点没有关系；
3. 回避过高的市盈率。

第三条是一个属于我个人投资原则。什么叫过高呢？要考虑这个行业和当时的市场环境。但是无论如何，200、300倍的市盈率对我而言是太高了。无论如何，我会等它降下来再说。

你看，巴菲特之前怎么也舍不得苹果，尽管被人讽刺说他已经落于时代了，但他一直要等到苹果的市盈率下降以后才买。所以，我觉得这也是投资里面很重要的一个原则——你看不懂的机会永远不叫“错失的机会”。

最后还是要给你强调一点，市盈率是一个非常好用的指标，但是市盈率里面也有很多坑：

+   1. 市盈率的分母是利润，但是利润这个财务数据是会比较容易被操纵的，所以会导致市盈率失真；
2. 当公司的利润会为负，市盈率就会失去意义；
3. 有时候一个行业的市盈率方差也很大，用平均市盈率来判断高者或低值难免偏颇；
4. 在不同的历史时期，整个市场氛围也可能对市盈率造成成功影响，比如牛市市中我们知道，市盈率就会普遍地偏高，熊市市中市盈率则会普遍地偏低。

所以再次地告诉你，任何一个指标，咱们都不要孤立地使用，投资是一门艺术，任何数字都只只是给你一个参考的标准。

# 今日概要：

+   - 划重点

+   1. 从概念和公式上讲，市盈率就是投资的回本时间，市盈率越低，回本的时间越短。
2. 我们经常发现市盈率高的股票更赚钱，是因为市盈率代表着市场的看好程度。
3. 到底应该选市盈率高，还是市盈率低的股票，要具体情况具体分析。
