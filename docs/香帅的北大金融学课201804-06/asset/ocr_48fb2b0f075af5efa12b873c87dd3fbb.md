# 077 | 欠债不一定还钱
——债务违约的必要性



你好，欢迎来到睿哲的北大金融课。

如果你问欠债是不是不一定要还钱呢？你会不会感到有点惊讶，这是我们一般人的认知中，欠债还钱是天经地义的事情。但是绝大多数人没有意识到的是，欠债不还（债务违约），也是债务关系相伴而生的。恰恰是债务违约的存在保证了债 务市场的正常运行，这就能够维系生死一样的正常新陈代谢，就像动物界的老死 病残，另有新陈代谢才能保持生态的延续。另外，赦免债务，也就是债务重组，是解决复杂危机的重要方法，也是一个让社会成本更低的策略。

# 一、没有违约的债务市场不能存在

下面我们首先来看看为什么 债务违约是债务存在的所有必要条件？首先，一个没有违约的市场是从世界上金融的“风险——收益的均衡”上，从理论上来说是对整个 风险是不存在的。因为债务的利息包括两个部分，一部分是资金的利息部分，另 一部分就是债权人，也是说借给你的个人，承担者被赖账的可能性及违约风险而要求 的补偿。这个风险越高，要求的补偿就越多。

所以说如果所有的债券百分之百都确定会得到清偿，也就是完全没有什么违约风险的话，债权人（资本）从持有人中无息地 按时、依约，债务人才会增加无限制 的 低成本的资金，这样一些其他的融资工具和融资方法也就没有什么存在的必要了。金融市场最后会变成 一个规模有限的债务市场。那很明显，在现实生活中这是不存在的。

除了违背这个“风险—收益均衡”的原则之外，缺乏违约的债券市场还会产生一个很大的问题，叫做道德风险。

咱们中国的市场上有一个你很熟悉的 词语，叫“刚性兑付”（刚兑），说的就是 为了避免债务企业的破产，政府会出手买 盘，强行将原本应发生的违约事件化解掉，也就是说政府人为地将违约的风险降到零。我们就知道金融的收益率跟违约风险 是正相关的，违约风险越低，要求的收益也就越低，现在违约风险被人为的化解 了，那么“风险—收益均衡”的价格信号就消失了，就会造成市场的扭曲。

上个世纪90年代的时候，咱们国家有很多有企业破产的次级债，因为它们都有政府兜底，没有破产的压力，所以就是全然不顾自己偿付能力而拼命地借款。而另一方 面，这些债券的投资者主要是国内银行，因为有政府兜底，它们也不关心违约风险，就认购了大量 根本没有偿付能力的债券，让银行的资产质量变得越来越差。这种 情况后来就演变成流弊，导致了银行坏账率超高，整个社会的债务关系非常 的恶化，最后政府被迫让金融体系休 整关闭，直到2000年以后才重新启用。

# 二、赦免债务（债务重组）是社 会成本更低的策略

现在你已经明白了，和自然界的代谢新陈代谢一样，债务违约其实是债券关系存 在的必要条件，没有违约的市场就像没有死亡的生物一样，很难想象一个不良的生态。可能现在，在想象，我们是不是应该让那些违约的企业或者违约的国家破产，进行债务清算？我们考虑的这个地方也会更加健康呢？答案是：不一定，在现代世界里，你会发现有很多时候赦免债务或者债务重组，是一个社会成本更低的策略。

比如说欧洲央行对希腊政府的救助 就是一个特好的例子。2009年政府，希腊 政府就宣布当年的财政赤字占GDP的 比例已经超过了12%，远高欧盟建议3%的上限，面临债务危机，远居欧压位，然后希腊的国债价格开始暴跌，面临着主权债 券违约的风险。刚开始的时候和很多市场 教育主义的想法一样，欧元区成员国坚决 推动希腊削减开支，无条件的威胁希 腊必须从经济内部解决来应对 经济危 机，而且还会引发本国纳税人的不满，所以救助计划就迟迟不能出台，希腊在债务危机里越陷越深，紧接着葡萄牙、西班牙也 都爆发出财政问题，接着一个很健康的德国和法 国也受到了拖累，一场新的金融 危机看上去马上就要在欧洲全面爆发 了。

这个时候欧洲央行和欧元区各成员国就 开始采取了紧急的救助措施，其 中最重要的措施就是把希腊的国债 减免了50%，相当于让步希腊政府躲过了1000亿欧元的债务。 那为什么减免希腊的国债呢？因为这是希腊 欧元区最大的主权债务方。欧元区各主要成员 的国家债务，经济依赖度是非常高的， 可牵一发而动全身，当时的希腊的债务危机已经影响 了国际社会对欧元区的态度。所以如果放任 下去，蔓延到希腊一路的神级债务危机也 会蔓延，最终所有的损失是巨大的不可估 计，所以让希腊赖账是而愿意承担巨额 损失是成本相对比较低的一个策略。

我在北大讲“公司金融”的课上，会用一个小例子说明为什么允许债务人欠债不还，可能是一个对双方有利的相较择的改造。比如说一个公司有1亿元的债务，从种种 对这个公司价值判断的客观指标来看下 的，能有的价值则 5000万元。但是 这个公司， 债务有50%的概率 能够赚1.5个 亿。好了，这个时候公司的债权人就有 两种选择：第一种选择直接去起诉它，让 这个企业破产清算，然后债权人拿到 它 账上剩下的5000万元，第二种选择就比较 复杂一些：债务人争取，比如把原来的一个亿的 债务降低到7000万，同时进 行债务重组，用更低利率的新债 来偿还老债 的债务，然后重组 经营。

那么哪种方法好？我们进行一个简单的 计算后，你就会发现，在第一种方案 中 债权人手中的最大金额是 5000万，在 第二种方案中债权人得到的是7000万， 也就是50%的概率拿到 1.5亿 的收入。是7500万，然后债务人又拿到剩下的5000万。很显然，第二种方案对债权人进行债务重组是对双方更有利的选择，也就是 所谓的帕累托改进。

这当然是简化了的例子，但是在现实世界中，你是能观察到像债务企业、政府、国家中最常见的金融行为。比如这几年中国在 自己的地方政府上采取了债务重组的 做法，以低息的新债 来置换那些高息 的旧债，实际上就是允许债务失信重组的 地方政府转嫁给双 方，它们负担 反复 的。
