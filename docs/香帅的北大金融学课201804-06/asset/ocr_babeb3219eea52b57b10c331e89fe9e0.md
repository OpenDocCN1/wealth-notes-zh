# **一、两种估值方法：绝对估值和相对估值**

首先简单回顾一下，市场上流行的投资原则。大家都知道，投资原则就是要求“低买高卖”，也就是说我们必须要用最低的价格买入，最高价卖出。这个标准就是绝对价值，所谓绝对价值，就是可以低于价值的价格买入，高于价值的价格卖出。

那价值怎么估算呢？在咱们金融市场上，估值的方法是很多的，你是听单绝对估值法，一种是相对估值法。

对于这两种估值法，纽约大学有一位著名的金融学者，他说绝对估值法有两种非常简单的总结，他说：绝对估值是一种专注于内在价值的估量方法，一项资产的内在价值是什么？就是这个资产在生命周期里所产生的预期现金流，还有这些现金流的确定性。

如说，两个债券，一个有长期稳定的债券，租期很长。另一个一个，长空置的资金收入很低。两相比较下来，前者，价值明显地更高或者是更高。这就是我们平时所说的，一个拥有高而稳定的收益的资产，具有更高的内在价值，这就是绝对估值，也是估值法，是内在价值。
