# 096 | 金融市场的“暗器”：金融衍生品

香帅

你好，欢迎来到香帅的北大金融学课。

在前面的几周课程里，我们讲了股票和债券这两个最基础的金融工具。其实，在这个领域里，股票和债券就像什么呢？就像刀和剑，它们是最基础的武器。

那么还有一种金融工具是什么呢？叫做金融衍生品。金融衍生品在金融江湖里的地位，就像江湖里的暗器一样，用的人很多，评价却是呈现一个两极化的趋势。

一方面，很多经济的诺贝尔奖得主都认为衍生品是金融创新最重要的创新。事实上也确实如此，到2017年的时候，全球金融衍生品的交易量已经是股票交易量的十多倍。品种也涵盖了大宗商品：外汇、国债、利率，几乎所有的金融衍生品，衍生商品，基本都大量使用金融的衍生品基金中自己的投资领域。

但另一方面，金融衍生品仍不被金融圈认可为“主流”，每次经济危机的时候，它都会被推到风口浪尖上，被当作靶。比如2003年，巴菲特就公开宣称，金融衍生品工具是金融界的大规模杀伤性武器。2015年，我们国家发生了股灾，首批冲锋杀出来“救市”的也是衍生品工具，股指期货。

那么金融衍生品到底是什么？为什么会在短短的几十年内席卷金融业，又为什么会遭遇到这么多的非议和质疑呢？在接下来的两讲里，我要让你从衍生品本质和特征出发，给你讲衍生品天使和魔鬼的两张面孔。

很多同学会对“金融衍生品”这个感到很陌生，但是大多数听过“期货”这个名词，比如A股股民中很多都炒过股指期货，还有2017年初看片引起很多大爷大妈讨论的大宗商品的期货。期货其实就是最为基础的金融衍生品之一。今天，我们就从最热门的、看清楚了什么是衍生品，到底又有什么用。

## 一、衍生品：实现风险的转移、再分配的金融工具

首先我们来看看什么是衍生品。

期货（Future）和另外一个衍生品，远期（Forward）联系在一起。但是这些名字听上去都挺抽象。要想理解这些概念，我先给你讲一个案例。

日本德川幕府（17世纪）的时期，日本的大米就可以用来投资。当时日本的大米都会运往大阪，大阪的边上有一个小镇叫堂岛，大米的商人都到发达到，很早形成了类似今天的金融市场。但是大米价格波动很大，在青黄不接的时候，米价可能会狂飙，到收获的时候，米价又会狂跌。不管是米商还是农民，都面临着很大的价格波动的风险。

为了锁定这种价格的波动，米商和农民就会事先去约定，在未来某个时间，用某一个固定的价格来交一定数量的大米，比如说定在一包大米是5两银子，米商和农民约定，三个月以后，用5两2钱银子一包的价格从农民手里收获50包大米。这么一份合约，就是一份“远期”（Forward）合约。“5两银子”在这个合同里就是“现货价格”，也就是现在的价格；“5两2钱银子”这个价格，也是三个月以后的未来价格。“三个月”这个期限又叫“远期期限”。这个合约的价值会随着什么变化呢？它会随着大米价格的而变化而变化，所以它就是一个远期的合约。那么这个“远期合约”就是大米的衍生品，这就是衍生品的来历。

签了这个合约以后，米商和农民双方都有好处。你看，即便未来三个月，米价像坐了过山车一样地起起落落，农民和米商都可以按照之前的约定交易。换句话说，远期合约通过锁定价格的波动，实现了风险的转移和再分配。

这就像是跷跷板，这个合约维持了跷跷板的平衡，不让任何一方因为承受过重的压力而落入到风险陷阱里。而“远期合约”其实就是历史上的第一种衍生品，它解决了价格波动的风险问题。

但是，这时候另外一个问题又出现了：因为是期合同是定制化的，也就是说根据难易度大的需求来定价的。一方面，遇到风险会比较小；另一方面，因为是一一对应。你根据买卖双方需求来谈好的，所以约定的合同，对方的需求合同会比较困难。用我们金融术语来说，就是这种合同“流动性不好”，很难产生一个很大的二级市场。

不管是做套期保值交易，还是做投机套利交易，像期货这样的衍生品的价格，它最大的好处是什么呢？它交易的是某种商品的未来价格，所以这种价格会汇聚人们对未来某个商品的信息和判断，而且市场的流动性越好，也就是换手得越多，汇集的信息也就越多，就越能够正确地反映基础资产。比如说大米未来的供求关系和价格趋势，这就是期货的价格发现功能。通过这种价格发现功能，期货市场能够掌握一个商品的定价权，石油、铁矿石，这些大宗商品的价格都是在期货市场上决定的。

但是直到上个世纪的七十年代，期货还主要局限在商品领域，包括农产品和工业品。主流的金融圈，尤其是华尔街，对于这种包括期货在内的衍生品交易毫不关心。

但是没有预料到的是，在七十年代以后的十年间，一场对“基础资产”的革命创造了一个特别庞大，而且复杂的金融衍生品市场。这个金融世界的新物种，将会改变人们对商品的认知，也会改变全球资产管理的格局，也引发了金融市场最针锋相对的观点。这些期货，我在下面的课程里还会跟你一一再讨论。

## 划重点

+ 1. 金融衍生品是一种合约，它用于置换交易的期限，锁定价格波动，实现风险的转移和再分配。所以它具有风险分担和价格发现等功能；
+ 2. 标准化的远期合约就是期货合约，这两者都是最基础的金融衍生品。

昨天的课程里，我想带你看到，金融衍生品的交易，其实比我们想象的要大得多。从21世纪初开始，衍生品的交易已经是债券和股票交易量的十几倍，甚至十几倍，没有哪个大的金融机构不使用衍生品，包括我们的八大行。更重要的是，衍生品的产品覆盖了几乎所有你想要得到和不能想象标品。原油、黄金、利率、债券、债务，甚至是飓风、地震、碳排放、水污染、换句话说，其实只要有风险，就会有风险，只要有风险，就可以用它作衍生品交易，对冲。这是衍生品一个核心的特征。

但很多人是没有意识到的，就是这个概念，其实已经触及了金融最核心的本质。

现在我们继续讲第一课跟你讲过，金融的本质是人们对概率不确定性的工具，及相关的制度安排。你再想一想我们人类交易的历史，我们从实物交易开始，比如买一个苹果，买双鞋，然后再发展到交易交换，做贸易，债券，最后发展到交易“不确定性”本身，这就是衍生品交易。

这个过程是一个你身处的交易的金融不断深化的过程，其实大家的认知不断提升的一个过程。但是，这个过程不是一蹴而就的，可以分别那来说给你看。我们从人类认知升级到那一刻，而这个故事要从芝加哥的商业交易所开始说起。

## 一、从“商品期货”到“金融期货”的 第一步：对冲波动

六十年代以后，美国对农产品采取了一定价格管制，农产品的价格非常低迷，就农产品期货的交易也变得越来越低迷。芝加哥商业交易所作为一个产品的交易所，就面临着极大的生存压力，他们需要不断地推出新的产品和新的合约来吸引客户。

在这个过程中，芝加哥商业交易所又出了一个伟大的领导者，他的名字就叫做梅德维拉利。利奥梅德维拉这个人就太不同凡响了，他非常具有商业天赋，在帮助交易所崛起的过程中间，他冲着一个想法，就是这个时期是用美元对所有的，在风险最多的市场上就应该是期货运用最广的市场。

那么市场上风险最高呢？毫无疑问，就是金融市场。所以从那时起，梅德维拉就一直想要看看能不能够引入到金融的领域里面去。这个机会，一直等到了七十年代初。

在前面的课程里面我讲过，战后全世界国家采取的布雷顿森林体系，也就是固定汇率体系，美元盯住黄金，然后其它的货币盯住美元，一个是固定的汇率制度，到了六七、七十年代，各国的经济发展就变得越来越不平衡，所以固定汇率制定就没办法维持下去了，固定汇率维持不下去，汇率的市场、外汇的市场就开始出现大的波动。换句话说，也就是当时对外汇风险的渴求就大大的增加了。

因为为前面经过了那么久的固定汇率制度，所以市场上缺乏有效的对冲工具，尤其对于个人和机构来说，完全没有办法有效地来对冲自己面临的外汇风险。

这个期间还发生了一件很有趣的小事，大名鼎鼎的货币专家、芝加哥大学的罗伯特·曼瑟斯教授，是浮动汇率最伟大的支持者，一直批评固定汇率制度。七十年代初的时候，他预测英镑会贬值，他就像去做英雄，结果英镑给他拒绝了，这件事被当地的一家报纸知道了，然后进行了大肆渲染，说：著名的货币专家想做空头而不得。

结果这篇文章被他两位才谈到的利奥·梅德维拉给看见了，他就敏锐地意识到，这是一个干笔赚机会，他马上找到了弗里德曼，跟他谈这个，说，浮动汇率时代，推出货币期货的必要性，然后希望弗里德曼能够从学术的角度对这种创新交易进行加持。

你可能会很好奇，为什么梅德维拉要去找弗里德曼呢？因为芝加哥商业交易所，当时在整个商品里是一个非常边缘化的小交易所。按照梅德维拉的说法，我是一个无名之辈，而弗里德曼的学识不一样，他当时自由主义经济学派的创始人，他的很多同事、朋友都占据着美国的财政部、美联储等重要的岗位，也就是说是说一个一言九鼎的人物，他如果会支持这么一个创新的概念能够推到弗里德曼的加持，这就是对如虎添翼的事情。

梅德维拉见到弗里德曼，他非常重视，弗里德曼没有想到，货币期货是一个他早就想过的创新，他就是想去查整这种创新金融工具，但是为了彰显自己是一个“资本主义者”，他还要在梅德维拉为此付5000美金的报酬给他，梅德维拉也说，这是金融的发展历史上最值钱的一笔投资，一笔5000美金的报酬促使了一个高达60亿美元的市场的出现。
