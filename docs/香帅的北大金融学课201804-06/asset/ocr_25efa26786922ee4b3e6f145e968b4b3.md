# 复盘 | 股与债到底有什么不同？

你好，欢迎来到老师的大金融微课堂。
昨天我们以基点为切口，把金融机构这个
大板块给我们梳理了一次。今天我们要再
稍微地理清楚和债这两个小模块。

# 一、投资者视角：股与债

首先我们来站在一个普通的投资者视角。
你想投资一个公司的时候，你可以买
公司股票，也可以买债券。那么在这种两
种投资中间，你的权利会有什么不同呢？

第一个不同：债券债权和风险是不一样的。
不管是股票还是债券，它代表的都是金融
索取权。也就是说你对这个公司盈利所取
的权利。不同的是，股票你所拥有的是
"剩余索取权"，就是公司要扣除所有的
成本，包括利息，剩下的部分才会给你
分红。而且这种分红是不具备强制力的。
所以你为了补偿你，公司要给你股权，你
可以参与它的经营管理决策，虽然你也
知道在现实中这种投票权并没有实质性
的意义。

那么从另外一个维度看，与股票的"剩余
索取权"是不一样的，债券具有的是"优先
追索权"。不管企业经营的好坏，它必须按
时间点给你带来利息，所以这种收益
是固定的。而如果企业面临破产的话，
你的债权比公司的债权的等级，首先要
清偿。因为你可以确定的回报，所以债券
的收益率会比较平缓。

因为有这些特性，所以一般认为，和股
票相比，债券是风险和收益的结构是比
较低的。但这也反映了投资者和债权者
的心态上。当你作为投资者投资的时候，
就会关心公司经营的稳定性，而债券投
者更关心公司经营的稳定性。这两种心态
会反映在股票和债权的博弈上，形成了
公司的股东、债权人的博弈。我们在后面
的课程里还要再跟你们。

但是你也要记住，这个风险和收益的对
比是针对同一个公司而言的，比如说就
用股票和债券去做比较，这就没有可
比性。

好，这是在投资者的视角来比较股和
债对你而言有什么不同。

# 二、融资者视角：股与债

从融资者的角度看，股和债又会有什么
不同呢？

第二个不同：从融资者的角度来说，股
和债权人的权利是完全不一样的。
股东和自己是拴在一条船上的妈仔，分
享的是上行利益，分担的是下行风险。
而债权人不一样，他跟你不一定是同一条
船的。他有时候可能像加重的下风。
所以，融资者可以选择债权融资的资
的时候，心态是截然不同的。

一般来说，假设这个融资人，他的手里
的项目业绩非常地稳定，盈利能力。那么
他从融资的角度来说，自然不希望有人多
分自己一瓢羹，所以进行债权融资的愿
望会更高。反之，一个项目虽然前景很
好，但是不赔，风险不确定且非常
大。这个时候，融资者肯定尽量避免被
追偿的利息压力，也会尽量避免选择权
融资。

所以你稍微地关注一下市场上的企业就
会知道，像中创板企业会去选择债权融资。
而像小贷行业、高科技这些现金流不
那么稳定的行业，企业的负债率也是普遍
比较高的。所以像公用事业这些现金流稳
定，上分空间也不太大的行业，往往更
多地使用债权融资。

刚才我跟你讲的是一些一般性的原则。但
是还是要你知道，现实世界里永远比那些
简单的复杂的多。比如现实中希望公司
和投资者中间也存在着博弈关系。比如
一个表现公司风险了，要
破不。现在我们换一个风险高的项目，赢
了就能起死回生，输了大不了还是破
产，反正是"有限资产"，股东的个人风险和
公司资产之间有责任的关联的。在这种
情况下，公司就会倾向于高风险的投资。
所以你看前面也经常提到，高风险的股
权和高风险的投资往往是混在一块的。

这就告诉你，到底是债权融资还是股权
融资，虽然有一些一般性的原则，但是一
定要把它案例放在具体环境下具体分析。
也就是说银行的一道重要工作"财资顾
问"，也是替企业做调研分析，决定它
们该采取什么样的融资方式。

# 三、股和债之间的联系是什么？

刚才你从融资者和投资者的角度理解了
股和债的使用。你看，这些观察和经验都
是基于微观表的，或者你注意这些讨
论时，我们都把股和债当作"现实交易中
的工具，股和债在这里是一种平行的关
系。这个角度当然没有错，经典的金融
教科书也是这么讲的。如果我们换一
个维度来考虑问题，可能就会有一些
不同的思考。

要理解股和债中间到底是什么关系，我们
可以先问自己一个问题：什么是金融证券
市场？这个市场上交易的到底是什么？
我给你的答案是：金融市场是一个关于
各种"债务关系"的市场。在这个市场
上，抽象的、虚拟的债务关系就具象化
为各种价格和数字来进行交易。

为什么？你想一下，股票也好，债券也
好，这些凭证形态上就一张纸，在电
子化时代，甚至是计算机存储的一个
代码，不是的。我们所说的交易就是这些代
码所表示的索取权和债务关系，而
这些索取权和债务关系是可以被量化的
责任。

好，明白了这一点以后，你再看看"债"
这个字，你会觉得很很有意思了。"债"这个
字是单人间旁加责。就是表示责任和义务。
在广义上，债是凡可以被量化和量化的
责任，所以有金融活动都可以理解为
"借贷"行为，它总是涉及到索取权和
义务。从根本上，你也可以把债权理解为
一种"债务关系"，只是债权的种关系并
包括债权，它包含所有经济权利。一般
一句话，在股这个特殊的债务关系中，"债"
权"变成了"产权"。

最后，为了更好地理解这个结构模
式，我给你画了一个融资模式的图。
我们可以根据资金流的来源融资，分为
融贷融资和债权融资。所谓
债权融资是通过银行机构借贷，直接通
过投资者手里吸收收息，这是借贷资金的
来源划分。

另一种，就是根据融资中双方的权利
和义务来分，分为债权融资和权益融资。
股权融资的契约就是股票，债权融资分为
两种：一种是银行贷款，一种是债券。

# 今日概要：

+   - 对融资者来说，股票和债券代表的都是金融索取权，但是股票代表的是剩余索取权，它的风险大，而债券代表的优先追索权，它的风险小；
- 对融资者来说，如果一项目业绩稳定，盈利好，他就不希望多的人分享权益，所以债权融资的意愿更高。反之，一个项目虽然前景好，但是不确定性大，融资者就避免被追偿的利息压力，就会尽量避免权融资；
- 金融市场本质是一个关于各种债务关系的市场。
