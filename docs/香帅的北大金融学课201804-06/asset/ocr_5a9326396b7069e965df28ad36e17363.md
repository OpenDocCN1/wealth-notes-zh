# —— 中国股份制改革篇 ——

今天，我先给你讲两个历史事实：第一个，中国资本的萌芽起源于中国的农村改革；第二个，中国资本市场最初的起步，其实是要解决城市的就业问题。

下面我们就来逐一着这两个问题。要讲中国市场，我们就要从股份制开始，为什么呢？因为任何一种集合资金，自负盈亏，

按股分配的经济组织形式，其实股份制的本质就是对产权的界定。而产权不清断，正是改革开放前中国几乎所有经济问题的核心。

# 一、股份制改造首先重新塑造了农村的格局

你可能感到很奇怪，农村和农业会和股份制改革有什么关系呢？关系非常大了！

中国的农村改革从股份制改造了第一批种子企业——乡镇企业，为八十年代的国企改革打开了乡镇企业。更重要的，数亿的农村青年以乡镇企业提供了大量廉价优质的劳动力。

回望历史，我们在1978年时，中国的农民是被饥饿逼得没有办法，这个时候他们开始了打破大锅饭的事业，以家庭联产承包制为核心，中国的农村改革拉开了序幕，一个最显著的事实就是，在这种改革底下，农民民吃饱了饭。1979年的时候，一个实行包产到户的新安公社，

一年的粮食产量相当于1965年

到1970年6年的总和。更重要的是，数亿的农村青年从土地上被释放出来，成为了青春劳动力。

很多人会忽略这么个一个事实，但实际上这1亿的青春劳动力贯穿后面整个中国

发展的主脉络，当时的历史背景是这样的：城乡格局区分的二元体制，城里是铁饭碗的国营企业，农村人才进去了城里，那么我们今天吸纳这些农村的青春劳动力，那些来乡村发展的这是呢？中央就决定大力发展乡镇企业，鼓励农民向各类企业投资入股，这就是股份制在中国的第一次落地。

乡镇企业取得了巨大的成功，尤其在江浙一带，整个经济就呈现出一个爆发式的增长，成千上万的农民变成像巨富一样地冒出来。它们的资金少，规模小，但是机制非常灵活，而且，乡镇企业起步大多是从事劳动密集型，国营企业不看重轻工业和手工艺。这是一个无心之举，恰好

对著名的比较优势理论的最好诠释。

今天我们看到的那些乡里民营企业家，不少都脱胎于当年的乡镇企业，你一看，鲁冠球的浙江万向集团，就是其中的佼佼者。

乡镇企业的发展速度这么超乎寻常，不但解决了大量的农村劳动力的就业问题，而且给当时仍然具有强烈意识形态色彩的中国决策层发出了一个重要信号。股份制不是资本主义的发明，而是迫切突破计划经济体制的束缚，这种思想的释放，为

下一步城市格局的变化奠定了很好的基础。

# 二、城市新现象：集体企业与国企股份制改革

股份制改造在城市的落地是以集体所有制企业的形式展开的。但最有趣的地方，不是从一开始就不是一个经济行为，而是为了解决就业问题，维护社会稳定而开展的。

在中国改革开改的历史上，我们北大光华

重要的创始厉老师就扮演了一个非常

重要的角色。厉老师是中国股份制改革的先驱，对中国的股份制改造有特别重要的推动作用，但您可能不知道的是，厉老师他们当时提出股份制改革的目标，根本不是要解决企业在利润最大化的问题，而是要解决一个当时社会最棘手的问题：知青返乡，以及伴生的失业率问题。

八十年代初的时候，经济完全停滞不前，所以吸收城市大口的能力极低，这时全国有300多万待业青年，待业青年，这也是一个非常具有中国特色的词语，当时为了避免“失业”这个带有政治色彩的词，我们就给出了一个等待就业、“待业青年”这么一个名称。

这300多万待业青年，加上当时的上下班下落人口，近2000万的知青返乡回原籍。这些人口加起业，占到了当时城镇人口的1/10左右。

中央召开的“劳动就业座谈会”上提出，要用股份化的方式解决就业问题，也就是说号召大家集资，兴办一些企业，让企业可以引大就业，扩大经营，以此解决就业问题。那时候，学者们就已经意识到，股份制可以解决用生产全“全民所有，无人负责”的问题，用产权“责权利”清晰划划，这都可能会在当时非常僵化的管
