# 第一天：资产组合理论：金融学的大爆炸理论

在第一天，我们讲了第一个概念，投资组合的理论。这个理论被称为“金融学的大爆炸理论”，属于现代金融学的开山之作。

它最牛的地方在于，它把这种抽象的风险转化成了可计算的变量，然后创造了一套风险收益的一般性分析框架，搭建了我们整个现代金融大厦的基础框架。

![](bbox=[0.11, 0.35, 0.89, 0.38])

在这个理论之后，我们的金融学才真正的脱离了玄学。而投资组合的这个方法，也为证券投资的科学化奠定了基础，造就了证券投资这么一个庞大的全球性行业。

![](bbox=[0.11, 0.42, 0.89, 0.45])

# 第二天：夏普比率：寻找风险调整后的收益

第二天，我们讲解了投资组合理论中一个重要概念，夏普比率。在做投资的时候，我们必须要同时考虑收益率和风险。在这个时候，我们就经常会用夏普比率这个指标，即收益率和风险的比值来代表每一单位风险带来的收益，那证券投资中的最优组合是什么呢？

![](bbox=[0.11, 0.55, 0.89, 0.58])

就是在于在科维茨的有效前沿上，夏普比率最大的那个组合。

但是，夏普比率也是有局限性的，比如说它不能够很好地区分上行和下行。的风险，所以我们又提出了一个改进版的SDR夏普比率，SDR的夏普比率主要考虑的是下行风险，这跟我们平时在投资中碰到的问题是一样的。我们总是希望投资者在被推销金融产品的时候，不妨多追问一下，多思考，以便作出更明智的选择。

# 第三天：资产定价理论：为联动性风险定价

第三天，我们继续讲了CAPM，也就是资产定价理论。资产定价理论是一个给联动性风险定价的方法，它和资产组合理论是一脉相承的。

![](bbox=[0.11, 0.76, 0.89, 0.79])

首先，我们用前8天讲过的资产组合理论，去寻找一个最优的投资组合，然后把这个资产和市场组合当中的联动定义成为贝塔，资产的价格就是它的贝塔与市场组合价格的乘积。

![](bbox=[0.11, 0.83, 0.89, 0.86])

有了这个理论之后，所有金融资产的定价就有了一个基准，就变得特别简单清晰了。CAPM理论就是金融定价理论的逻辑基础，但是在这个理论给定的一个完美世界的定价状态是推演出来的，而在现实世界里，我们知道，这种完美的假定状态都是不存在的，所以这个理论在最新的应用是有一些局限的，但是它是实际的应用是在它给后来的金融定价理论提供了非常特别有用的基准。

好，前三天的内容你会发现都非常理论化，其实这是现代金融学最基础的部分。金融学就是全球各个顶尖的商学院里面，金融系最核心的课程。
