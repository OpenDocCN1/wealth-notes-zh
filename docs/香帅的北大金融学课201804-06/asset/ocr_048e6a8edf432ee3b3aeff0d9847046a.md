# 3. 风投自己有很大的问题，由于存在着代理问题。会过度关注短期业绩。

![](bbox=[0.06, 0.19, 0.11, 0.22])

香帅

今天在我们课程里提到的，像共享单车行业，它们的背后站着的其实很多都是世界顶级的风投机构。这些风投机构，在美国硅谷其实也投出了不少非常优秀的科技创新项目。而且我们在前面的课程里也跟你讲过，股权投资本来就是一种相对长期的，追求稳定收益的投资。

那么我想请你想一下，为什么这些风投机构一到中国市场上以后，就开始会发生忽略长期效益，注重短期业绩，从投资演变成“烧钱大战”的这么一个局面呢？你觉得这种现象对于我们的整个商业环境，还有我们的创新业态会有什么样的影响呢？

欢迎你把你的思考放在留言区，跟我们一块儿分享。你也可以把今天的内容分享给那些做风投的，或者正在创业的朋友，看看他们对这个问题是怎么想，怎么看的。
