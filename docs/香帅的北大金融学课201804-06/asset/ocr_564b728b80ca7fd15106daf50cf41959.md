# 一、期货是如何交割的？

今天我们要讲的是第二次飞跃，商品是可以不必进行交割的。要彻底理解这个问题，我们首先要知道什么是交割。觉得在理解金融衍生品这个过程中间，很多时候障碍得其实来自于这种金融术语的障碍，所谓交割也叫“Settle”，就是我们平时说的“钱货两讫”。
平时说到钱货两讫，大家很清楚是意思原则就是钱货两讫。你付10块钱，拿两个苹果走，这就是现货交割，期货市场其实也是一样的，它只不过是在约定的时间和地点，以约定的数量和价格来付货款两讫。
举个例子，假设你开始炒矿，担心明年棉花价格的上涨你可以跟一个郑州棉花期货所，交一定的保证金买一个明年一月份的棉花期货合约。棉花期货的交割日规定是每个月的第十个交易日。
到了明年1月的第十个交易日，你就要进行交割，什么是交割呢？你要将你的货物打进交易所账户，而对方就要将棉花送去交易所指定的仓库，然后取得一个凭证。
买卖双方的仓口就分别去取货款和棉花，钱货两讫，完成交割。
这里要注意的意思就是在交割完成后，商品的交易就完成了转换期。看上去在商品的所有权，交割从天经地义。不过，除了这样的实物交割，我们生活中还有其他的结算方式。
大学的时候，你是不是在楼下小卖部赊过账，小卖部的阿姨拿一个小本子给每个人记账，月底的时候结算，这其实就是实物钱货两讫也换成了账面上的金额结算。而期货市场也可以类似地现金结算，和实物的交割是不一样的。
现金结算不涉及对所有的转移，而只是在到期日的前一两天对资金进行清算到，其实买了一个期货合约，你的期货合约的价格每天都波动，所以你的账户上的金额也每天波动。
这个时候现货合约就会每天根据你的盘给你进行现金的结算，如果你赚钱了，那么利润会划到账户，亏了的话，交易所就会划转证券的保证金，你想这种交易其实为那些投机者提供了特别好的工具。
因为有一个保证制度的存在，所以可以用少量的资金来撬动杠杆，如果这个市场越有杠杆就有以博大小的，那么也正是因为，在传统的观念中，保证金交易是现货交易的合法交易是赌博的分野。
早期的时候甚至有人认为，“一切不必交割为月的期货交易都是非法的”，所以一直到1982年的时候，现金结算在期货交易中还认为是违法的。

# 二、从交割到现金结算：股指期货的诞生

“必须交割”这个要求，其实就对期货有了限制，有些人一直认为股票很危险。有限而股指交易是合法交易的最终合约。为什么啊？其实在刚才的例子中，我跟你说过，通过棉花的期货合约，你就把棉花价格的未来波动锁定了，你的生产成本也就锁定了。
所以不管棉花的价格未来是涨还是跌，面对的不确定性变成了确定性，这就是风险的冲，这种功能对于很多生产者来说都是非常重要的。
在对商品进行风险对冲的这个过程中，人们就会更多地参与到其中，其实只要涉及到风险，就大多可以视为期货交易，而越是波动大的领域，风险对冲的应用范围就越大，比如金融领域。
同样的道理在金融市场上，那些风险最集中、应用最广泛的产品就是进行风险对冲的必然，什么风险是最大的呢？当然是金融市场的风险，而市场我们知道一般是根据大盘指数来衡量。比如说道琼斯指数，就是美国市场30家代表公司的总体平均值，它也反映了美国股市的总体波动，也就是代表着美国股市的市场风险。
正因为股票指数的代表性，所以它一直是期货界人士的梦想。但是在推出交割这个合约之前，股指期货一直没有办法，因为股指不是一个按一定标准，包含着很多实体股票的组合，它是一个概念，而没有实体，无论是谁，都没有办法对一个概念进行所有的转换。
所以如果要推出股指现货，你必须得有某种方法将期货数据转换成现金进行结算，而这就跟当时的法律发生了冲突。
那么这个限制到了上个世纪的七十年代以后就越来越不明显了，来自现实世界的需求使得“对冲市场风险”变得越来越成为必要。
首先你看，70年代以后，有一个“有风险性”兴起了。伴随着这个理论的兴趣，指数的基金也兴起了，一个是可以通过资产组合来降低风险，但是需要一个对整体市场波动的风险，这种风险只能是重要程度。另外一点就是基础在商业银行评价的时候也会选一个指标为基准，超过指数的部分才算超额收益，才会有分红，所以基金、基金经理们也需要把这个市场风险对冲掉。
我们在前面的课程里说过，60、70年代以后，美国的金融越来越形成一个中心市场，资产管理的越来越多，所以对冲市场风险的需要越来越大。
后来在业界的大力游说下，1982年的监管机构就决定废除必须实物交割的要求，以后所有的金融合约都可以采用现金结算的方式来。这个法令就为股指期货的推出到底铺平了道路。
之后不久，芝加哥商业交易所就推出了标普指数的期货合约，而股指的推出为整个资产管理机构，都是特别重要的一方面是现金的期货，它是帮助投资者从风险转移的工具，但是有办法通过投资组合分散掉的。而股指期货的推出，使得这种不可分散的风险能够得到对冲、被转移。
后来在美国之后，几乎所有成型的金融市场都推出了股指期货，以对冲本国市场上的系统性风险。
不过又有一件事很有意思的事情，我刚才跟你讲过了，股指期货是用于风险对冲的工具，股指是现金和期货合约。它有的时候为投机者提供了更高的杠杆，有时也会引发市场更大的波动。
在美国、日本，还有我们中国，股指期货都会在股市中的下跌中被为妖祸痛讨。
