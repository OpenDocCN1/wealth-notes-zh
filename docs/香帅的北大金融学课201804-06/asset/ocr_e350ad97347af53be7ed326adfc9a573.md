# 第一天：古罗马的治理是怎么“外包”出去的？

第一天，我给大家介绍了股份制公司。股份制公司是一种经济组织形式，它的本质是让不占人们能够取得经济利益一致性。

古罗马时期的“税收合伙人制度”在本质上就是现代的股份制，永久性、可转让、股票权益以及具有流动性的股票是这一制度的重要元素。股份制这一经济组织形式能够广泛地筹集资金、动员人力物力，政府能够转化成股份制公司的盈利性活动还有利于治理民主的实践。

# 第二天：法人：“永生”的财产拥有者

第二天我给大家介绍了法人这个重要概念。法律规定发行股票的只能是法人，法人方面和自然人一样拥有独立的法人财产权，另一方面法人可以突破自然人年龄的限制，让企业的长久持续成为可能，也使得发行股票成为可能。

# 第三天：有限责任的好处到底是什么？

第三天我们接着讲了公司名称中经常出现的“有限责任”这个词。有限责任含义是投资者只需要在出资额内对公司的损失承担责任。由于利益共享不设上限、风险共担损失可控制，这种制度安排降低了股权投资的成本，激励着投资者投资高风险的创新项目。当然，学者认为有限责任这一制度安排也有一定的问题，它容易产生道德风险和公平待遇问题。
