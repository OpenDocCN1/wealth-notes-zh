# 香帅

在今天的课程里，你可能会有这么一个感觉，中国的资本市场有一个很独特的形成逻辑，就是它的每一次驱动都不是我们通常所认为的市场力量，而是出于国家一些其他方面的考量。但更有趣的是，尽管驱动力不是市场力量，但是发展到今天，中国的资本市场也形成了非常蓬勃和有生机的局面。那你觉得这种非市场力量的驱动是怎么形成这么一个庞大而有生机的资本市场的呢？这中间的原因到底是什么？

这个问题比较烧脑，你可以好好地思考一下。欢迎你把你的思考放在留言区和我们一块儿分享，也可以把今天的内容分享给那些经历过这些岁月的长辈，让他们跟你一块儿分享你的得到。
