# 087 | 风投是如何塑造硅谷的？

你好，欢迎来到鲁帅的北大金融必修课。

我们都知道，硅谷几乎重构了我们的现代生活：从芯片到人工智能，从思科到谷歌，这些都是硅谷的产物。那么为什么一个小地方能够持续全球创新的狂飙这么多年呢？

可能你知道，硅谷是全球最大的风险投资所在地。硅谷的风险投资和企业创新就像手心背手一样，是不可分离的。但是很多人尤其是创业者，常常有一种幻觉，认为自己只要筹了足够的风险投资，就能长成“独角兽”。其实，硅谷的风险投资不是钱这么简单，它是塑造了一个全新的生态系统。如果你的企业创新就像在一个马戏团的雨林木语生态，风投就像给它们生态网里的雨林木语，培育了生态的要素，促进了整个生态的快速演化。

# 一、风投给的不只是钱，而是一套创新新生态

什么叫风投给的不是钱，而是一套创新新生态呢？我们从风投在硅谷的起源里面可以看到一些端倪。

50年代的时候，有8个工程师创立了一个叫仙童公司的半导体公司。当时他们几个是吃了技术，也就是人力资本以外，简直是一无所有，没有资金，没有销售渠道，没有商业人脉。这一切创办公司所需要的能力，他们都不具备，这种情况一下想到他们遇过了一个来自纽约的银行家，洛克菲勒以后，事情才有了转机。

和一般那些只追求利润的股东不一样，这两位投资人要求他们的股票参与了这家半导体公司的运营，帮助他们制定商业战略，分析他们的融资策略，撰写商业计划书，然后联系自己的融资渠道，还连他们一起融资了一百多万美元的资金，占仙童20%的股权。

所以，在技术资本和人和脉的支持下，仙童很快地成长成为五、六十年代最耀眼的明星企业，直接升级为全球第一的半导体公司，到1967年时的销售额就达到了2亿美元，这是当时不可想象的数字。一年多的时候，洛克菲勒卖掉了他手头上这家公司，公司的估值已经达到了几百万美金，所以两位投资人也获得了超级丰厚的回报。

更重要的是，通过这种模式，后来像仙童的创始人，还有从仙童出走的技术员、工程师，又陆续创办了几家硅谷企业，包括英特尔、国民半导体公司、AMD等等著名的高科技企业。这些企业都被称为“仙童的孩子”，然后撑起了硅谷的一片天空。

在这个例子中，你会发现什么呢？你会发现，企业创新不是一个独立的事件，而是一个复杂商业网络孕育的结果。这个网络不仅需要资金，还需要服务提供商，需要风险投资商，需要财务帮助。投资者对资金的投放，开拓强大的资本人脉，所以起到了连接金融机构、大企业、高校、企业和法律等机构的作用。相互作用的，共同演进，然后形成一个生生不息的创新生态。

硅谷的创新和风投，从一开始就有这么一对命相连的关系。具体地说，除了资金以外，风投在这个创新生态中，它有两个非常重要的作用：

+   第一，它起到的是一个评估信息、释放信号的作用。比如说初创企业的研发风险非常高，所以你经常会面临着招不到员工，上下游企业也不信任你的，各种法律、财务咨咨询机构不愿意合作的这么几个困境。所以，这个时候，风投的介入就像给初创企业信用背书，等于给创业者们发射了一个正面的信号，让他们更快地接受这些没有信用背书的创业者。所以，这也是为什么在市面上创业之前，很多初创企业宁可按更少的股权，融多一点资金，也一定要找那些著名的风险投资人领投，目的就是在释放信号作用。

谷歌在创立的第一年接受了两笔投资，来自硅谷最有名的两家风投公司，凯鹏华盈（KPCB）和红杉资本（Sequoia Capital），这两家风投的为谷歌在硅谷迅速站稳脚跟有重要的助推作用。

+   第二，除了这个信号作用以外，风投还有一个特别大的作用，它能把那些有创新人脉的企业家纳入自己的商业人脉网络，就好像打通了创业企业的奇经八脉一样。

你想，初创企业除了钱以外，最缺什么？最缺的是一条人脉网络。所以风险资本家常做的一件就是与他们投资的创业者分享自己的社交网络。

比如我们曾经在课程里提到过，阿里巴巴早期的时候，当腾讯给知名的投其当时500万美元的第一笔投资的时候。吴云当时有很多投资人有意向与名各有的阿里砸钱，但是是选择投资人的时候，马云就直率地说，他们希望阿里第一笔钱投进来的不仅仅是钱，而是他更多的要素，比如说商业资源，海外资源，还有下一步融资的资源等等。

# 二、风投的钱，有时候可能是致命的

说到这里的时侯，可能还是有很多读者会认为风，你说创新新生态化，那这不就是风险投资的不但解决不了问题，反而是致命的，

像我国中国的风险，就因为缺乏这种孵化生态的概念，当然也缺乏孕育的新生态的制度和学术大环境，所以往往会在演那种什么人气，大撒钱，拔苗助长，最后导致行业生态崩溃的事情。

从前年开始的共享单车的大战，就是一个典型的例子。很多人都知道，共享单车的商业是分为c对o资本起步的，但是部门管，所以摩拜单车的创始人推平李斌这个资深的投资圈内的人，迅速串去风大笔风投资，推出了更好的摩拜单车。卡摩拜单车是一个不错的，但是也是自管吹的商业模式，c为什么共享单车这个商业模式是有上限的呢？我在后面的课程，再和时间跟你分析。

共享单车这个模式出来以后，在各项风险投资的驱动下，迅速迅速地变成了烧钱大战，整个行业浮躁风大。去年很大可能还记忆在，一句话特别吉利的话叫：小单车，小单车、小蓝单车、小白车，颜色不够共享单车使用了。

2017年下半年开始，大家在全国各个城市的垃圾站里面都会看到堆满了的各种单车，占用面了地方，又造成了资源的浪费，那些上下游就快被拖欠，用户押金被搁置的纠纷层出不穷，行业里的三小小蓝单车折了，然后今年单年单车又以上轮估信的价格被卖出，整个行业的下行已经成为定局。

其实不仅仅是共享单车，中国这几年O2O的炒作出现了一茬又一茬的烧钱大战，背后大多数都是风险投资的支持。这种以烧钱补贴来获取新用户策略，从短期看，效果是很有限的。因为互联网时代，用户迁移的成本就接近于零，你只需要一下手下，用户流失立刻马上就可以。所以在这种情况之下，我们看到共享车车模式不是很乐观。前几年，我们国家先后出现100多个上市车类的创业项目，现在基本上都死得差不多了。

那么为什风投这么“傻”去钻钱车这种现象呢？里其实就要是向两种高估值风投或者机构投融资。那为什在管理层要投人融资中搞钱，那为了在短期内吸更多的资金让成股票暴涨，风投经常会有短期这现象，发布公开收购的行动尤其在O2O这种直接的用用户出销售，成本大特别商业化的行业，这种靠补贴来导致创业公司资金链断裂的公司的更是屡见不鲜。
