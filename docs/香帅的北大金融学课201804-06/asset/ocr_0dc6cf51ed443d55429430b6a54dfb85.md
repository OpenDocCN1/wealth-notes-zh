# 117 | 绝对估值法——有现金流才是王道

你好，欢迎来到秦帅的北大金融课。

今天我要跟你们讲的内容是怎么给股票估值，它的名字叫“绝对估值法”。

那么在讲这个之前，我先跟你们分享一下我这10年中经历的投资买卖的小故事。

第一个故事是关于谷子的。2003年的时候，我刚开始熟悉金融知识，我的一个同学就给我买谷子的股票，当时股价大概是100多美元。我们当时说，这个股票能涨到1000美元。当时我觉得这个人“失心疯”了。作为一个靠奖学金生活的学生，我当时口袋里不可能有6000美元的积蓄。所以我买了100股。当时，我同学说，这世界上不可能有这么大量的股票。当然，结果你们都知道了，不久之后，谷子的股价很快突破到了200、400、600，简直就是坐地起飞。

第二个故事是2012年左右，我当时已经回国，在北京教书了。当时茅台的股价已经达到100元，也涨不到2000元了。所以当时也有很多人在讨论，茅台的股价太贵了。我听了很熟悉，但是这一家的股票没有。我没有听到这个信息，而是听茅的财报数据，出来，用课本上学的现金流模型的方法大致地估算了一下，基本上是我们最保守的数数据。算出来，到2017年，茅台的市值应该在4000左右。也就是说5年5年两年大约有2倍的涨幅。只要未来不发生巨大的结构性调整，茅台应该是一支可以赚的投资。结果到2017年，茅台的市值达到8000元，远远超过我当时的计算。

好，这里说到我们的现金贴法（Discounted Cash Flow），其实就是一个最经典的绝对估值法。它在教科书上也会看到，叫“DCF”值。这种计算法，也是巴菲特最看重的企业内在价值的估算方法。

所以，今天我就来跟你们详细地解释一下，这个方法是怎么使用的。

# 一、现金流与贴现率

在讲现金流贴现法之前，我们首先要理解两个概念：自由现金流和贴现率。

好，首先来看一下自由现金流。

一个企业的自由现金流，你可以直接理解成，一个企业的经营活动，扣除所有的支出以后，可以自己支配的钱。

那就像一个公司能赚，它还可以买些设备，买些股票，投进别的公司。

它像一个自由现金流总和，就是一个人未来赚的钱的总和。

巴菲特有时候也把它称为“股票盈余”，就是说明一个公司未来可以提出来赚的那些。

但是这里有个问题，就是未来的钱不等于现在的钱。未来的钱需要你耐心等待，而且存在一定的风险，能不能把这些钱拿到手。

于是，在定个价位的时候，你需要把未来的这些现金流打一个折扣，折算到当下。也就是说折算到未来，把这个折算到当下，这就是一个不稳定的现金流在折现，反之就很小。

好了，把所有折现的这些现金流加总以后，那也就等于公司的估值了，所以这就叫做现金流贴现法。

说起来，这个方法算是正式金触正式“登上大堂”，成为一个正经职业的开始。

为什么这么说呢？其实在二十世纪初，大家都以为，股市是一个赌场。买股票跟抛硬币，买大买小一样，没有谁认为股票是个正确的。

直到二十年代，哈佛有本博士，叫威廉·谢尔比德，他写了一篇论文，叫《价值投资理论》。他提出，股票不是个商品，它是拥有未来价值的，有一个内在价值是一个企业未来能创造的现金流折算到现在的。而它代表的就是一个企业能够给股东创造的价值。

这个理论提出来以后，“价值投资之父”格雷厄姆，他也提出了一个理论，叫做“市场效率理论”。

这两块合在一起就成了证券市场上的价值投资的。从此以后，所有崇尚价值投资的人都会对这些企业内部的值非常地重视。
