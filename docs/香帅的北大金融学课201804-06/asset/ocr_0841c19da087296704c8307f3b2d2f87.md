# 第一天：投资的真正含义到底是什么？

第一天，我给你重新解构了投资这个概念。其实我们平时谈到的投资，包括着生产性投资和金融投资两个维度，说白了，我们这些人，投资的对象是股、险或股，包括我们买的银行理财产品、股票、债券，这些投资最终会流到金融市场上，变成生产性投资。就是你看到的企业生产、建筑建设等等。也就是说，宏观上来看，储蓄和投资是等效的。

![](bbox=[0.13, 0.31, 0.87, 0.36])

除了投资这个概念以外，另外我也告诉你，微观的投资决策主要包括三个问题：投什么、投多少和何时投资。如果有人能够回避这些投资决策，你未来的金融投资决策，就是个人、企业和国家对财务建设的决定因素，也是一个社会和国家未来增长的映射。

# 第二天：投资第一步——了解你的风险偏好

第二天，我跟你讲的是风险态度的问题。我们平时经常听到一句话，叫高风险、高收益。为什么会风险越高，收益也越高？在这几天的课里，我告诉你，这个现象是基于人类的风险厌恶的特征。为了补偿我们所承担的风险，我们需要风险溢价，而风险越多，所需要的补偿就越大。

![](bbox=[0.13, 0.6, 0.87, 0.65])

当然了，世界上有很多不同类型的人，像我们这种一般的是风险厌恶型，但是也有风险爱好者和风险中性型。所有的投资风险越高，就证明风险厌恶的程度越高。所以我们在做投资决策的时候，一定要根据自己风险偏好和风险承受能力，去进行。这样才能避免失去好的投资机会，又防止亏损过多、流动性不足。

# 第三天：衡量风险的三个维度——方差、偏度和肥尾

第三天，在了解了对风险态度的基础上，紧接着我们讲到了衡量风险问题，最常规的衡量风险的度量是测力度，你可以把它理解为随机变量对均值的偏离程度，即方差。除此之外，均值是测不准的可以用来衡量风险，对均值的影响越大，偏度和肥尾。而肥尾这个变量是往往上下可能比较大。这些概率上的概念非常抽象，所以我给你打了一个比方。

![](bbox=[0.13, 0.9, 0.87, 0.93])

平均来看，假设一个人的心情处于一个比较平稳的状态，你可以把它视为均值，那情绪波动很大的，你可以把它说方，就是说方差很大。而那些人天生优郁症，或者是优郁的人，就经常容易焦虑或者经常特别狂的人，你可以认为他在情绪上是有偏度的。而那种发生了极端狂热或者是极度伤心的情绪，你可以把它看为是情绪上的肥尾。通过这个一个有场景的例子，我想你会更加了解风险的度量到底是什么意思。
