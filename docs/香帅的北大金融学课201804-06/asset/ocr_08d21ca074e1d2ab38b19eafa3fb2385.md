# 第一天：股份制的前：工业革命不得不等待一场金融革命

第一天，我介绍的是工业革命和股份制之间的关系。工业革命需要技术创新和大规模的生产，而利益共担、风险共担的股份制使得大规模的筹资成为可能，是工业革命的催化剂。英国的圈地运动和中国股份制改革都证明了这一点。

![](bbox=[0.1, 0.39, 0.9, 0.46])

# 第二天：风险投资是如何塑造硅谷的？

第二天的课程，我给你继续讲述了风险投资这种模式是如何塑造硅谷的创新生态的。风险投资不仅是提供资金，更重要的是评估风险、释放信号，并且将创新企业纳入自己的商业模式，促进它们的生长。那些看似疯狂的大胆、豪赌的风投，反而可能会拨云见日。

![](bbox=[0.1, 0.57, 0.9, 0.64])

# 第三天：股份制or合伙制，选哪个？

第三天，我们对比了股份制和合伙人制度的不同。股份制和合伙制都是共同投资的经济组织形式。股份制强调的是股份入股，合伙制强调的是共同经营。股份制是以股权为基础，合伙制则是以人为基础的。所以说股份制比较适合用于人力资本和固定资本可以分离的行业，合伙制比较适合用于那些人力资本占核心地位的行业。

![](bbox=[0.1, 0.77, 0.9, 0.86])

股份制和合伙制当然是有各自利弊的，股份制容易资本控制欲，而合伙制团队实力受限制，风险大。所以创业团队应该根据自身发展的情况不断进行调整，也可以尝试着用分层的方法把合伙制和股份制的优势相结合，扬长避短。

![](bbox=[0.1, 0.93, 0.9, 0.98])

# 第四天：自上而下的推动—中国股份制改革发展篇

第四天的拓展话题，我们延续了上周的话题，继续给你讲解关于中国资本市场形成的几个重要事实，比如说证券交易的设立契机是九十年代初，重塑国家改革开放形象的需要，而二十世纪末的股份制改革的推进，是为了解决国有企业的亏损问题。

![](bbox=[0.1, 0.00109, 0.9, 0.00115])

在下一周里面，你要了解的是，中国资本市场是一个从上而下从顶层设计开始，然后再自上而下推进的，它需要服从于国家发展的总体的需要。这是构建中国资本市场一个非常重要的方面。但是，更重要的是，正是由于这些非市场化的目标，促成了我们在前面所听到的一个庞大的资本市场的发展。那么，这个也可以作为非常有中国特色的资本市场发展之路。
