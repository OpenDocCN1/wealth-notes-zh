# 126 | 规模因子和价值因子：选创业板和大盘等谁更赚钱?

你好，欢迎来到李帅北大金融课。

在生活中，我们普通投资者可能经常会碰到这样的困惑：几个基金经理来给你推荐基金，说他们的公司特别牛，特别会选股。有的说，我这个基金是专门投资创业板的。还有的说，我们专门投大盘的。

这个时候，你一般会去看一下他们的业绩，然后发现好像确实大盘的表现要好。

在这种情况下，我猜很多人会有点心，觉得这个基金经理可能真的特别牛，那他的收点基金管理费，可能也是应该的。

那么这些基金经理是不是真的特别牛呢？咱们先不用忙着给出答案，今天我先给你介绍一个市面上常用的会计理论，叫做Fama-French三因子模型。学了这这个模型之后，你再对这个问题作出判断。

# 一、两个“经久不衰”的市场规律

在讲这个模型之前，我们先聊一下美国二十世纪上半叶的时候，当时的一些市场规律。

当时美国是一个高度散户化的市场，市场上也没有形成成熟的研究，一些聪明的人就开始总结一些市场上的规律。其中有一个，就是说要是买市净率低的股票，未来就肯定更赚钱。

刚才提到了“市净率”的概念。市净率是一个金融里面常用的会计指标，它是每股的价格和每一般的净资产，这个比值的说法是给公司资产的定价。这个比值越低，就意味着这个股票越便宜。

有些聪明的人就发现，如果长期买入市净率低的股票，会比长期买入市净率高的股票，在未来表现会获得更高的收益。

另外一个规律就是买小公司，也就是那种市值规模比较小的公司，未来会更赚钱。

二、三十年代到四十年代，就有人已经发现了这些规律。随着马科维茨投资组合理论的出现，基金公司开始兴起。当时大型计算机出现了，机构投资者可以对市场进行大量的运算、分析，不断地挖掘规律，做成交易策略。比如说我刚刚说的两个规律，就都被基金公司挖掘了出来，做成了策略。

一个策略叫做“市值规模策略”。这个策略怎么操作？也就是在某个时点上，按照股票的市值规模，把所有的股票排序，然后分成很多组。买入小市值公司的组合，卖出大市值公司的组合。

另一个策略就是“市净率策略”，是指在某个时间点上，按照股票的市净率来排序分组，买入低市净率股票组合，卖出高市净率股票组合。当然这种策略得出的结果，会取得远超大盘的收益。比如说在1992年到1978年间，收益分组排名在前20和后20的股票，年收益率差1%，也就是说年化收益率差10%以上。

因为基金公司越来越多，很多形形色色的规律，就都花一边去了。这个两个策略，一个是市净率，一个是小市值，都经历了很长周期的时间有特别显著的回报。越来越多的入意识到这个趋势，逐渐形成了不同的投资风格。

有的基金就开始专门找小市值公司，像我们平时老看到什么小盘精选，还有专门的中小创投资，都是属于这个投资风格。

另一种就专门挖掘市净率低的公司，像我们平时看到的很多大盘蓝筹，现金稳定，行业也比较成熟的，就属于这样的企业。

# 二、CAPM错了？

上述这两个策略在市场上运行了很长时间的周期，终于引起了学术圈注意。

60年代，资产定价理论，也就是CAPM被引入。70年代，有效市场理论也盛行。那么根据这两个理论，市场得出了两个推论：

第一，在我们前面课程里讲过的市场组合，就代表着系统性风险。这是决定一个金融资产收益的主要因素，即决定金融资产价格的，我们把它称为“市场因子”。

我们前面课程说过，按照这个理论，除了市场因子以外的风险，都可以被分散。所以只要买入超过这个市场组合的，部分叫做超额收益。这是第一个推论。

第二个推论是，如果市场是有效的资产不存在具有超额收益，就证明这个资产有错误定价。

如果这两个理论都同时成立的话，那么这两个小机会带来的超额收益就很容易被否定。为什么？你看，如果市场是有错误定价，比如说公司价值被低估的话，市场这么聪明，一定会很快把它价格上拉，你买大市净率大的企业，它的股价会迅速上涨，市净率也就会下降。而如果公司被高估，股价下跌，市净率也会随之下降，超额收益的现象在长期来看，应该会慢慢地消失掉才对。

但是现问题就出现了，这个现象被发现了这么久，如果说是一个市场异常现象，或者是错误的定价，那么两三年就足够了。但是这个现象却持续了几十年。那么一定是理论出了什么问题。

那理论到底出了什么问题呢？当时芝加哥大学的尤金·法玛，2013年的诺贝尔奖，也是市场有效理论的奠基人，他说道：这个现象不能够证明市场无效，应该是CAPM错了。

CAPM哪里错了呢？尤金·法玛说，除了市场风险以外，还有其他的风险也是系统性风险，也应该可以作为定价因子。

有了这个想法以后，他和他自己的学生也开始一起动手，把美国二十年代的八十年代的所有股票的价格数据都拿了出来，然后开始分析，看看是不是能够找到证据来支持这个假设。

# 三、Fama-French三因子模型

按照刚才我们说的市净率和市值规模这两个规律，法玛和弗兰奇构造了两个风险因子，小公司规模前因子，一个叫价值因子，分别对应就是我们之前说的什么公司比较赚钱，低市净率的股票比赚缺钱这两个市场规律。

怎么样来看待这两个规模因子到是怎么构成的。

其实这个规矩超简单的，就是在某个时点上，按市值规模把全市场上所有的股票分成大的(B)、小的(S)，再按照市净率的大小分高(B/M)、中(M)、低(B/M)，得到了6组数据。然后用市值比较小的三组组合(S/H, S/M, S/L)的平均回报率减去市值较大的三组组合(B/H, B/M, B/L)的平均回报率，得出来的这个差值就是“规模因子”，即小公司对大公司的风险溢价。

另外一个价值因子的构造也比较类似，就是用市净率最低的两组组合(S/H, B/H)的平均回报率，减去市净率最高的两组组合(S/L, B/L)的平均回报率。

为什么它会被称为价值因子呢？因为很多低市净率公司都是那些成熟稳定，现金流丰富的公司，经常被称为价值型公司。高市净率的企业大多是为成长型年轻公司，被称为成长型公司。所以这个差值就被称为了价值因子，即价值型公司对成长型公司的风险溢价。

```
规模因子SML = 1/3(S/H+S/M+S/H)-B/M-B/H
价值因子HML = 1/2(S/H+B/H-S/L-B/L)
```

好，这里我们用这种分组的方法，就是学术研究中经常用的双重分组。

为什么要用双重分组呢？你想一下，大公司或者小公司的组合中，既有市净率低的，也有市净率高的，都可以参与分组。而按市净率分组，这个自变量，这个价值到底是来自于市场，还是来自市值规模，而用双重分组以后，就把这两种效果清晰地分开了。
