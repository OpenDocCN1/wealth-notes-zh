# 香帅

驴可达同学应该是对这两周的课程听得非常地认真，你的观察是很有道理的，市盈率和市净率是很接近的，但是有所区别。

它们的分子都是股价，而分母一个是每股净资产，一个是每股净利润。听上去这两个词很相近，而且现实生活中，这两个分母也是高度正相关的。一般来说，每股净资产高的股票，每股的净利润也相对会较高。

那么这两个指标有什么区别呢？区别主要在，每股净资产主要反映的是历史累积的账面净资产，是根据会计账减减去折旧累积起来的，所以反映的是历史信息。而每股净利润反映的是当年的信息，是最近的情况。

在我们国家，因为存在着一个从原来计划经济到市场经济转型的过程，会计准则也发生了很大的改变。所以我们国家这种账面净资产的数据质量是比较差的。

还有一个问题就是我们国家的企业情况变化很快，所以市净率对于解释回报率的作用是相对比较大的小的。每股净利润的质量会好一点，反映的是最近的情况。所以市盈率在我们国家的预测效果会好一点。

但是，这里又就是了，学过会计的同学肯定知道，在所有的财会报表中，利润是最容易被操纵的。有的企业账面利润很漂亮，但是现金流却一塌糊涂。这个问题我们在后面的公司决策板块里还要详细地给你讲。

所以有时候，光看一个指标特别容易犯这种以偏概全的错误，所以多看几个方是正道。
