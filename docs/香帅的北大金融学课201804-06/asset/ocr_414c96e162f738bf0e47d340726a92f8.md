# ## 099 | 延展话题：散户在衍生品交易中容易犯的3个错误

你好，欢迎来到春哥的北大金融课。

今天是周四，也是我们延展话题的时间。我们来讨论一个很实际的问题，就是散户在衍生品交易中特别容易犯的错误。

很多同学自己做过衍生品的交易，或者有的人是对手衍生品交易跃跃欲试。这时候，下面这三种错误就会对你非常有启迪意义。

+   - 第一，过度迷信价值分析。
- 第二，过于激进，仓位控制不当。
- 第三，以业余时间对抗专业精英。

# ### 误区一：过于迷信价值分析

第一个错误，就是很多散户过于迷信价值分析，这是非常危险的，经常要付出很大的代价。实际上，在衍生品交易中，没有价值分析是万万不能的，但是价值分析也远远不够的。

我举个例子，比如说你做了非常严谨的分析，或者说者是大模型可能，看空它的宏观经济，比如铜价可能会跌的，但依据这个判断在衍生品市场上做空，可能会错的，会给你赔的。为什么呢？我们来仔细地分析一下。

先来说你的判断，一个看空中宏观经济的判断不是那么容易被发现的，为了这个判断，你仔细研究了宏观经济数据，看到了机械制造业的投放在下行，房地产调控一时不会放松，房地产投资在下降。然后你看着就推算，投资相关的大宗商品的价格会下行，所以对于铜类，水泥，铁矿石，黑色的需求都会下降。这时候，你就看空了“黑色系”：准备做空螺纹钢，铁矿石、焦炭和焦煤。

看起来这些分析非常有道理，非常有逻辑。我们假定了判断是对的，但是你做空空系统能挣钱吗？很难，对你的关键在哪里呢？你看到的情况别人也看到了，你怎么知道价格是否已经反映了这种判断呢？

比如说2018年4月30号左右，铁矿石5月交割的价格在450块钱左右。那么未来是跌还是涨？你的看法的，那么应该看跌。可是这时候，现货的分析在500块钱左右，现货价高于期货价50块，未来是现货跌还是期货涨呢？

在回答这个问题之前，我先给你补充两条信息。

第一，铁矿石期的价格在过去的两个月之内，已经从530块的高位跌下来了，跌了100块左右，还会进一步下跌吗？

第二，5月15日，这个合约就到期了，到时候，期货的价格应该等于现货的价格，否则就有无套利机会，任何人都可以用它买一张期货，交割期货，然后把期货以高价卖掉去获得利润。所以，如果现货的价格不下跌，期货的价格不可能反弹。

这两分分析就指向了什么可能性呢？第一，对中国宏观经济的态度判断已经写在现在的期货中，所以在现在的价格存在着反转的可能性。第二，未来的价格趋势只能是下降的，是，考虑到目标期的价格已经低于现货价格，而期货很快到期，再进一步下跌的可能性是存疑的。再进一步地看，考虑到目前经济下行的证据已经比较多了，而中美间的贸易摩擦看起来一时的半块才能够缓解，那么为了防范经济过冷风险，中央政府有没有可能出台经济刺激政策呢？这种可能性是有的。

实际上，4月17号，央行就降准了一个点，已经是一个相对宽松的信号。在这种背景下，如果做空期货，很可能会赔钱。

我的一个朋友对中国的宏观经济的判断一直非常准确，但是他在4月16号左右开始做空铁矿石，现在已经赔了差不多。

刚才的分析其实告诉你什么呢？你的价值分析可能是对的，但是它对你的期货交易的指导是有限，你需要更多分析为你的判断方向。但是，价值分析不能够帮你找到一个确定性的交易策略，这是为什么呢？因为期货的基本面是非常方的，它的短期波动完全是有大量的非基本面因素决定的，甚至是人为操纵的，所以对于价值分析的局限性，一个散户要非常清醒的认识。

刚才说的是第一个错误，过度迷信价值分析的时候，即便你的分析对了，你也很可能赔钱。

# ### 误区二：仓位管理，谨记“剩者为王”

散户常犯的第二种错误，就是仓位的控制过于激进，有时候便是方向判断对了，却因为市场的随机波动损失惨重，甚至不为提前止亏，或者清盘。本来你应该赚钱的，结果却赔了钱。

回顾刚才的例子画面，假设你是看空宏观经济，看空铁矿石，而假使你就事存存证长期来看是对的，中国的经济就是下行的。但是你却做空铁矿石投入了很多资金，目前假设你投了10倍的杠杆，你知道吗？可能生什么东西呢？比如说你现在有一个大户，他和他的哥们儿相比，大大地买地抬高了价格，然后随着价格一点点上涨，很多的散户开始跟跑，跟着买入，然后价格进一步地上涨。

记住，这时候因为你用了10倍的杠杆，所以这时候你的损失非常地惨重。你损失惨重事会导至你足够的资金被保证金吞掉。如果你手里没有足够的资金来补保证金的话，你就可能在进一步的上涨过程中，甚至可能发爆仓的风险。这就是说，即便对3个月、5个月以后，你的判断被证是对的，但是你没有用，你已经被爆仓追出了市场了。

所以说，衍生品的好处是提供了加杠杆的机制，但杠杆既双刃剑，它可以放大收益的同时，也放大了风险。所以这种交易，仓位的控制就尤为重要，激进行操作，一次糟糕的心理可能就会让你惨不忍赌失。

所以，如果你的价值分析非常地准确，判断都是对的，那么仓位控制也非常非常地准确，一般能够在承受比较小的波动，就会实现最终挣钱。

所以这个小故事叫做“剩者为王”的就是一个故事，最终实现“剩者为王”的这个“剩者”靠“剩下”的“剩”，谁能够在市场竞争的洗劫中剩下，不被流走，就会是最终的王者。

好，刚才我说了第二条错误，就是仓位的控制比较激进。

# ### 误区三：用业余时间对抗专业精英

最后，也是最重要的一个错误，参与到期货交易中的散户，一般都是比较年轻的投资散，一般会以自己聪明，所以你期期货不会一亏二万亏去对抗机构的集体力量。更严重的是，散户大多是利用业余时间做衍生品交易，这等于是说用业余时间对抗专业的人，专业家。

我为什么说“用”这个词语呢？在前面的课程里我已经告诉你，衍生品是零和博弈，多数的人就对着看做多的，你挣钱意味着别人亏钱，亏钱就意味着着别人亏钱。所以，如果散户挣钱的话，就意味着看的人机构是赔钱的。

明白了这个对抗性之后，你就知道，其实谁派生的对谁多，谁获胜的概率就较大。

比如说铁矿石交易，专业的机构是怎么做的？他们有专门的人去计算海上漂着多少条船，每天有多少的铁矿石，每天的销量，然后每天多少的销售价格，每期货需要预计和预期。这需要要一个团队来做的，散户没有这种力量。所以在这种业余和中的对抗中，散户并不占优势。即便你趋势看对了，也不一定能够挣到钱。

那么散户在什么在期货交易中占据一定优势呢？在期货交易中，股票交易不一样，技术分析是会有帮助的。因为技术分析做得好，可以帮助你预测市场上买类交易的力量，如果类方力量强，你就可以看多。如果把力量强，你就可以看空。如果你能把技术分析和基本面的价值分析结合，并合理地严格地控制仓位，散户应该还是有机会在衍生品市场上赚钱的。
