# 第一天：资产估值—投资决策的第一步

第一天，我和你一起学习的是绝对估值法和相对估值的基本概念，以及基本原则。前者是计算每个资产未来的现金流再贴现，再把这些加总作为价格，后者是跟同类资产的价格，进行比教和微调，再出价。两种方法都要记住，没有先后的顺序。

![](bbox=[0.05, 0.31, 0.95, 0.36])

另外，当你在进行估值的时候，要牢记三个原则：
第一，估值只是提供一个参考，而不一定能够给你正确的投资决策。
第二，要尽量使用少而重要的信息进行估值，这是一个科学上的简约法则。
第三，要尽量克服我们人的一些偏好，对估值结果保持客观和冷静的态度。

# 第二天：绝对估值法—有现金流才是王道

在第一天以后，我接着给你介绍了一种重要的估值方法，也是巴菲特最喜欢的方法，叫做绝对估值法，也叫自由现金流贴现法。它的估值步骤大体上是这样的。
首先，要确定一个公司的未来增长率和它的贴现率，然后计算出这个企业的未来自由现金流，再用贴现率计算这些未来自由现金流的现值，再把它加起求，这样就是一个公司现在的价值，也就是它的内在价值。

![](bbox=[0.05, 0.56, 0.95, 0.62])

这种方法特别简单有效，像巴菲特，还有很多价值投资者都是用这种方法取得了不俗的成绩。

表：财务指标分析

但是你也要记住，由于增长率和贴现率难以准确预测，所以很多时候咱们得到的结果都不一定准确。

![](bbox=[0.05, 0.7, 0.95, 0.74])

所以这又回到了第一天我给你的讲，不要迷信，一个估值结果，只能够把它作为一个参考基准值，而不一定能够给你一个正确的投资决策。

# 第三天：相对估值法—如何用市盈率找到相对更便宜的资产？

第三天，我给你再介绍了一种非常流行，也是我们市场上经常听到的相对估值法—市盈率法。
市盈率，这个词你们在生活中听得很多，计算起来也非常简单，它就是一个一般股票的股息除以一般的每股票所得利润。它可以有几种意思，第一种是市盈率，你可以理解成它是一个投资回报的时间，所以一般你听到的本来说，市盈率越低越好，就意味着预期的回报时间里越长越好。
但是，有时候你会发现，市场经常会喜欢那些市盈率很高的股票，那是为什么呢？市盈率的分子是市场价，而分母是利润，包含着这个市场对那个公司看好了很多，所以市盈率高代表着这个公司被市场看好了。
所以，给你几条原则：
第一，在其它条件相同的情况下，应该选择市盈率相对较低的股票。
第二，如果一个公司盈利增长特别快的情况下，市盈率高一点也没有关系。
第三，我要提醒个人投资者，我会尽量避免去选一些市盈率高于200、300的股票。对于这种现象，大家要冷静对待，理性应对。

# 第四天：怎么给一个年轻的成长型企业估值？

第四天我和你介绍了相对年轻的成长型公司，比如说市场上非常热炒的独角兽企业的估值方法。
这种企业，因为它的成立时间短，很多时候没有收入，也没有现金流，不确定性很大，你很难给它准确估值估算增长率、贴现率和自由现金流，在现在是这种市场变换的情况下，很多独角兽公司的成长都出现新的行业里面，你也很难找到相同相似的企业去给它做比较，所以对于相对估值法和绝对估值法都不是特别地合适。
那么风投资金，在给年轻企业估值的时候就往往会遇到很多的困难，怎么办呢？这我给你介绍了一种可以调整后的绝对估值法，可以有效地解决一些这样的困难。
风投资金在给年轻企业估值的时候，也会把收入的增长率拉大，贴现率也拉大，然后算出关键人，为什么？这是因为我们都知道，一个初创企业里边，那种核心团队所创造的这些价值关键人有至关重要的作用。所以要给这个关键人负责计算出来的，通过这个调整后的相对估值法，对企业可以作出相对好的判断。
