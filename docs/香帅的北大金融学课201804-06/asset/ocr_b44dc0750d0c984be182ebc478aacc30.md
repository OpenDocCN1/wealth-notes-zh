# 5. 接下来讲什么？

到目前为止，我们从更加宏观和抽象的角度，给你的金融学大厦打下了很好的基础。

接下来我们要进入的是更加微观、具体的“投资者决策”、“公司决策”板块。然后在了解了公司和个人的投资决策的基础上，我们来研究：什么叫“金融创新”，理解什么是“金融危机”，在金融危机中应该如何自保。

在旅程的最后，我们要继续地升华，我们要从金融的过去，一直走到金融的未来，给你仔细地剖析“科技金融”的过去、现在和未来。在旅程终点的时候，还会给你一次小的惊喜，让你把所学到的所有的金融的“术”上升到“道”的层面，要理解这个“世界唯一确定的是不确定性”，然后在理解所有内容的基础上，深刻地“理解人性”。
