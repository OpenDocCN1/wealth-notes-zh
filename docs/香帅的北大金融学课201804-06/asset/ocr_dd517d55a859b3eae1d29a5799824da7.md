# 要正确认识运气

+   - 在判断投资绩效能力时，大湿的判断傲慢必不可少。不要轻易相信两三年的“明星”投资经理，不要轻易和还没有穿越过周期、经历过牛熊转换的投资经理人。

- 对自己“成功经验”保持警惕，同时也对自己的“失败经验”保持平常之心，要从这些经验中去发现，这些影响是怎么得来的。
