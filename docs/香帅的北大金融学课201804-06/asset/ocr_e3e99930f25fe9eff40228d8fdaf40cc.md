# 118｜相对估值：如何用市盈率找到相对便宜的资产？

你好，欢迎来到香帅的北大金融课堂。

上堂课我跟你说到，绝对估值法是有局限性的，而且比较难、要计算。所以它还是会对很多人造成障碍。

那我们在下一个企业估值的时候，有没有更简便的方法呢？这就是我们今天要讲的，用同类型企业作参照物，所进行的“相对估值法”。

很多对股市略有所知的同学会常常听到一个词话，市盈率。市盈率估值法就是市面上最常用的相对估值法。

这节课我们就来看一下，怎么用市盈率进行企业估值。

# 一、市盈率——投资回本时间

首先我们看一下，什么叫市盈率——市盈率就等于一个金融资产的市场价格除以利润。

你看一下五粮液例子就知道了，假设你花75块钱买了一股五粮液的股票，成了股东。2017年，每一个股东有2.88元5的利润。那么按照这个利润水平来，你回本的时间就是27.6年，这个数字也就是市盈率。所以五粮液是27.6，就是说你的投资要差不多27.6年才能回本。

很明显，市盈率越低，就意味着你的回本时间越短。作为投资来讲，就意味着这个投资更加划算的。

这是传统的市盈率选股方法的核心，把每一个股，它的市盈率去跟行业的平均值或者市值的平均值去进行比较，然后选出具有相对较低的市盈率的个股进行投资，这就是一种相对估值法。

这种估值方法，就是美国的价值投资之父格雷厄姆的原创。他在《聪明的投资者》这本书中指出，在他20年的投资生涯中，美国市场上市盈率最低的那些公司平均收益率是6.64%，而市盈率最低的公司平均收益率是多少呢？16.26%，中间差了10个点。那20年累计下来，就是8倍的差距。

这话什么意思呢？就是说两个人有相同的投资，一个人在20年中买市盈率最低的股票，另一个坚持买市盈率最高的股票。20年后，前者的财富是后者的8倍。这就证明了，市盈率比较低的股票是一个更好的投资方法。

不光是美国市场，咱们中国市场其实也有类似的规律。比如格科瑞电器在2011年年初的时候，市盈率只有9.44，远远低于当时中国股市的平均市盈率。结果这家公司股价从2011年到2017年涨了6、7倍，涨幅特别地大。

除了格力电器以外，像华夏幸福等当时很多的低市盈率股票，后来都取得了非常高的回报率。
