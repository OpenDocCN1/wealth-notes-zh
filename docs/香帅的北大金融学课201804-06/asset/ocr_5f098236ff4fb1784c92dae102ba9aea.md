# 划重点

+   1. 金融资产的核心就是对风险定价，我们可以将风险拆解成系统性风险和个体风险；
2. 个体性风险来源于局部个体，可以用组合的方式抵消掉，所以又被称为可分散风险；
3. 系统性风险又叫不可分散风险，属于整体市场的波动，几乎所有的金融资产都会受到其影响。因为这些风险没有办法依靠增加资产种类进行分散，所以对系统性风险的定价就成了资产定价的核心。
