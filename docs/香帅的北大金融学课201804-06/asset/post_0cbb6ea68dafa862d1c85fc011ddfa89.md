# 102 | 期权：你的“选择权”也是一种金融产品

你好，欢迎来到清帅的北大金融学课。

今天我们来讲一个比较有趣的衍生品，期权（option）：“期”是指未来，“权”就是选择权，所以这个产品交易的是“未来的选择权”。

这个概念又是很抽象的，我给你举个例子吧。比如说这个月底iPhone11上市，你想卖二手，定合同又不确定到时候卖多少钱，约定一个月底卖出一小笔黄金，用这100元，约定一个月底交，没有风险，没有约束，你买的是期权。没有买这个产品，你就没有权利，到期就废了，约定价格100元，如果卖150你赚了50，如果卖50，你不会卖，这个合约就自动作废了，你的权利就自然消失了。所以这个合约，其实就包含看期权这个概念。

### 一、期权与定金的差别

你可能会恍然大悟，这听起来挺玄乎，期权不就是平时我们买东西时的“定金”吗？这句话说不全，期权和定金有很多不同。

- 定金是一种约定，是合同的一部分，具有约束力，你交了定金，不买了，这钱就没了，卖家也不退了；你交了定金，不卖了，双倍赔偿。期权就不同了，你交了一笔钱，如果不行，你最多损失这笔钱，期权自动作废。
- 定金是一种单向合约，交钱方没有选择权，不交钱方没有选择权。期权是双向的，交钱方有选择权（买入价、卖出价），不交钱方没有选择权。期权是单向的，买方有选择权，卖方没有。
- 定金没有标准化的合约，每个商品的定金都不同。期权是标准化的合约，有到期日、行权价格等。期权有市场，可以买卖。

### 二、期权的金融功能

你可能会问，期权的金融功能是什么？简单来说，期权可以用来对冲风险、投机、套利。

- 对冲：如果你持有某个资产，你担心价格下跌，可以买入看跌期权来对冲风险。
- 投机：如果你认为某个资产会上涨，可以买入看涨期权来投机。
- 套利：利用期权价格和市场价格的差异，进行套利。

### 三、期权定价模型

期权定价模型有很多种，最常见的是Black-Scholes模型。这个模型假设资产价格服从对数正态分布，并且假设利率、波动率等参数是常数。

### 四、期权投资策略

- 买入看涨期权：看涨未来上涨，买入看涨期权。
- 卖出看跌期权：看涨未来上涨，卖出看跌期权。
- 买入看跌期权：看跌未来下跌，买入看跌期权。
- 卖出看涨期权：看跌未来下跌，卖出看涨期权。

了到期日，权证价格本来应该为零的，结果我们国家市场上发生过到了到期日，权证价格居然暴涨的情况。所以，这些疯狂的炒行为，就迫使我们的监管层两次叫停了中国的权证市场。

但是这几年以来，有越来越多的研究都认为，中国的A股市场太缺乏做空的工具了，所以负面的消息没有办法及时地反映到股价中，导致A股的定价过高，就产生了像我们课程里原来说过的，像A/H股有价差这些现象。当时我们国家迈出的第一步就是推出了我们昨天讲过的股指期货。很多人就说，下一步应该讨论引入个股期权，让个股的市场定价更加有效。

### 一、互换：互相交换，优势互补

要理解这个概念，我先给你们讲个小故事。我小学的时候，画画很厉害，一直都会去写表扬卡“三好学生”。但我写字和算术非常地，一学小学数学不好学，他特别适合，但是一碰到数学作业就发蒙。我们俩下就交换了作业，我帮写数学作业，给我画了一个画。结果画非常好，老师给了个好学生。所以，小学就成绩也变得突飞猛进，考上了全年级第三名，以后，有一天想起了这个童年往事，突然意识到，当时我们使用的就是“互换”这个衍生品。

为什么这么说呢？我们先从互换的起源讲起。互换是上个世纪七十年代的产物，那个时候全球有很多跨国公司有，比如说有一家美国公司A，在英国有一家子公司，另外一家英国公司B在美国有一家子公司，所以有时候就要发生什么，情况是两个公司都要给本国母公司打钱。但是跨国公司的首脑面临很多两个问题。第一个是，当时各国的外汇管制比较严格，跨国的转汇非常地困难。第二，那个时候的金融市场很大的风险，汇率波动很大，而且各种汇率政策，自己的一举一动，企业利润就吞没。

那么怎么解决这个呢？聪明的银行家们就想了个办法，就让大家来做“互换”。就是一个相互交换，怎么交换呢？美国公司A给英国公司的母公司贷款，这样一来，就不需要去国外贷款了，没有外汇管制，也没有汇兑风险了。而英国公司B给美国公司的子公司贷款。你看这样一看，就把解决了各自的融资需求，同时了外汇管制的限制，各自汇率波动的风险。

这种贷款的方式又叫作“背对背贷款”，它就是互换的起源。所以，互换本质上就是一个取长补短的置换，双方都会受益。

好了，现在会明白，为什么我说我们小时候，大家搭这种优势互补的作业互换也是一个典型的SWAP了。所以，互换的逻辑看上去不复杂，但是它背后其实是有很深基础的。它背后理论基础是英国著名经济学家大卫·李嘉图提出的“比较优势理论”。

李嘉图是从国际贸易这个角度来讨论的，他认为，假设两种产品两个国家都能生产，但是某一国在两种产品生产力上处于有利位置，而另一国处于不利地位。在这种条件下，每个国家应该在生产上具有“比较优势”的产品，这样双方都可以从中获利。获得比劳动分工优势，在现实经济中，强调分工的有利，互换这个概念，也跟上比较优势有很大的关系。

这个比较优势的运用极为广阔，大到国际形势，小到家庭主妇。在一个家庭里谁更擅长挣钱，就应该去挣钱；谁更擅长做家务，就应该多分担家务。

好，那么互换其实就是比较优势在金融领域的应用，具体的就是交换各自现金流上的受益。对方之间互换自己所没有的约，那么通过互换的目的就取长补短。

在这个合约中，资产利率、汇率、货币这些金融就是基础资产，那么合约价值就会随着基础资产价值变化而变化，也就是说“衍生”这些基础资产。

在金融互换里面，一个最典型的互换产品就是利率互换。其实是一个相反互换的，对不对？一般来说，自己的事情，那就自己去银行贷款，到市场上上去筹款，难道就让别人帮你不成？实际上这不仅仅是可行的，而且是互利互惠的。

给你举个例子，比如，有两个公司，其中一个A公司，它希望自己能有一笔浮动利率的贷款，那么B公司希望自己的贷款是固定利率的。但是B公司不太合适，A公司浮动利率市场上比B公司更优，能够在较低成本拿到款，而B公司在利率市场上比A更优。这个时候怎么办？两个企业比一笔交易，B公司去浮动利率市场上拿一笔A公司的固定利率市场的款项，然后自己的优势一下。这样，双方都实现了自己的优势，既满足了需求，又降低了融资成本。

以下是完整的计算过程：

- A、B两个公司打算各借一笔5年期的款，A希望浮动利率，B希望固定利率。
- A公司按浮动利率借债，资金成本是8%；如果按利率借债，资金成本是10%。假设B公司按利率借债，资金成本是9%，而按利息借债，资金成本是10.5%。
- 采用利率互换，B公司固定利率借债，比成本“按浮动利率借债+5%的价差”低0.5%。

- 如不使用互换，A公司浮动利率的成本是上海浮动利率加10%，B公司固定利率成本是10%。
- 采用利率互换，先让B公司比成个人一笔利率固定利率的贷款，比成本“上海浮动利率+5%的价差”低0.5%，然后通过互换给A公司8%的固定利率贷款，然后让A公司再给B公司一个固定利率。
- 结果：A公司浮动利率的贷款比上海浮动利率加10%（B公司按固定利率借债的资金成本8%+8.5%公司互换的利率），比原来成本高4.5%，成本是8.5%（同B公司1%）。
- 互换后，A公司比成本1%，B公司比成本1%。

你可以看到，采用互换，各家企业各自省去了多少呢。

虽然互换的概念非常简单，但是真正的难点在于怎么做双方的期限要求，还有双方的风险偏好这种匹配。其实互换是非常复杂的，它一个项目实现起来是极其复杂的工作，但是你也不用担心互换的计算方法，它是在互换过程中，达到一个最理想的状态。

### 二、互换不是天使

刚才我们利了利率互换，听到这里，你的感可能会互换这种产品真的是一张大网，既能帮助产品，又能降低资金成本。但是，你要记得，互换确实有很多的风险。比如你可能降低了融资成本，但也会获得杠杆效应。比如说你获得很大利润，但是如果汇率大幅波动，你的成本就会飙升。在金融市场上，这种例子非常多。

比如大家都很熟悉的宝洁公司，在1993年的时候就做了一笔利率互换，它当时把自己的一笔款换成了浮动利率。这个互换将它的融资成本降低了75个基点，降以后的幅度还是蛮多的。结果，到了1994年以后，利率节节攀升，攀升了差不多两个点。宝洁公司在这一笔互换上就亏亏了1.05亿美金。最后搞得宝洁公司的董事会主席只好跑出来跟股东道歉：像诸如此类互换产品的金融衍生工具，风险巨大，本公司因此遭到了重创。但是会引以为戒，绝不再做

从这个意义上说，互换和所有的衍生品一样，都面临着同一个问题。你看，刚才我们说的互换里面是什么资产？是因为利率升高，也就是基础资产变化了，所以导致这个衍生品也变化了。因为衍生品是衍生于基础资产之上的，你基础资产有问题，衍生品的质量自然会有问题。这就像烂苹果做的果酱一样，吃了是要闹肚子的。

一个最典型的例子就是2007年的金融危机中，有一个被诟病得特别多的互换产品，就是很多人都听说过的CDS（Credit Default SWAP），中文名字叫"信用违约互换"。我猜很多同学都已经听说过这个名词，知道它是2007年次贷危机的导火索，但是不知道它到底具体是干什么的。

这个信用违约互换是什么样的产品呢？这要从21世纪初开始讲起。我们在前面课程里讲到，21世纪开始，美国经历了一大波房地产的狂潮，有很多房屋贷款的资产证券化的产品就发行到了市场上，很多金融机构为了赚钱，就把这种贷款贷给那些没有偿还能力的人，这就是次级贷款。

比如著名的投行雷曼兄弟，就把自己手里一个亿的次贷证券化的债券向美国最大的保险公司叫AIG购买了信用违约互换。这个信用违约互换，互换的就是"信用违约"这个事件。意思是说，房屋贷款上的违约现象是很多的事的话，AIG就会帮雷曼兄弟来承担这个违约的风险，也就是说AIG和雷曼兄弟把信用违约进行了互换。雷曼兄弟把这个信用违约的风险转移给了AIG，为这个互换，雷曼兄弟要向AIG付出一笔费用。所以你看到互换，它的实质其实是AIG对雷曼兄弟的违约风险做了一个保险。

在当时的情况下，很多人都认为，房地产会一直往上涨，不可能有违约的风险。AIG的总裁甚至改变了风险假设，就认为在世界上真的有"免费午餐"。到05年左右的时候，这种信用违约互换的产品达到了巅峰，让AIG在这块业务上的收入达到33亿美金。在这么大利益驱动下，AIG就越发对这个衍生品的基础资产，房屋贷款的质量开始视而不见，它开始很大胆地为很多质量很差的次级贷款的资产证券化进行担保，等于就把这种烂苹果做的苹果酱放到了市场之上。

结果后面的事情估计你已经知道了，2007年，后面的次贷产品都陷入了违约的狂潮，雷曼兄弟倒闭，"AIG"也成了现实。替无数次贷产品进行违约互换的AIG陷入了倒闭的边缘。最后没有办法，为了避免这种危机进一步扩散，美国政府出手救了AIG。

而在这个事情上，也引起了市场很大的反应，认为美国政府拿着纳税人的钱去救助华尔街这些贪婪无厌的人，还讽刺AIG是大而不倒（Too big to fail）。

# 今日概要：

1. 互换，它本质上就是一个取长补短的置换，让双方都受益；
2. 互换背后是有理论基础的，就是大卫·李嘉图的比较优势理论；
3. 互换跟所有的金融衍生品一样，也是一个双刃剑，在把风险进行转移和重新分配的同时，也可能造成新的风险点。
