# 095 | 本周问答：中小股东的实际权利有多少？

你好，欢迎来到青帅的大北金融课。

这一周的课程我们主要围绕着股票的权利和义务在给你讲解。所以今天的问答，我也是挑选了其中比较有代表性的相关内容。

“分红权”和“投票权”虽然是股票的天然属性，但他们有时分红可不是管理层决定的，你们还问到，是不是会分红包股或者期股？强制规定？到后面中小股东是不是还得向大股东进行妥协，让渡表决权？

**青帅**

这个问题是一个好问题，它牵涉到名义上的权利和实际的中间，区别很大。

首先我要明白，投票权并不意味着决策权。就像我们在课程里提到的，小股东的投票权对公司的决策并没有太大作用。因为大多数的时候大家并不具备足够的信息做判断。或者说即使你有一些信息，你的观点也很难得到大多数其他股东的支持。所以实际上生活中主要是股东大会议或者几个大股东管理层共同决策。

那么分红权是什么呢？理论上，分红是由董事会提出，然后由股东大会通过。但是因为是管理层一般必须要强制全的，所以管理层，也就是“董小姐”具有很大的权力。对于中小股东来说并不是投票表决权，而中小股东的表决权又占多数，不能够影响决策。

其实中国的企业原来是不太爱分红的。后来监管为了改变这个局面就进行鼓励，国资委规定国企必须强制全分红，你看，几大行的分红比例都很高。很多投资者都认为强制分红是保护中小投资者利益的，这个其实并不是一定的，如果企业所在的行业投资机会比较多，企业分红完了，你的投资资金是空的，你还需要用更高的成本去融资，所以可能反而是得不偿失的。

那么具体到格力这次的这个不分红事件，其实不同的观点也是很多。格力管理层如果不全分红，然后拿着钱去一个不成熟的行业，比如说芯片，可是会很亏害中国大企业的，因为芯片是大投入，研发周期很长，所以在五年之内大可能是看不到回报的，对于没有行业基础的企业来说，就是打水漂。

如果像董小姐是暂时不分红，也是考虑到存钱是要应对2018年的宏观紧缩的环境。甚至拿着一部分投资，比如会增加一点风险，做一个高一点的投资，甚至去贷款，协议存款。那可能在现在的宏观环境下对格力股东都是有利的。所以这次不分红和立场不一定都是错误的，最对于格力不分红的市场反应也有可能也是错误的解读。

青帅老师，实行双重股权结构，其中最重要一点就是能够最大化的创始人团队的持续创新，长远只考虑公司发展做强，所以我觉得国内京东和搜狐股权架构是最早的，现在花旗两家公司可以参考国外的相关经验，我们有一帮朋友。

我们国内来说，金融都是全部不拥有很大的话语权，那么在中国是否能在所有都是一个非常重要的通过，那么机构有决定上市或保留一个的情况下，那么确保上市也不会让投票权大的投票都相关的利益集团利用矛盾呢？

**青帅**

Alex同学的想法很好，也是很实际的。现实生活中双实股可能会产生少数人或者创始团队牢牢控制公司控制权的情况。

这种情况一定是好事，会损害中小股东的利益吗？其实未必见得。你看AB股制度，它其实从最初设立的时候中保护投资者的利益，它是为了防止门外的野盲人争夺取控制权的。那么门外的野蛮人攫取了吗？控制权力以后是一定会有利于公司的？答案是未必见得。资本运作的能力和企业管理的能力是两种能力，门口的野蛮人有可能能够很好地经营好公司运作，但不一定能够把公司经营得更好，所以在这种情况下，创始人团队保护好他的控制权，不见得对企业是个坏事。

第二条就是对企业来说，特别是对创始人股东而言，企业就像自己的孩子，你要比别人爱护得多一点，因为对于公司最大了，最后感情中，也最容易把公司当成家。所以有中小投资者而言，买入这样的公司，反而可能是一种比较不错的选择。而且就像企业课程里讲过的，我们看看全球范围内的公司治理框架，大多数国家和公司都是大股东投票，也包括了家族企业为主的。只有英美类的以经理人制度，所以家族控制、创始人控制未必一定全是坏事。

这种做法已经存在很久了，现在还在进行过程中。所以存在也是有自己的合理性的。

保护中小股东的权益还没有更好的方法或者途径？不知道你们国家在这方有什么制度保障，又经历了怎么样的政策变化？

**青帅**

这个问题其实要从几个维度来思考。

第一方面从法律上看，我们国家保护中小投资者的立法体系实际上已经是很完善了。首先是它是公司法，证券法为核心的，另外还有上市公司，公司的信息披露要求，这种保护中小投资者相关的法律都全，从立法上看，我们已经相当完善。

另一方面是这个完整、完全的立法体系，但是看上去市场上对中小投资者的保护显得有些力，为什么呢？有两个原因：

+   * 第一，虽然立法是完善，但是法律的解释权，执法的力度变小，比如最常见刑《公司法》，《证券法》里面，内幕交易最高也就判十年，并处罚违法所得以下的罚金，这种力度在比较外有很多，国外对于这种内幕交易，有非常处天额的罚金，而目前很多城市罚款入等，所以对犯罪没有起到足够的震慑作用。

+   * 第二点是跟我们的法律体系有关，对证券市场来说，目前主要以行政监管为主，比如说市场准入，罚款等，它缺乏民事诉讼。没有民事诉讼意味着什么？就是没有让犯罪为陷入人民战争的汪洋大海。

但是近年来这个现象有所改变，像2017年在起诉索求违法事件上启动了民事诉。如果这个方法能够坚持下去，同时加强市场机构的监督，加强投资者的教育，我想未来的中小投资保护应该会做得更好。

老师，京东方有个A/B股，什么是B股？

**青帅**

其实B股是一个非常有中国特色的金融创新。它的典型形式也是中国最早资本市场而新的一种交易股。B股不是人民币境内种股权，它是一个以外币交易的境内股。在2001年之前只外股，外国公民或者在一些个之前，这个B股和A股市场的A股是相对的，A股是以人民币交易境内股，而B股是以外币交易的境内股。

B股的出现是基于什么理由呢？基于要引进外资这个理由。七十年代的时候，我们改革开放，中国的外贸方式是采取旧制度和实用投资的外方。九十年代以后我们需要靠吸引外资加快规模，所以就顺势使用股权投资的方式来引进资继续建设，所以就开始产生了B股这种专为外国投资者设计的人民币币、外币交易的证券投资。

当时上海和模实发行到了B股，那是中国第一条B股。这个模式在当时被寄予厚望，希望成为国际融资港的一个渠道。但是到了1993年以后，我们国家境内的企业开始去香港上市融资，这就是H股。又创约去融资（N股），然后到新加坡去融资（S股），到伦敦，到全球的各个资本市场去融资。
