# ### 第一天：你的个人信用，很值钱！

第一天，我给你介绍了是个人的信用杠杆，一个人的信用是可以资本化的，一个人的信用越高，他的承诺、价值就越高，这也是信用市场千金的金融逻辑。咱们中国的信用市场从鸦片战争以来发展滞后，主要的原因就是很完备的法律制度体系，完整及时的信 息披露和科学的信用评价体系。

![](bbox=[0.1, 0.48, 0.9, 0.58])

但是，从近些年的发展来看，中国的个人信用资本化的趋势是不可逆转的，因为生活场 景和移动互联网日益经是常化的现象，政府和互联网巨头合作去发展信用，这种感 觉机制的运行效率大大地提高了。

# ### 第二天：为什么总是说“中小企业融资难”？

第二天，我给你介绍了企业的信用杠杆。在世界范围的看，普遍存在着中小企业资 融资难的现象，这一问题的主要根源在于 中小企业的资信差，能够拿出来的抵押品 少。

![](bbox=[0.1, 0.91, 0.9, 0.98])

美国通过过板级市场，德国通过构建多层 级的地方体系来解决这一问题。目前，中 国的银行体系也在解决这一问题上进行 了有益实践。比如说浙江的泰隆银行， 就在中小企业金融方面做得非常好， 但中小企业融资难还 的货款额很少。但是能够准确地把握企业的经营状况，坏账率非常 低。
