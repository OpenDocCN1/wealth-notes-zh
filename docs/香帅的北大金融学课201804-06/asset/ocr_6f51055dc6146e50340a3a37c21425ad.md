# 072 | 为什么总是说“中小企業融资难”？

你好，欢迎来到青年的北大金融课堂。

很多人都听说过一句话，叫做“中小企业融资难”，也就是中小企业很难顺利地运用自己的信用杠杆。这句话在媒体上、政府报告里面出现的频率特别高。但是很多人都会有点迷惑，全国在高呼“双创”（创业创新），初创企业不应该拿钱很容易的吗？

很多人其实将初创企业，尤其是一线城市里形形色色的这些互联网企业当中中小企业的代表看，这个角度到还是很大的。在中国地三句、长三句都贴着大字的中国特色的中小企业。它没有“互联网”概念的加持，也很难在媒体上曝光。然而它们才是“Made in China”的核心力量。但它们也确确实实面临着融资难的问题。

# 一、信用与抵押：中小企业融资的困境

中小企业融资难这个问题，其实是中国独有的，而且是个世界性的难题。为什么呢？一般来说，企业的债务融资无非就是两种，发行债券，或者从银行拿贷款。

作为企业信用杠杆最大的场景，企业发债券的时候要用到企业的信用背书（抵押）。所以你会发现，全球的企业债市场都以大企业为主，亚马逊、麦当劳、华为、这些企业的股票容易交易。而中国的小老板，在这个市场上就很难取得一席之地，因为他们的风险很高，风险敞口也比较弱，要同时取得信用和债券市场这么多年投资者，成本会过高。所以，发债对于中小企业是相对困难的。

那么银行贷款是不是好一些呢？你不需要那么多的投资者，只要取得银行就足够了。但你再从那银行的视角来看，它花大量的时间、精力、人力地去调查一个客户的信用记录、经营情况。它的成本会过高，所以银行一般就采取简单的一刀切方法，押抵押品。抵押品中的房子、土地、机器、库存都可以拿来抵押。那么，万一企业破产的时候，损失就可以拿这些抵押品去拍卖，减少损失。抵押对银行来讲是一个成本相对较低的机制。

这个时期，很多中小企业就陷入了一个悖论中，贷款资金的常常是租房或买机器，如果资金资金不够的话，那不需要投资贷款了。在这种情况下，就引起了双方的纠纷，这个方案是一个均输，所以，无论发债还是银行贷款，对于中小企业都是难题。长三角信用，珠三角爱好，这种企业中间间民间借贷的存款规模，而这种企业在中国企业，在正说金融体系内缺乏融资渠道是有关的。

但民间借贷借利率高，中小企业就像很容易被裹挟的，只需要有行业动，比如政策变动，经济增长下滑，行业的变化，企业的资金链条就特别容易断裂，你经常看到的那些老板跑路新闻，其背后的根源就在于此。

# 二、中小企业融资难的破局之道

那中小企业融资难这个问题，到底有没有一定的解决办法呢？也是有的。美国与德国在中国中小企业融资上是做得不错的国家，但是它们采取的是不太一样的路子。

美国是债券市场企业的企业融资，在前面的课程里我们讲过，美国的创投，也就是高收益融资的市场，曾经为高校科研的小企业打开了一扇融资的大门，这个市场上的投资者追求高收益，也承担相对高的高的风险。中国也有类似于中小企业融资市场，但是主体上在美国对债券市场的深度不够，企业的信用建设这一业务没有发展起来，所以这个市场也没有起到特别大的作用。

所以，德国的经验对我们就比较重要了。德国跟我们一样，是以银行为主的金融体系。但是对于银行体系里非银行层级的，大银行对应大型企业，小型银行对应中型企业，小型银行对应当地地的小企业。这种结构能够很好地解决信息不对称问题。

举个很有意思的例子，咱们中国的金融体系是以四行为主的，是一个垂直型的结构。我们在90年代的时候，买断式剥掉中央银行权利，他就只保留了4家地方性的民营银行，其中有一家叫泰隆银行。

我们在北方的一个调研课程中发现，这家银行的中小企业业务，尤其是那些民营的中小企业融资业务做得到好，它们的金融，几万亿、十几亿的贷款额都能。而且利率很低。那么它们到底是做什么的呢？我们在调研的过程中就发现，就是“小米加步枪”的模式：比如你开一个超市，去银行里申请贷款，银行不看你的报表，因为小地方小企业的报表，作假的空间非常大，他会派几个信贷员到你的店铺蹲点，记录超市每天的客流量，平时到最近的消费趋势，仔细追踪，有几个月之后，很多的信息就非他清楚了。对一个欺诈的信贷员来说，非他每天来我这个群体来演戏，这个可能性是很低的。这样一来以后，有贷款对于自己当他的贷款客户而言是一个非常精准的数据，就筛选出了真正比较踏实、有潜力的企业。

其实泰隆银行的这个生存之道印证了德国经验的，当地的银行信息与当地的中小企业融资，大大降低了信贷交易成本。这也是我们需要发展多层次的资本市场的一个重要目的。

# 三、新技术的革命

除了这种发展多层次的资本市场的传统思路以外，其实有一个趋势是你需要注意的，就是这几年，一些技术对于中小企业融资的改造是很大的。比如京东的小农贷，它以平台自己平台上的商家进行融资，它根据商家的销售额、消费品的价格、商品的丰富度等指标来发放贷款的。一般贷款的上限大概是200万，最长期限是12个月。由于京东的数据最都是长年在京东的平台上的，完全可以直接地依赖押押这些贷款的安全，所以也不需要抵押品，就直接发放信用贷。阿里的蚂蚁金服也是同样的套路，用这些年沉淀的数据，对自己的平台上和相关平台的商家发放信用贷。

所谓大数据改变金融模式，在这些例子上是显而易见的，它们的信息搜集和下沉化的贷款使得贷款的利息都收集信息整理工作变得高效和便利，信息的成本下降得非常好。一笔几万块钱的贷款，蚂蚁金服的平均成本大概是2.3元，而同等金额的传统银行的成本大约2000元以上，此外，这样发放贷款的可能性很低，所以坏账成本也会下降。

我在蚂蚁金服调研的时候，听过一个案例，就是很有感触。当时他们考虑给淘宝商家发放的贷款，需要一套评估体系来判断不同商家的还款适合度。在经过多次的数据分析中，他们发现，传统银行贷款模型中，很多变量都不适用，一个很“淘宝”的变量居然浮了出来：商铺被顾客的回访速度，可以特别精确地预测坏账率。

这个结果很出人意料，但是对于一个淘宝重度用户来说，这一点都不奇怪。我当时马上就想明白，淘宝商家一般来说客单比较高的，用户的回单率也肯定是很高的。再仔细一想，在经济学家的思维上是完全符合逻辑的，网上的商家面对的互联网竞争很厉害，最大的投入就是人力资本的投入。一个店铺他的回头客越多，就意味着他的投入资本投入是特别高，这生意的质量就是比较好的，所以违约率比较低，完全是可能的。

现在，各大互联网平台都在争取金融牌照，想想自己平台上的企业做资融资业务，像滴滴就发行了一条供应商融资的金融产品，给滴滴的公司放贷款等。这些业务的思想都是一样的，都是用互联网平台沉淀数据的信息，将这个市场上信息不对称得到最底的信息，而信息不对称正是金融行业的最本质特征之一。
