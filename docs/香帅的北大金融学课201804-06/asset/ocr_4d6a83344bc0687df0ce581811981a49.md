# ## 第二天：股与债到底有什么不同？

第二天，我又给你讲了股票和债券的区别和联系。股票和债券讲透，本质上就是信贷，代表的是金融的道德本位，也是它的道德权和风险是不一样的，股票代表的是剩余索取权，它一个风险比较大。所以股东更希望公司取得长足的发展。而债权代表的债权风险相对较小的，所以债权人会希望公司稳健地经营。正因为债权和债权有这样大的区别，所以在融资的时候要具体考虑自己项目的现金流和未来的风险，然后选择不同的融资模式。

# ## 第三天：关于资管新规的解读，其实你早就学过了

第三天，我利用前面的知识点帮助你解读了当前大热资管新义的话题，资管新规。首先，我带你回顾了几百我国的资管行业的现状，这个现状可以用我们前面讲到的，投化化的思维结构来解释。在资全面，我们的层现两家机构，然后在资管面，不断加层次，这两者加层次，就是我们国家的资管市场，在短短的几年内快速发展。

![](bbox=[0.2, 0.00175, 0.8, 0.0019])

另外，我们国家又有一个分业监管和分业监管的结构，在这个个结构体系中，以监管收益为目标的高杠杆的通道业务又迅速发展。所以造成了近年来，金融市场高风险事件频发局面。监管推出新的资管规的主要，就是针对这种局面，它就是要去通道业务，降低杠杆。

![](bbox=[0.15, 0.0020499999999999997, 0.85, 0.00225])

所以在这个一个大新规下，我要告诉你的就是，任何回报率超高的金融产品，基本上是陷阱。也就是说未来的几年中，金融业也会经历一次大失落的寒冬，我们的居民在进行财富管理的时候要记得捂好自己的钱袋子。
