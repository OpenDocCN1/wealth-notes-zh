# —— 学习方法和使用建议 ——

+   1.课程讲的结构是什么？

——课程的设置是由8个大板块，30次学习模块组成，每个模块下面大约有2-4周的内容。每个板块、模块其实都是相对独立又前后联系的，而每一周的内容也具有一定独立性。

+   2.要不要补之前的课？

——因为每周的内容是相对独立，新同学不妨跟着香帅的课程节奏，每天学习，将当期内容新学理解。然后每期课补学，第一周课程开始补，一边吸收新内容，一边学之前的课程，你会发现，其实所有课程穿起来像珠链，分开是一颗颗独立的珍珠。
