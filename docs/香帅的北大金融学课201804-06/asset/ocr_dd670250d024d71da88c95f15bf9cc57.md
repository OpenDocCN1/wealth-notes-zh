# 119 | 延展话题: 怎么给一个年轻的成长型企业估值?

你好，欢迎来到希帅的大金融金课堂。

好，这节课开头，我想跟大家分享一个真实的案例。2010年年底的时候，谷歌准备收购一个叫叫团网的互联网公司，所以这个公司的创始团队特别年轻，所以谷歌的议价能力价格就一路提高，最后甚至达到了60亿的价格。

但是在收购的最后关头，团购网里请了一些数据科学家来为它做估值，得出的结论是公司还有数十倍的增长空间。同时，华尔街，像摩根士丹利、高盛这些投行，也给出了它们对团购网的估值，高达200亿到300亿美金。

所以这个团队就拒绝了谷歌的收购，一年之后以100多亿美元的市值上市了。

但这件事最后的结局其实有点令人唏嘘，上市之后，团购的狂潮慢慢地退去了，它的股价也一路下滑，一年多之内跌去了差不多80%的市值。

那么我要分享这个案例呢？其实要说清一个很复杂的问题，就是说给一个年轻的互联网公司估值，其实是一件很难的事情。即使是数据科学家或者摩根士丹利这样的著名投行，有时候也会作出错误的估值。

但是，给年轻的公司估值又很重要，不能忽视。

比如说最近，我们A股市场就希望独立独角兽企业IPO，那么就给它们定出了一个合理的价格，那这些公司就特别难受了，估值低了，它们不愿意回来，中国股民的分享有像网景、腾讯这样典型成长型企业成长的代价，但是如果搞高了，A股的股民可能就当了接盘侠，被割了韭菜。

所以，怎么给一家运营历史很短，概念很新的年轻成长型公司估值定价呢？我们今天就来探讨这个问题。

# 一、通用的方式适合给这些企业估值么？

那些年轻的成长型企业，我们基本上可以把它划分为三个阶段：

+   - 第一个阶段，婴儿期，这个阶段企业没有收入，或者只有一个想法，所以公司极其脆弱。
- 第二个阶段，是一个成长期，这个时候公司基本上处于测试产品的起步阶段，一切都是试探和学习的阶段。
- 第三个阶段，年轻公司基本上完成了最起码的学习，有的会开始朝着盈利之路迈进。

但是，不管是哪个阶段，企业收入的增长都非常不稳定，波动性很大，不像那些成熟的公司，收入和盈利都处于一个稳态。
