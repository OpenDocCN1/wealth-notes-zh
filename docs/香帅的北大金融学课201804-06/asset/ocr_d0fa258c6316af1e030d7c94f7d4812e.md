# 088 | 股份制or合伙制，选哪个？

你好，欢迎来到青帅的北大金融学堂。

现在很多人都在创业，一个让很多企业创始人很懵的问题是：你注册公司的时候，到底该选“股份制公司”还是“合伙企业”？其实这个问题对企业未来的发展是至关重要的，对于保护创始人自己的权益也是至关重要的。今天我就给你讲清楚这个问题。

你如果去查股份制和合伙制的定义的话，你会发现这个定义特别地抽象。其实你可以忘掉那些非常详细的概念，股份制的合式制，都是“共同投资”的一种经济组织形式。股份制强调的是“投资入股”，合伙制则强调“共同经营”。

我们想象一下，股份制像朋友，这个关系可以密不了一点合伙制像夫妻，可是不爱你都要得在一个屋檐过日子。

了解了这种关系之后，现在我们再来考虑你创业的时候该选股份制还是合伙制。

# 一、创业初始你该选择合伙制还是股份制

假设你说你和你的两个朋友打算开一个汽车备件厂，那么想你，一个汽车备件厂，它主要是依靠机器和生产线，所以你经常需要资金，生产东西，然后经过规模化的经营降低成本，实现盈利。换句话说，公司的人力资本投入，比如说你的管理和固定资本投入，是可以分离的。那么在这种情况下，股份制就是比较理想的选择了。

因为你们三个人的资金是有限的，你需要不断地像外部炒你的资金，也就是吸股的资本部分吸股外来投资资金。但是，这些外部股东并不一定要参与你的企业管理，也就是我们平时所听说的，所有权和管理权可以适度分离。换句话说，股份就是你们团队的创意和能力资本在资金的结合点。股东不一定在意企业本身，而是在意这个企业带来的利润和收入。就像我们买股票的时候，我们在意关心的是股价涨不涨，而不是公司运营好不好。

但是，如果你们几个人决定要开一个会计师事务所，或者开一个律师事务所，那么无论这个办公室的装修，项目成员要交多少，主要依靠你几个人的业务水平的高低。

美国有个很著名的电视连续剧叫《诉讼双雄》，里面有个著名的律师叫Harvey，他一个人就接管了半个律所。那么在这样的企业里面，人力资本就处于绝对的核心位置了，企业的经营和人力资本是密不可分。那个时候，合伙制就是比较理想的选择了。

像那些专业都特别强的行业，很多都会采取合伙。除了律师和会计师事务所以外，早期顶级风险资本也是倾向于你个人能力和人际资源，所以像高盛、雷曼兄弟，当年采取的是合伙人制度，这样子可以将个人的无形资源留在企业里面。

所以，这里你可以得出一个结论，就是股份制是一种以财务为基础的经营模式，而合伙制是一种以人力资本为基础的经营模式。所以股份制可以比较适用于人力资本和固定资本可以分离的行业，而合伙制适用于人力资本占核心地位的行业。

# 二、企业做大后，合伙制和股份制利弊

刚才说的是创业之初的时候，你要根据行业来选择合伙制还是股份制，但是当你企业做到一定程度以后，你会发现，不管是股份制还是合伙制，你都会碰到问题。股份制是一种比较模式，让你资金和权益的股东，可以在这种模式下，你会发现，创始人团队非常容易失去控制权。

比如说你们的团队经过几轮的增资扩股，虽然企业规模做大了，但是你自己的股份可能也被稀释得很多，所以你自己的想法利益和大股东发生冲突，很有可能会你被迫迁出这个公司。

在股份制架构下，控股股东控制着董事会，董事会向团队上的事情也无从干涉。前两天，我们的市场上除了滴滴、快的以外，还有一个很有名的打车软件，叫做“易到”，它的创始人叫周航，他在滴滴、快的对抗的过程中，因为急于融资，就引进了“资资”这个股东，结果后来易到资金上的发展的发展，最后周航团队被替换，易到易到，等于是卖掉了自己自认弃大的孩子。

那相比而言，合伙制的关键权益始终是不让渡出去的，所以在这个过程之中，你可能不太会遇到丧失控制权的问题。

现在的创业团队通常会用合伙制来保持他们的控制。比如说阿里巴巴，前些年它经过了几轮融资以后，像软银和Yahoo的持股比例都已经大于马云团队。所以马云团队在当中已经成了小股东。那么在这控制架构中找一个角度，公司的控制权就面临着旁落的危险。所以从2010年开始，马云团队竟然地采取了合伙制，包括马云在内的18位创始人由创始人身份变成公司里巴系集合权的人，这样保证了自己对公司控制权。

那现在你可能会想，如果我是创始人，那我直接就用合伙制就好了。其实合伙制也有其自身的缺点，一个是合伙人的数量是有限的，所以当企业需要大资金的时候，合伙制的缺失就比较明显了。另一个是，合伙人的合伙人对企业负有无限责任，如果一旦出现危险的话，你连自己家里的都得搭进去。
