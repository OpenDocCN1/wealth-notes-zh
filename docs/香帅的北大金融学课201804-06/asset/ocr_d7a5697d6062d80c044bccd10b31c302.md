# 第一天：如何为“风险”定价

第一天，我告诉你，我们可以把风险拆解成系统风险和个体风险。这个归纳对于金融资产的定价是非常非常重要的，归属于公司的自己流动就是个体风险，比如乔布斯的过世。这就叫苹果公司的个体性风险。而全球智能手机行业的发展趋势，美联储的利率水平，全球市场的风险，是系统性风险。

![](bbox=[0.1, 0.56, 0.9, 0.63])

你看，这种个体风险，它是可以通过投资组合来进行分散的，而系统成风险则需要通过风险补偿。把风险拆解成系统性风险和个体性风险，是理解风险一个非常重要的步骤。为什么呢？因为只有正确的归类，才能作出正确的决策。

![](bbox=[0.1, 0.72, 0.9, 0.79])

# 第二天：“无风险资产”真的是无风险吗？

第二天，我给你的是无风险资产。无风险资产其实是一个虚拟基准，它的存在让不同的资产变得可比可加。

![](bbox=[0.1, 0.91, 0.9, 0.98])

在实践中，我们常用国债的收益率作为无风险收益率。但是实际上，国债并不是完全没风险的。现代社会的国债依然要承担着通胀风险、外汇风险、和一定程度的违约风险。

![](bbox=[0.1, 0.00106, 0.9, 0.00113])

# 第三天：风险资产面面观：股票、债券、房地产

第三天，我给你不同资产各大类风险特征梳理了一遍，简单地概括，就是三句话：

+   1. 债券的风险主要是经济周期和债务违约。
2. 股票的风险主要是行业选择和经营不善。
3. 房地产的风险主要是经济增长停滞和市场萧条。

# 第四天：中国股市大盘同涨同跌背后的秘密

第四天，其实是一个应用性的课程。我给你把第一天的课程知识解释了我们中国股市一个常见的现象，就是经常大盘经常同涨同跌。中国股市为什么经常会出现要么一片红，要么一片绿的景象呢？这是因为，我们的股市有更多的反映的是系统性风险，而不是公司特有的个体性风险。

![](bbox=[0.1, 0.00161, 0.9, 0.00175])

这背后的原因是因为中国的A股是次发达市场，对于投资者的保护不利，所以投资者对公司披露的信息并不信任，因而投资者会更多地受大盘影响。而这种同涨同跌的现象会影响股市的可定价效率低下，然后导致市场的过度波动。
