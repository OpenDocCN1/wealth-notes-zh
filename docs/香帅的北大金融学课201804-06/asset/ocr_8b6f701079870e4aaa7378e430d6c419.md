# 第一天：中小股东的利益被谁代表了？（上）

第一天，我给你介绍了关于股票的两种权利，它们分别是经济性权利和参与性权利，也就是平时你听到的收益权和投票权。

![](bbox=[0.1, 0.305, 0.9, 0.365])

但是在实践当中，你会发现，中小股东的参与性权利，也就是投票权，很有可能被稀释。为什么呢？首先，股份分散的公司中，缺乏一个有绝对选举权的大股东，所以这样的公司往往会有一些非常强势的管理层，管理层就会容易凌驾于股东大会之上，让中小股东的权利被蒙授权。另外，很多公司自己设定的双重股权结构本身规定了同股不同权，也就是投票权不同，把中小股东的投票权给稀释掉了。

![](bbox=[0.05, 0.44, 0.95, 0.485])

# 第二天：中小股东的利益被谁代表了？（下）

第二天，我给你讲的是在股权比较集中的情况下，大股东和中小股东中间，他们的利益冲突和困境到底是什么。一方面，你会发现，大股东拥有关注短期的长期延续性，而中小投资者更注重短期利润的股价。所以，从这个角度来说，中小股东的活话权被稀释也是有它的合理性的。

![](bbox=[0.05, 0.59, 0.95, 0.635])

但是，另一方面，大股东享有绝对权益之后，也有可能利用控制地位的行为对自己有利，而损害中小投资者的作为。从这个小方面来看，你就可以解释，为什么保护中小投资者利益是全球公司治理中的重中之重。

# 第三天：同股不同权：A股和H股的价差之谜

在接下来的第三天，我给大家讲解了在中国市场上一个独有的同股不同权的观念，也就是同一家上市公司，它的A股和H股中间，长期存在着价差，导致了同一家公司在不同市场上的实际收益率不同，也就是投资者获得的收益率是不一样的。

![](bbox=[0.05, 0.83, 0.95, 0.865])

有研究认为，这种价差是不同市场投资者的风险敏感系数不同导致的。我们认为A股市场（市场分割），外汇管制和所谓的有限套利、套利难，是A/H股价差长期存在的重要原因。A股越是牛市，A/H股的这种价差就越大。

![](bbox=[0.05, 0.905, 0.95, 0.935])

# 第四天：股权分置改革——中国股份制改革完结篇

第四天的延展话题，我延续了前两周的延展话题内容，给你介绍了中国证券市场你必须知道的第五个事实，也就是中国股权分置改革的历程和影响。

![](bbox=[0.05, 0.001045, 0.95, 0.00108])

二十世纪九十年代的时候，我们的股票市场实行双轨制，流通股股东用真金白银购买股票，非流通股是根植原有资产的市场化价格计算而成的。经过了2001年的国有股减持风波以后，证券市场选择折中路径的方式，促进政府决策最终在2005年拉开了序幕。通过非流通股股东向流通股股东支付一部分对价，换取上市与流通权的方式，对市场进行改造。这个改造，在2010年终于完成了。这个改造，你可以看作是中国A股市场一个里程碑式的大进步。

但是你也要看到，由于股权分置改革中，运用了大量的行政干预手段，以导致今天的A股市场存在着诸多非市场的扭曲现象。
