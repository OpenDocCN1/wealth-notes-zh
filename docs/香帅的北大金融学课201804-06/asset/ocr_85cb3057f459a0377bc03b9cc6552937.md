# 079 延展话题：为什么我不建议你投资债券？



你好，欢迎来到睿师的大北金融课。

这周我们从债券的角度重新理解了人类社会演进过程中的一些现象。我相信你的金融史大视野已经有了质的飞跃。

在今天的延展话题里，我想跟你讲一个更加实际的问题，也就是更多同学在留言区问的，个人投资者怎么办债券的投资。其实，我想跟你讲的是，从个人投资的角度来说，债券不算是理想的标的。为什么呢？有两个原因。

# 一、债券市场：机构化的金融市场

第一，中国的债券市场是一个高度机构化的，个人缺乏进入的渠道。咱们中国的债券市场，分两个部分，一个叫场内市场，一个叫场外市场。场内市场又叫交易所市场，就是咱们平时接触的上交所、深交所。它对散户（相对机构的）散户参与的可能性比较小，交易所的规则也比较简单，我们可以像买卖股票一样地买卖债券。可惜的是，这个市场上交易的债券只占整个债券市场不到5%的量，剩下的95%的债券都在银行间市场，也就是场外市场交易。

在前面的课程里，我告诉过你，场外市场是不对散户开放的机构间场，像银行这样的大型机构才是主要的玩家。有时候咱们一单买卖都是百亿的规模，根本不是我们散户可以参与的数字。从2017年的数据来看，债券市场，散户的比例不到0.1%，股票的散户比例是42%。这么大的差距就是由债券是一个机构化的场外市场为主的结构导致的。

# 二、为什么债券市场不适合散户投资者？

第二，除了场外市场咱们个人投资者进不去以外，债券本身也不是最适合散户的投资标的。其中最重要的一个问题，就是债券的流动性是比较差的。所谓流动性就是资金随支随取转换变现的能力，流动性差就寓意着你的金融资产出不出去。举个例子，一般来说，你可以理解的是，交易所股票的流动性最好，因为你可以随时找到买家。而债券，它的交易远不如股票频繁。

举个例子，我们经常时常用“换手率”，也就是衡量资产转手的频率来衡量金融资产的流动性。频率越高，就证明这个资产的流动性越好。

今年3月份我们有一家上市公司叫大发发电，今年3月份的股票换手率是6.76%，而同一家公司发行的债券的换手率是0.0042%，差300多倍。这是你在相对活跃的交易场所。

在银行间市场上，今年3月份有300只企业债，换手率都是0。有时候可能是好久没才一单买卖。所以说，如果你持有过债券，你会发现，你想买的时候找不到卖家，想买的时候找不到买家，万一碰到对手市，交易就更加稀缺了。比如说2011年的时候，中国发生过一次国债市无价市，当时整个债券市场一次价，处于一个无价无市的状态。你想想，那时候如果持有债券，想卖房，想换手，小楼价卖房，不要说你的债券买八折，估计直接要卖不出去。所以债券对流动性需求比较高的个人投资者而言，不算最佳选择。

除了流动性差以外，债券投资的逻辑是宏观投资的逻辑，这对个人投资者来说也是相对陌生的领域。在股票中，我们强调的是个价检验，这个价值投资的理念是什么？企业微观数据到细致的把握。对于企业，投资者可以通过研究研发，分析行业，了解竞争对手的种种微观信息来极具性分析。这种微观对冲对咱们个人而言却是容易的，但是债券的逻辑不一样，在上周五的课程里，我跟你讲过，债券的收益率是跟着利率走的，而利率的波动又跟宏观经济环境有很大关系。所以，债券投资考验的是宏观逻辑，需要投资者对宏观经济面有深入的把握。

很多人认为，债券同股票简单，其实债券投资对专业技能的要求要高得多，很多著名的对冲基金，像索罗斯，劳宾逊的老基金，这里要说的桥水基金，他们引以为傲的全球宏观策略就叫债券对冲策略的。所以说，“把握宏观基本面”这件事情是很复杂的，个人投资者缺乏这方面的训练。

有的同学不服气，说我其实对宏观经济基本面有很深刻的认识，我建议，不妨给自己做个小测试，每个季度预测一下你的CPI和PPI大概在什么水平。CPI和PPI分别是国际通用的物价和生产的价格的宏观指标，咱们的央行每个月都会公布。除非你能连续做约7次以外，每次预测的误差都在5%以上，否则很难证明你对宏观经济面有很深的认识。

在现实生活中，我们其实可以看到，宏观分析对大多数个人投资者而言，门槛都较高，比较难过。

# 三、个人投资者更好的选择是什么？

听到这里的时候，你可能就会感觉，那债券投资是不是个人投资者最合适的？也是这样的，要想参与债券投资可以买入债券基金，基金管理公司会帮你做宏观分析、做研究。而债券基金也避免了债券本身的流动性。

给你举个例子，比如说有一个叫“光大转债”的基金，它的波动很大。单年振幅达到5%，而换手率也很低，近几年，单季的换手率不足1%，也就是流动性很差。但是有一个债券基金叫“财立方安心固收债券”，它丰富了这一种。在这一年中，这个债券基金的波动率是那个单一债券的一小半，也只是到了2.5%，换手率大概在30%，是单只债券流动性的30倍。所以，你看，通过投资债券基金，你既投资了债券，又避免了债券本身流动性的一些缺点。

在美国市场上，个人投资者都通过基金来投资债券市场。但是，我们中国债券市场的情况比较特殊，我们的债券市场是不小的情况有7万亿左右，主要是中小类金融机构以及为企业融资的信用债规模很大，占到债券债的1/3左右。更重要的是，很多债券发行企业都是国企，地方政府隐性担保。那这种“刚性兑付”的问题，使得债券的信用债信息被低估，债券的收益率并不能够全面反映它在内的风险。

这几年，货币基金强盛崛起就分流了很多的中小投资者，为什么呢？因为债券基金的流动性比货基更好，风险不大，但是收益率却一点也不低。以2017年为例，债券的平均收益率是2%左右，货币基金却是3%，所以咱们投资者会选择货基。这几年债券在市场资产场的份额占了差不多一半，货基只有10%左右。

所以，在目前的管况下，我个人认为，债券对于个人投资者来评不是最理想的标的。

# 今日概要

# ■划重点

+   1. 中国的债券市场是一个机构投资者主导的市场，绝大部分的债券是在银行间市场上进行的；

+   2. 债券对于散户来评不是特别理想的投资标的。一方面债券的交易流动性非常差。另一方面，债券的收益考投资者的宏观分析能力，对于个人投资者而言，门槛是比较高的；

+   3. 个人投资者可以通过债券基金参与债券投资。但在中国债券市场存在刚性兑付，收益和风险不匹配的现象，参与价格限制不够，限制了投资者参与债券投资的热情。
