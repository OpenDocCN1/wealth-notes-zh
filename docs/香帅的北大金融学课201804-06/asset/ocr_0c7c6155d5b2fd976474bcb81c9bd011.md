# 113 | 风险资产面面观：股票、债权、房地产

你好，欢迎来到香帅的全大金融课。

有一句俗语，叫做“幸福的家庭都一个样，不幸的家庭各有各的不幸”。这句话其实放到咱们金融市场也是一样的。

昨天我们聊到了，无风险资产一般来讲就是指短期债券，而风险资产就是纷繁复杂的，有很多种。

那么从资产大类上来看呢？市场上主要有三种风险资产，债券、股票和房地产。

今天我要告诉你的，就是‘不幸家庭各自的不幸’，归纳这几类资产的风险特征。

在今天的课程里，你要记住三个词语，第一个叫“用+闲置”，第二个叫“行业+经营”，第三个叫“增长+衰落”。今天的课程是概览全，所以你一定要听仔细了。因为理解了这三个词以后，当你再看整个金融市场，你会发现，几乎所有的金融资产的风险都可以用这几个词语进行高度概括和浓缩。

# 一、股票的风险：行业+经营

# 1. 行业风险

什么叫行业风险？为什么行业风险会对股票这么重要呢？

我先给你举个故事，十九世纪的时候，美国的纽约市最大的支柱产业，你猜是什么？是冰块制造产业。当时纽约州特别适合，很方便制造。将冰切割包装以后运到美国的各城市餐厅、酒店、等着各种冷藏的地方，这个行业为纽约市创造了大量的就业，当时在整个行业、大大小小的冰厂星罗棋布。还有很多龙头的制冰企业，生产非常高质量的冰块，特别是那些高档的夜场所。比如说曼哈顿冰点Whisky，要显示格调，你可以要求配什么大瓶子的冰块的。这些公司的股票是当时资本市场的热点。

结果几年之后，形势急转直下。为什么呢？因为冰箱发明出来了，所以那些个冰块制造行业在几年之内就全完蛋了，不管是龙头型企业，是非龙头企业，哪怕你企业经营管理再好，都没有什么用处，因为整个行业都销声匿迹了。

这样的事件在股票市场上真的是随处可见。你可以问问自己的父母，很多人是九十年代的股票股民，那时候股民老百姓知道中国股市里有一个叱咤风云的股票，叫做“彩虹股份”，那就是股市的“蓝海科技”。当时不是“长虹”，还有一系列的电视机会是股票最有利的“风云英雄”，很多股民应该在这些股票上获利不少。

但是到了90年代末期以后，彩虹行业变成了一个夕阳西下的行业，那个时候你手里买任何彩虹的股票，估计大概就会再处于被套牢的状态了。这种行业风险对股票估值的影响是很特别的。

在一个夕阳行业里面，企业很难有很大的作为，市场也很容易给很高的估值水平，这也是我为什么一直强调金融是一口关于未来的学问，金融的定位、估值都是针对未来的，所以学会判断未来是学习金融的最重要的一个能力。

# 2. 经营及风险

好了，除了行业风险以外，股票的另外一个风险就是经营风险，也是企业也经营不善。

举个例子，随着中国的互联网基础设施的建设和中国中产社会的形成，网络的文娱行业肯定是这几年，以及未来很长一段时间内的热点产业。这个行业里面，一定会产生一些独狼企业。

比如说乐视，也曾经是大家一度特别看好的一个企业，被认为可能会成长为这个行业的龙头。但是它的管理思路当时的战略拉得太长，一直没有推出有力的“拳头产品”，形成稳定的现金流，面临着资金链断裂的风险。所以美好的愿景最后都化成了泡影。

所以说，在这么一个朝阳的行业里，如果经营不善，股票获客可能就完蛋了。莱斯斯，但是你经营不好，就只能落到现在这么一个迅速的边缘。所以“商场如战场”，就是这么残酷的。

怎么来判断一个企业的经营好坏呢？其实也是我这个课程的下一板块“公司决策”里面的一个主要内容。

# 二、债权的风险：违约+周期

好，说了股票，我们再来看另外一类资产，也就是比较熟悉的：债券。

债券的风险点就和股票完全不一样了。你看，因为债券是承诺给你固定回报的金融产品，不管企业经济效益好不好，也不用处于哪个行业，都得还本付息。所以，行业风险和经营风险对债券的影响没有那么大。

那它的风险主要来自哪里呢？来自“违约”和“周期”。

# 1. 违约风险

首先我们先来看违约。

昨天我说过，债券最大的不确定性就是来自于违约风险，也就是违约风险。如果无抵押发生的话，投资就会面临着血本无归的处境。违约风险是特别重要，也是你特别熟悉的一种风险。

# 2. 经济周期的风险

债券里面的另外一种风险就是被很多人忽略，其实是经济周期的风险。所谓经济周期，其实就是指经济的繁荣或者衰退。

为什么说经济周期是债券的风险点呢？在前面的课程里，我给你讲过，当经济正冷或过热的时候，央行会做下降或者上调市场上的利率水平，增加或者减少市场上的资金。市场上资金的宽松或者紧张，就会影响我们投资人的价格波动。

我曾经说过，债券不是最适合散户的投资，为什么呢？就是因为债券的价格风险，主要是对经济周期的判断，而投资者短期的判断其实是我们这一般投资者比较薄弱的环节。

但是今天，我其实还是可以给你一点小窍门，让你学着怎么去大体上看这个经济周期。

我们国家的经济周期其实就和货币供应量的关系特别紧密。所谓货币供应其实就是央行印了多少钞票，也就是平时你经常在媒体上听到的M0、M0这些都是名词。你可以把货币发行量想象成水。水量多，农作物就能够更好得被灌溉。然后丰收的概率就大。所以货币发行这个指标，通常就领先于经济周期。

那现在我们来它来做个分析，你可以在央行的网站上查到最近的货币量M2。然后你会发现，最近M2的数据比较低，也就是央行最近货币发行量很少，那就意味市场上水的少，可能会发生“旱灾”。所以2018年下半年，经济发生下行。

但是这里要注意了，正因为经济有下行的风险，所以央行就做出进一步“紧缩”的动作，反而可能会适度放松，放一点点水出来。所以从这个角度看，2018年下半年经济可能不太好，但是债券的风险反而也不会这么大。

这套逻辑说起来不是那么复杂，但是真正要做到宏观预测，其实需要更大量的数据，在更大整体均衡的框架下进行思考，不是那么容易的事情。

# 三、房地产的风险：增长+衰落

第三类风险资产就是大家特别关心，特别是熟悉的房地产了。在今天的中国，房地产是最主要的资产了。它的总量已经超过了股票、债券、理财产品、银行存款加起来的总和。在整个中国的居民财富中，它的占比达到了2/3以上。
