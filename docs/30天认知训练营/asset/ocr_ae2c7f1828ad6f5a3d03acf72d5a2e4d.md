# “阅读”其实是件逆天事

首先要说，读书没什么了不起的。

古今中外，人们都非常重视读书。“阅读是思想最早期之义肢”，这话出自法国哲学家法戈-拉尔若（Anne Fagot-Largeault）。思想必须要附着在什么东西上，要有外部工具辅助，阅读就是最突出的工具。

很深刻，但不对。比阅读更早的思想义肢是语言。

无论古希腊还是春秋战国，最古老的经典都是对话体。在文字和阅读普及之前，思想主要通过对诗和吟唱来表达和传承。《荷马史诗》口口相传数百年才记载下来。事实上，当书写刚开始普及时，苏格拉底非常不满意，他认为思想只有在对话之中才能层层递进到精妙之境，还认为书写将思想外置，败坏了思想者的头脑。他预言人的记忆力会因此下降。

+   小朋友获得阅读能力的过程分为三阶段：
- 第一阶段是图像识别，就是把词语当图像来识别。
- 第二阶段里的关键是养成“音素意识”，即认识到语音由最小的单位音素构成。
- 第三阶段，大量阅读练习后，人能快速、自动识别词语。大脑在阅读时作大量的并行计算，最终养成专门的阅读神经网络。
