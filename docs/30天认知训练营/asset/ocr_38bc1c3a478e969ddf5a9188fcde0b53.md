# 《30天认知训练营》学习指南

文/【得到】App团队

你好，欢迎来到《30天认知训练营》。你现在看到的这一课，是由财新传媒总编辑王烁，开设的大师课。

# | 这门课里有什么？

+   1. 30个认知训练

王烁会带你打破学科界限，每天探讨一个认知问题。内容涵盖一社会心理学、博弈论、进化论、政治、经济、哲学、历史、神经科学等各领域的前沿精华。

带你拓宽视野，学会技能，掌握思考的工具和方法。用多元思想，解答真实世界的难题。

+   2. 30本英文好书

30个认知训练的背后，是王烁为你精选的30本英文好书。选择标准是经典、前沿。其中部分书目还没有翻译成中文版，王烁都会为你深度解读。

需要强调的是，这不是一堂讲书的大师课。书是为你提供的延伸阅读，王烁会跳出书本，以他独特的洞察，带你掌握看世界的方法。

在大师课《发刊词 | 30天，完成一场认知升级》的最后，我们也附上了完整的书单，你可以去看看。

+   3. 模块化体系搭建

这门课分为以下五个模块，让你在学习的过程中，能更好地把相关的知识联系起来，搭建体系，学会迁移：

+   模块1. 旁透思考：理解人性、学会思考、升级你的世界观；
模块2. 方法工具：10个你用得上的技能，10种认知方法；
模块3. 思想实验：4个思想实验，打开你的脑洞；
模块4. 时代悖论：4个悖论问题，4场思维辩论；
模块5. 另类视角：7个另类视角，迭代你的已有认知。

# | 你可以怎样学？

+   1. 保持好奇：这是一堂成年人的自我博雅教育。你需要做的是，对各种领域的知识保持好奇，跟着王烁一起开拓视野。
2. 思考现实：课程中所关注和讨论的，都是现实世界的真实问题。建议你带着问题驱动，跟着王烁在好书中寻找智慧，再反过来照进现实，这样反复迭代。
3. 参与讨论：每一讲的最后，都留了一个思考题。欢迎你在文稿下方的留言区写下你的想法，和王烁交流，也和大家在讨论中进步。
4. 争取奖品：多多参与课程互动，你有机会获得价值498元一年的“财新通”账号。用这个账号，你可以获得财新传媒平台上全部的收费新闻内容，可以选择语音朗读，一键听新闻。

# | 大师课有哪些功能辅助你学习

+   1. 建立你的“知识账本”
（1）收藏内容：你可以点击页面最下方中间的“桃心”按钮，对喜欢的内容点赞，进行收藏。
（2）笔记记：读到好的内容，可以通过长按屏幕点击“笔记”，来记录你的学习感悟。同时，你可以把记录下来的笔记通过“加标签”进行分类，方便查找。
（3）以上内容，都可以通过点击App首页最下方中间的“知识账本”按钮，进入查看。
2. 分享给朋友，一起参与讨论
（1）分享干货文字：看到好方法、干货和金句，你可以长按屏幕并选中需要的文字，点击“分享”，就能生成金句卡片，分享给你的朋友。
（2）分享文章：大师课新增“阅读红包”功能。点击页面右下角“请朋友读”，你可以把喜欢的这节课分享给朋友，和他一起过论。有30个免费抢读名额，可以分享给30个朋友。
3. 用好播放器，让你的学习更高效
（1）在“倍速播放”功能中，我们提供了0.7倍速、1.25倍速、1.5倍速、2.0倍速、3.0倍速，你可以根据信息接受需要，用更少的时间听到更多的内容，节省时间。
（2）播放音频时，只要点击音频封面，就能跳转到相应音频内容的详情页面，操作起来更方便。
