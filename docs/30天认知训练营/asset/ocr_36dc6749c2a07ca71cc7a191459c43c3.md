# 18 如果你是黑帮，如何安全传递信号？

今天我们来做一个思维实验：怎样让大家知道你是黑帮，但又 Shat 是刚刚好，不会给警察证据把你抓进去？

这背后的灵感来源于一本奇书，《黑帮密码：罪犯如何传递信号》（Codes of the Underworld: How Criminals Communicate）。

标题中密码这个词的英语原文是code，是双关。密码是这个词，准则也是这个词，比如说荣誉准则，codes of honor。两个含义在这里融为一炉，表示黑帮传递的信号既是一种互相交流沟通的密码，又在传递一种他们内部的准则，很贴切也很巧妙。

这背后其实是在没有法律保护、没有制度支持、也没有信任基础的极端情形下，比如黑社会，怎样才能安全地传递可信的信息，实现沟通？

# 黑社会与黑社会电影

从黑社会讲起。黑社会之所以是黑社会，因为这个社会对内及对外传递信息的方式与正常社会不同：既要传递信息，又要信息保密。

黑社会面临个大难题：如何安全地传递可信的信息？

本书作者迪戈·甘贝塔（Diego Gambetta）是意大利社会学家，长期研究黑帮现象，将信号理论用于分析黑社会的信息传递、身份识别、“信任”机制。

# 黑帮的终极信号

在形形色色的信号中，信号理论建议，找到一种信号，它对发送信号的人来说成本不高，但对伪冒者来说成本极高，所以无法模仿。如果只有拥有某种特质的人才负担得起发送这个信号的代价，那么信号必然就是真实不掺假的，而接受信号的人可以完全放心。

黑帮的终极信号是投名状。

# 黑社会如何使用暴力

谈过投名状，再讲讲黑社会如何使用暴力。黑社会是使用暴力的生意组织，过度使用暴力对生意不利，很贵，风险大，引发社会不安，政府打击随之而来；但黑社会又必须使用暴力，否则叫啥黑社会。
