# 16 大数据会颠覆公共利益吗？

我今天想跟你讨论的话题是“大数据会颠覆公共利益吗？”

这个问题是受到了 Grün Book 的启发，来自诺贝尔经济学家得主梯若尔（Jean Tirole）的 新书《公共利益经济学》（Economics for the Common Good）。

# “无知之幕”与公共利益

什么是公共利益？

梯若尔没有下定义，只给出一个 Siri 式的回答：它是我们对社会的共同期望（our collective aspiration for society）。

> “假如不知道自己是男人还是女人，健康还是生病，富有还是贫穷，受到教育还是文盲，有无信仰， 生于城市还是乡村，追求事业成功还是生活自由，不知道所有这些，那么你希望自己生活在什么样的社会里？”

从保险说起。
