# 27 博弈策略 | 策略性发疯

今天从一个博弈情节讲起，叫“<|start|>ame of chicken”。

# 马路上的“傻夫游戏”

在中国各大城市的马路上，时时刻刻都在上演着这一幕：你在车道上好好的开着，旁边车道上又有车硬要挤进来。你让还是不让？

你当然不想让，但他既然干得出硬挤这事，当然也不想撤回去。让谁谁输。

这就是傻夫游戏。

最好是你不拐弯，对手拐弯，你是英雄，只有光荣，没有损伤；

# 谁比谁更疯狂

博弈论大家、诺贝尔奖得主纳什给你出主意：你抢先把方向盘拆下来，扔出窗外。

傻夫游戏极为常见。
——公路上别的车坚决要挤进来，你的车坚决不让道，这就是个傻夫游戏。

如果双方不约而同，同时扔掉方向盘，同时扔出来，那就是灾难。眼睁睁看着两车对撞，不死即伤。

# 混合策略：偶尔发点疯

傻夫游戏不仅在国家之间上演，在生活中更是无处不在。但凡狭路相逢勇者胜的时候，就有傻夫游戏的影子，但这个世界并没有因此变成疯子的天下，因为正常人还有一个逃生通道：随机发疯。

大体正常、随机疯狂，这件事博弈论上有一个术语，叫做混合策略。你不能不发疯，那样会被疯子吃死；你不能总发疯，天天对对碰，世界很快毁灭；你得偶尔疯一次。

# 帆船竞赛：必胜的策略

今天一路讲下来，我们更明白，一致性崇拜不仅错在会导向哲学上的悖谬，还在于它不懂得现实中随机的价值：随机发疯是我们免于被疯子统治的唯一一办法。

真正的智者拥抱混合策略。正如《了不起的盖茨比》作者菲茨杰拉德所说：“同时保有全然相反的两种观念，还能正常行事，是第一流智慧的标志。”
