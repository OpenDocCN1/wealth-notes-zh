# 928、做到极致，才是我们生存之本

学员：

文哥，昨天看电影《无双》，里面周润发演的画家讲了一句话，做 一件事就要做到极致，我当时就想起您说的话了，记忆特别深刻。

陈昌文：

我们一定要把小事做到极致，把一个小点，做到极致。做到极致， 才是我们生存之本。否则，毫无出路啊。
