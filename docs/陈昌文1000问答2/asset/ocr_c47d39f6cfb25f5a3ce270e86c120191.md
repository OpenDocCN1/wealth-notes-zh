# 820、别跟我扯什么商业模式

+   学员：

我想跟你探讨一下这个商业模式？

+   陈吕文：

一切商业模式，就是利润、成本的问题。

一切商业问题，就得找到买单快的问题。资本市场，最终的买单侠，是投资人。一般企业的买单侠，是普通消费者。企业对企业的买单侠，是另一个企业。

真想盈利，就是截拳道。直接让人买单。我们这些人，道行浅，别 跟我扯什么商业模式。有人买单，做好服务，做好产品，不坑人，做好 免责声明就行了。
