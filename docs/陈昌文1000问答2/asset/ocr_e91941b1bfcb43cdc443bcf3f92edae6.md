# 542、这几句话，是非常深刻的，能悟到的人，万里挑一

学员:

谢谢老大让我格局又一次提升，我虽然能力不如各位，论心胸，还 是有自信的。格局和境界到什么程度，财富就到什么程度。

陈昌文:

有什么样的格局、境界，就有什么样的财富。

德行壅驭财富，不多一分，也不少一分。人是境界越高，越有财富。 猥琐者，必定贫穷，聪明也无济于事，帮不了您什么。这几句话，是非 常深刻的，能悟到的人，万里挑一。
