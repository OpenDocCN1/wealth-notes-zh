# 梁宁亲述

第三模块的最后一节课，我来讲关键任务——穿越生死线。

这个话题是我和阿里巴巴管理HR的副总裁王民明确领导力的时候谈到的。我问王民说：“阿里巴巴怎么定义领导力？”

他说：“把握客观元素，把事情做成的能力。”接着他又说了一个很有趣的话题，阿里巴巴对领导力的定义就是带领大家穿越生死的能力。

在常态状态下，大家做流程、分工、项目进度、质量评估，这个叫项目管理。

但是，在面对巨大压力，甚至是生死存亡的时间点时，在一堆事情里找到关键任务，带领大家穿越生死，这个是领导力。

# 朝鲜商人的生死线

韩国作家崔仁浩写过一本小说叫《商道》，讲的是19世纪朝鲜时期商人林尚沃，从一无所有变成了富甲朝鲜九道的朝鲜首富的故事。

这本小说讲了林尚沃的三个节点，分别是：“死”、“鼎”、“成盏”。

我们来讲他的第一个节点：“死”，林尚沃遇到的第一个生死线就是一场商战。

当时朝鲜最有价值的商品是红参。林尚沃带商团到北京和大清商人在做交易时，遭到了清商的联合压价。清商希望成交价是70两白银。

林尚沃为了抓住价格，借款收购了朝鲜商团所有的人参，形成了垄断。清商商人就联合抵制，不降价他们就不买。

这时，林尚沃面对巨大的压力，他是借的款，所有的人参在他手上，如果人参卖不掉，贷款的利息他都还不起了。

这时他做了一个选择：烧人参。反正每天烧一点，如果没有人来买，我就把今年朝鲜的人参烧光，今年中国市场上就没有朝鲜人参了。

于是，清商的联盟就崩溃了，按照林尚沃的价格160两白银成交。

当时有人问林尚沃，你烧人参的时候，有没有想过人参都烧完了，还没有人找你买怎么办？

林尚沃说，“在我刚开始动手烧人参的时候，我就已经想到烧完了，如果所有的人参都烧完了，我就跳进汉江里自焚，和人参一起消失。”

这就是生死线，这就是别人不敢玩、不敢拼的风险，就是壁垒。在生死线之外是安全区，安全区是没有壁垒的。

# 腾讯用风控能力区分等级

腾讯的职级系统中，对不同级别员工的风控能力的描述很智慧。

+   普通员工，明确知晓常见风险。比如，别靠水太，游泳有风险。

+   项目经理，具备风险规避意识。比如，安排活动路线的时候，有危险的地方就放弃、绕过。

+   小盘生悟信十级，一瞬间消灭了，这叫不具备风险规避意识。

+   总监，有风险控制力。我有风险规避意识，明确知道长线风险。遇不过的时候，我知道该怎么组织大家，以及做好突发事件的预案。

+   总经理，能操作有风险的操作。常规水域安全但竞争激烈，能多少游。有个地方鱼很多，但是要穿过一片全浪高大的地方，我有本事跨越大海，带你们去资源丰富的地方打大鱼。

+   常言道，富贵险中求。

+   平平安安，顺应当当地的地方，一定早有人来到这里，趟平所有的坑，控制了核心资源，并下定了有利于他自己的规则。

+   平原地带的竞争，一定是体量大的赢，先到的赢，不要命的赢。

# 傅盛带领金山，跨越生死线

刚才讲了一个小小说里朝鲜商人的故事，我再分享一个我身边朋友的故事。傅盛和他的猎豹的故事。

在第二个模块讲“点线面体”的时候，我讲了周鸿祎如何利用互联网思维杀入了杀毒市场，并且一举占领了杀毒市场大概90%的市场份额。

当时杀毒市场里都有谁？老大是瑞星，还有江民、金山。

瑞星、金山、江民这三家都是在杀毒这种点状市场里竞争，大家都是一条连着的曲线，线性发展了很多年。突然冒出360的降维打击，它们就遭遇了非连续，原来的线性发展无法延续。瑞星、江民持续了十年的线性发展到此处戛然而止。而金山跨越了非连续，也就是说它穿过了生死线。
