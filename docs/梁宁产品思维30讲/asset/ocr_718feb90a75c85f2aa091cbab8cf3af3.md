# 攻略二：完成作业，与梁宁交流产品问题

+   1. 写作业：每一讲的最后，梁宁都会留下一个和今天课程相关的作业，点击文稿下方的“写留言”，留下你的作业。学而时习之，每天逐步提高。

+   2. 提问题：每个人都会有具体的产品困惑或感受，非常希望你能把真实想法、具体产品问题，在文稿下方的“写留言”写下来，向梁宁提问或交流想法，这也是对这门课最好的反馈。

+   3. 做互动：真实的产品问题、细致的体验分析、独到的见解，都有机会被梁宁挑选出来，在直播和“驻场问答”中做深入解答。

+   4. 有奖品：贡献优秀互动的用户，有机会获得课程独家配套的“产品54个核心概念词扑克牌”周边商品。
