# 职场霸凌

国外的学术界对于“职场霸凌”，通过5个特征来定义：

+   1. 被霸凌的人遭到了语言、身体等方面的消极行为，比如上面所说的“被推操”，当然还包括“语言暴力”，比如被当众羞辱、工作价值被贬低等等；

+   2. 霸凌的行为不是偶然的，而是持续的。有海外学者给了一个标准，就是每周至少一次，持续6个月以上。学者们说的这一条很重要，因为它可以把职业霸凌和一次性冲突和偶然冲突区分开来；

+   3. 被霸凌的人自认为力量弱且没有防备的能力，这一条是很有趣的、不仅仅包括上级对下级，有时在同级之间、仅仅对上级之间，也会存在霸凌行为；

+   4. 这条最有趣，就是被霸凌的人一定要自己觉得是被霸凌了。不要忘了，在中国的职场社会里，有时被领导骂，不会被认为是一种侮辱，反而认为是与领导关系亲近的表现。
