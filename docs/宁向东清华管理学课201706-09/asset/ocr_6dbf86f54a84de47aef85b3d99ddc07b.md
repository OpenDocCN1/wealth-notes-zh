# 1.领导者是否有权选择团队成员

所有的团队，都有三个特征：第一，成员不止两个人，无论哪一位团队，高层成员是基层，都会选择干部职员；第二，团队要完成一个共同的目标，团队的每一个成员在心里都应该有这样一个目标；第三，团队成员要协作，通过互动，实现这个目标。

万丈高楼平地起。要想建立一个有效的团队，选择合适的成员是非常重要的。团队的领导必须要有所了解和调整成员的权力，否则，你就会有风险打造出一支有战斗力的团队。开讲座有几天，有一位同学留言，大意是：他是科长，下面有三个成员，两个是老关系户，一个是不能干活的。细节就不记录了。大意是这样。这位同学请教我怎么办，如何才能破局而出。

对于这个问题，我当时没有回答。因为这位同学根本就没有看清他所面临的管理的局面，他所谓的这个“一个老关系户”的局面，但实际上，他的局是领导和下属的局，是相互影响的局。团队的行为了什么，怎样不能干事情，领导要保级他们的利益，直接领导根本就没有办法调动他。他所谓的这两个成员关系户，这位同学所面对的根本就不是一个团队管理的问题。

在我看来，要打造一个有效的团队，领导者必须选择权拥有选择、指导、甚至调整团队成员的权力。我这样认为，领导的一个基本功，就是要学会选择合适的团队成员。如果做不到，团队整合后面一系列团队建设的措施根本都落不上。

# 2.三种人不能入选

该如何选择团队成员呢？德才兼备的老话，我就不再说了。可是，人无完人，哪有那么多可选拔的优秀者来帮你领导呢？所以，现实的原则是尽量不做什么领导，在用的过程中逐渐来淘汰。不过，有对于团队杀伤力是较大的，绝对不能用。

第一种，个性不健康的，不能用。这是一种，也是极其糟糕的人的续写，或者个性的原因，很难与他人合作，任何问题都不是简单地归结于“外控型人格”，而是全盘归咎于别人，一控型人格。这种人的最大危害是，他不断地喜欢诋毁是非。这种人会给一个他放错组织中的位置。我过去在做国企的时候，经历过不少这种人的事情。非常有意思，他能把这样的人安排在任何一个位置，他也会把他自己的位置带坏，把所有人的情绪都带个心情。这个人，在适当的机会必须请他离开。即使走不了，也要给他设定一个部门。这种人放在任何一个团队中，都会坏事。

第二种，态度不认真的，不能用。我发现在这个中端，最后能够留下来的，都有一个共同的特点：态度认真。我最近在带同学们读《博弈论》。说心里话，学起来很复杂，我觉得有必要把这本书推荐给同学们，甚至，我也希望你有机会读读。但是，你看看到后期他也遇到问题，每次做事的时候，你就知道他解决问题的方法。比如，马化腾一直在坚持，在寻找。我到他那边的时候，看到这个谜团，然后我大概的问到了一些“中”字，写“坚韧”的“韧”，这是一个创客态度坚定的，还记得我们在创业领导力那一讲中分享过的“未来”那首吗？

也许你觉得马化腾是创业中的领导者，但他不一样。其实，普通团队也领导，也态度问题的。今天讲座，开了一次关于写态度的分享，我非常喜欢，分享给你，希望你阅读中能够对“态度”这个抽象的东西多一点理解。

第三种，做事不职业的，不能用。我举个例子，你大概能猜出什么不职业。有一种人会开会，永远是挑问题；同样的问题，这次会议说，下次会议说，今年的会议说，明年的会。他永远没有解决问题的办法，他会说，他没有说，怎样能够解决，他永远都不会说。这就是不职业。什么职业呢？在我看来，职业就是解决问题。不职业的问题，职业能够解决问题的问题。不职业的人，自己不会成长，对于团队提升也很少有帮助，所以，这种人是我最讨厌的类型。

以上这三种人，我建议你每一个领导者都要对它们有清晰的认知。否则你会发现为你，你选不出好的，那不是，而是你永远是团队建设中的阻力，阻力。那，我说了“万丈高楼平地起”，如果说，这类型的人，是你要团队带来的一定障碍，你今天，如果知道了这三种人，你该努力为基础管理创造一个他们可以选人权，权力。如果希望组织下属领导者承担，会必须要给他选人的权力。责任永远要权力，否则，你没有理由要求他。

# 3.蠢不禁

让团队成员出局，是一个很难的制度安排，但是，却属于组织的百年大计，非常重要。韦东奇对创业有了很深的关系，包括，他的果农应该有很深的关系。记得有一次，于东宁高韦东奇有一个对话，于东问韦东奇，你真的是会每回给宁高10%的员工？韦东奇没有回答，宁高，他问于东奇：你真的是想要一个优秀的公司吗？

我把这个细节摘出来，韦东奇上任之后，通过事情涉及很多领域，有业务不赚钱，韦东奇把鲁克前来问计，德鲁克对于韦东奇提，这些业务，如果你想让，你这些糟糕的，你还会投资吗？韦东奇立刻得到启发，这就是经济学上所谓的“沉没成本”的概念。

什么是“沉没成本”呢？

企业的层面，如即将出售房产还可以收回来的部分，就是“沉没成本”。“沉没成本”只有过去，与未来的资源安排没有关系。

而未来的资源是什么？就是分出去了，那以收回来的部分，那一小部分是你今天的决策有关。所以，韦东奇为整个通用电器集团的业做了一个大框架，就是每个业务单元分别投资。从投资回报率上考虑业务价值。每一个业务单元，只要不低在行业里排名前三名，韦东奇就会把整个业务出售掉。在用人上，业务板块的负责人有绝对权力，通用电器每年的人员淘汰率都会在10%左右。

在削减业务和人方面，韦东奇确实狠。江湖上有句名言，叫做“慈不掌兵”。这句话，我特别理解，但是自己不好。带团队，“慈不掌兵”是一个重要的原则，为了创造高效率的团队，最基础的工作是请走不合适的人。当然，要人。可是，我们必须认识到，不是所有的都通过培养来调整；对于上所述三种人，我觉得要坚决开掉，除非像韦东奇所说，你只要需要一个优秀的企业。
