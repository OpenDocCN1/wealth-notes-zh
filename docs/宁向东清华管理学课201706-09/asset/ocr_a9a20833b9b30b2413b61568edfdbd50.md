# 040讲：中层领导力 | “画圆”的艺术

你好，欢迎回到《宁向东的清华管理学课》。

今天我们讨论中层管理者的领导力。管理者的技能一共有三套：技术性能力、人际能力概念性能力。三者，不同领导的层职不同，对这些技能的要求也不一样。

# 1. 能力跃迁

我先给你讲一个电影——《兵临城下》，就是那个狙击手 瓦西里的故事。

瓦西里是德军狙击手，具备的均是技术性能力；政委是中层领导者，具备的是人性能力；而游击队长作为战区的领导者，他具备的是概念性能力。

![](bbox=[0.2, 0.35, 0.8, 0.45])

以上是一个例子，用专业语言来说，“技术性能力”，就是一个人完成某一项特定工作的能力，也必须具备完成该任务相关的操作能力。比如说，餐馆要求你开火、会炒菜，就是一种技术性能力。所以，任何一位员工都应该具备技术性能力，任何中层管理者其实都应该从这种能力起步。

可是当你工作到一定时间以后，你的技术性能力，表现得比较出色的话，你的上级可能会提拔你，你可能会做组长、主管，或者领班长。比如说，餐馆要求你开火、会炒菜，就是一种技术性能力。而对你最重要的还是技术能力，就像瓦西里一样，最重要的能力就是打枪。后来有人跟着他打枪，他是班头，同时他也是一个基层的骨干。

因为你在一线，从事的还是原来工作，所不同的就是，你除了管自己之外，还要承担带任务。 解决难题，在管理学里叫任务能力，这时候，你，不管是被定义为基层管理者，还是中基层管理者，算是最低一级的，“中层管理者”， 因为你要开始带人，瓦西里其实以后肯定是要当更多的领导的。

不过，成为基层的领导者，技术性能力依然是最重要的，但你可以尝试培养自己的“人性能力”。  一个人的人性能力，有专业的语言说，就是跟他人进行沟通、协调、组织协作的能力。  又可以细分为纵向能力和横向能力：

+   - 纵向能力是上下级沟通的能力
- 横向能力是同级协同各部门的人的能力

它们有一点区别，当你在基层岗位的时候，纵向的人性能力可能使用得比较多；但是，你往上去，真正成为一个中、高层领导者的时候，横向的人际能力就变得更加重要了。

在一个企业里，中是领导是最常见的，因为他常常处在矛盾的焦点之中。对，你要承担任务，不能找各种借口来为自己兜不住去推脱， 能看得见问题的困难，不能断对，对中层，领导者要解决各种复杂的业务问题，甚至有时候还要代人受过。横向，你可沟通，因为搞坏了关系，问题实际向上级汇报， 反而汇报了。

我们在深入解析中层领导力之前，先讨论“概念能力”。

我们为什么把它放到最后讲？我认为对于一个人，概念能力是最重要的。中、高层领导者去比较概念能力，  因为对于中层来说，它最复杂，最难，它需要的是概念思维能力，对概念、逻辑、抽象能力。

那么，到底是什么概念能力呢？我把它分成两个：  一个是综合分析能力， 一个是预见能力。

# 2. 画圆和摆圆

我想象，一个最好的组织中，高层、中层和员工，他们应该是怎么个关系呢？ 他们就像是三个同心圆， 高层是圆心，中层是中，员工是外。  中层处于中间，帮助领导放大这个圆，这样组织才成。  要把高层领导者明确的长期目标转化为可以行动方案，让基层员工长期行动的员工。

![](bbox=[0.2, 0.0012, 0.8, 0.0013])

同心圆是个理想的情况，但现实中的这三个圆是什么样子呢？它们不是完全同心， 而是各自独立的， 或者说是一个个独立的同心圆， 只是相互交叉着。  高层有自己的圆， 中层有中层圆，  基层员工有基层员工的圆。  中层实际上处于一个交叉的位置，它既要对上，又要对下，又要对横向的部门。 所以，中层实际上是处在三个圆的交叉处， 它要理解上级圆的意图，又要理解横向圆的相关部门的工作，  还要理解下层圆的工作。

下面，我简单和你分享一下画圆的一些体会：

# 宁向东

+   - 首先，我建议你要建立“平衡点”意识，要学会通过平衡点，去尽可能地把纵向的三个圆画在一起。

在实际的组织里面，都是高层要承担多责任，中层管理者的责是高的工作。很多时候管理者是接到任务之后，他会下意识地把这个任务直接交代下属去完成，这就缺少了一个“平衡点”。  我讲完了，实际上，中层领导者是承接任务的人，  他需要“摆”  不是你一个人的组织、全家都是的身边人，  而是所有组织的全部、所有的。  这是你，你的任务，  任务是你组织的，  你的工作、你的责任，   而不是你的下属的工作、责任，  你的下属不会责怪你下面的兄弟，首先会怪罪你。

所以，中层管理者上任的第一天，就要在心理画像这三个圆。  高层的圆，自己的圆，  以及下面兄弟们的圆。  你想明白这些圆的位置关系，  为什么有的动作需要事先决定，  任务来了之后，  你要在需求决定之前，  第一步要想的，  就是如何在这个任务下面把一个圆画成一个圆。  通过下面协调不同的同心圆的圆，  让三个圆之间交叉的面积大。  你要去想怎么能够做到老板满意，  兄弟满意，  下边要说到这三点是一体的。  老板满意，  兄弟满意，  才是你。  任何人一输，  最后可能都是你输了。
