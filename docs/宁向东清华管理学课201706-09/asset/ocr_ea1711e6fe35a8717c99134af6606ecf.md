# 一周复盘｜读书时就像破案

你好，欢迎来到《宁向东的清华管理学课》。

非常高兴有第八周的大家在做一个复盘。这一周我们讲的核心内容是关于一个“领导模式”，其实那一周的本质是领导。每一个和若干位优秀的领导者的风姿，领导建立关于领导者的形象轮廓。从职权型领导者到感召型领导者，更多都是例子，所不同的是我按领导者和下属拥有权力的多少，依次进行排列。比如，授权力型领导模式下领导拥有的权力少，员工拥有的权力多。

# — 本周复盘 —

学完上一周课，我会故意提一个小的问题，就是五种领导模式，能不能一起使用。这个问题本身就是个圈套，因为无论你怎么回答，都可探讨，都有可聊之处。而你回答的好这个点，一定能对五种模式梳理一下，然后你依据自己的经验，做个判断，达到了我的教学目的。

回顾这两周的课，重中之重是这一周关于“建立”建设领导模式的第六步方法”。如果真有什么降龙十八掌，这一天的课，应该算是一掌。我建议你的周末如果有空余时间，再复习一下这一周的课，也许你会有更好的收获和体会。这种技术性内容的话，我大约每两周给你一次，频率应该不失调和。

本周第一天的课，虽然稍难，但相对于别的，会的人比较少。从文字上看，这节内容的难度应该较低，说明大家在听课时理解的最好。不过关于“建设”领导模式的应用题，比如，在创业的环境中，领导者是创业方法以及领导者是中层，领导者是画图的心态，是我自己悟出来的，建议你多花点时间琢磨琢磨。
