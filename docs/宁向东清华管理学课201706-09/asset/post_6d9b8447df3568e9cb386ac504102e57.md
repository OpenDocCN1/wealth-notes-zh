
# 宁向东

在结束我们的课程之前，让我给你们讲一段故事。1971年，有一位耶鲁大学的博士生奥尔德斯跑去找他的导师荷尔曼教授，给导师提了一个大难题，核心是：他不想独立做项目了。导师说，我们关系很好，熟知几年了，我们的研究也很顺利，可以独立做项目了，我的私交很多，关系也好，你还会有什么不满意呢？奥尔德斯说，我觉得和你一起做事学不到更多方法。现在，我不带你做，我觉得不好。导师说，好吧，我们一起合作吧。于是，他们又花了几年时间进行合作，共同建立了一套理论。这就是我所说的“工作特性理论”。

最后，总结一下今天的课：团队关系是一种员工之间的相互关系，但更加基本的，是员工和企业的关系。企业只有把员工作为资产，让员工体会出收入之外的工作价值，感受到他们真是有价值的资产，企业才会产生出生成企业外的竞争实力。也许你今天还不是领导，这里告诉你一句话，请你一定牢记住：当有一天你成为了领导，要把员工当作资产，而不仅仅是工具。

今天的课后，放了一篇宁高诗的旧文，我第一次看，非常感动，今天分享给你，请你认真思考一下。

## 推荐阅读

认识付洪炜是在一个很令人伤心的地方——医院的急诊观察室里。如果他不是这样，不可能很长时间我也不认识他，不仅仅是认识他时是什么样貌，更不会认识他的内心是什么样子。付洪炜是华润集团万家超市的一名普通员工，负责流转资产的编订和定价，他几个月前才加入外资企业（后转入）华润集团，可很不幸，他在浙江出差途中出了车祸，受了重伤。我刚好在杭州，去医院时，在那家小医院的急诊观察室里认识付洪炜。

去医院的途中，同事告诉我，付洪炜两天前受伤，眼睛有失明的危险，家属也来了。我想想，三十刚出头的小伙子，遇上这样的事情，心情一定很差，也许会发生一些事情，我一定要好好劝解他一下，如果有什么要求，我也尽量答应。

见到付洪炜，他正躺在床上，头上裹满了纱布。我握着他的手说：“洪炜，公司没有照顾好你，让我说了句。”他希望能说：“哎哟，宁总，您怎么也来了，惊动了这么多人，真的很对不起。”他竟对我捏着握手，很有力，我边说了些什么也不记得了，可付洪炜说的每一句话我几乎都记得，因为他的谈话让我回味了很久，让我感受到了一个透明、高尚的灵魂。

付洪炜说：“我刚开始工作，还没给公司做什么贡献，就给我们公司添了这么多麻烦，真的很对不起。”“我受伤后，公司这么多家照看我，这么多领导来看我，我无以为报，只能说好全力做好工作来报答公司。”他还说，“我很快会好的，用不了多久，我就可以工作。”“宁总，你放心，我知道我眼睛有问题。现在看来我右眼问题不大，左眼有问题。没关系，我一只眼也可以工作，也可以写字。”

从医院出来，同事告诉我，付洪炜是在凌晨的车祸中，在去邻近县一家新超市开业的路上受的伤。我们赶赴到这家医院时是早晨，第二天醒来，还没说几句话，他就问：“我们那家超市当天开业好不好？”这不是电影里的英雄故事，这是真事。

我们现在也不知道人品格是先天然形成的还是后天养成的，但人和人一定是不同的。在和付洪炜有较短的接触中，我感受到了他品格中的乐观、坚强和高尚。特别是人在遇到挫折时，这些品格不易显示：付洪炜不是华润集团最出色的员工，他加入华润集团几个月，然而就是时间再短，华润集团也没有这么大本事让一个人具有这些品格，但这个新人让华润集团体会到的却很多。

我本来不想写付洪炜的事，虽然他给我很多的思考，但我觉得有些忌讳，可有一件事改变了我想法，这就是最近收到付洪炜父亲的两次来信，这位七十多岁老人的信再一次让我的心灵受到震撼。

老人说，小儿受伤，公司这么关怀，我全家万分感谢，我全家谢谢大家了。我儿刚到单位，还没有什么贡献，就造成麻烦，只能以后更努力地卖力工作来报答公司。国有国法，家有家规，公司有规章，如果向公司提不合理的要求，请公司以我老信为据来拒绝。

老人说，千万不容易难司机，他已经很自责了，我相信这位司机不但会成为一个好司机，也会成为一个更好的有用之才。

真是有其父必有其子，老人的话与付洪炜的话如出一辙，也更多了一些温和和善良，老人的第二封信让我知道他是多么爱他的儿子，宁愿牺牲自己。

老人说，付洪炜（此处原文可能有误，结合上下文应为某位亲属或付洪炜本人，但原文如此，保留原意或理解为子女）女儿从他手上拿到眼球可以治付洪炜的眼，他想把自己左眼的球给妹妹。他说这样时间短，花费也小，父子同命，排异性小。为了说服大家同意和证明自己“不需要”左眼球，老人说，我写给我的这封信就是盖住左眼写的。

我到现在也不知道是什么造就了这样一对父子，我也知道付老先生从事的是什么职业，是怎样培养、教育儿子的高尚、善良，但是人心在父子身上表现得这样淋漓尽致，我只知道他们是好人，我在心里向他们敬礼。

# 周末复盘 | 组建有效团队的逻辑

![](img/e9c4ead90d162cb22377bd13386f3198_124_0.png)

你好，欢迎在周末来到《宁向东的高管管理学课》。

这一周，其实讲了一个概念：团队。基本逻辑也很简单，可以概括如下。

首先，要先时刻记住目标。

我们为什么要组建团队？因为一个人干不过来，一个人干不过来，找人帮忙，人人都向你投来，向你负责，这个叫群体。群体中的成员之间没有什么关联。如果你要实现的目标，需要较长时间的投入，成员间不仅需要对你负责，还要相互之间互动协作，就需要承担另一个团队。团队和群体的最大不同，就是成员之间有协同配合的关系，有共同目标。为了一个协同效应，我们的组织搞了很多团队建设的活动。但是，我推荐首先提醒留意的是：建立一个团队一定要集中到规划知道：你想干什么，团队的任务是什么，目标在哪里。

周一的课中，我没有明确区分“组建团队”和“团队建设”这两个名词。今天特别强调一下，我这周一课里讲的，都是组建团队的内容，我通常理解的“团队建设”是下一周的内容。

![](img/e9c4ead90d162cb22377bd13386f3198_124_1.png)

记述了目标，接下来的问题就是怎样搭建一个有效的团队。我周二和周三就分别讲了这个问题。

周二讲的核心观点是“选择团队成员，是领导者最重要的工作”。我用谷歌选人的例子来分析，对于组建团队来说，选人有重要，我还讲了三种尽量要回避的：人性不健全、态度不认真和做事不职业的人。当然，有人再选一个人的能力，有比后面这两重厉害。懂度人，真莫太高。但是，不含容易。周五，如果你有时间，我推荐你看电影《悲惨世界》，特别喜欢老佐治版（注：OCR原文为“老左版”，推测为“老佐治”或特定导演版，保留原意“老左版”或修正为常见译名，此处依OCR“老左版”可能为误识，暂保留或理解为“老版本”）。以德报怨，不容易，这是我对中学里看小说《悲惨世界》印象最深刻的东西。所以，我特别理解有些管理学者“换脑袋或换人”的说法。我当年靠常不靠尼尔森才给博尔的MBA毕业生，你毕业了不要进通用电气来，你们到华尔街，我们真正长大了，再来通用电气。所以，很多时候，有些人，惹不起，要学条躲得起（注：原文通顺度较低，保留原意“惹不起，躲得起”）。

# 051讲：组织承诺｜四种共同体

你好，欢迎来到《宁向东的清华管理新课》。

上一周，我们讲了团队的组建问题。这一周，我们讲团队建设。今天，我要给你介绍一个重要概念，组织承诺。然后，我向你介绍关于四种共同体的分类，我一般由此来判断团队的类型和性质。

## 1. 组织承诺

我先提一些问题：当我加入到一个组织中，为什么要我和一群人组成一个团队？凭什么我要相信你？我们参加了一些团队建设活动，你觉得那些东西真的有效吗？很多团队，我们情感情地要要求在活动中去一些陌生的成员去合作，在团建活动中去参与一些我们之前并不喜欢的人发生了接触。你可能会问这些，我们真的在心底接受了吗？

这些问题，都和一个叫做“组织承诺”的概念有关。正是在对于组织的不同的承诺状态下，我们加入了不同类型的组织，并且态度不同的心态去参与所谓的“团队建设”。

组织承诺，简单地说，就是组的成员愿意把自己力量集中在组织愿意、给在关系上（注：OCR混乱，推测为“组织成员愿意将自己的精力、资源集中在组织目标上”），是一个个体对于一个特定的组织接受、认同和投入的程度。成员对于组织在这个组织中，他会表现出一种对于组织存在这个组织中的强烈欲望，越是希望当一个组织的成员。

组织承诺这个概念，最早出现在上个世纪60年代的美国，那个时候的美洲社会（注：应为美国社会），处于动荡和矛盾等相互交织的状态。越南战争和民权运动，让美国社会充满了骚动，校园里有各种示威活动，社会上也有各种罢工和游行。但是，和社会上的激进相比，美国的公司却出奇地平静，无论是白领员工，还是蓝领员工，在平静地工作。

一部分学者开始觉得公司员工相对稳定，很有研究者说，为什么工人们混的很好，却不是，而是有序地生活着呢？每天上班，很少靠上班时（注：应为“很少在上班时...”），按时上下班，去办公室，很多在到上班时来动都不去（注：OCR混乱，推测为“很少迟到早退”）。后来，学者们想明白了，因为这些人是有组织的归属感，公司越大，越稳定，这些人的归属感越强，心越顺，同时，他们也表现出对组织更强烈的投入。也就是说越承诺越深。上面就是“组织承诺”这个概念的来源背景。

## 2. 组织中的四种共同体

现在，回到我们今天的课程主题：团队建设。团队建设之后，你为什么要花力气去组建团队呢？说明确（注：应为“说明确”或“明确说”），是为了增加员工对于组织的承诺关系。不过，在具体讨论团队建设办法之前，我建议你了解一下共同体的概念。因为，在你的共同体里面，成员和组织的结合关系是不一样的。所以，建设的方法是同的（注：应为“不同的”）。

第一种共同体，叫职业共同体。组织的大部分成员，加入的都是职业共同体。

在这个共同体状态下，员工主要是为了获得薪酬，工作的是为了养家糊口。在这个共同体，员工只能从他的岗位上进取得相应的收入（注：删去“进”）。心里感受就是，只要薪水合适，他也不会离开。还会保留着一种经济交换的关系。他心理预期就是，向领导讨出一个非正式组织。他或者一个人说的从工中获取（注：应为“从工作中获取”），会形成一个非正式的承诺关系，保持一定的安全感。他向领导和正式组织决定时间的时候，也倾向于从非正式组织获得同情和支持。非正式组织可能会成为一种隐形的权力力量。有打饭的，可能会有的，是领导会有的方式（注：OCR混乱，推测为“非正式组织可能会影响正式组织的管理方式”）。否则团队建设的种种努力，都会是无用功，或者事倍功半。

比职业共同体更进一步的是，利益共同体。顾名思义，利益共同体是利益关系维系的。中国有句成语就叫做利结于财，状态（注：应为“利聚人散”或类似，原文“利结于财”可能是“利聚人散”的误识，后文有“前财为人类”应为“财聚人散”）。老板们也不少一句话：前财为人类（注：应为“财聚人散”），财聚人散。很多企业家都考虑让早中持股期员工持股（注：应为“早期员工持股”），组织通过这样的方式激发管理层员工和企业的组织承诺。

前些年，我曾经为一家企业做了一段时间的咨询，老板先期到了一定的阶段（注：应为“企业发展到一定阶段”），希望把企业的业务规模再上升到一个台阶，用一批职业经理人进来取代中元台（注：应为“中层管理台”或“原有团队”）。职业经理人都是挖来的，薪水都高，能力都比老板要强。如何写点（注：应为“驾驭”或“带好”）这支团队就是老板进一步发展的难点了。这个公司有个上市为说事（注：应为“以上市为目标”），其实是希望用一个远期的利益讲（注：应为“故事”或“愿景”），团队用工具来大家的组织承诺（注：应为“激励”），增加团队凝聚力。

但是，坦率地说，把一个团队的凝聚力完全建立在利益的基础上，这个组织未来一定会会大（注：应为“会散”或“会出问题”）。如果有利益可以大发展的时候，团队的凝聚力瞬间就会消散。道理和利为（注：应为“道理很简单”），就是团队前成员（注：删去“前”）的组织承诺，都是以利益为基础的。所以，很多成功的企业都是把利益共同体和事业共同体链接起来，作为团队建设的目标。

事业共同体，是第三种合作关系的类型。如果你不理解事业共同体的特征，看看身边年轻人组建的创业公司，有不少就是基于单纯的理念的。创业团队就是事业共同体。我去访问过一家清华学生的创业企业，几个员工都是寒舍家的儒子（注：应为“贫寒之家子弟”或“出身寒微”），一起赚钱来看（注：应为“一起创业赚钱”），员工都是寒舍家的儒子（注：重复），也会说起上些什么的（注：应为“不会计较什么”），但他们更要把自己想做的产品做好，特别单纯。这就是最典型的事业共同体。

## 3. 心理契约

我们来介绍一位大师，这位大师的名字叫“卢格”（注：应为“Rousseau”罗索或相关学者，或“卢格”为音译，保留），中英文都写《忏悔录》的学者名字叫卢格（注：OCR混乱，推测为介绍学者背景），他1990年提出了概念“心理契约”理论，是卢格在管理学的研究领域。一个新论文，在论文提出之前，这个概念还提（注：应为“已有提及”），但属于非常伟大的管理思想。
