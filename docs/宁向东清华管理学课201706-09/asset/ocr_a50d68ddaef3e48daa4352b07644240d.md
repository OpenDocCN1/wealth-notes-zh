# 1、什么是“窄化效应”？

“窄化效应”是1996年由美国的一位教授弗里斯提在一篇很长的论文里提到的。我们都知道是有偏好的，偏好是一个人的喜好，听起来对外界的事物基本看法。偏好，听上去很复杂，说得简单点就是“知道喜好”。如果一个人“不好学”，其实，就是偏好坏了。比如，一个人今天说我是橘子好了，明天又说橙子算算好，这个人生前前后后有口无定，窄化效应，就是偏好发生了。因为他只关注了某个时刻某个点的偏好。

但现实中，很多时候我们都是一个窄化的人。比如，所有威胁性的行为。一定是他基本价值观，基本偏好。但是，为什么他不理解呢？因为他只复述了。这就是“窄化效应”。因为在复述的时候，他吸收性事件看得格外重，那种相对他的影响格外大。又比如说，一个人因为一个外在办公室，为了工作上的事情，几句不真，都不欢而散，第二冷下来反思，其实不是大矛盾，是又忘忘的。可当时为什么大吵一架？因为只关注了某个时刻某个点的偏好。

罗恩斯丹从神经生理上学上来找他的原因，他认为，人之所以会出现“窄化效应”，是因为在当时的某些“体内因素”（visceral factors），你也可以理解成“情绪效应”，你的体内分泌了一些化学物质，这些物质所导致的行为“驱动力”，九匹马都拉不住。这个拉不住，就指在集中时间内表现出了比通常更厉害的行为。换句话说，你可以把这种状态的人，叫做“窄化的人”，所以，当我们注意到一个人不断窄化，这个过程里要避开一些事发生的。比如，这个时候就特别适合进行沟通交流。

罗恩斯丹说，人的“体内因素”，常常和自己的偏好、过去。所以因素的变化和变化很快速、很激烈的。当时一个角度，他的眼中、他的心中就只有那个“偏好的东西”，会做出强烈出现的“暂时性反应”。而且，这种时候往往注意力集中、就像那些动物，当前要做什么长期、未来，什么自己发现的东西，都藏不住了。窄化效应

“体内因素”，是引起人的“窄化效应”的直接因素，体内因素会快速变成强烈的情感情绪。窄化效应”，就是这种内在因素的直接影响。
