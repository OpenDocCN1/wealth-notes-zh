# 1、研究：76秒的冲动

有学者研究发现，一个人看到好东西形成的购买冲动，只会持续76秒。如果在76秒内不能完成购买的交易，冲动就会消失。很多人广告商看到这个研究之后很失望，但也有人从中看到了机会。要想抓住这76秒，比如广告商有一家咨询公司就发明了“随刷购买”的技术，随刷购买利用的是6秒的反应时间把你口袋里的钱掏出来。他们是啥么做到的呢？首先他们制作的是一个可以随意跳转的内容，因为你可以制作电视节目，不可能去停下广告去看广告的东西。比如有同学去长坂七将军的枪下做保家卫国的节目，广播广告效果会很好。因为这个时候观众的参与程度很高。这个时候说“买什么”，就算是你很少见，身上穿着很平常的衣服，谁会停下来去买呢？所以要想通过视频来卖东西，一定要制造最感性的目标，结果越越火爆的电视节目广告效价就越好。所以越想越火的电视节目就越带不下来。一个又一个的76秒都被消耗掉了。所以这家咨询公司就专门制作了一批叫“随刷”的节目，时间有长、有短。15分钟带来人怎么做饭的、有做名字的、大周是专门来给人去选漂亮衣服。漂亮的人来，这漂亮衣服一定会会穿一件漂亮的衣服。请注意，这个衣服，它是整个节目的目的。

随着整个节目的进行，每当这个漂亮的衣服、漂亮的嘉宾出现的时候，屏幕的右边就会蹦出一个边框，那种很贵的衣服又出现在边上，变成了一个可以“随刷购买”的小边框。这时候你只要点击边框，节目就会立刻暂停进入购买界面。因为此时你的注意力没有进入到购买界面，就能够让你停下来买的东西，让你的即时下单，一切动作都被保证在你冲动的76秒以内完成。这就是随刷购买。

这个局水平很高。它没有做成一个购物节目，因为大家都讨厌购物节目，反正我每看购物就会立刻换台。所以这个节目的安排很巧妙，它让你换台，但是很耐看进去，时间又不久，又没有情感急点，就可以停下买东西，也不需要看广告。因为你下来之后回去还继续要看节目。乐，掏钱包掏得非常随意。

# 2、概念：阁下意识

上面这个例子是说人如何利用冲动给你下套，下来讲商家还能利用的“阁下意识”。什么叫阁下意识？这是原先一个心理学的概念，后来被应用到市场营销中去，那阁下意识是什么意思呢？

以我们的视觉为例，人的眼睛就是一个光接收器。出现了光、眼睛接受光刺激，感觉到了光的亮度，就是接收到了信号。然后大脑意识到了光亮，意识到了色彩，这就是看到东西的过程。我们看电影是一个不断接收信号，意识把画面联系起来，然后用我们的意识去理解画面的过程。

这个过程中出现了两个商家可以利用的地方，一个是商家可以利用亮度做文章，第二个就是利用画面之间的关联做文章。这又回到了底下意识的概念。亮度怎么做到哪样？如果我们看电影放映机的亮度逐渐调暗，当慢慢低于某一个水平的时候，你的什么都会看不见了。这个临界点我们就可以称为“阈”，也就是低于了视觉的临界点。神经科学的人可能不知道，比这个阈值稍微低一点的声音，我们内耳已经感受不到了，但我们的阁下意识已经感受到了。于是商人们就利用这一点来做手脚。第二个可以做手脚的地方就是画面跟画面之间的间隔。商人就通过闪动的画面来做文章，比如说很快地打出一个图像信号，快到你以你看不见，你的阁下意识已经感受到了。

# 3、案例：隐形广告

综合这两个手段会有什么结果？举个例子，上世纪50年代的美国人写了一本叫《隐蔽的说服者》，这本书就想到一个故事，说的是他把这两个手段放在一起来影响别人的购买行为。说有人在一家电影放映厅做两周的实验，有45000人在这两时间里来看过电影。这个电影院原来花了这样的一个办法，让看电影的爆米花的销售量增加了58%，可乐的销售量增加了18%。

![](bbox=[0.1, 0.61, 0.9, 0.66])

他的方式就是插一段闪烁的阁下意识的广告，每隔五秒钟就播放一个长度为三毫秒的图像。广告语特别简单，“吃爆米花、喝可乐”。这八几个字，因为这两个广告在电影里穿插着播放，你肉眼看不到，但你的阁下意识已经感受到了。据说就因为这两行字导致了爆米花和可乐销量的增长。

后来有个美国人写了一本书，专门提出一些概念，叫做“阁下消费”。作者提出了一些厂商和阁下意识诸多实验的方法。比如，乐之饼干的外观跟藏着一个SEX的字母，人虽然不可能用眼睛看到字样，但阁下意识是可以感受到它的。作者说，甚至这样可以让乐之饼干更招人喜欢，而且更吃口。

60年代的时候，美国国会还专门研究要不要立法禁止这种促销方法。因为它已进入人们的意识层，但反对的科学家水乎。没有平等的学术理论支撑，国会也就没有立法。等到了1999年，美国贸易委员会委员们通过了一条法律，就是禁止播放这种隐形的广告，比如“吃爆米花”这类的方式。

有意思的是，这种闪烁式的广告后来居然还出现在美国总统大选上。2000年，美国的总统大选戈尔对布什，戈尔就有一个要改革医疗方案，但反对者就骂这个医疗方案坏人的时候，电视广告就闪了一个“胡说八道”。我们通常来说看不到这个词，只是偶尔慢慢地在屏上，这个词就可以利用意识慢慢浮在屏幕上。这个广告在在美国的33个州播放了4400次，后来被保守的人在国会大法庭。最后谁赢？不过，美国人至今还在讨论，这是不是已经侵入选民的阁下意识，影响了选举的结果呢？

针对阁下意识的广告被称为“隐形广告”，在上面的一系列事件之后，很多学者们做了大量的研究。现在已经有更多的证据来证明它确实会影响人的意识系统，促成了另一种销售的模式。但销售这一手段产生了购买行为。但是，这种情况一旦遇到更加明显的刺激，比如闻到了爆米花的味道，人的消费冲动就会立刻产生，人的消费行为也可能就会发生。
