# 033讲：情感型领导 | 选老还是选贤

欢迎回到《宁向东的华智管理学课》。

今天的课我们谈谈：为什么那么多的管理者采用情感型领导模式，这种领导模式有什么好处，又要注意什么问题。今天的课程有两个要点，请大家注意接收。

# 1. 为什么新官上任都会“任人唯亲”？

所有的管理者其实都是从没有经验走上领导岗位的。当一个个人走上领导岗位之后，他会遇到两个主要问题：

+   1. 下属不服气，特别是有些下属认为你凭什么会升到这个位置，是该让他服他，他会充满一腔的敌意。有些人虽然表面上不会不服气，心里也期盼着新官上任把三把火，先烧了自己，所以他在往不配合。

+   2. 下属在工作方式上与你的工作方式的出发点和思考方式有所不同。同时，即便没有不服气，有些时候双方在沟通上，也会卡不顺的，或者是阳春雪。

在这种情况下，很多管理者为了能够尽快开展工作，都会选择一些有情感、同时支持自己的人来辅助自己。这就是现实时“一帮老干一起起”，而与立相应的，领导者往往建立“情感型领导模式”。情感型领导模式的心理特征就是用人，用自己信任的人，所以很容易被认作是“任人唯亲”。

用自己信任过的人，用人，往往是特定时限里巩固自己领导地位的一根支柱，工作很急很推进。因为你是新上任的，不了解和熟悉一个新的下属需要花时间的，下属在工作中，领导并不能有有时间慢慢选拔人才，同时，用熟悉的人，可以用花时间找人、挖人，时间成本会少很多。

另一方面，因为了解与信任，领导者和下属之间的关系是双向的，如果重用过的下属不尽全力，那也采用在言语上谴责或较大的损失，所以，采用情感型领导模式在很多时候是有道理的。

# 2. 悄悄王者转换

听到这里，你也许马上会问：情感型领导者不是新新上任吗，怎么就王者呢？等到领导地位稳定了，是不是就要摆脱这种领导模式，比如发展到能力型领导模式呢？

我确实，确实应该，但现实中也确有例外。我认为这里面的原因有很多：

+   1. 领导者熟悉了任人唯亲的形态，他在这种模式下感觉良好，他在这两种领导模式之中，他没有改变。

+   2. 就是事情事实上已经转向了，但是，并不一定看得出来。下面，我们就从这里深深说了。

我先和您分享一下李嘉诚先生的话：十年前，李先生在谈他最初的用人之法，以前管理都应该是伯乐，要不断地考察和选拔，挑选有心的聪明人。不过，他说到，忠心是基本的基础，就像我们说的“任人唯亲”。李先生把忠诚，就是把“老”看得比什么都重要，不仅仅看才“新”者，我们华人企业大多都看重“忠”。

但是，请些企业在发展的过程中，实际上是有变化。忠和能是并存的。不忠，忠水平没有动，但“能”的水平在往上走。忠诚不能往走的就研究“两不靠”：那些名实不，喜欢自我标榜，凡事以“自我荣耀”为忠心的“企业明星”；还有，就是光有忠心，但能力不足的人，他也不用。
