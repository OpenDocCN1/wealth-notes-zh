# 1.图示工具极其重要

20年前，我刚开始为企業做顧問服務的时候，凭的是几本教科书，几千篇理论。在企业做過培训，回来拿出一堆理论，再做几张PPT，写一份报告，基本上就完成和企业的咨询業務了。后来，在这样的项目要求下，渐渐地发现，咨询公司的核心能力，其实全在画图的功夫上。

我曾经有过两次在一家著名咨询公研究顾的员经历，接幾过几位顶尖级合伙人，与他们闲聊后才知道，进行图上作业是他们每年的必要课，以这家级级为例，每年的年会后，公司会把最重要的合伙人关起来，让他们根据自己一年的咨询经验，至少画出一张图，写入了他们公司，这个工具是水平，代表了合伙人对于公司的贡献，也让其他公司任级合伙人，可以借鉴。不上家公司也是如此，我经常和一家级的顾问公司去合作，我甚至和一家咨询公司合作，他们家的合伙人，就是一张叫做“5ice”的模型。

为什么画图那么重要，就是因为一旦把这件事真的认真了，一定可以洞见这件事背后的逻辑，明白，怎么用这个被证明好的东西吃饭呢？就是，怎么把这个图工具化，只有工具化才能帮助人解决问题。我当咨询顾问，不知咨询费很高，一定有你有能落地的工具。也正是应得了这个，我自己的管理学研究格外重视图画。熟悉我的人都知道，我在清华大学教书，课述写有板书，坚持画图。因为我要训练的，是学生学习画图的素养。当然，这是我个人的理念，不一定正确。

# 2.团队建设极间工具

今天，我要为你介绍一个画图的入，核心是：我是从画和说一个团队时，自己摸索出来的，不知道你看了会对你有帮助。这一个极简的入对群体发展成团队，算是一个极简的工具。

第一步，先确定组织的任务，或者目标。

你想一张表格，最上面一行，我们可以称为“任务栏”。在栏里填入任务。正如我们在上一个课讲的那样，你要把一个新成员发展的同一个课题，你的目标是什么，你的任务是什么？你一定会是养一个团队，那去建议什么团队，你听我在图上一讲了，这个案例，你应该知道团队建设的前提，是先得确定团队任务。好，请填到这个“团队任务”（或者若干目标来画图）填上一栏里。

第二步，你想一下，为了完成你的任务，实现这个目标，你需要怎么样的一个团队。

表格的第二行，我们称之为“理想团队栏”。填在下一栏的细节是：你想好，需要通过的团队入，又需要怎样的助动人员，进一个怎样的方法去使用你的工作。就像杰克逊教练那样，你可以设计一个战术，比如以一个三角形战术来整个战斗人员。当然，这是一种理想或理想的假设，在你描述这样的栏时，你最好把开来的现实因素，想象一个完美的状态。

我建议你可以从以下几个方面描述理想的团队的内部关系：

+   1. 团队成员的价值：价值观一致，是建立长期团队的基础。所谓“道不同，不相为谋”。如果你的价值观差异很大，团队无法获得大家的支持。
2. 动力机制的相容：团队每个成员的动力机制相容，是稳定团队合作的基础。只有动力机制相容，大家才把工作重点放在集体成绩上。否则，追求的利益不一致，会因利益冲突而大家貌合神离。
3. 角色关系的属性：这涉及到骨干与成员之间的关系，是管理者与执行者的关系？在组织内部，是上下级，是朋友？角色定位清晰与否，直接影响着团队内部的关系，如果团队中两个成员存在角色不清的问题，内部协作关系就会紧张。
4. 成员间的责任关系：包括决策权、工任务划分、以及沟通机制。决策机制，就是谁负责什么工作，谁有最终决策权，谁有权否决，大家积极投入决策，2之间的分工。
5. 成员的技能互补：每个人是否能够在自己专长的方向上发挥优势，是否要依赖别人的协助，是否要形成互补的工作关系。

毫无疑问，你的“梦之队”里，这五个方面的某些细节被得到很完美，当你把这些描述出来再对比现实时，这些理想是你认为要实现团队任务，建立一个有效团队的重要因素。

第三步，对现有团队成员进行评估。

在我设计的表格上，这是最下面一行，也就是第六行，你要去填这一些，这一栏是填写现有团队成员。你可以对他们的能力、协作关系、思想，等等，在这里写一些什么“现状栏”。

接下来，你要填写第五行“人员改善栏”。为了能够实现你的任务，你的团队必须要增加哪些入，增加哪些人。同时，对准备留下的人员，你应该进行什么能力培训？你的团队建设建议哪些工作？

作为领导者，你一定要清楚，所有的团队成员有两种选择，要么可以，要么不可以。所以，对领导而言，因为在上一级栏中的成员，或者被调离，或者淘汰，你其实就是一只手，原地踏步。第二种，淘汰，需要淘汰的人一旦确定，就应该考虑在团队建设中去留这个人了。

从最下面一行“现状栏”往上的“人员改善栏”里面，写写看，看有哪些人的表现，是需要被改变的。比如，其中一种是多年老臣，甚至包括你的副手，大家庭有旧有，有些还带他走上高岗，或是又没找到他，或者他的关系，这些难处，你要格外需要被激励的。

第四步，团队协调设计。这是群体打造成团队的关键一步。

我们可以根据第二步里面列出的五个方面，每个方面都用一个10度的线段来描述，画在三栏里。这一栏我们可以被为“曲线对比”。

用了10刻度的线段，就意味我们可以给每个方面打分。我们根据理想的团队状况，对比五个方面打分，理想的情况下，需要依据，你可以对五个方面的内容作进一步的对比。如果你已经忘忘了这些套路，要复习复习第三节。

我们可以根据团队现状分析，把所有这些线段上所标示的点连接起来，就是“团队现状曲线”。同样的方法，把“理想团队栏”和“现实曲线”的5个方面的表现画出来，形成“理想团队曲线”。

对比这两条曲线，你就可以知道，五个方面，哪些方面需要改善到什么水平，哪些方面我们不用再花时间去考虑了。

第五步，团队建设计划。

从第三行“曲线对比”中的内容，根据线段上的差距，我们推导出团队建设的主要方面，思考着这些方面的可以改善的方案供参考，找到可以建议。
