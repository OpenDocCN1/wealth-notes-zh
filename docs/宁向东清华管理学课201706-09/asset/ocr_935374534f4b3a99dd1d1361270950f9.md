005讲：涟漪效应｜破不了...

你好，欢迎来到《宁向东的清华管理学课》。

前几天的课，我一直和你讲成功破局的故事，可能会让你误以为学习管理学学习可以破掉所有的局，但我今天要告诉你，有些局是很难破掉的，特别是，自己给自己做的局。

为什么这么说呢？因为所有的管理工具和管理方法，都是一把双刃剑，既能解决问题，也会带来新的问题。所以管理工作，很是一劳永逸。大约20年前，我与河南建业的董事长胡葆森先生聊天，他问我说：‘向东，你说说管理是什么。’我告诉他，管理就是破个气结。管理工作，本质上就是要不断破局。你要防止上一个阶段自己的招法，给下个阶段的自己留下一个新困局。

# **1、涟漪效应**

今天，我就和你分享一个这样的困局：用关系进行管理的困局。

很多企业都习惯用关系作为管理的手段，在现代管理学界，有一个新词叫‘GuanXi’，是一个拼音创造的‘英文词’。以前老外将relationship或者connection用来翻译‘关系’这个词，但大家都觉得不足以准确描述中国人的独特的概念，所以，专门重新造了一个词，老外给‘关系’的定义是：中国人在生活和生意中，要建立和维系的人际网络。

那么，关系和‘破局’又有什么关系呢？

我先从一个人说起。费孝通先生，他是上世纪一位大社会学家。费老最著名的一本书叫做《乡土中国》，在这本书里他把中国人的社会关系比作一种‘涟漪效应’。

‘涟漪’，形象地说就是扔一块石头到水里，平静的水面上会产出一圈又一圈漾开的波纹。所以，用文艺的话来说，就是‘涟漪’。费孝通先生认为，中国人的社会关系，就是这样一圈圈围绕着中心扩散的。这种，这种现象就叫‘涟漪效应’。而位于中心点上的，就是每一个活生生的人。从某种意义上说，中国人是一人一涟漪。

![](bbox=[0.1, 0.73, 0.9, 0.84])

中国人想事情都是以自己为中心的，考虑一切事情的出发点都是我自己。所以，每个人都是引发涟漪效应的中心，每个人都有自己的涟漪，有自己远近不同的圈子。远一些，近一些，就意味着亲疏关系不同。我们有时候讲，‘亲戚有远近，朋友有厚薄’，说的就是这个意思。总之，涟漪效应是对中国关系一个很好的概括。

# **2、关系的局**

中国人基于关系的人际交往逻辑，实际体现在很多组织内部，在组织内部，存在着很多类似于‘涟漪’一样的现象：哪些人近一些，哪些人远一点。组织里的人都知道，对于领导者来说，跟身边的人特别少，是很少领导现象。圈子近的人，一定要坐到重要的位置上，自己才会感到安全。如果一个领导在台上讲话，台下坐着的人没几个认识的，哪怕你大权在握，心里也会有一种孤独感。

所以，在中国人的组织里，下属会强调领导对你好不好，领导也会格外去辨别哪些是亲信，哪些是外人。

在西方的企业里，虽然有公司政治和裙带关系，但更多的话，主要角度考核还是拿业绩说话，强调从业绩的角度去考核员工。这一点在亚洲企业中非常典型。上司和下属之间关系的亲疏较多还是基于工作层面，而中国人就要倾向于工作层面，虽然工作表现也很重要，但在很多时候就相对次要一些。

这会导致两种情况：

+   1. 上级对下属的评价会因为是亲信而有所区分。就像我们常说的：说你行，不行也行；说你不行，行也不行。为什么会差异化？就是因为亲疏不同
2. 在用人和分配资源上，信得过的人和信不过的人在机会和待遇上是不一样的。亲信通常会分配到更多、更好的资源。

# **3、为什么说它‘破不掉’**

下面要讲的观点，你可能不同意，但没意见。因为管理学的很多内容都充满了争议，我个人认为，上面讲的这个‘上级对于下属不公平’的情况，也许很多人都遇到过，有人会觉得这是个别现象，但我认为实际不是普遍现象。而且最为吊诡的是，人人都讨厌的事情，人人都在做。

比如，你问一个经理人，企业里如果到处都是亲信关系，对企业的长远发展是不是有利？回答一定是肯定的，他会说当然不利，企业就应该任人唯贤，不能任人唯亲。但在实际中，每个人都有因为所选择的‘亲信’做事，会有更好的感受，从某种意义上来说就是一种安全感，所以很多时候一天自己做下件事时还非常反感的事情，第二天自己做过了上级又会立刻亲手去做。

这就是我们的关系文化导致的结果。这种关系文化，为领导者和老板设置了一个非常难以破掉的困局。

这个困局难以破，组织就会出问题。因为下属会格外想成为亲信你最近的圈子里的人，所以他会假装‘忠心’、假装跟你有相同的价值观来骗取信任，这努力为自己打造成。

亲信为什么会这么强？在西方组织里，阳奉阴违、讲好话的人特别多，至少从来没有坏话。那些能力有点本事，敢于做的人，因为自己的能力而不局限于做这种事，在组织里就越来越少，甚至难以下立足，最后的结果则是组织的价值观非常不稳定，只有亲信坏了的时候，才会真正有正有用的人。

关系困局里最危险的就是：很多时候你以为的亲信，不是真正的亲信，而是演出来的。

我认识一个大企业的老总，他培养了很多人才，但55岁那年他突然中风了。几乎另一个他信得及的人给他到医院看了一次，但看完这一次，不少他自以为是铁杆亲信的人就再也没有来过。因你、你次关系，主要是看短期有没有没好。因为，第二次工作的可能，因为他快到了退休的年龄，如果短时期内没有恢复正常的可能的，就不需要再来了。他有原先非常好的经理人，这个时候都弃他而去了。反而是那些因为不断做事，不断遭到批评，以前他认为是他在圈子里比较远的人，一谈到北京或者后来，就医院来看他，让他深感感动。后来他就说：‘老祖宗讲的“人心险于山川”，真是太对了。’

总之，中国人是靠关系，你我都一样，一旦当了领导，都会用比较亲信和信任的人，当组织因此更信任地运行会有效率，同时也会很放心。但也是由于这种基于亲信和信任的亲疏文化，才形成了难以破掉的困局。
