# 1.为什么要一个人说了算

首先， 我得先声明，我是主张绝大多数情况下，应该由一个人说了算的，就是重要大事项，最后应该由一个人拍板。一个人承担责任。请注意，我的这个主张有三个前提，第一，有老板最多承担不了第一， 第二，个人拍板和他接受建议无矛盾，是一体的；第三，一个人拍板并不是否认大家要充分发表意见。

为什么这么说呢？

从逻辑上讲，一个人说了算的好处很多。 问题是可能他是决策效率高，当然，它的小缺点是会信息少，思考不够缜密，甚至出现决策失误。但是，靠班子成员进行集体决策，是不是可以解决这个问题呢？

我参与决策是，有20年的顾问经历，我的阅历是：靠多数人的表决不能解决这些问题，而且会产生新的问题。最主要的问题在于，商务世界中真正的，很多时候是掌握在少数人手里的。马云说过一句话，特别推荐的是， 如果一个方案提出来，大家都认为“ 可以”，那么它不一定考虑。为什么说呢？马云说特别坦白：大家都觉得可以，凭什么最后的成功者是你？

另外，多人共同决策，虽然拥有的信息多些，但是，也有很多问题：

+   1. 大家的信息能不能充分交流，能不能取得信息共知，这是第一个问题；

+   2. 能不能把大家都基于这些共知信息，都站在公司的高度去决策呢？做到这一点，其实很难，因为每个人的认知水平不一样；

+   3. 每个人有各自利益， 各自的格局，所以，想统一事情的时候，出发点会不一样。比如，A管的事情不同，同一件事情对于大家的好处不一样，同时，有时候信息充分了，反而容易导致更多的利益冲突，只是这些冲突不容易被看到。

所以，多数人决策并不一定比一个人决策更好。

还有一个更要紧的事情，就是每一个人的肚子不一样。管理学上有一个概念，叫“ 胆商”，英文叫Guts。很多决策都要冒风险，而不是用“ 胆” 的，而班子成员里面有一个每个人都有冒风险，如果大家担风险的能力也不一样，多人就是共同决策风险分担，很多人投票的结果，如果用投票的方式，最后投票的结果，很可能是很保守的事情，都被否决。这是管理学，我经历过很多，特别是在体制内。
