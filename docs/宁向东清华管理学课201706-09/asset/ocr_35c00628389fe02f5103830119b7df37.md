# 1、哈佛的案例分析

![](bbox=[0.08, 0.47, 0.98, 0.53])

在我看来，管理学根本没有一定之规，管理学的学习主要是经验共享。这个结论是我在给哈佛商学院的，全世界一流商学院的课，直到来在哈佛大学上完结之后，我就没有再去其他商学院问过这个结论，说得有点满，是表达到了一种强烈的自信。

让我先讲自己的一个旧事开始说起。2001年，在我已经做了十数年教师之后，我再次走进课堂，成为了哈佛商学院的管理学课程助理，这个课程历时3个月，是我改变我对管理学认知的一个主要事件。

首先，哈佛的课程收费特别高。在2001年，每天高达1000美元。按照当时的汇率，大约是8000元人民币。当然，哈佛的服务也非常周到，连吃饭的餐具都有人帮你收拾。生活是比在普通的五星级的酒店的水，我这么说不是为了让您有某种想象，而是告诉哈佛不给我买教材，不是因为差钱。

我学生员的位置，8个人住一套一室一厅，用于居住的房间并不大，但是，客厅特别大。当行李生把我的房间之后，让我非常吃惊的是，所有的几块教材都叠好了，整整齐齐地放在每一个几米长的书桌上，案例和黑板一起，叠起来有一米多高，但是，教材却只有一本薄薄的人门综合《教学简介》，开课一周，我也没发现发教材。

有一天我终于忍不住了。教公司购买课的教师说，哈佛教授的形象比较敏感。他曾经给我讲过他的二号人物，教授权威。我说去当过兵，他为什么没有教材？记得当时老师是这样回答的：‘我知道哈佛跟其它学校不一样，是100%的案例教学，没有学校的纯案例的那所学校是50%教学，50%是上面案例。但哈佛100%是案例教学，课堂上以案例教学为主，案例分析为主，难道我们需要准备案例时也不需要进行案例，不需要教材了？为什么学院不给我们发一点教科书呢？’

流动教授的回答也特别直接，他说：‘在我们看来，商业世界只有问题，没有理论。所以，我们只提供案例，帮助你去分析，帮助你去找到你想到的感受。至于你需要什么知识，需要什么，需要那些知识，你可以去图书馆去查阅。’我接着问：‘你拿公司来，像公司对待这种技术的非常大的课程也是一需要教科书的吗？’流动教授说：‘不要。’然后，他对我说了一句话影响很深，他说：‘真正的财务能力，其实是对话的。后来我才渐渐体会到这句话的意境，我认为这句话背后的意思是说，作为数字到一些市场上，他们本事就能够通过数字者看到一些市场上的。

在哈佛，案例是一切的核心。我们现在很多人，以书为例，就是商业界的做法。有人经常觉得：你看哈佛的事做写成哈佛的案例，其实看，哈佛的商业，是围绕着一个人的病，而且更重要的是怎么去作出正确的诊断。同时，哈佛的案例分析不是，而是在一个案例中，教授的任务是教学生，在一个案例的分析中找到正确的逻辑。
