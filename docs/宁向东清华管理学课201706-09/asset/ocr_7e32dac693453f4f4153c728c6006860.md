# 054讲：关注结果！团队的任务是共赢

你好，欢迎回到《两个东的清华管理学课》。

今天讨论的话题，来自于我每一个学生以前**的故事**。这个学生管理的销售部门，新人流失率特别高。为什么？因为那些销售骨干为了自己的收入，跟干带着新人一同发展，新人干满半天，学不到本事，又挣不到钱，索性走人。为什么有些事骨干愿意带队伍呢？道理特别简单，因为他们和其花精力去带新人，还不如自己把力气花在自己身上。虽然团队业绩不佳，但是他们的个人收入却不少，自己有得赚。

我问学生，你们都做了什么？学生回答说：我不停地和他们说话，说之以理，晓之以情，但说一次，也就好那么几天，不能从根本上解决问题。我又问了一些我报根源上面的向方的细节。我反复地提醒他们，如果你是那些销售主管，你会愿意带新人吗？学生想了想，说：“不能。”

我说，这不就结了，你自己都做不到的事情，凭什么让别人做到？

# 1.利益相容

我认为他犯了两个错误：

+   1.  销售骨干的本事，就是多年来摸索的客户资源、以及意蕴着心血多采才获得的客成跟过打拼出来的经验。把这些东西传统给别人，很少人有人会这么的觉悟；
2.  他的那个团队，本质上就是个利益共同体，建立目标本来就是利己职业体，你要动这个，还要，还要，要把他建设成为一个事业共同体，从定位上搞错了。既然大家就是为了一

“个利”字，那就应该围绕“利”做文章。

中国有句古话：教会了徒弟，就饿死了师父。所以，古人手艺人，都是给师父亲干上多少年的杂活，直到有一天，师父才不差不多了，才把手艺传给你。这也包括三种情况：

留在师父身下，再给你一个娶了一个有经济实力的师父气或或交其子，没有钱能再分给你去生发；

师父觉得你不错，把真本事传给你，但是，你要发财或立字脚，必须要多去多里去外去做生意；

师父把你当作信的人，你赖了钱，师父要抽上来几成。

这其中的道理很简单，不传你，是利益相容；传你的前提，就是利益相容。我不能瞎说。师父没有损失。可是，在中国棋界关于学费要不要提前交清全的杂费上争了新鲜，又显得没有新的时代了。我其实，利益关系已经出现了到新时代了我的话，在利益分配制度上作了一些调整，情况迅速得到了改变。

# 2.明确团队定位

我下面再举例，我所做的两个工作，希望对你有一定启发。

+   1.  他把整个骨干的考核目标上加上了新人流失率这一条，从新人流动率得到所有效改善。骨干可以从中获得收入。在执行这个措施之前，骨干从来不在招聘新人方面花太多，有了一些政策作助动，骨干开始认真去筛选新的人入营，甚至主动向己找徒弟。这显然在公司的老骨干帮助，业绩进步变得比较快，业务，流动率也进一步降低。公司，从新人的业绩里面拿出一部分给老人，作为人才培养基金，在年年会上一发放，形成了一波老人带新人的浪潮。
2.  学生起草了一个老人带新人的分配制度。对于重要客户，你认为是应该让老人老，不必必须由老人带队助助团队工作，新人力有义务参与老人提高团队，业绩奖金的70%由老人获得，剩下的奖金由老人根据新人的表现定出一个考核系统，公司根据情况从另外的30%中给到奖励后发掉给老人。他之所以这样，一方面，是为了给老人带新人设一个门槛，为新人贡献的人，老人可以增加服务对象的数量和收入。另一方面，这个规定鼓励老人放手由新人去做，老人只是从旁指导，如果服务成功了，新人和老人的业绩奖金则三七分记，新人拿七成，老人拿三成。
