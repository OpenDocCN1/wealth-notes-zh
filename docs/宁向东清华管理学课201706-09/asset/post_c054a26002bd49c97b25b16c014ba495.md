
作为领导者，你的精力是有限的，你首先要判断的是，花时间和某个下属建立怎样的影响关系，这是不值的。如前所述，要注意去发现这种潜在的机会，并且保持连续性，形成积极者。比如，对有些具有好奇心的追随者可以提前告知他的方案，来让他产生亲近感和道德感，明天全公司都要知道的事情，提前一天在办公室里和他下招呼，这会一下产生下属极强的归属感。

我看过盖洛普公司的一个研究，这个研究跟踪了100多个工作团队后发现，一旦一个人感到更多没有得到重视，他的动力没有得到肯定，他的努力没有得到激励的时候，对工作的专注度就会非常低，他大约有50%的概率会把心思花在怎么搞好工作上，这一点其实我们都会有体合，而一旦我们获得很大的能力受到尊重时，自己是领导关系成立后，这个时刻的工作投入程度会非常高。按照盖洛普的研究，这时候的工作投入度会上升到73%。

这个统计就说明，当下属觉得内在被机会充分肯定之后，他们工作的动力会被放大强化。这就是为什么领导者需要注意培养和那些重要下属之间独特的领导关系，也是为什么到今天仍向你的一个个性概念的原因，这是你先实现领导模式的第三步。

## 1. 创业领导力

今天的核心概念叫“创业领导力”，这是1999年提出的概念，背景是最早从事创业的人发现，他们所需的领导力，与一般意义上的领导力可能会略有不同。不同在哪里呢？根子上主要是因为以下四点：

- 1. 创业企业就像风雨飘摇中的一叶小舟，未来相当不确定；
- 2. 创业企业的生意逻辑，还没有完全打通，产品和服务都需要有时折腾；
- 3. 创业人的信念随时会遭遇打击，外部突然袭来的危机、内部骨干的流失，都会不断消耗创业者的心力；
- 4. 创业不是按部就班进行的，组织需要灵活多变，而对组织的承诺却十分脆弱。

我下面要讲的例子，这家企业不大是一家创业企业，但是，故事中的主人公所表达的领导力，可以特别地用来说明创业领导力。

这个人是宏基公司的CEO，名字叫陈俊圣。大约十年前，宏基的老董事长林旋来北京，我有个幸运地见到他一面，并请过他问课。那位应该是最早历史大发展最记本，当时听说陈先身体不太好。后来又听说，宏基请了意大利人兰奇来做CEO，接管了陈先生的生意。宏基开始全球扩张，在欧洲设立了另外一个总部，接着又风马牛了两年，之后就从我们的视野中消失了。等到宏基再次出现的时候，它已经变成了一家并购企业，年营业额高达几百亿人民币。我们身边也很少有人使用宏基电脑了。

![](img/e9c4ead90d162cb22377bd13386f3198_91_0.png)

陈俊圣就是在这种情况下接手宏基的。某种意义上来讲，陈俊圣为宏基和创业企业多少，但他仅用了两年时间，就让宏基的业绩转正，止住了亏损。那陈俊圣究竟做了什么呢？

据说，陈俊圣到宏基之后，从来不讨论过的问题。他用过话是：解决问题的速度，永远赶不上产生新问题的速度。所以，他把自己想主要放在了一个未来。然后，他把自己定位为公司里的“第一号业务员”，满世界跑客户。在一开始转他先光，他把家都全出发，不出差就背一只大号背包，里面装着十几款笔记本电脑。

陈俊圣每次出差都做七件事：

- 1. 了解所在地的业务情况；
- 2. 与下周进行充分沟通，甚至在现场指导销售人员卖电脑；
- 3. 和客户吃饭；
- 4. 会见记者；
- 5. 去看售后服务中心；
- 6. 到店走走，与店员谈话，看有什么产品卖得好，什么产品卖得不好的；
- 7. 较重要的一件，与员工干吃饭。

好，讲到这里，我们不再多说陈俊圣和宏基的故事了。我们看看刚刚已经叙述过的内容中有哪些要点值得你参考借鉴。我用这样几个词来概括创业式的领导力，也就是创业领导力，不知你是否同意。“未来”“现场”“吃饭”，这六个字，我认为是每个创业者都需要的，也是创业领导力的核心。

## 1. 未来

首先是“未来”，创业者要为“未来”而战。记得有一处企业家给创业者做过这样一个比喻：别指望当航海者，先做一个打不死的小强。“小强”这个词来自周星驰，周星驰演有个片子样子，其实，他也是那种演出了创业者一样，最开始也是个人物。你还记得周星驰演的《喜剧之王》吗？演的其实都是他自己，他对着大海呼喊“努力！奋斗！”，这其实都是他自己的心声。

![](img/e9c4ead90d162cb22377bd13386f3198_91_1.png)

当小人物不可怕，关键是你一旦成为了创业者，你就该以完全不同的心态去做小人物。一个心里装着“未来”的人物，其实就不太像小人物了。我认识的一个朋友，第一桶金来自于一个饭店。他刚开始的时候，开了一间小饭馆，没有员工，没有菜场，大家聚在一起，刚刚吃完饭，他就不想动了。我的朋友来吃饭，他还在，所有人里里，只有他要求起来。明天是什么可以不来，但只有他不能。明天是什么？明天就是未来。

怎样布局，怎样展示不同产品之间的关系，乔布斯不放过每一个细节

你知道吗？就在即将开业的前几天，乔布斯突然意识到，在现场的试区是按照自己的主观意志定的，没有考虑到客户的感受，包括客户在店面中流动的线条。可能路线不对，对客户的影响就不同。为此，乔布斯决定，苹果专卖店的开业时间再向后推迟几个月，用来调整布局、调整分区。调整之后，客户对于苹果的各种产品之间的联系，就跟原来有了完全不同的认知，今天美国人所谓的智能家庭，基本上是一个平板为中心的，而这个格局直接追溯到的是乔布斯的试验现场。这就是现场的力量。

而这种“现场主义”的精神，值得每一个创业者学习。还记得上一周我和你分享的话吗？你和乔布斯的差别，不在行业、不在规模，而在于你们的认知。

## 3. 吃饭

创业领导力的第三个内容，就是吃饭。领导他人，很重要前提是了解他人，要倾听他人。而倾听他人的最佳情境，我觉着就是饭桌。所以，我经常建议老板多找人吃饭。平时吃饭，不在于吃什么，而在于在什么情境下，怎么吃、用怎样的心态吃、和谁吃，几个人吃，这都是有学问的。

和员工吃饭，是老板最大的学问之一，创业者要格外注意：每一顿饭，都是工作。

首先，既然吃饭的任务是联络感情，了解他人，你就不要在饭桌上自顾自地、滔滔不绝地吹牛，而是要静下心来听骨干和员工吐露心声。平时他们可能听别人说，你要学会把自己当成听客人，让员工当主人，让他们多讲。吃饭，核心的目的就是要让员工打开话匣。所以，怎么安排吃饭，谁主不谁宾，如何排布组合，这是门学问。这个学问，也是要吃一段时间，才能修炼出来。

第二，饭桌上，有两种吃的东西，一种是饭菜，你要品滋味，另一种是员工的话，它也是饭菜。你也要品尝味道，并且还要把滋味记住。我和你说分享一个观点是：你要听出三种话，带有你理解的员工的话，你听新的员工所说不一的，他头脑里想说的话，这个三种话是不一样，他头脑里想说的话，是水鱼缸里面没放掉的鱼；他说得出来的话，是做好了端上来、正在你眼可以吃的话，是做好了端上来、正在你眼可以吃的话，是像正在你眼可以吃的话，是像正在你眼可以吃的话，是像正在你眼可以吃的话，是像正在你眼可以吃的话，

黎明时分，约翰逊记上心头：商店内部不能只按照公司的四款计算机产品线进行划分，还应该考虑顾客会想什么。他说：“比如，我想知道一个‘电影区’，在那里我们可以用几台Mac电脑和PowerBook，运行iMovie软件，向顾客展示怎么从摄像机中导入文件并编辑。”

（由于篇幅所限，省略掉几段话，大意是：约翰逊把这个想法告诉了乔布斯，乔布斯大感兴趣，但知道，约翰逊是对的，于是命令一切从零开始，重新布置了店面。）

乔布斯喜欢向人们讲述，他所做的每件漂亮事都曾有过返工的时候。当他说得不够完美时，就会重来。他对团队开始做这些事。他讲到了在制作《玩具总动员》的时候，知道这个颜色原本是一个令人讨厌的家伙：黄要金塔的制造过程中也出现过一些问题。他说：“如果你发现有有些事做的不对，你不可能只是忽略它，然后说‘以后再处理’，这是其他公司的做法。”

苹果样板店终于在2001年1月完成了改装工作，乔布斯请大家重新去前往那里。他先在白板上向大家讲述了他的设计理念，然后带大家乘面包车前往两英里外的样板店。在了解乔布斯和约翰逊最好的商店之后，大家一致批准让项目继续完善，董事会一致认为，如果零售品销售和品牌之间的关系提升到了一个新的高度，同时也能确保消费者不会把苹果电脑看成戴儿或康柏那样的大众化商品。

# 039讲：女性领导力 | 身段柔软的力量

你好，欢迎来到《宁向东的清华管理学课》。

坦率地说，在很长一段时间里，我对女性领导力这个话题并不以为意。虽然华为有孙亚芳，英特尔有格思林，联合利华有谢瑞博，但我在觉得女性领导力这个话题是一个噱头，骨子里并没有什么真正有差异的东西。直到最近，我开始关注如下一些人，我的观念开始发生了变化。

## 1. 著名的女性领导者

这些人包括德国总理默克尔、脸书的COO桑德伯格、社交的CEO雷曼、百事可乐的CEO约贝、IBM的首事兼CEO罗茜·罗德辛集团的二号人物黄秋莲……这个名单还可以拉很长。

先说默克尔，这位世界历史上任期最长的一位女政府首长。第一次当选总理的时候，她只领先给对手一个百分点，执政到了第三个任期，她打破了“任期越长，连选越难”的魔咒，领先对方竟高达16%的选票，让对手毫无悬念。默克尔凭什么呢？

在你的心目中，你可能觉得默克尔就是一个铁娘子。但现实不是这样的，你知道默克尔的家乡在哪吗？美国总统一上任，就会立刻跑到白宫；英国首相搬进唐宁街10号，德国总理其实也有官邸，但默克尔却一直和先生住在此之前公寓。默克尔的警卫很稀少，一辆警车，两名警卫。公寓的门上写着她的先生的名字。那个公寓楼，与北上广的豪宅又名相似，逊色太多，就是典型的德国中产阶级住宅。

![](img/e9c4ead90d162cb22377bd13386f3198_93_0.png)

默克尔住得很随意，而且还自己逛超市、买东西，亲自下厨做饭。一个寻常的家庭主妇做的事，她一样都不少。同样她能做到那么好的保持她的平常心。她很少当众反驳，相反，格外注意倾听大家的意思，注意如何把事情做好，作出最正确的选择。默克尔做事部前就决，不栗不慢。

据说，这是因为一位歌剧演员曾经跟默克尔说，当到面临难题的时候，到时间会说你说出最好的建议。默克尔非常欣赏这个建议，她就常让周围的那些些提不起同问检验的想法，最后留下来的一定是无可替代的选择方案。所以，她一定的是从死回各种压力和难题，很多时候都不简单地去决策。

再另外一个女性领导者桑德伯格。扎克伯格在创立脸书之后，无法应对原的管理事务，这时在注意到了谷歌的全球副总裁桑德伯格。在经过短交谈之后，扎克伯格就认定了会挖到桑德伯格，他的桑德伯格去了长达两周，终于，据说在六个月之内吃了50顿饭，挖到了这个他心仪的COO。扎克伯格说，没有她，脸书就不是一个完整的故事。

桑德伯格进行脸书工作后，媒体普遍都不看好，她做事身段较为柔软，在脸书这个工程师文化，界面是的公司里，她不停地给大家拉关系，推她的广告文化。据说，她常常穿梭在几八百人的大办公室，坐下来和骨干员工交谈，推她的广告策略，一点都不像个COO，总之，经过一段时间的努力，脸书开始在文化和产品上转向，为了支持这个转向，扎克伯格甚至每隔一个月亲自去放一个月的假，给桑德伯格留下施展的空间。而桑德伯格也不负期望，成为帮助脸书盈利，扭亏为盈。

![](img/e9c4ead90d162cb22377bd13386f3198_93_1.png)

今天，我要向你介绍一位女性领导者，她是华人界郭台明。他也许没有听说过这个人，但是鸿海集团和郭台明，你一定知道，它是世界工业集团化的企业，在全球有120万人为鸿海最多了。黄秋莲，就是这个大企业集团帝国的二把手。要说她对郭台明有多重要，郭台明曾表示，所有的投资项目，如果黄秋莲不签字，你不敢送到我面。而在鸿海集团，有一个非常有趣的问题，就是郭台明管的部门，我不一定能拿到钱；但是，黄秋莲的项目，你一定可以拿到钱。为什么？因为在鸿海，黄秋莲大家叫做“钱妈妈”。

鸿海集团发展的四十几年的时间，郭台明身段非常大动，但不一来不变的就是黄秋莲。黄秋莲不仅不变，还大权在握。那她身段什么样？就是“圆滑柔软”，身段软，不争夺抢，平易近人。当然，你如果惹她了，她也会骂人，但骂人的人会有私人对手，不对事。所以，换别人也会心胸口服，年底聚餐也会主动给过去敬酒。当然，黄秋莲在聚餐的时候，也经常和大家一起喝酒，非常平易近人。

总之，这些年对女性领导者研究得多，我发现女性领导力这个概念上真不是我以前想的那么，很值得我们认真对待以前提，进入深入探索，找到方法，供养有参考的。那么，下面我将梳理研究的线索上，帮你做个介绍。

## 2. 女性的领导风格

1990年，两位美国学者研究了女性的领导风格，发现女性领导者的核心差异表现在她们更多地呈现出“民主型女性”的领导风格，而男性领导者则更多地呈现出“硬权力”和“权威”的领导风格。而2000年之后陆续的研究表明，女性领导者在领导行为上更多地具有“社群风格”和“交易风格”，具有更加明显的“母性关怀特征”。

具体来说，女性领导者更加包容，更加虚心，更容易换位思考，替他人考虑，也更加的主动个性关怀。这种基于女性特质的领导方式，更容易让领导对象受激励，感召力，因此也更易被影响。

那么，女性特质中有哪些内容很重要呢？美国曾有学者家顾问公司里发起了一个研究，我们概括了一下研究结果，复述如下，供你参考：

- 1. 男性领导者更倾向于从自己的角度去发起问题，例如，沟通工作时不仅会，而女性领导者比男性更务实家为，这样就能够有全面的信息，能够更好地将这些信息综合起来，所以对于女性整合力上，有看特质上的优势。
- 2. 女性的耐性更强，持久力也比较好，所以，面对多数人都做不起和做不成的事情，她们的信心比男性都更主动而更高，这往往会导致意料之外的结果。
- 3. 女性特别十人，更愿意看见，她们也更愿意和别人分享自己的意见，她们问问题常常在探讨过程中较为充分，这就会让她人们在决决时过程中，可以找到更多的声音，也可以更加全面地作出决。
- 4. 女性具有更强的牺牲精神，她们更倾向于为什他们为价值的事牺牲牺牲。这是能女性的生涯就有一个关于活夫的人生过程，其实就是一个无法活夫的过程。所以，女性更容易把那些沉重的负理，变成动力。

听到这里，也许你同学已知道自己该怎么强化领导力了。那么，对于女性，我们能够想到什么启发呢？答案是最直最见的。以上两点，是对于女性领导力的总结，讲的既是“why”，也是“how”。我相信，对你一定会有帮助。
