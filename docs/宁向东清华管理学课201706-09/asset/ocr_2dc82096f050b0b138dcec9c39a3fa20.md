# 014讲：情绪｜第一生产力

你好，欢迎回到《宁向东的清华管理学课》。

昨天我们讲到达效应，今天我们来讲讲在这个克效的后程研究中，学者们发现的另外10个现象的现象中可能令你觉得的，当你用相对简单的任务考验他他的时候，他觉得得太小材料，而你，当他换成毫无一点的事情，他又特别容易直接败，士气低落到一滩稀泥。这就引出了一个重要的问题，我们应该如何建立起积极情绪，并用积极情绪来激励他人？

你可能觉得情绪只是一个管理学中的辅助概念，以为我要讲一个添油加醋的东西。但我要告诉你，情绪恰恰是目前人类以人类管理的最主要的一个管理概念，以前可能认为管理中最最重要的任务是决策，而决策又是最所谓 的“理性”，但今天要告诉你，情绪才是决策过程中的主角。

# 1、从笛卡尔到达马西奥：人类认知的大反转

我今天讲的课涉及一个400百理性主义的故事，也是人类认知的大反转。

还记得大科学家笛卡尔吗？他有一个名言，叫“我思故我在”。

这句话是一位科学家、数学家、生理学家、发发现条件反射现象的巴甫洛夫曾经说过一句话：“我们的起点就是笛卡尔。”

那么，笛卡尔给了一个什么样的起点呢？最核心的概念，他把人分成了心理系统和身体系统两个部分。心理系统专门管思考，身体系统专门行动。身体系统不是思考，只接受心理系统指挥。而我们的身体系统，在他看来跟机械系统没有太多区别。所以笛卡尔就说“我思故我在”，意思就是只有我的心理系统感受到了，我才知道我存在。

今天，在一般人的认知体系中，头脑是负责决策的。头脑也分成不同区域，不同的区域有着不同的功能，有管运动的，有管记忆的等等。神经科学家就是负责把这些器官送到脑体的不同部位，产生不同的行动，不同的动作。其实，对人的这种认知，本质上仍然是笛卡尔，是理性主义的。可以讲，笛卡尔就是理性主义的大师。这个传统不仅支配了科学，也支配了经济学、管理学，甚至是心理学。

![](bbox=[0.08, 0.435, 0.92, 0.505])

但最近30年里，我们发明了许多科技创新，比如核能的研究核磁核磁，比如PET技术等等，这些技术可以帮助科学家看到人类脑部神经活动的反应，所以可以让我们说这些点都是脑，但现在就是能带上一头脑做实验，这才是真真切切地核。那么，实验又发现了什么呢？

最重要的发现就是：人和身体系统是密不可分的。简单地说，躯体机构组成了你的身体，而你的身体机构通过种种生物化学反应产生心理运动，心理运动又影响了你的身体。用最简单的话来说，就是可能并不存在着心理系统和身体系统这样两套系统的区分。这个区分是笛卡尔所发明的，但其实我们是一个完整的有机体，在这个有机体里，情绪是一个最重要的内容。

首先提出这个想法的是一位神经科学家的专家，他的名字叫达马西奥。1994年，他出版了一本书——《笛卡尔的错误》。但这本书，并不好读，就你，因为你太深了，今天讲课给到你，就是希望你知道了这一回事，用到管理中去。

![](bbox=[0.08, 0.7, 0.92, 0.775])

达马西奥在这个书里，重点讲了两个病人。这两个病人，一个是因为工作，头做脑损伤，另一个是因为脑部发癫痫，受过手术。但是，当他这两个在做恢复健康之后，他们跟正常人没有什么不同，身体没有不同，智没有不同，也可以工作，可以结婚。他们唯一的不同就是很难再不稳定，也不稳定，也不稳定。就是我们判断能力出现了问题。后来，我们读到达马西奥的学术论文，他先把进的设备在很多人身上做了实验，发现了快乐的情况。所以，达马西奥断，情绪无法从决策中，是能不能脱离情绪，来进行所谓理性决策，人的所有决策，都是情绪参与的结果。

比如，我们在决策上常常会比较乐观的判断和决策，但事后又有点后悔。但为什么会有这种口气的坏感觉？是因为人体上上两个活法，气氛及其舒服，一片喜悦。所以，达马西奥认为，这就是情绪的作用，因为情绪，我们做出了理性的或者是不理性的选择。

# 2、情绪管理

接下来我们就展开讨论了，因为科学家至今还在探索脑和心情的关系，我们还没有找到一种方法，我们不能告诉你们研究好了再说，我们一定要知道情绪和智商的关系。下面，我给大家三个最重要的观念。

第一，情绪的产生，是大自然的一个自然过程，不存在只有好心情，没有坏情绪的可能性。产生好心情和产生坏情绪，都是一个自然的过程。而情绪会参与到我们的决策中。这一点要记住，这是讨论情绪管理的基础。

第二，情绪管理本质，就是控制自己产生好情绪和坏情绪的比例。有一门学问叫“积极心理学”，学者们建议大家掌握这个比，那是3：1，也就是说，好情绪和坏情绪的比例是3：1。那如何能掌握这个比例呢？我个人的经验告诉我的事情，情绪是人的积极的想法，认知是人的多愁善感，一个可积的办法。下面和大家分享一下我自已的故事。

我们看过钻石，美轮美奂，但我们不知道它的开采过程中有多艰辛。我是一直某一天看在了钻石的开采过程，才感受了到那种震撼。

其实，采钻石的人每天挖出的不是钻石，而是大量的泥土。钻石只有大豆子大小，而很多时挖，可能也是翻出了一大堆的泥土碎石，也不觉得能挖到一块钻石。这种时候，人自然而然生出负面情绪，会有沮丧，这是正常的反应。但是负面情感过后，会有挖掘的一定，这就是积极情绪的力量。当积极情绪冲了消极情绪的时候，人就会有积极的行动。

![](bbox=[0.0, 0.0, 0.0, 0.0])

所以，有了这个生命体验之后，每当我情绪很坏的时候，我就告诉自己一句话：钻石，这也是自己一个心里过程，我们天天遇到那些东西，都是硬地里挖出来的无用的泥土，但是没有这些泥土，我们怎么能得到那些坚硬的钻石呢？耐心事和我们的努力必定是正确的。

第三，管理者需要格外注意，情绪，才是第一生产力。管理者首先需要自己的情绪变得更好，同时要要学会把有意识地将这种情绪传播给员工。比如达马西奥的观点翻译成管理学的语言是：一个人情绪差的时候，他的工作表现一定差，而一个人情绪饱满的时候，他的创造一定超强。

我有一个学生，经营了一家高科技企业，虽然我们每天都事必躬亲，但他的产能始终很糟糕，我问他为什么？他回答得很含糊。我说，你的公司需要负责什么？要获取新的客户，需要要大的工作，讨论，比如通常要进头头脑风暴，所以上述过程中涉及到的常态中，你所提的问题必须及时得到大家的回复，或者大家能够体会到，却不容易传递给别人的知识，也就是我们常讲的“只能意会，不可言传”。
