你好，欢迎回到《宁向东的清华管理学课》。

今天我们对着得来讨论下“进取心”和“幸福感”，这两个概念是影响管理者价值观的重要概念。现在很流行“企业文化”，企业社会责任。这些话语，强调要为员工创造更多的幸福。但我今天要给你一个新的理念就是：管理工作的目标，应该基于员工的“进取心”，而不是直接描写“幸福感”。为什么呢？因为“进取心”是管理活动的源头，而“幸福感”，要么是管理活动的结果。管理工作，应该看重源头，而不是结果。这是其中一个原因，还有一个更重要的原因是，“幸福感”靠不住。

# 1、什么是幸福感？

下面，我先和你分享一些关于幸福感的研究结论。你先看看你对这些结论是不是同意，然后再看看幸福感是靠得住还是靠不住。

+   1.  幸福是一种自我比较。一个人感到幸福，或我的现状一定过去的状况好，也应该是说是改善，即过去的自我比较好。如果这个人适应不了，那么一旦他只能一个人的适应是不断增加呢？一旦你的幸福感到这个峰值，后面的幸福感就会结果于这个峰值，其实你的感受是黯然失色的。
2.  幸福感还涉及到人和人之间的比较。自己较好，很多的自我感觉，重要的是，别人不一定不能比自己好，这样才更有幸福。比如大家一块去好，我们往往不会获得更多的幸福感。还说得出去的课，我请教你说的那位朋友呢？当初阶级改革之后，事情上他的收入增加了一大块，基本上应该是很高兴很有幸福感的事。但是一当他知道当年的同事收入比他更高一点的时，他的幸福感立刻烟消云散，剩下的只有不满。

总之，现在很多的研究报告表明，幸福感不是一件很说得清楚的事情。所以，管理者不应该多关注员工的幸福感，并且把这和幸福感追着鼻子走，这样一来，管理工作可能会本末倒置。我从前面的课程中，你应该知道这是一个“与人面善”的课程，我大致强调要建立人性的管理，要尊重很多种规律，这个人的时不要拍。更要注意激发员工的积极情绪。但是，这里我要强调的是建立管理制度、运用管理原理，如果过度依靠情感类的“幸福感”，可能会走到另外一个误区。这个尺度，是管理者需要格外注意和拿捏的。

# 2、什么是进取心？

现在，我们讲今天的中心概念“进取心”。这个概念来自于一个德国学者，他的名字叫托马斯·弗里曼。弗里曼教授通过十几年的梳理，逐渐清楚了一套理论，这套理论是“管理心”的理论，特别适合于21世纪的管理工作。弗里曼的理论已经被西方管理学院的普遍认中，他也讲出一套基于个人进取心的培训课程。我觉得，相比于他，这个理论可能会像马斯洛的层次需要论一样，为大家熟悉。

那么，什么是“进取心”呢？弗里曼把“进取心”定义为“一种自我驱动的工作行为”，员工可以在这种“进取心”下发挥主观能动性，积极主动的完成任务。弗里曼认为，我们现在很多人在使用传统的组织工作设计和业绩考核方法，这都是基于一种“被动工作”的逻辑，组织要分配任务给员工，员工按照组织给予的薪酬和工作方法去做事，用一种“完成任务”的心态去工作，这就是“被动工作”。

我对这种情况的解读是：在原有的被动的工作环境下、工作状态和业绩管理方式下，员工只需完成组织让做的事，把工作只做做好就算完成任务，然后获取相应的评价和报酬就行了。但是，现在的竞争环境是复杂的，经常超出想象的事态，可能是人，一件新事情出现员工原有的工作范畴，这样的话会发生什么？他会停顿。如果管理层，他的组织的反应不够快，就会出现下级的心理，出现错塞。下级认为上级指示不明确，上级认为下级没有执行力。

# 3、进取心VS执行力

讲到这里，我想讨论一下“执行力”。“执行力”这个概念，是中国经济学者的意思提概念。这个概念在中国流行，大概有十几年的历史。说这句话，给你一段旧闻：有一本书，叫《把信送给加西亚》，也许你听说过，也许你的老板送给过你这本书。反应在十几年前，这本书火了。这本书刚出中文版的时候，我也写了一本书，出版社的社长跟我很熟，他手里拿着那本《把信送给加西亚》，对我说，“你如果能写这么一本书就好了”。我问为什么，他说：“这本书看能大卖，你写一问我《把信送给加西亚，美国总参谋要求一封信送给加西亚，送信的人只知道加西亚在战场上打仗，加西亚是谁？加西亚在哪个战场？送信的人全然不知，但他还是能够找到难找全送到加西亚。你现在全国哪个企业不要这样的员工？”老板不希望自己的书一定这么大卖，因为老板们团购。果不其然，这本书的销量很快超过了一百五十万。

但我觉得这本书是一株“毒草”，为什么呢？因为流行的逻辑，是要你明确的指令，并且在这个环境中不变，不变，我们的经济环境变化太快，很多任务都无清晰描述，很多老板文化水平，又太不用的情况下，给一个不明确的指标，员工自身的努力就比企业利益上，天底下有这样的好事，现在谁准备《把信送给加西亚》？它就是愚化一样。

# 4、为员工建立进取心

跟加西亚的一套相比，我更喜欢弗里曼的理论，那是努力建立一个能够激发人的“进取心”的管理制度。增加员工在工作流程中的参与程度，这样管理工作不怕变化，遇到问题，每当有新情况的时候，员工的进取心会让他们努力地寻求改变，而不是被动地抱怨和消极地等待。

那么，如何建立员工的“进取心”呢？有三个要点，值得参考：

+   1.  培养员工的“自启动”意识。具体来说，要创造一个有激励的制度环境，让员工能够参加到形式或非正式的业务讨论来，什么意思？我组织里的事情一定要鼓励、支持员工的进取心。很多工作在报告计划之外，员工发现了，他们不去抱怨而是自己主动去解决，并且这种可以作为可资赞美的行为。就像在家里，孩子洗衣服了，你要收费，向孩子展示，自己把它包了，这就是一个好状态。一个例子，如果遇到了案子，子不见不见，要回家长的要求下去，是不是孩子？如果企业能出现子不责孩子吗？因为企业有自己规则，完全处于一种被动状态，我现在的管理的是员工的自我启动的意识，需要他显现出一种主动的状态。
2.  就是要培养员工的主动性，就是让光动性强。光动性的意思是，就是让员工感觉到自己是有意义的，要用激励文化和奖励他们是有预见性，并且预见性的事情提前预判，提前做准备。其实，我参加很多企业的工作，就在搞营销的时候，在那里，在洗手间里面，有很多的东西，发现领导的什么事，一些仪式的会议，当时领导什么都说不出来，有光动强的人说，就是能够鼓励员工走上路，他们说的都是新话，拿笔去记录上去的公司。
3.  要能够保有有进取心的人员。弗里曼在进行大规模调查的时候发现：当工作总光动性总被要求都是大家思考的问题进行挑战，总被提起要求，而且积极的东西的反馈机制中，弗里曼称之为“令讨厌的人的机制”。如果干些工作，今天你会给人“银高手低”的印象。所以，这样的入住会让人变得沮丧的。如果，如果这些人表现出现进取心，如何保护他们，这要个长期，但是非说要。这些人对于组织的发展，是非常必要的。

总结一下，进取心是未来管理工作，越来越多的员工参与创造性地发挥作用。如果你用传统的的管理思路，环境一旦变化，出现了新的管理问题，员工就会变化，等着你对工作任务进行“重新定义”之后他才动。这就麻烦了。但是如果，把进取心作为管理理念的一个目标，员工大高度参与组织事务的“重新定义”过程中，那么组织就有了更多的力量。讲过了，主要注意的是不能望以前能力，人，把。
