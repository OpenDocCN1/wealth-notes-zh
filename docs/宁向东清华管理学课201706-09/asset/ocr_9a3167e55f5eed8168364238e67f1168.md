# 科学管理的发展过程

破掉100年前困局的是两个人——福特和泰罗。泰罗第一讲我们提过，福特是福斯汽车公司的创始人，本期内容的时间圈就讲到他。那福特和泰罗做了什么呢？就是提出了今天听来的，科学管理，科学管理听着挺复杂，其实就两条：第一，把要管理的事情按照作业任务分成若干个程序上的细节；第二，把每一个细节的效率提到最高。

打个比方，你想像一下小餐馆的后厨。没有科学管理的时候，就是一个人又切菜，又炒菜，有时候还得独自掏地板。有了科学管理之后，其实，所有行业就分成了洗菜、切菜、抓码、炒菜等干，每个人干一件事干得特别好；第二，老板监督你干一环节的一个人都为了做标准，就能效率、做到这个标准。

科学管理，你可以，就是看，是身一位管理活动，到当前为止，给人印象的管理其实都是基于这两条的。本质上就是把作业过程分析，然后改善每一个环节上的效率。

让我们再回到历史，福特汽车。最早生产的汽车有好多型号，为了提升生产效率，他把生产一种车型—T型车。然后，他把T型车的整个生产流程分解为84个步骤，这是件了惊人的工作。因为一旦拆成了这些工作，就产出了两个概念：“零部件”，也产生了专业化分工，就可以用装配线来组织生产了。

![](bbox=[0.2, 0.66, 0.8, 0.72])

把制造工作进拆解，其实最早提出这个想法的不是福特，当年，拿这个事来1000支手枪。在当时，是一个大工程。曾经一个会试提出把枪的生产零件化，然后组装，但拿破仑：“如果样生产的，那枪的老师徒不是白丢了？”，所以拆解的师傅并没有被批准。

后来1798年的时候又有一个大工程，美国军方要买一万支长枪，接这个工程的商人根本不会做，他为了证明没有工厂，也没机器，就是说，为了证明自己不行，他就把这个长枪制造过程给部化，然后完成每个局部的专业去给他办，而自己就干一件事，就是当政府官员的面把部件合成一支成型的枪，都证明他对政府官员说：“你们尽管在战场上打，把砸到多人都都不用怕，我肯定能给你做出足够的来。

而福特最大的贡献其实就是把这些想法在汽车生产上实现了，他把部化、流程化和装配线这些东西通通到了他的工厂。

福特干这件事的时候，泰罗还闲着。还记得第一天的内容吗？泰罗是运动员出身，所以能最熟悉的竟然是数学。所以，他面对企业是无法量化的现，首先他关注的是效率，泰罗是。他发现，老板们不知道工人每天能完成多少产量，所以很多人在完成一个作业的同时，需要做什么工作，每个作业需要多少时间，然后，再计算一个人完成全部动作应该花的时间，再进一步推算出工作一天应该达到多少产量。

所以，科学管理的出现，其实是在两条平行线上同时开展的：一个是福特，他考虑的是车一天能开多少个小节；另一个是泰罗，他研究的是每个生产环节中，工人应该通过多少个小时动作，才能最高效率地完成某项活动。

![](bbox=[0.15, 0.0011, 0.85, 0.0012])

福特和泰罗的共同努力，最后都体现在福特工厂的装配线上。一条生产线让人实现了彻底的分工。每个人都以最有效的方法从事他的工作部门，不用浪费的弯转，不用做任忙无实动作，不用去考虑别人可以工作。工人的思考，工形式，显然有取效率的大幅提高。所以在19年的时间内，福特汽车的车型在美国销售了1550万辆，仅福特一家公司的总产量就占了全世界轿车总量的一半。

后来有学者研究，因为科学管理的出现，生产一辆汽车的工作时间减少了三分之一，而且数量还有保障。1934年，美国有一位非常有名的独狼---职业杀狼的巴罗。巴罗写信给福特表达他的感戴之情，巴罗说：“虽然你的工作不合法，但这不妨碍我想写信给你，表达敬意。你生产的汽车真是太好了。每次只能以最快的速度离开移动场地，所以我可以福特汽车，因为质量和速度，任何车都追不上我。你要向他表示的敬意。”于是，由泰罗和福特，20世纪基本解决了体力劳动者管理的问题。

# 新困境：脑力劳动者的管理

德鲁克预计，因为泰罗和福特，体力劳动的效率提高了50倍。也德鲁克也说到，科学管理并没有解决脑力劳动者的生产效率问题。而我们现在从从事的工作大多数都是脑力活的。德鲁克说，脑力劳动者，也如知道工人生产率在20世纪不仅没改善，反而下降了，21世纪管理学最大的问题之一。

这就是我们今天面对为什么会面临更加困难的管理问题，生产线的出现，把机器加丁了机器的一部分，机器制造的速度和节奏代替了人类现的能力，由人可以做，控制人提升管理的效率，提高了工作的效率。人类通过先效率把100年前不知道怎么做来管理人的部格了。但是，在新时代，人的创造力占全生产出了比例很大，而人的创意力的管理用秒表是无效的，而如果你失去了人，机器、流水线，提高效累，是效率会另一方一方面的地损失。

我曾经在新加坡参观过一个工厂。在这个企业里，本来也有流水线的，但是原来老板把流水线拆了，把原来的装配品固定在个很大的生产间里，让工人可以自由选择让什么样的员工自己的工作装成部件。在每个员工自己的工位自主性，我回过老板为什么这么安排，他的回答很感。就是想让企业动员有核感的感觉。如今，即使是体力劳动者，他所从事的作部已经不再是单纯的体力，都有脑力参与，也要尊重人的自主性，减少流水线的工作方式，因为流水线的工作往往伴随着外部的强制性。

新加坡这个工厂告诉我们，在新时代，每一个管理者都需要求一种效率上的平衡，就是你来自人心的效率和强制力的效率这两者之间的平衡，这都要更高的管理境界，值得每一个人去思考。

这也是为什么今天我要花这么多时间和你谈科学管理的发展过程。
