# 本局复盘

这一周是导论课，我主要是用一个大家比较熟悉的概念：破局，来帮助大家建立一个关于管理学的基本认识。

我们为什么要管理学的？德鲁克说，就是因为我们都需要选择正确的价值观去做，并且把事情做对。所以，管理学是一个分析、权衡和决策的学习，分析、权衡和选择与人的目的什么，就是破局。

第二天的课题里，我用了资源的关系来定义中国人所谓的“局”，并且与大家分享了三种破局的方法。破局局，其实就是解决了矛盾，第二天的课程里面包含了一个重要的概念：目标。没有目标，其实就没有管理学存在。我同学的话很多首心里面，发现一些人的目标都不是明确的，所以，才会被问问题，因为不知道自己想要什么，也就不知道怎么去找办法。所以，请大家记住，要想有效地运用管理学的智慧，首先，要建立清晰的目标。

第三天的课，讲了科学管理的逻辑。科学管理的逻辑就是机器管理者，或者说是生产线条的问题，其实后者就是前者管理的逻辑。在我看来，管理难度，就是软性的生产力。很多同学认为是制式管理，还是人多问题，我认为是本机和机器管理是人的自身能力之间的关系。

这一讲，我是后面讲投入为行为、领导方法、团内、内容领域等概念。

第四天的课，讲了借势的问题，实际上是为其势，为客户，战略等等内容铺垫的。我内容告诉大家的是：管理的问题，有很多不是关于非市场竞争的，需要一些特殊的工具和方去找到策略和答案。比如，如何帮助别人。课后的阅读资料，来向一本叫做《时间问题》的书，是一位美国作者的著作。看什么，我会给大家推荐这本书，每个人都有机会，情也不同。但是，使用方法去挑机会窗时是要的，管理问题就是要求给大家这样思考。《时间问题》是2014年的新书，反映了管理学界最新的研究水平。

周五的课程讲关系文化的正面价值和负面意义，课程涉及物文化冲突关系文化，这是管理的一个方面。其实，我提到管理是一个连续局，这个过程，这个观念更重要，我想强调管理工作的连续性和动态性。

总之，这一周是导论课，目的是为学习管理建立一周整体的框架。有些同学着急破局，而且想直接得到答案。我想说，不着急。在华科MBA和MBA时，他们也有一些，我开出的课程是学时间积极，一大堆问题，想要答案。其实，越是负责的老教授，越不会直接给你一个直接答案的。渐渐地，大家都会安心上上课，考试了，等到两年的课下来，毕业时，水平自然出来了。

这一年，会把管理学中认为，去做的。新新的，在管理思想体系中，有有价值的，都逐渐拉到你后面。我相信你只要坚持下来慢慢学，一定会很有大的进步。

# 问题解析

这周大家要留了很多话，我都看到了，你们不仅用文字没没有发到回复区。我写希望你要坚持写，不是写给我的，而是写给自己的，写一遍，思路就清晰很多。很多人说，我写，是因为思维凌乱，思考欠差，我建议你坚持写，写多了，思考才就会出来。

最后，有同学给一个问题分析一下他的同学，主要针对他的处境，我也希望同学们帮他分析一下，解燃眉之急。

两家事业单位A（自收自支单位）和B（全额拨款单位），A单位一共13人，有4名编内人员，主任、副主任1人，2名科长，带编外9名；B单位：共12人，全是编内人员：副主任1人，2名科长、9名科长。现在A和B已经合并成为《某某服务中心》，格任一新位、两局4局长。A单位主任是前任一把手，称呼仍是一把手，两名副主任分别是以前A单位副主任（分管两个业务线）和B单位副主任（分管两个业务线），副主任仍是以前两个单位的老科长。合并了一半了，目前C单位是矛盾重重，剑拔弩张：副主任与主任矛盾；副主任水火不容；A单位9名外聘员工全在副主任管，觉得单位没有，3单位9名编内职工（均在B单位）觉得单位担心自己正式职工的尊严得不到体现。我是原B单位一名业务科长，现任副主任手下分管业务线长，易是两单位合并后综合难度最高的人，已经完全适应了新的领导下的局面，工作业绩也突出突出。昨天下班后，突然接到单位B方领导的电话，说他已经忍气不过，B方领导到纪委找上级机关弹劾主任，问我要不要参加，我可以对主任的做法很不满，请问我该如何抉择？我该怎么做？

+   1. 我看待此事的乐观面，就是上级来调查事情。我相信他的改革上级领导是认可的。如果他是不得已事上的领导，如果不可收拾，最后，会不了了之。

2. 干工作哪有不惹人的，只要没有经济问题和严重的作风问题，上级都不会处理。多到部门之间的结构，再做些调整。

3. 决定整个事情走向的，是合并之后的业绩，以及上级领导对这个业绩的满意程度。

以上三点是大趋势。

这位同学的问题，就是此时要不要和原有的部门站在一起。这个问题的本质是如何权衡。

+   1. 不站在一起，一万一变了，原来部门同事会打折扣。

2. 站在一起，万一状告失败，会得惩罚，将来不好办。

因此左右为难。

+   选择1：先和领导进行沟通，讲出自己的想法，然后在老同事的告状信中签个字。

选择2：不任何人沟通，直接签名，和原有的部门站在一起。

选择3：旗帜鲜明地拒绝签字，因为你是改革的受益者，从留上看看，你好像是支持主任的。

选择4：生病，或者回家看父母，但是，一个有目的地在逃避，你会给人留下一个懦夫的印象。

当然，还有其它的选择。

不知道大家是否有其它的选择；不知道大家觉得哪个选择更好？我觉得，不同的人有不同的性格，选择也会是不同的。
