# 1、动机理论

几乎每年的留言区，都有同学和我探讨：管理者到底应该怎么管理团队？今天，我就从了解他人的角度，和你分享一下这里面的基本逻辑。

任何人在工作中的业绩表现，都可以归因于两件东西：一是能力，二是愿望。今天把两件事做优，是这两类缺一不可。今天我们不展开说能力，就把愿望这一点说透。

在愿望的背后，有一个核心概念，在管理学上叫动机。马斯洛关于人的五个层次需求，每个需求都可以成为人们的 工 作动机。也就是说，当一种需求成为你采取某种行为的决定因素的时候，这种需求，就是动机。所以，我们要理解他人，其实就是我们善于透过行为去读人，试着找出他们采取相应行为的动机。

有三种动机比较常见，知道这三种动机，对于了解他人特别重要。

+   1. “特别成就的动机”。有这种动机的人，特别希望自己能达到这种优秀的标准，并且在竞争的环境中能够获胜，这就是我通常讲的“特别有野心和特别希望出人头地”。

+   2. “获得权力的动机”。权力，就是影响他人的能力，也是一个受人自己影响他人承认、自我、自我实现需求的动力。这是自我的驱动力。

+   3. “获得归属感的动机”。通俗地讲，有些人对“圈子”很敏感，他们喜欢归属感。他们喜欢在一个团队里，喜欢跟人打交到。

现在，我强插一个特别重要的话：每个人都可能是多动机并行的，而他的动机是会随环境而变化的。换句话说，这个动机就会成为一个愿望。这就是管理者可以利用的地方。

# 2、动机、愿望、努力和目标

讲到这儿，我为大家介绍一下位管理学大师，他叫弗洛姆。弗洛姆有个理论认为：如果一个行为给人们的认为：是有助于达到他们的目标并被人接受；而判断到某项行为会导致不负面结果，他就会拒绝。

弗洛姆的这种看似很合理，但只局限于一个动机：从动机到愿望，从愿望到努力，再“到努力”目标”的这样一个逻辑，这个逻辑其实是管理者到逻辑。所以，对于一个管理者，在准备开始管理他人之前，必须先记住一个“动机、愿望、努力和目标”这四个关键词。

诺瓦克的故事，是我们理解愿望和动机理论的一个好人。诺瓦克之所以知道这一点，是因为一次在和经销商的早餐中偶然发生的。当时，诺瓦克在经销商讨论关于如何激励员工的时候，诺瓦克说“你们的问题只要求你问问你公司的鱼就够了，鱼特别专家。

有一个甚至说，他在这个行业从业两年了，诺瓦克的鱼在西海岸一条鱼能学会一天吃到鱼。诺瓦克是知道他的下属的缺点，他叫他的下属去钓鱼，他觉得此时的鱼非常。

可他想什么没有想到的是：鱼都静静地坐在那儿，泪流满面。原来，鱼对诺瓦克说：“我在百胜服务了40年，现在我来退休了，不到两周我的故事讲了诺瓦克在百胜的故事。从那以后，他开始用另外的视角去看他自己的每一个鱼人。

诺瓦克是百胜餐饮集团创造了个神话，每一个人都感觉自己被自我尊重。而其他人觉得他像一个片一片轮和一颗螺丝钉，公司让每个人有机会实现自我，去成长。努力。
