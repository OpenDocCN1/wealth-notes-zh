# 041讲：领导争锋｜为什么合伙制不长久

你好，欢迎回到《宁向东的清华管理学课》。

在讲“团队引领”那一节中，我讲了这样一句话：所有的合作，本质上都是资源互补，而资源没有互补性，合作也就无法存在了。这也是为什么合伙制企业的稳定性最高。我当时特别强调，这个概念大家可以不用担忧，两个人合作要么承担，要么就是承担，一两天就说不清楚。索性今天用一次课的时间把这件事给大家讲清楚。

# 1.案例分析

好多年前，我认识的前合伙人合伙创办了一个销售部，他们两人是同事，一个是原来公司销售部门的负责人，一个是新公司里面负责销售的一个负责人。他以前是办公室主任，比如是一个机关，社会交往能力也很强，所以，他在新公司里负责内务，我外面的朋友过来帮助做销售，我提出的想法就很简单，就是尽快把公司的业务搞起来，挣点钱。那个时候挣钱也很容易，头两年，两个人的关系都满意。但第三年，两个人之间就出现一点问题。

问题主要来自三个方面：

+   1. 公司的发展方向上，两个人的分歧就比较大。比如，要不要搞自己的品牌，要不要扩大市场范围。

+   2. 在公司里面谁是老大？我和最先认识的人是那个办公室主任，因为注册了公司的董事和法定代表人，而另外一个人是公司的总经理。大家一查出来，公司资金，谁主公司，原来不是这个，但公司挣了钱，各方面都提高了，这就成了一个问题，中国人都是特别要面子的。

+   3. 一件事，就是原来的办公室主任，现在的公司董事，经常参加一些发言在公司里面，后来我去才知道，其实在公司里他就这样。后来，被营销的那个伙伴也是总经理，因为那个，我一个大将，总经理没说话，但他却留了一个大洞，我也和他很熟的，他说觉得这是一个没有办法说的事儿，人家看中的是搞销了，几万块钱，可我心里却觉得不定董事长报销了多少钱。

# 2.为什么要分家？

为什么我要给他们提出分设公司的方案呢？我和同事坐了一下，我同事说，公司发展的三年了，你现在如果在重新作决定，你还会与总经理合资创办这个企业吗？
