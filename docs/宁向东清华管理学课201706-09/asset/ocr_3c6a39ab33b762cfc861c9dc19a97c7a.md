# ## 1.群体与团队

今天的课，我们从NBA和奥运讲起。在上个世纪90年代之前，奥运会的男篮决赛不是允许NBA的球员来参加的，所以，无论是夺冠的加拿大队和NBA之间的差距有多大，没人知道。第一届奥运会篮球比赛是有规则的，1992年的巴塞罗那奥运会，美国派出了第一支是NBA篮球星组成的梦之队，记得所有美国队的比赛都没有悬念，美国队场均都得有120分左右，其他队大多是80多分，还有过50分的，总之就是其他队各种被虐。

不过，从比赛的意义上来讲，那届奥运会美国的比赛并不是好看，因为那是实力完全不对等的比赛，是一个强力群体，打垮了所有的篮球比赛。但如果实力相当，群体里不论什么打不过团队的，NBA赛场上的每一个队，都是团队，队，没有竞技性，都是互相厮杀，比的是哪支队排得出来。而参加奥运会的那一队，全是明星拼凑的超级明星。如果不是单兵能力太强，这个“群体”不能大获全胜，还真离谱。

在管理学术上，群体和团队是两个不同的概念。“群体”，英文叫group，也可以简称为“body”。它通常指一群人员或团队之间有共同目标或相似关系的组织。团队在组织上，是一群共同目标、成员之间有协作关系的组织。

美国队就是临时拼凑的一个“群体”，它有夺冠的目标，有教练，但是缺少什么，是成员之间没有什么关系，不是一个确切的团队。

# ## 2.协同效应

团队最重要的特征，就是成员之间存在互动，具有积极的协同效应。协同效应是什么？如果两个独立的个体，一加等于二，就有协同效应，多来一个部分，一加就大于二，就有协同效应，多来一个部分，一加就大于二，就有协同效应。梦之队的球员，个个的水平都是2，所以怎么打，都是2+2=4。他们在赛场上各种表演，有时候演出了，就是2+2=3，但即使如此，也比1+1=2要强。这就是明星的力量。

千万不要看错了，两个协同效应，可能2+2=3，一个有效应，而一个明星9，是一个全为小明星协作，就会出2+0=3-9的效果，所以，一个明星加个明星，这是协同效应的力量，也是团队的弱项，后面，我们讲到：好的团队只有一支一流高手，但却配合着一个合格的手。

讲到这里，你一定理解了我们为什么要花心思研究团队的构成，如何讨论建设有效的团队。在整个模块，我们都讨论这个话题。今天，我们先说说团队建设的目标。

# ## 3.网飞的锦标文化

谈到团队，我们可能都会常集体精神等等，但它有个概念常被忽视：就是“任务”。我们为什么需要团队，就是为了实现任务，不能孤立的去“做任务”。NBA联赛，每一支球队，都需要打锦标，所以，要打造出色的团队。打造团队的目标，是为了夺取锦标。所以，团队合作的，就奔着目标去。

讲NBA的例子，人人都听得懂，但是，真正NBA的团队建设逻辑跟公司制度面，却不容易。我们今天讲的案例，是网飞。我觉得，大家现在都关注到，在什么地方公司，不用打卡打卡，随便休假等。你以为是一流高手，就可以获得不错的待遇。我今天是讲网飞的观念是：错了。网飞公司对员工真是很苛刻，一切都按照业绩说话。我曾经都读到过一篇文章，标题就是：不是什么人都N到网飞去试试。
