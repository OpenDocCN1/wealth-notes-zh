# ## 资源关系 | 到底什么是 "局" 

你好，欢迎回到《宁向东的清华管理学课》。

今天，我和您谈谈“破局”的问题。“局”，是中国智慧中的高概念，老外不一定懂，但中国人提起这个概念，都心领神会。在我的观念里，中国人忙了几千年，其实就做了两件事，一个叫“破局”，一个叫“做局”。

# ### 到底什么是 "局" 

那什么是“局”呢？“局”就是身边各种资源之间相互关联和相互作用的状态，叫“资源”。这是一个重要的管理学概念，叫“资源”。什么什么是“资源”：钱是资源，物是资源，名声也是资源，是一种无形的资源。总之，你身边的一切其实都是资源。而这些，资源都是和你有关联的。

人只要想做事，就会有目标。有了目标就有了方向，当朝着这个方向行动的时候，你会发现你身边在一个“局”里。为什么？因为身处固定的所有资源，都跟你有关系。有些资源是支持你的，可以支撑，我们也叫它“正资源”；有些资源是阻挡你的，不能为你所用，我们也叫它“负资源”。人之所以被困在一个“局”里，就是正资源给的太少，你搞不定，就要办法去负资源太多了。所以说，“破局”和改变，就是改变资源之间的相互关系，让自己能够走得通。

所以，本质上的“破局”，是改变资源的状态，正负的资源状态。资源的改变是资源之间的相互关系，让自己能够走得通。

# ### 三种 "破局" 的思路

第一种，就是寻找那些先前没有进入你视野的资源，我可以叫“无关系资源”。然后通过正负资源和无关系资源的整合，当然，就可以完成对负资源的转化，自己找到路。

前几天，我和罗辑思维的CEO李天田聊天。李天田，说当她现在是成功人士，江湖人称“脱不花”，很混乱到今天，其实不知道脱多少场了。李天田公司，李天田没有大学学历，在一家广告公司打工，负责拉广告。她的广告特简单，就是往电视台的广告位，放到广告位。广告没收到，拉到客户，局就破了。这是商业上最简单的局。谁的局？她的老板。老板定任务，定目标，其实老板就是局，是李天田开玩笑说，天天的老板，都是局部的。员工把自己的局破了，顺便也把老板的局也破了，所以老板一定要给员工设好局。在管理学上，这叫目标管理，也叫计划设计。

李天田做的广告行业，破局最重要的资源，就是人。为什么是熟人呢？因为人家信任你，才把广告业务给你。

而那些跟你没有关系、不相信你的“客户”，说到底就是一种无资源。顶多算是一种潜在的“正资源”。所以广告人的直观想法，就是一个地方有一些陌生资源，努力把陌生资源转化为正资源。也许你现在每天做的事情，本质上也是一样。

李天田这个故事，之所以值得拿出来讲，就在于她用无关系资源来对负资源做转化。那天李天田怎么无关系资源做转化呢？

有一天，李天田在一家酒店的走廊里路过，听到会议室里面在讲《战略管理》这门课。20年前，《战略管理》这门课是门很新鲜的课。李天田一门心思听了个五句话，觉得老师讲得好，趁着老师还没走，就溜进去坐在最后排，听课。一般人听完课就走了，李天田没有。她说：“说不定以后有兴趣，那些客户去客户、企业家人也有兴趣。”于是她就想让老师再开一场课，老师讲：“我这里是外来的内训，为对外公开讲，李天田一听就要，不对了。因为公开的内训，社会上是听不到的。所以她开始跟那位老师商量，给她所在的广告公司做内训。

回到公司，李天田找了一大堆名片，都是大公司高管的名片。坦率地说，这些名片说是资源也可以，但其实是没什么用的资源，因为电话打过去，人家不是听广告，理都不理人。所以，绝大多都是“负资源”。正资源，需要一种新的方式建立和这些负资源的关系，起码得让人家理你。说到你里，也许你想到，李天田就是准备用一个“陌生资源”的方式来转这些资源。这个跟来来的“无关系资源”就是培训老师和她对外公内训的战略管理课。

李天田一个一个地打电话过去，不是请人做广告，而是请人来听课。来了20多位企业家，算是讲给一个广告公司的内训。老师的课程很好，企业家们听完，很感动。李天田组织培训的时候安排得很周到，大家也很满意。于是，企业家就对李天田有了信任，资源一下子就变成了正资源。成了熟人，广告就来了，李天田破局而出。

上面的故事说的是第一种破局思路。第二种破局思路，就是对“资源”进行重新定义，找到新的出路。

7-11是日本的一家著名连锁超市。2000年前后，它寻求业务发展，有了这个思路，重新定义资源。7-11做了几件事。首先，它在全365天营业，每天经营24小时，它是人是按人群密集度出发，能够最大程度接触客户，有位置优势；第三，它有十年的时间，综合各维度因素，集7-11觉得，它需要引入一个新产品，叫做“现金”，也就是把存款引入到店铺，进入ATM行业。这样就能新定义它已有的优势，所有的资源，找到了新的出路。

现在，日本的每七-11店里至少都有一台ATM，而且服务特别好，每台机器每年多出一台收益，一般的银行都过不去。后来7-11还把总部门户成了一家银行，并于2008年成功上市。7行门刚出来的时候，没有人相信这可能会盈利，但7-11门多管理思维的经营法在创业务上，现在已经没有任一银行可以与之相比。用这种服务告诉，打破同业的壁垒，7-11的收益能达到30%，而东京繁华地段的百货公司，盈利最多也只有4%。

第三种破局的思路，就是要重新定义自我，敢于把自己除掉。很多负资源固然是要去正的，但是有保留，你，只能用微小的力量从资源的缝隙里钻出去，去之后重新聚合，成为新的自我，这也是另一种破局思路，比如说我，在“得到”平台上开设课程，就属于这一种。退过去在学校教书就完全不一样了。那些旧在学校的资源，是我走出互联网时代数字化学习里没有任何新颖解决方案。

# ### 总结：

今天的课讲了件事：一是告诉你，所谓的“局”，就是人与身边的各种资源之间的相互关系。第二，破局之道，就是对于这些资源进行重新定义、重新整合。
