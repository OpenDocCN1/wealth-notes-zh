# 1、“局”的概念

前一周，我和你分享了“局”的概念。你还记得我当时关于“局”的定义吗？“局”就是你身边各种资源之间相互关联和相互作用的有关系。有时候，你只看想象，就与人际有了认知，你就会发现它处于一种资源关系之中。你也会发现资源关系中有关联，要服务于转化资源关系。比如，人是资源，你要领导一个团队，就要善于用人，帮帮大家朝着同一个目标前进。那么，如何会作为资源的人？从一个模块开始，我会讲领导力、团队和管理的一些基本方法，都带。一

002讲：资源关系｜到底什么是“局”

不过，对于一个领导者来说，用人也好、做事也好，要先有格局。格局有多大，就能认识到多的大天地，就能能够多大的局。所以，第五周，我很明确地先讨论了“格局”的概念。原来的课表设计，这个内容更靠后，但这个话题班上同学分享，和前面的破局形成一个呼应。这样前几周的课就形成了一个 2.0版的导读。

021讲：格局修炼｜当骨干前来辞职

“局”是资源关系，“格”就是认识能力。格局的本质，在我看就是能够把资源关系的认识清楚，把事情看通。比如，人际之间是交易，它交集是什么？你要什么？对方要什么？交集在哪里？把这些关系看清楚了，自然就可以顺着事情本身的关键，这就是我们所谓的“格局”，“做人要想顺应天理”。为什么？就是因为顺应天理的人，有“格局”，让人信服。

所以，这里我再强调一下，“格局”这个词，首先是一个动态概念，“格”是动词，“局”是一个名词，是宾语。它是强调认识资源的本质和相互之间的关系。可以讲，建功立业，首先就是认识资源，识局。当你有了真正的洞察，并且能够提炼出一个“格局”，“格局”这个道理就变成了一种状态，它表现为管理者的一种内在的状态，也就是我们所说的，这个人格局小，那个人格局大。所以我们努力要做到格局大。

# 3、如何成为有格局的领导者

当领导者有了格局，就会懂得注意观察、判断趋势。理性就是发展性作用，还记得到过线性管理？不会过理性是在人的基本上发挥作用，所以，我们需要充分了解人。人，是一个有机体，人不是机器，当信息不足的时候，当体内因素得不到判断的时候，就会出现重大失误，就会出现问题。理性化和感性化，管理者基本会出现。所以，管理自我和管理他人，一定要注意这一点，人不机器，人是生物，对自己，要注意控制精力，要通过休息调整状态。对他人也是一样，因为大家都不是机器。
