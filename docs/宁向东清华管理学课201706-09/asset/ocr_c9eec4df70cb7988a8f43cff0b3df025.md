# 直播精华｜人人都该掌握的管理学思维

+   1.感性思维——工具思维

有一次，我一个学生打电脑来，说我老板给了白板，希望让他吃饭呢？因为白板到工位， 问一下情况，小小白板，白板一边是问题，一边是解决办法。

![](bbox=[0.1, 0.14, 0.9, 0.28])

右边的办法列了很多条，密密麻麻比问题多，很是麻烦，这就出现了一种情况， 还是大家都不知道该如何解决。

顺便说一句，如果一个公司的讨论会没有白板，一定不是一个好单位，如果没有水笔， 就意味 着他们的讨论很玄。

我的学生坐在那里写写画画，最后弄出了这样一张图，我给你看一下。

![](bbox=[0.1, 0.43, 0.9, 0.55])

他的图和刚才的图不同，第一，有 幅点， 他找到了关键字，关键字 从问题中提炼出来，在关键字之间形成因果链条。比如 问，成本高，招待费更高，这是个坏 环， 的问题。出了这个图，你头脑中的 就清晰多了。

他把图二的并列关系进一步提炼，就出了 图三，就是底下的关键字，这个是导致问 题的原因，只要你把这张图理清，不知道就 可 下，5分钟了，而且有轻重缓急，我们 是可以排序的。其实最后，想都不用 想，只要逻辑对了，最后结果一定是对的。

![](bbox=[0.1, 0.73, 0.9, 0.88])

这就是工具思维。管理中有大把的工 具， 管理学学子的智慧很大程度上是使用 工具。

在我博士中，我最喜欢的管理学家人之一是卡普兰教授。1994 年，我参加了CEO，到 了卡普兰的一个研讨 会，他介绍了《平衡计分卡》。
