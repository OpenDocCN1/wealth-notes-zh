# **1、状态自尊**

今天，我先给你讲一个重要的概念，叫做“状态自尊”。没有人对“自尊”这个词感觉陌生的，但如果你请你们自己用语言来描述什么是自尊，你可能也不一定说得到。其实，在定义“自尊”这个词的时候，学者们之间也是充满了分歧。有学者把自尊理解为一种情绪状态，也就是说有自尊的结果，或者坏的结果是激出来的一种感受。到了90年代，学者们开始对这种自尊明确定义为“状态自尊”。比如，你被表扬了，被表扬了，这个结果就会激发出一种喜悦的心情情绪，这就可以叫“状态自尊”。我认为，知道这种“状态自尊”对于管理者来说是非常重要的，因为管理他人，最重要的应是是基于每个人“状态自尊”的基础上建立管理体系。

我在清华经济管理学院的同学和晓明和王蕾两位教授刚刚完成了一个特别有意义的研究，他们的研究成果发表在世界顶级的学术刊物上，因为他们发现了情绪和业绩之间更加细微化的关系。

我们这两位同事研究的就是我们中国人，他们选的就是北京的中小型非企业，整个研究目标是持续了三年半，非常不容易。他们跟踪调查的对象是这家公司71位在职的全职员工，跟踪调查的时间持续了三年，那么他们发现什么呢？

他们首先发现的是，每位员工是带着不同的情绪状态进入工作场景的，而且这一天里他们的情绪状态都是很大的影响。这种波动对于他们的行为又有非常大的影响。比如一位员工上班的时候遭遇堵车，他就会以较高的积极情绪和较高的热情情绪开始一天的工作。但是如果某天他的工作时间里面，他的导师对他前一时间的工作给予肯定和激励的时候，他的积极情绪就会上升，消极情绪就会下降。也就是说，他的“状态自尊”会有变化，而这种变化会导致他出现不同的行为。

但这还不是这个研究最有启发意义的，这个研究最有价值的发现就是当员工的积极情绪增加，同时他们的消极情绪也会增加的时候，你就会更多地关注自己，以一种专注和警觉的心态对待他们的工作任务。但如果消极情绪增加的时候，他们的状态是下属的，员工就会冲破他的自己的工作角色，更多地关注工作环境和他们的工作同事，表现出更有力为的是更改他们的同事。做出更加积极的行为和更加的工作行为。这就是我为什么说管理者需要了解他人的情绪，在了解“状态自尊”的前进去进行有效的管理。

为什么“状态自尊”可以让员工在做额外的工作，付出额外的努力去关注整个组织呢？我们应该会记得冯特马赫洛茨的“层次需要理论”，该理论是人类关系学系的重要思想基础。马斯认为，人的需求分成五个层次，从生理需求到安全需求到社交往的交需求，再到受到尊重、尊重需求以及自我实现的需求。马斯还说，人的需求是一级一级抬升，只有满足了低级的需求之后，才会去追求更高级的需求。那么，在今天这个时代，满足较低层次的需求，已经不再是个问题了。

所以，职场上的绝大多数人所追求的，主要是受到尊重的需求自我实现的需求。这告诉我们，其实和“状态自尊”的感觉有关。还记得上周我谈的是说大学生有马斯的理理论吗？既然情感是第一生产力，那么，“状态自尊”的增强，对于员工的工作业绩和工作行为一定会积极影响的。

# **2、员工在先，管理在后**

那么，怎样才能够给员工更多的“状态自尊”呢？不是靠仪表达，不懂批评？我告诉，不是，因为在一定程度上是错的，否则就不会出现虚假的秒杀和科学管理运动了。

现在与100年前不同的是，人不再是简单的体力劳动者，人的自主性在不完全产出中贡献的比重就加大了。所以如果100年前我们就要从生产性出发去管理的话，今天我们要从人性出发去想想的平衡点。

为了更好地理解这个问题，我再度你分享一个研究结果，这是新刚刚发表在国际顶极期刊上的论文。这篇论文的作者发现，优秀的管理的一个重要法宝就是：在充分尊重员工感受的情况下建立管理制度，通过一些管理工具，让员工自身努力和上级的一些管理工具之间形成平衡。下面介绍作者所强调的重要的三点：

+   1. 要让员工主动分享领域的特权，在这个基础上，领导者再去控制成；
2. 要给予员工发挥主动性的空间，在这个基础上，领导者再去控制达成目标的节奏；
3. 要在员工具有足够操作性的前提下，在管理者再去建立标准程序。
