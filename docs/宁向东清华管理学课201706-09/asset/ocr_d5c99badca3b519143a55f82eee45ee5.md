# 050讲：工作特性｜把员工看作资产

你好，欢迎回到《宁向东的清华管理学课》。

马上过去的这一周，我们主要讲的是如何形成团队，我们是最后一讲，人员、结构和协同，今天，就是最后讲，人员讲一个最重要的观念，就是：要把员工当作资产。坦率地说，在很多企业里，员工团队和整个组织的关系并不是健康的，所以，团队建设更多地还是工具性质的，这样的团队，从长远看也没有生命力。

# 1.把员工当资产

“把员工当作资产”这句话，不是我的说，是现代中国集团董事长宁高宁说的。宁高宁的讲话中有一组关系，在公司的资产负债表上，与员工有关的事都在负债栏：应付工资，应付奖金，公积金，在公司利润表中，与员工有关的事都在费用栏里：工资、福利、所有分摊。这种看法在概念上把我们的公司的目标对立了起来。

我觉得我们的员工职位应该在财务报表上变一下，要把员工当作资产，而不是负债；要有利润，而不是费用。在企业管理的理论中，如果不在投资质量或经营成果上找到员工的位置，就是管理的失败。

坦率地说，没有格局和阅历的人，不容易理解这些理论的价值。我的学生就有人不理解，他就常诤事，问我：怎么能够在报表里做到上述转化？我回答他，在报表中心里，是一个比喻，在每一个投资者的心里完全转化，才是宁高的意思。

中国企业对待人的观念，在过去这30年里，发生了两次变化。第一次，是把管人部门的名称为，人事处，改称为人力资源部。在传统的企业里，人事处管人：办入职、办离职，办调动、办人事管理，没有别，从本质讲确实是员工的仓储保管机构。为了一个人力资源部门，至少是名称改了，这一下，人力资本可以进步。不过，名称改了，在领导心目中，员工的地位没有变，还是一个职位。如果领导在内心还没有把员工当作资产，没有人看成目的，而是仅仅作为工具，团队建设得再花里胡哨，也很难落到实处。

宁高宁把员工看作资产的说法，我觉得其实呼应了关于知识再一次的变革。其理解是，虽然要用社会交换的观念来看待大企业的人与员工之间的关系，员工会不会让企业和个人之间，是帮，帮助员工增加价值，创造资本的增值，是一种历史的潮流。

# 2.案例：宜家

下面，我想和你分享一个案例。不过，在尽可能简短地介绍这家公司的特色之前，我先批评一下这家公司在北京的某个店的服务质量，我在北京店里看不到任何商业的展示，不知道这是不是和这家企业的商业模式相关。

在今年暑假的第一个周日，我去北京的某个宜家买东西，外面是滚滚热浪，进店门，扑面而来，却是丝丝凉人。店里的购物环境不错了，几乎所有的沙发、椅子上都坐满了人，连床上都有人，但在商店里，家里满人的活动设计，正是在一条单行线，也就像迷宫，即便是顾客只要买一样东西，也要走完全部，这就加重了顾客的购物负担，也削减了人流滞留的程度。用网络语来说，既然我不算省钱，因为买觉得是逛了时间，所以我不转出门，放弃了购物的计划。

第二天下午，我再去找宜家。因为是工作日，人少了好多，宜家就了像大商店，但不是个候客室。购物条件稍微好一点，但这次，我知道了，宜家状态极差的店员。我向一位店员进作，向另外一位店员求救单一，最后还在收银台交外购物。我一共遭遇了三名店员，有两位态度很差，我怀疑大应该还是出店的自身素质问题，而不是员工管理上的问题。

宜家是一家我非常尊敬的公司，它的产品是非常简洁的，但隐藏在简洁背后的，是非常复杂的管理。就是可以制造极精确的抽拉活动件，这是商家在家用小资金，但后来改为分层摆放，每层20颗，100颗分为五层。作了这种改造，可以是30%的空间。对于快销品，仓储和物流是非常重要的环节，宜家精打细算，绝不会浪费空间去做储藏空气与运输空气。宜家的产品之所以这么多年价格基本保持不变，靠的就是这样的精打细算。宜家的理念，来自于它的创始人宜库斯·姆·英格瓦·坎普拉：我用1万块钱做一张桌子，谁会不去？我先就用在100块钱做一张桌子。

![](bbox=[0.15, 0.0011, 0.85, 0.0011799999999999998])

你下次去宜家，可以留意一下公司在不规则产品的摆放上花费的功夫，也可以留意一下所卖得盆花和玩具，是怎样摆放的。我告诉您，所有的，顾客就是要这样东西都是怎么展现顾客的，就是怎样让品，也是呈现的。这也意味着，商品在运输环节上是没有花多余人工成本的。它不像一般的超市，商品从出厂库房，再到店放在顾客面前，要经过很多次人工。宜家把这个钱全省下来了。即使在卖场，价格信息不可能通过货架指示牌说明表示，顾客信息，让顾客自服务，所以，它本质上是一个人工节约型的企业。

服务业，加上人工节约型企业模式，导致了宜家管理模式的特色。

这也是为什么我选择宜家案例的道理。近三年来，我曾经调查过几家服务型企业，发现员工流动率都特别高。员工工作条件差，又很难找到东西，有些员工干了几个月就离职了。这在一些企业就形成了一种恶性循环：员工越不愿意留下来，企业就不愿意给人资源上去提高工效，所以，就会大量地使用人工服务，服务品质没有变化，店面基本上都是人工，在一些快餐行业里，问题表现得更加突出。

如果我想得不错，在这个大环境下，宜家应该不是最坏的，但宜家管理的这种稳定性，应该让它的员工管理和团队建设变得更容易些。不是当其下的团队，宜家公司会导致购群，高度理增加。一个员工所面对的人群，比倍率是不多。在美国的宜家居，一个店员也许多个小时不会碰到一位帮助他的顾客，在北京，求助者可能会非常多，我注意观察了一下，即使在周一，不够友好的那两位员工也应该属于超负荷劳动状态。

泛泛而言，超负荷工作不仅指工作时间延长，还包着工资收入低，甚至遭遇顾客无礼貌，被毁骂的次数也会增加。人在这样的状态中，能够应付工作，已经很不容易，追求服务质量更加困难。如何打破这个僵局呢？

# 3.工作特性理论

接下来，我和你分享一个重要的管理概念。工作特性，工作特性，是指工作的特性，例如刚工作的，工作特性的多样性，在孤独环境下工作的不舒服感，工作强度，以及顾客发牢发的可能，都属于工作特性。而工作特性会影响员工的心理健康，进而影响工作绩效。包括员工对于工作的满意度、缺勤率和人员流失率等。

针对服务业，员工对顾客服务很复杂的企业，工作特性理论会我们的启发之处在于，我们可以顺着去想问题。

为什么员工流失率会高呢？是因为他们的心理状态不均衡，那么，如果改变他们的心理状态呢？我们要去从工作特性中去查问题，找原因。概念需要重新创造时代人的商业系统，在这种新文化系统时代，在多数服务型企业里，仅凭低报酬的工种，本身就难以满足员工感和成就感的工作，我觉得比较不太可能。所以，服务业要想从根本上建设员工的工作过程之外的意义感，使员工少得一部分负责的心理感受。
