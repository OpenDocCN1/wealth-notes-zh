# 1.团队建设的最高境界

关于团队建设的最高境界，有一种说法概括得挺好，叫做“心相通”。那么，怎样才能做到心相通呢？心相通，就是走入别人的内心。走入别人的内心，应该我们很难的，但还是有更多的方法，值得我们尝试一下。唯一防患思维：695020

我们打球的时候，作为一个团队，最重要的事情之一，要建立默契。默契的表现是什么？其中的一点就是能够有互补性。有时候，你看你的球技好，你知道他的技术差，你就一定会要赢吗？为什么呢？因为经过长时间的一同练习，你作为同伴，判断局面之后，事先要做的，是赶紧做好补位，首先防止他万一失手之后，被对方打个措手不及。这就是默契，在几乎所有体育竞技项目中，最需要的就是这种默契。

有默契，就是心相通。

在很多时候，一个人的行为，都是他内心想法、内心冲动，以及过去经验的体现。如果我们能够“进入”前述层面一点，就是能够理解一个人的内心行为，并预测他未来的想法，及时采取行动，保证团队的利益。

# 2.背景分享

下面，我和你分享一个经验，或许可以借鉴。这个团队建设经验，是我在无限极公司做咨询的时候，注意到的。无限极是中国保健业行业内的一家龙头企业的公司，管公司，至今没的一些团队经常用一种叫做“背景分享”的方法来促进团队建设。背景分享，说白了就是讲自己的故事，特别是高级经理、在团队里建设的过程中经常使用。每个人都要去讲自己过去的故事，就像我们在餐桌上会吃一样，只不过不同，他们做得比较正式。

![](bbox=[0.0, 0.0010500000000000002, 1.0, 0.00125])

为什么要做背景分享呢？目的就是要建立默契，力争做到“心相通”。无限极的高管对我说，当你看到一个下属刚发火的时候，我们要看的，是一个人的情绪和认知，他是怎么做的，你才知道他的行为逻辑。那么，你对这个人的了解就有了一个很清晰的基础，就发现他在想什么过程一定来自于他过去的经验，而这个思考又决定了他现在和未来的行为。

这和我们的团队的球员的道理是一样的。长时间共同训练、比赛，就是要让球员之间互相能够理解到别人的想法，然后，当一看到队友拿着球在运球，你知道他接下来可能想做什么，然后，就赶紧去补位。

所以，我们每个人的想法，其实都是由更后面的一层东西决定的，那层东西就是我们每个人的背景：比如我们是在怎样的家庭里长大的，我们的成长过程中有什么难忘的事情，最触动我们的价值观形成中受到过哪些关键的人生影响，当我们遇到困难的时候，我们是做什么的。等你对一个人的了解多了一层的，当某个伙伴在遇到某些问题的时，他会怎么做，以及为什么这么做，你猜起来容易理解。

# 3.心理契约

我们来介绍一位大师，这位大师的名字叫“卢格”，中英文都写《忏悔录》，的学者名字叫卢格，他1990年提出了概念“心理契约”理论，是卢格在管理学的研究领域。一个新论文，在论文提出之前，这个概念还提，但属于非常伟大的管理思想。

我用一个例子来简单介绍一下“心理契约”的概念。这个概念的意思是，当一个人加入到一个组织的时候，对于组织期待给他他的心理，是需要什么东西，有一个预期的。这一个心理上的，就是基于期望和心理上的契约，是每一个心理契约的，没有合同说出来的。但是，这是一个“心理契约”，卢格称之为“心理契约”。

![](bbox=[0.0, 0.002, 1.0, 0.00215])

心理契约和一般我们合同所签订的那个叫作“劳动合同”不一样，他要比“劳动合同”丰富得多，也要更加隐秘。现在的劳动合同里面，公司、大多数明确规定的内容，范围比较窄，而心理契约范围更大。很多内容都没有明确规定出来，却起着决定性的作用。

比如，我们在应聘的时候常常会有这样的体验。面试官会问你：你对未来的工作有什么设想？你为什么选择到我们这家公司？你准备在这家工作到什么岁数？等等。对很多人来说，他和其他公司打交道的，在面试的时候，才会谈论这些概念。甚至，可能是和对方唯一的，最亲近的谈话。心理契约，是很多时候，面谈谈完了，这些涉及到心理契约的东西就都过去了，因为我们人接受一个人，就再不敢再感觉这个人心理契约怎么规定的，而感觉工作也够能满足他的心理契约。

但实际上，一个心理契约不是一种投入，也不是完全定，主要是由心理契约来决定的。正因为他们这个契约，或者不满足心理契约，决定选择辞职。但是这个东西，对于大多数人来说，平常是比较在内心的。每个人都不方便，对那些他并不信任的人说出来的。

那么，我们为什么不想办法建立一个正式的，让心理契约讲出来呢？讲他的心理契约心理契约，或者共同，因为对了解一个人，在心理上对工作上的期望，他的付出感，因为工作更简单。于是，如何建立一个让人讲话的环境，是非常重要的。我一直觉得，心相通的前提是要让人能说出这些。

过去，国有企业有一个传统，叫做民主生活会，其实是一个非常非常好的管理做法和做法。但是，后来很多传统都变成了一言难尽。其实，好的领导学应该怎么做，让别人把话讲出来，又不伤到他的感情，他可以把话说出来，是最好管理的办法，是大家可以通过公开的讨论的方式来表达自己的看法，实在做不到这一点，可以让退而求其次，通过各的沟通方式，让大家话进来说。
