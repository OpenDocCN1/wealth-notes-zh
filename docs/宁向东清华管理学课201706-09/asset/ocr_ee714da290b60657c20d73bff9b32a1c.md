# 1.团队中的三种成员

我读书的时候特别羡慕着名大学的教授会。当时，特别有感触的一件事，就是为什么超一流的大学的教师队伍里，并非个个都是顶级高手。后来，我又喜欢研究NBA联盟。原来，我发现，一个团队，想要获胜，需要靠一个领袖型的教练，加上几个顶尖高手，再加上一群配合度极高的角色球员。

我更喜欢从企业来描述这个概念。团队就是企业的“一个器官”。

而领导者的思维，最重要的，就是要有自己的商业边界。换句话说，你的公司、你的团队能解决什么问题，不能解决什么问题，你要非常清楚。

![](bbox=[0.1, 0.32, 0.9, 0.36])

# 2.骨干的重要性

而领导者思维就是，第一重要的，就是要有自己的商业边界。换句话说，你要让你的团队去解决什么问题，不能解决什么问题，你要非常清楚。

领导者的能力决定了一个组织的高度。

而骨干的力量，决定了组织的厚度。

为什么骨干特别重要？因为组织在扩张的时候，需要的不仅仅是“兵”（辅助人员），更需要“将”（骨干）。

# 3. 辅助人员的思维局限

领导者搭建了骨干，第二重要，也最容易忽视的是辅助人员。

辅助人员的思维方式，通常是机械式的、线性的，而领导者和骨干的思维方式，往往是系统式的、有机的。

这就是为什么，一个组织在扩张的时候，会遇到瓶颈，因为你的辅助人员（兵）的思维方式，跟不上骨干（将）的思维方式，而你的骨干（将）的思维方式，又跟不上领导者（帅）的思维方式。

我和大家讲一个我自己的经历。

“线性思维”和“有机思维”，是我后来从领导艺术中总结出来的。

在一个团队中，领导者和骨干一般是应该受到信息差益的，而辅助人员也应该享受这种信息差益。

我觉得这是对的，一个组织在扩张的时候，最需要的，就是辅助人员能够把自己的思维方式升级。
