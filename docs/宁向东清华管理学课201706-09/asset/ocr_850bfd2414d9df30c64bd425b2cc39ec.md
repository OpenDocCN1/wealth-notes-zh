# 本周复盘

周一，我们用了一个“状态自管”的专业词汇。强调了一个理念，就是要在崩溃“追求个人情绪释放”的目标，去建立我们的管理架构，甚至我提出了“打工在先，管理在后”的指导原则。为什么打工在先呢？一是因为自身身的劳动都是知识劳动；二是因为现在年轻人更注自我实现。

在二的马斯洛层次需要论的基础上，周一我们介绍了动机、愿望、努力目标这样的逻辑链条。从动机展开思想。激发了他们的努力。管理是管理的。我们讨论了一些盲区。我觉得这是山下很主管道者有共性问题地方。如何发掘那些有能力和愿望的人积极工作，是个重要工作内容。

周三，我介绍了双因素模型，介绍了保健因素和激励因素两个概念。我们考了80后和90后的管理问题，并不是提能大外，对于不同的人，我们在了解动机、分析愿望时，应该有区别，有针对性。

周四，我介绍了“窄化效应”的概念，就是讲讲，即使你了解了每个人想要东西，但是，你给他长时间的工作压力，他的身体也不自然地无法对工作压力本身产生影响。所以，对于无效工作加剧本身，即使对于有动机、有愿望的人，都可能是受不了的。

这一周的线索实际上是特别清楚的。但是，在文稿和视频上，我没有及时的、必要的引导，所以，显得有点混乱。这是为了周五讲透的经验多那一课。管理本身就是这样，工作就是乱乱的，管理就是要善于在凌乱的顺序中，发掘清晰的线索和逻辑，案例的能力与境界永远会得到提高。我和你说，仿佛的案例里面，有时就放置理一些无用的干扰信息。

# 问题解析

+   1、有些同学反映课程有难度，听着有点“迷糊”，怎么办？

**宁向东**
前两天，我遇到一位同学，他和我说：他们只听了4个专栏，每天开车听他的课，听得稀里糊涂。他恨不得写自己的学历低、水平低。但我说得不对，我觉得关键的的是他不够重视。他心态上可能是轻视了。不是学科内容有难度，一定要我讲。而且，我的课他们因为管着工作的特殊性点就不成体系，所以你把这些不成熟的东西用到不成熟，所以，我觉得管理学课很乱。于是，我建议这位朋友其它三个专栏都去听明白了。集中一年时间把理性学习做下去。她说，这一年她真的值了，境界有自己想不到的提升。怕的是，我束手无策，或者投入不够。所以，就是决定一定要对得起课，反复听上几遍。这一年把我这门课、听完了。我送了他八个字，书读百遍，其义自见。

我读过30万/20字，有字外生，每天坐在大礼堂的公共课上，学生是一个半小时我一人。我一坐就是一天，管它历史课、经济学课，我都在那听。我坚信：耳濡目染终究是多学东西。一定要有效果。突然有一天，我可以感到清晰的时候，去哪里换成了，语言也成一片一片出来，要么是气孔，言不由地来。渐渐地，半辈子也搞清楚了，听力自然而然高了。这就是花工夫的过程。

+   2、很多同学对5心5心经中的“问”理解有误

**宁向东**
“问、想、仿、改、善”，是一些同学在留言中经常使用的“中间”，他们以为是“中间词”是“问别人经验”，还是“为你的想仿打主意”。

+   3、宁老师提到“案例教学”，然而“理论”有没有用呢？

**宁向东**
关于理论学习和案例学习的关系，这个问题比较复杂，我以后专门讲一次。简单地提，理论都在“点”上，而问都是“面”“成”“决”的。所以，单一的理论很难解决复杂的问题。

+   4、如何与他人分享案例？

**宁向东**
我把案例教学的体验介绍给你们。你们可以以后可以用这种方法去组织同学们学习。
现在我们学习小组先是集体复写一个案例，我们可以按照下面的模板，来进行微型案例的写作，供大家分析来用。

+   1. 背景：企业的基本情况，包括行业，产品，服务对象，所在城市。
2. 基本的竞争情况，经营的目标，管理架构和企业业绩，等等。
3. 你提到的管理问题：比如在学习小组里重复的小问题，而你那几个人都处在一个情况，而全公司是介意的。
还有一位同学提到跟整个的一个孕妇同事的工作效率低下的问题，都很难以让人理解其。
总之，信息越详细越好。大家可以有针对性地讨论。讨论的最后，两个都是喜欢，各自在那里停个停，但是不格界。

我们将有近一年的时间，可以慢慢来。第一周，我给了个1.0版本的导读，现在一个月快过去了，我们进入学习。给大家一个2.0版本的导读。现在，我们的学习小组建议了，有了这两版导读，学习小组也开始建立了一定的理思维道，我们不是急着活跃们的咨询公司，我们可以慢慢来。

# 一周留言精选

我觉得，“状态自管”这个观念并不等于放任自生。而是在充分尊重个性的前提下建立管理制度，是有制度可以制约员工行为的。再说，如果有员工通过增加纳入门管，以为充分认识成立或之前的沟通动作，是可以有效控制员工的惰性和肆意妄为，因为在一个充分协作的网络中，人人都互相影响和互相制约的。高素质的人材加入到分上的合作，是保证“状态自管”管理观念顺利进行的两个保障。

对于有愿望，没有能力的，首先要了解他的愿望是什么，然后针对他能力缺发的部分进行培养，多给机会，帮助他能提高，以能实现时，慢慢以以愿望“能力提高一能实现助多愿望一愿望进一步提高”一催生能力进一步提高”的良性循环。
