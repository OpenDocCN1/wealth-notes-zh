# — 本周复盘 —

这一周，我和你们分享了五种不同的领导模式。其实，我们这可以描述出更多的领导模式。之所以选择这五种类个例子，是希望帮你建立一个关于领导力逻辑的初步认知，希望你能对这个领域行为有更深的认识。

我们每个人见过不少的领导者，但你也许没有用今天这种一种管理方案的眼光去看领导者，去思考领导问题的。

关于这一周的内容，我就不再一一叙述了。大家应该比较熟悉“硬权力领导”的情况。今天我又分享了一位我尊戴的企业家对在他的下属说：我要是你，就从楼这个楼上下楼下去。结果，下屋也没有跳下去，反而说：是，董事长，我回去一定努力。

全体共治的领导方式，大家见到的应该还比较少，但我也作为一种领导模式给大家做了介绍，虽然里面很简单，未来是它的组织，虽然不会太出现普遍意义的全体共治，但是，分权组织会越来越。

# — 周末问答 —

# 1.宁老师你讲的五种领导模式有优劣区分吗？

**宁向东**

这一周的多数例子，都是成者就的故事，通过这个故事，我告诉你，没有唯一有效的领导你的领导方式，一种领导模式，都有其应用的局限性，领导模式，没有好与坏，只有适合，还是不适合。好的领导模式，就是适合你。

+   1. 领导者的内在特质；
2. 领导情境；
3. 下属的情况。

# 3.我目前还没有管理经验

我和没有管理经验的同事聊聊如何学习管理学。

我是20岁从清华大学电机系转到经济管理学院，开始学习管理学的。坦率地说，我特别能体会没有管理工作经验的同学学习管理学的不易，我本也是从对个时候开始的。因为我没有工作经验，对企业了解也不多，所以，现在看来，大学期间有很多东西都没有学，虽然最后也拿到了一个学位。
