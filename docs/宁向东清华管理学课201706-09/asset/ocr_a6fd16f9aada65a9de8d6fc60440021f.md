坦率地说，在很长一段时间里，我对女性领导力这个话题并不以为意。虽然华为有孙亚芳，英特尔有格思林，联合利华有谢瑞博，但我在觉得女性领导力这个话题是一个噱头，骨子里并没有什么真正有差异的东西。直到最近，我开始关注如下一些人，我的观念开始发生了变化。

# 1. 著名的女性领导者

这些人包括德国总理默克尔、脸书的COO桑德伯格、社交的CEO雷曼、百事可乐的CEO约贝、IBM的首事兼CEO罗茜·罗德辛集团的二号人物黄秋莲……这个名单还可以拉很长。

先说默克尔，这位世界历史上任期最长的一位女政府首长。第一次当选总理的时候，她只领先给对手一个百分点，执政到了第三个任期，她打破了“任期越长，连选越难”的魔咒，领先对方竟高达16%的选票，让对手毫无悬念。默克尔凭什么呢？

在你的心目中，你可能觉得默克尔就是一个铁娘子。但现实不是这样的，你知道默克尔的家乡在哪吗？美国总统一上任，就会立刻跑到白宫；英国首相搬进唐宁街10号，德国总理其实也有官邸，但默克尔却一直和先生住在此之前公寓。默克尔的警卫很稀少，一辆警车，两名警卫。公寓的门上写着她的先生的名字。那个公寓楼，与北上广的豪宅又名相似，逊色太多，就是典型的德国中产阶级住宅。

默克尔住得很随意，而且还自己逛超市、买东西，亲自下厨做饭。一个寻常的家庭主妇做的事，她一样都不少。同样她能做到那么好的保持她的平常心。她很少当众反驳，相反，格外注意倾听大家的意思，注意如何把事情做好，作出最正确的选择。默克尔做事部前就决，不栗不慢。

据说，这是因为一位歌剧演员曾经跟默克尔说，当到面临难题的时候，到时间会说你说出最好的建议。默克尔非常欣赏这个建议，她就常让周围的那些些提不起同问检验的想法，最后留下来的一定是无可替代的选择方案。所以，她一定的是从死回各种压力和难题，很多时候都不简单地去决策。

再另外一个女性领导者桑德伯格。扎克伯格在创立脸书之后，无法应对原的管理事务，这时在注意到了谷歌的全球副总裁桑德伯格。在经过短交谈之后，扎克伯格就认定了会挖到桑德伯格，他的桑德伯格去了长达两周，终于，据说在六个月之内吃了50顿饭，挖到了这个他心仪的COO。扎克伯格说，没有她，脸书就不是一个完整的故事。

桑德伯格进行脸书工作后，媒体普遍都不看好，她做事身段较为柔软，在脸书这个工程师文化，界面是的公司里，她不停地给大家拉关系，推她的广告文化。据说，她常常穿梭在几八百人的大办公室，坐下来和骨干员工交谈，推她的广告策略，一点都不像个COO，总之，经过一段时间的努力，脸书开始在文化和产品上转向，为了支持这个转向，扎克伯格甚至每隔一个月亲自去放一个月的假，给桑德伯格留下施展的空间。而桑德伯格也不负期望，成为帮助脸书盈利，扭亏为盈。

今天，我要向你介绍一位女性领导者，她是华人界郭台明。他也许没有听说过这个人，但是鸿海集团和郭台明，你一定知道，它是世界工业集团化的企业，在全球有120万人为鸿海最多了。黄秋莲，就是这个大企业集团帝国的二把手。要说她对郭台明有多重要，郭台明曾表示，所有的投资项目，如果黄秋莲不签字，你不敢送到我面。而在鸿海集团，有一个非常有趣的问题，就是郭台明管的部门，我不一定能拿到钱；但是，黄秋莲的项目，你一定可以拿到钱。为什么？因为在鸿海，黄秋莲大家叫做“钱妈妈”。

鸿海集团发展的四十几年的时间，郭台明身段非常大动，但不一来不变的就是黄秋莲。黄秋莲不仅不变，还大权在握。那她身段什么样？就是“圆滑柔软”，身段软，不争夺抢，平易近人。当然，你如果惹她了，她也会骂人，但骂人的人会有私人对手，不对事。所以，换别人也会心胸口服，年底聚餐也会主动给过去敬酒。当然，黄秋莲在聚餐的时候，也经常和大家一起喝酒，非常平易近人。

# 2. 女性的领导风格

1990年，两位美国学者研究了女性的领导风格，发现女性领导者的核心差异表现在她们更多地呈现出“民主型女性”的领导风格，而男性领导者则更多地呈现出“硬权力”和“权威”的领导风格。而2000年之后陆续的研究表明，女性领导者在领导行为上更多地具有“社群风格”和“交易风格”，具有更加明显的“母性关怀特征”。

具体来说，女性领导者更加包容，更加虚心，更容易换位思考，替他人考虑，也更加的主动个性关怀。这种基于女性特质的领导方式，更容易让领导对象受激励，感召力，因此也更易被影响。

那么，女性特质中有哪些内容很重要呢？美国曾有学者家顾问公司里发起了一个研究，我们概括了一下研究结果，复述如下，供你参考：

+   1. 男性领导者更倾向于从自己的角度去发起问题，例如，沟通工作时不仅会，而女性领导者比男性更务实家为，这样就能够有全面的信息，能够更好地将这些信息综合起来，所以对于女性整合力上，有看特质上的优势。
2. 女性的耐性更强，持久力也比较好，所以，面对多数人都做不起和做不成的事情，她们的信心比男性都更主动而更高，这往往会导致意料之外的结果。
3. 女性特别十人，更愿意看见，她们也更愿意和别人分享自己的意见，她们问问题常常在探讨过程中较为充分，这就会让她人们在决决时过程中，可以找到更多的声音，也可以更加全面地作出决。
4. 女性具有更强的牺牲精神，她们更倾向于为什他们为价值的事牺牲牺牲。这是能女性的生涯就有一个关于活夫的人生过程，其实就是一个无法活夫的过程。所以，女性更容易把那些沉重的负理，变成动力。

听到这里，也许你同学已知道自己该怎么强化领导力了。那么，对于女性，我们能够想到什么启发呢？答案是最直最见的。以上两点，是对于女性领导力的总结，讲的既是“why”，也是“how”。我相信，对你一定会有帮助。
