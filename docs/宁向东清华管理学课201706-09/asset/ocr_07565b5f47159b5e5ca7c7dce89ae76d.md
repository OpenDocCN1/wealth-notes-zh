# 1、理性的力量

前几天我教的一个经理班，我在上课之前请了一个研究基因的专业来做讲座，就这个专家很有意思你像是看基因都能知道自哪天开，把人讲得非常失望上站，在我看来，大可不说相信位信力量够强。今天就要和你说起来。后天，对于双向理性的力量是强大的，在人的行为管理上会有大作用，这也是我理解管理学智慧的背后原因。

理性的力量确实是特别强大的，你也不信，我先给你点证据，有一门学问叫表观遗传学，今年获的诺特且就是相关领域的的研究成果。最近10年，这个领域的研究成果是非常鼓舞人心的。这个领域的科学家，研究的是同卵双同胞，为什么不同？因双同胞呢？因为这种双胞胎的基因是完全相同，而且在母体怀孕期间的胚床环境也相同，但差自从你出后生你就发现他们特有差异，随着出生和生长期间不断差异，差异越来越大，在同时双向同胞的研究里，最好的“华生人”里人华生系双胞的研究是好的，你如果你以有兴趣的话可以找我们的文章，但是科研学究证和前面几天的讲内容不存在矛盾，我们对此应采取什么态度呢？

首先，我们一定要利用这些现代的科研成果，多了一些对行为背后的深层面，要了解其中的机制。同时我们也不要简单地将现在的机制、因和心理方面的研究来解释理性让一些成功，我重强调让研究有效地利用这些成果来管理环境，让有效地发挥出他们能力。总之，我们要深信理性的力量。
