# 周末问答丨诚惶诚恐，保持敬畏

我周末在上海出差，用手机录一段话，帮助大家把这周的知识点作一个梳理，可能音质没有录音棚那样好，请大家包涵。今天我录了两件事，第一，对课程进行复盘；第二，借用同学们的问题和大家讲几心里话。

# — 本周复盘 —

这一周，我们主要从自我了解和自我管理的角度，选取了五个知识点，和大家分享了一些管理学的知识。

第一天，我们讲了从自我测试的角度了解自己；第二天，我们讲要敢于发现自己的优点，敢于利用个人的优势机会。测试这两天，很多同学都认真地去找到了测试工具，对自己做了测试，发现了一些原来没有注意到的。自己的一些特质，算是照了一下镜子。还有同学 在第三天的课上，请朋友同事对自己的优缺点进行了调查。这些都是非常有必要的工作。

第三天的课，我们沙龙效应这件事，讲了“自以为是”其实是很普遍的现象，主要是讲我们在判断事情上，有时会不自觉地把陷入一种惯性。这是由于信息和视角的不同。人们都有意识或者无意识的。从管理的工作，不仅要注意看你自己，还需要具备客观的角度去看待事物，看待他人。乔布斯说，stay hungry, stay foolish。我把它翻成“诚惶诚恐，保持敬畏”，其实觉也是中国文化中的“贤人之德”。我觉得这应该是每个管理者基本素质。

第三天，我们建立了认识外界的正确姿势。第四天的课，开始强调管理者的情绪四点。为什么呢？因为情绪会影响到认知，影响决策，保持积极心态。对管理者是非常重要的。但是，产生消极心态，也是正常的。现在也有很多人认为自己消极的心理理论，而不去终结它。我们重要的是不要让我们自己积极，这样才能更好地带动身边的人。

最后一天的课，我们对论心力的使用问题，我看得到很多同学，都意识到这个论题的重要性，有人甚至写下了决心书，我只能感觉到。

# — 问题解析 —

# 1、很多人不喜欢自己的测试结果，做什么来改变自己？

宁向东

对于你的测试结果，既要认真，又不要太过分看重，尤其不要用一种算命的心态去看待测试结果。比如我们人类对复盘是错的，人是相当复杂的，人类对自己了解极少，单靠一个测试，哪里说得清一个人的命运。我们的目标，核心是要让大家把关注先放到自己身上，了解了自己，然后，再去关怀如何处理好跟不同类型的人的关系，在这个基础上再去考虑给别人、组建团队、处理业务，再去考虑所谓的“破局”。

从很多同学课后留言里，我看到大家比较大同的“定下宣言”，这个说法，我觉得目标达成了。

# 2、要像小学生一样规划好自己的时间吗？

宁向东

从留言中，我看到很多人像小学生一样强调要规划好自己的时间，不肯浪费一分钟。但是，女生真的不要关注自己的衣服吗？没有，学自己的，白买了吗？我们不能自己搞得很累。生命的旅程是一场马拉松，要享受这个过程中的每一点美好，要平衡工作与生活。比如，陪家人的时候，也有心片的问题。你一边拿手机，一边想着孩子，这是一个正确的方式？我们每天，每一天，每一周是不太排了多点时间，和熟悉的老长者说说话，这些都是值得我们思考的。

# — 一周留言精选 —

我是专门做MBTI性格分析的心理咨询师，问卷测试的错误率高，是因为很多人在回答问卷的时候，答案是“渴望成为的理想自我”，有一个做企业咨询的朋友，内向，思维缜密，做事讲套律，很典型的INTP，几次问卷调查结果测出ENFJ，后 来 问 候 调 查 比 较 贴 近 自 己 的性格，而不是模仿者看起来想要“像的创业者”的性格。MBTI这些测试要降低低错误率，就像MBTI这诊断、受罗施纳这类量表手段，跟测验者客观给到结果的表现，我以为不是评估者测试，最大的价值在于：了解到世界上人与是不一样的，不能用同一套方法管理所有人。

团队运营中，适当地运用“人本特质”可以事半功倍。内向的人需要更多的授权和赋能，为粘性的人是优秀的执行者，列出具体关键点或目标，他们应该获得其成就感。如何减少短板是团队建设的的关键，毕竟团队需要差异化。

爱因斯坦说，自己掌握的知识是圆的内部，圆的外面是未知世界。当圆越大，才明白自己不知道东西越多。

确实不应该把心理和身体分开看，以后心理肯定会被重视，其实根本没有由心理状态，没有心理，一切都是人体内自然的物理活动产生的变化，通过身体各个部分表现出来。认为大脑就是一套物质，经过数据的不死机就能起到一种，表现不同行为。每个人的行为物理运动后，环境也不同。因此，人天生为心理。环境也可以改变行为。因此，让自己长期在某种环境中，通过环境的积累效应或在某个大脑内部活动，而改变行为是可行的。按照这个思路，抑郁症也不是心理疾病，而是身体疾病，严重的抑郁症者通过改变所在环境就应该可以没有治疗。

人生活有一个境界叫“无为”，故之四海而皆准。无为的另一个前提就是无意识的专注，专注的结果就会走向无为。信息的碎片化是专注的最大杀手，大多数人认为想要改变之一定是意志力的，学我也可以想降痛苦。今天的课程给我的启发：先放了一口气吃干净的杂念，当下最大的“课程”，也去想想的，我们绝大多数人之所以没有成为自己想变为的人，原因简单，再想想简单，系统的学习过于专注的表现如一数，还记得第一课的最后四个字：贵在坚持。坚持就是连性和动态的变化。
