# 你想要的 生活，就缺“管理学”

坐飞机的时候，你肯定有过这种体验：飞机抖落着在跑道上停得走走，迟迟不能停下来，这个过程里虽然有10分钟，却让人很不快乐。

飞机为啥磨磨叽叽？是啊，接机廊桥的准备需要时间。

但你有没有想过，如果有聪明的管理者能调整一下起落安排，让飞机稍稍飞慢一点，把10分钟的等待移到天上，就会乘客完全不同的旅行体验。

这就是管理学的智慧。

![](bbox=[0.15, 0.245, 0.85, 0.34])

如果你认为，管理学的智慧只能用在公司的经理里，那就错了。

我想给你讲三个人的故事：

**第一位**

他热爱体育，却最讨厌“公平竞赛”，他总是要制造一些条件，让自己处于有利的位置。

他身体条件并不出色，打网球的时候，总给自己设计了汤盘形状的网拍，球还没打，他就先胜七分。

他曾经获得过全美球桌舞的双打冠军，拿过1990年奥运会高尔夫球赛的第四名。当时的比赛规则常常因为他的“发明”而被迫改变，因为不调整规则，比赛就成一边倒的游戏。

这个人叫泰罗，他不是运动员。1911年，他《科学管理原理》出版，他也被称为“管理学之父”。

**第二位**

德鲁克，公认是管理学“领中的领袖”，美国国会图书馆馆员他是这个世界上最博学的人。

他每隔两年就会有写一个研究主题，从宗教到社会，从美国到中国，无所不包。他把管理学的智慧、应用到一切问题的解决之中。

德鲁克有本书，叫《卓有成效的管理者》，是当代最伟大的管理学著作之一。在这本书里，德鲁克提出了每个人可以追问自己的三个问题：

+   1) 不做这件事，又会怎样？
2) 这件事，别人做，会不会更好？
3) 有些想事情，就是交给别人做，也毫无意义？

你有没有想过，解答了这三个问题，你的生活大不一样？

**第三位**

哈佛商学院现在最贵的教授是克里斯滕森，“他最擅长的不是，最教人感到“颠覆式创新”来实现弯道超车，降到不包。

但在克里斯滕森的管理课中，他总是请学生思考这样的问题：

如何乐在工作？
如何与家人朋友关系幸福？
如何坚持原则，保持正直？

这才是管理学智慧的最高目标：让你的生命更有意义。

![](bbox=[0.15, 0.745, 0.85, 0.82])

最近50年，人类所创造的财富远远超越从前任何时代，超过所有财富所得。

管理学的智慧也早已超越商业世界的边界，走进了每个人的生活。

管理学，绝不只是管理公司的学问，它是帮你管理周围所有资源的学问。

大作家柳青在《创业史》中说了一句经典的话：人生的重要处，其实只有几步。走好几步，你就缺管理学。
