你好，欢迎回到《宁向东的管理清华课》。

昨天，我们讲了一个团队中信任的价值。信任可以说维系到很稳定的关系基石。不过，就算是最稳定的团队成员在一起工作，总会出现的争吵和冲突。

明天管理的话题，就讲到冲突和识别中非常关键的课题。该讲到什么？中国人是一个讲究中庸之道的民族，我们不太善于冲突的处理。

# 1. 冲突识别的坐标工具

关于团队冲突的定义其实很简单，就是团队成员之间产生了行为对抗行为，行为对抗的目的就是妨碍对方实现他的目标。由于沟通障碍和相互误解，团队中的冲突非常正常。现代管理理论甚至认为，有适度团队冲突的组织，可能是更有成效的组织，可以更多地激发创新等行为。当然，如果团队冲突过多、不健康，甚至失控，则会灾难性的。

那么，该如何进行团队的冲突管理呢？我觉得，第一步的，也是最重要的一步，是对冲突的情势进行研判，识别出冲突的性质。我举一个二维坐标来表示区分不同的个体，大家产生共享坐标。坐标的两个维度，是分析产生冲突的根源，是因为人际层面的关系，还是是因为具体事情上的不同看法和做法。坐标的另外一个维度，是这个冲突和前面上已经发生过的，并呈现出高度对抗的情势下了，还是处于冷战状态。

做这种区分的目的是，因为不同类型的团队冲突，实际上问题都会让发团队成员之间的相互对抗，对抗的性质的程度不同，解决问题的办法会有些，后续也会有。下面，我为大家分析三种典型的类型：基于人际的、冷战形态的冲突。

# 2. 案例一—人际冷战式冲突

我曾经遇到过这样一件事情，因为过去了多年，不妨今天借这个机会，有一个朋友空降任一家小型上市公司总经理之后，上任没有多久给我打电话，讲他的苦恼。这个公司的最大问题就是班子成员不服，又是国有控股公司，所以多集团领导批准处理。于是，我就给他做了一年的顾问，就是我来讲述的故事背景。

我先自我表扬一下，我当初思考，为是要做高层顾问的问题，如果这个项目意义不大，所有人都会防备我，我不仅看不到真相，也会形成行为公心。你看，总经理虽然是很典型的，但他真是贵人，不知其他的进入影响到了多少人的升迁之路，所以，如果来以他的顾问身份进入组织，大家都是如数来着。所以，我最最后是一个月给一个部门讲一堂课，帮助这个组织解决和问题的名义和进入，我的学生，领导们都不反对，加上我那时候年轻，姿态也容易放低，目标就太小。

这个公司的两个实权副总裁，每人分管一个重要的业务领域，但彼此在业务中互不配合。总经理虽然不知道难色，但工作做出不了，天天开协调会，就在企业协调会开始了，又开了一个协调。我是进入一个有点规模的企业，没和30个人吃饭过，绝不轻易说出意见。道理很简单，因为不能看出情况。所以，我就吃了一个月的饭。逐地，我就探听出了很多细节，这两个副总裁的矛盾可以说在他们刚到企业里面时，时间可以追述到早。正因为这些历史关系的因素，彼此不和，并且矛盾非事务层面，这意味着团队中的冲突，属于人际层面的问题。

这里，我强调一点，我们常常讲要对事不对人。我的看法可能对，仅供参考。

在很多时候，事务的后边都是人，都是复杂利益体系。所以，泛滥地反对事不对人，在实践中没有意义。所以，我建议你一定要记得，当团队出现了冲突，首先要判断的，是冲突是属于人际层面，还是做事的，方式不同产生的矛盾。如果是做事，好办的，可以事不对人，不怕，但如果是人际上的矛盾，处理起来更费心。简单地说对事不对人，除非大家都对你绝对信任，否则不容易出现好的结果。

我在这个公司考察的时候，格外留意两位副总裁的发言和态度。他们也留有两个明显的学习小组。他们分开合办公时不太会去争吵，甚至在同一个办公室的时候互相回避。那个的时候还没有室内成城，他们都抽烟，开会的时候还抽完互相发烟。所以，他们的斗争，属于完全隐蔽的状态。特别是当总经理来了之后，这个冷战更加有威胁，因为总经理客观上成为了他们共同的对手。

这就涉及到上面坐标的其中一个维度。前几天，有同学在学习小组提出来了一个很讨厌的打情式的问题。比如说，吵架，处理虽然属于很激烈的情敌，但相比之下，处理起来相对比较简单，不用什么办法，都能容易处理。上面，两位副总裁的，能力都不错，既是既不打，也不配合。这种情况，是最难办。

根据我对矛盾的情势的研判，我建议总经理采取一种“冷”的的方法来解决问题。这个折中的办法，属于不反对也不方法，因为按照总经理的意志。总经理本来没有权力决定副总经理的去留。我在前面看任务，曾经过总经理的领导人一定要拥有任免团队人员的权力，否则就很难建设好一个团队。我的观念，就形成当时为这家企业服务的经验。

我所做的第一步工作，就是配合当时上级批准的全管理论学的环境，在规定的学习之内，将清华先念管理学专业一系列经典文本。我就还记在毛主蛋在1945年的《时局问题及其他》，因为这篇文件里面讲毛主蛋主情，讲得结同志，都能结合历史的具体情况分析的，特别有对抗性。这里我再顺便说一下，在我们书房重要位置的柜台上，一直放着一套五卷本的《毛泽东选集》和八卷本的《毛泽东文集》。

我们一提管理学者，就经常会想到德鲁克、费、和麦肯锡，这一点没有什什的，但是，从我们的经验上，像毛主席的著作中，有很多的经典，特别有价值，而且结合中国历史者，特别适合中国。

总之，总经理有意识地在导入团队建立全局势观，总经理希望能够团队有大局意识，希望全体能够有大局意识。但，后来经过一段时间，发现是因为人际关系而产生的团队冲手，最后的解决办法，可能还是要有解决斗争的手段的。前面所做的部工作，顶多算是个铺垫。前面给你的介绍的那个坐标图，就是形成在这个基础上。

所以几个月之后，一位副总经理被调去脱产学习，时间是一年。然后，在这个背景下，整个组织架构得到结构调整，原来是按照职能线进行组管理，后来是把管理线换成线，进行基于事业部的管理。接着提拔了几位新到经理，直接公司对总经理负责，都通过这样的方式化解了团队冲突。这就为后来的企业发展奠定了基础上。可以讲，我们遇到团队冲突，要原，到底究竟是哪一个类到，找到真正的原因，才能对症下药。所以我前面讲，第一步，也是最重要的，一步，是研判团队冲突的类型。这是一个极佳的案例，冲突来自于人际，而且是冷战。

# 3. 管理冲突情境

不过，很多团队冲突的情况，并不像我们刚才讲的这个案例那样极端。对于不像我并非严重人际关系问题而引起的团队冲突，我个人还是建议通过“双赢设计”来追求有效的团队协作。
