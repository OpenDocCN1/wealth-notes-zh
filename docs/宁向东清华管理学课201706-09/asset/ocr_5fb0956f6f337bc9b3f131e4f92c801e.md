欢迎，欢迎回到《宁向东的清华管理精读课》。

昨天，我们讨论了一个人说了算，但一个人说了算有两个致命的问题：第一是信息不够充分；第二是判断可能会出错。所以，领导者做出正确的决策，其实还是需要有效的谋划。今天，我们就来讨论一下领导者的谋划力问题。一句话，真正的舞台其实是在领导的后面。

# 1. 真正的舞台在后面

领导者决策的谋划问题，自古就存在。政治上负责谋划的人，被称为“幕僚”或“谋士”；军事上负责谋划的人，叫“军师”；参谋中“参谋”；而在商业领域，这些人被称为“顾问”。反正不管叫什么名字，他们的功能都是差不多，是帮助我们领导者作出正确的决策。很多时候，我们在往只看，到一线指挥的领导者，觉得他一言九鼎，看到他就这么干练，可是，你可能不知道的是，在许多优秀的领导者背后，都有着一直强大的顾问班子，帮助领导者通盘着法。所以，在这个意义上，我们要强调一下刚才的观点：真正的舞台在后面。

不过，必须要先说明的是，当组织比较小的时候，或者当你的领导权限只受到很多制约的时候，单独建立一个专门的顾问团队，方方面面都不现实。所以，在这个阶段，顾问往往是是由若干的伙伴或者团队成员，当时的领导者还会通常会招一些外脑来帮助自己出谋划策，也就是“外脑”。

不过，领导者一定要知道，谁是可以商量事的，谁是可以商量重大事项的，千万不要找错人。

> **宁向东**

最近，国内很流行的“私董会”，就是企业或个人，加上几个或者十几个左右来坐在一起共同讨论一些大家关心小团体。我想，这个私董会，归根结底，也还是我们刚才所说的组织之外的外脑。只不过在组织内部，他叫外脑，而在组织外部，他叫“私董会”。

# 2. 如何选择顾问人才

根据我自己的经验，一个好的顾问人才，起码应该具备如下四个基本条件：

+   1. 头脑要对聪明的，要有发现那些隐患问题的能力，要有大局观；
2. 口述绝对严严，很多时候讲到的就说到到不了，这个人应该非常尊重功过序，有隐有精神；
3. 要注意，很多企业聘请了一些外部顾问，最大的问题就是企业的情况不熟悉，办法很俗套，但是因为情况不熟悉，建议不到位；
4. 就是有情感上的认同，敢于坚持自己的看法，哪怕有相反的意见。

坦率地说，找一个好的顾问人才，非常不容易。在骨子里面要发现这样人才，就更难了。用骨干做顾问，要格外小心。一要防止他搞小圈子；二要防止背锅。如果放到合适的顾问顾问，领导者应该求取不取，不一定非在有问题的时候才想到找顾问，所以要加强对顾问和企业的关系，这给顾问创造了解决企业问题的环境，这需要一些成本。可是，与企业的相关相比，这些成本事后再看，真不是什么大钱。

现在有一个现象，不知道诸位有没有注意：很多企业往往在出现问题之后才去想请顾问。其实，一个领导者最有远见才会把企业做大，应该在企业没有发现问题的时候，就聘请顾问长期跟跑。所谓养兵千日，用在在一时。

# 3. 案例：三星强大的幕僚团队

下面，我可以分享一个关于企业的例子，你也许可以看到顾问这个角色的价值。最近几年，三星在重大决策上，似乎总是在关键时刻能够找到正确的方向，以及李健熙会长经常被称为“救星”。三星的领路人不能光1987年李健熙接班之后所创造的业绩，也不能掩盖他本人的辉煌。

> **宁向东**

最近，关于李健熙的新闻不少。今天我们讲管理学，就事论事。

在前面我讲了30年的自己，李健熙所犯的错误很少，除了他在自己利用力量之外，很大程度上是因为他幕僚团队，非常大。我们经常说李健熙，也许是因为他个人导致，李健熙说言寡行，很少有面向大众露面，甚至很少到公司上班。但是，他每天在家里办公，也就是既管大事，又管小事。

在所有的大事里面，他绝不关注投资入的、重大投资决策，甚至是技术决定方面。他很多时候都是亲自拿主意。按照韩国一个研究三星多年的教授张世健的记述：三星电子在考虑是否要投资整个行业，把埋在半导体里的6英寸晶片生产线换成8英寸的，后者虽然成本不可行，但是并不能够。人只能看到技术上行，而进行这个尝试，如果失败了，将会造成以万亿计的韩元的损失。应该意味着，一个决策可以成败成败成了。它的意义是三星可以超越日本竞争对手，成为市场中的领先者。

这个决策是没有任何经理人可以拍板的，因为谁都没有能力承担后果，所以，最后拍板的只能是李健熙，而李健熙的用处就体现在拍照时间来研究思考，最后作出了现代的拍板决策中，三星果然超越了对手。

接着我们再说在拍板的过程中，他的幕僚团队所做的工。在拍板之前，三星要和顶级专家进行交流，或是顶级专家；幕僚团队要去寻找，去筛选。然后，他又要进行事后的交流与提出意见方案。最后，经李健熙反复讨论、思考之后作决策。

我见过好几家大型企业的幕僚组织，但是，三星的幕僚团队，给我印象最深刻的。三星的幕僚队伍，可以追溯到日本人的大参谋本部，这家参谋本部主要是著名之一。战后，这家企业进入商界，为了伊藤忠商事会长，也就是原引进到企业中，主要负责收集情报和参与决策。

三星的幕僚团队就是受到汤岛龙三的启动，在三星的创社者李秉哲时代，成立了秘书室，不过这个时候秘书只有二十几个人。1987年，李健熙接手三星，对秘书室进行了大改组，称之为“大长秘书室”，除了保持传统信息分析情报功能之外，还加入了很多经营管理的其他职能。1997年亚洲金融危机之后，秘书室改称为“结构性转本部”，之后又改为“战略企划室”，一步步走向前台。

三星的秘书处，韩国最优秀的年轻人入选的工作岗位，极为高。从1987年开始，李健熙步入三星时，大长秘书室开始运作，秘书处功能一步一步地推向前台。原来的秘书处只是参谋，大约只有10%的权力，主要的事情还是集中在高层的手中。
