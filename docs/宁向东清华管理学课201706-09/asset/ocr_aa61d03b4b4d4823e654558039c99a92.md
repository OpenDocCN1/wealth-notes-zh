# 037讲：领导模式实现｜三步走

你好，欢迎来到《宁向东的清华管理学课》。

昨天“权威领导”那一课，有两个核心要点：第一，就是通过对有效领导方式设计，能够最多的下属有效地工作。今天，我接着这个话题，和你分享领导模式实现的三步走策略。

+   1.  把领导力转化为追随力；
2.  用价值观吸引最多的下属；
3.  留出情感和空间，用个性领导的方式，抓住重点人物。

# 1.第一步：领导力=追随力+业绩

先讲第一步，把领导力转化为追随力。有个什么公式，叫做：领导力=追随力+业绩。什么是最有权威的领导者？个人领导力很强，看的是他能把多少人转化为追随者。我如果把昨天的课下，看了很多时间，去讲如何分析和了解下属，其实就是为了通过有效的领导力设计，吸引最多的人跟着你“走”。核心最早是“领导力”转变“追随力”，是最由大家共同创造的价值。也就是说：领导者的一个重要功夫，是要为、把自己的领导力，转换成下属的追随力、创造力，然后下转换成为业绩。

“追随力”，是个新概念，哈佛有一位教授有解释两个概念时说：“追随者决定着企业成败。”这句话，你不能不同意了。讲个故事给你听，90年代初期，清华的老校长高恩校长在世前几年，他在哈佛中国发展中心校长会致辞。他在席上接着记者说的一句话：“工作是如何来的呢？”当时听这句话，并未有什么特别的感受，随着阅历增长，越来越觉得这句话了不起，这句话里面就包含了一个追随力的问题。

上一周，我们一起向早年的乔布斯致敬，并且讨论了战略型领导模式。从一些同学的留言中，我非常他们的觉得乔布斯很伟大，但离自己很远。其实，很多伟大的战略型领导者，就在我们身边，只是我们没有意识到。学了今天的课，我希望能够帮助你建立这样的意识：今天观察身家身边的领导者，判断出哪些是值得你追随的领导者。因为他们的战略高度和影响力下属的能力是非常强的，你按照他们的理念去做，一定有前途。

高恩德校长就是这样一个人，他是进入清华大学之后的第一位校长，他远不及清华那样著名，但在各位心目中，他却更像清华历任校长中的佼佼者。我下面和你讲讲高校长“征地”这一件事。

记得我刚进清华时，学校周边都是成片的农田。八十年代初期，农村自留地不能划给大学，但每个农村户籍的学生，都希望能换城市户籍，享受只有城里人有的社会保障和社会福利。要知道高恩德校长从哪里来的远见卓识，决定用学校后勤里的种学生产，把那些农民从土地中置换出来，成为了“农转非”（农村非农业户口）的学校职工。我那时还不知道，食堂里的很多师傅，都是从农田里走出来，到清华上班的学生。那时，学校的工作价值观，土地不值钱，所以，高校长的这一决定，并不被所里的领导和干部认同。

为此，高校长亲自制订了“征地”的工作方针，但大量的农工员，都要靠自己去推动，靠学校内部的各级管理者一点去落实。我们听过一些中领后的别的，讲高校校长和职工集体开会，领导不同区域的故事。高校长学问大，是苏联的正博士。你可能不知道博士，苏联的教官方，在那个时代比博士毕业更加难。在那段国内向往上，苏联留学回来的副博士，就相当于欧美国家正式的正博士。

而高校长有学问，有德，同时又是正气和团结主要干部，所以，这种领导方式就创造了追随力。高长讲话时，力气大，大家都听着。然后，领导与追随力一起发挥作用。我读大事，后来读领导心成了。后来工作后，才深刻理解了高校长那句“工作都是同志做的”，这真不是一句简单平常的废话。

顺便多说一点，高校长的这一发现，为清华大学交一宿舍腾了二十年的发展地。今天回头看，如果没有高校长当年的前瞻性，中国不会会有清华大学的国际生。我们只能在中国的土上发展，那就不可有今天光鲜和硕的清华园了。所以，真正有战略的领导者，不仅只有乔布斯，我们就身边有很多。

“工作都是同志做的”，是我在印象最深的一句话。每当我想起这句话，头脑中自然就跳出一个方程式：领导力=追随力+业绩。这是今天讲的建立领导模式的第一步。

# 2.第二步：价值观牵引

讲了第一步，接着讲第二步，用价值观牵引最多的下属，用你的领导方式去牵引更多的下属。昨天，我留的作业是，如果有组织管理，经过分析之后发现非常分散，在四个象限都有。领导应该怎么办？看了同学们的留言，感觉不多。现在和大家我们讨论，谈定，不一定对，听听参考。我觉果一个领导者，面对形形色色的下属，管理者一定会很头疼。正常情下，没有办法有效影响的。所以，如果人太多，就一定要对人员进行调整优化，这退回昨天的事情。

调整的原则很简单，就是想办法让更多人和自己的频率相合。无论是改变观念，还是先交交去，总之，就要让对象相合，如果多数人频率不适，作为领导者，仅沟通一二，就会被累死。

解决了下属的频率问题，你规划的领导模式其实就有了落地的可能。昨天的领导模式设计中，有一点我们没有讨论，就是“行动中的价值观”，这是很要命的。很多企业都做了企业文化的定义，大多数公司会简介的，墙上贴的那几句，就是企业文化。我就得不是，中国传统文化，就是是企业文化，就是领导和，中或者老板文化。墙上写的那些什么“今天工作不努力，明天就比力去”，之类的，都不是企业文化，到就是企业一句话。

我去一些企业演讲，老板中午，或者晚上陪我吃个饭，但他并没有一天天都坐在那里认真组织。而把这张口声音强说，学习“学习组织”，他这个口又大声，就是“咱们学，请老师去讲课，顶多算上‘组织学习’，这就建立‘学习组织’了”，这是完全不同的两回事。

所以，无论你是不在领导，有一件事你要认识：就是下属为什么会追随领导者，不是你同他的，纸上的，而是认了你是认同你，那么，领导者要格外注意种行为背后所隐藏的价值观。

# 3.第三步：个性领导

以上是第二步，下面讲领导模式实现的第三步。就领导模式去，除了要善于用你的值观管理思想去影响最多的追随者之外，还学会运用“个性领导”的方式，抓住关键人物，解释一下，就是当领导者的目标、行和信念，吸引了绝大部分的追随之后，他就可以脱出时间了，他要利用这些时间去做可以凝聚他的核心。人，团结最多人，帮助自己把计划一点点落实，进而达成组织目标。

今天我要交付你的一个核心概念是“个性领导”。这个概念似在字面上很难解但形象很象，以是为最有个性的大师讲领导，个性领导，用我们的个人说话系统，就“看人下菜碟”，就是讲领导者学会对下属每个故，和每个人培养独特的影响关系。
