# 1、双因素理论

去年我曾和几个以前的学生聊天，他们都是80后和90后左右的年轻人。谈到工作现状，有一位男学生当我面前，让他极简直爽。因为领导非常宽松，让他极简直爽。

这几年，我访问了不少年轻人，希望走进他们，中心寻找突破点，在他们心目中，很多领导的形象就是简单粗暴，这让我们想到了以前看过的一篇论述，说80后和90后这一代人是“保健因素主导、激励因素缺失”。

那么什么是保健因素，什么又是激励因素呢？进入职场，无非就是为了满足两类需求：一类是，如非是为了满足衣食住行的这些基本需求，工作环境舒适程度，同事间关系，工资待遇的公平性，这些可以理解为“保健因素”。另一类是，工作本身带来的挑战，成就感和自我提升，这些可以被理解为“激励因素”。

明确提出保健因素和激励因素的管理学家，叫赫兹伯格。他在1959年的时候曾经对200名美国工程师做过一项问卷调查，调查的主要问题是：你在工作上最满意什么？根据这个调查，他得出了保健因素和激励因素的所谓“双因素理论”。赫兹伯格说：当保健因素不足的时候，比如工作环境恶劣，工资低，就会产生不满意的情绪，员工就不会满意。但是，当保健因素增多，员工一定会增加满意度，要想提高员工的满意度，就必须要依靠激励因素。

以上就是赫兹伯格对保健因素和激励因素的定义。在这个基础上，赫兹伯格强调：要想带出一个好的团队，不能仅仅靠保健因素，一定要依靠激励因素，让员工对工作产生正面的情绪。

# 2、80后、90后的特点：飞驰而来的高铁列车

那么，如何界定和依赖激励因素呢？还记得我昨天讲过的概念——“动机”吗？所有人的行为其实都出自他们的动机。比如，80后和90后不一样。我们在说80后、90后，其实是说这两类人群，他们应该都是先了解一些他们的动机。

影响动机的因素有很多，但我认为，首先对于80后和90后来说，中国社会从90年代一直保持到现在的“剧烈变化”是影响他们动机的关键。中国发生了翻天覆地的变化，从上世纪90年代的中期，这代人在人生的早期阶段就经历过各种不安定。

经历了如此大的孩子，他们对于“不再”的概念的理解和老一辈人是不一样的。
