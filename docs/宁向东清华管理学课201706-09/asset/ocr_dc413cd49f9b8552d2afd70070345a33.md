# 029讲：领导力修炼 | 演一百遍，演的就是你

你好，欢迎回到《宁向东的清华管理学课》。

我今天要讲的主题是：领导不是天生的，领导力是可以修炼的，更重要的是，你将来一定会成为一个领导者。

去年，我做过一份研究报告，它的核心观点是：让一些行业领域的成功人士，去做综合性的管理工作，从最开始可能就得错了。因为失败往往这些人能行，是因为他们业绩不错，口碑上还能不错，但是，他们不一定具备领导能力。

这篇研究报告选的对象是销售人员，研究者通过云游故得或做了几百家有关公司的销售主管，发现了两个很有意思的结论：

+   1. 从过往往后看，如果提取出业绩最好的人，这些人怎么样的主张？结果并不是很好，有人往往往住不信任管理职位。也就是说，业务能力并不一定是管理好手。

+   2. 从往往后看，试图试图回答另外一个问题，就是前级销售主管，在表现报告的人，在被破格云游或做主管时不很优秀的人，晋升到管理业绩比较差的，在被破格之前，单纯业绩上过往在表现最好的人，他们的强项反而是在团结同事上比较出色，他们善于向同保持合作的态

于是，这端报告得出了一个最终的结论，就是：最富潜力的领导人往往不是在起工作时业绩最好的人。或者说，业绩最好的人不适宜担任领导职务，于是，报告建议：组织应该选拔那些善于动员他人的，而不是专业能力最强的人来做领导工作。

坦率地说，我很难心这份报告将会形成误导，原因有两个：

+   1. 我获得数据的专业人士之所以表现得不够理想，很有可能是在提拔之后，由于缺少足够的领导力的支持。

+   2. 这份报告所呈现出来的倾向，很可能会误导组织中领导培养的方向，甚至会造

# 1、未来趋势：人人都有可能成为领导者

我们先说领导不够用的趋势。未来的组织是什么样的？这个问题在第二模块重复的时候，我们已经谈过。我认为是，未来的组织无法定义权力的来源国，本质上可都是像三角形的。组织由串一线的工作单元所组成，在一线会单元里，领导者团队、合作者、甚至客户，都是一种协助推动的关系，这个过程就是领导者推动。于是，人人都可能成为领导者，整合公司内部分的工作单元，而法定权力最大的上级只是整个工作单元的支持者协助者。

我们可以用今天装修公司的结构，来近似地想象这种未来组织的结构。工作的项目领导者，就是整个项目的施工者和协商者，客户经常会参与到设计、施工、质量监督各环节里，合约会被企业、设计师、不同工种的人，无论正式的正式员工，还是临时请来帮忙的合作者，都是重要的资源，你经常会有这样的结构组织只有这样的结构，才以最有效地利用资源，满足客户不断变化、有最难化的需求。所以，领导不是未来组织最重要的能力，因此，我在开玩笑地说，领导未来会不够用。
