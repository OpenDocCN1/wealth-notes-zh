# 1、什么是“格局”

你好，欢迎回到《宁向东的清华管理讲座》。

今天的课，我想讲讲格局的修炼。格局，曾经是一个非非常大的词汇，大家都知道有大局观，但什么算是大局观？大家的解释都不一样。

中国文字里面的“格”，是一个动词，是“认识”的意思。有一个词叫“格物致知”，就是认识事物、获得知识的意思；而“局”，按照我的定义，就是人和各种资源之间的相互关系。所以，“格局”这个词的字眼在相互联系。就是把各种资源之间的关系统合起来看。大局观，就是看到最终，把事情都看个通透，就不会为一些细节所困扰。中国人把这种叫“想开了”，想开了，你自然就有了大眼界，有了宽广的胸怀。

上面说得有点虚，举个例子。我不知道你对下属辞职这件事怎么看。前几天，有一个同学问我，他带了一个年轻一位在下面，问他怎么办。我四年：站在下属的立场上去考虑问题，然后跟他谈。坦率地说，做到换位思考并不容易，因为不合你的本能反应。当你的下属要来你走的时候，你很自然地产生不悦和愤恶。可是，因为我是“得到”课程中的学生，你和我说话时，我想让你都自我，让同事着换位思考、试着去理解。这就是为你的，其更重要的是锻炼自己，培养自己的大局感。你要想：

> 他为什么会辞职？

是不是不可逆转？

只有换位思考才能看清楚。只有认识清楚，才能做出最有包容性的行动，让自己的格局得到提升。

# 2、王永庆的格局修炼

![](bbox=[0.2, 0.26, 0.8, 0.31])

我这一套是从王永庆的故事中学到的。30多年前，台塑集团还没有今天的地位。有一次，王永庆为一个重要客户争取更多的收入。他向对方另一个企业的高管去老大，他向王永庆多次提出了辞职。王永庆都面请不回。中国人讲“一再再三”，再三请辞，那就是去意已定。于是，王永庆对他进行了很长时间的考察，通出了详尽的评估。这个人说：“那边的收入让我无法拒绝。”而且他自己也决定去，他已经过了工作水准。个人的钱，用我的话说就是老水挣，所以说，如果他现在去，将在业界易名分名。

我不知道如果你是王永庆，你会怎么做，你会让他毅然名辞吗？

王永庆没有说同意甚至不同意。他很平静地听这位辞职讲了一些事。他要去的那家新企业的情形也进行了详尽的分析，为这位高管做了利弊分析和解读，帮助他分析了两个半小时之后，王永庆对这位高管说：如果你想这样，我们就把合同期延长。于是，这位高管的同事期延长了，又经过了一两个合同期之后，离职的话题又过了一遍。于是，这位高管又谈了一次，王永庆还是给他做了分析，帮他做了吃过的。

我们对这件事有一下复。按照一般的逻辑，这些按照常规会按照惯例的做法，你内心是怎么想？无论如何原因，你肯定是心里不舒服，这是很自然的。所以，一个人产生愤怒感是很自然的，可是你一愤怒，就会落入到没有格局的局里去了。更重要的是，如果真的是通过深思熟虑作出决策的人，你的愤怒不仅于事无补，还破坏了关系，伤了友情。

所以王永庆没有去挽留，他采取了另外的办法。我不知道你有过同样的疑问，反正我第一次听到这个故事的时候，我也有点怀疑。我第一反应是：王永庆这种不生气？但我后来想明白了，没有人遇到这种事能不生气，但是，王永庆用他的理性硬“忍”了。所以，后面我会讲到“忍”可以锻炼你的格局。

“戒急用忍”的好处，是会让人变得冷静。情绪冷静了，你的智慧就更容易发挥作用，就可以考虑怎么去分析问题。退一步讲，即使事情发生，也是没有用的。人一旦形成了这件事的，就会形成所谓的“格局”（最高），久久为功你就会达到“忍”的最高境界。

我们再回到王永庆身上的，就从他的个案来看。他最开始遇到辞职的骨干，也是开导，和他谈话没什么不同。后来，进入第二个境界，就是开始怒，这个情况下，帮助这个辞职者分析前途。

把处理辞职，变成一次关系经营。

王永庆手里放出去的台塑高管，远远不止我上面提到的一位。他在有很多骨干都是王永庆的亲密人，有一位在三十年来的台塑高管，一方面是为台塑集团带来更多的资源，另一方面也是因为王永庆在王永庆的光环之下，他希望能站在舞台的中央，在王永庆的位阶高看一层，虽然对于台塑集团来说，有着万分的不舍。但是，王永庆用他的格局和观念来塑造这些人的常情，最终台塑之内，从台塑出去的这些台塑高管，都会成为王永庆的左膀右臂，都成了台塑的“自己人”。
