# 005讲：涟漪效应|破不了得局

你好，欢迎来到《向亚东的清华管理第一课》。

前几天的课，我一直和你讲成做局的故事，可能不让你会以为学习管理课可以破解所有得局，但是今天我告诉你，有些局是很难破解的，特别是，自己给自己做的局。

为什么这么说呢？因为所有的管理工具和管理方法，都是一把双刃剑，既能解决问题，也会带来新的问题，所谓解铃还须系铃人，很多局是一号永远。大约20年前，我与河南海的董事长胡登森先生聊天，他问我：“向东，您说管理课是什么？”我说：“管理就是个气力活。管理工作，本质上就是不断地破局，你要防止上一个阶段自己投法，给下个阶段的自己留下一个新局面。”

# 1、涟漪效应

今天，我就和你分享一个这样的局围：用关系进行管理得局围。

很多企业都习惯用关系作为管理的手段，现在管理界，有一个专门得词叫"Guànxì"，是一个有拼音得“英文词”。以前老外用relationship 或者connection来翻译“关系”这个词，但这念是要不得，无法表述中国人这个独特的概念，所以，专门新造了一个词，老外给"关系"的定义是：中国人在生活和生意中，要建立和维系的人际网络。

那么，关系和“破局”又得什么关系呢？我先从一个人说起。费孝通先生，他是上世纪一位社会学家，费老最有名得一本叫做《乡土中国》，在这本书里他把中国人的社会关系比作一种“涟漪效应”。

“涟漪”，形象地说是把一块石头扔进水里，平镜的水面上会生出一圈又一圈圆形的波纹，波纹一层向外扩散，就是“涟漪”。费孝通先生认为，中国人的社会关系，就是这样一圈圈地沿着一个中心展开的，所以，这种中心圆点叫“涟漪效应”。而位于中心点上的，就是一个活生生的入，从某种意义上说，中国人是入“涟漪”

![](bbox=[0.2, 0.67, 0.8, 0.74])

中国人想事情都是以自己为中心的，考虑一切事情的出发点都是自己，每个人都有自己的涟漪，有人自己远心不同的圈子，远近不同，也就意寓着亲缘关系不同。我们有时候说，“亲戚有远，朋友有厚远”，说的就是这个意思。总点，涟漪效应是对中国人关系一个很好的概括。

# 2、关系的局

中国人基于关系的人际交往逻辑，实施体现在“很多级内部”。在组织内部，存在着很多“涟漪圈”一样的关系圈子，哪些人多些，哪些人远一点。组织里的人都知道，由于级导致果果，如果己的人特别少，是很有优越感的，圈子近的人，一定要坐到重要的位置上，自己才会感到安全。如果一个人领导在台上讲话，台下坐着的人没几个认识得，哪怕他权力大，心里也会有种失落感。

所以，在中国人的组织里，下属会强调领导对你好呀不好，领导也会格外去识别哪些是亲信，哪些是外人。
