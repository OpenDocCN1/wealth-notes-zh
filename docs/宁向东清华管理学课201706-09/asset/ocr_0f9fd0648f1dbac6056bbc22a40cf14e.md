# 生封了15年的徐小平演讲

![](bbox=[0.25, 0.29, 0.75, 0.4])

《中国合伙人》这个电影，我在航班上看了几千万，就匆匆换成了另外一部电影，因为实在太长了。电影以新东方创业历程的故事为背景，这是电影前一段时间看得出来的。但在电影里，制作方却将新东方实头换图，叫作“新梦想”，三个主人公也都各自取得了新的名字。学校不叫北京大学，改叫燕京大学，但都知道说的是北京大学和新东方故事。

我最初会因为因为香港港导演陈可辛来讲，才开始知道这是一部香港导演的电影。后来听说这是徐小平亲自下的初稿，因为要求这篇成，我才开始看到，并把电影找出来，用成进的方式看了一遍，并把电影关注了后面三合伙人彼此冲突的部分。我仔细看到徐小平为该片定的调子，也看出了徐小平的厚道。

15年前，我和徐小平结识于一次电视节目，我有幸被看得起，认为是知音难觅。为此，他受邀请着看到我的课堂上和学生作了7门交流，我特意多走了一趟。我是现场唯一带DV的人，经小平同意，我录下了他的演讲和交流环节，这是我研究新东方早期发展过程的一个重要角度。

因为小平讲得诚恳，在演讲中有无数次吹言（上），他人认为他没有把这场演讲（以下简称“清华大学”）作为公关活动，也不是为了推销他的书《困穷对话录》，而是真诚地当作了许多演讲。我一度多认真，所以，这个演讲资料我一直很珍惜，没有讲过。看完《中国合伙人》，我将小平当时的讲话翻了出来，没想到，竟一连看了6遍，于是，我有了这篇文章。

新东方上市之后，俞敏洪也受我的邀请来和清华EMBA班做过交流。老总自然对他的角度，有人创立，也是他对大多数时期的他本人。但是，今天温小平当年演讲时，我再次在新老小平对老俞的价值之外，认识到了徐小平与王强的价值。新东方能有今天的辉煌，甚至可以是北大企业界的故事和案例，做教培集团既厉害，但是，如果换老态之后的这几年的内部冲突，没有徐小平和王强的理性，新东方的故事也许会有另外的版本。

![](bbox=[0.25, 0.81, 0.75, 0.92])

1990年代中期，在俞敏洪为新东方下一个坚实的后庭之后，徐小平和王强的加入，使新东方有了所谓“二驾马车”的格局。在一个新东方学子的旗帜下面，俞敏洪继续他优秀的出卷试训力，徐小平为大家从出国学生的入口咨询，王强开始了他的口语教学。一个平台，三类服务，自己管自己的情清。人，财、物各自不搭，秋后有了收成，无去多少，一律不计平白割自己的做下。当时的新东方，是典型的三个山头。

三个山头，缺乏协同效应，搞不好还不如三个独立的分公司，做大不成。同时，三类业务发展不平衡，利益也没办法平衡。于是，最自相然而然的，就是每个人都把自己的山头，利己然而拿出一部分来，让彼此交支持，通过互担担累而获得更多的协同。而这就好像更多的混无。用小平的话，这么说，比较加和的元杂，这是没法激起其他骨干、促进企业进一步发展的思路。
