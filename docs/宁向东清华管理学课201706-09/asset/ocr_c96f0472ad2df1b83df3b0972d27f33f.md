# 1.超越权责利

当你成为了一个管理者之后，你具备了根据组织授权而拥有的岗位权力。你有了指挥下属干活、表扬和激励权力。批评了惩罚的权力，但这些像是随着管理岗位而有的权力，是比较初级的权力。当然你不可以仅仅依靠这个来开展工作。但是，我们整个模块的学习，就是为了让你突破管理的层次，**帮你成为真正意义上的领导者**。

领导者，不是靠职位权力生存和工作的，他要是进下属的内心，要利用影响力把下属发展成为创造者。领导力，一旦变成了追随力，就会创造领导者自己也想不到的效果，一种成几倍效的业绩。创造影响力的关键点，是透过专业能力和魅力的展现，当然，具体的领导风格，包括在工作过程中展现。通过权威关系来展现，以及借助工具开展模式。每个目标都需要通过追造自己的领导风格，来领导下属和下属，达成组织愿景，实现组织目标。

# 2.不同的领导模式

领导者是构建影响力的有效，是多种多样的，从大大独独、乾纲独断，到员工主动、合作共治、类型特多。为了让大家能够更好地了解领导力的模式，我在第二周给大家介绍了几种基本模型，从集权到分权，形成了一个谱系。我在五种管理模式的讲解中，格外注重向你介绍它们的优缺点和适用条件。

比如，**硬权力领导模式常常很见效**，我相信在某些人心里也常常是常见的领导模式，但是，它也还是有用但是有限的，在组织快速发展要抓机会的时候可以有用，但是，它需要张强、持续创造和下属的忠诚感来获得。**SuperCell公司的协同型领导模式**，虽然非常少见，但在特殊管理情境中，可能是非常有效的。

我介绍了5种领导模式，有我一个学员的话，第36讲中谈的是另外一个分类概括，也有他的分类方法。可见，领导模式是多种多样的，不存在唯一最佳的领导模式，好的领导者要学会根据不同需要确立自己的领导模式。

# 3.根据情况选择领导模式

这就引出了一个概念：**“权变”**。“权变”思维，是管理学者最需要理解的一个概念。一个组织、一个领导者要选择什么样的领导模式，其实，权变模式，是需要根据情境自我设计的。不仅仅是领导者模式设计上，在**任何的管理问题上**，领导者都需要懂得在这种问题上，有分区分地解决，而在领导模式上，权变思想的核心，就是从追随者特征和领导情境这两个方面做文章，寻找一个恰当的实现方式。

首先，需要考虑追随者特征，对追随者的了解和分析，对与领导者是领干过去的必修课。我给大家介绍了管理学家费利叶的“追随者框架”。其实，这个表格你可以过它自己的表格里来，但是，不管它样对下属分类，**核心要点是要抓住下属的动机、愿望和内心**，通过有效的方式，带动你的下属。

坦率地说，管理者讲话通常是特别容易，但是落地比较难。所以，我在第36讲介绍了一个我自己开发的领导力模式设计工具。这是我已经使用很多年，但没有设计公开发过的工具。供你参考。很多人觉得第36讲最 “牛”，听起来，读起来都费脑力，但是，我觉得其中最大的方法是自也自力，是的，我自认为最有价值，所以，在清学和在「得到」的课中，我会和大家分这个东西。在外部任何演讲和教学过程中，都没有讲过。说这些，还是希望你能足够重视这一讲。

权变思考，第二个需要考虑的，是**领导的情境**。因为环境不同，领导模式的使用都应该人不同。打个不太恰当的比喻，就是要见人说话，见鬼说人话。有时候，我们说：大领导都平易近人，真是这样吗？不见得。达维书记见人，那是驾马连诚。但是，对待普通百姓，他则会堆起笑容。这就是权变管理。

# 4.不同情境下领导力的打造

为了让大家加深理解领导力和情境的关系，我讲了三种不同情境下的领导力问题。

+   1. 创业的情境。这是为了说企业发展阶段的不同，而考分的情境差异。我用“未来、现在、过去”这三个字，来概括创业领导力。希望由如何思考在创业领域中，领导力该怎么设计，应该有什么作用行为上。

2. 身的情境。我选择了研究生女性的例子，这是环境选择的典型。研究：身段关系、维度组合，是领导力效果特别好的模式关系。**有成功的母性特征**，但仍决决和行为上却表现出比男性还要强烈的原感和表达要求。

3. 管理中层的情境。我选择了中层领导者作为分析对象，这应该也是很多同学目前处的情境。对于中层管理者，人际能力也更重要。当然，核心能力和技术能力也重要。中层管理者应该围绕这一点来建立自己的领导风格。回顾的思绪，我也想起自己悟出来的一个办法，请大家记一下，并且学会应用。**圆圆的“细”**，没有讲，但“平面化”意识和“大局”意识，是面面观的核心。

# 5.善于把自己“演”成领导者

总结一下，好的领导者，要结合下属、追随者的特征，结合管理的情境，去设计自己的领导故事。有些是你特质中具有的，你需要**激发**；而对你的一些特点中没有的东西，你要**注意学习，注意表演**。

还记得我在课中向你转述的，领导力大师尼尔斯斯说的吗？领导者不是天生的，而后天造就的。没有一个领导者天生就想成为一个领导者，他们只是愿意给自己找理由。表现出来，我都成为好的领导者。所以，一定要记住：成为一个优秀领导的秘诀，就是练习。当你演了一百遍之后，你演的就是你。

好的领导者，善于运用你的价值观和领导风格去影响最多的追随者。同时还要求你运用“个性领导”的方式，抓住关键的少数。
