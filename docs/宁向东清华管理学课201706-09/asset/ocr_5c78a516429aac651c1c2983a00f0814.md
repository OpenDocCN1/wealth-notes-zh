# **1.画像**

你要做的第一步，是要深入洞悉下属和追随者的特征，给他们画个像。画像，在所有的管理工作中非常重要。比如，作为需求去跟消费者，你应该要了解消费者的需求，这就要给消费者画个像；或者你为一家公司做事，公司客户群一样，你还需要去理解你的企业客户和员工的特征。

> 要理解他们的基本逻辑。所以我建议：为了赢得追随者，你要了解他们的需求和期望，就是要在合适的时候给他们一个抓手。

画像的方法有很多种，有时候人的需要会具有一个特性，比如，需要很有复杂的东西才能画像，比如“需要层次分析”，这是我在很多管理工作都会用到的一种方法，但你只需要知道需求分析是一种给人分类的工具就行了。

我们不用画像，还是用你最熟悉的四象限图示来了解下层画像。

我们要领导别人，关键是要形成影响力，让追随者，或者下属完成任务，所以，我们可以根据工作任务的性质把下层纳入到一个四象限坐标系里。比如，今天我们采用：

+   * 横轴，是“工作结果是否容易判断”这样一个维度，我们将之简称“结果”；
* 纵轴，我们可以选择工作过程是否需要给予格外的关注和激励，我们简称“过程轴”。

于是，我们就可以得出下属的四个象限。

第一象限，就是下层的工作在结果上容易作出判断，但是，在工作的完成过程中，你需要给予额外的关注，让他们有足够的工作...这个象限的下层。

再看第四象限，这一象限的下层，工作结果很容易作出判断，而且在他们完成任务的过程中，你不需要给予他们过多的关注、指导等，只需明确目标。

# **2.展现**

第二步，我们就要结合下层的特点，思考如何展现自己的领导力，形成领导风格。因为你的任务，就是把下层带到自己的身边，完成组织的目标。

展现领导力，就要根据下层的情况来安排。展现领导力的途径，主要有三条通道。这种分类的方法，来自德鲁克夫的一位同事，我结合中国的情况作了一些改动，下面，我分享下。

第一条通道，可以用八个字来描述：以我为主，直接展现。比如，有的人的业务能力功底扎实，快速看到问题的能力超强，所以，...这种展现领导力的策略有两条：

+   1. 全身心投入工作，通过工作过程中的外在表现展现出领导力；
2. 不断超越竞争对手，用业绩来展现影响力。

第二条通道，是通过关系来展现影响力。可以用八个字描述：建立关系，诉求共情。这类人虽然能力不足，但很能协调...这种展现领导力的策略有四条：

+   1. 善于发现人才，通过为他人搭桥铺路来形成影响关系；
2. 善于与下属建立亲密的合作关系，乐于分享成果，勇于承担责任，以诚待人，共同克服困难；
3. 给予各种支持资源，通过协助、指导、整合下属资源帮助下属；
4. 善于利用他人之间的关系，促进形成不同利益的小团体，整合人际资源。

第三条通道，是利用工具来展现影响力。像授权分权、强化激励，都属于工具。也...这类人影响他人的策略分两大类就是两种：

+   1. 用分权的办法，激发人的上进心和责任感，通过成就他人来展现领导影响力；
2. 用物质激励来激发人的行动力。所谓大饼分，就是这个意思。

这三种影响力策略，你可能不能全部采用，虽然影响很大，你的领导风格选择鲜明，所以，我们的原则是用最少的策略，去影响最多的人。那么，接下来请你思考，如果只能选择五个策略，你该怎样选？如果只能选五个，又该如何选？若干年后，我总结出一种画连线的方法，请看下文。
