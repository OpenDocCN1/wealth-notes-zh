# 3. 雌雄同体

最后，我向你介绍一个最新的管理概念，叫做“雌雄同体”。这个概念来源于三位学者在2012年的最新研究。他们发现，当女性领导者在领导行为上表现出双性化特征（即“雌雄同体”，英文为androgyny）时，下属无论是男性，还是女性，会对领导者行为的有效性表现出较高的评价。

我们从前面几位女性领导者的例子中，也可以发现：所谓雌雄同体，就是她们都在处理同事关系这件事上保持了较强的母性特征，但是，在决策行为上却表现出比男性还要强烈的刚毅感和坚定感。我写和学生对开玩笑说：“雌雄同体”翻译成‘男人婆’，便于理论记。但是，传统意义上的‘男人婆’，是指女人不像女人，但是，如果女人还是女人，但又吸收了男人的精华，这种‘男人婆’怎么能不厉害呢？

好，今天的课，我们介绍了女性领导力的概念，最后，我用穆勒特的一句名言来结束今天的课。时代在转变，正好符合了女性的特质。这句话值得深思。

# 女生往上走，男生往下走

这篇文章，不论你目前的职位，不论你的性别，不论你成材与否，我都希望你能以我在第一模块所讲的，尊重‘人’的视角，洞察其背后的管理思路。另外，也欢迎分享给你的女性朋友。

当年，我在清华读书的时候，女生少得可怜。本科两年前，我的电报系，班才31个人，女生有6个，当时已经算是比较多的了。住在一起的热闹得数，女生只有了一两个人的情况，非常少见。每年过新年，班里搞活动，班长要外面去“借”女生，有的班长不借，直接回答“不借”，就搞了隔壁班的“念想”，这也是今天记忆中一个笑谈。我自己后来转到经管学院，班里20人，只有一位女生。我后来，继续在清华念研究，40个同学里面，女生也只有3位。这就是当时清华学生的基本性别情况。

今天的情况与那时有了很大变化。现在我的研究生比女生多，男生少了一半人。据说本科生里面，情况也差不多。情形与我们那个时候大相反。原因是什么？我不知道，但猜想可能是因为考不过女生的原因。一路杀到硕士，男生不会比女生多，也许是主要原因。女生考试总比较好，排名也比较靠前，因而得到录取。所以，现在一比二，女生得了博士的比例更高。前几天本系的博论文答辩，两位教授的五名弟子，竟然全是女生。

我多来一个奇怪的观念，也不知道对不对。就是：这个世界智慧主要由女人传承。关于基因的问题，我是爱好者，我看的书杂而泛，不成体系。但到目前为止，我还没有看到一种权威的说法，能够告诉我到底有什么东西决定人的能力。到底哪一条染色体、染色体的哪一段关乎人的智力。人的智力到底是先天决定的，还是后天的因素更强大。最近十儿年的论文很多，但研究结果莫衷一是，比如，这里面一个很大的问题：是什么叫做智慧，这可以说用智慧的水准，很多人会说难道人类智力这么复杂的事情，可以拿一个数字来代表？

有一个说法很有趣，我也不知道正确与否。这个理论说：智慧基因不是由X染色体承载的，女生是从父母那里各得自己的一条X染色体，父母的智慧都给了女儿，而男生则只来自爸爸，据说Y染色体基本上没有多少管智慧的东西。所以，爸爸的智商与儿子无关。女生天生就比男生有智力优势。因为爸妈把思想都给了女生。如果这种说法成立，男生考不过女生，就可以得到某种程度上的解释。

写这篇文章的目的并不是在科学证据上求得事于，请大家不必陷入对基因的讨论中。对于基因研究，我只是一个爱好者，但是，如果有最新科研成果，我也非常愿意和大家一起学习。

在女人的一生中，结婚之前的外界因素是极高的，不像男性那样容易吸引外界因素极度拥挤。同时，子女长女之后，减了负的女人专注力也是极佳的。我曾经接触过不少女性企业家，这些人50年的竞争过程中没有输掉，所以，输掉后半段的可能性更小。女人过了一定年纪，会更加专注，如果只有企业一件事，那种专注是极其可怕的。

她们中很多人通常很晚才离开公司，第二天一大早又在公司上班，绝对是工作狂级别的。这些女人如果不是因为更年期到了一些影响，很可能意义上说是无法出错的。相反，50岁的男性企业家可能会花很多时间去研究其他的事情，不如女性专注。女性唯一吃亏的，就是做事需要关系，而女性的社会交往比一般男性要少。

说了半天，其实就是一个意思，中国社会未来会出现一个漂移现象：女生群体向上，男性群体向下。既然高学历女生的比例提高，那么调女人员工的力量多，这也是许多企业家必须要正视的事情。因为高学历的女孩多了，有意思的策略会是解不掉的，而是‘解’的策略很可能非常愚蠢的。现在很多单位在录取研究生的时候，大都不愿意要女生，或者是在人家人如果是不想几年不分孩子。我觉得这是很愚蠢的要求，不合情理，也不近人性。与其提出这样的要求，不如重新‘企业办社会’，把托儿所和幼儿园办起来。
