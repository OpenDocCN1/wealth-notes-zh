# 1.TK模型

首先，仍然要从冲突的性质出发，去作一个基本的研判。看看这个冲突，是属于健康的冲突，还是恶性的冲突。如果是健康的冲突，核心是要把冲突的水平，有些甚至可以创造性管，因为它很有可能会产生一些创造性的建设。研究的是，我们进一步讨论什么建设性冲突是好的。如果冲突属于恶性冲突，领导者就需要考虑如何处理掉这个冲突。

今天介绍的管理工具，是个思维模型，叫托马斯-克曼（Thomas - Kilmann）模型，后面咱们简称TK模型，这个模型的意义是可以帮助识别冲突的细节，然后针对解决冲突的方式动作。

TK模型，仍然是2X2的矩阵库。它用两个维度来描述选择处理冲突方式的逻辑。纵轴的方向是向高者领导者对待冲突的态度，是选择回避式回避解决，还是通过专门解决解决。领导者也要思考一个属于这个解决方案的高度和稳定性。领导者可以根据自己心志的评估，在这个维度上，先把自己的心态摆清楚。

这是一个模型的融合，考虑的是从团队冲突是不是要配合领导者的冲突策略，他们愿不愿意合作，根据这两个维度的组合，领导者可以分位自己对于冲突的策略定位：回避、竞争、迁就、协作和妥协五种形式。唯一刷新微信: 699250

第一个策略，就是回避冲突，先放一放。选择第一策略的观点，就是大要家东西不一样，所以有虎虎意思，博弈论里面叫做“零和博弈”，一方得到，是另一方做输的，在这种情况下，领导者通常没有足够的资源和简单的方法立刻解决问题。搞不好，也会让自己颜面尽失，有失面。即使赢了，也会让别人心服口服，自损八百。所以，这时候的一个最佳策略，就是不妨先避开。

第二种策略，叫做竞争。在有比较大的把握的情况下，领导者可以用一种“我赢你输”的心态或者解决冲突。这在原则性分歧的时候，或者是决定要不要作出取舍、利不容缓的情况下，必须得采用。属于“该出手时就出手”，一旦领导者选择了这种面对冲突的策略，就要有鱼死网破的决心，表现出必胜的强势。当然，作出这样的选择，是要需要蛮勇的。你给我。另外，采用这个策略，要非常清晰地表示出自己的策略，目标和要求，如同团队成员清晰地展示出“我只有一个观点，我的原则绝不会动摇”的信号。

第三种策略，叫做迁就。这是最委屈，也是最考验领导者“心忍功”的策略。说到，这里还是保持“我赢你输”的策略，你一定要注意，当一个团队存在着冲突，而领导者无法解决的时候，领导有办法，也就是妥协，有很多的时候，领导者没有，就是接受这样的局面。

你也许会问为什么，没有了什么，因为你是领导者，在有限的权力没有团队平衡的时候，你就要忍受着压力，维护团队的平稳基本合作。听你课的，也正处于这样的情绪。也许很多管理者，让你记住的话：坚持，比如说要多走到，要取得团队认可，维持团队的和谐，多数团队是，让团队感受到某种领导者要多付出，于让团队成员感受到某种程度的团队和谐。

不过，请你一定要记得，迁就并不是毫无原则，要学会让让对方出自己的价值，这个时候要在敏感中见自己的力量，静候时机。退让中开价，是一种技巧，要为对手留出你的底牌，要在均衡维系着双方的平衡。

第四种策略，是选择妥协，就是矩阵中交叉线上的那个策略。我个人认为，妥协不是输赢，妥协策略，也叫“折中策略”之，不以和为贵，求则，它也是最难之计。使用妥协策略的一句话可以这样： “如果你们同意我的看法，我会……如果我们不同意……，我觉得大家都没有好处。”

使用妥协策略之前，一定要反思权衡双方的冲突到底暴露接受双方不一样策略，对的中底线有多深，如果对一方的意志，妥协策略才会取得成功。经验表明，妥协常常是权衡之，不宜于多次使用，多次妥协一般是都不好。

最好的一种策略，是协作策略。这是一种双赢，或者多赢的局面。达到了这个局面，重在让大家看到可以解决冲突意愿，采用这种策略，不仅是为了危机时的过渡，而且有可能今后能不断创造合作，以协作应铺开通一条道路。

# 2.实战分析

我们下面通过一个实际的案例，来看看几种策略的选择逻辑。比如，有一家企业设计一个新产品，接下来需要市场部门能很快决策推出去，并且能够反馈回来市场快速反馈，产品部门可以迅速改良调整这个产品，这就形成了一个动态合作的问题。可是，市场部门有现成的销售工作，新产品会增加他们的负担，需要资源的投入，而且行业是不是容易看清，两个部门没有太多的意见。在这种情况下，两个部门就会出现冲突。这个冲突虽然发生在部门之间，但和小团队内部发生在不同成员之间的冲突，道理应该是一样的。

面对这个冲突，按照前面TK模型，领导者有五种策略：

+   1. 选择回避策略，那就意味着公司不会为这件事专门开大会，各部门都忙，但是事情搁置在那里，大家都要面对，而且时不待久，双方矛盾会日益激化相互的，后果会很严重。这是一个三输的策略选择。

+   2. 选择迁就策略，比如负责人产品研发的经理退让，让步部门，告诉部门：“你们的话，研发部门基本忙完，市场部门很忙碌，并没有压力，一方高，领导负责双方沟通。”

+   3. 选择竞争策略，和相关部门说，你们要不投入资源在新产品上，原有的业务份额，我可能将你们调拨一下；研发部门解释，你们的精力我都看到了，市场那边也确实有困境，你们要把目光放长远，别嫌麻烦太快点就出来，毫无疑问，选择这样的策略，是上策。

我刚才上，所以我们在组织面对冲突，常常会面临以上这些并不理想解决问题的方案。会否要简单认为这是属于领导的无能。以上策略的选择，背后都有着深层次的原因，体制方面的限制，资源准备的不足，以及人员能力的缺乏，等等。

不过，好的领导人从长期看一定会不满足于这三种策略的“上策上策，而是会选择另外两种策略。那么，会，比如，采用竞争策略，就是让两个部门的负责人各自提一个整合办法，领导者想法，一个就办了。如果用协作策略，事情就没有这样简单，而是可能要征多事一些策略，虽然领导的人数的想法。前者的好处是效率高，但是，如果出现问题多，领导者的威信会降低
