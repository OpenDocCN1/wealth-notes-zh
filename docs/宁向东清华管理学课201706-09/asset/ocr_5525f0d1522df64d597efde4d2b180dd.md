# 1、追随者表格：区分5种追随者

我们先讨论一个概念——“追随者”。

大 concept，我应该不用细说了，“追随者”其实确实是领导者相对的、受到领导或者实际由支配的那些人。领导者和追随者，是组织中的两个角色，它们相互对应着存在。我们前面讲那么多关于时间理财的内容，其实就是想要把领导者的超越理想者的层次，把更多的下属转化为追随者。

不过，追随者也是有程度分别的，每个领导者都还应该对追随者的状态有清晰的认知。

1992年，管理学家凯利在采访了大量的领导者和追随者之后，总结了他和追随者的纲领，并按照两个维度，把他们画在了一个坐标里，这就是著名的“追随者表格”。

凯利对追随者的区分采用了如下两个标准：

+   1. 追随者是否积极。积极的追随者可以全部心甘情愿投入到组织中来，并且有更强烈的工作主动性和积极性。

+   2. 追随者是否具有独立性和批判性思维。

“批判性思维”最近很时髦，是西方管理学界兴起的一个新概念，意思是说：

一个人再判断问题的时候能够有效地搜集信息，逻辑思维，思考周全；

做到在充分论证再作决策的时候，能够独立，客观清晰，思考问题，权衡利弊。

凯利使用这两个标准作为两个坐标的维度，对追随者进行分类，于是，就把所有的追随者分成了五类人，准备说是他们所有的所存下属入了成5类人群。他们依次被称为，“有效的追随者”、“循规蹈矩的”、“不合群的追随者”、“实用主义的生存者”，以及“被动的追随者”。

![](bbox=[0.25, 0.62, 0.75, 0.73])

有效的追随者，是领导者最值得依靠的对象，因为他们能够积极地投身在组织的目标之中，同时，他们又简单易懂，具有独立性和批判性，敢于提出自己的意见，敢于表达不同的意见，敢于担当，对组织的目标负责。

可以说，拥有一个这样的领导有效心的，一心为组织的目标着想的领导者，有效的追随者越多，组织的成功机会越大，我前面所说的“打造成进取的组织”，说到底，就是要创造出更多的有效追随者。

落在第一象限的人，在组织中并不是太多。很多人大体都是积极的，但是，并没有太强的独立性和批判性思维的能力。他们落在第三象限，就成是循规蹈矩者。他们的特点是唯命是从，从某意义上讲，他们很像一个盲从的牛。这一类人群落在第二象限，他们的独立性和批判性思维程度高度发展，但是，因为各种各样的原因，他们态度消极，甚至处于组织显现出了一定的破坏性，这种人叫做“不合群的追随者”。落在第三象限的，是一些基本没有什么价值的下属。他们既没有独立思考的能力，也不会积极主动地参与组织的事情，他们被称为“被动的追随者”。

凯利这个坐标，最有创意的地方，是他围绕着原点定义了一群“实用主义的生存者”。这类人见风使舵，善于趋利避害。在这条线上，本文就称其为（领导学）里，对这一类人作了一句话描述，“这些人多半是把行为准则当作风险，他保守现状，政客们喜欢常常会出现这种情况，因为他们要在很短的时间里完成自己的工作。”

# 2、如何确定下属在哪个位置

好了，我们再把这五类追随者，或者下属的特征描述完了，很多同学说，讲到这里就结束了。但是内容就刚刚开始，我请你把你下，属到都放到这个坐标里。如果你没的话，下一层就是你下面的下属，就把它放在这个坐标里。

放好了以后，我想请你，随便选一个人，你不能告我，把他（她）放进这个坐标里，而不是他像什么？管理学的工具性都会全都放在追踪之中。所以，我请认真思考一下这个问题。

还记得中学的数学吗？在坐标上，定位一个点，需要两个值的，横轴有一个值，纵轴有一个值，以横轴为例，我们对一个人的积极性进行评分，比如0到5分就是消极的，0分最消极，5分算是中间状态，而获得5到10分就是积极的。10分是最积极的。你也可同样的是的，可以怎么算，请注意里的原点，它的坐标值是5和5。正是基于这样的定义，我们才建立了一个坐标。

于是，一个之所以被你放在第二象限，呈现为一个“不合群的追随者”，一定是因为两个的值，比如是（2，7）。他的独立性和批判性思维是7分得了分，这是纵向的得分，因为它高于原点，所以在整个坐标横轴上面。而横轴上他的积极性得分可能只有2分，比5分小，它就在原点或者纵轴的左侧，总之他是落在了这个坐标的第二象限。

那么，接下来，我还要问你：为什么这个人积极的评分下面，你又给了他2分？你是根什么给的？为了回答这个问题，我帮你准备了这样一个表格。

| 指标名称 | 权重 | 评分 | 加权评分 | 
| --- | --- | --- | --- | 
| 1. 工作动机 | 40% | 3 | 1.2 | 
| 2. 上下级关系 | 30% | 7 | 2.1 | 
| 3. 团队贡献 | 30% | 4 | 1.2 | 
| 加权总分 |  |  | 4.5 |

首先你想想，都有哪些因素会影响一个人的积极性。比如，你会想到我们要提到的工作动机，也会想到上下级关系等等。这些要素都会影响到一个人的积极性。列了这些内容，接下来，你会注意到，这些因素，对积极性的影响的程度会不一样，比如工作动机可能更重要一些，比如，大概占40%，上下级关系多一些，大概占30%，也就是说管理差异比给了我们不同的权重。当然，这些数字都是在打比方，占比反映了不同因素影响的大小。

好，有了影响积极性的这些选项，这些因素，同时给它了影响的权重或者影响的程度大小，接下来，你就已可以给他上选项打分了。打分可以由你自己完成，也可以由这个人自己打，还可以由独立的第三方来打，不同的打分者是不一样，反映内容也不一样的，不过，不管是谁来打分，最终都要把所有 的分值加上权重，然后再加总起来，得出加权的分值。之所以给这人2分，通过加权的分值应该是2分，所以把他画在了第二象限。

# 3、利用图表工具辅助领导力修炼

在象中，假设被放在第二象限的那个人，在许多影响积极性因素中，肯定有一项是得分最低的。那我该提一下，请考虑一下，为什么这项的最低？是什么样的历史文化者，或者是什么样的家庭背景影响了他这一项的得分？你可以使用什么样的办法，使用什么样的管理动作，去影响他这个意思得分？

你现在意识到了吗？当你努力改变他的得分的时候，比如他的坐标在开始向方向移动的，的时候，你就在自己影响力的圈。

而你的影响到他的积极性的时候，不就是一个有效的领导者了吗？我们又素来又是素来，你的成果其实也是希望找到好的幕后团队，然后通过学习，通过我们的管理动作影响他去改变自身。
