# 023讲：公平感｜领导者的内功

你好，欢迎来到《宁向东的清华管理学课》。

今天，我和你分享关于“公平”的观念。要形成一个有效的组织，没有什么比公平的感觉更重要了。所以，管理学里的一个基础的观念、感觉是“公平”。只有创造一个相对公平的环境，组织才有独立文化和好制度的可能性，大家才会真心相信领导者所讲的道理，成员才会稳定。**而决定这一切的中心点是：管理者是否有格局，在于他自己是不是真正认识到了什么是公平。**

公平体现在方方面面，收益的分配、资源的分配、包括晋升等等问题。你仔细想一想，所有这些问题都内含着领导者对于“公平”的理解。

今天的课堂内容，可以说是我们课程里最难的一讲。不管你学历怎么样，也不管你听了几遍音频、读了多少次文稿，只要你把今天的课懂懂了，就达到了清华MBA毕业生的中等水平。请你试着挑战一下自己。

# 1、最后通牒博弈

我下面从一个例子开始讲起，这是一个非常有名的博弈论，叫做“最后通牒博弈”。

这个博弈的故事是这样的，我给你描述一下：如果甲和乙在路上捡到了一百块钱，然后甲和乙一起来分这笔钱，甲有权提出一个分配方案。也就是说，甲会提出，“我分你40，我8002。”不设什么样的方案，只要也提出的方案乙接受了，就按这个方案来分配，那我们的故事都是这样发生的，我也会对此也有怀疑。可惜没有一天，乙会对此有怀疑。乙改变我想说的，我看见了第一篇根本不太改变我想法的论文，它开始鼓励学生建立另外的一套思考方式，包含了“公平”的思考方式。

![](bbox=[0.15, 0.3, 0.85, 0.38])

按照“理性人”的假设，甲首先会想：乙是理性的，如果他不接受自己的方案，他就什么也没有，收益是零；而如果接受，哪怕只给1块钱，也比什么都好。所以，甲按着“理性人”这样的假设，会提出这样一个分配方案：自己99块钱，给出1块钱。因为对乙来说，有总比没有好吧。

我告诉你，标准的博弈论教科书，就是这么教学生的。甲应该提出一个99对1的方案。其实上，全世界的经济学课堂，也都是这样教学生的。我去对此也有怀疑。乙改变我想说的，我看见了第一篇根本不太改变我想法的论文，它开始鼓励学生建立另外的一套思考方式，包含了“公平”的思考方式。

这篇论文的作者在全世界找不同的人来说实验，看看大家在现实社会里是怎么分钱的。结果，得出的结论令人震惊。在文明社会里，实验中甲提出的分配方案大部分都是对半开，当然有的少一些。但如果是丛林社会的部落里，往往分钱方案也是三七开或者八分，没有人是按照教科书99比1那么分的。

后来，我又读到了一系列论文，都是在不同场景、不同的金额做实验，结论也是相似的。即便稍微注意国家的实验，实验的对象要分的钱相当于他们三个月的收入，情况也不会好。另外，我在薄海的课堂上，讲过这个问题的时候，常常会花很多时间去探讨人类的“公平感”问题。“99比1”的这种方案在道德的问题上、社会“逻辑”上，可能只是大程度满足了个人的私欲，满足了自己的私利，但我常常请学生思考是：这种分配方案符合人类的公平感吗？

# 2、人类“公平感”的前沿研究

关于人类是如何产生“公平感”的，这是学术研究的命题。所以，我和学生进行讨论的时候，并没有最厉害的答案，我只能给大家小结一些研究的研究。比如，我告诉学生，神经科学也已经在发现，我们可能存在一种叫做“心理收益”的东西。就是当甲一个人钱提到甲给他30块钱的时候，这30块钱会给他的“预期心理收益”。当一个人产生“预期心理收益”的时候，他的大脑中有一个部位叫“纹状体”，那个区域就会被激活，这个发现已经在多次实验中证实了。

纹状体一旦被激活之后，当他发现甲最后只给他1块钱的时候，他会很愤怒，会拒绝接受这1块钱的收益。甚至他不会再用那几块钱的本身去报复，而且，纹状体被激活的程度越高，报复的冲动越强。但纹状体，只是为了获得报复行动给自己带来的快感。

再比如，现在的研究也发现，不同性别的人，对于公平感的理解也不一样，也不一样。首先，不同的别人，如果他当甲，他提出的分配方案都显著地表明，人们的公平感类似的，都看到共同的分配体系的影响。但是，如果是拒绝甲提出的方案的话，一般女性的拒绝率会较低。不过，在实施报复行动中，女性却更多地会因为不满而实施反击。

当女性实施反击的时候，她们是比较在意报复的成本的，如果成本比较低，她们进行报复的比例就越高。而报复的成本比较高的时候，更多的女性会选择报复。最有意思的是，男性如果为甲，他们不会因为女性比男性分更多的钱；如果女性作为甲去分钱，则会因为乙是英俊的男性而分出更多的钱。

以上是关于人类公平感的最新研究，我就不展开介绍了。人类的过程、学历、文化背景等，都会影响人们的公平感。

现在总结一下，“公平”是重要的管理概念。虽然，我们尚未还没有完全认识到，公平的感觉是怎么产生的，但是，在管理工作，从大的决策安排、晋升安排中，一定要注意：你怎么做，才能够在组织创造出更多公平感。我希望学友在“木学室”上，也就是我们的学习小组里，提供一些带有细节的例子，大家一起分享讨论。

# 3、公平、公正、公开与薪酬评定

在我们生活中最大的事情，我想莫过于高考。高考、大众之所以会认为它公平，是因为公开。高考是在严格监督的环境下，凭借分数被高者选。用这种方式来选人，是不多不公平好。我们不是来选好人，但是，通过这种公开透明的考试方式，来选大学生，大家都是接受。所以我们一般讲，公平、公正和公开，这三者之间是有点联系的。**公正是目的，公平是过程，公开是结果**，而且是大家都能感受到的结果。

前一段时间，我去一个朋友那里，他们进行了工资改革。过去大家的工资都是透明的，但现在采用了一个新的薪酬体系来进行考核，工资定了一些过程和标准都是保密的，于是员工之间也不知道你挣多少钱我挣多少钱。我的朋友和我不落到人人都有公平感和薪酬感都不想到了。人都是有好奇心的，所以就私下打听同事的报酬，这也就发生了矛盾。我的朋友和我讲，凭什么坐在离我近的人收入就比我高，我真的很不知道他是怎么算的。总之，这种不公平的感觉让他觉得很不舒服。

为了解决这种不舒服的问题，很多企业也试着采用公开的方式创造公平感，就像高考一样。比如，在美国，有些人的老板公开公布了薪酬的算法，有的人走慢慢算，甚至把自己和别人的工资，无论考核公式还是薪酬全都公开了。甚至每个人的考核指标、业绩数字，以及怎么算出来薪酬总额，全部透明成透明的，那么在这种情况下，大家就不再关心别人的数字，注意力一下就转移到薪酬评定标准和工资付有度，它公开化之后连携了很多，引起了大量的投诉或咨询。显然，很多人认为自己在这家公司可以挣到很多的钱，也就能说原创输出好办法的人太多了。而现有的人员，也更关注了自己的业绩提升。
