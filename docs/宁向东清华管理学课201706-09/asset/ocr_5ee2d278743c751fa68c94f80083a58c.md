# 1、霍桑实验

为什么我会这么想？这来自于我的管理学常识。这个管理学常识叫做“霍桑实验”。“霍桑实验”是80年前在美国一个叫霍桑的工厂里所做的实验，主导人哈佛商学院的梅奥教授。你可能会问，这决定要研究80年的实验，因为在很多企业发展中出现的问题，比如员工跳楼，在管理学上都可以追溯到霍桑实验。

霍桑实验的背景，是当时人们讲的“科学管理”的大行其道。科学管理的发展，让人的地位受到了很大的忽视。在这种情况下，哈佛决定要研究人在社会中人的问题，这就有了霍桑实验。霍桑实验意义非常大，后来催生了一个人际关系学流派，这个学派在扩散之后，影响了整个管理学、心理学、社会学等很多学科的发展。

霍桑实验的内容很多，下面我就和你分享两点与今天话题有关的发现。

第一，就是企业内存在着非常复杂的人际关系，包括非正式的组织。这些关系和组织有独特的权力，这些关系最后会对企业的生产产生非常大的影响。

梅奥教授当时研究了一个接线台的工作问题。小组里有9名接线工、3名电工，电工是负责检修电路的，打下的，这12个人是一线的生产人员。此外，还有1名监工和2名质量检查员。

这些人中的权力最大？按照道理讲，权力最大的应该是监工，其次是检查员。但梅奥发现：真正在工地上起作用的是接线工，权力关系全是反的。这是为什么呢？因为接线工在生产过程中扮演了关键的角色，什么时候该透口气，该干了什么面子，全由接线工说了算。接线工就是通过决定这些工作之外的小事来显示他们的地位和优越感。

这一点，你可以将来说房子，可以亲自去看一下，说不定会有和梅奥教授一样的发现。那些在技术上真正有本事的人，在现场往往也更多的话语权。

梅奥也发现，中午到饭的时候总是吃饭，因为他们要轮流去打下手，有时他们总是像往常一样，按照指定时间乖乖地去拿食物。但梅奥工中午时，他们会去小卖部，或者到休息室。这正不是工人对组织的规定，所以工作中常常会受到小组的干扰。电工完工之前，会在完工的接线台上吐口水，而搬运工进的时候，电工之间便回心一笑。

梅奥还发现，在这个组织里，围绕着接线工这个核心的集团，还会成立一些小集团。成立小集团的目的是为了保卫大家的利益，共同抵抗组织的压力。加入小集团都有条件，首先不能表现得太突出，也不能太笨，因为太笨人家看不起你，稍微吸收你进入他们的非正式组织。
