# 管理学讲什么？

提到管理学，很多人很容易想到那些大名鼎鼎的商学院：想到那些穿西装、打领带的、皮鞋锃亮的教授；想到那些特别深刻的概念和原理。但我告诉你，西装革履只是管理学中的某一面，管理学还有另外一面，就是"T恤牛仔裤"。

你也许听过我对管理学的定义，管理学就是一种"破局"的智慧。我们的课，就从开始讲起。

管理学的鼻祖是一个叫泰勒（Frederick Winslow Taylor）的美国人，他就是专门"破局"的高手。他的个人经历就非常丰富，曾获得过全美球类赛的双料冠军，还是一名优秀的运动员高手。

但是你如果因此觉得泰勒是一个身体素质特别好的，那你就想错了，其实泰勒的身体素质很差，他从小就哮喘，估计也差不多到30岁，但在特殊情况下，却取得了特别好的成绩。

![](bbox=[0.1, 0.42, 0.9, 0.52])

那么什么是管理学的"破局"智慧呢？

在泰勒那个时代，整个大环境都面临着"大萧条"的危机。

![](bbox=[0.05, 0.6, 0.95, 0.7])

"局"是典型的中国文化中的概念，但我个人认为它更是独立于西方学术体系之外的概念。所谓的"局"，就是人和资源之间的关系。而资源，则是西方管理思维中的主要内容。

我今天的主题就是要想帮你建立起一个"局"的概念，为什么呢？因为所有的管理问题，都需要"破局而出"。
