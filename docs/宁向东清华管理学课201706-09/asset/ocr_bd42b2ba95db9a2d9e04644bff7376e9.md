# 051讲：组织承诺｜四种共同体

你好，欢迎来到《宁向东的清华管理新课》。

上一周，我们讲了团队的组建问题。这一周，我们讲团队建设。今天，我要给你介绍一个重要概念，组织承诺。然后，我向你介绍关于四种共同体的分类，我一般由此来判断团队的类型和性质。

# 1.组织承诺

我先提一些问题：当我加入到一个组织中，为什么要我和一群人组成一个团队？凭什么我要相信你？我们参加了一些团队建设活动，你觉得那些东西真的有效吗？很多团队，我们情感情地要要求在活动中去一些陌生的成员去合作，在团建活动中去参与一些我们之前并不喜欢的人发生了接触。你可能会问这些，我们真的在心底接受了吗？

这些问题，都和一个叫做“组织承诺”的概念有关。正是在对于组织的不同的承诺状态下，我们加入了不同类型的组织，并且态度不同的心态去参与所谓的“团队建设”。

组织承诺，简单地说，就是组的成员愿意把自己力量集中在组织愿意、给在关系上，是一个个体对于一个特定的组织接受、认同和投入的程度。成员对于组织在这个组织中，他会表现出一种对于组织存在这个组织中的强烈欲望，越是希望当一个组织的成员。

组织承诺这个概念，最早出现在上个世纪60年代的美国，那个时候的美洲社会，处于动荡和矛盾等相互交织的状态。越南战争和民权运动，让美国社会充满了骚动，校园里有各种示威活动，社会上也有各种罢工和游行。但是，和社会上的激进相比，美国的公司却出奇地平静，无论是白领员工，还是蓝领员工，在平静地工作。

一部分学者开始觉得公司员工相对稳定，很有研究者说，为什么工人们混的很好，却不是，而是有序地生活着呢？每天上班，很少靠上班时，按时上下班，去办公室，很多在到上班时来动都不去。后来，学者们想明白了，因为这些人是有组织的归属感，公司越大，越稳定，这些人的归属感越强，心越顺，同时，他们也表现出对组织更强烈的投入。也就是说越承诺越深。上面就是“组织承诺”这个概念的来源背景。

# 2.组织中的四种共同体

现在，回到我们今天的课程主题：团队建设。团队建设之后，你为什么要花力气去组建团队呢？说明确，是为了增加员工对于组织的承诺关系。不过，在具体讨论团队建设办法之前，我建议你了解一下共同体的概念。因为，在你的共同体里面，成员和组织的结合关系是不一样的。所以，建设的方法是同的。

第一种共同体，叫职业共同体。组织的大部分成员，加入的都是职业共同体。

在这个共同体状态下，员工主要是为了获得薪酬，工作的是为了养家糊口。在这个共同体，员工只能从他的岗位上进取得相应的收入。心里感受就是，只要薪水合适，他也不会离开。还会保留着一种经济交换的关系。他心理预期就是，向领导讨出一个非正式组织。他或者一个人说的从工中获取，会形成一个非正式的承诺关系，保持一定的安全感。他向领导和正式组织决定时间的时候，也倾向于从非正式组织获得同情和支持。非正式组织可能会成为一种隐形的权力力量。有打饭的，可能会有的，是领导会有的方式。否则团队建设的种种努力，都会是无用功，或者事倍功半。

比职业共同体更进一步的是，利益共同体。顾名思义，利益共同体是利益关系维系的。中国有句成语就叫做利结于财，状态。老板们也不少一句话：前财为人类，财聚人散。很多企业家都考虑让早中持股期员工持股，组织通过这样的方式激发管理层员工和企业的组织承诺。

前些年，我曾经为一家企业做了一段时间的咨询，老板先期到了一定的阶段，希望把企业的业务规模再上升到一个台阶，用一批职业经理人进来取代中元台。职业经理人都是挖来的，薪水都高，能力都比老板要强。如何写点这支团队就是老板进一步发展的难点了。这个公司有个上市为说事，其实是希望用一个远期的利益讲，团队用工具来大家的组织承诺，增加团队凝聚力。

但是，坦率地说，把一个团队的凝聚力完全建立在利益的基础上，这个组织未来一定会会大。如果有利益可以大发展的时候，团队的凝聚力瞬间就会消散。道理和利为，就是团队前成员的组织承诺，都是以利益为基础的。所以，很多成功的企业都是把利益共同体和事业共同体链接起来，作为团队建设的目标。

事业共同体，是第三种合作关系的类型。如果你不理解事业共同体的特征，看看身边年轻人组建的创业公司，有不少就是基于单纯的理念的。创业团队就是事业共同体。我去访问过一家清华学生的创业企业，几个员工都是寒舍家的儒子，一起赚钱来看，员工都是寒舍家的儒子，也会说起上些什么的，但他们更要把自己想做的产品做好，特别单纯。这就是最典型的事业共同体。
