# 宁向东

在结束我们的课程之前，让我给你们讲一段故事。1971年，有一位耶鲁大学的博士生奥尔德斯跑去找他的导师荷尔曼教授，给导师提了一个大难题，核心是：他没给导师一点小礼物。导师说，我们关系很好，熟记几年了，我们的研究也很顺利，可以独立做项目了，我的私交很多，关系也好，你还会有什么不满意呢？奥尔德斯说，我觉得和你一起做事学不到更多方法。现在，我不带你做，我觉得不好。导师说，好吧，我们一起玩吧。于是，他们又花了几年时间进行合作，共同建立了一套理论。这就是我所说的“工作特性理论”。

最后，总结一下今天的课：团队关系是一种员工之间的相互关系，但更加基本的，是员工和企业的关系。企业只有把员工作为资产，让员工体会出收入之外的工作价值，感受到他们真是有价值的资产，企业才会产生出生成企业外的竞争实力。也许你今天还不是领导，这里告诉你一句话，请你一定牢记住：当有一天你成为了领导，要把员工当作资产，而不仅仅是工具。

今天的课后，放了一篇宁高诗的旧文，我第一次看，非常感动，今天分享给你，请你认真思考一下。

# 推荐阅读

认识付洪炜是在一个很令人伤心的地方——医院的急诊观察室里。如果他不是这样，不可能很长时间我也不认识他，不仅仅是认识他时用什么模样，更不会认识他的内心是什么样子。付洪炜是华润集团万家超市的一名普通员工，负责流转资产的编订和定价，他几个月前才加入外资企业加入华润集团，可很不幸，他在浙江出差途中出了车祸，受了重伤，我刚好在杭州，去医院时他，认识了一家小医院的急诊观察室里认识付洪炜。

去医院的途中，同事告诉我，付洪炜两天前受伤，眼睛有失明的危险，家属也来了。我想想，三十刚出头的小伙子，遇上这样的事情，心情一定很差，也许会发生一些事情，我一定要好好劝解他一下，如果有什么要求，我也尽量答应。

见到付洪炜，他正躺在床上，头上裹满了纱布。我握着他的手说：“洪炜，公司没有照顾好你，让我说了句。”他希望能说：“哎哟，心总，您怎么也来了，惊动了这么多人，真的很对不起。”他竟对我捏着握手，很有力，我边说了些什么也不记得了，可付洪炜说的每句话一句话我几乎都记得，因为他的谈话让我回味了很久，让我感受到了一个透明、高尚的灵魂。

付洪炜说：“我刚开始工作，还没给公司做什么贡献，就给我们公司添了这么多麻烦，真的很对不起。”“我受伤后，公司这么多家照看我，这么多领导来看我，我无以为报，只能说好全力做好工作来报答公司。”他还说，“我很快会好的，用不了多久，我就可以工作。”心总，你放心，我知道我眼睛有问题。现在看来我右眼问题不大，左眼有问题。没关系，我一只眼也可以工作，也可以写字。”

从医院出来，同事告诉我，付洪炜是在凌晨的车祸中，在去临去邻县一家新超市开业的路上。我们赶赴到这家医院时是早晨，第二天醒来，还没说几句话，他就问，我们那家超市当天开业好不好。这不是电影里的英雄故事，这是真事。

我们现在也不知道人品格是先天然形成的还是后天养成的，但人和人一定是不同的。在和付洪炜有较短的接触中，我感受到了他品格中的乐观、坚强、乐观和高尚。特别是人在遇到挫折时，这些品格不易显示：付洪炜不是华润集团最出色的员工，他才华进入华润集团几个月，然而就是时间再短，华润集团也没有这么大本事让一个人具有这些品格，但这个新人让能让华润集团体会的却很多。

我本来不想写付洪炜的事，虽然他给我很多的思考，但我觉得有些忌讳，可有一件事改变了我想法，这就是最近收到付洪炜父亲的两次来信，这位七十多岁老人的信再一次让我的心灵受到震撼。

老人说，小儿受伤，公司这么关怀，我全家万分感谢，我全家谢谢大家了。我儿刚到右眼单位，还没有什么贡献，就造成麻烦，只能以后更努力地卖力工作来报答公司。国有国法，家有家规，公司有规章，如果向公司提不合理的要求，请公司以我老信为据来拒绝。

老人说，千万不容易难司机，他已经很自责了，我相信这位司机不但会成为一个好司机，也会成为一个更好的有用之才。

真是有其父必有其子，老人的话与付洪炜的话如出一辙，也更多了一些温和和善良，老人的第二封信让我知道他是多么爱他的儿子，宁愿牺牲自己。

老人说，付洪炜女儿从他手上拿到眼球可以治付洪炜的眼眼，他想把自己左眼的球给妹妹。他说这样时间短，花费也小，父子同命，排异性小。为了说服大家同意和证明自己“不需要”左眼球，老人说，我写给我的这封信就是盖住左眼写的。

我到现在也不知道是什么造就了这样一对父子，我也知道付老先生从事的是什么职业，是怎样培养、教育儿子的高尚、善良，但是人心在父子身上表现得这样淋漓尽致，我只知道他们是好人，我在心里向他们敬礼。
