# 第 66 课：感受演讲

# 如何分享参加培训学习后的感受

我谈谈对一诺老师课程四个感受，分别是理、开、悟、静。

# 第一个感受：理

这个课程帮我理清了生活和工作上的问题，以及问题出现的原因是什么。让我有了一个很好的思路，让我找到了方向。

# 第二个感受：开

在课程里我们一起跳、一起闹、一起笑、一起哭，分享彼此藏在心中的故事。

# 第三个感受：悟

在上课的时候我一边听一边想着自己的生活和工作，会有很多新的突破性想法蹦出来，我感觉 3 天的课程就是一个开悟的过程。

# 第四个感受：静

在课程里我经历了努力、热闹、竞争、冲突之后，又重新回归到平静，更重要的是课程让我原来浮躁的心也变得宁静了。
