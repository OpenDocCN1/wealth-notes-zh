# 第 18 课：恐惧原因 5

# 放不下面子是影响演说家的最大因素

多数演说家在初登舞台的时候都会放不下面子，害怕自己在公共场合犯错，害怕观众会嘲笑自己。

一诺老师发现，放不下面子是影响演说家演说效果的最大因素，也是限制销讲能量场的负面能量。

![](bbox=[0.14, 0.4, 0.89, 0.54])

因为觉得自己长得不好看、气场不够强大、语言不够流畅、声音不够洪亮等，所以才会放不下面子。

而这些让人放不下面子的因素，归根到底就是对自己不够自信。因此想要放得开，就必须让自己变得更加自信。

但是自信并不是决定“放得下面子”的全部因素，他人对演说家负面的评价可能也会让部分演说家产生“放不下”的负面能量。
