# 第65课：年会演说

如何在企业年会做简短发言

在这里我要表达我的三个感谢：

# 第一个感谢：感谢每一位员工

正是因为在场所有朋友的不懈拼搏以及努力，我们才能创造这么辉煌的成绩。感谢你们！

# 第二个感谢：感谢每一位客户

从我们企业的生存发展，到我们的工资收入，再到我们能力的提升，都是客户给我们的。从一直以来的信任，无条件地支持，到如今的互助共赢，变成紧密的合作伙伴，每一位客户都是最好的见证者。感谢各位！

# 第三个感谢：感谢每一位竞争对手

百事可乐与可口可乐因为竞争而把可乐卖到全世界，肯德基与麦当劳相互竞争才让全世界吃上汉堡和炸鸡。

没有我们的竞争对手施加的压力，我们也不会进步这么快，所以在这里我们也要以掌声感谢他们！
