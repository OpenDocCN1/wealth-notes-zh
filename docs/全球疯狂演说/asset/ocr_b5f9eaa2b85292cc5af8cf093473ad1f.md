# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两!

一个事业部的一名姓高的总经理与他不相伯仲。

他们平日里也英雄相惜，相互欣赏。

唯一不同的是，高总的演说能力要比吕总好很多。

在一次公司的年度汇报会上，吕总先上去做他们事业部的年度总结，由于疏于准备，演说的效果一般。

紧接着轮到高总发言，他说得洋洋洒洒，获得满堂喝彩。

两人一对比，立分高低，吕总在下面听着特别难受。

从那天开始，吕总心里就对高总产生了恐惧，每一次见到他都很恐惧，需要上台发言的时候这种情况更加严重。

所以，吕总想来一诺老师这里看看有没有解决的办法。
