# 从小白到魔法演讲家之路《全球痴狂演说》 麦克风一响,黄金万两!

从 1 楼一口气爬到 13 楼，把一诺老师累得直喘气，到分享开始时还没完全平复。

但一件很意外的事情发生了，一诺老师的那些身体发抖、头脑一片空白的症状没有了，而且那天晚上 一诺老师演说的状态非常好，一诺老师自己都没有料到，为什么会这样呢？

经过后来的研究，一诺老师发现，由于一口气爬了 13 楼，运动量大，呼吸加快，血液循环加快，加速分解了因为紧张而分泌的那些激素，所以一诺老师自然就没有了紧张的症状。

![](bbox=[0.115, 0.455, 0.856, 0.597])

在后来的一次重要演说场合上，一诺老师同样运用了这个原理来缓解紧张，但那次一诺老师没有爬 13 楼，而是连续做了 50 个俯卧撑，发现效果也是一样的！于是 一诺老师就把这个方法总结出来了。

此外，听音乐、看一些激昂的电影片段也是种调整身体状态的方法，就看哪一种能对你的身体产生作用了。
