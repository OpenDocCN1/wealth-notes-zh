# 从小白到魔力演说家之路《全球疯狂演说》麦克风一响,黄金万两!

然而经验是经过漫长的时间积累获得的，没有人天生就是经验丰富的老手。

如果在舞台上因为经验的缺乏失败了一次、两次、三次，甚至更多次之后，就对演说产生恐惧，那么企业家也会在企业今后的运营中无法面对企业项目失败的挫折。

一诺老师认为，不能因为没有经验而害怕站在舞台上，害怕面对失败和挫折。

![](bbox=[0.115, 0.415, 0.856, 0.554])

所有的演说家都可以在失败的演说中获取经验，正如企业家同样可以在失败的项目中获取成功的经验一样。

一诺老师研究发现，只要能够不停地反复演说，再通过专业的培训加强自己的演说能力，就能够克服缺乏经验为演说带来的困扰。
