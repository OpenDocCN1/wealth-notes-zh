# 第 106 课：情感煽动

# 真感情胜过好文章

有一句话说得非常好：真感情就是好文章。

演说家要用真情实感来讲话，讲的是发自内心的想法。演说不仅仅是语言文字、声音语气、身体语言的沟通。

![](bbox=[0.12, 0.35, 0.86, 0.49])

很多人演说技巧一般，但情感充足，他的演说同样受欢迎。

一诺老师就见过很多这样的例子。撒贝宁主持过一档节目，叫《开讲啦》，请的都是些社会名人，包括企业家、明星、专家等。这个节目里的嘉宾讲述的自己的亲身经历，很多都很感人。
