# 演说时的四大要素

还记得我们念小学的时候，老师教我们的写日记的四要素吗？可能很多 人看到这里就会张嘴念出来了：时间、地点、人 物、事情。

四要素我们都背得出来，但你是否知道原因呢？

小学的老师教我们，有了时间、地点、人物、事情，才算 是一篇完整的日记。那演说的过程为什么要 有这些？
