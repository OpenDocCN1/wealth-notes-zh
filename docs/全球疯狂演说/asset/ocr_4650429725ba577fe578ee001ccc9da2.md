# 讲好故事的9个公式

将以下一诺老师教大家的9个小技巧融到演说的故事里：

+   ①选对题材：这个题材选得好不好？有没有更好的？
②要素交代：故事的四要素都是哪些？
③叙事方式：应该用哪种叙事方式讲这个故事更好？
④讲出节奏：哪些内容是故事的开端？发展？高潮？结局？应该用什么节奏表现？
⑤删减赘词：自己在讲这个故事时，可以减少哪些累赘词？
⑥情绪投入：讲述这个故事高潮部分用什么样的情绪？
⑦五觉魔法：能否用一诺老师的“五觉魔法”去表达一下故事中各角色的感受？
⑧细节刻画：还能对哪些细节进行一些刻画？
⑨故事总结：讲完这个故事后怎么紧扣自己想要表达的观点来进行总结？
