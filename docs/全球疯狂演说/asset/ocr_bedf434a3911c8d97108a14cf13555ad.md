# 第28课：激励团队3

# 将自己的梦想注入团队

企业家不仅可以通过演说表达对团队的信任，而且可以利用自己的演说将自己的梦想注入到团队中。

梦想是个⼈获得成功的基⽶，同时梦想也是团队取得胜利基⽶。但是，在不成熟的团队中，每⼀个⼈往往都有不同的梦想，而企业家作为团队的核⼼就必须将自己的梦想注入团队之中，并给予团队实现梦想的希望。

一诺老师认为，你要让员工听你的，就要满足员工的需求，让员工看到跟着你有未来、有希望。

> 腾讯的董事会主席马化腾曾在给员工的信中写道：“也许今天我还不能向大家断言会有哪些变化，但我们将尝试在腾讯未来的发展中注入更多开放、分享的元素。”
