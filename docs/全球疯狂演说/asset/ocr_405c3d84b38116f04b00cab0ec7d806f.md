# 第 43 课：积累素材

# 有助于演说的诗文素材

洛阳亲友如相问，一片冰心在玉壶。——王昌龄《芙蓉楼送辛渐》

粉身碎骨全不怕，要留清白在人间。——于谦《咏石灰》

力拔山兮气盖世。——项羽《垓下歌》

大风起兮云飞扬，威加海内兮归故乡。安得猛士兮守四方！——刘邦《大风歌》

老骥伏枥，志在千里，烈士暮年，壮心不已。——曹操《龟虽寿》

丈夫志四海，万里犹比邻。——曹植《赠白马王彪》

精卫衔微木，将以填沧海。刑天舞干戚，猛志固常在。——陶渊明《读山海经。其十》

天生我材必有用，千金散尽还复来。——李白《将进酒》

仰天大笑出门去，我辈岂是蓬蒿人。——李白《南陵别儿童入京》

我自横刀向天笑，去留肝胆两昆仑。——谭嗣同《绝命诗》
