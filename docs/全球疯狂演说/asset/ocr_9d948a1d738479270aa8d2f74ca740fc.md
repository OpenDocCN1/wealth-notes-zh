# 第34课：利他使命

# 我的梦想就是成就你们的梦想

有很多人问我说：“一诺老师，我什么时候才能像您那样成为多家企业的顾问、拥有多家公司的股份、可以在家写书、可以到全世界演讲、接受万人的崇拜、拥有五千万粉丝！”

一诺老师的回答总是一句话：

![](bbox=[0.14, 0.4, 0.89, 0.54])

古人云：书中自有黄金屋，书中自有颜如玉！

很多人为了改变命运，只好闷头读书，结果买了一大堆书回来，希望可以通过读书改变命运。结果呢？越看越糊涂，书中不仅没有黄金屋和颜如玉，而且最后自己变成了书呆子！

为什么会这样呢？

各位，你用脚趾头都想得出来，因为这个写书的人他自己本身是书呆子，所以写出来的书，除了“之乎者也”，就是叽叽
