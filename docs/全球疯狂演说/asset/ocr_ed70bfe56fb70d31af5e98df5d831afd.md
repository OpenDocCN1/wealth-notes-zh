# 利用媒体和新闻进行权威性

广州日报讯(全媒体记者刘冉冉)广州市交通规划研究院，

摩拜单车近日基于云平台智能模型运算和近10万份实地调查问卷，联合发布了《2017年华南区共享单车出行报告》。

报告显示，广州深夜0时至5时，写字楼周边成为共享单车出行热点区域，互联网行业、政府机关、金融行业共同包揽加班热门行业前三名。

![](bbox=[0.142, 0.486, 0.884, 0.622])

珠江新城是共享单车旺地，在深夜0时至5时，广州国际金融中心、高德置地广场、富力中心、珠江规划大厦、越秀金融大厦、保利中心、中泰国际、维多利亚广场、粤财大厦、达标国际大厦等十大商务区或商圈周边仍然有较多用户骑行共享单车，它们成为加班热门地区前10名。
