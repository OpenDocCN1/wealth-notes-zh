# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两！

一诺老师说:“那你在介绍这个人的时候,哪些才是重点?”

有同学回答:“对听众的好处才是重点。”

一诺老师说:“要挑什么内容讲,就要看看这个内容对实现让别人请他吃饭的这个目标有没有帮助,对实现目标有帮助的,就是重点,对实现目标没有帮助的,就不是重点。”

![](bbox=[0.12, 0.332, 0.86, 0.47])

请大家记住——

对实现演说目标没有用的就不是重点。

对实现演说目标有帮助的就是重点。

对实现演说目标有很大帮助的就是重点中的重点。

不是重点的内容都是废话,全部删掉。

所以你在准备演说内容的时候,一定要清楚你演说的目的是什么。
