# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两!

下三句话，这3句话其实就是演说动力最重要的组成部分。曾经一诺老师自己写下的3句话是这样的，供大家参考——

+   (1) 这个世界上不是你去影响别人就是别人来影响你。

+   (2) 你配拥有最美好的一切，包括一诺老师的知识！

+   (3) 众生愚昧等着我去拯救他们！

如果非得在其中挑一句，一诺老师会选：

![](bbox=[0.115, 0.37, 0.86, 0.51])

各位，你也要写下3句话，并挑选一句你认为能够给你最强动力的作为你的演说信念。当你的信念足够强大时，你会发现，你也想“向天再借五百年”。

《聊斋志异》作者蒲松龄先生就喜欢用一副对联勉励自己：

有志者，事竟成，破釜沉舟，百二秦关终属楚；

苦心人，天不负，卧薪尝胆，三千越甲可吞吴。
