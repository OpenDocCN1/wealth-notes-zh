# 第 37 课：突破紧张 2

# 第二招：熟悉场景,熟悉听众

为什么我们对某些事情的把握度会不够高？一诺老师发现，其中一个原因是不够熟悉。演说的场景对于很多人来说都是不熟悉的，不熟悉这种一对多的表达方式，不熟悉讲台，不熟悉那么多双眼睛一起看着自己。

一诺老师相信很多人第一次对众人唱歌都会紧张的，这是同样的道理。那我们如何解决呢？方法就是去熟悉这种场景。

![](bbox=[0.15, 0.486, 0.885, 0.622])

2005 年 6 月，一诺老师一位亲传弟子，年纪比较大了，他来上课的时候已经 63 岁了。

这位老先生是一家企业的董事长，他的企业是生产食品调料的，他也是当时某食品行业协会的会长。虽然已经 63 岁，但他并没有退休，而是继续经营着自己的企业。
