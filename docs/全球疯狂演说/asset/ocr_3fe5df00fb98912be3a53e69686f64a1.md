# 破框法：冲破恐惧的包围圈

任何人在面对困境和压力的时候都会产生巨大的恐惧感，

信念薄弱的人就会无法面对当前的困境和压力。

一诺老师认为，当眼前的困境和压力大于信念的时候，就要尝试使用“破框法”，打破“应该如此”“托付心态”“没有办法”这三个局限信念系统的思维，进而让自己的信念能够进一步突破现有的层次范围。
