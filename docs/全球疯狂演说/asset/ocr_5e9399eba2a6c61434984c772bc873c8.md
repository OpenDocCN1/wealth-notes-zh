# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两!

有了基本功，再去学习商业演说的秘诀时，这些秘诀才会产生作用。直接讲秘诀的话，普通人是驾驭不了的。

![](bbox=[0.118, 0.205, 0.855, 0.345])

小米的创始人雷军先生，在每一次小米的发布会上都会亲自展示产品。他们的团队做了精心的准备，PPT 也做得很漂亮。

但现场的气氛与演说的结果，跟乔布斯先生的发布会比起来还是有些差异。

在一诺老师看来，除了产品和演说策划团队的差异以外，雷军先生还可以通过提升演说的功力来增强发布会的整体效果。

一诺老师可以简单概括为两个方面：

一是乔布斯先生演说时的声音、语气、语调有种魔力，总 دهید能带动听众的情绪；

二是乔布斯先生的 PPT 里面，每一个动画、每一个设计细节都能跟他的演说内容很好地结合，节奏感很强。

在这些方面，雷军先生还有进一步提升的空间。
