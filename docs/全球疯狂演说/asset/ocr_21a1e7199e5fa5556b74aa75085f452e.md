# 第19课：恐惧原因6

# 准备不够充分是恐惧的原因之一

内容准备得是否充分，与演说自身的能力和经验有很大的关系。有的演说家，虽然会准备许多有用的内容，甚至会准备上百页的演说稿，但是还是会在演说中失败。

一诺老师发现，能力只能决定演说家为观众展示的内容，以及演说家能够为观众带来的利益。然而多数有能力的演说家却不能真正用自己的信念影响观众，也无法正确面对演说过程中出现的各种“意外”。

有经验的演说家，能够凭借自己的经验来应对舞台上的意外，甚至为可能出现的意外提前做准备，进而使自己的演说影响更多的人机会永远会留给有准备的人，演说也同样如此。
