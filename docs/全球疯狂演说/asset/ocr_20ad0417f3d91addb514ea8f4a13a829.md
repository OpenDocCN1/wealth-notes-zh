# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一喊,黄金万两!

第一位同学说：“海边很舒服，一望无际，眼中全是大海。”

第二位同学说：“海水很蓝，风吹着很舒服。”

学习过一诺老师《演讲的最高境界》课程的同学会这么讲述：“当我来到海边，远远看过去是一条海平线。有几座绿色的海岛屹立在蓝色的海水上面，几条渔船正在航行。蔚蓝的天空飘着几片白云，阳光明媚，海水一浪接一浪地冲上金黄色的沙滩，泛起层层白色的浪花。沙滩上面有很多脚印，一群又一群的游人穿着泳衣在海边嬉戏。偶尔我们会听到海鸥的叫声、轮船的鸣笛声，但更多的是游人的喧闹声，此起彼伏。我们走在沙滩上，软绵绵的。海水有点凉，但并不冰冷，跳下去游一段，可以尝到海水的咸味。走回岸上，感受带着大海味道的风。空气很清新，太阳晒在身上也很温暖。这，就是海边。”
