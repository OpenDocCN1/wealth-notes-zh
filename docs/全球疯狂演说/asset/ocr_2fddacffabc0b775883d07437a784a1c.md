# 第 14 课：恐惧原因 1

# 不自信是恐惧演讲的根源

不自信是恐惧演讲的根源，同时不自信也是人性的弱点。

很少有人天生就能够自信满满地做所有的事情，那些自信满满的人也时常会被社会上的挫折打败，同样变得不自信。

这就是人性的弱点之一，没有人能够逃避这样的弱点对自己产生的影响，但是所有人都有机会去改变这种弱点。而改变“不自信”这一弱点的首要目标，就是让自己变得“自信”。

刘总作为一名专业净水设备的经营与销售的企业老板，对自己非常不自信。特别是 2003 年他在一场招商会上的失败演讲，彻底把他打入了恐惧的深渊。

后来，刘总经人辗转介绍听了一诺老师的《演讲的最高境界》课程，学会了正确的演讲方式，从此打开了成功的大门。
