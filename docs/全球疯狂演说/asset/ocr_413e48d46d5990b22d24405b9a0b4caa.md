# 第一招：转换词汇,转换能量

一诺老师曾经在课堂上讲过一个笑话：一个即将登台演讲的人，因为非常害怕非常紧张，他在上台之前就拼命对自己念叨：“我不紧张，我不紧张，不紧张，一点都不紧张。”

各位觉得这个念叨起到作用了吗？当然没有！

他在上台后进行自我介绍时就说成了：“大家好，我的名字叫不紧张。”

越说不紧张反而越紧张，这是什么情况？

日本学者江本胜写过一本书，叫作《水知道答案》，里面有一种观点：水能够感知语言。如果经常对水说正面的、积极的、充满爱的词语，这些水在结晶之后生成的结晶体就会非常漂亮。
