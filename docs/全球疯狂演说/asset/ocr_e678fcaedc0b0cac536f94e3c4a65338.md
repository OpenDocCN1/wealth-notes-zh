# 从小白到魔力演讲家之路《全球疯狂演说》 麦克风一响,黄金万两!

开始就是教演说课程的，其实不然，卡耐基先生最早教的其实是一门培养自信的心理学课程，只是通过演说这种形式来增强学员的自信心而已。

一个人的自信心得到增强，需要有什么样的环境呢？

其实一诺老师的《演讲的最高境界》就是最好的一个培养自信的环境，这里充满了关注、微笑、点头、掌声还有鼓励的眼神，同学们彼此之间不会去批评对方这讲得不好，那讲得不好，而是用心去发现每一个人身上的优点，由衷地去赞美，并诚挚地提出帮助别人去做得更好的建议。

一诺老师的一位朋友——伦敦卡耐基分校的创始人乔治老师，把这个原理叫作“优势加强法”。
