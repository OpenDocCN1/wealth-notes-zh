# 第30课：催眠客户1

# 如何用演说削弱客户原有的信念

改变客户的信念不一定非要推翻客户之前的信念。通过演说的手段，削弱客户原有的信念也是改变客户信念的方式之一。

对于销售人员来说，当遇到对品牌和产品不够满意的客户时，很多人在第一时间想到改变客户的信念。

实际上，人的信念并没有那么容易改变。

除非能够用现实中真实可靠的证据，来证明客户原有的信念是“错误”的，否则在一般情况下，很少有客户会在与销售人员短暂的谈论中彻底颠覆自己的观念。

![](bbox=[0.145, 0.57, 0.885, 0.705])

但是削弱客户原有的信念则简单得多，通过演说中简单的观点、简单的例子，只要能够击中客户信念中脆弱的部分，就能够在一定程度上动摇客户原有的信念。
