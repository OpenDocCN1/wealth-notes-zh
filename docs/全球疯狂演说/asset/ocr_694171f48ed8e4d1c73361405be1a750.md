# 从小白到魔力演讲家之路《全球疯狂演讲》 麦克风一响,黄金万两!

乔布斯在每次发布会之前，都会找些朋友试着讲几遍，让自己熟练掌握内容。

2017年网上也出现过美国总统特朗普先生在车里面练习演讲的照片与小视频。

我们会发现，他们最重视的事情都是练习。

有的讲师，为了讲好一次演讲。二个句子，每一个词语，每一个停顿，每一个手势都要认真琢磨，训练到极致。这是一种工匠精神，值得学习。

一诺老师的一个亲传弟子是教练技术的讲师，他告诉一诺老师，教练技术的导师训练是先要把讲稿的一字一句全部背下来的，这样才能够保证内容不会出现大偏差。
