# 故事讲述举例：

有一位很年轻的特级教师到异地讲课，在他授课的阶梯教室里坐满了上课的学生以及慕名而来的想要观摩的教师，大家都想一睹这位教师的风采。

上课铃响起，从前排站起一位相貌平平、腋下夹着讲义的小个子教师，他快步走向讲台，远没有人们想象中的那么儒雅倜傥，台下响起一阵嘘声。

年轻人站在讲台上，平和友善地环顾有些躁动的人群，宣布“上课”，全体学生起立，但有一些前来观摩的教师斜着眼坐在座位上一动不动。年轻人示意大家坐下。

当他正要放下讲义时，发现讲桌上有一层淡淡的粉笔灰尘，他迅速走下讲台，背对学生，面朝黑板，用嘴轻轻地向前方吹
