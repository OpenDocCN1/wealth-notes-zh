# 第64课：产品演说

# 如何做简短的产品介绍

记得乔布斯演说时这样说：iPhone 第一代有三大功能……

第一大功能： iPod 功能

这款新手机跟 iPod 一样，可存放 2500-10000 首 mp3 格式的歌曲，可以作为移动硬盘使用，可以显示联系人、日历和任务，也可以用于阅读电子书等。

第二大功能： 手机功能

这款手机具备一般手机的所有功能，包括最基本的拨打、接听电话，收发短信，以及 PIM(个人信息管理)，日程記事，任务安排，日历等。

第三大功能： 网络功能

这款新手机可以上网，也就是说，你可以把 iPhone 当作一台微型手提电脑，在任何时间、任何地点都能连接上网络，处理你的个人业务。
