# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两!

刘总曾说：“我的进步非常迅速,很快就突破演说的恐惧。上台讲话不再害怕，无论是公司开会还是对外招商，我都能游刃有余。”

2005 年刘总再次做了一场净水设备招商会，当时现场成交金额高达 1655 万元，6 个月时间公司实现 1 亿营收，这些就是一诺老师课程带给他的改变。

刘总从一诺老师《演说的最高境界》课程中获得了自信，因此他克服了演说恐惧，进而让自己和企业共同得到了升华。无论对个人来说还是对企业来说，自信都非常重要。

因此，自信能够促进成功，促进自我发展，帮助个人避免许多负面能量的干扰。同时，自信也是一种积极信念。

一诺老师认为，无论是在工作上、人际交往中，还是演说的过程中，自信这种信念，一直都是支撑着企业家完成自己梦想的重要能量来源之一。
