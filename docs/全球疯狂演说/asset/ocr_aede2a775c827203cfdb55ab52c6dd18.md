# 演说恐惧的原因及自我诊断

英国的科学家曾经做过一个实验，他们对 2000 位读者做了一个调查，题目是：你最害怕什么？

30%的人回答最害怕的是死亡，排名第二。

15%的人回答最害怕的是贫穷，排名第三。

12%的人回答最害怕的是疾病，排名第四。

而排名第一的，居然是演说，高达 35%的人选择了这一项！

![](bbox=[0.14, 0.48, 0.88, 0.62])

你会不会觉得这是一个不可思议的数据？

是的，没错，就是演说。

按照这个数据，是不是演说比死亡还可怕？

这个时候大家都会笑，演说怎么可能比死亡还可怕呢？

但是演说确实排在第一位，且至今依然如此。
