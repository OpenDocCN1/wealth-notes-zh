# 第85课：故事总结

# 用故事直接号召和情感升华

就好像足球场上，防守、运球、过人、传球，这些是故事的过程，而最后的射门就是故事的总结。

防守、运球、过人、传球都是为后面的射门服务的。

也就是说，我们故事的情节、细节，重点讲哪些部分，是根据我们最后的总结而设定的。

![](img/3217947958f819d87eca9055b3404772_245_0.png)

我们讲一个去海边玩的故事，是为了告诉大家海边很好玩，号召大家一起去玩；讲一个打针的故事，是为了告诉大家要注意保重身体，不要感冒了。

讲故事是为了更好地影响别人，整个故事的过程都是在酝酿，影响力在最后的总结上爆发出来。

# 第88课：声音训练2

# 共鸣系统是声音基本功训练

共鸣系统是我们对声音的修饰，使声音可以变化多样。

要训练好声音，就需要先练习一些基本功。

![](img/3217947958f819d87eca9055b3404772_253_0.png)

# (1) 练呼——胸腹式联合呼吸法

对于发声来说最好的呼吸方式就是胸腹式联合呼吸。如何做到呢？胸腹式联合呼吸操纵气息的部位在胸部和腹部的连接处，即横膈膜。吸气时，胸部放松，腰部周围明显扩张，两肺底部的横膈膜向下运动，气息自然充分地吸入身体。呼气时，胸腔扩张挺起，小腹向内向上收缩，横膈膜向上运动，将气息由肺部挤出，完成呼吸过程。如此循环，养成习惯。

# (2) 练气息——数数字法

数数字法就是深吸一口气，然后慢慢吐气，同时从 1 开始

数数字，数到胸腔、小腹的气息已经完全用光，不能再数下去了再吸第二口气。这样可以锻炼我们的气息储存能力。

# 从小白到魔力演讲家之路《全球痴狂演说》麦克风一响,黄金万两!

# (3)练舌头——舌部操

第一个动作: 用舌头顶住口腔右内侧, 压着口腔依次往下、往左、往上、往右, 是顶着口腔内壁顺时针转动, 转 10 圈。

第二个动作: 用舌头顶住口腔左内侧, 压着口腔依次往下、往右、往上、往左, 也就是顶着口腔内壁逆时针转动, 转 10 圈。

第三个动作: 舌头顶着上颚最近靠喉咙的位置, 沿着上颚向外推出, 直到碰到牙齿, 练 10 次。

第四个动作: 打开嘴巴, 舌头往外伸, 再收回来, 重复 10 次。

这四个动作可以训练舌头的灵活性。

![](img/3217947958f819d87eca9055b3404772_254_0.png)

# (4)练双唇——唇部操

第一个动作: 揣着嘴唇往外, 收进来时把嘴唇含在嘴里面,

练10次。

第二个动作：撅着嘴唇往左、往右、往上、往下，练10次。

这个方法可以训练唇部肌肉的灵活度。

# (5) 练磁性——气泡音

口腔打开，放松喉咙，让气息自然地从喉咙出来，轻轻冲击声带，发出像泡声一样的聲音。这个训练方法可以放松声带，提高声音的磁性

# (6) 练音域“吖”声练习法

嘴里发出“吖”字的声音，不间断，音调慢慢升高，再慢慢降低。这个方法可以拓宽音域。

![](img/3217947958f819d87eca9055b3404772_255_0.png)

# 第97课：专业台风

# 关于站姿的注意事项

演说家给听众留下的第一印象是非常关键的。如果你一走上来就不像个专业的人，或者不像个有水平的人，自然很多人就不想听你讲下去了。那么，怎么让自己成为一个专业的人呢？

加州大学有一位教授叫海律比，他花了10年的时间去研究人与人之间的沟通，结果他发现，决定一个人对另外一个人的印象的，7%是这个人说过的内容，38%是这个人说话时的语气语调，55%是这个人的肢体语言、外在形象。

![](img/3217947958f819d87eca9055b3404772_266_0.png)

也就是说，你今天认识某个人，一个月后可能已经忘记了他聊过什么但他形象好不好，跟你聊天的感觉好不好，你还会有印象如何打造一个好的形象，我们从以下6个方面谈起。

# 第98课：站姿训练

从你的站姿就知道你情商高低

男士站姿的要求：双腿微微分开，脚尖向前或者稍微有点外八字，两只脚分开的幅度不超过肩膀的宽度。两只手轻轻握拳放在胃前(或者右手轻轻握着，左手轻轻抓着右手的手背)。

女士站姿的要求：双脚并拢(站定不动的时候也可以双脚一前一后呈丁字步)，双手虎口相交放在小腹上。

# 关于站姿的注意事项：

+   ① 头、挺胸、拉直脊背。
② 身体保持平稳与舒适。
③ 不要背对听众。
④ 不要把身体靠在桌子上。

+   ⑤ 不要抖腿。
⑥ 不要重心向一边倾倒。
⑦ 不要踮脚。

# 第99课：走姿训练

看你走路就知道你是否稳重

+   ① 用踱步的方式来行走。
② 走的时候步伐要稳。
③ 往回走的时候用退步，尽量不要背对听众。
④ 不宜太频繁地走动。
⑤ 走动速度不能太快。
⑥ 走动时也要抬头、挺胸、拉直脊椎。
⑦ 停下的位置要确保让所有听众都能看到你。
