# 第77课：选对题材

选择对自己表达观点有较大作用的题材

在演说中，各种故事题材都要有，这样演说的内容才不乏味。我们在选择题材的时候，可以选择一些经典的、容易理解的、能引发共鸣感的、特别的、震撼的、能引发情绪的题材，但最重要的是——

![](bbox=[0.12, 0.39, 0.86, 0.53])

别人的故事、书里的故事、自己的亲身经历这三种故事类型中，最有说服力跟影响力的肯定是自己的亲身经历。

有的人觉得自己没什么故事可讲，其实不然。
