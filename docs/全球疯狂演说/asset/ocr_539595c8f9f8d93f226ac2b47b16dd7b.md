# 第107课：实战演练

# 从菜鸟到高手的唯一距离

在一诺老师的演说课堂上，有一个对决环节，每个人都要用我们在课堂里教的方法上台去讲自己的产品，给每一个人的时间是3分钟。

有部分同学时间把控能力很弱，或是2分钟不到就讲完了，或是3分钟到了才讲到一半，或是内容跟时间的比例很不匹配。

每当见到这种情况，我就会问他们，上台之前自己练习了几次？他们的回答基本上都是练习不超过2次。

因为只要练习过2次以上，如果存在时间把控问题的话，自己肯定可以发现，然后及时做出调整。当然，更让一诺老师痛心的是，很多演说家没有练习过就上台演说了，结果讲得很糟糕，浪费了获得融资的大好机会。
