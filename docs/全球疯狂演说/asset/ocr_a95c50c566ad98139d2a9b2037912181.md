# 四种勾魂的叙事方式

在演说的时候，讲故事的方式可以分为直叙式讲故事、对比式讲故事、倒叙式讲故事、悬念式讲故事。

# ①直叙式讲故事

这是最常见的讲故事的手法，按照时间顺序或者剧情发展的逻辑顺序讲故事。比如曾经创下中国电影界最高票房纪录的《美人鱼》，就是典型的按照时间顺序来讲故事。
