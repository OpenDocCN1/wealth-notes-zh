# 从小白到魔力演讲家之路《全球疯狂演讲》 麦克风一响,黄金万两!

一起去吃夜宵。

期间他问了一个问题:“请问一诺老师,我们的年纪差不多,课堂里面我把您当老师,但是为什么现在在吃夜宵,我还是会把你当老师呢?我们年纪相仿,不是应该有一种同龄朋友的感觉吗?”听完这番话一诺老师陷入了思考:是不是一诺老师的讲课方式会让学员对一诺老师有一种距离感?从那天之后,一诺老师就开始调整自己。

一诺老师发现因为年龄差距与阅历的关系,一诺老师跟很多的企业主确实比较难沟通,话题聊不上,聊天的方式对不上。

于是 一诺老师开始努力改善这个部分,慢慢地让自己成为一个能够跟他们聊得来,聊天方式也对得上的人。

在讲课过程中,一诺老师也刻意地把这种沟通的感觉融入,在课堂里面和学员“玩”到一块。慢慢地,在讲课过程中一诺老师就有跟学员融合在一起的感觉了。
