# 第17课：恐惧原因4

# 失败的精力容易让人产生恐惧

不是所有人都可以像那样被轰下台9次、3次被砸场子、

共失败700多次之后，还能坚持不懈地坚持自己的演说之路。

大多数人在经历过两三次失败之后，基本上都会选择放弃。

虽然失败的经历会产生恐惧心理，是人类的正常心态。但是：

![](bbox=[0.12, 0.41, 0.86, 0.55])

演说中总会出现意外，可能会忘词、说错话、被观众嘲笑，

还可能像一诺老师第一次演说那样被主持人追着赶下台。

虽然对正常人来说，这些当众失败的尴尬场景都不想再经历第二次，但是身为一名演说家就必须强迫自己去面对这样的场面，并且要尝试主动对自己发起一次又一次的挑战，进而克服恐惧失败的心理。
