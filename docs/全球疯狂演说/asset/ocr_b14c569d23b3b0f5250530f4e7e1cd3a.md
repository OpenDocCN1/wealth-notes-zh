# 第01课：改变世界

如果你不演讲,谁知道你要改变世界

乔布斯先生是一诺老师非常欣赏的企业家之一。

百事可乐前总裁约翰。斯卡利的市场经营能力闻名于世，

尤其是他在百事公司推广“the Pepsi Challenge”，这项计划

使得公司从主要竞争对手可口可乐那里获得了相当多市场份额。

1983年，乔布斯为了让斯卡利加入苹果，说出了这句著名

的话：“你是想卖一辈子糖水呢，还是跟我一起改变世界？”

![](bbox=[0.147, 0.488, 0.884, 0.623])

这句极具煽动性的话至今仍被人津津乐道。

斯卡利果然被打动了，而后面发生的那些戏剧性的故事，

也造就了后来的乔布斯和苹果。

乔布斯通过一次又一次的产品演说，奠定了苹果在全球手

机企业中的霸主地位。
