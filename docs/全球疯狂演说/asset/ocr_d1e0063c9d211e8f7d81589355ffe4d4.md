# ③倒叙式讲故事

是指先讲故事的结局，再讲故事的经过，用结局或悬念来引起大家的兴趣。

《泰坦尼克号》用的就是这种手法。电影开篇先叙述大家去打捞“泰坦尼克号”，然后被年过九旬的女主角从电视里看到，于是这位女主角慢慢给大家讲述了几十年前发生在“泰坦尼克号”上面的事情。

# ④悬念式讲故事

悬念，即是挂念—悬挂起来，念念不忘。又称为“卖关子”。

通常是在文中设置一个个悬而未决的疑问，将这些疑问藏在叙述中，让听众去猜测，去关切，去担忧，使听众产生浓烈的兴趣和急切期盼的心理，在故事讲述中，逐步将这些“疑问”
