就会转移到游戏上面，对你的关注度自然就降低了。

随着游戏对听众情绪的带动，你对场面的把控就会越来越好，自然也就的就是不能太长，否则就喧宾夺主了。

# (2)提问让听众回答

刚上场的时候提出一个问题，找一位听众来回答。

当你的手势指向那位听众的时候，全场其他听众的目光也会会随着你的手势看向那一位听众，焦点就从你的身上转移到他的身上了。如果你觉得一个人回答还不够，那就请两个人或三个人。局面、时间自己能够把控住就可以了。

# (3)在投影仪上展示图片、视频、文字案例

在出场的时候对听众说“我们先来看一个案例”，然后展示图片、视频、文字案例，听众就会去看、去思考，焦点没有在你身上，你的压力就会减轻。
