# 从小白到魔力演说家之路《全球疯狂演说》麦克风一响,黄金万两!

很多人感到奇怪：为什么这么大年纪还来学演说？

因为他觉得演说一直是他的短板，并且长期困扰着他。

他是土生土长的广东人，每次上台发言之前，他都害怕自己不标准的普通话容易闹笑话，所以每次发言之前秘书都把稿子给他提前准备好，但他照着稿子念还是很紧张。

有一次下课以后他来请教一诺老师“一周后有一个行业论坛，要上台发言，请问一诺老师，如何才能解决紧张的问题？”

一诺老师给他进行了两次个人辅导，在帮助他把语气台风、手势各方面都训练好了后，一诺老师告诉他：“在论坛的前一天晚上，你去到第二天要举办论坛的那个酒店，舞台、音响、灯光、桌椅这些肯定都布置好了，你去熟悉一下那个场景，感觉一下，并找一些朋友在现场坐着听，你去讲台上练15遍。第二天正式上场的时候你就会很轻松了。”

他按照一诺老师的方法去做了。
