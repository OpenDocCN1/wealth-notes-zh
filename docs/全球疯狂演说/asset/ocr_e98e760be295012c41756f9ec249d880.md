# 从小白到魔力演说家之路《全球疯狂演说》 麦克风一响,黄金万两！

头发全白了！……

这就是养你 30 多年的妈妈……

如今静静地躺在那里，一动也不动！

仿佛睡着了一样，你把妈抱了起来，吓了一跳！不是太重了，而是太轻了！那一年，妈去了，永远地离开了你……

一转眼三年过去了，清明节那一天，下了好大的雨……

你跪在坟前，撑着黑色的雨伞，烧起了纸钱，看着升起的纸花，像黑色的蝴蝶漫天在飞……

你哽咽着声音！

捧着生疼的心说：“妈，如今儿子住大房子了，我好想你陪我一起来住！儿子如今有钱了，我好想你陪我一起来花！我带着你最爱喝的老酒，睁开眼睛收吧！！！”

回到老宅里，习惯地喊了一声妈，

却发现：没……人……答……应！

原来我以为，你的家是你的家，妈的家是妈的家！

自从妈走了，你才发现，妈在哪里，哪儿才是家！

各位，你听到这样的故事，是不是好像你自己在经历这件
