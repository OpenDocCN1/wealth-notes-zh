# 第81课：删减赘词

不要总是刻意地去咬文嚼字

许多人上台或许因为习惯，或许因为紧张，或许因为大脑一时“短路”很容易出现一些累赘的词语或者句子。

比如出现“呢”“然后”“就是说”“首先”“可是”“所以”这类词语，或者出现“我来跟大家讲个故事”“这点非常重要”等句子。有一个演讲俱乐部，里面就有评委专门统计演讲家出现了多少次这种累赘词句。

![](bbox=[0.14, 0.48, 0.89, 0.62])

最近这几年很多电视剧为了利益，将本来是 40 集的电视剧硬是剪辑成了 60 集，甚至 80 集，观众看起来就会觉得很拖沓。

同样的，在我们演讲的过程中，减少累赘词句可以让我们的故事更加精简，情节更加紧凑。
