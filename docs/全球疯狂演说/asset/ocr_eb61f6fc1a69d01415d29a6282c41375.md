# 第06课：商业演讲

# 把话说出去把钱收回来的能力

商业演讲，就是以商业为目的的演讲，演讲的最后目的就是两个字，大家猜猜是哪两个字呢？标准答案——收钱！

一诺老师从1996年第一次演讲开始，到现在已经有20多年的时间。全球巡回演讲3000多场次，亲传弟子超过100位，粉丝2000多万！平均每天都会有5个项目找一诺老师合作，所以从1997年到现在，一诺老师亲自看了不下3000个项目。

这些项目来找一诺老师的目的基本都是一样的，就是让一诺老师指导他们做商业演讲。
