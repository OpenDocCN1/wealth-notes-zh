# 第03课：对准演说

没找准对象的演说是在对牛弹琴

正所谓“知己知彼，百战不殆”。

演说之前，一定要研究清楚你演说的对象是什么。

就好比你带兵打仗却不知道要跟哪个国家的军队交手，对方都有什么样的兵种、武器、阵法，优势劣势是什么，请问你怎么打？一诺老师认为，演说也是一样——

![](bbox=[0.14, 0.44, 0.89, 0.58])

记得一次在上海演说，一位学员叫李总，在下课期间跑过来对我说：“一诺老师您好，我想在苏州办一场招商会，请问一诺老师能不能帮我们做一场演说呢？”

一诺老师：“演说的目的是什么？”

李总：“想通过演说，现场融资做一个项目。”

一诺老师：“你邀请来参加招商会的都是些什么人？”
