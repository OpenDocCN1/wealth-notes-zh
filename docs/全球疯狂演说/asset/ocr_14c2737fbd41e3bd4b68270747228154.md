# 带来什么？

以下状况，在你演讲时曾出现过的，都请打“√”。

| 口面红耳赤 | 口心跳加速 | 口手心冒汗 | 口手不知道放哪里 |
| 口词不达意 | 口吞吞吐吐 | 口满头大汗 | 口眼睛不敢看观众 |
| 口语无伦次 | 口大脑空白 | 口语速变快 | 口口头语变多 |
| 口脸部抽搐 | 口双腿发软 | 口重复口头禅 | 口后背、额头出汗 |
| 口身体发抖 | 口头脑空白 | 口小动作 | 口想要逃离现场 |
| 口结巴 | 口尿急 | 口 | 口 |

打完“√”之后，我想你就可以评估出自己的紧张程度了。

选项越多，紧张程度越严重。
