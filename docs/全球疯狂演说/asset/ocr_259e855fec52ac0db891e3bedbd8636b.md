# 共鸣系统是声音基本功训练

共鸣系统是我们对声音的修饰，使声音可以变化多样。

要训练好声音，就需要先练习一些基本功。

# (1) 练呼——胸腹式联合呼吸法

对于发声来说最好的呼吸方式就是胸腹式联合呼吸。如何做到呢？胸腹式联合呼吸操纵气息的部位在胸部和腹部的连接处，即横膈膜。吸气时，胸部放松，腰部周围明显扩张，两肺底部的横膈膜向下运动，气息自然充分地吸入身体。呼气时，胸腔扩张挺起，小腹向内向上收缩，横膈膜向上运动，将气息由肺部挤出，完成呼吸过程。如此循环，养成习惯。
