# 第88课：声音训练1

同样的话用不同语气,意思就完全不同

演说家如果有一个好的声音,那就会吸引听众一直认真听,不会分神，不会抗拒。

反之，声音可以催眠，可以让听众产生对抗的情绪。

我们现在围绕着演说来训练一下声音。
