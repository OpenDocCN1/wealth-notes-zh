# 第76课：讲好故事

故事是演说中非常重要的一环

故事是演说中非常重要的一环，曾经有人做过测试：

对于一般人来说，听了一场2小时的演说，第二天就会忘掉95%，一周后就会忘掉剩下的5%中的80%，那还记得什么？

就是演说家讲过的故事以及里面的一些细节。

有的人天生就适合讲故事，这跟他的性格有关。

有一种性格分类的方法把讲师的性格分成四种——

哪一种性格的人讲故事最生动呢，当然是活泼型，但活泼型容易讲着讲着就跑题了。
