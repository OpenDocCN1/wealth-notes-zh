# 第56课：明确目标

没有目标的演讲简直是没有任何意义

在一诺老师《魔力演讲家》的课程里有这样的一个环节：
每一位同学需要抽取一个同班同学的名字，然后上台介绍那位同学，介绍时间是1分钟，衡量介绍得好不好标准是：介绍完以后，听众是否愿意请被介绍的那位同学吃饭。

简单来说，就是A抽到B的名字，A要用1分钟的时间介绍B，如果听完A的介绍，大家都愿意请B吃饭，那么A的介绍就是成功的。

![](bbox=[0.11, 0.517, 0.854, 0.658])

在这个环节结束之后，一诺老师提问：“我们对自己要介绍的那位同学了解的信息很多，在1分钟的介绍时间里是不是要全部讲出来？”

大家回答：“不是。”
