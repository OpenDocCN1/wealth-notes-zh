# 第82课：情绪带动

演说就是信心的传递,情绪的转移

前面我们说过活泼型性格的人讲故事最生动，因为他们性格里天生就有种情绪变化快的特质，他们在讲故事的时候很容易将情绪投入到故事情节中。

因为情绪投入，所以表情丰富，肢体语言也丰富，整个故事就会让你有种身临其境的感觉。

演说演说，一半是演，一半是说，你要说好，还要演好。

情绪投入就是最好的演绎技能。

很多导演在挑选演员的时候，会看他的情绪表现，有的人经过几秒钟的酝酿就能流下眼泪，有的人却怎么打都挤不出半滴，这跟他们情绪调动的能力有关系。
