# 第68课：点到为止

# 要学会使用听众容易听懂的语言

“点到为止”在用这个方法的时候有几个注意事项：

+   (1) 尽量不要用“首先”“其次”等来代替数字

跟“1、2、3、4”比起来，“首先、其次、再次、最后”这些词语没有那么容易让听众听清里面的条理性，“1、2、3、4”这些数字要直接很多，也好理解很多。

![](bbox=[0.145, 0.44, 0.888, 0.58])

+   (2) 要点尽量简洁

要点的数字尽量一致，要点的句式尽量一致，这些都便于听众记忆。

比如“iPod功能、手机功能、网络功能”句式是一致的，“理、开、悟、静”每个要点都是一个字，“感谢每一位员工，感谢每一位客户，感谢每一位竞争对手”句式一致，这样容易
