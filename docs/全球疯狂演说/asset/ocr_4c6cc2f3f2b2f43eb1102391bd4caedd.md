# 第69课：画龙点睛

# 这样演说能起到画龙点睛作用

湖南卫视有一档节目叫作《我是歌手》，在第四季第六期中，歌手李克勤唱的是电影《古惑仔》的主题曲《友情岁月》，第一句唱得一般，中间发挥得还不错，最后的高潮部分他将唱法与歌曲旋律、节奏做了完美的结合。

各位猜，第一句有瑕疵，但最后发挥很好，能排第几名？第二名。为什么呢？因为大家印象最深刻的事情一般是离当下最近的事情。也就是说，在表演的前、中、后段水平都差不多的情况下，观众对表演者最后的表演印象是最深刻的。

在表演界这种例子很常见，其实演说界也是一样，一段精心准备的结语可以在最后为演说家将分数拔高很多。
