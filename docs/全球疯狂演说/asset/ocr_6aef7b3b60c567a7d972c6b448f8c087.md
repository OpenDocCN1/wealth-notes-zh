# 第58课：互相连接

# 优秀讲师一定要学会与学员连接

这种连接不是演讲家在上面说，听众在下面听，而是演讲家跟听众形成一种能量场的连接。

有很多学员评价一诺老师的课程说，他们听过很多老师的课程，其他老师也讲得很好，但是上一诺老师的课有一个特点，那就是感觉跟一诺老师是“心在一起”的。

怎么理解“心在一起”这句话？其实就是在能量场上跟学员连接起来，不是嘴巴上的互动，而是心灵上的互动。
