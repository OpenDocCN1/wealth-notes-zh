# 从小白到魔力演讲家之路《全球痴狂演讲》 麦克风一响,黄金万两!

各位,如果3分钟能够讲清楚的东西,别人讲了个半小时,你是不是也会厌烦?

二十几年前,一诺老师受邀去给浪莎控股集团的支付项目讲招商会的演讲。讲完之后,他们告诉一诺老师,他们这个项目之前也请过好多讲师,但一诺老师是唯一一个把项目讲清楚的讲师。从那个时候开始,一诺老师就成了他们指定的项目招商讲师。

为什么一诺老师是“唯一一个把项目讲清楚的讲师”？因为一诺老师讲的时候特别注重两个方面:通俗易懂、条理清晰。

通俗易懂,就是针对不同的听众,用他们能够理解的方式来进行演讲。相对论的提出者爱因斯坦先生,有一次被他的邻居,一位家庭妇女问道:“爱因斯坦先生,请问什么是相对论?”

你猜爱因斯坦先生怎么回答?
他会不会从时间和空间的角度来跟这位妇人解释?不会。
