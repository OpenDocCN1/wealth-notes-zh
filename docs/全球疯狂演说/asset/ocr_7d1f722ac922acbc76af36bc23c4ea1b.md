# 陌生的听众也会引发演说的恐惧

对于很多人来说，在熟人面前讲话与对陌生人对话的感觉和态度是完全不同的，演说家也同样如此。在熟悉的听众面前进行演说往往会更自然，压力也会更小，并且更放得开。

然而，在一群陌生人面前，许多演说家都会自我束缚，还会变得非常紧张。

一诺老师曾经给某大学的学生布置过这样的作业——去20人以上的陌生教室做一次3分钟演说。而且在演说前，学生不能向这些陌生人说他们是在“写作业”。

可想而知，一群演说经验、沟通经验都不充足的学生在陌生的教室演说，自然会受到许多人的冷嘲热讽。
