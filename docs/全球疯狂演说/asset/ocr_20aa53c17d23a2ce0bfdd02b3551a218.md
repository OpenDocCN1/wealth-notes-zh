# 第44课：积累素材

# 有助于演说的名人名言素材

即一些名人说过的比较出名的句子、观点等。

如果在竞争中，你输了，那么你输在时间；反之，你赢了，也赢在时间。（李嘉诚）

发射自己的光，但不要吹灭别人的灯。（牛根生）

今天很残酷，明天更残酷，后天很美好，但是绝大多数人死在明天晚上，见不着后天的太阳。（马云）

使这个世界灿烂的不是阳光，而是女生的微笑。（俞敏洪）

一个人事业上的成功，只有15%是由于他的专业技术，另外的85%要靠人际关系与为人处世的技巧。（卡耐基）

世界不会在意你的自尊，人们看的只是你的成就。在你没有成就以前，切勿过分强调自尊。（比尔·盖茨）

投资三条铁律：第一，保住本金。第二，保住本金。第三，谨记第一、第二条。（巴菲特）

成功的公式是 A=X+Y+Z！A 就是成功，X 是努力工作，Y 是懂得休息，Z 是少说废话！（爱因斯坦）
