# 五種金錢 EQ，你是哪一種？

你與金錢的關係，有一定的模式存在。如果沒有受過完善的金錢教育，恐怕就會符合接下來要討論的五種性格類型的其中一種或結合多種。

了解你是哪種模式，就能理解你的行為根源。為了與金錢建立健全的關係，最初的步驟就是誠實認清自己目前站在哪個位置上。
