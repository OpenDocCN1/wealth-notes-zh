# 學習心怀感恩，常保真心

很多人會說「想要更多的錢」，但是沒什麼人會說「我錢太多了！」。不過，到目前為止，我認識一個個人說過「我有很多錢」，那就是我的導師竹田和先生！

關於擁有「充足」的錢錢這件事，我在與珍娜·布瑞·艾特伍（Janet Bray Atwood）合著的書《提高真心！成功的祕密從「謝謝」開始》（Naro Up：The Secret to Success Begins with Argato）裡面提過。
