# ⑤接受他人的支持与爱

最后，第五项原则就是「打从心底接受他人的爱与支持」。在体脸负面情绪的时候，也许你会感觉光靠自己的力量要度过难关，几乎是不可能的任务。透过身旁的人给你的爱与支持，一开始让你觉得很重的问题，就会缩小到总有办法解决的程度，变得更好整理、因应了。前文提过，藉由向朋友或导师求助，就能够相信会有更好的未来。

我们往往会觉得，如果没有为别人做什么，就不能接受那个人的帮助。这是一个开始，能够接受帮助，就是为了往正确方向前进强而有力的一步。

当我们能够无条件接受他人的帮助之后，就能理解自己也有能力与人分享、帮助别人。我们身旁亲友的爱和帮助，拥有能够减缓那些会消耗我们、让我们无力不宁的能力。
