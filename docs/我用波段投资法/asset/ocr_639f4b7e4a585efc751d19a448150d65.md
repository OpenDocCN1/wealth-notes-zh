# 月營收: 看出公司成長或衰退

可以判斷公司每個月營收是否有成長、公司新產品是否有競爭力。我會比較去年同期的營收是否衰退或成長。如果今年的營收是衰退的，我會試著找出衰退的原因；如果今年的營收是成長的，我也會試著查出成長的原因，甚至會預測該題材是否能繼續成長，可以持續多久。

每個月的 10 日以前，上市櫃公司必須公布月營收的數字，所以我都會在這個時候，記錄我所關注的公司之月營收，觀察是否有成長。
