# 32 創造人生財富的理財習慣

我會把自己想像成電玩裡的角色瑪利歐兄弟，戴著一頂「M」標誌的帽子，象徵著「MONEY」，穿著藍色背帶式工作褲，如同自己努力工作，希望不斷往上跳躍，頭撞金磚，可以獲得金幣，突破困境闖關成功，獲得更多金幣。若要加強自己的跳躍能力，遊戲裡可以吃蘑菇，讓瑪利歐變大。變大後的瑪利歐被稱為「超級瑪利歐」，得到額外的生命值。在現實中，這些蘑菇道具就是我們的理財觀念，讓我們的財富更茁壯。
