# 弱关系
18.08.02

1973年，美国社会学家马克·格兰诺维特（Mark Granovetter）提出了弱关系（weak tie）理论。他的研究表明，通过朋友关系找工作的人中，在强关系帮助下找到工作的占31.4%，在弱关系帮助下找到工作的占68.6%。
黄峭一到一段水平

生活的<|start|>庆，多来自强关系；而事业的<|start|>庆，常来自弱关系。强关系产生家，弱关系生钱。

经营好弱关系，需要具备意识、方法、平台、行动。

# 意识

首先是要充分认识到弱关系的重要性，要有主动经营弱关系的意识。

# 方法

其次要学习拓宽和维护弱关系的方法。你需要学习发现人优秀的地方，比如修养经历、看他怎么样思考、怎么办事、怎么建立人脉。还要学习良好的思维和表达（如写作和演讲），经常看书、写文章和练习一分钟电子邮件自介绍，会对你很有帮助。

# 平台

再次要善于利用和搭建平台。网络给我们提供了天然的便利条件，却使我们注意力分散，而如果只用来逛街、刷朋友圈、看视频。你要学会利用一切创建联系平台，发展自己合适的自媒体，足够，主动去经营关系。也以此构建蒋兴平台台，如组织微信群，组织读书会，校友会，行业交流会，微博会，头条号，微谈，拉群等。

# 行动

最后也是最重要，经营弱关系要马上行动！就从现在开始，在实践中培养意识，练习方法，掌握平台，不要看了文章热血沸腾，睡一觉起来什么都不记得了。

# 现在

建立一个微信群，你就完成了一个弱关系平台的搭建；
在知乎上回答一个提问，你就完成了一次弱关系信息的分享；
在抖音上发一个短视频，你就完成了一次弱关系形象的树立；
把本文分享到朋友圈，你就完成了一次弱关系价值的创造。
