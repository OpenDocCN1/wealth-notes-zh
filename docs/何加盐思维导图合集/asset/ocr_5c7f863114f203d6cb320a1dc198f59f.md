# 公众号标题应该怎样写

能吸引读者目光的标题主要有两种文案，必要满足以下两个条件：1.高潮的制造；2.文字必须构成完整句子、想象感官的动词、细节一增强额感。也可以一句话... 根据需要，甚至可以融合使用。因为总结一下标题又文案... 写文章标题也可以发展，但不能死板的套用。

# 每一个公众号都需要有一个相同的定位

读者接触先声明，要有一个稳定的预期：他知道在每个点一定能得到他想要的一篇类型文章。

# 从价值层面来看，可分为：信任感、知识、投资、资源、情感、情绪。做等类型。

# 从内容构成来看，可分为人物、场景、事件、行业、动态、有网友动态分析。

# 从写作形式创新，可分为对比、对话、简历、新闻、影评、手记、小说、美文、方法论、历史、趣闻

# 从写作内容渠道，可分为渠道类素材、时效类、读书类、影视类、调研类、案例分享、指标类
