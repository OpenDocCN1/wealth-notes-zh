# 学历与专业
20.07.13

+   1. 学历非常重要。一个好的学历，会让成功的概率高很多很多。
2. 专业也非常重要。如果选中一个好的专业，成功的概率也会高很多。
3. 但这并不意味着靠学历论英雄和专业。没有好的学历，不是顶流上的专业，也有可能成功的，只不过概率要低一些。
4. 不管什么学历，什么专业，最重要的还是拥有快速学习、持续学习的能力，才有可能获得成功。

关于专业的另一个发现：对于大部分牛人而言，大学就研究的学生的专业，与后来所从事的事业多少都微有关系。

这点也启示我们，如果上了大学，就一定要把专业学好，因为如果你想成为一个牛人的话，很大程度上你大学学的东西，在事业上是用得上的。

学历和专业也非常重要，但更重要的是，是快速学习和持续学习的能力。

如果你想在商业上取得巨大成功，首先你要选择一个好专业，取得一个好学历。这样你所创造的事业以至事业发展过程中，会占据很大的优势。

如果你已经错过了获得好专业和好学历的时机，也没有关系，黄光裕、李想、童明栋、马云等人Diego的经历告诉我们，成功的道路有很多，学历和专业并非唯一。

不管你选择一个好专业，好学历，最重要的一点，请记住它。要提倡学习和进化，努力奋斗，相信天道终将酬勤！
