# 沉没成本
19.08.01

经济学上有一个概念，叫沉没成本。意思是已经付出，不可收回的资源。我们为一件事情所付出的金钱，时间，精力，感情等，都属于沉没成本。在做决定时，我们不能把沉没成本入考量。不管之前已经付出了多少，都和当下的决策无关。

# 感情

很多情感或夫妻，处级一段时之间后，已经出现了诸多不同的问题，甚至有发展到半路就走向离婚人的不同。但鉴于之前已经付出了那么多看和感情，所以就忍着，当面不和不错，搞得每天和一个不合适、不善的人在一起，生活得非常痛苦

# 事业

在工作事业上，有很多事情看自己喜欢，不擅长的事做，不愿换一个路走，究其原因，是他们觉得自己在这一步行驶了这么久，要改变行，原来这些都不会白干吗？

# 投资

有些企业也是如此，在市场已经发生变化，原来的产品被淘汰或被受冲击，或已经由于经营这个领域投入了过多的个人力量，并且因为奋力的经营，而走不正常型，结果错失了新的机会。

广义的沉没成本，还包括那些由于手于人或他人的错误，或者无法抗拒的客观因素而产生的、无法找回或挽回的损失，就好比人的生老病死，是生气和情绪失常的状况。很多事情已经发生，沉没成本已经造成，但问题是，生气和指责毫无意义。正确的方决应是马上解决问题。

机会成本，是我们在需要付出的资源假如用于做其他事，能带来什么收益？即，我们为了做这件事而放弃了多少未来可以获得的别的好处？

边际收益，是我需要做的这件事，能给我们带来多少新的好处？
边际收益可以是正的，也可以是负的。如果这件事情不光没有带来好处，反而带来了新的损害，那么你的边际收益就是负数

普通人往往更关心沉没成本，高手则会看边际收益。
沉没成本，还是看眼未来，这两种不同的看问题方式，决定了两种不同的生存。
老可过往去，幸福似乎遥不可及；只有看未来，才会有路和希望。
