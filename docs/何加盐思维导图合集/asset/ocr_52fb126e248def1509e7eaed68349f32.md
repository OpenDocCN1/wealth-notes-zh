# 何加盐

# 37岁更大的梦想
20.09.18

2000年9月，我进了高三，也进入了自己的17岁

高三那年，我依然是浑浑噩噩，每天依旧看春秋，长时间独处，收到收集喜好人卡。最后高考成绩勉强过了重点线，上了青岛海洋大学（现中国海洋大学）旅游管理系。

2001年9月，在大一新生军训的操场上，我第一次见到了阿姐的她。
后来的27岁的她，始终陪在我身边。

2010年，我27岁，结婚一年，工作两年从17岁到27岁这十年，应该说是体会在工作上和生活上。

感慨上，经过一次一次不成功尝试后，我终于在大学毕业那年和同龄的她凑到了一起，然后经历了三年痛苦的异地恋，终于在26岁那年修成正果，27岁生下第一个孩子。

2020年的时候，我37岁，创业两年半。
从27岁到37岁，可以说是不折不扣的10年。

35岁那年，为了给自己的梦想和野心找一个利于发展的安置之处，我离开了体制。先是做了一家咨询公司，后来又创建了“何加盐”这个公众号。

37岁的另一个小成就，就是我第一本书《持续进化》终于在今年五月正式出版。

2019年3月，我开始把主要精力放在写作上来，并确定了“专门研究私人”这个主题。

第一，它应该像《春秋》一样，家可记载企业家一个个故事过的轶事，及其对社会的影响。古人说，孔子作春秋，而后能明是非。
我希望企业家能够写出真实的企业家起这样的工作，让我们在善恶感悟之间 tast，而为支柱存在的，而有所成。

第二，它应该像《史记》一样，对企业家的描写细致入微，精彩绝伦，让人读起来不单不累，很不好回胃气。企业家成长历史应该要被企业家领悟的养，而民同所称的作品。应该有一本马上要用动人眼睛的绝妙，夹杂那些都诸社阅的场所再到。

第三，它应该像《资治通鉴》一样，鉴往知事，有助于治道。中国当代企业家的成长经历和企业的实践经验（也有瞎拐失误的教训），里面带很多的总结和相关资产，对较大的应有大的启发和激励作用（也有警示作用）。应该有一本书能把这些总结出来，传给后来人。
