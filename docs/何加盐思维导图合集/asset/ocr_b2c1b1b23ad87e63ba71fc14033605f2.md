# 不确定性
19.06.04

+   - 第一层次：接受世界的不确定性
- 第二层次：接受自己的不完美
- 第三层次：打造安全边界
- 第四层次：培养强大的决策力
- 第五层次：帮助人们应对不确定性

请记住，没有非黑即白，灰色才是世界的常态。

如果世界是不确定的，那么我们自己也不必是十全十美的，因为，你不知道这样的你，更适合未来的世界。

你的安全边界越宽广，在面对不确定性就越从容，应对突发状况越轻松。

环境是灰色的，但决策是黑白的。保持学习、观察、交流、思考，对我们永远都很重要。

你能帮助人们应对多少不确定性，就能获得多大的成功。

> “一个清晰方向，是在泥池中产生的，是从灰色中脱颖而出，方向是随时间与空间而变。它常常又会变得不清晰。并不是非白即黑，非此即彼。合理地慢慢合适的朋友，是每种种发展要素，在一段时间内和谐。这种和谐的过程叫妥协，这种和谐的结果叫灰度。”
需求度、速度、灵活性、冗余度、开放协作度、创新度、进化度
