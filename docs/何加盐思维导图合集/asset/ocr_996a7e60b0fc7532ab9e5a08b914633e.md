# 用好社交网站

我们把微博、微信、知乎、饭否、脉脉等叫做社交网站。这些路找资料非常重要的渠道。

有一些特别好的公众号，是研究知名企业和人物必看的，如“财经教室”、“中国企业家杂志”、“LateNews by 小惨”、“饭统戴老板”、“吴晓波频道”、“左林右”、“keso怎么看”、“乱翻书”、“卢洪言”、“左林右谋”、“8字路口”、“虎嗅APP”、“36氪”等。（当然，更不能错过的，还有“何加盐”）

# 用好视频网站

知名企业家比较靠过去的节目，有这么几个：《鲁豫有约》、《对话》、《波士堂》、《开讲啦》、《遇见大咖》、《人物》、《二十年二十人》。当然还有很多，大家可以以名字查，优酷、腾讯视频、B站等地方搜他们的名字找到。

如果是国外的企业家，那就要用到Youtube了。

# 用好名人演讲

大部分名都会在不同场合有一些演讲活动，如公司内部演讲、行业活动演讲、母亲演讲、家乡演讲等等，这里通常藏着很多重要消息。

# 用好传记作品

传记是了解企业和企业家最完整全面的方式。凡要研究他们，是不可不读的。

# 用好杂志

最后就是一定要用好杂志。中国有一些专业杂志做得非常不错，采访有深度，研究充分。

# 资料渠道

如果平時你得很少，或者比较挑剔，多花點時間无所謂，那就能免費的也差不多够用了。但是，如果想获得优质信息，或者想提高效率，最好还是付费版。

另外还有一个值得关注的是内部信。很多企业家都会通过内部信的方式回应某些问题，或者阐述某些观点。例如想知道腾讯在3Q大战之后的内容发展，就不得不看马化腾2010年题为《风开未来之门》。这篇内部信，想知道华为的精进，那就不要不要的《华为的冬天》和《三江春水向东流》这些经典文献。
