# 何加盐

# 成功企业家
20.01.08

+   1, 根据目标找资源，而不是根据资源定目标

他们会像老母鸡保护小鸡一样，随时为保护企业利益而虎视眈眈，有人敢危害企业利益，他们就冲上去和人拼命。
没有对企业的这一份超强热爱，就不可能做成一个成功的企业。

+   2, 把企业当成自己的生命去热

+   3, 遇到困难绝不退缩

成功的道路，从来都是遍布荆棘。每 一个成功的企业家，都有过困难到恨不得撤离的时候——当然，他们不会踹，再难的问题，他们都会坚强面对。
对他们来说，所谓成功，无非就是直面一切困难，咬着牙坚持到底。

+   4, 埋头做事，为而不争

所有成功的企业家，无一不是誉满天下，亦谤满天下。
但成功企业家的脸皮都非常厚，他们会自动忽略那些负面的声音。
马化腾曾经说过一句话，能很好的代表企业家这种心理。他说：“企业不会被骂死，但是会因找不到盈利模式而失血致死。”
