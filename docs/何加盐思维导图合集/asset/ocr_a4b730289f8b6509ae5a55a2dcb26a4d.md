# 影响10位大佬10本书
21.03.11

# 雷军与《硅谷之火》

我在40岁的时候，没有忘记18岁的梦想，我去试了。我要特别告诉各位话，叫作人因为梦想而伟大。只要你有了梦想，你就会变得到无与伦比。

# 马云与《人生》

人生的道路虽然漫长，但却处处常有几步。尤其是当人年青的时候，你所决定的，可以影响人生的一个时期，可以影响一生。——柳青

# 马斯克与《基地》

为了应对黑暗时代的到来，请聚集最优秀的科学家，建立一个基地，希望它成为拯救人类文明的灯塔。

不靠以什么方式读，只要读书，就会对我们产生影响。

# 孙正义与《龙马来了》

“龙马，你是男子汉，只要自己认为是对的，就应该毅然决然去做才是哟。”

# 芒格与《富兰克林自传》

芒格富兰克林致力于史实信仰，而且开辟了新的境界。在富兰克林那里是建议彼此做事，在芒格这里会永远成为必须做的事。

书会唤发我们的梦想，如同《硅谷之火》对雷军、《基地》对马斯克；

# 段永平与《穷查理宝典》

芒格本人的处世的中心其实非常简单，那就是反向思考，善良正直，极度专注，超脱耐心，坚守理性，热爱阅读。

书会指引我们的其实，如同《毛泽东选集》对任正非、《富兰克林自传》对芒格；

# 王兴和《有限与无限的游戏》

世上至少有两种游戏，一种称为有限游戏，另一种称为无限游戏。有以取胜为目的，而无限游戏以延续游戏为目的。

书会激发我们的思维，如同《有限与无限的游戏》对王兴、《从优秀到卓越》对贝佐斯……

# 张一鸣与《少有人走的路》

自律是解决人生问题最主要的工作，也是消除人生最高最重要的方法。

# 贝佐斯与《从优秀到卓越》

随着亚马逊越做越成功，贝佐斯并不夸言公司成功的就是应用了飞行效率板。此后，飞行效率板这个概念为分？亚马逊发展之路奠定了不可或缺的一个秘密武器。

世界上有些书，有些文章，你只要读到，就改变自己一生。

# 任正非与《毛泽东选集》

华为创新的阶段尚没有公司的企业文化，毛泽东思想就是公司思想。作者自白的学标兵说，“我喜欢毛（泽东选集），经常读懂毛泽东处理论我养成为年轻时的攻击，客户攻坚，竞争策略以及内部运营服务……
