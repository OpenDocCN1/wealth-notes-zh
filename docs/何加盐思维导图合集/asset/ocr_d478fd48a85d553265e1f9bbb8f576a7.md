# 深度工作利

一个人要想有所成就，必须具备深层工作的能力。而随着网络和智能手机的流行，向浮浅工作转变已经成为了一种文化，大多数人逐渐失去了深度工作的能力。少数能够抵御这种文化，学会深度工作的人，将受益于变大的经济前景和个人发展机会。

卡尔·纽波特认为，在数字时代的新经济之下，有两种人会成为赢家：一种是能够迅速掌握数百工具的人；一种是能在自己所在领域达到精深层次的人。

# 浮浅工作的危害

+   1. 注意力残留

当我们每天无数次在手机和工作之间切换时，每一次开始工作，你的注意意力都还残留在手机上，所以工作效率就极其低下。

+   2. 意志力消耗

美国心理学家罗伊·鲍迈斯特的研究表明：意志力并不具有弹性的展现。人在一段时间内意志力是有限的，它在使用过程中会不断消耗。

+   3. 心智残疾

如果我们总是被手机所干扰，受影响的不仅止于当下的工作，我们的大脑也在被重新编辑。换句网络用语说，在工作或学习时老看手机，会导致脑残一根据布鲁克林福德的理论，这句话可不是骂人，也不是恐吓，而是科学研究结论。
