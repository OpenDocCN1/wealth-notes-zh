# 弱关系
18.08.02

1973年，美国社会学家马克·格兰诺维特（Mark Granovetter）提出了弱关系（weak tie）理论。他的研究表明，通过朋友关系找工作的人中，在强关系帮助下找到工作的占31.4%，在弱关系帮助下找到工作的占68.6%。
生活的庆，多来自强关系；而事业的庆，常来自弱关系。强关系产生家，弱关系生钱。

经营好弱关系，需要具备意识、方法、平台、行动。

## 意识

首先是要充分认识到弱关系的重要性，要有主动经营弱关系的意识。

## 方法

其次要学习拓宽和维护弱关系的方法。你需要学习发现人优秀的地方，比如修养经历、看他怎么样思考、怎么办事、怎么建立人脉。还要学习良好的思维和表达（如写作和演讲），经常看书、写文章和练习一分钟电子邮件自介绍，会对你很有帮助。

## 平台

再次要善于利用和搭建平台。网络给我们提供了天然的便利条件，却使我们注意力分散，而如果只用来逛街、刷朋友圈、看视频。你要学会利用一切创建联系平台，发展自己合适的自媒体，足够，主动去经营关系。也以此构建蒋兴平台台，如组织微信群，组织读书会，校友会，行业交流会，微博会，头条号，微谈，拉群等。

## 行动

最后也是最重要，经营弱关系要马上行动！就从现在开始，在实践中培养意识，练习方法，掌握平台，不要看了文章热血沸腾，睡一觉起来什么都不记得了。

## 现在

建立一个微信群，你就完成了一个弱关系平台的搭建；
在知乎上回答一个提问，你就完成了一次弱关系信息的分享；
在抖音上发一个短视频，你就完成了一次弱关系形象的树立；
把本文分享到朋友圈，你就完成了一次弱关系价值的创造。

# 二八定律
19.04.16

人这一生，怎么样才算成功？

你在所选择的领域内，做​到前20%，就算成功。那你还可以进入20%里面的20%，也就是说前4%。如果你已经是前4%，你还可以进入前0.8%。所谓成功，就是不断从80%进入20%。

当你知道80%的生意，都来自20%的客户，你就应该把你80%的热情，献给这20%的关键客户。你的营销费用，你的陪吃陪喝陪玩的时间，你的礼品，你的关心问候，80%都要放在他们身上。

当你知道公司80%的命运，都来自你20%的决策时，你就应该把主要精力放在战略、人才和核心业务上面，不要再花费时间去管公司鸡毛蒜皮的小事。

当你知道你的80%的业绩，都是由20%的工作决定时，你应该该放弃万事求完美的心态。你应该首先分清楚什么是重点工作，什么是次要工作，然后把80%的精力，放在重点工作上。

二八定律更有价值的地方，是用于指导我们的日常思维和行动，帮助我们进入20%。

# 沉没成本
19.08.01

经济学上有一个概念，叫沉没成本。意思是已经付出，不可收回的资源。我们为一件事情所付出的金钱，时间，精力，感情等，都属于沉没成本。在做决定时，我们不能把沉没成本入考量。不管之前已经付出了多少，都和当下的决策无关。

## 感情

很多情感或夫妻，处级一段时之间后，已经出现了诸多不同的问题，甚至有发展到半路就走向离婚人的不同。但鉴于之前已经付出了那么多看和感情，所以就忍着，当面不和不错，搞得每天和一个不合适、不善的人在一起，生活得非常痛苦

## 事业

在工作事业上，有很多事情看自己喜欢，不擅长的事做，不愿换一个路走，究其原因，是他们觉得自己在这一步行驶了这么久，要改变行，原来这些都不会白干吗？

## 投资

有些企业也是如此，在市场已经发生变化，原来的产品被淘汰或被受冲击，或已经由于经营这个领域投入了过多的个人力量，并且因为奋力的经营，而走不正常型，结果错失了新的机会。

广义的沉没成本，还包括那些由于手于人或他人的错误，或者无法抗拒的客观因素而产生的、无法找回或挽回的损失，就好比人的生老病死，是生气和情绪失常的状况。很多事情已经发生，沉没成本已经造成，但问题是，生气和指责毫无意义。正确的方决应是马上解决问题。

机会成本，是我们在需要付出的资源假如用于做其他事，能带来什么收益？即，我们为了做这件事而放弃了多少未来可以获得的别的好处？

边际收益，是我需要做的这件事，能给我们带来多少新的好处？
边际收益可以是正的，也可以是负的。如果这件事情不光没有带来好处，反而带来了新的损害，那么你的边际收益就是负数

普通人往往更关心沉没成本，高手则会看边际收益。
沉没成本，还是看眼未来，这两种不同的看问题方式，决定了两种不同的生存。
老可过往去，幸福似乎遥不可及；只有看未来，才会有路和希望。
美国的创造人常说这样一句话，我也很有感。在这里和大家共勉：
既往不恋，情境向前。

如果平時你得很少，或者比较挑剔，多花點時間无所謂，那就能免費的也差不多够用了。但是，如果想获得优质信息，或者想提高效率，最好还是付费版。

# 三个价值
19.11.16

- 预期价值
- 体验价值
- 实际价值

消费者在检验产品之前的想象的价值，叫“期望价值”

选择期望价值的公司，是倒售型的公司。老板最关心的，是产品能不能卖出去，能不能卖高价。

如果企业长期选择领导向而忽略体验价值和实际价值，股东一定程度之后，就会遇到价值危机和盈利危机。

在使用产品之时感爱到的价值，叫“体验价值”

选择体验价值的公司，是交付型的公司。公司会设计各种方式，让用户在使用产品的时候感觉良好，甚至认为物超所值。

如果企业长期选择体验向而忽略期望价值，就容易长期的财务亏损，而且容易引起顾客制造约。唯有得到长期忠诚的用户，必须尽快地拼命拉拢，做大又要紧，没有尽头。

产品实际上对消费者起的作用，叫实际价值。

选择实际价值的公司，是产品型的公司。公司会投入大量资源去改善产品的功能。但有时候，这些功能却未必能被用户感知。

如果企业长期把功能向而忽略期望价值和体验价值，则产品很快速地打开销路，往往还没有达到盈亏平衡，企业就倒闭了。

# 成功企业家

- 3, 遇到困难绝不退缩

成功的道路，从来都是遍布荆棘。每 一个成功的企业家，都有过困难到恨不得撤离的时候——当然，他们不会踹，再难的问题，他们都会坚强面对。
