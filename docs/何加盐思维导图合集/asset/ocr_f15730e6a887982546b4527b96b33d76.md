# 第一层：与速去为伍 培养好的习惯，重塑底层系统

+   (1) 每天倾听10分钟；
(2) 每天做10个俯卧撑（或喊起床）；
(3) 每天读读10本书。

这件事，分別是表达自信、坚持特质和持之以恒。它决定了你的时间管理效率、身体健康度以及步步的持续性。

# 第二层：与速去作揖 从身体到思维，全方位提升技能

+   1. 学一些以后工作用得上的技能
2. 学一些生活用得上的技能
3. 学可以与生俱来调节情绪的技能
4. 也可以学一些益身心的技能

第一层的重要性并不多，先聚焦其中一两样开始学习，时间、数学、学业、争取学一门，会一门，不要到处学东，拾起这个累积那穷个。

在第二层，我们需要用同一个时间管理四象限法则。

谈起本命，是路径依赖不明显，和路径依赖缺失、情感人就是说：我要变，我去怎么去？

人生道路选择方法一：标杆法。
找个名单，标杆法，就是找一个人生标杆，或者模仿者，偷看他怎么做。

第一层：与速去为伍，我们要从最简单的事情做起，培养好习惯，重塑底层系统。
第二层：与速去作揖，我们可以做一些从未未来做过，永远都有用，从而也可以提升的事情，让自己从身到到思维，全方位提升技能。
第三层：与速去再见，我们要找到属于自己的终极问题，明确自己未来的目标和要做的事情，打破随境的死循环，一次解决根本问题。

人生道路选择方法二：三维落差法。
世界上有两种职业营销法，也就是选择职业落差的，乐观三维，我们要做做适合于，能给行业留下，如找到这个三维都符合的话，那么那个行业不适合。

1. 先把所有所做的职业（专业）列一个清单；
2. 在里面选出最喜欢的；
3. 让你喜欢好学好，让自己变得有竞争力；
4. 凭着有价值感，找到一份这个领域的工作；
5. 提高专业训练，让自己变得很擅长，成为该领域专家；
6. 凭借家族的力量，赚很多钱。

人生道路选择法三：岗位胜任法。
有一个公司将根据胜任模型工具，SWOT分析，
让这个公司个人进行分析，务必，和外部的机缘、机遇，个人需要如何匹配。
