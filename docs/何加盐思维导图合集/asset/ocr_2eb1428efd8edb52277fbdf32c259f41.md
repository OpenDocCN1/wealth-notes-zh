# 三个价值
19.11.16

+   - 预期价值
- 体验价值
- 实际价值

消费者在检验产品之前的想象的价值，叫“期望价值”

选择期望价值的公司，是倒售型的公司。老板最关心的，是产品能不能卖出去，能不能卖高价。

如果企业长期选择领导向而忽略体验价值和实际价值，股东一定程度之后，就会遇到价值危机和盈利危机。

在使用产品之时感爱到的价值，叫“体验价值”

选择体验价值的公司，是交付型的公司。公司会设计各种方式，让用户在使用产品的时候感觉良好，甚至认为物超所值。

如果企业长期选择体验向而忽略期望价值，就容易长期的财务亏损，而且容易引起顾客制造约。唯有得到长期忠诚的用户，必须尽快地拼命拉拢，做大又要紧，没有尽头。

产品实际上对消费者起的作用，叫实际价值。

选择实际价值的公司，是产品型的公司。公司会投入大量资源去改善产品的功能。但有时候，这些功能却未必能被用户感知。

如果企业长期把功能向而忽略期望价值和体验价值，则产品很快速地打开销路，往往还没有达到盈亏平衡，企业就倒闭了。
