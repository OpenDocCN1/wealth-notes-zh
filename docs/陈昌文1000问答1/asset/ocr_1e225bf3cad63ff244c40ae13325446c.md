# 259、有多聚焦，就有多赚钱

学员：

随着不断深入地学习，越发的想要改变自己。聚焦：这不是一句口号，我要把聚焦执行在我的行动上，任何时候都要聚焦，只干一个项目、只专注做好一个流量渠道、只做好一个关键词、只锁定一个概念踏实的做。

陈昌文：

凡是能聚焦的人，收入都翻倍，甚至几倍，有多聚焦，就有多赚钱。我们的聚焦核心理念是，只做一个环节即可。

# 260、极度有价值，自然有人付费的

学员：

内部营销系统：将流量导入微信、qq经过持续的关注进而成交，因此朋友圈和qq空间内容是必须具有营销性的，需要精心的打造。

陈昌文：

朋友圈、QQ空间，都需要我们耐心的打造，日复一日的丰富文案。里面极度有价值，自然有人付费的。
