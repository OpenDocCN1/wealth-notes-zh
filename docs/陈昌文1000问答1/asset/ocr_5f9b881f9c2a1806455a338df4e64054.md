# 328、按照市场原则对待

**学员：**

假如跟着自己打江山的员工，现在能力跟不上公司的发展，该怎么 办？

**陈昌文：**

我《创业兵法》里，对这个有详细论述。简单说两句，人好的、可爱的，留下来，变成私臣。一般人，给笔钱养老。外人、陌生人没什么关系的人，按照市场原则对待。
