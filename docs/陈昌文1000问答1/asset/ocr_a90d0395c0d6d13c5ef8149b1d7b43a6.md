# 101、天天干实事

**学员：**

为啥又出单了？我要平静下来。功力看来不够，都是小单。话术应该 还有问题。但是已经越来越有信心了。谢谢老师。

**陈昌文：**

认认真真复制大神，认认真真天天做几十个音频，专注、聚焦到极致。谈 企业家的内容、老板的内容。做具体的事情，踏踏实实弄吧，一天搞 到几万块再说。

记住，聚焦、做减法。

您现在这个收入，没什么好骄傲的，要平静、安静。踏实、善良。这样，然后，天天干实事。

不偷懒。聚焦、专注、专业、专心。把喜马拉雅上所有大神的好内容吸 收过来。争取每天出 5 单以上。
