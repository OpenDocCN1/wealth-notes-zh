# 386、您是穷、是达，您还不清楚

+   - 学员：
老大哥早上好，有问题想求助一下您，希望老大能給一些建议与指导， 我自己姐夫哥没有什么文化，被骗到广西北海洗脑进入了传销，他又把 我姐姐骗去洗脑交钱了，准备骗我，我好歹跟老大学会了这么久的思想。 他们还功力太浅，老大您说我该如何解救他们，老大能否帮忙给个建议， 在此万分感谢。

+   - 陈昌文：
拯救您自己。泥菩萨过河，自身难保。穷则独善其身，达则兼济天下。 您是穷，是达，您还不清楚？还要我给您答案？
