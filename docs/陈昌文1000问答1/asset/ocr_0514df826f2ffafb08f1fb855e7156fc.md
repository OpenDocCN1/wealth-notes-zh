# 409、您善良有什么用

您这样说话，就代表您其实非常浅、幼稚，我其实不想跟您说这些话，因为，您年纪比我大，但这就是真相。我的时间比您的时间值钱。我天 天管理自己的事情都管理不过来。我现在的状况是，我稍微管理一下自 己的时间、自己的圈子，我的收入就会倍增。

从某种角度上来讲，一个人老找我聊天，我都是讨厌的。我哪里还 有时间去摘您的那些东西？您一点商业逻辑、思考世界的能力都没有。 您善良有什么用？
