# 93、您必须做大部分人都需要的东西

学员：

我是做软件测试的，是不是可以讲测试技术类视频。就是怕没人听？

陈昌文：

有些行业非常小众，除非您特别出类拔萃，才有人听。

想要吸大量的粉丝，您还是必须得做群众喜闻乐见、赏心悦目的东西。也就是，您必须做大部分人都需要的东西。懂吗？

小众需求，您很难发财。
