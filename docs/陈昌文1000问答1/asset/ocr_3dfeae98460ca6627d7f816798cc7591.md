# 365、升级圈子

**学员：**

是的，老大，每天看您的朋友圈，您发出来的信息，是任何社会的 老大都不肯教给我们的。真正领悟了您所说的，就成功一半了。

**陈昌文：**

加油赚銭，才是真理，其他的都不是真理。变现去，搦粉丝去，搒 高端圈子，升级圈子。

# 366、我以前也舍不得清理一些人， 导致我止步不前

**学员：**

我彻底把朋友圈清理了。不是一个阶层的，全部删除，以前包括同学、同事甚至亲人，彻底大换血。垃圾不清理出去，新的血液进不来。
