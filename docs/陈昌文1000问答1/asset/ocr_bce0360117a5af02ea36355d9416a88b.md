# ## 196、粗糙，或精致，人们都能感觉出来

学员：

陈老师，视频一定要配字幕么？

陈昌文：

有字幕，当然更好，大部分人都形成了看字幕的习惯。没字幕，反 而听不懂您在说啥。顺着大众的习慣走，不要偷懒，把事情做到极致， 把细节做到极致。粗糙，或精致，人们都能感觉出来。
