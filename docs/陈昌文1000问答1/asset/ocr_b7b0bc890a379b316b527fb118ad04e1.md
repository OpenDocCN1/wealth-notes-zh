# 233、敏感的东西，永远也不要讲

学员：

我觉得从今天开始要做的是，1.研究抖音上其他同行的账号；2.每天从新闻、生活中搜集素材；3.继续听老师的录音，并且理解转化成自己的内容，每天都要做这些，这个思路对吗？

陈昌文：

+   1、 每次录制抖音，写一个提纲；

+   2、 照着讲，技巧、故事；

+   3、 每次只讲透彻一个小技巧；

+   4、 每天每个账号 3 个视频，日复一日的传；

+   5、 联系方式可以留 QQ、微信；

+   6、 注意违法乱纪的、敏感的东西永远也不要讲，否则，会给自己找麻烦。
