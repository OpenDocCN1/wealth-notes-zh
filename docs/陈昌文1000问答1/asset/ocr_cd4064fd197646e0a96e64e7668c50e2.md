# ### 115、我们早就知道上班没前途，所以
我们不打工

**学员：**

互联网创业计划。

我原先是在国企铁路局上班的，上了一年。正如大家所知，官僚很 严重，没有关系很难生存，我所见到的老职工上了几十年的班，工资只 比我們多几百块，而在外面只要你肯拼这么多年，不可能工资只有这些。

所以辞职的想法慢慢诞生，也可能是不甘平凡，怀着一颗热血的心，在一年之后毅然辞职。

**陈昌文：**

我们是创业者，我们早就知道上班没前途，所以我不打工。
