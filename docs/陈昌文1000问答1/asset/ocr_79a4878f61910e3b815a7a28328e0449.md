# 39、您给别人的东西，就别求回报

学员：

她在公司里做错事，有人敢说她什么吗？对她都是客客气气的，还 不都是给我的！
现在感觉她自己好厉害。为了一点利益，竟然什么都可 以不在乎！

陈昌文：

您给别人的东西，就别求回报。给了，就给了。给了，又想要人回报您，这
给人的感觉，就有点尴尬啦。如果您一开始就讲清楚，您给了她什么， 您要求回
报什么？这样，您也算是君子，让人欣赏。但如果您给了人家 东西，就希望别人
意识到什么，然后回报您，这未免太高看人性，太高 看别人的智慧了。

对自己要求要严格，有恩必报。但对别人，施恩不图报。
