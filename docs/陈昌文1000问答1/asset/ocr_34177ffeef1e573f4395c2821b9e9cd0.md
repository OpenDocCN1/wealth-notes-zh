# 388、只有真正领悟残酷冰冷的人，才配得上拥有温暖

学员（内部讲师）：

你说了这么多天了，还在跟陈-老师绕这个问题啊，我都服你了。

陈昌文：

有些人不喜欢正视问题。

他们自己喜欢逃避，而不是从残酷冰冷的现实去理解这个世界。只有真正领悟残酷冰冷的人，才配得上拥有温暖。

# 389、再过十年，您就知道您能不能改变命运了

学员：

总有人会改变命运的。

陈昌文：

一看说这话的，就是年轻的小孩子。等您社会上混几十年，您就不聪 慧了。跟您一样的学生蛋子，都是豪气冲云，认为自己很厉害，没关系，等 您多走几步、再过十年，您就知道您能不能改变命运了。
