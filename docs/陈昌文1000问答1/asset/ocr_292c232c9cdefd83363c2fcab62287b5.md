# 287、 开始一个人猛干，精通了业务，就团队猛干

# **学员：**

老师，到底如何赚钱？

我认为，赚钱的核心，不过是争分夺秒的拉流量，聊天塑造价值而已。说到底，就是开始一个人猛干，精通了业务，就团队猛干。然后利润就高了。
