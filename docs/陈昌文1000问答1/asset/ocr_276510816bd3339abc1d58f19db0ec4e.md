# 292、地狱众生总是欢乐

学员:

其实我很想跟她说，全是自己的原因，搞不清不赚钱的核心问题，换做什么也做不好。没敢说，怕她们听了伤心。

陈昌文:

只跟本来就很赚钱的人聊天、说话、帮助他们。对于不赚钱的人， 他们的情感、精神、物质、能力、道德，各方面都是有问题的，他们如 一个巨坑、黑洞，您填不满的。

为什么不去帮助那些需要帮助的人，而帮助那些根本不需要帮助 的人呢？赚钱的人，才需要帮助。不赚钱的人，他们根本不需要帮助，他 们的欢歌，就是陷入悲哀。他们的一生，演奏着悲哀的欢歌，您别同情 他们，您才是那个可怜的人。
