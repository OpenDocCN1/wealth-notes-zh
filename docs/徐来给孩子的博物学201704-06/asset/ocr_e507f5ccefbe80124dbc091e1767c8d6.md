在我们人类的眼中，世界是五彩缤纷的。这是因为，我们眼睛里有五种细胞，对三种特定颜色光线很敏感：红色、绿色和蓝色。这三种光彼此混合形成了我们所观察到的缤纷世界。今天我们要说的，就是其中一种颜色的故事，蓝色。

为什么要单独拎出蓝色来说呢？因为，蓝色曾经是一种非常难得的颜色。因为特别难，又因为很贵，所以，它总是被用在一些比较重要的形象上。所以，有些特定的蓝色，又赋予了特殊的含义。听完蓝色的曲折历程，你就会明白，为什么蓝色是一种特别迷人的颜色。

# 珍稀的蓝颜色

人类很早就开始画画了，在欧洲，考古学家们发现了很多洞穴壁画，是古代的人类画在山洞的石壁上，内容常常是和他们打猎行为有关。

这些洞穴壁画当中，最早的已经有四五万年的历史了。如果我们多一些这些壁画来看，会发现，其中的颜色大体上就是三种：红色、黄色还有黑色。原因很简单，这三种颜色非常容易得到。红色往往混合有铁的矿物颗粒，红色的铁矿石很容易找到，只要混有更红一点的红色，那么可以选择朱砂；黄色，则和一些地方的土壤有关系，也可以使用雄黄之类的矿物；黑色就更简单了，把树枝烧焦，我们就得到了黑色的画笔。

这个时候，如果再加一种蓝色，那么理论上说，画家就可以调和出各种各样的颜色来了。可问题就出在蓝色上。

![](bbox=[0.04, 0.58, 0.95, 0.68])

要说蓝色难弄，其实也不见得，因为人们很早就发现，可以从一些植物当中提取蓝色的颜料来，有可能会听说过有一种东西叫做板蓝根。板蓝根就是板蓝这种植物的根，听名字就知道，它可以做蓝色的颜料，除了板蓝之外，蓼蓝，茜草也同样可以做成蓝色的颜料。因为，它们实际上都含有同一种成份，那成份是蓝色的。不过，这种植物中的蓝色有一个问题，就是颜色不稳定，很容易褪色。如果是用来染布呢，做成衣服，那还好，褪色就褪色吧，大不了裁剪新的布料，做新的衣服。可是有些东西的颜色还是越持久越好，比如绘画作品，尤其是壁画作品。人们绘制这些作品，都是希望在一百上千亿保持鲜艳的色彩的，要是隔几年就要重新上一遍颜色，那可就不太好了。

后来，为了给颜料的问题，也有人给解决了。解决它的是古代埃及人。实际上，古代埃及人在绘制壁画的时候，就使用过蓝色。而这个蓝色是非单鲜艳的，古代人一画就是上千年，不过遗憾的是，到公元4世纪的时候，也就是 大都在1600多年前，这种蓝色颜料的配方失传了。没有人再知道是怎么配出来的了，所有人都傻眼了。在壁画当中，蓝色就此消失了。

# 埃及蓝的诞生

后来，颜料制造商和科学家们一直尝试着找回这种色彩蓝的配方。他们尝试了各种各样的可能性，后来才慢慢意识到，这种蓝色很可能是某种含有铜的矿物，跟一些其他的原料混合在一起制作而成的——这很可能就是人类制造的第一种合成颜料了。

到了19世纪，意大利人才再一次在壁画中重现了这种颜料，并一直沿用至今。后来，这种颜料呈现的蓝色，被命名为埃及蓝。

可是，埃及蓝的配方失传到被重新发现的这一千多年里，绘画艺术家们怎么办呢？那个时代，艺术家们会使用另外一种矿物颜料——群青。青紫是一种非常独特的一点和蓝的混合，它是一种非常迷人的颜色。迷人，不仅仅是指这个颜色很好看，还指它价值昂贵，让人着迷。因为制造它的原料，是宝石。

![](bbox=[0.04, 0.00132, 0.95, 0.0014299999999999998])

这种宝石的名字，叫青金石。对古代的欧洲人来说，它仅仅出产在阿富汗的山区。因为石墨显得很少，因此变得非常昂贵。把宝石研磨成非常细的粉末，再和油脂或者蛋黄混合，那么可以合成一种非常雅致、鲜明的蓝色颜料。这种颜料被称为“群青”。

群青稀少昂贵，在古代的欧洲，是非常受限的。所以，只有在绘制最重要的人物和最重要的场景的时候，才少会点一点群青。这种情况直到18世纪初才得到改观——不要误会，这个情况的改观并不是因为颜料商人们又一次配出了“埃及蓝”。这8成就还需要再等100年才能得到。

在18世纪的时候，一种新的蓝色颜料出现了。这是蓝色的发展史上的转折点，说它改变了历史也不为过。

# 普鲁士蓝的发明

这种蓝色的发现者，名字叫做大迪恩巴赫，是（德国人）。当时，他为一个名叫冯侯尔的人工作。这个狄欧尔克可是个重要人物。他那个年代德国非常有名的炼金术士。他经常的实验一直在尝试着做各种各样的炼金实验，副产品是各种化学反应产物。迪恩巴赫的工作，是负责炼金术士产红色的颜料。不过，在一个偶然的机会里，他在使用合在一起了的老板狄冯尔发明的一种原油，结果，神奇的事情发生了，颜料变成了蓝色。经过处理，他获得了一种新的蓝色颜料。经过一系列的测试，迪恩巴赫和老板狄冯尔发现，这种颜色遮盖能力非常好，于是开始推广这种颜料。因为是在德图发明的，后来德国的颜料名称穿过蓝是蓝色，所以，我们的颜色都是普鲁士蓝。普鲁士就是德国的另一个名字。

普鲁士蓝的发明，第一次为画家们提供了便宜而明亮的蓝色颜料，着色能力一点都不比群青差，但是却便宜了太多。这一点完全改变了艺术史。画家们开始在自己的作品中大量使用蓝色。这在这样的颜料越来越便宜，甚至成为最廉价的颜料之一时，有一些自制调的画家会开始用这种蓝色作为他们自然的背景，甚至使用一种著名的班哥画家华加索斯都经历过一段非常著名的“蓝色时期”。普鲁士蓝甚至影响到东方的艺术。在日本，最著名的浮世绘家葛饰北斋就是这种颜色，绘制了自己最出名的一幅作品：神奈川冲浪里。
