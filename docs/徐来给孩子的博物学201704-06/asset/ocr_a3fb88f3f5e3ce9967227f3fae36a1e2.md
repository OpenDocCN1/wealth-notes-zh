# 热爱旅行的鸽子

玛莎是一只鸟的名字，它是一只旅鸽，这是一种擅长长途旅行的鸽子。不过我们现在很难看到这种鸟了，它们已经灭绝了。

旅鸽是世界上市最大一只旅鸽。

旅鸽是一种生活在美洲的鸽子，它们生活在美洲的广大地区中，不停地长途迁徙寻找食物。最初，欧洲人并不知道这种鸟的存在，进入美洲之后，他们见到了这种鸟，进城的旅鸽场面之后让他们感到很惊讶，所以就给它们起了旅鸽这个名字。

![](bbox=[0.15, 0.49, 0.85, 0.62])

旅鸽飞行的场面真的很壮观。因为旅鸽曾经非常多，多到什么程度呢，19世纪有一位博物学家曾经遇到过一大群旅鸽，他们以为这是一道飞龙卷风，研究家估计，那时北美旅鸽的总数量，可能高达50亿只。而且，旅鸽特别喜欢聚集扎堆在一起，无论是起飞还是休息，都爱聚集在一起。

所以，这些旅鸽构成了非常庞大的鸟群，每个鸟群都可能会包含几百万只旅鸽，如果整群旅鸽同时起飞，阳光也会因此被遮蔽。

# 不绝的枪声

但也是正是在旅鸽数量最多的时候，欧洲来的人开始了对它们的大规模猎杀。旅鸽的肉很肥，特别是当它们为了躲避食肉类的西部地区的猎人们猎杀时，欧洲人利用这个特性，为了获得更好的旅鸽肉，猎人们开始利用一些很极端的办法来猎杀它们。比如，他们还会找到它们的栖息地之后，然后在这里布置下捕鸟网，等旅鸽群返回栖息地之后，再收网。用这种方法，猎手们甚至可以以极小的成本捕杀掉几百万只旅鸽。

一方面是在生存的空间快速的消失，另一方是旅鸽的数量在被快速地下降。很快，曾经旅鸽的数量被描述成下降了很快，曾经是旅鸽数量的描述成下降了很快，曾经旅鸽... 如果你想打猎，根本不用开枪，只要飞到它们头顶就有一只，就能很容易地打到。当旅鸽群变得稀疏起来之后，人们再也看不见遮蔽太阳的飞鸟。

这种情况一直持续到1840年前后。终于，人们注意到了这个问题的严重性。他们根据一段时间以来旅鸽数量的变化，推算出，按照当时的速度，大概只要再过50年，曾经是世界上数量最多的鸟类旅鸽就将彻底消失。这些人决定行动起来，保护这些鸟类。

几年之后，有几位学者向立法机构提交了一项议案，要求将旅鸽列入保护。但是，这个意见很快就被驳回了。立法者非常傲慢地想，难道还需要保护吗？它们到处都是，随便找一个开阔地，都能看到很多旅鸽。

无法得到法律的帮助，旅鸽的数量继续快速下降。到1870年前后，鸟类学家们发现，旅鸽已经不再出现在野外了。又过了十几年，到1890年之后，甚至连关于旅鸽的记载记录都很少听说。

# 玛莎：最后一只孤独的旅鸽

1900年3月22日，这是不平凡的一天，值得我们永远记住。鸟类学家们也永远不会忘记这一天。这一天，在美国俄亥俄州，一个叫做派克的男人，在一位年轻的猎手，用一支步枪，打落了一只旅鸽。这是世界上最后一只野生旅鸽的记载。随着猎枪的最后一声在野外发出响动消失了。

科学家们早就预料到了这一点，因此早就在考虑通过人工饲养的方法，让这个物种留存下去。大概到1880年前后，尽管当时野外已经很少见到旅鸽了，但芝加哥大学的一位教授，还是设法找到了一些，并将它们送到了动物园里。在动物们身上，并繁殖了动物繁殖了后代。

不过，不知道是因为饲养技术不佳，还是旅鸽并不适合人工饲养的环境，经过几代的繁殖，它们的数量越来越少。就在野外的最后一只旅鸽被杀死之后没几年，人工饲养条件下的旅鸽也彻底陷入了窘境，最后，一对能够配对繁殖的旅鸽双双死亡，只留下了它们的一小窝旅鸽了。

不久，到了1910年，有人人工饲养的旅鸽全都死去了。世界上只剩下了玛莎。

# 博物学家养成记

玛莎死后，被制作成了标本，陈列在美国自然历史博物馆里。我到现在的时候，正好上它去世100周年的纪念日。玛莎和另外几只旅鸽的标本被在玻璃展柜里。向路过的每一个人讲述这个，几乎是活生生被人类吃光了的物种。
