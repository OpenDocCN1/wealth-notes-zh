# ## 扩援，Q-W-E-R-T-Y

电子邮件不是一个特别古老的东西，比写在纸上的信，那肯定是要年轻多了。现在我们发电子邮件，都是通过互联网，但是第一封电子邮件出现的时候，全球互联网还没影儿呐。那是，在1971年一个叫汤姆林森的英国教师，通过自己编写的计算机程序，向同事的电脑发送了一段信息。这段话，后来被大家认为是第一封电子邮件。

那么重要的一个具有里程碑意义的电子邮件，里面一定写了很多的内容吧？这时汤林森写的是什么吗？后来有人去问汤林森，他说两个字，啥是机器人，机器人说，应该是Q-W-E-R-T-Y？汤姆林森想了想，说，应该是Q-W-E-R-T-Y吧。O-O。哎，他发的是东西字？难道是一码密吗？

等等啊，你别觉得这一组字母很耳熟啊？Q-W-E-R-T-Y……这不就是键盘最上面一行从左到右的字符吗？呵呵，确实是这样，汤姆林森的电脑也有键盘，但是当时，能随手键了这么个字母串上来。

这组Q-W-E-R-T-Y的字母，正是我们现在最常用的键盘的开头几个字母，实际上，这几个字母串在一起，中文的读法是扩援，所以，我们现在键键盘就被称作键盘。

![](bbox=[0.15, 0.54, 0.85, 0.7])

键盘是用来打字的。说起来，你打字应该打得不错。那你有多少字测试过呢，一分钟之内，能打出多少字？我自己也写个一字，我打字水平一般，理想的情况下，大概每分钟能打150个汉字。据说，有些高手打字有个叫，每分钟可以打200个字。那个速度，听起来一定是哐里啪啦，哐里啪啦的。

但是，你想在刚开打字打字的太慢了，你想想，Qwerty键盘实在是太用了，那些字母根本就是乱排一气，而且有些特别费事的。你看，这个字母A，明明是我们最常用的字母之一，它要么在手指，特别别特别难对。但是啊，放在了左手的小拇指上。右手也是一样，右手在我们最常用的两个手指，就是食指和中指的位置。这两个位置是R和K。这两个字母，其实我们在拼写中很少用到的两个字母。但是R和N的下方就是我们的M，M是常用字母。N在输入英语时更常用，这两个字母，在英语，输入出现的概率是比这两个字母多，N的使用频率非常高，不但要在左手，出现在前面，也要作为韵母出现在后面。像是拼写西南西北的南，N就出现了两次。

这样的问题啊，一点都不复杂，这个Qwerty键盘，用上前两行，都能注意到。可是，为什么最初设计这个键盘的人，却还是让人往这个火坑里跳呢？
