# 分类学·植物 | 桃树越老，桃子越好

世界好大，奇妙的事情每天都有，和我们一起去发现吧！

我的家乡，是一座江南的古城。江南，自古以来就比较富庶，所以会有很多好吃好玩的特产。不过，在我的土产当中，自己最喜欢的是桃子。我家乡出产很有名的水蜜桃，不但清甜多汁，更重要的是，个头儿非常大。普通大小的桃子，都有一个成年人两手握在一起那么大。一些特别大的，甚至有双手指尖那么宽。手心桃起来的那个大小。

其实，桃子是一种原产在中国的水果。野生的桃子几乎遍布整个中国。在长江、 在七八千年前的时候，当时生活在长江流域的人们已经开始吃桃子了。到了太桃3000年前，江南出现了人工栽培的桃子品种。

尽管已经开始人工种植，但在古代中国，桃子还是一种比较野生的水果，尤其是在北方地区，大桃好饭的桃子大容易见到。通常是达官贵人们才吃得出的东西。所以有的时候，好吃的桃子会被用来做一些其他的事情。

# “二桃杀三士”的故事

在战国时代，山东省这个地方有一个古国，叫齐国。齐国是那个时候非常强大的一个国家。国王手下有很多名将，他们统率着非常强大的军队。这些将当中，有三位将军的军队最多，功夫最高。不过，三位将领都有骄横，仗着自己控制着军队，而且战功高，可以慢慢地吃掉其他的大臣们提出来，齐宣王手中有一位文官，一看这个可不行，现在他们看不起国王了吗？那发展下去，岂不是要看看能不能夺国？ 那还用得了手，不就是主意，让齐王杀掉掉这三个将领，免得他们以后造反。可是这三个人本事很大，又没有明显的过错，怎么来啊？

正好，这个时候有人向齐王献上两样美味的桃子。文官说，这个机会好，于是就建议齐王，说手把这两颗桃子，分给三位将军当中功劳最大的两位吃。其中两位将军很开心地接受了这份功劳，然后各自拿了一颗桃子。第三位将军急了，找不到机会，说你们两个功劳最大，我也多，可能还不如我，怎么就把桃子吃了。那位是一级，有的有成就，却很谨慎。可是桃子已经吃掉了，再吐出来也不体面。于是，一怒之下， 干脆拔出剑来，杀了，人都自杀了。

第三位将军一看，你们俩全自杀了，那么我也不杀，不是显得是我逼死他们了吗？干脆我也自杀算了，把宝剑一横，也死了。这样，这位文官就用两颗桃子，杀死了三将大，好玩法，两个人的性， 气也是大，一言不合就会杀自己。

# 桃子属于蔷薇科

其实，桃子不但好吃，桃树开的花也好看。不过，很多人分不清是桃花和其他几种相似的花，比如梨子的花，李子的花，樱花等等。这一点却不好弄，因为它们都是同一个家族的，就是植物学上讲的蔷薇科。桃子的花，桃花木，其实桃木也是相当好的木料，这些木材相当坚硬，还相当富有弹性，所以是雕刻用的好材料。

![](bbox=[0.2, 0.97, 0.8, 0.0010500000000000002])

不过，桃木有个致命的问题，你自己找棵桃树看一看就知道了，桃树很多地方都当做园艺植物种植的，所以很容易见到，你一看就知道了，桃木个子很矮，树个也直来，还会不正。总是扭来扭弯的。这就是所谓的“不材之树”，没办法弄成大块的木板，也不能做成大柱子， 只是大材可用，桃木虽然不材，但能用来雕刻，或者做成小玩意儿，派不上大用场。

![](bbox=[0.2, 0.00116, 0.8, 0.00124])

![](bbox=[0.2, 0.00125, 0.8, 0.00133])

不过，古代中国人给桃木编出来一个特别的大用途：驱逐恶魔。你看，电影，小说，或者其他文艺作品里面，要是是描绘一个法师或者道士，去驱赶那些图谋不轨的鬼的时候，总是要到到大量的桃木制作的东西，桃木是用来和鬼怪们斗法斗争的宝剑，甚至桃木剑。

桃木这种驱除鬼怪的特性，至少在汉朝就已经出现。 在汉朝有一位作家写的一本很有名的书， 记载了这样一种故事： 在西苍茫的东方大海上，有一座非常大岛屿，岛上长着一棵巨大的桃树，树枝蜿蜒盘曲很长很长。东北边的树枝，往地面垂下，形成了二扇门，这扇门是鬼门。所有的鬼怪出入人间，都要走这个门。这扇门有两位神仙看门，一个叫神荼，一个叫郁垒。

这两个神守着这鬼门，监控各种鬼怪，如果有行为不端的鬼怪，就抓住它们，喂给老虎吃。 因为这个特性，所以各种鬼怪对桃木非常害怕， 或者，知道这个鬼怪的，在画面上，神荼郁垒二门，也是自有的门上，想着看着这两位神仙的能力，吓得各种坏法。后来，桃木就成为了打击鬼怪的重要武器之一。

用来打击鬼怪的时候，古人相信，从活得越久的桃树上砍下来的桃木，做成的桃木剑，效果最好。 出于同样的心理，他们认为，桃树活得越久，上面结出来的桃子也就越好吃。 刘念《西游记》， 西天故事，玉皇娘娘有一亩桃园，蟠桃树有三种桃子，分别要三千年、六千年和九千年，才成熟一次。其中，桃树寿命最奇特，不能想其中，而且最有最奇的功效。不过，这样的说法，完全是古人的想象。

# ——博物学家齐成龙——

树木是植物的动物， 有生命，但寿命短。 当然，也有自己生病死亡的规律。 就桃树来说， 大多数桃树，能开完花结果的时间，只有二十年左右。

最见见的桃树品种，一般在种三年左右的时候，开始结出可以吃的桃子， 并且在10岁之后的时候会将逐年增加，并且在10岁之后的时候达到顶峰。 然后就开始走下坡路了。所以，如果真的一棵桃树活到3000岁乃至更长的年龄，那么它基本上能能繁果就好，开花结果，那根本就不没有可能。

如果有机会的话，在种植桃树的花园里捡一些桃树的树枝回来，把树去掉，然后用小刀刻一 刻， 看看你能不能用桃木来做一个小桃木剑吧。
