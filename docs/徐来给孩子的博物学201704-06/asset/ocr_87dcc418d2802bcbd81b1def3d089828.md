# 遗传学·植物｜连僵尸都害怕的科学家是谁？

世界好大，奇妙的事情每天都有，我们一起出发发现吧！

你玩儿过《植物大战僵尸》这个游戏吧，或者至少知道这个游戏吧。这可能是最出名的一个塔防类的游戏了。在游戏中，不同类型的僵尸会向人类发动进攻，而所有植物中，最有效的一种是豌豆。因为在游戏当中，豌豆是一种攻击型的武器，名号叫做豌豆射手，它能发射豌豆，像枪一样击中僵尸。除了普通的豌豆之外，还有像冰冻豌豆、双发豌豆、三发豌豆和四发豌豆豌豆这样的增强武器。

这个游戏最流行的时候，有人拿这个作为题目，编出了一个科学家有关的笑话。说，僵尸最怕哪个科学家呢？答案是奥地利遗传学家孟德尔，因为孟德尔在院子里种满了豌豆。僵尸吃了豌豆，要挨僵尸我也能。可是，孟德尔为什么要种那么多豌豆呢？这个问题的点儿说来话长了，而且，孟德尔种的这些豌豆还解决了一个跟我们每一个人都有关的大问题。

# 你见过黄色的豌豆没有？

尽管豌豆很无聊，我们每个人的外表才不至于让豌豆到某些地方，无非是那几种可能性。比如，有些人是直发，有些人是卷发；有些人有单眼皮，有些人是双眼皮；有些人有酒窝，有些人没有酒窝。其实动物和植物也有这样的情况。比如，豌豆的颜色也都有，有些颜色，但没有黄豌豆。可是也常见到冷冻袋里买的是紫豌豆、白豌豆，那些里面裹着光的，而且是豌豆籽也全是绿色的。

可是等你看豌豆看得多了，就会发现，豌豆也有极少数表面并不滑，皱皱的，还有豆是紫色的。那为什么起皱的豌豆、黄色的豌豆，不如光滑的豌豆和绿色的豌豆常见呢？

孟德尔也注意到了这个问题。他在200年前出生在一个农民家庭，从小看着家里种地，种地豌豆和样也很正常。虽然他生活在一个农民家庭，但是他还是读到了书。上学读书时，不过，毫无疑问，穷苦的孩子交不起学费了。怎么办？那这个时代就万一人一个解决办法，就是进人教会。教会有钱，可以为他继续学习。所以孟德尔加入了天主教堂，成为了一名神职人员，然后就可以上学读书了。

# 性状是成对出现的

在学习的过程中，孟德尔就注意到了同一种植物的不同个体，在外形上的一些差异。他就想去看这个内容，而研究的内容，大多是豌豆，这里需要说明一下，很多人，也包括一些教科书，会把西方的天主教当成一个反对、对抗、迫害科学家的这么一个机构，对于教会有确实有迫害科学的行为，但这并不是全部，教会也会鼓励研究和鼓励创新。孟德尔是其中最早的一个，这样的情况在德国历史中，满清时代，很多西方科学的实践者都来自传教的耶稣会士带来的，中国还有一位历传教的天文学家和数学家，叫徐光启，做官也做到很大。上个世纪有个名唤徐家汇，徐家汇的徐就是徐光启他们家，这个徐光启也是个基督徒。

好，现在孟德尔要种豌豆打僵尸了，对。这是一种很做到的做法。他从小熟悉的商人那边一共买到30多种看上去不一样的豌豆，然后选其中的22种参与实验。这些豌豆，都各有自己的特征，比如有些是皱的，有些是圆的；有些是绿色的，有些是黄色的；有些茎杆高一些，有些矮一些；有些开花在茎上，有些开花在近上，有些茎杆上有颜色，有紫色，有白色，有些子茎杆上没颜色。这些外形色上特征，都是一对儿一对儿出现的。

孟德尔就开始封闭它们了。比如说，绿色的豆子和黄色的豆子这一对儿，他让一颗绿色豆子的豌豆，和一颗黄色豆子的豌豆结合，这个叫交配，也就是爷爷奶奶生下一代种子，子一代，相当于爸爸妈妈生下一代。它一种像它绿色的豆子，子二代，这个就相当于子二代，也就是孙子这一代，子二代就变到黄色，子一代的颜色，在它们中间却出现了黄色的。而且，绿色和黄色的比例，差不多是3:1的样子。
