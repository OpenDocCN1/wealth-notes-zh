# 分类学 · 动物 | 北极为什么没有企鹅？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

如我间你，生活在冰天雪地里的动物有哪些，你会怎么回答呢？我猜有企鹅和北极熊一定排在最前面。我就没有想对哦？

确实，企鹅和北极熊是大家最熟悉的两种极地动物。不过，它们可不能生活在一起。一个生活在南极，另一个却生活在北极，。企鹅为什么没在南极呢？北极熊为什么没在北极呢？

# 英语里的企鹅其实并不是企鹅

第一个问题其实很容易回答，因为南极其乐他的极地很冷，企鹅不会过去，但北极就有别的南极很热，。可北极没有企鹅啊？答答可能会出乎你的意料了，北极其实是有的企鹅，只不过它的不是企鹅本土，是非常像企鹅的一种动物。它的名字叫做大海豚，实际上，大海豚也是真正的企鹅，因为英语的企鹅这个词，也就是penguin，原是指的是大海豚，而现在我们所知道的企鹅则是认为大海豚的亲戚，才改用了这个名字。不过，企鹅现在已经见不到大海豚了，它们已经灭绝了。

在英国伦敦的自然历史博物馆里，有一个珍品室——一个叫名字的地方，那里的标签都是非常昂贵的。在这里，你会发现世界上最早的一件企鹅标本，也是世界上为数不多完整的大海豚标本之一。

# 大海豚就是北方的企鹅

大海豚的故事是这样的，它们长得跟企鹅几乎完全一样，头部和背部是黑色的，而腹部是白色的，看起来脖子短粗，腿也短短，大海豚不会飞，但游泳的速度非常快。这两种相似的行为也非常相似，大海豚靠鱼捕食，而在陆地上，走路起来也比较笨，有的时候，还需要用翅膀来帮忙。

本来，大海豚这种动物没啥天敌，它们体型比较大，在海底又是活的，所以除了海豚和少数大鱼的老虎之外，它们在地面上不怕。因此，虽然它们在陆地上行动能力很差，可也没啥大问题，小日子过得挺舒服的。

不过，人类的到来给了它们造成了非常大的影响，它们的肉味鲜道，蛋也很好吃，更重要的是，大海豚非常容易捕捉，所以很快就被它们猎取对象，小规模的狩猎并不是对它们的影响。而大规模性的影响是可怕的，在有些地方，猎杀大海豚的行为甚至可以追溯到大一万年前。
