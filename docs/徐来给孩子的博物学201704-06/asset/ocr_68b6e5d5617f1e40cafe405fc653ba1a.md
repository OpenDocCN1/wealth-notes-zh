# 一个英国人每年喝3公斤茶

这三种饮料，历史都很悠久。咖啡最早出现在非洲，巧克力最早出现在美洲，这两种饮料都是在欧洲被发扬光大的，所以啊，都被看成了欧美国家的典型饮料；而茶不同，起源于咱们中国的云南，四川一带，在中国，日本都很流行，是典型的东方文化的象征。

不过啊，仔细看一下就会发现，这种东西西方文化的区别没有那么绝对。尤其是欧美国家，很多地方，人们都非常喜欢喝茶，尤其是英国人。英国人有一句英国成语，翻译成中文的意思是“我怀有茶是我”。英国人用这样的成语来表达类比我们中国人说的“我是不是茶呢？”的意思。这个表述很有意思吧，它足以说明，英国人对茶的重视。

你看数据，也是这个样子。根据统计，每个英国人，平均每年喝掉的茶叶，注意啊，是喝的，干燥的茶叶，将近3公斤——这得泡多少壶啊？而在东方呢，每个中国人啊，吃的茶叶就算不到总国人的三分之一，最多可能也就1千克啦，这是按平均数算，中国地大，人口多，可也不是都是茶喝的国家，有些地方可能还好，就算是发展中国家的话，像日本茶人，日本是发达国家了吧，可每个日本人每年喝掉的茶叶，也只比中国多一点，跟英国人相比，还要得远好远。
