徐来
我小时候经常会过一种神奇的经历，心大概是无法想象的。入夏以后，最开心的时候是从冰箱里拿出过冰棒的那一刻。棒冰方方正正的，很便宜，都用小纸卷上土方正正的。又会又甜好甜的东西。

不过，有的，有时候发生一些意外情况。开开心心地棒冰放到嘴里，还不到一两秒钟，就是一声吐出来，然后尝着手里的棒冰大喊一句：苦的。然后，小脸皱皱黑着会脸给外公：很苦的，最后再说一句，“糖精加多了”。

# 世界上第一种甜味剂

后来我才知道，糖精其实是一种可以产生甜味的食品添加剂。因为太苦的存在，有点淡淡的甜味。因为苦精糖这种苦精糖，我的印象很不好，很容易把它和别的东西联系在一起。后来，我就知道了，糖精其实是人类发明的第一种人工甜味剂。它曾经在食品工业中当扮演着非常重要的角色。后来，糖精很多医学发展了，人们渐渐地发现，糖虽然很好吃，但是都会带来很多身体上的健康风险。于是，人们开始想方设法用一些物质来保留糖的味道，但又回避了糖的影响。这个时间，糖开始大显身手了。

有意思的是，当人们开始大量使用糖精之后，再回去翻阅糖这种物质的历史过程，会发现，这个过实验居然是由一种对该现行为组成的。如果最后被发现的是糖精，或者是其他物质，被实验者就毒死而亡了——而且还是被写进实验室流程的警告材料里，向所有人展示，违反实验流程和规则，有多危险。

# 合作实验室发现糖精

直接发现糖精的，是一位生活在美国的俄罗斯科学家。他的名字用唐斯坦丁，法赫伯格。大约在1905年前的1877年，美国巴尔的摩一家专门制造和销售白糖的公司，找到了法赫伯格，说：“你来给我们做一下，我们已经知道，制造白糖，但纯度到底有多高呢。确定了这个纯度高低，才好把这些糖分级的打价格。”

法赫伯格一看，工作找上门来了，没必要这个分析检测的工作，但是却没有实验室。没有实验室也去啊！做实验啊，公司想了一个办法，就和美国著名的约翰霍普金斯大学的一个化学实验室进行了合作，让法赫伯格去这个实验室进行检测。那个实验室本身很厉害，实验室的负责人叫伊拉·莱姆森，后来当上了这个学校的校长。法赫伯格在这个实验室里，工作倒也很愉快。

没多久，糖精公司的检测任务就做完了。但是，法赫伯格自己还意犹未尽，所以，跟伊拉·莱姆森就提出来，希望能在这两个实验室继续工作，打打酱油，也可以顺带做一点自己想做的实验。伊拉·莱姆森觉得法赫伯格这个人也不错了，就答应下来了。

就这样，干了没多久，有一天，奇怪的事情发生了。法赫伯格在实验室干完活后，回家吃饭，发现食物非甜！他责怪媳妇儿不该放太多糖，可媳妇儿一脸不知所措，说一点儿糖都没放。法赫伯格看，自己吃饭的时候没有使用糖，而是直接用用手抓东西。如果用食物没有放糖，但自己觉得食物特别甜，那只有这种可能，是自己手有额外的甜味。他想了一下，又看了一下手指，果然，手上比吃进东西要甜。

# 到底违反了哪些操作规定？

你看，在这个过程中，法赫伯格违反了实验规定。首先来说，你做完全实验者离开实验室，就得走。因为有些实验室中会接触各种商品，不洗手可在实验室中会造成彼此交叉感染，先洗手，每个人都知道饭前要洗手，再洗手，你不洗手是没有用刀子、筷子、勺子什么的吃饭，而是直接用手抓东西。不洗手，也不卫生啊。
