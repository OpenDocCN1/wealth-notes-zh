# ## 泼化学·生态｜渡渡鸟真的会种树吗？

世界好大，奇妙的事情每天都有，我们一起去发现吧！

世界上有一种鸟，非常有名。它生活在印度洋的小岛上，体形肥大、不会飞，但皮肤却出现在很多电影、漫画和小说里。它就是渡渡鸟。

# ### 亦真亦幻的渡渡鸟

说到渡渡鸟，你的眼前是不是就出现了它们那肥硕、呆萌呆萌的模样？如果我告诉你，这并非真实的话，你本来怀疑的，会不会更感到惊讶？其实没那么好吧，因为人类从来没有认真地描述过它的形象。这种鸟原产于印度洋的一个小岛。后来，被欧洲人发现了。

不过，在欧洲人第一次记录它之后，才过了70年，它差不多就灭绝了—这期间根本就没有人严肃地研究过它，所以留下的，不管是文字描述也好，画像也好，都非常不可靠。而且很难说那些描述有多少是亲眼见到的，有多少是看着标本或者尸体，有多少是根据自己的讲述添加或夸张的。所以，其实没有真人的知道渡渡鸟长什么样。

更糟糕的是，我们甚至一只完整的渡渡鸟标本都没有留下来。现在，如果去英国牛津大学的博物馆，你才可能看到一套鸟的头，还有一双脚，这是人类发现保存下来的仅存的一部分。现存的渡渡鸟标本，除了头之外，就只剩下骨头和化石了。

# ### 人类是罪魁祸首

你不觉得啼笑皆非吗，这是一种很可爱的动物，可人类为什么对它表现得这么鲁莽呢？其实，在渡渡鸟出现的第一类记录的，因为人类的流动和灭绝，所以叫渡渡鸟。换句话说，在渡渡鸟之前，人们并不知道自己可以消灭一个物种。所以，对于这个物种的灭绝人类没有做任何准备。

说到渡渡鸟的灭绝，其实大家还有一中误会。因为根据船员的描述，这些渡渡鸟很肥，看起来肉很多的样子，而且，不会飞，跑得也不快，所以非常好抓。而且，大家都很容易就想到，是不是船员为了吃鸡肉才抓它们，一真再再抓渡渡鸟都抓到无以为止了。不过，事实并没有大家想的那么简单，它们可能更多是喝水。它们靠吃海鸟蛋为生，这些蛋，岛上原来就稀有的渡渡鸟生，被破坏掉了，再加上人类的捕杀，才导致渡渡鸟在那么短的时间里也灭绝了。

# ### 渡渡鸟与渡渡树的命运

渡渡鸟灭绝之后，很多年过去了。大致在上世纪70年代的时候，有个科学家叫普鲁兹，公布了自己的一个发现。这个发现震惊了科学界：渡渡鸟的灭绝，很可能会带来一个连锁反应。在印度洋的那个岛屿上，生长着一种树，很大的那种，叫坦巴拉克树。

但是一个科学家在岛上走了一趟，没发现树中这树形，看到的就是老树。这些老树中最小的大概是50岁到70岁。这老树这个年龄有意思了，大概300多岁。这个时间，跟渡渡鸟灭绝的时间好像有点契合。这一说法，通常就产生了一个假设：渡渡鸟跟这棵树的命运，一定有着非常密切的关系。就是说，渡渡鸟灭绝之后，这种树也陷入了衰退。

为了搞清楚这一点，普鲁兹开始深入研究。他发现，这个坦巴拉克树的种子外面包着很硬的壳，硬得像什么？硬是厚厚的一层，恐怕没有谁吃它，包着硬壳的硬壳，一旦吃掉后消化后的壳变得很小，那么种子消化后包着壳的壳就变小了。那么，渡渡鸟当中的一个，这小石子很可能去打开原来这个种子外壳，给它弄薄。弄出小的缝隙来。

不过，渡渡鸟还是无法完全打开这些种子，所以，种子不会被消化掉，还是会被排泄出体外。又因为这些种子在渡渡鸟体内已经被打了缺口，它们在渡渡鸟正常地生长了。这个猜想的思想，在漫长的进化过程中，这岛上便的坦巴拉克树和渡渡鸟形成了一种叫做协同进化的关系，就好两个人手拉手一起往前走一样。

为了证明这一点，普鲁兹做了个实验，他把坦巴拉克树的种子带回了家。现在还是没有渡渡鸟了，但他还好，火鸡吃形像渡渡鸟还是有几分的相似，吃它吃形像是小石子里面还薄一些。如果前面的猜想是正确的，渡渡鸟用肚子里的小石子帮它打裂那树种子，那么火鸡肚子里的小石子也应该是能做到的。他在实验中一共向火鸡投喂了17粒坦巴拉克树的种子，其中10颗成功消化了体外，另外10粒种子，有3颗成功发芽了。在这篇文章中，普鲁兹兴奋地说道，有没有可能是300年来第一粒成功发芽的坦巴拉克树种子？！

他的这个论文发表之后，引起了非常多的关注和讨论。很多媒体都报道了这个发现，还有一些厉害的科学家、作家把坦巴拉克树与渡渡鸟之间的种种进化关系写进了自己的文章中。这个例子使得如此的有名，以至于后来大家不知道叫它名字，便坦巴拉克树了——这个学名似乎又怪又不好记，大家干脆给它改名叫渡渡树。

# ### 原来，是个错误的推论

怎么样，你不也也觉得这个故事很有趣，世界果然是充满了神奇的力量？不过，你听，不幸，这个故事很有，但却是错的。你可能会问，普鲁兹是做了很深的研究，怎么会犯下错了？很不巧的是，他的文章，不是鸟类学的资料上，他是鸟类学研究的，是个体学家的资料上。但是，他是鸟类学，他是个鸟类学家，不是植物学家。所以，他看问题的方式也有偏差。他在具体的方法上也是，会偏向于鸟类学的方法。加上他急于反应，太过着急地希望把这个故事说圆满，结果忽略了非常重要的线索。比如，他没有测试火鸡吃火鸡吃进去肚子里了。然后，种子发芽到底有什么效果，实际上，在火鸡吃了，就已经有植物学家提出，渡渡鸟可能并没有处理的种子，也是有可能发出来的。

后来，又有人陆续被研究了一些数据，比如，根据当地的记录，渡渡鸟在岛上的分布，跟坦巴拉克树，并不重合；还有，对岛上树木的年轮研究发现，实际上现有很多有树木100年左右，这些树在渡渡鸟灭绝之后才落进生根的。它们和渡渡鸟肯定是没有关系的。

这又是什么情况呢？很多科学家又困惑了。随后，又有科学家把这个问题解决做了深入的研究，最终揭开了谜底。确实有很多植物，把种子交给鸟类，如果经过渡渡鸟的肠道，可能会使硬壳稍微一些。但并不是说，必须是这样才能够使它们打洞种下。实际上，对渡渡鸟来说，当地的乌鸟或者更廉价的打洞和传播种子。渡渡鸟在这件事情上，其实只是一个配角。
