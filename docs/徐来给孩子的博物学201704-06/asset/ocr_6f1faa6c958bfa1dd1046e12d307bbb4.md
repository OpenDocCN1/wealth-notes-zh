# 徐来

今天我们要说的，是你和你的对手的故事。

这个故事发生在美国。美国最著名的繁华的一条路，叫第五大道，在美国的纽约。很自省的帝国大厦就在这条路上，路的两边还有各种商店。但是令人沮丧的事情要去逛的是一家药。

这条树的必备，有很多的街道树。你逛街的时候，不会注意到这些树的。但是今天不行，今天必须要认真对待这些树。因为这里有一种树，特别的怪，一般情况下，你不不会选择它当街树。因为它的树干上长满了刺，这个刺可不是小刺，看起来就很长很刺的。能有一个人手掌那么长。每三根为一组，就这种树枝着。可以想找一下树木，如果你从街道直看去，要扶住树或者背靠它树靠一下。呵呵，这个场面还是很怪的。

# 美国皂荚树的对手

这种树叫美国皂荚。为什么要在第五大道两边种这种暴力树的呢？其实是因为这个树它本来就生在这里。

好吧，那你原来就生在这里也没办法。可是什么又长这么暴力呢？当然出来说是美国皂有什么样的影响。植物出这样的，肯定是和防御有关的。要防的其他动物来啃食树叶。但我们刚才说，这个刺很长，有手背那么长，那它一定不太密集。刺不够密集，那它就无法防御体形小一点动物。实际上，在那个地方典型的会啃树叶的动物，比如麝。松鼠，就可以很轻松地挑开那些刺。在这些动物面前，美国皂荚的防御是无效的。那它的在防御呢？

那个对手一定很大。科学家们找了很久呢，才终于找到它，它是大象。大象会吃树上的叶子，也会吃树的果子，但这都不要紧。有些科学家说，象喜欢在地上刮痒。这一点对于美国皂是个大麻烦。那么重的大象仪蹲上来，跟施工机一样，很容易就会把树刮倒。但美国皂荚树长满了长刺，大象要跳过来蹭痒痒，一定会被扎得浑身是窟窿。像个筛子一样。

现在的美洲是没有大象的。但很早很早以前，这里也有大象。这些美洲的大象形貌跟我们现在看到的亚洲象和非洲象差不多，但它们在欧洲美洲，叫乳齿象。乳齿象就是美国皂荚树要防御的那个对手。

不过，因为有长刺，乳齿象不会在美国皂荚的树干上蹭痒痒，但常常会吃掉这树上结的种子，然后把这种树把种子散播到更远的地方。它们帮皂荚无事地共同生活了很长很长的时间，和其他所有的故事一样，它们之间的平衡也会被打破。打破平衡的是我们人类。你现在知道，人类最早出现在非洲，然后一点点在世界各地扩散，大概就是1万多年的时候，他们来到了美洲。这原来是美洲的印第安人，对，就是著名的儿歌“十个印第安人”的那个印第安人。随着他们的到来，乳齿象灭绝了。有科学家认为是，乳齿象就是被人类消灭的；另一些科学家认为，乳齿象已经快要绝了，人类只不过是给它一记棺材。总之，美国皂荚树好了好的心思防御的那个对手，突然消失了。
