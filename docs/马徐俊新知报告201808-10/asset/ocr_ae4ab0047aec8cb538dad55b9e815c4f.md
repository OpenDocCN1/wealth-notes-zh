# ## 西方主流媒体如何看待苹果市值破万亿?

很多人可能会想, “万亿市值”到底是个什么概念? 为什么突然就在全世界引起这么大的震动?

《纽约时报》做了一张图, 形象地回答了这个问题。从下面这张图中你可以看到, 苹果公司今天的市值, 是美国四家最大的银行: 富国银行、美国银行、摩根大通和花旗集团的市值总和。也就是说, 美国和前国家老百姓全都扭头跳起来, 才够苹果一家科技公司打了个平手。

![](bbox=[0.15, 0.32, 0.85, 0.43])

如果你对这类比没有概念的话, 那咱们换个比较好理解的角度来对比一下大家可能更熟悉的“苹果”吧: 在推特上做了一个有趣而又直观的估算, 一万亿美金, 相当于可以买:

+   - 10亿台iPhone X
- 3.3亿台苹果笔记本电脑
- 2亿台苹果台式机
- 2千万台特斯拉Model 3电动车
- 50万套的房子, 可以买200万套...

好, 现在你是否已经了解, 市值一万亿美金的公司, 是个什么概念了呢?

接下来, 我们看看苹果为什么会在这个时候大涨。据媒体消息, 微软、Google这几家科技巨头, 第一个突破万亿美金。

根据《纽约时报》的分析, 主要有三个原因:

第一, 苹果在财报周刚发布了最近一个季度的财报, 净利润达到71.5亿美金( $1.52 billion ), 相比去年同期增加了将近1/3;

第二, 苹果公司目前掌握的现金高达2,471亿美金, 按照原来的计划, 苹果将会给股东分红750亿美金, 这给了投资者极大的信心, 有助于提振股价;

第三, 苹果在今年4月份就宣布千亿股票回购计划, 这个计划一发布, 也帮助提升了股价。

此外, 西方媒体, 包括苹果公司在自己的发布会上, 也提到了其他几个重要原因, 值得你关注。

CNBC是美国全球性的财经有线电视卫星新闻台, 是全球媒体眼中的权威, 据分析师分析, 苹果公司值钱, 还有另一个原因, 苹果快速成长的软件、服务数据以及其他服务业务。

这些业务收入在 最近一个季度大涨了31%, 总营收高达9.5亿美金。对于这一点的具体分析, 你可以参考隔壁澎湃青报的介绍。

而苹果公司在自己的报告里也说, 他们在最近的一个季度里, 手机销售总收入增加了将近20%, 其中最主要的一个驱动点, 就是苹果手机平均价格的iPhone X 的高需求。

“中国因素”也是西方媒体关注的一个方面。

《纽约时报》分析说, 没有任何公司的成功像苹果这样依赖于中国。中国是苹果在美国最大市场, 根据苹果公司的最新一季度财报, 仅在中国大陆、香港和台湾, 手机的收入就上升了19%, 高达95.5亿美金, 几乎和美国本土的销售增长速度一样了。

美国有线电视新闻网CNN也认为, 苹果的市值能冲破一万亿美金, iPhone X 和iPhone 8的销量也是重要原因, 尤其是它们在中国和日本的销售。

苹果取得如此辉煌的成绩, 谁是背后最大的受益者呢?

# ## 西方媒体眼中, 谁是最大的受益者?

《华尔街日报》直接把这个问题作为文章的目标, 而他们给出的答案, 可能会让你意想不到。

苹果市值破万亿, 最大的赢家竟然是: 巴菲特。

因为巴菲特的伯克希尔·哈撒韦公司, 持有苹果公司大约5%的股份, 是第二大股东。其实咱们都知道巴菲特向来都是不投资科技公司的, 因为他也说, 自己最不懂的东西不碰。

但巴菲特之所以投资苹果, 是因为苹果的线下零售业务。所以巴菲特从两年前, 也就是2016年一季度, 在苹果股价高达99美元的时候, 第一次购买了价值10亿美金的苹果股票, 此后, 不断增持, 最终砸下了超过300亿美元。

而当苹果的市值破万亿的时候, 巴菲特手中的苹果股票价值超过了500亿。

而除了巴菲特之外, 《华尔街日报》说, 苹果公司破万亿美金, 收益最大的就是那些从上个世纪90年代开始, 持有苹果股票的个人, 投资者。他们比苹果公司是如何起伏和信任, 如今苹果的杰出表现, 是对他们最大的奖赏。

《华尔街日报》的文章中还引用了一个故事, 我转述给你:

> > 马克·库格林是苹果相对早期的一名员工, 他当初刚从加州大学伯克利分校毕业的时候, 就能最忠实的追随者, 也是布斯的信徒, 哪怕自己已经离开了苹果公司, 但他依然自己布道创立了这家公司。
>
> 他在苹果公司上市的时候, 得到了1000股的原始股, 按照现在的价格来看, 差不多就是每股500多美元, 然后, 此1亿美金净收益大家分成股票, 差不多把自己60%的净收益都配给了苹果员工, 他的投资顾问一直在他这边卖。在过去的15年里, 始终在劝说不要这么做, 但是, 马克·库格林的坚持, 在今天得到了回报。
>
> 而报道里还提到了另一个人, 也非常值得玩味, 这个人就是约翰·斯卡利, 他是苹果公司历史的人都知道的, 他就是当年百事可乐的CEO, 被苹果的一句“你想要一升苹果味X”是眼我一成世界智慧” 所打动, 他是加入苹果公司, 后来又把乔布斯赶出苹果公司的人。
>
> 在这个世界, 约翰·斯卡利 已经把目前持有大量苹果股票, 看来不再多, 但大约100万美元, 他又开始再次买入苹果的股票, 因为他看到了苹果强劲趋势被背后的巨大红利。不知道当苹果公司市值突破万亿的时候, 他不会回想起自己当年赶走乔布斯的情景, 心里又会作何感想?

当然, 除了因为信仰苹果, 投资苹果收益的人, 对于苹果市值破万亿, 我们更多关心的是, 这样的辉煌能够延续吗? 未来的趋势将会如何呢?

# ## 万亿市值背后, 代表着什么样的未来趋势?

在西方, 主流观点是看好苹果的, 比如《福布斯》杂志就统计, 由于下月苹果将会发布新一代iPhone, 苹果的股价将会继续上涨。

但也有媒体表达不同的看法, 比如彭博网络, 它是全球家大的财经资讯服务提供网站——彭博新闻集团办的网站。它给出的看法是: 苹果是苹果的顶点, 也是下落的起点, 苹果的辉煌可能无法延续。
