# 今日报告：为什么你会觉得这个进步的世界越来越糟？

我们对这个世界知之甚少。不要满足于像大多数人那样草草了事。

—史蒂芬·平克

徐骏捷

从很多层面来讲，这个世界变得更好了，而他们之所以感觉越来越糟，是一系列心理机制在“捣蛋”。

今天我们分为三个部分：

+   - 世界到底变得更好了，还是更糟？
- 为什么人们总觉得从前比现在好？
- 应该如何正确认识这个世界？

这个世界，是不是越来越糟糕了？

如果你也有这种疑问，那也许今天的内容能帮到你。最近，《纽约客》杂志上的一篇文章，专门针对这个问题给出了回答。

这篇文章的作者书亚·罗迪恩，是《纽约客》资深编辑，他向我们介绍了一本今年特别火的书，书名叫做《启蒙时刻》(Enlightenment Now)，这本书的作者就是鼎鼎大名的史蒂文·平克。

史蒂文·平克是著名的认知心理学家，也是世界级的语言学家，他的名气有多大呢？2004年，平克被《时代》杂志评为全球最具影响力的100位人物之一，2010和2011年，他两次被《外交政策》杂志评为“全球顶尖思想家”。

比尔·盖茨是他超级粉丝，他说平克的这本《启蒙时刻》，他最近拿来反复地“一书三读”。今年6月，盖茨还答应过《纽约客》的客座主编、盖茨发动自己的同事、邀请各行各业的高手来统一讨论一个话题——这个世界到底是变得更好了，还是更糟了？其中就有平克。很多人认为，在这个问题上，平克的观点非常值得参考。

如果平克参与了《时代周刊》的那次谈话，当成一次探讨和分享，那么今天这篇文章，就是平克通过《启蒙时刻》，来系统梳理他的观点和核心思想，可以说是一个升级板。

今天的金句特别多写得特别多，但是稍有点长，可以我先来关于子，在文章的最后告诉你。

# Ⅰ 世界变得更好了，还是更糟了？

平克的新书《启蒙时刻》，一个主要的结论就是，从许多层面来看，我们的世界是真的变好了。

平克引用了大量数据，从16个方面，详细地剖析了这个世界进步趋势。

比如说，从人类生存的基础层面来看，全球人均寿命从19世纪中的30岁，增长到了现在的73岁；医疗卫生条件大幅增加，新生儿及孕产妇的死亡率大幅下降，儿童的营养状况得到全面改善，孩子们能受到更好的教育，受教育的机会也少得多了；灾害和犯罪的收入，人工环境变得更富裕流动，退休平均也更长前了，以美国和西欧为例，1870年的工人，平均每周要工作60个小时，而现在是平均40个小时；环境污染状况得到改善，绿地面积扩大，野生动物保护区的数量也增加了。

与此同时，平克在书里引用了2015年底的一项民意调查，这项调查是在14个国家进行的，这些国家有，有英国、美国、澳大利亚、小国有丹麦、芬兰等。调查结果就是，大多数人的感觉都是“世界在走下坡路”“越来越糟糕”“大不如前”。

那你看，既然平克已经从数据上证明了世界没有这么坏，但为什么普通人的感觉，却恰恰相反？这到底是怎么回事？

# Ⅰ 为什么人们总觉得从前比现在好？

关于这个问题，《纽约客》的这位编辑，帮我们从平克的书里，归纳了三个主要原因。都和人类的心理机制有关：可得性法则、怠忽之罪、对自我和世界有主身的评判标准不同。下面我们一个一个来说。

首先来看第一点，可得性法则(availability heuristic)。这个词儿听起来挺绕口，可能有些人不太理解。在心理学里，它指的是人们在判断某一事件发生的可能性时，仅仅根据某些比较容易想到信息，或者容易联想到自己信息，做出判断。比如说，你越容易想到信息，你就越觉得它可能发生。这种可得心法，很容易产生偏见。

举个例子，你去海边游泳，本来被鲨鱼吃掉的可能性并不高。但你最近频繁看到媒体报道的新闻，让你担心鲨鱼伤人。在新闻报道中，人们总是喜欢猎奇，所以媒体经常报道鲨鱼咬人。这样久而久之，你就很容易高估在海里被鲨鱼咬伤的可能性，觉得去海边游泳不太安全。

为什么会这样呢？因为在进化过程中，人类的大脑过于自我保护的本能。往往会对风险更加敏感。这一点，现在被很多媒体有意识地产利用。通过传播“坏消息”来争夺人们的注意力，提高点击量。在新闻中，所有令人不安的话都叫“坏消息”，所以我们会各种媒体平台，最常见的往往是那些耸人听闻的爆炸性新闻。

可想而知，当人们常年被这样的坏消息包围，不间断地宣泄焦虑的冲击，你自然会觉得，这个世界好像危机四伏，问题不断。这，就是“可得性法则”带来的后果。

第二点叫作“怠忽之罪”（sin of inaction）。这个词出自但丁的《神曲》中描述了九层地狱，其中第九层地狱的名字，就叫怠忽之罪。

平克在书中说，我们对世界的进步，人们不知道意识到。他变得更好。人们就像躺在船上，一旦遇到问题和危险，人们就极度敏感。但只要有进步，很少有人会主动去思考，即便算开背后，有多少“无名英雄”做出过贡献。

平克以天花病毒为例。天花病毒在整个20世纪，曾夺去了7亿多人的生命，而现在打一针疫苗就行了。这可以说是一项非常伟大的贡献吧？可是有谁为这项不可估量伟大贡献命名了呢？1796年发明出天花疫苗的那个科学家。

你可能会想，平克是不是在指责人类都是“白眼狼”，不感恩。不，平克明确指出，“不感恩”是由人的心理机制和生理机制共同决定的。

平克提出了一个概念叫“set point theory of happiness”，我们可以理解为“幸福点理论”。它的指是，不管你的幸福基准线是低还是高，都会回到一个平均值，也就是“幸福点”。也就是说，即使你有天大喜，高兴过了也就消失了，不会一直high。

同样的道理，一个人假如得了心梗，被抢救回来了，他当时可能会感到极其庆幸，对生命会感到感恩，但等病好了，他还是会慢慢回到之前的怠忽状态，不会一直保持“捡回了一条命”的感觉。哈耶克在《自由秩序原理》中通过“幸福点”理论来分析心理，认为“心理适应”是人类进化中适应环境的结果。

出于自我保护的本能，人类还有一个生理机制，就是选择性遗忘。对美好的事物是“过眼云烟”，对痛苦和危险的事物却“记忆犹新”。随着时间流逝，那些曾经感到的负责色彩，也就慢慢消退。最终，你能记住的大多是那些美好的回忆。

所以，从心理的角度来说，人们很难对这个社会保持感恩，一直保持敏感，而会跟随时间流逝，慢慢习以为常。同时，对生理上而言，对不好的记忆又会更易消退，所以我们不怎么感觉，记忆还会逐渐消退。

第三点，人们对自己和世界所使用的评判标准不同，简单来说，就是人们对自身有主身的评判。
