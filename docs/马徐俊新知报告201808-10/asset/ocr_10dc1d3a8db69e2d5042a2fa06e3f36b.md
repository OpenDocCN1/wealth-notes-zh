# 098报告｜人工智能正在改变法律行业

今日报告：人工智能正在改变法律行业

就像医生和医疗行业之间的关系那样，AI不但不会取代人类律师，反而会提高律师的能力。——《卫报》

# 徐轶星

杰拉德·赖特利在《未来简史》里曾说，法律、律师正在被人工智能取代的可能性很大，尤其是那些只需遵循单调的标准化协议、不需要任何创造力的普通律师。这个说法，如今正在变成现实。

今天的议题分为两个部分：

+   - AI能提供哪些法律服务？
- AI将如何影响法律行业的未来？

《经济学人》最近发表了一篇文章，标题叫《顶尖律所进入AI时代》（Law Firms Climb Aboard The AI Wagon）。文章里说，纽约和伦敦的顶尖律所开始启用方案，计划让人工智能来完成一些法律工作。这样既解放了律师的劳动力，又能降低法律咨询的费用。而越来越多的创业公司，也瞄准了人工智能的潜力，正在研发机器人律师为人们提供法律服务。

很可能，在不久以后，咱们要是需要打官司，只能去咨询一些律师不太，提供纠纷与纠纷、机器人律师则能帮人省却一大麻烦——只需用机器人为我们准备好所需要的法律文书。

不仅如此，机器人律师还能告诉我们，要是打官司的话，胜诉率是多少，之前有类似的案例可以作参考和依据。

所以，不论是从事法律工作，今天的内幕都值得关注，因为它与我们的生活和息息相关。通过这篇报告，你会知道，AI到底能为我们提供哪些法律服务，它又会如何影响整个法律行业的未来。

# AI能提供哪些法律服务？

你之前可能听说，AI已经开始利用在法官、仲裁员领域，具体是用AI在什么领域，怎么用，我们并不清楚。而《经济学人》这篇文章最吸引我们的是介绍了AI在律师业上的巨大用途。

+   - 审材料
- 对案件结果的预测
- 诉讼策略的选择
- 文书起草

—— 全套的服务，AI都能提供。

我们先用AI如何提升法律检索的效率。首先律师在打官司前，要准备大量的文书材料，像相关案件先例，整理相关判决或先例……这些工作方法都要求极高的细致度和律师的专业理解，既费时费力，在很多律师的法律实践中……会看到律师熬夜加班。花大量时间查找材料的场景，现在，这种事都可以交给AI来做，AI的高效、准确、专注让律师们可以专注于更重要的思考。

其次，AI还能大幅提高材料审核的准确率和速度。AI在多个大型机构的案例中，可能要在几百个文件里找出一两个不合规的文件，如果人工来做需要花两周，而AI只需要20分钟，准确率还更高。

更厉害的是，AI还能从案列里找出律师们不易发现的疏漏。例如，美国法律AI平台LawGeex今年举办过一个比赛，让AI和20个顶尖律师比赛，比赛内容是在48小时内审核一些合同，找出风险点。AI的准确率是85%，而人类律师只有75%的平均水平。

由于AI在法律服务中的优势非常明显，所以，纽约和伦敦的顶尖律所已经开始计划引入AI，来优化律师的工作流程和效率了。

再次，AI还能对案件的结果做出预测，如果前两种应用都是AI为律师行业提供的“基础设施”，那么这相当于行业级的“超级服务”。硅谷的一家叫Lex Machina的创业公司，就提供这样的服务，这家公司的利用机器学习和大数据来，帮助客户评估诉讼风险，预测案件结果。比如，AI可以告诉你某个类型的案件胜诉率是多少，原告能获得多少赔偿金额等。国际顶尖律师事务所Fish & Richardson，就采用Lex Machina的分析工具，来预判他们的医疗纠纷案件，结果比人类律师更准确。

AI在法律行业的最后一个主要应用，就是机器人律师服务。一些科技公司目前已经在研究机器人律师，已经相对成熟，可以完成某些特定类型的法律事务了。比如，英国有一家叫Lissa的机器人律师，它的功能包括：帮用户起草或阅读协议，帮客户咨询简单的法律纠纷。

还有一家叫DONOTPAY的机器人律师，它主要服务是帮人“不交罚款”，能自动提交申诉、帮人申请减免。

你可能会问，这样下来，AI是不是就要取代人类律师了呢？

# AI将如何影响法律行业的未来？

其实《经济学人》在文章里给出了一个答案：未来，法律服务的趋势是，简单、重复性的事务将由AI完成，而律师专注于更复杂、更需判断力的工作。

第一个趋势很好理解。以前，法律服务是非常昂贵的，很多人看不起律师。而现在，利用AI提供基础法律服务，成本大大降低，律师可以服务更多普通民众。律师行业的服务范围也进一步扩大，不再只服务于大企业和大案件。

第二个趋势叫“智慧法庭”。其实就是利用AI来辅助司法审判，比如，用AI来审查证据链是否完整、法律适用是否准确。这样一来，可以减少人为偏见，提高司法公正性和效率。虽然现在还处于起步阶段，但未来可能会很常见。
