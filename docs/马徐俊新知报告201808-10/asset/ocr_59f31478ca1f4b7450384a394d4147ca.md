# 今日报告：昆虫急剧减少将威胁人类的生存？

> 即使全类人都消失了，地球还能恢复到一万年前生机勃勃的样子。但是如果昆虫都消失了，人类的生态环境将会崩溃，陷入混乱。

——生物学家爱德华·威尔逊

马俊达

昆虫对维持人类生态平衡的意义，远超你想象的重要。

今天的议题分为两个部分：

+   - 为什么说昆虫消失会给人类带来致命打击？
- 昆虫减少的问题已经严重到什么程度？

如果你是一名老司机，你可能有过这种经历——夏天开车长途，会有很多虫子撞在挡风玻璃上，收拾这些虫子是个很麻烦的事情。这种现象在生态学里有个专有名词，叫“挡风玻璃现象”（the windshield phenomenon）。

但是最近几年开车，你可能就会发现，这种现象不多了。没错，虫子确实变少了。你可能会说，那不是挺好的么，省得擦车玻璃了。其实，恰恰相反啊。昆虫数量的变化，会给我们带来大麻烦。

近些年来，昆虫正在遭遇一场巨大的危机。英国杂志《周刊报道》(The Week)最新刊文介绍了一篇文献综述，标题叫《昆虫危机》(Insect Armageddon)。文中用了大量的研究，严肃地讨论了一个问题——在全球范围内，昆虫的密度正在面临灾难性的下降，而这会给人带来毁灭性的打击。

这事儿有多严重？按照哈佛大学生物学家爱德华·威尔逊的说法，即使全类人都消失了，地球还能恢复到10000年前生机勃勃的状态；但是如果昆虫都消失了，整个地球的生态环境就会崩溃，陷入混乱。

这句话也被我选为了今天的金句：

> If insects were to vanish, the environment would collapse into chaos.

# | 为什么说昆虫的消失会给人类带来致命打击？

没有了昆虫，我们的生活将会变成什么样？刚刚那位生物学家爱德华·威尔逊说过：如果地球上没有昆虫，人类或许只能存活几天7。英国《卫报》的记者曾布鲁克也描述过昆虫灭绝的可怕愿景——开花植物和大多数无脊椎动物、爬行动物、鸟类、哺乳动物都会迅速灭绝，地球上铺满了死去的植物和动物的尸体。

这个景象，不是很可怕？

你可能觉得，这种说法是不是有些夸张？《昆虫末日》这篇论文，用了大量的事实和数字来告诉你，绝这不是危言耸听。

昆虫对这个地球的作用，比你想象的要大得多。首先，它们是绝大多数物种食物链的“工具层”，比如蝴蝶、蜜蜂、苍蝇、蚊子，都是很重要的授粉昆虫，没有它们，这些农作物就没办法“转卖代交”；其次，昆虫还是许多动物、哺乳动物、鱼类、爬行动物和两栖动物的食物，一些大型动物，昆虫直接构成了它们食物的“大半个池子”，昆虫灭绝了，这些动物只能靠土壤里的有机物，它们的粪便和尸体是天然的动物肥料，能够土壤更加肥沃。

另外，对于害虫的问题，也不用太担心。只要维持昆虫的种群数量和生态平衡，害虫的天敌昆虫共生，就能把害虫的数量控制在一定范围内，而不让它们泛滥成灾。

说到底是，昆虫对维持生态平衡的作用，我们都很熟悉。但它们的生死存亡，到底会给人类带来多大的影响？这个是我们原以为不会去考虑到的。
