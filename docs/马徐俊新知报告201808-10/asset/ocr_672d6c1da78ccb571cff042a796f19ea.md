# ## “小行星撞击说”的疑点

在支持“火山说”的科学家看来，“小行星

撞击说”无非是想让灭绝变得更有戏剧性，

一块巨石从天外飞来，砸中地球，瞬间把

恐龙都炸死了。

它似乎还包含一个名为“周末效应”

（bad weekened scenario），即恐龙是在

某个特定的“周末”灭绝的，而不是在漫

长的地质年代里。

这个故事很有戏剧性，听起来也很合理，

但证据呢？

小行星撞击的主要证据，来自一个名为

希克苏鲁伯（Chicxulub）的陨石坑，位于

现在的墨西哥尤卡坦半岛。

1991年，墨西哥石油公司在尤卡坦半岛钻

探时，意外发现了这个直径近180公里

的环形山。它的位置、形状、大小，都与

恐龙灭绝的时间（约6500万年前）惊人地

吻合。

但很快，科学家就发现了对“小行星撞击

说”的质疑。

首先，陨石坑的形成时间存疑。有科学家

认为，希克苏鲁伯陨石坑的形成可能比恐

龙灭绝的时间早得多，或者晚得多。

其次，撞击造成的环境破坏没有想象中那

么“瞬间”。

撞击确实会造成大量尘埃和气体进入大气

层，导致“撞击冬天”，但研究表明，这

种影响可能只持续了几个月，而不是几

万年。

更重要的是，有证据表明，在陨石撞击之

前，恐龙种群就已经在衰退了。

那么，究竟是什么导致了恐龙的灭绝？

把目光转向印度。

# ## 火山是如何造成恐龙灭绝的？

6500万年前，印度次大陆正以惊人的速度

向北移动，并挤压欧亚板块。这次碰撞

导致了德干高原的形成，也引发了一系列

大规模的火山活动。

德干火山岩流，是地球上已知最大的火山

岩省份之一，面积超过50万平方公里。

从6500万年前开始，德干高原的火山活动

持续了数百万年，喷发出大量的熔岩、灰

烬和有毒气体。

这些气体主要包括二氧化硫、硫化氢和

二氧化碳。

二氧化硫和硫化氢进入大气层后，会与

水反应形成硫酸，导致“酸雨”。酸雨会

严重破坏土壤和水体，杀死植物，进而

影响食物链。

与此同时，大量的二氧化碳会导致温室

效应，引起全球变暖。

变暖会导致冰川融化，海平面上升，淹

没低地。同时，高温和干燥的气候会改变

植物的分布，使得恐龙的食物来源减少。

更重要的是，火山喷发会向大气中喷射大

量的尘埃和颗粒物，遮挡阳光，导致“火

山冬天”。

“火山冬天”会导致全球气温骤降，植物

生长受阻，进而影响整个生态系统。

这些环境变化，比一颗小行星的撞击，

更持久，也更致命。

德干火山岩流，不仅改变了地球的气候，

也深刻地影响了生命的演化轨迹。

而这一切，都发生在印度。

# ## 人类会重终结于火山爆发吗？

虽然德干火山岩流是恐龙灭绝的主要原因，

但它并非孤例。

地球历史上，曾多次发生过大规模的火山

活动，如西伯利亚暗色岩流，它被认为是

导致二叠纪末大灭绝的主要原因。

这些事件提醒我们，地球的气候和生态系

统是脆弱的，一旦失衡，就可能引发灾难。
