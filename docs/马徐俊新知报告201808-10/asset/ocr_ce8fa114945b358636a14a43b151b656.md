# I 西班牙大流感100年的启示

100年来，全世界医学界对西班牙大流感的研究从未停止过，但研究结果却不尽乐观，如果用一句话来概括，那就是——既没有明确引起这场流感的究竟是什么，也没有办法解释，为什么它具有这么强的杀伤力和传染能。

我们都知道，普通的病毒都是通过宿主在传播的，正常情况下，病毒在宿主中会迅速被消灭，为什么不会？因为感染了病毒的宿主活的时间越短，它才可能更轻易地传染给更多的人，……（原文此处有省略号）……
