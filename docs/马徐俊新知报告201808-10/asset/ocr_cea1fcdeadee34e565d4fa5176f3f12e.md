# 总结

《经济学人》预测，10来年后，量子计算时代即将到来，它将会大大提高计算机的算力，但也会对现有的网络安全系统造成巨大的冲击。

其实对我们来说，对于量子计算时代的到来，不能用看神仙打架，做个吃瓜群众的心态来看。历史的发展进程从来都不是割裂的，新旧时代的交替，也不是用那些标志性的大事件来做简单的隔断，我们始终生活在趋势里，那些意识到趋势存在的人，比起对趋势的更茫然无知的人，显然更具备现代性。

也许某一天，你只是升级了一下手机里的app或者网站上的密码，但也许，在这个简单的动作背后，是一个技术时代的交替，是无数智慧的头脑钻研毕生的结晶。想到这里，你会不会对现代社会的复杂性，有了更深一层的理解呢？
