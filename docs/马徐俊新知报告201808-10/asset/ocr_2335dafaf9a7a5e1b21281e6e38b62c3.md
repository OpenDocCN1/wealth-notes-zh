+   **马俊锋**
现代社会，男性的精神压力越来越大了，如何通过虚拟现实和机器学习，帮助他们准确地分析精神状态，制定干预方案？

今天的议题分为两个部分：

+   - 为什么现代社会男性的精神压力这么大？
- 如何利用VR和机器学习缓解男性精神压力？

咱们通常都觉得，男人要承担更多的责任。在家里，男人要承担起照顾一家老小的责任，在社交上，男人也要成为中流砥柱。在这一点上是分男女两性的，咱们中文里有“顶梁柱”的说法，英文又有对应的说法，叫bread-winner，字面意思就是“养家糊口的人”。如果你是男人，你家人该不该更强？相信绝大多数人的回答都是肯定的。

但《新科学家》杂志在最新却发表了一篇文章，标题就叫《How Can VR Stop Male Suicide?》，作者西蒙·克朗普顿是一名科学家。这篇文章，为现代社会男性的心理状况，敲了一记警钟。

西蒙说，现如今男性的精神负担太重了，重到什么程度呢？文章提到，在英国25到49岁的男性群体中，头号死因竟是自杀，死亡的比例是35.2%，这件事，一定要引起全社会的重视。

今天，我们就从“英国男性自杀率增高”这个现象出发，来谈谈《新科学家》杂志提出的两个问题，第一个问题是，为什么在现代社会，男性的精神压力这么大？第二个问题则是精神病重所带来的精神压力，如何利用虚拟现实和机器学习提来缓解男性的精神压力？

总的来说，克朗普顿认为，如果虚拟技术和人工智能相结合的治疗方式，在临床实验中被证实能够缓解男性的精神压力，这种方式将会得到全面普及。

# # Ⅰ为什么现代社会男性的精神压力这么大？

男性精神压力这件事，不用多说我也知道，但是这个问题竟然严重到导致了这么高的自杀率，背后的原因，还是值得深思。西蒙罗列了几种男性压力的来源，给他们系统地找出了导致男性精神压力的六大原因，让你对这个问题有了更加全面的了解。

排在首位的是精神健康类问题，英国格拉斯哥大学的罗奥·康纳教授指出，有一类男性“社会性完美主义者”（the social perfectionists）的精神压力要比其他男性更大，也更容易出现精神健康问题。

为什么呢？因为他们觉得因为自己是男人，就应该像这一辈子养家顾口，承担起照顾家庭的责任。这种自我施加的极的精神压力。不仅如此，他们还认为自己有义务完全承担在工作上、家庭里的各种责任。

他们甚至认为，别人对他们的唯一期待，就是他们把什么都做好。在这种高自我期待下，他们的精神压力当然越来越大，产生了精神问题，比如说常见的就是抑郁。

而排在第二位的就是疾病。身体上的病痛会带来自杀风险。来自这些的极端者来说，癌症患者的自杀风险是普通人的两倍，而患泌尿生殖系统相关癌症的男性，自杀风险是普通人的五倍。

第三大因素是家庭矛盾，这个倒是好理解。

第四大因素是经济状况出现问题。文章介绍，在那些经历过经济危机的国家，当失业率上升时，年轻男性的自杀率也是首先上升。研究发现，GDP每增长1%，自杀率就会上升0.09%。

第五大因素和电子产品相关。根据佛罗里达大学的研究，青少年越接触电子产品时间越长，他们的精神状态越差，越容易感到抑郁，极端情况下甚至会想轻生。

最后一个因素是比较容易获得伤害自己的工具。比如说在不禁枪的美国，71%的自杀条件使用的工具都是枪。

来自精神健康、家庭关系、身体状况，以及社会经济等方面的六大因素，都加剧了人们的精神压力。那么，在科技快速发展的当下，除了传统的心理治疗，有没有新的方案来解决问题呢？

# # Ⅱ如何利用虚拟现实技术和机器学习缓解男性精神压力？

文章里介绍了乔·富兰克林，他是美国佛罗里达州大学计算机和脑部科学实验室的负责人，他和团队，正在用虚拟现实结合虚拟现实和机器学习，来进行精神分析。他把研究分成了两个步骤来进行，第一个步骤是利用虚拟现实技术采集和分析数据，第二个步骤是基于机器学习分析出的数据，有针对性地对人们精神压力。

我们先来看看研究人员如何利用虚拟现实来采集和分析数据。在一项研究中，社会孤立与精神压力之间关系的实验里，研究人员首先为实验对象设置了一个环境，让他们觉得自己受到了孤立，然后让他们戴上虚拟现实设备，实验对象就会发现自己进入了一个窄的虚拟房间，他会看到自己正站在一栋高楼的顶层。

这个时候研究人员会告诉他们，有两种方式可以完成任务：一个是从楼上跳下去，另一个是坐电梯到达楼下，选哪个都行。结果就是有人选择跳楼，有人选择坐电梯。

通过实验对象在完成任务过程中的表现，以及他们对自己最后选择时的解释，研究人员就测到他们之后的各项精神指标，比如说精神压力范围，愤怒值，情绪波动情况等，根据这些数据，研究人员就能预测他们的后续状态。

你是不是很想这就是个VR游戏么，没什么特别的？作者在文章里说，这种研究方式对精神研究可可不是最重要的吗。在精神研究中引入VR技术，最大的好处就是它给精神分析提供了一个稳定、安全的实验环境。

因为，本来测试一个人的精神状态就很不容易，考虑到变量很多，所以这种精确性就低。如果再设置个测试的话，去传统的方式，比如说填调查问卷，去进一步分析出这个人精神状态有多复杂，有时甚至无法知道这些行为，可想知，就更不准确了。

而通过VR实验，就成了实验对象设置各种非常的情境，减少了复杂变量的干扰，让他们的精神状态能够表现得更加直观、真实。比如说，只想测量抑郁，是否有某些状态，向精神焦虑提问，你不想去问这20个领域同时，他想不想想多了吧？现在，通过VR技术，这个问题就被解决了。

收集精神状态数据的第二种方法就是利用机器学习。根据文章的介绍，简单来说，就是给机器学习500例自杀者的具体信息，再输入500例有自杀倾向的人的信息，越仔细越好，比如说具体年龄、职业、家族精神病史、各项关于抑郁、焦虑...
