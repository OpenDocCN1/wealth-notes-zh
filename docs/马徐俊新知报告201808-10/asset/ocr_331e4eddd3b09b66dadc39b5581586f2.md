# 今日报告：克隆宠物可能带来什么问题？

马欣捷

如果陪伴多年的宠物狗死去了，你会选择用克隆技术让它死而复生吗？别着急，看完这篇文章，你再回来回答这个问题。

今天的议题分为两个部分：

+   - 克隆技术发展到了什么程度？
- 克隆宠物商业化的三个问题

今年二月，美国著名兽医基因学家拉·史翠珊，把陪伴自己14年之久的芭拉，通过克隆技术，复制出了两条一模一样的“替身”。过去的半年里，这件事在西方世界引出了很大的反响和讨论。

最近《名利场》杂志报道，采访了实施这次克隆手术的韩国医生和公司，pique网站也写成了科普文章。我综合了这两篇原文，当然从《科学美国人》《纽约时报》《华盛顿邮报》《卫报》《名利场》《时代》《史密森学会》《PhySy》《麻省理工技术评论》《商业内幕》、Futurism网站等多家媒体的报道和观点中，为做了一次系统梳理，让你直观地看到，西方媒体在对克隆宠物这个话题的态度和反应，克隆技术的发展趋势又到底如何？

# 克隆技术发展到了什么程度？

从1996年人类第一次成功克隆出小羊多利至今，已经过去了20多年了。今天的动物克隆技术已经发展到什么程度了？这么说吧，那种第一阶段、单块、换胚技术，然后克隆出一模一样的人/动物机器，至今仍只存在于电影或小说里。
说白了，我们现在克隆技术水平，离这样的科幻场景还差得远呢。

其实克隆技术说起来并不复杂——先从克隆的“原身”身上取下一个细胞，抽取它的细胞核，注入去除细胞核的卵子中，通过刺激让它们融合，然后植入代孕者的子宫内。经过处理后，通过正常的生育过程，“克隆宝宝”就诞生了。

关于克隆技术，有两点值得你注意：首先，以现在技术水平，还不可能直接克隆出一个成的个体来，只能通过克隆的孕胎进行克隆；其次，克隆出来的个体既带有被克隆对象的DNA，又带有卵细胞提供者的DNA。因此，它并不能百分之百克隆的“原身”。

到今天，人类成功克隆的动物包括羊、老鼠、猪、兔子、猫等等。犬科动物的克隆相对难一些，但现在的也可以做到。上面提到的芭拉，史翠珊的克隆宠物狗，就是例子。2017年底，中国成功地使用体细胞克隆技术，克隆出了世界上首例长爪动物——猴子，一共两只，分别叫“中中”和“华华”，引起了全世界的关注。今年一月，这个还登上了生命科学领域的权威杂志《细胞》的封面。

可以说，经过了20多年的发展，人类克隆动物的技术越来越成熟了，主要体现在两个方面：费用越来越低，成功率越来越高。

![](bbox=[0.1, 0.15, 0.85, 0.28])

咱们拿已经实现商用的克隆宠物为例吧。
最初，克隆一条宠物狗价格差不多是15万美元，现在降到5万美元了；克隆猫的价格更低一些，只有克隆狗的一半，大概是2.5万美元。

早在2005年，要成功克隆一条狗来，至少要使用1000个胚胎和123条代孕的狗，才能成功。而在当时的所有克隆实验中，最终只成为克隆猫的3条狗中，一条最高者只达到了10年，跟正常的狗差不多。但，克隆狗的成功率达到了20%。

至于克隆人的技术，到现在为止，比较成功的一个是由爱德华兹·休斯曼研究中心小学带来的。他们研究出了一种化学成分，能把人类克隆猫的成功率，从1%提升到10%，这已经是一个很显著的成绩了。

但是你想，克隆动物需要大量的受精卵和代孕母体，就比如刚才说到的两条克隆猫，仅使用7417枚受精卵和63只代孕母体，看到这么多数字你就明白，这种实验根本不可能在人类身上做。

况且，由于克隆人可能带来的伦理挑战等问题，多数国家法律也明确表示禁止严格限制的态度。中国也明确表示对进行克隆人的研究，而且目前国内克隆人的研究者，主要目标也是为了研究治疗人类疾病的替代器官。

总体而言，从科学研究的角度来说，克隆技术在不断取得进步，但是如果把它拿来商用，争议可就大了。

# 克隆宠物商业化的三个问题

目前，对克隆宠物进行商业化运用最多的，是韩国和美国。就拿宠物克隆为例，美国知名的是Viagen公司，而韩国至少有3-4家这样的公司。

咱们一开始说的芭拉·史翠珊的克隆宠物，是由韩国的Soomal公司完成的，这家公司是世界上第一家以克隆技术为主的公司，到目前为止，已经成功克隆了1000条狗。

西方媒体对克隆宠物，普遍是持批评态度的，无论是《纽约时报》还是《华盛顿邮报》，都很大篇幅来反对克隆宠物。我总结了一下，西方媒体反对的理由，主要有三个：昂贵、残忍、没意义。

![](bbox=[0.05, 0.97, 0.5, 1.0])

![](bbox=[0.55, 0.97, 0.95, 1.0])

首先，克隆一条狗的费大约是5万美元，也就相当于30万人民币，不算便宜。这位芭拉·史翠珊一欧元，克隆克隆这条狗，花了60万人民币。她自己也透露，如果不是因为她身是明星，承担得起这笔克隆的费用，对普通人来说，这笔费用是不是太贵了？

但是芭拉·史翠珊可能没想过，参与克隆过程的动物们，将要承受极大的痛苦和虐待，比如强制灌水，注射荷尔蒙，还有流产的风险，都是我们人类难以想象的。
而且别忘了，我们刚才说到，现在克隆猫的成功率只有20%，这意味着有80%的克隆过程是失败的，每一次失败，都意味着代孕的母狗要多经历一次折磨。难怪西媒体会说，克隆宠物这件事，太残忍了。

其次，即便克隆宠物成功了，其实也没什么意思，因为这条复制出来的生命，很可能不是你原来的宠物，脾气性情可能完全不同。

哥伦比亚大学人类认知实验室的主管阿里桑德拉·霍洛维茨就说，其实一条狗的性格，主要取决于成长时期的陪伴、互动以及周围环境等因素。她说，你爱这动物，并不是因为它是它的基因和样子，而是因为它曾陪伴你一度过过的时光。
