# 今日情报：终极语音助手如何“计算”情感？

目前，语音助手为人类提供的还是基础服务。但在不远的将来，它将会具备更高级的功能，在人类社会中扮演更复杂的角色。

> ——《大西洋月刊》

+   - 马修迪

智能语音助手的目标是成为人类亲密的合作伙伴。那么，它如何分析和模仿人类的情感？对智能语音助手的过度依赖，又将会带来什么问题？

如果我问你，《钢铁侠》中托尼·史塔克最形影不离的朋友是谁？答案是，他的智能语音助手，“贾维斯”。作为钢铁侠的全能智能管家，贾维斯不仅负责确保钢铁侠生活的方方面面，连钢铁侠的机甲都是他开发的。

虽然现实生活中的智能语音助手还没有这么强大，但在不久的将来，它很可能深入生活的每一个角落，成为我们极度依赖的伙伴，我们甚至可以叫它“终极语音助手”。

《大西洋月刊》的11月刊封面文章就谈到了这个概念，文章标题叫《Alexa，我们该不该信任你？》（ *Alexa, Should We Trust You, Alexa?* ）Alexa是亚马逊开发的智能语音助手，作者是朱迪斯·休拉维兹（Judith Shulovitz）是美国文化评论家，长期为《纽约时报》供稿，在这篇文章里说，语音助手解放了我们的双手和眼睛，我们可以移动时，就能轻而易举地发布指令。只是从长远来看，不只是改变人类习惯这么简单，语音助手的目标是成为人类信任、依赖的亲密伙伴。

理解了朱迪斯的话，你总会看清，终极语音助手将把我们的生活带往何处。

# 语音助手的研究前沿

你可能也有过这种感受，现在使用语音助手，有一种很“怪”的感觉，这主要是因为语音助手的发声听起来就是机器声，很生硬，自然就会令人感到疏离。而目前世界对语音助手的研究，就是为了解决这个问题的。研究本身分为两个阶段：

第一个阶段，是语音助手的语言设计。声音非常复杂，通过一个人的声音，我们可以判断他的性别、年龄、心情、文化背景等各种特征，如果一个语音助手的声音更像一个人，我们就会在心里呈现出一个真人助手的形象，从而对语音助手产生亲近感。

智能音箱的两大制造商谷歌和亚马逊就是因为看到了这一点，专门组建了“个性团队”，负责为语音助手设计性格，再通过声体现设计个性，让语音助手更“人格化”。比如说，亚马逊的语音助手Alexa的声音必须反映亚马逊的企业价值观，也就是“聪明、谦虚、和蔼而及时”。

除了声音听起来像个人，语音助手的设计方式也得符合人类的语言习惯，比如说，我们一般都把最重要的信息放在一句话的结尾，就像电影里常常会说“我的名字是汉克，而不是‘张三条’的‘三条’。谷歌有一个部门，专门负责开发语音助手的会话和人格设计，他们的工作职责之一，就是让语音助手表达方式和真人一样。

不过，语音助手的“人格化”也有一个底线，就是它所有回答必须符合机器人身份的问题，不可以冒充人类。艾玛·寇特斯（Emma Coats）是谷歌的对话设计师，她把这个底线作为对话设计的基准准则。她曾在亚马逊工作的Alexa举过一个例子，说在2017年有100个用户对一个亚马逊Alexa求婚——对，你没听错，求婚。

寇特斯说，作为一个机器人，Alexa不能以人的身份回应求婚。所以，艾玛为Alexa设计的回答是：“我们生活在不同的世界。你说的是在画面里，我生活在云端。”

刚才说了这么多关于声音的设计，听起来十分复杂，但这仅仅是语音助手研发的第一个阶段。

第二个阶段，也是更高级的阶段，就是通过学习与人类进行情感互动，将人机之间的距离缩短到最低。

要实现这个目标，语音助手需要去具备情感感生的能力，虽然目前这项技术还不成熟，但相关研究早就开始了，而且取得了巨大的进展。

罗莎琳德·皮卡德（Rosalind Picard）是麻省理工的工学教授，她在20年前就为情感识别技术取了一个专业的名字：情感计算（affective computing），并先创办了一个名为Affective的公司，率先开启了对情感识别的研究。

这个公司最近正在训练计算机解析人说话中的情感。首先，研究者会从构建各种情感语声来收集、收集、收集，并建立大的语声数据库；随后研究者要对这些语声进行标注，标注不但要标注情感，还要标注非词汇的声音，比如说咳嗽、咯咯的笑声，等等，因为有些也是表现心态的重要声音。

标注的过程费时费力，每个标注必须用到到5到8秒时间一个，一个研究人员要完成全部6000多的标注要花大约30小时。通过这些分析，目前，计算机已经可以识别出一个人说话的高音量、语速、说话节奏等非语声特征。

接下来的关键步骤，就是教计算机如何将这些声带特征与人的情绪一一对应。伦敦帝国理工大学的工程师戴维·比约和约翰·S·舒勒曾尝试在数字计算机上识别出“讽刺”这种复杂的情绪。
