# 113报告 | 做“加法”摆脱社交媒体依赖症

用好习惯去代替坏习惯，比拼尽全力去改掉坏习惯，要容易得多。

> ——《哈佛商业评论》

今天的内容比较长。我将用四个层层递进的实验，告诉你如何通过“做加法”来摆脱社交媒体依赖症。

很多人感觉，自己在社交媒体上浪费了太多时间，从起床开始，上班路上、工作间隙、下班前……各种社交软件停个不停，而且没有及时发现，内心有干干干个不停。那么，有没有时间投入、不受干扰地做一件事，越来越难了呢？那种深入阅读、学习、和人交流的时间，也越来越少了呢？

我们对社交媒体的这种依赖，已经成为这个时代的一个普遍困扰，它有个名字，叫做“社交媒体依赖症”，英文叫Social Media Addiction。用了addiction这个词，说明它更像是一种“瘾”。看起来，是社交媒体填满了我们的碎片时间，但其实是它，让我们的时间越来越碎片化。

要戒除这种“瘾”，并不容易。《哈佛商业评论》网站最近发表了一篇文章，作者叫莎拉·派克（Sarah K.Peck），她是一位专栏作家，也是一家公司的总裁。她做了两年时间，在生活中做了四个实验，成功地改变了自己对社交媒体的依赖。在这个过程中，她有一个有趣的发现：想要戒掉社交媒体依赖，重点不是戒除它，而是做加法。

莎拉认为，我们之所以会陷入“刷刷刷”的怪圈，是因为我们有更深层次的心理需求。只不过，我们把社交媒体当成了一种方便的感觉途径。这些需求可以归纳为三点：与他人互动、获取新闻、缓解疲劳。

很多人无法戒掉社交媒体依赖，是因为他们一直在做减法，比如少用手机。而正确的做法应该是做“加法”，通过提高规划，为这些深层次的心理需求找到更好的满足方式是核心关键。

今天的内容分四部分，我们将跟随莎拉·派克，逐一看看她的四个实验。每个实验，都会告诉我们一个关于社交媒体依赖的新发现。那么一个实验层层递进，最终，我们就能得到一套完整的、能够帮助你合理高效地使用社交媒体的方法。

# 实验1：彻底戒掉社交媒体30天

在这30天的时间里，莎拉通过卸载软件、关闭账号等，完全抛弃了她最常用的那个社交媒体。除了Facebook、Instagram、Twitter、YouTube、LinkedIn之类的，她只有一个明显的变化，就是发现自己的阅读量“蹭蹭上涨”。一个月时间里，她看的书比之前三个月加在一起都多。

当然，这并不是重点。重点是，通过这个实验莎拉发现，自己使用社交媒体是有一个固定模式的，这个模式呈现出明显的“时间性”——这也，也是她获得的第二条重要新知。

什么意思呢？原来，莎拉用软件记录的方式，追踪了一下自己在前30天的行为数据，通过比对发现，一天当中，自己有几个时间段是社交媒体的高峰期：一个是早晨刚起床，头脑放空的时候；一个是吃完晚饭，瘫在沙发上的时候；一个是晚上临睡前，有点困倦的时候。还有，强烈、短暂的“刷刷刷”的需求也呈强规律性，这样的时刻通常上午11点左右出现一次，下午3、4点钟出现一次。莎拉慢慢明白了，这是她工作累了歇一口气的时间。

通过戒断三十天的实验，莎拉摸到了自己需要使用社交媒体的“时间性”规律，找到了几个使用的高峰期。在分析了原因之后，接下来的第二个实验，莎拉做了一件事：针对这个“时间性”的规律，创造了每天的“屏蔽时间段”。

# 实验2：创造每天的“屏蔽时间段”

莎拉之所以有创造“屏蔽时间段”的想法，是因为她不想意识到，彻底杜绝社交媒体很困难，同时又不喜欢降低工作效率。“屏蔽时间段”设置的依据，就是她在第一个实验中确认的那些使用社交媒体的高峰时间。

第二个实验持续了两周，莎拉的结论是：“屏蔽时间段有用！尤其是设置在早上的‘屏蔽时间段’，让她的工作效率大大提升。”

早上不碰社交媒体之后，莎拉有了几个小时不打扰、可以全身心投入工作中。她发现，她进入沉浸式工作状态的时间，要比以前早了，而且能保持更长时间。她把这个状态叫“深度工作”，也就是“deep work”。

你可能觉得，起床之后刷社交软件，你不可能戒掉。那么，上上午不碰手机可以吗？莎拉的发现是，如果自己从早上开始刷到中午，那么进入“深度工作”状态会变得更困难。

莎拉还注意到，刷“社交媒体”的欲望在睡觉之前最强烈，刷“社交媒体”过后，这种状态就会增强，起来后如果还忍不住去刷社交媒体，那其余的早上的时间，就会变得不集中，不会再想着刷社交媒体的欲望了。

设置了“屏蔽时间段”之后，莎拉的工作效率有了一些飞跃。在第二个实验结束之后，莎拉有了一种深入思考。她认为自己之所以早上难以全身心投入工作，还有一个因素是，她以前很清禁使用刷的时间是有限的，所以她需要找一个新的“敌人”。

顺着这个思路，莎拉就想到，第二个实验的核心思路是“屏蔽”，那如果专门创造一个时段，可以让设计她尽情去使用社交媒体，是否，可以设置“放纵时刻”。

# 实验3：设置“放纵时刻”

“放纵时刻”，原文是happy hour，其实这里望文生义。每天下午4点5分，在忙碌的一天结束之前，是尽情使用社交媒体的一段时间。这个时候，她的什么也不干，就是玩社交媒体——刷朋友发的新动态，看看新鲜事，刷刷别人发什么新奇，她可以随意，这一小会儿不过得痛快？但没有意思的是，莎拉发现，这一小时，用不完。

什么意思呢？就是，当专门开出一小时给社交媒体使用的时候，社交媒体变得“不那么有趣了”。莎拉发现，自己一般用二三十分钟，就把所有内容刷完了，可供阅读、互动的东西也没这么多，仅此而已。还有一个，在这个小时内的“放纵时刻”，无论是回复别人信息也好，投资料也好，似乎都缺了很多，基本三五分钟就搞定了。

实验中，莎拉在社交媒体上发布动态的欲望也下降了。一般来说，她每天会开一个动态的窗口，如果发帖之后，就关掉，不回复信息、留言。但很多时候，她发现自己最后都不想发。之前那好几个小时的“沉浸时”，让她在想发动态之前，看自己想分享内容是不是真的有价值。

第三个实验让莎拉明白，对于碎片化的需求，不一定要用碎片化的时间来应对。用整块的时间处理，反而更高效。

莎拉的最新一个实验，是每周用24小时“打破循环”。
