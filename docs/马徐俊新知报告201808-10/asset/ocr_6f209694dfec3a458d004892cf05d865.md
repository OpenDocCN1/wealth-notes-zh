# 054报告 | 为什么夏天越来越热?

今日报告：为什么夏天越来越热?

全球变暖的趋势正在加剧，人类正在输掉这场战争，必须加倍努力才行。——《经济学人》

马徐骏

今年夏天越来越热了，连北极圈都一度飙到了32°C。全球变暖的问题，为什么越治理越严重？

今天的议题分为三个部分：

+   * 全球变暖比你想象得更严重
* 为什么“温室效应”控制不下来？
* 缓解全球变暖的转机与对策

这个夏天热得不够透？放心，这绝对不是你的错觉。罕见的高温天气，在这个夏天，袭击的不只是中国，大半个地球都遭了殃。

本期《经济学人》杂志的封面，就是一张很有视觉冲击力的照片——人们正在奋力扑灭一场Fire。文章的标题就叫《在火上浇油》(*In the Line of Fire*)。《经济学人》的观点是：全球变暖的趋势正在加剧，人类正在输掉这场战争，必须加倍努力才行。

```
The world is losing the war against climate change, all the efforts should be doubled.
```

你可能会觉得，控制碳排放、应对全球变暖，不是早就应该全球共识了吗？在巴黎气候大会上，全世界各国也拿出了解决方案了，怎么问题不但没解决，反而更严重了呢？

今天咱们来看看，对于如何全球变暖加剧的问题，《经济学人》是怎么分析的，又给出了哪些解决方案。

# ■ 全球变暖比你想象得更严重

全球变暖是一个老话题，但这次《经济学人》专门做了封面报道，还写了五篇相关文章，在不同角度、不同层面做了分析和论述，比重远超上一组再版报道了。其实不止《经济学人》，最近一段时间，全球变暖问题变成成为外媒体讨论的焦点，为什么呢？简单说，越来越糟的夏天，已经把这个话题推到了火烧眉毛的程度。

且不说中国，今年夏天，整个北半球都热得「扒了皮」。由于高温天气，美国加州发生了18场森林大火，创下了历史纪录，甚至改变了加州的整个气候；上周，希腊雅典也爆出一场森林大火，导致人们死亡；东安的气温，最高超过了40度，日本全国因为热病导致的死亡，导致125人死亡。而在几天前，北极圈的西点温度，一度飙升到了32°C，导致冰川大面积融化。动植物大量死亡，该处是「极地空调」的极地，现在甚至有「空调」的北来的。

全球变暖带来的极端天气，也引发了普遍恐慌。一项对38个国家进行的民意调查显示，61%的民众都表示全球变暖非常可怕，可以说恐怖袭击、恐怖组织非比寻常。英国《卫报》的一篇文章，甚至在标题里把climate（气候），直接替换成了calamity（灾难）这个词，用来描述问题的严重性。

《经济学人》说，跟工业革命之前相比，现在地球的平均温度，整体上升了1°C（注意，才有一度），要知道，《巴黎气候协定》的目标，是尽可能把温升上限的范围控制在2°C以内，换句话说，眼下的距离目标，还有不到头部。据统计，在未来的很长时间里，气温还会继续往上走，这意味着，接下去的日子，恐怕只会更难熬。

看到这里，你可能要问，除了特朗普命令美国退出了《巴黎气候协定》，全世界众多国家，不都在努力控制碳排放、降低温室效应吗？为什么还能越控制越糟了呢？

# I 为什么“温室效应”控制不下来？

《西游记》里唐僧在雷音寺火焰山，靠的是「芭蕉扇」，可借在现实世界里，没有这种东西。根据《经济学人》分析，要达到控制温室效应、降低全球气温的目标，难点至少有三个：发展人类需要消耗的庞大、政治和经济对「减排」力量的牵制、拿不到更好的替代技术。咱们一个一个来说。

首先是发展中国家的能源需求，尤其是对煤的依赖较大。在亚洲地区，从2006年到2016年，能源消耗增长了40%。对于煤、油、气最大的用能源，就是亚洲。亚洲对于煤的需求，以每年3.1%的速度增长，天然气和石油分别是5.2%和2.9%，要知道，这三种东西都是可以生产二氧花碳的主要来源。

那你们可能会说，都知道这些能源不环保，为什么不换成清洁的可再生能源呢？可问题在于，哪有那么容易换呢？

你看，大部分亚洲国家的能源系统，本来就更兼容煤矿和石油，依赖煤炭系统来发电，这个成本可不只是设备成本，还有社会和经济成本。

举个例了，印度是世界上第二大煤炭消费国，80%的能源供应依赖于煤炭，采煤和发电，占到了印度十分之一的工业产值，大约有50万人以煤炭工人为生。

根据印度官方的统计数据显示，煤炭工业所养活了大约二万到三千万个家庭。所以你想想，要是能源改革太狠，整个印度社会系统就会受到巨大的冲击。

另一方面，新能源的表现并不稳定，比如风，太阳，风能表现就是吃天，风不刮就不，太阳不照就不电；所以印度的能源供应，57%都是靠靠靠靠，印度政府也也不敢就煤炭发电，为了更快发展发经济，到2020年，还要增加44%的产能。

印度的这种用，在很大的发展中国家都存在，下面这张图，是1995到未来100年的能源结构，你从图中可以看到，最坚不可摧的能源来源，就是煤炭了。因此，《经济学人》用一个词来形容碳块煤的不能一下子被替代，就是「用一下试试」，谁能知道能不能一下子吃，但是新奶这件事，做起来也真的不容易。
