# 今日报告：为什么欧洲没有科技巨头？

欧洲已经很久没有诞生过科技巨头了，原因就在于市场太分散、文化太保守、对资本和人才都缺乏吸引力。

> ——《彭博商业周刊》

马徐征

在我们心目中，欧洲曾经是工业革命的引领者。但在这一波科技浪潮中，欧洲却显得黯然失色，这是为什么呢？

今天的话题分为三个部分：

+   - 过于分散的欧洲市场
- 保守的文化传统
- 对资本和人才缺乏吸引力

在互联网技术席卷全球的今天，美国和中国诞生了一大批颠覆性的互联网企业，像苹果、亚马逊、微软、Facebook、Uber、阿里巴巴、腾讯等等。但曾经引领工业革命潮流的欧洲，在这一轮变革中似乎很黯然失色。

你或许还记得英国的诺基亚、瑞典的爱立信，但它们的辉煌早已经远去。根据科技投资者和导师GP Bullhound的数据，目前欧洲最有前途的互联网科技公司，是瑞典的Spotify，这是一家正版流媒体音乐服务平台，苹果和它们有合作；另外一个则是德国的Zalando，它主要做服装和鞋类的在线零售业务。

但是，这两家公司的总市值只有420亿美元，这个数字你可能没什么概念，我对你说一下——阿里巴巴市值是4,800亿美元，而Facebook的市值是5,500亿美元，你看，这个差距是不是很...

从经济上说，欧盟是世界上最大的经济体之一，经济规模基本和美国相当；从人口上说，欧洲的人口是美国的两倍，欧洲的教育水平又处于世界领先地位，涌现出许多一流的数学家、计算机科学家和软件开发人员。那你可能要问到，为什么欧洲在这个时代，却没有诞生一家顶尖的互联网企业来呢？

最近《彭博商业周刊》发表了一篇名为《European Do Tech?》的文章，《080》已经翻出科普产业了，这篇文章，说欧洲已经很久都没有诞生过科技巨头公司了，原因就在于市场太分散、文化太保守、对资本和人才都缺乏吸引力。

```
It's been a long time since the region produced a consumer-tech giant. Now this is why.
```

# | 过于分散的欧洲市场

咱们都知道，对于科技公司来说，想要大规模的扩张，前提是，你得有需要大量用户的市场。欧洲有多少人？7.4亿，而美国呢？才3.2亿。这样看下来，欧洲不但不缺人，还有很大的优势啊！

但欧洲的问题是，它有数十种官方语言，这等于7.4亿人口，生活被数十种语言给割裂了。这意味着，一个产品要想推广到整个欧洲，你就需要开发10几种不同语言版本，而且这还不光是多个语种的问题。欧洲每个国家的人还没有截然不同的文化和偏好，你的产品还不能只是做一个简单的翻译，你的界面，还要开发出不同的风格和逻辑，在界面市场推广时，还要采用不同的营销策略和市场定位，这样一来，就大大增加了企业的研发成本和推广难度。

但这还不是很要命的事情。更大的障碍在于，公司最反对各国不同的法律体系和多量税收的问题，这让他们的规模化扩张难上加难。一家美国原创的社交媒体网站，如果只发展在美国的话，它只需要面对用户有3,000万，这大抵和美国的阿巴巴马州的用户数量差不多，规模自然不小了，但如果它想发展整个欧洲市场，就意味着要开拓另外27个截然不同的市场，这对于企业来说，成本实在太高了。

Zalando的联合创始人雅克莫夫·鲍曼斯就说过：“和硅谷相比，我们更需要更多的人手，因为这里有那么不同的语言和支持方式。”伦敦Accel Partners的风险投资家哈里·乔尔也说过：“这就是欧洲投资公司发展受局限的原因，在中国和美国能够把融资的公司，在欧洲很难推起来。可能是德国的第一大公司，但在法国，根本就没人听说过你。”

小国林立的欧洲，在市场规模上已经吃了大亏，这对于科技巨头的诞生来说，问题远不止于此，从文化上来说，欧洲也不是互联网创新的好土壤，这是为什么呢？
