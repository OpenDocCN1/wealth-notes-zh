# ## 今日头条报 | 真正科学的性格分类方法

西方心理学界更倾向于把性格看作多个连续的维度，随着人们年龄增长、生活成熟，个人的性格特点在这些维度里所处的位置，也会不断发展、变化。

——《自然·人类行为》

杨健

你喜欢做性格分类测试吗？我今天就给你介绍的这个科学的性格分类方法，它不仅严谨、更全新，而且可能会颠覆你对于性格分类的认知。

今天的议题分为两个部分：

+   *   人类性格的四大类型
*   性格类型会随着年龄而“流动”

你大概对性格分类测试不陌生，一旦有太兴奋的新东西诞生了，总能第一时间刷爆朋友圈。举个例子，最近清宫戏热播，相应的性格测试，马上就流传开了。我有很多人在乐此不疲地玩着……有说自己是皇后的，有说自己是贵妃的……人们玩的虽然开心，可惜在科学界看来，这种五玩人的性格测试并不严谨，严格来说，它们都属于“伪科学”。

你可能会说，这不就是茶余饭后的消遣吗，又没人会当真，但事实上，性格测试的影响，远比想象的要大。有个在全世界非常知名的性格分类方法叫“迈尔斯-布里格斯性格分类法”，也叫MBTI，这类分类法基于瑞士心理学家荣格的理论，将人的性格分为16种类型。二战后，美国有很多大企业用它作为员工筛查的参考指标，某些职位甚至明文规定，只招收特定性格类型的应聘者。

MBTI性格法非常流行，但是，很多心理学家指出，是指称背后的科学原理和评价标准都是假。换句话说，别看这些性格分类看起来好像很专业，但实际上，它并不算科学。

那真正科学的性格分类到底有没有呢？答案是有的。科学期刊《自然·人类行为》最新发表的一项研究，提出了一种相对科学的性格分类框架，这是研究的发起者美国西北大学的威廉·雷维尔（William Revelle）团队，按照他们的结论，人的性格可以大致划分为四种主要的类型一平均性、保守型、模特型和自我中心型。

你的第一反应可能是，这几个分类太平淡了，远没有“哲学家”“艺术家”“思考者”“领袖”这些听着头很有意向；但请注意，这可能才是最“科学”的性格分类。

为什么说，这个性格模型有两点做得非常扎实：一个是它有一套清楚的、可重复的算法；另一个是，它的研究基础，是从多达150万人，在线测试里采集来的大数据。

这项研究的贡献，不光是提出了四个性格类型，研究者还推导出了一个很有趣的结论，一个人的性格类型，是连续流动的。你年纪越长，性格也会随之流动。这一点，或许能颠覆你对于“性格”这件事的认知。
