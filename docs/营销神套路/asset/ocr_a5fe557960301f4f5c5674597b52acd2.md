# 第33课：温克勒动态定价的价格套路

下面是一诺老师在线下交流时，给亲传弟子分享的一个案例。

定价关系到公司的利润，任何一家公司在定价决策前，都应去了解顾客的接受程度。然而，有的公司则认为，价格只是影响消费者购买与公司利润的因素之一。

行销专家约翰·温克勒曾说，“太多公司企图维持稳定的价格，尤其是那些小公司，这可能就是他们的规模做不大的原因。价格必须随时检视，并不是一直不变，而是注意它是否恰当。由于它是很重要的决策，因此不能稍有忽略。”
