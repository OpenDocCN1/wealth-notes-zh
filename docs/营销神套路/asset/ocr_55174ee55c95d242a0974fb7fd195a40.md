# 第19课：培训禅操作引爆百万利润

一个音乐系大学毕业的女士，开了一个音乐培训班，主要针对6-15岁的少年，她对这份事业很有信心，因为这是自己的绝活。

但是时间一天天过去了，半年来，只招了13个学生，发传单、上报纸、上当地电视台，可以说自己知道的宣传渠道都用上了，最终宣传还是无效果，面对招不来学生、入不敷出的困惑，她不知所措，开始怀疑自己的选择……

后来经过一诺老师亲自辅导，通过一个神套路引爆百万利润，她是如何做到的呢？且听我细细道来。

经过朋友的介绍，她找到了我，当时我了解了她的基本情况后，我应用了鱼塘借力技术……
