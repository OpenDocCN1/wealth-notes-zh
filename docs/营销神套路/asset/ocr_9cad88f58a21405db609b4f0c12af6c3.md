# 第38课：高级酱油的价格套路

下面是一诺老师在线下交流时，给亲传弟子分享的一个案例。

在台湾市场上，当味全推出酱油露之后，一些厂家看到有利可图，也竞相推出高级酱油，一时间市场红红火火，但好景不长，市场渐渐萎缩了，使狭小的市场，在短时间内呈现饱和状态。

在这种情况下，厂家为了维护市场的占有率，一面苦撑市场，一面不得不通过价格的修正加以弥补。

味全在推出酱油露之后又推出了珍味酱油，价格从原来的15元降到了10元，而味五厂在推出陈年酱油后，也发生了同样困难，因此，在它包装上加以改变，以大瓶装的陈年酱油，售价调整为12元。
