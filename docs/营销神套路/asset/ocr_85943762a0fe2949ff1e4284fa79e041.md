我常说，资源不是发现的，也不是创造的，而是整合的！整合资源，是杠杆借力中的一个重要的环节。关于资源分类，可以是人脉资源，自然资源，物质资源，人力资源，信息资源，社会资源等。

在杠杆借力营销课程中，我给大家分享了一些如何轻松借力周围资源的方法，请认真思考以下几个问题：

+   1. 他们在做什么？

+   2. 他们身上有什么优势？

+   3. 他们是运用哪些资源在做自己的事情？

+   4. 他们在用哪些资源帮助他们把生意做得更好？

> “我借用你的场地，我不是用来做任何商业行为，只是用来带领学校里的学生晨读英语。”

这样，借力是不是合情合理，后勤主任那边肯定没有太多……
