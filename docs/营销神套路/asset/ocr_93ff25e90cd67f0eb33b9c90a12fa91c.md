# 第 06 课：新瑜伽馆神套路疯狂引爆客流量

在我的学员中有个开瑜伽会所的，开张之后一直苦于没有客源，她一般的广告宣传都是传单，传单这种模式现在都已经被大家用烂了，广告的载体一定要遵循，离目标受众最近的原则。

![](bbox=[0.1, 0.38, 0.85, 0.52])

所以传单随着时间的流逝，越来越无效，传单就是垃圾广告，因为对受众是没有利益的！因为利益才是最大的驱动力。

张总开了一家瑜伽馆，门可罗雀、发不起工资、交不起房租，后来经过一诺老师亲自辅导，通过一个神套路，疯狂引爆客流量，她是如何做到的呢？且听我细细道来。

做任何行为都要事前定位，不做定位你就找不到努力的方向，像这家瑜伽会所呢，每天派很多人去发传单，最后发现派的人越多，越发发出去，而且还要防着城管，所以老板很苦恼。
