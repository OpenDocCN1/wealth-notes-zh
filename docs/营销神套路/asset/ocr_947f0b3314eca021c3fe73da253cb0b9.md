# 第04课：大师神套路放长线钓大鱼

下面是一诺老师在线下交流时，给亲传弟子分享的一个神套路：大师神套路放长线钓大鱼。

营销点评：商业模式就是帮你做产业链。

一个企业的价值链的每一个环节，都能创造价值。比如说设计环节增加资源，比如说施工环节增加资源，比如说在拿项目环节增加资源。有了资源，就会产生竞争优势。

> 现在是客户之间的竞争，现在是平台之间的竞争！
——一诺老师

比如很多企业通过改革开放搞加工，你加工鞋我也加工鞋，你加工冰箱我也加工冰箱，你加工空调我也加工空调，于是，大家都变成了性质差不多的加工企业，同质化严重。

这个时候谁做品牌谁厉害，这个时候谁做技术谁厉害，这个时候谁做渠道谁厉害。
