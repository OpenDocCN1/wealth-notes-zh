# 【整年购买】

有服装店用这招收入翻倍，简单有效，“600 元高档靓衣，月月免费送”，做法：买 600 元热销品，送 600 元赠品（分 12 月送），每月到店送 50 元（如饰品）。

秘诀：将新客转老客每月持续来店；客户来拿赠品趁机卖更多；还有后续会员营销，奥妙无比。
