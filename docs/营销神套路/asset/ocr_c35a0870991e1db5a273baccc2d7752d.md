# 第 27 课：食用油大战的广告策略

下面是一诺老师在线下交流时，给亲传弟子分享的一个案例。

由台湾维力食品公司引发的食用油广告大战，最终虽然并没有改变多少市场结构，但从这场广告战的结果来看；维力食品公司的清香油以小搏大的策略，逼得沙拉油出招反击，以致造成话题，应该说是成功的。

![](bbox=[0.15, 0.54, 0.91, 0.67])

清香油是从猪油提炼的，它去除猪油中的大量硬脂酸与胆固醇，降低饱和脂肪酸，而增加单元不饱和脂肪酸。为了推广这一产品，1988 年底，清香油拍了一个 100 秒的电视广告，而且投资了近 6000 万元的广告费，目的在于介绍商品的性质，并争取 10%的市场占有率。
