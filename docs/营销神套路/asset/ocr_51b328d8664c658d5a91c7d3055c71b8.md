为什么会出现宠物租赁这种生意呢，我们中国一般都是销售宠物，对吧？

# 一、客户痛点分析：

+   1、可能是由于父母担心豢养宠物会耽误孩子学业或影响孩子健康

+   2、可能是学校或单位宿舍的相关管理制度严格，不允许长期养宠物

+   3、也可能是居住面积狭窄，不方便饲养宠物，更为普遍的原因是工作太忙，无暇照顾宠物，所以他们无法长期在家饲养宠物。

# 二、接下来分享该宠物租赁服务的特点：

对于这些人来说，宠物租赁服务，自然是又贴心、又理想。

在宠物租赁商店的商业模式中，对外租赁价格很低，还要负担宠物大部分时间内的食物、用品以及洗澡、免疫、医疗等费用，整体计算下来几乎无利可言。

就是说他们做宠物租赁服务，是不怎么赚钱的。
