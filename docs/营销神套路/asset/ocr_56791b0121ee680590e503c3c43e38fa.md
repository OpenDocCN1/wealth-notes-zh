# 第 26 课：共同语言的广告套路

下面是一诺老师在线下交流时给亲传弟子分享的一个案例。

从 1886 年饮料先驱可口可乐推出“畅饮可口可乐”的口号以来，大约每隔一段时间，它就会推出一句风行全世界的口号，例如：

1960 年的“可口可乐，才是真正可乐。”

![](bbox=[0.14, 0.45, 0.9, 0.59])

1970 年的“心旷神怡，万事如意，请喝可口可乐。”

1980 年的“微笑的可口可乐”。近几年所采用的则是“就是可口可乐”。

不过，据说还有一句更新的口号已经推出，人们将其翻译为“如此感觉无以伦比”。
