# 攻略1：按个人习惯学习，高效又方便

![](bbox=[0.28, 0.00102, 0.86, 0.00132])

+   ① 优化浏览方式：看图文、听音频任你选，满足不同使用场景
② 倒序查看，方便翻阅早期内容
③ 进入专栏首页，选择右上角的「更多」按钮

进入学习小组

最新版得到已将专栏简介置入「更多」内，其会涉及专栏更新时间、适用人群等详细信息

点击打开「文章推送更新」，第一时间收到本专栏更新提示，别错过好内容

# 攻略2：积累个人「得到」资料库

![](bbox=[0.1, 0.00235, 0.95, 0.00268])

+   1. 划重点：长按内容文稿部分，「划线」标记重点
2. 写想法：长按内容文稿部分「写想法」，记录针对本段文字的感悟笔记，「加标签」方便查找
3. 分享干货文字：长按并选中需要的文字部分，选择「分享」，将你收获的金句、方法，以图片形式保存或分享给朋友
4. 以上内容，均可在 App 首页 - 我的 - 文章笔记 中查看
5. 看到好文章，点击「请朋友读」左侧的「大拇指」点赞，所有点赞音频和文章都可以在 首页 - 我的 - 我赞过的 中收藏

# 攻略3：活用分享，帮助朋友解决问题

![](bbox=[0.08, 0.0037, 0.92, 0.004019999999999999])

+   1. 点击右下角的「请朋友读」，将好文章免费分享给朋友读
2. 看到干货文字，长按文稿，以卡片形式分享给需要的朋友
3. 当然，如果你是本专栏的死忠粉，也可以在专栏首页右上角的「更多」中，选择「推荐给朋友」，直接安利给朋友

# 攻略4：进入「聪明家长会」学习小组，背靠万人智囊团

![](bbox=[0.1, 0.004900000000000001, 0.9, 0.0053])

+   1. 如何进入学习小组？
得到首页 - 我的 - 学习小组 - 聪明家长会
专栏首页 - 右上角「更多」 - 聪明家长会
通过每篇文章结尾的浅绿色框，进入聪明家长会
2. 如何发帖：点击聪明家长会顶部的「打卡」按钮，连续打卡三天即可发帖
3. 发帖格式及要求，请详细阅读学习小组置顶贴「必看 | 聪明家长会，怎么玩」

# 攻略5：快速定位内容，好知识，用起来

![](bbox=[0.1, 0.0064, 0.9, 0.007])

快速搜索专栏内容

得到首页左上角 放大镜标识 - 选择专栏内容 - 输入关键词 “智力脑” “情绪脑” “语言脑” 即可查找
