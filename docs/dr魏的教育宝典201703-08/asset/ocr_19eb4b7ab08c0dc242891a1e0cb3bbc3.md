# 如何利用记忆术？

1个观点：
记忆术利用声音、空间视觉信息或联想作为线索，把需要记忆的信息，多加一层信息转换。懂点记忆策略，搞定一些陌生而抽象的内容就够了，没必要专门学。

特效药：
1.声音编码，把诗歌变成朗朗上口的歌谣，方便记忆
2.视觉编码，画一个图形，记住单词的意思，比如画一个香蕉，代表字母C
3.联想编码，拆分理解，再整合记忆
