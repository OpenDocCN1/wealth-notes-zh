# Dr.魏

宝宝不喜欢搭积木，有时候可能是太难，产生畏惧情绪。她让你搭，那么不妨给她做示范，在搭积木的时候应该注意什么，比如大积木在下面垫底，再放小的，那么不容易倒。这个过程你可以要点“小心机”，让宝宝帮着拿积木、放积木，渐进式地参与进来。

注意，不要搞太复杂的，宝宝觉得自己做不到，更不愿意动手。如果宝宝玩的过程是有自信的，那么她会感兴趣。这需要你及时肯定宝宝的“闪光点”。积木是用来创造的，给谁创造？创造什么？你可以从绘本、故事里汲取灵感。

比如，给小猪佩琪盖个房子，给小火车头托马斯盖个车站，给过河的小马建一座桥。这样一来，你们搭的不是积木，而是有故事的积木。如何给孩子肯定？推荐阅读《016｜表扬有技巧：别让夸奖害了孩子》（可截文章末尾的推荐阅读查看）。
