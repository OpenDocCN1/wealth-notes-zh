# 今日问题：爸爸天生不会带孩子吗？

Dr.魏

这个星期天是母亲节，各位妈妈一方面是女儿，要给自己的母亲送上祝福和感恩，另一方面是母亲，自己的孩子还太小，要指望他来给你过节，不现实。

那怎么办呢？难道你身为母亲，却不能过母亲节吗？

当然不是。至少我每年都会给我太太好好地过个母亲节。倒不是说买多少蛋糕、送多少礼物，而是在这一天，我尽可能多地带孩子，让她可以会闺蜜、逛商场、做美容，反正这是属于她的节日，她想干嘛就干嘛。所以我的口号一直是：

母亲节的最好礼物，是爸爸带孩子。

# 科学论证：爸爸可以带孩子

有些妈妈可能不太放心：“啊？让我们家那位带孩子？你都不知道他有多不靠谱！让他带孩子，非把孩子带到沟里去不可！”，还有爸爸会说：“唉，带孩子是女人的事。我也想着带孩子，天生不会啊！“

让爸爸带孩子，乍一听有点心灵鸡汤。所以，我今天送给各位妈妈的母亲节礼物是，从科学上来说论证，爸爸也应该带孩子！
