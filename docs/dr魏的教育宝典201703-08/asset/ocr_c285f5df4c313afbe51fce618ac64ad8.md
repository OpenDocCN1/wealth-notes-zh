# 1.分享聪明白家长 @徐楠 提供的一个培养孩子阅读习惯的好方法：随机奖励

@徐楠：奖励机制可以根 据各个孩子 的不同的喜好而设置，但一定要是随机的。刚开始的时候，我也是给固定的奖励，比如说买一个玩具，看半小时电视等等。
但是很快发现，孩子们对这个就没有什 么热 something 了。后来我就给他们设计了一套随机奖励机制。我的具体办法是用一套扑克牌，其中有一些扑克代表着看半小时电视，有一些代表着看一部电影，有一些代表着一个小乐高玩具，有一些代表着一个大乐高玩具。每天，只要他们完成了他们应该完成的 目标，就会有一次抽奖的机会。抽的奖他们可以选择马上兑现，或者留到周末，也可以小小地升级一下（延时享受）。
结果是，我的儿子上瘾一般地阅读。读完一本书，得到一次抽奖机会，如果奖品都不满意，他会马上要求阅读第二次。后来我就不得不劝他不要读了。后来，实在是控制不了了，我就把游泳训练也加到这个体制里来。我就对他说，你记得sophie 吗（ 7 habits for happy kids，写高效率人的七个习惯那个儿 子写的），你需要平衡你的生活。
如果完成游泳教练给你布置的训练任务，也可以得到一次抽奖机会。游泳和阅读只能交替进行。刚开始的一段时间，他完全是被奖励机制所激励，而每天坚持阅读和游泳。但是到了现在，在不 知不觉中，他已经非常非常喜欢阅读了。他自己甚至都 没有意识到这一点，还觉得他阅读就是为了得到奖品。
现在他的妹妹三岁了，愿意学哥哥做的事情。我就把妹妹的学习任务交给了哥哥，让他用我教他的方法教妹妹，哥哥非常非常高兴，也很有成就感。这个方法还有一个附带的 好处，就是让我孩子了解了概率。其中最大的奖品是一个大型乐高玩具，大概有1%的中奖概率。刚开始的时候，我的儿子觉得，他总是可以得到这个奖品。
但是过了 好好长长时间，大概半年左右，他一次都没有得到这个奖品，他最多只得到一个中型乐高玩具（大概2%的中奖概率）。我希望他最终能得到一个结论，抽奖和赌博，都是不靠谱的事情。
这套东西我完全是根据电子游戏的规则设计出来。好多大人对这套规则都完全没有抵抗能力，何况是孩子。
我的看法是：这个方法非常好，一方面调动了孩子的积极性，另一方面随机奖励的方式避免了孩子过于依赖奖品，结果将阅读这件事情当成外在的动机，而 不是内化成自己的内在兴趣了。

# 2.分享 @W.Q 关于表扬儿子的一段反思，既有反思又有改进方案，聪明白家长认证！

@W.Q ：“成长型心智” 将来对应的应该是 “进取型人格”，“固定型心智” 将来对应的应该是 “表现型人格”。一不小心，自己总是掉坑里，平时经常表扬儿子，每每都是泛泛地表扬，口头禅就是“宝贝真棒”。以前时不时还会说“宝贝最棒了”，老公听了，小纠正一下，“把最字去掉了，老是说最，这样他以后会有压力的”。嗯，好好像有道理，于是就把“最”去掉了。
看了老师今天的文章，发现也没好到哪里去。反思一下，我家经常夸孩子的几个点：1.颜值。儿子因为长的像爸爸，孩子他爸，他爷爷奶奶，每次都会说，“宝宝长得真好看，真帅，穿什么都好看”，每当这时，我就会跟老公讲，“你希望他将来靠脸吃饭吗？”我隐约觉得他们这样高频率地夸孩子长相，肯定是不妥的，这样会让他觉得长的好看能得到大人的夸奖，看来长的好看最重要，于是把注意力就放在了颜值上。
对应老师说的，那这个问题到底应该怎么纾解？长相，是与生俱来，不需要努力就能获得的，如果就这个 问题一直夸，那其实现就是在培养孩子的“固定型心智”，所以，我觉得，就不应该去夸奖，那如果别人夸奖自己孩子长的好，为了不让孩子太过于在意这件事，那我岂不 是要说，“宝贝，长相这个事其实跟你没太大关系，主要是由爸妈的遗传基因决定的”。
2.日常小行为。比如说能用杯子自己喝水了，或者自己能单独站一会儿了，或者把饭吃完了……总要加一句“宝贝真棒”，或许以后可以把表扬说的更具体，“宝贝前几天还要妈妈扶着杯子喝水，今天就能自己单独用杯子喝了，有进步，真棒”，关注点放在成长上。
3.早教。从三个月开始给孩子看早教卡，早教老师总是强调，上完课要表扬孩子，亲亲或者抱抱孩子，我也是这样做的，每次都表扬，同样还是那句，“宝贝真棒”，棒什么？怎么棒了？做了什么棒了？或许还应该是更具体一点，比如“宝贝今天又多学了两张卡片机，多知道了两个知识点，真棒”。引导学习新知的乐趣，“宝贝今天看得比昨天认真啰”，鼓励态度，“宝贝今天自己拿点读看看的，真棒”，鼓励互动。总之，多观察，多留意，才能说出有建设性的鼓励语句来吧。
我的看法是：多观察，多留意，才能说出有建设性的鼓励语句来——很好的总结！说“真棒”很容易，但说出有建设性的话来，很考验大人的能力！这也可以用于跟其他人的互动。特别别人工作很棒容易，但是能够句到点上不是更得人心么！
