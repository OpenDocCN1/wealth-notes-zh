# 快乐教育真好吗？

现在流行一个词，叫快乐教育。信奉快乐教育的爸妈们认为，得给孩子快乐的童年，不能“训练”孩子，要顺其自然。前阵子，有一个琴童的妈妈跟我聊起她的苦恼：孩子5岁的时候，兴致勃勃要学钢琴，家里费大功夫找到了一个有名的老师，老师也觉得这孩子乐感挺好，就收了。

可是没到半年，孩子就不愿意再学了，一到练琴的时候就推搪，甚至哭闹着不愿意练。妈妈很犹豫，到底要不要让孩子坚持学下去呢？

一方面，孩子对钢琴感兴趣，乐感也不错，妈妈希望他能坚持下去，不指望他成为艺术家，至少可以陶冶性情，多一个表达自己的方式。另一方面，孩子练琴又练得很痛苦，妈妈挺不忍心毁掉孩子的快乐童年。

# 练习是必要的，但父母可以帮助孩子减轻负面情绪

不管孩子想掌握什么能力，练习都是必要的，不管孩子天赋有多高。我强调一遍，没有什么不练习就能取得成就的天才，几乎所有的天才，都是后天刻苦练习雕造出来的。
