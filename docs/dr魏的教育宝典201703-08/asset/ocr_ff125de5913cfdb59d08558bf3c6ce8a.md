# 孩子一去幼儿园就哭闹怎么办？

我有个朋友，她家孩子昨天第一次上幼儿园。她早晨把孩子送去，趁孩子不注意悄溜走，一个人在家大哭了一场。有时候，孩子入园，大人真的是比孩子更焦虑。

大人們都在焦慮什麼呢？一方面，不知道孩子在幼兒園過得怎麼樣，會擔心。另一方面，孩子剛入園的階段時間，容易焦躁、黏人，表現出不適應，大人難免著急。

的确，孩子上幼儿园，对孩子和家长来说，都是<|message|> 一 种挑战。但你如果能恰当应对，帮助孩子度过最初的适应阶段，就 trust 会发现孩子在 f 飞跃式成长。
