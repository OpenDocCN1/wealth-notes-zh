# 情绪脑｜小龄宝宝如何批评？

Dr.魏，您好，我家宝宝现在15个月，很喜欢咬人，每次她咬人，我都会很严肃地告诉她：不可以咬人，你咬了别人，你和被咬的那个人都会很痛的。因为她还不会说话，所以不知道该教她怎样表达自己的情绪。

我想请教Dr.魏，一是我的批评方法是否就是您所说的成长型批评，二是对于还不会语言表达的孩子，该教她如何表达自己的不满情绪呢？

Dr.魏

很多宝宝都会有咬人行为，虽然无故被宝宝咬出一排牙印，肯定是又痛又气。首先先位妈妈能压制住自己的情绪，不是单纯告诉孩子不可以做什么，而是跟孩子解释这背后的原因“你和被咬的那个人都会很痛的”，能理智地跟宝宝讲道理，这种批评方式很好，能帮孩子内化道理和规则，有助于他们成长。

不过这时侯小龄宝宝的理智脑还没有发育成熟，参见《情绪脑｜坚持这三步，搞定发脾气的娃》。这时候讲道理他们不一定能理解，也就是回到你的第二个问题，对还不会用语言表达的孩子，该如何引导小龄宝宝表达他们的消极情绪？

# 情绪脑｜批评过激，“打”了孩子怎么办？

小孩子经常说，“我一点都不喜欢爸爸妈妈，因为每次我不听话的时候，你们就要打我。”其实我们只是打过她一次，她就记住了，现在就经常这样说，我都担心，她会不会现在听我们的话，就是怕我们打她，怎么办呢？

# 运动脑｜精细运动，家长怎样更好地引导？
