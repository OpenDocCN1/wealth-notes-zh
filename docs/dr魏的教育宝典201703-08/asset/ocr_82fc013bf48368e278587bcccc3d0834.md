# 21天就能帮孩子养成一个习惯？

我看到一个妈妈留言，说孩子坏习惯特别多，比如不爱刷牙。幼儿园里很多小朋友已经开始有龋齿了。跟孩子讲多少遍不刷牙的坏处，他就是不配合，一逃跑，二闭嘴，三哭闹，像要了命似的。

不就刷个牙嘛，怎么就这么难？她说网上有21天养成一个习惯的说法，问我能不能在21天之内，让孩子养成刷牙的习惯？

你肯定经常看到朋友圈和微信群里有各种打卡活动：21天隐形计划、21天坚持读书、21天断嘴食…孩子能不能21天就养成一个好习惯呢？这听起来很诱人，但并没有科学依据。

这个说法，可能是来自于美国一位整容医生麦克斯威尔·马尔茨（Maxwell Maltz）在1960年写的一本书《心理控制论》。

马尔茨博士在书中写到，通常情况下，截肢病人需要21天才能接受他们失去肢体的事实；而整容后的人，平均需要21天来习惯手术之后的新容貌。人们需要21天来适应生活中的重大变化，但跟养成一个习惯是两码事儿，后者远远多于21天。
