# 男人发型。

发型是个很贵的消费。你看 KTV 的优秀女同学，每天小保养是一百，隔段时间还要做大保养，几百元，每天还要在臭烘烘的发行坐小半天。大部分男生是没有时间和金钱，去摆弄头发的。

但是，发型是男生的第一形象，必须重视。怎么又省钱又方便？

1，两侧头发撸干净。看上去就比较干净了。油腻大叔的标配是，鬓角长乱白，配上一小撮冲出来的鼻毛，恶心到吐。

2，平时用吹风机，吹五分钟，基本整齐就行了。

3，上班时间，略微用点摩丝，头发整齐有光泽。

4，至少二十天理发一次。

只想睡，不结婚的男人，肯定是讨人喜欢。

天天说小美白好话（反正不要求你改什么缺点），

花钱大方（比去 KTV 便宜），

说话幽默风趣（占了便宜心情好）。
