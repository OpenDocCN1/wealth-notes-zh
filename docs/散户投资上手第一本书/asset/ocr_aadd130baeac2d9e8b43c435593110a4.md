# 人來瘋，不會在股市成功

有智慧的人最好能利用群衆心理，來觀察漲跌趨勢，切忌隨群衆起舞。

要不要天天去號碼看盤呢？意志不堅者最好不要天天去號碼（證券公司的看盤大廳）。

能不能永遠都待在家裡（辦公室）電話（網路）下單呢？答案是：可以。
