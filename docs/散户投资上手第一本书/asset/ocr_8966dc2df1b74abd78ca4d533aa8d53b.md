# 被套牢了，怎麼辦？

碰到套牢虧損時，情緒會變差，理智會衰弱，會變得不敢停損。此時要冷靜下來，思考一些事情。

對新手而言：買股票是很簡單的事（因為他會亂買），賣股票是很困難的事，「上車容易下車難」。

對初級投資人而言：進場時機的挑選比較重要，出場比較簡單，「下車容易上車難」。

對資深投資人而言：抱單比較重要，「待在車上不動，忍著不下車，很難」。

對投資老手而言：部位最重要，「進出都是大手筆，超難」。

我建議初學者不可偏廢，要知道以上這些都很重要。然後，很多股市贏家都會異口同聲地說：停損最重要。
