# 股市大崩盤，令我反省

+   （1）就是因為人類的科技愈來愈發達，於是工商業的競爭淘汰也就愈來愈激烈，賣的東西愈來愈便宜，利潤愈來愈薄、股利愈來愈少，股票的價值當然也有可能是愈來愈低。學如逆水行舟，不進則退。不上進的公司當然會被時間所淘汰。
