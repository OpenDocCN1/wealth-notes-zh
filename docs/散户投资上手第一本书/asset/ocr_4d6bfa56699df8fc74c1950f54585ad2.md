# 11
## 一、对《办法》的总体评价
- **总体评价：**
  国家金融监督管理总局发布的《商业银行互联网贷款管理暂行办法》(以下简称《办法》)，是规范商业银行互联网贷款业务、防范金融创新带来的风险、推动互联网贷款业务规范健康发展的重要监管规则，是我国首部专门针对商业银行互联网贷款业务颁布的规章。《办法》顺应互联网金融发展趋势，通过明确互联网贷款业务基本规则，既支持商业银行运用互联网等现代信息技术手段进行贷款业务的创新，又能将商业银行互联网贷款业务纳入有效监管，防范金融创新带来的风险，推动互联网贷款业务规范健康发展。
- **《办法》的核心要点：**
  《办法》共五章34条，对商业银行互联网贷款管理的基本规则进行了明确规定，包括互联网贷款概念及特征、业务准入、贷前调查和贷款审批、贷款风险监测和预警、客户投诉、营销管理、数据管理、合作机构管理等。

# ## 二、主要内容和理解
- **(一) 总体要求**
  商业银行要遵循依法合规、安全可控、普惠便捷的原则，运用互联网等现代信息技术开展贷款业务，以优化业务流程、提高金融服务效率、提升风险识别能力。商业银行应强化互联网贷款管理，确保贷款业务全流程管理的有效性，实现互联网贷款业务规范健康发展。

- **(二) 定义**
  《办法》明确了商业银行互联网贷款的定义，即商业银行运用互联网和移动通信等信息通信技术，基于风险控制和成本可控前提，为符合条件的特定客户提供的，用于满足其融资或相关消费需求的本外币贷款。

- **(三) 适用范围**
  商业银行互联网贷款包括个人消费贷款、个人经营贷款和小微企业贷款，不包括个人住房抵押贷款、个人商用房抵押贷款等。

- **(四) 业务准入**
  商业银行开办互联网贷款业务应符合以下条件：
  1. 具备相应的业务管理能力；
  2. 有符合要求的互联网贷款业务系统和信息系统；
  3. 有完善的风险管理体系；
  4. 有明确的风险控制措施。
  开办互联网贷款业务的商业银行应当在每年3月31日前，向国家金融监督管理总局或所在地银保监局报送上一年度互联网贷款情况，包括互联网贷款业务规模、业务结构、风险管理、合规性等情况。

- **(五) 业务模式**
  商业银行开办互联网贷款业务，应根据业务模式和风险程度，审慎确定贷款期限、额度、利率等定价，实现收益和风险均衡。商业银行应自主确定贷款审批，不得将授信审批、资金支付等核心业务外包。

- **(六) 贷前调查和贷款审批**
  商业银行应独立开展贷前调查和贷款审批，不得将贷款审批等核心业务外包。商业银行应通过互联网技术手段，合理确定授信审批的自动化程度，对无法进行有效风险识别、评估或控制的贷款，应采用人工方式进行审批。

- **(七) 贷款风险监测和预警**
  商业银行应通过互联网技术手段，实现贷款风险监测和预警。商业银行应定期对互联网贷款风险状况进行评估，对风险状况发生变化的贷款应及时采取措施，降低贷款损失。

- **(八) 客户投诉**
  商业银行应建立有效的客户投诉处理机制，及时妥善处理客户投诉。商业银行应通过互联网技术手段，实现客户投诉的及时处理和反馈。

- **(九) 营销管理**
  商业银行应规范互联网贷款营销行为，不得发布虚假、误导性信息。商业银行应建立有效的营销管理制度，确保营销信息的真实性和准确性。

- **(十) 数据管理**
  商业银行应加强互联网贷款数据管理，确保数据的安全性、完整性和保密性。商业银行应采用加密、访问控制等技术手段，保护客户数据和贷款数据。

- **(十一) 合作机构管理**
  商业银行应与互联网贷款业务相关的合作机构签订合作协议，明确双方权利义务。商业银行应对合作机构进行尽职调查，确保合作机构具备相应的资质和条件。
