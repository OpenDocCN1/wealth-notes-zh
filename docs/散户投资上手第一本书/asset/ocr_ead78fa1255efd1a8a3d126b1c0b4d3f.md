# 14
什麼樣的「利空」環境才能進場？

股市走空一定有它利空的消患面作祟，投資人應客觀分析籌碼面與基本面，配合技術面的輔助等待底部浮現。

買股票當然要逢低買進，但是小心低還有更低。

不管是石油危機、戰爭爆發、政治鬥爭、金融風暴種種利空所造成的股市下跌，散戶切忌躁進，必須先冷靜下來做一些功課：

+   （1）檢查利空消息發生時，股市在相對高檔還是低檔。

如果之前已經漲了一大段，小心藉著此一利空來個大回檔，鐵定會跌昏一票人。如果已經跌了一大段，小心藉著此一利空來個「超跌洗盤吃貨」，「跌到令人無法想像的地步」，然後再來個超級大回升。

不過，只怕等不到回升，散戶就已經在「超跌段中許多自以為是的反彈」中慘遭套殺，賠掉老本。
