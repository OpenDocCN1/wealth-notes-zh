# 如何在西尔斯获得退款

你只要要求，就能得到！西尔斯，罗巴克公司承诺：保证满意，否则退款。没有如果，还有，但是等问题。看看西尔斯是如何履行他们著名的保证的吧。不是有时会履行，而是一直。

“我们保证您满意，并安全地为您寄送您订购的任何东西。”

这些文字，是理查德·西尔斯——一个年轻的芝加哥商人 62 年前写的，他通过给顾客绝对公平的交易，建立了一个大型企业。

如今，西尔斯，罗巴克公司依旧履行着它的承诺：满意保证，否则退款。

西尔斯怎么有能力承受这样的保证呢？通过保证人们满意。

第一：西尔斯采购人员和他们的供应商有密切的联系。这些供应商知道，只要他们满足了西尔斯高质量标准的要求，西尔斯就会定期大量在他们那里进货。

第二：西尔斯拥有世界上最大的私人实验室，来测试他们的产品。这个实验室对任何不符合高标准的产品，都有绝对的否定权。

第三：西尔斯永远不会把质量当作理所当然。即使一款产品已经得到西尔斯实验室的认可，他们还是会密切关注，确保质量永不变。

# 罕见的例外

西尔斯尽一切人力能做到的事情，防止问题出现。但是，时不时地总会出现一些问题。假设有一个问题发生在了你身上。

你只要把它拿回来，说明问题。你就知道西尔斯说的：保证满意，否则退款，所言不假了。
