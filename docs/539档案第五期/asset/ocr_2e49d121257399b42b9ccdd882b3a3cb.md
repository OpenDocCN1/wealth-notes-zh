# 电子钟价格如何？

如今的电子钟，已经非常接近人们理想中的时钟了：走时精准，不用麻烦地去上发条。

电子钟淘汰了需要上发条的钟。而且，电子钟走时非常准确。还有更大的消息告诉大家：大多数电子钟，事实上比需要上发条的知名品牌的钟还要便宜！

需要上发条的钟，依靠定期给它们上发条，才能走时。比如，老式钟，需要两个发条。“计时间的”发条，以及“计闹钟的”发条。每晚都要重新上发条。

相比之下，你选择一个电子钟，就能一劳永逸了。电子钟永远不需要上发条。它们靠小电动机带动，走时非常准确。

这种特殊的电动机，是马塞诸塞州亚什兰的亨利·E·沃伦发明的。正是这种电动机使得现代电子钟成了可能。

1916年，第一款使用这种电动机的钟被发明，但是，存在一个问题……要么时间走得快，要么走得慢。最后发现，原因是，电流不稳，无法保证稳定的60赫兹。为了解决这个问题，发明家必须研究一款主时钟，来维持稳定地输出60赫兹，现在几乎所有电子产品都在使用这种装置。

如同大多数新产品一样，最早的电子时钟价格非常昂贵，需要25美元。今天，电动报警器，彩色电子厨房时钟，售价仅为3.98美元，含税！
