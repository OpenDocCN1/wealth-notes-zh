# 如何帮助你一劳永逸，彻底消灭杂草！

你可以消灭每年丛生的杂草。但是，你只用除草剂做不到这点——即使使用的是阿格力克苗前除草剂这么有效的药物也不行，你需要双管齐下：

# 1. 先清除杂草小苗

随着土壤变暖，杂草就会开始发芽。喷洒一次阿格力克苗前除草剂，就会防止杂草幼苗长成和小草一样的大苗。阿格力克苗前除草剂能杀死两叶阶段的杂草。但是，最好现在就用。

# 2. 接着——培育你的草坪

杂草最大的敌人是浓密，健康的草坪。这种草坪会排挤杂草，因为这种和小草似的杂草种子发芽需要阳光，生长空间以及空气，才能发芽，生长。

培育一片浓密的草坪，需要施加富含氮，磷和钾的养料。阿格力克草坪养料（含 60%的有机尿素），就包含这些必要元素，还有其他很多对草坪好的元素。每袋阿格力克，能带给你比其他许多普通草坪肥料多 30%的养分。所以，阿格力克可以让小草长得更茁壮。
