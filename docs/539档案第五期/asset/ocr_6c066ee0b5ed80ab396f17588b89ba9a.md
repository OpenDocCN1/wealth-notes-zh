# 说到狗狗

# 我曾经是个少年犯

来自：蒂洛

歌剧电影明星
劳里茨·梅尔基奥口述

有一件事可以确定……我落到那种地步，不能怪我的父母。我来自一个很好的家庭。我妈妈是一个著名的小动物猎手。我就不提她的姓名了，因为你可能认识她。

我也不能完全怪我的老板。当然，他是忽视了对我的训练，但他是一个心肠软的人，不愿意说不。我只是一个6个月大的小狗，充满了斗志，对什么都跃跃欲试。

当我一个人被留下的时候，我遇到了一群狐朋狗友……附近的其他3只狗。天呐，我们的日子真可以说是逍遥自在！在花园里乱刨，弄翻垃圾桶，追小猫，钻灌木丛。哇！太美了！

然而，大街上另一条狗和我们却不同。它待在自己的院子里，主人随叫随到。非常有礼貌的一个小家伙。我们嘲笑它，称它为“大姑娘”。但是，内心深处我却很羡慕它——它似乎很快乐。

而我的日子越来越糟，直到有一天，我弄坏了邻居家的杜鹃花。我的老板十分恼火。起初他说要扔掉我，后来他把我关到车里。我以为我无可救药了！
