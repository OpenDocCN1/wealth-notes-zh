# 第一款安全有效的草坪养料故事

培育出完美的理想草坪，需要 16 种元素。

有了这些发现，维果应运而生。这是唯一一款纯植物养料，除空气和水以外，富含植物需要的所有养分。

在过去的 30 多年中，科学家们对该配方进行了无数次测试和完善，直到找到草和其他植物最好的养料。但是，给小草上养料的方法一直是个问题。你看，一般给小草上养料，是把所有养料全部撒在小草上面。除非接着浇水，否则小草会被烧死。

草被烧死。一部分原因是“渗透”现象。通俗的说就是：植物养料在水中溶解，因为它“渴”。

当撒在叶子上时：植物养料会吸收每一滴他们能吸收到的水分。

但这还远远不够。它们会吸收叶子中的水分。叶子开始被灼烧。

过去，降低对小草灼烧的唯一方法，是在上完养料后，给小草浇水，或松土……或者，每一个月左右，给草上一次“熔化后”的草养料。

但是，维果的科学家并不满意。他们想要一个不会灼烧小草，能够一次上足，持续一整个季节——不需要浇水的养料。

为什么？因为每次灼烧——即使轻微到看不见的灼烧——对小草也是一次伤害。这样的伤害，会让小草暴露在大风，烈日，昆虫，疾病之下。
