# 如何管理你的情绪...

# 过上更幸福，更健康的生活

我们每个人偶尔都会情绪不安。幸运的是，大多数人——像表面看到的那样——都有能够缓解紧张情绪的其他爱好，或娱乐活动来转移忧虑或紧张的情绪。

他们不愿接受现实，不愿坦然面对自己或大或小的问题。

这些持续、无法解决的情绪问题，使得我们无法过上健康、快乐的生活。因为身心是紧密联系的，它们会相互影响。

除非我们明智地处理情绪问题，否则它们会打击我们的精神，耗费我们的精力，引起一些身体疾病或障碍。包括心悸、消化不良、关节和肌肉疼痛和慢性疲劳等。此外，高血压、溃疡、和一些过敏症状通常也是情绪问题引起的。

事实上，大部分病人在就医时，因为情绪严重波动引发了一些疾病，或让疾病雪上加霜。所以，医生们比以往任何时候，都更重视情绪在疾病治疗中扮演的角色。

情绪疾病的治疗需要时间和技巧。医生需要知道病人的很多生活细节——尤其是病人的情绪反应给大多数人带来麻烦时。

有了这方面的知识，他就可以帮助病人解决这些引起，或部分引发他们疾病的恐惧和忧虑。他可以帮助患者学习新方法，来观察和处理可能让他们情绪紧张，不快乐或生病的问题。

如果你曾经被情绪问题压得喘不过气，记住，克制这些情绪非常不明智——很不健康的做法。你要和自己的医生去讨论这些问题。他推荐的诊所医生，或者别的精神科医生，很可能能够帮你找到烦恼的根源，让你重新获得更好的心理健康。
