# 黏膜——主要的敌人

你所感觉到的附着在牙齿上的那种黏膜，便是牙齿的主要敌人。它附着在牙齿上，进入到牙齿中间，并且会停留在那里。它会使牙齿失去光泽，然后长时间对它们进行攻击。如果 你放任不管，它会日日夜夜对你的牙齿进行不断地伤害。

黏膜会吸附污渍，使牙齿看起来很脏。它是构成牙垢的主要成分。它会吸附可以发酵，并形成酸性物质的食物。而它所存留的酸性物质会不断地与牙齿接触，从而腐蚀牙齿。
