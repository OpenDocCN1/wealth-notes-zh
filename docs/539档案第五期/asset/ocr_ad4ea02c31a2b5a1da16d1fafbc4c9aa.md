# 为什么西尔斯聘请泰德·威廉姆斯？

理由非常简单。为了使西尔斯的每个运动装备在进入公司的目录册，或进入 740 个商店中任意一家之前，都能得到客观、冷静、专业的质量分析。

威廉姆斯的顾问工作非常重要。他帮助西尔斯挑选要销售的运动器材。他亲自对每个运动器材进行实地测试。为了确保西尔斯在体育器材领域遥遥领先，他会给出专业的改进建议。

例如，他可能会建议给旅行拖车配备更大，更坚实的轮子。给狩猎靴配上更轻的鞋底。给守场员的手套配上更柔软，更轻薄的皮革内衬一让人“感觉”更不受约束。

确保自己的产品真正实用一直是西尔斯主要理念。这就是为什么西尔斯投入 50000000 美元对它的所有产品进行测试。

这也是为什么西尔斯聘请泰德·威廉姆斯。如果传奇人物威廉姆斯鹰一般的眼睛都找不到产品缺陷。那么西尔斯就可以确定这款产品绝对是一流的。

西尔斯运动器材上印有的“泰德·威廉姆斯”并不只是个名字而已。
