# 氟化物对牙齿健康作用的报告

龋齿，是继感冒之后，人类最常见慢性病。但是，现在科学家们通过在以下 3 个方面应用氟化物，在对抗龋齿方面已经取得了突破性进展：1.在饮用水中加入氟化物；2.牙医在给患者治疗时，直接在局部应用氟化物；3.在牙膏中使用氟化亚锡。

如果要选择含氟牙膏，请注意下面一些惊人的事实，可以给你一些指导：（1）并非所有含氟牙膏够含有氟化亚锡，众所周知的抵抗龋齿的成分。（2）有些含氟牙膏还未使用，其中的氟活跃性就会损失高达 80%。 （3）如今市场上，只有一 种牙膏，能让你的口腔“坏境”对氟最有利，从而令氟化亚锡发挥最好的效果。

# 哪种牙膏？

最新牙膏品牌，百普索登含氟牙膏，开创了牙膏新标准，你可以根据它来判断其他牙膏。

首先，它含有氟化亚锡，氟（作为一种牙膏成分）被牙医所认可，是因为它有强化牙釉质，抵御龋齿的能力。

更重要的是，尽管最近的实验室测试证明，所有知名的含氟牙膏，在未使用前就会失去氟的活性（有一个品牌失去了三分之一，其他品牌失去了 80%），而百普索登的氟活跃性能保持到高达几乎 90%——即使开封 6 个月后。

另一个区别：百普索登全新的长效含氟配方，和其他含氟牙膏相比，能让牙釉质更耐酸性腐蚀。这是经过实验室测试证明的。
