# 令人难于置信的 Zippo 打火机
——一个相信打火机应该永远不会坏
的人的故事

第一个制造 Zippo 打火机的人，早期在父亲宾夕法尼亚州的机械维修店里掌握了经商之道，现在仍然掌控着全局。

他掌握了手工技能，学会了机械原理。除此之外，他还学会一样东西：那就是对机械工艺本身的热爱。

19 世纪时，他成为了一名传统的美国工匠——制造实用器械的人。在这行做了很长一段时间。

如今他制造出了实用的打火机。Zippo 打火机。他用心谨慎地制造着每一个 Zippo 打火机，为的就是给顾客提供美国商业史上的最强保证。

不管你用了多久，状况如何——只要你的 Zippo 打火机不能用了——他都会为你免费维修！

一些追求快销产品的现代商人不是特别尊重 Zippo 人的商业意识。

但是，他做的很好。每天晚上躺在床上，他都感觉很好，很安心。这种感觉来源于他制造了真正好用的产品。每次，每年，每代，都如此。一旦不好用了——他都会免费维修。

宾夕法尼亚州布拉福县 Zippo 制造公司，安大略省尼亚加拉瀑布加拿大有限公司。
