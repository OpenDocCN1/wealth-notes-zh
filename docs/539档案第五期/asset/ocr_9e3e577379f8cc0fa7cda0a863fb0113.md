# 如何给孩子 “御寒”

来自比尤拉·法朗士，R.N.：儿童关爱专家，《如何拥有一个快乐的孩子》的作者；关于衣物的一些实用建议

我的一个小邻居正遭受着悲惨的童年，因为他的母亲不知道下雪的冬天给孩子穿什么衣服！整个冬天，我都听见她在叫：“皮特，当心。不要把衣服弄湿。皮特，不要再外面待太久。不要……不要……不要……，皮特。你会感冒的。”

糟糕的是，她可能是对的。冬天在室外玩得太久，可能会生病卧床，因为很多时候，孩子只是看起来穿的很暖和。真正不会让孩子生病的，不在于你给孩子穿了多少衣服，而是你给孩子穿的什么衣服。

我多年来一直致力于研究怎么更好地照顾孩子，我发现羊毛衣服可以让孩子拥有本应无忧无虑的童年，同时给予他们最好的健康保护。经过在大学里对纺织品的研究，我知道，这当中有很多道理。

首先，羊毛能能留住温暖，把冷气挡在外面——不管是什么样的天气，它都可以持续给人舒适和保护。纯羊毛甚至能够“带走”雪花的湿气——因为，每个羊毛纤维都有自己的“雨衣”，使织物能够自然防水。

同时，羊毛还能防汗（玩耍通常会让孩子出汗），它可以吸收皮肤上的汗水。因为每个羊毛纤维中都有细小的毛孔，可以吸收水蒸汽。这就是为什么羊毛衣服可以保护孩子免受潮湿，还有出汗后身上湿冷而导致的“感冒”。
