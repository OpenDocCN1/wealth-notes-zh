当你掌握了这套撰写销售文案的方法之后，你再写引流文案，免费赠品文案，朋友圈文案，微信内容，企业形象广告，等等，你都能轻松自如。

# 透露秘诀

举个例子，在此研习班中，你将学会：

+   ○ 我的独门秘笈。无论你是否写过销售文案，你都能下笔有神（你在撰写文案的时候，就不会像面对一张白纸一样，不知道如何动笔。）
○ 透露给你撰写销售文案的两个重要铁律。能让你的文案吸引力比原来增强 2 倍。
○ 如何站在客户的角度思考问题——90%的人都无法真正换位思考（这是一个大的秘诀，有 3 种方法可以帮你真正了解客户，按照客户的角度、语言来写作。）
○ 什么时候该用长文案？什么时候该用短文案？（长、短文案，要根据你的目的，你的渠道，你的产品来定，而不是自认为用短文案或长文案。）
○ 一个小故事，让你彻底了解人性，并被你所用。（我并不是教你如何操控别人，让他们做不想做的事情。完全相反，你能学会怎样给对方一个有价值的服务，利用这些达到自己的目的。）
○ 找到你的精准顾客的秘密！（这个方法既省钱，又有效，让你的销量提升 3 倍）
○ 发现自己的产品或服务潜在的价值。（利用这些隐蔽的好处，大大能够促进顾客购买。）
○ 如何了解你的客户，了解你的竞争对手，了解你的产品（不是教科书上讲的大道理，而是实实在在的经验之谈。）
