# 这次不要自己来

回想一下，上次你觉得不像平时那么神清气爽是什么时候？很可能那时候你的某个朋友，没有任何从医资格，但完全出于好意告诉你应该怎么做或吃什么药，来缓解你的“虚弱”或“紧张”或反复出现的疼痛感。

这样的建议让人觉得好像可以“自己动手”配药。事实上，自我诊断、自我用药，可能会带来很大的危险。

除了非处方家庭常用药，其他药物只有遵照了解其特性的医生的嘱咐服用，才是安全的。

比如，即使是温和的泻药，如果是在胃痛的时候服用——或是突发阑尾炎——可能导致最严重的并发症。

使用非处方药减肥是最浪费，也是十分危险的一种自我治疗方法。尽管这些产品通常会“保证”快速而轻松地减肥，但是千万不要被他们诱人的承诺所迷惑。

当涉及到药物或诊断或治疗时，要采取安全、合理的做法——谨遵医嘱，除了医生，别人的话不要听。
