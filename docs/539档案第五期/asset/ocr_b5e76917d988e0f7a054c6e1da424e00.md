# 因斯坦冰茶是如何改变我的看法的

来自：玛丽·玛格丽特·迈克布莱德 作家 演说家 广播人

在我的书《美式烹饪的收获》中，我畅谈了未来的食物理念——通过电子设备衡量食材分量，3 分钟就能烘焙好的蛋糕，甚至还有为太空旅行者专门配备的从挤压管挤出来的食物。我还说，速食食品肯定不能和“自己做的”食物相匹敌。

现在我应该知道了，每当我做出一个断言时，总有一些事情出来改变我的看法。这一次改变我看法的是速溶茶！请注意，不是一般的速溶茶，而是没有添加物，没有碳水化合物的一种新型纯茶！

这种速溶茶叫做因斯坦茶，我第一次喝就觉得它的味道很好。我告诉自己“竟然有口味这么好，而且省时省力的东西，我很高兴不用‘自己做’食物。”

当然，我还需要舀一勺纯茶晶，将它溶解于沸水。然后添加一些冰块，打开水龙头加入水。但这已经是全部工作了。不用等待茶叶泡好，没有滴水的茶包，而且几乎不用下手！

所以，如果你想喝茶，我的甜点可能是我花精力“自己做”的。但是，有了因斯坦速溶茶，我的冰茶却可以速成！
