医疗小组如何找到一个革命性新型“止咳药”……现在证明比麻醉可待因还有效，而且家人食用非常安全

# 瑞士新发现

# 这个冬天，将让5亿人不再咳嗽

这个冬天，广大的美国成人和儿童，将受益于一个专门研究小组的“失败”。该小组研究人员，为了研发一种非麻醉类止痛药，投入了数月时间——结果，发现它并不能止痛。

如今，瑞士实验室的这个“失败”，却能止住感冒引起的令人无比痛苦，烦躁，无法入眠的咳嗽。所有证据都显示，这是医疗史上最有效的非麻醉类止咳药。

# 失败变成成功

这种新药是瑞士研究人员当时研发的许多药物之一。像其他药物一样，它被证明没有止痛效果。但是，一个警觉的医学家注意到，它有另一个特性——镇定神经中枢，止咳。

咳嗽似乎是从喉咙或胸部开始的，但实际上，是大脑的咳嗽控制中心发出的咳嗽“命令”。在瑞士医学家发现之前，只有麻醉类药物，如可待因等，能止咳。但是，可待因可能引起胃不适，抽筋，头晕，还会形成依赖。而他们最新发现的这种药，不是麻醉类药物，却能止咳，没有副作用。

# 现在被广泛使用

在美国一家知名医学中心，对这种新药进行了临床试验。超过30000病例都证明了医学家们的期待——比麻醉类可卡因好很多。如今，越来越多的医生更喜欢给病人开具这种药物，而不是可待因。
