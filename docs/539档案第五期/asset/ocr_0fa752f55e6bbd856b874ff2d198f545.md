# 第一款安全有效的草坪养料故事

几乎从清教徒第一天登陆开始，美国人就试图在原来长草的地方再种上更繁茂的草。

这一切都始于斯夸托，一个友好的万帕诺亚格印第安人，向早期的定居者展示了如何在每座玉米丘陵下方种植青草。

自从开始种草后，无数科学家开始努力研发更有效，更容易使用的植物的食物。

比如，维果植物营养学家花了 35 年时间；来研发草坪和花园的养料。

最近，他们通过和草“谈话”，发现了惊人的秘密。

由此，植物科学家们研发出了第一个“等渗”植物养料。对不做学术的家庭主妇们来说，这简直是一款绝对安全有效的草坪养料。

这个故事是从维果科学家第一次“听”植物谈话开始的。他们把草种种在富含不同植物养料的无菌撒哈拉沙漠沙中。在生长期间，植物说了一些话，科学家们确切地了解到了植物需要什么养料。

他们发现喂养氮、磷和钾，并不能让草茁壮成长，许多生长在自然的肥沃土壤中的农作物也是如此。
