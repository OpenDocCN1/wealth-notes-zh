# 100%速溶纯茶

来自：玛丽·玛格丽特·迈克布莱德 作家 演说家 广播人

曾经习惯辛辛苦苦地用手工制作土豆泥，“在闷热的灶炉”忙前忙后准备布丁和其他特色菜肴的家庭主妇，现在也开始选择速食食品了。如今，她们的厨房里还出现了一种新型速食食品——速溶茶。

然而，在制作真正的优质速溶茶时，需要解决许多问题。最主要的一个就是——如何制作100%纯茶的速溶茶，不添加任何别的味道，如糊精和麦芽糖等。

康涅狄格州斯坦福德标准品牌实验室给出‘答案——经过多年实验研究——研究人员找到了一种在纯晶体‘捕捉好茶味道的方法。

成果就是因斯坦速溶茶。在冰茶杯里，它可以立即释放真正的茶味道。你只要 fidelity 一勺茶晶，在少量开水里搅拌溶化。然后，装满冰和水即可开始饮用。

家庭主妇们都说这款冰茶不仅冲泡简单——不用等待，没有滴水的茶包——而且味道也很好。许多人无法把它和常规方法冲泡的茶区分开。

美国人追求轻松生活的趋势，使得速溶产品的前景一片光明。
