# 医学研究人员发现了一个能满足食欲，又能减肥的饮食方案

# 慢慢享受吧……

在一所著名医药大学的减肥饮食报告上，有一个特别好的消息。许多体重严重超标的人，通过一日三餐食用含有丰富蛋白质，特别能满足人食欲的食物，成功减重 100 磅。

这些人 “既控制了饮食，又享受了美食”，因为他们从美味，诱人的瘦肉中摄入了蛋白质——一次吃双份，一天吃两顿。

肉是这个饮食方案中最重要的东西，同样，我们也推荐所有人都这么吃，既美味，又获得了必需的营养。

蛋白质是人维持生命的重要元素。肉是人体所需蛋白质含量最丰富，最优质的天然食品之一——供我们身体制造血液，肌肉生长，增强免疫力，抵抗感染，营养神经和组织。

B 族维生素，铁和其他重要的矿物质，肉能提供身体所需的大部分必要营养物质。

肉中的脂肪也扮演着非常有益的角色。易消化，不要太过量，不仅能增加饮食的乐趣，还能提供我们需要的能量。

肉中包含丰富的蛋白质，B 族维生素，矿物质，能量（非常美味！）  崔怪人们都说 “肉，真是好东西。”
