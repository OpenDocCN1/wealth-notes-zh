# 表演者表现糟糕、愚钝，冰冷是罪魁祸首

希普斯特德&约翰逊的埃迪·希普斯特德，
世界第一场神话般的冰雪秀的创造者
送给体育爱好者的充满智慧的话

“每次摄人心魄的旋转，每次曼妙的华尔兹舞步，每个准确优美的体操动作背后，都经过了长时间艰苦的练习，以及在潮湿、粗糙、含氮的冰上无数次的摔倒。我无法想象还有什么样的场景能向在冰场上一样，衣服不断地被刮扯，却还必须看起来非常完美。

“比如我们的一个溜冰选手，在 2 年中一直穿着同一套礼服超过了 800 次！能经历这种考验的衣服真不多。但是我们知道，一套精致的羊毛套装，穿 800-1000 次后能依旧看起来和刚买来时一样。

“我们的著名设计师瑞妮告诉我们，原因之一就是因为羊毛纤维具有独特的弹性。溜冰者可以在冰上弯曲、拉伸、扭转、翻转、下落、滑动——而他的羊毛套装却不会变形，失去光泽，或变薄。羊毛这种非凡的弹性，不仅能让表演者行动更自如，带给表演者更多自由，外表更有型，还能给我们省钱。穿羊毛制品，护理和更换成本能降到最低。

“经验表明，羊毛制品可以让溜冰选手表现更好。纯羊毛衣服经过日复一日最残忍的磨损，依旧能保持最好的状态。多年后看起来依旧明亮鲜艳！”

不言而喻；如果羊毛能承受住专业溜冰选手这样的穿着磨损，那么它也能带给你更多保障。溜冰者和滑雪者穿的裤子、夹克、毛衣……粗糙的狩猎衣服……冬季套装，以及美国制造的纯羊毛外套，精纺套装，都能带给你无与伦比的性能。
