# 家庭取暖魔法,节省高达 20%的燃料费

如果你所在的城市也和爱荷华州,苏城的冬天一样出奇的寒冷,那么你一定对雷蒙德·布莱索的经历深有体会。他说直到最近一直觉得自己是这个城市里最不快乐的新房主之一,原因是什么呢? 用他的话来说就是:

“当我们买了新房后,我们选了最好的家居设备。厨房,浴室,杂物间,包括地下室,我们都选择了名牌产品。取暖设备,我们也选了最为广泛宣传的品牌。

# 寒冷的气流——高昂的燃料费

“当第一股寒潮来临时,就让我们意识到我们的取暖设备有严重的问题。尽管我们有恒温控制设备,但是室内温度变化还是很大,我们感觉室温舒适的时间,一次从来没超过几分钟。当火炉燃起的时候,地板上会飘来一阵冷气——而且,我们的燃料费高到离谱。

“一个朋友来拜访我们,注意到了我们的不适。他以前盖了一座新房,安装了雷诺士取暖设备。

# 朋友建议重新检查调整

“雷,他说道‘我给科林斯供暖空调公司打个电话吧。就是他们给我安装的雷诺士。给你安装取暖炉的人,看来没办法给你调整好。科林斯可能可以。

“第二天。科林斯就派了服务员过来。我们的取暖设施确实有些小问题,他做了一个改动,就彻底改变了我们的室内舒适度。他称之为‘CAC 原理’——设置鼓风控制,制造‘连续的空气循环’。
