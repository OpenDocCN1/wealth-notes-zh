# 为什么 Zippo 人

# 在打火机小轮子上投入 300000 美元

1946 年春天，Zippo 人发现了一个令人忧伤的事情。他们的打火机上有些打火轮，没有之前预想的质量那么好。

当然，其中很多打火机的打火轮质量还是很好的。但是也有一些质量差的混了进去。这些质量差的打火机，无法满足 Zippo 打火机每一部分都能给顾客提供年复一年的服务要求。

所以，尽管当时的销量蒸蒸日上，但是他还是叫停了那批 Zippo 打火机的销售。他没有解雇任何人。只是，不再销售该批次的打火机。Zippo 人开始寻找世界上最好的打火轮。

他用能找到的各种钢材进行实验。做了成千上万种打火轮。但是，这个完美主义者依旧不满意。

他向世界上一些最伟大的冶金学家请教。然后和自己的工匠经过不懈的努力，加上一点点运气，他开发了出了一个引人注目的打火轮，可以让你的 Zippo 打火机使用一生。

这就是 Zippo 能为你提供令人难以置信的保证的一个重要原因。不管你的 Zippo 打火机用了多久，用到什么样的程度，一旦它不能用了，Zippo 都会为你免费维修！
