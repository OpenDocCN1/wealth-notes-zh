# 新型牙膏
——对抗口臭和蛀齿细菌
的超级武器

自从科学家们找到了引发蛀齿和口臭的细菌后，他们就一直致力于研究一款能杀死这些细菌的牙膏。牙膏本身并不能有效地杀死细菌。它只能把它们刷走。但是，那些没有被刷走的细菌，很快就会大量繁殖。

二战期间，科学家们发现了一种最有效的杀菌物质——六氯酚。

医学院的外科医生发现，手术前，用六氨酚洗手，杀死的细菌数是传统洗手方法的 7 倍。也许更重要的是，他们发现六氯酚能提供一种持久的安全屏障，能有效隔离细菌。

利华兄弟公司把他们新研发的一款红白相间的六氨酚牙膏——条纹牙膏，和市场上竞争力最大的牙膏品牌和漱口水进行测试时，他们发现了同样的杀菌优势。

在这个测试中，有两组人。A 组人，用条纹牙膏刷牙。B 组人用其他知名品牌药膏刷牙。测试证明，A 组使用的条纹牙膏，在杀死引发口臭和蛀齿的细菌方面，效果远胜 B 组使用的牙膏。然后，又进行了更为严格的测试。请 B 组人刷完牙后，再漱口。即使这样，测试结果依旧是：

条纹牙膏杀死引发口臭和蛀齿细菌的能力，是知名牙膏品牌加漱口水杀菌能力的 3 倍！
