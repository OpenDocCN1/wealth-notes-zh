# 我们理性地看下你秋天的大额消费

来自：费伊·亨利，企业金融协会报专栏作家，在全国100多家报纸上发表过文章

因为女人管理着国家 65%的财富，所以，很明显女人不只是只会做蛋糕或找车钥匙。她们在买股票，冰箱——以及衣服时，也非常精明。

比如，上周一个朋友买秋天的外套，就引起了我的兴趣。

像我们购买任何重要的东西一样，她对即将购买这个外套反复盘问了许多苛刻的问题。“它能和我的其他所有衣服搭配，又能保暖吗？它能在正式场合穿，又能在出去买东西时穿吗？被雨水打湿了怎么办？穿着它进出车子方便吗？开车方便吗？最重要的是，它值这个价吗？”她最后终于选了一件漂亮的羊毛外套。我看到上面标着 100%羊毛时并不感到惊讶。因为我知道只有纯羊毛的东西才能让她满意。

我最近读了一篇关于羊毛纤维的文章，非常有趣。首先，大自然给了它超强的弹性——它被拉伸到高达 30%后，仍然能恢复原来的形状。这就是为什么羊毛外套总是看起来那么好看——穿起来那么舒适——不容易起皱。

文章还说，每个羊毛纤维都有蜡状保护层，能防雨雪。奇怪的是，这个保护层又有著细小的毛孔，能吸收水汽。这就是为什么纯羊毛外套能保护你不受潮湿，阴冷的天气的影响——却又不会让你感到湿冷，不透气。

大自然还让羊毛纤维卷曲或“烫卷”。这些卷曲纤维，能形成数以百万计的微小气泡，形成绝缘效应，给你提供保暖效果——抵御外部温度的变化，就像窗外暴雪飘舞，窗内温暖如春一样。
