# 我们的青少年存在健康风险吗？

太多的高中生，都可能面临着没有活力，发育迟缓，牙齿不好，骨骼不结实，神经系统紧张——可导致成年生活质量低于平均水平的永久伤害。

为什么会存在这种风险呢？即使最富裕家庭的孩子也可能无法幸免？答案是：

一旦离开家人的监督，许多青少年就开始了不良饮食。专家说，其中最严重的是，他们喝的牛奶不足。

为什么这很严重？因为其他食物含钙量太少，喝牛奶是获取足够的天然钙的唯一可行方法；因为牛奶是核黄素的主要来源，还含有丰富硫胺素，同时也是最优质的蛋白质来源。

在身体快速生长的青少年时期，孩子需要更多的食物营养——保证正常的生长发育，强健的骨骼，健康的牙齿，白皙的皮肤，健康的神经系统和基本的活力。

甚至一夸脱全脂牛奶都无法满足青少年每天所需的钙和核黄素。然而，青少年中，只有 42%的男孩和 21%的女孩每天会喝一夸脱牛奶。大多数人都认为“只有孩子”才需要喝牛奶。

幸运的是，现在出现了一种青少年真正喜欢喝的牛奶，它解决了他们的“特殊”问题。

这就是康乃馨“魔法水晶”速溶脱脂奶粉。

康乃馨“魔法水晶”能立刻溶于冰水。每夸脱水只要添加 1/3 杯“魔法水晶”，青少年就能享受到香浓的脱脂牛奶——比新鲜牛奶多 25%的钙，蛋白质和维生素 B。而且它是脱脂，低热量。
