# 一个鸡蛋有多大？

# 新的先进食品技术
使制作更美味，口味更一致的蛋糕成了可能

母鸡咯咯咯，耀武扬威地产下鸡蛋，不过，很有可能一个鸡蛋重 2½盎司，而另一个鸡蛋重 4 盎司。

鸡蛋不仅大小，重量不一样，而且质量也不同。所以，随便拿两个鸡蛋，几乎不可能拿到一样的。

虽然，母鸡并不关心鸡蛋是否有不同。但是，鸡蛋不同，就会将蛋糕产生影响——不一样的鸡蛋，可能会做出品相一般的蛋糕，也可能做出品相好，味道佳，结构匀称，每个女人都想要的蛋糕。

这个问题带来了食品科技的一个极大进步——加工鸡蛋的开发和使用。

这种鸡蛋，也是新鲜鸡蛋，只是没有水分。它的营养成分和刚从鸡窝里拿出来的一样。加上水分以后，和普通鸡蛋一样。

这种鸡蛋有很大的优点。它们的品质完全一样。能精确地满足食谱上的重量要求。当然，更方便。

这就是为什么加工鸡蛋，在我们日常生活中的很多食物中，都得到了普遍应用——冰激凌，婴儿食品，面条，蛋白糖饼等等。

因为我们在皮尔斯伯里，精心挑选来自全国的鸡蛋，每 120 个里，我们精心挑选出一个。（很显然，把鸡蛋放到面包原材料中的成本，要比不放，高得多），我们希望这可以帮助你理解我们为什么要这么做。
