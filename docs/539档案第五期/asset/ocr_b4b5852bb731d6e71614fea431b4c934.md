# 如何同床共枕——睡得舒服

来自：席梦思公司

两人同睡一张床，都知道床垫下塌有多不舒服。当丈夫的体重远远超过他的妻子时，情况更糟糕。他的一举一动，都会影响妻子的休息。

这些床垫问题在于，它里面的所有弹簧顶部和底部都是联系在一起的。对任何一个弹簧施加压力，附近的弹簧也会被带着压下去。连在一起的弹簧，受到压力也会一起塌下去。

这就是为什么席梦思睡美人系列床垫完全不同于其他床垫。这是唯一一款拥有独立弹簧的床垫。没有任何其他床垫使用过这种独特的结构。

它里面的弹簧不是联系在一起的，而是独立支撑。每根弹簧只支撑它上面的重量。这些独立的弹簧，能给丈夫和妻子独自的承担力，从而都会感到很舒服。睡着后，当一方转身或者晃动时，另一方身下的床垫不会随着晃动。

如果席梦思睡美人系列床垫非常适合两个人睡，那么可以想象，一个人睡时多么舒服。

独立弹簧结构，意味着它从头到脚都能给予相应的支撑。比如，这些弹簧在重量较大的臀部下方能给予温柔地“支撑”，而对重量较小的背部，则会轻柔的拖住。这就是为什么席梦思睡美人系列永远也不会形成凹陷——引起睡眠者身体疼痛的原因。
