# 今天你买了多少健康？

购买什么食物通常由人们喜好来决定。如果把食物营养作为购买的决定因素，那么肯定会购买让我们更健康——减少疲惫，精力更充沛，抵抗某些疾病的能力更强食物。

为了身体健康，选择好的食物种类要多样化——包括，肉、牛奶、蔬菜、水果、面包和谷类食品。然而，有三件事你必须注意：

1. 每餐都要有富含蛋白质的食物。孩子的成长和成年人的日常都需要蛋白质。肉、鱼、家禽、鸡蛋、牛奶、奶酪和冰激凌是蛋白质最好的来源。

关于蛋白质的一点建议：价格低的肉和价格高的肉营养一样丰富。黄豆、豌豆、扁豆和某些谷类食品也含有丰富的蛋白质。

每个人都需要牛奶中的蛋白质和钙。儿童和青少年每天要喝3—4杯牛奶。成人需要2杯，或者等量营养的其他食物。脱脂奶粉，用在汤、蛋羹和牛奶饮料中会非常棒。

2. 每天都要吃绿色或黄色的蔬菜。它们能为我们提供一些最基本的维生素和矿物质。

3. 每天都要食用一些富含维生素C的食物。这种维生素不能在体内储存。柑橘类水果——新鲜、冷冻或罐装都可以——番茄汁，或新鲜或罐装的番茄都是维生素C的优质来源。

我们大多数人的饮食习惯，都需要调整——尤其是青少年。许多青少年的健康问题——牙齿不好，气色不好，疲劳和肥胖——可以通过摄入一些基本的食物，少吃甜食和髙脂肪食品进行改善。
