# 蘋果與甜甜圈

你或許會以為，十疊安打一定都是些奇奇怪怪的小型股，像是什麼沒頭沒腦的生物反饋療法，或者是太虛幻境虛無飄渺的研究開發公司等等，都是那種理性投資人避之唯恐不及的小鱷股。事實上，有很多十疊安打各位肯定都聽過：唐金甜甜圈連鎖店、沃爾瑪百貨、玩具反斗城、停車採購超市、速霸陸汽車（Subaru），這只是隨口指出幾家而已。有些公司的產品深受各位的喜愛與支持，不過你是否曾經想過，如果你在購買速霸陸汽車的同時也投資它的股票，那麼你現在也許成了百萬富翁呢？

沒錯，的確如此！當然，這筆意外之財是根據幾個假設計算出來的：第一，你是在1977年每股股價低於2美元時買進；第二，在1986年的高價時賣出，從當時一股分割為八股倒推回來，股價應該是每股312美元，*這可是156疊安打，等於39支全疊打。因此，

> *註：本書將一再提到複雜的股票分割，許多上市公司會把原始的上市股數分割為更多股，例如一股分割為兩股、三股或者更多。如果你投資1,000美元買進X公司100股，也就是以每股10美元的價格買進。當X公司股票一股分割為兩股時，你持有的股數就會增加為200股，但是每股價格變為5美元。比方說，兩年後股價又漲到每股10美元，那麼你的投資實際上已經成長一倍。但如果不曉得這兩年間股票是否曾經分割，而只看股價的話，那麼以10美元買進又以10美元賣出，就可能誤以為股價並沒有上漲。
以速霸陸來說，股價並不是真的漲到每股312美元，因為在到達這高價前，公司就已將一股分割為八股了，所以當時的市場報價實際上是每股39美元（312美元÷8）。若照此往前推算，速霸陸股價都應該除以8，因此1977年該股2美元的低價經「分割調整」後，實為每股25美分（2美元÷8），但事實上速霸陸的股票從來沒有以每股25美分的價格成交過。
上市公司通常不願意讓每股股價的絕對金額過高，因此公司採行股票分割的理由之一，就是為了壓低股價。
