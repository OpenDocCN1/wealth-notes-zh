# 存貨

公司年報中有一個部分叫「管理階層對盈餘的討論」（management's discussion of earnings），裡頭會詳細談到存貨的狀況。我一定會檢視存貨總額是否增加，不管是製造商或零售商，存貨增加通常都是一項利空消息，如果存貨增加的速度比銷售還快，那就危險了。

有兩種基本會計方法可計算存貨價值：LIFO和FIFO。如何？看起來像兩隻獅子狗吧！LIFO是指「後進先出」（last in, first out），而FIFO是指「先進先出」（first in, first out）。如果韓地哈曼公司在三十年前買進黃金，每盎司進價為40美元，昨天它們又買進黃金，進價為400美元；假設它們在今天賣出黃金，售價為450美元，試問利潤為何？根據後進先出法，利潤為50美元（450美元減去400美元），如果是根據先進先出法，利潤則是410美元（450美元減去40美元）。
