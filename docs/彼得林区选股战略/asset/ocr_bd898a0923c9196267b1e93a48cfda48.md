# 4. 分拆公司

將公司的事業單位或部門分拆為一家獨立的公司，像芝加哥生牛皮公司分拆出安全克林、州際百貨公司分拆出玩具反斗城等，通常也是有利可圖的投資對象。幾年前合併的達特—克蕾芙（Dart & Kraft）公司，最後又各自獨立，克蕾芙公司回復成為純粹的食品業者，後來在1988年被菲利浦。摩里斯收購；擁有特百惠（Tupperware）公司的達特公司，獨立後稱為普里馬克國際公司（Premark International），本身即是一支很好的投資標的。

大型的母公司都不希望事業單位分拆出去，然後看著分拆公司步入困境，因為這將影響到公共形象，損害母公司的信譽。因此，分拆公司的財務通常十分健全，而且已經做好準備，在自立門戶後能夠大展身手。而且，在這些公司獲准獨立之後，擁有充分自由能大力施為的新管理階層，將會開始降低成本，並採用創新的方法來提升短期及長期的獲利。
