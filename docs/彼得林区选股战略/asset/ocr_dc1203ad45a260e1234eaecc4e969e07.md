# 底線——稅後純益及稅前淨利

不管你上哪兒，經常都會聽到「底線」（bottom line）這個字眼。「底線在哪呢？」不管是運動節目、商業交易甚至在法庭上，經常都會聽到這樣的說法，所以，真正的底線在哪呢？就在公司損益表底下的最後一個數字：稅後純益（profit after taxes）。

企業的獲利能力經常會遭到誤解。我曾經看過一項研究，訪問一些大學生和年輕人，請他們猜測企業的平均獲利率大概是多少，結果大多數的回答都是在20%到40%之間，但事實上近數十年來只有大概5%而已。

稅前淨利（profit before taxes，或是一般熟知的稅前淨利率）是我用來分析一家公司的工具。稅前淨利是公司一年的營業收入，在扣除包括折舊及利息費用等所有的成本費用後所剩下來的金額。在1987年，福特汽車的營業收入是716億美元，稅前淨利為73億8,000萬美元，稅前淨利率為10.3%。而零售業的獲利率就比不上製造業了，生意很好的連鎖超級市場或藥局雜貨店，例如亞伯森
