# 17 買進和賣出的最佳時機

前面說了這麼多，不是要讓各位認為我是一位市場時機選擇者，並且告訴各位何時是買進股票的最佳時機；事實上，只要你能說服自己，你已經找到了一項不錯的商品、而且價格相當好，這絕對就是最佳的買進時機，就像你在百貨公司買東西時的情況一樣。不過，的確有兩個特定的期間，各位很容易就可以找到廉價的好股票。

第一個期間是年底的節稅賣壓，這可說是一年一度的慶典，也難怪股市的大跌行情多半都會出現在10月到12月之間。由於這段期間的假日特別多，股票營業員就像我們一樣，也會需要許多錢來滿足開銷所需，因此他們都會打電話問你你要不要賣股票，故意造成虧損來抵稅。不知道為了什麼，投資人似乎都喜歡利用投資虧損來節稅，好像這是一個大好機會或是美好的禮物一樣，可是我實在無法理解，為什麼投資失敗還可以讓人這麼高興。
