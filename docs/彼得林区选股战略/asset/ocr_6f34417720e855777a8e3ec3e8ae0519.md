# 何時賣出景氣循環股

最好的賣出時機當然是在景氣擴張快要結束時，但是誰曉得景氣何時將會走軟？甚至有誰知道自己所談的是哪一類的循環波動呢？有時候某些號稱對景氣相當敏感的專家會慌忙賣出景氣循環股，但在一年後公司才出現一項下滑的訊號，可是這麼一來就會讓股價無緣無故地下挫。

要成功地操作景氣循環股，必須先了解它特殊的遊戲規則，這就是景氣循環股難搞的原因。國防產業股的表現與景氣循環股頗為類似，通用動力公司曾經在盈餘大好之際，股價卻下跌了50%，原因是那些「有遠見」的景氣觀察家提前賣出股票，避免到時候和大家一起搶著賣出。

除了景氣擴張結束的時機外，公司如果出現某些利空狀況，當然也是賣出的最佳時機。例如成本開始大幅上揚，或是公司現有產能已經全滿，開始花錢擴充產能；而如果你是在上個景氣低迷期和最近的繁榮期之間買了某支景氣循環股，那麼你就應該知道，最近的景氣繁榮期已經結束了。

如果公司的存貨大幅增加，而且沒有辦法降低，這也是一個明顯的賣出訊號。表示公司必須降價求售，因此盈餘必然會受到拖累。我總是會注意公司的存貨是否正在增加，如果連停車場都堆滿了存貨，那麼就應該賣出這支景氣循環股。事實上，你在此時賣出已經有點慢了呢。
