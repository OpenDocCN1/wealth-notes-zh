# 18 十二則關於股價的 最愚蠢（和最危險）說法

關於股價為什麼會波動，市場上有許多流行的解釋，有些是出自於專業投資人之口，有些則是在散戶投資人之間流傳，我對這些流行的說法總是感到驚訝不已。如今我們已經大量破除了醫學和天氣預報方面的無知和迷信，我們嘲笑老祖宗們在收成欠佳時竟然會歸咎於穀神，也懷疑「像畢達哥拉斯（Pythagoras）這麼聰明的人，怎麼會認為在零亂的床單裡藏有魔鬼呢？」但是，我們現在卻依然相信，哪支球隊在美式足球超級盃中獲勝會跟股價表現有關。

我在念研究所時前往富達打工，當時我首度了解到，即使是最聰明的教授，他們談到股票時的謬誤，就和畢達哥拉斯如何看待床單差不多。此後我還不斷聽到各式各樣的說法，每一則都足以讓人誤入歧途，可是卻又廣為流傳。這些迷思和錯誤觀念多到不勝枚舉，以下謹記錄十二則最愚蠢的說法，希望大家能徹底破除這些迷思，有些說法看起來還真熟悉呢。
