# 小心中間供應商

有些公司把它25%到50%的產品或服務都賣給同一客戶，這種狀況要特別留意。SCI系統公司（SCI Systems，不是開葬儀社的國際服務公司〔SCI〕，別搞錯了）經營得不錯，而且它是IBM公司的主要零件供應商，但是天曉得IBM公司什麼時候會改變策略，決定自己生產零件？或者IBM公司不再需要那些零件，因此會取消SCI系統公司的訂單。如果供應商的存亡完全繫於一家客戶的身上，想投資這家供應商就得三思而行。生產磁碟機的公司，如坦頓公司（Tandon）等，總是在災難邊緣打轉，正是因為它們只依靠幾個大客戶存活。

就算未曾出現取消訂單的情況，但由於大客戶擁有極大的能力，可以要求供應商降價，進而壓縮供應商的獲利水準。因此，這種仰人鼻息的供應商很少會是一個好的投資標的。
