# 1. 聽起來很無聊，或者荒唐可笑者更佳

完美的股票必定來自於完美的公司，而完美的公司必定是經營非常簡單的生意，簡單的生意則一定會有一個非常無聊的名字，越無聊越棒，比方說「自動資料處理公司」就是個好例子。

不過，「鮑伯·伊文斯農場」（Bob Evans Farms）就比自動資料處理還要更乏味！有哪支股票聽起來會像「鮑伯·伊文斯」那麼愚蠢呢？光想到都讓人直打呵欠，而這卻是它「錢」程遠大的原因之一。不過鮑伯·伊文斯農場還不是最無聊的，甚至連「松尼」、「瓶蓋、瓶塞與封口」（Crown, Cork, and Seal）也都還不是，我覺得最無聊的名字是：活力男孩—曼尼、摩伊與傑克（Pep Boys-Manny, Moe, and Jack）。

「活力男孩—曼尼、摩伊與傑克」真是我所聽過最有前途的一個名字！比單調乏味還要高一級，簡直是荒唐可笑！誰會把錢放在一家聽起來像是有三位丑角的公司呢？哪個正常的華爾街分析師或投資組合經理人，會推薦一支叫做活力男孩—曼尼、摩伊與傑克的股票呢？除非他們已經知道這家公司有多賺錢，不過在這個時候，活力男孩的股價已經漲了10倍囉！

在雞尾酒會中吹噓自己買了支活力男孩—曼尼、摩伊與傑克的股票，想必無法吸引聽眾，不過要是你說投資了基因分裂國際公司（GeneSplice International），儘管只是唸嚷幾句，保證大家都會側耳傾聽。但是基因分裂國際公司的股票只會一路下滑，而活力男孩—曼尼、摩伊與傑克的股票卻是步步高升。
