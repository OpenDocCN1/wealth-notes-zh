
# 現金部位
由於福特汽車擁有每股16美元的現金淨值，因此我知道福特汽車的股價不可能跌到16美元以下，這就是這支股票的下檔底限。

# 緩慢成長股
- 你買進這種類型股票的目的就是為了取得股利（不然你幹嘛買它），因此你要注意過去是否持續發放股利，並且持續調高股利。
- 如果可能的話，試著找出股利占盈餘的比例。要是比例偏低，代表公司在面對艱困時期，還會有轉圜空間，此時儘管盈餘下降，但公司還是可以維持股利發放；如果比例較高的話，也許會有發不出股利的風險。

# 穩定成長股
- 這類股票是不太可能被三振出局的大型公司。因此其關鍵就在於股價，而本益比可以告訴你目前的股價是否偏高。
- 檢視公司可能進行的「多角化」經營，看看是否會拖累未來的盈餘。
- 檢視公司的長期成長率，看看最近幾年是否維持相同的成長動能。
- 如果你準備長期持股，要注意該公司在過去幾次景氣衰退和股市大跌時的表現（麥當勞在1977年股市大跌時表現甚佳，在1984年的空頭走勢中也能維持橫向整理，不過到了1987年的股市大崩盤時，它就跟著其他股票一起大跌；但是整體來看，麥當勞還是相當優秀的防禦型股票。反觀必治妥的股票，在1973年至1974年的空頭市場中就慘遭痛苦，主要是因為當時的股價太高了；不過到了1982年、1984年及1987年時，其表現又相當好。家樂氏除了沒躲過1973年至1974年的空頭行情外，在最近的幾次大跌中，其表現都很好）。

# 景氣循環股
- 密切注意存貨的狀況，以及市場上的供需關係。留意新加入市場的競爭對手，這通常是一個警訊。
- 在景氣復甦時，本益比通常會降低；而一旦盈餘創新高，投資人就要小心景氣擴張或許即將結束。
- 如果你對自己所投資的景氣循環股相當了解的話，便擁有研判景氣循環變化的優勢。

例如，大家都知道汽車產業存在景氣循環的波動，大抵上是三、四年的好光景，之後便緊接著三、四年的不景氣，這種循環變化向來如此。雖然人們可能會延遲一、兩年汰換汽車，但遲早還是要汰換。

如果汽車產業在景氣衰退期間跌得越深，那麼在復甦時就會表現得越好。有時我反而會樂於見到額外一年的銷售疲弱，因為我知道這將會帶來更長且更穩定的景氣回升。

最近汽車業已經持續五年業績表現優異，因此我曉得我們正處於景氣擴張的中期，或者即將接近尾聲。不過，預測景氣循環股何時會回升，可是比預測它何時會走下坡要簡單多了。

# 快速成長股
- 仔細調查讓特定公司賺錢的特定商品，是否占該公司業務的主要部分。例如蕭格絲便是，而雷克森塑料則不是。
- 檢視最近幾年的盈餘成長率（我最喜歡的盈餘成長率是在20%到25%之間。如果超過25%，我就會有點擔心成長率是否難以持續。至於熱門產業中常見的50%高成長率公司，你也知道它們的下場都是如何）。
- 這家公司是否已經在一個以上的城鎮，成功地複製其經營模式，並證明未來的擴張將會成功。
- 這家公司是否還有成長空間。我第一次拜訪揪省百貨時，它們才剛搶下南加州的市場，並且準備進攻北加州，而未來還有四十九個州可供其發展；西爾斯百貨則正好相反，它們已經到處都有分店了。
- 本益比是否和其成長率相當？
- 擴張的速度是否正在加快（去年新開三家汽車旅館，今年新開五家），或是在減慢（去年五家，今年三家）？又如自動感應公司的生意，主要是「一次式」的交易，不像刮鬍刀，消費者會重複購買，因此如果成長趨緩，可能就會演變成一場大災難。1970年代末期到1980年代初期，自動感應公司的成長非常耀眼，但如果要維持盈餘成長，它們出售的商品防竊系統就要逐年增加。可是光靠已經購入系統的商家添購商品防竊標籤所帶來的收入，又比不上出售整套系統給新店家的收入，因此到1983年市場飽和後，該公司的成長率立即趨緩，盈餘成長也減緩，甚至出現縮水，所以股價也在十二個月內從42美元跌到6美元。
- 很少有法人機構持有這家公司的股票，甚至只有少數分析師聽過這家公司，對一家正在崛起的快速成長公司而言，這更是一項利多。

# 轉機股
最重要的是，這家公司會不會被債權人逼上絕路？它還擁有多少現金？負債又有多少？（當蘋果電腦陷入困境時，手上還有2億美元現金，而且沒有負債，因此你知道它不會就此完蛋。）這家公司的債務結構如何？它可以在赤字中支撐多久，是否能在破產前解決問題？（國際哈維斯特公司現已改名為奈維斯達公司，原本是一支極富潛力的轉機股，結果卻讓投資人大失所望。因為這家公司發行數百萬新股來籌措資金，雖然這個辦法救了公司，但是稀釋盈餘的效果卻救不了它的股票。）

如果公司已經宣告破產，股東還可以分到些什麼？

這家公司計畫如何起死回生、東山再起呢？它是否已經處理掉虧損的事業單位？這對獲利將會大有幫助。例如，洛克希德公司的國防事業單位在1980年的每股盈餘是8.04美元，但是其商用飛行器部門卻因為L-1011型三星客機的緣故，導致每股虧損6.54美元。L-1011型客機是很不錯的飛機，可是這個市場原本就不大，而且還要面對麥克唐納·道格拉斯公司（McDonnell Douglas）DC10型客機的激烈競爭；此外在長程市場方面，又被747型客機痛苦。因此洛克希德的商用飛行器部門一直處於虧損狀態，直到1981年12月，公司宣布停產L-1011型客機，隨後提列鉅額的虧損（高達每股26美元），但這只是一次式的損失。1982年，洛克希德的國防事業部門每股盈餘是10.78美元，而且沒有其他虧損部門在扯後腿，因此整個公司的盈餘在兩年內從1.5美元跳升到10.78美元。各位可以在洛克希德宣布停產L-1011型客機時，以每股15美元的價格買進，四年後漲到60美元，這是一支結結實實的四疊安打。

德州儀器公司也是一支標準的轉機股。1983年10月，德州儀器宣布退出家用電腦市場（又是一個競爭過於激烈的熱門產業），而光是那一年，德州儀器在家用電腦市場虧損就超過5億美元。同樣的，這項決定讓德州儀器一次提列了大筆的虧損，但這也表示這家公司在未來將會集中發展它最穩健的半導體及國防電子產品業務。在宣布提列虧損的隔天，德州儀器的股價從101美元跳升到124美元，四個月後更漲到176美元。

時代公司（Time）也曾經賣掉旗下的事業部門，因而大幅降低成本，這也是近來我最喜愛的轉機股之一。事實上，時代公司也是一支資產股，光是有線電視部門每股就有60美元的潛在價值，所以如果時代的股價是100美元，其實你只要花40美元就可以買到這家公司的其他部分。

- 生意好轉了嗎？（伊士曼·柯達公司的情況就是如此，在軟片銷售復甦之後，該公司又開始賺錢了。）
- 成本是否縮減了？如果是，其成效如何？

克萊斯勒關閉部分工廠，導致成本急速降低。許多在過去自行製造的零件，如今開始外包給其他公司生產，因而節省了幾十億美元的成本，並且馬上從成本最高的汽車公司，變成成本最低的業者之一。

至於蘋果電腦的轉機則較難以預估，不過，如果你曾密切注意這家公司，可能就會發現它的銷售額向上竄升，成本也降低了，同時新產品還頗受歡迎，多項利多因素幾乎是同時出現。

# 資產股
- 資產價值為何？是否擁有隱藏資產？
- 有多少負債要靠這些資產來償還？（債權人享有優先權。）
- 這家公司是否有新的負債，並使得資產價值更低？
- 是否有人準備收購這家公司，並讓股東能從這些資產中獲利？

# 以下是第二篇「挑選贏家」的重點
- 要了解你手中持股公司的本質，以及持有這支股票的特定理由（「它真的快漲了！」可不算是個理由）。
- 清楚區分持股所屬的類型，如此才較能了解你可以從這些股票中獲得什麼。
- 大公司只會有較小的漲幅，小公司才會有較大的漲幅。
- 如果你希望特定的商品能為公司帶來鉅額的利潤，那麼先確定公司的規模大小。
- 尋找那些已經開始賺錢、而且已經證明其經營模式可以成功複製的小型公司。
- 要特別當心年成長率高達50%至100%的公司。
- 要避開熱門產業中的熱門股。
- 不要相信多角化經營，這通常會變成「多慘化」經營。
- 時間拖得太久或目標太遠的投資不會有好成績。
- 最好避開股票的第一波漲勢，先等等看公司的計畫能否奏效再說。
- 人們可以從自己的工作領域中獲得許多極具價值的基本面情報，而且可以領先專業投資人好幾個月，甚至好幾年。
- 不必理會任何報明牌的人，即使他非常聰明、非常有錢，或者他最近的明牌的確很準。
- 某些股票明牌可能會相當有價值，特別是某個產業的專家所提供的明牌。然而，實際的情況卻是，紙業專家經常推薦製藥股，健康醫療產業的專家又成天嚷叨著某家造紙公司即將被收購的小道消息。
- 投資那些看起來乏味、平凡、不受喜愛，而且還未吸引華爾街注意的簡單公司。
- 非成長型產業中的中度快速成長公司（20%到25%），將是最理想的投資目標。
- 尋找具備某項利基的公司。
- 如果要買進艱困公司的股票，必須尋找財務狀況較佳的公司，並且避開擁有大量銀行負債的公司。
- 沒有負債的公司不會破產。
- 管理能力可能很重要，但是很難評估。所以各位要把重點放在公司的未來前景，而不是放在總裁的資歷或他的花言巧語。
- 艱困公司開始復甦時，可以讓你大賺一票。
- 小心考慮本益比，如果股價大約上已經被過度高估了，不管其他條件有多麼好，你還是無法賺到錢。
- 在追蹤公司的題材時必須找出主要脈絡，並據此監視公司的實際進展。
- 尋找持續回購自家公司股票的公司。
- 研究公司歷年來的股利紀錄，以及過去幾次景氣衰退期間的盈餘表現。
- 尋找只有少數幾家法人機構或是沒有法人投資機構持有的公司股票。
- 如果其他條件都相同，管理階層本身也大量投資自己公司的股票，會比管理階層只靠領薪水得利的股票更佳。
- 內部人士買進自家公司股票是一項正面訊號，特別是同一時間有許多人買進會更好。
- 每週至少要花一個小時做投資研究，但是把你得到的股利加總，計算一下盈虧，可不算是研究。
- 要有耐心，心急水不沸，緊盯著股票也不會漲。
- 只根據公告的帳面價值來買進股票，不僅非常危險，而且不切實際，應該以其真實價值為準。
- 如果有疑慮時，不妨等等看再行動。
- 在挑選一支新股票時，至少要投入和你在挑選一台新冰箱時同樣的時間和精力。

# 16 設計一份投資組合
我曾經聽人們說，如果投資股票每年有25%到30%的報酬率，他們就很滿意了！這樣只是很滿意嗎？如果報酬率真的這麼高，他們很快就可以和日本人以及德州投資大亨貝斯兄弟（Bass brothers）一起割據半個美國了。就是1920年代那些操縱華爾街的大戶，也不敢保證能永遠得到30%的報酬率呢！

在某些時候你一年可以賺30%，而在其他年度或許你只能賺2%，甚至是虧損20%。實際的情況就是如此，你只得接受現實。

期望過高會有什麼問題嗎？如果你認為每年應該有30%的報酬率，或許你會因為失望而感到挫敗，於是失去耐心，並因此在錯誤的時機放棄繼續堅持下去；或者更糟的是，你會因此承擔不必要的風險，追求不切實際的報酬假象。只有不管市況是好是壞，都能堅守一套投資策略，才能讓長期的投資報酬極大化。

如果說每年25%到30%的報酬率不切實際的話，那麼應該多少才合理呢？當然，你投資股票的報酬率理當要比投資債券好，但如果長期下來你每年只能賺個4%、5%或6%的話，那就太糟糕了。如果你檢視自己的長期績效，並且發現你投資股票的報酬率和銀行存款利息差不多的話，就表示你的操作技巧有問題了。

附帶一提，當各位在計算自己投資股票的績效時，可別忘了你還花了錢訂閱投資通訊、財經雜誌，還有交易手續費、參加投資講座的費用，和打給營業員的電話費。

一般而言，投資股票的長期報酬率大約在9%到10%之間，這是整體市場的歷史平均值。假如你是投資買進標準普爾500指數中500種成分股的無佣金共同基金（no-load mutual fund），這種基金會自動複製標準普爾指數的績效，那麼長期下來你會有10%的報酬率。這種自己完全不必做功課、也不必花額外的費用所產生的報酬率，可以當作一個基準指標，用來衡量你的投資績效，同時也可以用來衡量麥哲倫等股票基金的操作績效。

如果我們這些受雇挑選股票的專業人士，績效表現無法超越根據指數照單全收的指數型基金的話，那我們就該回家吃自己了。不過，請給我們一個機會。首先，你要考慮你投資的是哪種類型的基金，如果你是投資金礦股基金，一旦黃金價格下跌，即使是全世界最棒的基金經理人負責操盤，照樣也是坐困愁城；此外，只以單一年度的績效來判定生死也不公平。不過，如果你已經投資了三、五年，結果發現其報酬率只是和投資標準普爾500指數一樣，那不如直接投資標準普爾500指數；或是另找高明，挑一支過去操作紀錄比較好的管理型股票基金，畢竟它花了那麼多時間挑股票，報酬率應該會比較高才是。

既然有這麼多方便的選擇，而你還是認為值得付出心力自行挑選股票，那麼長期來說你應該得到12%至15%的複合報酬率才是。而且這必須是扣除所有的成本和手續費，並且加上所有的股利和其他紅利所得出的數字。

這也是為什麼長期持有股票會比短線進出更划算的一個理由。對小額投資人來說，頻繁進出的交易成本相當高。現在買賣股票的交易費用的確是比以前便宜，這一方面是因為折扣券商的出現；另一方面則是由於「零股」買賣費用的修正——即不到100股的買賣交易費用修正（如果你在開盤前先把要賣的零股交給證券商交易櫃台，就可以和別人的零股彙總在一起，而不必支付額外的零股交易費用）。儘管如此，業餘投資人每次買進或賣出股票，大概就要付出1%至2%的手續費。

因此，如果散戶投資人每年調整一次投資組合，股票一進一出就要損失4%的手續費。換句話說，投資人一開始就有4%的缺口要彌補，因此，如果投資人希望每年的投資報酬率在扣掉成本後還能達到12%至15%的話，那麼他挑的股票就必須要有16%到19%的報酬率才行。而如果進出的情況越頻繁，要超越指數型基金或其他共同基金的績效就越困難（現在有一種新的「基金家族」投資方式，你剛開始參加時必須支付3%到8.5%的手續費，之後就可以根據你的需要，在股票、債券或貨幣市場基金間進行轉換，而且無須再支付手續費）。

儘管有這麼多的陷阱，但如果散戶投資人可以打敗大盤平均10%的報酬率，譬如每年可以達到15%的話，那麼十年下來就會是一筆不錯的報酬。如果一開始是投資1萬美元，每年15%的報酬率在十年後將會變成4萬455美元，而每年10%的報酬率則只會有2萬5,937美元。

# 持有多少支股票才算太多？
如何設計一個可以創造12%到15%報酬率的投資組合呢？你應該持有幾支股票呢？現在我可以告訴各位：如果可能的話，千萬別一次買1400支股票！不過這是我的問題，不是你的問題。此外，你也不必煩惱什麼5%、10%的規定，也不必管理90億美元的龐大基金。

長久以來，投資顧問界就分成兩個陣營，一直爭執不休。洛伯（Gerald Loeb）的陣營宣稱：「把所有的雞蛋都放進同一個籃子裡。」而托拜斯（Andrew Tobias）的陣營則反駁說：「不要把所有的雞蛋都放在同一個籃子裡，搞不好籃子裡破了一個洞呢。」

如果我手中有一個籃子是沃爾瑪百貨的話，我會很樂意把我所有的雞蛋都放在這個籃子裡。相對的，如果要我把所有家當都放在伊利諾大陸銀行（Continental Illinois Bank）的這個籃子裡冒險的話，那我就敬謝不敏了。如果我手中有五個不同的籃子，分別是松尼連鎖餐廳、有限服飾、活力男孩、塔可貝爾，以及SCI的話，我保證把我所有的雞蛋分別放在這些籃子裡肯定會是一個好想法。可是在這種分散投資的做法中，包括雅芳公司或瓊斯—曼維爾公司的話，那我寧可只挑一個堅固的籃子來放雞蛋，例如唐金甜甜圈這種股票。其實重點不在於「幾支」股票，而是要仔細研究每一支股票，看看它們到底夠不夠好。

就我來看，如果是①你具備優勢的股票；以及②你發現極富潛力，而且研究後證實的確大有「錢」途的股票，那最好是能夠全部持有。或許這只是一支股票，也許是一打股票，那都沒關係。或許你打定主意要專注在轉機股或資產股，因此你買了幾支這類的股票；又或者你剛好只是對特定的某支轉機股或資產股比較了解，那就挑這支股票也行。如果只是為了分散風險，而去投資自己不了解的股票，這樣根本毫無用處。愚蠢的分散投資做法，根本就是專吃小散戶的妖魔鬼怪。

不過有人說，只投資一支股票並不安全，明明你非常努力地做了研究，但是你挑選的股票還是可能會因為未知的環境變化而遭遇不測。我個人認為，對一個小規模的投資組合來說，持有三支到十支股票是最合適的。這樣做有幾點：

第一，如果你要尋找十疊安打的話，你持有的股票越多，碰上十疊安打的可能性就越高。在幾支同樣具有潛力的快速成長股中，到底哪支股票會勝出、漲得最多，結果通常會出人意料之外。

停車採購超市就是我始料未及的大贏家，我原先還以為最多只能賺個30%或40%而已。它是一家不起眼的公司，當時股價還正在下跌，於是我在1979年開始買進它的股票，其中部分原因是我喜歡它的股利殖利率不錯。後來它的情況越來越好，旗下的超級市場和折扣商店的生意都十分興隆。當時我是以每股4美元買進，等到它在1988年被收購時，股價已經漲到44美元了。萬豪集團這支股票也是出乎我意料之外的大贏家，我知道萬豪的經營很不錯，因為我在它的飯店住過許多次，但是我壓根兒想像不到它的股價表現會這麼強勁，早知道我就不該買其他股票，應該把錢全部押在萬豪才對。

附帶一提的是，最近報上充斥各種企業收購的傳聞，但是在我因為預期被收購而買進的股票中，根本沒有哪支股票最後真的被收購了。實際的情況通常是，我因為基本面強勁而持有的股票，結果反而被收購了，這當然是意料之外的狀況。

既然我們無法預測各種不同的意外驚喜會從何而來，因此多持有幾支股票，你從中受惠的機率就會提高。

第二，你持有的股票越多，運用資金的彈性就越高。對我的投資策略而言，這是非常重要的一點。

有些人把我的成功歸因於專注在成長股所賜，可是這只說對了一部分，因為我絕對不會把基金資產超過30%至40%的比重放在成長股上面，其餘部分我會用來押注本書所說的其他類型股。通常我會持有10%到20%的穩定成長股、10%到20%左右的景氣循環股，剩下的部分則押在轉機股上面。雖然我總共投資了1400支股票，但是有一半的基金資產是押在100支股票上面，大約三分之二是投資在200支股票上面。另外有1%的資金分散在500支次級的投資機會上，這些股票我會定期追蹤，很可能隨後會進場加碼。我一直在各個領域尋找有價值的投資機會，如果我發現在轉機題材有某些投資機會比快速成長型公司更好，那麼我就會持有較高比重的轉機股。如果那些列入追蹤名單的次級投資機會中，某一支個股出現利多，並且讓我有信心，我也會把它納入主要持股當中。
