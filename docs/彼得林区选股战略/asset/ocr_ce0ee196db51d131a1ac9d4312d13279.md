# 發不發放股利有所謂

如果你買股票是為了獲取股利，那就要注意公司在不景氣或狀況欠佳時，是否也能夠照樣發放股利；是否能找到類似北星艦隊公司（Fleet-Norstar，以前稱為國民工業銀行〔Industrial National Bank〕）一樣，自1791年以來即不曾停止發放股利的公司。
