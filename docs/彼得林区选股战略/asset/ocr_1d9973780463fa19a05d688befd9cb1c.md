# 2 華爾街的矛盾修辭

在英文中，舉凡military intelligence（軍事情報）、learned professor（博學多聞的專家）、deafening silence（靜默窮然）、jumbo shrimp（巨大的小蝦）等，都是「矛盾修辭」（oxymoron）的最佳例子，這裡我想再加一個：professional investing（專業投資）。其實，業餘散戶投資人大可抱持某種恰當的懷疑眼光來看待所謂的「專業」，這點非常重要，至少你也要了解你的對手。由於大公司的股票有70%是掌握在法人機構的手中，因此不管你是買進或賣出這些股票，都是在跟這些所謂的專業投資人交手，這對各位來說可真是個好機會。我們這些專業投資人往往會受到許多文化、法律和社會規範的約束（事實上其中有很多是我們把自己搞得綁手綁腳），儘管整體表現還算不錯，但這還是讓人驚訝！

當然，並非所有的專家都是矛盾的綜合體，還是有一些偉大、有創意及特立獨行的基金經理人，懂得隨心所欲地進行投資。約翰．坦伯頓（John Templeton）就是其中一位佼佼者，他是進軍全球市場的開路先鋒，是最早在世界各地賺錢的專家之一。他讓他的投資人避開了1972年到1974年的美國空頭市場，因為他很聰明地把錢轉進加拿大和日本股市。而且，他也是第一批在日本股市獲利的美國投資人之一，從1966年到1988年，道瓊指數才上漲一倍，但日經指數
