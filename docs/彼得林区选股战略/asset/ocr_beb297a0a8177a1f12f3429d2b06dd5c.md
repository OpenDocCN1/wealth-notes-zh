# 實地調查

自從卡洛琳在超級市場發現了薈格絲，而我從墨西哥肉捲上發現了塔可貝爾之後，我就一直相信逛街和吃東西也是一種基本分析的投資策略。當然，你得問對關鍵問題才行，前述的比德諾公司就是個慘痛的例子。不過當你對某家公司進行調查研究時，如果能從實際層面加以檢視，結果將會更為可信。

我的朋友迪羅特告訴我玩具反斗城這家公司，但是等我真正到附近的玩具反斗城走一趟，才會相信這家公司真的懂要怎麼賣玩具。如果你問店裡的顧客是否喜歡這個地方，他們都說還會再來光顧。

在我買進拉昆特的股票之前，曾經在它們的汽車旅館住了三晚；在我買拚省百貨的股票之前，曾經去過它們位於加州的一家分店，並且對店內的低廉價格印象深刻。拚省百貨的經營策略是取得從一般通路撤架的停產商品，並以瑕疵品或水漬品的低廉價格出售。

我可以直接從拚省百貨的股東關係室取得這些訊息，但是這和親眼看到顧客發現一瓶知名品牌的古龍水標價才79美分，並且露出又驚又喜的表情，可是完全不一樣的感受。財務分析師可以告訴我，拚省百貨買下康寶濃湯公司（Campbell's Soup）退出狗食事業後價值數百萬美元的狗食產品，並且轉手賣出賺得鉅額的利潤，但是親眼看到顧客大排長龍，手推車裡堆滿了狗食罐頭，你就會找到拚省百貨經營策略成功的最佳證據。
