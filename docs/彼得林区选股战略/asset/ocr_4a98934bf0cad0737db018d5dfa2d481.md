# 4 通過自我測試

「奇異公司是個好投資標的嗎？」這不會是我針對某支股票首先提出的問題。也許奇異公司確實是個好投資標的，但這不代表你一定就得買它。除非你先把自己的狀況搞清楚，否則馬上研究財務面的問題可是一點道理也沒有。在你投資股票前應該先問自己三個問題：①我有房子嗎？②我缺錢嗎？③我的個性是否能讓我在股票投資上獲致成功？股票投資到底是好是壞，和你針對這三個問題所做的回答有關，而且甚至比你在《華爾街日報》上所讀到的任何東西都更有關。

# 我有房子嗎？

華爾街人士大概都會說：「買房子，這可是一筆大交易！」不過在你投資股票以前，應該先考慮買房子。畢竟，買房子幾乎是每個人都能做的好投資，當然也會有例外的情況，例如房子蓋在污水坑上，或者位於地價下跌的高級地段。但是買房子，99%都會賺錢。

你經常聽到有哪個朋友或熟人，跟你抱怨他買的房子賠得很慘嗎？我是不常有的。數以百萬計的房地產散戶投資人在投資自己的房子時，通常都做得相當好。有些人會因為急於搬遷而降價求售，但是很少聽到有哪個人是一幢一幢地買，然後又一幢一幢地賠，可是
