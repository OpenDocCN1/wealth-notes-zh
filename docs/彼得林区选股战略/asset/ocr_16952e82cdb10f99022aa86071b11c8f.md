# 再談隱藏資產

帳面價值可能會高估，也可能會低估真正的價值，而後者就是各位要找的資產股類型。

擁有天然資源的公司，例如土地、林木、石油或貴金屬等，其帳面價值通常只有真正價值的幾分之一而已。例如在1987年時，貴金屬生產商韓地哈曼公司（Handy and Harman）的庫房裡有一大筆黃金、白銀和白金庫存，其帳面價值是每股7.83美元，而且是以買進當初的價格來計算，但這已經是三十年前的事 情了！如果以今天的價格來計算（白銀每盎司6.4美元、黃金415美元），這批貴金屬資產每股的平均價值就高達19美元。

當時韓地哈曼的股價是每股17美元，比它的貴金屬資產價值還要低，那麼這就是一支資產股了吧？我們的巴菲特認為這是一支資產股，於是連續數年緊抱大量韓地哈曼公司的股票，可是這支股票卻很少波動，而且公司盈餘起伏不定，多角化經營也不成功（諸位都已經知道多角化經營是在搞啥了吧）。

最近有消息指出，巴菲特對這家公司已經不再感到興趣，而到目前為止來看，這筆投資算是他唯一一筆較差的投資，儘管這支股票的隱藏資產還是深具潛力。但如果黃金和白銀的價格大幅上揚的話，其股價也會跟著上漲。

除了黃金和白銀之外，還有許多其他類型的隱藏資產，例如可口可樂或諾比舒咬的品牌就很有價值，但這些並不會出現在帳面上。另
