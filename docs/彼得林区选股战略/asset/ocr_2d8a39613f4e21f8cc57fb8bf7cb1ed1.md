# 何時賣出資產股

最近這段時間，最好的投資想法就是等待企業「狙擊手」的出現。如果哪家公司真的擁有隱藏資產，像史坦伯格（Saul Steinberg）、哈夫特（the Haft）或萊希曼（the Reichmann）等狙擊手就會馬上出現。只要這家公司不是債台高築，進而導致資產價值縮水，你就可以緊抱持股。
