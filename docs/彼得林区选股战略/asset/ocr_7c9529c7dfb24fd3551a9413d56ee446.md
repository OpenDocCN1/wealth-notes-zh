# 後記

# 絕對不要空手！

我在本書一開始，提到一個度假的故事，或許在結尾時也應該再補上一個度假的故事。1982年8月，卡洛琳、我和孩子們開車前往馬里蘭州，準備參加卡洛琳的妹妹瑪德琳（Madalin Cowhill）的婚禮。沿途我安排了八、九個休息點，而在休息點附近百哩之內都會有些上市公司。

那時候卡洛琳和我剛簽下購屋契約，8月17日是最後的悔約期限，如果在期限前悔約的話，已支付的10%訂金還可以全部拿回來。我提醒我自己，這可是一大筆錢啊，等於我在富達工作頭三年的薪水。

要買下這幢房子，我就必須對我未來的收入有信心才行，而我的收入大部分要看美國企業未來的表現如何而定。

當時股市的氣氛持續低迷，利率飆升到兩位數的超高水準，不少人擔心美國快要變得跟巴西一樣慘，還有些人擔心1930年代的慘劇即將重演。有些「英明」的官僚則在懷疑，我們是否應該開始學習怎樣去捕魚、狩獵、採野果，好在數百萬的失業大軍出現時，先到森林裡去找食物。這時的道瓊指數是七百多點，而十年前還在九百多
