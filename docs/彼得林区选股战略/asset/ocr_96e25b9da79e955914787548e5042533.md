# 13 一些著名的數字

以下是公司財報中一些值得注意的數字，介紹的先後順序與其重要無關。

# 營收比例

如果我是因為某項特定產品，而對一家公司感到興趣，例如蕾格絲、幫寶適或雷克森（Lexan，PC聚碳酸酯樹脂）塑膠製品等，首先我要搞清楚的問題，就是這項產品對該公司是否重要？這項產品占該公司的營收比例（Percent of Sales）有多少？蕾格絲絲襪可以讓漢斯公司的股價大幅上升，這是因為漢斯公司的規模相對較小；反觀幫寶適比蕾格絲更賺錢，但是對於大型的寶鹼公司來說，幫寶適的重要性相對就沒有那麼大。

比方說你對雷克森塑膠製品感興趣，並且發現這項產品是由奇異生產的。然後你的證券商告訴你（或者你從年報中發現），生產雷克森製品的塑膠事業部是隸屬於建材事業部，而整個建材事業部的營收只占奇異總營收的6.8%，因此，即使雷克森製品也像幫寶適一樣受歡迎，但是對奇異的股東來說，這項產品的重要性就不大。所以，你要不就去尋找生產類似產品的公司，要不就乾脆忘了這項產
