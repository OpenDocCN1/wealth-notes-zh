# 1987年的股市重挫

在1987年10月大崩盤時，你有機會低價買進我在這本書中提過的許多好股票。在當年夏秋之際的千點重挫行情中，所有股票都被拖下水，但事實上表17-2中所列的股票，其實都是體質強健、獲利極佳的好公司，根本沒有犯下任何差錯。這些股票在重挫後，大都很快就回升了，所以一旦碰上逢低承接的好機會，我自然是當仁不讓。我曾經錯過了德萊弗斯公司，但這次我馬上就抓住這個好機會（如果被騙一次，是對方可惡；如果被騙兩次，那就是自己太笨了）。當時德萊弗斯的股價跌到每股16美元，而該公司扣除負債後的每股現金淨值卻是15美元，所以這有什麼風險可言？除了現金之外，在這次市場危機中德萊弗斯也賺了一票，因為有許多投資人慌忙逃出股票市場，並轉進德萊弗斯公司所管理的貨幣市場基金避險。
