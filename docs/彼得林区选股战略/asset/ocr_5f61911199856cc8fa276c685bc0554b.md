# 打電話給公司

專業投資人經常打電話給上市公司，大部分的業餘投資人卻從來沒想過，他們其實也可以這麼做。如果你對某些問題特別感到疑惑的話，上市公司股東關係室就是排疑解惑的好地方，這時營業員還能再幫上一點忙：可以提供你上市公司的電話。即便你是從窮鄉僻壤打電話過去、就算你只持有100股，上市公司還是樂於和你交換意見。如果這家公司的規模不大，或許你還有機會和總裁親自對話呢。

萬一你覺得對方很冷淡的話，不妨說你目前持有兩萬股，正在考慮要不要加碼一倍，然後再不經意地提及，這些股票都是登記在證券商名下。這樣做的話，事情或許會比較順利一點。當然，我並不鼓勵各位這麼做，不過這種小謊無傷大雅，也不可能被拆穿，因為用證券商名義所持有的股票，不會對外公開個別投資人的詳細資料，外界只能看到總持有股數，因此上市公司也「只好」相信你真的持有兩萬股。

在你打電話之前，最好先準備好你要提出的問題，不過別一開始就問：「這支股票怎麼下跌了？」如果這是你的第一個問題，對方馬上就會知道你是個投資菜鳥，而隨便敷衍你。而且就大部分情況來說，上市公司也不知道股價為何下跌。

盈餘是個好話題，不過開門見山、單刀直入就問：「你們會賺多少錢？」這又似乎有點不太禮貌，好像陌生人打探你們家一年賺多少錢一樣。你應該要用比較委婉但直接的方式來問：「請問華爾街預期貴公司明年的盈餘是多少？」
