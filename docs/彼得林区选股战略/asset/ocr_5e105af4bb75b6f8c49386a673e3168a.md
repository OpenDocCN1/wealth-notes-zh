# 師法前事

不管我們是如何看待最近的金融情勢，我們總是根據最近一次發生過的事情，而不是未來將要發生的事，為自己做準備。這種「師法前事」（penultimate preparedness）的求生方式，正是因為我們根本摸不清未來將會發生什麼事情。
