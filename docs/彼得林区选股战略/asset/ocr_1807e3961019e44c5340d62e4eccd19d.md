# 謝詞

本書的修訂版承蒙許多人和團體給予慷慨而專業的協助，包括：在一般事務方面——出版代理商Doe Coover、富達資本公司行銷經理Paula Caputo，以及丹芳夏出版公司的Ellen Hoffman；在資料蒐集與核對方面——奈德·戴維斯研究公司、FactSet、道瓊公司、富達市場研究公司的Scott Machovina，以及富達技術集團，尤其是Patricia Mulderry、Denise Russell、Shawn Bastian和Krista Wilshusen；在編務協助方面——賽門舒斯特出版公司的Airie Dekidjiev、Doris Cooper。

我有幸能在1960年代即成為富達公司的一員，我們都暱稱它為「Fido」。富達是個有點保守且老式的地方，恰如其分地安座在波士頓一幢古老的九層樓建築物裡。每位員工儘管有所差異，但是相處融洽，對於股票雖常有爭論，但不至於傷了和氣，我們甚至還保留著慶生會和吃蛋糕的習慣呢。

我受到許多人的鼓勵和啟發，如果要全部列出的話，一定可以寫滿一整章。以下我只提到其中幾位，對於沒有特別提及的諸位，本人謹此致歉。
