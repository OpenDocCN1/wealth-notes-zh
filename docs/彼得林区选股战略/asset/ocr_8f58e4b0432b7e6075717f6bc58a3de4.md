# 12 取得事實資料

身為基金經理人雖然有許多缺點，不過卻有一項好處：上市公司會願意和我們說話，如果你喜歡的話，一個星期甚至可以談上許多次。當他們想要請你買進幾百萬股時，你就曉得自己有多麼受歡迎了。我經常在美國各地旅行，從東岸飛到西岸，拜訪一個又一個的投資機會。上市公司的董事長、總裁、副總裁，還有許多股票分析師，都會塞給我許多有關資本支出、擴張計畫、縮減成本方案，以及和公司、股票未來有關的各種資訊。而且，同行的投資組合經理人也會告訴我他們聽到的消息，此外，如果我不去拜訪公司，他們也會來找我。

不過從另一個角度來看，我並不覺得業餘投資人就無法找到那些有用的資訊，所有的相關訊息其實只是等著被發掘出來而已。過去上市公司的資訊雖然不是很公開，但現在已經不再是如此了。現在的公司會在上市的公開說明書、季報及年報上，詳列各項訊息，各種產業公會也會在它們的刊物分析整體產業的前景（上市公司也樂於寄發公司的各種通訊刊物給你，在這些洋洋灑灑的文章中，有時也能找到有用的資訊）。
