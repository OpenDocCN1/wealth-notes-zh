# 轉機股

最重要的是，這家公司會不會被債權人逼上絕路？它還擁有多少現金？負債又有多少？（當蘋果電腦陷入困境時，手上還有2億美元現金，而且沒有負債，因此你知道它不會就此完蛋。）這家公司的債務結構如何？它可以在赤字中支撐多久，是否能在破產前解決問題？（國際哈維斯特公司現已改名為奈維斯達公司，原本是一支極富潛力的轉機股，結果卻讓投資人大失所望。因為這家公司發行數百萬新股來籌措資金，雖然這個辦法救了公司，但是稀釋盈餘的效果卻救不了它的股票。）

如果公司已經宣告破產，股東還可以分到些什麼？

這家公司計畫如何起死回生、東山再起呢？它是否已經處理掉虧損的事業單位？這對獲利將會大有幫助。例如，洛克希德公司的國防事業單位在1980年的每股盈餘是8.04美元，但是其商用飛行器部門卻因為L-1011型三星客機的緣故，導致每股虧損6.54美元。L-1011型客機是很不錯的飛機，可是這個市場原本就不大，而且還要面對麥克唐納．道格拉斯公司（McDonnell Douglas）DC10型客機的激烈競爭；此外在長程市場方面，又被747型客機痛苦。因此洛克希德的商用飛行器部門一直處於虧損狀態，直到1981年12月，公司宣布停產L-1011型客機，隨後提列鉅額的虧損（高達每股26美元），但這只是一次式的損失。1982年，洛克希德的國防事業部門每股盈餘是10.78美元，而且沒有其他虧損部門在扯後腿，因此整個公司的盈餘在兩年內從1.5美元跳升到10.78美元。各位可以在洛克希德宣布停產L-1011型客機時，以每股15美元的價格買進，四年後漲到60美
