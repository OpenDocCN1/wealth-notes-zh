# 9 我會避開的股票

要是我可以避開一種股票的話，肯定是熱門產業中的最熱門股票。那類股票最受大眾喜愛，投資人搭車子或捷運時，都會聽到身旁的人談起這種股票，因此很容易就會屈從於社會的壓力，買進這種股票。

熱門股會快速上漲，而且通常會漲到沒有任何價值衡量標準可以評價的地步，最後，等到只剩一廂情願的狂熱和稀薄的空氣在支撐股價時，它的崩落速度也會一樣快。如果你員在賣出熱門股時不夠聰明的話（事實上，你會買進這類股票就代表你不夠聰明），很快地你就會看著你的獲利變成虧損，因為這種股票在下跌時通常不會慢慢盤跌，而且在你買進的價位也不會有什麽止跌的支撐力道。

我們來看看最近正熱的電視購物業中的熱門股——家庭購物網（Home Shopping Network）（見圖9-1），這支股票在十六個月裡從3美元一路飆到47美元，後來又跌回3.5美元（經過分割調整）。如果是在47美元高價賣掉，當然是可喜可賀；但萬一是在47美元、股價最熱時買進呢？要上哪兒去找盈餘、獲利和未來展望來支持呢？這樣的投資簡直和賭輪盤沒有兩樣。
