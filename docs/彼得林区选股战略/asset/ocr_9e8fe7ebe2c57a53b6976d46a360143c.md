# 何時才應該真正賣出

如果市場不能告訴你何時應該賣出，那該怎麼辦呢？有關賣出的問題並沒有單一的法則可以一體適用。「在利率上揚前賣出」或「在景氣衰退前賣出」，當然是值得遵循的法則，但前提是我們要知道利率何時會上揚、景氣何時會衰退？但是我們怎麼可能會知道呢，所以，這無異是一堆廢話。
