# 11 兩分鐘的推敲

現在你已經知道你面對的股票是哪一種類型，是緩慢成長股、穩定成長股、快速成長股、轉機股、資產股，或是景氣循環股；而本益比則讓你有了粗略的概念，可以稍微判斷這家公司當前的股價相對其當前的展望是高估或低估。再接下來則是要盡量調查、打聽，了解這家公司計畫如何提升業績、刺激成長，或是有任何其他的利多消息，這就是我所謂的做功課研究上市公司的題材。

除了資產股之外（這類股票你必須耐心地等待企業持有的不動產、石油蘊藏或電視台的價值獲得其他人的認同），一家公司的盈餘如果要保持成長，就必須具備某些驅動力才行。如果你越能確定這些驅動力為何，那麼你就越能根據自己的判斷去操作。

從證券商取得分析師針對一家公司所做的研究報告，或閱讀《價值線》中的短篇分析報導，將提供你專業觀點；但如果你在某家公司或某個產業擁有特定的優勢，那你也可以發展出自己的方法來研究、調查上市公司。
