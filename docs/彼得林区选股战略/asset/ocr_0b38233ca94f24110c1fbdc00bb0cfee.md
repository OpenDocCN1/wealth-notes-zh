+   - 耗費太多資金在收購上，使得資產負債表從原先擁有數百萬美元現金、零負債的狀況，惡化成為零現金、而有數百萬美元負債的情況。造成即使股價下跌，公司也沒有多餘的資金可以回購自家公司的股票。
- 即使股價相對較低，但是股利殖利率還是低到無法引起投資人的興趣。

# 何時賣出穩定成長股

對於這種類型的股票我通常採取換股操作的策略。由於在穩定成長股中不太可能會出現速成暴利的十疊安打，所以只要股價上揚超過盈餘成長趨勢線，或是本益比上揚遠超過正常水準，此時你就應該考慮把它賣掉，等到股價下跌時再以較低的價格回購，或是像我一樣，買進其他的穩定成長股。

其他的賣出訊號包括：

+   - 過去兩年來所推出的新產品，銷售狀況有好有壞；而其他正在研發中的新產品，距離問世還有 一年以上的時間。 
- 本益比高達15倍，而同一產業中類似等級公司的本益比卻只有11倍到12倍。 
- 公司的經理人和董事在去年都沒買進自家公司的股票。 
- 占公司盈餘25%、且易受景氣衰退影響的重要事業單位，正開始面臨景氣下滑的影響（如房屋開工率、石油鑽探率下滑等）。 
- 公司的成長率已經趨緩，雖然公司透過降低成本來維持獲利水準，但是未來降低成本的可能性已經相當有限了。
