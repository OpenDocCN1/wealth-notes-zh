# 品管檢驗四次

如果你以為華爾街的一般專家都是在找某些理由，藉以支持買進某些黑馬股的話，那麼你就真的不夠了解華爾街。其實基金經理人倒是比較努力尋找「不買」那些黑馬股的理由，萬一到時候股價真的上漲，這樣才有理由搪塞客戶。最常見的藉口是：「那支股票太小了，所以我沒有買。」此外還有：「這家公司沒有歷史紀錄可供參考」、「這個產業不會成長」、「它的管理階層還沒有經過市場考驗」、「它的員工都是工會成員」，以及「競爭會使它們被淘汰」。於是乎你會聽到，「停車採購超市不行啦，會被7-Eleven給宰掉」、「掠省百貨（Pic 'N' Save）不行啦，會被西爾斯（Sears）百貨給宰掉」，或者「機構租車（Agency Rent-A-Car）公司在赫茲（Hertz）和艾維士（Avis）的夾擊下，沒希望囉」。這些都可能是合理的問題，但還是要做仔細的追蹤調查，不過他們往往只是做了輕率的判斷，然後就一筆抹殺掉所有機會。

為了保住飯碗，很少有專業投資人敢買賣拉昆特汽車旅館的股票。事實上，如果是要在一家不知名的小公司賭賺大錢的機會，和明知會虧小錢仍挑選一家大公司之間做選擇的話，一般的共同基金經理人、退休基金經理人和公司投資組合經理人，一定都會選擇後者。會不會成功是一回事，但萬一失敗，千萬不要死得太難看。華爾街有一條不成文的法則：「如果你投資IBM，並且虧掉客戶的錢，絕對不會丟飯碗。」
