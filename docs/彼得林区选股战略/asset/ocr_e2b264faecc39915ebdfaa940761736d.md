# 16 設計一份投資組合

我曾經聽人們說，如果投資股票每年有25%到30%的報酬率，他們就很滿意了！這樣只是很滿意嗎？如果報酬率真的這麼高，他們很快就可以和日本人以及德州投資大亨貝斯兄弟（Bass brothers）一起割據半個美國了。就是1920年代那些操縱華爾街的大戶，也不
敢保證能永遠得到30%的報酬率呢！

在某些時候你一年可以賺30%，而在其他年度或許你只能賺2%，甚至是虧損20%。實際的情況就是如此，你只得接受現實。

期望過高會有什麼問題嗎？如果你認為每年應該有30%的報酬率，或許你會因為失望而感到挫敗，於是失去耐心，並因此在錯誤的時機放棄繼續堅持下去；或者更糟的是，你會因此承擔不必要的風險，追求不切實際的報酬假象。只有不管市況是好是壞，都能堅守一套投資策略，才能讓長期的投資報酬極大化。
