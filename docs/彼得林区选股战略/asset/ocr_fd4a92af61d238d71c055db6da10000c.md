# 閱讀公司報告

有那麼多上市公司的年報被丟到垃圾筒，這點實在不足為奇。那些印刷得漂漂亮亮的文字，大家都看得懂，可是卻毫無用處；至於後面那些難以理解的數字，反倒是最重要的部分。儘管如此，還是有辦法只要花幾分鐘時間，就可以從公司年報中取得一些資訊，而我看一份年報通常也只花幾分鐘的時間。

我們來看看1987年福特汽車的年報。封面是攝影名家伍傑諾斯基（Tom Wojnowski）的攝影作品，拍的是福特林肯車系Continental的車屁股；封面內頁則是對亨利·福特二世（Henry Ford II）的阿諛奉承，還配上一張福特二世站在他的創辦人爺爺的畫像前面的照片。這主要是對股東傳達一項友善的訊息，代表這家公司的企業文化傳承，同時還提到福特家族贊助彼得兔（Peter Rabbit）創作人碧翠絲·波特（Beatrix Potter）的展覽。
