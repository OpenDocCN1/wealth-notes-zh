# 敲邊鼓效應

下面的例子是要告訴各位，散戶投資人跟專業投資人一樣，都很容易受到別人的影響。我們這些專業投資人的耳邊有很多專家在吱吱喳喳，而在各位身邊也有很多朋友、親戚、營業員和各式各樣的媒體報導圍繞著。

也許你已經聽過了「恭喜啊，不過別太貪心喔！」的說法。營業員會打電話來說：「恭喜啊！ToggleSwitch這支股票已經上漲一倍了，我們別太貪心，還是賣了換成KinderMind的股票操作吧。」結果你賣出之後，ToggleSwitch還是繼續上漲，而換了KinderMind股票後沒多久，它竟然破產了，並且把你原先賺的錢也全部賠光。但是這對營業員來說可是一點也沒差，他在兩筆交易上都賺到了手續費，而每一聲「恭喜」都像是在加薪。
