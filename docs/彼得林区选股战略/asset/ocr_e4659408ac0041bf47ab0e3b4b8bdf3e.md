# 10 盈餘、盈餘、盈餘！

假設你曾經注意到發明商店防竊標籤及自動感應器的自動感應公司（Sensormatic），在1979年到1983年間業績持續擴張，且股價從每股2美元漲到42美元。你的營業員告訴你，這是一家成長快速的小公司；又或許你是檢視手上的投資組合，發現裡面只有兩支穩定成長股、三支景氣循環股，此時你該怎麼辦？你怎麼知道買了自動感應公司後，它的股價還會不會繼續上漲？或者，你怎麼曉得手上的持股會不會漲呢？再者，如果你要買進自動感應的股票，什麼價位才算合理？

其實你問的問題是，哪些因素讓一家公司具有價值？為什麼能讓它在明天比今天值錢？對於這個問題有許多種解釋，不過對我而言，我只看盈餘和資產，特別是盈餘。有時候股價要花上許多年的時間，才會反映企業的實際價值，時間久到讓投資人都不會懷疑是否真能出頭天。但是真正的價值終究會勝出，起碼有很多例子可以證明，基本面還是值得信賴的。

分析企業股票的盈餘和資產，其實就跟你分析住家附近的某個自助洗衣店、藥房雜貨店，或某間公寓建築值不值得購買是一樣的。各位應該謹記（雖然有時會忘記）：股票並不是彩券，它是一家公司
