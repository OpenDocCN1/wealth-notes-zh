# 同類股幾乎都會同時創新高價

同類股除了走勢相近，也幾乎會同時創新高價。請見圖表3-2，這張圖表所列舉的個股都是海運公司，11家公司中有7家在2003年5月～8月之間創新高價，而且每家公司突破史上最高價的時間，都出現在2007年。

海運類股和圖表3-1的四家綜合商社相比，股價的成長倍數落差更大，這是因為它們的獲利落差實在很大。像乾汽船（成長35倍）
