# 混亂期的時間很長

③ 行情顛覆及之後的狀況

| 標的 | 起算點 | 漲幅 | 低點 | 高點 | 停泊時間 | 停泊時相對漲幅 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 美國股市 | 1929年9月 | -86% | 3.0年 | 13年 | 低點與高點間繼續停泊，亦不確定 |
| 黃金價格 | 1980年1月 | -70% | 19.6年 | | |
| 石油價格 | 1980年10月 | -75% | 18.2年 | | |
| 日經平均指數 | 1989年12月 | -82% | 17.8年 | 22年以上* | |
| 那斯達克指數 | 2000年3月 | -78% | 2.6年 | 12年以上* | |

說明：*表示現在仍在持續停台中。

後，分別經過20年與18年的平穩期，才進入新的上升期。為什麼這麼久？我們以那斯達克指數為例來說明。

那斯達克指數的科技股占比很高，上一個上升期的結束時間，是網路熱潮結束的2000年3月，此後便進入混亂期。網路熱潮是在手機與電腦普及的背景下誕生的，這種新科技並非幾年就出現一次，而是數十年才會出現一次的大發明。因此那斯達克指數在網路泡沫化後，等於失去了行情的重要支撐。由於短時間內很難再出現一樣的革命性產品，因此那斯達克指數暴跌後，只能長時間停留在平穩期。

正因為平穩期都很漫長，所以只要有人告訴你了「再過多久，大盤就會漲到○○○點。」這種預測通常不準，唯一可以肯定的是，全球股市接下來仍會持續低迷。
