# 第一章：選股密技百百種，我的最快看 出賺股

穩定後陡升，就是飆股的起漲點

「穩定後陡升」是令投資人最安心的買點。一般而言，股價總是上下波動，如果買在這段高點，之後股價就會下跌；而史上最 高價，就是上升波段的最高點。

我們在上一節介紹過蘋果公司，圖表1-10是它2000年～2005年的 K線圖。如果你實在突破2000年歷史新高的價位，從圖表上看，大約 三個月後你就應該停損了。在這之前，蘋果的股價幾乎每個月都開出 陽線（上漲），所以隨時出現微幅下跌的狀況，一點也不稀奇。
