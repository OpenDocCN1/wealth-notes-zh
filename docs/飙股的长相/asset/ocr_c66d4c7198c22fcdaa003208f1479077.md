# 選「第一」，不如選「唯一」

其實光有業界第一的稱號，還算不上是好股票。投資人真正追求的是，擁有獨家技術或服務、能在競爭中獲得壓倒性勝利的公司。有句話說「選第一不如選唯一」，這是因為「第一」隨時都有被超越的危險，而「唯一」就沒有這種困擾了。當然，假如業界第一大公司是人微的「格力佛企業」，那就另當別論了。因為再多的小人圍攻，也難敵格力佛的寡頭壟斷（格力佛是小說《格力佛遊記》主人翁，他曾造访大人國與小人國等畫奇的國家）。
