# 第二章：三種巨大轉變，讓企業變得很賺錢

2-1，日航於2010年1月破產，之後的三季，日航旅客數（以旅客里程數來計算）衰退了21%，天馬航成長了6%。半年後，根據2010年6月期的財報，日航的營業額衰退了9%，天馬航空卻成長了18%。股價方面，天馬股價在7月創下新高，之後半年的股價更是翻漲三倍，相較之下，全日空幾乎沒有上漲。
