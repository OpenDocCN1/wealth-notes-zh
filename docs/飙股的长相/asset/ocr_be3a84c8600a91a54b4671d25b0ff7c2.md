|---|---|---|---|
| ①股價持平 | 小 | 持平 |  |
| ②助跑行情 | 中 | 微幅上漲 |  |
| ③上升行情 | 大 | 暴漲 |  |

![](bbox=[0.29, 0.34, 0.75, 0.89])

情分成股價持平、助跑行情、上升行情。「助跑行情」介於「股價持平」與「上升行情」之間。通常，股價持平時會形成平穩期，助跑行情的形狀則像是要上漲，又像是要形成平穩期，「範圍」會比平穩期大一些。

在第一章第二節的圖表1.24裡，我們看到股價如果在第二個平穩期的漲幅較大，代表即將進入上升行情；但在助跑行情中，平穩期的上漲不會只出現兩次，而是重複好幾次，這些多來的微幅上漲，就是「助跑行情」。
