# 獨協的長相

舉例來說，可爾必思是「格列佛企業」（市占率第一），也是「唯一」（獨占市場）。通常食品專家提到這種飲料，多半會稱為「乳酸菌飲料」，可是一般民眾聽到「乳酸菌飲料」反而覺得陌生，對日本許多家庭來說，「可爾必思」已經成為所有「乳酸菌飲料」的代稱了。這表示「可爾必思」這個商品名稱的名氣，已經大壓過它真正的名稱，這種案例在國內外都很常見。

不過，我們要找的不是「市占率第一＋唯一」，在選擇獨占型（唯一）企業時有一個重點，就是市占率必須很低，因為這種股票未來才會有很大的攤漲空間。以最典型的獨占事業電力公司來說，關西電力公司幾乎完全獨占了關西地區的用電市場，但正因因為關西電力公司提供家庭和工業用電的比例幾乎已達 100%，所以市占率已經沒有擴張的空間了。如果是在電力尚未普及且每家戶人家的發展中國家（如印度），電力公司或許還是值得投資的對象。

獨占型企業能冒頭，代表背後潛藏著社會的巨大轉變。例如 WORKMAN 這家專賣工作服的公司，專門販售工作服給在工廠、建築工地工作的人，市占率雖然只有 10%，但第二大廠達 1% 都沒有；WORKMAN 也是市面上唯一家工作服專賣店，而且產品豐富、價格便宜，店內裝潢又簡朗明亮，所以它是獨占型企業。

過去，當白领、坐辦公室的上班族，是求職者嚮往的目標，但在這個公司隨時都會倒閉的年代，努力與技術工作重新受到重視，在這樣的時代潮流下，WORKMAN 必然會逐漸成長。

不過，獨占型企業還是要搭上時代潮流的順風車，才有機會成長茁壯；因此，它的特徵是投資人很容易能辨識出時代巨大轉變的助跑。
