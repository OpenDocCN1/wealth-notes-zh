# 運用賣出指標的四個重點

+   獲利重點：不執著於賣在最高點。
重要度：★☆☆

前面介紹過我的選股方式，是看出翻股的「漲」相，這種翻股要買在創新高價位，也就是K線上平整後陡升的位置；同時，這種翻股的特性是翻漲後會暴跌，因此股票從一買進，就要做好隨時賣出的心理準備。

不過，賣出持股比買進決定簡單多了，在多數情況下，只需要照著技術分析的指標，機械性地操作即可——當賣出訊號出現，即便該公司的基本面很好!還是得賣。

投資人也可能碰上基本面惡化，而必須賣出持股的情況，不過這種情況很罕見，發生機率不到一成。因此賣出時機的判斷，主要还是依據技術分析。用按技術分析的賣股指標，有四個重點。只要牢記並記住這四個重點，今後你實股時就能獨立斷、不必求人。

# 重點一：不執著於賣在最高點

選股時你怎麼挑三揀四都不為過，標準可以盡量嚴苛，因為即使漏抓一條大魚，也不會產生實際虧損。因此，即使是投資新手，只要熟習一套好的選股方法，就不會有太大的問題。
