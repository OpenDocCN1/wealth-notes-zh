# ## 飆股的長相

規谷底和短期谷底，RSI 數值一模一樣，可見光靠RSI，投資人無法判斷這支股票接下來的走勢會如何。

有些股票進入平穩期後，即使每季出爐的財報數字都很好看，股價卻不動如山；而且就算接下來幾季的財報同樣漂亮，股價還是紋風不動，直到某一天，投資人彷彿全睡過來的，股價便突然一飛沖天。

例如日本建築公司新興 PlanTech，請看圖表1-13中的平穩期（紅色網底部分）及這段時間的獲利表現，平均來說，新與PlanTech 各季的經常利益成長率在100%（兩倍）以上，股價卻沒什麼動靜。但它的投資一動新高、吸引了投資人的關注，立刻一飛沖天。理論上來

> > 即使獲利成長，股價仍維持在平穩期
