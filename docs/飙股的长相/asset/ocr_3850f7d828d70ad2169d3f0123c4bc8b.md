+   4. 營業額不佳，股票會被拋棄

如果同基本面分析中，營業額跟獲利哪個比較重要？答案當然是獲利。因此，大多數投資人在買股票前，一定會先確認該公司的獲利成長率。不過，不少人會忘了確認營業額。獲利是從營業額中產生的，當營業額不再成長，獲利的成長空間自然也會跟著受限。
