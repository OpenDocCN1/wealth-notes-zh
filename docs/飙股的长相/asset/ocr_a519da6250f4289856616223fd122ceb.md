# 第一章：選股密技百百種，我的最快看山翻股

> * 過去二～三季（與去年同期相比）
* 營業額成長10%以上
* 經常利益（含股兌稅後純益）成長20%以上

一定要看清楚你選的股票，是否達到上述標準，如果沒有達標，那麼就算它的K線圖看起來多有翻漲潛力，你都必须淘汰。

以圖表1-2的近鐵車輛來說，它的業績好到不能再好了。如果依照美式的K線分析法，會把平穩期的後半解譯為「杯狀帶柄型態」。
