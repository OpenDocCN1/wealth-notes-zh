# 超股的長相・別冊

而掌握特殊的利基，這便會是一個值得長期持有的好標的，直到這個利基被打破為止。以合股來者，統一超（2912）便是其中一例。

統一超商在1987年成立，由高層逐一打造，歷經七年時間才轉虧為盈，之後獲利便穩健成長，來到今日的規模，並藉由國內實施通路的壟斷。

統一超商的成功，可以說是「長尾理論」的最佳典範。它以科學的技術，利用POS機制，建立精密的管理系統，將小眾市場集合起來達到經濟規模，並且樹立了進入門檻，使得該公司在展店數量突破經濟規模後，獲利便開始突飛猛進。它在1997年6月掛牌上市，截至今日為止，將除權、除息還原回來，一共上漲了近十倍！這期間不過六年的時間，漲幅相當驚人，原因就在其享有通路上的競爭
