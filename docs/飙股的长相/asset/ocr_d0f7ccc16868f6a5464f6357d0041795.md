# ### K線波動率的公式

首先，算出單日股價的涨幅＋跌幅

| 昨日收盤價－當日開盤價 | + | 最高價－最低價 |
| :--- | :---: | :--- |
| 最高價－最低價 | + | 最低價－收盤價 |

| 昨日收盤價－當日開盤價 | + | 開盤價－最高價 | + |
| :--- | :---: | :--- | :--- |
| 最高價－最低價 | + | 最低價－收盤價 | |

# K線波動率的公式

波動率(%) = 「單日股價漲跌幅度」的月平均值
收盤價的月平均值 × 100
說明： ｜ 為絕對值。
