# 第五章：賣得好，賺更多

相對來說，賣出則是將手上的持股變現，在某種程度上必須跟現實妥協——你遲早都得賣掉股票，但吉凶時事在高點，往往會成為傷本的根源。

儘管技術指標有優劣之分，但無論使用哪種指標，幾乎都會同期（差距約在數日內）發出賣出訊號。當然，這些差異累積起來，也是一筆可觀的報酬。但對投資新手來說，當務之急是先學一套好用的買進分析指標，因為買進才是造成獲利差異的最大關鍵。

# 重點二：了解何時適用什麼指標

本章將介紹兩種技术分析的要股指標，這兩種指標已經得到長期數據的證實，能比其他工具幫助投資人獲取更高的獲利。

可能有讀者會想：「是不是只要學會這兩種指標就行了？」我的回答是：任何指標都有失靈的時候，所以在使用任何一項指標之前，應該先了解它的特性，挑選適合的時機使用。

請見下頁圖表5-1，順位相關係數（Rank Correlation Index, RCI）這項指標用在股價於高點圈附近徘徊時，效果特別好（將在第五章第三節詳細說明）；相對地，賣出轉變線則適用於股價暴跌時（將在第五章第二節詳細說明）。

另外，從波動率的觀點來看，在高點圈附近，若波動率小，則適合用 RCI；波動率大，則適用賣出轉變線；我在前文介紹的「賣壓比例」，則介於兩者之間（見〈大漲的訊號〉第四章第五節）。
