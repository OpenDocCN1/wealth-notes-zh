# 即使獲利重回高峰，股價也只剩一半

2. 獲利必須快速成長，而非穩定成長

下頁圖表6-17的日本雅虎則是從快速成長變成穩定成長，從2008年3月起，年均獲利成長率高達7%。如果說股價會和獲利連動，那麼股價也應該每年成長7%才對，但實際上，它的股價不僅跌幅超過日經平均指數，2011年的低點更是從高點跌掉77%的市值。
