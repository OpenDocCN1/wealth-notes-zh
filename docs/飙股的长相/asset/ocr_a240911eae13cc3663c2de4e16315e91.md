# 合併只能延緩股價下跌

日本大部分的購併案都發生在金融業。1980年代泡沫經濟崩潰以前，日本都市銀行曾被稱為「15行體制」（指昭和、神戶、埼玉、三和、住友、第一、太陽、大阪、東海、東京、日本勸業、富土、北海道拓殖、三井、三菱這15家銀行），如今只剩下三大集團（三菱UFJ金融集團、三井住友金融集團、瑞穗集團）和Resona銀行（前身爲大和銀行）而已。

銀行合併的過程中，金融股的行情也開始是下跌。由於金融股合併後股票代號改變，形成新的股價，所以無法算出精確的跌幅，但就算只看待1980年代開始購併、表現最好的住友信託銀行，股價從1987年高點到1998年的低點，也下跌了95%。

企業合併確實有好處，可以降低成本，遏止獲利繼續惡化，但這廠做也只是把股價下滑的幅度從銳角轉成鈍角而已，還不足以吸引投資人買進。
