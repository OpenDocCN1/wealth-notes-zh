# 四個步驟，
迅速看出飆股的長相

獲利重點：練出迅速看見飆股的「直覺反應」，就能贏在比例
人快一步。

重要度：★★★

你有沒有碰過類似的經驗，電視節目上出現新藝人，或是跟
公司、業界的前輩或晚輩初次碰面，往往你只需一眼就能感覺到
「這個人以後會成功！」
直覺與暗猜不同，那是你累積了許多閱人經驗後的反應，我相信從以前到現在，能讓你直覺「這個人以後會成功！」的對象，只有鳳毛麟角。

股票也是一樣，我們必須投資那種直覺「這支一定會飆漲」的
股票，要做到這一點，就得練習看懂飆股的「漲」相；而想看懂這
樣的股力，就得大量接觸股票，了解公司成功的必要條件。

這種直覺有個特色，就是你對自己的選擇不會妥協。當你去超
市買啤酒時，最喜歡的牌子剛好賣完，這時你多半會改買第二喜歡
的牌子；但我們不會因為今天沒看到讓人眼睛一亮的人物，就降低標準，對另一個人產生「這傢伙不簡單」的感覺；股票也是一樣，我們不會因為今天看不到有「漲」相的股票，就退而求其次，感覺另一支股票會飆漲。
