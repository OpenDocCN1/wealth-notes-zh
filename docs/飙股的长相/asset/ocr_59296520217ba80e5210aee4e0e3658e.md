# 廢氣排放標準變嚴、換車需求跟著提升

際公司規定了船舶只能使用不含鎳的資料。中國鎳料公司從1992年開始製造非鎳鎳料產品，本身所擁有的技術大幅領先國外廠商，因此股價前後大約翻漲了九倍。

大同金屬是日本製造汽車軸承的大廠，該公司率先研發出世界首創不含鈿軸承。這項開發符合世界的環保潮流，即盡量避免製造含鈿物品。歐盟本來打算在2005年開始實施含鈿量的規定標準，但因為歐洲企業應變不及，所以這項規定晚了三年實施。表面上看起來歐盟的延後實施對大同金屬不利，但這反而證明了該公司具有前瞻性，股價也翻漲了五倍。請見下頁圖表2-15，大同金屬在2004年出現了一道漂亮的平穩期。
