# 顈股的特相

# 2. 看股價走勢圖選股

經濟學家、商業顧問、企業經營者無法掌握股票致富，主要是因為他們沒有養成看股價走勢圖的習慣。即使他們知道某個事業將來大有可為，但他們的進場時機不是太早，就是利多早就反映在股價上，對選股沒有足夠的敏銳度。

專業投資人在選股時，一定會看股價走勢圖（方法詳見第一章第二節），遵照顈股的兩大定理，去尋找創新高價位。股價走勢圖是所有重要情報匯聚在一張圖中的便利工具，光是這張圖就能衍生出各式各樣的分析技巧。我們沒道理不好好利用它。我認為善用股價走勢圖，才是通往獲利的捷徑，所以我给它三顆*。

真正會漲的顈股，股價走勢圖會表現得非常鮮明強列，當它出現創新高價位，就是最好的買點。這好比是藝人經紀公司，他們很少從零開始培育一個新人，往往是在某個人突然爆紅時快捷簽下，因為爆紅的人已經通過市場的檢驗，所以值得投資。

當你選出中意的個股後，還要拿你選的股票跟別的股票做比較，了解目前市場如何看待你選的股票（方法詳見第三章）。如果你選的股票裡，有一支的股價走勢與其他同業完全不同，就要多加注意。
