# 顯股的長相

從圖表3-4可以看到，東利多（烏龍麵店）與利民（居酒屋）這兩家外食連鎖業者，在2008年11月同時股價平穩期，股價大漲，光憑這一點就能證明它們可視為同類股。

股市裡其實不常出現獨行狼。當你發現疑似獨行狼的股票，可以找找同時期是否有急速成長的新興企業，那或許就是它的同類。

其實尋找同類股，還有一個更重要的意義：這麼做能讓我們不僅光找出新高價的個股，還能在尋找性價相近股票的過程中，意識到市場的整體變化，讓我們得以用俯瞰的角度，理解在哪些領域、哪些股票比較會受到市場青睞。這是投資人了解股市的整體動向時，不可或缺的一環。
