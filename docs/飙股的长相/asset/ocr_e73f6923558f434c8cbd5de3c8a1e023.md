# 二、能提供同業難複製的服務

製造業者購買生產設備之後，相同產品的數量生產愈多，就能壓低成本。其他業者進入這種領域，也是以大量生產、降低成本為主要策略，導致市場上相同產品的價格不斷下殺，這就是家電產品會愈來愈便宜的原因。

相對於製造業，如果某個產業是以員工人數的成長為企業成長的關鍵，其他業者想要打進這塊市場，就沒那麼容易了。該領域的業者只要登上龍頭寶座，就會把第二名以後的企業遠遠甩在後頭。
