
## 第四章：這支股票會漲到哪？

### 「兩段式上漲」的波段構造

接下來，我們藉由實際的K線圖，再進一步說明「兩段式上漲」的原理。

股價的變化主要是由兩段漲跌波幅範圍相似的大波動組成，其構造有如洋蔥，無論剝了幾層，都維持著相同的形狀（只是愈來愈小）。同理，一波大漲中包括兩次中型漲幅，中型漲幅又可細分成兩次更小的漲幅。無論你是從大、中、小的漲幅範圍來計算，最後推算出來的亮點，基本上漲姿都是一樣的。

請先記住這個概念，然後再來看圖表4-15，它是由兩段長期漲幅AB和CD所組成（加起來約20年）；接著再看圖表4-16，CD又是由兩段較小的漲幅組成（加起來約4年）。也就是說，CD是由兩次中期漲幅CV和WD組成，而WD又能再細分成WX和YD這兩個短期漲幅。

- **長期漲幅**：根據圖表4-15，信越化學從1985年的A點572日圓漲到2000年的B點6,630日圓後，2001年又跌到C點3,260日圓。因此，就長期波動來看，我們可以推算它的高點如下：
  高點D的預測值 = 3,260 (C) + AB (6,630 – 572) = 9,138

- **中期漲幅**：請看圖表4-16，這支股票從C點3,260圓漲到2006年的V點7,040圓，是它的第一段中期漲幅；之後，它又跌到W點5,380圓。所以，如果要從W點預測它下一次的高點，預測值應為：
  高點D的預測值 = 5,380（W）＋CV（7,040-3,260）＝9,160

- **短期漲幅**：隨後，它的股價從W點5,380圓，又漲到X點8,170圓，這是它的短期漲幅。碰到高點後它又跌至Y點6,880圓。如果投資人要从Y點預測接下來的最高點，預測值應為：
  高點D的預測值＝6,880（Y）＋WX（8,170-5,380）＝9,670

### 預測漲幅過20%，才值得買進

如果你看上的某種股票，預測漲幅不到20%，千萬不要冒險買進。我們來看一個實際例子，我直接從圖表4-16附兩個創新高價的來證明：

- V點：此時我們預測股價最高值是9,138圓（參照從長期漲幅推算的高點預測值）或9,160圓（參照從中期漲幅推算的高點預測值）。如果從V點算起，兩者的漲幅分別是32%、30%，都還算高，在這個時點「買進」沒有問題。

- X點：此時可預測的高點除了上述兩個計算結果外，還能從短期漲幅推算出另一個預測值9,670日圓；但即使假設股價最高能觸摸到9,670日圓，從X點（8,170日圓）上漲到這個預測值，漲幅也才18%，不到20%，因此這個時候不宜買進。

結論是：Y點和X點都是創新高價的位置，但Y點可以買，X點不能買。假如你買在X點，由於之後股東看到的實際高點是9,580日圓，漲幅約有17%，如果你在此時賣掉，就有17%的報酬率；但在實際操作上，我們無法剛好在高點賣掉股票，能砍17%拿到一半的獲利就很了不起了。

最高點的計算結果，可能會因長、中、短期漲幅的切入點而有所不同，一般來說，只要記得愈短期的漲幅愈接近現實情況即可。以倍越化學為例，從短期漲幅推算出來的結果是9,670日圓，在三個預測值中最接近實際的最高點9,580日圓。但是，為了保證確見，買進時還是參考三個預測值中最低的一個價位比較妥當。

另外，我之所以說「Y點可以買 X點不能買」，是為了讓大家更容易理解兩段式上漲的概念；實際上，我們不會等到股價突破Y點才買進，而是在脫離平穩期後（Y點之前）陡升時就買進。

### K線圖漂不漂亮？該怎麼看？

如何看出K線圖漂不漂亮？相信現在各位讀者也能辦到，只要大量看K線圖，一定愈來愈能區分哪些K線圖長得漂亮、哪些不漂亮。

圖表4-17的日立製作所，就是K線圖不漂亮的範例。如同前面的例子，我們先解釋它的「兩段式上漲」。從K線圖中可以看得出，它的兩段式上漲為：

- 長期漲幅：AB和CF
- 中期漲幅：CD和EF

我們假設現在這時候股票來到紅色箭頭標示的新高價位D點（888日圓），根據兩段式上漲的計算方式，看看這支股票是否值得買進。

用長期漲幅計算：
`F點的預測值=C點+AB=604+(850-366)=1,088`

用中期漲幅計算：
`F點的預測值=E點+CD=644+(888-604)=928`

從現值888日圓到928日圓，漲幅不過5%；而如果漲到1,088日圓，漲幅有23%，雖然符合標準，但保險起見還是不應該買進；實際上，F點最後只漲到947日圓。

日立製作所的股價觸頂後，立刻大幅下跌。在F點之前的D段跌了244日圓（D點888日圓－E點644日圓），而更早之前的CD段漲了284日圓（D點888日圓－C點604日圓）；換句話說，它的跌幅佔漲幅的86%，等於在上漲後跌了近九成，證明投資人根本不看好它的基本面。

其實這支股票在基本面分析的階段就已經不合格，根本不用再進行兩段式上漲的分析。換句話說，基本面不佳的股票，用「兩段式上漲」的方式篩選，一樣會被淘汰。

最後提醒大家：高點的預測值不能只在創新高買那天計算，而是要隨著股價的變動，隨時修正預測值。雖然太過依賴預測值很危險，但這還能讓你對股價高點心中有數，避免過了高點暴跌、卻還沒賣出的窘境。

## 第五章：賣得好，賺更多

### 運用賣出指標的四個重點

- 獲利重點：不執著於賣在最高點。
  重要度：★☆☆

前面介紹過我的選股方式，是看出飆股的「漲」相，這種飆股要買在創新高價位，也就是K線上平整後陡升的位置；同時，這種飆股的特性是翻漲後會暴跌，因此股票從一買進，就要做好隨時賣出的心理準備。

不過，賣出持股比買進決定簡單多了，在多數情況下，只需要照著技術分析的指標，機械性地操作即可——當賣出訊號出現，即便該公司的基本面很好！還是得賣。

投資人也可能碰上基本面惡化，而必須賣出持股的情況，不過這種情況很罕見，發生機率不到一成。因此賣出時機的判斷，主要还是依據技術分析。依照技術分析的賣出指標，有四個重點。只要牢記並記住這四個重點，今後你實戰股票時就能獨立判斷、不必求人。

### 重點一：不執著於賣在最高點

選股時你怎麼挑三揀四都不為過，標準可以盡量嚴苛，因為即使漏抓一條大魚，也不會產生實際虧損。因此，即使是投資新手，只要熟習一套好的選股方法，就不會有太大的問題。

相對來說，賣出則是將手上的持股變現，在某種程度上必須跟現實妥協——你遲早都得賣掉股票，但吉凶事在高點，往往會成為傷本的根源。

儘管技術指標有優劣之分，但無論使用哪種指標，幾乎都會同期（差距約在數日內）發出賣出訊號。當然，這些差異累積起來，也是一筆可觀的報酬。但對投資新手來說，當務之急是先學一套好用的買進分析指標，因為買進才是造成獲利差異的最大關鍵。

### 重點二：了解何時適用什麼指標

本章將介紹兩種技術分析的賣出指標，這兩種指標已經得到長期數據的證實，能比其他工具幫助投資人獲取更高的獲利。

可能有讀者會想：「是不是只要學會這兩種指標就行了？」我的回答是：任何指標都有失靈的時候，所以在使用任何一項指標之前，應該先了解它的特性，挑選適合的時機使用。

請見下頁圖表5-1，順位相關係數（Rank Correlation Index, RCI）這項指標用在股價於高點圈附近徘徊時，效果特別好（將在第五章第三節詳細說明）；相對地，賣出轉換線則適用於股價暴跌時（將在第五章第二節詳細說明）。

另外，從波動率的觀點來看，在高點圈附近，若波動率小，則適合用 RCI；波動率大，則適用賣出轉換線；我在前文介紹的「賣壓比例」，則介於兩者之間（見〈大漲的訊號〉第四章第五節）。

### 重點三：小心「助跑行情」

重點三最重要。了解前兩種指標的特性後，接下來要了解這兩項工具在什麼樣的行情中，有可能會失靈。使用賣出指標時，比起「了解指標的作用」，更重要的是「了解這個指標在什麼狀況下不會發生作用」。

指標如果失靈，就有可能在股價之後，股價不跌反升，而最容易發生這種情況的，就是「助跑行情」。助跑行情是投資人做出賣出決定時最大的關卡，因為任何一種賣出指標，都可能在助跑行情中失靈。

請看圖表5-2，假設股價呈現齒狀上下波動，我們大致可以把它分成股價持平、助跑行情、上升行情。「助跑行情」介於「股價持平」與「上升行情」之間。通常，股價持平時會形成平穩期，助跑行情的形狀則像是要上漲，又像是要形成平穩期，「範圍」會比平穩期大一些。

| | 股價走勢 | 波動 | 成交量 |
|---|---|---|---|
| ①股價持平 | 小 | 持平 | |
| ②助跑行情 | 中 | 微幅上漲 | |
| ③上升行情 | 大 | 暴漲 | |

在第一章第二節的圖表1-24裡，我們看到股價如果在第二個平穩期的漲幅較大，代表即將進入上升行情；但在助跑行情中，平穩期的上漲不會只出現兩次，而是重複好幾次，這些多來的微幅上漲，就是「助跑行情」。

在助跑行情中，若是跌幅稍微大一點，很容易出現假的賣出訊號。請見圖表5-3，如果你在創新高價時買進，由於賣出訊號出現，所以會出現太早賣出的情形。

#### 助跑行情可能持續很久

以嬌聯（日本婦幼用品製造商）這家公司為例，假設有人在2006年買進嬌聯股票，而且拖到2010年再賣出，能獲得將近兩倍的獲利，但如果依照賣出訊號操作，獲利幾乎是零。

請見圖表5-4，嬌聯這支股票在2006年～2010年間多次形成平穩期，股價也屢創新高。此外，它在2009年還沒形成平穩期就創新高價，但隔月及下個月都開出陰線，出現賣出訊號。

#### 投資人很難從助跑行情中獲利

看嬌聯的業績，就能發現支撐它助跑行情的理由。在2005年～2011年期間，嬌聯的營業額與經常利益的年均成長率只有7%左右，所以股價上漲比較緩慢。照理說，這樣的成長率並未達到我們設定的標準（營業額10%、獲利20%），應該不買才對，但有時成長型的股價，會出現長期維持助跑行情的狀況。

有人可能會認為：「既然業績好就先別賣，觀察一陣子再說。」但一般來說，當一家公司的基本面漸入佳境，有時股價會提前反應、達到該賣的高點，所以不能光看基本面就決定買進。

買股時，我們很難判斷接下來的上升行情是會一路繚漲，或只是助跑行情。當整盤股市出現疲軟，該股也可能在助跑行情結束後下跌。此時遽照技術分析的指標做決定，才是最明智的選擇。

賣出指標除了在助跑行情可能失靈外，其餘的時候都沒有太大的問題。尤其在上升行情的高點附近，賣出指標最能發揮作用，其威力甚至能超越基本面分析。

### 重點四：避免放空

到目前為止，賣出的重點大致上已經說完畢，最後我想再談談放空。

放空是指投資人判斷股價已漲到高點後，從賣出開始的交易行為；換言之，就是先賣再買。也是投資新手較不熟悉的交易型態。

股票交易通常是低買高賣，放空其實也一樣，只不過是先賣再買，所以股價跌得愈重，放空者賺得愈多；但我要請各位讀者不要放空，因為要是賣出後反而出現上升行情，將會蒙受很大的損失。

因為這種操作方式太過於仰賴技術分析。相對地，如果從買開始操作股票，就可以同時利用基本面分析與技術分析來選股，看兩個面向當然會比只看技術指標強，勝率也比較高。

有些人會想：「既然如此，那就在基本面出現惡化時，趕快放空不就好了？」但通常此時股價的跌勢會很猛烈，等到你出手時恐怕就來不及了。請看圖表5-5，過度依賴技術分析，可能會在這種情境中受到重挫。從中期來看，股價只是暫時觸頂，之後雖然下跌，但長期來說會繼續上漲，朝著更高的價位邁進。

### 二、賣出轉換線的原理

#### 暴跌時，注意「賣出轉換線」

- 獲利重點：適用於股價暴跌時。
  重要度：★★☆

賣出轉換線是我的發明，簡單來說，就是用第四章K線波動率的觀念來計算停損點，其原理是：「從近期高點算起，跌幅多少就賣出」。例如，假設近期的高點為1,000日圓，而你設定的停損幅度是10%，那麼當股價跌破900日圓時，就得賣出（也就是說，900日圓是賣出轉換價格）。

請見圖表5-6，當股價過了左邊的小高峰後小幅下跌，但不到10%，由此判斷不必賣出；然而當股價過了右邊的大高峰後，股價大跌且超過10%，就必須考慮賣出股票。使用賣出轉換線時，時間的長短不列入考量；也就是說，不管下跌是發生在高峰後的一週或一個月，只要幅度超過10%，就要考慮賣出。

不過，根據我的經驗，傳統的跌幅定義使用起來的效果並不好，因此我設定了如圖表5-7的規則，根據波動率來計算每天的轉換幅度，而非死守10%這個數值。這麼做是因為同樣的波動率，對於不同的股票來說意義差很多。

例如，假設某一天，阿拉伯聯合大公國和日本出現了相同的降雨量，在日本會被視為稀鬆平常；在阿拉伯地區卻是不得了的天候異常，媒體一定會大肆報導，因為當地的道路沒有排水系統，一定會出現淹水的災情。同理，股價波動幅度大的股票，稍微跌一點還不至於要賣出；但若是股價波動幅度小的股票，即使下跌幅度不多，也應該考慮賣出。

#### 平均漲跌幅度的3倍，就是轉換幅度

我們可以先把持股先粗略分成波動較小和波動較大兩組，不過，股價的波動沒這麼單純。住在一支股票在某種情況下算是波動小，在某種情況下卻算是波動大，因此最好的方法，是掌握漲跌幅度的平均值。當股價跌破特定的平均漲跌幅度，就代表波動範圍超出標準，已達賣出轉換時機。

轉換幅度的算式，請先參照第四章第三節的漲跌幅算法，漲跌幅度（20天的平均值）的3倍就是轉換幅度。以圖表4-12（見第150頁）為例，第一天和第二天的平均漲跌幅度是35日圓（(40+30)÷2），3倍就是105日圓（35×3）——這就是它的轉換幅度——但正常來說應該採用20天的平均值。

接著，我們來看一個實際案例。圖表5-8的三井不動產，其股價在2007年5月10日來到4,000日圓的高點，之後便進入下跌行情。根據賣出轉換線，賣出訊號出現在6月14日。圖表5-9就是依據實際狀況描繪的賣出轉換線走勢。6月14日當天，它的平均漲跌幅度是160.5日圓，而近期高點則為4,000日圓，因此，根據圖表5-7的公式，計算賣出轉換價格=4,000-160.5×3=3,518.5（日圓）

當天它的收盤價來到3,510日圓，已經突破賣出轉換線了。

#### 何時適用賣出轉換線？

如果某支股票過去都呈現緩步上漲，但突然在某個時間點向下急殺，那麼賣出轉換線可以比其他的技術分析指標更早發出訊號。

請看圖表5-10的範例：五十鈴汽車的股票在2007年7月17日達到720日圓高點。根據賣出轉換線，賣出訊號出現在觸頂後的第11個交易日8月1日，當日收盤價為620日圓，若此時賣出，便可以避免之後暴跌到100日圓時措手不及。

如果股價過了高點後，平均漲跌振幅值很小，賣出轉換線就很難發揮作用，但請放心，因為在實際的股票走勢中，幾乎不會發生這種狀況。
