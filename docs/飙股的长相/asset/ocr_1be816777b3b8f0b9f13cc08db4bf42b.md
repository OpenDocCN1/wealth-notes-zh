# 1 別買業界裡的「獨行狼」

獲利重點：早同业一步创新高價，不是好消息。

重要度：★★☆

本章要帶領讀者看典型的怪貓股，這類股票看起來有飜股的長相，容易讓投資人上當，具體來說，分成以下四種：

+   1. 獨行狼：同類股票都下跌，只有該公司先漲上去。
2. 落後補漲：同類股票都上漲了，只有該公司股票落後上漲。
3. 公司重整：公司可以裁員等手段，來換取財報獲利。
4. 公司購併：公司發布購併另一家公司的消息。

以上這四類股票最好不要買，尤其是「獨行狼」的K線看起來很有「漲相」，千萬不要上當。至於「落後補漲」、「公司重整」、「公司購併」的股票，股票分析師們都會對它們做出正面、看好的評論，我希望各位禁得起誘惑。
