# 交易紀律與價格風險管理

交易紀律最容易發生問題的地方，通常都在風險管理方 面。如同本書第1章曾經提到的，根據丹尼爾·卡尼曼（Daniel Kahneman）與阿莫斯·特沃斯基（Amos Tversky）有關於「前 景理論」（Prospect Theory）的研究，人類普遍都有拒絕認賠 的心理偏頗，而所有社會制約更傾向於強化這種天生偏頗。不 論是從小接受教育，或長大服務於社會，我們都被灌輸一種絕 對不可認輸的思想，我們把「認輸」跟「輸家」連結在一起。 很有趣的是，對於金融交易來說，贏家反而是那些願意認輸的 人；在這個領域裡，我們必須學習如何跟「交易」分割，交易 盈虧並不代表我們本身的輸贏。當然，我並不是建議各位只要 看到交易稍有虧損就立即認賠，目的只是為了證明自己具備認 賠的能力。此處談論的紀律，是說交易者一旦認定某個部位已 經失敗，就應該儘快認賠。

1987年，當我剛踏進期貨行業，曾經到很多結算交易機 構接受面試。有個面試讓我印象特別深刻，這是發生在 SLK 期貨公司（目前屬於高盛 [Goldman Sachs]）。主試者問我，「你 是大學生？」我回答是的，他立即搖搖頭說，「沒用的。」我 完全聽不懂，因此請他稍做說明。他說，「我們聘用了很多大 學畢業生，大概20個，都是長春藤名校畢業的 MBA，每個都 是班上的前幾名。我們給他們每人$10萬塊，他們都在6個月 之內就破產了。沒有一個例外。」他們當然會破產。很諷刺的，
