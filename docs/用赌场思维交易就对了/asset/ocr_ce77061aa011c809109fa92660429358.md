我可以跟各位保證，長期而言，絕對沒有所謂的運氣。如果想憑藉著運氣來協助你克服風險，那麼帳戶破產只是時間的問題——凱恩斯說過 $ ^ { ( 註6 ) } $ ，「長期而言，我們都會死。」每隔三、兩個月，就有初學交易者會問我，如果帳戶內只有 $ 2,000 或 $ 3,000，應該怎麼做？對於這類問題，我的答案很簡單：「什麼也別做。」多數情況下，對話至此就結束了。可是，某些人會進一步追問，「你是說，無論如何也不可能把 $ 2,000 變成 $ 100 萬？」「沒錯，我就是這個意思！」

當然，純就機率而言，我的結論或許有些言過其實。有些人確實能夠把 $ 1,000 變成 $ 100 萬，但可能性很低，甚至低到沒有實質意義。所以，爲了避免發生誤會，我會強調「絕不可能」。
