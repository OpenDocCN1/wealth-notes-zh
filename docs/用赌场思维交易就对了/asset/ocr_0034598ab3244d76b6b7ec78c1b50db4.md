# 時間架構確認交易

根據傳統的時間架構分析，當數學技術指標（譬如移動平均，或 RSI 等%擺盪指標）顯示所有時間架構的趨勢都呈現多頭則買進，所有時間架構的趨勢都呈現空頭則放空。一般常用的時間架構確認訊號有兩種版本。第一種，每當所有時間架構都顯示多頭或空頭趨勢，就盲目地買進或賣出，而不論這些確認訊號發生的時間彼此之間差距有多遠（請參考圖 7.8）。

第二種版本相對可靠，長期時間架構的交易訊號必須先發生，而當最短期時間架構分析由背離轉變為確認，這時候才代表交易訊號得到確認。請參考圖 7.9 與圖 7.10，其中圖 7.10 顯示通用電器 RSI 在下午 2：40 向上穿越 50 的買進價格爲 $16.65，而若根據收盤價買進的價格則爲 $16.78。
