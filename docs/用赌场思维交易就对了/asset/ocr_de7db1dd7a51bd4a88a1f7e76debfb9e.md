加到中性、多層面的市場行爲上，因此侷限了我們客觀評估真實市況的能力，也妨礙了我們交易成功的能力。

# # 不確定

下一檔價格跳動究竟是向上或向下，沒有人能有絕對把握。由於金融市場隨時都存在不確定性，交易者任何時候、對於任何一筆交易，都不能放鬆風險管理。另外，由於市場行爲的不確定性，成功的交易者應該從機率角度做思考。強迫自己思考機率，這可能是交易成功最重要的關鍵之一。如果我們接受市場行爲的不確定性，就必須承認任何價格都是可能的，而在這種過程裡，無限而多層面的市場性質就會抹除任何妄想。

初學者往往不知道如何處理金融市場行爲的不確定性。結果，他們可能反其道而行，想要尋找某種明確的解決之道。說來有些奇怪，本章想要提供的，也正是這種難以掌握的明確解決之道（但未必是初學者想要的）；「不確定性」就是所有交易者想要尋找而難以掌握的確定之物。由於不確定性隨時存在，這迫使我們必須針對當時市況做調整，而不是把我們的想法強加到市場上。
