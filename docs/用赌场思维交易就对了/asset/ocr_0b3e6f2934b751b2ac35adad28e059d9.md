```
MACDA(@,13.000,26.000, 9.000) [-1] AND
MACDA(@,13.000,26.000,9.000) [-1] < 0
```

相較於前述 MACD 穿越系統，讓我們看另一套結構很簡單的順勢突破系統「包寧傑帶狀突破系統」。進場法則很單純：當資產價格向上穿越過去 20 天期包寧傑帶狀的上限，則建立多頭部位；反之，當資產價格向下穿越過去 20 天期包寧傑帶狀的下限，則建立空頭部位。

另外，當價格反向穿越先前 20 天價格的簡單移動平均，則結束既有部位（換言之，對於多頭部位來說，出場訊號是價格跌破 20 天簡單移動平均；空頭部位的出場訊號，則是價格向上穿越 20 天簡單移動平均）。請參考圖 3.3，AverageDuration 顯示部位平均持有期間為 14 個交易日。這雖然是一般交易者比較容易接受的部位持有期間，但對於某些交易者來說，14 天還是太長。

運用CQG語言編寫包寧傑帶狀突破系統的方法如下：

```
Long Entry:
Close(@)[-1] > BHI(@,Sim,20,2.00)[-1]
Short Entry:
Close(@)[-1]< BLO(@,Sim,20,2.00)[-1]
Long Exit and Short Exit:
MA(@,Sim,20)[-1]
```
