# 第9章

# 提前猜測訊號

> 耐心是種美德。

— Geoffrey Chaucer

關於交易紀律，一種最常見、最嚴重的破壞行爲，就是提前猜測交易訊號。本章將探討歷史高價／低價的誘惑，說明投機客爲何會因爲歷史價格資料而背棄正值期望報酬模型。我們會特別強調如何藉由某些心理工具，強化交易者面對史無前例之價格時所必須提升的耐心與紀律。

# 永遠針對價值做交易，而不是價格

相信各位必定聽過：買低－賣高。這種看似簡單、明顯的道理，實際上充滿險惡，導致無數交易者失敗，因爲行情一旦發展到史無前例的價格區域，沒有人知道高價或低價究竟在哪裡。2011年，當我寫目前這些文字時，道瓊工業指數1,067.2點看起來頗低，但這個價格在1982年則是歷史新高價（參考圖9.1與9.2）。過去所謂的歷史高價，後來看起來可能很便宜（也有可能正好相反），所以我說：永遠要針對價值做交易，而不是價格。
