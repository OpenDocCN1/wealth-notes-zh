這個問題的答案，往往取決於交易所採用的是以技術分析或基本分析（包括季節性型態）爲主體的系統。若是以技術分析爲主的模型，每個市場通常都可以運用相同方法；但若是以基本分析爲主的方法，則需要針對個別資產的性質做調整。

# 問：交易進場與出場的準則是否不同？

這雖然是個「是」或「不是」的問題，但我們希望讀者更深入思考交易方法的策略。譬如說，如果修正進場或出場準則，績效是否能夠提升？

# 問：相關交易方法是否特別適用於某種時間架構？

交易方法如果運用於某種時間架構的績效特别好，這是是否因爲相關資產在該時間架構上，呈現特別顯著的順勢或回歸均值傾向？或是因爲持有時間較長，因此而節省了佣金成本、減少了流動性風險？

# 問：交易方法是否特別適用於某些市況？

交易方法的績效雖然會因爲市況不同而產生差異，但真正理想的交易系統，不論在多頭或空頭市場都能賺錢。另外，這個問題也凸顯出系統分散（同時採用性質不同的交易系統）的效益（參考本書第 8 章）。
