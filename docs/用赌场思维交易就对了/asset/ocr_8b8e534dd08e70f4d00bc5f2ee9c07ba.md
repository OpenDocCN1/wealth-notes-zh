# 結語

當我在 1987 年剛踏進金融交易行業時，大約每隔 6 個月左右，就有一位父執輩朋友的小孩來找我，他們剛從大學畢業，不知道自己應該幹什麼，於是找我探聽有關從事投機交易的可能性。現在，仍然有年輕人跑來找我，仍然是詢問金融投機事業的可行性，但他們大多是我朋友的小孩。在這 20 多年期間裡，我對於他們的回應始終相同：「別做這行。」如果你是因爲不知道應該幹什麼而決定從事金融交易，那就不太可能在這個領域獲得成功。你遲早會碰上連續 4、5 筆虧損交易，帳戶淨值也隨之減少 10%，然後你就幹不下去了。為什麼？因爲當你拿金融交易與其他行業做比較，就會想「我爲什麼要忍受這些？全世界的各種行業之中，很少有哪種行業，會讓你精疲力盡忙了一整天，結果反而讓鈔票減少。」

所以，對於那些打算從事交易的人，我總會問相同的問題：「你爲什麼想做交易？」除了想賺錢之外，如果沒有別的理由，我就會請他們打消念頭，因爲當不可逃避的連續虧損發生時，這些人就會放棄，想要另外尋找比較容易討生活的行業。可是，如果從事交易是因爲熱愛做研究、想要解決問題，那麼當逆境出現時，反而會強化鬥志，更想成功。就我個人來說，當操作不順利的时候，我會更堅堅持交易紀律、克制自己的情緒。古代煉金術經常會提到：「如其在上，如其在下」（As above, so below），翻譯爲白話文：「金融交易就如同日常生
