# 金字塔中間層

風險管理金字塔中間層的計量工具，所處理的問題包括資產的價格波動，以及資產彼此之間的相關性。

# 風險值

關於停損設定，更穩健的做法，應該要考慮當時的資產價格波動狀況。換言之，當時市況的價格波動愈劇烈，就應該採用愈寬鬆的停損，以避免原本可獲利的部位，被正常價格波動引發停損；反之，若當時市況的價格波動愈緩和，停損也應該設定得愈緊密，免得發生不必要的損失。正因爲停損設定應該考慮價格波動程度，所以我們很少只單獨談論停損，而會將部位規模也同時列入考慮。更明確說，價格波動愈劇烈，除了應該採用較寬鬆的停損之外，部位規模也應該考慮調降；反之，若價格波動愈緩和，停損也就應該更緊密一些，而部位規模則可以考慮放大。

對於停損設定、部位規模與價格波動之間關係的考量，促使我們進入風險管理金字塔的中間層，也就是所謂的風險值（Value-at-Risk，簡稱 VaR）。VaR 在風險管理模型內增添了两種不可或缺的要素：價格波動程度與價格相關性。VaR 檢視資產的歷史價格波動程度，以及資產彼此之間的價格相關性，如此可以讓停損設定與部位規模的設定更爲穩健。
