# 關於交易者

這些問題要求各位檢視自身的處境，以及相關處境對於金融交易的影響，議題包括：交易時間限制、財務限制、流動性風險議題，以及交易心理偏頗。

問：你是否還有其他職務？

這個問題讓你思考交易操作與各種研究工作在時間上的限制，因此也會影響交易模型的選擇。舉例來說，如果你每天必須朝九晚五地工作，顯然就不可能隨時看盤，也不能做當日沖銷或更短線的交易。

其他正職工作雖然會造成交易時間上的限制，但也有好處。譬如說，從事交易的機會成本不高，交易方面的固定支出相對有限。對於多數交易者來說（尤其是初學者），來自其他方面的影響或壓力愈小，通常對於績效愈有幫助。

問：交易不順利的時候，哪些因素會阻止你放棄？反之，交易很順利的時候，哪些因素會阻止交易行為變得草率？
