# 虧損與不確定感的恐懼

邁向交易成功之道的兩大障礙，分別是對於虧損與不確定的恐懼感（反映在交易上，就是擔心帳面獲利得而復失，結果演變為實際損失）。就佛教而言，這兩種障礙被人格化為死魔。

金融市場的虧損，等同於我父親（他是股票選擇權經紀人）早在我還沒有從事交易之前教導給我的死亡。我記得他曾經指著華爾街三一教會墓園裡的一座墓，半開玩笑的跟我說，「華爾街有座墓園，每天都有初學交易者埋葬在此。」

關於死魔，佛陀的教誨如何呢？想要克服這種障礙製造者，不能透過否認、憤怒、否定或沮喪等手段。死亡不會就此消失。你不能藉由意志力避開或克服死亡。若想要把死亡當作一種障礙來克服，只有接受與認同它。

上一段文字裡，請各位把「死亡」取代為「虧損」。

伊麗莎白·庫伯勒·羅斯（Elisabeth Kubler-Ross）在其《論死亡與臨終》《On Death and Dying》一書中指出了臨終前的五階段。這些階段也可以用來描述交易者所面臨的問題：虧損、缺乏控制力、不確定、懊悔，這些障礙讓交易者不能客觀觀察市場多層面的真實狀況。這五種階段分別為：
