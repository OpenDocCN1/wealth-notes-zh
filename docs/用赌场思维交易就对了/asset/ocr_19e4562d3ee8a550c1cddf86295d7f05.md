# ## 結語

部分獲利了結、然後把停損調整到損益兩平點等這些珍貴而可減緩懊悔的技巧，能協助交易者脫離陶醉 - 恐懼的惡性循環，讓心靈恢復平靜（本書最後一章將探討交易者如何維持心靈平靜的議題，好讓我們能夠秉持客觀的態度處理交易機會）。另外，只要掌握了減緩懊悔的技巧，就能有效防範交易完美症候群。所謂的交易完美症候群，是指交易者想要尋求完美的進場 / 出場價位，想要買在最低價或賣在最高價。追求完美的非理性執著，將妨礙交易者成功地進場與出場。若想要減緩懊悔的情緒，交易者通常需要分批進場與出場，如此也就不會去追求絕對完美的進場或出場點。總之，透過這些能減緩懊悔的手段，華爾街流傳的很多格言才能在情緒上變得可能，包括「正確而堅持」（being right and sitting tight），以及最經典的「迅速認賠，讓獲利部位繼續發展」。
