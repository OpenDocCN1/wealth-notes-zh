+   *   部位基於什麼理由出場？

+   *   是否嚴格遵循正期期望報酬交易模型？

+   *   是否嚴格遵守風險管理準則？

+   *   是否背離賭場典範？理由何在？

記錄交易日誌雖然是一件相當繁瑣的工作，但所有專業機構，包括：避險基金、商品基金、商品交易顧問、專業交易員、代客操作、以及造市者，都會詳細記錄這類的交易日誌。讀者如果不願做這方面的工作，就應該檢討爲何不願意的理由。是否交易方法存在某些我們不願意面對的瑕疵？我們是否違反 1~2% 的準則？我們的交易是否過於頻繁？失敗部位是否持有太久？是否過早獲利了結？交易者必須坦承面對自己的缺失，否則就不可能改進。長期累積的問題，不會突然之間自己獲得解決。想要改變交易行爲上的問題，首先就必須先找到問題，承認問題存在…這一切都要仰賴交易日誌。
