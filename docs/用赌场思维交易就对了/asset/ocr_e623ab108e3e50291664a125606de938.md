# 個別資產的績效紀錄

個別資產績效紀錄雖然並非必要，但還是有助於瞭解與改善交易偏頗。我個人覺得這部分報告很有用。個別資產績效紀錄採用的欄位，與多月份績效紀錄相同（22 欄）。這份報告的主要功能，是分析資產類別在多、空部位方面的方向性偏頗，以及非理性的風險管理偏頗。

# 個別交易模型的績效紀錄

如果採用兩種或以上的交易方法，這份紀錄可以追蹤、比較不同方法之間的表現。這份紀錄也採用多月份績效紀錄的22 個欄位，關鍵是分析每種交易模型的績效穩健程度。
