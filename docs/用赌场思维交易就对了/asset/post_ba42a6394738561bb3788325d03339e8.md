## 一目均衡穿越系統（Ichimoku Crossover Systems）：

1969 年，日本新聞記者細田悟一（Goichi Hosada）設計了一套順勢交易方法稱為 Ichimoku Kinko Hyo，也就是「一目均衡走勢圖」（one-glance balanced chart）。目前，此種指標通常稱為「一目均衡雲圖」（Ichimoku clouds），因爲其形狀看起來像是天上的雲朵。一目均衡雲圖有 4 種主要成份：

- 轉換線（Tenkan Line）：最近 9 期的（最高價 + 最低價）÷ 2。
- 基準線（Kijun Line）：最近 26 期的（最高價 + 最低價）÷ 2。
- 先行跨度 B（Senkou Span B）：最近 52 期（最高價 + 最低價）÷ 2，繪圖往前移動 26 期。
- 先行跨度 A（Senkou Span A）：（轉換線 + 基準線）÷ 2，繪圖往前移動 26 期。

實際通用上，轉換線 / 基準線可以被視為傳統的短期 / 長期移動平均，因此而構成移動平均穿越系統。反之，先行跨度 A 與先行跨度 B 的差值（換言之，兩者所夾的區域），則代表往後 26 期之支撐 / 壓力的「均衡雲」（請參考圖 8.5）。

![](img/4f4885b7fad5d7bd5221cd08845566cb_215_0.png)

一目均衡雲圖可以用來建構各種順勢交易系統，此處準備討論一種最簡單的轉換線 / 基準線穿越系統（請參考圖 8.6 與表 8.5）。

運用 CQG 語言，一目均衡穿越系統可以編寫如下（譯按，轉換線向上穿越基準線，則建立多頭部位或結束空頭部位；轉換線向下穿越基準線，則建立空頭部位或結束多頭部位）：

```
Long Entry:
Imoku1(@,9)[-1] > Imoku2(@,26)[-1]
Long Exit:
Imoku1(@,9)[-1] < Imoku2(@,26)[-1]
Short Entry:
Imoku1(@,9)[-1] < Imoku2(@,26)[-1]
Short Exit:
Imoku1(@,9)[-1] > Imoku2(@,26)[-1]
```

前述轉換線 / 基準線穿越系統如果結合「均衡雲」，績效表現會更穩健。更明確說，多頭部位買進訊號必須發生在均衡雲圖的上側，空頭部位放空訊號則必須發生在均衡雲圖的下側。另外，當轉換線反向穿越基準線，則結束既有部位（請參考圖 8.7 與表 8.6）。

## 包寧傑帶狀突破系統（Bollinger Band Breakout System）：

第 3 章曾經介紹包寧傑帶狀突破系統，這是結構最單純的機械性交易系統之一。如同 RSI 趨勢系統一樣，目前這套系統的獲利，主要也是來自於回歸均值系統交易者。此處討論的包寧傑帶狀，是以 20 期簡單移動平均為中心，然後上、下各取 2 個標準差做為帶狀寬度。傳統運用上，包寧傑帶狀原本屬於回歸均值模型。此處的突破系統，運用原則剛好相反：若收盤價突破帶狀上限，則建立多頭部位；若收盤價跌破帶狀下限，就建立空頭部位。追蹤停止點設定在 20 期簡單移動平均（請參考圖 8.8 與表 8.7）。

藉由 CQG，包寧傑帶狀突破系統的編寫方法如下：

```
Long Entry:
Close(@)[ -1 ] > BHI(@,Sim,20,2.00)[ -1]

Short Entry:
Close(@)[ -1 ] < BLO(@,Sim,20,2.00)[ -1]

Long Exit and Short Exit:
MA(@,Sim,20)[ -1]
```

## 回歸均值系統

就多數順勢系統來說，最大問題就是勝率太低。回歸均值模型的情況剛好相反，系統勝率很高，但維持高勝率必須付出代價，因爲回歸均值模型的盈虧比率（P:L）通常較低。

### RSI 極端系統（RSI Extremes System）：

RSI 極端系統是本書最先介紹的回歸均值模型，該系統結合了回歸均值擺盪指標（RSI），以及長期趨勢指標（200 期簡單移動平均）。運用這套模型時，交易者必須等待 RSI 擺盪指標進入極端超買或超賣狀態，然後再順著長期趨勢方向建立部位。就此處討論的案例而言，操作準則爲：收盤價位在 200 期簡單移動平均之上，而且 9 期 RSI 跌破 35，此爲建立多頭部位的買進訊號；反之，收盤價位在 200 期簡單移動平均之下，而且 9 期 RSI 向上穿越 65，此爲建立空頭部位的賣出訊號。而當 200 期簡單移動平均維持多頭趨勢，9 期 RSI 高於 65 時，就是多頭部位獲利了結的訊號；若是 200 期簡單移動平均維持空頭趨勢，9 期 RSI 跌破 35，則爲空頭部位的結束訊號。另外，這套系統採用了一種防患萬一的停損：限定每口合約最多損失 $7,500（請參考圖 8.9 與表 8.8）。
