# 第 5 章

# 針對市場進行交易 而不是為了錢

> 如果有人為了急需用錢而從事股票交易，結果會如何？在這種妄想下，他其實是在賭博。所以，他承擔的風險將遠超過精明的投機。
— Edwin Lefevre

投機客到頭來為什麼會針對金錢做交易，而忘了市場行情？本章將討論投機客針對金錢做交易的幾種情況，包括：不理會市況而設定金錢目標、基於金錢目標（而不是市況發展）獲利了結、不考慮價格波動狀況而盲目設定金錢停損（只因爲害怕虧損）。

# $1 萬塊是很多錢

著名投機客巴魯克（Bernard Baruch）曾經說過，「獲利了結不會讓人賠錢。」對於這種說法，我的觀點是，「話雖如此，但你所賺的錢，卻有可能在隨後 3 筆交易虧光。」如果我們總是想趕快獲利了結，賺些蝨頭小利，恐怕將難以應付失敗交易的虧損。多數書籍雖然都鼓勵交易者儘快認賠，並且讓成功部位儘可能繼續發展獲利，但我們總是想著錢，而不是市
