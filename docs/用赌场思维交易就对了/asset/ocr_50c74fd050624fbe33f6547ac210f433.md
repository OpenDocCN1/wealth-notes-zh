# 對於交易系統缺乏信心

對於交易系統缺乏信心，是導致交易紀律敗壞的另一個主要原因。本章稍早已經多次談到，一套正值期望報酬模型如果想發揮預期效果，該模型必須符合使用者的個性。除此之外，使用者之所以放棄交易模型，很可能是對於模型的某些性質缺乏信心，譬如：勝率、帳戶淨值最大耗損等。這些問題跟績效本身沒有太大關連，主要是因為缺乏某方面的信心，這可能是因為交易實際資金（參考第 5 章）、預期某種訊號（參考第 9 章）、猶豫不決而放棄進出場地點或風險管理準則。想要解決缺乏信心的問題，唯一的辦法是在實際操作之前，儘可能做完整的研究，包括歷史測試在內（細節討論請參考第 8 章）。

# 害怕沒有夠多的訊號

非理性地擔心交易系統沒辦法提供夠多的訊號，這點有別於交易系統不符合使用者個性的問題。此處討論的，是一套符合使用者個性的交易系統，但因為使用者非理性地擔心訊號數量不足而失掉耐心。這個問題之所以發生，癥結通常是因為使用者把注意力完全擺在「金錢」（我需要賺多少錢才能支付帳單），而不是市場行為。另外，使用者也可能要求實際結果來證明模型的賺錢能力。賭場經營者絕對不會因為在星期三清晨 2 點以前沒有賺到足夠的錢而關門大吉，或改變賭場的法則。同樣地，想要解決這方面的問題，辦法也是做儘可能完整的研究與歷史測試。
