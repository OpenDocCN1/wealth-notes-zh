# 執著於虛幻信念

佛學所謂的五蘊（也就是五陰魔的五陰），分別為：色（matter）、受（sensation）、想（cognition）、行（mental formations）、識（consciousness）。此五者也被視爲障礙，因爲它們也是我執的對象，因此而生虛幻。就交易而言，此五者讓我們遠離多層面的、不確定與持續變動的市場真實行為，轉移到一些我們主觀認定而虛幻的市場信念。

+   1. 色（Matter, Form）：

色包含我們內在的實體，以及外在的現象。

+   2. 受（Sensation, Feeling）：

受是對境而承受之主觀作用，譬如：愉悅、痛苦與中性。

+   3. 想（Cognition, Perception）：

想是指客體能否辨識而言（譬如：叮噹聲、箱子之形狀、桃子的味道…等）。

+   4. 行（Mental Formations）：

行包含客體引發的所有心智活動。佛教進一步將此劃分爲外界物體（譬如：書籍、電影等）引發之被動心智活動或想法，以及內 Department 部心智主動產生之心智活動。主動的「行」對於交易者心理影響甚鉅，以致於對於交易者本身和市場性質產生很多錯誤或虛幻的信念。
