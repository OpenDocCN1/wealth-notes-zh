# 推 薦 序

操盤手與職業賭手的賺錢方式是相同的。

早期研究投資加碼策略時，研究過金字塔、倒金字塔、等量、變量等策略，如今看到本書提到這些方法，都與賭場的賭博策略一樣，才發現投資、投機與賭博之間，有這麼多的共通點。

本書一開始就道破交易與賭博間的共通點，也就是李佛摩說的，只在勝算大的地方下手。用本書的話語來說，就是發展正值期望報酬模型。簡單來說，投資、投機、賭博要贏，就必須找到勝算較大的地方下單或下注。本書第一章就導入大量技術分析，藉以發展出勝算較大的系統與模型，接著談停損、停利、風險管理，再運用投资策略中「嚴守紀律」的規則來貫徹執行。
