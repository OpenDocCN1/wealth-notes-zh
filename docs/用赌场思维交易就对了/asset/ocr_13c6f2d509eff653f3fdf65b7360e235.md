+   4. 盈虧淨額—顯示扣減佣金之後的每個月盈虧淨額。

+   5. 交易筆數—這項數據會顯示出交易過份頻繁的警訊。  對於搶帽子或當日沖銷者，這項數據會偏高，但就各  月份彼此之間的比較而言，數據最好低一點。

+   6. 最大耗損—這是指月份內與跨月份的淨值最大耗損。  *標示月份內的最大耗損數據。

+   7. 期初餘額—月初帳戶餘額。

+   8. 報酬率%—代表月份報酬率，由第4項的「盈虧淨額」  除以第7項的「期初餘額」（除非當月份另有存入或  提領現金）。

+   9. 現金進出—交易帳戶存入或提領現金。

+   10. 期末餘額—月底帳戶餘額，通常也就是次個月的期初  餘額。

+   11. 成功交易筆數—當月份賺錢交易的筆數。

+   12. 失敗交易筆數—當月份虧錢交易的筆數。

+   13. 平均獲利—成功交易的平均獲利金額。

+   14. 平均虧損—失敗交易的平均虧損金額。
