# 第 12 章

# 沈著穩重的交易者

> 不顧一切追求、執著於某種快樂者，終將摧毀快樂。隨緣享受快樂而不勉強者，將永遠享有快樂。

— *William Blake*

交易者絕對不能抱持著死板的信念。雖然初學者經常展現極具破壞性的偏頗，譬如：過早獲利了結、讓虧損持續發展…等，但即使是老練的交易者，也可以藉由糾正某些偏頗而提升續效。舉例來說，有經驗的交易者雖然知道他們不該偏多或偏空，但每當調整交易模型或風險管理方法時，這方面的彈性往往就喪失了。本章準備探討很多心理、身體方面的工具與技巧，包括：冥想、觀想與研究，藉以協助交易者緩和情緒，促進創造力，克服各種交易上的偏頗。
