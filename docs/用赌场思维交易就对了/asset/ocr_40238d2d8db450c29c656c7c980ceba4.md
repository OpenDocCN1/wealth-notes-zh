# 反轉案例：CME 小麥期貨

關於預先猜測市場走勢，最常見的情況之一，就是預測趨勢反轉。這種情況之所以發生，主要是因為多數人都習慣以價格爲交易對象，而不是價值。當價格創新高價時，我們就會開始盤算，如果行情拉回到上個月的某個價位，將可以賺多少錢。相較於在新高價買進而期待價格邁入海闊天空的領域，預期價格回檔而拉回到上個月的價格區域，恐怕更切合實際、更明智一些。因此，我們會猜測行情將拉回而在新高價放空，結果只能在更高價位認賠回補。
