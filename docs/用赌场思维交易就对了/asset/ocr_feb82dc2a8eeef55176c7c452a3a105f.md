# 問：你的績效紀錄是實際發生的，還是假設性的？

本章稍後會提供一份完整的交易日誌範本，協助各位記錄交易績效資料。很多初學者與進階者認爲，正值期望報酬模型的歷史測試紀錄，可以取代實際交易結果。撇開執行上可能出現的錯誤（以及其他操作上的問題）之外，我們還必須考慮實際交易時的流動性風險，而且在某些情況下（譬如遭遇連續虧損），交易者未必能夠嚴恪遵循紀律（一般來說，只有老練的交易者才能在遭逢連續虧損時，繼續堅持既有的正值期望報酬模型。相關討論請參考本書第 6 章）。

# 問：目前交易哪些資產？

這個問題促使交易者考慮相關資產的價格波動程度、部位規模議題、流動性風險，以及各種資產之間的價格相關程度（correlations）。

# 問：交易特別順利或不順利的期間，是否會影響正常的交易頻率？

關於這個問題，初學者要考慮報復性交易的問題，較有經驗的交易者則要考慮交易系統如何受到多頭與空頭市場影響，或受到價格波動循環的影響。
