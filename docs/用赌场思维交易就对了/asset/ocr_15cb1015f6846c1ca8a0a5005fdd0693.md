# 持續變動

「變動」是金融市場的另一項特質。價格的下個跳動雖然是不確定的，但不確定並不同於隨機。如果市場行為真是隨機的，那麼價格就會呈現鐘鈴狀常態分配。可是，實際分配卻有著高耸的峰位，以及肥厚的尾部（如同本書第 1 章所談到的），所以這種不確定、持續變動的市況，提供了高勝算 - 低風險的機會。沒錯，我們雖然不確定價格波動是否會由穩定轉變為劇烈波動（反之亦然），但我们仍然能夠藉由正值期望報酬模型，運用這種價格波動循環性質（細節請參考第 4 章）。

遭逢連續虧損時，交易者通常會覺得喪氣，自言自語道，「他們把我搞慘了」、「我實在禁不起另一次虧損」、「交易簡直是不可能的」、「沒有人可以在這些市場裡賺錢」、「連續虧損永遠不會停止」…… 一旦落入這種負面的惡性情緒循環裡，我建議各位深呼吸，平靜地問自己一些問題：「我的交易方法是否具備正值期望報酬？」「我是否妥善管理風險？」這些問題的答案如果是否定的，就應該停止交易，直到你能重新發展正值期望報酬模型、穩定管理風險為止。

反之，如果前述兩個問題的答案是肯定的，那麼交易者就應該強化下列概念，直到能夠重拾賭場典範、客觀看待市場為止。「市場行為是多層面的、不確定的、持續變動的。我採用一套穩健的正值期望報酬模型，而且隨時都做好妥當的風險管
