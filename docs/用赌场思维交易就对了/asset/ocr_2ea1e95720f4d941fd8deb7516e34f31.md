# 破壞性情緒

> 自大帶來毀滅，傲慢帶來滅亡--舊約箴言

根據佛學的說法，煩惱魔這個障礙製造者會展現六種不同的破壞性情緒。這六種情緒分別為：傲慢（pride，慢）、嫉妒（jealousy，疑）、執著（attachment）、愚昧（ignorance，癡），貪婪（greed，貪）與厭惡（aversion，瞋）。傲慢是指我們的優越感；嫉妒是來自於我們希望擁有其他人的東西或素質；執著來自於害怕變動，恐懼喪失；愚昧來自於偏見與妄想；貪婪是因為我們想擁有更多；厭惡源自於對於外界的敵意。

+   1. 傲慢：傲慢讓交易者不願迅認賠，即使種種證據顯示趨勢已反轉，仍然不願獲利了結。如果我們擔心別人對自己的評價，就會妨礙我們當下採取正確的行動，再也不能客觀體認市場多層面的、不確定的、持續變動的行為。

**正確作法：不理會他人可能的想法，立即自我調適，面對目前客觀的市況。**

+   2. 嫉妒：嫉妒情緒會讓別人的行爲（更好的進場或出場價格）影響我們的操作。務必記住，永遠都有某些人，他們的買進價格會比我們低，賣出價格比我們高。問題是：我們是否允許這種無可避免的現實影響我們的
