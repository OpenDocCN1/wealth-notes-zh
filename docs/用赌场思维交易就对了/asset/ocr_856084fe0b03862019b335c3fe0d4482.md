# 問：是否自行發展交易模型？

交易模型如果不是自己設計的，是否屬於黑盒子系統？對於黑盒子系統，我個人持著保留的態度。不論多麼穩健的系統，遲早都會碰上連續虧損的問題。以黑盒子系統來說，一旦遭遇連續虧損，我們根本不知道究竟是甚麼原因造成的，因此很容易就會喪失信心。
