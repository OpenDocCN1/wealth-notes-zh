位）。這些欄位包括：

+   1. 資產 — 也就是交易對象，期貨必須註明合約的年份與月份（如果是選擇權，必須註明買權或賣權，以及履約價格）。

+   2. 部位 — 註明多頭或空頭部位。原則上，交易方法不該偏多或偏空，但順勢操作應該在多頭市場建立多頭部位，在空頭市場建立空頭部位。

+   3. 進場日期 — 我建議採用經紀商截記的時間和日期（而不是交易者所屬時區的時間）。

+   4. 進場時間 — 部位持有時間愈短，進、出場時間資料愈重要。搶帽子與當日沖銷交易，可以根據交易執行時間分析績效與成功機率。對於波段交易者來說，第 4 欄與第 8 欄資料還是值得參考的，雖然這對於較長期部位的幫助不大。

+   5. 成交量 — 成交股數或契約口數。留意某些資產成交量資料顯示的偏頻、多空偏頻等。

+   6. 進場價格 — 如果有兩個或以上的進場價格，記住要計算平均價格。

+   7. 出場日期 — 原則上，成功交易的部位持有時間，通常會超過失敗交易的持有時間。

+   8. 出場時間 — 參考第 4 欄。
