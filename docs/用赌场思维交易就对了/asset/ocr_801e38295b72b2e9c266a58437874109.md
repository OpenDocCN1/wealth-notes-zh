# 股票交易模型

全球金融交易普遍採用電子平台，使得佣金費率下降，市場流動性顯著提升。可是，公開叫價制度消失，也造成開盤突破與跳空缺口這兩種過去有效的正值期望報酬交易模型不復可行（註 29）。
