+   2. 交易筆數（Number of trades，簡稱 # Trade）是指整個歷史測試期間所進行的交易筆數。對於長期順勢系統來說，我們希望在不妨礙續效的前提下，這項數據愈低愈好。

+   3. 天數（Number of days，簡稱 # Days）是指交易持有期間的平均天數。如同交易筆數一樣，假定其他條件相同，天數愈小愈好。

+   4. 最大耗損（Maximum drawdown amount，簡稱 Max Draw）是指交易帳戶淨值由峰位到谷底之間的耗損金額。

+   5. 最多連續虧損筆數（Maximum consecutive losses，簡稱 MCL）是指歷史測試期間曾經發生過的最多連續虧損筆數。

+   6. 總淨利對最大耗損比率（Profit to maximum drawdown ratio，簡稱 P:MD）是指總淨利與淨值最大耗損之間的比率。這項比率值當然是愈大愈好。這可能是最具參考價值的基準數據，因為這讓我們得以瞭解整個歷史測試期間所達成的獲利，以及達成該獲利所承擔的風險。

+   7. 勝率（Percent winner，簡稱 %W）是指成功交易筆數佔總交易筆數的比率。前文曾經談過，順勢系統的勝率通常較低，回歸均值系統的勝率通常較高。
