# 關於操作方法

下列有關操作方法的問卷，主要目的是協助各位糾正非理性的交易偏頗。另外，我們也希望協助讀者有系統地評估既有方法的優點和缺點，持續做修正，讓交易系統變得更穩健。

> 問：你如何敘述所採用的各種方法？

這個問題協助交易者把相關方法做分類：系統性 / 主觀判斷、順勢 / 逆勢、技術分析 / 基本分析等。各位的回答應該儘可能周詳。舉例來說，假定你使用一套以技術分析為主體的系統性逆勢系統，交易訊號是否允許被主觀判斷否決？若是如此，主觀否決被引發的條件是根據什麼：價格波動程度、價格相關、其他風險管理考量、或是基本分析（譬如新聞相關的風險事件）？

> 問：所採用的方法，是否永遠在市場中持有部位？是否允許空手？如果允許空手，這種狀況大約佔多少百分比？

交易系統如果永遠持有部位，帳戶淨值耗損通常較嚴重，勝率也較差。允許保持空手的系統，可能有幾個星期或幾個月完全退場觀望。交易系統持有部位的時間如果不夠長，就需要多交易幾種資產，如此才能確保穩定的績效。
