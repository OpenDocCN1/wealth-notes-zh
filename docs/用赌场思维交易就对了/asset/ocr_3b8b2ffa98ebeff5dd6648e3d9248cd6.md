# 結語

在進一步討論價格風險管理的議題之前，我想再跟大家分享我個人的交易經驗與多年研究心得。

我們稍早曾經說過，成功的投機活動需要做一些令人覺得不舒服、不自然的事情。就本章討論的內容而言，最重要的就是：儘快結束失敗部位。換言之，務必要保持「大贏」或「小輸」的局面。我經常告誡學員們：「任何白癡都懂得獲利了結，但只有真正的專業玩家才知道如何認賠。」原則上，交易者應該儘快判定部位失敗而認賠。當然，這不是說你應該盲目砍掉任何稍有虧損的部位，目的只是爲了證明自己具有認賠的能力。我想要強調的是，如果能夠愈快判斷部位已經失敗，交易成功的機會就愈高。

最後，我經常看到交易者把「冒險態度」跟「英雄氣慨」、「專業特技」等概念相提並論，甚至還有其他種種不合理的聯想。沒錯，金融交易往往需要行險，但有必要因此而葬身市場嗎？風險管理是容不得開玩笑的，也沒有後悔的空間。風險管理只要出差錯，一切可能就結束了；所以，這絕對不是表演英雄氣慨或炫耀膽量的場合。套用著名避險基金經理人拉利·亥特（Larry Hite）說的話：「不下注，就不可能贏。但如果輸掉所有的籌碼，你就不能下注了 $ ^{\text {〔註 } 14\text {〕}} $ 。」

（註 14）請參考 Jack Schwager 的《金融怪傑》（Market Wizards, Marketplace Books, 2006，寰宇出版，F015/F016），第 189 頁。
