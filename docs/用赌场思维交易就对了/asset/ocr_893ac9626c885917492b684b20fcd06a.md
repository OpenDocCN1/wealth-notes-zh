# 停損

停損設定是最簡單、也是最重要的風險管理方法之一。事實上，「停損」是其他結構更複雜之風險管理工具的基礎。可是，停損究竟有何重要呢？停損單上設定的價格一旦被觸及，該停損單立即成為市價單。所以，建立部位當時，交易者如果同時或隨後立即設定該部位的停損，則必須事先明確估算風險。請注意，建立部位當時或稍後立即設定停損，能讓風險管理得以保持客觀立場，完全根據明確的法則設定，不至於受到行情波動引發的貪婪或恐懼情緒影響。停損單沒有討價還價的餘地。停損單不需要懂供需狀況、氣候型態或國際情勢。停損單只需要懂得根據預定條件結束部位即可；因此，一旦停損單遭到引發，交易部位就會被迫結束。

如果回顧過去的價格走勢，初學交易者往往會覺得信心滿滿，相信自己能夠賺錢。在價格走勢圖上，他們往左尋找過去的價格低點，然後往右尋找價格高點；只要在最低價買進，然後在最高價賣出，就能賺進無數的財富。他們往往忽略了買點與賣點之間可能發生的市況。
