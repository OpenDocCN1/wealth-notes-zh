+   9. 出場價格－如果採用第6章的分批出場方法，請按照數量加權計算出單一出場價格。

+   10. 盈虧毛額－這是扣減佣金成本之前的盈虧金額。

+   11. 現金進出－登錄存入交易帳戶、或由帳戶提領的現金。

+   12. 佣金－除非是搶帽子或當日沖銷，否則佣金佔盈虧毛額（第10項）的比率應該不大。

+   13. 盈虧淨額－這是扣減佣金成本之後的盈虧金額。

+   14. 天數－這是部位持有天數。一般來說，成功部位持有的天數，通常會多過失敗部位。

+   15. MTM耗損－此數據代表該月份之內，帳戶淨值由峰位到谷底的最大耗損。一般來說，這個數據佔帳戶總資產的百分率不應該超過5%。此項百分率如果超過10%，就代表有問題；百分率如果超過20%，就應該關閉帳戶。

+   16. 成功交易－如果採用第6章建議的減緩懊悔情緒的技巧，此欄要登錄成功交易百分率。

+   17. 失敗交易－失敗交易筆數可能超過成功交易筆數，但失敗交易的平均虧損數據應該顯著較小（長期順勢交易系統尤其會有這種現象）。

+   18. 獲利－此欄登錄獲利金額。
