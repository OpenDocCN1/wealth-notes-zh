# 有钱人字典里没有“不可能”

> “在我的字典里，没有‘不可能’的字眼。”

著名的成功学家拿破仑·希尔，年轻的时候胸怀当作家的雄心。
要达到这个目标，他知道自己必须精于遣词造句，字词将是他的工具。
当时他家里很穷，不可能接受完整的教育，因此，很多朋友好心劝他，
放弃“不可能”实现的雄心。

年轻的希尔存钱买了一本最好的、最完全的、最漂亮的字典，但
是他首先做了一件奇特的事——找到“不可能”这个词，用小剪刀把
它剪下来，然后丢掉。于是，他有了一本没有“不可能”的字典。他
告诉自己，没有任何事情是不可能的。

为它寻找借口，把这个词永远地抹杀，而用光辉灿烂的“可能”来替
代它。
