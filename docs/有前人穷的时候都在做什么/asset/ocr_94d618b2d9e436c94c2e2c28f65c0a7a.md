# 你挖的是金矿还是土矿？

古话说，“只要功夫深，铁杵磨成针”；但是今人又告诉我们，“选择比努力更重要”。财富是人生圆满的一个重要指标，如果现在你正走在追求和创造财富的路上，假如你现在正在从事的事业是寻找矿藏，那么它是黄土矿，还是金矿呢？
