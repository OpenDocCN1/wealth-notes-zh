# 财富加速方程式

自然界中关于“加速度定律”，由于是牛顿发现后用数学方法表示出来的，所以叫“牛顿第二定律”。这个定律可以用简单的数学公式表示：

F（力）=m（质量）× a（加速度）

我一直在问自己：这世间如果真的存在一则财富增长的定律的话，该怎么用公式表示？经过不懈探索，我最终得出了如下结论，其数学公式如下：

财富 = 对钱需求的迫切程度 × 复利 × 时间²

我把这个公式称为“财富方程式”，也就是我一直探索的财富定律。

其实，世上并不存在成为有钱人的绝对定律。而且，我也不能提供推导出这个公式的具体数据。不过，这个公式里面确实包含着能够让财富增值的原理。
