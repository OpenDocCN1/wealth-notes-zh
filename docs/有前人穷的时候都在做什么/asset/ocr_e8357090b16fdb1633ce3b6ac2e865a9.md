# 戴尔·拉姆齐

《纽约时报》畅销书作者、全美广播脱口秀节目主持人

克里斯特尔·佩因身兼多职，既是企业家、妻子，同时还是一位母亲，这一切让这本书在理性中充满感性。总之，《有钱人穷的时候都在做什么》一书将帮助你改变金钱观、学会赚钱，并让你获得一种重新掌控生活的感觉。

# 安·沃兹坎普

《纽约时报》畅销书《一千份礼物》作者

这本《有钱人穷的时候都在做什么》不仅能够启发读者，而且还提供了切实可行、有创造力的方法来帮助你改变对金钱的思考方式。至于本书第 6 章中关于创业的内容，值得大家起立鼓掌。
