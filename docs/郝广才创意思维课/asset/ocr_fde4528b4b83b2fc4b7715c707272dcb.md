# 利用游戏，提高储蓄率

先来看一个真实的案例：

在美国，有一家叫 Long Game 的，是一个科技金融公司。

这家公司调查后发现，美国的中产阶级普遍没有储蓄，70%的人，储蓄少于1000美金，储蓄率非常低。

而且美国忽然变成M型社会，也就是有钱人和穷人的多，但是中间阶级失去了竞争力，沦落为穷人。

要知道，中产阶级普遍没有储蓄基金，风险来临的时候，自然没有多余的资金来缓冲。

那么怎么增加大家的储蓄呢？

Long Game 根据我行合作，想了一个非常巧妙的办法，把钱跟游戏，游戏化，结合在了一起。

为什么会想到这种方案呢？

> 原来，Long Game 在调查中发现，美国的福利彩票，它每年的总营收高达700亿美金。相当于平均每个家庭，每年要花540美金来买彩票。

你看，美国人可以花500美金买彩票，但储蓄却不到1000美金。如果把钱拿去储蓄，不就负担500美金的额外支出了吗？

所以，Long Game 就也想，可不可以做一款游戏，让人们可以一边存钱，一边玩，偶尔还可以得到现金奖励。

于是，Long Game和银行合作，开发了一款手机应用程序。

他的方法很简单，打开 Long Game App，你每次最少存入的钱是5美金，最多可以存5000块。

存钱后，系统会给你一个虚拟的金币，有了这个金币，你就可以去玩App上的小游戏。

要是没有存钱，你就得不到游戏的虚拟金币。

虚拟金币是根据你的存钱金额来决定，存得越多，虚拟金币也越多，这个金币不能直接兑换现金，但是偶尔会给你现金奖励。

所以，大部分人存钱是为了得到这个金币，好来玩好玩的游戏，玩游戏的同时，偶尔还会有现金奖励，这种设计，就是让你玩游戏的时候，感觉很快乐，有点像免费彩票一样。
