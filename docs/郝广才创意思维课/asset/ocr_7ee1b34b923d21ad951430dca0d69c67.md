# **16 | 软化术：如何打破思维僵局？**

你好，我是都广才，欢迎来到我的创意思维课。

前一讲我们讲了新定义术，就是创意一定要发明新东西，新的观念会产生新的意义，新的定义会带来新的改变。

这一讲，我要跟你讲的产生创意的方法是软化技术。

什么是软化？就是讲的角度，正化和反之之外，我们要找到一个有趣的角度，来软化原来僵化的思维，让它变得灵活。这样一来，原来在陷入僵局的时候，就更容易打破。

# 拯救美国牛奶业的软化术

为了方便你理解，我们先从一个真实的案例说起。

上世纪八十年代，美国的牛奶销量大量下滑。

为什么会这样？

因为当时以可乐为代表的软饮料，各省奇招，挖空心思宣传，抢占了大部分市场。

而且，”牛奶“的年轻人不被贴上“伟宝宝”的标签，所以年轻人都不爱喝牛奶。

这样一条，奶农就急了，因为新鲜牛奶不好存，当天没卖掉，它就不新鲜了。

面对困境，奶农协会和政府想尽了各种办法，花了很去多败广告，找各种人来拼命宣传喝牛奶的好处，但是，不见任何起色。

直到后来，他们找来一个叫杰克·曼宁的人，由他操刀设计了一系列的广告。结果，牛奶的销量就开始创增。

为什么会这样？因为曼宁设计这一系列广告的时候，找到了一个有意思的角度。

我们都知道，做广告宣传，一般有两个思路：正面鼓励和负面恐吓。

拿推销牛奶这件事来说，正面鼓励的方式就是告诉别人，喝牛奶有诸多健康，你可以补充各种有益的元素呢等等；负面恐吓的方式，可以是，不喝牛奶，你会缺钙之类。

但是，这两类宣传方式，基本都不管用。

因为牛奶的形象已经很正很满了，所以广告重点不是加强牛奶的形象，而是要加强消费者的行为。

而负面的恐吓，对不喝牛奶的人也没作用，因为他本来就不在乎，如果在意早就有喝牛奶的习惯。

所以，在正面与负面之外，我们要缓解一下张力，找到一个有趣面来软化一下。
