# 15 | 再定义术：如何让旧事重现生机？

你好，我是郝广才，欢迎来到我的创意思维课。

上一讲，我们介绍了空缺填补术，知道了在旧的事物里寻找空隙，可以发现有各种创新机会，这一次，我要再介绍一个新生的产品创意的方法——再定义术。

2007年，乔布斯在iPhone发布会上说，苹果重新发明了手机。当时苹果破天荒地把iPod、电话、上网通讯设备集合成为一台设备，从此开创了一个新的智能时代。

苹果的这种颠覆式创新，一直被津津乐道，很多人说他们模仿不来，说自己重新发明了电视、电吹风、汽车等。

这种氛围，有让你过得很舒服，要抓住机会，一定要发明个新东西，做些颠覆性的事情出来？

其实，创意一定不是发明新东西，甚至用什么也不用改，只需要改变自己的眼光看，用新的眼光去看事情，旧的一切都会有新的变化。

# 相同的事情，不同的定义

什么意思呢？我们先来看一个葛亚书店的例子。

葛亚书店是日本的一家传奇书店，它的社长增田宗昭在1983年刚创业时，手头资金不够，所以想跟银行借钱，但银行觉得他的商业模式不好，赚不到钱，不肯贷款给他。

银行为什么要这么认为呢？

原来，葛亚书店有一个业务是在书店里做DVD租借的，当时日本的DVD租赁商是另一家大公司，而增田宗昭采用的是租借模式，一张DVD可以30元租借15天，但租金只要600日元。

所以银行说，这根本赚不到钱，DVD是用户买了就要看的，而租金只要600日元，租一次也就50元，根本不够成本，这种模式没有前途。

但增田对银行说，这不是租金，DVD片500日元，现在他租了15日，可以再用30次，每天只要50日元，这比买一张DVD划算，这是新的消费模式。

银行听了觉得有些道理，但增田又说，我不仅租碟片，还提供电影周边、DVD、书等周边商品的销售，这是把娱乐、文化、销售结合在一起的商业模式。

银行最后被增田的“再定义”打动了，葛亚书店拿到了贷款，从此开始快速发展。

其实，这件事最本质的变化，不是商品或服务，而是“定义”的变化，这就是“再定义术”。

再定义术，就是重新审视旧事物，用新的框架、新的视角去定义它，从而发掘新的价值、新的机会。
