# 01 | 创意的生成原理

你好，欢迎来到我的创意思维课，我是郝广才。

谈到创意，你眼前会浮现出什么画面？灯泡一亮，灵感降临？

很多人认为，创意的来临不可捉摸，非常神秘。产生创意，主要靠天才挥洒，灵感焕发。

我，相信创意的来临，当然以“灵光一闪”的方式出现，但它有一定的生成方法，而且可以“量产”。我的这门课，就是要帮你找到这个量产的方法。

# 什么是创意？

要找到量产的方法，先弄清楚创意是什么。

为了方便你理解，我们从问题来切入：

当你被钓鱼鱼吞大钩，你会怎么办？

奋力挣扎，杀尽鱼群打鳄鱼？不仅没用，鳄鱼还会吃得更欢。

那有效的办法是什么？

不妨来看一个十岁的小女孩是怎么做的：

2017年，美国一个叫朱莉安娜·奥斯（Juliana Ossa）的小女孩，被一条短吻鳄叼住，鳄鱼张着大嘴，把她拖向水中，她试图抓住鳄鱼的背鳍。鳄鱼无法挣脱，只能拖着她往深水区去。媒体狂赞小女孩冷静、勇敢，而且极具创意。

那创意是什么？
