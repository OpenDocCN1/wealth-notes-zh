# # 03 如何让头脑风暴更有效？

你好，我是郝广才，欢迎来到我的创意思维课。

第一模块最后一讲，我要给你介绍一个产生创意的重要方法——头脑风暴。

提起头脑风暴，相信很多人已经耳熟能详了，一些公司如组织在设计产品的任务时，还会经常组织会议，把大家召集在一起，进行头脑风暴。

但是，在我看来，头脑风暴没有你想的那么简单。

如果说得好，它不仅不会杀死你的创意，甚至还会浪费时间、扼杀创意。

为了说明这一点，我们先回到头脑风暴的源头，看看它到底是这么一回事情。

# ## 头脑风暴的诞生

头脑风暴法是美国着名创意大师亚历斯·奥斯本（Alex Osborn）在1939年提出的方法，奥斯本是着名的广告公司BBDO的创始人，BBDO的Q就是他创的炒鸡蛋。

1938年，BBDO公司出现危机，流失了很多重要客户和员工。奥斯本为了挽救公司，想出一套全新“创意”的研发流程，希望利用团队合作、结合业务、文案、设计，这些不同角色的人员，合力发展出更强、更多的创意。

在公司内部不断地进行实验后，1942年，奥斯本在《思考的方法》这本书中，第一次公开提出了“头脑风暴”的概念，并提出了关于头脑风暴会的四个原则：

第一个原则：禁止批评。在开会的时候，所有成员自由发想，相互之间不能批评。

第二个原则：独特性。所有成员都追求无限制地生成想法、轻松保持自由。点子越新奇，越能激发独特想象。

第三个原则：量重于质，也就是数量比质量重要，开会的时候，围绕主题，发散出抽象的点子，拼凑大量点子。数量越多，好点子出现的机会越大。

第四个原则：结合改善。一加一大于二，多个点子结合可以变成更棒的创意。

另外，在头脑风暴会议时，还要注意七个步骤：

1. 确定具体的主题。如果大会的主题是“避免交通事故”，想不出有效的解决方案时，就改为“让车能安安全全”，进一步把主题具体化，就会好点。

2. 桌子排列成三角形。成员围坐成三角形，如此发表意见时，每个人的眼神容易交会。

3. 主持人要带动讨论。主持人要掌握气氛，帮助每个人从不同角度思考，鼓励大家热烈参与。

4. 聚集各种领域人才。参加头脑风暴的人数，理想为5~8人，如果成员有与主题相关的专家，最好有9人参加。越多不同领域的人才，对生产点子越有利。

5. 自由发想，详细记录。记录时不可简化、压缩，要逐字记录。卡片备忘录都是解决问题的线索。

6. 休息。会议进行到一度落，可以让大家休息后再讨论。理想的休息时间可控制在十分钟左右。休息时可以读网页，从宏观角度思考别人的点子。

7. 评估，以“独创性”与“实现性”为主，评估所有点子的可行性。尝试结合不同点子，提升点子的可行动性。

奥斯本宣称“头脑风暴”神效十足，像美国财政部那么一块一毛的机构，利用这个方法，居然在四十分钟，想出103个销售储蓄债券的方案。

他还成立了一个“创意教育基金会”（Creative Education Foundation），专门教导公司、团体、个人如何运用头脑风暴。

许多大型企业，比如IBM、杜邦公司，甚至美国政府机关都采用他的方法，作为内部会议的准则。

头脑风暴从此变成专有名词，成为无数人眼里，用来突破瓶颈、激发创意的方法。

# ## 头脑风暴是创造的神奇钥匙吗？

但是，头脑风暴真的这么有效吗？

美国明尼苏达大学的研究人员，做了一个测试。

这个测试的参与者是3M公司的研发人员和广告创意者。研究人员将受试者分成了两半，一半受试者4人一组，另外一半个人独立作业。

得出一组结果，再把其他人重新分组，也是4人一组，过程中如果有重复的创意，只能计算一次，后面的不算。

结果发现，每一个问题，个人产生的创意比团体多出30%-40%，质量也较高。

在另一项研究中，研究人员将168人分成5人、7人、9人一组，以及和多人相对应的大型小组。结果一看，小型参与表现比组创意多，品质高，而且组员人越多，表现越差。

也就是说，团体头脑风暴对创意思考不但没有帮助，还会造成限制。

为什么头脑风暴会失败？

是头脑风暴这个方法有问题，还是使用这个方法的组员有问题，操作不当？

为了弄清这原因，美国印第安纳大学针对头脑风暴最大的禁忌“禁止批评”，做了一次实验：

研究人员找来一群学生为三个不同产品开会命名。一半学生要求讨论过程不能有任何批判，另一半则可以自由批判。

结果不能批判组果然点子比较多，但其实烂点子更多，基本上同质量的点子，两边差不多，测不出差别。

那么，“禁止批评”也不能提高点子的质量，那问题出现在哪里呢？

答案是：开会。

头脑风暴会议，不仅不会带来我们期待的创意，反而会造成“生产力损耗”（Productivity Loss）。

为什么会这样？因为会议让人对创意的看法变得越来越一致。会议会强化相同的意见，支持创意，反对创意则相互碰撞。

你想想看，一群人坐在一起思考，这时，有人提出了一个想法，这个想法就会影响到每个人记忆。

要知道，我们的大脑跟其他设备一样，好处是，能够产生想法。现在在人人提出了点子，我们就围着这个点子打转转，不必努力想到不同的点子。

但是当一个人独立思考的时候，我们的大脑就不会受到别人的影响，就会产生各种不同的想法。

所以说，会议会让大家对问题的看法，变得越来越一致。

此外，人是群居动物，我们喜欢意见一致，太多人看法相同，安全感就极高。

所以，会议不会产生创意大师，而是会产生平庸者。

而领导者是什么做呢？

领导者就是能影响他人的人，让大家跟着走，这样不仅不会产生更多不同的想法，反而会形成一个固定的思考。

你看，这不是刚好跟头脑风暴的原意相反？

而且，你喜欢提问，领导者一般倾向于不确定，喜欢快速决定，促进所有人达成一致共识，马上行动。这就意味着在会议上，不可能达成头脑风暴想要要的、平等、自由的效果。

所以，说，开会让头脑风暴失效，变得不太管用。
