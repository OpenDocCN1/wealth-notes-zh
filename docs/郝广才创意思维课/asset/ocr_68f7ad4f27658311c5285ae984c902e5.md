# 相关联想法

联想法分两块，一个是相关联想法，另一个是随机联想法。

相关联想法，顾名思义，就是把两个原本没有关联的事物联结起来。比如，给铅笔加橡皮，或者给耳机加音乐。只要通过联结思考，产生的点子就会有创意。

那么，相关联想法具体怎么操作呢？

一共有五个步骤，为了便于你理解，下面我就通过具体的案例，一步一步地为你讲解。

第一个步骤：列出要解决的核心问题。

比如说，我们想在姜为一个汽车轮胎制造一个创意的点子，重点是强调这个轮胎的抓地力。所以，抓地力就是我们在构思创意时，要解决的核心问题。

第二个步骤：想出一系与核心问题直接相关的字词，系统地列出来。

这些字词，特别重要，它们是我们创意灵感的催化剂。

回到刚才那个例子，我们要系统化地列出与汽车、轮胎、抓地力相关的字词，列举的时候，要不断地问自己：还有呢？每个词，至少找出六个相关的字词，并写在同一张纸上。

比如和汽车相关的字词有：

+   - 驾驶，车灯，方向盘，安全带，仪表盘，音响。

和轮胎相关的字词有：

+   - 橡胶，轮胎，轮子，轮圈，胎面，金属。

和抓地力相关的字词有：

+   - 胶水，磁铁，吸尘，马桶刷子，胶带，马蹬。

要特别提醒你的是，这些相关的字词，你一定要写出来，这样你的脑子才不会搞混。

刚才说的是相关联想的第二个步骤，列出和主题相关的字词。

第三个步骤，在刚才列出的表格中，把各个不同的元素画成图，并且互相联结。

这里有一个小技巧，你可以在字词本身的含义、利益、功能、形状、颜色、发音之间，找到潜在的联结。

比如，在刚才的字词图中，我们可以看到，轮胎、喇叭和字圆圈起来，联结在一起。为了避免看起来显得混乱，你可以用大一点的纸来做这一步工作。
