# 模块设置·这门课会怎么对你讲？

这门课的四个模块，对应着四项创造力的重要修炼：

+   1. 生成原理：帮你掌握创意产生的奥秘，避开创意思考的陷阱；

+   2. 产生思路：帮你掌握产生创意10个思路；

+   3. 量产方法：帮你掌握量产创意的9个方法；

+   4. 传播法则：帮你掌握传播创意的11条法则。

需要提醒你的是：创意没有固定的思维模式，所有的方法和套路，都不是孤立存在的。在学习的时候，融会贯通将是你升级创造力的秘密武器。

# 学习环节·这门课该怎么学习？

1.利用好每讲最后的创意训练题

创造力，不是光掌握知识就够的，它是一项技艺，需要你每天训练，才能内化为自己的。

所以，学习这门课程最有效的方法，是把理论与创意实践相结合，每一讲课后的创意训练题，一定要每天独立思考，认真地把你的想法写下来，和大家分享。

2.充分利用辅导课及同学的作业

+   * 辅导课：课程更新期间的每周日，郝广才老师会用户的留言中，挑选一批出来，进行针对性的点评。你可以充分利用点评辅导，发现不足之处，加以改进。

+   * 同学的作业：它山之石，可以攻玉。每天在独立学习、思考之余，在留言区看看其他同学的创意作业，不仅能收获各种创意，还能结识有趣的新朋友。

+   * 提出你的疑问：在课程中，郝广才老师会根据你的反馈，不定时集中回答具有代表性的问题，我们会以加餐文章的形式，更新在课程中，所以千万不要错过机会，多多提出自己的问题。
