开特力，是美国的⼀个⽼牌运动饮料厂商，世界第⼀瓶运动饮料，就是它发明的。后来，这个牌子⽼了，销量⼀直在往下降。

但是在2015年的时候，开特力的销售额，⼀举跃升到56亿美金，在美国的市场占有率达到78%。

开特利是怎么做到起死回⽣的？

就是把注意力聚焦到了运动员⾝上，开发了全新的产品。

开特利在调查的时候发现，运动员在比赛前，⼀般会先补充碳⽔化合物，然后中问会补充⽔和电解质，运动完后，会补充蛋⽩质，来修复肌⾁。

所以，开特⼒把运动饮料刻意拆成了三块：分运动前喝的，运动中喝的，还有运动后喝的。

+   * 运动前喝的饮料，主要成分就是碳⽔化合物，还有维他命B，这可以运运动员有充沛的能量；
* 运动中喝的饮料，主要帮运动员解渴，补充流失的⽔跟电解质；
* 运动后喝的饮料，主要是提供蛋⽩质，来修补受损的肌⾁。

你看，这就是刻意拆开，把原来只有⼀瓶的运动饮料，拆成了运动前、运动中、运动后⼆瓶。不仅方便了运动员，还拯救了开特⼒。

这就是关⽬拆开门我给你条建议：

+   1. 要把多的拆开；
2. 要根据人的极限拆开；
3. 还要去做刻意的拆开。

那有了这些⽅法，还有什么要注意的吗？你要运⽤自如，要可拆开，也可组合。

我再⼊给你举个典型的例⼦，就是伦敦奥运。

伦敦奥运办得很成功，不只是各⽅⾯都办得好，最重要的是主办单位没有赔钱。像希腊办个奥运，国家都快⾯⾯⾯了。伦敦奥运就⽤了这个组合，拆开门。

比如说它的主场⽩，在奥运会期间可以容纳8万⼈，但它其实是⽤可以拆开的工具搭出来的。所以，奥运会结束后，不再需要容纳那么多⼈的场馆，主⽅就可以把它拆掉，剩下容纳2万5千⼈的空间，平常使⽤就足够了。

再比如，沙滩排球的比赛场地就在⾦⽩宫旁边，把骑兵队的草地铺成沙池，打完奥运比赛，就可以拆掉了。

所以，伦敦奥运这样的设置，没有留下不能拆掉的空间资产，其他国家⽤奥运，建造了⼀些大型的、不能拆除的建筑物，最后变成财政上的重⼤负担。伦敦奥运则很简单，⽽且还能赚得。

所以，想要拥有组合拆开的创意思维，你必须想象自⼰是⼀列火车，各个车厢可以随时拆开、组合。这样，你就会运⽤自如。
