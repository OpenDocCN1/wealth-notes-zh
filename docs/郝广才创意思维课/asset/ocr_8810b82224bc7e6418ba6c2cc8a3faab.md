# # 13 | 最渴望联结点：如何制定有效的宣传方案？

你好，我是郝广才，欢迎来到我的创意思维课。

上一讲，我们讲解了相关联想法和随机联想法这一讲，我要给你讲一个我的独门方法——最渴望联结点。

你有没有想过这样一个问题：

> > 为什么流行音乐能如此风靡？

可能有很多因素，比如音乐本身的律动好听，唱片公司在营销上费了很大力气，歌手是俊男美女等等。

但是，流行音乐之所以流行，其中最重要的原因，在于它的歌词。分析所有畅销歌曲的词，你会发现，这些流行歌曲中80%的歌词都跟爱情有关。

不论歌手是男是女，是什幺个性，不论是哪种音乐类型，情歌比其他任何主题的曲也更容易受到欢迎。

因为大多数音乐相关产品的族群就是那些恋爱中，失恋中或想恋爱的年轻人，这些音乐的内容只是用了爱情主题和它们的听众联系起来。

所以你想要歌曲卖，请情歌就对了；要让自己受欢迎，就要唱那些听众觉得重要的主题。

从这个发现中，我们学到了什幺？

> > 爱情比音乐重要！如果他们将洗发水做广告，就要和标星牌比，说他们能将泡沫发水更重要的事，你要找出那些重要事物和目标人群连接起来，用创意将这些重要的事物和人的产品连接起来。

这就是“最渴望联结点”这个工具最要帮你做到的。

它可以帮助了解你心里在想什幺，并将你的产品和服务，跟他们渴望的东西建立联结。

# ## 制造最大惊喜的最渴望联结点

那么，具体如何操作呢？

为了让你理解，我通过一个案例，来具体讲解它的用法方法。

假设我们现在要卖一个顶级的家庭影院音响系统，这个音响的售价是20万人民币。那么，如何使用最渴望联结点，制定一个推广计划呢？

一共有五个步骤：

**第一步：确定目标用户，也就是你的宣传方案要跟谁来沟通。**

在这个案例中，愿意花20万人民币买顶级音响的人，一般是很有钱，已经成立事业的中年男人，他们渴望在家里听音乐设计的感觉上，尽情欣赏最有临场感的音乐、观看动感逼真的画面。

**第二步：把目标用户最感兴趣的东西找出来，写在一张清单上。**

比如，我们刚才说的有钱的中年男人，他们会什幺事物感兴趣？

+   * 可能是名贵的家具、经典名表、高品质的海岛游、五丈酒店的住宿、敞篷跑车、创新公司、艺术家、电影、夜总会、顶级超级杯、俱乐部会士卡、定制西服、高尔夫球、米其林餐厅、歌剧、音乐会等等。

将这些目标对象感兴趣的事物，找出20到30个。

**第三步：精剪列出的清单，去掉所有和产品相关的项目。**

比如在电影、体育项目、歌剧、音乐会等，因为这些和家庭影院音响之间有直接或间接的关系。

我在前面创意的基本原则组合的时候提到过，越差别大，距离越远越有创意。越起来就有越多的，让我们要制造惊喜，所以要去掉那些相关的项目。
