# 14 | 空隙填补术：如何寻找市场空白？

你好，我是那广才，欢迎来到我的创意思维课。

上一讲，我跟你讲了最强联想技术，它能帮你量产各种营销上的创意。

这一讲，我要向你介绍的方法是空隙填补术，它能帮助你识别市场，发现各种创新机会。

什么是空隙？举个打球的例子，你就明白了。

伟大的球员，不管是打篮球，还是踢足球，都有一个明显的特点：就是虽然打法不同，但是都具备着发现空隙的能力。他们会找到空档切入，进球得分。

即使对方是铜墙铁壁，他们也能利用移动，主动创造空隙，进球得分。

所以空隙等于什么？

成功的机会。打球是这样，做产品、想创意也是这样。

可以说，发现和寻找空隙是产生创意的一条捷径。

# 不断创造机会的空隙填补术

为了帮你理解，下面，我就通过一个实际案例，来向你介绍空隙填补术的魅力之处。

在美国，有一家公司，发明了一种新材料，然后，它找到市场上所有的空隙，进行了填补，不但帮助自己腾挪，而且深入所有人的隐私，改变了我们的生活样貌。

这家公司1872年在美国成立，叫金佰利-克拉克（Kimberly-Clark）。它原来是专门生产高品质的书写用纸，像奢华纸。1914年，他们研发出了一种材质像棉的化学纤维，叫“纤维纸”。

刚好，这时第一次世界大战。开口，金佰利公司就把这又便宜又松软吸水、吸水比开普纸的新产品推销给了美国军方，作为开放性伤口的止血敷料。

战争中的成功经验，让金佰利公司瞧准了纤维纸的吸放能力，他们开始在市场上寻找新的空隙：有没有谁，他不打仗，也没有受伤，但是也需要处理出血的问题？

女生，女生每个月都有月经。于是，金佰利公司在1918年的春天，在芝加哥的药店，推出了世界上第一款“女性卫生纸”，给它起名叫做Kotex，也就是我们现在熟悉的“高洁丝”。

你看，纤维纸已经在我发现的东西，但是金佰利公司在医疗止血的材料之外，给它找到了一个新的空隙，从而开辟了一个巨大的市场。

但是，如果说获得满分后，还会继续寻找新的空隙、发现新的得分机会一样，金佰利公司并没有停止寻找下一个空隙。

他们在想，既能纤维纸可以吸血，那可不可以吸血呢？很多妈妈，女孩子在即妆的时候，脸上会有很多溢出来的油。

但是，纤维啊这个问题，它长得皱巴巴，擦在女性细腻的脸上，虽然动能说没什么问题，但手感不好。

于是，金佰利公司拿婴儿来试纤维海绵，这样，皱巴巴的纤维纸，就变成了一张张软又柔软的“面纸”。

可是，薄薄的纤维纸一张太薄，擦在一起，擦不完，然后不好卷。稍微用点力，就会拿起好几次。如果用常规包装，既不好看，也不方便携带和使用。
