# ## 美感法则

先来看美感法则：

通过前面几讲的内容，你已经是清楚，我们在做传播的时候，要考虑人脑的特性。除了自反应、追求简单之外，我们的大脑还有一个重要的特性，就是喜欢美。

比如，当年莎莎波娃和大小威廉姆斯都是职业网坛的顶级选手，但是莎莎波娃总是能出更高的广告分成，收入更高的女网球运动员。

为什么？因为莎莎的基因多。

虽然她不是所有女性中长得最漂亮的，但她是打网球的顶级运动员，长得最漂亮的。广告商在做投资、选择代言人的时候，就会更加倾向于莎莎波娃。

虽然这有点不理性，但人就是这样，天生喜欢和创造美的事物。

所以，在做创意传播的时候，用好美感法则，往往能起到事半功倍的效果。它不仅能够给你带来关注，还能给你信任。

比如劳斯莱斯，它是奢华的代表。虽然性能并没有比它多强多少，但是豪华车，都是手工打造，每个细节，都是精雕细琢，给人的感官带来巨大的美感享受，让人感受到巨大的满足。

再比如网络上的一些诈骗图片，用的都是俊男美女的照片。你知道吗，那些图片并不代表真实的，但还是有人会点击。

为什么？因为美会让人放松，从而更容易产生信赖的感觉。

既然美感法则如此重要，那么具体怎么运用呢？我这里给你介绍两个小技巧。

第一个技巧，要通过曲线来让人放松。

要知道，人体非感性。硬邦邦的直线，会让人不自觉地集中精神，变得紧张。柔和的曲线，会让人放松，而放松，就会带来愉悦，产生美感。

比如，丹麦有个设计师，叫雅各布森，他设计了一把非常有名椅子，叫做“蛋椅”，它的整体形状，有点像一个切开的鸡蛋。
