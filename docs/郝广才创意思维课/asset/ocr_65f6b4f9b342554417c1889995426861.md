# 05 | 转换借用门：如何让旧事物发挥新用途？

你好，我是郝广才，欢迎来到我的创意思维课。

上一讲我们讲了组合拼开门，不相干的东西组合在一起，说不定就会产生意想不到的效果，而有些东西被创造性地断开，也会产生源源不断的创意。

这一讲，我要为你讲的创意思维方式是转换门和借用门。是指将事物原本的样子，换个角度展，颠倒转个弯，就会产生很大的创意力量。

首先，我来跟你讲一讲转换门。

转换门有三个关键点，分别是物转其用、人转其才、地转其利。

这句话你可能很耳熟，其实它改编自孙中山说的那句“物尽其用、人尽其才、地尽其利”。

下面，我来详细为你解释一下这三个关键点。

# 物转其用

物转其用，就是怎样去转换事物的用途。

1853年，有一个人叫李维·斯特劳斯，他带了一大批帆布到美国加州，因为当时的淘金热，吸引了很多人来挖金。

他想这些挖黄金的人一定需要帐篷，所以就带着很多帆布来到加州。

结果发现原来加州热得要死，也不下雨，根本不需要用来帐篷。那他怎么办？把帐篷再运回去？

他脑筋一转，发现当时这些淘金的人都是跪在地上干活的，裤子容易破，破坏了就这些人需要一条耐磨的裤子，那就做帆布短裤，用以做工作服。

这样，转出了牛仔裤，也转出了李维斯（Levis）这一世界知名的牛仔品牌。

你看，这就是物转其用。如果不转，那一堆帆布就没有再用了。李维·斯特劳斯之前做的帐篷就没有价值，他一转，所有做的都变成了对的。
