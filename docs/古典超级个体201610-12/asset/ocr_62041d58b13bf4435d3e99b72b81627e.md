# 知识众筹 | 时间管理“利器”展7-5

Hi，欢迎来到超级个体，在不确定的时代，确定地生活，为个体崛起的时代做好准备。

本周，我们玩了个知识众筹，邀请大家分享自己的时间管理“利器”，这几天后台一共收到200多个“利器”推荐。我们整合、精选了一些有代表性的，并进行了分类整理。

# 1.时间日志

吴雷：推荐 atimelogger2 或 timetrack.io（均需付费）。这两款时间记录app，由同一位作者开发。后者算是前者的更新版本，功能更完善（多了番茄钟、标签等）。可以预设“工作”、“读书”、“休息”等主题。操作简便，开始做一件事时点一下，做完继续下一件事时再点一下，即完成记录。还能添加备注，记录的日志也可以导出，在电脑上做分析整理。

# 2.习惯养成

荔子: 推荐“种子习惯”app。它就像一个闹钟，在你规定的时间给你发推送，提醒你这个时间段该做什么事。每一个时间段做什么事，自己可以随意填写。

抹茶宁: 推荐 playtask 软件，一款类似人生升级游戏的app。可以在每日任务中写上自己想养成的习惯，然后将要做的事 情当成游戏任务执行，并且给每项任务设定一个经验值。挣到的经验值可以满足欲望库里的事项，这些事项也是自己设定的。例如: 想要个6000元左右的单反，可以在欲望库写上“单反需6000点”，完成任务后，你就可以奖励自己一个单反了。

# 3.任务清单

freistark: 推荐“滴答清单”app。可以创建工作、学习、购物等不同类别的清单，将自己的生活按不同领域进行清单革命；实现按情景进行时间分类，将碎片时间进行整合。

# 4.制定计划

林夕: 推荐“橙子成长联盟”公众号的“三件事”。这个小习惯让我不那么焦虑。晚上打到匀的时候，真的很享受。“小确幸”环节设计特别贴心，每天创造一个小确幸，每天都有期待。

许旭: 推荐《效率手册》。是本纸质的效率手册，很好用。我会在每天上班时逐条列出需要进行的工作，不分大小。完成一件后，随手记录开始和结束时间，被打断后也是如此。最大的好处就是便于每天结束后统计工作量，而且能逼着自己在被打断后马上开始，强行减少空闲时间。

无间狂刀: 推荐 Doit.im 软件。它非常清晰地帮助人们做计划，梳理杂乱的事项，甚至还有教学视频，与GTD联系紧密。缺点是不适合于复杂和深度项目的日常管理。

凤灵子: 推荐用Excel表格，这个表格包括: 1.横栏: 工作内容、负责人、完成时间、完成状态、未完成情况说明。2.纵列: 总结、计划。它能帮助个人将工作内容进行轻重缓急罗列，并依次执行。

Excel表格虽然不炫，但对于团队管理，也适用且实用。

孙欣: 团队以周为单位用Excel制定工作计划，每周会沟通工作重点和时间进度安排，以便及时了解工作进度，掌握团队成员的状态。

# 5.提升专注力

y: 推荐 Forest 软件。这是一款旨在帮助人们建立“无手机”个人习惯的app。开始专注工作或学习之前，播下一颗种子，在我们专心的同时，种子会长成一棵大树。如果期间没忍住滑动手机，或打开别的app，树苗便会枯死。Forest每天都会记录我们的专注森林，记录我们专注的时间。

# Forest也是本次“知识众筹”中，推荐人数最多的一款应用。

罗希: 推荐学霸拯救地球 app，本质是番茄工作法，但是融入在搞笑武侠打怪故事里，并且此app开启后，如果再开其他app，手机就会大声报警，只有电话打进来会不受影响。可以帮助重度没事儿就刷下微信的患者。

江之岛: 推荐番茄工作法——厨房倒计时钟。设定25分钟，专注做一件事。25分钟结束后，5分钟彻底放松。仅仅做到25分钟专注，就很有效了。我经常会觉得: 25分钟结束后，好像只过了几秒，这就是“心流”吧。

上海大众李嘉乐^_^: 推荐潮汐 app。通过白噪声强行引发心流模式，对于工作时间常被打断，而且需要深度思考的人来说，三五分钟就能进入状态，并在一个番茄时间内，达成一项小成就。

# 6.综合类

Alice 嘟嘟修妲: 推荐 时光似金 app，貌似只有iOS版。推荐理由: 1.操作简单。自由设定工作、购物等不同场景，每个场景活动对应一个“脚丫”按钮，每次完成就点击，直接记录。2.可视化回顾每天或任意时间段的场景消耗分布。3.可以设置计划，并看到预定和实际花费时间对比。4.有番茄钟。
