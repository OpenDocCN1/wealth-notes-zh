今天没有贴出具体某个人的问题，因为很多都类似，我整合了一个后台提问的FAQ：

# 1.万一以后用得上呢？

很多东西，以后的确用得上，但是当你用的时候，你需要付出3个成本：

+   - 重新找到的成本；
- 一直保存的成本；

未来还要用过去的东西，而没法用可能更好的东西，损失的机会成本。

思考这些成本以后，重新看收益，你发现大部分东西都不值得保存到未来。

那么该怎么做？

扩大心量。

# 2.别人的礼物怎么办？

留下心意，送走物品。

# 3.过去的纪念品该怎么办？

每一个纪念品都是过去经历的一个里程碑。

# 4.浪费吗？

其实你算过自己的时间和注意力值多少钱吗？

# —— 空的力量 ——

所以为什么要清零？

+   1. 你是由你过去的资源构成的，但是你并不等于你的资源，你需要新陈代谢。
2. 扩大你的心量：把你的心量扩大到离家1公里，你会发现你几乎所有需要的东西，都能在10分钟内买到。你的“自我”扩大到组织，你发现很多自己修炼不出来的能力都有了。把“格局”放到三年，你发现很多你遇不到的资源，都有了。
3. 只有流动能让物品的价值最大化，也让你有机会遇到超越现在的你的事。
4. 所以有空间流动最重要，降低你的库存，一直要有机会流动为止。
