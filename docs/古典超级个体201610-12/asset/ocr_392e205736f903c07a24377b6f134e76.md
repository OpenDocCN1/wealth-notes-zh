# 第一部分 关于《未来职业世界，只有三种人》的回应

前天《未来职业世界，只有三种人》引起了巨大的反响，很多人开始重新思考自己的底层工作方式。

其实这三种分类并不算太“未来”，在很多互联网公司、小型的创业团队，组织内其实就是这种分类，做产品技术的、做运营传播的、做管理的一一分别对应了产品人、媒体人和运营人。

随着职场的互联网化和行业的持续跨界，职业海洋体系的渐显，这三种人的分类会越来越清晰的。

另外一种探讨也很有趣——如果把这三种人比作人的大脑神经网络的话——产品人是神经元，产生电信号；媒体人是轴突，传输电信号；运营人是⼤脑的前额叶部分，调配这些信号的产生和传递。

讲到这里你就懂了——

首先，你应该是三种能力都有的人。在这一个个人就是一家公司的时代，很难想象一个完全缺乏某种能力的人；

其次，你应该有一个比较强的专门的赛道，这样才不至于分散优势；

第三，也是最重要，你没有必要每个都强，但是需要足够认识什么是好的——因为你可以和最专业的人合作。

很多人内心持续地和同事、同行较劲，觉得他们水平也不怎么样，怎么过得这么好？等到有一天分出来赛道，你就意识到，其实你们是不同赛道的人，不是对手，恰恰是最好的合作伙伴。

所以也思考下，你是什么人？你身边的竞争者、同事、资源各自是什么人？你能和谁是最好的伙伴？

# 第二部分 来自50+个行业一线的职业趋势报告

我们所有留言中“众筹”得出的四大职业趋势：

+   1. 外包的产生与内部抗衡

各行各业内可以被规范化、信息化领域，都在逐渐完成三个阶段：规范化分工、技术化提效、互联网化放大，前面2步会极大提升效率，而后面1步是杠杆，会放大影响力。

一旦一个专业职位进化到技术化，一个公司的工作量就已经不足以喂饱这个专业岗位，产量高于需求必然导致向外接活，这个职能就从公司内部走到了市场外部。

从公司子机构到独立运营的外包子公司，从企业员工到个人品牌是必然趋势。

内部员工和部门抵抗这种变化的方式有2种，一种是自己按照这个进化路径走，壮大扩张，成为全市场的外包；一种是自己深刻理解业务，形成与企业的深度联盟。

Allison：近几年技术规范性、可替代性让整个大行业有一种不断细分的趋势。能够普遍适用的专业，都开始从子机构变成独立运营的子公司，说明行业内部的专业，逐渐开始从对内服务走向对外服务。

+   2. 持续差异化内容导致马太效应

持续输出差异化的内容是吸引注意力的核心，有持续生产能力的人和组织会越来越强，形成独特的品牌或时髦的说——IP，而同质化的内容和服务会逐渐消亡。

桃源：现在建筑专业比较大众化的住宅什么的已经不行了，所以整体显得行业很不景气。现在的建筑界，靠的基本是明星效应，比如一些建筑大师，类似国外的库哈斯、扎哈等的角色，在国内是很有市场的。

苏伟：同质化的内容沉没，差异化的内容被逐渐隔离出来。同质性的内容，越来越没人看，打开率极低，各种应用和新奇内容都在抢夺大家的注意力。尤其今年最大的感觉是：发现人没了。去年还热热闹闹做团购，搞活动，各类群里每天都很活跃，随便扔一个话题，都能讨论半天。现在，再也没有这种盛况了。我们做的儿童图书、教育教养的信息内容，比起儿童智能玩具，在吸引注意、抢占时间上，没有优势，原因：不能持续提供差异化的内容。做内容，不管是针对哪个人群，先到先得，后到没有任何机会。

用思想来思考：我是一家地方电视台的娱乐脱口秀节目的编导，母庸置疑技术和互联网对我们的传统媒体冲击很大，一是表现为广告投入大大降低，二是我们受覆盖面小的缺点更加明显，三是更没有收视率了。

小柳涂姗：我是一名电商设计，这几年设计的地位有所提升，从跻着到跨着了，更多的大店铺重视视觉营销，设计感，传递品牌调性！设计工作者也从运营说做什么做什么，变成了能提出自己的见解！我觉得互联网让设计者的地位越来越高了，以前设计产品包装logo看不到实际的价值，但现在一张好的图片，就可以很大影响图片的点击率和广告投放的效果！想要在产品同质化严重的时代脱颖而出，就需要古典大说会的讲故事、设计感、好玩等高感性能能力。

+   3. 中间商、信息差、价格差的业务很难行得通

阳春：我是汽车行业的，离开店端服务已经一年，也就是进入互联网架构的平台一年。互联网改变了部分业务模式和管理模式，目前在汽车行业的改变还在探索中。最大的变化是价格更透明，交易透明，以前线下隐秘操作的业务模式，因为透明的平台化更便于管理。

顾凯杰：我是做海运物流的，这些年互联网对我们这个圈子最大的改变是信息的透明度越来越高，客户随便在网上查，就能比一个刚入行的新销售知道得多了。利用信息不对称来赚取更多利润已经很难行得通。

+   4. 什么在消亡，什么在进步？

能够被规范化、技术化的手工业、基础体力和脑力工作在消亡；

廉价生产力在海外外包；

使用人的独特能力的职位在崛起。

正在消亡的：制造业工人、白领、法律咨询、保险计算、工程造价、司机、银行柜员，还有编辑……

正在兴起的：艺术类的职业，画家、音乐家、服务员、知识管理和个儿呢规划专家、讲师、产品体验师……
