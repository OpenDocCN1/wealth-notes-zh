# 超越碎片化时代 7-3

Hi, 欢迎来到超级个体，在不确定的时代，确定地生活，为个体崛起的时代做好准备。

# —— 一个观察 ——

如果你住在大城市，估计你常常遇到这种情况——马路上挤满了车，都在向前挣，每个人都在焦虑地按着喇叭，看着有点空隙就赶紧变道，变过来变过去，也没有前半身位。这只不过是在缓解自己的焦虑了。

碎片化的时间就像是一条三车道的马路，路上走的各种车就是要做的事情。好车就是特别重要特别赚钱的事，比如几百万的合作生意；破车就是碎碎的事情，比如打印资料、回电话。不管好车烂车，在碎片化的马路上，谁也快不到哪去。

那请问你怎么才能畅通无阻地通过这条马路呢？

# —— 三个策略 ——

# 1.抵御干扰

让我们时间变碎片的是各种干扰，那要整合时间就得学会应对干扰，干扰一共分两种：内部干扰和外部干扰。

+   - 电子静默：主动关掉大部分的手机和桌面推送；
- 物理隔离：尽可能让自己待在一个不被干扰的空间、时间；
- 调整期许：不要对方一说话就马上回复或回微信，但是每次回都留出足够时间处理，重要的事情直接电话，培养大家对你的好期待；
- 学习拒绝：学习沟通技巧，懂得拒绝、协商、中断和管理各种关系。
