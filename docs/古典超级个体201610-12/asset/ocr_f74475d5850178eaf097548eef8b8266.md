# 本周特约成长导师：李忠秋

快速进入一个领域最好的方法，就是直接找到这个领域的高手。本期的联合策划人李忠秋老师就是结构思考力的国内顶级高手，也是在这个领域持续耕耘了近10年的人。他常常说：“思考力的提升比知识更重要。”我深以为然，因为知识爆炸，而思考稀缺。

今天是古典陪伴你成长的第67天，一起加速，成长为更好的自己。
