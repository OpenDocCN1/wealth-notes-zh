# 发刊词 | 52次加速，助你成为“超级个体”

“我们已经有了关于商业、趋势、政治和财富的内容，为什么我们不做一档关于个人的栏目呢？”

和罗振宇碰这个专栏定位好几次了，直到这句话突然跳出来，我看到他眼睛里放光。

——唉，我们真应该为个体做个专栏。

很多人认识我，是因为我写的一本书《拆掉思惟里的墙》。

在过去10年里，我大多数的时间都在做职业生涯的咨询、高管的教综、课程研发和授课，在我看来，这都是一件事——帮助他人加速发展。

> “知识狂躁，这群人。”

上世纪美国50年代，美国的精英阶层也集体焦虑。心理学家罗洛梅说：“焦虑是人类面对威胁希望创造自我的正常状态。在这样一个高速发展的时代，焦虑的人才是真正的健康、感觉到时代脉搏的人。”

+   这群“超级个体”是这样的人：
- 科技+人性：能抓住趋势，善于利用科技，也有高感性能力；
- T型人才：良好的基础素质，在某一个领域有极致的专长；
- 联盟思维：善于组织、平台密切合作，共同成长；
- 个人品牌：有自己的个人影响力；
- 自我实现：有点品位、有点追求。

每个人，包括我自己，都需要加速升级自己的眼界、心智和能力才能抓住这个趋势。而越是靠前的人，看得越清晰，所以就越发努力。

1968年墨西哥城奥运会，跳高运动员福斯贝里（RICHARD FOSBURY）第一次在全世界前面施展他的背越式跳高。在那个流行跨越式或者仰卧式的年代，他的动作诡异而奇特，引发阵阵哄笑。随着横杆一次次升高，笑声没有了。在最后一跳成功后，他获得了奥运会金牌——全场起立鼓掌。

《科学革命的结构》把这种转化称为“范式转换”（paradigm transition）。飞机的发明就是典型的范式转化的结果。

这就是加速成长的第一个要素，转换模式。

这是加速成长的第二个要素，学着应用新的工具和技术。

这是加速成长的第三个要素，也是最重要一个——修内功，提高核心素质。

正确的模式、工具技术和个人素质，是加速成长的三个要素。最后一个虽然听上去最不酷，其实花时间最长，也最重要。只听不动的人，往往跟别人越来越高，手脚越来越低，变成一只知识痴痴的“长颈鹿”。

> 曾国藩说：“兵闲拙速，未睹巧之久也”，仅仅是精巧的东西长不了。职业发展是“拙速”，找到一个点，老老实实做事，踏踏实实练习，一年下来就会超过很多人，遇到一个机会，呼啦一下就起来了——成功是长久而持续的积累过程。

在《超级个体》里，我们准备这么干：

+   1. 我们会每周探讨一个加速成长的主题

+   我把这52个主题分成这么4大类：
- 对事的竞争能力
- 对人的影响力
- 对组织的领导力
- 内在发动机制——个人成长
