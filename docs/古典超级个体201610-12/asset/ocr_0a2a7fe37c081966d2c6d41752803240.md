# —— 一个问题 ——

“行业-企业-职业”这个模型失效，行业不断的被跨界，职业不断的变化升级，所以我们在职场中间就经常会觉得慌——会觉得自己的职业什么都能干，一会又觉得谁都能威胁你。就好像创业初期的时刻，你缺乏一个明确的职业赛道，所以边界感很差。

# —— 一个观点 ——

我们先从一本书开始说起，名字叫《增长的本质》，它是一本关于经济学和社会学的书。作者塞缪尔是麻省理工学院的一名物理学家。

它提出一个观点——今天的社会和原始社会的不同，本质上来说是物质排列的方式的不同。

# —— 一个策略 ——

你看，今天你刚刚听到了一个新的模型，叫媒体人、运营人和产品人。你会怎么样下意识的处理这件事情呢？

# —— 一个总结 ——

今天我们提到，社会、科技和商业的进步就是一个不断的信息增量的过程，而3种不同的信息处理方式决定了不同的职业属性。
