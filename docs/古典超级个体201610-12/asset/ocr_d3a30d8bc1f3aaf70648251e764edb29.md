# —— ◆ 一个总结 ◆ ——

碎片化时代无可避免，但我们至少还有3个策略。

第一个策略是拆除干扰。分为内部和外部干扰，内部干扰给大家介绍了念头收纳和3秒禅；外部干扰介绍了电子静默、物理隔离、管理期待和善于拒绝。

第二个策略是通过持续投资优势和趋势，让自己进入自由职业态，创建系统甚至投资。

第三个策略是创建一个人生主题，连点成线，吸附碎片化。

后面这两个话题是我们《超级个体》的讨论重点，会慢慢带大家走，不要着急，慢慢来比较快。
