# 古典

如何用好留言区？

《超级个体》是一个强调践行的栏目，看完文章以后留言也是一种重要的自我修练和习惯养成方式。很多人会说：“看留言区就觉得很有意思啊。”那么如何用好看完文章的留言区？想到下面几个玩法，希望大家一起遵守。

# 1. 作为社交货币【今日精华】

把内容精华写下来，更有利于自己的记忆和思考。如果把这些内容和当日工具卡分发到朋友圈，它们会成为你的学习见证、社交货币。聪明人懂得同一个时间发布多次。

# 2. 作为提问窗口【我要提问】

提出真正的好问题。这几天的互动答疑都是围绕大家最感兴趣、提问最多的话题展开的。好的问题证明我们这些超体的思考质量。为了增加我们看到这些问题的概率，你可以用“【我要提问】+清晰明确的问题”的形式来留言。

# 3. 作为智慧贡献【我要分享】

正如你看到的，很多超体们提供了很多好的智慧、观点、资料来源。很多时候埋没在漫长的文字中……为了增加我们看到这些问题的概率，你可以用“【我要分享】+自己的观点和见解”的形式来留言。有想法就要给自己“加粗”，是不是？

# 4. 作为行动汇报【我在践行】

践行者往往不会马上留言，而是会隔一段时 间。这让他们的留言有时候显得滞后。其实对于他自己来说，他自己深深知道，这不是滞后，而是提前。因为看完不动只是快的幻象。
所以，践行者在我们这个社区有最高等级的权限。你有任何通过践行我们的专栏内容达成的阶段性的成果和感悟，都可以在下方留言区加上“【我要行动】+你的阶段性成果和感悟”。
对了，也不要忘记——把内容分发出 去，成为你的社交货币。
我们先制定一些简单的规则玩起来。一定要记得，移动互联网时代，你的文字就是你的产品。请认真对待你的文字。
