# 暴衝山羊教會我的事

離開那兩隻山羊旁邊，就算有，也不 созданы不會離那些羊超過二十呎遠。「你自己在這裡幹嘛呀？」我一邊走下車一邊問著，同時豎起耳朵等著聽到羊蹄敲擊玻璃門的熟悉聲音。我腦中的第一個念頭是，「真奇怪，我不在家的時候，牠們還會想要進屋啊！」（畢竟牠們喜歡來煩我的程度，大概就跟那匹馬黏牠們的程度一樣）；而第二個念頭是，他馬的，這下糟了。

我發現這兩隻羊根本不是試著想進門，而是拚了命地想出來。以一種感覺像慢動作的快跑，我衝進屋子把羊趕出去，竭盡所有力氣把門關上，並且加固這扇剛被攻破的大門。然後當我有時間能好好看看眼前這幅景象時，事實上，我只能呆呆站著，雙手撐著嘴巴，嘴巴不斷重複念著「我的天啊」！眼前景象彷彿一場放浪形的戯的兄弟會派出對束後的樣子，史詩級的災情慘重、晴天霹靂、令人咋舌的恐怖，儘管百般不願，但除了死盯著這個災難現場，我也實在沒能做別的事情了。山羊們終於實現了牠們不可能的夢想了！牠們把玻璃拉門踢出軌道，大搖大擺通過
