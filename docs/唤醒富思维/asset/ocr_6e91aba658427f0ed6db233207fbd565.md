# 改變從創造環境開始

對她來說，酒精根本沒什麼，只是日常生活中的一部份而已。擺在桌上的那瓶酒所能提供 的興奮感，就和它旁邊那條麵包沒啥兩樣。但對我來說，酒是禁忌之物，就和抽菸或是連名帶姓直呼別人爸媽一樣既危險又刺激。我已經不只二十一歲了，再也不需要聽誰的話了，我想幹啥就幹啥，所以想當然耳我就做了自己想做的事，就算它們讓我作嘔又怎樣！

環境會型塑生活中的每件事，上至飲食習慣、財務狀況，下至外貌等，我們愈常讓自己浸潤在某個環境中，這個環境對我們就有影響力。你有沒有注意到，有養寵物的
人最後會長得愈來愈像他們的寵物？或是隨著你待在英國的時間愈長，你就愈容易把蕃茄念成「偷媽偷」而不是「偷沒偷」。

> ① 原文寫為「Oh solo mio」，實際上應該是「O Sole Mio」，是一首世界知名的義大利民謠。
