# 嘴巴說出來的，最後都會跑回你身上

你花最多時間相處的人，對你的影響力也特別大，而你花最多時間相處的人，就是你自己。因此你平常到底都對自己說些什麼，非常重要。你這一生不斷對自己重複的所 有思想、信念和話語，不論它們是有意識或無意識的，都會創造出你目前所處的現實。 所以如果你不喜歡現況，就應該要著手改變。重新編程心態的最佳方法，就是透過重複 確認，重新型現實。注意你常脫口而出什麼話，腦中常冒出哪些念頭，用可以傳達出 正面感受的新言語和想法取代之，然後一次又一次，不斷地重複講出這些新詞句。 比方說：

賺錢和花錢對我來說都很容易。我喜歡賺錢，也喜歡花錢。
金錢就是自由，金錢就是力量，金錢是我的好夥伴。
我愛錢，錢也愛我。
我想擁有的財富已經在這裡了。
我充滿能量，錢就是能量，我們超有默契，我們是闇密。
