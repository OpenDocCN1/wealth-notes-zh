那不怎麼亮麗的財務「現實」魔咒，覺察絕對是第一步。要如何做覺察練習，有四步驟

+   1. 留意那些會限制你的想法和信念。
2. 對這些想法和信念提出問題，並且仔細檢視答案。
3. 重寫你的想法和信念。
4. 大聲念出這些更新過後的想法和信念。
