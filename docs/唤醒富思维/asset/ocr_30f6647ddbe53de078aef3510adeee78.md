# 5. 你喜歡你的工作，但它賺不了什麼錢。

請老闆為你加薪。但是你要知道為什麼自己值得加薪，把你對公司的貢獻、你為什麼是公司不可或缺的資產條列出來。研究一下公司聘請你以後增加多少資產、士氣有何改變、形象和聲譽有何提升。比如說，你主辦過公司有史以來最棒的假日派對等。你是否有些他尚未被看見的技能、想法和優勢，是公司還不知道或尚未運用到的？或許你能和上司一起擬定升職的時間表和方式。想一想，你認為自己值得多少薪資，然後以自信和帶著感激的態度去爭取，同時也做好未獲同意就拂袖而去的準備。事實是當你受僱於人時，雇主通常已經預設好你的能力值了，所以如果他們不退讓，而你也不開心，那麼或許就是另尋其他薪資較好的工作的時候了。絕對不要帶著怨恨留在原地。自己去找升職的機會。公司裡有沒有什麼職位是你有興趣，薪資也比較好？如果有，去和那些做這工作的人聊聊，找出部門主管是誰，需要具備什麼資格，然後設定好任職目標。看看現在你能夠提供什麼幫助，和該部門成員維持聯繫，和那裡的人混熟，烤餅乾送他們，向他們表達你的誠意。如果你的公司沒有內部晉升的習慣，或許這個做法就不能適用；但如果公司會從內部晉用，那就大膽一試
