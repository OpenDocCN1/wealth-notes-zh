# 冥想才能和宇宙接上線

刻意地在沉靜中盤坐，是供給你心靈力量的最佳方法。用比喃說的話，你的思想像是常常待在一間很吵的酒吧（你的大腦）裡，裡頭每個人都叫啊鬧啊，用醉醺醺的聲音高聲唱著〈荒野流浪客〉②。而冥想就是讓酒吧關門，把每個人都掃地出門，讓更高層

過去你所能理解，你是狼角色！別忘了，金錢即貨幣，貨幣即能量。所以當你的能量以最高頻率，也就是愛的頻率振動時，你就像是一道挾帶美好的龍捲風，捲起所有好東西和財富，最後還會把這些好東西回這個世界，你接觸到的人也因此受益。如果

你想致富，你需要了解當你活出真我時，你就是挖到金礦了。泡杯甘菊茶，點起一盞香草味的蠟燭，我們一起來看看要怎麼帶著最美麗的你，開始賺錢。

> ② 〈荒野流浪客〉（The Wild Rover）是一首知名的愛爾蘭飲酒歌，歌詞描述離家多年的年輕人浪跡天涯多年回到故鄉的情節。
