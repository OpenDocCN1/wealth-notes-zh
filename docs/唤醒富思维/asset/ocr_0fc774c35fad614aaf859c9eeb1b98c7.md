# 心態成長，恐懼縮小

沒有？總之，我們繞了又繞，四處檢查，非常確信我們所在之處應該是城堡的警衛室，或是紀念品店？啊！一定是紀念品店啦！但過了一會兒，我們才終於意識會過來，就是這樣了，我們小時候認為輝煌碩大的城堡，根本是用小人國的標準來看。

當你的心態成長後，你會面臨的情況就和這一模一樣，很多你以前覺得龐大的東西，現在看起來卻再也不巨大了。舉例來說，想想看，有沒有什麼事以前曾讓你嚇得半死，面對它的恐懼如山大，但後來你成功克服了它，現在想起來，不過是不足以掛齒，甚至你根本已經不太記得的一段回憶：你上班的第一天、生了第一個小孩、開口要求離婚、要老闆加薪，那時那些緊張、不舒服的感受是如此強烈，你覺得你好像快爆炸了，但現在當你回想那些恐懼，你只覺得，蛤？
