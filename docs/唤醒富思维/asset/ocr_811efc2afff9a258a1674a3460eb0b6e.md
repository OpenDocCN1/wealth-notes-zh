# 寫一封情書給錢，說出你的愛恨情仇

不管你有沒有意識到，但你和金錢確實是有關係的。要是你身無分文，那也是因為你對待金錢的方式對待你身邊的人，所以才落得每年感恩節只有自己孤身一人享受火雞大餐的境地。如果想知道你對錢真正的觀感，那麼最有用的辦法就是把錢當成一個活生生的人，然後寫一封信給它。我自己覺得這個方法真是太了不起了，我也收到許多客戶和讀者的回饋，他們都 conceptual的發現，原來他們談論錢的方式，竟然就像個瘋子。我還記得那時候我寫給錢的信大概是這樣子：「親愛的錢：我愛你而且想要擁有更多的你，但我討厭自己這樣的需要你。我需要你的時候你總是不在，我完全不相信你。要承認我想要你，會讓我覺得自己很下流，可是每次你出現的時候，我都好興奮。我常常在擔心你。我希望自己不需要你。你爛透了。老天幫幫忙，拜託你快點出現，而且數量要多一點好嗎？」和大部分的人一樣，我跟錢總是維持著這種欲拒還迎的關係，這種態度如果你還賺得到錢，就真是奇怪了。我把力氣都花在一邊拒絕它，一邊又試著歡迎它。這裡有一些讀者寄來的隻字片語，是他們寫給錢的信，希望可以讓你知道，你不是唯一一個被錢搞得像瘋子一樣的人。
