# 讓態度為你掌舵

一樣，總是有tr可以因此致富，而有人卻只能落得破產一途。以下是一些可以用來駕馭大能的思想，讓你獲得財富的必勝心法：把焦點放在對的地方。你把焦點擺在什麼東西上，就會創造出更多的它來。這個概念實在簡單到不行，卻得一次又一次地提醒，我也將一直不停把這拿出來說，因為這個他媽厲害的概念，也很容易被人們立刻拋到九霄雲外去，畢竟我們對於「事情該要長什麼樣」有着根深柢固的看法。我們不願意相信天下有這麼簡單的事，也不想放棄自己怨艾的權利，也不肯任意見丟棄那些根據過往人生經歷所形成，「覺得自己懂點什麼」的那些股舒適感，還有，呃，不願真正為自己的人生負起責任，擺出一副我連買一包玉米點心都沒錢，怎麼可能再聘一個人替我架設、管網路站的死樣子。我們其實常毫無所覺地使用聚焦的神奇魔力，並和我們人生中的親愛夥伴——擔憂，聯手創造出生活中的不快樂。
