# 缺乏才是你無法進步的原因

因為害怕財富會讓自己變得惹人厭，或覺得自己不配獲得財富；或是認為自己的富裕會導致別人缺乏，因而決定繼續窮下去，這些想法都是源自於缺乏感。缺乏是一種狀態，一種覺得自己不足的狀態。這種缺乏的思想模式認為資源不足以讓眾人同享，你不夠好、不配得擁有美好人生，你花的錢就像潑出去的水，再也回不來……。同時對金錢、事物和體驗貪得無厭，也是根源於這種缺乏感，害怕再也得不到你需要的東西，害怕不安全，害怕不被愛。於是你試著填補心中的無底洞。要知道，任何事物只要過度都不健康，暴飲暴食和厭食同樣致命。否定心裡的欲望並不會讓我們更高尚，只是好端端浪費掉這些好欲望；同時也讓世界沒有機會得到我們可以給予的美好。或許有時侯你會為了世界的苦難而感到絕望和憂慮，你會覺得「我算哪根蔥，憑什麼……比別人有錢，世界上有些人只能餓肚子，也有入為了躲避轟炸只好逃出自己的國家，去當別人的奴隸。」請記得，變有錢是你能為這世界做的一點好事。這個世界的結構中，錢跟權彼此交織纏繞，如果你要做出積極的改變，錢是最有效 的工具。當然你也可以貢獻時間、組織動員、策劃示威、遊說、警告大眾，在臉書上發表文章，但如果財務困境
