# 冥想幫助你釐清想法和言語

我最喜歡的一句話是這麼說的：「聰明人閉口不言。」這句話讓我喜歡的地方有很多，它提醒了我們，只有當我們閉上嘴巴，退開到一旁聽聽那些聰明傢伙，也就是俗稱的直覺和宇宙的聲音時，才能獲得真正的智慧。這個智慧，會由我們裡面向外流露而出。
我們嘴巴說出來的話，常都和「快看我，我要告訴你五百萬件關於我的好事，會讓你完全愛上我！我要搶在別人之前先先開自己玩笑，省得讓自己看起來像個傻瓜」這類事有關。
言語是能幫助我們和他人相關的有力工具，它讓我們可以分享訊息、愛、快樂、想
法和酸豆檸香雞排的食譜。你愈是讓自己慢下來，愈是把嘴巴閉上，你就愈有機會做出影響深遠的抉擇，也愈有空間讓你在話語之間自問：「我應該要講什麼才對？」
