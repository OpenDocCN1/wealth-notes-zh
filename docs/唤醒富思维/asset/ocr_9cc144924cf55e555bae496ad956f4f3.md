# 用盡吃奶的力量

我曾經和一個朋友一起去科羅拉多河泛舟，結束後，我們得從大峽谷最底部一路往上爬才能回到我們停車的地方。那次泛舟結束的時間比當初預期得還晚；也就是說，我們得快馬加鞭沒命似地沿著峽谷邊坡連爬八個小時上去，才有機會在太陽下山前抵達停車處。我們還在泛舟艇上時，我還想像著等dades可以悠閒地健行，在走上山的頭幾個小時，還能時不時停下腳步浸入路過的那條清涼溪水中，拍些自拍照片讓其他朋友對成功征服大峽谷的我刮目相看，當然最重要的是可以休息很久。我的身材跟所謂的健美相差甚遠，於是當我們終於在日正西落時抵達峽谷頂端，我幾乎腿軟到快沒辦法站好，累得半死，完全不確定在不尿濕褲子的狀況下走完這最後四分之一哩的路程。我還記得，我一邊拜託自己身體動起來，一邊喃喃自語一些自 Escola話：「快到了，快到了！」我朋友朝我嘆嘆著一句話，我知道我聽得懂，卻沒辦法馬上意會過來。我轉過頭看著她，看到了她指向那座通往巴士停靠處的山丘。這輛剛剛靠站的巴士會載我們回到幾哩外的停車場，而它的班距是每四十五分鐘一班。就在那時，我才終於知道我朋友剛剛在對我喊什
