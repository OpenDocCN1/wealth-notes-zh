別去改變他們。試著鼓勵、愛他們，當他們提出疑問時，你可以提供建議，肯定他們，但別認為你的任務是讓他們「開悟」。除非他們自己想改變，不然你也不會讓他們動起來。以身作則。不要去告訴他們該或不該做什麼，專注在自己身上，盡力成為最棒的自己，這麼一來，假如哪天他們問你是怎麼辦到的，你就可以用盡一切方法幫助他們了，如果他們沒有開口問，那就這樣吧！
如果你已經知道他們不會支持你，或者是會把他們的懷疑、憂慮都丟給你，那麼就別和他們分享夢想或你正在做什麼！有什麼用呢？你還是得愛他們、得和他們相處，但就別讓他們干涉你人生中的這一區塊吧！
多和成功人士以及那些能理解、支持你的人相處，他們就是你的新「家人」。如果你不認識這樣的人，想辦法去認識，比如說，參加教練研討會、到社群媒體上找、上去一些課，或乾脆自己弄個自我成長的讀書會，只要你找得夠認真，一定找得到人。

當我們所愛的人不支持我們的選擇時，我們會非常難受、苦惱，拜託，對我們來說，人生中還有人比他們更重要嗎？和家人之間的連結，是人生中最不可或缺的一件事，然而當我們開始成長、改變，他們卻沒有跟上來時，就會為每個牽涉其中的人招來大麻煩，甚至讓「我會被拋棄」，這個全人類最深層的終極恐懼（被 人拋棄，失去一切熟悉的事物、自我認同和人生活改變，林林總總等原因加起來，結論就是我會死掉）冒出頭來。但事實是如果我們要生活得精彩，活出最美好的自我，我們就得放手，不再緊抓這些人際關係。關於放手的重要須知。你願意放手，不代表他們就一定會離開。話說回來，你不可能一邊緊抓著舊的自己、舊的關係不放，同時卻又想成為一個新版的你。你必須選擇：緊抓不放，繼續留在原地；或是放手，看看他們會不會跟上來。

## 豬隊友拋棄

## 那些人才是神隊友？

沒有其他東西像朋友尖銳的言語，一下就刺破我們的信心氣球。
我們浪費太多時間容許恐懼恣意擺弄我們，而多半時候，我們這些恐懼和懷疑壓根就從沒成真過！保持注意在你渴望的事情，而非恐懼上，相信每件事情都會如它所命定的一一就定位。當你成長、改變後，你會開始脫去舊我的層層外衣，較低的本性自我脫落，挪出空間來讓最真實的自我得以生長。如果想成長，你一定得先脫去舊事，才能為新事物騰出空間。
以下提供一些為什麼和高頻率人士相伴，可以幫助你致富的關鍵原因：
1. 他們可以提升你的能量：想看，當你聽完一個特別激勵人心演講者演說，或和一位對經營事業大有熱情且有成的朋友，在他遊艇的甲板上，一邊喝著啤酒，一邊彼此來回交換各種絕妙點子，或就算是和一群很棒的人一起做你喜愛的事，這些事都會

大大激勵你。再試著想想跟那些成天發牢騷的人相處時的感受，他們老是抱怨老闆多麼混帳、好的保母多難找，或我們好衰，因為當我們年老時，社會福利制度早就已經跨了等。他們的話，就好像一整籃被倒在你腿上的濕襪子。有些人的能量能提振你，和這些人相伴，你就能獲得致富的能力。

2. 他們可以強化你的信心：和自信、對財富正面態度且你敬重的人相處，會讓你更容易相信你也能享受到宇宙智慧的無限供應。不論環境看起來多不可抗，一個滿懷信心、毫不懷疑的人會擁有大自然之力，也能激發你達到全新的高度。

我以前會和一些朋友到戶外輕裝旅遊，他們會帶我到猶他州西南邊那些鳥不生蛋的荒野地帶去。我們會穿越峽谷，走到一大切沙地，爬過彷彿無止無盡，一塊又一塊的巨石，徒步順流而上，小心翼翼穿過淺灘；五天後，當我們「蹦」地穿出荒野時，正好就是我們之前停車的地方。

有一次，我們聘請一位經營一家吉普車接送服務公司的女士，讓她載我們到某個峽谷的入口處。她跟我們說，我們打算去的那個峽谷最近剛好碰上響尾蛇的繁殖季，那裡現在應該到處都是響尾蛇。我在一旁是尷尬不安，好像在看恐怖片裡面那些即將成為受害者的主角們，這女人不是什麼菜鳥，她和這些峽谷一樣久經風霜，簡直快一樣老了，

但我朋友就這樣聽她說完，一副壓根沒聽到她提到蛇，而是繼續講她家小狗今天早上又做了什麼可愛的事，接著不急不徐地問她峽谷裡有哪裡可以獲取水源，還是我們得自己帶去。我完全信任我的朋友，對他們也有百分百的信心，若如他們不擔心以響尾蛇毒液流竄在血液中，做為人生謝幕的最後一刻，那我也不怕。帶著這股信心，我跟在他們後頭進入峽谷。六天後，我就這樣走出這座峽谷，身上沒有任何咬痕，旅途中也沒看著什麼響尾蛇。有有些人對自己、對你、對這個豐富的宇宙智慧，都有著無堅不摧的信心，和這種人做伴，你就能踏出致富所需的巨大一步。
3. 他們能讓你表現得更好：和那些很擅長又很開心賺錢的人為伍，不能讓你看見自己的可能性，同時也會大大激勵、驅策你。如果否天和那些只會在沙發上呼碌的人做伴，那你可能會覺得能洗完自己的衣服都好棒棒呢！良性競爭是伴很棒的事，和那些拿出最佳表現的人當朋友，會讓你也想拿出自己的最佳表現。
4. 他們讓你覺得無所不能。有一個故事是這樣的：有一支部隊正準備要過橋，上尉命令士兵絕不可以齊步走，因為如果大家步伐頻率相同，同樣的動能累積後，會讓橋彎成一個可怕的弧度，就是它斷裂前會出現的那個彎度。當人們朝同一個方向移動時，會創造出相當強勁的能力，足以讓一座橋一裂為二。所以和屬害的人結伴同行，和他們分享有資源、想法、人際網路、專業知識、熱情，那麼即便你擁有有的不多，還是比你自己踱踱而行走得更快、更遠。

5. 他們會和你一起歡慶成功：人們常說，只有在你深陷絕望谷底時，才看得出誰才是你真正的朋友。但我想為那些在你呼風喚雨時仍願意相伴在側的朋友喝采。當你落入屎坑時，人們常願意伸手提供援助，因為助人讓他們覺得自己很有用處，可以拯救局面，過足英雄癮。別誤會我，彼此照顧是很美好也很必要的一件事，我也曾困在垃圾坑裡，真的很謝謝每一個在那時幫助過我的人；但在你春風得意時仍無私為你歡呼｜特別是過得沒你好的那些朋友，確實值得我替他們多說幾句好話。你的成功會逼他們檢視自己的人生，思考自己是否可以換個方法，雖然這的確不會讓他們太開心。和那些挺你，而且不論如何都願意一起慶祝你的成功的人做伴吧！
