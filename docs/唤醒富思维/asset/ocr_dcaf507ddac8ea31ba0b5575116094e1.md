# 別再「我應該」了，請和最真實的自己連線

在那些山羊大肆虐和強暴我的家之後，我花了好幾天的時間才終於回復到正常狀態。我還花上好幾千美金換新我那臺奧迪（全新的，還真多謝你們啊）的敞篷車頂蓋，因為牠們把我蓋在車上的木板整個踢掉，然後在我的車頂上大跳踢踏舞。可是我實在沒辦法對牠們生氣。不只因為牠們可愛得要命，而是因為牠們是山羊！牠們的天性就是搞

念頭會完全壓倒任何其他一切。愛就像是藥物，它會改變邏輯思考的能力，把焦點只放在你所渴望的那個人事物上，或讓你進行一段有趣的對話：「對啊，這間餐廳的蒼蠅真的很多。說到蒼蠅，鮑伯，就是那個我愛上的人，他家裡有一次也飛進一隻蒼蠅。」當你愛上你想致富的那個原因時，同樣的事情也會發生。你所有的應對機制，這些可能 會試著阻止你離開原地的東西，都不會是這股渴望成就偉大的熊熊欲火的對手。任何 覺得自己會變成叛徒或跟貪婪的莎莉阿姨一樣糟糕的恐懼和信念，都會被充滿在你腦 中，唱著歌、彈著豎琴的幸福小青鳥們淹沒。我們只能愛上明確的事物和人，所以面對 即將手到擒來的財富，鉅細靡遺地搞清楚細節就非常重要了。
