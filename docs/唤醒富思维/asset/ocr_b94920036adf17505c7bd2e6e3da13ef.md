探尋找合夥人或找人合資、投資的可能。 總之，就是去找找看是否有人能夠幫助你擴展事業。
找不到看有無可能創造被動收入來源，被動收入的意思，就是你只需工作一次，但之後卻能一輩子不斷獲得收入。 比如說：把自己在研討會上演講的畫面錄下來，然後燒成光碟販售或供人收費下載，或是寫本書、自創其他種類的產品、投資別人的公司等。 被動收入好到不要不要的，它讓你可以一邊在沙灘上啜飲著瑪格麗特，一邊笑看錢還是不斷流進你的戶頭。
4. 你擁有一份令你痛恨／無聊得要命的工作。
你花大數清醒的時間做一件事令你痛恨／無聊得要命的事？這是不合法的！你一定得辭職！但是辭職以前，還是得對這份工作心存感謝，畢竟它也讓你賺了一些錢，也是因為它，你才能更靠近夢想。 然後記得也要看一下第五點。
