# 就是要有錢三步驟
一、念出來就是你的：

錢在我們的生活instances
錢在我們的生活可說是無所不在，想像一下，還有什麼其他東西和錢一樣四處充斥在我們的生活呢，如果你想到它時也和想到錢一樣，充滿了厭惡感，那又會是什麼樣子？舉例來說，如果把錢代換成⋯⋯天空呢？天空真是萬惡之源、討論跟天空有關的事是不禮貌的、因為我愛天空，所以我是一個很不好的人、天空可以讓正直的人變成豬等。如果真是這樣，你根本就不踏出家門，更別說還要享受人生樂事了。
如果有意識或下意識地憎惡金錢，或緊抓你對金錢的有限認識不放，或也不願意去賺錢，這麼做並不能幫助你自己或其他人，肯定也不會讓你變得更高尚；反而只是將自己拒於所有讓你得以生存、成功的事物之外，這和絕食其實沒啥兩樣。擁抱金錢，跟上金流，如此一來，你就可以打開自己，準備好接收那份現在正試著要找到你的豐富生命。
