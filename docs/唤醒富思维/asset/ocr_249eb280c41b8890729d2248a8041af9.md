# 他人的眼光不能定義你自己

擺出毫不抱歉、昂首闊步的態度。你愈愛這個出色的自己，愈和他合拍，你就愈不會在意那些不欣賞你特質的人的想法，你就愈能大顯身手，找到樂趣，和白花花的鈔票來場熱戀。

能否致富和讓夢想成真，都取決於你是一個怎麼樣的人，你怎麼想，怎麼說話，你相信什麼，你能想出什麼，你如何突破，如何認知這個世界，這一切都會影響你如何採取行動。當你熱愛最高層次的自己，並且和他有極深刻的連結時，你就會發現，不管是你害怕工作表現很差的不安全感、怕錢不夠用的恐懼、或在臺上時別人拿著茄奔去你，正中你的臉，讓你氣得跳腳；這些事都不能定義你是誰，只不過標明了你現在的位置而已。

① Prince 是美國傳奇音樂人，其曲風結合搖滾、Rap、Punk、電子音樂等多種風格，獲獎無數。
