# 幸福眼光啟動能量和行動

現在，你，要轉移你的焦點，用新的眼光看待同樣的狀況：我需要｜，我相信｜已經存在某處了；也就是說，當我需要它的時候，它就在那。我還要為自己擁有
這有 份能夠賺錢的工作感恩，既然我找到這份工作，就表示我值得被聘用，所以我一定可以找到更好的工作。我擁有家人和他們的愛，還有住在跟鞋子一樣大的房子裡？這不是很酷嗎！
你會發現，這個新的眼光讓你：
○ 覺得自己的生活有值得感恩之處，而這會成為你深信不移的信念。
○ 接著這個信念會引發一連串想法，讓你相信自己很幸福。
○ 於是開心、希望、興趣等情緒便被啟動。
○ 有力量跨步出去，創造出更多美好的事物。
