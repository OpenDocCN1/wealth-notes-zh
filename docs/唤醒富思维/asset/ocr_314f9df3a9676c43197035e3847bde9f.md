# 實現夢想需要和心臟病發一樣的力道

不要只是一味地想著該怎麼減少支出、存錢、打安全牌，著眼在你能夠如何擴張、成長，並且像個可以掌控自己人生狠角色，展開行動吧！

我知道我花了好幾頁的篇幅在告訴你明確的重要性，但同時，你一定也得保持開放，讓宇宙智慧把你需要的東西送過來，只是這些令你心裡快活得想唱歌的人、事、機會，或許會以和你期待中不盡相同的樣子出現。我們需要再次確認，宇宙知道的比我們更多，但是如果我們死抓著自己想要的東西不放，比如說，「我看到自己這個月多賣」
