# 五種人生階段卻能增加收入

我會模擬五個可以幫助你增加收入的不同情況，但我希望你牢牢記住，如果你想揮出全壘打，那麽不管發生什麼事，你都要放寬心胸，讓目光可以超越你現的環境。

快醒過來，看看自己到底是怎麼詮釋「現實」，做新選擇，向外尋求新鮮的觀點，去相信那些感覺不可能的事。

多數人繼續在財務困境中掙扎，不是因为他們工作做得很糟或

是欠缺願景，而是因為他們不願意拓展眼界。

不管你現在的情況類似以下哪個狀況，也別忽略其他模擬的狀況，因為它們之間或有重疊之處，你永遠不知道會在哪獲得改變人生的靈感。
