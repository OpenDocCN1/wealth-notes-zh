# 面對恐懼時，請同時往前進

到自由，那麽我們就得丟掉這些故事，既然這樣，還有哪個故事會比可能也完全是狗屁的這個故事更適合呢？
人們常選擇待在自己創作出的故事裡，並且從中得到一個我稱之為「錯誤的好處」，我們可以繼續維持破產的自我認知、把欠佳的財務狀態歸咎於除了自己以外的任何事情（我沒時間、我有七個小孩、景氣爛透了、我身邊沒有筆可以記下待辦事項…），好讓我們不需要把自己推出舒適圈，冒著失敗的風險、看起來像傻蛋、賠錢、變成跟我們家人和朋友不一樣的那個人這種風險，當然啦，這張危險清單還可以繼續寫下去，但最終你都需要面對一個事實：比起這些戲劇人生，你得更渴望你的夢想。當我們啟程準備找出這些限制你的信念時，我還想提醒你，不要花費太多時間去處 理這個問題，以至於反而讓你無法動起來，採取改變人生必要的種種行動。我看過太多人過度執著於自己的問題，他們花了好幾年的時間記錄問題，參加各種營會，一邊哭一邊試著拆解內在自己，這些最後卻反而成為他們的藉口，讓他們不願意跨出繼續往前的
