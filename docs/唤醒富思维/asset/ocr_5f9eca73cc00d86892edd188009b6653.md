# 勇於面對財務狀況

這和許多有財務困難的人對待金錢的態度一樣。我們寧可跋腳，裹住和金錢這段破爛不堪又不健康的關係，只因為我們害怕這一層層綑帶下的東西。但是如果我們勇於面對紗布下的東西，不管它是因為想要致富而出現的罪疚感，或是錯誤的投資、無效的致富計畫等，只要我們開始留意、釐清，就能獲得結束這些殘難的力量。我們總想要避免疼痛，但卻事與願違。我們不想面對追求財富過程中可能感受到的羞愧、倔促不安。感，寧可繼續維持破產狀態，然而兩袖清風也是讓我們覺得丟臉、不安。我們不喜歡管理大筆金錢帶來的壓力，所以寧可維持窮困，繼續因為錢而壓力山大；我們不希望錢成為人生焦點，因為其他事情更重要，所以我們仍舊和自己的財務狀況脫節，最後我們還是為錢傷心傷神，不知不覺中，錢幾乎變得比其他事更重要了。

妥善包紮好便是；但我不是，而是繼續一跛一跛地走路，洗澡時繼續在腳外麵套上塑膠袋，而且能夠穿著開口笑的鞋子有多久就多久，只為了避免拆開那團已經髒到不行的綑帶，和綑帶下的傷口面對面。
