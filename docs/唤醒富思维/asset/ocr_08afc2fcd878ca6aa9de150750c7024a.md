# 別理搗蛋鬼

屈不撓的態度，展現出他對這些邁向成功最大的攔阻，被他人喜愛和融人群體的需求，毫不關心。如果想從貧窮到富有，也需要持續冒這個不被人喜歡的險。你不能在大改變自己的人生同時，又期待身邊一切，特別是你和他人的關係，都如常不變。當你不再是那個舊的你時，有的人會被你激怒，你會失去一些朋友，或許和家人的關係也會出現裂痕。所以你那份自我成長的渴望、你即將創造出的生活的模樣，和與之相關的各種感受，都得時刻牢牢地被擺在你腦袋裡的最優先位置，這樣你才能有勇氣堅持到底。你要相信，你的渴望一定會實現，你也要知道，雖然你還是很愛那些在追逐夢想過程中失去的人，但你也會吸引到和你頻率相同的搖朋友。

當你下了毫不含糊的決定，立志改變人生和變有錢時，你的潛意識不會開始朝你丟出所有最深的恐懼，同時它還會端出我稱為「搗蛋鬼」的東西。所謂的「搗蛋鬼」，就是一些超有吸引力的誘惑，是心裡的小王子為了讓你脫離預定計畫、重回舒適區，而精心為你量身訂製的。
