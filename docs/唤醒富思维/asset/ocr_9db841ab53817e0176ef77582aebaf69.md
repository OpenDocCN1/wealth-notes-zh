+   二、想大改造
1. 列出五個關於金錢的正面形容詞。
2. 練習每次拿到錢的時候都說：「謝謝。」「你要這麼想：「看吧，錢也喜歡我，它就是不黏我不行。」在你家進行勝利大遊行，親吻你的支票，為自己已經進入錢金錢，可能是有人用現金袋寄錢給你，或你投資獲得利潤，或有人拿錢給你等，潮這一歷史時刻盛大慶祝，你為金錢感謝，金錢就會愈變愈多。不管你怎麼獲得金錢，但每當你收到錢時，就用上面提到的方式慶祝吧！享受在金錢潮中優游時這種感覺吧！謝和歡快的感覺吧！
3. 每天花至少五分鐘的時間，坐下來，讓自己安靜，和金錢的能量連結。想像錢潮包圍著你、填滿你，在你的心中進出。同時每天不管什麼時候，都要盡可能地想像這種感覺。
4. 在你住所各個不同地方都放一些錢，讓自己可以習慣走到哪裡都看到錢這件事。常常提醒自己有很多處富有，把它弄得好像是找復活節彩蛋一樣。
