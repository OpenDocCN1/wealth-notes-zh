
# 用富思维创造现实

你愈是有意識地去思考那些有能力想法，你就愈不容易被有限的五感和事實藍圖創造出來的錯覺困住；你愈是緊密地和宇宙智慧連結，你就愈容易獲得財富。在這些紛擾且令你分神的日常生活中，我們主要利用兩種不同類型——由外而內和由內而外的思想，我和宇宙智慧保持連結和溝通。

我們是地球上唯一具有意識思考能力的生物，我們利用意識來建構現實，以及向宇宙智慧傳送訊息。宇宙智慧創造了過去和未來的萬物，你的思想則是你運用了自由意志的結果，它能驅策宇宙智慧為你模塑出你所面對的現實。如果散發出想法是——我哪有錢可以去渡什麼假，我看短時間內這個情況大概都不會改變吧！那宇宙接收到的訊息就會是！好，收到！你付不起，沒問題。那你就繼續待在家裡吧！你的思想創造出你現在正在經歷的財務現實；同樣地，你也可以反過來利用它來創造你想要的現實，聽清楚我說的，一個字都不能少：「你想要的現實」。你所能想到的任何事物老早就已經存在於這個宇宙中，如果它不存在的話，你又怎麼想到它呢？我知道，你一定覺得我是神經病，沒有關係，請先試著繼續跟上來。

不論是我們物質層面、心裡層面、精神層面的資訊，都是出自於同一個來源：宇宙智慧。在這些念頭從你的腦子裡冒出來以前，它們會是在哪？這麼小不拉機的種子怎麼可以開出花來？你靠著自創貓咪服飾事業而讓收入翻倍的現實是怎麼成的？所有這一切其實早就在於能量領域中了，透過你的思想，再加上那些因思想驅使而採取的各樣行動，讓一個新的事實得以就此產生於物理平面，也就是現實中。你能夠想到的任何想法早就在，因為既然所有一切都源自宇宙智慧，那麼人的思想一定也有具體的形狀。假如你想要月入五千美金，那麼這筆錢和你賺得它的方法早已存在；不然你一開始壓根就不能會有這個念頭，因為和金錢有關的想法或說金錢本身，其實都是同一檔子事。當然如果要把這個概念說得明白，我大概需要寫一本一共三千八百九十七頁的書，再加上祈禱墊和一大桶藥才行，但既然我們還有別的事得做，我只能在這裡大概的解釋一下了。你的想法控制了所謂的事實。所以如果你現住在你媽房子的地下室，在路口那間時薪七。九五美金的快餐店上班，但你心中定了主意，而且毫不疑惑，自己會擁有 一塊佔地兩百公頃的養雞場和一部凱迪拉克豪華轎車，那麼這間養雞場和駕著車兜風，就是你的事實。你的思想會對宇宙智慧發出訊息，提醒它開始為你準備能量，讓你的願望可以出現在物理平面中，你需要學習怎麼看見和接受這些新機會，後頭還會有更進一步的討論。

你的思想同時也啟動情緒，讓你開始行動，如此這般，現實就開始改變了。所以有些明明坐輪椅的人卻能夠出門爬山，有些從小家境貧窮的人卻能致富，因為不管「現實」看起來怎樣，他們認為自己的想法就是事實，並且為之興奮、努力不懈，最後目標就真的成真了。他們不滿足於眼睛所看到的現實，而是運用思想的能力創造出他們渴望的事實，而這個能力，你我其實都擁有。所謂學習掌握致富心態，意思就是說，你要選擇用能幫助自己致富的方式看待金錢，以及你現在生活中所有和金錢相關的事物。當你有意識地專注自己的想法在渴望的財富上，想像自己躺在一堆花花綠綠的小朋友中，和致富那令人興奮的感覺上，你就正重新排列身旁和心中的能量，讓它們可以高頻振動，這麼一來，現實就會以同等的頻率將機會和渴望的事物折射給你。你可以感受到這股能量，它能鼓舞你，為你蒐集那些曾被你拒於門外的機會和事物，而你之所以拒絕它們，可能為你剛好看到銀行戶頭近乎空蕩蕩而情緒低落，或是因為你找不到工作、爭取加薪失敗等。想想看，如果可以一次付清你那一千五百美金的信用卡欠款，那該會有多好！你得不斷告訴自己：「能夠一次還清這筆款項真是讓我感恩到跪下

## 與宇宙智慧攜手合作

宇宙智慧其實常常現身在我們生活裡，它可能正手拿一杯咖啡，等著來討論我們可以怎麼幫助我們增加財富。

有志者眼裡處處見機會。

它和你聯繫的管道包括：
- 你的直覺：雖然比我預期的還要貴，但我就知道我該買那間房子。不知道為什麼，總覺得這是一個正確的選擇。
- 同步的巧合：不知道烹飪課認識的珍娜最近怎麼樣，嗨！她怎麼在那！
- 突來的靈光一現：我腦中不知為何突然冒出這首超讚的旋律，你快來聽看看！
- 你的渴望：雖然到現在連一齣劇本都沒賣出去，但我就是知道我是有錢人的命！
- 隨機、湊巧發生的事：我一打開書就翻到這頁，裡面的內容剛好對我很有幫助！

如果你真心想成為一個大殺四方的狠角色，那你一定會希望和宇宙智慧有更緊密的關係，你可以這麼做：
- 學習讓腦袋停下來，這樣你才能接受宇宙智慧傳送給你的訊息。
- 相信你所得到的訊息，也就是你的直覺，不管看起來多嚇人／瘋狂／難以接受，你都要相信它就是你正在尋找的答案。
- 當你勇敢踏入未知時，要相信宇宙智慧會罩你！
- 承認你還不知道要怎麼做那些該做卻不知從何開始的事，並且相信宇宙智慧會為你帶路。

讀完了這一章，如果你還不想趕快出門去買超人披風跟緊身衣，那我也不知道還能再說什麼了。

透過思想，我們每個人都擁有足以駕馭宇宙的能力。

某一個早晨，當我下樓找媽媽時，只見她穿著睡衣站在廚房裡，沉著臉把杯子裡的咖啡倒進水槽，「我們沒有牛奶可以泡咖啡了！」她不帶感情地宣布著。但是她並沒有打算梳洗一番，換件衣服，走上個這麼一小段路進城去買牛奶。她對我說，她要穿著身上的睡衣、球鞋、隨便戴個棒球帽和擦上厚厚一層橘子口味的唇膏去買牛奶，看來，她終於認識真正成為鎮上那個名副其實的「有趣傢伙」了，「我都已經七十歲了，也是時候了吧！」

我媽的幽默感令人發噱，大部分時候也的確很好笑，我想我認識的人中沒有更勝她的人了。這也是為什麼當我某天接到她打來的電話，在電話中以震驚的情緒說，她直到剛剛才知道「智障」這個字的意思時，會令我這麼驚訝。「你是認真的嗎？」我心想妳不是明白一天到晚都用這個字眼罵妳兒子嗎？但她聽起來真的很沮喪，似乎完全挫敗，甚至於完全失去能力為這個真的很有趣的字找到至少一個有趣的點。

我媽打這通電話來的那年，她正為深具歷史魅力的郊區市鎮擔任董事會成員，在任期中，她為許多她認為至關重要且至為關心的一 些議題請命，包括曾保護了她最愛的那座公園不落入開發商手中、在主街分隔島上種植蒲公英、確保這個水庫旁的觀光小鎮沿途的路標維持在最低限度的數量等。顯然地，應該是為了要全力保持景觀完美在董事會上你來我往的討論，最後才會有這段沮喪的對話。隔著話筒，我都可以聽到她躺在床上，嘴裡不斷喃喃自語著：「天啊，天啊！」根據我所能拼湊出來的事發經過：當天稍早，她當著一整屋受人尊敬、為人正直的董事會會成員提出異議，而異議內容大致上是這樣的：「那只是一個小彎道，我們到底什麼需要在那個彎道前、中、後弄了五個，五個，畫著箭頭的路標，警告人們需要稍微往左轉一些？這些路標真的很刺眼，完全是浪費納稅人的錢，如果你真的『智障』到需要每隔兩步就看個路標才會開車，那你根本不應該開車吧！」直到這時我才知道，這已經不是她第一次口無遮攔地在整個董事會面前說出「智障」這個字眼了，顯然她在過去這幾年間都一直故意使用這個詞，比如說，用來指稱市長辦公室那些透過她不喜歡的法案的蠢蛋們，或是那些在人行道小吃攤對牆噴漆上「二○○三年畢業班」字樣的「智障」高中，還有那個去年萬聖節撞斷艾姆路上電線桿的酒醉愚蠢白痴智障。話筒中傳來她的悶聲。「我以為這個字是不聰明的意思，結果後來是花園俱樂部部長吉妮亞當斯，她把我拉到一邊，叫我克制一下，嘴巴放乾淨一點，天哪！」我母親結束了這場鬧劇，經過此事，她不但發現到謹慎用字的重要性，同時也赫然發現自己在無意間成為了社區裡的有趣傢伙。

當不留意自己的言語、想法和信念時，你就好像是冒險讓自動運轉你的人生。舉例來說，你以為的信念是根據事實建構而成，但你並沒意識到，這些信念很可能來自於你父母或其他身邊的人。你的言語其實忠實地反映出你的信念。所謂的言語，就是你無心地重複敘述那些以前聽過的東西，不然就是證明了你對於字彙的選擇非常糟糕。一旦你覺醒，開始有意識地留意自己的思想、信念和言語，並且謹慎選擇所思、所信、所言，你的人生就不會這麼無趣或比無趣更糟，也不會一直卡在財務困境中，而對我媽來說，則是不用被一個園藝比她更糟的人當眾指責嘴巴不乾淨。

掌握你的心思對人生各個層面都有幫助，既然錢在世界上，特別是在金錢這塊扮演了如此重要的角色，有一個正確的心態對我們來說更是極為關鍵；我們甚至可以說，沒有正確的心態，我們根本就無法正常運作。

話雖如此，我們卻很少，甚至不曾停下來深究我們對金錢的觀感、我們談論它的方式，或金錢實際上到底是一個什麼樣的東西。

## 錢只是工具，無法取代你是誰

所以讓我暫時先停在這。不掌握好自己的心思，便是在脆弱的根基上構築人生。

古早時候，那時還沒有貨幣的存在，人們以物或勞力易物，好比說，為人砌一面石牆以換取一條獸皮和一袋鹽，或是用兩個女兒換一座城堡等。但是帶著一條獸皮或一堆石頭走來走去實在會累死人，為人蓋東西又得耗費掉許多的時間，於是乎，人們想出了「錢」這個概念，賦予硬幣和紙鈔面額，所以今天我們買車或買任何東西時，只需要掏出錢包，而不再需要選出五隻最好的駱駝交換。金錢是一種人們進行交換行為為時衡量的單位。有異於一般的想法，錢本身並無好壞之別，它亦非敵非友，骯髒或乾淨，錢就只是錢，它只管自己的事，並且努力試著不讓自己被卡在自動販賣機裡。錢，只是傳聲筒，你如何運用它，以及你對它的看法、感受和談論它的方式，才賦予了它人格。你賦予它什麼人格特性，則會決定了你想要被它包圍，或是敬而遠之。

這也是為什麼當你完全不經思考地認為錢是不好的、骯髒的，同時還一直大聲嚷嚷著這個想法，你就是在不斷加強這個想法，而這剛好是使你窮哈哈的最主要原因。舉例來說，你很有可能有過「金錢真是萬惡之源啊」的這個想法，或曾脫口而出這句話。

沒錯，我們的世界中充滿許多人們為錢所做的醜陋、不公義的事，但做錯事的是那些人，而不是錢；這就好比是說車子很邪惡，只因為有的人手一握方向盤就成為討人厭的混蛋，或者是只因為你削皮時不小心削到手，就說削皮刀是令人厭惡的東西一樣。錢、車、削皮刀都只是工具，它們能為人帶來極大快樂、興趣的冒險，更不用說，也是完美的結婚禮物。用已故俄裔美籍哲學家、小說家艾茵·蘭德的想法來說—錢只是工具。它能帶你到任何你想去的地方，但它沒辦法取代身為司機的你。

一種難以被滿足、極度自私的感覺，想要更多更多更多。另一個也很容易和錢掛勾的字詞是「爭權」，它的意思是以一種高壓和極度惡質的方式發揮影響力。咱們也別忘了「腐敗」，意指道德破產，只注重個人得失，完全罔顧法律或是自己的行為會帶給別人什麼影響。

以下是其他我們常誤用來形容「金錢」的方式：

這些說法都挺狠的，不是嗎？就好像錢是個惡棍，闖進你家，海扁你一頓，嘿！它只是想讓你可以買東西而已啊！而如果你打算大賺一筆，那你還需要知道另一件關於金錢的重要事。

幫對街的老太太清掃她院子裡的落葉而獲得五十美金，它的意義和你從地鐵上隨便哪個人的口袋裡摸來的五十美金就完全不一樣。你在二手家具店買的那張價值五美金破破爛爛的椅子，如果是來自大衛．鮑伊的巡迴巴士上，那可能就值五千美金了。有些藝術家的畫作要價二百美金，有的則要二千美金。當你被僱用負責某項工作後，卻發現工資大都被低估，那麼當終於領到薪水時，還是會覺得彷彿是收到一張濕答答的面紙，感受很不好；然而如果你收到的工錢遠遠超過工作內容所值時，又會覺得尷尬，懷疑自己是否有些卑鄙、骯髒。當然如果你的薪水金額恰當，與貢獻相符，會備感激勵，勢不可擋。付出、收取金錢是人和人之間充滿能量的一種交換行為，你的責任就是有意識地調整你的欲望，直到它到達和你所渴望的事物相同的頻率；意思就是說，你需要了解你所提供的事物或服務的價值，並且心存感激、期待，不要對於獲取金錢感到不自在、抱歉，同時懷抱信心，相信金錢正在到來的路上，不要成天擔心要的是錢不來的話會怎麼樣。這裡我要提一下一個很重要的觀念：錢雖是經由其他人那裡流過來到你這裡，但它的源頭卻是來自於宇宙智慧。所有事物都是如此。這也是為什麼賺錢的關鍵，是你要注意自己腦中思想的頻率，而不是把焦點放在那些你想從他們那裡賺到錢的人身上。比方說，假設你需要弄到四千美金，好讓你的奶奶可以坐頭等艙去參加在加拿大的新斯科細亞省參加她夢寐以求的那場編織大會。於是你決定賣掉未拆封的歐比王公仔換現金，很幸運地，也出現了相當感興趣的買家，你要做的是調整你的頻率和朝你而來的這四千美金對齊，而不是去在這個表達購買意願的特定人選。你即將要把星際大戰紀念品中最棒的一件，就是這個配有兩支伸縮光劍的公仔，拿去換你想要也應得的一筆錢，把焦點擺在這件事上。你可以想像奶奶在頭等艙和其他乘客聊聊天、喝著香檳、和人討論可以使用的哪塊拼布的畫面。你的焦點應該擺在以下是你想獲得這筆錢本身，以及它會被用來做什麼事情；為了獲得金錢，你會和他人分享一件有價值的東西，而他會因為獲得這件物品樂不可支；你為著即將獲得的金錢充滿感激，這件事一定會成真，你會獲得這筆錢；還有你知道宇宙智慧罩你等。

原因很簡單，一來，別人要幹麼和你一點關係都沒有；二來，如果你把焦點都擺在特定一個可能是或不是金錢管道的人身上，反而可能讓你和宇宙派來帶著一整大袋鈔票的那個人失去連結。這和你決定要把你的一生摯愛吸引過來一樣。你會把眼光和焦點放在他的特質，和想像跟他在一起的興奮感上，你開心地想著，他一定也在尋找你，於是你更常微笑，在隨便什麼東西上都畫個小愛心，讓自己的房子充滿著結婚花束的香味，這些都是你會做的事；但是妳不會花時間去找咖啡店那個坐在你隔壁，有一輛摩托車的性感男子，他跟妳毫無共通點也對妳完全不感興趣，但妳卻想試著說服他妳就是他的天命真女，最後反而因此錯失有著大鼻子，但卻和妳是絕配的公司同事。賺錢這檔子事也一樣，你負責做那些充滿能量的事，讓自己的思想、行動、言語和你渴望創造出的事物對齊，然後把剩下的交給宇宙吧！
