# 請關掉受害者模式

思考這些道理，你就能夠明白為什麽你如此重要了。
高頻率的能量你愈給，就得到愈多。沒有什麽東西的頻率和施予者的頻率一樣，可
以說給予的頻率和情人們的頻率一樣高。那麽就應該使用的天賦來幫助他人，比方說，你可以寫一個幫助人從心碎中恢復的部落格，或教小朋友閱讀，烤一個好吃到掉渣的藍莓派等，這麽做就等於幫了自己一個大忙。就算只是為人指路、對他人抱持正念（如果余你剛好很討厭那個人，那更是額外加分），幫人撿起他落下的東西，和說出大家最想聽到的四字真言「薯條給你」的這類小事，也都很棒。給予會散發出的高頻率能量，最後會回到我們身上；可能會經由我們施予的人，也可能不會，但它絕對會以某種形式回來。我們生來就該分享，這是真的，所以貪婪從來就不會讓我們喜悅，貪心只會激發
