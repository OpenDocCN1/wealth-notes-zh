# 6. 你目前待業中，想要找一份工作。

列出那些對你來說很重要的，心目中夢幻工作的條件：薪資數字、想和什麼樣的人共事、這份工作可以運用到哪些技能、上班的服裝要求、去上班時的感受、公司是不是每週四都提供免費的貝果等等。愈鉅細靡遺，這份夢寐以求的工作就愈有真實感；最重要的去感受這個感覺。不分日夜，你都要去想像畫面，沉浸在那些感受中，心存感謝知道這份工作一定存在於某處，並且要帶著堅定不移的信心，相信它正朝你前來。最後別忘了，管好你的嘴巴，別一直講那些沒營養的話，諸如：找工作好難喔、我快抓狂了、景氣超爛的、我太老了、找了快一百萬年、我是不是看起來一臉衰樣，是不是這樣子才沒人想錄取我？讓你的思緒、說出口的話、信念和感受都和你渴望的工作相配，然後未達目的前都別停下腳步來。要記住，不管你在尋找什麼，它也在尋找你。用你知道的每種辦法找工作，跟認識的每個人和他們認識的每個人說你在找工作（特別是那些你很少接觸的人），把履歷上傳到求職網站，和在相同產業裡上班的人聊聊，徵詢他們的建議和推薦，或乾脆找個獵人頭顧問。用盡一切辦法，然後後再多走一哩路，你的工作就在這裡，如果它不存在，那你也不會有想做這個工作。
