# 現實是言語和思想建構出來的

言語同樣會大大影響我們對現實的認知。藉由不斷被重複敘述，話語能讓我們的思想和信念活過來，這些想法和信念最後就會成為我們面對到的「現實」。話語幫助我們確認自己的身分。我們心裡那些沒有說出來的話，和習慣以為常的既定行為模式會抓住我們：我記憶力超差，所以我又忘記帶鑰匙出門了，我真的是弱智！你愈是一直說自己是健忘的弱智。你要是一直跟一個小孩說她很笨，只要說的次數夠多，那就算她明白自學英文有成，最後她還會信以為真。四十年頭裡幾乎每一夭，我都不斷跟自己說：「我不知道自己人生的目標是什麼。」因為這樣，我自認就一直處在毫無盼望且困惑的狀況裡，就這樣長達數十年。如果把「我不知道」換成「到處都有線索」，我就可能早點接收到生活中的片段線索，而不是總把機會之門悍然關上，天知道我因此錯過多少良機！人是習慣的動物，所以我們會一直重複講同樣的話，久而久之，這些話就像鑿子，在我們腦袋裡鑿出痕跡，一次又一次地不斷播送相同的故事，型塑思想和信念，最後便定義了現實。我們的話就像流過石頭的水，隨著時間在石塊上刻畫出痕跡，甚至可深如
