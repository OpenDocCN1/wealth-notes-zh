# 養成能讓你成功的習慣

當我們談到習慣時，通常會想到諸如咬指甲、抽菸、罵髒話、玩頭髮、早起遛狗、用吼的方式講手機等行為，事實上，這些習慣構成了我們生活中大部分的行為：懶散是種習慣、感到不知所措也是一種習慣，遲到是，失敗也是，成功、有耐心、愛說八卦、賺錢、破產，林林總總，都是習慣。習慣，就是一種不假思索，反射性和重複性的行為，考量到我們常不經思考就行動，因此我們的行為大部分都可以被歸在習慣這個區塊中。
人們常處在一個根據潛意識反覆行動的狀態之中，而一旦我們察覺到這個現象，並且決定要改為有意識地回應現實，我們就可以改變習慣；而當習慣一改變，我們所處的現實也就跟著改變了。
