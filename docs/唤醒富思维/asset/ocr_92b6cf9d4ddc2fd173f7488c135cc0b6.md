# 金錢即貨幣，貨幣即能量

這些說法都挺狠的，不是嗎？就好像錢是個惡棍，闖進你家，海扁你一頓，嘿！它只是想讓你可以買東西而已啊！而如果你打算大賺一筆，那你還需要知道另一件關於金錢的重要事。

幫對街的老太太清掃她院子裡的落葉而獲得五十美金，它的意義和你從地鐵上隨便哪個人的口袋裡摸來的五十美金就完全不一樣。你在二手家具店買的那張價值五美金破破爛爛的椅子，如果是來自大衛．鮑伊的巡迴巴士上，那可能就值五千美金了。有些藝術家的畫作要價二百美金，有的則要二千美金。當你被僱用負責某項工作後，卻發現工資大都被低估，那麼當終於領到薪水時，還是會覺得彷彿是收到一張濕答答的面紙，感受很不好；然而如果你收到的工錢遠遠超過工作內容所值時，又會覺得尷尬，懷疑自己是否有些卑鄙、骯髒。當然如果你的薪水金額恰當，與貢獻相符，會備感激勵，勢不可擋。付出、收取金錢是人和人之間充滿能量的一種交換行為，你的責任就是有意識地調整你
