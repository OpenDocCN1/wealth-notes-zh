# 發現窮思維的根源

會裡，我一直不斷調高頻率、高舉我的拳頭，提升我的認知，讓它遠遠超過我目前財務「現況」的局限，所以我完全沒去思考這像伙可能有妄想症，而是深信我一定可以生出這八萬五千美金來。當我瞬間轉變思想，從「不可能」到「一定有辦法」的那一剎那，我突然明白了直以來讓我無法賺錢的那個最大障礙是什麼。有很多方法可以幫助你挖出內心根深柢固恨惡金錢的潛意識信念，而其中最強而有力的方法，莫過於把自己推上火線，迎面對抗你最大的恐懼。為了朝你的夢想前進，你需要一些重要、大膽的行動，就會因為此尿濕褲子，你也在所不惜。對我來說，做一個這麼重大的決定，並且意識到我竟然能夠並且願意如此投入，使我進入了另一個現實環境。賺得到錢和成功的感覺第一次這麼、這麼、這麼可能，而這可嚇壞了我心裡的小王子。當你打算跨出生命中很大的一步時，這就是你會經歷的感覺：你既興奮同時又害
