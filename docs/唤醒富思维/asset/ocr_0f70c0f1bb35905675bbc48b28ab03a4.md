# 用富思维创造现实

你愈是有意識地去思考那些有能力想法，你就愈不容易被有限的五感和事實藍圖創造出來的錯覺困住；你愈是緊密地和宇宙智慧連結，你就愈容易獲得財富。在這些紛擾且令你分神的日常生活中，我們主要利用兩種不同類型——由外而內和由內而外的思想，我和宇宙智慧保持連結和溝通。

我們是地球上唯一具有意識思考能力的生物，我們利用意識來建構現實，以及向宇宙智慧傳送訊息。宇宙智慧創造了過去和未來的萬物，你的思想則是你運用了自由意志的結果，它能驅策宇宙智慧為你模塑出你所面的現實。如果шка散發出想 法是——我哪有錢可以去渡什麼假，我看短時間內這個情況大概都不會改變吧！那宇宙接收到的訊息就會是！好，收到！你付不起，沒問題。那你就繼續待在家裡吧！你的思想創造出你現在正在經歷的財務現實；同樣地，你也可以反過來利用它來創造你想要的現實，聽清楚我說的，一個字都不能少：「你想要的現實」。你所能想到的任何事物老早就已經存在於這個宇宙中，如果它不存在的話，你又怎麼想到它呢？我知道，你一定覺得我是神經病，沒有關係，請先試著繼續跟上來。
