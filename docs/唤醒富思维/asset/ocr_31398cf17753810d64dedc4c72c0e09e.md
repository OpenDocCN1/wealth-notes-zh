# 孤注一擲的前提是擁有正確的心態

為了進到下一個階段，有時候我們得冒一些可怕的險｜花那些還沒賺到的錢。意思就是說，你會因此負債，而在我們的社會中，債務就是那隻很壞的大野狼。事實上，債務就和其事一樣，取決於你的心態如何。如果是帶著恐懼、懷疑的心態，並且毫無清償債務的動力或計畫，就魯莽擲你沒有的錢，過著打腫臉充胖子的生活，為自己挖一個大坑，是完全另一回事。我並沒有建議你要怎麼做。然而如果還有別的選擇，我不鼓勵你負債｜這是萬不得已的孤注一擲，前提是你需要擁有正確的心態，它才能是讓你起死回生的方法。冒險，然後遍自己一定要解決問題，不把錢賺回來誓不停止，這才是我所謂正確的心態。這就好比你想去旅行，卻一直找不到對的時間；快他媽的把票買一買，旅館訂一訂，該搞定的事搞定，然後喬好你的行程去配合。如果цик你總是想等到有時間才出發，那你永遠都無法GRESS成行。

這些事的道理都一樣｜如果你想等有錢再行動，那你就永遠不會行動。在這段突破自我，脫離貧窮生活方式並且致富的過程中，我一直都努力這麼做。我新辦了一張信用卡以支付教練課程，不管教練說什麼，不管聽起來多駭人，我都照著去做，非把錢賺
