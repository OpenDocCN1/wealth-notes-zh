# 权威的力量是无穷的

社会是人群的集合，每个人都在孜孜以求，奋力拼搏。但单独的个人力量与整个社会的力量比较起来，如沧海一粟，高山一草，毕竟太小了。要做一番像样的事业，就不能仅仅局限于自身，必须借助第三者的力量，造成一种声势，这是利害成败的决定因素。而借助的第三者，最有力量的恐怕是那些有权有势或名望很高的人了。所以，中国历史上，假借皇权的名义来陷害忠良，排除异己的闹剧、悲剧就层出不穷。

明武宗时因宠信太监，不管朝政，于是刘瑾得以擅权。

武宗宠信的太监共有8人，即：马永成、谷大用、魏彬、张永、邱聚、高凤、罗祥、刘瑾等，时称为8党，后又号称8虎。这8人中，刘瑾最为狡诈。他曾读过一些书，粗通掌故，能力在7人之上，又最得武宗信任，因此被推为太监的首领。

刘瑾擅权的手段主要是：“击球走马，放鹰逐犬，俳优杂剧，造作巧伪，”使皇帝心神震荡，劳耗精力，起居失节，不问政事。刘瑾得以暗置党羽，矫传诏旨，排斥忠臣，陷害异己，阻塞言路，从中弄奸。
