# 凶：缺德者的不变定律

缺德者说：“只要能达到我的目的，他人卖儿卖妇，都不必顾忌，但有一层应当注意，凶字上面定要蒙上一层仁义道德。”

缺德之人，有的表面上很慈善，而内心却像蝎子一样毒狠，凶残无比，有的干脆表里如一，从脸上到骨子里都渗透一个“凶”字。

唐朝武则天时大兴诬告之风，索元礼以善审诬而升官至推事，他审讯囚犯时，制作了一种“铁笼头”的刑具，紧箍犯人的头，还加上楔子塞紧，有不少人看到这刑具就违心地屈招，有的刚烈之士，死不承认，被整得头骨开裂，脑髓流淌地。他还设计了“凤晒翅”、“猕猴钻火”等刑法，“凤晒翅”是用椽子锁住犯人的手足加以扭转，同时劈砍，直到骨头破碎。又把囚犯悬吊在屋梁下，用悬石下坠敲击他的头。此人真是凶残无比。
