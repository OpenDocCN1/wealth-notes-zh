辑往下推，大家自然会合力推出许多证据，证明你的上司“骄傲自大、鼻孔朝天”，到时他就四面树敌，想不垮台也难了。

捧上司的另一个目的是：防止别人向上司说你的坏话。

# 第六法——告诉别人你的上司是个吝啬鬼

当我们说别人坏话时，听者常紧张起来，可是当我们说某某主管是一个小气鬼时，大家却能笑着接受。也许大家早在心中认定有权有势的人常很吝啬（民间故事里有太多一毛不拔的员外），也有可能“吝啬”是最温和的攻击字眼。

因此，各位在和上司共餐、共搭计程车时，要抢先付钱，事后再以一附委屈的表情向同事说：“那家伙真大牌，又贪贪小便宜，每次都慢吞吞地掏腰包，要不然就是拿百元大钞付小帐，我只好说，我有零钱。”大家听了哈哈大笑之后，便对这位上司产生恶感，你就成功了。日后别人又听到这位主管的其他恶评，也不会感到奇怪。

其实，对付主管何止以上六法？本人还特地保留了七法不说出来，以维护宇宙和平。所幸各位天资过人，缺德成性，不难举六反七，闻六知十三。

# 爱护你的上司

上班族之所以畏上司如畏虎，有时并不全是上司张牙舞爪的缘故，前述对付上司六大方法中已指出居上位者若干难为处，有时上司的确有他不得不貌岸然的苦衷，换句话说，上司对你造成的压力有时来自你本人。

理由何在？在于你的不安全感。不安全感的主要成分有二：一是单调的生活，一是受制于公司的经济来源。
