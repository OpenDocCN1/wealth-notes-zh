# 装聋作哑

聋，就是耳聋，笑骂由他笑骂，好官我自为之。但聋子中包含瞎的意义，文字上的诋骂，闭着眼睛不看。

聋的意思是看见的装作没看，听见的装作没听，别人骂让他骂去，只管自己做官，不管名声如何，虽然别人在戳自己的脊梁骨，自己也不生气。

聋的另一方面意思是大事化小，小事化无，为了当官，即使有人骑在自己脖子上拉屎拉尿，也照样当作没看见，没听见。对奸佞们残害忠良，欺下瞒上，淫乱荒唐，也要视而不见，充耳不闻。

魏晋南北朝时期，在以鲜卑族贵族为主的高氏齐国，出了一个大奸臣，他就是和士开。

和士开掌了朝中大权后，作威作福，荒淫无耻，当时人们指责和士开贪淫乱政，凡是不向他屈服的文武大臣都被他一一杀害，手段残忍，令人生畏。

和士开还秽乱宫闱，与武成胡皇后公然相婘，毫无顾忌，又仗势为非作歹，强夺人妻。有一个叫徐之才的官员，他的妻子是魏广阳王的妹妹，长得非常漂亮，和士开贪淫成性，竟跑到徐之才家里去强淫其妻，正好被徐之才遇见。可叹徐之才毫无男儿气概，只有缺德学术精通，为了官位竟自行避开，且自我解嘲：“妨少年戏笑。”
