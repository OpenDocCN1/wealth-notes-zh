# 摆出上司的派头

居高临下，与臣僚保持适当距离，这是掌权者显示其高不可攀的尊严和不可一世的威风的一种重要手段。一般来说，掌权者是不会平易近人的，因为在他们看来那样会失去威严，会使臣下变得放纵，会“蹬着鼻子上脸”，因此，他们要装腔作势，显示出那么一副神圣不可接近的气度，距人于千里之外，仿佛越这样便越有威望，可以给臣下造成一种心理上的压力，使其自觉其渺小，自惭形秽，从而不由自主地对君上畏服。

明太祖朱元璋出身寒微，做了皇帝后自然少不了有昔日的穷哥们儿到京城找他。这些人满以为朱元璋会念在老朋友的情份上给他们封个一官半职，谁知朱元璋最忌讳别人揭他的老底，以为那样会有损自己的威信，因此，对来访者大都拒而不见。

有位朱元璋儿时的好友，千里迢迢从老家凤阳赶到南京，几经周折才算进了皇宫。一见面，这位老兄便当着文武百官大叫大嚷起来：“朱老四，你当了皇帝可真威风呀！还记得我吗？当年咱们俩一块光着屁股玩耍，你干了坏事总是让我替你挨打。记得有一次咱俩一块偷豆子吃，背着大人用破瓦罐煮。豆还没煮熟你就先抢起来，结果把瓦罐打烂了，豆子撒了一地。
