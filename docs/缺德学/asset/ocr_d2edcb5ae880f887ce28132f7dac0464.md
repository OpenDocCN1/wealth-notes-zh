理想的公司体制下，决策者和执行者的意见能上上下下畅行无阻，当某部门的成员不了解自己的任务，或某主管不了解下一级部门成员的想法时，该部门主管就有问题了。这种问题主管可分六种类型：

+   一、阴晴不定型——情绪容易波动，手下疲于了解他的想法。

+   二、争功诿过型——出毛病叫手下负责，有了成绩却又归功于己。

+   三、迟钝冷感型——言语乏味、面目呆板，手下对他敬而远之。

+   四、冷血独裁型——比“争功诿过”型人物更聪明，待有利用价值者如上宾，待无利用价值者如废纸。

+   五、特立独车型——不喜欢和其他部门主管相处，使自己部门的成员在公司抬不起头。

+   六、舍生取义型——不向现实低头，老是领导众人赴汤蹈火，成仁取义。

其实，问题主管何止以上六种类型？本人还特地保留了七种类型不说出来，以维持世界和平。所幸各位天资过人，缺德成性，不难举一反三，浮想联翩。

# 对付上司六大方法

对付问题主管时，各位要有大敌临头的感觉。害怕上司是一种根深蒂固的本能，在展示权威的仪式、措词、手势、服装下，要能冷静地出手，才能成功，因此困欺君罔上而良心不安固然不可，一心以为自己理直气壮是要为民除害也必败无疑。
