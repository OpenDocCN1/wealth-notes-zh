# 如何党同伐异：
争取公司内部的同志以对抗异己

三女成奸

日本有句俗话叫：“三女成奸”，这句话和同性恋无关，意指女性爱聊天，三个女人凑在一起便可闹翻天（各位女姓学员，别忘了这是缺德讲座）。当这三个女人中的一人离开时，剩下的两人又要议论起刚走的那一位，而那一位在别处也会怀疑另外两人在说她闲话。有趣的是，“三男”照样“成奸”，各位男性上班族是否会在目送一位同仁离开后，压低声音要旁人“凑耳过来，闲言碎语一番”？总之，党同伐异的“成奸现象”是人类的通性（我可没说是通病）。

退一步说，即使自己公司的同事不爱在人背后议长论短，我们仍十分在乎别人如何评价自己，我们常担心自己没有别人。客套话所形容的那么受欢迎，甚至怀疑某个鞠躬成癖的人暗中大放冷箭。当同仁之间有明显的利害冲突时，上述不安更加噤人。

各位要搞清楚（老式的说法是：诸君，猛醒吧！）：学生时代早已离开我们上班族而去，不要向现实社会乞讨太多的友情及诚恳，学生时代每年缴完学费，你可以随意自己安排功课及社团活动，就是夜乘烛游也没人管你；和朋友交往可以率性而行，不用心机，只和自己喜欢的人在一起，如今环境不同了，
