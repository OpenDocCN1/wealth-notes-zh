# 在干坏事前，先找个替罪羊

嫁祸于人，亦即移祸于别人之意。目的是消灭对方或排除异己。嫁祸于人往往与无中生有是一对孪生兄弟。嫁祸，一种是自己有祸，转嫁他人，使自己逃脱罪责，转嫁给自己的仇人，则是一箭双雕。另一种是自己无祸，而欲加罪于自己的仇人，故意制造一些罪名转嫁到仇人的头上。

齐国有个中大夫夷射，有一次在王宫里参加酒宴，喝得大醉，靠在回廊门上。有个仆人名叫别跪对他请求说，“把您喝的酒给我一点儿好吗？”夷射叱骂道：“滚一边去，下贱的仆人也敢向贵人要酒喝。”别跪急忙跑开了。等夷射走后，别跪就在回廊门外洒了一些水，好像有人在此撒了尿一样。第二天，齐王看到了这一滩水，以为是尿，便问：“是谁在这里撒尿？”别跪回答说：“我没有看到，不过，昨天大夫夷射在这里站了一会儿。”当时，在宫廷内公共场合撒尿，是大罪。齐王便把夷射处以死刑。别跪因夷射不给他喝剩的酒并叱骂了他，他便设计嫁祸。加罪于夷射，使夷射被杀，可见人心之险恶也。

明代重臣严嵩是一个五毒俱全的家伙。他玩起来“嫁祸于人”术来，轻松自如，炉火纯青。

嘉靖年间二十九年六月，蒙古俺答部进犯大同。当时负责大同防务的是大总兵仇鸾。仇鸾的官职是靠贿赂严嵩买来的，他是个大草包，面对俺答部的进犯，惊慌失措，不敢抵抗，只好偷偷派出自己的亲信去见面俺答，贿以重金，求他不要进犯自己的防地而转犯他处。俺答收了仇鸾的重礼，果然引兵东去，攻打古北口。一路烧杀掳掠，直奔北京。
