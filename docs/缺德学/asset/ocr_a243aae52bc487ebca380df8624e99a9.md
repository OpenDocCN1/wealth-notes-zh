# 四、牢牢控制下属的利器

世界上有两种人既危险又可怕：聪明人和自作聪明的人。

聪明人对别人耍点魔术，迷惑人；自作聪明的人常对他自已变点戏法，懵自己。

当官的是聪明人。

你要官给官，要钱给钱，爱色给美女……但“士为知己者死”，吃人家嘴软，拿人家手软，受人恩惠者自然要受人驱使，效犬马之劳。

缺德者对付别人的手段花样多多，但也不过是“皇帝的新衣”。
