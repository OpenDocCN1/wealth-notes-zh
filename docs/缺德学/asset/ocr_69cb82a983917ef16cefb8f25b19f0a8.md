# 冒天下之不韪的缺德学

嘿！缺德，真缺德！有谁竟敢斗胆提出如此的学问来研究。你个人吃着国家的皇粮，是不是吃饱了饭没事干？说不定，有些读者一气之下要在读完本书后，专写一本极尽谩骂之能事的文章与我对垒呢。尽管如此，我还是不好再三推脱友人的“缺德”好意。于是，按照他的意思，我们贸然行事，树起了缺德学的大旗。接受这个观念虽然显得有些突兀，但却有一点一直令吾自信欣慰。那就是，缺德学作为一个严肃的社会话题，有史以来第一次登上了“大雅之堂”。而且，其内在的涵义并非如读者诸君想像的那么肮脏、卑鄙、无耻、下流。有了这样的“学”，还有什么不敢下笔的？我们愿意首先告诉读者诸君的是，缺德和缺德学并非一码事。缺德是一种行为，一种倍受谴责的不道德举止。而缺德学则讲的是知识体系，它研究的对象不是如何缺德，而是如何合情合理的避开缺德二字。也许有人会说，历史上好多成就大事、建造伟业的人物都是使用了缺德术才得以成功的啊！是的，您说对了，这是一个不争的历史事实。这也正是驱使我们动笔的催化剂。在中外历史上，大红大紫的千古风流人物云来雾往，其中不乏“不能流名千古，便要遗臭万年”的枭雄。究竟他们是何缘故而落得如此的结局呢？我们是不是应该从中汲取深刻的历史教训呢？固然，对一个欲成大事的仁人志士来说，历来都是：“多少事，从来急，一万年太久，只争朝夕。”但有效使用高超的战略战
