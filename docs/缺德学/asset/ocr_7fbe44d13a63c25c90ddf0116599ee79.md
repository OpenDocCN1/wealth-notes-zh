# 缺德夜话：
说尽身边无限事，唯有缺德难开言

您一定听说过这么一句话：“德不德，情来定”。说实话，道德听起来神圣，但做起来确实不那么听使唤。个中缘由还在于它属于情感、心性范畴的东西。有鉴于此，笔者就有了自己的缺德观。我这个缺德观就是要公然申明，本书是教育众人“如何合法缺德”的。我们不是伪君子或真小人，不能为达到目的就不择手段，但是当缺德者先采用卑劣的手段攻击时，应坦然以相同的手段进行自卫。既然敢这样冒天下之大不韪，自然就有一把他人所不知的金刚钻。
