# 离间对手和上级关系，
借上司之手将其整倒

春秋战国时期，与孙武齐名的军事家吴起，在魏国为魏武侯效劳，镇守河西，立了大功，为人很正直廉洁，治军有方。

魏相田文死，公孙得以继任为相，公孙无论从才能和功劳上都不及吴起，怕吴起取代自己的地位，非常忧虑，便与手下谋士商量除掉吴起，一个谋士献计说：“这很容易。”

“有什么好主意？”公孙问。

“你应当对武侯说：‘吴起是一个很有才华的人，应让他长期为魏国效力，但魏国小，而秦国强大，这样，吴起就可能背魏而去秦，实在令人担心。’

武侯一定会问你有什么主意可以知道他是否忠心？

“你就向武侯献计说：‘令他娶公主（武侯的女儿），如果他答应，他就是愿意长期在吴国效力，如果不答应，就会背叛魏。’

“如果大王同意这样做，你就让尊夫人（公孙的妻子，也是武侯的女儿）在府上摆出公主高傲的神态，故做看不起你，让吴起看，吴起的自尊心很强，心想娶了公主一定也会受气，这样他就会拒绝娶武侯的女儿。”

公孙叔照计而行，果然，吴起看到公孙叔窝窝囊囊的受公主的气，而又不敢反抗，一国宰相尚且受气，何况自己呢？就拒绝娶武侯的女儿。
