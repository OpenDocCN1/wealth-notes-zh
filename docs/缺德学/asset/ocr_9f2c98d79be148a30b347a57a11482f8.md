# 高明者杀人无须自己动手

杀人有贤愚之分：笨者杀人，直截了当的白刀子进去，红刀子出来，表面上既英雄，又痛快。可是这样一来，难逃法律的制裁，人家会说你是残忍暴戾。聪明者杀人不需 要自己动手，而是公开利用法律或假手别人去执行自己杀人的意图。这样，目的达到了，在仁义道德的面具上还可以多涂一层油彩，这就是借刀杀人。

费无忌借囊瓦之刀杀了对手郰宛。

战国时，楚昭王即位，以囊瓦为相国，和郰宛、鄢将师、费无忌同执国政。

是年，郰宛出征吴国，大获全胜，俘获兵甲无数。昭王大喜，将所获兵甲赐一半给他，每事必和他商量，宠幸无比。

费无忌心生妒忌，和鄢将师一起设计陷害他。于是，费无忌对囊瓦说：“郰宛有意请客，托我来转报，不知相国肯降临否？”

囊瓦立即回答：“既然相请，哪有不赴之理？”

费无忌又对郰宛说：“相国早有意在贵府饮杯酒，大家快乐一下，不知你肯做东道主否？现托我来问一下。”

郰宛不知是计，毅然答应，说：“我是他的下属，难得相国看得起我，真是荣幸之至！明天好了，我当设宴恭候，请你先去报告！”

费无忌又问：“既然相国要来，你准备送他什么礼物？”

“这倒提醒我了，”郰宛说：“不知相国喜欢什么？”
