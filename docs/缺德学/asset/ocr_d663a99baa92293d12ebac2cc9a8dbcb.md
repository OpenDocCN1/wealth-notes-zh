则是“循环型”的变形，只因多了一个 D，A 和 D、B 和 C 都有结盟的可能，理由很简单——每个人都容易对敌人讨厌的人或讨厌敌人的人有好感，有时这些人会提供珍贵的敌情给你，本型可称为“假性循环型”，不可和类型二弄混。
