# 开 讲 辞

各位优秀的上班族，欢迎参加本讲座，今天有这么多人共聚一堂，身为主办者的我不胜喜悦之意。

只是“优秀”二字并不是用来形容那种日夜不忘公司大恩、本分稳重得不敢擅自拉屎放屁、凡事公司至上、生平只爱读书及听音乐、乏味而不显眼的人。这点请各位记住。

我们生活在这个社会，个人凭才能争取财富，国家几乎不加干涉，放任自由竞争。外表上，公司像一道保证上班族的防洪波堤，可是我们除了化身为公司的一颗细胞，要对抗同业之外，仍得在堤内与同僚、部下、上司竞争，甚至要和一些模糊的评分标准比赛。“胜者王，败者寇”，当你在这些竞争中被打得落荒而逃时，前途便化为乌有。

我们常听说一些在校学习十分好的学生，踏入社会后却一蹶不振，其原因，即在于校园内外的价值观不同。本讲座无意否定学校师长的说法，充其量只是在他们所谓的“优秀”中，补充一些竞争活力必备的项目，如强悍、大胆等。我们认为厚脸皮能适度地使坏的人（其实不是人，是上班族），才有资格参加本讲座，欠缺这些条件的人（又说错了，是上班族，不是人）上课必毫无所获。以下详述各位学员应具备的条件。

+   A. 于社会大众所谓的“公司”的组织体中，提供精神方面为主的劳力，以换取每周或每月的报酬，并赖以维生。

+   B. 不满于公司对自己的评价及待遇。
