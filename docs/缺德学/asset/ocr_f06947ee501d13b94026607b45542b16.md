# 一 朝天子一朝臣

俗话说：“一朝天子一朝臣。”当权者要想有效地巩固权力地位，树立个人权威，就必须大量提拔重用亲信。任人唯亲，这是古今中外掌权者的通病。即使是那些贤明的君王也不得 不“明知其不可为而为之”。

一般来说，掌权者在用人时首先关心的便是对方是否对自己忠诚，才能倒 在其次。若是任用-一个颇能干但对自己怀有二心的部下，天长日久势必会大权旁落，这岂不是养虎遗患？因此，重用亲信，排斥异己，形成自己的一派政治势力，这也是统治者驾驭臣僚，树立和巩固个人权威的重要手段。

蒋介石用人，一般有两个标准，一是看对方是不是黄埔系，二是看对方 是不是浙江人。对自己的嫡系部属，蒋介石恩宠有加，常常委以重任。除非万 不得已，蒋介石不会重用非嫡系的人。在用人方面，蒋介石有其独特的方法。 在他看来才学固然是一个重要标准，而对他忠诚却是第一标准。
