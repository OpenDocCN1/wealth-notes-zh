# 缺德定律：
八仙过海，各显神通

有的读者在看了半天之后一定发闷：你说了那么多缺德之人的缺德事，我们一定不敢缺德了。可有一点我们百思不得其解，若是遇到了缺德人的挑衅，又没有一个讲理的地方，究竟怎么办呢？

以我之见，最好的办法还是“以牙还牙，以眼还眼”。这正如数学上的负负得正原理。否则，真是“秀才遇着兵，有理说不清”。比如说，当不人道的战争燃起之时，你还在那里讲什么仁义道德，那不是痴人说梦吗？倘若真是这样，你又陷入了不道德的境地。东郭先生和狼的故事人人皆知，狼无德，人也跟着瞎摆弄，怎能不令人发指？

说实在的，中国古代的所谓“圣贤”并不乏缺德带冒烟的主儿。然而，他们的贤明地位却从来没有动摇过。为什么？人家有谱儿。打了胜仗，得了便宜，还要卖上一段乖。而且，在名义上还落个“仁至义尽”的美名。“桃园三结义”是传颂了几千年的一段美谈。可有谁知道，刘备的心思并不只是一个简单的“结义”。他表面上仁义忠厚，可肚子里的计谋却并不亚于“诸葛亮”。只不过是他自愿摆出一副“大智若愚”的样子罢了。“不能同年同日生，只愿同年同日死”听起来固然是“义”字当先，也催人泪下。可是，我们也明明看到，在硝烟弥漫的战场，“大难临头各自飞”的情形也在所难免。无论
