# 若是上司打了你的左脸，就伸出右脸

官场凶险，有时需要暂时忍耐以便待机而发。“忍”是中国人为人处世的一项重大发明，传到日本，变成了“忍术”。在儒家哲学中，它是为实现某种远大担开而采取的一种自我克制、媒转退讨的谋略。在道家学说中，“忍”更是一种柔刚的武器，运用得当，可以克制一切坚硬办强的力量。俗话说：“忍字上有一把刀”，形象地说明了“忍”作为处世谍略的进攻性功能；它求不是逆来顺受，而是脉光养晗、待时而动。

中国作为一个具有上千年历史的文明古国，自古及今造就了无数个忍学大师。
