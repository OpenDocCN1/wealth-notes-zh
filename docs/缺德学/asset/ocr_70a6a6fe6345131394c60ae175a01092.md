# 二、踩着别人肩膀往上爬的伎俩

天大地舞台，舞台小天地。

人生如棋，芸芸众生，当是有输有赢。输不怕，怕的是输不起，输不起者常输，于是就开始笑里藏刀，或偷子，或捣盘，或悔棋无赖，或设陷阱等，令大丈夫防不胜防。而真正的棋手又往往被这些无赖弄得焦头烂额，甚至一败涂地。

# 美人的笑能埋葬豪杰

这是一种相当阴险的害人之术。

对于人來說，最天真的本能就是笑和哭。由于人有奸诈，此本能也就变了质，走了样，哭和笑，就有真和假。真哭或假哭，不外乎发泄一下内心的郁闷或博人同情；但笑却不同，有天真的大笑、微笑和媚笑等，其目的不是谋人之财，就是害人之命。因为哭的形象是丑恶的，笑是美丽的，人多厌丑而爱美，所以哭计上当少，笑计上当多。美人的哭能淹没英雄，丽人的笑也可以埋葬豪杰。笑的方式可以多样。总之，表面上装出谦恭敦厚，和蔼可亲，以假笑争取真笑，以假真诚争取真真诚，以假同情换取真同情，使对手不知不觉陷入术害之中，这乃“笑里藏刀”的妙用。

郑袖是楚怀王的夫人，长得漂亮，又聪明机智，很得楚王宠爱。
