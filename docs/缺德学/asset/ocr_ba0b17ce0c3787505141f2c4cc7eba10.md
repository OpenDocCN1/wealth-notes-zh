# 第一部 缺德学原理

。 缺德与缺德学大相径庭。如果把前者比作一枚地雷，那么后者就是一架探雷器。

缺德者，“既要做婊子，又要立贞牌坊”之谓也。古往今来的缺德者莫不“随风潜入夜”，玩着令人心惊肉跳的黑心把戏。

缺德学，明缺德之学也。君不见，缺德学领域的专家可以招收博士研究生，晋升缺德学教授的人也比比皆是。

缺德陷阱黑幕层层，缺德之术登峰造极。中外古今都不乏其人。但中西缺德者难分伯仲，亚当与夏娃亦各有千秋。

玩味“缺德”，把握“缺德”心态，慧眼识“缺德”。
