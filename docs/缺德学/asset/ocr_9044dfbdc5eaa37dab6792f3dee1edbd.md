# 缺德史话

以假乱真，制造骗局，达到目的的事例举不胜举。

东皋公运用此计，帮助伍子胥躲过了楚王的追杀。

伍子胥在驿馆听到楚太子建被杀的消息，心惊肉跳，急忙带着建的儿子胜逃出郑国。又怕郑国来追，他们白天不敢露面，星夜赶路，慌慌张张来到陈国，准备到吴国去。

昭关（今安徽含山县西北）是两座山当中的一个关口，平时也有官兵把守。楚平王和费无极料到伍子胥准会到吴国去，于是特意派大将粝越带着军队守在那里。关口上挂着伍子胥的画像。对于这些，伍子胥一无所知。

伍子胥和公子胜来到昭关60里处的厉阳山，在树林中弯弯曲曲的小道上行走着。

忽然从树林中走出一个老头，上前作揖说：“伍将军上哪儿去？”

伍子胥急忙回答说：“老先生别认错了人，我不姓伍！”

那老人笑着说：“真人面前不说假话，我乃是扁鹊之弟子东皋公，一辈子给人看病，在这儿有点小名声，观已年老，隐居于此。”

伍子胥说：“先生有何指教？”

东皋公说：“前天我去给把守昭关的粝越将军看病，在关口上瞧见有张贴有伍子胥的画像。今天一见解你，就认出是你。这里不是说话的地方，请随我山后寒舍叙谈。”

伍子胥见东皋公诚心如此，就同公子胜随老人到他住的茅舍。

东皋公说：“昭关把守森严，公子如何才能出关，必想出个万全之策，不可贸然行事。”
