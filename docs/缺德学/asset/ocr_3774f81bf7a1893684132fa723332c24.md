# 大人不计小人过

高官、厚禄、美名，这大概是投身官场的人所追求的三大目标。君上对于臣下的安抚、笼络，一般说来，不外乎官职、钱财两种，但有时上级对下属不必付出实质性的东西，而只要通过某种表示、某种态度，便能给下属最大的满足，甚至会使他们产生受宠若惊的感觉，因而感恩戴德，更加忠心耿耿地为其效劳。

汉高祖刘邦当上皇帝后，封萧何为第一功臣。按照当时的礼仪，大臣在朝见皇帝的时候，要跪着进殿，入殿前要去掉身上的佩剑，脱掉鞋，在拜见皇帝时，要自报姓名，而刘邦却给了萧何这样的特权，这便是允许他“入朝不跪，剑履上殿，赞拜不名。”后来，这几乎成为对功臣优宠的一种通例。民国初年，袁世凯称帝时也学会了玩弄这种小手段。当时，许多部属和民国元勋都不愿向他下跪称臣，登基大典日益临近，如不很好地安排他们，可能引起不良影响。于是，袁世凯便顺水推舟卖了个空头人情，他下令开列一个名单，将自己的旧朋故交统统罗列进去，并封徐世昌、赵尔巽、李经羲、张霭这些昔日同僚为“嵩山四友”，让他们享受以下五项优待条件：一、免其称臣跪拜；二、赏乘朝舆，到内宫换乘肩舆；三、皇帝临朝时，得设矮几赐坐；四、赏穿特种朝服；五、每人给以岁费 2 万元。然而，由于袁世凯恢复帝制不得人心，这些旧属亲友大多都采取了不合作态度，袁世凯耍弄的这种小手法最后还是落了空。
