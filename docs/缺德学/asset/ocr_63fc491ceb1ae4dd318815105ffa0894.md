# 缺 德 学

和士开是南北朝时北齐武成帝高湛的宠臣。他虽然身居要位，却从来没有想过怎样为国为民做一两件好事，整天只想着往上爬，抓大权，保住贵盛的地位。因而竭尽全力和挖空心思获取宠幸。他的办法就是“导上为非”，引导高湛干些无道之事，不但言辞容貌和行为举止，都极其鄙亵，夜以继昼地寻欢作乐，君主不像君主，臣下不似臣下。甚至对高湛说：“自古帝王，死了都会变成灰烬，尧舜，桀纣，有什么区别呢！所以，陛下应当趁年轻及时行乐，好好享受，不枉过这一辈子。至于国家大事吩咐大臣去办就好了，何必自己亲躬呢。”做臣属的居然对君主说出如此的话来，而高湛皇帝对这些亡国丧邦的鬼话，不仅不感到恼怒或愤恨，反而乐意接受，并且果真去干，终日醉生梦死，不问政事，偶然坐朝，也是无精打彩，心不在焉，胡乱批几个字，便匆匆退朝。

后来，和士开又把这一方法运用到后主高纬身上，同样取得满意的效果。和士开的权势达到炙手可热的程度。

“导上为非”术用得登峰造极的莫过于仇士良了。

仇士良是唐朝后期的一名大宦官，他先后侍奉过六朝皇帝，专权达二十余年，一直居高位而宠幸不衰，他保权固位的秘术何在？仇士良晚年退休告老时，曾对前来送行的宦官们说：“你们想侍奉好皇上，讨个好前程，这并不难，我在宫中这么多年，总还有些经验之谈，你们愿意听我说说么？”大家一听，正求之不得，连声答应。

仇士良把他集多年经验而行之有效的秘诀，明白无误地告诉了他的门徒们。他说“你们侍奉皇帝，绝不能让他整日闲着。他一旦有空闲，就必定去看书，会见儒臣，结果就会采纳朝臣的规劝和建议，变得聪明起来，考虑问题也就比较长远
