# 正面进攻，不如暗中下手

明白了自己要竞争的对手，就要想办法将他整倒，在对方的势力很大，自己力量不足时，就不要正面与他争斗，而要暗中下手，这就如《孙子兵法》上说的“出其不意”，要从敌人没有防备，意想不到的地方进攻他。这样，你就一定能取得胜利。

武林高手决斗，讲究的是光明正大，而黑道上的不义之徒，从不讲什么仁义、道德，他们用的都是毒辣手段，或放暗器，或挖陷阱，在兵器上抹毒药等，这样一来，往往是武艺高强的正人君子打不过卑劣的小人。这些黑道上的不义君子，才是缺德的祖宗。

在政治斗争的大舞台上，奸佞权贵们很善于使用暗箭伤人的绝活，他们一个个心狠手辣，狡猾多端，而品行端正的正人君子则往往讲什么仁义道德，结果无不被小人陷害，或被置于死地，或不被重用。

在战场上，敌我双方进行激烈的战斗，勇敢的将军冲入敌阵与敌人做殊死搏斗，正当他集中全力对付来自正面的敌人时，他的战友——来自内部的仇敌却向他开弓射箭，在混乱中谁也不知道他死于自己的战友之手，甚至连自己也不知中了谁射的箭，看，这一谋术是多么狠毒啊！
