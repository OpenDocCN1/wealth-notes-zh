# 脚 蹬 两 只 船

赏与罚，这固然是掌权者驾驭臣下的主要手段，但也不可能每天施用，尤其是一些重大的赏罚，多用于非常之时、非常之事、非常之人。当权者与部属朝夕相处，如何在日常交往中牢牢控制住对方，这是一门值得研究的学问。

掌权者要想巩固自己的权力地位，维持部下对自己的忠诚，最关键的一点是要制造向心效应，同时防止产生离心效应。尤其对那些权力过重，有可能对自己构成潜在威胁的臣下，必须严加防范并采取适当措施加以牵制，以免造成尾大不掉、喧宾夺主之势。

中国历代官场都流行窝里斗的恶习，大臣之间为了争权夺利明争暗斗。如果掌权者能够巧妙地加以利用和操纵，便可收到意想不到的效果。
