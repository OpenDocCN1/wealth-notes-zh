# 缺德园里：

# 州官可以放火，百姓可以点灯

中国有句成语叫“只许州官放火，不许百姓点灯”。而这句话若是用在缺德园里就不那么恰当了。俗话说：“上梁不正下梁歪”。所以我们说缺德大观园里什么鸟都有并不过分。大智、大勇、大权者有，奇娟、奇伶、奇阄者也不乏其人。

缺德这玩意儿似乎没有专利，什么人都能做。而且，也没有时间限制，今人古人都能做。说得宽泛些，也没有地域限制，中外各地无不有之。列位听着，下面我们——说来。

一个仅有小聪明的人尽管缺德，但他“缺”不过一个具有大智慧的人。因此，我们的话题不免从“领袖”开始。毕竟，衣服的“领”与“袖”总是最为先烂的地方。

大家一定听说过“指鹿为马”的成语。我总觉得这个成语里讲的人物赵高是一个极为缺德的奸人。说的是秦朝二世皇帝的时候，丞相赵高想造反，又怕别的臣子不附合，就先试验一下。他把一只鹿献给二世，说：“这是马。”二世笑着说：“丞相错了吧，把鹿说成马了。”问周围的人，有的不说话，有的说成是马，还有的说成是鹿。事后，赵高就把说成是鹿的人杀了。固然，在他之前的商纣王等领袖型人物也很缺德，但相对而言，赵高的“黑”与“厚”更高一筹。依笔者之见，他是中国缺德史上最为值得大书特书之人。所谓的心狠手辣，所谓的颠倒黑白，所谓的丧尽天良，尽在其中。
