# 假作真来真亦假

真的就是真的，假的就是假的。这是一种客观现象。然而，判断真、假的主体是人，人的阅历是有限的，人的视野也是有限的，事事能明察秋毫的人是不多的。实际上，人大部分时候是糊里糊涂的。这就给那些奸佞邪恶之辈以假乱真创造了条件。

以假乱真，须在“真”字下功夫，要从各个细节做起，将假的做得像真的一样，以造成对方的视觉错觉，混淆对方的真假概念，使其模糊不清，即所谓“假作真来真亦假”。当然，也要讲究时机，时机不当容易引起对方的怀疑。
