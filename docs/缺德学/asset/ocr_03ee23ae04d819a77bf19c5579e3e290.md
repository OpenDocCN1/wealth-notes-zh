# # 无毒不丈夫

民国人物李宗吾先生在《厚黑学》中把古往今来成功政治家的为官秘诀概括为“面厚心黑”。

“三国英雄，首推曹操，他的特长，全在心黑，杀吕奢，杀孔融，杀杨修，杀董承、伏完，又杀皇后皇子，悍然不顾，并且明目张胆说‘宁我负人，毋人负我’，心子之黑，真是达到极点了。有了这般本事，当然称为一世之雄了。”

俗话说，量小非君子，无毒不丈夫。官场凶险，尔虞我诈，最忌讳的莫过于心存妇人之仁。想当初，若是项羽听从范增劝告，在鸿门宴上诛杀刘邦，也不会落得个自刎乌江的悲惨下场。一世英雄竟败在市井无赖手中，怎不令人扼腕叹息！

政治是最无情的东西，政治家对名利地位的追逐往往会导致人性的扭曲和变态，在他们的眼里，夫妻之情、骨肉亲情、朋友之情变得如此淡漠，统统成了他们手中猎取功名地位的工具。人性中最自私的一面在政治家身上表现得淋漓尽致，因为他们比一般人更为清楚，要索取就必先付出代价，舍不得孩子就打不着狼。
