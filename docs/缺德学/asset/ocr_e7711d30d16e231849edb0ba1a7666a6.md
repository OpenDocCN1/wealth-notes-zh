# 看不见的利益

法律只是道德的最后防线，没坐过牢并不值得炫耀，一个商场的老狐狸当然可以不犯欺诈罪，那就得证明他有犯意、有犯行、他的行为和不当利益之间直接的牵连关系，各位可以想一想，这有多难？任何有三年以上社会经验的人，都能说出一个吃暗亏的故事，如果他说不出来，可能是他不敢说，或者是他根本一直被蒙在鼓里，人世悲慘，莫此为甚！各位缺德的同志，有了以上的认识，我们发现：欺骗公司同仁的要领在于争取 “看不见的利益”，利益一旦隐形，犯意和犯行也就凭空消失，谁又抓得住你的小辫子？

所谓的 “看不见的利益”，就是 “有利的情势”， “情势”是一种不能作定量分析的能源，它常在紧要关头发生作用，平时闷不吭声，敌人不容易嗅出味道，一旦亮相，往往沛然莫之能御也。相较之下， “看得见的利益”就危险多了，如公款、总经理的女秘书、回扣、保险金等，弄得不好就成了如山铁证，抵赖不掉。所以，聪明的上班族在行骗时，要急于摆脱有形利益，想法子将它送给非敌非友之人，至于为什么不能送给敌人及同志，我希望各位自己思考一下。
