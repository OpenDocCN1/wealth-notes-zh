# 最好在上司作乐时打报告

皇帝老儿本来就是孤家寡人，可还有一些心术不正的臣子，绞尽脑汁，施展手段，将皇帝圈禁于深宫之中，阻断他与臣下的联系；斩断了他的臂膀，堵塞了臣下的言路，使君令不能下达，下情不能上通。这样，皇帝老儿便成了睁眼的瞎子，耳聪的聋子，对政情、民情全然不知，只能听任专权的大臣摆布、玩弄与欺骗。

赵高残害忠良，滥杀无辜，自知结怨甚多，害怕大臣入朝时在秦二世面前揭露他的罪行，于是他用“断臂去翼”的手段，使秦二世成了地道傀儡。

有一天，赵高对秦二世说：“天子之所以贵，就是因为臣下只能听到天子的声音，但是不能直接见到天子的面，所以天子自称为‘朕’。先帝在位的时间长，经验丰富，对群臣也都了解，所以群臣不敢在先帝面前胡说。如今陛下年纪比较轻，许多事情陛下还不很熟悉。在朝廷上面，对群臣奏事，举措如有不当，群臣就会立即发现陛下的短处，这就有损于天子的神明。今后，陛下宜深居内宫，臣下的奏章送来之后，可以和我精通法律的近侍商议之后，再发出诏令，这样，群臣们就不敢胡说，也可使天下都知道陛下的英明。不知陛下意下如何？”秦二世哪里知道赵高的鬼胎，还连连点头称是。从此，秦二世不再亲自出朝，会见大臣，只住在深宫内院之中，连丞相李斯也见不到皇帝。而赵高得以和秦二世经常议论朝政，所以朝中一切大事实际上都由赵高作出决定，许多不利于赵高的话和奏章秦二世根本听不到、看不到，赵高见此阴谋又获成功，便更
