# 吹喇叭抬轿子

为官之道，要善于察颜观色，投人所好。自古以来，都是有坐轿的，就有抬轿的，有吹喇叭的。喇叭吹得响，就可以获得主子的恩宠，得到好处。

。政治舞台上，也是这样。一个人做了官，他手下就要有一帮子捧场的人，这一帮子人也就是吹鼓手的角色。

这些吹鼓手靠吹捧的功劳，也可以捞个一官半职干干，享受荣华富贵。

自古以来，在官场上，官员之间相互吹捧，奴才吹捧主子，小官吹捧大官，都是司空见怪的事。在日常生活中，人们总是把“投其所好”当作一个贬义词。事实上，投其所好，曲意逢迎不仅是一种人际交往的重要手段，更是一门高超的做官艺术。

民国初年，曾两度任国务总理，叱咤政坛的政客靳云鵬，就有一段离奇的发迹史。靳云鵬早年家境十分贫寒，靠卖煎饼度日，由于人不敢出，他的母亲一度给人当奶妈。靳云鵬19岁那年，投人袁世凯的“新建陆军”，后又入随营武备学堂第一期学习。

段祺瑞当时任随营武备学堂的校长，二人有师生关系。后来，靳云鵬被调到段祺瑞手下任职，为了求升迁，靳云鵬细心研究段祺瑞的爱好，他发现段祺瑞爱下围棋，经常与幕僚王某对弈。
