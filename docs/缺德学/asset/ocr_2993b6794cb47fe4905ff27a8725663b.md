# 驾驭缺德：

# 山穷水复疑无路，柳暗花明又一村

人们在生活中常常有各种各样的无奈式感叹，其中“好人不常寿，坏人活百年”这句话就是针对缺德之人的一种诅咒。至少，他们很是不满：为何坏人还能活百年呢？恨不得他们即刻死亡的急切心情跃然纸上。当我们常常陷入缺德的圈套而不能自拔的时候，是否也会产生同感呢？遭遇缺德的时候，我们又该作何处理呢？

第一，“草木皆兵”法。在生活中，无论是出门在外，还是寓居家中，都需要有较强的防范意识。“人人都献出一点爱”是歌曲里的一个美好愿望，切不可简单地以为“人之初，性本善”。更何况，人之初，性本善，并不等于他一成不变。千万不要以为世界早已变成一个美好的乐园。警惕！您身边时刻会出现危险。所以，在精神上时刻保持高度的“紧张”，有百益而无害。1995年，公安部门破获了一起“黑衣人”的特大恶性杀人案。这名杀人犯心黑如炭，狡诈多端，用假身份证住进旅社，作案27起，杀死了25人。我们现在不去关心他是如何作案的，还是让我们先来看看其中的两位是如何幸免于难的吧。有这样一位青年，他带着女友出差，将女友安排在另一房间，他和“黑衣人”住在了一起。那位黑衣人几次和他套近乎，他都不予理睬。当天，他和女友上街买东西，回来后发现自己的枕头下面的身份证等物件不见了，立刻提高了警惕。夜
