# 上班族觉外精神考:

# 修练上班族觉外精神

# 风化作用

天下没有不散的筵席，换句话说，恶梦总会过去，本讲座已接近尾声。各位用功的上班族，必定已发现我们的精神在于“反抗”，不反抗无以知上班族受到有形无形的束缚。

在进入最后一讲之前，我们要谈一谈上班族的觉外精神，请各位继续张牙舞爪、呼啸叫好。

一般说来，上班族的生活没有什么高潮。除非特别好运或杰出，不可能平步青云或大发利市，地位和薪水都要靠长年累月的攀爬。上班族的宿命在于：不在长年累月之后，不知结局。而漫长的时间必然使各位有气无力，使各位成为规格化制品——一枚自傲或自卑的螺丝钉。我们把这三鼓丧气的过程称作“风化作用”。

从另一方面来看，一个大企业总是由极少数有个性的人去领导大多数的规格化人类，如此才能把活泼乱跳的人性集中用在同一个方向，这种制度上的要求使“风化作用”更为严重。

于是，各位也在相同时段穿相似的服装往返于家与办公室，你们看同样的电视节目，在同一个假日到郊外互相大眼瞪小眼。你们的学历、收入相仿，预计生相同数目的儿女，对黄色笑话感兴趣，不随便买陌生作家的书。这些就是企业成长的
