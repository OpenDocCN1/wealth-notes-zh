# 缺德丛话：

# 雾里看花花更花，水中望月月更月

鲁迅先生说过：几千年的中国文艺就是“瞒和骗”的文艺。如果不会和鲁迅先生打官司的话，我就要撩美一次：几千年的缺德历史也就是“瞒和骗”的伎俩之凝结。对此，我在上面已经作了一点阐述。在缺德丛话这一栏里，我所要谈的则是大逆不道之人的缺德美学观。或许，有人会问，你是怎么知道的，莫非你和这些缺德者有联系。诸位，请听我言，不管个人缺不缺德，倘若我连这个都看不透，又怎能向各位夸下海口，大谈特谈缺德学？大凡在世上干一件事总要讲究个“门道”。俗话说得好：“不会看的看热闹，会看的看门道”。

干一行，精一行。缺德者亦是如此。日积月久，相互交流，慢慢儿就形成了一门学问：缺德学。缺德学学会还经常举行学术讨论会，定期召开年会，时不时慷一次国家之慨，吃一吃缺德饭，这也是常有的事。这事在古代可不就有？只是形式略有不同而已。过去，我们的传统习惯就是为名人讳，“讳”得连名字都找不到。即使找到了，也是言过其实。一般来说，古代之人的盖棺论定多数是好就好得不得了，坏就坏得不得了，很少有客观、公正、一分为二的分析评定。这并不是有德的表现，相反，在我看来，倒是一种缺德的表现。本来，缺德事就见不得人，所作所为者想尽办法要把它遮掩住，而我们还要使劲地为他打掩护，这岂不是为虎作伥？事实上，所谓的贤
