# ### 第二部 缺德史话

当心被别人治理。

有的人略施小技，便可弄得尸横遍野、血流成河。甚至在他挥舞屠刀杀人之时，被杀者还死心塌地高喊“谢主隆恩”呢！
拒绝小人，迈向生命的圆满，轻轻松松过一生。

+   - 一、讨得上司欢心的秘诀……（62）

穿鞋的人不一定在走路。狼在吃人时总要披上漂亮的羊皮外衣。真正聪明的人应该在不伤害他人的前提下保护自己，不足则近似近虑，有余则有奸臣之嫌。
对人，对己，做到洞若观火实在是不易的，所谓知人者智，自知者明，而达此境界者古今能有几人？
