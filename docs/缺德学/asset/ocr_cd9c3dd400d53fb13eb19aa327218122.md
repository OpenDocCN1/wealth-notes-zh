# 缺德原理：
随风潜入夜，润物细无声

我们讲解缺德原理，目的在于小心您身边潜伏的缺德之人。一般来说，缺德“圆舞曲”有这“三步”。

第一，缺德事发生时，总是“这里黎明静悄悄”。密则事成，这是缺德者必须首先学会的讲义。您没有听说过“当面说好话，背后下毒手”的顺口溜么？它其实就是笑里藏刀、面善心恶、两面三刀、阳奉阴违的代名词。所以，当心您身边对您点头哈腰、阿谀奉承的小人是很有必要的。对于您的领导，他当面批评您并不可怕，他立即反驳您的批评也并不值得大惊小怪。最可怕的还是“小鞋”，而且您要记住，不少上司是秋后算账。“马上就给你小鞋穿”的领导并不是多么可怕的领导，但是在中国这种领导是不会干多长时间的。正直的人官运不佳，奸诈的人平步青云。像包大人这样的清官，在中国历史上毕竟寥寥无几。

蚊子叮人总是在晚上或是黑暗的角落。见不得人的事也总是在隐形状态下密谋。而且这些缺德大人们都有一种天生的良好素质：即使做了亏心事，也是脸不红，心不跳。秘密的意义也正在于此。人们常说某某会做官，做人“滴水不漏”。可人们哪里知道，在“不显山，不露水”的背后又有多少奸头滑脑的事从我们身边溜走呢！秦桧为把立下汗马功劳的岳飞置于死地，便以“莫须有”的罪名将其打入死牢。奸臣诬陷忠良，天
