# 如何欺骗同仁：
尔虞我诈在人际竞技场
干净的白衬衫

我们在上一讲推出“如何谋杀公司同仁”，有许多非上班族来信指出那简直是开玩笑，本人不想多作辩论，以遵“天何言哉”的古训。

倒是这种“不相信上班族会杀人放火”的心理，颇值得研究。换句话说，局外人（甚至上班族本身）对上班族已有了刻板印象，我们不妨举出两个讯息来源当例子。

一、电视广告片——上班族漫步在压力隔间的现代化办公室中，谈笑间咬一块饼干，惊喜地点头。由他们匀称的身材和纯真的笑容看来，这些人满面笑容，和蔼可亲，不可能有置公司同仁于死地的野心。

二、早晨七点半到八点的公共汽车——上班族抽动着浮肿的眼皮，有的陷入半昏迷，有的索然咬一口站牌旁买来的饭丸，一个个獐头鼠目，就算有杀人的念头，也没有胆子下手。

总之，公共场合中的上班族不是开心得离谱，就是窝囊得气人，这些都不是江洋大盗应有的身段。

说到这儿，各位杰出的上班族恐怕要微笑了，男的抚弄下巴，女的掩住小嘴。不错，我们上班族是现代社会的中坚，讲究的是智慧型犯罪，古代血溅五步的那一套未免脏了我们身上
