# 前言

揭示缺德是从政者的利剑；
提防缺德是经商者的坚盾；
识别缺德是安身立命的护身符。

《缺德学》，一本绝世奇书。

不是冲动，更不是为了标新立异，而是寻找人类自古以来理藏在“光明”深处的幽灵。

上下数千年，大千世界，色彩缤纷，鱼龙混杂，胜败之道难以料说。所谓人世间，大鱼吃小鱼，小鱼吃虾米，虾米啃泥巴，一片混杂。滚滚红尘，决不是人类理想中的桃花源；月白风清，香烟缭绕的幽谷独处的生活也只是难以觅寻的鸿爪。

天下熙熙攘攘，尔虞我诈，彼此倾轧，演出了多少人间惨剧。面对现实强烈的竞争，任何人都在迫切渴求赢的策略。然而卑劣小人往往设下许多埋伏，增设许多障碍，既有刀光剑影，还有温柔陷阱，“随风潜入夜，润物细无声”，让人防不胜防。因此，在得意者盈盈笑脸的背后，常常演出“缺德”的叫骂。

缺德现象，自古而然。不仁不义的奸佞小人虽然不可用繁如群星喻之，然而鬼域之后，黑影幢幢。颠倒黑白、混淆是非者有之；阳奉阴违、两面三刀者有之；勾结党羽、狼狈为奸者有之；栽赃陷害、反口噬人者有之。缺德者搞鬼有方，诡计多端，花样万千；缺德手段登峰造极，令人深恶而痛绝之。

厚黑大师李宗吾说：“古代成为英雄豪杰的人，不过脸厚心黑罢了”。其实，中国一部二十四史，哪一页不欠下血泪斑斑的缺德账？历史更迭，豪杰辈出，又有哪一个不是精于算计的？又有哪一个不是使用诡道才成功的？

无赖小人刘邦虽无学无才，却用阴谋诡计成为一代帝王，谁说他不是缺德高手？一代明皇唐太宗李世民名垂青史，再听听幽光昏暗处无数冤魂的控诉，谁又能说他不是缺德大师？屈指数来，又有谁能把这缺德账算个清清楚楚、明明白白？

我不禁要问：为什么骗子能得手？为什么小人能得势？为什么无赖能挣大钱？为什么伪君子还能当官？……

“黑夜给了我黑色的眼睛，我却用它来寻找光明”。

于是，我开始苦苦思索，苦苦探求，四十多年，惨淡经营，发明一部敢冒天下之大不韪的奇作《缺德学》，为善良的人提供一部警世之作，使您未雨而绸缪，看穿缺德小人的嘴脸及伎俩，明察世态，烛破奸诈，轻轻松松过一生，而并非鼓励人们去缺德。

《缺德学》与缺德大相径庭。前者让你谨防缺德陷阱，后者说的是陷阱黑幕，如果把缺德比作一枚地雷，那么《缺德学》就是一架探雷器。

《缺德学》，一部人类隐秘历史的大曝光；
《缺德学》，一部人类灵魂再铸的金钥匙。
《缺德学》，给您穿上防弹衣，让您在变幻莫测的世界中经风雨、见世面。

多少事，从来急。时代的车轮在飞速旋转，多长个心眼吧，当心别人把您活埋！

### 冒天下之大不韪的缺德学

嘿！缺德，真缺德！有谁竟敢斗胆提出如此的学问来研究。你个人吃着国家的皇粮，是不是吃饱了饭没事干？说不定，有些读者一气之下要在读完本书后，专写一本极尽谩骂之能事的文章与我对垒呢。尽管如此，我还是不好再三推脱友人的“缺德”好意。于是，按照他的意思，我们贸然行事，树起了缺德学的大旗。接受这个观念虽然显得有些突兀，但却有一点一直令吾自信欣慰。那就是，缺德学作为一个严肃的社会话题，有史以来第一次登上了“大雅之堂”。而且，其内在的涵义并非如读者诸君想像的那么肮脏、卑鄙、无耻、下流。有了这样的“学”，还有什么不敢下笔的？我们愿意首先告诉读者诸君的是，缺德和缺德学并非一码事。缺德是一种行为，一种倍受谴责的不道德举止。而缺德学则讲的是知识体系，它研究的对象不是如何缺德，而是如何合情合理的避开缺德二字。也许有人会说，历史上好多成就大事、建造伟业的人物都是使用了缺德术才得以成功的啊！是的，您说对了，这是一个不争的历史事实。这也正是驱使我们动笔的催化剂。在中外历史上，大红大紫的千古风流人物云来雾往，其中不乏“不能流名千古，便要遗臭万年”的枭雄。究竟他们是何缘故而落得如此的结局呢？我们是不是应该从中汲取深刻的历史教训呢？固然，对一个欲成大事的仁人志士来说，历来都是：“多少事，从来急，一万年太久，只争朝夕。”但有效使用高超的战略战术，却不是缺德的表现。即是说，只要不是小人奸计，都将排除在本书之外。

不知道读者诸君是否已经明白了我的意思。反正缺德学这样一门学问，和模糊学、糊涂学、混沌学等相似，皆是对历史或社会现象的透视与暴露。模糊学意在让人更清楚一些问题，而不是对问题本身越来越搞不明白。比如，模糊数学讲的就是怎样让人思路更清晰。这里，我们也要提前告诉读者的是，缺德学不是为缺德而缺德，读完本书，缺德之人不会有什么长进。我们倒很希望芸芸众生从中获得一些人生智慧，藉此防范于未然。俗话说得好：“害人之心不可有，防人之心不可无。”进一步说，嘘！悄悄地告诉你，在世风日下、人欲横流的今天，无论是在商场上角逐，还是在政界当差；无论是在人际交往的生活中，还是在花红柳绿的情场上……善良的人们，请您多长个心眼。

当然，对一些经常陷入陷阱的人来说，本书的出现可能显得有些姗姗来迟。在此，我们要深情地说一声：“抱歉，让您久等了！”但愿下面我们的“危言耸听”能让诸君弥补您那“等待的太久太久”的饥渴热望。

书归正传。鉴于“名不正，言不顺”的考虑，我们不妨先给“缺德”一词正正名。我们知道，一个人的名声与其道德素质有着极其密切的关系。因此也就有了“有德”与“无德”之分。不言而喻，“无德”就是缺德的一部分。但是，这里有必要说明的是，它们两个并不是半斤八两的关系。在某种意义上说，“无德”的意义意指一种没有付出行动的客观叙事，而“缺德”则是指一种已经造成严重不良后果的恶劣、卑鄙的行动。譬如说，“女子无才便是德”讲的就是这样一种情况。“女子无才便是德”，那要是有“才”呢？按照这一逻辑推演下去，很可能就是“女子有才便无德”。很明显，“无德”是一种静态概念。千呼万唤始出来，及此，我们该触及“缺德”了：“缺乏好的品德。指人做坏事，恶作剧，开玩笑，使人为难等”。这是颇具权威性的商务印书馆《现代汉语词典》的注释。平时我们日常生活中经常所说的“缺德话”、“缺德事”、“真缺德”等口头禅都是重现眼前事实的。

或许这是每一位作者的习惯，每做一件事都要事先来个“留下真名从头说”。您说我“既要做婊子，又要立牌坊”也好；说我如同鲁迅笔下的哪个喝于人家的血，还要发一大堆议论的蚊子也好；说我“写缺德书本身就缺德”也好，反正这次我已横下一条心，让“缺德学”走向角角落落。胡适博士有一句话颇为适合我们的心情：“既然做了过河卒，只得拼命向前了。”我想，当年胡适一帮人搞新文化运动时那种惴惴不安的忐忑心理一定和“寡人”有相似之处。

### 缺德物语：我的缺德学观

不同的事物有其不同的特点。而对人们来说，即使是对同一个事物，从不同的角度去看它，又会得出截然不同的结论。就为人熟知的缺德观来说，可能也是仁者见仁，智者见智。即是说，一个时代有一个时代的道德。比如，很多在古代看来不道德或是缺德的事在今人眼里都成了过眼烟云。这就是哲学上所说的事物的相对性。古代人的婚恋凭借的是“父母之命，媒妁之言”。若是有谁违背了这个道德武器约束下的规定，随随便便的自我定情约会，那必定会被骂作大逆不道、为非作歹的缺德鬼。相反，今天若是有谁硬是逼婚强娶、拆散一对好姻缘，同样也会被人们指责为不尽情理的“半吊子”。“半吊子”者，“二百五”之谓也。依笔者看来，缺德的意义很难在此解释清楚。这并不是写书的人耍滑头，或说缺德学的书还未出就开始缺德了。因为照我的想法，缺德的可塑性比任何品性都来得复杂。缺德是一种品性，它与高尚、美德、情操无缘。正因为如此，在中国这样一个一向以道德为第一准绳的国度里，缺德之人在所难逃。人们认为道德最高尚的人就是最伟大的人。“万恶淫为首，百善孝为先”从正反两个方面述说了道德的重要性。但就是这两句话是否就说得天衣无缝呢？“万恶淫为首”一古脑儿地将人性的本能给轻易否定了；“百善孝为先”则置“忠”的做事原则于不顾。难道说这就是道德高尚与道德低下之区别？可能问题并不如我们想像的那么简单。当然，人们对

您一定听说过不少关于仿造假药、假酒赚黑心钱的缺德事件。那些丧尽天良的人为了个人利益真是大胆妄为。可是，您是否知道，还有人曾打着锣鼓去深表谢意呢！何以故？原来，两口子生气喝了假农药安然无恙。“谁能告诉我，是对还是错？”这里，笔者并没有为造假者开脱的意思。我只不过是想借此说明道德不道德亦有偶然性。好的动机不一定有好的结果，好的结果也不一定就是好的动机所致。说来说去，缺德学就是这样不可思议！
