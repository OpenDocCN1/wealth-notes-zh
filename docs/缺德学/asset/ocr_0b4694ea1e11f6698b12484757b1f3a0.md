问大人，我们怎样办才好？”

鄢懋卿见了海瑞的报告，知道海瑞这是有意在与自己过不去，心里恨得咬牙切齿，但又知道海瑞是个铁面无私的知县，弄得不好自己难以下台，所以只好在海瑞的报告上愤愤写下几个字：“当然照正式通知办事。”

后来，鄢懋卿干脆绕道而去，没有进入严州地界——他怕去碰海瑞的软钉子。

海瑞的软钉子并不软，不可一世的鄢懋卿碰得疼痛难忍，却又无处发泄。海瑞的高明之处在于：利用鄢公的表里不一，以子之矛，攻子之盾。

# 茅坑里也塞个亲信

俗话说，物以类聚，人以群分。封建官场派系林立，臭味相投者往往勾结在一起，狼狈为奸，党同伐异，搞得官场乌烟瘴气。

明朝太监魏忠贤与他的阉党沆瀣一气，干尽了坏事。

明万历年间，朝臣分为两派。东林党和齐、浙、楚三党相互攻击又轮流执政。东林党人虽大都比较正派，对时局也有切中要害的针砭，但并无改革的有力措施，而且门户之见甚深。凡不合己见的，皆认为是异党，一旦掌权便大加贬斥，这就势必把一些人推到了对立面。天启初年东林党拥立朱由校登基并再度掌权。被排斥的官员为保全自身，便纷纷依附了魏忠贤。魏忠贤早就对东怀恨在心，因为东林首领刘一燝、杨涟等曾力主客机出宫并弹劾过自己。如今见朝中两派不和，乐得趁机张网抛线，搜罗党羽，壮大自己的势力。
