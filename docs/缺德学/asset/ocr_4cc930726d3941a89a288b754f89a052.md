# 第四法——用问句和上司交谈

上司之所以是上司，在于他常要站在高位下判断，因此我们要大量提供各种问题让他烦心，再琐碎的小事都采取恭候圣裁的䩄略。譬如说：

> “您要搭计程车去还是坐公交车？”“中午要在轻松餐厅吃台菜，还是舒服饭馆吃火锅？”

当然，婆婆妈妈久了，难免惹火对方，上司会说：“随便。”这时你就要不愠不火地说：“火锅的确不错，现煮现吃，滋味好，可是偶而吃一点道地的地方小菜也无妨，萝卜干炒蛋您喜欢吗？花生炒小鱼干也是一大美味。对了，或许我们去吃日本料理？”

在任何人耳中，你的话都是关怀备至，可是由于上司是一种对问句敏惑的动物，这种说话方式保证能大耗他的元气。不知大家同意不同意？嗯？啊？呢？咦？

# 第五法——把上司捧成明星人物

捧上司要注意不要在部门内捧，否则会引起同事的反感。同时，非必要也当避免直接向上司拍马屁，马屁必须转变，才能存其声而去其臭。

把上司捧成明星人物的目的在于激发和他同级的主管的嫉妒心，同时也激发上司和上司的戒心。试想，当大家到酒廊、饭店吃喝作乐时，娇滴滴的副理说：“咦？你们公司的某某科长怎么没来？”随后又到地下舞厅去，老板又问：“咦？你们的某某科长怎么没来？”有心人听在耳中，心中滋味并不好受。
