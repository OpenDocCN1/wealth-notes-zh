# 少女用“缺德”法报父母之仇

清朝，有一个恶霸横行乡里。为富不仁，他将一家夫妇二人害死，霸占了这对夫妇的小女儿。

这个少女非常聪明，操持饮食服用之类十分得手，将那恶霸侍候得舒舒服服，恶霸非常高兴。这个少女不惜一切代价迎合恶霸，凡是可以博得他欢心的事，甚至冶荡押蝶，无所不至。人们都认为这个少女没有良心，忘了父母的深仇大恨。

时间一久，恶霸对少女言听计从，受其蛊惑很深。于是，少女就开始引导他生活奢华，把他的家产败去了十分之七八，又在他的骨肉间进谗言挑拨离间，使家人如仇敌。

恶霸过惯了奢华的生活，但他的家产愈来愈少，以致入不敷出，于是少女就怂恿他私通盗贼，干些杀人越货，拦路抢劫的事。终于，此人以杀人而被偿命，恶霸被斩那天，少女不去哭她的丈夫，却背着一桶酒，祭奠她父母的墓，她说：“父母二老是在梦中惊吓我，恶狠狠地震要打我似的。现在知道了我当初为什么要那样作吗？”人们开始知道她是蓄志报仇雪恨。

试想，在封建制度下，一个弱女子，呼天天不应，呼地地不灵，手无缚鸡之力，又出身贫寒，唯一的资本就是自己的身体。面对着杀父仇人，却强做欢颜，此少女心中是何其痛苦啊！但她忍辱负重，巧设陷阱，步步引诱，终于报了父母大仇。
