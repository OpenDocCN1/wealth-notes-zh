# 三、保住既得利益的妙法

人怕出名猪怕壮，这不是吃不着葡萄就说葡萄酸。

功高震主。当你最得意洋洋之际，也是危机重重之时。既可以让你荣华富贵，也可以让你家破人亡。所以得意莫忘形，得势需知退。否则，“机关算尽太聪明，反误了卿卿性命”。

> “祸兮福之所倚，福兮祸之所伏”。

# 趁着走红快退伙

俗话说，功高震主。大臣权势声望最高的时候，往往也是危机最重的时候。因为在封建时代，皇帝掌握了臣子的生杀予夺之权，他既然可以让你荣华富贵，那么他就可以让你家破人亡。作为万人之上的君主，他最担心的是大权旁落，你的权势大了，各种流言蜚语也来了，君主的疑心也来了。所以为官者，对付缺德的君上，切记老子所说的一句话：“祸兮福之所倚，福兮祸之所伏。”功成名就之时，也是退步抽身之时，千万不要被胜利冲昏了头脑。

范蠡和他的朋友文种不同的结局则充分说明了这一点。

越王勾践在范蠡和文种的帮助下灭了吴国，为了庆祝胜利，下令在国内设置高台，在上面大摆宴席，宴请各位有功之臣。
