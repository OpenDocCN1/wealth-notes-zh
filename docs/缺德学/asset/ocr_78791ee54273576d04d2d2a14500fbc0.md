# 做上司肚里的蛔虫

心理学认为，人们意见、观点一致时，彼此就会相互肯
定，反之，就会相互否定。所以，那些缺德谄媚之徒，在谄媚
巴结他的上司之前，总是先细细揣摩他的喜好，然后尽量迎合
他，满足他的欲望。更妙的是，有的谄媚高手还能够抢先一
步，将上司想说而未说的话先说了，想办的而未办的事先办
了，把个上司乐得美滋滋的，自然，上司回报给下属的东西总
是沉甸甸的。

清末巨阉李莲英可谓揣摩高手。

自进宫廷当了小太监后，李莲英从来不放弃任何一个巴结
上司的机会。在一个偶然的机会，他从同乡太监沈兰玉的嘴里
得知，西宫的懿贵妃因梳头太监们梳不出时新的发式，经常呵
责他们；而深居宫廷之内的梳头太监们见闻狭窄，只会梳一些
传统的发式，面对着骄横逸纵的懿贵妃，无法讨得她的欢心。
李莲英得到这个信息后，经常借机溜出宫外，悄悄地跑进妓
院，观察着妓女的各种新颖、时髦的发式，偷学梳头的技术。
