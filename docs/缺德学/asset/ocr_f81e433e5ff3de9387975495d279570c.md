# 拆散对手的同盟

挑拨离间，即是当政治对手比较相当，从正面进攻难以奏效时，便着意从对手内部打开缺口，设法让对手和他的盟友相互猜忌，相互拆台，以至将他的盟友从他们内部拉出来，削其力量，孤立其身，然后轻而易举将其击败。

挑拨离间之术关键在于找准能使对手同盟破裂的缺口。此术常为那些缺德小人所运用。

东汉末年杨彪将此术用到李傕和郭汜身上，一针见血。

公元192年，王允、吕布等合谋诛除了董卓。接着，便在朝中捕杀董卓余党，并且宣称凡是董卓的旧部都不能赦免。这引起了董卓的部将的不安。于是以李傕、郭汜为首发动暴乱，几天之间，攻下了长安城，杀死王允，控制了汉献帝，把持了朝政。随后，李傕、郭汜在长安放纵兵士大肆抢掠，居民死伤数万，长安城中米价达到五十万钱一石。以太尉杨彪、司马朱隽为首的一班元老重臣便图谋除掉二人。但由于二人勾结甚密，势大难图。因此，怎样拆散二人的联盟就成为一个难题。

一天，杨彪与朱隽计议说：“李、郭二贼图谋不轨，他们往来密议，一定在夜间。我听说郭汜的妻子十分妒嫉，让一个人告诉她，说郭汜与李傕的妻子有染，她一定会禁止郭汜与李傕往来。然后，再暗中派人召曹操入朝勤王，乘二人分裂的机会攻打他们，一定十分容易。”
