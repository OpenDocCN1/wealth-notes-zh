金庸小说中的令狐冲擅圆月杀法，但心中还有一片温暖，本型人物却极冷漠。患有精神阳萎的虚无主义者对一切都不感兴趣，请辨明此毫厘千里之差。各位可以把他当成极端的利己主义者，这种人一旦感到生存受威胁，常利无反顾，行事不拘下流危险之至。

**[对策]**    使他由假性虚无走向真性虚无的不归路。打击他的信心，多称赞和他有相同特长的人，派个稍难的工作给他，不管成果好坏（多半好不到哪儿去），挑些毛病数落他，使他自觉平庸，失去所有热情，进而成为我们的同类。

# 第五类 寄生虫类

**[症状]**    算盘珠子，一拨一动，一定要听到命令，才采取行动。绝不主动独断，买条领带都要拉人同行为他出主意。他并无心尊重别人的意见，潜意识和浮意识都想推卸一切责任。和这种人合作很愉快，因他百依百顺，但是遇到事急事多之际，他会心平气和地撒手让你一人承担。

**[对策]**    劝他从军。

# 第六类 闹钟型
