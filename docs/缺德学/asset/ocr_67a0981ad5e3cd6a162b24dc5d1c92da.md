# 好人要帮，坏人也要帮

不偏不倚，亦即中庸。这是儒家思想的精髓，也是不少人
做官处事的法宝。持中庸之道，不得浮躁，超然于派系斗争之
上，不过分亲谁，疏谁；持中庸之道，良心不能大大的好，见
人搞阴谋活动，要装瞎子，听人拨弄是非，要装聋子；持中庸
之道，也不得讲原则，好人要帮，坏人也要帮。持中庸之道，
得削磨棱角鲠没个性，似人似鬼，任人评说；持中庸之道，也
不等同消极软弱，见利得当机立断，毫不手软，但进得快，退
得也要快，见好就收，知足常乐。

由此以来，你的敌人就少，你的形象就好，你的官位就
稳。

不信，就瞧瞧徐世昌。

国务总理；段其瑞执政时，他做过总统。可以说，他是个地道
的不倒翁。
