# 走夫人路线

在中国政治舞台上，像吕后、武则天、慈禧这样直接站在前台执政的女人不多，但隐身幕后对朝廷政治施加影响的女人却大有人在。当然，她们都是与皇帝关系密切的人，或是为皇帝宠幸的皇后、妃子，或是皇帝喜爱的公主，或为皇帝信赖的奶奶。几乎可以说，在中国历史车轮或前或后的运转中，或隐或显的，总可以发现一些女子的纤纤玉手。

正由于这些女人能够对皇帝施加影响，所以那些溜须拍马者将目光盯在她们身上，设法取悦她们，借她们向皇帝吹枕头风以获得权势。这种手段我们把它叫做“走夫人路线”。

魏忠贤就是靠走夫人路线，获得大权的。

明熹宗的乳母客氏，是皇帝身边的亲信人物。魏忠贤便向客氏大献殷勤，立刻博得客氏的欢心。客氏本是魏朝的“对食者”。所谓“对食者”，是明朝宫中的一种惯例。明朝太监都要轮流在乾清宫值班。可是，他们又不能在宫中做饭吃。而宫女们却有伙房烧饭，于是太监都结交一名宫女，请她供给饭食。这种关系，被称为假夫妻，公开则称为“对食者”，也还有叫“菜户”的。按现在说法，就是“搭伙”的。魏忠贤过河拆桥，一下子抓住客氏，从魏朝手中夺取了客氏，两人成了“对食者”。魏朝对魏忠贤非常不满，但魏忠贤颇能笼络客氏，使客氏愈来愈疏远魏朝。他俩相处得十分亲密。魏朝为了争风吃醋
