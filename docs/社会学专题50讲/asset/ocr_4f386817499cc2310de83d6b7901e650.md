# ## 1.办公室政治并非是非黑即白

表面上看，办公室政治就是人和人之间的关系，问题肯定是出在个别人身上。这是最简单的逻辑，也是早期很多管理学者的方向，比如一名学者就提出，有些人就习惯把个人私利放在集体利益的前面。你不难看出，这种观点是从个体动机的角度分析办公室政治。

由这种观点催生的解决方案，就是HR在招聘时最好做充分的背调，调查什么？应聘者从一家公司离职的原因。他是从那个爱撩妹，办公室政治的？如果我发现问题有这种倾向，就会试图把他筛掉。

而不另一学者则认为，谁是组织。工作流程不够标准化，为政治提供了温度。解决办法就是做更多严谨的制度建没，比如制定更详细的员工手册。

这些做法都有道理，但都太简单了。办公室政治如果一定要靠制度控制，那我们还能做什么呢？下面我举个实际的案例，咱们来看一看真实的办公室政治是什么样的。

查尔斯·霍斯是嘉信公司的一名高级工程师。他开发了一种新型监测器，但是在内部招标中落败了。原因是销售部门为了风险过大。但霍斯坚信，当时销售部门判断出错，所以开始施展自己的办法说服高层。这里的办法是加引号的。

首先，他的下属公司中，未经许可访问了数量众多的文件机会，也就是潜藏在客户中。向它展示原始数据。天下没有不透风的墙，这种行秘很快被发现。

霍斯并不死心，他级把调查资料送到了公司年会上。按照规定，本来看是不被允许的。但公司的报纸系统并没有被公司禁止讨论，所以销售的高层看到了这份报告。经过讨论，他们否决了霍斯，营销部门，他们的论据，并且按照大会的规范，要求案例当场亲自演。

这是一个难得的验脸机会。因为以他的级别，本来要享受了这么高的待遇，却过这么一番。他将许多客户推荐给用可情多老板还没有。省部门了用究打打证明，把有能成大，尽到老板上卡，打老板证，明明不想再见这个计划了。

老实讲，换一个人，这就是最终的结果了。但察尔斯居然没放弃。老板的话不想看到第2个计划。这是带有两种理解方式。第一种是说，别是放屁，第二种正好相反，快快，让我看我快。意思。察尔斯是第二种理解，向同事进行解释，把老板的话从否定变成了商方宝创。

因为之前很不顺利，察尔斯决定加大幅度。首先，他开发或成是商成是具项目的优先级。商，避免报复，其次，为了让品能够顺利投放市场，他潜拉布萨后，把他先搞定了几个商，商，然后，让他游戏。之前设计的2个经理。请后，帮他完成绩效目标。条件是商自己保护神护。

这对察尔斯赢得了时间，当案子再次摆在老板卡德面前时，监测器已经占领了一定的市场。商，卡德不了解整个程后，态度也发生了转。这种监测器后来市大异。

# ## 2.办公室政治无法被根除

案例讲完了。察尔斯的做法应该被鼓励，还是应该被惩罚？不是很难回答。他的成功是大大缓解了，是，如果一个人都是捣，企业不要乱来，所以肯定要鼓励。但如果你要模仿，我确实促进创新，带来了绩效。甚至英雄主义，还能隐约感觉到这个人是个英雄。

我之所以要向你介绍这个案例，首先是因为它会帮我们。我们发现前提办公室政治，总会比较简单地作中个上非黑即白价值判断。但是察尔斯游走于可否之间行为，才是办公室政治真实

其次我想说服你，行为学对办公室政治看法。第一，我不认为，办公室政治的根除。根源，因为不是组织与个人的间，组织与资源之间的矛盾，也就是资源有限是办公室政治发生的本质说。

在嘉信这个案例里，察尔斯为什么要办公室政治，就是因为公司没有给到足够的额，空间去发展业务。我们平时观察到，权力的游戏就像分产，如果资够大。大家都心平气，想出各种手段，资源有限是办公室政治发生的本

第二，办公室政治是一种技能。换句话，不存在一种公司动机，就是搞平、究官文化，支持。采动机都不是为了这的用采。像察尔斯的人，采用政治手的目的，也是为事，可做。

个体倾向马基维利主义”的人特质，一句话，为达目的不择手段的程度。有高人，有高人，比较，到问题，就容易被用政治能。

好，既然办公室政治很根除，而且它是一个体行为，达目的，那怎么做，如果你管理者，该怎么办？我们需要办法去控制，把办公室政治维持在一个可控范围内，而不是一味避免它。这是你的手里握着一根诱绳，要做到的是组织运行在正确的。
