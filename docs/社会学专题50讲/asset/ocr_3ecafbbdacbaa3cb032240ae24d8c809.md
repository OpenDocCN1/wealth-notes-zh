# 21讲 | 共享心智：怎么管理组织的知识资产？

李育辉·组织行为学



你好，欢迎来到组织行为学的课堂。

如果前几讲，我们说的是如何管理组织中的一些看得见的东西，那么这一讲，我们就会来管理一个看不见的东西，那就是全体成员的知识、经验和思想。

我先问你个问题。如果说在农耕时代，人类生产就靠两样农作物；在工业时代，生产就要靠能源和矿石；那么到现在，对企业来说最重要的原材料是什么？

你一定可以想到，是知识，它是比设备或者资本更重要的生产要素，知识领域有个热门话题就叫知识管理，探讨企业如何把员工的知识、经验、教训组织起来。

知识管理到底该怎么做，这一讲我们就来谈谈。

# 1.使方法的缺点

很多人听到这里，第一反应就是：记下来呀。这真是太有逻辑和管理了。记录一个人，通常是人力负责或者信息部的负责人，组织大家集合，把经验写下来，做成大集合，之后，企业会建立一个数字系统，存储这些文字资料，并且发动大家来写。写三、四周，写满两三个月的时间，汇总八九千条。

听上去顺理成章，大家也都这么做，但我告诉你，这是组织行为学家最不推荐的做法，为什么？有三个关键问题你一定会遇到，最终会把这件事变成一个面子工程。

第一，因为你让半强制的方式让大家贡献经验，员工看不到做这件事对他的私人价值，那就会，他不会自断，「别人学会了就可以取代我了」非常可能。这种情况下，汇报上去的往往是一些不太核心的知识。

第二，很多知识不能用文字准确表达和转换，它们叫做隐性知识。比如一个销售如何通过电话和面谈判断客户的核心想法，这种经验表情，判断企业的核心经验都是隐性知识，你怎么用文字记录？

第三个问题最关键，就是任何知识和经验，一经文字化传播，就变成了确定的信息，这就没了市场里面的变数。我们都知道这种概念，文本下发下了一大堆字和脚本，大家根本看不懂，要么就是跟本资料，反正效果都不是很想。

总结这三点你会发现，单纯用文字系统记录知识，知识出来的不是知识管理，而是「岗位化知识的」。员工正确虽然可以这样想，但知识管理没有这么简单。

# 2.共享「知识地图」

那么怎么避免这三个问题？我们来看。表面上，知识管理就是收集，储存，共享有价值的信息和经验。咱们再往下思考一层，这信息的目的又是什么？归根结底还是为了方便员工学习，更好地解决问题。

既然把知识以文字的方式搜集、整理到系统一直留在员工手里？我们不可能要求员工都能随时看到，那谁能准确地找到掌握知识的人去咨询。如果这件事能做到，效果是不一样的。

换句话说，组织不为大家共享知识本身，而是共享一个结构性的「知识地图」。沿着这份地图，每个人都能找到对的人，同时可以很好地学习、解决问题。

# 3.共享心智实验

这能做到的？当你向我介绍了个实验。有一位叫马丁医生给医疗团队做过本研究知识管理的研究，他获得成果很有价值。

我们知道，大型手术通常由十几个人共同完成，有大医生、助手、麻醉师、第一助手、第二助手等等。手术过程很紧张，经常会面临重大出血、心率骤停等复杂情况。这就要求团队、成员决策，迅速沟通能够形成上面共识，谁的经验最有价值，听谁的，避免现场争论。

一般来，团体在一起时间久了，自然就会建立起来默契。但是这位医生发现，手术时候的成员决策是从来都是临时调配过来的，谁补谁进，谁就加入，也就是，大家互相不熟悉，没什么默契。怎么办？

他和这个科室的领导配合，推动大家做了三件事：

+   - 第一，由主任，也就是术者牵头，发动大家做经验分享。请注意，不是在微信群里读一段话那么简单，而是专门找一个时间段，大家坐在一楼，随意地派每个人轮流上台，把专家本领以演讲的方式告诉大家。

+   - 第二，在没有重大任务的时候，大家会被随机分成小组，然后模拟做台手术。有意思的，大家会互换角色，假设医生要去当麻醉师，麻醉师当护士，护士当主刀，总之就搞个大反转。当然，因为没有真实的患者，所以过程还是很轻松的，但是配合中每个都不可预知。

+   - 第三，大家要在真实的术后进行复盘，并且请其他人旁听。复盘的重点是手术中出现了哪些变化。比如大家是预设的术中出血，若麻醉剂用量比预期要的多，那原因是什么，有哪些经验教训可以参考。

这些经验分享和演练的频率很高，至少每两都要进行一次。半年后，这位医生发现了几个显著的变化：

+   - 第一，因为每次演讲的仪式感很强，或者有拿走体验，大家会认为很，或者不太实在，所以没有人会戴看戴着。半年之后，所有人对人他的能力都清晰有了特别清晰认知，谁家能进对专家，遇到难题就找谁，每个门都能准确地叫出来。

+   - 第二，因为经常相互演练，并且对真实手术中的变化及为协同进行复盘，所以大家对于解决复杂问题的思路，以及各自的心理状态了如指掌，每个人都能站在对方的角度考虑问题，对其他人掌握的经验就有了更深的理解。

这些改变，最终体现在了手术用时减少，或高手术重，对于手术室来说意义重大。但是你可留意，这是外国的医院，中国医院都有自己内部机制。请注意，知识管理有一个先付比，后收货的过程。知识管理是一个先付出，后收货的过程。

说到这里，你应该明白我为什么要介绍这个实验了。这个科室其实就是建立我们所说的「知识地图」么？它达成了知识管理的目标，而且不依赖隐性文字系统，开始变通，它都很好地解决了。

组织行为学把这个方法叫做「建立共享心智」，最早由英国组织行为研究者20年前提出，经过这年的实践，学者认为它主要包括三个要点：员工共享组织的知识地图；共享隐性知识；以及明确在多大程度上可以交换思维的规则。

这三点，精要是知识管理要达到的目标，所以企业要做好知识管理，必须要先建立共享心智。

# 4.如何建立共享心智

你可能有图像，像角色互换这样的动作，你的组织未必通用的。没关系，我为你总结了建立共享心智的四个要素，以及三种不同企业的成功案例。先看要素：

+   - 1. 组织高频率、仪式感的知识分享活动；
- 2. 保证相关人员参与，建立他人知识地图的认知；
- 3. 帮助员工进行换位思考，理解他人行动背后的思维逻辑；
- 4. 格外重视关于失误、妥协、变通的经验分享。

你可以围绕这四点来设计知识管理方案，但请注意，不同企业具有不同特质的员工，较难用一套模板。下面我就介绍三个比较典型，区域分布。三个不同的员工，如何调整方案。

第一个是海底捞，它的员工教育水平说话也很普通，有非情，但服务水手平很高。他们的方法是传播，一天的工作结束后，组织老员工给新员工介绍经验。

我在调研时就被带入过。有个老员工就跟新人说，「让客人开心的关键点，不是点头哈腰，而是要记住他们的长尾和名字。为什么？他们，是恭恭敬敬地一句「没想到你想了」，「好，是，您贵客，今天吃碗粉？」，客人更高兴。」
