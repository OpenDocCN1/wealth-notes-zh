# 15讲 | 群体迷思：如何降低集体决策的风险？

李晋修·组织行为学

你好，欢迎来到组织行为学的课堂，我是李晋修。

这一讲是模块的最后一讲，我来说一个领导力太过强产生的说忧不及的现象。

我们都知道，集体决策的质量应该高于个人决策。一个集体事情没有商量，大家一起想，成功率会很高，但你有过这样的体验吗？就是问集体中每个都很厉害，但集体作出的决策是明显出丑的。

组织行为学发现，集体决策质量低于个人决策的情况其实很常见，原因就是大家非常缺乏！恰恰相反，越团结，出现集体决策失败的概率反而越大，这是怎么回事？这一讲我们就来讨论，如何降低集体决策的风险。

# 1.精英团队也会决策失误

首先有人会质疑，如果我们的团队是由精兵强将，那他也错不到哪去，这是想象太小看这一讲了。我告诉你举个例子。

著名学者肯·戴维斯很早注意到了这个问题。他认为不是商业组织，而是容隐质量低的组织形式。肯尼发现，国家决策团队也会出现在极低失败，最典型的案例就是熟悉的猪湾登陆。

1959年，美国策划让土兵扮演流亡者古巴猪湾登陆，占领机场，然后用电台反击，当这个美国国家团队以民众诉求为理由，堂而皇之地开始入侵。

指挥团队由肯尼迪总统亲自牵头，下辖4位部长级人物，也包括三名白宫智囊，其中两位是律师团队。可以说，全是肯尼迪能信任的精英顾问，而且也都是总统的支持者，有的甚至是总统竞选时的核心圈人物。

但在后面，就是这样一个“梦之队”，在之后却被搞成了各种低级失误，导致三次土古巴被俘的1000余名雇佣兵，三天内被全部围杀。

随便举个列子。行动的一个关键点，就是不能让民众观察到使指挥失密，必须制造古巴人民自愿的假象。但肯尼迪团队居然派出78架大型运输机，14架轰炸机，十多艘军舰参与，而伪装手段只是在机身、尾翼上贴上古巴国旗。

拜托，你是百万流亡者，谁家的流亡者有这样的实力？只有天才才会相信。行动一开始，媒体立马发通了，苏联人士就上台，机军舰所演的部队暴露都开始在整台了，行动瞬间演变成外交危机，刚开始就完了。

请记住，如果低级的决策失误不是总统团队发出的，我们可能都很难想象，难道我们不也会犯下更大错误。

但你可能也会说，这是政治团体，参考意义不大。但是肯尼迪指出，如果我们看看身边商业团体就会发现，精英的精英团队同样在犯与己水平不相称的错误。我给你再举个例子，来自于你正在使用的得到。

得到曾经有个想法，就是推出“全通卡”，让你可以在一年内浏览所有的产品，这个想法确实有着好的一面，但也有些问题。它会被当出看时候，团队非常高兴，团队确实出看的时候，因为该功能，对于产品受众和研发，技术团队已经启动、集中研发，不做完大家都不能完。总之，没人想到这件事存在着明显的谬误。

当然，在没有全通卡设计，说明它用，开没全通卡意味着没有，没全通卡于对于产品数量的需求放在首位，而这势必会影响很多产品的质量，与之战略规划要么不。这是一个明显的逻辑漏洞，但很难在讨论中被大家忽略了。

至于得到是如何意识到这个错误的，我们有几句话，要个关子，问题出来，肯尼迪团队，也有得到，它们的问题在哪？

# 2.团体迷思

学者通过调查重发，这些团队出现决策失误的逻辑惊人相似，都是他们都太注重共识了，过于急于达成一致性，导致坚决的共识而牺牲了决策，肯尼迪团队，我们把这个现象称为“团体迷思”。
