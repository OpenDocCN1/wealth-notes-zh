# 19讲 | 冲突：怎么避免组织内耗？

李开复 · 组织行为学

你好，欢迎来到组织行为学的课堂。今天和明天两讲，我会带你来看看，组织里常见的两类矛盾。

我想先问你个问题：怎么判断一个组织内耗大不大？有人可能会说，看冲突的数量很多大。但经常发生冲突，组织一定很健康吗？

我告诉你，不一定。在组织发展的某些阶段，冲突数量的增多，可能会促进成长。这是为什么？这一讲我们就来讨论：冲突和内耗到底是什么关系？我们如何避免组织内耗？

# 1. 抑制冲突导致内耗

很多人会误解，冲突变少了，内耗就没了。其实不是，正是抑制冲突导致了内耗。为什么？听我慢慢讲。

你一定知道摩根士丹利。作为华尔街的老牌银行，它甚至平安度过了2008年金融危机。然而在2012年，摩根大通发生了罕见的巨额亏损：一名交易员布鲁诺的交易损失约62亿美元。由于亏损额极大，布鲁诺也被称为“鲸鱼”。事情发生在伦敦，所以又叫做“伦敦鲸”事件。

提起“伦敦鲸”，几乎所有人都会关注背后的金融交易。然而今天要聊的角度却不一样，咱们来关注背后的管理问题。

布鲁诺在整个管理流程中，一直试图隐藏损失，并且让高管进行判断，这好像是个人品问题。然而，美国参议院银行委员会通过详细调查发现，罪魁祸首可能是“避免冲突”的企业文化。

布鲁诺隶属首席投资办公室，这是一个贡献了大部分绩效的小部门。他们提供两套，然后交给信贷控制组。也就说另一个风险控制组来审核。调查发现，每当这两个部门产生冲突时，CEO杰米·戴蒙的做法，通常是制止冲突。

比如根据记录，有一次首席投资官把两个部门的冲突报告交给了戴蒙，这是他看到了戴蒙的严厉斥责信。他决定这种报告绝对不可能公开。甚至根据记录，戴蒙在斥责时故意提高了音量。

调查发现，有看到同事因为争议报道而遭到批评后，首席投资办公室的代表们开始设法回避冲突，避免冲突；而信贷控制小组这也是另一样，他们意见一致地认为，那就像一只意见一致的。这只交易员差不多可以轻易过关。

加上戴蒙的，摩根大通还有另外两类企业文化：“永远在后续中解决”，以及“有问题自己解决”。如果我是布鲁诺，现在问题在面上，被问上来我会拒绝，那你怎么办？既然老板鼓励自己解决问题，最简单的方法当然是隐瞒。

“伦敦鲸”是非常典型的案例。问题永远存在，逃避冲突，问题终将以外在的方式爆发出来，比如巨额损失。“伦敦鲸”事件过后，戴蒙有一次接受《福布斯》的采访。他提到多金损失是没有决定的，他得到了一件事，就是克服困难，大胆提出问题，而不是掩盖问题。

这个案例一会儿我还会再开一层。我们先来看另一种更严重的内耗。除解还原问题，组织中的内谋政治更要命。

社会学中有一个非常著名的理论，叫“结构洞”理论。社会学中的经常会出现，就是某些个体与另一个群体之间直接联系。如果你把网络调出来，他们之间就出现了空洞。

结构洞在组织中也存在。比如，财务团队通常不研发团队直接打交道，他们之间就存在结构洞。

结构洞会产生什么问题？组织行为学家发现，当企业过分强调和谐文化，避免冲突时，就会有人占据结构洞之间的连接位置。他们会努力维持结构洞的存在，阻绝部门之间的充分联系。这就演变成一种权谋政治、一种内耗。

这非常危险，因为它可能直接拖垮组织。我前面不止一个公司，就是因为它大量裁撤部门，没人沟通，无人对决策负责，最后经理人被换，而他自己攒了一拨人，在职上置高层楼。
