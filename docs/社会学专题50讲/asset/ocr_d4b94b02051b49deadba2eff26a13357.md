# 样让团队快速产生凝聚力？

你好，欢迎来到组织行为的课堂。

今天的课打破一下以往的惯例，先不要谈解决什么问题，我用两分钟讲，讲一部经典的电视剧：《兄弟连》，我建议你看完，而且应该对里面的战斗场景印象深刻，但我要讲的是有一段可能被你忽略的情节。为什么我要讲？一会儿告诉你。

1942年，一群年轻人从四面八方来到美国佐治亚州，加入了101空降师的E连，他们要在这里接受训练，从平民百姓，变成前指挥、懂合作的精锐空降兵，参加二战。

负责训练的军官叫索伯。我还记得他出场第一个镜头：拖着行李，踢着鼻子，眼睛瞪，完全是顽固而粗暴的新兵鼻子。索伯则就给大家来了个下马威：所有人忘掉周末的休息，在这三天，每天都要训练。

索伯对新兵的态度不仅是用蛮横来形容，简直变态。他不能容忍新兵，头发太长、枪擦得不够亮这些错误都要体罚。而且夜里有噩梦，还要练跳伞。有一次，一名士兵跌伤了膝盖，索伯让他把他灌满水，再背12公斤，有一次，他发现有士兵的枪托生锈了，便大骂道：你的武器像狗屎一样，你以后的名字就叫狗屎，明白了吗！

新兵们对索伯恨之入骨，但互相之间却变得越来越团结，成为他互相支持起来对抗索伯。有一次，索伯惩罚一名士兵跑完50分钟，结果全站的前方索伯反而被大闹开除了。E连也成长为一支团结、训练有素的队伍。

后面的故事你都知道了，他们杀敌四方，和索伯已经没有了关系。但斯皮尔伯格在最后一集告诉你说升了一个官佐，接连的二兵少尉要为一个叛徒。在接连军俘虏的时候又遭到了索伯。这时，他们的军衔已经高过了索伯，想起他来训练时的蛮气，他让索伯给他行个礼。索伯则向原先的下属，现在的长官行了一个标准的军礼。

这当然要体现出什么报复、快意，作为组织行为学的研究者，这个情节让我唏嘘。为什么？我带进今天的主题。

# 1.寻虐管理

前情提要讲，我们谈到如何让新人快速融入工作群体。但是带过团队的人都知道，彼此熟悉还远远不够，要**能形成战斗力，成员间便像死一样成为一股力量**，在组织行为学上称为“团队的凝聚力建设”。

提高团队凝聚力的方法有很多，奖励集体成绩、提高凝聚、鼓励，甚至很多餐厅早上还会让大家到门口喊字，这些都很普通，而且都是符合一般管理规律的正常手段。

但是有另一种组织，千百年来一直在采用与之相反的手段来打造凝聚力，那就是军队。军队的行为，在军人眼里被称为**惩戒**。组织行为学给这种惩罚取了个名字：**寻虐管理**。长久以来，不管是在学术界还是在企业实践中，寻虐管理都被认为是完全负面的。

那既然负面，军队为什么还要这么干？很简单，因为有效。寻虐管理因为“政治不正确”，几十隐离，逻辑值就都被忽视了。但最近十几年，组织行为学研究在研究我们才发现，它其实是一种有效的管理手段，只是有很强的局限性。

# 2.相对利己

那为什么索伯能把士兵打造成凝聚力超强的兄弟连？真的是打骂等表面手段么？我们来看看。

社会学家斯弗托夫关注过一种现象，就是有人看到邻居家买了一个轿车车，本来和他没什么关系，但是他就觉得，自己也应该有一辆。没有，就说明社会不公平。

斯弗托夫把这种**你有的我有，但并无真正得到的感觉**，称为“**相对剥夺**”。他说，个体一定时是通过与他人进行比较，来确定自己的地位和处境。**如果比较后到，发现自己弱势的地方，就会生到剥夺的感觉**，这也是为什么要加上“相对”两个字。

你可能会说，这不就是嫉妒么？没错，是嫉妒，但还没说尽。随着研究的深入，大家发现，相对剥夺的一些作用很有意思，其中典型的就是它在大促进了“内群体”的凝聚力。什么是内群体？我用一个例子来解释：

加拿大魁北克地区生活着两类人，一类以法语为母语，一类以英语为母语，说法语的人较少。研究发现，如果当地政府的决策倾向语言类，那么说法语的社会待遇变好，体现在邮政投递次数多、集会增多等方面。那么这个时候，一起用法语割手感的看法就特别**讨厌说英语**，特别羡慕说英语的人；

我们再来看看索伯。他打骂时，新兵和外界的敌视，同时当兵也大多由四：一是和其他部队比。有一个习惯，背叛的突然有人感叹，说你看其他部队都在睡觉，咱们在这儿又是又是又是什么啊，这也是一种比较；三是和索伯本人比，那无疑，我们全是委屈的人。

这种比较带来的对同事，是让他们把这视为十分患难与共的感觉。军队是以这种**剥夺新兵部分权利的方式，再辅以艰苦的训练，最终加速了团队凝聚力的形成**。

# 3.如何让团队快速建立凝聚力？

好，说到这，我们详细讲今天的主题了：如何让团队快速建立凝聚力？

按逻辑，开头介绍的些手段就用了。但是如今竞争越来越激烈，企业方时更需要迅速应对突然发生的“战争”。从不同部门抽调员工组成临时团队。

2009年左右，中国已经爆发了液晶屏幕大战。那个时候，企业想做出产品，可能只领先对手几十天。在这种情况下，所有突击团队都是临时组成的，哪有精力做什么正规训练。

如果真到了这种情况，那相对剥夺理论也就无能为力。我们难道只能照搬军队的做法。作为商业组织，我们却没有这样的权利。而且你也不是专门打造团队有很多负面作用，关键是要怎么拿捏这个度。

我2015年在一家高新企业做了一个实验，之所以选在这里，是因为员工之间的交流相对频繁，任何偶遇上的差异，他们都能马上感知到。实验总共耗时三个月，我们来尝试发现，有效的相对剥夺如何对团队凝聚力产生促进作用，而不是相对剥夺。这个研究的结果发表于2016年的核心期刊上，这里介绍给你。

基本的做法就像理论所说的那样，通过差别对待，让员工替换参与群体，把自己和伙伴当作能够部分权利分配的“内群体”。

我们是这么做：三个月一起，每个星期，团队对某部分资源进行分配。注意，所有团队都有的资源，**没有合作，领导会对某个人态度冷漠，并且会不情指地指出工作中的错误，而且不会反驳**。

那被冷漠的员工就会和**平均团队**或者原来被冷漠的队员进行对比。“为什么以前的领导那么善解人意，而现在这位则是个性子脾气？”

每天这样一次，连续对比，凝聚力才会大家被冷漠的感受效大于我，凝聚力的提高。最危险，遭遇不公待遇的人也会受到这部分的人一半，百例员工只想快点离开这个团队。

我们由此得到了第一个结论：就是领导可以在特定人态度上做到差别对待。不过，得**上一步是做到“公平”，不要团队成员差别团队进行社交，而不是在内部制造差异，更不能只对少数人进行训话**。

继续说，是实验中，我们特意做了一个对照实验，就是在薪资待遇上对员工做差别对待，采用比较苛刻的绩效扣减办法。结果就很不平衡了，团队氛围、战斗力都下降了。以至于考验过后，我们特意对团队组员进行了了解，并补齐了因为做实验而扣发的奖金。

类似的实验，实际上也有人在做，结论相同。所以第二个结论是：**员工的相对剥夺，一定局限在自尊、荣誉感这类一点的东西上，不能和直接经济挂钩**。

我们得到的第三个结论是关于如何产生负面作用的。最好的办法，是让你的团队成员所暴露的、换句话说，开开你的保险可以提意见，但是，你要为他们提供全方位的辅助。人家完成任务，要什么给什么。这种情况，员工就会把负面感受归因在领导的人格上，不会威胁到组织的。
