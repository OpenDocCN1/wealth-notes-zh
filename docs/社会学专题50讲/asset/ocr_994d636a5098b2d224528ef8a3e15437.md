# 18讲 | 权力：怎样防止授权走样？

李馨倩 • 组织行为学

你好，欢迎来到组织行为学的课堂。这是组织模块的第二讲，我们来谈权力。

前两天，一个刚进入职场的女生给我发微信，说她被降到高级，因为上级把一件非常重要的工作授权给她， 策划和执行方案都由她来决定，还给她配了两个人的团队。她说，公司里尚无有年轻权威人挑大梁的先例，所以很兴奋。

但是，我给她泼了一盆冷水。我问了她三个问题：第一，上级有没有明确她需要的责任和边界？ 她说没有，上级没有给你提供必要的指导？ 她说，没有大提供；第三，上级有没有告诉她， 如果失败和后果谁来担？ 她说没有，我们都得不在先验，所以也没说。当时我就想，这可能不是好事。

领导者 下提供明确更多的自主权去完成工作，这是好事， 组织行为学上称之为授权。但是如果做不好，就会走样，产生坏的结果。

授权走样会产生哪些坏的结果， 组织该如何预防？ 今天这一讲咱们就来说一说。

# 1.失败的授权案例

我们先详细讲一个案例， 它几乎涵盖了所有授权不当产生的问题，后果也非常严重，请密切留意听我思考。

1995年2月23日，创建于1763年，拥有200多年历史， 业务遍布100多个国家的巴林银行倒关闭了， 原因是名叫李森的员工违规交易数 数日其巨大， 以至于亏掉股东和员工数千万美金，这一切是怎么一步步发生的？我们来看看。

银行交易出错是难免的事，所以巴林银行总部和伦敦， 清算部门在伦敦，清算部门。清算负责全球分公司的交易结算结算，总部设委清算事务，员工们就想到， 那新加坡自行处理里面的清算工作，省总部的麻烦。

结果李森来到新加坡之后，掩盖了期货投机交易，原来清算就是用客户的损失弥补自己的损失。因为自己是简单算算张，所以如果亏了钱，可以巧妙地掩盖而过去。

但是常在河边站，哪有不下湿。李森赚的钱开始越来越大， 资金负债也越滚越，但是总部的负债风险越来越大。但是神的是，总部仍然选择信任信用， 因为伦敦的董事长期不联系， “看看新加坡李森多能就解了一个公司， 如果是会做一无知。

1994年底，李森的资产负责账上居然已经有5000万美金的盈余了，但是隐瞒的负债风险， 依然是巨大的。但是是1995年1月，日本神户发生大地震，东京期货指数狂跌， 李森就彻底走垮了，这也导致了公司的全面崩溃， 1个月后，巴林银行倒闭。

表面看起来，这是一个涉及个人道德的案例分析， 但是内心的监控体系显然出了问题。而多年李森说在太书里， 叫做“假如乔纳森银行”，许多细节被暴露出来， 开始审视这把背后的授权问题。

首先，李森不是一上来就想搞垮公司的。他的第一笔损失只有2万美元， 新加坡起来也不过170万英镑，比起最开始的亏损5000万美元确实是小题，但是 在这段时间，总部没有给予李森任何关于能力上的指导和反馈。要知道，他上任之前 确实是一名非常赚钱的的交易员， 但是在管理分公司这么一个大的一个摊子是一筹摸的。

其次，巴林银行混淆了交易与清算两个角色，但是就是致命的失误。李森靠经营清算， 担任是定期向总部提交清算经理两个职能。请注意， 刚才我们讲了， 派他过去是为了清算账能。但是总行的高层领导，是想，就是既能赚点钱也赚。这种权利模糊的状态直到始末， 所以李森就是想在有核的情况， 都是赚钱， 这是总部为什么总部一直不懂怪责李森的原因， 他们的欺骗是李森在做的。

这还在破产的前两个月， 巴林银行居然不在公司的总部长上， 后李森成功破局， 报纸从热到冷的声音，因为他尝试为公开道歉， 但是 在董事会后， 他一直揣在心底， 如果承认了谁来承担责任。 总部从没有明确告诉过他， 只说为了什么， 成了我们的责任。

这三项原因使得李森在面临亏损时，选择了瞒报继续赌博， 最终全部资产归零， 但是是 “我 感觉是个骗子感到羞愧， 但是我不知道他们在 也就是公司高层， 不清楚他们的犯我职责， 界限何在。我不清楚我们是不是公司责任。他们的做法不罚， 而我则难避致死。”

# 2.心理授权

案例我们就讲到这里， 它代表了最常见的一种授权状态。 要么领导把所有活分下去，然后责任不重， 要么就是另一个形式， 就是领导管得太多， 天天盯在你的身边， 嘴上说 你做主， 但其实根本不放心。
