“小时候总想知道沙漠那边是什么，走过去，才知道沙漠那边还是沙漠，没有尽头，看不见希望。但你仍然要勇往直前，没有退路。”

桐洁（独白）：可怕的不是对手的强人与残忍，而是漫漫黄沙路上，只有你一个人，一种无边无际的孤独，和恐惧。

也许，只有经历过创业的人，才懂上面的话。

有一天，四年级的儿子放学回家，我问他：

“伯乐，你知道爸爸在中国的公司是干啥的吗？”

伯乐像我小时候，整天心不在焉的样子。他说：

“我知道，你在帮助很多人。”

在加国，孩子这样的回答一点儿也不算“高大上”，然而却让我心底啥噎一下。

原来，看起来晕乎乎的孩子，正在看着你。

创业，有时候和孩子一样，是命中注定的。

真期待能早一点儿带伯乐和预言家两个小朋友到中国各地看枝繁叶茂的春藤。

非常幸运的是，春藤比我想象中生长得更加美好。

如今，春藤已经遍布全国，正在以“数字化基础设施+有温度的社区”的独特商业模式，快速发展。

再次证明，做正确的事情，比做容易的事情走得更远。

春藤还只是刚刚开始，而我个人早已受益良多。

# 创业，就是一个自我压榨的过程：

+   你会以非常痛苦的形式，剥离那些幻觉和虚假的东西；

+   你将在怀疑、压力、挫折中发现真正的自己；
