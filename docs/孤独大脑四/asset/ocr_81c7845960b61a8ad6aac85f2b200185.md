# 成年人毫无希望

收录于话题 #大脑碎片 3个内容

本文只是大脑碎片，句子和句子之间并无联系。

碎片只是些火花，不代表任何观点和结论。

成年人毫无希望，只有那些冒充成年人的孩子例外。

成年人不是指“为自己和他人负责”，而是指“只为自己和他人的算计负责”。

成年人愿意为明天花钱，但不愿为后天播种。

成年人并非不干傻事，他们只是失去了干傻事的能力。

成年人不再做梦，他们的梦境仅用来欺骗别人，却骗不过自己。

成年人靠购买孩子的想象力、真诚和牺牲来延续贪婪。

成年人以无私的名义，哄骗孩子，利诱孩子，鼓动孩子，直至残忍地将孩子也变为成年人。

有些人生下来就老了，有些人至死都是孩子。大多数人只是夹生。
