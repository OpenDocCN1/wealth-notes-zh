
# 故事一：关于弱小

这是一个关于弱小的故事。

那年梅西13岁，身高只有一米四，还没有走出侏儒症的阴影。在他刚刚加盟巴萨少年队的第二场比赛中，被铲断了腓骨。受伤后，巴萨差点儿放弃梅西，将他送回阿根廷。

吃马铃薯和胡萝卜长大的梅西从小营养不良，在11岁时被诊断为生长激素短缺型侏儒症。拿到结果的那天，他与父亲走在寒冷的街头，尽管心底清楚家里根本没钱为他治疗，依然分外平静。

![](img/3dace955367687898560fd4145a321db_305_0.png)

![](img/3dace955367687898560fd4145a321db_305_1.png)

惟有凝视过绝望深渊的人，才能真正理解希望的意味。即使后来成为这个星球上最顶尖的射手，梅西在足球场上的身影，依然有少年时代的孱弱。

他因此塑造出另外一种杀手气质。既不强壮，也不冷血，亦无“非我不可”的执拗。他压根儿没有夺命的冷酷，甚至有一点点儿神游般的忧郁。

但这毕竟是在球场上，犹如现代社会的斗兽场，球员何尝不是一名角斗士？杀手必须进球。梅西手中的无影剑轻若柳叶，触球，闪移，射门，貌似绵软，却游刃有余，如庖丁解牛般精确、致命。

回想当年，梅西的父亲说：“他从不抱怨。”对于已发生的一切，梅西温顺地接受；对于貌似没希望的未来，他从不放弃。就像终于长大成人后的他，并非不再弱小，而是将孱弱与强壮融为一体，独步江湖。

# 故事二：关于胆怯

这是一个关于胆怯的故事。

1843年10月，一位农村孩子来到了圣托马斯修道院。他不高，偏胖，不苟言笑，温和恭顺且单调乏味。5年后他开始做神父，被认为“完全被无法克服的胆怯所束缚”。

为了摆脱这种窘境，他申请去高中教书。在资格考试中，他的地质学成绩很不理想。生物学知识匮乏又成了他的致命短板。考官在评语中写道：“申请人似乎对专业术语一窍不通。”

在教会的庇护下，他被送往维也纳大学。返回后，在修道院花园中的小块空场上，他进行了8年的豌豆杂交实验。这是一场孤独、卓绝的个人科学探险，远比看上去更加艰难。他获得了数量众多且可供分析使用的数据，其中包括2.8万株植物、4万朵鲜花以及近40万颗种子。

他频频给当时顶尖的科学家写信，被忽视、被敷衍、被忽略。

在去世的前一年，他对一位同事说道：“我相信，我的研究的成功很快就会得到整个世界的认可。”

事实上，整整35年后，直到1900年，他的成果才被证实。他，孟德尔，一位胆怯的、不合格的神父，被公认为科学遗传学的奠基人。他提出的遗传因子（现称基因）显性性状、隐性性状等重要概念，以及所阐明的遗传规律，后人称之为孟德尔定律。

# 故事三：关于无力

这是一个关于无力的故事。

尽管直到16岁，伽罗瓦才被准许读他的第一门数学课程，他依然迅速展现出惊人的天赋，17岁就发表了第一篇论文。当他报考全国最有声望的学院时，在口试时不愿做解释，逻辑太过跳跃，使考官感到困惑。

对自己的才华未被认可感到沮丧，伽罗瓦大发脾气，把一块黑板擦掷向考官。

他还只是个无力控制自己的孩子。

伽罗瓦将解五次方程的论文送交法兰西科学院时，令评审震惊，他们退回论文让伽罗瓦重新提交以角逐数学大奖；而再次提交，却又因傅立叶去世而遗失。

![](img/3dace955367687898560fd4145a321db_309_0.png)

![](img/3dace955367687898560fd4145a321db_309_1.png)

受挫的天才试图成为一名职业反叛者，他因背叛国王的罪名被捕，释放后再次被抓。他无力让自己过上一种不颠簸的日子。

最后的任性发生于一场莫名其妙的情仇，数学天才在计算人生得失方面犹如白痴。情敌是法国最好的枪手，伽罗瓦明白会发生什么。

慷慨赴死的前一天，他彻夜工作，写出了所有的定理。绝望地试图使它们得到承认，他相信这些定理全面地阐明了有关五次方程的疑难之处。

在那个短暂的夜晚，在最后的手稿上，除了复杂的代数式，还写着少年天才那撕心的感叹——“我没有时间了，我没有时间了！”

手稿上，伽罗瓦使用群论的想法去讨论方程的可解性，整套思路现称为伽罗瓦理论，是当代代数与数论的基本支柱之一。

夜尽时分，演算终于完成。接着，他在决斗的早晨被射中腹部。

在临死前，伽罗瓦拉着他哥哥的手说道：“不要哭，我需要足够的勇气在20岁死去。”

# 故事四：关于心碎

这是一个关于心碎的故事。

作为巴菲特的搭档，芒格看起来更洒脱、更懂得享受人生。但其实，他的个人生活曾经艰难、凄惨，经历了各种苦难和不幸。

草率的婚姻，离婚、穷困潦倒，开着敞篷跑车，7岁的儿子因身患白血病离世。

> “他的儿子正躺在病床上慢慢死去，他走进去抱了儿子一会儿，然后跑到外面沿着街道边走边哭。”

1973年，世界石油危机和之后的股市大跌，更是让芒格管理的投资公司损失过半。当他与巴菲特联手准备大展身手时，因为白内障手术意外导致左眼完全失明……

马斯克经历过类似的遭遇。他的一个儿子出生10周后不幸夭折，“我不太愿意提这个事儿。如果你身上有家庭有责任，还有其他子女需要抚养，完全沉溺于丧子的痛苦中对周围人都不好。我不知道那种情况下该干些什么。”

芒格没有被接踵而来的苦难和不幸所击倒。他告诉自己，不要让一个悲剧演变成两个。

![](img/3dace955367687898560fd4145a321db_311_0.png)

芒格儿子小查尔斯说：“他就是能够义无反顾地摆脱了这些悲剧的困扰。”查理和格雷厄姆、富兰克林一样，正是那种能够经由地狱抵达天堂的圣者。

# 故事五：关于绝望

这是一个关于绝望的故事。

我们都曾深陷泥潭，但没谁比《海边的曼彻斯特》里的Lee更绝望。他因为粗心烧掉了自己的家，三个孩子葬身火海。在警察局里，他试图抢枪自杀，如果真的得手，日子也许好过很多。

然而并没有。他被囚禁于现实的炼狱，犹如行尸走肉。除了沉默，就是失控后的暴怒。他甚至不能如《三个广告牌》里失去女儿的妈妈那样对着小鹿自言自语：因为神并不存在，这世界是空虚的……

![](img/3dace955367687898560fd4145a321db_312_0.png)

> 我的心碎了，我知道你也是如此。
> My HEART WAS BROKEN, AND I KNOW YOURS IS BROKEN, TOO.

这时命运又将他失去父亲的侄子推到面前。在曼彻斯特冰冻的土地上，没有出路的男孩和男人，彼此撕咬、依赖、踟蹰。

“I can't beat it. I can't beat it.”

每个人都有权利不与自己的过去和解。也并非每个人都要拥有未来才能活着。

漫长的冬季后，依然有松软的春天。故去的亲人终于逃离冰柜，得以下葬。来自弥赛亚选章的配乐响起，其中有些歌词是这样的：

凡劳苦的都得到他那里去。

# 后来

“梅西，我想跟你说一些话，我想告诉你不应该为任何事感到歉疚，任何事都不。我还是像以往那样喜爱着你，尊重着你……”马拉多纳对梅西呼唤。

上帝没有再救阿根廷，而是让姆巴佩将法国队带上神坛。

![](img/3dace955367687898560fd4145a321db_314_0.png)

梅西未必马上没落，他依然是球场上的肖邦。舒曼说：肖邦的音乐是“隐藏在花丛中的大炮”。梅西柔软的利剑将继续挥舞，待下一个天才被唤醒，让阿根廷为之自豪、流泪。

孟德尔与伽罗瓦直至死去，都不曾听过半句“你是对的”。努力到无能为力，上天也未必会给你开一扇窗子。

塞内加的秘密是：我从来没有信任过幸运女神。我把她赐予的一切——金钱、官位、权势——都搁置在一个地方，可以让她随时拿回去而不干扰我。我同它们之间保持很宽的距离，这样，她只是把它们取走，而不是从我身上强行剥走。

但，如果被取走的是你挚爱的人呢？无论芒格和马斯克取得多大的成就，他们都会在某个夜晚，因离去亲人的入梦哭泣而醒。

Lee被压得塌陷于冻土上，如同那些数不胜数的平凡人，沉默孤独，承担着生命不可承受之重。

# 最后

在这些关于弱小、胆怯、无力、心碎、绝望的故事里，我要呈现的主题并非“悲剧”。

在英国散文家卡莱尔看来，“生活的悲剧不在于人们受到多少苦，而在于人们错过了什么。”

这5个故事中的主角在生命中最黑暗的时刻，从未倒下，不曾错过。

![](img/3dace955367687898560fd4145a321db_316_0.png)

这些，是关于命运的故事。

塔勒布写道：“不管我们的选择有多复杂、我们多擅长支配运气，随机性总”

在他看来，这是人类与概率平起平坐惟一的方式。

在巨大的不确定性来袭时，在最无力的瞬间，他们像有尊严的人那样挺直腰

“其实，一个男人的梦想几乎是从来不会实现的。”维特根斯坦这样写道。

# 生而被缚

起初，我是在咖啡馆里写下这段文字。2014年，我每天下午送伯乐去幼儿园，送和接之间的三小时，像是束缚中的一段自由，于是大多待在咖啡馆。而接送孩子，又像移民后自由生活里的一段束缚。也因为这自由之中的束缚的自由，我才有空自由思考--于文字的束缚里。

重发本文，是因为《生而被缚》当年几乎就是为自己而写。它没有太多对阅读者的取悦，写作者也没有刻意秀智商、秀深度、秀系统。那时，我甚至没意识到自己已经年过四十，所谓对束缚的理解，像是青春尾巴不甘成熟但又若有所思的挣扎。

确切而言，热力学第二定律，才是一切束缚的源头。

这一统治了当下已知宇宙的定律，处心积虑地打翻我们的牛奶，让我们担心的事情"终将发生"，令时间一去不复返，它摧毁青春的容颜，使食物腐烂，为一切生命体设定死期。

总之，热力学第二定律仿佛能够穿透我们的心思，千方百计地设计"将事物变得更糟糕"。

但是另外一方面，物质和能量的随机扩散，似乎是万事万物得以运转的根源，甚至也可能是时间和自由意志存在的原因。

例如，当无序扩散的分子被装入发动机，就能够驱动汽车，快速带你去另外一个地方，让你对抗重力和时间的束缚。

又例如，在淤泥里长出的荷花，之所以没有成为更加污的淤泥，是因为荷花DNA里的信息束缚，利用了淤泥里的随机性。

于是，人类的几乎所有努力，与其说是对抗熵增，不如说是通过制造“束缚”，利用物质和能量的随机扩散来做功，来生长，来自我延续。

正如我们将自己有限的大脑，束缚在孤独的颅盖骨里，却可以用它去探索无尽的宇宙。

## 开始

### 一、监狱上空的《费加罗的婚礼》

仿佛来自漫无边际的星空，我脑海里常浮现出童年时工厂里的高音喇叭。

那本是计划经济链条的一部分，播着通知、音乐，象征着灌输与覆盖。记忆里，空气中歌声高亢，蓝天白云如布景，爸爸妈妈强壮地工作，孩子们放羊般四处野玩儿。

那种被束缚强化的旋律，如《肖申克的救赎》里著名的高潮：男主角不顾一切、相对于其漫长的越狱计划而言极不理性地放《费加罗的婚礼》，当他将莫扎特的音乐切换到广播模式时，高音喇叭的魔力出现了：

“我到今天也始终不明白，这两个意大利女人在唱什么。事实上，我也不想去明白。有些东西不说更好。我想，那是非笔墨可形容的美境。然而却令你如此心伤。

那声音飞扬，高远入云，超过任何在禁锢中的囚犯们所梦，仿佛一只美丽的小鸟，飞入这灰色的鸟笼，让那些围墙消失，令铁窗中的所有犯人，感到一刻的自由。"

![](img/3dace955367687898560fd4145a321db_326_0.png)

在这个本身不对我有束缚意义（也因此其实反而被深深束缚）的公众号写作中，本期想写“束缚”和“枷锁”，以及其统治下的自由，由我一个被深深束缚的个体。

这个主题早就潜伏在“孤独大脑”的名字里，只是现在才冒出来（当我从另外一些枷锁中出入出出）。

### 二、神经元的彼此捆绑

自由与束缚，像人生秋千的两头。人们在束缚中追求自由，在自由中自我束缚。
