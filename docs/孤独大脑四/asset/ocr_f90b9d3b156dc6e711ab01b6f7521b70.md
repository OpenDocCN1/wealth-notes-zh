“可口可乐生产浓缩原浆，在某些情况下直接制成饮料，卖给那些获得授权的批发商和零售商进行灌装。”这句话 一个世纪以来一直出现在可口可乐的每年年中报中。

巴菲特喜欢收购企业，但是不喜欢出售企业，回避那些拥有大型工厂，技术变化很快的企业，也回避那些劳保费用高、养老负担重、产品变化大的企业。

他也不喜欢雇员跳槽，他的伯克希尔公司很少有哪个企业的经理辞职，除非他病故或者退休。半个世纪以来，伯克希尔公司从未发生什么变化。

可是，以上简单几乎都是“化繁为简”的结果。简单化的简单毫无价值。

所以，简单化的巴菲特仍会去买苹果。

# 弃子争先

+   围棋十诀：a、不得贪胜；b、入界宜缓；c、攻彼顾我；d、弃子争先；e、舍小就大；f、逢危须弃；g、慎勿轻跃；h、动须相应；i、彼强自保；j、势孤取和。

其中，d、e、f都和弃子有关。

围棋发烧友金庸在《天龙八部》里，描述了虚竹无意间破解逍遥派“葬哑老人”苏星河的珍珑棋局（无崖子所摆下的），其要点即弃子自杀一棋棋。

虚竹的师傅玄难道：“这局棋本来纠缠于得失胜败之中，以致无可破解，虚竹这一若不若意于生死，更不着意于胜败，反而勘破了生死，得到解脱。”
