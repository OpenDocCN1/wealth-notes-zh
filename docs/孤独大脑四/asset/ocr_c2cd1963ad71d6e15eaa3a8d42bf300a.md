有时候你支配生活，有时候你被生活支配，技能和运气都是生活重要的元素。你可以打赌、检查、糊弄和提升自己。有时候你赢得一副牌，有时候你会输掉整栋房子。

无论什么情况发生，最好的应对方式就是一直洗牌。

所以，只要你还有一口气，你手中就还有牌。珍惜她，打好她，输了再来。

# # One More Thing

一直停留在牌桌上，并不只是说，让自己活得更久，赚得更多，聪明得更彻底。

我们还可以切换一下思路：

聪明人能否放大自己的牌桌？

这些年我开始重新思考：

聪明人征服世界的目的和意义何在？

我看见太多聪明人，陷入对名利的无限追求。

面对有限牌桌上的无限贪婪，绝大多数人都不会是赢家：

+   - 财富如海水，越喝越渴；
- 比较是万恶之源，你爬再高，抬头也能望见一个屁股。

我看见太多聪明人，为了维护自己的聪明，试图既赚了钱，又赢了名，还要不染一点儿尘土；

我看见太多聪明人，千方百计地用夹层概念去解释这个世界；

我看见太多聪明人，竭力去“模仿自己”，为虚荣的人设而表演自己；
