# 极大极小原理

在“假设发生如下事情”之前，祝福我们此生永不发生这类事情。

假设你外出时，遭遇绑架，该怎么办？

有一位（国外的）自卫专家，给出了三个应对原则：

+   1、不要跟他去第二个地点。

如果你心怀抱幸，他可能将你带到偏僻的地方，为所欲为，甚至下毒手，然后掩藏他的罪恶痕迹。

+   2、记住：他在撒谎。

不管坏人说多好听，别相信。

这位专家的观点是：

从一开始，每个谋杀犯，绑票犯，强奸犯，他们都会用同一句话：“照我说的做，我就不会伤害你。”

然而，一旦你照他们说的做，最后受伤最重的，还是你。

+   3、要在原地，用尽一切手段与之搏斗。

这一点似乎有点儿让人疑惑，万一受伤呢？

被人用刀抵住，拼命挣扎要么是不幸丢了命，岂非不识时务？
