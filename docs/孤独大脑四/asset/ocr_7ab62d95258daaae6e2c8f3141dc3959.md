多少年过去了，情况未必好转。

在康德那里，判断力是“一种智能被付诸实践，而不能被传授的特殊能力”，判断力处理特殊事物，如果思维的我离开一般概念的领域，进入特殊现象的世界，那么精神就需要一种新的“天赋”来处理它们。

康德认为：“一个迟钝或精神褊狭的人……通过学习和训练确实能成为有学问的人。但是，这样的人仍然缺乏判断力，经常可以看到，有学问的人在应用其科学知识的时候往往违背初衷，因而不能得到好的结果。”

让我们鼓起勇气，敢于自己做决定，敢于承担责任，敢于追求真理。

# 孩子更值得期待

更重要的是，在孩子受到保护的童年，尤其应该教会他们掌握认知风险的技能。

以色列这类国家，已经证明了这方面努力的价值。

例如，下面这些希伯来语所传递的信息：

+   1、Balagan（巴拉干）：适度混乱，打破预设；

+   2、Chutzpah（虎刺怕）：无礼冒犯，勇敢大胆；

+   3、Chanich（哈里赫）：开始，启蒙，在实践中学习；

+   4、Combina（康遮那）；非常规，跳出盒子；

+   5、Dugri（杜格里）：直言不讳，坦诚相待；

+   6、Iltur（伊尔图尔）：马上开始，降低对资源的依赖；

+   7、“Rosh Gadol”（侯施伽多勒）：自找麻烦，任务之外的大格局。
