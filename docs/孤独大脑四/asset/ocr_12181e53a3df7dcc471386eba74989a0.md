# 远离这类人。

举例说吧，经济较发达区域的特点之一是：民众只算自己的账，而不去算别人赚多赚少。

倘若不如此，就会出现如下局面：我才赚十块，你居然赚一千块，我宁可牺牲自己的十块毁掉你的一千块。

这就是损人不利己。

如此一来，博弈论的均衡就无法出现。因为非对称情况下的“损人不利己”，也就是理性的失去，会摧毁整个游戏。
