# 负重是有益的

沃尔夫定律：定期给骨骼施以一定的压力有益于骨密度的上升。

作为一名杠铃爱好者，塔勒布在《反脆弱》里对负重有一系列精彩的阐述：

+   a、偏好压力和厌恶压力。给我们带来最大利益的并不是那些曾试图帮助我们的人，而是那些曾努力伤害我们但最终未能如愿的人。

+   b、压力源即信息。

+   c、学习语言最好的方法可能就是在网外被“囚禁”-段时间。

+   d、稳定性是定时炸弹。

与李世石十番棋大战，古力拜访灵隐寺，老法师向他言道：你的对手都是你的朋友，你的敌人是你自己。

> “同情他人是把他人当作弱者而使他人感到羞愧。对所爱的人，应锻炼他，使他提高，这才是真正的爱。”
