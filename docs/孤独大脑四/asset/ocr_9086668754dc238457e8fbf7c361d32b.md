# 11•投资思维
### 《博格长赢投资之道》

博格劝告短线投资者：

“所有尝试捕捉短线交易的投资者，都在玩一场输家游戏”。

他称，没有一个人能知道明天会发生什么，所以“我永远不会做10年以下的投资，除非那项目能证明10年后有可观回报，我才会参与。”

巴菲特多次推荐了博格的书与他的投资理念。

博格一生致力于做一件事，并且在商业中践行服务社会，令人难忘。
