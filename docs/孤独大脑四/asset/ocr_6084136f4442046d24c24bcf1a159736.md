# 学会12个关键创业思维模型

“创业思维”不仅是创业者的必备素养，更是孩子应对未来的基本能力。

在这一模块，我会通过文字、音频和直播三种方式分享我的创业经验和智慧，帮孩子深刻理解12个关键创业思维：

+   1、使命思维：发现不容置疑的使命

2、资源思维：以资源有限为前提，去实现目标

3、决策思维：灰度认知，黑白决策，在不确定中前行

4、试错思维：验证、测试、调整，聪明“犯错”

5、胶带纸思维：不在乎解决问题的形式

6、聚焦思维：切割钻石，大胆取舍，发现内核

7、复利思维：大规模复制，实现杠杆效应

8、系统思维：构建系统，打造护城河

9、领导力思维：领导力是承担责任，帮助他人
