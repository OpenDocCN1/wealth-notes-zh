# 扑克高手第四课

控制情绪

# 要点1：克服恐惧

首先，你要克服恐惧心理。

居里夫人说：

生活中没有什么可怕的事物，只有需要理解的事物。现在是我们理解更多事物的时候了，只有这样，我们害怕的事物才有可能越来越少。

从不犯错的系统称不上是智慧的系统。

克服恐惧，并不是彻底摆脱恐惧。

恐惧应该是一种高级的情感。而且，从基因层面，我们很难用几千年的文明史去改变自身数十万年的丛林生活记忆。

克服恐惧，这个说法需要更精确地描述：

我们要的不是在理性决策的时候不恐惧，而是在恐惧的时候依然能够理性决策。
