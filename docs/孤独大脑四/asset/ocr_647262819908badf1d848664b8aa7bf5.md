# 成功学

**恶即低效。**

假如某样东西令大多数人“无效”，可视为恶。例如我们的成功学。

成功学的价值观是互为枷锁，一桌人，要么牛B，要么是傻B。

所谓成功学，就是今天你牛B我傻B、你羞辱我，明天我牛B你傻B、我羞辱你。

中国人对于成功的定义，即所谓上人中下人，每个人头顶都有个更牛B的，心底全是loser。
