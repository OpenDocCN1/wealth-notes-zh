# 条件反射

几乎所有关于人如何犯傻、人的直觉如何可笑、决策如何不理性的研究，都会指向人类来自丛林时代的条件反射。

**所谓理性，就是反条件反射。**

但，当"反条件发射"成为一种条件发射呢？

就像"逆向思维"固然可贵，刻意的"逆向思维"则愚蠢可笑。

# 上瘾

每个人都有自己的瘾。（以下来自维基百科）

**瘾，是指一种重复性的强迫行为，即使这些行为已知可能造成不良后果的情形下，仍然被持续重复。这种行为可能因中枢神经系统功能失调造成，重复这些行为也可以反过来造成神经功能受损。**

**瘾被用于描述精神强迫或者过度的心理依赖，例如物质依赖，药物滥用（即俗称的滥药、毒瘾）、酒瘾、烟瘾。或是持续出现特定行为（赌、暴食）、网瘾、赌瘾、食瘾、财迷、工作狂、暴食症、色情狂、跟踪狂、整形迷恋及购物狂等，是生理或者心理上，甚至是同时具备的一种依赖症。**

**温和的上瘾，成就了烟、酒、咖啡、茶、休闲食品等诸多行业。**
