# 回答：

做网红培训这个有两条路。

第一，培养的网红归入自己旗下，对网红们的收益抽成。如涵电商就是这个路子，老板是张大奕是超级大V，底下培养一批网红带货。但饶是张大奕给底下的网红尽力倒流，下面的网红带货能力仍然不好，毕竟大V的数量有限，不是那么好培养的。

还有一些机构专门培养小V，一开始模式确实不错但后期培养出来的小V想法多了，也不好管理了。整体来看，这条路对网红界的资源和运营要求比较高，没相关经验的肯定是不建议走。

第二条路是只做培训，赚培训费。这个模式其实一直都 有，只培训的好处在于，很多人都觉得做主播赚钱，确实愿意花钱学，另外你也不用指望所有学员都成才，有那个一两个冒尖做成功案例，就有人嗷嗷愿意花钱学了。
