### 1、无门槛准入型

接下来复盘一下, YouTube 上 vlogger 赚钱的背后,有三种收益的方式:首先是 YouTube 平台本身的效益,然后是金主爸爸们的合作,最后是付费订阅,也就是在自己的订阅者基础之上,发展自己独特的服务.

也可以联系到国内的微信公众号的生态,差不多也是这个模式.

首先是微信公众号订阅数超过一定数量之后,底部会有广告,也就是在赚取「微信」平台本身的利益.

接下来就是当微信公众号的影响力慢慢变得越来越大的时候,就会有各个广告主的合作找上来.

再然后就是如果自己还有精力的话,可以发展一下自己独 有的服务,这个就看各位的能力了.

## 3、最后说说, vlog 与短视频有什么区别,为什 么目前它火了起来

Vlog 就是视频博客,短视频也是视频,它们之间的差别在 哪儿呢?

| 区别 | 短视频 | vlog |
| :--- | :--- | :--- |
| 长度 | 15-60秒 | 4-10分钟 |
| 内容来源 | 以账号定位为主 | 以创作者为主 |
| 流量去向 | 流向内容本身 | 流向创作者个人 |
| 表达方式 | 碎片化 | 主题式表达 |

从上面这些区别我们能够看出来,短视频是以账号定位为 主的,而 vlog 是以创作者个人为主的,这就是 vlog 为什么 会是风口的原因,因为短视频可以抄袭类似的主题,类似的 内容,但是 vlog 不同,它是以创作者个人为主,那么一个 vlog 就代表着一个人的生活,短视频的内容主题可以抄袭, 但是每个创作人的生活却不会雷同.

这就意味着,如果平台可以让很多用户来玩 vlog,就相等于几乎是 0 成本增加了很多可持续的创新内容,这样会吸引更多的流量,而这些流量的吸引,又可以用来补贴 vlog 的创作,怎么算都是百利而无一害,所以这是很多平台开始扶持 vlog 的原因.
