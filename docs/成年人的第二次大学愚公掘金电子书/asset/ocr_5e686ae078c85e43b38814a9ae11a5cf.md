# 2. 同行里应该中国人外国人都有，怎么在竞争中形成优势？

Lin：更好的产品，更好的文案，更好的定位，更多的预算。：）要形成优势的话，那就是你的数据累计。
facebook 广告平台的 pixel 像素是所有的广告互动数据，当你累计大量数据以后，你可以根据这些用户数据画像去做更多的产品尝试。
