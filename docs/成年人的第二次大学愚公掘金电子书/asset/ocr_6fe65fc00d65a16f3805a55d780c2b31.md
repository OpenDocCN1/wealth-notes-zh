# 3. 如何引流，成本投入和人员构成是什么样的？

岁月静好：引流就是多开店铺，把大量的时间和精力投在开店以及选品，成本投入就是店铺押金、周转资金、公司一些固定开支，还有一部分软件费，想对选品有帮助的要买一万多一年的软件服务费，还有一些触碰到规则的罚金。
