# 13、如何积累的用户？

乐尚：累积用户的方法，这就是做买家群了，赚佣金的，应该是这段时间评价比较火。

# 14、微信群是怎么积累的呢？这个方便分享吗？

乐尚：微信群这一块是做买家的。现在应该都是前期一个群里面拉一部分人。然后通过送礼品给钱的方式裂变。不断裂变不断增加人。
