# Q&A:

1. 付费项目线下和线上都有吗？客单价大概多少？

夏天：付费项目目前主要集中在线下。客单价视课程/活动不同而不同，按成本和目的的不同来设置，比如有一些活动，我们就是纯引流的，那么就是只要转发朋友圈就能参加，这个属于客单价为零；有一些课程，做了好些年了，客源获取比较稳定，那么就主要以赚钱为目标，就会比较贵，比如3000元/4次；还有一些课程是刚刚发展起来，还需要培育市场，就会介于这两者之间，比如1200元/10次。
