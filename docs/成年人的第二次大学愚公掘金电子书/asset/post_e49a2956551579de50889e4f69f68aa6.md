## Q&A:

### 1、只要资源在于qq群么？

乐尚：资源很多，只要单子质量好，帮你推广的淘客太多了。

### 2、请问大佬，一般情况下，流量到下单的转化率是有多高呢？

乐尚：一般情况下，10%左右。

### 3、招人培训主要让他们做什么内容呢？

乐尚：找淘宝卖家，去问他们需要推广吗？需要推广了，加微信谈力度。核心就这一个工作。

### 4、招商就是对上对接卖家，下对接淘客，上下游是怎么聚集到用户的呢？

乐尚：上游我们去大批量的找商家，一天一个业务员要聊300个左右的商家，下游的淘客，他们是赚佣金的，也就是淘宝客的佣金，自然会去多搞点用户。

### 5、单子质量的判断是依据哪几个维度？

乐尚：品牌，券后价，佣金，天猫。

### 6、对于类目是否有偏向？

乐尚：类目，就居家日用，食品。也就是一直需要的，例如卫生纸，垃圾袋。高复购行业。

7、淘客卷的收益者是买家，淘客佣金是淘客推手的主要获利来源，比如商家佣金设置40%，淘客可以设置20%放出去给消费者，剩下20%就是淘客自己利润，是否可以这样理解？

乐尚：淘客赚佣金。我们赚商家的服务费。用户赚这个优惠券便宜。不过也会有的淘客，会以返利的形式给用户。例如这个产品是40%佣金。他们会给用户返20%。自己会留20%。

8、据我了解淘客还是在快消、服装的非刚需类目比较活跃，刚需类目比如说电视机，马桶这些怎么操作的呢？

乐尚：电视机马桶的话。应该淘客很少去推广。我们现在主要是打造爆款。也就是一单我们可以赚几千几万。像电视机马桶我们就走日常单。

乐尚：ab单之前一直在做，之后应该是淘宝封杀就彻底不做了，现在做ab单完全就是买家激活群里用户。来增加活跃用的，并且ab单有一定几率封阿里巴巴账户，一般做ab单都需要好多阿里巴巴账户来操作。ab单一般就是3000单1000单左右就是商家来拉评分的，量大了很多商家也承受不住。

# 资源站

影视站里面用到的资源，是从哪里来的呢？ 答案是「资源站」。

资源站是提供给影视站采集用的，所有的资源都会有专人进行维护，每天都会更新资源。做资源的人为了给不懂技术的新站长使用，一般都会制作一个简易的采集教程。有的资源站还会把伦理资源放出来，供站长筛选。资源站里的资源能涵盖市面上绝大多数的观影需求(如果缺片还可以联系管理添加)。

![](img/5688f8284c7103ed77046cfddaf3da13_35_0.png)

资源站一般都长这样。

资源站一般都会把视频资源加上水印(资源站网址、滚动广告), 然后把处理好的视频上传到云端(这又涉及了一个灰产领域, 感兴趣的话可以继续深入分享), 再把视频链接提供给站长们。刚刚影视站里第二张截图的滚动广告就是这种。

资源站一般也会作为解析接口的备用资源，因为解析接口由于技术 和成本的原因 不能解析全部类型的视频(为什么不能解析呢？这得说视频平台安全机制了，感兴趣的话可以继续深入分享)，那么就会将不能解析的视频用资源站作为备用播放。资源站在视频中添加水印，滚屏广告(一般色情、菠菜居多)。去站长的群撒广告推广靠口碑传播就行了。

# 解析接口

刚刚提到了解析接口

解析接口的功能就是通过技术手段，把一些视频突破了平台的限制，如去90秒广告、去除中间广告、去除贴片广告、去除VIP限制、去除购买电影券的限制等。**解析接口分为两类，收费和免费。**

免费接口是长这样的 http://jx.xxxxx.com/?url=要破解的视频地址。接口是可以判断用户使用什么设备播放的，大部分的接口都是在移动端有广告，部分接口PC端有广告，有精明的会在晚8-10点投广告。提示：链接是假的，这里只是展示下接口的格式

收费的接口大概可以分为两套收费标准，一是包月XX元钱，二是按量解析一次XX「解析点」，解析接口其实和github的一个开源项目(you-get)有些相似，如果感兴趣 的可以了解下 https://github.com/soimort/you-get 。

解析接口都支持什么解析平台呢 说出来吓你一跳。

免费的解析接口现在只能靠广告联盟进行赚钱，20万的ip一天可以赚小两千。解析接口想推广 首先接口质量得好，必须秒解析 无限速 最差的画质是高清，符合这些条件 很好推广，去同行群里发广告就行了。

# 影视类APP

下面开始分享一下影视类APP。

在说APP之前，其实还有两个地方可以说一下的，就是公众号和小程序。这两个在18年的时候也很火热，后来微信审查力度大了，封号快 做这两个的人就很少了。其实无非就是通过公众号或小程序把影视站封装起来，这里就一带而过了。

我是17年11月23号开始做APP的，当初纯粹为了玩，为了锻炼技术，当我看见市面上有同类产品（做的不如我的）能赚钱的时候，心里开始痒痒了。于是在18年做了2.0版本，并推广运营(我的app免费无广告体验相对较好)，天真的我想要干过同类产品，最终现实给我上了一课。没推出去后，APP扔那快半年了没有管，有一天闲着无聊看友盟数据，发现用户居然有上升趋势！于是开始投入点时间进行维护，维护后从新增几十人 到 新增几千人，当时的心情和赚多少钱没关系了，就觉得APP做成了，不赚钱无所谓 但是我没白干！现在用户已经有25万，次日留存50%左右，使用时长30分以上占60%左右，新用户4周留存22%左右，活跃用户4周留存50左右。
