于是痛定思痛，开始只做自己擅长的事，并且注重长期积盈利。第一桶金是通过选品、写推文、找流量投放的方式赚到的，比较成功的爆款可以赚六位数，比较忙的时候拉了小伙伴兼职处理。

不过这种模式，仍然是以产品为核心，不符合长期积累影响力的要求，所以后面你知道了，开始做自媒体，而且效果还可以——其实也是积累的结果。

# 4. 坚韧

以上三点，是我选出来的，对我比较重要的几个转折点。但如果用一句话总结过去几年，我觉得最重要的是：

追求当一个持续的聪明人。聪明、思考、总结，很重要——但持续的去当个聪明人更重要。

不少花友知道我晚睡，其实我的作息是这样：一点半左右睡，八点半左右起床，一周至少工作六天——这个作息我坚持很久了。
