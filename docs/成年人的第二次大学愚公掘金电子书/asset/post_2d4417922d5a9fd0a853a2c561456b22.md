## 前言

大家好，我是花爷。

当我整理电子书，面对几十万的内容时才意识到，原来半年时间里，我们已经创造了如此丰富的回忆。

不害臊的说，我从小学习能力比较强，在朋友的印象里，我经常和差生一起厮混，却还能考全班前几名。但大学之后，我的成绩非常差，每学期挂科好几门的那种差。但比挂科更让我惊奇的是，我发现考前几名的学霸和我其实并没有本质的区别，反正他们考高分的学科以后都不太用得上。

带着这个疑问，我只身跑到上海实习，成了整个学院最早外出实习的人。而几年后，我终于解开了当初的疑惑，也终于明白了一个道理：

这个国家的教育，代表着他们希望你变成什么样的人，只有进入社会后的自学，才是你自己想要变成的那个人。

所以，在写公众号之前，我确定了以下几点客观事实：

- 1. 随着意识觉醒，会有越来越多渴望突破天花板的社会中层
- 2. 赚钱是大多数人的切实目标
- 3. 能赚到大钱的永远是绝对少数，但能赚到一定原始积累的人数会指数级扩大
- 4. 快速完成原始积累已经是小概率事件，但通过正确的引导，可以培养赚钱的能力，提高原始积累的概率

基于此，我根据自身经验，在成立付费社群“愚公掘金”前提出，培养赚钱能力的过程需要四个阶段：

- 1. 开眼开智：

大多数的中产、白领、中小生意人，在自己的领域钻了太久，已经形成思维定式了。偶尔抬起头，想做件事情的时候，懵圈了，不知道该干嘛。

我们缺的不是大道理，而是眼界、实例推演、和细节。

- 2. 复制：

将别人案例中的技巧，移植到你自己的领域里。虽然前几次移植尝试，大概率会失败。

- 3. 贯通：

失败的经历，会转化成经验，成为你的虚拟资产。你开始更深入的理解了商业、社会和人性本质，理解社会运转的元规则。贯通后的你，不一定能马上变现，但在能力、分析、情商上都会有巨大的提升。

- 4. 跨越：

贯通的人，最终会找到一个合适的领域，将自己的思维、方法变现。这个阶段有早有晚，甚至可能需要一点运气。有意思的是，大多数人从贯通到跨越，都不再完全从事自己原先专注的领域。

如今，“愚公掘金”已经成立半年有余，这半年里我主要为付费会员提供更多开眼开智的内容，很高兴的是，已经有一部分花友通过“复制”获得了收入。当然，我还是要说，短期内赚没赚到钱并不是特别紧要的事，当你明确感觉到自己比以前更好时，惊喜一定会在未来发生。

因为内容太多，这次电子书只精选了“愚公掘金”过去半年最值得看的部分内容，主要包括三个部分：

- 1. 掘金案例：

20个不同领域、适合不同人群的掘金案例，全部由具备实操经验的花友分享，你可能会从中找到适合自己的方向。

### 分享：

大家好，先给大家介绍一下，我是做淘客招商这个行业的。

淘客这一块其实很简单，要我讲的话可能就几句话就讲完了，淘宝客说白了就是给商家卖东西的，那么在这个中间有好几个环节，商家要想把东西推出去，他必须得找好的淘客，找到好的淘客，还得给高的佣金和优惠券，然后那些买家群的淘客看到这个产品，会编辑文案发到他们用户群。

买家群的淘客，就是会把一大帮子想在网上想便宜买东西的人聚集在群里，然后整理产品给他们。我们是做招商的，就是最上游，就是找商家要不要推广的，要了我们就接下来这个单子，和商家谈力度。
