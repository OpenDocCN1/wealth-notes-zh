# 故事三：中心城市有资源的人，他们这么玩（二）

这个故事离我更远，因为我只是听一位前辈讲过，而自己还没有机会操作。当然啦，这位前辈德高望重，绝对不会乱说，所以真实性是可以保证的，但是其中细节我尚无法参透，只能先把一个轮廓告诉大家。故事的发生地点还是在拥有丰富高校资源的城市，这两年流行一种面向企业或政府单位的培训。基本模式就是需要培训的单位通过中间人，在高校门口挂一个横幅，“**单位大学培训**”，租一间这个高校的教室，请1-2位这个高校相关专业的老师（视培训需求而定）。然后这个来培训的企业或政府单位就可以高调宣称“组织多少人在某某高校接受了为期*天的培训”了，而实际上这个培训跟这个高校一丁点关系都没有，只是借门头挂了个横幅拍了个合影、租了间教室、请了俩老师。但是这笔培训费用是极为丰厚的。

这里面自然有利可图，但可以想见需要搞定的人也不会少，但我觉得还是可以尝试一下的。毕竟这个路径只要走通一遍，后面的都可以如法炮制，而且这种需求只会越来越多，市场还是挺大的。
