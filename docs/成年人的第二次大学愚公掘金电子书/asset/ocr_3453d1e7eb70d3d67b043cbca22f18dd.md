# 5.2如何判断一个活动策划的成果：

活动成果很难量化，去判断一个活动是否成功，主要看两个方面：

一是现场气氛，活动好不好，大家享受不享受，投入不投入，兴奋不兴奋，是有序进行的还是混乱不堪的，这个是一看就能看出来的；

二是活动之后的意见反馈，因为和客户平时关系都维护得比较好，再加上你特别真诚地去问，不要带有任何导向性，多问几遍，多问几个人，自然就能得到比较真实的反馈；

还有一点也可以作为判断的补充，就是看大家发朋友圈的积极性，比如有一次我们做了一个“红楼梦里度佳节”的活动，现场逼格很高，大家都拿起手机拍视频发朋友圈，一时间朋友圈被刷屏，那就说明大家很满意这个活动。当然，有时候不发也不代表不喜欢这个活动，也有可能是活动本身让人很有收获，但是画面感比较差，拍不出啥内容，不适合发圈。所以说这一点只能当作参考。
