# 18、目前行业基准的服务费和佣金大概在什么水平呢？

乐尚：券后价格的8%到10%是服务费。

# 19、你觉得你是如何谈到一手优质单的 靠的是什么？拼服务费？ 拼影响力？ 拼谁更勤奋？

乐尚：一手单就是拼谁更勤奋，二手单就是拼服务费。不过我们这边目前不做拼服务费这个事情。我便宜一毛他便宜5毛，天天在争这个事。

# 20、淘客可以兼职做吗，兼职做大概每天需要投入多少时间？兼职一个月大概能赚多少钱？有没有可能教退休的爸妈做淘客赚钱？

乐尚：很多淘客都是兼职做的，举个最简单的道理，你能把你小区的人聚集到一个微信群里面。，然后每天在群里面分享产品。一个月最起码3000~5000块佣金收入。官方上一年公布的数据，淘客的群体已经达到了300万。就是做那些买家淘客的人。
