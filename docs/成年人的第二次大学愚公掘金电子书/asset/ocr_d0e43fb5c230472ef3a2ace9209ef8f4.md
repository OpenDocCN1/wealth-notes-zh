光光：对于影视站就是及时的下架律师函中提到的影片。资源站和解析风险相对小，根本没人管，除非同行举报。APP可以参考乐尚和麻花，还有一种办法就是我现在用的：做很多壳子！100万用户在一个APP上容易被盯住，但假如我有10个壳子(每个壳子功能一样，就名字不一样 )，这样一个APP就10万用户 就相当安全了。

# 3.咳咳 破解，这个不会犯法吗？还是说用户量大了，才会被盯上？

光光：侵权当然犯法了，理论上 如果同行、客户不举报、政治上不严打、不去视频平台叫嚣都没什么问题。当初乐尚的代理们去腾讯、爱奇艺这些视频平台发弹幕... 特别嚣张。但如果像麻花一样有后台 会规避风险(不卖卡 不做三级分销)还是相对安全的。

# 4. 破解的网站或者视频是通过什么渠道进行传播，扩张？如何说服顾客买单？

光光：传播分人群，有的人借爱奇艺会员用 有的直接爱奇艺包年。想让后者使用这类产品很难，但是前者的用户体量很大~ 有的通过社交渠道自传播，有的为了利益去主动传播。
