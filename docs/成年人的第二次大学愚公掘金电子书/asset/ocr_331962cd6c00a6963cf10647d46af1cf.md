# 回答：

1.不开培训机构是对的，你老公不同意是对的，因为你确实在冒险。我在星球里回答过几个培训机构的问题，也给过一些建议方案，但再好的方案，没有合适的人执行也成不了。

2.你主动帮培训机构的老板招生，这很棒，但从你的描述里，我至少看出来两个问题：

a.第一次帮忙做招生的事，感觉没什么收获，这太正常了。我一直在说，别觉得人家成功是一两年的事，那都是积久的积累。你之前没有积累基础，就更好做好要积累几年的准备，不要嫌几年时间长，你现在不积累，一辈子都积累不起来，一辈子的时间更长。

b.第一次做招生，你觉得没学到什么，这时候正确的做法是什么？是你想一想，如果再给你一次机会，你可以如何更主动一些，如何去认识更多人，如何去接触更多环节。一开始总是在外围浅尝辄止的，没关系，再深入一点，比如和人家吃个饭，没事多聊聊促进关系，让人家多教教你，等等等等，只要你愿意主动出击，还有很多机会可以做。
