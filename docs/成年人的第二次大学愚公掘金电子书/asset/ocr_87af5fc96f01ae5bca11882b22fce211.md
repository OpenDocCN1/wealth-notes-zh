Lin: 出口一直是国家鼓励的。唯一的风险是目的国政策风险，我们基本都是国内直邮发货。所以相对来说目的国国家要监管也比较难。不像B2B贸易，一票货被盯上麻烦就很多 损失也很大。另外还有个相对比较麻烦的是资金回流。初期交易量小的时候，我觉得不需要考虑这个问题。如果交易量大的话，香港公司，美国公司就很有必要了。这个有兴趣回头我再展开讲。

# 4. 代发时产品遇到纠纷，退换货之类的怎么处理？

Lin: 看问题。如果是我们的问题，直接退款，产品也不要求客户退回 了。如果是客户的问题，给些下次购物的优惠券。还不行？就商量部分退款。

# 5. 货物的关税怎么处理，发货量太大海关不会限制？

Lin: 走小包，没有关税。税其实都已经算在运费里了。我们没有遇到限制的情况。发货量大，反而运费更加便宜了。哈哈
