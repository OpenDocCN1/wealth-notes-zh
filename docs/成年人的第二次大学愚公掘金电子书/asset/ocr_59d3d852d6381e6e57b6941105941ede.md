# 分享：

回到正题讲 dropshipping。

**主要分**为3大板块：**选品，**推广，**运营**。

刚起步时我们人少，所以挑核心工作去做，也就是**决定** **业务成败最关键的部分：** **选品和****推广**。其实每一个板块拆分出来其实有很多工作可以做。要成功通过 facebook 广告推出一个爆款出来，我们最后总结出来：**选品占 40%，广告素材 35%，受众定位 25%**。爆款当中其实也会有分大小， 我们暂借归类为：小爆，中爆，大爆，颠覆人生爆。各自对应 100-200美金/天，300-400美金/天，1k-2k美金/天，3k以上/天，可以做个参考。

**选品：**

接下来说下选品。

dropshipping的选品是个频率很高的工作。我们一周大 概要测试30-40个产品，多的时候一周60-70个都有，看 自己情况和预算。每个产品我们会给个100刀的预算，能 测试跑出来的，我们才会考虑扩量，否则直接 pass 下一 个。
