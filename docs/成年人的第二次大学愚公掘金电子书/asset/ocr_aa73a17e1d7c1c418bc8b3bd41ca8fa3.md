# 处罚等级

+   1. **处罚后果**：商品移除资源位、禁止上新、移除广告。
**处罚时间**：三天

+   2. 物流服务和投诉两项指标均高于五倍类目均会会受到二级惩罚
**处罚后果**：商品移除资源位、禁止上新、禁止上架、禁止上资源位、移除广告；
**处罚时间**：一个月（一个月无法上新）

+   3. 三级惩罚跟售后相关，务必做好售后尽量避免平台介入，如果店铺纠纷高于类目5倍可能就会受到三级惩罚。
**处罚后果**：商品全部下架、禁止上新、禁止上架

# 项目管理：

人员管理
设计合理的人事制度和薪资架构，优化人员配置，培养多几口能替人选，以防止人员空缺造成的损失

硬件配置
资金允许的情况下，硬件配置尽量配一整套。比如鼠标键盘必须让自家拿手不乏，运营程序体验流畅，有电脑等，还有各新标签等线路的多特性

产品数据
产品数据的好坏，直接反映了店铺产品的好坏，进一步需要是：挖掘一款爆品，拯救颓势，避免可能会停不损失

财务制度
在运营开始阶段，就要建立规范制度财务制度，建立管理好制度，因为财务利水，把握看住，更是根本
