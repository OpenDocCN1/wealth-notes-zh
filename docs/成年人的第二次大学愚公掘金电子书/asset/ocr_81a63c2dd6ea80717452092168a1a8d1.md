这个很难一言以蔽之地去概括，但就目前 的经验来看，卖得好的课程和活动都或多或少 有以下几个特点:

+   一、有趣、新奇、以前没怎么见过;

+   二、高大上、雅致、有内涵，但不至于太高深;

+   三、入门容易，短期内能见到成积;

+   四、有利于发朋友圈装逼。

# 12.2利润重心是课程费还是课程附加的服务或商品售卖费？

目前还是课程费用，后期会更多倾向于开发课程相关的 商品和周边，另外前面提到的定制活动利润也还不错。

# 12.3客户注重的或者说项目规划的重点是课程本身，还 是课程给客户带来的圈际沟通空间及闲暇时间消磨的愉 悦感？

活动和课程本身，这是核心，其他都是围绕这个产生 的。
