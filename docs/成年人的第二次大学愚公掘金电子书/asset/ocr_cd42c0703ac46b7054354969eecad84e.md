# 5.1课程如何推广：

第一，所有在我们这里参加过活动或课程的人，都会在我们不同的群里，这些群就成了我们推广的阵地；

第二，其他不在任何群里的朋友，比如过来参观的游客和领导啦，我们也会想办法让ta关注公众号或者加客服号，这样也能触发一些信息的到达；

第三，我们街区的微信公号会常年转发我们的内容，算是一个官方的推广；

第四，和客户性质相近的组织或机构进行异业合作，互相导流，如高端瑜伽馆等。

说实话宣传渠道这一块其实一直都比较弱，目前主要还是靠口碑和熟人圈，还有请的大咖自带的流量。所以今年也在学习社群运营、被动涨粉这些技巧，希望今后能有所改观。
