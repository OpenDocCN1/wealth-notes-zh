現在，讓我們來看看「特別費用」的問題。在第4季被扣除的1,880萬美元（每股88美分），顯然是很重要的。它究竟應該完全予以忽略，還是應該從盈餘中全部扣除，或者應該部分忽略、部分扣除呢？警覺的投資者心裡可能有點疑惑：為什麼在1970年年底時，很多公司都出現此類的特別扣除，但前幾年卻沒有這種情況？難道會計作帳裡頭，出現了某些靈巧的義大利工匠（當然，這裡所做的一切，肯定都在合法範圍之內）？$^2$ 我們仔細觀察後就會發現，這些費用是在實際損益發生之前就先認列，這麼一來它對未來的「基本盈餘」就不會產生不利影響了。在某些極端的情況下，人們可以利用這種做法，讓隨後的盈餘看起來比實際盈餘高出將近一倍——只要透過某種形式的稅賦抵免就可以了。

關於美國鋁業公司所列出的這些特別費用，我們首先要弄清楚它們是怎麼來的。附註內容表明非常具體，這些扣除額來自於4個地方：

+   1. 企業管理階層對可能關閉鋁造部門的費用預估。
2. 企業管理階層對美國鋁業公司有可能關閉鑄造廠的費用估計。
3. 企業管理階層對美國鋁業信貸公司逐步退出市場的虧損估計。
4. 還有，完成「慕牆」需要大約530萬美元的費用。

所有這些項目涉及到的都是未來的成本與虧損。人們很容易就可以看得出來，這些全都不是1970年「正常營運結果」的一部分——不過，如果是這樣，那又應該將這些項目歸屬於哪一部分呢？難道這些項目都是如此「特別而不經常發生」，以至於沒有適當的歸屬項目？像美國鋁業公司這樣年營業額高達15億美元的企業，一定有很多的單位、部門和分部。

2. 在此，葛拉漢指的是從義大利移民到美國的石雕匠靈巧的手藝。1900年代初期，他們在整個紐約地區從事建築物的雕刻裝飾。同樣地，會計師也可以將簡單的財務事實轉變為複雜、或甚至是無法理解的樣式。
