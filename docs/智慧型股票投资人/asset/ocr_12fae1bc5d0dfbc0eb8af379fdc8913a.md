# 公用事業股的「解决办法」

如果我们现在转向公用事业股这一领域，就会发现该领域让投资者更有安全感、更有吸引力。$^{8}$在此，从业绩记录和价格比率来看，绝大多数的股票似乎都正好适合我们所定义的防御型投资者的需要。对于公用事业股的检视，我们排除了一项标准，即流动资产相对流动负债之比率。这一行业的营运资本因素无需人们去关注，因为它可以透过出售债券和股票来获得成长所需的资金。然而，我们会要求股本与债务之间必须维持一个适当的比率。$^{9}$
