当只有想法或非常小的产品时，你就应该测试这个市场的需求。具体怎么做呢？

# 第一步：找到你的种子客户

他们应该具有以下这些特点。

+   • 你信任的人。

+   • 至少10人以上。

+   • 有不同的背景、学历、行业，单身或已婚。总之，样本要具有多样性。

+   • 找年轻人。年轻人指的是年龄或心态年轻的人。年轻人往往有更多的猎奇心，更愿意尝试新鲜事物。

# 第二步：一对一私聊

可以问他们以下几个问题。

+   • 你对这个想法怎么看？

+   • 你有这方面的痛点急需解决吗？

+   • 你对我这个想法有什么意见或建议？

# 第三步：尝试销售产品给他们

可以问他们以下几个问题。

+   • 你愿意购买吗？

+   • 你愿意付多少钱？
