# 第三大动作：角色分配

在社群运营中，群主应该想办法激发所有人的参与度，不能只是自己一个人演独角戏。参与的人越多，气氛越热烈。

因此，一个社群运营应该有不同的角色分工。以我的社群为例，我有班主任、运营官、小组长、学习委员、鼓励官、点评官、赋能官、宣传官……不同的运营官有不同的角色定位。这些角色可以鼓励群成员主动申请参加，然后从众多人选中挑选合适的人。

你可能会担心没有人参与，事实上，每次我们招募运营官，都有超过30%的人申请，每次都是典型的“竞争上岗”。
