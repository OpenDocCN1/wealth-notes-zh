# 3-1 做當沖，開盤前務必先做好功課！

事前收集並分析基礎資訊，才能大致理解價格在一日之內的變動原因，並進行預測，或是察覺預測和實際變動的差異所產生的不協調感。

做超短期買賣時，需要什麼事前準備？過去有許多做超短期買賣的交易員，不用看新聞，也不需要做分析，只要在開盤前一刻到公司，觀察委託單再進行交易即可。但股市沒這麼好混，如果你能靠這種方法一路贏下去，八成擁有天才般的投資靈敏度。

我也有一段時期迷上當日沖銷，並且投入大筆資金。當你冒著如此大的風險，就算是當沖，盈虧也會有相當大的振盪。如果此時完全不做準備，在缺乏足夠依據的狀態下交易，心臟恐怕會承受不了。所以，從維持心理層面的觀點來看，即使是當沖，我也不會輕忽事前準備。

為了在短時間內重複進行同樣的交易流程，交易員必須儘可能簡化在盤中關注的資訊，因此應事先收集並整理
