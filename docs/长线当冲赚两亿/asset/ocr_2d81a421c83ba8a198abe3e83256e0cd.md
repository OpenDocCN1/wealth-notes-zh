# ### 3-7 停利或停損點，不是看賺或賠多少來決定，而要......

行情絕對不會照自己的想法走，既然要靠股價的變動獲利，停利或停損點都應該依股價的變動客觀決定。

停利的目標價位與避免大賠的停損點，都必須以股價為基準，本節要思考該如何設定。

可能有些人會用「賺了多少就停利」或「賠了多少就停損」來決定，但這只是主觀想法。行情絕對不會照自己的想法走，既然要靠股價的變動獲利，停利或停損點都應該依股價的變動來客觀決定。

另外還有一個重點，就是進場和出場的依據要一致，或是有合理的共通點，兩者必須有一貫性。

超短期買賣時，雖然用技術分析進場，結果卻看委託單的氣氛出場。中長期投資時，明明依據基本面進場，最後卻用技術分析出場。這類進出場依據不一致的案例，經常出現在股市中。反覆進行這樣的交易，當你回顧交易記錄時，會搞不清楚自己到底是要抓哪種獲利、想進行什麼
