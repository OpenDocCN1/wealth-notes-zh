# 对 βᵢ 的理解：

+   1. **βᵢ = σᵢᴹ / σᴹ²**：单个证券风险（σᵢᴹ）对市场组合风险（σᴹ²）的贡献程度；

+   2. **σᵢᴹ = βᵢ · σᴹ²**：单个证券风险与市场组合风险的关系；

+   3. **βᵢ = [E(rᵢ) − r_f] / [E(rᴹ) − r_f]**：单个证券超额收益率与市场超额收益率的敏感程度；

+   - **β > 0**：证券收益与市场组合收益正相关；
+   - **β < 0**：证券收益与市场组合收益负相关；
+   - **|β| > 1**：进取型证券，波动率大于市场波动；
+   - **|β| < 1**：保守型证券，波动率小于市场波动。
