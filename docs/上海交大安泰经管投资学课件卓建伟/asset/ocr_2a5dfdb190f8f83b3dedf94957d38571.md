# Example 5.2 Annualized Rates of Return

Suppose prices of zero-coupon Treasuries with $100 face value and various maturities are as follows. We find the total return of each security by using Equation 5.6:

| Horizon, T | Price, P(T) | [100/ P(T)] − 1 | Risk-Free Return for Given Horizon |
|---|---|---|---|
| Half-year | $97.36 | 100/97.36 − 1 = .0271 | r_f(.5) = 2.71% |
| 1 year | $95.52 | 100/95.52 − 1 = .0469 | r_f(1) = 4.69% |
| 25 years | $23.30 | 100/23.30 − 1 = 3.2918 | r_f(25) = 329.18% |
