# 7：信息差：

人类之中，但凡赚到大钱的，要么垄断，要么利用信息差。

> ——洛克菲勒

信息差这东西，是个人都知道，但往往容易忽视它的威力。

因为总有一种声音在告诉你： “如今是信息社会，任何信息都趋向透明化，早已没有那么多空子可钻。”

大众往往认为： “信息化程度高意味着：获取信息越来越容易，我知道的事情应该越来越多了才对。”
