# 看上了个小鲜肉

（玛丽莎小说）

菜菜，我今年 37 岁，已婚已育妇女，老公对我很好，这些年家里置了几套房产，都有我
的名字（按照你的标准来看，他是好男人），如果不是因为前任出现，我想我和他合是很幸福的。
前任是富二代，我小康家庭，大学校友，我们是彼此的初恋，当年十分相爱。因为他父母强烈
反对（剧情跟电视剧一样，他家庭出现危机，父母希望他和官家女联姻），我受不了那么大的压
力（如果他公司倒闭了我就是罪人），狠心离开了他，离开了那个有他的城市，切断了跟他的联系，跟
所有我们共同认识的人划清界限。从那以后，我感觉自己的心死了，再也没法投入那么多热情去爱
一个 人。

前几个月我们戏剧性地重逢了，他质问我为最初为什么那么决绝，为什么不相信他能摆平一
切，不会负责，说话话他的眼圈红了，直了眼眶，我也觉得不能 自己，他没有和那个官家女联姻，
而是自己扛起重担，让一个摇摇欲坠的公司又走上了正轨，然后更大变现。当然，这花了他很多
精力和时间，这些年一直单身，没结婚，也没谈过恋爱，他说他没办法再爱上了，他已经决定一
辈子不结婚。他父母见他这么多年结婚不谈恋爱，也看着了，不敢再管他。他曾对我说，无论父
母怎么逼他，他都不会顺从，他不会受他们摆布，他爱我，永远不会放弃我，但我当初太懦弱了，
没有给他足够的信任。我很后悔，也很痛恨自己当初的决定。

他说他不会要求我回到他身边，只要远远地看着我过就好，只要我幸福就好。

菜菜，也许没有人能理解我们之间的感情，现在的人都说太贵了，没有人会相信世上有他
那样的男人，也没有人会相信，无论过去和现在，我爱你，我金钱无关。

我跟老公关系也很融洽，就像亲人一样，我也不忍伤害他。

其实我也不知道我表达什么，就这样吧。
