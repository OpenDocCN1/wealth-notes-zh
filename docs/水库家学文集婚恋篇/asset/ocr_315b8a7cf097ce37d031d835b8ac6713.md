# “天下男人都没用的货”

有个师妹，自己很努力，靠打工和奖学金，美国好大学的研究生毕业。但是，她实在是郁闷，人生中没有遇到一个幸福的男人。

+   一、随我老爸，欠了一屁股债，到处躲，还经常打她妈妈，家徒四壁，她也没有嫁妆。
二、老公是个傻木头，既缺自己长好算着妹，没房子，没存款，又须眉，父母包袱很重，只能找个没房子的国企老公受累，话说清不楚，一天到晚拖个手机上网。
三、公公也是个受累，婆婆住院也不管，只管自己炒股，唱歌，拉二胡，同学会。
前两年，为了买房子，把男方家里的确金罐子，逼着公公婆婆拿了一百万，现在，全家终于过上了内环线一百平米的生活，她私下说，出了门，根本不想老公，只想女儿。

她教育女儿是这样的：天下男人都没用的货。

女人走到这个地步，真是悲哀呀！
