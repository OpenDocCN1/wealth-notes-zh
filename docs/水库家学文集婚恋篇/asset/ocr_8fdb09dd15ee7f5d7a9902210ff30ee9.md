# 老男人保养行情

菜菜：这个压价实在是太凶残了！我所说的是 1 年 50 起步价。

@上海辣小御柳

结合多个离婚房子和老男人保养行情，得出一个很有意思的结论：

就是包养一个小三的价格差不多和房租等同，就是老男人在自己工作的地方租一个五六十平米修饰行的一室户。

老男人多半四十多事业有成，小姑娘二十多，大学刚毕业京都沪漂，房租也是不小的开支，确实实在不舒服，老男人给租个房子，每月过来几次，吃几顿饭，保持长期稳定关系，当然也不允许和其他男生乱来，有点类似古代的妾。

然后节日，生日，老男人再送几个包包，一年十几万的开销，在精英眼里也是很小一笔钱，小姑娘除了生理价值，还有情绪价值提供，各取所需。

而且老男人总有很多社会资源，这毕竟算计了，老男人也会帮助小姑娘事业上尽快上路，走上正轨。
