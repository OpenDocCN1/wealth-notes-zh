# 我担心老公想入非非

菜菜，我是陈纸，我老公 27 岁，对面楼的那家女人，三十几岁，经常穿小内裤和胸罩在阳台上拿个东西，应该是洗烫后拿换的衣服，大概是几分钟钟。我老公已经看过好几次了，那女的，白花身花的一身肉，身材比我还好点。我担心老公想入非非。我怎么处理？我气死了。

# 我他妈的更加郁闷

菜菜，你上一条微博是阳台上拿东西。我他妈的更加郁闷。我住在老小区，隔音不好，隔壁那个死女人，一到晚上十一点，就开始撕心裂肺的叫床。我恨死她了，总不能我们的生活按照她的时间安排吧？我有一点贴了纸条说，晚上不要吵梁，我是很含蓄的。那个女人说，他们感情很好，从来不吵梁，我说错人了。难道我要直接去投吗？

# 我现在生不如死

我和老婆一起十年，感情一般，但女方也没什么错，浑浑噩噩活到现在，现在劈腿了一个小三，感觉自己浑身舒服，找到真爱了。我是为了道义，牺牲自己，还是不管不顾，放飞自我？老婆条件一般，年龄偏大，要是离婚，她今后就很难了。但我真喜欢那个小三，我 40 岁，老婆 35 岁，小三 23 岁。

为了这个决定，我已经毁食难安了，小三也不可能再等我多久了。

答：用几次就好了。不要太当真。另外，最后给小三一些分手费吧，像个男人一样。

# 不要相信女人的温柔

我和菜媒谈朋友的时候，菜媒真是温柔体贴，貌美如花，我觉得自己很幸福。婚后几年，我满个天啊，女人那叫变得快啊！现在，菜媒就是头母老虎，动不动就干架，一言不合，摔锅砸碗，和 22 岁的时候，简直是两个人。女人的什么温柔，都是假的。她们本质上都是为了控制男人。

# 时间太短了

菜菜，我是浙江未婚媳妇，年龄是三十九头，老大了不小了。男票在外人眼里是优质，人帅钱多工作好，但就那事情，哎呦，时间太短了，传宗接代应该可以，但其他快乐就沒有了。如果换人，我这一年龄已经太尴尬，不能够多久了，如果不换人，这辈子过得就是清汤寡水了。我其实很享受那个事情，问问姐妹们，如何克服心理压力？

# 为钱还是为情？

菜菜，我今年 43 岁男，年薪百万多，大企业部门正职，有个小姑娘刚刚毕业进单位。我是随便撩撩的，没想到居然撩上了。她很讨喜欢我，愿意等我离婚，给我一年不到的时间。我试用过了，超满意。问：如何辨别是为钱还是为情？
