# 杭州出了个奇葩离婚案

婆婆把 200 平米的春花月豪宅，让给儿子媳妇住，又在大姑婆老家庭买了一套房子，作为他们名义上的房。婆娶到城房子，和九十多岁的老父母一起住。

婆婆能这样，在我们江浙沪地区的老百姓看来，已经算好的了。当然，婆婆的内心真实想法大概是，过段时间搬回家去。毕竟 200 平米住三代人是可以的。
