# 昨天被老男人打了一个耳光

我今年 31 岁，漂亮大长腿，老校花，离异女，工作是铁饭碗，一年十几万，类似杭州这样的城市吧。离异后，也不在乎年龄了，有个比我大二十岁成功大款追我，上市公司前几大股东，我也同意了。大叔对我真的好，先是给了几百万现金，各种礼物不断，给他，他脾气暴躁。

昨天我也情绪不好，发炮闹了一个多小时，主要是领结婚证的事情。我当时气急了，去抓他的脸，他可能也在飙心，直接给我一耳光，打出五个指印。我当时怒了，哭着回家了。我走在回家的路上，听着手里的音乐，慢慢的独自流泪。

偶尔回一次娘家，爸妈看到我很高兴，我本来是要回家哭诉的，突然觉得，我不应该再给父母添麻烦了。于是强颜欢笑，陪父母聊天。爸妈不知道我的心情，一再表扬我。爸爸说我给他买的小轿车很漂亮，成为退休老头里的大款了。妈妈的按摩椅几万元，也很好用。家里的人参膏，大补肾，西洋参，龙井茶，应有尽有，各种新电器，例如苹果手机，抽湿机，暖风机，空气净化器一应俱全。

我无言以对。这些都是那个老男人买的，委托我送过来的。我第二天醒来，摆的高化妆品也都是老男人买的。我开车去上班，车也是老男人买的。身上三万元的大衣，也是老男人送的。银行卡里的三百万，也是老男人给的。欧美旅游，海鲜大餐，一个电话就可以解决任何麻烦。所有的一切都是那个打了我一个耳光的老男人给的。

就为了这一个耳光，我就要重新开始吗？菜菜，你帮帮我，告诉我答案！

答：把老头的微信给我，我去揍他！
