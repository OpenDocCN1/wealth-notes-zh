# 白富美绝不和富二代结婚

但是，对于白富美，你的人生就真麻烦了。任何企业，特别是大中型企业，肯定是要银行贷款的，千万或亿。银行必须要求法人的家族老小去签字，到时候执行方便，你不去？你不去签字，公婆当法院叫你着。

你不去签字了，你就不是你，你的档案带就夹在了那个你从未没有操作过的公司了。一且出问题，你就改名叫“黑名单老婆”了。你婚前父母给你的一切资产都会被法院划定，全部是银行的。花无百日红。你结婚后还有五十年的生活。经济社会变化太快了，那有什么五十年长盛不衰的企业？你的命运还不如嫁个大叔等遗产更划算。
