只希望这位姑娘及时止损，当你长大了，有了自己的家庭的时候，你就会觉得非常羞耻，这根本就不是感情，而是不要脸的老男人在玩弄你而已。

# ## 总结下来这些姑娘都有几个共同特征（十四）

看了那个姑娘的事情，我非常心疼，我也特别理解这个姑娘的感受，我算是一个小富三代，父母过亿，我个人资产目前千万以上。我身边有很多这样的姑娘，包括我姐姐。总结下来这些姑娘都有几个共同特征：

+   1. 成长环境中父母极其强势，父母自己一般都有强迫症，不仅强迫自己，更强迫孩子。你读这个姑娘看上去很忧郁，我就更感觉成长于这样的环境。

+   2. 父母在年轻时候基本都有跨越阶层的努力，因此孩子于长期陪伴就非常多，童年时期对孩子的要求也极其苛刻，我可能阐述得不好，总之这种苛刻对于孩子会留下非常深刻的心理阴影。

+   3. 父母之间相处模式就有很大的问题。比如我一个朋友，父母都是富豪，这一生都是在彼此算计中度过的，为什么会给那么多财产在孩字名下？仅仅是父母为了保全自己，孩子常常也只是父母利用的工具。

+   4. 因为这样的女孩子从小钱就不是任何问题，她们对钱也丝毫看不上，基本就是没钱概念，说什么自己能过苦日子啊，卖房子帮男方还债啊之类的。钱对于她们而言就是纸。

+   5. 这样的女孩子本身性格有极大缺陷，脾气暴躁，自己也很强迫症。大叔应该很多时侯都很顺从她。
