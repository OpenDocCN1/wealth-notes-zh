# 我朋友 28 岁底层公务员

年收入到手 18 万，上海户籍，一套内环老公破小婚房，他能找到什么款式的？

答：你这个收入，我一看就知道是什么单位了。撩拨后勤保障处的小姑娘，隔壁单位的五姑娘，也就这样了。

# 老公能力差怎么办？

我是女汉子，年入 38 万。老公人好，家务活抢着干，但是能力差，还是个事项。他天天忙进忙出跑业务，但好几年赚不到钱。最近还给他姐姐货款担保 25 万。姐姐亏了，他全都赔钱，最后我来兜底。

这种婚姻让我经济绝望了，实在是看不到任何希望。离不离？

# 我不是渣男

女票，我已经用了三年，心里话是用到吐了，毫无兴趣。但是没办法，我是大单位，怕事，只能硬着头皮去结婚。

准丈母娘拎不清，提了好多要求，我把这些条件整理成微信，发到朋友圈了，主要是给单位同事看的。然后，顺势分手了。

现在，女方追打到单位了。我们单位没有一个人同情女方，我工作也没受影响。但是，我接下来要谈新对象，还是得补偿她几万元，各让一步，了结此事。你说多少金额合适？

答：找个中间人去说说，应该行。我看，你的一年工资吧。

# 不想耽误自己，也不想便宜屌丝

某总，28 独女未婚，集体京户，五户，妆后六分，个子高，已在省会购房，重点本硕，在做自己的小事业，但还无法自己两年内赚一套北京房子，家里帮不上，大家也帮不上，不想耽误自己，可也不想便宜屌丝。你看这样行不行，找个 1-2 分的北京经济适用男，有个住房，户口也落到房子里，再找 9 漂亮聪明的做个种，生个娃，让男的养几年，孩子大了，自己事业稳定了赚钱了，再离婚，各不耽误，可行吗，还有更好办法吗？

我备注一下：京沪集体户口，生孩子是不能落在集体户口的，必须回原籍。但是，这个姑娘又买不起北京房子，所以出了这么个想法。

# 70 岁老爷子，出轨了

我爷爷过动手手里将近 400 万，出院了，老爷子 70 了，出轨对象像 50 多，我奶奶精神不太好，不敢告诉她，爸爸妈妈现在已经是避重趋轻，想找我爷爷对质，会不会老爷子一激动，这些钱不分给我们了，万一他真这么做怎么办？

答：这事情况用的。老爷子想女人想疯了，根本没考虑你们。我看看算了。
