# 外来的媳妇复仇记

我是川妹子，远嫁到北京已经有 13 年了，老公对我很好，因为他说是他的梦想就是娶个四川媳妇，美梦成真，很开心。但他妈觉得北京人最高贵，所以瞧不起我外地来的。

她以前老在我面前说姥爷是看城门的官，有多了不起，言外之意是奉攀他们家了！尼玛我外祖父和爷爷还是 GMD 的大军官呢！但说这些有毛线用啊。

早年她老在我老公面前说我坏话，挑拨我们夫妻关系，但我老公立场很明确，直接对她说，我媳妇是我自己挑的，你要满意不满意，我自己满意就行。她妈气昏古七了，说家里两套房，一套也不给你！

我老公还有个哥哥，很有钱，但性格变态，喜欢耍女人，不想结婚，只想让人帮他生孩子。他妈特偏心他哥，从小他哥要什么有什么，我老公要什么没什么。我老公曾怀疑自己不是她亲生的，心理阴影很大，但他爸对他还不错。

他哥等这么大年龄了，没结婚，没孩子，他妈对他有点失望，于是主动提出给我老公一套房，让我卖了，我们自己再凑点，买套大房子，但大房子不允许加我的名字。为了顺利拿到房子，我老公只有答应。

于是 2015 年底我们用他妈卖房的钱加自己的钱买了一套大三居，他把房本给他妈看了之后，我们就去房管局加了我的名字，她妈不知道。

今年大年三十吃团圆饭，老公说他现在也释怀了，虽然她妈以前对他不好，但这套房算是弥补了，让我给他个面子，给他妈个好脸色，要是他知道我们之前把那些网页也都加上了我名字（老公婚前买的），更要气昏古七！外地两套房就不说了，没有北京房子值钱，一套是两个人的名字，一套是我一个人的名字。

在婆婆婆的这场战争中，我算是赢了吧，但我表面上还得装成个啥也没得到的受气小媳妇，憋屈。
