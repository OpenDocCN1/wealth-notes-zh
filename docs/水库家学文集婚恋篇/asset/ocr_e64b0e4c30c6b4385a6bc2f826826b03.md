# 老丈人要把好关

女儿应该找个门风好的，有房子的对象。儿子没房子的原因：

一是吃喝嫖赌抽，公差只要粘上一个，全家完球。

二是有毛病，看着着的全家都是傻。

三是懒，一辈子吃父兄光。工地上一个月万把快的工作，比比皆是。市场经济几十年了，还这么卷功，无非是懒病。富在家里面孩子不找钱啊。

四是贪慕虚荣。某屌丝，一辈子就想出风头，好不容易换了个官位，又开始发神经，去学人家当老板，亏得底掉。

五是赖赖了跨免征，利息高啊，几十万打水漂了。

六是炒股，”几啊，等老爸发财了，给你上私立初中，住别墅”。十多年过去了，啥工作也不想干，也没钱，就剩下一个光溜溜的免费账号了，继承吧。

“几啊，做人要有志气，自己买房，现在微博上的几个大屌丝都是自己买房。倒插门也行！你就别来烦我了。我还准备 A 股翻身，把隔壁小区的王府领赎回来呢！”
