# 采桑，我是管家婆

老公今年 36 岁了，人品还可以，一切收入都花在我这里。他月入一万多，平时花不了什么钱，上班有单位的班车，中午有单位餐厅，每月结余的餐费卡，可以换几条红双喜和几桶油，生活品都是我淘宝的。你看，每个月给他多少零花钱就行了？我考虑大方一点，给他 1200 元，加班车费算在里面了。你看是不是给多了？男人甭管，不管不行啊！

答：我觉得给 500 元就够了，只要他有钱找个车嫖资，还要什么钱啊！另外你注意，有些大单位还会年底发现金，五六千是很正常的。这一部分的额外收入，是大漏洞，经常被老男人们私藏截流了，性质恶劣，影响极坏。

做好管理工作，既要关口前移，预防在先，还要警钟长鸣，责任落地。你要定期和不定期相结合，时不时地搜一下他的小钱包，如果出现了和零花钱不符合的物品，必须一查到底，绝不手软。任何人打招呼都不行。

管理老公的工作，是一项长期而复杂的斗争。我们既要打的赢攻坚战，也要打的起持久战。我们要高瞻远瞩，目光长远，站在本地区社会经济长远稳定发展的高度，审时度势，紧抓不辍。

管理男人的任务，艰巨而又光荣，这是我们的历史任务。

责无旁贷，舍我其谁！
