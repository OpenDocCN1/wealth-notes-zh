# 他老婆嘲笑我没名分，是破鞋

我男朋友和他老婆已经没感情了，他们共有公司股权 60%，公司高管经理有 40% 股权。

其实这公司是我男朋友一个人创办的，只不过他老婆吃了一个现成的夫妻共同财产。如果我男朋友离婚，就失去公司控制权了。

我委找律师查过了。但他不离婚，我一直是个三，他老婆经常嘲笑我没名分，是破鞋。我气的经常想哭。

# 我和闺蜜，谁更幸福？

菜菜，我是外地女，当年和同宿舍的闺蜜，师范大毕业一起来南京。

二十五年，弹指一挥间。她结婚找了好几个真爱，现在是中年女屌丝。

我找了个高中老师，外地人，眼镜猪头男（现在也毒习惯 了），攒下 3 套房和 1 个儿子，还有个代步车。我不爱我老公，但双方也没有偷人，就是过日子。

我和闺蜜，谁更幸福？

# 我和前男友因为他妈妈分手

前男友和我当初很相爱，分手因为他的妈妈。

三年了。我离开了他的城市，在外地创业，等我觉得现在的能力，能是够好的站在他身边，想找他，才发现他已婚。

但是据说婚姻不是很幸福，我知道应该控制自己不去想，但是我就是放不下，有什么方法让我忘记，我拼命努力的工作，就是为了自己更好的站在她身边。

答：千里送医的老戏码又双上满了！

# 老公嘴骚

谈朋友时就喜欢说，这个女生腿好看，胸大好。怀孕时，他天天和我想出去玩。

人是好人，做家务，上交所有钱，脾气好，嘴贱的小姐妹用昵称。他是大学老师，经常对我说，学校里这么多美女大长腿。

是不是理工技术男都这么闷骚！每次听他吹嘴骚，就心疼将要抱住自己，表面却风淡云轻。

# 男票不想买房，想买车

菜菜，我是妹纸，在南京。男票不想买房，想先买车。我想问问，南京房价会会跌吗？

答：按照这么多年的历史经验，南京，跌最多一年 10%，涨就是一年 50% 甚至更高。遇到这种男票，你以后苦了！
