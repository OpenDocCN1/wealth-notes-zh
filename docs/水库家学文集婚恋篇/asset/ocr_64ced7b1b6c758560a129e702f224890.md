# 帅气老公没主见，今后怎么办？

菜菜，我是个小公主，家里条件非常好，找对象挑花了眼，选了一个最帅的。

婚后发现，他只会天天去上班，体制内副科，人品还好，没有犯桃花，其他万事不管，实际上也没能力管。本质上，他是妈宝，没主见，不会打交道，但由于我们和婆婆一起住，所以没有什么直接矛盾。

现在，我爸妈每年倒贴五十万，婆婆倒贴十万，日子过的还算舒服。但双方父母也老了，今后怎么办？

# 接上贴

年收入：双方父母补贴60万，老公15-20万。我带孩子，暂时不上班

总支出：

+   1. 漂亮小区三居室的房租水电气，20万（我想买北京豪宅，首付1200万，双方家长没抗气）

+   2. 保姆，12万打包价，我还压了价的。

+   3. 吃饭水果日用品，每月2万不到，20万，主要是网上配送，附近没有菜市场。我和保姆一日三餐，孩子和老公是早晚晚餐，周末自己做餐。孩子吃的比较贵一点。

+   4. 孩子幼儿园，6万，一般档次

+   5. 养车，3-5万，很节约了

+   6. 两个黄金周，国内外，四个人出去，两个标间，合计5-10万，拖拖搂搂的

+   7. 聚会轮流买单，意外开支（修车），买个大件例如苹果耳机，几万块

基本不剩钱了，还没买什么衣服化妆品。日子还是紧巴巴的。

租个三居室的原因，保姆带娃，小夫妻，双方老人时不时来一个星期。确实需要三间房。这个小区，环境整洁，绿树成荫，人车分流，孩子比较安全。
