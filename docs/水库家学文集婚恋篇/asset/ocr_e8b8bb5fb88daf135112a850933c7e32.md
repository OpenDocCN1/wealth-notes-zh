# 婆家不同意加名字

菜菜，我是已婚妇女，30岁，无娃。婆家不同意加名字，我俩家只能给自己首付四个小户型，但现在已婚，二套房首付七成，利息1.1倍，买了还是夫妻共同财产。

这种关系婚姻再继续下去，我这辈子就没房子了。现在，婆家三两天头显摆优越感。离不离？

答：离。

# 加名字

我只是把广大已婚年纪妇女的心声说出来了。

少数富裕妇女家里有点陪嫁，无所谓加名字，但这毕竟是少数。

广大三四线城市农村待嫁女性，还是希望男方给予一定的保障，生了孩子后，被出轨男一脚踹了，至少不会居无定所，像浮萍一样四处漂荡。

# 前男友得知我要买房，又哭又闹

我前男友贷款买了一套房，他自己名字，不加我名字。

他得知我要买房以后，又哭又闹。

我买房了，他首先失去优越感。其次，我家钱被我转换为婚前财产。

我买房不是为了防着他，而是我的梦想。他匿名到误导我刷爆信用卡逾期，这样我房贷就批不下来了。被我识破，细思极恐，目前他已滚。

# 我很幸运

18岁读大学的时候，父母就买了一套漂亮公寓送给我，在我名下；

24岁领结婚证的时候，公婆第一时间扯我去看新房，由我挑小区挑户型，真气全款，加了我名（我从没提过这方面的要求）；

今年我26岁了，自己的工作很好，养活自己没问题，踏实生活，踏实管好全家的钱。疼我的父母、厚道的公婆和老公、一直很努力自己。都是我安全感的来源！
