# 为什么公务员男生最抢手？

上海年轻公务员，工资不高，比工地拎灰桶的小工也差不多。但是，不管天南海北，大受丈母娘欢迎，这是有深刻原因的。

+   一是单位监督备行。现在的异性诱惑实在是太多了。我一个又穷又丑的大叔，微博上有点小名气，都有女粉丝看得上我。要是你在外面开个小公司，那不是十里挑花了？丈母娘怎么放心的下？

+   二是身体智智有保证。公务员体检标准比婚检还高，至少没有传染病。考的上公考的，智商一般不差，如果是通过法律考试，进入法检队伍的，那算上傻上的智力了。

+   三是收入逐渐增加。公务员的优点是，低开高走，年龄越大，收入越高，这在丈母娘那里是加分项目，很多码农，一开始高工资，超过四十岁，高台跳水了。公务员四十岁才算起步。

+   四是有少许社会地位，不说占便宜，至少不会受欺负。遇到不法侵营，总可以找单位领导求助。
