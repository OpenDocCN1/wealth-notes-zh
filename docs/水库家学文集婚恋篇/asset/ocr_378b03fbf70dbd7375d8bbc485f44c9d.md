# 小王今年离开上海了

小王是华中某一级地级市姑娘，2009 年鸡兔年科毕业后就来到上海了。她是她随遇而安的人，因为男票坚持来上海，她也就来了。男票父亲是地级市的实权人物家庭（超级有面子），但是父母闹离婚，当儿子的心病，不想看到他们。

来上海后，两个年轻人靠着自己找工作，收入还是可以的。2012 年（可能不准确），小王结婚，面临要买房。在上海只能买最破最脏的那种五十年代的市区房子。在地级市，可以买市中心漂亮小区三居室。就在这个左右为难的时候，男方家长电话，市中心某楼盘开盘，前几名签约的可以优惠九折，总价是 72 万，减 7 万，七万是 2012 他一个人的年收入。
