# 我对出轨没兴趣

我都四十多岁了，女人会看上我什么呢？这个世界上有一部分人就是崇拜成功者。但是，为什么崇拜成功者？归根结底，权或钱。

嫖娼肯定是找死，传染病太多了，就不要自找苦吃了。有人就说出轨，搞个小三之类的。

一，小三在哪里？

你在超市看到一个漂亮姑娘，是不是能去问要不要做小三的。否则，一个大嘴巴子就来了。你也是已婚人士了，正常人也不可能给你介绍对象。小三的最大来源，应该是在生活工作中自己认识的，要到了手机号。小部分是狐朋狗友介绍。

二，女人图什么？

你都四五十岁了，人家二十几岁，总要图点什么，否则亏大了。

+   1. 权力。这个男人或许没什么大钱，但职务高也可以。我能够把你的影响力变成利益。这就够了。

+   2. 金钱。你有钱，咱一起吃啊。先给五十万零花钱。

+   4. 周旋。女人单身久了，也要活动一下各种零件，就算便宜你了，以后开个车，跑个腿的，你麻烦点。这种情况很少。

三，用了之后会如何？
