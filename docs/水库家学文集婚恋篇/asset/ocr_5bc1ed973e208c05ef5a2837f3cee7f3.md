# 这男的实在是太抠门

答：这款式，妹纸你以后用起来麻烦。反正，婚后没有共同财产，闹翻了，你就是被白用几年而已。

从你的微博来看，你这样的条件，靠自己翻身很难了，我有自知之明，我不求过上富太太的生活，只想安稳，好好相夫教子，所以，这对我来是不是获得想要的生活的机会呢？
