# 拉单子的女人

我和男票都是外地人，是做通用技术的，核心竞争力是拉单子，秘密都在 under table。男票已婚，不可能裂我，对我很好。他是这个行业的资深人士，比我大六岁，负责场面上交际应酬，垫付前期资金。拉单子，我在公司里负责落实技术细节和安排工作进度。赚钱后，他四我六。

他来了，就和我睡。大概是 4-10 月份，入冬后，没生意了，他就回老家陪老娘了。我也回自己老家过年。这几年，我个人赚了省会一个大三层，现在价值五百万，无贷款。我是村里最有出息姑娘，把父母接到省会住上了漂亮房子。

我今年 36 岁了，因为半年在外地，半年在老家，没相亲恋爱，但类似已于婚生活了。我对男票充满感恩，我是农村出来的姑娘，自学大专。本来是路子是，十几年前找个偏远村里的农民，婚后在电子厂流水线打工。带孩子。

机缘巧合，我遇上了男票，让我当上了老板，赚了不少钱，生活体面。现在，各种场合，人家都叫我“张总”，管了十几个大男人。我非常有满足。只要男票愿意娶我，我可以等一辈子。

问题是，他明确说，为了家里两个孩子，他不可能离婚。他同意，我结婚后，彻底断了，再来往了。我这年龄了，再不结婚就麻烦了。如果我结婚了，这层关系就算了断，即使老东西再维持几年单生，终究也不是事。

要钱，还是嫁人？笨笨，你帮我拿个主意。

答：生个孩子，其他慢慢再说。

# 小鲜肉？不存在的

菜菜，我中年离婚妇女，43 岁，孩子读上大学了。资产丰厚。我在网上看到什么小鲜肉，一开始也有想法，实际上基本不可能。健身房用发廊拉单子的那帮爷，都是村炮，要给他们送昂贵礼物，刷卡，缴费，送礼，还要给人玩。他们玩起来不把你当人用，简直是乱用。私下还被人体羞辱，我的自尊心也受不了。

现在，我也想开了，托人在介绍，想找个比我大几岁的事业单位离异男士，就是个伴侣。能不能结婚也不强求，大家年龄相当，一起过日子就行了。

提醒一下其他姐妹，不要以为有几套房子就可以胡思乱想了。这个社会很现实的。离婚不是解药，只是溃烂。大家想清楚了。

# 本地女怎么在市区男面前不自卑？

我是上海本地土著女，刚刚毕业工作不久，之前认识了一个大我十多岁的市区男。他言语里挺高在上，有点看不起本地人，和我讲话都故意普通话，说怕被带我的口音。现在和他拜拜了，但心里一直有个结，很自卑，现在已经不敢交新的男朋友了。
