没房子是什么待遇？惨的不加判。

没房子意味着，你家穷。穷意味着，你的生活质量差。度穷，抠门，节约小钱，不舍得买礼物，不懂得豪华吃喝玩乐，只会在家看苦。毫无乐趣的男人。

没房子意味着，你不可能买很多东西，只能是什么都凑合。连个洗衣机都没有，男人就没有心思买衣服，买书包。衣服鞋子都是旧的。被子常年不晒太阳，都是臭的。连个冰箱也没有，吃的肯定馊烂了，肤色也不好。

没有房子，意味着女方今后的生活压力很大，家庭绝大部分收入要花在房子上，买房租房都是钱。我本来就穷，再加上这么一个支出。女人的十年青春就算被毁了。更不要说什么环球旅行，买包包了。

我追一个大单位的黑妹胖姑娘（本科，外地人），人家都不要我，对我一脸嫌弃。这不怪人家，她也没房子。

给我介绍的对象，都是远郊区农村的拆迁户女儿，拆迁居民离远的根本不可能正常上下班。

我后来看上一个姑娘，是住在类似于曹杨新村老破小里的。那时候，这种六楼楼，在我的心里，就是世界上最美的房子。结果，人家就是个小二居，也不可能招女婿！

那些年，我是绝望的眼睛都绿了。本来讲，算了，出国谋生吧！

# # 何苦去害人

十几年前，我有一次去复旦校区，拜访一个女同学。她是毕业分配当老师。晚上回出租房时，突降大雨，马路上几乎没人了，非常安静，冬夜里，我一个人在等公交车，路边万家灯火。

我看着那一盏盏暖暖的橘色灯光，多么希望自己在市区也有个小房子，可以和家人挡风挡雨。公交车四十分钟后才来，我浑身湿透，冷得发抖。

那一刻，我就在想，像我这样穷的男人，女人嫁给我也是吃受害苦，何苦去害人啊？

# # 凤凰男

上海丈母娘如何看待县域凤凰男？

我就是凤凰男出身，年轻时侯，市区没房，穷的一B。凤凰男之所以离婚，是因为贫穷，没钱就抠门了，小钱比天大。但是，人心会随着富裕和地位的。

如果你家是小门小户，小知识分子的，尽可能不要找凤凰男。双方家庭，理念差距太大，大家都有点斤斤计较，时间长子，磕磕碰碰矛盾多。

如果丈母娘家是大户，真别太介意了，公婆穷，抠门，势利眼，都是好事啊，给他们买张省会郊区别墅，七人八大锁，安排到希尔顿宾馆吃三天，他们立马就消停了。他们的眼光就这么大了，注意力全部用在炫耀乡里了，会千方百计已结婚如。

大部队top10出身的凤凰男摆脱了后顾之忧，他的优点就明显了，隐忍，坚强，智商高，耐力强。虽然情商可能不太高，但这个可以后天化的。你去看各单位里的安徽人处长，个个是精。

当然，凤凰男可能会秃顶。但是，这是所有人的问题，不要单单算在凤凰男头上。
