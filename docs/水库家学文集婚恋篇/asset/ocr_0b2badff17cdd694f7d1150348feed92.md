# 为什么出轨的男人大多最后并不幸福？

大叔出轨，分为两种：为情，为色。

遇到真爱，例如夫妻关系恶劣，互相伤害感情，大叔发达后，遇到真爱，但毕竟不多。绝大部分男人出轨是为色。比较常见的是 45 岁男娶个 28-35 岁女。小女人嫁大叔，可能也夹杂着一些感情，例如报恩，仰慕，但是归根结底还是为了钱。很多年轻女性比较幼稚，认为嫁个开玛莎拉蒂，开卡爹的大老板，今后什么都解决了。实际上没那么简单。

+   一、经济问题

小女子对婚后经济的渴望值是非常高的。一套 800 万到 1500 万的房子，写自己名字，婚后开支一般要超过 50 万/年。请保姆，养车，吃饭，化妆品，炫耀消费。再存个 20 万的私房钱。

大叔必须能够拿出 1000 万。离高婚前，家庭资产至少应该有 2500 万。男女各一半，再留一点给前面的孩子做抚养费，自己到手也就是 1000 万的资产了。

在北京上海，1000 万的资产，其实是也是很普通的，扔在人群里，一点都不起眼。稍微有点面子的就要 2000 万以上。大叔高婚前一般应该接近半个亿的净资产。这个可能性是微乎其微的。

男人花天阔地，其实用不了多少钱。一年吃喝玩乐，花不了 50 万的。买辆豪华 80 万，多年前买豪宅，也不过是几百万。很多女的就被这个外表给迷惑了，以为男的很有钱。实际上，高婚后，男的拿到 40%，和她结婚，已经不算很富裕了。

+   二、前妻子女

前妻的子女一般十多岁以上，可能很快就要读大学留学结婚了。这个时候做父亲的往往还要拿出一笔钱投资，这就又会触到小妻子的利益，因为她也有孩子。这个矛盾是很难调和的。

+   三，收入下滑

男的 45 岁到达事业顶峰，50 岁之后，生意可能就走下坡路。而女的 30 多一点，正是花钱的时候，男的就想想着点养老钱，女的要奢侈性消费，怎么找钱，矛盾是非常大的。

+   四，体力下滑

咱们不谈性，就说出去玩。逛街，聚会，唱 k，旅游，应酬聚餐，都是非常耗体力的，男性 50 岁后，身体不能跟 30 岁比了，很难每次都全程陪同妻子。而妻子觉得自己很委屈，可别人老公公怎么怎么样，你就这个个样，越说越胃火。

+   五，倒贴娘家

很多女人是苦出身，才下得了狠心嫁大叔，翻身市，往往有一种炫富乡里，倒贴娘家的心态。这个也会引起很多矛盾。

结论：

高婚后，男方拿出 2 千万净资产，日子比较好过，矛盾少。
