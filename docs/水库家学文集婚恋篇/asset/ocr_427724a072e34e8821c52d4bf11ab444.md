# 我被“好单位里的男人”耍了

来来，我被“好单位里的男人”耍了。

男的是在边缘者的好单位，有个小职务，三年后户口可以转回女方家里，单位给他一笔钱，自主选择业，我在省城。男方各方面貌似不错，同意谈恋爱，也同意嫁他用了。

半年后才知道，渣男是离异的，还有个娃在老家，自己有存款，据说还有一些债务，自主选择业更要等五年后。我气得差点就疯了。

# 老婆嫌我收入低，怎么办？

我和我老婆都是外地人，硕士毕业落户上海，双方家境一般。婚前我在郊区买了套小房子，有贷款，无法加名字。婚后老婆对此耿耿于怀，一是嫌房子小，二是房子没加她名字。这是她的心病，为此我们还离过一次婚，让她就可以买套自己的房子（当时我是把所有积蓄都给了她），但是因为种种原因，没有买成，现在已复婚。

我老婆工作非常努力，除了本职工作，还在外面兼职，每周都在忙，是非常辛苦的，周六日本也都在赚外快。她说工作这么拼，就是为了早点再买一套。但是，她的花销较大，上班的工资，基本月光，主要用于买衣服，化妆品，每个月赚外快的钱就是她积蓄。

我曾劝过她，让她少花点，这样可以攒更多钱，但是她不愿意，怪我挣钱太少。我承认挣钱不多，可是老被她这样说，也很郁闷，现在倒班就是经常吵架，每天很烦。

她认为我没有本事，让她过得很累，这是事实。我也很累，为了她上班近点，我之前买的房子没有，我们搬到市区了，我上下班共花四小时吧。如果再赶上加班，基本上晚上10点十分到家，然后还有一堆事情要忙，基本每天（包括不加班的时候）都忙到晚上十点半吧。

# 老公很懒，我该怎么办？

我和老公都是外地人，研究生，上海居住迁证。我一直催老公考个职称，为了办上海户口。但是老公懒情，吃完饭就看电视。没户口，女儿今后要回老家读书了，我 mindset很不开心。于是，我就自己考职称，争取办户口，但是，老公不但帮不忙，还经常抱怨家务没做好，清洁没做好。

我现在，一边上班，一边带孩子，晚上只有两个小时复习功课。老公不帮忙，婆婆不帮忙，甚至房子也不想买，是我爸出钱首付，2014年才买了。

我现在一心的苦熬，就是为了女儿有个好前途。但我这么辛苦，老公就想只顾跟我沾光，不想付出，这公平吗？离婚也不可能了，我这年龄，财富，颜值，都是劣势，还带个孩子，谁会要啊？想想真的气伤心了。
