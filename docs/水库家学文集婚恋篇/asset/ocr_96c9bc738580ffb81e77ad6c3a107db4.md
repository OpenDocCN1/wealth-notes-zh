# 菜菜找你评评理，我该不该离婚？

昨天我去弄了一个包3万，买了一个iphone7，在和闺蜜吃了顿饭，一个下午花掉了4万块钱。我喜滋滋的告诉老公，结果老公立刻黑起了脸。现在已经吵得要离婚了。我觉得我没做错什么呀，他说捐给我的，我也花了，而且是买了又要用的东西。

答：三观不合，抓紧离婚。
