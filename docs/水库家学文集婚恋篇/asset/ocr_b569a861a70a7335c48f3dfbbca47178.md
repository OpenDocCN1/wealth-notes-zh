# # 这个东北故事流传二十年了

我一直不相信是真的，我们都经历过下岗年代，即使下岗了，还是有各级组织关心，介绍工作，几百元生活补助，还有国家发的房子，孩子学费全免，何必去卖淫？

在东北下岗工人的故事里，我总能看到这样一幕：

> 工业区很多工人都家庭双下岗，生活无着，妻子被迫去夜店或按摩门店上班，偶尔得分。丈夫则被银行追讨还住房的房贷，苦于生计，十几口大孩子和乳臭未干的孩子在外流浪或寄宿，午夜下班，再用车载款到出租屋。当地陷入持续之“恐怖萧条”

女人去夜店打灯，或是有人去包夜，其实并非每个时期最惨的窘境。著名“红色记忆”的东北国营食堂供应过他们的兔肉.

一户家庭夫妻下岗，生活艰辛，一日，读中学的儿子回家。说学校要开运动会，老师要家穿运动鞋，家里实在拿不出运动鞋钱，吃过晚饭，孩子开始收拾第二天因为带鞋，天太晚了的话，一顿不说，要他动手不动。第二天不下班，默默背书包去，一跑而下。

要问作者在她关于东北的文字里面，更是写过让我想起来后背寒凉的一段：

一对双交下岗的夫妻，想找工作但没有机会，不想到别人家中做临时给他们带了白饭，终于有一天，这个家庭的小女儿却来了久违的—份猪肉+白米饭，稚气的小脸上满是幸福

小女孩不知道的是，这份饭里，是由她爸爸和妈妈含泪放进去的老鼠药

之前看过自己家族的飞岗经历，会看到有网络认证为本城媒体的网友反驳，下岗潮发生在上个世纪末，2001年根本不会发生这样的事

在铁路沿线偷煤、抢劫江某的时候。大规模下岗在铁路煤矿，矿井挖不上金，带着全家人挖老君煤的事，就发生在2016年春节

# # 我是离异带娃的女老板

相爱皆妹，年收入几百万，家族企业资产几个亿，37岁。离异寻找对象很麻烦。

+   1. 找小鲜肉，一天到晚找我婆要钞票，要吃饱玩，我感觉自己不是被疼爱的女人，而是一个傻乎乎的买单大姐，我也烦死了。
2. 找同龄人的失败者，我还不喜欢。
3. 找同龄的成功者，人家有的是小姑娘倒是，看不上我们这种带孩子的离异小阿姨。
4. 找同龄的专业男，一般都是没钱的，我的意思是，不领证，合则散，不合则散。日常开支我出钱，但要是离婚了，别分我的大型资产，我是男方希望领证，变成夫妻共同财产。

折腾了几年，我 现在是找不到对象了，只能是睡一下了。

答：算了，也别结婚了。有孩子了，开心一天是一天。（又到了男人为女人操心担忧的栏目了）
