# 乡下婆婆强迫我全家吃一只死鸡

我是中环的姑娘，老公是安徽凤凰男。本来也没什么事。前几天，婆婆搭老乡的车，来上海看我们，带了两只土鸡，放在后备库。都是他们当地的土鸡，价格较高，一般两百元一个。这对婆婆而言，算是给我们送大礼物了。上午九点出发，下午三点到我家。我是四点半到家，晚饭准备两只鸡。我在厨房发现，其中一只要肯定是死鸡，我想也没想，就把死鸡扔进了垃圾桶，要炖那只活鸡。

婆婆大怒，她说，下午的时候看过，两个鸡都是活的，现在这个死了，也就一个小时，不得不事，可以吃。我说，上海人绝对不敢吃死鸡的。婆婆也没说什么，炖了那个死鸡了。

晚上，我爸妈来看亲家母。吃饭的时候，婆婆拼命的说她的鸡好，要我爸妈吃，我担心有细菌，就说那只鸡是死的，不能吃。我爸妈胆子小，也不吃了。这下子，惹毛了。整个饭桌就围绕那只鸡死了几个小时争论，大家都恶心。

晚上继续吵了几句后，我老公一下子爆发了，彻底站到他妈那头的，把我的狗血喷头。我准备离婚了。来来，你觉得谁对谁错？

# 请教山东小姐姐

我是苏州小女人，郊区普通人家出身，985 学霸。老公是鲁西南县城，双职工家庭出身，985 学霸。双方出身，学历，收入均匹配。结婚十年，白手起家，一路走来，资产两千万。现在，老公年薪 100 万，我年薪 70 万。再干几年，我们在苏州也是小富家庭了。问题是，我生了个女儿。鲁西南家庭，对生儿子好像有谜一样的兴趣。我因为身体原因，也不可能再生了，老公和公婆三天两头羡慕人家有儿子，可以继承这份家业。我每次听了，都气的哭。我想问问鲁西南的小姐姐，你们要是不生儿子，是不是只能当大房了？

# 强强联合的婚姻，只是一个起点

我见过很多强强联合的婚姻，一方级别高，一方暴有钱。我年轻时候见过一对小夫妻，女方陪伴一百万（当时中环房价四干左右，相当于现在的一千万五去吧）。但是，十多年过去了，恨铁众人矣。

小夫妻婚后起时髦，去留学，花掉了大部分钱钱，房子还是那套婚房。公婆退休几年了，也没什什么的花头了，现在小夫妻同居了，和普通人也差不多。

级别高，也会退休的。钱再多，也会毛掉的。唯一不变的是，金光闪闪的中环线。

# 来来，我是毛脚女婿，准备结婚了。女方提出一个方案。

女方老家小安排 400 万，我家出 400 万，贷款 400 万，买 1200 万的房子。

婚后，女方生三个和我，共同居住，女方娘同意帮带孩子，名字三个人，丈母娘，我和老婆。

我觉得貌似合理，又不合理。大家给点意见。

# 丈母娘给我们准备了婚房

来来，今天，我心思很不舒服。我是外地县城大学坐，现在省会工作，找了当地女票。丈母娘给我们准备了婚房，家电，我心思还是感谢。
