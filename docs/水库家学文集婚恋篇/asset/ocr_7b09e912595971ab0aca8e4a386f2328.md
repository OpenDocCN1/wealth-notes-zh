# 莱菜：二本子的货源又要丰富了

于子哥哥：前我时间在公园里散步，进入一个相亲交流会。

在座的女士普遍比男士看起来要小很多，其中不乏是一些大学刚毕业的女孩。

当时我特别不解，就私底下问了我朋友。

。他说：“你不知道吗？现在女性相亲的普遍年龄是二十三四岁，而且她们觉得这都已经晚了。”

原来，中国姑娘在心理上是害怕变老的，她们害怕“被剩下”。

这些女孩到了 25 岁就诚惶诚恐，其实并不是因为她们真的老了，而是因为外界的干扰。

比如，收到姐妹们的结婚请柬，父母的催促，接着总有人告诉他们，“再过几年就长得挑啦！”

姑娘们压力山大，真的可以理解！

但是，女孩子 25 岁，本是最美好的年华，不该被“老去”的焦虑所包围。

而“剩女”这个词，本来也不应该有意义。

演员王凯在访谈中，就说过对剩女的理解：

“剩女”其实是一个褒义词，因为你足够优秀，有更高的要求，所以感情上会晚一点，但属于你的感情迟早会来。

王凯的话，道破了“剩女”的真实内心。

的确，被称为“剩女”姑娘们，一般都不是被钱剩下，而是因为“挑不到”而剩下。

也就是说，她们本身很优秀，所以一直在等同样优秀的另一半。

因为挑选本身需要时间，要择优就不能快，于是自然而然地被“剩”出来了。

所以，我更愿意叫那些女孩为“单身适龄未婚女青年”，而不是充满恶意的“剩女”。
