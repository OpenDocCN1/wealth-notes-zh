# 男票是兜里没钱的富二代

求助。我是妹纸 23 岁，男票是兜里没钱的富二代。我已经毕业，住到男方家里。

在学校时，男女还蛮平等。现在，男票越来越骄横了，经常气我，吵架也不来哄我。他爸反对

若分手，妹纸已经被自用了三年，不甘心。不分手，苦日子漫漫无期。怎么办？

# 爸妈可能在老家抬不起头了

我是妹纸，22 岁，找了个土豪儿子当男票，年龄相仿，男方英国硕士，我是 985 本科。我已
住到男方家里一年多了。是的，被男票彻底用过了，我鄙意的。

我家是小地方的，我爸妈很自豪我能够找到这么好条件的男人，到处炫耀。那些有女儿的亲戚
们，不相信我还有这好命，能够一步登天，成为豪门正房长媳。他们纷纷等待着看我笑话（被富二
代甩了）。我父母见过男票，催我们快结婚，想在婚礼那天，让那些多年看不起我们家的亲戚们，
羡慕到富贵七。

但是，事情发生了变化。最近，男票经常夜不归宿，经常挖苦我，想甩我了，但等我先开口。
如果真的分手了，最难过的可能是我爸妈，在老家永远抬不起头了。我很痛苦。怎么办？

# 我举个以孕逼婚的例子

男方，真正的豪门，一线城市中等开发，社会职务非常高。

男方，没学历，混社会的，不是坏人，就是小老板级，游走于各色人群，非常漂亮，很会勾人。

女方把富二代搞倒后，怀孕逼婚。男方给儿子找了个门当户对的儿媳。对这个女的出价 80 万
一年，作为婴儿的抚养费。男方先给两百万，让女方回成都买套漂亮大平层，五年前的事情。

现在，女方一个人带孩子，改嫁不容易。抚养费经常拖欠，一般是三十万比较爽气，后面就拖
欠。女方也没法翻脸，就是不听的找男方讨要那要钱，很疲劳。

女方已经找不到这个前住了。因为这个档次的男人，不是住在家里，女方根本没有能力，蹲
省找人。
