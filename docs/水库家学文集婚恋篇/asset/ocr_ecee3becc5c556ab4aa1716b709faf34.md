# 我家是”双百万家庭“（投稿）

男女年龄都过百万的家庭，已经越来越多了。我一开始以为钱多了，生活就会好，但现在越来越痛苦，我和老婆的个性都非常强，大事小事经常吵架。我喜欢大房子，上班近。老婆喜欢金山别墅，老是追求个性的宁静。我不希望孩子读早教班，老婆呢，争取考科大少年轻，四岁就学数学。还有什么老家亲戚往来，买什么牌子的灯具，镜子装在哪里。为了这些事情，大吵三六九，小吵天天有。
