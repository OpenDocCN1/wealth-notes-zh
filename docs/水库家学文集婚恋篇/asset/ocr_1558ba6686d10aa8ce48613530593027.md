# 给未婚小姑娘提个醒

千万不要以为婚嫁有钱大叔你就有钱了，还要看他给不给你花。

我老公比我大十岁离异带儿子，我未攥大学毕业后。当初看上他职业好（外科医生）工资高帅气。

我都没想到他二婚娶不错了，他妈妈反倒嫌弃我没有好的工作（国企、事业编制之类）不同意我们。当初要不是我老公瞒着他妈去和我领结婚证，就要分手了。那个时候以为那就是爱情。

婚内没房，啥也没有，聘礼 3 全啥也没有《每天接我妈骂活该》，领证之后一直住娘家，两年之中怀孕了女儿。没法上班了，矛盾开始出现了。带带孩子就给我两三千一个月给孩子买买衣服都不湿（他一个月三万），我没法上班也不给我生活费。我婆婆还催我赶紧断奶早点去上班。（断奶奶不给我带孩子，她要想孙子，让我给我妈带）我老公每天晚上都看儿子做作业到很晚。月子到今天都是我一个人带孩子 也没钱给我花，孩子快一岁了，自从怀孕到现在都不想跟他发生关系！

他想，我不给，想离婚。口口声声说他赚钱辛苦，要养老，要养两个孩子，还要换房子，要节约，现在想就是对我抠门。

男人赚再多钱都跟我的没关系 主要是给你花多少。如果离婚，我也啥也没有。房子房子都是他的。钱也是他的。他有儿子，女儿自然向我。我 28 岁 离异 带女儿 没有好的工作，还能嫁得好吗？

# 优质男并不一定要娶到优质女

很多男生自身条件好，例如朗博，他大概只看得上欧洲王室公主了。

现在很多男星条件也很好，个子高，皮肤白，家里有大大平层，自己是高学历，五百强公司，年薪六十万，万里挑一的。但是，他们最后不一定混的好。选择太多，迟迟不愿意下注，总以为还有更好的。

年轻时候，看上他的姐妹多，自己乐的开心，常换新常，用几次就甩了，就像是零食袋。反正不停的有雪漂亮女人扑上来，想嫁给她。他呵呵呵的免费试用，开心到 35 岁，头大了。新生代妹妹管他们叫大叔，老嫩女他们也不看上了。好一点的新女友结婚了。自己也不再是万人迷了。

这时候，父母急了，想抱个孙。自己也急了，崩形，隔壁家张小姐的儿子都读小学了，我还在相亲，但周围已经没什么好货了。年轻妹子图你的钱。“你比我大十岁，我吃亏了，加名字”。年纪三十头的女性，往往条件一般，性格不好相处，只是找你凑个对子。你也没办法了，凑一个吧。生完孩子，闲婆家事。

男人跑到四十岁出头，有两个可能，一是事业发达了，舒舒服服娶个腿，美英处。二是碌碌无为，没有出人头地，那这辈子完了，四十多岁的老头子了，三十岁的新生代，分分钟碾死你。

建议：男性在三十岁必须结婚，这是你最后的上限了。不管女方是否你最满意的，必须下注了，没什么大不了的，发财了再换。
