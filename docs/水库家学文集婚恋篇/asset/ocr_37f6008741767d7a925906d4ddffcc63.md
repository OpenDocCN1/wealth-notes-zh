# 说说我的失败婚姻，给妹纸们敲警钟

浙江这里流行结婚两家开一家两头做房间。

结婚的时候说好我家出房车车头贴跟我姓，二胎跟男方姓。头胎儿子出生后男方家长翻脸不认人，说太丢面子后悔了。

月子里吵着要么房子加名字，要么离婚，我爸妈随口答应一直拖着，男方记恨上了，开口要我 家二十万彩礼。我爸妈买了辆四十万的车给他，每个月给三四千零花（全叫他买点奶粉，用不完），每年孝敬他爸妈几万，还是不满意，各种找茬吵架还升级动手。

间了一年多把我搞得产后抑郁，去医院回来的路上把我骂了一顿赶下车，就分居了。分居后一年多不来看孩子不问不闻，心死离婚，孩子跟我。

现在他家为了再娶，到处抹黑我公主病脾气差门楣糟，我爸妈出尔反尔，说是因为我不愿意生 二胎万般无奈才离婚，我们是小地方，我找三十了带儿子离婚人财两空身体搞坏，还被人说，每晚 想起来想气吐血了。
