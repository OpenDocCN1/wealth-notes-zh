# 婚后不孕，是老公的问题

老公是个死胖子，富二代，婚后不育。我检查了：自己没问题，说明是老公的原因。

婆婆上次闲聊随便说了一句，不行就做个试管婴儿。我现在是装糊涂，说再等等，其实已经知道答案了。

我妈的意思是，找个和老公血型相同的人，自然怀孕。我犹豫。如果离婚，啥也没有。不离婚，必须做试管，我也不愿意。

# 钓鱼城的夫妻鄙视上海人生活质量

我上次去钓鱼城，就是南宋抗元，抵御蒙古的川东战场。

风景区遇到一对小夫妻，孩子岁差不多，就一起聊聊天。他们是当地国有单位，老公年薪12万，老婆 10万。

他们鄙视上海人住的小，上班远，生活品质一塌糊涂。他们上班几分钟，家家户户大房子（当地房价六千左右），自驾车，寒暑假几家人合伙自驾游。在当地，读书看病找工作，什么事情都有熟人帮忙，幸福指数极高。

我想半天，觉得他们说的肯定是对的，但是，他们的孩子永远走不出县城了。一旦出走，就是两手空空的手下孩子，不要说宁波定居，就是去台北都难。
