# 82 年还能找到优质男吗？

莱莱，82 年，女，身高 168，工作稳定（好像收入还不错）深圳大平层一套，还能找到优质男吗？

![](bbox=[0.2, 0.21, 0.49, 0.39])

菜菜，内环线老阿姨来求助了。

儿子在沪一本学校大三，被外地妹猪倒了，现在姑娘要上门，姑娘的父母已经见过我儿子了。我和孩子他爸都不想见对方。这个事情怎么处理为好？我愿意做出合适的经济补偿，但是不会同意接纳。儿子名下无房，女方现在没提要求。儿子默不作声，估计也有点后悔了。

女方是小城市的双职工家庭，估计别没有任何经济底子。儿子娶了他们家女儿，估计还要给文母娘养老了。我们家属于中等水平，郊区别墅十内环线三居室。本来儿子考上上财，全家很高兴，现在搞出这么一件事情，郁闷大了。

问问行情，补偿多少钱，算合理了？我们也是讲道理的人家。儿子瞧了人家，据说是新的，我们该给钱也不含糊。但实在是不愿意孩子今后辛辛苦苦给外地家庭养老。

答：我觉得，十万，签字分手。
