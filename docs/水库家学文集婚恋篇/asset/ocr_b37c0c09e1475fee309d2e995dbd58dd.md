# 老汉再娶，要隔几个月？

我的一个老大哥朋友，亿豪，今年 61 岁了。老豪是公司内当家，管钱的。前不久，老婆车祸没了，赔了 80 多万。隔了三个月，老汉要娶一个 32 岁的头婚女（好像是公司财务）。据说是老汉那段时间心痛苦闷，交作业比较积极。财务女可能怀上了。彩礼 88 万。就是车祸赔偿金。

前妻的娘家人不高兴了，他们本来是依靠老爷子的话语权，控制了销售，采购，是公司势力最大的一派，现在失势了。于是，就去挑唆老汉的女儿发难。女儿也确实不高兴。因为后妈比自己还小，以后亿万豪财，肯定不到自己手里了。于是，女儿在外戚的支持下，去打了女财务两个耳光，惹毛了老爸。

老爸立刻提升女财务做了实际内当家，管钱。女财务又在其他部门安插了自己的亲信，专门收集外戚捞好处的蛛丝马迹。这种事情一般抓不到证据，但通过逻辑分析，还是有迹可循的。现在，一家人，四分五裂。

老大哥的意思是，现在公司里都说财务是小三，实际上是领证了。让我去劝劝他女儿，同意老汉办个正常婚礼，女财务强烈要求名正言顺，就我电话了女儿，意思是，老汉这个年龄，总要有人照顾。这事挡不住的。女儿也讲不出个所以然，就一句话，说是这才几个月，时间隔的太近了，心里接受不了。

这我就搞不懂了。大家觉得隔几个月合适？
