# 嫁给富二代？

姑娘，25 岁结婚，活到 75 岁，要经历 50 年。实事求是讲，明星岩，盛宣怀，都没富裕过 50 年，假药停也不过就是短短几年。在经济社会急剧变化的时代，富人都是高杠杆和负人数。一旦败了，负债累累，甚至是大祸临头。

# 带娃的重组家庭，怎么给孩子分配财产

菜菜，你好。华北省的。我带一个儿子，女方带一个女儿，再婚后生了一个儿子。我的收入占总收入的 2/3，女方 1/3。我贡献大。

婚后买了两套房子，一套 600 万，一套 300 万，现金 50 万。我和老婆建议：

+   1. 600 万的房子，留给老三。
2. 300 万的房子，我们在到退休回老家，留给我的儿子。我儿子结婚，我们就不管了。
3. 老婆带来的女儿，给 40 万现金嫁妆。

老婆的意思是：大房子给老三可以。小房子和现金，老大老二各一半。但这样表面看公平，实际后果是：我儿子估计找不到老婆了，而他女儿的嫁妆算是比较丰厚了，我明显吃亏了。

现在，实在是谈不拢。大家想想办法。
