# 我爸想让我找富帅

（上海妹子攒心事）我父亲从小到大对我很好，抚养我到了 985。我在大学里和没什么钱外地男孩朋友。我爸极度暴躁的打了我，他希望我嫁个有钱的，提升家庭阶层。我迫不得已，和男票分手。但是，高富帅也不是那么好找的。怎么办？我很烦。

答：我在家成也遇得到这个事。十年前，小姑娘在外地读大学，找了个外地男票，一路追到上海。父母暴怒，拳打脚踢，拆散了。小姑娘哭了几个月，后来嫁了个上海体制内工作的拆迁哥，三套房。现在小日子好的飞起来，每年出国旅游，买买买。大家都说父母有远见。小姑娘也说当年不懂事，还被外地男票白占了便宜。

# 我爱上了两个儿子的男人

菜菜，我是 211 妹子，22 岁，遇到知根知底的已婚男票。男票今年 30 岁，已经跟离婚前两年多了，两个儿子，养在男方家里，大家都知道。他先闹离婚，再和我谈的。

女方面高价，大概要一千万。男票和她说不找，离婚手续没办下来，如果起涉，涉及到一系列股权分割。

他什么都好，就是 174cm，个子太矮了，我 170cm+高跟跳。我是喜欢他的。他也对我非常温柔体贴，从不大声说话，都是爱护关心。现在有两个麻烦，一是这么拖下去，也不是办法。

二是将来两个儿子归男方，我可怎么办？

答：1，打官司离婚，大概判到两年以上。一般是平均分钱。

2，他的孩子，平时住校，周末交给阿吧。反正不是亲生的。

3，劝说男方只要一个儿子就行了。
