# 劈腿证据分析题

我在单位值班室夜班，单位监控拍到了一把手和女下属，鬼鬼祟祟在一个房间，半个小时后 出来。我觉得他们是通奸，想告他一把。证据够吗？

答：一把手和女员工，在单位里见面，即使是晚上，不能算太奇怪，他完全可以找个勉强合理 的理由。例如私下布置一个比赛任务，临时来取个材料，征求对某件事安排的意见，让办公室某单人 是不是迟到早退等，这些不适合在工作时间交代的话。

虽然这个理由看上去有点可笑，但逻辑上还是成立！最多是工作方法不妥，以后注意。

如果你在宾馆门口拍到了男一女进入宾馆，一小时后出来，那就是实锤了。因为这对男女没有 正当理由在宾馆单独见面，符合我们吃瓜群众的逻辑。
