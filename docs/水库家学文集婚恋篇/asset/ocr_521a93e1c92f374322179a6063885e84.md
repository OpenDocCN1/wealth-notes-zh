# 有人说，上个故事有点假

我刚才仔细想了想，这个案例其实是心理学战术，老男人不会输的。

+   一，妹纸是好人，最多收 1.2 次。

+   二，妹纸贪财，及早摘坑里。

+   三，只吃罐叉，不要炮弹

+   1，这一般是主动给对方的心理准备，女生作为男人随机挑选的被动方，一般也不会有如此强大的诈骗心理素质。

+   2，最后掉秤的时候，如果是各让一步，老男人是可以得手几次的。这事情，女生是有 100% 心理准备的。

+   3，女人如果完全诈骗，也是非常麻烦的。毕竟是在校学生，搞大了，也难看。

+   四，不排除个别男人的某种奇怪心理，例如这个女生长的像初恋之类的。
