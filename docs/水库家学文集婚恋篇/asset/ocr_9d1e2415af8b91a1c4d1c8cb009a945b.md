# ## 双方个性决定婚姻的保质期

 我坚决反对两个 985 的结婚，我周围这种强强联合，看似完美，实际上一般偏缺，很多是离婚的，甚至是三年内就离婚。这里面有个你不知道的逻辑，我来说一下。

 人的个性，千奇百怪。但是考上清华北大的人，个性都是差不多的：苛求完美，超级自信，不容置疑，绝不妥协。

 婚姻家庭有很多事情，共同决策，共担后果，如果两人意见不一，那就无法协调了。装修，买房，投资，吃什么菜，去哪儿玩，甚至看哪个电影，什么事情都会吵起来，双方性格极强，顽固到底。举例，我要投资一个项目，五十万，女方说，风险太大，不行，男方坚决要投。于是开始辩论。

 女方用大数据罗列了男方近五年的各种失误，袜子穿反了，出门忘记关煤气了，也全都算进去。

 男方用大数据证明，女方就是 250，傻婆娘！不是你扛着，我早就发了。

 这种家庭，智商太高，正常人根本劝不了。就算到法院离婚，他们都可以不需复印件，把各种数据，背得清清楚楚。 ”法官，我说的事情在材料的第几页，第几行"。

 这种强强联合，在计划经济时代，是没什 么问题的，大家都是一百元工资，除去吃饭穿衣，剩不下什么了，就没什 么吵架的，但是，在经济形势突飞猛进的现代社会，任何事情都有风险。双方对风险的判断程度不同，又特别自信，绝不妥协，那就说的错了。吵架多了，时间长了，基本没感情了。
