# 上海妹纸嫁入千万豪宅的精确比例

妹纸嫁入豪宅小区，肯定是在豪宅老嫩新娘。这是上海风俗，也是新娘子在亲戚同事面前显摆的机会。

在上海豪宅小区姬求结婚，必须要和物业说一下，给个红包，原因：一是留出停车位，二是稍微放几个鞭炮，物业不要骂丢。扫地大妈增加了工作量，也要意思一下。物业经理，门卫和扫地大妈，每年额外拿红包的事情很少，一般是印象深刻。于是，我就得到了一个非常精确的数据。

我问他们，今年在本豪宅小区结婚的新人有几个？他们说，入住初期的三年，每年有3-5对，占1%，这几年没有了。

98%的上海家庭，其实没什么大钱。房子是虚的，你也不可能卖掉或者抵押借款。上海人经商极少的，生意做大的更少，中产家庭都是靠工资，年入百万又如何？这是业绩说话，不是很稳定的。大部分上海有钱人只是有外快而已，例如三甲主任，外贸公司飞个单。或者少数贪污犯，诈骗犯。

# 内环线已婚妇女说个心路历程

三年前，有两个候选男，相亲认识的。

甲男，靠近内环很漂亮小区三居室，没什么感觉，也不讨厌。乙男，是我最喜欢的款式，文艺男青年，家里内环老破小。我喜欢钱和房子，但心里偏向文艺男青年。我妈以死相逼，要我嫁给甲，最后妥协了。我和甲结婚。

三年后，我因为其他事情，再次进入乙男家里的那个小区，没想到乙男。小区里是一片老破小脏兮兮的景象。花坛里没有花，只有干枯了一半的刹车，泥土裸露，还有破砖头，白色的塑料袋，一股呛味地方的浓烈气味。我不想在那里多站一分钟。我庆幸当年老妈妈给我指明了正确的选择，让我下半辈子住在了鸟语花香的漂亮公寓。

回头想想，如果当年嫁给老破小，可能也习惯了。但我知道，那不是我要的生活，仅仅只是忍耐了自己。我和老公，爱情谈不上，但是感情和信任还是有的，孩子也很乖。我已经满意了。
