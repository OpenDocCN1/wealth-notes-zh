# 紧急叫停某个妹纸

剧情。小粪白被男票白用了1-2年，现在男方要分手。男方父母嫌弃女方家里穷，冷嘲热讽。男方亲戚以为是来吃大户的，没什么好脸色。妹纸气不过，准备通过隐秘手段，把男票家族企业的账上资金卷走，逼他来谈判。

现在是年底企业结账的高峰期，很多家族企业账上有大笔的钱，这些钱是有用途的，千万不能随意动。有的是工人工资，有的是材料款，有的是备务到期。妹纸被逼到这个地步，要卷走的肯定不是小数了。但这些钱被劫走了，男方家生意，年底结不了账，立马就垮了，肯定是报案了。这个妹纸，你现在还只是想法，放弃吧，太危险了。
