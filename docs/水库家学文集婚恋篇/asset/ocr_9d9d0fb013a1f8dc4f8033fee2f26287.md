# 一手烂牌打成四个王炸

（根据真实故事，我瞎编的）

离异外地县城女，39 岁，无房无学历，颜值一般，带个 16 岁的女儿在京沪谋生，就是打杂。女儿不能在沪读高中，读了个京沪职校，反正是不回老家了。这种条件在京沪是比比皆是。

这女的若依靠沪嫁人，估计也只有退休老头了，而且还不一定愿意给房子，她女儿这条件，估计也是农村来沪的屌丝捡盘了。就这一手烂牌，居然给这个女人打出了前所未有的新高度。

女人是在一个京沪大单位外聘的物业公司上班，单位里有个本地房，实在内向，30 岁找不到老婆。物业女就故意接近他。一来二去熟悉了，说要给他介绍女朋友。（本文不是一般套路，别想简单了）。接下来是殿堂级教程了。

+   1. 老婆男也不好意思推辞，物业女带女儿一起陪男方朋友，介绍的对象因故未来，三个人就一起吃了个饭，散场了。

+   2. 过了几天，物业女又找老婆男说，女儿十几六七了，早恋了班上的外地小屌丝。她动不动，让老婆男帮忙劝劝。老婆男闲的无事，就一起去了女方家帮劝。女方是一室一厅租房。物业女就把男和女儿放在客厅，劝谈话。自己躲在小说间没出来。聊了两个小时后发现，也就是小孩子互相拉手，没有什么事情，老婆男就走了。

+   3. 物业女因为这件事情和男方的就近了，时不时说说话。一个星期后，物业女突然和男方说了个惊人的消息：女儿看上男方了，问他愿不愿意谈恋爱？但十八岁之前，未成年人肯定不能发生事情。成年后，女儿点头，她就不管了。男方当场就激怒了。

我们埋一下这个套路，上海男非常内向，县城女条件太差，这是摆不了的。但是物业女通过正常事情，先让男的和女儿认识，进一步让他和小女儿混眼，水到渠成，非常自然。

男方想了两天，急恋不违法，十八岁之前，互相了解一下也可以，保证不发生任何关系。男方下班后，直接去女方家里，大家有默契，直接就像是亲戚串门了。女儿跟男方的聊天。县城女做饭菜。这男的简直是禅到蛋裤子了。

+   4. 县城女看男方完全失去警惕性了，就下手了。某晚，县城女把男的搅了几杯酒后说：我们母女今后都靠你了。姑娘未满十八岁，不能配，是苦了你，今晚我来。你放心病，双方自愿，合法操作。男的熟血沸腾了。

+   5. 打这以后，男方的工资卡就交给女方了。又过了一段时间，女儿满十八周岁，有权合法恋爱了。这时候，男方法问女儿，能不能确立恋爱关系？女儿和母亲都同意，但有要求，用之前，必须买房。否则，只能谈，不能用。因为男方和物业女有那情况，这事也可以缓几天。
