# 日本小姑娘爱上上海男生

无力的善良: 姑娘, 我为你滴爱情流泪

![](bbox=[0.2, 0.63, 0.47, 0.91])

Moe, 日本, 大学生

“在我16岁的时候, 我爱上了一个来日本做交换生的上海男生。当他回到中国后, 我们先失去了联系。我用尽了一切办法重新找到他, 在往后的4年, 我一直在餐厅打工, 终于用这省下来的工钱去上海见到了他。我们恋爱了。他邀请我去他家见做客, 我用学来的中文对他父母说“你好”, 换来的却是完全的不理解。当我和他说谈论到国家大事时, 他对我说, 他的家人不喜欢日本人。所以强烈的反感, 我们分手了。我觉得, 我们两国的年轻人都应该付出更大的努力, 让中日关系变得更好。”
