# 我见过一次婆媳矛盾大战，惊心动魄

男女双方都是河北来沪定居，大学同学。

男方有房子，内环钱大平层，价值千万，无贷款。婆婆一辈子女妇，男人前两年死了，儿子被她管的服服帖帖，儿子没什么大本事，国企一股职员。

女方是小干部家庭，一子一女，女方是好单位，硕士，女方家长的钱全部给儿子买房了，女儿是手工嫁过来的。

婚后，婆媳按规矩性生活，对小姑爷管头管脚。儿媳忍气吞声，熬了几年。有一次，忍无可忍，婆媳大吵一架，婆婆使出杀手锏，让儿媳妇滚出去。

儿媳就回娘家（弟弟家里）了，老丈人看到女儿被欺负了，嚎啕大哭，说是没本事给女儿买房，对不起女儿，这个到不像是装的，确实是有点愧疚。

女儿觉得人生毫无乐趣了，老公是奶生，老婆没钱，老妈不会吵，住在弟弟家里也不是个事情，于是，下了狠心，准备离婚一个人过了。

婆婆无所谓，觉得儿媳肯投钱。

儿子左右为难，如果离婚，自己带个孩子，再娶老婆也不见得行。于是，二选一，站老婆这边了，小夫妻回去和婆婆摊牌了，撤出出去，以后不见面了。

婆婆一个星期后认怂，求媳妇和儿子孙于一起回来。儿媳说，回来可以，房产证改名字，儿子也坚决要求改名字，儿子担心，万一老人再婚，房子就说不清楚了，婆婆不同意。

僵持了半年，婆婆彻底投降，房产证过户。

事后，婆婆为了挽回邻居，在老家亲戚面前说，自己厉害了一辈子，最后被儿媳妇收拾了，不过，儿媳知厉害，管的住男人，儿子家今后肯定兴旺。（真是贱三期）
