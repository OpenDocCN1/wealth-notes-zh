# 我这辈子第一次见到了 bao 月妹

我家门口有个中低价 KTV，名字起的很暧昧，类似于“尊长鹰飞凤凰殿”这种的名字，反正你一看就懂。兔子不吃窝边草，我因为天天要路过这个 KTV，从来不敢进去。这么多年，傍晚时分，我经常看到门口有三三两两的小妹进进出出。

这个 KTV 开了很多年，我相信里面基本是合法的。因为路过的次数实在是太多了，我基本可以推测出，客户是些什么人。

+   1. 黄窗恋的大爷大妈。在我幼小纯洁的心灵里，一直认为这种地方，一般都是不要脸的包工头才会去。实际上错了，这个中低价 KTV，最多的客户居然是交谊舞大爷和大妈。因为这些人我都脸熟。

广场舞分为两种：

一是大妈团，清一色是中老年妇女，跳小苹果为主，没有大爷掺和。

二是男女团，主要是跳交谊舞，就是逗爷男女抱在一起扭的那种。

这个 KTV 最多的是这群交谊舞大妈。我推测，广场舞人太多了，众目睽睽下，也不好意思成猪事，就到这里的来了。来的大妈都是精心打扮的，涂了一点口红。大爷一般是骑助动车来的，大妈是打车或者步行。

+   2. 上海中年妇女，半夜相袭。这个 KTV 隔壁都是小餐馆馆，点菜大概是人均 120 元左右，我以前喜欢半夜一个人去吃点小冷炒，经常看到很多一男一女在里面，最明显的特点是，男女都穿的厚，不喝酒，好像不是很熟悉的样子。年龄都是 40 岁左右，不老天。有一次我半夜十二点独自在里面吃小冷炒，隔壁那桌和我只有三十公分距离，听他们谈话，上海男的四十多岁，开个小公司，上海女高离，刚刚唱歌出来。

+   3. 上妹谈钱的地方。昨天夜里十点，我出去买西瓜，从 KTV 走出一对男女，我们一迫在等红绿灯时，我听到了一场精彩对话。

男：今天晚上就付一次的钱了，我微信给你。如果你觉得合适，明天开始包月。

女：嗯。

我一开始以为他们是移动公司卖 4g 的。扭头一看，我靠，男的可能是 50 岁，类似于村会计的气质，穿了一件质量较好的衬杉，配黑西裤，迈过的，皮肤黝黑，但保养得不错，不是大金链子气质，而是社会会计气质。外姓女，二十多岁一点过，完全素颜马尾辫，八成新的一般连衣裙，165cm 左右，类似于菜场菜来菜的小妹，或超市营业员气质。

最奇怪的是，男的一直紧系的看着女的，女的依头走路，不怎么说话。两个人好像完全不熟悉。霎那间，我看傻了。
