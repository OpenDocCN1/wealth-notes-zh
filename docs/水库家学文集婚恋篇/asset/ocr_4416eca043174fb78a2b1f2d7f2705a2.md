# 婚姻中的忽略，往往来自欺骗

现实中，女方为了面子而欺骗的情况是比比皆是的。主要是：

+   1. 学历。清华函授说成全日制，留学没拿到学历，说成高大上。
2. 家世。老爸是小干部说成中高档次。
3. 陪嫁，不说现。
4. 黑历史，被调零。
5. 夸大收入。

当然，男方也有类似问题。

# 我的软饭表哥

表哥北方小城市工薪家庭出身，现北方某省的大单位正式编制，月薪4~5K，身高颜值6分。相亲认识一女孩：年龄比表哥小3岁。身高颜值6分，海外留学归来，在校老师，家里有矿厂和广告公司。相亲后，女方父亲立即给表哥一辆宝马车x系，九成新。

我表哥大喜，迅速结婚加名字。婚后两月发现：

+   1. 女方文凭是国外野鸡大学，中国都不承认，
2. 女方工作是合同工，月薪3K。
3. 矿厂和广告公司是女方某亲戚的，老公大人是给亲戚打工的，
4. 宝马车是别人借钱的抵押物，人家还债后就拿回去了。苦逼的表哥现在每天挤公交上下班了。

表哥塌了半天足，送出去了半套房，只不过是开了两个月旧宝马，气的天天打老婆。

# 你的婚姻为了什么？

最近，来问婚姻选择题的特别多。各有千秋，各有不足，左右为难。
其实答案很简单。你的婚姻为了什么？
A 为孩子，选择大城市吃苦，给孩子一个前途。
B 为自己，找小地方三居室，天天吃麻辣烫锅。

# 夫妻之间

年轻夫妻之间，维系感情和利益的方式不是契约和房产证，而是无条件的信任。
如果你娶了一个满意的老婆，就要为她全心全意算的打算。房子全部给她，工资全部给她，手机密码给她，这样的婚姻才是让人放心的。
