# 一吵架，我老婆就叫我滚

我是外地男，快三十岁，去年在杭州房子买了，首付我家里就出了十来万，剩下的是女方出。

收入我一年到手10万多，我老婆到手30-40万，我上班清闲，她班不知工资没人说，家里到单位步行五分钟。

现在有个矛盾，一吵架，我老婆就叫我滚，回自己老家，现在我家宝宝也快四个月了，我该咋整，吃软饭好受气？

答：装个吊！我家从来不吵架。

# 怎么防止大叔骗我

某来，我是贫困县姑娘，本科生，非常想去欧美留学。我最近遇到一个大叔愿意给我钱，当然，这事情大家都懂。问题是，怎么防止大叔骗我，或者一年后不管我的学费了？谢谢。

答：让合作伙伴终身满意，天天舒服，就不要担心钱的事情了。
