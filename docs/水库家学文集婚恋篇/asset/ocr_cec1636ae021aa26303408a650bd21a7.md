# 选男票的标准

无非是自然属性和社会属性。

自然属性：身高，学历，相貌，坚持几分钟等。

社会属性：财富，地位，性格，职务，职称，几套房子等。

如果兼而有之，自然最好。如果不能两全，女人直接选择自然属性。社会属性的形成，有运气 的成分，这个男人事业失败了，下一代还有机会。身体好就行了。
