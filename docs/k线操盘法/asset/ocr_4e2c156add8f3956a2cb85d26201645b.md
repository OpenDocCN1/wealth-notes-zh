# 案例19

2004年3月19日星期五，收了一根小紅線，上漲28點，前一天3月18日是收長紅，上漲209點，這根長紅為什麼會大漲？有人說是為了那年的總統大選，看好連戰跟宋楚瑜那一組人馬會當選，所以在3月18日進場大量布局，於是3月18日就大漲了。到了3月19日，漲勢很快慢了下來，只小漲28點，不過還是在十日線之上，大家準備第二天投票選總統去。

3月19日下午，總統候選人陳水扁在台南市區遊行時，突遭槍擊，兩顆子彈很明顯地朝向陳水扁先生及呂秀蓮小姐打來，其中一發子彈擦過陳先生的肚皮，幸好陳桑中年有點發福，魚肚子的油脂抵擋住子彈的火炮攻擊，只留下一點擦傷，沒有生命危險，也因為沒有生命危險，報了個平安，政治當局認為不需要停止選舉，照常投票。
