# 經典案例解讀（七）

# 案例15

2002年10月11日，開高走低，收一根大長黑，下跌97點，這根黑棒跟10月7日的黑棒有一個共同的特徵，就是它的斬殺區都是在4000點到3900點，有種並列的味道，但是10月11日並沒有跳空下跌，也沒有再締造出很漂亮的新低點。10月7日的低點是3910，10月11日的低點是3845，差距雖然達到65點，但還嫌不夠多（夠不夠多要用目測，因為要跟周圍K棒的長度互相比較，視線範圍內會有一大堆的K線，很難用數學講得清楚，只能用肉眼去直接判斷。這就很好比一個花園裡開了很多的花，很難講出眼前的這朵花跟其他花的大小差距是多少，我們只需要用肉眼去判斷這朵花比較大，還是比較小，這樣就可以了）。

重要的是，10月11日跟10月7日的開盤點位置都差不多，同樣是開高走低，下跌的區域範圍大致重疊，這就是所謂的「一個地方洗劫兩次」，第二次如果榨出來的油不夠多，就要小心這一塊地皮已經被榨乾淨了（詳見圖49、圖50）。
