# 王力群 k線操盤法

均線沒有希望躍過了，才會在錘子線發生當天的盤中，留下 一根長長的下影線，意思就是，它在盤中的低點往上拉，拉 成一根長的下影線，在製造下影線的過程當中，股價從低點 拉到相對當天的高點，在這段過程，買方就把手中的多單出 掉，讓給盤中那些回補的空單，或是搶短多的多單。如此的 反彈，可能就會提早夭折，或者只進行一天就失敗了。

養成觀察平均線的習慣之後，緊接著就是型態學。以一根 曰K線為例，先去觀察它附近有沒有重要的中長期平均線經 過，接著再觀察它左邊，也就是在過往的歷史K線中，有沒 有什麼地方被套牢，如果有地方被套牢，那就形成了所謂的 「壓力線」。於是，這根錘子線如果它可以反彈起來的話， 碰到壓力線也會產生挫折。同樣道理，我們把情勢反過來， 如果在過往的歷史當中，某個歷史性的股價附近有個所謂 「底部的支撐」，那麼，錘子線發生的地方只要不要破當時 那個底部的低點，就會形成型態學的「W底」。W的意思是 兩個底部，且右邊的低點比左邊的低點要高一點，就沒有破 底。既然沒有破底，右邊的低檔股價得到左邊低檔股價的支 援，這兩隻腳於是形成一個底部，也就有機會上漲了。以上 是從一根K線觀察它左邊的歷史型態，看看以往的型態是否 能提供它支撐，或是以往的型態有沒有所謂的壓力線構成它 日後上漲的威脅潛伏。
