# K線的第二層境界

K線的第二層境界是「知道自己在想什麼」。
我常常對新手講：如果對於一根K線沒有感覺，就盡量不要去操作它，停止你的交易，不採取行動，也許就是最好的方法。意思是說：如果當事人已經拿到了一套正確的方法，卻還跑不出結果，表示某個地方出了問題。有時候方法出了問題比較好解決，但如果出問題的是自己，那就有鏈瑣了。

在股市中，尤其是是台灣的股票指數期貨市場，人最常出現的問題是「通常他們並不知道自己在想什麼」。

絕大多數人的情況是：還沒有拿到正確的操作方法，就貿然投入股市，就算你的思考正確，也只是在朝向建立自己的操作系統多前進一步而已，系統能不能建立成功還是未知數。這篇文章談的不是這種狀況，我想要討論的是，如果操作者已經拿到了一套正確的操作方法，但是他在使用這套方法時，發現跟實際狀況兜不攏，於是心生疑惑，此時，我會勸這些有疑惑的人乾脆停止操作，以免發生意外。
