
# 王力群 k線操盤法

均線沒有希望躍過了，才會在錘子線發生當天的盤中，留下 一根長長的下影線，意思就是，它在盤中的低點往上拉，拉 成一根長的下影線，在製造下影線的過程當中，股價從低點 拉到相對當天的高點，在這段過程，買方就把手中的多單出 掉，讓給盤中那些回補的空單，或是搶短多的多單。如此的 反彈，可能就會提早夭折，或者只進行一天就失敗了。

養成觀察平均線的習慣之後，緊接著就是型態學。以一根 日K線為例，先去觀察它附近有沒有重要的中長期平均線經 過，接著再觀察它左邊，也就是在過往的歷史K線中，有沒 有什麼地方被套牢，如果有地方被套牢，那就形成了所謂的 「壓力線」。於是，這根錘子線如果它可以反彈起來的話， 碰到壓力線也會產生挫折。同樣道理，我們把情勢反過來， 如果在過往的歷史當中，某個歷史性的股價附近有個所謂 「底部的支撐」，那麼，錘子線發生的地方只要不要破當時 那個底部的低點，就會形成型態學的「W底」。W的意思是 兩個底部，且右邊的低點比左邊的低點要高一點，就沒有破 底。既然沒有破底，右邊的低檔股價得到左邊低檔股價的支 援，這兩隻腳於是形成一個底部，也就有機會上漲了。以上 是從一根K線觀察它左邊的歷史型態，看看以往的型態是否 能提供它支撐，或是以往的型態有沒有所謂的壓力線構成它 日後上漲的威脅潛伏。

有一派技術分析的人士認為，應該另外尋找或發明新的

技術指標來做預測或操作，或是把現有的技術分析中某幾項傳統工具加以利用，就能夠得到更好的效果。這些人覺得更好、更進步的技術方法，已經藏在現有的古老技術工具中。不過，這些古老的工具並不包含一般認為比較難以解讀的平均線與型態學，而是某種更便利、更直接的技術指標。對於這樣的看法，我個人表示不贊成。

我的練功方式是：先了解K線，再了解型態學，然後是平均線。因為不論是預測還是操作，這三種功力的混合使用，也就是融會貫通三者之後的綜合能力是很重要的 —— 本書正是為了這個信念而寫。

# 碰到問題，
贏家都這樣分析

所謂「分析」，應該是科學式思考的一種。

一個東西，可能不是外表看見的那樣，裡頭可能藏有其他東西，我們把它做分解，打開來看，就能看到藏在裡面的東西。這種工作表面看起來好像是破壞，其實是為了突破表相、深入真相。

如果不把一個觀念分解掉，我們就無法發現它的真相。好比一塊蛋糕掉在地上，過了很久的時間，看來還是一塊蛋糕，但如果拿到顯微鏡底下觀察，就會發現很多細菌。顯微鏡就是一種分析工具，在它的觀察下，能看見很小的東西，而這些本來是肉眼看不到的。

同樣道理，K線本身只是價格的紀錄而已，所以分析K線的正確說法應該是「分析價格」。如果操作者執著在K線的定義，就無法進入分析的領域。例如，一支股票價格200元，一般操作者會執著在「200元是貴還是便宜？」這在一般人的思想中，一定有個公定標準，依照這個公定的標準尺

度，即能很快知道200元是貴還是便宜……這就是執著在定義上面。

「200元是貴還是便宜？」這個問題需要經過分析，不是一下子就能得到結論。進行分析時，首先要做的工作是「破壞成見」：先把自己心中原來對於價格先入為主的觀念拿掉，才有辦法繼續分析下去。至於如何思考分析？以下舉五個例子說明：

# 案例一 上影線出現時……

上影線的正方思考是：可能中線跟長線是看好的，於是中長線的買家在盤中買了較多的貨，把價格拉了上去，價格高了以後，短線出現比較大的價差利潤，因此短線的操作者率先獲利了結。這一賣，拉高的價格又掉了下來，留下一根上影線。但是這個部位是落入中長線的買家手上，將來還是會繼續上漲。

上影線的反方思考是：贏家對於未來的局勢不看好了，於是盤中拉高出貨，把部位倒給實力不太好的人或是短線的買家，賣完之後，主力那一方就不再拉抬，於是行情可能會掉下去。

對於多頭而言，正方思考是順向思考，反方思考是逆向思考；對於空頭而言，反方思考是順向思考，正方思考是逆向思考。

不論是作多還是作空，在思考K線的時候，先做某一方向的思考，然後再倒過來想，挑戰自己原先的思考，懷疑自己原先可能想的是錯的，這就是著名的「逆向思考法」。思考時，也就是處在分析的過程中，不是做結論，所以沒有對錯可言。對跟錯，是要等到做結論才出來。如果在思考中每個步驟都在問對或錯，那就是落入成見的陷阱。注意：

思考的過程中，主角是邏輯的推動。邏輯的推動只有合理或不合理，不一定會有答案。沒有答案，也就暫時沒有對跟錯的分別。

舉例來講，張三的老婆懷孕了，可能會生男的或是生女的。生男或生女，就是推理；至於到底是男是女，那是答案，不是推理，得等到懷胎十月呱呱落地之後才知道。對於懷孕的分析，合理的推理就是：「張太太會生一個男孩或生一個女孩」，而不是「張太太一定會生一個男孩」或是「張太太一定會生一個女孩」。
現實生活中，我們看到張太太懷孕了，然後去問老張：「恭喜啊，是男還是女啊？」老張說：「不知道咧，胎兒還不到兩個月大，現在還檢查不出來」。此時我們絕對不會罵老張是笨蛋，竟然連胎兒是男是女都不知道。因為我們知道，超音波檢查胎兒性別要等3個月。

反觀股市，絕大多數的K線操作者無法接受上面這種問答，只會認為老張是笨蛋，竟然還要等到3個月以後才知道

結果。他們總覺得「結果」是在懷孕的那一刻已經決定，怎麼可能不知道呢？同樣道理，他們以為看到一根K線後該作多還是作空，在K線誕生的那刻起就已注定，怎麼可能不知道呢？

超音波已經算是進步的科技，卻還是要等3個月後才知道結果，換句話說，即使工具再犀利，也要「等一段時間」才能找出答案。因此，我們必須經過一段思考的時間，才能大概知道，看到這根K線後該作多還是作空。

一般的操作者，並不了解K線的解讀需要思考的過程，只一心一意尋找定義。如同某個女明星準備出席金馬獎典禮，其他女明星都在苦惱該穿什麼樣的晚禮服出席盛會，她卻覺得「只要是禮服」就行，至於禮服是什麼花樣、什麼款式、什麼牌子統統不重要……你看過這種女明星嗎？應該沒有。但在股市中存著這樣思考的人一大堆！

正方思考與反方思考，只是教你思考K線的起步。萬丈高樓平地起，萬事起頭難，好的開始是成功的一半。一步一步來，不要躁進，才是上策。

# 案例三 下影線出現時……

下影線的正方思考是：下影線代表低檔有人進貨，而這些進貨的人比較有智慧或是實力比較堅強的，於是他們的智慧結合財力就能讓盤勢止跌回升。因此，這根下影線代表的是

比較堅強且持久的買家，不太像是做短線。有時候我們會把下影線叫做「地樁」，如同樓房的地基打了長長的基樁，上面才能蓋更高的大樓，漲勢會比較確實。

下影線的反方思考是：可能有人認為目前趨勢將要跌下去，而這些人是比較有智慧的，或是實力比較堅強的，他看得可能比較準確，因此在盤中倒貨，把價格打了下去。此時，另一方則是在盤中下跌後撿便宜買進，而這個動作可能在短線上造成盤中急拉，拉高了以後，那些有智慧的人也不動聲色，於是留下一根下影線。過了以後，中長期的主流買盤不再進場，買氣衰減，最後就真的跌了下去。

不論是正方思考或是反方思考，只要有思考到就好。先正後反或是先反後正都無所謂，重要的是：正反兩種情況都要考慮，以免自己想錯的時候不知所措。

# 案例三 實體紅棒出現時……

實體紅棒的正方思考是：代表買氣強勁，猶如火箭升空，準備往上衝，未來看好。

實體紅棒的反方思考是：買氣雖然強勁，但可能只是短線的買家在買而已，中長線的買盤可能沒有進場。因此，當天雖然拉出一根實體紅棒，但是力氣用完了，明天可能精疲力盡，這根紅棒就稱「竭盡紅棒」（俗稱「一日行情」）。

# 案例四 實體黑棒出現時……

實體黑棒的正方思考是：代表賣壓沉重，猶如土石流，準備向下沉淪，未來看壞。

實體黑棒的反方思考是：賣壓雖然沉重，但可能只是暫時的而已，或許只是做短線的人在搞鬼，故意製造悲觀的氣氛，中長線的部位並沒有賣出。所以當天賣完了以後，可能明天就不會再賣了，此時，雨過天晴、煙消雲散，盤勢重新恢復樂觀，恢復上漲。這根黑棒就稱「竭盡賣壓」，只痛苦一天，熬過去就沒事了。

# 案例五 小黑星出現時……

如果當天K線的實體長度很小，我們就可以按照自己的意思把它視為「小星星」。星星的意思是K線實體長度很小。實體愈小，表示多空爭鬥不激烈，收盤跟開盤的價差不大，當天行情震盪幅度小，甚至可以說乏味。基本上這種行情有兩種解釋：第一種是多空雙方正在等待機會決一死戰，但是目前沒有合適的機會或是雙方都還沒準備好，兩方都僵持在那裡，屬於暴風雨前的寧靜。

另一種想法是：雙方已經打完了。有時是經過一場規模較大的生死決鬥，有時是在盤勢進行中邊走邊打（至於是哪一種，操作者要憑自己的智慧去判斷分析），雖然仗已經打完

了，其中有一方貨還沒有出乾淨（不論是多頭部位或是空頭部位）。因此，每天的買賣生意變少了，交易清淡，就變成了小紅或小黑，沒有什麼大行情，只是在拖延時間而已。至於將來要怎麼走？雙方還拿不出一個把握，大家只好騎驢看唱本走著瞧（唱本是指客觀環境的變動）。

# 投資別想簡單了，換個角度看事情

一般人在日常生活中，是不太習慣這種正反兩方思考法，只能順從單一方向思考。提供以上兩種角度的想法，不是去死看死背，而是希望讀者多多學習從不同的角度去思考，並且嘗試從收集到的零星證據裡，整理出一個完整合理的故事。如果給你一堆線索、一堆證據，結果還拼湊不出一個像樣的故事（我講的是合理的邏輯推理，而不是天馬行空的胡亂瞎拼），那麼，當事人的思考能力就有待加強了。

有些K線操作者當初能夠進入短線領域，或許真的是比別人的天賦好一些，並對自己的思考能力有點自信，才跑過來操作K線。這些有天賦的朋友，在股市中因受各種環境的影響，可能會變得更具有自信，但未來若發展得不好，就會失控，變成一種長線的自大狂。

在這幾年的股市生涯，我看過許多對K線稍有才華的朋友最後下場都不太好，盲點是：他們總認為自己比一般人厲害

很多，既然如此，就應該是贏家了。殊不知，大部分的人對於K線的天賦，其實是負數，就算你比對方厲害，在真正的贏家眼中只不過是比平常人「高出一公分」而已。可惜的是，不少人很難破除這種自信，最後就成為執著；有了執著，思想就很容易結塊，思路就堵塞了。

這篇文章是寫給態度謙虛的朋友看的，鼓勵他們可以從事多方面的思考。畢竟，在人生的旅途裡，考慮周全一些，是大有好處的。

# 正與反，都是正確的思考

每一件事情，都有正反兩個角度的性質。例如：
一個人沒錢很苦，但他可以選擇安貧樂道，不必為了錢太多而苦惱。不過，一個人若是錢太多，親人為了爭奪財產打來打去，每天還有騙子上門獻策，也是很苦、很煩惱。

在股市中一次買進，有它的優點跟缺點；分批買進，也有它的優點跟缺點。

做長線，有它的優點跟缺點；做短線，也有它的優點跟缺點。並不是說做短線就不對，只要做得有道理，一條線就成立；如果做得沒有道理，不論是任何一條線，都不成立。

房子很大，有它的優點跟缺點，優點是廣闊，缺點是散財；房子很小，也有它的優點跟缺點，優點是聚氣，缺點是狹隘。

諸如此類的例子，多到舉不完。這些都充滿在我們的日常生活角落，只要留心，就一定可以發現；如果不留心，你就會走入填鴨式教育的陷阱，誤以為天底下每一件事情都有它的最佳方案。擁有最佳方案，可能就擁有它最大的弱點或缺點——這個道理，是中國哲學家老子告訴我們的。

每根K線，基本上都有兩種成分所組成，一種是「多」，另一種是「空」，多空成分不一樣。記住：多空成分是依照戰場上面臨到的戰況變化而有所調整，它是忽大忽小、變化不定，所以才需要我們這些幕僚軍師做分析；如果光查手冊就查出來它的定義是什麼，然後直接歸類，那還要我們這些分析師幹什麼呢？

天下萬物各有其優缺點，K線也不例外，每根K線都有其多方觀點及空方觀點，或者說它具有多方的性質及空方的性質。如果操作者本人的思考無法逆向，也就是沒有辦法換成其他角度思考，那麼，他的思考就會變得狹隘，無法應付千變萬化的世界，當然也就沒有辦法應付股市了。

任何一種K線類型都有其多方解讀及空方解讀，只是成分的不同而已！有時我們可以憑直覺去感覺其中的成分多還是少，然後直接做出下多單還是下空單的決定。但是多數時我們都無法判斷，正如很多時候，並無法判斷只送一朵玫瑰花能否打動女朋友芳心，勢必要搭配其他動作，如請她出去玩、寫情書、唱情歌、做一件令她非常感動的大事情……這

些就是所謂的多元化手段（在股票市場叫做多元化指標或方法），目的是打動對方的心。我所主張的多元化手段前面已經講過了，就是平均線、型態學以及成交量。只有在多元化的觀點圍繞下，才能觀察到整個市場的大格局，我們的系統才可以比較完整。

如果只用K線而不用其他的工具，那麼我們遺漏的東西一定非常多！

一般人做K線為什麼常常失敗？就是因為他只拿一把超級小刀就跑到深山裡面打獵。超級小刀只能夠解決一些非常幼小的生物，碰到中型及大型的毒蛇猛獸，超級小刀就無法應付了！超級小刀就是短線的工具，而在股票市場中，K線是短線的工具，必須要搭配其他工具才能夠讓K線的功能比較客觀、真實地發揮出來。

# 關鍵不在死技術，在於活的心

我曾經花了一個星期，學會如何手工繪製K線而不依賴電腦，也順便了解基本K線類型，例如：陰線、陽線、大陽線、大陰線……後來花了至少七年，才比較熟練運用K線及掌握各種變化。又花了超過十年時間，才有辦法把K線跟其他操盤手法「比較地」融合在一起，並運用這些技術操盤賺錢。

在學習K線的過程中，以及我對「學習」這件事情的理解，都沒有遭遇太大的問題。等到我開始銷售股市知識的前幾年，也沒有同學有任何學習障礙。直到近幾年，尤其過了2013年才赫然發現，一般人學習K線，不論是在態度或方法都有很大的落差，令我非常驚訝！

# 大家都想找到完美的運算公式

這些人對於K線的錯誤認知，究竟在哪裡？

K線，是一門偏重於人文的知識，而不是現代科技的知識，如果強行做分類，K線應該放在人文學科。可不可以硬放在理工學科？我的答案是：絕對可以，但不適合現在，而是在遙遠的未來。

為什麼？因為每一種K線類型都是隨著戰場上的更替而變化，並非坐在家裡用頭腦就能嚴格定義出來。問題是，現代科學講究的是定義，如果定義不出來，就沒有辦法做定量分析；如果沒有辦法做定量分析，就無法進行嚴格的實驗；實驗如果出不來，現代科學也建立不起來了。奇怪的是，很多股市朋友都是以理工科的態度切入，他們會要求用一種很嚴謹的態度去看待K線。例如每條平均線的繪製都有其數學式的計算方法，100日平均線就是把最近100天的價格加起來，然後除以100，就是今天100日平均線所在的位置。

# 無法一個蘿蔔一個坑

相同邏輯，有人問我：三白兵的定義是什麼？我會說：三白兵就是連續三根紅色的K線。再圓滿一點的說法是：如果第三根K線比前面兩根明顯短很多，就叫「大敵當前」；如果第三根K線最短，第二根K線次之，第一根K線反而是最長，那我們會稱之為「步步為營」。所以，即使是一個最簡單的基本K線，至少有三種變化。

剛才的三白兵是用「長度」來區分大敵當前及步步為營。

# 除了長度以外，K線的定義還受到什麼影響？我認為，還會受到「每個人認知」的影響。

這句話是什麼意思？每個人對於K線的認知不同，了解的深淺不同，所以形成各式各樣的K線名稱與定義。即使是同一個操作者，也不太可能把自己所使用的K線名稱都做了嚴格的定義，因為嚴格的定義牽扯到嚴格的理論，大部分的實戰派操盤手對理論其實並不在行。跟打籃球一樣，我們無法嚴格定義每個籃球動作，更無法嚴格定義比賽進行時每種可

# 沒有公式可套！「準備」才是王道

由於理工科的朋友從國中就開始接受制式化訓練，凡事都以精確的計算為要求，目的在求得更精確的答案，而不是像問答題能讓你高談闊論。長久接受這種教育，會有一種嚴重的負面作用，誤以為天地萬物萬事，甚至人際關係都能用數學方式去做精密的計算。

姑且不論這樣的思考，究竟是不是宇宙真理的實相，若把範圍縮小到股市，依我個人淺薄的經驗來看，人類的智能目前還沒有辦法用數學掌控股票市場全局，充其量只能够在一

個戰場上獲勝，可是那個戰場是有限的，不是全面性，更不是永恆！換句話說，理論上我們可以接受精密的數學控制整個宇宙，但在人類的有限能力下，對於數學的終極真理也不盡了解，當然就沒辦法談到用數學公式來統治股市。

操盤者想知道K線的精確定義，如同嘗試用數學公式統治股市一樣 —— 在科學萬能或是數學萬能的概念下，我們的思想及行為都在一個可以嚴格控制掌握的法度之中。這種法度，有時候叫做制度，有時候叫做法則，有時候叫做公式，有時候叫做法律，有時候叫做道理，有時候叫做規則……各種事物因為人類理解的程度不同，而做出各種不同的文字規範。它具有約束人類的行為思想的功能，也具有導正人類行為思想的功能，可說是一體兩面，利弊互見。

股民用理工科的態度，嚴格要求股市中每一門知識的嚴格定義，本來是件好事，可惜，在人類智能尚無法突破瓶頸的現在，這種想法會害了大家。一般人非常希望自己在股市中的每個動作都因為有嚴格定義的根據，也就是有確實的理由，最好是一種精密的數學程式，如此一來，接下去的動作及最後結果，都能用連環推理的方式計算出來。

這種連環推理，在人文思考方面是一回事，用數字計算又是另外一回事，現在的股民剛好夾在其中，他們並不希望太複雜的數學計算，只希望有個簡單的流程，那就是「看到某個精密定義的K線類型，如果屬於多方類型的K線，就買

進；如果屬於空方類型的K線，就賣出或是放空」。這樣的思想就是我常講的「中了牛頓經典力學的毒」，把複雜的世界給簡單化了（亦即沒有道理的刻意簡化）。

股市實戰猶如打籃球，你永遠不知道最後的分數是多少，也不知道在這場比賽之中，你的實力能不能發揮；就算是發揮了，能夠發揮到幾成，自己也不知道。我們能夠做的，就是盡量把自己的體能狀況調整到最好，如此而已。萬一受到場邊觀眾的吹噓聲干擾呢？此時，就要堅定自己的心理素質。

股市實戰就是這樣，短線跟中線的人在場上的時間比較多，像是職業選手，而K線正是我們這些職業選手常用的工具，但有太多人並不認為我們是在打一場籃球賽，而是在進行精密的計算，就像寫數學考卷或是化學考卷那樣。你說，這種觀念對嗎？
