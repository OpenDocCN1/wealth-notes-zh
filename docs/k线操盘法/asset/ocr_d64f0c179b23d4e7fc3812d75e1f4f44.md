# 王力群 k線操盤法

倉2～3天的短線操作有心得，如果這兩個人在一起，把他們的規則互相核對一下，非常可能會在很多地方產生嚴重的衝突與矛盾，甚至完全風馬牛不相及！

這種事情往往會讓初學者感到很疑惑，就好像一個幼稚園大班的小孩剛畢業，拿到了兩本國文課本，一本是小學一學級的國文課本，另一本是大學一年級的國文課本，此時他會覺得很奇怪，因為兩本書教的東西完全不一樣。我想，這種疑惑大概每天都會在股民中發生數萬次，乃至於數百萬次！

K線的操作原則，基本上要看操作者是做什麼線的，長線、中線還是短線。每種線路的法則都不一樣，但是坊間的K線書籍會不斷把這些路線搞混，讓大家無所適從。

愈低級的K線境界，愈講究技術；愈高級的K線境界，愈講究心法。大概高到某種程度後，從某個角度來講，技術幾乎完全消失不見，只剩下心靈的律動。
