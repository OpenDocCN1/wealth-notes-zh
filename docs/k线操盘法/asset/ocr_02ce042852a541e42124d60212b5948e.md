# 盤後練功

以上26個分析，在操作時，我是把K線、平均線以及型態學都同時放在心裡，三條主線同時進行，也就是三種領域的知識互相輔助、互相融會。有同學會問：到底要不要先有一種型態的成見呢？我的答案是：如果妳控制得住，確實是可以先有一個型態的大致預測藍圖，然後一天接著一天把K線給它黏上去，如果K線行進路徑大致符合型態學的圖案，就繼續堅持下去，否則圖案就要隨時修改。

三條主線同時進行，對一般人而言，是難上加難，而且對於絕大多數而言，是難得不可思議，難得飛上雲端，其中主要原因是：一般人在日常生活中無法運用自己的系統知識去思考自己的生活，所以換到股市之後（技術領域中），也一樣無法運用股市語言去思考「操作」這種行為的人生意義。講得實際一些：我們哪一天做了哪些事，或者是做對了哪些事、做錯了哪些事；是過了有意義的一天，還是過了無聊的一天……這樣的記錄，就相當於股市的日K線。接著我們
