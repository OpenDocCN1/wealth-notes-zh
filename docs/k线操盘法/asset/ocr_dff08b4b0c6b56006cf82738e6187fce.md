# 王力群 k線操盤法

坦然心理，如果箱子頂部被突破，則要立刻空單出場。
（15）2010年6月8日，小紅棒小跌5點，跟昨天的K線幾乎是並排的，顏色也一樣，多空不明顯，或是說多空雙方都有理，雙方都可以保持不動。
（16）2010年6月9日，收中黑棒，下跌80點，把7日跟8日的兩根小紅線都吞噬掉了，但是沒有跌破箱子底部，所以多空雙方均無動作。
（17）2010年6月10日，上漲110點，就短線而言，三根紅棒把6月9日的一根黑棒夾在當中，這是一個可以冒險的多頭訊號，短多單可以進場。
（18）2010年6月11日，跳空大漲117點，雖然只是黑字十字，但是點數漲很多，多單續抱。如果11日跟10日都沒有進場，那怎麼辦呢？答案很簡單，就是等待箱型頂部被突破以後再進場。
（19）2010年6月14日，跳空小紅線上漲87點，箱頂被微微突破，多單續抱，新多單則可以再多等一天，等待實體長度比較長的紅棒。
（20）2010年6月15日，上漲66點，以中紅的姿態突破箱頂（5月31日的高點7373），這是中線的買進訊號，新多單進場。
