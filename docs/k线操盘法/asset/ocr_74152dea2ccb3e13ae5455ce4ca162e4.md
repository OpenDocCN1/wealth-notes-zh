# 碰到問題，
贏家都這樣分析

所謂「分析」，應該是科學式思考的一種。

一個東西，可能不是外表看見的那樣，裡頭可能藏有其他東西，我們把它做分解，打開來看，就能看到藏在裡面的東西。這種工作表面看起來好像是破壞，其實是為了突破表相、深入真相。

如果不把一個觀念分解掉，我們就無法發現它的真相。好比一塊蛋糕掉在地上，過了很久的時間，看來還是一塊蛋糕，但如果拿到顯微鏡底下觀察，就會發現很多細菌。顯微鏡就是一種分析工具，在它的觀察下，能看見很小的東西，而這些本來是肉眼看不到的。
