# （4）成交量

每一根K線都帶著成交量，把成交量與K線合併起來解讀叫做「量價分析」。通常量愈大，正面解讀來說有加分作用，從負面解讀則有減分作用。因為力量過大，可能會把力道耗盡，所謂最後一搏，再下來就黔驢技窮了。

# （5）平均線

K線如果被不同的均線劃過，或者發生在不同的均線附近，那又是另外一番解讀了。

# （6）左邊的壓力與支撐

在K線圖上，歷史是記錄在左邊位置，往右則代表未來。往左邊看，過去的股價線路圖會形成某些壓力帶，表示有籌碼在那個地方。因此，股價如果處在上漲趨勢，就要考慮左邊的那一些壓力——K線必須要考量型態學的壓力或是支撐力。

# （7）位置高低

以上漲K線為例，如果發生在相對比較高的位置，也就是指數的相對高檔，正面的解讀是「有人可用更昂貴的價格追買股票」，是件好事；負面的解讀是「由於價格已經過高，有可能變成拉高出貨，買在這個高檔的人是傻瓜」。
