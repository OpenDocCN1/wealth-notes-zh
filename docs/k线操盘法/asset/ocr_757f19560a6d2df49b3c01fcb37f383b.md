# 重點1

老師父出拳打死一頭牛，徒弟卻連狗都打不死，明明是同樣招式，為什麼有這麼大的差別？只要你有一點點練功夫的常識，或是看過武俠小說，你就會知道這個答案是什麼，不會太難。

# 重點2

武功祕笈上是從第一招到最後一招，每一招可能都附上插圖。練功時，會把第一招練到最後一招，也就是從第一頁開始練到最後一頁，例如太極拳三十六式，從第一式起手式到第三十六式收太極，整套流程是連續的，例如第八式「如封似閉」之後，就是第九式「十字手」。

反觀在股市實戰中，當你施展如封似閉之後，不一定要施展十字手，可以突然施展一陽指把對方戳倒，這就是隨機應變。散戶最致命的是，總認為第八式以後就是第九式，絕對不可能跳脫到别的招式。如果把這個觀念講給武林高手聽，他一定會愣住，然後哈哈大笑。散戶這種荒謬到極點的作戰觀念，就是來自於從小被訓練出來的數學公式計算流程，一個蘿蔔一個坑，每一個觀念都是一個圈圈，每一個圈圈都是一個牢籠，思想範圍在每一個牢籠裡面打轉，最後變成僵化死板。
