# 案例16

2002年10月15日，指數跳空上漲220點，就指數而言是二連紅收復十日線，是⼀個很好的反攻訊號，象徵著2天前的低點，也就是10月11日的低點3845沒有跌破2001年的超級大低點3411，形成了⼀個長線W底（詳見圖51）。這個W底，理論上而言可以用許多形式做確認，10月15日所交出來的成績單是二連紅，就等三連紅來更加確認這個長線的W底（在基本K線學中，三連紅叫做三白兵，是比較強勁的多頭訊號）。

由於10月15日的跳空大漲，所以我跟朋友約定好要在第二天大舉買進。就季節而言，發生在冬天的低點，確實對多頭是比較有利，這點我們還有点自信，於是10月15日晚上，幾個好男兒做了這樣的誓約，等著10月16日來大買了。

熬了⼀個興奮發癢的夜晚，經過幾個小時後，好不容易等到黎明的曙光，終於到了9點鐘開盤。果然，開的是高盤，很不錯，可惜興奮一下子，它就開始逐步下跌，變成了開高
