# 缺口為什麼會被填補？

至於跳空缺口的實戰法滿簡單，大概有以下幾條規則：

（1）上升缺口如果沒有被回填，它就會形成防禦的力量，也就是一道支撐。缺口愈大，支撐的力道就愈大。

（2）下降缺口如果沒有被回填，它就會形成壓回的力量，也就是一道關卡。缺口愈大，打壓的力道就愈大。

（3）按照不成文的慣例，歷史上絕大部分的缺口都會被回補，只有極少數的缺口沒有被回補。

這三條是市場常常運用到的缺口法則，簡單明瞭，行之亦有多年。自從我教K線以來，卻有人問過我一個很好的問題：「為什麼大部分的缺口都會被回填？」

十年前，我的回答大概是這樣：
