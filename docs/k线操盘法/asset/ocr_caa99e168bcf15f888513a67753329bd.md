# 對於用K線做短線的操作者來說，你會給他們什麼建議？

Ans：要把握在股市中的人生歲月，不只是要學習正確的股市真理，還要體會人生的真相與道理。

多數人之所以會淹沒在股海中，原因沒有幾百個也有幾十個，歸納起來只有一個結論：操作者原本對待人生的思考方式有太多錯誤的地方，所以在股市中就跟著錯下去。

我常說，台灣的填鴨式教育失敗了。填鴨式教育來自於中國1500年的科舉考試，到最後整個死掉，學校變成摧殘知識的惡魔黨基地，但多數學生不是很清楚這點，甚至老師也不知道自己在做幫凶。

填鴨式教育帶給國民無窮的後患，台灣今天之所以國力不振，中國今天之所以走向霸道，都是中國古代傳統思想中，霸道的法家幽靈在作祟，法家代表人物就是韓非、李斯、秦始皇，還有商鞅。

錯誤的人生觀從大格局來講，就造成錯誤的人生規畫。從中型的格局來講，因為看待事物的方式錯誤，進股市後不論怎麼學習，由於認知出了問題，所以學不好股票，最後只能悶著頭當輸家。

股市的道理並非世俗的道理，而是屬於宇宙人生的真諦。
