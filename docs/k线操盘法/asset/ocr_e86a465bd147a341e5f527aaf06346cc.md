# 季節＋指數位置，
掌握漲跌格局

有人問我如何掌握漲跌格局？以下就以2015年12月4日的大盤來說明。

就長線而言，先觀察外資的態度，不論是股票、期貨，都是持續買進或買超，加上國內也沒有經濟蕭條的慘況，所以長線沒有太大變動，差別只在於「現在是不是比較好的買進時機？」

關於這點，可以從兩方面去想：第一個切入點是「季節」的觀點，也就是春夏秋冬哪個季節適合買進；另一個切入點則是「指數高低的位置」，現在是否恰當？對一般人而言，這就是所謂「摸頭猜底」——坦白講，底部在哪裡我也不知道！有時候我只管買跟賣，而不猜測市場的指數位置，我只是就著市場指數的位置去調整我的買賣策略而已。

就中線而言，2015年8月24日的最低點7203，到底是不是當年的最低點呢？若不去猜測的話，7203還算是一條堅固的防線，如果7203被跌破了，也就是技術分析的關卡被跌破，
