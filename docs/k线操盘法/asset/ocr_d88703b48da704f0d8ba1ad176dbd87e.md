# 方法5

實戰的當下，必須嚴格限定自己的思考範圍不能超出現有的倉庫太多。倉庫裡的知識已經夠龐大了，更不要說五、六個倉庫同時聯結運作，那是一項很龐大的工程。我們在做短線實戰時，就是在做這樣子的工程，不然你以為我們在幹什麼呢？

# 方法6

一般人在思考時，總以為自己真的在思考，就好像坐在馬車裡面的人，以為自己在向前運動，殊不知是馬兒在拉著他走。基本上大多數人類的思考都缺乏理性，而是被兩種東西往前拉，一是欲望跟感情，二是潛意識。也就是說，都不是自己的主張，而是聽別人指使。如果各位發現自己有這種傾向，那就要朝向「認識自己的潛意識」去努力了。
