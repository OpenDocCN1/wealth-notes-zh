# 填補7年前的缺口

接下來2003年、2004年、2005年、2006年的4年間，台股都在震盪打底，別的國家的股市大部分都是往上衝，尤其是亞洲的韓國（2000年高點是1000點，2007年的高點是2000點）。反觀台股因為有政治的不確定性及思想上的巨大弊病，造成國家停滯，以致於台股這四年的漲勢不如亞洲新興國家。儘管如此，台灣還是有希望，所以我一直在等待；我這個等待可不是感情用事，而是切實地感受到這個年代並沒有那樣絕望，全世界景氣依然是往上走。台灣即使再糟糕，身為地球村一分子的我們，也不是落後國家，一定可以得到世界景氣的幫助，走出一條活路 —— 這是我所堅信的，也是巴菲特教我的：永遠不要對股市失望。

在2006年6～9月之間，台股做了一個震盪三小波，橫向地拖磨了3個月，似乎是在打底；最後 Easter 在2006年9月18日揭曉，那天是一個跳空上漲的大紅棒，收盤漲了201點，留下了一個跳空上漲的上升缺口，也代表台股多年來被壓抑的多頭市場終於爆發，即將展開它的上升之旅。
