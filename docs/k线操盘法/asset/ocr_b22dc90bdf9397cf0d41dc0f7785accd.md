# 王力群 K線操盤法

時代那樣天天做功課，才重新開始吸收資訊、學習知識。殊不知，過去在學校裡是一個小圈圈，資訊範圍出不了考試卷界限，但在現實世界中，最重要的並不是辨別資訊對錯的問題，而是要確立正確知識與有價值的資訊來源管道。然而，過去在學校中，這個來源管道已經幫你確定好了，就是課本與老師，或是考試卷與教育部，學生不必再花腦筋去自由選擇。等到進入成人世界後，所有的知識、資訊向我們湧來時，多數人還是跟以前在學校一樣，誤以為凡是資訊必有其價值，所以他們非常執著於解讀資訊，而不是先開闢一條正確的管道，以方便讓正確資訊循著這條軌道而來。群眾並不清楚天高地厚，誤以為資訊的領域就像以前的考試卷般，再大也大不過一張桌子。

不論股市是不是在做頭，左右兩個高點相隔14天，也足夠讓一般人昏迷過去，因為資訊太多了，這是一個沒有遊戲規則的世界，各路人馬、各大門派、妖魔小丑、紳士淑女、富翁窮人……全都聚集在一起混戰，如果自己沒有一套過濾資訊的系統，勢必被資訊淹沒，而構成這個系統的，恰恰又是知識本身。換句話說，就是你以前在學校裡面應該學到的東西，但老師從來都不教。老師幾乎不會跟你講一個正確的人生系統是什麼，他們會叫你看很多書，不過，他們可能自己也不知道，一個具有嚴謹的科學邏輯的知識認知系統應該如何建構。
