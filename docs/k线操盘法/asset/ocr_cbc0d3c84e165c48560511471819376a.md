# 重點3

武學大致分為兩種，一種是外功，一種是內力。股市中，內力就是你的經驗及見識，外功就是你的招式及速度。經驗靠累積，見識依靠廣泛的閱讀與深入的思考，當然還有智慧的遠大。招式要靠祕笈，也就是老師發的講義或經典書籍，更重要的是操作者自己的記憶力。按照我的經驗，大多數的操作者連這一關都過不去，也就是他上了戰場就忘了武功招式。速度要靠不斷的練習，這跟一個人的決心有關，短線操作者如果過於猶豫，當斷不斷、当進不進，很難成功。

# 重點4

會打電動玩具的人都知道，遊戲中有所謂的「放大絕」（放大絕招）及「冷卻時間」（CD、Cool Down），意思是說，你不能夠一直使用最厲害的絕招，因為使用絕招是要花力氣的，而且也不是每次用完絕招後，敵人就一定會死。而且如果你當天感冒，或是身體狀況不太對，你的絕招施展後的效果一定大打折扣，這是非常簡單的道理！

但是，一般散戶依據一個蘿蔔一個坑的數學計算觀念，他會認為每次施展絕招的效果是相同的，也不需要什麼冷卻時間，施展絕招也不需要耗費體力……如此荒謬的觀念，也是拜填鴨式教育之所賜。
