# Q4 你是如何看待K線的？

Ans：K線只是價格的紀錄，本身毫無意義，要經過人的解讀才會變得有意義。如果解讀壞了，或者根本錯掉了，那麼K線對那個人也就沒有意義了。每個人依照自己的人生經驗去解釋K線，解釋地愈好，愈能形成一套完整的規則也就愈趨近真理。

人生也是一樣，就狹義而言，人生毫無意義，端看你怎麼樣去充實它的定義。如果好好過自己的人生，人生就有意義了；如果我們搞砸了，就會覺得人生沒有意義，而感到悲觀，完全是自作自受。
