# 請教一個案問題，該如何加強自己的K線功力？

Ans：這個問題，上課時也常有同學提。第一次聽到這個問題時，我有被小小嚇了一跳，因為我 Lin得  很簡單：不就是「用功」就好了？若問怎麼用功，不就是多讀書、多思考、多點實戰交易經驗……不就是這樣嗎？

後來，我想起自己以前的經歷，可能跟現在同學的遭遇很像。我在念高中時，腦袋裡的問題不是「如何用功念書」，而是「用怎麼樣的讀書方式才能考得上台大」。

還有在讀初中時，有次老師叫我們幾個功課較好的同學站起來發言，告訴其他人該怎麼樣讀數學、物理、化學等等比較難的科目。當時我發言的內容，現在回想起來奇蘊無比，我建議：「多做習題！」（真是填鴨式教育的受害者啊！）

同學在面臨林林總總的教材，如果沒有一個終極目標的指引，往往會變得不知該如何下手。什麼叫做「終極目標」？以學生來講，考試的「題目」就是終極目標，這些題目都有一定範圍，原則上不會超出教材太多，也都有一定的標準答案（重解答而不是重思考）。

反觀股市，長、中，短三條路線混雜在一起，每個人獲利的方式也是千奇百怪，不可能會有一個統一的標準，於是終極目標就變成模糊了。有人認為，終極目標不就是賺錢
