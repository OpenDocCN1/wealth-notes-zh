# 跳空缺口是「負債」，
遲早要還

K線圖中，如果有一段沒有人交易，就會發生空白，這個無人交易的空白區，稱為「缺口」。缺口需要兩根K線做夾擊，如果第二根K線比第一根K線高，就叫做上升缺口；如果第二根K線低於第一根K線，就叫做下降缺口。

為什麼會發生這種情況？舉個例子：周一收盤落在8000點，當天晚上突然發生一個大利多，周二早上九點鐘開盤前，可能有很多爭相遞單做買進，出價的價格也會一個比一個高，於是周二的九點整第一盤開出來的價格，很可能遠高於8000點，假設開在8200點好了，那我們就把這200點的無人交易區稱為開盤上升缺口。如果當天一直到收盤，價格都沒有辦法再回到這個空白區，這個缺口就大功告成，正式留下一個空白的缺口。如果盤中曾經有觸及這塊空白區，但是收盤時又拉上去，沒有停在空白區，就會留下影線。不論是上影線或是下影線，只要在缺口範圍之內的影線，都會影響這個缺口的威力——缺口內的影線愈長，缺口威力相對
