# 經典案例解讀（一）

做K線那麼多年，尤其是1998年8月台股加權指數期貨開跑之後，K線的操作生涯更是難忘。現在，我就把一些很經典難忘的案例寫在這裡，供各位深入領會。

# 案例1

1998年4月9日收了一根大黑棒，開高走低下跌173點，在這之前的7日跟8日是收高檔兩顆星，換句話說，漲勢已經停頓兩天了，而且在更之前的4月3日跟4月4日都是收跳空紅棒，市場人心大為振奮，認為股市將要再度上萬點。當時，有一位做股票很多年的大哥告訴我：不要怕利空、不要對股市感到失望，要從容布局……他那時候買了很多，自認為是很成熟的企業家，所以來訓斥我這個年輕人。但是4月9日的那根長黑「很明顯」是三尊頭的右肩成型的訊號，三尊頭的左肩在2月27日的高點9378，中間的頭在3月17日的高點9165。後來，第二天4月10日收雙烏鴉，再過一天，4月13日大跌190點，成為三烏鴉（詳見圖23），到年底一共跌了4000點（詳見圖24）。
