# 4-3
K線的第三層境界

第三層境界有兩個重點：第一個重點是「親身體験」；第二個重點是「深刻記憶」。

# 重點① 親身體験

新手跟老手比起來，老手最明顯的優勢就是經驗的累積。

以日K線為例，每一根日K線就代表一天的歷史。回憶當年，我還是個年輕小伙子，天天待在證券公司，當時叫做號子，看著電視牆，從早上9點到中午12點，3個小時看完，這180分鐘的歷史就構成了一根日K線。

回到家後，稍微休息一下，下午就去河濱公園跑步，跑完後在回家的路途上，一邊走著，一邊想著今天的K線涵義……買完晚餐的食材，以及一些日常生活用品，大包小包提回家，一邊過著簡單的日常生活，一邊繼續思考今天的K線與過往的股市歷史有什麼關係……吃完晚餐以後，看看投顧節目、看看財經節目、看看報紙、看看雜誌……就這樣大概
