# 揭開漲跌
背後的祕密

一般人對於K線的看法，都來自於對整個股市的原始觀念，但我覺得那是屬於一種「非常有效率」的俗世觀念。什麼叫非常有效率呢？就是市場每一天的價格表現，或是說每一根K線所顯示的當天價格，已經代表了「一切」——所有的消息，不論是利多還是利空，一切嘗試影響市場價格走向的企圖，都已經「完全」反映在每一天的K線價格。

在散戶的心中，每支股票最重要就是價格，正如俗世的觀點認為，每個人存在的價值取決於身家財產，不太會想到人的價值應該取決於道德品行。

因此，若以俗世的眼光來看待萬物，很多事情會變得非常單純。例如，股市裡的一切變數，其存在的目的都只為了推動股價上漲而已。當然這中間，也會跑出一些小惡魔干擾股市，股價就下跌。股價之所以會上漲，是大家共同努力把這個價格給推升上去，不論是用震盪的手法，還是不太光彩的手法，這些「努力」的結果，都會表現在股價上面。總之，
