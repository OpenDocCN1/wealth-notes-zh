# 經典案例解讀（三）

# 案例7

1999年11月26日收一根大長黑，狂跌309點，聽說是中共再度舉行軍事演習，一聽到軍演大家就緊張了，害我那一天的多單認賠出場，雖然賠的不是太多，但也感覺到痛。我的策略自認為很整齊，但對於這根突如其來的長黑感覺很意外；也因為很意外，所以被氣到，盤中時血氣上衝，喪失思考能力。我自己也知道這種狀況，於是心一橫，把多單認賠賣掉。

雖然我認為原先的操作計畫的方向是正確，可惜因為心理建設不夠，盤中情緒受到衝擊，怕自己在失去理智後會做出錯誤的行為，所以我就把眼睛一閉，狠下心腸，暫時先出場——這種作法對於心智脆弱的人而言，是非常重要的。除非已經練到不動如山的境界，否則不可以任意濫用「一動不如一靜」的保守策略，不夠成熟的人往往在保持不動之餘，成為慢半拍的落後者。這一點提供大家做為借鏡。

這一根長黑的長度很長，好像打下了一根柱子一樣，成為了一個標竿。往後，只要不要繼續下跌，守住這根長黑經過
