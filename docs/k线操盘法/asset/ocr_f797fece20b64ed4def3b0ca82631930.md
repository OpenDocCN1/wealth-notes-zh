# 案例17

2002年12月9日，開高收平，上漲84點，留下了一個黑十字星。這天的高點是4867，跟11月18日的高點4862差不多，只有小突破5點而已，不算多。很明顯地，12月9日這個十字星有資格成為中短線的多空關鍵，因為它試圖挑戰11月18日的高點，雖然過了，但超越太少，沒有紅棒，反而留下黑線，對於多頭來講，這種攻擊法不太對。比較好的攻擊方法是，在面臨關卡的時候直接用衝的，如果要休息，就等衝過去以後再休息，或者在衝關之前橫盤整理，也可以當做是休息。
