# 案例四 實體黑棒出現時……

實體黑棒的正方思考是：代表賣壓沉重，猶如土石流，準備向下沉淪，未來看壞。

實體黑棒的反方思考是：賣壓雖然沉重，但可能只是暫時的而已，或許只是做短線的人在搞鬼，故意製造悲觀的氣氛，中長線的部位並沒有賣出。所以當天賣完了以後，可能明天就不會再賣了，此時，雨過天晴、煙消雲散，盤勢重新恢復樂觀，恢復上漲。這根黑棒就稱「竭盡賣壓」，只痛苦一天，熬過去就沒事了。

# 案例五 小黑星出現時……

如果當天K線的實體長度很小，我們就可以按照自己的意思把它視為「小星星」。星星的意思是K線實體長度很小。實體愈小，表示多空爭鬥不激烈，收盤跟開盤的價差不大，當天行情震盪幅度小，甚至可以說乏味。基本上這種行情有兩種解釋：第一種是多空雙方正在等待機會決一死戰，但是目前沒有合適的機會或是雙方都還沒準備好，兩方都僵持在那裡，屬於暴風雨前的寧靜。

另一種想法是：雙方已經打完了。有時是經過一場規模較大的生死決鬥，有時是在盤勢進行中邊走邊打（至於是哪一種，操作者要憑自己的智慧去判斷分析），雖然仗已經打完
