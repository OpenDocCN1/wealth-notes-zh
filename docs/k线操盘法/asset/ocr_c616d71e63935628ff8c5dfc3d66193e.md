# 有人一直活在媽寶世界中

第二次世界大戰結束迄今，已經70年了，在這超過一個世代的歲月中，大家豐衣足食，酒足飯飽（我講的是台灣多數人民的現在狀況，不是講非洲），大家的觀念乃至於自己的人生觀與世界觀，都逐漸變成一種屬於「媽寶」的觀念，意思是說：大家把世界看成是現成的。

20世紀的科技昌明，民生富裕，但這是經過過去3000年人類努力奮鬥換來的，而不是你一生下來就有。所謂媽寶，就是把這個世界看成是已經都為自己準備好的，欠缺的東西都在架子上，只是我沒有去拿而已。於是很多人就認為，股市的贏家知識就是在房間裡，只要把房間鑰匙拿到手，開門進去，再把那個方法提起來，走出房間拿到外面使用，就會賺錢了……
