# 王力群 k線操盤法

別好高騖遠。不過，幾乎所有股票書籍都不知道有這種層次的存在，於是很 容易陷入一團混亂，往往學了10年、20年、30年之後，還不知道K線的意義在哪裡，甚至在屢戰屢敗的盛怒之下，直接就把K線這門知識一腳踢掉，然後告訴別人「根本就沒有用」，此般例子屢見不鮮。

這是我第17本股市作品，從本書開始，我希望帶各位走進一個全新的領域，在財務方面可以經由股市智能的提升得到舒緩與挹注，但光是這樣，還沒有辦法取得真正的財務自由。想得到真正的自由，必須從改革我們思想的「根本錯誤」著手，同時建立起一套全新完整的思考系統，與我們的心智牢牢密切連合在一起。一旦達到如此境界的身心平衡，我們才有資格說：「真正享受到了一些幸福的自由。」
