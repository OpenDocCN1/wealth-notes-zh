# 王力群 k線操盤法

率稀少所引起的时间感覺。

有的人認為人應該「無憂無慮」過一生，而後再把它引伸擴大解釋為「無思無想」過一輩子。無思無想本來是叫你休息，應該趁這個機會減少妄想，去體會自己的本來面目，結果變成腦袋一片空白；本來應該浪漫天真的，卻變成渾渾噩噩，痴痴呆呆，對於當下的一分一秒沒有太多感覺，當然也就不能夠體會每一分每一秒的珍貴性，時間在他身上就被浪費掉了。
