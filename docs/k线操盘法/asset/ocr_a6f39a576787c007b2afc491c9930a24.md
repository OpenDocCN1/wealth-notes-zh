# 案例18

2003年1月3日，跳空上漲101點，不僅過了10日線跟60日線，也突破了自從2002年12月13日到2003年1月2日的下降箱型，這個箱型是斜斜往下的，大概有14天，如果加上2002年12月10日、11日，以及12日連三天的下跌，大概有17天時間是在苦悶的跌勢中緩緩度過。換句話說，2002年的12月成交量冷清，股市下跌，人心失望，是一個振作不起來的季節。

過了這個沉悶的12月之後，2003年1月3日的這一根跳空十字紅線，突破了下降整理的壓力線，是一根具有關鍵性與決定性的紅線（詳見圖55、圖56）。如果因為實體長度不夠長，還可以多等一天。等到第二天1月6日，收盤上漲63點，紅線實體長度擴大，買進訊號就比較確認了。
