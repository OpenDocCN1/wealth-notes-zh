# 王力群 k線操盤法

大概在8400～9200之間做震盪，如果有邪惡的第五波，那就是5月26日到6月8日的高點9209（附帶說明一下，第一波只有一天，就是5月5日的一根大長紅，俗稱一日行情）。

2000年6月27日這一根黑棒，在我眼中，等於默默宣告未來3年台股空頭時代的來臨（2000～2003年）。

通常盤勢在橫盤時，嚴格來講，我們不應該知道它到底是在做頭還是在做腰，如果橫盤做頭，將來就是下跌；如果橫盤做腰，將來就會是上漲……到底是哪一種？如果要預測的話，可不可以？有經驗的老手會勸你少預測，或者是根本不要預測，因為我剛剛講過了：一般人自以為的獨立思考，其實只是機器人式地隨意組合觀念，也就是隨機抓藥的配方，錯誤機率非常高（如果單純就思考方式評論，這種思考方式本身就是一種錯誤），所以不要亂猜底部、亂猜頭部。但是有時候，頭部跟底部的訊號確實非常明顯，很容易預測正確，雖然這種「非常容易預測正確的機會」不是那麼容易發生，但散戶只會挑軟的柿子吃，他們只會記得那些容易的機會，然後把大部分預測困難的時光給疏忽掉了。
