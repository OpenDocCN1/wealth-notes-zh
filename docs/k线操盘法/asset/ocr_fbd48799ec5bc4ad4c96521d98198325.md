# 王力群 k線操盤法

這一張搶隔日沖的單子蒙受不小損失（詳見圖47、圖48）。在非常有把握的狀況下遭到這種損失，感覺真是複雜。

做短線，一半靠運氣，一半靠技術。話雖如此，但很難領會到什麼叫做運氣。大致來說，技術跟心理要成熟到某一個程度之後，我們才能比較真切感受到運氣的存在。換個例子來講，就像練武功一樣，功夫必須要深到某個境界，才能夠感受到體內真氣的運行。所謂真氣的運行，其涵義就是運氣，也叫氣運。

運氣有分為好幾種，較常見且容易理解的有三種，第一種是天生的運氣，此類運氣是前生注定，這輩子來驗收成果的；第二種是這輩子的後天努力，以現在的年輕人來說，大概就是你過去30年功力的累積，會形成一股氣運，這是屬於中線；第三種就是在當下對於氣場的即時感受，這需要敏銳的觸覺，而敏銳的觸覺更仰賴於當下身心的正確平衡感。

以上三種運氣在短線操作中，大概占了50%的成分，分量不可謂不重，但大多數的人感受不到，多數人會很單純地認為技術成分在短線的成分很高。其實，技術成分才占不到一半，甚至有的人只占了三成到四成而已。少數操作者會有這樣的錯覺，是因為天賦的氣運在作祟，但他自己不知道，誤以為是他今世努力的後天成果，殊不知那是一種天賦；對於今世而言，過去世的遭遇與努力，只是一種莫名的無形氣
