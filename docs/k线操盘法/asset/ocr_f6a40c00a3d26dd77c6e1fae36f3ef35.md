# 王力群 k線操盤法

日，又創了新高，但也不過是6048點而已，比2個月前的高點只多了200點（詳見圖45）。它確實有進步，但進步地如此之慢，讓人不禁納悶：這種進步其實是一種退步！

接著，最想不到的事情發生了。從2002月2月18日開始，電子股產生大暴跌，這下子可好了，因為在12月5日買股票的人，大部分都是買電子股，沒想到3個月之後，新高沒有多高，卻發生了猛烈的跌勢，於是之前買進的大量股票部位，除了金融股之外，大多損失慘重。

再回過頭去看看12月5日那一根紅K，確實是多頭啊，沒有問題啊，為什麼會這樣呢？一切問題都出在「K線本身只是個短線，但是在配其它訊號的同時，K線會誕生新的意義」，因此，在中長線也有了它一席之地，就是這種多重身分的重疊，一個人在不同的三個領域具有三個不同的定義，使得神經比較大條的操作者無法接受這個事實。在他們的想像中，漲就是漲，跌就是跌，如果漲是曲折離奇地上漲，那就超出他們的思考範圍了。

在預測法中，大家都把預測想成是「預測結果」，很少人會把「預測過程」也包括進去。舉例來講，春嬌跟志明談戀愛，如果預測結果的話，只要預測他們將來會不會結婚就好；反觀如果是預測過程，就要把他們兩個談戀愛的過程到底是痛苦還是快樂，也要一併預測出來，如此一來，難度就升高了，而難度到底升得有多高？答案是：高得難以想像！
