# 我的K線學習之旅

我最早接觸股市是念大學的時候，但是當時只知道黑黑白白的線叫做K線，除此之外，就沒什麼去想了。

1995年開始做短線，才算對K線有了正式的學習。我大概只花一個半月思考，並且用實戰驗證K線的道理，一個半月過去，就覺得自己「已經把K線這門學問弄懂了」，現在回想起來，那種浮誇的感覺實在非常幼稚可笑！K線這門學問博大精深，它的基本定義或許有限制，練功的層次與境界卻是沒有限制。如果你聽到有人講自己的K線很厲害，他大概是沒有把「境界」這個因素考慮進去。

這本書，主要是寫給稍微具備K線知識的朋友們看。至於最基本的K線常識，各大券商的網站都有相關資料，且免費提供，有需要的話可以自行查閱。如果實在不行，2016年夏天，我已經將K線基本知識的教學影片上傳到YouTube，只要輸入「王力群」三個字就可查到。那些基本知識雖然重要，但畢竟是入門，各位不妨安排兩個月時間學習，讓自己對K線有個書面文字上的初步認識。
