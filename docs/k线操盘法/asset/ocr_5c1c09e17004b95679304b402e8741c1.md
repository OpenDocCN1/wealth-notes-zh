# 只是一種表態，並不是每根K線都能如實反映市場的真實面。

再強調一次：每一根K線，每一根紅棒或是黑棒，只是告訴我們從過去到現在為止，所有的利多及利空消息在今天收盤的時候它發揮了多少，如果是空方發揮的比較多，那麼它就收黑，如果是利多的消息發揮比較多，那麼它就會收紅。

發揮不出來的，我們就送進倉庫，等待將來的機會，而不是把它送上斷頭台，宣判死刑。依據能量不滅定律，真正利多跟利空的消息不會憑空消失，它會以另外一種能量的型態儲存起來，就是在我們的潛意識之中。

真正的股市高手會追蹤那個潛意識，去記得真正的利多跟利空消息，然後予以了解，之後再深入我們的意識，進入我們的思想。如果我們在市場上沒有看到今天的K線價格告訴我們它發酵了，而把這個利多或利空的消息放在我們的記憶中，就比別人掌握了先機！

因為這些沒有消失的利多與利空，別人認為它們死掉了，其實只是潛伏。能夠知道它潛伏而不是被消滅，就等於掌握到了利多利空消息的行蹤，也就是掌握到了未來趨勢的先機，因為這些利多利空的因子將來因緣成熟，總有一天會發酵，屆時本來以為這些消息已經死亡的人，就會覺得很納悶：為什麼股市又重新上漲或下跌了？反觀真正的股市高手都知道，這些消息在他們心中，被牢記著沒有消失。
