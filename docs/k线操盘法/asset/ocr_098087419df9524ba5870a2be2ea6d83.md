# 經典案例解讀（二）

# 案例4

1999年2月5日，當天盤中各類股大跌，放眼望去全是綠的，但過了幾分鐘，電子股開始翻紅，中場只跌了40點而已。這一天的低點創下了年度紀錄，達到5422點，市場瀰漫一股悲觀氣氛（詳見圖29）。

印象深刻的是，有一位羅盛豐期貨（與寶來期貨合併，後又被元大金控合併）的分析師寫了一篇好幾千字的長文，告訴我們這個盤暫時不可以看多。他的文筆非常好，分析地「頭頭是道」、「有條有理」，看得出來是個心思細膩的人。結果呢？當天的低點就是最低點，第二天大漲（詳見圖30）。

我開始想像，這位分析師一定是個文藝年輕、擁有豐富的才華以及卓越的分析能力，才能够寫出這麼一篇宏偉、壯觀的文章，頗有戰國時代縱橫家的文采風華……。但過了兩天，我冷靜下來思考，發現他講的全是細節小問題，殊不知，股市常常是中長線背後的因素在那兒發威，表面上看不到。
