# 王力群 k線操盤法

過了優閒的一天。晚上十點，再繼續收看美國CNBC的美股開盤，一邊看，一邊想著明天的交易計畫……有時候看著看著就睡著了，有時候精神特別好，一邊看電視，一邊玩電腦……這就是小王操盤手一天的生活。現在回想起來，記憶還是很深刻。

就這樣，日子一天一天過，經驗一天天地累積，我成長了，但也變老了；我的經驗變多了，但是我的體力也逐漸衰退；我對於這些過去日子的記憶更深刻，但過去存在的歷史負荷也加重了。
