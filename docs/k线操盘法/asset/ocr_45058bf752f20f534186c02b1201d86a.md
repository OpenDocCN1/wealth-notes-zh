# 大戶操盤不需要人文解讀

如果你想提高人文解讀的能力，就要多讀書，也可由老師上課時所舉的例子來思考（模仿老師的思考）。人文解讀在思考時，要以感情面來思考，這個部分很重要，但很多人跨不過。

感情豐富、聯想力好的人，較容易做好人文解讀。例如古詩「床前明月光、疑似地上霜、舉頭望明月、低頭思故鄉」……這些都是人文聯想，古典的詩詞有很多這樣的訓練。

同一件事情，不同的人所做的人文解讀會產生不同的結果，其改善方式是提高人文解讀的程度，這也就是科學家與工程師的差別：工程師看事情的眼光較實際，科學家會較抽象。如何提升層次？得先看自己缺乏哪一部分，若想當科學家，須提高抽象思考的能力；若想當工程師，則須常做測
