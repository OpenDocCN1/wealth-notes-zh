# 從歷史統計機率？

# 不可以！因為格局不同，方法也不同

除了要求孕育線的嚴格定義外，很多人會進行一個自認為「屬於科學的實驗」，就是把歷史的孕育線找出來，再觀察這些孕育線將來上漲或下跌的可能性有多高，最後做一個統計，我以前習慣把這行為叫「跑報表」。當然，報表做出來以後，統計出（孕育線出現之後）上漲機率，我們希望能夠達到七成以上（以短線而言）。

在某些年代，確實可以發現靈驗度達到七成以上的「上升孕育線」，同學因此受到了鼓舞，認為王老師教的孕育線真的很棒！但同學不曉得的是，如此一來，大夥會掉入一個窠臼，誤以為所有K線都要經由這樣的「統計」方式去找出它的上漲或下跌機率，也就是用數學統計的方式確認其價值。

# 這種方法好不好呢？給各位一個明確的答案：不好！

格局愈大，意義就愈明確，如果格局愈小，操作的周期愈短，要把事情做得好就變得不簡單，因為愈是短線、愈是操作周期短，裡面的轉折變化就會非常多，此時，如果我們依舊按著大格局的理想去切入短線，勢必會遭受許許多多的挫折。
