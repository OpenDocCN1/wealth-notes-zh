# 自己找答案才是贏家

能夠擺脫K線表面稱呼的束縛，就算是K線入門了。

例如乾坤雙劍，很多人看到類似乾坤雙劍的K線時，就會跑來問我，這到底是不是乾坤雙劍？其實，是不是乾坤雙劍不是那麼重要，因為這根K線的最高價、最低價、K線上影線有多長、下影線有多長、K棒的顏色是紅是黑、K線的實體長度有多長，跟鄰近K線相關位置的高低……這些資料都已經擺在你眼前，足夠你去思考判斷。我們要做的工作是：看到這些基本資料、基本圖型，然後去做思考。它叫什麼名字，不是那麼重要。好比一個老師在台上講課，他上課的內容你都聽到了，他發的講義你都看到了，他抄的黑板你也都做筆記了……那麼，你認不認識這個老師不重要；這個老師叫什麼名字不重要；這個老師是台大王牌教授，還是隱居在鄉下默默無名的私塾老師，一點都不重要，重要的是這個人教得好不好，而不是頭銜。

投資人往往會忘記自己看到了什麼，也不去思考看到了什麼，只關心自己看到的東西別人怎麼稱呼它，這種行為叫捨本逐末。就好像一個女生嫁給一個男生，不去關心這個男人是好是壞，只關心這個男人在別人的眼中是好是壞。

很多買名牌包包的人，並不在乎包包值不值得這麼高的價格，只在乎別人知不知道他拿的是名牌包。這種執著於世俗表相的邏輯錯亂，千萬不可以搬到股市裡面啊！
