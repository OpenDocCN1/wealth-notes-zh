# Q3 怎麼樣知道自己已經成為K線贏家？

Ans：先套一句老前輩安德烈·科斯托蘭尼（André Kostolany）講過的話：「我這一輩子到現在為止，從未看過短線致勝的贏家。」

有很多 人或許反對科老先生這席話，但還是建議各位換個角度想：為什麼科老先生在70多年的交易生涯中，竟敢斗膽說他從未看過任何短線贏家？以他在股市中如此德高望重的地位，難道真的沒有看過一個短線贏家嗎？以他如此淵博的見聞，難道他不知道全世界的金融市場盡是臥虎藏龍嗎？……能夠確定的 是，在股市中，科老先生絕對不是個笨蛋，之 所以講這樣的話，一定有他的道理。

就個人有限的精力來講，我看過大多數的短線高手，到最後幾乎都被自己的狂妄自大給吞噬了，幾乎沒有一個人能夠有什麼好下場。也有一些年輕的短線操盤手，在最近風起雲湧的一些熱門市場中，頗有獲利，甚至成為暴發戶，但是考驗他們的時間都嫌太短，還沒有到蓋棺論定的時候。如果有人問我，過去像他們那樣靠短線暴發的操盤手現在在哪裡？我的答案是：大部分都陣亡了，也有的不知所終，還有許多不是生了令人嘆息的重病，就是家庭破裂，人生的幸福隨著他的財富降臨而愈來愈遙遠。
