# 王力群 k線操盤法

在。常人會因為資金部位的大小而念念罣礙，到了此一境界，則我不受世相束縛，資金的大與小、時間的長與短、皆是世俗之見，與法理不相容。如有一正法，則無一邪念；如有一正念，則無一罣礙。資金部位的大小，乃俗世煩惱之牽動，行者自然到此境界，見俗非俗、見空非空、多空雙沬、上下無別、大小亦無別，唯有正理是從。

以上七點，只是個大概，千山萬水走來，柳暗花明又一村。但是在此之前，卻有許多的山窮水盡，又有許多次踏破鐵鞋無覓處，卻到了山窮水盡之絕地。行者至此，如果念頭不轉，心眼不開，不悟本心，智慧不開，則境界無法提升，如此則永遠停留在平面的領域，深受盤中資訊汪洋大海的波折，往好處講，是資訊眾多，材料豐富，胡扯瞎掰起來亦多有所本，旁人誤以為莫測高深，其實是「莫名其妙」。自欺欺人，莫此為甚。從K線的第一層到最後一層，途中層層關卡、各個心魔，層出不窮，自大者不識、狂妄者不見、保守者不悟、無德者無緣。

此層境界正所謂八方玲瓏，隨手拈來，盡是香花珍寶，光彩奪目，引來眾生讚嘆。但凡此種種，皆為表相，不可執著；若為聖解，即為魔境。

過了倒數第二層境界，不需我講，各位也可以猜得到，那就是佛境界了。
