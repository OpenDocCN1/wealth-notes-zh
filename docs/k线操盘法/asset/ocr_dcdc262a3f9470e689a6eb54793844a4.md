# 一場自我發現的
思辨與智慧之旅

陳志清

股市學習除了破除「我執」外，首重「尋得明師」。在因緣際會下，2001年的冬天，當我在準備研究所考試的同時，有意無意中，在台北市重慶南路的某家書局的書架，覓得一本王力群老師寫的《散戶操盤必讀的第一本書》，自此與王老師有了一段師生之緣。
