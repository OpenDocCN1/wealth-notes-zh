# 小结：认识视觉会议

为了更好的参与感，全景思维，和群体记忆，你可以用画图的方式，邀请右脑一起来开会。开视觉会议，你并不需要是画家。记住三类（逻辑结构，时间顺序，发散思维）视觉图，就能成功召开大部分会议了。

它们是：利弊图，二维四象限图，分布图，系统图，甘特图，流程图，历史图，思维导图，鱼骨图，曼陀罗图。
