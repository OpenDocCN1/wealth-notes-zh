# 1、分析外部环境时，用波特五力模型和PEST模型

首先，这些战略分析工具当中，有一些是用来分析企业外部环境的。例如：波特五力模型和PEST模型。但是，它们是有区别的。

PEST模型，是从政治/法律、经济、社会文化和技术的角度看宏观大势。而波特五力模型，则是从行业层面分析公司的外部竞争：直接对手、顾客、供应商、潜在新进公司和隐性替代性产品。用这两个工具，可以帮助你从远看到近，从宏观看到微观。

# 2、内部战略选择时，用波士顿矩阵、通用电气矩阵和SWOT分析

其次，我们讲了波士顿矩阵、通用电气矩阵和SWOT分析。这三种战略分析工具，是用来做企业内部的战略选择用的。你可以用它们分析自己的业务组合、思考战略问题、寻求最佳的发展姿态。但是要注意，波士顿矩阵，通用电器矩阵，是从今天的，和未来的“产品”角度，看待企业的战略选择。SWOT是从公司相对外部环境，竞争对手的“能力”的角度，看到企业的战略选择。一个是“产品”导向，一个是“能力”导向。

在使用这三个矩阵分析自己企业，或者个人的战略能力时一定要注意。把产品，和能力放入矩阵不是目的。根据矩阵，讨论对应的策略，才是目的。比如，你还记得吗，在SWOT矩阵中，当S（优势）遇到T（挑战），你应该采取什么策略吗？

# 3、平衡短期长期利益，用平衡计分卡

然后，我们还讲到了“平衡计分卡”。在经营企业的时候，我们最容易看到眼前的利益得失，不容易看到长远。这就是格局。这时候，你就需要“平衡计分卡”来帮助你“德智体美劳”同步发展了。平衡计分卡从“财务，客户，过程，创新与学习”四个维度分别设定指标，来平衡公司的短期和长期，客户和财务，结果和过程，把公司的“愿景和战略”自然地融入到每个人日常工作中。

# 4、工具给了框架，但判断力需要苦练

10天的课程，恢宏铺陈，你一下子了解了很多咨询公司最常用的分析工具，也掌握了很多咨询业的黑话。比如瘦狗、现金牛什么的。但是，千万不要因此觉得，自己立刻就是商业高手了。

有了这些框架性的工具，它能给你整体性、前瞻性，让你总能提前迈出半步。但是，工具给了框架，却并没有解决判断力的问题。或者说，工具解决完整性问题，却并不解决正确性问题。

比如，每一个判断，比如SWOT里的T（挑战）是什么，PEST里的T（技术）是什么，在你的场景中，这需要不断提高的判断力。如果判断不准，比如今天的技术趋势是人工智能，你说不一定，也许是算盘。判断不准，工具再好都没有用。这是一个技术活，需要苦练，并且多和专家讨论。

另外，我在第198期问了大家一个问题，哪些是百度的现金牛业务，而哪些是百度的明星、瘦狗和问题业务？大家的回答都很好。很多同学都说，搜索业务，显然是百度的现金牛业务。没错，确实。

还记得判断现金牛业务的标准吗？整体市场增长率不高，但是公司的相对占有率很高。百度的搜索业务，尤其是PC搜索业务，明显是这一类。

人工智能呢？这显然是百度的“明星业务”，这一块业务，百度相对比较领先，而且这一块市场正在爆发式增长。人工智能，确实有可能会成为百度的下一个现金牛。

那什么是百度的“问题业务”呢？百度金融可能更符合这个标准。相对于蚂蚁金服，甚至腾讯来说，百度金融的市场占有率相对较小。但是这一块的市场总体增长非常迅猛，所以这块是问题业务。而百度外卖、百度糯米，从波士顿矩阵的标准来看，属于“瘦狗业务”：市场占有率相对于竞争对手较小，同时O2O的爆发式增长也已接近尾声。

用波士顿矩阵分析百度，就不难理解，为什么李彦宏，陆奇都说，要“all-in”人工智能了。
