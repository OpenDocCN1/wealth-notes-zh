是体力吗？是努力吗？还是智力呢？都不是。“自己”这家无限责任公司拥有的唯一资产，我们能用来与这个世界交换的唯一的东西，就是“时间”。人与人的差别，就在于同样给你一生的时间，你能换回什么。有人什么都没换回，有人换回了几乎整个世界。

那怎样才能用一样的时间，谁也不比谁长？的每一秒，每一分钟，每一小时，每一天，换回更多的价值呢？

《刘润·5分钟商学院》第三季度个人篇已经结束了。我和得到团队商议，正式选定8月5日在成都，8月12日在深圳，举办两场，也是唯一的两场“个人篇线下大课”，分享“自己”这家无限责任公司，“用时间换世界”的商业模式。用一个简单的公式表示，就是：时间价值 = 专业 x 效率 x 杠杆。

什么意思？我将在大课上，分为三个部分，与你分享它这个“个人商业模式”背后的逻辑。

第一，专业。如果你是个裁缝，你一小时的价格是200元；你是好裁缝，你更专业，你的价格是2000元；你是全球顶级裁缝，比尔·盖茨找你做衣服，你的价格是2万元，或者20万元。让自己变得更“值钱”，也就是更专业，是“个人商业模式”的基础。但是怎么才能做到呢？拥有什么样的精神力量，才能让自己比别人更专业？拥有什么样的学习方法，才能让自己比别人更快地变专业？拥有什么样的心理素质，才能让别人感受到你的专业？

第二，效率。让自己变得更值钱，是不够的，因为你再值钱，你能与这个世界交换的资本，时间，总是有013的。怎么管理好你的时间资产？从17分钟里省出17秒来，叫做时间管理吗？大量浪费掉的碎片时间，就像乱花的钱，怎么利用起来？如何通过方法、工具，提升自己时间效率？如何通过演讲、写作，提升自己沟通效率？如何把17分钟，用出17小时的气势？

第三，杠杆。让自己变得更值钱，并让每一分钟都用来赚钱，还是不够的。想用自己的底牌，和这个世界换取最大的价值，你还需要和其他选手打好配合，用好“杠杆”。如何利用“团队”杠杆，突破“你的时间终究有限”这个魔咒？如何利用“产品”这个杠杆，让你的时间，和你的团队时间，可以无限复制？如何利用“资本”这个杠杆，让你的产品价值飞跃式提升，并且提前提升？

时间价值 = 专业 x 效率 x 杠杆。用好这三个乘数，同样的 一生，也许你也能换回你的全世界。
