# —— 本周留言精选 ——

雕爷的《MBA教不了的创富课》，算是我的商业入门书籍，里面对于蓝海战略的讲述和案例分析讲的很清楚。

蓝海战略是通过对价值链的各个环节进行调整，突出客户更重视，更容易感知的环节，对客户不太注意，或者隐性的环节则做减法。比如经济酒店无法在硬件上和五星酒店相比，但是可以用最好的枕头，来让客户能有一个好的睡眠体验。zara通过强烈的设计风格，效率极高的新衣上架，以及跟随着修品牌选址的逻辑，让客户买的有面子，穿的有个性，而在不那么重要的面料，做工方面则进行了成本消减。价值链的加减，背后对应的是成本结构的调整。

推荐《六维领导力》给新上任领导以及后备领导，快速顿悟，具备领导基本功：持续成长的学习力；多谋善断的决策力；整合资源的组织力；带肤育人的教导力；达成绩效的推行力；凝聚人心的感召力。

（1）一入一出（学习力和教导力）：学习力，关注如何摄取、吸收、转化知识，是“输入”问题；教导力，关注的是如何应用知识、技能，是“输出”问题。

（2）一思一行（决策力和推行力）：决策力，主要表现在思考上；推行力主要表现在行动上，一个思想变，一个行动，构成了一思一行的关系。

（3）一硬一软（组织力和感召力）：组织力，主要在于整合资源，使用组织、制度、流程等硬件资源；感召力，则是领导个人的号召力、个人魅力、企业文化等软件资源，软硬兼施，构成了一硬一软的关系。

推荐战略学习的书籍清单：

+   1、《定位》是战略里边入门级的书。不管喜欢不喜欢，都是躲不过去。 2、《蓝海战略》，有一点像太祖的游击战，是在血肉模糊的红海竞争里，再杀一片新天地的战略。 3、《华杉讲述孙子兵法》，号称为往圣继绝学，个人觉得他把《孙子兵法》解读的非常贴近今天这个时代，并融汇了他ic战略方面知行合一的心法。 4、《推手》是老东家王志纲工作室的一个案例库，胜在案例主导，不枯燥。可以从案例倒推战略路径、方法。 5、《略胜一筹》，是曾鸣教授进阿里前的最后一本书，已经出版很久了，虽然代表不了他最新的思想，但是没办法，最新的书好像没有。 6、最后一本《竞争战略》，来自大名鼎鼎的哈佛教授迈克尔波特，是全球最经典的，还有两本是他的战略三部曲。

在中国，几个战略大家，王志纲重大势，王明夫产融学一体化学，曾鸣终局看开局，华杉、李克，把战略贯彻到包装盒上，别开生面。如果加两个互联网时代奇人的话，我会再加上雕爷，梁宁。

第一本，莫提默·J·艾德勒的《如何阅读一本书》，当你掌握对不同的书运用不同的阅读方法时，会收获读书带给你的精神和物质上的巨大回报。

第二本，奇葩说团队的《好好说话》，它的价值不仅给你提供具体的技巧，更在于让我们重新审视说话这件事。

第三本，成甲老师的《好好学习》，是讲学习技巧和如何管理自己知识的书。它将帮助你把零碎的知识打造成高效的知识管理体系，构建你的学习竞争力，让所学知识真正变成你的资产，让学习成为财富积累的过程。

刘润老师的《趋势红利》，概括出了底层的商业逻辑，搭配近在身边的案例，读一会儿想一会儿。我们做公寓咖啡厅，“流量变现”“单客经济”等等，不仅仅是顾客上门那一瞬间的交易，更有拓展价值链的持续消费。同时也是反映自己的服务能力，不断挖掘提升点，迭代更新。
