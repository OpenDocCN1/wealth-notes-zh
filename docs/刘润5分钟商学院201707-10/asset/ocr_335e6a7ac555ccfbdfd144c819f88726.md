# 小结：认识Scrum

Scrum是一套项目管理流程，包括：三个角色（产品负责人，Scrum专家，团队成员）、四个仪式（冲刺计划会，每日站会，冲刺评审会，冲刺回顾会）和三个物件（产品积压，冲刺积压，燃尽图）。
