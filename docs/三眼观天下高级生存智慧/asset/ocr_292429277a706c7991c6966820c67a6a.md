# 现象与逻辑

这篇文章小伙你读完了，在研究“阴阳管道”上一定会进入一个误区，就是“现象与逻辑”搞混。

比如佛家讲“幻象”多，幻象就是一种“水流”的结果表象，因为众生眼见为实，跟他们讲抽象的形态过程，多数人根本理解不了，要“普度四海”那就需要讲具象的，这样沟通的面才能广。

贪、嗔、痴、慢、疑、恶、恨、恼、怒、烦…等等，都是“毒”

毒是啥？就是“症状”！而不是人心的根本形态！

也就是人中病毒有了病，所表现出来的各种症状，人的思想“犯病了”就很痛苦，就要对名入座，那就需要修习法治理法去去去去去去去病？

所以佛家主流方法，是叫人们去体会，多数都是通过“讲故事”（身教）的方法，让人们对名入座去感受，在感受中去悟道。

不是说道家就比佛家要牛，而是方法利用法（法术）不同而已，大道殊途同归。

佛家“玩自己”较多，道家“玩别人”较多，诸子百家的各种“玩人大道”都是师承道家

所以，倒食要研究道家，佛家靠东西没有大智慧是很難用的上的，在古代（现代也一样）每当天下大乱了，道家就要出来“解决问题”，也只有道家解决问题的水平最高。

因为其最直接最赤裸，所以才会最有效。

而西方哲学呢？大多数是在那里“绕圈”，乐此不疲，津津有味。尤其是各种名言，其事实都是“100%正确”得反复！比如

供养的人为智者所经营，愚者所吸服，阿谀者所崇拜，而为自己的虚荣所奴役…”
