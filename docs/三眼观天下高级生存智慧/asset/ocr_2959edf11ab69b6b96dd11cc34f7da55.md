# 可欲

既然谈到“欲”，最后再啰嗦点
人打造“结构”也好，伪装与猎杀也好，心灵的净化也好，上山也好，下山也好，都围绕人的天性欲。
切道法术玩的核心就是这个“欲”。
人不能没有欲，只能顺应它，更高級一点叫做操控它孟子《尽心篇》中：“可欲之谓善”
这一句话人翻译，三眼还是觉得有问题，不准确。
直接翻译现代意思就是：值得追求的就是善这一點逻辑也没有啊！熟悉三眼的小伙伴应该知道，三眼解读“善”字不是好的意思而是一种“高级的生存伪装智慧”！
孟子这句话准确翻译应该是

既然离不开欲望，要想操控它，唯一办法就是要顺应它，爱上它，让它变成自身的一种习惯，废寝忘食，完全投入，这样才能做到“善”，也就是至极的智慧。当然，后面还有一堆

可欲之谓善，有诸己之谓信，充实之谓美，充实而有光辉之谓大，大而化之之谓圣，圣而不可知之，之谓神。

啥意思呢，讲的是一个凡人到圣人再到神人的过程。这么讲太虚，接地气讲法就是“人提升维度”的过程
“可欲”是第一步。

不颠魔不成活，不入魔焉能入圣入佛？
啥叫脱胎换骨？脱胎就是儒的游戏， 进入了就是重新投胎；
换骨就是道的游戏，进入了就能底层代码（骨架）。
这四个字还要加上“提魂”，就是释放，从心投魂。
无论哪個，都要“可欲”！
