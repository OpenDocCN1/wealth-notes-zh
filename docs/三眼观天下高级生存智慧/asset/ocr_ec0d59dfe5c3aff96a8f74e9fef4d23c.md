# 规则的力量

这里插一嘴，很多小伙伴从小就有个不解之谜，曹操瘦弱的小身板，性格还古怪，聪明也不要，为何他就能统领万众？因为他意志力强，懂得意识世界的本源竞争规则，会使用规则的力量，也就是“胜一为难，胜万人易”

以往文章总是讲“分配”，社会怎么搞分配？像动物一样，按照体量，体型大小搞分配？按照专业技术水平搞分配？代码编的好当皇帝？按照体力劳动价值搞分配？那还会有首富吗？都没有，是按照能力搞分配！这个能力就是参与意识世界竞争游戏的能力，是动用规则力量的能力，是在认识社会结构的基础上，自身结构与社会结构的平衡能力。

好了，这就是总结两点 1、人的一切都是在意识世界里，人的胜利是意识的胜利。读多少书，学会多少技术，那也只是工具而已，真正的“技术”是意识如何竞争，是如何在意识之中展开伪装与狡猾！ 2、三眼看“寄生”这个词很关键，人的成熟与否就在于对这个词的认识。常生二字让人感觉有点是非，更能冷静的看待社会与生存，每个人都寄生于社会之中，我们都像寄生虫，天王老子也一样！寄生虫活成什么样不是自己说得算的，而是取决于寄生环境。有什么样的寄生环境，寄生虫就该怎么活。
