# 漏洞二、善模仿

人类就像病毒一样去复制自己觉得优良的东西。
这个行为叫：模仿！
模仿，是人类“自我治疗”的一种天性疗法。
这句是三眼的解释，不同于模仿行为的模仿，不知道用什么词更适用。
不同于低端植物的地方在于，人类的模仿越惕行为层，会在思想上进行判断和复制就做病毒迭代一样。
如果在生物体层面对与自然界的动植物比较，人类显得相当弱小，理应在优胜劣汰中首先被淘汰掉。
而人类有思想，像病毒一样复制外界优势来弥补自身的劣势，不断改进自己模仿与学不会一样，学习有意识的，模仿无意识。
此种大体在人类精神规则上表现为不断地用“活着为什么”来“推残”自己，其实是想达到一种生存的终极目的，想“复制”一个能够永存的方法。
在终极目的没有达到前，“活着为什么”永远是一种病态，在这个“病症治疗”上，佛陀是最明明的“医生”。

所以，没有什么“出世观”和“入世观”，那都是宗教玩的花花样，对于思想来说，本质上只有“药物”的水平高低而已，具体怎么“用药”那是形式问题了所以为什么讲“精神规则”，而是“宗教”？
因为这完全是佛东西，后面讲：我们先来看看人类是如何一步步“制药”的？
