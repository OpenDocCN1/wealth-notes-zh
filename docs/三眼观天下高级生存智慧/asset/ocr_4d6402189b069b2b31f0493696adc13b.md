# 道法术与上山下山

道，就好比底层代码
抽象的看不见它，也很难表述，也很难传递，但是它是本源，悟道之人都会逐渐形成一个模糊朦胧的“道的形态”，藏于自身之中，平时也感觉不到它，但遇到问题之时它就自动跳出来发挥作用。
这一术有些诸者应该有感受，洗练现场的感受…时而推胸顿足心思烦躁，时而柳暗花明通透。
人话中的自信不是来自金钱、地位等，那都是过眼云烟飘忽不定的，自信是源于对“道”的理解和距离，只要有“道”的加持，给人扔在什么群体之中都会富有极强的生存力。
法，就好比软件
也就在某个领域具体的应用يران，这就具体化了，每个人生存都需要有“法”，俗称套路…法高不高明，直接决定了人处理事物高不高明。
术，就好比实体具体操控技巧。套路得于啊，这就需要灵活机变的术去实现。人他们最喜欢的就是“法术”，因为具体形象受，容一易理解，实用性强，但是没有“道”的加持，“法术”不会高明，“术”也不总是通。
道，是不断拔根的能力法，是系统化运作能力；术，是灵活变换操作能力。
大家虽然喜欢法术，那为什么“法”难呢？
