# 人要少读书没有文字，思想依旧分层！

![](bbox=[0.14, 0.24, 0.93, 0.48])

世间只有思想家，没有读书家。

总有读者要求我推荐书籍，有必要专门写一篇文章来讲讲读书了。

在这样一个娱乐化、碎片化时代，多数人饭做好了喂到嘴边都不吃的，这辈子也就那样了，爱好学习的人真不多，而在这么为数不多爱学习的人当中，假学习又占了大多数…

假学习的根不是态度问题，而是学习方法问题。

99.99%的人学习方法都错了！三眼讲这句话不是标题党，这是事实，很负责 任，这个错误方法是从小就“锻造”出来的！

如果一个人方法错了，将会绕很大一个弯路，而最后还是要回到起点，从 0 开始，不就就是“学废了”！

这个 0 就是思考！

这时候喷子应该跳出来了：“三眼你讲的这不就是废话吗？学习当然要思考！”

我说：“你错了，多数人还真就不思考，而是做偏了。”
