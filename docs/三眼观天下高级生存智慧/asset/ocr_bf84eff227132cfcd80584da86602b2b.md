# 4、个人创食

在所有“假象填补领域”中，最后落脚点还是个人创食。
不管是“虚的基本面”还是“实的基本面”，还是两个基本面中间的“讲道理缓冲带”，小动物左右看看，到最后还是自结成一个问题或叫目的:我的想赚钱我 Judge! 所以什么狼道呢、成功学呢、赚钱108招啊、炒股秘籍啊、虚拟币投资30法啊，跟钱没关系的呢？做人36计啊、泡妞黄金大法、职场精英10大法则啊什么的那怎么间来呢，用假象去研究假象的人，只能告诉他假象。这人吧，想要什么，就只能看见什么。

所以，一个小动物，基本脑子里填充的假象总结成以上4个领域，在里面不断着相对了！这个有娱乐，就是吃饱了思想欲、找乐子、求刺激、探求神秘等那些东西，本身娱乐直接就是假象、那个不谈了。

这时候该子该喊了，三眼，你说了一堆，就算你说的对，那你说啥叫真相？
认知，就是接近真相的距离！

# 1、世间无真相。

这世间没有什么根本的真相，或者叫“终极真相”，就好比一个人寂静的夜里问自己到底要什么，他想死也想不出来，哲学、各种宗教、家派、思想流派就是这么来的，都是创根底求真相，所以佛道最后总结，都是研究生与死的问题，因为那是人类思维所认定的终极形态。

# 2、但真相有距离。

真相虽然不存在，但是呢，求取真相的过程，会将人们的认知形成一个个梯度，暂且叫他“接近真相的距离”，这个东西决定了“猎杀水平”。
呢，会有一个“暂时性真相”。就好比政治制度几千年来一直在迭代，但每一个制度作为当时的一个时代的“基石”，会持续个几十年上百年不动摇，这个取决与信息传递度，取决与社会发展速度，决定了迭代速度，可以叫做暂时性真相，越接近这个，猎杀水平越高。

再说几个标志性的真假象，便于示意理解。先说个大的，决定人生“十年磨一剑”创食的。
政治决定经济，经济决定分配，分配结果就是社会饶理

# 1、政权的出现，需要“合理性”，这个东西叫做“法”

政权是个动态体，不是一成不变的，是一直在变化的，当一个政权建立之时，一定是要打破旧有的分配，重新建立一套分配，没有这一点，那跟木仓杆子土匪没区别是猴子那么没有效性就不长，包括一些军阀，根本问题就是没有找到“合理性”。当皇帝空手套能得到政权的人，关键就在于“土”改，没有这个“改”，和蒙古元与军阀没区别。
