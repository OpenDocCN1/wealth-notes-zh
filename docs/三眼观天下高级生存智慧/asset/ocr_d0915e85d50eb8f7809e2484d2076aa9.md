# 2、当一个政权边界解决了温饱之后，其“合理性”就过渡到分配二字，其主要关心并不在于生产，生产的主要目的是为了解决换领先打的问题，吃饱饭之后主要问题就是解决分配，而不是生产，这有先后顺序。大船不稳，谈什么航海？任何大组织干事，首先是解决自身稳定平衡问题，其次是航海问题。

所以把自己当成救世主，当成 G 之栋梁的那些娃娃可以洗洗睡了，理想主义等于理论主义，就不是小韭菜，怒喷科技不行的，怒喷制造业兴不来的，怒喷什么靠断开的东西等，拿着西学那套理论往上套的，都是小韭菜。

这不是“一人有限公司”玩过家家，这是“全民所有股份制公司”，这是大船。在分配问题上，说到根子就是有产和无产，所谓高速发展就是做大蛋糕造有产，所以以前一直强调 8，当速度不行了，那就要在“外部”找“增量”（外循环），实在不行了，才能“痛药”打的有产者消费群体，再送分配，到那一步是很痛苦的，相当于船开不动，停下来，船员们用拳头重新找一平衡。

那么有产无产，玩的是啥？核心在这个“产”字。以“土”起家，玩的就是土。什么时候“土”玩到极致了，那时候就会变成老鹰的翻版，什么翻版？就是玩“外盘”。是从英国 100 年前干的事例如讲楼市、土地财政等，大多舆论基本上都是假象，各类曲线啊，供需矛盾啊，结构啊，乱说一通，都是乱辩。以牛刀为代表的团体，这才炮火没多少响今天的事在几十年前其实现就可以预判到。98 房改，本质是啥？就是拿出一部分土地造有产，不造有产的话，经济循环不起来！十几年间的城市地产热闹非凡，是给谁造的？是给开放三十年里通过“租改买借”沾衣缝水富起来的一小伙件造的，手有余粮给他们一个空间落地。

什么叫经济循环？就是“给你点啥再用报弃回去”，形成一个回环。为啥就不需要房产税呢？为啥交易税很低？为啥没有遗产税呢？因为造有产还没有完呢！从开改到至今，经济的发展的本质就是“造有产”的过程，这是“基石”!!! 没这个玩不多久。但是再这么造，也不可能给你私有化，这是命根子，从这起家，发展也是靠玩这个。

造有产按照路线？肯定有先后啊！此处去研读一下“先富后富”理论为啥之前讲农民一定要变富裕了，因为按照节奏，到了这部分造产啊在哪造？怎么造？花多少成本？分出去多少？怎么拿回来？这就涉及到真假豪、就涉及到“猪杀”收割了。

刚要造，一般人反应不过来，造了一会了，有些人反应过来，更多人是喷，随着造的规模越来越大，喷的人越来越多，等造的差不多了，也就是“租改买借”那部分富裕富实的空间都给塞实好了，喷它就没有用了。开城缝该了，开始喊着要喝汤吃肉…背债分家富豪寡安本部……顺便自己高兴洋洋的说说“妥协”。回到主题：空间结构的假象似乎把人往沟里带，要通过时间来收割。资产这玩意不是“拼终点”，是“拼起点”。

现在的小动物就论上喊米喊地产，喊地产，喊实业问题等，穿越所有假象，归结到真相的根子，就是拼房产无产的怒喷而已，变成有产，立马笑脸迎人，态度“积极”！每天抱着经济学捧着脆弱的娃娃上，上面这个路线会写在经济学书里吗？貌似还没有本书叫做真实政治经济学
