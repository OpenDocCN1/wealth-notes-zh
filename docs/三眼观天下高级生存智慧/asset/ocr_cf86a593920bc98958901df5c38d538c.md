# 3、反向思考

看风向和贴脸都属于正向思考，比如大庄家号召全民进股市“充分调动居民存款入市”，并且大户人家真刀真枪的率先进去了，这就是要来真格的了，又是一轮蔽面“转圈圈”，那就要紧抄袭底紧跟步伐。但没这个茶餐能吃呢？毕竟还需信息的综合判断。

那就要学会反向思考，这是最简单的。

比如严格打击限制某些区位地段的房地产价格，那不用想了，这些地段就是最好的，一定要反着来；
比如支持 wan 众创业，那不用想了，就是让你自己养活自己，互相服务解决就业，不要添乱，这种玩法只能是“存量转移”，富了这家穷了那家，一片火海，那你还玩吗？

识时务者为俊杰，方法给了，人的性格都不一样，剩下看自己恬了，会紧跟步伐要比钱值钱的多，尤其对年轻人来说。
