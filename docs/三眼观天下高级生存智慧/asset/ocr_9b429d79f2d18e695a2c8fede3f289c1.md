# 智与谋

为何讲一篇文章可开智？首先要明白何谓智
古人讲智谋，看过此篇就会明白这个词的含义了：智，古文“知”，也就是说要知道事物存在的形态，结果就是“明”(抓住事物的本质看透了)，这就叫“明智”，其实现在被强调整“看成”智慧。
所以，从最本源上明人类family的根本形态，真正的认识“人”是什么，才是开悟之基！在《思想现象系列》里讲过，人类社会是个主观社会，我们所见到的诸多事物，其之所以被称作各种“事物”，均是由人去定义 的， 深深带着人的思维印记，人心与外界交互镜像的两个面，互为映射， 了解人心，即可了解外界。 而人的行为、群体体的交流互动，都跟人心里在照。

何为“谋”？
谋是一个戴帽子的言(古人戴帽子为官、为思想者，可以理解成有思想的人)，通过运用一个“言”(言语，来自观察、改善和操控他人水流(人心)，这就叫做谋。
从针对个体上升到针对群体，就叫作“谋略”，因为群体是有纹理格格(略)的。
所以工作也好，交朋友也好，谈恋爱也好，混圈子阶层也好，混组织也好，首先要弄清楚“略”，找到人心的形态。
