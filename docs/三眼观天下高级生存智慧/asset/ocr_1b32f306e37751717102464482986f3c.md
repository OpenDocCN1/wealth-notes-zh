# 何谓 1？

思想的本质是超越实体感知（眼耳鼻舌身意），通过更高维的感知能力，将具象化事物逐步抽象起来，这样才能到本源
思想的结果——就是看清事物存在的形态。
而我们生而为人，所有事物的形态归结到最后，本源都是对“人的形态”的研究。
老子和佛陀的“1”就在此！

研究的所所有东西，最后都要以人为核心，哲学思想比科学超前一步，但最后都要殊途同归，研究的标的最终都是研究 1。
所以，如何消万世不易的财富？
那就是：拥有看清“人存在于完整轨迹”这本书领。这是所有思考（0）前面的思想有了 1，可看清自身所有，也可看清外部所有
“人存在的完整轨迹”就像是根，无数事物都是由根生出的支脉，人的最终本领就是看清脉络的能力，最后自然而然的洞悉到“生存法则”！

# 人存在的完整轨迹

生存法则写到这是第三篇，这三篇综合起来，讲述的是“人存在的完整轨迹”
套用哲学三大问题更便于理解。
首先，看人要超越实体观察，将人看做“一束光的轨迹”：一束光线穿越时空，
那条“轨迹”才是人本身。

它包括

+   1、它怎么出现的
2、它呈现出什么暂时的样子？
3、它要到哪去？

生存法则二，讲述的是“我从哪里来”

也就是“我”怎么出现的。
画出人心（或思想）从 0（空无、静止态）到 1（人心一动）再到∞（诸多人心形态）这一过程。

人心动到刹那，趋利避害，产生“阴阳”两个方向，人的漏洞在于必做选择，“选择”多了，产生了诸多人心的形态，衍生出一系列“系统规则”，即为道徳，以此定义和规范在某一界限内（国家、区域、领域、行业、圈子、家庭、亲朋等）的思想行为了。
道徳的最终表现就是社会的“纹理”，也就是所谓文化（纹化）。
