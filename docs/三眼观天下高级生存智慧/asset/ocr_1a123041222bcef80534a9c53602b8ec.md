# 结构的复杂与简化

人生来是没有所谓“结构”的，生下来的时候空空如也，大家都像一张白纸，单纯得很可动，我其实不像，人本来就是动物而已，这是“生”。但人的诞生与小动物不一样，小动物幸存于自然生态，这是“天定的”；而人都要“寄生”于社会，社会是人造的，没有人可以独在生存，这就是“存”。
这俩凑起来叫做“生存”。
而社会的存在是有“结构”的！人类社会不是自然而然的一种生态，它是人为创造出来的，深度带有“人的痕迹”，诸如权力、宗教、政治、文化、文明、文字、分工等等，形成一种特有的“结构”。
这就迫使人的存在也要有“结构”，通过两个结构的平衡，来达到个体生存的延续。把社会的“结构”搞明白了，做人的“结构”就明白了研究“社会结构”的书籍很多，大致是西方法派别——切块式研究，搞得我复杂。比怎马克思按照生产关系分类，把社会分成原欲、奴隶、封建、资本、社会主义等；还有的按照生产方式分类，分成部落、农业、工业、信息等等如果作者能活一万岁，书可以继续写，信息社会后面会有意识社会、五维社会会什么的，根据时代发展出现酱写啥。马爷爷的书也不能加内，可以加什半妖民地球封建社会、社会主义、国家资本主义等等···根据现实情况可以加料，哈哈补充。
