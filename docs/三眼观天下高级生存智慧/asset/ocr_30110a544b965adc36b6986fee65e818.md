# 运用一、做人

有了方略，就会总结出做人的三个方法

# 1、不要标榜自己

标榜就是踏入了各种“管道上的标准刻度”之中，陷了就会跳不出来，到底是要尽忠还是尽孝，这是个无解的问题！
所以老子讲“无为”，讲“不争而争”，用在做人上就是能够思想跳出“方略”，思维自然通透，然后再去玩耍，自然“变化无形”何谓“变化”？就是“水性”，避高走低，没有固定形态，承载万物，润泽万物

# 2、善者不辩，辩者不善

因为每个人在方略中的“坐标”都不一样，正如和嗜讲义气会引来嘲笑，与吝啬之人讲康乐会适得其反，所以智慧的人不去辩驳，爱辩驳的人是不智慧的！善，不是好的意思，后世人在后面加个良字，把善的本意给曲解了。善，是高级智慧，是顺应事物形态变化的高级方法。

# 3、要学会区分人，哪些是“兽类”，哪些是“人类”。

从兽到人，越来越懂得节制，智慧也越来越高，反之，越来越趋向动物本能。兽类与人类没有严格界限，假如画一条分隔线，那么想必十之有七都是兽类，都活在兽性的本能之中而已。

这三句话是要一起综合运用的，是相互关联的。比如有人天性向善，向阳，做人积极友善，这样的人越容易陷入“标准”里，去标榜自己，因为他们懂得阴阳平衡，善于反思自己，自己就会“拿高标准要求自己”——越是智者，越陷入标榜之中。
反之兽类才不会标榜，因为兽是本能驱动，只要是有利的，即可趋之，兽类会害怕，但很少会反思自己。
所以我们经常看到这一幕，就是向善的人，实在在的人，都很直率，遇到兽类就会变得很想去辩驳，而辩驳的驱动是因向善之人想要“争个理”，争理就是寻求标准，争过诀就是在不断反思“自己达没达到心中的高标准”
如果这些向善的实在人，明白了第三句话，想必他们就不会去辩争了这三句话还可以延伸出很多道理！
比如，对不请自来的人去讲理，这是自寻烦恼，自找麻烦比如，兽类是一种动物本能驱动，所以满足它们，它们就开心，但它们是“填不满”的，因为一直向着阴或阳一个方向行驶，满足千万事，但只要有一件不满足，那千万事也立刻灰飞烟灭，优恨立即生出，而且越是满足越容易生仇恨

古语云：斗米养恩，担米养仇。就是这个道理。
