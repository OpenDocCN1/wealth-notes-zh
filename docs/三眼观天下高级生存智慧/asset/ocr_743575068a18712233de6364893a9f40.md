# 生存法则（三）万世不易的财富：真实面对自我，看清人存在的完整轨迹

![](bbox=[0.13, 0.26, 0.89, 0.49])

认知，就是接近真相对应的距离。
人的真相是什么？
我们每天的逃窜无措与痛苦挣扎，皆源于对这个问题的认识不清！
舍本与逐末，从1到0从古至今，对于个体之人来讲，最缺的是什么？
人活一辈子，能留给后世的“万世不易的财富”是什么？
思考！
思想有什么用？
对于猎人来讲，猎物多寡只是暂时的，猎杀的本领才是最终的无论是对自身还是对于后代，“本领”才是万世不易的财富。
何谓真正的思想？
很多人人有一个迷惑，就是学了很多思想，但是没感受到“本领”提升，陷入一个“思想到底有没有用”的困惑之中
其实，那种学的不的思想，而是思考
思想不是思考！
思想与思考差别很大，前者源自于心，后者纯脑力运动（后文系统讲述）。
如果把世间所有知识、信息、逻辑等等集合起来看，真正的思想占比极其稀少，甚至不足亿万分之
思想，是根据，取决于事物存在的本源形态-1：思考，是枝叶，是在1后面不断+0。现代人上以无用，思想是找到真相（接近的距离），思考是在假设里无限画圈。有思想的人只能极少一部分，因为需要“用心打破业障”。脑子负责加工（思考），心负责确定加工的方向（思想）。
所以叫“心智”，而不叫“脑智”，人都有脑子，而且差不多，都会思考，都会“画圈”，但人的心不一样
人心的决定人一辈子，而不是所谓“聪明才智”
老子与佛陀，这两个人的思考方向（1）决定了几千年东方人的思考（+0）。
在他们之前有所谓“1”，他们是用什么发现的？用心！
