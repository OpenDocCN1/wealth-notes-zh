# 漏洞一、精神指向

因为人类有一个巨大的漏洞
就是总拿“人为什么活着”这个问题来“搁浅”自己。
会运用此漏洞才是生存的最高技能！
不要觉得虚，这个问题无比重要，对这个问题的解答，让人类社会有了比动物界更高级的“秩序”！
没有这个，所以文明（秩序）就崩溃了。
人因思想而“自残”。
生命依赖于氧气而活，但反过来也氧气了生命，生命的存在和死亡都因氧气人的思想就如同生命之气，人因思想而获得存在感，获得快乐与满足，但也因思考让人痛苦不堪。
人与动物植物的区别在于有思想，也因为有思想而“自残”。
思想的特点是一直在变换，让其停住极其困难，据说大乘菩萨可以做到，这时咱也不清楚
思想像水，得有个东西给他“罩住”，不然就会漫无目的、迷茫空虚，痛苦与慌乱会接踵而至，人就这么做
这就让人类精神需要有个指向，就像一辆列车行驶必须要设定好一个方向让“气”与“水”都流动起来，才能有的放矢，人的精神世界才会平衡稳定下来。而在所有指向思考中，“人为什么活着”就是所有思考的核心，这也是人在思想上最大的“自残”行为了。
动物没这种活，活一辈子就是专心创食，啥时候饿啥时候算，永不问自己活着的意义，小动物开心不开心人类也不知道，估计只有庄子梦蝶才知道小动物可以独立活清空精神不崩溃，人类不行。
