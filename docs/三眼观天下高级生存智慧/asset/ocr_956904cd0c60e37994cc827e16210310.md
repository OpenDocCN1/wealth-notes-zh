# 假象、养殖与猎杀

没有时空，意识就没有“地方”去熏蒸。
极其稀少的意识（人）会主动去观察时空；绝大多数人都是被时空牵制着意识时空就像在那里，只能去感受，而不能去改变所以“智者”们发现，这个世间最巧妙的“魔术”，就是左右意识，从而左右行为，从而即可获得想要的结果。
而左右意识的本质就是：改变了“人们对于时间空间”的感受，从而“改变”了时空
时空并非改变，变的是人的意识！
就如同一切身感受，每个人每天所感受到的“时间长度”是不一样的空间上都是假象，唯有时间能拆说真相。
“智者们”干的所有事情，都可归结成一件事：通过改变意识，来改变对时空的认识，再通过假象来猎杀与养殖。
