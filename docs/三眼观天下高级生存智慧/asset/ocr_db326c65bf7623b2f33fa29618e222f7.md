# 一、世间方略

首先，大家原来都是野猴子，什么时候变成“人”，这个时间点不知道，但肯定有这么一个过程：从畜生变成人。

孔老二对这个变化有个词：衣冠禽兽。

禽兽穿上衣服就是人了，这个衣服可不是指代棉麻制品啊，而是“思想的衣服”。
我们把“穿衣服”（衣冠）这个过程再简化一下
“脱衣服”就是人的最本源形态，“穿衣服”就是在打造人的概念，“衣服”不同，
打造出来的人不同，这个叫文化归属。

假设一个人出生，就将其放在一个密闭的实验室里，不去接触人类社会，那么他就不是他，而是“它”，人类文明中的种种情感、道德、伦理、规则等“它”都没有，这时候的“它”就是人的最初形态，或者叫做“原始模型”。

怎么看原始模型呢？

起心动念决定它的外在表现：它长什么样子，复杂的行为表现等，不是它本身；
它为心知在动，才是它的本真。
因为它“没有穿衣服”，所以它的心与动结结构，是最干净的，是“人心”的雏形在思想观系列里讲过，人思想存在的巨大漏洞，就是必须要有一个方向选择！

人的思想不动（死）就是“一”，只要一动（活）就是“二”，就有一個方向。
