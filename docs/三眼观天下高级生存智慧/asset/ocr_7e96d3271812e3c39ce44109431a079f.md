# 二、方略运用

总结一下何谓“方略”？

人心一动，必有方向，趋利避害，此为阴阳，阴极为阳，阳极复阴，阴阳相生按照阴阳标准，设定各式各样的阴阳管道，顺应人趋利避害的漏洞，并在管道上设定各个刻度；不同用法，不同刻度，三维交织，形成方略。只要人就会陷入方略之中，只要起动心念，必有“管道”来为其“人心之水”引流有此方略，即可“神机妙算”，观人察事即可有了“动态结构”。讲个主要运用，运用之法共道一也，一通百通，在于变化懂人心，就能懂事物，所以叫人事，叫人物理，先人后物。事物都是人为出来的，我们所面对的人类社会是一个“主要环境社会”。学会如何叫“玩弄”？因为就像是逻辑公式不变，但是演化出的各种例子是变化多端的，平时拿着方略多角度把玩，即可“神鬼莫测”！
