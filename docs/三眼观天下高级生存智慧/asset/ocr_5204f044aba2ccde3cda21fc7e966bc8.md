# 【2600 多年的“服务业”】

服务业是啥？

万恶资本家开足马力大生产，一下子过剩了，严重积压，牛奶倒掉也不便宜卖，邪恶的资本主义！
咋办？
海外搞个殖民地卖一卖，抢殖民地就要干架，消耗工业产能顺便老大老二排顺序。

感性“小资”还是不要看三眼文字了，回头你再看那些慷慨激昂的战争电影该没感觉了！
因为看着大白皮踏着枪向前冲高喊民族大义，配上音乐有模有样，伟岸与道德形象顿时树立起来，但明白真相看起来就很搞笑了，不就是抢地盘嘛！

后来人类竟然出现了一波务虚大师——经济学家，大师们告诉诸位地主权益，咱不用往死里生产，一部分人生产即可，但养羊就要有闲位就业啊！
咋办？
那就让不参与生产的互互相服务吧，这就是服务业。
自从有了服务业，各位大佬对内可以安抚众夫，大家都有了就业有饭吃，对外也和平了许多。

尤其在神州大地，搞经济学、政治学、人类学、心理学、历史学这些混社会学的人，基本上对财富生产没啥具体作用，如果非要说有作用，就是提高人们精神质量的。
