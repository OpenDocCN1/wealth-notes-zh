这些朝着相反方向做人做事的，就叫韭菜。

# “我乐意”

# 韭菜看着想看见的东西，听信喜欢听的东西。

比如韭菜想发财？
错！
韭菜是想很轻松的发财！
那么你就告诉他轻松发财的路子，当然，轻松发财的路子 99.9999% 肯定是忽悠人的。
但韭菜喜欢听，你说了他就信。

# 韭菜不是要学习，而是要发泄。

经常有读者私信问三眼，该读些什么书获取认知？
图书馆里落一层灰的书就是好书；
公知嘴里讲的话都是“100%正确的话”——也就是废话。

针对韭菜玩切割，一是说假话，二就是要挨着情绪。
乡镇青年要用反叛和热血挨着情绪；白领要用民主和小资挨着；
一挨一个准，顺着毛撸，乖乖交钱。
