三观就是系统化思想。

其实绝大多数人对三观是很模糊的，而且市面对三观的定义也 SST 模糊，有好几套，其实大同小异，都是截取片段：宇宙观、世界观、人生观、价值观、道德观、情感观…。其实就是从大到小、从虚到实、从道至术的一个 n 排列，截取其中 3 个就是市面上的某一套三观。

我们拿宇宙观、世界观、人生观来讲，这个比较“正统”，其实就是中国传统思想中的“天地人”。

思想，就是观察事物形态；三观，就是观察外界形态的系统化方法。

宇宙观（天）——事事物存在的本源为何，也就是什么东西诞生了宇宙；

看起来很虚吧？其实最重要！道家诸境是一二三、阴阳、八卦、五行、天干、地支什么的。有了这个本源认识，才会有根可生长，开始向自然科学（方术、堪舆等）和社会科学（人心活动）上系统发展。

世界观（地）——认为宇宙是怎么诞生的，直接决定了如何看世界。

比如以万物为弔狗，有无、美丑、高下、善恶相生。再具体套到社会交互活动，政治、经济、人伦、人纹、利害、优劣，乃至生存方法等等。
