# 看到平量式攀爬上看震盪區間，應耐心持股待漲

![](bbox=[0.08, 0.62, 0.2, 0.71])

平量式攀爬上看震盪區間形態，是一種揭示主力參與股情況的量價形態。個股首先出現了持續時間較長的橫向震盪價格走勢，這是一種常見的運行格局，此時很難判斷是否有主力參與其中，多數投資人只能結合震盪走勢進行波段式的高賣低買操作。一旦股價有向上穿越震盪區的趨勢，投資人很難作出判斷。但利用這種量價形態，我們可以判斷股價是會開放突破上攻走勢，還是會再度折轉返回震盪區間內。
