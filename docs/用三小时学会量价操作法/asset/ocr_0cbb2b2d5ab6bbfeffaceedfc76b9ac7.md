# 2.6.4  巨幅下跌後縮量

巨幅下跌之後股價可能已中期見底，但也可能只是短期見底。在實盤操作中，我們一要看股價的累計跌幅，二要看縮量止穩時的股價重心變化情況。

如果股票累計跌幅較大，且在縮量止穩時股價重心不下移，這往往是趨勢見底的訊號，我們可以逢低買入，耐心持有；在股票短線跌幅較大，但在累計跌幅不大的情況下，縮量止穩時又有股價重心下移的現象，則表示空方依舊佔據主動地位，此时的止穩並不是跌勢見底的訊號。在實盤操作中，我們可結合大盤實施短線博反彈的操作，但不宜進行中長線的買入操作。
