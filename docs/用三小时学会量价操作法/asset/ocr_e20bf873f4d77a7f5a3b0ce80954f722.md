# § 1.2.3 動力與方向的關係

汽車跑得快不快，主要看引擎；沒有足夠的動力，再漂亮的車也只能成為擺設。量價分析的實質就是動力與方向的分析：成交量是動力，而股價走勢則是方向，這種動力作用尤其會展現在股價的上漲過程中。一般來說，如果沒有放大的量能作為股價上漲的動力，那麼上升走勢是難以維持的。

雖然公司的基本面情況、經濟因素、政策因素等均會影響到股價的走勢，但歸根究底，決定股價漲跌的力量，還是來自市場本身的買賣活動。股價上漲時，量能穩步放大，這表示漲勢仍在延續；股價上漲但成交量卻在縮小，這意味著漲勢已到了盡頭，是大盤反轉的徵兆。反之，股價下跌而成交量大增，顯示跌勢初起；股價持續下跌，但成交量越來越小，反映跌勢將結束，這是大盤反彈的訊號。

我們看圖 1-6 中的方框標注處，股價穩步上漲時，可以看到此時的成交量一直處於溫和放大的狀態。溫和放大的量能，代表著股價上漲時的動力，只要這種量價關係可以有效地保持，股價的上漲就具有較強的持續性。
