# § 2.5.4 強勢股整理區縮量

高位整理區中的「高位」是一個相對概念，在股價累計漲幅不大的時候，若此時與起漲點的低點相比已有一定漲幅，但上漲幅度在一倍以內，這也是一個高位。但在這個位置點，主力可能不會出貨，因為此時既沒有足夠的出貨空間，也難以吸引跟風盤追漲買入。

在這樣的位置點出現縮量漂浮形態時，若股價前期走勢獨立、上漲阻力較小，並且在橫向漂浮走勢中未出現股價重心下移的情形，則多是橫向的整理並非築頂，一旦多方力量積蓄完畢，新一輪的上攻行情會隨即展開。
