（x_{-m}, p_{-m};⋯x_{-1}, p_{-1};x_{0}, p_{0};x_{1}, p_{1}, ⋯, x_{n}, p_{n}） （6.13）

该选项的价值为：

∑_{i=-m}^{n} π_i v(x_i) （6.14）

首先来看价值函数。Tversky and Kahneman（1992）给出的v（.）的形式为：

v(x_i) = { x_i^c 若 x_i ≥ 0 
 -κ(-x_i)^c 若 x_i < 0 } （6.15）

由式（6.15）的定义可知，c ∈（0,1）代表了敏感度递减的快慢，而κ>1是损失厌恶系数，系数越高说明越厌恶损失△。图6.4（a）给出了当c=0.5、κ=2.5时的价值函数。在实际应用中，Tversky and Kahneman（1992）根据他们的实验给出的参数取值为c=0.88、κ=2.25。在Tversky and Kahneman（1992）发表之后，学术界又出现很多关于累积前景理论的大量研究，得到了不同的参数取值。一般来说，大量的实验结果表明，c的取值在0.5到0.95之间，而κ的取值在1.5到2.5之间。

再来看看累积前景理论中的权重函数，它的定义为：

π_i = { w⁺(p_i + ⋯ + p_n) - w⁺(p_{i+1} + ⋯ + p_n) 若 0 ≤ i ≤ n 
 w⁻(p_{-m} + ⋯ + p_i) - w⁻(p_{-m} + ⋯ + p_{i-1}) 若 -m ≤ i < 0 } 
 w⁺(P) = P^γ / (P^γ + (1-P)^γ)^{(1/γ)} 
 w⁻(P) = P^δ / (P^δ + (1-P)^δ)^{(1/δ)} （6.16）

其中γ, δ ∈（0,1）。在以上π_i的定义中，当i=n或-m时，π_i分别简化为π_n=w⁺（p_n）和π_{-m}=w⁻（p_{-m}）。与前景理论不同，在累积前景理论中，π_i的取值由累积权重函数w⁺（.）或w⁻（.）决定。具体来说，对于x≥0的结果，它的π_i的计算方法如下：分别计算所有不差于x_i的结果的概率之和（即p_i+⋯+p_n），和所有严格优于x_i的结果的概率之和（即p_{i+1}+⋯+p_n），将这两个概率之和代入w⁺（.）并求它们的差，即w⁺（p_i+⋯+p_n）-w⁺（p_{i+1}+⋯+p_n），这个差就是π_i。类似的，对于x_i<0的结果，它的π_i的计算方法如下：分别计算所有不好于x_i的结果的概率之和（即p_{-m}+⋯+p_i），和所有严格差于x_i的结果的概率之和（即p_{-m}+⋯+p_{i-1}），将这两个概率之和代入w⁻（.）并求它们的差，即w⁻（p_{-m}+⋯+p_i）-w⁻（p_{-m}+⋯+p_{i-1}），这个差就是π_i。w⁺（.）或w⁻（.）的形式如式（6.16）所示，它们的-di形式相同，只是参数γ和δ的取值不同，从而允许人们对于盈利和亏损结果赋予不同的权重。Tversky and Kahneman（1992）给出的参数取值为γ=0.61和δ=0.69。由定义可知：w⁺（0）=w⁻（0）=0且w⁺（1）=w⁻（1）=1。图6.4（b）给出了不同δ取值下权重函数的形状。
