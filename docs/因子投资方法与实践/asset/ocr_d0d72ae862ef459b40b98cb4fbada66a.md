# 正态性：

```
√T( b̂₀ − b₀ ) \xrightarrow{d} N(0, (ad)^{-1}aSa'(ad)^{-1'})      (2.115)
```

式中-1表示求逆，'表示转置，所以（ad）^{-1'}表示先求ad的逆矩阵，再转置。

Hansen（1982）给出了渐进分布成立需要满足的一系列假设。在实际应用中，应牢记的是数据x_ t需要满足弱平稳性，这是因为GMM的基础是随着T的增大，样本均值向总体均值收敛。

此外，Hansen（1982）中的引理4.1指出 g_T( b̂₀ ) 满足如下渐进正态性：

```
√T g_T( b̂₀ ) \xrightarrow{d} N(0, (I − d(ad)^{-1}a) S (I − d(ad)^{-1}a)')      (2.116)
```

式中I是n阶单位阵。式（2.115）和式（2.116）中的a就是样本矩的线性组合权重矩阵，但以上还未说明d和S是什么。接下来2.7.3节会把它们的含义说清楚。式（2.115）和式（2.116）中正态分布的方差 var( b̂₀ ) 和 var( g_T( b̂₀ ) ) 的表达式看似无比复杂，但它们本质上也都离不开2.7.1节介绍的样本均值的方差。

一旦有了 g_T( b̂₀ ) 的分布，便可以对GMM第一部分中提出的模型进行检验，从而决定是接受还是拒绝它。以资产定价为例，矩条件代表了给定定价模型下不同资产或投资组合的定价误差α，人们关心这些定价误差联合起来是否50为零。有了样本矩 g_T( b̂₀ ) 的分布，可以构建相应的检验统计量。如果检验统计量超过给定显著性水平的阈值，就第可以拒绝该资产定价模型。

总结一下，本节介绍了GMM的三个部分，其中：

+   • 第一部分把关心的问题表述成一组总体矩条件；

+   • 第二部分用样本矩代替总体矩从而把样本数据和模型联系起来，并进行参数估计；

+   • 第三部分计算 var( b̂₀ ) 和 var( g_T( b̂₀ ) )，并进行统计检验，决定是否接受第一部分提出的模型。
