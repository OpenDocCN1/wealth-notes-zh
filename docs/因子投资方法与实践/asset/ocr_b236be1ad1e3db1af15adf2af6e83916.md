# 表5.2 用于计算G-Score的8个指标

|  | 指标 | 计算方法 | 打分方式 |
|---|---|---|---|
| 盈利能力 | ROA | 净利润（不含少数股东损益)(TTM)/总资产(平均) | 高于行业中位数得 1 分，否则 0 分 |
|  | CFOA | 经营活动现金净流量 (TTM)/总资产(平均) | 高于行业中位数得 1 分，否则 0 分 |
|  | 应计利润 | ROA - CFOA | 小于零得 1 分，否则 0 分 |
| 保守会计处理 | R&D/总资产 | 费用化 R&D(TTM)/总资产(平均) | 高于行业中位数得 1 分，否则 0 分 |
|  | 销售费用/总资产 | 销售费用 (TTM)/总资产(平均) | 高于行业中位数得 1 分，否则 0 分 |
|  | 资本性支出/总资产 | 资本性支出 (TTM)/总资产(平均) | 高于行业中位数得 1 分，否则 0 分 |
| 盈利稳定性 | ROA 方差 | 过去三年单季度 ROA 的方差 | 低于行业中位数得 1 分，否则 0 分 |
|  | 营业收入同比增长率方差 | 过去三年单季度营业收入同比增长率的方差 | 低于行业中位数得 1 分，否则 0 分 |

将单个指标得分进行加总，就得到最终的G-Score。和F-Score一样，不同G-Score下的股票分布也并不均匀（见图5.4）。为此Mohanram（2005）也将所有股票按照G-Score高低分为3组，其中得分为0分和1分为低G-Score组，得分为2～5分为中G-Score组，得分为6～8分为高G-Score组。在针对A股的实证中，本书对上述分组方法稍有调整。由于2005年之前的数据存在指标缺失问题，因此在2005年以前将得分为2～4分的股票分为中G-Score组，5～8分的股票分为高G-Score组，在2005年以后则采用Mohanram（2005）的分组方法。
