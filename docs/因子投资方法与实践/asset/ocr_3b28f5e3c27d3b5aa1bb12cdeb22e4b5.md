式中Σ_R为因子收益率的协方差矩阵，Σ_s为特质性收益率ε_R的协方差矩阵。收益和风险模型错位意味着式（7.50）中的暴露β_α和式（7.51）中的暴露β_R不同。

在投资组合优化中，最常见的目标函数是Markowitz（1952）的均值—方差模型，它在最大化收益的同时对波动进行惩罚：

```
max_ω (R^α)'ω - ζ/2 ω'Σω    (7.53)
```

其中ζ是风险厌恶系数。在实际中，最优化目标函数式（7.53）的同时还会加入特定的约束条件。7.3.4节将会对约束条件进行详细介绍。接下来仅以最简单的无约束优化说明收益和风险因子模型错位造成的问题。

由于收益模型和风险模型的错位，R_α可以被分解成两个部分。其中一部分是R^α在由K个风险因子构成的超平面内的投影，另一部分是垂直于该超平面的残差。在数学上，上述分解可以表述为：

```
R^α = β_R (β'_R β_R)^{-1} β'_R R^α + (I - β_R (β'_R β_R)^{-1} β'_R) R^α    (7.54)
```

为简化表达，定义R^α_R ≡ β_R (β'_R β_R)^{-1} β'_R R^α和R^α_⊥ ≡ (I - β_R (β'_R β_R)^{-1} β'_R) R^α，并使用它们分别代表式（7.54）右侧两部分。当以式（7.53）为目标进行最优化时，由R^α的分解可知，求解最优的股票权重ω将受到R^α_R和R^α_⊥这两个方向的影响，最优的权重将是这种共同影响的结果。由于μ_⊥与风险因子所张成的超平面垂直，即β'_R R^α_⊥=0，因此从风险模型的角度来看，R^α_⊥没有任何风险。这将使得最优化过程过度倾向于R^α_⊥，这就是模型错位造成的问题。下面从数学上进一步说明。

式（7.53）的无约束最优解为ω* = 1/ζ Σ^{-1} R^α。将式（7.54）代入最优解（并假设所有股票的特质性风险相同）可得：

```
ω^* = 1/(ζ σ_s^2) R^α_⊥ + 1/(ζ σ_s^2) (I - β_R (β'_R β_R + σ_s^2 Σ_R^{-1})^{-1} β'_R) R^α_R    (7.55)
```

式中σ_s是股票的特质性波动率。式（7.55）说明最优权重ω*由两部分组成，第一部分和R^α_⊥有关，第二部分和R^α_R有关，它是这二者的加权平均。一方面，由于R^α_⊥在风险因子上的暴露为零，因此由R^α_⊥的系数可知，对于这部分收益率，最优化过程仅对股票的特质性风险进行了惩罚。而另一方面，由R^α_R的系数可知，对于这部分收益率，最优化过程同时对因子风险和特质性风险两者进行了惩罚。从上述对比可以看出，收益和风险因子模型的错位使得最优化过程误认为R^α_⊥没有风险，因此赋予其更高的权重。在投资中“盈亏同源”，R^α_⊥纵然是风险模型（7.51）无法解释的收益，也绝非没有风险。因此，模型的错位造成这部分收益率的风险被低估，从而影响最优化的结果。正确评估R^α_⊥的风险并对其惩罚就是需要解决的问题。
