质量进行综合性评估。神奇公式则主要由两个指标构成：净有形资产回报率（分子为息税前利润，分母为净流动资产与净固定资产之和）和盈利回报率（息税前利润与企业价值之比）。质量因子则由盈利能力、成长性和安全性三个维度复合而成。同Frankel and Lee（1998）类似，Bartram and Grinblatt（2018）的AFA策略也着重于买入内在价值相对股价较高的公司。但有所不同的是，后者将企业的内在价值与财务数据相关联，通过公司市值对16个来自资产负债表的指标、11个来自利润表的指标，以及1个来自现金流量表的指标的截面回归来估计公司的内在价值，然后计算内在价值相对价格的偏离幅度并据此选股。从上述描述可知，Bartram and Grinblatt（2018）关注的是通过其他公司隐含的企业内在价值。最后，Penman and Zhu（2019）指出股票的下期预期收益（1-period ahead expected return）与公司的预期盈利及预期盈利增长有关，并用8个指标凹来估计预期盈利和预期盈利增长，然后构建选股策略。

Hou et al.（2019a）使用多空对冲组合代表上述每一个策略，并检验该组合是否能够获得q和q⁵模型无法解释的超额收益，以及该组合在模型所包含的风格因子上是否有显著的暴露。表7.27总结了检验结果凹。对于绝大多数价值投资策略，q和（或）q⁵模型中的因子均能较好地解释它们的收益率，说明这些策略的风格可以被这些因子解释。具体结果详见表7.27，文中不再赘述。

# 表7.27 价值投资策略风格分析结果

| 策略 | 风格分析 |
|---|---|
| 内在价值策略 | 内在价值策略在 q 和 q⁵ 模型下均没有显著的 α；其多空对冲组合在投资因子上有显著的正暴露。从金融学角度来说，这是符合逻辑的，因为股票内在价值同账面价值的增长有关，而账面价值的增长与投资因子密切相关 |
| F-Score | F-Score 在 q 和 q⁵ 模型下均没有显著的 α；其多空对冲组合对盈利因子有显著正暴露，同时对市场组合和规模因子有较显著的负暴露。由于盈利能力是 F-Score 的一个重要维度，因此上述风格分析结果符合预期 |
| 神奇公式 | 神奇公式在 q 和 q⁵ 模型下均没有显著的 α；它对于盈利因子有高度显著的正暴露，而对于市场组合有显著的负暴露。由于神奇公式的两个维度都与盈利能力有关，因此它对盈利因子有显著的正暴露符合预期。除此之外，神奇公式对 q⁵ 模型中的预期投资增长因子也有显著的正暴露，因此 q⁵ 模型比 q-因子模型能够更好地解释神奇公式策略 |
| 质量因子 | 质量因子在 q-因子模型下能够获得显著的 α，但在 q⁵ 模型下能够很好地解释其收益率。从风格暴露来看，质量因子对 q⁵ 模型中的盈利和预期投资增长因子有显著的正暴露，对市场组合、规模和投资因子有显著的负暴露。考虑质量因子由盈利、成长、安全性等多个维度复合而成，上述风格暴露与其构造逻辑相一致 ® |
| 无先验的基本面分析 | 无先验的基本面分析策略在 q 和 q⁵ 模型下均没有显著的 α。从风格暴露来看，投资因子和规模因子起着决定性作用，多空对冲组合对前者有显著的正暴露，对后者则有显著的负暴露。此外，当控制了市值后，该策略对盈利因子和期望投资增长因子分别有显著的负暴露和正暴露 |
| 期望收益策略 | 期望收益策略在 q-因子模型下能够获得显著的 α，但其超额收益在 q⁵ 模型下不再显著；它对盈利和预期投资增长因子有显著的正暴露，对规模和投资因子有显著的负暴露。上述风格特征与质量因子十分接近。由于该策略的基础指标覆盖盈利能力、投资和估值等多个维度，因此其风格暴露与质量因子相似是符合预期的 |
