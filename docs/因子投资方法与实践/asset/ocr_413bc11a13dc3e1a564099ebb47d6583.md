```
∑_{m=1}^{M} σ(R)ρ(r_m,R)^2 = ∑_{m=1}^{M} x_m σ(r_m)ρ(r_m,R)
⇒ (∑_{m=1}^{M} ρ(r_m,R)^2) σ(R) = ∑_{m=1}^{M} x_m σ(r_m)ρ(r_m,R)
⇒ 1 × σ(R) = ∑_{m=1}^{M} x_m σ(r_m)ρ(r_m,R)
⇒ σ(R) = ∑_{m=1}^{M} x_m σ(r_m)ρ(r_m,R)  (7.106)
```

在上面的推导中，∑_{m=1}^{M} ρ(r_m,R)^2 = 1 利用了可决系数 R^2 的性质。由于假设所有的收益源都是不相关的，即 ρ(r_m, r_n)=0，在这种情况 下 R^2 等于投资组合收益率与每一个风险源收益率的相关系数的平方和，即 ∑_{m=1}^{M} ρ(r_m,R)^2 = R^2。此外，根据假设，投资组合的收益率完全由这些收益源解释，因此 R^2=1。结合上述两点，最终有 ∑_{m=1}^{M} ρ(r_m,R)^2 = 1。

# 7.7.4 将三要素公式应用于多因子模型

下面把收益源用多因子模型中的因子代替，利用风险三要素公式给出风险归因表达式。假设在风险归因的投资组合中包含 N 支股票。由给定的多因子模型可知，每支股票的（超额）收益率可以分解为因子和其特质性收益的线性组合（为了简化表达，省略时间下标）：

```
R_i^e = ∑_{k=1}^{K} β_{ik} λ_k + ε_i  (7.107)
```

进一步，假设在目标投资组合中，股票 i 的权重为 ω_i，则该投资组合的超额收益率是这些股票收益率的加权之和：

```
R^e = ∑_{i=1}^{N} ω_i (∑_{k=1}^{K} β_{ik} λ_k + ε_i) = ∑_{k=1}^{K} (∑_{i=1}^{N} ω_i β_{ik}) λ_k + ∑_{i=1}^{N} ω_i ε_i = ∑_{k=1}^{K} β_k λ_k + ∑_{i=1}^{N} ω_i ε_i  (7.108)
```

式中 β_k = ∑_{i=1}^{N} ω_i β_{ik} 表示投资组合在因子 k 上的暴露，它是包含个股在该因子上暴露的加权之和。对式（7.108）直接运用风险三要素公式便可方便地求出该投资组合的风险归因：

```
σ(R^e) = ∑_{k=1}^{K} β_k σ(λ_k) ρ(λ_k, R^e) + ∑_{i=1}^{N} ω_i σ(ε_i) ρ(ε_i, R^e)  (7.109)
因子贡献的风险    个股特质性贡献的风险
```

可见，投资组合的风险由因子代表的系统性风险和个股特质性风险两部分组成。个股特质性风险源于个股的特质性收益率，它是因子无法解释的部分。在使用多因子模型进行风险归因时，需同时考虑以上两部分，才能正确地对投资组合进行风险归因。
