# 2.6.3 用正交化过程求解多元回归

考虑如下线性回归模型，其中x0=[1, 1, ⋯, 1]′和x1=[x1, x2, ⋯, xn]′，假设x0和x1非正交：

```
y = a x0 + b x1 + ε  (2.88)
```

模型（2.88）的OLS估计量为：

```
â = 1/n Σ_{i=1}^n y_i - b̂ (1/n Σ_{i=1}^n x_i)，  b̂ = [Σ_{i=1}^n x_i y_i - 1/n Σ_{i=1}^n x_i Σ_{i=1}^n y_i] / [Σ_{i=1}^n x_i^2 - 1/n (Σ_{i=1}^n x_i)^2]  (2.89)
```

接下来说明如何通过正交化求解 â 和 b̂。 由于 x0 和 x1 非正交，首先需要构造出一组正交向量。令 z0 = x0 = 1 为其中的一个向量；将 x1 作为被解释变量、z0 作为解释变量进行一元OLS回归（不带截距）得到的残差就是和 z0 互相正交的向量，记为 z1。由式（2.85）以及回归的性质可知：

```
z1 = x1 - <z0, x1>/<z0, z0> z0 = x1 - x̄ 1  (2.90)
```

上式中 x̄ 表示 x1, x2, ⋯, xn 的均值。接下来，将 z1 和 y 代入式（2.85）恰恰就得到式（2.89）的OLS估计量 b̂：

```
<z1, y>/<z1, z1> = <x1 - x̄1, y>/<x1 - x̄1, x1 - x̄1> = [Σ_{i=1}^n x_i y_i - x̄ Σ_{i=1}^n y_i]/[Σ_{i=1}^n (x_i - x̄)^2] = [Σ_{i=1}^n x_i y_i - 1/n Σ_{i=1}^n x_i Σ_{i=1}^n y_i]/[Σ_{i=1}^n x_i^2 - 2 n x̄^2 + n x̄^2] = [Σ_{i=1}^n x_i y_i - 1/n Σ_{i=1}^n x_i Σ_{i=1}^n y_i]/[Σ_{i=1}^n x_i^2 - n x̄^2] = [Σ_{i=1}^n x_i y_i - 1/n Σ_{i=1}^n x_i Σ_{i=1}^n y_i]/[Σ_{i=1}^n x_i^2 - 1/n (Σ_{i=1}^n x_i)^2] = b̂  (2.91)
```
