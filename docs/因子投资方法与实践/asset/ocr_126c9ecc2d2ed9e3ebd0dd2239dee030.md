# 7.7.3 从风险角度看收益相关性

风险三要素式（7.100）不仅为风险归因提供了依据，而且还为理解收益之间的相关性提供了全新的视角。三要素公式说明，收益源和投资组合的相关性ρ（rₘ，R）对风险贡献至关重要，而ρ（rₘ， R）又和不同收益源之间的相关性有着千丝万缕的联系。

在通常情况下，用来构建投资组合的收益源之间难以满足完全独立的条件，而是或多或少存在相关性（可以是正相关也可以是负相关）。例如在多因子模型中的大部分因子虽然相关性很低，但也不是相互独立的。收益源m和n的收益率之间的相关性可以由它们的相关系数ρ（rₘ， rₙ）表示。风险三要素式（7.100）为解读ρ（rₘ,R）和ρ（rₘ,rₙ）的关系提供了全新的思路。通过简单的数学推导可知：

```
ρ(rₘ,R)= cov(rₘ,R)/[σ(rₘ)σ(R)] = cov(rₘ,∑ₙ=1ᴹ xₙrₙ)/[σ(rₘ)σ(R)] = ∑ₙ=1ᴹ xₙ cov(rₘ,rₙ)/[σ(rₘ)σ(R)] = ∑ₙ=1ᴹ xₙ [σ(rₙ)/σ(R)] ρ(rₘ,rₙ)  (7.103)
```

式（7.103）说明任何一个收益源m和投资组合的相关性ρ（rₘ，R）都等于该收益源与收益源n的相关性ρ（rₘ，rₙ）以权重xₙ（σ（rₙ）/σ（R））相加之和。收益源n对ρ（rₘ,R）的贡献度取决于投资组合对收益源n的暴露程度xₙ、收益源n对投资组合的相对波动率σ（rₙ）/σ（R），以及收益源n与m之间的相关性ρ（rₘ,rₙ）。

只有当xₙ足够大、rₙ的波动与R的波动有可比性、rₙ与rₘ高度相关，三个条件同时满足时，收益源n才足以影响收益源m与投资组合的相关性。通过比较不同收益源的xₙ（σ（rₙ）/σ（R））ρ（rₘ， rₙ），就可以方便地判断哪个收益源n对ρ（rₘ，R）的贡献最大。这可以为基金经理控制投资组合的风险提供新的思路。

在理想情况下，如果投资组合的收益可以完全被若干个收益源解释，且这些收益源之间都是不相关的，即对于不同m和n都有ρ（rₘ， rₙ）=0，在这种情况下（并利用ρ（rₘ,rₘ）=1），式（7.103）简化为：

```
ρ(rₘ,R)= xₘ σ(rₘ)/σ(R) ⇒ σ(R)= xₘσ(rₘ)/ρ(rₘ,R), ∀m  (7.104)
```

乍一看，这似乎与三要素式（7.100）矛盾，但在简单计算后不难验证式（7.104）与式（7.100）是一致的。将（7.104）两边同时乘以ρ（rₘ,R）²得到：

```
σ（R）ρ（rₘ,R）² = xₘσ（rₘ）ρ（rₘ,R）, ∀m  (7.105)
```
