在独立双重排序中，两个变量的地位是完全对称的，因此很容易就可以得到围绕X₂变量构建的因子投资组合，它通过做多L₁ (=5) 个在变量X₂上高排名组合（P₁₅、P₂₅、P₃₅、P₄₅以及P₅₅）、做空L₁ (=5) 个在变量X₂上低排名组合（P₁₁、P₂₁、P₃₁、P₄₁以及P₅₁）而构成，并满足资金中性。该因子第t期的收益率λₓ₂ₜ为：

```
λₓ₂ₜ = 1/L₁ ∑ᵢ₌₁ᴸ¹ RᵢL₂,ₜ − 1/L₁ ∑ᵢ₌₁ᴸ¹ Rᵢ1,ₜ (2.6)
```
