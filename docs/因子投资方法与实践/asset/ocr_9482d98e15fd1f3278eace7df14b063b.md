λ̂ = (β̂′β̂)⁻¹ β̂′ E_T[R^e]                (2.20)
α̂ = E_T[R^e] - β̂λ̂                                    (2.21)

为了联合检验所有定价误以及每个因子的预期收益率，仅知道λ̂和α̂是不够的，还需要求出它们各自的标准误。令ε_t=[ε_1t, ε_2t, …, ε_Nt]′（ε_it是时序线性模型（2.17）中的随机扰动，且定义Σ_f≡cov(f_t)以及Σ≡cov(ε_t)，利用它们并假设f和ε_t之间相互独立，且它们各自在时序上满足独立同分布，Cochrane（2005）给出了λ̂和α̂的协方差矩阵：

cov(λ̂)=1/T[(β̂′β̂)⁻¹ β̂′Σβ̂ (β̂′β̂)⁻¹ + Σ_f]                (2.22)
cov(α̂)=1/T[I - β̂(β̂′β̂)⁻¹β̂′] Σ [I - β̂(β̂′β̂)⁻¹β̂′]′          (2.23)

在实际中，由于真实的Σ和Σ_f未知，故可采用残差向量ε̂_t=[ε̂_1t, ε̂_2t, …, ε̂_Nt]′代替ε_t，计算样本Σ̂代替Σ，并使用样本协方差矩阵Σ̂_f代替Σ_f。将Σ̂和Σ̂_f代入式（2.22）和式（2.23）就得到协方差矩阵的估计。进一步利用它们计算标准误即可进行检验。

尽管上述表达式看上去已经足够复杂了，但仍有两点需要简单说明。第一，在截面回归模型（2.18）中，作为解释变量的因子暴露β̂是从第一步时序回归中得来的，它们是估计值而非真实值。对于模型（2.18）来说，β̂被称为生成的回归变量（generated regressors）。因此在计算标准误时，应该对生成回归变量造成的误差进行修正。对于此，Shanken（1992）给了解决该问题的修正方法（被称为Shanken修正），即在cov(λ̂)和cov(α̂)的表达式中添加系数(1+λ′Σ_f⁻¹λ)：

cov(λ̂)=1/T[(β̂′β̂)⁻¹ β̂′Σβ̂ (β̂′β̂)⁻¹ (1+λ′Σ_f⁻¹λ)+Σ_f]                  (2.24)
cov(α̂)=1/T[I - β̂(β̂′β̂)⁻¹β̂′] Σ [I - β̂(β̂′β̂)⁻¹β̂′]′ (1+λΣ_f⁻¹λ)          (2.25)

在实际应用中，使用λ̂代替λ，Σ̂_f。第二，除Shanken修正外，截面OLS回归中存在的另外一个问题是，在截面上α_i存在相关性。这种相关性虽然不会影响OLS估计的性质，但是会使OLS计算的标准误存在巨大的误差，造成对标准误的低估。为解决这个问题，可以使用广义最小二乘（Generalized Least Squares，即GLS）代替OLS。

当使用GLS求解截面回归时，估计量λ̂和α̂的表达式为（以下数学符号中加入了下标GLS以便和OLS表达式进行区分）：

λ̂_GLS=(β̂′Σ⁻¹β̂)⁻¹ β̂′Σ⁻¹ E_T[R^e]                 (2.26)
α̂_GLS=E_T[R^e]-β̂λ̂_GLS                                 (2.27)
