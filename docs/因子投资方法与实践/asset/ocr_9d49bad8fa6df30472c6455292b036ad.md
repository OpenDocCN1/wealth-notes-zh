```
PMU = 1/2 (S/P + B/P) - 1/2 (S/U + B/U)   (4.6)
```

# 4.1.4 Fama–French五因子模型

Fama and French（2015）在Fama–French三因子模型的基础上添加了盈利和投资两个因子，提出了新的五因子模型：

```
E[R_i] - R_f = β_{i, MKT}（E[R_M] - R_f）+ β_{i, SMB} E[R_{SMB}] + β_{i, HML} E[R_{HML}] + β_{i, RMW} E[R_{RMW}] + β_{i, CMA} E[R_{CMA}]  (4.7)
```

式（4.7）中，E[R_{RMW}]和E[R_{CMA}]分别为盈利因子和投资因子的预期收益率，β_{i, RMW}和β_{i, CMA}分别为个股i在这两个因子上的暴露。每年六月末，使用最新财务数据对股票重新排序并对规模、价值、盈利和投资四个因子的投资组合进行再平衡。

该模型从股利贴现模型出发并利用Miller and Modigliani（1961）的结果推导出t时刻公司市值M_t满足如式（4.8）关系：

```
M_t = Σ_{τ=1}^{∞} E[Y_{t+τ} - dB_{t+τ}] / (1 + r)^τ   (4.8)
```

其中，Y_{t+τ}是t+τ期的净利润，dB_{t+τ}是未来t+τ期的账面价值的变化，r是股票长期的预期收益率。将式（4.8）两边同时除以t时刻公司的账面价值B_t可得：

```
M_t / B_t = [ Σ_{τ=1}^{∞} E[Y_{t+τ} - dB_{t+τ}] / (1 + r)^τ ] / B_t   (4.9)
```

Fama and French（2015）通过分析式（4.9）提出了如下关系：

+   • 当除了 M_t 和 r 的其他变量不变时，更小的 M_t（或更高的 B_t / M_t）对应更高的 r；
• 当除了 Y_{t+τ} 和 r 的其他变量不变时，更高的 Y_{t+τ} 对应更高的 r；
• 当除了 dB_{t+τ} 和 r 的其他变量不变时，更高的 dB_{t+τ} 对应更低的 r。
