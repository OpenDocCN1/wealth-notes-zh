# 表7.18 因子配置方法

|  | 金融学假设 | 实现方法 | 数学公式 |
|---|---|---|---|
| 简单多样化 | 不预测因子未来表现，等权重配置 | 所有因子的权重相同 | ω_k = 1/K |
| 波动率倒数 | 绝对收益率的波动率更低的因子能提升组合的风险收益特征 | 按因子绝对收益率的波动率的倒数赋权 | ω_k ∝ 1/σ_k |
| 风险平价 | 平摊不同因子的风险贡献，从风险角度实现多样化配置 | 每个因子对投资组合的边际风险贡献相同 | ω_i ∂σ_p/∂ω_i = ω_j ∂σ_p/∂ω_j |
| 最大分散度 | 追求组合的分散性 | 选择因子权重使得组合的分散比率最大化 | arg max (ω'σ)/√(ωΣ'ω) |
| 因子动量加权 | 因子的历史表现在未来会持续 | 以因子过去一段时间相对基准的表现作为权重 | ω_k ∝ μ̃_k/σ̃_k |

表中，σ_p表示投资组合的波动率；σ和Σ分别为因子组合收益率的标准差向量和协方差矩阵；μ̃_k和σ̃_k分别为因子k超过基准的平均收益和其波动率。

这个结果并不意外，一方面因为被配置的因子指数本身的风险收益差异并不大（表7.15）；另一方面则因为复杂的方法需要更多的参数，而使用历史数据估计参数有很大的误差。由于这两个方面的原因，复杂配置方法无法显著战胜简单多样化配置方法也就不需要理解。上述结果和DeMiguel et al.（2009）针对美股的实证结果相吻合。因子指数的不同配置权重方案，本质上也属于因子择时或轮动，是否有效目前尚没有明确的答案。
