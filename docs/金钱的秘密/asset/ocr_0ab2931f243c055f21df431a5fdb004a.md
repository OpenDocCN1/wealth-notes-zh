# 瞬間崩潰的世界經濟

就業市場的惡化，將導致今後生產、消費、投資和實物指標等所有方面的惡化。不禁令人再次想起 1929 年美國經濟大蕭條的情形，被稱為先進國家的美國、英國以及歐洲主要強國，就這樣崩壞了。
