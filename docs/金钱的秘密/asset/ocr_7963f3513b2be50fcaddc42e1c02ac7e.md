# 09 會計師  很會投資嗎？

> 降低風險才是成功的捷徑，投資者去冒險
就等於投機。要過濾掉沒有利潤或預測虧損
的公司，就必須學習理解財務報表。

所謂的價值投資，就是以適當的價格買進成長可能性較高的企業股票，若超過適當的價格就賣出。此時要找出股票是否為合理的價位，最正確的เครื่องมือ就是該企業的財務報表。一般人很難了解一家公司的財務報表，因為不僅很難理解那些用語，而且也看不懂。那麼精通財務報表的會計師，真的很會投資嗎？

投資分為資訊和心理，對財務報表的理解和解釋的能力是屬於資訊。我們在亞馬遜就算購買一支 20 美元的眼影筆，也會確認商品評價是否超過四顆星，並搜尋看看有哪些負評。在書店購買一本 1 萬韓元的書（約台幣 250 元），也要確認書評。但是我們購買股票時，既不看商品評價，也不看書評，單單靠著未經證實的傳聞，也能非理性地決定讓數千萬、數億韓元出擊。
