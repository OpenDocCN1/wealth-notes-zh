# 08 每筆錢
都有不同的品性

> 有堅定的生活哲學，才能匯集優質的錢。
只要錢的主人下決心積存優質的錢，
那麼錢會自動黏在主人身邊。

每一分錢會隨著產生的過程，具有不同的個性。每筆錢都有性格傾向和氣質，所以有很固執的錢，有非常大膽的錢，也有些軟弱無力的錢。有些錢喜歡待在家裡，有些錢出去後永遠不會回來。正如出於同一個父母的兒女，他們的喜好和性格也都不同，而金錢也一樣。

同樣的1,000萬韓元，靠著粗重勞動賺的錢、從投資股票賺的錢、從賭場賺的錢、從儲蓄生出來的利息錢，絕對不同。因為每筆錢都不一樣，所以有些錢死黏著主人，無法發揮錢的價值；有些錢很容易消失，有些錢會引來其他的錢，甚至有些錢會帶走周邊的錢。因為錢隨著產生的方式，而長出性格和傾向。
