# 勿憑一句話做決定

會問問題是好的，功課好不一定會成功，但會問問題的人成功率可能會比較高。但投資的世界例外，因為投資與金錢直接相關，根據一句話所做的決定，與實際收益有很深的關聯。最大的問題是，回答的人不知道答案。銀行職員、證券公司的職員、會計師、專業投資人，甚至知名的基金經理人都不知道真相，他們只是傳達展望和傳聞罷了。諸如報章雜紙或電視上經常出現的高手外傳、必殺技、項目推薦、股票命理大師、投資訣竅、預測上漲的項目、投資實戰法、圖表技術分析、買賣特別講座、短線當沖、技術分析成功祕訣等，所有誘惑的言論都是騙局。
