# 06 風險高的時候
風險最低

了解風險，不是根據模式和分析而得出推測，
而是從哲學的角度來接近風險更為合理。

投資遵循未來的觀點，其觀點的核心為風險管理。基本上
我們會有某個程度的預測，知道哪些資產或股票會上漲。但是
即便預測正確，風險仍然存在。因為根據特定資產的投資時機，
收益也會有所不同。雖然整體資產上漲，但還是有虧損，因為
時間不足，或投入的資金質量不佳。
