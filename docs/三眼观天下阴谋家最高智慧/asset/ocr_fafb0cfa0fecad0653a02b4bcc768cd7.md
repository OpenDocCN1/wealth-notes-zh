在“堵漏洞”这件事上，有两大方法，都是在找“漏洞之根”：
一是研究我从哪里来；
二是研究我到哪里去。
而这俩事一般都一起研究，就像研究一个行驶的列车，得研究“两端”，有来有去，列车才算是行驶状态。

人类从“野兽形态”开始升级直到现在，“堵漏洞”这事还是没有破解：

我从哪里来，无论哲学、神学还是科学，都归结成俩字——天性。

我到哪里去，这事大家就开始有分歧了，哲学的最高答案是“入空和至虚”，神学的答案就是“各种极乐世界”，科学暂时没答案，一直在破解各种宇宙元素中。。

有分歧很正常，俗话说一猪生九崽，连母十个样，用高大上的话说就是“我的出身我决定不了，但我能决定走什么路”。

所以，跳出来看的话，哲学、神学、科学都像是叛逆期的孩子，各自都觉得自己最牛逼，互相看对方都觉得傻逼，个别有天赋的能“坐下来好好聊一聊”，互相取长补短。

好了，了解游戏模式、进度、漏洞只是基本面，关键是要玩好游戏，玩爽。

# 玩游戏三大法则

把前人的各种“游戏玩法”总结成三大法则：

+   1、无欲则刚；

玩游戏不要求“通关”，但凡是求通关的都通不了关。

因为人类之上的那个“谁”，给人类游戏设定的规则就是在人类终极目的上，你越想要越得不到，人只有“脑子里没有要或不要这个概念”的时候，才能真的得到。

这个“没有要或不要”的形态叫做“虚无”。

玩虚无在哲学界最高思想的佛道来看，就是“归根”，归到最原始的根子上，也就是“从三到二，再到一，最后到无”。
