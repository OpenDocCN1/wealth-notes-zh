# 谋也是分水平的！

任何谋略，在出招之时，就要想到结果，前文讲的会搞事但是也能收尾。

这东西背后就叫作“算计”，所以谋又称作“计谋”。

比如象棋，是给帅和将玩的，都是线性思维，你攻击我，我攻击你，看谁能把对方将军，但凡搞对抗的招数都是下策。

围棋就不同，你中有我，我中有你，对于棋局、棋路、棋步考验人的计算能力。

# 所以老子第三大特征—反！

把老子反着看，玩“逆道”，就是各种“硬来”的谋略。众人最喜欢的就是这个。因为每个人都有戾气，都有欲望。

嗜欲深者天机浅，欲望大玩不了上等谋略！切记！

所以老子讲：宠辱若惊，贵大患若身。

一般来说，一个人不能宠辱若惊，那么没等对手攻击，自己就把自己瓦解掉了，玩死了……

而攻击对手，最常用的套路就是通过宠辱，在鬼谷子看来，就像是破坏一个坛子，坛子只要有那么一丝丝裂纹，最后就会延展开来，自己就破裂了。

讲到这，一些不善斗的小伙伴就很忧愁了，哎呀三眼，这玩意也太麻烦了，我又不想有什么大志向，有没有简单的？

三眼想了想，有肯定有，老子他那么牛逼，什么东西都可以在道德经里找得到，但是更难！
