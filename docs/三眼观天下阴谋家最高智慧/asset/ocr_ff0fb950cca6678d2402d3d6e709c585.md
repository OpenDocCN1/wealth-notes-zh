# 阴谋家的最高境界（六）天地不仁，结构与象数理占卜

道德经第五章：天地不仁，以万物为刍狗，圣人不仁，以百姓为刍狗。天地之

间，其犹橐龠乎，虚而不屈，动而愈出。多言数穷，不如守中！
这一章有代表性：

+   1、就像是老子思想中“体”与“用”之间的一个“转换器”，就像开车得有离合器。

车子有个根本形态，叫做车子，就像是体，也可以看成“静”；而车子是具有行驶功能的，向前开动，就像是用，也可以看成“动”。驾驶员想让车子“从静生动”的时候，得有个“离合器”来掌控，学驾驶先要学会踩离合。所以这一章很关键。

在第一章里，讲述了有与无的“同出而异名”，有和无是道家看万物的两个基本形态，有与无的互为化生、缠绕的形态就是玄，众妙之门，宇宙间万事万物起源的根本形态，和佛家“缘起性空，性空缘起”一拍即合。

这个一拍即合就成为中国文化几千年来的根子。

往形而上走，在精神境界上的修行，修的是“空无”；往形而下走，落地成器，散布在各个领域的具体应用，都是“空无”而生“万有”，思想、军事、政治、谋略、方术等等，这些都是实修。从上到下一条根脉，所以屹立不倒，文化不断。

而这种根本形态在运动表现的时候，就是第三章的“道冲”，万物都是“冲”出来的，冲出来个“虚而不满”的万有形态，在后面章节中也讲到“大盈若冲”。

这种“冲盈”在庄子思想里，就是“炁吹万物”。

从自然运行去看天地运行，观察出的这种无所不在“功能运行”之道，而后以天道观人道，让人要模仿天地的运行，人就像是个“器”，形而上者谓之道，形而下者谓之器，产生了东方文化独特的“人器”存在形式，道德、谦卑、包容、水善、无为等等。

所以不夸张的说，不了解这条“根脉”，绝大多数文字词汇很难看懂，因为这些词汇不是靠经验主义拼凑出来的“块块”，而是由根脉推演出来的一颗庞大的“树”。
