# 阴谋家的最高境界（二）众妙之门！事物运动的本质形态

读的再多，思考再多，最后还是会被老子都收编了——您可能看事物有多种方法，但最后发现还是老子的思维最简单有效。

如果我们脑存的诸多逻辑是一套套机械，道徳经就是开动机械的万能钥匙。

说明：

三眼强迫症，先聊道，后聊法，人生漫漫着什么急。

聊道的话就很枯燥，诸位最喜欢看法，比如怎么具体分析人、分析事物，具体怎么搞投资，具体谋略等等，三眼一写那些小伙伴们就很高兴，因为感觉直接可以用得上。

但法无定法！没有道的加持，法都是死法（不活），就好像在星球里写了一篇如何观人的方法，其实那都是死法，要是换N个角度一样可以写，理论上讲可以写无限ppt，区别就在于众人的接受角度。

像大多数兵书啊、谋略啊什么的都是讲“死法”，都是死的，不活！那再思考思考，从小到大我们学的绝大多数东西呢？也都是死的…得抓到背后的、共通的底层逻辑（道），死法才能变活法。

读者总是问三眼道德经某某句话咋解读，其实这是错误的，道德经是一个整体系统，单拿出某句话想要解读透彻，就需要把其放到系统里讲才行，所以每次解读提问者的某个具体问题，三眼都要往系统上延伸一下，这样一是麻烦，二是延伸肯定不够，形成断章取义的感觉。

但是如果直接写系统，文言变成白话，相当于把道德经砸碎了，重新组合新的结构展示，整个抽象形态换了个表述（因为观察角度变了），就像是用生物学描述物理学的既视感，读者还要边唬道德经边复原。

比如写的第一篇道德经冰冷智慧，就是按照三眼观察角度去写，几乎不引述原文，以假象、猎杀、养殖等“新结构”去解读，砸碎了再重组三眼累，读者也累。薇芯：yxsk2022

所以比较折中的方法，还是一边翻译道德经原文，一边来看其结构，这样讲的每个结构都能在原文上归位。

可以理解成一个从点（分章解读）到线（章节之间的交涉关联）、再到面（形成立体化系统）的过程。
