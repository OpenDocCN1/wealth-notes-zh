# 您的认知维度在哪？很简单地就能测出来！

问：三眼先生，最近在结构和规则上有些糊涂了。结构是不是说：相同的元素以不同的方式结合就产生了不同的结构，结构侧重点在结合方式。规则是结构的表现形式。

答：是，但可能有些人还是很迷糊。

简单一句话就是：人观察事物形态的方法（思想）。

举个简单的例子：一个简单的四边形，它会呈现出什么样子？

为了找到这个四边形的“真相”，就需要人动用“结构”的力量。
