# 三眼：此二例全错！胡说八道！

要这么讲，老子别讲道德经了，干脆讲个“舌头经”吧，老子那年代词汇量再少，起码舌头这个东西还是有的吧？拿过来搞比喻直接用啊，多方便…

还有那个“水滴石穿”更是啼胡扯，老子讲“水”，就把实际的水往上套，把物理学往哲学上套；

三眼此篇论述的“柔弱”不敢讲是最正确的，道德经是刺激开悟的，没有固定逻辑，但思想维度要比“舌头和水滴”高不止十个层级，一个天上一个地下。

刚柔之道，上到政治、军事、管理；中到投资、创业、创食；下到做人、做事、职场、家庭。皆为顶级思维！柔弱背后讲的是一个“对形态的操控”。

思想，就是观察事物形态的方法！

拿“舌头大法”出去攻城略地试试？嗯…用于猥琐做人还可以…

道德经全篇讲“柔”不少，但讲的都是形态，而不是某某具体事物。

舌头大法怎么个错误咱们后面细聊，先顺着其错误看看世人如何错上加错！

# 鸡贼的众生

只要是个大师，一提到道德经，就开始拿“水滴和舌头”往做人做事上面套：“这做人呀要学会用软、用柔、用弱”云云…

所谓柔弱就是谦虚啊、退让啊、吃亏是福啊等等，然后“以退为进”，强行与“曲则全”那个章节逻辑硬衔接，“进没进”不知道，但可以肯定的是通过大鸡汤给人变傻了…

只要人不缺心眼，都知道一直吃亏不是福，一直玩柔弱那是懦弱…很多人读道德经读歪了，老子不是让人不争，而是争得更轻松，获胜概率最大化！

# 没有极强的攻击性，是看不懂道德经的！
