为何要有法呢？还是因为“自然”太累了，天天仿效它人家很疲倦，仿效者也累得够呛，所以在大类的实践领域就要开法门。

所以，一个人在某个实践领域拼的主要是法。法不那么抽象，但也不是特别具象，刚刚好，上承接道，下指导术。

法字拆开，是水路+行动。

所有生物都要逐水而居，找到“水路”生灵就能生存下去。人
在某个领域就是找到“水路”，就是找到“根本法”。

但还是那句话，没有道的加持，就不知道法是怎么来的，法就是死法。

所以和尚老道下山传法，明眼人一看就知道了：哦，拼的其实是背后的道，佛家的“宇宙”和道家的“自然”互相拼，看谁更接近本源，看谁“给的东西”多！

拼来拼去，嗯…都一样的。然后尧子和长发看了看人间，哎哟，有位孔子，人家定法抢地盘比我们厉害多了，人家才是实践大师啊。所以佛家总想把孔子定位成大乘菩萨给收编了…

好了，不开玩笑，悟道还是需要严肃一点的。我们继续解析老子的做人之法。

# 不自视故明不自见故章，不自伐故有功，弗矜故能长。

这几句解释的人太多，但多数都是字面意思。所有字面直接看都是“死法死术”，也就是死逻辑，人们在里面绕来绕去绕不出来。时间久了，老子的心法就变成术了！变成术就只会照猫画虎、依葫芦画瓢，不会变通。

看字面意思：

# 不自视故明——

“视”在帛书上写作“示”，都一样，意思是人不去反思和观察自我就能开明。

这句不是“正常人思维”，多数人看完一脸懵逼…

但前面讲了，这是“法”的主要牵引逻辑，可以叫做“法根”，我们后面讲，先看下面那几句，比较“正常思维”的。
