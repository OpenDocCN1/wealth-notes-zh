# 1、天机；

# 何谓天机，就是程序的开关，或者可理解为关键代码。

这里得插一嘴，程序员只是个比喻，"道"那套程序不是人造程序所能比拟的，所以三眼以后的比喻会很多，不限于程序。

天机这词来自庄子，嗜欲深者天机浅，天机就是做人做事的那个"关键环节"。

但是这词吧一带个"天"字就显得很虚，咋办呢，给去掉！

# ——机！

这词在古代写作"几"，老子讲"几于道"，就是水顺着道的形态去流动。

此后，人们对于关键环节都用"几"来比喻，比如转机、契机。

但是老子水流这个比喻可能符合古人审美，但不便于现代人理解，咱们再延伸一下。

几，就是门的轴，或者是木头机械的连接处，所以后人加了个"木"字旁，成为"机"。

# 当找到事物的"机点"了，那么摆弄事物就会很容易。

就好比百思不得其解的某个事，让高人去分析，可能就简单一两句话即可点破，因为点到"机"上了！

咱们怎么跟老子一起玩"小机机"呢？

# 老子玩机是很抽象的，不是阴阳就是有无，有个标志性逻辑：

# 想要怎么样——就要先不怎么样——而后才能怎么样。

在这些怎么样又不怎么样的绕来绕去里找到机点。

极度抽象才叫道嘛，由道推导至中间层，就是法，比如做人之几，处世之几，攻城略地之几、治政之几等等。

中间层就是"粗分类"，分成一大块一大块的，按照行业啊、区域啊、门类啊等等。

再往下推导到具象层，就是术，比如谈话之几，又可以细分成怯悠人的技术，隐藏的技术，表演的技术等等，那就非常非常具象了。
