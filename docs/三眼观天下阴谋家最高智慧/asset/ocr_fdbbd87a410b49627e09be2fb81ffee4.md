所以，三眼讲道德经，师承老子的鸡贼心法：不要想着破解道，破解不了。只能去感受道，感受领导给你的“方针策略”。

为了便于理解，三眼举个例子：

为什么破解不了道呢？

道就如同事物没有真相，真相是“无”，如同人们找寻事物的“底层代码”终极代码就是 0 与 1，源自“无”。

小伙伴读到这就懵逼了，心理寻思：那研究道有啥用啊…都是“无”了。

那三眼就问您：平时用软件不？

我们生活中所面对的大大小小的诸多人事物，都是“软件”。

道德经是一本“程序”教材，观察事物就是找到“程序”，无论您是个程序员做编程（修炼自身的思想观察力），还是您是个黑客（攻击与谋略），您都得熟悉“程序”才行啊！

只不过“道”这一程序是天定的，而不像计算机程序是人定的；

后者只能在芯片上发挥作用，前者是“无所不在”——道是最高级的“程序”。

# 您可以用这样理解：

道德经讲的不是“终极代码”为何，因为人类思维承载不了，维度太高；而讲的是“程序如何发生作用”。

顶级思想家玩的都是这个路数，比如佛家的“不可说、不能说、不必说”，佛陀老子手拉手，讲的是一回事。

这些“三不说”的东西，只能去感悟，而表达不出来，只要能表达了，那就歪了。

歪，不是因为表达者是歪的，而是因为众人理解必然会歪。

思想的本质，就是把具象化事物抽象化起来；

看事物，是看事物的形态，而不是表象。

到了抽象层，很难去表述，就要比喻，这在古代叫“象比”之术，也就是修辞学的开端，比如事物的构成比喻成“骨血肉”。

但古人很明白，只要是玩“象比”了，那必然会形成假象，所以假象的“象”字与真相的“相”字绝对不能写成一个字。
