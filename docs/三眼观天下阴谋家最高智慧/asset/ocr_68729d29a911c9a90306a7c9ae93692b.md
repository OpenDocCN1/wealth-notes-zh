但！道是求不道的，求到的“道”都不是道。而在这个一路追求的过程里，推动着人们的智慧得以不断升华，生出了百家文化，生出了中华文明！

# 认知，是接近真相的距离。

真相如同真理是无限远的（没有），但我们离真相更进一步，认知就更高一维。

所以道这个字是“人首”在车子上不断前进。

所以，为何三眼讲“如何学习”要远远比学到了什么更重要？因为学到了什么都是“死”的，只有“如何学习”才是活的。

如何学习=悟道；学到了什么=法或术。当“如何学习”升高了维度，“学到了什么”也会跟随其变化。

这就像是一个班级的诸位同学，老师都是同一个，教授的内容也都一模一样，但是成绩结果差异很大，这源于每个人的“如何学习”不一样，导致最后“学到了什么”也不一样。

# 人与人的差别，就在于找寻事物形态方法的不同。事物的形态都是假的（暂时有限正确），只有方法才是真的，这才是人一生中恒久的财富。

在观察老子之门的过程中，会有一个思维贯穿始终——“反思维”。

老子：反也者，道之动！

这个反可不是仅仅是反向、反对、相反之意，如果这样理解那就成为“死逻辑了”！

三眼用现代词汇把其翻译成“映射”。

# 事物存在的本真并不是正或反，而是正与反的互相映射的过程，万物因动（映射过程）而存在，没有完全静态化的事物，世间只有“活物”，没有“死物”。

也就是说，老子的“反”不是个形容词或名词，而是个代表运动逻辑的词汇。

# “无，名万物之始也；有，名万物之母也”。

# “有无之相生也”。

有要依赖于无，无要依赖于有，他们俩的互相“映射”形成了万物的运动本真，从而成为万物的“父母”，万物都是“映射”出来的。
