# 道德经第二章

故有无相生，前后相难易相成，长短相形，高下相倾，音声相和，前后相随。

不是有和无“相互”生长，相互是引申出来的动词，这是现代话了占文字是单字单意的“模型碰撞”，应该这么念：

+   难和易产生了一个相，就是成。
长和短产生了一个相，就是形。
高和下产生了一个相，就是倾。
音和声产生了一个相，就是和。
前和后产生了一个相，就是随。

前面的自然之象，后面的属于心理的相，人会利用相去看象，这样应用范畴就变广了，而随着应用扩大，概念也需要替换，阴阳-无有。

所以：相也是象，只是玄力的震荡运化范畴变大了，从物理-生理-精神。以相看象，就是用我们“内部的有”再次去捕捉“外部的有”。

而无论是象还是相，都是有和无的变化而已，无震荡生出有。无
