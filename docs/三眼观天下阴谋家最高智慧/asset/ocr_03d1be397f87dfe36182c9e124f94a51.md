# “决定加工什么”要远远比“深度加工”来得重要！

但这里不要思考歪了，不是教人不务正业，不去打磨专业技能；而意思是每天要抽出更多时间思考一下“加工什么”，这是一个劳心血的活，不是一蹴而就的，需要坚持。

脑子劳动要比体力劳动累得多，而劳心更累，且面对事物的风险要大得多。

按照做功大小：心力>脑力>体力。

按劳计算收益，心力付出最多，理应收获最大。
