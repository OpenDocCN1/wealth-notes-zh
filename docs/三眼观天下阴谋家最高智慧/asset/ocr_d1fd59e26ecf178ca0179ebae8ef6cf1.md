# 可致诘，故混而为一。

这是讲“有形观无形”的角度。当我们用感官去量化声、光、触这些现象，极端无限量化是不可得的，而且现象是不可穷尽的，所以有“大音希声”“大象无形”等词汇。声音现象分解到最终是没有“声象”的，也就是没有“量”也就没有“形”，走到尽头后就是“无量”的。

所以为了有限处理，就要混而为一，翻译过来就是以“一”的力而混合去看，找到力的头绪(元)，才能将事物有限化。

一是数理词汇，是在思维逻辑上的用词，与前面的三对应。到了真实世界，是没有一的，所以后来变成叫“混元一气”，其实叫做“混元一力”也可以。

一生二生三，世间的形、象、量是无穷叠化的。所以庄子说“六合之外存而不论”，因为人未能感官接收到的东西是无限的，所以才会敬畏，不信也不否定的说法，这不是和稀泥。

而所谓迷信，不是超感知对象迷不可信，而是感知主体迷信。
