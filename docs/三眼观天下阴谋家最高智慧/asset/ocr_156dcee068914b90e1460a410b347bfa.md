# 高级一点的：哲学观。

比如通过道德经的虚实去看：

例如因为四边形有着外部，所以它的内部就存在；

实线是实的，因为有实，所以才会有空白的虚。

这种形态结构是超越死逻辑的，更超越了没逻辑的情绪，常悟常新。

比如古人就悟出了外圆内方的做人形态。再比如，中庸之道，就是“一边画线一边掌控虚实平衡”的形态。

再比如，道存在是“映射”，当四边形逐步画出来时候，第一笔一定是个“点”，此时内部完全是实的，外部完全是虚的。而慢慢点连成线，线又联合在一起形成了“内与外”，观察虚实的范围也变化了。

对于以上形态的逐渐变化，这一序列“映射过程”，就是老子研究的“道”。

当然，拿四边形只是举例子，道这种东西无处不在，是一种更高维度观察事物形态的方法，只讲述四边形就锁住了道，就会形成“法”。

所以道是什么？

是高维观察事物形态的方法。

高维表现在哪？

就是不停变换维度（变）！用维度带着别人一直跑，不断升维。
