# 刚柔一体

为何道德经总被扭歪？因为功利心！

比如前文讲的歪曲，非要把柔与刚、弱与强给分开，然后来个大比拼，看谁能赢，小家子气….

柔刚、强弱、阴阳这是一体的，分开玩那还是道德经吗？道家子弟已气哭..

在思想观系列里讲过，这人的漏洞就在于必然做出选择，人心就像是个“矢量方向”，符合此方向的就是“得利”，逆着此方向的就是“失利”，非要选择个方向，就是“功利”。无论对于虚的情感，还是实际的名利权位，皆是如此。

人做出选择就要进入假象，这就好比人的双眼只能目视前方，眼前风轻云淡，而身后可能是洪水滔天。

# 人越重利，假象越深！因为人心的“方向”不变通！

动物进化出多种感官，是为了更加完整地判断周围环境；人被赋予了意识(心脑)等于是被赋予了更高维度的感官，而功利之心越强的人，硬生生把意识玩成了小动物低级感官…

一个人只懂得趋利避害，那只能是低级动物。老子为了把低级变成高级，动用意识的能量，反复讲利害相生，最后归于“道”。

道家是专业研究事物形态的，研究形态就要无我，跳出自我没有敌我，无是非无选择无对错，这样方能仿效自然，去观察事物的整体的、本真的形态，而后再入进去搞“寄生”。

硬要把柔与刚(阴与阳)给分裂开来比高低，就像低级小动物，那是绝对看不到事物的本真形态的！
