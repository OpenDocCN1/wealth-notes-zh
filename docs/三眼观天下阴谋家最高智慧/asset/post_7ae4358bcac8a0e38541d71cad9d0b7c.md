此后，无私和自私的辩证逻辑开始普及开来，对这俩词的理解水平产生了智者和愚者的区隔。

大家一提到无私，就会跳出个概念"这家伙喜欢付出"、"舍己为人"等等…三眼负责人的告诉你，那不是无私，那是傻…。

真正的无私，与"善"一样，都是一种高级的生存智慧，很冰冷的逻辑，只是世人喜欢给它们加上温度，或者有的是别有用心而已。

如果一个人故意去无私，或者被人看出来是无私，最后结果一定是成为一个笑话而已，自己翻翻历史书，这事不好讲。

道家智慧从老子这开始，追求的终极形态是"无形"，如果一个人能够做到"无形的无私"，那才是大智慧，只有这样才能达到"获得私利"的目的，无私的目的就是自私，只是手法特别高级而已。

这就好比一个领导的副手故意玩个无私试试？不把无私藏起来，甚至故意去对外展示，玩一个深得民心试试？第二天领导就弄死你………

这知识可以分成两类一天定的和人定的。

人活一辈子出来混，主要是跟对领导，跟着道混，就是学习天定的规则，天定的规则明白那么一丝丝，也够拿去看透人定的东西了。

所以，三眼讲道德经，师承老子的鸡贼心法：不要想着破解道，破解不了。只能去感受道，感受领导给你的“方针策略”。

为了便于理解，三眼举个例子：

为什么破解不了道呢？

道就如同事物没有真相，真相是“无”，如同人们找寻事物的“底层代码”终极代码就是 0 与 1，源自“无”。

小伙伴读到这就懵逼了，心理寻思：那研究道有啥用啊…都是“无”了。

那三眼就问您：平时用软件不？

我们生活中所面对的大大小小的诸多人事物，都是“软件”。

道德经是一本“程序”教材，观察事物就是找到“程序”，无论您是个程序员做编程（修炼自身的思想观察力），还是您是个黑客（攻击与谋略），您都得熟悉“程序”才行啊！

只不过“道”这一程序是天定的，而不像计算机程序是人定的；

后者只能在芯片上发挥作用，前者是“无所不在”——道是最高级的“程序”。

## 您可以用这样理解：

道德经讲的不是“终极代码”为何，因为人类思维承载不了，维度太高；而讲的是“程序如何发生作用”。

顶级思想家玩的都是这个路数，比如佛家的“不可说、不能说、不必说”，佛陀老子手拉手，讲的是一回事。

这些“三不说”的东西，只能去感悟，而表达不出来，只要能表达了，那就歪了。

歪，不是因为表达者是歪的，而是因为众人理解必然会歪。

思想的本质，就是把具象化事物抽象化起来；

看事物，是看事物的形态，而不是表象。

到了抽象层，很难去表述，就要比喻，这在古代叫“象比”之术，也就是修辞学的开端，比如事物的构成比喻成“骨血肉”。

但古人很明白，只要是玩“象比”了，那必然会形成假象，所以假象的“象”字与真相的“相”字绝对不能写成一个字。

比如讲，这个人做人很“软”啊，何谓软？多软算软。每个个人理解都不一样。

三眼总写文字很明白一点，玩表述等于玩自己，那个煞心血啊，有的东西到了抽象层，怎么说都说不出来，而且观众的认知也是分层的，那就不容易表述了。

所以，道德经为何难懂，因为极具抽象！

所以，写道德经，一半是写自己，这是“心性方向”所致，就像前文讲的，道是“装饰品”还是“利器”，跟悟的方向有关。

诸子百家都是师承老子，但是各家派玩法都不一样，因为悟的方向不一样，虽然“本源利器”的套路都差不多，但对利器的雕琢（用法）不一样。

所以咱们悟老子要“适度”，就是在找“本源利器”，诸子百家都用的那个“利器”，这个利器得到手了，就够用了。

思想存在的唯一目的就是“搞吞噬”，诸子百家玩神州几千年了，现代人的“骨血”里面都有“被玩”的痕迹。

在《生存法则一》里讲过，社会存在本质就是一场场猎茶，因为人们被假象与直相区隔，活在假象里就如同行走的羔羊，等待着猎人的击杀；

要看明白“猎杀形态”，不仅要看猎物的形态，更要观察猎人的形态。

诸子百家（不限于，要敢想）都是猎人！

您非要钻牛角尖，跟三眼辩论“道德经在科学制造上的应用方法”，请出门左拐，去找给道德经做“装饰品”的大神，跟他们一起雕花玩去…

以前在文章里讲过，任何思想都是有局限性的，因为用法决定方法。不是老子不牛，而是我们太傻。

老子，无限的接近于他的领导（道）；
我们，无限的接近老子；
认知，就是接近真相的距离。
这就是文化传承！
