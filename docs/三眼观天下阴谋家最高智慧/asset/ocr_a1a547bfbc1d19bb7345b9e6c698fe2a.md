可以善良也可以邪恶。

前者是做平衡；后者是搞破坏。

前者被称为美德；后者被称为力量。

心净本质是对矛盾做平衡；谋略的本质是运用矛盾做破坏。

善良是包容，是成全，是付出；

邪恶是极端，是破坏，是获得。

# 前者是长久生存的智慧；后者是巨大力量的来源。

这是人活着的两种运之法，亦代表着宗教与政治的本质工具。

伟大的人物这两种皆运用自如，世人看其是极端、是神鬼莫测，其实解构到最后，其是对平衡与破坏的两种运用而已。

如果世人皆做平衡，世界将公平完美；

而事实上恰恰相反，事物由不断地破坏而推动发展。

正如最伟大的无私一定包藏着巨大的自私，人们所见诸美好的底层均有一层邪恶，这是事物运动的根本力量。

# 人们相信什么，能量就源自什么；

相信善良是生存最好的伪装；

相信邪恶是会获得巨大力量。

# 而最能够摧毁他们的，就是他们所相信的东西。

世间所信奉的正义可能只是一场表演，而真正的主宰是利用矛盾进行破坏。

（假设）每个人都是恶的，只需要轻轻拨弄，人们就都会放弃正义，自私与丑恶这种结果性形容词汇俱现。

# 文明程度的本质在于人们放弃正义的底线；

越是穷困的地域或底层，和越是接近权力的顶峰，越容易受到生存与生命的威胁，就越容易放弃底线。

# 人们越放弃什么，就越要伪装成为什么。
