# 找寻事物的本源形态要求人的思想运动要不断“退化”，退化到最本源形态。

老子的这种思维在观察社会发展也体现“退化”，就是小国寡民老死不相往来。

而众生因为有着天生的“漏洞”，只要心脑一动，就是在不停“演化”，导致人们想的越多却越笨，人的假象（业障）都是自我制造出来的！

而小 A 制造个假象，小 B 制造个假象，如果制造方法一样，就会有共鸣，他们俩的假象形成共振——这就是“噌”。

噌，就是动物（万物）所发出的声音。

恒有欲也，以观其所噌。

# 无欲、不动、归根、至虚等，往搞“退化”这边走，才能逐渐找寻到事物本真形态—这靠心带方向；

# 而有欲，就是心脑逻辑不停运转，往搞“演化”这边走，就会形成各种“假象共振”，你发出个声音，他发出个声音，形成“音声相合”，时间久了大家都困死在假象之中—这靠脑子运转。

这个共振，这种互相的叫喊，形成了文明。文明就是用假象去不断下定义，还欲想由此得到真相。生物的天性本能就是伪装，人亦如此，人所构成的文明与社会亦是如此。

所以三眼讲文字、道德、规矩等等皆为假象，因为它们都是人定的，只能在其某种领域里共振才能方显作用。

比如三眼过去写文章，是在尽力帮大家搞“退化”，比如讲政治决定经济，而政治与宗教的结构都是源自人本性使然，而人本性再去抠根就能抠到阴阳之动，这才能从假的不断向真的走。

认知，就是接近真相的距离。

人研究问题，越是搞“退化”，越是能接近本源形态。往内层的本源得到了，就 可以和外层的所有人搞共振，大家一起“噌”，因为共振的“底层代码”都通晓了，怎么“编软件”还不可以呢？

再比如三眼经常讲做人（做自己）就要思想冰冷、无是非，因为情绪的本质就是做选择，选择共振上了大家都很开心，共振不上就像架子鼓配上喇嘛念经。只会玩共振那么人就都活在假象之中。

# 要想共振玩得好，先要学会“不共振”。
