# 起源：玄！（不解玄不可能看懂阴谋家）

# 前言

静下心来进阶一下，系统化敲一下道德经！

不敲这一篇，道德经的所有用法都不会通

1、道德经是[重置世界观]的。

世界观就是如何看待世界的存在方式，这是最重要的，世界观决定看待一切，当它重置后，人生风景都会大变样，就是个“自动化”的过程

2、观察世界的两大轨道[心与物]

也就是物理和精神，道家的起点是物理轨道，

1+2=玄！不了解玄，就不可能了解老子，更看不懂道德经

3、道家≠老子

从道家起始-老子，以及老子-我们现代，前者要比后者时段长得多。原始道家是物理玄学，是找寻万千事物背后的运力规律，主要概念叫[阴阳]

4、老子≠阴阳

老子的特点是贵无，不讲阴阳，而讲[无和有]。阴阳属于物理学，无有属于辩证哲学

3+4=升级！从物理学升级到哲学，应用范畴就扩大了，以便应用到社会学。

5、基础和创新

升级就是在 95%的基础上(玄)，加入了 5%的创新(无有)。基础与创新二者缺一不可，道德经才能完整呈现。玄是小初高，无有是大学。

6、物理和模型

玄是物理现象，道是玄运动方式，物理运动用模型表现出来，就是汉字。汉字是动力模型，道家是建模专家。

5+6=以图象模型才能看懂道家

1+2+3+4+5+6=道德经是物理玄学的升级版，须以模型角度切入来诠释这场升级！
