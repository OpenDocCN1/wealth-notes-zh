# 所以，众生（90%）只有好恶，眼中只能看得见自己。

四边形在情绪的观察下，就像是一面镜子，映射出众生的好恶。这种观察法，也可称之为主观，虽然主观二字不是特别恰当，但方便理解。

因为这种观察方法漏洞太大，覆盖面太广，所以我们平时所看到的各种社会交互活动，基本都是在攻击这种低端漏洞。例如品牌、营销、政z、宗教…

再延展一下，比如艺术的形式，众生觉得一个东西“很有艺术感”，甚至被感动的痛哭流涕，其实都是在“观察自己”。

而艺术家们基本都是疯子，偏执、疯狂、精神与思想扭曲，扭曲的越大，越有艺术感。艺术家们就是不断向“四边形”泼洒“颜色”，以颜色来寻求共鸣，而每一次“喷绘”都是一种“扭曲”！

所以顶级的艺术，是超越情绪的，是理性的，那必然是平和、简单、素、淡雅。这也是佛道艺术能登顶世界的原因，背后都是维度在比拼！

# 中级一点的：科学观。

比如数学去解构。此时四边形才真的是“四边形”，本来这就是一个数学几何用语，它有面积、角度、距离等等。此时它在人们眼中呈现出“数学逻辑”。

漏洞是什么？

死逻辑！死逻辑就不具有实用性！

所以人们不满意，要把死逻辑变活，要把这种逻辑套用灵活运用，套在生物学、心理学、经济学、精神学等等领域之中，这时候四边形呈现出生物样式、心理心态等等。

数学是本源，理化等是基础学科，其他多为应用学科。这一系列科学体系，也遵循“道法术”的维度层层落地。

# 本源的维度，决定了道的高度，道的高低决定了法术的有效性。

所以科学要发展，首先要在数学上追求高度，数学上求高度，最终也会进入哲学，哲学求高度会进入神学。神学是什么？就是人类正常思维理解不了的高度。
