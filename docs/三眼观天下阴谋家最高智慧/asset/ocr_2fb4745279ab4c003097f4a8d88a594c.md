# 人无论是打工创业，是个体刨食还是集群行动，是家庭还是家族，都要牢记：我很“大”，都是“我”！

举个典型小例子，虽然比较低级，但是便于理解：“通过我们厂子的勤奋努力，我们如何如何…”

如果有心人去看古书，看古代故事，看官话典籍，都是带着“道”的，只不过很多当官的没有“道”的加持，把“法术”给学死了，不会灵活运用，时不时就来个“有形”，导致官路凄凉！

# 庄子讲“嗜欲深者天机浅”——这人的“寄生能力”与“忘我能力”是成正比的。

好了，本章节呢还剩一点：

曲则全，枉则定，注则盈，敞则新，少则得，多则惑。

是以圣人执一以为天下牧。

其实呢，从“曲-多”这一堆技巧例子，看不看都行，都是“柔弱和不争”一些具体的术，都是具象的。

# 活学活用，只记得“曲”字就好！

老子写东西也不能都抽象啊，上来就是有形无形的，读者思维直接地面到天上承受不了的，需要拿一些众生能够直观感受到的具象事物，逐步引导至抽象层。

我们要看到这些直观感受背后的逻辑才行，拿着逻辑您也可以累加“X则X”。

弱则强，柔则劲，无则有…然后到曲则全…然后继续累加。然后后排跟上，无为而有为，不争而无不争…

看道德经千万别拧偏了，认为每一句话都是“武功秘籍”，都是一个系统，那是小说，不是思想类书籍。

比如很多现代大师抠毛爷爷的矛盾论：哎呀，电子和原子是那么回事吗？毛不懂科学这是瞎说啊！

这些大师都是“腐儒”！

思想，是意识流，具象化的东西（术）都是为了引出抽象化（道法）做服务的，难免有一些具象化的东西经不住细抠，就像拿电子和原子来比喻矛盾。
