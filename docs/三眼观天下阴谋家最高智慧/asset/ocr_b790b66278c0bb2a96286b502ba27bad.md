# 高维:逆着人本性。

所以讲“悟道”是归根，是逆向的。如果人人都沿着人本性运动，只能进入“竞争红海”

人性的运动就像是无数物理粒子向前行驶，随着时间画出无数的轨迹(空间变化)；逆人性运动就像是让时间倒流，站在原地不动，或者往后行驶，从而能看清行驶在“前面”的无数轨迹，从而观察出事物的形态(空间结构)。

低维的竞争都是“空间结构”下的竞争。

最低维的:小动物通过咬死对方,而获得额外能量——直接吞噬；

高维一点:通过咬死竞争对手,从而能更多的占据额外能量——抢地盘：

再高维一点:通过制服竞争对手,从而利用对手帮助自身获取能量——控地盘；

再高维一点:通过竞争博弈产生协同,从而分食能量——共生共赢共建地盘。

嗯。. 这就是权力组织的演化过程。

# 从低维竞争到高维竞争,在人的心智当中,是个低级感官和高级感官谁占优势的过程

越是动用低级感官,人越是情绪占主导,产生出最低级的竞争方法,也就是想要“直接吞噬”,譬如暴力、仇恨、嫉妒、诽谤等等；

越是动用高级感官(意识),人越是理性(无我)占主导,依次产生出高级的生存竞争方法,顶级方法就是柔弱胜刚强。

人活着都要获取外界能量,从而延续自身(生物本性),所以必须​要争、要有所作为,这就必须要运用攻击！

老子是将攻击的维度提升到顶级,不争而争,无为而无不为,竞争锁定在最高维目标:恒久存续。
