# 何谓“外其身”？

# 就是寄生于外物！

外其身就是告诉人们不要“自生”，在佛家讲就是不要“我执”，也就是在观念上不要认为自己主宰自身的命运，能够自己生化和造化自己，而人的存在都是因果缘的交汇结果。

在道家入世观看来，是要与外界达成一种“寄生关系”！

人来到世界，本来就是由万物所化，聚敛精气而成人。没有万物就没有天地，同样也不会有人，人本就是天地万物的一份子。

而人呢因为有欲望，由“自我”吸纳牵附着各种欲，认为“自我”是独立存在的，每个人都认为自己是独一无二的。这是人性之中巨大漏洞！让人们忘却了“本源”。

那么好了，道家推导出这“第三种生存”很高明，因为是仿效自然、趋近自然之道。但这只是“道”的层面推导，如何落实到“法术”呢？

也就是怎么具体做到“寄生”呢？需要什么样的套路和技巧呢？

｜是以圣人执一以为天下牧。

｜古之所谓曲全者，岂虚言哉！诚全归之。
