# 因为充实就是存在的一种形式，相当于把漏洞给堵上了。

但不能静下来，静下来漏洞就出来骚扰人类！所以人类一旦独处就要玩手机玩游戏，或者看美国和岛国大片，就是不能闲着。

所以伴随着物质发展，娱乐将必定统治人类，而“逻辑定义”的传递迭代，驱使科技让娱乐的形态越来越接近意识化，超越文字、影像。

其实“动起来”的时候漏洞也会出来骚扰，这里可以简单理解成“相对不充实”。

比如十个人吃饭，九个聊的很投缘很嗨，剩下那个就“相对不充实”，被那九个挤到漏洞边缘，这时候又开始“自残”，我为什么存在？

# 所以“无视”为啥是最有效攻击？因为给对方挤到漏洞里去了，很痛苦！

在社交上“无视”的攻击力表现还差一些，因为大多数人都会有在意他的人，可以互相之间找寻存在感，来暂时弥补漏洞。

在监狱里对待犯人，无视的杀伤力更强，关小黑屋一个月生不如死，其实对人最残忍的惩罚就是给他扔到封闭空间，隔绝交互独自生存，并断掉希望，小强就一点都不怕，有吃喝就爽歪歪，因为人家只能到“存续”这个维度。

就好比一个男人思想力旷世古今，而能征服其的女人靠思想力是行不通的，有至强必有至弱之处，而能征服他的女人唯有靠这个弱处。

# 为啥年少坎坷的人，尤其是无亲孤儿长大了容易于大事，就算于不成大事，生命力也表现更顽强？

因为从小就开始训练“对抗孤独”，这就是“逼出来的”典型例子。

这种人因为总在漏洞边缘徘徊，所以“最熟悉漏洞”，如果有天赋的自然就变得“更会玩漏洞”，以至于心力与思想力大概率都比常人要高。

玩游戏就是玩漏洞，这个后面讲。

好了，所以思想家之所以是思想家，是因为强大，表现就在于能够“相对不怕漏洞”——对抗孤独的能力相对强悍。
