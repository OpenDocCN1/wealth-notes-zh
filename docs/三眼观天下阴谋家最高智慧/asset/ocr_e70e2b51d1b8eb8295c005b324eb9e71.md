# 人人都“有病”

在看道德经的时候，其核心的“道经”部分字数极少，且虚无缥缈极度抽象。假设一个人不知道老子这个人，更不清楚老子的“地位高”，在看过道德经后很可能觉得这是神经病。

道经开篇即讲：

“道，可道也，非恒道也。名，可名也，非恒名也。无，名万物之始也；有，名万物之母也。”

又要给出道的定义，但又讲说不出来；后面更奇范，“无”与“有”居然成为万物的父母，严重毁灭了科学与哲学的三观！

也就是老子名气大，如果路边一位衣衫褴褛的人跟众人这样讲话，都不用上升到科学与哲学这种维度，大家就直接骂他是神经病了

而其实呢恰恰相反，众人才是神经病！

这人自打生下来，其实所有人都是带病（漏洞）的，我们的心念与脑子一动，就会生出假象（业障），这就是病！而自以为正确（我执）是基础病症。人活一辈子终极目的只有一个：就是为了治好病。佛与道都是大夫。

病根：失魂；

治疗：找魂！

而有病的人正常反应是高喊着“我没病”，就像喝多了才会一个劲说自己没喝多…只有痛苦出现之时，人们才会意识到自己可能是得病了。

所以什么人喜欢悟道？

都是思想痛苦之人！也就是感受到自身思想肯定是得病了，为了解决病态痛苦，逼迫着他们去悟道。不要伤心，这才是人的高级天赋！这就是慧根，在以往文章中讲过，这是慧根要破穷生长，过程当然痛苦万分！

上天给每个人都装上了漏洞，并由漏洞产生痛苦而逼迫人们去领悟上天，给你个病，但只能到我这治疗，这个买卖不是很淳朴呀…天地不仁，以万物为刍狗。
