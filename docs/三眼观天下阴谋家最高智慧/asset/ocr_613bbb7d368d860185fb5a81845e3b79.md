# 而观察事物，就是观察其从无到有、从有到无这个“映射过程”，这才是事物本真。

这就好比观察一个人的思想，要观察其“如何起心动念——念头消失又起心——新的念头又生成”这一循环往复的过程，人的念头从无到有、有又还无（还无可能是返璞归真按原路返回，也可能打死了之前的念头另起一个头）才是人思想的本真。

这个过程就好像风箱、又像是蝴蝶煽动翅膀等等一样，一开一关一合一张，这个“节奏”就是事物在运动，“节奏”才是事物本身。

所以：

处理人或事物=处理这一合一张的运动形态。

将欲翕之，必固张之。将欲弱之，必固强之。将欲去之，必固与之。将欲夺之，必固予之。是谓微明。

这句里的细处逻辑我们以后再聊，我们看其整体，讲的就是：

要想摆弄事物，首先就要洞察事物；而事物的本质是运动，那就要通过一个“反”去搞“映射”，“映射”一动，事物的运动本真即可显现；

这就好比拿“冷”去试探“热”，冷与热的“映射”才是事物的本真。

而在洞察了这一过程之后，要找到摆弄事物的关键点——微明。

这个微明其实并不是一个“点”，我们现代人从小接受西方思维都习惯了，逻辑很容易限死，这个微明是一个“链接处”，其实这么讲也不是很恰当，但总比“点”字要生动。

如果把事物运动比喻成窗户一开一关，那么这个“链接处”就像是窗户的“合页”，古人对此有个比喻——几（后来写作机）。

只要掌控它（机点），即可掌控事物如何运动。

这就如同现代人总说“我们要掌握好节奏啊”，这句话可追溯到几千年前的道家，但其实大多数人根本就不清楚“节奏”是個啥。

人们每天都讲着道，但却不知道其是个啥！百姓日用而不知，故君子之道鲜矣！
