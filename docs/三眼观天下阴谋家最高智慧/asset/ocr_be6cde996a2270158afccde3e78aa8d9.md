# 为何佛道为上乘|明白 “人怎么定义规则”，就能破解各种规则！

此篇主旨：
知道怎么定义规则，就能破解规则；
研究 “如何定义规则” 就是在研究人本身。
人类社会是由人主观上定义出来的，各种 “边界” 各种 “规则”；

佛道之法高明之处在于：研究 “人如何去下定义这一过程”。
心法枯燥，但很重要，没有心法，怎么学刀法呢？
在上一篇里有句话，用来开篇此文：

“佛法可能是最高思想！科学远远比佛学维度低！”

一定会有无数喷子喷三眼，尤其是现在西学东渐，被 “科学” 严重洗脑的孩子，因为这句话打破了他们的赖以生存的、唯一能用来装逼的三观。

上篇讲，人都活在某一思想所塑造的 “边界”，在里面搞出 “游戏规则” 来 “养殖” 里面的众生。

“边界” 就像个扣着的 “锅盖”，本来大家伙在里面折腾很开心，以为世界就那么大，当你把 “锅盖” 掀开了，活在里面的人 “见了光”，顿时失去安全感。

# 很久很久以前，西方有个著名傻逼喷 “东方无哲学”！这个扣在 “锅盖” 里的人名字叫黑格尔。

喷子的特点：用 “锅盖” 里的认知来判定外面的大千世界，还自以为没毛病。

# 蛤蟆与宇宙

这世界最迂62通的事情，莫过于 “蛤蟆在井里研究宇宙”！

我们都是蛤蟆，蛤蟆有两种：
一种是知道自己是傻逼，去感悟宇宙；
另一种是觉得自己牛逼，用 “井观” 去判定宇宙。
