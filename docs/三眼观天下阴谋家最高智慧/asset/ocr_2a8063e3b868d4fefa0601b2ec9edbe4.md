又讲：

# 端末未见，人莫能知；天地神明，与物推移；变动无常，因敌转化；不为事先，动而枢随。

啪啪啪一堆字，其实就是前文讲的“周期”和“微明”

“不为事先，动而枢随”，就是先不要去干扰事物形态，而是先观察它的运动形态，等待“微明”一出，而后根据它的”轨迹”再玩“夺之与之”那一套(枢随)。

又讲：

# 故日：莫不贪强，鲜能守微，若能守微，乃保其生。圣人存之，动应事机。

大白话就是人性习惯就是趋利避害、就强避弱，很少有能观察形态的，请大家不要着了“强弱”(空间结构下)的假象，而是要观察事物强弱转化的”微明”(时间结构上)，然后开始玩弄形态平衡(动应事机)；这样才能获取长久存续(乃保其生)。

又讲：

# 能柔能刚，其国弥光：能弱能强，其国弥彰：纯柔纯弱，其国必削：纯刚纯强，其国必亡。

不要觉得一讲治国就高大上，做人做事和治国道理一样，就像音乐不分国界，思想也不分等级。

简单讲就是要“刚柔并济”

刚柔并济可不是一会扮演柔，一会扮演刚，那是精神病。

”济”是水流动起来(形态)，刚柔并济就是使得刚与柔流动的形态平衡，平衡才是恒久存续之道。

此处插一嘴：很多小伙伴内心矛盾之处，在于总是“神魔交战”，做人想要刚吧又狠不下心，做人要柔吧又觉得这样很懦弱，自己把自己玩懵逼，后台好多这种问题，这里就解答了。

做人要跳出自我，无我的观察形态，心智与思维立马升维度，不会再去想着扮演刚还是柔，而是很自然而然的刚柔并济(玩平衡)，根本不需要去苦哈哈的搞扮演，太假啦。

做人要“寄生”，形态怎么变人就怎么变，不是人去选择刚或柔，而是形态决定选择。
