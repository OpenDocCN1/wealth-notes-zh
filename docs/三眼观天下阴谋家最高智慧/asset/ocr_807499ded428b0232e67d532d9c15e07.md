# 为何越孤独越强大？思想力就是对抗孤独的能力！

有这么一场游戏，动物不知道，石头不知道，天地草木也都不知道，只有 人知道，这场游戏叫做“对抗孤独”，这是一个人类专属的游戏。

本篇主旨：

游戏模式；
游戏进度；
游戏漏洞；
游戏玩法。

关键要点：

从“存续”到“存在”；
存在的方法是“下定义”，文明就是逻辑定义传递；
文字是最最低级的思想传递形式；
人类定义外界的两种维度：空间与时间；
哲学三大问题均为了“堵漏洞”；
充实是堵漏洞的基本形式，娱乐必将统治人类；
无视是最有效的攻击；
成功多为“逼出来”，因其游走在漏洞边缘；
玩好游戏三大法则：无欲则刚；超越生死；佛魔皆法。
何为无为而无不为，不争而无不争；
人之苦痛皆苟且，如何冷静、畏惧；
道德与慈悲均为谎略；
给予选择，是定规则、设边界、搞养殖的基本手法。

在《思想观系列》前几篇里有三句话：

1、知道人类是“残次品”才能开悟智慧；
2、没有漏洞就没有游戏，人类社会游戏的游戏必附于人类的巨大漏洞之上；
