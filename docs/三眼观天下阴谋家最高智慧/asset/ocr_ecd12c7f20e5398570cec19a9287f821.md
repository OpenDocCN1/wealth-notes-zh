# 什么叫谋略？

一种是顺道，本质就是伪装；

另一种就是逆道，就是“硬来的方法”。

怎么硬来呢？举个简单例子：

得道者昌，失道者亡。

第二种谋略，就是让对手“失道”啊！此处可以延伸 100 万字。

打败对手的不是你，而是他自己。

攻击一座城，一定是城池内部先瓦解掉。

“硬来”是跟第一种谋略比，它就显得很硬，因为它“逆道”；

但事实上要比您想象的的还要软，因为这是个技术活，老子就是技术活鼻祖，只是都藏在其文字的最深处罢了！

以前讲过一个例子，很典型：

比如皇帝的利器是赏罚，而赏罚之本在于罚，这东西只要守住了，王位能一直拥有。

有的大臣就很鸡贼啊，跟皇帝说：赏你来办，大家都喜欢你，罚这种操蛋事我来办，我替你挨骂。

时间久了，大家就不怕皇帝了，只怕大臣，紧紧团结在大臣身边，整个人心水势发生 180 度大转弯。水势一成，谁也扭转不了命运。

但是呢，大臣这么玩，大概率也会给自己玩死。人用什么招数上得台面，也会被人用什么招给赶下去。自己给自己捧多高，到时候摔的就有多疼。
