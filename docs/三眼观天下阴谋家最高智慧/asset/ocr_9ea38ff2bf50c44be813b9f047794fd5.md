# 玄之又玄

易经老子庄子叫三玄之学，什么是玄学？

下个通俗简单定义：

玄学就是要利用[无形]维度处理[有形]维度的方法之学。

就好比老中医望闻问切，是在无形维度做观察，而不是拍CT片子那种，在无形维度找寻事物存在的方式，把患者给“无形解剖”噢。

这不是个玄幻的东西，而是唯物科学，道家也是唯物的，区别在于“唯无形物也就是看事物时候是[先看无形---再以无形观有形]，那个唯物正好是倒过来。

道家是“唯无”的物理学！

例如道家演化出的中医（医学）、道德（社会学）、兵法(军事科学)、纵横捭阖(心理学)等等，首先都是物理学，其次才是社会应用：

中医讲[气]的运行，用物理学语境来说就好比能量运行，整套下来就是运用无形能量的物理模型，用以观察人体的科学。

道德是讲社会学上的人际交互形式，是先把人看成物理形态，阴阳虚实刚柔之类，而后在物理形态的交互之中，选择以更加有利的形态去存续(用阴类形态)，这个叫做[利用]，不是个贬义词；很会利用就是高级生存智慧，就叫做[善]；会善就能获得优质存续叫[德]，德就是得，而道属于背后的物理运行方法，德是用它来推导的，所以连起来叫做[道——德]。

孙子兵法讲[形势]，这也是个物理运动。形就是物理上有形可见的部分，而势是物理形态背后的动态势能，它是以玄力运动呈现的，所以叫势力。这都是通过[玄]而推导出来的。
