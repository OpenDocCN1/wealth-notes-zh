# 道

天长，地久。

天地之所以能长且久者，以其不自生也，故能长生。

# 法

# 外其身

不自视故明，不自见故章，不自伐故有功，不自矜故能长。夫唯不争，故莫能与之争。

# 术

# 退其身

世则全，柱则定，浅则盈，敬则亡。少则得，多则惑。

这两章结合在一起，就是做人“道法术”的完整结构体现。

“退其身”是具体的操作技巧，主要代表逻辑就是“曲则全”。

世人往往只记得曲则全，这仁字火的要命，但很少有人能“上下打通”，只有通过“寄生”这个中介观念加持，能打通才是“活法活术”。

术就是技巧。

为何要有术呢？因为人无论做什么，不可能每次都要“有-无-有”这样绕一圈啊，那不累死人了！

所以要推导出一些具体实用技巧“工具箱”，到了具体运用之时翻出来，但是术也是有规则的，一个“曲则全”引领术规，在其后可派生出多种术。

但是没有道的加持，不悟道（有-无-有循环），术就是无源之水，是死术死技巧。

正如人们所追求的“洞察事物本质”的能力，其实这种能力平时感觉不出来作用的，因为它不会起到立竿见影的效果，但有道即可推法，有法即可推术，这样在术的具体使用上就会灵活，因为术都能“归位”了！

人要归根（思想），术要归位（运用）！

“外其身”就是心法，就是法门，需要它去引领术，主要代表逻辑就是“不自视”。
