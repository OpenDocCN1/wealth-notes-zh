见（xian）后来被改成“是”，章被改成“彰”（会意字，站在多姿多彩的的面前，古代文字少没办法，用现代话可以翻译成“装 x”）。

这就形成了两句话。

一个讲的是“人只要不自我显现才会异彩纷呈”，现代大白话就是人不主动装 x 才能真正装 x；话糙理不糙，喜欢严肃的小伙伴出门左拐。

另一个讲的是“人只要不自以为是（正确），才能明辨是非”（彰此处为“明显显著”之意）。

这两句话其实一个意思，现代话就是“低调才能高调”。

# 不自伐故有功——

伐，自我夸耀的意思。此句表面意思也很好理解，人不主动居功（通过自我赞扬和夸耀而抢功劳）反而才会得到功劳。

# 弗矜故能长——

弗，不的意思；矜，自尊的意思。此句后来被改成“不自矜，故长”。

自矜，往小了说就是自尊心（缩小了），往大了说就是傲慢（放大了）。今天的语言看自尊和傲慢有点区别，这是因为各种文化合流的结果，文字乱成一团，其实这俩词起心动念的过程是一样的，只是量级不一样，古人搞文字都是一步步推出来的。

每个文字、字意都是一个系统旗下的，系统融合就要混乱，比如佛也讲法，道也讲法，法家儒家也讲法，西方佬也讲法（法律），，就一个法字乱成一锅粥。所以学习文字其实也要归根（归于一个系统）。

矜（jin）还有个读音是（qin），是没有箭头的矛，一般用于特殊场合“造气势”用的。翻译成大白话就是“自抬身价”。这就与自尊和傲慢的起心动念过程合上了。

但是呢，这与“自伐”（自我夸耀）有区别：矜的这种“自抬身价”自己都信以为真了…

言归正传不外延了，继续看此句，意思也很好理解，人只要不自己尊自己，不傲慢，才能存续长久。
