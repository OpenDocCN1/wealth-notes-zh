# 第七章：天长地久。天地所以能长且久者，以其不自生，故能长生。是以圣人后其身而身先，外其身而身存。非以其无私邪！故能成其私。

大白话翻译：

这人要想活的恒久，一直存续下去而"长生"，就要跟随领导步伐，模仿和顺应天地之道；

天地之道什么样子？它们并不是为了自己生存而生存着，所以才能"长生"，圣人要模仿天地之道，想要保全自身（身存），就要像天地一样"无私"，只有这样才能达成活下去这个"自私"的目标。

此后，无私和自私的辩证逻辑开始普及开来，对这俩词的理解水平产生了智者和愚者的区隔。

大家一提到无私，就会跳出个概念"这家伙喜欢付出"、"舍己为人"等等…三眼负责人的告诉你，那不是无私，那是傻…。

真正的无私，与"善"一样，都是一种高级的生存智慧，很冰冷的逻辑，只是世人喜欢给它们加上温度，或者有的是别有用心而已。

如果一个人故意去无私，或者被人看出来是无私，最后结果一定是成为一个笑话而已，自己翻翻历史书，这事不好讲。

道家智慧从老子这开始，追求的终极形态是"无形"，如果一个人能够做到"无形的无私"，那才是大智慧，只有这样才能达到"获得私利"的目的，无私的目的就是自私，只是手法特别高级而已。

这就好比一个领导的副手故意玩个无私试试？不把无私藏起来，甚至故意去对外展示，玩一个深得民心试试？第二天领导就弄死你………

这知识可以分成两类一天定的和人定的。

人活一辈子出来混，主要是跟对领导，跟着道混，就是学习天定的规则，天定的规则明白那么一丝丝，也够拿去看透人定的东西了。
