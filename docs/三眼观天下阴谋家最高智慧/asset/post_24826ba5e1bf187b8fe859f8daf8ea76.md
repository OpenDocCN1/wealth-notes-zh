人类能当上“万物灵长”因为有思想；
生命的目的存续，思想的目的就是存在，一字之差将游戏升级了，变了大花样。

升级了什么呢？

游戏升级前呢，自然界众生只思考活着的事，也就是“存续”的事。
哪能刨食能吸收能量，自然众生就往哪里跑，说白了就是吃喝拉撒；

水是万物之源，是能量交换最基本载体，所以在“存续”这事上有个规律就是“逐水而居”，人在“野兽形态”时候也一样，所有小动物都找水源，吃饱了喝足了，然后开始仰望星空。

游戏升级后呢，也就是人类从“野兽形态”升级到“有思想形态”，就开始思考活着之后（死亡）的事，也就是“存在”的事：

# 游戏到了“存在”维度，就形成哲学三大问题：

# 我是谁？我从哪里来？我到哪里去？

咱们一个个研究！

# 我是谁？

因为“野兽升级”了！开始研究“存在”了！

# 存在就要“下定义”！

先给自己下定义，比如什么万物灵长了，我叫人类了…

# 存在就是自我，自我就是存在，这俩东西互相依存，失去自我就没有存在，设有存在就没有自我。

这东西在佛家叫我执，科学心理学上叫自我，大众文化叫自私，一句话就是人类以自我为原点，向外思考。

这是“升级”后的本性，是优点也是漏洞。

然后呢，以自我为中心再去给宇宙万物下定义！

水里游的、天上飞的、会动的、不会动的，连十几光年外的星星都不放过，反正眼耳鼻舌身这些感官能感受到的，统统给下定义；

这还没完，还能上升到“意”，也就是对抽象的事物也下定义，比如上下左右、对和错等。

见到啥就给人家下定义，文明就这么诞生了！

插播一下：

# 所以文明是啥？就是逻辑定义的传递，或者叫思想的传递。

文就是纹，人心交织人的交互，纹就是人类社会的纹理结构；日月为明，代表物理世界的结构。

大家伙纷纷想办法搞传递，有的画符号（象形文字），有的用声音（语音文字），文字是传递的最基本模式，其实很低级的，因为低级所以适用面最广，最被大家伙熟悉；

# 能纸面记录下来传授的东西，最低级，可以比作“刀法”；

# 能够通过示范传递的东西，属于高级，可以比作“用法”。

# 但最高级的传递就是“不传递”，可以比作“心法”。

禅宗讲“不可说，不能说，不必说”就是这个意思，最牛逼最有效的思想传递，是超越文字形式的，至极形态就是意识传递，也就是“悟”。

所以佛教玩“业绩”方法也是迭代的，论佛理最低级，然后感佛法，也就是把佛祖走过的路自己去走一遍，这是中级，发展到禅宗了就到了“悟”，这是最高级的。

但是禅宗这句话最逗逼的在于，“不必说”也得靠“说出来”。

言归正传：

# 人类下定义主要有俩维度，一个叫空间，一个叫时间；

# 空间代表静态观——以自我为原点，向外产生“两端”；

# 时间代表动态观——动态观是对静态观的弥补。

像是非好坏对错等，这都属于空间，跟上下左右一个判断逻辑，只不过上下左右得用实际的尺子测量，而是非对错这种抽象的东西得用“抽象的尺子”去测量，但逻辑一样；

人类刚“野兽升级”时候很低能，看东西都是静态的，但后来发现，好能变成坏，上能变成下，对能变成错…

一时间有点懵逼，咋办呢，就给这种东西又下定义，叫做“变化”。

思想又升级了！

比如我们看群经之首的《易经》，讲的就是一个变化，不变的东西（不易）、变化的东西（变易）、以及找到变化的关键点（简易）。

自打有了动态观，人类一下子牛逼了不止一大步，思想开始大爆发，什么变易啊，什么我思故我在啊什么的，一堆思想大师就出现了，都是以这个为基本思考面。

好了，给万事万物下定义之后，人类觉得自己非常牛逼，但随之很尴尬！

为啥呢？

因为人类在给万事万物下定义时候，突然反思到：

哎哟，我这在给万事万物下定义，但我也属干万事万物啊，那么肯定有个“谁”在定义我！

或者说，有个“谁”让我这么玩！

人类突然觉得自己也是被定义的、被玩的，感觉好傻B…在人类之上，有个东西，它给人类抠出“存在”二字，然后游戏开始了。

所以，下两个哲学问题就开始了！

# 我从哪里来？我到哪里去？

这俩问题可以算成是一个问题，提出问题就是解决问题，人类提出这俩问题都是为了解决一个问题：

# 如何堵上“存在”这一漏洞！

不然人天天拿“为什么活着”来“自残”。堵上漏洞了，人就能松口气，堵不上，人类就会一直觉得自己是“被玩”的，很傻B。

平时搞社交、出门刨食、吃喝拉撒、玩雌雄合体等等很充实，就不寻思漏洞，为什么呢？
