# SKIN IN THE GAME
Hidden Asymmetries in Daily Life
NASSIM NICHOLAS TALEB

![](bbox=[0.28, 0.58, 0.78, 0.62])

过去这一个來月，英文世界出了兩本非常重要的書。一本是納西姆·塔勒布的 Skin in the Game，我建議把書名譯為《傚關》（或者《利益傚關》）。另一本是史蒂芬·平克的 Enlightenment Now，我將其譯為《啟蒙此時》。

塔勒布和平克，我們中國讀者都非常熟悉。塔勒布寫過《黑天鵝》、《反脆弱》等書，平克寫過《人性中的善良天使》等書。二人都可以稱得上是當世之俊杰，他們的思想，我們應該好好學習。

一般人可能會告訴你，這兩位都是大師啊！但我想說的是，這兩位的思想，存在根本性的矛盾。塔勒布是個哲學家，塔勒布眼裡的平克，大約是個脫離現實的知識分子。不過平克對塔勒布的態度倒還是比較禮貌的，畢竟平克是個……知識分子。

據我理解，這個根本矛盾就是，平克認為作為一個現代人，我應該對所有人都好。而塔勒布認為那是不可能的，我應該只對跟我“利益傚關”的人好。

這句話說起來特別簡單，但是從此出發，現代社會生活的方方面面，小到個人大到國家，就能推導出來各種主流的、充滿沖突的理念。

在我看來這兩個人的思想都有道理——當然，平克主要是啟蒙運動前人思想的總結，而塔勒布更多的是帶有他個人的風格。

我認為不讀平克，你就不是一個真正的現代人。不讀塔勒布，你就不是一個真正的實在人。平克引導你仰望星空，塔勒布提醒你腳踏實地。平克是時髦的學院派，塔勒布是深刻的思想家。

所有這些矛盾，說的都是，怎麼在現代社會生存。

平克的書將會給你帶來勇氣。塔勒布的書則會讓你充滿底氣。

塔勒布的出發點，就是你得有利害傚關，你說的話才值得我聽。我們專欄有一位讀者建議把“Skin in the Game”翻譯成“生死與共”，我覺得不至於。我們去醫院看病，只要醫生跟我們的健康有利害傚關就行，不需要他跟我們生死與共。

不負責任地胡亂搞、有利害傚關、和生死與共，這三種態度的區別，可以說構成塔勒布這本書思想的一個主線。

塔勒布這些思想既是價值觀也是方法論。咱們舉個例子。比如你開了一家小型的航空公司，你總共也沒有幾架飛機。現在有一個降低運營成本的方法。大的航空公司一般都是“僱傭”飛行員，要給飛行員提供養老之類的各種福利，淡季也得養着他們，而且不能輕易裁員。但是你可以選擇不正式僱傭，而是臨時跟飛行員簽合同。有活兒就讓他們來干，沒活兒你也沒負擔，大家自由合作。

那你說這種方法有什麼弊端呢？對飛行員來說，又是哪個方法更好呢？這個故事，正好處在傳統和現代的邊緣。答案不是顯然的。
