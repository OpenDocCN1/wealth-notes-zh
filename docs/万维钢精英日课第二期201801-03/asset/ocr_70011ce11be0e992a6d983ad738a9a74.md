# Top1.未来简史 / 尤瓦尔·赫拉利

![](bbox=[0.22, 0.74, 0.78, 0.86])

*《未来简史》，不图谋预见未来，只妥善清理现状。@李文彪

*整个人对世界的看法被刷新了，以至于很长一段时间都在考虑今后怎么做个神人。跟着作者回顾历史展望未来，感觉整个人都变得厚重了。@边走边瞧

*超越人类智慧的人工智能、主动的基因改造技术，更高级的经济增长，会把人类变成什么样？同样是人人关心的大问题，经赫拉利一分析，就连老司机的三观，都能被刷新一遍。

有多少历史学家对当前生物学的进展信手拈来？有多少宗教学家了解截bg到2016年，现代科学对人的“意识”的理解？有多少经济学家能同时用历史、心理和动物学的理论解释明白，让大规模人群合作，和小团队互动，有什么本质的区别？非得有一位像赫拉利这样通才式的学者，才能把这一切综合起来，让我们对现代世界、对历史和未来，有点深入的见识。@万维钢

# Top2.为什么佛学是真的 / 罗伯特·赖特

![](bbox=[0.2, 0.00138, 0.8, 0.0017800000000000001])
