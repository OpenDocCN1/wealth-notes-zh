# 1

首先，互联网行业是不是吃青春饭？

这个问法其实不准确。

这就相当于问，医药行业会不会受到互联网冲击？

其实不应该这么问。而应该问医药行业里创造价值环节和传递价值环节分别会受到什么影响？

真正受到互联网冲击的是传递价值环节。

做医药的工厂还是那些工厂，但因为有了互联网，卖药的方式会有很大的改变。

同样的道理，说互联网行业是吃青春饭的，也不准确的。

没有一个行业是吃青春饭的，而是这个行业里有一些职业是吃青春饭的。

在互联网行业，有工程师，也有人力资源、销售、PR、市场等等各种职业。

我们说互联网行业吃青春饭，通常是说工程师这个职业吃青春饭。
