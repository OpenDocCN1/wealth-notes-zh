# 二年级 第28课 《像科学家一样看》 《泉泉的语文课》

郑浩然
《泉泉的语文课》春季班 二年级

我观察的是玫瑰花。

用放大放大再放大的方法，观察到它的花瓣是粉红色，花瓣底部渐渐变黄，外层的花瓣要大，内层花瓣逐渐变小；它是圆形的花瓣，一边有点卷卷的，边上有些小的缺口。花柄是长长的，接近花的柄上有许多小刺，越往下刺越大，又尖又硬，我用手碰了一下马上尖叫起来，太有杀伤力了！
花蕊包在花瓣中看不到，我用手拨开花瓣，看到了金黄色的花蕊。叶子是绿色的，也长有尖刺，有的叶片由3个小叶片组成，有的 有5个小叶片，还有4个的，大多是5个的。

我还用了夸小夸小再夸小的方法，观察到它闻起来是有点樱片的味道，它的花瓣摸起来很光滑。背面更光滑。我用舌头舔了舔，觉得很粗糙、牙齿咬了咬，很难吃。

2013-05-07 20:43:31

# 少年君哥-文文老师点评：

郑浩然同学将句子补写得很完整。你对玫瑰花观察得很仔细，观察到玫瑰花“花瓣是粉红色，花瓣底部渐渐变黄，外层的花瓣要大，内层花瓣逐渐变小；它是圆形的花瓣，一边有点卷卷的，边上有些小的缺口。”“用手拨开花瓣，看到了金黄色的花蕊”的描述很不错！玫瑰花闻起来“樱片的味道”很独特，希望你以后在生活中继续用上这种方法，仔细观察周围的事物，这样你会收获更多的知识。
