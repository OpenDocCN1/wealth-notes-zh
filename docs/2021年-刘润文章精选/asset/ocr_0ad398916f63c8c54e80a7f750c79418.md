# 水量代表能力水平

如何判断一个员工是“难堪大用”，还是值得委以重任，快速晋升？

到底怎么来判断这件事儿，我自己有三个标准。

这三个标准，你可以在脑海里勾勒出一个“瓶子”的样子。然后用 3 种不同的视角来审视这个“瓶子”。

第一，是看这个“瓶子”里面现在装了多少“水量”，这个“瓶子”之中所盛的“水量”，代表他的能力水平。

“水量”的高低特别重要，如果特别低，说明此人没有能力积累，没有办法解决实际问题。
