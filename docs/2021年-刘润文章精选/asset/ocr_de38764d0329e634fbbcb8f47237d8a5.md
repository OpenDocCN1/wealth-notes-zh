# 少年得到-小亭老师点评：

仕壮同学用了两个动词来描写你着急的样子，基本完成了作业的要求。但是“穿”和“背”这两个词本身不能表达“着急”的含义。学习是一个长 Malays的时间的过程，刚开始上课没有完全学会方法是一个很正常的现象。妈妈陪着孩子看两遍视频，这个做法是明智非常有帮助。对于孩子放松积蓄不是很旺盛的情况下，建议你暂时和孩子可以做一些相关小游戏，像泉灵老师在课上和庆轩玩的游戏一样。比如在《小老鼠喝妈妈》这个童谣中先找出动词，然后察它是用力的还是不用的力的。动作持续的时间是长约还是短的，用什么方法表达动词的真正含义。这样就可以很好地帮助孩子积累词汇了。不要担心，慢慢来，静待花开~
