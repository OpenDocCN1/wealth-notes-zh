# 培训、咨询

培训和咨询，是润米咨询的“现金牛”业务，但也是在 2020 年受到影响最直接的业务。

有几乎 3 个月的时间，因为疫情，我们无法开展任何线下活动。

这段时间，Fiona 和我反思了培训和咨询业务的脆弱性。一种以前想不到的脆弱性。

很快，我们一起开发了在网上的直播讲课业务，并制定了疫情期间的优惠价格。

这个改变，给公司带来了一些收入上的帮助，但并不非常可观。

但它的意义在于，我们验证了自己的快速响应能力。这是我们非常希望看到的。

然后，我们认识到，线下业务的脆弱性，源自于自己主动可控业务的比率过低。

于是，花了半年的时间，启动了黑马营，和阿仁加速器的两个项目。

感谢新合作伙伴。
