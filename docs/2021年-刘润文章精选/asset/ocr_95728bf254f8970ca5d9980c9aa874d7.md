# 三个错误

从 2001 年到现在，我管人也管了 20 年，面对过无数管理者和被管理者。

但在汇报和沟通这件事上，我发现还是有许多人做不好。

不论是基层，还是高层，沟通的时候，总会犯这三个错误。

# 第一个错误是：夸自己，藏问题。

很多人一沟通，一汇报，就觉得到终于到展现自我的时候了。

所以不停夸自己的成绩，说自己的辛苦，想让所有人都知道自己的不容易。

# 夸自己，是必要的。但是点到为止。

否则，会让人产生一种感觉，这个人做了太多自我包装，说话这样，做事可能就更是这样。

而且，夸自己的背后，经常是想藏问题。说了很多好听的，难听的真问题就不会暴露出来了。这样就不会显得我无能。
