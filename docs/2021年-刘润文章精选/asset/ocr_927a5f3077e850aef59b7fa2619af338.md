# 在一家大公司工作，你会明白如何通过“体系”、“流程”、“组织”取得业绩，而不单单是依靠个人的能力。

在大公司工作，经验值会不断提升，逐渐明白规则，限制，盈利模式，职业生涯，优秀人才标准等等一些非常有用的东西。

# 那为什么之前在大公司的，最好也去一次小公司呢？

因为你可能错把平台的能力，当成自己的能力，以为自己就值这个价钱。

去一家小公司，会真正知道自己有几斤几两。

# 更重要的是，去一家小公司，也能有更加全面的成长。

你会知道人际关系也许并不简单，也会懂得与道德不良的人互利共存。

你会知道业务目标多么现实无情，为了生存根本没有讨价还价的余地。

你会知道商业世界多么真实残酷，办公室免费的纯净水不是理所当然。

在一家小公司里面，你不再是一个专业的螺丝钉，而会成长出三头六臂。
