# 人口变化

# 是城市投资的关键

聊完 2019 年宏观经济，香帅还和我分享了她另一个研究的领域：城市化。

她有一个基本的判断：城市人口变化，是发展的潜力，是投资的关键。

经济发展的本质是什么？——是人的活动。

那么，人的活动怎样会更有效率？——人的聚集、城市化。

城市就是为了人的聚集所形成的一套相应的基础设施。是我们每天上下班的公路，是每天车水马龙的公交地铁，是我们拿着手机连着的互联网……

这一切能帮助人们连接聚集的东西，形成了城市。

人越多，交互也就越多，演化的更复杂，进化的更快。

而中国的城市化率，可能比我们想象的还要高。因为我国的城市化率是按照行政区划来划分的，目前大概在 59% 左右的水平。

但如果按照人口的实际聚集，城市化的程度，会比统计数据的显示还要高。
