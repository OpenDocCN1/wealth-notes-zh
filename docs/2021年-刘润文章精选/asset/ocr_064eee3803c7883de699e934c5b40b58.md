# 1

很多人都经历过这样的阶段：

工资低、压力大；上升通道窄，前途看不清；老板恶心，上班没劲。经常有掀桌子不干了的冲动，但又不知道去哪里更好。

如果你正在经历这种感受，那你其实并不孤单。

有调查数据显示：

95%的职场人都对外面的新职位感兴趣，但只有 22%的人真正付诸了行动。

也就是说，有七成多的人都停留在“工作不爽想换”的阶段，每天心中纠结、内耗，但是实际一动不动。
