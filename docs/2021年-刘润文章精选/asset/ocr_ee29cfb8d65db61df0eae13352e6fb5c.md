# 人与人之间的竞争，其实是手握海量优质数据的洞察。

比如数据。数据是非常非常重要的资产。

用户留下的数据，是他们的真实想法和行为，仔细分析数据，能发现真实的用户。

比如，有人想在淘宝上做生意。

一开始总是不得要领。后来，他研究了淘宝用户的用户行为数据，发现有一项，极有价值：

淘宝上，用户购买最多的商品，集中在 100-200 元之间。仔细想想，很有道理。

因为在网上买东西，多少还是不放心。

买 1000，2000 元的东西，还是觉得有风险。

而 100，200 元的东西，还行。刚刚好是心理账户能承担的范围。

所以，后来他改变了策略，在淘宝卖 200 元以内的高端产品。

生意就好起来了。

这是一个很简单很常见的例子。
