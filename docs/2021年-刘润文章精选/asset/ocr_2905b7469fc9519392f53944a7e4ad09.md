# 最怕一有困难就重新开始

# 无法积累势能

我经常说，商业的“价值模型”，可以简单分为创造价值和传递价值两个环节。

创造价值阶段是一个势能积累的过程，企业基于组织创新能力，把产品做出curve 相当于把千钧之石推上万仞之山。

这是一个非常艰苦的过程，目的是获得一个巨大的势能。

传递价值阶段则是在万仞之山上将千钧之石一把推下去，在下降过程中，重力势能转化为动能，获得尽可能深远的用户覆盖。

企业基于创新能力，把产品做出curve 就相当于把千钧之石推上万仞之山，这个过程非常艰苦，是为了获得尽可能大的势能。

其实，这个理论运用到个人也一样。在工作中经常会遇见各种各样的困难，但是，遇见困难是正常的。
