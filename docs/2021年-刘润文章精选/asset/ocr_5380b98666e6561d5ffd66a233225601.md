# 1，从业绩（结果）的角度看，这半年做到（没做到）了什么？

这是最关键的衡量指标。这一点，不要欺骗自己。

# 2，从方法角度的看，这半年做对（做错）了什么？

也许做到了一些成绩，但是做事的方法，是不是合理的？符合价值观的？

正确的动作，但暂时没有效果；和错误的动作，但带来了效果。前者更重要。而且重要得多。

做对的，继续保持，推广。

做错的，立马叫停，纠正。
