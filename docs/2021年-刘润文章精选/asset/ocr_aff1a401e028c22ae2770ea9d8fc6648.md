# 第二，向别人学习。

优秀的组织和个人，不只是自己琢磨，也会看看别人的好做法。

定期去参访，去见人，去聊，常常会有一些特别好的启发。

在一个开放的环境里面，成长会更快。

# 第三，正式的培训。

这些培训，有利于培养自己的职业化程度。

这些职业的习惯，也让工作更有效率。

所以，降维执行，也要靠一个系统来保证。

# 要有执行的“意愿”，也要有执行的“能力”。

你可以看看自己的组织，也可以看看自己，是责权利的系统出了问题，还是执行的能能力出了问题。
