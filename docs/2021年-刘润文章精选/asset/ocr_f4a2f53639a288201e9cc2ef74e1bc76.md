# 首先，如果你意识到你必将面临这个问题，就要每一天都保持 day0 的心态。

每一天，都是第 0 天。

在心态上，抛弃走到今天为止你获得的所有成就、既得利益、社会地位和光环。

把自己当成刚刚大学毕业，每天都像是从 0 开始。

就算你过去年入百万，现在只能挣 10 万了，你要接受这件事儿，并且理解这件事儿有它对应的价值。

大家之所以有“35 岁”的焦虑感，是因为大家总认为自己一定要越挣越多。

但是，社会上没有一套机制来保证年龄跟成就之间是线性关系。

前面跑得快，后面跑得慢，直到后面跑得快的人超过你，这几乎是一定会发生的。

# 所以保持 day0 心态，很重要。

# 第二，你要不断学习、不断尝试、不断更新。

你要相信在你的一生中会有若干个工作生命周期。

过去一辈子是干一个工作、一个行业。
