# 为什么有些商家，在疫情的冲击下措手不及、甚至溃不成军，而有些商家却能从容应对、甚至逆势上涨？

# 因为私域流量。

理解私域流量，我们需要先了解“流量”。

# 获得流量，是有成本的。而流量越来越贵是必然趋势，为什么？

开一家线下实体店，地段租金就是支付的流量的成本。每天进店的人流，就是你用租金，向各个商圈购买的一次性流量。

开一家线上淘宝店，支付给平台的佣金，买广告位的花费，这些都是你的流量成本。
