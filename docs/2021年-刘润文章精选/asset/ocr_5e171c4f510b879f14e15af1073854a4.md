# 接受 60 分的事

作为一名商业顾问，我经常和很多创业者聊天。

有一次，一名创业者和我说，他正在做一个产品，特别好，一定会大受欢迎。

我很有兴趣地问：哦？那能不能给我看一下？

结果他说：对不起。不行。我正在憋一个大招。等产品正式上线了，再给你看。你一定会喜欢的！

听他这么说完，我先是为他祝福，然后心里一凉，默默为他捏了把汗。
