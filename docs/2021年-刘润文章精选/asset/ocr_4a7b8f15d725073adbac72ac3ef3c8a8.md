# 比如：基于 LBS 系统分配订单。

LBS（Location Based Services），基于位置的服务。

什么意思？

当品牌总部从各个渠道获得分散的流量后，可以通过一系列运营动作，获得新的订单。

然后，用 LBS 的方式分配给各个门店。

用户离谁近，就进谁的门店。

注意，这一部分的订单，之前可能是完全没有的，是总部通过自己的努力得到的新订单。

对门店来说，这是全新的增量。

因此，对于线下门店来说，总部更多是赋能，而不是争利。
