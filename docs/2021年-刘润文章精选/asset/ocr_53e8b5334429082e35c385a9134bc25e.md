从触点，到需求，到信任。

# 3

第三种顺序是：信任，需求，触点。

按这个顺序决策，消费者会去哪里买东西呢？

在线下，你会去你朋友推荐的地方。而在线上，你会去“社交电商”。

你有个多年的朋友，是开玉石珠宝店的。你对他很了解，你知道，他是个值得信任的人。这就是信任。

有一天，你想给女朋友买个玉镯子。这就是需求。

你突然想到，我这个朋友，不就是卖玉镯的吗？玉石市场鱼龙混杂，外行很容易被骗。但我这个朋友，不会以次充好来骗我。于是你就去店里找他购买。这就是触点。

因为“信任”，所以一旦有了“需求”，就会主动找到他这个“触点”。

线上的“社交电商”也是这个逻辑。

在线上卖东西，核心就是建立高信任的人设。
