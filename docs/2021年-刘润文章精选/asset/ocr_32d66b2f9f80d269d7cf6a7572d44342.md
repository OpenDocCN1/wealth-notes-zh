# 每一次受到启发的时候，我都会随手把零碎的想法写下来。

过一段时间，随着积累的案例越来越多，这些想法越来越完善，就会集结成一个完整的逻辑。

我就会把这些逻辑录下来，请我的小伙伴们，或者我亲自写成一篇结构清晰的文章，发在公众号。

等公众号的文章积累到一定程度，一些主题的文章集结起来，就可以出版成一本书。

# 每一次写作，都是对输入知识的思考和总结。

# 除了写，你还要练习说。

# 说，就是讲给别人听。
