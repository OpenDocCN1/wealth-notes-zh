# 二年级 第28课 《像科学家一样看》

# 《果灵的语文课》

郑洁然
《果灵的语文课》名师课 二年级

我观察的是玫瑰花。

用放大放大再放大的方法，观察到它的花瓣是粉红色，花瓣底部渐渐变黄，外层的花瓣要大，内层花瓣逐渐变小；它是圆形的花瓣，一边有点卷着的，边上有些小的缺口。花柄是长长的，接近花的柄上有许多小刺，越往下刺越大，又尖又硬，我用手碰了一下马上尖叫起来，太有余侦力了！

花蕊包在花瓣中看不到，我用手拨开花瓣，看到了金黄色的花蕊。叶子是绿色的，也长有尖刺，有的叶片由3个小叶片组成，有的由5个小叶片，还有4个的，大多数是5个的。

我还用了变小变小再变小的方法，观察到它闻起来是有点薯片的味道，它的花瓣摸起来很光滑，背面更光滑。我用舌头舔了舔，觉得很粗糙，牙齿咬了咬，很难吃。 2019-05-07 20:43:31

少年猩猩·文文老师点评：

郑洁然同学将句子补全得很完整。你对玫瑰花观察得很仔细，观察到玫瑰花“花瓣是粉红色，花瓣底部渐渐变黄，外层的花瓣要大，内层花瓣逐渐变小；它是圆形的花瓣，一边有点卷着的，边上有些小的缺口”，“用手拨开花瓣，看到了金黄色的花蕊”的特写，很不错！玫瑰花闻出“薯片的味道”很独特，希望你以后在生活中继续用上这种方法，仔细观察周围的事物，这样你会收获更多的知识。
