# 还有一种错误，是只思考不行动。

不断推演，不断计算，不断归因，沉浸在思考的喜悦和快感里面。

当思考的过程结束，以为问题就解决了，于是懒得动手。

但是这样的方法，往往更加糟糕。思考和现实之间，还有一条巨大的鸿沟，

只有行动了才能验证自己的思考。

给自己画了一个闭环，就不愿意出来了。

这样的人，我们会说他陷入“思考茧房”。

# 知而不行，等于空想。

# 行而不知，等于蛮干。

这就是我们面对问题时最常见的两个错误。

这些错误如此普遍，普遍到我们根本没有察觉。

所以我常说，我们要拥有上帝视角，能瞬间把自己拉到空中俯瞰全局。又

要有操盘手技能，瞬间俯冲到地面死磕细节。

# 我们要知道“为什么”，也要知道“怎么办”。
