# 从周期角度看

# 2019 年货币财政都比较宽松

如果说前两个问题，是让香帅带着我们站在高处，重新理解金融的话，那么后两个问题，则是真的更贴近“财富”。

我想，这也是众多读者更加关心的话题。我请香帅分享对 2019 年宏观经济的真知灼见，也请她分享一些投资建议，让我们更有机会成为“财富的朋友”。

香帅告诉我，从经济增长的角度看，中国经济的大趋势是没有改变的。2018 年，2019 年都会是增长。

但为什么我们会感觉这两年经济不是很好，即使在盛夏时节，也觉寒风凛冽？

其实这是一个经济周期的拐点。宏观经济和信贷政策紧密相连，2018 年过的很苦，某种程度是信贷周期的反应，是前一个周期的下行。

但同时，宏观经济又和政治周期紧密相连，尤其是在我们国家。
