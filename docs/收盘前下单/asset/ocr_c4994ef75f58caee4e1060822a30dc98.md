# 收盤前下單，月薪多 50 萬 ¥

可以再複習一下短期移動平均線與中期移動平均線之間的關聯。

+   5. 關卡

一般來說，股價出現 500 日圓、1,000 日圓、10,000 日圓等整數就稱作整數關卡（見圖表 4-9）。

投資人對這些關卡特別敏感。當價格遇到這個關卡時會怎麼變動？股價每遇到整數關卡，買賣就會特別活躍，大概會有這兩種情況：股價一遇到關卡就容易反

# 圖表 4-9 整數關卡

+   1. 股價如果是 2～3 位數
10 日圓、50 日圓、100 日圓、500 日圓……。

+   2. 股價如果是 4 位數
1,000 日圓、3,000 日圓、5,000 日圓……。

+   3. 股價如果是 5 位數
10,000 日圓、30,000 日圓……。
