# 開戶，是初學者
最後才要做的事

第一，開證券戶是最後才要做的事！

新冠肺炎導致股票市場混亂，股價大幅滑落。很多人在這時候覺得機不可失，想趁機大賺一筆，沒多想的開了證券戶，把錢匯進去就開始交易。

一開始的虧損，會讓你發憤圖強學習相關知識，也不算是壞事。據說在股市交易的世界中，90% 以上的人都是輸家，是非常無情的世界。因為想賺錢而投入股市並非壞事，但若因此使自己的資產化為烏有，賠上時間和金錢，那就得不償失了。

重要的是，自己有沒有能力從今天的股價判斷未來會往上或往下，以及會往上多少、往下多少。如果這兩件事都弄不懂，最好還是不要投入真正的錢做交易。
