# 圖表 3-8 移動平均線、布林通道、MACD 是什麼？

| 名詞 | 說明 |
| :--- | :--- |
| 移動平均線 | 過去一段時間裡的平均成交價格。 |
| 布林通道 | 是由均線和標準差組成的指標，總共有 3 條線：中線、上線、下線。<br>通常是用中線加減 2 個標準差成上下線，而由上下線構成的區域就是布林通道，可用來判斷買賣訊號、進出場時機。 |
| MACD | 是使用長期與短期的移動平均線兩者交叉狀態，來判斷股價的趨勢方向，屬於中長期趨勢指標。 |
