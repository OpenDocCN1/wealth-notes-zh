# 陈昌文微商赚钱第（26）招：打造公司赚钱法

??我的赚钱核心逻辑，就是打造公司。

我这个人，从来不喜欢自己做 事，就比如，刚开始，我要订一个披萨来吃，因为我饿了，早上吃的少。

我就叫一个小伙子过来，说，你去订几个披萨，让员工们吃一吃。

我自己是不做事的，都是交给别人做。

我也在网络上搞视频，搞音频，但都是交给别人做。

我在网络上搞软文，也是交给别人去发。

我这个人，虽然自己也写软文，而且写非常多的软文，这是因为我喜欢，而且，写软文也赚钱。

但我从来不自己做事情。我喜欢团队，喜欢拥有团队。团队才是赚钱的核心。

一个人，赚的钱始终是有限的。

几十个人，几百个人的团队才能赚大钱。

只有分工合作，比如，招聘的人专门做招聘，她才能做的非常细致。

比如，一个员工要辞退，不应该由老板亲自去辞退，因为浪费时间嘛，让人事去就行了。

刘邦，毛伟人，之所以纵横天下，无人能及，就是他们会用人，会打造团队。

项羽不行， 他身边没什么得力的人，就算有，也被他气跑了。

刘备那么牛逼，就是因为会用人，手下人才济济。
