# 陈昌文赚钱秘籍

陈昌文做微商赚钱第（1）招：在网络上搞培训赚钱。

网络上有很多人搞培训，我搞的是微商赚钱培训，因为很多人做微商，市场非常大，传统行业不景气，于是，做微商的人更多了。

而很多人不知道如何做微商。

于是，我就搞了微商培训。

我是怎么搞的？

首先，打造一个 QQ 空间、一个微信、一个公众号、一个微博。

上面更新的都是培训的服务内容，培训的价格比如，初级课程 1999，中级课程 3999，高级课程 6999 元。

这些培训内容如何写？

培训广告如何打？我都是每天收集 50 个广告案例，把这些广告案例读懂了，内化成自己的功夫，然后发到自己的 QQ 空间，微信朋友圈、公众号，微博上就行了。

流量渠道呢？

首先，是自媒体，比如，今日头条，一点资讯，搜狐自媒体，其次是贴吧、QQ 部落、然后，我还组织了人拍视频，搞音頻。

做网络培训生意，主要是坚持，你前面三个月肯定是没钱赚的。

或者说很难赚钱。但只要坚持，关注你的人多了，就有人买你的单子，你也就能养活自己了。

我坚持了几年，收了几千，上万的会员，也赚了数百万。

我的目标是组织 20 个人，跟着我继续搞网络培训赚钱，一年看能不能弄到 1 个亿的收入。

如果你想成为网络培训的高手，你必须每天搞 5 万字原创出来。很多兄弟太懒，一天只能搞两篇文章，2000 字，这样的人是没前途的。
