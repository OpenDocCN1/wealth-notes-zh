# 第88课：威性数据的套路

# 数字概念越是具体,消费者信任感越强

一诺老师发现，列举数字、数据最容易获得消费者的信任，

“数证法”的说服力有目共睹。

一诺老师曾经问弟子：大家知道国内市场上卖得最好的奶粉是哪一种吗？是伊利。

![](bbox=[0.13, 0.412, 0.88, 0.552])

一诺老师研究发现，在 2003 年之前，伊利奶粉无论是销售量、销售收入，还是市场份额与产品毛利，都曾经处于弱势地位，婴幼儿奶粉的销售收入连前五名都排不上。

从 2005 年起,伊利奶粉异军突起,销售量跃升为行业第一，

2008 年后受三聚氰胺事件的影响，销量大幅下滑。

到了 2011 年,虽然国产奶粉的市场份额总体上敌不过洋奶粉,但以单一品牌来衡量,伊利又重新占据了行业销量第一的
