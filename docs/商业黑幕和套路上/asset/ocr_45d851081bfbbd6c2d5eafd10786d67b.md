# 一诺老师案例：新舒肤佳，新老产品无品质区别

舒肤佳推出新款的香皂产品，同期的广告中多次提及“新舒肤佳”“变异细菌”等字眼。

一些消费者猜测，新产品可能增加了其他科技成分，质量肯定比旧款的好一些：“可能新产品是专门针对变异细菌的吧。”

促销人员也不断推荐说：“这旧产品卖得不错，除菌的。”

至于新舒肤佳和以前的产品有什么区别，促销人员一概不知。
