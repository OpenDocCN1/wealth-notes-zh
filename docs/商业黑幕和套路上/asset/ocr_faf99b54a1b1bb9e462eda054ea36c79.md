# 文字游戏：因为误会而结合,因为了解而分开

一诺老师认为：文字也是一种“大杀器”，运用得好，效果丝毫不亚于视觉形象。中国的文字博大精深，别看广告上、合同上写的几个字，用好了、用足了，奥妙雷同房地产的楼书。

很多楼书上都要标明：“本广告仅供参考，广告中确定的部分，可以作为合同附件。”你知道什么是“确定的部分”吗？一诺老师只能告诉你，“每平方米 7500 元~11000 元”“均价 8650 元/平方米”“绿化率 35 以上”之类的信息，肯定是不确定的部分。至于哪些内容是“确定的部分”一诺老师不知道，你要是有北大中文系教授的水平，说不定能找到。
