# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

问题：是首先满足客户，还是首先满足企业和自己？

以前有一个理论，企业存在的目的在于为消费者创价值，

消费者在享受便利的同时回馈企业，两者互惠互利，相互依存。

听起来非常美好，这也是我们企业家非常想做的。

![](bbox=[0.135, 0.307, 0.882, 0.447])

是的，买卖永远不可能一心，博弈和斗争无时不在。

一诺老师无数次跟亲传弟子说：消费者少掏一点钱，企业

的利润就损失一点，还可能亏损倒闭。企业要多赚钱、获得更大的发展，就要从消费者身上多挤压一点。

一诺老师提醒你：不想当元帅的士兵不是好士兵，不想多赚钱的企业也不是好企业。在向消费者多卖货、卖出更高的价钱上，任何企业家、企业家都是不含糊的。

营销是“在可获利的基础上满足消费者需求”，企业工作的重心是“建立可获利的客户关系”。虽然他也提“双赢”讲和消费者长期共生，但前提还是企业的获利。
