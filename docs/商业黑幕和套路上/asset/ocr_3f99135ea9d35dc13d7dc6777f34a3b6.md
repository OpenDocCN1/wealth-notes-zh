# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

一诺老师十年前就说：推销的时代已经过去了。

说老实话，推销本身就是不地道的，人家待得好好的，你偏要向他推销，烦不烦？

所以一诺老师要教大家营销，什么是真正的营销？

![](bbox=[0.136, 0.306, 0.883, 0.447])

那营销是怎么做的呢？

一诺老师认为：方法不是“推”，而是“拉”，是“哄”！

没错，你要想方设法把消费者引诱过来，哄他们开心，然后让他们心甘情愿地、舒舒服服地把钱送到我们手里。

哄，是我们做企业的高级阶段。

因为它讲文明、讲礼貌，靠的是你情我愿，还让人高兴。

但是——客户为什么自愿把钱给我们呢？

洗洗睡吧，别熬夜哈，下堂课继续跟着一诺老师学习“客户为什么能心甘情愿地把钱给我们”。
