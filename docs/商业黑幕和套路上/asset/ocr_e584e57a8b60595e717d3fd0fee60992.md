# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

一诺老师曾经无数次在课程中讲过一个案例：

北京某著名的眼科医院旁边，有一家销售少儿眼镜的专卖店。为了跟医院内部配眼镜的部门竞争，专卖店将眼镜的价格下调到 30 元一副。

他们错误的以为，这下子就会门庭若市。但结果，来看的客户确实不少，但大多询问了半天，就是不买。老板抱怨说：
“这么低的价格，消费者就是不识货，现在的生意真不好做。”

![](bbox=[0.135, 0.435, 0.885, 0.575])

因为中国人的传统观念就是：便宜没好货！

一诺老师的问题是：如果你帮这家眼镜店做咨询，你会建议这个老板怎么做？

有弟子说，一诺老师啊，我们换包装！把店面装修得漂亮一点，给眼镜设计几种时尚、高档的盒子，不怕客户认为质量不好；玄虚一点的，给眼镜造个新概念，比如“润眼眼镜”“纳米眼镜”“哈佛眼镜”，再配一张充满科学原理的产品说明书。

这是全宇宙最深.最深的套路！能打得同行满地找牙！跪在地上唱征服！
