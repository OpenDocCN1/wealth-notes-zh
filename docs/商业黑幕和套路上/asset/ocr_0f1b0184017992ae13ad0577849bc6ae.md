# 产品包装一定要大到不可思议

产品包装要精美，或用蓝、银灰等冷色显示高科技、高价值，或取红黄、橙等暖色传递亲和力和喜庆感，关键是包装一定要大。其实这些都是涉及到消费者心理学，有机会成为一诺老师的亲传弟子，你就能学到更多的、更实战的干货。

一诺老师举例：原来一瓶装 180 粒，外加一个小木块样子的小纸盒，卖 240 元，绝对不如把它分成三瓶，一瓶 60 粒，做成个宽宽扁扁的大盒子，总价 480 元，不信你试试。
