# 如何给产品定高价

以前的做法，是先计算一下成本和费用，再在这个基础上加上一个利润率，就成了价格。如果东西俏一点，利润率就定得高一点。比如开餐馆的，在每道菜的食材和加工成本上加两倍的毛利，一道菜的价格就出来了。

从你看了一诺老师这本书，你就不能这么干了。

再把定价和成本扯在一起，这生意就没法做了。
