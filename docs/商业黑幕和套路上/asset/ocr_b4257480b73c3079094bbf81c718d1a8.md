# 改头换面,将产品和服务升级换代进行到底

老是学别人的，总有侵权、盗版的嫌疑，说不定什么时候惹上了官司，不划算。

一诺老师认为，最安全、最体面的办法，还是自己盗自己的版，稍加改头换面就出来个新产品，任何人也奈何不得。

企业对自己的产品最熟悉，随便加点配料，改个剂型，增加一点小功能，还不是分分钟的事情？这样做还有额外的好处，丰富了自己的产品线，正所谓是肥水不流外人田。
