# 第69课：精确化的套路

# 精确说起来很复杂,其实做起来很简单

咱们传统的东西，吃的好，用的好，搞管理也好，做学问也好，都是估摸着来的，不精确；西方人来了不仅在工业产品的生产上是标准化、数量化的，连做饭做菜用多少料、放多少盐，都是精确称出来的。

麦当劳、肯德基更是把自己的食品配方和营养成分，精细到每一克、每一卡，还向消费者公布出来。

对比之下，中国人的观点变了：精确的就是好的！

咱们做企业的，要顺应消费者的想法。消费者喜欢精确，咱们就给他提供精确的东西，尽量将自己的产品精确化。
