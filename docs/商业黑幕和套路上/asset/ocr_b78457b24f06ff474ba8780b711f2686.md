# 第44课：吓倒客户的杀手钩

# 只要吓不死,就往死里吓

喇叭式：广泛宣传各种症状表现，让消费者“对号入座”。

义诊式:以免费检测验证严重后果,将消费者“请君入瓮”。

一诺老师 18 年前就讲：“喇叭式”是为了充分引起消费者的注意，在强大的广告声势之下，你想不注意、不自行对号入座是不行的；“义诊式”是为了彻底把消费者搞定,有科技手段,又眼见为实，你不能不相信。

![](bbox=[0.137, 0.499, 0.882, 0.638])

一诺老师经常在课程中说：像这后面一招，在消费者看不到媒体广告时，作用更显重要——以免费、关心你的方式，将消费者吸引过来，就像街上的算命先生，招手把你叫住，然后神秘兮兮地盯着你看半天，说你在半年之内有血光之灾。你一旦被吓住，就不由得不往他的“瓮”里钻，走也走不掉。
