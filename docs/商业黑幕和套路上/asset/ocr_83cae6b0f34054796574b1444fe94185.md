# 世界10大品牌在红海市场的生存之道

西方的营销学教材里，对如何给产品定高价，讲了一个“撇油”定价法怎么“撇油”？这是一个形象的说法，就是指把蛋糕最上面的一层奶酪——精华，先撇下来，自己吃掉。

在产品定价里，指的就是在新产品投放市场的初期，在竞争对手的同类产品还没有出来之前，利用消费者求新、好奇的心理，以高价销售，在短期内获得尽可能多的利润。

![](bbox=[0.135, 0.498, 0.885, 0.638])

在竞争对手增多后，再逐步地降低价格。西方的营销专家说话也直接，“撇油”就“撇油”，不遮遮掩。

不过，撇了油之后怎么降价，要讲技巧。

降价事大，一定要谨慎而为。
