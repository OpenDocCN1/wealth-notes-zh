# 第87课：产品分分钟创新的套路

# 在新上下功夫,以满足人们喜新厌旧的本性

一诺老师研究发现，你们迫切需要一样商品，一旦获得之后，你们又迫切需要另外一种。营销大师的工作就是说服消费者选择那些使用寿命最短的产品。

当你们省吃俭用，终于买下梦想的汽车，也就是我在上次促销中推出的那种，我却早已让它过时了。我总是比你们时尚，更超前，而且总让你们望尘莫及。

营销大师需要捕捉消费者的注意力，从情感上吸引他到商品上来，帮助营造关于拥有它生活将会被如何提升的个人幻想。

![](bbox=[0.135, 0.585, 0.88, 0.72])

所谓“新”，并不就是“好”。横向营销思维首先不是在“好”上下工夫，而是在“新”上下工夫。“看人看衣裳”，看产品就得看“包装”。有了好的包装，才能让人相信你的产品是好的。
