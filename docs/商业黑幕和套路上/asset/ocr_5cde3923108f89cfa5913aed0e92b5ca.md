# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

里模糊地提出了 1:1:1 的比例，消费者容易误解为这样的比例说的是油内含量，可是油外包装上却写着油里三种酸的比例是 0.27:1:1。不过，字体非常小，不容易辨认。

金龙鱼生产商嘉里粮油广告部有关负责人表示：“除了食用油，人们日常摄入的肉类也含油，我们是说把两者加起来达到 1:1:1 的均衡比例。我们的产品一直都标明比例是 0.27:1:1，并没有欺骗消费者，而且我们会继续推广！”

![](bbox=[0.13, 0.435, 0.88, 0.575])

什么是“1:1:1”，它只是金龙鱼宣传的一个健康饮食观点，金龙鱼并没有说自己的油是“1:1:1”。虽然这件事经北京个别媒体一闹腾，让金龙鱼的形象受到了一些影响，但影响仅限于北京地区的一部分消费者。借助于这个创意，金龙鱼被全国更多的消费者所认识，成为食用油的头块牌子。
