# 第 45 课：恐吓+利诱=销量

# 不得罪人的征服术,天堂地狱推拉法

在一诺老师的指导下，好记星转战武汉，整整投了 150 个整版；整版广告的密集投放，把武汉人打蒙了。几个月后，好记星全国市场迅速铺开，一个又一个的整版广告每到一处就迅速炸开一个市场。好记星每到一个地方，就让一个地方的父母乖乖掏钱。可能一诺老师自己都没有想到，采用保健品式手法叫卖的好记星，竟然如此轻易地撕破了千千万万家长的口袋。

保健品营销的技巧在于，先恐吓，然后利诱。10 多年企业顾问的一诺老师显然深谙此道。
