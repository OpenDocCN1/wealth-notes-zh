# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

弄两个新概念，让你觉得新奇，似懂非懂，人家的目的就达到了。这跟企业做产品是一个道理。

一诺老师提醒大家，有个词要记牢，就是“差异化”，要达到张口就来的地步。学会了这个词，你离营销大师就不远了。

![](bbox=[0.13, 0.31, 0.88, 0.45])

顾名思义，所谓差异化，就是要让自己的产品体现出与别人的不同。

为什么要不同？

因为相同的产品实在太多了，甚至连概念都是相同的，大家一拥而上，刚开始消费者还有点新鲜，随着跟风的产品越来越多，很快就都卖不动了。

如果你不琢磨点不同的东西，消费者根本不会注意你。

一诺老师研究发现：人们天生只对新鲜的事物感兴趣，很多时候你说自己多么好，消费者懒得听，但你说自己与别人有什么不同，留给消费者的印象就特别清晰。
