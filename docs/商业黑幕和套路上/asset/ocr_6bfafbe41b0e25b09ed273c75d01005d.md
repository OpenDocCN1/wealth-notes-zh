# 想要做慈善,手里先有钱

很多人问我说：“请问一诺老师，商业的真相是什么？”

在一诺老师回答你这个问题之前，我们先想一个问题：如果

你已经成功了，你已经有钱了，你已经不需要亲自收钱、数钱、发钱的时候，你就可以装逼地说：“啊，其实我不喜欢钱，我对钱没有概念……” （赶紧捂脸）

可问题是，很多中小企业家还在生死线上苦苦地挣扎着，说不好听的连饭都吃不饱，还装什么清高？
