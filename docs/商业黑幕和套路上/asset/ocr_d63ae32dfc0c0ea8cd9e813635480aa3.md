# 一诺老师独创的广告三重保护伞

+   1、绝大部分真实情况，消费者是不知道的。
2、即使有的消费者知道了，大部分是不愿意告诉别人的。
3、即使消费者告诉别人，大部分是传不远的。

以前有句俗话，“好事不出门，坏事传千里”，为什么到了现在，消费者的抱怨反而传不远呢？一个原因是，以前那种街坊邻居、乡里乡亲的居住方式少了，隔壁的人你都不认识，你传给谁听呢？说给同事朋友听，一般的事开不了那口。
