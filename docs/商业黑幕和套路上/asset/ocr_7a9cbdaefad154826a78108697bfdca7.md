# 案例：宝洁为什么敢于承诺？

一诺老师曾经问国内的化妆品、洗发水的老板，为什么我们不能像宝洁那样承诺？消费者肯定更买账。老板们说：怕工商局罚，而且中央台也不给播。

可是，宝洁的片子很多都违反广告法，中央电视台照样播，地方台就更别提了。原因很简单：宝洁养活了 80%的地方台。
