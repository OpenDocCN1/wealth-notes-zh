# 第05课：赚钱就是对消费者负责

企业赚得钱越多,消费者的利益越大

那么，企业家的职责是什么呢？

一诺老师送你一句话，就是“想方设法地卖货”！

两句就是“尽可能地卖货，卖更多的货”！

如果要一诺老师加一个说明的话，那就是要“尽可能地卖出最高的价，获得总利润的最大化。”
