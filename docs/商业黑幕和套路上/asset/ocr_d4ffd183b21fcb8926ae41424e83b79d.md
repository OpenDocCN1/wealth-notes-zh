# 全球最黑的《商业黑幕和套路 1》容易走火入魔！某猜 18 禁读此书！

占到化妆品零售价格的 5%~8%，“但国际知名化妆品的品牌宣传费用是 很高的，有的高达 20%，这些都会转嫁到零售价格上”。

这样的例子比比皆是。一瓶 SK-II “神仙水”在 中国卖 560 元，据行业内人士讲生产成本不足 8 元；电视里卖 1000 多元的好记星，出厂价只有一两百元；路易·威登一两万元一个的包包，生产成本不过百八十元……对这样的生产成本，根据什么标准来确定产品的利润率呢？100%？200%？300%？都不行！

![](bbox=[0.13, 0.44, 0.88, 0.58])

因为利润率不好确定，现在根据成本加利润率定价的产品越来越少。可行的办法是，不管什么成本，消费者能接受什么价，你就定什么价；然后再让会计计算一下利润率，利润率高是你运气好，利润率低是你没福气。

用这种方法定价，一般需要先做一个市场调查。这就面临了一个新问题如果调查显示，消费者能接受的最高价格是 100 元，你怎么办？
