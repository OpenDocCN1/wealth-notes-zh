# 一诺老师案例：空调技术没有真正改进

一诺老师发现，很多空调厂家加上几层纱网，就成了空气净化系统；加个换气装置，就成了负离子健康空调；添了个紫外线灯，就成了高科技健康风扇……

一位不愿透露姓名的家电商城空调部销售经理告诉一诺老师，业内人士公认，空调进入市场这么多年以来，真正的技术改进只有一项，即由原来的普通定速空调进步为变频空调。

目前如此多的空调技术概念不过是“炒作的卖点”，是“为了满足功能性宣传需要，对空调局部进行的略微改进。

可能短时间内有点作用，但作用不大”。

据介绍，制冷、制热是空调最根本的功能，随着空调厂商不断推出一些技术概念，空调价格也水涨船高。
