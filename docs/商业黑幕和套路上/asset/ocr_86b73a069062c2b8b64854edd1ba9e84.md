# 第40课：产品快速创新套路3

# 山寨到产品“他妈”都开始怀疑人生

在外观设计与包装上搞创新，虽然效果明显，但毕竟不属于真正的新产品，容易被人跟风仿冒。

其实，一诺老师觉得推出一个新产品也不难。

![](bbox=[0.136, 0.371, 0.884, 0.51])

什么叫创新？一诺老师经常说：创新很简单。就是推陈出新！把“陈”的东西推倒，略微调整一下样式，或者增加点配料，鼓捣鼓捣，琢摸琢摸，不就出来一个“新”东西了吗？

一诺老师研究发现：国内很多复方药品、医院的自产制剂就是这么干的，很多服装、小家电厂家也是这么干的，国产手机更是这么干的。有人称之为“山寨”。

一诺老师问你，山寨又怎么了？

三星的一款手机，不就山寨苹果的 iPhone 吗？
