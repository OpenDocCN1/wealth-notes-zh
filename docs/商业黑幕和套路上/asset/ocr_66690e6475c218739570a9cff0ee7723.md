# 第 21 课：概念套路 2

# 造概念第二招：利益诱死人

在居家生活等领域，消费者首先关心的是产品的功能，希望它能给自己带来实际的好处。一个好的概念，要把产品的功能优势和利益点突出出来，让消费者一听就知道好在哪里。

一诺老师记得，海尔曾首创了“氧吧空调”，——上市就引起抢购，彻底改变了以往秋冬季空调销售停摆的状况。很多家庭甚至把它当成年货送人。海尔的销售员说，氧吧空调不但能够调节温度，还能使室内的氧气充足达到 21%~22%。

其实不用他们解释，就冲这名字，消费者就展开了丰富的联想—就算达不到森林公园里的含氧量，怎么着也是郊区吧？

家人朋友过年时坐在一起聊天，过个“有氧年”，多舒服！
