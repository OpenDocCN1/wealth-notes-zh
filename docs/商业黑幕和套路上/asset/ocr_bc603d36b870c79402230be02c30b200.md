# 第14课：葫芦里为消费者准备的药

# 买卖之间隔的不是一座山而是一个世界

消费者为什么不明白你葫芦里卖的是什么药。一诺老师告诉你：消费者不明白的原因，首先是“隔行如隔山”。现在很多产品号称是高科技，隔的岂止是一座山，简直是一个世界！

消费者即使花费精力专门研究，也难以搞清楚你的产品到底是怎么一回事。再说，现在的产品太多，每个消费者又都有自己的一堆事，哪来的工夫一一搞清楚？

![](bbox=[0.13, 0.5, 0.88, 0.64])

一诺老师曾经问过几位亲传弟子：说实话，你对自己的产品又能了解多少？其实也只是一知半解，比消费者稍微清楚一点点。遇到别的门类的产品，还不是两眼一抹黑、被人牵着鼻子走？
