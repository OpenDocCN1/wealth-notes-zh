# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

消费者逐渐明白是怎么一回事了，就不再有了。

一诺老师想问你：这有什么关系呢？只要能形成一阵风，就说明效果好。哪能想出几个字就保你一辈子赚钱呢？明年你再创造个新概念，不就行了吗？

![](bbox=[0.135, 0.308, 0.883, 0.445])

一诺老师十几年前在深圳罗湖桥两边，这种感觉特别明显：香港的房地产广告，讲的都是每间房多大面积、卫生间用什么水管、厨房的橱柜怎么摆放；翻开深圳的报纸，满版都是“金领人生”“英伦小镇”“五星级的家”……靠着这些美好概念，深圳楼盘价格“蹭蹭蹭”地一路上涨，甚至超过了对岸的香港。

概念是什么？一诺老师给大家说白了，就是对外宣传的几个字。简单的，就是一个产品的名字，让消费者只听到这个名字就想买货；复杂点的，就是一句响亮的口号，一行介绍产品的文字。大家别小看了这几个字，作用大着呢！
