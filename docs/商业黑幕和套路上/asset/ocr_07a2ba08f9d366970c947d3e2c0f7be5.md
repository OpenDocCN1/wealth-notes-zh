# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

住宅项目，叫万科城市花园。这里原先是一片稻田，距离虹桥机场只有 1500 米，隔几分钟就会有一架飞机飞过。这样闹哄哄的地方怎么卖房？据万科总经理郁亮透露，他们的售楼小姐带客户看房时，正好有飞机从头顶上飞过，售楼小姐马上说：

“看，飞机是现代生活的标志，这里离现代生活只有一步之遥。”客户听得又惊又喜。一传十十传百，成百上千的购房者闻讯而来，二话不说就把房款交了。万科城市花园一下子成了上海的明星楼盘，人人以能住在那里为荣还有一个更传奇的故事，说是有 一个偏瘫患者，住进万科城市花园不久，有一天在睡梦中被一阵飞机的隆隆声惊醒，慌乱中他一下子从床上跳了下来多年的偏瘫竟不治而愈。（差点来不及拗脸）

这个故事，也被售楼员拿来说事，成了楼盘的一个卖点。
