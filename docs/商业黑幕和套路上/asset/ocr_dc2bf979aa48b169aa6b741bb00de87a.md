# 借用别人的嘴,喊出我们的好

抬出来，比如说中国科学院卫生部中国保健学会之类。

中国人相信专家，更相信专家背后的组织机构，特别是带

有“中”字号、“国”字号的机构。

只要这些机构给你盖个章、发个牌子，或者只是在开会时

挂个名，权威性、可信度立刻就不一样了。
