数字运用得好，奥妙无穷！台湾的一家咖啡甜品店，名字叫 85 度。为什么要叫这个名字？

店家解释，因为咖啡在 85° C 时最好喝，在这个温度时可以品尝到咖啡中的甘、苦、酸、香醇等味道；而一般咖啡店卖的咖啡，温度大约在 90° C 到 96° C 之间。
