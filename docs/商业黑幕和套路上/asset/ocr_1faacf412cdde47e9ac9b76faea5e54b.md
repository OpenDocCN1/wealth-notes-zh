# 第 42 课：没有吓不倒的客户

# 女人怕老,富人怕死,老百姓怕生病……

一诺老师认为，恐吓要恰到好处，贴近现实，与消费者目前最关心的事物相结合，才能收到事半功倍的效果。

前面一诺老师讲到了广告宣传的许多方法。

对很多产品来说，一诺老师觉得，只要你描绘的优点突出，敢于承诺，一般都能吸引一批消费者。不过，采取相同手法的企业多了，市场的反应就不免大打折扣，广告投放的效果就会不断下降。这就对企业家提出了新的考验。

![](bbox=[0.135, 0.543, 0.882, 0.682])

怎么办？一诺老师研究发现，医药保健品行业摸索出了一种行之有效的办法：如果利益诱惑不了消费者，就要采用恐吓的方法——吓唬他，威胁他，“如果你不马上买我的产品，后者很严重”。对那些身体有毛病的人来说，一吓一个准。
