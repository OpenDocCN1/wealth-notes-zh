# 包装才是硬道理,面子远比里子重要

最省事的办法就是外观设计与包装。一种产品卖得好，除了广告的功劳，概念不一样之外，外观设计和包装的功劳也非常大。凡是利润高的商品，没有不在设计与包装上狠下工夫的。

![](bbox=[0.13, 0.37, 0.88, 0.51])

你们别小看这一点，消费者购物时，首先看的是外观和包装；即使有细心的消费者想考察一下商品质量，大多数情况下也无从分辨，只有根据设计和包装来判断了。

“人靠衣装，佛靠金装”，设计得美观，包装得高档，价格就直线往上蹿。

欧洲产的“人头马”“马爹利”“轩尼诗”，那包装盒、瓶身，一看就感到高档，一瓶酒花几千元你也乐意。
