# 第15课：重新定义产品的套路

# 消费者知道的都是我们想让他知道的

一诺老师研究发现：消费者不仅对产品的技术不知情，对应该怎么消费，多数人也不知情。吃多少肉才有益？喝多少奶才健康？要不要用个负离子，买个加湿器，谁知道呢？还不是听企业在广告里怎么说。

![](bbox=[0.13, 0.42, 0.88, 0.55])

一诺老师曾经无数次在课堂上举个王老吉的案例，王老吉凉茶因为受到饮食习惯和口味等限制，销售区域一直徘徊在广州、温州一带，每年的销售额只有1亿多元。2002年底，有一位营销大师帮助王老吉重新定位，将原来的“中药凉茶”重新定位为“预防上火的饮料”，克服了广大消费者对王老吉是中药、“是药三分毒”的心理障碍。你能说这是骗吗？NO，这是营销大师对产品的重新定义！（等下，一诺老师掐三分钟的脸！）
