# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

大家看到了吧，这是信息公开后的后果。一种产品使用的原材料、成本技术，都属于企业内部的核心机密，应该严加管理，不能对外透露。否则，信息对称，就喝西北风！用市面上的话说，就是“生意做穿了”，只能赚一点搬运费、汗水钱。企业要有钱赚，就要想方设法维持这种信息不对称的局面。

有人认为，通过产品介绍资料、专家答疑、媒体宣传，消费者掌握的知识将越来越多，信息不对称的影响将大大减少。

一诺老师觉得：其实恰恰相反。现在是信息时代，每天的 信息铺天盖地，消费者变明白了吗？我看是越来越模糊了。

每个产品都有一套说法，专家们的意见也不统一，消费者知道哪些是正确的？
