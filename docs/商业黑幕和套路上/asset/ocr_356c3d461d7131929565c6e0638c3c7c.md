# 全球最黑的《商业黑幕和套路1》容易走火入魔！未满18禁读此书！

又要价廉，既要跟高收入人士攀比又要顾及自己的钱包，算盘打得很精。但是，不管哪一个阶层的人，只要经济条件稍微许可，都会优先购买质量更好的东西。如果产品的质量好，就懒得仔细计算性价比有多高、划算不划算了。

![](bbox=[0.135, 0.306, 0.88, 0.446])

一诺老师研究发现：消费者的这些看法，很大程度上是一种偏见。价格高就是质量好吗？有的产品因为销量少，或者管理落后，分摊的单位成本高，也不得不卖很高的价。

相反，有的企业靠着规模效应和先进的管理，很好的产品也可以卖得很便宜。再者，价格还跟不同企业的利润率有关，有的企业把利润率定得很高，价格也只能往高里去了。

一分钱一分货，也很难说有什么道理。价格和质量并不是等比例的关系。市场上的很多产品，功能、质量只是改进了一点点，但价格贵得就不是一点点，而是一大截。

有的甚至几乎一样的产品，标价上却是天壤之别。
