# 第四课：让客户心甘情愿掏钱的套路

# 我们卖的是产品,客户买的是广告

客户为什么自愿把钱给我们呢？难道客户是活菩萨吗？

当然不是！

因为我们手里有一个产品，一个对客户有用的好产品。

营销有 4 个 P, 第一个 P 就是 Product, 产品！什么叫好产品呢？前些年有一个顺口溜，叫作“人无我有，人有我优，人优我廉”。

一诺老师多年前听过一场科特勒老先生的演讲，他说，市场营销的新观念就是开发那些能够卖得出去的产品，企业家首先应该发现对客户真正有价值的产品，有创新，性价比高，后面的销售就水到渠成了。

这样的观点对不对？一诺老师觉得当然对。但在企业里，没有哪个老板愿意听。人家问，有了这么好的产品，还要你做什么？营销的现实环境是,大家的产品都差不多,同质化严重。

要搞个真正的创新，投入大不说，还要看时机和运气。
