# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

有了这项高帽子，楼盘的档次立刻提升了一大截，国际社区的形象就有了。开发商启发购房者的美好联想，购房者为美好联想买单，逻辑就这么简单！

为楼盘所在的地理位置和区位进行命名，附加值就更大了。

一个号称在 CBD(中央商务区)的楼盘，价格起码要比其他地方的高出一半。但是，CBD 就那么大地方，不在 CBD 范围内怎么办呢？……如果隔得不远，那叫“泛 CBD”“后 CBD”“CBD 边缘区”。如果隔得远，那就改个类似的说法，叫“CLD”(中央生活区)、“CMD”(中央休闲区)、“CED”(中央教育区)好了！这些洋名词老外是不懂的，但咱中国人喜欢！
