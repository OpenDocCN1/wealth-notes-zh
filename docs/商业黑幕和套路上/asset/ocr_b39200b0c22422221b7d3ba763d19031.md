# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

价 300 元，消费者就会相信你的眼镜值 300 元吗？

当然！因为你标的价格是 300 元啊！什么叫“一分钱一分货”？就是你标价一分钱，消费者就认为你的产品只值一分钱；你标价一元钱，消费者就认为你的产品值一元钱。

消费者一般都会认为，产品的价格与质量、价值是对等的。

营业员在售货时，如果特意提醒客户某一个标高价的产品质量更好，客户心中“一分钱一分货”的看法就更加坚定了。

有一次，一诺老师课程现场，有一位学员脑筋转不过弯来，一个劲儿地问：一诺老师啊，您凭什么标价这么高？凭什么说自己的东西质量好？总得有个理由吧。

一诺老师说：是的，一般来说，价格高的东西，需要有相应的理由作为高价格的支撑。但是，价格是一种独特的东西，它自己就是自己的理由。
