# 第16课：永远不能说的秘密

# 公布行业内幕相当于搬起石头砸自己的脚

一诺老师再举个例子：2002年，奥克斯公司公布空调成本白皮书，将空调成本来了个大“兜底”。结果，当年在市场上尚属“贵族”的空调，迅速从四五千元的价位拉到了1500元左右。空调行业的近千家企业也被迅速洗牌，只剩下三四十家。

2005年10月，奥克斯再次在南京对外公布了中国手机成本白皮书，对以前神秘的手机成本进行了披露。据称，不管多高档的手机，其成本也不会超过2000元；某些洋品牌手机在中国市场上赚取的是500%的暴利！

奥克斯因一再公布行业内幕，被电子行业称为“内鬼”。

在行业利润减少的同时，其自身也陷入了“知名度高，美誉度低，发展后劲缺乏”的困境，可谓“杀敌八百，自伤一千”。
