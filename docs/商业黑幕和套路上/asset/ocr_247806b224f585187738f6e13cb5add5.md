# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

五粮神 216 为主打，终端价位在 380 元。

2006 年，约 3 万吨的全国高档白酒获得了 125 亿元的销售收入，占白酒总销售收入的 13%，但创造的净利润却占行业总利润的 70%。

2011 年下半年，五粮液、国窖 1573 再次上调出厂价，其中五粮液价格上调 30%左右，52 度五粮液酒出厂价由 509 元提升至 659 元，终端指导价提升到 1109 元；国窖 1573 上涨 40%。

茅台零售价的涨幅更是领先于其他白酒。2010 年底 53 度飞天茅台卖 1099 元/瓶，2011 年中秋前后，北京市场的茅台酒最高已涨到了 1980 元/瓶，2012 年更是超过 2000 元/瓶。

如此丰厚的利润，让业外资本也眼馋不已。2012 年 1 月，由星河湾地产出产的“星河湾老酱香”在上海亮相。

一位参加星河湾老酱香品鉴之夜活动的地产人士透露说，“星河湾老酱香一斤要卖到一万元”，价格将超过茅台。
