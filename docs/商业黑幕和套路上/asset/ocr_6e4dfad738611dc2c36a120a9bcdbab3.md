# 第20课：概念套路1

# 造概念第一招：科技永不倒

一诺老师经常教导亲传弟子：要给产品打上一个高科技标签，而且要最新的。中国老百姓大多数是高科技的粉丝，即使对这个技术根本理解不了，懵懵懂懂的，也照样崇拜得不行。

家电行业对高科技概念最为热衷。互联网、物联网、低碳、智能、云计算……每一阵技术浪潮兴起后，家电企业总是能抢先推出相关概念的产品，让消费者目不暇接，生怕自己家里的摆设过时了。
