# 宝洁电视广告的“三板斧”模式

第一板斧：先提了一个你面临的问题，引起你的注意。

第二板斧：有一个权威专家告诉你，有个解决方案，那就是用宝洁的产品。

第三板斧：你听从了专家的建议，问题解决了。

这个“三板斧”说起来简单，但老百姓喜欢，因为帮他们解决了困难。

老百姓不是记者，不会遇事就打一个问号：“那个专家是真正的权威吗？”“他们到底是怎么说的？”“他们说的话可靠吗？”
