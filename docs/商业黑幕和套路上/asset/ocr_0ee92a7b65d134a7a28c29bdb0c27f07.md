# 第28课：特点的套路

# 缺点也要说成特点,因为那就是特点

一诺老师认为：企业家应该研究人们相信什么，并根据他们的世界观说故事。只要故事说得好，消费者就会相信——

![](bbox=[0.13, 0.33, 0.89, 0.47])

的确如此，你自己都不说自己好，谁还会说？跨国企业怎么好起来的，不都是自己说出来的？

前不久上海有个新入行的房地产商，不知哪根神经被绊动了，在广告里信誓旦旦地说，他的房子的特点就是朴素实在，价格实惠，目的是让打工者也有自己的一个家。(赶紧捂脸)

结果怎么样？价格比别人低一大截不说，还卖得特别慢。

一诺老师专门问过这样的人，为什么广告做得土里吧唧？他们说，怕描绘得太好，兑现不了，消费者扯皮。

这样的人太迂腐，太不了解社会现实。
