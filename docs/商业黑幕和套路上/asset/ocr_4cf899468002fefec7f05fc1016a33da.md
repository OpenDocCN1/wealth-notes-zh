# 如何利用数字概念打造高端产品

一天，一个顾客在佳*电器(拟名)的展品前驻足良久，听完一诺老师的弟子温总监耐心的产品介绍后，指着其中的一个样品问：“这个数码 9000 的 9000 指的是什么？”

温总监当时一愣，心想：如果老老实实说是品牌型号，估计就没戏了。于是便严谨地说：“这是数码产品的技术参数，9000 在国内是相当高的了。你见比我们这个参数还高的产品吗？”

“没有。但为什么别的品牌都没有这个参数呢？”顾客很怀疑地反问。“那是因为他们的数码彩电数码参数太低，大部分才 3000~4000，不好意思标出来罢了。”温总监深沉地小声说。
