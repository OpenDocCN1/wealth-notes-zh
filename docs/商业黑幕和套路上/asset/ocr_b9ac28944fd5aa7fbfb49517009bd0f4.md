# 之二：小沙盘，大乾坤

沙盘，也叫模型，售楼处最重要的道具之一。一般你一进门，首先看到的就是这家伙。现在的沙盘越做越精致，花草树木，鸟兽鱼虫，亭台楼榭，山水人居，都能栩栩如生，惟妙惟肖。在沙盘的潜规则里，最常用的就是“缩”和“放”，这一缩一放就大有文章可做啦。
