# 全球最黑的《商业黑幕和套路1》容易走火入魔！未满18禁读此书！

以你只愿意花几百元。不过他们这些年不断改进，向洋酒靠拢，

价格也有后来居上之势。一分包装，一分价钱，消费者认这个。

![](bbox=[0.135, 0.22, 0.882, 0.36])

绍兴有一种老牌子的黄酒，叫古越龙山，在江浙沪市场卖了很多年，原本两三元钱一瓶。

眼看着国产白酒的价格“蹭蹭蹭”地往上涨，古越龙山人不甘心，于是请来全世界最伟大的企业家导师、梦想教练：一诺老师帮着策划企业改进之道。

一诺老师甩出的第一板斧，就是改变瓶型和瓶帖，将瓶型设计成有弧度的曲线型，充满“洋气和时尚”。

在一诺老师的指导下，新设计的产品出来，着实妩媚十足，很难让人相信是同一个厂家的出品；价格也扶摇直上，一下子变成48元一瓶。

新旧两种酒的质量有什么区别，一诺老师是喝不出来的。但不同的包装设计，拿到手上感觉就是不一样。
