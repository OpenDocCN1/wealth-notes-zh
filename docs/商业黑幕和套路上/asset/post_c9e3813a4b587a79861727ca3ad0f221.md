# 第65课：权威机构证言套路

# 行之有效屡试不爽的借力七大绝招

消费者相信，喊专家的一定是专家，而且还相信，号称专家的一般都是行业第一或最好的。一诺老师的亲传弟子，就知道如何让自己秒变专家，但今天教大家如何借力权威机构：

- 方法一：组织一次“国际性”的学术研讨会

比如开一次“亚太糖尿病医药研讨会”“第X届世界养生大会”，主题当然少不了“中国XX药的神奇功效”。然后发一篇报道：《XX产品在国际X高峰论坛上获得高度赞扬》《XX产品治疗XX的功效，在XX病研讨会上得到充分肯定》《XX荣获X会议金奖、特别大奖》……

![](img/15f198c22cd7a7cb9b4d6820552aa00d_332_0.png)

- 方法二：为某个重大活动、某次重大会议提供赞助

比如神源口服液，它的一个宣传语就是“荣获联合国第十五届国际科学与和平周指定礼品的称号，并作为珍贵礼品赠送给出席联合国国际科学与和平周开幕式的嘉宾”。老百姓只要看到“联合国”几个字，马上就会想，这样的产品肯定好。

# 方法三：将审批产品的国家机构的名称打出来

任何一种药品、保健品化妆品，都可以打出“中华人民共和国卫生部批准”“国家医药管理局批准”之类的招牌。虽然每一种公开卖的药品、保健品都必须经过这两个机构批准，算不上什么特别的优势，但老百姓不这么想。只要你把这两个权威机构的名字打出来，老百姓就感到你是权威认可的，放得了心。

![](img/15f198c22cd7a7cb9b4d6820552aa00d_333_0.png)

# 方法四：将其他权威机构的名头打出来

前几年卖得很火的“联邦减肥朵朵靶”，在广告中反复说的是：“广州x公证处证明，xx老师减了x斤，腰围缩小xx。”
