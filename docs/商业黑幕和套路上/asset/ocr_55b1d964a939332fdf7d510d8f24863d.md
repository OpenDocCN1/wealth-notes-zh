# 行之有效屡试不爽的借力七大绝招

+   方法一：组织一次“国际性”的学术研讨会

比如开一次“亚太糖尿病医药研讨会”“第X届世界养生大会”，主题当然少不了“中国XX药的神奇功效”。然后发一篇报道：《XX产品在国际X高峰论坛上获得高度赞扬》《XX产品治疗XX的功效，在XX病研讨会上得到充分肯定》《XX荣获X会议金奖、特别大奖》……
