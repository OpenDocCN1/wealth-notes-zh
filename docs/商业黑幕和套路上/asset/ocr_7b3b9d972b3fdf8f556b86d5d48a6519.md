# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

一诺老师曾经看到一个产品在宣传中说：“他的 XX 产品得到亚洲成功学权威某某老师的高度认同，先后被 EMKT、ADCN 等网站刊登。”

如此抬举“权威”，都是托“权威”两个字的福。

哪怕不是真正的权威和专家，只要有一个专家形象，效果也立竿见影。所以你会发现，现在很多自封的世界大师、亚洲权威、中国专家……

广告法规定不许用医生形象做广告，很多牙膏、医药厂家就让模特穿上一件白大褂。

厂家并没有说穿白大褂的就是医生，但在消费者看来，这样的人说的话就可信得多。

在其他领域，专家证言也有重要的功效。房地产公司为了增加可信度，经常请一些权威人士对楼盘进行点评——规划设计、新技术新材料，还有什么性价比、区位优势，角度多得很。
