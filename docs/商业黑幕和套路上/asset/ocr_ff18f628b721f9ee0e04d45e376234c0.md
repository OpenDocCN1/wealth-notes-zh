# 第61课：傍名人的套路

# 让更多牛逼的人说你牛逼你才真的牛逼

一诺老师研究发现：在这样一个消费者普遍不自信、需要意见领袖引导的时代，明星其实是代表了一种形象和具体化的心理感受，在相当程度上起到了意见领袖的作用；同时消费者对明星的喜欢和信任会转移到由他来代言的品牌上。

![](bbox=[0.135, 0.412, 0.882, 0.555])

不知大家有没有注意到这样的一个现象：这几年，国产的运动鞋、运动服装正在集体崛起：安踏、特步、361°、乔丹、耐克、贵人鸟、七匹狼、柒牌、利郎、九牧王、金莱克……

这些品牌一改前些年仿冒国外知名品牌的做法，堂堂正正地打出了中国人自己的牌子，大长中国人的志气。

知道这些品牌有什么共同点吗？

一诺老师告诉大家，它们都来自福建一个小地方——晋江。
