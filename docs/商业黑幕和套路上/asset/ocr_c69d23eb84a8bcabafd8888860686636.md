# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

意图和实景合成图四类。一诺老师研究发现：其关键在于能左右你的第一印象。比如一见钟情啦、惊艳啦，都是在说第一印象的厉害！这打扮好的图，就跟一个花枝招展的大姑娘似的，哪个“小伙子”眼一热，接下来自然就“情不自禁”了。

最老实的实景图——在楼书上，多出现在描绘周边配套的段落里：一座人潮熙攘的大卖场，一所师来生往的小学校，有时候比几百字的介绍更直观。但要是你以为实景图是照片，所以真实度应该是百分之百，那你就错了！听说过 photoshop 这东西吧？对了！很多照片都是修过的。

一诺老师听过有一首歌这样唱的“让上海的天更蓝，让上海的水更绿”，就是对这类实景照最好的注释。
