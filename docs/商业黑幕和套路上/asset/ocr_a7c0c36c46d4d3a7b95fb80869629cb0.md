# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

一是避免消费者怀疑你的质量下降更重要的是避免降价影响商品的形象。

切记：降价次数多了，形象就毁了。

汽车行业经常遇到这样的情况。比如丰田凯美瑞在上市后的很长时间，价格一直雷打不动，甚至要加价才能拿到现货。但消费者宁愿排队等待，也不愿买经常降价的蒙迪欧。

如果价格老是不动，多少会受到那些降价产品的冲击。

一诺老师认为，价格是企业家手里的一把宝剑，不能老闲着不用，要经常地升一升，再降一降，撩动消费者的神经。

升也有利，降也有利；升有升的理由，降有降的手法。

最高明的做法就是经常地、小幅度地提价，给消费者传递出价格坚挺的信号。
