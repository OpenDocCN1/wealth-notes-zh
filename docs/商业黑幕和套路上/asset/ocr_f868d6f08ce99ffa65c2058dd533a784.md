# 全球最黑的《商业黑幕和套路 1》容易走火入魔! 未满 18 禁读此书!

这和我们前面讲的“客户觉得好，才是真的好”，道理是相通的。

一诺老师提醒大家：现在的世界变了！以前我们穷，商品少，都觉得经久耐用的才是好东西。一个小板凳，也要父传子、子传孙，最后都成了文物。一诺老师发现老外市场经济搞得早，明白这样做不行，发明出了“短寿商品”，一个商品用到一定时候就坏，不坏也让你过时、落伍。

比如微软的 windows 操作系统、苹果、奔驰等经常升级，消费者每次还不得跟着追赶。

![](bbox=[0.13, 0.47, 0.89, 0.62])

在一诺老师知识体系的指导下，中国的企业家虽然比不上外国那些大公司，但进步也是神速的。

即使是电视、汽车这样的耐用消费品，每隔一两年也要升一次级、换一次代。

如果从外观上看不出是换代产品，厂家就宣布，生产线是第五代、第六代的。(知道内幕的人纷纷捂脸)
