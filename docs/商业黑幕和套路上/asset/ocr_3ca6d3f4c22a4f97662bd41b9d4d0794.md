# 一诺老师的肺腑之言

亲爱的有缘人，当你热血沸腾地学习这本旷世绝学，你是否感觉自己满血复活、醍醐灌顶、顿悟商业真谛呢？

强烈建议你至少学习 10 遍、20 遍、50 遍……当你学习 100 遍以上，你将会掌握全宇宙最深、最深的套路，你能让所有同行一脸懵逼、目瞪口呆！甚至你将有可能颠覆整个行业，打的同行满地找牙，跪在地上唱征服！

此绝学于 2011 年截稿，但是由于一诺老师秉承实事求是的原则，所以内容太过实战和裸露，揭露了很多行业内幕，因此，这本书被 173 家出版社，拒稿 2937 次！

万般无奈之下，只能在港发行送给一诺老师的缘人！

当你有缘分拥有这本旷世绝学，你可以选择在任何国家出版(一诺老师不要版权了，就当做雷锋了)，但是，请别怪一诺老师没提醒你，这本书揭露了很多企业家成功的真相，若被报复或暗算，后果自负！请好自为之！
