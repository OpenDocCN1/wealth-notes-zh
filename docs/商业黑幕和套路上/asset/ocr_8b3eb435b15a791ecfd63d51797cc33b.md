# 造概念第四招：名正则言顺

有的时候，也不需要费这么多脑筋。只要取一个好听的名字，效果就大不一样。

一诺老师就拿厕所吧，以前乡下叫茅房，其实早就不 是茅草盖的了，但乡下人不懂营销，尽取这些难听的名字；城里人有文化，先管它叫厕所，后来又叫卫生间，现在更升级了，叫洗手间。这名字一改，你还能想到那不太雅观的事吗？还能闻到一点臭味吗？

![](bbox=[0.135, 0.543, 0.885, 0.682])

汾州老窖推出 的高端酒，取名“国窖 1573”。这个名字有讲究，你茅台酒号称“国酒”，但我是“国窖”。俗话说“好窖出好酒”，我比你茅台还正宗，价格当然也比你贵！

在命名方面，一诺老师觉得我们都要跟房地产行业学习。
