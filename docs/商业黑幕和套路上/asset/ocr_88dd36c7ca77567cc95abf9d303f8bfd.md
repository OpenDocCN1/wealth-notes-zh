# 第 55 课：极限定价套路

# 不断挑战消费者的心理价格极限

很多企业为产品定价，一般在产品上市之前会做一个市场调查，摸一摸消费者能接受价格的心理极限，然后在这个极限下方定一个价。道理似乎是对的，问题是，怎么准确判断消费者真正能承受的心理极限？调查过程中怎么向消费者提问题？

如果你问“定什么价格比较合理”“期望价格多少”，这样问出的结果，非把你气死不可。有的楼盘开盘前询问意向购房者“多少价格合理”，大部分人填写每平方米 4000 元、5000 元，8000 元就到顶了，两三千元也有人敢写。
