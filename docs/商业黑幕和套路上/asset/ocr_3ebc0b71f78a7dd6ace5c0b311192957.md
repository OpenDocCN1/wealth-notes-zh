# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

一诺老师在江南辅导一家企业的时候，遇到有种针对新装修房的“除甲醛剂”卖得很火。

商家宣传说，该药剂能够清除装修时所留下的甲醛和苯、甲苯、二甲苯等污染物，将其分解为二氧化碳和水，消除异味，净化空气，既环保又对身体有益。

有懂行的人告诉一诺老师，除甲醛剂实际上就是一种化学合成剂，利用化学反应把甲醛转化为其他物质。

这个产品从理论上是成立的，也有一定的实际效果。

![](bbox=[0.13, 0.48, 0.88, 0.62])

但要想一次性把甲醛、苯等有机物全部分解为二氧化碳和水，几乎不可能，同时，在转化过程中会产生其他污染物质。

对于这一点，商家当然绝口不提啦！
