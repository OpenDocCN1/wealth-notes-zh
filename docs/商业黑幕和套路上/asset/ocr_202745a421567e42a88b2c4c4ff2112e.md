# 视觉引导：给客户难以磨灭的“第一印象”

如何进行“视觉引导”呢？一诺老师经常说，我们要在产品的广告、包装或者外观、图片、颜色等方面，进行模仿或者加工，引导消费者产生美好的视觉印象，达到以假乱真、真假难辨的效果。

虽说一诺老师的方法比较简单，但由于消费者一目了然、直截了当，效果也相当不错。
