# 第43课：恐吓客户的不二套路

把消费者吓到：相信这个世界上有鬼

威胁法：着力渲染，夸大身体危害。

羞辱法：“无中生有”，渲染社会后果。

恐吓营销最通常的方法，是向消费者强调某种情形对身体健康的危害适度夸大问题的危险性与严重性，也称“威胁法”。

为什么要“威胁”？

一诺老师认为，在大多数情况下，人们面临的问题并没有那么紧迫和严重，比如说人体缺乏维生素，只要坚持正常的饮食，就不会出现黄金搭档软文中所描述的那种严重疾病。

但是，大多数消费者都有惰性——

“羞辱法”则通过“无中生有”的方法，渲染消费者的某种身体缺陷可能引起的社会后果，激发消费者的羞耻心理。
