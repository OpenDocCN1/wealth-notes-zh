# 一诺老师赚快钱的 “不二” 之选

“不一”：产品属于新出现的品种—消费者没有使用经验。

“不二”：产品的功效难以验证——批评者还未找到确凿的证据。

在美国纳斯达克上市的橡果国际，旗下的产品线非常丰富：

有矫形的、丰胸的、减肥的、增强记忆的、抗衰老的，还有运动器材、数码相机、数码摄像机、车载导航仪等。

这些产品基本都是近几年才出现，老百姓以前没用过，不知道好坏标准，心里没数。
