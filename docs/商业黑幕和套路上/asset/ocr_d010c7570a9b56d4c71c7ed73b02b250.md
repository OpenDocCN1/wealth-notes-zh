# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

“认知”到了，再无价值的东西也有价值。

哪怕原本只值一分钱，如果消费者认为它值一毛钱，它就值一毛钱；如果消费者认为它值一元钱，它就值一元钱！

![](bbox=[0.136, 0.262, 0.882, 0.403])

那么，我们怎样让客户对一个产品形成好的“认知”呢？

一诺老师给你最靠谱的答案：

当然要靠做广告。

不过我们不要忘了，广告不是全部，产品名称、包装设计、

产品说明书、价格、卖场环境、商品陈列方式……这些都是客户接触一个产品的接触点，对客户的影响都很大。

我们做企业，就要从这一个一个的接触点下手，一点一点地征服客户，让他们觉得我们的产品好。
