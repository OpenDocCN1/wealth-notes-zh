# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

求定位在“响”。这样，一诺老师一刀把中国的瓜子切割为两块，你别的竞争品牌再厉害，你们都是香瓜子，我是“响”瓜子。

“响”被当成了购买的理由，产品被赋予了感性的力量，这种力量使产品变得与众不同！

事实上，所有的瓜子在嗑的过程中都会发出“咔咔”的响声，一诺老师只是将它放大，用它来激活消费者对一个普通产品的认知。

如果你能想到的“说法”都被别人抢了先，怎么办？
那就为这个产品编一个新的类别。
在这个新的品类里，我总会有与众不同的、有差异的产品吧？现在不光企业家，连卖西瓜的都懂得编品类了。

前些年他们吆喝的是“沙瓤”“保甜”，现在干脆喊什么“寒瓜”“冰糖瓜”，乍一听，还以为出来新品种呢！
