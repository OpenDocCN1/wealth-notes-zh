# 造概念第三招：新奇加生动

好的概念—诺老师总结了几个标准：新奇、生动、响亮，要让人听起来一震，想不注意都不行。

—诺老师发现，保健品市场越来越难做，所以对概念的要求也越来越高。就这一个“洗”字，策划人就用到极致——不是洗衣服、洗脸，而是洗内脏：先出来了几种“洗肺”的虫草、清茶，洗完肺又出来一批“洗肠”的，洗完肠又“洗血”，洗完血又“洗肾”，洗完肾又“洗斑”……碧生源常润茶畅销了好几年，它的广告语是“洗肠更润肠”“快给你的肠子洗洗澡”。

前两年又出来一个常青素，号称能“洗细胞”，更厉害！

大家看这“洗”字，多形象多生动，比起养颜、排毒之类的老式概念，醒目多了。
