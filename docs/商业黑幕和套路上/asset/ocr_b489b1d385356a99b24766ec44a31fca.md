# 全球最黑的《商业黑幕和套路 1》容易走火入魔！未满 18 禁读此书！

常有。一诺老师记得，曾经信集团总裁周厚健就放了一炮，说白色家电行业普遍虚标能效，“这个行业是一个完全没有实话的行业，讲假话比讲真话还滋润。

比如说标的节电是多一天多少度，没有一个是真的。再比如，我们开发出一个一天耗电 25 度的空调，别 人是 3 度 5 度，但是他可以标 2 度”，没有人去查。一诺老师发现，数字这东西，只要你敢标，没有谁跟你较真。

大家发现没有，在戏剧舞台上，有事没事就要放一把烟；咱们搞企业的人，有事没事，就要摆出一堆数字。

一诺老师上面列出的数字，大都是关于产品的成分或生产工艺的，间接证明了产品的质量，还需要消费者动一番脑筋，运用对比、想象和推理的方法才能得出自己的结论。

为了让顾客更轻松、更省事，一些大企业干脆就直接用数字表明产品的功效。
