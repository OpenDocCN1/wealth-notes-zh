# 第62课：专家和权威的套路

# 在专业技术方面,权威专家更具有可信度

明星虽然有知名度、有魅力,但毕竟不是技术方面的专家。

唐国强和郭德纲在代言的产品爆出质量问题后都公开表态，他们不懂专业技术，管不了产品的质量。

一诺老师认为，对很多科技型产品来说，除了邀请名人、明星代言外，还有必要把相关方面的专家请出来。

![](bbox=[0.135, 0.455, 0.885, 0.595])

一诺老师发现,在专业技术方面,权威专家更具有可信度！

事实上，北京新兴医院在请唐国强代言时，也突出了它的强大专家后援团，包括原卫生部副部长、原中国中医研究院院长、原中医药管理局副局长……

现在有的网友给专家起了个外号，叫“砖家”。
