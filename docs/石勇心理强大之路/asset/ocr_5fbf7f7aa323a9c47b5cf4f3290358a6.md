+   2. “北大”这块金字招牌在中国的价值排序是很高的，无论你在嘴巴上是否唾弃拥有“北大”这一属性的人，在心理上你的确都屈服于“北大”位于高端的价值排序。凭这块招牌，范跑跑可以在非北大面前具备足够的心理优势，可以真的很牛 B。

+   3. “无所谓崇高”，这是取消道德判断。骂他的人依赖于道德判断的游戏规则来界定范跑跑的道德弱势，但范跑跑根本不承认这样的游戏规则。不和大家一起玩共同的游戏规则，你的道德判断对他就没有效用，他就不处于道德弱势，从而在心理上也不处于弱势。

+   4. “你们就装 B 吧”。他认为，骂他的人都是在装 B，说好听点就是在表演。既然是表演，骂他也就没有任何力量。这种认定是道德上的反击，他反而可以通过这种反击获得心理优势。
