# # 自我

每个人都说“我”。“我”就是一个人的身体、一个人的观点、一个人的偶像，一切进入、驻扎在一个人的心理世界操纵他的东西。攻击到一个人所认同的观点、一个人所信仰的对象，就是攻击到他的“自我”。

精神分析的鼻祖弗洛伊德讲过一个关于人格结构的故事。这个故事的主角是“本我”、“自我”、“超我”。
