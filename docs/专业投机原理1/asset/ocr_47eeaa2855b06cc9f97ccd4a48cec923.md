# 圖 6.2

1990年12月份的S&P期貨與S&P現貨指數的五分鐘走勢圖。電腦交易程式對於盤中走勢的影響。電腦交易程式發明以前，任何如此大幅度的持續性走勢中，必然會夾雜著反彈。電腦程式可以使期貨與市場指數出現巨幅的波動，經常會使交易者誤判市場的趨勢。
