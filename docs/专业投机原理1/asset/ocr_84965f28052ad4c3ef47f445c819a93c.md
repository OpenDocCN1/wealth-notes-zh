# 經濟學與人性

> 經營事業猶如逆水而上。他毫無選擇；不進則退。

——Lewis E. Pierson

自由市場經濟是人類創造的制度，它奠基於一種觀念，人類具有獨立而理性的思考能力，他們能夠維繫自身的生存。它雖然是人類創造的制度，卻是自然產生，它是個人在社會架構內理性行為的自然結果。政府並未創造市場；它們以強行的干預破壞市場。如果政府讓它的子民自由發展，市場將自動產生，它們猶如有自己的生命。
