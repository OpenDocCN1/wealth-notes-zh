# 圖5.2

1990年12月份黃金期貨的日線圖（上側）與週線圖（下側）——三種趨勢。長期趨勢（數個月至數年）向下，它在下側的圖形中以A線表示。中期趨勢（數個星期至數個月）向上，它是以B線表示。短期趨勢（數天至數個星期）向下，以C線表示。

上升趨勢——上升趨勢是由連續一系列的漲勢構成，每一段漲勢都持續向上穿越先前的 aiut 高點，中間夾雜的下降走勢（換言之，跌勢）都不會向下跌破前一波跌勢的低點。總之，上升趨勢是由高點與低點都不斷墊高的一系列價格走勢構成①（參考圖5.3）。
