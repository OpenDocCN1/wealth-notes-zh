# 成功的必要條件

我認為，身為交易者、投機者與投資者，如果希望在金融交易中獲致穩定的成功，需要俱備一組個性上的特質。

第一，必須俱備有根據的自信心（self-confidence），相信自己的心智可以學習真理，並由正面的角度運用在生活中的每一個領域。

第二，必須俱備自我的動機（self-motivation）與決心（commitment），有能力與意願將時間與精力花費在交易的知識上，並學習如何交易。

第三，必須俱備智識上的獨立性（intellectual independence），面臨各種不同的見解時，可以根據事實自行判斷。

第四，真誠地熱愛自己的工作，體認最大的報酬來自於工作過程的本身，而不是工作得到的名與利。
