# 如何根據貨幣與財政政策以預測趨勢與趨勢的變動

任何市場的長期價格趨勢最終都是由市場力量——供給與需求——決定。然而，不論任何市場，在供給與需求的方程式中，一部份都是貨幣與信用的供給與需求。不論是股價指數、個股或商品，Fed與政府的財政政策都會明顯影響貨幣與信用，以及價格趨勢。

我最大的交易勝利，來自於我能夠預測政府政策的結果（當然還需要配合其他的方法）。然而，我最大的失敗，發生於我假定政府會採取合乎理性的行爲。
