# 第七章
創造財富的契機：
辨識趨勢的改變

金融市場中最迅速而安全的賺錢方法，是儘早察覺趨勢的改變，建立部位（多頭或空頭），順著趨勢前進，並在趨勢反轉之前或之後不久，了結你的部位。任何市場的專業玩家都會告訴你，在低點買進而高點賣出（或是在高點賣空而低點回補），這僅能仰賴運氣的眷顧；但經過適當練習之後，你非常可能掌握中期或長期走勢的60％至80％。

為了辦到這點，你首先必須知道有那些不同的市場，有那些金融工具可供交易，如何與在那裡交易，保證金的規定如何，以及其他類似問題。①瞭解這些相關知識以後，接著你需要以某種方法尋找俱備理想投資機會的市場。
