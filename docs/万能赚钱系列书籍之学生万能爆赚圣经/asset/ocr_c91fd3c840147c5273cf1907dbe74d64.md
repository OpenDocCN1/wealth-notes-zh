表单出来。

# 3. 改善这些产品的不足之处

知道了不足的地方，然后寻找可以替换或改善的方法，也可以通过集思广益获得。

# 4. 将创意或新产品出售给商家或自己销售

当经过改善后的产品，经过实际的验证证明是可行的；或者比原产品更加受客户们喜欢的话，你就可以把它推荐给可能对你的新产品，感兴趣的厂家。同时商议是否愿意购买你的产品或创意。（为了不被别人窃取你的成果，你可以先同对方签订一份保密协议，或采取一些保密措施，如现场录音等方法，来防范这些潜在的风险）如果生产或制作上较为简单容易的话，你还可以自己亲自制作销售。如果资金不足，可以寻找一个有资金的合伙人共同去做。不会销售的话，就将销售外包给别人去做。假如你的产品真的很有潜力，定会有很多人感兴趣。
