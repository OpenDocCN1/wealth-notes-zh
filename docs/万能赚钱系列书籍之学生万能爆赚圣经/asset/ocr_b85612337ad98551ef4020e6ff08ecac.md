# 第四步：在威客网完成产品的制作。

将你想要的答案和结果，发布到威客网任务上面。如猪八戒网，威客中国等；在威客网上，合理设定你的价格，将有成千上万有才识的人，等着为你出谋献策。你所做的只是将他们，在所递交上来的无数作品当中，将最佳的答案或产品定下来。而这些很棒的产品和创意，你只需要付出一丁点钱就可以办到。
