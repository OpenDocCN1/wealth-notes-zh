# 第八步：持续的沟通

当你向客户推荐后，也许你的客户会没有反应。原因可能是多方面的，没考虑好，没明白，还不够了解，或者是因为某事忘记了。面对这些情况，不要以为客户不需要，拒绝你或你的产品。

你需要做的事情就是不断的提醒他，解释给他听；让他明白购买这款产品，是他最好的选择，对他会有很大帮助。这就需要不断的多次的沟通。

如果你的产品价格很贵，多次的沟通还是很有必要的。你要让客户时时关注你的产品，记住它，进而了解它。有很多做直销的都一致认为，持续多次的沟通，可以让你的成交率成倍的提高；而只沟通一两次就成交的很少。

客户需要有一个了解，吸收消化 的过程，而这需要一段时间，需要对其不断地提醒和沟通。
