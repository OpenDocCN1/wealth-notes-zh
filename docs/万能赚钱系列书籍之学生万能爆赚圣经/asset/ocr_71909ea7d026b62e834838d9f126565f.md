# 第七步：零风险承诺保证

通过无效退款，不满意退款等系列的零风险承诺方法，将你客户的戒心和不信任心理防线解除。或者是提供试用，有效或见效后再决定是否购买完整 frontera 的产品等的措施。

如果将你的产品质量做到位，不用担心会有大量的退货，你的退款率会很低。

为了降低你自己的风险，有时你该设置一些附加条件，来回避一些意外不可预料的风险。比如要求对方必须是按照上面说的去做，去使用，去学习等附加条件。因为方法再好，购买去不去做也见不到效果；就像一台好风扇，买回去不插电是不会扇出风来的，那就不是属于电扇的质量问题。

所以有时加设一些必须的条件还是有必要的。因为很多人是比较懒惰的，哪个是最简单的按，没有催促和监督都很难以完成，自然影响到作用的发挥，最后也会影响到结果。

这样，就将会将一些占便宜的人，或者比较懒的人排除掉；这些人也会将是你退货最大的威胁。
