饭店属于客户经常性消费的行业，光临次数多，许多隐藏的资源没有发挥出来，以下介绍几种简单增加收入的

方法，以供参考：

# 方法1：通过产品的转介绍收取佣金

这种方法许多饭店都在用，如许多饭店通过向顾客们，提供饮食所相关联的产品来赚取佣金。啤酒，饮料，餐巾纸等附带 큢其它产品，来赚取额外的利润。虽然利润小但是数量多，积累下来收入也是相当大。

除此之外，还可以通过推荐其它产品和服务，如***公司产品消费券，打折券等。当消费者持此卡券消费时，你将获得佣金提成。也可以将此类信息，印成小册子或消费积分卡等，在店里免费发放赠送给顾客。其实，很多客人对打折类的信息很感兴趣的，关键在于你的想象力。

# 方法2：闲置多余空间的充分利用

饭店是人流量非常大的场所，可以将店内的广告位整体出售或出租。如希尔顿大酒店曾经将一家旅馆内，没有起承重的大柱子拆除，设计成漂亮的广告橱窗，出售里面的广告位，每年赚取大量的额外利润。国外有家饭店在餐桌上设计名片展示位，向名片提供者收取展位费。
