# 序言二

有次我和朋友打赌，问他相不相信我能够从他身上赚到 100 元钱？朋友很肯定的摇摇头。我解释道：

> “每个人都有自己的弱点，比如你的弱点，可能是你的妻子，父母，孩子或者是其他的什么人或者事情。如果我从这些人的身上去找机会，一定会有所突破的。比如，我发现你很爱你的老婆，而你的老婆很热衷潮服装。我如果经营服装的，就针对你老婆的胃口，推荐一款不错的衣服。当你老婆决定购买并付款时，而你也可能将成为付款者。也可以说，我间接的从你身上赚到了钱，不是吗？”

黑猫白猫，能够老鼠就是好猫。不管你用什么办法，只要是合法的手段，结果达到了，你就是胜利，你就是大赢家。我们做任何事情，也应当如此。我们需要的不是过程，我们需要的就是结果。对于本书中的某些方法，有一些可以说是简单之极。但是，越是简单的方法，简单的东西，越容易被人所忽视。

而那些采用这些方法，加于行动起来获得成功的人，也就不是那么奇怪和神秘的事情了。
