# 2. 制造雷人事件

所谓雷人事件就是做出一些，让别人感到惊讶，震惊，无法想象和感到不可思议的系列的事情 或活动。如芙蓉姐姐恶搞写真集，凤姐的征婚炒作等等，都是通过这些雷人事件，在别人口头议论的当中，宣传和广告了自己。

采用这种方法，可以在极短的时间内，让很多人认识你，以及传播你所制作出的雷人事件。只要把握住分寸和火候，也不少为一种宣传自己的方法。

# 3. 提供免费的赠品或资料，实施信息的共同分享

我们很多人都喜欢免费的东西，如免费音乐，免费电影，免费的门票和免费的资料等等。如果在你身边有别人，非常需要的产品或资料，或者服务等，而且是完全免费的话，你将会很短 时间获得大量的索取者。这样，你就会获得很多结识这些人的机会。
