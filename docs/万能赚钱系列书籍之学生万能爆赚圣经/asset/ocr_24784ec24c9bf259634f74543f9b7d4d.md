# 第十步：重复这个模式

当你的产品完成了销售，你将会获得一个交易记录。你要把这个记录给保存下来，可以作为未来销售给其他人的引证。

因为人都是有共通性的，对于某人有效的方法或产品，同样的群体也依然有效。当证明你的产品是不错的时候，你要做的事情是，寻找同样类型，同样群体，再次的重复这个过程。

你只需要将这个过程向更大范围，更深层次去销售就可以啦。因为是已经证明有效的事情，所以成功率会达到很高。

# 第十一步：出售升级产品

当别人对你的产品感兴趣之后，你就要在此基础上，增加或者开发出新的，更高价值的东西。

凭借首次成交对你的信任，如果你的产品价值是不错的，客户会很乐意再次购买你的服务。因为他们已经从你那里得到了好处，他们想要得到更多。

# 第十二步：将你的产品给别人授权

如果你的产品很好，而你时间不是太多，那就让你的服务或产品授权给别人。允许别人其在限定的范围之内，销售你提供的东西；而你也将会获得利润分成。
