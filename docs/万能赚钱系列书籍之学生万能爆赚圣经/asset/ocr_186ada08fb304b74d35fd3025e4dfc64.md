# 第七步：实施零风险承诺

当你的产品作用或效果，客户已经产生好感，或者已经充分认可的时候，你要做的重要一件事情，就是帮助他们下决定。激发其马上行动并付款购买。当客户并没有马上行动时，就表示他还有顾虑，可能是对你的诚信，对产品质量，以及售后服务等还放不下心。你要做的就是一个个解决这些问题。

解除客户的购买顾虑，很好的一個办法，就是把这些客户认为潜在的风险给消除掉，可以实行不满意 退货退款的方法。期限可以是15天，一个月或更长时间。

结果表明，随着时间延长，退货率会降低，因为很多人已经淡忘掉这些事情。产品销售实施零风险承诺，对客户来讲这样做自己的风险很低，没有太大的损失。对你来讲如果质量真的很好，退货也自然会很低。否则就是你的产品质量太差劲，趁早更换你的产品。

客户既然要购买就是很需要，如果有效果高兴还来不及；即使没有说的那么好，很多 还是可以接受的。因为真的要去退款退货，毕竟是觉得很别扭的事。只有迫不得已，极度生气，产品实在太差了才会来退。
