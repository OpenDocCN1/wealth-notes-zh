# 附录：一件简单发明成就奇迹

1987年美国弗吉尼亚州的两个邮递员汤姆科尔曼和比尔施洛特无意中看到一个小孩子，手里拿着一种发绿色亮光的荧光棒，于是他们边设计了一种将棒棒糖放到荧光棒的顶端，在夜间光线透过半透明的糖果，显出奇幻的色彩，为此产品申请了专利，卖给了美国开普勒糖果公司，大赚了一把。

不久，他们有设计以一种新的东西，就是为棒棒糖安装了个电池驱动的小马达，经过减速可以旋转起来，这样，吃起来跑糖子就不会太费劲。结果大获成功。通过超市和自动柜台机，6年里，共卖出6000万个，每个售价2.99美元，获得丰厚的回报。
