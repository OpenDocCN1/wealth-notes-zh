# 方法 3：使用消费充值卡，赢得新客户

通过办理会员制的方法，将新客户发展成为老客户。如果你的店里老客户多，消费次数多，你可以推荐其办一张会员卡。凭借此卡来消费时可以享打折的优惠。初次消费后由于卡内有余额，下次他还会来消费。你便有一群稳定的客户，新客户也变成回头客，甚至为你带来他们大量新的同事或朋友来消费。

国外有家某氏餐厅，就是采用会员制的方法。当客户首次消费完结账时，服务生会询问顾客，如果办理一张会员卡的话，（当然要充入一定金额的现金），就可以不用支付这顿饭的饭钱，结果生意发展很兴隆。

其实，这样做，首次消费的费用，可以在以后的消费中冲抵。重要的是，你有一批稳定的客户。

也可以采取消费优惠卡，可以流通转借的方式。如果持卡人的亲戚或朋友持卡也可以享受优惠，并可以获得一定的积分。积分一定时，还可以冲抵消费现金。
