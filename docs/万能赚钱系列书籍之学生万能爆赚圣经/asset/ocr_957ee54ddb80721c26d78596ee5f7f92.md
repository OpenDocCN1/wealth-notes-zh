# ◆ 资源置换典型案例 ◆

作家秋更斯所写的第一篇故事并没有卖钱，他跟人交换了一袋弹珠。

法国画家罗特别克用他的画，同别人交换食物与房租。

克莱斯勒汽车公司曾以 192 辆车，跟西班牙语电视网络七家电视台交换广告。而电台拿出其中

45 辆车，跟电视转播设备厂商交换价值 50 万美元的设备，利用这设备在旧金山开设全功率的电视台。

美国佛罗里达州的嘉年华邮轮公司，以空舱位跟 100 多个城市的，广播电视台与报社交换广告

告，为期达十年。因为如果邮轮开航，空出来的舱位其实成本等于零。这家邮轮公司利用方法，他们在 100 多个城市，十几年以来不断打广告，却是一毛钱也没花。成为全世界最大的邮轮公司。

某家国际大旅馆每年发行价值 700 美元的住宿抵账凭证，几乎跟任何广播电视台，与户外广告招牌公司都交换广告。因为全世界 1500 家旅馆都可以通用，所以非常受欢迎。
