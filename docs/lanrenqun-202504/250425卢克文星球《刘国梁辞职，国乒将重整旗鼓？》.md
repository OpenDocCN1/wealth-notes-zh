

# 刘国梁辞职，国乒将重整旗鼓？

4月20日，澳门乒乓世界杯男单以巴西选手雨果的胜利落幕，这让很多球迷都有点绷不住。

足球踢不过巴西就算了，国球居然在家门口失手，这场耻辱性大败已经成为了这两天中国体育界最大的话题。

没想到，23日就出了更大的新闻——乒协第十届会员代表大会第二次会议审议通过刘国梁主席辞职，选举王励勤为新任主席，高元义、马龙为副主席。

相信很多球迷朋友会感到意外，2023年4月6日，刘国梁才二度当选乒协主席和法定代表人，乒协主席四年一届，任期未满换届，可是中国乒坛头一次。

刘国梁为何在届中辞职？是否是因为澳门败绩？

## 壹 急流勇退

四位老乒协主席（陈先、徐寅生、蔡振华和刘国梁）中，刘国梁绝对是大众最熟悉的一位。老球迷可能还亲眼见证过1999年世乒赛中，刘国梁达成首个超级满贯的辉煌历史。

年轻的球迷虽然无缘看他打球，但很多人也是看着他的得意门生“二王一马”长大的。

在“二王一马”时代，他就是神一般的教练，否则2017年他卸任主教练，改任乒协副主席时，也不会爆发马龙、许昕、樊振东三大主力退赛事件。能让运动员甘为教练退赛，刘国梁当时堪称德高望重。

虽然退赛风波一度把刘国梁推上风口浪尖，但2018年，刘国梁还是接替了恩师蔡振华，成为新任乒协主席。

次年，在他的推动下，国际乒联成立了WTT（世界乒乓球职业大联盟），2020年，又担任董事会主席至今。

从大满贯选手到金牌教练，再到乒协和WTT主席，刘国梁的三段职业生涯，不断再创辉煌。他这大半辈子对乒乓球运动作出的巨大贡献，也是有目共睹的。

不过月有阴晴圆缺，刘国梁在三段职业生涯中也都遭遇过坎坷：1999年尿检阳性风波，让他在世乒赛团体赛连败两局，几近崩溃；2004年雅典奥运会首次带队即告折戟，被韩国柳承敏夺了男单金牌。

刘国梁的第二届主席任期，似乎正是他的第三次坎坷。

“大头”王楚钦本来被刘国梁寄予厚望，培养他成为接替马龙、樊振东的国乒新一代主力，2021-2022年王楚钦足足斩获8个冠军，其中4个是男单，2023年7月4日的国际乒联排名中，王楚钦首次反超樊振东，问鼎男单世界第一，大有接班之势。

然而时至今日，王楚钦世界排名第二，最关键的三大赛——奥运会、世乒赛和世界杯单打荣誉却依旧是零，头几年还能说给年轻人时间，可现在都2025年了，给你机会，得中用呀。

新秀不出成绩，刘国梁很愁，王楚钦可是被寄予厚望的“京圈太子”，教练安排最好的，比赛优先考虑他，京圈上一个有此待遇的还是马龙。

给马龙砸资源，他真能还你个超级全满贯，给大头砸，就没那么灵了。25岁的王楚钦虽然双打混双是把好手，可三大赛单打还卡着，而刘国梁26岁就带着大满贯退役了。

即使恨铁不成钢，刘国梁还是没放弃王楚钦，在巴黎力挽狂澜的樊振东赛后反被“雪藏”，难免让人联想到樊振东的沪圈身份——2020年八一队解散两年后，樊振东受王励勤之邀，加盟上海队。

联系到巴黎奥运男团夺金后，上海市委贺电祝贺樊振东、马龙和王楚钦三人，北京市委贺电却在马龙、王楚钦后将樊振东含糊地用“队友”带过，京圈沪圈之争，恐怕不是空穴来风。

马龙能出成绩，捧他谁也没意见，但捧迟迟不出成绩的王楚钦，雪藏超级全满贯的樊振东，难免被质疑“唯京是举”，导致无人扛鼎，梯队建设青黄不接。

而且，刘国梁虽然一再强调反对体坛饭圈乱象，舆论却普遍质疑他对王楚钦频繁带货、代言和饭圈炒CP“网开一面”。商业行为多，网上流量大，饭圈乱象也难以控制，刘国梁的管控力度，显然不孚众望。

除此之外，去年年末马龙、樊振东和陈梦退出世界排名，引发了对国际乒联“不参赛就罚款”制度的广泛抗议，刘国梁作为第一副主席也成为众矢之的。

今年2月WTT取消强制参赛，并赋予奥运冠军外卡的新规，背后自然有刘国梁出力，但如今龙胖梦三人仍未复出。对他的争议也未平息。

刘国梁搞WTT赛事，是为了提高乒乓球运动职业化和商业化，让运动员参与有更多比赛打，有更多奖金赚，提升乒乓球运动影响力，这也是“养狼计划”的环节。

仅今年2月的新加坡大满贯，总奖金就达150万美元，男单冠军林诗栋和女单冠军孙颖莎都拿了7.5万美元的大奖，还有持平奥运会和世乒赛的2000积分，可谓奖励丰厚。

但WTT赛事虽然是体坛盛事，然而也暴露了众多问题：比赛多，惩罚严，重积分。

仅今年，WTT就有4站大满贯、6站冠军赛、总决赛以及多级别挑战赛，赛程密集，运动员压力山大。

再加上去年新规，致使龙胖梦三位世界冠军退出排名，无疑削弱了乒坛活力。

WTT商业赛积分奖金丰厚，使很多运动员更重视商业赛而非三大赛，商业赛喧宾夺主，显然背离了举办初衷。

总之，刘国梁连任主席以来，舆论争议不断，难免身心俱疲。

早在去年9月，刘国梁就提出过辞职，希望卸下重担，而且他连续参与八届奥运，也疲惫不堪，只是在澳门失利后，辞职交接才正式完成。

网友猜测刘国梁辞职是由于澳门失利，显然不太靠谱。

首先，乒协主席这么大人事任免，两天搞不定；

其次，澳门赛后本身就是一个适合交接的节点，胜了是光荣交棒，败了，证明现在乒协需要换届调整，亡羊补牢，为时未晚。

现在公布的多哈名单，也是刘卸任前拟定的。

这并不是给王励勤挖坑，距多哈开赛不足一个月，国乒尚无把握争冠，刘国梁此举恰恰是为了避免王励勤因可能的失利而背锅。

刘的主动辞职，促成了乒协班子的平稳过渡。

## 贰 大力上任

刘国梁辞职后，“二王一马”这一代接棒也在情理之中，不过为啥是王励勤？

熟悉“大力”的人都知道，他是上海人，而且2009年，他就被任命为上海市乒羽中心主任助理，两年后升为副主任，2013年退役时又升为主任。

短短5年升主任，可谓一路飞升。

这些年来，大力对上海体育事业有突出贡献，想不被重用都难，2018年，任上海市体育局竞体处处长，并在刘国梁当选主席的第九届代表大会中当选副主席。

正如当年刘国梁在蔡振华时代当选副主席，之后接棒主席，当年的副主席王励勤又接任刘国梁的主席，颇有一种师徒接力的传承之感。

成为乒协副主席后，王励勤不仅要参与全国乒乓球发展建设，家乡也给了他更大的责任。2021年，上海市政府任命他为竞技体育训练管理中心主任，2022年，他又当选上海市乒乓球协会第十一届理事会会长。

2022年樊振东加盟上海队，就是王主任的手笔。当年4月，樊振东被保送上海交大，但异地求学多有不便，5月王励勤就发出邀请，将他引进至上海队，并帮助落户。

小胖投桃报李，为上海队斩获2022年全锦赛单打冠军，携手许昕勇夺乒超联赛男团亚军。

在樊振东受伤病困扰时，还是王励勤亲自安排上海顶尖医疗团队助其康复，还安排了仅次于许昕的赵子豪为其陪练，樊振东的巴黎单打金牌，可以说有一半是王励勤的。

巴黎夺金后，樊振东第一个找的人，就是看台上的王励勤，王励勤蹲下轻抚樊振东脸颊的场面，也令无数球迷感动。

大力爱才惜才，小胖知恩图报，称得上一段乒坛佳话。

然而京圈和沪圈不对付，小胖和大力如同千里马和伯乐，感情非常深厚，谁都知道小胖是大力的兵。

因此即使战功赫赫，他在国乒享受的资源，也远不如王楚钦。

而且，樊振东反对饭圈营销和过度商业化，还坚持“三不原则”（不戴智能设备、不印商业logo、不配合CP营销），保护个人隐私，这与刘国梁提出的“职业化必须让渡部分个人权益”观点颇有矛盾。

樊振东坚持运动员自主权，自然和刘国梁的职业化理念不合，国乒新老两代人，思想冲突是难以避免的，倒不全是圈子的问题。

某种意义上，刘国梁辞职也是意识到传统的“铁腕治军”不再适应新生代运动员，国乒的管理思路，是时候调整了。

而王励勤刚好在两代人之间，既有老一辈技术为重的硬派风格，又更能体谅年轻运动员的难处，管理人性化，所以乒协更新换代，更有利于带好新兵，做好梯队建设。

再说到副主席马龙，他去年9月才被任命为北京市顺义区青年联合会副主席，虽然和体育没啥关系，但也积累了宝贵的行政工作经验，联想到刘国梁也是在9月向总局领导辞职，给马龙的安排，可能早在为他担任乒协副主席做铺垫了。

经验丰富的大力当主席，新人马龙当副主席，是一个很妥当的安排，二人都是刘国梁弟子，而且一位沪圈一位京圈，既能改变一家独大带来的弊端，又能协调二者关系，缓和矛盾，共同建设国乒。

更令球迷欣喜的是，马龙将参加今年11月的全运会，“副主席正在热身”不再是玩笑。

当然，副主席马龙继续领队洛杉矶还是不太现实，球迷朋友最关心的，可能还是当打之年的樊振东何时复出？王励勤要达成洛杉矶奥运六块金牌的目标，势必重新起用樊振东，他的复出只是时间问题。

而不参加多哈世乒赛，主要是由于大赛需要竞技状态，来不及恢复，万一失利，今后再启用樊振东将面临舆论压力。

不过可以肯定，能者为王的背景下，樊振东能获得更多资源来进行恢复训练，以备洛杉矶之战，即使今年不行，明年的世界排名，樊振东也极有可能“王者归来”。

至于王楚钦、林诗栋，更需要在多哈拼一拼，证明自己。

他们是有实力的，但相比被刘国梁当年夸过“有打败马龙张继科的理想、信心、野心”的樊振东，“只有一点”的王楚钦和新人林诗栋，心态上急需锻炼。

新的梯队建设，有能力的老中青三代都要有，青训新人，也要狠抓。职业化商业化是大势所趋，但带来的弊病，还需要王励勤、马龙和国际舞台上的刘国梁共同纠正。

重振国乒，还需努力，希望乒协的这次“换血”，能吹起洛杉矶周期的新风。
