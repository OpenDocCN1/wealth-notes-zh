

# 面对美国104%的关税，中国会怎么反制？

4 月 8 日晚，特朗普因为中国 34% 的报复性关税而加征的 50% 的关税，正式生效了，这样算下来，美国对中国关税已经加到了 104%。

显然，贸易战已经大大升级了。

对这种威胁，中国丝毫不怂，表态说“如果美方一意孤行，中方必将奉陪到底。”也就是说，针对这 50% 的关税，中国也还会有进一步的反制措施。

那么，中国会怎样“奉陪到底”呢？

## 1

中国的反制措施，像特朗普那样对等加 50% 是不行的。

一方面，中国进口美国商品，其实就三类：电子类（芯片、显卡、一些高精尖设备等）、能源、农产品。

能源和农产品都好说，再多加也没关系，反正有替代品。但有的电子类产品还真的替代不了，所以再加关税相当于自己吃亏。

另一方面，在中国加美国关税其实已经到顶的情况下，光加关税对特朗普伤害不大，要反制，必须要真正让特朗普感到疼才行。

目前，市面上流传着六大反制措施的观点，这六大反制措施，完美体现了上述两点。

- 第一，大幅加征美大豆等农产品关税。

说个冷知识，虽然中国是农业大国，但在大豆方面，极度依赖进口。2024年，中国消耗大豆1.2亿吨，但国产大豆只有2000万吨，也就是说，83%的大豆都是进口的，其中每年要花900亿人民币来买美国大豆。

不过，反过来说，中国对美国大豆的巨大进口量，现在成了中国手中的巨大筹码。

前一阵，中国已经宣布对所有美国商品加征34%的关税，再叠加3月初单独对美国大豆加征的10%关税，已经到了44%，如果这次再加码的话，美国大豆就彻底别想往中国卖了。

中国市场上的大豆空缺，中国可以找巴西、俄罗斯来填补。但美国一时半会上哪儿找能吃下几千万吨大豆的买家去？

- 第二，禁止美禽肉输华。

长期以来，美国的规模化养鸡技术都是世界顶尖的，在国际鸡肉市场上是 top 1，也是中国重要的鸡肉进口来源国之一，2024年美国禽肉占中国进口量15%。

和大豆的情况差不多，一旦中国在现有的44%关税基础上再加关税，美国的禽肉出口就会再次面临巨大打击。

而且，就算像麦当劳肯德基这样的美国企业仍然坚持进口，也不是他们想进口就进口的问题了，美国的养殖业滥用药物非常普遍（比如台湾人最喜欢吃的莱猪），如果中国想针对美国禽肉，直接把某些药物列入禁止进口清单就行了。

这样一来，基本上美国禽肉就别想往中国卖了。

- 第三，暂停中美芬太尼合作。

说实话，芬太尼问题和中国一点关系都没有，完全是特朗普为了加关税找的借口，中国人生产的所谓4-ANPP、NPP之类的“芬太尼前体”都是合法化学品，压根没想着美国人会买去造毒品啊。

> 你买了一把菜刀杀了人，难道还要抱怨卖菜刀的么？

所以，特朗普的指控完全说不通。但是呢，本着人道主义的态度，中国还是配合美国做了很多工作，比如中国对所有芬太尼类物质实施整类列管，建立了涵盖生产、流通和进出口各个环节的监管体系，而且还在寄递行业施行“实名收寄、收寄验视、过机安检”制度，堵住了芬太尼出口渠道。现在嘛，我管芬太尼，你给我加关税；我不管芬太尼，你还是给我加关税。那我为啥还要管？

信不信我把美国市场上的芬太尼价格彻底打下来？让全体美国人都能享受到特朗普给他们带来的福利？

- 第四，服贸领域反制措施。

特朗普整天嚷嚷着中国对美的一万亿顺差（其实只有 3612 亿美元）是不公平，但有意思的是，他对美国在服务贸易方面的 2268.70 亿美元顺差，只字不提。

啥叫服务贸易呢？举个例子你就明白了。

比如，中国人去美国上学交学费，这就是服务贸易。

中国人看 NBA 要交费，还是服务贸易。

中国人聘请美国英语老师、美国球员、美国咨询师、美国会计等等，更是服务贸易。

相对普通的商品贸易，服务贸易的利润率非常非常高。

比如我要给美国卖商品，我要买原材料吧？要投入资金买设备建厂吧？还要承担人力费用，生产出来之后还要花钱运输、仓储、保险，等商品卖到美国，能有 5%的利润率就谢天谢地了。

服务贸易就轻松多了。

像金融服务、技术咨询、法律服务这些，主要成本就是人力成本。一个专业的金融顾问或者律师，能凭借自己的知识和技能开展服务贸易，根本不需要大量原材料和生产设备，也没有复杂的运输环节，虽然人力成本高，但创造的利润也高啊。

如果中国对美国的服务贸易动手，比如不再承认美国文科专业学历，停止美国律师、咨询师和会计的在华资质，禁止中国企业与美国企业服务贸易，那才真的会打疼美国。毕竟大豆+禽肉加起来进口额才几百亿，可光服务贸易这一项，都有数千亿！

- 第五，禁止进口美国电影。

电影其实也算是服务贸易的一种，早些年，好莱坞电影每年能从中国捞走很多钱，这些年随着中国电影的崛起，这种局面才慢慢被改变，一年顶多从中国拿走个几亿美元。

不过，美国电影的 IP 授权，却是一笔不小的收入。

比如，漫威系列电影爆火后，仅漫威英雄的各类手办、模型周边就卖出 230 万套，还有美国环球影城，一年有 1000 万中国人去玩，这能给美国带来多少收入？

最关键的是这种 IP 授权，美国人不需要干一点工作，全程都是中国人在干，美国人躺着收钱就行，何其轻松？

现在如果中国禁了美国电影再禁了这些 IP 授权费（不再给美国人交钱了），恐怕美国人就要急得跳脚了。

- 第六，调查美企在华知识产权获益情况。

啥叫知识产权获益呢？

我们再举个例子，过去 40 年，美国一直凭借其技术垄断地位，长期向全球征收“知识税”：

从微软的 Windows、苹果的 iOS、高通的通信专利，到 Oracle 的数据库、Adobe 的设计软件、特斯拉的 Autopilot 系统……全球企业每生产一台设备、开发一款软件，甚至使用一个算法，都要向美国支付高昂的专利费、授权费、渠道费等等。

而中国，就是最大“纳税人”，仅微软一家，每年都能从中国卷走 30 亿美元。还有工业软件领域，比如 CAD、catia、edgecam 等等工业软件，因为替代选择不多、国产软件兼容性较差等原因，每年都要从中国获取数以亿计的使用费和授权费。

此外，中国生产某些零部件，只要使用了美国的专利，也要交专利费。美国相当于啥也不干，就能白白从中国拿走一大笔钱。

这些行为，是否存在滥用垄断地位获取暴利呢？

肯定有的。

总之，这六条针对的都是美国痛点，有特朗普的票仓，也有具有强大游说能力的跨国企业，更有华尔街资本，这一切的目的，都是倒逼这些利益群体站出来，通过各种力量逼特朗普改变关税政策，最终把中美关系掰回正轨。

## 2

那么，如果中国真的施加了再次的反制措施（可能不限于这六大措施），未来双方的博弈会向哪个方向发展？

从现在的情况看，双方都已经没有退路，只会螺旋式升级。因为全世界都在看着中美。

对中国来说，中国是最强硬的一个反制国家，事实上起到了一个反关税旗手的作用，寄托着所有被加关税国家的期望。这些国家大部分是拖字诀，就想让中国试试美国的成色，自己再做后续的决定。

中国能退么？绝对不能。

而对美国来说，中国就是关税战最难啃的一个骨头，把中国逼服了，其他国家不在话下，如果搞不定中国，其他国家在对美谈判时就会更有底气。

所以，如果中国在 50% 关税后选择反制，特朗普也一定会再次加码，而中国必须提前做好准备。

那么，美国会出台什么新的措施呢？首先，美国也清楚，104%关税之后，现在已经事实脱钩了，对华再加关税已经没有意义，也吓不住中国，所以也会和中国一样，在其他领域出招。

比如，建立一个排他的关税同盟。

目前，从特朗普在对等关税中排除加拿大和墨西哥来看，显然是想重签北美贸易协议，组建一个北美关税同盟，对内 0 关税，对外高关税。

那么，如果特朗普把这个关税同盟扩大呢？谁如果想加入这个关税同盟，享受零关税，就要对中国也加上高额关税呢？

只要特朗普开这个口子，世界上会有无数国家将毫无心理负担地出卖中国，日韩就不说了，就连现在正忙着反制的欧盟，也一定会如此。事实上，已经有国家开始这么干了，比如越南，在 4 月 6 日对中国合金钢镀层板祭出 37.13%的临时反倾销税，这已是半年内第三次针对中国钢铁产品的关税行动。

特朗普的目的，就是把中国排除出国际贸易体系之外，彻底断绝中国出口。

说实话，这会让中国非常难受。

只不过，这个关税同盟的可能性太低，毕竟零关税等于冲垮美国仅存的制造业，红脖子不得发癫。连 TPP 都搞不成，大规模零关税联盟，就更不用说了。

当然，特朗普深谙极限施压的精髓，出招绝对不会只有这一招，中国持有的美债，也可能是动手的方向。特朗普不会直接宣布没收、冻结或者作废中国持有的美债，不是特朗普不想这么干，是不能这么干。

一方面是中国持有的美债除直接购买的，还有从他国手里买来的，不记名，特朗普没法精准识别出哪些是中国持有的美债。另一方面，美债本身就是信用债，美国随意没收美债，那美债信用就坍塌了，以后谁还敢买？特朗普会从另外的角度下手：征税。

目前，已经有美国媒体爆出猛料，说特朗普计划对外国持有的金融资产征税。也就是说，你买了美债，赚了利息，你就要向美国交税。

既然是交税，那税率自然也是特朗普说了算了，比如，中国这样的“不友好国家”，税率高一些，给你收个百分之七八十。其他友好国家，给你收个百分之二三十，这样既打击了中国，又能再捞一笔税收。

不过呢，中国还真的未必怕这一招。

之前中美关系有两个压舱石，一是贸易，二是中国持有的美债。

现在贸易废了，美国又给中国持有的美债加税，买美债都无利可图了，还留着干嘛？

其实中国这几年一直在抛售美债，从最高点到现在已经抛售了数千亿美元，现在持有的大概也就7000多亿美元的样子，不过因为之前都是慢慢抛的，所以引发的波动不大。

但如果中美贸易战打到不可收拾的程度，中国不排除会大量抛售美债，让美国也尝尝金融战的味道。

一方面，抛售美债会导致美债价格急剧下跌，那么以后谁还会借钱给美国？

另一方面，抛售美债导致债券收益率大幅上升，以10年期美国国债为例，抛售可能导致收益率上升0.5%-1%，直接推高美国国内的借贷成本，导致未来10年美国利息增加1.5-3万亿美元。这对债台高筑的美国政府来说，可以说是雪上加霜了。

所以，从政策上来看，双方眼前都会拼命加注，拼命出牌来让对方感到痛苦，逼对方屈服。而这一过程，注定不是短暂的，而是漫长的，一直到一方扛不住服软为止。

现在，到了拼血条的时候了。
