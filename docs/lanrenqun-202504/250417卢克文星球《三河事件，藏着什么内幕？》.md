

# 三河事件，藏着什么内幕？

4月15日，随着一纸通报，闹得沸沸扬扬的三河市改招牌事件终于尘埃落定。

但是，三河市市委书记被免职，并不能解答所有人心中的疑问。

这个市委书记到底为啥要改招牌？背后藏着什么内幕，又暴露了什么问题呢？

首先要明确一点，事情有没有网上传的那么玄乎？没有。

毕竟在这个自媒体时代，事情越奇葩流量越高，所以改招牌事件在网上传播过程中，必然会产生走样和夸大的情况，让人产生误解。

比如所谓“换招牌是宗教原因”，其实完全和宗教没关系。稍微懂点宗教事务的，都能看得出来招牌的绿色和宗教的绿色根本就不是一个色号。

比如所谓“单色警徽”“单色国徽”是想搞“江山变色”的说法，也有点上纲上线了，单色警徽并不违规。不信大家可以搜索一下国家公安部大楼，挂的也是未上色的单色警徽。还有所有警察头顶的帽徽包括里面的国徽，也都是单色的。拿这个说事完全站不住脚。

还有所谓三河全都换了招牌，也有点夸大。如果你现在去三河看看就会发现，没换的招牌比比皆是，就算换了招牌的，也不都是绿色。绿招牌主要集中在央美大街附近，比如著名的“绿雪冰城”，就是在央美大街上。

至于风水一说，没法证实也没法证伪，暂不做讨论。澄清这些，并不是给三河洗地，主要是想排除一些错误信息干扰，回归事情本源。

那么为啥市委书记不去琢磨干部，非要去琢磨招牌呢？

也许，我们可以从这个市委书记的经历找到答案。

市委书记付顺义，1975年生，今年50岁，要说快吧？50岁到县处级，明显不快，这是因为他年轻的时候有点耽误了。

1998年，付顺义从河北经贸大学货币银行专业毕业，进入秦皇岛经济技术开发区总公司工作，但没拿到编制，所以官网履历只有工作单位没有职务，人事关系挂靠在了昌黎县人才交流中心。

2002年，是付顺义的一个转折点。也许是贵人赏识，把付顺义从管委会调进了秦皇岛市政府，定为科员。这样来算，付顺义比一毕业就考进政府的大学生，耽误了整整4年。

还好，此后付顺义一路顺风顺水，花了9年时间，一路从科员干到了市政府办公厅综合二处处长和督查室主任，解决了副处级。

2011年4月，付顺义下放昌黎县任县委常委、办公室主任，历经秦皇岛市北戴河区委副书记，最后在2019年1月，付顺义迎来关键晋升，担任秦皇岛市抚宁区委副书记、区长，解决了正处。4个月后，履新到固安县当县长，总算是能主政一方了。

从这段任职经历来看，付顺义显然是有人赏识的，要不然不会晋升顺利。但这个赏识的人级别显然不高，只能把他扶持到正处级、县主官已经到极限了。

剩下的路，可能就要付顺义自己走了。

但是怎么走呢？

这里需要介绍一下河北这些靠近京津的县市的特点了。

古人有云，前生不善，今生知县；前生作恶，知县附郭，恶贯满盈，附郭省城。

简单来说就是，上辈子没干好事，这辈子就要当“附郭省城”（也就是紧挨着省城）那个县的知县。在这里当官，虽然也算主政一方，但因在上级眼皮子底下，所以天天小心翼翼、如履薄冰。

固安和三河，都属于“附郭”的县市，而且附郭的还不是省城，而是首都。

河北人都知道，河北就是“北京护城河”，无论什么资源和机会，都要优先京畿。北京有什么要求，河北必须第一时间满足。

那么作为该地的主官，想要出成绩拿政绩，也就难上加难了。

你要搞重工业，对不起，环保一条卡死你。你要搞科技，对不起，你竞争不过京津。你要搞加工厂，对不起，当地工资太低，人都跑京津挣钱去了。

经济搞不上去，怎么进步呢？只能从别的地方想办法。

比如，固安没什么经济支柱，要想发展经济，只能靠北京吃北京，请来专业人士把城市好好设计一下，城市面貌搞好一点，提升一下城市格局，多吸引一点北京人来买房子。

不信我们可以去固安看看，固安的城市建设不错，公园绿地、建筑风格、整体格调，在环京独树一帜，完全不像县城。

就算房地产下行，房子卖不动了，只要城市面貌搞好，在小红书上宣传一波，固安真的是一个宝藏拍照打卡地啊，文旅这波流量不就能吃到了？

而且，万一哪天撞大运，领导路过固安（北京大兴国际机场一部分就在固安），看见固安的城市面貌别具一格，夸赞几句，进步的机会不就有了么？

所以，在付顺义任上，固安的城市面貌工作一直是重中之重，《固安县城市规划建设管理实施导则》出台。

如果我们仔细看一下这份导则，就会发现一些有意思的细节。

比如，要求字体不允许用通用电脑体，应该有设计（也就是艺术字），不允许用红蓝底色或字样。比如，牌匾颜色不得简单一致，应有变化，牌匾一般应有亮化效果，商业街区和示范路必须亮化等等。

说实话，这个导则还是有一定道理的，但从群众的角度，我的招牌虽然土，买卖照样做，土一点也不碍事。

你还别说，付顺义挺有官运的，固安城市面貌刚搞出了点样子，2024年3月，三河燕郊就发生了天然气管道爆炸事件，这起事故伤亡不算大，但因为工作人员推搡央视记者，被闹得人尽皆知。

面对汹涌舆情，三河市委书记刘连杰黯然调离，付顺义被调来三河救火。你要是付顺义，你会咋想？河北这么多县处级，为啥轮上我了？是不是我搞的市容市貌整治起作用了？

所以到任之后，付顺义不出意外地，又把“提升城市格调”的习惯带到了三河。

巧了，要论“提升城市格调”，三河就是比固安有优势，因为中央美术学院城市设计学院的燕郊校区，就在三河。

有这资源，干嘛不用？于是三河就把燕郊校区北侧的“北蔡街”更名为“央美大街”，和央美共同启动了“央美大街”环境改造工程。

付顺义对央美大街非常重视，显然是奔着打造成燕郊新地标去的。

官方媒体的措辞是：助力城市文化品位提升，为市民带来更加优质的文化体验，吸引更多游客前来感受燕郊独特的艺术魅力。

显然，燕郊就是想走网红路线，以此作为主官的政绩。

毕竟，付顺义已经50岁了，年龄不占优势了。想要进步，就要搏一搏，搏一搏，单车才能变摩托啊。

只不过，付顺义犯了两个错误。

第一个错误，央美的设计，有点不接地气。

“中央美术学院”的官方报道中有一句：“中央美术学院将与三河市委市政府、燕郊高新区携手并肩，共同设计、打造燕郊城市艺术品牌大街。”

看到没？央美大街的设计方案，是中央美术学院参与了的，主题是“学院风和国际化”。

但问题在于，对于央美的设计，老百姓买不买单？老百姓可能觉得，央美没搬过来的时候我的招牌就在这里了，凭啥央美来了，我就要换招牌？我咋觉得你设计的招牌还没我原来的好呢？

第二个错误，钱。

说实话，如果是政府出钱，商户换招牌，可能阻力也没那么大（固安县就是这么搞的），大家顶多吐槽几句折腾。

但现在呢？政府没钱，又为了统一效果让商户自己花钱换招牌，就没那么愿意了，一个招牌便宜的几百块，贵的几千，谁愿意花这个冤枉钱？

也可能是因为这项工作进度缓慢，相关业务部门挨了市委书记批，所以最后城管和市监开始简单粗暴地强制要求换招牌，最终才酿成了这次舆情风暴。

### 2

这起舆情，到底暴露了什么问题？

首先，就是很多基层官员的水平问题。

说实话，现在中国官场的主要矛盾，已经成为了基层官员想干事想要进步，但自己水平和能力都不足以支撑自己干事之间的矛盾。

以付顺义为例，他在主政一方之前，从事的都是机关工作，没有抓过经济、工业，也没有主抓过纪检、政法这种需要硬碰硬的工作。可以说其能力本身就不是那么全面的，或者说，你让他抓“面上”的工作行，但让他处理复杂问题，可能就想不那么周全了。

这其实就是很多从基层一点一点熬上来的官员的写照，想干事，但受学历、眼界影响，往往搞出令人啼笑皆非的事情来。

相对来说，城市建设出效果快，往往是基层官员最喜欢搞的事情。比如榆中县花了9个亿建设市民公园，安徽省淮南市建设12车道玉兰大道车却没几辆，还有贵州独山县明知道财政收入只有10个亿，却花2个亿建设水司楼事件等等，都反映了这个问题。

基层官员，想要政绩，可以理解，但需要记住一条：如果没能力把事情办好，那就别办事，否则办的事只会反噬自己。

其次，是县级干部的生态问题。

在这起事件中，明眼人都能看出这种简单粗暴地换招牌要出大事，但所有人似乎都在不折不扣地执行。

出现这个现象，只有两种可能。

第一种，是付顺义的权力极大，已经无人能制约了。

三河市虽然叫市，但其实是县级市，而县级市的市委书记，是省管干部，也就是说，三河市的上级廊坊市没有直接任免县委书记的能力。

上级难以监督，那本级就更难了。

很多人可能不了解县委书记的权力有多大，可以说，他是县域人事的最高决策者，无论是乡村干部、县直单位局长、副局长，都要县委书记拍板。因此，只要县委书记说句话，所有部门都要必须当成重要指示来办，没有人敢提出反对意见。

第二种，是有人在搞事情。

付顺义作为一个空降的书记，在本地没有势力，必然会遭遇本地官僚体系的掣肘。而且三河这个地方很特殊，有了三河履历，下一步当廊坊副市长进班子就有了助力，这必然会挡别人的路。

我们冷静一下仔细回想一下舆论，就会发现个奇怪现象。整个三河，似乎都在故意让事情激化，引发舆情。

这其实也是官僚体系的传统做法了，当你对一项工作不满的时候，你不能不干，因为不干要挨收拾，所以你需要大干特干，等事情激化了，自然有人去收拾上面。

比如，原本《导则》上说，可以用“浅灰、浅咖、玫瑰金、象牙白”等高级色，但你就让他用绿色，造成同一颜色的离谱效果。

比如，原本计划是一点一点做工作，但你就是马不停蹄地强拆强换，激起民愤。

最后，借老百姓的手机，把舆情传播出去，来向上级发难。

这一点，从舆情中的绿色十字，到PS的消防车，都能看出这件事背后不简单，似乎想故意把事情搞大。

当然，就算有人在搞事情，付顺义的应对也称不上合格。

一个县委书记，直接管着党委宣传部，这么点事情，都没有个预案么？出来解释一下为什么要换招牌，换招牌有什么好处很难么？就算公众不一定相信，起码也能平息一下舆情啊。可是有么？并没有！甚至全市连个统一的解答口径都没有。

了解舆情应对的都知道，如果没有官方统一的信息供给，那必然导致流言泛滥。得不到信息供给的记者只能四处乱问，再出于流量目的，把各个部门的答复添油加醋地加工一番，再次推爆舆情。

比如三河市监部门负责人说“蓝色太俗”，记者就写“领导说要脱俗”。

比如，记者致电燕郊开发区管委会，工作人员表示自己不负责此事（确实不是管委会负责的），于是答复“当时是哪个部门让你们换牌匾的，你找一下他们。”然后记者就写成了“谁让你拆的你找谁。”

这种推波助澜，难免火上浇油。

所以，可以说付顺义这次栽跟头，一方面是自己能力有限又爱瞎折腾，另一方面是三河整个体系和媒体共同作用的结果。
