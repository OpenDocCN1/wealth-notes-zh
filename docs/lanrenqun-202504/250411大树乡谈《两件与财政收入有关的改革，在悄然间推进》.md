

# 两件与财政收入有关的改革，在悄然间推进

250411 大树乡谈

有两件事需要放在一起说，那就是两办《关于完善价格治理机制的意见》和《税收征收管理法（修订征求意见稿）》，之所以放在一起，是因为都跟财政收入有关。只要提到价格改革和税收征管，其实基本就是推进物价上涨和增加税收，这是最核心、最直接的影响，就看怎么干，力度如何。这两个都是时隔多年出现的新进展。

前者的价格治理，过去关注度比较高，几乎年年提，但由于当年通胀太高，如果再搞价格改革也就是推进物价上涨，那社会负面影响太大，所以有些雷声大雨点小。这种价格改革的惯性持续到上一届的前几年，2015年的时候出台了《关于推进价格机制改革的若干意见》，在这份意见中提出了不少基本的改革理念，影响至今。

但2015年文件出了以后之后，除了少数领域，价格改革也基本停滞，毕竟从2018年之后中国通胀率又上去了，再者面对贸易战和疫情的压力，涨价也实在不好推进。直到去年才重新关注到价格改革，但主要关注的是公用事业价格改革，也就是居民水电气价格。

尤其是电价改革，这方面推进比较快，尤其适逢推进新能源变革，需要平衡火电与新能源、央地和央国企、民企之间的利益关系，所以上网电价改革上一直动作不断，主线是贯彻2015年提出的“管住中间，放开两头”。今年1月印发了《关于深化新能源上网电价市场化改革促进新能源高质量发展的通知》，要求新能源上网电价将全面由市场形成，不过这是远景目标，现阶段还是执行混合电价，逐步市场化，比如山东新一轮改革后，分布式光伏上网电价目前降到一度0.34元。

电价的市场化改革也是时代必须，因为不同于传统火电，新能源电价受科技和产业规模影响很大，这几年新能源发电在价格上已经低于火电，继续执行固定上网的价格机制就导致错配，所以必须市场化。

而居民端的水电气价格常年保持较低水平，这也是一个很头痛的难题。居民用电一直低于工商用电，也就成了逆市场化的工商用电补贴居民用电模式，从世纪初到现在，电价几乎没变，而且很多地方比如农村，电价实际还降了；而水也是财政补贴为主，目前居民交的包括污水处理费在内的水费，还不到真实成本的一半，尤其污水处理费，到现在全国多数城市还没达到国家要求的最低限，针对居民收钱，各地政府都有些发怵，但接下来又要推进供水质量提升、推进农村自来水管网建设，这都是钱；而气价涉及到安全问题，加上这几年推进管网升级和智能气表改造，相对好一点。

所以在小镇看来，别说中国不喜欢给居民发钱，仅居民水电气的大规模财政补贴，就花多少钱，每年起码大几千亿。但现在财政紧张，很多地方迫切需要减少补贴，让价格回归市场化，尤其公用事业的价格需要涨上去，一切公用事业价格改革的核心就是涨价。

所以，别看这份文件涉及到价格改革的方方面面。比如分项第一部分“健全促进资源高效配置的市场价格形成机制”，把重点放在了市场环境营造上，还说要搞动态的价格调控机制，加强市场价格监管，还提到粮食、绿色电价、公共数据价格改革等等，无所不包，但最核心也是最重要的就是第二部分中一小部分的“公用事业价格机制”。

这也是最近几年政策尤其发改政策的特点，就是大而全，无所不包，成了大汇总、大目录，但这里面很多是提出了但并非短期内推进的重点。比如最近的提振消费就是类似情况。

因此最终还是要落脚在居民的公用事业价格上调上，而且提价客观上也有利于改善通缩问题。但是呢，也得考虑民心看法，总之这事不太好办，预计也就先从阶梯上调开始。

更值得关注的其实还是税收征管。前些年大搞减税降费，效果确实不错，但是之后就开始强调稳税基，毕竟财政缺口太大了，一边减税降费，一边要求多做事，那钱从哪里来呢？

还要注意一个非常关键的点，那就是中国税收征收能力长期不高，所以税收基本是针对大企业的间接税，很缺乏直接税征收能力，在土地财政和经济中高速发展的时候，这个问题还相对不严重。所以税收征收管理法上一次修订已经是2001年了，但之后20多年出现了巨变，最大的变化就是新技术的应用，网络技术、信息技术、智能技术等大规模应用在税收上，尤其推进纸质票据电子化，大大提高了税收征管的能力。

最终的标志性突破就是金税四期，金税四期极大扩大了数据来源，查税不仅仅局限在税务体系，更融入了更多其他部门数据，而且越来越多，这跟2017年开始的公务员财产申报审查是一致的：另一个重点就是变主动审查为被动审查，大幅减少人为因素。过去查税是办税人员自己去查，有很多人为因素，而且效率也很低，但金税四期以后，由系统自行筛查，认为有问题的直接弹出预警，要求办税人员根据预警去查办，这就有些类似网上很多人期待的“AI治理”。

这几年已经有很多成果，一些网红、明星被查税，关键线索就来自金税四期的大数据比对分析。最近司马南等大V也开始进入被打击的范围，这些人的偷税漏税方式太低级了，基本就是通过个人账户收款隐匿应税收入或者转变收入虚假转换收入性质，后者特别常见，也就是通过注册公司尤其个体工商户，把个人劳务所得转换为生产经营所得。这么干的同时必然会存在违法公转私、虚开发票等行为。

个税上限是45%税率，个人劳务所得享受20%减免，实际上限是36%，而个体工商户生产经营税是35%，乍一看差不多，但在一些税收洼地搞个体工商户核定征收，可以降到总税额的10%，于是35%的上限税率就降到了3.5%；再加上个体工商户还享受国家的税费优待，所以就大规模逃税了。司马南逃税600万，最后加上罚款一共是900万，还有之前的范冰冰、郑爽都是一样的问题。

但注意，除了个人所得部分，还有企业部分，搞这种偷税漏税的，企业纳税肯定也不会乖乖的。

最近税务公布了五起偷逃税款被处罚案件，最值得关注的就是第一起网络主播乐传曲也就是“曲曲大女人”偷逃税款案。“曲曲大女人”一直教女性所谓的“向上择偶”，2023年底就被全网封禁，但她早就完成了线下引流，照样可以从事私域咨询，比如加群费高达98800元。

这次就通过大数据比对发现，“曲曲大女人”两年申报个人收入仅有60余万元，跟她的银行账户流水和消费情况严重不符，所以大概率触发了金税四期系统报警。只要被关注到，证据太容易找了，所以案件通报中就提到检查人员接到立案信息后进行走访调研和资料调取，很容易就发现了“曲曲大女人”不是传统的带货，而是私域引流付费，还找亲戚朋友开皮包公司。

这种事情在互联网领域普遍存在，可以说几乎所有的头部、腰部主播，都存在不同程度的偷税漏税问题。就算是图文领域，也有不少搞很多皮包公司，一查公司所有人，就那三四个人，除了分散注册、降低账号风险，很重要的就是享受国家税收优惠。顺带一提，小镇始终坚持个税缴纳，不搞这套虚头巴脑的，多交税是公民的荣耀而不是负担，毕竟收入高了就理所当然要承担更高社会责任，言行必须一致。

税收征管看的是本质，不是说披个外皮就行了。自媒体或者主播、网红这一行，虽然也能雇用几个人，但其收入跟提供的就业严重不符。国家给小微企业、个体工商户提供税收减免、核定征收，就是为了支持小本经营、促进就业，但是内容生产这个领域，本质就是个人劳务所得，非得批着公司外皮蹭国家优待，肯定要成为被打击的重点。

一个基本的运行规则是：提供多少税收和就业，就能支撑多少的收入。如果收入超过提供的税收和就业太多，那别管怎么获得的，就是个人劳务所得，如果逃个税，早晚被查，而且税收可不管什么不溯及既往。

现实已经大大超越了2001年的旧法，要求法治必须跟进，于是这次全面修订就应运而生，要把这几年的新变化、新经验上升为法。

这次税收征管法修订，最核心的变化就是大大加强对平台经济的税收征管，在此前电子票据、金税四期等基础上，进一步加强大数据查税。最近查司马南、曲曲大女人，背后都是大数据查税的威力。客观地说，未来税收征管能力还会进一步提升，还可以引入AI大模型，虽然大模型的精确度不高，但本来就只是要求系统检索、报警，具体查办还是人工进行，那么引入大模型后，效率就更高了。

司马南罚了900万，曲曲大女人目前仅个税罚了758万，接下来肯定还要查相关的企业偷税漏税。这笔钱可真的不少了，全国有多少明星、网红、大V偷税漏税呢？而且偷税漏税的伎俩极为低下，简直就是一个模子出来的，都不知道是谁交的。

这一块跟价格改革有些类似，都是新技术、新业态催生改革。价格改革核心的电价市场化是因为新能源变革，而税收征管则是平台经济、数字经济和相关技术变革带来的影响。于是原本分散的个人收入，在数字时代变得跟间接税一样好收，何况如网络主播等已经开始冲击传统大平台的电商模式，如果再不加强税收征管，本质就是税基被侵蚀，破坏公平的市场竞争秩序，恶化贫富差距。尤其主播大V具有极强的社会影响力，如果是一群连税都不足额缴纳的人在干，其言行必然掺杂私货，不利于社会风气向上。

比如网络主播动辄要30%甚至50%以上的抽成，很重要的原因就是逃税，这是不对的，也导致主播卖货领域，假冒伪劣极为泛滥。

只要加强税收征收管理，把这些偷逃税的新领域管起来，税收立刻就能有明显提升，网红、明星、大V们过去几年吞进去多少税款，慢慢的都得还回来。

当人的智商、道德和财富不匹配的时候，财富早晚会以某种方式回流到社会。
