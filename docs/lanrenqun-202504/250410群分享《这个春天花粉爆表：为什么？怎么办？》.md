

# 这个春天花粉爆表：为什么？怎么办？

250410

整理：公众号懒人搜索，懒人专属群独享懒人微信：lazyhelper

![](img/3964adcc98c8da822cd32d0504287924_0_0.png)

你有没有感觉到，这个春天的花粉特别多？据说最近北方不少医院，过敏患者的接诊量都不低。前段时间，网上还流传一个视频，拍的是北京天坛公园，大风吹过，漫天花粉，乍一看就跟沙尘暴差不多。

但是，跟整个季节的花粉浓度相比，这才哪到哪。北京协和医院副主任医师王子熹说，花粉季时，一平方英里，也就是大概2.6平方公里的土地上空，可以收集到16吨花粉。16吨是什么概念？一头成年雄性亚洲象的平均体重是4吨，也就是有四头大象那么重的花粉飘在一平方英里的上空。

再加上北方干燥，花粉很难被墙面路面吸附，风一吹就会继续飘在空气中。于是，千万过敏者的噩梦就这么开始了。根据北京气象局发布的数据，北京3月底，连续9天，花粉浓度都处于“很高”的级别。

今天，咱们就聊聊今年的花粉季。我们主要回答这么几个问题。

## 第一，今年的花粉季是个什么水平？简单说，这是一个又早又长的花粉季。

根据气象部门的监测数据，今年花粉季的开始期和高峰期都比去年提前了。起点和高峰都比去年早了一周左右。有人可能会说，早点开始难道不好吗？毕竟早开始早结束啊。

不好意思，花粉可没有那么讲武德。花粉季其实是分阶段到来的，一波未平一波又起。三月中旬是第一波高峰，主角是柏科，比如圆柏，这波高峰会在4月初有所下降。但是紧接着，柏科刚走，松科就开始发挥了。4月中下旬，松科树木将创造花粉的第二波高峰，一般会持续到5月下旬。

当然，说到这再插一句，所谓的花粉过敏，准确说，它的始作俑者其实不是我们通常认为的花，而是树。因为花的花粉普遍颗粒较大，传播距离有限。但树产生的花粉颗粒更小，而且量大，风一吹就到处都是。

比如网上流传的天坛公园的视频，其中散播花粉的就是圆柏树，这也是很多北方城市的花粉大户。圆柏属于雌雄异株植物，只有雄株会散粉。而且圆柏的花粉直径只有28微米，质量又小，这让它能够长时间飘浮在空中。

那么，为什么很多人觉得今年的花粉特别多呢？比如北京，网上流传一个说法，说是因为北京在前几年为了增加绿化，种植了大量的圆柏。而几年过去，今年圆柏正好到了散粉的年纪。但是，也有人查证过，发现这个说法可能不准确。北京确实有不少柏树，总计700万株。而松柏需要三五年才开始成熟散粉。但在2019—2020年，北京并没有大规模种植柏树的记录。

而且相反，北京还在号召控制柏树的种植。2021年，北京市园林绿化局修订了《北京市主要林木目录》，将包括圆柏在内的刺柏属，从目录中直接剔除。并且特别强调，在新增绿化项目中，要避免在人员集中的地方种植容易导致过敏的树种，还要求新建园林绿化绿化工程禁止使用圆柏和侧柏雄株。

你看，圆柏散粉年的说法，似乎靠不住。那么，

### 今年的花粉到底为什么这么多呢？

#### 一来，可能是花粉本身有大小年之分。

北京市园林绿化科学研究院的丛日晨教授说，树木开花结果，分为大年小年，量大就是大年，量小就是小年。而从目前的情况看，今年可能是个大年。

#### 二来，这也许和气候有关。

《柳叶刀·行星健康》在2019年刊登过一项研究，分析了1990—2018年北半球17个国家的花粉数据。结果发现，一个地区的年均气温每升高 1°C，植物花粉产量增加 16.8%。

而根据新华社的数据，2024 年我国平均气温 10.9°C，往年平均是 9.89°C，高了 1.01°C，并且创下 1961 年以来的历史新高。今年的全年温度数据尽管还没出，但从 3 月的情况看，一些日期的温度确实要高过往年。这也直接导致了花粉产量增加。

注意，花粉变多不是咱们国内的个例。比如，《美国国家科学院院刊》曾经刊登过一项统计，1990 年至 2018 年间，北美花粉季节的长度增加了 20 天，花粉浓度增加了 21%。再比如日本，种植了大量的杉树，树龄超过 25 年的杉树会像圆柏一样产生大量花粉。2019 年日本花粉症发病率 42.5%，其中杉树花粉症占 38.8%，相当于每三个日本人里就有一个杉树花粉过敏，这也被称为日本的“国民病”。

之前还有研究机构预测，预计到 2050 年，全球过敏性患者将有 40 亿人。没错，未来全世界一半的人，可能会受到花粉的困扰。不少人感觉这几年的花粉更夸张，未必是错觉，这个趋势也许正在发生。

## 第二，回到咱们国内的北方，既然松柏科有这么多的花粉，当初又为什么要种它们呢？为什么不种别的植物呢？

### 这其实是地理环境决定的。一个城市的地理条件，圈定了它可选择的绿化树种。

首先，种植的树木最好成长很快，寿命要长。其次，为了降低保养成本，不能娇气，生命力要强，不需要太多后期打理。同时，从城市美观度的层面看，最好其中还能有三成的树是常青的。

就拿北京来说，早些年一度绿化率不足，那么种点什么好？这个树种必须得满足这么几个条件。你看，这些要求是不是都很合理？而在这些要求的整体约束下，以北京为代表的整体北方城市，能选择的树种其实并不多。而在这并不多的选项里，松柏和杨树就属于相对理想的选项。

松柏杨树不仅好养、常绿，而且还能遮阳造景。要知道，北京在 2012 年以前，即使把行道树、防风林带以及房前屋后的散生树木全算上，平原部分的森林覆盖率也不过 14.85%。而在松柏杨树的大规模加持下，2024年底，北京的森林覆盖率已经达到了 44.95%。

更何况，现存的树木中，有不少还是有文物价值的古树，比如北京就有 41000 多株古树，其中侧柏大概 22000 株，圆柏大概 6000 株。因此网上流传的通过砍树解决花粉的说法，可行性几乎是零。

听到这，可能有人又会说，不对啊。前面不是说过，树木只有雄株会散粉，那么改种雌株不就得了？不好意思，**雌株也有雌株的问题**。雌株虽然**不散粉，但它会开花结果，到时花果掉落在地面上，会给城市清洁增加难度**。雌株还会**飘絮，在干燥天气里可能成为火灾隐患**。

注意，我们想说的重点，可不是哪个方案一定对或者不对。而是面对一个复杂问题，可能很难有完美方案，很多现状都是取舍的结果。

那么，**难道我们拿花粉一点办法都没有吗？**也不是。目前，很多城市都在推进治理方案。

比如北京，首先，在居民区附近严格控制易致敏树种的种植。针对现存树木，在花粉高峰期用水枪喷淋，并且不定期对周边路面冲洗清扫，减少花粉季的影响。其次，在清理枯死树的时候，把树木替换为不产生花粉的雌株柏树，或是白蜡梅之类的树种。

**未来，我们还可能会挑选出更适合国内北方城市的树种，到时花粉问题是有可能解决的，但是需要一些时间。**

那么，回到现在，面对花粉问题，我们个人可以做点什么呢？这就是咱们要说的第三个重点。

**面对花粉问题，最有效的策略就是物理隔绝。**

首先，户外活动时要避开花粉传播的高峰期，可以通过观察树木的开花情况或是通过气象网站，查看本地的花粉预报。对易过敏体质来说，在花粉指数大于等于 3 级时，出门时就要做好防护措施。

怎么防护？普通的医用外科口罩就能达到很好的阻隔效果，不需要佩戴N90、N95。同时也要戴防护眼镜，因为花粉也能通过眼睛诱发过敏症状。除了口罩和防护眼镜之外，还有两种产品可以使用，一种叫花粉阻隔剂，另一种叫惰性纤维素粉，都是通过涂抹或喷洒在鼻部黏膜上，实现隔绝花粉的效果。同时，过敏的人还可以常备洗鼻器。洗鼻器把生理盐水送入鼻腔，可以把鼻腔中的过敏原和病菌冲出来，从而缓解过敏症状。

还有大量的证据表明，规律的有氧运动，尤其是游泳，可以增加身体免疫力，达到预防过敏的效果。还有减重，能够降低手部湿疹以及过敏性鼻炎的发病率。此外，冯雪老师还建议，注重饮食的多样化。因为多样化的饮食能够让肠道菌群更稳定，这能让我们的免疫系统起到更好的保护作用。

而回到城市层面，要想彻底解决这个问题，是一个漫长的过程。毕竟，城市是一个各类因素环环相扣的复杂系统，每个决策都要想办法在绿化、成本和环保之间掌握平衡。而气候变化和城市化，让这个问题变得更加复杂。
