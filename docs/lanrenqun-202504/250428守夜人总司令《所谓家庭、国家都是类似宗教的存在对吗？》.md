## 【学员提问】

所谓家庭、国家都是类似宗教的存在对吗？他们作为结构力量，形成共识，自我驱动自我强化，通过传导体系转嫁成本，包括对外转嫁或者自我奉献，而这些都是基因库构建强大工具完成对能量的摆取和转化的显性表达，以存续并向承载更高密度信息的基因进化，另外，追求基因数量、质量上，是否有优先级呢？

## 【司令回复】

一下子不明白你具体要问什么。从你杂乱的表述来看你混淆了底层的逻辑和上层的形态，为了形象的让你理解。你了解计算机的原理吗？今天计算机演绎出来的一切，如果层层往下的话，你就发现最原始的结构非常简单，但是计算机有一个明确的导向性，也就是存在一个天然的悖论。

我还是拿计算机体系来举例，因为这个更简单明了，电流强弱变化形成某一个节点的磁场变化从而就实现了 0 和 1 的存储，而这些 0 和 1 的有序组合就能形成指令和数据。

指令操作数据也操作指令本身，不管是操作指令还是操作数据，都是为了形成一个具有导向性的秩序，而这种秩序在各要素之间所搭建出来的关系就是一个结构。在这个秩序之下，结构内部的各个要素会形成相互支撑又相互制约的关系，互为表里互相抵消，还能形成稳定性，所以，任何结构都是对某种秩序的描述。当秩序不存在的时候，结构就坍塌了！

不管是道德体系还是宗教都是在做一件事情：以最低的成本来建立起一套秩序，在这套秩序的构建和维系过程，存在一个抽象又具体的东西，之所以说他抽象，正因为只存在于人的观念之中，说它具体是因为这种抽象的观念会作用于具体的个体身上，从而在个体与个体之间，个体与群体之间，群体与群体之间形成一种结构化的秩序，这种相互支撑又相互制约的关系，同时具备竞争与合作两个特征。

我还是拿计算机这个简单的模型来举例，而不要拿社会这个复杂的模型来处理。一个服务器要在单位时间内为更多的访问者提供某种服务，就需要有一段机制来实现数据共享，并扩大服务器的灵活性，然而，这种灵活性和数据共享，就必然会带来数据竞争和秩序的混乱。计算机系统为提供某种并发型的服务所构建出来的结构体系，就是在二者之间取得平衡，为了这种平衡而形成的一些约束，恰恰是为了保障秩序本身，当这种有约束的秩序存在的时候，系统所提供的服务才可以存在，当秩序坍塌之后，服务也就没有了！换而言之，这个结构所形成的秩序，本身就是为了提供这样的服务而存在！

然而，不是每一个使用者都有架构师的视角，每一个使用者都会从自己的角度出发，要求给自己更多的灵活性，要求解除施加在自己身上的各种约束，甚至会以破坏的方式来获取这种自由度，于是就会形成一种博弈，这种博弈所形成的消耗会让这套秩序所能提供的服务资源更加紧缺。而享受这套体系所提供服务的用户，只会本能的以更大的破坏性试图在存量中获取更多的部分，以缓解自身的焦虑和恐慌，直到让整个秩序失控结构彻底坍塌。

先说这么多吧，目前手头有事。你看理解多少，再梳理一下你的问题。
