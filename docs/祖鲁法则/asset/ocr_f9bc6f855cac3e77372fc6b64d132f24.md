# 2. 和成長率相比，本益比不高

截至1992年5月31日的年度預測盈餘為9.1便士，和前一年的7.3便士相比，增加1.8便士，年度成長率為25%。這裡我們會碰到一個小問題，9.1便士的每股盈餘必須向下調整，排除出售子公司貝利公司（ICS Bailev）50%股權的影響。公開說明書中清楚指出，貝利對工業控制服務集團450萬鎊的稅前盈餘預測貢獻為119萬鎊，賣掉50%股權後，其中一半會喪失，使預測的稅後盈餘從294萬鎊降為254萬鎊，經過調整後的平均加權股本每股獲利降為7.7便士。然而，預測中沒有考慮出售貝利公司50%股權會得到的現金收益，而且公開說明書在這麼接近會計年度結束時預測的獲利通常很保守，因此我覺得為了計算本益比，採用8便士的每股盈餘，能夠讓我安心。

因為工業控制服務集團會計年度的最後一個月是5月，評估時，採用1993年度的預估本益比相當合理。在安全系統市場不斷成長時，你可以合理預測未來幾年內，年度成長率應該會繼續維持25%，因此每股盈餘會從8便士提高為10便士，以150便士的股價計算，1993年度的預估本益比為15倍，因此，預估本益成長比是用15（預估本益比）除以25（成長率），得到的數字為0.6，很有吸引力。
