足以對股價產生重大影響的新因素主要有四種：

+   1. 新經營階層。
2. 新產品或新科技。
3. 整體產業的新事件，包括新法規。
4. 新併購。

新經營階層是最重要的因素，原因很簡單——傑出的新經營階層可能具有長遠而持續的影響。如果能力高強的新經營者掌控公司，他們的努力可能在未來很多年裡，都會創造優異的成果。

這方面有很多大家熟知的例子，韓森（James Hanson）和懷特（Gordon White）進入懷爾斯集團（Wiles Group）董事會，以及韓森公司前高級經理人哈欽斯加入湯金斯公司，是其中兩個例子。懷爾斯集團後來改名韓森集團，隨後的二十八年期裡，營業額從不到200萬鎊，飛躍成長為110億鎊；哈欽斯加入湯金斯公司的九年裡，公司營業額從600萬鎊激增為14億鎊。這些經營階層改變的好處持續很多年，到今天仍然持續。
