# 第5期

事件

+   - 信用緊縮。
- 經濟狀況嚴重惡化，但是社會與政治狀況惡化更厲害。
- 消費明顯減少或下降（汽車銷售、住宅與家電銷售量下降）。
- 企業獲利劇降。
- 股市進入漫長而嚴重的下跌趨勢，外國人開始退出市場。
- 不動產價格劇跌。
- 第3階段時屢屢成為新聞題材的「大型業者」破產。
- 公司短缺現金。

徵兆

+   - 辦公大樓空置，旅館空房率很高，很多建築工地停工或無法完工。
- 券商裁員或關門。
- 研究報告變薄，第2期和第3期內溢價銷售的國家型基金現在折價銷售。
- 國家不再是大家喜愛的旅遊目的地。

例子

+   - 1992年的泰國。
- 1982到1983年的新加坡。
- 1931年與1973年底的美國。
- 1992年初的日本。
