# 重點摘要

+   1. 理想的公司擁有很高的淨現金流量，現金餘額龐大，沒有負債，衰退期間尤其如此。
2. 我們規定的負債對股東權益比率上限為 50%，而且只有在所有其他標準都符合時，才容許這麼高的上限。
3. 流動資產淨值減去庫存和進行中的業務後，和流動負債之間的速動比率應該至少有 1：1，最好有 1.5：1。
4. 睜大眼睛，注意工程營建公司遭到扭曲的現金部位，這些公司經常收到顧客預付的高額保證金。
5. 永遠要研究公司的現金流量表，特別是要一再查核營業淨現金流量，至少要等於營業淨利潤，最好是比較高。如果其中有不正常的重大差異，代表公司用會計花招作帳。
6. 應該避免純粹為了維持生存，必須大量投資資本設備的公司，能夠產生大量可自由運用的現金流量，用在擴充未來盈餘的公司，吸引力大多了。
