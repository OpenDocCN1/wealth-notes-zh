保留太多，最好的公司會比大多數公司更善於熬過衰退，有些強而有利的利基公司幾乎不會受到衰退影響。葛蘭素、MTL、能多潔和史普靈蘭一直都是絕佳的投資，表現大幅勝過達格帝和布頓之類沒有事業關係的公司。

擁有強勁事業關係的公司通常會創造絕佳的資本報酬率，產業公司的資本報酬率通常比以「人力」為主的公司低多了，例如廣告公司和保險經紀商，如果不考慮商譽，廣告和保險業者可能展現極高的報酬率。如果是小型產業公司，我希望看到20到25%的報酬率。這樣不會高到吸引過多的競爭，卻高到足以創造很多未來的成長。報酬率的计算方法如下：

+   1. 資本是普通股股本、特別股、公司債、債券與其他債務的總和。
2. 平均計算會計年度期初和期末的資本。
3. 把應付利息和特別股股息加回到稅前盈餘中。
4. 拿3.除以2.算出百分比。
