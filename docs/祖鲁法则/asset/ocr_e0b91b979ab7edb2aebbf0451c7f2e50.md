# 領導股

領導股的缺點之一是經常有很多人研究，股價通常比較貴。

大公司和小型的公司沒有兩樣，你在大公司裡不會找到借殼上市公司，卻會找到很多成長股、景氣循環股、轉機股和資產股。買賣領導股的好處之一，是安全性毫無疑問地大多了。大型股歷史比較悠久，更像是社會結構的一環，因此比較不可能因為缺乏資金或意外事故而倒閉。此外，大型股市場的流動性高多了，如果是小型股，你會常發現市場突然萎縮到只成交 1,000 股，內外盤差距很大，如果是領導股，你要獲利或停損時，應該總是能夠成交。
