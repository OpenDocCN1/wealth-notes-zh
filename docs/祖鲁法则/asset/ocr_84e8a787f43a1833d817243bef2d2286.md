我在那篇文章中解釋說，我尋找的股票是擁有高於平均水準的盈益率（用今天的話來說，等於低於平均水準的本益比），加上高於平均水準的成長展望，我也列出了九個重要的投資標準。今天回頭來看很有意思，因此我直接從這篇文章中引用這些標準：

+   1. 股利率至少有4％。

+   2. 股本盈利過去五年內，至少有四年成長。

+   3. 股本盈利過去四年間至少必須倍增。

+   4. 董事長最新的聲明必須樂觀。

+   5. 公司必須擁有合理的流動性。

+   6. 公司必須不受特殊因素傷害。

+   7. 股票必須擁有合理的資產價值。

+   8. 公司不應該由家族控制。

+   9. 股票應該有投票權。
