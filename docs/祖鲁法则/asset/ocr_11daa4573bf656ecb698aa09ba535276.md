# 股市一般名詞定義

+   1. 空頭——對市場展望悲觀，認為股價會下跌的投資人。

+   2. 多頭——對市場展望樂觀，認為股價會上漲的投資人。

+   3. 套利新股股東——指申購新股，申購成功後打算迅速賣出獲利的申購人。

+   4. 買權——買進股票或商品的選擇權。

+   5. 賣權——賣出股票或商品的選擇權。

+   6. 績優股——地位穩固、備受投資圈尊敬的頂尖公司。

+   7. 金融時報股價指數——英國有兩種主要的股價指數，一種是金融時報100種股價指數，成分是百大股票；另一種是金融時報綜合股價指數，成分是七百家頂尖公司。金融時報綜合股價指數基礎比較廣泛，最能反映實況，但是媒體比較常用金融時報100種股價指數。

+   8. 承銷——在股市安排新股發售，邀請大眾申購的方法。

+   9. 私募——透過券商或投資銀行，對投資機構與私人顧客發行股票，以便在股市掛牌上市的方法。

+   10. 借殼上市公司——通常指資產微不足道，但是擁有在證券交易所掛牌優勢的普通小公司。企業家經常會把自己的事業，灌進這種借殼股，取得從後門上市的機會。這種企業家本身的公司大都因為歷史太短，或是因為有其他缺點，不能用正常方式上市。
