# 股市贏家之道

為了競爭，你需要培養優勢。

投資跟任何遊戲沒有不同，勝利遠比失敗有趣多了，運氣和技術都有影響。差勁的玩家經常抱怨自己運氣不好，但是就像著名的高爾夫好手布萊爾（Gary Player）說的一樣：「你越努力，運氣越好。」已故的保險大師雷特曼（Elmer Letterman）換一種說法：「運氣是準備遇上機會。」讓我告訴你怎麼為投資做準備，變成贏家。
