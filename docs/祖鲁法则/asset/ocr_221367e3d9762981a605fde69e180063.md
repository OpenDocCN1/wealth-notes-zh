銀行貨款（如果有的話）、抵押貨款、融資租賃貨款與分期付款合約及其他長期貨款。

+   2. 準備金——為可能發生的債務或損失而保留的任何金額。
    好戚公司的這個項目只有25萬鎊的租稅緩課。

+   3. 轉投資——代表在非百分之百持有的子公司的資產比率。
    好戚公司沒有這個項目。

因此，可動用淨資產總共為700萬鎊（1,000萬鎊減300萬鎊），股東透過持股，擁有這些資產。公司發行的普通股數為1,000萬股，票面為25便士，因此實收資本額為250萬鎊。好戚公司的情形和很多其他公司一樣，股東的原始資本投資已經因為歷年盈餘（450萬鎊）的再投資而增加。

截至1992年5月31日止的年度合併損益表也很簡單，在每一個主要數字背後的財務報表附註中，通常都有一個解釋比較詳細的相關數字，例如營業額會有詳細的分析，另外還有一個附註，會顯示營業利潤，同時說明營業利潤已經扣除董事酬勞16萬鎊、會計師簽證費用4萬鎊，與其他相關項目。
