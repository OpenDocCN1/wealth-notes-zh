# 重點摘要

你要找的股票應該具有下列特點：

+   1. 過去五年的每股盈餘複合成長率大約為 15% 以上。如果最近盈餘加速成長，也可以接受比較短的期間，更好的是還有換新經營階層這類明確又持續性的優勢。
2. 和成長率相比的本益比很有吸引力，目標是預估本益成長比不超過 0.75，最好低於 0.66。換句話說，預估本益成長比不應該高於預估未來成長率的四分之三，最好低於三分之二。
3. 和公司的歷史、業界平均值與大盤平均水準相比，本益比要有吸引力。
4. 董事長的年度和半年聲明必須樂觀，股利政策必須能夠配合這種樂觀氣氛，市場的獲利預測共識也必須樂觀。

應該記住的其他重點包括：

+   1. 成長股的股價會上漲，完全是因為盈餘成長和本益比倍數的變化，後者經常比前者重要多了。
2. 避開本益比高得離奇的股票。
3. 考慮半年營運成績時，特別注意季節性因素，記住某些股票上半年業績一向比較好。
4. 注意處在復甦期間的景氣循環股和成長股的差別。景氣
