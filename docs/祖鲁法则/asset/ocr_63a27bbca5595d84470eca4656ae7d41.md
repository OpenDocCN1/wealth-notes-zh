# Chapter 3
# 盈餘、成長率與本益成長比

本益成長比是衡量工具，也是很重要的投資工具，不要低估這個比值的價值。

公司盈餘指的是普通股每股的稅後盈餘。如果公司的盈餘為每股10便士，本益比為10倍，股價應該是1鎊；如果本益比為20倍，股價應該是2鎊；如果本益比為50倍，股價應該是5鎊。盈餘年成長率與預測的未來成長率是決定本益比的主要因素。本益比是你打算付出多少錢、以及別人在你之前付了多少錢，購買未來成長的指標。
