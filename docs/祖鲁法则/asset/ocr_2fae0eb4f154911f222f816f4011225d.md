# 與上市股票價值評估有關的定義

+   1. 股利率——計算方式是用年度股利總額除以股價。如果公司配發的股利總額為每股收益 10 便士，股價為 100 便士，股利率就是 10%。如果股價漲到 200 便士，股利率會降為 5%。股利率可以分為歷史與預估股利率，歷史股利率是根據去年的配息計算，預估股利率是根據董事會預測的未來一年股利計算，股利通常一年配發兩次，期中股利是在半年結束後配發，期末股利是在全年度的會計報表結算後配發。股利率是根據公司在某一年內配發，或計畫配發的股利總額而得。

+   2. 總市值——公司發行股數乘以股價就是總市值，總市值是不斷變化的數字。

+   3. 本益比——指目前股價除以每股收益得到的倍數，根據去年每股收益計算得到的倍數叫歷史本益比，根據預測餘額計算得到的倍數叫預估本益比。

+   4. 每股收益——指公司可分配普通股股東的稅後餘盈，計算方式是用稅後餘盈除以發行股數，得到的就是每股收益。

+   5. 淨值——指公司資產總額減去所有長短期負債、準備金與費用後的金額。

+   6. 每股淨值——指公司淨值除以發行股數得到的數字，每股淨值跟以資產為基礎的不動產公司和共同基金關係特別密切。
