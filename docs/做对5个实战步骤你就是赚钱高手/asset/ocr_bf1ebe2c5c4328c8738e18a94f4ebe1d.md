# 5. 指標參考

# 6. 可能的獲利目標

+   ○ 上面MA60、MA125均線的壓力。\n○ 前面（由右向左看）轉折的低點（底部）和高點（頭部）的壓力。\n○ 前面盤整區壓力。\n○ 前面大量向下跳空，形成缺口的壓力。\n○ 前面出大量的K線被跌破之後，再上漲時前面的出大量的K線造成的壓力。\n○ 下跌趨勢形成的下降切線壓力。\n○ 如果是型態突破後的上漲，型態的目標價滿足點也會形成壓力。
