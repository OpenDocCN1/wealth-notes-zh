# Part 2 ▶5大實戰步驟

![](bbox=[0.11, 0.2, 0.79, 0.53])

① 浩鼎（4174）連續大漲到高檔，2014/7/28當天出現大量跳空下跌黑K線，跌破前一天長紅K線低點，放量約為前一天的1.7倍，呈現急漲後的急跌。

② 急跌回檔到前面低點位置，出現支撐十字雙盤線。次日2014/8/8，為開低盤，不宜進場。

③ 2014/8/18，回檔到前面兩個低點位置，出現支撐十字雙盤線。觀察次日是否有機會開高反彈。次日2014/8/19，跳空開盤，開盤買進做多當沖。

④ 2014/9/9，當天出現大量長紅K線，收盤突破前面高點，放量約為前一天的5倍，多頭確認，收盤做多的次日上漲。
