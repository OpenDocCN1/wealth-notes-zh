# 多頭、空頭和盤整趨勢

無論做長線或做短線，都要知道什麼是「趨勢」。股價的走勢方向維持走多頭、走空頭或橫向盤整，這3個方向稱為「趨勢」。

+   1. 多頭趨勢：股票上漲時，維持「頭頭高、底底高」的圖形走勢。 
2. 空頭趨勢：股票下跌時，維持「頭頭低、底底低」的圖形走勢。 
3. 盤整趨勢：股票行進時，既非多頭的圖形，也非空頭的圖形走勢。

趨勢的詳細說明，參見《抓住飆股輕鬆賺》第1篇。
