# 武装自己
变身股市赢家

投 资人如果想要成为股市赢家，必须奉行「投资之道，趋势为师，顺势而为，坚守纪律」的赢家最高圭臬。

投资之道：想走股票投资这条路，就要找到正确的方向，用正确的方法，做正确的事，才能到达成成功获利的彼岸，见到股市如来。

趋势为师：大盘的趋势方向，就是引领我们前进的明燈，大盘的变化就是淬炼我们的导师，天大地大，趋势最大，投资时，要谦卑恭谨慎地跟随趋势。

顺势而为：借力使力，顺水推舟，事半而功倍。顺天应势，得道者富，赚钱如反手折花。

坚守纪律：股市狡诈，千变万化，迷惑股海眾生，人心善变，恐惧贪婪，无法自持，唯定法坚守，以不变之法，照股市眾妖，定法依法，去杂乱之源，归万念於一，此定心矣！
