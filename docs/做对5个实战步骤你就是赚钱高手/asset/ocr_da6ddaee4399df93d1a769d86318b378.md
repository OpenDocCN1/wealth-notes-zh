# 情況5 頭部為頭肩頂、復式頭肩頂、三重頂、上升楔型等型

態，大量跌破，完成確認的頭部，為弱勢下跌的潛力股。

![](bbox=[0.1, 0.285, 0.785, 0.605])

+   ① 奧斯特（8080），日級高檔時出現爆大弈、黑K線吞噬的轉折向下回檔下跌。
② 再出現大弈長黑K線下跌，同時出現「一星二陰」繼續下跌。
③ 弱勢反彈後大弈長黑K線下跌，再跌破前面低點，出現「頭肩頂」的型態確認，同時形成空頭「頭頭低、底底低」確認，後續連三黑下跌，為弱勢空頭，反彈不過高再下跌，可繼續做空。
④ 「頭肩頂」的型態確認後下跌的目標價位置。
