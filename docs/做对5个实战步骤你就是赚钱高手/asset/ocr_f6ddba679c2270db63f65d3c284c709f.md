# Part 2 ▷5大實戰步驟

![](bbox=[0.11, 0.197, 0.8, 0.545])

聯發科（2454）2011/11/3，當天出現向下大亞長黑K線貫穿前一日紅K低點，以下是符合短線做空的條件：

+   ① 向下大亞長黑K線實體棒，貫穿前一日紅K低點，收盤跌破前面低點，空頭的「頭頭低、底底低」的趨勢確認。
② 均線3線向下空頭排列，股價在3線之下。
③ 第一個頭，348大亞創高後，次2日長黑K線向下跳空回檔。
④ 高檔再放大亞，股價後續沒有再創348高點，形成價量背離，要密切注意盤頭下跌的可能性很高。
⑤ KD指標空排向下。

符合短線做空的條件之後，再往下看會遇到哪些支撐，這些支撐就是可能的獲利目標。

+   ⑥ 季線向上的支撐。
⑦ 轉折向上的低點支撐。
⑧ 大亞向上跳空缺口支撐。
⑨ 轉折向上的低點支撐。
