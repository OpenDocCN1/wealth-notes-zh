# 情況6 底部出現2次以上大量轉折向上的K線組合型態，例如：

長紅吞噬、孤島轉折、晨星轉折、內因三紅、跳缺回補、上升三法、一星二陽等的組合，為強勢上漲的潛力股（上述轉折向上的K線組合，參見《抓住K線獲利無限》）。

![](bbox=[0.14, 0.34, 0.84, 0.68])

①國揚（2505），週線最低點大盪反彈，3日K線為內因三紅K線組合的向上轉折訊號，落底第一隻腳。

②回檔1天就出現長紅吞噬K線，再形成晨星轉折K線組合的向上轉折訊號，出現底底高的第二支腳。

③再出現大盪長紅K線上漲，突破前面高點，多頭「底底高、頭頭高」確認，為強勢多頭底部，股價最低12.65元反彈回升，後來一路上涨到33.45元。
