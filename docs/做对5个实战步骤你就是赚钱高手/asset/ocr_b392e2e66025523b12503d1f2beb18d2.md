# 鴻海週線：K線操作法

①鴻海（2317）2009/3/2，週線大盈長紅K線上漲，突破前面高點，多頭趨勢「頭頭高、底底高」確認，當週收盤75.4元進場短線做多，用週線「K線操作法」操作。

②2009/6/1，黑K線收盤跌破前一週K線最低點，跌破MA5週均線，收盤111.5元多單賣出。短線單次獲利36.1元，獲利率47.8%。

③2009/7/6，週線大盈長紅K線上漲，收盤突破前3週的最高點，多頭回檔再上漲，當週收盤109.5元進場短線做多，利用週線「K線操作法」操作。

④2010/1/18，黑K線收盤跌破前3週K線最低點，跌破MA5週均線，收盤138元多單賣出。短線單次獲利28.5元，獲利率26%。

# 操作成果

+   ○週線「K線操作法」操作短線，一共進出2次，時程10.5個月。
○總獲利36.1元+28.5元=64.6元，獲利率64.6÷75.4=85.6%。
