# Part 2 ▷5大實戰步驟

情況3 底部轉折低點出現大量連三紅，或是上漲3天出現2次跳空缺口快速上漲，後續完成多頭底部，為強勢上漲的潛力股。

情況4 強力反彈後回檔不到反彈幅度的三分之一，就轉折上漲完成「頭頭高、底底高」的多頭確認，為強勢上漲的潛力股。
