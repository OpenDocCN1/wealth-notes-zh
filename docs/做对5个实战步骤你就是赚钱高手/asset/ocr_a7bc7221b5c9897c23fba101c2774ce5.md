# 長線做空實戰範例

![](bbox=[0.109, 0.236, 0.78, 0.582])

範例1A：創惟月線空頭趨勢確認位置

+   ① 創惟（6104）2007/4，月K線長黑吞噬，跌破連續上漲7個月的上升切線。

+   ② MACD指標在0軸之上，死亡交叉向下。

+   ③ KD指標80死亡交叉向下，月線回檔訊號，可<|start|>迴線條件做中空。

+   ④ 2007/8，月K線長黑吞噬，頭部「頭頭低、底底低」，空頭確認。 MA5、MA10均線，死亡交叉，迴線空頭確認可做長空。

+   ⑤ MACD指標在0軸之上，空頭排列向下。

+   ⑥ KD指標空頭排列向下。

月線完成長波段條件，回到迴線操作，長波段中線操作可用5迴均線操作，長波段長線操作可用20迴均線操作。
