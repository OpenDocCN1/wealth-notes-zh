# Part 2 ▷5大實戰步驟

# ②下跌飆股反彈停利

下跌飆股每日跌停，當天大量打開跌停，向上反彈超過半根停板時，停利回補。

![](bbox=[0.11, 0.32, 0.79, 0.61])

① 云辰（2390）2014/7/25，大巫長黑K線吞噬，未突破前面2高點，高檔盤三重頭，在此可試空單，收盤56.5放空。

② 股價連續飆跌9支跌停板下跌到低檔，隨時準備獲利回補。2014/8/7，開盤跌停板，盤中熄火打開跌停板，反彈到只剩下跌3.5%、股價30.7元獲利回補。獲利25.8元，獲利率45.6%。

③ 2014/8/12，空頭反彈後，大巫長黑吞噬K線下跌，收盤30.45元繼續做空。後續沒有飆跌，按一般空頭股票操作。

④ 2014/8/21，大巫長紅K上漲，出現K線轉折訊號，收盤27.4元停利回補。獲利3.05元，獲利率10%。

# 獲利成果

○做空操作2次，獲利28.85元，獲利率51%。
