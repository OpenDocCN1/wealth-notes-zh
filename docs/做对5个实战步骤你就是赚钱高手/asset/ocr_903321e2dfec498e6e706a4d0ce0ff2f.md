# Part 2 ▷5大實戰步驟

④ 2006/3/27，大亞長紅K線收盤突破MA5週均線，收盤19.45元多單贅出。短線單次獲利0.55元，獲利率2.7%。

⑤ 2006/5/2，週線長黑K線下跌，收盤跌破前4週的最低點，空頭反彈再下跌，當週收盤19.1元進場短線做空，利用週級「MA5均線操作法」操作。

⑥ 2006/9/18，長紅K線收盤突破MA5週均線，收盤11.6元多單賣出。短線單次獲利7.5元，獲利率39.2%。

# 操作成果

+   ○ 週線「MA5均線操作法」操作短線，一共進出3次，時程11個月。
○ 總獲利−0.55元+0.55元+7.5元=7.5元，獲利率7.5÷22.7=33%。
