# 多頭進場位置6

多頭下面的圖型，可以在當天收盤或次日開盤進場，做隔日沖或當日沖，賺取上漲價差。

+   1. 抓住次日開盤或當天收盤的機會進場，賺取上漲價差。\n2. 以日線K線轉折或續漲的訊號，做為買進的位置，與基本面無關。\n3. 次日或當天走勢強弱，可以看趨勢、價量配合及位置再留單一天。\n4. 次日或當天走勢不理想，沒有價差就出場，因此沒有大賠的風險。\n5. 屬於超短線操作，獲利不大，要以量取勝。

# 操作紀律：

+   1. 選擇符合條件的強勢多頭股票做多，或空頭急跌的股票搶反彈做多。\n2. 盤中可以用5分K走勢圖操作。\n3. 此法獲利小，要以量取勝，資金要集中在1～2檔，不宜同時做多檔股票，以免盤中無法照顧。\n4. 操作必須看盤，並且嚴守停損及停利紀律。
