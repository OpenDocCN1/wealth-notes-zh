# Part 2 ▶5大實戰步驟

由上面支撐的獲利目標來預估，下跌有獲利空間，可以做中期操作獲利，後面走勢結果如下：

+   ⑨ 週線由最高點連續下跌5週，遇到週MA60均線向上的支撐，及前轉折高點的支撐，當週出現大垓長紅K線反彈。

+   ⑩ 週線反彈後再連續下跌3週，遇到前轉折高點的支撐，出現大垓紅K線反彈。

+   ⑪ 週線反彈後再連續下跌6週，遇到前面轉折低點的支撐，出現大垓紅K線反彈。

週線低檔出現大量長紅K線，同時打底向上突破前面高點，完成「底底高、頭頭高」多頭趨勢，結束空頭操作。

附註：這次空頭趨勢下跌超過半年，為中期空頭走勢。

資料來源：富邦e01證券交易系統
