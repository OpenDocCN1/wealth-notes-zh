# 金剛2 K線變化

K線看的是每天買賣雙方的交易意願強弱，也就是說，K線可呈現當天看多及看空的投資人力道，這些力量的改變，可以研判走勢的延續，或者走勢將出現轉折的情況。

![](bbox=[0.145, 0.355, 0.845, 0.65])

觀察每天的K線變化，可以在高檔時掌握反轉的訊號。

+   ① 股價連續上漲後，K線在上方橫盤5天，多空雙方對峙。② 出現大並長紅K線，股價上漲，多方勝出。③ 延續2天出現黑K雙盤線，多方上攻力道減弱，應注意可能向下轉折。④ 當天開低盤，顯示股價上攻的企圖不強，收盤出現大並長黑，顯示空方力道極強，連續4天K線形成「夜星轉折」的向下訊號。⑤ 股價於低檔盤整6天，出現大並向下跳空的黑K，反轉成空頭趨勢。

資料來源：富邦e01電子交易系統
