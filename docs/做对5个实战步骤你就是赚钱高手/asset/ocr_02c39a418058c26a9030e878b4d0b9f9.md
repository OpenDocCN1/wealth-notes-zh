# 方法4：週線空頭「K線操作法」做空

+   1. 週線波浪型態空頭完成。
2. 股價符合空頭進場位置進場。
3. 進場停損守當週進場黑K線最高點。
4. 收盤突破前一週K線最高點出場。
5. 空頭趨勢改變（週線趨勢出現底底高），停止操作。
