# 金剛4 成交量

觀察成交量與股價變化的關係，再看所在的位置，就能研判是誰在買、誰在賣。

![](bbox=[0.148, 0.324, 0.84, 0.628])

① 股價橫向盤整後上攻，出現大量，後續股價沒有跌破這根大忌K線的低點，這是攻擊的進貨量。

② 股價高檔盤整之後，再出現大量上攻，次日股價漲停板，這是攻擊的進貨量。

③ 股價連續上漲出現黑K大量，後續沒有跌破這根大忌黑K線的低點，這是續攻的換手量。

④ 股價連續上漲9天的高檔，再出現紅K線大量，要密切觀察後續股價是否跌破這根大忌紅K線的低點，決定是出貨量或換手量。

⑤ 長黑K線跌破了大忌紅K線的低點，前面的大量是漲多的出貨量。
