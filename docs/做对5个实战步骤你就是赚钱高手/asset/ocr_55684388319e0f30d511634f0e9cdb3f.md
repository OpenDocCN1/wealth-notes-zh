# 第6章

# 長短線綜合操作法：
趨勢＋均線＋乖離

影響股票走勢的因索很多，即使一檔股票的基本面很好，技術面的月、週、日線都合乎多頭上漲的條件，仍不能保證一定會大波段上漲，可能上漲中波段或小波段，就結束多頭趨勢。

為了解決上述的困擾，可以考慮採用以下的操作策略：

# 策略1      長線趨勢操作

長線趨勢操作，必須在底部多頭趨勢確認位置，或頭部空頭趨勢確認位置開始操作，如果位置在高檔的末升段或在低檔的末跌段，就不適合用長線趨勢操作。

# 策略2      從短線開始操作

剛進場操作時先從短線做起，當走勢持續時再做長線，例如日線底部多頭趨勢剛確認時，先做短線，當日線持續上漲一段，週線走勢圖也完成底部多頭趨勢確認後，再改做長線，這樣有週線多頭趨勢的保護，在日線做長線「趨勢操作」，成功的機會就很高。
