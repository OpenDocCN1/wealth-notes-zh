# 空頭趨勢做空用均線停損

例如以10日均線操作：空頭趨勢不變，反彈結束沒有突破前面高點，再下跌的中長黑K線收盤跌破10日均線，均線下彎時進場放空，停損守進場當日的10日均線。

+   ① 台橡（2103），大且長黑K線，收盤跌破盤整頭部，空頭趨勢確認。\n② 空頭反彈後大多長黑K線，收盤跌破MA10，當天做空進場，停損守MA10均線。\n③ 空頭反彈後下跌黑K線，收盤跌破MA10，當天做空進場，停損守MA10均線。\n④ 空頭反彈後下跌黑K線，收盤跌破MA10，當天做空進場，停損守MA10均線。
