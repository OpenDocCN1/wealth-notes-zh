# 事欣科日線：多頭進場停損

![](bbox=[0.175, 0.205, 0.845, 0.512])

① 事欣科（4916）2013/12/24，當天大選長紅K線，突破盤整，是多頭買進位置，收盤48.1元買進，停損設在紅K線最低點46.2元。後續6天都沒有跌破停損，持股續抱。

② 2014/3/3，當天大選長紅K線，突破盤整，是多頭買進位置，收盤66.5元買進，由於進場位置在高檔，同時當天出現近來來的最大量，停損設在長紅K線的二分之一位置63.75元，這個位置被跌破，表示多空力道改變。

③ 2014/3/7，當天大選長黑K線，跌破停損價，多單出場，避開了後來反轉成空頭的下跌風險。

資料來源：富邦e01 量子交易系統
