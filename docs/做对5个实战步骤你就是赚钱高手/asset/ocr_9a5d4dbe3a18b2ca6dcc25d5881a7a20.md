# 方法2：日線空頭「K線操作法」做空

+   1. 波浪型態空頭完成。
2. 股價符合空頭進場位置進場。
3. 進場停損守進場黑K線最高點。
4. 收盤突破前一日K線最高點回補。
5. 空頭趨勢改變（日線趨勢出現底底高），停止操作。
6. 逆勢做空也可用此方法短線操作。
