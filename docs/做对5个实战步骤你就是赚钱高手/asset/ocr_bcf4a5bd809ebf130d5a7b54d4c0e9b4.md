+   4. 多頭看價量的配合，籌碼變化看3大法人買賣超、融資融券增減，是否有經過洗盤再漲的狀況。\n5. 看個股週線走勢方向如何，觀察有沒有長線的機會。\n6. 觀察日線及週線的MACD、KD指標，是否在高檔向下或低檔向上。\n7. 觀察近3～5日K線的變化，是否有短線轉折的機會。\n8. 多頭時，看該股是否屬於主流股、題材股、應景股、轉機股、軋空股。\n9. 觀察均線的排列及位置，是否呈現多頭排列向上或空頭排列向下。\n10. 預估機會獲利空間及風險範圍。\n11. 看是否有明天可以進場的標的（挑選最佳的3～5檔）。

# 精選好股 建立財庫

投資人若能依照上述方法，每天觀察強勢股和弱勢股，就能從中挑出許多有潛力的多頭及空頭股票，再用這些股票建立一個資料庫（也有人稱為「水庫」），以便於鎖股應用。

基本上，鎖股可分為鎖做多與鎖做空兩部分，再依據類股的強弱順序排列，每天檢視變化，把最強勢、近期有機會發動的股票，優先排列在前5檔，這樣就能在盤中快速掌握最佳的進場機會。
