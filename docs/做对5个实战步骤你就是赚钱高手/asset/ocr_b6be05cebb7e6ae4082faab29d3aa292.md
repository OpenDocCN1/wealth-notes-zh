# 簡單回顧 K線橫盤的突破

1. K線如符合「價漲、量增、線實」的訊號，買進上漲的機率很高。

價漲：收盤價上漲，突破盤整的上頸線。

量增：成交量大於昨日成交量的1.3倍以上。

線實：K線收中長紅K的實體棒（上漲2.5％以上）。
