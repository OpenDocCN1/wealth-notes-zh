# 空頭放空位置3

空頭中長黑K線下跌後，股價維持在K線下方橫盤，當再出現中長黑K線，收盤跌破橫盤最底點時，是放空的位置。

簡單回放置 K線橫盤的跌破

+   1. 黑K線如符合「價跌、線實」的訊號，放空成功下跌的機率很高。
   價跌：收盤價下跌，收盤價跌破K線橫盤的最低點。
   線實：K線收中長黑K的實體棒（下跌2.5%以上）。
   成交量：大量或小量都可以。

+   2. 日線進場的K線訊號是操作短線的放空位置。
   週線進場的K線訊號是操作中長線的放空位置。

+   3. 跌破當天如果是跳空下跌的黑K線，代表股票越弱，更要把握機會放空做空。

+   4. 放空後要設定停損，並且嚴格執行停損。
