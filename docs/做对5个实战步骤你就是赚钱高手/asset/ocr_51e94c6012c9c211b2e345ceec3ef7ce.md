# Part 2 ▷5大實戰步驟

![](bbox=[0.11, 0.2, 0.79, 0.53])

① 美時（1795）2013/11/28，當天出現大玉長紅K線，放量約為前一天的3.8倍，收盤突破前面高點，「頭頭高，底底高」多頭確認。

② 2013/12/4，當天多頭回檔，沒有跌破前面低點，出現長紅K線實體棒，放量約為前一天的1.8倍，收盤突破昨日高點，多頭穩綏上漲，是多頭買進位置。

③ 2013/12/24，當天多頭回檔，沒有跌破前面低點，出現長紅K線實體棒，放量約為前一天的1.3倍，收盤突破昨日高點，多頭穩綏上漲，是多頭買進位置。

④ 2014/1/14，當天多頭回檔，沒有跌破前面低點，出現長紅K線實體棒，放量約為前一天的3倍，收盤突破昨日高點，多頭穩綏上漲，是多頭買進位置。
