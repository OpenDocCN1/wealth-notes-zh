# Part 2 ▷5大實戰步驟

# ③條件3：做多高檔停利

在做多高檔（連續3根以上的長紅上漲K線、趨勢未升段的急漲），爆大量和K線轉折訊號向下時，停利出場。

![](bbox=[0.1, 0.33, 0.765, 0.648])

① 陽程（3498）2012/8/29，大量長紅K線，突破前面高點，多頭確認，均線3線多頭排列向上，收盤14.6元做多買進。

② 股價上漲到高檔，連續5天長紅上漲K線，出大歪，K線出現轉折訊號時要準備停利。

③ 2012/10/8，股價開低走低，大量長黑K下跌，收盤24.45元停利出場。獲利9.85元，獲利率67.4%。後續在高檔盤頭。
