# 範例1B：創惟週線空頭走勢及進場部位

![](bbox=[0.18, 0.2, 0.84, 0.54])

① 創惟2007/7/30，週K線大氐長黑吞噬，出現高檔「頭頭低」，跌破月線，且月線下彎。

② MACD指標在接近0軸，即將死亡交叉。

③ KD指標死亡交叉向下，週線進入盤頭。

④ 2007/8/13，週K線大氐長黑，跌破回檔低點，空頭確認。同時週線出現一星二陰K線組合，縱勢下跌，日線可以做空。

⑤ 2007/8/27，月線大氐長黑K線空頭確認，但是週線是空頭的盤整，要等週線盤整跌破時才能進場做長空。

⑥ 2007/10/22，週線盤整跌破，空頭續勢。MA5、MA10、MA20、MA60均線，4線空頭排列向下。MACD指標在0軸之下，空頭排列向下。KD指標向下。週線可以開始做長空。
