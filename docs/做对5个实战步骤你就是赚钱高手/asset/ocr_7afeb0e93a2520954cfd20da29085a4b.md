# 多頭、空頭和盤整轉折

除了趨勢之外，無論做長線或做短線，也要了解什麼是「轉折」。股價在走趨勢的時候，漲漲跌跌，每次的上漲轉向下跌，或者下跌轉向上漲，稱為「轉折」點。

+   1. 多頭轉折：股票上漲一波到高點，轉向回檔的下跌；股票回檔結束後轉向的上漲。\n2. 空頭轉折：股票下跌一波到低點，轉向反彈的上漲；股票反彈結束後轉向的下跌。\n3. 盤整轉折：股票在盤整區的上頸線轉向下跌及下頸線轉向上漲。

轉折的關鍵在K線的變化，K線的轉折應用，參見《抓住K線 獲利無限》第3～4篇。
