# ⑪短線做空實戰範例

![](bbox=[0.14, 0.23, 0.85, 0.57])

智易（3596）2011/11/10，當天出現向下跳空大至長黑K線，以下是符合短線做空的條件：

+   ① 向下跳空長黑K線實體棒，收盤跌破前面低點，空頭的「頭頭低、底底低」的趨勢也確認。

+   ② 均線3線向下空頭排列，股價在3線之下。

+   ③ 第一個頭，41.6創高，當天大量最後回檔。

+   ④ 高檔放大大量長紅K線，在前高41.6之前放出大量，為關前大量，要密切注意，後續如果不能突破高點拉回，容易形成「頭頭低」的頭部。

+   ⑤ KD指標空排向下。

符合短線做空的條件之後，再往下看會遇到哪些支撐，這些支撐就是可能的獲利目標。

+   ⑥ 季線向上的支撐。

+   ⑦ 大量向上跳空缺口長紅K線的支撐。

+   ⑧ 雙胸打底的支撐。
