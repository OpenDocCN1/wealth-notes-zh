# 內在因素4 台股的結構變化

變化1：台股有電子、金融、非金電三大組合，其中電子股影響大盤指數最大，擔當大盤指數上漲的攻擊部隊，金融股擔當大盤指數防守的部隊，非金電類股是穩盤的角色。所以觀察這3大類股走勢的強弱，可以掌握大盤的強弱。

變化2：台指期貨量、價、線的走勢及電子期、金融期、非金電期的走勢為現貨的領先反應。
