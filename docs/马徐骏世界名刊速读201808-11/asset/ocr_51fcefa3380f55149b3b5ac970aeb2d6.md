# ## 1 森林浴是什么？

森林浴，forest bathing ，它是来自自然之旅，它是日本很久之前的一种治疗方法，强调的是让身体全部沉浸在自然之中。在森林中散步、发呆、倾听、嗅闻当地的有机食物，最好能找到一条溪流。作者在文章中强调，森林浴不是简单的让你走得快、放松压力，而是具有让你意识能力的效果。

地理学家彼得·曾，曾经带一些人在森林里做科学探索，并将其称之为一种治疗方式。她说，旅行时间越长，治疗效果越好，这种效果对所有人都有效，几乎无一例外。

文章中讲了一个案例，有一个从伊拉克退伍的老兵，他的一位女性大脑中残留了子弹碎片，无法手术，精神上还在医院里躺了五六年。出来后神经上，还是身体上，他遭受了很多的折磨。在参加这次自然之旅的时候，这位女士已经失去了求生的欲望，甚至带着杀人的念头。当他们进入那片树林的时候，这位女性在不自觉中，开始对动植物进行细致的观察，并且开始跟它们产生联结，她一个人一遍又一遍地沿着小溪走，直到自己完全释放了所有的焦虑。
