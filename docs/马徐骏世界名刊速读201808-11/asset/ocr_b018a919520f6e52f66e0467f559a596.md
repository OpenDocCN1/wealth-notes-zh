# 1 | 中国的创新

今天的内容来自于《经济学人》杂志的《中国的创新，Innovation in China》，讲的是中国在创新方面有什么独特的优势。

中国虽然是发展中国家，但是如今生活在中国的城市里，感受着这里的人们四通八达的交通网络、铺天盖地的各种服务，还有便捷的电子支付，都让我们觉得中国的生活非常便利。我做了个测试，三天的时间，没有任何货币，用现金去消费，但是生活完全没有受到影响，无论是工作还是日常生活，哪怕你拿着纸币去买一个点心，经常找不到任何商家可以接受纸币...

我想，很多人读外刊，除了想了解外面的世界最新的思想，还有一个目的就是想知道西方世界是如何来看待中国的。这次的报道就是一个很好的机会，让我们从旁观者，甚至是竞争对手的眼中，发现中国的发展和创新。

中国在商业领域，创新已经渐渐进入了世界的前列。中国取得的这种创新优势，既不是先发优势，也不是后发优势，而是靠中国独一无二的特殊条件，其他国家想模仿都模仿不了。
