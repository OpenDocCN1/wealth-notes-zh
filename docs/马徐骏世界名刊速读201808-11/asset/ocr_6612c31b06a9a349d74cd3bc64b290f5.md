# **| 圣殿骑士团的兴亡**

今天的内容来自于一本名为《BBC 历史》的封面文章《圣殿骑士团的兴亡》，*Templars on crusade*。作者乔斯·林斯是一位英国历史作家，写了多本关于中世纪和欧洲历史的书籍，比如《金雀花王朝》。

说起十字军东征，哪知不了解详细历史的，也多会听说一些。十次十字军远征中，绝大多数是以宗教名义出发的，从圣伯尔纳德的号召出发，为了从穆斯林手中夺回圣地。从1096年出发，直到1270年，十字军东征历时174年，一共发生了八次大的十字军东征，每次都有不同的目的。

但是今天我们要讲的，是其中一次特别著名的：第三次十字军东征。而我们要讲的主角，则是一个神秘的组织：圣殿骑士团。这个组织到底有什么厉害，又是怎么消失的呢？

# **| 圣殿骑士团的起源**

1119年，第一代十字军东征时期，有8位骑士来到耶路撒冷圣殿山，发现那里有被遗弃的圣殿山上的所罗门神殿。为了保护朝圣者，他们就决定在这里建立一个保护朝圣者的组织，这就是圣殿骑士团的起源。

![](bbox=[0.1, 0.76, 0.9, 0.82])

一开始，这群骑士只有7个人，后来为了招募更多人，他们开始接受捐款。教皇和贵族们都支持他们，因为保护朝圣者是一件非常高尚的事情。很快，他们的名声就传遍了整个欧洲。

到了12世纪中叶，圣殿骑士团已经成为了欧洲最富有的组织之一。他们拥有大量的土地，遍布欧洲各个角落。他们甚至还建立了一个银行系统，帮助商人安全地携带资金旅行。

但是，财富往往伴随着危险。随着十字军东征的失败，圣殿骑士团也开始陷入困境。1307年，法王腓力四世突然下令逮捕了圣殿骑士团的成员，以异端罪名判处他们火刑，圣殿骑士团就此灭亡。
