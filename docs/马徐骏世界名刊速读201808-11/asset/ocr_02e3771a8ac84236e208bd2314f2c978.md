# ## 马丁·路德的锤子

今天咱们门《纽约客》杂志的《马丁·路德的锤子》，The Hammer，这篇文章的作者是菲茨·阿利·帕瑞，她是《纽约客》杂志的资深撰稿人，1992年就开始为《纽约客》杂志写稿了。

马丁·路德，对于大多数中国人来说，可能是个熟悉的陌生人。咱们中学历史教科书上讲过他，1517年10月31日，距离在教会门上，马丁·路德写了95条论纲，引发了欧洲的宗教改革，从此整个西方宗教一分为二，一派是源于罗马教皇的天主教；另一派，就是新教。咱们大多数中国人对他的了解也止于此了。但是在西方世界，马丁·路德是个了不起的人物，德国经济迅速发展在他的身上，马丁·路德回到经，他引起了西方的宗教改革，翻译了圣经（379），从英国四处受到迫害的新教徒离开了欧洲，跑去美洲建立了美国。

《新科学家》杂志的文章说，马丁·路德是为科学革命开满道路的人，因为他的质疑精神引发了人们对权威的怀疑和对自身存在的思考，甚至有人称他是改变西方历史的伟人。今2017年10月31日，距离1517年10月31日，马丁·路德把95条论纲钉在教会门上，整整过去五百几十年，很多西方媒体，比如《卫报》《观察家》《新科学家》，都在发文章谈马丁·路德。

但是如果你仔细想一想，你会发现马丁·路德这个人的身上，有很多令人费解的问题，比如说在他之前，也不止有人挑战过天主教会的权威，基本上都没什么好下场，比如伽利略，被关在狱里；坚持日心说的布鲁诺被烧死了。但是为什么马丁·路德不但成功发动了宗教改革，还平平安安一直活到老年呢？马丁·路德之前也有很多人翻译过《圣经》，但都不如马丁·路德的版本流传广，影响大。这又是怎么了？

甚至《纽约客》的这篇文章，一开始就告诉我们，马丁·路德是首闯走进走到教皇门口，在95条论纲里就提了在门上这件事，其实在历史上并不存在了。那么，马丁·路德的宗教改革是怎么回事，他的成功依靠的是什么？

# ## 马丁·路德的宗教改革

马丁·路德出生在一个普通的中等家庭，他的父亲原来是一个矿工，后来开行了一个冶炼作坊，家境还过得去。家里一共有五个孩子，马丁·路德是老二，但是他的父亲本来希望他将来做个律师，但是马丁·路德的理想是有某种精神的，他不喜欢当律师，就进寺庙当修士了。马丁·路德21岁那年，遇到一场大暴风雨，几乎活不来了，于是他对天发誓说，如果活了下来，他就改投宗教，终身为上帝服务。没想到，他真的在耶稣风雨中幸存了下来，从此之后，他就成了一名天主教会的牧师。

路德后来反抗的欧洲教会，那时候为了敛财，在向要买，那时候的赎罪券就是说，你死后想进入天堂吗？那么人都是要在炼狱里待一段时间的，洗自己的罪过。这个赎罪的作品就是缩短你在炼狱煎熬的时间。说白了，就相当于花钱买保险，少坐点牢。当时很多人就买了这个赎罪券，但是没想到，这是少数，教宗就动了心，他们会说，上帝的原谅是靠你多行善事，他们批出了新版的赎罪券，相当于赎罪券2.0版，效果更好，威力更大，甚至有种神秘人宣称，教皇的权限是圣母玛利亚的，这种新的赎罪券也可以洗清你的罪过。这就属于非请神也不要钱，当时整个欧洲对此非常不满。

就是在这样的背景下，马丁·路德提出了95条论纲，其实论纲真正的核心就两条，第一条是要忠于自己的信仰；第二条，要忠于《圣经》。

什么叫忠于自己的信仰？就是说，既然上帝已经把自己最爱的人类赏罚来了，为世人牺牲了，所以上帝会是爱我们的，无论人性怎样，人都会是错误的，哪怕你是有原罪的，但只要虔诚地信仰上帝就够了。

什么叫忠于《圣经》原文呢？就是说，《圣经》里那些已经作有的道理和教祖都是告诉我们了，《圣经》里没提到的都是胡说，比如说，在《圣经》里面并没有说有炼狱的存在。所谓的炼狱，不过是一些学人的创造，或者说，某些人出于不可告人的目的编造出来的。

这两条，明显就是直击教会赎罪券的理论基础，就批评教会的敛财行径，一提出来，就为整个欧洲引发了轩然大波，好多已经对天主教皇很支持不满的人，纷纷站出来说声对路德的支持，甚至最后诞生了新教这个分支。

不其实马丁·路德并不是我们印象中那种偏执激进的革命家，他的一生，主要工作就是教学和写文章，很平和，但是他是如何就取得了宗教改革的成功？

# ## 成功的要素

文章里面谈马丁·路德的成功，其最关键的因素就是Timing（时机）。

首先，那个时候，从普通老百姓到贵族阶层，都已经对天主教会的不倒行径非常不满，所以马丁·路德的主张是有群众基础的。

其次，欧洲的领主和贵族，也一直被天主教会的压制来反对他们的，但是马丁·路德翻有圣人站出来反对教皇。所以马丁·路德就受到神圣罗马皇帝查理四世的保护，他甚至在下一个世纪，把圣经的《新约》从希腊翻译成德文。

马丁·路德成功最关键的一个因素，其实是技术的进步，也是印刷术的出现。

咱们之前也说了，马丁·路德并不是第一个翻译《圣经》的人，但是为什么他的版本是流传最广，发行量最大的？甚至当时整个欧洲的德语区有1/3的出版物，都是马丁·路德写的。就是因为古腾堡的印刷机发明出来之后，使得德国各地的印刷术加快，加上路德翻译的《圣经》有两个特点，一个是文字非常通俗易懂，有很强的语感；另一个是里面还有插图，这对于很多不写字的老欧洲人来说，理解成本就特别低，所以马丁·路德的《圣经》就散发到全欧洲人们家里的一本了。这也给带来了巨大的影响力，同时也教会不敢迫害马丁·路德，因为他的信徒太广了，也不敢动摇，这也保证了路德的人身安全。
