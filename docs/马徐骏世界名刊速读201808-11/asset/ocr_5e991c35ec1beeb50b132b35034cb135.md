# | 女人为何为难女人

职场上不只是女上司为难女下属。这种为难其实是互相的，女下属对女上司的要求也很苛刻，而这种互相为难的现象，有三大理论来解释，分别是基因理论、现代职场环境理论和社会对两性的双重标准。

先来说基因理论，波士顿暨曼纽尔大学的心理学家乔伊斯·本纳森（Joyce Benenson）认为女性的基因就是排斥与同性合作的。这个特点在大猩猩的行为当中就可以观察出来。雄性猩猩之间的合作是比雌性猩猩之间合作多很多的，雄性猩猩会一起捕猎寻找食物，而雌性猩猩却很少有合作，因为它们要与其他雌性猩猩争夺配偶和资源哺育后代。咱们说同性相斥、异性相吸，就是这个道理。

而德国心理学家内奥米·伊利莫斯（Naomi Ellemers）认为女性之间的竞争是现代职场的产物。在一个以男权为主导的社会里，职场是男性的天下，女性为了能够在职场上立足，不得不表现出很多男性特质。伊利莫斯教授为了研究阿姆斯特丹学术界女性教授很少的现象，针对女性教授进行了一项问卷调查。

在调查中，这些女教授都倾向于把自己描述得像男性一样，比如说愿意主导他人、有进取心，她们一致表示年轻的女下属工作不够努力。因为她们有较高的职场地位，付出的其实比男性要更多，在看到身边的年轻女下属，就会有，你还不够的感觉。

而更深层的原因，作者卡耐引用了罗斯赫大学的社会心理学教授劳里·拉德曼（Laurie Rudman）的观点——社会对于两性的双重标准。

最普遍的双标体现就是，除非拼命争取，否则女性很难获得重要的职位。就算是争取到了还会遭到其他人的冷嘲热讽和不好看。这个现象在希拉里和特朗普竞选总统的时候是特别明显的。根据调查，希拉里在没出来竞选总统时很受欢迎，一站出来竞选总统，受欢迎度就急剧下降。而且你会发现，在竞选的时候，希拉里选择原谅克林顿的出轨，居然成了女权主义者攻击她软弱的理由，但特朗普的多次婚烟就没有多少人质疑。

这就是典型的双标。另一位女性政客，美国佛蒙特州前州长玛德琳·M·库宁（Maeleine M.Kunin）就曾意味深长地说：“男人只要做自己就行了，女人却必须得做女神。”
