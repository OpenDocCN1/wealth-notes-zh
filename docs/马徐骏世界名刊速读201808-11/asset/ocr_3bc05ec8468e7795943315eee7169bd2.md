# 1 如何提高阅读速度

今天的内容来自《今日心理学》网站上的文章（如何提高阅读速度，即 So Much to Read, So Little Time），这篇文章讨论的是如何提高一个人的阅读效率。

这篇文章的作者是两位女性：芭·拉施瓦尔德和玛丽·科维奇，他们都是乔治亚大学的研究员，并且，这两位教授还合写过一本书（阅读心理学），在阅读这个领域，两人很有权威性。

第一看到这篇论文，我就觉得应该拿出来给用户们“解药”了，“用户们”当然就是终身学习者，我们都面临一个问题：要读的东西特别多，但时间却不够用。如果我们能够在阅读速度上提效，就像是增加了输入带宽，自然也就提高了学习的效率。

# 1 速读的秘密

文章里说，现在可以阅读的材料越来越多，多到完全不胜负荷。比如说，光是去年一年，全世界出版的图书就有190万本，而互联网上的信息更是井喷的状态。现在全世界的网页大约有45亿个，而且还在高速增长中。我们普通人读什么，读速大概是多少呢？

有一个大家的数据，抛开一些没啥营养，读起来很无聊的东西，在读起来既痛苦又很学术的文章，比如一些高等级的科学材料，或者哲学著作中的，那么西方国家，以英语作为母语的阅读者，大学作业的时候，差不多是1分钟能读200到400个单词左右。

在中国，一般人的阅读速度在1分钟350到500字左右。一天里精读会花多少时间，按精读小时计算，就是4-6个小时。当然，这是理想状态，事实上很难做到，要读得更多。

是不是人就想说，那我们能不能通过某种训练，提高阅读速度呢？

半个世纪之前，西方就兴起过快速阅读的热潮，最有名的一个叫伊芙琳·伍德的人写的课程（Reading Dynamics）。据说这个课程可以让人在理解文章内容的情况下，达到每分钟读2000个以上单词的速度。

这个课程现在仍在举办，而这两天中国也有很多类似的大快读训练，包括有一些小孩子提高阅读速度的课外班。甚至国内还有一个叫艾高斯，号称可以帮助你的手机APP，有速成阅读训练，可以说提高阅读速度提高7倍。

那么这种速读真的有那么神奇吗？

文章里说，其实速读并没有他们宣传的那神（神奇），他们的秘诀其实就那么两条：skim（略读）和提高词汇量。

skim是一种阅读技巧，直译过来就是“略读”的意思，也就是只挑那些关键信息、关键句以及重要的句子，来理解整篇文章的内容，说白了，就是抓重点。其实skim这个技巧，很多学的是英语读，大家学精读在需要大批处理文字信息，比如书论文、出书的时候，都会使用。作者的skim是可以帮助我们提高阅读速度的一把钥匙。因为阅读的目的是理解，而不是一个字一个字地读。

另外参加了12周快速阅读课程的人，在这12周时间里进行大量的文字阅读，而平均并没有这么多，对于提升阅读速度也是有帮。经过密集的阅读理解，最多不能达到一分钟2000个单词，但是一分钟能读500个单词或者600个以上的文字还是可以做到的。

但你发现没有，skim 和增加阅读量，不用猜，自己也能达到同样的效果。所以速读训练没法达到他们宣传的效果，归根结底是因为人的阅读速度受到生理和大脑理解能力限制。

# 2 关于阅读的研究

加州大学的教授雷切尔·雷诺专门做了一个阅读速度的研究，他们把这个研究里面最精华的部分拿出来。

首先，我们的阅读速度会受到生理上的限制。

在阅读的时候，我们的眼球飞梭在一块文字上停留，然后再马上移开下一块文字，就是扫过去，而人一般到一块不是以单词的字或者单句作为阅读单位而是以行的形式来理解一个句子的。也就是说，比如我们说“阅读时眼球”这个概念，阅读速度比较快的人，眼睛停留在一个字上面的时间大概是250毫秒。

这个250毫秒有多快呢？由于眼球的构造关系，我们其实只能看到视觉范围内很小一部分。如果说我们想看到自己10英寸远的一个单词，也要用20个点，起出这个范围，你看到的东西在视觉上其实都是模糊的。模糊到根本无法辨认，这些字，我们靠记忆去填补大脑的理解。也就是说，眼睛在视网膜上的成像其实是无法理解的。

其次，我们的阅读速度是受制于大脑理解力。

我们可能会觉得自己有两个很快的阅读习惯，一个是会回头读之前的内容；另一个是在读某个地方，花太多时间进行阅读，但研究就发现，这两个都不是坏习惯。而是大脑在理解或纠错。

比如跳回去读之前的内容，英文叫 regression，像我们非常有效的阅读者们，也会花10%-15%的时间做regression，原因是眼球移动太快，不能完整地理解前面的内容，所以就会回头去理解，以确保理解的信息，比如漏读了一个词、理解错了某个短语，或者一个新名词是啥意思。

有的人在一页上停留了很长时间，不是因为眼睛没有看清楚，而是因为大脑没完全理解信息，大脑在消化，这是理解问题，不是阅读速度问题。

有人说，阅读的本质是理解，阅读问题就是理解能力问题。要提高阅读速度，本质是让你的大脑有更好、更快速的消化能力。

所以，那些速读阅读的课程，其实作用并没有那么大。

作者说，提高阅读速度，我们比较有效的方式，是一种文字掌握得更快，以及我们自己生活历练带来的知识和阅读经验。多读、多阅读不同风格的文字，提升阅读的广度，才是提高阅读速度的不二法门。
