# #### | 更年期改变大脑

更年期一般发生在女性45岁左右。女性在更年期期间，卵巢内的卵子数量越来越少，雌激素水平也逐步下降，由于缺乏雌激素或卵巢分泌的其他荷尔蒙，综合在一起，就触发了更年期的各种症状，比如潮热。潮热指的是忽然觉得身体里有一股热浪袭来的感觉。还有疲乏、体重增加、缺乏性欲等等。这些生理上的变化也会导致心理和精神上的变化，比如情绪容易易生气波动、失眠、焦虑、健忘等等。

在过去的十年中，有越来越多的研究显示，无论是男性还是女性，激素水平下降，对记忆、情绪和大脑健康都有非常大的影响。

美国南加州大学的神经学家罗伯塔·布林顿（Roberta Brinton）和其他科学家发现了雌激素和大脑的关系。雌激素对大脑有保护作用，有一种雌激素叫做雌二醇，它能够帮助大脑中的线粒体活动。可以这么说，雌二醇就是大脑细胞的能量站，雌二醇越多，能量就越多，这可以加速细胞自我修复的速度，尤其是随着年龄老化带来的脑损伤。

澳大利亚昆士兰大学的神经学家阿芒迪娜·格林（Amandine Grimm）就专门研究“大脑和雌激素相关的功能”，他是这样解释的：“你可以想象一下，如果说雌激素下降了，那么大脑用来修复细胞的能量就变少了，大脑对伤害的抵抗力就会下降，这就有可能导致神经细胞的死亡。

雌激素水平的下降不仅影响着大脑能量的降低，也改变了大脑的能量来源。对于我们绝大多数人来说，大脑最主要的能量来源是葡萄糖，大脑是我们身体当中最依赖葡萄糖的器官。当身体组织缺乏葡萄糖时，身体就会进入一种饥饿状态，转而消耗身体的脂肪作为能量来源。

这种情况也会发生在大脑当中。进入更年期的女性，葡萄糖的糖替代就会急剧降低，如果大脑持续缺乏葡萄糖，那么就会开始消耗脑中的脂肪作为能源。大脑中的脂肪叫做脑脂质，脑脂质是白色的薄膜，包在绝大多数的大脑细胞外，确保大脑信号能够迅速传导。研究者布林顿说，他们发现大脑缺乏能量的时候，就会把脑脂质作为能量来源。换句话来说，就是大脑开始吃自己了。

总结一下更年期和大脑的关系，更年期中的女性，雌激素的水平急剧下降，导致了大脑能量的不足。葡萄糖代谢的降低，导致大脑需要消耗脑内部的脂肪作为能量来源，这就让大脑更脆弱。
