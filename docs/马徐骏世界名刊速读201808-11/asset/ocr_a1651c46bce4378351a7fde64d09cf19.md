# 抑 郁 症：depression

周 五 我 们 讲 了《时 代 周 刊 》的 封 面 文 章《对 抗 抑 郁 症》，The Anti Antidepressant。

抑 郁 症 的 英 文，一 个 是 depression，另 一 个 是 melancholia，melancholia 是 一 个 很 古 典 的 表 达，而 现 代 的 抑 郁 症 就 叫 depression，咱 们 还 说 了 美 国 经 济 危 机 引 发 的 大 萧 条，英 文 就 是 Great Depression.。
