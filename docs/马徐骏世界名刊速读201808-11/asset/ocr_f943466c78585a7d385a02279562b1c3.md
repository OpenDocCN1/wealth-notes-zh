# 我们到底是如何选择伴侣的

今天我们讲万古网站上的文章《我们到底是如何选择伴侣的？》，*Keeping it in the family: why we pick the partners we do*? 文章的作者是英国诺桑比亚大学的心理学副教授，汤姆森·萨克斯坦。

伴侣的选择是个复杂的问题，没有标准答案，但是这篇文章的作者认为，人们寻找伴侣的时候，会受到潜意识的支配，寻找跟自己家庭成员在长相上有相似性的伴侣。
