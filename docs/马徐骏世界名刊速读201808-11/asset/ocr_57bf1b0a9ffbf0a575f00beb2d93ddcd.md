# 今日关键词

faceprint：面纹。这是个组合词，就是把face（脸）和print（印记）组合在一起而成的新词。咱们对于fingerprint（指纹）已经很熟悉了，它可以辨识身份、解锁电子设备、用于网络支付。faceprint 就是fingerprint 的升级版。

Straight：直。在今天的内容里，你需要记住另外两个表达：一个是keep a straight face，“正襟危坐、严肃面对”的意思。一个是“异性恋”。我们知道同性恋者一般被称为gay，而异性恋在英语里一个简单的说法，就是straight，所谓的“直男”就是这个词翻译过来的。英文里不用“弯”这个词来表达同性恋，但可以用not straight 来表达。

我们原来开玩笑说一个人关系多，人头熟，到哪儿都有朋友，办事很方便，别人帮忙，他好脸。但现在我们真的可以靠刷脸就能完成很多事了，比如上班打卡、解锁设备。

然而，《经济学人》的文章告诉我们，面部识别技术，不仅仅是一种新技术，它会改变整个人类社会。

# 面部识别技术的应用

对于人类来说，正是由于我们可以识别出不同的长相，看脸认人，我们才能够组建造出一个复杂的社会，而且面部faceprint 作为一个生物特征，不像指纹是相对隐藏的，它是可以远距离识别的。

而且，现在的面部识别技术，甚至可以不受干扰因素的影响。比如剑桥大学的研究生就发现，人工智能可以在一个人戴墨镜，或者化妆的情况下，准确地通过面部特征识别出这个人。

而面部识别技术，正在我们的生活里得到普及。在美国，有一些教堂应用面部识别技术来检测信徒有没有来出席礼拜活动；在英国，有家售香烟的面部识别技术辨别出店里来访者的小孩；今年威尔土警方通过面部识别技术，在一个足球场外，抓到了一个犯罪嫌疑犯。而在中国，面部识别技术，可以应用于上班打卡，也可以用来确认滴滴打车的司机身份，接单前先刷脸卡。

但这些都是面部识别技术的简单应用，faceprint 的功能远不止于此，比如它能够透过面纹来判断一个人的性取向。

# 面纹可以识别性取向

斯坦福大学的研究者迈克.科辛斯基和王宜伦做了一个研究，就是通过分析面部特征来判断一个人的性取向。

他们从美国性交换网站合，搜集了公开的人脸照片，其中有36000多名男性和38000多名女性，总共差不多30多万张照片，过滤模糊不清的照片之后，剩下14000多人的，总共35000多张照片是清晰、可分析的。

然后他们用一个叫 VGG-Face 的软件分析这些人的面部特征，建立了两个预测的模型。因为社交网站上这些人性的取向大部分是公开的，根据资料进行预测，结果发现对于男性中性恋态的预测准确率达到了81%，女性略低一些，但也有71%。要知道如果是让人来预测的话，成功率只有61%。

这是怎么做到的呢？两位研究者说，是因为胎儿在子宫里发育的时候，会受到各种各样荷尔蒙的影响，其中有一种叫做睾丸酮的激素，它会响一个人的面部结构，而睾丸酮也会决定一个人的性取向。有一些人可能分辨不出来的东西，在机器，尤其是人工智能大数据模式识别之下，可以轻而易举地识别出来。

当然，这个研究现在主要还是在实验室里做出的，出了实验室，成功率会下降不少，但也有差不多一半的概率能够判断出来。随着数据量的不断增加和算法的迭代，那么很快就会达到精准的判断了。
