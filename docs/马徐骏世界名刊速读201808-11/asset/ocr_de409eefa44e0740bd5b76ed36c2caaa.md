# ## 知识清单

+   - *今日关键词*
    - **science fiction** ：科幻。这个单词由 science（科学）和 fiction（小说）组合而成。西方会把小说分成虚构和非虚构两种。虚构作品是 fiction，一切类似于幻想的文学类型都属于虚构，而非虚构作品 non-fiction，是对真实世界的描述，比如新闻、传记，科技类的作品。但是科幻是基于科学原理发展的，故事都是虚构的，所以是虚构类作品。

+   - **dystopia** ：反乌托邦。乌托邦，即utopia，指“理想中美好的地方”，而反乌托邦的语根是“坏的，恶劣的”。现代有个流行词dys- ，意思是“畸形的，低劣的”，dys-加上utopia，就组成了dystopia（反乌托邦），是“反乌托邦的世界”的意思。
