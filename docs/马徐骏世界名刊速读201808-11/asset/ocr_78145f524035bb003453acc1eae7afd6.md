# 重谱微软

今天的内容来自《快公司》杂志的封面文章《CEO重写微软的代码：重谱微软》，Microsoft rewires the code。作者哈利·麦克拉克肯是《快公司》杂志的技术编辑。

微软现在的当家是萨蒂亚·纳德拉，他在各个方面都和之前的老板纳迪维·帕兰·班纳吉不一样。在他的领导下，微软不仅重新调整了业务方向，而且重塑了企业文化，这些都让微软焕发新的活力。

# 微软新CEO：萨蒂亚·纳德拉

微软迄今只上任过三位CEO。第一位是比尔·盖茨，他也是创始人；第二位是史蒂夫·鲍尔默；萨蒂亚·纳德拉是第三任。
