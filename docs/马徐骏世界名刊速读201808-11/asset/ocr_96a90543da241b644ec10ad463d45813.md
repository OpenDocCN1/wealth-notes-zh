# | 皇帝的新币

今天的内容来自《福布斯》杂志的封面文章《皇帝的新币》，The Emperor's New Coins，作者是《福布斯》杂志的高级编辑劳拉·申，她专门研究加密货币和区块链技术。

关注比特币的人都知道比特币在8月迎来了大涨，在短短的一年之内就从570美元涨到了4300美元，价格涨了将近8倍。不仅是比特币，其他加密货币也是水涨船高，价格一路飙升。今天这篇文章讲的是，以比特币为代表的加密货币疯狂上涨，除了吸引大量的投资者涌入，成为当红的投资方式，还成为了美国公司进行筹集资金的新方法。

但这一次，《福布斯》是持着看态度的。

# | 加密货币的狂热潮

美国公司已经开始利用加密货币展开新一轮玩法了，初创公司通过发行加密货币来进行融资。

比如说一个初创公司需要融资，那就发行一种加密货币，投资者看好这个货币未来潜在的升值空间，就会去购买这个公司发行的加密货币。如果这个公司之后的发展非常好，就会有更多的投资者想买这个公司发行的加密货币，那这个加密货币的价格就会“蹭蹭蹭”地往上涨了。很可能你早期买的时候是一美元一个，几个月之后就涨到几百美元一个，资产瞬间涨了几百倍。

要注意，和股票不一样，就算你买了这个公司发行的加密货币，它既不表明你拥有了这个公司的股权，也不代表你可以去分这个公司的利润。

用发行加密货币来筹集资金可以玩到多大呢？

今年4月24日，美国一个叫做Gnosis的众筹项目，通过这种形式在11分钟之内筹集到了1250万美元，当时这个项目的估值就上了3亿美元。两个月之后，这个公司发行的加密货币价格，从刚开始发行的29.85美元一个涨到了335美元，一下子涨了十倍多倍，这个项目的估值马上破了三亿美元。

这个估值，比《时代周刊》的母公司时代公司的估值都要高。这个公司创立于1922年，它们用将近100年才攒下的身家，Gnosis两个月就完成了。那你要问，这个Gnosis到底是干嘛的？这个项目叫“基于以太坊的去中心化预测市场”，我是了解一点虚拟货币的，但我也不知道它是干嘛的，我相信绝大多数买了它的人也不知道，但这不正说明了虚拟货币的火爆吗？
