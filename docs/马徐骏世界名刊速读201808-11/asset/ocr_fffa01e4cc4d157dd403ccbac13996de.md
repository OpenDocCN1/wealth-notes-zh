# | 如何使友谊更亲密

今天的内容来自《大西洋月刊》的《如何使友谊更亲密》，How Friends Become Closer。作者朱莉·贝克是《大西洋月刊》的高级副主编，主要负责健康和心理板块的内容。

咱们经常说“天上不会掉馅儿饼”，天上不仅不会掉馅饼，友谊也不会凭空而降，友谊和其他的任何关系是一样的，都需要努力去维系。但是说这话，咱们现在的生活太忙了，需要耗费精力的事情太多了，工作、家庭、谈恋爱……结了婚，这种情况会更明显，生了孩子，那就是上有老下有小，维系友谊就被放到了最后一项。咱们也知道，如果一直这样下去的话，朋友之间也会变得 疏远。

今天这篇文章，就是告诉我们，可以用哪些办法解决这个问题。

# | 渐行渐远的友谊

在现代社会中，人们不仅搬家的次数比以前频繁，活动范围也是前所未有的大。流行病学家大卫·布拉德利曾经对他自己家庭中的四代人做了一个生命轨迹的研究。生命轨迹是动物学的一个术语，用来描述一个动物从出生到死亡一生的迁徙路径。

布拉德利发现，他的曾祖父一生的生命轨迹大约是40平方公里，他的祖父的生命轨迹大概是400 平方公里，而他的父亲，有4000平方公里，他自己的活动范围，则有4万平方公里。

你可以体会一下这个活动范围的倍数级增长，布拉德利认为，这种情况其实是非常普遍的，人类的 活动范围只会越来越大。中国也一样，很多到大城市打拼的人都是背井离乡的，也有人会因为 一份不错的工作就就去其他城市生活，甚至还有人选择出国，我们的生活轨迹比起父辈，大了很多。

人类的活动范围越来越广，对于友谊的影响很大。

一方面，以前人们生活在小范围内，抬头不见低头见，干完了一天出去吃个饭、喝个酒都很容易。家里需要帮忙，喊几声，对门跨几步就到了你家了，亲密度当然深。

另一方面，现在我们搬家如此频繁，当你离开一个地方，你的家人可以跟你一起走，朋友却不行。当然，互联网让任何人都可以和远方的朋友联系上，但这还是有差别的。总搬家，意味着社交圈不停在换，难以建立比较深入的关系。那些经常搬家的人更容易失去朋友，其中一个原因就是他们已经习惯了不断和朋友失去联系的生活。

那么，在现在这种快节奏、高压、活动范围更广的环境下，有没有办法交到好朋友、维系友谊呢？有的。

# | 如何增强友谊

澳大利亚阿德莱德的大学的瑞安·哈伯德从事社会创新设计工作。哈伯德发起一个研究项目叫做风筝线（Kitestring）。这个项目就是想要弄清楚人们如何组织自己的生活，加强友谊，以及到底有哪些让友谊更加亲密的、具体有效的方法。

他们进行了20次深入的采访，以及50次小型的采访。严格来说，这不是一个严谨的学术研究，更像是市场调查，目的是看看在真实操作中有哪些有效的方法。

他们从中还真得出了一些有趣的见解，比如可以通过增加交叉点，不断“切换”以及使用容忍理论来增强友谊。咱们下面就解释这几个方法究竟是什么意思。
