# 今日关键词

- **know it all**：无所不知。注意，这是一个中性的表达。一个人无所不知，未必是好事，因为无是全知无所不，甚至好为人师，所以无所不知也容易让人觉得很讨厌，比如《哈利·波特》系列里，最聪明的赫敏，就被人叫 know it all，而且对方明显是带着嫌弃的语气。
- **Polymath** [polīməθ]：博学者。这个词是褒义的，用来形容像达芬奇、柯南·道尔这样的人。

# Ⅰ 成为一个无所不知的人

今天的内容来自于《纽约客》的《成为一个无所不知的人》，*Know It All*。这篇文章的作者是本·尼特·格登（Benoit Grenand），作者，是一位美国的记者和作家，也是《纽约客》的撰稿人。

今天这篇文章来自于《纽约客》的一个板块，*A Critic At Large*（大评论家），这个板块大家应该对于书籍、思想和言论的评价，这也是《纽约客》上我个人最喜欢的专栏版块，因为《纽约客》杂志涉及领域很杂，*A Critic At Large* 这个板块的含金量是最高的，咱们专栏中《纽约客》的文章大都来自于这个板块。

这次的专栏内容，是作者凯瑟琳·舒尔茨演讲牛津出版社的一套百科全书，叫《通识读本》的 *Very Short Introduction* series。它写了知识非常受限受众的书，还带我们回顾了人类百科全书的发展史。最重要，也是最有趣的地方在于它，我们常说“知识就是力量”，但是知识到底是什么力量？舒尔茨帮我们回答了这个问题。

# Ⅱ 畅销的百科全书史

一般咱们提起百科全书，脑子里立刻会浮现出厚重、编码清晰的书籍。百科全书也是一类最不像特别好的，但百科全书似乎是对于所有问题的终极解释。其实人类一直想通过了解所有事物尽在掌握，并做出最终解释，这种努力本质上就是百科全书的发展史。

然而，百科全书始终有个特别尴尬的问题。首先，知识的迭代让人没法对万物做出最终解释；其次，知识体系太复杂会导致让人困惑阅读。

先说第一点。比如，世界上最早的百科全书，公元前，罗马时代的普林尼写的《自然史》。但是普林尼当时认为世界的认知太有限了。当时罗马流行用铅粉熬膏当做药粉、颜料“萨帕”，阿提尼对此大加赞赏，但实际上，这种东西中含有铅粉，吃多了会造成中毒的。后来罗马帝国灭亡，跟“萨帕”有多，作者普林尼是不知道，而普林尼最后去世，是因为公元79年，维苏威火山爆发，普林尼在逃离过程中，结果火山爆发，最后因为空气太稀薄而死。《自然史》的作者其实对于自然界的事物了解非常有限。

再来从宗教角度，编辑百科全书的两种动力来自于宗教崇拜世俗统治者的需要。比如西方教会势力特别大的时候，搜集知识、编辑全类的书，是有士大夫们这是做不出上的一级，上面伟大的人，咱们熟悉的按照等级，比如说等分法，百科全书是基于宗教的等级划分，先是天使，再是小天使，然后是凡人。

而世俗的统治者，为了彰显自己国力强大，也会编写百科全书。咱们中国有盛世修典的传统，比如清朝的《四库全书》，现代的《永乐大典》。《永乐大典》可算是数字时代到来之前，人类最全的百科全书。

这两种动力都不足自身本身，而且这两者也都不是。就算有认知者，大家都知道，你看，现在咱们的电脑和手机，也可以放下上一套百科全书，但也没谁铺天盖地查看。舒尔茨在文章里写了个比方很形象，百科全书就像是顶楼的单层照明开关，大家都说好，但普通人拍照都是从电梯和手机来照。

# Ⅲ 畅销全球的白小百科全书

一套奇葩的百科全书，改变了这个前提。

1995年的时候，牛津出版社了《通识读本》系列的百科全书。这套书每年会出差不多50个新书，现在已经达到了1250个主题的新版，卖得非常好。这套书翻译成49种语言，迄今为止已经卖出了800万册。但这一套特版的百科全书，完全不符合咱们一般人对百科全书的印象，它有三点特点：简洁、碎片化、不装腔作势，很符合这个时代的特点。

先来说说这套《通识读本》，装帧非常简单，它不是精装本，而是平装书，规格非常统一。每本书讲一个主题，无论主题大小，都是120页，3万5个字单位左右。比如“沙漠”这个小主题，写了一个一本，而罗马帝国历史，像爱德华·吉本的《罗马帝国衰亡史》，是七十多字罗马人的故事，要是满满当当写一百五十页。在《通识读本》里，跟“穷苦”这个主题一样，就一本，120页。

![](img/183bdfd5baf7cb9c4bd26d5a132a702e_190_1.png)

《通识读本》的规划也非常奇葩，特别碎。我们一般看来，百科全书的书节学一个大主题下部分分类，年代、作者，但这《通识读本》不是。哲学出了一本，还有印度哲学，欧洲学，古代物理学，苏格拉底，黑格尔，罗曼这些哲学家常单独出一本书，甚至不少内容还有交叉和重复。

更有意思的是，《通识读本》不写自己收录的主题做终极解释，它去写得有趣。比如“沙漠”这个主题，咱们会觉得，这是一句话就能说得清的事儿嘛，甚至写一本书，沙漠本沙漠历史、沙漠的动植物，谈到沙漠的面积约地球表面的25%，但后告诉你，沙漠雨其实算不上准确定义，不说沙漠少沙，沙多就都是沙漠，实际情况复杂得多。

最后作者给出了一个非常有意义的定义。如果说你给一个满杯的放在里面，这个地区如果是沙漠，那么，海洋里也有干旱的沙漠，甚至海洋里的小城就是沙漠。

按照这篇文章作者凯瑟琳·舒尔茨的说法，《通识读本》就是对所有的知识做一个切片，切割每颗算子，而且《通识读本》实际就是主题，虽然你看可能也想不通，居然是“全球化”和“文学理论”。

你可能会这一个问题，像“全球化”“文学理论”这种知识，找谁道了有啥用？要，牙齿、沙漠、哲学，音乐……知道了又干啥用呢？

道了又有什么用呢？

# 知识有什么用？

很多时候，普通人都在问一个很难回答的问题：我知道这些知识有什么用？能升职加薪吗？都说知识就是力量，知识到底有什么力量？

作者舒尔茨在文章里对这个问题有一段很棒的回答：“我们的认知，可以改变我们的行为，也许不是立竿见影，也许会有反复，但是拥有知识，已经足够对人产生决定性的变化。”

从大了说，如果人们对宇宙的认识，停留在教会宣传的“地心说”，那么人类就不会发展到今天的科技水平；往小了说，朋友圈里过分迷信养生文章的人，跟拥有科学常识的人，无论是生活方式，还是看待问题的角度、处理事情的方法，都是截然不同的。人的行为是很难改变的，但拥有知识却可以简单地做到。因为知识是思考的起点，思考是行动的起源，所以无论教会还是过去的统治阶级，牢牢控制知识，就是为了能够控制住人的行为。

总结一下，知识不在于编撰得多全、多好，而在于能让多少人知道，影响多少人，不用大部头吓唬人，不把自己当做解释问题的终极权威。而这，正是《通识读本》这套百科全书的成功之处。

**《名利场》：Vanity Fair**

周一我们讲的是《名利场》杂志最新发布的《2017 年度成就榜单》，*The 2017 New Establishment List*，今年这份榜单的总评委，是《乔布斯传》的作者沃尔特·艾萨克森。

标题中这个 establishment 来自于它的动词 establish，“建立”的意思，所以 establishment 原来的意思是“地位高”，可以理解为已经建立声望和地位的人，《名利场》的这个榜单其实就是评选各行各业的牛人。

说到 Vanity Fair，学英国文学的人有一本必须知道的小说，就叫《名利场》，它是十九世纪英国讽刺现实主义作家威廉·萨克雷的作品，讽刺了上流社会的骄奢淫逸，但是《名利场》这本书也不是这个意思，而是在告诉你上流社会是如何生活的。

有意思的是，文学作品一般都是对上层社会的人情人性放批判态度，快乐好人的电影也总是在描写穷人是多么快乐，富人怎么虚伪伤心，但这其实是常识。从现实的视角来看，钱只要是自己劳动的，财富与尊严正当地位来的，有何不好？人生高潮，难道不更高也能吗？有更富贵的日子，生活质量更高，社会也会更好。

Vanity Fair of the fair 有另一含义就是“市集”，英语里有个表达叫 fair play（公平竞争），之所以这么说，是因为古代集市中做买卖，如果不公平肯定就没法交易的。由此看出，西方商业文明对于信誊和公平很看重。这引出了另一个表达—fair and square（光明正大的），fair（市集），square（广场），在广场上做生意，可不是光明正大的嘛。与之相反，地下交易也叫市语，是 black market。

英国也一个非常有名的旧事，叫《斯卡布罗集市》，它的英语就是 *Scarborough Fair*，经典电影《毕业生》里，Simon 和 Garfunkel 唱过这首歌曲全球通。斯卡布罗集市市历史上真实存在过的一个商贸贸易活动，中世纪从斯克里夫尔到附近的斯卡布罗集市，从丹麦运到欧洲波斯的商，几乎所有的商人人都聚集于此，参加这个为期45天的集会，算是英国第一个商贸集市，那么多人聚集到一块，显然会有各种各样的娱乐活动，所以游乐场的英文叫 fun fair，跟这个也是有关联的。

来源：《名利场》2017 年度新成就榜单

# ❏ 意想不到的成就

今天我们讲《万古》网站的一篇文章《意想不到的成就》（*An unlikely triumph*），这篇文章说的是美国的高等教育是怎么回事的。作者大卫·拉尼是斯坦福大学的教授，还曾经担任美国教育研究院的副院长，写这篇书是他在今年新出的新书《完美的混乱：美国高等教育意想不到的崛起》的摘要。

美国的高等教育是世界一流的，全世界排名前100的大学里，有52所来自于美国，排名前20的大学里，美国更是占了16所。21世纪，有一年的诺贝尔奖都颁给了美国的的研究机构。但如果时间回到150年，19世纪时是美国高等教育刚刚复苏时期，那是个笑话，欧洲人都嘲笑美国人，"就你们那些学校，也好意思叫大学？要人力没人，要钱没钱，总归在角落背弃的。"别说学术成果了，连生存下去都困难。

谁都不会想到一个世纪以后，从20世纪中开始，美国的高等教育一骑绝尘，成为了全世界所有国家都羡慕，资金相对富裕，培养世界其他国家精英的摇篮。它是怎么做到的呢？

# ❏ 为搞房地产建大学

文章里说，美国的高等教育一开始就跟欧洲的模式完全不同。欧洲的 Oxbridge model (就是指牛津的牛津、剑桥模式) 是非常典型的贵族学校，主要是由政府和教会出钱并且主导的，其实现在中国的高等教育也是这个模式。但美国一开始搞大学的目的，是为了增加土地的价值。

建国初期的美国地广人稀，土地资源比买土地的人多多了，怎么才能把自己手上的地卖个好价钱，怎么才能让投机者们 speculators 们头脑里的问题，甚至连富坚万·沃什、华盛顿，都一直试图把手里的5万英亩土地卖个好价钱，但却始终都没成功。

到了19世纪，投机分子想出了个好主意，就是给土地增加文化价值。他们自己手里的一部位土地出钱来建大学，然后大学周围的土地不就升值了吗？其实直到后来房产开发商也在用这招。比如，建个高尔夫球场，然后坐等周围的土地和房价升值。后来，这种模式开始流行起来，当时的美约大学如同雨后春笋一样被建立起来。到了1880年的时候，光是美国俄亥俄一个州，就开了37所大学，当时整个法国一共才有16所大学。

大学建了，总得有人来。当时的美国没那么多人口，所以大量的学校都是教会学校，宗教办学当时的是确实有明星校办学的。总之，生财道，虽然来人是大学的人不多，但至少教会的信徒还忠实的。其次，师范问题总得解决掉，那时候的大学老师基本都当校数，受过良好教育，而为了信誉，要的工资也不高，教会还时不时给点拨款救一救一下，至少能让这个大学活下去。

虽然这些大学后来渐渐褪去了浓厚的宗教色彩，但是这样的起点，给美国的高等教育留下了非常独特的烙印，形成了一直追溯到今天的历史特色。

# ❏ 历史造就的特色

聊起美国的高等教育，肯定会说到很多有特色的地方，比如大学位置偏、学费高，私立学校比公立学校好、校友网络最强大、气候款般为强、求教学员发展自由等等，其实这些都和美国高等教育发展的历史有关系。
