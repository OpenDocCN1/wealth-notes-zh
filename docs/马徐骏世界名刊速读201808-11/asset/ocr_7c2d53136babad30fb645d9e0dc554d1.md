# 今日关键词

+   - journalism: 这个词来自于 journal，除了我们比较熟悉的意思“日志”外，它还有一个意思是“期刊，杂志”，引申到 journalism 就是“新闻业”的意思。
- traffic: 这个词不只是“交通”的意思，它也用来表示“流量”。比如说网络流量就是 web traffic，获得流量可以说 earn traffic。

# 硅谷已经掌管了新闻业

今天的内容来自《大西洋月刊》封面推荐文章《硅谷已经掌管了新闻业》，When Silicon Valley Took Over Journalism。作者是美国老牌政治杂志《新共和》的前主编富兰克林·弗尔（Franklin Foer）。

《新共和》是一本有100多年历史的老牌杂志，在美国话语权极高，被称为美国自由主义舆论旗帜。它在2012年曾经被Facebook合伙人克里斯·休斯（Chris Hughes）收购，在后来的几年磨合中，以失败告终。

《新共和》不是特例，很多传统媒体都被硅谷公司收购了，比如说亚马逊创始人兼CEO杰夫·贝佐斯在2013年的时候收购了《华盛顿邮报》，苹果创始人史蒂夫·乔布斯（Steve Jobs）的遗孀劳伦娇·乔布斯（Laurene Powell Jobs）就在今年，宣布收购《大西洋月刊》，也就是咱们今天讲的这本杂志。
