# 知识有什么用？

很多时候，普通人都在问一个很难回答的问题：我知道这些知识有什么用？能升职加薪吗？都说知识就是力量，知识到底有什么力量？

作者舒尔茨在文章里对这个问题有一段很棒的回答：“我们的认知，可以改变我们的行为，也许不是立竿见影，也许会有反复，但是拥有知识，已经足够对人产生决定性的变化。”

从大了说，如果人们对宇宙的认识，停留在教会宣传的“地心说”，那么人类就不会发展到今天的科技水平；往小了说，朋友圈里过分迷信养生文章的人，跟拥有科学常识的人，无论是生活方式，还是看待问题的角度、处理事情的方法，都是截然不同的。人的行为是很难改变的，但拥有知识却可以简单地做到。因为知识是思考的起点，思考是行动的起源，所以无论教会还是过去的统治阶级，牢牢控制知识，就是为了能够控制住人的行为。

总结一下，知识不在于编撰得多全、多好，而在于能让多少人知道，影响多少人，不用大部头吓唬人，不把自己当做解释问题的终极权威。而这，正是《通识读本》这套百科全书的成功之处。
