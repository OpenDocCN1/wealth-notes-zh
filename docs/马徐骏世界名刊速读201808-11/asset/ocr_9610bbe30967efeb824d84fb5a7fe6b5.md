# 今日关键词

budget [budʒ] 预算。这个词既是动词也是名词，还有形容词的属性，搭配非常多。比如，国家的总体预算，overall budget；军事预算，Military budget；为什么预算紧，budget for sth；预算赤字，budget deficit。

hedonic treadmill 享乐适应症。Hedonic [hɛ'dɒnɪk] 是快乐、快乐，treadmill 是水的踏机轮也是跑步机，它跟水车一词，都含有循环往复的意思。所以，hedonic treadmill 也可以意译为“快乐水车”。但是经济学上的一个概念，意思是人们不断努力去追求快乐，却给自己带来更多压力，结果追求的生活并不能给自己带来快乐。这篇文章会教我们怎么去对抗享乐适应症，或者反来到利用它创造幸福。

# 怎样做预算才能让你更幸福

明天就是双十一了，这个时候，很多人的购物车里，可能已经涌进了存款，或者他们去超市了。我建议先别着急，听我看完今天的这部分内容，学一下怎么更好地做预算，不但省钱，还能让你更开心，也不用因为冲动消费后让下半个钱包。

今天我给你介绍《今日心理学》杂志上的一篇文章《怎样保持预算才能让你更幸福》，How To Budget For More Happiness。这篇文章的观点是：预算并不代表一定是要少花钱，而是要精明地花钱。

这篇文章的作者是捷克克戴维斯，他是一位专门研究幸福的专家，他说写这篇文章的目的也是想告诉大家，怎样才能更好地提高生活质量。

# 四种消费类型

乔治大学的马克·格伦博士，把消费分为四种类型：固定支出、可变支出、欲望型支出和需求型支出，英文分别是 fixed expenses，variable expenses，wants expenses，needs expenses。

固定支出（fixed expenses）指的是我们必须的生活开支，每个月、每年都要花的钱，比如房租、电话费。

可变支出（variable expenses）指的是预料之外的消费，比如朋友借给你的钱、停车等费用等地方花的费用。

我们想要快乐，首先得满足基本的需求，比如说租房、食物，你吃不饱穿不暖，没地方住，肯定快乐不起来啊。而可变型支出对我们的生活质量也有影响，比如，你突然车坏了、要修车，或者生了一场大病，这些事儿，都要掏钱，也都不便宜，如果你是月光，一下子拿出一大笔钱，那你就得焦虑了。

另外两类：

欲望型支出（wants expenses），是指我们为了自享乐而花的花费，看电影、喝咖啡之类。

需求型支出（needs expenses），指的是我们满足自身必要需求的花费，比如买房、教育等，每个人都不太一样。

这四种支出类型是可以互相组合起来的。比如：

固定需求型支出——你有车，每年必须要花油钱洗车钱。

可变需求型支出——你突然得了一个病，意料之外，但是要花一笔钱。

固定欲望型支出——你习惯每天去喝明星宝兑的星巴咖啡，那这是你每天必去的。

可变欲望型支出——你出去旅游的冲动消费之类。

作者的意见是，对于固定支出，不管是欲望型的还是需求型的，都要尽量削减，而且削减得越多越好。有人可能会说，这样会降低生活品质啊！

还记得吗我们今天的关键词 hedonic treadmill（享乐适应症）吗？

作者说，有人愿意承受高贷款，只为了住在一个特别好的房子里，或者说他很高了，分期付款买辆好车，生活品质是很高的，这就于需求型固定支出，但是很快也就习惯了，其实没办法给我们带来很大的快乐，而如果为了买个大房子，导致生活质量是降低了，反而让你变得越来越不开心，甚至你可能为此背上了很多的贷款，想到这些就会让你焦虑而不快乐。这样的支出能够以外看。

而类似每天叫外卖，天天喝咖啡这种欲望型固定支出，一旦成了习惯，也不能增加我们的快乐度，但是支出是在那里的，那你这个花费也是应该收缩的。

作者说，享乐适应症也是可以被利用的，等到你适应了下外来的状态，也不会有多难受的，那种对每项消费支出，我们有什么具体的省钱窍门吗？

# 怎么省钱更幸福

首先是固定需求型支出。房子的租金总不能再低吧？作者说其实是可以省的。

她举了一个例子，从2015年开始，作者就设法租房子了，她的方式就是把自己的房子，挂在airbnb上出租，这些来短短的租客，交的就能够弥补房租，而从2015年开始到现在，两年多的时间，作者总共省出了一个21,000美金，差不多有14万人民币，对于一个有小孩的家庭，当年没有人花这些钱，也无孩孩子，所以相对来说很自由，但是这单靠租来代替自己的，看起来好像省不出来的这种想法，换个方式居然也能减少，甚至全省下来。

第二种是固定欲望型支出。我们前面讲过，这种支出可以完全节省下来，习惯了也没设问题。

如果你每天下30多块钱的咖啡，一年那也真上万块钱了。那你可以会前，但也就是喝喝，你不喝吧，或者还是举举例来说吧，很多喜欢喝星巴克果汁，后来发现，如果买了浓缩果汁，自己兑点水喝，味道是差不多，但是这个浓缩果汁便宜很多，于是她就为买，结果每年光果汁一项省了400美金。如果你天天习惯喝咖啡，那么可以从精磨咖啡换得买，也省了不少钱，所以长期来看，省得还不少。

而可变欲望型支出，应对的办法是买个保险，一些商业上的健康保险，开车的车辆和人身保险，这些不是不该省的，看你是小镇，但万一不出事儿，看保险有省多少
