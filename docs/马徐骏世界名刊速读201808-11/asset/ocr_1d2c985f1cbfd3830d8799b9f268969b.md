# 1 代码的末世论

今天给你讲《大西洋月刊》网站的一篇文章（代码的末世论），What you see is what you get。

如今有一句正在西方世界越来越流行：软件正在吃掉整个世界（The Software is eating the world），我们在许多大型公司的科技餐桌上都全看到这句话。越来越多的公司声称自己在转型，或者正在变成科技或软件公司，为客户提供最复杂的解决方案。这也意味着它们对员工的软件控制能力提出更高的要求，在快速被编程，程序所掌控，说到底还是代码的另一种。与之息息相关的互联网行业也在蓬勃发展，可以说，代码，正时刻都在改造着我们的生活。

# 1 代码惹的祸

2014年，美国曾经发生一件事，整个美国为了申请了911报拨服务而停止了。在西雅图，一个女人去打了911少了37次，但是回拨的次数只有三次。不止是华盛顿州，这次危机几乎遍布了加利福尼亚、北卡罗来纳、加利福尼亚州等各个州的系统。最终发现，导致这次事件发生的罪魁祸首，就是科罗拉多一家服务网上运行的软件。这一软件供应商的程序员在测试的间隔搞高了一些东西，从而造成了全国范围内大面积的服务器瘫痪。

就在一年之后，2015年的一天，美国联合航空公司的全部飞机停飞了，因为管理系统出现了问题。与此同时，纽约证券交易所交易软件也突然暂停升级，华尔街日报的网页真着要瘫痪。这一切的发生都是因为服务器配置问题造成的。而最可怕的问题是，人们意识到，这次 崩溃的发生只是一个巧合。

这些灾难事件引起了学术领域的关注，在美国麻省理工学院航空领域学者，从事软件安全研究超过35年的教 授南希·勒文森在接受采访的时候，他们曾经认为所有人来做更精力的系统，都是有秩序 的，可以进入一个状态或者想去思考，比如说我们设计一个 机场系统，你有用每张图来 表现一 抽象整体的时候，你可以用每一个配置都 知的事情，着它去 思考。一旦你开始对建立起来的秩序，就会精确 知道 知 处理而掌握一些突发状况。
