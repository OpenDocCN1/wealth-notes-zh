些有效的方法。

他们从中还真得出了一些有趣的见解，比如可以 通过增加交叉点、不断“投标”以及使用容器理论 来增强友谊。咱们下面就来解释这几个方法究竟是 什么意思。

# 1.增加交叉点

人们对于友谊的理解，比较像是在一张白纸上画 下交叉点。比如说，你在公司的朋友，你们只 在办公室见面，你们之间的交叉点，就是办公室。 和你有某种共同兴趣的朋友，你们也只有在某个 兴趣点上面有交叉点。如果想要有更深入的友 谊，在这张白纸上，你应该画下更多个交叉点， 让你们在不同的场合、不同的事情上面都有交 集。

# 2. 不断投标

“投标”这个术语借鉴了心理学家约翰·高特曼在 恋爱关系上的研究。向对方投标可以包含各个方 面，从给对方一个微笑，主动和对方交谈到邀请 对方和你的家人一起出去旅行。在人际关系中， 无论是恋爱关系还是友谊，对方对你的投标回应 得越多，你们的关系就会越深。对方面前就对你 的投标拒绝得越多，你们的距离就会越远。这就 像是一个循环一样，互动越多，循环就越强；互 动越少，循环就越弱。

这个方法的重点是，总有一个人要主动开始。很 多人都会有这样的想法，你没有给我打电话，那 我也不给你打电话。但如果你真的在乎这段友 谊，其实谁先开始并不重要。

# 3. 容器理论

容器理论的意思是把你和朋友的关系统系在固定的 容器里，会更容易维持。这个容器，指的就是固 定的常规活动。比如说，每周一聚聚会晚餐，每 个月一次的读书会，总之，就是大家定期共同做 些事情。

# 4.移情法

容器理论还有一个升级版就是移情法。移情你的 友谊。什么意思呢？当家里的植物长得更好的 时候，你会把它换一个更大的花盆里。一样的道 理，比如说你在工作中交了一个朋友，你每天 能见到对方，但是你们见面的唯一场所就是办 公室。如果你想深入发展这段友谊或者强化这段友 谊的话，你就得把你们的友谊放到一个更大的 容器里。比如说，邀请对方来你家做客，让他 参与到更多的生活中去，你们的关系自然会更加 亲密。

当然，如果你和新交的朋友，就得注意一下 你们之间的亲密程度和距离。如果你们之间熟悉了， 你们可以亲近，就像咱们前面说的关键词 intention，你可以展现出更强的想要和对方多 交往的意向，对方一定会很开心。但如果你们认 识还没多久，你就得注意一下你们之间的距离 了，就像咱们前面说的，你们之间需要一些空间 （You need some air）。

好，总结一下今天的内容，现代快节奏的生活方 式，以及人类活动范围越来越广，影响了人们之 间的友谊。针对这种变化，我们并不是无计可 施，通过增加相互之间的亲密，多创造一些固定 的活动，或者将你和对方的友谊放入更大的“容 器”，都可以让你拥有更深入的友谊和更多的朋友。

同时，我们对朋友也要多多理解，有些时候生活 就是太忙，太累了，朋友的疏远可能真的是顾不 过来。文章里有句话说得特别好——友谊的精 髓就在于它让人们对彼此尊重、彼此鼓励，生活 也因此变得无比美好。
