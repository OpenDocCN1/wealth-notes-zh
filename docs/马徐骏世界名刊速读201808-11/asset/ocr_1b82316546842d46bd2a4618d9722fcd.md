# | 关于抑郁症的三个认知偏差

今天的内容来自于《时代周刊》的封面文章《 对 抗 抑 郁 症 》， The Anti Antidepressant。这篇文章的作者是曼迪 ·奥克兰德，她是《时代周刊》健康版的副主编。

文章指出，我们对抑郁症有三个认知上的常见偏差，一个是觉得抑郁症是现代人才会得的都市病，第二个是，有的人会小题大做，会把自己的不愉快、情绪低落，当成抑郁症，我在文稿里给出了美国国家心理卫生研究所列出的抑郁症主要症状，一共有十一条，你可以自己对照一下，不符合的话，不用担心自己患上了抑郁症。第三个偏差是，有很多人并没有意识到抑郁症的可怕和抑郁症患者的痛苦。

患上抑郁症的人，其实是非常痛苦的，严重的会引起自杀。抑郁症患者会拒绝交流，所以更需要周围人的关心。有些妈妈可能生产完孩子之后产后抑郁，对自己和孩子的健康，甚至整个家庭都有影响。所以抑郁症并不遥远，也需要引起我们的重视。

# | 抑郁症的历史

这篇文章参考的坐标是美国，在美国患有抑郁症的人可能比你想象的要多，占了美国整体人口的6.7%。差不多有1600万人患有抑郁症。

虽然现在有很多治疗抑郁症的方法，包括药物治疗及心理治疗，但是这篇文章告诉我们，有1/3的抑郁患者，是尝试了多种治疗方式之后依然无效的。甚至可以说，在过去的30年里面，其实我们并没有什么特别有效的，对抗抑郁症的手段，我们甚至对于到底是什么引发了抑郁症，也并不清楚。医学上一个相对比较主流的说法是，抑郁症，是人脑中的三种神经递质血清素、去甲肾上腺素和多巴胺，减少引起的。

而且抑郁症并不是一个新鲜事物，它几乎贯穿了整个人类的历史。

古希腊的时代，人们就已经意识到抑郁症的存在了，那时候管它叫melancholia（忧郁症）。根据古希腊的哲学分类，忧郁症被认为是黑胆质分泌过多造成的，那时候采用过放血、呕血、节食等各种各样的疗法，都没啥用。
