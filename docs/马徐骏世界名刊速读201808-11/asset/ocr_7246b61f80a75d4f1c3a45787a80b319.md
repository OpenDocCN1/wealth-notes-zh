# 知识清单：

# | 今日关键词

Silver Time Bomb：银发定时炸弹。指的是社会人口结构呈现老年状态，进入老龄化社会，这会像炸弹一样，对社会、经济结构带来不良影响。

Baby Boomers：婴儿潮一代。指的是美国第二次世界大战后的“4664”现象，也就是从1946年至1964年，这18年间，出生的人口高达7600万，这个人群被称为“婴儿潮一代”，也是现在老年人口的主要组成。

# | 新生代老年人

今天我们来讲《经济学者》的一篇特别报道，主题叫《新生代老年人》，*The New Old*，哈葩们之前讲过，《经济学者》每年特别报道的数量不多，但是质量都奇高，一组文章，就可以把某个领域的问题分析得清晰又透彻。这篇《新生代老年人》，是从全球，特别是西方老年人的角度，分析了老年人职业观、消费观、恋爱观等问题。

# | 长寿红利

很长一段时间以来，社会学家和经济学家，都对“Silver Time Bomb”银发定时炸弹发出过很多的警告，仿佛一个人进入老年阶段，就是放弃人生的信号，而他们所待的国家也必须担负起养老金和医保开支的责任，承担着巨额的财政压力。

但这篇稿子提出了一个新的观点，就是新生代老年人（The New Old）是激活国家“长寿红利”的关键。同时也让新生代年轻人意识到，随着人类寿命的增长，我们需要对65+人的职业生涯和“新退休”生活有着更新的认知。

# | 退休只是新工作的开始

婴儿潮这代人今年，不少已经退休或者不久就要退休了，他们中的很大一部分已经有了计划：到了正式退休的年纪也要继续工作。

但社会机制面对这代人的需求，却没有完全准备好。荷兰全球保险集团（Aegon）最近的调查报告指出，超过一半以上的55岁以上的被雇佣者希望能继续工作，更加灵活地向往退休过渡，然而只有不到25%的雇主愿意让他们以兼职形式继续工作。

好在跟年轻人不一样的是，大多数老年人找工作并不会考虑升职加薪的问题，就是想找事做。因此不少婴儿潮一代的老人，也开始蹭起了热点，比如共享专车。

在美国共享出行领域，排名第一和第二的Uber和Lyft中，超过1/4的司机年龄都超过了50岁。美国的司机年龄没有上限，只不过到了一定年龄就需要每隔几年申请一次延期驾照，所以只要开车开得动，年纪不是问题。

一位同时兼职Lyft和Uber的60岁老司机Ayluk Durgun，他的口头禅就是“我的生我做主。” “I Now I manage my own fulture, I manage my own life.” 这句话说出了大部分婴儿潮老人的心声。

能税前月入6千美金，还能与世界各地不同的年轻人们打交道，这些婴儿潮老人甚至觉得自己找到了预防老年痴呆最好的方法。

除了享受“共享经济”的红利，也有更多的婴儿潮一代瞄准了“创业”。据考夫曼基金会（Kaufman Foundation）的统计，在美国，55岁~65岁的人创业的可能性，比20岁~34岁的人高出65%；在英国，70岁以上仍在工作的人群中近60%都是创业者。
