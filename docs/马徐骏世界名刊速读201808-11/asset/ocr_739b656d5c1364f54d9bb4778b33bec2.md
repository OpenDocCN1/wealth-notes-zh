# ｜成功人士怎么利用“复合时间”？

我们通常在听到各种成功人士的生活或学习方法时会觉得没有可比性，比如听到投资大神沃伦·巴菲特会拿出大量的时间读书，很多人心里可能都会想：“我和他能一样吗？人家那么有钱，当然想干什么干什么。”

作者说：“你错了，巴菲特在还没有成为股神之前就是这么做，不是因为他有钱了，然后才有了高效的生活和学习方式，正是因为他持续的学习、成长，让他总能做出正确的投资决策，才有了他如今的成就。”

那些高手利用复合时间都做了什么呢？他们强调刻意休息，持续的、长年累月的阅读，以及与他人交流想法激发创意。听起来很普通，普通到我们觉得做了这些事情就会有多了不起。可就是这些看似最普通的习惯，在日复一日、年复一年的时间里被坚持做，最后会变成一种让人“仰望”的存在。这就是“时间的复利”。

文章里有一个方法，是作为NO.1，头号方法提出的，就是“积极的自我暗示”。它是生活里很小的一个细节，是关于如何清醒地开始和结束每一天。

作者发现，这些成功人士都会在清晨给自己积极的暗示。比如杰米·弗林·布莱尔，她每天早上会问自己：“我今天会做点什么特别的事？”乔布斯则是每天早上会站在镜子前跟它说：“如果今天是我生命的最后一天，我还愿不愿意做今天要做的事？”再比如说奥普拉，她更加直接，每天早上都会写感恩日记。

听到这儿，你可能会觉得这是“鸡汤”，但其实不是，这是一种心理学方法。

有一个社会心理学现象叫做“自证预言”，指的是我们总会在不经意间使我们的预言成为现实。你给了自己积极的暗示，最后的结果就会朝着这个方向去发展。所以，在清晨给自己积极的暗示，实际上就是应用了这个心理学概念。

而晚上要结束这一天的时候，这些人会盘点这一天。比如亿万富豪雷曼·雷曼会在睡前做“睡前复盘”，他会问自己：“我今天学到了什么？有哪些事情可以做得更好？明天最重要的事是什么？”

他们通过这样每天一“复盘”的方式，每一天，都给了自己一个积极的开始，和一个经过思考的结束。

我们身边也有这样的人，他们每天做的事情和我们差不多，只不过每天多翻几页书，比我们多写几句备忘录，多学一门技能，多思考一会儿。他们看似只是多花了一点，但一年年下来，这种“复合时间”带来的差异，就足够让他们在人生轨迹上跑出不一样的结果。

总结一下，这些成功人士在每天开始之前，会给自己积极的暗示，在每天结束之前，他们也会复盘这一天。他们利用这些“微小的间隙”来积累“复合时间”，最终让时间产生了复利的效应。

在做这期节目的时候，我接触到了一个概念，叫做“高浓度效应”。这是每个人都可能会遇到的现象，即你在某段时间内做某件事的效率极高。
