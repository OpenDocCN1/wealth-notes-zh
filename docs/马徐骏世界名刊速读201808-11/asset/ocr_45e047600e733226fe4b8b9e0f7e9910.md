# | 美国弗吉尼亚暴力事件

美国弗吉尼亚州暴力事件的起因是夏洛茨威尔市要拆掉一尊美国南北战争时期，南军总司令罗伯特·李将军的雕像，然后这件事引发了白人至上主义者和左翼抗议者之间的暴力冲突。简单来说，这好像是美国左翼和右翼之间的冲突，但整个事情的过程更复杂得多。

今天我来讲一下，这件事到底是怎么回事，西方媒体是如何报道这件事的，四大周刊《经济学人》《纽约客》《时代周刊》和《新闻周刊》各自的侧重点有什么不同，同时也能让你更了解这些杂态的政治谱系和倾向。

# | 暴力冲突是怎么发生的？

这次暴力事件发生的地点，弗吉尼亚州是偏保守的南方州，而南方州支持共和党的居多，共和党也就是特朗普代表的党。但是，弗吉尼亚又是个夏洛茨维尔市，是个大学城。我们都知道，知识分子支持民主党的更多，所以在政治生态上，夏洛茨维尔市像是在弗吉尼亚一片红色的共和党包围下，一座支持民主党的蓝色孤岛。这样的地方，当然就容易成为冲突发生的地区。
