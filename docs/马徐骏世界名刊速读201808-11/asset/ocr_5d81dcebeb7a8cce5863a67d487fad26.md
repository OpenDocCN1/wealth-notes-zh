# | 文明的诞生

文明是褒义词还是贬义词？可能绝大部分人的第一反应都是，褒义词啊！文明难道不好的吗？

这个问题的答案来自于《纽约客》杂志的文《文明究竟是如何产生的？，How Civilization Started》。这篇文章的作者劳伦斯兰伯特是一位著名的记者和作家，他在德国上学，在香港长大，在英国受过的教育。

所以，上面那个问题的答案是：文明是中性词。

作者的文章里说了三个对于人类文明至关重要的技术突破：火、农业、书写。

# | 火与文明

人类最重要的技术发明就是火，根据耶鲁大学政治科学教授詹姆斯·斯科菲尔德的研究，火对人类来说至少有两个重要意义：

首先，火使得人类可以烹饪食物，这不但使人类从食物中获得的范围更多，同时扩大了人类采食物的范围。跟人类基因非常相近的黑猩猩的最短肠道是人类的三倍大，因为它们吃下去的食物就消化掉。用火烹饪食物另一个好处就是，人类可以负担得起我们非草食的犬齿，人类的大脑消耗了身体1/5的能量，而一般哺乳动物的大脑，只消耗了1/10的身体能量。

其次，火使得人类可以根据自己的意图来改造周围的环境。

斯考特教授认为，就是因为这项技术的发明，使得人类食物由原始到居住的习惯，因此发明家们发现最早六原的洞穴，经过南非非发现，这些洞穴的主人是鬣狗，因为科学家从这些洞穴中一层层发掘出了完整的鬣狗骨骼和一些人类骨头的碎片，这说明那个时期，人类只是潜在的食尸者，也就是说他们吃鬣狗吃剩下的动物骨头上的肉，在洞的底层里，火文明是人类完整的骨骼和动物骨头的碎片，这说明鬣狗先食发生了逆转，人类把其他动物变成了盘中逆转。
