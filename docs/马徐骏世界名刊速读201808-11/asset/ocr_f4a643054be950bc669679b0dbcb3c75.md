# ### | 今日关键词

DINK：丁克。它是“Dual Income、No Kids”的缩写。dual的意思是“双，两个的”，income是收入，连在一起就是“双方都有收入，但是没孩子”的意思。

# ### | 无子化的兴起

今天的内容来自《经济学人》，标题是《无子化的兴起》， The Rise of Childlessness。

这篇文章，将目光聚焦在发达国家，比如英国、德国、美国等。在这些国家里，无子化的现象越来越明显。这篇文章讲的是这一现象背后的原因。

总体来看，人们会出于各种原因不要孩子，但是其中有很大一个群体，他们被南普顿大学的人口统计学专家安·伯林顿（Ann Berrington）称为永久拖延者，这些人觉得自己应该在完成了所有教育之后再组建家庭，组建家庭之后，还得再有一份稳定的工作和住所，在这一切都完成了之后，他们才觉得可以要孩子，而一般来说那个时候已经太晚了。
