# 用户留言

今天这篇文章有些高端，不过这个问题，和人的大脑，细胞构成几乎是完全相同的，但为什么每个人体会出来的聪明才智是不一样的呢？这个问题给我的启示是，我们现在对于大脑的理解是处于一个相当肤浅，而只有在更细微的层次中，才能把新的解决办法和更复杂的问题，换句话说更深层的，另外就是拓扑数学的应用也是说工具不光是解决问题，也是一个思维方式，学习一个工具多了一个看世界的角度。

这一期内容一定要和《数学的起源》结合起来看。在那篇文章里探险：“人类不过在数学的庞大丛林里探险，发现了不知道的的秘密而已，而随着每一次数学的新发现，我们对世界和宇宙的认知就会扩大一点。”对于大脑也是一样，这个精密复杂的思维宇宙也许只有借助数学，就能比细胞生物学，从更高的维度上探索才能揭示出意识的神秘罢了。又觉得，大脑的终极意义如果彻底暴露了，人类的独特性会不会丧失，人工智能会不会变成仅像上一期专栏里讲到的《银翼杀手》里的仿真真人。

读后感：数学是万物之根本，相比之于土壤海洋，它是一种无形的存在，需要用独立的一种语言来描述可视化和可感知。人的意识作为一种无形的存在用数学的语言来解读至少不会出现南辕北辙的错误。

单个人工智能=封闭的算法+大数据云计算，而模型=多个人工智能的有机组合，现在看问题呈现。人的意识是多个模型多个维度的翻译器，这用顶级大师作原型，当大师逝世后，完全可以克隆大师死前一样的机器入大脑，达到大师大脑意识永生。如成功，奇迹就在眼前。

这篇文章反映了西方的一种思维倾向，那就是数学是宇宙基本的底层代码，任何科学的底层就是数学，如果部分科学还不能数学化描述，要不然就是研究的还是太表层，要不就是还没有发现合适的数学工具。

人脑从基因上就有很大的不同。神经传递的速度、酶化程度、突触的数量在先天上就决定人的智力有差异，而从婴儿一出生，外在的环境就在不断塑造其中的神经元结构，这就是为什么说一卵双生的双胞胎都不能保证后天接受的刺激完全一致，更不要说放在社会层面上比较。

人脑中的神经团结构可以用拓扑学数据结构来说明，这确实是一个了不起的发现，对人类智能模拟人脑肯定有巨大的促进作用，能否取得是否为了高维度，还为时过早，至于能否解释意识的产生，更是一个很难说的问题，至于人工智能能否产生意识，是不是人类一样的意识，或者是否需要深入追究什么是意识，人工智能能否拥有意识，只不过这种意识和人类完全不同，人类也不能理解这种意识，就好像低维生物难理解高维生物一样。

还是拿地铁公交图做比，当一个城市有三条地铁线，几十个站点，大多数人不借助手机app就不知道怎么换乘了；而大脑，有千亿级“站点”，很多路线随时而停，这都能正常运行，对于路痴的我，有这么多厉害的大脑，不服自己都不行。至于“拓扑书”，我最好最近在着，才刚看到一般拓扑第二张就对于数学定理不知所云了，看来又得是一个五年计划啦

数学是人类研究的重要工具，它可以让我们对的研究更加彻底。通过优化拓扑算法研究大脑的研究就相当于尝试给大脑的脑图控制“地图”。在“地图”的引导下，我们对研究才不那么乱无章，可能更加有针对性地研究，把抽象的东西直观化是研究中的一个非常重要且有效的手段。人的大脑与获得目前我们研究的对象中非常复杂，高级的一种，要把它研究清楚，必须把它具象化，让我们的研究有迹可循。普通人对高维度的理解可能还有些困难，但是，在数学工具和图形解释的帮助下，相信这些“高维度”的概念将会逐渐进入寻常百姓家。

让我想到“操控无人机”的，既有通过屏幕看到的第一人称视角，也有抬头看无人机的旁观者视角。

代替拓扑学视角的人脑图，应对不同事情时产生的神经元不同的几何构，来发现人脑意识的究竟，这也是知觉性好奇心的作用。

这篇文章让我发现数学的美妙，引用以前一期《创新学家》数学的起源说明：数学的作用时帮助克服经验和感觉带来的不精确，让我们不但可以用自身的感觉来理解世界和宇宙，还可以使用数学符号，对抽象的概念进行深入的探索，并且可以传达给其他人。

我不同意对于普通人来讲所谓智商体现的不真实感觉是人们对大脑的利用率不同，我们的大脑有许多的开发潜能，而能让那些看上去聪明的人也只是知道如何更大程度上使用大脑，因此我们还是应该多读书，多思考，让我们大脑上的神经元扩展和连接的更加密集
