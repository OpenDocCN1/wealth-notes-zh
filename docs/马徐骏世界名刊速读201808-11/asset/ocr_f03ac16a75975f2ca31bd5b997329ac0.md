# | 消失的战场

今天我们讲Aeon，万志网站的文章《消失的战场》，*The battlefield is dead.*。这篇文章的作者是安东尼·鲍尔斯（Antoine Bousquet），他是伦敦大学国际关系学院的高级讲师。2009年的他已经出版了一本书，叫做《科学战争的方法：现代战场上的秩序与混乱》。

最近西班牙的加泰罗尼亚闹独立的算几，搞得四万方世界有点不太平。不过回到来看，发生战争的“可能”性不大，在第二次世界大战之后，世界进入了一个相对和平的时代。但与此同时，我们也看到了，地区冲突的不断扩大，宗教主义的卷土重来。当然也包括恐怖主义对社会的巨大威胁。这似乎又让我们感觉，战争并不遥远。今天这篇文章讲的，为什么传统的战争形式，可能不会再出现了，未来、未知的战争会是什么样的。

# | 逐渐消失的传统战争

咱们先来给传统意义上的战争下个定义。传统战争，就是在特定的地理范围之内，也是两军对阵的一系列列方的地方，兵法策略的某种作战方式。其实这种作战方式如今已经不复存在了，这是为什么呢？

简单来说，是因为武器装备与技术的改进，使得传统意义上的战争没有继续存在的“可能”了。

古代战争基本就是靠肉搏，拼智力，如果用到盾牌、弓弩、攻城锤、火炮这种，就已经算是高级的武器了。武器的打击范围是很小的，比如早期的火炮，打击范围也只有75米左右，准头也实在不怎么好。只有军队要集中操作，行程也不好，打一场仗需要非常多的人，每个人负责的部分可能只有几厘米。从这样的打仗就意味着非常大的时间，从这个出兵到临阵城下，对方总是有足够的准备时间。

这样的传统模式其实保持了相当久的时间，虽然装备与武器科技一直在进步，但到真正能开战争开的是18世纪以后，空中战场这个新维度的加入，给了战场的一个全新的维度，也让打击的隐蔽性得到了空前的提升。

到了第二次世界大战的时候，每一个战士可以负责打击27000平方千米面的面积，而1911年河沟2000，这个数字涨了将近16倍，变成了424000平方千米。对这个打击能力，保护地方正面交战很重要，因为任何军队暴露在地方立刻会被消灭。传统意义上的作战方式，在这个时候已经不太常见了。老式的小型武装成为了十分普遍的攻击方式。打击目标也不再是以成团农业物为基地，甚至是以中火，比如1999年，北约对南斯拉夫联盟的战争，就没有派出地面部队，用飞机轰炸了78天，直接打垮了南斯拉夫联盟。

这个走向，经济与工业中心已成为了主要方向，主要和主要方，要打击敌需要摧毁的其实是双方的后勤、工业、交通甚至信念。

二战之后的冷战时期，美国、俄罗斯双方的核武器，也带给了战争全新的变数，一个小小的按钮就可以决定一个国家，甚至整个世界的生命，冷战期间，美国跟苏联都不开核升级自自己的核武器，但双方核庞备，他们都不想主动发射这个武器，而来替着好，我的核武器比，如果用武器来恐吓老大实，其实你方先动手，但结果是不能想的。

其实到了这个时代，有强大的核武器，再加上国际战争建立的秩序和规则，没有谁轻易想发动战争。这些都是看在当前的全球局势下，一旦出现真正划分边界的战场，很难避免那种明暗的冲突，因此就很可能很容易对那种明暗的开始，而限制在特定战场上的战争，传统意义上的战争，也就这么消失了。
