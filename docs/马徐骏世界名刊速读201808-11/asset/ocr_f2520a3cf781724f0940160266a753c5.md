# 面部识别可能带来的社会问题

尽管面部特征是属于个人的，但是同时，面部也是具有社会属性的。如果记录、存储和分析人脸的技术，变得越来越便宜，越来越透彻，收集的数据越来越大的话，那么总有一天，会带来隐私和公平性的问题，甚至带来人与人互动关系的改变。

举个例子，因为现在拍照采集图像太方便了，硅谷的一些科技公司，就会通过采集走进汽车销售展厅的顾客的照片，来识别出这些人的身份，然后给他们发送汽车广告。而像FBI的数据库里，有一张与美国未成年人的照片，这是执法部门一个强有力的武器，可以用来追踪孩子是不是心不在焉。父母用这个技术来识别孩子是不是心不在焉，或者老板用来识别员工是不是心怀不满，那么可以预见的是，家庭关系和工作关系，会变得更加真实，但是显然也更加不和谐。

再比如说，通过识别一个人的面部表情来判断情绪，可以帮助有“情绪识别困难”的自闭症患者，读懂其他人的表情，就能更好地融入社会。但是如果父母用这个技术来识别孩子是不是心不在焉，或者老板来识别员工是不是心怀不满，那么可以预见的是，家庭关系和工作关系，会变得更加真实，但是显然也更加不和谐。

此外，通过面部识别来歧视性地筛选雇员，了解你的政治倾向来拉选票，对应你的个人信息判断你的健康状况，都是可能实现的，所以，也会造成很大的社会问题。

所以欧洲监管部门出于对数据和隐私的保护，对人脸识别技术持谨慎态度，像美国那种走进一家卖车的店，被面部识别出身份，然后不停地发消息追着你，在欧洲是违法的。欧洲的法律也禁止雇主通过面部识别技术来筛选应不工作的人。

就像前面说的，因为人脸是兼具社会性和隐私性的东西，所以各种技术的研究和推广，需要比指纹更慎重。就像文章里说的，如果记录、存储和分析人脸的技术，变得越来越便宜，而且越来越透彻，收集的数据越来越大的话，那么总有一天，会带来严重的隐私和公平性的问题，甚至是人与人互动关系的改变。

对于我们普通人来说，不用对新技术抱着抵触的态度，但需要 keep a straight face，严肃认真地思考它的两面性，做好准备，防范可能出现的问题。
