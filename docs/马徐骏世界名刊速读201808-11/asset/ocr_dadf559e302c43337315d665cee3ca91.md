# ❏ 意想不到的成就

今天我们讲《万古》网站的一篇文章《意想不到的成就》（An unlikely triumph），这篇文章说的是美国的高等教育是怎么回事的。作者大卫·拉尼是斯坦福大学的教授，还曾经担任美国教育研究院的副院长，写这篇书是他在今年新出的新书《完美的混乱：美国高等教育意想不到的崛起》的摘要。

美国的高等教育是世界一流的，全世界排名前100的大学里，有52所来自于美国，排名前20的大学里，美国更是占了16所。21世纪，有一年的诺贝尔奖都颁给了美国的的研究机构。但如果时间回到150年，19世纪时是美国高等教育刚刚复苏时期，那是个笑话，欧洲人都嘲笑美国人，"就你们那些学校，也好意思叫大学？要人力没人，要钱没钱，总归在角落背弃的。"别说学术成果了，连生存下去都困难。

谁都不会想到一个世纪以后，从20世纪中开始，美国的高等教育一骑绝尘，成为了全世界所有国家都羡慕，资金相对富裕，培养世界其他国家精英的摇篮。它是怎么做到的呢？

# ❏ 为搞房地产建大学

文章里说，美国的高等教育一开始就跟欧洲的模式完全不同，欧洲的 Oxbridge model (就是指牛津的牛津、剑桥模式) 是非常典型的贵族学校，主要是由政府和教会出钱并且主导的，其实现在中国的高等教育也是这个模式。但美国一开始搞大学的目的，是为了增加土地的价值。

建国初期的美国地广人稀，土地资源比买土地的人多多了，怎么才能把自己手上的地卖个好价钱，怎么才能让投机者们speculators 们头脑里的问题，甚至连富坚万·沃什、华盛顿，都一直试图把手里的5万英亩土地卖个好价钱，但却始终都没成功。

到了19世纪，投机分子想出了个好主意，就是给土地增加文化价值。他们自己手里的一部位土地出钱来建大学，然后大学周围的土地不就升值了吗？其实直到后来房产开发商也在用这招。比如，建个高尔夫球场，然后坐等周围的土地和房价升值。后来，这种模式开始流行起来，当时的美约大学如同雨后春笋一样被建立起来，到了1880年的时候，光是美国俄亥俄一个州，就开了37所大学，当时整个法国一共才有16所大学。

大学建了，总得有人来，当时的美国没那么多人口，所以大量的学校都是教会学校，宗教办学当时的是确实有明星校办学的。总之，生财道，虽然来人是大学的人不多，但至少教会的信徒还忠实的。其次，师范问题总得解决掉，那时候的大学老师基本都当校数，受过良好教育，而为了信誉，要的工资也不高，教会还时不时给点拨款救一救一下，至少能让这个大学活下去。

虽然这些大学后来渐渐褪去了浓厚的宗教色彩，但是这样的起点，给美国的高等教育留下了非常独特的烙印，形成了一直追溯到今天的历史特色。

# ❏ 历史造就的特色

聊起美国的高等教育，肯定会说到很多有特色的地方，比如大学位置偏、学费高，私立学校比公立学校好、校友网络最强大、气候款般为强、求教学员发展自由等等，其实这些都和美国高等教育发展的历史有关系。
