# | 数学的起源

今天的内容来源于《新科学家》杂志的封面文章《数学的起源》，*The origin of mathematics*。这篇文章的作者是阿利·阿南塔斯瓦米，他原来是一名软件工程师，后来转行做了科普作家，同时也是《新科学家》杂志的顾问。

本期的杂志封面，非常鲜艳、好看，它描绘的是，在一片生机勃勃的原始丛林中，有一个探险的人。这个封面有两重含义：一个是猎人与自然的关系，人类在狩猎中生存；另一个暗示着这篇文章的主旨：数学是一片生机勃勃的原始森林，人类在这片森林中不断地探索和发现。

今天这篇文章探讨的是，数学究竟是什么？它到底是怎么来的？为什么会发展成为一门学科？虽然我们从小就爱学数学，但是这些问题还真没多少人知道，所以这篇文章主要是用来拓展我们的眼界和认知的。

# | 什么是数学？

对一般人来说，数学意味着数字和计算，但其实数学远比这些答案复杂得多，它是研究数量、结构、变化、空间以及信息等概念的一门学科。总的来说，数学可以分成三个部分，几何、分析和代数。

几何，geometry，是描述静态物体空间关系的。

分析，analysis，是用来处理物体随时间改变和移动的，像微积分就属于分析。
