# 今日关键词

Lean: 这个词是指“短少的，肌肉精壮的”，在管理学当中，被翻译成了“精益”。比如说管理的《精益创业》，就是 *The Lean Startup*。

# 通用向谁学习

今天内容来自《财富》，标题是《通用向谁学习》， *Teaching a Giant to Think Like A Startup*，作者是埃里克·莱斯（Eric Ries），莱斯是硅谷企业家，也是畅销书作家。

埃里克·莱斯在美国可是个红人，他最初走红是因为他投的那些创业公司，告诉你们大企业都用了哪些有效的策略和方法，他还因此写过一本书《精益创业》，讲的就是这些创新。在今年，他又出了一本书《像初创公司一样管理大企业》（The Startup way），反过来，教那些全球化的大公司像创业公司一样灵活、创新。

今天这篇文章讲的是通用电气向莱斯请教了，这是因为他谈的是如何优化。莱斯本身是一个外科，不懂通用那些技术，但在他的引导下，通用确实能取得了一些成就，比如一个本来计划五年能完成的项目，缩短到不到六个月，就初步地实现了。

咱们今天就讲的问题，是莱听到他是怎么做到的，他的方法是什么？我们怎么能在生活中去借鉴。

# 企业教练埃里克·莱斯

对莱普管理理念影响最深的，是由丰田的生产过程衍生出的管理哲学——精益管理。这个概念的核心意思是，任何不能给消费者带来价值的事情，就只能是资源的浪费。这话听着有点绕，说白了，一个企业自己没想得再仔细，也得用全量，前量再远一点，如果用户不买账，就是白烧钱。

丰田汽车坚持要贯彻这一理念。别的汽车厂商搞的是大批量、大生产，靠广告营销和廉价的小机组生产来赚钱，哪里需要，哪里就迅速调整，反正规模也不大，而成本还会更低，这反而帮助丰田迅速抢占了市场。

埃斯精益创业的核心思想是用最低的成本、最快的速度去做试验。他提倡企业进行“假设性设计”，先向市场推出最小化可行产品，再根据反馈进行调适，不断测试。最小化可行产品的英文是Minimum Viable Product，简称MVP。

埃里斯呢？就是你得先出一款产品，不用非得在尽量完美的时候才推出，先做一个基础款，具备核心功能就行，这个基础款就是咱们刚才说的最小可行产品MVP。

那这个思想，到底要怎么用？

# 通用向莱斯学了什么

莱斯在书中介绍了他给通用电气优化项目的经历。当时，通用电气的CEO杰夫·伊梅尔特（Jeffrey Immelt）和副总裁康尼·斯图（Beth Cornstock）读了莱斯的《精益创业》。对于精益创业的理念非常感兴趣，他们认为，通用电气这家有150多年的历史的老牌巨头公司，也需要尝试新方法，让通用能更好地适应时代，持续成长，长久地繁荣下去。

当时，他们计划做一款做X系列（Series X）的发动机，设想得特别好，这个系列的发动机可以适应不同的地形和环境，全方位的满足各种类型的客户，但是是一个10亿级别的项目，他们计划用五年的时间来完成。

这个X系列就是当时通用想用来测试莱斯方案的项目。他们的想法是这样的，如果莱斯的通用化思想真的适用于大、跨平台的项目中有的效的话，那他的方法就可以应用到通用电气旗下各个行业的主题中。

莱斯和书里详细记录了过程。通用的工程师和各层管理层在讨论项目的时候都普遍，你想啊，一个10亿级别的项目，主要是做了，各个行业可以融合在一起，可是做了一件大事，作为变革与在莱克的引下，提出了各种疑问，当时那些高层和工程师们一致表示，心想这是谁呀？接下来莱斯就一步一步地引导他们，将五年的工期变成了六个月。

在这个过程中，莱斯主要用了两招，第一招就是最小可行产品MVP，先做这个基础款。第二招是假设，分清楚哪些是你自己确定的信息，哪些是你自己的假设，这还得看怎样最小化可行产品来做。咱们来简单总结一下。

莱斯举了一个例子，比如他要把高管、工程师等各个相关人员都召集到一起，先讨论一下，这个系列到底要有多长时间才能完成？要多少时间？他们当时说完了这个五年计划，在这个过程中，他一直在提问。注意，这里问的是我的第一招，第一招不是，那这些消息都是确定的，哪些是假设的。他问，你们怎么能知道这个产品可行不行呢？要不要各种条件？你们怎么知道这些人的需求是这样呢？你们这么短的时间到底是因制作流程，还是因为通用电气内部的流程呢？

通用的团队就纷纷表示各种图表、数据、预测，就是希望未来会给创造数十亿收入的美梦未来。莱斯说这篇文章写道，说了这么多，还是没解决这个问题，那就是为什么有这么长时间才能做好这款发动机？

莱斯说，关键就在于这个项目，设想也太太细，想一次性解决所有问题。但你想到的这些想法，都是由传统的市场调取的方法收集到的，不是通过实验证的实验，就算你们对时候都是对自己过的度想象，就真不知道，他们未来会跟你想什么？那这个计划，大家都把这意图想在这么太的大图上，也就是这些东西到底能不能做出来？莱斯说，你们有没有想过另一个问题，它不应该被做出来？

实践出真知，这得用最小可行产品MVP来实验。经过讨论之后，工程师得出结论，可以把整个产品过程，从五年前到两年，莱斯想验证努力，他们五年都到问题，如果是做出第一个发动机需要多长时间呢？
