# 今日关键词

casting-couch  [kæstɪŋ kaʊtʃ] culture : 试椅椅文化。casting couch，演员在试镜的时候坐的椅子。为了得到自己想要的角色，有时候演员就不得不满足一下有权势的选角导演提出来的要求。后来这个casting couch culture 就引申为以性为交易获得角色的行为，这在美国影视界非常普遍。也有人把这个词翻译为“潜规则”。

tacit  [tæst] code : 潜规则。tacit，是“不言而喻、心照不宣”的意思，code 是“代码、规定”的意思，合起来就是“心照不宣的规则”，即tacit code，潜规则。

# 性骚扰

性骚扰，是指不受欢迎的，以性为目的的言语或身体接触。

# 好莱坞制片厂

好莱坞制片厂是指电影公司在好莱坞建立的制片厂，包括环球、派拉蒙、二十世纪福克斯、索尼、迪士尼等。
