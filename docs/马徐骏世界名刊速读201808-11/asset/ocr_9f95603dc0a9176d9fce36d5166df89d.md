# 知识清单：

# 1 今日关键词

winner takes all：winner 是“赢家，胜利者”的意思，Winner takes all 是今天这篇文章的标题，意思就是“赢家拿所有”，有点咱们中国人说的“胜者为王，赢家通吃”的意思。

carrot and stick：carrot 是“胡萝卜”的意思，stick 是“棍棒”的意思，结合起来就是“胡萝卜加大棒”，引申开来就是咱们中国人说的“软硬兼施，恩威并济”的意思。比如说一个软硬兼施的办法，英文就是 a carrot-and-stick way.

# 1 胜者为王

今天的内容来自《福布斯》的封面文章《胜者为王》，Winner takes all。作者兰达尔·柯恩，他代表《福布斯》杂志对特朗普进行了独家专访。

这篇文章特别有意思，封面大大的引号写的就是“特朗普的脑子到底长了什么样的？然后下面有一句话这样解读的：对于这个世界第45位总统来说，没有伙伴，没有炎器，没有敌派，最顶的优先现，就是得视特朗普会一直走下去。

文章里没有对特朗普各种政治跑题的解读。在这篇专访中，作者说，要理解特朗普，你得明白特朗普是一个什么性格人。他对自己的世界有着怎样的看法。明白了这些，就能看明白特朗普种种行为背后的原因了，比如说，为什么他特别能在推特的言论那么极端，为什么他动不动就宣布退各个协定，为什么甚至可以同特朗普学一些他的有效的谈判技巧。

这次专访《福布斯》从三个方面对特朗普进行了提问，分别为：

+   - 特朗普的处世哲学
- 特朗普的治国之道
- 特朗普的谈判手段

# 1 特朗普的处世哲学

在这一部分中，《福布斯》主要是针对特朗普的身份特质以及他的处世哲学、行事风格提问。比如：“特朗普，你觉得你的商业背景对你的担任总统有用吗？”或者“特朗普，简单，无论是过去，还是现在，你准备好总统了么？”

看完了这部分特朗普的回答和文章的解析，这来更对特朗普做出的种种“让外界难以理解”的行为，就能能理解了。

特朗普在这一环节的回答一直在强调他曾经的商人和性质，他是一个交易家，也不是一个生意人，他是一个交易家，明白他身份特质非非常重，因为这种交易思维贯穿了他做生意和理解国家的方式中。
