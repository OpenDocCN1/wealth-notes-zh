# 今日关键词

Negotiate: 意为协商、谈判。和某人谈判就是negotiate with sb.。“我们是试图和他们谈判，但他们拒绝了”，英文就是We tried to negotiate with them, but they refused.

# 如何和老板谈加薪

今天讲《金钱》杂志的一篇文章，标题是《如何和老板谈加薪》，Negotiate a Raise，作者是克里斯汀·巴氏（Kristen Baehler），他是一名金融和商业记者。

有一个宇宙都通用的规则，就是涨薪水这种事情，如果自己不去谈，老板很少会主动给你涨。一般来说，涨薪水这种事情肯定是要一对一谈话的，这给人心理造成的压力可不小，根据美国职业机构调查，大家都觉得，和老板谈涨薪水，比工作还要让人焦虑、紧张，咱们今天就来讲一讲如何体面、高雅地和老板谈加薪？

# 和老板谈加薪前要做什么准备

+   1.我到底值多少钱？

找老板谈加薪时，最傻的做法就是什么都不想，冲到老板的办公室跟老板说：“老板，我想涨薪水。”

不打无准备之仗。在找老板谈之前，最重要的就是要知道自己到底值多少钱，千万不要信口开河。比较好的方法是，参照同行业中，和你职位相同或类似的工作岗位的薪酬标准。公司在招聘网站上发布招聘职位时，都会写薪酬范围，这就是重要参考依据。除此之外，还可以留心一下公司一般的工资涨幅是多少，心里有数，不会开出一个让老板听起来很不靠谱的数字。

+   2.帮老板找定给你涨薪水的理由

找足老板给你加薪的理由。要注意，这就是一场谈判，你要说服老板，让他觉得你配得上一份更好的薪水。你要强调的是，你在这份工作上的优异表现以及付出。

不建议强调私人原因，比如房租涨了、想出国旅行没钱等。涨工资是公事，要用公事的理由才对。

这一步的准备工作可以这样做：首先列下工作的成绩清单，注意按照时间倒序列，从最近完成的工作往前推。描述工作业绩时，要具体化。假如你负责销售，不要说你增加了公司的利润，要告诉老板，你为公司多挣了多少钱。假如你参与了一个项目，就要讲你从担你的角色，怎样推动项目的进展，越详细越好。

还可以列一个技能清单，你在工作当中具备哪些技能，包括硬实力和软实力。

+   3.提前演练

提前演练相当重要，首先大开脑洞去想，老板可能会问什么问题，尽可能多地列下来，列出来之后，再针对这些问题去想，怎么回应才是最好的。然后和家人或朋友进行角色扮演，对方扮演一个固执老板，不肯涨薪水，你就努力说服他。练得差不多了，你才算是做好了上场和老板谈加薪的准备。
