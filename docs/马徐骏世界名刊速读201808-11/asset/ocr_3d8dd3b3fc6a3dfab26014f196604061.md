# 特朗普访华

美国总统特朗普宣布将于2017年11月7日至10日对中国进行访问，这是他就任总统后首次访华。此访是应中国国家主席习近平的邀请，以进行国事访问。

+   - 会访问哪些城市？
- 会举行哪些活动？

北京、杭州、上海。两国元首将举行会晤、会餐等活动。特朗普还将参观中国丝绸博物馆。

此次访问的主要目的，就是经贸合作。中美高层经贸磋商机制正在建立中，这是两国关系中的重要一项。

据分析人士指出，特朗普访华期间，将重点讨论包括中美贸易平衡、双边投资、知识产权保护、农产品贸易等经贸议题。

特朗普随行代表团成员包括美国商务部长威尔伯·罗斯、外交顾问柯比·伯内特等。其中，商界代表还包括了美国科技巨头公司的CEO，如苹果公司CEO库克、FacebookCEO扎克伯格等。

分析指出，美国代表团此次访华并非一个空壳子，而是包括了众多业界巨头的实权派，他们代表着美国科技和工业界。

中国方面，此次访华期间，除了北京、上海外，还将访问杭州，展示中国互联网科技产业。

# 访华背景

+   1.  特朗普政府推行“美国优先”政策
2.  中美贸易逆差问题

自特朗普上任以来，一直强调美国优先政策，认为中国从美中贸易中获利巨大。
