# 知识清单：

今日关键词
labor：我们比较熟悉的意思是“劳动、劳工”，比如这张廉价劳动是cheap labor, labor这个词还可以用来指“生产”。比如生孩子就可以说go into labor，和give birth是一个意思。“生产过程”就是during labor。

女神神话
今天的内容来自于《时代周刊》的封面文章《女神的神话》，The Goddess Myth，作者克莱尔·霍沃茨是《时代周刊》编辑部主任，作品曾发表在很多美国大刊上。

以《时代周刊》的封面文章，都是跟一些国家大事相关的，像特朗普的政策、美国的未来、或者全球气候变化。今天这篇文章与其说话题性，就温情多了，就讲当妈养孩子的事儿。咱们平时看美剧，总感觉老外不是生孩子就是养孩子多容易的事，这简直是让我们中国妈妈们一想就难电视相当混乱？这篇文章就讲就是在科技、社会大环境，以及主流思想观点这些因素影响下，美国母乳喂养现状。当然，中国和美国国情不同，但妈妈遇到的问题，差别却不大。

有妈妈的女神神话
女神神话的英文是The Goddess Myth，作者说美国妈妈们在对女人、女性有神话这样设定的：“要顺产、要母乳”，这也就表达了美国的主流生育观，你有觉得耳闻吗？我先给大家说一下上面提到的女神神话的解释：“母乳喂养才是最好的，在顺产，还是顺产手生产问题上，当妈的就应该选择顺产。而且，对一 妈妈来说，生产应该是一件非常神圣的事情，就应该费力地去医院做剖腹产。如果是顺产孩子，那就是不负责任了。还有，生孩子这件事太重要、太伟大了，所以妈妈应该各种神化、目光放远。
