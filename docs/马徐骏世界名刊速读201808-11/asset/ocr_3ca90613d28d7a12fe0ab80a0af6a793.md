# **时间是一种健康资源**

今天咱们来讲《大西洋月刊》网站的一篇文，题目叫《花钱买时间可以让你更快乐，Uber, but for Happiness》。作者奥尔加·卡赞（Olga Khazan）是一名专职作者。

他在文章中提到，澳大利亚国立大学流行病和人口健康中心的林德利·斯特拉兹丁斯教授（Lindell Strazdins）在2011年就曾经率领其他7位作者共同发表了一篇论文，标题叫做《时间稀缺》。论文提出，时间是一种健康资源，与人的健康有着非常大的影响。研究已证明，人们因为没时间，所以会产生各种健康问题，如焦虑、肥胖、失眠等。

# **有孩子的白领不够快乐**

研究发现，有孩子的白领父母，他们的快乐程度低于那些没有孩子的同龄人。孩子并不是让父母不开心的因素，令人身心俱疲的是那些繁琐的照顾孩子的工作。单就该给准备食物来说，每天准备各种营养食品可能要耗费一个妈妈好几个小时的时间，其间还要做家务，应对孩子各种突发状况。但如果，给妈妈雇一个厨师，解决孩子所有的餐食问题，那么可以大大减轻这个妈妈承受的压力，她的心情和状态就会因此好很多。

但却很少有妈妈会这么做，而且不只是白领家庭，这是一个普遍现象。

研究者采访了98个已经工作的成年人，问他们，如果给他们每人40美金，他们会怎么做？其中只有2%的人会去购买节省时间的服务。

# **人们为什么不愿意花钱买时间？**

主要原因是，花钱买时间带来的快乐感受没有那么大冲击力。

花钱当然可以买快乐，花钱方式正确的话，就会更快乐。专栏在4月26日讲过一期《怎样买更买快乐》，也像在来《大西洋月刊》的文章，讲的就是花钱体验比买东西带来的愉悦感更持久。不同性格的人，能让自己开心的花钱方式也各不同。

但买体验带来的快乐和买时间带来的快乐还不一样，买体验带来的快乐在你眼前特别实，比如看电影，环境音效、大场景，这个爽是立竿见影的。去旅行，沿途的美景、经历，也是让你久难忘。买体验带来的快乐一种特别强烈的快感冲击。而买时间带来的快乐，对对比如说要干平得多，它更多是减轻你的压力，让你更从容。

# **花钱买时间可以让你快乐**

《美国科学院院刊》（PNAS）最近发表了一个研究，研究者找了四个国家的受访人员，分别来自美国、丹麦、加拿大和荷兰。研究者问他们每个月大概花多少钱在自己做事上，省时服务指的就是把原本自己做的工花钱雇别人来做。比如使用超市的送货服务，找家政阿姨收拾屋子，衣服送去干洗等。然后又问了这些人的生活满意度。

研究者发现，花钱购买省时服务的人群生活满意度更高。
