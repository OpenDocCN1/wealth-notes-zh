# 本期杂志：《时代周刊》《经济 学人》《纽约客》《新闻周刊》

《时代周刊》：美国三大时事性周刊之一， 它因“为高端忙碌人士提供高深而深入的世界新闻报道”而著名。

《经济学人》：一份由伦敦经济学者本报讯 有限公司出版的杂志，所有文章都不署名，往 往带有鲜明的立场，处处用事实说话。

《纽约客》：美国知识、文艺类综合杂志。 对美国和国际政治、社会重大事件的深度报 道，是《纽约客》的特色之一。

《新闻周刊》：美国三大新闻杂志之一，与 《时代周刊》《美国新闻与世界报道》并称 为美国三大新闻周刊，尤其以时政新闻见 长。
