# 如何在职场建立信任感

今天的内容来自《哈佛商业评论》的《如何在职场建立信任》(How To Gain Credibility When You Have Little Experience), 作者有两位，杰迪·莫琳斯基和杰基·范·切尔克斯。莫林斯基是康涅狄格州康涅狄格学院的教授，范·切尔克斯是美国一家大软件公司工作，主要帮助大型企业分析大数据。

这篇文章特别形象，它讲的是如何在职场建立靠谱的形象，让同事和老板都信任你，有事情愿意交给你做，机会也会优先给你，以及怎么和同事处好关系。作者的观点是：没必要等待时间和积累，缺乏相关技能可以学习。建立职场靠谱形象这件事儿，当下立即就可以做。

# 如何塑造靠谱的职场形象

塑造职场靠谱形象(reliability)有三个要点：工作有态度、做事有章法，再建立小策略。

不管是很年轻有经验的，还是新手，你都是刚入职，尤其当自己还是一个老的环境，可能你只是多主动做点事儿，都能给他人留下不错的印象。如公司请的负责人，谁有空帮老板团队同事准备一些材料，你就可以主动站出来，当然，前提是你有能力完成这一工作。

作者在文中强调，你得利用好这个机会，快速地证明自己，你得利用好这些机会，快速地给别人留下一个你靠谱、有才干的印象。

做事有章法指的是有效管理工作，主动沟通，想要建立职场靠谱形象，这一条是必须。你得知道自己的边界，你能做什么，不能做什么。能做什么你很清楚。当地say不 不会为你加分，你得知道，当自己的工作大到无法完成时，就要say no。

更重要的事，要主动沟通工作进展。比如在完成不了的任务前，一旦遇到了自己解决不了的问题，不能干等着，等到deadline，别人找才说。中间出现问题，对项目没有影响，都要尽快向上级相关事项沟通，需要的活，可以寻求指导，别怕遇到问题。

最后，做任何工作都要有始有终，也就是闭环的事有事情有结果。任何工作都清楚开始、顺利落地落地的事，不留尾巴，这样干净利落、有始有终、及时沟通的行事风格，会很大程度地塑造你的职场形象。文章有一句话说得特别好，可能不是办公司那些有经验的，你也可以成为最靠谱的那个人。
