# 敬畏感：awe

周一文章来自《新科学家》，标题叫做《敬畏感的大用处》，*Awesome awe*。

这篇文章说敬畏感带来的好处是，会让人心态上更谦迪，心态上更积极，还能激发创造力，对孩子的教育也有好处。

我们说了两个词awe和goose bumps。awe是“敬畏感”的意思，敬畏感也可以用上周咱们讲过的sense of的结构，sense of awe。而awesome是一个非常口语化的表达，相当于“非非常的好”，比如你看了一部激动人心的电影，就可以跟别人说，It's a awesome movie。我在英国读书时有个英国同学，很喜欢用一个词wicked，这个词在里是“邪恶的、坏人女巫”的意思，但在口语里可以表示“好得邪门”的意思，This novel is really really wicked！意思不是说“本小说很邪恶”，而是说“这本小说好得不得了”！这两个表达都建议加入你的口语词仓库里，出来非非常地道，仅一个词就能让人对你刮目相看。

# 谈加薪：Negotiate a Raise

周二文章来自于《金钱》杂志，文章标题是《如何和老板谈加薪》，*Negotiate a Raise*.

跟老板谈加薪首先要主动，其次要有备而来，提前准备，最后要体现场妆，体现自己的专业性。词汇很简单，negotiate 和raise。

negotiate，是“协商，谈判”的意思，谈判专家，英文就叫negotiator，这个词和argue相比，更加正式，argue有种讨价还价的感觉，negotiate更官方、更体面，还带着一点仪式感。除了加薪之外，升职应该怎么说明呢？很简单，promotion。要求晋升就叫ask for a pay raise，要求升就是要ask for a promotion。被升了，叫get promoted.

留言里有读者问我，想要学商务英语，怎么提高？我建议你可以参加一个考试叫BEC，剑桥商务英语，这是世界公认的考试，里面有很多商务英语，包括教你怎么谈判，有BEC中级或者以上的证，足够向外企证明你的英语水平，而且从专业分类上来说，比读口译更加对口。

# 网络巨魔：internet troll

周三讲的是《鹦鹉螺》杂志的文章《如何对抗冒犯性的言论》，*How to Defuse Offensive Speech*.

学会对抗网络暴力是冒犯性的语言，是现代人的必修课。锻炼心态最好的方法，就是直接经历，再多的间接经验都不如亲身体验一次好。

咱们说了iGen和internet troll。iGen是一个组合词，internet generation，互联网一代的缩写。iGen指的是1994之后出生的人，这代人在精神和抗压能力上比之前的新代要差一些，可能是因为他们面对了更多的语言暴力环境。而网络巨魔，internet troll，指的是在网上发动攻击性言论，打击破砖瓦，甚至骂骂威胁他人的人，像咱们中国水军、刷屏党之类的，这正是网上特别不受欢迎的那类人。troll这个词的本意就是巨魔，里面是《魔戒》那个巨魔原就是的人，如果你想要骂人，也可以直接用。（哈利波特）小说里测试，最低分就是troll。

对抗网络暴力，无视，是一种好方法，而更高级的方式是自嘲或者自我，英文叫self-mockery，和self-deprecating.

说起暴力，英文叫violence，网络暴力就是cyber-violence，家庭暴力，叫domestic violence.
