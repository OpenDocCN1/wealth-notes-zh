# 精选：lean

周一我们讲了《财富》杂志的《通用向谁学习》。Teaching A Giant To Think Like A Startup.

这篇文章里，我们讲了《精益创业》这本书的作者埃里克·莱斯， 怎么用初创公司的思维，帮助大企业更好地进行管理改进的故事。莱斯的秘诀主要就是两个：MVP，最小化可行产品以及验证，并分出确定的信息来。

在莱斯的帮助下，通用电气把一个原本需要五年的项目，缩短到了六个月。我们常讲外行不是管理能力内行，但外行可以帮助内行找到！当不是一件事已经熟练之后，是很容易发生思维定式和盲区的，而且明显不合理的地方，在外行人的眼里就更容易被挑出来。

这篇文章里我们学到了lean这个词，这是个好词，意思非常丰富，首先我们说的瘦的，就可以叫做lean，所以这个词也叫有“精简”的意思。《精益创业》就叫The Lean Startup，在我们的留言里，一位叫Robert Parker 的用户说，facebook的COO雪莉·桑德伯格的畅销书《向前一步》，英文也总结到，Lean in. 没错，因为lean还有“倾斜”、“ 依靠”的意思，所以lean在本意就是“往别靠”的意思，翻译成“向前一步”是非常贴切而且漂亮的。

在留言里，还有用户对这篇文章的全句 Every one has levers that make them run. All it takes to pull them is courage man a word (lever 咱们) 问题，说不是应该念成“[li:va]”吗？ 为什么说是“[livə]” ，这里回答一下，[livə]是美音的念法，我发音习惯是在用英音，所以这个词就是发现成“[livə]”的。我们专9月17号的内容，《硅谷利华的商业挑战》，我们讲过硅谷利华的企业Unilever 的念法，英语也是“[li:va]。 英美念法也不同，自己念得舒服，别人听得顺耳朵就可以，比如说有些人把蕃茄tomato 念成[tə'mɑ:təu] ，但是美国人会念成[tə'mɑ:tə] ，这没什么对错之分。

# 时机：timing

周二正好是马丁·路德引发宗教改革整500年的纪念日，在西方世界也是件大事，咱们讲了《纽约时报》的文章，《马丁·路德的锤子》， The Hammer.

马丁·路德在西方世界是一位影响力极大的人物， 经会 的教父路德·彼得·威尔宁的1517基金会，就是源自1517马丁·路德发表“九十五条论文”，引发宗教改革，彼得·威尔宁1517基金会则是美国的高等教育机构。不过马丁·路德是一个有反叛精神，但是并不是激烈的，他主要是自己著作和演讲，最终结果他冲破了宗教改革，改变了整个欧洲。这里也是timing（时机）这个重要因素。教会的倒行逆施，社会各式阶层的愤怒，以及印刷术使得信息能够大规模地传递，让新思想传播，天地利人和，缺一不可。

不过文章里还说了一个点你可能没注意到，马丁·路德对于犹太教和犹太人的批判，给后来德国纳粹的种族大屠杀定了基调。这是因为，一开始马丁·路德试图拉拢劝说犹太人皈依天主教，但是遭到拒绝，之后路德对犹太人就非善可恶，说过很多激烈的话，类似什么应该烧毁犹太人的家园、拔掉种着他们教堂的树之类。这些后来都被希特勒和德国纳粹所利用，作为迫害犹太人的依据，在二战的时候间接造成了600万犹太人的死亡。
