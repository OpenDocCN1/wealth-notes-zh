# ## 数学对生物的作用

简单来说，数学是为了人类自身的生存而发展出来的境界。

自然是复杂而充满未知的。我们居住的环境会变，捕食者会发起袭击，食物也会消耗殆尽，所以，一个生命体的生存，依赖于它对周围环境的理解。比如，知道什么时候夜幕将降临，遇到危险时怎么找到最快的路径逃命，或者哪里是最可能找到食物的地方。

而你要知道这些，就必须得用到数学。

其实我们无时无刻不在使用数学进行计算，虽然有时候或是无意识的。比如你要抓住一个飞来的球，或者是在拥挤的交通里穿行时时候。我们的大脑时刻都在着非常复杂的数学计算。我们大多计算都能自己可能遇到什么，再通过跟现实的碰撞来不停地修正，重新预测。而且你会发现，这种计算方式，目前机器还不能完全做到，比如无人驾驶就不能完全代替人类的驾驶员。

伦敦大学的计算神经科学家和物理学家卡尔·弗里德曼·数学具备简洁、直接和完整的特性，所以如果你把它看作一种语言的它，它的任何语言都更适合用来描述这个世界。从海豚到菌类生物，在进化的过程中，都在用数学的方式理解这个世界，解读它的逻辑和规则，以便自己能生存下来。

问题是，既然数学是所有生物为了生存都具备的一种能力，那为什么人类会把它发展成一门学科呢？

# ### 数学对于人类的特殊意义

文章里说，虽然数学的运算模式，可以帮助我们在物理世界里活下去，但这并不意味着，发生在我们脑海的计算一直是对的。

举个“赌徒谬误”的例子，比如你在玩俄罗斯轮盘赌，小球第一次停在了红色区域，你会觉得，下一次小球出现在黑色区域的可能性会更大。但是从数学概率上来说，其实每一次的概率都是50%，那你为什么会觉得，小球再次出现在红色区域的概率不如出现在黑色区域的大呢？

这是因为在我们的祖先的生活经验里，在一个地方生活过一段时间后，把那里的食物收集得差不多之后，就必须换地方了，不然没东西可以吃了，所以从生存经验上来说，出现过一次的事件，不太可能出现第二次，这种认知模式被保留下来，就出现了“赌徒谬误”。

再举个例子，让你感觉一个1公斤的砝码和一个2公斤的砝码，哪个重？你肯定立刻就感觉出来是2公斤的更重。但是如果你感觉一个21公斤的砝码和一个22公斤的砝码哪个更重。同样是差一公斤，这次你可能不太能感觉出来了。

这叫做韦伯·费希纳定律。对人类来说，只有外界经验和感受带来的不精确，让我们不但可以超越自身的感受来理解世界和宇宙，还可以使用数字符号，对抽象的概念进行深入探索，并且可以传达给其他人。没有数学的帮助，科学是没有办法发展的。就连以前认为跟数学没啥关系的生物学，现在也不能忽视数学的重要作用了。因为无论是基因组的测序运算，还是神经科学的计算都跟数学有关。

```
$\Delta I/\Delta I = k$（其中，$\Delta I$为刺激量，$\Delta I$为刺激阈值，$k$为常数，又被称为韦伯分数）
```

这两个例子让我们理解，数学的作用是帮助我们克服经验和感受带来的不精确，让我们不但可以超越自身的感受来理解世界和宇宙，还可以使用数字符号，对抽象的概念进行深入探索，并且可以传达给其他人。没有数学的帮助，科学是没有办法发展的。
