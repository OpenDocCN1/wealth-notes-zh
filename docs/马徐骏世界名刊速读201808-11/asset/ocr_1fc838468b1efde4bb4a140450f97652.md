# Ⅰ 成为一个无所不知的人

今天的内容来自于《纽约客》的《成为一个无所不知的人》，Know It All。这篇文章的作者是本尼特格登，作者，是一位美国的记者和作家，也是《纽约客》的撰稿人。

今天这篇文章来自于《纽约客》的一个板块，A Critic At Large（评论家），这个板块大家应该对于书籍、思想和言论的评价，这也是《纽约客》上我个人最喜欢的专栏版块，因为《纽约客》杂志涉及领域很杂，A Critic At Large 这个板块的含金量是最高的，咱们专栏中《纽约客》的文章大都来自于这个板块。

这次的专栏内容，是作者凯瑟琳·舒尔茨演讲牛津出版社的一套百科全书，叫《通识读本》的 Very Short Introduction series，它写了知识非常受限受众的书，还带我们回顾了人类百科全书的发展史，最重要，也是最有趣的地方在于它，我们常说“知识就是力量”，但是知识到底是什么力量？舒尔茨帮我们回答了这个问题。

# Ⅰ 畅销的百科全书史

一般咱们提起百科全书，脑子里立刻会浮现出厚重、编码清晰的书籍，百科全书也是一类最不像特别好的，但百科全书似乎是对于所有问题的终极解释。其实人类一直想通过了解所有事物尽在掌握，并做出最终解释，这种努力本质上就是百科全书的发展史。

然而，百科全书始终有个特别尴尬的问题，首先，知识的迭代让人没法对万物做出最终解释，其次，知识体系太复杂会导致让人困惑阅读。

先说第一点，比如，世界上最早的百科全书，公元前，罗马时代的普林尼尼写的《自然史》，但是普林尼尼当时认为世界的认知太有限了。当时罗马流行用铅粉熬膏当做药粉、颜料“萨帕”，雅典尼尼勒对此大加赞赏，但实际上，这种东西中含有铅粉，吃多了会造成中毒的。后来罗马帝国灭亡，跟“萨帕”有多，作者普林尼勒是不知道，而普林尼尼最后去世，是因为公元79年，维苏威火山爆发，普林尼尼在逃离过程中，结果火山爆发，最后因为空气太稀薄而死。《自然史》的作者其实对于自然界的事物了解非常有限。

再来从宗教角度，编辑百科全书的两种动力来自于宗教崇拜世俗统治者的需要，比如西方教会势力特别大的时候，搜集知识、编辑全类的书，是有士大夫们这是做不出上的一级，上面伟大的人，咱们熟悉的按照等级，比如说等分法，百科全书是基于宗教的等级划分，先是天使，再是小天使，然后是凡人。

而世俗的统治者，为了彰显自己国力强大，也会编写百科全书，咱们中国有盛世修典的传统，比如清朝的四库全书，现代的永乐大典，永乐大典可算是数字时代到来之前，人类最全的百科全书。

这两种动力都不足自身本身，而且这两者也都不是，就算有认知者，大家都知道，你看，现在咱们的电脑和手机，也可以放下上一套百科全书，但也没谁铺天盖地查看。舒尔茨在文章里写了个比方很形象，百科全书就像是顶楼的单层照明开关，大家都说好，但普通人拍照都是从电梯和手机来照。

# Ⅰ 畅销全球的白小百科全书

一套奇葩的百科全书，改变了这个前提。

1995年的时候，牛津出版社了《通识读本》系列的百科全书，这套书每年会出差不多50个新书，现在已经达到了1250个主题的新版，卖得非常好，这套书翻译成49种语言，迄今为止已经卖出了800万册。但套这一套特版的百科全书，完全不符合咱们一般人对百科全书的印象，它有三点特点：简洁、碎片化、不装腔作势，很符合这个时代的特点。

先来说说这套《通识读本》，装帧非常简单，它不是精装本，而是平装书，规格非常统一，每本书讲一个主题，无论主题大小，都是120页，3万5个字单位左右。比如“沙漠”这个小主题，写了一个一本，而罗马帝国历史，像爱德华·吉本的《罗马帝国衰亡史》，是七十多字罗马人的故事，要是满满当当写一百五十页。在《通识读本》里，跟“穷苦”这个主题一样，就一本，120页。

![](bbox=[0.15, 0.00158, 0.85, 0.00165])

《通识读本》的规划也非常奇葩，特别碎，我们一般看来，百科全书的书节学一个大主题下部分分类，年代、作者，但这《通识读本》不是，哲学出了一本，还有印度哲学，欧洲学，古代物理学，苏格拉底，黑格尔，罗曼这些哲学家常单独出一本书，甚至不少内容还有交叉和重复。

更有意思的是，《通识读本》不写自己收录的主题做终极解释，它去写得有趣，比如“沙漠”这个主题，咱们会觉得，这是一句话就能说得清的事儿嘛，甚至写一本书，沙漠本沙漠历史、沙漠的动植物，谈到沙漠的面积约地球表面的25%，但后告诉你，沙漠雨其实算不上准确定义，不说沙漠少沙，沙多就都是沙漠，实际情况复杂得多。

最后作者给出了一个非常有意义的定义，如果说你给一个满杯的放在里面，这个地区如果是沙漠，那么，海洋里也有干旱的沙漠，甚至海洋里的小城就是沙漠。

按照这篇文章作者凯瑟琳·舒尔茨的说法，《通识读本》就是对所有的知识做一个切片，切割每颗算子，而且《通识读本》实际就是主题，虽然你看可能也想不通，居然是“全球化”和“文学理论”。

你可能会这一个问题，像“全球化”“文学理论”这种知识，找谁道了有啥用？要，牙齿、沙漠、哲学，音乐……知道了又干啥用呢？
