# ## 科技时代，我们信什么？

今天的内容是《新科学家》的封面文章《科技时代，我们信什么？》， In *What? How Do We Trust?*。作者诺拉 海瑟(Nora Hauser)是《新科学家》杂志的一名副主编。

这篇文章讲的主要是信任在科技时代的变化。它以互联网为框架来分阶段，之前信任主要来自于面对面的人际关系，以及你发心或官方机构的信息。在互联网时代，信任变得非常复杂，信任的范围在不断扩大，信任的对象在改变，信任的机制在变化，信任的成本在降低。

# ## 我们为什么会信任别人？

信任是进化出来的，它是为了生存。我们的身体和大脑为了信任做出了很多适应。

在人类历史上，信任一直是稀缺资源。在大多数情况下，信任是被给予的，而不是被要求的。

保罗·拉马克（Paul Zak）是一位神经科学家，他在研究信任时，发现了一种叫做血管加压素的激素，它能促进信任。当人们感到被信任时，这种激素的水平会上升。

他还做了一个实验，证明人们愿意相信别人是因为他们想维持好的关系，而不是因为害怕不信任的后果。

人们之所以产生信任，是因为，信任会让我们脑内产生催产素，从而让我们感觉良好。

随着科技和社会的发展，我们信任的对象也在变化。在过去，人们很轻易就相信各种权威机构所给的信息。因为互联网即时传播信息的透明度和速度大幅提高，任何信息都可以与几乎任何人分享。

# ## 科技时代的新型信任

科技时代，信任的标准和信任对象与以往不同。人们不再只依靠直觉判断别人是否可信，人们信赖的结构变成了各类电子平台。

依赖于陌生人之间的信任的公司正在蓬勃发展，他们的主要手段是建立一套信任系统，比如Airbnb、支付宝和Uber等。他们通过建立信任机制来减少交易风险。

以Airbnb为例，它把房东和房东进行信誉评估，包括房东的信用分。在信用分高的情况下，你更可能找到安全的住处。

对于平台，信用评估是核心。通过评论、评分和等级制度，平台可以建立一种信任机制，让用户对陌生人或产品有信心。

在这个变化中，信任不再只是人与人之间的事情，也变成了平台与用户之间的事情。
