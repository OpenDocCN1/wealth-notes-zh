# 如何拥有拒绝的能力

福格说，学会说不，其实是一种自信的表现。

+   1.不要夸大别人被自己拒绝后的反应

首先你要明白，很多人夸大了别人在被自己拒绝后受到的影响。哥伦比亚大学的管理学教授丹尼尔·阿莫斯说，大部分寻求帮助的人，其实并没有期待得到一个肯定的答复，所以他们不会因为拒绝而产生太激烈的反应。

+   2.划定界限

休斯大学的市场营销学教授，温妮莎·帕特里克，给出了一个比较好的拒绝办法：划定界限。

说起来是一个简单的话术调整，比如有人请你吃一块巧克力蛋糕，你不想拒绝，就要说，“我不吃”巧克力蛋糕，而不是说“我不能吃”。如果你说的是“我不能吃”的话，你传达的意思就是，“有外界的东西影响着我，制约着我的行为”，那你等于是求着看别人，你为什么不让我吃吗？如果你说的是“我不吃”，那对方可能认为这就是你的习惯或者原则，这件事都是不容置疑的。就说白了，就是不要给对方留下追问或者是劝导你的口子。

再比如说，有人问你借钱的时候，你就可以跟他说，“不好意思，我不借钱给任何人，这是我的原则”，那意思就是不只是你，没有例外。

这就叫做界限。告诉别人这是你的原则，而不是任何外力劝阻，或者其他因素的错误可以改变的。

+   3.理由不能有突破口

不是什么事情都能联系原则问题，那么在拒绝的时候，要注意给出的理由不能让对方有突破的口子。比如说，朋友求你，他不在家的时候请你帮他照看一下屋子，如果你不想帮这个忙，不要说，“哎呀，我对你们家的猫过敏，所以不方便”。那你肯定就会说，“那我把猫送到别人那里去，你帮我看一下房子吧”。这样你就没办法拒绝了吧？

你可以这样说，“不好意思啊，我很想帮你的忙，但是最近有一个工作确实非常紧张，我一定要在办公室里跟同事一起完成，所以实在抽不出空来”。这个理由就无法不接受。

另外作者说，千万不要用模棱两可的回答拒绝别人，因为这样只会使他们的期望更高，最后把场面搞得非常尴尬。如果你要说“不”，那就要坚决地说“不”。

+   4.模拟拒绝练习方法

作者介绍了一个你可以自己操纵的拒绝方法——模拟练习。你越是在脑海里反复地练习，说出no这个词，等到你真的要开口说的时候，就容易多了。虽然我们不想跟别人撕脸，但是如果无止境地满足他人的要求，其实只会让我们产生对他们的憎恨。

总结一下，我们之所以很难拒绝别人，因为跟他人保持一种生存本能，而我们可以透过划定界限、调整话术以及模仿练习的方式来训练自己说“不”的能力。就像作者说的，学会说不，其实是一种自信的表现。在我们渴望取悦他人的欲望、与他人满足自己的需求发生冲突的时候，拒绝是我们最有利的武器。
