# —— 下周预告 ——

从明天开始，我们正式进入精准医疗领域，我会为你带来最前沿的报告。

我们说精准医疗是大势所趋的发展方向，简单理解起来，其实就是依靠单个个体的全方位数据，给出相应的个性化的治疗方案。

我们常常会有疑惑：为啥两名患者得了同一种病，医生都给开了一样的药，但一个人吃了药很快就好了，而另一个却没啥好？

其实就是因为个体间存在差异，而这些差异多种多样，与基因、身体情况、消化能力等等都有关联。

而精准医疗，就是针对每个人的具体情况对症下药。

但不得不说，人类对于生命的探索还有很长的路要走。
