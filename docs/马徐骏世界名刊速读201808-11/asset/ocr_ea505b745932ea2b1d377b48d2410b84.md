# | 今日关键词

Amazon：很多人知道亚马逊，但英文名总是会念错，应该念/ə'mæzon/。我们都知道亚马逊是一条河，其实，在古希腊，有一个战斗力很强的女性部落也叫亚马逊。在古英语中，mazo 就是乳房的意味，a表示没有，连起来就是“没有乳房”的意思，因为这些女战士很强悍，周围部落的男性都打不过她们，再加上她们射箭时会穿胸来保护自己，看起来胸部很平，所以周围部落的男性就用“没有乳房”这种表述来黑她们。

亚马逊公司选择amazon作为自己的公司名，有几重含义，杰夫·贝佐斯认为，亚马逊河流域生物种类极其丰富，用它来表示亚马逊公司商品种类应有尽有。另外，亚马逊的logo上有一个笑脸一样的箭头，从a指向z，英语26个字母，正是从a开头，以z结尾，蕴含着一网打尽、无所不包的含义。

trump card：在扑克里，trump card的意思是“王牌”，从19世纪初开始，trump card 也被用来指“有效的谋略、手段”。

# | “万货商店”亚马逊的下一步

今天的内容来自于科技大刊《连线》杂志的封面文章，标题是《“万货商店”亚马逊的下一步》，Amazon's Next Move。作者利亚特·克拉克（Liat Clark）是《连线》杂志的责任编辑。

说起亚马逊，最近几年没少上头条，它最早是一个在线购物网站，同时，还做云计算服务，全球十大视频网站中唯一收费网站Netflix是亚马逊的客户。这个云计算平台年营收已经有120亿美元。亚马逊今年6月份，花137亿美元收购了线下食品连锁店全食，另外还涉足影视业，旗下电影已经拿下了三项奥斯卡奖。

2013年的时候，一名叫布拉德·斯通的记者就专门针对亚马逊写过一本书，书名叫做《万货商店》。截止到今年的4月份，亚马逊的市值已经达到了4398亿美元，成为全世界第四大公司，而前三名分别是苹果、谷歌和微软。

接下来亚马逊要做什么呢？亚马逊的trump card（王牌），到底是什么呢？

# | 为什么大公司都在搞音箱

最近各大科技巨头，争相推出自己的智能音箱，谷歌推出google home，苹果推出home pod，而亚马逊在这个方面走在了前面，早在2014年就推出了自己带人工智慧的音箱Echo。

巨头们为什么这么热衷于做音箱呢？其实智能音箱的核心，就是四个字：人工智能。音箱就是人工智能的交互界面，科技巨头们的争夺战，就是一场人工智能的交互界面之争。

现在的智能语音助手对于手机极其依赖，比如说苹果的语音助手Siri和微软的语言助手小娜（Cortana），这两个智能助手最大的问题就是将交互界面死死地局限在手机触摸屏上。这些科技巨头公司，苹果、谷歌、微软也都意识到了这一点，并使劲儿地让智能助手有更多的载体。

家庭里，还有什么电器能够成为这样的载体呢？音箱就是个好地方选择，现在人们可能不是经常打开电视，但是都愿意享受音乐带来的快乐，所以用音箱作为一个交互界面就很适合。

亚马逊的Echo，内置智能语音助手Alexa。你家里如果买了亚马逊的智能设备，只要喊一声Alexa，这个智能语音助手就会被自动激活。
