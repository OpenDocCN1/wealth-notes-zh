**hybrid [ˈhaɪbrɪd] : 杂交、混合。**

两种不同的东西混合在一起，就可以说hybrid。比如在赛车里是汽油和柴油都能叫hybrid car；被称为混合动力车，英文就叫hybrid car；混合起来的系统，就叫hybrid system。

#### 为什么大多数怪物都是混合体

今天我们看的是《鹦鹉螺》杂志的《为什么大多数怪物都是Hybrid？》，**Why Are So Many Monsters Hybrids?**

这篇文章，主要是通过探讨人类对于怪物的恐惧，帮助我们理解恐惧的来源，更好地克服恐惧。这篇文章的作者斯蒂芬·阿马尔马是芝加哥哥伦比亚大学的哲学教授，他也是一位非常高产的作家，已经出了十本书，其中有一本就是专门研究人类恐惧的。

#### 什么样的怪物最吓人

英语的monster这个词，来自于拉丁词monstrare，意思是to warn（警告），那些值得我们警惕的奇怪之物，就是怪物。

作家阿玛说，他觉得最可怕的怪物，是《异形》里的抱脸虫，英文名face-hugger。这是异形的幼虫，像一只流淌着黏液的巨大蜘蛛，钻进人类体内，最后从大异形破面人的胸腔里出来。他13岁的时候第一次看到这种怪物，整整一个多小时的剧间都没法进去，稍微有一点点风吹草动都会让他彻夜不眠，留下的心理阴影实在太深了。小时候看《异形》的那夜晚上，我吓得没敢睡觉，之后也花了好长时间才缓过来。

不知道你发现没有，人类想象出来的好多可怕的monster，都是不同的东西混杂在一起的。异形的抱脸虫，就是蜘蛛+吐粘液的混合物。

而在很多不同的文化中，也到处都有这种混杂的怪物，比如古埃及文化里的斯芬克斯，狮身人面像，就是狮子的身体混杂人的脸发出的怪物。在古希腊神话里，半人半马的变通，它能去吃掉你，狮身人面像到现在已经有至少4500年的历史了。

而在文学上《吉尔莫美多里》，人鬼写的“半仙半鬼”，是半人半魔鬼，是一种长着狮子的头和爪子，身体上覆盖着鳞片的怪物，相当于狮子和龙蛇的混合体。文章里面有个这怪物的插图，你可以清楚地看到它的样子。

![](img/183bdfd5baf7cb9c4bd26d5a132a702e_203_1.png)

而在希腊神话里，混合式的怪物就更是多了去了，比如说半人鱼、马人鱼、九头蛇、夸特狗，这些原本只能是写文字的图片流传的物品。如今用先进的图形艺术，都能鲜活地变成形象展现在我们面前了。

其实无论是古老的英国传说《贝奥武夫》，到托尔金的《指环王》，再到美国的《哈利·波特》，里面永远都存在着各种各样、混合了各种可识别形象的怪物，甚至在现代的小说里，机器人与机器的合体，也属于这一类，比如说《终结者》。

毫无疑问，hybrid monster 的可怕程度是远高一般怪兽的。根据作者分析，这主要是因为两个原因：生理和文化造成的恐惧。

#### 怪物恐惧的生理机制

达尔文曾经做过这样的实验，他多次把真正的动物带到动物园里的灵长类动物里，后发现它们很不安，不管是猴子还是猩猩，都会让发慌灵长类动物。哪怕是生活动物圈里，没见过蛇的黑猩猩都害怕蛇。难道是在漫长的进化过程中，对于险象的恐惧感深深地植入了动物的脑海里吗？

并不是。这种恐惧其实是因为动物的大脑存在着分类机制。而这种分类机制，人也有。

根据心理学家丹·斯帕伯和人类学家斯卡波的尔的研究，当我们还是孩子的时候，我们就容易觉察或者不自觉得，去周围的事物品类、比如说，这是人，这是狗，这是虫子，水边的都是鱼，这些都是虽然很粗糙，但却是我们理解世界最重要的一种方式。

我们大脑这么做，主要是因为我们需要帮我们建立一种预测型的模式，区分出有用的信息和无用的噪音，可以帮助我们更好地生存下来，还可以节省我们的认知带宽。

根据心理学家梅德·格蒂和沃夫冈·施莱顿的研究，动物在学习分类的过程里，很快形成了“自动化反应的模式”。任何陌生的生物，如果靠近它，不在它们的认知分类里面，就会反应。这就是比如幼年老鹰，一旦看见老鹰在老鹰的形象里，哪怕老鹰是它的干父，在老鹰心目中，幼鸟也不会害怕老鹰。但是当认知形成之后，给幼鸟看了它们没有见过的大白鹫的图片，鸟马上不会产生任何威胁，它们仍然会感到害怕。

人类幼儿形成各种分类的时间，大概是在六个月左右。如果在人类的脑子里，在保护大分步的时候，被其他动物所害，获得得很好，任何在地上爬行的东西很容易引起孩子的恐惧，因为这完全突破了他们的认知分类。说白了就是，“没见过，我害怕。”

而综合了各种具有杀伤力的生物特点的怪物，显然在任何一个分类中，但却极其危险，这是引发生理恐惧的恐怖。排除了生理原因，文化原因也会让我们产生对某种特定事物的恐惧。

#### 怪物恐惧的文化和社会原因

出于各种文化和政治的需要，把各种抽象的概念，变成具象的怪物形象，引发人们的厌恶、至恶者恐惧，是一种非常有效的行为引导手段。比如说，你要是破坏了某种规则，小鬼就会来抓你；如果抽烟，恶魔就会找上你；如果会失败，你会像动画片《千与千寻》里的人一样，变成一头大的猪。

为了激发厌恶和恐惧，所有的敌人都必须被描绘为下跪、不堪，令人厌恶甚至让人恐慌。这个时候英雄出场才备受期待和瞩目，会变成一个文化认同，比如童话里的主角和坏人、神话中的英雄、文章里至善的神和圣人、神话中的英雄，文章里甚至还提到了中国的孙悟空。当我们讲起这些故事的时候，其实就有了善恶之分。

什么是对错，什么是正确的行为准则，故事起到了加固文化和社会认同的作用。当我们有了共同敌人，我们才会更团结，所以怪物的作用，是使得人类，可以更容易地被团结在某种社群之中。

而为了达到更好的传播效果，怪物的形象设计就很有学问了。普通的东西是不够的，只有当我们看到突破我们认知分类的事物，比如说会飞的蛇、下半身是蛇的人，这种东西就会迅速抓住我们的注意力，更难被忘却，很容易回忆起来，也更容易在人群里形成传播。

所以怪物总是被描绘成奇异的形状，综合很多丑恶凶暴的动物特征，是为了更好地被记忆和传播出去。

因此后天的文化因素也会引导人们的恐惧，而文章里说，当一种怪物具备了生物和文化的双重恐惧属性，才是最成功的，而好莱坞一直很善于设计出这样的怪物，这也是恐怖片票房的保证。

通过这篇文章，我们知道了一件很重要的事：恐惧并不是与生俱来的，是后天习得的。通过分类，通过文化因素，我们才产生了恐惧感。

那么我们怎样克服恐惧感呢？一个简单的办法就是扩大分类，习以为常的事物不会让我们恐惧，突如其来的东西才会让我们害怕。如果你害怕某种事物，比如说演讲，如果不试着挑战自己的恐惧，努力去习惯当众讲话的状态，你一辈子都是害怕的。就像文章里说的，恐惧来自于认知混乱，并不来自源于认知的内容本身。

## 投机：speculate

周一我们讲了《万千》网站上的文章《着想不一般的成就》，An unlikely triumph.

这篇文章说的是美国高等教育是怎么崛起的。让人意想不到的是，一开始美国办大学，不是为了教育，而是为了增加房地产地，也就是文章的关键词：speculate（投机）。结果这些大学为了活下去，进入了残酷的市场竞争，变成了四下生亡生出来的——杀敌者，在熬过了一开始的困难之后，形成了世界顶尖的高等教育体系。

## 混合：hybrid

# 今日关键词

Lean: 这个词是指“短少的，肌肉精壮的”，在管理学当中，被翻译成了“精益”。比如说管理的《精益创业》，就是 *The Lean Startup*。

# 通用向谁学习

今天内容来自《财富》，标题是《通用向谁学习》， *Teaching a Giant to Think Like A Startup*，作者是埃里克·莱斯（Eric Ries），莱斯是硅谷企业家，也是畅销书作家。

埃里克·莱斯在美国可是个红人，他最初走红是因为他投的那些创业公司，告诉你们大企业都用了哪些有效的策略和方法，他还因此写过一本书《精益创业》，讲的就是这些创新。在今年，他又出了一本书《像初创公司一样管理大企业》（The Startup way），反过来，教那些全球化的大公司像创业公司一样灵活、创新。

今天这篇文章讲的是通用电气向莱斯请教了，这是因为他谈的是如何优化。莱斯本身是一个外科，不懂通用那些技术，但在他的引导下，通用确实能取得了一些成就，比如一个本来计划五年能完成的项目，缩短到不到六个月，就初步地实现了。

咱们今天就讲的问题，是莱听到他是怎么做到的，他的方法是什么？我们怎么能在生活中去借鉴。

# 企业教练埃里克·莱斯

对莱普管理理念影响最深的，是由丰田的生产过程衍生出的管理哲学——精益管理。这个概念的核心意思是，任何不能给消费者带来价值的事情，就只能是资源的浪费。这话听着有点绕，说白了，一个企业自己没想得再仔细，也得用全量，前量再远一点，如果用户不买账，就是白烧钱。

丰田汽车坚持要贯彻这一理念。别的汽车厂商搞的是大批量、大生产，靠广告营销和廉价的小机组生产来赚钱，哪里需要，哪里就迅速调整，反正规模也不大，而成本还会更低，这反而帮助丰田迅速抢占了市场。

埃斯精益创业的核心思想是用最低的成本、最快的速度去做试验。他提倡企业进行“假设性设计”，先向市场推出最小化可行产品，再根据反馈进行调适，不断测试。最小化可行产品的英文是Minimum Viable Product，简称MVP。

埃里斯呢？就是你得先出一款产品，不用非得在尽量完美的时候才推出，先做一个基础款，具备核心功能就行，这个基础款就是咱们刚才说的最小可行产品MVP。

那这个思想，到底要怎么用？

# 通用向莱斯学了什么

莱斯在书中介绍了他给通用电气优化项目的经历。当时，通用电气的CEO杰夫·伊梅尔特（Jeffrey Immelt）和副总裁康尼·斯图（Beth Cornstock）读了莱斯的《精益创业》。对于精益创业的理念非常感兴趣，他们认为，通用电气这家有150多年的历史的老牌巨头公司，也需要尝试新方法，让通用能更好地适应时代，持续成长，长久地繁荣下去。

当时，他们计划做一款做X系列（Series X）的发动机，设想得特别好，这个系列的发动机可以适应不同的地形和环境，全方位的满足各种类型的客户，但是是一个10亿级别的项目，他们计划用五年的时间来完成。

这个X系列就是当时通用想用来测试莱斯方案的项目。他们的想法是这样的，如果莱斯的通用化思想真的适用于大、跨平台的项目中有的效的话，那他的方法就可以应用到通用电气旗下各个行业的主题中。

莱斯和书里详细记录了过程。通用的工程师和各层管理层在讨论项目的时候都普遍，你想啊，一个10亿级别的项目，主要是做了，各个行业可以融合在一起，可是做了一件大事，作为变革与在莱克的引下，提出了各种疑问，当时那些高层和工程师们一致表示，心想这是谁呀？接下来莱斯就一步一步地引导他们，将五年的工期变成了六个月。

在这个过程中，莱斯主要用了两招，第一招就是最小可行产品MVP，先做这个基础款。第二招是假设，分清楚哪些是你自己确定的信息，哪些是你自己的假设，这还得看怎样最小化可行产品来做。咱们来简单总结一下。

莱斯举了一个例子，比如他要把高管、工程师等各个相关人员都召集到一起，先讨论一下，这个系列到底要有多长时间才能完成？要多少时间？他们当时说完了这个五年计划，在这个过程中，他一直在提问。注意，这里问的是我的第一招，第一招不是，那这些消息都是确定的，哪些是假设的。他问，你们怎么能知道这个产品可行不行呢？要不要各种条件？你们怎么知道这些人的需求是这样呢？你们这么短的时间到底是因制作流程，还是因为通用电气内部的流程呢？

通用的团队就纷纷表示各种图表、数据、预测，就是希望未来会给创造数十亿收入的美梦未来。莱斯说这篇文章写道，说了这么多，还是没解决这个问题，那就是为什么有这么长时间才能做好这款发动机？

莱斯说，关键就在于这个项目，设想也太太细，想一次性解决所有问题。但你想到的这些想法，都是由传统的市场调取的方法收集到的，不是通过实验证的实验，就算你们对时候都是对自己过的度想象，就真不知道，他们未来会跟你想什么？那这个计划，大家都把这意图想在这么太的大图上，也就是这些东西到底能不能做出来？莱斯说，你们有没有想过另一个问题，它不应该被做出来？

实践出真知，这得用最小可行产品MVP来实验。经过讨论之后，工程师得出结论，可以把整个产品过程，从五年前到两年，莱斯想验证努力，他们五年都到问题，如果是做出第一个发动机需要多长时间呢？
