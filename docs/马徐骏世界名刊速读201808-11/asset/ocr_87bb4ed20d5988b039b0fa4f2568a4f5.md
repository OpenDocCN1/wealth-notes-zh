# | 什么是“蜂后”型同事

20世纪70年代，密歇根大学的社会心理学家用“蜂后”——queen bee这个词来指代在职场上故作强势的女性，也叫蜂后效应。指的是一些女性在职业上比较成功，成为了企业高管，会觉得自己和其他的女性不一样。这些女性高管对待比自己职位低的其他女性时，就会更为苛刻和挑剔。

作者卡赞采访了各行各业的女性，询问她们是否遭遇到过来自同性上司的职场冷暴力。绝大多数女人都说：有！其中一个采访对象是这样说的，有一天，她上班的路上把脚给撞伤了，脚踝一直在肿，所以她就去问女上司能不能早点下班去看看吧。结果这个女上司特别生气，用很失望的语气对她说：“我本来是你寄予厚望的！”不仅请假没给到批准，还教育了她一顿。

此类案例还有太多，女性对于自己的同性上司的评价都很低，有的表示自己在工作上犯了一点点小错误，女上司就对她大喊：“我怎么可能和你这么没用的人一起工作呢？”要不就在网上说，说她们没有理想，不上进。还有的当着你的面说你工作有进步，转头就和同事说你工作能力不行。

2011年，加州大学洛杉矶分校的女性研究中心的研究者希金·范恩萨，分析了一份受访者超过6000人的调查。调查问卷是：“你更希望有一个男上司还是女上司？”绝大多数受访者表示更想要一个男上司，这些受访者描述女上司用的词多是“情绪化”“阴险”“刻薄”。

在另外一个调查中，受访者来自于律师事务所的142个秘书，她们全部都是女性，居然没有人表示说和女老板共事。其中只有3的人吞吞吐吐地表示，如果有女同事还忍得一忍。这些秘书都表示，和女同事、女老板共事实在是太痛苦了，连夜都睡不好，还会头疼。这个律师事务所的调查报告在《美国银行家协会期刊》上刊登后引起了轩然大波。读者表示女同事赤裸裸的性别歧视了。这些愤怒的读者要求他们把文章撤下。后来《美国银行家协会期刊》迫于压力，刊登了一篇道歉信。

从这些数据和调查来看，在职场上，歧视女性的主体，居然是女性自己。那是为什么呢？
