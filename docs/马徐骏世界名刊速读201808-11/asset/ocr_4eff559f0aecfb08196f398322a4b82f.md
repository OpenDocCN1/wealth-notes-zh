# 今日关键词

iGen : iGen 是一个组合词，Internet Generation，即“互联网一代”的缩写。中国人会用10年为一个单位划分代际，70后、80后、90后、00后。而美国人喜欢用共同的特征来区分。之前专栏里讲过的 Baby Boomers（婴儿潮一代）就是这样的典型，还有 X generation（X世代），Millennials（千禧一代）。Internet Generation 也就是 iGen，指的是1994年之后出生的人。

Internet Troll：意为网络巨魔，指的是在网上发起攻击性言论，打击破坏谈话，甚至辱骂、威胁他人的人。Troll 这个词的意思就是巨魔，比如《哈利·波特》里出现过的山地巨怪就叫 Mountain Troll。Internet Troll 有点像水军、刷房客的集合。

# 如何对抗冒犯性的言论

今天的内容来自于《鹦鹉螺》杂志的文章《如何对抗冒犯性的言论》，*How to Defuse Offensive Speech*。

这篇文章，对每个生活在这个时代的人来说都很重要，在这样一个信息井喷的互联网时代，人们在网上表达自己观点变得非常方便，几乎不用付出什么成本，这带来了更平等的表达环境，但同时催生了网络暴力。美国艺术家安迪·沃霍尔有一句话很有名，“每个人都有机会当15分钟的名人”，但他可没说这15分钟的名人是好还是坏，可能一句无意间的话，一张你自己都忘了的照片、一个不小心丢失的电子设备，都有可能让你登上头条，成为别人关注的对象。你可能会说，我就是个小透明，这样的机会离我太远了，但你有机会在网上碰到过骂人吧、说话难听，甚至是粗言、没教养的人吧？被人说闲话或者被人用无中生有的语言攻击，气不气？甚至哪怕就是现实生活中的流言蜚语，都会影响你的心情，甚至是健康。

# 可怕的网络暴力

美国华盛顿首府奥林匹亚有一座文理学院。一次，学校里所有白人教授都被邀请参加一个活动，叫“一天不进校园”。按理说，既然是邀请，可以参加也可以不参加。进化生物学教授布莱特·温斯顿就拒绝参加，理由是，“一天不进校园”的活动，是1970年代黑人公民运动的一部分，为的是体现黑人学生的重要性，展现的是如果校园里没有了黑人，感觉会多么不一样。温斯顿认为，这样的活动是黑人民运的传统，白人为什么掺和？

结果温斯顿教授被叫成“超级恶毒的白人工族主义者”，有很多针对他和他家人的暴力威胁，最后他不得不躲了起来。

语言攻击的伤害力，并不比身体攻击小。

神经科学家和心理学家丽莎·巴瑞特说，暴力语言对一个人造成的伤害很大，哪怕是在没有任何肢体接触的情况下，也会让人倍感恶心，它会伤害大脑中的神经元，甚至损害健康，会改变你对这个世界的看法。

相比之前，信息时代中的语言攻击更加泛滥和频繁了。人们在现实生活中，多少还会有所收敛，但在网上因为不用对自己的言行负责，心理阴暗的人会更加肆无忌惮。

社会心理学家珍妮特·温格写了一本书，叫《互联网一代》，这本书里的研究发现，在美国90年代中后期出生的年轻人，也就是iGen，他们的精神健康状况比前代人更差。
