马徐骏

《马徐骏说·世界名刊选读》本期为你讲述《今日心理学》的封面文章。

在职场和生活中，学会拒绝是非常重要的能力。为什么说“不”这么难？又该怎么学会拒绝？

今天的内容，会让你了解：

+   - 为什么拒绝别人这么难？
- 哪些人特别不擅长拒绝别人？
- 想要拒绝别人该怎么做？

# ## 知识清单：

+   - 1日关键词

refuse：拒绝。除了这个词汇以外，还有几个词也可以表示拒绝。包括：reject、decline、denial。词组turn down，除了“关掉”的意思，也可以表示拒绝。

+   - 1世界上最难说出口的话

这是《今日心理学》第一次出现在这个专栏中，它是一本创立于1967年的月刊，总部在纽约，聚集了众多著名的心理学家、学者、精神病学家和作家等专业人士，旨在帮助受众正视、研究心理问题，对正在发生的事情进行分析，并寻找解决办法。

这期《今日心理学》的封面文章《世界上最难说出口的话》，The Hardest Word，其实说的就是一个词，no。

这篇文章的作者拉林·福洛拉是一位科普作家，也是《今日心理学》的杂志编辑。福洛拉在文章的副标题里说，要对别人的请求开口说“不”的确不是一件容易的事，对于每个人来说都是这样。但是学会拒绝，对于一个人的心理健康和自信心的建立都是非常重要的。

今天这篇文章探讨的就是，为什么说“no”这么难，以及应该如何学会拒绝。这对每个人的生活都会有帮助。
