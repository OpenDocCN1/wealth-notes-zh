# 用Python写个拉取Facebook广告平台cost的小工具，最好可以可视化

好的。以下是一个使用Facebook Ads API和Python编写的拉取广告成本的小工具，并使用 Matplotlib可视化结果：

首先，需要安装Facebook Ads API和Matplotlib库。可以使用以下命令进行安装：

```
```
pip install facebook-business
pip install matplotlib
```
```

然后，在Facebook Ads Manager中创建一个应用程序，并生成一个访问令牌。在代码中，需 要使用此访问令牌进行身份验证。

```
```python
from facebook_business import FacebookAdsApi
from facebook_business.adobjects.adaccount import AdAccount
from facebook_business.adobjects.adssnake import AdsInsights
from matplotlib import pyplot
```
```
