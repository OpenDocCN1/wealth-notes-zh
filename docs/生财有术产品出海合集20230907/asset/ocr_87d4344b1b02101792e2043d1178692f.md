+   2. 中国优秀的企业家和资本、管理、技术等向东南亚输出。

这个过程不是现在才开始的，早在几十年前，

东南亚的各个国家，都有我们的华侨、华人，去到当地。

而在这个阶段，在当地耕耘沉淀了多年的华侨华人与国人的碰撞合作，国内创业者与东南亚本土的融合，出现了“井喷”式的力量，击穿了这个量变到质变的点。

中国输出技术、管理、资本，东南亚国家进行生产流通销售的贸易体系。
