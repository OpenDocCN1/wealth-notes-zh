# 1.1.2 通过自身需求挖掘痛点

可以先从自己的需求出发，问问看自己有那些行为能够通过AI绘画完成。

然后作为一个用户，下场体验不同的产品，并把你遇到的问题记下来。

在使用时记录下来遇到的问题，问题包含三类：

3）**app**什么地方改善，会让你觉得更好？
