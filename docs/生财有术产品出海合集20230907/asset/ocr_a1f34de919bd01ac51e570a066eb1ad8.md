比现在我们的展示份额仅在 SHEIN（希音）和亚马逊下面，说明我们的展示份额已经比其他竞争对手高很多，在我们前面只有一些顶级头部卖家。

好了，在广告账号慢慢养成的同时，我们也开始去找国外的网红帮我们做一些产品测评，还有找国外的媒体网站去帮我们背书。

一般会把网红根据粉丝数目分为五大类：

+   - 入门级：5,000-15,000 粉丝
- 低级：20,000-50,000 粉丝
- 中级：60,000-150,000 粉丝
- 高级：200,000-500,000 粉丝
- 大咖：500,000-1,000,000+ 粉丝

粉丝太少，对品牌和产品的宣传力度就没那么大；粉丝太多，价格又太贵。所以我们先选中级和高级的红人。然后开发信方面，我们尽量对每个网红都是有自定义的内容，不会完全发一个相同的模板。这会显得我们更加真诚，有合作的诚意。

在这么有计划地推广下，我们 3 个月就做到盈亏平衡了。
