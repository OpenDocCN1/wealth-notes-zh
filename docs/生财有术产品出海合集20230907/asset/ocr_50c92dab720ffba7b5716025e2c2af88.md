# # (精华帖)(139赞)在疫情期间找准用户需求， 半年打造月销千万的品牌独立站

作者：鱼丸|亦仁助理

疫情爆发，跨境物流费用暴涨，利润空间被疯狂蚕食，这是目前跨境卖家普遍遇到的问题。既然没办法节流，开源就十分重要了，如何找到疫情期间的产品需求呢？本期「生财合伙人」专栏，@图帕先生 就來和我们一起聊聊这个话题。
