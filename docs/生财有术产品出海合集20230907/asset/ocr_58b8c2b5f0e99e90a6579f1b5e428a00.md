# 2、考虑地区及用户差距

不同广告平台的在不同国家的表现差异是非常大的，开发者要结合自己流量分布的情况选择合适的平台接入。如果对海外广告平台不够了解，可以参考 **Appsflyer** 等三方平台出具的广告平台综合表现报告，对各个国家的常见广告平台优先接入。
