如果必须 SDK 接入，还需要考虑 SDK 的大小，是否会影响应用初始化？

以 Google Admob 中介为例，官网上清晰注明哪些广告平台是支持实时竞价，且是否需要接入第三方 SDK；如果广告平台支持实时竞价且不支持第三方 SDK，那接入及运营成本相对较低，可以优先考虑。
