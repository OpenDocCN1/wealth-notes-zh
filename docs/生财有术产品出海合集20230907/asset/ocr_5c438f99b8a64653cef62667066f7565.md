# 五、过程中的一些经验分享

+   1.通过关键词和自身需求挖掘痛点，利用好第三方工具。

+   2.验证需求注意四点：用户画像、使用场景、行业竞品、确保产品能够解决需求。

+   3.寻找达人tiktok上除了搜索，利用好达人的关注和类似账号，再关注#标签。

+   4.Tiktok creator marketplace用来分析达人数据很好用，但是达人收录不完全。

+   5.联系达人常见方法是Insta或邮箱，其次是星图和评论区留言，最后是私信。
