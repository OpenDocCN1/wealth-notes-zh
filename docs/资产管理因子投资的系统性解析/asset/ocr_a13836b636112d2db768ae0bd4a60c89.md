# 6.2 房地产与通货膨胀

关于房地产对冲通货膨胀的效果如何，文献中有很大分歧。Fama和Schwert（1977）首次提出，房地产可以完美地对冲预期内和预期外的通货膨胀。但是，由于缺少直接房地产投资回报率的数据，他们只能使用CPI指数中住房部分的数据。对于直接房地产投资，研究结果并没有统一的定论。一方面，Goetzmann和Vallais（2006）认为，直接房地产投资可以较好地对冲通货膨胀。另一方面，Huang和Hudson—Wilson（2007）发现“常识上认为的房地产作为一个资产类别可以有效地对冲通货膨胀的看法是言过其实的”。从文献中可以清楚地看到，REITs在短期并不能对冲通货膨胀1。Gyurko和Linnelmann（1998）认为，将REITs作为对冲通货膨胀的工具并不合适。

我相信房地产在某种程度上有一定的对冲通货膨胀的效果，但是远远谈不上有效。房地产投资只能进行部分对冲。

在图11.9中，我展示了在多个时间段内，直接和间接房地产投资回报率与通货膨胀率的相关系数。作为对比，我在图中也画出了股票回报率与通货膨胀率的相关系数。我们在第8章中可以发现股票对冲通货膨胀的效果不佳。图11.9-A画的是传统的皮尔逊（Pearson）相关系数。REIT回报率与通货膨胀率的相关系数略高于股票回报率的相关系数，这两项相关系数在一个季度内约为0.1，在五年后升到0.4。NCREIF回报率与通货膨胀率的相关系数在一个季度内约为0.4，五年后微降至0.3。正如我此前强调的，NCREF回报率的数据在短期内由于流动性偏差，可信度不高。在长期内，流动性偏差明显缓和，NCREF和REIT回报率与通货膨胀率的相关系数均在0.3至0.4之间。因此可见房地产在长期内可以部分对冲通货膨胀，而在短期内不能。

图11.9-A显示的相关系数均存在高估。在图11.9-B中，我画出了更稳健的斯皮尔曼（Spearman）相关系数。三项相关系数均低于A图的皮尔逊相关系数。REIT回报率和股票回报率与通货膨胀率的相关系数在短期内均为负值，约为-0.1（这与第8章关于股票的发现一致）。一年后，REIT回报率与通货膨胀率的相关系数略高于股票与通货膨胀率的相关系数。五年后，REIT回报率的相关系数约为0.4，与A图中的值相同。而B图中的NCREF回报率与通货膨胀率的相关系数比A图中的值明显下降。NCREF回报率的相关系数在一个季度内约为0.2，随后升到0.3，而在五年后又降回0.2。

① Classcock，Lu and So（2002）认为，我们观察到的REIT回报率与通货膨胀率的负相关性在统计上是一种伪相关。它可以被其他宏观因子解释，尤其是货币政策冲击。这与Fama（1981）关于股票对冲对通货膨胀效果不佳的文章观点相似（参见第8章）。Case and Wachtel（2011）观点相反，他们认为REITs的对冲效果很好，但他们并不是将对冲对通货膨胀的效果定义为与通货膨胀率的相关系数。
