# （2）信息匮乏

契约是不透明的，并且存在各种不为人知的费用。Loftis关于PE合同是“普通纳税人难以理解的”说法是绝对正确的。Philippou（2009）认为所有的PE信息——包括真实收益率和费用支付——都是“隐蔽的”。

# （3）有选择地公布

“你接触的每家私募股权公司都处于第一象限。”一个大型养老金基金的管理者指出⁽¹⁾。而这些公司并没有说谎。通过有选择性地公布IRR、倍数，甚至是初始投资年份，所有PE公司确实都可以处于第一象限。于是，投资者被一些可疑的粉饰表象的业绩衡量指标所欺骗。

# （4）被行业宣传欺骗

或许资产所有者是被PE表现优异的业界宣传引入歧途。他们根本不知道有生存者偏差、低频交易偏差、选择偏差，以及其他涉及衡量PE收益率的问题。或者他们的顾问还没有阅读（或理解）针对这些问题的学术研究。

# （5）投资者目光短浅

即便投资者具备挖掘所有这些信息的能力，他们也会视而不见⁽²⁾。

# （6）缺乏学习能力

或者可能是不想学习？不管怎样，大多数资产所有者并不具备Swensen所说的那种“选择基金的高超技能”。有些投资者甚至欺骗他们自己说目前的合同是最优的。针对这种流行的2/20合同，美国加州公共雇员养老基金说：“当这种报酬结构被使用时，基金管理人的财务利益与包括我们在内的有限合伙人一致。”⁽³⁾
