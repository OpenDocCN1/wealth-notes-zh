# 2.2 包含无风险劳动收入的资产配置

现在考虑有无风险劳动收入的个人的资产配置，例如一个顶尖大学的终身教授或者法官。她的人力资本等同于拥有无风险资产。假设她的工资现金流等同于现在的人力资本 $H = \$ 1000000$，她还有 $W = \$ 1000000$ 的金融资产。因此，她的总财富为 $H + W = \$ 2000000$。与第一个投资者一样，我们假设她的风险厌恶系数 $\gamma$ 为5。

在有无风险劳动收入的情况下，对风险股票的最佳持有量为：

```
$ w^{*}=\frac{1}{\gamma} \frac{\mu-r_{f}}{\sigma^{2}}\left(1+\frac{H}{W}\right) $ 公式 (5.2)
```

注意当人力资本为零时，$H = 0$，公式（5.2）就与（5.1）完全一样。有无风险劳动收入的投资者相对于只有金融资产的投资者会将其资产配置向股票倾斜。投资者在这个例子中持有股票的比例是：

```
$ w^{*}=\frac{1}{\gamma} \frac{\mu-r_{f}}{\sigma^{2}}\left(1+\frac{H}{W}\right)=\frac{1}{5} \frac{0.10-0.02}{(0.15)^{2}}\left(1+\frac{1}{1}\right)=125\% $ 公式 (5.3)
```
