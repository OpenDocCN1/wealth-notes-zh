基于Vayanos和Vila（2009）的现代“客户模型”预测，在其他条件不变时，供给越小或者需求越大，债券价格越高，收益率越低。Vayanos-Vila分析框架认为，特定类别的投资者，例如外国投资者，由于一些外部原因而只购买特定期限的债券——以中国为例，这个外部原因可能是为了管理汇率——这些外国需求影响了债券价格。Greenwood和Vayanos（2010），Hamilton和Wu（2012），以及Krishnamurthy和Vissing-Jorgensen（2012）发现，国债的供给效应与“客户模型”一致。因此，在考量美联储的行为时，例如量化宽松政策，必须同时考虑到外国投资者的需求，这将涉及供给余额如何影响到固定收益产品的最优持仓量。我们将在第14章再次讨论这些问题。

# 4. 信用利差（公司债）

到目前为止，我们的分析都是基于债券无风险的假设。对于公司债而言，它会受到所有影响无风险债券的因素的影响，此外，我们还需考虑信用风险，或违约风险。我们可以看到，公司债利差，即公司债与国债的收益率之差，并不只是包含信用风险。
