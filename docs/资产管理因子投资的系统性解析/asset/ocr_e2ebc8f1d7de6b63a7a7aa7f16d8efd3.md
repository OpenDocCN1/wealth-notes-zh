司售出其他服务而赚取大量财富，并通过这种方式来补偿它们在PE投资中的损失。普通的资产所有者就没有这样的奢华待遇。

# （8）错误定价

最后，投资者可能为PE投资支付过多费用。有太多的有限合伙人向数量极其有限的PE公司投入了太多资金。从长期看，投资者可能会恍然大悟，PE价格也会随之降低。

有些PE公司正在为预期的业务下滑作调整。大型并购基金如黑石（Blackstone）、凯雷（Carlyle）和KKR集团，已经开始多样化经营，涉足对冲基金和类似投资银行的咨询业务。从更广的层面，有些甚至开始启动共同基金，从而吸引新的投资者类别——父母们——以获得低于平均水平的风险调整后收益\[1\]。

# 4.6 Kauffman基金会的报告

Ewing Marion Kauffman基金会从事提升企业家精神和教育的事业。截至2011年末它的基金规模达到18亿美元，其中45%的资金投入PE。2012年，该基金会发布了一个不可思议的、自我反省的报告“我们遇到了敌人……敌人就是我们自己：从Kauffman基金会20年间投资于风险投资基金和希望战胜经验的教训”。这篇报告让人惊叹于它的诚实——考虑到该基金会专注于企业家精神，却揭示了这个机构在风险投资中的失败案例。结果表明，在扣减费用之后，Kauffman的风险投资平均来看尚不足以返还投资者本金。

这个报告陈述了Kauffman捐赠基金不断追求风险投资美梦的主要原因在于“像我们这样的投资者一次又一次地为故事所误导，一个被充分研究的金融学偏见。关于风险投资的故事是引人注目的，故事里遍布创业英雄、惊人的回报、和命运被成功改写的公司”。希望和梦想，确实如此。

Kauffman的报告提倡从IRR和倍数等衡量指标转向采用相对于小盘股的业绩衡量指标。这正是延伸到规模风险因子的PME的概念。这也是被加拿大养老金计划基金管理人——加拿大养老金计划投资委员会（Canada Pension Plan Investment Board、以下简称CPPIB）所实践的“因子投资”概念\[2\]。对于CPPIB来说，PE不是一种资产类别，
