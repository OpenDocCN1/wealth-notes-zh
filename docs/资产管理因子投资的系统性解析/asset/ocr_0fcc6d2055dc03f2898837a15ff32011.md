# # 3. 生命周期

在阐述生命周期的最优资产配置之前，我们先来回顾一下。

# ## 3.1 金融规划师的建议

金融专家提出的普遍建议是，随着年龄的增加，要减少股票配置。一个流行的法则是用100减去你的年龄，也就是说你在资产组合中配置的股票比例应该是你的年龄与100之间的差值。还有很多其他不同的说法，但我会把那些建议你随着接近退休而逐步减少风险资产配置的计划都称为“100减去年龄法则”。

表5.1 生命周期的资产配置

A表：Vanguard Target Retirement 2050基金

|  | 股票 | 债券 | 现金 |
| :--- | :---: | :---: | :---: |
| 退休前25年 | 90% | 10% | 0% |
| 退休前1年 | 50% | 50% | 0% |
| 退休 | 30% | 65% | 5% |

B表：生命周期中对股票的配置

| 年龄 | 100–年龄法则 | Malkiel（1990） | Shiller（2005） | 联邦节约储蓄 |
| :---: | :---: | :---: | :---: | :---: |
| 25 | 75% | 70% | 85% | 85% |
| 35 | 65% | 60% | 71% | 75% |
| 55 | 45% | 50% | 26% | 50% |

表5.1-A是Vanguard Target Retirement 2050基金的资产配置。这种目标日期基金（target date funds）会随着投资者接近退休而调整相应的资产配置——在此例中，退休日期是在2048~2052年之间。这种基金实际上是基金的基金（Fund of Funds，FOF），并且会随时间而改变底层基金的配置比例。投资者既要为底层的基金付费，也要为随着年龄自动调整基金配置的特权而付费（这些基金可能很贵）。根据Vanguard基金，还有25年退休的投资者应持有90%的股票和10%的债券。这个比例会随时间而发生变化，到退休前一年，投资组合可能会变成一半对一半。随着投资者变老，股票和债券投资比例的变化被称为“调降路径”（glide path）。在退休时，投资者会进一步削减股票持有量至30%。
