# 6. 主权（ “无风险” ）债券

我对因子投资的建议——是从市场组合出发，了解你的偏好与平均投资者相比有何不同——必须允许一个重要例外：即作为“安全”资产的主权债。我建议不要按市场权重来持有无风险债券，或从无风险债券的市场权重出发。然而，因子投资仍适用于这类资产。确实，这些投资的特性意味着将因子纳入考虑会非常有价值。

# 6.1  不要按市场权重持有主权债

在简化的经济模型中，政府所发行的安全资产处于零净供给（ zero net supply ）。市场上没有无风险资产的加权权重，因为对于无风险资产的每个多头，就对应有空头方为其提供头寸。无风险资产的价格是有意义的，但这些价格是借贷双方所形成的合同报价$ ^ { \text{①} } $。其他所有风险证券——股票、公司债等——都有正的净供给（ positive net supply ）而且代表真实财富。因此，对于公司债，我建议从标准的因子投资流程开始$ ^ { \text{②} } $。

这一概念适用于所有的政府债，而不仅仅是指短期美国国债。李嘉图等价（ Ricardian equivalence ）这一名词反映了任何政府债务都需被偿还的原理（“现在征税或未来征税”），在没有摩擦成本的简化经济模型中，政府债并非净财富：如果我们写出经济体跨不同年代的综台资产负债表，我们将看到零净供给。

专业人士在这些简单案例上做了进一步扩展，证明了政府债可以是净财富而且能满足借贷以外的许多其他目的$ ^ { \text{③} } $。简化的经济模型有效地指出，投资主权类安全资产的基本情景不应该是采用市场权重。主权债的市场权重意义不大：为了决定安全资产的最佳头寸，投资者需要理解安全资产所起的作用，以及政府为什么发行债券、发债数量及其违约频率。

+   1. Cox, Ingersoll and Ross（1985）的一篇重要文献指出均衡状态下的无风险利率过程受到的限制条件很少。他们假设所有安全债券都处于零净供给。
2. 公司债不是也类似吗？因为每个发行（卖出）债券的公司也会对应着一个买家。为什么公司债是净财富呢？ Miller and Modigliani（1958、1961）告诉我们，在无摩擦市场，公司债和股票没有差异。我们知道真实世界并非如此，但要点仍然一样：即公司债和股票都能对产生盈利性投资机会的风险公司享有权益。无风险性政府债则并非如此。
3. David Ricardo 是 19 世纪早期开创了经济学领域的卓越人物之一，李嘉图等价就是以他命名的。经典参考文献有 Barro（1974），其通过假设扭曲性税收来克服李嘉图等价。Lucus and Stoney（1983）是另一篇标准参考文献。 Riccitti（2003）则是一篇总结性论文。
