# ## 4.2 流行的投资建议

对于长期投资者，从Merton-Samuelson动态交易框架出发可推导出三类组合：

+   ①负债对冲组合；
②短期或短视市场组合；
③长期机会型或长期对冲需求型组合

这些投资建议与一些财务顾问的建议不谋而合。曾管理过普林斯顿高级研究院基金会的Ashvin Chhabra（2005）提出了一个从业者框架，建议个人投资者构建三种类型的组合：

+   ①保护性组合，可以规避“个人”风险。该组合是为最小化下行风险所设计的，是“安全第一”策略的一种形式（参见第2章）。准则是：“不要影响基本的生活水准。”
②市场组合，是平衡好“风险和收益来自一个广泛分散化的组合中获得与市场水平相当的业绩”，该组合具有市场风险敞口。
③进取型组合，以“承担可衡量的风险来显著增加收益”为目标而设计的。进取型组合的风险是投资者效用函数的一个属性，是为了达到更高的财富目标而机会性地增长财富的渴望。

这与Merton-Samuelson的建议看起来非常相似。Chhabra的组合与Merton-Samuelson的三种组合相对应：

+   ①保护性组合 = 负债对冲组合；
②市场组合 = 短期组合；
③进取型组合 = 长期机会型组合。

Merton-Samuelson与Chhabra的投资组合之间仍有一些微小差别。对于保护性组合，Chhabra主要提倡使用安全的固定收益资产，然而Merton的负债对冲组合认为，美国国债可能并不安全，而且考虑到偿付债务的要求，有时是极其不可靠的。但总体而言，Chhabra的理念与Merton-Samuelson的理论是相似的。

因此，一些财务规划师虽然没有读过20世纪六七十年代撰写的曾获得诺贝尔奖的论文，也仍然提倡Merton-Samuelson的动态组合选择理论。区别在于，正式的组合选择需要定量的解法（当无法解析求解时，可通过数学方法求解组合权重）、经济学的严谨性以及将动态组合选择与期权策略相关联的一些洞见，从而理解长期投资建议在何时以及为何表现得好或者坏。
