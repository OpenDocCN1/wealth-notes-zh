尸公司以亏损价售出，或者关闭。遗憾的是，这不是LP能做的决定。“私募股权是一个退出障碍很多的行业。”一位PE顾问专家讥讽道①。

按照承诺资金而不是已投资金收取管理费背后有一个理性原因。如果按照已投资金收取管理费，CP可能会尽早投出资金并且很有可能对不良公司进行投资。但是总报酬的数目之大，细分种类之多，使得上述考虑显得微不足道。资产所有者从来都应该是在价值被真正创造时 才支付费用，而不是因为管理人运营基金而付费——仅因运营基金而支付的管理费应该低得多（参见第14章和第15章）。

# 业绩提成

业绩提成一般是20%。通常的做法是，当基金IRR达到8%（被称为门槛回报率，hurdle rate）时就会先给投资人分红。相关规定十分复杂，只允许部分现金流（例如承诺资本、减记、费用等）被纳入IRR计算中。当8%的门槛收益率达到后，GP就可以获得基金利润的20%，剩下的80%则归投资者所有（这时20%的分成是从0%而不是8%收取的）。有时还会有追补条款（catch-up provision），该条款要求直到某既定目标达到后，才可以将所有分红都给CP——通常在LP收到其支出的80%后达到追补条款后，GP就可以收取属于他的20%。PE合同通常有个回拨条款（claw back provision）。在该条款规定下，GP不能保留超过基金累计利润20%（通常是20%）以上的分红。因此，回拨条款要求任何“超额分红”都归属LP。

尽管2%的管理费、20%的业绩提成（行业术语“2/20”）是一个常见的收费方式，但仍在变化。管理费在1%~2.5%，业绩提成在20%~35%之间不等。GP和LP之间利润如何分配的总休方式被称为“瀑布式结构（waterfall structure）”。瀑布式结构可以很复杂。例如，管理费可以在某基金的存续期内递减，或是承诺资金和已投资相结合（会随时间变化但是明确的），或者甚至就是一个固定金额。

# 其他费用
