如果根据信用风险来对国家进行排序，按照最安全到最不安全的顺序我们排出三个（我随机选择的）国家，分别为：挪威、美国和巴西。

# 抵押品

安全资产可作为抵押品用于借款或者做空其他资产$^{①}$。对上述国家的债务按照其能作为抵押品的能力进行排序，分别为：美国（美国国债是目前此类抵押品的最大来源），然后根据具体情况（比如说你是挪威投资者还是巴西投资者）是挪威和巴西。

# 交易

安全资产具有像现金一样用于执行交易的功能$^{②}$。中央银行用流动性一词（这与我们在第13章所讨论的非流动性溢价是不同概念）来描述这个功能$^{③}$。金融危机期间货币政策的主要目标之一是缓和流动性紧缺，至少美国是如此。如果要按照哪国债务最有助于执行交易来进行排序，将又是美国、挪威和巴西、后面两国的顺序取决于具体情形。

无风险资产尤其是货币（可以看作是即时到期的主权债）的另一个相关角色是价值标准。我们通常认为价值与衡量单位无关（比如不管用英寸还是用厘米来衡量，你的身高都一样），而且价值标准能将价值从一个单位转换成另一单位。然而，选择哪种价值标准非常重要。挪威基金公布其收益时可以采用本币、美元或一篮子货币。任何一种选择都会对基金的波动率以及公众所了解的风险有影响。

# 宏观因子

第9章详细探讨了经济增长和通货膨胀会如何影响利率以及安全资产价格。其他条件不变时，高速经济增长会让国家更加信守承诺。如果我们按照经济增长从高到低对上述国家排序，那么应该是巴西，然后是美国和挪威。如果我们按照通货膨胀从低到高对上述国家进行排序，则为美国、挪威，然后是巴西；低通货膨胀对安全资产的投资着更有利，而高通货膨胀则对着眼于投资收益的投资者更有利（参见下文）。
