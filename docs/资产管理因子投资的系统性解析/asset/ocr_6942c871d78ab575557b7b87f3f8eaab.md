12（b）—1费用得名于40法案的相关段落，该段落允许共同基金持续使用基金资产支付分销和营销费用，而不是一次性收费。12（b）—1费用设立于1980年。在2010年，投资者共支付106亿美元12（b）—1费用，其中40%支付给财务顾问、经纪人和例如退休计划记录管理者等其他一些金融专业人士，以及折扣经纪公司等。这些金融中介从事基金的营销、分销和账户管理。投资者服务费用占12（b）—1费用的52%，包括维护投资者网站、电话客服中心等 ${ }^{①}$ （很多人会认为此类费用是通过基金管理费或账户管理费支付的）。12（b）—1费用的剩余部分用于基金的承销和广告。

Janus Global Research基金的股份类别A，C和S分别收取0.25%，1.00%和0.25%的12（b）—1费用。因为不是一次性收取，一些投资者可能并没意识到他们在支付12（b）—1费用。通过在管理资产规模上收取12（b）—1费用，其实是目前的投资者付钱给基金管理公司用于增大基金规模（随着基金规模的扩大，基金往往业绩不佳），而不是新的投资者。

“其他费用”类别包括保管和法律费用、会计费用和其他行政费用。

“总运营费用”是管理费用、12（b）—1费用和其他费用的总和。Janus Global Research基金的股份类别C收费昂贵，超过2%的管理费是典型的积极型共同基金费率两倍多。其他股份类别的年度总费用约1%。较好的被动指数型基金的总运营费用远低于0.2%。在2013年3月Janus Global Research和Janus Worldwide合并之后，合并后的基金费率结构与Janus Global Research基金相同（因为Janus Worldwide不再存续）。表16.1显示Janus Global Research基金每种股份类别的费率都较高。通过简单地合并两支基金，Janus能够向资产规模更大的、拥有20亿美元的Janus Worldwide征收更高的费用，而不是只对资产规模仅为3亿美元的Janus Global Research收取这样的费用。
