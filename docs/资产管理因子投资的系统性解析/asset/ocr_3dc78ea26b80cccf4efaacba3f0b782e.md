资产管理公司也可以通过内部交易或者购买罗索1000指数型基金来复制罗索1000指数。因此，对于Martingale和GM，它们都有这样一个共同的、低成本的投资选择。

有些基准由于超出了资产所有者的专业范围，而不能被他们所复制。这类不可复制的基准就不是一个好的选择。由于资产所有者本身不能投资这个基准，那么就很难或者根本无法衡量组合经理创造了多少价值。还有一些基准，例如绝对收益基准，是组合经理都无法复制的。这种情况对于组合经理是不利的，因为他一开始就无法获得基准收益率。

# （4）风险调整

很遗憾，大部分基金管理业务中所采用的基准都没有经过风险调整。

采用罗索1000指数作为基准会假设Jacques的投资策略的贝塔值是1，但是低波动率策略的实际贝塔值是0.73。这种风险调整使得阿尔法出现很大的差异；按低波动率策略的实际贝塔值0.73来计算，其阿尔法是每年3.44%，而假设贝塔值是1时，阿尔法仅为1.50%。

当我们计算Martingale策略的贝塔值时，我们假设投资者可以构建由罗索1000指数和美国短期国债构成的基准组合（$\mathbf{r}_{i}^{\text { benchmark }}=0.27 r_{f}+0.73 r_{t}^{R 1000}$），并且每月进行再平衡。GM资产管理公司很容易做到这点，但对于那些不够成熟有经验的客户而言，这种风险调整后的基准就较难实现。其次，我们是用整体样本区间的数据来计算贝塔值。也就是说，0.73的贝塔值是事后计算出的Martingale贝塔值。在样本初期，我们并不知道Martingale能否通过交易实现该贝塔值。

即使Martingale采用罗索1000指数作为基准（不管贝塔值调整与否），如果上面进行的风险调整是错误的，那又会怎样呢？我们知道除了股票市场以外，还有许多其他的风险因子（参见第7章）：动态因子如价值一成长、动量、信用以及波动率风险因子等。或许我们也应该按这些因子进行调整？在第3节我们将根据更广泛的多种风险来源进行风险调整。
