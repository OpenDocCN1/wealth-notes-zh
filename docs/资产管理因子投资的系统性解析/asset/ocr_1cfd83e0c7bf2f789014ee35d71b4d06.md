模型（CAPM）的正确之处在于其认为市场组合得到了较好的多元分散化；实际上，市场组合是投资者能以被动方式构建的最多元分散化的组合。

如果你不同于平均投资者，那么对你来说最优的不是按市场权重持有组合。你会如何偏离市场取决于你的投资者特征。重要的问题是： “你如何不同于平均投资者？”你是像挪威基金一样，有比一般投资者更长的投资期吗？你会因为需要满足固定的债务支出需求而害怕高波动时期吗？市场崩盘时，你会由于收入与市场表现直接相关而感到焦虑担忧吗，因为你的金融财富流失伴随着你的失业从而让你遭受双重打击？

每个因子都界定了不同的不景气时期集。投资者应该问的是，比如价值一成长因子所界定的不景气对我来说是不是景气时期吗？如果对我来说是不好的，那么我所遭受的损失是否会小于其他的市场参与者？

因此，在因子配置过程可考虑以下三个步骤。

# （1）我如何不同于平均投资者？

明确你的相对优势。正如“教授的报告”为挪威基金所列举的：a.透明性和长期的投资使命，b.规模大，c.投资期长且没有即时的现金负债，d.基金管理人NBIM有能力，具有较强公共服务意识，并能减少委托投资管理中最具挑战性的代理问题。

明确你的相对劣势。规模对于挪威基金而言是把双刃剑，基金体量大也就意味着小规模的阿尔法机会对于总组合来说效果不明显。如果你是捐赠基金，由于所在的大学需要定期支付薪水，你可能无法承担较大损失（这种情形哈佛发生过，参见第13章）①。或是你倾向于跟随市场潮流，对近期热门股票过于热衷？

# （2）在不景气时期我能承受多少损失？

根据每个因子对不景气时期的定义来评估你的风险承受能力。这实质上就是你对每个因子的风险厌恶程度。如果你是偏风险厌恶型，你将无法承受该因子在不景气时期的任何损失，那么你应该持有与这些因子相反的头寸。也就是说，你可能应该投资成长股而非价值股，或者应买入波动率保护而不是卖出它。

# （3）再平衡！

市场先生在另一个方面也很特别：平均投资者从不做再平衡。如第4章所解释的，对应于低买高卖的再平衡操作者，市场上总有人作为交易的另一方由于买高卖低
