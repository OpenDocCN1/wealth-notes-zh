方式来表达¹：

E ( rᵢ ) − rₐ = cov ( rⱼ , m ) var ( m ) × var ( m ) E ( m ) = βₑₖ , m × λₘ                         公式（6.8）

其中βₑₖ , m = cov ( rⱼ , m ) / var ( m ) 是该资产相对于SDF的贝塔。公式（6.8）体现了我们之前从CAPM模型中得出的“不景气时期”的直觉逻辑。需要记住的是，m是一个不景气时期指数。资产在不景气时期的收益越高（cov ( rᵢ , m ) 和βₑₖ , m 也越高），那么该资产的预期收益就越低。公式（6.8）中的高贝塔值与“不景气时期”风险的价格相乘，λₘ = − var ( m ) / E ( m ) 是因子风险的倒数，因此带有负号。公式（6.8）直接体现了从CAPM模型得出的结论6的直觉逻辑：资产的cov ( rᵢ , m ) （不景气时期协方差）越高，那么它的风险溢价越低。不景气时期回报较高的资产值得持有，因此这些资产的价格往往较高而预期收益较低。

正如CAPM模型导致资产具有与市场相关的贝塔，公式（6.4）中SDF的多因子也使得资产的风险溢价与多个贝塔相关：

E ( rⱼ ) = rₐ + βₑₓ₁ E ( f₁ ) + βₑₓ₂ E ( f₂ ) + … + βₑₓ E ( fₜ )                 公式（6.9）

其中βₑⱼ , k 是资产i关于因子k的贝塔，E ( fⱼ ) 是因子k的风险溢价。对于宏观因子来说，比如f₁可以是通货膨胀，f₂可以是经济增长。不景气时期具有高通货膨胀时期、低经济增长时期、或两者并行时的显著特点。对可投资的多因子而言，f₁可以是市场组合，f₂可以是一个做多价值股、做空成长股的投资策略。长期来看，价值股表现优于成长股（参见第7章）。不景气时期具有低市场回报、价值股表现不如成长股，或两者兼有的显著特点。

# ## 4.3  多因子模型结论

事实上，多因子模型的重要结论与CAPM模型是一致的：

|  | CAPM（市场因子）模型 | 多因子模型 |
| --- | --- | --- |
| 结论1 | 多元分散化投资是有效的，市场组合通过多元分散化投资能消除非系统性风险 | 多元分散化投资是有效的，可交易因子通过多元分散化投资能消除非系统性风险 |
| 结论2 | 每个投资者都有其相对于市场组合的最优敞口 | 每个投资者对不同的因子风险都有其最优敞口 |
| 结论3 | 平均投资者持有市场组合 | 平均投资者持有市场组合 |

¹） 可参考例如Cochrane（2001）中的直接推导。
