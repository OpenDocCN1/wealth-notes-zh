# 2.3 更精细的收益分解

风险管理人员通常会深度挖掘资产类别内部或持仓头寸层面的数据，以更精细的方法进行收益分解 $ ^{\text {①}} $（正如公式（14.1）所示的那样通过加减推导而来）。在上述分解中，资产配置决策是基金做出的最重要决策。

还可将基金总收益分解为基准收益、基准中资产类别的择时部分（被称为战术资产配置）、各资产类别内部的选股部分（被称为证券选择），可用以下公式表述：

$ r _ { f } = r _ { 基准 } + r _ { 择时 } + r _ { 证券选择 } $ 公式 (14.3)

① 也可参见Karnosky and Singer（1994）和Lo（2008）。
