# 3.3 长期风险

我们从数据中看到，实际消费增长的自相关性接近零。例如，表8.1中的数据展示出的季度自相关性为0.08。基本的Mehta-Prescott模型假设消费冲击是独立同分布的（independent and identically distribution，简称i.i.d），或者说是无法预测的。在一篇具有影响力的文章中，Bansal和Yaron（2004）更改了这个假设，具体指出消费增长的均值不是恒定的，而是非常缓慢地上下游离以至于很难区分i.i.d过程与这种缓慢而持续、可预测性很小的过程¹。这种变化的消费过程被Bansal和Yaron称为长期风险²。Bansal和Yaron还修改了Mehta-Prescott模型中的基本CRRA偏好，使得代表性参与者更在意长期风险³。Bansal-Yaron长期风险模型被调整应用到不同的情境中，解释了很多种典型化事实，包括本节的股票溢价之谜和无风险利率之谜⁴。

本书撰写之时，欧洲正是长期风险之说的极好例子。比如，某个欧元区国家的一场沸沸扬扬的议会投票所带来的当前冲击，会对我们现在对未来经济增长的预期产生影响，但同时也会对未来十到二十年的经济增长产生影响。这个投票可能会削弱现在的生产率，而降低现在的生产率则可能会让欧洲长时间处于低增长通道。长期风险是存在的。Bansal和Yaron采用的特殊偏好区分了这些冲击的短期和长期效果。股票对长期风险尤为敏感，这并不奇怪，因为股票是一种长期存在的（事实上，永续存在的）证券。
