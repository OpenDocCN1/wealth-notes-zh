# 3. 委托组合管理

现在我们来对委托组合管理中特定的一系列代理问题进行讨论。

资产管理领域普遍存在多种委托代理问题，许多问题之间还相互冲突。我们来考虑图15.1中归纳的NYSCRF所涉及的委托代理关系。关系（1）中，审计长是该基金的唯一受托人，因此是受益人（即资产所有者）的代理人。审计长负责在关系（2）中监管内部基金经理和选聘外部基金管理人，这些代理人往往比审计长掌握更好的信息（逆向选择），并且审计长无法用100%的时间来观察他们管理基金的努力程度（道德风险）。审计长得到咨询顾问的帮助，但这又增加了另一层代理维度——作为委托人的审计长与作为代理人的咨询顾问的关系（3）。关系（4）中，咨询顾问本身在与基金管理人打交道时可能是委托人，比如那些被雇佣来寻找和筛选一流基金管理人的咨询顾问。
