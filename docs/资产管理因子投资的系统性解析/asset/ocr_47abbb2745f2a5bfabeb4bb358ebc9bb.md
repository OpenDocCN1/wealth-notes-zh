# 负债驱动型投资 （Liability-Driven Investment ）

应该如何管理养老基金呢？显然应通过管理基金来满足其债务偿付要求。Martin Leibowitz，时任所罗门兄弟公司（Salomon Brothers）的分析师，在1986年提出了负债 驱动型投资框架①。在这一框架下，养老基金经理应该对盈余（即养老基金的资产与 负债之间的差额）进行管理，并在给定风险水平下最大化盈余回报②。在这一优化过程 中所引入的风险规避可以反映出受益人和公司二者中的一方或者双方不愿承担风险③。

然而知易行难。精算师用不同的方法计算养老金负债：最常见的两个指标是累积 给付义务（Accumulated Benefit Obligation，以下简称ABO）和预计给付义务（Projected Benefit Obligation，以下简称PBO）。ABO是根据公司员工和退休人员当前的工资福利 水平计算的价值。这是假设公司立即关闭时公司所应承担的契约责任。然而，健康 的公司会持续运营，所以PBO还考虑了现有员工未来的预期工资水平（因此PBO大于 ABO）。但即使是PBO，也是不全面的：公司随着时间的推移不断成长，而PBO没有 考虑未来新员工的退休福利。ERISA采用ABO来衡量负债。而真实的经济负债评估结 果很可能甚至超过PBO。
