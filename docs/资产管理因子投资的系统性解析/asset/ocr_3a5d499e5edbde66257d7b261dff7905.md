# 5.1 家族变迁

对于家族或个人财富而言，最大的风险就是Vanderbilt家族所经历的情况：子孙后代挥霍无度。富有的家族和主权财富基金实际上在许多方面相似：主要目的是避免现在就花光所有的钱，能够实现财富跨代传承。要做到这一点，两者都需要建立健全的治理结构，以确保他们能够有条不紊地开支。通常情况下，家族在财富保值方面表现糟糕：70%的家族财富仅传承了两代人就挥霍一空，极其类似于发生在Vanderbilt家族的情况${}^{②}$。

富有家族中存在的以下问题会让他们的财富不复存在。

（1）家族内斗

托尔斯泰（Tolstoy）一语中的，他说：“所有幸福的家庭都是相似的；不幸的家庭各有各的不幸。”争吵不休的家族成员无法决定家族企业该如何管理业务或明确适合家族办公室的投资风格。在最坏的情况下，家族成员在法庭上争吵，将大笔的钱浪费在无谓的法律费用上。有钱人应该关注继任计划，并教导子女如何对待、照看和管理财富。投资高净值人群的财富需要心理学和金融学相结合${}^{③}$。

（2）裙带关系

家族富裕并不意味着应该由家族成员来管理家族资产。由专业人士来管理他们的企业、基金会和财富其实对于整个家族而言会更好。而家族成员可能是（但很可能不是）经营管理的最佳人选。Pérez-González（2006）以及Bennedsen等（2007）得出令人信服的结论，即由家族成员进行管理会不利于家族企业的发展；由外部引入的首席执行官（以下简称CEO）通常比由家族下一代继承者担任的CEO表现要好得多。但许多家族不愿意聘请外部人士。即使是创始CEOs常常也会把持着权力不放，尽管后期
