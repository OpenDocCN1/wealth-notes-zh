时都收取，监管费用则为0.4%左右${}^{1}$。

业界设置管理费的方式引发了很多激励问题${}^{2}$。管理费通常是以公司的资产价值作为基础，而非所有权益价值。这会促使PE基金背负更多债务来增加公司资产，从而最大化费用。GP也会更偏向于将公司拆分成很多小份，因为这样他们能从多个小份而不是一个整体公司中赚取更多费用。这些费用是基于交易的，而非基于价值增值的事实，会驱使GP对公司做出尽可能多的改变，而非最优的改变；GP对公司做出的每个资本结构改变都能增加其费用报酬。

在私募股权投资中，总费用数目的披露情况并不理想。Philippou（2009）发现只有25%的私募基金在业绩报告中公布其扣除所有费用后的业绩，而它们往往是业绩最为出色的基金。

# 补充协议

有些投资者会收到补充协议（side letters），即标准合同（所有投资者都会收到标准合同）之外的附加协议。补充协议能给一些投资者更有利的条款、费用抵消以及其他条件。幸运的投资者获得“最惠国”待遇，表明没有其他投资者可享受到更优待遇。毫无疑问，与PE公司保持持久的业务关系，或提供大量的承诺资金，就意味着能得到更有利的补充协议。

# 4.2 费用，费用，还是费用！

PE的费用非常高。
