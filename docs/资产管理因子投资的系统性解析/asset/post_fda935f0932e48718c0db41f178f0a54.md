
# 4.2 定价核与贴现率模型对比

其中任一K因子都界定了不同的不景气时期。

采用定价核m的另一个优势在于，尽管CAPM模型将m限定为线性的，但在现实中往往是非线性的。我们希望构建模型来揭示这种非线性关系①。研究人员开发了一些复杂形式的m，我们在第8章关于股票和第9章关于债券所讨论的部分重点模型也是非线性的。

下文阐述了这些定价核是如何发挥作用的。在传统的CAPM贴现率模型中，我们通过将未来收益贴现到今天来得到资产i的价格：

$$P_i=E\left[\frac{\text{payoff}_i}{1+E(r_f)}\right] \text{公式}(6.5)$$

其中贴现率是根据CAPM模型的$E(r_i)=r_f+\beta_i(E(r_m)-r_f)$给出。在SDF模型中，我们可以采用m符号将资产价格等额地表述为②：

$$P_i=E[m \times \text{payoff}_i] \text{公式}(6.6)$$

从而有了“随机贴现因子”的名字，因为我们在公式(6.6)中采用m来对收益贴现，正如我们在传统贴现公式(6.5)中采用贴现率对未来收益进行贴现。SDF被称为定价核，在此借用了统计学中的“内核”一词，因为人们可以用核估计量来估计公式(6.6)中的m。由于这是对所有的资产定价的内核，因此被称为“定价核”。概率和统计学的学生会意识到公式(6.6)中的价格是关于定价核的期望值，因此SDF也被称为“状态价格密度”(state price density)。

我们对公式(6.6)左右两边分别除以资产现价$P_i$，得到：

$\begin{array}{ll} \frac{P_i}{P_i}=E\left[m \times \frac{\text{payoff}_i}{P_i}\right] & \text{公式}(6.7) \\ 1=E\left[m \times(1+r_i)\right] & \end{array}$

当未来收益恒定时，公式(6.7)就会出现特例，即得到无风险资产，所以无风险债券的价格可简单表述为$1/(1+r_f)=E[m \times 1]$。

于是，我们能将某一资产的风险溢价j采用类似于公式(6.2)中CAPM模型的SML方式来表达¹：

$$E ( r_j ) - r_f = \frac{\text{cov} ( r_j , m )}{\text{var} ( m )} \times \frac{\text{var} ( m )}{E ( m )} = \beta_{j,m} \times \lambda_m \quad \text{公式}(6.8)$$

其中$\beta_{j,m} = \text{cov} ( r_j , m ) / \text{var} ( m )$是该资产相对于SDF的贝塔。公式（6.8）体现了我们之前从CAPM模型中得出的“不景气时期”的直觉逻辑。需要记住的是，m是一个不景气时期指数。资产在不景气时期的收益越高（$\text{cov} ( r_i , m )$ 和$\beta_{j,m}$ 也越高），那么该资产的预期收益就越低。公式（6.8）中的高贝塔值与“不景气时期”风险的价格相乘，$\lambda_m = - \text{var} ( m ) / E ( m )$ 是因子风险的倒数，因此带有负号。公式（6.8）直接体现了从CAPM模型得出的结论6的直觉逻辑：资产的$\text{cov} ( r_i , m )$（不景气时期协方差）越高，那么它的风险溢价越低。不景气时期回报较高的资产值得持有，因此这些资产的价格往往较高而预期收益较低。

正如CAPM模型导致资产具有与市场相关的贝塔，公式（6.4）中SDF的多因子也使得资产的风险溢价与多个贝塔相关：

$$E ( r_j ) = r_f + \beta_{j,1} E ( f_1 ) + \beta_{j,2} E ( f_2 ) + \dots + \beta_{j,k} E ( f_k ) \quad \text{公式}(6.9)$$

其中$\beta_{j,k}$是资产j关于因子k的贝塔，$E ( f_k )$ 是因子k的风险溢价。对于宏观因子来说，比如$f_1$可以是通货膨胀，$f_2$可以是经济增长。不景气时期具有高通货膨胀时期、低经济增长时期、或两者并行时的显著特点。对可投资的多因子而言，$f_1$可以是市场组合，$f_2$可以是一个做多价值股、做空成长股的投资策略。长期来看，价值股表现优于成长股（参见第7章）。不景气时期具有低市场回报、价值股表现不如成长股，或两者兼有的显著特点。

### 4.3 多因子模型结论

事实上，多因子模型的重要结论与CAPM模型是一致的：

|  | CAPM（市场因子）模型 | 多因子模型 |
| --- | --- | --- |
| 结论1 | 多元分散化投资是有效的，市场组合通过多元分散化投资能消除非系统性风险 | 多元分散化投资是有效的，可交易因子通过多元分散化投资能消除非系统性风险 |
| 结论2 | 每个投资者都有其相对于市场组合的最优敞口 | 每个投资者对不同的因子风险都有其最优敞口 |
| 结论3 | 平均投资者持有市场组合 | 平均投资者持有市场组合 |
| 结论4 | 市场因子的定价是基于CAPM假设下的均衡状态 | 在无套利或均衡的假设下，各因子都存在风险溢价 |
| 结论5 | 某资产的风险由CAPM模型的贝塔来衡量 | 某资产的风险根据该资产的因子敞口（因子贝塔）来衡量 |
| 结论6 | 能在市场回报较低的不景气时期提供较好收益的资产具有吸引力，这些资产具有低风险溢价 | 能在不景气时期提供较好投资资产的资产具有吸引力，这些资产具有低风险溢价 |

与多因子定价核模型相关的价值64000美元的问题在于（译者注：此处提到的64000美元源于美国1956年非常著名的有奖问答电视节目，作者在此意在强调问题的重要性）：投资者如何界定不景气时期？对于持有市场组合的平均投资者而言，答案是当每增加1美元都变得很有价值时就是不景气时期。这将SDF理解为市场中代表性参与者的边际效用，我们将在第8章阐述股票风险溢价特点时对此做进一步探讨。高边际效用时期是指，比如你刚失业时收入很低，每多一美元对你都很重要。这段时期你的消费也较低。对于有代表性的平均消费者来说，这与宏观因子所界定的不景气时期是对应的：当GDP增长缓慢、消费低迷，或者经济增长整体放缓时均为不景气时期。我们也可以采用相对概念来界定高边际效应时期：比如当你的消费水平低于你邻居或者低于你以前的消费水平时。在第2章中，我们采用攀比效用函数来描述前者，采用习惯效应函数来描述后者。

2008 ~ 2009年金融危机期间，属于波动率高且遭受巨大金融冲击的不景气时期。因此，波动率是一个重要的因子，下一章可以看出波动率高企时很多风险资产表现欠佳。因子还可以是可交易、可投资的，比如流动性好的公开市场资产类别如股票和债券；还包括一些容易复制，能以低成本（到客户层面时往往不再是低成本）、大规模方式执行的投资策略，如价值—成长策略①。

# 5. CAPM模型的缺陷

CAPM模型是基于一些严格的假设前提推导而来。我们有必要对这些假设进行检验，并探讨如果将这些假设条件放宽时会出现什么情形。

## （1）投资者只有金融财富

如本书第一部分所强调的，投资者有其独特的收入流和债务，因此投资者在构建最优组合时需要将这些情况纳入考虑。债务往往是以实际债务来界定——比如说即使价格上涨我们也希望保持一定的生活水准。收入流往往是有风险的，因为在经济增长低迷时收入通常也会减少。这使得通货膨胀、经济增长等变量成为十分重要的因子，因为很多投资者的收入和债务水平都会随着这些宏观变量的改变而相应变化。

此外，还有一个驱动资产收益的尤为重要的因子即人力资本，也称劳动力收入风险②。Jagannathan和Wang（1996）发表了一篇有影响力的论文，指出如果将劳动力收入风险纳入考虑，CAPM模型的表现有较大提升。

## （2）投资者具有均值-方差效用

如第2章所强调的，由于投资者面对损失所承受的压力通常会高于获利时的喜悦，因此更接近现实的效用函数对风险的处理往往是不对称的。所以，我们应该预期能找到偏离CAPM模型的股票，这些股票对下行风险有不同的衡量标准。Ang，Chen和Xing（2006）的研究显示下行风险越大的股票具有越高收益。大量文献表明，其他高阶矩风险如偏度和峰度等也会带来风险溢价③。

## （3）单一投资期

单一投资期本身是个小假设。Merton（1971，1973）的研究将CAPM模型进一步扩展到著名的动态情形。在该研究体系下，CAPM模型在每个单一投资期都成立。

尽管长投资期对CAPM理论来说是个无足轻重的假设，但当我们将组合选择扩展到动态、长期的框架下，长投资期限就具有重要意义。如本书第一部分所阐述的，对长期投资者来说最优策略是再平衡策略（参见第3章）。而持有市场组合的平均投资者，通常不进行再平衡。

## （4）投资者具有同质化的预期

该假设确保所有投资者在CAPM模型中持有相同的MVE组合，在均衡状态下MVE组合成为市场组合。但在现实世界，人们显然并不持有完全一样的观点，而是会有异质化的投资预期。投资者具有同质化的投资预期这一假设本身并不那么重要：如果预期收益是所有投资者预期的简单平均，某种形式的CAPM模型也是成立的①。但将该假设与下一条假设结合起来的，那么异质化的投资预期可以产生明显偏离CAPM模型的结论。

## （5）没有税收或交易成本

税收有重要影响。第12章指出税收会影响预期收益，而且可视为一种系统性因子。同时，不同股票的交易成本也不同。我们可以预期流动性差的市场具有较高的交易成本，可能会与CAPM模型有较大偏离。事实也确实如此，本书第13章对各种流动性溢价展开了深入探讨。

交易成本的另一个影响体现在交易摩擦与异质性投资者相结合时。如果投资者不能做空，那么投资者的观点就十分重要。持乐观态度的投资者对价格影响较大，因为持悲观态度的投资者的观点难以体现在股票价格中：悲观的投资者希望做空股票却不能做空，所以股票价格仅体现了乐观投资者的观点；因此，投资者观点成为了一种系统性因子。Miller（1977）最初基于理性解释提出了上述概念，现在也有从行为学角度对上述情况进行分析。与该假设相关的还有下一条假设，当单个投资者能影响股票价格时，市场很可能流动性欠佳且存在较强的交易摩擦。

## （6）单个投资者都是价格接受者

消息灵通的投资者擅长交易并且能够影响价格，因为他们拥有其他人没有的信息。当交易量很大时，投资者对价格是有影响的。这引出了下一条假设。

## （7）信息是免费的，且所有投资者都能获取

收集和处理信息是有成本的，而且某些信息不是所有投资者都能获取得到。正如Veldkamp（2011）研究指出，在某些经济学框架下，信息本身可以被视为一种因子。CAPM模型适用于模式化、有效的市场；而我们认为在有效性较差的证券市场，尤其是信息获取成本高且大多数投资者难以获取时，投资者能获得额外的风险溢价。事实确实如此，我们将在后续章节对此进一步探讨。那些小市值的股票以及在信息并非公开有效、流动性欠佳的市场中交易的股票对CAPM模型的偏离最为明显。

总的来说，我们认为当CAPM模型背后的假设不成立时，就会产生额外的风险溢价。这包括能对投资者非金融面产生影响的宏观因子、不对称风险所带来的影响、非流动性和交易成本、税收等。我们预期在流动性欠佳、有效性较低的市场会看到CAPM模型的缺陷更为明显。尤其是完美信息的假设，是现代经济学家不再相信市场是有效的（传统CAPM理论认为市场有效）原因之一。

# 6. 有效市场理论的失效

现在，经济学家不再相信完全有效市场①。事实上市场不可能完全有效。市场近有效（market near−efficiency）理论这种现代提法是由Sanford Grossman和Joseph Stiglitz（1980）发展起来的，这也是令Stiglitz获得2001年诺贝尔经济学奖的系列论文之一。Grossman和Stiglitz所描述的世界是一个近有效市场，他们试图解决CAPM模型关于信息成本为零的假设所带来的难题。假设收集信息和交易信息是有成本的、如同在现实世界中一样。那么，如果所有信息已经反映在价格中，谁还愿意投资去获取这些信息呢？如果没人愿意投资去获取信息，那这些信息又如何能反映在股票价格中、市场又如何有效呢？因此，市场不可能是完全有效的。

Grossman和Stiglitz创立了一种市场是近有效的模型。积极管理人不断找寻市场无效带来的机会，而这种活动本身会导致市场越来越有效。在市场无效带来的这些投资机会中，积极管理人获取超额收益，以作为对收集和运用信息所花费成本的补偿。在前面讨论的CAPM假设中，我们可以预期，市场无效带来的机会会存于流动性欠佳、信息传播不畅，以及超额利润难以获取的细分市场，因为这样的交易机会很可能会影响股票价格。至于积极管理人是真的为投资者（而非他们自己）赚取了超额收益，我们将在本书的第三部分集中展开探讨。

Grossman和Stiglitz提出的近有效市场理论与Ross（1976）创立的APT理论下的多因子风险框架相辅相成。Ross的多因子模型指出，积极管理人和套利者驱动着资产的预期收益，使其达到与均衡状态下的风险收益相比匹配的一个值。APT模型中的因子是系统性的因子，或者说是会影响整个经济体的因子，这些因子是投资者希望对冲掉的。从本质上看，这些因子代表的是不能通过套利消除的风险，投资者应该为承担这些风险而获得补偿。

尽管现代观点认为市场并非完全有效，但仍有大量文献试图验证有效市场假说（Efficient Market Hypothesis, EMH）。有效市场假说意味着，由于投机交易都是有成本的，积极管理总体是亏钱的，且投资者无法战胜市场①。有效市场假说给了我们一个很高的基准：如果我们是平均投资者，那么我们持有市场组合，由于节约了交易成本使得我们的业绩居于前列。即使我们知道市场不可能完全有效，对有效市场假说进行检验仍然十分重要，因为这能帮助投资者估计他们能从何处获取超额收益。在Grossman–Stiglitz的研究框架下，聪明的投资者能辨别市场无效所带来的机会，从而正确引导积极投资管理。

市场有效假说在过去几十年不断改善，以修正CAPM模型最初的许多缺陷，包括信息不完全，交易、融资和代理都有成本等改进。许多行为偏差也有类似效果，而且有些摩擦确实被认为是行为偏差。Ang，Goetzmann和Schaefler（2011）对市场有效假说检验进行了综述。与我们讨论相关的是，对市场有效性的偏离有两种形式：理性学派和行为学派。对于资产所有者而言，需要厘清哪种形式更占上风很重要，以决定是否投资市场无效所带来的某个特定机会。

理性解释认为，高收益是用于补偿投资者在不景气时期所遭受的损失。这是以定价核的方式来进行资产定价。重点在于如何界定这些不景气时期，并明确其对单个投资者来说是否是真正的不景气。比如说有的投资者受益于经济增长放缓，尽管这对大多数投资者来说是不景气时期。在理性学派的解释框架下，这些风险溢价会持续存在，除非整体经济发生很大的结构性变化（这种情况鲜少发生，2008–2009年的金融危机并不算结构性变化）。此外，这些风险溢价的规模较大，适用于大型资产所有者。

行为学解释认为，高预期收益源于市场参与者对某些新闻或事件的过度反应或反应不足。行为偏差也可以是源于对某些信息的疏忽，或对某些观点的不及时更新等。完全理性的投资者不会有这些行为偏差，他们能通过充足的资本来逐渐消除错误定价。接下来的问题在于，资产所有者能多快地赶在其他投资者采取行动之前进行投资。一个更好的投资理由，至少对于行动缓慢的资产所有者而言，就是因为存在资本进入壁垒而导致某种行为偏差的持续存在。有的壁垒可能是结构性的，比如某些投资者无法利用这类投资机会，例如：监管规范要求有的投资者只能持有某些特定类型资产，比如一定信用等级以上的债券，或达到一定市值门槛以上的股票。如果存在结构性进入壁垒，那么这种行为偏差可以长期被利用。

有的风险溢价最适合从理性角度解释、比如波动率风险溢价；有的风险溢价则适合从行为学角度解释，比如动量因子带来的风险溢价；还有的风险溢价适用于两者结合来看，比如价值一成长投资产生的风险溢价。总的来说，投资者并不在乎风险溢价的来源到底是基于理性学派还是行为学派；更恰当的问题是，他是否不同于面临着理性限制或行为学限制的平均投资者，以及收益来源是否预期能在未来（至少在短期）持续存在。我们将在第14章探讨因子投资时对此做详细阐述。

# 7. 关于2008~2009年金融危机的回顾

金融危机时期，许多风险资产的表现都同时不尽人意，这与多因子模型指出的很多资产类别都对相同因子具有风险敞口的说法是一致的。金融危机是典型的不景气时期：波动率很高、危机末期经济增速缓慢，政府和货币政策有很强的不确定性。有些市场的流动性出现枯竭。面对这些因子风险，资产收益表现的共性有力地证实了风险的多因子模型，而不像有些批评者声称的那样否定了金融风险理论。资产获取风险溢价，是为了补偿其隐含的因子风险敞口，在不景气时期，这些因子风险凸显时资产收益表现低迷。但长期来看，资产的风险溢价较高，以弥补不景气时期的低收益。

有些评论者认为2008年金融危机事件表明多元分散化投资已经失效。其实多元分散化投资本身并未失效，但金融危机证明了资产类别的标签具有很强的误导性，导致投资者以为已经通过资产多元化较好地分散了风险而事实上却并非如此。真正重要的是资产所隐含的因子风险，资产本身是由一系列因子风险构成。我们需要理解资产背后的因子风险，正如我们在吃东西的时候需要通过食品名称和口味去了解其背后的营养构成，以确保获取维系我们身体所需要的营养。我们通过承担风险来获取长期的风险溢价，这需要我们了解这些因子风险在短期内会在何时以及如何实现。有人批评采用均值——方差效用函数来进行多元分散化投资的这一方法，该方法假设资产类别的相关性不变，而事实上资产类别的相关性在不景气时期很可能上升¹。因子敞口能够也会随着时间而变化，导致相关性相应变化——这都更需要我们去了解什么是风险溢价的真正因子驱动力。
