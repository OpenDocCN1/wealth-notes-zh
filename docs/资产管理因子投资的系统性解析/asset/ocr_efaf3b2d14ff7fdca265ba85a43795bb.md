# （3）进行政策评价

政府政策对于股票和固定收益市场有一定影响（分别参见第8章和第9章），但是对于房地产，这种影响尤其重要。房地产价格不可能不受监管政策的影响。经济模型可以很好地衡量外部政策变化的效果（通过比较静态（Comparative Statics）分析）。房地产价格的一个极为重要的决定因子是供给。在“超级明星城市”（包括旧金山、波士顿和类似的海滨城市）中，全新的住房和办公室的供给受到监管的严格限制1。由此产生的稀缺性推升了房价。而在亚特兰大，供给侧的限制比较少，因此房地产价格相较于海岸边的城市偏低。政府政策对不同城市的房价有影响，对各个城市中不同区域的房价也有同样重要的影响。在其他条件不变时，当供给政策发生改变，经济模型可以让我们预测到哪些区域会受益或受损，受益或受损的程度是多少。

# 6.1 直接投资或间接投资？

我的分析重点将是，机构投资者的直接房地产投资，以及通过REITs进行的间接房地产投资。REITs是一种类似于共同基金式的投资工具，广泛地持有各种房地产资产。许多REITs都是公开交易的。REITs需要满足很多限制条件：最重要的就是，每年它们须要将至少90%的应纳税收入作为红利分配给持有者。REITs是少有的一种可以让零售个人投资者投资到商业地产市场的工具，于1960年由议会通过房地产投资信托法案而建立。起初，议会并没有意识到允许大众投资商业地产可以带来的分散化收益。REIT法案最初只是一项修改关于雪茄烟征税法的法案的附属品。在房地产行业进行大量游说后，REIT法案获批通过，这样开发商可以通过股票市场募集更多资金2。

由于直接房地产投资和REITs都包含可以产生现金流的建筑和土地，人们可能会认为这两种投资方式回报率的相关度很高3。当然，直接和间接的房地产投资在长期来看都会受到共同的基本面因子驱动。但是，它们的相关度并不高，这被称为REIT之谜（REIT Puzzle）。
