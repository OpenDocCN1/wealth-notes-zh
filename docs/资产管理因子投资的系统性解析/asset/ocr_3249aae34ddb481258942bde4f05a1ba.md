# 1.1 总收益率

我们将从时点 $t$ 到 $t+1$ 的总收益率（gross return）定义为：

总收益率 $R_{t+1} = \frac{P_{t+1} + D_{t+1}}{P_{t}}$ 公式（附1）

其中， $P_{t}$ 为资产在第 $t$ 期初的价格， $P_{t+1}$ 为资产在第 $t$ 期末的价格， $D_{t+1}$ 为 $t+1$ 时点支付的红利。我用大写字母 $R$ 表示总收益率。公式（附1）的定义假定我们可以衡量资产价格——但该假设对于有些流动性较差的资产并不成立。这里我们先假设所有资产都是可交易的；关于非流动性资产的收益率，我在第13章进行了讨论。

财富会随着时间不断积累，我们将每期的总收益率连乘计算复利。假设某个资产在 $t$ 时点价值为1美元，它连续三年每年总收益率为 $R_{i+1} = 1.10$，那么在三年年末它的累计价值为：

$W_{t+3} = R_{t+1}R_{t+2}R_{t+3}$
$= 1.10 \times 1.10 \times 1.10$
$= 1.3310$
