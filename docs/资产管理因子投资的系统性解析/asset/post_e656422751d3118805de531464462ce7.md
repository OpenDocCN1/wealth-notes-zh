# 后记

## 因子管理

发展于20世纪60年代的资本资产定价模型是最早期的因子投资模型，该模型认为市场组合这一因子决定了资产的风险溢价。但在当时，投资者并没有渠道投资于市场因子。市场指数基金直到十年之后才开始出现，它提供给投资者一种以低成本获得整个股票市场风险敞口和赚取股票市场风险溢价的渠道。市场指数基金直到20世纪80年代仍是小众产品，在90年代才真正迅速发展。现在很多投资者能以便宜的价格和最小的代理成本大规模地投资于市场因子。然而，投资于市场组合因子的理论从概念出现到普及历经了二三十年时间。

超越了单纯市场因子的多因子理论于20世纪70年代开始发展。验证因子风险有多种来源的理论发展和大量实证研究出现于80年代和90年代。我们如今正在经历着激动人心的因子投资的发展时期，金融行业的创新带来低成本、可规模化、并能在各种资产类别和区域之间进行多元分散化的因子投资产品。非常便宜的新一代因子指数基金将能让投资者获取多种来源的风险溢价，包括价值相对成长、动量投资、信用风险和波动率风险等。业界的大部分努力主要集中在随着时间变化的非市值加权持仓的动态因子上，也有些努力更进一步地将宏观因子与资产配置联系在一起。

我认为我们在三个领域上还未能达到理论水平：这些领域也正是行业发展能帮助我们实现因子投资全部潜力的领域：

## 识别和管理不景气时期

本书从资产所有者开始着手，讨论了资产所有者的恐惧、欲望、收入的风险性、负债及其对不同来源风险的感知——所有这些因素都界定了该资产所有者持有的不景气时期集合。财富水平较低的时期通常是不景气时期，但不景气时期也包括道德上的义愤、同行和邻居投资表现更好时的妒忌以及财富和消费水平恶化后不能达到习惯水平而带来的痛苦。资产管理的最终目的是构建能够减轻投资者在不景气时期遭受风险的投资组合，同时用不景气时期所承受的痛苦去换取潜在收益。

我们有处理来源于高波动率和低平均收益的不景气时期的快速方法（均值—方差最优化），但总的来说我们用来处理一般种类的不景气时期的定量方法仍不尽人意。这在以下情形中尤其如此：模拟不景气时期在投资者生命周期中如何变化，在长投资期内动态地处理低流动性带来的不景气，纳入随时间而变化的负债，以及考虑对损失和收益的不对称处理方式。我们取得了一些进展，但如果我们能拥有一个标准的商业优化器来帮助我们实现各种效用函数之间的切换（尤其是那些将对下行风险的厌恶纳入考虑的效用函数）并看到对最优组合的影响，那样则会更好。投资者在将一系列不景气时期以及他们如何感知不景气时期风险来与不同的量化投资模型进行匹配这方面需要帮助。

## 因子风险溢价是对不景气时期遭受损失的补偿

因子投资的概念将某一投资者的不景气时期与典型投资者（即市场投资者）的不景气时期相比较。事实上，由于市场组合是严格地被被动做多持有资产，市场投资者并没有捕捉到任何动态因子风险溢价。市场组合也不进行再平衡。我们可以偏离市场权重而持有平均而言能够跑赢大盘的证券组合。这些高收益不是免费就能获得的。因子组合获取风险溢价以补偿投资者在不景气时期所承受的损失。然而，典型投资者的不景气时期对你来说可能并非不景气。如果你能容忍这些损失，这将提供给你一个收获风险溢价的渠道。其他投资者愿意放弃因子敞口是因为他们过于厌恶风险。

我们看到很多创新已实现了定制化非市场权重因子指数、定制化风险敞口的大小，以及更加廉价地创造最优因子组合。这些都是积极的变化。但当资产所有者在不同因子风险之间进行选择和决定风险敞口大小时，他们很少问自己：我与市场之间有什么不同？在理想情况下，咨询顾问、财务顾问和资产管理人应该就不同的不景气时期所对应的因子风险损失提供指导。在我们能说某些因子风险是否适合某个投资者之前，我们应该了解一些解释这些因子风险溢价存在原因的经济学原理——即便是对于基本的股票风险溢价。理解产生风险溢价的经济学理论，将这些理论与各类因子已实现的亏损和盈利相联系，并证明这些风险因子对于某个特定投资者适当与否，这样才是决定投资者应该获取哪些因子以及应该获取多少因子风险敞口的最优方式。

一个有效的批评说我列举了大量因子风险的来源和大量可投资的动态因子溢价，但如何在这个聚宝盆里做出选择？如何理解所有这些因子风险的理论？资产所有者必须通过明确他的信念以及他对不景气时期的界定来决定他应采取的立场。（投资者政策声明或投资理念声明是达成这个目的的理想工具。）然后我们从选择的多个维度将投资者与市场进行对比：投资时间期限、承受风险或损失的能力、负债的水平和性质、劳动收入的可靠性等。从代表平均投资者的市场组合出发，判断你在这些特质方面与市场平均水平有何不同，这将决定你的风险承受能力。投资者应该只选择一个或两个维度来使自己与市场区分开来，将自己的比较优势和劣势转化到风险因子敞口上。风险敞口未必都是正向的——在波动率急剧上升时，对我们更好的做法或许应该是支付波动率保险费用来购买保护，而不是收取小额的波动率保险费并在波动率飙升时遭受惨重损失。

### 投资者拥有资产所有权

代理问题是资产管理行业的重要和中心问题。我们不希望由于功能失调的委托代理关系而给投资者带来更多的不景气时期。在这方面，业界和学术界都还可以作出更多努力以增加资产所有者的福利。业界的投资工具经常给予资产所有者不公正的待遇。例如在很多对冲基金和私募股权的合同中，资产所有者对他们的资金仅有很少或者根本没有控制，信息披露很差，代理人没有什么动力去为资产所有者的最大利益行事。学术研究者可以通过对最优合同提出建议和为资产管理机构找出最优控制和治理机制来作出更多贡献。

因子投资将会对此有所帮助。因子基准能改善代理问题。当损失是由于因子表现不佳所导致时，他们不会惩罚表现不佳的基金管理人。从资产所有者的角度来看，因子提高了积极管理的门槛。投资界是有人才的，我们希望能够辨别出那些确实具有技能的投资人员并对其进行丰厚奖励。但是，这样的人才应该能在通过其他低成本方式获取因子风险敞口的基础上产生超额收益。

目前，多头被动因子基准在行业中占主导。低成本因子组合的出现应该能够加快为每个投资者所定制的动态因子基准的采纳进程。如果我们能够以低成本方式获得因子风险敞口，那么我们就能去除昂贵的积极管理中并非真正应该收取的那部分费用。

资产管理实际上不是对资产的管理，而是对因子的管理。
