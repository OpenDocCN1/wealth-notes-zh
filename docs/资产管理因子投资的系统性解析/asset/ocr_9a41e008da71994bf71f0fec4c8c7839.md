# 1. 东帝汶

东帝汶民主共和国是一个地处东南亚、拥有一百万人口的小国$^{①}$。它位于澳大利亚的西北部，领土包括帝汶岛的东半部及西部一处“飞地”（指在某一国境内隶属于另一个国家的领土）。帝汶岛的其余部分归属于印度尼西亚。

如今的东帝汶在16世纪时曾沦为葡萄牙的殖民地，殖民者向当地传入了天主教和咖啡。时至今日，天主教在东帝汶宗教体系中仍旧占据着主导地位，而在当地生产力水平不高的农业经济中，咖啡已成为支柱性产业。第二次世界大战期间，澳大利亚人和荷兰人曾登陆东帝汶，与日本人作战。东帝汶在此期间遭受了毁灭性的打击，后来葡萄牙恢复了对东帝汶的殖民地位，在其统治下东帝汶缓慢复苏。

当葡萄牙人开始从其海外殖民地撤离时，东帝汶爆发了内战。1975年11月，主张独立的东帝汶独立革命阵线（the Revolutiory Front for an Independent East Timor，简称革阵）宣布东帝汶独立。之后不到一个月，出于对这个在家门口冒出来的马克思主义国家的担心以及在冷战期间西方政府的支持下，印度尼西亚出兵东帝汶并于1976年7月宣布东帝汶为其第27个省。

在被印度尼西亚占领期间，东帝汶局势十分残酷。大约20万东帝汶民众因战争、疾病或饥荒而丧生。两位东帝汶领袖人天主教主教卡洛斯。菲利普。西门内斯。贝洛（Bishop Carlos Filipe Ximenes Belo）和何塞。拉莫斯。霍塔（José Ramos-Horta），于1996年被授予诺贝尔和平奖，这引发了世人对印度尼西亚践踏东帝汶人权行为的关注。在1998年印度尼西亚总统苏哈托（Suharto）被迫下台后，他的继任者同意东帝汶通过全民公决的方式选择是否自治$^{②}$。结果80%的选民投票赞成自治，2002年5月20日
