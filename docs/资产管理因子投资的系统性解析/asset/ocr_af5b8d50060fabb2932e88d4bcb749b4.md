# 规模较大的共同基金表现更差

规模较大的共同基金比规模较小的共同基金差，因此存在规模不经济$^{①}$。当一支基金变得更大，建立较大的股票仓位就变得更加困难。很多获取超额收益的机会集中在市场上流动性较差的部分。好的投资因此往往难以规模化。的确，当规模大的基金持有更多的流动性较差的股票时，业绩表现受到阻碍，规模较大的基金也需要雇佣更多的分析师，使得协调起来更困难。有更多的雇员之后，信息在机构内的传导更加困难，根据信息采取行动也更加困难。（在经济学上，这些成本称为层级成本hierarchycosts）$^{②}$。

# 收费越高的基金表现越差

对于多数行业，都是一分钱一分货。你在第五大道Saks百货公司花的钱比在廉价商店多，因为你得到了更好质量的商品。你在米其林三星饭店吃饭花的钱比在麦当劳多，但你在优雅的环境中品尝了更加美味的一餐。在诸多领域，你花的钱越多，得到的就越多。但在共同基金行业，刚刚相反，你付的费用越高，你得到的就越少$^{③}$。Carhart（1997）研究发现，你付给共同基金的费用越高，收益越低。投资者最好是投资于低费率基金。Gruber（1996）发现表现最好的基金收费比表现最差的基金收费低。那么哪些是收费最低、同时正好持续地跑赢了超过半数的积极型基金呢？答案是指数基金。

# 3.3 持续性
