再平衡方式导致超过单日的收益率与标的指数的收益率出现偏差。假设你对标的指数相同的一支传统基金和一支虚构的“三倍杠杆基金”分别投资100美元。指数上涨10%。传统基金净值达到110美元，三倍杠杆基金增长了30%净值达到130美元。杠杆交易所交易基金每日进行再平衡。现在假设在第二天，指数下跌10%。传统基金下跌为（1-0.1）×110 = $99。杠杆交易所交易基金的回报率为（1-0.3）×130 = $91。在两天之后，指数收益为99/100 -1 = -1%。相对而言，三倍杠杆基金的收益率为91/100 - 1 = -9%。这与两天之中指数收益率-1%的三倍相去甚远，与一般投资者根据基金名称所预期的收益也很不一样。在多日重复这个过程之后，实际收益与预期收益可能出现巨大的偏差$^①$。

图16.9绘制了标普500, Direccion Daily 标普500 Bear 3X和Direccion Daily 标普500 Bull 3X的收益情况。按照设计，两支交易所交易基金分别对标普500指数持有三倍的空头和多头仓位。图16.9绘制了在2012年1月1日至2012年12月31日，分别对三个产品进行1美元的投资的累计收益情况。标普500的收益率为-11.8%。Bear 3X基金的收益率为74.6%，超过标普500指数收益的6倍。Bull 3X基金的收益率为-31.6%，是标普500指数收益的2.6倍。这些回报率与根据基金名称所预期的“三倍”有很大差距。
