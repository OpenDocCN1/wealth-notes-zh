# 图14.3

对于图14.3-D，我会问2008 ~ 2009年期间的负积极收益是否能被预期到。该问题不同于问上述负积极收益是否能被完美地预测到（诺贝尔奖得主物理学家Nils Bohr说过“预测是很难的，尤其是对未来的预测”）。图中的圆点表示基金每个月的实际积极收益，实线表示能被因子敞口所解释的积极收益。图中有两条线：一条是跨整个样本期问的因子敞口估计，另一条是采用滚动窗口估计。后者每月更新因子敞口，并且仅采用当时的可用信息。很明显，这两条线基本相合①。两条线都解释了实际积极收

① 有意思的是，采用扩展窗口的估计值预测2008年9月的损失远远大于实际发生的损失。这与NBM通过改变内部或外部投资策略来管理随时间变化的因子敞口的技能是一致的。
