# 将非流动性资产再平衡至长期平均持有头寸以下

由于低频交易的存在，非流动性资产财富可以发生很大变化并且是右偏的。假设当流动性事件发生时，非流动性资产的最优持有比例为0.2，那么投资者很容易预期在非再平衡期间，非流动性资产的持有比例会在0.1~0.35之间变动。正是因为这种右偏态，可以说非流动性资产的平均持有比例是0.25，高于再平衡后的最优持有比例。这意味着非流动性资产的最优交易点低于长期平均持有水平。
