为主权财富基金，二者之间界限模糊。澳大利亚及新西兰的主权财富基金是专门设立用来满足国家未来养老金负债的需求，它们欣然接受了主权财富基金的称呼。而另一方面，加拿大养老金计划（Canada Pension Plan）则煞费苦心地为释为为什么它不应该被称为主权财富基金①。

目前有四种类型的养老储蓄：

+   ① 国家养老计划，例如社会保障；

+   ② 私营固定收益计划（defined benefit plan），即私营企业承诺受益人可以在未来收到一定的或预定的收益；

+   ③ 私营固定缴纳计划（defined contribution plan），即按照预定的金额缴纳，但未来收到的收益金额不固定；

+   ④ 私人管理的基金，这在美国包括个人退休账户（IRA）、自雇人员退休金计划（Keogh）和401(k)计划等，可以享受税收优惠但对缴纳有严格限制（参见第12章）。

经济学家在谈及养老保险制度设计时，通常会提到多层次、多支柱的概念②。社会保障是第一支柱，旨在为绝大多数公民提供最低限度的保障。第二支柱则包括与工作有关的退休金，包括上述第②项和第③项，在美国这两项构成了人们退休储蓄的很大一部分。第三支柱是个人自愿储蓄，即上述的第④项、同时还包括没有税收优惠的其他退休储蓄。当然现在还有第四支柱：当退休储蓄不足以维持生计时，连老奶奶恐怕也不得不重返职场。

# 3.1 固定收益计划与固定缴纳计划

根据固定收益计划，雇主会根据雇员的年龄、工作年限、现在及过去的工资水平来支付退休收益。因此，退休收益已经被明确规定。退休时支付收益的常见计算方法是“收益系数×三年期限内的最高平均薪酬×任职期限”，其中收益系数可能会随着年龄增长而增加。例如，美国最大的养老金计划——加州公务员退休基金（California Public Employees' Retirement System, CalPERS）规定教师在55岁退休时收益系数等于2%。对于年满63岁的教师，收益系数会增至2.5%。由于雇员在退休时的福利金额是可以预测的，雇主（在多数情形下）会承担投资风险。
