# 1. 罗德岛州的员工退休体系

罗德岛与普洛威顿斯庄园州（The State of Rhode Island and Providence Plantations），简称罗德岛州（Rhode Island），是美国50个州中面积最小的$^{①}$。尽管夹在马萨诸塞州和康涅狄格州两个大州之间使它显得有些黯然失色，罗德岛州人（只有略超过一百万的居民）却有着敢想敢做且敢为人先的美誉。罗德岛州是13个殖民地中第一个从大不列颠帝国统治下宣告独立的——1776年5月4日，比其他殖民地早两个月。当林肯总统要求各州派兵参加内战时，罗德岛州也是第一个积极响应州。在2011年，罗德岛州又是第一个完成公共养老金体系改革的州。

罗德岛州的员工退休体系（Employees' Retirement System of Rhode Island，ERSRI）为包括公务员、教师、法官、地方行政人员如警察或消防员等在内的公共雇员提供退休金、残疾补助金和遗属抚恤金。与美国大部分公共养老金一样，它也面临着严重的资金短缺问题。2011年ERSRI的资金比率（funding ratio）仅为59%，只有63亿美元的资产却要偿付108亿美元的负债。罗德岛州的每个人需要支付4230美元来弥补这个缺口$^{②}$。此外，养老金的花费还挤占了其他公共服务开支。2002年，每个纳税人缴纳的每1美元中有3美分流向了养老金。在2009年这个比例上升到了9美分，2018年预计会达到20美分$^{③}$。但与此同时，州雇员的养老金缴款比例仍维持在8.75%，教师的养老金缴款比例仍是9.5%。
