# 4.2 通用汽车（GM）资产管理公司

动态因子涉及交易，因此最小化成本和换手率是构建因子基准至关重要的部分。大型投资者都已构建和交易其定制化的因子组合。

GM资产管理公司是其母公司养老金计划的基金管理人，其针对价值和动量因子构建了公司内部的动态因子组合 1。GM资产管理公司的全球公开市场业务总监James Scott（2012）说，他们的方法与“Ang, Goetzmann和Schaefer（2009）所建议的在养老金总层面管理阿尔法和风险以及进行盈余计划管理是一致的”。

GM资产管理公司从机构投资者的可投资范围出发。他们不做任何成长股或表现不佳的股票——与市场权重相比，他们低配这些股票，或持有零头寸。他们采用账面价值/价格（Book/Price）、预期盈利/价格（Forward Earning/Price）、价格/销售额（Price/Sales）、过去12个月盈利/价格（Trailing Earnings/Price）以及过去12个月现金流/价格（Trailing Cash Flow/Price）的平均值来衡量基本价值。他们将动量定义为过去12个月的收益（遵循学术界的标准做法，剔除最近的一个月以避免反转效应）。组合按月度进行再平衡，并试图保持低换手率。因子组合只有少量的价值和动量敞口，这表明GM资产管理公司期望仅获取少量的因子敞口（他们的跟踪误差限制很严格）。他们构建了美国价值和美国动量组合，以及国际价值和国际动量组合。

GM资产管理公司采用这些内部因子组合作为其股票管理人的基准。管理人需要证明他们能创造除了从因子基准被动获取的收益以外的超额收益。他们运用下述回归公式来评价管理人：

```
$ r_{active} = r - r_{mkt} = b_0 + b_1r_{mkt} + b_2r_{size} + b_3r_{value - growth} + b_4r_{momentum} + \varepsilon $ 公式 (14.6)
```

$r_{mkt}$ 是标准的市值加权基准，$r_{size}$ 代表规模效应（采用Russell 2000减去Russell 1000的差值），$r_{value - growth}$ 和 $r_{momentum}$ 分别代表其内部界定的价值一成长因子组合和动量因子组合的收益。系数$b_1$ 到$b_4$表示因子敞口，这样管理人的积极收益就包括真正的阿尔法$b_0$再加上由于市场、规模、价值一成长和动量敞口变动所带来的收益。
