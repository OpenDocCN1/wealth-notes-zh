两只不同的股票，可能由于不同的管理者和运营的原因，价格出现较大的差异。但是对于两个不同期限的无风险债券，它们的价格不可能出现较大的背离。这是因为这些债券的现金流是无风险的，它们的唯一差异只是期限不同。债券市场中充满了众多套利者，一旦相似期限债券的价格之间出现些许差异，他们会迅速抓住哪怕是非常微小的机会进行套利操作。债券市场尽管可能存在非常有限的套利机会（即使是象牙塔里的学者也没人相信市场是完全有效的；参见第6章），但是债券价格通常紧跟着其他债券一同变化，否则，当套利机会变大时，聪明的投资者就会像“打地鼠”游戏一样迅速用“大木槌”打掉这些机会。我们通过多种模型来解释这种现象，其中投资者获得的回报是与其持有债券的风险相匹配的，并且作为一个近似处理，我们假设债券价格会挤出所有套利机会。这些模型被称为期限结构模型（Term Structure Models）。这一类模型的关键点就是，不同期限的债券收益率在不同时点都是相互关联的。

以两年期美国国债为例，如果我们有两年的投资期，我们可以直接去买两年期国债；我们也可以去买三个月短期国债，三个月之后把所有本息再用于购买新的三个月短期国债，这样我们还需要连续滚动操作7次。这两种方法的区别在于，如果是购买一系列的短期国债，我们会面临展期风险，而如果购买两年期国债的话，我们现在就能得到确定的收益率。不过，三个月短期国债的价格并不可能过多地偏离两年期国债的价格。如果展期策略相比于直接购买两年期国债明显便宜的话，套利者便会买入短期国债，卖出两年期国债。相反的，如果短期国债明显偏贵，他们便会卖出短期国债，买入两年期国债。按照这个逻辑，任何长期债券的价格一定是与短期债券的价格密切相联的。

# 风险溢价

我们可以将长期债券收益率的变化分解为两部分：一部分是纯粹的“预期假设”，另一部分是风险溢价。根据20世纪早期最伟大的经济学家之一-Irving Fisher（1896）的预期假设理论（Expectations Hypothesis），

> 名义长期收益率 = $\frac{\text{预期短期收益率的平均值} + \text{风险溢价}}{\text{这部分称为预期假设}}$ 公式（9.2）

如果我们将三个月短期国债的收益率看作短期收益率，那么两年期国债的收益率应该是连续8个三个月短期国债收益率的平均值：当前的三个月短期国债收益率，3个月以后的三个月短期国债收益率，6个月以后的三个月短期国债收益率，以此类推。
