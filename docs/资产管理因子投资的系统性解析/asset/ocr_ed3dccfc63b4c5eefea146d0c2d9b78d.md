Huang（2008）的主要成果在于她能够计算出税收影响下的最优配置，而行业模型中这样做的几乎没有（或者即使做了也极少做对）。更何况Huang仅通过运用一个应税账户就完成了相关计算。她认为税收递延的回报可以转换为应纳税的回报。在税收递延账户中持有资产等同于在应税账户中持有加杠杆后的同一资产。我们已在公式（12.6）看到这一点：投入到养老基金的税前1美元相当于应税账户中的1.66美元（1/（1-0.396））。应税投资组合相当于在税收递延组合上加杠杆，从而产生相同的回报。投资者在税收递延账户所做的任何事情，都可以在其应税账户中予以撤销（或重复完成）。

Huang的做法是计算等值的应税财富，先加总应税账户中的所有财富即\(W^T\)，然后将所有税收递延的财富即\(W^D\)，转换为等值的应税财富。她将总财富即\(W\)，重新定义为二者之和：

```
\(W = W^T + Z \times W^D \) 
公式（12.8）
```

其中Z是将税收递延的财富转换成等值的应税财富的合理系数。遗憾的是，最流行的业界做法并没有在计算最优配置时按照公式（12.8）考虑等值的应税财富。

Merton（1971，1973）提出的标准解决方案可以适用于总财富（\(W\)），这在第4章中有过介绍。资产配置问题和资产定位问题可以分开决策。这归功于适当的调整系数（\(Z\)），能实现税收递延财富与应税财富之间的转换。因此，需要根据税收递延的影响对资产配置进行调整。

Huang分析的关键点在于能够在应税账户中卖空。中小投资者无法做到这一点，但成熟的大型投资者完全可以。如果投资者不能在应税账户中运用杠杆，那么投资者会更愿意在税收递延账户中持有税率低的资产，从而降低可享受的税收优惠的波动性。Huang的基本分析也没有考虑Constantinides关于税收时机选择的影响。其实这是可以纳入Huang的分析中。我们可以对公式（12.8）中将应税财富转换为税收递延财富的系数Z加以修改，结合税收选择带来的好处，调整后的系数Z体现的是实际税率，而非法定税率。从理论上讲，所有这些影响均可以纳入Huang的分析框架。但缺点是在实践中可能很难计算出系数Z。
