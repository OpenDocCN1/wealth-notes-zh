# CAPM

CAPM模型能较好地说明这一过程如何实现²。根据CAPM模型，投资者应该持有市场组合和无风险短期国债，如图14.6所示。将短期国债和市场组合的不同组合方式画出来就可以得到资本配置线（CAL），短期国债头寸可由y轴的截距表示，市场组合则由图中的圆点所示。投资者持有资本配置线上的组合。有一个特别的投资者会持有100%的市场组合（即市场先生）。如果投资者比市场的风险厌恶程度更高，那么投资者会持有低于100%的市场组合，即持有CAL线上位于市场组合左侧的组合。如果投资者比市场的风险厌恶程度更低，那么投资者会对市场组合加杠杆，并做空短期国债。这种情况下，投资者组合将位于CAL线上市场组合的右侧。
