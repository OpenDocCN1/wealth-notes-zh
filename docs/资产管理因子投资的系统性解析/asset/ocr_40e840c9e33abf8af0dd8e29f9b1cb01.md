第一，政策制定者们使用了错误的模型。在20世纪60年代时，经济学家们都普遍认同Phillips（1958）中的菲利普斯曲线，它描绘了失业率和通货膨胀率之间的反向关系。经济学家们认为，通货膨胀率上升时，失业率就会下降，但是随着时间推移，人们意识到这种反向关系并不总是成立。在20世纪六七十年代，失业率和通货膨胀率同时上升。弗里德曼和卢卡斯（他们在1976年和1995年分别获得诺贝尔经济学奖）在20世纪70年代引领的经济学“理性预期革命”认为，菲利普斯曲线是不稳定的，政策制定者们不能根据该曲线有效地制定政策。

第二，经济学家们在如何应对高通货膨胀的问题上产生了分歧，虽然大家都认为通胀是个问题，但其中一部分人认为美联储不需要对此负责。他们认为，由于石油等自然资源价格攀升造成的成本推动型通货膨胀（Cost Push Inflation），是在美联储控制范围之外的；而由于经济过热造成的需求拉动型通货膨胀（Demand Pull Inflation），是在美联储控制范围之内的。大部分经济学家认为这个时期的高通货膨胀是成本推动型的。甚至那些认为美联储有能力控制通货膨胀的经济学家，也建议美联储此时不应该进行控制，因为控制的代价（Sacrifice Ratios）巨大——压制通货膨胀会导致CDP下滑。这些人同时倡议，民众应该学着适应当前的高通货膨胀率，因为高失业率的代价是难以接受的。不幸的是，高通货膨胀率和高失业率在20世纪70年代后期仍然同时发生了（称为滞胀，Stagflation）。如果可以尽早解决通货膨胀率的问题，失业率的问题也不会如此严重。

第三，美联储在当时面临巨大的政治压力，它的独立性远不如今天。Meltzer写道，“通货膨胀一直在持续，这是因为考虑到政治和社会成本较高，政策制定者们并不愿意采取措施设法降低通货膨胀率。在20世纪60年代及以后，在议会和政府中对于抗通胀政策的政治支持几乎为零。”这点尤为重要：如果在政治上对如何控制通货膨胀无法形成共识，那么通货膨胀就会一直持续下去。通货膨胀既是一种经济风险，也是一种政治风险（参见第7章中通货膨胀风险和政治风险作为因子的内容）。

美国总统Jimmy Carter于1979年8月6日委任Paul Volcker担任美联储主席，Paul Volcker担任该职务直至1987年8月11日，他在任时终于成功控制住了通货膨胀。当Volcker上任时，公众已经准备好为控制通货膨胀而承受剧痛。Volcker通过在20世纪80年代早期将联邦基金利率升至19%的做法控制住了通货膨胀。经济开始衰退，但是至少通货膨胀被控制住了，这一时期被称为沃尔克式控通胀（Volcker Disinflation）。投资者从中学到的一课是：坚定的货币政策可以控制通货膨胀，但过程是痛苦的。通货膨胀风险与货币政策风险是相伴相随的（参见第9章）。
