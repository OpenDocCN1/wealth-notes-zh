
# 6. 房地产

溢价较高的原因之一（参见第8章）。普及了风险平配理论（均值方差投资的一种特殊形式；参见第3章）的对冲基金领域的超级明星Ray Dalio认为，黄金是一种“被低配了”的资产，如果投资者将组合中黄金持仓比例提高到与全球黄金市值权重（全球黄金市值占全球总财富的比例）相同的水平，那么黄金价格将会上升。这个结论乍一看太过于不合实际。世界上所有的黄金——无论是地面下的、金库里的，还是海底沉船里的——都已经是有所属的了。Dalio的理论只有在如下情况才成立：市场参与者愿意通过购买来增持黄金，使持仓比例达到黄金的市值权重，并且对所需支付的价格完全不敏感。即，一些投资者的需求曲线是完全无弹性的（Perfectly Inelastic）。可能有些机构投资者是这样的，例如中央银行、新兴市场中不断增加的富裕阶层和中产阶层，或许还有一些误认为黄金是完美对冲通货膨胀工具的养老金。Erh和Harvey（2012）估计，黄金占总财富的比例在2%～10%之间，具体比例取决于你是只计算投资者持有的黄金，还是所有的黄金供给，这些供给包括未被开采的黄金以及央行持有的黄金。

当我看到图11.7-A时，我吃惊于黄金实际价格在长期的均值回归特性。20年的黄金实际回报率与其自身滞后20年的实际回报率的相关系数为-63%，这个相关系数让人难以置信。当黄金的实际价格已经高企时，那么接下来黄金的长期实际回报率将会偏低。这对所有正在增加黄金配置的投资者是一个警示。追求回报的投资者犯的经典错误就是投资于过去回报率很高的资产。接下来的回报率通常会让人极其失望。

最后，我们来看图11.7-B中黄金和股票的实际回报率之间的关系。代表黄金的线与图11.7-A中完全相同，只是我将纵轴做了对数化处理。图11.7-B中加上了股票的实际回报，也是以1987年9月为初始值1。可以看到，股票的实际表现明显打败了黄金。

空间，是房地产投资的一切。更准确地说，房地产投资是通过建立和保持某种结构，来消除人们与机构之间的物理距离。城市经济学中有两个核心模型，来描述影响房地产供给和需求的基本来源。这两个模型的核心是空间均衡（Spatial Equilibrium）的概念，该概念是指人们和企业投资房地产时，房地产的价值与它们的地理位置无关。代理人的效用和最终房地产的价值是由房地产能提供的各项设施条件所决定的，包括与消费者和供给者的邻近程度、人力资本的溢出效应、内在的地理优势（包括优美的视野和宜人的气候）。房地产的价值也受到劳动者收入、居住成本和交通成本的影响。

Alonso（1964）、Mills（1967）和Muth（1969）的模型按照在某一城市内房地产与城市生产中心的距离，来解释它们的价格变化：随着交通成本上升，房地产价格将下降。Rosen（1979）和Roback（1982）的重要模型则解释了在不同城市和都市区域之间，由于收入、设施、生产力水平的差异房地产价格出现了怎样的差异。更高的土地价格反映了进入都市圈生活的门槛，因为这些区域有生产效率更高的企业和更好的设施（包括更丰富的文化活动、更低的犯罪率、更好的学校、更宜人的气候）。

房产中介的口头禅“位置，位置，位置”其实只说对了一半。位置在Alonso-Mills-Muth的模型中确实是驱动房地产价格的基本因子之一，但是它的影响来自交通成本。Rosen-Roback模型强调的则是，不是位置本身，而是位置所带来的各种优势（例如贸易和生产机会）与企业和劳动者的生产力、其他宏观因子之间的相互作用。

房地产投资者们应该将城市经济学作为投资的基础。城市经济学让我们可以：

## （1）理解宏观因子

经济模型可以很好地解释内生变量（例如房地产价格、人们在哪里居住、买多少房产）怎样被外生变量（例如地理、缓慢变化的生产力水平）所决定。经济模型可以让人看到价格背后的基本面，包括总需求因子和总供给限制等。强调宏观因子尤其重要，因为持有房地产是一种长期投资，机构持有单个房地产投资的期限中位值大约是十年以上。

## （2）在大环境中理解房地产

就像其他所有的价格一样，房地产价格由均衡水平所决定。我住在纽约，那里的房地产价格高，平均工资高，生活成本也高。从劳动者的角度来看，高工资是好的。从雇主的角度来看，高工资是不好的。企业为什么不将生产从纽约转移出去，从而降低工资支出呢？在均衡状态下，只有这个城市使得所有劳动者和企业的生产效率更高，房地产价格才会更高，工资才会更高。是什么创造了生产力？是什么保持了生产力？是什么使生产力消失？只有将房地产置于经济大环境中，我们才能更好地理解它。

## （3）进行政策评价

政府政策对于股票和固定收益市场有一定影响（分别参见第8章和第9章），但是对于房地产，这种影响尤其重要。房地产价格不可能不受监管政策的影响。经济模型可以很好地衡量外部政策变化的效果（通过比较静态（Comparative Statics）分析）。房地产价格的一个极为重要的决定因子是供给。在“超级明星城市”（包括旧金山、波士顿和类似的海滨城市）中，全新的住房和办公室的供给受到监管的严格限制。由此产生的稀缺性推升了房价。而在亚特兰大，供给侧的限制比较少，因此房地产价格相较于海岸边的城市偏低。政府政策对不同城市的房价有影响，对各个城市中不同区域的房价也有同样重要的影响。在其他条件不变时，当供给政策发生改变，经济模型可以让我们预测到哪些区域会受益或受损，受益或受损的程度是多少。

## 6.1 直接投资或间接投资？

我的分析重点将是，机构投资者的直接房地产投资，以及通过REITs进行的间接房地产投资。REITs是一种类似于共同基金式的投资工具，广泛地持有各种房地产资产。许多REITs都是公开交易的。REITs需要满足很多限制条件：最重要的就是，每年它们须要将至少90%的应纳税收入作为红利分配给持有者。REITs是少有的一种可以让零售个人投资者投资到商业地产市场的工具，于1960年由议会通过房地产投资信托法案而建立。起初，议会并没有意识到允许大众投资商业地产可以带来的分散化收益。REIT法案最初只是一项修改关于雪茄烟征税法的法案的附属品。在房地产行业进行大量游说后，REIT法案获批通过，这样开发商可以通过股票市场募集更多资金。

由于直接房地产投资和REITs都包含可以产生现金流的建筑和土地，人们可能会认为这两种投资方式回报率的相关度很高。当然，直接和间接的房地产投资在长期来看都会受到共同的基本面因子驱动。但是，它们的相关度并不高，这被称为REIT之谜（REIT Puzzle）。

表11.4汇总了从1978年初至2011年末，直接和间接房地产投资回报率以及股票回报率的均值、标准差、自相关系数和相关系数矩阵，所有数据均采用季度数据。直接房地产投资的回报率来自美国国家房地产投资信托委员会（NCREIF），该机构从它的所有会员处收集房地产数据。NCREIF每季度根据房地产估值计算一个价值加权的指数。间接房地产投资的回报率是FTSE NAREIT All Equity指数的回报率，计算频率同样是每季度一次。我将这两项回报率与标普500股指的回报率进行比较。

**表11.4 相关系数矩阵**

在表11.4中可以看到，NCREIF回报率（季度自相关系数为78%，波动率仅为2.2%）与REIT回报率和股票回报率（自相关系数接近于0，波动率在8% ~ 9%之间）相比，显得非常平滑。REIT回报率与股票回报率之间的相关系数高达63%，而NCREIF回报率与REIT回报率的相关系数低至15%。这样REITs看起来更接近于股票，而不是直接房地产投资。在所罗门兄弟任职的房地产从业者Hartzell和Mengden于1986年率先发现了这种现象，并掀起了关于房地产回报率特性的大讨论。房地产确实是一种独立的资产类别吗，或者它只是另一个版本的股票（和债券）？

关于这个问题的讨论延续至今。我从众多文献中为投资者总结了如下几点内容。

**直接房地产投资回报率并不是种可通过现实投资获得的回报率**

NCREIF数据序列（和在欧洲广泛使用的Investment Property Databank数据序列）存在很多数据偏差，因为这些数据并不是基于现实中的市场交易。而REIT回报率，是一种可通过现实投资获得的回报率。NCREIF数据序列有两个重大的数据偏差：

### (1) 平滑性偏差

采用估值数据（一年最多一至两次）就会人为地引入平滑性，这就是表11.4中NCREIF数据序列自相关性比REITs或股票高很多的原因。

### (2) 选择性偏差

你所见的被出售的房地产并不能代表全部房地产的存量。例如，也许只有最好的房地产才会被出售，因为开发商只会对这类房地产进行包装，而那些止赎的、劣质的房地产则无人问津。

此外，REITs投资是附有杠杆的，而NCREIF回报率则是无杠杆的。研究者们开发了很多新方法试图将以估值为基础的指数转为以实际交易（和重复销售）为基础的指数，将房地产投资回报率去平滑化，加入对于选择性偏差的考量，以及剔除其他的流动性偏差。这些偏差的影响是巨大的。例如Lin和Vandell（2012）发现，在一年的持有期间内，直接房地产投资回报率的波动率比表11.4中计算的波动率高三倍。Pagliari、Scherer和Monopoli（2005）认为，在进行了去杠杆和板块构成调整以及估值数据去平滑化调整后，直接房地产投资与间接房地产投资的回报率并无太大差异。

所有欠缺流动性的资产都存在平滑性偏差和选择性偏差的问题——包括私募股权在内——我将在第13章讨论解决这些问题的方法。我在此仍使用NCREIF回报率进行分析，但请记住：它们并不是真实的回报率。

**长期来看，直接和间接房地产投资的回报率同步变化**

直接和间接房地产投资的回报率在长期来看是相关的。图11.8画出了经对数化处理后，长期NCREIF回报率与REIT回报率的相关系数。在一个季度的时间段内，两者的相关系数是0.22，这反映了表11.4中两者的低相关度（表11.4中的回报率是将季度数据取算术平均值，而图11.8使用的是对数化的回报率；参见附录）。在十二个季度以后，两者的相关系数上升到约0.43。这意味着NCREIF和REIT的回报率中，有一些长期的共同构成部分。计量经济学研究也发现有力证据证明，公开的房地产市场领先私募房地产市场，这是可以预料到的，因为公开的房地产市场由于流动性更好，可以更快实现价格发现。

有读者现在可能会想，如果直接和间接房地产投资在长期来看是同步变化的，那么在REIT与股票相关系数高达63%（参见表11.4）的情况下，房地产可以被看作是一种独立于股票的资产类别吗？CPIB，一家规模达1620亿加元的加拿大养老基金计划管理机构，认为房地产并不算是独立的资产类别；CPIB在进行房地产投资时采用了因子投资方式，将房地产看作一种具有股票和债券特征的资产。在第10章中，我们也发现，房地产投资并没有获得超过股票、债券、REITs基准的超额回报。不过CPIB的观点仅属例外，大多数投资者仍将房地产看作一种独立的资产类别（或者说独立的因子）。但REITs并不是独立的，因为如表11.4所示，它与股票的相关系数很高。大多数投资者的上述观点是基于直接房地产投资的回报率，但如我们所知，直接房地产投资回报率并不是一种可通过现实投资获得的回报率。尽管REIT和NCREIF的回报率在长期体现出一些共同的特性，但是如图11.8所示，两者相关系数远远达不到1。因此：

**直接和间接房地产投资是不同的**

相比于直接房地产投资，上市交易的REITs似乎有一个重要优势：它们的流动性更好。但是截至2012年6月30日，只有150只REITs产品在纽约证交所进行交易，总市值约为5450亿美元。这相当于平均每只REIT的市值为36亿美元，低于世界上很多大城市中的大型房地产开发项目。FTSE NAREIT All Equity REITs指数的总市值约为5620亿美元。相对而言，Florence等人（2010）估算，美国（直接投资的）商业地产市场在2009年末的总值超过9万亿美元，尽管该市场已于2006至2010年之间损失了4万亿美元。

如果REITs有很大的流动性优势，那么为什么投在REITs的资金量不到商业地产市场的1/10呢？为什么REITs并不那么受欢迎？

从结构上来看，REITs与直接房地产投资是不同的。在1990年代早期以前，REIT行业规模很小，因为REITs按规定必须使用外部顾问来选择和执行投资策略。1986年，REITs被允许自由地选择和管理资产，随后在1990年代早期，很多REITs对这些职能进行了内部化重组。因此，1990年代以后被称为新REIT时代（New REIT Era）。

但即使在今天，REITs的法律结构也与直接房地产投资差异很大。Graft（2001）有力地说明了REITs的法律监管要求产生了很大的代理成本（参见本书第III部分，委托资产管理的代理问题）。收入审查（1986年有所放松）要求REIT收入的75%须来自房地产投资，这个要求使得REIT管理人相比于私募房地产合伙企业更有动力去收购价格被高估的资产。此外，REIT管理人通过管理费的形式可以获得持续的收入，而封闭式基金通常要在预定日期进行变现，开放式基金在收到投资者赎回要求时也会进行变现：5-50检验可以使REIT免于重复征税，该检验是指每组投资者（5个或更少）不能持有超过50%有投票权的股票，这意味着REITs不能被接管并解雇表现不佳的管理层。如表11.4所示，REITs的平均回报率高于NCREIF回报率，这符合REITs比直接房地产投资风险高的特性，它们的高回报率是对高风险的补偿。

即使不考虑代理问题，REITs的法律结构仍会导致其与直接房地产投资的差异。REITs每年要支付90%的收入，意味着REITs管理人倾向于投资已经产生稳定现金流的项目，而不是投资于现在需要现金、未来才产生现金流的在建项目。另一方面，最近REITs在很多新板块上都有很多创新，例如医院、数据中心、存储设施。但是由于这些新板块的规模较小——与办公地产市场相比，自助存储中心和服务器农场占比很小——NCREIF仍然聚焦于包括公寓、零售、办公和工业在内的传统“核心”板块。

然而总的来说，我相信代理问题和法律结构的差异都是次要的。尤其是在长期看来，REITs和直接房地产投资之间有更多的相似性。这与经济理论的预期一致，因为两者都是基于建筑物和土地，这也有实证研究支持。直接房地产投资回报率和REITs回报率在短期内的差异，很大程度上是由于直接房地产投资的回报率并不是一种可通过现实投资获得的回报率。

## 6.2 房地产与通货膨胀

关于房地产对冲通货膨胀的效果如何，文献中有很大分歧。Fama和Schwert（1977）首次提出，房地产可以完美地对冲预期内和预期外的通货膨胀。但是，由于缺少直接房地产投资回报率的数据，他们只能使用CPI指数中住房部分的数据。对于直接房地产投资，研究结果并没有统一的定论。一方面，Goetzmann和Vallais（2006）认为，直接房地产投资可以较好地对冲通货膨胀。另一方面，Huang和Hudson—Wilson（2007）发现“常识上认为的房地产作为一个资产类别可以有效地对冲通货膨胀的看法是言过其实的”。从文献中可以清楚地看到，REITs在短期并不能对冲通货膨胀。Gyurko和Linnelmann（1998）认为，将REITs作为对冲通货膨胀的工具并不合适。

我相信房地产在某种程度上有一定的对冲通货膨胀的效果，但是远远谈不上有效。房地产投资只能进行部分对冲。

在图11.9中，我展示了在多个时间段内，直接和间接房地产投资回报率与通货膨胀率的相关系数。作为对比，我在图中也画出了股票回报率与通货膨胀率的相关系数。我们在第8章中可以发现股票对冲通货膨胀的效果不佳。图11.9-A画的是传统的皮尔逊（Pearson）相关系数。REIT回报率与通货膨胀率的相关系数略高于股票回报率的相关系数，这两项相关系数在一个季度内约为0.1，在五年后升到0.4。NCREIF回报率与通货膨胀率的相关系数在一个季度内约为0.4，五年后微降至0.3。正如我此前强调的，NCREIF回报率的数据在短期内由于流动性偏差，可信度不高。在长期内，流动性偏差明显缓和，NCREIF和REIT回报率与通货膨胀率的相关系数均在0.3至0.4之间。因此可见房地产在长期内可以部分对冲通货膨胀，而在短期内不能。

图11.9-A显示的相关系数均存在高估。在图11.9-B中，我画出了更稳健的斯皮尔曼（Spearman）相关系数。三项相关系数均低于A图的皮尔逊相关系数。REIT回报率和股票回报率与通货膨胀率的相关系数在短期内均为负值，约为-0.1（这与第8章关于股票的发现一致）。一年后，REIT回报率与通货膨胀率的相关系数略高于股票与通货膨胀率的相关系数。五年后，REIT回报率的相关系数约为0.4，与A图中的值相同。而B图中的NCREIF回报率与通货膨胀率的相关系数比A图中的值明显下降。NCREIF回报率的相关系数在一个季度内约为0.2，随后升到0.3，而在五年后又降回0.2。
