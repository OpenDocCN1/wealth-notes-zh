由于PE基金没有强制或标准化的报告要求（不同于40法案基金，参见第16章），GPs可以在内部收益率、倍数及其他业绩指标之间进行选择。并购投资基金通常会公布倍数，但它们并不总是公布IRR。当业绩表现差的时候，IRR往往就消失不见了。这并不奇怪。举个极端的例子：如果倍数刚好是零，那么IRR应该是-100%。Philippou（2009）证明当倍数小于0.1时，有超过80%的基金不会公布IRR。

# 3.3 PMEs

IRR和倍数都是绝对衡量指标，不能计算相对于某个基准的业绩：分别在芝加哥大学和麻省理工大学从事PE研究的教授Steven Kaplan和Antoinette Schoar（2005），引入了PME指标来改善这个缺点$^{(1)}$。PME指标能计算相对于市场的PE业绩表现。业界实践者对PME还不太熟悉，但PME在学术界已广泛流传。
