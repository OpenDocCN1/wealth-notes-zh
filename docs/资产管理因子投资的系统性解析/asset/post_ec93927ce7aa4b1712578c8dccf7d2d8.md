### 3.3 随时间而变化的因子敞口

CAPM模型的发明者之一William Sharpe在1992年建立了一种有效的分析框架，用以处理随时间而变化的基准。他称之为“风格分析”。在我们的讨论中，风格分析是一种因子基准，该基准中的因子敞口都会随时间而变化^(1)。

我们以如下四只基金来举例说明Sharpe的风格分析中的随时间而变化的因子敞口：

- LSVEX：LSV价值型股票基金。LSV是一家“为机构投资者提供积极管理服务的量化价值型股票管理人”，它以其三位创始人学者的名字命名：Josef Lakonishok、Andrei Shleifer和Robert Vishny^(2)。
- FMAGX：富达麦哲伦基金。它是世界上最知名的零售共同基金之一，在20世纪八九十年代，它在超级明星基金经理Peter Lynch的管理下业绩突出，声名鹊起。
- GSCGX：高盛资本成长基金。我们怎能漏掉高盛公司的产品呢？
- BRK：伯克希尔·哈撒韦。既然我们此前用过Buffett的例子，这里继续使用。

### 禁止做空条件下的风格分析

风格分析试图通过被动地投资于一系列低成本的指数型基金来模拟上述基金的表现。这一系列指数型基金被称为“风格权重”（style weight）。

让我们用以下指数型ETFs（参见第16章的40法案基金）来举例说明：

- SPY：SPDR 标普500 ETF，它被用于模拟标普500指数；
- SPYW：SPDR 标普500 Value ETF，它被用于跟踪标普500价值指数；
- SPYG：SPDR 标普500 Growth ETF，它被用于复制标普500成长指数。

与Fama–French组合不同，这些低成本的指数型ETFs是可交易的。它们属于道富环球投资管理公司（State Street Global Advisors）旗下的SPDR（发音类似于“spider”）系列ETFs。

我们对基金 $i$ 进行基准因子回归分析（以下公式中由于下标太多，我不再标注“ $i$ ”）：

$$r_{i, t + 1} = \alpha_{i} + \beta_{SPY, i} SPY_{t + 1} + \beta_{SPYW, i} SPYW_{t + 1} + \beta_{SPYG, i} SPYG_{t + 1} + \varepsilon_{i, t + 1}\text{ 公式}(10.14)$$

限制条件为：

$$\beta_{SPY, i} + \beta_{SPYW, i} + \beta_{SPYG, i} = 1$$

即所有因子权重或因子系数之和等于 1。公式（10.14）右边的各因子权重构成了一个对基金i的复制组合。

风格分析的主要意义在于，我们在因子基准中使用了现实中可交易的基金。我在公式（10.14）中使用的是 SPDR系列ETFs，但我也可以使用其他ETFs或者指数型共同基金作为基准组合。

请注意公式（10.14）中的时间点。我们在估计时采用的是截至时间t时的信息。该基金在下一时期t+1时的回报率等于t时所构建的复制组合在t+1时期的回报率，加上残值$\varepsilon_{t+1}$，再加上该基金在t时期的阿尔法$\alpha_i$。这些权重可以随时间而变化。公式（10.14）提出的一个问题是：“我们可否使用机器人对SPY、SPYV和SPYG进行随时间变化的投资，来复制Buffett的回报率？”

图10.5画出了这四只基金的因子权重（风格权重）。我采用过去60个月（t - 60至t）的数据来估计这些因子，以获得在t时的基准权重。除了所有因子权重之和为 1这个限制条件，我还限制了这些因子权重必须为正值（即禁止做空）。第一个因子权重是在2006年1月的估计值。

从图10.5-A可以看到，LSV仅仅包含了市场（SPY）和价值（SPYV）两种风格。富达麦哲伦起初在2006年时包含了所有三种ETFs的风格，但是在2012年底时体现的完全是成长（SPYG）风格。高盛成长基金在样本前期大部分是市场敞口（SPY）和成长（SPYG）风格，但是到后期就只有成长（SPYG）风格。Buffett的因子敞口最为有趣：在2006年时是很强的价值（SPYV）风格；在金融危机期间，风格转换为成长型；在金融危机之后，风格又转回到很强的价值型。

基金在t + 1时期的超额收益等于该基金在从t到t + 1期间的回报率减去基准组合（根据t时的权重构成）在t + 1时期的回报率：

$$r_{t+1}^{ex} = r_{t+1} - [\beta_{SPY, j} SPY_{t+1} + \beta_{SPYV, j} SPYV_{t+1} + \beta_{SPYG, j} SPYG_{t+1}]$$

### 3.4 非线性回报

当获得了较好的阿尔法和信息比率时，任何管理人看上去都似乎能力出众，但事实并非如此。

阿尔法是根据线性分析框架计算出来的。但是，有很多非线性投资策略，尤其是涉及动态期权的策略，可以仿造出阿尔法¹。举一个极端（且算得上典型）的例子，参见图10.7。我按照Black–Scholes（1973）的定价方式，采用小样本构建了“卖出挂钩于市场组合的看涨期权”的投资策略。这些看涨期权的回报率在图中用×表示。然后，我对这些模拟出来的回报率进行了CAPM模型回归分析。“阿尔法”看起来是正值，但是我们其实知道在Black–Scholes的框架里，看跌期权或看涨期权并不会创造额外价值。这种阿尔法完全是虚假的。产生该问题并不是由于样本小（尽管样本小会加重该问题），而是由于线性分析框架无法充分捕捉到非线性策略的特性²。这在现实中是一个较为严重的问题，因为诸多常用的对冲基金策略，例如并购套利、配对交易、可转债套利，它们的回报都类似于非线性的期权波动率策略³。

为什么无法准确衡量动态的非线性策略的阿尔法呢？因为买卖期权——或其他任何动态策略——会改变回报率的分布⁴。静态的衡量指标，例如阿尔法、信息比率、夏普比率，都只能捕捉到回报率整体分布的某些特定部分。通常来说，做空波动率策略可以使得阿尔法和信息比率虚高，因为这些策略会增加分布的负偏度（negative skewness）。即这些策略会扩大分布左尾的损失并使分布中段“变宽”，如果用线性业绩指标来衡量就会显得更有吸引力。阿尔法和信息比率并不考虑偏度以及更高阶矩的情况。

我们可以用两种方法来分析非线性回报。

#### 引入可交易的非线性因子

如第7章至第9章所讨论的，市场总波动率风险是一个重要的因子。如果要获得做空波动率策略的效应，一个简单的方式就是引入波动率风险因子。我们也可将其他的非线性因子纳入因子基准中。这样一来，资产所有者就是假设她自己能够交易这些非线性因子。但是，有时只能通过某些特定的基金管理人才能获得这些因子的敞口。在第17章中，我将阐述控制非线性因子会如何关键性地改变对冲基金的阿尔法。Fung和Hsieh（2001）以及其他研究者指出，对冲基金回报率通常十分倚重于期权策略。

#### 检验不可交易的非线性属性

通过在因子回归公式的右边加入非线性项，我们可以比较容易地检验出基金回报率是否呈非线性属性。常用的包括平方项，例如 $r_t^2$，或者类期权项，例如 $\max(r_t,0)^{①}$。该方法的不足之处在于，加入这些项以后，阿尔法就不存在了——我们总是需要在公式右边有可交易的因子才能计算阿尔法。

我们必须找到一种比阿尔法更合适的衡量指标，在存在动态操纵的情况下，仍能有效地衡量管理人的能力，并对他们的业绩进行排名。目前最好的一种衡量指标是Goetzmann等（2007）引入的$^{②}$。在有足够长时间样本的情况下，该指标的衡量效果无法被扭曲，因为卖出现权不会产生错误的业绩衡量结果。

Goetzmann et al.使用的衡量指标是：

$$\frac{1}{1-\gamma} \ln \left( \frac{1}{T} \sum_{t=1}^{T} (1 + r_t - r_{rf})^{1-\gamma} \right) \tag{公式（10.16）}$$

其中 $\gamma$ 被设定为3。各家基金可以根据该指标的数值高低进行排序，数值最高的基金即是最好的。公式（10.16）让我们想起第2章关于效用函数的介绍，它确实是一种CRRA或者幂效效用函数（更准确地说，它是CRRA效用函数的确定性形式）。Goetzmann等人的研究中提到，晨星公司（Morningstar）使用的是该指标的一种变型形式：

$$\left( \frac{1}{T} \sum_{t=1}^{T} \frac{1}{(1 + r_t - r_{rf})^{\frac{1}{2}}} \right)^{-\frac{1}{2}} - 1$$

这也是一种CRRA效用函数，其中风险厌恶系数 $\gamma=2$。
