# ## 2. 因子理论

因子之于资产就如同营养成分之于食品。表6.2摘自美国国家医学院的食品营养委员会（Food and Nutrition Board），其列出了普通人体（男性、女性及儿童）所需的五大营养成分——水、碳水化合物、蛋白质、纤维及脂肪的建议摄入量。碳水化合物通常可以从谷类食品中获取，蛋白质可以从肉类和乳制品中获取，纤维大量存在于小麦和稻米，脂肪则可以从动物以及某些植物如花生来获取。每种食品都由一系列营养成分构成，许多食品都包含一种以上的大类营养成分，比如稻米包含碳水化合物和纤维。不管健康与否，不管性别或年龄差异，不同个体都有不同的营养成分需求。我们进食是为了获取食品中所包含的营养成分，正是这些营养成分滋养着我们。
