# 2.4 动态因子

大量学术文献以及长期投资经验发现，某些股票、债券以及衍生品证券能获取比主要市场指数更高的投资收益。相对对基本面价值而言较便宜的股票（价值股）在长期能战胜相对于基本面价值而言较昂贵的股票（成长股），从而产生价值溢价。长期来看，历史收益较好的股票（优胜股）往往能战胜历史收益较差或为负的股票（失败股），从而生成动量策略。相对于流动性好的证券而言，流动性较差的证券通常交易价格偏低，且有更高的平均超额收益，由此带来非流动性溢价²。违约风险高的债券通常有更高的平均收益，这反映了信用风险溢价。由于投资者愿意购买波动率保护，以应对收益出现大幅下跌时的高波动率时期，在期权市场卖出波动率保护的投资者平均来看能获取高回报。

我们通过做多上述资产类别中能带来风险溢价的证券，并同时做空或低配表现不佳的证券，由此可以获取动态风险溢价。部分策略名单如下：

+   价值—成长溢价=价值股减去成长股
动量溢价=历史表现好的股票减去历史表现不好的股票
非流动性溢价=流动性差的证券减去流动性好的证券
信用风险溢价=风险债券减去安全债券
波动率风险溢价=卖出价外看涨期权的同时持有股票或看涨期权以生成市场中性头寸
