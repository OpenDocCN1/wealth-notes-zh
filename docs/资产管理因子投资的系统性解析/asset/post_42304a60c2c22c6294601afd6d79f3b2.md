
# 1. 罗德岛州的员工退休体系

罗德岛与普洛威顿斯庄园州（The State of Rhode Island and Providence Plantations），简称罗德岛州（Rhode Island），是美国50个州中面积最小的$^{①}$。尽管夹在马萨诸塞州和康涅狄格州两个大州之间使它显得有些黯然失色，罗德岛州人（只有略超过一百万的居民）却有着敢想敢做且敢为人先的美誉。罗德岛州是13个殖民地中第一个从大不列颠帝国统治下宣告独立的——1776年5月4日，比其他殖民地早两个月。当林肯总统要求各州派兵参加内战时，罗德岛州也是第一个积极响应州。在2011年，罗德岛州又是第一个完成公共养老金体系改革的州。

罗德岛州的员工退休体系（Employees' Retirement System of Rhode Island，ERSRI）为包括公务员、教师、法官、地方行政人员如警察或消防员等在内的公共雇员提供退休金、残疾补助金和遗属抚恤金。与美国大部分公共养老金一样，它也面临着严重的资金短缺问题。2011年ERSRI的资金比率（funding ratio）仅为59%，只有63亿美元的资产却要偿付108亿美元的负债。罗德岛州的每个人需要支付4230美元来弥补这个缺口$^{②}$。此外，养老金的花费还挤占了其他公共服务开支。2002年，每个纳税人缴纳的每1美元中有3美分流向了养老金。在2009年这个比例上升到了9美分，2018年预计会达到20美分$^{③}$。但与此同时，州雇员的养老金缴款比例仍维持在8.75%，教师的养老金缴款比例仍是9.5%。

《天道日报》（Providence Journal）的编辑总结了罗德岛州的问题$^{④}$：“除非着手改革这个不可持续的养老金体系，否则未来罗德岛州将面临很高的税收；政府服务和

罗德岛州不是唯一遇到这个问题的州。罗彻斯特大学的金融学教授Robert Noy-Marx和斯坦福大学的金融学教授Joshua Rauh对公共养老金计划的资金短缺状况进行了调查，并引发了人们对该问题的关注。他们估计截至2009年，各州会积累5.7万美元的负债，而相应的资产则少于2万亿美元——也就是说有3.7万亿的缺口。这个缺口非常大，各州发行的未偿还公开交易债券才大约1万亿美元[sup]①[/sup]。

曾在2010年担任罗德岛财政厅长的Gina Raimondo认为，修补州养老金体系对于维持罗德岛州的金融稳定至关重要。Raimondo委托完成了一份报告，《数据中的真相：罗德岛退休体系的可持续性研究》（*Truth in Numbers: The Security and Sustainability of Rhode Island’s Retirement System*），于2011年6月公开。该报告指出导致养老金巨额赤字的五大原因[sup]②[/sup]：

- ①养老金缴款比例过低；
- ②从20世纪60年代到20世纪80年代养老津贴不断上升，缴款比例却未相应上升；
- ③养老金计划设计不完善，有些退休员工的收入比工作时的收入还高；
- ④平均寿命的延长；
- ⑤养老金的投资回报率过低，罗德岛养老基金从2000年到2010年的投资回报只有2.3%，而之前预计同期的回报率为8.25%。

养老金赤字问题已累积多年。ERSRI的执行董事Frank Karpinski说：“现在正为之前积累的问题买单”[sup]③[/sup]。《数据中的真相》一文成功地让大家注意到了养老金问题。它同时也提出问题：无论是谈论养老金问题的哪个方面，每个人都是基于相同的研究报告。

Raimondo和州长Lincoln Chaffee一起组建了一个包含工会代表、商业代表和学界代表的特别委员会。该养老金委员会从2011年6月到9月一直在全州召开公开会议，并向公众分享他们的观点。会议中的讨论强调了养老金问题的严重性。Raimondo说：“最终没人会批评这个过程。这个过程历时较长，是彻底、公开和透明的。”[sup]④[/sup]

# 2. 劳动收入

劳动收入是财富的一种形式。它不能被交易（第13次修订法案废除了奴隶制），使得劳动收入不同于资产组合中的金融资产。我们一生的人力资本很大程度上在出生时就已经决定了，个人能通过教育来增加人力资本，而失业或疾病等情形会减少人力资本。个人劳动收入的风险——波动性以及其与金融资报回报的相关性——会影响个人的资产配置。

我们将人力资本视为一种资产②。假设我们将个人工资的折现值记为H（即人力资本）。人力资本是个人一生劳动收入的折现值；也就是与个人工资流相等的当期值。人力资本是有风险的，因为工资收入会波动——在最糟糕时可能会跌到零。

我们将金融资产记为W。总财富为H+W，换句话说，总财富是由人力资本和金融资产所组成。

### 2.1 不考虑劳动收入的资产配置

考虑没有劳动收入、只有1百万美元金融资产的个人的资产配置。为简单起见，我们假设只有股票（期望回报率μ为10%，波动率σ为15%）和无风险政府债（收益率$ r_f $为2%）。投资者具有均值方差效用函数，或等同的具有CRA效用函数，风险厌恶系数y为5（第2章和第3章分别讨论了效用函数和均值—方差投资①）。

投资者只有金融资产，他会持有 $w^{*} = 62.5\%$ 的股票，这是从均值方差投资公式推导而来：

$$ w^{*} = \frac{1}{\gamma} \frac{\mu-r_{f}}{\sigma^{2}} = \frac{1}{5} \frac{0.10-0.02}{(0.15)^{2}} = 62.5\% \quad \text{公式 (5.1)} $$

（参见第2章的公式（2.10）），他的资产配置为：

- 持有 $0.625 \times \$ 1000000 = \$ 625000$ 的股票
- $\frac{\$375000\text{的短期国债}}{\$1000000}$

### 2.2 包含无风险劳动收入的资产配置

现在考虑有无风险劳动收入的个人的资产配置，例如一个顶尖大学的终身教授或者法官。她的人力资本等同于拥有无风险资产。假设她的工资现金流等同于现在的人力资本 $H = \$ 1000000$，她还有 $W = \$ 1000000$ 的金融资产。因此，她的总财富为 $H + W = \$ 2000000$。与第一个投资者一样，我们假设她的风险厌恶系数 $\gamma$ 为5。

在有无风险劳动收入的情况下，对风险股票的最佳持有量为：

$$ w^{*}=\frac{1}{\gamma} \frac{\mu-r_{f}}{\sigma^{2}}\left(1+\frac{H}{W}\right) \quad \text{公式 (5.2)} $$

注意当人力资本为零时，$H = 0$，公式（5.2）就与（5.1）完全一样。有无风险劳动收入的投资者相对于只有金融资产的投资者会将其资产配置向股票倾斜。投资者在这个例子中持有股票的比例是：

$$ w^{*}=\frac{1}{\gamma} \frac{\mu-r_{f}}{\sigma^{2}}\left(1+\frac{H}{W}\right)=\frac{1}{5} \frac{0.10-0.02}{(0.15)^{2}}\left(1+\frac{1}{1}\right)=125\% \quad \text{公式 (5.3)} $$

拥有劳动收入的投资者最优资产配置为：

- 持有 $1.25 \times \$ 1000000 = \$ 1250000$ 的股票
- $\frac{-\$250000\text{的短期国债}}{\$1000000}$

配置在股票上的比例比前一位没有劳动收入的投资者大得多。有无风险劳动收入的投资者做空无风险资产，并加杠杆持有125%的股票。但实际上总组合里仍刚好是62.5%的风险资产。

如果我们考察投资者总财富组合，则有：

| 项目 | 金额 |
| :--- | :--- |
| 人力资本 | $1,000,000 |
| 股票持有 ($1.25 \times \$1,000,000$) | $1,250,000 |
| 短期国债 | -$250,000 |
| **总资产** | **$2,000,000** |

作为总资产的一部分，股票占总资产的比例为$1250000/2000000=62.5\%$，与第一位没有劳动收入的投资者一样。

由于有无风险劳动收入，投资者可在其金融组合中承担更多风险。实际上，公式 (5.2) 是对公式 (5.1) 中的标准股票头寸加了杠杆，杠杆率为人力资本与金融资产的比率，H/W。

资产配置一定要从更广义的总资产的角度来看，总资产里既包含金融资产也包含人力资本。无风险劳动收入等同于无风险债券。金融资产组合里需要持有更多股票来平衡投资者无风险的人力资本。用经济学家的行话说就是，人力资本的风险敞口会挤占金融资产承担风险的能力。

### 2.3 包含风险劳动收入的资产配置

我们来考虑一个有风险劳动收入的投资者。我们需要判断他的劳动收入看上去是像股票还是像债券。如果你正在读这本书，你大概是从事金融相关行业，所以你的劳动收入可能与股票呈正相关。我的很多MBA学生的人力资本与股票市场高度相关。

劳动收入和股票收益之间的正相关性会减少投资者金融资产组合里风险资产的最优配置比例。在这种情况下，人力资本等同于配置了股票。你希望减少金融资产组合里的股票比例以抵消类似股票的人力资本。但减少股票的配置并不能消除你的劳动收入带来的类似股票的风险。简而言之，当人力资本比较接近股票时，你实际上已经拥有股票，所以你的金融资产组合里应该配置更少股票。

那些工资与股票收益呈负相关的投资者呢？这些人通常会在股票市场低迷时期赚得更多。例如破产律师、擅长指导企业扭亏为盈的专家以及收债人。这些投资者的人力资本与股票呈反向变动，所以他们的资本是反股票（anti-equities）的。如果是这样，他们会希望在金融资产组合中持有更多股票来抵消人力资本的反股票性。所以，他们会比无风险劳动收入的投资者更激进地多配置股票。

以下是几个非常重要的推论：

- ①如果投资者的收入与股票市场同向变动，则应该持有更多债券（或其他低风险资产）。这些投资者有类似股票的人力资本，所以他们应在其金融资产组合里配置与股票相反的头寸。
- ②John Roberts，Antonin Scalia，Sonia Sotomayor以及其他所有最高法院的法官都应该持有相对激进的股票头寸。他们的收入类似无风险债券，所以其金融资产组合应相反地配置更多风险股票头寸。
- ③投资者应该不持有或持有很少的雇主公司股票。因为她的劳动收入本身就已经有该公司的风险敞口，她不应该让其储蓄有更多的类似风险。她的金融资产应该多元化分散掉收入里所反映的雇主公司风险（参见第3章）。
- ④如果你在美国工作，你的金融资产组合中应配置更多海外股票而非本国股票。你的收入已经来自美国，所以你需要在金融资产组合中持有更多非美国股票$^{1}$。

上述都是规范性的陈述，或是关于投资者应该如何做的标准建议（参见第2章的规范经济学vs. 实证经济学）。现实中，许多人做的与上述建议恰恰相反。有些交易员喜欢在个人金融资产组合中持有非常高风险的资产，尽管他们的劳动收入已经高度依赖于股票市场。太多投资者大量持其雇主公司的股票，并且他们偏好本国资产而几乎没有海外头寸。这些投资者的金融资产组合包含了与他们人力资本相同的风险敞口，以至于没能多元化分散掉一部分人力资本风险（参见第4章）。

### 2.4 劳动收入的风险

衡量劳动收入的风险比较棘手。我们没法观察到人力资本的价值，因为它不可交易。

将人力资本视为资产并给它赋予价值的首位经济学家是Gary Becker（1964），他于1992年获得诺贝尔奖。Becker指出，教育是一种人力资本投资，而不是简单的奢侈品或消费支出。他还指出人力资本投资对于经济增长是必须的。劳动经济学中很大一部分文献通过计算人力资本投资带来的收益来衡量人力资本回报率：劳动经济学家测算了研究生学历学生比有大学本科学历的学生、高中学历的学生和高中以下学历的学生所多赚取的工资。显然，随着受教育程度的增加，工资也不断提高（根据2012年劳动统计局的数据，高中以下学历的工资中位数为每周薪水471美元，本科生是1066美元，本科及以上学历是1735美元）。有意思的是，博士生的工资金位反而下降到每周1624美元（在我为博士学位努力奋斗之前要是有人告诉我这个数据就好了）。众所周知，女性工资低于男性，黑人工资低于白人。

人力资本是未来所有工资收入流的折现值。人力资本的回报率通常采用工资增长率来计算<sup>①</sup>。Palacios-Huerta（2003）计算了不同职业和性别的人力资本回报。他发现有本科学历和1～5年工作经验的白人男性人力资本年回报率为14.2%，而那些上过大学却没有获得学位的却只有10.5%。虽然本科毕业生有更高的人力资本回报率，但回报的波动性也更大：白人男性本科毕业生的人力资本回报率的标准差为11.3%，而受研究生教育的人力资本回报率标准差只有4.7%。所以，这些有着1～5年工作经验的白人男性本科毕业生的原始夏普比率（raw Sharpe ratio）（我将其定义为期望收益（而非超额收益）除以波动率，参见第2章）为14.2% / 11.3% = 1.3，比受研究生教育的白人男性的原始夏普比率2.2要低。相比之下，标普500的原始夏普比率为0.6左右。平均来看，教育是个很好的投资。

人力资本除了有随时间而变化的风险，不同职业的人力资本还相差悬殊。Christiansen, Joensen和Nielsen（2007）的报告显示，医生的平均人力资本回报超过25%，标准差为18%；经济学硕士学位的人力资本回报均值为12%，标准差为16%。Christiansen、Joensen和Nielsen发现有些职业的平均人力资本回报显著为负，例如教育学硕士或音乐硕士。

在经济衰退期间工资收入可能大幅下降<sup>②</sup>。Guvenen, Song和Ozkam（2012）运用社会保障总署（Social Security Administration）的历史数据研究了数以百万人的收入动态。他们发现，在衰退时期，工资的大幅增加几乎不可能，而工资的大幅下降变得很有可能。收入分布的中间部分与两端的变动相比趋于稳定。那些最富有个人——前1%（或许就是你，亲爱的读者）——的收入下降，有最高的劳动收入风险。2008～2009年经济衰退时期，财富居前的个人遭受了巨大的收入损失，比处于第90百分位的
