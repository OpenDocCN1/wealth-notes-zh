# **6.4 安全资产的最佳权重**

因子投资方法始于列出对资产所有者而言重要的因子。流动性是最重要的因子吗？或许我们更想强调信用的重要性，或者我们希望所投资基金仅持有储备国家的头寸，或者我们的首要目标是潜在投资收益。国家权重应该反映出这些因子的重要性，而市值加权或GDP加权可能还无法做到这点。投资者应该先决定选取哪些因子，然后再通过国家权重来反映这些因子的重要性。

在一个给定国家内的最佳安全资产头寸是什么呢？图14.10显示了2011年12月31日所有美国国债的市值，数据来源源于彭博。B图则显示了除短期国债以外的美国中期和长期国债的市值。如果投资者采用市值加权指数，则会持有很多短期到期的美债头寸，因为美国财政部发行的大部分国债是短期债券。如果你一定要按市场权重加权，那么你是否真的想要如图14.10所示的到期结构呢？
