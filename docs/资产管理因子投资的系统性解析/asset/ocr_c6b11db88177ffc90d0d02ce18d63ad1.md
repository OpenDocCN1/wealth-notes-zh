# 6.2  安全资产的因子

与其他资产一样，政府债也是由一系列风险因子构成。问题在于，安全资产中起作用的风险因子太多，有些甚至相互起反作用。先来看看国际货币基金组织（IMF）如何说①：

安全资产被用作是一种储存价值的可靠工具，在组合构建中帮助资本保值。它们是私营银行和中央银行回购（repo）协议以及衍生品市场中流动性好、稳定可靠的抵押品的重要来源，扮演着金融交易中信任的替代者或润滑剂。作为审慎监管的重要组成部分，安全资产为银行提供了一种机制能增强其资本和流动性缓冲。作为基准，安全资产能用于其他风险资产的定价，最后，安全资产还是货币政策操作的重要组成部分。

接下来我们来讨论一些因子。

# 信用风险

理想的价值储存工具应该具有零违约风险。所以私营部门很难创造足够多的安全资产（文献中也称之为信息不敏感资产）来满足需求②。但主权债也有信用风险。主权债违约时有发生③。Tomz和Wright（2013）计算表明，一个给定国家有1/50的概率随时违约，但对于1980年之后的样本来说，年度违约概率翻倍为4%。当政府违约时，投资者将损失40%左右（即估值折扣），但损失范围可达30%～75%不等④。

即使美国也曾违约两次。1934年，美国将美元价格从每盎司黄金兑换20.67美元大幅贬值到每盎司黄金兑换35美元。Reinhart和Rogoff（2008）将美国废除黄金兑换条款视为违约事件，因为那时所有的主要货币仍以黄金为本位币。接着在1979年4月和5月还有个鲜为人知的小插曲，美国短期国债的投资者没能及时收到利息收入⑤。财政部将此归咎于程序问题以及国会疏于对债务上限采取行动（后者是老生常谈的问题）。一开始，财政部不愿意支付任何额外利息、结果激起了集体诉讼。后来在大量游说下政府终于支付了利息。
