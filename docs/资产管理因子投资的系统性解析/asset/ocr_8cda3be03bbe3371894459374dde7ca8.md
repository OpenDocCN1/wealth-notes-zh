# # 3.3 生命周期模型

人们在他们工作时获得工资，但当他们退休时这种收入现金流就停止了。因此，人们必须在工作时储蓄以便在退休时还能维持生活。经济学家用生命周期模型来研究人们在不同年龄阶段的消费、储蓄和投资决策。第一个相关模型是由Franco Modigliani和他的学生Richard Brumberg提出。他们写了兩篇文章，一篇发表于1954年，另一篇发表于1980年。Brumberg因为心脏病英年早逝，Modigliani直到后来发表他的论文合集时才将第二篇文章发表出来$^\text{①}$。

生命周期模型包含至少两个时期：个人工作储蓄的积累时期和个人动用存款的去积累时期。有时还有其他时期，比如退休早期和退休晚期，年轻劳动者时期和之后的中年劳动者时期等。个人会根据他们在不同年龄的需求来调整消费、储蓄和投资决策，养老金则允许他们在生命周期中平滑消费。

Modigliani和Brumberge还创建了跨期迭代（overlapping generations，OLG）经济体，这里每个个体都遵循生命周期模型，并且存在不同的世代。在简单的两期生命周期模型设定里，每个时期都有两代人生活。其中一代是正工作的年轻人，他们的父母则是另一代退休的老年人。在下一期，新的年轻一代会出生，之前的年轻一代会变老而成为年老一代，之前的年老一代则因死亡而离开经济体。在OLG模型里，支付给一代人的养老金可以由后面几代人来融资$^\text{②}$。OLG模型使得经济学家可以衡量代际的不公平性：Raimoondo改革罗德岛养老金计划的出发点之一就是减少年轻员工对年老员工和退休者福利的支付。Modigliani于1985年获得诺贝尔奖。

# # 3.4 生命周期资产配置

决定股票配置是否应该随年龄增长而减少的重要因素是人力资本与股票的相关性。人力资本是一种资产，如果它类似股票，我们就希望持有更少的股票（反之亦然）。生命周期模型考虑了随时间变化的人力资本变化。

① Deaton（2005）中有详细叙述。

② 见Kolikoff（1988）的调查研究。OLG模型的一个重要结论是人口和经济增长会促进储蓄。如果年轻人比老年人多，年轻人的储蓄就会超过老年人的去储蓄（储蓄减少），就会有正的净储蓄。如果收入是增长的，年轻人的储蓄会超过老年人的去储蓄带来的储蓄减少。
