# ## 4.1 负债对冲组合

几乎所有的投资者都有负债。即使投资者没有显性负债（例如挪威基金），至少在短期也常有来自利益相关人对其管理职责的预期而产生的隐性负债。负债可能是固定的，例如贷款偿付；也可能发生变化但相对比较稳定，例如养老金费用；也可能由突发情况造成一次性支付的，例如死亡抚恤金。

如果引入负债，那么最优的组合将包含三个部分：

```
长期权重($t$) = 负债对冲($t$) + 短期权重($t$) + 机会型权重($t$)  
投资组合($t$)
```

这里的投资组合与我们在第2节和第3节中提到的无负债的案例完全一样：在收益率服从独立同分布且可预测的假设下，最优的策略是再平衡，最优的短期组合会随时间而改变，长期投资者有额外的机会型策略。负债对冲组合，是保证投资者可以偿付债务的最优组合。我们通过持有与负债相关性最高的资产头寸来求解这个问题$^{①}$。

最优负债对冲组合有以下几种特殊情况：

（1）现金流匹配或免疫（immunization）

这包括构建一个与每期的负债支出可以完美匹配的组合。你可以通过持有到期日与债务支付日相近的债券，来匹配每一笔负债支出。

（2）久期匹配

如果负债可以被归结为单一的利率因子，这种情况对于养老金负债来说很常见，那么我们可以通过持有久期相同的资产组合来匹配负债$^{②}$。
