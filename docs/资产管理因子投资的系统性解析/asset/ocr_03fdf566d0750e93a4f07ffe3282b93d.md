新兴的私募股权和对冲基金二级市场对于大型资产所有者来说是提供流动性的巨大机遇。二级私募股权就像是仍然全新的二手车。当你驾驶一辆新车离开车场时，新车会立即贬值1/4，即使它与经销商库存里放的车完全一样。二级私募股权仍然是私募股权，但其价格比直接从经销商手里购买要便宜得多。

# 逆向选择

因为买方可能拥有非公开信息，做市商面临着以远低于股票真实基本面值的价格卖出的风险。知道某只股票会升值的买方会继续购买，从而推高股价。在这种情况下，做市商过早以过低的价格卖出股票。这被称为逆向选择。Glosten和Milgrom（1985）和Kyle（1985）——两篇开创了做市微观研究的论文——创立了买卖差价应如何将逆向选择效应纳人考虑的相关理论。为了避免被利用，DFA会与充分披露信息的交易对手进行股票交易，同时DFA也会保证自己以可信的方式进行交易，杜绝利用信息提前交易或者操纵股价②。

# 4.4 再平衡

资产所有者能提供流动性的最后一种方法是通过动态组合策略来实现。这对资产所有者的总组合产生的影响远大于选择流动性好的证券或是做市，因为这是一种从上至下的资产配置决策（因子归因参见第14章）。

再平衡是提供流动性的最简单方式，同时也是所有长期投资策略的基石（参见第4章）。再平衡迫使资产所有者在其他人想卖出时以低价买入。相反的，再平衡会自动减少价格高企的资产，将这些资产转给希望在较高价位买入的投资者。由于再平衡是逆周期的，所以它可以提供流动性。动态组合规则，尤其是那些基于简单估值方法的规则（参见第4章和第14章），进一步扩展了这一理论——只要他们在其他人想卖出时买入即可，反之亦然。如果可能的话，对非流动性资产头寸也进行再平衡至关重要（参见下文）。
