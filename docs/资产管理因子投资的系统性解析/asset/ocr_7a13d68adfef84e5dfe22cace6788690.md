# 3.2 股票的长期风险不会下降

“100减去年龄法则”背后的一个普遍原因是认为在长期股票风险会下降。Siegel（1994）的支持者们令这一观点广为人知。他们认为股票的长期风险会下降等同于认为股票收益是均值回归的。但支持这个观点的证据却很微弱：第8章指出，理论预测和实证检验都证实股票收益的均值回归程度非常小。

此外，如果股票收益是可预测的并且是均值回归的，那么最优资产配置就不应该遵循“100减去年龄法则”。如果股票是均值回归的，你应该在股票价格低、期望收益高时买入股票（低买），在股票价格高、期望收益低时抛出股票（高卖）。你的资产组合构成将取决于股票和债券的相对价值，也就是说你的资产配置应该对市场状况以及你的年龄都较为敏感。哈佛商学院的金融学教授Luis Viceira说：“一边认为长期风险会降低，一边无视产生该风险的收益变化，这在逻辑上是不一致的。”②

Pastor和Stambaugh（2012a）认为，对一个需要预测股票收益波动率（统计学家称为预测方差（predictive variance））的投资者来说，股票的风险在长期实际上会增加。他们指出，虽然股票收益确实有微弱的均值回归现象，但都被当期和未来预期收益的不确定性以及预测收益的计量经济学模型的较大参数估计误差所淹没。收益的均值回归确实会导致股票的长期风险下降，但其他两方面因素带来的影响超过了这个效应，导致股票的风险随时间长度增加而上升。

# 防止股票长期表现不佳

波士顿大学的养老金融专家Zvi Bodie（1995），通过计算防止股票表现不及债券所需的成本，发现股票的长期风险并没有下降。
