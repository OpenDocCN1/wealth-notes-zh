为了说明Geltner-Ross-Zisler的去平滑化处理过程，我们采用r<sub>t</sub>来表示t时期末的真实收益率（该值是无法观测到的），采用r<sub>t</sub>*来表示公布的收益率（该值是可观测到的）。假设观测到的收益率遵循以下公式

r<sub>t</sub>* = c + φr<sub>t-1</sub>* + e<sub>t</sub>
公式（13.1）

其中，φ是自相关参数，而且绝对值小于1。公式（13.1）是个AR（1）的处理过程，这里“AR”代表自回归，“1”代表其旨在捕捉滞后一个标准单位时间的自相关效果。假设观察到的收益是当前真实收益和滞后真实收益的函数（这被称为“传递函数”或按工程师的说法是“观测方程”），我们可采用公式（13.1）反推出真实收益。如果平滑过程只涉及本期和前一期的平均收益，那么我们可通过以下公式来过滤可观测到的收益率r<sub>t</sub>*，并估算真实收益率r<sub>t</sub>：

r<sub>t</sub> = 1/(1 - φ) r<sub>t</sub>* - φ/(1 - φ) r<sub>t-1</sub>*
公式（13.2）

公式（13.2）对可观测到的收益率进行了去平滑化。如果我们关于传递函数的假设是正确的，那么公式（13.2）所包含的可观测到的收益率的自相关性应该为零。因此，该过滤器将一系列自相关的可观测收益率过滤后并计算出真实收益率，这些值接近IID（或者说是不能预测的）。需要注意的是，真实收益的方差相应高于可观测到收益的方差：

var(r<sub>t</sub>) = (1 + φ²)/(1 - φ²) var(r<sub>t</sub>*) ≥ var(r<sub>t</sub>*)
公式（13.3）

由于1φ1，所以我们在可观测到的收益率中加入变量就可以估算出真实收益率。

另外一种解读公式（13.1）和（13.2）中去平滑化过程的方法是，假设平滑的，或公布的收益都等同地遵循以下公式：

r<sub>t</sub>* = (1 - φ)r<sub>t</sub> + φr<sub>t-1</sub>*
公式（13.4）

因此，t时期对应的非平滑的收益率r<sub>t</sub>*，是t时期未平滑的，或真实收益率r<sub>t</sub>与滞后的前一期非平滑收益率r<sub>t-1</sub>*的加权平均。因此，平滑后的收益率仅缓慢更新——其部分反映了真实收益率发生的变动，但仍存在评估过程引发的滞后效应。
