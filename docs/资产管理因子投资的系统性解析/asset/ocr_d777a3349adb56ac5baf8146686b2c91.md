# 2. 真正重要的是因子

# 2.1 什么是因子？

因子是在长期能 提供 更高收益 的 投资 风格。然而，风险溢价 并非 免费 的 午餐，因为因子 在 短期（“不景气 时期”） 可能 表现不佳。因子 损失 往往 与坏的 经济 情形 相关，如 高通货膨胀、低经济增长 时期。股票 和债券 是通过 简单购买 资产（做多） 来 获取 风险溢价 的 因子 示例，因此 它们是 静态 因子¹。其他 因子 往往 需要 涉及多 空头 寸 的动态 交易，即 我们 必须 不断 调整 组合权重。正如 静态 因子 一样，动态 因子 策略 如 价值 成长 投资、动量 投资、做空 波动率 策略 并不总是 赚钱的，投资者 需要在 市场 低点 时能 撑得住。正是由于 承受了这些 损失，所以 因子 能 累积 风险溢价。资产 中 蕴含着不同的 因子 风险 组合，正如食物 是不同 种类营养成分 的 混合。

最简单的 因子 是挪威 基金选取 用来 作为 其 收益基准 的 股票 和 债券 指数。通过 购买 便宜的 指数 基金 便可以 轻松地 投资 上述 因子²。资产 管理 的 传统 方法是 在 股债 组合的 基础上再 加入 其他 资产 类别，尤其是 股票 和债券 细分资产 类别 如 新兴市场 股票、高收益 债券等，或是 另类 资产 如 房地产、私募 股权 和 对冲 基金（这被称为 捐赠 基金 模式，但与 最初 提出 该 概念的Swensen（2009） 对此 的界定 不同，参见 第13章³）。即使 不 加入 另类 资产 类别，在 股票、债券 因子间 的 决策 仍是 各 基金 需要 做出的 最重要 决定 之一。因为 这能 解释 大部分 的 业绩 变化。
