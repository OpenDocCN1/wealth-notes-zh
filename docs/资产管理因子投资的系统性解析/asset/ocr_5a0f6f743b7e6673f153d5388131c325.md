两个主要原因。首先，人们希望能自主投资（即来自雇员的需求增加）。固定缴款计划是可以转移的，这对于经常跳槽的人们而言非常具有吸引力，在当今的劳动力市场跳槽现象已经屡见不鲜。更何况金融业的市场营销手段让许多人相信，他们能够在投资自有资金方面做得更好$^{[1]}$。

其次，从供应角度来看，雇主发现固定缴款计划相对而言成本更低且操作更简便。自20世纪80年代以来，固定收益计划的成本逐步上升：雇员寿命越来越长，实际工资不断增长，缴费的不确定性对企业和股东来说代价很高。对固定收益计划的监管变得越来越繁琐；政府希望提高固定收益计划中雇员资金的安全性，但与此同时政府监管提高了企业成本。下一节会介绍新的法规体系。

# ## 3.2 \hspace{1em} 雇员退休收入保障法（ERISA）

1974年颁布的《雇员退休收入保障法（以下简称ERISA）》规定了养老金计划的最低标准：它规定必须提供给员工的最低福利，以及确保这些福利的最低资金要求$^{②}$。在ERISA颁布之后，一些养老金法案陆续出台，近期最典型的是2006年颁布的《养老金保护法案》（以下简称PPA）。“ERISA”用作术语时是指与养老金监管有关的所有法律，包括在《雇员退休收入保障法》之后颁布的法案。ERISA仅规范企业已创建的养老金计划；不强制要求企业创建养老金计划。

ERISA的首要目标是保护基金受益人。ERISA明确要求公司应留出充足的资金以偿付固定收益计划的债务。遵照PPA法案，设定的目标是养老金债务能够100%得以偿付，如果资金不足，公司必须在7年内加大缴款力度来缩小差距$^{③}$。针对那些“危险”或“情况危急”的养老金计划，即存在严重资不抵债的情况，公司还应支付额外罚金并增加缴款金额（当然，固定缴款计划没有这样的资金问题）。公司向养老金缴款是有代价的：资金投入养老金计划意味着可供公司投资的资金变少，股东分红变少$^{④}$。养老金支出对公司股票价格有着很大的影响：美国电话电报公司（AT&T）的养老金
