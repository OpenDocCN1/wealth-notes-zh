绝不会持有100%债券的资产组合。由于股票与债券相关性较低，在债券组合中加入股票可以起到分散化效果；上述样本中股票与债券的相关系数仅为11%。由于当债券表现不佳时股票可能表现较好，因此投资者最好持有一些股票。但是资产所有者应持有多少股票呢？

最优资产组合取决于资产所有者的风险厌恶程度。图2.8-B中加入了风险厌恶系数 $\gamma = 2$ 时投资者的无差异曲线，该投资者希望通过选择最优资产组合w来最大化其效用：

```
$\max E(r_p) - \frac{\gamma}{2} \text{var}(r_p) \qquad\qquad\qquad\text{公式 (2.6)}$
```

对于这个问题，确定一项资产（如股票）的权重便自动确定了另一项资产（债券）的权重，因为两者权重之和为1。图2.8-B形象地描述了公式（2.6）的最优化问题。最大化效用等同于寻找尽可能高的无差异曲线。

图2.8-B中最高的无差异曲线与均值—方差前沿在三角符号标出的点相切。在这一点上，资产所有者持有78%的股票。我们也画出了更高的无差异曲线，但这些曲线并不与均值—方差前沿相交，因此这些无差异曲线是不可行的。我们选择的点需要在均值—方差前沿上，因为通过持有股票和债券仓位能获得的所有资产组合均已在此前沿上。故该三角符号标出的点是我们能够得到的最高效用。

从图2.8-C可观察到风险厌恶水平更高（$\gamma = 7$）的投资者的无差异曲线（请注意，这些无差异曲线比图2.8-B中的曲线更陡）。三角符号标出的切点在均值—方差前沿上更接近100%持有债券的位置。对于$\gamma = 7$的资产所有者，32%的股票持仓是其最优选择。

那么，什么风险厌恶程度会对应持有60%的股票仓位呢？图2.8-D画出了随风险厌恶程度变化的股票权重。一个60%股/40%债的组合对应着$\gamma = 2.8$ 的风险厌恶程度。因此，与大多数个人投资者类似，典型养老基金是中度的风险厌恶者。这种由资产组合倒推出风险厌恶程度的方法被称为显示性偏好（Revealed Preference）。

# 3.4 市场的风险厌恶

资本配置线（Capital Allocation Line, CAL）描述了由一种风险资产（如股票）和无风险资产构成的资产组合。我们暂将后者假定为美国短期国债，尽管它面临着一点点头（主权）风险（参见第14章），但我们暂时忽略该风险。我们假设无风险利率已知，用 $r_f$ 表示无风险利率，用 $E(r)$ 和 $\sigma$ 分别表示风险资产的期望收益率和标准差。

在资产组合的均值—标准差空间（ $E(r_p), \sigma_p$ ）中，我们用下述直线来描述CAL：

```
$E(r_p) = r_f + \frac{E(r) - r_f}{\sigma} \sigma_p \qquad\qquad\qquad\text{公式 (2.7)}$
```
