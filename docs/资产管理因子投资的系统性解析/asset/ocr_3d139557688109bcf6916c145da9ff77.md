# 3. 公布的非流动性资产收益率并非真实收益率

正如Faust和Forsi在哈佛各院系理事会的通知中所提到的，非流动性资产的真实损失要比公布的数据更大，我们从中可得出一个重要推论：非流动性资产公布的收益率并非真实收益率。下述三个重要偏差会导致人们夸大期望收益并低估非流动性资产的风险：

在非流动性资产的市场中，投资者必须对公布的收益率数据持高度怀疑的态度。

# 3.1 生存者偏差

导致生存者偏差的原因是由于业绩不佳的基金会倾向于停止公布其收益情况。这类基金大多最终以倒闭告终，但业界却很少把他们的失败计算在内。这使得非流动性资产的真实收益率比公布的数据更糟。
