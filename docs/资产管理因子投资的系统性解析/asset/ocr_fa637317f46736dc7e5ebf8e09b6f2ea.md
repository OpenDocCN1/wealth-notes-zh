# （3）展期（Roll）回报

投资者如果想获得持续的敞口，必须在旧期货合约临近到期时，用新合约进行替换。他们卖出旧合约、买入新合约，会产生收益或损失。

表11.3将GSCI的平均总回报率划分成即期回报率、现金回报率和展期回报率三个部分。图11.5画出了这三个部分在过去几十年的滚动两年平均值。从1970年1月至2011年12月间，GSCI的平均总回报率为11.3%，其中包括6.4%的即期回报率、5.6%的现金回报率和-0.7%的展期回报率。在20世纪80年代，即期回报率仅为-0.4%，但是由於抵押品获得的高利息，现金回报率为9.1%，以及展期回报率为2.4%，因此将GSCI的平均总回报率拉回到正值。在21世纪头十年，展期回报率为-7.5%，但是即期大宗商品市场表现出色，即期回报率为13%，因此GSCI平均总回报率仍然为正值。
