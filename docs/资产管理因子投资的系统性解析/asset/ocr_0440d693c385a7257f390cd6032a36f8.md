预期效用是 $\frac{1}{2}U(X)+\frac{1}{2}U(Y)$ ，该点位于 $U(X)$ 和 $U(Y)$ 的连接线上，并用三角符号标记。可以看到，确定结果的效用比随机结果的效用更高$^{①}$。

$U(\frac{1}{2}X+\frac{1}{2}Y)\ge \frac{1}{2}U(X)+\frac{1}{2}U(Y)$

图2.4中星号与三角符号的差距越大，表明投资者风险厌恶度越高。换句话说，资产所有者越厌恶风险，他就越想要确定的事情。效用函数越凹，投资者越厌恶风险。

在特殊情况下如果投资者偏好风险（Risk Seeking），则其效用函数变为凸函数，而不再是凹函数。如果投资者是风险中性的，则其效用函数为线性。这些情况很少见，大部分投资者都是风险厌恶者。

# 2.3 你有多厌恶风险？

风险厌恶程度会随着财富的改变而改变，对大多数个人来说，风险厌恶程度会随财富增加而减小——个人一般会在财务状况有保障后愿意承担更多风险。因此，我将讨论（相对）风险厌恶，这里风险厌恶程度是相对于财富来衡量的，为了简便起见，从现在开始我会省略“相对”一词$^{③}$。

C RRA效用函数采取以下形式：

$U(W)=\frac{W^{1-\gamma}}{1-\gamma}$ 公式 (2.1)

$\gamma$ 是资产所有者的风险厌恶系数。C RRA效用函数在资产组合选择理论中被广泛使用。C RRA效用函数非常有吸引力的一个特性是，通过它得出的组合权重并不依赖于财富规模：一个人管理1 000万美元还是1亿美元并不重要——其资产管理的技术完全一样——这是财富管理行业的可扩展性之美，至少对基金经理来说如此（该特性被称为财富同质性（Wealth Homogeneity））。在C RRA效用函数下，风险厌恶程度对所有财富规模来说都是相同的——因此这个效用函数的优势也会成为其内在的劣势，因为相对于同等获益的喜悦程度，投资者通常对损失的风险厌恶程度会更高（参见第4节）。不过，只用一个风险厌恶参数即可总结所有投资者行为，这会很省事。那么，投资者的风险厌恶水平如何呢？

$^{①}$ 或者 $U(E[X])\ge E[U(X)]$，这是Jensen不等式在凹函数时的结果。

$^{②}$ 从形式上看，存在一个由Arrow（1971）和Pratt（1964）定义为 $-L^{''}(W)/L^{\prime}(W)$ 的绝对风险厌恶系数，以及一个定义为 $-WU^{''}(W)/U^{\prime}(W)$ 的相对风险厌恶系数。请注意，这些风险厌恶系数的定义对于仿射变换是不变的，因为效用排序本身对于仿射变换是不变的。Levy（1994）的调查对象在他们变得富裕且其效用近似于C RRA时，表现出绝对风险厌恶系数递减的特点。
