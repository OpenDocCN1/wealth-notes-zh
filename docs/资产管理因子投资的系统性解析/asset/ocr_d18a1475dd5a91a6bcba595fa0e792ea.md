# 你是类似股票还是债券？

大量研究都试图估算人力资本收益与股票收益之间的关系。在总体层面——将美国所有劳动者或较大子集里的劳动者的收入全部加总作为一个代表性参与者——人力资本与股票之间的相关性很低。例如，Cocco，Gomes和Maenhout（2005）报告称，大学毕业生劳动收入与股票收益之间的相关性为-2%，只有高中学历的样本相关性为1%，对于高中以下学历的样本则为-1%。因此对平均投资者而言，人力资本更倾向于类似债券¹（也许“100减去年龄法则”终究还是对的，至少对平均投资者而言）。

早期的生命周期模型依赖于类似的估算²。它们假设平均劳动者的劳动收入是类似债券的，与股票的相关性较低，进而预测年轻人应该比老年人持有更多股票。它们还预测年轻人总是应该持有一些股票，且贫穷家庭应该比富有家庭持有更多的股票。为了理解后者，假设贫穷家庭与富有家庭有相同的风险特性，贫穷家庭的总财富更多是由人力资本所主导，因此，他们会通过在其金融资产组合中增加股票权重来抵消其类似债券的人力资本。

事实上，以上这些预测都与事实相反。
