# （3） 政治风险

资产所有者应该考虑的最后一个宏观风险是政治风险或主权风险。新兴市场的政治风险一直尤为重要：政治风险越高，则需要越高的风险溢价来补偿承担风险的投资 者。以前人们认为只有新兴市场需要担心政治风险。金融危机改变了这一看法，未来发达国家的政治风险也很重要。

# 3. 动态因子

CAPM模型的因子就是市场组合，而且投资者可以通过低成本的指数基金、交易所交易基金、股票期货来交易市场因子。其他有些因子也是可交易的，这些因子反映了宏观风险，并在一定程度上反映了经济体隐含的基本面风险。然而，有的宏观因子如通货膨胀、经济增长等通常并不是直接用于交易（至少规模不大，波动率除外）。因此动态因子的重要优势之一在于这些因子能比较容易地在投资组合中执行。

本书采用由Fama和French（1993）引入的、最著名的可交易多因子模型来阐述动态因子。我有时会交替使用“风格因子”“投资因子”和“动态因子”，业界也有很多人将这类因子称为“聪明贝塔”或“另类贝塔”。
