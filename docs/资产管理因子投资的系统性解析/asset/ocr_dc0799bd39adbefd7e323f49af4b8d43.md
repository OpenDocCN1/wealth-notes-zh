# 4.2  如何应对？

# 改变效用

我的第一个建议是不要使用均值—方差效用。投资者还会担心其他风险，他们关心相对表现，比如向邻居看齐或习惯效用，而且他们对损失的畏惧远多于获益的喜悦（关于更广泛的效用函数，参见第2章）。遗憾的是，我们缺少那种可以针对更加现实的效用函数输出最优组合的商业化优化器（至少撰写本书时我还没有发现），但已经有许多很不错的均值—方差优化器。如果你坚持（或被迫）使用一均值—方差效用，那么请做到以下几点。

# 使用约束条件

Jagannathan和Ma（2003）指出，加上约束条件会大有帮助。实际上，无约束条件的原始均值—方差权重很不稳定，以至于实践中使用均值—方差优化时总要加上约束条件。约束条件会有用是因为它们将无约束的组合权重拉回到经济意义上合理的水平。因此，它们可以被解释为一种将无约束的权重降低至合理数值的稳健估计量（robust estimator）。我们可以通过以下方法更普遍地做到这一点。

# 使用稳健统计量
