# 1. 失去的十年

2000年以来这十年对于股票收益来说是“失去的十年”。图8.1展示了2000年1月1日分别投资在标普500、美国长期国债、美国短期国债（我称之为现金）上的1美元截至2010年12月31日所能获取的累计收益。可以看到，股票业绩表现惨淡。股票收益从2000年后期开始下降，2001年9月11日的恐怖袭击事件以及接下来的经济衰退令股票收益持续下降。到2002年9月，初始投资在股票上的1美元累计损失超过40%。虽然股票收益在2005年前后有所反弹，但2007年随着次级抵押贷款情况恶化，股票又开始遭受损失，随后全球金融危机爆发，股票在2008年下跌了37%。随着政策制定者们维稳金融市场、经济状况开始好转，股票在2009年出现反弹。然而，截至2010年12月31日，十年前投资在股票上的1美元仅增长至1.05美元。投资者通过简单持有短期国债都能获取更好收益，初始投资的1美元在2010年12月31日已累计增长至1.31美元。而长期国债的表现远超股票和短期国债，初始投资的1美元十年后增长至2.31美元。
