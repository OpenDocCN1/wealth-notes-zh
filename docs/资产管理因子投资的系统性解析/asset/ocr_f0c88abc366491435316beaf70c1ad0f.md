# 1. 美国评级下调

2011年8月5日星期五，标准普尔公司将美国的信用评级从AAA级下调到AA+
级，评级展望为“负面”①。标准普尔公司担心美国政治风险，尤其是立法议员们
能否通过增收或减支的办法使本国不断增加的债务水平稳定下来，更不要提减少本国
债务了。该公司评论道，“我们认为在面对持续的财政和经济挑战时，美国政策制定
机构的有效性、稳定性和可预测性都出现了下降”。标准普尔公司从1941年起就将美
国评定为AAA级，此后从来没有将美国降级，即使在“二战”时也未曾改变评级。

8月8日星期一，是该决定公布后的第一个交易日，全球股市下挫。美国国债价格上
涨，在图9.1中可以看到美国十年期国债收益率上周五收盘时为2.58%，周一收盘时降
至2.40%，8月12日周五收盘时继续下降至2.24%。
