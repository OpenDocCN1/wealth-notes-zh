无关性结果强调了资产所有者最优组合的重要性。如果不先确定资产所有者的最优组合是什么，我们就无法讨论基金管理人与资产所有者之间的代理关系。在第14章中，我们已经知道这必须建立在因子风险的基础上。因此，有两种决策是不能委托给代理人的：能承担的风险水平以及可利用的风险溢价主要来源，这两点都取决于投资 者的特征及其负债、收入和财富情况（参见本书的第一和第二部分）。正确选取基准 是第一步，这样代理问题造成的所有偏差都可以相对基准来衡量。

无关性结果指出，即使我们给定资产所有者正确的基准，如果采用线性契约来支 付基金管理人，那么该基准对于基金管理人的行动来说也是无关的。但我们可以给定 代理人一个不同的基准。

# ### 3.3 基准的最优设计

解决无关性结果的方法之一便是使用更有效的（smarter）基准。在简单的 Stoughton-Admati-Pfleiderer研究设定中所使用的基准是简单、静态的资产类别基准、比如传统的标普500指数。如果我们坚持采用线性契约，那么将静态基准改为更有效 的动态基准可能能够让我们雇到最好的代理人并使其最大程度地付出努力。这正是 Ou-Yang（2003）的研究所指出的$^{①}$。Ou-Yang创造出一个每种资产的数量占比都随时 间而变化的积极基准，而不采用每种资产数量占比都固定的被动基准。

第14章所讨论的因子基准正是如此。在动态基准中，资产数量份额会随时间而变化，这种随时间变化的属性被设计嵌入到因子基准中以最优地获取最大化因子风险敞口。尽管这与Ou-Yang研究设定中所预测的最优基准不完全一样（且Ou-Yang的最优基准可能很难计算），但总的概念是，如果要保留线性支付结构，我们应该改为给委托组合管理人设定更有效的动态基准。至少，从无关性结果中我们知道静态基准不会 为资产所有者创造任何价值。
