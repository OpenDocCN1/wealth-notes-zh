# 图10.12 *B*4*B*因子构建示意图

Frazzini和Pederson在构建*B*4*B*因子时，仅使用了两个贝塔值组合。他们别无选择。在图10.10中，第一个贝塔值组合的事前贝塔值接近于零。如果对该组合加杠杆的话，组合敞口将会趋于无限大。因此，构建*B*4*B*因子时可供他们选择的贝塔值组合数量非常有限——最多二至三个。这里可以看到波动率组合的一个优势，即它们可以直接被交易而无需引入无风险资产，因为各波动率组合的波动率、预期回报率都有比较明显的差异。
