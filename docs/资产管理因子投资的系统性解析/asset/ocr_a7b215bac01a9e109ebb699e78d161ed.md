# # 3. 均值一方差效用

根据均值一方差效用，资产所有者只关心（他们喜欢的）均值和（他们不喜欢的）方差。均值一方差效用将不利情景定义为低均值和高方差。

均值一方差效用由以下公式给出：

```
$$U = E(r_{p}) - \frac{\gamma}{2} \text{var}(r_{p})$$ 公式（2.4）
```

其中 $r_{p}$ 是投资者的组合回报率， $\gamma$ 是风险厌恶系数。

均值一方差效用与CRRA效用密切相关（参见公式（2.1））。事实上，我们可以认为用CRRA效用和均值一方差得出的预期效用大致相同 ${ }^{(1)}$。因此，公式（2.4）中的 $\gamma$ 与2.3节中的风险厌恶有相同的解释，并且我们认为大多数投资者的 $\gamma$ 在1到10之间。公式（2.4）中的参数 $\frac{1}{2}$ 仅是一个换算系数，可被忽略。

均值一方差效用是投资行业的重要工具。Harry Markowitz在其1952年的开创性著作中引入这一概念，但直到1979年Markowitz才在与Haim Levy合著的一篇论文中详细阐释了在预期效用框架下运用均值一方差效用的合理性。Levy和Markowitz用均值一方差效用函数估计任意预期效用函数：

```
$$E\left[U\left(1+r_{p}\right)\right] \approx U\left(1+E\left(r_{p}\right)\right)+\frac{1}{2} U^{\prime \prime}\left(1+E\left(r_{p}\right)\right) \text{var}\left(r_{p}\right)$$ 公式（2.5）
```

其中 $U^{\prime \prime}\left(\cdot\right)$ 表示效用函数的二阶导数。效用函数都是凹的，因此它们的二阶导数为负，公式（2.5）中的第二项为负。公式（2.5）表示，投资者最大化其预期效用，大致等价于在给定方差水平下最大化其均值，故而公式（2.5）与公式（2.4）的均值一方差效用有相同形式。

公式（2.5）中Levy - Markowitz 用均值一方差效用作为对任何预期效用函数的近似估计，其逻辑在于回报率集中于何处（均值）以及它们有多分散（方差）是最重要的两个因素。如何在这两个因素之间进行权衡取决于投资者的风险厌恶程度，而这正是公式（2.4）中均值一方差效用的设置。均值一方差效用在投资行业中无处不在（值得庆幸的是，在学术界要少得多）。它已蒙受无情的批评，这确实没错，但尽管如此，均值一方差的建模技巧仍给我们带来了大量可以延伸到更复杂情景的启示。而且均值和方差的确是两个最重要的因素。其他因素通常也有影响—but遗憾的是，均
