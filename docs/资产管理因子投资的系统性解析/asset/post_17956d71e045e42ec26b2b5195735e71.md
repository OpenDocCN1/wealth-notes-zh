
票价格，$P$，是未来股息贴现后的现值：

$$P = \frac{D}{E(r)-g}$$ 公式（8.2）

其中，$D$ 是下一时期的预期股息，$E(r)$ 是贴现率，$g$ 是股息的增长率。公式（8.2）是一个估值公式。如果保持 $D$ 不变，当前股票价格高是因为 $1/(E(r)-g)$ 低：要么是未来预期收益低，要么是未来增长高、或者两者都是。我们通常认为，高股价的出现是因为增长将会较高。例如，本书撰写之时，苹果公司（Apple Inc.，代码 AAPL）和脸书公司（Facebook Inc.，代码 FB）的高股价意味着这些公司未来的增长还会持续。但总的来说，高股价预示着低增长（这是价值效应，参见第7章）。

公式（8.2）中的 Gordon 模型可以等价地表达为：

$$\frac{D}{P} = E(r)-g$$ 公式（8.3）

这表示：高股息率是由于未来预期收益高，或未来增长低，或两者都有。我们也可以写成：

$$E(r) = \frac{D}{P} + g$$ 公式（8.4）

这表示：预期收益是股息率加上现金流增长率。公式（8.4）表明股息率应该可以帮助预测预期收益，金融界从 Dow（1920）就开始对此进行研究。

学术界研究了股息率的方差分解（variance decomposition），即通过对公式（8.3）的两侧求方差来计算。这样一来，我们可以将股息率的变动分解为由预期收益或贴现率 $E(r)$ 引起的变动、增长率 $g$ 引起的变动以及两者联动所引起的变动：

$$\operatorname{var}\left(\frac{D}{P}\right)=\operatorname{var}\left(E(r)\right)+\operatorname{var}(g)-2\operatorname{cov}\left(E(r), g\right)$$

对于后面的讨论，我们假设可以忽略协方差项，所以可写成①：

$$\operatorname{var}\left(\frac{D}{P}\right) \approx \operatorname{var}\left(E(r)\right)+\operatorname{var}(g)$$ 公式（8.5）

显然，股息率随着时间而变动。图 8.5 展示了 1900 年 1 月至 2011 年 12 月标普 500 的股息率和盈利收益率。两条数据线协同地移动，相关性达 73%。由于价格是出现在股息率和盈利收益率计算公式的分母中，当股票市场处于萧条时，这两个收益率通常较高，正如在大萧条时期、20世纪50年代早期、20世纪70年代末至20世纪80年代初以及2001年一样。2008年当股票在金融危机期间下跌时，股息率处于非常低的水平。但在这期间，盈利收益率则开始反向变动，因为金融危机导致盈利减少了很多，而股息支付不易变化。

“什么驱动着股息率的变动？”其实与“什么可以预测收益？”是一样的问题。假设现金流是不可预测的，或者是独立同分布的（i.i.d.），那么在公式（8.4）中，预期收益可以用股息率来预测：当股息率高或价格低的时候，未来的预期收益就高。公式（8.5）表明，股息率的所有变动都是由贴现率变动所驱动。现在假设所有股息都来自现金流且贴现率为固定值，公式（8.4）表明，如果我们能预测公司的未来现金流，那么预期收益会随时间而变化，公式（8.5）则表明股息率的所有变化都来自于变化的现金流。

股息率的变动究竟是由于贴现率变动，还是现金流变动还是两者都有呢？学术观点上对此仍有分歧。John Cochrane于2011年在美国金融协会（American Finance Association）作主席演讲时给出了一方观点，他指出，股息率的所有变动都来自预期收益，而不是现金流。由于Campbell（1991）和Cochrane（1992）的研究，这一观点曾在金融界较为盛行，尽管同时期持异议者认为收益是不可预测的（例如，1993年的Goetzmann和Jorion）。Campbell–Cochrane的观点是，股息是独立同分布的，股息率预测预期收益，而不是预测未来现金流。然而，在Bansal和Yaron（2004）解释股票溢价的研究框架中，则是完全相反的情况。根据Bansal和Yaron的理论，几乎所有股息率变动都来自于现金流，实质上并没有贴现率作用¹。根据公式（8.4），风险溢价仍然是可预测的，但它们仅由可预测的现金流来驱动。

我也参与了上述学术研究，但与像Cochrane那样的对贴现率可预测性深信不疑的人不同，我的研究发现了现金流可预测性的存在①。在Ang和Liu（2007）的研究中，我指出，由于股息率和股票收益波动率都随时间而变化（也可参见下面第6节），那么风险溢价一定也有可预测的部分。总的来说，我认为事实真相是介于Cochrane和Bansal–Yaron两种极端观点之间：现金流和贴现率的可预测性都存在，但很难同时发现它们（参见下文）。

投资者应该从中获取的信息是，股息率会随时间而变化，因此预期收益和现金流是可预测的。按照贴现率说法，低价格意味着未来有高收益，低价格时期是买入股票的好时机。根据现金流说法，如果我们能够预测到未来有高现金流，那么我们会愿意持有股票。一个聪明的投资者或许能利用这些信息来获利。

## 5.2 理论表明随时间变化的股票风险溢价很难估算

理论表明股票风险溢价是可预测的，但理论同时也指出可预测性很小。因此，很难从统计上通过数据发现可预测性，更难据此进行交易。

### 可预测性回归

一种常见的用于捕捉可预测性的统计模型是可预测性回归（predictability regression）：

公式（8.6）

$$r_{t+1}=c+b^{*}X_{t}+\epsilon_{t+1}$$

其中，$r_{t+1}$是市场超额收益，$X_t$是一系列预测变量。预测变量的范围包括从经济学上很直观的因子（比如宏观因子）到更深奥的变量（比如基于推特（Twitter）或脸书（Facebook）的情绪因子）②。在回归公式（8.6）中，可预测性的强度是由预测系数$b$的统计显著性来衡量。计量经济学家喜欢看得到高的$t$统计量，或者是低的$p$值，他们使用$5\%$的$p$值作为“统计上显著”的标准临界值。如果将收益和预测变量都标准化，即设为均值为0、方差为1，那么$b$代表一个预测变量当前和下一时点收益之间的相关性。在这种情况下，回归$R^2$就是相关系数的平方，$b^2$。

我们还关注长期限可预测性（long-horizon predictability），这可以通过将回归公式(8.6)的左侧扩展为多个时期的收益来进行统计测量。我们采用对数收益，这样可以进行加总。例如，对于三期超额收益，我们得到：

$$r _ { t + 3 } + r _ { t + 2 } + r _ { t + 1 } = c + b \cdot X _ { t } + e _ { t + 3 , 3 }$$ 公式(8.7)

由于数据有限，我们通常采用重叠数据来进行长期限回归。也就是说，当我们在 $ t + 1 $ 时点考虑预测未来三个时期收益的变量时，我们预测的是从 $ t + 1 $ 到 $ t + 4 $ 时点的一期超额收益，即 $ r _ { t + 4 } $ 、 $ r _ { t + 3 } $ 和 $ r _ { t + 2 } $ 。因此，考虑公式右侧变量分别在 $ t $ 和 $ t + 1 $ 时点的两个回归公式，我们发现公式左侧的一期收益 $ r _ { t + 3 } $ 和 $ r _ { t + 2 } $ 会在这两个公式中出现重叠。这种重叠体现在公式(8.7)中用复杂符号 $ e _ { t + 3 , 3 } $ 代表的残差中。该符号表示：残差是在 $ t + 3 $ 时点实现的，但其涉及了过去三期的收益（下标中的第二项，即3）。重叠数据结果会带来一些非常麻烦的统计特点，导致常规的普通最小二乘法统计推断严重高估了数据所具有的真实可预测性。这不仅对那些爱钻研的计量经济学家来说是个问题，而且对投资者也有很大启示，正如我们下面将看到的。

我们应该预期有多大的可预测性呢？并不大。Ross (2005，2012)和Zhou (2010)研究表明，预测回归公式(8.6)中的 $ R ^ { 2 } $ 应该很低。从技术上，Ross和Zhou证明了回归 $ R ^ { 2 } $ 的界限是定价核的方差（参见第6章），而定价核的输入因子，比如消费，通常波动性不大¹。Ross计算的界限是8%，而Zhou给出的界限更低。我们应该预期 $ R ^ { 2 } $ 很低，通常低于5%。也就是说，95%的市场变动应该是不可预测的，任何一个声称可以用高 $ R ^ { 2 } $ 预测未来收益的投资策略都非常值得怀疑。这种低可预测性与第6章中Grossman和Stiglitz (1980)提出的近有效性市场相一致：能赚钱的市场择时策略极少，而且统计上也很难被发现。

数据证实了这点。实证上，很难找到稳健的统计证据来证明可预测性。表8.2列出了期初不同预测变量所预测的下一时期收益的相关系数。测量的基本单位是一个季度，所以回归公式(8.6)中的下一时期收益就是跨下一个季度。我也按一年期、两年期、五年期进行了公式(8.7)中的长期限回归分析，这些结果也用相关系数表示如下。表8.2还列出了可以解释重叠观测值问题以及随时间变化的波动率问题的稳健 $ t $ 统计量，这些问题也导致常规普通最小二乘法太过频繁地拒绝可预测性的零假设²。表8.2考虑了学术研究中的各种变量，包括宏观变量、利率和利差以及历史超额收益。

### 警惕长期限R^2

很多评论者声称数据中有大量证据证明了长期限可预测性，而表8.2并未证明这点。长期限可预测性确实存在，但再次强调的是，它很难被发现。你不能采用标准R^2测量值来进行长期限的统计推断。公式（8.7）中的重叠观测值导致长期限R^2被极大地夸大了；简单的R^2看上去能体现很强的可预测性，但实际上并非如此。比如，以股息率与未来五年期超额收益的相关性为49%为例，这意味着R^2 = (0.49)^2 = 24%。这个数看上去很大，尤其是在金融理论预测认为回归R^2应该接近于零的情况下。

投资者不能太过相信长期限R^2值，因为它们具有欺骗性。也就是说，虽然真实的可预测性很低（我们称为总体的可预测性小），但小样本的回归R^2会大得多。这里所说的小样本可以是几百或几千年。这种欺骗性效果的直觉逻辑即，公式（8.7）中观测到的重叠值人为地引入了依赖性——从t到t + 3时点的三期长期限收益与从t + 1到t + 4时点的三期长期限收益之间有两个时段重叠——而这个问题会随着时间期限的拉长而变得更为严重³。包括Vallkanov（2003）及Boudoukh、Richardson和Whitewlaw（2008）在内的一些研究推导出了正确的小样本R^2分布，并指出它们有很大的向上偏差；采用
