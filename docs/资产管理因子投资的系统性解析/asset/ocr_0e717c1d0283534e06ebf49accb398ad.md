# 长期投资其实是短期投资

对长期投资另一个常见的误解是，由于投资期限长，因此长期投资者本质上不同于短视的短期投资者。Alfred Rappaport（2011）认为，长期投资者的行为方式应当与短期投资者完全不同。通过动态规划的求解可以看出，这种说法是明显错误的。动态规划通过将长期组合选择问题看作一系列的短期投资决策问题来求解。也就是说，长期投资者在本质上应当被视作短期投资者。他们可以做短期投资者能做的所有事情，并且由于他们有更长的投资期限，因此他们可以做得更多。通过间接效用函数，我们可将长期投资期问题拆分为多个单一投资期的最优化问题进行求解（参见公式（4.11））。我的意思并不是长期投资者应该将其行为“短期化”（Short Termism），即那些通常发生在只着眼于眼前业绩的公司管理者和投资者身上的短视行为①。动态规划的解法表明，要想成为一名成功的长期投资者，你首先应该从成为一名成功的短期投资者开始。然后，再利用更长的投资期限所带来的各种优势。

现在我将讨论一个重要案例，在该案例中长期投资者和短期投资者并无差别。该案例恰好在实证层面最为相关，并且是所有长期投资策略的基础。

# 2.4 再平衡策略

假设收益率是不可预测的，或投资机会集是独立同分布的（i.i.d.）。独立同分布的假设非常符合真实情况。我们将在第8章说明，资产收益率很难预测。我们可以这样来理解独立同分布假设，资产回报率就像若干次抛硬币，唯一的区别在于抛硬币只有两个结果（正面朝上或背面朝上），而资产收益率可以有很多结果。抛硬币的结果即是独立同分布的，因为当前这次抛掷出现正面或反面朝上的概率并不依赖于以前若干次抛掷的结果。这同样适用于资产收益率：当资产收益率独立同分布时，每期收益率都是来自相同的概率分布，当期收益率与之前若干期的收益率是互相独立的。在独立同分布的假设下，资产收益率就像是“升级版”的抛硬币。
