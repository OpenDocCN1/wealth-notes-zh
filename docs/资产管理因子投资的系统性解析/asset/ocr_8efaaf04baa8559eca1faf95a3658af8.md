偏差校正。他们估计，校正后的房地产平均收益率从1.7%减至0.3%，标准差估计增加1.5倍。房地产收益的平均值较小，这是由于其样本期为1984年至2001年，期间包括了20世纪90年代早期和21世纪初的房地产下行阶段。样本期错过了房地产在2005年或2006年前后的牛市阶段。

# 3.5 小结

对待已公布的非流动性资产收益率需要非常小心。幸存者往往有着高于平均收益的低频观测值，而且非流动性资产的收益率具有只在估值较高时才会被公布的倾向，这些都会造成估计的收益率过于乐观，且风险被低估。简单来说，已公布的非流动性资产收益率太过优异而有失真实。

# 4. 非流动性风险溢价

非流动性风险溢价是对投资者无法立即获取资本的补偿，也用于补偿投资者在流动性危机时期赎回流动性的风险。

获取非流动性风险溢价

资产所有者能够获得非流动性溢价有以下四种方式：

+   ①对非流动性资产类别设定一个被动的配置比例，比如房地产。

+   ②在某资产类别内选择流动性更差的证券，也就是与流动性选券相结合。

+   ③作为某种证券类别的做市商。

+   ④在总组合层面上运用动态策略。

经济学理论认为因为投资者承担了非流动性风险而相应获取非流动性风险溢价，尽管溢价可能很小 $ ^ { ①} $。在非流动性风险对价格的影响很小或没有影响的模型中，不同个体之间的非流动性变得模糊。某特定个体可能会受到非流动性的影响——非流动性会抑制他的消费或影响他的资产持有（正如我在下文提到的包含非流动性风险的资产配置模型）——但其他市场参与者并不会受到限制，或者他们可以在不同时间进行交易。
