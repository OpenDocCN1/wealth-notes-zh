验结果。理论研究表明风险—收益关系确实可以为负，而且可以随时间而变化¹。但无可争议的是，当波动率显著上升时，资产往往发生损失。只有那些能在高波动率期间承受得住巨大损失的投资者，才应该考虑卖出席动率保护。

# 2.4 其他宏观因子

还有文献对其他宏观因子进行了广泛研究，值得资产所有者关注。

# （1）生产率风险

宏观经济学所发展的一系列真实经济周期模型，试图解释宏观变量（如经济增长、投资和储蓄）与资产价格在经济周期中的变动。在这些模型中，宏观变量和资产价格会随着经济周期而变化，这是企业和市场参与者对真实市场冲击做出的理性调整。真实经济周期中的“真实”一词重在强调经济周期是由真实冲击所造成的，而不是像John Maynard Keynes（1936）模型中提到的由于市场失效或需求不足导致的。真实经济周期模型中也有通货膨胀，但通货膨胀是中性的或者说并无真实影响。这些模型描述的是生产经济（production economies），因为其中除了涉及市场参与者的最优化消费和储蓄决策，还涉及企业的最优化实物商品生产，但企业面临着会影响其产出的市场冲击。影响企业产出尤为重要的冲击之一即生产率冲击。早期文献如Kydlund和Prescott（1982）未包含资产价格（Kydlund和Prescott于2004年获得诺贝尔经济学奖），下一代模型如Jermann（1988）则涵盖了资产价格。最新研究如Kaltenbrunner和Lochstoer（2010）还对真实、复杂、动态的冲击和市场参与者行为进行了研究。
