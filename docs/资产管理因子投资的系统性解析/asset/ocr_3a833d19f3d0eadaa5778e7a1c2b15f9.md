# 隐性费用

虽然有40法案的披露要求，仍然有几种重要的费用是不为投资者所见的。基金不包括交易成本，基金的开支比率内也不包括交易成本。但是较高的交易成本会减少投资收益。**交易成本包括：**

+   ① 佣金：买卖证券的经纪费用必须披露，但不在基金的招股说明书里。
② 买卖价差：卖方的最低卖出报价和买方的最高买入报价之间的差额。
③ 市场影响成本：大额交易会改变市场价格。这种成本虽然是隐性的，但可能超过佣金和买卖价差。

交易成本很高。Edelen, Evans和Kadlec（2007）研究估计，交易成本约为1.4%，甚至超过了积极型基金收取的费率。交易成本与交易额成正比，交易得越多，交易成本越高。Carhart（1997）和一些随后的研究显示投资换手率越高的基金业绩越差（这也是投资于指数型基金另一原因）。

在2012年，Janus Worldwide的投资换手率为49%，Janus Global Research的投资换手率为67%。Janus Worldwide在合并后消失，因此该基金的投资者现在须支付更高的Janus Global Research的交易费用。该基金的换手率低于80%~90%的积极股票型基金的平均水平。但是，一支指数型基金的换手率一般低于5%。
