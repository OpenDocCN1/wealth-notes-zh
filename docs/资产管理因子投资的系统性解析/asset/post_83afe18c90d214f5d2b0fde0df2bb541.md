
收益率短期国债的安全性（这些投资者的最优贝塔值低于1）。如果投资者的风险偏好程度高于市场先生，那么他们将获得比市场组合更高的平均收益。这些投资者比平均投资者能更好地经受住不景气时期带来的损失，所以能获取更高收益（比市场先生风险承受能力更高的投资者所持组合的贝塔值大于1）。因此，投资者持有较大或是较小的市场因子风险头寸，取决于其与市场先生相比是更偏风险厌恶型还是风险偏好型。在均衡状态下，比市场先生风险厌恶程度更高的投资者会与比市场先生风险厌恶程度更低的投资者相互平衡。

CAPM模型为如何构建最优因子组合提供了方向，即最优因子组合就是对所有风险资产进行市值加权后的组合（当然是指市场因子）。这点现在看起来很简单，但在20世纪60年代早期CAPM模型刚被推导出来时，还没有方法获取市场因子敞口。要感谢先锋集团（Vanguard）（参见第17章），散户投资者在等了二三十年之后终于可以通过低成本方式来获取市场因子组合。

## 价值—成长因子

我们采用价值—成长因子来举例说明动态因子配置。

关于价值—成长溢价，市场上主要有两种理论。理性学派将价值股表现不如成长股时界定为不景气时期。如第7章阐述的，有些解释描述了市场组合表现不佳的情形（这是有条件的CAPM模型），如果市场表现欠佳已经让你变得小心翼翼的话，那么你显然应该远离价值投资。这一情形曾在2008年和2009年上演。其他理性解释则采用低投资增长或长期消费增长水平较低来界定不景气时期。当这些情形发生时，你要问问自己相对于市场而言，是否能更好地承受住价值策略带来的损失。如果答案是肯定的，那么价值—成长策略就适合你。

行为学派则认为，由于投资者过度专注于飞速增长的成长型股票而忽视了价值型股票。投资者将过去的高增长过度外推至未来，这导致他们会高估未来的增长机会。过去高增长的股票往往已价格高企，因此价值股相对便宜。根据这种推理，你是否还会青睐于因近期表现好而备受新闻关注的热门股？如果答案是肯定的，那么你并不适合价值投资。相反，如果你能投资于不受青睐或陷入困境的股票，那么价值投资可能适合你。

这种方法不同于粗糙地将价值—成长因子放入均值—方差优化器中。我们以资产所有者的需求和特征为出发点（按照经济学家的术语，即投资者的效用函数）。我们将投资者面临的不好结果与价值因子所界定的不景气时期进行对比。这需要从经济学逻辑上去理解为什么存在这些风险溢价，而不仅仅是统计上的优化过程。因子策略的合适性取决于投资者能否比平均投资者更好地忍受因子的不景气时期，或者他与平均投资者相比有何行为差异。

## 3.5 小结

因子投资需要投资者与平均投资者相比，看其分别如何应对不景气时期。如果你是平均投资者——平均投资者并没有什么不好——那么就持有市场组合。如果你不同于平均投资者，则有可能向动态因子风险敞口倾斜。你持有的因子头寸会在不景气时期带来损失，但你对损失的容忍度比典型投资者更好。或者，你也可能持有负的因子头寸，这相当于购买保险来防止因子损失。

## 4. 动态因子基准

动态因子其实是指会随着时间而变化的非市值加权的头寸组合。不同于CAPM模型，业界并无唯一方法来构建最优化动态因子组合。

### 4.1 构建原理

有三只股票分别被称为“价值股”、“中性股”和“成长股”，其市场权重分别为20%、50%和30%[^1]。假设这是市场上唯一能交易的三只股票，而且我们是根据股票价格相对其基本面价值之比来进行上述分类。我们通过做多价值股、做空成长股来构建价值一成长因子。假设理想组合是100%的股票组合伴随有5%的价值一成长因子敞口。最优化基准就是市场组合再加上价值一成长因子：

表14.1

| | 市场组合 | 价值一成长因子 | 基准组合 |
|---|---|---|---|
| 价值股 | 0.20 | 0.05 | 0.25 |
| 中性股 | 0.50 | | 0.50 |
| 成长股 | 0.30 | -0.05 | 0.25 |
| 加总权重 | 1.00 | 0.00 | 1.00 |

[^1]: 摘自Ang, Goetzmann and Schaefer（2009）论文的第IIIB部分。

价值—成长因子能捕捉价值股和成长股之间的收益差异，是一个多空组合（按行话，.txt是个零成本的模拟组合）。价值—成长因子敞口的权重为0.05，这是由投资者选定的。

理想组合是将市场权重根据价值—成长因子敞口相应调整后的组合。需要.txt注意的是最优组合并非市值加权组合；最优组合会超配价值股、低配成长股以达到期望敞口。实践中，如果价值—成长因子的敞口足够高，那么理想组合可能会有负的权重，这需要投资者对总组合进行动态的杠杆操作。

现在假设价值股表现很好，所以新的高价格使其成为了中性股。“新中性股”（旧价值股）的市值权重从之前的0.2上升为0.4。旧中性股随着价格下跌其权重也相应从50%降为30%，成为“新价值股”。成长股仍保持其初始特征——仍是成长股因此其权重仍与初始的30%一致。价值—成长因子相应有变化：它剔除了旧的价值股（现在是中性股），加入了新的价值股（之前是中性股）。现在的组合如下：

表 14.2

| | 市场组合 | 价值—成长因子 | 基准组合 |
| :--- | :---: | :---: | :---: |
| 新中性股（旧价值股） | 0.40 | | 0.40 |
| 新价值股（旧中性股） | 0.30 | 0.05 | 0.35 |
| 成长股 | 0.30 | −0.05 | 0.25 |
| 加总权重 | 1.00 | 0.00 | 1.00 |

最优组合反映了这种变化。纯市场组合基准不做将动态价值—成长效应纳入考虑的再平衡。但因子基准会做这种再平衡。

上述简单例子尽管非常程式化，但表明了关于因子基准的三大要点：

- ① 价值—成长因子的期望敞口由投资者设定（此例中权重设定为5%）。
- ② 基准组合不再是简单市值加权，而是能反映投资者所期望的价值—成长敞口的组合。
- ③ 基准组合是“被动的”，因为它基于一系列系统性规则；但也是“动态的”，因为其构成会随时间不断变化。

所有大型指数商都在推出非市值加权指数，一些资产管理公司也是如此。比如Arnott，Hsu和Morre（2005）根据衡量基本面价值的多个变量赋予股票权重来构建组合，提供了获取价值溢价的一种方式[^2]。这些敞口并不由投资者直接决定，但可以作为获取动态风险溢价的第一步。真正的因子投资需要有针对具体投资者的基准，在指数业务中定制化已成为一种增长趋势。

[^2]: 参见Perold（2007）、Jun and Malkiel（2008）以及West（2010）的评论

### 4.2 通用汽车（GM）资产管理公司

动态因子涉及交易，因此最小化成本和换手率是构建因子基准至关重要的部分。大型投资者都已构建和交易其定制化的因子组合。

GM资产管理公司是其母公司养老金计划的基金管理人，其针对价值和动量因子构建了公司内部的动态因子组合 [^3]。GM资产管理公司的全球公开市场业务总监James Scott（2012）说，他们的方法与“Ang, Goetzmann和Schaefer（2009）所建议的在养老金总层面管理阿尔法和风险以及进行盈余计划管理是一致的”。

[^3]: 原文此处可能有脚注引用标记，OCR识别为“1”，根据上下文逻辑保留为脚注引用。

GM资产管理公司从机构投资者的可投资范围出发。他们不做任何成长股或表现不佳的股票——与市场权重相比，他们低配这些股票，或持有零头寸。他们采用账面价值/价格（Book/Price）、预期盈利/价格（Forward Earning/Price）、价格/销售额（Price/Sales）、过去12个月盈利/价格（Trailing Earnings/Price）以及过去12个月现金流/价格（Trailing Cash Flow/Price）的平均值来衡量基本价值。他们将动量定义为过去12个月的收益（遵循学术界的标准做法，剔除最近的一个月以避免反转效应）。组合按月度进行再平衡，并试图保持低换手率。因子组合只有少量的价值和动量敞口，这表明GM资产管理公司期望仅获取少量的因子敞口（他们的跟踪误差限制很严格）。他们构建了美国价值和美国动量组合，以及国际价值和国际动量组合。

GM资产管理公司采用这些内部因子组合作为其股票管理人的基准。管理人需要证明他们能创造除了从因子基准被动获取的收益以外的超额收益。他们运用下述回归公式来评价管理人：

$$ r_{active} = r - r_{mkt} = b_0 + b_1r_{mkt} + b_2r_{size} + b_3r_{value - growth} + b_4r_{momentum} + \varepsilon \quad \text{公式 (14.6)} $$

$r_{mkt}$ 是标准的市值加权基准，$r_{size}$ 代表规模效应（采用Russell 2000减去Russell 1000的差值），$r_{value - growth}$ 和 $r_{momentum}$ 分别代表其内部界定的价值一成长因子组合和动量因子组合的收益。系数$b_1$ 到$b_4$表示因子敞口，这样管理人的积极收益就包括真正的阿尔法$b_0$再加上由于市场、规模、价值一成长和动量敞口变动所带来的收益。

学术界将公式（14.6）视为Fama和French（1993） [^4]的产业界版本。GM资产管理公司认为市场、价值、动量是风险溢价的来源，并且他们能通过内部的指数因子组合来低成本地获取上述因子敞口。GM资产管理公司喜欢向价值和动量倾斜，但仍希望挑选到有选股技能、能创造超越因子敞口收益的管理人（他们希望看到 $b_{\mathrm{a}}>0, b_{\mathrm{b}}>0, b_{\mathrm{c}}>0$ ）。他们认为规模对风险溢价没有贡献，这与我们目前从数据中观察到规模效应不足的结论一致。他们还希望基金管理人不要承担额外的市场风险。因此，其他条件不变时，他们希望管理人有与基准相似的市场和规模敞口（ $b_{\mathrm{i}} \approx 0, b_{\mathrm{j}} \approx 0$ ）。

[^4]: 原文此处可能有脚注引用标记，OCR识别为“2”，根据上下文逻辑保留为脚注引用。

GM资产管理公司采用因子基准作为其挑选和评价管理人的工具之一。GM资产管理公司还发现他们的方法在股票总组合层面控制因子敞口方面也很有用。目前他们仅在公司内部使用这种工具，还没有将因子基准提供给他们的外部管理人。事实上，大多数组合经理会对包含价值和动量效应的给定因子基准感到极不舒服。也许大范围地采用因子基准会改变这一现象。

### 4.3 提高积极管理的门槛

我们可以采用因子基准来评价所有的管理人，而不仅限于像GM资产管理公司那样仅针对股票管理人。在理想的因子投资实施过程中，我们将为管理人直接提供定制化因子基准，而不再使用基于市场的被动基准。

比如，我们可采用以下方法来评价管理人：

- 采用股票市场因子 + 债券市场因子 + 流动性因子 + 信用因子来作为私募股权管理人的基准。CPIB是这么做的，只是目前他们仅采用前面两个因子。
- 采用债券市场因子 + 信用因子 + 波动率因子来作为公司债管理人的基准。如果我们能通过其他方式低成本地获取信用敞口，那么管理人应该创造出更多超额收益来证明其收费是合理的。
- 采用股票市场因子 + 价值一成长因子来作为价值型股票管理人的基准。GM资产管理公司现在是这么做的，只是还未将因子基准提供外部管理人。

将因子敞口纳入考虑后，我们会提高积极管理的门槛。我们愿意在积极管理人创造价值时向其支付可观的报酬（参见第15章），但必须确保积极管理人能比低成本的动态因子基准创造出更高的费后净收益。

### 4.4 风险一收益因子分析

因子配置的一个重要部分是分析组合收益在不同因子敞口上的分布。这使得高深的统计分析有了用武之地。许多投资者会对多头因子如股票和债券进行统计分析，即对选取的一些股债混合组合进行模拟测试，计算并分析不同组合的风险—收益特征。我们可以将这一过程扩展到动态因子配置。大多数投资者对下行损失的厌恶程度要大于对上行获利的喜欢程度（他们有损失厌恶效用函数，参见第2章），所以我建议集中关注对下行风险的衡量。

“教授的报告”通过对NBIM组合所暗含的因子权重，以及运用比NBIM在金融危机期间所隐含的更为保守或更为激进的配置，对上述观点进行了举例说明。因子配置所创造的收益通常是高度左偏的。也就是说，因子配置偶尔会导致极大损失。将这些潜在损失视为因子敞口大小的函数，使得投资者可以调整至其理想的因子风险头寸。

### 4.5 因子和治理

挪威基金几乎没人对因子非常重要且值得密切关注的观点进行争论。然而，一个主要挑战在于需要决定由谁来设定因子敞口。正如所有的投资策略决策，因子决策也离不开治理结构。

“教授的报告”建议资产所有者根据投资期来对因子进行分类，并在每一个投资期内设定合适的业绩回顾和投资策略。图14.7包含三种（简化的）投资期：短期、中期和长期 [^5]。大多数基金管理人，尤其是追求阿尔法的积极管理人，投资期较短且竞争激烈。下图的另一端，是通常由董事会、财政部、受托人或投资委员会所代表的资产所有者所设定的长期资产配置权重。对挪威基金和CPPIB而言，这就是由它们的最高层（分别是议会和董事会）所设定的长期股票—债券配置。

![](img/e2a8f768e844f37dcab93b54b9e826d9_483_0.png)

动态因子策略处于中间地带，因为它们的检验期通常为2～5年。比如说，价值策略在20世纪90年代末的互联网热中，持续跑输长达5年之久。许多短期资产管理人可以收获因子风险溢价（有时伪装成阿尔法）。如果资产所有者不清楚其因子敞口，那么当因子表现不佳时他会感到意外和愤怒——正如挪威公众对NBIM那样。因子基准则不会因为因子本身业绩不佳所造成的损失而惩罚管理人。

如果资产所有者选择对其部分组合设定因子敞口，那么他们也会受益于显性的因子基准。丹麦最大的养老基金ATP集团，负责为大部分工作的丹麦人提供养老金。ATP将其金融资产划分为对冲组合和投资组合，对冲组合被用来匹配该基金的负债，而投资组合的目标是“创造能充分保持养老金长期购买力的绝对收益”[^6]。投资组合又被划分为不同的风险类别：利率、信用、股票、通胀挂钩资产以及大宗商品。ATP对上述因子进行再平衡以维持大致的风险配置（ATP实践采用了一种风险平配的形式，参见第3章）。ATP也进行因子择时操作。因子基准使得ATP能够进行逆周期投资，所以当一种因子策略变得有吸引力时其因子敞口会相应上升。

如果资产所有者和基金管理人都不对图中灰色区域的中期动态因子负责的话，问题就会出现。比如，许多资产所有者刚好在2008年巨大损失发生之后就放弃了波动率策略，这本来是逆周期投资者增加敞口的最佳时点（参见第2章和第4章）。与所有动态因子相似，将波动率风险因子引入基金的总基准，能增强资产所有者在长期致力于投资因子策略的能力。

## 4.6 小结

因子投资可以生成最优的非市值权重指数。投资者应该能以低成本方式投资因子组合，并根据投资者具体情形和特征来定制化他们的因子敞口。资产管理行业的创新正带领我们接近这种最优状况。

## 5. 宏观因子投资

目前为止我们探讨了投资型或风格型的因子投资，因为上述因子都是可交易的投资策略。因子投资的另一种方法是基于（非交易型的）宏观因子。这在学术上较清晰，但执行操作起来难度更大。

这是因为资产类别并不会随着宏观因子而对应变化，事实上，资产类别的很多变动是反常的或至少是有悖直觉的。比如，股票是对实物资产的所有者权益，但其追踪通货膨胀的能力极不足（参见第8章）。房地产有相对更好的抗通胀作用，但仅仅部分“实际”（参见第11章）。债券价格反映了通货膨胀风险，但其他因子如货币政策风险和非流动性风险是长期债券的重要驱动力。

### 学术模型

运用宏观观点需要一个关于宏观因子如何同时影响多种资产类别的分析框架。Ang和Ulrich（2012）给出了一种能用于宏观因子投资的模型。该研究创立了实际债券、名义债券和股票是由两大宏观因子——通货膨胀和经济增长，以及用于捕捉美联储如何制定货币政策的因子来共同决定的一种模型。比如，如果发生通货膨胀冲击，该模型会显示所有资产价格将如何变动。宏观因子能解释预期收益的大部分变动；比如，经济增长能解释股票风险溢价变动的60%，而预期通胀能解释实际利率变动的40%和名义利率变动的90%。

### 桥水基金

大型对冲基金桥水基金（Bridgewater Associates）创立了关于宏观因子如何影响资产价格的实践框架。如图14.8所示，桥水的全天候策略将通货膨胀和经济增长作为宏观因子。尽管桥水在金融危机期间偏离了其最初想要执行的策略，但仍值得我们对总体框架进行分析。桥水估计了不同资产在经济增长高或低时或者通货膨胀上升或下降时分别会如何表现。他们运用一个2×2的矩阵来对应上述情景。如图14.8所示，他们预期当经济增长和通货膨胀同时下降时，名义债券表现良好。相反的，当经济增长高、通货膨胀温和时，股票表现突出。这与Ang和Ulrich（2012）所创立的正式模型相比显然简化了许多，但理念是一样的：我们试图了解宏观因子变化时各资产会如何反应。

### 阿拉斯加永久基金公司

表14.3显示了阿拉斯加主权财富基金的资产配置情况，官方名称为阿拉斯加永久基金公司（Alaska Permanent Fund Corporation），其资金来源于矿物租赁收入和矿区使用费 [^7]。根据对不同宏观因子风险的反应，阿拉斯加基金将资产类别划分为不同组。公司敞口类包括股票，股票通常“会受益经济增长和繁荣时期”。公司债也属于公司敞口类——而不在单独的固定收益配置中。第9章指出，很多影响股票的因素也会影响公司债——如果一家公司表现不佳，其债权人和股权人都会受到影响。相应减去美国短期国债收益后的公司债收益和股票收益的相关性很高：股票与投资级公司债的相关性为48%，与高收益债的相关性为65%。阿拉斯加基金不将公司债和股票视为单独的资产类别，因为它们对宏观风险的反应一样。

[^7]: 原文脚注标记

阿拉斯加基金有意思的另一原因，是其遵循本书第4章提到的Merton（1971）模型对长期投资的论述。阿拉斯加基金有一个投资类别叫特殊机会，其目标配置是18%。长期投资者会持有对短期投资者而言最优的组合，这被称为短视组合（myopic portfolio）；也会持有机型组合（Merton称其为长期对冲需求组合），即长期投资者会充分利用随时间变化的预期收益。当有困境资产特殊投资项目时，或者有好的非流动性投资机会时，阿拉斯加基金能利用这些机会因为其投资期较长，这些投资归于其特殊机会资产配置。如果市场上没有此类有吸引力的投资机会，那么尚未投出的配置就会归于公司敞口资产类别中。
