场因子是系统性的，会影响所有资产。市场风险溢价是投资者风险厌恶程度和效用变量的函数。也就是说，市场因子的风险溢价反映了经济体中所有人的总配置。我们后面介绍的其他因子——如可交易因子中的价值—成长因子和波动率因子，或宏观因子中的通货膨胀和经济增长因子——这些因子的风险溢价还基于投资者特性、资产范围以及经济体的生产能力。只有当经济体发生根本性改变时，这些因子才可能会消失。均衡的因子风险溢价不会消失，因为市场上总有聪明的对冲基金在进入和交易——不过这类投资策略本身并非因子。市场因子和其他系统性因子不会因为投资者套利而消失。

# 3.2 CAPM结论2：投资者有各自的最优因子风险敞口

如图6.1所示，所有投资者都将持有市场组合，只是持有比例不同。投资者在CAL线上不同位置持有不同比例的无风险资产和市场组合（参见第2章和第3章）。因此，每个投资者都有不同的因子敞口，正如不同个体会有不同的营养需求。

# 3.3 CAPM结论3：平均投资者持有市场组合

市场组合代表了不同投资者的平均持仓。如图6.1所示，CAL和均值—方差前沿的相交点代表的是某持有100%MVE组合的投资者。这个切点代表了平均投资者。100%持有该组合头寸的投资者 的风险厌恶程度就是市场的风险厌恶程度 $ ^{\text{①}} $。

值得注意的是，那些不同于平均水平投资者的投资人，会根据其自身风险偏好而承担更多或更少的市场因子风险。我们将在第14章阐述因子投资时对此展开探讨。
