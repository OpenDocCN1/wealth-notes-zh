情况进行了估计<sup>①</sup>。截至2009年6月，各州已累计约5.7万亿美元养老金债务，而州立养老金计划的资产总额尚不足2万亿美元。这是一个超过3万亿美元的黑洞，比各州发行的流通在外可公开交易的债券总额高出三倍。市立养老金计划的情况更为糟糕。Novy-Marrx和Rauh研究了各主要县市最大的养老金计划，估计每户家庭的养老资金缺口合计7000美元。

作为美国退休体系的第一支柱，社会保障自身也存在资金不足的问题。美国社会保障总署（Social Security Administration）估计社会保障基金将于2033年全部用完，此后年度工资税仅能覆盖社保基金承诺义务的75%，还需要8.6万亿美元资金才能覆盖已有的全部义务<sup>②</sup>。这相当于80%的美国国债总额（2012年年末达到11万亿美元）。养老金承诺可以说是非常昂贵，尤其是当提取金额与通货膨胀挂钩时，社会保障就是这种情形。大都会人寿（MetLife）估算过，为一对60岁的夫妇按社会保障最高标准支付退休金将会花费约120万美元<sup>③</sup>。

因此，尽管美国的养老金资产总额达到了国内生产总值的70%，但规模必须变得更大，才能充分满足养老金负债。如果不这样的话，那么就是养老金承诺太过慷慨。从长远来看，不管是哪种情况，资产和负债必须相等。
