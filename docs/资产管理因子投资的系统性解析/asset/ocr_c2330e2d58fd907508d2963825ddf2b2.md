# 2.1 阿尔法的定义

阿尔法是超过基准收益率的平均回报率。因此，阿尔法的概念首先需要我们界定一个可以用来衡量阿尔法的基准。

我们将超额回报率r_t^{ex}定义为某资产或策略的回报率超出基准回报率的部分：

```
$ r_{t}^{ex}=r_{t}-r_{t}^{bm k} $ 公式 (10.1)
```

$r_{t}$是某资产或策略的回报率，$r_{t}^{bmk}$是基准回报率。有时我们将超额回报率$ r_{t}^{ex}$称为积极回报率 (active returns)。该术语假设基准回报率是可以被动 (passive) 获得的，即不需要任何特别的投资知识或者人为干预就可以获得。常见的被动基准是市值加权组合，如标准500指数或者罗索1000指数，投资者可以通过购买低成本的指数型基金来跟踪基准。

我们将公式 (10.1) 中的超额回报率取平均值从而得到阿尔法：

```
$\alpha=\frac{1}{T} \sum_{t=1}^{T} r_{t}^{ex}$ 公式 (10.2)
```

其中，T是指样本区间内的观测值数量。

另外两个需要定义的术语是跟踪误差 (tracking error) 和信息比率 (information ratio)。跟踪误差是超额回报率的标准差；它用以衡量投资策略回报率相对于基准回报率的分散程度：

```
Tracking Error $=\overline{\sigma}=s d e v\left(r_{t}^{ex}\right)$ 公式 (10.3)
```

跟踪误差限制可以确保管理人不会过度偏离基准 (参见第15章关于委托资产管理的代理人问题)。跟踪误差越大，管理人的自由度越大。如果基准是经过风险调整的，学术界常将这种跟踪误差称为“非系统性波动率” (idiosyncratic volatility) (参见本章第3和第4节)。

信息比率是阿尔法与跟踪误差的比值：

```
Information Ratio $=IR=\frac{\alpha}{\sigma}$ 公式 (10.4)
```
