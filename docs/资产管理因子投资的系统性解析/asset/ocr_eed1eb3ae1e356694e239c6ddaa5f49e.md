# 类似债券的人力资本

一个年轻人在他事业的起步期，可能只持有很少的金融财富。这时他拥有的更多是勇气、韧劲和才能：即人力资本。如果他的人力资本类似债券，那么他的金融财富组合应该抵消其人力资本债券头寸，而更多地配置股票。我们首先考虑极端情况，假人力资本等同于无风险债券。假设我们用 $ H + W $ 来代表年轻人的总财富，包括人力资本和金融财富的总财富平衡表可表述为：

| 年轻人 |  |
| :--- | :--- |
| 人力资本（债券） | $800000 |
| 金融财富：股票 | $200000 |
| 金融财富：债券 | $— |
| 合计 | $1000000 |
| 总财富中股票的比例 | 20% |
| 金融财富中股票的比例 | 100% |

假设该年轻人想在包含人力资本和金融财富的总组合里持有20%的股票，由于他的人力资本等同于债券，这就意味着他在金融财富组合里只会持有股票，而没有债券。我们可采用图5.3-A的饼状图代表他的资产状况。尽管年轻人持有的股票占总财富比例为20%，但其股票占全部金融财富的比例为100%。如果人力资本是类似债券的，年轻人应该持有很 大比例的股 票。

现在考虑当这个人变老了并接近退休时的情况。我们假设其总财富不变，仍是$1000000，但现在总财富的大部分都是金融财富。投资者在他工作过程中将人力资本转化为金融资本。他的资产状况变为：

| 老年人 |  |
| :--- | :--- |
| 人力资本（债券） | $100000 |
| 金融财富：股票 | $200000 |
| 金融财富：债券 | $700000 |
| 合计 | $1000000 |
| 总财富中股票的比例 | 20% |
| 金融财富中股票的比例 | 22% |

这个老年人仍想持有20%的股票。为了维持该风险属性，他用实际债券来替代其类似债券的人力资本。他的股票持有量占金融财富的比例现在变为 2/(2 + 7) = 22%。因此，与年轻人相比，该老年人减少了其金融财富组合中股票 的配置。图5.3-B是相
