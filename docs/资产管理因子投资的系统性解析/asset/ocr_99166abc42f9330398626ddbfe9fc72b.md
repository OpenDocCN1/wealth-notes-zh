动性较差的股票通常收益更高$^{\textcircled { 1 } }$。这些变量包括买卖价差、成交量、成交量是否是由买方或卖方发起、换手率、美元成交量的绝对收益率（通常被称为“Amihud措施”，基于Amihud 2002年的论文）、大额交易的价格影响、知情交易（逆向知情交易，参见下文）、询价的规模和深度、交易频率、出现零收益的频率（流动性好的市场中收益上下波动），以及收益的自相关性（衡量价格是否有停滞）$^{\textcircled { 2 } }$。这些都是个股所特有的非流动性特征。同时也存在非流动性风险贝塔。它是股票收益率与非流动性衡量指标（如市场非流动性或已签名成交量）之间的协方差。

参考文献对非流动性风险溢价的估计范围在1% ~ 8%之间，取决于采用哪种非流动性衡量方法。然而，Ben-Rephael, Kadan和Wohl（2008）指出股票的非流动性溢价已大幅度减少——对于采用某些非流动性指标衡量的风险溢价现在为零。Ang, Shtauler和Tellock（2013）发现，场外交易股票市场如粉单市场的非流动性风险溢价高达20%，而可比上市公司股票的非流动性风险溢价仅1%左右。

# ## 非流动性资产

一些具有更高收益率的对冲基金其流动性更差，从这个意义上说当资本赎回具有更多限制时（称为锁定期，参见第17章），或当流动性枯竭时对冲基金的收益率会下降$^{\textcircled { 3 } }$。Franzoni, Nowak和Phalippone（2012）指出私募股权基金存在显著的非流动性溢价，通常为3%（更多信息见第18章）。在房地产市场，Liu和Qian（2012）为美国办公楼建筑构建了衡量价格影响和搜寻成本的非流动性衡量指标。他们发现这些非流动性衡量指标提高10%时，会带来预期收益增加4%。
