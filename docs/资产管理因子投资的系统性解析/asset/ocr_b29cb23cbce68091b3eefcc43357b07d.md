理人（代理人）具有不同的效用或风险厌恶程度、投资动机、投资期限、技能、信息集或者利益。此外，委托人监督代理人的能力也有限。即使在有可能监督的情况下，监督的成本也可能很高，监督的频率可能只能较低，而且资产所有者可能并不能理解监督过程中发现的一些信息。委托人缺乏足够的能力去判断代理人是否有才能或者代理人是否做得不错。即使雇佣了一个有才能的基金管理人，委托人也并不清楚代理人是在工作还是在偷懒。

主要存在两种代理问题，其术语都源于保险业：

+   **逆向选择**出现在委托人无法核实代理人技能的时候。管理人总是比资产所有者更好地掌握信息。管理人声称能获取阿尔法（alpha），而资产所有者自然会持怀疑态度。但资产所有者无法核实该管理人会是下一个Warren Buffet还是下一个Bernie Madoff。

在保险业情境下，逆向选择出现在当个人拥有比保险公司更多的信息时，这样只有那些知道自己患了不治之症的个人才更有可能购买人寿保险。如果不将逆向选择纳入考虑，会导致保险公司收取的保费过低。

+   **道德风险**出现在委托人无法观察代理人的努力程度以及代理人拥有或能够获取比委托人所拥有的更优质信息的时候。假如，资产所有者雇佣了初露头角的Warren Buffet，但无法监督他。结果Warren并没有为资产所有者的组合创造价值，而是为他自己的组合增值并忽视资产所有者的组合。更糟糕的是，初露头角的Warren在过度交易和提前交易，所以实际上是让资产所有者亏了钱。

在保险业情境下，道德风险出现在（例如）当保险公司出售了一份涵盖失窃险的保单时。但保险公司无法监督购买此保单的个人，他现在可将家门敞开，因为即使发生失窃他也不用承担损失。如果不考虑道德风险，最终会导致保险公司对保单定价过低。

经济学家研究了如何减轻代理问题的方法。委托人与代理人之间可以签订契约或者建立治理机制（经济学家称此为博弈）。契约必须能让有才能的好代理人认为值得为之工作（行话称为参与约束（participation constraint）），还必须提供能让这些代理人努力工作的正确激励，以免有才能的基金管理人把时间都花在打高尔夫上（这被称为激励相容约束（incentive compatibility constraint））。该契约不仅要最大化委托人的价值，还应考虑参与约束和激励相容约束。
