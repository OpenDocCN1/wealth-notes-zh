在这几只基金中，只有富达麦哲伦基金的阿尔法在统计上是显著的，为每月−0.27%，即每年−3.24%。这意味着富达麦哲伦基金的投资者遭受了亏损，并且该亏损在统计上是显著的。伯克希尔·哈撒韦的阿尔法估计值虽然是正的，但在统计上并不显著。在3.1节的分析中，样本区间始于1990年，其阿尔法显著为正；但现在将样本区间推后十年，即从2001年开始，Buffett的阿尔法就不显著了。这说明，要在统计上发现超额收益的显著性是非常困难的，即使是在超过十年的样本区间中。

从各个因子的系数来看，LSV属于比较明显的价值投资者——其 $HML$ 系数高达0.51（T统计值高达14.6）。伯克希尔·哈撒韦也属于价值投资者，其 $HML$ 系数为0.34。富达的 $MKT$ 系数（市场贝塔值）为1.12，说明它相对于市场具有一定的杠杆。四家基金的 $UMD$ 系数均不大，并且统计上不显著，说明它们都不是动量投资者。

我们试图用风格分析来弥补上述分析中的两点潜在不足之处：

+   ① Fama–French组合是不可交易的①。

+   ② 因子系数可能随时间而变化。

# 禁止做空条件下的风格分析

风格分析试图通过被动地投资于一系列低成本的指数型基金来模拟上述基金的表现。这一系列指数型基金被称为“风格权重”（style weight）。

让我们用以下指数型ETFs（参见第16章的40法案基金）来举例说明：

SPY：SPDR 标普500 ETF，它被用于模拟标普500指数；

SPYW：SPDR 标普500 Value ETF，它被用于跟踪标普500价值指数；

SPYG：SPDR 标普500 Growth ETF，它被用于复制标普500成长指数。

与Fama–French组合不同，这些低成本的指数型ETFs是可交易的。它们属于道富环球投资管理公司（State Street Global Advisors）旗下的SPDR（发音类似于“spider”）系列ETFs。

我们对基金 $i$ 进行基准因子回归分析（以下公式中由于下标太多，我不再标注“ $i$ ”）：

```
$$r_{i, t + 1} = \alpha_{i} + \beta_{SPY, i} SPY_{t + 1} + \beta_{SPYW, i} SPYW_{t + 1} + \beta_{SPYG, i} SPYG_{t + 1} + \varepsilon_{i, t + 1}\text{ 公式}(10.14)$$
```

限制条件为：

```
$$\beta_{SPY, i} + \beta_{SPYW, i} + \beta_{SPYG, i} = 1$$
```

① GM资产管理公司已经投资了一些可交易版本的Fama-French组合。更多细节参见Scott（2012）以及本书第14章因子投资的内容。Gremers, Petajisto and Zilzowitz（2012）认为，Fama-French组合的不可交易性导致了阿尔法的计算出现了扭曲。
