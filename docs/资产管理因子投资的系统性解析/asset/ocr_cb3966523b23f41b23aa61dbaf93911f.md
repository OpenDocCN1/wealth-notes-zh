# ### 4.3 信用利差之谜

预期违约损失率可由以下公式求得

预期违约损失率 = 违约概率 × (I - 违约回收率) 公式 (9.5)

其中，违约回收率是指在企业发生违约时，债券持有者可以收回的资金占债券面值的比例。结构性违约模型可以给出影响违约概率和违约回收率的诸多因素，如上所述，最值得注意的是波动率。尽管信用利差确实反映了违约风险，但信用利差的变动似乎与那些衡量违约概率和违约回收率的变量不相关。此外，在简单的结构性模型中，公司债利差比按照预期违约损失率推算的理论值高好几倍。这被称为信用利差之谜（Credit Spread Puzzle ）。$ ^{①} $

表9.8列出了公司债与国债的利差以及Moody's提供的信用损失率。根据公式 (9.5)，信用损失率包含的损失等于违约的部分扣除发生违约时可以回收的部分。对于投资级债券，其信用利差是其信用损失率的好几倍。但是，对于垃圾级债券，其信用利差基本等于其信用损失率。

不仅在表9.8中的样本区间中，而且在更长的区间内，我们都可以观察到信用利差之谜。Giesecke等人（2011）研究了从1866～2008年这150年间的美国公司债利差，他们发现长期的平均信用损失率约为每年0.75%，其中有一些时期的损失率明显偏高：1870年代（铁路繁荣与崩溃）、1930年代（大萧条）以及2011年（互联网泡沫破裂）。同期平均信用利差为1.5%，比信用损失率高约80个基点。
