我也参与了上述学术研究，但与像Cochrane那样的对贴现率可预测性深信不疑的人不同，我的研究发现了现金流可预测性的存在①。在Ang和Liu（2007）的研究中，我指出，由于股息率和股票收益波动率都随时间而变化（也可参见下面第6节），那么风险溢价一定也有可预测的部分。总的来说，我认为事实真相是介于Cochrane和Bansal–Yaron两种极端观点之间：现金流和贴现率的可预测性都存在，但很难同时发现它们（参见下文）。

投资者应该从中获取的信息是，股息率会随时间而变化，因此预期收益和现金流是可预测的。按照贴现率说法，低价格意味着未来有高收益，低价格时期是买入股票的好时机。根据现金流说法，如果我们能够预测到未来有高现金流，那么我们会愿意持有股票。一个聪明的投资者或许能利用这些信息来获利。

# 5.2 理论表明随时间变化的股票风险溢价很难估算

理论表明股票风险溢价是可预测的，但理论同时也指出可预测性很小。因此，很难从统计上通过数据发现可预测性，更难据此进行交易。

# 可预测性回归

一种常见的用于捕捉可预测性的统计模型是可预测性回归（predictability regression）：

公式（8.6）

```
$r_{t+1}=c+b^{*}X_{t}+\epsilon_{t+1}$
```

其中，$r_{t+1}$是市场超额收益，$X_t$是一系列预测变量。预测变量的范围包括从经济学上很直观的因子（比如宏观因子）到更深奥的变量（比如基于推特（Twitter）或脸书（Facebook）的情绪因子）②。在回归公式（8.6）中，可预测性的强度是由预测系数$b$的统计显著性来衡量。计量经济学家喜欢看得到高的$t$统计量，或者是低的$p$值，他们使用$5\%$的$p$值作为“统计上显著”的标准临界值。如果将收益和预测变量都标准化，即设为均值为0、方差为1，那么$b$代表一个预测变量当前和下一时点收益之间的相关性。在这种情况下，回归$R^2$就是相关系数的平方，$b^2$。
