挪威主权财富基金在2008～2009年间遵循了固定的再平衡规则，在价格低、预期收益率高时买入了股票。如果该基金采用了长期机会型策略，那么它应该会在当时买入更多股票。因此，再平衡规则其实相当于“低买高卖”的一个保守下限。我建议，在专注于机会型策略之前，先专注于再平衡。简单的再平衡本身是逆周期的；Stambaugh模型中的长期机会型投资，则是更加激进的逆周期操作。如果连再平衡策略（已涉及买入相对于其他资产而言价格正在下跌的资产）都无法实施，那么更无法实施机会型的长期投资。当收益率服从Stambaugh模型时，相比于简单的再平衡策略，机会型的长期投资将买入更多价格下跌的资产。同时，我还建议机会型组合应该是审慎的：考虑到估计误差以及总体上数据的可预测性较弱（参见第8章），在实际应用中，图4.8中的两条曲线（分别为随时间变化的短期权重和机会型权重对于预期收益率的函数）都将显著变得更平缓。

## 3. 再平衡相当于做空波动率

再平衡是一个期权策略，更准确地说，是一个做空波动率策略（short volatility strategy）。（期权交易员们将再平衡称为负伽马（negative gamma）策略。）此说法并不为人所熟知，但对于熟悉金融理论的读者来说并不陌生，因为第2节中求解长期组合选择问题（即动态规划）的方法也被运用于期权估值（被称为递推法（backward induction））。通过展示再平衡如何在机制上等同于一种做空波动率策略，可以让我们更深入地理解长期投资者使用再平衡策略的得失。毕竟天下没有免费的午餐，至少在经济学理论中没有。

### 3.1 示例

这个例子非常典型而且简单，但是充分地说明了再平衡是一系列期权的集合。

假设股票服从图4.9-A的二叉树（Binomial Tree）分布。股票从初始价值 $S=1$ 开始，每期各有 $0.5$ 的概率可以翻倍或者减半。一共有两期，所以在二叉树上有三个结点。到期日，有三种可能的股票收益：$S_{uu}=4$，$S_{ud}=S_{du}=1$，和 $S_{dd}=0.25$，它们的概率分别为 $0.25$、$0.5$ 和 $0.25$。另外，投资者可以持有无风险债券，债券的每期收益率为 $10\%$。

让我们首先考虑“买入并持有”策略，其中股票占 $60\%$，无风险资产占 $40\%$（从第2节我们知道，买入并持有对于长期投资者来说并不是最优选择）。在第1期末，投资者的财富可以增加或减少到

$W_{u}=0.6 \times 2.0+0.4 \times 1.1=1.6400$

或

$W_{d}=0.6 \times 0.5+0.4 \times 1.1=0.7400$   公式 (4.18)

该结果正如图4.9-B二叉树的枝干所示。在公式（4.18）中，如果我们进入了上分支，股票的收益率是 $2-1=100\%$；如果我们进入了下分支，则为 $0.5-1=-50\%$。在第1期的上节点，“买入并持有”策略中持有的股票比例是 $0.6 \times 2.0/1.64=73.17\%$，在第1期的下节点，组合中的股票比例为 $0.6 \times 0.5/0.74=40.54\%$。在第2期的最后两个结点上，“买入并持有”策略的最终财富是

$W_{uu}=1.6400 \times (0.7317 \times 2.0+0.2683 \times 1.1)=2.8840$，

或 $W_{ud}=1.6400 \times (0.7317 \times 0.5+0.2683 \times 1.1)=1.0840=W_{du}$，

或 $W_{du}=0.7400 \times (0.4054 \times 2.0+0.5946 \times 1.1)=1.0840=W_{ud}$，

或 $W_{dd}=0.7400 \times (0.4054 \times 0.5+0.5946 \times 1.1)=0.6340$   公式 (4.19)

结果如图4.9-B的二叉树叶子节点所示。

现在考虑最优的再平衡策略，在第1期重新调整回 $60\%$ 的股票和 $40\%$ 的债券。第1期末的财富与公式（4.18）一样。再平衡策略在第2期末的最终财富为

$W_{uu}=1.6400 \times (0.6 \times 2.0+0.4 \times 1.1)=2.6896$，

或 $W_{ud}=1.6400 \times (0.6 \times 0.5+0.4 \times 1.1)=1.2136=W_{du}$，

或 $W_{du}=0.7400 \times (0.6 \times 2.0+0.4 \times 1.1)=1.2136=W_{ud}$，

或 $W_{dd}=0.7400 \times (0.6 \times 0.5+0.4 \times 1.1)=0.5476$   公式 (4.20)

结果如图4.9−C所示。

![](img/e2a8f768e844f37dcab93b54b9e826d9_153_0.png)

图4.9—D将“买入并持有”策略（公式（4.19））和再平衡策略（公式（4.20））的收益，表达为第2期末股票价值的函数。虚线表示“买入并持有”策略，即没有再平衡的策略。它的损益与股价呈线性相关。相比之下，再平衡策略的收益与股价呈凹函数（Concave）关系。如果股价在到期日回到1.0，那么再平衡策略让投资者获得更多财富（当$S_{ud}=S_{du}=1$时，再平衡策略为1.2136，“买入并持有”策略为1.0840）。不过当股价低（$S_{dd}=0.25$）或高（$S_{uu}=4$）时，再平衡策略的表现则不如“买入并持有”策略，抵消了之前的影响。

再平衡策略的这种非线性收益可以等价地通过卖空期权头寸模拟产生。这种策略卖出价外（out-of-the-money）看涨或看跌期权，因此是卖空波动率。

假设存在一个执行价为3.6760美元，到期日为第2期末的欧式看涨期权。该看涨期权在第2期末的收益情况如下：

$\begin{gathered} C_{uu} = \max(4.0000 - 3.6760, 0) = 0.3240, \\ \text{或} \ C_{ud} = \max(1.0000 - 3.6760, 0) = 0 = C_{du}, \\ \text{或} \ C_{dd} = \max(0.2500 - 3.6760, 0) = 0 \end{gathered}$    公式（4.21）

在第0期，该看涨期权的价值是0.0428美元$^{①}$。

同时还有一个行权价为0.4660美元，到期日为第2期末的欧式看跌期权。该看跌期权在第0期的价值为0.0643美元，它在第2期末的收益情况如下：

$\begin{gathered} P_{uu} = \max(0.4660 - 4.0000, 0) = 0, \\ \text{或} \ P_{ud} = \max(0.4660 - 4.0000, 0) = 0 = P_{du}, \\ \text{或} \ P_{dd} = \max(0.4660 - 0.2500, 0) = 0.2160. \end{gathered}$    公式（4.22）

现在对比以下策略：

表4.1

| 策略 | 第0期 | 第2期 ($S_{uu} = 4$) | 第2期 ($S_{ud} = S_{du} = 1$) | 第2期 ($S_{dd} = 0.25$) |

| 卖出看跌期权 | +0.0643 | 0 | 0 | -0.2160 |

① 这可以用风险中性定价方法估值。看涨期权的价值在第0期的时候为$\frac{q^{2} \times 0.324}{(1.1)^{2}} = 0.0428$，其中q为风险中性概率，由$q = \frac{1.1 - 0.5}{2 - 0.5} = 0.4$得出。为了解风险中性期权定价，请参见Bodie, Kane and Marcus（2011）。式（4.22）中看跌期权的价格在第0期是$\frac{(1-q)^{2} \times 0.216}{(1.1)^{2}} = 0.0643$。

表4.1在标记了 “第0期” 的列中标记了不同策略的现价，在 “第2期” 中标记了它们的收益情况。第2期末的收益情况取决于同期末的股价。因此在第2期，分别有三列表示不同的股价，分别是 $ S_{uu} = 4 $、$ S_{ud} = S_{du} = 1 $ 和 $ S_{dd} = 0.25 $。

现在考虑第一组策略。今天卖出看跌期权意味着获得 ( “+” 号 ) 看跌期权的溢价0.0643美元。如果股价在第2期末变低 $ ( S_{d} = 0.25 ) $，那么投资者必须支出0.2160美元 ( “-” 号 )。同样地，今天卖出看涨期权意味着组合获得看涨期权的溢价0.0428美元。如果股价在第2期末上升 $ ( S_{u} = 4 ) $，那么投资者必须向该期权的买方支付0.3240美元。同时，投资者在第0期买入0.1071美元的债券。这意味着资金流出，所以是负号。在第2期末，该债券价值为 $ 0.1071 \times (1.1)^2 = 0.1296 $ 美元。最后，我们若在第0期用1美元投资 “买入并持有” 策略，其在每个可能状态的收益列在公式 (4.19) 中。

如果我们将卖出看涨期权、卖出看跌期权、买入债券和 “买入并持有” 策略合并起来看，该组合在第0期的现价为1美元，在第2期末，净值在各情境下与再平衡策略相同 (在公式 (4.20) 中列示)。也就是说，由债券融资的做空波动率策略加上 “买入并持有” 策略，等价于再平衡策略。因此，再平衡等同于做空波动率策略。

在图4.9-D中，“买入并持有” 策略完全是被动的 (Passive) 直线。再平衡策略是积极型 (Active) 策略，把股价极低或极高时 $ (S_{uu} 和 S_{dd}) $ 的收益转换为股价居中时 $ (S_{ud} = S_{du}) $ 的收益。再平衡通过对股票的 “低买高卖” 来实现。做空波动率头寸也正是如此。看涨期权可以动态地由 “买入股票和卖出债券” 头寸来复制。它在股价上升时买入股票，在股价下降的时候卖出股票。做空看涨期权与此相反：它意味着在股价上升时买入，股价下降时卖出。同样地，卖空看跌期权可以动态地由 “股价上升时卖出，股价下降时买入” 来复制。这些和再平衡策略是一致的。

## 3.2 解释

再平衡的市场价值是多少？在这个两期的二叉树例子中，再平衡策略相比于 “买入并持有” 策略多出的价值可以由卖出看涨期权、卖出看跌期权和买入债券来复制。这三部分的价值为：

> 卖空看涨 + 卖空看跌 + 买入债券 = 0.0643 + 0.0428 - 0.1070 = 0.

也就是说，再平衡被赋予的市场价值为零。即，市场并不看重再平衡。

最优的再平衡策略是局部均衡 (Partial Equilibrium) 策略。并非每个人都可以进行再平衡操作。既有像NBIM那样在金融危机最黑暗的时刻买入股票的机构，也有像CalPERS这样迫不及待地降低股票风险敞口的机构。CalPERS未进行再平衡而产生的损失，即意味着NBIM通过再平衡所获得的收益。简而言之，对于每个买家，市场上必然存在一个卖家。在均衡状态下，每个人不可能都同时卖出或买入①。再平衡并没有被市场赋予价值。事实上，与此相符合的，持有市场组合的平均投资者并没有进行再平衡：市场本身就是“买入并持有”的②。

再平衡能给投资者带来的好处因人而异。将股价极低或极高时的收益换为股价居中的收益（如图4.9-D所示），这对于投资者而言是最优的，因为此举降低了风险。在我们的例子中，当风险厌恶程度$ y = 0.51 $时，60%股/40%债的组合对于投资者而言是最优的。确定性等价计算（参见第2章）表明，如果投资者被迫采用“买入并持有”策略，而不是实施最优再平衡，那么其初始财富的每1美元都需要被补偿0.29美分③。长期投资者重视再平衡，因为该策略可以降低风险、提高效用。而市场并非如此，这是因为市场上必然有部分投资者没有进行再平衡。

因为再平衡等同于卖空波动率，它自动地赚取了波动率风险溢价。在我们的例子中，波动率是不变的（股票波动率等于0.75），但是在现实生活中，波动率是随时间发生变化的。波动率是一个风险因子，其风险溢价为负（Negative Risk Premium）。投资者通过卖出期权或卖空波动率，获取波动率风险溢价。我将在第7章进一步讨论这个问题。

由于再平衡策略是一种将收益移向中间值的卖空波动率策略，它在市场不断下跌时会扩大损失，它在市场不断上涨时表现不如“买入并持有”策略，因此我们可以清楚地看到，再平衡策略是从市场反转中获取收益。这是该策略在1926~1940年以及1990~2011年期间表现良好的原因之一（如图4.5和图4.6所示）。当市场在最剧烈的崩盘后强劲反转时，再平衡策略的表现就将如奇迹一般。在大萧条时期，以及最近的2008 ~ 2009年的大衰退和金融危机时期，我们都经历了市场的强劲反转。相反，如果反转没有出现，而是持续的牛市或持续的熊市，那么再平衡的表现将不如“买入并持有”策略。

再平衡等同于卖空波动率策略这一点，与Antti Ilmanen（与我一同担任挪威主权财富基金的顾问）的说法一致，“再平衡是对市场机制改变（regime change）的卖空”。考虑一个极端情况，如果当前市场机制改变并对股票市场形成永久性打击；再平衡策略将表现较差，因为其会在价格下跌时买入股票，而此时股价持续低迷。另一个反向的极端情况是，当市场机制改变，股票进入永久性的牛市。此时再平衡的表现也将不如“买入并持有”策略，因为再平衡会卖出那些不断上涨的股票。

永久性市场机制改变有时会发⽣，但很少见$ ^ {①} $。我完全同意Reinhardt和Rogoff（2011）的观点，人们总是认为“这次不一样了”。我们用两个真正的市场机制改变的例子来说明“这次真的不一样了”，一个是在1933年前后，收益率曲线的形状⽣了永久性改变；另一个是1987年前后，价外看涨期权波动率曲⾯的变化。在1933年之前，收益率曲线是向下倾斜的，而在1933年之后直至现在，收益率曲线通常都是向上倾斜的。学界认为，脱离⾦本位制度可以在很⼤程度上解释这个变化（参见Ward（1983））。在1987年以前，期权的隐含波动率，在市场受冲击时呈现对称性（被称为隐含波动率微笑（implied volatility smile））。⽽在1987年市场崩盘之后，隐含收益率呈现出显著的负偏度（参见Rubinstein（1994）），即行权价低的期权波动率比行权价高的期权波动率高很多。隐含波动率微笑变成了隐含波动率偏笑（implied volatility smirk）。2007 ~ 2008年间的金融危机算不上市场机制改变，从2009年开始的欧洲主权债务危机也不是机制改变。真正的永久性机制改变非常罕见。

事实是，再平衡等同于卖空波动率，因此卖空市场机制改变意味着你必须对那些基本不可能发⽣永久性机制改变的资产类别（或者是因子，参见第14章）进⾏再平衡操作。俄国股市在1900年时是很大的市场，然⽽在随后不到二十年间就消失了：投资者损失殆尽。但是全球股市在一个世纪之后仍然存在，并且还将长时间存在，或许直到资本主义消失。俄国债市也在俄国革命期间消失了，但是全球债市并没有消失。全球股市和债市已经并将继续长时间地陪伴我们。再平衡的最优性经过历史验证，并且真实存在$ ^ {②} $。
