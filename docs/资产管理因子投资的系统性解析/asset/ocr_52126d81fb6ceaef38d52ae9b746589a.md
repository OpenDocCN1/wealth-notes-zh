两支基金于2013年3月15日合并。资产规模更大、投资历史更长的Janus Worldwide基金不再存在，而是被资产规模更小、投资历史更短的Janus Global Research吸收取代，为什么呢？

图16.3-B绘制了自2005年2月至2012年1月Janus Worldwide和Janus Global Research的年收益情况。Janus Global Research击败了比它规模大得多的Janus Worldwide。在样本区间内，Janus Global Research的平均收益为9.9%而Janus Worldwide的平均收益为5.0%。两支基金的波动率相似，均略低于20%，因此Janus Global Research的夏普比率（参见第2章）是Janus Worldwide的两倍。

合并后的基金只继承了Janus Global Research的优异收益。Janus Worldwide停止存续，其不佳的业绩也在Janus基金家族中消失。
