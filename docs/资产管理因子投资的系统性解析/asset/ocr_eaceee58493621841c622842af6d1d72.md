# 续表

| | 公开市场股票（标普500） | 私募股权 |
| :--- | :--- | :--- |
| 估值 | 容易并且实时客观 | 估值难度大，分析方法偏主观且估值频率低 |
| 投资期限 | 中期 | 长期（10年左右） |
| 合同 | 标准 | 复杂 |

公开市场股票的估值是客观、实时的，并且很容易通过市场价格来核查。而另一方面，私募股权很难估值。估值过程频率较低，且带有主观性和不必要的、充满神秘色彩的复杂性：大多数私募股权基金的投资期为十年左右，有的更长，有时超过十五年。因此，当基金清算最终发生时，私募股权基金十年期间或者更长时间的真实收益率无法被计算得出。私募股权的较长投资期意味着投资者难以对私募股权头寸进行再平衡，这使得之前在第13章中提到的标准（通常为均值一方差）投资组合选择模型不适用于私募投资。

最后，流动性资产的合同基本上是标准化和透明的。而私募股权合同在这方面却恰好相反，它需要投资者付出更多的努力和勤勉。

# 2.3 私募股权的类型

私募股权有如下几种类型：

杠杆收购（Leveraged buyout）或并购基金（buyout）通常是用较高的杠杆水平购买成熟的、往往已上市的公司（并购基金的平均杠杆率是$3^{①}$）。配置到私募股权的大部分资金都属于这种类型，因此有时“PE”术语被用来特指并购基金。我在本章会介绍更广义的私募股权。

风险投资（Venture capital）基金（简称VC）投资处于早期发展阶段的公司，很少使用或不使用杠杆。天使投资人是风险投资人的一种特殊类型，通常只使用其自有资金，而不是像风险投资基金那样依赖于一群投资者的资金。天使投资人擅长于公司发展的最早阶段，比如众所周知在某人车库中刚起步的初创公司。苹果、谷歌（这两家公司确实最早是在车库中起步）、亚马逊和YouTube都是以这种方式融资。这些都是高科技公司，这一点并非偶然——因为风险投资基金倾向于投资高成长的初创公司，尽管有些风险投资公司专长于其他领域。
