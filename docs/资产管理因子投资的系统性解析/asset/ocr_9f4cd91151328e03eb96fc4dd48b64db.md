# 公司投资风险

Berk，Green和Naik（1999）提出了一个关于价值型和成长型公司行为的重要见解。他们的分析基于实物期权（real option）的相关文献，其中管理者的角色是最优地执行实物投资期权来增加公司价值①。这种情形下的公司是由现有资产以及一系列管理层可以选择执行（或不执行）的投资期权所构成。CAPM模型是一个线性模型，如果有期权特性的话CAPM模型就难以完全运行（参见第10章）。Berk，Green和Naik指出管理者会在市场回报较低时最优地执行投资期权。这些投资期权与账面市值比（以及规模）等特征动态相关，从而产生价值溢价。价值型公司有风险，其风险实际上与CAPM模型或其他宏观因子所界定的传统不景气时期的风险是一致的。除非能承受不景气时期这些价值型公司所遭受的损失，你才可能成为价值投资者。

Lu Zhang撰写了一系列论文来解释价值风险溢价，其视角为价值型公司如何由于其潜在的生产技术而变得有风险。其中一篇重要的论文就是Zhang（2005），其分析是建立在Cochrane（1991，1996）提出的基于生产的资产定价（production-based asset pricing）框架之上。Cochrane 指导人们通过分析公司投资来研究公司回报。Cochrane-Zhang 的分析要点如下：价值型公司和成长型公司在能有多大灵活性以及能多快地应对冲击方面表现不同。不景气时期，价值型公司的风险性更高，因为他们背负着更多的低生产率资本。比如生产笨重小部件的价值型公司，当不景气时期来临时，他们无法将公司业务转型为利润更高的业务，而只能继续生产小部件。他们希望削减资本，但又无法出售生产小部件的专用设备。按照经济学家的行话，他们具有高昂且不对称的调整成本。然而，成长型公司则很容易削减投资，因为他们雇佣的是聪明而年轻的员工，而且所投入的资本大部分是人力资本而非笨重的零部件生产工厂。因此，价值型公司从根本上比成长型公司的风险性更高，相应也会要求要有长期溢价。
