期国债的相关系数也高达98%。这些债券的现金流都是确定的，因为我们假设美国财政部无兑付风险，唯一的不确定性就是这些现金流的贴现率。七年期债券的贴现率可以看作一年期债券贴现率加上第1年和第7年间的远期利率（Forward Rate）。同样，六年期债券的贴现率可以看作一年期债券贴现率加上第1年和第6年间的远期利率。因此，影响短端利率的因子通过收益率曲线传导到长端，即长期期债同时受到短端利率和长期冲击的影响。短端利率影响所有债券的价格。这就是水平因子在固定收益市场中如此重要的原因。

如果你将风险分析范围从国债扩大到机构债、投资级公司债以及高收益债，非系统性风险因子的占比会增加。但是对于所有这些债券，水平因子仍是最主要的影响因子。为了理解固定收益投资，投资者必须理解水平因子。水平因子的变化就如同联邦基金利率，因此我们需要理解美联储怎样制定货币政策。

# 2.3   泰勒法则（1993年）

1977年美联储改革法案中明确了美联储的政策目标。即：

美联储将保持货币和信用的长期增长与经济长期增长潜力一致，提高生产，有效地实现充分就业、物价稳定和长期利率平稳的目标。

这三个目标中的最后一个通常会被人们忽略，但在我看来，该目标授权美联储应当为降低不确定性而采取行动。在金融危机期间，美联储采取了特殊手段来稳定货币体系和经济体系，无疑也降低了波动率。1913年美联储法案第13（3）节，授权美联储在“非常紧急的情况下”可以借钱给任何人。在这次金融危机之前，上一次使用该条款还要追溯到大萧条时期。前两个目标“最大化就业”和“物价稳定”被称为美联储的“双重任务”（Dual Mandate），一些学者认为这两者是矛盾的（Dueling Mandale）①。尽管“低通胀”不一定意味着“物价稳定”，但物价稳定在传统上被视作低通胀②。包括欧洲央行在内的许多中央银行、并没有促进经济增长的任务，而只有稳定物价的任务。金融危机以来，包括美联储在内的许多中央银行，加入了金融稳定（Finacial Stability）的任务。
