确。如同Anness在对冲基金定义中说的一样，“每隔三四年它们可能取得一次百年一遇的收益。”

# 对冲基金行业

如果多数对冲基金策略是在做空波动率，那么整个对冲基金行业也具有做空看跌期权的特征就不足为奇了。Jurek和Stafford（2012）显示，单纯的出售价外看跌期权的策略恰好准确地匹配了对冲基金指数的风险特征，事实上该策略表现还更好。在1996~2010年的样本区间内，对冲基金相对于美国短期国债的超额收益为6.3%，而出售价外看跌期权的超额收益为10.2%。

# 3.6 杠杆

使用杠杆是对冲基金的显著特征之一。在资产管理行业中，对冲基金是使用杠杆程度最高的。对冲基金使用杠杆以达到投资者期望的收益波动性水平，特别是那些投资于波动性一般较低的固定收益证券的对冲基金。对冲基金也会随着投资机会的变化调整杠杆。最后，对于那些若不加杠杆则盈利能力不足的策略，对冲基金会使用杠杆来提高收益（如果不幸的话，则是扩大损失）。

Ang, Gorovyy和Van Inwegen（2011）研究了对冲基金的杠杆。在我们撰写该研究报告的时候，对冲基金还未公布他们的杠杆，而我们的研究是第一个使用真实杠杆率数据来分析对冲基金杠杆的。现在证券交易委员会取得了对冲基金杠杆的报告，监管者对对冲基金的拆借情况有更好的了解（虽然投资者可能没有）。

我们发现对冲基金的杠杆平均来看并不那么高。有一些固定收益的对冲基金杠杆率在30倍以上，但如图17.7所示（左坐标标示的实线），整个对冲基金行业的杠杆率约为2或3。这是因为一半的对冲基金行业集中在股票资产，而股票类策略的杠杆率一般较低。一个更惊人的事实是，对冲基金杠杆相对于投资银行杠杆来说具有反周期性。我本人觉得这令人吃惊的原因是，在撰写这篇论文之前，我认为在杠杆策略上对冲基金将会是投资银行的缩影。
