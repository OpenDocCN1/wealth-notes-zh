其中资产 $i$ 在组合中的权重是 $w_{i}$ 。我们要找出在两个约束条件下能够最小化组合方差的权重组合 $\{w_{i}$ 。第一个约束条件是投资组合期望收益率等于某个目标值 $\mu^{*}$ 。第二个约束条件是组合必须是一个有效的投资组合，也就是我们之前见到过的可容许性条件。运筹学的学生会认出公式 (3.2) 即为二次规划问题 (Quadratic Programming Problem)；已经有非常高效的算法来解决这类问题，这使得均值一 方差投资策略非常强大 (但也会被错误应用；参见下文)。

图 3.6 形象地展示了上述问题。选择一个目标收益率 $\mu^{*} = 10\%$ ，我们找到波动率 (或方差) 最低的投资组合，用 × 标记此点。然后我们更改目标收益率为 $\mu^{*} = 12\%$ ，再次找到波动率最低的投资组合并用另一个 × 标记。均值一 方差前沿就可以通过这样的方法绘制：不断改变目标收益率 $\mu^{*}$ 然后连接不同目标收益率下所有的点 ×。于是，均值一 方差前沿是一组点的轨迹 (locus)，其中每个点代表的是每个目标收益率下可达到的最小方差。
