
## 4. 董事会

如同在公司架构中一样，很多委托人通常是由董事会来代表。长期以来，董事会被认为是一种可以减少代理人的机会主义的良好监督机制。公司财务领域有许多文献从理论和实证方面都强调了董事会中独立董事的重要性(1)。有效的董事会能够维护委托人利益。通过监督和诠释相关信息，董事会能减轻委托代理问题(2)。

尽管董事会本身就是他们所代表群体的代理人，比如受益人、家族办公室的家族成员、整个国家（对主权财富基金来说），本节我将集中讨论作为委托人的董事会及其在与作为代理人的基金管理人关系中所扮演的角色。

本节我将重点关注NYSCR F所关心的问题。1979 ~ 1993年间担任审计长的Edward Regan曾试图将NYSCR F的治理结构改为董事会形式，并尝试通过改革将他自己从唯一受托人的角色中解放出来。他回忆说：

> 在20世纪80年代，当我是审计长时，我提议了一项立法以呼呼为该养老基金建立一个由投资专家组成的小型董事会，来代表当地政府以及在职的和退休的州政府员工。然而，该法案在被引入的几周之内就面临要被修订，意见是将更多的
>
> 席位授予给受惠利益集团。因此我不再支持该法案。

一个被特殊利益集团主导的养老金董事会，尤其是在大部分代表者缺乏专业知识的情况下，可能会酿成灾难。假设我们选择董事会模式作为最优治理结构，那么NYSCRF应该如何选择董事会呢？

### 4.1 董事会成员

公司财务理论和实证数据表明，独立的董事会能增加最大的价值(2)。我将对NYSCRF可以效仿的两种模式进行讨论：加拿大养老金计划投资委员会（Canada Pension Plan Investment Board，简称CPPIB）和新西兰养老基金（New Zealand Superannuation Fund，简称NZSF），后者是新西兰的主权财富基金(3)。两者都有独立于政府的董事会。

CPPIB是专门负责对加拿大养老金计划的资产进行投资的基金管理人，其目标是“在不承担过度损失风险的前提下最大化投资收益”。它“独立于政府”而设立。根据1997年加拿大养老金计划投资委员会法案（1997 Canada Pension Plan Investment Board Act）的条款，CPPIB由十二人组成的董事会进行管理。他们由联邦财政部长经过与各省（除了不参与的魁北克以外）磋商之后，在提名委员会的协助下进行任命，任期为三年。他们的任期是交错的，以使任意一年中都不会有过半数的董事任期期满。董事有资格再次当选，最长服务期为三届。董事必须具备投资特长，“拥有可信的金融领域的能力或相关工作经验，以使董事会能有效地达到其目标。”此外，董事必须是“加拿大各不同地区的代表”。董事会里没有政府官员。CPPIB不用向政府提交投资策略或商业计划来获得批准；也不需要政府批准其薪酬政策或薪资水平。若要改变CPPIB的治理结构及其使命，需要联邦政府和代表2/3人口的2/3省份的批准。高级副总裁和首席投资策略师Donald Raymond评论说，这“比改变加拿大宪法还要难”。

## 2. 注册投资公司

虽然共同基金在注册投资公司中持有的资产最多，但其市场占比在缓慢下降。在2000年，共同基金占所有注册投资公司资产的96%，但2011年年末这个比例降到了90%。

与共同基金相反的是，封闭式基金（Close-End Funds）的股份不能赎回且数量固定（在基金成立之后可能会有二次发行，基金可能也会回购股份，但这些情况一般较少发生）。在首次公开发行之后，这些股份在二级市场上交易。相对于共同基金（须提供流动性），封闭式基金可投资于流动性较差的证券。

共同基金和封闭式基金均由独立于基金的注册投资顾问管理。投资顾问的收入来自基金投资者支付的费用。通常，注册投资顾问受雇于基金发起人。基金的发起人通常是类似于Janus，创建和推广多个注册投资公司的资产管理公司。拥有相同品牌或基金经理的基金通常被称为共同基金家族（或综合体）。Janus基金家族包括所有用Janus名称做推广的基金，例如Janus 20基金，但Janus也是例如INTECH基金等其他基金家族的发起人。

基金发起人有时候可以将基金的管理外包给第三方（转包投资顾问）。这些外部管理的基金通常在一个基金家族的框架下进行推广。American Skandia保险公司就曾使用Janus作为转包投资顾问来管理自己的基金。在Janus由于科技泡沫破灭出现灾难性损失之后，American Skandia于2002年终止了与Janus的合作关系(1)。共同基金公司采用转包给无关联的投资顾问的形式获得专业化的管理服务，而这些转包投资顾问也获得相应的分销渠道(2)。Chen, Hong和Kubik（2010）的研究显示，外部管理的基金跑输了共同基金家族内部管理的基金。

单位投资信托（UITs）是共同基金和封闭式基金的混合体。与封闭式基金相似，单位投资信托发行固定数量的股份（单位）。与共同基金的股份相似，这些单位可赎回，但单位投资信托的发起人维持一个二级市场让股份可在投资者之间进行买卖。单位投资信托购买和持有一系列资产直到预设的终止日期，此时单位投资信托被解散，投资款项退还给股东。单位信托一旦成立之后，一般情况下其所持有的资产不再交易。不同于共同基金和封闭式基金，单位投资信托如此简单，他们并不需要董事会或投资顾问。但单位投资信托仅仅是投资公司中的极少一部分（参见图16.2），因此在本章中不单独讨论它。但是，单位投资信托种类最近有所增长，这是因为某些交易所交易基金在技术上被归类为单位投资信托。

交易所交易基金（ETFs）与封闭式基金均在交易所进行交易，因此能提供即刻的流动性给投资者。不同于封闭式基金的是，交易所交易基金的股份份额不是固定的，基金的发起人可买卖股份以保证交易所交易基金的报价贴近基金资产的净值。交易所交易基金大部分被归类为共同基金或单位投资信托。交易所交易基金的市场成长迅速，其市场占比从2000年不到1%增长到2011年超过8%，如今交易所交易基金持有超过一万亿亿美元的资产。

### 2.2 减少利益冲突

在40法案之前，投资者相对于基金管理人处于巨大的劣势地位。简单地说，基金管理人经常明目张胆地从投资者处窃取资产(1)。40法案阻止了这种现象，而且进一步“最小化了利益冲突”。它创造了一大类的保护一般投资者利益的投资工具，并且在这个方面做得很出色。

40法案通过如下方式缓解代理问题。

**强制性透明度**

注册投资公司必须提供招股说明书，披露基金的投资目标、策略、风险、费用和股份交易的说明。40法案要求定期向美国证券交易委员会提供招股说明书和其他报告并将这些提供给公众。财务报表必须通过审计，基金的持仓情况必须报告（共同基金每季度报告，交易所交易基金每天报告），且基金必须公布它们在代理投票中怎样投的票。所有这些信息在很大程度上都是标准化的，因此个人投资者可以在基金之间作比较，一些投资咨询公司（例如晨星，Morningstar），将这些信息加以对照和传播，并基于数据提供选择基金的建议。

重要的是，40法案保证了投资者能通过净资产价值（NAV）知道基金投资的市场价值。共同基金投资者可放心的基于基金持仓的价值减去任何适用的费用进行交易。

**强制监督**

共同基金拥有董事会。至少40%的董事必须是基金管理公司之外的独立董事（虽然他们是否真的独立行事是另外一回事）。从2003年开始，美国证券交易委员会要求每个基金和基金管理人必须聘请首席合规官。由美国证券交易委员会监控基金的合规性。

40法案最重要的要求之一是基金的资产独立于基金管理人的资产。共同基金管理公司有三种方法对投资进行隔离保管：通过银行（最受欢迎的方式），通过经纪公司（较为少见）和自我保管。如果自我保管，有严格的监管条例要求基金资产必须和公司的其他资产实质性隔离。

40法案也限制基金、基金管理公司和关联公司之间的交易类型。在大萧条之前和期间，很多基金管理人以低于市价的价格从基金购买资产，或者基金向内部人士以虚高的价格购买资产，或者基金为管理层提供低成本贷款。40法案明令禁止这些侵犯投资者利益的行为。

**受托责任标准**

40法案要求注册投资管理人遵循一定的受托责任标准（fiduciary standard），意味着他们必须以客户的利益最大化为行为准则。经纪人不是受托责任人，遵循适宜性标准（suitability standard），意味着不必找到对投资者最好的产品，仅仅是适宜的产品即可。是这样的，多数出售共同基金的经纪公司和投资咨询公司并不是必须把投资者利益放在第一位。即使投资咨询公司是一个注册投资管理人，受托责任标准也不能完全消除委托代理问题，正如第15章中强调的一样。

**限制杠杆率**

最初的40法案的第13（a）章节提道：“除非在有投票权的股份以多数票通过的情况下，注册投资公司不可以借款投资。”如今杠杆已被允许，但美国证券交易委员会仍然限制其使用。共同基金最多有300%的资产覆盖率（最多可以借33.3%），封闭式基金相对债权最多可以有300%的资产覆盖率，相对优先股最多可以有200%的资产覆盖率。很多基金选择完全不借钱投资，并且对它们的投资风格设置了一些其他限制(1)。

**限制收费**

共同基金的业绩费必须对称地围绕着某个选定的基准，这个基准被称作费率支点（fulcrum fee），必须充分披露(2)。在实践上，业绩费用也设有上限和下限。法律上排除了不对称合同，例如权奖奖金或类似期权的费用。第15章内容显示使用这些费率形式可以增加投资者福利（参见第17章。免除40法案注册的对冲基金可自由制定管理人的费率）。大多数共同基金不收取业绩费。Elton, Gruber和Blake（2003）研究表明，收取业绩费的少数管理人相对不收取业绩费的同类型基金具有轻微的优势。但是，有业绩费的基金倾向于在表现不好之后增加风险水平。

40法案除了规定注册投资公司管理人有避免对投资者过度收费的受托责任之外，对于投资管理人收取管理费的费率结构的限制较少(3)。通常，管理费是按投资规模的某一比例进行征收。

### 2.3 仍存在的代理问题

信息披露虽然是强制进行，但其措辞可能相对晦涩。很少有人投资前阅读招股说明书，这些厚重的招股说明书需要一定能力才能充分理解。虽然公布费率，但很少投资者会留意，AARP（前身是美国退休人员协会）于2011年2月进行的一项调查显示71%的受访者为认为他们并不支付任何费用(4)。

美国在公布退休资产管理费用方面落后于其他国家。在退休计划中支付给基金的费用中也包含管理人、投资顾问和其他一些费用。共同基金的费用必须披露，但那些为退休储蓄的投资者几乎不清楚他们支付的费用情况，包括他们退休金投资的共同基金的费用情况。在2012年8月30日，对退休储蓄计划有着管辖权的美国劳工部才开始要求提供费用明细给退休计划的参与者(5)。根据投资公司研究所（ICI）的统计，共同基金资产总量为4.7万亿美元，占美国2011年年末17.9万亿美元退休金资产总量的26%。美国家庭持有的缴费确定型养老金计划（defined contribution pension plan）中55%的资产投资于共同基金，个人退休账户（IRA）持有的45%的资产也投资于共同基金。

共同基金的治理比一般公司弱很多(6)。共同基金在法律上独立于推广、出售和管理着这些基金的公司。董事会的存在赋予了基金一层独立性。但基金经理真正忠诚于管理基金的公司，而不是拥有基金的投资者。这种关系是天生扭曲的，输的始终是投资者。共同基金的很多董事，特别是董事会主席，也是投资管理公司的内部人士。基金董事一般不会，而且在很多情况下也不能独立地验证基金管理公司提供的信息。将基金的治理从基金发起人处分离并不足以保护投资者。

最高法院支持基金和基金管理公司在法律层面上的分离，虽然在实际操作层面，共同基金仍然由共同基金公司进行管理。2003年Janus市场择时的丑闻导致了Janus资本集团对第一衍生品交易员公司（First Derivative Traders）的法律案件(7)。在2011年6月，最高法院判决Janus基金，而不是Janus基金管理公司，应当对招股说明书中造成对某些投资者不利的市场择时行为的误导性语言负责。在法律上，所有过失都由Janus基金承担。Janus基金管理公司得到了一个免费通行证，虽然它发起、营销并管理着这些基金(8)。

### 2.4 总结

作为注册投资公司的好处是其能向公众募集资金。为了保护一般投资者，40法案对注册投资公司进行了一些限制。该法案规定信息披露，最低限度的监督，以及基金管理人收费的限制。这些监管条例降低了委托代理的问题，但并不能消除该问题。

40法案并不完美，但没有它会更差，正如我们将在接下去的第17章和第18章中分别讲到对冲基金和私募股权时会看到的一样。
