# 1. 量化策略危机

在2007年8月的第一个星期，量化对冲基金普遍跌入了深渊\textcircled{1}。从8月7日至9日，量化基金遭遇了空前的大幅损失，而造成这些损失的原因不明。市场并未出现整体下滑，而大幅损失也仅仅出现在量化投资基金中。

量化投资策略通过挖掘历史数据和创建量化信号来选择证券。该类策略发展始于20世纪60年代，此时正是资本资产定价模型（Capital Asset Pricing Model，参见第6章）为基金经理人提供了基于股票Beta（一个度量股票与市场之间收益关系的统计量）来估算预期收益的方法论的时期。高频统计套利基金采用技术性很强且持仓时间很短（从几秒至一两天不等）的交易策略。相对长期的市场中性基金的投资期从数周到数月不等，它们基于经济模型和较低频率的统计预测模型进行投资。一些市场中性基金倾向于使用基于因子投资的策略，例如价值一成长、市值、动量、波动率和公司信用等（参见第7章）。很多对冲基金使用财务杠杆并进行做空。

量化基金采用的复杂模型加剧了在8月那三个严峻交易日期间的下跌。麻省理工大学的研究生Amir Khandani和他的教授Andrew Lo（研究投资策略的对冲基金专家，同时也经营着一家对冲基金）、专门研究了此次量化策略危机。在Khandani和Lo（2007）中，他们称此次危机为“完美的金融风暴”。
