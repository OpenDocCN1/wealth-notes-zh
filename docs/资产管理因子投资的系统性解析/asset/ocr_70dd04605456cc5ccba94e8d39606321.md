# 4.2 资产类别内的非流动性风险溢价

在所有主要的资产类别中，平均而言，流动性差的证券比流动性好的证券具有更高的收益率。这些非流动性溢价可以通过动态因子策略获取，即做多非流动性资产和做空流动性资产。当非流动性资产流动性增强时，投资者可进行再平衡，反之亦然。（第14章讨论了如何对这些因子和其他因子进行配置）。

# 美国国债

美国国债市场有一个众所周知的流动性现象，即新券/旧券之间存在价差¹。最新拍卖的国债（即新券）比发行已久的国债（即旧券）具有更好的流动性，价格更高，因此收益率更低。这两种类型的债券利差随时间而变动，反映了美国国债市场的流动性状况²（更多细节参见第9章）。

2008~2009年金融危机期间，国债市场具有明显的非流动性效应。美国长期国债和中期国债本质相同，只是美国财政部发行长期国债的初始到期期限为20~30年，而中期国债的到期期限为1~10年。但十年后，原本二十年到期的长期国债便与中期国债一样。如果到期日相同，那么这只特定债券是长期国债还是中期国债本身并无区别。而在金融危机期间，到期日相同的长期国债价格比中期国债的价格要低5%以上——这是在世界上最重要、流动性最好的市场之一中体现出来的显著的非流动性效应³。

# 公司债

交易频率更低、或者买卖价差更大的公司债通常收益率更高。Chen, Lesmond 和 Wei (2007) 发现非流动性风险可以解释投资级公司债收益率变动的7%。非流动性风险可以解释垃圾债收益率变动的22%；对于这些债券，买卖价差中1个基点的上升会导致收益率增长2个基点以上⁴。
