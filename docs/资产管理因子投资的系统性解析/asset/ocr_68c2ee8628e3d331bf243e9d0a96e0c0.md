# 1. 房地产对冲通货膨胀的效果如何？

Carole是一家中型养老金的顾问，该养老金的投资组合构成是传统的60%股票和40%债券$^{①}$。长期以来，该养老金由于规模偏小，而从未考虑过进行房地产投资。但是最近由于雇主大量注资，养老金规模也随之扩大。该养老金的受托人担心通货膨胀对养老金的负面影响，认为可以通过房地产投资来对通货膨胀进行一定程度的对冲。

这些受托人的想法可行吗？房地产直接投资是一种效果较好的通胀对冲工具吗？Carole知道这不仅仅是数字运算的问题，房地产与养老金组合中的股票和债券这类传统资产是不同的。虽然房地产直接投资的配置相对静态，但是它也需要由专业人士进行积极管理。例如砖瓦砂浆等建筑材料需要持续的资本支出才能保持该房地产的竞争力。该养老金此前已经通过被动地配置可交易的房地产信托投资基金（REITs）取得了房地产投资敞口。那么，REITs等同于房地产直接投资吗？Carole不得不解决这些疑问。

当通货膨胀率高企时，养老金的负债端就会增加。为了最大程度地减小资产端与负债端之差的波动（资产负债顺差，参见第1章），受托人需要资产端在通货膨胀率高的时候产生高的收益。事实上受托人最渴求的是，找到回报率与通货膨胀率高度相关的资产。如果房地产不能充分地对冲通货膨胀，那么Carole还可以考虑其他哪些资产呢？

我们在本章将讨论那些传统上被认为可以对冲通货膨胀的资产，尤其是通胀挂钩债、大宗商品以及房地产。我将对这些资产的对冲通货膨胀效果（回报率与通货膨胀率的相关度）和长期回报率做出区分。某一类资产的长期回报率可以大幅高于通货膨胀率、但这类资产对冲通货膨胀的效果也许并不好：对冲通货膨胀的效果指的是两者是否能同步变动，而长期回报率指的是回报率的长期均值。我们将发现，大多数实际资产并没有那么“实际”。

① 该案例来自“Is Real Estate Real?”, ID#111704。
