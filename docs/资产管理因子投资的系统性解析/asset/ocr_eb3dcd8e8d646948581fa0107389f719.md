# # 5. 再平衡溢价

如果没有对再平衡溢价（Rebalancing Premium）的讨论，那么关于长期投资的分析就是不完整的。这会涉及一系列名称，包括分散化收益（Diversification Return）、方差流失（Variance Drain）、增长最优投资（Growth-Optimal Investing）、波动抽利（Volatility Pumping）以及凯里标准（Kelly Criterion）或凯里规则（Kelly Rule）（这是以一位在贝尔实验室工作的工程师John Kelly（1956）命名的）$^{①}$。“分散化收益”（diversification return）一词是由Booth和Fama（1992）最早提出，它可能是在金融领域中最广为认知的术语，而凯里法则（Kelly Rule）和波动抽利（Volatility Pumping）则在数学领域更为有名。我不倾向于使用Booth和Fama的术语，因为单一投资期的分散化与随着时间而获取溢价的再平衡之间存在差别。分散化在单一投资期内为你带来好处，但是如果你没有进行再平衡，分散化优势就消失了$^{②}$。再平衡溢价只对于长期投资者存在，投资者可以通过每期实施再平衡回到固定的权重来获得这个溢价。我使用“再平衡溢价”这个名词来强调该溢价来自于再平衡而不是来自分散化投资。

# ## 5.1  再平衡策略长期来看优于“买入并持有”策略

假设每个标的资产的价格是平稳（Stationary）的；也就是说，每个资产的价格都基本上在固定区间内波动，而不会趋向于无穷。100%持有每个资产的头寸不会让你的财富增长。但是，再平衡的组合在长期可以提供无限增长的财富（财富以指数（Exponentially）速度增长）$^{③}$。此外，通过每期再平衡回到一个恒定不变的权重，投资者可以获得随时间增长的财富，并且任何这样的再平衡策略最终都将打败最好的“买入并持有”组合。这看起来很像魔法：Erh和Harvey（2006）称其为“把水变成酒”，Evstigneev和Schenk-Hoppé（2002）则称其为“从一无所有到家财万贯”。
