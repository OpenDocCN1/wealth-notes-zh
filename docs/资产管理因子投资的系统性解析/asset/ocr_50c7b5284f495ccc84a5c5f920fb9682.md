节目Jeopardly的参与者。这个节目的赌注很高，而且有巨大的压力，因为只有获胜的 玩家才能得到回报（Jeopardly的参与者也很聪明，所以你不能说他们不知道自己在做 什么）。Metrick发现，该节目的参与者风险厌恶程度较低且接近风险中性。Aarbu和 Schroven(2009)给出了最新的研究数据，他们对挪威人进行了调查，发现其风险厌 恶值约为4。Kimball、Sahm和Shapiro(2008)也进行了调查，他们的估计值较高，约 为8。需要注意的是，这些只是调查结果，并不是真实的财务选择。在哥伦比亚大学 商学院，Paravisini、Rappoport和Ravini(2010)研究了在个人对个人的线上借贷平台 中投资者的财务决策。该平台可以决定谁能得到资金、得到多少资金。他们估计投资 者风险厌恶程度在3左右。

# 2.4 预期效用

预期效用将结果发生的概率（这些事件是否经常发生？）与投资者是如何看待结 果（这些对我来说是不是景气时期吗？）结合起来：

```
$$U=E\left[U(W)\right]=\sum_s p_s U(W_s)$$

公式(2.2)
```

在公式(2.2)中，下标s表示结果s发生，所以预期效用即是发生概率$\underline{p}_s$乘以该事 件在该状态下的效用$U(W_s)$。从技术层面，我们认为预期效用涉及对概率和结果的 可分离转换。概率是用于衡量不景气时期出现的频率，结果转换则是用于衡量投资者 对不景气时期的感受

预期效用概念的提出可以追溯到18世纪的数学家Gabriel Cramer和Daniel Bernoulli。 而普遍将其作为决策工具来应用，则是在John von Neumann和Oskar Morgenstern于1944 年发表《博弈论和经济行为学》（The Theory of Games and Economic Behavior）将预期 效用规范化之后。Von Neumann是现代最伟大的数学家之一，他在物理学和计算机科学 上也做出了开创性的贡献。他和经济学家Morgenstern开创了经济学的新领域—— 博弈论。博弈论研究参与者应该如何制定策略来互相竞争与合作，囚徒困境便是著 名的例子。Von Neumann和Morgenstern最初将预期效用应用于靠碰运气取胜的游戏； 预期效用理论只是博弈论整体理论的一个附属品。股票市场是一个靠碰运气取胜的游 戏——但不同于扑克，股票市场的概率空间是未知的。作为该理论的重要扩展，Savage (1954)指出当概率不是给定的，而是主观的、源自于参与者行为时，预期效用函数 仍然适用。因此，公式(2.2)中的概率既可以是客观也可以是主观的⁽¹⁾。

⁽¹⁾ 参见Schumaker (1982)中关于预期效用模型及其变型的总结。
