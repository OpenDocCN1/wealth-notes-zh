# ## 4.2  损失厌恶或前景理论

损失厌恶是由Kahneman和Tversky在1979年发表的一篇具有里程碑意义的论文中提出，它的产生最初是为了替代纯粹的、理性预期效用。不过，它其实是广义定义下预期效用的一种变形，因为它采用（主观）概率可分函数和回报效用函数来测量风险。Daniel Kahneman因其将心理学与经济学相结合的研究工作，尤其是他在前景理论上的研究，荣获了2002年诺贝尔奖。他的长期合作者Amos Tversky很遗憾在此之前已经去世，而未能获此殊荣。Kahneman和Tversky基于人们实际上如何做出决策形成了前景理论（这是一个实证理论）<sup>①</sup>。

前景理论由两部分组成。

### （1）损失厌恶效用

投资者发现，损失带来的痛苦要多于收益带来的喜悦。损失厌恶效用使收益和损失拥有不同的斜率（边际效用）。

### （2）概率转换

Kahneman和Tversky的研究超越了概率——甚至是主观概率。他们将概率转换为不一定服从概率法则的决策权重（*Decision Weights*）。例如，该权重不一定像概率一样加总为1。决策权重可以让投资者对于低概率事件赋予极高的权重，比如自然灾害和彩票中奖。
