上述估计结果与Fama–French模型回归的结果非常接近。与Buffett不认同动量投资的观点相吻合，UMD的系数接近于0（u = −0.04），在统计上也不显著。该回归的调整后为27%，与Fama–French模型回归相同，表明加入动量因子后并没有提高因子回归的拟合度。加入动量因子后，Buffett的阿尔法法（每月α = 0.68%）甚至比Fama–French回归得到的值（α = 0.65%）还略有提高。
