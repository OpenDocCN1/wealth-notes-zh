| 资产类别 | 交易间隔时间 | 年化换手率 |
| 公开市场股票 | 几秒钟内 | 超过100% |
| 场外交易（粉单市场）股票 | 一天内，但是许多股票间隔超过一周 | 大约35% |
| 公司债券 | 一天内 | 25% ~ 35% |
| 市政债券 | 大约6个月，其中5%的市政债券超过十年才交易一次 | 低于10% |
| 私募股权 | 基金存续期超过10年；投资期的中位数是4年；退出前在二级市场交易发生的概率相对较低 | 低于10% |
| 居民住宅 | 4 ~ 5年，但跨度可从几个月到几十年 | 大约5% |
| 商业房地产 | 8 ~ 11年 | 大约7% |
| 基础设施 | 初始承诺约50 ~ 60年，有些可长达99年 | 可忽略 |
| 艺术品 | 40 ~ 70年 | 低于15% |

大多数资产类别缺乏流动性

除了普通的公共市场股票和债券，大多数资产类别市场呈现出长周期的特征，交易间隔时间有时长达几十年，并且换手率非常低。即使在股票和债券中，有些子资产类别的流动性也非常低。场外交易市场的粉单股票交易可能一周或更长时间都没有交易。市政债券平均每年交易两次，而且整个市政债券市场的年换手率低于10%（参见第11章）。在房地产市场，独户住房（美国）的持有期通常为4 ~ 5年，而对于商业地产来说通常为8 ~ 11年。大型基础设施的持有期可达50年或者更长，而艺术品的周转时间平均为40 ~ 70年。因此，大多数资产市场是缺乏流动性的，就其交易频率很低且换手率低而言。

非流动性资产的市场很大

非流动性资产类别的市场很大，在规模上可以与公开发行股票市场相媲美。2012年，纽约证券交易所和纳斯达克证券交易所的市值总额接近于17万亿美元。美国的住宅房地产市场规模式计为16万亿美元，而直接的商业房地产市场规模为9万亿美元。事实上，传统的流动性高的股票和债券公开市场规模小于投资于非流动性资产的总财富。
