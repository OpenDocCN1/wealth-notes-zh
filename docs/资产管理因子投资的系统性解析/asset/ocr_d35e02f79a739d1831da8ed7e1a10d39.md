# **投资者流动性有限**

Jones对他创立的第一支对冲基金进行了流动性方面的限制。因为他的投资策略包括须交付抵押品的做空仓位，他进行了一定限制以防投资者在他须交付保证金时进行撤资。虽然不是全部，很多现代对冲基金跟Jones一样，并不允许投资者随时赎回（这点跟至少每天提供流动性给投资者的40法案基金不同）。

# **有限的透明度**

40基金须报告其持有的资产（对于共同基金来说至少每季度一次、对于交易所交易基金来说至少每天一次），但对冲基金具有保密性。大多数对冲基金仅提供粗糙的投资分布情况和模糊的投资策略细节①。自2012年3月30日起，规模在1.5亿美元以上的对冲基金被要求注册登记并报告资产、某些交易、经纪人、杠杆率、交易对手风险敞口和对低流动性资产定价的方法等信息②。但这些基金仅被要求向美国证券交易委员会报告，而无须向有限合伙人投资者报告。

# **管理费高且包含较高的业绩费用**

监管条例不允许共同基金收取非线性的管理费用（参见第15章），而对冲基金则可自由选择费用的收取方式。其收取费用中的很大一部分来自非线性的业绩费用。

# **2.3 对冲基金资金流**

据对冲基金数据库HFR统计，截至2012年末，投资在对冲基金的资产总量为2.25万亿美元。这个数字相对比较保守。由于对冲基金不受40法案较为严格的报告要求限制，该行业真实的总规模不为人知（仅仅是规模较大的对冲基金被要求向证券交易委员会报告，在2013年撰写本书时证券交易委员会并未公布其收到的相关表格信息）。需要注意的是HFR只是数据供应商中的一家，如果对冲基金选择报告数据的话，可以向不同的数据供应商提供数据③。
