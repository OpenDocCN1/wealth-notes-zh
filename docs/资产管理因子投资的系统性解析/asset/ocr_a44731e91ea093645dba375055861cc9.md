# （2）如果观测收益率不相关，那么去平滑化不会产生影响

在许多情况下，公布的非流动性资产收益率是自相关的，这是因为非流动性资产价值是通过评估得出的。评估过程会导致数据平滑化。因为评估人员正如他们所应该做的，采用了与历史评估价值（是估计价值或认知价值）相关的最新和最可比售价（交易售价）。这种来自评估过程中人为的平滑促使人们在房地产领域构建纯粹基于交易的指数，而非基于评估的指数②。一些更不可靠的主观估值过程也会导致自相关性——如管理人不愿意在市场下行时进行逐日盯市。

许多情况下，我们预期非流动性资产的真实收益率也是自相关的④。非流动性资产市场——例如房地产、私募股权、林业种植业和基础设施——这些市场的信息不是所有市场参与者都能获取，信息不会迅速扩散，而且资本不会立即配置到新的投资中。信息无效率的市场伴随着缓慢的资金流动使得非流动性资产市场呈现出稳定收益的特征④。
