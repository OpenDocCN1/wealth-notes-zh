从1986年1月至2011年12月间，GSCI的回报率为8.9%，标准差为20.7%。扣除无风险利率前的原始夏普比率为8.9%/20.3%=0.43*。与之相比，股票和债券在同时期的原始夏普比率分别为0.66和0.94。大宗商品期货回报率与股票和债券的低相关度（分别为14%和-9%），使其成为富有吸引力的投资对象。将大宗商品添加到传统的股票和债券组合中，可以获得很好的投资分散化效果（参见第3章）。

大宗商品可以对冲一些通货膨胀，但是它并不能完全对冲。广义GSCI指数与通货膨胀率的相关系数为29%。这反映了能源期货具有相对较好的对冲通货膨胀效果。原油本身以及所有能源类产品（包括原油、布伦特原油、无铅天然气、燃料油、柴油、天然气）与通货膨胀率的相关系数分别为23%和26%。非能源类期货对冲通货膨胀的效果不佳。例如，农产品与通货膨胀率的相关系数仅为-4%。包括黄金在内的贵金属以及黄金本身与通货膨胀率的相关系数分别仅有2%和1%。

表11.2也列出了大宗商品与工业生产增长率（每年同比）、VIX波动率指数之间的相关系数。大宗商品回报率，尤其是能源和农业，在经济增长时更高。大宗商品回报率与经济增长率的相关系数约为10%，比与通货膨胀率的相关系数更低。值得注意的是，贵金属与经济增长率的相关系数略为负值，这表示贵金属在经济不佳时提供了一定的保险价值，但该相关系数的绝对值低于10%。波动率是另一个因子：广义GSCI指数与VIX的相关系数为-18%，当波动率高时，能源和农产品表现较差。形成对比的是，贵金属与通货膨胀率几乎不相关。

综上，只有能源类大宗商品可以对冲通货膨胀，尽管如此，其相关系数也远远达不到1。能源和农产品期货在经济增长率低、波动率高时通常表现不佳。相对而言，贵金属的表现与宏观因子相对独立。

# ## 5.3 即期回报、现金回报和展期回报

# ### （1）即期（Spot）回报

是指大宗商品的现货价格发生变化带来的回报。

# ### （2）现金回报或抵押（Collateral）回报

是指进行期货合约交易时，交易所要求投资者拿出的抵押品（或保证金）所产生的利息。
