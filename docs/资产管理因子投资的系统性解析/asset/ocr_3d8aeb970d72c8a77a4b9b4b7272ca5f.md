# 3.1 因子回归分析

我们可以采用因子回归分析来估算得出风险调整后的基准，或者相对应的模拟组合。

# CAPM 基准

我们现在来考虑价值投资大师Warren Buffett的投资数据。我们使用伯克希尔·哈撒韦从1990年至2012年5月的月度回报率来进行下面的CAPM模型回归：

r_u - r_f = α + β( r_m - r_f ) + ε_u 公式 ( 10.9 )

其中普通最小二乘方（ordinary least squares）假设回归残差ε_u与市场因子相互独立。通过估计公式（10.9）中的CAPM回归，可以间接得到CAPM模拟组合的权重。对于伯克希尔·哈撒韦的估计结果如下：

表10.1

| 阿尔法 | 0.72% | 2.02 | 贝塔 | 0.51 | 6.51 | Adj R2 | 0.14 |

这表明CAPM基准包括0.49的美国短期国债和0.51的市场组合，即 r^hmk = 0.49r_f + 0.51r_m ，投资于伯克希尔·哈撒韦的$1等同于“（1 - 0.51）= $0.49的美国短期国债加上$0.51的市场组合”。

相对于这个基准组合，Buffett每月能获得 + 0.72%的阿尔法。

这算得上是非常好的业绩！Buffett使用大约一半的市场风险（β=0.51），产生了每年约0.0072×12 = 8.6%的阿尔法。我们将通过公式（10.9）的市场组合基准估计出来的阿尔法称为Jensen阿尔法（Jensen's alpha），以纪念Michael Jensen在1968年作出的关于共同基金业绩的开创性研究。（但是共同基金的业绩通常都不能战胜市场；参见第16章。）

该阿尔法在统计上是显著的，t统计值高于2。t值等于2对应着95%的置信水平，这是统计学家认为很神奇的一个临界值。Buffett创造的业绩确实不同凡响。大部分的因子回归都不能得到显著的阿尔法估计。上述CAPM回归的调整后决系数为14%，也比较高。对于大多数股票而言，CAPM回归得到的都小于10%。

① CAPM回归倾向于产生较低的、因为股票回报率的非系统性风险较大。从经济学上说，创建投资组合可以获得很大的多元分散化好处。参见第3章。
