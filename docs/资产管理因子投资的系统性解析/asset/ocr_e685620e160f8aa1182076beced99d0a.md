# 2. 劳动收入

劳动收入是财富的一种形式。它不能被交易（第13次修订法案废除了奴隶制），使得劳动收入不同于资产组合中的金融资产。我们一生的人力资本很大程度上在出生时就已经决定了，个人能通过教育来增加人力资本，而失业或疾病等情形会减少人力资本。个人劳动收入的风险——波动性以及其与金融资报回报的相关性——会影响个人的资产配置。

我们将人力资本视为一种资产②。假设我们将个人工资的折现值记为H（即人力资本）。人力资本是个人一生劳动收入的折现值；也就是与个人工资流相等的当期值。人力资本是有风险的，因为工资收入会波动——在最糟糕时可能会跌到零。

我们将金融资产记为W。总财富为H+W，换句话说，总财富是由人力资本和金融资产所组成。
