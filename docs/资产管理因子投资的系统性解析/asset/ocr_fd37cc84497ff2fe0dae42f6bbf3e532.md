经济学家不可能做到意见一致（比如，经济学家甚至在股票风险溢价的来源上存在意见分歧，如第8章所示，但我坚信股票在长期拥有比债券更高的收益，因此股票是一个风险因子）。基于这个标准，价值一成长、动量、做空波动率策略都是合适的风险因子。新的研究能别新的因子，或者证实大家之前普遍认可的熟知因子，或者甚至否定某些因子并相应地修改投资政策。

# （2）表现出预期能在未来有持续的显著溢价

我们不仅应该对为什么因子在过去存在风险溢价有所了解，而且应该有一定理由相信因子溢价在未来仍将普遍存在（至少在短期）。因子按定义是系统性的——因子溢价是由有望持续存在（至少在短期）的风险或行为偏好所产生的，即使所有人都知道这些因子，而且许多投资者都采用类似的因子策略$ ^{①} $。

# （3）存在不景气时期的历史收益数据

因子风险溢价存在的原因，是为了补偿投资者愿意在不景气时期遭受损失。能有一些衡量最坏情景的数据，对于评估风险收益特性和风险管理很有必要（参见下文）。我们也希望历史数据能有合理的时间长度以便执行这些操作。

# （4）能通过流动性好的可交易工具来执行

正如加拿大养老金投资委员会（Canada Pension Plan Investment Board, CPPIB）的参考组合那样，因子策略应该非常便宜，最好能通过流动性好的证券来构建实现。对大型投资者来说，规模性是重要的要求之一。

因子策略往往涉及杠杆。比如，投资者需要在高配价值股的同时低配或做空成长股，做多价值股和做空成长股就是一种动态杠杆策略。即使无法做空，因子策略也仍然有效：Israe l和Moskowitz（2013）研究表明，即使投资者不能做空，价值和动量因子的溢价仍然显著存在，但这些因子策略的利润减少了50%～60%。

将投资者局限于流动性证券，似乎使得构建因子的非流动性溢价不太可能，但实际情况并非如此。投资者可以通过在流动性市场上做多流动性（相对）欠佳的资产、做空流动性（相对）较好的资产，来获取非非流动性溢价。研究结果表明，（流动性）资产类别内部的非流动溢价远高于跨资产类别如私募股权、对冲基金和其他非流动性资产（参见第13章）的非流动性溢价。这些非流动性资产还存在着错综复杂的委托代
