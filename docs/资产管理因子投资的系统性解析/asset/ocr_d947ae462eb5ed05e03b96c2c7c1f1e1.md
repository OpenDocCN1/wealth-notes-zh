比之下，股息增长的标准差为9.6%，所以收益波动率要比基本面波动率高。然而，将盈利作为基本面时情况却不同，盈利增长的波动率为36.0%，不会出现过度波动率问题。但盈利不能直接用于对股票进行估值，因为获得盈利的公司是同时被债券和股票持有人所拥有的（而且盈利是一个会计概念，并非真实的现金流支付）①。而股息只派发给股东。股票收益波动率比股息波动率高的事实反映了Cochrane与Bansal-Yanron的辩论中所说的风险溢价的部分可预测性来自于贴现率而不是现金流。

Robert Engle（1982）开发了预测波动率的模型，被称为ARCH模型（即“autoregressive conditional heteroskedasticity”，自回归条件异方差）。这是个又长又拗口的词，它的意思是指，条件波动率会随着时间而变化（“heteroskedasticity”是希腊语中“different dispersions”（不同量差）的意思）并且是以自回归（“autoregressive”）的方式。该模型被Bollerslev（1986）扩展为GARCH，即“generalized autoregressive conditional heteroskedasticity”（广义自回归条件异方差），这是业界和学术著作中使用的名字。GARCH模型彻底改变了波动率建模，尤其是对于风险管理领域。Engle因此被授予了2003年诺贝尔奖。

在基本的GARCH模型中，条件方差σ<sup>t</sup><sup>2</sup>，满足以下公式②：

```
σ<sup>t</sup><sup>2</sup> = a + bσ<sub>t-1</sub><sup>2</sup> + cε<sub>t-1</sub><sup>2</sup>  公式（8.8）
```

公式（8.8）的主要含义是，波动率取决于它自身，因此是持续的（通过接近1的系数b）或者说是自回归的，并且它会受到过去冲击的影响（通过系数c）。所以，大的冲击——如1987年（股票市场崩盘）、1998年（俄罗斯违约以及新兴市场危机）、2008年（雷曼破产）——会导致更高的未来波动率。一旦这些冲击发生，波动率会在均值回归之前维持在高位一段时间。这使得GARCH模型能捕捉到市场动荡和平静的不同时期。我们可以从图8.6中看出这点，图中按月度画出了1990年1月至2012年12月GARCH预测的波动率与实际的波动率（用当月的每日实际收益来计算）。月初的GARCH波动率与下个月的实际波动率之间的相关性为63%。将此相关性与我们预期可以预测未来股票风险溢价的不到5%的相关性比较一下，足以看出在股票市场中波动率更容易被预测。

如果波动率如此可被预测，那么波动率交易应该能够获得很好的投资收益。的确如此。尽管前面我对预测预期收益持悲观态度，但我对预测波动率的投资策略要乐观许多。
