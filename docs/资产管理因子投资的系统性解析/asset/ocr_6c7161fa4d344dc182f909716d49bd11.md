# 4. 多因子模型

多因子模型认识到对不景气时期的界定可以更为广泛，而不仅限于低市场组合回报。首个多因子模型是由Stephen Ross（1976）发展起来的套利定价理论（arbitrage pricing theory，APT）。采用“套利”一词是因为这些因子无法通过套利或多元分散化投资而消除——正如CAPM模型中的单个市场因子。在均衡状态下，投资者因为承担了多种因子风险而必须获取相应补偿。CAPM模型给出的不景气时期仅仅是指市场组合的低投资回报时期，而多因子模型的各个因子都对不景气时期给出了各自的定义。

# 4.1 定价核

新的资产定价方法采用定价核（pricing kernel）概念来捕捉多因子模型中的复合不景气时期。这也被称为随机贴现因子（stochastic discount factor，SDF）。我们用m来表示SDF。SDF是一个不景气时期指数，即将不景气时期按不同因子及不同状态编制为指数而成。由于所有近期相关的资产定价理论均采用这一概念和术语，所以我们有必要花些时间来理解SDF方法与传统CAPM方法之间的相互关系。采用SDF方法，我们同样可以得出一些有用的直观推断（如果你倾向于少些技术推导，可以略过后面两小节，从第三节开始阅读）。

通过采用单一变量m来捕捉所有的不景气时期，我们可得到一种非常有效的表述来涵盖具有多个变量的多种不景气时期。CAPM模型实际上是m与市场回报呈线性相关时的特例，①常数为a和b：

```
$$ m=a+b \times r_{m} $$
```

（与市场回报呈线性相关的定价核使得公式（6.2）中的SML具有与市场相关的资产贝塔。）采用m符号，我们可以轻松地将多因子通过基于因子向量的SDF来表示，多因子向量可表述为F=(f₁, f₂, ⋯, f_K)：

```
$$ m=a+b_{1}f_{1}+b_{2}f_{2}+\cdots+b_{K}f_{K} $$
```

+   ① 常数a和b可采用公式（6.3）推导如下：

$$ a=\frac{1}{1+r_{f}}+\frac{\mu_{m}\left(\mu_{m}-r_{f}\right)}{\left(1+r_{f}\right)\sigma_{m}^{2}} \text {, } b=-\frac{\mu_{m}-r_{f}}{\left(1+r_{f}\right)\sigma_{m}^{2}} $$

其中$\mu_{m}=E\left(r_{m}\right)$和$\sigma_{m}^{2}=var\left(r_{m}\right)$分别是市场回报的均值和方差。请注意，与m相乘的系数b为负数：SDF值较低意味着不景气时期，在CAPM模型中是指市场的低回报。
