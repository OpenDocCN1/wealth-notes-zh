# 2.3  包含风险劳动收入的资产配置

我们来考虑一个有风险劳动收入的投资者。我们需要判断他的劳动收入看上去是像股票还是像债券。如果你正在读这本书，你大概是从事金融相关行业，所以你的劳动收入可能与股票呈正相关。我的很多MBA学生的人力资本与股票市场高度相关。

劳动收入和股票收益之间的正相关性会减少投资者金融资产组合里风险资产的最优配置比例。在这种情况下，人力资本等同于配置了股票。你希望减少金融资产组合里的股票比例以抵消类似股票的人力资本。但减少股票的配置并不能消除你的劳动收入带来的类似股票的风险。简而言之，当人力资本比较接近股票时，你实际上已经拥有股票，所以你的金融资产组合里应该配置更少股票。

那些工资与股票收益呈负相关的投资者呢？这些人通常会在股票市场低迷时期赚得更多。例如破产律师、擅长指导企业扭亏为盈的专家以及收债人。这些投资者的人力资本与股票呈反向变动，所以他们的资本是反股票（anti-equities）的。如果是这样，他们会希望在金融资产组合中持有更多股票来抵消人力资本的反股票性。所
