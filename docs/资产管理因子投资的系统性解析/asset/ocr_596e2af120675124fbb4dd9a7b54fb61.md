# ## 1. 2008~2009年金融危机

2008~2009年金融危机期间，大部分风险资产的价格骤跌。如表6.1所示，2008年美国大盘股的收益为-37%，非美发达市场股票和新兴市场股票的损失更为惨重。固定收益产品中相对高风险的公司债、新兴市场债和高收益债，也与房地产齐跌。对冲基金等“另类”投资虽然鼓吹自己对市场扰动具有免疫性，却并非安全避难所：股票对冲基金和固定收益对冲基金均下跌20%左右。大宗商品则损失逾30%。2008年唯一上涨的资产是现金（美国短期国债）和避险港国家的主权债，尤其是美国长期国债。

为什么这么多资产类别都在金融危机期间同时崩盘？这种同跌是否意味着多元分散化投资概念的失效呢？

本章我们主要阐述因子风险溢价理论。不同因子风险会构成不同类型的不景气时期，承担这些因子风险的投资者在均衡状态下需要获取相应的因子风险溢价作为补偿。资产的风险溢价并非源于资产本身，而是因为资产是由一系列因子风险组成，实质上是资产所隐含的因子风险敞口所获取的风险溢价。这些因子风险在不景气时期表现明显，如2008年末和2009年初的金融危机期间。
