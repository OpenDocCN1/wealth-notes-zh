合规性。

40法案最重要的要求之一是基金的资产独立于基金管理人的资产。共同基金管理 公司有三种方法对投资进行隔离保管：通过银行（最受欢迎的方式），通过经纪公司 （较为少见）和自我保管。如果自我保管，有严格的监管条例要求基金资产必须和公 司的其他资产实质性隔离。

40法案也限制基金、基金管理公司和关联公司之间的交易类型。在大萧条之前和 期间，很多基金管理人以低于市价的价格从基金购买资产，或者基金向内部人士以虚 高的价格购买资产，或者基金为管理层提供低成本贷款。40法案明令禁止这些侵犯投 资者利益的行为。

# 受托责任标准

40法案要求注册投资管理人遵循一定的受托责任标准（fiduciary standard），意味 着他们必须以客户的利益最大化为行为准则。经纪人不是受托责任人，遵循适宜性标 准（suitability standard），意味着不必找到对投资者最好的产品，仅仅是适宜的产品 即可。是这样的，多数出售共同基金的经纪公司和投资咨询公司并不是必须把投资者 利益放在第一位。即使投资咨询公司是一个注册投资管理人，受托责任标准也不能完 全消除委托代理问题，正如第15章中强调的一样。

# 限制杠杆率

最初的40法案的第13（a）章节提道：“除非在有投票权的股份以多数票通过的 情况下，注册投资公司不可以借款投资。”如今杠杆已被允许，但美国证券交易委员 会仍然限制其使用。共同基金最多有300%的资产覆盖率（最多可以借33.3%），封 闭式基金相对债权最多可以有300%的资产覆盖率，相对优先股最多可以有200%的 资产覆盖率。很多基金选择完全不借钱投资，并且对它们的投资风格设置了一些其他 限制¹。
