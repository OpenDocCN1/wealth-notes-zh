NYSCR F面临着与企业养老金计划同样的委托代理问题，包括管理人的自利以及管理人与受益人激励机制不一致等问题。但作为一家公共养老金计划，NYSCR F还涉及关于纳税人与政客利益冲突的其他委托代理问题，因为最终是纳税人为养老金的负债承担剩余责任¹。公共代理人经常面临着能为员工支付多高薪酬的限制，因此最有才能的投资管理人一般来说并不会供职于公共养老金计划。而立法和政治方面的流程也会阻碍公共养老金计划的管理。

纽约总检察长Eric Schneiderman曾批评过这种唯一受托人的模式。他说：“唯一受托人的身份赋予了比一个好的审计长所想要的、比一个腐败的审计长所应有的还更多的权利。”²

然而，一个由多位受托人组成的董事会（而非集所有权力于单一的单一受托人）也有其自身的劣势。由政客、政府官员或者工会任命的受托人可能不具备投资才能，并且可能被特殊利益群体所主导，或者他们可能根本就是骗子。

那么对NYSCRF来说，什么才是正确的治理模式？

# ## 2. 委托代理问题

资产所有者通常不直接管理自己的财富，而是雇佣资产管理人。这就产生了代理问题。资产所有者是委托人，他们将组合管理职责委托给基金管理人，即代理人。“委托人”和“代理人”的术语来自于普通法系。

代理问题是由Ross（1973）引入经济学中的——正是那位开发了多因子模型理论（参见第6章）的Stephen Ross。代理问题随处可见：它们出现在雇主与雇员、房东与房客、客户与律师、病人与医师、公众与政客等关系之间。在资产管理领域，委托人是基金所有者，而代理人是基金管理人或顾问。
