# 3. 再平衡相当于做空波动率

再平衡是一个期权策略，更准确地说，是一个做空波动率策略（short volatility strategy）。(期权交易员们将再平衡称为负伽马（negative gamma）策略。）此说法 并不为人所熟知，但对于熟悉金融理论的读者来说并不陌生，因为第2节中求解长期组合选择问题（即动态规划）的方法也被运用于期权估值（被称为递推法（backward induction））。通过展示再平衡如何在机制上等同于一种做空波动率策略，可以让我们更深入地理解长期投资者使用再平衡策略的得失。毕竟天下没有免费的午餐，至
