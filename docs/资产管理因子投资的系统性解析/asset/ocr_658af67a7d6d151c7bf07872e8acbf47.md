# （2）忽略了风险

非流动性资产类别包含的风险远不止非流动性风险。调整这些风险后，使得非流动性资产类别不再那么具有吸引力。第10章指出NCREIF房地产指数的收益（尽管原始收益率看上去十分诱人），还不如普通的由60%股票和40%债券构成的投资组合收益。第17章和第18章将分别指出对冲基金和私募股权基金的平均预期超额收益为零。尤其是在风险调整后，大多数投资者投资标普500指数比投资私募股权基金的回报更高。

# （3）非流动性资产类别没有“市场指数”

没有投资者能取得非流动性资产指数的收益率。例如，任何资产所有者都不会从房地产投资组合中获得NCREIF指数的收益率。这一点对大多数对冲基金指数和私募股权指数同样适用。在流动性高的公开市场中，大型投资者只要支付很低的费用（接近于零）就可以获得指数的市场收益。相比之下，NCREIF指数是不可投资的，因为投资者不可能买到指数中的所有房地产。与NCREIF指数包含成千上万的房地产相比，所有的资产所有者仅持有极少的房地产，因此他们面临着更大的非系统性风险。大量的非系统性风险在某些情况下能提高回报，但也可能导致相反的结果。投资于非流动性资产的收益率可能远低于公布的指数收益率。

# （4）无法区别因子风险与管理人水平

股票和债券市场的可交易且低廉的指数基金，使得投资者能将系统性收益（或因子收益，参见第7章）区别于管理水平。而在非流动性市场，这种区分是不可能的：投资非流动性市场通常是看好其管理才能。非流动性资产市场中的代理问题至关重要，我会在本书的第三部分进行讨论。代理问题可以而且经常会压倒非流动性风险溢价所带来的任何优势。

正如Ang、Goetzmann和Schaefer（2011）所阐述的⁽¹⁾，将数据偏差纳入考虑后，关于资产的平均收益率会随着资产类别流动性变差而变高的各项证据无疑是混杂在一起的。不过，尽管资产类别间似乎没有显著的非流动性风险溢价，但在资产类别内还存在着较大的非流动性风险溢价。

> ① 然而，不同资产类别之间的非流动性情形存在共同点。比如，当美国国债市场的流动性欠佳时，许多对冲基金也趋于表现不佳。可参见Hu、Pan and Wang（2012）的例子。
