度大到能产生富有吸引力的高预期收益时，就会买入价值股。价值投资本身具有稳定平衡机制。动量投资则是正回馈策略（positive feedback strategy）。历史收益高的股票更有吸引力，动量投资者持续买入这些股票导致其价格进一步上升。如图7.6所示以及我将在后面讨论的，正回馈策略最终会打破稳定平衡，也因此会不时地面临亏损。

动量的存在与我第4章建议长期投资者做再平衡操作的建议并不矛盾。动量投资主要是一种资产类别内部的横截面策略：选取一组特定股票（历史收益高的股票）与另一组股票（历史收益低的股票）相对比。相反，再平衡策略主要是在资产类别之间或策略层面操作，因为再平衡往往需要资产或策略长期存在，而单个股票可能会消失。动量因子与价值因子一样，也存在于不同的资产类别中①。动量投资可作为长期投资者机会型策略的一部分（如Merton（1969）提出的长期对冲需求组合）。

动量因子经常作为可投资因子被加入到Fama-French模型中②：

```
$$E(r_{p}) = r_{f} + \beta_{i, MKT} E(r_{m} - r_{f}) + \beta_{i, SMB} E(SMB) + \beta_{i, HML} E(HML) + \beta_{i, WML} E(WML)$$
公式(7.4)
```

与Fama-French模型给出的直觉逻辑相一致，动量贝塔$\beta_{i, WML}$值也基本在零附近。历史表现优异的股票具有正动量贝塔，运用公式（7.4）其风险溢价会有所上调。历史表现欠佳的股票具有负动量贝塔，其风险溢价相应会有所下调。市场组合则既非相对优胜股又非相对失败股，仅仅是代表整个市场而已。

# ## 动量风险的特征

如图7.6所示，尽管动量策略平均而言能带来高收益，但也容易不时地出现亏损，有些亏损甚至长达好几年。Daniel和Moskowitz（2012）对此展开了具体研究。在动量策略出现的11次最大亏损中，有7次发生在20世纪30年代的大萧条期间，1次发生在2001年，另外3次则发生在2008年金融危机期间。金融危机期间表现不佳的股票主要是急速下跌的金融股：花旗（Citi）、美国银行（Bank of America）、高盛（Goldman）、摩根斯坦利（Morgan Stanley），以及受大形势拖累而遭受重创的其他股票如通用汽车（General Motor）。表现不佳的股票有继续亏损的趋势，如果不是山姆大叔出手援救，这些股票会持续亏损。政府的紧急援助为这些股票的价格托了底，股票价格随后飞跃。由于动量策略做空了这些股票，所以当股票价格反弹时，动量投资者遭受了巨大损失。值得注意的是，动量投资的其他几次较大损失主要集中在大萧
