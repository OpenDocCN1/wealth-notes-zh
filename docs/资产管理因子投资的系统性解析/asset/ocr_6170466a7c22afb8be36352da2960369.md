著名的泰勒法则（Taylor Rule）认为，联邦基准利率应该与通货膨胀率和经济活动相关，它的原始方程式是：

```
$$FF_{t}=r^{*}+\pi_{t}+0.5(\pi_{t}-\pi^{*})+0.5Gap, \qquad \text { 公式 (9.1) }$$
```

$FF$表示联邦基准利率，$r^{*}$表示长期实际利率，$\pi$是当前的通货膨胀率，$\pi^{*}$是目标通货膨胀率。$Gap$是产出缺口，即实际$GDP$与潜在$GDP$之差。泰勒法则既是一种描述性工具（美联储做了什么），也是一种预测性工具（美联储应该做什么）。

泰勒法则抓住了美联储的双重任务，即描述当产出缺口和通货膨胀率发生变化时，美联储应如何调整联邦基准利率。产出缺口的系数是0.5（在不同数据和后续理论中，该系数有所不同）。如果产出缺口收缩、经济活动放缓，美联储应当降低联邦基准利率来刺激经济增长。公式（9.1）中通货膨胀率$\pi$的系数是1.5，它被分为第一项$r^{*}+\pi$和第二项$0.5(\pi-\pi^{*})$。第一项是实际利率与通货膨胀率之和，根据费雪假设（参见下文）应当等于名义短期利率。第二项是当前通货膨胀率与目标通货膨胀率之差。当通胀上升时，美联储提高联邦基准利率来抑制物价上升。由于通货膨胀率的总系数大于1，表示当通胀上升时，美联储提高利率的速度快于通货膨胀率上升的速度（大于$1:1$），这意味着此时，美联储提高了实际利率。这被称为泰勒原理（Taylor Principle）。

泰勒法则发展出许多不同的版本，用以描述美联储对于通货膨胀和经济增长的反应方式。这些模型使用了对通货膨胀率（如$GDP$平减指数、总$CPI$、核心$CPI$、$PPI$等）或经济增长（$GDP$增长率、产出缺口、工业生产增长率、就业率等）的不同定义。公式（9.1）包含的重要概念是，美联储会对通货膨胀和增长基本变化作出反应。泰勒（1993）之后发展出来的其他模型使用了前瞻性的指标，例如调查或代理人预期（前瞻法则），以及除了当前通货膨胀率和产出之外的其他历史数据（回溯法则）。泰勒法则的不同版本还可以适时进行调整，反映美联储仅对部分信息作出反应时（部分调整法则）的情况$^{②}$。我们将联邦基准利率真实值与泰勒公式中算出的联邦基金
