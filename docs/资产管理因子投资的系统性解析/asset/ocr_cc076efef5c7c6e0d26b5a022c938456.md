# 1. 哈佛清算案例

没有人想到资产清算事件会在哈佛发生(¹)。

2008年，金融危机导致全球范围的资产价格暴跌，哈佛大学捐赠基金作为全球最大的大学捐赠基金，也未能幸免于难。与自1980年起15%的平均年化收益率相比，哈佛大学捐赠基金遭遇了历史上最惨烈的跌幅，仅在2008年7月1日至10月31日之间就下跌了22%。超过80亿美元的市值在短短三个月内蒸发。

考虑到由于捐赠基金规模萎缩而即将发生的预算缺口，哈佛大学校长Drew Faust和执行副校长Edward Fostat在2008年12月2日向院长理事会发出了警示通知，要求各学院缩减开支和待遇，并收缩扩张以应对锐减的收入。他们谨慎地指出基金的实际损失甚至比外界报道的金额更大：“即使这一发人深省的数字也还是无法完整地反映这段时期的所有实际损失，因为它并没有体现某些在管资产类别全面更新后的估值，最明显的是私募股权和房地产。”(²)

哈佛大学依靠哈佛捐赠基金的收益来支付很大一部分学校费用。截至2008年6月30日的财年，超过1/3的运营收入来自于捐赠基金收益。对于学校的某些院系来说，这个比例甚至更高，比如：拉德克利夫高级研究学院、神学院以及艺术与科学学院来自捐赠基金的收入占比分别为83%、71%及52%。
