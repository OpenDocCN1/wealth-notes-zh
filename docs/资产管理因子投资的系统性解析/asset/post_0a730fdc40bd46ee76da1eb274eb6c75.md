## 4. 信用利差（公司债）

到目前为止，我们的分析都是基于债券无风险的假设。对于公司债而言，它会受到所有影响无风险债券的因素的影响，此外，我们还需考虑信用风险，或违约风险。我们可以看到，公司债利差，即公司债与国债的收益率之差，并不只是包含信用风险。

### 4.1 公司债的风险和回报

图9.11展示了从1973年1月至2011年12月间，公司债收益率与国债收益率之差。从AAA级（非常安全）到Caa级（高收益债，或垃圾债），风险逐渐增加。各种公司债利差之间有很多相似之处，尤其对于投资级公司债（评级在Baa或以上级别）。图9.11可以看到这些公司债利差随着经济周期而发生变化。在1970年代中期、1980年代早期、2000年代早期以及最近的金融危机时期，利差都大幅攀升。此外，垃圾债的利差水平和利差波动率都明显高于投资级公司债。

然而，高收益率并不一定能带来高回报率。表9.5列出了从1987年1月至2011年12月间，公司债利差和回报率的数据。公司债相对于国债的超额回报比较平稳，并明显低于公司债利差。AAA级公司债相对于国债的利差是0.93%，但相对于国债的超额回报仅为0.32%。Baa级公司债的利差是2.09%，但超额回报仅为利差的一半，约1.04%。垃圾债的利差达到10.19%（也可参见图9.11），但超额回报仅为0.86%，甚至比Baa级公司债的超额回报还低。同时，垃圾债超额回报的波动率达到16%，与股票的波动率相当。表9.5也列出了夏普比率，AAA级公司债为0.12，Baa级上升到0.22。垃圾债的夏普比率仅为0.05，低于所有评级的投资级公司债。

为什么高收益率并不意味着高回报率呢？Ilmanen（2011）认为，与收益率中的高信用利差相比，实现回报率中较低的信用溢价可以归因于信用和流动性溢价（约30~60个基点）以及期权调整利差（OAS，约70~100个基点）。期权调整利差是指公司债在发行时常常包含了嵌入式衍生品，原始的信用利差需要根据这些衍生品的成本进行调整。这些衍生品对于债券买方而言通常是一种成本，而对于债券发行方则是一种收益。Ilmanen同时指出，这些债券在评级时会存在系统性偏差。这种偏差通常是降级偏差，当信用环境恶化时，公司的信用评级更倾向于被调降至风险更高的级别，这些原先是投资级的公司债可能被降至垃圾级，因此垃圾级“过度计算”了债券违约的可能。尽管这样，信用风险溢价的大部分确实是自然反映了信用风险。

### 4.2 违约模型

结构性违约风险模型始于Robert Merton（1974）。这些模型都是植根于同一个基本理念，即Black-Scholes（1973）的期权定价公式。事实上，Black-Scholes期权定价模型在他们最初的论文中的实际应用之一就是用于公司债的估值。

结构性违约模型可以模拟算出公司的价值。如果公司价值降至某一预设值之下，那么该公司即被视作违约。在违约时，债券持有者可以收回债券面值的一部分。通过简单的案例，我们可以定性地模拟出公司价值，但是定量模拟则需要更为复杂的模型。在最初的违约模型中，预设值被外生地（exogenously）设定为债券面值。在最新的结构性违约模型中，违约的预设置是内生的（endogenous），因为公司可以通过选择最优的违约时点来实现股东价值最大化。当公司处于财务困境时，债券持有者们也可以决定何时触发公司破产程序①。

① 第一篇研究内生性违约边界的文章是Leland（1994）。Broadie，Chernov and Sundaresan（2007）则讨论了股东或者债券持有者主动发起违约的案例。

违约模型的关键点是，债券可被视作一种对于公司资产的看跌期权。我们用V来表示公司价值，即公司标的资产价值（企业价值，Enterprise Value）。假设该公司发行债券的面值为100美元。在债券到期时，债券持有者得到的回报是：

**表9.6 债券持有者的回报**

| 债券持有者的回报 | 公司价值V<100美元 | 公司价值V>100美元 |
| :--- | :---: | :---: |
| | V | 100美元 |

如果公司价值低于100美元，债券持有者可以得到整个公司，价值是V。如果公司价值高于100美元，债券持有者得到100美元，股东得到剩余价值（V-100美元）。我们可以画出如下示意图：

![](img/e2a8f768e844f37dcab93b54b9e826d9_311_0.png)

这些回报可以等同于：

**表9.7**

| | 公司价值V<100美元 | 公司价值V>100美元 |
| :--- | :---: | :---: |
| 持有无风险债券 | 100美元 | 100美元 |
| 卖出一份行权价为100美元的看跌期权 | V-100美元 | 0美元 |
| 总计 | V | 100美元 |

这样，公司债持有者的回报等同于持有一份无风险债券，并卖出一份行权价等于债券面值的看跌期权。债券持有者卖出的这份基于公司资产的看跌期权，相当于做空波动率（short volatility）。相对地，股东相持有基于公司资产的看涨期权，相当于做多波动率。

按照这种分解方式，我们可以看到

持有无风险债券+卖出看跌期权=持有公司债

或

持有公司债-持有无风险债券=卖出看跌期权 公式（9.4）

因此，公司债利差等于卖出看跌期权的价值，该期权的标的资产是公司资产，行权价等于债券的面值。该信用利差随着波动率、杠杆率和到期期限的增加而增加。

“信用利差是一种看跌期权”的直观逻辑在于，股东具有有限责任，其获得偿付的顺序后于债券持有者。股东相当于是向债券持有者借入了等于债务面值（在上述例子中是100美元）的资金。当公司价值太低时，股东可以一走了之，直接把公司抵押给债券持有者。这相当于是股东买入了一份看涨期权。根据买卖期权平价关系，股东拥有公司的看涨期权——股东做多头率，债券持有者做空头率。从另一个角度来看，股东拥有全部的上行收益空间，即公司资产的看涨期权。债券持有者只有下行风险，在公司价值上涨时无法获得任何额外收益。因此，债券持有者计入了这种下行风险，即卖出看跌期权。

根据公式（9.4）可以推测出，信用利差随着波动率的增加而变大。图9.12-A画出了从1986年1月至2011年12月间，波动率指数VIX（衡量期权的隐含波动率）和Baa级债券与国债的信用利差（简称Baa国债利差）；B图画出了VIX和Caa级债券与国债的信用利差（简称Caa国债利差）。这两图的左轴标记的是VIX，右轴标记的是信用利差。VIX与Baa国债利差的相关系数为64%，与Caa国债利差的相关系数为56%。可以看到，波动率是决定公司债信用利差的重要因素，高波动率通常伴随着高信用利差和低实现回报率。在图9.12的两图均可注意到，1987年股市崩盘导致的波动率短暂飙升并没有反映在公司债利差中；该事件的影响仅限于股市。在1990年代早期和2000年代早期，Caa国债利差先于Baa国债利差开始上升，而波动率的上升更是先于这两种信用利差的上升。在2007～2008年的金融危机中，波动率和信用利差几乎是同时飙升，在2009年市场稳定后又同时下降。概括地说，信用投资是一种做空波动率的投资。

### 4.3 信用利差之谜

预期违约损失率可由以下公式求得

预期违约损失率 = 违约概率 × (I - 违约回收率) 公式 (9.5)

其中，违约回收率是指在企业发生违约时，债券持有者可以收回的资金占债券面值的比例。结构性违约模型可以给出影响违约概率和违约回收率的诸多因素，如上所述，最值得注意的是波动率。尽管信用利差确实反映了违约风险，但信用利差的变动似乎与那些衡量违约概率和违约回收率的变量不相关。此外，在简单的结构性模型中，公司债利差比按照预期违约损失率推算的理论值高好几倍。这被称为信用利差之谜（Credit Spread Puzzle ）。①

① 参见Huang and Huang（2012）中对于信用利差之谜的综述。

表9.8列出了公司债与国债的利差以及Moody's提供的信用损失率。根据公式 (9.5)，信用损失率包含的损失等于违约的部分扣除发生违约时可以回收的部分。对于投资级债券，其信用利差是其信用损失率的好几倍。但是，对于垃圾级债券，其信用利差基本等于其信用损失率。

不仅在表9.8中的样本区间中，而且在更长的区间内，我们都可以观察到信用利差之谜。Giesecke等人（2011）研究了从1866～2008年这150年间的美国公司债利差，他们发现长期的平均信用损失率约为每年0.75%，其中有一些时期的损失率明显偏高：1870年代（铁路繁荣与崩溃）、1930年代（大萧条）以及2011年（互联网泡沫破裂）。同期平均信用利差为1.5%，比信用损失率高约80个基点。

信用利差之谜类似于第8章中的股票溢价之谜。新的模型通过随时间而变化的风险溢价来解释信用损失率和信用利差之间的巨大差异，可以捕捉到高股票风险溢价和高信用利差。由于公司债和股票构成了公司的总价值，因此这两者一定是相互关联的。公司债券持有者拥有第一索偿权，而股东拥有剩余收益。这样，当公司总价值发生变化时，我们将看到公司债价值和股票价值发生变化。当公司价值缩小到损害债券持有者利益的时候，股票和债券的回报率都会很低。（这就是4.2节的例子中V<100时的情况）

![](img/e2a8f768e844f37dcab93b54b9e826d9_314_0.png)

图9.13显示了从1983年7月至2011年12月间，Baa投资级债券、Caa高收益债券和股票相对于国债的超额回报一年移动平均值。这三项超额回报均已按照股票超额回报的波动率（在此样本中为16.2%）进行了同比例调整。从图9.13可以看到公司债超额回报与股票超额回报有明显的相似之处；在这一样本区间中，Baa级和Caa级债券超额回报与股票超额回报的相关系数分别为48%和65%。从图9.13还可以看到在2005年以后，尤其是在金融危机期间，它们之间的同步性更加明显。股票和公司债在2008~2009年都遭受了重创，在2009~2010年开始反弹。2005年后，上述两项相关关系数分别升至65%和84%。因此，公司债可以被看作股票回报的缩比例版。

同样的，我们可以用这个逻辑来解释信用利差之谜①。低增长或衰退对于股票和债券都是一段“不景气时期”（这与第8章对股票的分析相同）。这些股票的“不景气时期”，对于公司债也是“不景气时期”。在这些时期中，公司业绩不佳，出现了更多的违约事件，股东为保住公司价值而选择提前进行公司清算。根据4.2节的结构性信用模型，当发生衰退时，清算边界就随之上升。即相比于公司在经济繁荣时违约，如果公司在经济衰退时违约，债券持有者可以回收的资金比例也将变少。这样，在“不景气时期”，公司债投资者与股东都面临着相同类型的宏观风险敞口。高信用利差相对于信用损失率偏高，反映了投资者的风险厌恶情绪，因为当公司债损失发生在经济衰退时，这恰好是投资者承受能力最低的时间点。只有当投资者在经济衰退时承受住高损失，才能最终将公司债的风险溢价收入囊中。

① 如需了解这些模型，参见Chen、Collin-Dufresne和Goldstein（2007）和Chen（2010）。

### 4.4 公司债的流动性风险

流动性风险——在市场上以低成本进行交易的能力——是决定公司债回报率的重要因素。Collin-Dufresne、Goldstein和Martin（2001）认为流动性风险、宏观经济风险以及整体金融环境风险合起来可以解释40%的信用利差变化。Longstaff、Mithal和Neis（2005）发现，信用利差中所有的非违约成分都可以被归因于流动性。在金融危机中，流动性对于决定公司债回报率起了至关重要的作用。图9.14显示了从2006年1月至2009年10月间，Baa级债券与国债的利差（左轴）与新券/旧券流动性因子（右轴）的关系（图9.14中的公司债利差与图9.11中的国债期限利差很相似）。信用利差的变动反映了流动性的变动，两者的相关系数高达96%①。公司债的流动性风险敞口相当大。

# 5. 关于美国信用评级下调回顾

2011年8月，标准普尔公司史上首次下调美国的信用评级，但美国国债收益率却不升反降。如果在其他情况不变的前提下，美国信用风险增加，美国国债的投资者应该要求更高的风险溢价，这样会使收益率上升，而不是下降。影响债券价格，尤其是国债价格的一个重要因素是流动性和波动率风险。美国国债具有的安全属性使其在经济低迷时会非常受投资者青睐。在欧洲债务危机持续动荡之时，即使调降美国信用评级，投资者也不得不将大量资金转移到作为避风港的美国国债，从而压低国债收益率。

流动性是美国国债的次要特征。对于所有固定收益产品而言，最重要的是水平因子，该因子会使收益率整体向上或向下平移。美联储对经济增长和通货膨胀反应方式的改变，会极大地影响水平因子。随着经济增长加速或通货膨胀率上升，美联储需升息使经济降温。因此，债券价格既可以反映经济因子风险，尤其是通货膨胀风险，也可以反映预期外的货币政策冲击。

在本章中，我们将美国国债视为无风险产品。美国信用评级在2011年8月的下调，意味着它不再是完全无风险的产品。我们将在第14章分析主权债务风险，包括它对最优组合选择的影响。
