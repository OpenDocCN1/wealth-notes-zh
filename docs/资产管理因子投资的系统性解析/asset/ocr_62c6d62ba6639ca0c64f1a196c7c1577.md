投资者相比有何行为差异。

# 3.5 小结

因子投资需要投资者与平均投资者相比，看其分别如何应对不景气时期。如果你是平均投资者——平均投资者并没有什么不好——那么就持有市场组合。如果你不同于平均投资者，则有可能向动态因子风险敞口倾斜。你持有的因子头寸会在不景气时期带来损失，但你 对损失的容忍度比典型投资者更好。或者，你也可能持有负的因子头寸，这相当于购买保险来防止因子损失。

# 4. 动态因子基准

动态因子其实是指会随着时间而变化的非市值加权的头寸组合。不同于CAPM模型，业界并无唯一方法来构建最优化动态因子组合。

# 4.1 构建原理

有三只股票分别被称为“价值股”、“中性股”和“成长股”，其市场权重分别为20%、50%和30%^{①}。假设这是市场上唯一能交易的三只股票，而且我们是根据股票价格相对其基本面价值之比来进行上述分类。我们通过做多价值股、做空成长股来构建价值一成长因子。假设理想组合是100%的股票组合伴随有5%的价值一成长因子敞口。最优化基准就是市场组合再加上价值一成长因子：

|  | 市场组合 | 价值一成长因子 | 基准组合 |
|---|---|---|---|
| 价值股 | 0.20 | 0.05 | 0.25 |
| 中性股 | 0.50 |  | 0.50 |
| 成长股 | 0.30 | -0.05 | 0.25 |
| 加总权重 | 1.00 | 0.00 | 1.00 |
