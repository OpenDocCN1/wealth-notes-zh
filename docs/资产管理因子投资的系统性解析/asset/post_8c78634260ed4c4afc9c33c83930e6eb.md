
## 非流动性资产

动性较差的股票通常收益更高$^{\textcircled { 1 } }$。这些变量包括买卖价差、成交量、成交量是否是由买方或卖方发起、换手率、美元成交量的绝对收益率（通常被称为“Amihud措施”，基于Amihud 2002年的论文）、大额交易的价格影响、知情交易（逆向知情交易，参见下文）、询价的规模和深度、交易频率、出现零收益的频率（流动性好的市场中收益上下波动），以及收益的自相关性（衡量价格是否有停滞）$^{\textcircled { 2 } }$。这些都是个股所特有的非流动性特征。同时也存在非流动性风险贝塔。它是股票收益率与非流动性衡量指标（如市场非流动性或已签名成交量）之间的协方差。

参考文献对非流动性风险溢价的估计范围在1% ~ 8%之间，取决于采用哪种非流动性衡量方法。然而，Ben-Rephael, Kadan和Wohl（2008）指出股票的非流动性溢价已大幅度减少——对于采用某些非流动性指标衡量的风险溢价现在为零。Ang, Shtauler和Tellock（2013）发现，场外交易股票市场如粉单市场的非流动性风险溢价高达20%，而可比上市公司股票的非流动性风险溢价仅1%左右。

一些具有更高收益率的对冲基金其流动性更差，从这个意义上说当资本赎回具有更多限制时（称为锁定期，参见第17章），或当流动性枯竭时对冲基金的收益率会下降$^{\textcircled { 3 } }$。Franzoni, Nowak和Phalippone（2012）指出私募股权基金存在显著的非流动性溢价，通常为3%（更多信息见第18章）。在房地产市场，Liu和Qian（2012）为美国办公楼建筑构建了衡量价格影响和搜寻成本的非流动性衡量指标。他们发现这些非流动性衡量指标提高10%时，会带来预期收益增加4%。

### 为什么非流动性风险溢价在同一资产类别内而非不同资产类别间更显著

据我所知，我们还未构建出正式的均衡模型来解释为何同一资产类别内而非不同资产类别间存在显著的非流动性风险溢价。

原因可能是各资产类别缺乏一体化。即便是在流动性好的股票和债券市场间也存在一些重大障碍，导致资本和投资策略无法实现无缝切换$^{\textcircled { 4 } }$。投资者将不同资产分门别类，很少持续将它们视为一个整体。这种现象在卖方机构和买方机构都会发生，要

方的固定收益部、股权部和其他部门之间很少互相交流，而在买方，每种资产类别分别由不同部门来管理（我将在第14章介绍，加拿大养老金计划的因子投资策略是一个值得注意的例外）。不同资产类别间非流动性风险溢价的潜在错误定价可能反映了机构约束、资本流动缓慢和套利限制①。

另一方面，资产的非流动性风险溢价较小的原因可能是投资者对非流动性资产出价过高；他们有追逐更高收益的错觉，哄抬非流动性资产的价格直到非流动性溢价消失。缺乏一体化的资产类别市场导致投资者对非流动性资产做出不明智的决定。与此相反，在同一资产类别中——尤其是流动性好的股票和债券市场——不喜欢低流动性的投资者往往愿意支付部分金额而获得可以随时交易的特权。由于投资者在同一资产类别内展开竞争，他们追逐流动性并为其付出高价。

## 4.3 做市

做市商通过扮演买方和卖方之间的媒介来提供流动性②。流动性供应是昂贵的。做市商需要资金来应对潜在大笔买单或卖单的突袭，并随时可能与拥有比他们更多信息的投资者进行交易。为了补偿这些成本，做市商往往以低价买进并在“公允价格”附近卖出。与做市商交易的投资者需要支付买卖差价。

在流动性好的股票和债券市场，做市现在就等同于投资者通过构建大型计算机系统在不到一秒的时间里提交买卖指令来进行的高频交易。美国股票美元交易量的70%以上被认为是基于高频交易③。许多成功的对冲基金专门从事高频交易（参见第17章）。

许多资产所有者不能通过构建高频交易系统来获取非流动性风险溢价，也不能直接或间接地进入这一领域。但是大型投资者可通过某种方式来实现低频交易版的做市。

Dimensional Funds Advisor（DFA）是一家成立于1981年，专注于小盘股的基金管理公司。DFA的策略与学术上的因子模型有着很深的渊源，而且公司创始人David Booth和Rex Sinquefield 身边聚集了很多金融学界的泰斗，如Fama、French及其他人来建立公司。从一开始，DFA就将自已定位为小盘股的流动性提供者，并且做市是其投资策略的组成部分④。当其他投资者寻求紧急出售大量小盘股时，DFA作为交易的另一方会折价买入。相似的，DFA会以溢价方式向急需流动性的投资者提供小盘股。

大型资产所有者如主权财富基金和大型养老基金，都可以担任提供流动性的角色，特别是在流动性不好的市场。他们可以接受已折价的大型债券、股票甚至房地产组合，并在后期以溢价出售。他们可通过计算在限制的（基准跟踪误差）约束条件内能进行交易的规模。也就是说，他们能对不同证券提供一定的流动性，以确保他们没有过于偏离基准。一旦他们树立了提供流动性的声誉后，买家和卖家就会联系他们。

### 私募股权和对冲基金的二级市场

开展对冲基金和私募股权二级市场交易的交易所如雨后果春笋般涌现，但这些市场规模仍有限。很多交易并没有通过有组织的二级市场监管平台进行$^{\textcircled{1}}$。

私募股权的二级市场有两种形式。首先，在二级（和三级）收购市场中，私募股权公司之间互相交易封闭式公司。这些市场已经蓬勃发展：在2005年，二次收购占所有私募股权收购交易的15%左右$^{\textcircled{2}}$。从资产所有者（即有限合伙人）的角度看，该市场没有给私募股权基金提供退出机会，而且最坏的情况是私募股权公司像走马灯似的循环交换公司股权。在最好的情况下，更多的市价交易（假设这些基金交易间不存在诈骗）使得资产所有者能更好地评估其非流动性投资。有限合伙人（LPs）的资金仍困在基金中，但当其基金组合里的某个公司被卖给另一家私募股权公司时，LPs能获取部分现金。

有限合伙人的二级市场，即允许他们从私募股权基金中退出的市场，相对更小且更不透明。即使业内参与者承认该市场“还相对不太成熟……并且仍只占一级市场非常小的比例”$^{\textcircled{3}}$。这些交易中的买卖差价是巨大的。如Cannon（2007）所指出的，有限合伙人的二级市场在20世纪90年代曾被陷入困境的卖家所主导。在这些交易另一方的专业公司得到了30%至50%的折扣；这也是为什么这些公司被称为“秃鹫”的原因。21世纪初，折扣降至20%以下，但在金融危机期间折价比例迅速上升。哈佛大学在2008年试图从私募股权基金撤资时就曾面临50%的折价。

对冲基金的折价要比私募股权小得多。这反映了一个事实，就是对冲基金的投资者在大多数情况下能在锁定期已结束且履行通知义务后的预先指定期限内将自己的资金收回（除非对冲基金另有规定）。在2007年和2008年对冲基金在二级市场上的折价

约6% ~ 8%，反映了这种较大的潜在流动性溢价⑴（少数不再吸纳新投资者的对冲基金实际上是溢价交易）。

新兴的私募股权和对冲基金二级市场对于大型资产所有者来说是提供流动性的巨大机遇。二级私募股权就像是仍然全新的二手车。当你驾驶一辆新车离开车场时，新车会立即贬值1/4，即使它与经销商库存里放的车完全一样。二级私募股权仍然是私募股权，但其价格比直接从经销商手里购买要便宜得多。

### 逆向选择

因为买方可能拥有非公开信息，做市商面临着以远低于股票真实基本面值的价格卖出的风险。知道某只股票会升值的买方会继续购买，从而推高股价。在这种情况下，做市商过早以过低的价格卖出股票。这被称为逆向选择。Glosten和Milgrom（1985）和Kyle（1985）——两篇开创了做市微观研究的论文——创立了买卖差价应如何将逆向选择效应纳人考虑的相关理论。为了避免被利用，DFA会与充分披露信息的交易对手进行股票交易，同时DFA也会保证自己以可信的方式进行交易，杜绝利用信息提前交易或者操纵股价②。

## 4.4 再平衡

资产所有者能提供流动性的最后一种方法是通过动态组合策略来实现。这对资产所有者的总组合产生的影响远大于选择流动性好的证券或是做市，因为这是一种从上至下的资产配置决策（因子归因参见第14章）。

再平衡是提供流动性的最简单方式，同时也是所有长期投资策略的基石（参见第4章）。再平衡迫使资产所有者在其他人想卖出时以低价买入。相反的，再平衡会自动减少价格高企的资产，将这些资产转给希望在较高价位买入的投资者。由于再平衡是逆周期的，所以它可以提供流动性。动态组合规则，尤其是那些基于简单估值方法的规则（参见第4章和第14章），进一步扩展了这一理论——只要他们在其他人想卖出时买入即可，反之亦然。如果可能的话，对非流动性资产头寸也进行再平衡至关重要（参见下文）。

纯粹主义者认为再平衡并非在严格意义上提供流动性，再平衡只是一种资产管理策略。事实上，再平衡仅发生在流动性好的市场上。但价格大幅下跌通常是因为不对称信息的爆发，或者是因为募资成本快速提高使得许多投资者不得不卖出证券——导致非流动性的部分关键因素在第二节开篇已提及。Brunnermeier（2009）指出这些效应在金融危机期间金融市场崩溃时起到了重要作用。相反的，再平衡使得新投资者能够获取风险资产，例如那些比现有投资者风险厌恶程度更低或者追逐历史高收益的潜在投资者，或者是那些因为有广泛融资渠道且察觉不对称信息水平低而在风险资产价格高企时大量买入的投资者。在这一广泛的框架下，再平衡可以提供流动性。

大型资产所有者胆怯地跟踪标准指数而放弃了非流动性风险溢价。当指数成分发生变动时，资产所有者因被迫跟随指数变化而需要流动性。这种指数成分的加入或删除会对价格产生3%～5%的影响，而且越是近期数据这种影响越大①。大型资产所有者应该在指数成分调整中获取溢价而不是支付溢价。他们可以根据自己专有的基准来实现这点。候选指数应突出非流动证券的特性，并且应该以获取因子风险溢价作为构建基础（参见14章）。即使指数没有向非流动性倾斜，资产所有者也可以通过从其他被迫追踪标准指数的投资者那里获取流动性溢价。

## 4.5 小结

四种获取非流动性溢价的方法中，包括①对非流动性资产类别持有被动的配置比例，②在同资产类别内持有流动性较差的证券，③在单个证券水平上做市，④在总体层面上进行动态再平衡。最后一种最简单可行，且对组合收益影响最大。

## 5. 非流动性资产的组合选择

要决定将投资组合中的多大比例配置给非流动性资产，投资者会面临许多基于其自身情况的具体考虑因素。投资者有不同的投资期。非流动性市场没有可交易的指数，因此投资者必须找到有才能的积极管理人。接下来他们会面临代理问题，而评价和监督组合经理也需要技巧。因此，因承担非流动性风险而获取溢价是因人而异的。计算这些非流动性溢价需要有涵盖流动性资产和非流动资产资产配置模型。这些模型还可以建议非流动性资产的最优持有比例。

业界通常会采用单一投资类投资决策模型，该模型一般是在特定的Markowitz（1952）均值方差模型加上一些特设调整（是的，目前业界大多仍采用20世纪50年代以来的模型；参见第3章）——该模型对于非流动性资产投资并不适用。投资者现在不能交易非流动性资产，而在未来会交易的事实，使得非流动性资产投资成为一个动态的、较长投资期的问题。非流动性所涉及的两个重要方面——大额交易成本和交易间隔时间很长——均被涵益在非流动性资产的组合选择模型中$^1$。

### 5.1 考虑交易成本后的资产配置

George Constantinides（1986）首次构建了一个考虑到投资者必须支付交易成本的资产配置模型。例如，卖出价值100美元的股票最后得到90美元是因为有10%的交易成本。毫无意外地，投资者通过减少交易频率来减少交易成本。Constantinides证明了最优策略是在风险资产头寸触到上下边界时进行交易。上下边界间的无交易区间就是从假设投资者能持续、无摩擦交易的模型中得出的最优资产配置（Merton 的1971年模型；参见第4章）$^2$。

这个无交易区间是关于交易成本规模和风险资产波动率的函数。Constantinides估计如果交易成本是10%，那么对于波动率为35%且最优持有比例为25%的某风险资产而言，无交易区间将大于25%（我敢说哈佛在2008年试图出售其私募股权投资时希望只需折让10%）。也就是说，资产所有者在0%～50%之间无须交易——确实，非流动性资产头寸有很大波动。非流动资产 的投资者应预期不会频繁地进行再平衡。

Constantinides的模型能用来计算非流动性风险溢价，按照定义即某种非流动性资产在无摩擦状态下为了给投资者带来同样效用所需要的预期收益。这是投资者在承担交易成本时所要求的风险溢价，而且这是一个确定的等值计算（参见第2章）。如果交易成本为15%或更高，则所需的风险溢价将大于5%。可以将该值与非流动性资产类别数据中平均为（接近于）零的超额收益进行比较。

交易成本模型的一个主要缺点是假定支付了交易成本后就可以交易。但事实上私募股权、房地产、林业或基础设施投资并非如此。有时短期内可能没有机会找到一个买家。即使可以找到交易对手，你还需要等待尽职调查和法律谈判的完成，并且交易

对手还可能临阵逃脱$^{①}$。在金融危机时期没什么交易，很多流动性资产也经历了流动性冻结——因为找不到买家，所以不论什么价格都没有交易。

### 5.2 考虑低频交易后的资产配置

我在Ang，Papanikolaou和Westerfield（2013）中设计了一个资产配置模型，模型中投资者只有在发生随机流动性事件时才能交易非流动性资产。这种非流动性概念是指通常情况下非流动性资产缺乏流动并且不能用于交易。但是当流动性事件发生时，投资者可以交易。

我采用带有参数$\lambda$的泊松分布过程来模拟流动性事件的发生率，流动性事件的区间是$1 / \lambda$。就房地产或者私募股权投资而言，交易区间为大概每10年左右发生一次，所以$\lambda = 1 / 10$。随着$\lambda$增至无穷大，再平衡的机会就会越来越频繁，而在该值有限的情况下标准的Merton（1981）模型认为交易会持续发生。因此，$\lambda$代表了一系列非流动性结果。

泊松分布事件自Perter（1982）以来就被用于模拟有搜索摩擦的情况，Perter于2010年获得诺贝尔奖·之后的一年，他被提名在美国联邦储备委员会（Federal Reserve Board of Governors）任职，但他的提名因遭到共和党反对而被否决。

非流动性风险使得投资者对流动性和非流动性资产都表现得更加规避风险。非流动性风险导致随时间变化的内生性风险规避。哈佛捐赠基金在2008年发现尽管其资金充裕，但还是无法“吃掉”非流动性资产。非流动性财富与流动性财富是不同的；代理人只能消费流动性财富。因此，非流动性财富对流动性财富的偿付比率会影响投资者的组合决策和支出规则——它会成为驱动投资者有效规避风险的一个状态变量。
