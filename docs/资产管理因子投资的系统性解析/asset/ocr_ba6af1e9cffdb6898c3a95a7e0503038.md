许多更为丰富的效用模型会将上述内容全部纳入考量。其中一些模型符合本章前几节提到的预期效用框架，因此前述所有关于直观逻辑和经济机制的内容都将适用。在经济学中，有很多效用函数切实地描述了人们的行为。遗憾的是，在资产管理行业，只有一个效用函数占主导地位——且是遥遥领先的，即限制性均值一方差效用模型。我们希望可以有一个商业化的优化器，能实现在多种效用函数之间进行切换，尤其是那些包含了下行风险厌恶情绪的效用函数。最好还有一个应用程序可以将一系列不利情景以及投资者如何感知这些不利情景的风险映射到不同类别的效用函数中。遗憾的是，就我所知，在撰写本书时尚未有资产配置模型应用能做到这些。不过，所有的经济理论和优化方法都已是公开资料。

# # 4.1 安全第一

在安全第一的效用框架中，正如该名字所示，投资者追求的是资产安全第一。Roy（1952）提出的效用非常简单：只取决于资产组合的收益率低于还是高于预设水平，若低于预设值，取值为0，反之取1。也就是说，如果收益率低于该水平，则是灾难性的结果；如果高于该水平，那么灾难则会被避免。安全第一即是最小化灾难发生的概率，它对于那些首要任务是偿付债务的投资者来说是理想选择。这并不令人意外，因为安全第一首先控制了下行风险，在此框架下的资产配置方法非常直截了当：先保守性地持有安全资产，直到满足预设水平，在满足安全水平后，再去承担尽可能多的风险。
