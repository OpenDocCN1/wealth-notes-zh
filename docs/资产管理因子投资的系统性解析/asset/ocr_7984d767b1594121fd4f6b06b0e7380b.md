# 6.3 清算哈佛？

哈佛捐赠基金是否通过大量投资于非流动性的另类资产而创造了超额收益，或者说获得了非流动性风险溢价呢？是的。哈佛可以从这些非流动性资产投资中获得价值并不是因为非流动性资产本身有很高的风险溢价，而是因为哈佛捐赠基金是一个技能娴熟的投资者。它是少数有能力这样做的投资者之一。

但这并不能帮助哈佛解决其现金困境。哈佛最大的失误在于基本的资产负债管理。即使不采用含有非流动性风险的资产配置模型或者Gilbert和Christopher给出的建议，哈佛应该认识到其资产与负债不匹配。用专业术语来说，即负债的久期比资产的久期短。

+   - 哈佛面临五个选择：
    - ① 变现捐赠基金的部分资产。但哈佛捐赠基金中的很大一部分是非流动性资产，且不能出售。
    - ② 削减开支。大学就像政府机构：庞大、膨胀而且低效。大学几乎很难裁掉任何人。所以削减开支的力度有限。
    - ③ 增加捐赠。为了弥补因错误管理导致的亏损而请求捐助是令人尴尬的。
    - ④ 增加其他收入。哈佛可以取消其非服务性奖学金（need blind是非服务性奖学金的一种）的财政资助政策，但结果表明这并没有节约多少钱。
    - ⑤ 借款。

哈佛选择了第五项。它发行了25亿美元的债券，使得2008~2009年间其杠杆比率翻了一倍多。哈佛的而努力尝试削减开支，并推迟了Allston校园扩张计划。捐赠基金是否像Dershowitz所说的那样，是Joseph用于拯救家人和所有埃及人的应急备用金吗？答案是否定的。事实上，哈佛在2009年调低了它的支出比率，倾向于尽可能保持捐赠基金不受影响$^{(1)}$。也许Hansmann的建议是对的，即捐赠基金管理的主要动机是声誉最大化。毕竟，人人都喜欢资金充裕的捐赠基金。
