表9.6
| 债券持有者的回报 | 公司价值V<100美元 | 公司价值V>100美元 |
| :--- | :---: | :---: |
| | V | 100美元 |

如果公司价值低于100美元，债券持有者可以得到整个公司，价值是V。如果公司价值高于100美元，债券持有者得到100美元，股东得到剩余价值（V-100美元）。我们可以画出如下示意图：

这些回报可以等同于：

表9.7
| | 公司价值V<100美元 | 公司价值V>100美元 |
| :--- | :---: | :---: |
| 持有无风险债券 | 100美元 | 100美元 |
| 卖出一份行权价为100美元的看跌期权 | V-100美元 | 0美元 |
| 总计 | V | 100美元 |

这样，公司债持有者的回报等同于持有一份无风险债券，并卖出一份行权价等于债券面值的看跌期权。债券持有者卖出的这份基于公司资产的看跌期权，相当于做空波动率（short volatility）。相对地，股东相持有基于公司资产的看涨期权，相当于做多波动率。

按照这种分解方式，我们可以看到

持有无风险债券+卖出看跌期权=持有公司债

或

持有公司债-持有无风险债券=卖出看跌期权 公式（9.4）

因此，公司债利差等于卖出看跌期权的价值，该期权的标的资产是公司资产，行权价等于债券的面值。该信用利差随着波动率、杠杆率和到期期限的增加而增加。
