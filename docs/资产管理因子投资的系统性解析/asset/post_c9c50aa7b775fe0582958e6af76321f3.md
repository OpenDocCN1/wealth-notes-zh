
## 3. 因子基准

现在来看关于资产（或者策略、基金）i的CAPM模型：

$E(r_i) - r_f = \beta_i [E(r_m) - r_f]$

公式（10.6）

其中，$E(r_i)$是资产i的预期收益率，$r_f$是无风险利率（美国短期国债），$\beta_i$是资产i的贝塔值，$E(r_m)$是市场组合的预期收益率。假设贝塔值是1.3，即$\beta_i = 1.3$，那么我们可以将公式（10.6）写成

$E(r_i) = r_f + 1.3E(r_m) - 1.3r_f$

调整后我们得到，

$E(r_i) = -0.3r_f + 1.3E(r_m)$

公式（10.7）

上面的式子表明，持有$1的资产i获得的回报率等于持有$-0.30美国短期国债空头以及加杠杆后的$1.30市场组合多头的回报率。注意在公式（10.7）的左右两边，我们都是考虑$1的资产。这样，CAPM模型推出了一个可以复制资产i预期回报率的模拟组合（replicating portfolio）：即无风险资产和市场资产的一种组合。因此，该资产的贝塔值实际上是在模拟组合中市场资产所占的权重（mimicking portfolio weight）①。

因子基准是公式右边一系列投资组合或者因子的组合，它们能够获得与公式左边的资产相同的回报率。因子基准描述了资产i的回报率中的系统性成分。

资产i的阿尔法是指超过“$0.3美国短期国债空头加上$1.30市场组合多头”的那部分预期回报率：

$E(r_i) = \alpha_i + [-0.3r_f + 1.3E(r_m)]$

公式（10.8）

其中，基准包括风险调整后的股票头寸以及无风险利率头寸，$r^{bmk} = -0.3r_f + 1.3E(r_m)$。由于该基准来自于CAPM模型，因此阿尔法是指高于CAPM预测回报率的那部分平均回报率。

## 3.1 因子回归分析

我们可以采用因子回归分析来估算得出风险调整后的基准，或者相对应的模拟组合。

### CAPM 基准

我们现在来考虑价值投资大师Warren Buffett的投资数据。我们使用伯克希尔·哈撒韦从1990年至2012年5月的月度回报率来进行下面的CAPM模型回归：

$r_u - r_f = \alpha + \beta(r_m - r_f) + \varepsilon_u$ 公式 (10.9)

其中普通最小二乘方（ordinary least squares）假设回归残差$\varepsilon_u$与市场因子相互独立。通过估计公式（10.9）中的CAPM回归，可以间接得到CAPM模拟组合的权重。对于伯克希尔·哈撒韦的估计结果如下：

| :--- | :--- | :--- | :--- | :--- | :--- |
| 0.72% | 2.02 | 0.51 | 6.51 | | 0.14 |

相对于这个基准组合，Buffett每月能获得 + 0.72%的阿尔法。

这算得上是非常好的业绩！Buffett使用大约一半的市场风险（$\beta=0.51$），产生了每年约 $0.0072 \times 12 = 8.6\%$ 的阿尔法。我们将通过公式（10.9）的市场组合基准估计出来的阿尔法称为Jensen阿尔法（Jensen's alpha），以纪念Michael Jensen在1968年作出的关于共同基金业绩的开创性研究。（但是共同基金的业绩通常都不能战胜市场；参见第16章。）

该阿尔法在统计上是显著的，t统计值高于2。t值等于2对应着95%的置信水平，这是统计学家认为很神奇的一个临界值。Buffett创造的业绩确实不同凡响。大部分的因子回归都不能得到显著的阿尔法估计。上述CAPM回归的调整后决系数为14%，也比较高。对于大多数股票而言，CAPM回归得到的都小于10%。

① CAPM回归倾向于产生较低的、因为股票回报率的非系统性风险较大。从经济学上说，创建投资组合可以获得很大的多元分散化好处。参见第3章。

![](img/e2a8f768e844f37dcab93b54b9e826d9_329_0.png)

高$R^{2}$表明，相比于个股CAPM回归的典型拟合度，CAPM基准的回归拟合度更好。相对于CAPM风险调整后基准，伯克希尔·哈撒韦创造的超额收益为

$$r^{ex}=r_{i}-r^{bmk} = r_{i}-(0.49 r_{f}+0.51 r_{m})$$

各期超额收益的平均值即为阿尔法，即每月$\alpha=E(r^{ex})=0.72\%$。图10.2展示了伯克希尔·哈撒韦的累计超额收益。虚线对应的是采用CAPM基准时的情形。我们注意到，累计超额收益曲线的斜率近期变平坦了，特别是从2000年代中期以来。在2012年，伯克希尔·哈撒韦的市值超过$2200$亿。在1990年代早期，其市值不到$100$亿。随着公司发展壮大，它的平均超额收益却在降低。Buffett在2011年表示：

> 我们想强调的是，那些美好的时代一去不复返。我们现在管理的资产规模让我们很难再有机会获得超常的业绩表现，但我们仍然会努力争取获得高于平均水平的、让投资者愿意投资于我们的回报率$^{①}$。

所以，即使是伯克希尔·哈撒韦，也不得不对规模报酬递减的规律。

### 市值规模和价值—成长基准

Eugene Fama和Kenneth French，两位在金融领域最具影响力的学者，在1993年引入了一个新的基准，拓展了CAPM模型，纳入了捕捉规模效应（小市值公司表现好于大市值公司）和价值—成长效应（价值型股票表现好于成长型股票）的因子。他们将规模因子定义为小市值股票减去大市值股票的差值，记为“$SMB$”；将价值—成长因子定义为高账面市值比股票减去低账面市值比股票的差值，记为“$HML$”。这里的价值型股票指的是价格被低估的股票，$HML$因子将这些股票的价格（市场价值）进行了标准化处理，即采用它们与账面价值的比例。因此价值型股票是那些有着高账面市值比的股票。第7章讨论了Fama-French模型以及规模、价值因子溢价背后的经济学意义（尽管如今规模效应已经很弱了，但下文会看到，在解释伯克希尔·哈撒韦的业绩时考虑$SMB$因子仍具有指导意义）。

$SMB$和$HML$因子都属于多空因子。它们均同时包含 $1$的多头头寸和 $1$的空头头寸。即：

$SMB = $ $1$小市值股票（多头）$-$$1$大市值股票（空头）

所以$SMB$因子是为了捕捉小市值公司相对于大市值公司的超额收益。$HML$因子则是为了捕捉价值型股票相对于成长型股票的超额收益：

$HML = $ $1$价值型股票（多头）$-$$1$增长型股票（空头）

Fama-French基准相当于持有$SMB$和$HML$因子头寸，再加上传统CAPM模型中的市场组合头寸。

Fama-French将公式（10.9）的CAPM模型回归拓展引入了规模因子和价值因子。Fama-French基准可以用以下回归来进行估计：

$r_{t}-r_{f t} = \alpha + \beta(r_{m t} - r_{f t}) + sSMB_{t} + hHML_{t} + e_{t}$ 公式（10.10）

即在标准的市场因子的基础上再加入$SMB$因子和$HML$因子。

$SMB$因子和$HML$因子的系数分别用s和h表示。如果一只股票既不与小市值股票也不与大市值股票同向变动，那么它就是中型公司，s就等于0。如果它与小市值股票同向变动，s为正值；如果它与大市值股票同向变动，s就为负值。同样的，h衡量了一只股票在多大程度上类似于其他的价值型股票：h值为正表明股票倾向于价值型，h值为负表明股票倾向于成长型。市场组合本身既非小公司也非大公司，既非价值型也非成长型，所以市场的s和h值均为零。

我们对伯克希尔·哈撒韦的回报率按照Fama-French模型进行回归，可以得到如下结果：

表10.2

| | 系数 | $T$统计值 |
|---|---|---|
| 阿尔法 | 0.65% | 1.96 |
| $MKT$系数 | 0.67 | 8.94 |
| $SMB$系数 | -0.50 | -4.92 |
| $HML$系数 | 0.38 | 3.52 |
| Adj $R^2$ | 0.27 | |

Buffett的阿尔法从以CAPM模型为基准的每月0.72%（每年8.6%）下降至每月0.65%（每年7.8%）。控制规模和价值因子后，Buffett的阿尔法减少了近1%。

首先，这里的市场贝塔值从传统CAPM模型回归中的0.51上升至Fama-French模型回归中的0.67。这表明加入$SMB$和$HML$因子确实能够解释伯克希尔·哈撒韦的一部分回报率——只有当$SMB$和$HML$因子对Buffett的回报率没有解释能力时，市场贝塔值才会保持不变。

在Fama-French模型回归中的$SMB$因子系数为s = -0.50。负值表明伯克希尔·哈撒韦股票与小市值公司股票反向变动（记住，$SMB$是做多小市值公司股票，同时做空大市值公司股票）。也就是说伯克希尔·哈撒韦有大市值公司股票的敞口。值得注意的是，市值大其实对Buffett的业绩表现是不利的，因为根据Fama-French模型，大市值公司股票的表现在一般差于小市值公司。

$HML$因子系数h = 0.38表明伯克希尔·哈撒韦具有较强的价值导向；它倾向于与其他价值型股票同向变动。

因此，负的$SMB$因子系数和正的$HML$因子系数表明伯克希尔·哈撒韦是一个大市值、价值型投资者。当然，这点显而易见。无需专门的金融知识就可以知道，这是Buffett自20世纪60年代创建伯克希尔·哈撒韦以来就一直坚持的投资策略。值得欣慰的是，计量经济学方法得到了与我们的常识相同的答案。同时，这一统计方法还给予我们恰当的基准来衡量Buffett的风险调整后超额回报。

Fama-French模型回归的结果令人吃惊，即使在控制了规模和价值因子后，Buffett仍然能够获得相当可观的超额收益：Buffett每月的阿尔法高达0.65%；通过Fama-French模型算出的阿尔法比CAPM模型算出的阿尔法每年降低不到1%。这并非因为规模因子和价值因子是不合适的风险因子。恰恰相反，Fama-French模型回归的调整后高达27%，这在实证金融中已经算很高，比CAPM模型回归的调整后为14%高出很多。因此，引入规模和价值因子大大提高了传统CAPM模型回归的拟合度。同时我们还能看到Buffett的投资业绩显然并不仅仅来源于价值型投资（这里所说的价值至少是相对于CAPM模型所衡量的价值）。

上述Fama-French模型回归结果所表示的基准资产组合即：

- （1 - 0.67）= $0.34的美国短期国债
- + $0.67的市场组合
- - $0.50的小市值股票+$0.50的大市值股票
- + $0.38的价值型股票-$0.38的成长型股票

在上述基准之外，Buffett每月创造了$0.65\%$的阿尔法。

这些因子系数可以直接用于构建基准组合，只是现在的组合中包含小市值公司/大市值公司股票的多空头寸以及价值型/成长型股票的多空头寸。它仍然代表将$\textdollar$1的资产在因子组合之间进行分配。每次进行因子回归，我们都假设可以构建一个因子基准资产组合。

### 加入动量因子

我们可以将动量效应——指历史收益率高的股票有继续上涨的趋势，而历史收益率低的股票会继续下跌——加入到因子基准中。在很多资产类别中都存在动量效应，它是一个系统性因子（参见第7章）。Buffett对动量投资则持怀疑态度，他的投资决策多是基于公司的基本面而不是过去的成长和价格变化。他有三句名言：

- “今天的投资者无法从昨天的成长中获利。”
- “要关注影响价格的根本因素，而不是价格本身。”
- “用合理的价格买一个优秀公司，比起用便宜的价格买一个普通公司要好得多。”

我们在Fama-French基准中加入动量因子$UMD$，即做多过去上涨的股票，同时做空过去下跌的股票$^{①}$。

$r_{n}-r_{n}=\alpha+\beta\left(r_{\text{mkt}}-r_{f}\right)+s S M B_{t}+h H M L_{t}+u U M D_{t}+\varepsilon_{n}$ 公式（10.11）

其中，$UMD$因子的系数（或贝塔）是$u$。通过回归分析，我们得到：

| 变量 | 系数 | T统计值 |
| :--- | :--- | :--- |
| 阿尔法 | 0.68% | 2.05 |
| MKT系数 | 0.66 | 8.26 |
| SMB系数 | -0.50 | -4.86 |
| HML系数 | 0.36 | 3.33 |
| UMD系数 | -0.04 | -0.66 |
| Adj R² | 0.27 | |

① 最早将动量因子引入Fama-French基准的是Carhart（1997）。

上述估计结果与Fama–French模型回归的结果非常接近。与Buffett不认同动量投资的观点相吻合，UMD的系数接近于0（u = −0.04），在统计上也不显著。该回归的调整后为27%，与Fama–French模型回归相同，表明加入动量因子后并没有提高因子回归的拟合度。加入动量因子后，Buffett的阿尔法（每月α = 0.68%）甚至比Fama–French回归得到的值（α = 0.65%）还略有提高。

在Fama–French模型中加入动量因子后，完整的模拟组合可表示为：

- （1 – 0.66）= $ 0.34的美国短期国债
- + $ 0.66的市场组合
- – $ 0.50的小市值股票 + $ 0.50的大市值股票
- + $ 0.36的价值型股票 – $ 0.36的成长型股票
- – $ 0.04的过去上涨的股票 – $ 0.04的过去下跌的股票

除此以外，Buffett每月还获得了0.68%的阿尔法。

图10.2展示了Buffett投资策略相对于Fama–French基准以及相对于“Fama–French 加动量因子”基准所获得的累计超额收益，分别用点线和实线表示。这两条线均在Buffett投资策略相对于CAPM模型基准所获得的累计超额收益曲线之下，主要是由于引入的价值—成长因子HML降低了Buffett的阿尔法。

## 3.2 不使用无风险资产

基准组合不是必须要包含无风险资产。

### CalPERS

CalPERS是美国最大的公共养老金，截至2011年6月30日旗下共管理2460亿美元的资产①。该养老金的基准可能是一个由一系列股票指数基金和债券指数基金所组成的被动组合——这也是加拿大养老金计划（Canada Pension Plan）通过其参考组合（Reference Portfolio）所使用的基准。股票—债券基准能以接近于零的极低费用获得，它是衡量积极管理能否增加价值的可靠标尺。

我们按照上述基准对CalPERS的回报率作回归分析：

$r_u / \$1 = \alpha + (\beta_s r_s + \beta_b r_b) / \$1 + \varepsilon_u$ 公式 (10.12)

① 本节的数据和其他相关信息来自“California Dreaming: The Mess at CalPERS”，哥伦比亚大学案例#120306和“Factor Investing: The Reference Portfolio and Canada Pension Plan Investment Board”，哥伦比亚大学案例#120302。

其中，$r_s$是CalPERS的股票基准回报率（原OCR误作CalPERS的回报率，根据上下文及公式逻辑，$r_s$和$r_b$分别为股票和债券指数回报率，而公式左侧为CalPERS实际回报率），$r_b$是债券组合回报率——这里我们采用Ibbotson Associates长期公司债总回报指数。为了获得一个基准组合，我们加入限制条件：

$$\beta_s + \beta_b = 1$$

也就是说，该组合的各项权重之和必须为1。这样，公式（10.12）左边投入CalPERS的$1可以被右边的股票和债券组合的$1（组合权重之和等于1）再加上CalPERS基金经理创造的阿尔法所复制。

使用CalPERS 1990~2011年的年度回报率数据来估计公式（10.12），可以得到：

表10.4

| | 系数 | T统计值 |
| :--- | :--- | :--- |
| 阿尔法 | -1.11% | -1.16 |
| 债券系数 | 0.32 | 13.97 |
| 股票系数 | 0.68 | 13.97 |
| Adj $R^2$ | 0.90 | |

调整后的高达90%：这表明CalPERS的回报率可以非常好地被包含32%的债券和68%的股票的模拟组合所解释。

CalPERS 阿尔法的点估计值为负数，每年-1.11%。我们是否应该立刻解雇CalPERS的基金经理，并将所有的钱都投入到低成本的指数型基金呢？根据以上回归结果，我们只能做出如下表述：“在95%的置信水平上，我们不能拒绝‘CalPERS相对于32%债券和68%股票的基准组合，获得了超额回报’的假设。”因为T统计值的绝对值小于2，结果在统计上并不显著。

然而，CalPERS的管理费用极高。2011年，其费用比率的内部估计值超过了0.50%，而从其年报中推算出的费用比率则高于0.80%（它在年报中竟然未明确公布费用比率，这是多么讽刺的事）。CalPERS的费用比率远高于业内同行。根据Bauer、Cremers和Frehen（2009）的研究，在规模较大的养老金计划中，费用比率的中位数是0.29%；在规模排前30%的养老金固定受益计划中，费用比率只有0.15%。因此，CalPERS的费用比率比Bauer、Cremers和Frehen研究样本中的养老金中位数高3到4倍，比规模排前30%的养老金高出近9倍。如果是管理与CalPERS规模相当的指数型股票或指数型债券基金，费用比率会远低于0.10%（挪威主权财富基金2012年的费用比率仅为0.06%）。所以，如果CalPERS可以用接近于零的费用来管理一个包含股票和债券的基准组合，也许它确实应该考虑解雇基金经理并完全进行指数型投资。
