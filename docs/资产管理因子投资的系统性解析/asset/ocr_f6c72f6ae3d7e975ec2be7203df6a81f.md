# (1) 平滑性偏差

采用估值数据（一年最多一至两次）就会人为地引入平滑性①，这就是表11.4中NCREIF数据序列自相关性比REITs或股票高很多的原因。

# (2) 选择性偏差

你所见的被出售的房地产并不能代表全部房地产的存量。例如，也许只有最好的房地产才会被出售，因为开发商只会对这类房地产进行包装，而那些止赎的、劣质的房地产则无人问津³。

此外，REITs投资是附有杠杆的，而NCREIF回报率则是无杠杆的。研究者们开发了很多新方法试图将以估值为基础的指数转为以实际交易（和重复销售）为基础的指数，将房地产投资回报率去平滑化，加入对于选择性偏差的考量，以及剔除其他的流动性偏差。这些偏差的影响是巨大的。例如Lin和Vandell（2012）发现，在一年的持有期间内，直接房地产投资回报率的波动率比表11.4中计算的波动率高三倍。Pagliari、Scherer和Monopoli（2005）认为，在进行了去杠杆和板块构成调整以及估值数据去平滑化调整后，直接房地产投资与间接房地产投资的回报率并无太大差异。

所有欠缺流动性的资产都存在平滑性偏差和选择性偏差的问题——包括私募股权在内——我将在第13章讨论解决这些问题的方法。我在此仍使用NCREIF回报率进行分析，但请记住：它们并不是真实的回报率。

长期来看，直接和间接房地产投资的回报率同步变化

直接和间接房地产投资的回报率在长期来看是相关的。图11.8画出了经对数化处理后，长期NCREIF回报率与REIT回报率的相关系数。在一个季度的时间段内，两者的相关系数是0.22，这反映了表11.4中两者的低相关度（表11.4中的回报率是将季度数据取算术平均值，而图11.8使用的是对数化的回报率；参见附录）。在十二个季度以后，两者的相关系数上升到约0.43。这意味着NCREIF和REIT的回报率中，有一些长期的共同构成部分。计量经济学研究也发现有力证据证明，公开的房地产市场领先私募房地产市场，这是可以预料到的，因为公开的房地产市场由于流动性更好，可以更快实现价格发现³。
