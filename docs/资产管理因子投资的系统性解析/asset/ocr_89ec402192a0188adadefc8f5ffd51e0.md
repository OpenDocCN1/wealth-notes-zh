# （3）要谦逊

如果你试图对市场择时，那么一定要谦逊。预测收益是十分困难的。由于很难从统计上去发现可预测性，也就很容易因为接连走运而自欺欺人地认为自己是世界上最棒的管理人（这是自我归因偏差（self-attribution bias）），而当运气耗尽时这种过度自信真的会很不利。你还需要正确的公司治理结构来承受可能持续多年的痛苦时期（参见第15章）。需要告诫资产所有者的是，有投资技能的管理人非常少，尤其是在那些自认为有能力的人当中（分别参见第17章对冲基金和第18章私募股权）。

既然数据中的可预测性很低，投资者将独立同分布情形作为基本情形即可。这意味着通过再平衡回到固定权重（敞口）来进行动态的资产配置，与第4章所阐述的一样。如果数据中体现出收益有一些均值回归特点，比如高价格会带来低收益（或者反之亦然），那么再平衡回到固定权重将是有利的。我们回顾一下，再平衡是一种逆周期策略：在股票价格下跌时买入，所以当期收益高时，股票仓仓相应有所增加；在股票价格上涨时卖出，所以当期收益低时，股票仓仓相应有所减少。如果你能预测未来的话，你可以比这个策略做得更好，但你很可能无法预测未来。至少再平衡可以让你往正确的方向去做——真正最优（最理想）的策略只会比再平衡策略更激进些。如果你不能持续不断地进行再平衡，那么当股票风险溢价的真数据生成过程（data-generating process）显示出可预测性时，你很可能无法采取最优投资策略。
