式(8.6)的左侧扩展为多个时期的收益来进行统计测量。我们采用对数收益，这样可以进行加总。例如，对于三期超额收益，我们得到：

```
$ r _ { t + 3 } + r _ { t + 2 } + r _ { t + 1 } = c + b \cdot X _ { t } + e _ { t + 3 , 3 } $ 公式(8.7)
```

由于数据有限，我们通常采用重叠数据来进行长期限回归。也就是说，当我们在 $ t + 1 $ 时点考虑预测未来三个时期收益的变量时，我们预测的是从 $ t + 1 $ 到 $ t + 4 $ 时点的一期超额收益，即 $ r _ { t + 4 } $ 、 $ r _ { t + 3 } $ 和 $ r _ { t + 2 } $ 。因此，考虑公式右侧变量分别在 $ t $ 和 $ t + 1 $ 时点的两个回归公式，我们发现公式左侧的一期收益 $ r _ { t + 3 } $ 和 $ r _ { t + 2 } $ 会在这两个公式中出现重叠。这种重叠体现在公式(8.7)中用复杂符号 $ e _ { t + 3 , 3 } $ 代表的残差中。该符号表示：残差是在 $ t + 3 $ 时点实现的，但其涉及了过去三期的收益（下标中的第二项，即3）。重叠数据结果会带来一些非常麻烦的统计特点，导致常规的普通最小二乘法统计推断严重高估了数据所具有的真实可预测性。这不仅对那些爱钻研的计量经济学家来说是个问题，而且对投资者也有很大启示，正如我们下面将看到的。

我们应该预期有多大的可预测性呢？并不大。Ross (2005，2012)和Zhou (2010)研究表明，预测回归公式(8.6)中的 $ R ^ { 2 } $ 应该很低。从技术上，Ross和Zhou证明了回归 $ R ^ { 2 } $ 的界限是定价核的方差（参见第6章），而定价核的输入因子，比如消费，通常波动性不大<sup>1</sup>。Ross计算的界限是8%，而Zhou给出的界限更低。我们应该预期 $ R ^ { 2 } $ 很低，通常低于5%。也就是说，95%的市场变动应该是不可预测的，任何一个声称可以用高 $ R ^ { 2 } $ 预测未来收益的投资策略都非常值得怀疑。这种低可预测性与第6章中Grossman和Stiglitz (1980)提出的近有效性市场相一致：能赚钱的市场择时策略极少，而且统计上也很难被发现。

数据证实了这点。实证上，很难找到稳健的统计证据来证明可预测性。表8.2列出了期初不同预测变量所预测的下一时期收益的相关系数。测量的基本单位是一个季度，所以回归公式(8.6)中的下一时期收益就是跨下一个季度。我也按一年期、两年期、五年期进行了公式(8.7)中的长期限回归分析，这些结果也用相关系数表示如下。表8.2还列出了可以解释重叠观测值问题以及随时间变化的波动率问题的稳健 $ t $ 统计量，这些问题也导致常规普通最小二乘法太过频繁地拒绝可预测性的零假设<sup>2</sup>。表8.2考虑了学术研究中的各种变量，包括宏观变量、利率和利差以及历史超额收益。
