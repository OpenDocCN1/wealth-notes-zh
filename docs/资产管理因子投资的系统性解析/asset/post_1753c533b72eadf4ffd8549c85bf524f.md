
## 3.1 IRR（内部收益率）

投资基金的IRR在20世纪80年代平均为17%，在20世纪90年代达到峰值50%，此后开始下降。1996年，并购投资基金的IRR接近于零，在21世纪初，并购投资基金的IRR达到22%，但自2006年以来几乎为零。风险投资基金的IRR在20世纪90年代中期一直很高、超过70%。自从2000年高科技泡沫破灭以来，风险投资基金的IRR一直在零附近徘徊或仅略高于零。

任何上过MBA金融入门课程的学生都被教授建议过不要采用IRR。一个众所周知的原因在于IRR假设可以按照内部收益率对现金流进行再投资。IRR也会因为现金流的时间点而被扭曲。在PE领域，这些问题的确非常棘手。IRR并不是收益率。

> 正如Joshua Lerner所说¹：
> “当你观察人们是如何公布业绩时，就会知道他们玩了多少花样来操纵IRR。”

假设某投资者在时点0对基金投资100美元，在时点1收到150美元²：

| 时间 | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 现金流 | -100 | 150 | | | | |

如果投资者在时点1退出投资，那么IRR是50%。现在假设有个投资机会可在接下来的四年里获得25%的年化收益率。这个收益率很高，所以投资者会倾向于将已投入基金的钱留存到第5年，从而连本带利获得366美元。

| 时间 | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 现金流 | -100 | | | | | 366 |

如果GPs这么做的话，IRR将为30%。尽管对于资产所有者而言，将投资资金保留到时点5会更好，但GP更偏好于在时点1提前退出。正如Gompers（1996），Lee和Wahal（2004）所指出的，提前退出的情况在现实生活中确有发生。并购投资基金有尽早支付红利的动机，这使得现金流会更早地出现在IRR计算中。提前退出可能会破坏价值，但这能使得IRR虚高³。

GPs可以通过其他方式滥用IRR。IRR可以按照投资初始年份来进行计算，也就是将给定初始投资年份的所有基金汇总计算IRR，而不是分别计算每个基金的IRR。将基金分组汇总可以隐藏业绩不佳的基金。如果一个私募股权公司在早期有某些基金表现优异，那么将所有基金汇总能产生一个高的IRR，从而可以掩盖其他不良投资。Philipou（2008）发现约有一半的并购投资公司是将各基金先归集到一起，然后再计算整体IRR；而不是首先计算每个基金的IRR，然后再根据各基金的权重来计算所有基金的加权平均IRR。甚至有些LPs也采用这种汇总策略来使得他们的PE投资业绩看起来更好⁴。

即使IRR的数值为正，也并不意味着资产所有者的投资业绩较好，因为其承担的风险——被投资公司的潜在风险，以及非流动性、高费用、LP与GP之间严重的代理问题等风险。Sorensen, Wang和Yang（2012）开发了一个模型，从LP的角度将所有这些风险都考虑在内。如果被投资公司的贝塔为0.5，那么对应愿意承担低到中等风险的资产所有者的合适盈亏平衡IRR应在13%~17%之间。如果被投资公司的贝塔为1.0，即与市场组合的贝塔一致，那么IRR的盈亏平衡应在17%~19%。图18.2显示并购投资基金的平均IRR为16%，所以适度规避风险的投资者仅达到了盈亏平衡。而且自2004年起，并购投资基金就没有为投资者创造价值。

## 3.2 倍数

投入资本总值倍数的计算公式为LPs的总资本回报（扣除费用后的净值）除以总资本承诺额或已投资额（包括费用）。

![](img/e2a8f768e844f37dcab93b54b9e826d9_611_0.png)

倍数要比IRR难以被操控，但同样是没有意义的。

图18.3展示了由Harris, Jenkins和Kaplan（2012）整理的并购投资基金和风险投资基金的倍数。像IRR衡量指标一样，倍数显示出与IRR相似的随时间而发生较大波动（并购投资基金和风险投资基金的倍数与内部收益率之间的相关性分别为77%和85%）。在20世纪80年代，并购投资基金和风险投资基金的倍数大多超过2.0，且风险投资基金倍数在20世纪90年代中期高达6.5，并从21世纪初以来持续低迷。自1999年开始，风险投资基金的倍数略高于1.0，2006年以来并购投资基金的倍数约为1.0。

![](img/e2a8f768e844f37dcab93b54b9e826d9_612_0.png)

如果倍数大于1，那么资产所有者收回的资金会高于已投资金。但这并不代表投资者的PE投资达到盈亏平衡，原因如下：

### （1）资金的时间价值

这个关键因素是无法调整的。事实上，这里隐含的假设是再投资资金的收益率为零。

### （2）久期

不含久期信息的倍数几乎毫无用处。倍数为2意味着你获得了初始投资的两倍——但如果这是一年内取得的，那么会是个惊人的回报；而如果是十年内取得的，是不是就显得平淡无奇了？即使你知道初始投资年份，你仍不知道该基金是在早期或者接近尾声的时候才会分红。尽管资产所有者需要久期信息来解读倍数，Philipou（2009）发现只有不到2%的私募股权基金招股说明书中会公布以现金流加权后的持有期回报⁵。

### （3）风险

如果不知道潜在的杠杆水平就无法正确解释倍数。当倍数同为3时，很显然没有杠杆的基金要比有着5倍杠杆的基金更令人印象深刻。我们还需要知道被投资公司的潜在风险，并将代理问题、非流动性风险纳入考虑范围。

将杠杆和风险纳入考虑后，Sorensen, Wang和Yang（2012）研究估计盈亏平衡的倍数在3～6。如图18.3所示，在20世纪80年代和90年代初期，并购投资基金的倍数尚在此区间，但此后就一直表现不佳。风险投资基金在90年代的初期和中期也达到了这个倍数，但自2000年开始风险投资基金的表现也一直欠佳。

由于PE基金没有强制或标准化的报告要求（不同于40法案基金，参见第16章），GPs可以在内部收益率、倍数及其他业绩指标之间进行选择。并购投资基金通常会公布倍数，但它们并不总是公布IRR。当业绩表现差的时候，IRR往往就消失不见了。这并不奇怪。举个极端的例子：如果倍数刚好是零，那么IRR应该是-100%。Philipou（2009）证明当倍数小于0.1时，有超过80%的基金不会公布IRR。

## 3.3 PMEs

IRR和倍数都是绝对衡量指标，不能计算相对于某个基准的业绩：分别在芝加哥大学和麻省理工大学从事PE研究的教授Steven Kaplan和Antoinette Schoar（2005），引入了PME指标来改善这个缺点⁶。PME指标能计算相对于市场的PE业绩表现。业界实践者对PME还不太熟悉，但PME在学术界已广泛流传。

PME是用流入LP的资金除以从LP流出的资金，对流入流出的资金均采用已实现的市场收益率进行折现。

$$
PME = \frac{\sum \frac{Dist(t)}{\prod (1+r_{m}(t))}}{\sum \frac{Call(t)}{\prod (1+r_{m}(t))}} \quad \text{公式(18.3)}
$$

其中 $r_{m}(t)$ 代表市场收益。$\prod (1+r_{m}(t))$ 指将现金流折现到基金初始期，这样就考虑了同期投资于公开股票市场的机会成本。

图18.4展示了由Harris, Jenkinson和Koplan（2012）所计算的并购投资基金和风险投资基金的PMEs。将市场风险纳入考虑后会对结果产生影响。在图18.3中，并购投资基金的平均倍数是2.0，而在图18.4中PME值下降至1.3。特别是，20世纪80年代时并购投资倍数约为3.0，但是PME只略高于1.0。与倍数衡量指标相似，在21世纪初并购投资PMEs约为1.5，但从2006年以来就在1.0附近或低于1.0。风险投资基金的情况类似。图18.3显示风险投资基金倍数的平均值为2.5，而其相应的PMEs则降至1.5。如图18.4所示，虽然风险投资基金的PMEs在20世纪90年代中期超过了4.0，但从1999年以后其平均值就降至1.0以下。

![](img/e2a8f768e844f37dcab93b54b9e826d9_614_0.png)

PMEs假设资本召集和分红具有与市场组合相同的风险。在现实中，分母包括管理费，这主要是无风险的负债。而分子中产生分红的被投资公司，很可能有比市场组合更大的风险。对分子使用一个更高的折现率会减少PME值。因此，在谨慎考虑风险的情况下，PME应该超过1才能赚取超额收益。Sorensen，Wang和Yang（2012）研究指出，如果被投资公司的贝塔为0.5，则LP需要的盈亏平衡PME值在1.2~1.7；如果被投资公司的贝塔为1.0，则实现盈亏平衡的PME值在1.8~2.1。如果以后者为基准，那么只有20世纪90年代早期的并购投资对LPs创造了价值。

## 3.4 风险调整后的收益率

衡量PE的风险和收益率不是一件容易的事情，因为PE不会直接公布收益率，而且IRR、倍数和PME都不是收益率指标。研究表明，在20世纪80年代和90年代初期，未经调整的PE投资业绩领先于公开市场业绩。Harris，Jenkinson和Kaplan（2011）研究结果指出，例如“并购基金在20世纪八九十年代和21世纪初的业绩看上去均超过公开市场业绩。”但一旦考虑了风险因素后，投资者就无法判断PE基金是否能真正创造收益，尤其是在当前的市场环境下。事实上，PE基金的风险调整后收益大多低于公开市场股票；在机构投资者开始投资私募股权大约30年后，Kaplan和Schoar（2005）首次记述了这一事实。

私募股权的整体收益率具有很强的顺周期性。给定年份的已投资本与当年的收益率之间呈负相关⁷。Philipou（2011）发现在每个投资年份募集基金的数量与IRR以及倍数这些衡量业绩的指标之间呈现较大的负相关性。这并不奇怪：并购基金的退出往往取决于公开市场的热度。首次公开发行的数量呈现波浪形，其在市场最高位时达到峰值。并购活动也同样具有很强的顺周期性⁸。

### 私募股权收益率的偏差

学术研究对PE数据中存在的两个严重偏差加以考虑：①基金或公司价值的不频繁观测值和②选择偏差⁹。后者指的是那些更成功的公司或者基金在数据中有被过分代表的趋势，导致PE投资收益率看上去比实际上的更好。交易只有在被投资公司估值高时才能被观测到——只有当公司运转良好并获得下一轮融资时，只有当公司估值高且公司会IPO时等——那些业绩不好的公司（僵尸企业）经常会被当作壳公司而苟延残喘，不会有市场估值。

对僵尸公司的估值往往被写入PE合同中，表述如“投资将以成本估值除非有重大变化证明需要采用不同的估值方法。”¹⁰正如一位估值专家所说：“基金管理人……存在明显动机，继续持有投资前景不佳的投资，只不过是为了从中得到更多的基金管理费。”¹¹根据咨询公司 TorreyCove Capital Partners的调查结果，僵尸公司在PE投资中占比超过5%以上。由PE投资公司 Colter Capital开展的另一项调查显示，在2011年有57%的北美LP在他们的投资组合中持有僵尸基金¹²。

学术界在解决由低频抽样和选择造成的偏差上主要采用两种方法，但这两种方法都有缺陷。第一，我们可以检查单个被投资公司层面的信息。这能提供更多数据，所以会有实际的收益率（不同公司的时间间隔不规则），但选择偏差是一个主要问题。这种分析也反映了PE基金在扣除费用之前的总收益率，而不是LP赚取的扣除费用之后的收益率。第二，我们可以分析PE基金层面的数据。这种情况下选择偏差会更小是因为最后变成僵尸的被投资公司会反映在该基金的最终结算支付中。采用基金层面现金流的主要缺点在于这些都不是直接衡量收益率的指标。

### 公司层面的估计

Cochrane（2005）首次将选择偏差考虑在PE投资的动态风险收益模型中。他根据以下公式估计CAPM模型的对数收益：

$$
\ln(1+r_{i})-\ln(1+r_{f})=\alpha+\beta(\ln(1+r_{m})-\ln(1+r_{f}))+\varepsilon_{i} \quad \text{公式（18.4）}
$$

其中，$r_{i}$ 代表公司i的收益、$r_{m}$ 代表市场收益，$r_{f}$ 为无风险利率。系数 $\alpha$ 和 $\beta$ 分别是风险投资的对数（log）超额收益（alpha）和市场敞口（beta）。公式（18.4）是标准CAPM模型回归的对数版本，通常用来表示算术收益率（参见第6章和第10章）¹³。

Cochrane发现选择偏差的影响是巨大的：如果不考虑选择偏差，公司的（log）alpha是92%。而将选择偏差纳入考虑后，（log）alpha缩减至-7%。Beta估计大约为2。被投资公司的波动率极高——每年超过100%。Cochrane发现风险投资公司的业绩表现与小型和微型的纳斯达克股票非常类似（事实上，可比上市公司股票的波动率甚至比风险投资公司的波动率更大）。这反映了初创公司的投机性质和它们的高波动性：PE基金中，85%的收益率来源于不到10%的投资，并且只有13%的投资最终实现上市¹⁴。

我在哥伦比亚大学商学院的同事Morten Sorensen，从Korteweg和Sorensen（2010）研究中发现选择偏差会将风险投资基金的原始收益率估计值每月减少2%—3%（算术回报率）。与Cochrane相比，Korteweg和Sorensen估计的风险投资基金贝塔更高，大约为3。他们发现风险投资的阿尔法从1987年至1993年都是正值但并不大，阿尔法在1994年至2000年期间非常高，但是阿尔法在本世纪初是负值。尤其是在2001年以后风险投资的算数阿尔法一直都持续为负，大概每个月为-3%。

### 基金层面的估计

基金层面估计的一个优势是因为PE基金有相似的存续期（10年左右）而且选择问题相对较少，可以采用相对传统的算法进行分析，而不需要采用对数收益率。通过使用基金层面的现金流，Philipou和Goltzschalg（2009）发现PE基金的业绩比标普500指数的业绩低3%。如果将获取规模溢价和价值溢价的额外风险因子纳入考虑，则风险调整后的PE基金业绩将比标普500指数的业绩低6%。

Driessen，Lin和Philipou（2012）估计并购基金的贝塔大约为1.3，风险投资基金的贝塔大概是3，这与Korteweg和Sorensen（2010）的研究结论一致。Driessen，Lin和Philipou发现在1980~2003年期间——这期间非收益率的衡量指标IRR、倍数和PME值是最高的（参见图18.2~图18.4）——并购基金的每月业绩低于市场表现约0.4%。风险投资基金在调整市场风险后的每月业绩则相应低出1.1%。这是相当差的业绩表现。在考虑了额外的规模和价值一成长因子后，并购基金和风险投资基金的月度阿尔法分别是-0.7%和-1%。这些数字说明业绩大幅落后。

对于并购基金而言，规模、价值一成长敞口都是风险溢价的来源。Philipou（2013）指出并购基金如果存在任何业绩优势的话，主要在于它们以便宜的价格买入规模小的公司甚至是微型公司。这些倾动能给予并购基金高于市场的收益率，但投资者也可以通过便宜的指数基金达到同样效果。同时别忘了，并购基金使用了大量的杠杆。

Jegadeesh，Krauss和Pollet（2009）从另一个角度解释了PE如何创造价值。他们研究了上市的PE基金和基金的基金（Funds-of-funds）。在控制了公开市场股票的风险因子后，他们发现每年的超额收益为-7%~-5%，他们还发现上市的PE基金对规模和价值因子有重要的风险敞口。

### 其他风险因子

非流动性是PE收益率中一个重要的风险因子。Franzoni，Nowark和Philipou（2012）指出，PE投资与公开市场股票有着相同的非流动性风险敞口。也就是说，如果某资产所有者想获取非流动性风险溢价，也许更应该从公开市场中而非私募市场中获得（参见第13章）。Franzoni，Nowak和Philipou发现非流动性风险溢价能解释约3%的PE收益率，而其PE收益率的样本值为18%。也就是说，剩下15%的PE收益率是由其他风险因子决定的。在控制非流动性风险之前的超额收益已经较小（甚至为负），将非流动性风险纳人考虑后的超额收益会变得更小。Franzoni、Nowak和Philipou 的研究估算表明在考虑了非流动性、规模和价值影响后PE投资的超额收益是零到小数点后三位。
