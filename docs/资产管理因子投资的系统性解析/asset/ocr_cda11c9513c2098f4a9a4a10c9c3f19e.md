# 1. 是否坚持到底？

2009年4月，金融危机中最艰难的时刻刚刚过去，独立投资顾问Amy Harrison正准备和她的客户Amelia Daniel见面①。三年前Harrison被介绍给Daniel，那时Daniel刚刚通过出售她的医疗信息公司“Daniel Health Systems”获得了1000万美元现金。同时她刚离婚。她认为，出售公司的套现所得和她个人生活中旧篇章的结束，都让她能够重新考虑开始新的、风险较小的投资机会。

在两人第一次会面之后，Harrison为Daniel起草了一份投资政策声明（Investment Policy Statement, IPS），这份声明包含以下内容：

+   ①描述了Daniel对风险的理解并确定她的风险容忍程度；
②确定了Daniel的中期与长期目标，以及她的偏好和约束条件；
③精细规划了一个长期的投资计划；
④提醒她在实现投资目标过程中应坚持的指引；
⑤规定了投资与监控流程。

第一年Harrison和她的客户合作较为顺利。然而，有时需要说服Daniel来遵循Harrison的建议。像其他很多企业家一样，Daniel通过持有高度集中的组合来积累她的财富，实质上就是全部资金投入在她自己的公司。但Harrison的建议来源于分散化投资和最优资产配置的理念，以在降低风险的同时最大化收益。Daniel没有债务；她的父母生活安逸；她没有孩子并且也没有生孩子的打算。她过着并不奢侈的生活，公司收购方继续雇佣她作为顾问并且支付给她足以应付日常开销的工资。由于其企业家背景，Daniel 比较愿意承担风险，并且更注重长期投资。Harrison因此建议Daniel将组合中的大部分平均地分配在一个短视的（成长型或市场导向型）组合和一个长期的对冲需求（机会型）组合之间。其中，短视组合包括流动性较好的美国股票和国际股票以
