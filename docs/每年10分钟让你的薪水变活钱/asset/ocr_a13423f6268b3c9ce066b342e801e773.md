# 每年10分鐘，讓你的薪水變活錢

投資觀念和付諸行動，不只是看懂故事，而是要經過反覆求證，一旦認同故事背後的投資理念之後，就要讓它進入血液，融入骨髓，變成一個非要達成的目標，這樣才能以簡馭繁產生巨大驚人的力量。

我過去三十年的經驗無論在學理和實務上都印證了它的可行，但誠如孫中山先生所言：「吾心信其可行，則移山填海之難，終有成功之日；吾心信其不可行，則反掌折枝之易，亦無收效之期也。」所以需要你的執行力和持續力。

剛開始時你需要有一點耐心，就像帶你走森林的道路，這時你只能見樹，但見不到林，沒關係，你只要跟著所說的故事走，瞭解每一個故事要表達的意涵，就像輕鬆的享受樹木所散發的芬多精就可以，等隨著章節攀登到一定的高度時，回頭一看，就會有一個清楚的輪廓甚至全貌，或可一覽眾山，看到豁然開朗的山水之美。

B組的朋友除了欣賞平地的風景以外，還願意嘗試一下高原的生態，例如進入香格里拉觀賞高原景觀（平均在3,200公尺的高度，這樣的高度在台灣多為高山，而香格里拉卻是一個漂亮的高原，不同的是要對抗高原反應，你可能需要多準備一個氧氣瓶），但仍然是相對安全的地方欣賞美景，適合有較多的時間也有理財興趣的朋友，但又不希望整日在股市裡頭打轉。
