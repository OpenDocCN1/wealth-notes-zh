# 美國藉二大優勢復甦經濟

美國得天獨厚的「美元」地位，讓它比全世界任何國家更有條件進行金融及財政的刺激或調整手段，脫離困局，因美元是國際間流通的結算貨幣，換成其他國家，在金融海嘯期間，幾乎沒有這個條件和實力能大印鈔票還不破產的，而且這還不一定是大印鈔票就能奏效的。

以日本為例，安倍2012年底上臺提出振興經濟的三支箭：寬鬆貨幣政策、大規模新的公共開支以通貨膨脹刺激經濟及經濟結構改革，目標是加速刺激，擺脫經濟停滯與通貨緊縮的惡性循環，帶領日本走出「失落的二十年」，最引人注目的就是寬鬆貨幣政策，日圓匯率開始加速貶值。

安倍經濟學這套政策組合能否發揮功效，世界都很關注，特別是歐洲，如果能夠仿效美國的寬鬆政策而成功的話，可以做為其他相同經濟困難地區的指引參考。

然而《經濟日報》社論指出：「經過近兩年的運作，『第一支箭』寬鬆貨幣政策已成強弩之末；『第二支箭』擴大公共支出，也因提高消費稅率而中途墜落；『第三支箭』經濟結構改革則因政治考量，始終引弓未發。」
