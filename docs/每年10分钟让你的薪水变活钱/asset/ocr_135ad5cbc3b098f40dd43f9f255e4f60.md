# 每年10分鐘，讓你的薪水變活錢

讓你在這個趨勢之上再加以變化，充分利用我的建議，符合證券行和散戶的利益。

而我所提的建議如下：

+   1. 針對新客戶開發——可以藉由書中所提之工具和操作特性開發新客戶，例如停泊在定存和購買公司債的這些客戶族群（七年中鋼公司債約1.75%，十五年只有2.15%左右，但0050和0056兩者混搭的股利約高達5%，就算0050 的股價十五年不動，都比公司債高1倍），使用景氣對策信號本身就有基礎分析的原理，也參考了領先指標，半山腰進半山腰出，成功的機率相對高。

+   2. 教育現有的客戶群——當部分資金進入上述指數，因為穩健在不虧損又能獲利的的情況下，客戶不會離開股市。

+   3. 帶進活水源頭——因為0050和0056都是非常安全的工具，新的資金加入也有助於台股的證券市場活躍，而獲利就可以帶進其他觀望的客戶群，這多少也是帶進活水源頭的小溪流。

+   4. 扮演教育者——做為主管的妳，可以讓同事扮演教育者，不要只有守株待兔等待客戶下單，把客戶依不同的需要，分成幾類族群，第一種有人喜歡長線操作，那美股台股的混搭是一個方法。可以使用貴公司的複委託，不過
