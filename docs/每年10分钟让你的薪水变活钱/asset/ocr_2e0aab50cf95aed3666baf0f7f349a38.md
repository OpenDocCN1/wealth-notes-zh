# 每年10分鐘，讓你的薪水變活錢

《信函8》

# 你可以是別人
不可或缺的朋友嗎？

居賢：

台灣這幾年興起了單車環島的活動，我常在花東縱谷的晨曦中，看到一群群自行車隊伍，或兩、三個人一組的，也讓我想起三十六年前，單車環島還沒形成風氣，我和四個朋友江慶峰、吳文欽、簡禎祥、蔣東雄，帶著帳篷、打氣筒，風餐露宿，十幾天的單車環島領略到許多開車和健行不同的樂趣，蜿蜒不絕而且帶一點險路的北宜公路，驚濤拍浪、懸崖峭壁的蘇花，鬼斧神工的中橫，田園風光的花東縱谷，山與海呢喃美不勝收的東海岸，南迴公路亦有可觀之處，太麻里寬闊的沙灘，這些美麗的畫面，單車走一趟，值得回味和懷念。

在路上的也碰到只有一个人出行的畫面，覺得好可惜，當然一個人也有一個人 的樂趣，但出狀況時，哪有同伴可以照應，古人說，獨學而無友，則孤陋而寡聞，現在人說，獨行而無友，爆胎沒人幫忙補，你算是一個小留學生，合美兩邊，哪邊的朋友多呢？你怎麼看待擇友這件事
