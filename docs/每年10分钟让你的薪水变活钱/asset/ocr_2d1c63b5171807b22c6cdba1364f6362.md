# 每年10分鐘，讓你的薪水變活錢

# 噢，
原來你也在問相同的問題

張愛玲在《愛》小說中有句名言：「於千萬人之中遇見你所遇見的人，於千萬年之中，時間的無涯的荒野裡，沒有早一步，也沒有晚一步，剛巧趕上了，也沒有別的話可說，惟有輕輕的問一聲：「噢，你也在這裡嗎？」

這麼一句話，看似平淡，卻又出奇的把緣分做了貼切又淋漓盡致的表達。這是張愛玲的功力和她的表達手法。

其實這句話也像我工作上經常碰到的場景寫照，每一個來我辦公室諮詢的客戶朋友，不管帶著自信的眼神或是欲言又止的語氣，都會關心問道：

「未來的投資報酬如何？」
「有多大的風險？」

當這問題提出時，我腦海裡有個回應：「噢，原來你也在這問相同的問題！」

不管收入豐盛的專業人士，還是商場上身經百戰的企業主或辛苦的上班族，這是他們想要豎起耳朵專注聽解答的提問，而投資管理中接下來的布局和規畫，便因這兩個
