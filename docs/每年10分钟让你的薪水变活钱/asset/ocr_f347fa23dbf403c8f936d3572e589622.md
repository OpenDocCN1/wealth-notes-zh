# 美國隊長重生了嗎？

太陽底下每樣東西都有影子，美國也是在太陽的照射下，自然也不例外，要說美國的缺點，也可以舉例上百條，看完上述的例子，不以為然的人都可以舉證一二，這些我覺得都成立，談投資，一定要對每一個投資標的，正反面都詳細評估和瞭解，有心的讀者也可以翻閱有關美國缺點的書籍，看看不同角度的探討，例如（英）托尼·金賽拉的《美國在崩潰》。

還有其他的質疑，例如美國面對的致命危機，現有的經濟模式有可持續性嗎？老化走調的美式民主政治，這裡發出了一個警訊，美國的精神守護神，也就是權力制衡的機制，有失效的跡象，正發生一種逆向制衡，還有他的信仰危機，美國在監獄人數超過230萬，在監獄的犯罪人數和占總人口的比例，這兩方面都名列世界第一。

此外，美國本身也有許多的問題和面臨的挑戰，他的外貿赤字，扮演世界警察所受到的質疑，和常有執法過當及效率不彰的公營機構，例如郵局，這和台灣的郵局幾乎不可相比，也有許多沒有效率的管理，特別是有些鄉鎮級的地方政府機構，以新澤西州為例，有時開車不到五分鐘就經過了兩個城鎮，所以這些疊床架屋的組織結構都不是最有效的。
