# 我是怎麼掉進股海？

先來聽個故事吧，有位企業家要選接班人，決心、膽識和毅力，是他看重的，邀請了公司所有員工到他的豪華別墅舉行派對。當大家享受美酒、美食和美樂時，音樂驟停，他召集大家到一個池邊說，「你們都知道我想選接班人，這池有幾條凶猛的鱷魚，誰能從池的這一頭游到那一頭，他就是我的接班人。」話剛說完，還沒有時間給大家思考，只聽「撲通」一聲，有一个人已經下去了，這聲音驚動了池內的鱷魚迅速朝年輕人游去，只見這位年輕人使出全身的力量，拚命且快速地游到池的另一頭，一個躍身就上了岸，企業家非常高興的走過去，問年輕人如何做了這麼一個難以下的決定，年輕人氣喘吁吁的說，「董事長你能不能先告訴我，是誰把我推下去的？」

這年輕人之所以有這麼大的本事，是因為對鱷魚來說，不過是一頓點心，但對年輕人來說，那是他全部的生命；點心固然美味，但用不著拚老命，一旦生命受威脅，那力量是非常驚人的。我為什麼會進入管理投資的這個行業，因為我別無退路，也是被推下去的。
