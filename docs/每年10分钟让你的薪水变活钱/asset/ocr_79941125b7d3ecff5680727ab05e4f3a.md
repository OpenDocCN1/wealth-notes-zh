# 每年10分鐘，讓你的薪水變活錢

![](bbox=[0.17, 0.17, 0.47, 0.23])

+   1. 施先生的書，是針對0050的操作方式來討論，相當的聚焦，可優先閱讀。
2. 邱小姐的書，涵蓋內容相當多，幾乎投資和財務規畫都有涉獵，適合多數家庭參考，方法簡單，適合優先操作試用。
3. 陳忠瑞先生的《股海戰國策》，以投資為主，涵蓋了ETF和單一股票，在使用燈號操作0050上也有獨到的見解，而且涵蓋了個股的討論，所以也適合操作個股的投資者參考。
4. 至於台股的操作方式，可以個人喜好來調整，或將資金分成三份，分別用上述的操作模式做嘗試，再選最適合自己的。
5. 如果想進一步瞭解0050和其他基金的績效比較，那麼綠角的《股海綠經》，對指數化投資也有深入和精采的討論，特別是閱讀本書對美股開戶還有疑慮的，他的書有很清楚的步驟說明。
6. 有關美股開戶也可以參考畢德歐夫《美股大贏家》。
7. 想對美國整體經濟或社會制度進一步瞭解的，有下列幾本書：愛樹克的《道瓊3萬點》、王伯達的《美元圈套》、龐宗佳和陳思進合著的《美國憑什麼》。
