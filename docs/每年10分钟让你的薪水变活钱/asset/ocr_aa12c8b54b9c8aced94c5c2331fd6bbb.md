# 台股指數和標普500
哪個容易被超越？

道瓊30工業指數雖然也是加權平均指數，但它幾乎都是產業的龍頭老大，從美國上萬家公司中選出了30家，至於標普500，也有人稱為500強，這個「強」字，就說明了它的體質。

台灣的加權指數，有超過866家，幾乎台灣所有上市公司全部列入，雖然也有加權比重，例如2014年台灣台積電佔比률은 13.64%，鴻海 5.56%，但是弱的公司還是有被列入。不像道瓊30或標普500，把弱的都已經排除了。

簡單的說，台灣指數是強弱的混合，雖然強者的比率較高，但也把弱者考慮進來了。
