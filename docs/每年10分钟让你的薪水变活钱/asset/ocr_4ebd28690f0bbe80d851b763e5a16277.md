# 在大海中為你撈到那一根針

湯姆·漢克斯有一部電影《達文西密碼》，每個投資領域也有它專業的密碼，沒發現以前，你就像在大海裡撈針，發現後，可能你就不覺得稀奇了，這就是台灣俗語所說的「江湖一點訣」，說破了一點都不值錢，大海找一艘沉船都不容易，何況是撈一根針，當我以金融海嘯做測試的四種進出方式，呈現在你眼前時，最好的成績是表3-12中B案的方式，以藍燈啟動，經濟衰退時進場的，累計總報酬98%，也領先邱小姐的81%，這個波段，領先台股0050的71%，多數人可能會覺得我以藍燈啟動的方式，分5次或10次進場的績效最為理想，因為它的績效看起來很好，但所謂數字不會騙人，人卻會玩弄數字，許多行業的行銷經常告訴你是「正確」的數字，但卻不是夠「完整和全面」的數字，從事投資，如果只看到片面的數字指引，一方面沒有足夠的用心，二方面沒有這方面的專業，就容易被誤導，如何比較客觀和全面呢？
