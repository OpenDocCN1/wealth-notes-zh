# 同樣的投資理念，
適用於不同時代嗎？

或許你會有個疑問，第一代老張、老王的例子發生於1959年，各自投資兩種不同的投資工具，老王為了「短期資金不受波動與本金的安全」，選擇了三十年期公債；老張關心的是「長期購買力的保值」，選擇了美國的指數基金。三十年後，兩家人有了一個巨大的差距，老張三十年後的資金成長比老王多了3倍，這種的結果是一時的，還是一個的長期趨勢？

# 第二代老張老王的故事

我們同樣再以老張老王做個驗證，這兩位第二代鄰居，從1970年開始，時間比第一代縮短，以二十年來做對比，兩對夫婦同樣以20萬美元開始，老王夫婦還是很幸運，找到了年利率8%的二十年期公債，老張投資標的同樣是標普500的指數基金，這一次，老張改變做法，提出的金額加大，從第一代的3%提高到每一年領取5%的
