# 台股如何複製
阿甘投資法？

想想看，全世界百大品牌有一半在美國，這些企業在全世界為它的股東們攻城略地，有這樣的環境和武器，沒有交出任何成績來都很難，所以我非常鼓勵所有投資者 在地球村的時代，應該開個帳戶透過美國投資全球。

有些投資者一則無法克服語言障礙，二則對台灣的環境比較熟悉，那麼如何利用台灣「限」有的環境來發揮呢？有沒有辦法複製阿甘的投資策略？當然有，台灣代號0050的出現，解決了這一半的問題，既然有摔不破的特性，接下來就是如何讓這工具充分利用台灣股市特性做更好的發揮。台灣的投資達人施景輝在他的著作《只買一支股，勝過18%》有些精采的論述，呈現了台灣0050自2003年6月底成立以來，到2012這九年多的股市投資績效。
