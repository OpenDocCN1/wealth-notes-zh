# 每年10分鐘，讓你的薪水變活錢

果，每家藥廠新藥發展所累積的專業和經驗，也都是它接下來的突破口。

試想，一家公司的研發費用，相當於一個國家的國防預算，可想見這個國家兩百年所打下的基礎。另外還有微軟公司，一年研發費也是90億美元，相當於2,700億台幣。全世界很少有一個國家不但有這麼多公司，還投入這麼高的研發費用。這也就是美國可以不斷提高生產力，推出創新產品，引領全球風騷的實力，產值當然就不是出賣勞動力的國家可相比擬的。

以上分析可以看出，美國絕對不是那隻病貓，最近兩次的股市崩盤，兩次的中東戰爭，讓美國付出了失落十年的代價，但當戰爭結束，當年網路泡沫投入的基礎建設，讓今天的網路更有效能和生產力，如果我們預判對的話，很可能就是美國東山再起的階段。當然，美國已不可能維持當年超強的地位，中國崛起，歐元區也有共識，未來的挑戰很多，但放眼未來二、三十年，美國兩百年打下的基礎，不可能如此就土崩瓦解。它的綜合國力，和藏富於民的規模，都是世界之最，提供了它脫離困局的本錢。容我再強調一遍，兩百年藏富於民的基礎和努力，如果無法深入這點，就無法看懂美國。
