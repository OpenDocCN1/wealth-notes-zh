# 解惑篇：為什麼我的退休金是別人的一半？

追上去了，英代爾失去了優勢，公司沉痛宣布放棄這個產品，想看看當年這是一個多麼沉痛的決定，自己發明的產品卻拱手讓人，日本主導市場若干年後，現在又變成韓國的三星取得領先地位。

英代爾當時的總裁葛拉夫，有一句名言：「唯偏執狂得以生存。（Only the Paranoid Survive.）」《我看英代爾》的作者華裔副總裁虞有澄也曾提到，葛拉夫經營公司有相當的危機意識，有一次開會打出一張幻燈片，把在場的主管嚇出一身冷汗，圖片顯示對手已追了上來，明明上個月開會還遙遙領先，怎麼才一個月時間就山河變色，難道要重蹈當年DRAM的下場嗎？

大家心中疑問怎麼可能這麼快？最後葛拉夫告訴大家，這張幻燈片就是當年自家DRAM被人家取代時的歷史場景，大家才鬆了一口氣，但也上了一堂課，永遠不能懈怠，符合孟子所說生於憂患死於安樂。
