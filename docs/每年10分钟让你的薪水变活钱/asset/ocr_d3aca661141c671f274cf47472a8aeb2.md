# 解惑篇：為什麼我的退休金是別人的一半？

婦這三十年所領的總和也不過34萬美元（每年利息8,000美元×30年，加上拿回到期的本金還是10萬美元，見表2-1）。老王難過的說：「三十年前的10萬美元是多麼值錢啊！現在的10萬，老兩口哪能過幾個殘冬。」
