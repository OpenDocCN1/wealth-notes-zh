# 股災下的危機應變

關於第四代的老張老王數據演算，我們刻意選擇2000年開始，因為這是美國歷史上少數慘重的失落十年，就算加入了股利，這十年幾乎都沒有成長，又碰到公債的大多頭，所以在這麼困難的情況下，再來看看股市的投資是否禁得起考驗，也有特別的價值。(多數人都聽過美國1929年開始的經濟大恐慌，事實上股票的大跌是在1930年代，從1930-1939年，是一個悲慘的十年，而2000-2009年其實完全類似，這十年股災相當嚴重。)

近十五年當中，老王在2000年找到的二十年公債利率是6.86%，所以每一年可以領到13,720美元的利息，截至2014年12月31日為止，十五年的期間一共拿了20萬美元左右的利息，假設本金20萬美元如數領回沒有虧損。
