# 邱小姐的投資心法

212買股法則，是指當景氣對策信號分數，約略是上一次景氣高峰時燈號分數最高的二分之一，而且連續出現兩個月，就代表可以開始進場買進台灣50ETF。這是從整體經濟角度來切入，因為景氣對策分數包含了幾項經濟上所謂的領先指標參考。

282賣股法則，則是指當該月景氣對策信號分數出現28分（不含）以上，而且一連出現兩次，代表景氣可能趨熱，可以開始獲利了結。景氣穩定的綠燈分數是落在23–31分。

邱小姐使用282賣股法則，也就是28分出現兩次就準備離場，是比較保守的做法，是景氣開始稍微要熱，但還沒有過熱，做法保守也沒有什麼不好，她的操作不會在最低點進，也不會在最高點出，而是選擇半山腰進，景氣指數28分還不是過熱，但她覺得賣在半山腰，早一點出場也算安穩。
