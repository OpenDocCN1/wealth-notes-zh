# 每年10分鐘，讓你的薪水變活錢

你想知道未來一百年的趨勢嗎？從通貨膨脹造成購買力下降的走勢來看，永遠是持續下跌的趨勢，未來一百年、兩百年都不會改變。而股票未來一百、兩百年永遠是呈現上漲趨勢，現在看這個圖形很清楚，但是一談到投資，還是有很多觀念的盲點和迷失，造成理財成功的威脅，這可能就像我們要呈現的圖形一樣，需要經過一番教育和說明，才能徹底改變你失敗的基因，開始換成有錢人的腦袋和思維，當這個知識變成信仰融入血液，進入骨髓，你才會做出正確理財決定。

通貨膨脹造成購買力每三年下降的圖形由於趨勢緩和，不會讓人有危機感，但長期就是溫水煮青蛙的效應，相反的，股市的圖形，短期間有大漲大跌的現象，但長期的股票趨勢都是由左往右呈現上漲，一百年以後也是如此。

台股失落了二十五年，但通貨膨脹侵蝕購買力依然進行著，過去三十年，台灣的購買力損失近40%（見圖2-8），台灣的股市沒有像美股亮麗，這二十五年中，雖然股市幾乎沒有成長，但每一年還有4-5%的股利率，也擊敗了通貨膨脹，如果能夠搭配美股則成績大不同，這也是我們建議多少也要考慮美股的原因之一。
