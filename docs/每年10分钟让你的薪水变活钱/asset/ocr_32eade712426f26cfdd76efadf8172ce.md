# 每年10分鐘，讓你的薪水變活錢

時扮演一個大水庫，先讓企業活起來。像金融風暴這幾年，美國大藥廠十年來也很少有新藥發展成功。我有位客戶，在默克（Merck）這種國際性大公司工作，2013年聚會，我才知道他的部門已裁到只剩下他一個，這是經濟結構的高度自由化。以上所舉的例子，只是一個企業體的部分而已。貨幣寬鬆政策推出以來，美國實行得相當有效，背後的條件，並不是每一個國家都能夠依樣畫葫蘆成功的。

談到對外貿易的開放，用柯林頓總統當時簡單的一句話就可以說明，他向日本官員喊話，大意是：「開放吧，別讓你們的牛肉那麼昂貴！」或許有人說，不是開放的問題，日本人看不上外國的牛肉品質，如果你到過美國的好市多（Costco）或許多的超市，有些水果品質極為穩定，而且價錢合理，全世界好的產品彷彿都優先到了美國似的，要美國人不消費看起來都很難。

總結的說，美國的貨幣寬鬆政策目前能成功（後遺症要若干年後才能檢驗），背後有許多條件，還真不是一般國家能夠依樣畫葫蘆成功的。
