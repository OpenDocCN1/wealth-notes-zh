# 每年10分鐘，讓你的薪水變活錢

有一件事情是真正的結束，直到你停止嘗試的那一刻。

+   6. 不要害怕承認自己的不完美，正因為這不完美的共同點，才讓我們維繫在一起。

+   7. 不要害怕面對風險，我們可以借助它學習如何勇敢。

+   8. 不要藉口真愛難尋，而讓愛遠離生活，最快得到愛的方式就是給予，最快失去愛的方式就是緊緊擁抱，最好的方式保有愛就是給他一雙翅膀，自由而沒有負擔的。

+   9. 不要把生活步調經營得太匆促，以至於忘了身在何處、走向何方。

+   10. 不要忘了一個人最大的情感需要是希望被欣賞。

+   11. 不要害怕學習，知識是沒有重量的寶庫，你可以隨意攜帶。

+   12. 對時間與說話都不能輕率，這兩者都覆水難收。

+   13. 生活不是百米的賽跑，而是我們足下的每一段旅程，昨天已成歷史，明天充滿未知，而今天是一份禮物，這也是我們稱它為當下（英文中的present是「禮物」和「當下」的多義詞，在這裡一語雙關）。
