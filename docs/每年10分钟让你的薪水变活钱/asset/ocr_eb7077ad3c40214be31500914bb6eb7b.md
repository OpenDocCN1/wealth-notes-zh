# 經歷股災的阿甘投資法
是否無恙？

曾被選為全美第一名的基金經理人，投資奇才彼得．
林區，在他隱退時的第一本書《選股戰略》（*One Up on
*Wall Street*），一開始就有一個章節分享他的專業經驗，
題目是「這是一個好市場嗎？請別多問」。

基本上他是一個採用由下而上方式選股的投資者，他
和巴菲特的成功都不是仰賴對市場判斷的成功而成功，他
們都比較關注於投資標的是否價格合理，具備吸引力，而
決定是否要投資的思維。

他和巴菲特一樣，不認為誰能夠長期的預測股市的轉
折點，他提到，數以千計的專家研究指標，還是無法有效
預期市場，就像羅馬帝國皇帝身邊的智士，費盡腦汁也算
不出敵人何時來襲。
