# 只有具備理財能力才有機會財務自由

說來難以置信，第三年我們又是重複的話題，我非常 的感觸，我和他有這麼好的交情，他也幫了我這麼多忙， 這些年我為許多客戶創造出投資的分身，這幾年來每年的 獲利，相當於客戶一年的工作所得，這些客戶把握了股災 之後反彈的契機，毀滅性的金融海嘯走了，發財列車來 了，我們多少也上了車，我這位朋友卻沒有好好把握機 會，我彷彿看到車窗外的他愈來愈遠。

我曾經玩笑的對他說，你所有的事情都比我聰明和能 幹，可是唯一在投資理財上你趕不上我。我在想問題出在 哪裡，如果他有一點阿甘的傻勁，又能借助別人的長處或 專業，或像彼得·林區所說的，別老問這個市場好不好， 投資就對了，以他這麼多年的奮鬥，應該在步入中年，進 入被裁員的高峯期時，早就應該有一個賺錢的分身。

你認為問題出在哪裡？我們常說知識就是力量也是財 富，他也想投資，要不不然不會一直找尋進場的切入點，但 他並不瞭解股市的本質，也不瞭解美國股市的特性，如果 他能對股市有一個寬闊的視野，瞭解每一項投資工具的限制，以及如何利用這個限制，就像我們這本書從頭到尾， 循序漸進，想要呈現的這些財務知識，或許他的膽識和決 定會不一樣。
