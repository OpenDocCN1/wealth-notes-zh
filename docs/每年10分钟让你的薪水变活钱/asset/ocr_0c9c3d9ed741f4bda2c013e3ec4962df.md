# 理財學堂

賣權（PUT），即在到期日或到期日之前，按照一定執行價格賣出標的資產的權利。以上是教科書的說明，許多人有看沒懂，用我的說明如下：就像保險公司跟你的合約，在彼此同意的條件下，如果發生事情，保險公司必須理賠，但你必須支付保費，你就像是買了賣權（花錢買保障），保險公司則是賣權的賣方，收你保費，判斷事情不會那麼嚴重，舉例：星巴克咖啡現在股價$88，有人判斷它不會低於$80，那它就可做賣權的賣方，萬一低於$80，比如跌到$75，他就賠你$5的差額，但定出一個時間，你要付保費，時間到了，沒有發生，你的保費就白付了。
