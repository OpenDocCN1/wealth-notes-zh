
# 每年10分鐘，讓你的薪水變活錢

投資者第一個想法，和他的投資風險承受能力。

但用心的專業人士也不應放棄，而應進一步帶領投資者有登高望遠的視野，給投資者寬度和深度的延展，讓他進入第二個層面，例如更清楚的瞭解投資世界過去的歷史，未來可能的變化，和在人生不同的階段，應選擇不同的投資工具和適度風險承受，來因應未來的衝擊。簡單的說，瞭解過去的歷史和進一步的理財教育，常有助於找尋到投資者真正和他恰當的風險承受範圍。

通常關心風險意味著投資安全性如何，而多數的投資者都同意風險與安全的相關性，因此我會問提問者：「所謂的安全意味著短期的波動和本金的不可以損失，對嗎？」多數人都會有這樣的期望。

接著我再問：「長期購買力下降的風險，你關心嗎？」幾乎每一個人一定都會點頭表示同意。第三個問題是：「短期價格波動的風險與長期購買力的風險，你更關心何者？」

上面三個提問是想開啟許多投資者以往可能沒有思考過的，在這樣的狀況下，如果未經思考而錯用投資工具也就不足為奇。長期的投資目標卻用短期的投資工具來應對，投資的結局當然往往不理想，就如同美東到美西，北京到上海，台北到台東，飛機若遇空難倖存的機會最小，所以走路最安全，可是多數人不會選擇用步行的方式，因為緩不濟急，這個搭機或走路的選擇方式很少人會做錯，但在投資的世界裡，錯用工具的比比皆是，遺憾的是，發現這樣的錯誤時，許多人可以修正的時間早已流失，在下面的章節裡，讓我說一個故事，你可能就更能明瞭：為什麼你的退休金是別人的一半？

## 解惑篇：為什麼我的退休金是別人的一半？

### 公債與股票的績效之爭

讓我用老張、老王兩家人，在不同時空背景下的例子跟大家說明，不同的理財規畫，和產品的認識及觀念，會造成怎麼不一樣的結果。其中，這故事人物是虛構的，但所使用的數據是真實的。

老王選定的是15-30年的政府公債，老張投資部分，則使用美國標普500的指數基金，美國追蹤且複製道瓊或標普500的基金和指數基金ETF很多（見「理財學堂」），管理費大約在0.15-0.35%，比一般共同基金的管理費1-1.5%相對的低廉。

### 第一代老張老王的故事

1959年時，老王和老張兩對夫婦覺得辛苦了大半輩子，決定提早退休頤養天年，於是變賣產業，付清了其他的負債。巧的是，兩個家庭都有10萬美元餘款，王太太告訴老王，這筆錢的投資一定要安全，最好是能有保證的，老王心想，依照這個原則，定期存款（CDs）或公債（Bond），是最符合的了。

#### 先甘後苦的老王

當時，銀行提供的利息，大概只有3%左右，高品質的公司公債（Corporate Bond）的利息也不過略高於3%，但老王實在夠幸運，竟然找到了利率8%、三十年到期的公債投資，這好比是現在找到了利率13%、三十年到期的公債。老王心想，該是了卻多年的一個心願了，那就是擁有一部凱迪拉克（Cadillac）車子，那時車價是5,455美元，老王第一年所領的利息8,000美元，付得輕輕鬆鬆，老王開著這部車子，老兩口徜徉湖光山色，老王滿意極了目前的收入和退休生活。

![](img/61834aabde2e6630ef195b2156c18099_49_0.png)

老王購買的公債是屬於固定收入型的投資（Fixed-Income），特性就是當初載明的利率（利率每一天都在變動），一旦簽約購買，在這時間內利率就固定，所以在這三十年中，每年都會領到8,000美元的保證利息，而且到期時，可領回當初投入的本金10萬美元（見表2-1）。

然而，不幸的事發生了，老王的車子奔馳多年後，終於進了廢車場，老王夫婦一點都不擔心，因為支票馬上就要到手了。老王夫婦已熟悉凱迪拉克的設計和性能，所以兩人一致決定，還是再買同一種牌子。第二天，兩人興匆匆的出門，卻垂頭喪氣地只開了一部福斯（Volkswagen）的小車回來，因為老王的8,000元利息經過多年的通貨膨脹後，連付一半凱迪拉克的車款都不夠，老王夫婦實在不能理解，這世界為什麼變得這麼快，快得他們都跟不上，老王說：「看來以前拉風的日子已經過去了。當年看起來安全又穩當的投資，此刻卻是陷入了經濟上的難題。」

再來看看老張夫婦的遭遇可就完全不同了。老張認為投資注重安全是極為重要的，但是未來的購買力也要能跟上時代，要不然日子愈過愈差，連給孫子們買玩具的錢都沒有，說不定得靠兒子、媳婦的經濟支援，老張認為這樣就有失提前退休的原意。

有了這樣的目標，老張把錢投資在美國標普500的指數基金，這個決定讓老王取笑了好幾年，怎麼說呢？因老張第一年領取只有3,000美元（這與老王是不同形態的投資，利息和股利率是不同概念，公債領取的是利息，而股票則是發放股利〔見「理財學堂」〕），這筆錢只夠老張夫婦買了一部新的雪佛蘭（Chevrolet），為此，張太太還埋怨了老張好一陣子，每年收到支票就要囉嗦老張一頓，而且懷疑這個決定是不是錯了。老張很有耐心地說：「太太，相信我，這個投資決定，不會比你嫁給我所做的決定來得冒險。我是做過研究，因為物價上漲會侵蝕我們的財富和購買力。股票是一個比較有效的保值方法之一，而且，透過美股的指數基金來操作，風險可以降低。」

![](img/61834aabde2e6630ef195b2156c18099_51_0.png)

老張認為，股票投資，投資者就是股東，只是大股東、小股東的區別，但投資者可以享受到公司的成長（當然也可能有虧損），但整體而言，不會像公債或定期存款，只能領取固定的利息，公司賺錢了，公債的擁有人也分不到盈餘，因為他們只是借錢給公司或政府，拿點利息罷了！短期投資還可以，長期而言，就不是一個很理想的做法了。而既然是投資，總要給點時間，不是今天投資，明天就是百萬富翁，那種方法，以前叫「投機」，現在就叫「瘋」的！老張覺得投資要的是穩紮穩打，給一點時間，再來印證。

後來，老王車子壞了的同時，老張的車子也壞了，老兩口決定買部新車，老張心想：光是1989年的股利，就有21,210美元（見圖2-2），相當於當年10萬美元投資的21%，應該有能力給老伴買部多年來她想要的凱迪拉克，以便印證老王夫婦口中的這種好車，結果老張花了22,975美元買下了這部車，只多加了1,765美元。

張太太靠在舒適的椅背，望著窗外蔚藍的天空，和風徐來，心情舒暢，一時興起，拿起了資料，盤算了三十年來的投資表現，令她大吃一驚的是，這三十年，光是她所收的股利就已高達23萬多美元，除了股利外，當年的10萬美元本金，現在已總值到近112萬美元；而老王夫婦這三十年所領的總和也不過34萬美元（每年利息8,000美元×30年，加上拿回到期的本金還是10萬美元，見表2-1）。老王難過的說：「三十年前的10萬美元是多麼值錢啊！現在的10萬，老兩口哪能過幾個殘冬。」

上面兩個故事，透露的訊息和觀念，我整理如下，做為參考：

### 觀念一點通

- 1. 短期內要動用的錢，或不能承受任何一點虧損風險的投資，定期存款（CDs）是一個較安全的地方。
- 2. 如果可以承受風險或者中長期以上才可能動用的錢，股票的投資應該列入考慮。
- 3. 股票的特性之一，短期而言，就是價格的浮動性要比公債及定期存款來得大，但中長期而言，整個股市必定往成長的方向發展，所以，中長期的投資，不要因為短期的價格浮動，而不敢接近股市。
- 4. 從我工作上的接觸，我發現有許許多朋友，錯把自己所買的公債基金當成股票基金，這是兩個截然不同性質的投資，投資前有必要確切瞭解自己所購買的產品特性。
- 5. 退休帳戶（IRA或401K），在正常情形下，59歲半以後才可動用，有如此長的投資時間，最好是以股票或有一部分為投資工具，美國居民有所謂的個人退休帳戶IRA或公司提供的401K退休帳戶，資金可投資股市，最大的好處是這金額可免掉所得税，且在股市獲利也可暫不交税，遞延到退休領取時，所以有兩項福利，延稅和節稅，可惜台灣並沒有這樣的設計，允許個人可以有退休帳戶投資股市，所以必須讓合法的稅務規畫和個人投資分開來進行。
- 6. 有數不清的投資者不分情形全擺在銀行裡，但别忘了，銀行是個儲蓄的地方而不是投資的場所。

股票的擁有，大約有二種方式：1）個別股票（Individual Stock），2）共同基金（Mutual Fund）或ETF。嚴格講，股票的挑選是困難度相當高的工作，許多人玩了多年的個別股票，依然沒賺到錢，而績優的股票共同基金或足以代表市場的股票指數基金ETF（不是所有的指數基金都是穩健的）則是比較穩健的投資工具，值得好好利用。

「安全」的投資，並意味著投資的結果一定有保證，安全指的是風險的承受要適度，過少或過多，同樣不會有好的投資效果。

「風險」這兩個字，在財務的世界裡，應該是個中性的字眼。沒有一項產品能夠免除風險，人走在路上有被車撞的危險；錢放在銀行，有變薄的風險；錢放在股票有價格波動、甚至虧損的風險。

老王夫婦最大的錯誤，就是錯把利息的「保證」當作是安全的投資，而忽略固定收入型的投資（Fixed-Income）如定期存款等，只有利息的収入，沒有資金的成長，或公債有利息收入和資金的成長（當利率下降時），但長期以來擊敗通貨膨脹的效果有限，錢變薄的情形之下，是無法有效處理購買力降低的風險。所以，對股票投資有恐懼或不以為然的朋友，應該重新考慮把它列入規畫、投資的組合。對風險承受力低的人也不必擔心，資產配置可以解決大部分投資者關心的問題。

### 理財學堂

> **共同基金**——基金公司依法設立，以發行股份方式募集資金，投資者做為基金公司股東角色出現。它在結構上類似於一般股份公司，但本身不從事實際運作，而將資產委託給基金管理公司管理運作，同時委託其他金融機構代為保管基金資產。

**道瓊和標普**——原則上沒有利息收入，發放的是股利，每家公司決定的高低不同，比率不定，如同蘋果公司長達二十幾年沒有發放股利，一直到2012年。道瓊和標普在不同年代有比率不同的股利發放，例如道瓊1980年大約有4%股利的水準，2000年後大約維持在2~3%之間，股利率是不固定的，台灣許多績優公司比美國發放的還高，大約在4~6%。

**公債**——是指政府或公司為籌措資金，憑其信譽按一定程序向投資者出具的承諾，在一定時期支付利息和到期償還本金的一種格式化的債權債務憑證。

**通貨膨脹**——指一般物價水準在某一時期，連續性的呈現上漲的狀態。

**ETF**——指數股票型基金，是一種在交易所上市交易的開放式證券投資基金產品，交易手續與股票完全相同。ETF管理的資產是一籃子股票組合，這一組合中的股票種類複製了某一特定指數，它的本質像基金，但交易的行為方式卻像股票，所以英文名稱是在「交易所買賣的基金」。

## 同樣的投資理念，適用於不同時代嗎？

或許你會有個疑問，第一代老張、老王的例子發生於1959年，各自投資兩種不同的投資工具，老王為了「短期資金不受波動與本金的安全」，選擇了三十年期公債；老張關心的是「長期購買力的保值」，選擇了美國的指數基金。三十年後，兩家人有了一個巨大的差距，老張三十年後的資金成長比老王多了3倍，這種的結果是一時的，還是一個的長期趨勢？

### 第二代老張老王的故事

我們同樣再以老張老王做個驗證，這兩位第二代鄰居，從1970年開始，時間比第一代縮短，以二十年來做對比，兩對夫婦同樣以20萬美元開始，老王夫婦還是很幸運，找到了年利率8%的二十年期公債，老張投資標的同樣是標普500的指數基金，這一次，老張改變做法，提出的金額加大，從第一代的3%提高到每一年領取5%的帳戶金額，部分來自於股利。

### 股票獲利優於公債穩定利息

- 1. 有些基金公司為了凸顯兩者的差異，可能會選擇石油危機過後的1975年開始對比，如果在那種情況之下，老張成長的幅度極為明顯，幾乎領先老王5倍，但為什麼我們選用1970年代做為測試的起點？因為1973-1974年的石油危機，使美股重挫超過40%（這是指年度累計報酬，如果是從高點到低點則跌幅更重），這麼重的跌幅，用來測試股市是否還是一個值得的投資，選擇股災做為測試的標準，是我們覺得比較客觀的檢驗期間，避免過高的預期。

本書特別關注在重大股災的情況下，這種投資理念是否依然適用，結果發現，第二代老張投資股票的成績，仍然優於老王投資的公債，雖然沒有像第一代，兩者差距3倍之多，但這樣的成績也是相當出色。

- 2. 表2-3中有些數據提醒，如1974年底，老張的本金從20萬美元下跌到14萬美元左右，現在回頭看成績是優秀的，所以你不會覺得驚慌，但如果是在當時，這麼重的跌幅，而且大家手上也沒有水晶球，不知1975年標普500會有一個37%的大反彈，在前一年本金損失了30%的情況下，許多人可能就沒有了信心，早就認賠出場，那就不會有後面亮麗的成績，這也是我一再強調的，股票市場最大的缺點就是劇烈的波動，會讓許多人在轉彎點提前出場。

3. 巴菲特的第一投資定律是不要虧損，第二投資定律是不要忘記前面的第一項，以他這麼謹慎的性格和投資方式，他都還說到，如果在股票市場，你不能接受它下跌50%的震盪，你其實不應該進股市，而過去的股災，短期確實都有達到這樣的跌幅。

4. 如果上述這樣的跌幅你不能承受，那麼老張的這種投資模式就不適合你，適合你的則是資產配置，股市依然可以參與，但是在比例上和方式要做一些修正。
