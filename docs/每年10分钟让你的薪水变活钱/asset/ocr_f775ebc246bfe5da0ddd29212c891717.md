# 前言：這本書憑什麼值得購買和閱讀

# 有實務經驗，為客戶創造了賺錢的分身

我除了管理共同基金以外，更多管理的資金是在全權委託的代客操作，原因是比較靈活，有時績效會比基金更突出，這幾年因投資管理為客戶創造出來的分身，所帶來的投資獲利不亞於他們的工作所得。

# 過去犯錯但又可敗部復活的珍貴經驗

如果我投資管理的成功，是未經過股市的最殘酷打擊和淬鍊，那可能還只是停在打順手球的階段，而過去近二十五年的投資管理生涯中，我歷經了幾次重大股災和美股失落十年的重大挫敗，特別是2008年金融海嘯，我幾乎被打趴在地上，有人說成功是最差勁的老師，失敗後再成功的經驗更值得你參考，我是敗部復活的見證之一。

# 為你節省閱讀的時間和金錢

這本書以每一年我閱讀10本書來參考，三十年就讀了300本，經過醞釀沉澱，理出脈絡，且在實務中試煉，最後才提煉出的「雞精」，這是去蕪存菁，還是不施打荷爾蒙的雞精，這樣為你省下閱讀300本書的時間和金錢。
