# 每年10分鐘，讓你的薪水變活錢

認為股市應該沒有時間上的關聯性，如果他能讓你相信這 一點，他認為這本書已經達到目的，這麼強烈的用語應該 透露他想扭轉一般人對股市的錯誤認知。

我的看法是，股市和時間未必有強烈的關聯性，和它 的本身價格是否合理則有一定的關係，股市價格高估，也 未必會立即反應，還可能會持續被高估一陣子，但高估的 市場終究會反應，下跌拉回，再回到一個正常合理的區 間，周而復始。

對專業管理者來說，每一次的轉彎點是想要去掌握卻 未必每一次都能正確判斷，多數的業餘投資者如果來做這 樣的工作，未必要不是明智、最好的方式則是在你風險承受 範圍之內，想辦法「全程參與」。例如阿甘式的投資法， 利用每一個下挫點，在你可以的範圍內適度的逢低加碼， 如果你想低進高出，一旦錯過了幾次關鍵的轉折點，沒有 搭到列車，花了许多時間，卻未必能交出一個你所預期的 亮麗成績單。
