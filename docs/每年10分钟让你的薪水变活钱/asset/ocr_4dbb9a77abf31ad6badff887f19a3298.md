# 每年10分鐘，讓你的薪水變活錢

投資大戶如何衡量自己一生的價值呢？有遠見的應以巴菲特為典範，帶頭登高—呼支持公平正義的稅制，也就是股市的獲利應納入所得，這些繳稅，對大戶只是九牛一毛，但可以幫助國家稅制健全，社會進步，當財富到了一個階段，能扮演這樣的推手，人生還有什麼比這個更有意義的呢？這樣的人恐怕還需要帶點浪漫、有高瞻的視野和信仰的情懷，期待台灣也有這樣大戶的產生。

至於對躲在定存、靠微薄利息收入、或找不到投資標的廣大投資者，如何找到簡單，安全和有績效的投資方法，是重要的第一步，而這已找到，整本書都介紹了符合這三個標準的工具，接下來是讓更多人能參與和分享台灣及全球經濟成長的果實。

那麼對年輕族群的教育，首要的是，瞭解勤俭致富和獲取第一桶金的重要，有了它，就有了立足點，也就有機會和全世界一流的企业共同成長，年輕人有希望，這個國家就有活力和安定。

一般投資者和年輕族群的教育，值得大家注意和推動，台灣民眾勤奮，善良，如因觀念上的盲點，視野的受限，無法突破，以至於沒有行動，我覺得十分可惜，教育絕對是脫離貧窮，創造財富的最佳途徑，只要播種，就有希望，只要開始，就會有收穫。
