# 每年10分鐘，讓你的薪水變活錢

以金融海嘯股災單一來看，我使用的燈號操作方式優於邱小姐的績效，但以過去二十年的成績來看，邱小姐的表現領先其他三種方式，這並不是說，以燈號進出場的方式會差，而是這裡面有技術和藝術的成分，例如，資金分幾次進場，對績效就會有很大的影響，而且目前只是用定時定額的方式，如果是股市的老手，使用定時不定額，把資金在最底部時進入，成績更好，但這樣的變數，都不是我希望給一年十分鐘來操作的讀者，因為藝術和變數的成分較多，邱小姐的方式就非常接近科學，較少模糊的空間，所以容易操作，縱然彼此使用的方式互有領先，但我覺得她的方式對多數的讀者應該優先考量。
