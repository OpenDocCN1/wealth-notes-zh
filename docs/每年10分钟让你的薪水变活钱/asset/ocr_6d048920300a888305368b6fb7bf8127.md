# 每年10分鐘，讓你的薪水變活錢

力上與日本做了黃金交叉。

我有位客戶，小孩在美國著名大學企管系畢業後，特地送到日本去念碩士，做為接班的培養，念完回來，我問他心得，日本是不是可以比美國快速脫離經濟的低迷，他的答案竟然是很難，因為企業文化和結構性的問題，我問到日本原引以為傲的企業終身雇佣制，難道沒有效用嗎？他說有好有壞，雖然終身僱制有它的優點，員工穩定，但公司在換血時，有所顧忌，反而有可能拖垮公司的財政。

上市公司如果不能獲利，股價就低迷，就形成了所謂的惡性循環，如果是股市投資者，或曾在美國上過班或聽過的人，就有很深刻的感受，每一次經濟衰退時，公司裁員毫不留情，初來乍到會覺得美國怎麼變得這麼沒有人性。這要換一個不同的思維來看問題，公司也要生存，碰到經濟衰退時，公司有權利做所謂的人事精簡和最有效的資源運用，度過寒冬。

大公司有些人才因故被裁掉，進入了中小企業，這原本是中小企業不容易有的機會，公司裁員通常是沒有情義的，第二天上班被通知時，安全警衛說是陪著，也是監視著，當天收拾私人物品、領取公司的裁員貼補方案。這樣看是殘酷，但公司可以快速的原因經濟衰退的各項對策，財政不被拖垮，如果能夠快速穩定，避過風暴，進而獲
