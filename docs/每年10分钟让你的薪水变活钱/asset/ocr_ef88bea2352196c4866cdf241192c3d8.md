# 每年10分鐘，讓你的薪水變活錢

簡單的說，這件事可以有三個階段來看，標普有兩個階段跟柯達的績效有關，第三個階段則無關：

**第一個階段：1930-2004年柯達是藍籌股中的藍籌，迪士尼樂園當時還為它建立了一個場館，這段期間它的股價相當亮麗，標普500因它是成分股而分享了它的績效。**

**第二個階段：2004-2010年柯達股價由40美元跌到5美元，跌幅近87%，因为是標普500的成分股，標普500因而受到拖累，由於還是成分股，所以必須承受。**

**第三個階段：2010年12月17日，柯達因不符合標普500的成分股而被踢出，之後股價從5美元繼續掉到0.34美元，請問第三階段柯達股價的好壞，與標普500有關係嗎？我個人也是美國多數投資管理者，認為這時標普500的成績與柯達的好壞已經無關，如果踢出名單之後還有關聯，那所有的指數基金可能就无法進行績效評估了。第一階段受益，第二階段受損，這都是合理的，因為它是成分股，但是第三階段不是成分股時，標普500與柯達就沒有關聯了。**

標普500成分股的變動，通常在七天左右向媒體宣布，讓跟指數基金有所連動的投資者或基金，這時有所依據而調整。總結的說，標普500的績效，考慮了成分股表現的好壞，長期績效還是精準的。
