# 前言 這本書憑什麼
值得購買和閱讀

多年前，一個宴會場合，朋友發現了我，把我拉到一旁輕聲細語的問：「買股票真的能賺錢嗎？我姊夫買股票最近好像虧了不少，我姊姊和他鬧意見……你知道嗎？他還是大學的會計教授……」這段對話，時隔二十年我還印象深刻，買股票會不會賺錢，跟學歷或哪個行業無關，跟用對方法有關。

用對方法看似簡單，有些投資者一輩子都還沒有悟出，而我準備用職業生涯中總結出的賺錢方法來告訴你，雖然未必是獲利最大的方式，但重要的是它達到簡單、安全和獲利的三個原則，而且一年只花十分鐘，或每一季只花一小時，這樣的理財投資方式，對象是給：

+   1. 有理財投資需要，但是沒有興趣的人；
2. 有理財投資需要，但沒有時間的人；
3. 有理財投資需要，但覺得理財太枯燥深奧的人；
4. 有理財投資需要，但資金資源和財務知識都相對欠缺的人
