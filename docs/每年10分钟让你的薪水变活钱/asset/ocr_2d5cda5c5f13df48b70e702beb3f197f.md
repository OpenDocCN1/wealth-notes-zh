# ## 每年10分鐘，讓你的薪水變活錢

是我關心的重點，我關注的是多數人都可以做到的，可以藉此嘗到投資的甜蜜果實，進而達到財務的自由。

這個方法確實可行嗎？許多人無法虎虒生風使用的，就是被多數投資書籍所誤導，與其終日尋找長生不老藥，不如就從今日開始注重養生，過一個不生病的生活，何者重要？許多人都可以回答，但一想到一夜致富的投資，就又走入歧途，什麼雪球，什麼長坡，都置於腦後，又是飆，又是沖，對於我們職業操盤手而言，當然也會去找尋這種火箭股，但更不會忘卻股價反映的是公司的經營，公司合理的股價不可能像樂透，我們相信每天務實的生活經營，尋找雪球股比火箭股更實際和重要。

我就是利用這個觀念和方法達到財富自由，為了讓你和我一樣有同步的深刻印象，你必須在理論上和實際上完全信服，才可以轉化成你的信仰，這個信仰落實於你的投資操作，現在你所需要的，是想準備多少的時間來滾這個雪球，方法找到了，工具找到了，坡度也找到了，如果你一點時間都不給，也滾不出一個像樣的雪球，那需要多長的時間呢？最少二十年，巴菲特的財富也是超過二十年以上滾出來的，你我都沒有巴菲特的功力和機遇，所以二十年是最少的，如果你連二十年時間都沒有，這個方法不是不能用，但是無法讓它表現得淋漓盡致，也就不如找尋別的其他方式。
