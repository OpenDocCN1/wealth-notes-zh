# 理財學堂

+   1. 藍燈，有一首歌叫〈藍色的憂鬱〉，經濟衰退，人的心情確實憂鬱，還真有几分貼切，就不知色彩學是否也認同。
2. 綠燈，交通號誌綠燈表示通行，也意味著經濟穩定。
3. 紅燈，代表警告，景氣可能過熱了。
4. 黃燈，通常意味著停下來聽、看，代表方向可能轉向。
