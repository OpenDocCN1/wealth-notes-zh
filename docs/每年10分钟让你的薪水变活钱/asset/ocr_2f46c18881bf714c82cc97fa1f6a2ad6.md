# 〈信函 4〉

# 成功的人找方法，
給證券營業員的一封信

仁山兄：

「落花時節又逢君」，距離上次相逢，又隔了好幾年，你還能在證券這領域，代表你的努力和能力，但你也說了，台灣市場這幾年的成交量沒有突破，又有這麼多家的證券商分食這塊不見擴大還萎縮的小餅，所以辛苦是可以想見的。

或許你認為我是幕後的操盤手，不瞭解你們第一線面臨的辛苦，我一直沒有告訴你，事實上我和一般基金操盤手不一樣，我的每一位客戶幾乎都是經過我親自面談，要不就是有一個談話之後，才開戶進入我的管理服務，可以說對每一位投資者的狀況有相當的瞭解。下單時，看到的客戶名字，幾乎都可以聯想到他的財務狀況，風險承受，什麼時候見過面，聊過哪些事，最重要的是，因為我的性質和你們不同，你們是客戶做決定，執行下單，我是全權委託，我做決策是要負責任的，這個壓力許多人可能不想承受。
