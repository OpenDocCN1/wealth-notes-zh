# # 禁得起考驗證的 投資理念

好的投資理念，不是在太平盛世或風平浪靜時才行得通，最重要的測試點其實是在股災來臨時，最好是重大的股災，才是最好的測試期。第二代的老張經過了石油危機的測試過關，隨著時間的推移，第三代老張面臨最大的考驗，也就是多數人都還記憶猶新的2000年開始的高科技泡沫，以及2008年突如其來的金融海嘯，第三代老張能禁得起這麼殘酷的兩次重大考驗嗎？如果是，這個投資理念，絕對值得你注意，我們往下看。
