# 喜歡混血兒嗎？
台股美股的混搭操作

不知道妳對混血兒的印象怎麼樣，有些人說混血兒比一般人聰明，我以前辦公室有位助理，嫁了個老外，有天帶了一個比芭比娃娃還可愛的女孩到我辦公室，竟然還講了一口標準的國語，那時我才發現，東方女性跟西方男士生下的洋娃娃，特別是女孩子真的漂亮可愛，反過來或許就沒有這樣的效果。

談投資，學學美國人利用全世界的資源、人才，成就他的霸業。台灣的投資者也可以用同樣的觀念，利用自己的資金、美國的市場，做一個結合，截長補短，美國股票適合成長，台灣股票波動大，如果把兩者的優點做個結合，也是一個不錯的做法，過去二十五年美國雖然面臨了失落的十年，發生兩次重大股災，但實力和國力還是比台灣強，如果兩者混合，可以有提攜、照顧、防衛的效果。

台灣還是新興國家的一環，照理經濟的成長速度和動力，應該高於經濟成熟的國家，如果哪天台灣有這個動力再現，那就是台股反過來照顧美股了，在這一天還未來臨
