# 每年10分鐘，讓你的薪水變活錢

一年碰上中美斷交，生意特別差，蔣萱輝兄和他的弟弟東雄還特地去擺地攤兜售卡片，那年寒訓去成功嶺，也是朋友幫我跑書店、收貨款，幾乎國中、高中、大學同學都幫上忙，在給你寫信的此刻，他們當時的神情和模樣都一一浮現。一路走來，幫助我的人真是很多，那份感謝常在心中，現在慢慢要學會表達出來。

有人說，朋友不是送你鮮花的那個人，是願意真心陪你和你一起笑、一起哭的那個人，朋友不是天天讚美你的那個人，而是指出缺點讓你進步的那個人。

你小嬦嬦2004年過世，你知道她的歌聲很美，那陣子我足不出戶，整天看鄧麗君的實況演唱系列，許多人都擔心我的精神狀態，怎麼脫離那個低潮。現在回想起來還真的不容易，但人生一定有他的困境，這也彷彿前美國總統夫人希拉蕊·柯林頓說：「人生有誰是可以一帆風順的。」那時我的這位朋友萱輝兄，每隔兩、三天就找我出去，無非是希望我能盡快脫離低潮，我告訴他，我沒有興致，不太想講話，他說，「那我就安靜的陪你。」有次在茶莊，我多半時間遠眺台東的夜景，事實上那種情形，别人也很難安慰，它需要時間癒合，而且是一段長時間，但我至今都非常感謝他的陪伴。我還記得十年前，小嬥嬥狀況不佳，從台東被送到了花蓮的醫院，我從美國趕回，有天從病房走出，在長廊的板凳上，發現幾位老友等我，他們放
