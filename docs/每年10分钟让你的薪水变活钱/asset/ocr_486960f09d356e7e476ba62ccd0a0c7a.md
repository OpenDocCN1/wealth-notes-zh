# 每年10分鐘，讓你的薪水變活錢

你可能不知道，我也是從理專的角色開始，當年在美國先考的是基金的執照，所謂的Series 6（6號執照），後來才考了營業員的執照Series 7，巴菲特當年為拯救所羅門兄弟（Salmon Brother）證券公司的經營，擔任了CEO的角色，也規定要有這個執照，他在期限前離開了職位，開玩笑的說，躲過了災難，要不然也考不上。

我做營業員的時間非常短，原因是我發現它違背了我的信仰，我很難接受，也不忍心看散戶投入股市，卻像是一個士兵走向戰場，訓練不足，槍法不準，在一場沒有炮聲的戰爭中，扮演一個戰敗者，要在股市獲勝，一定要有對的方法，瞭解股市的特性和經驗，這些都不是多數散戶能夠達成的。

所以我決定成立投顧公司（基金公司是又隔十年後成立的），為了符合當時公司和監管法規定，我也必須做其他的犧牲，但這樣才是和客戶利益可以契合的唯—做法，1990年我成立投顧公司的第一天開始，所有的客戶都是全權委託，收管理費但完全不拿佣金，進出之間的交易費，我們完全不拿。所以就算一天進出好幾次，客戶都不會懷疑我的操作，就算一年沒有進場，例如2000–2001年高科技泡沫期間，客戶也不必擔心，背後一定有我的道理，因為不拿佣金，所以不會有任何利益衝突，績效是最重要的考量，客戶的帳戶管理好了，他獲利了，我們也成功了。
