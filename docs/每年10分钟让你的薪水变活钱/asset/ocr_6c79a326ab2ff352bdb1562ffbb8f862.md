# 哈博士
怎麼會摔得這麼慘——
股市到底有沒有專業？

哈博士當年有三項完美學經歷的結合：一、哈佛的博士，二、自稱二十年的投資經驗，三、他曾發表的論文是當年證券分析師CFA 考試指定的閱讀教材之一，卻還讓我摔得這麼慘。

在哪裡跌倒，試著從那裡爬起，我開始思考，為什麼股市是這樣，很少有一種行業和一門學問，是在這樣完美的學經歷下，還會有如此極端的錯誤，若股市投資是一門語言，那對哈博士來講，恐怕還是一門外語，他還沒有抓到股市這門語言的神韻之處。

所以，那陣子我開始試著瞭解股市投資。無數個晚上坐在學校圖書館的地毯上，因為不知如何著手，只好一本書的翻閱，但相當的失望，那些博士論文的艱深數學方程式，有看但沒有懂，沒有方向，又沒有人指引，心情是低落的，所幸有位猶太同事，得知我在找尋股市的書籍，告
