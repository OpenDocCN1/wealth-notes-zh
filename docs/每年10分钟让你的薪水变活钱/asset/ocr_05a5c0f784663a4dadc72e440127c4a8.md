# # 別讓銀行搶了你

網絡上流傳，有人搶劫銀行，舉起槍向大家說，錢是銀行的，命是自己的，許多人都因而乖乖配合，寓意是這年頭做什麼事都要懂得心戰喊話，打動人心有所共鳴，有些人或許認為標題寫錯了，這年頭只聽到民眾搶銀行的，沒有聽過銀行搶民眾的。

搶，有合法的，有非法的，有你知道的，有你不瞭解的，有光天化日的搶，有暗地的搶，不管你有什麼理由，搶銀行都是違法的，但如果銀行搶了你，是一點都不違法，只能怪你沒有理財方面的能力，如果你不懂得理財投資，投資其實也是一種沒有炮聲的戰爭。資金是武器，理財知識和能力則是決定你勝負的戰略戰術，戰爭是一種不文明的掠奪侵占，而投資則是比較文明的戰爭，但既然是戰爭，就有勝利和失敗的一方，你是站在哪一方呢？
