# ## 第二類：阿甘投資法

第二類的朋友，雖然喜歡老張和阿甘投資法成功帶來的獲利，但也要特別注意，每種投資工具和策略都有它的限制和不完美的地方，上述兩個方法無法有效處理股災來臨時的劇烈震盪，這個震盪幅度有多激烈，我們會在書中特別標示和強調，讓投資者可藉以評估這兩個方法是否適合自己。如果不適用，但又希望透過證券市場享受經濟成長帶來的好處，那麼最有效的方法就是資產配置，這可以適用不同風險承受力的家庭。資產配置另書討論，但本書仍應先閱讀，才有機會瞭解阿甘的魅力所在。
