# 每年10分鐘，讓你的薪水變活錢

幸福，都維繫在這裡，股價可以一日看三回，但保健的知識卻彷彿是醫生的事，你說，我們聰明在哪裡？

有人說，健康彷彿是銀行存款中的第一個數字，第一個數字不見了，後面再多的零也沒有意義，以下這幾本保健的書，我建議你優先閱讀，它帶給你的財富絕對不會輸給你現在書架上的財經書籍。這些書有營養學家、養生達人、不同科別的醫師，但都願意從比較整體和生活性的面向告訴你如何養生。

推薦書單

+   1. 《你吃對營養了嗎？》，作者吳映蓉。
2. 《真原醫》，作者楊定一。
3. 《吃錯了，當然會生病！》，作者陳俊旭。
4. 《哈佛醫師養生法》，作者許瑞云。
5. 《每天清除癌細胞》，作者陳月卿。
6. 《不生病的生活》，作者新谷弘實。
7. 《醫生不是天使》，作者黃崑巖。
8. 《別讓不懂營養學的醫生害了你》，作者雷·斯丹。
9. 《帶醫師回家》榮總醫師合著，潘懷宗策劃，及潘教授系列書籍。
