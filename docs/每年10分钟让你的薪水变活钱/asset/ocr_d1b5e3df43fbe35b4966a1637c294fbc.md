# 每年10分鐘，讓你的薪水變活錢

# 觀念一點通

+   1. 短期內要動用的錢，或不能承受任何一點虧損風險的投資，定期存款（CDs）是一個較安全的地方。

+   2. 如果可以承受風險或者中長期以上才可能動用的錢，股票的投資應該列入考慮。

+   3. 股票的特性之一，短期而言，就是價格的浮動性要比公債及定期存款來得大，但中長期而言，整個股市必定往成長的方向發展，所以，中長期的投資，不要因為短期的價格浮動，而不敢接近股市。

+   4. 從我工作上的接觸，我發現有許許多朋友，錯把自己所買的公債基金當成股票基金，這是兩個截然不同性質的投資，投資前有必要確切瞭解自己所購買的產品特性。

+   5. 退休帳戶（IRA或401K），在正常情形下，59歲半以後才可動用，有如此長的投資時間，最好是以股票或有一部分為投資工具，美國居民有所謂的個人退休帳戶IRA或公司提供的401K退休帳戶，資金可投資股市，最大的好處是這金額可免掉所得税，且在股市獲利也可暫不交税，遞延到
