# 健康的飲食和費用的節省

建議你有一個專屬的冰箱，再到大賣場採買食材，或許你可以將整個禮拜一定的量煮好之後分裝冷凍，前一天拿出冷藏，第二天早上只要很短的時間就可以打理好自己的早餐，比你在外面早餐店買的還要健康，而且省錢。
