# **解惑篇：為什麼我的退休金是別人的一半？**

股利，每家公司決定的高低不同，比率不定，如同蘋果公司長達二十幾年沒有發放股利，一直到2012年。道瓊和標普在不同年代有比率不同的股利發放，例如道瓊1980年大約有4%股利的水準，2000年後大約維持在2~3%之間，股利率是不固定的，台灣許多績優公司比美國發放的還高，大約在4~6%。

**公債**——是指政府或公司為籌措資金，憑其信譽按一定程序向投資者出具的承諾，在一定時期支付利息和到期償還本金的一種格式化的債權債務憑證。

**通貨膨脹**——指一般物價水準在某一時期，連續性的呈現上漲的狀態。

**ETF**——指數股票型基金，是一種在交易所上市交易的開放式證券投資基金產品，交易手續與股票完全相同。ETF管理的資產是一籃子股票組合，這一組合中的股票種類複製了某一特定指數，它的本質像基金，但交易的行為方式卻像股票，所以英文名稱是在「交易所買賣的基金」。
