# 每年10分鐘，讓你的薪水變活錢

賠錢的一方有機會反彈，台股、美股混搭的績效會比單一投資在台股好，第二個方案則是選擇1989年開始，因為1989年台股有驚人的88%漲幅，全部投資在台股，到2013年台股變成約34萬美元（台股的部分同樣沒有考慮股利的投入），美股則是投資在標普500（包含了股利），這二十五年美股成長到近230萬美元，台股美股兩者混合則變成了117.8萬美元。

以這兩個模式來看，台股美股混搭，確實有比單一投資在台股的風險分散，成效也比全部投入台股來得好，相當於有3~4倍的提升，所以值得進行，如果台股部分再以0050做上一個章節邱小姐和我、施先生的心得來做調整，績效還可以再提升。
