# 每年10分鐘，讓你的薪水變活錢

面向全球，台灣對境外投資有一定需求，除了代理外，應可培養我國對全球市場投資的操作人才，看台灣對境外基金代理和法規的設限，都感覺非常可惜，有人才、又有資金的台灣，卻沒有看到相對應的高度和格局，美國投資者光憑資金就可縱橫全球，台灣是不是可惜了自己手上的青冥寶劍，這些應該都可以透過法規鬆綁、操作的活化和創意的發揮有所改善和提升。

每每看到台灣人才濟濟，卻又動彈不得，那種惋惜，真是難以言表，但與其詛咒黑暗不如點燃蠟燭，我覺得自己可以做的就是從基層的教育開始，觀念的推廣，讓投資者手邊的錢可發揮功效，透過正確的投資方法，解開不敢行動的盲點，在簡單，安全，又有績效的原則下，進行投資，只要有獲利，必然會帶動母國的消費和繳稅。

我有一段時間也猶豫，並不希望台灣的資金外流，美國華爾街不缺台灣資金，但台灣的企業卻相對需要，其實這也是觀念上的盲點，經濟學者李勝彦指出，美國金融市場在全球化的程度之高，如在從2010年到2014年第二季美國的境外投資部位的GDP占比，由47.85％上升到57.56％，且逐年上漲，簡單的說，美國不僅利用了全世界的資源和人才，資金也大量投資全球有競爭的企業，進而分享這些成長，如台積電，就有高比率的外資，台積電的獲利和成功，美國投資者也能分享。
