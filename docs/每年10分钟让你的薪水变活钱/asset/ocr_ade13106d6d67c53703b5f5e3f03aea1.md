# 有錢人
致富的基本祕方

截至2014年8月底，你手邊的20萬美元，過去十年來是否成長1倍？或過去二十年來成長了6倍，達到123萬美元？或過去三十年成長了23倍，達到475萬美元？如果沒有，你應該瞭解本書介紹的這個簡單的投資工具，如果有，你的投資眼光的確不同凡響，但若你急需用錢，能在一天變現嗎？如果也有，你確有理財天分，但你能一年只花十分鐘做到嗎？

多數人都滿意上述的投資成果，也好奇的問，多高的投資報酬才可以產生這樣的投資成果？投資報酬複利在過去十年的是7.25％，二十年的是9.55％，三十年的是10.81％，這個數字會讓許多人訝異，原來年複利根本不需要20％，甚至15％的高報酬就可以致富，全世界長期超過十五年能交出20％的操盤手也沒有多少人，藉由過去三十年的數據呈現，成功的投資者應該學著打破新聞媒體聳動標題的陳述，只要有穩健約略10％的複利投資報酬，就可以輕鬆的致富，而且可以空出更多的時間和心思
