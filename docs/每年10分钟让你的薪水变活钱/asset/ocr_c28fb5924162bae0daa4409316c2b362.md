# 每年10分鐘，讓你的薪水變活錢

薄的利息也足夠支付各項開支，就算如此，適度和適量加入成長型的投資工具，例如房地產或股票，做到穩定中有成長（畢竟要考慮物價膨脹所造成的購買力下降），以及要能在成長中保有穩定，避免過度激烈的震盪，而造成投資者的卻步，不敢參與股市，喪失了參與經濟成長的機會。

台灣在固定收益方面的投資環境和產品完整性，不如美國，美國2013年底可以找到的二十年的政府公債利率是3.72%，而台灣知名公司所發行十五年的公司公債，利率大概在2.15%左右，固定收益的報酬率與美國有一個差距，讓我憂心和不捨的是，有許多仰賴固定收益的退休族，該如何改善？

+   1. 瞭解各種投資工具的優缺點和其限制，進而適時、適度、適量的混合及調整。2. 透過美國和全球連結，讓投資效益提升，財務的知識可以是一種力量，更可以創造財富。

公債和定存這種固定收益型的工具，看起來「短期」收益安全，但長期都會面臨通貨膨脹，造成物價購買力下降的威脅和衝擊，所以是短期安全，但長期卻有隱憂，甚至危險，特別是定存。股票投資短期劇烈波動，看起來危險，但長期反而安全（以後也會更深入觸及），這個現象值得深入瞭解。
