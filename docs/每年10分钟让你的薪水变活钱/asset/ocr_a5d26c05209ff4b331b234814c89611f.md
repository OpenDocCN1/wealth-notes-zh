# 讓全世界一流的企業家為你幹活

在股海裡航行了三十年，如果要有一句話可以真傳，我個人認為，在股市要能投資成功的本質就是要做到「讓全世界一群一流的企業家為你幹活」，而且在股海中有足夠的航行時間，你所能見到的奇景是未曾出海的人無法想像。

時間不停的堆積，資本不停的累積，一流企業不停地運轉，財富因此而創造，其實巴菲特也有相同的體悟，只是表達方式不同，巴菲特的名言：「找到雪球股，再找到足夠濕漉漉的長坡，讓它滾出一個大雪球的財富。」巴菲特的雪球跟長坡都是一個比喻，就算知道這個概念，可能還是不知道如何著手，那麼讓我告訴你哪邊有雪球和長坡，以及如何著手。

# 達到財務自由的尋寶圖

約三十年前，在美國當財務顧問時，看到了某家投資機構用圖表來呈現了一個投資觀念，仔細研讀，令我眼睛為之一亮，它就是引導我比許多人提早達到財務自由的尋寶地圖，這個圖表歸納了一個二十年的投資紀錄，背後其實就浮現出簡單卻又不簡單的投資理論和方法。
