# 每年10分鐘，讓你的薪水變活錢

數要比台股指數難以擊敗，這也是巴菲特過去十一年無法擊敗標普500的原因之一。

所以選擇標普500的指數基金，本身就是一個不錯的投資選擇，這也是我們這本書選用的投資標的之一，挑選這個選項，本身就是高手中的高手。

2014年標普500的成員有54家公司，包辦了世界一百大品牌的一半，不但名列美國之強，也是世界之最，如果還不能為投資者創造利潤，其他的指數基金就更困難。

就拿各個國家的指數基金來相比，標普500的安全性高，相對的恢復性也高，就算指數掉下來，在一定時間內也都會彈回去，所以符合安全投資的考量。

從歷史來看，它的中長期報酬也相對的亮麗，更重要的是它也符合了本書強調的，投資方法簡單，但績效不簡單，空出的時間得以經營人生其他更重要的財富，例如健康、親情、友情、心靈等，符合人生財富的平衡追求。

以下是標普500成員中被選為2013年全球一百大品牌的公司，這些公司不只是以美國為根據地，還以全世界為市場，利用它的研發、技術或品牌，為它的投資者攻城略地，創造財富，這樣的公司你怎麼能不心動、不考慮呢？
