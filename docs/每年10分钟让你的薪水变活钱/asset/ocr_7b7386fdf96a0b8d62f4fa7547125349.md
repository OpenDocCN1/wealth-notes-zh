# 每年10分鐘，讓你的薪水變活錢

投資者第一個想法，和他的投資風險承受能力。

但用心的專業人士也不應放棄，而應進一步帶領投資者有登高望遠的視野，給投資者寬度和深度的延展，讓他進入第二個層面，例如更清楚的瞭解投資世界過去的歷史，未來可能的變化，和在人生不同的階段，應選擇不同的投資工具和適度風險承受，來因應未來的衝擊。簡單的說，瞭解過去的歷史和進一步的理財教育，常有助於找尋到投資者真正和他恰當的風險承受範圍。

通常關心風險意味著投資安全性如何，而多數的投資者都同意風險與安全的相關性，因此我會問提問者：「所謂的安全意味著短期的波動和本金的不可以損失，對嗎？」多數人都會有這樣的期望。

接著我再問：「長期購買力下降的風險，你關心嗎？」幾乎每一個人一定都會點頭表示同意。第三個問題是：「短期價格波動的風險與長期購買力的風險，你更關心何者？」

上面三個提問是想開啟許多投資者以往可能沒有思考過的，在這樣的狀況下，如果未經思考而錯用投資工具也就不足為奇。長期的投資目標卻用短期的投資工具來應對，投資的結局當然往往不理想，就如同美東到美西，北京到上海，台北到台東，飛機若遇空難倖存的機會最小，所以走路最安全，可是多數人不會選擇用步行的方式，因
