
# 禁得起考驗證的投資理念

好的投資理念，不是在太平盛世或風平浪靜時才行得通，最重要的測試點其實是在股災來臨時，最好是重大的股災，才是最好的測試期。第二代的老張經過了石油危機的測試過關，隨著時間的推移，第三代老張面臨最大的考驗，也就是多數人都還記憶猶新的2000年開始的高科技泡沫，以及2008年突如其來的金融海嘯，第三代老張能禁得起這麼殘酷的兩次重大考驗嗎？如果是，這個投資理念，絕對值得你注意，我們往下看。

## 2000年網路泡沫加2008年金融海嘯衝擊

第三代老王從1994年開始，由於利率下降，只能找到6.48％的二十年政府公債，但第三代的老王還是滿意每一年有12,960美元的安全固定的收入（200,000美元×6.48％）。

至於老張投資的是美股標普500的指數基金，沒有利息，但有股利，這幾年標普500的股利大約在2-3%左右，老張也在1994年同一天投資了20萬美元，但老張每一年領取帳戶資產的5%做為一些開支的補助，比率是固定的，金額不固定，隨著每年帳戶年底成績的高低而變動。

例如1994年領取1萬美元（200,000美元×5%），1998年因標普500指數的上升，5%金額可以領取19,330美元，因高科技泡沫，2003年領取的金額下降為14,426美元，但金融海嘯過後2013年，可以領取的金額回升到17,563美元，隨著標普500指數的成長，以及股利的增加，老張這二十一年一共從帳戶領出了350,614美元，這來自於股利和股票的成長，不同於老王的公債是利息的收入，二十年後的同一天，老張的帳戶金額累計到447,470美元（計算見表2-5）。

# 三代老王的績效

先讓我們看看三代老王的成效，這三代老王在做決定的那一剎那，他們的觀點都是一致的，本金不能損失，且有一個不錯的利息收入，但這個看似安全每年有固定收益的投資，要提醒的是：

1. 通貨膨脹有侵蝕購買力的隱憂，二十年前，老王在1994年每年得到的12,960美元利息能購買的東西，經過通貨膨脹，造成購買力的下跌，二十年後也就是2013年，同樣的東西必須用20,715美元才能買到（反映通貨膨脹相同購買力）。
2. 更令人擔心的是，這些年美國二十年政府公債的利率節節下降，2013年結束之後，老王如果還想續約下一個二十年的美國政府公債，在2013年利率市場的環境下，只能找到3.72%的利率，也就是20萬美元本金歸還以後，重新購買的政府公債的利息減少了，得到的利息只有7,440美元（200,000美元×3.72%），比二十年前的12,960美元下降許多。

老王確實被保證收得到利息，本金到期歸還，但與二十年前相比，不但是利息收入損失了42%，再加上通貨膨脹造成幣值購買力下降37%，這兩個雙重打擊，使得當年看起來安全萬無一失的投資一點也不安全。

## 三代老張的投資績效

老張夫婦可以開懷，主要是做對了投資的決策，老張夫婦明瞭股票的投資可能上下的劇烈震盪，特別是美國經歷了兩次股災，2000-2002年高科技泡沫股市重挫50%，納斯達克狂瀉78%，2008年的金融海嘯為百年罕見，標普500指數也再度重挫50%，這十年的兩次超級風暴，股票的投資報酬幾乎沒有成長，但是：

1. 2000-2009年，美股過去十年幾乎沒有成長，所以老張這段期間帳戶幾乎停滯不動，相對於老王的投資，每一年不管股市是否有波動，都收取6.48%的利息，兩相對照，看起來老王的投資報酬會較高但其實不然（見表2-4），時間一拉長到二十年，可以很明顯看到，從第一代到第三代的老張，所有投資成績都優於老王的公債表現。

2. 為什麼老張從第一代到第三代的投資績效都優於老王呢？因為過去美國兩百年的歷史紀錄一再顯示，經濟的發展會推升股市的攀升，可以在說在美國股市，投資者享受了經濟的成長，這才是參與股市的真正意義。

投資美股，短時間也可能會產生虧損，例如2000-2009年這段美國失落的十年，就是一個非常黯淡的投資期，如果沒有一個較高的視野和對股市歷史的瞭解，許多投資者就會在轉彎的關鍵時刻，被股市的震盪給甩了出去，也就無法修成正果。

表2-5所標示的框框部分，是兩次重大股災大幅震盪的結果，現在事過境遷再回頭看，是歷歷在目，然而在股災的當下，絕對有許多人看不到曙光而在低點殺出，這是因為不瞭解股票市場的特性，投資者應該自我評估最恰當的風險承受能力。如果沒有專業的協助，請利用我們所附上的計算圖表，帳戶金額的變動可以幫助投資者瞭解股災震盪起伏的程度。

如果過去兩次股災如此激烈的震盪超過自己的承受能力，那麼再好的投資成果也無法享受，這時就應該考慮資產配置這種波動風險較小的投資方式，後續我們也會來檢驗第四代最倒楣的老張，假設從2000年高科技泡沫進場到2019年，和同期的老王相比，這二十年的投資成績差距有多少，這個二十年的投資競賽答案要到2019年的時候才能揭曉。

2000-2014年，過去這十五年碰到公債的大多頭，相反的，是美股的大空頭，所以老王這次應該有機會獲勝，這也是這幾年公債市場受到矚目，較多人參與投資的原因之一，但正因如此，從長遠的角度來看，反而更應該注意鐘擺理論的現象（見後面章節），也就是任何投資最終都是要回到它的歷史平均合理範圍，過去公債十五年的領先成績，還能夠持續多久，是一個值得關注的有趣話題，如何應變和調整，更是一個成功投資者不可忽視的，接下來的章節，我們會有這方面的討論。

# 公債與股票的交叉組合運用

以上是用公債和股票對比的例子來說明，但千萬不要誤解，以為公債是不好的投資工具，其實如果懂得搭配和運用公債，不但可以降低投資組合波動的風險，如果還能懂得在適時關鍵時機做一些調整，公債可以發揮後援部隊奇襲的功效。

用這麼極端的兩個不同工具作對比，一方面在提醒，任何年齡的退休族，都不應「只有」固定收益型的投資工具，例如定存、公債等，除非本身資產已夠龐大，只有微薄的利息也足夠支付各項開支，就算如此，適度和適量加入成長型的投資工具，例如房地產或股票，做到穩定中有成長（畢竟要考慮物價膨脹所造成的購買力下降），以及要能在成長中保有穩定，避免過度激烈的震盪，而造成投資者的卻步，不敢參與股市，喪失了參與經濟成長的機會。

台灣在固定收益方面的投資環境和產品完整性，不如美國，美國2013年底可以找到的二十年的政府公債利率是3.72%，而台灣知名公司所發行十五年的公司公債，利率大概在2.15%左右，固定收益的報酬率與美國有一個差距，讓我憂心和不捨的是，有許多仰賴固定收益的退休族，該如何改善？

1. 瞭解各種投資工具的優缺點和其限制，進而適時、適度、適量的混合及調整。
2. 透過美國和全球連結，讓投資效益提升，財務的知識可以是一種力量，更可以創造財富。

公債和定存這種固定收益型的工具，看起來「短期」收益安全，但長期都會面臨通貨膨脹，造成物價購買力下降的威脅和衝擊，所以是短期安全，但長期卻有隱憂，甚至危險，特別是定存。股票投資短期劇烈波動，看起來危險，但長期反而安全（以後也會更深入觸及），這個現象值得深入瞭解。

# 股災下的危機應變

關於第四代的老張老王數據演算，我們刻意選擇2000年開始，因為這是美國歷史上少數慘重的失落十年，就算加入了股利，這十年幾乎都沒有成長，又碰到公債的大多頭，所以在這麼困難的情況下，再來看看股市的投資是否禁得起考驗，也有特別的價值。(多數人都聽過美國1929年開始的經濟大恐慌，事實上股票的大跌是在1930年代，從1930-1939年，是一個悲慘的十年，而2000-2009年其實完全類似，這十年股災相當嚴重。)

近十五年當中，老王在2000年找到的二十年公債利率是6.86%，所以每一年可以領到13,720美元的利息，截至2014年12月31日為止，十五年的期間一共拿了20萬美元左右的利息，假設本金20萬美元如數領回沒有虧損。

經過兩次重大股災受傷的老張，目前看起來是落後，以每一年領取5%帳戶金額計算，一共領回了10萬美元多一點，截止同樣的時間點，帳戶金額是175,457美元（見表2-7），所以這次老王在二十年的競賽中，總算有一次領先的機會，但是球賽還沒結束，未來的五年，公債還會持續領先嗎？沒人能知道，但歷史數據顯示，股市的成績長期以來優於公債，如果這個趨勢正確不變，未來的投資可能就要做一些轉向和調整。

# 股債優勢大翻轉

從這代的例子觀察，如果長期的歷史數據顯示股票優於公債的歷史趨勢不變，2012-2014年標普500投資報酬分別是15.89%、32.15%、13.48%，而美國十年公債的報酬率分別為2.97%、-9.10%、10.75%。而2013年巴克萊公債投資報酬是虧損的，這是不是開始透露出反轉的訊號呢？值得玩味。

美國的貨幣寬鬆（QE）政策已結束，如果美國失業率能持續下降，經濟持續復甦，美元趨勢就有走強的條件，同時利率也可能會調升，在那樣情況下，過去十幾年公債的多頭狀況可能就要暫停。

就算第四代老張落後了老王投資表現，但因過去2000-2009年是一個非常特殊的十年，老張在標普500這種指數型的基金投資短期未必優於公債，但長期而言，股市的報酬領先幅度還是大於公債，只是幅度的大小而已。從第一代老張領先將3倍，第二代領先1.5倍，第三代領先近1倍，這樣的成績來看，參與美股這種有成長性的投資工具，絕對有其列入投資組合的必要，至於多少的比例，如何適時、適度、適量，因不同的家庭狀況，而有不同考量，使用得好，即可降低波動的震盪和投資風險，進而達到最適合個人的財務需求。
