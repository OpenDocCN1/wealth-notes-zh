# 每年10分鐘，讓你的薪水變活錢

富達（Fidelity）、嘉信（Charles Schwab）、TD（TD Ameritrade）。

這三家中以嘉信比較注重開發華人市場，也是股票上市公司，算是老字號，原本交易費用要比其他證券行高，但這幾年都已經下降，內部控管可能做得最嚴謹，到目前為止，都還要求W-8（美國人處理稅務上的問題，要填W-9，提供報稅用的社會安全號碼，相當於台灣的身分證號碼，而W-8就是給非美國居民使用，這是正式表格，告知你是外國人，得以免資資本利得稅。）必須原稿郵寄，任何一點小差錯都會被要求重新再來，其他證券行都已 可以接受掃描或網上填寫，嘉信在這方面的控管非常嚴謹。其他兩家因為沒有中文界面的網頁，所以我們就不列為推薦，但有英文能力閱讀者不在此限。

史考特（Scottrade）是這幾年的後起之秀，先以低價搶攻市場，最近也開發了財務顧問的交易平台，在某些方面和嘉信是競爭者，但有趣的是，它的共同基金交易作業是透過嘉信，所以是既競爭又合作。

億創（E-Trade）在亞洲的總部設在香港，其他三家公司則是設在美國，也是股票上市公司，億創在金融風暴期間受創嚴重，對資金的需求會比較急切，所以有時也會提供一下促銷活動，來吸引投資者的資金入注。
