# 筆者失敗和成功的故事

1987年在美企研所畢業，當大家準備展翅高飛時，我的屁股上卻寫了兩個大字「負債」，還是幾乎可以念5個學位的負債，彷彿一隻翅膀受傷的小鳥，飛不起，還往下墜。但多年前，我比預期的還提早達到財務自由，現在心嚮往之的，就像某企業家所說，為理想奮鬥耐風寒，為興趣工作永不倦怠，任何人逆轉勝的寶貴經驗，都有可以借重和參考的地方，我應該也不例外。
