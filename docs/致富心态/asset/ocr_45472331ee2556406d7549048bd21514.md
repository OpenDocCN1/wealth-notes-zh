# 投資決策。

但實際上人們並不會這麼做。

兩位經濟學家發現，人們一生的投資決策會大幅奠定在他們那個世代投資人所擁有的經驗，特別是他們剛成年時的經驗。

倘若是在高通膨時期長大，和那些在低通膨時期長大的人比起來，往後投資在債券的比重會比較低；假使你的成長期間剛好弱達股市強勁走勢，與那些在股市疲軟時期長大的人比起來，往後投入股市的資金會比較多。

這兩位經濟學家寫道：「我們的發現顯示，散戶承擔風險的意願，取決於個人的人生歷程。」

這與智力、受過的教育或性格的老練與否無關，就看你有沒有在對的時間、對的地方成長的好運氣。
