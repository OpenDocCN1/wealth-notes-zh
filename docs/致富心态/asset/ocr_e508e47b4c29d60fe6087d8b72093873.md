# 美國消費者的養成之路

如果想了解現代消費者的心裡，並掌握他們下一步的前進方向，就得先知 道他們怎麼走到這個地步。

他們又是怎麼走到這個地步。

倘若你在 一九四五 年沉睡，醒來已經是二○○○年，你會完全 不認得周遭的世界。
