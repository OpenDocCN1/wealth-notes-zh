# 我

和一個朋友一起長大，他既非權貴，也非天才，卻是我認識最勤奮的人。這樣的人可以提供許多寶貴的經驗，因為他們可是一步一腳印的走完成功之路。

他在青少年時就已經立下當醫師的人生使命與夢想。如果說形勢對他不利其實都是很婉轉的說法，當時理性的人都不看好他有可能會實現夢想。

但是他奮發向上。而且雖然比同班同學晚了十年，終完成功穿上白袍。

從兩手空空起步，一路過關斬將，最後登上醫學院的頂峰，進入最崇高的行業，應該有很大的成就感吧。

幾年前我和他聊天，對話大概是這樣：

+   我：「好久沒聯絡了！你過得如何？」

+   他：「這一行爛透了。」

+   我：「哈哈，這個嘛……」

+   他：「老兄，這一行爛透了。」
