# 致謝

就像所有書籍一樣，《致富心態》一路上若是少了無數人士助我一臂之力，就不可能有付梓之日。我想一一列舉的名字多不勝數，只好在此列出幾位特別鼎力相助的人士：

+   布萊恩·理查茲（Brian Richards），他是第一個打賭我辦得到的人。
克雷格·夏皮洛（Craig Shapiro），儘管他不必打賭我辦得到，卻仍願意看好我。
葛蕾琴·豪瑟（Gretchen Housel），她始終堅定不移的支持我。
珍娜·阿布杜（Jenna Aboud），她提供協助，不求回報。
克雷格·皮爾斯（Craig Pearce），他鼓勵、指導並提供我基礎訓練。
