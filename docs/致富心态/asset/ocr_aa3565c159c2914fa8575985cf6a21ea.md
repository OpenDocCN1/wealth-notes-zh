# 每

個事物都有價格，與金錢有關的很多事情中，關鍵就是找出標價，並心甘情願付錢。

問題在於，許多事物的標價並不明顯，除非你有第一手經歷，但到了那時，帳單往往已經到期。

二〇一四年，奇異是全球最大的企業，市值超過三千三百億美元。近十年來，它每年都在第一、二名之間升降，是資本主義下頂尖企業裡超閃亮的巨星。

然後，一切徹底崩裂。

二〇一八年的金融危機把奇異旗下貢獻全集團超過一半獲利的財務部門推入火坑，最終還像廢棄物一樣被賣掉；隨後它押注的原油與能源都變成災難，導致最後得註銷幾十億美元的虧損。奇異的股價從二〇一七年的四十美元跌至二〇一八年的七美元。

各界的譴責全都猛烈的直接對準二〇一一年接班的執行長傑夫．伊梅特（Jeff Immelt），大肆批評他的領導能力、購併決定、裁撤事業單位與裁員的做法，當然也包括一落千丈的股價。本因如此，在景氣大好的時候，紅利隨著盛世財富而來，一旦熱潮
