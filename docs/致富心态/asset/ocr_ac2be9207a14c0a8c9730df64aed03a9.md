# 〇一九

一年去世的先鋒集團（ Vanguard ）創辦人約翰・伯格（ John Bogle ）說過一則與金錢有關的故事，凸顯我們未曾深思的重要意涵：

一名億萬富豪在美國紐約州的雪特島（ Shetler Island ）舉辦一場派對，寇特・馮內果（ Kurt Vonnegut ）對友人約瑟夫・海勒（ Joseph Heller ）說，派對主人是一位避險基金經理人，一天就能賺很多錢，遠比海勒廣受歡迎的小說《第二十二條軍規》（ Catch-22 ）至今貢獻的版稅還高。海勒回答：「是這樣沒錯，不過我擁有一樣他絕對沒有的寶物：……那就是滿足感。」

滿足感，這三個簡單的字讓我震驚，有兩個理由：首先，因為我這輩子一向是要什麼有什麼；再者，因為沒有什麼看法比約瑟夫・海勒的話還精確。滿足感是我們社會的關鍵要素，包括許多最富裕、最有權勢的人在內，現在看來它指涉的範圍似乎無邊無際。

它如此精明、如此強大。

請讓我舉兩個因為貪得無厭招致危險的例子，並闡述它們帶來的教訓。
