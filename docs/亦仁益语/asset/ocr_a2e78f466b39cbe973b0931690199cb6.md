# 02 普通人真的能赚到钱吗？

从 2017 年年初在知识星球平台按下「创建星球」按钮之后，生财有术就一直说要帮助普通人赚钱。

但我能力有限，高阶的赚钱选手已经很强，我和我的团队其实不太能帮得到他们；不过，帮助更多的普通人，实现他们第一桶金的突破，我们能帮上很多。而这不管是对个人还是一个家庭的影响，都会让我们有成就感，也是我们继续做下去的力量来源。

那么，普通人真的能赚到钱吗？（我们定义赚 50 万以上算赚到）

如果你已经在生财有术待了一年，我相信，你一定很确定，这个答案是肯定的。

当然，这个「普通人」还是要打个引号的。不是中国的所有人都有机会。但是，这篇文章能够传播到你这边，说明你已经具备了赚到钱的、基础的信息渠道和能力。

过去几年，我观察过、接触过、深度沟通过上千位年收入在百万以上的圈友，我没有碰到过天才，接触下来，都是真正的普通人。
