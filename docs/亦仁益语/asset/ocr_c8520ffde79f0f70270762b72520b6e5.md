# 2. 尽可能让自己开心一点。

短短人生，不过百年。

在时间的历史长河中，人类其实没有什么特别的意义，只是尘埃而已。

不管你怎么过这一生，终了之时，看回去，你会发现那些痛苦、纠结、崩溃的时刻，也就如此。

既然人生这一辈子都没什么意义，那就活的开心点啰。

多顺着自己一点，对自己好一点，让自己开心一点，哪怕很多时候，别人觉得你是个人自私的人。

想那么多干嘛，开心最重要，follow your heart。

# 3. 多认识一些乐观的、大格局的、相信长期主义的朋友。

每个人，都会最终在自己的认知圈子里面转来转去，直到有人来点醒你。

乐观的、大格局的、相信长期主义的朋友，就是这样会经常来点醒你的人。

多结交这样的朋友，然后足够主动，对他们好，珍惜他们，时间会回报你。不回报也没关系，交个朋友。
