WordPress 有这样一个插件，可以自动找到该博客下其他相关的文章，根据标签或者类别进行推荐，提升老文章的阅读量，那么对于公众号，这样的插件时候可能存在呢？基于小程序为公众号赋能。

# 15、微信群发红包请转发如何让效果最大化？

如果你写公众号文章，一定遇到过这样的场景，丢了一个红包到微信群，请大家帮忙转发，结果红包没了，转发也没有，很尴尬，但没撤。基于红包+场景的小程序仍然有非常多的机会，包你说笑了，包你拆笑了，红包+求转发的场景呢？红包+投票的场景呢？红包+刷阅读的场景呢？红包加问答的场景呢？

# 16、如何将文章转成海报方便传播？

图片天生对人的吸引力大于文字，分享一篇afka文章到朋友圈与分享一张图片到朋友圈，吸引到的注意力也是不一样的，将文章很方便的生成一张海报，或者是一张词云，配上评论，分享到朋友圈，一定会很酷吧。"套慕打码"小程序在这个需求上捷足先登，不过还有更多的场景和机会，期待挖掘。

# 17、如何将写好的文章一键同步到其他十几个自媒体平台？

一键同步多发是一个很古老的需求了，并不是什么新鲜的事情，包括新榜也做了类似的产品。前段时间与朋友聊天，还听说在房地产行业，针对垂直网站定一键制同步发布到多个网站，年入千万的故事。
