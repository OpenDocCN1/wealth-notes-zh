# 《生财有术运营思考》

# 1.删帖规则

2017-03-24 10:21

+   1. 目的是为了圈子内分享的内容噪音较少。
2. 暂时未设定其他管理员，删帖的原则是
   a. 一句介绍、无背景、无经历等，如大家好，我是亦仁，很高兴见到大家，这将会被删。
   b. 黑产相关信息会被删，违法法律的内容会被删。
   c. 大而空的问题会被删，如请问有没有像今日头条，怎么通过自媒体赚钱，提问之前请先搜索，能搜索到的东西不同别人是个非常好的习惯。当然付费提问另外说了。
   d. 太没价值的信息会被删，如现在内容创业是个好机会，大家赶紧做。
   e. 删帖不另做通知，如有疑问，请参考删帖规则。
3. 如有其他规则更新会再发布。
