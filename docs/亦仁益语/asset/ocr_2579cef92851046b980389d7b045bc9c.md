# 7. 不要在短期的事情上想长期的意义

短期的事情不是没有意义，但在短期 的事情上去想竞争 力、护城河、战略就没有什 么意义了。

什么是短期的事情？

搬运，套利，无货源、无人直播，垃圾内容，薅羊毛，平台漏洞，对抗规则。

如果你将整个商业模式架构在短期 的事情上，总有一天会塌陷。

# 8. 简单复制就可以有收入的已经被高手干完了，只有要动点脑的项目

简单可复制可赚钱，交钱跟着学习就行。

这样的项目，只会出现在招商副业的文案中。

剩下的，都是需要动脑的项目，正是因为有一些问题需要动脑解决，才留下了赚 钱的机会。

否则钱早就被资金更多、团队更强、执行力更强的人赚完了。
