# 第九章 别急着当“最狠的人”：真正的长期赢家，常把蛋糕做大

马可·奥勒留打过一个很妙的比方：有人帮完忙就盼着回礼，有人嘴上不提却把人情记成账；还有一种人像葡萄藤，结出果实不是为了交换，帮完别人便转身去忙自己的事。前两种当然常见，但第三种，才是更值得学的姿态。

先看一个反差极大的故事。主人公叫德里克，是个化名。他体格强壮，做过大学联赛里的核心球员，也打过职业比赛；伤病终结运动生涯后，他转去做合同谈判，专门和运动员、经纪人掰手腕。为了练本事，他还去顶尖商学院上谈判课，在角色演练里一会儿扮药企高管收购工厂，一会儿扮开发商和木匠争条件。

有一次模拟谈判，四位渔民因竞争过度、鱼资源枯竭而坐到一起商量。大家议定：两人按约把捕捞量减半；第三位让得更狠，砍掉65%；德里克却一点没减，反而能捞多少捞多少。会前他收益垫底，会后却冲到最前面——利润比那位最克制的同伴高七成，比另外两人高三成。别人质问，他直说：我要强硬谈判，击垮对手。

后来他在职业球队里也这么干。看中一名小联盟球员后，他和经纪人谈合同，照旧先压一个极低价。经纪人又气又急，说同类球员拿得更多，指责他欺负人，可德里克不为所动，最后对方还是让步了。按说这是一场“胜利”，替球队省了几千美元。可那天回家，他心里不踏实：对方离开时明显带着怨气，也许自己谈判时根本没认真听。

于是，他推翻刚谈成的低价，按经纪人最初的要价补上几千美元。乍看这不聪明：钱是球队的，交易已结束，目标也达成了，反悔图什么？但这件事比表面聪明得多。范德堡大学的布鲁斯·巴里和雷·弗里德曼研究发现，当谈判双方都聪明时，共同收益最高；更反直觉的是，最聪明的谈判者往往给对手争取到更好的结果。因为他们更懂对方在意什么，能提出对自己成本不高、对对方却很有价值的方案。德里克多付的那几千美元，对球队不过九牛一毛，对球员和经纪人却意义不小。这是利他，也是自利。

那他为什么转向？谈判课结束时，同学投票评奖。最佳合作、最佳创意、最佳道德，德里克一票没得；唯独“最冷酷无情奖”，他压倒性胜出。更尴尬的是，另一门谈判课的学生很多根本没和他面对面，只凭流传的名声，也把奖投给了他。那一刻他开始反思：靠获取短期确实有收益，但人际关系和声誉的账，迟早要还。向经纪人让利，反而建立了善意；后来对方遇到自由球员，会主动打电话告诉他。回头再看，他庆幸自己那样做了。

不过，作者并不认为这叫“成熟”。成熟像是线性成长；德里克更像从谈判桌边退半步，把生活里早就有的原则搬进新场景。他原本就乐于帮同事、指导年轻运动员，从小学到大学常被选为队长，甚至新人时期就当了职业队队长，习惯把团队利益摆在自己前面。场上他想赢，场下却愿意帮对手收集运动员信息，分享知识，帮曾在队里的球员做更好决策。他不是突然换了价值观，而是有了自信和勇气，把旧价值观用在新领域。

这也解释了一个常被忽略的事实：成功阶梯顶端并非只有获取者。沃顿课堂上，学生大多认为付出者会掉到底端，顶端则属于互利者或获取者。可作者说，你们低估了付出者。持续付出又不设边界的人确实可能吃亏，但调整方式后，付出者同样能登顶。夏立安·普莱斯起初只肯匿名讲自己的付出者特质，后来发现公司里的职业模范几乎都是付出者，参照标准一变，她不再害怕，还发起行动鼓励付出者亮明身份。皮特·奥德特也是例子：他花几个小时开车帮一位看似穷困的废金属工人理财，对方其实很富有，后来带来大量业务；皮特还帮他推荐经理，三周后客户多年首次带妻子度假。帮助越多，他越成功，而他衡量成功的方式，是看自己为周围人带来了什么。

获取者把成功看成压过别人，互利者追求成就与公平的平衡，付出者则把积极影响他人也计入个人成就。若组织在招聘、评估、奖励和晋升时，不只看个人产出，也看这种产出能否带动他人，成功的内涵就会被拓宽。创业者亚当·芮福金、风投人戴维·霍尼克、编剧乔治·迈耶、教师C·J·斯肯德尔和康利·卡拉汉、护理销售领域的吉尔戴尔·埃斯科托与南希·菲尔普斯、咨询领域的贾森·盖勒与莉莉安·鲍尔，乃至林肯，都说明同一件事：付出者可以既成就自己，也托举别人。获取者扎堆时，成功像零和游戏；付出者聚在一起，整体往往大于部分之和。

当然，策略性地“先帮人、再求回报”也有风险。行为会泄露动机，接受者一旦怀疑你另有所图，感激就会打折，其他互利者也可能不愿配合，甚至传播负面评价。更稳妥的做法是：用自己舒服的方式，去帮那些你真正重视其福祉的人；即便没有即时回报，也先像付出者那样行动。久而久之，反复的选择会让人长出付出者的身份认同。

我们大半时间都在工作，工作也在塑造我们是谁。若把付出只留在私生活，职业里就少了很多可能。哪怕只向付出者的一端轻轻倾斜，也可能换来更大的成功、更重的意义和更久的影响。别等到被贴上“最冷酷无情”的标签才改变——把蛋糕做大，远比抢一块蛋糕更划算。
