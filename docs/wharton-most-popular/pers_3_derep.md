# 第二章 可信性，比话术更致命的说服地基

你有没有发现一个很奇怪的现象：同样一句话，从不同的人嘴里说出来，分量完全不一样。

有人开口你就想关掉页面，有人开口你就愿意往下听。

差别在哪里？不在嗓门，不在话术，而在三个字：可信性。

今天这篇，就专门聊聊：凭什么让别人相信你，以及为什么这件事，比你想象中更致命。

一、从亚里士多德说起

时间拉回公元前367年。一个年轻人走进雅典的柏拉图学院，他就是亚里士多德。他特别喜欢他的老师柏拉图，也真心认同老师很多理念。但他最终没有全盘接受柏拉图的思想——因为柏拉图谈的是理想国、是幸福的抽象原理，而亚里士多德这个人，太务实了。他关心的是逻辑、修辞、政治，是现实社会里怎么把人说动、把事做成。

公元前350年，亚里士多德开始公开讲授修辞学。他把说服力拆成了三个基本要素：个人特质、情感、逻辑。翻译得直白一点就是：你是谁、你怎么打动我、你怎么证明你说得对。

今天我们要拆开的，就是这三个要素里的第一个——个人特质。它是说服的地基。地基如果不稳，后面盖什么都是危楼。

二、个人信誉：靠时间一点一点攒

个人特质这件事，听起来很玄妙，其实拆开无非三个东西：能力、诚信、专业知识。

先说能力。能力是你干出来的——你做成过什么事，你解决过什么问题，你在某个领域有没有拿得出手的战绩。这些不会凭空出现，它们是日积月累的。而且有个很有意思的规律：信你的人越多，你的能力就越被放大。

再说诚信。诚信不是装出来的一次好人，而是长期稳定的一致性——你是什么样的人，和你表现出来的是什么样，这两者必须统一。

“真诚”这个词很有意思。它的拉丁语词源是“没有上蜡”。古罗马时期有个习俗：雕塑家用蜡来填补雕像上的瑕疵，让作品看起来完美无瑕。所以“没有上蜡”的意思就是：你没有用蜡填坑，你没有掩盖缺陷，你是真材实料。

但请注意：个人信誉有一个极其残酷的属性——它积累得极慢，碎得极快。考验永远不是“你能不能一直证明自己”，而是“你一次没证明住，之前的账还作不作数”。

2009年，AIG——美国国际集团，一个花了90年时间做到全球最大保险公司的巨头，因为一个动作就把自己的信誉打了个稀碎。

金融危机来了。美国政府用纳税人的钱，给AIG提供了850亿美元的紧急贷款。结果呢？拿到贷款不到一星期，这家公司就跑去加州一家豪华度假村开商务会议。8天，烧掉50多万美元。水疗24000，高尔夫7000，宴会将近15万。

纳税人的愤怒是可以想象的：我们刚用血汗钱救了你的命，你就这么挥霍？

AIG也委屈：这场会议在拿贷款之前就订好了。而且行业里都是这么干的。就算退一万步，这笔费用在商业上未必不合理。

但一所有名商学院的教授，道破了这件事的本质——他说：“公司的行为在绝对上是否正确，根本不重要。真正的问题在于，公众觉得这件事是错的。这已经是一个认知问题，而不是事实问题。”

AIG用90年攒下的信誉，最终为了一周的度假付了代价。一旦你给人的感受是“言行不一”，后面你说什么，都是辩解。

三、被证明可信的信誉：借来的光环

那如果没有个人信誉积累，就没机会了吗？也不是。还有第二条路：用专业知识来补。

什么叫被证明可信的信誉？简单说，就是你的底气和依据，来自已经被验证过的权威。

比如你买车不知道选哪款，你是相信一个经验丰富、有资质认证的机械工程师，还是相信你家水管工？答案不言自明。

再比如这两句话，你更信哪个？——“好像今年工作比去年好找了一点。”或者：“根据《纽约时报》的报道，今年的失业率比去年同期有所下降。”

第二句话，你靠的不是自己的判断力，而是《纽约时报》长期积累的公信力。那个公信力被“借”给了你。

当然借钱要有好征信。如果你拿《国家调查者》这类八卦小报当论据来源，那就不但借不到信任，还会把自己搭进去。

四、最大的障碍：竞争和无知

你可能以为，现在信息更透明了，建立信誉更容易了。恰恰相反，现在比过去难多了。

首先，每个普通人都能发声。人人都是话筒的时代，人人都在争夺注意力——真正的问题不是“你怎么开口”，而是“凭什么是你”。竞争者太多，突围很难。

其次，人们都变聪明了，或者说，变警惕了。2009年皮尤调查中心有一个数据：多数受访者认为新闻报道不准确、新闻节目带有政治偏见。媒体公信力跌到了20年来的最低谷。大家看什么都先问一句：这是不是又有什么立场？

更让人愣住的是：调查显示，只有不到一半的高中生能判断一个网站是客观还是带偏见的。

如果越来越多的人缺乏辨别能力，那“信誉”这个词在未来会被稀释成什么？如果大家连什么权威、什么胡说都分不出来，说服就无从谈起。

一位说服力领域的专家杰伊·康格尔说得很直白：不管哪种信誉，都可以建立，也必须建立。否则，后面所有说服步骤，全是空转。

五、怎么把信誉用起来：不是所有时候都要自夸

但在动手“攒信誉”之前，你需要知道一个更大的前提，这也是很多人对信誉最大的误解：

信誉不是必须挂在嘴上说出来的。信誉在的时候，你甚至不需要提它。

比如美国总统发表政策演说，不会先花三分钟介绍“我是美国总统，我有丰富执政经验”——所有人都知道。那个身份和信誉就立在那里，不需要重复占用注意力。

但反过来也要谨慎：在某一个领域的信誉，不能随便迁移到另外一个领域。

举个我遇到过的例子：一位销售代表，在很多客户那里已经建立了不错的个人信誉。新品上市的时候，他照样推不动。为什么？因为客户信的是过去的他，而新品是全新的领域——他必须有新产品相关的专业知识、新的可被验证的依据，才能续上原有的信任。

你看，信誉不是一座你建好就能躺一辈子的房子，而是一个越走越长的坡，你得一直往上推这块石头。

写在最后

你可能会问：为什么要费劲建立信誉？

一位叫桑迪·埃尔盖尔的作家在《培训与发展》杂志上写过这样一段话，我认为是这个问题最好回答：

“没有信誉，就没人相信你。没人相信你，你就无法说服任何人。不能说服任何人，你解决不了问题，创造不了价值，也带不动团队。到最后，你会变得无关紧要。”

2300多年里，亚里士多德给出的答案从来没有过时。今天的问题不是要不要相信它，而是——在今天这个每个人都能发声、但真正被信任的人越来越少的世界里，你拿什么让自己被听进去？

电影《真心英雄》里有句话是：“你有没有信誉，你自己心里清楚。”那是扮演黑帮老大说的。但也适合你，适合我，适合任何一个打算说点什么、做点什么、改变点什么的人。

最后回到那个买电视机的例子。丈夫想买一台新电视，但妻子并不急。他发现妻子的核心需求是“更好地招待亲戚、办家庭派对”。如果他想说服妻子接受他看好的型号，他有两条路：要么动用自己过去一贯靠谱的购物记录——这是个人信誉；要么好好做功课，翻阅《消费者报告》、查阅同情况消费者的真实评价、比对周末促销，然后把这些信息和依据拿出来——这就是被证明可信的信誉。

那么轮到你了：面对你的听众，你的信誉从哪来？是曾经做过靠谱决定的积累，还是手上握有真材实料的专业知识？你想好了吗？
