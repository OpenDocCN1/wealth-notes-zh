# 前言 任何人都能争取更多

有没有想过，谈判其实不是一场你输我赢的博弈，而是一种让生活变得更好的能力？

这本畅销全球的书，从出版至今已经被翻译成26种语言，销量超过150万册。它想告诉你的核心观点很简单：无论你是什么性格、什么背景，都能通过学习成为更出色的谈判者，为自己争取更多——但不是不择手段地抢，而是稳步地改善生活。

作者用30多年教学经验证明，很多人对“谈判”的固有认知可能是错的。那些我们习惯依赖的理性分析、强硬姿态、抢占先机，甚至“双赢”口号，在现实里经常失灵。真正管用的恰恰是一些看起来不太符合直觉的方法，比如敏锐察觉情绪、建立真诚关系、设定清晰目标、一小步一小步推进、懂得判断时机。这些策略可能很“软”，却非常有效。

这本书里有大量真实故事，来自作者本人、他的学生、企业高管和各种职业背景的人。你会在别人的成功和挫折里，找到属于自己的谈判启发。

需要说明的是，这不是一碗盲目乐观的鸡汤。它提供的方法是实打实的工具，能帮你和最难缠的对手周旋，不会让场面失控，也不会让你吃亏。遇到敌意时，你可以不硬碰硬，而是看清对方情绪背后的真实需求，最终掌握主动。和喜欢对抗的人打交道，可以采取一种非对抗性的“以牙还牙”方式；在给出信任的同时，也守住自己的承诺。这不是软弱，而是真正能达成目标的智慧。

“争取更多”不是要抓住所有东西，而是追求持续而温和的进步，就像学一门课程或者一项运动。这些策略在商场、在家、在路上都适用。它是一整套思考方式，而不是一堆小技巧。每个人可以根据自己的性格和生活场景，灵活调整和使用。

当你能把这种模式内化成自己的习惯，谈判就会变成一次真诚的交流，而不是一场对抗。多方一起朝着共同的目标努力，所有人都能有所收获。作者在书中最常用的开场白是一句：“你还好吗？”想想看，这哪里是竞赛，分明是一种让人更从容、更自信地过日子的态度。

当然，不是每个策略都适合所有人。有些内容可能与你无关，但总有一些东西能为你所用。关键在于，去找到那些能给你和周围人增添价值的点，并且真正用起来。

如果你怀疑这些方法是否有效，不妨先在一个没有风险的小场景里试一试。书里的理念经过反复验证，符合人类心理学的基本原则，它们确实有用。不要一次性把所有招数都堆上去，挑几个试试，感受效果，再调整完善。这个过程会伴你一生。

不要只是纸上谈兵。把策略用出来，才能看到改变。如果你想分享自己的成功或困惑，作者和团队很乐意倾听，你可以通过 sd@gettingmore.com 或 www.gettingmore.com 联系他们。这本书欢迎每一个愿意用另一种视角看世界、愿意为自己争取更多的人。

你准备好，争取更多了吗？
