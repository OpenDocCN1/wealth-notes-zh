# 前言

Preface

你会发现身边有太多人状态像被多线程拉扯住：手机不离手、电脑一直开着，事情一件叠一件，目光很难在同一件事上停留超过几十秒。在这样的环境下，想要把信息讲清楚、讲进去，本来就难上加难。而现实是，分散注意力的干扰源比过去任何时期都多，越来越多的人在嘈杂中失焦，也让传递信息的人不得不寻找新的突破口。

正是基于这份普遍的沟通困境，《让松鼠聚焦：沃顿商学院最受欢迎的说服课》应运而生。书里既有可借鉴的理论框架，也有可以直接上手的实操方法。我们希望它能成为身处信息洪流中的人的一件实用装备，也能成为每一个渴望把沟通做得更具说服力的人的参考指南。

斯科特博士没有对注意力涣散的听众横加指责。她选择正视这个时代的常态，并把这份常态反向利用成表达者的筹码——一套兼顾信息复杂度与信息量的轻巧方法论。说到底，关键在于读懂听众，可这件事听起来简单，做起来却充满门槛。凭借多年的沟通研究与教学经验，斯科特博士拆解出一个操作门槛很低的抓手，亦即她提出的题目设定法，又被称作橡果策略 ACORN，用它来把听众的注意力稳稳收拢到核心信息上来。

她推崇的，并不是单向灌输式的表达，而更像一种基于常识的双向交流。真实的对话、彼此的互动，本身就是构建和传递有力信息的过程。她会带你练习如何找到与听众的交集，甚至是面对那些挑剔甚至尖锐的听众时也能找到共鸣点，让表达清晰、易懂、易接受。

我们与斯科特博士长期共事，深切感受到她在专业深度与教学热诚上的双重可贵。读完《让松鼠聚焦：沃顿商学院最受欢迎的说服课》，你会发现她有种让人意外的教学天赋，能把一个常常让人望而却步的话题变得顺理成章，甚至读起来很有乐趣。
