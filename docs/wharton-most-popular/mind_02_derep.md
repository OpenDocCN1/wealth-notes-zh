# 序 3 我见过太多有钱人败在认知上，所以我把认知当成最好的理财产品


大学时人类文化课老师的一句话一直钉在我脑子里：我们实际在用的世界，是我们脑子里建出来的世界。换句话说，真相从来不是裸奔的客观事实，而是认知这台机器加工出来的投射。难怪有人说世界因人而异，工具不同，看见的景色自然不同。同样的局面，有人看到的是机会，有人看到的是麻烦，其实没有绝对的客观评判，只有人对世界不同的解读。

我带的团队常年给想进文旅行业的老板做顾问，接触下来这些人大多腰缠万贯、干劲十足。文旅要动基础设施，门槛极高，能上桌的自然都是各行各业里被大众定义的赢家。可是几年下来回头看，除了运气和时点都爆棚的极少数，剩下的成败绝大多数都押在老板认知高低上。

原因很简单，文旅这几年变天了。游客从过去被旅行社牵着走，变成自己挑玩法、自己定假期。竞争的半径因此被拉爆，从圈内打圈内，变成了一个无边界的混战。手里有钱有权有资源，前期可能风光一阵，但缺了开阔的视野和敏锐的判断力，在这种复合战场里照样被淘汰。这种边界消失的趋势不只是文旅，未来会蔓延到越来越多的行业。窄认知，基本无胜算。

所以换个投资的视角看，这个时代最值得押注的资产，就是认知本身。

我花这么多精力研究思维模型、琢磨认知深度，并不是因为工作需要。文旅需要它，但更核心的是，它是面向未来的通行证。认知已经不再是影响成败的加分项，而是起步的门槛。认知抬上来之后，它可以复用到事业、战略、投资、家庭关系上任何一个场景，而且它有天然的复利属性：活得越久，复利越厚。这大概是市场上唯一的高收益、零风险、终身分红的人身险了。

认知要升级，就得靠高质量的内容喂养。时间很贵，试错成本更高，学什么比怎么学更关键。理想状态是能跟着顶尖大师泡在一起沉浸式学习，但这对大多数人来说不现实。退而求其次，就是读大师的书。可现在书海浩瀚，出版社一年出上千本，从里面挑出真正经得起时间考验的经典，本身就是一件费时费力的事。

很庆幸，这次中信出版集团推出的“全球知名商学院经典课程系列”，正好帮大家省了这笔筛选成本。我一直很认可中信出版社的眼光，我自己的第一本书《好好学习：个人知识管理精进指南》也在中信出版。此次他们把哈佛、沃顿的顶尖课程搬上纸面，为想升级认知的人点亮了一盏灯。

系列里有四本通识里的硬核之作：《沃顿商学院最受欢迎的谈判课》《沃顿商学院最受欢迎的思维课》《哈佛商学院最受欢迎的营销课》《哈佛商学院最受欢迎的领导课》。

谈判这本，聊的是最日常的沟通。国内多数谈判书都在讲策略、话术、技巧。斯图尔特·戴蒙德则往更底层走，他把情绪和感受放到了谈判的核心。大多数人以为谈判是理性的博弈，却忘了纯理性并不存在。越是针锋相对，情绪和本能的牵引力越强。正是在这个洞察上，戴蒙德总结出了一套能在任何人和任何情境下都适用的谈判方法。

思维这本是沃顿商学院最年轻的终身教授亚当·格兰特的代表作，主题是大家都在问的成功学，原书英文是《GIVE AND TAKE》，初版名叫《沃顿商学院最受欢迎的成功课》。国内的成功话题很容易变成鸡血式励志，信自己、拼努力。格兰特心理学出身，把个人成功放回社会网络里看。他把人分成三类：付出者、索取者、互利者。大量的研究指向一个反常识的结论：最舍得付出的人，往往最成功。这大概是最颠覆的成功论了。

营销这本有种哲学家的焦虑。扬米·穆恩看着大家用同样的套路互相模仿，最后变成一个模子里刻出来的品牌，忍不住发问这就是我们想要的营销吗？他的答案很简单：差异化。不是在原有框架里小修小补，而是在激烈竞争中强行跳出第一曲线，用真正的差异去建立护城河。

领导这本回答了一个经典疑问：领导力是天生的吗？卡普兰教授认为不是。只要用对方法、按清晰的框架训练，人人都能成为领导者。他的领导力框架涵盖愿景与要务、时间管理、工作授权等七个关键问题，想练领导力，这是一本可以直接上手的标准答案。

认知，是未来唯一的确定性投资。这四本书，就是省时间的捷径。
