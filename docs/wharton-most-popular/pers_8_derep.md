# 第七章 工具：让“橡果策略”真正落到一张表上

读到这里，你对橡果策略（ACORN）应该已经有了整体印象。第七章不再停留在概念层面，而是递上一件能直接上手的工具——说服策略表。它不是临时补充，而是本书从开篇到收尾反复用来创建信息的那张“施工图”。我的期待很简单：合上书时，你能真切感到这套内容不悬空、不晦涩，既能看懂，也能马上执行。接下来，就请安心享用属于松鼠的那顿美餐吧。

## 说服策略表

**场景：** 需要开口说服、设计表达、组织信息时。

**说服的五个因素：**
1. 听众——先替对方问一句：“这对我有什么好处？”
2. 可信性——让对方愿意相信你说的。
3. 信息的顺序——把内容放在合适的先后位置上。
4. 记住我——留下清晰、可回想的印记。
5. 情感联系的需要——让表达不只入脑，也能入心。
