# 例子1：从细节看房屋主人的面貌

今年春节过后，我跟薛兆丰老师偶遇在西班牙。有一天我们坐车从城区到郊区，经过了一片别墅。在我们的观念当中，别墅区一定是富人区嘛。但是在那个地方可不一定，因为那儿买一栋别墅就是30万到50万欧元，也就是相当于200多万到300多万人民币，在北基基本上可以买个宽敞的厕所。

我就很自然的问薛老师，你觉得这是富人区还是普通人住的地方。他看了一下，他说是富人区。我说为什么呢？他说，你没有看見那个院子非常干净，而且院子里那张桌子擦得非常的亮。

表面上这是一个细节，把一张桌子擦得很干净的成本与买这栋房子的成本相比，可以说是一个微不足道的成本。但是我们看事情要从 content 到 context，从内容到语境。你看到每家的院子都是那么整洁、桌子都是那么干净的时候，背后支撑这个细节的是一些什么东西呢？

第一，你不仅要买得起这个房子，还要雇得起人每天帮你打扫院子，擦桌子，这个成本已经不低了。但比这更重要的是另外一种资源，是很稀缺的，那就是你有这个需求。有的人出得起这个钱，他没有这个需求。比如说我们走进一个单身汉的房子，就会觉得他很乱。这不一定说明他雇不起保姆，雇不起小时工，是因为他没有那个需求，没有那个心情让人来打扫这个地方。

《诗经》里有一句诗叫“自伯之东，首如飞蓬”。自从我的男人到了远方，我的头就很蓬乱。不是因为我不会收拾，而是“谁适为容”，我打扮好了给谁看呢。所以她没有这个需求，没有这个心情。成本是有的，能力也是有的，但是我们看到的细节是她的头发很乱。所以除了有资源、有钱、有能力之外，还要有需求、有心情。
