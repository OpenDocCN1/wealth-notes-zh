# 什么是“口令思维”

最近我看到网上又在为一个大公司的公关危机刷屏。本来以为是一件并不大的事情，结果越来越大，直到最近还在进一步发酵。

其实所有的公关危机都是一个相同的故事：一个公司出了问题，然后有人出来，本来是想解决问题，但是常是在解释问题，话越说越多，最后解决问题的方式又直接导致问题进一步的恶化。

其实在解决公关危机的时候，有一个非常古老、非常没有新意、但是永远有用的一个法则——先解决问题，再解释问题，或者也可以不解释问题。但是这个法则常常会被忽略，我们总是看到当事人站出来说了很多不得要领的话，而这不得要领的话又挑起了很多事端，让一个本来严重但不是尖难性的问题，最后变得有尖难性意味了。

由于这件事情我就想到了一个词，“口令”。为什么想到这个词呢？我们在一些战争影片里总是看到这样的情节：哨兵在那儿站岗，某个大人物走过来，然后哨兵问，“口令”，那个大人物直接说出口令，就过去了；还有一种就是发生争执，旁边的XL说“你连他都不认识吗”，说了一大通，结果那个哨兵又叫死理，最后弄得非常麻烦。

这样的事情概括起来就是一句话——将简单的问题复杂化，甚至尖难化。为什么会出现这样的问题呢？简而言之，就是缺少口令思维。什么叫口令思维？就是用一个最简单的方式解决很可能最复杂的问题。

这跟人类的一大发明有关，那就是钥匙。想想开门、进门，让该进的人进来，让不该进来的人留在门口，这个问题说起来非常的复杂，但是人类发明了一种方式，就是钥匙。拿到钥匙的人就能够进来，拿不到钥匙的人就不能进来。不管你的力气有多大、不管你手里头拿的是锤子还是棒子、不管你的口才有多好，把这些所有的这些复杂的问题都屏蔽在外，你只需要一个东西——一把小小的钥匙就能够解决问题。

# 婚姻生活的“九字真言”

几年前我参加一个朋友的婚礼，在这个婚礼上有一个人，也许是经历比较多，他给这个朋友提了一条很有意思的建议，说你今天结婚了，我送你一个九字真言，如果你希望你的婚姻生活幸福，你就经常说这九个字，就会少很多麻烦，多很多幸福。

这九个字其实是两句话：第一句话是——“我错了”，第二句话是——“就按你说的办”。

他说这九个字有一种神奇的功能，首先它能够省去很多的口舌，就像你要进门，你没有钥匙的话，可能会想很多的办法，最后不仅费力，而且没有，甚至有可能来意想不到的麻烦。

举一个最简单的例子，你要打开手机，你只要记住你的密码，就可以很简单地打开；或者今天更简单了，用你的指纹就能够打开。如果你忘记了你的口令，在那儿乱动，想暴力进入，不停地在那儿尝试，尝试几此以后手机就自动锁定了，你再继续尝试的话，它会把里面的信息全部删除。如果你地上银行忘记了密码，你尝试三个三次，就会把你的账户冻结，反正你今天是取不了款了，或者这个星期你也取不了款了。

这个经验很多男士在处理家庭婚姻生活的时候，可能会有相同的经历：遇到冲突、遇到意见相左的时候，你在第一时间内想要的是钥匙在那儿，或者口令在那儿；而不是把钥匙、口令给忘了，在那儿开始长篇大论、洒酒不绝。最后结果就是两个：第一个，一下子锁了，根本他就不会再理你；或者更极端的，你说得越多，错得越多，最后她气恼就把所有的信息删除，宣布你跟她之间的这个游戏结束，这是一个很要命的事情。

这时候，这个朋友说的这九字真言就显得非常的重要，你只要用这九个字，这个门就开了，门开了以后，什么都可以谈；而在门没开之前，谈什么都是错的，而不仅是错的，甚至会引发尖难性的后果。可以说这个原则具有普遍适用性，在家庭生活当中是这样，在与客户的沟通、在与合作伙伴的沟通、在与上司的沟通等等，我们都都要记住口令是什么。也就是说那种最管用、又最简单的方式是什么，而不是把这个东西抛诸脑后，用一套你自以为的方式来解决问题，这种方式除了添乱，不会有任何好的效果。

# 贯穿阿甘一生的“口令”

20年前我看《阿甘正传》的时候，我就明白了一个道理：阿甘最大的特点就是一种口令思维。

一个智商只有70的人，面对着一个如此复杂的世界，他怎么活得下来。但他不仅活得下来，而且还活得很精彩、很成功，原因就是他具有一种口令思维，他应对这个复杂的世界就那么几句话，大部分是他妈妈教给他的，所以他一开口常常是妈妈说如何如何，妈妈说如何如何。

他的人生当中有一句非常重要密码：Forrest！Run！Forrest！（阿甘，跑！）这句话是他的女朋友珍妮小的时候对他说的一句话，整个电影的情节其实都跟这句话有关。

第一次，当一帮熊孩子来欺负阿甘的时候，珍妮说了一句“阿甘，跑”，他就不断地跑，结果从一个残疾的少年变成了一个正常的少年。

第二次，又是碰到一帮已经长大的熊孩子来欺负他，他耳边响起的还是珍妮的那句话，“跑，阿甘，跑”。他就跑跑跑，结果跑到一个地方，后面是汽车追着他，他使劲地往前跑，跑到了一个橄榄球场，结果被一个教练看到，这样他就顺利地进了大学。

第三次，他在越南战场上，也还是因为他记住了珍妮跟他说的那句话，“跑，阿甘，跑”，所以他就成了一个战斗英雄。

当然这是一种艺术的夸张，作者是想告诉我们，处理这样一个无比复杂世界，其实你只需要用最简单的方式。这个道理，文学家们好像用各种不同的故事来给我们讲，比如说金庸先生就跟我们讲了这么一个故事，一个郭靖，一个杨康，郭靖因为傻，所以跟阿甘一样，也是使用了一种口令思维，他用最简单的方式在应对一个复杂的世界；而杨康正好相反，用一种非常复杂的方式来应对一个非常复杂的世界，最后的结果就是不作不死。上次我还给大家提到过《士兵突击》（见本专栏4月21日内容《如何知道自己是什么材？》），说的也是这样一个故事。

# 口令思维在公关危机中的应用

我们不再谈文学，我们谈管理。管理其实重要内容就是沟通，就是如何减少沟通成本，提高沟通效率。我们很多本来很聪明的人，在沟通上常常不懂得到这个道理。

有的同学可能会问了，世界这么复杂，你用这种简单的方法，能够应对这个世界吗？我想说的是，这个世界不管多复杂，你的目标应该是非常简单、非常明确的，在达到目标的路上会有各种各样的关卡、有各种各样的细节，如果我们忘记了自己的目标，你很可能就会出现这种捉襟见肘，一下子被细节纠缠着，而忘记你真正想干的是什么。

我卖进到这个房间，我想干什么是我的目标，这个门并不是我的目标。打开这个门的方式可能非常简单，由于打开这个门本身不是你的目标，你要尽可能在这上面少花精力，把精力和资源用在你真正目标上。

很多公司在遇到危机的时候，他忘记了自己最终的目标是什么，是平息，就是以最快、最有效的方式平息公众的愤怒，这是你的真正目标。

当然造成问题的原困可能有多种多样，甚至有可能是竞争对手在黑你。如果你上来就说，这是竞争对手在黑我，或者说竞争对手的产品并没有比我们做得好，你们为什么不说啊？这些话可能都是实话，但是你不能说。原因是：第一，跟你的目标没什么关系；第二，他甚至正好跟你的目标相反。
