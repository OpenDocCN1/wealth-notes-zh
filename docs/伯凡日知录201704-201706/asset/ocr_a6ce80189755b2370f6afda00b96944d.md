# 一、另一个角度看归因谬误

前不久我偶然注意到一个可能很多人都意识到的现象：中国历史上有很多奸臣都是著名的书法家。大家可以到网上搜一搜，到底有哪些奸臣是书法家，比如蔡京、秦桧、和珅都是大名鼎鼎的书法家。

这就导致了一个问题：是不是字写得好就成为奸臣，或者说奸臣就字写得好。这听起来是一个无厘头的问题，但是它包含着一个我们以前讲到过的一个概念——归因偏差，或者叫归因谬误。

我还在这一期节目里分享了一个著名的调查：吸烟到底对健康有没有致命的伤害。得出的结论可能出乎我们的意料之外。但从这个案例里，我们意识到一个结果是有众多的可知和不可知的原因。我们不能从众多的原因中挑出一个原因，作为这个结果的直接原因和唯一原因。

在了解归因谬误的同时，我还分享了奸臣们都悄悄遵循的一个很重要的营销学谬辑。

# 二、印度的沙盒创新

对印度有所了解的同学可能会注意到，印度很多产品的价格低到让我们难以置信。为什么印度出现了众多在价格上非常有竞争力的医药产品呢？

这里包含着一个概念，叫沙盒创新。之所以和大家分享这个概念也算是一种提醒吧，我们在创业的时候应该将自己的注意力聚焦在穷人，而不是富人身上。我们不要想当然的以为赚富人的钱比赚穷人的钱更容易，事实上不少国家的首富恰恰是因为赚穷人的钱而成为首富的。

# 三、死而不亡者寿

本周我又从植物和动物的生存逻辑上讲到了一些管理学的规律，我讲到了两种比较罕见，但是对企业的经营和管理，以及战略和成长路径的选择很有启发性的两个物种——一个叫卷柏，一个叫水熊。大家可以先预习一下这两个物种它们在生存上到底有什么独特之处。它们对于经营企业和管理个人到底有什么样的启示。

# 四、反常识

以前我们曾经讲到过反本能（见本专栏10月23日内容《你深信不疑的东西，正在欺骗你》），本周我又和大家分享了一个观念，叫反常识。正如在下棋的时候，真正的妙招往往是险棋。在今天这样一个商业环境急剧变化的时代，那些卓有成效的管理手段和方法很可能听起来是匪夷所思的。我通过分享Zappos公司的案例，让大家感受到为什么在一个充满黑天鹅的时代，我们要学会反常识。
