# —— 知识笔记 ——

我们今天都在说自我迭代，过去不说这个，过去叫自学。我记得我上大学时有一本杂志就叫《自学》，这个杂志是专门针对那些求教无门的人如何自己学习。

那个时候的报纸上、杂志上还不断地涌现那种自学成才的人，今天我们好像没有这样的人了，因为大家基本上都有权利接受九年制义务教育。

今天我们说自我迭代其实是自学的升级版，所谓自学就是自己做自己的老师，但是我们开始自己做自己的老师的时候，忘了一件老师必须要做的事情。

# 自我迭代的前提：模式识别

《中国哲学简史》写孔子的时候，那个标题我还记得叫“中国的第一位教师”，孔子作为中国的第一个教育家，他的教育理念第一句我们可能都能想起来——有教无类，第二句可能我们就不太想得起来——叫因材施教。

孔子的学生里头真的是五花八门，比现在的那种创业营里的类型还多，有杀猪的、有赶车的，有各种各样的职业。

孔子要教的东西首先是六艺：

+   礼、乐：礼仪、音乐，有点像今天在搞红白喜事的司仪；
射、御：怎么射箭、驾马车；
书：书法；
数：如何计算，包括算命之类的，包括预测之类。

他教的是各种各样的课，我们今天也有各种各样的课。但我们今天各种各样的课是不管你是谁，你所有这些课都要学，高考的时候是算总分的。

孔子的教育里头，他往往是针对这个人，你想干什么，我现在就教你干什么，这就是典型的因材施教。

我们今天要做自己的老师的时候，要学会对自己因材施教，我们自己是个什么样的材。做木匠的人知道什么样的木头适合于打什么样的家具，适合于盖什么样的房子。

有的是栋梁之材。我记得小时候房子，大人说这是我们家最值钱的东西，就是那个屋脊上的叫梁；栋是竖着的撑起这个屋顶的；然后还有一些不怎么直的木头，适合于放在什么地方，打家具时什么样的木头适合于做什么样的家具。这叫材质，不同的材质适合于做不同的东西。

识别自己是什么材料，用我们今天时髦的话说叫模式识别。一听说哪儿有一个什么班我们马上就去了，第二天又听说哪儿又有个什么班，恨不得马上又去报。尤其是对待自己的孩子，大人往往是用不停的报班来缓解自己对孩子命运的焦虑，号称是不要让孩子输在起跑线上。

但是你知道孩子的起跑线是哪儿吗？这个孩子他是什么材料你都不知道，你就带他到一个所谓的起跑线上，是游泳呢，还是短跑呢，还是长跑呢？你都不知道，所以我们就不停地带孩子到不同的起跑线上，那是一件很荒诞的事情。

比这更荒诞的是我们自己在自我迭代的时候往往也是这样一种思维，不要让自己输在起跑线上，所以我们就让自己不停地切换各种起跑线。

# 学习模式：自学型、对话型、输出型

德鲁克对现代教育有一个经典的评价，他说现代教育的创立者他们有一个共同的认知谬误，就是这个世界上只有一种正确的学习方法，这一方法适合于所有的人，这是现代教育体系建立的一个前提。

为什么会以这样一个东西作为前提呢？原因是现代的学校本质上它是工厂，是工业革命兴起以后，当工厂出现以后教育这样一个古老的行业也开始用工厂的方式，流水线、分级的、标准化的这样一套模式来塑造人。

但每一个人接受教育的方式是非常不一样的，也就是说知识输入到人的头脑当中，融化在人的血液当中，它是有不同的接口的，每一个人的接口都不一样。

例子：贝多芬、培根学习模式的不同

比如说贝多芬有一种很特别的学习方式，他想学一个东西的时候要不停地做笔记。他做笔记的目的不是为了以后复习用，而是他只有通过记笔记，他的思维、他的情绪才会调动起来。如果一旦不记笔记，所有他接触的知识都是过眼烟云。

我记得英国的哲学家培根说过一句话，他说我所学到的所有真正有用的东西，都是自学得来的。他所说的自学不是听别人在那讲，自己在那听，别 人讲的时候他完全没有感觉的，他一定要自己动手操作，进行摸索性的、探究式的学习，这个知识才能够入自己的脑子。

但我们在日常生活当中观察，不同的人学习的方式是很不一样的，同一个班上的学生，有的人听课特别有感觉，也不怎么做笔记，听完课他基本上就能记得住；而有的人必须做笔记；还有的人喜欢读课本，边读课本边记笔记，用这样的一种方式。
