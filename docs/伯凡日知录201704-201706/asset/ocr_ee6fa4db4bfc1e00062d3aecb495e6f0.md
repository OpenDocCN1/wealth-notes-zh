# 技能易得，“热心肠”不易得

前天我们讲到了狗型员工和狗型员工，其实狗型和狗型所代表的是冷心肠和热心肠的两种类型的性格。雇佣人的时候有一个很重要的原则是雇佣性格培训技能，而不是雇佣技能培训性格。性格不太容易培训，但是性格是可以营造的。

人的自我下面有多个亚自我，他在不同的场景下会显现出不同的、甚至看上去完全相反的两个自我。营造一个良好的公司文化和组织氛围，一个很重要的目标就是能够激活员工当中的积极正向的那个亚自我。

医学上对热心肠和冷心肠有各种各样的解释，我听说中医里还有那种治疗冷心肠的一种药方，说这个人性情凉薄，往往是因为某种生理的原因。不管这个具体的结论对不对，我相信人的性格是有ц一个生理基础的。

我看到一个概念叫离婚因子，它说的是人的状态除了他体内分泌的催产素的多少以外，人的性格和状态还跟催产素的受体有关。催产素分泌大，如果它的受体的量小的话，人也容易陷入到冷漠、挑剔、烦躁的状态。所以受体量的大小决定了人体里头有一种叫做离婚因子的东西，据说受体量少的人离婚的概率比受体多的人高出50%。当然这只是一种还在争议当中的观点，但我相信每个人的自我当中都有相应的生理机制和要素影响着人的心理状态。

有一种理论告诉我们，一个人合群的程度，组织的参与程度与一种指标有关，那就是他成为志愿者的愿望和动机大小决定了这个人组织参与程度。有些冷心肠的、猫型性格的人可能不太理解那些乐于做各种各样志愿者的人，但是我们在与一些志愿者接触的时候，你确实能够被他的那种热情所感染，他的参与感本身就是他参与的报偿，所以有人建议企业要多雇佣那些具有志愿者倾向的人。这当然是有道理的，但有一点值得注意，每一个人的行为动机都是多重的、都是复合的，而不是单一的。
