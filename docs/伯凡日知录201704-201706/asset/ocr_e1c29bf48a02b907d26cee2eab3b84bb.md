# 5.25 | 带你走出黑暗森林的实用主义

# —— 知识笔记 ——

昨天讲到岩石逻辑和水的逻辑，也就是山的逻辑和水的逻辑，也就是男人逻辑和女人逻辑。今天的话题也与水有关。

例子：铁桶盛物的管理寓言

这是一个管理学教授在上课的时候做的一个实验。

他在桌子上放了一大块石头和一只铁桶，问下面的同学，这个桶里到底可以装多少东西？同学说当然这块石头就可以装到这个桶里，他就把石头放在桶里。

看上去这个桶基本不能再装别的东西了。教授就从讲桌上拿出一罐石头倒到桶里，告诉学生你们刚才这个判断是错的，它还可以装很多的石头。

这时桶里就是一块石头和石头子，已经把桶装满了，他问学生你们觉得还能装什么吗？学生说不能装什么了。这时教授又从讲桌下拿出了一小盆沙，他把沙往桶里倒，一边倒一边摇晃，这一小盆沙也装进去了。

又是同样的问题，你们觉得这里还能装什么吗？学生说真的不能再装什么了，这时教授又从讲桌下拿出了一小盆水，把水倒进了这个桶里。这时教授说，只有在这个时候我们可以说这个桶里再也装不进别的东西了。

当然这个比喻可以用来讲时间管理、可以用来讲资源管理，但我现在想到的是岩石逻辑和水的逻辑。岩石和水最大的不一样，就是水能够创造在岩石逻辑看来完全不可能的事情。其实如果我们把这个场景进一步延伸，就能发现背后其实是一个非常重大的哲学问题。

我们已经知道岩石逻辑就是事实的逻辑、真相的逻辑，是坚硬的、没有弹性的，一是一、二是二的逻辑，而水的逻辑就是柔的逻辑。这二者的区别，我觉得《道德经》里的一句话已经说到了极致，以天下之至柔驰天下之至坚。

# 实用主义哲学的真正含义

在西方哲学史上有 一个很重要的转变，就是从本质主义向实用主义的转变。

所谓本质主义通俗地说就是真相主义、事实主义。

实用主义这个词名声不好听，道理很简单，实用的东西总让我们产生各种不好的联想，“这个人很实用”意思往往是“这个人很功利”，我们常常用实用来容纳那些负面的东西。但我要说的是，也许是由于翻译的问题，在汉语世界，“实用主义哲学”这个词确实是被大大误解了。

什么叫实用主义呢？著名的实用主义代表人物约翰·杜威用了一个例子来说明到底叫实用主义。

例子：走出黑暗森林

想象这样一个场景，你在森林里迷路了，这个时候天已经黑了，你完全不知道你所处的准确位置，更不知周圍的地形。你面对的是一个越来越黑暗的森林，以及好像已经听到了野兽的叫唤。这个时候你要面对的问题很简单，如何以最快的速度走出这片黑暗的森林，不然你就有生命之忧。

我们如果是抱着传统的哲学思维方式，可能就会希望手里有一个地图。但真实的处境是，你手里没有地图，也没人给你送一个地图。即使你手里有地图你也看不见，你没有灯、没有手电，你什么都没有，你是越来越陷于困惑和恐惧当中的一个孤独个体，你怎么办？这个時候传统哲学所谓的解决方案只是一张地图，实际上这不是什么解决方案，而且即使有解决了没有任何问题。

实用主义面对这种场景，给出的是什么样的方案呢？其实也没什么特别，它首先告诉你的是回到你真实的处境，同时发挥你最大的主动性找到解决方案。这时你听到了水声，只要听到水声就意味着在你不远的地方有一条小溪或者一条小河。

水有一个特点，它走弯路但是它不走回头路，你顺着这条小溪走也许会走很多弯路，但是它一定会带你向森林之外。第二，有水的地方就有可能有人，也许你会碰到跟你一样迷路在森林里的人，再幸运一点你可能沿着这条小溪走的过程中遇见一个猎人住的小木屋，如果你能找到这个小木屋你就可能得救了。即使你没有这种幸运，只要跟着这条小溪一直往前走，你也能走出这个森林，至于这个森林的地形地貌、它所处的位置以及你在什么位置，已经不重要了。

# 总结：知与行

简单地说，传统的本质主义的思维方式是为了解释世界，而实用主义的思维方式是解决问题的。传统哲学的终极诉求就是找到关于世界的真相，而实用主义告诉你，真相也许你永远找不到，即使找到了也没用。人活在这个世界上首要的目的是求存，获得生存，而不是求真。不再详细解释这两种哲学的差别，我想说的是我们如何看待管理学，以及跟它好像有关的一门学科——经济学。

管理学的终极目标或者说唯一目标就是解决问题，而经济学的最大功能，也是它最大的诉求就是解释各种经济现象。说的更简单一点，管理学始终关注的是how，也就是怎么办、怎么样，而经济学关心的是what，是什么。我们并不是说经济学是没用的，比如回到森林场景中，假如你事先看过关于这个森林的一张地图，而且你还能记得住，那么它对你走出这片森林可能会有一定的作用。但是它的作用，第一是有限的，第二很可能是不要的。

这就回到了我们《伯凡日知录》一直在讨论的问题，什么叫认知？认知有什么样的作用？真正起作用的到底是什么？今天我们没有时间来详细的回答这个问题，关于这个问题我只想抛一个相关的，可能大家都很熟悉的、跟很流行的那样一个问题，为什么你懂了那么多的道理却依旧过不好这一生？大家不妨在底下试着回答这个问题。不管你的答案是什么，对于什么叫认知、认知到底有什么用这样一个问题都会有一点点的感悟。
