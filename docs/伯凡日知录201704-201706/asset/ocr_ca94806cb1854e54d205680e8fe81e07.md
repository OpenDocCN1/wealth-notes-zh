# 为什么中文里有很多“A而不B”的句式

例1：在河之洲

我们就算没读过《诗经》，至少读过《诗经》的第一篇《关睢》，“关关睢鸠，在河之洲。窈窕淑女，君子好逑”。

在《诗经》里有很多跟这首诗相关的场景和意向，那就是一个美好的东西，一个你所看中的、你所追求的目标往往是被一条水隔开的。一只很漂亮的鸟在河里的一块沙洲上，你可以看见，但是你没办法接近它，你可以远观，不可近抚。有人甚至概括出这样一个规律。《诗经》中的恋人总是被水隔开的，“所谓伊人，在水一方”。

例2：牛郎织女

我们都读过另外一首诗，这不是《诗经》里的，但是它的意境意象跟《诗经》如出一辙，“迢迢牵牛星，皎皎河汉女。”“盈盈一水间，脉脉不得语。”这里都包含着一个理念，那就是中庸的理念。

这种原则概括起来是八个字，“乐而不淫、哀而不伤”。欢乐而不过分的欢乐，悲哀但不能到伤感的程度。用一个哲学的概念来说，这种观念可以概括成必要的张力（essential tension）。它里头包含着两种因素，两种因素之间存在着一种张力。正是因为有这种张力在，它的美才存在。如果没有张力，或者说一种状态它不是处于两种对立状态的中间，而是已经处于某一个极端的时候，它就不美了。

玉之所以在中中国文化当中这么高的地位，实际上是因为它恰如其分的体现了中国文化的核心价值观——中庸之道。

我们在读中国传统经典的时候，这样的句式比比皆是。明不过察，就是说这个人你要做到明智，但是不要过度，人至察则无徒。直不过矫，就你要做到正直，但是你不要去整天去纠正别人。仁能善断，你要做到仁义，但是要做到善断。有些人好像很仁慈，但是他会陷入到一种好好先生，一种习惯性的优柔寡断当中。清能有容，你要做到清廉，但是你又同时要做到包容。

例3：大清相国

王玖文在他的《大清相国》这本书里，他对他书中的主人公陈廷敬是这样概括的。德官多庸，陈廷敬是德官，但是他不乏铁腕；能官多专，陈廷敬是能官，但是他从善如流；清官多酷，陈廷敬是清官，但是他宅心仁厚。

既要做清官，但是你不能做酷吏；既要做德官，但是不能做好好先生；要做一个能官，但是你要从善如流。这里的核心理念还是那两个字，中庸。它的象征物就是玉。

# 三、真正的علی不是折中主义

如此说来，有的一些同学会问了，那好，不过就是这两个极端当中打个折扣吧。这种叫折中主义，真正的<|start|>不是那么简单的。中，或者说恰当它是非常艰难的。比如说你找到了一种有效的方法，你会不知不觉会迷恋，甚至迷信这种方法。

1、不迷信“不迷信常识”

上周我们讲到了反常识，这是一个好方法。有的同学在留言里感谢我，因为他用我说的反常识的办法在股市上赚了一大笔，他很得意，也很感谢我。

我想提醒这个同学，执象而求，咫尺千里。任何一个方法，哪怕是被你过去的经验验证为是非常有效的方法，当里头不存在着张力的时候，它就会悄悄的把你带到陷阱里去。我们既要不迷信常识，也要不迷信“不迷信常识”。这就很难了。

我们总想找到一个确定的、拿来了可以用、而且一直好用的一种方法。但是，这种方法并不存在。任何一种方法其实都是一种牢笼，任何一种方法都在给你提供一种认知的舒适区。在这个舒适区里，有一种魅力让你很舒服，让你很迷恋于这种状态。一旦陷入这种状态，那就是特别危险的。还是那句话，在任何的舒适区里我们都应该给它立一块牌子，“此地不可久留”。

2、破坏性创造

中庸起来很简单，好像是在打对折的，好像既不这样，又不那样，我就找到方法了。但是，在两点之间到底哪一个点是最恰当的，绝对不是打对折那么简单。

我们说要告别黑白思维的暴政，我们要拥有一种灰度思维，但是什么样的灰度才是好的灰度，什么灰才是高级灰。那是太难的一件事情，今天的高级灰也不一定是明天的高级灰。

经济学家熊彼特对于创新有一个经典定义，叫破坏性创造。创新的本质就是不断的破坏你既有的模式，哪怕是这个模式当初是极具创新性的，但你如果你没有一种破坏性创造的意识，那你就很可能被这种所谓的创新给牢牢的套住。

3、君子不器

孔子有一句话叫君子不器。这句话什么意思呢？就是说君子又不固着于某一个固定的外形。他今天是这样，明天可能是那样。

君子的特点就是要不刻意的强化某中东西，总是要在自己的思维和行动里拥有一定的张力。只有保持这种张力，你才能够做到真正的中庸。

4、不执象而求

弘一法师在临终的时候写过一段偈语，我们通常把它称为《临终偈语》。“君子之交其淡如水。执象而求，咫尺千里。问余何适，廊尔忘言。华枝春满，天心月圆。”
