# 用户留言

我与达亿，必须弄清楚自己是那种韧性，如今我们时常的叫做模式认知，选择适合自己的那种学习方式，从而因材施教。否则起初方向都勾选错误，持续下去，只会越挫越远，或者不停的更换起跑线，到最后才发现时间浪费了，啥也没有学会。

关于学习的三中模式，我是属于输出型的。

我始终相信教是巩固学习最好的方式，所以我会把自己学到的东西，教授给别人，在教的过程中发现自己的不足，也因为要教，会倒逼自己进一步去复盘所学知识，这样一来，对新知识的吸收才会更深刻。

关于表达能力，我属于倾听型。我喜欢与做一个简单的大纲，会在大脑里对这些内容做一个检索。在实际情况中，根据对话内容，调动大脑里对这些知识，进行解答。这种方式，比较灵活，不死板，运用起来很自如。

关于工作模式，我是领导型。很大一部分原因来自如我的性格，内外兼修的类型，有领导精神。考虑问题通常比较周全，顾全大局。

风吹不走，雷打不动
首先认清楚自己很重要。无论是什么类型，在今天这个最好的时代，都有它自己发挥的空间。为什么北上广深房价高企，但年轻人趋之若附的跑来，还有一大堆名人在为北上广深背书。因为大城市人多，资源多，总有你发挥自身长处的位置。像罗振宇常常讲他的口才天赋，在家乡里发展最多是一个小老师，但来到北京他的表达模式就能创业服务更多的人。只有先找到自身类型，或者叫长处、优点、天赋。那才能进行自我迭代，把优势做大到很多人需要你，那么自然会有人来补足你的弱点。比如艾森豪威尔背后的小团队。倘若一开始出发点没有找准起跑线，分析清楚是进行那一类型比赛，盲目的自我迭代，陷入一轮又一轮的补足缺点的怪圈。最终也是徒劳无功。
