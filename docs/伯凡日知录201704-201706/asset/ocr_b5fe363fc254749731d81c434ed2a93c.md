# 本周问答｜聪明的90后知道如何与环境相处

本周问答｜聪明的90后知...

注：苹果与生姜的比喻，见专栏4月27日内容《90前是苹果，90后是生姜》；辣椒的提问，则是针对5月1日《大自然的首席营销官》一文。

苹果要转变观念接纳包容生姜，那生姜怎么和苹果相处？我觉得我是一个快被体制磨成苹果的生姜，突然觉得害怕起来了

吴伯凡

首先说明，我们所说的苹果、生姜都是一种理论上的分析模型，为了把问题分析得更清楚，我们设定了这些模型。但是在现实生活 children 中很难找到纯粹的生姜，也很难找到纯粹的苹果。哪怕是60后，不守规矩的、在思想上和行动上出轨的人也有；哪怕是90后，其实他也知道规矩到底在哪个。

90后绝对不是是非不分，有钱任性、没钱也要任性的那样一群人。事实上我们很多人都是介于苹果和生姜之间的，但是由于每一代人所处的生态不一样，导致了他们最后个体的形态不一样，这是肯定的。

生姜型人格很有个性，但是你要知道，你的顶头上司、你的老板可不是90后。什么叫聪明？就是你要知道你所处的生态，给出相应的对策，适者生存。达尔文说，留下来的不是最强大的，也不是最聪明的，而是最适应环境的。所以聪明的90后，他在知道自己本身是什么样特性的情况下，更知道在外的环境是什么样子的。要和谐地相处，要把握几个原则：

+   1、我知道我跟你不一样。你不能按照你的标准来要求我，但我也不会按照我的要求来要求你。

就像有些心理学家说，男人跟女人完全是两种不同类型的生物，一个来自火星，一个来自金星。表面上他们说着同样的语言，实际上一个说的是火星文、一个说的是金星文，说的话总要经过对方的一个无形翻译系统。你觉得你说明白了，对方根本没听明白；你觉得你说的是这个意思，对方理解完全不是这个意思。

那么怎么样才能够相处呢？首先应该意识到二者是有巨大差异的，比如说男人的诉求是事实、道理，女人要求的是态度、姿态。如果她按照态度这个标准来衡量你，而你总是按照事实和道理在说话，就一定会发生巨大的冲突

+   2、要知道对方的价值标准、语言系统。

就像油画家，画画的时候是近距离在画，但是他知道人在三米之外看到这幅画又是什么样，他按照三米之外的标准在画他眼前的画，所以最后画出来效果就很好。如果你是按照近距离的标准在画画，效果往往是出不来的。

90后是新物种，反观过去每一代都是这样过来的，用上一代的标准来要求下一代注定效果会大打折扣。不知吴老师会用什么来比喩00后呢？

吴伯凡

我也想不出一个恰当的比喻，但在我看来，00后与90后相比更接近于生姜的形态，原因是他们面对的资源类型更多、获取资源的渠道更多、获取信息的方式更多，他们更加是电子土著，他们一出生就生活在一个互联互通的世界。

这一点跟他们的父辈60后和70后是很不一样的，因为他们的父辈在世界界形成的关键时期里，资源是匮乏的，接受信息的方式是广播模式的。所以00后应该是比90后更加90后的一群人。

在村里的时候，发现辣椒越小越辣。这么辣，除了人，其他动物怎么搬运它呢？辣椒这个物种是不是一般规律相反的呢？

吴伯凡

首先越小的辣椒往往越辣，这是个普遍的规律。据说世界上最辣的是墨西哥的一种辣椒，很小，人要是舔一下会马上陷入昏厥状态，那是一种极其可怕的辣椒。

我们今天就来谈谈辣椒这回事。我们常常把辣椒跟其它的味道连在一起，“酸甜苦辣”。但辣椒本身不是味觉。人的舌头觉得辣椒辣，并不是用味蕾感受到出来的，而是辣椒里包含的物质对人形成一种强烈的刺激痛感，这种刺激痛感并不是味觉。

可以说，辣椒算是一种软性的毒品。有很多让我们上瘾的东西，都是刚开始让我们很难受的。它会打破我们现有的平衡，这个平衡被打破之后，人会尽量调动自己的补偿机制，也就是机体努力的机制，让机体处于一种饥渴的状态，调动各种资源让这种不平衡修复到平衡。如果人持续的受到这种刺激，那么这方面的能力就会变得越来越强，而且他希望把这种机能进行发挥。一开始让你难受的东西，最后会变成一种成瘾性的依赖。这就是为什么有的地方的人是辣不怕，有的地方的人是不怕辣，有的地方的人是怕不辣。

我记得我小时候在老家经常听到这句话——“这事让我感觉特别不辣”，就是这事让我感到特别不舒服，就叫特别不辣。大家一听就知道我们这个地方吃辣不吃辣了，这就是瘾头的来源。

所有的瘾，好的瘾和坏的瘾，里面都包含着一种找不自在。在这种不自在、不平衡当中又能找到某种动态的平衡，找到努力之后的那种成就感、获得感和战胜感，这是所有瘾头的特点。

这位同学说，那些小辣椒那么辣，其它动物是不愿意搬运它的，其实这真还不一定。我们刚才说了辣椒不是味觉，如果动物体内没有这种东西的受体，它就一点都感觉不到。比如电视机就收不到收音机的信号，没有受体再强的信号也是没有用的。

有一种动物就对辣没有受体，那就是鸟，鸟是不怕辣的，确切的说不是不怕辣，而是对辣完全无感，没有受体。90后现在说“你端着我却无感”，那个鸟肯定对辣椒说你端着我也无感，我对你的辣一点都没感觉，只爱吃辣椒的籽。

从过程看是进化，从结果看很像是设计。辣椒为什么有辣味，说白了就是一种设计。哺乳动物吃辣椒以后，消化系统是很容易把辣椒籽破坏，吃进去以后排出来的辣椒籽，是不能发芽的。

但是鸟的消化系统不一样，它吃进去的辣椒籽，随着鸟粪排出来以后，不仅没有受到伤害，而且鸟粪有利于它的发芽，其实有很多的种子都是借助于鸟粪来传播的。简单地说辣椒这种辣味的设计就是趋利避害，不让哺乳动物吃它，只让鸟来吃它，因为鸟的消化系统有利于它的传播。
