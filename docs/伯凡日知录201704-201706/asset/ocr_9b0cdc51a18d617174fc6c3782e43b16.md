# 一、成功学为什么不靠谱？

有一位《日知录》的同学问，以前讲到归因谬误，而且你好像对成功学很不屑，这两个东西到底有关联吗？我告诉你还真有关了，成功学最大的问题就是陷入了归因谬误。

归因谬误，就是两个在时间序列上先后发生的事情，“果”是一定的结果，但“因”充满着不确定性。首先是数量的不确定，其次是质量的不确定，显因、隐因、主因、辅因、合成因……众多的因聚到一起，才会产生一种不聚到一起不可能产生的作用。所以，原因是一个巨大的包裹，甚至可以理解为一个黑箱。它是怎么导致了这个结果我们不知道，它里面到底有多少东西我们不知道。

但成功学在干什么呢？它是从一个固定的结果出发，倒推一个原因，然后从原因包里头拎出某一个原因。这个原因看起来好像是个原因，但它到底起了多大的作用、甚至是正反还是反面的作用都不能确定。

有的人干了很多跟他目标相违背的事情，但这个目标最终实现的时候，他甚至会觉得他干的那些事情，就是这个所谓成绩的重要原因。真实的情况很可能是，他无形中搞了一些破坏，但破坏并无得逞，有他的因素导致了成功，而他却把这些破坏性因素归结为原因。

还有一些原因，可能根本就不是原因，只是在时间的因果序列中处于前面，这就是典型的“雄鸡一唱天下白”，大公鸡以为天是它叫亮的，因为每次它叫完后天就亮了。这就是成功学特别不靠谱的地方。

# 二、吸烟与健康

再给大家讲一个很著名的调查，大家可能就更理解归因谬误有多可怕，成功学有多么不靠谱。

曾经有一个宣传戒烟的公益组织，为了让公众懂得吸烟有损健康，花了一大笔资金请了一个调查公司，调查吸烟如何导致不健康。这个调查公司按照科学的方法实施调查，遵守大样本双盲随机对比实验，也就是样本要大、调查方和被调查方彼此不能够识别对方是在调查或者不是在被调查、具有随机性、要对有对比组。所以他们就找了大量的一个吸烟、一个不吸烟的双胞胎样本，四年的时间才做完这个调查。最后的结论让出钱方非常尴尬，结果是，吸烟的人比不吸烟的人寿命要长。

这个例子绝不是说吸烟对健康无害，我想说的是在这样一个看似科学的对比实验中，仍然包含着没有意识到的谬误，那就是健康或不健康是一个结果，但导致健康和不健康因素有多种多样，吸烟只是其中的一个。这个结论并不值得相信，也许样本再大一点，就又是另外一个结果。

比如我们想象，兄弟俩一个抽烟，一个不抽烟。但抽烟的人身上说不定有很多有利健康的做法，比如情绪乐观，放得开，人际关系好；同胞兄弟不吸烟，但是他可能会有其他的问题，比如说他从事的是不利于健康的行当，他住在一个雾霾特别大的城市等等，这些东西都有可能导致他不健康，甚至足以抵消他不吸烟带来的正面影响还有余。所以虽然他不吸烟，但是他比他的哥哥寿命要短，这完全有可能。

这就是说当一个结果是一定的时候，我们不能够简单的追踪一个原因，并把这个原因作为这个结果的直接导因，这是我们一定要遵循的一个原则。

成功学最大的问题就是，它完全忽略了导致成功的诸多要素，而且这些要素之间的权重完全不清楚。比如大环境特别有利于成功，而且特别有利于某一类性格的人成功；如果换了一种环境，这类人可能是最倒霉的人。这一原因，就可能抵得上很多其他也可能导致成功的、但权重比较小的原困。所以我们不能简单的倒推，从而得出一个结论，“因为它这样，所以它成功”。

# 三、奸臣与书法家

还有一个可能是言者无心，听者有意的现象。我在书法史中发现，书法家里有很多奸臣。比如，北宋四大家，苏黄米蔡，苏东坡、黄庭坚、米芾，这个蔡是谁呢？就是蔡京，那是大奸臣。但他的字可是无可置疑的好啊。

还有一个人，他发明了我们今天还在用的字体“仿宋体”（注：发明者有争议）。仿宋体就是比宋体更瘦更清秀的一种字体。大家知道那是怎么来的吗？

![](bbox=[0.07, 0.00428, 0.95, 0.0050999999999999995])

书法史上有一个很著名、很具有个人特点的书法叫瘦金体，瘦金体的创始人就是宋徽宗。有一个人就揣摩皇帝的偏好，这个人很厉害，如果活在今天他可以写一部营销学的书。为什么呢？他干的这件事情特别符合营销学上的一个原则：当你想服别人的时候，装作无意地去有意模仿对方的某些东西，让大家瞬间产生亲近感，对方对你的接纳之情就会变得不可抵挡。

比如说你作为乙方跟甲方谈话的时候，你发现甲方特别喜欢用哪些词，甚至一些口头禅、小动作等等，你要是在第一时间发现这个，然后看似无意地在你的措辞中模仿他，小动作里倏他有某种相似性。对 方就会在心里里觉得跟你对上了暗号，就 会无可阻挡的认可你。

这个人就很懂，写奏章的时候，用一种很像瘦金体、但是又有有所改进、不完全是模仿的那种字体，这就叫营销。所谓营销，首先是提高产品的可nexpected度，就是在众多同类产品当中，你有一个特色让对方一下就能注意到你。皇上看了，这些奏章中有一个奏章用的竟然是自己自己的字了，但 是又有所改进创新，我心里就很喜欢。这也是营销学一个原则：隐蔽处的相遇最容易产生亲近感（见本专栏5月2日内容《爆款产品的“隐蔽开关”》）。所以这个人就很快的就被识别了，这个人叫泰栓。

现在故宫博物馆里，有几幅字，过去都认为 是乾隆的字，但专家们已经考证，那不是乾隆的，是一个叫做和珅的人写的。可能和珅也从泰栓身上学到了不少。

![](bbox=[0.07, 0.00805, 0.95, 0.009300000000000001])

好多年前，我看一份出版于台湾的杂志叫《天下》。“天下”这两个字写得非常漂亮，后来我请教，这个字这么漂亮是谁写的？有人告诉我，这是一个叫祁孝肇的人写的。据说还有四个人字也是他写的，“交通银行”。确实是有很名的书法家，但是也是很有名的汉奸——伪满洲国大臣兼文教总长，祁孝肇。
