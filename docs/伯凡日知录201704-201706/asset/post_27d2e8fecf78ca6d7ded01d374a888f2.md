
# 本周问答 | 怎么看待规则对人的驯化？

本周问答 | 怎么看待规则... ↓

马亮：伯凡老师，中国传统文化和“胡萝卜加大棒”理论中，部分一直认为“人性本恶”，所以要用各种方法约束员工的行为，甚至是惩戒。

这样的管理者是不是期待自己的规则能够驯化员工？即使最初不习惯，慢慢惩戒产生效果时，也就有了通过规则驯化员工的过程。

甚至很多员工离开了这样的企业很久后，还感谢当时严格的规定，这和您讲的好劳恶逸的“天性”好像不是一回事，但能起到同样的效果。请问，应该怎么理解这种驯化？驯化是不是分为后天和先天？

我讲到驯化的时候，重点其实是讲反驯化。当你全身心地做一件事情，去伺候它、去服务它，慢慢你就会被这种过程悄悄地驯化。

比如说养花，有一次我到一个朋友家里头，他那个花长得特别漂亮，他说你知道这花为什么长这么漂亮吗？我說不知道，他说因为是刚买的。我可以想象让他再养几天的话，那花就一定很难看了。

花要养好，是要倾注大量的心思的，我尝试过，你只有从心底里对它好，对这花好，它才长得好；要是你忽略它，爱搭不理的，偶尔浇浇水，它一定会慢慢枯萎下去。所以你如果没别的爱好，你就去养花，当你开始很投入地去养花时，你会发现你在发生变化。

中国文化当中有很多类似的观点，比如说人磨墨，墨磨人，我们在写字之前要磨墨，我们磨墨好象是在改变墨，但是你悄悄地会被这个墨所改变。哲学上把这种过程叫异化，就是主体跟客体在互动的过程当中，主动那一方的权利会悄悄地被让渡，你为了方便，去使用一个秘书，你一直在使用他的时候，你会渐渐地意识到，不是他离不开你，反而是你离不开他。

我们跟电脑，跟各种技术打交道的时候，都会遇到这种情况。刚开始好象是它在伺候我们，但实际上我们不知不觉已经开始在伺候它，我们将我们所有的权利不知不觉地让渡给所谓的工具，在这个意义上说，你成了它的工具。人类文明史上由此太多这样的案例了。

比如说《人类简史》里头讲到的小麦，就是一个最典型的例子，我们为了有粮食吃，我们种小麦，小麦的产量越大，我们养活的人就越多，人口越多就需要种植更多的小麦，本来小麦只是在中东、在两河流域的一种野草，经过人类驯化以后，出现了一种植物。但是后来遍布世界很多地方，它成了植物史上最能成功就是最高的一种植物，这也是驯化。

马亮同学说的这种驯化是指我们被动地被一个外加的力量来强制人性，当然这种方法的背后有一个世界观，那就是人性本恶。在管理学上有三种理论，一种叫X理论，Y理论，Z理论。

简单地说，一种是认为人性都是恶的，所以你就必须用各种的规范去管理他。管理学家发现，管理者以奴隶主对奴隶的态度来管理员工的话，表面上在顺从，实际上他已经跟你展开各种各样的博弈。在这个所谓的驯化过程当中，你发现员工越来越难伺候，劳动效率会越来越低，这就远离了管理的初衷。

罚的那一面，它会天谴，它会用各种各样的手段来惩罚人类的恶习。另一方面，老天爷有好生之德，它又会滋养我们，应该说这两者不可偏废。《道德经》里说的比较客观，它说“天道无亲 唯与善人”，就是说老天爷没有亲戚，它不会偏袒谁；但是如果你是个善人，它会眷顾你。

我记得在犹太的《圣经》里头有一句话，说人在少年负轭是有好处的，轭就是套在牛肩膀上的那个东西，如果一头牛没有被套上那个轭，它永远是一头野牛。人的最大的不幸就是在少年的时候没接受过这种规训，你表面上是自由的，但是其本质是任性，是你根本没办法跟你更深层的自我相遇，也没办法跟世界的更深层的本质相遇，这个时候你就泛泛地生活在这个世界上。因为你没有受到严格地规训，所以这个规训也好、训导也好、甚至惩罚也好，都是为了激活人性当中的某种力量。

具体说到学习的时候，我们谈到了学习就是勉强，它一定有那种让你不舒服的东西。如果一个人没有经历过那种持久的不舒服的状态，你是不可能让自己实现人格、知识各方面的转型的。与此同时，学习它也有乐趣，但是我们要意识到，当我们开始学习的时候，我们必须接受学习的这两面，一方面就是让你难受的，在规训里的那一面；另一方面，在被训、在受虐当中，你渐渐地感受到了某种乐趣。当然你不叫受虐狂，那是因为努力，因为被折腾而获得了某种赏赞，这就是学习的另外一面。

所以当我们提到驯化的时候，不要觉得它很可怕，它是我们作为一个人必须经受的一部分。卢梭说人生而自由，但无时不在枷锁中，人生于世，佛教讲苦海无边，你从苦的这个角度来看，处处是苦，你应该承认这个苦的那一面，在这个苦中以苦得乐，不是逃避这个苦，而是在苦当中喊回一种快乐，痛并且快乐着。

张浩：在武志红老师的书里有一个中国式好人的概念，即讨好型人格，怎么区分自己是宽宏大度，而不是老好人呢？

吴伯凡

这问题细究起来，还真是个很深刻，也很难回答的问题。我们不妨从另外一个角度看，有一本书大家有空可以看一看，叫《魔鬼辞典》，我年轻的时候经常看那本书，那里头充满着负能量。但是负能量有一个很大的好处，就是让你清醒，让你看到世界的并不那么可爱的那一面，让你接受一种严峻的现实，也能够让我们自己反省和解剖自己。

它里头有很多这样的话，有一句话就是说，它对勇气的解释是，勇气是男人们在没有危险的时候最乐于表现的一种气质；它对宽容也有一个解释，当面对一种处境，你无能为力，你无可奈何的时候，我们常常做出的一种掩饰自己内心怯懦的一种姿态。这话里头的负能量显而易见，但是它对我们是一种提醒，很多的美德看上去很美，但是背后并不美。

这就回到张浩同学的问题，宽宏大度跟老好人有什么差别？宽宏大度是我内心有很强大的力量，我有能力制服你，我甚至可以消灭你，但是我不滥用这个权利，我的退让不是因为我的怯懦，不是时间因为我的胆小而退让，而是因为我不屑于、没有兴趣跟你来较短长。还有一种可能是，因为你强大，所以你不太感受到他人的威胁，或者你不愿意在这样一件在你看来很小的事情上浪费时间，表现出你的恶意。

一个恢宏大度的人，他尽可能地隐藏自己的恶意，尽可能地表现出自己的善意，但是背后他是有 一个实力作为支撑的，常常表现出自己恶意的人，往往是弱小的人，内心是不强大的人，他遇到很小的 事情也会感受到很大的威胁。这时候有两种选择，一种选择就是鱼死网破，遇到一点点事情勃然大怒，那当然你在外人看起来你就是一个很不大度的人。如果这样的人有一定的生活经历，他发现这种策略是很不划算的，他会选择另外一种，就是退让，体面地退让。

有一个德国笑话，说有个人骑着马到乡下去休假，后来当他睡了一觉，醒来的时候发现自己的马鞍子被人拿走了，他就对这个村里头的人说，你们要是不给我把马鞍子找回 来，我就会采取断然措施。后来村里人还真帮他把马鞍找回来了，是那个淘气的小孩子拿走了。别人把马鞍还回来的时候问他，要是我们不给你找回 来，你要采取什么断然措施？他说那我就牵着马回去呗。这就是断然措施，这显然不是恢宏大度。

这样老好人和宽宏大度的人的区别就很清楚了。宽宏大度的人是有实力、有自信，他不滥用自己的权利和优势，他内心有一种丰饶感和安全感，他习惯于做出退让。而老好人呢，是没有原则的，而且是没有实力的，遇到任何事情他统一地采取这种退让，收缩自我，苟且偷生这样一种状态。

要做一个恢宏大度的人其实是很 难的，实力是关键。

### 1、寓教于乐没有错，但是弄清楚什么叫“乐”
力的，要你的思维进入到活跃状态。当他能够开动脑筋，能够转弯的时候，他会得到一种强烈的快感。

我们玩游戏的时候困难不困难？从下棋到电脑游戏，都有一个很重要的因素，就是设置困难。但这个困难的程度不要太高，太高以后你会产生绝望感。这种困难往往是在你的能力范围之内，但你需要调动你的精力、心智去克服这个困难，当你克服这个困难的时候，你就会得到一种强烈的乐趣。

比如看电影，假如我们看过一部电影，哪怕它是一个悬疑片，看过一遍你就觉得没意思了。只有在没看过的时候，我们才津津有味地去看它，原因是你看过后，这个困难已经不存在了。

所以“寓教于乐”并不是让我们处于一种放松的、散漫的状态，而是在教育活动当中设置与受教育者的智力相适应的某种困难，我们鼓励他去克服这种困难，克服困难之后得到了某种快感，这样他对困难的态度就改变了，第一不惧怕，第二甚至是喜欢困难、喜欢挑战。

### 2、现在的教育存在着两类问题
第一类问题就是在教育活动当中设置了大量的跟孩子的兴趣不相匹配、同时跟他的智力也不相匹配的困难，要难得让他绝望，让他把学习当成是一种非干不可的苦役，他对学习就会有一种强烈的恐惧和畏缩。这是我们现代教育里特别普遍的一种现象：厌学，不喜欢他所学的东西，教育的主要功能成了让受教育者不喜欢学习。

另外一个问题可以说是矫枉过正的。过去的教育以折磨孩子为主，所以现在有一派教育理论就提倡，让孩子在学习过程当中处于最轻松的状态，应该说这跟教育、跟学习关系并不大，无非就是让小孩处于一种享受生活的状态。在这种受教育过程当中，他产生不了快感，因为这里没有一种必要的困难和挑战。

用这种方式，第一没办法让孩子的知识有实质性的升级；第二，也很难让孩子喜欢上学习，因为这里没有学习的一个很重要的因素，就是发挥自己的智力克服困难和挑战，最后获得一种快感。在这个意义上，学习就是一个快感的滚雪球过程，雪球越大，学到的东西越多，快乐也越来越多。爱因斯坦说，热爱是最好的老师；我们中国人也说，知之者不如好之者，好之者不如乐之者。

## 4.3 | 婚姻是一种涌现

## —— 知识笔记 ——

这几天我在复习一本我读过的书，这个节里头有一段让我读懂，尽管这本书我已经读过，但是读到一个段落的时候，我发现有个词我不知道什么意思，它叫突发体系。因为这是一本翻译的书，我就在琢磨，这到底原文是什么。这个概念在这本书里头出现得非常频繁，其中有这么一段话，“突发体系模型得到了更为广泛的接受，当将不同的元素结合在一起，并产生出比其总和还要大的结果时，突发体系便应运而生了。”

我再往下读的时候，猜出来了，这个词的原文是什么，每一个译者都有自己的知识盲点，何况这本书有太多的知识点。所以译者用“突发体系”这四个词用来翻译英文中Emergence，它通常的意思是出现、发生、暴露，但是这个词是一个很著名的哲学概念，最早是由古希腊的哲学家亚里士多德提出的，但是在后来，在20世纪后半期这个词被很多研究系统论、复杂理论和混沌学的人经常使用，这个词通常翻译成涌现，就是那个什么什么当中，从什么什么当中涌现了，比如说从广大的人民当中涌现了很多人，就是这个涌现。

例子：蚂蚁的智慧

在KK的《失控》这本书里头，举了好几次一个例子，就是蚂蚁的智慧，每一只蚂蚁的智能是很低的，别说智能，它的感官系统都是不齐全的，蚂蚁主要是凭借嗅觉而不是视觉来生存的，每一只蚂蚁分头觅食，刚开始的时候都是在做布朗运动，没有规则、没有方向的运动。但是如果有一只蚂蚁发现了食物，很快地这个蚂蚁群就都知道这个食物在哪儿，它就能找到一条从食物到蚁穴的最短的路线。

美国西南航空公司请了很多的物流专家做了一个物流的模型，后来他们发现这种模型跟蚂蚁的物流系统非常相似，大家要知道这是万物之灵的人类当中的人尖子，借助于现代计算机技术，做了一个模型，结果做出来的这个模型跟蚂蚁的物流系统竟然是一样的。那么弱智的动物，竟然拥有了我们人类费了老大劲才能拥有的一个智能，要知道蚂蚁一直是在用这个智能系统，我们只有在今天才发现了这个智能系统，专家把这种东西叫群体的智慧。

这不仅是在蚂蚁群当中，在蜜蜂群、在白蚁群，在很多的群居生物当中都能够发现的一种智能。简单地说，个体非常弱智，但是它们一旦汇聚在一起的时候，就涌现出了一种高度的智能。蚂蚁之所以拥有这种智能，不是因为蚂蚁里头出现了一个超人，它能够发号施令，指挥大家按照最佳的路线来搬运食物。而是只要是局部的，只要它们聚集在一起，这种智能就可能出现，但是在个体身上是没有的，凯文凯利把这种现象称为“众愚成智”，众多的愚蠢聚集在一起就成为一种智能。

其实大数据里头就包含这种“众愚成智”的成分，每一个个体的上网行为都是盲目的，但这些数据汇聚到一起的时候，我们就能够从中发现一种智能，你可以利用这些，利用大数据来预测未来的很多事情。其实涌现作为一种现象，在自然界，在人类社会当中非常普遍，最直接的涌现的例子就是水的波浪。无数的水分子聚集在一起的时候就成了水，有了水就出现了波浪，这个波浪就是涌现出来的，它的特性是不能够归因到每一个个体的，就像我们不能把蚂蚁的智慧归结于哪一个单一的蚂蚁。

所以涌现这个词听起来是个动词，但是我们说的涌现是一个名词，就是它带有某种无中生有的含义，Emerge这个词本来的意思就是出现、浮现，原来没有，突然出现了一个东西。这种现象甚至在我们日常生活当中也很普遍，比如说婚姻就是一种涌现，婚姻是一种相遇，是男人和女人走到了 一起，这两个角色聚到一起的时候，就会出现一种双方都可能没有意识到的一种，我们可以称之为隐秘关系的东西。

我们在日常生活当中经常发现这样的现象，某个人，每一个女子结婚以后，你发现她好像变成了另外一个人，她的以前的种种的优点好像突然消失了；或者她以前的种种的缺点也突然消失了。

我们民间的说法是卤水点豆腐，一物降一物，其实这里头包含着我们所说的这个意思，它是属于，它加入到一个叫做婚姻的生命体当中了，它只是其中的一个器官，一个零件，或者说婚姻是一个突发系统，在新出现的一个系统，它只是系统里头的一个终端，你所看到的它是整个系统运行在这个终端里头的表现而已。

在国外的婚姻诊疗室里头，一个有经验的咨询师，他都有这样一种意识，现在坐在他面前的表面上是两个人，实际上是三个当事人，另外那个当事人在哪儿？看不见，但是只要他们两个人在一起，就出现了第三个当事人。这个当事人是一个隐秘的操纵者，他在左右两个人之间的关系，但是两个人的任何一方都觉得，自己面对的只是对方，只是一个人。
