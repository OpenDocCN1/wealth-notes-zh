本周预告｜学和习的差别

这几天我拿起一本我曾经很认真读过的书，发现里头划了好多的“道道”，但是很多划“道道”的地方我现在都没什么印象了，这说明我读书不认真，当时好像很认真，过后都不记得。但是我有一个感悟，就是书一定要反复地读，就像我们认识一个人，你说你认识谁谁谁，就是因为在某个聚会上跟人着了一张像，别人不认识你，别

我们有时候觉得我们读过一本书，其实那跟没读也差不多，就像我们微信里头少了很多 sperson，实际上根本跟不认识也是一样的。那么要真正认识一个人，要反复地跟他交往，回过头来，没有回头交往的那就不算认识。一本书如果不是回头再读，你基本上跟没读是一样的，因为重读这本书的时候有很多收获，我本周就给大家分享一些我早该记住又没有记住，但是这次一看很有意思的一些知识点，和大家分享。

# 1.涌现

这个词听起来很普通，涌现出什么什么。但大家到留意，这是一个哲学概念，而且是一个很重要的哲学概念，在互联网时代是一个非常重要的概念，要不然我们根本没办法理解好多很时髦的说法，什么叫失控，什么叫蚂蚁的智慧、蜜蜂的智慧，就是只有理解涌现这个概念，我们才能够理解互联网。

# 2.钟与云

这两个概念必须放在一起说，因为它们正好是对立的概念。提出这对概念的人，是我已经给大家提到过的一个牛人，索罗斯的老师卡尔波普，他提出来的，这是一对很有意思的概念，这两种看上去很不相关 的东西，可以作为我们这个世界的基本隐喻，有一些事情属于钟，有一些事情属于云，在云计算的年代，我们更应该了解什么叫钟，什么叫云。

# 3.催产素

这听起来是一个医学概念，但是我要给大家讲的不是医学。大家可能注意到有一种现象，为什么人衰老的时候，会表现出一种常见的毛病，那就是啰叨，我们到底是因为什么而啰叨呢？为什么说树老根多，人老话多，这个啰叨的本质是什么？我讲的是催产素，想解释的是啰叨的本质到底是什么。

# 4.学与习

这是很平常的一对概念，我们经常把学习连在一起说，但学和习的差别，我们大大忽略了学和习的差别。孔子说学而时习之，那这两个概念到底有什么不一样？

我们每天在接触各种各样的信息，信息叫 Information，但是这些信息是否真的有用呢？

我们不停地往自己的蓄水池里头灌东西，是不是灌得越多越好呢？

学 和 习 背后 还有 一 对 概 念 ， 就 是 Information 和 Transformation，就是一个是信息，一个是转型，这两个词在英文当中看起来很相似，但其含义差别很大，我 们 如 何 实 现 从 Information 到 Transformation 呢？

什么样的学习才是真正有用呢？有哪一种学习其实也就是瞎耽误功夫呢？
