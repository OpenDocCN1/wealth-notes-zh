# 表达模式：阅读型、倾听型

我们接受教育有一个很重要的内容就是表达能力。我过去一直以为表达能力就是表达能力，没有什么差别，实际上表达能力至少可以分成两种：一种是阅读型，一种是倾听型。

什么叫阅读型？简单地说就是照本宣科型，他在说之前一定要很清楚地把这个东西写下来或者由别人把它写下来，列出很详细的大纲，然后他这样说出来效果非常好。

什么叫倾听型呢？倾听就是说他是在跟别人的对话当中整理自己的思路，他表达的最精彩的地方全是表现在他的应对型上，甚至是越刁难的问题越让他思如泉涌。

这种人他根本不需要纲要。如果你让他照着提纲来讲的话，他讲起来要不是语无伦次，要不就是干瘪无味，一点感觉都没有。但是当他把这个大纲扔在一边的时候，他滔滔不绝，口若悬河。

这就是两种类型，前者叫阅读型或者叫照本宣科型，后者叫倾听型。
