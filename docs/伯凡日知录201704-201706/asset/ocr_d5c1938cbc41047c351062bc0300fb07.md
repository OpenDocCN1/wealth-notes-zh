# 一、中国人为什么痴迷于玉

有个新闻，说在巴西某地发现了一块巨大的翡翠。我看那个照片比人也高好多，据说这块翡翠的估值在20亿人民币以上。

想象一下，如果这个世界不是一个全球化的世界，在巴西捣出这么一块石头的话，没有任何人在乎。它之所以值几十亿，是因为它知道这个东西是有人来买的。谁来买呢？我们中国人来买。

西方人对中国的好多事情弄不明白，其中最大的困惑之一就是：中国人为什么那么喜欢玉。玉本质上是石头，西方人也爱石头，他们喜欢的石头我们都知道，现在的女孩们也都喜欢的——钻石。

# 2、玉是中庸的石

我们中国人为什么如此痴迷于玉？玉本身就是一种石头，一种特殊的矿石。在《说文解字》里对玉的解释就是“石之美者”，就是石头里的比较好看的东西就叫玉。还有一种简化的解释就是温润而有光泽的美石。
