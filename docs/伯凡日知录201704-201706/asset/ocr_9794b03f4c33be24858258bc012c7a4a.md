# 5.16 | 职场的“中档化危机”

# —— 知识笔记 ——

# 一、中等收入陷阱

最近一个朋友告诉我，说他连续收到了7、8份简历，都是他的朋友给他寄过来 的。他不是人力资源总管，有人向他寄简历，是想让他帮助介绍工作。他看了这些 简历，发现这些朋友都有一个共同的特点，就是在公司工作都超过5年，有的可快 到10年了。

最近听说有一些公司在做隐性裁员，基本 上是针对年龄在35岁左右的这样一些人。处 于这种状态的员工，让我想到了一个我们 这几年经常听说的一个词，叫“中等收 入陷阱”。这是一个经济学上的名词，我 对这个概念也没什么研究，只是望文生 义，把它挪用到我想说的这个事情上。这 些朋友在职场上陷入了一种“中等收入陷 阱”中。

什么叫中等收入陷阱呢？就是说他按照年 头也好、贡献值也好，收入逐渐的上升来 了，但是也不够高，比新入职的员工虽然 高出不少，但是跟同年龄的、贡献值大 的、优秀的员工相比，他们之间的薪酬显 然有一个明显的落差。所以他们就会感觉 到不太爽。

很多老板其实很头疼在一个公司已经工作 了5年以上，但是又好像不知道把他往哪 搁的这么一批员工。这些员工一方面工作 能力很难说有多优秀，但是他们的工资却 是不能将就的。这样的员工与那些新来的 员工相比，他们在劳动力价格上显然是缺 乏竞争力的。那些员工虽然能力不那么讲究，但是工资是可以将就的。

# 二、中档化产品

处于这种状态的员工很容易让我们想到了 一类产品，我们把这种产品统称为“中档 化产品”。

比如说当我们进到一个服装店的时候，我 们很可能会留意到那些价格适中的产品和 品牌。但是很快我们的注意力就会转移， 因为讲品质、讲品牌，它不如此高端 的品牌，它们会显示出明显的弱势。尽管在 价格上好像有一些优势，但是当我们的心 思从品牌、品质转移到价格的时候，我们 又能马上看到很多价格上明显有优势的产 品和品牌。所以这一类产品常常是最先进 入我们的视野，但是也是被我们最终放弃的 品牌和产品。

我们在选择住酒店的时候，要不选择那些 经济型酒店（应该说这一类品牌还是很多 的）；要不当我们觉得要面子的时候，我 们就会去选择那些五星级酒店。最尴尬的 是那些三星级、四星级酒店，要面子没面 子，说便宜又不便宜。所以这类酒店在 我们内心占据的份额是很低的。当然，我 们就为它买单的机会也就很少了。

# 三、山坳人家

汉语当中有一个词叫山坳，所谓山坳就是 在两座山之间的一个低洼地。往左走是一 座山，往右走是一座山。我们人类选择居 住地的时候往往会选择这样的地方。因为 这地方有水，风不大，但是是两边的雨水都 会流向这边，所以它是一个宜居的地方。

但是在职场上，最不好的地方就是山坳。

说起来有点不尽人情，但是事实就是这 样，老板看着这些人是最不顺眼的。简单 地说，就是他们的性价比非常的低。当他 们在一个公司工作了5年以上的时候，他 们获得了某种安稳感，他们的人际关系不 错。新来的员工是不敢造次的，心里老老 想着做错什么事，老板会开掉我，或者会 失去加薪提职的机会，所以他们会比较谨 慎，做事情比较卖力。有意思的是他们 有的是力气，不是怎么在乎自己的付出。 与此同时，要求回报的意思也不是那么 强。

而工作五年以上的员工，一方面他们丧失 了对工作的敬畏。我们经常说敬业，当我 们提到敬业的时候，其实包含着对这个工 作本身的敬畏。这些年头长的员工他们很 自然而然的缺少一种敬畏心。也就是说他 们工作和学习的动力可能在不知不觉当中 在慢慢的消退，但是他们觉得自己在这里 工作时间长了，没有功劳有苦劳，工资是 不能够低的。再说，他们往往到了结婚生 子的年龄，生活负担也很重，所以他们在 薪酬上也很在乎。这一点跟那些新来的员 工是不一样的。

# 四、此地不宜久留

摆在这些处于山坳上的员工面前的好像 有两种选择。

一种是奋力的爬上左边的山，进入到那些 贡献值大，工资也很高的那样一个人群当 中。但是，他们必须要克服职场上的地心 引力，那就是惰性，必须要挑战自己的能 力。这需要很大的勇气，也需要花很大的 精力来让自己实现一个迭代和刷新。这说 起来容易，做起来很难。所以这个选择好 像是一种选择，其实对很多人来说已经不 再是一种选择。

看起来他还有一种选择，就是退回到那种 能力上不讲究，薪酬上也不讲究的那个人 群当中去，事实上也不可能。因为经济上 的压力、个人的尊严已经足以阻止他走向 那个山头。所以处在这个山坳上的员工其 实选择的机率是越来越少。

我好像对中年危机有一个定义，就是要求 越来越高，能力不见长，机会又越来越 低。在这种情况下，他逐渐会陷入到一种 静静的绝望当中。

过去说人挪活，树挪死，问题在于这样的 员工挪的机会会越来越少，冰冻三尺非一 日之寒，他不得不为他历年来积累的惰性 和被动来买单。这就是在职场上的中档化 危机。

日本的企业在精益生产和质量管理上有 一个很重要的理念，如何消除质量问题？那 就是在问题发生之前就消灭这个问题。当 质量问题已经出现以后，不管你用什么方 法来解决都可能是，既是低效率，又是高 成本的。或者说看起来好像有出路，实际上 已经是没有什么办法了。

我今天之所以讲到这个问题，首先是对我 自己的一提醒。“人到中年”，人到中 年，你就不知道不觉就成了山坳人家。陷入 到其实已经很深重，但是好像又不那么明 显的危机当中。我们通常把这种危机形象 为温水里的青蛙。

我记得中国好几个企业家是在40岁，甚至 在40岁以后创业的，人到中年开始创业， 这是一件很奇怪的事情。他们当初创业有 的是被迫创业，有的是不知深浅糊里糊涂的 踏上了创业这条不归路。既然到了那一 步，他们就像一只扑到开水锅里头的青 蛙，他必须顽强地从那个开水锅里头跳 出来，结果就免于成为在温水锅里头被逐 渐煮死的青蛙。

听到这里，大家可以拿出一张白纸，用笔 在白纸上写下一个大写的英文字母M，看 着这个字母想一想自己到底是处在哪个位 置上。如果不幸正好处于中间的那个最低 点的话，我们有没有勇气、动力、办法， 让自己离开这个地方。因为这个地方好像 很平稳，其实很危险，此地不可久留。

> 平静的地方往往最危险，此地不宜久留。

——吴伯凡《职场的“中档化危机”》
