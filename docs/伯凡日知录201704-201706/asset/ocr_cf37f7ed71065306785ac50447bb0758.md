# 案例：奥地利的均势外交

这个案例来自《战略》这本书，罗辑思维也有一期节目讲这个。

奥地利这个国家的外交政策，可以叫“均势外交”。它有一个外号叫“布娃娃帝国”——可爱，但是不强大。但在19世纪的欧洲，奥地利扮演了非常重要的角色，一直stones到一战以前，奥地利的维也纳就成为了欧洲的中心，那个年代有头有脸的人都在维也纳混。

为什么奥地利在这些强国之间，居然还需要能够长袖善舞？原因是它把握了战略的本质。

说到战略就会想到一个与战略对应的词，叫战术。一般说来战略是战术的对立面。为了区别战略和战术，罗胖用了一个比喻，叫“围棋和象棋”。

我们在下象棋的时候，头脑里一直出现一个词，就是“将”。将死他，就是一招让对手完全失去反抗能力，自己也就获得了全胜。

我们在下围棋的时候，想到的不是如何把对方搞死，而是要尽可能让自己的子多。用一个很简单粗暴的比喻，就是拳击当中是以点数取胜，还是单拳击倒。围棋更强调点数取胜，象棋讲的是一拳击倒。

这两者的差别有点类似于战略和战术的差别。我们还可以说，战术常常是单次博弈，而战略是多次博弈。在制定实施一个战略的时候，应该想到的是如何玩下去；战术常常是如何不玩下去。

在这个意义上说，战略首先是要寻找一种均势。为什么要寻找均势呢？就是只有在这个均势里，你才能够继续玩下去，同时谋求某种持续的优势。

# 案例：为什么说捉放曹是一种战略

在捉放曹的故事里，如果诸葛亮派张飞去守华容道的话，张飞看到曹操肯定是二话不说，曹操的人头落地，这事就完了。但是诸葛亮是战略家，他不可能派张飞去，他又要抓他、又要不抓他，这样他就选定了关羽这个人。关羽在浑然不知的 情况下，替诸葛亮实施了一个很重要的战略。

诸葛亮要保持三国之间的均势，而不要因为曹操的突然死掉，结束了三国之间的均势。只有在这样的一种均势当中，刘备才会有生存空间；一旦打破了这个均势，也就把自己给连锅端了。这就是那句谚语，骑着树枝锯树枝，一定不要锯你骑的那根树枝。战略就是这样一种看似矛盾的，既要锯树枝，但是你又要保护树枝。

所以对战略还有一个定义，就是“有选择的舍弃”。就像《菜根谭》里有一句话——必胜非勇，可胜可不胜为真勇。抱定必胜的目标去打仗，顶多是一个战术家、一个执行者；而真正的战略家是要通盘考虑每一个阶段、每一个动作对于整体的贡献率。

摆在诸葛亮面前的任务：

第一，战胜曹操。在这一场战斗当中战胜曹操，给赤壁之战这场战斗画上一个句号，你输了，我赢了。但是更重要的是，他要维护整体的战略均势，给自己留下空间。我们下围棋的时候，每下一颗子，都要意识到是在给自己留空间、还是在给自己刨坑。只有战术思维、没有战略思维的人下的棋往往是这样，表面上他赢了，其实是在给自己挖陷阱。

第二，如何驯服关羽和张飞这两个对他一直很不服气的人。他明明知道关羽会放曹操，他让关羽事先立一个军令状。当关羽把曹操放走的时候，既实现了他的整体战略，同时在他跟关羽的这场交战中也画上一个句号，因为关羽已经欠他一颗人头。面对这样一个结果，张飞也会老实起来。

所以诸葛亮捉放曹，是一个战略行为，或者说是包含多种战术在其中、最终让每一个战术只是战略的一个器官而已，这就是战略和战术的最重要的区别。

# 案例：金门、马祖的战略意义

这不是一个新鲜的案例，但是可以给出一种新鲜的解读。

台湾和大陆之间的两个小岛，是金门和马祖。在中国的历史上，这两个小岛一直是属于福建省的。也就是说国民党占领台湾的时候，在理论上占领了两个省，虽然他只是占了福建省的两个小岛。

如果有人想搞台独，就必须要把这两个岛让出来，谁敢搞两个中国，就要把属于大陆的土地还给大陆。如果大陆去打金门和马祖，根本涉及到对台的战争，我们只是在收回我们大陆的一个省份——福建省，在海上的两个小岛。只要你说台独，大陆占领金门和马祖这两个岛是完全符合法理的。

最重要的是，在历史上无论是郑成功收复台湾，还是康熙收复台湾，都有一个事实：只要占领了金门和马祖，台湾是一定会被攻下的。所以有人说，金门和马祖相当于台湾的麻筋，我只要一踩，你立即就软了。

国民党占领金门和马祖，表面上是获利了，但实际上这是它的负资产，所以台独是一件不可能的事情。

这里就能看出战略和战术的区别，如果从战术上考虑，占领金门和马祖应不应该？答案是显然的。但是在战略上，用欲擒故纵的态度，让国民党占领这两个小岛，其实是战略的考虑。
