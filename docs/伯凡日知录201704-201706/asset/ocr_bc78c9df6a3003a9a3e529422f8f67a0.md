# 用户留言

Ethan

留言是一个很好树立假想敌的方式，对流言的要求不仅仅是能够把这篇文章的意思给表述出来，更重要的是在理解的基础上，能够提出自己的见解，指导自己的生活，自己怎么样去改进，这也是强迫自己跳出舒适区的一个方式。

另外一种方式是每天晚上花五到十分钟的时间回顾自己一天看了些什么东西，每一篇文章最重要的点在哪里，自己学到了什么，这样有利于让自己摆脱那种虚幻的获得感，真真正正知道自己理解了什么东西。

最终极的方法就是写一篇文章或者做一个演讲，这就是强迫自己有结构有逻辑的输出一个观点，在这个过程当中，自己对于一些概念，对于概念和概念之间的逻辑连接的弱点，就全都能暴露出来了。
