# 本周问答 | 心灵越狱，才能俯视生活的桎梏

本周问答 | 心灵越狱，才能...

恐惧和贫鸨很容易让人洗脑，再凶的老虎饿上几天就屈服了。万阳是强人啊，可是我必须赚相对多的钱，让自己和家人相对舒适一点，我心才安宁。也许我们普通人一开始就输在起跑线上了，“从小没有立志”，一步输，步步输。老师您说我们普通人还有救吗？

吴伯凡

这个问题以及提问的方式其实我们大家都很熟悉，我立即联想到以前热播过的一个电视剧，女主角以很快的速度语气，把她每天面对的账说一遍：每天早上起来我要还银行的按揭，是四百几十几块钱，我还要还什么什么，有多少，小孩儿上幼儿园我要花多少钱，每天菜钱是多少……只要一醒来就觉得自己欠了多少钱，绵绵无绝期的还债。这也有点像出租车司机早上一起就觉得自己欠了多少钱。

这样倒<|message|> 是目标很明确，每天早晨醒来你知道你该做什么，但这种状态的可怕不在于每天的债，而在于你最后形成了一种还债式的人生，每天还不得还的各种小账。

如果是这样的话我可以说没救，真的没救。

那怎么才有救呢？我又想到另外一个电影——《肖申克的救赎》，它叫救赎，它不叫救。人 的阶段性目标特别明确、陷入到一种还债式思维的时候，人心理上同时具有两种倾向：

第一，尽快的筋疲力尽地把每天的账还完，在疲惫当中睡去，在绝望当中醒来；

第二就是希望有一个奇迹，希望生活中出现某种奇 迹，一下子把自己欠债全部解决。所以一般处于这种状态的人有一个特点，就是爱买彩票，总希望用两块钱来解决他人生的根本问题。

这就是说一方面他有阶段性的目标，这个阶段性的目标很细，另一方面他还有一个长远目标，但是这个长远目标一方面是虚无缥渺的，另一方面他付出的努力也是很小、很轻，很没有风险的。

在这两者之间还有一种方式，那就是像《肖申克的救赎》里头的安迪那样，设定一个遥远的、看似缥缈但是又很实在的目标，第二是每天为这个目标不断地努力，尽管这种努力看上去几乎是微乎其微。

他设定了第一要越狱，第二越狱以后要做一个自由人，而不是一个已经被监狱的生活悄悄割裂了的人，因为他的狱友、他的两个好朋友，就陷入了出狱以后得到自由，却不知道拿自由怎么办的状况。而他不是，他从一开始人 在监狱但心不在监狱，或者说他越狱的第一步是从心理上越狱，每一天付出的努力看似根本不能解决他当下的问题，但是他一直是朝着那个远大的目标，一直是跟那个远大的目标有关的。十年如一日，终于有一天他每天微小的努力变成一个实实在在的结果，所以他越狱了。

在监狱里头种种看似没有意义的事情，每天帮典狱长去理财，最后实际上是在为他自己理财。他在监狱里头干的是没有报酬的工作，实际上直到结尾的时候我们发现，他在入狱以前他是一个银行家，在监狱里照样是一个银行家。18年的岁月其实他只是变换了一个工作地点，最终他得到的财富是一样的，只有这样才可以说是有一救的。

从根本上改变你的思维方式，就是超越你的阶段性目标，超越眼前的苟且，来看世界、看自己，悄悄地开始一个新的游戏。

每一个中国父母不可回避的问题：对孩子未来的设定似乎在其呱呱坠生之前就已经被量化了，恐惧与焦虑的心态在之后的K12教育过程中如影随形。形成这一普遍性社会顽疾的根源在哪里？

吴伯凡

我们以前讲到过归因偏差、归因谬误，一个结果出现的时候去追溯它的原因是一件非常困难的事情。我们在归因的时候容易陷入偏差、陷入谬误有一个很重要的点，就是我们常常忽视我们自己就是原因之一，我们总是置身事外地在看原因，其实我们自己就是原因之一。

在股市上存在着自我实现的预言，就是说一旦有人说了一个预言股市要涨、股市要跌，某一只股票要涨停，某一只股票要跌停，看上去这只是一个预言，但本身这个预言就会成为一种原因，而这个原因本身之所以能够起作用，有赖于我们听到这个预言的人的行为。当很多人都相信这个股票要涨的时候，这个股票果然就涨，相信它跌的时候它果然就跌，跌作为一个结果它有多种原因，那些显而易见的原因之外预言是一个原因，听预言的我们也是一个原因。

我这样说的我是，当我们习惯性追溯原因的时候，我们不妨给自己一个提醒，我是一切问题的真正原因，或者说是所有原因发挥作用的一个关键因素。我记得罗胖说过，我们在孩子之间总会出现一个很常见又很奇怪的角色，就是“别人家的孩子”。别人家的孩子是会影响你、影响你的孩子，在别人眼里你的孩子也是别人家的孩子，当大家都在说别人家的孩子的时候，别人家的孩子作为一个巨大无形，不 知道在哪儿又无所不在的一个亦真亦幻的实体，就在暗中影响我们所有的给孩子实施教育、以及孩子接受教育的所有方式。

生活当中是不是就有伯凡老师说的那九个字就够了，还有没有别的钥匙。

吴伯凡

其实我只是举了一个例子，不同的场景里都会有不同的钥匙。

恋爱婚姻当中也还存在着各种各样的钥匙，有的钥匙甚至是根本不需要任何言语。有一种钥匙据说比较流行叫“万能抱”，当女生生气的时候、不高兴的时候，那个时候很可能她自己都不知道为什么不高兴，她为什么要生气。很可能是这样——反正不高兴先生气再说，然后再找理由。这个时候你怎么办呢？最好有一个办法叫“万能抱”。这个“万能抱”可能就是一把万能钥匙，在这个“万能抱”中她的  心情好了，心情好了什么都可以谈了，都可以捋开来谈。但是心情不好，这个时候她唯一要求的就是打开她的心扉，千万不要多说话。
