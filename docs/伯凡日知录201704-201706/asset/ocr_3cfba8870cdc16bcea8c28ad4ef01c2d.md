# 预告 | 受体——冲突背后的源头

预告 | 受体——冲突背后的...

《伯凡·日知录》的同学们，我们本周的话题都围绕着一个核心的概念来展开。

有些养猫养狗的朋友特别喜欢自己的宠物，同时又特别喜欢吃巧克力，他们己所欲施于人，把自己最舍不得吃的巧克力都给了自己的小狗小猫吃。结果，发现小狗小猫肚子坏了，甚至是出现了中毒的迹象。为什么会出现这种现象呢？

有些总裁上了总裁班，上了EMBA，学到了很多新鲜的管理理念、管理方法，在自己的公司里头推行。结果是EMBA学位拿到的时候，也就是公司破产的时候。为什么会出现这种现象呢？

为什么同样是辣椒，我们人吃起来特别辣，而小鸟感受不到辣呢？

种种现象的背后都涉及到一个概念，那就是 受体。我们所面对的世界都是我们自定义的世界，都是基于我们的感受能力、接受能力而对世界的一种反应的模式而已。

一个产品，我们觉得好的产品，我们觉得对性能、体验都特别好的产品，市场上为什么不买账?原因也在于，我们对消费者的感知能力、对他们的受体缺乏认真的探究和认知。结果，就会出现事与愿违的现象。

为什么有的人特别难以相处？为什么有的人很难步入婚姻的殿堂，即使结婚也会很快地离婚，甚至会出现连续\习惯性离婚的现象？这背后到底是因为什么呢？那回答是，还是跟受体有关，还是跟一种我们称之为离 婚基因的东西有关。这种东西其实是催产素受体的缺乏。

听完萌是一种竞争力以后，很多同学在问，萌跟钝感力有什么关系。我们从受体这个概念出发，对钝感力进行了比较详细的分析。我们无论是在生活中，还是在工作当中都会遇到沟通的障碍，都会出现我们不愿意遇到的种种冲突。如何管理自己？如何管理好自己的人际关系？如何更和谐地和他人相处？我相信听完本周关于受体的这几堂课，我们就会获得一个比以前更加清晰的认知。
