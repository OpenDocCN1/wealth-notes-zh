
# 本周问答 | 乌合之众与众愚成智矛盾吗？

本周问答 | 乌合之众与众愚...

笔者指出：乌合之众的群体是非理性的，也是非智的，KK又说超有机体众愚成智，他们的说法矛盾吗？还是两者关于群体的定义有什么不同？

吴伯凡

这应该说是一个很常见的问题，《乌合之众》是一本很老的书，希特勒、戈培尔曾经从这本书里头得到了很大的启示。KK说众愚成智，他的观点其实是来自于詹姆斯·索罗维基的一本书，叫《群体的智慧》，也有把它译成《百万大决定》的。

《群体的智慧》跟《乌合之众》观点好像正好针锋对，一个是群体导致愚蠢，一个说群体导致智慧。其实这两者根本不矛盾。以前我曾经说过，我们发现了显而易见的矛盾，产生了强烈质疑的时候，往往是因为我们的观察，我们的思考不够细致，不够深入导致的。

《乌合之众》的作者叫勒庞，他所描述和分析的是这样一种现象，就是当大量的人群聚集起来以后，就会产生一种超级的愚蠢。这些人也许并不那么愚蠢，但是由于聚到一起的时候，他们的智力会集聚下降，会做出种种愚蠢甚至疯狂的行为，表现出一种是歇斯底里的状态。众多的人聚集在一起，智力下降是有几个前提条件的。

# —— 知识笔记 ——

最近最火的书之一就是《未来简史》，有个爱较真的同学他就问我说，未来还没有来，你怎么就叫简史呢？历史是指过去发生的事，未来还没有发生，你怎么能够给它说叫未来简史。

现在叫简史的书有几个特点，一个是一般比较畅销。当然应该反过来说，畅销的书里头有很多叫简史的。你比如说我写本简史就未必能畅销。简史成为了一种文体，我们把它叫简史体。大家可以在脑补一下，我们买过多少，买过不一定看过，好多叫简史的书。第一本叫《时间简史》，历史就是指过去时间里头发生的事情，这个《时间简史》它怎么会有历史呢？历史本身就是时间，时间怎么会有历史呢？这也是一个悬念。后来我们还买过或者读过《万物简史》，还有一本书叫《世界是平的》，曾经也很畅销，它的副标题叫二十一世纪简史。这本书出版的时候，二十一世纪十年还没过去呢，听起来也是很荒唐的，二十一世纪刚刚开始就要写一本二十一世纪简史呢。应该是在2106年，而不是2006年写这本书嘛。到底这个简史是什么意思？

当然，最畅销的书就是在《未来简史》之前还买过和读过一本书叫《人类简史》。《人类简史》听起来很顺，这本书的内容就是对迄今为止人类过去发生的一些事情的评述。但你如果真的读这本书，你会有点失望，那里头并没有讲太多的史实，或者说它只是在讲一种学说，一种假设，一种理论的同时用一些历史上的事实和案例作为佐证。它讲的其实是一种理论，顺带讲了一些历史的事件和案例。

+   1. 世界越来越呈现为一个各种各样的屏幕，不管是大的电视屏幕，还是手机屏幕，还是电脑屏幕。这个屏幕的特点就是平的。世界是平的意思就是世界会变成各种各样的屏，我们跟世界打交道就是跟各种各样的屏幕打交道。
2. 过去处于很有优势的这些区域，这些民族，互联网作为一种强大的推土机把世界的原来的那种有等级，有阶梯的状态变成了一个扁平化的世界。

我们知道《人类简史》其实无非就是讲了一个逻辑。

人类最早跟其他的哺乳动物，跟高级的动物、灵长类动物没有什么太大的差别，如果有差别的话常常是劣势。比如说我们的祖先，生活在东非草原上的那些祖先跟大猩猩相比，如果仅仅是作为一个动物的话是没有任何优势的。一个800磅的大猩猩可以把一个个头小一点的人手撕，新撕布娃娃一样的撕掉，手撕人类这样的悲剧常常在东欧平原上演。但问题是，那么弱势的动物，它们是怎么逐渐的成为这个地球的主宰。我们人类叫智人，自以为很聪明的，自以为自己很有智力的这些人在安排着这个世界，然后把大猩猩不是关进了动物园就是关进了动物实验室，有的心情好的时候让它们在野生动物园待一待。为什么会出现这种状况呢？

赫拉利认为这背后有一个根本的逻辑，就是大猩猩也有心理活动，也就是说它有它的主观世界，它也会想办法，比如说猴子，猴子它能够在椰子成熟的时候，它能把那椰子累积起来，放在有太阳大的地方晒，晒上一个七八天以后，用大石头砸，一砸就给砸开了，证明它们是有想法的，它们是有主意的，所以它们是有精神世界，是有主观世界的。

同时它们也知道有一个客观世界，它们在用它们的智力，已经不低的智力跟这个世界博弈，它们能够描述世界。那边来了一头狮子，那个地方有好多香蕉已经成熟了，要去摘等等，它们对客观世界也有一个认知，但是它们有一个根本上的能力的缺失，也就是说它们没办法完成一个认知升级。这个升级在哪里？人类会讲故事。这个故事就是彼此陌生的人因为一个故事，大家就能够建立某种信任，建立一个游戏规则，大家就可以合作。

就像我们今天面前站着一个人，你可能没有感觉，他一说他是某某省的某某县的，你一听还是小老乡，你们之间很自然就有一个合作的愿望了。这个所谓的传说就是一个故事，因为这个故事，你们就可以在瞬间从陌生人变成合作者。还有，像美元这样的东西，它其实是一个故事，就是说你相信了你拿着这张纸去换一堆东西，那个人他为什么能够把这个东西给你，是因为他也相信他拿着这张纸也可以从别人那里换来一堆东西。

当所有的人都相信这个故事的时候，再陌生的人都能够建立合作，那么就可以聚集起巨大的陌生人群进行大规模的协作，10个大猩猩可以合作，100个大猩猩就不容易合作，10000个大猩猩会打起来。人类10万人可以坐在一个体育场里头，但是10万大猩猩坐在一起就完全不可能的。这就是赫拉利发现了这样一个逻辑，那就是因为有了编故事，讲故事，有能够很优雅，很体面，很学术的悠悠的这样一个能力，使得人能够建立一种信任体系。所以人类就终于从一个并没有什么优势的动物变成了主宰整个地球的动物，这就是《人类简史》要告诉我们的。至于里头讲到的那些历史事实和案例不过是用来自证他的这个观点的。

我们简单的总结一下，所谓简史就是指历史的逻辑，它的意思并不是指简单的历史，而是指历史的逻辑，或者说从历史的事实当中抽取了一个可以贯穿整个历史进程的一个隐性的规律，它讲的就是规律和逻辑。

《万物简史》也好，《人类简史》也好，《未来简史》也好，《二十一世纪简史》也好，包括《时间简史》等等，它们讲的都是发展逻辑，时间的发展逻辑，未来的发展逻辑，二十一世纪的发展逻辑。

# 狗的驯化

狗是最早被驯化的动物，有人说是一万八千年以前，有人说是两万八千年以前，我最近看了一个资料有人说狗有可能是四万年以前就被驯化了。我们就说两万八千年吧，那是一个什么样的年月？是人类还没有文明的时候。

埃及人很自豪，说他们有七千年的文明，我们中国人说我们有五千年的文明，不管你的文明有多久，你不会一万年，而狗在人类的文明来临之前，就已经成为人类的伙伴了。大家可以想象那样一个场景，那时候地球上的人口是很少的，一个一个的小部落稀稀拉拉地分布在地球上，狗一旦跟某一个部落形成了协同关系，它切换主人的机会是很低的。因为下一个部落在几十里之外，而且那个部落也可能也有狗，那已经是别的狗的地盘了，它一旦跟形成战略联盟，它是不大可能跳槽的。

那个时候也许会有那种不太忠诚的狗，但是它已经被饿死了。那些狼不狼狗不狗的动物早已经不存在了，只有坚守在一个小小的部落里面的狗，它才能活下来，它的基因才得以保留。所以说不嫌家贫这样一种忠诚的特点已经成为狗的基因。

# 猫的驯化

猫是一种很晚才被驯化的动物，人类驯化的这些动物当中，猫和马都是比较晚的。

猫可能更晚，猫和狗的驯化隔着一个时代，狗在人类还处于游猎时代的时候已经被驯化了，而猫是在人类进入农业时代以后才被驯化的。

世界上最早的谷物产生于两河流域，就是今天的伊拉克那一代。很快这个谷物，也就是小麦沿着同纬度往西传，传到了一个不是太远的地方，这个地方叫尼罗河三角洲。

尼罗河三角洲是一个很特殊的地方，因为它处于地中海的东南角，地中海气候的特点就是降雨量很少，气候很干燥，有一定的降雨，但是降雨的时间很短。所以这个地方的空气都很干燥，尤其是地中海南岸都是沙漠。

尼罗河三角洲作为一个农业基地，相对于整个地中海南岸，也就是北非这个地方可以算是一个非地，它跟周围的东西不搭界，莫名其妙地出现了。为什么在紧邻沙漠的地方会出现那么大的一個产粮区呢？是因为非洲中部的充沛的降雨再加上非洲中部的肥料，也就是说火山灰借助尼罗河，每年定期地就送到这个地方来。

现在在农业领域流行一个词叫“水肥一体化”，就是把肥料融入到水里，灌溉的时候同时就是施肥。这是一种很先进的现代农业技术，可是在最古老的时候，尼罗河就实现了水肥一体化，尼罗河的河水中当有大量的火山灰，火山灰是天然的肥料，所以每年尼罗河泛滥的时候，一方面带来了水，同时也给这个地方施了肥，最重要的是它是每年都要施肥。所以这块地方是非常肥沃的，撒下种子就能长。所以尼罗河三角洲就成了人类历史上最早的，也是最大的产粮基地。于是相应的就出现了一种东西叫粮仓，大量的粮仓在埃及出现了，有粮仓的地方就会有老鼠，这个老鼠找到了天堂，当老鼠找到天堂的时候，另外一种动物也找到了天堂，那就是猫。那个时候它还是野猫，但是由于粮仓周围出现了大量的老鼠，也就同时聚集了大量的野猫。这时候这些野猫跟人类就有了第一次紧密接触。

在狗被驯化的时代，人烟很稀少，当狗投靠人类的时候，它真的是豁出去了，因为狒狒那边吃不着食，在人这边也只能非常可怜地啃骨头，狗的食物一直是处于匮乏状态。而猫从一开始，它就是脚踏两只船，因为猫在跟人类接触之前，它已经开始吃田鼠，田鼠在田野里到处都有。猫跟老鼠的脚步于人类产生第一次紧密接触的时候，它不像狗那样面临着食物匮乏的巨大挑战。所以它跟人接触，但是能够保持一种游离的状态。

猫跟人的关系是一种若即若离的关系，它没有必要去依附于哪一个人或者哪几个人哪一家，它在田野和村庄粮仓之间自由地走动，这也就形成了它的那种高冷、神秘、落落寡合，偶尔亲近，常常远行这样一种状态。这一点它跟狗很不一样，没有忠诚基因的狗没办法活下来。但是猫没有忠诚基因，没有死心塌地的行为方式，它也能活下来。这就回答了为什么猫和狗的差别有那么大。

# 企业中的两种员工

为什么要说到这种差别呢？我想到的是一个HR（Human Resources 人力资源）的问题。

创过业或者经营和管理过一家公司的人，可能都会认同一个分类，有些员工是非常忠诚的，有更多的员工，数量更大的员工是不那么忠诚的，前一种的性格接近于狗，后一种的性格接近于猫。尤其是在今天切换成本很低，在跳槽的可能性越来越大的个人跟组织之间的依附关系变得越来越弱的时候，显然猫型员工的数量会越来越多，狗型员工的数量越来越少。因为很少有员工会觉得离开了这家公司，他就活不了了。这可以说是一个世界潮流，浩浩荡荡，顺之者昌逆之者亡。

做老板的，你别老要强调员工要像狗一样的忠诚，别期望哪个员工到外面说我是谁谁谁们下走狗，这不大可能的。但是值得提醒的是如果你是在创业的话，您要尽可能地让你的创业团队，让这个狗型员工在你的创业团队的占有尽可能地大。如果从一开始猫型员工就很多的话，不仅仅是你做事情的效率会很低，最重要的是猫文化会成为你公司的文化。在文化基因上接近于狗的一些员工也会逐渐地变成猫，或者他觉得这不是他的地盘，他会离开。在这样一个闪婚闪离变得如此普遍的时代提忠诚可能有点滑稽，但是你要真正想做好一家创业公司，我们还是要琢磨如何让自己的员工，尤其是种子员工要有一定的高度的忠诚性。

我们前面说猫和狗在基因上的差别起源于他们食物来源的差别。在今天公司跟员工直接的纽带就是薪酬，一种劳作为雇佣和被雇佣的关系。但是我们要知道，工资已经不再是公司跟员工之间的唯一纽带了。如果公司倚着这样的纽带来把员工维系到一起的话，那是一件相当危险的事情。

说到粮食，还能想起一个词精神食粮。你给员工发粮的时候，工资是一个物质食粮，但是让员工对公司产生一种依存，产生一种离了你就很不舒服，甚至有点觉得活不下去的，哈哈就是你公司的精神食粮。我们每个月给公司老板发工资的时候都会体会到一种阵痛，每个月到了那几天，你都会体会到一种阵痛。但是我们应该明白的是，除了发工资之外，你还发了哪些东西，如果你仅仅是发了点物质食粮，而没有精神食粮，或者是精神食粮甚少。那么你就在做一件事情，就是把你的员工逐渐地驯化成与你若即若离的，高冷的、神秘的，像猫一样的员工。反过来我们需要想的是如何定期不定期地给员工发放精神食粮，他们吃了这些东西以后，也许会逐渐地形成一种狗不嫌家贫的习惯，对老板来说，这也许是一件很美妙的事情。
