# 曼鳅 Emma 1

假想敌的本质其实是学习的目标，微妙的不同在于"目标"是在你的前方，你向前需要去抓取的东西；而"假想敌"是一种外来的刺激，在你的后方，逼着你必须前进前进。两者虽然都是人的主观意识设定的，但是微妙的不同导致结果很大的差异。
鸡汤文里到处可以看到如何励志如何去实现目标，但是人啊，天性是好逸恶劳的，我们有太多的诱惑太多的惰性，导致我们走着走着就忘了目标，甚至会觉得原定的目标并不存在。

今天伯凡老师提到的"假想敌"对我深有感触，因为假想敌离我更近，ta可能就在你身后的一步之遥，你必须保持警醒加快向前步伐，不稳定才是真正的稳定。这种刺激让我们在学习中更能认识清事情的本质，不是为了囤积知识而学习，不是为了收藏文章而收藏，必须是快速的感知该知识是否对你有用，有用就迅速拿下，没用就暂时先丢（可以先缓存以后再看）。因为每个人的知识结构生活阅历都很不一样，可能在这个阶段对某个知识无法体会，但下个阶段再看时就如醍醐灌顶，大脑先建立的神经回路帮助了下一个新回路的形成。

创业的过程也是这样的，我们离失败永远只有一步之遥，每天要复盘在产品、团队、市场、运营各方面有什么潜在的漏洞。我们的"假想敌"并不是竞争对手，而是我们自己。促成一个成功的公司因素方方面面，但是失败的公司却有很多相似之处。

总结来讲，有一个"假想敌"能够帮助我们：1)时刻让我们保持危机感；2)迫使我们认清事物的本质。

# 年年歲歲 0

认知循环：
眼前的场景（假想敌）
-->映照出你的认知系统缺陷（原有的知识网络受到了撞击）
-->让你陷入不自在的不均衡状态，这个不均衡让你深深恐慌
-->试图调动既有的认知去维稳 -->意识到原有解释网络的不完备和缺陷，产生强烈的期待和渴望，放弃原来的认知，留出空位让新知识趁虚而入
-->完成知识的自我补偿，快速弥补欠缺，获得了暂时稳定和均衡状态
-->再次不自在，打破平衡
-->...
学习就是这种持续的"打破均衡，又再次均衡"的状态。每一次的再均衡都是提高，循环的周期越多，次数越多，迭代的速度越快。

就用走路来类比：
双脚站立（平衡稳定，却停止不前）-->迈出一只脚（不均衡，很累，很痛苦，但是在向前走）
-->快速落地，第二只脚跟上步伐（重新获取平衡，因为第一步迫使你不得不迈出第二步）
-->...
这就是一直往前走，动态中的不平衡，而且是持续的不均衡，远离平衡态的平衡态。
结果：耗费了力气，但是走的很远，同时锻炼的腿部肌肉，完成了肌肉的自我补偿。

想起了一句话："凡不能毁灭我的，必将使我强大"——尼采
