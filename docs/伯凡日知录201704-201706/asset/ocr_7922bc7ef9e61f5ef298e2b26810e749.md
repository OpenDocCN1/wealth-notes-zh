# —— 知识笔记 ——

昨天我们讲到了猫、尼罗河三角洲、埃及。讲的时候我就想到了埃及对面的一個国家，希腊。

其实那个时候希腊也不能算一个国家，它是一个地区。那里遍布着很多的城邦，雅典、斯巴达，有很多很多的那种城治国家。其实在希腊的城邦形成之前，有一个地方叫腓尼基。就是今天的黎巴嫩那个地方。过去是埃及的领地。

埃及当时国家大的时候，它的领土从地中海的东南角一直延伸到地中海的东南角这个地方。那个地方的人通常叫 nga 南人，也就是《圣经》里头经常说的迦南之地，应许之地。希腊人把那个地方叫腓尼基。

腓尼基是整个地中海文明的一个二传手。首先有埃及文明，因为有粮食，粮仓是埃及文明的基础，埃及越来越强大，它的领土沿地中海东岸向北延伸。
