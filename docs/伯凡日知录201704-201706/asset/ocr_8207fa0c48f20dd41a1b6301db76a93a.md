5.31 | 蛇的策略之一：极致

今天要讲的是一种相当常见、又相当特殊的动物——蛇。

# 一、早期人类对蛇的关注

我桌上有一本书叫《符号中的历史》，在各种文明的符号中都能时不时看到一个元素：蛇。在犹太基督教文明里，蛇是一种很有象征性的动物，它象征着邪恶，是魔鬼的化身。按《圣经》的说法，蛇本来是四肢健全的，长成现在这个样子是因为它勾引夏娃吃苹果，导致上帝愤怒，让它终生爬行，以土为食。

在印度教里，蛇的形象无处不在。在希腊文明里，蛇的形象就更多了，邪恶女神美杜莎，她的头发就是无数条蛇，希腊的医神阿斯克勒庇俄斯就是一条蛇，单蛇是医药的符号。

在中国文明里，蛇也是非常重要的象征物。我们都见过那样一幅图，人首蛇身的伏羲和女娲，尾巴交缠在一起，他们兄妹结婚合产了人类，所以我们汉语里对性有一个特别的说法叫交尾。中国龙的主体是蛇或者说蛇身，我们民间把属蛇的人叫小龙。早期的人类对蛇是相当关注的，这样一种动物饱含着人类诸多 phenomen 的想象。

# 二、残化的身体，恶劣的环境

蛇到底特殊在那里？应该说，它是一种典型的残疾动物，缺胳膊少腿，眼睛几乎看不见，甚至是全盲，很多蛇对声音是没有感知的。这是外表的残疾。同时它的内脏也是不健全的，肺只有一个，肝脏只有一叶。它的内脏是精简了再精简。

前不久我们讲过一个话题“核心劣势与核心优势”（见本公众号4月18日及4月12日内容），很多的组织生物核心优势常常是源于它的核心劣势。在这一点上蛇是非常典型的，由于它是一种典型的“残化动物”，它在这个世界上生存也就面临着巨大的挑战。

我们昨天讲到了汤应比的文明理论，文明本质上是面临外部环境的挑战而被激活的一种应战形态。文明如此、创新如此，在这一点上蛇是非常典型的，由于它是一个残化之身，所以它要生存在这个世界上，就一定要有特殊的应战手段或者说核心能力。

说到蛇我们马上会想到毒，“毒蛇”，毒跟蛇是连在一起的。但实际上毒蛇占蛇总量的比例并不算多，大概1/4到1/3。为什么会出现有毒和没毒的蛇呢？

我想起了黄鳝，黄鳝看上去跟蛇很像，但黄鳝是没有毒的，为什么呢？因为黄鳝生活在水里，水里太多小的供它吃的食物了，蛀蚓之类是非常充足的。面对蛀蚓这样的猎物，没必要动用毒液来征服，直接把它吞下去就完了。有水的地方生命就多，没水的地方生命就少，食物就稀缺。

在沙漠里，蛇可能多少天才遇到一个猎物，所以它要保证它打击的精准性和可靠性。它需要它的捕杀是万无一失的，仅仅靠物理的手段去征服猎物风险是很大的，对手逃脱的可能性就很大。生物的任何一种技能其实我们都可以把它理解为一种生存策略、一种战略，特殊的环境造就了特殊的战略，毒液就是在食物相对匮乏的环境里蛇选择的一种生存策略。

冷兵器时代是纯物理的，热兵器时代加进了化学的因素，再到后来出现了生化武器，杀伤力一个比一个强，对手漏网的概率越来越低，凶狠的程度越来越明显，毒蛇的毒液就是这样一种生存策略的担当。

毒液说白了就是一种蛋白质，它是一种特殊、饱含阴谋的蛋白质，当毒液进入猎物体内后，它可以顺畅地在体内流动。但它有一个特点，它很多的特性都跟动物体内担当不同功能的蛋白质是一样的，只有一个关键的不一样，就是它相当于肚底的特工。毒液打到一个机构组织里，要么就不作为、磨洋工，该担当的关键时候它让你掉链子；要不就是干脆破坏它所替代的那个蛋白质的功能。比如说响尾蛇的毒液，它是破坏人的凝血机制，光这一点就能够致人于死亡。

所谓“四两拨千斤”，无非就是让进攻所消耗的能量，跟最终结果之间形成巨大的不对称。毒液就是那种攻击力量和最终效果之间极不对称的一种武器，当蛇处于一种对手很少的环境中，没必要使用这样一种武器，当对手比较多、形态比较复杂时，也就意味着它的猎物数量减少、对手增多的情况下，它必须要用这样一种致命武器。

# 三、极致创新的“攻击产品”

我们知道生物体是非常复杂的，生物都有代偿和过度补偿的能力，当一个平衡被打破的时候，机会会调动各种各样的能量和机能来恢复这种平衡。如果毒液的功能很单一，就有可能不能很快让猎物丧命，甚至能被安全地逃脱，所以毒蛇在进化过程中也是不断创新的。

蛇毒的种类有100多种，而且毒素的成分也不是单一的，它是一种复合型毒素。化肥里有一种肥叫复合肥，复合肥的肥力要比单一的化肥肥力要强得多。很多蛇的毒液都不是单一的，就是为了形成一种组合式攻击。我们在投资的时候讲投资组合，我们在产品布局的时候讲产品组合。毒液也是一种为了确保它攻击的有效性，而实施的一种解决方案。

要达到攻击的有效性，毒蛇不仅让它毒液的毒性很大，还要最大化利用它的毒液。早期毒蛇的牙齿进化出一种凹槽，这个凹槽相当于一个盖子，毒液出来以后，它把毒液罩住，确保这个毒液能够全部进入到猎物的伤口。在进化的过程中，凹槽变得越来越深，后来干脆进化成一种像针头一样的牙齿，能够确保毒液一点都不浪费，直接注射到猎物的体内。

现在看来蛇真的是一个处心积虑的动物，它在为了确保它攻击的有效性，它把它的功能创新进化到了极致。雷军同志七个字的互联网思维里，不是有 一个“极致”吗？蛇在蛇毒这个产品的研发上上的确做到 了极致。做到极致无非就两个目的或者说是合二为一的目的：尽可能地节省成本，尽可能地增加效能。现在我们也就理解了毒蛇为什么这么毒。
