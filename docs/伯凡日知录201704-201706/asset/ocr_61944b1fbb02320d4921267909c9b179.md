# 本周问答 | 如何知道自己是什么“材”（周日直播预告）

本周问答 | 如何知道自己是什么...

Yao Tong：看到吴老师周末有直播很期待，可惜周末晚上上课去不了了，如何破解？

吴伯凡

这么重大的一个问题，我先说说那天是4月23日，是世界读书日，正好这一天直播我想和大家谈四本书，为什么要挑这四本书呢？首先这四本书很薄，我不希望说一本很厚的书，心里知道别人肯定不会读，自己在那儿说得津津有味。

我为什么要挑这四本书呢？是我自己有这么一个小小的执念。所谓在我们这个时代读书是一件不太容易的事情，因为我们都处在一个过度互联的世界，真正的读书或者写书，都必须要为自己找到一个属于自己的洞穴。

什么叫洞穴？洞穴就是互联度为零的一个空间，你不跟周围所有的东西联系，不被随时可能到来的信息所打扰，将自己的注意力放到一个单点上，在这个单点上进行纵向的突破，而不是东张西望。

这四本书跟普通的书不太一样，一本是《活出生命的意义》，是一个叫弗兰克的作者，写的是他在奥地利辛集中营的生活，他的感受、他的思考，那是一个没有任何互联度的空间，在这个空间里头他感受到了某种我们在平常的场景下完全感受不到的那种体验。

还有一本书叫《狱中书简》，作者是一个试图刺杀希特勒而未遂，最后被抓进了纳粹的监狱，这本书就是他在监狱里头写下的书信。

还有一本书叫《仙人》，写的是一个企业家在修道院里头一周的生活，这也是一个封闭的空间，一个洞穴。

还有一本书，我很久以前谈到过，前苏联时期的一個作家写的一本书，那是一本很短的传记文学，写的是一个叫柳比歇夫的科学家，他创造了一种叫做时间统计法的自我管理的方法。但它不仅仅只是一种时间管理方法，他从20多岁起就为他每天所花的时间记账，从此再也没有间断。在以后的生活当中，他随便打开某一天的时间账本，他就能够复盘过去的一天，他是那种能够站在时间的河流旁，清晰地回顾他生命当中的每一天的那种人。

这四本书可以说是我的老朋友，是四本伟大的小书，我把它们放在床头，时不时会拿出来翻一翻。很长时间我没有看它，都会时不时想起这几本书，属于那种从来看不提起，但永远不会忘记的小书。在世界读书日这一天，我想跟大家分享这四本书的内容。

至于直播看不了怎么办，我们会把直播的文字发表在下周六，因为平时周六是不更新的，刚好有空档。但是可以就书单先提一些问题，直播中我们会选取一些有趣的问题与大家互动。

晴天：老师，现在越来越多的人在讲个性化教育，其实这也算是因材施教版本的教育的另一种实现。那么，问题来了，我们如何知道自己是什么样的“材”呢，比如您是什么时候怎么发现您适合做商业评论的呢？

吴伯凡

这是一个很个性化的问题，涉及到我个人的，我尝试回答一下吧。

在那期节目里我着重提醒大家的是那种去个性化的、工厂化的教育方式，如何内化为我们自身的学习方式，我们不知不觉地接受了这样一种观念，那就是存在着一种唯一正确有效的学习方式，适合于所有的人。

我们在进行终身学习时，忘了首先搞清楚自己到底是什么样的“材”，同时也没有仔细地考量识别到底是什么样的学习方式适合于自己。在这两个问题没搞清楚的情况下，就匆匆忙忙地开始了学习，其结果很可能是以不断地努力证明自己永远不能成功，越努力越焦虑，越焦虑越努力。
