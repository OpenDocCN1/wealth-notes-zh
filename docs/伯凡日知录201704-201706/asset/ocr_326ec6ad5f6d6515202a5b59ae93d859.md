老师，我觉得很委屈，我也不愿意成为“中档化产品”，但是年轻的时候被安排到一个固定岗位上任劳任怨，现在年纪大了，家里负担重，熬夜又比不过刚毕业的小孩，这能怪我吗？我又能怎么办呢。

本周我们关于职场中档化危机的内容，引发了好多同学的思考。其实我录完这期节目以后，心里就有点不安：这样说是不是会很粗暴，会伤到一些很善良、很努力的人的心，所以我里面特别说了到，我其实是对我自己的一种反省。

有两个同学提到了相似的问题，这些问题我念着都很沉重。我把国印同学的问题简化一下，变成一个问题：中年到底意味着衰年还是盛年？

# 一、知识权力与职务权力

我们现在看到中年就意味着很衰，但这不是我们陷入悲观的理由。事实上虽然中年危机在国外也是一个很普遍的现象，但是跟中国相比，有很多国家不是像我们现在看到的情况这样触目惊心，比如说在德国和日本，这种现象就比较少。

原因很简单，因为这两个国家的制造业是经济主体，而且他们的制造不是简单制造，而是精密制造。在制造过程当中，隐性知识比显性知识更重要，而隐性知识常常是随着时间的增长而逐渐增长的，可以说尤其是那些我们称之为 Know-how 的隐性知识，其实是一种时间的玫瑰。

在国外，那些年轻的工人从入职开始，在长达20年的时间里头，他们是没有出头之日的。但是到了40岁左右的时候，他们会觉得迎来了人生的盛年。原因是什么呢？这里有一个概念，叫知识权力，由于他们隐性知识的积累而获得的一种权力。这要从两个方面说：

+   1. 一个公司的成长，是否依赖于那些只有时间中才能积累生存的能力和价值；
2. 这些在里面工作的人，是否随着时间的流逝，自己的能力也在增加。

如果一个公司雇佣你只是因为你显而易见的那些能力，甚至只是你的体力，比如说搬运公司、过去的码头工人，那当然你过了中年，就很成问题了。但是如果你所在的公司，竞争力是有赖于那些长时间在这个行业、在这个企业工作的人在时间中积累起来的知识，那么随着时间的流逝，你的知识权力在增加。

> 英特尔的前CEO格鲁夫说，一个公司的盛衰取决于两种权力的博弈，一种是职务权力，一种是知识权力。

什么叫职务权力呢？用我们现在一些公司的话说，是走管理路线的，管理路线就是一步步往上升。大家要知道，管理的岗位是呈金字塔型的，越到上面职务越少，那就意味着只有很少的人能够一直往上升，如果你在公司里谋求职务权力，你也就选择了一条上升空间其实是很少的这么一个路径。

在一个可持续成长的公司里，还有另外一种权力，那就是知识权力。在一个公司里头到底是谁说了算，是管理层说了算，还是说在不同领域里、不同层级里的那些真正拥有知识的人说了算？在格鲁夫看来，知识权力大于职务权力的公司才是能够持续成长的。可惜的是，我们现在中国很多的公司不是这样的，它基本上是职务权力远大于知识权力，甚至根本不讲什么知识权力，这样的公司特别的多。

# 二、泡茶型公司

一些初级的制造企业为什么要 employing 民工？原因是：第一，这些人精力充沛，通宵加班都没有问题；第二，他的工资很低；第三，千一段时间以后，你不让他走，他也要回到老家结婚生子。

我把这样的公司叫做泡茶型公司，员工就像茶叶一样，扔到这个公司里，他把你的精华经过几泡以后泡完了，你作为茶渣就可以扔掉了，那是很恐怖的一种状态。

当然这种情形是比较极端的，有些公司表面上好像不是泡茶公司，但实际上由于他的上升通道只靠职务权力，公司里并没有有意识地去发展、强化知识权力，那么他根本就不要求你拥有知识；同时大家连到这个公司之后，可能自动地放弃了在知识权力上上升的这样一种愿望和冲动。

当我们进到这种公司的时候，从一开始就要有一个风险评估，我愿意作为一包茶叶扔到这个公司吗？他泡了几泡以后，我愿意作为茶渣给倒出来吗？或是一直在那儿混，开水不停地加进来，味道越来越淡，虽然还没有把你赶走，他也觉得意思越来越不大，你也觉得意思越来越不大。

当然对于员工来说风险更大，因为公司还可以经营下去，而你作为已经被泡得很伤害的员工，出来是没有公司愿意再泡你的。

# 三、网状权力体系

我们回到建设性的层面上来考虑这个问题，如何避免中档化危机。

其实在节目里我已经说到，我们在一个公司里头不能自甘沉沦，你进到公司的那一天其实很可能就意味着增殖（见本专栏2016年12月29日内容《直面熵，是种座而死》），如果不做熵减的工作，你不采取措施避免让自己的熵增加，你就会不知不觉地成为山德里头的人，那到时候你很想爬到山顶上去，但是你已经力不从心了。

第二，选择职业的时候，一定要选择那种权力体系不是线性的、而是网状权力体系的公司。也就是说不能选择一个逐渐的从一个小卒子，通过苦熬最终做到副总的这样一条路径，这是一条线性的路径，非常单一，最终你发现你在打擂升级的时候，会越来越难，你每往前走一关，就意味着你自己被淘汰的概率越大。

例子：德国制造业

在德国的一些制造企业里，有一个特殊的待遇，就是工厂里的吸烟室，只有那些40岁以上的工人才能进去，那是对这些人的一种特殊的待遇。从这一点上你都能看出，它是一个知识权力大于职务权力的公司。你可以一辈子都不用升官，但是你可以去发财。

例子：“八级工”

中国在四十五年前有一种制度，我觉得挺有意思，就是走行政级别可以从科长、处长，一直做到大厂的厂长；还有一条路径，就是你可以从一级工到二级工，一直Reflected to 八级工。一个八级工的工资相当于工厂里头的总工程师的工资，可以养活一大家子。

这种路线，我觉得中国以后，这种多元化权力体系、强调知识权力的公司，而不是单一化权力体系、强调职务权力的公司，会越来越多。

在职业生涯的第一步你要选对公司，投胎也要投对，只有进到这样的公司，你才可能在中年的时候，你会迎来你人生的盛年，而不是人生的衰年。也許你并不能當上官，但是你拥有一双金子般的手，官再大的人都觉得他们离不开你的时候，你就拥有了一种权力，这种选择就是知识权力。

# 总结：努力、选择同样重要

当我說職場的中檔化危機的時候，不是在唱一種悲觀的論调，首先是一種提醒。

其次，无论处于职业生涯的哪一个阶段，尤其是对于刚刚进入职场的人来说，女怕嫁错郎，男怕入错行，不僅不能入錯行，而且你要进到那样的公司，那些永远是知识权力大于职务权力，至少不是知识权力明显小于职务权力的那样的公司。它是一个多元化的进阶体系，一种网状的，而不是线性的进阶体系的那样的公司，我们才可能免于中档化危机。
