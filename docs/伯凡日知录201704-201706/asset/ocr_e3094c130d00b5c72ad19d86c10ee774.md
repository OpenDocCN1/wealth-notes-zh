# 一、战略资源不要消耗在非战略节点

我们讲到口令思维时（见本专栏5月10日内容《公关危机、婚姻生活都适用的口令思维》），我看到有同学反馈说，口令思维钥匙，不就是把复杂的问题变简单吗？这世界是复杂的，你用这种简单的方式，能够解决间题吗？当我们觉得矛盾的时候，首先是我们开始思考的时候，第二是我们的思考方式可能遇到了挑战，我们遇到的问题在挑战我们既有的认知。

事实上这是两个不同层面的问题。我们讲的是沟通流畅性的问题，而不是世界本身的复杂和简单的问题。在沟通过程当中，沟通的最大诉求是流畅、持续，是沿着一个你可能无法规划的路径，达到一个意想不到的共识，这是沟通所要求的逻辑和结果。

我们之所以在沟通中要选择口令思维、钥匙思维，是因为我们要达到一个既定的目标，而不是被随时可能出现的小岔子、小话头引入到死角中，以至于出现事与愿违的沟通局面，把一场本意在平息冲突的沟通，变成了一场挑起新的争论、更加冲突的对抗。

口令思维恰恰是要我们意识到这个世界本身的复杂性，同时又不被复杂性所干扰，将我们的注意力、目标设定在我们最终需要的结果上。

这里可以引用一句华为广告语，在沟通的时候我们一定不要把战略性的资源消耗在那些非战略性的节点上。大量失败的沟通，都是因为我们忘记了沟通的初衷，同时将我们过剩的精力和资源耗费在那些无关紧要的事情上，而这些无关紧要的节点又出人意料地把我们引向最不愿面对的局面。

# 二、岩石逻辑，与水的逻辑

沟通必须面对世界本身的复杂性，我们如何以不变应万变达到我们的目的？

有一本书，相信很多同学读过，是爱德华·博诺写的《我对你错》，讲了从岩石逻辑到水的逻辑。

所谓岩石逻辑，就是我们的传统思维，尤其是男性思维特别爱遵循的，一种以真相为基础、以寻求所谓真相等目的的逻辑冲突。当我们遵循这种逻辑的时候，我们就会情不自禁地为了寻找真相而倾向于否定和攻击。岩石的特点是它有固定的形状，它是坚硬、棱角分明、永远不变的，拥有绝对的独立性。

而水的逻辑恰好跟岩石的逻辑相反。水一个很重要的特点叫随形而化。水有什么形状？没有，水的形状取决于容器的形状。水有什么方向？没有，它只朝一个方向运动，那就是低水位的方向。

所以水的第二个特性就是它始终不变的方向性，在局部好像没有固定方向，但是它始终朝向一个固定的方向流动。荀子把水的这个特点概括为“虽万折而必东”，河流不管绕多少弯，最后都要朝东流去，“青山遮不住，毕竟东流去”。

水还有一个特点是流畅性，它是连续性的，而不是非连续性的。岩石就是由于它的形状固定、棱角分明，所以这种逻辑常常让世界来适应我，而不是我去适应世界。

# 三、男人的逻辑，与女人的逻辑

所谓岩石逻辑和水的逻辑，我们也可以把它简单地称为男人的逻辑和女人的逻辑。男人在沟通的时候，他有一个诉求就是真相和事实；女人在沟通的时候，要的是高低之间的倾斜性，是一种姿态。

很多丈夫跟妻子沟通的时候，百思不得其解，明明事实就摆在那，她为什么就不承认呢？他不知道女性的逻辑是，你越强调事实，就越表明你想保持一种对她的碾压和居高临下的状态，而她要的就是你要去培这种碾压和居高临下的状态。当你不能解决这个问题的时候，你说再多的事实不仅没用，而且恰好起到相反效果。

例子：所谓“话赶话”是怎么回事

一对夫妇为了纪念他们的结婚十周年，提前一个月就准备在结婚纪念日那一天，在一个环境优雅、品位很高的餐厅里吃一顿烛光晚餐。男的去订位置，而且到了那一天提前一个小时就到了那个地方，可见他是如何重视。但不幸的是那天出了一个小状况，他的妻子在来的路上遭遇全城爆堵，丈夫因为提前来的所以躲过了这场爆堵；而他的妻子本来也是提前出发了，结果晚到了半个小时。
