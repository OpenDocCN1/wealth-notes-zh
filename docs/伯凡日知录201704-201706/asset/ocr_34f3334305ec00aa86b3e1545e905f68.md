# 引子：为什么美国教授不爱招中国博士？

前不久跟北师大的钟伟教授聊天，他说了一句话让我特别讶异——如果讲学生的素质，南昌大学毕业的学生比哈佛大学毕业的学生要好。我觉得很奇怪，但他接着说第二句话的时候我听明白了。他说如果作为一种就业前的准备，你上南昌大学比上哈佛大学要好。

哈佛大学不是一个就业前的培训基地，它的目的要培养对某种知识、思想的持续执着。所以这两个学校毕业的学生，如果到同样一个公司里，你发现往往哈佛大学的学生还不如南昌大学的学生。但是如果是要比创新精神、比未来的增长潜力，哈佛大学的学生要好的多。

# 一、我们被威胁驱动的一生

上述现象不知有多少的普遍性，但想一想它是有情理的。因为我们中国的教育一直是“威胁性的教育”。上幼儿园的时候家长就会告诉你，你要好好学习，像史家胡同小学、中关村一小，到时候会要考试的。小孩心里就被注入了一个目标，其实是被注入了一种恐惧。因为父母在给你设定目标的同时，也给你设定了一个恐惧，你要是上不那样的学校，你将来考考不到好的初中、好的高中、好的大学，你就只能去干什么，而不能去干什么。

# 二、靶子教育（Target）与目标教育（Purpose）

斯坦福大学教育研究所的威廉·戴蒙教授，通过长期研究发现，优秀的、真正有创新潜力的学生，学习动机往往不是由阶段性目标外在驱动的，而是由内在目的驱动的。前者可以叫要学习，后者叫我要学习。

这对应英文当中的两个词，一个叫target，一个叫purpose。Target就是一个具体的目标，本意是靶子，确切的阶段性的目标。Purpose是目的，做事的内在原因和企图。

# 三、常见的故事，不常见的“大教堂思维”

很多人都听说过“三個石匠”的比喻：一个人遇到三个石匠，问他们在干什么？其实他们三个表面上干的都是一样的，但是三个石匠的回答是很不一样的。第一个石匠说，我终于找到一个不错的饭碗，第二个石匠说我做的是方圆几十里数一数二的石器活。他问第三个你在干什么？第三个说我在建大教堂。
