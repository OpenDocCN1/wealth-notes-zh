# 1、任何一个媒体的繁荣，都有特定的生态

有声读物的繁荣是由于我们现在有大量的碎片时间，而在这样碎片时间里，我们很难做别的事。

# 2、人 людьми通过听觉获取信息，比通过文字来获取要早得多

人类有250万年的历史，文明的出现也不到一万年，有些民族只有语言、没有文字，通过文字获取信息只有五六百年的历史。1453年古登堡印刷机的出现，才使得我们可以通过大量的印刷品来获取信息。
