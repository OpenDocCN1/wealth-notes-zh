# 1、为什么“战拖”成了市场

第一个话题跟拖延症有关,但讲的不是拖延症。我真正关心的是为什么拖延症成为一个经久不衰的问题,以至于围绕这个话题形成了一个蓬蓬勃勃的话语市场。说的人和听的人都那么起劲,原因到底是什么呢?从这种现象我们分析了为什么会出现一种叫做按摩工业或者叫鸡汤市场的东西。很多所谓的解决方案其实不过就是一种介于有效和无效之间,基本上是无效的,但是能够让我们有某种舒适感的按摩而已。

面对一种疾病,我们又不愿意忍受痛苦、麻烦去从事真正的治疗,同时我们又不愿意放弃治疗。这就形成了一个巨大的橄榄型的市场。大家如果感兴趣,请听我分析一下战拖到底意味着什么。

# 2、M型陷阱

以前商家打广告的时候常常会说价格适中。他们想通过适中的价格来吸引消费者。但不幸的是,价格适中的产品往往销路是不畅的产品。

我真正想说不是产品和市场,而说的是
一种在职场当中的中等收入陷阱。在劳动力市场上,我们不知不觉的让自己成为了一种中档化的产品。而一旦陷入这种中档化,我们就会面临着一个看似很平稳,实则困难深重的一个大陷阱当中。

# 3、细节的成本

本周还讲到了一个概念叫细节的成本。我们之所以觉得一些东西是细节,不是因为它小,而是因为我们并没有充分的意识到它的价值。有些细节跟钥匙一样,看似很小,实则是至关重要的。

我们在忽略细节的同时,也忘记了细节的成本。就像人与大猩猩在DNA上的差别也许只有0.01%,但是这个0.01%决定了人和大猩猩的本质区别。但是要真正拥有这样的细节,可能需要付出我们完全低估了的巨大的成本。
