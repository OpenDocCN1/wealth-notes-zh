# 5.3 | 品牌的最高境界 是没有品牌

# —— 知识笔记 ——

我们今天接着讲跟产品开发有关的话题。

以前我做杂志报纸的时候，特别崇拜一份报纸，叫《华尔街日报》。不仅仅仅是说它的内容，这张报纸本身放在那里，你就会觉得它是一种神一般的存在。特别有意思的是，你在地铁车厢里远远地看见有个人在看报纸，如果他看的是《华尔街日报》，你一眼就能知道他看的是《华尔街日报》；如果地上有一个小的碎纸条，如果它是从《华尔街日报》上撕下来的，一眼就知道它是《华尔街日报》。

如果是别的报纸，就算是把整张报纸扔在地上，除非看到报头，你也不能确认它是哪张报纸。这就涉及到了一个我们今天要讲的一个现象—— 品牌颗粒与情感暗号。

# 品牌的境界

我们知道任何物质都是由一个个的颗粒组成的，原子是不可分的颗粒，再往上是分子，这些小单位构成了一个整体。但我们识别一个物体的时候，常常是要根据它的外形。如果它属于某一个品类，那么我们如何识别它是它呢？那就给它取一个名字，在商业领域，这个名字就叫品牌。

品牌最初就是一个商标，是一个贴在上面的标签，像军人和警察的徽章一样，告知它的ID、它的身份、它是谁。

但是研究品牌的人知道，做品牌最重要的工作就是超越商标。因为任何一件在市场上合法销售的产品都是有商标的，也就是说它们都是有名字的。就像每个人都有名字，每个人可不一定都是名人。

品牌，就是要将这个商标在人们的心目当中占据很大的份额。这个一般叫 mindshare，心灵份额、内心份额。一旦提到这个品牌的时候，立即会想到它所属的那个品类。极端的情况就是品牌名称变成品类名称。这是我们通常要做的。但这还不是做品牌的最高阶段。

说起来有点道家的意味，品牌的最高境界就是没有品牌。就是在没有标签的情况下，它还有很强的识别度和用户忠诚度，同时让用户对价格的敏感度降到最低。

# 例子：隐秘处相遇的Logo

比如说有一种男装，可以说它是没有 Logo 的，它的 Logo 只在最不显眼的地方。它跟有一种服装正好是相反的，就是我们有时不时 alloys 看到有一种有钱人穿着一件衣服，左胸几乎是被一个巨大的图案占据，胸前有个巨大的男人骑在一匹马上挥舞着一个东西。有时候我看见穿这种衣服的人我就特别害怕，我躲得远远的，怕它打着我。
