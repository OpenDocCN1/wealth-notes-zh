# 用户留言

简史，既然是简史，它肯定不可能像其它史书那样面面俱到，只有通过高度的凝练、抽象、概括，讲出内在逻辑才行（但正因为如此才精彩，像《世界文明史》这种大部头，去年挣扎一年，也就读完了第一本《东方的遗产》）。

但是这里面也存在一些问题，从简史作者的角度讲，如果他没有把这个历史搞得很透，没有充分去考量到历史的种种可能性，如果仅仅某天脑洞大开，感觉自己发现了一个规律，那么他就可以去提出论点，按需从历史中摘选论据，然后忽视不同论据即可。所以说作者能不能驾驭这个简史需要注意。从读者的角度讲，自然很多读者知识的积累，是赶不上作者的，其实很多人他不怎么读书，然后听说某某简史很好就去读，那么这个人实际上自己根本无法驾驭这本书，因为他对很多历史都不明白，不清楚这个历史到底是怎么回事，如果觉得大家说好，又是畅销书确实也写得很喻道里，那么他的认知就会产生一些偏差的，我认为这也是需要警惕的。就像初中生刚接触历史，就先学一些历史虚无论的东西，自然会让你显得与众不同很有思想，但除了嘘嘴皮子还有啥呢？

最后如果要说我发现的一个逻辑的话，那就是，技术简史——它的底层逻辑，就是所有的技术都是为了满足人类偷懒取巧的，更往深一层讲，就是为了缓解人类的生存焦虑的。无论是探索太空的那些高精尖的东西，还是一个自动洗碗机，包括如今这个智能的终端，实际上都是为了让人过得更舒服，活得更长。再倒推回来，所有的个人成长类的书籍和经验，其实都是让人克服懒惰和恐惧本能。
