# 引子：商业的本质

最近关于新零售的讨论越来越多了，我看了一下这些文章，越看越不太明白到底什么叫新零售。旧零售到底是什么？新零售它又新在哪里？这里涉及到一个很朴素、很根本，但同时也是非常重要的问题，商业的本质到底是什么？

沃尔玛的创始人山姆·沃尔顿说，商业的本质很简单，就是“己所欲，施于人”。

进到一个商店里最想要什么，你作为一个卖家就要把你想要的那个东西卖给买家。这个哲学就导致了沃尔玛的诞生。在山姆·沃尔顿看来，人们进到商店就是想用最少的钱买最多的东西。所以，他们无论是在营销上、还是在生产的流程上，都沿着这个路径把它走到底。

# 一、是谁让沃尔玛在德国铩羽而归？

沃尔玛进到德国，不到一年仓皇逃窜，为什么玩不转呢？是因为德国有一家企业跟沃尔玛有某种相似之处，但是它是真正地将零售做到了极致的一家企业。这家企业以前我一直习惯叫它阿尔迪（ALDI），很多的文献里都把它叫阿尔迪。

最近它进入到中国来了，而且进入的节奏好像非常快。上周，我们在查关于它的信息的时候还不多，这一周期发现网上它们的 信息以指数级的速度在增长。它注册的中文名称不叫阿尔迪，叫“奥乐齐”。

# 二、ALDI的九大神奇之处

# 1、价格极致

我曾经在德国生活过一段时间，对它有一种特殊的感情。去德国之前，一个在德国生活过的朋友告诉我，你住下来以后，第一件事情就是找附近哪儿有阿尔迪。生活了很短的时间，我就明白了为什么这个朋友要我一定要先找到阿尔迪。

简单的说，它的商品的价格比其它的零售店，还有那些小杂货店的价格低25%-30%。这是一个很吓人的数字。你如果在德国生活，你进阿尔迪店是一个必不可少的选项。一个最直接的问题就是它为什么能够做到这么便宜，这得从这家企业的历史讲起。

# 2、战乱中成长的发家史

二十世纪初期，1913年在德国的鲁尔工业区有一个小食品店，叫“艾玛婶婶商店”，其实现就是一个小杂货店。它真正的发家史是在二战以后，也就是在1945年以后。1945年以后的德国是一片废墟，据说这家店当时也是被飞机轰炸，但是破坏的程度不是那么厉害。经过简单的修整以后，它又可以营业了。

在当时的德国，物资极度的稀缺，人们进商店要买的东西就是那几样特别必需的商品。比如说盐，比如说啤酒，日常生活当中最需要的那几样东西。因为，这家店它自己的资金不够多，它也只能用有限的资金采购很少品类的几种商品供大家来购买。

德国是一个制造大国，生产汽车、化工 业、IT业都很厉害。但是，现在德国的首富永远是阿尔迪的老板。有意思的是这个老板是两个老板，兄弟俩分别经营着德国的南部和德国的北部的市场。也就是说，基本上把阿尔迪的总财富除以二，还是德 国的首富。

这就有点奇怪了，如此传统的一个行业在一个如此发达的国家里它竟然能够有如此强的竞争力。即使在今天电子商务这么发 达，它不仅没有衰落，而且似乎有一种基 础?上的势头，所以它最近开始向中国扩张。

# 3、SKU极致

它是如何做到的呢？简单的说是跟它的基因有关。由于它的前身就是一个小卖部，就是一个杂货店，由于它的资金不足，它就被迫选择了一个路径，那就是永远保持商品的品类最少化。

德国人会精算，听说经过精算以后，一般的普通人要过正常的 生活需要270多种商品就够了。现在它的商品的SKU有所增长，一般是400到750个。但是，最大的店也就 是1000个SKU。这是什么概念？沃尔玛、家乐福的SKU都超过1.5万，甚至有的到了10万这样一个数量。

> SKU释义：简单地说就是一个商品的单品。这个单品最后体现为结账的时候它是一个独立的条形码。举个例子，iPhone 7是不是一个SKU呢？不是。是iPhone 7是深空灰色是一种。亮黑的又是一个SKU。6.1G的是一个SKU。128G的也是一个SKU。就是它不仅仅是指一个商品的单品，而是说它的性能、价格都是独一无二的。在结算的时候是可以作为一个单独的条形码出现的，这样一个单品才叫SKU。

同样的销售额，由于阿尔迪的SKU少，所以每一个SKU的采购量是巨大的，这就意味着它对上游厂商的议价能力非常的强。可以这么说，如果阿尔迪选中了你的商品，那你的企业就会在一夜之间就发达起来；如果阿尔迪取消了订单，你这个企业就立即有可能破产。阿尔迪对上游企业的议价能力是非常高的，上游企业就花大 力气保证它产品的质量，这就意味着阿尔迪 售出的商品一方面价格便宜，另一方面质量是得到保证的。

# 4、压缩营销费用

当然，它还有一系列的策略来保证它的商品既是便宜的，又能够完全保证质量的。它一般采购二线、三线的品牌，在德国这个国家里，便宜的东西绝对不意味着劣质。它之所以便宜不是因为它偷工减料，而是因为它没有把大量的资金用在营销上，用在渠道的开拓上。它们的产品质量是完全能够得到保证的。

这就意味着消费者从阿尔迪买到的商品里 没有多少钱是花在营销费用上的，这就进一步降低了它的成本。这些默  品牌它们没有多少所谓 的品牌议价，最后必然是阿尔迪让利给消费者。当然，让利的过程同时也就是它获利的过程。

# 5、压缩占地面积

线下零售有一个巨大的痛点就是房租太贵。阿尔迪把它店都设在住宅小区附近的比较偏僻的地方，而不是在市中心那些房租巨贵的地方。一般的店也就是二三百平米，最小的是150平米，最大的 是500平米，当然，也有少数达到1000平米这样的比较大的店。由于这些店不是在那些繁华的商业区，它的房租的成本自然就会很低。

与此同时，由于它的商品品类很少，消费者 进到那个店里的时候非常明确的，迅速的找到他们所要的商品。所以，每一个顾客在这个店里逗留的时间是很短的。换句话说，它虽然面积很小，它的总客流量是足够的。

# 6、简化购物流程

在一般的小店里只有两个员工，一个负责收款，另一个负责补货；大的店也只有4到5人。

阿尔迪店结账台上都有一张纸，上面就是这个店里的所有商品的目录。你结完账以后，就随手拿一张纸。下次要来购物的时候，就像我们中国人喝早茶的时候，在上打勾，写上几份。进来以后不用东奔西窜，很容易找到他所要的商品，迅速的结账走人。这就保证每一个店的流量很大，但是它的面积很小。不像沃尔玛，你走进去以后，一不小心你可能会迷路。

# 7、高工资，低成本
