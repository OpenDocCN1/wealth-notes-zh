# 引子： “便宜” 的印象是怎么形成的

有一个人到香港去买各种各样奢侈品，买几万、几十万的手表，但是舍不得花10港币买一瓶水。这里<|start|>含有一个问题：人对价格合理性的判断来自什么。

卡尼曼的书里有一个很重要的观点：价格合理性的判断来自于记忆。

> （注：卡尼曼，心理学家、行为经济学专家，2002年诺贝尔经济学奖获得者）

# 例子：小摊主的价格参考系

打个比方，你到秀水市场买衣服。一个摊主告诉你这件衣服800块钱；接下来再逛，另外一个摊上说是500块钱；再逛一会儿，一个摊上说300块钱。那么你就会立即会觉得这300块钱非常的便宜。
