# 鲨鱼的能耗最小原则

前不久，我桌上有本书叫《鲨鱼经济学》，那本书的其实不是怎么好，但里面提到了一个细节是我以前从来不知道的。我们以为鲨鱼是极其凶猛的动物，其实它是一种非常脆弱的动物。

蟑螂在地球上已出现了4亿年，鲨鱼出现的时间比它还要早，是4亿2千万年。年代那么久远，也就意味着它的整个身体结构其实是比较简单的。跟后起的那些动物相比，它的身体实际上是很简陋的。比如说它的内脏的90%都是肝脏。鲨鱼长了一个巨大的脂肪肝，有些鲨鱼一年只吃一顿，它跟那个蟑螂也差不多。大吃一顿以后，这些能量就储存在它的肝脏上。吃不到东西的时候，肝脏就能成为一个稳定的能量供给库。

由于它有这么大的肝脏，所以它是很脆弱的。比如说如果遇到海豚后，海豚要是对其进行撞击的话，它就会受到很大的伤害，这种伤害甚至是致命的。因为它的身体本身缺乏足够的弹性和坚韧性。

由于它的这样一个特点，所以它在捕获的时候遵守能耗最小原则。我们想象鲨鱼就是一部巨大的手机，它一年才充一回电，它要特别谨慎地使用它的电量，它不做任何多余的动作。所以它不像大鲸鱼那样用极其猛烈的动作去攻击它的猎物。它采取了一种什么样子的策略呢？它常常会采取一种看上去很轻微，很轻柔的攻击方法，它会找到猎物身上的某一处咬它一口，看上去是一点都不致命的，但是这个地方的伤口会让猎物流血不止。

对于鲨鱼来说，猎物流血不止有两个好处。第一个，鲨鱼可以持续地追踪它的猎物。因为鲨鱼对血液极其敏感，看上去它是在不急不忙地巡游，实际上它是闻到了非常微小的血腥味，然后再持续追踪。在这个追踪的过程当中，鲨鱼消耗的能量最少，而猎物在不停地流血。第二个好处，鲨鱼在这种优雅的追踪当中静等着猎物流血而死，这样它吃到这个猎物的时候就很不费劲。同样，它遵循了捕获当中能耗最小的原则。

# 重大变化的源头往往微小

从鲨鱼的这个攻击行为里头，我们是不是有所感悟。

我们注意到这样一类现象：对于一个意义重大的改变，我们如果详细地追踪它的源头以及它的起因的话，我们会发现，这个起因看上去是非常微小的，意义不那么重大的。正是这样一个看起来很小的导因，最终导致了一场重大的变化。用学术的话说，就是诸多不可预测要素的连锁反应和发酵导致了一个重大的改变。

听起来大家有点头晕，我说一个可能大家都听说过的民谚，大家就可能明白了。这个民谚好像有各种版本，我看到的这个可能是有点山寨。它说的是：因少了一颗钉子，而掉了一块马蹄铁，掉了一块马蹄铁就瘸了一匹战马，瘸了一匹战马就摔死了一个骑士，摔死了一个骑士就丢了一份情报，丢了一份情报就输了一场战争，输了一场战争就亡了一个国家。

如果我们把这个民谚进行引申的话，可能大家会想到蝴蝶效应。我今天不讲蝴蝶效应，我讲的是另外一层意思，就是面对世界，面对让我们焦虑的种种事情，我们如何去改变。

# 改变大习惯，从小习惯开始

什么叫焦虑，大家知道，焦虑就是因为眼前有急迫的事情发生，而我们找不到一个明确的步骤和程序，只好面对这样一个急迫的情景而持续的恐惧和无所作为。那就叫焦虑。焦虑感的反面是紧迫感，紧迫感的特点是同样面对一个非常紧急的情景，我们能够有计划，有步骤，有程序地持续改变，直到逐渐出现重大的改变。就好像下棋的时候，直到最后收官。

人世间有很多东西能改变，最难改变的东西当中有一样应该是大家公认的，就是习惯。无论是个人的习惯、组织的习惯，还是社会的习惯，它都会成为一种我们往往意识不到，但是又极具其稳定地操纵我们的行为和思维的那样一种力量。

一种习惯肯定不是在一天当中养成的，而当我们要改变这种习惯的时候，当然也不可能用很短的时间来实现这种改变。如何才能改变一个让我们自己觉得像癌症一样可怕，像癌症一样难以战胜的习惯呢？比如说大家经常说，懒癌晚期。怎么能改变呢？

有时候你可能听了一堂成功学的课，听了一场励志演讲，回到家里头对着镜子，“我要改变，我是最棒的”。可能三天下来，你就改变不下去了。因为，那是一个庞然大物，你不自量力地去改变，最后你发现这个难度太大了，所以，就只好放弃，依然如初，就继续过着跟从前毫无差别，甚至会更坏的一种生活。

那怎么才能够改变呢？好几年前我读过一本书叫《习惯的力量》。在这本书里头它提出一个原则——一个明显的大 的习惯的改变，往往是从一个看上去微不足道的小习惯的改变开始的。这种改变它可不是愚公移山，通过时间的累积，通过这种简单 的做加法，或者叫做减法的方式把一个习惯给去除掉，这是不可能的。

它的改变的过程常常是这样的：一个小习惯的改变会悄地导致另外一些相关小习惯的改变，进一步地引起连你都甚至没有意识到的、隐藏在背后的那些小习惯的改变，这个时候你就身不由己了，你是这场改变的发动者。但是，这种改变在某种程度上它获得了它的自主性，你会不知不觉、身不由己地陷入到一种改变当中。最后，奇迹般的改变了这种习惯。

# 美国铝业的经典案例

当然，任何习惯的改变都不是那么简单的。

我记得这本书里头讲到了一个关于美国铝业的案例。那是一个庞大的企业，它的历史很长，员工的数量很多，这也就意味着它的习惯往往是很顽固的，积重难返。它因为种种没法改变的恶习而身陷经营困境，几乎到了破产的边缘。

后来，公司找到了一个据说在美国具有传奇性的CEO，他是一个推动变革管理的 高手。当他来到这个公司的时候，大家对他寄予了很高的希望，大家以为他会新官上任三把火，用那些猛烈的动作推倒公司内部的墙，打碎一切官僚的流程和习惯。可是，大家觉得很奇怪，他到这个公司来并没有推出什么新政，过了差不多一个月的时间，他悄悄地做了一个动作，这个动作看上去像是一个小动作。大家想一想，在一个身陷经营困境的企业里头，他竟然推出的第一项改革是如何明显减少，甚至消除生产过程当中的工伤事件。

在这样的企业里头总会存在着工伤。但是，花那么多钱请你过来，不是让你来解决员工的工伤问题的，你是来解决战略、组织、文化这样一些大问题的。让人很奇怪的是，他就只抓这样一件小事，如何明显减少甚至消除公司的工伤事故。

工伤事故虽然小，但是是跟员工的切身利益相关的。随着公司的经营越来越坏，与这个公司的经营状况越来越相伴随的，是这个公司的工伤事故也逐渐增加。很多员工对那些惨烈的工伤事故记忆犹新。

所以，当他推出这样一个举措的时候， 很多员工都积极参与。 随着这项举措的推进，大家没有意识到的问题逐渐显现出来，工伤事故频发的背后是企业内部信息传递的低效率，甚至几近到了瘫痪的地步。为了杜绝工伤事故，各基层部门密切配合。如何加强公司 的信息传递，以及部门与部门之间，部门与主管部门之间，以及主管部门和CEO之间信息传递的机制就逐渐变得通畅起来。

公司的DNA是由四个因素组成的。第一个是公司的激励方式，你激励什么和反对什么决定你公司的DNA。第二个因素是公司的组织结构。第三个因素是决策权，到底是由一线的人来决策还是由中层来决策，还是要上层来决策。还有一个就是信息传递方式。 四大因素当中，最重要的因素就是信息传递方式。

杜绝工伤事故这样一件小事，让公司 的信息传递机制的问题极大地暴露出来，就引发了对这个机制的改造和变革、变革和优化。然后，由于这个信息传递机制优化以后，公司的激励方式、决策权，甚至组织结构也相应地发生了改变。
