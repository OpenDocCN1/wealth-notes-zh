# —— 知识笔记 ——

前几天我看了一篇文章。那文章讲的是某个人经过了十几年的调查，发现那些亿万富翁都有哪些特点。一共归纳出八大特点。

其实所有成功学的逻辑都是错误的。比如说第一个习惯是爱阅读。他举一个例子，说比尔盖茨是特别爱阅读，所以他成了世界首富。

这里的逻辑荒谬性一看就知道。贝索斯也许可明年就是世界首富了，我自己觉得他明年很可能是世界首富，他到底爱不爱阅读就是一个问题。我只听说他爱卖书，不一定他爱阅读。

而且我亲眼见过一些亿万富翁，他们是很不爱阅读的。他们喜欢获取知识，但有的人甚至有阅读恐惧症，他怎么做呢？他通过跟别人的交谈、通过抓住某一个问题进行探索式的学习。他不一定具体读哪一本书，他常常去找那些高人学习，也能获得知识。

还有一类，由于中国特殊的经济环境，有些人成为亿万富翁是莫名其妙的，连他自己可能都不知道怎么就成了亿万富翁，他根本不读书。

当年秦始皇为了保住自己的政权，把读书的人坑掉，把书烧掉。后来有人写了一首诗，说“刘项原来不读书”，最后刘邦和项羽两个都是不读书的人。这是一个很简单的逻辑错误，归纳和演绎是完全不一样的，你不能用演绎的法则来说归纳的事情。

那本书里还讲到很多的习惯，我就不一一重复了。但这篇文章引用了一句话，正好这个人是我最喜欢的一个哲学家叫爱默生，我曾经翻译过他的书。

> 爱默生说，习惯如果不是最好的仆人，它就是最坏的主人。

我们的习惯应该成为我们的仆人，它们要为我们所用。

但是你要没有清醒地意识到习惯的力量有多大的话，它会翻天的，它会倒过来支配你，尤其是那些坏习惯。很多人之所以陷入到失败，恰恰就是因为他们让坏习惯成为了他们的主人。所以我觉得失败学比成功学更有意义。要归纳成功的路径，可能永远归纳不完。但是失败，只要有一样就足以让你失败。

# 识别坏习惯：失败学比成功学更有意义

昨天我们讲的是学习的时候如何对自己进行模式识别。今天我们要讲的话题是如何对自己隐秘的障碍和隐秘的习惯进行识别。做对了99件事情，做错了1件事情，你就可能陷入到全盘的失败当中。而且，成事不足，坏事有余的那些要素，比如说坏习惯，常常又是你自己意识不到的。

很多习惯在我们自己看来是理所当然的，而且我们常常会陷入到一种归因谬误，甚至反过来会把它当成是我们做成事的原因，但很多时候恰恰是失败的原因。有些时候它没坏你的事，是因为这个时候它使坏是不致命的。如果是持续下去，总有一次会让你车毁人亡。

我们有很多弱点，有些弱点是致命的，有些是非致命的。所以有些时候，我们甚至会把一些弱点作为一种优点来炫耀。

比如说他是个工程师，“我这个人不擅交际，我这个人不擅表达”。当他这样说的时候还有某种自鸣得意的东西。“我这个人直来直去”。我们就说直来直去这件事情。由于你的专业能力非常强，在特定的环境当中你的这个缺点就显得不是致命的缺点了，它并没有为你加分，它只是没有太碍你的事。

如果场景一旦发生变化的话，你可能就因为这个缺点，因为这样一个习惯而翻车。有一个很简单的让人莫名其妙的陷入到失败的一个小的习惯，就是不懂做礼貌的举止。比如说不太爱说“谢谢”、不太爱说请。这些在幼儿园阿姨都要教的东西，你都不具备，但是好像也没有对你形成障碍。

事实上，越是重大的损失，我们往往意识不到。不知不觉当中，你已经丧失一个机会了。但是，你不知道你丧失了。小机会你是往往知道你丢失的。大机会常常是在你完全没有意识到的情况下丢失的。这个大机会的丢失可能就是因为你不太爱说“谢谢”、不太爱说“请”，以及与此相关联的种种的习惯，导致你还没有意识到的情况下你已经被别人悄悄的拉黑和屏蔽了。

所以说我们在自我迭代的时候，不要花太多的时间去琢磨怎么样才能够成功，起码你要割出一部分时间、一部分精力和注意力来让自己识别有哪些坏习惯在悄悄地坏我的事。
