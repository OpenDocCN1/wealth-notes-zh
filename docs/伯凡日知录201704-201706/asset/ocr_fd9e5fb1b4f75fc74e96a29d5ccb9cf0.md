# 引子：道法自然

有同学问，你为什么最近老讲动植物物 的例子，为什么不用企业的案例来说明白管理学上的道理方法。

这里有很多的原因，有一个直接的原因就是我自己的一个认知变化，或者说是升级。

十几年前我就开始对管理学感兴趣，读了很多管理学的著作，读的最多的是当然是德鲁克的著作。德鲁克被公认为现 代管理学的创始人。可是在他晚年 的一个自述里，他对他的身份界定不是管理学家或管理学的创始人，而是社会生态学家。

这个差别在哪里呢？首先，他关心的还是那个问题，就是在一个社会或组织里谁说了算的问题，所谓管理者就是在一个组织里说了算的人。后来德鲁克逐渐意识到，一个组织到底是谁说了算，这不是一个很容易回答的问题。后来他逐渐意识到，很多时候是一种我们看不见的力量在说了算，而不是哪个人在说了算。

在生态世界里，任何一个物种都不能说了算，是各个物种的复杂关系，它的互动网络最终决定了每一个生物个体的命运，所以是一种看不见的东西说了算。这就让人想到《道德经》那句话，“域中有四大，道大，天大，地大，人亦大。人法地（人应该按照地 的法则行动），地法天，天法道，道法自然”。最高的规范准则  是来自于那个比人、地、天还要高的“道”，而道所遵循的就是“自然而然”。这个自然而然既可以理解成我们的自自然，也可以理解成整个自然中一种无形的力量。

所以后来我花了比较大的力气读两本书，一本书是《道德经》，一本是《失控》。我跟KK聊过《失控》的核心理念，如果要用几句话来概括你这本这么厚的书，应该是哪几句话？他说，就用《道德经》第38章的那一段话。（注：指“无为”）

所以我的兴趣还是讲管理学，但是我更多从生态的视野，从生物个体与整个环境之间的关系互动，来看管理的法则。谁在控制，谁在管理，就是那个看不见的力量在管理，“无为而无不为”的那种东西。用这种一种视野来看生物世界的一个个物种，你发现它们都是独具匠心的，每一个物种经过几亿年的大浪淘沙还能活下来，它一定是有 一个经过反复优化的管理手段和生存策略。所以我们今天还是从两种比较罕见的物种，讲一个很有意思的管理学现象和法则。

# 一、卷柏的弹性

一个台湾作家在一篇散文里提到，有一次他在沙漠看到一种枯草。当地人告诉他，这不是枯草，它其实是活着的。如果你把它带回去，放在一个水杯里，你就会发现它一天一  天的绿起来，最后整个杯子充满一团绿油油的草。他觉得很神奇，把草带回家，果然见证了这么一个奇迹。

看到这篇文章以后，我就去查找有没有类似的植物，就是我今天要讲的这种植物——卷柏。它是一种叶子很像柏树的蕨类植物。

![](bbox=[0.28, 0.00233, 0.78, 0.003])

最早期的木本植物，像水杉，其实是来自于蕨类植物。蕨类植物，包括蕨类植物进化过来的那些木本植物，都是一些资历格的骨灰级植物。王东岳先生讲过，越简单的物种意味着它的依存度越低，也就意味着它的稳定性就越强。卷柏可以说是一种对外依存度很低、稳定性很强的植物。它的生命历程可以概括为：死去活来。看上去好像死了，但是它其实并没有死。

有一个日本科学家曾经不小心把水溅到了卷柏的标本上，没想到它居然复活了。而它作为一个“死去”的植物标本，已经在这个实验室待了十几年了。所以它真的是“心还在梦就在，看人生豪迈，只不过从头再来”。

南美洲的卷柏更加神奇。当天气干旱的时候，它的根会自动折断，就等于给自己理一次发，全身卷成一个小枯球，随风而动到处流浪。简单地说，它让自己获得了高度的移动性。这个卷球总有一天会滚到有水的地方，重新生长。如果这个地方的气候环境正好是旱季和雨季交替，它就有水住下来，没水就着走。它是一种旅行植物。

说到这里，大家是不是对这种植物怀有一份尊敬。它的生命力如此之强悍，能够滞留在死亡的边缘，在几乎等同于死亡的条件下坚定地等待它可能有的 sinh机。它卑微到极处，弱到极处，同时它又强大到极处。

我又想到《道德经》两句话：

+   1. “死而不亡者寿”，就是说一个东西它死了，但是没有亡。“死而不亡”这样的东西才是真正的长寿。\n2. “天下之至柔，驰骋天下之至坚”。这两句话都可以来形容着柏生命的柔性，上穷碧落下黄泉，哪里都能生存。风来了把我带走，风走了把我留下，哪儿有水哪儿就是它生长的地方。

# 二、水熊的弹性

还有一个物种，在科学的分类上是一种极其独特的动物。这种动物的名字很容易引起误解，它叫水熊，但体型小到只有50微米。它跟卷柏一样，是一种很古老 的物种，它的存在可以追溯到5亿年前的寒武纪。但它的生命力可以说比卷柏还要强悍。

水熊是一种卵生的动物，但出生就已成年，没有童年期，一生风华正茂，身体里细胞的数量终身不再改变。昆虫和鱼类的共同点是出生和成年 的形态很相似，水熊更彻底，它一出生就是成熟的，比 嗤还厉害。

水熊这种在水里生存的物种，它能承受的温度跨度超过400度。设想一下如果人类没有暖气、空调或衣服的话，能忍受的温度跨度到底有多大。水熊能在150℃到-272℃之间存活，-273℃是绝对零度，它能承受的温度是几乎接近绝对零度。它在液氮里泡8个小时，遇水还能复活。我们把蚂蚁称作小强，但蚂蚁的生命力跟它比简直弱爆了。

几乎所有的微生物都怕酸，酸可以用来杀菌。但水熊在PH值为1的强酸，以及PH值为13的强碱里还能生存。人类 的骨头要是放在那样的环境下，会迅速的溶解。更绝的是它能在运行的微波炉里活很长时间。它还在那个完全无气压的真空当中，以及正常气压的6000倍里，还能够生存。

这是一个极端的例子，简单的说就是水熊几乎在地球上所有的环境当中，甚至是在很多接近于极限的人工环境当中还能生存，它是真正的打不死的小强。

# 三、战略的弹性

上周我们讲到了一个概念叫战略弹性（见本专栏6月1日内容《蛇的策略之二：弹性》）。提出核心竞争力的管理学家哈默尔写过一篇《战略弹性》，他之所以提出这个概念是基于他的一种反省——他发现有些企业有很强的核心竞争力，但是“核” 的问题就是硬、刚性，所谓“结核”就是很刚性，没有柔性。

哈密尔发现，一个战略要有效，不仅仅在于它在特定环境下表现出 的巨大竞争力，而而且在于它在 在一个多变环境下的适应力。也就是说它在具有刚性之外，还有巨大的弹性。只有同时既在特定的环境下具有竞争力，同时在多变环境下还有适应力的战略才是真正优秀的战略。

有些企业，比如像稼尔这样的企业，凭着几乎无法撼动的核 心能力称霸一时。但是，当市场环境发生改变的时候，顷刻之间一败涂地。
