在我们录音室的外面一个小院子，院子里会时不时出现几只神秘的猫。在录音休息的时候在讨论一个问题，猫为什么显得那么神秘那么高冷，跟狗为什么那么不一样？

现在很多人养猫已经养成了猫奴了，但是很少听说有狗奴的。

狗它的特性就是忠诚，我小的时候，我看见我们邻居家他们因困难，但是那条狗真的是非常非常忠诚，主人自己都吃不饱，更没有东西给他吃，所以那只狗很瘦很瘦，但是它就是坚守在那个贫困的家门口。

猫是可以全村里面，甚至是跨村进行穿越的，谁家有吃的，它就到谁家去，时不时你会发现，你家里面来了一只不速之客的猫，北京人说猫是奸臣，狗是忠臣，我们可能一般人都会有这个印象。

# 猫与狗的驯化过程

# 狗的驯化

狗是最早被驯化的动物，有人说是一万八千年以前，有人说是两万八千年以前，我最近看了一个资料有人说狗有可能是四万年以前就被驯化了。我们就说两万八千年吧，那是一个什么样的年月？是人类还没有文明的时候。

埃及人很自豪，说他们有七千年的文明，我们中国人说我们有五千年的文明，不管你的文明有多久，你不会一万年，而狗在人类的文明来临之前，就已经成为人类的伙伴了。大家可以想象那样一个场景，那时候地球上的人口是很少的，一个一个的小部落稀稀拉拉地分布在地球上，狗一旦跟某一个部落形成了协同关系，它切换主人的机会是很低的。因为下一个部落在几十里之外，而且那个部落也可能也有狗，那已经是别的狗的地盘了，它一旦跟形成战略联盟，它是不大可能跳槽的。

那个时候也许会有那种不太忠诚的狗，但是它已经被饿死了。那些狼不狼狗不狗的动物早已经不存在了，只有坚守在一个小小的部落里面的狗，它才能活下来，它的基因才得以保留。所以说不嫌家贫这样一种忠诚的特点已经成为狗的基因。

# 猫的驯化

猫是一种很晚才被驯化的动物，人类驯化的这些动物当中，猫和马都是比较晚的。

猫可能更晚，猫和狗的驯化隔着一个时代，狗在人类还处于游猎时代的时候已经被驯化了，而猫是在人类进入农业时代以后才被驯化的。

世界上最早的谷物产生于两河流域，就是今天的伊拉克那一代。很快这个谷物，也就是小麦沿着同纬度往西传，传到了一个不是太远的地方，这个地方叫尼罗河三角洲。

尼罗河三角洲是一个很特殊的地方，因为它处于地中海的东南角，地中海气候的特点就是降雨量很少，气候很干燥，有一定的降雨，但是降雨的时间很短。所以这个地方的空气都很干燥，尤其是地中海南岸都是沙漠。

尼罗河三角洲作为一个农业基地，相对于整个地中海南岸，也就是北非这个地方可以算是一个非地，它跟周围的东西不搭界，莫名其妙地出现了。为什么在紧邻沙漠的地方会出现那么大的一個产粮区呢？是因为非洲中部的充沛的降雨再加上非洲中部的肥料，也就是说火山灰借助尼罗河，每年定期地就送到这个地方来。

现在在农业领域流行一个词叫“水肥一体化”，就是把肥料融入到水里，灌溉的时候同时就是施肥。这是一种很先进的现代农业技术，可是在最古老的时候，尼罗河就实现了水肥一体化，尼罗河的河水中当有大量的火山灰，火山灰是天然的肥料，所以每年尼罗河泛滥的时候，一方面带来了水，同时也给这个地方施了肥，最重要的是它是每年都要施肥。所以这块地方是非常肥沃的，撒下种子就能长。所以尼罗河三角洲就成了人类历史上最早的，也是最大的产粮基地。于是相应的就出现了一种东西叫粮仓，大量的粮仓在埃及出现了，有粮仓的地方就会有老鼠，这个老鼠找到了天堂，当老鼠找到天堂的时候，另外一种动物也找到了天堂，那就是猫。那个时候它还是野猫，但是由于粮仓周围出现了大量的老鼠，也就同时聚集了大量的野猫。这时候这些野猫跟人类就有了第一次紧密接触。

在狗被驯化的时代，人烟很稀少，当狗投靠人类的时候，它真的是豁出去了，因为狒狒那边吃不着食，在人这边也只能非常可怜地啃骨头，狗的食物一直是处于匮乏状态。而猫从一开始，它就是脚踏两只船，因为猫在跟人类接触之前，它已经开始吃田鼠，田鼠在田野里到处都有。猫跟老鼠的脚步于人类产生第一次紧密接触的时候，它不像狗那样面临着食物匮乏的巨大挑战。所以它跟人接触，但是能够保持一种游离的状态。

猫跟人的关系是一种若即若离的关系，它没有必要去依附于哪一个人或者哪几个人哪一家，它在田野和村庄粮仓之间自由地走动，这也就形成了它的那种高冷、神秘、落落寡合，偶尔亲近，常常远行这样一种状态。这一点它跟狗很不一样，没有忠诚基因的狗没办法活下来。但是猫没有忠诚基因，没有死心塌地的行为方式，它也能活下来。这就回答了为什么猫和狗的差别有那么大。

# 企业中的两种员工

为什么要说到这种差别呢？我想到的是一个HR（Human Resources 人力资源）的问题。

创过业或者经营和管理过一家公司的人，可能都会认同一个分类，有些员工是非常忠诚的，有更多的员工，数量更大的员工是不那么忠诚的，前一种的性格接近于狗，后一种的性格接近于猫。尤其是在今天切换成本很低，在跳槽的可能性越来越大的个人跟组织之间的依附关系变得越来越弱的时候，显然猫型员工的数量会越来越多，狗型员工的数量越来越少。因为很少有员工会觉得离开了这家公司，他就活不了了。这可以说是一个世界潮流，浩浩荡荡，顺之者昌逆之者亡。

做老板的，你别老要强调员工要像狗一样的忠诚，别期望哪个员工到外面说我是谁谁谁们下走狗，这不大可能的。但是值得提醒的是如果你是在创业的话，您要尽可能地让你的创业团队，让这个狗型员工在你的创业团队的占有尽可能地大。如果从一开始猫型员工就很多的话，不仅仅是你做事情的效率会很低，最重要的是猫文化会成为你公司的文化。在文化基因上接近于狗的一些员工也会逐渐地变成猫，或者他觉得这不是他的地盘，他会离开。在这样一个闪婚闪离变得如此普遍的时代提忠诚可能有点滑稽，但是你要真正想做好一家创业公司，我们还是要琢磨如何让自己的员工，尤其是种子员工要有一定的高度的忠诚性。

我们前面说猫和狗在基因上的差别起源于他们食物来源的差别。在今天公司跟员工直接的纽带就是薪酬，一种劳作为雇佣和被雇佣的关系。但是我们要知道，工资已经不再是公司跟员工之间的唯一纽带了。如果公司倚着这样的纽带来把员工维系到一起的话，那是一件相当危险的事情。

说到粮食，还能想起一个词精神食粮。你给员工发粮的时候，工资是一个物质食粮，但是让员工对公司产生一种依存，产生一种离了你就很不舒服，甚至有点觉得活不下去的，哈哈就是你公司的精神食粮。我们每个月给公司老板发工资的时候都会体会到一种阵痛，每个月到了那几天，你都会体会到一种阵痛。但是我们应该明白的是，除了发工资之外，你还发了哪些东西，如果你仅仅是发了点物质食粮，而没有精神食粮，或者是精神食粮甚少。那么你就在做一件事情，就是把你的员工逐渐地驯化成与你若即若离的，高冷的、神秘的，像猫一样的员工。反过来我们需要想的是如何定期不定期地给员工发放精神食粮，他们吃了这些东西以后，也许会逐渐地形成一种狗不嫌家贫的习惯，对老板来说，这也许是一件很美妙的事情。
