大。与此同时，一个危机在悄悄的形成，那就是突然有一天，当它的能量供给不那么充分的时候，而它巨大的体型需要消耗大量能量，它就会在这个环境下整体灭绝。

事实上，恐龙就是这样灭绝的，它之所以灭绝是因为它太强大，或者说它有太显而易见的核心能力了。

# 例子：蚯蚓与海星

很多动物和植物选择了另外一种战略路径，那就是通过极端的弹性，而不是核心能力，让自己获得无限广大的生存空间。除了我们刚才讲的卷柏和水熊之外，还有很多的动植物也是这样的。

蚯蚓这样一种没有任何反抗能力的、极容易被伤害的动物，在你斩断它的身体的时候，它能够断肢再生。海星也有断肢再生的能力，有一个管理学家专门就这种动物写过一本书，叫《海星式组织》。当我们用刀砍掉海星的一个角的时候，一方面这个被砍掉的角会逐渐再生，长出一个完整的角；另一方面，被砍掉的那一部分它会变成另外一个小海星，它开始生长。它是一种非常典型的具有战略弹性的动物，它能够直接将你对它的伤害转化为对它的帮助。你如果把一个海星的所有角砍掉，你就是在帮助它繁殖。

据说，曾经在南美很活跃的游击队就具有这样一种能力。你越打发现越多。有兴趣的同学可以去读那本书，《海星式组织》。 

# 总结：至柔驭刚至坚

我们今天之所以讲到了好几种怪异的动物，其实是想给大家分享一种视角，就是在这个世界上生存下来，而且能够繁衍、发展、壮大的方式不止一种。有时候，看似最弱的方式往往是更强大的方式。还是回到老子的那句话，“以天下之至柔，驭天下之至坚”。
