我们今天讲一种动物——松鼠。松鼠非常可爱，我很喜欢。有一阵中科院动物研究所的几个专家，在颐和园驯化了几只松鼠，跟游人玩得特别好，去颐和园的时候我都要到那里去跟松鼠玩一玩，那时候我就觉得松鼠很聪明。

最近有一本即将在中文世界发行的书《创造性思维》，我在 pall 书里看到了一个关于松鼠的案例，特别有意思，先给大家分享一下。

引子：松鼠的创造性思维

美国有一个教授叫赞迪，他住在美国的宾夕法尼亚州，这个教授有自己的花园，花园里有一棵杏树。松鼠除了爱吃松子，其实也爱吃别的东西，比如说杏子，吃了外面的果肉还可以吃里面的杏仁。

有一天赞迪教授看见松鼠爬上了他的杏树在摘杏儿，他为了不让松鼠上去，就弄了一些塑料的锥子，把它绑在树干上。如果让我们来做的话可能会在树枝上插一些玻璃渣子，总之对于松鼠来说是致命的障碍，它再也爬不上去了。

但是有一天他发现，松鼠居然又在摘他的杏儿，而且杏树上松鼠越来越多，那是怎么回事儿呢？他大叫一声把这些松鼠都赶走了，之后他就在那里看着，看看松鼠是怎么爬上这棵杏树的。

他发现原来是这样：松鼠显然不能从杏树的树干上爬上去，这个巨大的障碍使得它要选择别的路径，教授无意当中打破了它的路径依赖。松鼠是爬上了旁边的一棵树，然后再跳到杏树上，这是一个高难度的动作，并不是所有的松鼠都敢跳、都能跳。松鼠中的“精英”做了一件很有意思的事，它跳上这棵树以后，再选择那些相对比较细软的枝条，顺着这个枝条往尖儿上爬，最后这个细枝就会往下垂，一直垂到了地面，这个松鼠就抱着这根细枝的头，其它的松鼠沿着这根细枝一下子就爬上去了，就开始摘杏儿了。

教授看了以后就很有感触，我们也很有感触。第一个感觉显然是松鼠很聪明；再往深处想，就是教授是如何见到松鼠的聪明的？如果他不在树干上设障，他就见识不到松鼠的聪明，也就是说他设置障碍，首先改变了松鼠的路径依赖，然后由于这个挑战使得松鼠给出了一种应变的方式，最后出现了一个很有创新性的解决方案，这个解决方案甚至比它们以前摘杏儿的方式还要有效率。

# 创新的定义

我对创新有一个听起来不那么正经、很通俗的定义：创新就是“不可能”河上的一座桥。有一条河叫不可能河，在这条河上有一座桥，这个桥叫做创新。没有河就不能有桥，创新的发生一定是因为有一个巨大的障碍，这个障碍大到什么程度呢？大到让我们深深的觉得不可能。这就是一种博弈，当环境出了这样一张大牌的时候，我们怎么想办法再出一张牌能压过这张牌，这张牌并不是你手里已经有的，你必须去创造出一张牌来压过这个障碍，这就叫做创新。

著名的英国历史学家汤因比，提出过一种著名的“文明发生生理学”：所有的文明都是由于挑战而导致人类被迫应战，应战的结果就是文明。

汤因比认为没有挑战的地方是没有文明的，如果人跟他的环境和谐相处，这是福音也是诅咒。什么诅咒呢？就是你永远不可能有什么创新了。所以在一些气候条件很优的的地方，饿了树上就会掉香蕉、掉椰子下来的那种地方，是不大可能有文明的。只有在季节交替非常的明显，尤其是冬天相对比较漫长的地方，人必须要解决人一出生就面对的三大难题。

小孩子一出生就会大哭，为什么哭呢？饥寒交迫。他在子宫里头是很温暖的，而且是不会感觉到饥饿的，吃都不用吃，他直接借助于脐带从母体里吸收养分，他一出生就面临饥饿和寒冷，所以他就会哭。

在有冬季的地方人类就会面临着饥寒交迫，因为冬天你不大可能找到食物，那你就必须要在冬天来临之前生产和存储食物，同时你必须要建房子、做衣服来避寒。当人类被迫这种时候文明就产生了、创新就产生了。这就是我为什么把创新定义为不可能河上的一座桥。

创新的理论有很多，关于创新如何发生的学说数不胜数。有一派我印象很深，就是当文明发展到一定程度的时候，也就意味着这个文明的已有路径走到了尽头。也就是说，这个路径能够给予你的全给予你了，没有新的路径这个文明就会慢慢的坏死。

当年汤因比就是这样评价中国的古代历史以及中国近代史的，他甚至说了一句让我们听起来不太舒服的话：不存在哪个文明消灭哪个文明，只不过是一种先进的文明把一种垂死的文明，在它病痛缠身、痛苦不堪的时候给予了它痛快的一刀。这样的理论我们确实在历史上能找到一些例证。

例子：日本德国的意外崛起

第二次世界大战结束的时候，世界出现了新的格局。这场大战导致了几个大国崛起，我们当然首先想到的是美国，二战之前美国在世界的影响力是很小的，二战以后美国成为世界的老七。当然也有国家不认为美国是老大，那就是俄国（苏联）。双峰并时，两个大国形成了长期的冷战局面。在这两个大国的旁边我们还看到了两个非常出人意料崛起的国家，一个是日本，一个是德国。

前两个老大是战胜国，他们是胜利者；这两个国家是失败者，而且是被打残了的。在二战结束的时候这两个国家一片废墟，能活下来就不错了。照理说发展特别好的是那些并没有受到战事创伤的国家，比如瑞典、西班牙这样的国家。但恰好相反，是两个遭受了沉重打击的、在某种程度上是经济已经破满的国家。尤其是德国，二战后期盟军除了往德国的各大城市投炸弹之外，还投了大量的假币，把德国的金融体系都给摧毁了。

德国战后有一段时间出现了很多奇形怪状的货币，比如香烟，很多东西是用烟来计价的，那种破落贫穷，我们在各种影视作品里都看得到，但是它居然那么快地崛起。而且最有意思的是，当德国（苏联）已经不再是一个大国的时候，德国仍然强大，有一种解释就是战争巨大的破坏，其实是给他们创造了一种新的环境，尽管这个环境是非常可怕的。用我们前面的话说，德国也面对着一条不可能的河。

日本也面临同样的情况，或者说由于这个巨大的挑战导致这两个国家被迫应战。挑战只不过是激活应战的一种方式，不可能其实是创新的一个引子。

例子：iPhone解决的“不可能”

我们今天都在使用智能手机，已经司空见惯，但我们今天可能忘记了一个事儿，所请智能手机，一个很重要的特点就是触屏，没有键盘。记得2007年我使用iPhone的时候经常会被别人拿过去当怪物来看，这是手机吗？怎么连键盘都没有。

智能手机最先提出概念而且推出成熟产品的，不是苹果，而是诺基亚。但是诺基亚在做智能手机时，面临一个特别大的挑战，那就是你生产一台本质上是电脑的手机，就意味着必须做到两件事：第一，键盘必须是全键盘，而不是九宫格的键盘，九宫格的键盘对功能手机是够用的，对于智能手机是不够用的；同时，既然是智能手机，那就不仅仅是显示一个电话号码、显示短信息的问题，它的屏幕要尽可能的大，屏幕上要显示很多的图文。

这两个诉求都是必不可少的，同时它又是正好对立的。手机那么大，屏幕大了就意味着给键盘留下的空间小，键盘是不能够无限压缩的，屏幕也是不能够压缩的。这个悖论非常折磨诺基亚，诺基亚想了很多的办法但是都没有解决这个问题，他们总是试图去调节屏幕和键盘的矛盾。

最后这个非常让人头疼的问题，触动了苹果公司，逼迫苹果公司去应战。最后他们做出了一件让人耳目一新的创新，那就是不可能河上的一座桥——键盘要最大，屏幕也要最大——最后的结果就是触屏，既是键盘又是屏幕。从这个案例里我们就能意识到，为什么说创新是不可能河上的一座桥。
