# 成功后的归因谬误

前不久我们讲了一个概念叫归因偏差，或者叫归因谬误。我们在追溯一个原因的时候，常常会犯一个我们自己不知道的错误，那就是把一个结果在一个巨大的原因包、或者叫原因黑箱里，挑出某个单一原因作为这个结果的原因。

这种归因偏差或者叫归因谬误，给我们带来的危害远远超乎我们的想象。且不说那些成功学的谬 incr，就是我们在总结自己过去的时候，也常常会陷入到一种自我欺骗当中。我们常常把一个结果归结为一个单一的原因。尤其是你有意为之一件事情，的确可能是你看到的后果的原因之一，但是它也是与诸多的或明或暗的其他的原因交织在一起的。

简单地说，原因不是一条光线，而是一道光谱，你看到的只是一道光线，其实你仔细看的话是存在着一个光谱的。我们知道一道光线经过三棱镜的折射，就能看出来橙黄绿青蓝紫。在每一个光谱之外，红之外有红外线，紫之外有紫外线。那里的复杂程度远远超乎我们的想象，但是我们常常是看不到这种原因的复杂性。

在产品开发和营销的时候，也容易出现这种归因偏差。比如说一款产品成了爆款，既有来自产品自身的多种显性和隐性要素，也有来自外部诸多你看见和看不见的因素，有时候时尚潮流，社会和文化的氛围，甚至某个突发性事件，这些跟你的努力没有关系，它常常是偶然出现的。但是这种外部的因素很可能大大影响你这个产品是否是一个爆款，也就是说大量浑然不知的因素在暗中成全你，或者在暗中消遣你，毁灭你。但是我们用这种机械论的、格式化世界观，我们是看不到这一点的。

尤其是一些企业，在制定战略的时候常常爱回顾战略。当我们在回顾过去的时候，首先映入眼帘的就是我们过去的成功。但是，这个成功到底怎么来的，跟你相关的付出是一方面，而跟你不相关的很多因素你看不到。还有，你的付出之所以有效，它是在特定的语境，特定的生态下产生的作用，如果那些语境和生态不存在的话，你的努力也没有用。

还有这样一种可能，就是昨天的蜜糖是今天的毒药，昨日之是今日之非，这个时候就很危险，如果你要依据这种回顾来制定未来的战略的时候，就会很危险。我们经常听到那些曾经做出过辉煌业绩的那些老板们说一句话——“我当年就是怎么怎么样”，他所有的思考和行动的前提都是他过去的成功。但是这个过去的成功只是一个结果，导致它的原因是五花八门，形形色色，你的感知能力完全没办法触达的那些东西在决定你的成功。

在统计学里头有一条原则，凡是回顾性的调研都不能证明因果关系，至多是相关关系、同步关系。什么叫相关关系和同步关系？就是“雄鸡一唱天下白”，同时发生的偶然关联，雄鸡叫了，天亮了，这是两个事件。但是这两个事件反复地在一个时间序列里出现，我们就可能认为它是一个因果关系，它其实不是。

# 例子：为什么亚马逊能做成Kindle，索尼不能？

索尼公司曾经也研发过一款看起来跟Kindle差不多的阅读器。你肯定没见过，我也没见过，因为它根本没推向过市场。它在小范围试销结果非常惨，最后他们就放弃了。为什么在小范围的试销里头就惨败呢？看上去这款产品跟Kindle没有什么差别，消费者为什么完全无感甚至是抵触呢？到了后来他们才慢慢的有所觉察。

说到这里，我就想起一件事。我们有些中国女性在国内看起来至少不是那么美，为什么在国际市场上很走俏，一会儿黛多克，一会儿儿普京，一会儿布莱朵。这些人都是见过市面的人，他们为什么被同一个中国女人所迷倒，而这个中国女人在她的祖国被认为起码外表上并不是那么优秀。这里就跟一个东西有关，就是隐形开关。

美国选举的时候有一个词叫“隐秘的G点”，这词太性感，我们不用，就叫“隐秘开关”。就是说你在说服别人、取悦别人时，使了各种各样的招，别人都无感；恍然也不知道为什么，他就一下子特别感兴趣，这就是那个隐秘开关打开了。也许某个模特也好，某名中国的女性也好，她们身上存在着某种可以打开西方男性隐秘开关的那种特质，我们自己是没有感觉的。

我们在使用一款产品的时候常常只是觉得它的体验很好，但是为什么体验好？我们自己不太清楚。就像有时候我们会莫名其妙的会对一个人有好感，或者对一个人有恶感，我们都说不清楚到底是为什么。我们已经说了，有个隐秘的开关。隐秘的开关打开了，你就很喜欢他，或者你很厌恶他。但是我们做产品的时候不能撞大运，一款真正获得消费者普遍认可的产品往往包含着某种隐秘的开关，你看上去觉得也平淡无奇，为什么它卖得那么好？

我们就以Kindle为例。Kindle正面底部的那些按键位置、大小、形状它是经过了大量的反反复复的人体工学的研究和测试。你用它的时候你只是感觉很顺，很得劲。它非常得劲到你完全不知道它为什么得劲。

索尼却没有做这样的探索，本质上是一家家电公司；亚马逊是一家互联网公司，在互联网公司里头也是最强调一切以客户为中心的这么一个公司。Kindle这个产品很火，我有一段时间死活不知道为什么它那么火，看上去跟苹果的产品相比显得那么黯淡，显得那么的不光鲜，但是它卖得非常的好。当然，它有很多人很多的原因，其中有一个很重要的原因就是它暗中植入了某个隐秘的开关。

最近我在重读《韩非子》，他有一篇文章叫《说难》，就是说说服别人是如何困难。他是以帝王为目标客户的一个人，那他的主要工作就是去说服那些帝王。他在说服的过程中积累了很多的经验，后来他写成了这篇文章。他里头就讲到，你真正要说服一个人，一定要找到在大量的他已经明说、或者你想当然的那些 hinaus 点之外的某个东西。这个东西往往就是用力最小，但是效果最好。用现在的话说，它就是打开了隐秘开关，找到了隐秘的G点。效果非常好。

我们在开发产品的时候，不要自己想当然，第二是不要人云亦云，自以为是的以为客户需要什么。我们要开发爆款的产品首先要有个意识，我这款产品的隐秘开关在哪里，连这个意识都没有的话，要推出爆款的产品可能就很难。

但隐秘的开关不是下赌注，它要经过反复复杂的测试，通过一次次的迭代，在一次次的猜想和反复当中渐渐地接近那个隐秘的开关，最后你的产品让用户觉得很顺、很得劲、很爽，同时他都不知道为什么让他很爽。原因我们已经说了，你打开了他 的隐秘开关。
