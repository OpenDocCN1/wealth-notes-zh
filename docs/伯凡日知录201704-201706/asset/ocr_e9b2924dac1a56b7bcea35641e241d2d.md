关于《黄山松的生存之道》：动植物的奋斗目标都是求存，如果说繁殖下去对我们真的是那么首要的任务，那么在我们人口大爆发的时代，为什么越来越多人的选择做丁克或不婚的生活，看起来是与物理繁衍目标背道而驰？是否是时代从其他方面满足了人们对繁殖目标系统的需求，繁殖目标系统的边界比我们想象的要大而广？

“人口爆炸”这个词现在越来越少听说，因为越来越多的国家面临的不是人口爆炸，而是人口快速萎缩的问题。尤其是在发达国家，人口出生率锐减。

在新加坡，这样一个以重视生育、“不孝有三无后为大”的华人为主的社会，人口出生率也会那么低。在法国，政府推行了各种各样的措施，颁布很多政策鼓励生育，比如一个妇女如果生到第三个孩子，得到的补助相当于她有了一份正式的工作，但即使这样，法国的人口出生率也只有1.98。

1.98是什么概念？保持人口不增不减的出生率是2.1，一对夫妇生两个，加上有的孩子长不大，或者将来由于各种原因没法繁殖后代，正好平衡。但是，1.98就意味着人口的净值会减少。

我们中国目前的生育率，在实行二孩政策之前我看到一个数字是1.6，这是一个很低的数字。原因当然有很多，其中一个原因是城市里很多人选择了不婚、晚婚、或结婚以后坚定不移地不要孩子。

为什么会出现这样的状况？有一句话叫“城市化是最好的避孕药”。这里说的避孕是一个多向度的避孕，比如不结婚也算是避孕、结婚不生孩子也算避孕，还有同性婚姻，还有很多很多多形态的对于传统婚姻的代偿性的机制、组织，使得现在的结婚生育面临非常大的问题，以至于一些经济很发达的国家为这个问题苦恼不已。

# 一、协作后的家庭空心化

我看到有一个预测是俄罗斯到2030年，可能人口下降到8000万。占大半个欧亚大陆的这么一个国家人口只有8000万。为何会出现这种情况呢？简单的说就是“家庭”这个传统的组织结构在城市化、网络化时代遭到了前所未有的挑战，或者说被空心化。

无论是植物还是动物，它们的生命轨迹都是由既定的程序固化了的，它的生命无非是在这个程序的驱使之下分阶段的发展而已。这其中个体是没有任何自由意志决定自己的选择的人类不同于动物的是，人类有自己的选择。

# 二、集聚后的长尾效应

城市化还有一个功能，就是长尾效应。它将一些本来是小众细分的需求收集起来，将这些人群聚在一起，让他们能非常方便地沟通和交流。比如同性婚姻只有在城市化的社会里才会越来越成为一种亚文化。

# 总结：意义的源代码已经被篡改

总而言之，随着社会的发展，随着城市化和社会的网络化日益明显，人不再是必须附属于一个像家庭这样的小共同体内。也正因为如此，人生的意义发生了改变。

# 一、不适者生存

我记得德国哲学家莱布说过，“不适者生存”。听起来好像跟达尔文相反，但其实他们正好互相补充。他举了一个例子，当初在非洲有大量的森林被稀树草原所替代的时候，最初的猕猴家族里有些想留在树上，它们就找到了它们已经早已适应的森林，因为别的地方还是有森林的。

# 二、自由与约束

这涉及哲学上一个很古老的问题，叫“自由与约束”的问题。有 一派观点认为，自由就是没有约束。还有一派观点认为，没有约束就没有自由，约束恰恰是让我们追求自由的一个契机。
