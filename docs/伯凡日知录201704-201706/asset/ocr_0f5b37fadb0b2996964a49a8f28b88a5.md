6.1 | 蛇的策略之二：弹性

# —— 第136天的知识笔记 ——

我们昨天讲到了毒蛇为什么这么毒：它是一个残化之身，它有显而易见的劣势，所以它进化出了一种核心优势，在创新上做到了极致。

我们今天继续讲蛇的另一面。

# 一、蛇的适应性

毒蛇之所以有毒，是为了最有效率的获取猎物，也就是获取资源，这叫开源。但是，蛇面对的生存环境是非常恶劣、非常具有挑战性的。要生存下来，除了极致的开源，还有要极致的节流。它要活在这个世上，就要最大化地适应这个充满着变化和不确定性的环境。

世界上 सहाय两种人，一种是让环境适应自己，一种是让自己适应环境，适者生存。

越强大的动物越不太去迁就环境。但是蛇作为一种弱势动物中的弱势动物，必须要最大化它的适应性。其中适应性的极致就是高度的弹性。当环境发生变化的时候，我也能做最大化的变化。

说到弹性，大家可能马上想到了蛇的那张嘴，想到了“蛇吞象”的说法。蛇的嘴是富有弹性的，周围的皮平常叠起来，扩张的幅度远远大于大多数动物。“狮子大开口”是因为狮子的口本来就大，蛇大开口是看上去口很小，但是能张大到难以置信的程度。所以，才有了蛇吞象的说法。

蛇类的颌骨上，肌肉可以拉到非常非常长，以至于连接在一起的叫肌动蛋白能够被扯开。也就是说它的这个构成材料都会被扯开到这样一种程度。撕裂以后，它有迅速恢复到原位的能力，这是蛇的弹性一个很明显的表现。

但蛇的弹性远不只是表现在这里。我们知道蛇都有冬眠的能力，它冬眠是因为没有东西吃了就洗洗睡了。蛇在不冬眠的时候也会遭遇多少天忍饥挨饿的情况。所以，它就必须要养成为一种听起来很不健康、其实是很利于它生存的一种方式，叫暴饮暴食。所谓“吃了上顿没下顿”，这个下顿是什么时候？真的不知道。有蛇上顿跟下顿相隔的时间甚至是以天计，而是会到几个月。辟谷的同学们应 该向蛇学习，但是辟谷的朋友们做不到，因为我们的身体里没有这样一种机制。

蛇能够忍饥挨饿这么长时间，一方面是为了适应恶劣的环境里可能长时间找不到猎物；还有一点，即便有动物，它也要减少捕猎的次数，因为它一旦出了洞，就意味着巨大的危险，所以它要减少出行的风险。

为什么说辟谷的同学们做不到蛇那样呢？是因为蛇的机体里，内脏是极富弹性的。比如蟒蛇在吞下猎物的几天之内，它的小肠和肝脏的体积和质量会增大一倍，肾和心脏的体积也会随之增加，以便它消化猎物。它的新陈代谢率可以提高到平常的45倍。消化完了后，它把这些能量存储在体内，下一顿最长可以隔到几个月。蟒蛇这个时候，几个月不吃东西的话，那怎么能够活下来呢？有专家说，当蛇把它的新陈代谢率降到接近于0的时候，它几乎是一条死蛇。如果对它进行体检的话，你很不得给它一张死亡证明。

# 二、劣势的代偿

讲儿童教育的时候，有一对概念叫“蒲公英式小孩”和“兰花式小孩”。蒲公英式小孩就是适应能力特别强，风来了把我吹走，风走了把我留下，哪里有土地哪里就是我生长的地方，有些小孩是这样的。还有一种小孩是兰花型的，林黛玉式的，他只在特定的环境里头长大，环境稍有变化的时候，他就死给你看。

如果给蛇归纳出一种生存哲学的话，可以用这样一句话：有也行，没有也行。我们经常说要像爱护眼睛一样的爱护什么东西，眼睛是很重要的吧？对蛇来说，眼睛也可以不要。有眼睛完全是瞎的蛇，还有很多的蛇即使有眼睛，但它都是近视眼，视力都很弱。因为在阴暗潮湿的环境里生存，甚至是在地下生存，眼睛的作用不大。所以，慢慢的它的眼睛就跟它的四肢一样就变得多余了。

人和动物生存在这个世上，第一目的是求存，而不是求真。就像蝙蝠不必有很好的视力，蛇也是这样。但是，缺少一个东西，就一定要有代偿的功能。只要这种带有补偿性的功能能够帮助它在这个世界上生存下来，那就足够了。所以蛇虽然视觉不行，但它会用其它的方式去感知周围的环境。比如说它有热感应，简单的说它有一种红外线传感器，能够察觉到环境中极小的温度差异。一旦有危险动物出现的话，它不仅会马上发现这个情况，而且能够准确地感知猎物的位置。

由于视觉退化，它的嗅觉非常的灵敏。它的舌头是细分化的舌头，是分叉的舌头。这种设计能够让它锐敏地感觉到猎物留下的气味，它甚至能够感受到分子级的气味。它根据这种气味感受能力，不仅能感知猎物的存在，而且能追踪猎物，按图索骥、顺藤摸瓜地找到猎物。

说到互联网创业，我们经常会说到“剩”者为王，剩下的才是王。蛇这种动物那么的弱小，它的生存空间、生存机遇是很少的。但是，它居然在这个充满着不确定性、复杂性和异变性的世界里头生存下来，不断的繁衍。应该说它也是王者，也可以说是王者荣耀。

# 两期内容总结：战略的极致与弹性

如果说让我们向蛇学习，听起来比较别扭。但蛇的确有不少值得我们学习的地方。

蛇首先是一种具有高度适应性、具有高度战略弹性的动物。一方面它能够将一种策略发展到极致；另一方面它又能够让它的策略富有弹性，让自己的整个机体随不确定性的环境的变化，能保持巨大的变化。

一个卓越的战略不仅在于它的有效性，更在于它的弹性。我们好多的企业，得势的时候势不可挡，威风八面。但是，突然之间就告别了这个世界，原因就是它不能够适应这个快速变化的世界，它的战略没有弹性。而蛇是一种非常具有弹性的生物。

蛇还有一方��，是它具有敏锐的感受能力。它不仅是在产品上做到极致，而且在感受力上也能做到极致，它能有红外传感器，它能有辨别分子级气味的能力，也许就是蛇这样一种弱小的生物得以在世界上繁衍生息的秘密。
