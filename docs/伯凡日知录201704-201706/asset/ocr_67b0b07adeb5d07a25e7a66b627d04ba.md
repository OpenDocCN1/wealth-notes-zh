6.6 | 印度的沙盒创新

—— 第138天的知识笔记 ——

# 引子：极端条件离我们并不遥远

有同学问，你为什么要讲黄山松？（见本专栏5月29日内容《黄山松的生存之道》）那是在最无可奈何的环境里想出的办法，虽然也算是一些绝招，但这跟我们目前的生存处境有什么关系呢？我们还不至于什么资源都没有，在石头缝里头求生存。

其实大家应该明白一点：自2015年下半年一直到今天，中国创业投资的市埸实际上是在逐渐萎缩的。虽然资本总量并没有特别大的缩减，但是资本的集中度变得越来越明显，也就意味着很多的初创企业拿到资金的机会会越来越少。所以，有些企业其实早已经感受到了资本的严冬。所谓资本严冬就是你获取资源资金的可能性越来越小，你如何在这样一种环境当中求生存，这就是我跟大家要讲黄山松的一个很重要的原因。

我们上周讲到的那几种东西，都有一个共同的特点：在极端的挑战、极端的约束条件下如何寻找新的生存空间。这一过程就叫做创新。

# 一、何谓“沙盒创新”

今天跟大家讲一个我其实很久以前就想讲的话题，叫沙盒创新，Sandbox Innovation。这是一个专门的名词，是由印度裔的美国管理学家普拉卡拉德提出来的一个概念。

所谓沙盒，就是一个盒子里装满的细沙，象征着它的外部约束条件是非常明确、不可更改的。但是你又要创新，那怎么办呢？只能在一些细小的环节上保持弹性，这就是沙盒创新。

他说的是印度的那些底层淘金企业的创新方式，也是一种商业模式。我们时不时会看到新闻，有些中国游客或者去印度出差的人，用各种方式把印度的药品带进来，实际上那属于走私的范畴。还有一种旅游公司，专门组织那种所谓的主题旅游、医疗旅游，其实这些去旅游的人不是去看风景的，而是到印度去买那些药品的。同样一种疗效的药品，在印度的价格和在中国 的价格有明显的差异，甚至与香港的价格相比也显示出格优势。关键还不在于它的价格便宜，而在于它是有 效的。

去年5月份我去了一趟印度，联想印度分公司的CEO说，在印度一个产品要想卖得好，必须符合两个条件：一、性能不打折扣；二、价格大打折扣。这两句话就可以概括沙盒创新的本质。

在印度的这个绝对贫困人口占4.5亿的国家里，你的产品要有销路，必须要将价格降到足够低，低到这些真正的穷人都买得起，才可能拥有市场。所以印度的很多行业，不仅仅是医药行业，出现了一批这样的企业，他们在产品的功能、性能不打折扣的情况下，最大限度的降低成本。这也是在严格约束条件下的创新。

# 二、为什么印度能产生沙盒创新

例子：穷人做得起的眼科手术

眼科手术在全世界都是很昂贵的一种医疗服务。有一种说法叫金眼科，就是眼科是在整个外科手术里头是最好的，最好的外科医生就是做眼科手术，因为它的难度最大、风险也很大。要培养出一个真正合格的优秀眼科医生是很难的，这就意味着做眼科手术必须要付出很高的价格。

但是，像印度这样一个十几亿人口的国家，光得白内障的就有多少人，其中有很多的穷人，如果不做眼科手术，就只能双目失明，这就给印度的医疗界提出了一个课题，这个难题我们可以把它称之为“不可能河”。在这个不可能河上要搭一座桥，就是又要这个眼科手术有效，同时成本要低到最穷的人也能够负担得起。所以，在印度出现了一种在西方国家不可能出现的眼科手术方法，价格只相当于欧美国家的1/10~1/15，但是它又是很靠谱的，它是如何做到的呢？

在欧美社会，他们不会遭遇印 度人面临的问题，因为欧美人付得起钱。而在印度的眼科手术，其实可以称之为眼科手术流水线，因为最优秀的眼科手术大夫一天也顶多能做4个手术，这4个手术做下来都累的无法站立，因为这是体力的消耗，更是大量的注意力、脑力的消耗，人必须 要保持高度的专注。

但是，他们注意到一个事实：最优秀的眼科手术大夫，绝活也只是最关键的地方割一刀，其实有大量的工作是没必要他做的。传统手术的方式是由这个大夫从头做到尾，所以他一天也只能做4个手术。于是在印度医里，他们把所有的病人按成一套流水线，很多辅助的工作由不同资质的外科医生来做，而只把最关键的那一刀留给最优秀的眼科手术大夫。所以他一天能做很多的手 术，所以它叫做眼科手术的流水线。

大家可以想象一下，这样做眼科手术的成本就比传统手术的成本要低的多。如果印度没有那么多穷人，他们是不会想到用一种新的办法、用更低成本的方法来做手术的。

例子：穷人买得起的假肢

在印度这样一个十几亿人口的国家，需要假肢的人数量是相当大的。但是，这些需要假肢的人都是付不起钱的。

印度有一种证件，这个证件正式的名称我忘了，但是在印度干脆把这些人称为穷人，把这个证件称为穷人证。拿着这个证件就可以便宜地买到面粉，我算了一下，大概是2毛钱人民币一斤面粉。也就是 说，他一天只花两毛钱就能吃饱肚子。据说拥有这种证件的人占20%到30%。这些 吃饱只花2毛钱的人， 即使他们的腿断了，手臂断了，他能够花多少钱来买假肢呢？所以这个价格就必须要做到足够的低。

在这种市场环境下，印度的企业就开始研发新的材料、新的工艺。他们做出的假肢性能跟正常的假肢没有什么差别，但是这些假肢的价格只有欧美市场的1/8到1/10。这就是在特定约束条件下导致的一种创新。在我们看来，这也是一种商业奇 迹，这个奇迹的发生恰恰是由于它的约束条件太严格了。这种创新我们就把它叫做沙盒创新。

# 三、沙盒创新对中国创业者的启示意义

沙盒创新对于那些面临资本严冬的创业企业来说有什么启示意义呢？

+   一、在资源很少的情况下如何才能够活下来，如何才能够做出一个看着不可能的产品，印度的企业提供了一种思路；

二、我们中国有些创业者从一开始，就不自觉的踏入了一个误区，那就是去赚有钱人的钱，不去赚穷人的钱。因为，他们认为穷人的钱是非常难以赚的，或者根本赚不到的，只有富人的钱才是好赚的。

但事实可能正好相反。我问几个问题，大家就可能明白了：

+   1. 日本的首富是谁？
2. 德国的首富是谁？
3. 西班牙的首富，曾经也做到了世界首富的人是谁？

答案是，日本的首富是优衣库的老板；德国的首富是一个廉价超市的老板；西班牙的首富是ZARA的老板。他们赚的钱都不 是富人的钱，至少他们客户的主体不是富人，而是穷人。穷人的钱不好赚，但是穷人有他们的刚需。你之所以觉得他们的钱不好赚，是因为你没有沙盒创新的能力，没有在成本上将不可能的事情变得可能的 这样一种能力。

赚穷人的钱还有一个非常重大的优势，那就是不仅他们有刚需，而且数量非常大。他们在社会金字塔的底层，金字塔下半部分 的面积是远远大于上半部分面积的。所以，如果你能够创新出一种产品，穷人愿意用，而且买得起，那将是一个巨大的市场。

沙盒创新给我们最大的启示是，在中国这样一个人口众多，而且大多数人还不是富人的市场里，如果你能够生产出他们很想买，而且买得起的产品，不管这些产品是医药还是医疗器械，还是服装，还是日用杂货，你都有可能成为中国的第一富。我觉得这样的首富对中国更有意义。
