# 1.简史

这些年来我们可能读了不少以“简史”命名的书，《时间简史》、《万物简史》、《21世纪简史》、《人类简史》，今天我们又都在读《未来简史》。大家有没有注意到，《未来简史》这个书名是不是听起来有点有悖常识，未来都没有开始，怎么就有了简史呢？历史说的是过去的事情，怎么未来也有了简史呢？我们就从简史起，本周的《伯凡日知录》就和大家分享一下，为什么会出现这么多的简史体的书，简史的真正的含义到底是什么。

# 2.猫和狗

我们讲到了不少动物，以前我们讲到了熊猫、讲到了狼、狗，还讲到了斑马，还讲到了蚕等等，我们这周要讲一种常见的动物，就是猫，为什么猫是那么高冷、那么神秘，它跟人相处的时候为什么总是表现出一种若即若离的状态。狗不嫌家贫，但是猫常常是嫌家贫的，狗和猫这两种很不一样的特征的背后，到底有什么样的机制呢？

一个公司里头，如果我们对员工进行分类的话，我们是否可以把员工分为狗型员工和猫型员工呢？

# 3.核心劣势

本周讲到了一个听起来也有点违背常识的概念，叫核心劣势，我们只听说过核心优势，难道还有什么核心劣势吗？大家可能没有想到的是，有很多的核心优势常常是跟核心劣势密接相关，我们就以古希腊文明为例，跟大家分析一下到底为什么核心劣势会导致核心优势。

# 4.挤出效应

挤出效应说的是人的行为有多种动机，当我们对一种动机进行激励的时候，有可能会导致零激励甚至负激励，如果企业给那些自动加班的人发加班费，会导致一种什么样的结果？大家如果感兴趣的话，也听我仔细地分析这背后的机理。

欢迎大家收听本周的《伯凡·日知录》。
