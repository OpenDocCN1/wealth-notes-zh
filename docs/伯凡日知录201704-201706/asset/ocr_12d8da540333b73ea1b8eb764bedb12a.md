007比较多的话，你发现这个时候不是故事的结束，恰恰是一个故事的开始。

# 例1：007的失败只是序幕

007这个的系列电影有一个很大的特点，就是它的序幕特别的长。基本上那个序幕就好像是一部电影，这个序幕的结尾常常是詹姆斯·邦德历经千辛万苦终于找到了一个什么秘密的据点，找到了他所要的一个什么秘密武器或者秘密文件，发现探照灯打过来，他被包围，这时候电影才刚刚开始。

所以，乞兵思维也好，007的思维也好，不过就是一种我们在面对极其复杂，充满着各种偶然性的世界里，我们如何恰当的面对这个世界的思维方式。事实证明，乞兵思维以及与乞兵思维相关的那些思维方式恰恰是成功者必备的一种思维方式。

# 例2：犹太人的流亡与商业头脑

犹太人在几千年的历史当中，他们已经接受了一种观念，生来就是被迫害的，生来就是被追逼的，生来就是一个偷渡客。这就是他们的世界观。这就是罗网斯，就在这里跳吧。没有一个所谓的理想世界，让你安心做自己想做的事情的一个世界。

# 例3：“大不了退回去要饭”

好多年前我看过一部商战电视剧，这是我看过的为数很少的商战电视剧之一。那里的主人公创造了很多的商业奇迹，他之所以能创造奇迹，与他的出身密切相关。因为这个人是要饭出身。在长期的要饭生涯当中，他已经形成了一种世界观，或者说是一种意识的参照系。在他眼里，即使他已经是一个大老板了，他还是一个乞丐。

这种思维有什么好处呢？首先，他不会把他的成功看成是必然的，他认为失败是必然的，眼下的成功只不过是稍稍远离了失败，所以他有一种强烈的危机意识。第二，当他遇到一个充满风险的重大的决策的时候，其他的商人都会特别害怕失败，而他首先想到的是富贵险中求，大不了再去要饭。

一个要了那么多年饭的人，他虽然是个文盲，我相信他的潜意识当中同样懂得一个道理，0是最大的负数（注：仅从思辨角度说明数值比较，数学意义上0既不是正数也不是负数）。这个0也乙就是一无所有，是他把自己锚定在这个世界上的一个原点。当他总是在基于这个原点在思考问题，在处理事情，在做决策的时候，他就获得了一种其他没要过饭的人不可能具备的那种强悍。

# ——延伸思考——

大家听完我上面的话是不是觉得很悲观呢？其实这是一种积极的悲观主义。跟这种世界观相反的是一种消极的乐观主义。或者说这种世界观的背后是一种回归原点的勇气和能力。在这个世界上积极的悲观主义往往要比消极的乐观主义要有用的多。只有这种世界观的人他所拥有的前景可能恰恰是相当乐观的。
