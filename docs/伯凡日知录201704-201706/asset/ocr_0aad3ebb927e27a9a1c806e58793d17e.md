# 本周预告 | 道家思想的现代应用

本周预告 | 道家思想的现代...

本周的《伯凡日知录》讲的四个话题，可以说都跟《道德经》、道家思想有关。经常有同学留言，希望我讲讲《道德经》。但是我不能系统的讲《道德经》，本周我只是通过一些案例，通过一些概念让大家从一个侧面对《道德经》有一个感性的，也许是很局部的认知。让大家在这种惊鸿一瞥当中感受到《道德经》的魅力。

# 1、萌是一种竞争力

我首先讲到的是《道德经》的第五十五章的一个话题，我把它概括成萌是一种竞争力。这听起来很让人诧异，这样一个话题与《道德经》好像是很不搭界的。大家听完我的分析以后，也许会觉得还真的能够认同我的观点：萌为什么是一种竞争力。

# 2、信任是一种杀伤力

我讲到的第二个话题是信任的杀伤力。常识告诉我们信任是好的，是善的，它是一个道德范畴。但在我看来信任绝对不只是与道德有关。信任有它很强硬的一面，甚至可以说信任有时候具有一种强大的杀伤力。我通过一个大家听起来可能会觉得有点不寒而栗的故事，让大家具体的感受到信任是一种力量，而且是一种强硬的力量。

# 3、管理亚自我

我还讲到了一个话题叫管理人其实不是在管理某个人，而是在管理这个隐藏在这个人内部的某一个亚自我。这个亚自我是他的众多的自我当中的某个面向。每个人在不同的场景下会呈现出完全不同的亚自我。一个善于和别人沟通，和别人相处，善于管理别人的人一定是一个对人的亚自我有深切的感知，并且能够积极主动的与人的亚自我打交道的人。

# 4、改变，从小动作开始

最后，我还讲到了一个话题，许多意义重大的改变往往是来自于看上去微不足道的小动作。一个重大的变化往往是由诸多不可预知的要素连锁反应和发酵而成的。在所有要改变的对象当中习惯是最难改变的一种东西，我们无法真正有效的去改变自己的习惯。如何避免痛下决心强力改变之后半途而废，回复到原位甚至退步？这里涉及到一对概念，杠杆解和症状解。到底什么叫杠杆解、什么叫症状解，杠杆解为什么威力无穷，请大家和我一起去分析一个个的小案例，从而见微知著。
