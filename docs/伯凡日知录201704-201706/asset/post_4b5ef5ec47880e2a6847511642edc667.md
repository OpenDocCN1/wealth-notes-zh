# “一万小时定律”的真相是什么？

本周的伯凡日知录首先讲到了一万小时定律。这个大家纷纷谈论的定律，其实是很容易遭到误解的，并非你在一件事情上花上一万小时，你就能够成为这个领域的专家。

看一万个小时的电视，不可能成为电视专家；刷一万小时的微信，也不能够让自己成为某个领域的专家；哪怕是用一万小时去刷知乎，也很难实现认知的升级。这里的关键在于，要获得认知升级必须要经历认知的循环。

获取知识就像获得利息一样，我们知道一笔钱让我们最终获利的大小，既不完全取决于利息的大小，也不取决于时间的长短，而是取决于现金周转的次数。也就是说能否赚到很多的钱，取决于这个利息是周息、月息还是年息。所以我们在学习的时候，一定要尽可能多的实现提高认知周转的次数，否则我就可能是一个永远的留级生。

# 学习的本质是什么？

本周的伯凡日知录通过对富兰克林学习写作的案例进行分析，展示了学习不是知识和信息的囤积，在单纯的囤积和收藏中，我们享受着一种虚幻的获得感。这种滞留在舒适区中的伪学习，其实是一种学习的拖延症。

学习的本质是既有概念体系和解释网络，受到创伤后的自我补偿机制。是持续的让既有的认知进入到一种不均衡，不稳定状态以后的系统更新；是认知在遭遇挑战、威胁和危机之后放弃旧概念，吸纳新概念的重新建模。

为什么说学习必须要有假想物？为什么学习需要以挑战性情景为抓手？为什么说没有这样的抓手，我们就很难获得认知的升级？如果大家对这些问题感兴趣，就收听本周的伯凡日知录。

# 90后与90前，如同生姜与苹果

本周的伯凡日知录还讲到了一种听起来很怪异的哲学概念，这就是由法国哲学家德勒兹提出的一个概念，生姜。

生姜是一种无生长层次，无生长方向，反谱系的植物。生姜的那种随机性、不确定性形态与云很相似，它代表着一种后现代状况。为什么苹果和生姜有如此明显的差异，为什么说90后与90前的人的差别恰好相当于生姜与苹果的差别？这对于我们如何管理和激励90后，如何与90后相处有什么样的启示？请听本周的伯凡日知录。

# 一万小时定律真的成立吗？

这些年，有一种学习理论非常流行，叫一万小时定律。和很多流行的理论一样，普通人对这种理论的了解不过就是一句话，一句听起来特别简单、特别容易理解的话，要不它也不会流行。

我们对一万小时定律通常的理解是：你想成为某个领域的高手，就要在这一上花一万小时的时间。一万小时到底多还是少，我们是没有概念的。

为什么有的人的认知长期处于停滞的状态，因为他的循环周期太少，周期持续的时间太长。如果你每年的知识增长1%，那就比较危险了；如果一个人的学习收益是按一辈子计算的话，也就是说你一辈子都没有完成一个完整的循环，那就很可惜了。

我们现在再看一万小时定律，关键是这一万小时里，认知循环周期的多少。如果这个周期的数量多，每一个周期持续的时间短，那么你获得的认知的量就会很大；如果循环周期很少，或者说迭代次数很少，那即使花上两万个小时，你的收益仍然是很少的。所以我们要破除对一万小时的迷信，要从关注时间的量转向关注时间的质，无论是挣钱还是认知，都要关注一个非常重要的点，那就是循环周期。
