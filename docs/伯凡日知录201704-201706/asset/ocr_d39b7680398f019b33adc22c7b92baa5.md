# 4.20 | “后现代”的起源

4.20 | “后现代”的起源

# —— 知识笔记 ——

昨天的战略与战术提到了围棋，关于围棋有一个学术八卦。

有一个法国哲学家叫德里达，很多人没听过他的名字，但今天说得沸沸扬扬的“后现代”这个词，跟他密切相关，他是西方后现代哲学最重要的代表人物。

所谓后现代，顾名思义就是现代之后。要理解什么叫后现代，首先要理解什么叫现代。就象北京有一个楼盘叫现代城，肯定是先有现代城，然后再有后现代城。

所谓现代是强调共识、强调知识的基础、强调结构性和稳定性；所谓后现代，就是这些东西都终结了，没有基础、没有共识、没有稳定性。所以有人把马克思的那句名言作为后现代的经典定义：

> 一切稳固的东西烟消云散，一切神圣的东西都被亵渎。

所以后现代说白了就是不稳定，就是亵渎，什么神圣拿什么搞事情。

德里达的思想有没有什么源头呢？当然，他的思想源头有一堆，但他有一段很重要的个人经历，对他的理论产生了非常大的影响。

中国在发生文革的时候，西方、尤其是法国，也发生了红卫兵运动。可以看到一些照片，法国的红卫兵在巴黎的街头游行示威等等。所以在那段时间，法国的有些知识青年对中国有一种朝圣的情感，他们想到中国来看看中国的红卫兵运动。

德里达就在那个时候来到了中国。来到中国以后，他看到了有两样东西让他非常震惊：第一是围棋，第二是大字报。

# 德里达眼中的围棋

围棋是我们中国的国粹之一，特别有意思的是，在文革期间它还没有被作为四旧被废除掉，还有很多人下围棋，比如说聂卫平。当时虽然已经上山下乡了，在农村、在农场里也坚持下棋。

他在中国看到很多人下围棋，作为一个西方人，他觉得很困惑，每一个棋子都没有确定的身份，唯一的差别是白和黑，分别属于对弈的两方，棋子的身份是完全平等的。

更让他不可思议的是，这种棋居然没有固定的路径。他熟悉的是国际象棋，国际象棋每一个棋子是有身份的，是车还是马，是国王还是王后，还是主教。每一个棋子不仅有身份，而且有固定的路径。中国象棋里，马走日只能走日，不能乱走；国际象棋也有车，也叫戍堡，它可以一路到底，横冲直撞；权力最大、最没用的就是那个King，就是我们中国的帅。它们都是有固定的活动范围，有固定的路径，有各自的走法，是不能乱套的。

由于有种种的规则，由于每个棋子有固定的身份，所以它是一个结构，是一个很稳定的结构，所有的厮杀都是每一个棋子有固定的身份、有固定的路径、按照规定的规则在走。而围棋的规则可以说降到了最小，没有哪不能走，完全是一个人人平等的社会。

而且最重要的是，它棋子的数量要远大于象棋，象棋总共加起来32颗子，每方是16颗子。而下围棋的时候，一人拿一个小筐，围棋的棋盘是19×19，双方各有181和180颗子，棋子的数量是象棋的十倍还多，我们也就理解了为什么说围棋代表人类智力的尊严。

上个世纪，电脑就把国际象棋的世界顶尖高手卡斯帕罗夫给打败了，而计算机把人类的围棋顶尖高手李世石打败是在去年的事。围棋棋手被计算机打败以后，很多人都伤心欲哭，觉得人类的尊严掉了一地，引发了全世界对人工智能的关注，这是后话。

回到德里达和围棋，他真的看不懂中国古人竟然发明这样一种游戏，没有身份、没有路径，也很难一时半会定输赢，这么高级的游戏对他的思想产生了很大的震撼。

# 德里达眼中的大字报

他在中国还看到了一样东西，大字报。这已经是一个历史名词了，在文革期间很普遍，90后的朋友可能都没有听说过。大字报是十年动乱的一个特殊的产物，早就是历史陈迹了，我们就说这个现象。

德里达看到大字报的时候，他完全不能理解，我们中国那个时候是短缺经济，什么都匮乏，热衷于写大字报的人他们遇到一个大难题，就是纸张不够，没钱去买白纸，那怎么办呢？因陋就简，很多人就在旧报纸上写大字报。

当德里达看到这样的大字报的时候，他很不明白，本来是一张报纸，上面写着字，人们是在看报纸，还是看上头的字呢？这是两个完全不同的系统，是两个完全平行的文字，就像是在两个平行的世界里运行。当然人写的字从总体上是盖过后面的那个字的，为什么中国人看这个东西的时候，一点儿困惑都没有？他读一读前面的字，会不会看后面的字呢？

后来他知道，当人们看大字报的时候是自动忽略后面的字的。所以德里达发明了一个哲学概念，叫“书写”。

我们过去说人跟传统的关系是有模板、有规范的，我们按照这个规范在模仿它、在继承它。而他已经感觉到在西方出现了传统的断裂，你爱传统不传统，我可以无视你。就象在巴黎，你可以有卢浮宫、有枫丹白露这些东西都保留在这里，但是不妨碍这些法国的红卫兵在那里搞古人看不懂的事情。
