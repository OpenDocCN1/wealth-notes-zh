# 吴伯凡

不是在极限场景下，你是很难发现你的核心的优势和劣势的。

自我管理里头有一个重大的课题，就是通过不断的反馈，发现自己的优势或者是发现自己的劣势。

在一个很平和的场景当中，我们的那点优势比如说你长的很帅，你换了一个场景发现这一点优势都不是。

要发现自己的优势和劣势必须要到一个极限的场景当中。像贝爷一样，如果让一个亿万富翁跟贝爷一块儿到荒野去生存一天、两天，立即就发现自己的好多好多的劣势，发现自己一点儿优势都没有。那反复来就能感受到贝爷的那种劣势。

有一个电视剧叫《士兵突击》，那里头两个，一个精的像猕猴，一个蠢的像猪。但是我们知道，那个蠢的像猪的许三多胜出了，成为兵王。原因是在特种部队里头，所有的 人面临的都是一个极限体验，那些有明显优势的人可能第一批就被淘汰了。

原因是啥呢？的确平 时他们就有优势，在那个场景里头他们没办法放下自己的架子。他早就有这种自以为是的特点，而且在平常自己觉得不会认为是劣势，甚至认为是优势，行动果敢、能够有主见，但是在那个场景下你会发现都会成为你的巨大的障碍。

而许三多这么一个别人认为他蠢的像猪的人，在那个场景下有一个别人都不具备的优势，那就是“无我”，没有面子，没有尊严。长官要求他做到，他不会讲条件，他只会干一件事——下笨功夫。因为他笨，所以他只能下笨功夫，最后他成了兵王。

所以一定是发现自己的核心劣势也好，建立自己的核心优势也好，一定要进入到一种极限化的场景当中。

汉武大帝说的，非凡之事，必待非凡之人。还可以补充一句，一定是在非凡的场景当中。如果你平时老是把自己置入到轻轻松松的场景当中，你将既不能发现自己的劣势，也不能发现自己的优势。
