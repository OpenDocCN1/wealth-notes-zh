6.27 | 你有观念里的FDA...

我们可能听说过这样的事，某个女生特别爱养猫。除了爱养猫之外，她还爱吃巧克力。她要把她最爱吃的东西给她最爱的宠物，结果就发生了问题——猫吃了巧克力之后就会拉肚子，甚至会中毒。为什么会出现这种情况呢？说到底还是跟受体有关。

# 冲突，是没意识到受体的重要性

我们人是哺乳动物，我们小的时候即使你吃不了母乳也是喝奶粉长大的。但是，长大以后，消化系统就会发生变化了。以前我们看到过一些新闻报道，某一种奶小孩喝了以后拉肚子，甚至引起很强烈的生理反应。这里头一个很重要的原因就是：有些人，甚至一些小孩，随着年龄的增加，消化系统内缺乏了水解乳糖所必需的乳糖酶，乳糖酶就可以理解成为一种受体，或者是一种接收器。

为什么你觉得那么好吃的巧克力给猫吃，给狗吃，它们就会出问题呢？原因也很简单，就是因为它们的消化系统里头没有受体去接受并消化巧克力，使其变成能量。且不论猫吃巧克力是否能感受到那样一种美味，单单这种物就对它来说就是有害的。

这种现象值得做管理的人特别的注意，既然这是一个很常见的，显而易见的事实。有些老板去上了几天EMBA，回到公司就推行各种各样的新的管理方法、管理理念，推行一种什么样的文化。比较好的结果是不了了之，坏的结果是上完EMBA，证书是拿到了，公司破产了。他犯的错误其实跟那个养猫养狗的小女生犯的错误是一样的，他认为好的东西，而且是被证明是好的东西拿来就推行，结果产生了很不好的效果。

当我们理解了受体这个概念以后，我们会发现，日常生活，包括工作当中的种种沟通障碍和冲突，往往都是因为我们没有充分意识到受体的重要性。

# 蜜糖与砒霜

好多年前我看过一本书叫《黄金法则》，这本书专门研究人类各 种文明里头，好像都有的一个通行的法则。这个法则用中国话来说就是“己所不欲，勿施于人”。

在犹太文明里头，在基督教文明里头，甚至在阿拉伯文明里头都有类似的法则。但是，我发现这些法则听起来好像是一样的，但细究起来又是很不一样的。比如说基督教它的表述方式是“己所欲，施于人”。“己所不欲，勿施于人”和“己所欲，施于人”是 很不一样的。

前面讲到了，有人把自己喜欢吃的巧克力给猫和狗吃，那叫己所欲施于狗与猫，最后引发的是完全超乎他预期的效果。有 一句话叫你的蜜糖，别人的砒霜，或者昨日 的蜜糖，今日的砒霜，这里头背后的原因就是受体。小时候你喝奶不拉肚子，长大了喝奶就可能消化不良。

# 观念市场的FDA

前不久参加一个活动，是关于儿童教育的一个活动。有人就问我，说现在有很多人拿着国外的某些先进教育理念到中国来办学，这件事你怎么看。我当时第一个想到的是一个英文缩写，叫FDA——美国食品药品监督管理局。一个新药要上市，从它申报到上市平均时间是12年。为什么要这么长时间呢？是因为这个药品在很多的临床实验当中都证明是有效，而且无害的。 但是，由于这个实验的范围不足够大，呈现效果的时间周期不足够长，使得你没办法确定这个药到底是好还是坏。就象我们的同辈人里头有很多牙齿特别不好的 人，原因是他们小的时候吃过一种药叫四环素。应该说四环素还不是很坏的一种药，它无非是让你牙齿蜡看一点。还有一些药，它解决了眼下的问题，结果造成了不可逆的恶果。所以FDA这个机构就特别重要。

可是在观念市场，在知识市场上，好像没有一个类似于FDA的机构。常常是某个大师突然创造了，或者干脆就是在国外看到了一种东西，立即就拿过来在国人当中推行。我们经常会在朋友圈、各种微信号里头看到几个常见的词，“哈佛教认为、斯坦福大学实验室研究表明、马云说”等 等。一般来说，只要冠之以这样名称的，都是不靠谱的，跟哈佛，跟马云都没有什么关系。他们只是为了让他们的某个观念、要推销的某种东西显得更加具有合法性和可信性，但谁能证明其有效性和可靠性？没有。

尤其是在今天，我们大家都处在一个普遍的知识焦虑、认知焦虑的时候，我们很容易陷入到一种病急乱投医的状态。听到一个来自于哈佛和斯坦福的观念，听到某大师在怎么说，你就马上不分青红皂白地接受。把自己当人肉小白鼠，把自己的公司当小白鼠进行实验，甚至你都没有意识到你是在实验。最后的结果，就是你用你的生命的代价证明这个东西不可靠，这是一件很可怕的事情。

以前我们在《伯凡·日知录》里头讲到了一种现象，比如说有些公司它就是靠某种管理手段，某种激励方式成长起来的。他就认为这种方式、手段特别有效。但是，他浑然意识不到他今天的员工跟他以前的员工完全不是一类人了。有时候这人与人的差别，代与代之间的差别，大于人与猿，人与猴子的差别。

比如说我使劲地用钱来砸，激发你的创造力、工作的冲动，你相 信重赏之下必有勇夫。如果你 的感受能力还没有变得完全迟钝，你就会意识到它不管用了。事实上，几代人之间对同一个东西的受体是不一样的。好一点的结果是不管用，坏一点的结果是它会起到你完全没有料想到的副作用。

上周我们讲到第二个募捐的团队由于引入了提成这种好像很有效的机制，结果导致这个团队的绩效严重下降。这也可以从受体这个角度来解读这个案例。

听完我今天的分享以后，大家可以问自己一个问题。当我们遇到每天都可能出现的那些好的观念，好的方法，好的措施，我们有自己的FDA吗？如果没有，我们就可能面对着一种我们没意识到的巨大的危险——把砒霜当着蜜糖来服用。

吴伯凡

今天大家可以思考一个问题作为作业：在你的生活当中，以及你能观察到的周围的人和事里头，有没有那种误把砒霜当蜜糖的事？请写下来与我分享。

受体因人而异、因时而变。

当你忽视个体间受体的差异时，就会出现冲突——彼之蜜糖，我之砒霜；
当你忽视时间对受体的影响时，就会让昨天的蜜糖变成今天的砒霜。

当务之急，是建立自己观念里的FDA——给自己的知识之把把关，别把自己当小白鼠，用生命的代价做实验。
