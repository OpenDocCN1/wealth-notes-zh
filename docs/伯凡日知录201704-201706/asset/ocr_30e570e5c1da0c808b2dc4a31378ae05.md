# 一、关于《道德经》第五十五章的理解

含德之厚，比于赤子。蜂虿虺蛇不螫，猛兽不据，攫鸟不搏。骨弱筋柔而握固。未知牝牡之合而偃作，精之至也。终日号而不啼，和之至也。和而日常，知常日明，益生曰祥，心使气曰强。物壮则老，是谓不道，不道早已。

> （注：文中生僻字较多，可配合音频阅读）

# 1、含德之厚，比于赤子。蜂虿虺蛇不螫，猛兽不据，攫鸟不搏。

这一段话的关键词首先是赤子。什么叫赤子？就是赤条条的孩子，也就是婴儿。我们常常说大人不是赤子之心，就是这个赤子。在老子看来，德的最高的象征是赤子，是一个赤条条的、不穿衣服不寒暄的那样一个孩子。

# 2、未知牝牡之合而偃作，精之至也。终日号而不啼，和之至也。

# 3、物壮则老，是谓不道，不道早已。

# 总结：失控者的强大

# 二、萌是一种竞争力

我为什么今天要跟大家分享《道德经》里的这么一段？几个星期以前，我曾经讲到萌态的动物，说的是动物出生之后它需要它的母亲来比较长时间的呵护抚养的话，它长的样子常常是很萌的（见本专栏5月1日内容《大自然的首席营销官》）。如果一出生它就能自由的行动，比如说昆虫、鱼，不过是一个小板的成虫、小板的成年的鱼而已。因为它不需要它的母亲来呵护它抚育它的话，那它就没必要表现出萌态来赢得母亲的呵护和关爱。

从这个现象里我们引申出一句话，萌是一种竞争力。
