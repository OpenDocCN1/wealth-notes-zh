# 本周问答 | 简单是最好的解决方案

又到了周末和大家互动的时间了。本周大家发言很踊跃，关于《“萌”是一种竞争 力》和《信任是一种杀伤力》，大家都发表了很多让我特别有启发的见解。

我们这些无所不用其极的成年人如何反 朴回到幼态延续的状态呢？脑子里装了 这么多潜意识的所谓成年人的道理，如 何才能再回到至纯如婴儿子的状态？

吴伯凡

“萌”是一种竞争 力，这个“萌”应该 打上引号，不是简单的明星们卖萌的那 个萌，而是让自己的思维方式、感知方 式和行为方式变得尽可能的简单。当你 简单的时候，世界会变得相应的简单； 当你复杂的时候，你就会把他人、把世 界很复杂的那一面激活，你面对的就会 是一个无比复杂的，你调动你所有的智 力来应付，都还觉得琐碎见时那么一 个事件。我们的聪明、我们的复杂常常 是在捅马蜂窝，把世界暗黑的那一面给 调动起来了。

听到“幼态延续”，想到大学一年级我 独自逛火车站附近的鞋品店被一群小偷 盯上的情景。当时我背着一个类似羽毛 球拍的包，拉链在背侧面。我坐在凳子 上低头试鞋子，突然感觉包被人碰触 了。我转头一看，一个40岁模样的人手 正放在我包里，还没来得及抽出来。我 脱口而出：“叔叔，这是我的包，你的 手好像放错地方了。”那人憨怯的一 笑，说：“是，不好意思，我把你当我 爱人了。”当我走到收银台结账的时 候，那个人收银的姐姐告诉我，刚才有 五个小偷围着我，她不敢吭声，问我有 没有被偷。我惊出一声冷汗。好像不 怀好意的人围绕着我，我居然成功脱逃 了。现在看来，当时面对小偷的那句 话，貌似是一种“幼态延续”呢！

吴伯凡

这个例子非常的生动。当时那句话“叔 叔，这是我的包，你的手好像放错地方 了。”这里头有一种降维的意思，把自 己降到了一个特别傻白甜的那种状态， 而不是一个成年 的、经验老道的人在跟 这些贼打交道。一旦你以这样（老道） 的面目出现的时候，贼就会无所不用其 极，你就会陷入巨大的麻烦当中。有时 候，简单是一种最好的解决方案。

这个话题可以说好久，我建议大家还是回 头看一看罗胖曾经讲过的曾国藩的那一集 节目，那个题目叫《成大事者不纠结》。 里头讲的核心意思就是曾国藩的人生分为 两段，前一段是极其复杂的，特别爱讲道 理，特别爱公事公办的曾国藩。到后来他 幡然醒悟，发现让自己特别精明、特别复 杂、无所不用其极的那样一种状态，其实 是在给自己不断地挖坑，不断地招来敌 人。最后他选择了一种极其简单的方式 ——当所有的人都发现，原来跟他打交道 其实是很简单的，他的规则已经透明到谁 都能够看得见的时候，大家就纷纷采取一种 很简单的方式跟他打交道。最后，他事情 就越办越顺。所以，在这个意义上 说，“萌”或者说“幼态延续”就是一种 竞争力。

关于第二个，信任是一种杀伤力，这个题 目可能会有一点引起误解。我想说的意 思，其实是面对一个复杂的，甚至是不乏 恶意的世界，我们应该采取一种什么样的 态度。这跟前面的那个话题有关系，你是 选择萌呢，还是选择老司机的态度呢？

以前讲到过一个话题——灰度。真正的答 案既不是在白也不是在黑，而是在一个广 阔的，非常丰富的灰色地带。

信任也是这样，我们选择信任的时候，一 种是无条件去信任别人，无条件去爱别 人。客户虐我千百遍，我待客户如初恋。 这样一种态度可行不可行呢？应该说在很 多时候是不可行的，你随时可能面对刁蛮 的客户，刁蛮的同事，刁蛮的上司和下 属，那你选择什么样的方式？你选择刁蛮 吗？你选择一种很有心机的状态去应对 吗？这种态度也会让你疲惫不堪。

我们说信任是一种杀伤力，我们要选择一 种既包含信任，同时也暗藏一种防范机 制，暗藏着防火墙的那样一种态度。这就 是我们在这个极其复杂的、每一个具体的 节点上都会消耗我们大量心智的世界，我 们该采取的一种合适的态度。一方面你选 择信任，选择善意，另一方面让你的善意 和信任里头包含着一种硬度。那是一种善 良的人、值得信任的人根本没有机会感受 到的那样一种硬度和杀机。但是，如果他 不是这样的人，他是一个坏人，他一定会 按照他自身的逻辑跟你博弈，那他就会 碰到那一个层面，你以简驭繁的方式将他 消灭于无痕的那种状态。

有一个同学（中武妖）还提到了 一句话， 叫“德高鬼神惊”。这是一幅对联，它原 来说是“道高龙虎伏，德重鬼神钦”。 在这个藏龙卧虎，神出鬼没的一个世界里 头，你要采取什么样的 方式？正确的答案 是，你要选择道和德，你要选择道德，而 且让自己的道要高，让你的德要重。道高 德重不是妇人之仁，妇人之仁是单向度 的，只有善的那一面，信任的那一面，缺 乏一种硬度，缺乏一种防护机制。

信任的杀伤力不是来自于外界，而是 来自于自身。信任的力量就像吸星大法， 它可以将对方的力量吸到自己的身上， 然后再打出去。而没有信任力的人， 他的力量就像是一把剑。两个人都没有信 任的话，就像是比拼剑的锋利程度。 一个有信任力的人和一个没有信任力的人 相遇在一起，结果可想而知，没有信任 力的人会被自己的剑所伤害。

吴伯凡

我想说的是，在这个世界 上我们打交道 的时候没必要总是拿着一把剑。很多时 候，无剑胜有剑。即使无剑的话，很友 好的表面里头也要包含着一种防护的力 量。《道德经》说“国之利器不可示于 人”、“兵者，不祥之器”。锋利的东 西是不祥的，你要藏的很深很深。但 是，藏是有可藏，不是说没有。人与 人打交道的时候用不着兵戎相见。但 是，如果真的到了那一刻的时候，看不 见的剑它会现身的。我觉得这是一种现 实主义的真正有效的信任观。
