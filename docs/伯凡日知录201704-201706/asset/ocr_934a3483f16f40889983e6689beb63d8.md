# ——► 知识笔记 ◄——

今天要跟大家分享的是一对概念，钟与云。提出这对概念的是一个牛人，这个牛人我给大家讲过，是索罗斯的老师卡尔波普，他提了很多让人拨云见日的概念，其中钟与云是一对很著名的概念。他认为世界上的事物、事件甚至是人，可以分成两种，一种是钟，一种是云。

# 钟

钟就是简洁有序的系统。

前不久我还真参观了德国一家手表厂，还亲手装模作样地打磨了几个零件，打开这个表的时候，你会发现里头密密麻麻，你必须要用显微镜看，你才发现里头非常复杂，据说一块表从打磨到最后全部组装好要三个多月的时间。这是一个多么复杂的系统，但是在哲学家看来，这是一个很简单的系统，简洁、有序，你可以用还原性的方法对它进行界定和评估，比如说你能够把一只表、一口钟拆开来，计量它的每一个部分，了解它是如何组装在一起的。如果 nasc 了，你是知道你错了的，因为它不运行。

用我们以前讲过的话说，它其实是一个简单的事物，以前我们讲到过一个分类，简单的事情、复杂的事情、超级复杂的事情，一口钟尽管看上去很复杂，但是它很简单，简洁有序，结果是相对稳定的，它的运行的状态是相对稳定的。作为一种计时工具，它的价值就在于它的稳定性。

在波普看来，世界上还有一种东西正好跟钟是完全相反的，那就是云。

# 云

一朵云它是不规则的，它是动态的，一会儿看上去像一头骆驼，一会儿看上去像一头老虎，一会儿看上去又什么都不像了，你很难对它进行计量，因为它每一秒钟都在发生变化，你对它的描述只能用日常的叙述对它进行描绘。

有一种工具叫超级计算机，这个超级计算机有一个很重要的功能，就是用来分析卫星云图的，它能把一个云图进行高度细分，然后以每秒钟多少亿次的速度在分析和观察它的运行状态，做这种分析普通的计算机是完全做不了的。从这件事情上，我们就能看出云是多么复杂的一个东西，它跟钟有多大的差别。

高智商的人在解决像钟一样的事物的时候表现出非常强的优势，因为他面对的对象是确定的，不管它有多复杂，它是可以数量进行计算的，而且是可逆的、可还原的，你只要有快速的运算能力，你就能够比别人更快地了解这个你要面对的对象，从而找到解决的办法。但是高智商的人面对云一样的事物的时候，它就往往失去优势了，有一句对MBA很不敬的话，说学MBA就是天天在学校里头学如何烧开一壶水，但他到了企业以后，发现他有点用不上自己的这个技能，原因是因为他找不到壶在哪儿。

在对象确定，规则也确定的情况下，高智商的人他能够很好地解决问题；但是当他没办法定义这个对象是什么，它的规则到底是什么的时候，他一下子就晕了，他没办法去定义规范，思考眼構築这个时时刻刻在产生变化，运行规律和外形都非常不规则的这样一个对象。他的技能就变成了屠龙之技，天天学怎么杀龙，但是结果他找不到龙在哪儿，甚至世界上有没有龙他也不知道。这样我们就能解释为什么有的人学历很低，好不容易上了大学，后来又退学，但是他能够把一个企业做得很大很大。因为企业在很大程度上，它不是一口钟，而是一朵云。

麦肯锡是世界著名的咨询公司，在这个公司里头有两个派别，有两种咨询方法，一类叫结构派，它跟一个企业做咨询的时候，它快速地画出这个企业的结构图，股东是怎么组成的，这个管理层，CEO下面几个副总，几个什么CXO等等，它的中层是什么样子的，然后它的客户体系，它的合作伙伴等等，它很快地画出一个结构图。针对这个结构，它发现，它寻找问题发生在哪儿，然后给出了一个解决方案。

我们听起来这很美妙，但是另一派人认为这套方法根本不管用，另一派叫过程派，或者叫动态派，它要观察的是一个信息是如何在一个组织里头传递，然后如何变成决策，最后产生了什么样的效果。一个订单是如何引发一系列的反应，它通过这个反应来观察这个企业到底出了什么问题，或者它的优势在哪里。针对它看到的这些现象，给出一种看上去并不规范，但是很可能有效的方法。
