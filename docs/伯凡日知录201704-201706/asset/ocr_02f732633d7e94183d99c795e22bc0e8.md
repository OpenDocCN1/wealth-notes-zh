# 1、绩效主义教育与目标阈割

斯坦福大学廉戴·姆勒教授在大量案例研究后发现，现代教育出现了一个大漏洞，或者说是大缺失。父母都在努力为他们的下一代提供他们最好的教育，这种所谓的最好教育其实在无意中实施一种阈割术。孩子在一个个阶段性目标驱使下，在各种威胁利诱下努力，逐渐地丧失了努力的内在动力源。

现代的教育逐渐成为一种泛职业教育，一种被强拉着走而不是被强大的内在动机驱动的教育。这种绩效主义教育的危害到底何在？其危害性到底有多大？如何从注重阶段性的靶子教育转向注重整体性、注入内在使命感和动力源的目标教育？请听本周的伯凡日知录。
