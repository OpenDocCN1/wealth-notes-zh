资额就足以能够将最优秀的售货员吸引过来，其它店是没有办法跟它比的。

# 8、反经济周期

阿尔迪店还有一个其它的店不具备的特点，就是反经济周期。什么叫反经济周期呢？就是说经济越不景气，穷人越多，那么它的店的生意就越好。

在德国有些有钱人有时候也会偷偷的进到那个店里去买东西。据说的德国教授是不好意思到阿尔迪店去的，他进去以后觉得在占穷人的便宜。因为，教授的工资很高，税也比较低，所以他才有那种占便宜的感觉。在德语当中，ALDI正好是德语当中的一句话的首写字母的缩写——“所有的穷人谢谢你”。

# 9、去掉一切不创造价值的环节

德国是一个新教国家，从这个店里我都能感受到它的文化和经营理念当中的清教色彩。什么叫清教？清教就是纯洁主义。清教有个很重要的主张，那就是人生于世，最重要的使命就是去掉那些不创造价值的环节。阿尔迪的管理从它的SKU的数量到它整个的管理流程都体现出这样一个理念，去掉一切不创造价值的环节。

有一个小细节，它的商品包装都很简约，没有任何多余的包装。但是，它商品上有一样东西是比别的商品复杂的，那就是在每一件商品上都有多个条形码。为什么会是这样呢？这个结账员拿到任何一件商品的时候，她都很 容易找到这个条形码，不用翻来翻去。大家可以算一算它一天的商品流量是多少，如果每一件商品节省0.5秒或0.3秒，那将会节省多少时间。就这么一个细节，就能够保证它的售货员的工作效率是最大化的。

# 三、新零售离不开商业的本质

回到我们最初提出的问题，什么叫商业的本质？商业的本质就是最大化的创造客户价值。

互联网的确是在改变零售的方式，但是，它并没有改变零售的本质。如果，我们忘记了这一点，把手段当成目的，为新而新，那么你的所谓的零售看上去很新，但是在一些根本的环节，根本的流程上你并没有遵守“去掉一切不创造价值的环节”。

《论语》里有一句话，君子务本，本立而道生。商业也是这样，你必须要务本，有商本才会有商道。如果本不立，道就无法立。可以说，孔子的这句话对于我们来认真的思考新零售的本质是非常有用的一个提醒。
