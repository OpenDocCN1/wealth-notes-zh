# 9.不要指望朋友。

绝大多数所谓的朋友，只不过因为你还有点小小的利用价值，亲戚来往也类似。如果你没混好，人到中年，想找朋友帮忙，我告诉你，不要自取其辱了。除非你卖惨，人家同情你一抱，到此为止了。

# 真正的朋友有两种，

一是有共同的兴趣爱好。例如很多运动员能够保留一辈子的友谊，因为他们有共同的话题，都是共同感兴趣的。

二是价值对等。部门经理和部门经理交朋友。小老板和小老板交朋友。大佬和大佬交朋友。可以是不同领域的，但必须有利用价值，否则，很快就散了。其他的只能说 是业务关系，认识他，知道这个人。酒桌上敬一杯的，效果就是等于零，百分百。
