# 3.3小学生攀比，如何解决

现在孩子们攀比财富的情况非常严重。

我住的小区有几个小学生，经济条件好，但他们学校的大部分学生是住在老破旧。下课后，孩子们结伴同行，自然分群，各自回家。高档住宅小区，玩的地方大，设施多，富孩子和富孩子一起滑车，捉蝴蝶，辨认树木，玩的不亦乐乎。老破旧小区，场地狭窄，没有绿化，车辆乱窜，家长不敢让孩子在外面玩，回家玩手了。

我家对面有个简易棚小超市，老板娘孩子借读小学，孩子非常自卑，虽然是同行，但他不愿意和富人小区的孩子搭话，因为到了小区门口，富孩子就去花园了，穷孩子就去阴暗潮湿的简易棚了。

我和老板娘聊聊天，问了孩子的学习情况，属于后40%的状态，一个班35人，他大概是第20-25名。初二就要回乡下读书了。等初三毕业，争取在上海学个什么手艺，例如修车，做小吃，实在不行，继续干小超市。

穷爸爸可能无法负担较高的补课费，孩子成绩差是普遍情况，少数自然开窍的优秀学生例外。现在富人小区一般都会摇几个廉租房，本意是好的，但实际上孩子们会不会更加虐心，这个需要进一步思考？
