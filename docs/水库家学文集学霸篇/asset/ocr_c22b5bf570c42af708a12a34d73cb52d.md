# 9.2大学扩招，学历贬值

# 回到古代，你是个什么货色？

我确保可以考个秀才，中举人的可能性有一半，进士不可能了。古代进士，不是靠读书的，而是靠名师指点。进士的考卷，基本是策论，这个需要对天下大事，朝廷风向，皇帝偏好，非常熟悉，才能考上，死读书是不可能的。至于现在的一些田园女权，基本就是伙房粗丫头档次。

秀才有啥档次？每次考试，全省录取三百名秀才，相当于考上清北复交。古代读书人少，录取比例相当于考上 985。举人录取比例是 5~9%，在乡间相当于享受乡长待遇，可以做官，县教育局长，县法院院长到顶了，少数成为大官幕僚。进士起步是县令，最好的是军机处行走，几年后可以成为地级市一把手。

比较有名气的秀才举人进士。朱德 19 岁中秀才。刘伯承 12 岁中秀才（因冒用他人户籍被取消）。何叔衡 26 岁中秀才。覃必武是举人。建国后，最高法院院长沈钧儒是末科进士，他是民盟。其他著名人物，因为年龄关系，没有赶上科举。

学历的疯狂。
