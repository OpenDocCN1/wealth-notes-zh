# 九，考场策略

+   1, 放弃理科最后两个或三个大题，看都不要看。把前面的题做两遍，确保考出115~120 分（满分 150）。考同济没问题了。

+   2, 语文，留出 35~40 分钟，确保写完作文。

+   3, 英语，不会做的选择题，放一下。把会做的做完后，统计一下，ABCD，如果答案中，b 或 c 明显少了。那就全部猜这个。
