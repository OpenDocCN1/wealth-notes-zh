# **10.3 留学毕业的前途**

**留学生的回沪前途。**

第一是父母朋友圈。第二是论文档次。第三看脸或内环线本本。结论：去不去，都一样！欧美理工科试验设备好，**出国**有优势。文科社科类专业，严重脱离国情，聪明人都教傻了。英国经济学从来不谈父母关系，就喜欢画表格，建数模。内地商业第一要点，去大单位大老板那里拉单子。你行吗？
