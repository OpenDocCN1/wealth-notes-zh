# 我有个心愿。

我要在孩子读大学之前，带孩子去领略一下世界的美好。预算是一套内环线房子，目前价值大概 120 万美元。我们只是财富的守卫者。若干年后，或许被打土豪，我们有心理准备。这一套房子，是我和我老婆在十多年前贷款买的婚房，是劳动所得。

孩子长大后，或许可以承接我们的巨大财富，或许是再次从零开始，我们都认。这个世界并不美好，充满了残酷的竞争或者斗争。有时候，甚至是你我死的拼杀。但是，孩子的童年只有一个，在力所能及的情况下，我们尽量让孩子对世界有个美好的认识，让孩子带着爱长大。

有爱的人，就有朋友。若干年后，还会翻起来的。
