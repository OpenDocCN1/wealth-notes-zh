# 11.4 分数差距的本质问题

我们都希望孩子刻苦努力，成绩能从中下或中等或中上等，提升到上等。却可能没想清楚，绝不仅是努力那么简单，更多是孩子要去改变一种学习习惯。而这种优秀的学习习惯，可能是孩子之前从来没有过的。

孩子之间的差距，表面是分数的差距，但本质更多是学习习惯的差距。

而优秀的学习习惯，更多的来自小时候父母有意识地培养。

坦白说，孩子小时候，父母大多处于事业奋斗期，且本身也不是在教育行业（没时间钻研这事儿），所以，孩子没养成一个好的习惯，更多是寄希望于遇到一个好老师去培养。

孩子在70分时的学习习惯和95分以上孩子的学习习惯，一样吗？完全不一样。

因此，我们表面上要求孩子刻苦学习，只是目的！其实，更多的应该去控制过程！改过程！（过程，就是学习习惯！）因为，只有过程，才会影响最终的结果！

我之前在很多文章里写过，学习进步和社会上把事业做成功是非常像的。

本质是完全相通的！

举个简单直接，我自己减肥的例子。

前段时间我减肥，表面看就是想掉几斤肉，但本质是改生活习惯和饮食习惯！我以前就特别喜欢晚上吃东西，晚上上完课，回家媳妇儿给做个饭，整点炸酱面，炒个菜，一顿胡吃海塞之后，感觉生活如此美好！

但要想减肥，就必须尝试从未有过的生活习惯饮食习惯和健身习惯。比如：我每天去跑5000 10000米，每天早饭敞开吃，但午饭少吃，只吃菜，晚饭不吃。不吃冰激凌蜜三刀薯片等各种我爱吃的甜食！
