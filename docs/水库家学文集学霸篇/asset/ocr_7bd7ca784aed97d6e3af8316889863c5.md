# 如何考上同济上外华政？

考清华北大复旦交大，需要运气，一个选择题猜错了，就失之交臂了。

但是，考同济这样的二流大学，稳扎稳打，还是可以的。我教你个简单的办
法，放弃理科最后一个大题，拿1-3分即可，把其他题目做两遍，确保全拿分
！这是百发百中的办法。
