# 4 学奥数

**奥数，我是绝对不会让孩子去学奥数的。**

因为奥数培养的是一种投机取巧，走捷径用妙招的思维模式。这种思维模式会害死人的。奥数最多让你数学成绩高一点，但这个代价太大了，孩子长大后，因为走捷径尝到甜头，就会迷信捷径，进一步发扬光大，最后自己的人生就赔进去了。

**奥数，对人生没有帮助，相反，读近视了，**

**读傻了，读丑了的孩子更加多。**

我小时候就是那条路子走过来的，参加各种学科竞赛，但对高考也没帮助。

高考数学化，不会涉及奥数类的难度。强加于孩子们的奥数，其实是出于优质中学选拔考试机器的卑劣目的。奥数好，说明孩子会考试，学校一本率高，校长有面子。

**奥数有用吗？**
