# 我小时候没有补课家教，但我考试成绩好，其实也是花钱砸出来的

小学三年级上英语课。我家没人会英语，社会上也没有录音机，没办法了。我妈是聪明人啊。她带上我，到外语老师家里。她给老师做饭，红烧肉，清蒸鱼，炒青菜，剥毛豆，差不多一个小时，外语老师陪我练习半个小时英语。每年冬天，我妈还给老师打毛衣，还给老师的女儿，老公，一人一件毛衣。毛线是老师的，我妈出力气。

到了高中，实在没有什么补课老师。但我妈有本事啊。她带我去福州路新华书店，凡是带高中考试四个字，全部买下来，基本是一年去四次，前前后后花了很多很多钱。我就偷偷在家里办个图书馆。任何不懂的题目，我至少有十几本参考书，可以查阅，再查不到也就算了。

我高中英语，是全班第一。因为我的英语参考书，大概有几十本。也不是全看，就是对比查阅。我的任何一门课，参考书比教研组组长还多。她们出考题也是抄参考书的，我是一猜一个准。

那时候大家都是穷人，我就是这么拼出来的。你家行吗？

现在，大部分家长，月薪低于一万的，是不舍得花二十万一年，给孩子补课的。家长们最喜欢的就是说，你看隔壁村张二狗家的儿子，也没花什么
