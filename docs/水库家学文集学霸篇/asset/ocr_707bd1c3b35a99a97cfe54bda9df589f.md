# 第十二章家学知识启蒙篇

自古有一种学问：家学。这是口口相传，秘而不宣，真实存在的。就是祖上世世代代对人生的经验体会，涉及方方面面，包括如何做学问，如何安身立命，对外怎么说活，对内如何管家，如何选择机会，如何对上对下。一般人不承认这个事，但你可以看到，很多家族不管朝代更替，真的就是人才辈出，没办法了。

家学就是家里传男不传女的那些技能。49年后长期臭老九政策，近三十年文凭决定一切，导致几千年的家学传统，彻底丢失。家学一般有两种，一是罕见技能，例如某个小语种，螳螂拳，烤鱼秘方；二是为人处事原则。现在我慢慢看到，很多富裕阶层已有意识在恢复了。好事。
