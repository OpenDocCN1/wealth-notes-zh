你说 怎么办？

优质父母，应该把一切给到子女，毁灭一切自我意识。

倾尽三代人的努力，让孩子在更高的层面上，取得一次机会。我家世世代代就是这样。我们家的男丁，生下来就是一大套的家国教育，不言鬼神，不畏生死，风雨向前，无愧先祖。败了无所谓，只要家族精神不丢，三代之后，卷土重来。

理论联系实际。我是个优质油腻大叔，但从来不搞女人，不吃喝嫖赌，天天在家围着老婆孩子转悠，攒下一切资源给孩子买房。我有钱有貌，风趣幽默，跪舔一流，要想自己开心，真不难。但如果我只考虑自己吃干抹净，孩子怎么办？

为人父母，要做到几条：

+   1，少生孩子多买房。集中资源，薪火相传。

+   2，中年男女都要管好下半身，不要到处打野炮。

下半身一时爽，二房闹上门。

+   3，时刻注意孩子的心理健康和学习进步。

+   4，中年夫妻多努力，尽可能多赚钱。多写经验总结，树立一个良家风。
