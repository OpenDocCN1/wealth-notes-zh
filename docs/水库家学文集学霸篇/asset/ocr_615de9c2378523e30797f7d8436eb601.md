# 家学：如何过上优雅从容的中产日子？你要像做企业一样的，经营自己的人生。

一，练就一个强项。就是企业主打产品，你总要赚钱吧。

二，发现外部技术人才。你和你的家人，在今后几十年的生活中，会遇到各种突发情况，紧急需要帮助，而你一瞬间又无力判断哪些人是人才，哪些是混的。

你需要未雨绸缪，主要涉及：

+   1. 律师（例如房产，婚姻，交通事故等）

+   2. 医生（例如我有支气管炎）

+   3. 各类教师（例如中小学，考研，考职称）

+   4. 各种部门的人（你总要去盖章吧）

+   5. 技术人员，例如修车，家装，维修

+   6. 保姆中介物业等等
