# 三是家庭环境。这是感情问题。

如果父母很有钱，但是天天打架闹离婚，出轨打老婆，会对孩子形成巨大刺激，影响学习。

我们不排除个案或特长学生，但大体上是富裕稳定家庭的孩子成功可能性大。另外，考场发挥是个次要因素，不过是记忆熟练程度的问题。滚瓜烂熟就不会紧张。

# 高考就是考熟练度。

考清华北大复旦交大，每年合计招生近一万人，录取率千分之一。天才的比率是百万分之一，所以基本还是靠“疯狂刷题+运气”，选择题蒙的全对。数理化最后两个大题，五分钟就有灵感。

+   - 考 985，录取率 9-12%，刷题刷到精神恍惚，四肢发软，80%有神经衰弱。
- 考一本，录取率 25%，刷遍市场上主流的练习题，记忆力中上。
- 考二本，每天刷题到晚上十点半。每周可以玩一天。
- 考大专高职，平时像个学生样子即可
