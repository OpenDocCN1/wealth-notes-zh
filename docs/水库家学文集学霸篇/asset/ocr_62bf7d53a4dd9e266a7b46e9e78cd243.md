# 6.初二是学生的变化时段

一是心里已经转为青少年了。大部分小学娃娃不清楚家里的经济情况，到了初二基本都懂了。“哦，我家是屌丝啊，父母是小中产，呸呸呸。”这时候，孩子的思想状态会发生变化。

+   二是身体发育。很多早恋，谈朋友，

就是初二开始。特别是女生要早熟一些。

+   三是学业难度开始上来了。数学难度大大增加，物理课简直是折磨人，两个小球撞来撞去，实在是受不了。语文开始要求比较难的理解题了。表现了什么意境？我日，老子怎

么知道，你去问问李白？外语开始考听力了。老子杭州话还没学会，考个锤子的英语？

+   四是考试难度呼啦啦上去了。明年就要中考了。这是校长扬名立万的时候，一个初中

好不好，关系到老师，发了疯也要拉。怎么提高中考成绩成为校长最关心的事情。如果本

校初中部能考上20个省市重点，校长就是区县牛人。老师的压力就转化为考试难度。到了

初二，很多学生比老师个子还高了，老师一般把学生当做大人来看了，不再有什么考虑了

。直接拉难度，考试难度直线上升。

与此同时，很多家长和孩子还在小学思维里，靠死记硬背。这就不行了。有点孩子因为不能转变思维逻辑，一个学期就垮了。怎么办？
