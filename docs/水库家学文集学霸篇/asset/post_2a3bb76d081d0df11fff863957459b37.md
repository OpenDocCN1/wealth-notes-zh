
企业生存周期是五年，任何民企黄金期不超过三年。年轻时在京沪混，吃青春饭，男屌丝跑销售，女屌丝做行政，谈一场穷得轰轰烈烈的恋爱，好像很浪漫。但过了35岁，经济压力袭来，男人消沉，女人出轨，比比皆是。

男屌丝的脱贫标配：公家单位+拆迁妹，其他皆浮云。二本妹注意了，隔壁班的那些男孩子大多是屌丝，妹妹就不要理他们了，毕业后都是去群租房的货色。

年轻人真要读书，就读实战书。喜欢政治就学法律。喜欢经济就学税法。喜欢文学，就去学写作。千万别读废纸一筐的萨缪尔森、《国富论》、《货币战争》。这种书只会误导你，自以为是解国事经济，其实你连支票也不会填写，报纸也看不懂，一实践就二百五。实战中，你自然而然会想，为啥要这么规定？那时，你就真懂了。熟读凯恩斯、萨缪尔森，还不如装热水器来钱。真的，别骂我，这是事实。

买一张二本文凭，搭进去四年时间和父母10多万现金，如果没有在学校里找到一个土肥圆，那是亏吐血了。出了校门，你就是二百五，没房没车没希望，土肥圆都鄙视你。不要愤怒，谁让你考不上清华研究生的，这怪谁啊！

有人用“人人都高贵”来忽悠大学生，毫无意义。你住在京沪漂亮公寓，对住在群租房和地下室的人说，你是高贵的，真好笑。我希望你能看清现实，努力去涉公单位工作，赚钱买房，踏实生活。现在，大部分私企不太好，少部分私企暂时得到融资还不错，但是长远看，还是不行的。国企机关事业好，努力去考吧。

**在你成功之前，不要为亲戚人情所累，没意思的，特别是春节前。**

学个特别精通的技能，攒钱买个房。找老婆，不求多好，先过小日子。挤进中产的机会有时候还会不经意地出现几次。过日子精打细算，洁身自好，不要黄赌毒。身体当心，别吃垃圾食品。把英语学一下，以后不用请家教花钱了。

**不要和别人争论无关紧要的事情。**很多人的价值观和思维方式是与生俱来的，长期贫困底层练练就的，不可能因为你几句话就改变的，他们大多数还自以为很聪明。与人争论的结果是，他在心里骂你是傻。正确的做法是：假装认真地倾听点头，实在觉得他傻，就找个借口走吧！也不要去学管理。管理的前提是，你先要有个大企业，先给百十来个人发出工资。屌丝应该先学一点手艺技术，例如挖掘机、码农、制图、拎灰桶、搬砖。等你赚到了首个 1000 万，有钱可以开家大工厂了，那就抓紧考虑买房的事情。

要记住：在你背后说坏话的，和你抢老破小的，和你抢土肥圆的，给你妈开保健大处方的，给你爹卖保健品的，卡着你居住证的，和你在地铁上争位置的，还真不是房东。你今后的人生，就是和这些人纠缠一辈子。你努力啊，房东没时间和你对骂。

看到权贵，你就千方百计使劲贴上去，几年后，要么直接得到钱财，要么得到机会，要么得到经验。你不好意思贴上去，你就苦命了。这个话有点儿残忍，但哪个富一代不是这么过来的？也抄送女屌丝。屌丝不要相信独立人格，人格不是人，不会发钱给你买房子的。屌丝不要脸，成功在眼前。

屌丝混职场，第一要谦卑。屌丝可以经常说说家乡的土特产、老家比上海差远了之类的招人喜欢的话。现在很多屌丝真的发疯，经常来一句，“去年某安徽亲戚赚了几百万”。混职场，说这种话要遭霹雳的。你要是觉得钱少，直接滚。某熟人经常说，能够在上海工作很幸福之类的低调话，十年后副处长了。如果你是混好单位或大公司的屌丝，你记住一句话，你的敌人，就是那些和你称兄道弟的同龄人。因为你们的资历业务差不多，机会永远不够，他有时无。所以，远离这些人，警惕这些人。关系再好，也不要吐露心声，因为你的那些话，很快会被这些人拿去献给领导。

**一定要追求几个自己心目中不可企及的女神。** 虽然你追不到手，但是通过女神的反应，你会学到很多，以后撂倒土肥圆，那就是手到擒来的事情。别担心失败！ 你也没啥损失，反倒是青春的记忆。万一你成功了，嘿嘿。尾炸天！ 对于已经毕业屌丝男的建议，别挑挑拣拣了，抓紧找个土肥圆，一起合租搭伙。拖过 30 岁，年轻土肥圆也不要你了，只能找二手土肥圆了。

**京沪小白领，赚钱后回老家买个大房子，安静地过好下半辈子，**

有山的爬爬山，有水的地方多游泳，多吃点儿好的，多玩一会儿，彻底放弃以前的尊严。在京沪，烦恼会时时刻刻地纠缠你。不要多考虑孩子的将来，你现在如果没有户口，我保证，你永远都别想了，政策，我比你熟悉。当然，你不会真同意我的。

**一个忠告：用尽三代人的关系，进国企；花光三代人的存款，大城市买房。**

**做到这两件事情，你就不会蠢蠢欲动，想当小老板了。实在进不去公家单位，创业也要做公家的合同。** 道理很简单，绝大部分社会资源都在公家单位，而花钱的人是在花公家的钱，只要你懂事，价格贵 20%~90%，领导绝不心疼。千万不要去做那种纯市场，市场一热，三年完蛋。

生活必然会遇到各种艰难险阻，不要气馁，不要悲伤，努力奋斗，生活会好起来的。你可以多看看书，多学习一些财务知识、金融知识，实在找不到老婆， 你就先泡个士官，凑合一下群租。生活对每个人都是公平的，勤俭节约，量入为出，按时交租，生活一定更美好。

你最好在结婚前，把要考的证考出来。否则，你今后会面临谈恋爱、结婚、买房、租房、事业发展、同事关系、家庭矛盾、抚养孩子、照顾老人、投资决策等一系列极度耗费精力的事情，你根本静不下心来。我不反对下海赌命 ，但聪明伟大的你，最好先去考个值钱的证，壮壮胆。即使今后，巴菲特没有给你风险投资，等你坑完了所有亲朋好友，烧钱结束，公司破产，你好歹还有个饭碗。否则，你熬到三十多岁，穷屌丝一个，啥也没有，掏出来的只有一把辛酸泪，那是把老婆孩子坑了。

我本科毕业时，上海还是一个尘土飞扬的大工地。

我和同龄人一样，除了户口，家里没给我钱，也没房子，我是一个人站在孤零零的浦东大道某招聘会，受尽了白眼和屈辱，当时，我立志要赚一套房子。二十年后，我得到了太多太多。暂时的贫穷和困窘不可怕，只要你不要丢失信心，这个社会就会给你回报的。我的经验是，专注。小成功源于专注。

大成功是碰运气。大富豪坐牢被枪毙的，比比皆是，不必太羡慕。你不要研究太多学问，不要什么事情都去插一脚，这不会给你的人生加分，反而让你精力分散。谈恋爱就专心谈，读文凭就努力读。不要夸夸其谈，要脚踏实地，目标明确，自己努力争取一下，肯定有够得着的目标，例如按时交租。

# 如果你能超过你爹的水平，你的人生就胜利了。

不要想着和各类官二代富二代比。屌丝也不要想着去京沪买房，这不是你应该想的，一代一代积累，才有盼头。一步登天的事情，完全是运气。如果你是 70 后的外地人，复旦毕业，去静安区街道办当了科长买了房，那是运气好。错过了，也不要抱怨。

年轻时，人改行机会特别多，有很多看上去是捷径。我奉劝那些不想一夜暴富，或者一把搞定下半生的年轻人，坚持自己的专业，不要轻易改行。现在看上去是捷径，其实过几年你想兑现的时候，客观情况变化好大，最后不一定划算。

要明白，让你哭的，不是我写了几句话嘲笑你，而是你拼爹失败。你再努力，再优秀，你就算是哈佛毕业，在 40 岁之前也无法买得起上海的稍微像样一点儿的房子。当然，如果上海嘉定南汇的某拆迁妹，偶然翻了你的牌子，你的人生从此就与众不同了。地段决定人生。

如果你为了图自己轻松，建议去中西部省会就业，再找个工资尚可的老婆，努力五到八年，攒个省会首付。但子女又要重奏一次你的进京沪之路。如果你愿意牺牲自己，有两条路：一是去京沪拼命工作，一辈子租房，退休前买个极偏远的小房，等待户口政策开口子；二是学习凤姐。熬个四十年，肯定有机会。

去京沪，须谨慎。用高房价来赶人，是比拟理想的办法。如果你不准备为孩子牺牲一辈子，那就建议同学们去省会城市发展，不要在京沪熬了。个人的努力，比不上资本的力量。来沪的小博小硕小本，我建议，最好去南汇奉贤嘉定崇明等区县。下了车，最快速度相亲，找个拆迁妹妹，一切全部解决。在陆家嘴和外滩上班的金融狗，表面看，好像很有面子，一点儿也不实惠，下了班还要挤公交车回出租屋。十年打工，也无力首付车程一小时以内的房子，肯定是人生悲剧。

努力二十年，再回市区。

如果你打算创业或者经商，首先要学会怎么管理员工。

我是怕员工的。我公司办公集中在某一楼层，如有一个员工大吵大闹，肯定影响全部员工，那时人社局是不会理会小老板的。我是忍气吞声地熬和让步，最后忍无可忍，生意也不赚钱了，索性关闭。

出于什么考虑，我不知道，但是我对象当小老板是彻底不感兴趣了。记住一条准则，保你发财。搞定各种手续，得八成利润，干活的拿两成利润。坚持这个比例，可以保证你一生发财，直到永远。比如做一个国企超大型软件，假设 1000 万元，智力不值钱，拿到单子才是王道。让出去八成利润，是底线。

做人的一个准则：忠诚。对上级，对朋友，对家庭，对爱情。忠诚的前提是，你要看准了人， 就不变了。吕布勇冠三军，不断叛变，最后没人理他了。

做人，不要首先去挑战别人的底线。宁可错，不可叛。

千万不要从小就学习适应社会，学一些偷奸耍滑、占便宜的事情。

要培养孩子将来做大事的心态，必须要讲诚信。诚信是，吃小亏，等待大机会。年轻人收入低， 很容易陷入斤斤计较的窘境，一定要摆正心态。占便宜就像做小偷，会上瘾的。必须在源头上卡断，从小盯紧， 不忘初心。第一次合作，如果是五五开的分量， 你主动谦让一部分利益，你六我四，各自尽力而为，确保对方把第一次合作干好，保证了你对外的信誉。完成后，观察合作方的态度。

**如果他觉得，他拿六是正经意义的，那就点到为止了。**

如果我觉得，下次应该看贡献分成，说明人品靠谱，值得交往。就我自己来说，我对孩子投入那么多心血，不是为了培养一个很会占便宜的聪明小人。我的一生，都是为了孩子将来在更大的舞台上竞争一次，哪怕失败，也值了。这种高段位的竞争，基本不看聪明了，而是看你对利益的态度。你每次分 30%，你可能会有 100 次机会，你每次分 70%，你就没有下次了。你对人宽厚，人家心里都懂的。

**刚毕业的大学生 99%的人写简历=获奖汇总，毫无意义。**如果你是去求职（不是猎头主动找你），你要明白，任何单位都不缺情怀和总裁，他们只要两类人：老黄牛，拉单子。其他都是废话。你啰啰唆唆写了这么多自我表扬的话，没用的。如果你实在要显摆一下，可以放在最后。你去面试也简单，要么干一个实例，要么自带客户。

**如果你是在校的学生，珍惜现在的美好时光，珍惜爱情，珍惜身体。**不要为了一点小事请假发脾气。大学这段时光，将是你人生中无法磨灭的印记，即使现在不快乐，也要好好走完这段历程。出了校门，你将面对各种残酷的事情和一大堆像我那样的浑蛋，每天为生计发愁，为房子愤怒，为爱情而现实。珍惜现在，珍惜爱人。

大学男生不适合谈对象。22岁的男生，心理状态基本是个孩子，也没有任何谋生经验，除看了几本发财秘诀外，和中学生差不多。但是22岁的女生，心理状态完全成熟，目标明确，如果男生家里有钱有地位，还好说。如果一穷二白，我建议男生不要太过于幻想了，一遇到现实问题，你就手足无措了，内心备受打击。

很多年轻人，很有朝气，幽默，阳光，搞笑，真的很有意思，比我们当年强大。希望他们开心。我们这一代人没有什么功劳，现在大都已经沉默无语，默默生活了，希望年轻人幸福。我经常吊打屌丝，也是一种幽默，别介意。哈！

# 总结、

1. 再谈学区房。我的观点是小学毫无意义，初中可以考虑。

小学教育看的是家长，和老师没啥关系。我家娃驻所在的小学，硬件一流，实际上没什么意义。一个老师面对四十个孩子，一人说一分钟就要 40 分钟了，你就别指望了。

大多数家长的心态是，交给学区房，我就轻松了。事实上，绝不可能。一个孩子成绩好不好，完全是家长的作用。我老婆每天辅导孩子，长年累月，效果很好。有点家长因为工作忙不管孩子，基本就没希望了。

初中涉及到早恋，打架等一系列问题，学校好，相对破事少，也不完全。初中有个好一点的学校风气，作用是孩子不要学坏。至于初中的成绩，不要多想了，还是看家长。一道题讲三分钟，你家孩子不一定学会，全班四十个人，就是两个小时，我觉得你就不要想太多了。老师也好累。

如果你家老婆不是单位的明日之星，就算了，别折腾了，好好的把孩子管起来。孩子考上 985，人生豁然开朗，比你多赚二十万有意义。建议，把孩子推给学区房是懒惰的表现，效果不一定好。

2. 复交同华

复旦交大，大家都知道，沪上名校。特别是复旦附中和华二，如雷贯耳，比大学还厉害。同济也是名校。我们那时候，同济以建筑，汽车，德语出名，现在不熟悉了。因为几十年前，能进桑塔纳是毕业生非常高兴的选择。那时候，正式编制不那么热，外资是热门。现在不一样了。

华师大也是著名大学，虽然叫师范，实际上，我们都不认为是师范大。学他是一个综合性大学，文理兼备，各行各业都有，但是存在感不强，去中学的比较多。

985是看各系总量的，上海还有一些好的行业学校，例如华政上外上财。但是体量小，估计混不上985。目前的户口口径抵在985研究生。如果放宽到985本，江浙皖闽，冀鲁豫的高考格局就有变化了。结论：小娃娃考试分数最要紧。985的含金量越来越高。

# 3.考试很重要

我对九十年代的户口还有印象，因为单位里，我对好朋友办户口比较有印象。当年，落户口有两个大的渠道，一是应届大学生，二是有中级以上职称。指标是发到单位学校，大学生是一张黄表格。应届大学生，成绩好的，一般都有，我听他们说，好像一个班级有十几张。

还有就是中级职称，这个在单位手里。那时候，单位招聘，同意要你了，就给你一个表格。说起来是人才。但是，人才是很难判断的。一个人58岁发明了的计算机，他22岁的时候能不能算人才？这个话，谁也讲不好。怎么办呢？划硬条件学历，职称基本也有学历因素。

我们那时候，学历比较简单，就两种大专，本科。

现在分类比较细了。我的意思是，万变不离其宗，考试太重要了。

建议：如果你不能给你家娃娃买房买车，那就一条正路，考试。我家保姆的子女，小时候居然在小县城学钢琴，最后高职毕业就没读了，我是目瞪口呆。你是什么条件，就干什么事情。对于一殷家庭，考试是正道。千万不要想入非非。你家女儿20岁走艺考，还是在华尔街大读书好？

如果读书不行，就考个职业技能，例如会计，小师范。千万不要荒废学业。你不要以为自己娃啥都行，艺考文化双一流，不可能的。

+ 4. 高中怎么办？我仔细研究过衡水模式，无非是当年我们那一套打法。

高中的特点是，家长彻底没办法了。我高中的时候，有个同学家长是 985 教授，没用，根本没帮助。高中的数理化，难的飞上天。绝大部分孩子基本靠努力了。我简单说说，怎么安全度过高中，混进前一半（本科）。

# 一，找准动力

高中孩子已经是人高马大了，家长打不得骂不得。搞不好，家长会被腰戳趴下了。所以，千言万语，循循善诱，没用。关键是孩子自己努力。努力要有个动力。高中最大的动力是面子。高中同学最要面子。因为高中已经有喜欢的女生男生了。要想在班级里博得女生好感，在同学里有面子，必须成绩好。这就是动力。

# 二，高价辅导

5. 孩子的未来，就在我们一念之间

小娃娃上小学还没几天，开始写作业了。这时候区别就大了。有的家庭，因为孩子写作业，已经影响夫妻感情和亲子关系了。“听啊，隔壁妈妈又在打娃娃了”。大人骂，小娃哭，还有男女混合双打。我家小娃娃写作业完全没有负担，一个小时的作业，十分钟搞定。

为什么？我老婆仔细研究了小学课本，发现一个有意思的现象，小学一二年级的孩子，还不太认字，却在数学应用题。孩子光是理解题目文字就已经非常困难了。再要做对这些七拐八绕的 58 题目，怎么可能？我家小娃娃认字早，所以写作业不是问题。小娃娃的童年幸福在于学习好，而不是杂七杂八的歌舞表演。有个小娃娃一天到晚练习吹喇叭（好像是唢呐之类的）。

老师实际上把他当个小丑，有什么活动了，让他去跳一跳，表演个节目。这个娃娃傻乎乎的，把大部分精力用在了无意义的音乐演奏，导致学习中下水平。平时，这种成绩差的娃娃像个 250，这班级里很被鄙视。这孩子今后麻烦大了。没人会管你是不是能读区重点高中。

每一个孩子都是家长的宝贝。如何帮助孩子过好每一天，其实就在家长的一念之间。我有个建议，一定要学习好，用 95% 的时间学习，5% 的时间体育。你一年级学好了，就抓紧赶二年级，三年级。我认识一个家长，孩子成绩超级好。我问她为什么？她说，孩子在二年级就把三千个常用字全部学了。所以，孩子的文字理解力强大，上课相当于复习，做题不操心。我听的浑身冒冷汗。

我也不是鼓励你家孩子跳级。我的意思是，一心一意抓孩子学习，不要分散精力，一天到晚在路上跑兴趣班，大人累，小孩累，不如踏踏实实考个双百分。孩子的江湖也非常复杂。我家小娃娃还要给一些喜欢打人的娃娃送小礼物，例如一些小玩具，以此搞好关系。但是整体来说，学习好的孩子，一般不受欺负。最可怜的孩子，往往是学习差，老师不重视的。

# 6. 初二是学生的变化时段

一是心里已经转为青少年了。大部分小学娃娃不清楚家里的经济情况，到了初二基本都懂了。“哦，我家是屌丝啊，父母是小中产，呸呸呸。”这时候，孩子的思想状态会发生变化。

+ 二是身体发育。很多早恋，谈朋友，就是初二开始。特别是女生要早熟一些。

+ 三是学业难度开始上来了。数学难度大大增加，物理课简直是折磨人，两个小球撞来撞去，实在是受不了。语文开始要求比较难的理解题了。表现了什么意境？我日，老子怎么知道，你去问问李白？外语开始考听力了。老子杭州话还没学会，考个锤子的英语？

+ 四是考试难度呼啦啦上去了。明年就要中考了。这是校长扬名立万的时候，一个初中好不好，关系到老师，发了疯也要拉。怎么提高中考成绩成为校长最关心的事情。如果本校初中部能考上20个省市重点，校长就是区县牛人。老师的压力就转化为考试难度。到了初二，很多学生比老师个子还高了，老师一般把学生当做大人来看了，不再有什么考虑了。直接拉难度，考试难度直线上升。

与此同时，很多家长和孩子还在小学思维里，靠死记硬背。这就不行了。有点孩子因为不能转变思维逻辑，一个学期就垮了。怎么办？

1，家长去买大量的习题册。

+ 2，花钱请家教。

3，发狂刷题。

4，注意饮食，保证孩子长身体。

5，留一个安静的房间，保证复习环境。家长五年不看电视。

重点是，有个家教。单纯刷题也有问题，老子学不会，刷了也白刷。如果你家没钱请高水平教练，建议父母自己上。现在很多父母都是大学生，至少读过高三。初二的问题，你总可以摸索一下？也不白辛苦，等娃考上了985，你相当于省了一套房子，理直气壮让小美女倒贴房子。如果进三甲，让丈母娘倒贴两套。你辛苦几年，相当于实打实的几百万。划算！

# 7. 考985的三个点。

小学三年级，初二，高一。我今后一个一个慢慢讲。今天说一个大家经常忽视的小学三年级。小学三年级是个巨大的坑。一二年级是认知教育，一朵花，两片云，比较形象，而且家长都有能力辅导一下。到了三年级以上，难度陡增，开始引入一些乱七八糟的逻辑思维了。举例，几只鸡，几条狗关在一起，数脚丫子。其实，这是为了淘汰一些逻辑能力差的。作为家长，你要高度重视小学三年级，否则，一不留神就会让小娃娃掉到坑里，很难爬起来。

一是你先读一遍课本。做到心中有数。

二是化解问题。你要把孩子看不懂的问题，让他看懂，这考验你的知识结构和表达能力。
