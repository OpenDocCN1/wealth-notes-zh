# 我们大部分人都没有审美能力。

前段时间出去旅游，我在风景区随机找了几个貌似中产阶级的中青年游 客，帮我拍照片。他们拍照技术非常差，就是人物放在当中拍一下，当然，我不怪任何人。我的结论是，

大多数人缺乏对美的欣赏能力，也不太会创造美。

这个情况是非常普遍的。我们从小到大，就看分数和职务，从来不考虑 美化生活。装修就是买贵的。如果谁把刷题的时间用来刷眼睫毛，小说说你，心思不在读书上，往大了说就是，小小年纪不学好。
