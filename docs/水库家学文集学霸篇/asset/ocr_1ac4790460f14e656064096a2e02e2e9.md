# ## 6学英语

# ### 6.1学英语的收益

普通人学英语有用吗？

如果你的收入来源是国内，没有外贸业务，英语毫无意义。你肯定会说，科技论文，都是英语的。我日了狗了，就你那点水平，你会去看英语的编程说明书？不可能的。我告诉你，就算是 985 教授，也不愿意看英语说明书，除非万不得已，要发表论文评职称。

学英语肯定有精神层面的好处，主要是个人爱好，可以了解一点外闻。但是，靠这个赚钱，除了中小学生补，抓小，其他不可能的。我们从小到大，花这么多时间精力去学习外语，其实很愚蠢的。这些话得罪了英语老师！
