# ## 2中产家庭父母的焦虑

**中产揪心的是教育。**

中产最大的烦恼是，辛辛苦苦一辈子打下的事业基础，不能传承。教授医生律师，程序员作家是中高收入人群，他们的收入来自于技术和职称。这个东西不能传承。如果他们的孩子不能考出个资格证书或者 985 硕士，他老爸就算是总行副总裁，985 校长，三甲院长，也不好意思招子女进来，更没办法给子女发展铺路。

中产们长期脱离社会底层，他们只喜欢职务，技术和高薪，对未知事物和不确定因素，充满紧张不安的情绪，让他们眼睁睁看着子女在社会上游荡，心理上是难以承受的。为了解决传承问题，中产对子女教育已经疯狂到无药可救了。

我劝这些朋友们别太紧张了。体制外的世界，并不是你想象中的充满危险。体制外也是有大量机遇的，不一定比当医生副教授差。
