（家学）家族兴盛的秘密。人世间，只要有富，必定会有穷。穷和富，是相生相伴的。个人和家族的命运，也是如此。没有长盛不衰的家族，但是，家学传承是再起的精神准备。

有几条可以参考。

# 一，学习真本事

大路货知识，知道就行了。立体几何，在一百年前算是知识，现在因为不过是几毛钱的小程序而已。真正的知识是，懂人心+专业技能。在的时髦话是，消费心理，士农工商心理。

# 二，占据好位置

国内有三个好地方，京沪广（深）。这三个地方，是中国经济的源头。无论贫穷富裕，在那里占个坑，总是不错的。首推上海。

# 三，锻炼好身体四，关注新机会

在中国，传统行业，都是早就有霸主了。逆袭是不可能的。只要是明确发财的事情，你千万不要去。好事情轮不到你。但是，中国人有保守心理，权贵们在不能保证发财的情况下，往往不愿意切入新行业。这才是你的机会。
