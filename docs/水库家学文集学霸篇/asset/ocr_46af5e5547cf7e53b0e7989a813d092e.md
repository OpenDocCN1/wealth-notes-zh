# 11.1 学习中正确的复习方法

场景一：

在高一、高二时，还处于全班88人“稳居”57名的劣等水平……在那个纯真浪漫的求学年代，天真无邪的柴胖子，智力水平实属一般，放电视剧里，基本上活不过第三集。

但高二下期中考后，一位退休老教师丁爷爷，找他谈话……整个下午，办公室里佛烟缭绕，盘腿席座的丁爷爷，发髻冒烟，将毕生总结的学习秘诀，通过手掌不断重击其后背的方式，传给了他。除了差点没拍死他，一切都显得那么神秘和井然。

接下来的一年里，每次考试，柴胖子都前进5名左右，偶尔还数学满分，和物理138分……

这到底是什么方法，比电线杆子上的老军医还要神奇有效？
