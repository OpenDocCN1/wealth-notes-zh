# 留学有用吗？

作为老留学生，我的体会是，现在留学基本无用，拿到博士，可以去安徽的三本大学混个讲师。90 年代初期，留学生是超级牛比的，不管学什么专业，只要回来，就是报效国家，好机会通通给你。那时候，大学老师工资大概是 80 美元，外围洗碗的工资是 1200 美元，能够下决心回来的，确实不容易。由于留学生自带光环，所以引发了狂潮。

2000 年后，国内富人留学已经普及了。一般是三种模式：公派，合作办学 2+2，自费。除了公派，其他模式一般是卖房凑钱。京沪卖房留学的特别多。当时，普通孩去一般是去商科类专业，反正是万金油，大家去的时候高高兴兴。

等到毕业的时候，大概是 2006-2010 年了。当初去的那些学生，无论老家哪里，回来基本是京沪广深。由于过于集中，造成了留学生大贬值，海带就是那时候出现的。关键问题是，留学生学的知识，国内几乎没用。除了学习计算机的，其他文科商科专业，在国内市场环境中，毫无意义。举例，你就算是耶鲁法学专业，哈佛商学院，回到上海，律师考不上，做生意没关系，除了去外企当基层员工，真是别无出路。
