# ( 家学 ) 门当户对，真的没道理吗？

古代大户人家娶儿媳妇，非常讲究门当户对。这不是歧视穷人，是形势倒逼。富人从来不歧视有本事的穷人，只不过小门小户的女生，实在是拿不起来。你看很多土豪 “ 榜下捉婿 ” ，穷小子中举，立马倒贴嫁女儿。

清朝大盐商娶儿媳妇，最喜欢的是宦官或其他大盐商的女儿。这种利益联姻牢着呢！宦官千金，娘家父母哥嫂是后援团，强强联合，肯定给面子，遇到搞不定的事情，可能直接就帮忙了。大盐商的女儿是更好了，从小就耳闻目睹，虽然不直接参与工作，但是方方面面部都懂一点的。今后，作用很大。

一是资金周转。

两亲家毕竟说得上下话，如果女儿管家，多多少少给个面子。

二是人才积累。男方家，人才断档，老管家玩阴的。没关系，

娘家带三个销售经经理保安经经理过来压场子。要打要斗，不怕你。
