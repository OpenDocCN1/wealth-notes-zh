# 四，培训江湖的海天盛筵

我对培训班老师没意见，这是劳动所得。我只是说一下行情。现在，培训班是靠名师发财的，名师自己直接就发财了，收入高到一般人不理解的程度，具体多少，我怕说出来你会精神崩溃。这些金钱本来是广大家长和孩子们的，现在因为一个考试，全部变成了商业机构的收入了。

# 五，培训班毫无社会意义，但个人价值

无论怎么烧钱，从社会的角度看，985 还是这几个名额，那些解析怪题的技术，对科研生产也没什么实际意义，完全是社会的浪费。但是从个人来看，意义巨大。我把你挤下去了，我就嗨了。以后我考上 985，当高收入的金融人士，你读个高职，以后去当前台小妹。

在这种诱导下，哪个家长敢殴孩子？
