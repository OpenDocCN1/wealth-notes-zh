# 【给毕业季大学生的建议】

再有几天，你们即将奔赴大江南北，在新的工作岗位上开始新的生活。

在今后几年内，你们还要找，新的女友，新的房子，新的工作。如果你不能拼爹，那么你要有互联网思维，把自己想象成为一个 VC 投资人，把自己当做资本，寻找可能的热点行业，勇敢的进入，并长期持有。

大学生即将离开校园。以我不太多的人生经验告诉你，运气比能力重要。我的 2 个同学，水平差不多，一个在三线城市，由于一次大力提拔年轻干部的机会而飞黄腾达（那时小县城几乎无名校大学生），另一个在大城市默默无闻，但赶上了低房价，陆续买了多套房而发财。多年后相聚，互相感叹莫名其妙的人生。

# 大学生如何规划今后十年？

首先你定位自己：交际型（拉业务）还是闷骚型（技术男）？无论哪种，开始都很苦逼，没经验没客户，90%人熬不住，要转行跳槽。天下公司一样黑，各有各的烦。跳槽可以，但不要轻易转行。你就赌十年成才，不行就滚回老家。真正赚大钱的，还是拉业务提成。技术男拼加班熬身体。

我以前卖塑料桶，员工都不愿意出去拉业务，我没办法，自己出去拉。一开始简直是胆战心惊，无地自容。后来发现，我居然是超高素质的推销员
