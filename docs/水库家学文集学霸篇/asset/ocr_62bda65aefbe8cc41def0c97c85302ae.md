我是上音附中，上音本科，毕业好几年了。以后我要是生了小孩，小孩要想学音乐，就算他再有天分，再愿意坚持，我都想好了，直接打断他腿！

我目前的人脉和资源，已经算是音乐圈里比较顶尖了。只是因为，我运气好，有灵气，恰巧碰到了好老师。所以，我对其他家长说几句，不要白费力气了，音乐专业很亏。你家里有矿吗？？

花钱学琴，花时间练琴，都是小事。小时候学，父母至少一个全天不上班陪读，东平路附近租房子费用不说，父母长期分居离婚的也不少。（这个我还没想到）

+   独奏家怎么当？ 1，国际比赛拿奖。

+   2. 你父母是独奏家或者圈里人。普通人根本不可能。

孩子学几年，专业变强了，买乐器几十万搭进去，音乐系毕业只有千分之一成独奏家，一般人只能考个乐团。我家也算是为我付出了太多，读了上音附中之后，全家搬学校附近。我算是运气好的，家里有能力砸进去上海一套房子的成本。明年出国了，今后两年不知道要花多少钱？

深造之后的工作或者机会，我是一片迷茫。上交交响乐团的普通演奏家，税后工资跟门卫一样多。我一心想要改行，但是除了音乐，别的也不会……
