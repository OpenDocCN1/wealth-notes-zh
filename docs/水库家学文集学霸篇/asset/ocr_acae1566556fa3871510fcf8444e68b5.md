# 家长要避免成为以下这几种情况。

+   一，三甲内外科医生，至少倒霉五年，校长班主任拿你当宝贝了。那写什么呢？你随意。

+   二，实权人员，也是麻烦很多。你懂的。

+   三，低端行业，废品回收，卖菜杀鱼，KTV 副总，国际娱乐会所领班，包工头，校长也烦。

+   四，装修队长等，你就头大了。等着吧，好事不断。

+   五，暴发户，小老板。嫉妒恨。

# 如何面对优质学校的伸手？

学校会出个题：你家长愿意为本校教育发展贡献一些资源吗？自愿捐资助学多少金额？

答：随叫随到，义不容辞。捐资助学金额，5-40 万。按照本年度捐助的中位数认捐。超过四十万就无能为力了。

（我说的是美国私立优质民办小学，不抬杠）
