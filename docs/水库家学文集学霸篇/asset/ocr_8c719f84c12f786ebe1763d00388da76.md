# 学校里的新年音乐会。

很多中小学校喜欢搞管弦乐队，把学生们组织起来，让家长出钱，搞一支乐队，吹拉弹唱。表面上是什么热爱音乐，本质上是给学校做广告。你看，我们学校是素质教育。

# 吹萨克斯的孩子。

我原来年轻时候，住在一个城乡结合部拆迁户小区。楼上有个孩子吹萨克斯管，噪音实在是太大了。学校老师鼓励孩子，不要管邻居死活，每天晚上必须吹一个小时，别人都是傻逼，吹萨克斯的才是精英。拆迁小区一般房子小，萨克斯太响了，自己家长也受不了了，就怂恿孩子在楼道里拼命的吹，自己关起门。老式楼道会产生回音，差点把几个老人吹出心肌梗塞了。

在京津沪住房如此紧张的地方，学校老师大面积的鼓励孩子们自私自利，制造噪音，坑害邻居，这种素质教育，实在是卑鄙。孩子们长大了，心态都是扭曲的。当然，学校无所谓，校长直管自己拿奖。
