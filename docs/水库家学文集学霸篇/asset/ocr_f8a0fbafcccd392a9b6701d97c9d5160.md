# ## 11.2 正确学习的方法

第一，先低头看你刚写的解题过程，再看我划在黑板上写的正确答案的解析过程。哪些是我讲之前写的， 哪些是听我讲完后你补充上的。 是哪个小伙伴把你卡住了，没整出来？ 然后把那一伶小的细节， 拿红笔圈起来， 旁边再画朵大菊花， 表示非常重要 亲，这就是， 你从该题中学到的第 1 点

第二， 闭上眼睛， 合起本来， 想想哪些知识是你做这道题前不知道的，而是做完之后才总结出来的。 然后， 用自己的语言 （ 即写出来是非常土的大土话 ）， 把你的总结， 记在本上 并在旁边画朵大菊花， 表示非常重要。

第三， 想想这道题可以总结出什么来， 它可以归到你之前做的哪类题目里来。

深刻地去挖， 去总结你做过的每一道错题 若一道题， 从开始就一点儿思路都没有， 那么不是你这道题不会， 而可能是你这个题型不会

因此， 你下课要主动跟老师说一声， 要这种题型去。 说白了， 就是对每道中档题、 难题， 都总结、 总结、 总结、 总结、 总结、 总结、 总结

总结出规律， 要遇到这种题型的题， 用规律去解题 无论是英语、 数学、物理、 语文， 都这么干 你一定牛 这样， 我们即使只做 3 道题， 也能顶得上别人不思考、 不总结做的 9 道题。

啥叫高效率？ 亲， 这就叫高效率

学的不是一道一道的题， 不是解题过程， 不是答案， 你要学的是题型方法以及怎样总结题型的方法。

无论学哪一科， 学到的都应该是这些 事怎么做， 永远比吭哧吭哧使
