# 没搞专业了。现在一个小卖部推销钢琴。

这种小卖部就是国产钢琴厂的路边摊，租个便宜的房子，放几个钢琴。那些业余教钢琴的老师在教课之余，家家户尸推销，然后领家长过来买，吃 点差价。

她是专门服务社区过路客的。因为销售提成高，据说一个月卖掉 2-3台 就可以了，收入还算过得去。关键是，钢琴销售不需要到处跑，她也习惯坐 在小店里的生活。生意惨淡，经常是一个星期白板，上班就开始打瞌睡，干 坐到下班，虚度生命。后来她找到了一群新客户，退休大妈，努力推销了很久就差喊 妈妈了。但是，大妈只想玩不愿意买。不了了之。

原来，钢琴考级是中小学加分项目，把孩子逼惨了，但钢琴老师生意较 好。现在，也不加分了，学的人越来越少少了。钢琴老师也每况愈下。理智的 讲，钢琴本来是贵族玩意，我们这些平民子弟能够考到中央音乐学院的，有 几个啊？大多数还是去了小师范。

我是 90后三线城市女生。从小学钢琴，砸进去无数时间金钱，从一年级 学到小学毕业，考了南京艺术学院的十级证书。

长大后发现，钢琴技能一点用都没有。我钢琴导师儿子，小时候啥也没 学，本科发迹文化课成绩只够上一本，转学美术，走艺考，去了同济学设计
