# 七，建议改革大学招生体系

我们不卡洗脚按摩，不卡桑拿洗浴，为什么要卡孩子读大学呢？培训班千奇百怪的根子是，有些部门把学习科学，搞成了怪题比赛。然后卡着一些孩子，不让他读高中，不让他读大学。家长能不急眼了吗？

孩子想学习知识，想读全日制本科大学，为什么要拦着他？让他读啊。985 场地有限，但一般本科可以放开，彻底管够啊！文科经济类的大学，不就一块黑板，几个教室吗？在小地方根本不值钱啊。不要说什么缺少老师，那些教师是什么水平，我还不知道吗？多招几个不就好了吗？
