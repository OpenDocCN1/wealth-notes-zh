# 11.13 干的冒烟的学习方法干货，适合初二及以下年级

讲一个真实小故事。 有一个高二学生叫赵 XX。她妈妈必须得重拾英语。

为啥呢？

她妈妈所在的超级大央企 开发的产品卖给外国人。但外国人不会使得他们培训。本来这都是刚毕业小年轻儿内部竟聘干的事儿。但她家 2015 年刚换了大房子 有房贷 20 多年的北京打拼生活 周遭工作也乏味 就想换个环境 重点是工资还翻倍呢 于是就递交了内部竟聘申请 准备考试。

要学英语 并且还得学大量行业内的专业英语术语。她妈妈本是 20 多年前的大本英语底子还行 但过了这么多年 也忘得差不多了啊 于是就不得不重新拾。

天天追着孩子问。 孩子英语本来中上等 但轻飘啊 老以为自己英语都好到她妈家了。 就给她妈讲。一开始 还有点优娇 还嘴畔瑟 还有点爱搭不理的劲儿。但很快就歇菜了 就原形毕露了。 教不动了 教不明白为了。

经常是给他妈照着答案讲完一道题后 自己也懵 她妈也懵 两人面面相觑。更有题目 是谁也不会了 两人干瞪眼。

但公司不是儿戏 申请都交了 那能说拉倒就拉倒！于是母女俩就一起查有道词典、Google 翻译硬啃。按女儿的话说：每晚都有一个后进生 要强迫和她一起学习。还不停地问 都快烦死了！

实在是晚上查不明白的 就记好了 第二天让她女儿问老师。第二天晚上回来了 女儿先给这当妈的讲。两人还互相监督 背单词 背短语 互相提问。谁背不出来 晚上刷锅刷碗。 经常是 7 点吃的晚饭 晚上快到 11 点了 才决定出谁刷碗。
