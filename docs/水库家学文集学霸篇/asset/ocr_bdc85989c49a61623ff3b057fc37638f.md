# 四，去碾压同龄人，建立自信心

我们其实在家里已经完成了语数外启蒙了，根本不需要去报幼升小补课班了。但我还是报。我的目的很清楚，去碾压同学。孩子每次小测验回来都是第一名。老师表扬，同学巴结，心情美美哒。

其实，这个结果是预料之中的。我是让孩子感受一下，长期做第一名的自信心。我不比别人差，只要我努力，我也是第一名。
