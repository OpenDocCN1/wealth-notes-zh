# 在国外打工的华裔，大部分事业发展不太好，除了专门做国内生意的。

这么多年来，清北 985 毕业的在美国，少说也有几十万人了，就没见过几个混到五百强中高层的，大部分还是实验室民工。这些人可是我们这里百里挑一的人才。说白了，语言不行，文化不融。

第二代 ABC，发展的也不怎么样，长大了只不过是居住国的少数人口而已，汉语只会说几句日常话，失去了第一代华裔的苦熬精神，又没有人家的社会背景，父母也是老实的打工仔。总体而言，华裔在美欧的社会地位方面，还不是想象中的那么好。

我在留学期间看到，九十年代读博士出去的第一代华裔专家，少数人运气好，岗位还算体面，成为了专业沟通桥梁的中介。他们在国内的很多大单位有老同事，出去就找他们联系安排。那些年，中国文化热，这也给他们在欧美的专业领域创造了小小的话语权。第二代ABC，基本就是打个工的小职员了。
