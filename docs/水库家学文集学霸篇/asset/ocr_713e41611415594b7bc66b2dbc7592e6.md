# 花雕酒的化学作用。

很多肉类遇热后，会散发膻味。膻味的化学性质是有机挥发物。去除有机挥发物，只能靠酒精作为溶剂。所以，必须用酒。

白酒为什么不行？因为白酒在去除了肉中的有机挥发物后，自身还有较浓味的杂醇，不容易挥发，就留下来了。所以，白酒做菜，就是一股白酒味，不好吃。

花雕酒中也有味道的化学成分，但容易挥发。菜烧好后，热气既带走了肉中的有机挥发物，也没有花雕酒味道的留存。
