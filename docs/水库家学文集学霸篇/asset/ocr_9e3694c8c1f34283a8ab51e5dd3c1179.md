# 1.1关于教育

什么是教育？

对于 90%的人而言，教育是谋生手段。

大学的起源是，富人孩子为了追求精神享受，或者科学怪才推动科学发展， 这是极少数的事情。现在搞笑了，农夫的孩子不种地了，去追求历史沧桑感了。平民的孩子去学习企业管理了，你的企业在哪？
