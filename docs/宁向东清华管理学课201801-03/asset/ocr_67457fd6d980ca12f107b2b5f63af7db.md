# 周末复盘 | 每天用功的你，请不要焦虑

周末复盘 | 每天用功的你，...

今天的复盘，我不想复述有关的课程内容，我想谈一点学习方法。

从开课后，一直有同学在后台留给我，觉得学习太多的管理知识，不知，听我那么多听多新，但记住的不是很多，问怎么办。今天和你分享一点我学的体会。

我举个例子。我们学语文，读了很多课文，学了很多字，很多词。那些课文，你们都记得吗？我想你肯定没有，我自己也没记得几篇课文了。但是学语文，让我们说出了标准流利的话，让我们会请调完整的句子，这样，我们就可以借助书面和白语的方式来交流了。这就是学语文的功效。不瞒你说，我自己是在翻看中学生课本上的文章，有些字词已经都不记得正确读音了，但我觉得没关系，虽然很多人说多学多的节我全忘记了，但你前我学有点，大逻辑我没有忘，我觉得没必要。

当然，有些东西，是先光学习课本，无法能够懂的。第一遍学习，多少只能是知道，知道之后，需要随着阅历的增加，才会渐渐体会。涉及到这一类的知识，不要着急，这一类，需要时间。

我再来举个语文的例子。比如，小学生就知有个词语叫“老泪横流”，但你没有生活阅历，你无法真正懂得它老泪横流的机会。而反过回去，老人一般都都经历过很多事。一件事，够为一位老人流泪，这是否句常的事情。所以，当你到这个词，并产生真理解，其实需要时间和阅历。

所以，只有真正自己老泪横流，你才会理解老泪真正的程度，才体会得这种流泪的机会。而反过回去，老人一般都都经历过很多事。一件事，够为一位老人流泪，这是否句常的事情。所以，当你到这个词，并产生真理解，其实需要时间和阅历。

学习管理学的道理，其实与此非常相似。你印象感受记住的不多，真正理解的也不多，这是正常的。管理学，是介于科学与人文学的一门学科，因为为管理活动中有道德的因素，所以它有科学的成分。科学成分的东东，你学一遍，总会有人文这一阵子，但是，管理学中有大量人文学的内容，是需要时间理解和消化的。所以，你不标把管理学当纯物理学来学，它没有标准答案，也不可能学完了马上就会用。

总之，管理学的学习，需要慢慢地练。你订制了门票，其实，就是买了随同上门的机会。你现在学懂，不会到了一些事情可以再看，也许很容易就看懂了。过去，我们学花生了大字，考时清无，也只能听一遍，现在互联时代，无事能听，你慢慢学习就是了。所以，不需要焦虑，也不需要急于求成。

今天的资本资产代价值型中的贝塔值给了我启发，它可以是代性地应用到我们的工作和生活中：一是在设定绩效激励措施时，不同的级别的目标值用不同的贝塔值不一样，比如高管的考核的薪酬值；二是在人员管理上，不同级别、不同贝塔值的人，所做的事应该也是天差地别的。高贝塔值的人做了一件低贝塔值的事情，即便做得再高也不应该受到表扬；三是人际关系中的应用，这个是一个反例，不同贝塔值的人关系系入的和不同可能带来的回报也是不比例得，高贝塔值的联系人投入时间大，不在往住也没有关系，如工作、生意上的关系；低贝塔值的联系人，投入时间少，平时不怎么会联系，如你的挚友、家人。在人际关系上我们该更多关注低贝塔值的关系。
