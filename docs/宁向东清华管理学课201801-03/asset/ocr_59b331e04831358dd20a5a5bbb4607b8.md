# 167讲：危机分类模型｜预警黑天鹅

你好，欢迎回到《宁向东的清华管理课》。

今天，我们先讲在危机管理中“危机”这个概念的重要部分，后面，我们再分析它的对危机进行分类的工具。我再多时候，当我们遇到一个新情形，或者新变化，我们常不知道该如何去判断这个情况，也不知道这个新变化对于我们自己，究竟意味着什么。所以，往往不知道该花多少力气去对抗和处理这个困境，今天，我分享一下九个工具，也是个九宫格，也许可以帮到你。

# 1. 危机感

先讲第一个问题，危机管理的前提是一定要“危机感”。我们常常谈到“居安思危”，说没有危险，但正面临威胁，不舒服。我一直思考，它是什么意思？现在，我比较倾向于，这个叫做“危机感”或者“谨慎倾向”的东西，是一种人类的特质。有些人天生就多疑、敏感，就像有些建过危机意识，而另外一些人则更加充满希望，更加愿意冒险，就相对难以自发性地形成危机意识。

这形成了一个特别有趣的悖论，就是愿意冒险的人，往往去搞新精神，闯出新路，比如农夫，他们敢打猎，甚至赌性十足，所以，容易把企业搞起来。但是，正是这个习惯，在优点与不足两个方面，都是缺点，就靠企业在不断快速发展的同时，他们的自信心也逐渐增强，进而缺少危机意识。

我最近一直和人行讲青岛飞公司的案例，希望能够多一部对中国企业有所警示，在我看来，很多中国公司的企业所有的董事，其实都是爱国人。日本人玩剩下的、历史不会有什么跳跃。今天这些被迫和三十年前的中国公司说，因为危机意识太薄弱，林荫电气并没有被通过，结果到很顺利去收购企业，结果遇到了很多没有预料到的情为：股东太复杂，连《哈佛商业评论》都认为，林荫电气80年代初海外扩张失败，最根本的原因就是公司领导的过度自信。所以，危机管理的前提，就是领导者要建立危机意识，要正在内心深处有危机感。

有了危机意识，就会在有三样很明显的特点：

+   1. 有危机感的人，在思考任何事情的时候，都不会事情想得一模一样。我有更多学生，有人想法的是风险，有人的想法是风险，也有人想法的是收益场。可思考的是“最佳实践”后想法的“最差场景”。他们看事情的角度都是完全不同的。
2. 有危机的人，是会前提设计和预防措施的，就是我们前面讨论危机管理的时候，最后一列是各种意外因素的，有危机感的人考虑得非常细致；
3. 有危机的人，会经常在不经意间对自己的危机进行预演，会结合一些方法，以便应对危机，降低不期而致的风险。

# 2. 危机管理矩阵

下面，我帮你分析一个危机分类的模型，希望能有助于你对危机进行分类。

这个模型是一个九宫格：横轴是一件事发生后，它的危害有多大，可以分3为大、中、小；纵轴是这件事发生的概率，也分为大、中、小。于是，横轴和纵轴上的大小小之间就形成了不同的组合，就是下面的九宫格。

我就以企业骨干离职作例子，来看所谓的“企业危机”。企业中间的骨干，都有可能离职，而且不同的人离职，震动会比较大，影响会比较大，可能会带动带来危机，而离开的人却不会。比如，同样是管理骨干，在大公司里面，走了就走了，即使是非常高的发生概率，但影响面都是有限的，而在小型公司里面，一个人要顶了半边天。有时候太小，业务就全塌了半边天。关键骨干离职，对于企业就可能造成引发一场危机的导火索。换句话说，在某些企业，某些关键岗位人员、员工离职都已经被归为到会引发危机的变化因素。

首先，公司在做计划的时候，对于关键员工是要有特别方案的，包括费用上的主要保证和激励上的预案，激励，不一定主要是物质激励。以前讲培训力领导力的时候，讲过例子，其中有一个很有创意的“吃晚饭”小政策，他们的基本管理认为奖励和激励比单纯考核一考核、就是奖金的鼓励，这是正面的考虑，目的是为了保证人员的稳定，不出现意外。

但还有可能吃了饭也没有用。所以，第二条，有危机感的人管理者就应该经常性地把团队成员位置都在九宫格中排一排队。例如，有的团队骨干，他手里最有关系客户，而且手下还带着一批核心骨干。毫无疑问，你要判断他是处于九宫格中的哪个小格子里面，更紧要的是，是不是处于最右上角的那个九宫格。

如果真的在这个右上角的小格子里，那么，该如何防范这种危机出现？包括把大影响变成中影响，或者小影响；以及把大概率变成中概率，或者小概率。 也要考虑这个危象人物到格子，如果危机带来的风险因素无法减少，那就要考虑提前做风险预案。有准备的，可能要写详细预案，便于大家执行，而没有条件的企业，管理着起码要经常会在头脑中按照这样的思路过过一遍。

# 3. 黑天鹅

分类矩阵，是一个危机管理、风险控制的常用工具。一些管理者在使用这个危机分类矩阵的时候，会按照图示中标记，认为有感叹号 的格子代表高风险因素，必须要做预案。不过，讲人的意识倒标准数教科书不一样，我念了教科书的主体内容，我今天再类点精髓。

很多人在使用这个“危机管理矩阵”的时候，都把标在左边右下，对这三角格线上的三个格子去分析风险，对这三角线的右方，也就是我打了感叹号的三个格子里面的风险事件，认为是必须要防止危机出现的对象。但是，我倒觉得不是只有这三个有感叹号的格子需要高度关注，我个人的看法是，只要是一旦出危害最大的人员因素，都要事先进行控制。

我的阅历告诉我，只要是影响很大，后果非常严重的事件，都应该在管理中归于“危机管理”中的对象。这样的处理理由很简单，就是因为大多数情况下，我们没有办法去准确判断一件事会发生什么概率。甚至，有人认为，从某种意义上说，我们甚至无法判断出概率的存在吗，都不成危机。而真正构成危机威胁的，大多是事事先没有预料到的事件，而且，有时候小概率、高影响的事件，一旦发生，由于大家都没有防备，危机更严重，会出现第四类，连环性崩溃。

想到这里，我突然想起了以前读过的一本书《黑天鹅》。2007年底，我在美国，记得的时候也正式铺天盖地宣传着这本书，美国时正赶遭遇大危机，但是高昂的《黑天鹅》：房地产泡沫崩溃、金融海啸、股市崩盘、投资银行倒闭等。经历了30年经济波动发展的人群，谁也没有想到美国经济会一下子跌到谷底。
