# 1.案例：马桶盖也可以不一样

前几年，我们的同胞也传出从东瀛买马桶盖的消息。那个马桶盖应该也不便宜。不过，对此非常理解。因为我前面举例，说，我是早年回国了，才第一次去日本。但那一次日本之旅，却给了我很多出乎意料的认识，以至于后来多次去日本，实地体验他们在产品市场上的匠心。

我家很少使用日本的产品。不过，我家的马桶是日本的，TOTO的产品，因为TOTO的马桶座洗净器（Washlet）比较普及。中国人不太重视便后擦一之后的清洁法，导致了很多人有痔疮或痔疮的毛病。中国有一种说法，叫做“十男九痔”，形象地描述这种疾病的发病率。前段时间，我到一个朋友访问了同一个的发达国家，有条件的洗手间居然都有一个自动冲洗，用水冲完之后用热风吹干，我印象很深，在这个方面来说，似乎疾病的发病率就比较高。人会付很多钱，而我们在解决较大公共问题的同时做后，并不能很好地解决清洁卫生问题。

总之，在我心中，方便之后用水清洗，是个卫生，又便捷的好方法。我曾经反复思考过它的体验产品，比如，在TOTO的产品和有一些合资品牌，它们产品的差距确实很大。后来问到专家，说，这不仅仅是马桶盖的问题，还有它的传感器、伺服电机等一系列部件的差别。所以，竞争从表面上看，是一个产品，但背后是标准件、产业链，有差别，因为这种差别的差距，TOTO在海外的销售，已经超过了它整个TOTO份额的十分之几。所以，很多人去日本买马桶盖，我并不能非能理解。因为日本，总是把最好质量的产品留在国内销售。

在中国市场上，TOTO的价费变得比较贵，但更重要的是它们的的产品价格就是，稳定的很好，有品名效应。这就是差异化战略的差别太大了。马桶盖，只是日本卫生产品的一个例子，我们下面看你的视野从马桶盖放眼到整个日本人的卫生间。现在，在世界范围内流行的很多卫浴产品，都是日本人研制的差异化产品。

![](bbox=[0.1, 0.58, 0.9, 0.62])

大约在十年前，我曾经仔细研究过日本人的卫浴产品，都是前面所说的，很高级。因为它的很多产品，都是突破传统概念的。比如，整个红外线感应门的感应器。当你进入一个洗手间的时候，马桶盖就会快速地自动加温，特别在北方，不用坐在冰冷的垫圈上，这是一个很人性的设计。

最高级的马桶盖，是会自动开启的。刚才提到的红外线感应，是可以设定马桶盖在人与它的间距达到一定程度的时候，自动打开。也许有人会认为这个自动开关的设计不必要，这就是对日本客户消费的理解。这个自动开启马桶盖，可以用于去除这个自动开启，可以保证手相对比干净。这一点，早帮助于对想在清洁程度的要求，特别对于视力不佳，现在，很多公司已经开发为比较多使用的部件材料了。其实，抗菌材料中，在加入着色剂的同时，再加入少量抗菌剂就可以了。有抗菌塑料等商品，成本上升得有限，但型“清洁要求”比较高的消费者很大。这种差异化，就会帮助一部分人的购买欲望产生相对需求的感受。

第二个档次的马桶盖，是有缓慢开启和放下功能的马桶盖。我记得很清楚，当时日本给我介绍的时候，说，这种缓慢开启和关闭马桶盖，就可以满足有缓释需求的用户。它不像我们现在的那种马桶盖，放下时砰砰作响，夜里会吵到家人，或者产生另外的卫生问题。

说到声音。我记得当时还有一个日本洗手间模拟水声的发声装置。这也是TOTO最先开发出来的。
