# 1. 业绩是管理活动的关键变量

为什么这样说？管理学的核心，是要追求业绩。我前面所讲的“整合资源，破局而出”，为什么是关键？就是获得好的业绩，无论是财务的业绩，还是综合的业绩。一切的领导活动，一切的管理工作，最后的目的地，就是为了达到理想的业绩目标。比如，我们是如何理解“我们的目标从战争到商业有没有什么运动机制和团队，包括我们要重要的，就是控制成本和变革，为了什么，都是为了追求良好的、令人满意的业绩。所以，业绩，是一切管理活动的关键变量。

上面这段话，在这个模块的复盘中，我把它画进了，我们整个模块比大家程序输入，它是一个粗的时钟，进讲学者的财务逻辑。财务学者的核心，就是公司收益率，或者投资收益率。股东投资金公司，都是为了让企业的长期利益最大化，为了长期利益最大化，那么，怎样获得长期投资最大化？从财务的角度，就是提高利润率，增加周转率，适当地建立财务杠杆。

那么，如何提高利润率呢？根本上就是要找到最好的客户，通过你的战略，指挥有效的行动，打败竞争对手，给你的客户提供最有价值的产品和服务。我们所有的财务战略、战略战术，所有那些创新，其实是为了一个共同的目标，通过你的产品和服务，获得最大的利润回报率。当你的资产不等大的时候，可以想办法去寻找外部资本，无论是投资、贷款，还是找到的债权，都是为了实现最优的资产规模，通达资产，获得利润。

钱多大了，资产规模大了，有了内部运营沟通与变革，管理需要提高。企业的内部的管理就要提高，我们前面讲的领导力、团队建设、组织运作等等一系列管理问题都需要加进来。其实，在这里，财务指标就必须转化为非财务指标。比如，从资产周转率的一个主要因素是，应收账款的回款率。这个看上去是财务指标，但是这个指标的是企业的产品质量是否足够好的、售后服务团队的工作质量也是是够好的。它并不简单单地就是重要的问题。

上周一所讲的鱼骨图方法，包括以前讲的平衡分析、标杆管理，在这个模块都可以大显身手。总而言这，就是得导出一系列的绩效价值的KPI，并且，把这些KPI落实到组织的各个环节中去。

还记得我讲的要给组织穿上业绩的衣服吗？组织穿了业绩的衣服，每一个班组成一了团队，都背了清晰的业绩指标。接下来的问题，就是如何在工作中做到沟通协调，打造高绩效的团队。我们在这一周的课程，讨论的都是这一类的话题。

# 2. 业绩管理的四个步骤

从一般的管理学逻辑上说，业绩管理的本质就是四步动作。

第一步，就是设定明确的业绩指标，然后进行业绩目标沟通，业绩规划的核心不是强硬地把业绩指标压下去，而是与管理者进行协同，达成在于，于业绩目标的共同认知。我自己的实验是，在业绩计划模式下，业绩指标可以强制地压下去，但是，执行的效果都不算太好。

第二步，就是要进行及时的、持续的成绩通报与改善。在这一环节上，我帮你设计了一个“六行表”，并且向你介绍了一个“导航仪”的观念，希望对你有帮助。

第三步，就是需要业绩业绩考核的情况，学会了要，必须说。业绩模块的沟通进行复盘一下有关MBTI的那一讲。不同性格的人，沟通技巧是完全不同的。如果不能掌握人的性格特点，有时候业绩谈话工作的结果，会适得其反。

还记得我以前讲的“加藤坐标”吗？今天的课后，不妨做一张加藤坐标复盘一下。说一下对你提高业绩面谈有非常大的帮助。加藤坐标是一个方法，是一个工具，业绩面谈是一个场合。你需要思考一下在某个特定的场景中，面对不同的谈活对象，如何有效地使用这个工具。
