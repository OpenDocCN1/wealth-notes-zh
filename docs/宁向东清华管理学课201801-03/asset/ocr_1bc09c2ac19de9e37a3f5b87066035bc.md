# 1.从财务出发

既然美孚主要问题是资本回报率低，所以公司的战略目标之一就是后表现为：要在三年之内把资本回报率从7%提升到12%，从财务指标出发思考你的运营逻辑，平衡计分卡的基本逻辑，所以，无论从卡普兰和诺顿作为工具的提供者，还是企业的管理者，都得从这个开始是关键。

提高资本回报率的途径，无非就是两种：一种叫做做油，叫做大资产，就是把更多的产品卖出去。第二种是，做加油业务之外的新业务，比如，洗车业务、维修、保险，甚至零售里面的各种消费品业务。

第二种是提高资本回报率的途径，叫做做强。我们有时候也经常提到做强的两个手段，一个是做什么做强，一个是做资本回报率，让单位销售的收益提高。第二，就是提高资金的运营效率。换句话说，就是在特定的产业下，获得更好的现金流、减少库存，总之，就是提高资金的使用效率。

这些逻辑关系，你可以从今天的图示中看到这个，它反映了公司基本的财务逻辑。所以，平衡计分卡虽然强调要从长期到短期，但从体系逻辑上，还是从财务这个层面入手的。对应财务方面的工作，一般是公司的计划财务体系，所以，当你学习使用平衡计分卡的时候，你也要首先从你的计划财务体系来启动。
