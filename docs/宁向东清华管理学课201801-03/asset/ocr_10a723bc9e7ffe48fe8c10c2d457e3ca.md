# 划重点

> 目标设定理论要点：
1.难不要紧，重点是要明确；
2.员工必须知道怎样努力，才可以完成这个有难度的目标；
3.员工必须能够看到其行动结果的及时反馈，以便让他们知道，他们正在向“目标”进军，这涉及到持续承诺的建立。
