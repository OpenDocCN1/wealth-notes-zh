# 163讲：战略地图的标准模板

你好，欢迎回到《宁向东的管理哲学课》。

昨天我们讲了平衡计分卡，在美孚美公司的时候，这也是卡普兰和诺顿亲自操刀的一个案例，相信已经掌握了最基本的逻辑，就是从结果层找出原因，通过解决因来达到结果的逻辑。今天，我们再把这个逻辑往深了走一步，和分析这家学术思想中的重要工具：战略地图。

# 1.平衡计分卡的演变

1996年，卡普兰和诺顿出版了他们“平衡计分卡”的第一本书，不过这时候，作为一个管理工具，平衡计分卡的底层逻辑虽然已经成型了，但是，工具层面还是欠缺很多。所以，在那本书的序言里，卡普兰和诺顿特意写了一段话，给读者一个严肃的忠告。我记着最后三句：或者再过几年，我们还会再写一本书《平衡计分卡》的续集。

事实上，卡普兰和诺顿后来写了四本书，加上最初的一本书，一共是五本，形成了这个学术领域的经典系列。2000年，卡普兰的第二本书。2001年，我正是在哈佛商学院读书，只读过一本诺顿教授写的，但这本书我只读了不少遍，印象深刻，这本书我读起来不是很流畅。但深读卡片言和诺顿在书中所表达的那种变异。当然，这种变异是我隐约感受到的。

第二本书名字叫《平衡计分卡（续）》，书中《战略中心型组织》读了很多后来手操刀的一些案例，一些做法。这本书的最后是叫《避免陷阱》，讲了平衡计分卡这个工具进入组织之后，在使用中的种种问题。当时，太多的公司开始使用平衡计分卡了，所以，出现了很多问题。

![](bbox=[0.15, 0.38, 0.85, 0.55])

卡普兰特别有针对性地给大家解释使用中的问题，因为他专门研究这个卡设计的七条，以及因为实施而引发的七大问题，导致平衡计分卡无法落地，或者落地以后会失控。整本书我读了很多遍，在序言里他写了一段话了：平衡计分卡作为一个管理工具，是没有问题的，但是，实施这个管理工具如果运用得不恰当，是会导致很大问题的。

# 2.一把手工程

卡普兰向大家提出的第一个失效原因，就是领导者会把平衡计分卡当成一个考核工具，然后，把这个工具的使用权交给项目团队或管理团队。这里的的故事是这样的。平衡计分卡，是一个事一公司高层身的大管理工具，所以，决定在公司里使用这个管理工具的公司，就是一家一把手工程。我一般把这种情况叫做“一把手工程”。

一把手很容易听到这样的鼓动：就是：如果有人一张时评分卡，公司里面的人日常动作就会跟随这个总目标去，效率就会提升，每个小组都有目标，就好像是该朝的方向，管理效率会大幅提升，自然可以把高管团队的运行效率。一般来讲，一把手一旦听说这个项目有显著的效果，都会同意，然后交给下属落实。因为《平衡计分卡》这本书，有图标，涉及绩效体系，所以，一个通常就被交给人力资源，作为一个改善管理的工具。

2001年，我花了太多时间读这本书，从内到书名，都花了很多时间。我渐渐意识到，卡普兰教授在努力改变这本书的定位，他开始强调把该卡看该用户，平均计分卡只是一个仅仅关于组织的工具，它并不是战略地图的工具。所以，他的第二本书叫《平衡计分卡（续）》，但也叫《战略中心型组织》。如果你有空，又好奇，可以读一下《战略中心型组织》的序言。你一定能读出一个理论化论化的逻辑。

总之，因为读得早，读得认真，我在2001年就感受到了“平衡计分卡”这个工具，不仅能仅作为一个考核工具被使用，它应该是一个战略工具。而如果是战略工具，在实施的全过程中，就应该是一个一把手工程，而不仅仅人力资源部去组织实施。

和你们分享趣事。由于这本书的中文版是2008年中大报的命，是在此之前的08年里，很多中国新企业把这本书作为考核工具来使用的。记得有一家大机构曾经在清华大学招，那时的大概是04年，当时我们一起学平衡计分卡的思路，我们告诉你，我们已经在用。了。这家机构的老板很年轻，也很有想法。正如我前面说的，当他听说了这个管理工具之后，就决定使用，但他们把这个工作的系头部门放在了人力资源部。

那天的课堂发生了一点小冲突。因为我简单问了一下情况之后，我断定卡普兰所说的7个问题，他们都犯了，所以，成功不易。那时我还不成熟，课上直接表明态度了。他们的人力资源总经理当时在场，就是把我得罪了。我虽然后场，但明显还是有感，动机较强。后来升的，他们的二期培训，没有请我讲课，有否聘请讲课，人力资源总监都是我发言权的。

但第三次培训，他们又找我了，而且他们告诉我：宁教授，我们的平衡计分卡项目，现在的牵头单位已经从人力资源转移到总务处，我有点得意，但得意并不是觉得自己高明，而是证明了对卡普兰的“定位错误”判断对了。有些事，这是一个平衡计分卡，一把手要抓，是不可能有好效果的。
