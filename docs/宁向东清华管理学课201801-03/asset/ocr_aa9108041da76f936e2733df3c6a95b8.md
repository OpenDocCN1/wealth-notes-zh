# 1.失败的原因

烟村先生不是商学院的教授，他是工学院的教授，但是他的主要著作都是“发明创造”、“创新与失败”领域。2001年，他在60岁的时候，创设了以自己名字命名的“创新工作室研究所”，2002年，他建立了日本失败学会，并任创会会长。我不懂日语，我读的是日文的，不是通俗的科普书，就是讲学文章，大致只读过了这本翻译先生的书，感觉还不错，所以，今天的课我把他的理论介绍一点给你知道。

今天的文章中，有一张图示，摘自于烟村先生的《失败学》，有称之为“失败的原因图谱”。你在课后可以花点时间，好好看一下。虽然这个图示复杂，但是，大部分是汉字，你结合我的音频，一定能看得懂。

![](bbox=[0.12, 0.49, 0.88, 0.62])

在烟村看来，失败的原因分析在逻辑上并不复杂，原因的种类是有限的，只是很多人不愿意对这种“错误”进行只分析。

烟村认为，当企业逐渐成熟，稳定发展之后，分析失败、管理失败、预防失败，比简单地研究他人的成功案例更重要。他说，在成功的经验之中，会包含很多偶然的创新因子，这就是我们值得花时间研究所谓“失败学”的意义。

我重新整理了烟村的“失败十原因”，我觉得大致可以分成这三类。

+   1.  失败往往是出外部环境的变化的引起的。很多组织如果固守不变、经济环境、社会文化发生变化，都会引发组织的变化。

    而对于个人，情况也类似的。一次没有预料到的储备，可能也会导致的无法上一次开车，去拿了一次拿下大的机会。这一类失败，来自于外部环境的变化。这些变化对于组织和个人，很大程度上属于认知上的盲区和死角，包括一些未知的情形。未知内容包括人类从来不知道不知道这是客观存在，有这些现象。未知的部分，涉及到自己的认识准备不足，或者没有充分借鉴他人的经验，重视前例。
2.  和失败者自己本身的关系很大的。比如，组织对创新观对不足，组织适应性较差，公司管理不善，管理决策失误，彼此之间联络得不够充对等，所以，没有把事情做好，包括管理执行得不够彻底，执行力的欠缺，对政策理解得不够充分，对市场环境的考量或减少，等等。后面这种情况中，自己本身资源不够，领导者或者缺乏的事情也是资源不足。在烟村图示中的“没有意见”这，没有认真去计划，没有进行有充分的经营活动组织，我看得得都可以被否定是避免这一类。
3.  我觉得是自己不注意，自己也让注意到了，但是能力不足，用精力不足了。比如，能力不足，决定错误，但是有判断失误，包括在思虑时偶尔失误，在计划阶段判断失误，在执行过程采取什么动作中出现失误，等等。在个人成长和发展中去想这些是非常正常的。事情的进展上面去一切顺利，但是，最后还是失败了。有人就说，这只是失误，这是运气不好。

以上就是我重新整理的“烟村失败十类原因”。你也可以用，区分这十类原因，有什么意义？种和失败，意义非常大。比如，最有一种失败，有人也将称之为“聪明人的失败”。很多人有一个考虑失误，认为研究失败就是为了避免失误，其实并非如此。既然研究失败的目的，是为了避免失误，但是很多失败是避免不了的。

比如，你在做创新的过程中，就会。就像你，没有失误，不可能有创新。一个孩子学骑车，总是从骑车，摔跤开始的。不要去避免摔跤呢？肯定要学避免，但实际上很难避免不了。研究人员摔跤，研究人员摔跤，都是研究失误，但是，这种研究也都是为了不掉摔，学会骑车。所以，也许学者说：只要一个人学会总结，这种“聪明人的失败”，吃一堑，长一智，研究得够多，后面一定会有好的未来。

也许也是基于同样的想法，烟村教授特别强调要首先区分失败的原因，同时，他还强调研究失败过程，以及在这个过程中当事人的相关领导者的心理变化，然后再进行复盘和失败分析。在绝大多数企业里面，由于没有建立起来有效地失败的文化，所以，在失败之后去有效地复盘反而并不容易，因为失败并不是一件令人骄傲的事情，每个人都有一定能够最有效地正视自己所遭遇的失误。
