# 1.资本资产定价模型

我们投资投进去一笔钱，究竟应该赚回多少钱，有关这个东西的逻辑，有一种主要的理论。我们今天下的讨论基于一种叫做“资本资产定价模型”的理论，基于这种理论都不涉及，也不需要深究。完全搞懂“资本资产定价模型”，需要非常好的公司财务的训练，所以，我尽量简化地把这件事说清楚。你只需听个大概，就可以了，因为它不妨碍听我今天的其它部分。

假如你有一个亿的现金，你最希望的投资是什么？最低风险的投资，就是把它存到中国的某个大银行，工中都是可以的，你觉得这些银行在中国就是相对无风险的。只要国家在，这些银行就是安全的。所以，它的收益率很低，可以说是无风险的。在美国，学者们倾向于把20年期的美国债券作为无风险的投资。这些都是无风险投资的例子。

如果你做的投资，回报率低，那么你的风险就小；如果你的风险大，回报率高，你就承担了更多的风险。这个逻辑你理解了吗？

```
i = i_f
```

如果你再多想一点，你可以去买企业。最简单的是，投资企业的办法，就是买上市公司的股票。如果一种股票就买了一点，就相当于你买了整个盘，那个时候你可以得到整个市场的平均回报水平，也就是说，你获得了市场的本金回报，如果市场涨，你就涨；如果市场跌，你就跌。

```
i = i_f + (i_m - i_f)
```

如果你不满足于大盘，你就波动，很多风险，你记在一个大数，想想多风险，市场会给你多少回报。简单地说，无风险，无收益。在想要赚钱之前，先想好自己能承受多少风险。

我举个例子。2015年股市大涨，我买了一些股票，收益率很高。为什么呢？就是承担了多风险。所以，我们股票是承担多风险，风险很小，所以，收益也有点低。相反，我的一位朋友是大牌基金经理，为什么他为他的钱来买大盘股票呢？因为股票的特点就是——一旦启动了就是有几个涨停板，如果一直打出来了，那么就有几个涨停板，大家一起涨。如果你抓到了大起的那一段，赚掉了大掉的那一段，就会赚大盘钱。我这位朋友赚的就是这种高风险的钱。

不过，尽管他赚的钱，是我赚的钱的几倍，可是，我觉得我们的投资回报水平是类似的，我们的风险差不多，有什么差别？就是他承担了更大的风险，理应要求更一点，我们今天讲的资本资产定价模型，就把这件事说透了。

```
i = i_f + β ⋅ (i_m − i_f)
```

资本资产定价模型，我写在白板上，就是把我前面的公式又往前推了一步。比如，我买了一支股票，相对大盘的风险水平，多了20%。所以，我挣回来的，就应该比每股股票赚多一点的股票多0.2倍。这个股票的β就是1.2，而β我的那个朋友，他买的股票就是风险更高的股票，而β是1.5。

如果他买的股票相对于大盘指数，是5倍，那么，他挣回来的钱，就应该比每种股票多5倍，他理应更4、5倍才行。道理很简单，因为他承担的风险大，合理也是相应地大。

# 2.区分业绩性质

我今天讲资本资产定价模型这么复杂的财务知识，是想说明什么道理呢？我想说的，同样经营着两个业务，比如都带一个亿的资产，两家企业的经理人都挣了1000万，投资回报率是相同的。但是，我问你的，这两家企业的业绩是一样好？开年会的，你们所受到的待遇应该一样吗？

往简单了说，他们所进行的业务、要承担的风险是不同的，承担风险多那个部门、那位经理，就应该给多，风险小的那位经理挣回来的1000万就低一些，就应该至少算得出来。

我再举一个例子。北京有些地方，大机构成，不管什么银行在那里设一个支行，只需要摆二十几个人，一年的存款就能轻松完成。而同一个银行在在线性上搞一个支行，如果想实现同样的业绩指标，那个难度几乎近乎天。所以，我常常企业的领导说，我们每天开年的时候，一定要心中有个倍的概念。

不过，我所说的这个贝塔的概念不仅仅指风险的大小，我们强调通过资本资产定价模型，能够去包含经营方面的一个类似于难度系数的指标。风险构成难度系数的一个部分，但绝不仅仅限于这个。所以，我坚持认为，不同岗位的经理人员，经营的环境和背景不一样，业绩的含义就应当不同。也正因为这个原因，有的人赚1000万，就该重奖，而另外一些人，赚回1000万，可能要撤职。

也就是说，我们要透过业绩水平的绝对数量，学会判断业绩的性质。因为业绩的性质，更加决定经理未来的走向，什么业绩的性质？我举个例子来说明。2020年，又要开奥运会了。假如某国派出了男子100米决赛，你觉得那个金牌有多难？它能不能算上1千米乒乓球？我没答案，只是举个例子，引发你思考。我觉得，进行这个分析，有利于判断业绩的性质。在同一个系里，在同一个部门中，大家做的事情并不是相同的，除了那些常规性的指标，我们还要看着这些指标背后的东西。

# 3.发现卓尔不群的人才

提出VRIO模型的大管理学家巴尼曾经举了一个例子，有三家电子企业，都生产了软件，第一家企业生产了优秀的工程师，工的是A级的工程师；但是，由于管理的问题，企业B创造了B级的业绩。第二家企业，企业的工程师，业绩的是A级的；第三家企业，创造的是A级的业绩，第三家企业产生了B级工程师，生产的是B级的报酬，但企业也创造了A级的业绩。你说，哪家企业的业绩更好？毫无疑问，第一家企业的业绩更好，因为这家企业的业绩产生于期望的那种类型，业绩高出了资源所有者的期望水平。

为了把这个逻辑讲得清楚，我做一个解释。其实，在资源的企业就是一种生产资源。不同的，不同有人提供了一些不同的资源。为了盈利目的，把这些生产资源混合在一起。但是，每一个提供资源的人都会得到来自的回报要素。比如，资本提供了资本，但我们有利可图和期望，只有工资、奖金，甚至是股权激励回报要求。就像你给团队资源提供A级工程师的回报，给你B级的工资，他们天然不会来了。总之，所有提供了资源的人，只有在他们的资源得到企业之后，他们才会把自己的资源交给企业继续使用。否则，他们就会撤资或辞职。
