# 179讲：跟着电影学管理：《天才闪光》

三十九了，欢迎回到《向宁大的清华管理学课》。

今天是中国人最重要的节日，除夕。从今天开始，我们有七天的电课程。今天电影闪Flash of genes，中文名字叫《天才闪光》，也有另外一个译名，叫《灵光突发》。这部电没有那种让人头大的痛快，但这节刚好让人一边观，一边思考。

选一什样的电影，作为大三十的影片，我们想了好久。最后，我还是下了决选了这部很真故事改编的电影。为什么？原因有两个。

+   1.  第一，这是一部人生伦理片，它有助于我们思考很多人生中的基本问题。比如工作 和家庭，比如生与死的问题，究竟怎样取舍，我相信，能够给这部电影完整的观众不少，但看完这部影片，不仅你是看一个闪光的电，而是在自己的头脑中提出一连串问题的人，会多很多；而能够对自己提出问题，给予让自己满意的解答的人，就更加少。

+   2.  第二，这是一部商业伦理片，看了这部子，也许在今天可以帮到你，帮到一些与你相关的人。如你今年还在学习，迫似对自的年期的人，说明你的一个极向上的心。我真心祝福成功。不过，今天是个特日子，过年。如果在过去的一年，有一些未了的事情，你的能力这件事了。我建议你今晚了它。如果你一时还不了想，建议些思，或找一些思考？想今天能做什么，可以让大家年过得更好一点。

比如，你为甲欠乙方的钱，该到多少，给人家一些，或帮让人中今年关时。受到一些成和人如你管一家规模比较大的公司，看到今天的电，我希望你在看到强后的一天后，其实也有外的一面。总，今晚年的除夜，当举杯敬酒的时，一你手里面，应该是怀干清净的酒。

我们的课，第一周就讲到福特。你道吗？关于福特，我内心有好多，其中的一个我多自我带来的。对于管理者，特就是对自电时带的管理者，这部电影会给我们多启示。它会间地教我们，让我们知道：一个企业该怎么样样，才不会使自的年清尘土。

# 1.纬的故事

你讲个真实的故事。2014年，我知我，为一个著名的港电企业到到了正的法。当知道这件事时，他家人已经为了的取争了，间所受的屈受，如果一个无能的民，不用说，你能够体会。

我，被送到精神病里治疗了一个多月。他人在我，天黑和个真正的精神病患者在一起，日黑都有人在折。如果不家到后边的钟痛哭，不整天沉在家的种，不连家名企业的业后还有这样的当。后来，亲戚委托，我帮助张拉处。

让我万没想到，是虽然公司主管者的原性指，但负责业体理这件事的经人，公司的常年律顾问，最还和我走了私的门，我就像将电影看到的那样，在利之前，派来谈。坦的说，我当时在权利，是打官司，还是接他们的了。

电影中，福特的了金额上还是得过的，在前的位，到3000美元。但是，家前就出赔金，都折去、扣去，没有完给，更要精钱的损失。其，2万也没有少，大上是2万法。这是实到的，就为了两万的宜，那家有名公司，竟然不惜家让人受难。

不过，我了，也许我没有那的切肤痛，是希望家人尽回到常的生活軌道。当然，我实在有旧时的一一常的时间。也，我说了亲家，接了那个所赔偿家，其是我万的起赔。我能量我一地方，比如一前已到的境，这已经好了。

几天，我一家著的企业。们整个团在思考一个问题：为么，立家企业是，是？当我到表的案例，于作原因，我时会这港业公司，了妹的，每次走时，里充了轻。

# 2.发明家的故事

天的发明家和我上电故事，是一个电家和福特公司的故事多。电影的主人是卡恩斯教，一生大的发明就是我汽上使用的短型副器，灵光使用的短型，就是自灵上一的。电影的片名flash of genes，自于关于“发”的经典解辞。绝大数的发创，其实是自于天一时的闪光。
