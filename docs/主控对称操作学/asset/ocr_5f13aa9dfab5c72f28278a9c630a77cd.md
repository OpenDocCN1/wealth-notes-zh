# 自然界的對稱

只要細心觀察自然界中的各種現象，就會發現對稱無所不在，無論是浩瀚的宇宙或是微小的粒子，像是飛禽走獸、草木花卉、雪花晶體、海浪起伏、分子現象，甚至連染色體序列都是呈現對稱的結構。以人類來說，以一條經過<|start|>鼻樑到肚臍的直線當成對稱軸，不正是完美的對稱形態？
