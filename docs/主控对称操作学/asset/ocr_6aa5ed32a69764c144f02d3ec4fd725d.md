# 對稱的評估

假設股價進行有規律的運動，且處於明顯的走勢時（也就是攻擊），那麼在空間裡將會出現對稱的行為。因此，對於未來可能的走勢目標，就可以利用蹺蹺板原理進行評估。

![](bbox=[0.288, 0.317, 0.756, 0.54])

如果 K 線組合成特殊型態，比如母子、子母或島狀等等，當股價突破型態高點或低點時，就可以取高、低點或收盤價為對稱軸，利用對稱原理進行評估。以母子型態為例，請看圖 1-14，如果股價往上突破時，取高點為對稱軸計算未來可能目標；如果股價往下突破時，取低點為對稱軸計算未來可能目標，公式如下：

往上突破目標區 S=H+(H−L)=2H−L
往下突破目標區 S=L−(H−L)=2L−H
