3. 尾數 7 的年份是大好買點：通常出現在尾數 7 的下半年，或者遞延到尾數 8 的年份。

4. 尾數 0 的年份頭部出現：此為十年循環的上漲終點，通常會出現轉折，造成股價劇烈修正。

賴瑞·威廉斯建議投資人：市場似乎傾向於重複過去的變化，未來的價格型態也會遵循這種十年的指引，這種觀念將會進一步強化，投資人應該更有信心，把這種觀念當成未來歲月，甚至是未來數十年投資活動的基本方針，以此尋找最適合買賣的特定時點。

經過筆者驗證，「十年價格型態」的循環觀念輔以價格測量與浪潮推演，再搭配「同型態比較」，的確能 tackles 長線投資人以更充分的耐心等待長線型態完成，並尋找安全的進場時機。因此，筆者建議投資人，在長線操作的決策過程中，可以考慮將此觀念列入參考條件。
