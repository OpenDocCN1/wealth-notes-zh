圖 3-28 台指期貨的單根 K 線測亞（資料來源：奇狐勝券）

請看圖 3-28，操作思維如下：

+   1. 在極短線急挫過程中，出現一筆下影線很長的槌子線，這種線型通常具有轉折的內涵。

+   2. 標示 A 明顯站上槌子線高點，可以運用單根 K 線轉折計算去評估極短線上漲目標。

+   3. 測量幅度取 H～L，利用黃金比例數字 1.618、2 與 2.618 倍計算。這個評估方法建議只使用到 2.618 倍，如果要用更大的倍幅計算，宜配合其他技術面的條件。

+   4. 走勢分別在標示 B、C、D 滿足上漲目標。
