# / 第三版序 /

《道德經》說：「人法地、地法天、天法道、道法自然……」意思是說人應該效法大地無私包容；地應該效法昊天浩瀚無際；天應該效法道者萬法運行；道應該效法自然而然的規律。而「自然」就是一種宇宙萬物共生與和諧的規律，所見所得呈現的必然如此，也就是說，人類應該觀察宇宙天地萬物的運行法則，發掘和體悟蘊含其中的「自然」之道，並將其當做指導原則。

金融市場是集合眾人期望的體現，當然也包含在宇宙萬物內；反覆觀察商品走勢，就會發覺股價波動自有其規律！既然能觀察到走勢的規律變化，就可以據此擬訂買賣訊號，這些方法通稱為「技術分析」。因此，只要是符合市場規律變化的技巧，就是合理的方法。

也就是說，掌握合理的觀察方法並加以運用，就是道法自然的最佳呈現。《主控對稱操作學》所探討的技巧，能吻合「自然」的規律，因此只要能善用書中描述的判斷法則，再加上耐心的等待，便可以在恰當的時機進行操作。
