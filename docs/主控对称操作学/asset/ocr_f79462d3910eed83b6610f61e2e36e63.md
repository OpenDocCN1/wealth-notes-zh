# 時間的對稱

討論空間對稱時，由於呈現的形象是具體的，我們比較容易理解；但是，討論時間的對稱時，因為時間既看不見也摸不著，反而不容易被理解。如果不是藉由分、時的定位，人類對時間長短的感覺恐怕也會因人而異。

根據我們目前的認知，時間被當成無限延伸的一條直線。因此，當時間被定義為線性座標時，就可以產生對稱效果，在文字上可以表述為早晚、日夜、生死、進退、往復、先後、遲速等等；至於物理學所認為的時間對稱，是指過去與未來無法區分。然而，時間的對稱通常不會單獨存在，而是與空間對稱產生關聯。

比如，在不考慮摩擦力與空氣阻力的背景中，當物體沿著光滑的斜面上下運動，其單位時間應該相等，這是時間的對稱；所以，垂直拋體與斜向拋體，在上升與下降的時間也呈現對稱。這些物體運動所表現的對稱不佃與時間有關，也與空間有關，已經超出幾何對稱的範疇。

因此，當我們將時間對稱運用在股市波動的觀察時，必須注意到：一者是時間的單位必須固定；另一者是時間的不可逆性，將造成某事件的獨立性。至於運用的方法，將在第五章討論。
