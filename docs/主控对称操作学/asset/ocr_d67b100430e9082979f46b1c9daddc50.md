# 中軸的移動

操作者認知的對稱軸（即平衡中軸）並不一定是未來走勢中所真實呈現的，只能算是自己的主觀認定。有時候，走勢可能不符操作者的預期而表現為弱勢，那麼停損機制將會啟動，協助規避風險。走勢也有可能超乎預期而表現為強勢，那 dem 表示股價走勢所反映的並不是原本主觀所認定的對稱軸。這時候，操作者就需要移動平衡中軸，進行下一波走勢的觀察。

請看圖 6-9，在標示 C 的位置，代表以標示 P 為對稱軸進行鏡射的對稱後，所完成的相對高點，也就是標示 C 對應到標示 L。當實際走勢已經完成原本評估的目標，或者初始型態被完全複製結束後，就需要移動觀察的平衡中軸。上述原則只是眾多移動中軸的方法之一，也是最簡易並容易操作
