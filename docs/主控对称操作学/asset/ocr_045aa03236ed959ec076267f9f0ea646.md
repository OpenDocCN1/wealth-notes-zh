# 單根 K 線的對稱

股價走勢波動過程中，必然出現許多高低轉折，轉折間則由大小幅度不同的 K 線所串連。如果轉折當筆與行進間的 K 線，有相對較大的高低震幅，且具有表態意義的內涵，那麼這些 K 線在短線上也可以進行測量，同時根據測量幅度的多寡，分別代表不同的意義。
