# 形態的對稱

價格的對稱在金融走勢圖的表現上無處不在，最常被使用的是等距離的「價格對稱」，屬於翹翹板原理；至於「黃金螺旋」、「衝擊螺旋」，則是從翹翹板原理變化出的不完美對稱。這些目標的計算，不但可以運用在單根 K 線與組合 K 線，對於型態學的所有型態，也能一體適用。本章除了介紹型態的對稱，也對虛擬對稱與同型態對稱做基本的說明。

## 型態的對稱

在型態學中，評估目標的最基本的方法是使用價格對稱，又稱為「型態對稱」。除此之外，無論是頭底轉折，或行進間的整理型態，在調整過程中必然會產生與趨勢前進方向相反的走勢，因此也可以利用反向力道，進行「衝擊螺旋」的測量，而相同方向則利用「價格對稱」與「黃金螺旋」進行目標評估。

## 型態的運用

圖 4-1 所示為 V 形反轉型態，屬於單腳或是單頭反轉，是多空力道互換最強的轉折型態之一。既然該型態要在走勢圖上呈現直接多空互換的氣勢，就必須將原始走勢破壞殆盡。以原始走勢是多方者為例，不考慮發生型態時的相對位

置，從標示 H 轉折向下跌到標示 L 的正反轉點附近時，呈現上漲走勢與下跌走勢相等，多空力道勢均力敵；這就如同兩軍作戰，空頭部隊只不過將多頭占領的區域搶回。

![](img/3c84e6cd103643aff54a814e5a9d9319_102_0.png)

圖 4-1 V形反轉的型態對稱。

直到空頭軍隊打破多方的防守陣地（即標示 L 的正反轉點），並且將多頭軍隊原本攻占的領土，從標示 L 的正反轉點處，再吃掉相等的距離，以拉開空頭軍隊可以抵禦多頭軍隊的防守領域，如此才能算是空頭軍隊的勝利。也就是說，空軍必須以原始上漲的力道（即 H－L）為測幅，從標示 L 等幅下跌，才能够將多頭力道破壞殆盡；也唯有如此，才表示空頭力道有正常程度的發揮。

這種多空對峙的概念，運用在價格上的計算，就是型態對稱的基本邏輯思維。

![](img/3c84e6cd103643aff54a814e5a9d9319_103_0.png)

圖 4-2 雙重頂與雙重底的型態對稱。

圖 4-2 為雙重頂與雙重底的型態示意圖。這種型態對稱，頭部是取 H1～L0 為測幅，底部是取 H0～L1 為測幅，也就是從頸線往下或往上計算等距離的幅度，做為型態完成的基本滿足點。如此計算的理由是：股價在多頭走勢時，標示 H1 的高點無法大於 H0 的高點便形成轉折向下，暗示多頭走勢可能已經走弱。在走勢跌破標示 L0 的頸線後，短期空頭趨勢便已經形成。

但空頭如何讓多頭知道空方力道已經轉強？自然是將多頭最後的上漲力道完全破壞殆盡做為表態，所以必須計算從頸線向下的等距離幅度。底部完成後的計算思維，同理可證，不再贅述。

計算時，如果頭部取 H0～L0 為測幅，底部取 H0～L0 為測幅，則是認定股價已經開始進行完成轉折方向的攻堅走勢，除了可以用對稱計算，也可以套用「黃金螺旋」的計算。

另外，我們可以根據走勢是否滿足基本幅度，定位原始趨勢的力道強弱；例如，滿足時應如何行動？不滿足時又該怎麼辦？操作者應同時思考當時多空分野的位階。因此，不可忽視幅度的計算，並且必須分辨走勢滿足與否所透露的含義。

所有定義型態幅度的計算原則，都是根據型態的「對稱理論」歸納而來，同時也是走勢過程中「理想狀況」的呈現。進入市場實際操作時，經常因為研判錯誤、定位偏差，或時空背景等等因素，導致實際走勢與預期的走勢不一致。比如，上漲時所計算的幅度並未滿足，股價便產生轉折向下；或上漲走勢比預期強勁，顯著超過規劃的幅度，偏偏手中持股早已經出脫，喪失了後面一段利潤。

這些對稱的不完美必然存在於現實中，所以操作者無法避免，只能以「操作策略」做彌補。簡單地說，構成投資人所推論的方向與漲跌輪廓的，是他們所學的技術分析，這是「戰術」的層面；而配合技術分析的概念所孕育出來的操作策略，諸如停損、停利的運用，以及資金比例控管等等，則是「戰略」的部分。

所以，操作時不能只依賴戰術勇往直前，仍需戰略防身，將損失極小化，讓利潤極大化；甚至在運用戰術時，只要嗅到一點風險，就應趕緊利用戰略先行退出，以保全自己軍隊的糧草。

接著，本單元將以雙重底型態，描述戰術與戰略的整合運用。雖然這些都是基本的運用道理，不過讀者可以據此舉一反三，達成操作順遂的境界。

## 行進間走勢的評估

請看圖 4-8，當走勢圖在相對低檔，呈現標示 L2 的低點高於標示 L1 的低點時，暗示走勢可能盤出第二隻腳（L2）。當走勢突破經過標示 H 的下降趨勢線，領先操作者可以考慮介入佈局，亦即主觀地認定標示 L2 屬於第二隻腳，同時規劃出可能的走勢方向與上漲目標。截至目前為止，這都是戰術的運用，至於介入多少資金比例，則為戰略的運用範疇。

![](img/3c84e6cd103643aff54a814e5a9d9319_107_0.png)

圖 4-8 假設會成立第二隻腳

然而，實際走勢是否如規劃般前進？這一切在還沒有完成以前，都是未定之數，因此在佈局介入時，應同時顧及以下的戰略思維：

- 1. 如果走勢沒有突破標示 H 的頸線，暗示多頭的上攻走勢失敗；那麼，應該將觀察點定位在何處，才能決定底部可能失敗的型態，並且讓已經進場的資金安全退出？
- 2. 如果走勢突破標示 H 的頸線，是不是真的完成底部？操作者應該以「真假突破」的研判法則決定觀察點，以避免走勢尚未完成價格對稱而呈現假突破訊號。
- 3. 如果走勢如預期上攻，在還沒有達到評估的目標時，應該如何控制行進間的風險？
- 4. 當走勢真的如預期穿越評估的目標後，應直接賣出持股，或等待下次可能出現的漲勢？又該以哪種方法觀察較為恰當？

從以上的論述中，不難看出在戰術中有戰略，在戰略中也有戰術，環環相扣，才能造就恰當的操作邏輯。

![](img/3c84e6cd103643aff54a814e5a9d9319_108_0.png)

請看圖 4-9，假如領先操作者在主觀認定第二隻腳成立時介入操作多單，並同時設下停損觀察點以保證進場的多單；當走勢不如預期時，必然會觸發停損機制，此時便可以讓進場的多單先行退出。觀察點的設置與每位操作者的認知成正相關，而操作者的認知是否恰當，又與所學的技術分析成正相關。無論如何設定屬於自己的觀察點，一旦被觸及，就必須確實執行既定的操作策略，以規避底部失敗的風險。至於後續走勢如何變化，不在執行停損時的考慮範圍之內，絕對不能心存僥倖地假設價格還有繼續上漲的機會。

操作者在領先介入後，最常見的缺點是過度期待與樂觀，即使出現底部失敗的訊號，仍然不斷說服自己相信倒楣的事情不會發生在自己身上，或嘗試為已經失敗的走勢辯解：「以前曾經出現這樣的訊號，之後股價仍然持續上漲，所以這一次應該也會如此。」操作者沒有察覺的是，上次的操作經驗其實是一種錯誤認知，只是當時運氣好，讓錯誤的決策成為成功的經驗。

如果在類似的操作過程中，經常發生價格觸及停損觀察點後，卻仍然往原先假設的方向前進，那就意味著操作者設定觀察點的方式需要改進、調整，甚至應該重新學習技術分析，揚棄舊有的觀念。

在圖 4-10 中，若標示 L2 的正反轉點促使股價上漲超過標示 H 的頸線，表示底部已經成立，但必須等到基本幅度滿足後，才算完成整個型態。一般操作者都會將走勢穿越頸線設定為安全的買進點，只要維持「真突破」訊號，就應當認定底部型態不會被破壞。在真突破訊號出現後，並且未滿足評估的目標之前，都可以尋找恰當的點位進場。不過，越靠近滿足區，買進的風險越高，所獲取的利潤越少，但走勢方向卻相對明確。

走勢往假設的目標區前進的過程中，並沒有人可以保證非到達目的地不可，走勢可能在中途夭折，所以此時需要利用「移動式停利法則」，協助操作者規避風險。
