# 隨機與相似性

有人說：「任何股價走勢的波動都是隨機的。」換句話說，未來的走勢根本無法預測。如果這種說法是真的，那麼我們都不必研究技術分析或基本分析了；以此論調推想，一家公司的營收與成長不也是隨機的嗎？產品在市場上是否能夠受到消費者青睞，銷售量是否能夠如預期成長，有誰可以百分之百斷定？

筆者主觀地認為：有些隨機現象是可以被觀察的，並且可以依據已經完成的現象來判斷，以合理的角度進行推論與評估（或者預測）未來可能的結果。就像池塘的水面被激起了漣漪，我們無法得知是誰扔下那顆小石塊，但既然事實已經發生，我們可以根據漣漪的形狀、大小，評估波動方向。

即使又有人往池塘丟進一顆小石塊，我們依然無法事先得知哪一個頑皮的人做了這件事，但事實是，池塘又呈現了另一個新的漣漪。縱使新的漣漪會影響前一個漣漪的行進與波動，導致池塘的波紋互相干擾而顯得更複雜，但水面的波動行為依然是可以被評估的。經驗豐富或經過訓練的人，仍然可以從錯綜複雜的波紋中找出徵兆，然後再據以研判。
