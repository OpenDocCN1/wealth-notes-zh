# 對稱原理

從幾何圖形的角度探討對稱原理，我們可以將對稱區分為：點對稱與線對稱。

點對稱的特徵是，對稱點和對稱點之間的連線會被對稱中心平分。

請看圖 1-1，標示 O 的位置稱為對稱中心，如果點 A 想要在平面上呈現一個對稱點，則應該在 A～O 的延伸線上，找到異於點 A 的另一個點 B，並使 A、O、B 三點共線，而且 A 到 O 與 O 到 B 的距離相等，此時 A 是 B 的對稱點，反之 B 也是 A 的對稱點。同理可證，點 C 與點 D 亦互為對稱點。

點對稱有另一項特點，就是將原圖形以順時針或逆時針旋轉 180 度後，依然能夠與原來的圖形完全重疊。中國的太極圖便是將點對稱旋轉的代表圖形，如圖 1-2 所示。
