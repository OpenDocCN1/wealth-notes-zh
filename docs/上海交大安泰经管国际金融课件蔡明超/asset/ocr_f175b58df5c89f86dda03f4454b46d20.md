# 用Matlab模拟技术分析的投资收益：数据回测

```
a=xlsread('08Euro MOnthly Average Price.xls');
l=length(a);
buy=[];
sell=[];
ReturnRate=[];
date=1;
i=6;
while (i<=l)
    if a(i)>a(i-5)
        buy(date)=a(i);
        i=i+1;
        disp(buy);
        % pause;
        while i<=l & a(i)>=a(i-5)
            i=i+1;
        end
        sell(date)=a(i); % sell在1.0322处循环
        date=date+1;
    end
    i=i+1;
end

ReturnRate=sell./buy;
Length=length(ReturnRate);
accum=1;
for i=1:Length
    accum=accum*ReturnRate(i);
end
disp('Passive Return');
disp(a(1)/a(1));
disp('Active Return by Momentum');
disp(accum);
```

收盘高于5月前价格，
为买入信号
结果表明:买入并持有收益率13%,趋势投资50%
