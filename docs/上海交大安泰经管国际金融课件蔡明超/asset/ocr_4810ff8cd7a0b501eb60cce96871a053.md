# 报价换算例： 交叉汇率(cross rate)交叉相除

| 币种 | 汇买价 | 汇卖价 |  |  | 昨收 |
|---|---|---|---|---|---|
| 美元/日元 | 118.16 | 118.56 |  |  | 118.87 |
| 欧元/美元 | 1.1279 | 1.1312 |  |  | 1.1202 |
| 欧元/日元 | 133.3 | 134.1 |  |  | 133.17 |

如果中国银行即期汇率报价为 USD/JPY 118.16/56 USD/EUR 0.8840/66

求：该银行的交叉汇率EUR/JPY双向报价？

解：可以用“交叉相除”的方法得出EUR/JPY汇率双向报价

EUR/JPY即期汇率买价为118.16÷0.8866；卖价为 118.56÷0.8840

按惯例写出报价即为 133.27/12
