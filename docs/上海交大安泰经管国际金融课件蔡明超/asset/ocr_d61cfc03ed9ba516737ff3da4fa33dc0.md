# 企业外汇风险分类

+   - 交易风险：未来的各种外汇债权、债务受汇率影响（资产负债表）
+   - 经营风险,也叫经济风险,汇率变化对(1)企业销售收入(2)企业融资活动等影响。(损益表，现金流量表)
+   - 折算风险,也叫会计风险,汇率对跨国公司合并报表产生的影响.
+   - 例：简化的资产负债表与损益表
