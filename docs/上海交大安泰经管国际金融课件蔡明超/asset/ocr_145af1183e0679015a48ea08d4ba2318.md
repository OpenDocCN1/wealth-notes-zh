# 盯住与94-95墨西哥金融危机

+   - 1995前墨西哥比索盯住美元。
+   - 90年代初，墨西哥加入北美自由贸易区NAFTA，资金大量流入墨西哥，短期资本流入推动比索大大升值。
+   - 但墨西哥通货膨胀率高于美国，1994年墨西哥外贸赤字高企。
+   - 1994 发生了两起政治谋杀，一起政治暴动。短期资金迅速撤离
+   - 94/12/19日，上台不到20天的塞迪略政府为缓解当时外资大量抽逃对墨西哥货币新比索形成的压力，宣布新比索贬值15%。市场即刻出现抢购美元的风潮，新比索币值急速下滑。政府采取紧急措施进行干预，但仍遏制不住下滑势头。维持盯住的外汇储备已经不够
+   - 万般无奈，政府于12月21日午夜被迫允许新比索与美元的汇率自由浮动，比索由3.74兑1美元跌至 5.9兑1美元。
