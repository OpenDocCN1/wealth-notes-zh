# Currency Put Options
看跌期权基本概念

+   - A *currency put option* grants the holder the right to sell a specific currency at a specific price within a specific period of time. 持有⼈⼀般预测市场跌
+   - A put option is
+     - *in the money* if spot rate < strike price,
+     - *at the money* if spot rate = strike price,
+     - *out of the money* if spot rate > strike price.
