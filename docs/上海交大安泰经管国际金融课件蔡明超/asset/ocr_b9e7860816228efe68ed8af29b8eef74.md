# 争议货币：Bitcoin

2009-1-3
中本聪在位于芬兰赫尔辛基的一个小型服务器上挖出了第一批50个比特币

2010-5-21
一位程序员用1万个比特币购买了价值25美元的披萨。这项交易诞生了比特币第一个公认汇率

2010-11-6
Mt. Gox上的价格达到0.5美元，此时比特币经济达100万美元

2011-2-9
比特币价格首次达1美元，比特币与英镑、巴西币、波兰的兹罗交易平台先后开张

2012-12-6
世界首家官方认可的比特币交易所——去国比特

+   - 交换媒介、价值尺度、支付手段、价值储藏
+   - 许多国家拒绝承认
