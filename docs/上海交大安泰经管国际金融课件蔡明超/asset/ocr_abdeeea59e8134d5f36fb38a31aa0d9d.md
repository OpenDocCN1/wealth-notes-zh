# 基本面分析的多因素回归方法

+   理论： quantity theory of money
+   
+   Pₛ = Mₛ Vₛ / yₛ
+   Pₑ = Mₑ Vₑ / yₑ
+   S = (Mₛ/Mₑ)(Vₛ/Vₑ)(yₑ/yₛ)

+   对上式取对数，并构建多元线性方程得

+   s = α + β₁(m - m*) + β₂(v - v*) + β₃(y* - y) + u

+   s = Ln(S), S为$/£, *表示英国数据

+   系数由历史数据估计，根据最新自变量预计未来s。斜率β₁是自变量变化引起的汇率变化幅度，ds/d(m - m*) = dln(S)/d(M/M), 注意dln(S) = dS/S
