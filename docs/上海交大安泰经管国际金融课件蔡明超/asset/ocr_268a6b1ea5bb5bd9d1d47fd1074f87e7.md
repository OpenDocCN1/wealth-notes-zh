# Plain Vanilla Swap: Pricing

一般结论：

+   - The fixed periodic-rate on an N-period swap at initiation (as a percentage of the principal value) can be calculated as:
+     F = [ 1 - Z_T / (Z_1 + Z_2 +...+ Z_T) ]
+     Where Z_t is the present value of $1 to be received on the t^th payment date, of T dates.

+   - 采用相同原理，根据中长期Libor 报价可以得到2年，3年，5年，10年。。美元互换利率

+   - 采用相同原理，根据中长期Libor 报价可以得到2年，3年，5年，10年。。。其它欧洲货币互换利率的报价，即固定利率支付水平
