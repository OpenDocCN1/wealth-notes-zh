# 换算风险简析

+   - 假设某私人公司年初有16亿人民币自有现金，其中6亿按当时汇率变成1亿澳元汇入澳大利亚，成立1亿的子公司。
+   - 全年没有经营活动，但澳元从6变成5。
+   - 按现行汇率法核算的报表，公司没有亏损，因为该方法轧平项在资产负债表
