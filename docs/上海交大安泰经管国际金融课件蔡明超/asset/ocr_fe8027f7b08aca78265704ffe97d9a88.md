# 外汇市场收益与风险：对冲者与投机者的效用函数

![](bbox=[0.043, 0.174, 0.908, 0.359])

+   - 居民效用函数 U=E(r)-1/2*Gama*Var，Gama>0 为 **Hedger**，Gama<0 为 **Speculator**。E（r）、Var 分别是预期收益与风险
+   - Assume RMB/$ goes up 1% at the probability=0.5, down 1% at the other probability. 【收益与风险估计的情景分析法】
+     - Expected return=0, Var=1/2*(1%-0)^2+1/2*(-1%-0)^2=1(%^2)
+   - Suppose Mr. A is a hedger (Gama>0), his utility function U=E(r)-1/2*Gama*Var=1/2*Gama(%^2)
+     - U<0 if he participates in FX market
+   - But if Mr. A is going to travel in the USA, he will pay 1% more if $ goes up, and vise versa. So for Mr. B:
+     - if he buys $, E(r)=0, Var=0, his utility =0
+     - If he doesn’t, E(r)=0, Var=1(%^2), his utility <0 when Gama>0
