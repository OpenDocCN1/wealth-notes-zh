# 期权组合策略

+   - *Straddle*（跨式期权）： One strategy for volatile currencies is to purchase both a put option and a call option at the same exercise price（未来大幅波动，即有可能大涨幅或者大跌，则同时买看涨、看跌肯定赚钱）

+   - By purchasing both options, the speculator may gain if the currency moves substantially in either direction, or if it moves in one direction followed by the other.
