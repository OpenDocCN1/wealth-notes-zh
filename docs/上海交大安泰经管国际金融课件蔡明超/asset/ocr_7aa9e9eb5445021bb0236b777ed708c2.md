We follow the following protocol: for every dataset, we build a supervised baseline with a diverse set of features akin to prior work (Yan et al., 2020). We additionally benchmark vanilla baselines, architectural ablations, and stylised model variants for every dataset. The protocol is devised to keep compute budgets and selects a simple approach, and an equally strong Deep Neural Network (DNN) model.

For the DNN model, we use a RoBERTa-based cross-encoder for text inputs (Devlin et al., 2019) and a ResNet-50 cross-encoder for visual inputs (He et al., 2016). We also train a late-fusion variant with both models concatenated via a two-layer MLP, which fuses their output features.
