# 利率平价公式与我国的远期结售汇制度

+   - 中行的远期报价由总行采用利率平价公式全行统一。
+   - 美元利率每天以路透公布的LIBOR基础利率减去1/16（可调）个基本点计算，
+   - 人民币利率综合采用全国银行间同业拆借中心同业拆借市场(SHIBOR)利率、人民币存款利率、中央银行再贴现利率和再贷款利率等多项指标通过一定加权计算而成
