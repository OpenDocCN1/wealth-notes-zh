# Foreign Exchange Transactions
外汇交易的特点与分类

+   ◆ 特点
+     ◆ There is no specific building or location where traders exchange currencies 无集中场所.
+     ◆ Quoted by market maker 做市商制度

+   ◆ 分类I
+     ● Spot 即期（现货）
+     ● Forward 远期（现在约定价格、将来交割）

+   ○ 分类II：实盘交易与保证金交易
+     ● 远期一般采用保证金或杠杆交易，很多经纪公司也推出了现货的保证金交易
