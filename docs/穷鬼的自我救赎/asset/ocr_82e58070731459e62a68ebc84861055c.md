# 二、偷梁换柱思维

偷梁换柱，指用偷换的办法，暗中改换事物的本质和内容，以达蒙混欺骗的目的。“偷天换日”、“偷龙换凤”、“调包计”，都是同样的意思。在军事上，联合对敌作战时，反复变动敌军阵线，借以调换其兵力，等待敌军一败涂地、有机可乘之时，将其全部控制。
