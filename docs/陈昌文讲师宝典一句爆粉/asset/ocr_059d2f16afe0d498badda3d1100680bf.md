# 1、一切都是模板化、流程化、标准化

想要做好社群，一定要有直播、视频榜样老师。这样的人必须有道德，也就是知道什么是为社群发展做贡献。这样的人必须有业务能力，必须能出单，能做品牌营销。这样的人必须智慧、聪明，知道什么该说，什么不该说。找到榜样，然后让所有人向这样的老师学习，则所有人都会做了，利润自然就起来了。

做社群，就是抓榜样，做营销，做团队。做管理层，也是抓榜样，有这样一个好的榜样，所有人都有样学样。没有榜样，大家不知道跟谁学，问题就会层出不穷。

让所有人都按照一种模式直播，让所有人都按照一种善良的风气做视频，这个生意就做起来了。也就是视频、直播、讲话内容、发心、做事，都是有模板的。没有模板，所有人不知道该如何做。打造好了模板，让所有人跟着模板学习，则一
