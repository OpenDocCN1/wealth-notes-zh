# 做一个真人

我再讲最后一个道，这个道叫做真。你们看电视剧，看小说，这个道家的人物里面有一个叫什么，张真人。

道家人物，得道了，就叫真人。全真教，就是都是真的，不跟你来虚的。你们很早的时候就都知道全真教，你们不知道什么意思，对不对？我一句话给你们解释，全都是真的，咱不玩虚的，这个就是道。真了就是道，真说真干。

对于任何人只讲真话，因为讲假话成本大，一个假话后面要接一个假话，还要接一个假话，最后假话破裂，会很大的代价，这个叫真话。

对任何人要讲真话，不要忽悠人。佛经当中有这样一句话，言出法随。在道教当中也有这样一句话，嘴巴里说出来，就是法。
