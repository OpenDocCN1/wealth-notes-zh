# 陈昌文：

社群里面有严重的错误，必须一个个的改回来，全面正能量，全面讲道德素质。所有老师注意，所有讲师团的人彻底注意这个问题，不要污名化、流氓化，伤风败俗，还有被国家搞净网行动的风险，不准讲pua，不准用下流词汇。

社群讲师很辛苦，特别辛苦，所有人都知道，我还天天批评。但我不得不批评，不能所有人都做好人。请所有人，所有讲师理解。每个人，都需要一个敬畏的人，需要一个不断批评您、挑刺的人。你们不愿意做这个挑刺、批评人的人，好，我来做吧。虽然我知道很多人不爽，不过，我就是要做这个，我不得不做。我慢慢理解了地藏王菩萨了。我得支持所有人赚钱，得真正的帮助大家走正道。我得罪你们，也得得罪你们，没办法。
