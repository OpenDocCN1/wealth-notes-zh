# 4、利用好书籍这个流量系统、传播系统

书籍就是一个流量系统、一个传播系统，一个为了卖社群，卖代理，卖读书会的更好的传播系统。也就是，社群出书的目的，就是让大家拿去搞流量，变现而已。拿着我们的书籍不断的营销，能影响太多的人。

要利用好书籍这个流量系统、传播系统，大家就要认真读我的书，而且要精通，按照书本上的内容去讲解，不要出错，不要低俗化讲解，用词全部正能量，符合儒家思想、陈昌文方法，这是我们每个人、每个老师都必须重视的。自己直播的时候，要把书拿着，让对方看到。要录制屏幕，对自己的销售话术、语言系统进行研发。也就说，每天都有进步才是对的。然后做读书会，做陈昌文老板社群，搞品牌营销，这个模式会非常厉害。竭尽全力的帮助大家赚钱，提升道德素质，大家按照书籍去讲，就会非常厉害。
