# 2、想做好营销，首先要理解营销的逻辑

营销直接模仿行业标杆，看看其话术逻辑、语言逻辑、故事目的。他讲的每一句话、每一个故事、每一个段子，都会引导到书籍上，引导到书籍的理论上。他讲话的目的是让你们买书，是让你们去到这本书上去看。他的话语、故事，包括自己亲身经历的故事，也是让大家去买书，他是为了营销他的书籍。这才是我们所有人要学会的。
