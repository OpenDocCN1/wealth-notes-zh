# 1、照本宣科，就是简单化，
一切爆粉形式必须简单化

我讲过复制营销系统爆粉，也就是一切爆粉的文安、直播的内容，都是复制来的，复制着讲就行。这样不用动脑，还有效果。只是有一个版权问题要注意，但是都复制我们社群内部的东西，则不存在版权问题。

而我们的书籍就可以照本宣科的讲，也可以发散到你的故事里，根据自己的直播情况、视频情况，自己去琢磨，去改编、优化。

不要瞧不起照本宣科，不要觉得非要脱稿演讲。这是框架，拿掉。你可以拿本书，还演绎得很好，很神秘，这仅仅是个表现形式而已，你同样可以演绎得很有神韵。
