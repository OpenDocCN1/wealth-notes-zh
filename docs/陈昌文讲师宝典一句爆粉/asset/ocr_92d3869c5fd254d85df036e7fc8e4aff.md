# ●人生的一个重要课题就是要隔离坏人

今天晚上我主要给大家讲一些道的东西，这个道是怎么牵引我们去赚钱的？还有就是我是怎么样去驾驭社群的？

我们社群也不小，读书会有一万人，我们陈昌文老板社群差不多也有一万人。只是你们看到我有一个3000人的这个群，其实我做了很多个群，那么这个团队是怎么样去驾驭的？

首先呢，我的道场不要垃圾人，我希望你们也做到，你们的道场也不要垃圾人。我其实蛮温柔的，但是我觉得错了，我想你们的人生当中也因为你们的软弱和温柔，让那些坏人伤害了你们，是不是？你们的人生当中也因为你们的软弱和纵容，导致那些坏人去伤害你们。

比如说有人找你们借钱啦，比如说你的对象伤害你啦，比如说你管理团队这些人他不听话，错的他还去做。这些人都要把他踢了。有人骗你，我们都把他踢了。
