# 16、分享和传播，让粉丝疯狂裂变

还记得我在一个电视节目里看到一个广告，说的就是越分享越快乐，越分享越拥有。如今我们做互联网，做社群，我又记起了这个广告。

每一个人，都必须是一个传播者、一个分享者。这个观点、这个书籍、这里面的概念，没必要是你的，你就是不断的传播、分享、收单子就行了。做好一个传播者，做好一个分享者，每个人每天的时间都去分享，都去传播，自然有人买单。

每天早上 5 点起床，做好基本的准备工作，就录制视频号，一个上午录制几十个视频，然后传播到抖音号上去。每个人玩十个账号。然后下午到晚上，就可以直播分享了。

做好一个分享者、一个传播者。你总是在想，我要分享一句话、一个观点、一个概念，对大家有用。不断的在我的书籍里找精华去分享，你的粉丝就多了。分享多了，流量就大了，做直播就自动成交了。这就是卖读书会，卖陈吕文老板社群的
