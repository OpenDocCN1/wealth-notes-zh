# 1、我到现在还没有吃早饭，因为我在收单子

学员：

老大，实话实说，我最近有负面情绪，我得先把负面情绪给调整过来。我也不怕您骂我，我倒希望您骂我，让我清醒！

陈昌文：

我到现在还没有吃早饭，因为我在收单子，您说我有负面情绪吗？成年人，就是疯狂的去拼命赚钱，当您有负面情绪的时候，跟您一起的那些兄弟，比如刘兄弟，别人已经开始第二春了。比如群里其他一些有几十万粉丝的人，别人又开始不断的收单子了。别人在疯狂的直播，做账号，收单子，在搞进账，您说您的负面情绪有价值吗？如果负面情绪有价值，能赚钱，我建议您长期拥有。如果负面情绪不能让您获利，不能长期赚钱，不能让您每天有几万收入，我建议您别拥有负面情绪了。

成年人的世界，都是忙忙碌碌的，都是拼命的搞流量，做变现，永远都在拼命，而且是斗志昂扬。真的，我们所剩下的时间不多了，加油吧。
