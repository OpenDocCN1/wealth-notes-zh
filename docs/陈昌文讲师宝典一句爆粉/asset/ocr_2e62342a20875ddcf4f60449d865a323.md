# 7、书籍营销的目的，

让每一个跟着我们的人都有收入

我们做书籍营销系统的目的，是让每一个跟着我们社群的人，他们想做事，都有收入。保证参与进来的人，随随便便都有日收入。稍微努力一点，就能赚钱。这就是我们彻底的追求，这也是我们社群管理层想要做到的事情，目的就是为大家的经济收入做考虑。

书籍营销有多重要？是最厉害的一环。人拿到书籍了，就成为我们的铁粉，而且可以照著书籍教学。这个读书会，会疯狂的提升你的精准粉丝，以及影响力。而且这个书到了学员手里，他们就会真正知道我们社群的干货、威力。也就是我本人亲自在帮你们做营销了，我的力量用上了，结合你的直播、视频力量，你的收入就会迅速往上爬。这就是读书会营销的威力。陈昌文读书会，就是一个非常厉害的品牌营销模式。
