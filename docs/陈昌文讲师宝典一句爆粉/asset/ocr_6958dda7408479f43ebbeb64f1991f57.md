# 8、如何才能让大家多赚钱

绝对专注读书会的发展, 绝对专注一个项目、一个社群营销,就会非常厉害了。做好一件事, 其他事情别弄, 这样就会非常厉害。做好一个小公司、一个小项目。只有一个卖点, 就是读书会, 就是一本书, 就是陈昌文老板社群。日日循环痛点营销,这样利润就会越来越好。循环我讲过的《恋爱宝典》精讲, 天天复制营销就行了。不断的复制, 不断的收单子就行了。

我写了这些书籍, 算是用了6年时间写出来的。这些书籍,就是互联网营销教程, 当老板教程、恋爱教程、主播教程, 视频、直播教程。按照教程做视频、直播, 收单子就行了。我们围绕着书籍循环就行了, 其他的不用循环。所有老师、主播, 全部围绕我们的一本书日日循环。围绕《恋爱宝典》循环, 你会变成神的, 前提是, 循环一辈子。
