# 18、我终于知道为什么有的人能日出一百多单了

**学员：**

不实践是真的无法领悟啊，我终于知道为什么有的人能日出一百多单了，真的是要躬行。您天天老生常谈的东西，说的耳朵里起茧子了，但是领悟不了，就是实践太少。量大出奇迹，您讲的这句话，适用于任何的学习，更适用于直播，这是无上门。感恩老大，感恩您。真理就是老生常谈的东西，不懂的人一辈子都不懂，懂了过后就偷偷的很开心，哈哈哈……

**陈昌文：**

要实践，琢磨，才能体会，才能真正学会。对学习，要有恭敬心，千万别傲慢，以为自己懂了。我们社群里有大量的人，其实啥也不懂，根本理解不了什么是品牌营销、链接式营销。我讲的那些课，他们只是以为自己懂了而已，根本没有扎进去学习过，更没有实践过，只是听到耳朵里，就开始生起傲慢心了。
