# 5、如何简单的提升收入

如何简单的提升收入？

1、做讲书人。

2、围绕书籍讲一个主题，就讲营销，成为营销大师，或者就讲恋爱，成为恋爱大师。永远锁定一个卖点，围绕书籍，围绕一个主题，这样，读书会就卖出去了，赠送模式就卖出去了。讲书人账号，讲一个主题，日日循环这个主题，采取这个模式，全部是垂直的。

3、利用书籍爆粉+专业的内容，这样持续循环。一个视频爆粉，一个直播爆了，就会直接带来大量的读书会销量。这才是最好的变现模式。爆破一点就行了。爆破读书会就行了。

4、用读书会、陈昌文老板社群变现。

5、把其他讲师都推起来。社群里有很多优秀的老师，把这些老师的长处吸收过来，整合出自己的风格。这样，就会变得更强大。谁强大，我们吸收谁的长处，然后整合进读书会、讲书人这个模式里去。
