# 12、多听听现在群里的课程，比以前的牛 B 多了

学员：

我是最早进入这个老板社群的，那个时候收费是 6 千多还是八千多都忘了。那是我第一次在自己身上投资最贵的学费。当时跟着老师还做了一年项目，最后自己没有搞起来。我就怀学生孩子了。现在我又开始学习文案，当时听了你的课就觉得文案太重要了，所以一直想把学文案的技能学会。我又拜了一个老师学文案。现在在一个线上的短视频团队做文案导师。在这期间我也报了很多课程，但是都离不开陈老师教的心法。想干什么之前先把同行都找出来，然后再把东西变成自己的。之前我没有能力去把别人的东西转化成自己的。但是我现在终于有了这项技能，也会拆解各类视频和文案。虽然做的不是暴利项目，但是踏踏实实的做还是越来越有收获的。感谢陈昌文老师。
