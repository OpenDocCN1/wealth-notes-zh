# 41、您想怎么弄，就怎么弄

学员：

老师，我是半年前加入社群的一名定驻在海外的，通过**
加入的学生。是这样的，通过在我们老板社群才半年多的学习，
已经在各方面，不管是家族事业，还是我个人事业上的收入、
生活，都发生了翻倍的改变。

最近像退休了似的。我感到很幸运，才20多岁就实现了我
想要的生活方式和生活状态。在这个社会虽然我很渺小，但是
我最近很闲。成长过程中我感觉自己越来越要有一个社会责任，
不是非要有收入才想投资什么做什么，而是最近感觉总想为这
个社会做点什么。然后我想了想，网络时代，国际上中国也在
崛起，国内的抖音啊什么的由于国际IP阻断，不能通过网络输
出价值，所以我在国外创建了自己的YOUTUBE账户，想让更
多进不去中国国内网络、居住在海外的华侨以及懂中文的人，
和外国人，认识我们社群的文化。想让更多外国人知道我们中
国国内有这么一个老板社群。

我并不是以招讲师为目的获取利益，也不想去读书会获取
薄利什么的，只是想时空时间，单纯的想为您做什么，想
为了这个社群做点什么，想为社会需要帮助的人做点什么。这
