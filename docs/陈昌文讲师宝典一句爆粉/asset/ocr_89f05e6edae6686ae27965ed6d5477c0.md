# ## 28、一年策划 12 个读书会

**社群管理层：**

我们新书发布，大家可以热心参与，有设计能力、文字组织能力，组织能力的都要参加，做一个完整的活动，把细节进行分工。只有参与进去，才知道怎么去运营一次活动，以后可以带头做项目组长。这样事业才可以做大。

参与的人一定要服从项目组长的工作，让项目组长工作顺利进行，以后如果换人做项目组长同样也是要全力配合。只有协作才能把事情搞大，分配下去的任务，什么时候完成，也得及时。执行力差的不要参与，这样会影响整个项目的推进。

在项目推进中，不管谁，都要配合项目组长的工作，不要说一些无用的。最后做成一张统计表出来，所有的都按统计表去执行，什么时间、什么节点做什么事，都要写得清清楚楚。这样，执行人员就可以知道他要做什么事情，什么时间，什么内容。

**陈昌文：**

这样就进入了营销策划、活动营销时代，我们社群要多做项目组长，跟踪每一个项目，争取每一个项目都合格，并且成功。
