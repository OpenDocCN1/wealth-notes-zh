# 1、借力打力，精准定位与爆粉的关系

做抖音，我们是要精准粉丝的，也就是企业家、老板。我们有一个精准粉丝概念，但是也不要耽误我们的传播。传播不仅仅要让精准粉丝传播，还要让泛粉丝传播。精准定位传播与热点炒作传播要结合起来爆粉，这并不矛盾。不要觉得我们搞精准定位，就只能是少量粉丝。我们也要名气，也要传播，也要爆粉，也要有专业的爆粉文案，调动女人去传播，调动男人去传播。

真正的传播学，是利用大众的传播情绪，利用大众的情绪。大众觉得这个东西好玩、好看、有趣，或者反对这个观点。也就是我们有一个精准定位，就是营销企业家、美女老板。但是我们的爆粉模式，可以结合人群中的大面积情绪、关注点，进行借力打力。从这个角度来讲，我们的传播效率是可以极大提高的。
