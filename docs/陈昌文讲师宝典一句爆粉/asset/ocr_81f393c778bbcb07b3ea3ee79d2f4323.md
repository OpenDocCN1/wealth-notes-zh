# **■ 善为上者为之下**

再讲一个用人之道，这个用人之道在于什么？在于你必须要知道别人比你厉害。

善为上者为之下，《道德经》里面讲的这一句话。你心态里面一定要认为这些人比你厉害，那么他们才会跟你干，那么你也才舍得授权。

他们跟你干，你看不顺眼的，要容忍一下，不要什么都不能够容忍，那么你这个团队是搭建不出来的。你要知道别人比你厉害，然后培养他特长的那一方面，或者是他天赋的那一方面。一等人靠天赋；二等人靠天才；三等人靠能力，靠智慧，靠能力，靠智力；四等人靠体力。

那么这几句话呢，同样也是用人之道，就是你在什么境界上，也就是说如果你是超级高手，那你是拥有天赋的人，就是你一个人，看的是他的天赋。
