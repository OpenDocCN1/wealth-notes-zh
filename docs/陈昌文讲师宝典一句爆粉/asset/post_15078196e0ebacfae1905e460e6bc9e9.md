
# 做一个真人

我再讲最后一个道，这个道叫做真。你们看电视剧，看小说，这个道家的人物里面有一个叫什么，张真人。

道家人物，得道了，就叫真人。全真教，就是都是真的，不跟你来虚的。你们很早的时候就都知道全真教，你们不知道什么意思，对不对？我一句话给你们解释，全都是真的，咱不玩虚的，这个就是道。真了就是道，真说真干。

对于任何人只讲真话，因为讲假话成本大，一个假话后面要接一个假话，还要接一个假话，最后假话破裂，会很大的代价，这个叫真话。

对任何人要讲真话，不要忽悠人。佛经当中有这样一句话，言出法随。在道教当中也有这样一句话，嘴巴里说出来，就是法。

人是怎么能够获得别人的信任的？就是你这个人从来不说假话，那么你讲出来的都是金刚语，人们会自动相信你，只要你从来不说假话，人们就会自动相信你。这个很重要，各位，只要你不说假话，人们就会自动相信你。只要你常年坚持，人们就会自动相信你。如果你只讲真话，那么你做视频，做直播，你坐等收钱就行了。

你们很多人都听不懂的，我这几句话你们也听不懂。如果你只讲真话，你坐在那里收钱就行了，但是你喜欢讲假话，即便是你口吐莲花，你也赚不到钱，你也没有成就。即便是你口吐莲花，赚到了钱，你这些钱都会走，你还会倒霉。

所以儒家经典里面，我经常提到这句话，叫做言悖而出者，亦悖而入；货悖而入者，亦悖而出。什么意思？你这话怎么进来的，就怎么出去。你骂了别人，别人就要骂你，偷盗别人钱财，人家就会偷盗你。

我们再讲一个词语叫真干，是真的去干，真抓实干，这个也是道。真就是道，真抓实干就是道。你只有去干了，你才会有道。你不去干，你就没有道。

道是在干的过程当中拥有的，而不是坐在那里想，就会有的。坐那里想，是没有道的。我跟你们讲，只会把你饿死了，穷死了，渴死了。你要去干，比如说现在抖音火，我们就要去干抖音视频，干抖音直播，有能力的我们干团队。一切都是干出来的。要真干。假干什么？假干是忽悠，假干是忽悠别人说我干了。有些人更狠，他忽悠自己，他自欺欺人。

说真的，干真的。自己没有那本事，不要说有，这个也是道。自己没有的本事，就实在的告诉别人，我没有这个本事，不要骗别人说，我行，你把钱给我，我给你干，这就是骗子。这不在道中，会倒霉的。

所以赚钱有一个法则，就这个“真”字，就是你要求我的，我做不到，抱歉，这个钱我不赚。你们如果学会了用我这个方法做直播、做视频，你们赚钱的速度会非常快的。为什么？因为社会上到处都是骗子，他做不到，他说我做不到，他就是为了人家付费，他去骗别人。人家说你能解决什么什么问题吗？他解决不了，他一想，要是我说解决不了，人家就不给我钱了。

所以人家说，你能解决我情感问题吗？能能能。你能解决营销问题吗？能能能。你能解决品牌问题吗？能能能。你能解决我人生的什么问题吗？他说能能能。然后人家给他交钱了，最后他又解决不了，平台也解决不了，然后就会出事。

那么我们应该告诉别人什么？你这个问题，我们解决不了。我们有什么，我们只告诉别人真的，我们百分百确定的。你比如说加到我们读书会，我会送你一套书，我赠送给你，这个是真的，我们不会骗你，对不对？加到我们读书会，我不保证你学什么，学得得学不到，靠你的缘分，你愿意来就来，你不要找我麻烦，这个也是真。我们也不希望别人找我麻烦。至于我能干什么，对你有什么好处，你自己却发现不了，不要来。

今天有两个人打我电话，我看有一个老板，广东那边的，尾号好像是四个9，他要加群，我说有缘分就来吧，没缘分就算了，然后我就把电话挂了。我不管你有多少钱，我不跟你说那么多。我们只是讲我们的好东西，你看懂了，几千几万无所谓，你就跟我，但我绝对不骗你。你要让我骗你，休想。那么你这样说去说，能不能赚到钱？能，能赚很多钱，懂的人自然会来。

我希望大家学会我讲的这个语言模式。真说，真干，真能做到的。就是你的本事到底有多少，你休想让我骗你，要劝退一批，留下一批。
