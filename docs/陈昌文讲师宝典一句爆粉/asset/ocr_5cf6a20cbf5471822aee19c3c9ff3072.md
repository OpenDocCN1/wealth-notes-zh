# 14、我们只是卖圈子的、卖链接的，
其他任何事情不卖

我们的书籍就是我们的道具，也就是法器。你得不断的在粉丝眼前晃，晃多了他就买了。你得不断的说我们是儒家思想延伸出来的正能量。我们有一本书叫《陈昌文解读〈论语〉》，我们传播的是孔子的正能量。我们的《恋爱宝典》《72大营销系统》都是正能量。我们只传播正能量。

书籍在粉丝面前晃，然后卖读书会，卖陈昌文老板社群，就会越来越容易。你把自己当成卖货的、卖西瓜的，然后不断的解释，介绍这个西瓜、货就行了。而我们的读书会、陈昌文老板社群，就是西瓜，就是货。不要只会不断的讲，表现自己，这样搞没有利润，没有转化率，就是自嗨了而已。

永远让书籍、陈昌文读书会、陈昌文老板社群当主角。永远以品牌贴现为目的，赚钱为目的，其他都是虚的。能变现是高人，不能变现，一切都是假的。
