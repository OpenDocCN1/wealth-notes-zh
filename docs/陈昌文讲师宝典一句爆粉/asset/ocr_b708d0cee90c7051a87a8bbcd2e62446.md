# 3、一切都是捡来的，一切都是复制来的

所有人都必须明白，流量是复制来的，不是自己原创来的。看到谁的文采爆粉了，直接复制。看到谁的视频爆粉了，直接复制。看到谁的直播能收单，直接复制。人不用动脑，复制就行。能筛选就行，也不用原创，直接复制，收钱就行了。（注意，是复制我们社群内部。你复制外部，涉及侵权、犯罪。）

有人的文案爆粉了，所有人复制，做成视频、直播。别人能出十单，这个视频、这个文案，你就能。也就是一切钱是捡过来的，一切流量、粉丝，都是捡过来的，是直接复制那些已经爆粉的文案、视频、直播，去收单子。一个爆粉文案、视频、直播，就能捡钱了。一个好的文案，捡几千块很容易，这就是抖音的玩法，复制营销。所有老师、高级群的人，永远都在研究如何复制流量，复制粉丝，复制直播。采取最高效率、最不费脑子、最低成本的复制营销模式。
