# 管理的本质是管理自己

那么再讲一个道，也是我们经常讲的一个道，也是我经常讲给很多人听的。我最喜欢讲的一句话叫做：管理的本质是管理自己。

儒家思想专门讲了一个内圣外王，修身齐家治国平天下。修身就是管理自己。致知格物，修身齐家治国平天下。《孙子兵法》当中讲的知己知彼，这个修身就是把自己的身体搞好，把自己的思想道德观念搞好，就叫做修身。内圣外王。《孙子兵法》里面讲知己知彼，百战不殆。这个知己，也是要知道自己，管理好自己，知道自己该干啥，什么不该干。

德鲁克讲，管理的本质是管理自己，这一句话也是道。你不要去管别人。当我们做管理工作的时候，我们会发现我们要去管理别人。那么修身齐家治国平天下，说的是我们只管自己，确实可以不去管别人。
