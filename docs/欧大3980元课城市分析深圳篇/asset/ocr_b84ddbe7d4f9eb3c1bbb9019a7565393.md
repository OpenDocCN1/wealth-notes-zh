# 宝中故事

2019-2021轮期间，宝安投资公司遍地，有行家老板，几乎全片区的中介都认识，听说如果哪天睡觉前他没看盘，都要起身约个中介去看一套房。此老板在这一轮前半段赚的盆满钵满，主要是低价收，加价卖。后期加大杠杆，收了不少大货，壹方、熙龙湾之类。据传已爆仓。

2023年初，网上传一，征婚启事，貌美小姐求婚士，送海纳公馆，前提是付款1200w。此事因为海纳尚在限售期内。

2023年初，花样年业主想送房。27平单房买入价365w左右。年初价格在240w左右。几乎是资不抵债状态。血筹码可见一斑。

华x银行高峰期，此房可贷300w。后遇深房理事，银行客户经理一年啥事不干，就处理这笔贷款，负责把客户请出去。怕雷爆在本行。
