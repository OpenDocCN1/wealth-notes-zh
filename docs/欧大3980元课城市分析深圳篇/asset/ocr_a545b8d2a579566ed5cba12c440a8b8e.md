# 教育配套

+   - 深圳湾学校(原望海学校)2011年即规划建设，家长们对这所九年制的学校寄予厚望，可惜学校的建设进度一直不理想，直到15年才动工开建，2017年9月1日正式动工使用。2020年第一批生源成绩出来，中考成绩排名南山下游，原深中的网红校长牛皮吹得有点大，但是似乎也不怎么影响孩子家长的情绪，也没有影响到房价。

+   - 深圳湾学校以中英双语教学、STEM教学、体育及艺术为主要办学特色;硬件设施非常优秀，让学生和教师获得成长、让体育和艺术回归教育、让教育与世界相融合。重视体育，每天一节体育课。

+   - 学校教师团队汇聚英才，主要来自哈佛、哥伦比亚大学等世界名校，来自北京大学、清华大学、中国人民大学、北京师范大学、华东师范大学等国内著名高校以及港澳一流高校，体育老师方面甚至聘请奥运冠军作为学校辅导老师。
