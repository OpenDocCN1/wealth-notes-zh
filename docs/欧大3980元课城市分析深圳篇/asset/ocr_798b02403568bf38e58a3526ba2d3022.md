# 福田 --- 保税区

+   位于深南大道-滨河大道黄金带南侧

+   1991年建立保税区，保税区内好似“深圳的小香港”，封闭管理，后取消

+   但之前不通地铁，出入口长期堵车，进出排队等待时间很久，外面的人很少进保税区，还是相对封闭的一片区域，2020年保税区内才通地铁，带动了一波房价上涨

+   2018年福田外国语学校建在保税区，大大改善了保税区内的学区品质，带动了一波保税区的房产投资热情，“雅房”当时一度主推保税区，投资客较多

+   保税区在福田区长期是“拖后腿”的存在，保税区内以制造业和物流业为主，相比金融业和互联网，产业相对落后

+   保税区列入河套深港科创合作区的一部分后，未来还是有希望的

+   保税区内很多小区自然环境太好，小区内常有“注意蛇出没”的警告牌，有小孩的家庭需特别注意
