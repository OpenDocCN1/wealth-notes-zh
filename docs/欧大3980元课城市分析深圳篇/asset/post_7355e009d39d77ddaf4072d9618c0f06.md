# 福田 --- 保税区

- 位于深南大道-滨河大道黄金带南侧

- 但之前不通地铁，出入口长期堵车，进出排队等待时间很久，外面的人很少进保税区，还是相对封闭的一片区域，2020年保税区内才通地铁，带动了一波房价上涨

- 保税区列入河套深港科创合作区的一部分后，未来还是有希望的
- 保税区内很多小区自然环境太好，小区内常有“注意蛇出没”的警告牌，有小孩的家庭需特别注意

# 南山 --- 深圳湾

- 深圳湾原名“后海湾”，意为“前海湾之后”的海湾，是介于香港新界与深圳南山的对开海域。后来，由于香港先使用了“后海湾”，深圳遂改称为“深圳湾”。
- 早期的深圳湾泛指，从西边蛇口半岛开始，到深圳湾总部基地及后海，延伸至红树林，东临河套地区，这一片20平方公里的海岬，这一片统称为深圳湾。（对岸可以看到香港的元朗）
- 随着城市的不断更新和发展，这一片20平方公里的填海海岬，就被逐渐划分成:蛇口、后海、深圳湾、红树湾4个重要板块。

## 双拼房/7090政策

- 深圳湾是2009年后新兴的豪宅区，当时普遍开盘3万左右，由于受到2006年的7090政策影响，开发商一般采用以下两种方式规避
- 一种是“双拼房”，即用两套小面积的房子去拼成一套大面积，居住使用与一本证户型无任何差异，只是购房者购买这套房占用了两个购房名额。后来限购限贷调控政策逐步收紧之后，双拼房则受制于购房名额和贷款的限制，很多人买不了，其交易活跃度和价格都收到一定程度的压制。
- 另一种是把不到90平的小户型通过高赠送的方式，改成中户型。比如恒裕滨城89平，通过高赠送，实用面积达到120平。所以它单价为什么是深圳湾中心路上最高达30万/平，这就是最核心的原因。实际合算下来的单价在22左右，就不会觉得离谱。
- 深圳湾东滨路以南、中心路两侧共有18个小区，总户数8117户，其中单证房源5227套，占比64.4%，双证房源2890套，占比35.6%。
