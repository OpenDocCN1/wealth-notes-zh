# # 福田 --- 竹子林

+   • 位于深南大道-滨河大道黄金带上，也属于泛香蜜湖区域，最早是一片小山坡和成片的竹林

+   • 援建深圳的工程兵聚居地，后来工程兵转业成国企和机关单位公务员

+   • 区域内很多单位福利房小区，==正在旧改中==，签约率接近100%

+   • 房改后，2005年前后，陆续建成了一些小区

+   • 临海还有一大块位置最好的政府保留地块，待后续开发

+   • 有深高南学位+居住体验感不错的小区，单价是本板块内最高的

+   • 宝能公馆2017年入市，有公寓，有人才安居房，有住宅，住宅有深高南学位，但目前还有网传开发商保留了一些尾盘

+   • 总体是相对冷门的板块，除了宝能公馆都比较老旧，==承接香蜜湖的溢出购买力==，特别是想上车香蜜湖又够不到的、在香蜜湖或者附近国企（包括少量证券公司和银行）和机关单位上班的、对学校有要求的中产白领家庭和公务员家庭
