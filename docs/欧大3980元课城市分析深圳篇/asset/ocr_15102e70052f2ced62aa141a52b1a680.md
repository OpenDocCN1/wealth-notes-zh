# # 福田—中心区

+   *   位于深南大道-滨河大道黄金带上
*   1990年上步区更名为福田区，同时开始规划建设深圳市中心
*   根据深圳山脉走向，选择莲花山脚下 “龙脉”风水宝地，以北京故宫和明故宫的中轴线为模板
*   征地水田后，统一平整土地，按最高规格建造地下排水等城市隐蔽工程
*   是深圳的政治中心、金融中心、文化中心
*   远离机场，不限高，全球第四/全国第二高楼（平安金融中心）
*   区域内写字楼、商场、市政府相关机构为主，住宅分布于区域内四角
*   商业配套完善发达，莲花山公园和市民广场提升居住体验感
*   价格很稳，成熟板块，随大市上涨，**本轮回调中基本没有跌/微跌**， 非常难得
