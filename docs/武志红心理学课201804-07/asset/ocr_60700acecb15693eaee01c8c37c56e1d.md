致，从而可以创造奇迹。

合一状态中，人类会用各种方式去追求合一。并且，在“一”中，因为没有矛盾，没有冲突，不会纠结，所以人很难去追求这种状态。但是，充满冲突与矛盾的“二”，才是我们更容易处于的状态。

![](bbox=[0.35, 0.1, 0.65, 0.12])

二，就是二元对立。看到了A，也就意味着看到了“A：这是我喜欢的”一句话，它是对二元对立的一种表达。

二元对立，可以视为分裂。人性中最重要的“分裂”是从共生，到“我”与“你”的分裂。有了你，也就有了我。还可以这样理解：“我”，是一个人整个人的内部世界；“你”，是一个人的整个世界。一旦有了这层意识，一个人就会关心他对内部世界的感知，因为知道这能提示他外部世界是这个人的内部世界和外部世界的关系。

从你和我共生，到你和我分离，是因为创伤的发生。先是隔着痛感形成的分离，婴儿从妈妈的完全子宫里而得到安全感。后来，当母亲不能满足婴儿的需求时，婴儿和人的开始意识也被打破了。破碎的时刻，婴儿开始意识到，他和妈妈的身体和心理是分离的，“我”的意识由此而生，同时也意识到了“你”。

生命最初的创伤已经很强。但它也可以经由关系的良好照顾而得到补偿，这对补偿是否可以适当发生，这将决定婴儿最初的内感受和外部世界的感知。这将成为他/她的内在世界与外部世界的隐喻，这是如同命运一般的力量。

围绕着“我”与“你”，我们还有很多重要的二元对立同时产生：

# 生能量与死能量

当“我”的一个动力被“你”拦住，这个动力没有“我”体验到生能量，当这个动力没有得到回应，它就会被“我”体验到死能量。

# 创造欲与毁灭欲

这是生能量与死能量的另一种表达。

# 全能自恋与自恋性暴怒

对于婴儿而言，当动力被拦住，婴儿就会体验到全能，觉得无所不能，当动力没有得到回应，就会产生自恋性暴怒。心理发展水平停留在婴儿状态的成年人，内心也一样。

# 彻底无助与被害想象

自恋性暴怒表达不出去，就会转过来镇压自己，会变得彻底无助，同时这份敌意就会投射到外部世界，觉得好像是外部世界有一个敌意力量要置自己于死地。越无力的人，越容易有敌意想象。所以软弱的我，不能轻言善良。

# 生与死

因为没有形成抽象意义的自我，婴儿会觉得，每一个动力都是“我”，所以每一个动力的生死，婴儿都会体验到真实的生与死，而因此有了真实无处不在的死亡焦虑。成年人的各种焦虑的背后，根本上一样都是死亡焦虑。

# 爱与恨

传递生能量时，是爱；传递死能量时，是恨。爱与恨，是生与死的一对孪生。
