# 专业类

《动机与人格》马斯洛

![](bbox=[0.15, 0.27, 0.85, 0.47])

马斯洛在书中提出了需要层次理论、自我实现理论、高峰体验理论等。本书是一部经典的、解读“人性”的著作。阅读本书，就如同在倾听自己内心的声音。它并不晦涩难懂，适合我们心理学课每一位想了解自己、了解人性的同学阅读。

《心灵的面具》布莱克曼

![](bbox=[0.15, 0.7, 0.85, 0.9])

布莱克曼结合自己30多年临床和教学工作经验，以及其自身曲折传奇的个人经历，理出了101种心理防御，完成这样一本既有教育性又富有阅读乐趣的书，讲解了人们发展某些防御的原因并提供了识别无意识防御的技巧，使无比复杂的概念和内容变得平易近人。
