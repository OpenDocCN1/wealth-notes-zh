# 加餐：给你的自我腾挪出空间

武志红

我先来讲一个有趣的现象：影视剧中，经常会演绎这样的画面，两个人在一块儿，水平相当，甚至反派角色的能力更高一筹，但主角突然灵机一动，发现周围有东西可以使用，然后凭此一击击杀反派。

例如在电影《杀死比尔》中，女主角在日本，和一个高中生模样的女杀手较量，明显实力不济，不幸被女杀手的流星锤撞进了脖子，陷入绝境，正在就要惨死的时候，突然发现旁边有一个带钉子的木板，立即拿起木板杀死了女杀手。

这种影视剧中刻画的画面，是仅仅刻了主角光环的效果，还是真有一些更深的道理呢？我个人觉得两者都有，并且倾向于认为这其中包含着深刻的道理。

在我的理解中，决斗的时候，就是死能最顽强的体现，主角和反派都面临着死亡威胁，而且我强大的人即使这个时候，还是会很有冲心理空间，让他们的意识仍然能保持一种放开的状态。于是发现更多可能；而反派虽然实力强大，但面对可怕的死威胁，一种很多有意的心理空间了，结果他们处于一种高度紧张状态，这导致他们的现实选择空间也变少了。

再继续讲讲昨天我提到的考试轨道法。在广状元考完心理老师，当我拜访这位高考状元和她的老师时，在交流时，他们听到我的考试轨道法，惊讶的不是我的理论，而是我在高考还有三月时，竟然选择不做题，把时间基本都放到了研究考试方法上。

他们说，也有一些学生有和我类似的发现，但在高考冲刺阶段，压力太大，他们不敢去做这种与众不同的选择。

我可以这么说，这和电影《杀死比尔》中刻画的那一幕有相似之处，在巨大的压力之下，高考生听新的，容易走偏执，有早期的高压，他们的自我是能够对抗这个巨大压力的，从而为自己的心腾出一部分，从而让心智可以比较好地去运作，不仅发现了机会，还可以更理性。

相反，自我不够坚韧的人，在巨大压力下自我越发可危，有危机也就是死亡的焦虑，这个地方，无力感就被死亡焦虑给抵消了，这种心理被死亡焦虑淹没，就没法看到更多可能，做好更多的选择了。

我再来讲一个电影中的经典画面，在《魔戒》这部电影里，魔王代表邪恶的力量，对于都能发起了攻击，城市里的政治王觉得魔王力量太强，正义力量必败，这个时候的意识是容易无比狭窄，做了一系列错误的决定。因此，就像鲁滨逊漂流记中的鲁滨逊，没有一个大的决定是对的。

相反，影片中代表正义一方的白袍巫师甘道夫，却在任何情况下都做出最正确的决定，即使在魔王势力要强夺城市最后一道防线时，他仍保持镇定。因为，他悟了生死。当时，影片中一个角色对甘道夫说：没想到我们的生命会这样结束。甘道夫说：

> “结束？不，这不是生命的终点。死亡只是生命的另一段旅途，是我们都要走的旅程。当人与时间的雨幕在合拢起开，一切将如银色水晶般闪耀，你会看见它……”

甘道夫的领悟，立即让对方不再惧怕死亡，也从意识狭窄的状态下恢复了出来。

虽然这是一部奇幻电影，但我们可以设想一个推理：如果死亡并非结束，而是一段旅程能保持宽广的心理空间。即使死亡真的是你的生命的彻底结束，真正不怕死的人，也仍然是能够在死亡前保持一种豁达，所需豁达和宽广的心理空间，是一个智慧吧。

我再来给你讲几个意识狭窄的经典案例。

多年前发生一件很伤感的新闻事件，一位孕妇被贯穿身体一很痛苦，骗取年轻女孩的信任，最终和丈夫合谋杀害了女孩。

我记得当时我知道这个事件后，非常震惊。虽然因为不可思议的事，但我还是很难过。不过难以置信的事，我虽然听了这么多残酷的故事，但你没有觉得，还保持着宽容。所以，我试着用心去体会，这种残酷且愚蠢的性行为，到底是什么样的心理原因。

我的一位来访者的解释，让我有了真切的理解。该来访者是一位女性，她和她丈夫恋爱时有过出轨的行为，结婚后被丈夫知道后，他嫌收不得了，并对丈夫说，你也可以出轨，作为对她的报复。

当然，她没有做出有出轨的行为，我问这位来访者为什么会有出轨行为？她说，她当时也不知道为什么，现在回头看，可能是因为她太怕痛苦了，如果有人向她表态好感，她会逃进去。

这种说法，我在我的一个朋友身上也见到过。当时，他有一份很满意的爱情，觉得与女友的感情深到了血雨里，他因为另一名女孩对他表达了爱意，他突然获得一些曙光，女友会极度不安，而且嫉妒他和外。他还会为飞蛾扑火，一头扎到三角恋的泥潭中，果然，女友知道后，坚决与他分手了。之后，他感觉失去了整个世界，和第三者的关系也索然无味，走向了分手。

我经过了解后发现，这位来访者和我的这位朋友都有极其孤孤单的童年。例如这位朋友，四五岁经常独自回家，晚上独自睡在野地里，而家人竟然也听任他这么做。这样长大的人，不可能会有内源感自我。

正常人恋爱中，能发起有起致性的行为，也就是说他们不会只看到眼前的一小步乃至几小局部，而是会看整个整体。相反，我的这位来访者和这位朋友，他们追逐感时，只看到眼前的一点好处就会扑上去，而不能前后有心量，同时，当遇到危机时，他们心理也狭窄，让他们只能处理眼前短暂的一小步的问题。

我认为前面案例中的孕妇很可能就是这种逻辑：她对心理极度失控，当她入迷她时，她就心动了；丈夫很热情，她就不自在了；肉了，就想扑救；扑就扑，就不管后果，她永远都在解决当下那个难题，甚至永不当药方的状态。

另一起新闻中的一名软件工程师可能也是如此。他要买房子，要170万首付，于是他就选择了抢。
