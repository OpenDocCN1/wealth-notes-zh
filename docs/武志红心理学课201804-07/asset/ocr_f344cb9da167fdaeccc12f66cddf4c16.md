# 无常04｜头脑的伟大之处

无常04｜头脑的伟大之处

**武志红**

我们这一单元的主题是“无常，是更大的自由”，这是第四讲，“头脑的伟大之处”。

我一直在探讨梦与许的意识和潜意识，好像一直在否定头脑思维的价值，但我这一节，我要为头脑与思维做一个正名。所有的人性与价值都非常重要，这个道理在头脑与思维身上也一样存在。

我先来进一个故事。一天晚上，我的一位女性朋友，在电话里向我讲述她的家事。她的妈妈是典型的“扶弟魔”，就是说，她的妈妈不但不帮忙，缺乏理智地帮助弟弟，已经严重损害了我这位朋友小家庭的利益，而且弟弟也是有个“败家子”，妈妈帮助他也没用，就像是在一个无底洞一样。可是，谁劝她妈妈都不行。

我一边听这位朋友讲，一边帮她分析局面，然后清情书序的逻辑，渐渐变得清晰起来。个人认，也许根本上，是她妈妈在维护自己的弟弟的情，以及帮助轻家败家弟弟的另一个必须的情，妈妈在家庭中被忽视的感觉，可以妈妈不能面对的这个。

谈到了呢，我这位朋友非常敏感，她说，先不让她妈妈是有帮助，但她的分析，倒是触动了她内在的感。这句话刚刚，她在电话里听起，突然之间感到别着，似乎有一口气从书往上，一直升到后脑勺的位置，头发都快都立起来了。

听她这么说，没关系，试着不选走，感受一下这个感觉，看看会怎样。

她感受了一下后，告我她说她打了一个冷，然后说门对门有一个双的她在看，好像一个充满态的“”在她那里。

过了一会儿，她突然间始流出了，然后又松了下来，说她“”好像是她自己。

我这为朋友看上去是善良的人，里必须加个“假”字才能真正形容她的里。而我认，这意味着她身的上性，她的头脑部是开了的，而或是最微弱态的，当它们从高意识中露出时，就会她为是“”。其常脑脑我们脑是最有潜意，态性正是生命的本。

态性是一个很大范畴的术，可以换成一点术，那就是故意。小故意的表，是，很多人最需态意的表识中，而必需头脑的防能行，所以这头脑的伟大价。

什么用“伟大”来形容头脑的这份力？因，当你的心灵不成熟、不，一觉察到故意，就会很保，如果处不了在内和外的敌意，都会被卡在这里，动不得。

例我这位朋友的妈妈，她的确是非理的事，不计代价帮助家一般的弟弟，对故意自己是什，到对弟弟的义，自己可能是感到非理为。同时，这份意会烈其他着，让没法去弟弟，及其相的系。

因，面对故意，我们有下面这的逻辑：

+   1. 把敌意投射到外界；
2. 面对外界故意的故意，本能上是想自己占上，可占也被损；
3. 如果自己不占上风，落了，就生重故意，我怎么那么，同时也生重故意，甚至大故意，对敌意方的恨力，而且会对敌意方就是害，哪怕会正我也这。

4. 一旦体到自己的故意，就生出烈的坏，这份坏如果向对方，会向他发攻击。

这样，敌意就会在孤的想中折自，一它系中，可能会给系带来坏。
