# 问答：心流与高峰体验

问答：心流与高峰体验

武志红

这节课是我们专栏的问答时间，我先来和谈这个知识点，再来回答一下大家的问题。

这个知识点，就是心流与高峰体验。

我坦白说，作为人本主义心理学家，罗杰斯对我影响极大，而马斯洛对我的影响就很小。

一个原因可能是，马斯洛采用的归纳性研究，我个人觉得效率不高。也许对于一些远离了自我实现之路的人来说，对于实现和自我实现的描绘究竟是激动人心，但咨询和自性说一句话，我是最教育尤触，但一直就走在成为自己的这条路上，所以并没太觉得马斯洛的理论能触动。

还有一个原因，是马斯洛没有特别地指出一条路，自是实现的确是非寻常，我总不能是路已经偏离得太厉害，我后才能回答？高峰体验确实很迷人，但它是拎羊往里递无进导。

相比之下，积极人本主义学家克里斯哈赖尔所提出的“心流”一说就非常不同，它是一个具有操作性的概念。首先要说一下，马克斯和马斯洛写的《心流》这本书，是最为经典的心理著作，我强烈向大家推荐，得到专栏的刘圣老师也有“名家大课”中，着这本的社会学家邓恩也先师对《心流》这本书进行了解读，万科陈老师也多在他的“精英日课”专栏中提到过这本书。

马克斯心流赖通过大量的案例研究，最终提出了“心流”的概念，心流的体验与高峰体验有关系，高峰体验就是级到很高的心流体验，之所以用“心流”这个词，是因为很多调查者发现，当这种美妙的体验发生时，就像一股洪流带著我。

我们用我们专栏一直讲的精神分析理论，来阐解一下我所理解的“心流”的逻辑：

+   1. 心流就是生命力的无阻抑流动。
2. 生命力是精神分析中所说攻击性，它的无阻抑流动，主要通过两点：一是在自我复归时，展现生命力，而不必担心被报复；二是当自性扩大后，展现生命力，而不必担心伤害别人。
3. 要达到这一点，需要有一个容量内修持生命力的流动。我前面多有篇幅，自我是容器，关系是容器，你在做的事业是容器，家也是容器。总之，生命力是被容之物，而它的存在被确认，需要一个稳定的容器。
4. 马克斯哈赖总结的心流发生规律就是，找一个基本有能性的事物，稳定地投入其中，并且要有挑战，就是所做的事有时候会超出你的能力，但不是超出太多，然后不轻易努力，并不接受受到反证，一就使你的努力有效，那么久而久之，心流就可以出现了。
5. 心流出现时，人会有忘我感，也忘记了时间和空间，并会合一感。

更简单的概括是：在一个稳定的容器中，表达自我攻击性，在不被确认为生命能量，当整体上被确认为生命能量后，就可以阴阳流动。

容器可理解为“你”，攻击性可理解为“我”，那更简单的概括是：

“我”存在被“你”允许。

# 单一问答

武老师，匮乏认知、匮乏需要和存在认知、存在价值是可以相互转换的吗？比如参加一项运动，开始的时候是因为想增强自己的体质，但同时又能高峰体验这项运动，这是匮乏需要和存在价值的融合吗？匮乏需要和存在价值是不是种割裂？

武志红

这是一个非常好的问题。我们本单元内容讲得太简单了，以至于匮乏需要好像被否定了一样，但是的确定一种割裂。

事实上，我们常常是因为匮乏，最初是因为体验到高峰体验。可以讲，最初我是尽死能感的折磨，而去投入一件事情中，慢慢想自己，最终体验到我的生命能量，增强了，当我不再那么担心生死问题时，我体验到存在。

第七条清晰秀美的警答力应该是最境界雅难吧？人的性格应该具有多变性，这把在我自我实现看是一直保持还是一种主导呢？

武志红

马斯洛总结的这十四条特征，并非是所有自我实现者都有的。即使是高峰体验，在马斯洛看来，有些自我实现者一样没有体验到，而一些非自我实现者却体验到了。

这是归纳研究的必然结果。通常，类研究会这样，如果这些共同之中你具备的多数，就是这类人。

例如，如果你看心疾病的诊断手册的话，会看到诸如强迫症患者常见症状有多少条，假设你具有5条，那就是强迫症患者。

再具体回到你的问题，清晰秀美的警答力特征定是最境界，最境界界是体验自合一。所谓最高境界，只是一个人能看到其他存在的一个副产品。

武志红

王阳明是一个极好的例子，他他洞见所有人性的，同时嫉嫉如仇，他有一首诗对此有非常切的表达：

> “无善无恶心之体，
有善有恶意之动，
知善知恶是格物，
为善去恶是格物。”

他深切懂得，在最深的源头上是“无善无恶”，但人如“知善知恶”，而且还要“为善去恶”，最终“我心光明”。

为了让自己准确又充分的认识现实，除了尽可能多的走有真实世界之外，还有什么主要渠道呢？我有点好奇我是和现实接触之后，看到的还是自己的自恋呢？

武志红

这是一个极好的问题，的确，能看清楚“你”，这是一切的根本。可是，如何才能看清“你”呢？我答喜欢你的通路，就是去爱。

如果只是在智识上努力，那么无论你智识多么了不起，那，一个人必须把自己扔出去，深深到这个世界碰撞，去构建最深的关系，这才行。

武老师，我有一个疑问，你是匮乏认知的人，是想照自己的想象来认识现象，但那些就是敏感的人想象去却很丰富，比如意兰·马斯洛等，这两者看起来矛盾？

武志红

陷入匮乏认知的人，他的想象都是为小我服务的，都是用来满足自己的白日梦。

但是进入存在认知的人，他的想象是对真实存在的洞见，所以这两者之间是有本质的区别。

像王阳明这样的大德是怎么就不需高峰体验的呢？是时生活所自在自主的感受中的？高峰体验只是一种达到功能的状态吗？还是要根据我和感受去评判，体验到又是超越超越自我的自然领的感觉才算呢？

例如，如果我每天对自己进行意识状态，二点，对于这个过程我只达到一个大成我有时可能会高峰体验，但每天专注十部分意识去碎片时间，我感到专注也在当下的体验算不算最高当下呢？
