# 加餐：高峰体验

加餐：高峰体验

武志红

我们这一单元的主题是“自我实现”，这节课加餐，我来为你讲一讲“高峰体验”。

# 高峰体验

除了自我实现和需要层次论，马斯洛还有一个经典的术语广为人知，就是高峰体验（peak experience）。

马斯洛发现，自我实现者们常常会提出一种特殊的生命体验：感受到一种发自心灵深处的愉悦、欣悦、满足、超然的情绪体验，由此获得的感受，就像光一样，照亮了他们的一生。这种体验持续的时间虽然短暂，但深刻无比。马斯洛称之为高峰体验。

高峰体验是一种很特殊的东西，马斯洛发现在这种体验中，当人虽然会自我消融感，并且时间感和空间感也会发生变化，但他们同时又具备最高程度感的自我认同，而且他们有时又像是触碰到了人性、宇宙或者存在的本源。

处于高峰体验的人，有以下一些特征：

+   1. 有一种比其它任何时候更加整合的自我感。更自由，更少冲突，更少犹豫，更少竞争心态，注更集中，同时高度放松，身体高度协调；

2. 自我整合感的此时，他们体验到和其他存在合而为一感。例如，在行动中与他的孩子合而为一，母亲与她的孩子合为一体，艺术家观察到合成为画、绘画、舞蹈，而音乐、舞蹈、绘画也像可能是为了他；

3. 高度地发挥了潜能，感觉自己更聪明、更敏锐，更有效，更强健。在“一般”情况下，我只有一个力量用于行动，部分用于抑制这些能量的爆发，而现在不再需要，几乎全部能量都用于行动。此时，他如一条鱼在千里大海中自由地流；

4. 虽然潜能有了最大程度的发挥，可时使人又觉得轻松如云，毫不费力；

5. 高度的责任心，自主性和创造力。他们深刻地感到，自己不再是孤独的、被决定的、无能为力的，暮气沉沉的。只觉有特殊的使命感，他感到自己是重要的；

6. 在行动上更具有自发性、表达性、纯真性。无防备、无防御，在行动时更加自然、放松、简单、宽松、不动脑、不故作，直截了当，有一种特殊的淳朴，自由地涌出生命力。

马斯洛不是哲学家，甚至都不是一个好的科学家，他的语言学逻辑也不是很精确，但我几次关于他的理论的文言时，都有很多话觉得这是我和他的最好的文章。也许是因为，高峰体验和自我实现，就是我们人可以达到的一个境界。

不知道大家在读以上这些关于高峰体验的描述时会想到什么。相信学习过之前合集的对《命在8》这本书中，书中描绘的心灵合一体验，和马斯洛所描绘的高峰体验很像。

在《命在8》放下头脑，信任身体》这节课里，我是里面介绍了一些伟大运动员身心合一的体验，那也是高峰体验的最好描绘。例如NBA超级巨星比尔·拉塞尔的描述：

> > 就好像在用慢动作打球，我几乎能够预见接下来出现什么动作，下一次是怎样得分……

相信还有许多用户会想起我在“创造”这个大主题下，对一些伟大的艺术家们的别体验的描述，例如在《创造2 容死想》这节中，我引用过杰克逊·波洛克、米克逊、约翰、利欧·玛莎、格雷厄姆等人的感言，例如莫扎特所说：

> > 我的不从谱谱而来，音乐不是我而来，音乐不流进我里面。

此外，在《自我14 | 真自我和假自我》这节课中我讲过“高二男生的完美七天”这个故事，故事中的主人公，体验过七次像那样老大的体验，那就是一种妙不可言的天堂般的体验。

这些体验都是高峰体验，如果让我来总结，它们有这样的特点：

+   1. 自我和自我合二为一，特别是通常统治者与被统治者主要感受的“头脑自我”，也就是我1消失了；

2. 作内部世界的自我“我”和外部世界之间。我合“我二了，这时，你会觉得整体意义上的“自我”都消失了；

3. 时间感觉了，好像时间不存在了；空间感变了，好像空间不存在了。

整体上说，这叫为“合一感”，就是头脑自我消失，空间自我消失，时间消失和空间消失。如果用马丁·布伯的《你与我》这本书中的理论来讲，合一感就是“我与你”的关系建立的那一瞬间。

# 如何追求“合一感”？

体验到合一感，常给人巨大的愉悦。那应该如何去追求这种感觉呢？有两条截然不同的道路：

第一条道路是：既然合一感中，好像最重要的条件是自我消失，那就努力放下自我

第二条道路是：既然合一感是我实现者的专利一般，那就努力去成为自己。

后一条道路，是我们通常所知道的道理，也是马斯洛的自我实现之路。前一条道路，是各种修行路。在相当程度上，这两条道路都使得通，为什么？

我认为，当“我”的存在得以确认时，“你”的存在也就显现了。而两者的同时出现确认了，合二就呈现了。我们心理学家主要讲的是第二条道路，就是成为自己的道路，努力在这个世界上确认“我”的存在。

我也来为你大致讲一讲第一条道路。

我认识的很多人，他们坚持不懈地做一件事，就是打坐。例如我的催眠老师斯蒂芬·吉利的尔，从十几岁的时候，他就开始打坐冥想，到现在已经坚持四十年了。以至于自己，现打坐禅身的练习，也有十年时间了。

表面上看，这是很无聊的事情，但实际上这也不是完全的。因为的打坐，你最终是种到消。最初，先要把注意力入脑上，这移回到身上去，就已经进入了享受，这是一种到在的安静。接着，当进入比较较深的安静时，你会体验到一段段空白。但是和思维和头脑自我大时，会时体验到时间和空间的变化；当一切都消失时，那时体验到合一。

我有很少的时候，练习时，语言、思维和自我都三个完全的体验消失了。来无从描述的。体验然也是如此，思维和自我消失后有的体验，也意味着也不可用语意来形容，也不能用思维来思考。

我们需要知道的是，语言、思维和自我这三个东西是紧密联系在一起了。有了语言，才有了思维，然后就有了自己。

坚决走第一条道路的人，他们的决心会震惊到你。吉利根师说，他每天花费个小时用于打坐或冥想上，而我有些朋友，他们每天花费四五个小时。

这条路非迷人，可同时，第二条道路，也就是自我实现之路，同样是非常迷人的。

我的心理学课主要是借用了精神分析的理论，我一直坚持，经典精神分析追求的并非把自我消解掉，而是实现一个终极目标，让被分析者由内信他的自发性。

马斯洛所描绘的高峰体验，在我看来就是自发性。在高峰体验中，你会有种强烈的、迷人的体验，而同时会去到，这些体验发生时，当所有人都体验到不费力、纯发自然的感觉，这就是自发性。

马斯洛给我印象最深刻的人，给我们提供了一种可能，那是最能像做自己的。那些有自主人格的人，他们并没有成为自私自利、自我为中心，相反人，他们的潜能实现时，他们成了最好的。

这也是我们的心理学课一再讲的，一个人的人性路之路，也许是迷途，但它是被允许，被看见时，人性既开之道，也是生命力不断擦亮之路。
