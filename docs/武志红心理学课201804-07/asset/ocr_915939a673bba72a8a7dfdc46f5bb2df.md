# # 现实12|你可以好，也可以坏

武志红

“武志红” 现实12|你可以好，也可以坏

我讲这一单元的主题是“从分裂到整合”，这是第二讲，题目是“你可以好，也可以坏”。

前段时间，我又重温了一部电视剧《倚天屠龙记》。张翠山的死，令全剧笼罩在悲剧的阴影下，让人感慨万千。电视剧中的张翠山，和金庸小说中的张翠山，区别很大。小说中，张翠山是金庸先生塑造的一个“好人”，为了救妻子和义父，他选择了自杀。电视剧中的张翠山，则更像是一个反派，为了夺权，不惜害死义父，最后走投无路才自杀。电视剧改编得比较通俗，也更符合现代人的心理逻辑。

我最近读了一本书，叫《好人难为》，里面讲了一个概念，叫“全能自恋”。我觉得，张翠山的悲剧，很大程度上就来源于此。他认为自己是好人，就应该被优待，应该被保护。当别人不这么对他时，他就受不了。

我最近在读的一本书是吴伯凡老师的《吴伯凡认知方案》，他在其中提出了一个观点：现代人，由于信息过于丰富，导致精神容易疲惫。这种疲惫，往往表现为一种“好与坏的分裂”。

在吴伯凡老师看来，这种“好与坏”的分裂，在古人那里并不存在。古人虽然也有善恶之分，但他们是混在一起的，没有绝对的界限。现代人则不同，我们喜欢把事物一分为二，非好即坏。

例如，王阳明在江西巡抚时，当时江西有很多土匪，土匪的窝就在王阳明的地盘上。王阳明要想剿匪，必须先获得朝廷的批准。但朝廷的官僚体系，往往会对他的请求进行拖延，甚至驳回。

王阳明想出了一个对付这些内部人的办法，他安排一支队伍去剿匪，结果却无功而返。朝廷因此对王阳明很不满。但王阳明知道，如果他不这么干，那些内部人就会一直拖延，剿匪就永远没有希望。

在剿匪时，王阳明对土匪进行了无情的剿灭。但最后，为了安抚那些内部人，他却不得不给被俘虏的土匪一些优待。小说《明朝那些事儿》中，对当时朝野给王阳明做了一个概括，说道：

> “公正地说，在日常生活中，王廷灿确实是一个正真忠厚的老实人，但到了一打土匪，他的心思与行为比最好的奸商还好，这是要命的人，比的是最恶人的命。”

最后，王阳明在江西剿匪成功，名声大噪。但那些内部人，依然对他心存芥蒂。这种“好与坏”的分裂，是王阳明必须面对的难题。

其实，我们每个人内心都有这样“好与坏”的分裂。我们希望自己是好人，不希望自己内心有坏的那一面。但坏的那一面，总是存在的。

而真实的“你可以好，也可以坏”的整合，大概可以一开始就教给孩子。

这样的说法，也许你会觉得很可怕。但其实，不让孩子知道“好与坏”的分裂，只会让他们更脆弱。

如果，孩子认为这个世界非黑即白，那么一旦遇到挫折，他们就会很崩溃。因为世界不是这样的，所以他们的心理模型是错的。
