# 今日得到

1. 我们的内在生命力，需要借助我们所创造的外在之物去修炼。如果想有一个很大的心理空间，需要通过创造外在现实之物去拓宽，也就是“扩容”。当生命指向成长时，我们的一生必然是不断扩容的过程。

2. 只有真正达成的成就才能拓宽你的空间，想象中的世界大小不能起到这个作用。你的心理空间有多大，需要现实作为去检验，也需要现实就去扩容。

3. 太多人不敢去做事不敢去爱人，不敢去创造不敢生出渴望，几乎都是因为担心自己会失败，为了避免受挫后的羞耻感。

4. 心理扩容的最佳时期是孩童时，因为年龄越小，达成夸张目标所需要的现实资源越少。成年人如果想扩容，最好的方式是去创造你真心想创造的事物。
