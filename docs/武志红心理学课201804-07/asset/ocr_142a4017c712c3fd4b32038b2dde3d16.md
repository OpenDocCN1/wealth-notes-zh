自由09|你的需求不是罪

武志红

我这一单元的主题是“让欲求流动”，这是第二讲，“你的需求不是罪”。

# 为什么怕表达需求？

对于一个怕麻烦的人来说，表达需求是一件很不轻松的事。例如，我的一位亲戚，我们都觉得她这辈子可能没怎么求过别人，不过这可能，一个人生一辈子总有那么几次求人的时候，但她这位亲戚肯定是非常少求人。

我问他：“为什么对你来说，求人这么难？”他想了想说：“一旦被拒绝，就会非常糟糕的感觉。”

这些糟糕的感觉，有非常丰富的情绪层次：

首先是羞耻，会让人觉得很丢面子。

其次有暴露。像他这位亲戚一点も点拒絶不能承受，是因为背后藏着羞耻感，一旦表达需求，就必须被满足，否则有自恋性挫败产生。

糟糕的感觉里，还有失望、绝望与悲伤。他成为这个样子，必定是因为无数次体验过期望不被满足，于是期望变成失望，变成绝望，而这巨大的丧失，也会导致悲伤。

# “需要有罪”和“我有需要”

这些复杂的负面情绪，可以概括为一个非常简单的逻辑：

+   1. 需要有罪；
2. 我有需要。

围绕着这两个部分，可以分出好人与坏人。坏人，或者说我们常谈的小人，几乎没有第一部分“需要有罪”，而只剩下“我有需要”，并且不择手段去追求需要的满足。

不过这并不是真的，这世上的人只是不能很好地意识到第一部分，同时也常被这影响到身上——那么笨蛋，活该要被利用，最严重的时候，坏人不仅要剥割好人，还要将好人逼到绝路，因为“你这么笨蛋，还没死”。

相比之下，好人似乎没了第二部分“我有需要”，而只剩下“需要有罪”这种感觉，所以他们压抑自己的需要，不过，这也不是真的，好人仍然有罪。不用巧妙的方式来求，什么方式呢？通过满足别人。

例如，有这样一位妈妈，她对自己极为苛刻，自己一毛也没有任何零食，可她带儿女去买时，会会对儿女说：“挑吧，你爱吃吃什么就买什么。”儿女拿了自己喜欢的零食后，就特别优先，甚至是更昂贵的零食，以此来表达对女儿的在乎。

可是，回到家后，妈妈觉得女儿吃零食的样子很贪食，于是爆发了，居然又骂女儿：“你们知道吗我们家里多困难，你凭什么这么做无道！这这种多难啊，如果你拒绝你妈妈妈的付出，会如何呢？”

# 负罪感需求的满足

在这个案例中，妈妈是好人，她压抑自己的需要，但似乎要真儿的有什么需要，但她们透过看似满足女儿的需要来释放自己心中蠢蠢欲动的需求，然而又将“需要有罪的”这种感觉转移到女儿身上。

我自己作为经典的好好人，也有这个问题。大家有印象，我一直一个女孩，让这个配偶用上最好的、我，我曾经想象自己挣得很多钱，让她最好的、穿最好的、用最好的，但同时，我又觉得她是个“坏女孩”。

我们常说的“食男寡女”，性与吃，的确是两个最基本的需要，如果说食欲的有罪的话，那么男人们的的需求也就是如此了，常常有各种显性的、隐藏着的罪恶感。但是，女人的需要和饮食的需要一样难以压抑。怎么办？

最好的办法是，我勾引出你的需要，你因此来求我，我也心甘情愿地满足了，但我也说，你是坏蛋。

一些电影中，常对这样的心理有非常极端的刻画，在生活中不多见，但一般程度的表现，生活中比比皆是。

我在该心理学研究中，对调情有一个定义：两个人，不动声色地调济彼此的情欲，而自己不主动，谁先动了情欲，谁就输了。

欲就是有罪的，情欲是不可遏制的。所以，通过勾引对方的欲求来释放自己的情欲，又透过打击对方的情欲来转移自己的罪恶感。

男人觉得女人勾起了他们的情欲，所以在男性社会，男人可以更加理直气壮地说，红颜祸水。

女性也有同样矛盾，或者矛盾的心理，男人均她们有性，性对象，但男人又希望她们永远没有性欲，要么是纯洁的。因而，女人就要求表现得很纯洁，甚至连自己都不知道自己是性欲的。

所以我个人认为，关键是不要消除，关键意识我所谓的性对象，其实我真正的需要，看到你已围绕着需要而建起来的负罪感，然后学着去消负罪感以让自己去满足，然后去体验这需求渴望在关系中流动的感觉。

催眠大师艾瑞克森有个经典的案例。有一位女士，她想要呕吐，但总是强烈的罪恶感，这位患者感受被她与最痛苦的罪恶感，艾瑞克森是怎么处理的呢？他给这位女士讲了一个故事，她觉得，讲到她，说，当这位女人在治疗中体会到罪恶感，而且非常严重，等治疗快要结束时，艾瑞克森对她说，我们每个人在享受罪恶的，你也可以。

同时，我也要补充一下，可能只要有需要，一定的罪恶感是不可避免的。

# 我与，你，与我

犹太哲学家马丁·布伯说，关系有两种，一种是我和你，另一种是我与它。当我们将他视为满足我的需要的工具与对象时，这一关系就是我与他。

当我与你的全部目标与我，带着我的全部存在与你的全部存在与相遇时，这一关系就是我与你。所以，只要有需要在其中，就意味着我与你这被降格为“我与它”。

有一天，我快递员给我送了一杯咖啡，我收下了快递员，我一声谢谢。他走之后，我回忆时发现，尽管事情是刚刚发生的，但他的样子已经变得非常模糊。

因为，我是和他沟通“快速”，对我来说，我面前那一刻，我就是一个快递员，满足了我正在进行的一种需要。如此一来，我没有拿出我的全部存在与它碰撞，于是他对我也而言是很模糊的。

想到这一点后，我看着我喜爱的加菲猫，那一刻，我突然明白了，尽管它对我而言是很需要的，因为我它仍然是一种需要与被需要的关系，我喜爱它的爱，我也一直扮演着喂它和它打交道。

想想是这一点后，忽然间，我好像丢了我什么，看到了阿白的全然存在。

很有趣的是，接下来一会儿时间里，阿白与我形影不离，我问到哪里，它就跟到哪里，而这时我比较心走是跟它有任可需要的。之前，这种事只发生在它需要我的时候。

需要是有罪的，所以，很多修行的人会断绝关系，独自一人待着。

这一体悟是惊人的，如果境界不够时，独自一人待着会受到两个考验：一个饮食，一个是男女。饥饿中，腹欲会吞噬内脏，而欲火也可以让一个人走火入魔。

孤单寡人常常是一个奢望，需要或欲望总是逼迫我们依靠建立一个系统。所以我们总说，欲望是一个检测器，将我们彼此粘在一起，直到你完全找到自己的真。

如是说，“我与它”的关系就像是有种关系一样，那么我们可以通过“我与它”的关系而前行，让一切流动，同时觉知“它”，而不断走向“我与你”的境界。
