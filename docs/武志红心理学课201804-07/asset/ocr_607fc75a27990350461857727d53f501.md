是“故意”。之所以如此，是因为在专栏创作过程中，我对它的认识越来越深。

我曾为《温尼科特传》这本书写序，读这本书时，看到书的作者，相当于用自己的写作为温尼科特做了个完整分析，其中多次谈到温尼科特的后半年，越来越多的谈到“恨意”。故意、恨意、“杀”，自体焦虑、关系中的恨、毁灭欲、暴怒、死能量……这些词讲的其实都是同一个东西——无常的制造者。

生命一开始，婴儿就会感知到浓浓的故意，他要吞吃乳汁，这会让他担心乳房会被他吃掉，而如果有所顾而不能，婴儿会对界外感到在意，只愿意到不能承受这一点，立即把它经由投射感知为，是外界在对自己发出恶意。

故意通向死亡，于是婴儿担心，自己的故意会杀死客体，同时也担心，外界的故意会杀死自身。该如何处理这些故意呢？婴儿的死力，是否让它存在，或者投射到尽可能远的地方，好像它与己无关，与自己所爱的无关。

所以，你需要首要学习，觉知到故意在自己身上和关系中的存在。觉知到以后，你就可以看到，故意是如何影响自己和关系的。在没有觉知之，你会觉得很多事情是那么不可思议，但觉知到后，你就会发现，原来它是存在的，起着破坏和摧毁的作用。

觉知故意的时候，可以有一个基本假定：你感知到的外部世界的故意，和你的外部世界的故意，是对等得。你要知道，绝不能的情况是外部世界充满敌意，唯独你善良。对故意越来越敏感，你会看到你周围世界的“无常”，常常是你心中的故意所致因。然后你就不容易这样想了：为什么我一门心思做好事，这个世界却要麻烦对我。

当你对故意越来越有觉知，而还能容纳并转化它，你会看到故意也是被剥离掉的生命力。

# 无常

无常的世界里，复杂的人性中，有一点是恒常的：选择，决定着你是谁。你必须是做自主性的选择，直接说出：这是我的选择！

这时，围绕着这个选择而产生的一切感受和体验，无论是正能量的，还是负能量的，才能真正地与你的“我”真地联系到一起，从而真实地塑造着你的样子。你要知道，这里并没有主动力去做选择的原因。因为这时你就可以认为这不是你的选择，所以，那些不好的体验和你没有关系。

不主动做选择的人，可能会给自己留着两个常见的幻觉：

一个是我还是全能自恋的。你看事情没有做好，是因为我还没有做选择嘛，如果我一出手，事情会立即不同。

另一个是我还是好人。你看事情做得那么可怕，有人受伤，有人显得狰狞，这都和我无关，都是我干的。如果我出手，谁都不会受伤，我也绝不会面目狰狞。

任何真正做事情的人，都可以被贬低，被怀疑动机有问题，而不去做自主选择的人，则可以一直抱有一种全能感和清自昼幻象。然而，时间无情。当日子一日复一日地消逝，没有做主选择的人生，人会感觉到生命的空虚。

这里，其实我首先说的是我自己，我在几年前有一次照镜子发现自己鬓角有白发，突然有了感觉，写了迄今为止唯一的一首诗：

```
你封闭自己
以为抓住了有序
日复一日的规律行为，制造着轮回归

你，宛如自己命运的主人
岁月，不经意间爬上眼角、额头和鬓角
你惊惧
最大的悲哀，是尚未活过
```

存在主义哲学说：我选择，我存在。而我最想说，一个道理是，遵从你的本心，做出你最想要的选择，追逐它，实现它，哪怕伤痕累累也在所不惜，拿你的肉身做棋子，与这个真实的世界去碰撞，然后你会看到，你的样子。

最后，我还想为你念一首童年的诗：

```
那一天终将会到来
带着喜悦，你问候自己
到达你自己的门口，看着你自己的镜子
你们彼此向着对方微笑，说，
请坐，请吃吧

你将再一次爱上这个陌生人
他，就是你
给他美酒，食物
将你的心再度交还给他
给这个不爱你一生的陌生人。
```

再次谢谢你，耐心读完了这一封长信。

更要感谢，在每一节心理学课上的聆听，愿每个人都成为真实的自己。
