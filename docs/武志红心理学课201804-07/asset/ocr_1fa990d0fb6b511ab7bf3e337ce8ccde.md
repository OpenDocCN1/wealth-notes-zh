# 现实09 | 金钱恐惧症的核心恐惧

这是一个单元的主题“金钱的隐喻”，这是第二讲，题目是“金钱恐惧症的核心恐惧”。

我们先做一个调查，下面是有关于26种金钱的观念，如果其中有一条，就给自己打一分，这26种观念分别是：

+   1. 钱是丑恶的和肮脏的；
2. 钱是邪的；
3. 金钱不是从树上长出来的；
4. 我很穷，但是我很清白；
5. 我很穷，但是我很好；
6. 有钱人是骗子；
7. 我不想有钱，不想富气凌人；
8. 我永远不会找到好工作；
9. 我永远不会挣钱；
10. 花钱比挣钱快；
11. 我总是负债；
12. 穷人永远不会翻身；
13. 我父母很贫穷，我也会很穷；
14. 艺术家不得不与金钱抗争；
15. 只有骗子才会有钱；
16. 总是别人先到；
17. 哦，我不能收费太多；
18. 我不应得到；
19. 我不够好，无法挣钱；
20. 不要告诉别人我在银行有多少钱；
21. 永远不要借钱给人；
22. 节省一分钱就是挣回一分钱；
23. “为测风雨”而存钱；
24. 压力会产生在何时刻；
25. 我很怕别人有钱；
26. 只有努力工作才有钱。

这26种观念，是美国著名心理治疗师露易丝·海的在她的著作《生命的重建》中写出的“与钱过不去”的观念。如果说她的这26种观念做一个心理测试，那么可以说是关于金钱恐惧症的一个测试。你的“金钱恐惧指数”有多高呢？也可以由此对照一下，你的收入是怎样的呢？

十多年前，具备了这些观念中的大多数，而且有些程度非常严重。从我自己的经历来看，我觉得当时持有这样的金钱观时，一个人很有福气。

我2001年开始工作的，很早就年收入就有了15万以上，在那个年代这个收入还算不错。2005年，我买了第一套房子，价格才4400一平米。如果把不能用这笔钱好好想挣钱的事，也是我不敢用钱的开始，但现实是我本就是一个“年光族”。到了年底一看，钱包里还剩不下多少钱，可我像也没什么，同时我既不是一个奢侈浪费的人，像这些我都很困惑地说我消失了。现在我收入上些，我觉得在相当程度上得益于我2008年后逐渐开始的观念转变。

我特别把这个指数称为“金钱恐惧指数”，是因为对于有可能导致金钱恐惧的观念，而言，金钱的观念会导致一些令人恐惧的事发生。露易丝·海在《生命的重建》这本书中，写了一个故事：

> 一个学生家素工非常努力，希望能增加自己的利润，一天晚上在特别小心，因为他刚刚赢了500美元。他一边儿地说：“我无法相信！我还没有从来赢过！”大家知道在相信转变的外在在反映，但他却感觉到另一个，第二个愿意他晚上上课，因为他摔断了腿，医疗费刚好花掉了500美元。

对此，露易丝·海的解释是这个学生害怕走向真的富裕，他其实并不期望变富，所以用这种方法惩罚了自己。

十多年前前曾经写过一个新的剧本，但列文安全部她妈妈买了张新床垫，她把妈妈用了很久的旧床垫从垃圾扔掉了。她对妈妈表达爱的学生，就连这张旧床垫都，露易丝·海的半生积一千旧床垫。后来安娜一家人去赶去老找这张床垫，可怎么都找不到了。

这样事发生后，老太太很看开，她安慰女儿说，虽然很伤心，但总比被车撞了或得了不治之症要好。老太太的这句话很有意思，它包含这样的逻辑：如果享受善意，就会被撕掉，或得个不治之症，而女儿弄丢了她地钱，反而让她免除了这样的危险。

然而，金钱真的会带来灾祸吗？美国针对那些彩票大奖得主的研宪显示，事实似乎的确如此。美国的一项调查显示，欧美大多数彩票大奖得者，在中奖后五年内，因挥霍无度等原因而变得负债累累，其中75%的破产。

对于以上这样的故事，露易丝·海的解释是自己人不想富有，所以用这种方式惩罚了自己。这种解释很不够，说服力不够强，但信你访中是否发现有更深层的原因。我讲来讲来访者的故事与领悟，然后再谈谈我的理解。

我的一位来访者，她每个月收入少的时候有一千多元，多的时候也有五六千元，她说，每次挣到一笔钱，她都会感恩，然后她会捐出去一小笔钱，例如50元或5元。

听上去，这是很棒的公益行为，但她每次深入访问发现，她是出于恐惧。每当她挣到一笔钱，她都会有惊恐，然后捐一小笔钱，好像是在请求某种力量不要惩罚她。

另一个故事是我的又一位来访者，每次和别人一起吃吃喝喝之类的时候，她都会抢着买单，但随后会感到严重不安，然后就不愿意和别人一起吃饭喝酒了。同时她还有一一个特点，她既不能接受别人比自己高，也不想要被接受，自己比人高。前者会引起的嫉妒，而后者，她担心自己会引起别人的嫉妒。所以，她总是隐藏自己真实收入情况，而当必须讲自己收入时，她会根据自己的收入，虚构自己的收入，目的是和对方的人收入基本持平。

第二件是去讲中的嫉妒，我总觉得是很根本的原因。之前《嫉妒① 动力与弱点》这门课程中我讲到，强烈的力量维度和善意的道德维度，来的人的个心理维度。如果说金钱是什么隐喻的话，那么最重要的隐喻就是力量。的力量，人可以支配的越多，这就意味着她的力量越强，在能量力量时，第一重要的因素是权力，可权力比很多东西都，也也不能很好地量化，特别是当家的权力处于相对水平时。但金钱不同，是一个很容易量化的指标，谁多谁少，一目了然。因此，金钱很容易引起人嫉妒恨的嫉妒。

力量的强弱，也可以延伸出一个很好诉的维度，就是谁高谁低，或是活在全能自恋中的人，更容易在乎关系中谁高谁低。基本落在一些关系的人，会希望永远都是高他人，可他们也会知道，在另个时候别人会高过他。同样，在一关系中，人会想自己而那样显得更有力、地位更高的人，会是的很不得对方去死。

这样一来，就引出了一个很深的矛盾：我不能接受别人比我高，又不敢比对方高，那最好就是我们彻底平等。

我们再回头来看安娜妈妈的，故事，她说，一万或千了是很好，但总比被车撞了或得了不治之症要好。这意思显然是如果她真赢了一百万，就可能会像某种力量惩罚，而撞车或病治之症。我认为这种意思，可能是他想念中的别人的嫉妒。

露易丝·海讲的赢了500美元然后摔断腿的学生，他的隐喻也更明显，你赢的500美元，这可以用以隐藏更清楚完整的表达是，作为学生我就是一个客体500美元，然后他摔断腿，他认为可以传递在这个集体传递这信息：别嫉妒你，别伤害我，我根本没有那么多力量。这样我第一句听到，这一点令我的来访者，每次挣到一笔钱都会捐出去一些，我也认为是在向某种力量传递同样的含义。

力量强调这个维度来看，金钱恐惧的强弱，可以从自己，有所处的情家庭或家族许奖励竞争吗？虽然我们现在特别强调成功，家长为了培养强者的竞争能力，让他们去争第一。
