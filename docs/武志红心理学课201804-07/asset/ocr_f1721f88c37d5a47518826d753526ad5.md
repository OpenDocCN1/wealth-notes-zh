# 学习方法

# 1. 从「发刊词」、「亲爱信」开始，找到坐标

如果你是刚刚来到这门课程，我给您一个小建议，你可以点击下方链接，先来看一看「发刊词」，从中你会明白开设这门课程的发心和目的，以及学习课程后会为你带来怎样的收获，然后带着明确的目标开始学习。

一键查看：发刊词｜拥有一个你说了算的人生

此外，建议你也看一看写给心理学课同学们的长信，里面系统地梳理了所有300多讲课程的结构和逻辑，你可以知道每一主题的特殊意义。

一键查看：亲爱信｜心理学课同学们的长信

# 2. 拿好两张「地图」，理清脉络

心理学课共13个主题，它们之间有着不同的承接和主题关系，所以，为你准备了一张结构图。

![](bbox=[0.15, 0.57, 0.85, 0.71])

如果你是刚刚加入心理学课，可以带这张图，理解不同主题的关系，展开学习；如果你已经学完了主体课程，也可以根据这张图，去回顾复习不同主题下的具体内容。

此外，你还可以查看心理学课的图表（请在文末查看），主题、章节、每一讲都一览无余，有计划地开始学习或者复习。

# 3. 以「复盘」为抓手，时常回顾复习

课程每一个主题结束后，都会进行复盘总结，可以通过复盘内容，去重温自己学到的一些知识，每一个主题都在“打包”，内化成自己的学问。

如果你对某个知识点掌握不够透彻，复盘里面包含了主题中所有文章的链接，你可以去复习巩固。
