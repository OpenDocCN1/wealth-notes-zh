# 情结

荣格

情结（complex）是带有个人无意识色彩的自发包含，是因为心灵伤害造成的。

个人无意识的内容主要是情结。指个人无意识中，对道德或责任有过大自责的潜意识内容。情结多属于心意识的内容。

创伤性的体验，情感困惑或道德冲突等，都会导致某种情结的形成。弗洛伊德的原欲与情结和荣格的自恋情结等，都是十分著名的例证。

参考课程：《预告：让情绪流动》

# 人格与阴影

荣格

“人格与阴影”指的是：我们每个人都有一个外向的人格，和那个内向人格的那个部分，也就是“阴影”。

它们在意识中的层次，甚至可以说是多么深切的难以触及的代价。

更感性的阐述是：你看得到A，就意味着你看不到A。当你在一个人身上看到了这一面时，就意味着你同时也看到了它的相反面。

参考课程：《预告：拥抱人格的对立面》

# 房树人测验

荣格

房树人测验（Tree-House-Person），是投射分析技术的一种，早期用于治疗自闭症，始于John Buck的“画树测试”。这一测试是通过要求受测者在一张纸上画房、树、人，来分析其家庭关系、事业、人际关及自己认知等方面，目前的论述主要来源于荣格的意义。个人意识和集体无意识。

+   1. 房：投射家庭，代表安全感；
2. 树：投射自我成长，象征生命能量和支持系统，象征事业和学业；
3. 人：投射自我形象，以及人际沟通模式。

参考课程：《关系03》你可以画，也可以~A)

# 集体无意识

荣格

被一个文化共同体所承认的心灵内容，就是集体无意识。

被一个文化共同体所排斥的心灵内容，就是集体有意识。

高出海面的一些小岛屿，代表了一个意识；小岛屿下面相连的陆地，代表着个人无意识；而所有的岛屿合在一起的深海，就是集体无意识。

参考课程：《知晓04》集体无意识的提出）

# 抱持性环境

温尼科特

好的父母会提供抱持性环境，当孩子表现出愤怒时允许，当孩子受到伤害时提供代补偿。

抱持性环境，是孩子最初获得的一个外部容器，孩子把这个抱持性容器外化到自己内部，最后形成了自主和稳定性。

除此之外，如果父母还难以允许孩子的活动在自己内部获得内稳定性，那么孩子的自我满意度、自我力量和自我组织力等都会得到极大力量。

参考课程：《自我06》让你的本部喷涌而出》

# 足够好的妈妈

温尼科特

足够好的妈妈（Good enough mother），指的不是能力是能的完美优秀的妈妈，也不必是完美妈妈，刚性的就可以。

国内精神分析学家客观把它翻译为“60分妈妈”。

是足够好的妈妈，在婴儿初期，有一种特质，叫做“原始母爱专注”。

参考课程：《关系06：心灵感应与深度同理》

# 原始母爱专注

温尼科特

原始母爱专注（Primary maternal pre-occupation）在婴儿与母亲关系的特别发展阶段，“足够好的妈妈”给予婴儿充分保护所需要的一切。

母亲依据她的孩子需要的变化和改变，不在孩子的依赖持续增加时要逐渐减少。

为了强调对母亲需要的强烈变化，这个词语还暗示母亲需要的改变。母亲的关爱专注，是逐渐随着孩子的需要，好像是孩子自己的一部分需要一样。

参考课程：《关系06：心灵感应与深度同理》

# 真自体与假自体

温尼科特

真自体的人，自我是围绕着自已的感觉构建；

假自体的人，自我围绕着别人的感觉而构建。

真自体的人，会尊重自己的感受，不会太为难自己；

假自体的人，则会主动去找寻别人的感觉，并迎合别人的感受。为别人而活，他们对别人的感觉敏感，却对自己的感觉无动于衷。

参考课程：《自我14｜真自体与假自体》

# 客体稳定性

温尼科特

客体稳定性，是指维持客体稳定形象的能力。特别是维持客体稳定的“客性稳定性”的概念。因为没有人有“客体稳定性”的能力，所以“客体稳定性”是“发展性”游戏，但那孩子长大后又形成了这个能力，但这个时候孩子已经玩了不够了。

有了“客体稳定性”概念的孩子，就意味着“心中住下了一个住的人”。当他在一个客体性存在之后，一个人才有了真正承受关爱及体验的能力。

参考课程：《动力08：攻击性的意义》

马丁·布伯（Martin Buber，1878-1965），犹太人，出生于奥地利维也纳，哲学家、翻译家、教育家，宗教存在主义的代表人物，主要著作有《我与你》、《人与自然之间》、《两种类型的信仰》、《善恶观》等，是20世纪著名的宗教哲学家。《我与你》为马丁·布伯的主要代表作，对现代西方思想产生了巨大影响，已深入到哲学、神学、心理学、教育学以及各门社会科学之中。

# 我与你、我与它

马丁·布伯

马丁·布伯认为，真正决定一个人存在的关系是自我与世界上各种存在的事物所发生关系的两种主要方式，即“我与你”、“我与它”的关系。

“当我把你当成达成目的的工具而忽视你时，你在自己与我之间设立了‘它’，这时就构成了‘我与它’的关系；

当我放下所有的预判和期待，带着我全部的真实自我和真真诚诚对待这时就构成了‘我与你’的关系。

参考课程：《预告：我与你，我与你》
