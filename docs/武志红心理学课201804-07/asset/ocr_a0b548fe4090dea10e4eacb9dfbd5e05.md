# 加餐：升级你的生命尺度

我讲这个单元的专题是“金钱的陷阱”，这是个非常著名的加餐课程，题目是“升级你的生命尺度”。

人，是万物的尺度。古希腊哲学家普罗泰戈拉如是说。而有这样一句话：你的感知，就是丈量你自己命运的尺度。

我来先给你讲一个故事。我的一位来访者，是个超级宅女，她有一些轻度的强迫症。例如，有一次她在淘宝上看到2.9元一打的圆珠笔，感觉两打，还都有几支笔真是超值，非常划算，可以，她本来十块圆珠笔都没用完。然后她买不买呢？所以她再考虑了一整天，会怎么样？但就是，她想：‘我的钱太少了，花了两块九就少了两块九，万一下周急需买笔的时候呢？’她就这样思考了一整天，最后才出了一个最佳的选择。必须要交代的是背景，她没有工作，家庭也比较不富裕，她是在花自己积蓄，并且积蓄也确不多了。

在我们的咨询中，她特别想和我探讨怎样才能是一个最优化的选择。可是只要她一和我探讨，所谓最佳决策已经荡然无存。因为，她只要不便宜，一分价格就远超2.9元。如果待时间过长的话，这样探讨也有价值，以了解她的心理机制，她就可以在未来以后的类似情境中做出更好选择了。

和她探讨了许久之后，我发现她没把“时间是否值得的”这个因素考虑进去。我仔细一想，我的确是不值的，因为她一工作就一星期的时间确是少值的，哪能花一整天时间思考一块2.9元人民币的选择，有一定合理性。

和她继续探讨时，我想到了“选择尺度”的概念。继续选择时，我们自然都有各自的尺度。而这些尺度，有源于自己的生存体验和认知的，不同的生命感受不同和不同的认知和导致的尺度感不同，然后在做选择时就会有不同的选择，因此也导致了不同的人生命局。

像我的这位来访者，她曾经考虑过一份工作，月薪为3000元，她觉得太少，不足以改变她的人生格局。可是，一旦她有了这样一份工作，考虑到个月一般会有22个工作日，那意味着她一天会有一百多元的收入，而那边再遇到2.9元一打的圆珠笔时，她的选择尺度就会发生变化。

有些人有清晰的变化，会这样思考：我一天都会挣一百多元，所以我拿一天去思考一个2.9元的选择就是，非常不值的。即使没有这样的清晰概念，你也不是在这个框架下产生的，你仍然会有不同的选择尺度。

这样说，还因为这个来访者不是典型的强迫症，她的思考只是一种现实性焦虑，如果是典型的强迫症，那么控制性的不安感，而不是她自己认知不到的潜意识，这样分析就意义不大了。

从2015年下半年起，我坐飞机时，差不多就只坐头等舱了。讲清楚的是五星酒店店，这点令我无法去讲座的标配。刚开始这样做时，我一样有焦虑，觉得自己自己在浪费钱，虽然我身形有点胖，但我感觉我基本那个胖乘客的形象就要消失了吧？下，我坐了几次头等舱后，我就接受了这件事，因为它的确有几个真实的好处：

+   1. 空间、头等舱有专门通道，排队快；
2. 去早了，有专门休息区；
3. 舒服，可以好好打电话：2016年我做得疯狂一半，经常在全国甚至国外飞来飞去时，在飞机上就已经完成了一件重要的事。
4. 宽敞，可以非常方便地读书，或使用笔记本电脑。

体验到这几个好处后，即便我自己掏钱，也一样会坐头等舱头等舱了。这就是衡量选择时的尺度变了。

形成选择尺度这个概念后，我想影响选择尺度的因素有两大类，有理性因素和心理性因素。其中的理性因素有以下几个：

+   1、时间的尺度，你单位时间创造的价值越大，时间的尺度就是重要。
2、空间的尺度，你进入到空间越大，空间就是越丰富，这个能会你有很强的阅历与体验，这会很大地改变你的尺度。
3、关系的尺度，你愿意为不同性质的关系，付出什么样的努力？这一性质我己深有体会，我见过太多，但作为“好人”，我很依赖绝人的，所以在很多方面别的要关系的时上，消耗了大量的时间金钱。现在各种事各种关系，如湖水一滴滴水，通过我不断升级拒绝拒绝别人的能力，越来越重视到底要让自己生活在什么样的关系中。
4、身体的尺度，还是以我自己为例，我作为“好人”，做出前端的选择不算少，其中一个因素在时是太复杂了，身体有一个轻度的肠道，让我醒悟过来，发现事情必须做出改变。
5、金钱的尺度，之所以把这个尺度放到最后，并非是因为它不重要，它其实是一个根本性的尺度，前几个尺度，都是和这个尺度联系在一起的。你拥有和处理金钱尺度越大，对你人性考验也就越大。

金钱、时间、空间、关系与身体，这是考量选择尺度的一个思想框架，它们可以合起来理解其的尺度的概念，你想改变你的人生格局，就可以在这几个因素上努力。

此外，选择尺度还有一些心理性因素，包括阅历、觉知和想象。

# 阅历的尺度

阅历丰富的人是不一样的，有丰富的生命体验，他/她的在时间、空间可以饱满具体，在金钱时，也因在可以跟感受，人生格局上都非常遭遇各种考验，如此知道己的分量，能更清晰、更快做出更合理的选择。

商业虽然总被我们社会所诟病，但商业是一个逻辑相对清晰的世界：你必须把事情做好，尊重金钱的人性规律，才能真正赚到钱。而且金钱的世界，它有非常大概率被打败。所以商业可以很好地锻炼一个人的某些心性。

所以，打开你的世界，增加你的人生阅历，丰富生命体验，这是必要的。心田打开，经过真切的体验，才能更成熟地形成符合人性的选择尺度。

# 觉知的尺度

阅历并不必然会改变一个人，很多人尽管人生阅历发生了巨大变化，但他们处理人生并发生真正转变，他们仍固守在自己尺度的上，于是他们的人生也像没有变化一样。

美国心理学家斯科特·派克提出了“心灵地图”的概念，认为人需要在外在创造心灵地图的同时，及时地修正内在的心灵地图，否则会出问题。

例如，之前课中提到过我的父亲家的金钱观，我从小就有中两个的地图，一个家庭内的地图，爷爷奶奶不允许他强大，一个社会的地图，他放他的车钱有钱买车是有尊严的。但改变发生，事件发生了变化，可父亲的认知地图上，导致他的人生尺度变化不大。

# 想象的尺度

想象，可以是一个无限的尺度。尽管你事实在某个一个比较狭窄的物理性尺度的中，你的金钱、时间、空间、关系和身体的因素都并没有进入到很大的格局中，但你也可以先想象了一个大的格局。所以，马云可以预见了互联网的威力，以坚持不懈创造了阿里巴巴。

我再来说述自己的一个小故事。2009年，我在广州建设了我心理咨询工作室，一开始我的构思就是：坏境不能舒适，像家一样，装修的钱不少计划：一开始就计划了心理咨询师的舒适办公比例，因此我添置了优秀咨询师都断了自己工作室的念头。我咨询求助者，来访者咨询我来咨询，这取决于他自己和我的咨询的专业度。

这是我第一次做老板，后来看了同行开的心理咨询中心才多少，我必须向心地说一声，我投的咨询量相对我算的很多。虽然我没实现咨询量，但我想象的一个气象大气的心理咨询中心，最终也得以实现。

从根本上说，一个人的外在人生格局，就是由一个人的内在想象所决定的。
