# ## 现实10 | 金钱与嫉妒

武立虹

我这个单元的主题是“金钱的隐喻”，这是第三讲，题目是“金钱与嫉妒”。

这本书讲到一个很重要的概念“嫉妒”。琼森，是我奥林匹克精神分析师兰尼·克里斯提出的概念，她有一本书，书名就叫做《嫉妒与思考》，专门来论述这个概念，这本书是一本极好的书。不过对于非专业人士而言，可能太艰涩了一些，所以不是特别推荐。

嫉妒，听上去很像我们所说的“羡慕嫉妒恨”，但它其实有很特定的含义。它的英文是envy，意思就是我有个东西，我也想要拥有，可我想要那个东西我也没有，所以只能跟剥夺它，可惜嫉妒存在，于是觉得拥有了它，于是想毁灭它，它带有破坏性，同时它也把自己给毁坏了。

昨天讲的故事中，其实都是在讲嫉妒的故事。如果，嫉妒在现实中世界不是很常见的存在，那么，在潜意识里对拥有物的人会很别人的嫉妒，担心别人会过来掠夺它，毁掉它，同时它也把自己给毁坏了。

“嫉妒是深深刻，最根本的一种死能量”

嫉妒的根本在于我觉得我创造不了也拥有了个好东西，同时，受全能感受的支配，我不想落后，那怎么办？办法是光嫉妒亏你好东西不行，因为光对好东西仍然感觉有所不如，那就我最好把你好东西夺过来，连同创造的那个好东西的东西，一并毁掉，这样我就比你高，比你强了。

原来我一直理解不了，为什么历史上改朝换代的时候，项羽一定毁掉巨鹿？当理解了嫉妒这个概念后，我觉得自己找到了答案，这应该算是嫉妒。我创造了你的宫殿，不厉害，就是我想我本就想创造了这个宫殿，看它我让你就有自卑，觉得你比我能，严重伤害了我的“全能神”的感觉，那干脆就毁了。

原始的嫉妒必然是发生在母亲与婴儿之间，精神分析家认为，母亲有一个丰盛的乳房，才是“真正的嫉妒的象牙塔”。这个说法就是弗洛伊德，这里的意味就是极为美好的地方。当婴儿与母亲不能建立起连续时，婴儿母亲的这份丰盛与强大产生严重威胁男人的全能自尊。

常与嫉妒相伴的是贪婪。不过，贪婪还是要比嫉妒专一点的属性，因为贪婪的意思就是要抢夺占有你的好东西，所以我并不想毁掉它。

嫉妒，就更是一种层次的人性了。你有好东西，我在另一方面却强于你，我嫉妒，但多少知道我和你有边界，我不会去毁掉它。

如果一个社会和文化中，嫉妒过于浓烈，金钱恐惧或者说强大会恐慌症就会很常见，至于一个群体或个体，拥有强烈的嫉妒，即会导致这种恐慌症。

例如，嫉妒、吃醋等故事似乎是关于女人做的，看起来，好像女人的嫉妒更强厉害，但这是错的，我们人嫉妒的根本原因是，现在基本上还是男性社会，女性还没有完全全身得到平等的待遇，还有一些女性在金钱获取上受到压迫的男性相对而言不允许拥有“自强大”这个最美好的东西。

而且，在某些女性对财产权也不能很好地掌握，例如女性没有拥有土地的权利，也许是因为自己母亲的，于是，嫉妒的本身使“我的创造也也拥有了好东西”，在女性身上就不会强过男性，但也显得比男性的“羡慕嫉妒恨”要柔和的。但是，不可忽视的，最原始的嫉妒就是婴儿对母亲乳房的嫉妒。

我在和我的精神分析师说我的金钱恐惧症时，我需要谈到我的收入、影响、名和地位，这时他会问我：“你谈这些的时候，在我和你之间，也显现了你比我有钱，你比我强这种感觉，这带给你什么感觉？”

最初这样回答他的时候，我全觉得自己像“比性心理”这种感觉，我全觉得不像在谈数字和客观事实。后来我逐渐看到，其实这些有时是有一些不安的，再后来看到这些不安背后是一些恐惧，当意识我我也在我的分析面前争什么，而一旦涉及到金钱名利这些现实世界的东西，我即退缩了，我这些都是假的。

我会注意到——当谈到这些东西，我就会屏蔽掉情绪感受，也就是三种心理过程，情绪过程，貌似只剩下理性的思维过程，可是我的身体就“出卖”了，这个时候，我的身体都会显得有点僵化，这是一种自动的举动，这样是在向他表达距离。

因为对钱这种恐惧，金钱或利益打击就是一种很高级的谋杀。我们看互联网上流行的一句玩笑话：“何以解忧，唯有暴富。”但我觉得实际上暴富未必是一种祝福。

我们上一节课程中讲到，美国的一项调查显示那些在彩票中大奖的人，75%的人五年内破产，这方面的故事和研究有很多。例如个别方面的农民因为研究还很多还获得巨额，却折返巨款后的后半内，因自杀和患重病的人就高达21人之一，还死了一百多死亡的，有些人是一个人觉得算算是暴富的一种“诅咒”，钱真的是可以毁害人的力量的东西，可一下子暴富的人，还会有学会如何和金钱打交道，驾驭不了，反而被它控制住。
