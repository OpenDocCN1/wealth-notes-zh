
可以说是一种地地道道的“输在起跑线上”。单纯的脸，常常就是一张顺从的脸。顺从的人，必须简单，因为一旦有了复杂的智慧和力量，就不可能再去顺从了。

# 加餐：中国式关系中的“葵花宝典”

**武志红**

这是“现实”主题下的第一单元“单纯”，这一讲是加餐，题目是“中国式关系中的葵花宝典”。

这一讲我们也是从一个故事开始。

有一位非常有力量、也很有魅力的女士，她有一个憨厚有魅力的丈夫，同时她也和一个她一样复杂有魅力的情人。在这个三角关系中，她一直很少照顾自己的丈夫，觉得自己很爱也很在乎情人。

在一次咨询中，我请她谈谈，她理想中的爱人是什么样的，可以用欣赏观也可以用管理道，我请她谈一下，这位女士本来是想谈一个超级完美的人，所以这份自画像很容易。几秒钟内，她就一一列举了以下几个条件：

1. 要帅，要有肌肉感；
2. 要像白马王子一样，对我好，其实是黑又王子都接受；
3. 要有社会地位，要有很多钱；
4. ……

她列了很多条件，最后列出的条件是“愿意做家务”。

这些条件中，“做家务”是最不起眼的条件了。但接下来，我请她一一删除这些条件，也就是当她不得不放弃某些一个条件时，哪些条件是最愿意放弃的。然后很有信息的矛盾发生了，她发现最愿意删除的条件，其实是“愿意做家务”。由此她明白，她老公的实际重要性远远超过她的想象，而表面上符合她条件的情人，其实只是一道配菜。

说到最后，我对她说：看来你想找一王子，而她愿意为你做家务。她若有所思地说，她丈夫其实也很对她，但在两人所说的关系中，逐渐变成了一个二十四孝老公，实际上，在谈恋爱时，他就是这样。

这样的故事可多了，我逐渐总结出这样一个说法：中国式恋爱的绝招是把对方当婴儿一样照顾，当神一样崇拜。

然后我也发现，互联网上流传的各种迎合女人发疯梦的文案，其实都是在讲这个东西。现在中国，也的确承认认可进进的男人，他们极善于照顾女人，但同时他们也花心至极。

我下的观念不断延伸，后来我总结出，这个现象中国式恋爱中的绝招，也是中式关系，或中国式存之道的绝招，只是刚才这两点还不够，如果再加点一点就以达到葵花宝的级别了。这一点就是：有一张愚忠的脸。

这样一来，我认为中式关系的“葵花宝典”的完整神就是：把对方当婴儿一样照顾，当神一样崇拜，同时自己有一张愚忠的脸。

单纯，是一个很好的词，简单，就是一个中性词，而一旦变成“愚忠”这个词，这个人很难接受了，可思虑太多了，这三个词在一定程度上是一脉相承的。

上一讲课程中我们谈到，我们在社会中，无论家长是如小儿童，都希望孩子能长大成人，因此婴孩期不余地希望孩子的。逼迫和顺从，也就是中式关系的一个基本特征，也知道，强迫的目的是希望他顺从于我。

那反过来，如果我们表面上去顺从大家的这份需求，然后我从中等挑人，也就会得到所谓顺从的中式关系中的人的绝招的信悟，并把这种使用得淋漓尽致，因此获得了成功。

为什么有一张愚忠的脸呢？因为逼迫和顺从中最有的一类，忠是一种顺起，就会不愿意顺从，顺就顺从，那是压抑和屈辱，所以你必须要有方面是愚蠢的，这样才可能顺从他人。这种算计，在中式关系中也太常见了。

例如明朝的大太监魏忠贤，我们的影视作品中描绘他，你看他极易会刻画出他极聪明狡黠又智极高的人，但很可能最重要的特征不是智智，而是完美地实现了这三点：他不敢当人一样暴躁，当神一样崇拜，同时又有一张愚蠢的脸。

我们容易攻击吕布顺忠的人，但这的人如果更多一些可能更好，因为这样一个社会就可以明白这种式的人到底是怎么回事了，然后去寻求追求“你要心甘情愿地顺从于我”这种东西。

同样的，我们还可以做一个推理：一个人既顺从，又愚忠像心甘情愿一样，那很有可能又因的是他自己的智商。

用稍神分析的模式来说，就是他启动了“自我功能的中断”这种自我防御机制，而即抑制的，就是自己的智商。

我觉觉得那个时刻，他的智商是关闭了一样，在妈妈门口等个三小个时的愚蠢行为，也许本质就是一种顺从。太听见的，很容易出现一种思维，在根大上都想你什么，而所想的也不得不根据这上放弃这根本动力，那如果把自已再慢一下，是没办法这样做的。

如果你在养育一个根为，你一开始就让他顺从，还是希望给他这种感觉：世界有足够好的他的本能嗨响而做，这句话也是心理学派尼斯特说的，我在中国的课中中提过它，我现也在逐渐形成了自己的表达，在这里分享给你：

# 问答：幼稚、单纯、世故和成熟

**武志红**

这一讲是我们专栏的问答时间，我先分享一下我的感悟，再回答一些用户的问题。

我的这个感悟来源于我仅有的一次相亲经历。说实话，我有点点头约，我感觉自己条件说得还过去，但是不知道为啥，没有人给我介绍相亲，这是我仅有的一次。

在这次相亲中，我讲了一句很有感受的话：成熟有两种，一种是掌握了现实规则的成熟，一种是人生性的成熟。

我就不给大家讲有秘密的相亲故事了，我要说明，毕竟没有秘密的人是长不大的孩子。

我想继续给你谈简单和复杂。很多用户在留言中提到，如何定义单纯、简单、幼稚和复杂这些词。

这是一个好问题，就用我刚才这句话感悟，和管理学院中向向东老师不断使用的‘四象限坐标图’来区分下简单与复杂。

点击试听：宁波大学·海洋学院管理理学·《学术领导的极简指南》

制作一个四象限坐标图，需要有两个维度，结合本单元的‘复杂与单纯’这个主题，以及我刚才说到的感悟，我认为可以有两个维度：一个是内在人性的幼稚与成熟，另一个是外在规则的无知与掌握。

这样一来，就可以区分出四种模式和我的定义：

1. 内在人性幼稚，同时对外在规则无知，这是幼稚；
2. 内在人性成熟，同时对外在规则无知，这是单纯；
3. 内在人性幼稚，同时掌握了外在规则，这是世故；
4. 内在人性成熟，同时掌握了外在规则，这是成熟。

![](img/1c8805f81e6502071128412767cb1966_57_0.png)

世故和成熟的人，都是复杂的，而幼稚和单纯的人，都是简单的。

四象限坐标图是很有用的工具，我觉得可以在这个坐标图上继续发挥一点创造性，我们可以在坐标图上坐标的原点，也就是在内在人性和外在规则都为零的这个位置上，这是一种原始的合一，而在内在人性和外在规则得分都很高的位置上，也会存在合一的可能。

这样的人，就可以达到王阳明的境界，不仅证悟到天道即理心“致心”之外，则无它了。而且悟得‘此心无’，随缘而应。到了这种境界，就是最简单，也是最复杂，简单和复杂由此统一了起来。

**我自己尝试回答这个问题，而在我的原生家庭里，这种好人是被贴了无比正确合理标签的，我也因为好人的形象在原生家庭里获得更多的爱。而一开始先生在我面前时表现出的好人形象就像他在面对家庭以外的人一样，所以这种形象自然就吸引了我。而当进入婚姻生活后，先生发现我是个好 人，所以很自然地就把他在原生家庭中坏人的一面毫不费劲的展示出来，不知道我的理解是否正确？但是对于为什么长期以来我在工作中之能展现坏人的一面，先生在工作场合却一直给人好人形象还是没有找到合理解释，可否请教老师呢？**

# 预告：从想象世界到现实世界

**武志红**

这是“现实”主题下的第二单元，本单元的主题是“从想象世界到现实世界”。

“现实世界是有疗愈性的”，最近两年我常常在我的文章中使用这句话。这是什么意思呢？

这首先是来自于我对一些问题很严重的来访者的观察。这些来访者，他们通常看上去非常简单，但同时他们是封闭的。有的来访者，他们可以看到自己内在有非常黑暗可怕的想象，而有的来访者，他们意识不到这种内在，但随着咨询的深入，这份黑暗可怕的想象会呈现出来。

对于这些来访者而言，现实世界的美好程度，要远远多于他们的内在，所以当他们逐渐走出来后就会发现，现实世界是有疗愈性的，他们变得更好了。

其次，“现实世界是有疗愈性的”，这句话还来自于理论。每个人都需要把自体的生命力，展现在与客体的关系中，只有这样，生命力才会被驯服。这意味着我们必须进入现实世界，真实地呈现自己并与各种存在去碰撞，这虽然会显得非常复杂，但却可以让我们变得更好。

第三，在精神分析理论看来，人的发展是需要经历这样的阶段：最初每个婴儿都活在孤独的幻想世界中，然后进入妈妈或其他抚养者构建的过渡世界，在这个过渡世界中初步走出幻想世界，整个家庭都像是一个过渡世界，孩子在这个世界中学习如何展现自体，并与客体相处，最终，孩子进入到现实世界。

第四，在我看来，即便非常成功地完成了社会化过程，非常好地进入了现实世界，这个过程并未结束。按照英雄之旅的概念，整个家庭和社会构成的现实世界，都可以理解为过渡世界，一个人在这世界中不断学习，最终发现，自己的内在想象和外部现实，竟然是一回事，由此证悟到了合一。

我们这一单元就来谈谈这个过程。本单元的调查是，你在什么时候有发现过，更深地融入社会让你变得更好？

分享两段鲁米的诗，先来给你读读第一段：

渴望是神秘的核心
渴望本身就可以疗愈
忍受痛苦，这是唯一的法则

下面是第二段：

你必须训练你的愿望
如果你想要什么
那就先奉献什么

我个人认为，这真是妙不可言的两段诗句，这的确是一个人的内在想象与外部现实之间的根本规律。
