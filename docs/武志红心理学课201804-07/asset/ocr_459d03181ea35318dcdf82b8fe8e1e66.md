# 问答：总感觉不到自己怎么办？

问答：总感觉不到自己怎么办？

+   武志红

今天是我们的问答空间，我先来集中回答一类问题，这是我们专栏中最容易被问到的一个问题。

武老师，总感觉不到自己的梦想怎么办？

说到与身体地接受自己内心的声音，可我发现内心内批评的声音冲淡实际，自己的感受在内心的声音就弱到难以察觉，怎样才能清晰那些批评来的噪音？静静思考真正的内心深处声音？冥想？感受身体吗？现在还是摸不着头脑。

这就是一个问题。首先我想起过《真自我来身份合一》，这篇散文中的一案例，我在采访孙博时，她是有读中文专业的，我问她是如何判断的，她回答说：我不判断，只感觉。

这句话的意思是，我不用‘头脑’去分析判断，只用‘身体’或心灵直接去感受。

孙博的这种状态，我羡慕不已，这种境界真是少有。我虽然在很多地方能尊重我的感觉，但离她的境界还是相差太远。

同样的，我想很多基本上一直都在使用头脑的人，你们的确不知道自己的感觉是什么。那该怎么办？

一个办法是去聆听自己很弱的感觉的声音，如聆听身体，聆听声。

还有一个可以使用的方法是，过于使用头脑的人，可以去注意那样被你视为严重的人格缺点的东西。他们常常是你的声音。然后，可以尝试在一段时间内，彻底允许自己去除这些缺点来。

例如严重的拖延，这样的人会用头脑脑分析批评自拖延，但你会发现都是无济于事，因为众多‘内在批评声音’常常就在内在的父，而那个试图拖延的部分，就是‘内在的自我’在投。可以好好试一下，在没有任何的影响下，就给自己一段时间，彻底地去拖延。

这是迪士拖延策略的一种延伸。我们心中常常同时有几个矛盾的声音，同时出现在一个时空间，然后纠结在一起，谁都不能发挥作用，迪士给我们家可以现试，当把批评与分割开，我们就可以实验试，当把那些纠结的声音分割开，例如分别给批评者和拖延各一个空间。

当然请记住，这样做最关键的一点是，我们需要内在这批评者拿开了。
