关系，关系势必都会出问题。

再接下来的《你的需求不是罪》这节课中，我既从普通人的角度，也从哲学的角度谈了我需求就会带有罪恶感这个观点。我认为这是很彻底避免的，因为需求将关系从“我与你的”高度，降到了“我与它的”地步。

再接下来，我谈了一个特别主题《让你的声音流动》，这也是极为重点的部分。观察一个人是如何发出声音的，可以推断他在原生家庭中是如何被回应的。

流动，是动力发生在“我”与“你”之中，这意味着“我”的内在世界和“你”的外部世界是自由地发生着交互。人类的一切需求都蕴含着这种内在与外的交换，而一个人如何感知他的内部世界和外部世界的关系，会影响他对这种交换的自由度。所以，一切交换也会有这种隐含的自由度。

在我们能有意识的一些重大交换中，呼吸是最不需要条件的，所以，当一个人能坦然地呼吸时，那也意味着他内在世界和外在世界的关系是比较和谐的。呼吸有了障碍，可能的反应是你与世界之间有了敌意。觉得外部世界有“毒”，也就是敌意，可还不呼吸。自己内部制造“毒”，也可能不得不吸气。但是，可以制造障碍。

呼吸的这种隐脉无处不在，可它是如此普遍，我们并不容易意识到，但你真可以觉察一下，假如你自由地呼吸可以很简单，而你的呼吸到了这种状态，说明你在这个时候你的内在和外部世界的关系是怎样的。所以，自由并不容易。

# 无常

# 第一单元：无常，是更大范畴的自由

自由，再前进一步，就是无常。无常，通常理解是变动，万物每时每刻都在变动中，但我们的无常是死亡。

这一单元的内容讲的是“自我”也就是头脑自我的死亡，而下一单元的内容讲的则是肉身的死亡，也就是通常意义上的死亡。

人很容易固守着这种感受“我就是这样”的本色，并且，如果能完全放下自我，你可能会体验到一种极致的流动。至少，我们都要关于自我的定义，同时也是一个牢笼，将你锁在其中。

第二节课《让一切流经你的心脏》，一样也是讲到当一个人地自我不是一个封闭的像墙一样的防御系统，而是能敞开，能让一切流经自己，那种感觉有多好。当我们能特别轻松地做到认识到自我，你就能体验到第三节课中所说的《活在当下》，我们也可以有意识地去体验活在下行的感觉，那就是看着注意力从你的思维上移到，而放在你的身体上，以及你的身体与其他存在接触的感觉。

在第四节课（头脑的伟大之处）中，我也为思维，特别是思维编制的自我防御系统做了辩护，强调它和人性的其他部分一样有巨大价值，特别是当一个人的心灵还不能处理真实的自我黑暗和关系中的隐藏时，通过启动自我保护体系将它屏障掉，让它们不进意识，这是很重要的，这样你才能让自我继续发挥作用，如果防御的启动自我虚弱和很脆弱，像一掌拍碎，你的自我就可能会“瘫痪”，这可能也超出了你的处理能。

所以，不要老看到头脑自我也就是自我死去，让这一切自然发生。

# 第二单元：生命的意义在于选择

最后一单元，我们谈的是肉身的死亡，这个看似极端的无常，以及人是如何面对这个无常。我认为面对的方法就是选择。

我特别讲了《尼奥的选择》这一节课，在《黑客帝国3》中，主人公尼奥做好了主动去死的准备，并最终以此灭掉了史密斯，拯救了人类世界。

在我看来，一个人的心灵是这样一种东西，当一个人选择时，他的内在与外部世界的关系会陷入到他心中，所以，他选择黑暗，心灵就坠入黑暗；选择光明，就会陷入光明。因此，整体上选择了黑暗的人，会陷入，因为觉得黑暗中有邪恶的力量，会吞噬掉肉身死后的自己，而整体上选择了光明的人，会对死亡有一份坦然，因为坠入到光明中，将不那么可怕。

我在这样理解中，我还是要用黑暗与光明对立起来，所以我接着运用衔尾蛇的意象，讲了无常不是对一个又一个个的存在而言，对整个宇宙就像衔尾蛇一样不断在吞吃自己，同时又不是在生长。

当能完整地活出自己，又完整地看待宇宙的无常时，就意味者一个人拥有了对内在世界和外部世界的完整认知，而这样被你成为“自性化”，当你将整个自我都整合进你的“自性化”就会看到你的内在世界和外部世界是互为镜像的。当然，这也许只是一个假设，一个哲学上的探讨。

最后一节课是身心选择中，我讲到肉身的感觉，是你的生命选择的一个评价标准。如果人没有肉身，没有喜怒哀乐，没有疼痛，没有死亡，那么选择就变得容易了，但生命就是没有后悔还有机会的，这让每一次选择变得尤其有意义。

在我看来，你也需要在肉身存续的时间，活出你生命的意义，否则，在肉身向衰老和死亡时，你会经历一种深刻的阵痛；对得起你的肉身吗？
