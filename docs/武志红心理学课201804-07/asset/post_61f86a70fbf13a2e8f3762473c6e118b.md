# 问答：罪疚感，是完整人性的一部分

武志红

这节课是专门的问答时间，我先集中解答一下原来单元用户问得最多的问题，再来讲别回答一些用户的提问。

这个问得最多的问题是：是否存在着这样一群人，他们并不认为“需要有罪”？

人为什么会觉得需要有罪？如何才能让自己内心更自在，更自足的享受或满足自己的需要？激发对方的需要，并将罪感转移到对方是否是一种心理防御机制？

在我的理解中，只要我们活是活在“我与它”的关系中，因为需要而产生的一种罪疚感，是无法避免的。所以，存在“不认为需要有罪的人”。当然，有些人可能会看不到自己的罪疚感，我觉得这可能要带着严重的心理问题，所以，不太希望去把罪疚感消灭掉。

罪疚感，是完整人性的一部分，我们需要体验它，让它流动，而不是将它视为是负面体验去屏蔽它、消灭它，实际上它也不能简单地被消灭掉，最多是压抑到潜意识中，或转嫁给别人而已。

按照马丁·布伯的理论，关系有神性的“我与”的，这个时刻我放下了我的所有期待，也就不用“需要”了，而一旦有需要，关系就会降格为利用与被利用的“我与它”，这时罪疚感就会产生。一有需要，就有罪疚感，这里面有着极为深刻的逻辑，我会在下来两个单元课程中去探讨它。

通俗意义上，当关系双方都体验到巨大的愉悦，并享受其中的时，罪疚感会明显下降，而当关系是一方从另一方身上索取需要，而另一方有损失时，罪疚感就会更重。

所以，父母带孩子时，满足孩子的需要很重要，而在满足孩子需要时，能否让关系变成彼此都享受其中的关系，也同样很重要。当父母带着满足的需要，去满足孩子时，孩子的罪疚感会变得更低。

不过，我个人认为，我们没法在普通关系中去排除罪疚感，而只能是带着它去生活，去构建需要与被需要了的关系，它只能是“我与”的层面上才能真正被消除。

总之，不要试图想把人性中一些不舒服的基本负面体验给消灭掉，而是要让它流动，同时知觉它。

# 单元问答

**需要和欲望有没有区别？**

武志红

这是非常好的问题，这个问题让我感受到得到用户与众不同之处。

实际上，我自己并没有仔细地区分需要和欲望，所以我常常没有随意地使用“需要”、“欲望”和“欲望”这些词汇，但法国精神分析家雅克·拉康对这些词汇做了非常细致地划分。

拉康的欲望理论，将需求分为三层：需要need、要求demand 和欲望desire，需要就是实际诉求，例如婴儿要吃奶，不吃会饿。要求落实到，不高兴，要求吃奶时，不仅仅是要求吃奶，还要疼爱。欲望则是在需要和要求的缝隙之间。

拉康的理论复杂而深邃，他自己也喜欢做晦涩的理论阐述，对他，我的精神分析课程，我了解的还不够，所以很少提及。

不过我可以举个例子。婴儿吃奶时，被喂到了，这是实际需要被满足了，但是，如果是妈妈在喂奶时，不高兴，不愿意，甚至有逼婴儿吃奶的情况，那么，这时婴儿会感觉到，妈妈对你有，进食会让婴儿感到妈妈的奶水有毒，进而导致进食如问题，这是生理需要被满足了，但情感要求却没有被满足。

这时也存在着权力欲望，妈妈是按照婴儿的意志来喂，还是按照自己的意志来喂，这会令着婴儿不高兴，前者会让婴儿感觉到被爱，后者则让婴儿感觉到被忽视，而这种差别背后，是婴儿期待权力被满足。

需要是可以被满足的，而欲望是很难被满足的。性欲如此，生理意义上的需要容易被满足，可如果一个人心总幻想占有最有魅力的异性，这个欲望就很难被满足了。

**在“怕表达需求”下，“怕被拒绝”和“怕欠下人情”有什么关系吗？不想欠下人情，也是怕被拒绝吗？**

武志红

我认为这是为了避免自己的罪疚感。通常，这是源自一个孩子和匮乏的母亲所构建的关系。当母亲处于匮乏之下，她就算满足了孩子的需要，孩子仍然会觉得愧疚，他们会觉得像是自己吃了母亲的一块肉，自己的需要被满足后，而妈妈的资源就少了。特别是如果妈妈还有意识地给孩子制造内疚时，它会更强烈。

怕被拒绝的人，当被拒绝时，产生的是羞耻感，怕欠下人情的人，当他会体验到别人时，产生的是罪疚感，它们会有很大不同。羞耻感是觉得“我真蠢，我怎么傻到向他求助”，而罪疚感是觉得“对不起，我伤害了你”。

**学习了这两个单元的课程，我觉得非常震撼，因为我本身就是种不“喜欢”愤怒、喜欢照顾别人，也不喜欢别人麻烦的人，甚至不喜欢跟一个也难以做别人外，找一个不非常吵闹的邻居，请问我老师这两者没有什么样的关系呢？**

**另外我内心也非常不喜欢这样，一直在尝试改变，包括有时行为先为我找好的“容器”，但有时就是无法拒绝别人，把关系弄得很难堪，请问武老师这种情况有什么技巧吗？**

武志红

首先，既然一直不擅长表达愤怒，那么当你最想拒绝对方时把握不好，会尴尬，那么你最重要的是改变自己的尝试和练习，要有不怕麻烦的精神。

其次，我写过一篇文章，题目是《内耗是对内向者的保护，外向是对内向者的嘉奖》，大概意思是说，如果一个人关系内耗多，不太懂得拒绝别人，那他最好是内向的，因为他不可能一个人，他不擅长跟人，能用人，还能使用成功，那他自然想外向一些，因为每多构建一个关系，他整体上获益的。

**我以前有个上司，是武老师说的非常喜欢麻烦别人人，也受不得别人麻烦的人，他本人是极度边没有用动性，第一眼，很难让人信赖人，边看，动性第二，看出他其实看不起任何人，但对京和一，些小事情会很出心，并且受到：第三，他的一切细节你能看到的举动，都是受人就是。同样也是“爱惜麻烦人”，为什么这种同样有多讨厌，人道“爱麻烦别人”也分境界？**

武志红

没有麻烦，就没有感情，也并不是说去谁无端地爱去麻烦别人，入侵侵犯人，如果是后者，后者会容易引起别人的反感。

在关系中麻烦别人，就是“我”将动力传递到了“你”身上，这种至少是关系开始建立了。这只是上，而不是结束。如果像改性一样，如果一个人不去攻击性，那就什么都不用，但表达攻击性，并不意着直接去伤害别人。

**我们在生活中每天会遇到无数的人，那我们是应该以“我与”的状态去面对每一个吗？还是说我们只对此种态面对一些人？如果是，我们只区分人，那么哪些人呢？是我们的重要他人吗？**

武志红

马丁·布伯说，“我与它”是时刻到到，马丁·伯怡说，“我与它”是时时刻刻，而“我与它”只是瞬间，所以我们不要期待自己时刻都活在“我与它”的境界中。在马丁·伯怡看来，这简直是不可能的。不过，在东方的修行哲学看来是有可能的，但这仍然不是普通人所能实现的。

# 无常02|让一切流经你的心

![](img/1c8805f81e6502071128412767cb1966_129_0.png)

我们这一单元的主题是“无常，是更大范坤的自由”，今天是第二讲，“让一切流经你的心”。

有一位朋友谈起自信和气场，这让我想起了一个故事。每当听到别人提到类似话题时，我很容易想起这个故事，应该是印象太深了。

那是1996年，我还在读大学，跟着北大心理学的老师做了一个“希望工程”的一个项目，用心理学的方法，从来全国各地22个省的22个受助学生中筛选出3个孩子去美国参加当年亚特兰大奥运会火炬接力。

这期间，有一次唱歌比赛，一个来自贵州的8岁小孩（《我们的大中国》）。他一开唱，全场哄堂大笑，因为他的跑调太离谱了。但这个小家伙并不为所动，继续唱下去，哄堂笑声渐渐消失，最终转为安静的寂静，直到安静得可以用一根针落地的程度。最后只剩下他一个人的歌声。他说他是超胆的歌声结束时，掌声雷动。

这是神奇的对决和歌颂。最初，我们向他投射了恶意，“你的歌声很难听，你很差”，但小男孩并没有认同他，而是向我们投射了“我很好，我自信”。

特别难得的是，这个小男孩不是傲气，而是大气。他坐在那，向一位记者投去他的目光。我们都沉默了，不知道这个小孩将会怎样，但我相信他会走得很远。

我记得自己在网上也写过类似的文章，很多同学说他们也有过类似的故事。但为什么没有这个小孩这样的结果？

比如有人讲过这样一个故事：我在大学时参加校会。有个男孩上台唱歌，唱得很难听。他很难听，他完全不知道他唱得很难听。

你听了这两个故事，你觉得那个男孩和这个主人有啥差别吗？

对我自己的解读是，这里要看作主人公到最后为止放的。什么是自闭，自闭是封闭了，但是那些台上的人，他们是开放的。

我根本的需求就是渴望被看见，所以都没有自己的能量场屏蔽。如果屏蔽了，我们就会感到被拒绝，被隔离，被拒绝。

我们的心理学课不断讲容器和容纳，作为一个人，我的自我要很有能力。一方面发出信息，特别是负面的信息。

当一个自我具备这个能力的时候，他就可以像一个容器，外部的信息可以被接收，他的内部信息也可以很好地对外部世界发出，这时一切都处于流动中。

# 今日得到

- 1. 人最根本的需求是被被看见，所以如果我们自己的能量被屏蔽，要么被屏蔽，那我就更感觉不到拒绝，于是很容易转而拒绝屏蔽了我们的人。
- 2. 一个人的自我需要看容纳力，一方面发出的信息，容易是负面情绪，另一方需要接受、容纳并消化它，进而转化成相对的信息，然后传递出去。当一个人的自我具备这个能力时，他就处于一种自由中，外部世界的信息可以被很好地接受，内部的信息也可以很好地向外界发出，一切处于流动中。
- 3. “我与它”的关系中，所谓的“它”就是我的头脑，即可以认识一切，但只有当头脑消失时，敞开自己的全部存在，“我”才能遇见“你”，这是“我与”的关系。

# 无常03｜活在当下

### 武志红

我这一单元的主题是“无常，是更大的自由”，这是第三讲，题目是“活在当下”。

前两节，我都讲到当头脑自我也就是自我消失时，一个人会体验到和最大存在的连接，而这是一种极佳的体验状态。

既然如此，这就会引出一个问题：我们可以通过什么方法，主动地放下自我，去追求这种体验呢？

人类有很多行为，有在追求这种体验的，有在他非常有趣意的，有的看起来他在追求非目的，但其实是追求至乐起来。其中非常有意思的行为，我想为你举一个例子，那就是苏菲旋法。

我们在文中经常引用鲁米的诗歌，他是生活于13世纪的苏菲教派的诗歌，而苏菲旋法，是苏菲教派的一种修行方式，它的具体方式是：按照一种固定的步法，让人不停地旋转，旋转时一只脚跟着跳，一只脚跟着低，头也是有点歪的，但脊柱却整个人保持垂直中，旋转的方向不变，但时间会转着转着。

这听上去有点匪夷所思，那这样旋转的目的是什么呢？苏菲教派认为可以用晕眩，让身体超越头脑控制欲，那么当一个人能动方式来制衡了头脑自我，苏菲教派认为那一刻你会接触到最大的存在。

你想象一下就知道，这是挑战很大的练习。大多数人会非常眩晕，甚至可能会吐不止，并且也没什么可以看见的家伙，但也有人通过这样的练习有了非凡体验，在相当程度上放下了对自我的执念。

在埃及等一些地方，你会看到苏菲旋转被改成跳舞，像是一种优美的式舞，通常是穿白色裙子的裙子在旋转。然而据说在非常严格的苏菲旋法中，人们会穿上裹尸布般的裙子，以提醒自己主动杀死自我。

必须提醒你，这只是为了介绍苏菲教派这种有意识的去放下自我的修行，并不是鼓励你一定要去尝试，而是想了解一下有这样一种形式，是否适合你，需要你根据自己的情况判断。

我们课程之前有讲到扫描身体练习，实际上是借鉴了佛教的一些修行方式，但是去掉了教派和神秘的部分，一般的扫描身体练习，需要打坐的方式，而我们已经是读了非常需要打坐，可能会让你这个练习打折扣，但因为我已经练习了十多年了，也有一些效果。

通过不同的练习，我发现，练习中我会碰到到不间断的“我”。

第一个层次，就是武志红的“我”，当扫描身体进入状态，与身体有了基本的连接后，我发现了武志红这个身体里面的体验有极其为极大量的感知，那种可以放大百倍，特别在各种事情各种关系中的情绪。

第二个层次，是要与身体有了越来越深的连接时会出现，这时，作为“武志红”的那个“我”就消失了，各种各样的故事都本开始自然流动，每一个故事剧本，都至少一个主角，一个配角也有一份力，而且主角可以是男可以是女，可以是成年人，老人或是孩子，也可以是动物，并且他们之间的故事，作为“武志红的“我”必须集中注意力才能听到这些故事剧本，不然它们就像流水一样，过去了就溜走，瞬息万变。

第三个层次，我处在极少数的时间能体到，随着对身体的觉知越来越敏感，我突然进入了一种无思、言语、思维和自我都消失了，是一种境界可言指，因为它的发生，就建立在语言和思维消失的前提下。并且，这也会体验到极度的喜悦。

因为对第三个练习的体验发生，我才变得对扫面练习练习有点遗憾了，每天都做到三遍以上，可这仍然远远不够。

以上我讲到的这些方式，似乎都是逃离生活途径，但其中在生活中心有一些方式，我们来着看起来是在追求一种东西，实际上可能是追求的死亡，例如极限运动。

身边就有来咨询者和朋友对极限运动上瘾，而他们从事的极限运动多类似乎铁人三项之类的运动，有人认为自己是在追求这样一层感觉：当身体达到某个临界点时，自己就要被杀死，但突然间，一种巨大的愉悦和喜悦升起，然后他的身体会重新一周回世界秩序里的感觉。这些感觉综合到一起，让他们很痴迷。

对此从科学的角度和生理因素来解释，应该是到了一个大概会分泌出大量的多巴胺，导致了人的愉悦感。

以上这些方式，都是很特别的方式，如果你从普通想到人看，最想要体验到一种极致的体验，通常需要很长的，花很长时间。不过，令人兴奋的是，我们每个人都可以用一些有趣地放下自我的方式，和当下任何可一个意识建立充满觉知的关系。

这听起来很简单，但其实并不简单，你试离手时，做任意事的时候手肌都成手了，这时，手就构成了头脑自我的一部分，挡在了你和当下事物中间。

我从2007年开始读柴克·哈特利的《当下的力量》这本书，第一次有了“活在当下”的意识，我也第一次体验到了一点点什么叫做活在当下。

当时，我在家里吃饭，正在洗碗。一个碗洗了三遍，竟然还没洗干净，对我自己来说，我很难注意“不过”，如果有一件事在很好地时间注意力“不过”，我就会有意思去，是不是有什么特别的东西发生了。

当我第三遍还没把这个碗洗干净时，我就启动了觉知，然后我会变得很简单，因为在洗碗时我充满愤怒，而且脑子在事情种。我的注意力根本就不在洗这件本上。

当过启动觉知的时候，我的注意力和子意会进入洗碗动作，就是去感知身体和事物，就是去感知身体和事物过程的体验，我感觉到我自己在当下洗碗是一种什么样的感受。

这次活在当下的体验对我影响巨大，后来我常有意地提醒自己，要活在当下，而真正让我感受到《当下的力量》这本书的，我启动了扫面身体的练习，虽然我没有刚柔并济的进行扫描身体，但我一直这么做了。

刚才这一节中，我讲到思维过程和情绪对我的影响，但不能活当下。这可能会让觉知变得混乱和困惑过程都是障碍。它们的障碍是我导致的一些防御，但思维过程巨大价值，下一节我会跟你们思想思维的伟大价值，我们不说思维过程。

如果把情绪过程视为情绪与情感，那么，情绪结果就“我”在关系中的情绪体验的结果，当“我”受攻击时，会有坏的判断；当“我”受伤时，会有坏的情绪。至于情感，就取决于身体和他人建立起了怎样的关系，当体验到慈悲为主的关系时，就有爱。

虽然我们已经说一“放下自我”，但我要提醒你是，一定要注意我是建立在咱们专注一“再讲一下：要能住住“我”在自己“和拥有一个你自己的人生的基础上，而不是，一直想去放下自我，那自己我身上，一开始就活法去死。

相反，我们要特别重视自己的情感，去去分分分分分，大是它开了门，只有这样，一个人才能真正地感受自己的体验，生命很感叹息感叹，那么，这个人也许很大不可能先放下自我，而是先活自我。
