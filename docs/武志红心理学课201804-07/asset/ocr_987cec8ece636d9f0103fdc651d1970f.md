# ### 爱因斯坦的创造力

我们都知道，爱因斯坦有着最顶级的创造力，二十世纪的经典物理学家对关于牛顿力学已经开启了的物理学大时代，爱因斯坦提出的理论简直是让整个大翻。上周专栏内容中我讲到，伟大常常从冒险开始，我觉得爱因斯坦绝对是一个伟大的冒进者。

现在，我也试着冒进了一下。我首先要为你说明的一点是，对于爱因斯坦其实我并不非常了，今天解读他的创造力求来源，并非是我原创，而是来自美国著名咨询师罗伯特·迪尔·托马斯。罗伯特·迪尔·托马斯是国际顶级NLP大师，NLP神奇语言程序学家的编写，他本来是做关于人类行为与沟通程序的一套可行的模式，虽然它本身并不是一心理疗法，但常常被用来了解人类经验的行为。

罗伯特·迪尔·托马斯是我的催眠老师兼课程吉利的策师，他曾在我开一个叫“天才的策师”。他在这个课上详细解释了几个天才的唯模模式。

迪尔·托马斯的观点是，天才的思维方式是你可以模仿的，虽然你很可能无法达到他们的级别，但使用他们的思维模式会让人受益。

例如爱因斯坦，迪尔·托马斯认为他的思维模式的特点在于他不是使用常规化的线性推理，也就是说是他并不是用公式和理论去推导理论的，相反，他是使用视觉化思考的方式。

我也讲过很多次，弗洛格德认为人有两种思维过程：初级思维过程和次级思维过程。初级思维过程的表达是图像，次级思维过程的表达是文字，图像可以不存在，而文字则总是存在的。

初级思维过程的问题是以图像，一个人如果只在这个状态，就可能会忽略事物和其他人，但它可以非常柔和，也即它的状态可以很好，但是不存在寿命。如果你太依赖它，你的思考可能会缺乏生命力，甚至都接触不到真实存在。

如果一个人既掌握了次级思维过程的符号系统，又能很好地使用初级思维过程，就能让想象流能在符号化的存在，同时就会有很高的创造力。

我认为罗伯特·迪尔·托马斯所说的视觉化思考，就是这两种思维过程的综合。

杨振宁在一次接受采访时，20世纪物理学的三大革命，爱因斯坦一个人贡献了两个，分别是狭义相对论、广义相对论和量子力学。爱因斯坦早在16岁时就开始了一个视觉化的想象实验：如果光追束一束光，那么会发生什么？能看到这束光在空间中静止吗？

最终，爱因斯坦认识到光不可能被慢，而且光也离他远去，光速不变，但时间发生了改变。这个想象实验，最终启发了他提出狭义相对论。而爱因斯坦说他，他之所以开始这个想象实验，是因为他做了一个梦，梦见自己在追逐一束光。

爱因斯坦也有很多重要的想象实验，例如“有一个叫“电梯的绝对”，他对物理学不够了解，就不详细地介绍了，简单说，简单来说就是这个想象实验最终启发了他提出了广义相对论。

科学家的创造力来自哪里？杨振宁自己的回答是：“你不需要很多知识，也不需要多高明的数学，你只需要有天才不怕的精神，然后去奋斗，你就成功了。”

这种是一种敢于做白日梦的精神，而弗洛伊德的两种思维过程理论和罗伯特·迪尔·托马斯的观点，我认为都值得一考。

# ### 用感觉去聆听

在“天才的策略”的培训课程上，迪尔·托马斯根据爱因斯坦的视觉化思考，设计了一个练习叫做“用感觉去聆听”。

练习的步驟如下：首先，五个人一组，大家围成一圆；然后，从一个人开始，简单地向下面一位做自我介绍，其他人听关于这个人的一些优点，并说“我喜欢”。

特别强调的是必须是真实的优点，而不是你想象的。例如，不能说“我获得你很善良、很宽容，因为这是一个判断和猜测，不是真实的，这样叙述时，对方心里可能会冷冷一笑：“你怎么知道我善良！”

你可以这样说：“你的头发真美”，“你的皮肤很白”，“你的衣服很好看”等，这些就是真实优点。这样做的目的是为了构建小组成员之间的连接。

接下来，安静下来，闭上眼睛，简单地感受一下身体，静静地跟随。

从一个人开始，讲述他（她）的故事，大约5分钟。听的人不使用思维，只是将注意力放在感觉上，留意听的时候自己产生的各种感受，如他的视觉、听觉、触觉、嗅觉以及其他各种感觉。不管它们看上去多么无意义，都要让它们发生。

一边听，一边把自己的感觉，画成一幅画。你可以画得很常简单，也可以画得非常抽象，总之去表达出你感受就好。

听故事的人讲完后，听故事的人把已自己的画给他看，并告诉他，故事的人把自己的什么这么画，在听的时候自己产生了什么感受。最后，给这幅画起一个名字，写在画下，最后，然后送给讲故事的人。

做完练习后，拥抱彼此，感谢彼此，闭上眼，安静一会儿，然后结束练习。

这个练习，跳过了思维，而让听者和故事直接地融摄的感觉，会有非常不可思议的效果，特别是第一次，练习的参与者会惊讶于对方是怎么捕捉到那种感受的，可能会发现自己其实完全没讲，完全忽视的信息，被对方捕捉到了。

在专栏《让家成为真正的港湾》的内容中，我分享我的一次练习，练习中一个台湾同学给我画了一幢抽象画，深深地触动了我。当我上了一幅，一个深沉的梦，然后直接画出了我一直在逃避的本命命题：我的父母没有能力保护我的家庭，所以我的家不是一个温暖的港湾，有各种入侵者可以进入。

当时这个练习主题讲诉一个梦想，我具体讲了什么并不重要，从该是想成为潜意识想咨询者之美的。按从意识和想层面，我完全没有表达我的家庭信息，实际上都内容在我的潜意识中，在这个练习内容中包含着我，他不知道，用感觉去聆听时，却听到了我潜意识中的这个信息。

这个练习我后来多次使用，很多人都发现了这个不可思议的能力。例如有一次我去一个高级公司讲演，我想办法让公司让各位高讲诉自己的梦想，然后各位公司去打开感觉聆听。然后员工纷纷感知到了他的各种东西，而太多也超出了这位老板的意料。

直接聆听感觉，都是有些危险性的，如果想降低这个危险性，就需对这个练习有所设置。例如，罗伯特·迪尔·托马斯在巴黎的一家工厂，让公司的人一个危机，他就让相同部门的职员们构建一个安全，然后各自的人想法感受，但公司人一样，这是感受，并且每画一幅画送给讲话者。这个经历在很大程度上化解了员工的心理压力。

还有一次我去一家公司，组建了一个小组，请这家公司两位创始人，讲讲他们是什么给公司创建者一个名字。那天，大家非放松，两位创始人也非常平常，而我搭建这个小知，则有意让了几位非敏感的，包括组里有意识的心情非常糟的，然而所有人发现每个人都不从不同角度，收到了两位创始人的各种非常重要的生命线，而且有一些是深重于为他们的意识状态的东西，有的还是隐藏到不可思议的东西。如果我们意识思维去聆听，绝不可能想到听者可以接受到讲者这些信息。
