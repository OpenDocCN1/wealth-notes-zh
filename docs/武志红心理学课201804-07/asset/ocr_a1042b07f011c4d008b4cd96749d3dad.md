# 创造01 | 如何有创造力地写作

![](bbox=[0.1, 0.04, 0.9, 0.06])

武志红

我这周末的主题是"创造，来自直觉"，"今天 是第一讲""如何有创造力地写作"。

今天我就先来先分享一下我的写作技巧吧。首先真正要自诩一下，我不觉得我的写作技巧有多高，也不觉得那是种什么天才般的写手，我的写作之所以带来了一些影响，不是因为我写作技巧，而是因为我直接触碰了一些东西。

直觉，就是存在，而最深的存在，就像是潜意识深处的水流一样。你要深入其中，就像双手去触及那流水，这时，你的文字才有直击人心的力量。

这是我一直以来的一个认识，现在这个认识又进了一步：当能用双手触摸深层存在的"水流"时，你能写、做，散，或其他的直觉的形态；但当你只是期待这股水流，甚至成为它时，你才能写透，得真痛一下，我甚至是很真切的，像荷马的那种诗歌，像孟子、李白、苏轼的诗，但丁诗篇，但都不算，太用逻辑的那种诗也不算。

我是虽常在心理咨界面，但实际上心理咨咨者们的身份我人让我很佩服，例如沙弗因泰老师也许不那么让我服气，不是因为他不厉害，他真是太厉害了，而是因为他还不能够真，还没有做到像鲁米那样直接触碰存在本质。

不说鲁米，那境界太高，实际上我很容易佩服艺术的、画家、舞蹈家、音乐家和诗人，他们一旦会酣畅淋漓表达而被我感动时，我会瞬间泪流而下。

说这些，是在表达我对那些能直接触碰存在的人的敬佩，同时也可以说这是我的渴望，也是我写作的宗旨。说了这么多，那我到底是如何写作的？我先来讲个故事。

2013年，撒切尔夫人去世后，一家杂志找我，请我写一篇撒切尔尔夫人的心理画像，精确说出他们杂志社的最新标准。我后来写了一篇，他们非常喜欢，想一直约写对各种人物的心理画像，被我拒绝了。

为什么拒绝呢？因为我的写作方式吓到了我自己。在主持广州心理报社专栏前，我就当几年的国际新闻编辑，我对"撒切尔夫人"的"铁娘子"有所了解，但真要让我去写写一篇文章，我对自己的要求是这样的：我能触及到她内在的存在，并且这份感知要有一种完整感。

为了实现这种感知，我花了3时间，找各种关于撒切尔夫人的资料，最终直到形成了一种一种完整感知后，才动手写了这篇三千字的稿件。杂志社编辑，编辑咨询的收费不上讲，所以这种写作的成本太高。

同时，我也不是国际新闻编辑，我现在在平时的工作中可以掌握很多撒切尔夫人的各种信息，可以积累很多东西，而现态都需要花三天时间才形成她的一种完整感知。

写撒切尔夫人的这篇故事时，这种写作方式还不够经典，最经典的是我主持心理专栏时，写对红极一时的一位大红红的分析。

当时，我花了两三时间搜集她的各种资料，每天工作10到11小时，搜集了几天资料。之所以形成这样，是因为我一直在感觉我还没有对她有足够完整的感知，我总觉得还缺少什么，而且还是缺关键的那种信息。

有一天深夜，还在投入地找资料时，突然一个声音在脑中响起："够了！"这个声音表达的不是厌恶或不满，而是说足够了。并且这个在脑海中是这种碎片就像一团真水存在，它们本来是碎片，突然间很有秩序地形成一个整体，而且就好像是自动的。

同时，脑海中升起一个画面：一个小孩在爬一块墙，不过一米墙，但她撑了下来，说她非常难受；可爬下来的选择是"继续爬什么了不起，我把下来爬去爬高是"，"让你看我多下来"可是，她墙爬的本没增强，却挑战了更高的事，我选择得那么厉害；可她选择下来的选择的是"我爬不起来，爬不起来爬去爬爬，给你看看..."
