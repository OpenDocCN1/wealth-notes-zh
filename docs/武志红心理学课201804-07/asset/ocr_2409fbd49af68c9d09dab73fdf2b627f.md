# 西格蒙德·弗洛伊德（Sigmund Freud，1856 - 1939），奥地利神经病医师，心理学家、精神分析学派创始人。开创了潜意识研究的领域，促进了动力学心理学、人格心理学和变态心理学的发展，代表作有《梦的解析》等。弗洛伊德的精神分析建立了心理学史上第一个系统的人格理论，包括人格结构和人格发展两个方面。

# 潜意识

西格蒙德·弗洛伊德

> “潜意识”概念最早由精神分析学派弗洛伊德提出。他认为潜意识控制着我们诸多心理行为。

人的内在想象中，包括意识和潜意识。

意识层面，很容易让我们感知到，而潜意识层面，无法清晰感知到。因此，我们认为人是外在意念的结果。

弗洛伊德：你的潜意识指引着你的人生，而你称其为命运。当潜意识变成现实，你会说这就叫改变世界。

参考课程：《觉知02》潜意识的提法

# 思维过程

西格蒙德·弗洛伊德

弗洛伊德认为人有两种思维过程：初级思维过程和次级思维过程。

初级思维过程的表达是意象，次级思维过程的表达是文字。意象可以视为存在，而文字是存在的符号系统。

初级思维过程的问题是以欲望满足，次级思维过程的问题是寻求现实定位，那两者可能会缺乏生命力。

参考课程：《创造03》爱因斯坦的矩阵

# 本我、超我和自我

西格蒙德·弗洛伊德

本我，也就是本能，由各种欲望组成，是一个人格的最底层和核心，是原始和自然，遵循快乐原则。

超我，是人格中的管制者，代表着道德，遵循道德原则。

如果一个人只有超我，那么这个人所有行为出发点都不是为了自己。本我原始，超我是道德，它们两者之间的协调就是自我。

作为咨询师，自我是执行原动力的，也是来访者讲什么个人做什么，这个人就做什么。

参考课程：《自我04》本我、超我和自我

# 个人体验

西格蒙德·弗洛伊德

“个人体验”（Personal Therapy）是心理咨询咨询一次或几次，短程或长程接受心理咨询和治疗。

精神分析的工作是探索无意识对人们想法和行为的影响，而无意识分析是帮助人们无意识，首先要理解发展而来的无意识。它是无意识的，并在工作中的各种体验自我无法察觉的。

因此，精神分析在受训过程中，自己也必须接受分析。
