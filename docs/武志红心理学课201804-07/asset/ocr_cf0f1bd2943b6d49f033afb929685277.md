# # 自由03|怎样回归自主

自由03|怎样回归自主

武志红

我们这一单元的主题是“自我实现”，这是第三讲，题目是“怎样回归自主”。

自我实现是自主人格的一个副产物，那么自主人格是如何形成的呢？

我觉着一个大概率的答案是：因为命运的馈赠，也就是说，生命一开始，你的自主性就是被允许、被鼓励的。但可你或许会问，如果你的原生家庭大糟糕，你的自主性被破坏了怎么办？

如果是这样，我想先给你一个故事。

这个故事是马斯洛自己的故事。马斯洛有一个糟糕的童年，他曾这样说自己：

> “我是一个很不快乐的孩子，我的家庭是一个令人痛苦的家族。我在母亲是一个可怕的养家糊口的人。没有朋友，我在母亲是一个吝啬且长大的，但是，奇怪的是，过着这样的童年生活，我居然没有精神神经病。”

马斯洛在童年和青春期，因为瘦弱和大鼻子一直很难看，也“从来没有任何优越感”。这和他的父亲塞缪尔有关，父亲曾在大型杂志发表过《向孩子道歉：亚当夏娃不是你们见过的最早的坏家伙》（上行就是马斯洛，他的全名是亚伯拉罕·马斯洛）。

对马斯洛来说，塞缪尔是一个“不存在的父亲”，他不回应家人，和孩子关系淡漠，但终马斯洛还是和父母和解了。在晚年时，失业了，也花光了积蓄，和妻子离婚，之后住到了马斯洛家中。他们相处得不错，而且与马斯洛，他是一个“很好的老头，一直到他去世，我们都是朋友”。

但是对母亲，马斯洛一直抱有很深的恨意。母亲去世后，他甚至拒绝参加她的葬礼。他形容母亲是一个冷酷、愚昧无知和充满恶意的母亲，他觉得自己很讨厌孩子把孩子当成“隔离”，而父母之所以对孩子冷漠，也为了躲避她。虽然父亲有极大的冷，但母亲给自己买冰箱时挑起来、只有当心情给自己买药吃的时候，她才把冰箱打开。母亲不认可能孩子，总认为自己的孩子就比谁都好，也孩子们“发不出成不成功上下都是惩罚”。她破坏过马斯洛心爱的照片，给马斯洛带回家的两只小猫当着孩子的面活活打死……

这样的家庭背景，没有阻碍马斯洛成为最有影响力的心理学家之一，他显然拥有自主人格。

# ## 怎样回归自主？

自主性被破坏的人，该如何回归自主呢？马斯洛有这样一些建议。

+   1. 重建你的内部评价体系。在决定你自己的事情时，试着自己做决定，你的该是让别人去评价，且看到，喜欢，文化乃至流行的迷惑。

2. 倾听并接受你内心的声音。马斯洛认为，“自主接受你的体验和感知”。他认为，直觉、感觉或体验性的东西是我们认识自己、别人和世界最可靠的部分。
