# 加餐 | 呼吸的隐喻

+   加餐 | 呼吸的隐喻

武志红

我们这个单元的主题是“让欲望流动”。这节课是加餐，题目是“呼吸的隐喻”。

流动，是指能在自身与客体之间的自由往返交换，是能参与到客体的内部世界与外部世界关系中的主题，都是看是否能自由流动这个隐喻。

最简单的例子，比如你的呼吸。你肯定经历过考试，考试焦虑很常见。你看着各种考试焦虑的方法，深呼吸应该是最常用的一种。焦虑时用几次深呼吸，让自己放松下来。在各种冥想、静心与禅修的方式中，呼吸也占据着重要地位。

可是，为什么呼吸会有这个效果呢？因为呼吸是一个人和外界关系的隐喻。你以什么样的方式吸入外界的空气，可以反映外界的基本态度；用什么样的方式吐出外界的空气，也可以反映外界对自己的基本态度。

如果你处于考试焦虑或任何一种严重的事情中，你会发现呼吸改变了。事会全身开始呼吸，甚至会呼吸困难。在这个时候，人会觉整个外部环境如同一个苛刻的、充满恶意的“毒”者，而心中对这个“考官”产生敌意。在这种敌意的情形中，外部空气和自己内部的空气都像是有毒了，于是不敢大口吸气，怕受伤害，也不敢大口气，怕把恶意伤到对方。

这时，如果你能做深呼吸，就是在用主动制定深呼吸的方式，来让自己的感知与外界的关系还可以是友善的。

见到这个道理不容易。我第一次听到这种说法，也不觉得应该太不放心。但是，我还是流动地、自由地呼吸。自由呼吸，意味着自由地大口呼吸，意味着和外部世界交换信息，是自由流动，意味和自己的呼吸会变得困难。

我个人认为可以这样概括来说：如果你潜意识中觉得外界是“毒”者，意思外界呼吸，放意太深，你也会就会故意过意，那你呼吸会变得困难。

我就吸会得着，我觉得是这样一种逻辑：“外界不友好，外界对我有敌意，故意就是有毒，”意思我不能不吸入外界的空气，它有毒，可是我我呼吸忍受着小心吸入，于是，吸气变得困难。

同样的，如果你觉得自己有毒，那么，你对外空时，也会会有困难。比如你见一个心里爱的人，你紧张得屏住呼吸。我认为这是因为你无意识中觉得你呼出的气息可能会伤害到对方。

毒，也就是敌意，它有两部分，你对外界敌意，和外界对你的敌意。我觉得这两者如果有分值的话，那会是等值的。

你可能会觉得外界对你充满敌意，而对外界充满敌意。但是请相信我，这是不真的。这是分裂、认知失调的结果，也就是说你的自我自尊，将在一定程自承认了自己的恶，接着将这部分定义的恶，投射到了外部世界，由此才产生了你内部、外部世界敌的感觉。

所以我们以说提直对方，感知中的外界意思程度，就是指自身对世界的敌意程度。你也可以由此来观察别人，别轻易相信一个人是恨且外界界的逻辑。

敌意的根本，是婴儿最初全能破坏欲与全能毁灭欲对抗，婴儿可能会特别惧怕外界敌意，怕自己已经轻易毁灭，也怕自己的全能破坏欲，能轻易毁灭别人乃至世界，这种矛盾状态就体现在呼吸上。

例如，一个婴儿如果体在呼吸不足，太渴望来不满足的时候，会生出浓浓的敌意。觉得让自己放松都敌意药，如果留在自己身上，会让自己受到伤害，他可能会将毒气吐出去，由就使感觉他对外界对于自己深的敌意。

我认为，呼吸是这样的道理，吃饭与排泄也是如此，可以解读这些原始行为。“婴儿需要妈妈或原始的养育者基本满意。这一来就可以让妈妈觉得是好的，他，于是会大气地呼吸，安心吃喝，坦然排泄。如果对原始的养育者基本不满，那么呼吸、吃饭、进食与排泄都可能出问题。

我们在之前的课程中多次讲到过，成年父母对孩子的养育中，有一个特别重要的功能，那就是去毒化。孩子因为无如，都会与有毒、高毒素，很容让生出的毒的。他们会将这些“毒”传递给养育者，比如发脾气、说脏话、需要这着带着“毒”的信息给，然后进行无毒化处理，最后还给孩一个“毒性”小了的回应。

成年人一定有这种逻辑，而一个好的关系会有一定的去毒化功能。

例如我的一位女性来访者，她缺乏能力，不得不依靠家人馈赠金钱而生活，但可避免，她有对客这些金钱，会对方没有的。她觉得一定钱里是真的，但多是想象的，是她心中固有的想象或想象中的敌意，放大了很多倍。

不仅对这种带有毒性的事情，她处理很成功对敌意，还是真实的敌意，更是对敌意很多倍。结果，她的感知中外部世界整体是黑色的，而她整体上也是黑色的，都是恶意满满。

所以，这位来访者尽可能地把断自己与外界联系，这样就可以避免被毒害，也可以避免自己毒害外界。可她不得不受安慰的状态下，活下去。

这形成了一个矛盾，她不得不吸入亲密的辅助，但因为她心中故意太深，所以她满得这些东西，都是黑色的，毒性满满的。
