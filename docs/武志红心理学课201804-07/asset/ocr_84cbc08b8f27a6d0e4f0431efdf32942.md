# 无常07|自性化：从生到死的英雄之旅

![](bbox=[0.05, 0.08, 0.15, 0.1])

武志红

我们这一单元的主题是“生命的意义在于连接”，这是第三讲，《自性化：从生到死的英雄之旅》。

在这个单元课中，我们一再讲“英雄之旅，这个概念是美国心理学家荣格·坎贝尔提出来的，而坎贝尔是瑞士心理学家荣格的学生。所以，有关英雄之旅的概念，既是对世界地图神话的另一个研究，也是借鉴了荣格的一些概念，特别是自性化的概念。

要解释这个概念，就要涉及到我自己的定义。头脑自我，就是自我1，英文是ego。“自体”对应的英文是self，指的是头脑、身体和情感构成的完整自我，而荣格的心理分析流派使用的“自性”一词，对应的英文也是Self，带第一个字母大写的人，你可能会问，它有什么区别？我认为，更接近于“大写自我”，“我”的意思。中国心理分析流派中也有学者认为，这个词也可以翻译为“道”。

总之，自性指的是内在自性上，它隐约超越自我的存在。但隐秘地实际上它像是在自我之外寻找关于自我的东西，而自性化指的是一个更大的自我，成为他自己的，而会发现有更大的存在。

例如，坎贝尔所说的“英雄之旅”中，通常会有这样的现象，英雄意识到了自己一些使命，而要去完成这些使命，英雄需要离开自己熟悉的家生活，它总是会在情志、困境或者命运中冒险，他也会受到一些考验，但类似的考验，让他发现，有一种东西在召唤自己，最终他除掉自己的恶魔，接受了这个恶魔来自他自身部分在内心深处召唤的声音，而踏上英雄之旅。

英雄之旅，会从“分离”开始，即离开自己的本来之我，也像是母亲的怀抱，听到“自性的召唤”。经历母亲的考验，获得“传媒奥秘”，再“回来”，成就一番事业。

在此前课下题注《动力21》英雄之旅》这节课中，我谈论英雄之旅的三个阶段：花园，沙漠和狮子。

英雄之旅这个词，容易给人一种昂扬向上的感觉，但它完整的过程，就是自性化的过程，不仅仅是要开放过程，理性化也能，也会接受无常与死亡，坦然拥抱死能量。坎贝尔说，弗洛伊德的精神分析理论只强调了太阳升起的旅程，而弗洛诺理论同样重视了太阳落下的过程。正如我们的出生，从母亲的子宫里来，再死亡，最后展开发生的生命，自然里来死亡，最终进入坟墓，而坟墓可以说是黑暗的子宫。

我认为弗洛伊德的视野极其广阔，当然不可能既来自阳光的过渡，更不能忽视死亡这样的，他的特别讲述了生命能认知本能，认为这是最本能的动力。不同的是，荣格的自性化理论，认为是人本性是愉悦，与“道”相连，所以不需要压制，全然地意识到它，弗洛伊德还认为本能全都是坏的，认为需要去压制，而相反而言，弗洛伊德对人总是心怀怀疑，因此可以说，他的确实像荣格那样完成自性化。

弗洛伊德提出了自我防御体系，而防御的就是不愉快的体验，我认为总体自我的脆弱和关系中的恨，一谈到死亡，自体的脆弱和联系中的恨，就会上升到自我的死亡和杀死对方这样的级别了。也的确可以说，我们很怕自体的虚弱，就在很恨憎恨的我们自己的亲密关系，死亡在惧怕里，也是恨自己的亲密关系去杀死别人。所以可以说，自我防御体系防御的是死亡。
