# # 创造08 | 创造和扩容

武芷红

我们这一周的主题是“臣服的動力”，今天第四讲“创造和扩容”。

今天我分享的基本观点是：我们的内在生命力，要跟随着我们所创造的一个外在之物去修炼。这个外在的被创造之物，它的生死存亡牵动着内在生命力的生死，它的品质昭示着我们的内在生命力的品质。

在不断创新的过程中，我们自己的容器，或者叫空间，也会不断地扩大，我把这一概念标为“扩容”。当生命横向成长时，你的一生必然是不断扩容的过程。

被创造的外在之物，可以是一件很实际、很真实的事物，例如房子、公司，也可以是一件有点抽象的想象之物，例如一部作品，一个理论，或者一件美妙的艺术品。

要做到这并不容易，因为这个世界上有伟大创造功的人都是少数。更为重要是，人类的所有外在创造，最后都会毁灭，都会归于无常。并且你可能会亲眼看到，你所创造的事物将不属于你，甚至被毁灭。

这一切，都非常考验人的心灵。如果看充满着你的心血的外在创造物，在经历生老病死的轮回，而且这一切沧海桑田没有冲垮你的心灵，相反，你的内在心智在这个过程中变得愈坚固、更有力量更圆满，那就很好了。

在我所了解的事物中，最能浓缩地体现这个过程、是慈济佛陀的“坛城沙画”，是非常令人震撼的图景。

我来给你简单介绍一下。坛城沙画是一种宗教艺术，具体来说就是喇嘛们会用彩色的沙粒“画”出异想天开的佛国，这个过程非常辛苦，制作出来的坛城沙画色彩绝伦，绝对可以做艺术品来收藏。

![](bbox=[0.05, 0.72, 0.4, 0.82])

但是，这个艺术活动最后一步，是将这个嘛嘛们沥血沥心、极其辛苦才创作出的惊人作品，毫不留情地打掉，把沙子倒入流水中。这个活动的寓意，就是无常。

在我的理解中，已经知道自己的所创之物会毁灭，归于无常，但仍然能全情投入，去创造最高水平的作品来，并且这份毁灭是自己亲手去实施，这个过程实在太磨炼心性了。

由此我反思自己，我1974年出生，到现在已46岁，除了写了几十万字书，构建了一个自认为还算独特的思想体系，我在现实中什么都没创造。
