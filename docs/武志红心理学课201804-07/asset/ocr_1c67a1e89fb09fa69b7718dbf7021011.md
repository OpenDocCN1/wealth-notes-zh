卡尔·兰德塞姆·罗杰斯（Carl Ransom Rogers，1902-1987），美国心理学家，人本主义心理学的主要代表人物之一。他从事心理咨询和治疗实践与研究，主张“以当事人为中心”的心理治疗方法，强调人的完整性、强调人格中自我作用，注重健康人格的培育，因此对自我心理学产生了重要影响。

# 现象场

罗杰斯

罗杰斯认为“我，是一切体验的总和”。如果你想了解一个人，就需要进入他的现象场，体验到他的体验。

现象场就是一个人的体验和时空等环境因素的结合。

每个具体体验，就是一个“现象”，它们合起来，就是现象发生的“场”，它们结合起来，就是一个人的现象场。

参考课程：《自我⑦进入别人的现象场》

玛利亚·蒙特梭利（Maria Montessori,1870-1952），出生于意大利科桑比奥，意大利第一位女医学博士，著名医生、幼儿教育家、哲学家与慈善家，以革命性的教育哲学与儿童教育方法闻名于世，教育界“儿童之家”的创办者。她在实验、观察和研究基础上形成的《蒙特梭利早期教育法》、《蒙特梭利儿童教育手册》、《童年的秘密》、《发现孩子》、《有吸引力的心灵》等，被译成37种语言文字，到多国设立了蒙特梭利协会或蒙特梭利培训机构，以她名字命名的蒙特梭利学校遍及110个国家，包括中国。

# 精神胚胎

蒙特梭利

每个孩子一出生，就己经有一个精神胚胎。就像是一粒种子，成长，就是这个植物胚胎发育的过程。

植物种子的发育，需要阳光、空气、水和土壤等条件。而精神胚胎的发育，需要的营养是“感觉”。

精神胚胎在发育过程中，会知道自己想要什么，它会驱动孩子去做各种各样的事，所以孩子的自主选择，有某种含义。

参考课程：《自我13哺育你的心灵胚胎》

埃里克·伯思（Eric Berne，1910-1970）是加拿大心理学家。他发展了相互作用分析（Transactional Analysis，简称TA）的治疗流派，比起精神分析、认知行为等治疗流派，TA更注重对小儿的心理疗法。伯思提出了人生脚本和自我状态理论。伯思的书中文版本在售的有《人本脚本：说完“你好”，说什么》《人间游戏：人际关系心理学》等。

埃里克·伯思

每个人都有一个人生脚本”，它在童年时形成，有开始、展开、高潮和结局几个部分。

那些重复打你的人故事，很可能就是人类共同的重要“人生脚本”；

那些重复打你的故事，很可能就是你的“人生脚本”。

参考课程：《预估读懂你的人生脚本》

罗伯特·罗森塔尔（Robert Rosenthal），罗森塔尔最初开始研究临床心理学，后来转为研究社会心理学。主要研究方向是人际期望。即一个人对另一行为的是期望本身会导致该期望成为现实。同时他还对非语言交流很感兴趣。主要成就是设计了罗森塔尔实验，发现了著名的罗森塔效应，著有《行为研究纲要：方法与数据分析》。

# 罗森塔尔效应

罗森塔尔

罗森塔尔效应，也被称为“皮格马利翁效应”，是一种社会心理效应。由美国心理学家罗森塔尔和雅各布森于1968年通过实验发现。

教师对学生的过高期望能无意识地被带到他的教学中。一个人对对方有行为的期望本身导致该期望期成为现实，也就是说，权威的期待，可以强大有力影响人和动物。

参考课程：《命运04罗森塔尔效应》

海因兹·科胡特（Heinz Kohut，1913-1981），自体心理学（Self psychology）的创立者。科胡特做的一个巨大贡献，就是为“自恋”这个词正名了。在他以前，当精神分析师们使用自恋这个词时，就像一个贬义词一样，但在自恋以后，自恋被视为一种基本的、不可或缺的人性动力。

# 自体客体

科胡特

自体客体（Self object）就是，你的确是客体，在我各个自体之外，可我觉得，你好像是我自身的一部分，我可以像使用自己手臂一样使用你。

我把另外一个人或物体当作我的一部分来使用，并且没有把他人体验成和我同的，与我不同的客体。

这里的人就是自体的客体延伸，更重要的是，我需要使用他人来扩展自体的需要。

参考课程：《情感01依恋的形成》

# 内聚性自我

科胡特

内聚性自我（Cohesive Self），这是美国心理学家科胡特提出的概念。

内聚性，意思是你的自我有一种向心力，可以保证心理自我成分不致分向四散。向内收，整个体，性自我地协调成一致，有一个内在性自我稳地里聚着。

内聚性自我的形成，必须建立在“我是好的”这种感受上。这是自信，是一种内聚能力，可以把你关于自我的各种素材统一在起。

参考课程：《问答：内聚性自我如何形成》

# 恰到好处的挫折

科胡特

“恰到好处的挫折”（optimal frustration）指部分性的挫折，也是挫折的程度不至于使被挫折的情结，可以处理的挫折引起变化。

“恰到好处的挫折”，是创伤得到内化过程的概念，创伤化到不被淹没的挫折。

“恰到好处的挫折”，有两个比较重要的意思：首先是对挫有效益的理解解释，其次是没有效益的坚忍和不含诱惑的深情。

参考课程：《现实04三重世界》

科胡特

不含诱惑的深情指的是，人与人之间最美丽的、我深深保有的情绪，而不是对你没提任何条件。
