# 加餐：中国式关系中的“葵花宝典”

武志红

这是“现实”主题下的第一单元“单纯”，这一讲是加餐，题目是“中国式关系中的葵花宝典”。

这一讲我们也是从一个故事开始。

有一位非常有力量、也很有魅力的女士，她有一个憨厚有魅力的丈夫，同时她也和一个她一样复杂有魅力的情人。在这个三角关系中，她一直很少照顾自己的丈夫，觉得自己很爱也很在乎情人。

在一次咨询中，我请她谈谈，她理想中的爱人是什么样的，可以用欣赏观也可以用管理道，我请她谈一下，这位女士本来是想谈一个超级完美的人，所以这份自画像很容易。几秒钟内，她就一列举了以下几个条件：

+   1. 要帅，要有肌肉感；
2. 要像白马王子一样，对我好，其实是黑又王子都接受；
3. 要有社会地位，要有很多钱；
4. ……

她列了很多条件，最后列出的是一条是“愿意做家务”。

这些条件中，“做家务”是最不起眼的条件了。但接下来，我请她一一删除这些条件，也就是当不得放弃某些一个条件时，哪些条件是最愿意放弃的。然后很有信息的矛盾发生了，她发现最愿意删除的条件，其实是“愿意做家务”。由此她明白，她老公的实际重要性远远超过她的想象，而上很符合她条件的情人，其实只是一道配菜。

说到最后，我对她说：看来你想找一王子，而她愿意为你做家务。她若有所思地说，她丈夫其实也很对她，但若有她所说的关系中，逐渐变成了一个二十四孝老公“，实际上，在谈恋爱时，他就是这样。

这样的故事可多了，我逐渐总结出这样一个说法：中国式恋爱的绝招是把对方当婴儿一样照顾，当神一样崇拜。

然后我也发现，互联网上流传的各种迎合女人发疯梦的文案，其实都是在讲这个东西。现在中国，也的承认认可进进的男人，他们极善于照顾女人，但同时他们也花心至极。

我下的观念不断延伸，后来我总结出，这个现象中国式恋爱中的绝招，也是中式关系，或中国式存之道的绝招，只是刚才这两点还不够，如果再加点一点就以达到葵花宝的级别了。这一点就是：有一张愚忠的脸。

这样一来，我认为中式关系的“葵花宝典”的完整神就是：把对方当婴儿一样照顾，当神一样崇拜，同时自己有一张愚忠的脸。

单纯，是一个很好的词，简单，就是一个中性词，而一旦变成“愚忠”这个词，这个人很难接受了，可思虑太多了，这三个词在一定程度上是一脉相承的。

上一讲课程中我们谈到，我们在社会中，无论家长是如小儿童，都希望孩子能长大成人，因此婴孩期不余地希望孩子的。逼迫和顺从，也就是中式关系的一个基本特征，也知道，强迫的目的是希望他顺从于我。

那反过来，如果我们表面上去顺从大家的这份需求，然后我从中等挑人，也就会得到所谓顺从的中式关系中的人的绝招的信悟，并把这种使用得淋漓尽致，因此获得了成功。

为什么有一张愚忠的脸呢？因为逼迫和顺从中最有的一类，忠是一种顺起，就会不愿意顺从，顺就顺从，那是压抑和屈辱，所以你必须要有方面是愚蠢的，这样才可能顺从他人。这种算计，在中式关系中也太常见了。

例如明朝的大太监魏忠贤，我们的影视作品中描绘他，你看他极易会刻画出他极聪明狡黠又智极高的人，但很可能最重要的特征不是智智，而是完美地实现了这三点：他不敢当人一样暴躁，当神一样崇拜，同时又有一张愚蠢的脸。

我们容易攻击吕布顺忠的人，但这的人如果更多一些可能更好，因为这样一个社会就可以明白这种式的人到底是怎么回事了，然后去寻求追求“你要心甘情愿地顺从于我”这种东西。

同样的，我们还可以做一个推理：一个人既顺从，又愚忠像心甘情愿一样，那很有可能又因的是他自己的智商。

用稍神分析的模式来说，就是他启动了“自我功能的中断”这种自我防御机制，而即抑制的，就是自己的智商。

我再来讲一个经典的故事，这也是曾经轰动一时的新闻，也许你听说过，有一夏天，汛期将至，有一个村庄有很大可能发大水。一个年轻的村民，他本是在市里打工，却因为担心家里老父母家，于是特意开车赶回了老家。他的父母可能是有一些矛盾，所以爸爸妈妈住在村子西边，而爸爸、妻子和两个幼小的孩子住在村子里东边。爸爸是腿脚不便，两个孩子一个两岁，一个四岁。

他本来的计划是接先去妈妈，再接上一家三口，这样都可以顺顺当的。但是他到了妈妈家门口，不想顺顺当当。然后坐在家门口，在门口等了一到两个多小时，发现大水和妻子来了，救自己的担心。回到家后，他妻子孩子了了自己的担心，然后因为太累就睡着了，可妻子一直喊，就没醒着。后来，洪水真的来了，都水进到他们家院子，妻子及时唤醒他。

接下来这位小伙子的选择非常耐人寻味，他立即跑去救门，去救他妈去了，等他妈叫醒并带上到房顶上后，他大，没法回去，和妻子和两个孩子在村子里东边，也都没有安全地放在了房顶上了，都没事。

可妻子从此后不再和他说话，来向他提出离婚。

这件事被报道后，轰动一时，这位年轻人，绝对是孝顺的化身了，如果放到十多年，那肯定是一奖，可公子的认识发生了转变，他是懂的善良少了很多，很多人觉得他很愚蠢，这时对的选择简直是不可能。

在那样的急时，人很难有两个选择，这种忠心的做法让人很难得，都可以理解，我认为真正的问题就既然已经预判到了洪水要来，他为什么不亲妈妈门口等个几多小事，这些要求在婆婆家里，如果他能叫醒妈妈，让妈妈先准备，然后提早联系父亲和妻子做好准备，安全效能会提高很多，同时财物的损失也可以降低很多。

我觉觉得那个时刻，他的智商是关闭了一样，在妈妈门口等个三小个时的愚蠢行为，也许本质就是一种顺从。太听见的，很容易出现一种思维，在根大上都想你什么，而所想的也不得不根据这上放弃这根本动力，那如果把自已再慢一下，是没办法这样做的。

如果你在养育一个根为，你一开始就让他顺从，还是希望给他这种感觉：世界有足够好的他的本能嗨响而做，这句话也是心理学派尼斯特说的，我在中国的课中中提过它，我现也在逐渐形成了自己的表达，在这里分享给你：

当一个人感觉到，他的生命能够按照他的自自由意志来展开，他将会被关爱、困难、拒绝、封闭和消解将他折磨他，每一时刻的孩子都想被爱，一个被爱和自由意志的孩子，常常会像一个文心机一样，同时又能专注地投入在他们正在做的事情中。

如果你正在养育一个孩子，你可以给他需要这种感觉。同时你也别忘了，你也可一样需要这种感觉。

+   1. 如果一个人顺从了，又愚的像心甘情愿一样，那很有可能启动了他的智商，抑制的就是自己的智商。
2. 太听话的人，容易出一顺，因为人根本上想都做放弃，而听话的人不得不放弃这些。
