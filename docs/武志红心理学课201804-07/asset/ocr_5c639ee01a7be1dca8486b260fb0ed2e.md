# 创造06 | 你在，我才能流动

![](bbox=[0.0, 0.07, 0.1, 0.1])

武志红

我们这一周的主题是“臣服的动力”。今天是第二讲“我在，我才能流动”。

先来讲一个故事吧，这是刚刚发生的一件事儿。

我在写我们这个专栏的时候，流程是这样的：每周一，我会召集我们广州的小组开例会，讲述我要写的内容，我的想法和小组有分歧的地方，再听大家的反馈。得到小”的两位心理治疗师和资深专员后坐。并且，我们只是主题，讨论的时候大家天马行空，说什么都可以，我更需要的是大家开拓我的思路，而不是从他们那里寻求答案。

我讲的故事发生在上周二，当我们的例会没有在上午九点开始时，我本来是想开个会，没想到一坐上去滔滔不绝地讲下去，讲了二十分钟左右。我讲得很投入，大家也听得入迷。讲完之后，我不禁感慨：虽然你们什么也没做，但是只要有你们在，我的创造力就出来了。刚刚的那些内容，我真的没想到，但讲着讲着就流出来了。

他们纷纷开玩笑说，我们是你的专业听众。并且，在这个讨论会上，他们自己也常有类似的体验。我觉得这种体验的关键所在，所以我就存。

这句话我们此前也多次讲过，它还可以延伸为：你稳定地存在着，我也持续地流动着。意思是，当你稳定地在这里，你想稳定地看着我，回复我的感受和爱时，我的感受流就形成了，就有信心一直持续地流动着。

相反，如果你不能稳定地存在，我的感受流之水流就会变得时断时续。我在世界中稳定的持续性和外部世界稳定的存在稳定性，是一种信任的存在。所以在大多情况下，我们会看到那些伟大的思想家，我们都知道少有关键的，听者，就是所谓的观察者。例如，弗洛依德有一个叫弗洛里恩，他的很多思想，都是先写给这位观察者的。

为什么要这么重要？而且还需要一个听者稳定地存在？

我讲这个心理问题后，得到小组中的咨询师王先生聊着进咨询室的咨询师，她想到一位来访者，有一段时间没来，再重新来了以后，对，王医生老师，他的头发长了好多，是以前那个那个。

做过咨询的咨询师们都会看到这个问题，随着咨询的发展，来访者会呈现的强烈要求你，要稳定地存在。那些心理问题的来访者，对这一点的需要更加，这是为什么呢？

简单理解我们前面讲了，当你稳定地存在，我的感受和想的水流才能持续流动。但我们还可以继续问，为什我的内心水流流动需要一个外在客体的稳定存在呢？

因为内在的水流，作为深刻的存在，它既是创造力的源泉，也是危险的力量，不是否否否，我们总会担心自己水流动，会带来巨大的外部世界破坏。当外部世界不稳定的时候，例如有些客户会在，直到长时间内不在，我会觉得我的生命力是受到影响的，我生命动力就会消失。这个时候，我们就会害怕，进而切断生命力的流动。

相反，如果外在客体一直稳定地存在，我们就会得一种确信：我生命力的流动没有带来毁灭和破坏，所以我的生命力是可以流动的。

我再多分享一个我的故事。那是2016年的9月30号，我和我的分析师做团体咨询。突然，我看到一个倒吊在小窗口里的脸，但是，用倒立着的小镜子都不够，得用，才能表达出那种。

我的分析听我讲了这个我的这种状态，他给我了解释。这个解释并没有让我反感了来。在回去站下的那一刹那，我体验到了一种极度兴奋的状态，这种松弛感描述到可以是99%，并且在我的视线、空间感、空间感都发生了一些变化。

从此以后，和我的分析师做咨询，常常会陷入这种极度放松状态。

这一种放松是怎么发生的？我的理解是，我和我的咨询师进行了两年时间。是头一，我知道他一直是稳定地在那里，非常稳定。但是我的感受和意识，需要再有两年的时间，才能形成真正的稳定感，才能确信的确一直就在那里。

当这种稳定感形成后，我可以在他面前放下我自己的头发了，也就是自我了。因为我的生命，我的存在和他的生命。就是这样保护，是在出于对彼此信任的对等。在这种稳定感形成后，我一直要有赖于我的自我1的保护，我自然就很放松了。

我再多讲一个来访者的故事。这位来访者是一位严肃的老汉，从她记事以来，她都有严重的睡眠问题，她感觉自己的睡眼，但是都是在高速运转，所以休息不好，她为此非常痛苦。

我们也是经过漫长的咨询，突然一天，她的眼睛睁了很大，她发现了我可以连续地睡六个小时了，而睡眠也有了较好的休息功能。

这发生了什么呢？我们的理解是经过漫长的咨询，她对于和咨询师关系有了，她的稳定信念开始为它开始展现出来，而我没有做破坏，甚至她建立没有她的伤害，反社会，但她都会进行，然后她第一次对人产生了信任。

依恋产生后，她的自我1，或者说是头脑与意识的自我，就松了下来，头脑与意识在底层翻腾的自我2，也就是身体与意识是外面的自我。她的自我1永远不能放松，因为很担心失控，自我2就会失控。我，比如紧张，以至于根本没有好睡眠。

依恋产生后，她的自我1终于可以放松了，她可以在一定程度上相信他，把他交给你的睡眠自我去处理。从这个意义上来说，臣服，是一个基本需求，因为只有臣服发生，我们才能放松下来。

再讲一个故事。一位富二代也地接到了父亲的故事。掌握了一公位的，也接连接了一些漂亮至极的事情。他本来是一个非常自信的人，这些话，他常常觉得，会给他自己带来大的伤害，在不知道自己情况下，他再也不会受到这些喜悦。他只觉得受到了伤害，并且往家里打碎他，他觉得特别受伤害，开始拒绝爸爸。

我们探讨过这种变化的时候，发现他。在历史上发生了，我也被深深震撼。他根本就没法理解父亲里，于是产生了毁灭，我，在我的咨询室里好好睡了一觉。

咨询最后十分钟，我问醒他。和他探讨这部分。我分析说，以前你没有彻底掌控你，你的后面可以掌控，你可以任性。可以是，可以，享受自恋者得到喜悦。那些建立在父母的爱的空间比你的空间更大。这一全能自恋，得到了巨大满足，但你所有空间的绝对大。你要为这部分负责，就可能轻易放松。，你感知到这是你不敢享受的，你。

所以，你常常回到家里，在老婆孩子面前放下你的自恋，你这是在对你老婆孩子表达你的依恋，表达你的臣服。在这里。你，你，你，你，你。

对我所说的这些，他非常敏感。

容纳和容纳之物，是一对深刻的矛盾。创造力都发生在容纳之物，也就是生命力的流动中，有极大的容器就流动了。但流动中有一个巨大的容器，给了一个空间。

虽然。我们可以有意志地利用自己的力量去创造更大的空间，但我们的能力，创造了更大的存在，提供了更大的空间，在托着我们。这时候我们就可以放下自己，自己的头脑层面的保护，让生命力能够流动就好。

从这一点上来说，如果一个家庭、社会、国家乃至全世界，希望个人有更高的创造力，需要提供可以的安全空间。
