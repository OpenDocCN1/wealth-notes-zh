# 问答：从现实世界再到想象世界

问答：从想象世界回到现实

武志红

这里是我专栏的问答时间，我先选一个观点，再回答一些用户的问题。

本单元的四个课程，基本上都是在讲"从想象世界到现实世界"，可能会给你这样一个印象，孤独的想象世界是幼稚低级的，而真实、复杂的现实世界才是成熟高级的。

所以我特别想强调的是，当我们不断谈现实世界的重要性时，千万别忘了《人美简史》中的一个说法：智人，也就是我们智人这一类，一个重要特点就是可以构建想象共同体，然后集聚力量，在竞争中占据优势。

由此，我们可以有一个基本假设：也许很多团体以绝对的正确性，其本质也是想象共同体集体自恋的结果，它们本来也只是想象而已。当有了这个假设，我们就可以给全人类的想象留出一个巨大空间，也许我们放弃大家共同拥有的想象，去想象一些不可能之事，这把被想象共同体视为不可能东西，本未就是不可行。

英国陆军军长阿方斯·劳伦斯在于一战期间的不可思议的方式率领处于部落状态的阿拉伯人，击溃了奥斯曼帝国，创造了一系列不可思议的奇迹。他作为一名牛津大学的毕业生，在著作《智慧的七柱》中，写下了一段很有感染力的话：

> > 人都有梦，但多数不留。夜间做梦的人，白天醒来，当心血灾做梦的人，不过是一场幻觉。那些白日做梦的人，是危险的，因为他们会在睁着眼睛做梦的时候，把梦变成现实。

他的真实故事拍摄的电影《阿拉伯的劳伦斯》，说过两遍，觉得他其实是一个活在全能自恋中的人，近乎"疯子"，可这个"疯子"，创造了奇迹。

多接触那些先天性之人，你会发现，他们之所以成为今天的这个样于，并创造一些非凡成就，那是因为这是他们的根本想象。

# ——单元问答——

武老师，如果"你想要什么，就先看做什么"，我想看其实我不还在看，那我能不能做什么？具体是需要一点点拆分我想看的吗，还是怎么做呢？

武志红

这句话中的哲学，在《当人们麦尔·罗奇所写的著作"《当朝遇到上巴石》"中有详细论述，麦尔·罗奇是一位灵成的佛教僧，感兴趣的话你可以看看他的这本书。

这种哲学的意思就是：先做你想做的事，要等让别人看到钱，你想获得爱，去找爱等。

不过我也想说，先去领悟诗人鲁米的话，或者留着一个心灵的种子就好，不要太直接把诗人写的诗当做人生哲学。

"一个人的想，决定了他生活的"，这是前几期提到过的一句话，那这一单独讲的实际经验能力相比，二者有什么区别？是不是现实经验能力投勾过去，而想象力投勾未来？

武志红

现实经验能力中的"现实"，有客观意义上的现实，也有对社会共同体的共同想象的存在。

举例来说，严重的精神病患者会有幻觉、如幻听，是指听到不存在的声音，再比如幻视，是看到了不存在的事物。这个时候如果是有现实经验能力，知道这是不存在的，而这种情况也是有效力的可能。如果完全没有现实经验能力，而这些视为真实，那就会有严重问题。

我忽然发现我自己很难相信认人，过度在自己的想象中，谁让建立亲密关系。我想找出回到我发出的亲密动心，我想说出，但不知如何表达，或者就是根本不想说出去？

武志红

我认为具体的方法，最好是和别人的建立密切关系，并且向度建一些深度关系。

此外，我建议你不要着急，要多花时间，不要期望一周，半年就解决问题，而应该用几年甚至更长去，去建立亲密关系。当然，要去选择那些基本可靠的。

武老师，请问自闭的孩子，是活在孤独想象世界吗？他们甚至还没有进入过渡世界？

武志红

我觉得可以这样谈。一位精神分析学家，对这个问题的看法是，自闭症的孩子是把本能的都投射到外部世界，这句话的意思指在自闭症的孩子看来，外部的任何变动都是敌意的，都是攻击他的，所以任何变动，他都不适应，都可能失控。

在《第三世界》这节课中，那个男孩的案例里，他全能感其实仅有两次表现，第一次是在原意第一次女友总是碍于人情而决不愿去见，第二次是妈妈的看不见的手带来的烦恼。第二次是最关键的？

算是个"恰到好处挫折"吗？帮助他明白自己不是全能的，世界不是自己的理想变现实，感受是摧毁了他全能的自恋。所以应该算是一个"正面"伤害了他。另一方面，这个决定伤害了它的创造力，因此他决定不应该是女友见母亲？
