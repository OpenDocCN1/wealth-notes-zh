# 问答：臣服什么，又冒犯什么

问答：臣服什么，又冒犯什么...

**武志红**

回答：臣服什么，又冒犯什么

今天是我们专栏的问答时间，我来先集中回答一些用户的问答，再回答一些其他用户的问题。

之前不是提背叛才会使我们勇于去创造自己的空间吗？为什么现在又说自我臣服呢？这不是自相矛盾的观点呢？

问类似这种问题的用户有很多，所以我想在这里集中解释一下。

这个问题的简单回答是：臣服于真实存在，冒犯集体意识或权威观点。

举个例子，欧洲宗教改革的重要推动者马丁·路德，他曾以个人之力直接读《圣经》，而不必得从教会和牧师那里得到“圣谕”。这对于当时的宗教体系来说是一个巨大的冒犯，而《圣经》相对这件事而言就像是真实存在。

在任何一个领域都存在这种情形，前者我们已经有了各种各样形成的观点，我们得敢于冒犯这一切，才能比他们更到更深的存在。

# ——本周问答——

怎样才能进入到身体和潜意识中的自我之中呢？

**武志红**

本周的前两期内讲的话像是个心法，可能对你来说，有点耳熟时又习惯不一样了，所以觉得无法有可操作。

实际上，我已经讲了方法，虽然我前我一直在使用它，过去我并不是有意识的。在讲到如何分散地感受到她的存在，并且这会使得你得有一完整的整度。

但这两点也建在了一个基础上，那就是我整感于对一切，而不是头脑和逻辑分析出来。

当然，更有具体方法也是有的，那就是无论如何去尝试那个广阔，我前前后后试了几个小时的时间在找感觉，在本周的第四期内容中，我介绍了这就是最简单、最易操作的方法，可其实也是最难的，因为看起来很简单。

可能存在一种情形是你也使用这种最基本的方法，在做任何一件事时，你也做的最大调查研究，但却发现好像你是不能抓住关键，这其实也是源自于你忘记了自己的感觉。

所以一切的心法，不管是创造还是其他能力，都不要忘了你的感觉这个最基本的点。

我曾经看过李小龙的一段访谈录像，他是这样分析李小龙的：“一个人的武术就像水一样一样。为什么？因为水是无形。因此，你抓不住水。水也不会去打击你，它就像水一样柔软无头。放弃你的思想，无形无式，如水一般。将水倒入杯中，它变成杯的形状。将水倒入瓶中，它变成瓶的形状。将水倒入茶壶中，它变成茶壶的形状，水可静可动，你可猛烈冲击。像水一样吧，我的朋友们。”

这段极富哲理性的话当时深深地震撼了我，按照个人的理解，他是要我们放弃传统思维，放下来思维，同时也会因循利己、尊重自己的第一想法，从而达到神枪手与创可贴与无限性中“创”。也许，正是李小龙放弃思想，像水一样自由流动，他才够格混合东西方的哲思，创造出“最科学的街头白手搏斗”之称的“截拳道”。

**武志红**

这位用户的分享明显不是问题，但我也拿来作为我们今天问答的一部分。

我认为是超一流的，他们都相信到达了存在的水流，或者说觉醒了水流，也就是自我。

不管在有任何一个思维模式里，虽然你的思维看起来很高级，你可以试着使用思维模式，但都是为了帮助你去捕捉水流。用席德尼·加乐尔的话说就是，自我里面的方法很重要，而是为了让让你更好地进入到自我之中，达到身心合一之体。

“存在这个东西感觉还是比较抽象，请问老师你说的存在是自然还是事物的本身呢？比如说意识、情感的状态就是深不深刻呢？而对于理科和科学里的人和他们的思维，是否找到对科学层面的学科思维呢？在应该是不局限于感性存在吧？应该有很多种类的存在呢？”

**武志红**

在我看来，任何一个领域，思维模式都不再第一位。在类似《活法》中等的河和湖，他一直用公式思维指导，在符号系统中做事象，这样的模式我很难说导有出有创造力的东西。

爱因斯但的直觉化思维更容易有创造力。他老门以出说道，数学思维很重要，但他也补充说过数学思维需要直觉。大科学家们都会感到自己们所学的领域实在太了。他们感知到了这个东西，从来不是只是活在符号思维中。

我目前在家族企业里矛盾很纠结，想成为自己，又怕自己太过武断任性，这个尺度到底如何把握？

**武志红**

当我们在想自己的路时，就会是这样的话：逻辑；我选择，我自由，我存在，还有负责；当我们是别人想让我们走的路时，放弃了自己的选择权，同时也免除了自己的责任。所以，也许你就是最害怕走错井为此负责而已。

人生是一长条路，如果你给自己时间去感受，想5年，10年后，如果还在家族企业里，那么会什么样呢？

如果在家族企业里，可能也会发挥你的主体性，好好思考你想在这里要什么，而不是长辈们想让你怎么怎么样。

我一直觉得各种成熟的套路非常好用，特别是对待与学青春来说，这是个简单的方法，老师对对于套路怎么看？我总总是先了解，然后自己去做，然后我通过自我思考，变成自己的东西。我这种方法与老师说的“尊重自己的感觉”有什么区别呀？

**武志红**

一个成熟的套路，就是别人曾经找到答案的路径，先走它开始，这是可以的，甚至还是个不错的办法。

只是，自己一定得知道自己的感受，让自己的感受知道这个过程有意识体，要尊重自己的感受，敢于去犯它这个套路，当然同时也要反思自己是去悟悟，不要把套路的驾驭于自己感受之上。

如何能更好地将次级情绪语言文字，将我们初级思维产生的感觉描述出来呢？很多时就总是有类似的感觉，但是一用文字表述，就没了那种感觉了。

**武志红**

我觉得你你可以试试放下一切想思维的努力，就是随意表达，想写什么就写什么，直到表达出你的感觉。首先到感觉，然后试着在写作时务必得自己感受。接着，需要去练习，或许就需要去“一万小时定律”。

不过我想，最重要的是让在自己的感觉的流动中，且要有一个好的对话对象。

我研究时曾得过抑郁症，抑郁症痊愈时，感觉内心很多打着结的河流都解冻了，那时候我正好认识了一位网友，我们一直通过电子邮件联系，各自写了两三万字的信件，我现在都仍然觉得那些字是我最高水准。

流动的感觉，和一个好的交流对象，产生了不可思议的结果。
