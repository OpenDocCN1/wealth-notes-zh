# 问答：不做选择，就别追问意义

> 问答：不做选择，就别追问意义

武志红

这节课是专栏的问答篇，我先谈一个节点，再回答一些用户的追问。

# 我想讲的这个观点是关于悲剧的。

在无常面前，我们容易感受到自我的虚弱，而且无力太找替，我们也容易觉得自己的人生因为无常而像是悲剧一样。

可是，如果你没有做主动的选择，那你的人生悲剧就都没必要了。

这是古希腊哲学中的一个表述，古希腊传说中有很多悲剧英雄，例如《俄狄浦斯王》就是古希腊三大悲剧之一，故事的主人公俄狄浦斯就是个主动做选择的人。

他被视为英雄，因为虽然世事无常，但他一直在主动地尝试去做正确的选择。

在这个故事中，当俄狄浦斯听说他的未来是弑父娶母时，他就逃离了柯林斯王宫，而想去躲避来自天神的预言。

可是，造化弄人，他其实是普洛柯尔斯国王夫妇收养的，他亲生父亲是科林斯国王。

俄狄浦斯无路可走的路，也是回家的路。受命途的驱赶，他流浪到科林斯，而在路上，他受到了一次仇人的欺辱。

为了保护自己的尊严，他杀死了仇人，还死了四个手，却有了他的亲生父亲。

弑了国王之后，打败国王后，娶了王后，而王后就是她真正的母亲。

而这也没法阻止了灾难发生，他成了自己的敌人。

俄狄浦斯不畏艰难地杀死了斯芬克斯，而且终于破译了她的谜语的方式，这意味着他也是最具有智慧的人。

可是，他的智慧还达不到最终得救的地步。

随后，他成为忒拜国王，兼备智慧、勇敢与力量的他，是一个很作为的好国王，将王国治理得很好。

但接下来，他的王国遭受瘟疫，他也于是为了拯救他的王臣，因为发现了自己父母犯下的罪行，于是，他刺目双珠，再次主动选择流浪。

虽然无命命途的驱使，而俄狄浦斯一直在主动做选择，他虽然有破碎自己的命运，他却也是悲剧英雄。

所以，这个虚构故事让我感受到，如果一个人从未做过选择，那只是觉得自我的人生悲剧，因为那其实不过是虚无主义的笑话而已。

# 单元问答

请问武老师，我们平时理解的无常不就是不确定吗？

武志红

是的，我觉得无常的确是不确定性，而人性为恐惧、抵御不确定性，是因为惧在不确定性中藏着死亡，就藏着能量，就威胁。

所以，这个单元其实是说死亡，上一节我们主要讲的是头脑里的“死亡”，这一单元讲的是肉身里的“死亡”。
