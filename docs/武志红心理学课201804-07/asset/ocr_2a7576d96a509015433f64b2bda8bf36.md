# 无常08 | 身体与选择

![](bbox=[0.05, 0.15, 0.15, 0.22])

武志红

我们这一单元的主题是“生命的意义在于选择”，这是第四讲，“身体与选择”。

我出过二十多本书，其中读者反馈最有疗愈性的一本书就是*身体和答案*。

记得我写这本书是一个很重要的转折点，那就是2008年，我开始做催眠一系列课之后，发现身体是如此敏感，它比头脑聪明。我记得当时给这本书起名字的时候，我使用最多的一句话是“聆听你身体的声音”。

我还计划写第二本，书名也想好了，就叫*身体的答案*，一些著名的内容其实在我们这个时代心理学中出现了，如*已有的隐喻*、*呼吸的隐喻* *身体的隐喻*等等，它不断深入认识这个主题，当年常常回想起鲁米的演讲。

身体只是一个仪器，用以测量精神的天地。

透过这里来观测，
让人感受得更加海洋般浩瀚。

我们心理学上在某一单元一直探讨“选择”这个话题，可我们知道，自己的选择是对还是错，是好还是坏？有测量工具吗？我认为是，身体，是一个测量器，很直观。

只是，身体看来太普通了，很多人容易忽略，若一旦生出死生级别的大事面前，它可能会让你一些警告。

我曾经采访过一位肝脏中有癌瘤的老人，他有雪白的头发和纹身的皮肤，看上去非常老。这位老人曾在上世纪八十年代的时候，查出了肝癌，当时医生说他只有几个月的时间，但这位老人做了一系列“选择”，最终得以痊愈。
