# 自由06|两种愤怒

武志红

我们这一单元的主题是“让情绪流动”，这是第三讲，题目是“两种愤怒”。

听到这个标题，你肯定第一个想到的是哪两种愤怒？所讲的两种愤怒，一种是愤怒，一种是好的愤怒；和坏的愤怒。好的愤怒，既能保护你自己的空间，也能促进关系向建设性的方向发展，而坏的愤怒，常常只能带来破坏。

我先来讲一个故事，来帮助你理解这两种愤怒。

有一位男士，我们暂且用A代替，他有一位朋友，咱们用B来代替。A总觉得B是觉得他蛮了不起的，有一次，A和B同时去上厕所，B接走了他多少次小便，A一直觉得B是各种各样会占A的小便宜。

A认为自己是个人物，所以对B占小便的行为并不一驳一驳，可内心中的怨恨还是变得很严重。有一次，A中过一件B接走了他多少小便，A大怒，觉得这个人怎么这么不知好歹。并且，当说上B，B还透露出一种感觉，好像是觉得A是个不能保护自己的、让人瞧不起的蠢货。

B的这种商业上的趾高气扬的态度，让A更为恼火，于是，A设计了一个连环套，让B不断中计，最终遭受了一连串损失，然后A再不经意地透露，你看我怎么这么低，这么容易就被算计了。

做这些事情，A做好了两个人关系玩忽的准备，但没想到，遭受了一连串损失的B，竟然从A表达了尊敬和歉意。从此以后，他们对关系还变得很友好。

这个故事让A明白，原来表达愤怒、“报复”和“设计”，当然，这里的报复算是打着引号的，竟然也可以带来别人的尊敬和引见一个，更变得更好。而不是只会破坏关系。后来，A在表达愤怒上容易了很多。

我觉得这很愤怒的独有价值。人们通常尊重的都是些，一个没有愤怒与力量的好人，容易获得同情，但没有获得敬重，不仅如此，美国心理学家托马斯·摩尔在他的著作《灵魂的深夜》中还说道：

> 你最好只和那些会表达愤怒的人做朋友。

他为什么这么说？我认为至少有两个原因：

+   1.  一个能坦然表达愤怒的人，会很快速表达他的立场和态度，这样可能可以很小幅度，他立即愤怒，而不是直接表达他的立场态度，这会让沟通变得更高效。
2.  愤怒是人的本性，说出的愤怒通常消失的，愤怒还会让人其他方面表现出来，并且，压抑自己的愤怒是觉得愤怒是破坏性的，所以一旦他表达愤怒时，常常会有破坏性的后果。

例如，太压抑愤怒的人会使用被动攻击，例如拖延、遗忘、莫名其妙的错等等方式，从而阻碍事情的发展。
