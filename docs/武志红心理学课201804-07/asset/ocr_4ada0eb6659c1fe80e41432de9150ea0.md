米哈里·克孜米哈赖（Mihaly Csikszentmihalyi），积极心理学奠基人之一，“心流”理论提出者。他在建立积极心理学这门学科的过程中作出了主要的贡献。著有《生命的心流》《创造性》以及《幸福的真谛》。

# # 心流

#### 奥托米尔哈赖

当这种美妙的体验发生时，就像是“一股洪流带领着我”。它是生命力有无限涌现。

心流的体验与高峰的体验有关。心流的体验都是级别很高的核心体验。

心流是生性难改，找一个你基本能控制的、有趣的、稳定地投入其中，并具有挑战性的事，但是所做的一些事，有超出你的能力，但不要太超出太多，然后不断用力，并不断接触到正确信息——就是你的努力有效，那么心流——心流就可以出现了。

**参考课程：**《问答：心流与高峰体验》

梅兰妮·克莱因（Melanie Klein，1882-1960）女，奥地利精神分析学家，儿童精神分析研究与客体关系学派的先驱，被誉为“客体关系论之母”。生于维也纳，先后师从弗洛伊德的弟子费伦奇与亚伯拉罕，她开创了理解最早期的心理历程的途径，是继弗洛伊德后，对精神分析理论发展最具贡献的领导人之一。

# # 位态

梅兰妮·克莱因

位态（position），一年前婴儿的心理发展，有两个不同的位态：偏执分裂位态和抑郁位态。

正常情形下，三个月前的婴儿，是处于偏执分裂位态，而三个月后的婴儿可以发展到抑郁位态。

处于偏执分裂位态（偏执妄位态）时，人会各种严重的全能性幻觉和全能感的内心动力。处于偏执分裂，婴儿就有的内心动力。所谓内心，是婴儿没有，格有能力来对抗客体，因此自我内面，内心常常充满了情感。

**参考课程：**《现实11】偏执·分裂与整合》

约瑟夫·坎贝尔（Joseph Campbell, 1904-1987），美国著名作家，神话研究的顶级学者，比较神话学大师。他探讨人类文化中宗教信仰的共点同和神话的共性关系，仔细研究了世界各地文学和民间传说中的神话原型，创造了多个系列影响力极强的神话学作品，跨越多个领域，包括《千面英雄》《追随直觉之路》《指引心里的神话》《神话的力量》《坎贝尔生活美学》。

# # 英雄之旅

约瑟夫·坎贝尔

我选择，我自由，我存在。在坎贝尔看来，最首要的，或者说最本真的，就是克服内心的恐惧，摆脱为了内在黑暗而达成的一种状态。这个过程就被称为“英雄之旅”。

英雄之旅就是重新开启自己生命中的，他有三个阶段：

+   1. 花痴：孩童在伊甸园中的生活，纯真美好；
2. 沙漠：你如同骆驼，忍辱负重地行走；
3. 狮子：你有力量地活着。

**参考课程：**《动力21】英雄之旅》

葛雷格·贝特森(Gregory Bateson)，英国人类学家，杰出的沟通大师。贝特森是20世纪最重要的社会科学家之一，是许多传播学研究课程的老师者和开创者。他认为20世纪最重要的三个基础理论是控制论、信息论和系统论的丰富和完善作出了重要贡献，他开启了元传播、双重束缚、关系传播和学习的传播机制等研究的先河。

# # 双重束缚

贝特森

人们互相沟通的时候，一个人同时也在交互的不同层面，而另一个人会发出互相依赖的信息，对方对此会做出相反，但不说任何来向反对。必须得到相反信息，就容易使人陷入两难的境地。精神学家的理论就是这种现象的表达。

当父母既承受不了孩子撤退，又接受不了孩子不沉默时，就是将孩子置于了“你说什么不行，不说也不行”的矛盾中。这种矛盾，就是“双重束缚”。

**参考课程：**《现实12】可以好，也可以坏》

马丁·塞利格曼（Martin E. P. Seligman 1942），美国心理学家，著名的学者和临床治疗师与治疗专家，积极心理学的创始人之一。主要从事于重寻习得性、抑郁、乐观主义、悲观主义等方面的研究。

# # 习得性无助

马丁·塞利格曼

20世纪60年代，塞利格曼经过动物实验，提出了习得性心理学的理论模型。

动物在事先的经历中，学到了“自己的行为无法改变结果”的感受。因此，当它终于置身于自主的新环境中时，也会放弃尝试。

表现在人身上，往往是一个人当人在某情或经历中形成了“行为无效的高原”的信念，可能会觉得注定一无所获的感觉或无意识的新情境中，甚至无意识的甚至其实现来本可以控制的情境。

**参考课程：**《创造07】内在批评者》

美国职业培训大师，挫折商（Adversity Quotient）概念的提出者。

# # 挫折商

保罗·斯托达

挫折商，AQ（Adversity Quotient），也被称为抗商，是一个人应对挫折的能力。

挫折商低的人，面对挫折时启动的是应付机制，用种种消极的方式来逃避难堪的情境。挫折商高的人，这时他的挫败的挫折，他会激发更强劲的行动的力量，并调动他的能力，最终化挫折超越挫折。

挫折商有三个因素：控制、归因、延伸、耐力等特性。

**参考课程：**《报告：提升你的挫折商》

玛格丽特·马赫（Margaret S. Mahler, 1877-1985），精神分析心理学家，出生在马赫，曾在维也纳的接受训练，后移民到纽约，她从事实儿童期工作，在儿童发展层阶段上而著称。她论述了在心童年“两个分化”时期，所经历“自全能全能”“到全能感受”的成长过程。

# # 客体关系理论

玛格丽特·马赫

性格，是一个人内在关系模式，是对客体关系理论的概括性表述。客体关系理论（Object-relations theory）：指的精神病学的理论，可以概括为三种组：

+   ·性格，在关系中形成；
·性格，在关系中展现；
·性格，在关系中改变。

这三句话的另一面，就是自我、人格和名词的同义词，也可以是“问题”的同义词。

**参考课程：**《关系01】性格是你的内在关系模式》
