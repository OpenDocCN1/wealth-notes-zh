# 武志红

“我”与“它”的关系中，“我”在利用、吞
吃“它”，常常是一个单向的能量，是我将
自己的意志强加在作为目标或工具
的“它”之上。

“我”与“你”的关系中，“我”与“你”同样尊
贵，甚至“你”更尊贵，我臣服于你。总
之，我任由你的能量穿越我，同时我也能将
能量自由地流向你。我体验到好像我就是你，
你就是我，所以能量流动很自由。

发生任何问题时我都觉得无助，觉得
外境不友好。这时候只愿躺在床上什么
不想、拖延看，不去解决，我应该去
接受自己这种现状吗？怎么才能做到勇敢
面对问题呢？

# 武志红

这种状态下，你需要得到帮助。可以说，
这是你的自我被破坏，但因为没有了内聚
性，所以破坏后就像是被瓦解了一样。少
数时候，这样待着，也是在积聚能量，
让瓦解的自我重新聚合，然后就可以出去
了。但此时会太慢、太痛，代价也可能太
大。这时候会合适的是寻求关系的帮助。
借助关系的力量，先提供一个外部容器，
再内化这个外部容器，增强自己的“自我”
这个容器。

我认为有时候药物治疗也很重要，药
物治疗常常是降低或升高能量，从而
达到一个人能使用能控制的程度。

最初看到“无常”这个主题时，以为要
讲人如何面对死亡的话题，看了两段觉得
好像是要说人面对自我的死时的一些
问题。请问人面对亲人或对其关系亲密
的人的死时，应该怎样进行心理调适呢？

# 武志红

因为心理学课一直在谈“自我”，所以到
了无常这儿，也没怎么谈亲人死亡带来的
问题。如果在这方面有问题，我推荐瑞士
心理学家维娜·卡斯塔特的著作《体验悲
哀》。

简单来说，我们不仅要体验悲伤，完成
哀伤过程，还要获得这种感受：爱是不会
失去的，任何外部世界的实在之物，都
藏在内部世界之中，外部世界有失去，
可内部世界对应的存在并未消失。

当然，内部世界也一样是无常的，在
彻底悟生死与善恶前，我们需要先假借一下
爱在内世界的恒常感。
