# 现实01｜越简单，越复杂

![](bbox=[0.05, 0.03, 0.95, 0.1])

这是“现实”主题下的第一篇文章“单纯”，这一讲的题目是“越简单，越复杂”。

这一讲的话题，是从两个故事开始。

我有一位来访者，是位女士，她学历、工作也非常好，可以说很精英。她长着一张非常单纯的脸，好像脸上就刻着“我很简单”这四个字。

而有意思的是，她总是喜欢上复杂而危险的男人，而且她还沉迷于一个相当有权势的小圈子。整体上，她给我的感觉就像是 一个傻傻的女孩，微笑着在一群有野心、有阴谋、有势力的男人堆穿行着。

不过，她是真的很简单，她就是对这些危险的男人好奇，自己丝毫没有野心和心机，而这个小圈子中，关键人物对她如此单纯也起了圈护之心，对她有所保护，所以她还算安全。

我和她探讨，她为什么会爱上复杂而危险的男人呀，她说，她知道自己太简单，自己的父母又太简单，但实际上这样的简单是一种软弱。所以她对复杂背后力量非常感兴趣，她说，她是最喜欢游说的女性，她有教养的男人不惧怕游戏的关系。

还有一位来访者，也是位女士，也有类似的情况，只是她没有痴迷地和危险男人打交道，也没有沉迷有权势男人的圈子，而是作为一个超级讲求道德的女人，她给了一个毫无道德可言的男人。在这个关系中，她先是感到自己容易被刺和利用，而这就的确是她和他想象中的感受一致。她有着直接证明她这关系的，当看清起来过程非常艰难。她一开始觉得，是丈夫不想和她离婚，最终发现是她自己不想离婚。

在咨询中，我问她什么会对这个男人感兴趣，她一开始给出一个简洁的回答，说她急着嫁人。后来，她又给出了一个复杂的答案，说自己还是一名校的学生，她想出来的父母太简单，格物太小的时候，也一样，他们一家三口活得像“傻子”一样，所以想找一个聪明人。

我个人的这两位女士的故事是同一类型，最简洁的两人选择了最复杂的男人，并且她们是有明确的主观意识的，而之所以以这样的选择，是因为她们的认识到她们父母简单的某种方式一种本能的识别，所以想找复复的男人，因为在她看来那份复杂意味着力量。

这些男人报复来形并不准确，更准确的表述是她们对复杂而无情，他们将没份混合了狡诈和天真的复杂。在两性关系中，所以，第一个故事中的女人，作为一个简单女人，却选择了最复杂的男人做伴侣，很容易付出可怕的代价。

从另一方面来讲，这样的选择非常常见，起来可以这是一种很难抗拒的选择，对于简单且自我体系的人来说，是走上复杂并增强自我的一条常规之路。

世界是相反的，当你看到了A，就意味着你看 不到B。从这两位来访者的故事中，我觉得能够感受到这条规律在发挥着作用。

刚才我们说了女性的简单，下来来谈说男性的简单。王小波在他的小说和杂文中都讲过，社会特别崇尚“憨儿”现象，就是一个小伙子，  他要么是身强力壮，一脑子道德观念，但头脑简单，一看到不道德的现象，特别是男女之事，就去打抱不平。

很多影视文学作品中都塑造过这样的“憨儿”形象，最经典也是我喜欢的，都是金属型，饰演角色，演员刘超在电影《硬汉》中饰演的形象，是一个有超过正气凛然的憨儿形象，他脑子坏了，可  力壮，像着一杠红枪到处打抱不平。再以演员主强演的各种形象，也是典型的憨儿形象。

我觉得这个憨儿形象的特点可以概括为以下四点：

+   1. 简单。心口如一，怎么想就怎么说。

2. 道德。他执意于道德原则，也会去做别人不做的事。

3. 不动脑子，不做复杂的思考，而是简单直接按道德原则行事。什么是道德的，就按什么原则去做，所以显得一根筋。

4. 绝对自信。认为抱者以上的原则，所以会觉得自己绝对是对的，而不容易有动摇。

憨儿，是一种极为简单的活法，在这种活法中我们可以找到。很多人不喜欢纠结，不喜欢矛盾，自己想到一种简单的活法，想用这些简单的原则活一辈子。

但是，命运不会给你这种好处。命运，会 给这样的人最复杂的问题。通过这些问题让人看到，明白这种活法的局限。而且，更可怕的是作一个简单的人，如果 你仔细去看，就会发现这种活法是命自制造出来的。那些复杂的问题，常常是简单的人自己主动邀请到生命中的。

从心理学角度看，一个在某一生活面分类数太多的人，其实是活在做挑分裂状态。意思上，他人在极端的A边上；在潜意识中，他有极点的A，只是将A压在 深处，甚至自已都不知道具有复 性生活中，就好似已经决绝它的一部分切割掉了。这个人，他需要通过潜意识层面唤起A，然后通过和他们建立关系，学习人性这一部分。

我个人认为可以说，他的潜意识要通过这个人表达出来，这样一个人就有机会看到自己内心的一小部分，具备说就是， 人的这一小部分。具体来说就是，最不老实的人，会做最老实的事；最没有心的人，会被最有感受力的人吸引；最没有欲望的人，会被欲望满的人吸引等等。

所以我多次讲过一个观点：追求人性完整的力 量，要远胜过追求幸福快乐动力。

活法，常常看起来很傻气，有时会像 像章那样种仙，又常到了章种样仙人般的去活这种憨，现实中并不多见。痴心人，是人的需要，如果不够简单，痴心人过于执着，不会击中，  就不不会醒。

上面的这些表述，我觉得还是在一定程度上美化了简单，说简单是一种非常纯正的防 御，而防着你看是为自己一个自己一种好的感受：你看，我是一个这么有道的人，我没有坏心眼，我是对的，我是好的。

道德上的自我良好，可以让我们回避 复杂的高超，简单人的概括理解。并且，有意无意，简单人“好”生命中，  他人身边，势必会带有复杂的人。

所以，活得太简单的人，需要看到自己这 份对道德的自恋。并且，要去做一个正对自己的人，也对自已最需要的东西，要去抱者一种简单信条去生活，道多了一些。

人性无比复杂，但你要求任何人都是简单 活法，可以说：任何人都没有简单活的福气。

# — 今日得到 —

+   1. 简单是一种强大的自我防御，根  本是为了给自己一种很好感觉。为此会自  己道的人，以回避掉自己复杂而简单 人选择复杂问题，这是最简  体或别的，走上复杂并增强自我的一条  规之路。

2. 活得太简单的人，需要看到自己这份  道德上自我良好，并且要去做一个正  对自己，要对自已最需要的东西，要去抱  种简单信条去生活。
