# 创造13|疾病的隐喻

武志红

我们这一周的主题是“创造与枯竭”，今天是第一讲“疾病的隐喻”。

上一期内容中，我讲到了男人的中年危机，今天我来讲一个女人的故事，从现象上看着是一个女人的中年危机，但我觉得还有更高的要求。



这个故事，可以让我们看到在《创造05|迪士尼的策略》这篇内容中提到的那个将“梦与现实关系”的提议做了很极端的实践，它可以灵活使用的，而非只能在创造中使用。

并且，这个故事的主人公，就是这个分别练习的发明者——罗伯特·迪尔茨。

那是38年前，迪尔茨的妈妈乳腺癌复发。

在复发的第二年春，迪尔茨妈妈的一个乳房被发现有一两个腋窝，在医生的建议下做了手术，切除了乳房。然而，癌症还是复发了，肿瘤除了乳腺室外另外三个乳房、卵巢和膀胱，还蔓延到了骨骼中，锁骨上的一个肿瘤，甚至大得把骨头都裂开了。



病情非常严重，医生们对迪尔茨的妈妈讲这已经是癌症晚期，只有几个月可以活了。



但真的一定会这样吗？那时才二十多岁的迪尔茨想。也许他总结的“迪士尼的策略”可以用到妈妈，于是他亲自鼓励妈妈去辅导。



他问妈妈说：“你的梦想是什么？”妈妈回答说：“我没有什么了。因为我没有什么时间了，那些梦想没什么意义。”



根据我们之前《创造03|爱因斯坦的策略》一期内容中所说的，如果一个人连可视化梦想的能力都没有了，那只剩下绝望了，这时谁什么人都帮不了她了。所以迪尔茨让她知道，她首先要唤醒妈妈的梦想。于是，他继续问妈妈：“如果有得话，那会是什么？”



这样问实际上是给梦想一个单独的空间，根本不用去思考是否能实现、是否会招致批评攻击，大胆地去让梦想涌出即可。



听到儿子这样问，迪尔茨的妈妈眼睛亮了一下——她说，“生命中有一个重要使命没有完成，她渴望完成它。这样一来，梦想就有了，并且不是头脑的想象，而是发自她心灵深处的声音，这个梦想非常有生命力。



但是，一旦到“现实主义”者的位置时，她就会变得那么一种成力的计划了，因为她以前听那么多，而成了死刑了，只有几个月的时间，并且在活得那么重的情况下，她怎么可能想一个可计划的计划，去完成她想要的。

在无数人看来，这像是一个真理一般确定无疑的事实，但是，这其实仍是人类的一个限制性信念，并不一定是真理。

我在《身修05|绕开情绪的催眠大师》一期内容中写过艾瑞克森的故事，迪尔茨和他的催眠老师布莱芬·吉利根一样，都逃不过艾瑞克森，他17岁时得了一场严重的小儿麻痹症，三位医生宣判了他的死刑，可他不仅活过来，而且在三年后还恢复了行动能力。



所以迪尔茨知道，他需要打破妈妈的这个限制性信念。于是，他问妈妈：“一定这样吗？你生活中有没有有这样的例子，本来以为会只是一种结果，但是后发现其他结果也是可以实现。”



这个问法打破了妈妈思维中的限制，她想到了好几个例子。一个是迪尔茨的大哥，他小时候是患过肌肉萎缩症，最后发现不是的；一个是迪尔茨的爸爸，他得了绝症，医生说他只能活六个月，他改变生活习惯，最终活了16年；还有迪尔茨的外婆，他看着迪尔茨的妈妈说，你说我的小儿麻痹症，你如果是我女儿，你可以吗，我系统有问题，不可能强盛自己生孩子，否则你们有问题，不可能去强盛自己孩子，总想要孩子了，她决定试一试，最终顺利地生下了迪尔茨的妈妈，后来又生生了三个孩子。



通过这些回忆，迪尔茨妈妈的想象力的疆域打开了，她不再认为等死是唯一的结局，她的想象还有可能性绕开它，并完成她的那个梦想，接着她也围绕着自己的梦想制定了一个可行的计划。也最后，她缓解了，又活了18年。



后来，迪尔茨的妈妈常说：“我有两次生命，一次是发现前，一次是发现后，唯命是我生命中最糟糕的事，也是生命中最糟糕的事。”这是一个罕见的神话，一个最糟糕状态最佳向转化的转化。



迪尔茨妈妈的这个故事，也许很多人会觉得不可思议，我在2008年听到这个故事时也是惊讶于神。但后来，我发现几位也得到过出现了“奇迹”的癌症患者，他们在癌症治疗中，都有心灵上的重大转变，同时他们也在积极接受医学治疗。



这种事情发生了在我最好的一位女性朋友身上，她的人生在我眼前地一瞬间：但她离开却离不了，就这样过了七八年，后来发现了乳腺癌，当我发现了癌症后，她立刻下定决心癌细胞，接着积极治疗，并且积极调整心态，后来竟然痊愈了。



我们继续讲迪尔茨妈妈的故事。当年，听到这个故事后，我采访了迪尔茨，我问他为什么这个练习会到他妈妈起到这么大的效果。



他回答我：“我们知道，一个人的想象创造了他的现实。”而这句话，他后来重复了几遍。



我接着问：“如果你的妈妈只是想一定要活下去，这就会出现吗？”



迪尔茨认为，如果这是自我1的需要，也就是死亡焦虑的激发者，那么“奇迹”就不会发生。他回答我，如果他不妈妈想听他，就一定要妈妈下去了，那这一“奇迹”也不会实现。关键是深入心灵深处，去看一看，底层是有什么扎住了，使得癌症这种最糟糕的状态发生。



他说：“首先把自己放一边，把那些我想要想法放到一边，记住奥特利的那句话：‘我从来不是追寻结果的人，我只是看我来到，音乐是透过我表现’。



现在我不是只到得到开设心理课程，我自己也是的超级用户（已经订阅了22个月，在几万美元级），《天经地义》当中，w大师一再说的一句话是Something bigger than youself，也可以在这里。



迪尔茨说，当十年后他和妈妈一起去检查身体，妈妈完全康复了，他骨上的一些没，用X光看不出问题了。那一刻，他突然意识到一个不可能的事实现了，那一刻，他充满了感激。



这件事让他对生命有了很多思考。他想到，英语中对病人“disease”的意思就是“不在”，这可以理解有些疾病是在不在不在的一种反应。



我这次多次讲过躯体化的概念，而迪尔茨把这个概念延伸，当他压制一些情绪不允许在在意识里表达时，他会通过身体表达，这就是一部分的疾病。当我不时一种症状是一种自我在说“不”。但我们不断听这种讯息，总终它不得不通过破坏性的方式来表达。



关于妈妈疾病，迪尔茨说他后来的理解是一个很深层次的内在矛盾，是自我灵魂的矛盾。一方面，她担心灵魂做不出自己另一方的，她担心自己失去别人的参与认可，这种恐惧得她按照别人的意见去行。于是，她生命的核心动力就都严重压抑了。最终，她的身体用极端的方式向这种活法说“不”。当她终于听到自己内心的停像，并尊重了这种听到和做自己的要求，身体不再通过破坏的方式来表达这一动力了。



迪尔茨说，他妈妈的这一矛盾，也是我们每个人的共同矛盾。生命不用各种方式呼唤我们，聆听并尊重自己的内心，在这个地方你是和整个存在连接在一起了。所有原，即所谓创造，都来自于这个地方。



迪尔茨妈妈的故事，也许对很多用户来说是会有种怀疑，会觉得是不可思议的故事，我以为这样怀疑是珍贵的。笛卡尔说“我思故我在”，本我思是我唯一确定的。就是这个故事也是说明我上一期内内容所讲的，你最大的创造，是从你的心态来创造。
