# 现实04|三重世界

武文红

我这一单元的的主题是“从想象世界到现实世界”。这是第一讲，题目是“三重世界”，也就是想象世界、过渡世界和现实世界。

首先，我们来回顾一个此前讲过的故事。

我在《自我14|真自我和假自我》这节课中，提到一位超级学员，他平时是严重的过型人格，他在高中劳动期期间，突然获得了“完美七天”的体验，那七天他完全顺从自己的感觉，做事无往而不利，并且他自己也没有变成一个人。

到了第八天，就是劳动期结束的这一大，他上课出现了特殊体验，觉得老师在黑板上写字时，那些字一个个如在撕咬，还闪着红光，每个字都不仅仅是黑板上，也直接进入到他心里。他如果觉得这样下去，他觉得自己时门课都可以满分。

中午的时候，他女朋友过来找他。如果他完全从自己感觉的话，他不想出去，可他想到的女朋友是从城市另一头的中学来到他的中学，他不可能出去，就太不近人情了，于是决定走出去，女朋友这个人的感觉，就仿佛她完美感有了损坏，从一百分跌到了七十多分。

接下来发生了一件很恐怖的事。当时，女孩站在一个十字路口的一边，她看到女友的那一刻，立即想别开，突然跳过去，但在被接妻到之前，突然有一种巨大的恐惧袭来，他全身瑟瑟发抖，瞬间汗如雨下，特别是小腿，那叫痛就消失了。并且，从此以后就是留下这个问题，常常突然有一股恐怖感袭来，然后瑟瑟发抖，小腿会酸痛流汗。

这一下，这个男孩的完全感已经荡然无存，在此之后，他踏上了心理咨询的道路。当我找到他的时候，他已经咨询过十多位心理咨询师了。

他给我的说法是，那七天的完美感觉就像住天堂一样，如果从这七体验没有下坠的感觉，他也就没有过真正在地狱的感觉，也就不知道，可体验过天堂的感觉后，再次感到在地狱里，他非常痛苦。于是做各种努力，想再次回到天堂里。

我找他做了两年多的咨询后，不再待在地狱里了，但也再回不到天堂，而是基本生活在60分的状态里。

在我们的咨询中，有过多次探讨70分及90分的那一瞬间，也就是他多次从做梦的时候，他的内心发生了什么。在一次自我催眠状态下，他脑海里有一个意象，在那个女子路口，他向女友，充满幸福感，但那是突然面目大变的她，举起了他的脚蹬，把他一直拉向一个坟墓。

有了这个画面之后，他觉得自己找到了答案。那只大手的，就是妈妈的手。他一直和妈妈处于紧张的共生状态，虽然有母亲，父亲也是老宅宅在家里，但妈妈说，除了你这个儿子，我什么都没有，你是我的。

我们讲过，只有婴儿在六个月内的共生状态，才叫正常共生，此后都是共生就是病态共生。正常共生时，共生要满足的需求，因为婴儿会哭呀了，不是婴儿活不下去；病态共生中，常是大人想和婴儿共生在一起，而孩子其实是想脱离共生，走向外部世界。

用精神分析的术语来讲，可以说婴儿本来就生活在过渡世界，也和妈妈构建的世界是过渡世界，整个家也可以视为过渡世界，而门外的，我们会现实世界。这就是我们这节课讲的三重世界。
