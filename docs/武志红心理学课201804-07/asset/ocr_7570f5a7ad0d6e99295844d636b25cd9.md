# # 自由01 | 自我实现者的人格特征 (上)

武志红

我们将这一讲的主题是“自我实现”，人们给你讲一讲最近“自我实现者的人格特征”，这一讲是第一讲。

我首先来介绍一下人本主义心理学家马斯洛的研究方法。

与精神分析一开始接触的多是心理问题患者不同，马尔洛多是直接研究478位杰出人物，比如林肯、杰斐逊和爱因斯坦。马斯洛认为他们就是自我实现者，他的研究对象也包括一些普通人，被称为自我实现者或可能的一些真实者，马斯洛的具体研究方法会分析他们的来信、作品等各种资料。

讲到这里必须要澄清一下，有不少人认为精神分析治疗的是病人，但即便在弗洛伊德那个时代，也不完全是这样，而现代社会能够接受功能欠缺的经典精神分析治疗的人多是高收入人群，弗洛伊德的来访者有很多成功人士，他们中至少有十多位，将他们接受弗洛伊德分析的过程写成了书。读取他们的书，你会发现有的病情不轻，但还真不能诊断出他们有什么严重的心理疾病。

同样的，像林肯、杰斐逊和爱因斯坦这些人，如果给他们做深度精神分析，他们一样是有各种问题。可以说，每个还没有像毛姆那一半开悟的人，都必然有各种各样的心理问题，而且仔细研究的活述都不同。

像日本一位精神分析大师，他始终认为精神分析是放羊的人，他一生中也只接受了几百位来访者，其中十几人坚持了他一辈子，到了后来，这些来访者也没有达到诊断标准心理疾病，还继续接受精神分析，就是为了更正面深入地解问自己。

再回到马斯洛这里，我们先界定一下什么是自我实现，也就是那些成为了自己的人。不过这个说法还是容易引起误解，我们比较容易说的是一个更简单的理解，就是拥有自主人格的人，他们自己决定自己，自己为自己负责。

自主人格，能一方面活在实中，他们生命力会充分看见，这部分生命力也因而更成熟，这会带来一些好处，让他们既能深入地理现实界，又能真诚地看待自己，他们的自我和谐，具备B认知的人，他们与世界的关系更为密切。马斯洛则认为，真正自主的人具备14个明显的人格特征，我们一一讲述下，这节课先讲前七个特征。

# ## 一、准确和充分地认识现实

马斯洛将人的认知能力分为两种：B认知，也就是存在认知（Being Cognition）；D认知，也就是匮乏认知（Deficiency Cognition）。

具备B认知的人，是现实怎么发展，就怎么认识，不会按照自己的想象，想象或愿望去认识现实。不自卑是具备B认知的人最明显的特点。相反，具备D认知的人，是按照自己的需要、想象或愿望去认识世界。

我们之前在课程中讲过“花轿子摸黑的信号”，这是讲的一位只听到消息的国王，这个故事是经典的B认知。这位国王有一种天真的逻辑：如果大家报的都是好消息，那么就会有好事情发生。

我再来举一个真实的案例。有一位大学，毕业后没有找到工作，到一个偏僻山区的伐木场做工人。他发愤图强，每年都考研究生，可每年的学校和专业，北京大学、人民大学、吉林大学，都不一样在变化。他几乎考得非常多，但学业成绩不升反跌，关键的科目竟然一年比一年分数低。

为什么会这样？因为他对考研一信心都没有，他只是借考研这种事情让自已和身边人知道，他是有上进心和远大理想的人。但他不清楚他的D认分形势，按实力报学名，而且每年都不切实际地报学名，名专业，甚至在复习时也毫无方法。他甚至不查他所报专业今年的参考书是什么。

这是典型的D认知，因为内心想什么，就会是什么，而且会根据自己的想法来行动，而不是根据现实来行动。因为需要自信，所以他对别人和自己说，他一定能行。

寓言故事《皇帝的新衣》中的小男孩，到了宣传现实者，这是最能识B认知的，有B认知的人不会因为任何原因改变自已对事物的原认识。所以，可以说B认知是自主人格的基石。

# ## 二、宽容而又嫉恶如仇

具备这种人性格特征的人能看到事物的两面性：一方面，他们深刻地理解人性的善弱，具备高度的宽容；另一方面，他们对人性中的恶意有高度敏感和抵触。

例如王小波，他的作品既幽默又性弱态描写得入木三分，善或似恶似悲无人留下。但同时，他的作品中又有无限尺的宽容。

# ## 三、对自己的体验全然敞开

具备这种人性格特征的人，对自己的内心体验全然敞开，自然地表达情绪和思想。他们坦率，自然，也不落入俗套，而且按照本心去行动。

# ## 四、以问题为中心，不以自我为中心

具备这种人性格特征的人，他们为工作而工作，而那些非自我实现者，是为生活而工作。

以问题为中心的人在做事时，非常投入，把事业，为业自身而吸引，而不是当把事业当成职业，或者赚钱权力者相当主要目标。非自我实现者则正好相反，他们也也许会热爱事业，但求去的是非事业本身，而且是了产品目，比如说别人，赢取社会经济地位，甚至变态地要求其他人服从自己。

在工作中，自主者总是新息不断，创新仿佛总是信息来自，这也是因为B有B信念，而不是D认知。

# ## 五、超然独立的性格

是指具有独处与独立的强烈需要，自己就判断，不依赖别人。

# ## 六、不迷信权威和文化

是指权威和文化对他们没有压力，不随大流，不受制于文化环境、权威而被动选择。

# ## 七、清新隽永的鉴赏力

具备这种人性格特征的人像是没有“审美疲劳”，能永恒地，惊奇和愉悦的心情体验并鉴赏一生中所遭遇到的各种事情，并频频产生“高峰体验”。

在这里简单解释一下高峰体验（Peak Experience），这是马斯洛在他的需要层次理论中创造的一个名词，是人类最需要的需求，人类在越接近自我实现的高处体验越迷人。这是越主要和愉悦的情感。高峰体验指在人在追求自我实现的过程中，基本需要的短暂、满足到，自我实现时那种感受到的短暂、满足、极乐的感觉。这是一种始于顶端、超越时空、超越自我的满足与完美体验。

在高峰体验时，人会产生一种存在认知，这与一般的认知不同。这种体验仿佛与宇宙融合了，是人类自觉的顶点时刻，是超越自我的，忘我的、无我的状态。

马斯洛归纳了高峰体验的六个特征：

+   1.  产生的突然性；
2.  程度的深刻性、强烈性；
3.  感觉的审美性；
4.  存在的普遍性；
5.  结构的一致性；
6.  时间的同一性。

高峰体验其实是“我的品质与其它重要的高B本质的联系”。马斯洛对此提出了B价值和D价值的概念。

所谓B价值，就是存在价值。自主者既理解自己，又理解别人和自然，他们能以孩子般的心态欣赏一切，可以看一看日日落而不厌倦。

D价值，就是匮乏价值。非自主的人需要别人和物品满足自己，我们根据这些需要给他人和对象定义上了一些意义。当需要消失时，别人或物品对其而言具备的价值也就消失了，“审美疲劳”也心而生。
