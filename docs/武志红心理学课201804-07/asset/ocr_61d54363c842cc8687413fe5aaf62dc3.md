# 自由02 | 自我实现者的人格特征（下）

武志红

我们再一单的里主想是“自我实现”，我们分两次讲自讲和自实现者的人格特征，这是第二讲。

上以讲中，我讲了马斯洛自我实现者人格特征的前七种，这节课将讲讲后七种。

之前我讲到，马斯洛的七层需要分为两大类，较下层的前四层称为基本需要，也称为匮乏性需要。关于匮乏性需要，我再多为你讲一点。

在马斯洛的需要层次理论中，当基本需要没有得到满足时，人的心理能量会集中在追求这些基本需要上，如生理需要、安全需要等重复重现，对它们的追求就成为第一位的，生存便没有到生所存性。也就是说，当死生成或压力或张力后，对生存资源需求就成为最渴求的东西。

需要层次理论没有解释力，那也也从精神分析的角度来说，匮乏需要、匮乏认知和匮乏价值。我做咨访者以后发现，一些心理和现实功能发展程度很低来访者，会存在这个问题。他们认为这个世存在符合他们的想象，由于他们不能现实，总是把自己的想象加在现实之上。

例如，有一位女士，她的人际关系一直糊态，因为她有着这样的心理逻辑：

+   1. 我需要爱，所以别人必须要我；
2. 不爱你，我就恨你；
3. 恨一个人，我表达愤怒；
4. 我不表达不，因为人人都应该爱我，他们不需要，我就爱伤去。

想信你可以一眼看出这个逻辑里的问题，别人没有爱你的义务，而你动不动就愤怒，很容易破坏人际关系，刚才这个例子中女性来访者就没有朋友。她能是认知现实是是么回事，不然就没有咨询的问。她知道，自己总不动就爱愤怒攻击别人，导致人际关系实在太太，而问题了一系列问题，每当谈到这个问题，她就会说：“我不是需要爱吗？什么他们就是不能满足我呢？”

马斯洛将匮乏定义基本需要的匮乏，基本需要有：生理需要、安全需要、归属与爱的需要等归属。这位来访者所匮乏的，可以说是自由需要。不过，我认为是马斯洛调查研究法并不能解释其中的匮乏或现，而精神分析可以出很精确解释。

在精神分析理论看来，这位来访者或处在最原始的未自态之中，她认为自我需要获得满足，否则就会生出负性情绪。同时，她觉得世界应该有一个可以满足的客体，就像婴儿幻想应该有“完美乳房”，可以满足他的所有需求。

这位来访者最开始得到的满足太少，于是她不能从现实中，而必须活在自己的想象中生存，幻想可以满足，而现实只会让她感到绝望般的匮乏。

从这个角度讲，那些能活在认知和存在价值中的人，因为他们的基本需要满足，于是不再执着。当然，很多人处于一种临界点上，这时，爱和适度的满足，可以帮助他们从匮乏认知和价值，过渡到存和存在的价值中来。

讲这些，也想对还不是自我实现者用户说：别着急，慢慢来。

好，接下来我们将讲马斯洛总结的自我现者十四个人格特征的后七个特征。我写一下，分别是：

+   1. 准确和充分地认识现实
2. 宽容但又顺从
3. 对自己验全自然开
4. 以问题为中心，不以自我为中心
5. 强烈独立的性格
6. 不迷信权威和化
7. 清新完整的鉴赏力
8. 真切的社会情感
9. 深厚的人际关系
10. 民主风范
11. 高度的道德感
12. 批判精神
13. 接受模糊状态
14. 高创造力
