# 创造14 | 职业枯竭

这是「创造」主题下的第四单元「创造与枯竭」，这一讲的题目是“职业枯竭”。

首先，我想问你，什么是“职业枯竭”呢？

有一次，我和一位专业摄影师聊天，得知这位摄影师大学时迷上了摄影，毕业后，他以兴趣将他进入了一家大型广告做专职摄影师。但工作了十几年后，他基本失去了对摄影的热情，所以现在继续做摄影师，只是因为“它是一份还不错的工作，可以养家糊口”。

这位摄影师身上发生的事情，就可以被称为“职业枯竭”。

美国心理学家贝弗利·波特说：典型的职业枯竭是，你有工作能力，但却丧失了工作动力。常见表现包括：觉得工作索然无味，毫无意义；觉得自己脑筋呆滞，已经油尽灯枯；厌倦工作，缺乏明天去工作的动力。

贝弗利·波特（Beverly Potter），美国心理学家，获得斯坦斯大学咨询心理学博士学位，旧金山东加大学职业康复咨询学硕士学位，曾经写过众多关于工作倦怠和工作节奏的著作，代表作《不焦虑的秘密》。

贝弗利·波特将职业枯竭称为“职业抑郁”，因为和抑郁症患者一样，陷入职业枯竭的人会有深深的无助感。

波特认为，导致职业枯竭的原因可以归纳为两类，无助感和习惯化。无助感是指一个人觉得丧失了对自己工作的掌控感，觉得是领导和收成，而不是专家工作动力；而习惯化是指一个人日复一日地重复同样的工作流程，最终枯燥倦怠。

# 无助感

波特的无助感问题，其实也就是在《空间05 | 维护你的权力空间》这一讲中讲过的权力空间问题。当一个人彻底失去权力空间，在工作中沦为其他人意志的执行者，就会慢慢失去热情和创造力。

我们要厘清情感是，这种或某一个人的人生热情并不是“消失了”，而是转变成了对自己的攻击，原本的白色生命力变成了黑色生命力，本能变成了死本能。

我来再给你讲一个故事。有一位男士，进了深圳一家港资企业，做机房的销售工作。他特别能吃苦，第二年，第一年就成了一冠，收入也因此很高，老板非常器重他。然而，他却陷入了职业枯竭状态，越来越不愿意出门，不愿意见生人，公司组织出差，出差回来会想尽快回单位，即便回了单位也不愿意见老板。

为什么他会这样？这位男士很清楚，原因在他的老板太“霸道”。老板不仅制定一切销售策略，也过问一切销售细节。老板说能力不够，他得看自己老板的，在打拼，这位男士觉得自己只是老板的一个棋子。最终，虽然收入不错，但这位男士还是提了辞职。
