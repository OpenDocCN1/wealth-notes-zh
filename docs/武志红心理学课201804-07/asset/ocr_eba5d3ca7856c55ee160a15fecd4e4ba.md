# 复盘：关于“现实”主题的回顾

> 复盘：关于“现实”主题的回顾

武志红
我们专栏讲了“命运”、“自恋”、“关系”、“动力”、“思维”、“身体”、“情感”、“空间”、“创造”和“现实”这十个主题，这一节课我们来到“现实”这个主题，最终让我们对“现实”这个主题进行一次复盘。

在我本来的计划中，这一主题是想写金钱名利，但得到了要写时，我发现权力我已经写得够多了，而名声这个东西，也没有那么复杂，于是就剩下了金钱这个主题，但我为金钱这个主题更重要和简单与我，切切实实的结构。这些话题，我非常非常有感触，不过有的时候，还是觉得写得不够酣畅淋漓，留了点遗憾，我会在这节的尾段课程里进行了迭代，弥补这些遗憾。

目前这个课程是1.0版本，在我的计划中会有2.0和3.0版本，去修改和完善这个版本，最终让这一门心理学课达到我心中的一个极致。

我写得不够酣畅淋漓，是因为有些东西在这里卡着，把“坏”写透，我是有一些恐惧，有很感感到过，于是，在讲解时那个通道没有得到特别的打开。

我们一直有讲到名声，现在简单说说名声这件事吧。

作为一个有点名气的人，我的理解是名声越大，意味着越多人关注你，这类关注中，如果其中是一种认同，那么就意味着你会在一个由共同想象构建的人类共同体内，得到一个群体承认。因为群体承认会影响到其他人，他们看到你很有时候，会想集体已经给了这个人一种认可和地位，和这个人沟通时便会很有这个前提。

除了这个显而易见的好处，名声对当名人会有巨大影响，如果当名人严重活在自恋中，那么名声就会极大地消减这个人的自恋，这个人群会觉得很满足不了自恋的人，一旦名声消失，就像鬼把鬼一样，"的"一下就不复存在，而流连于名声的人会感觉到无比失落。

没有内驱自我的人，可能喜欢名气胜过金钱，因为，集体目光的关注，也会给这样的名人构成一个巨大压力，他们，会想，这些目光看着我怎么做，就会说出这个样子，否则他们就不会喜欢我了。这样一个人，就彻底不自我了。

我真心觉得比起名气来，金钱才是好东西，比起没有名气和没有钱的无名无姓的人，做一个默默无闻的“财神主”，其实是一件更幸福的事。

接下来，我们做一下本主题下四个单元内容的回顾。

# 第一单元的主题：单纯与复杂

人，没有简单活着的福分。这一单元表达的就是这样一句话。

在《越简单，越复杂》这节课中，我讲了我们对中人的“假”现象，也特别讲了两类互反者的故事，人们常常想简单，却喜欢欣赏复杂猎物的故事。这显示出了种矛盾，社会文化复杂单纯，可太简单得简单的人在处中复杂复杂。因为在简单的社会，人不能简单活着。简单地活着，骨子里是一种服从，不敢活得复杂而强大。

在《“好人”逃避了什么》这节课中，我有些陆地地指出，简单的“好人”，实际上是借用复杂的“坏心”的力量，来帮自己应对外部世界的挑战，而自己虽然外在利益上容易受损，但保留了道德优越感。

要有一个自己说了算的人生，首先要有竞争自己、有强大的自我，如果根本不敢竞争自己的强势面，不能很好地保护自己，那在社会竞争中容易输，这一点很容易理解。在竞争的路上，来自乎哪儿呢？我在《在起跑线上》这节课中，讲的是婴幼儿一开场的那些叱咤拉撒游戏中，如果有者都在逼迫孩子放弃自己的选择和意志，而从不放弃者，那就是她/他的输在“起跑线上”。

逼迫与顺从，是各种国系关系中的一对核心矛盾，不仅是家庭关系，社会关系中也是一样。因此有了《中国式关系的“葵花宝典”》这节课，把对方当婴儿来照顾，当神来崇拜，同时自己有一张张恶心的脸。

这一单元的课，颇显得有点散，也没有清晰逻辑线。在这个单元中，我使用了“四象限坐标系”，定义了幼稚、单纯，复杂和成熟。

# 第二单元的主题：从想象世界到现实世界

真实世界是有疗愈性的，这是第二单元要表达的核心观点。

婴儿最初活在孤独的想象世界，最终需要进入到复杂的现实世界，而最好的抚养者和进现实，构成了一个现实世界的“三主世界”。活在想象的想象世界，必然会有致命的现实问题：因为生命力无法展开，在想象中，因为生命力不被看见，反容易虚假原质。在这个意义上，现实世界虽然有限，但现实世界的善意和阳光，要多多好与孤独的想象世界。

在《两条道路》这节课中，我讲了生命成长的两个方向：一个是向前，进入复杂的现实世界，一个是退回到过渡世界，甚至退回到想象世界。

前两者课程中的表述，容易让人以为母亲的怀抱，阻住了孩子的脚步，而这也正是“阿德勒主义”的隐暗，但一个生命最早的人都应该这样思考，因为生命中最关键的一步，就是母亲通过与婴儿建立关系，将婴儿从孤立的想象世界引入到与关系存在的过渡世界。《如何加入复杂》这节课中讲到，完成这一点，是相当不易。

单单一个人时，人性无好无坏，甚至无人能维，而一旦建立关系，人性才开始展开。人性虽然不乏复杂，但也概括为两个维度：力量维度，就是强弱，道德维度，就是善恶。这又回到了我们一贯表达的论点：在善恶的“它”面前，我们不能低头，必须强大，可同时又担心被惩罚；在善恶的“你”面前，强弱都可以。

从想象世界到现实世界，容易让人感觉复杂世界是低级粗糙的，现实世界更高级正确，判断则听不同，所以在问中，我为你讲解了《从现实世界再到想象世界》。

# 第三单元的主题：金钱的隐喻

害怕有力，是害怕强大，这是第三单元的核心理念。如果金钱是关键隐喻的话，金钱就隐喻着强大。

这一单元用的篇幅是最多的，而且是平时的两倍以上，说明大家对金钱真关注，和金钱恐惧感的描绘也让很多人来触动。

在强弱这个维度上，金钱是最直接的量化标签。同时，因为意识维度的丰富复杂，会给人以为禁止生命会大金钱，可同时又会恐惧强大，为你强大会导致别人对你的伤害。

所谓拥钱，就是我想夺你的好东西，特别拥有好东西是我想，会衬托我得特别弱，我因此羞耻和后悔，可是，我夺了你的好东西也用于为我想你深觉情者，也对你用了它，于是我想夺这个东西，同时我也想拥有好东西的你一手摧毁。

我一直在讲生成和死能量，而嫉羡几乎是唯一能生成的死能量。

有严重嫉羡心理的人，会渴望强大，可又不敢强大，于是选择绝对的公平主义，大家在一个水平上，这就没问题了。
