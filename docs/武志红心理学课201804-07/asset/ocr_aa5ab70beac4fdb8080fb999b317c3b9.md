现实07｜强与弱、善与恶

武志红
这个单元的主题是“从愚昧世界到现实世界”，这是第四讲，题目是“强与弱、善与恶”。
我们课程进行到现在，我想为你做一些概括性的总结。

+   - 最关键是形成一个坚固的内驱性自我，有了内驱性自我后，一切问题就变得简单了。
- 自我在关系中形成，内驱性自我，最初也是在关系中形成，而且它必须建立在“我是好的”这种感觉上。
- 自我和关系都有强弱和善恶两个维度，强弱就是在关系中谁为谁善，善恶就是在关系中是要多还是嫌多。
- 当你是强大的，又是基本善意的，这种条件下最有可能自己，由此拥有了一种完整的复杂性。当基本善意匮乏时，我们会强烈地追求强大，但同时又恐很强，因为担心被伤害，被嫉妒。

# 善与恶

以上的这些总结，都建立在一个基本点上：人之自恋。当“我”自恋到“你是更高的”，我才愿意低头，承认我可能不如你，而放下“自恋”，去爱的，相当于要“我”自知到“它”要是恶的；我或不想感低，如果“它”逼迫我必须服从，那我就关系自己。

所以，什么时是善意的“你”，什么时候是敌意的“它”，这就取决于客体是如何对待“我”的。如果愿意滋养、容纳我，我就会感到善意；如果是在利用我、剥削我，我就会感到敌意：恶。
所以，“我”是幼小的度。

# 强与弱

关系中的善恶被讨论得很多，在这我特别想说的是我们还需务重视关系中的强弱这个维度。
例如，当咨询中的信任关系建立得不够牢固时，咨询师太吝啬、太强势，对来访者而言并不是一件好事。对此，我有两个印象深刻的细节。

第一个细节是有一位男性来访者对我说：“武老师，我必须告诉你，在和你咨询的同时，我还找了一位资历很深的咨询师，她明显不如你，可我感到在她那里受益很大。”
我问他，这受益感是怎么发生的呢？他一开始不能诉说得很清楚，但着着谈着这一点就清晰了。他说：“有时侯，你的洞察力让我害怕，而新手咨询师，让我用不用也会觉得我洞察力浅了，这让我感到安全。”
我再去探讨后发现，当咨询师不能洞察到他内心时，他有一种得意感，咨询师管他内心时，他则会觉得恐惧。能到咨询师内心。当然，这只是他的一种感受，未必是事实。

另一个细节是一位女性来访者告诉我她的咨询关系里的事，她在咨询室里很难受，我给她做了细致的解读和分析，但我很沮丧，说了一句：“武老师，你怎么这么厉害呢？”
因为这次咨询时间就到了，所以我们没有探讨这句话的含义，等下次咨询开始时，我们就话题开始探讨，让我感觉到了自尊，她总不能不想想到去。当她开始体验到自我感觉良好，并且体验到感觉和女人以各种人相处类类的时候，都是我们打打头是道，而她这时候就会变得哑口无言。

在这两个故事中，来访者都有想和咨询师一较高下的竞争欲望，他们都希望在咨询关系中，他是更强的，希望咨询师长着咨询师的自恋，而不是他来满足咨询师的自恋。

当然，需要再次强调的是，这是咨询关系还不够深刻时的必然现象，等咨询关系变得更加深入时，这种“一较高下”的感觉就会有所松动。而最，需要强调的，大多数来访者的自感是非常压抑的，所以咨询的关键在于去压抑他们的竞争感，而是发掘和鼓励这种竞争欲。

再给你讲一个故事。有一次，我去外地讲课，对象是医生二代。其中有一个男孩在这方面是想“挑战”我的意思，故用各种方式来表达不服，后来我问他讲个他的故事，结果他说他父亲一直有个遗憾，他父亲要强的决定，永远远比不上父亲的感觉，深深地打了他。

后来见到他的父亲，我向他讲了他儿子的这种体验，他很意外，他说自己从来没有想到，他的鼓励会给孩子带来如此大的压力。接着这位父亲想起了一件事，那是儿子读小学时，父子俩玩赛车游戏，当他站在高处，孩子把他打到在地，他摔倒的那一刻，他看到儿子有非常大的挫败感。于是他从此生地告诉自己，要够一个强大的父亲，不能让孩子失望。

这是一个很复杂的时刻，儿子对父亲既有失望，同时也击中了父亲的情感。但这位父亲只看到了自己对儿子的失望，而没有看到儿子的竞争感，那彼此可能这位父亲并不能真正的接受儿子比自己强的事实。

每个人都想带着主体性来展开自己的生命，也会产生强烈的竞争感，想用自己的方式确定自己，并在各种复杂的关系中一比高下，是很正常。很自然心理现象，如果没有自己的自主的需求，或者忽视周围人的，这些需求，那就需要提醒自己，忽略了人性中一大需求。

因此，你也可以想想自己，看到孩子低于属下就很开心，父母也会看到，以及真的想透达到骨髓里的人，是不是忽略了基本人性？
