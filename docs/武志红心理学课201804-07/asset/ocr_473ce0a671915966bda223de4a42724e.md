# 现实05｜两条道路

“我这一单元的主题是‘从想象世界到现实世界’，这是第二讲，题目是‘两条道路’。

# 两条道路

我们先从一个故事开始。有一位男士，在我刚开始做咨询前不久，找我做了两年的心理咨询，他的故事很特别，以至于我整理专门为他写一本书，书名就叫《一个中国男人的样本》，之所以起这样的名字，是因为他深深感到，对他身上的问题，在很多男性经典问题相当。

这本我是一种感觉，后来咨询越多，听到的故事也越来越多，就有点验证了“我”的这种直觉性的判断。不过我在这里必须要说明的是，在没有真正得到严格的调查统计前，这都是一个假设。

在这位先生的故事中，有一个堪称辉煌的细节，那里他刚参加工作，他和同单位的男同事、女同事一起出差。他还是很喜欢他的两个女孩同事，于是也都是女孩追求他。结果，这引起了一个比他长得更好的男同事嫉妒，这位男同事也找了很多的借口，甚至在中途拿了一把刀，看到了这位同事抽出一把刀的那一刻，他非常惊恐，这让他感到有恐惧，但这还不是最主要的。

最重要的是他感，他是不是太沉溺于女人的关系中？而其实那个感觉，有一种深刻的感叹，就是男人和女人关系，总以很黏稠，有一种活泥化不开的感觉。一直以来，他们都想摆脱这份感觉，让女性关系打搅，给了他一份感受，让他下决心，先远离女人。于是，他做了一系列决定。

首先，他和两个女孩都分手了，他觉得他们之间都缺乏爱。

接着，他说，先把主要精力放在工作上，如果女同事和工作之间发生了冲突，把工作放到第一位。之后也真是发生过很多类似的冲突，例如周末，也是女友，那边是工作需要，他都选择了以工作为重。

第三，他有意识去亲近男性权威，例如他的直接导师和单位大领导，非常刻意地向他们学习。

咨询中，在回顾这段历程时，他深深感谢已做的这一系列决定，他觉得这些努力，让他一定程度上，脱离了与母亲的粘稠关系。

关于他和母亲的共生关系，我做一些简单的介绍。他的老宅是一个很漂亮的地方，虽然他的父亲，年龄比几个姐姐还大，但母亲也只对他说，你是我儿，我只有一个手。这句话在一方面，满足了他的自恋，但同时成为非常沉重的东西。

并且，母亲是控制欲望极强的人，尤其是，越是期待着他听他的话，满足于母亲的没有期待。这对他构成了严重的被否定创伤。

可以说，他的生命就停留再和母亲的过渡世界里，从想象世界到过渡世界再到现实世界，是一个正常的生命进程，所以当他冲击现实世界，他生命中本最常见的这几次来彻底发生，他拼尽全力试图进入现实世界，而他的这份努力也获得了很大成功。

这个历程相当不容易，很多时候，他很容易幻想回到现实世界，特别是男性权威的排斥，这是他内心世界和外部世界的另一种呼应，从今认为，因为和母亲一直共生，会引发严重的俄狄浦斯情结，他与在父亲之间自然会有着关系，他会简单地与男性权威的对抗，或让他感到挫败。

母亲太需要他，这是他停留再过渡世界最重要的原因。不过非常有意思的是，当我们深入探讨他从这个最终功能退入到现实世界时，他还是给到功劳属于妈妈，他说，妈妈对我的重视和爱，让他相信这个世界是珍爱他的，这是他信任的，所以当他与人发生冲突时，总能看到别人身上有值得信任的部分，有对好的一面。

上一节课中我们也讲了这一点，当母亲把孩子们从孤独的想象世界中，拉到到自己乃至家庭的过渡世界中，这是是母亲的一份巨大贡献。

他是一个重性般的故事，藏着两条道路：到底是继续停留再自己的想象世界中，让进入现实世界。前一种道路，你越想越简单，越活越封闭，而是一种通路，你会越活越复杂，意味着开放和宽广。

# 沟通和现实检验能力

按一般的理解，从孤独的想象世界进入过渡世界再至现实世界，并不是一件难事，多沟通就可以了。

我在开办连续几天的工作坊时，最后一两天，常常让大家做一个练习：把你某个学员的情况，讲给对方听，然后对方把你说的真实情况，再反馈给你，问你有没有会听我真相，学习员们告诉我他们的感受是，我会给对方反馈，并且保证反馈是真实的，当然可以选择，但一定要说出的就必须是真实信息。

这个简单的练习非常简单，学员们很容易看到，自己对他人的‘判断’常常只是想象，而不是现实。

例如有一位学员，对我讲了一件她认为重大的事。有一天上课时，她来找我咨询。在她之前，已经有一个学员占了她的第二个位置。我回答他到，他第一个位置的问题，会认为她，没想到，我跳过她回答一个有理由的，她以为是故意忽略她的，因此暴怒，不能对我老师爆发，而是转身离开了。

我的真诚回答是，我注意到她下午来，但她上课，真诚地听到她提问，而其他学员也反映，她是去其他同学排了个外国。
