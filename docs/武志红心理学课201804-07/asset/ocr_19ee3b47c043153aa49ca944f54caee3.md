# 自由08｜没有麻烦，就没有情感

自由08｜没有麻烦，就没有...

我这一单元的主题是“让欲望流动”，这是第一讲，“没有麻烦，就没有情感”。

首先来和大家分享一个视频的内容。这个视频的名称是“收到礼物的小萝莉”，视频内容是这样一个：一个小女孩收到了妈妈送给她的生日礼物，是一个书包，里面塞满了礼物，有2张零钱、糖果、零食和带有迪士尼标志的T恤。这些礼物都很普通，但给了小女孩惊喜，她像堵狗般地问妈妈：“你怎么知道我想要这个！你怎么知道的？”

礼物看完后，妈妈问她，如果可以自由选择，你想跟着这个书包去哪里，小女孩指着说“好，今天就去！”小女孩子再次被震惊到了，她回答说，这是我的吗？当场确认后，她喜极而泣，痛哭大哭，又笑着说，妈妈就，跳个开心舞吧，她立即又带着泪珠跳了个开心舞。

整个视频中，小女孩的情绪转折非常多，这些情绪中转折的发达，都非常自然，加上她生动的身体姿势和表情，让视频极有感染力。感兴趣的话可以去看视频原链接来看。

我觉得这个视频是对“情绪流动”的一个经典诠释，不知道什么叫做情绪流动的朋友，可以好好看看这个视频。

视频中小女孩的情绪流动，是怎么形成的呢？这又要从另一个讲的一个理论模型上：每个人都是一个能量体，他发出的一切能量触角，如果关关系被接受，就是被看见，然后会成于生命力。如果不被看见，就会化为黑色生命力。如果一个人活到了，他发出的能量触角没有被接受，那这个人就会在能量团里没有太大的阻碍，于是能量伸展得就会自然流动。

你的每一个欲求，都是一个能量触角。像这个视频中，我们清晰看到，小萝莉的需求被充分看见了，让她非常幸福，而她的需求不过是两部糖果、一些零食和衣服，最大的一个需求是去迪士尼。当这些需求都被看见时，她整体上就处在能量自然伸展的状态里。

当然，她的情绪流动如此自然，我们还可以推论：在这个看似活普通的外国家庭中，她可能一直是协调、放任自己基本感觉。相反，如果一个人身体紧张、表情僵硬，那个人就很可能没有获得这种感觉。

讲到这儿，我们可以问一个问题：在你的原生家庭中，你获得过这种基本感觉吗？

可能你会反问，我如何判断，一个人是否获得过这种基本感觉呢？

情绪的自然流动，是一个标志，而另一个可以目测的标志是一个人在表达需求情绪时，他的身体可能是协调、放松而自然的吗？如果是，那就可能是获得过这种基本感觉。相反，如果一个人身体紧张、表情僵硬，那个人就很可能没有获得这种感觉。

没有获得过这种基本感觉的人，其中一部分人，会特别怕麻烦。他们既怕麻烦别人，又不愿意被别人麻烦。
