# 现实08|金钱恐惧症

我这一讲单元的主题就是“金钱的陷阱”，这是我的一讲PPT，这是“恐惧症”。

首先我得澄清一下，专业诊断中没有“金钱恐惧症”这种心理疾病，这也是我很喜欢说的一个说法，所以用这个词来描述我自己先觉得这是一个很有说服力的说法。

于是，我早上8点左右就离港地到了广州白云机场后，为理登机手续，立即登机，然后赶赴北京没有其它航班，可以当天晚上就到北京。一直到只有一个航班，而且只余一个商务舱位了，其实很久以前我就已经乘坐过商务舱位了，和得到签约的事也越来越重要，但我竟然犹豫了一会儿，然后要决定时这个商务舱位已经没有了。

最后结局就是我第二天一早的飞机，在中午前赶到了得到公司，签了签约。你可以从这件事情中看出很多小事，作为一个很研究心理的心理咨询师，我真的绝还有一点点心理问题，而且花钱再，绝对是“久病成医”了。

虽然我是一名“病人”，但我也养成了心理咨询师的职业习惯：每当发生类似的事情时，我都要问问自己这是怎么回事。关于上面所说的签约到迟的事，以及一些相似的事，通读分析，通过自我分析，以及找我的精神科医师分析，都得出了同样的结论：我害怕省钱。

上面讲到的案例，分析得出的可能结论是，我有时已经想到和得到签约会有可观的收入，可是竟然会因入已经付不，但每年入于下边还不少，得到专门帮你将我的收入抵过我的心悬悬然于看，我最意识中应该让事情，然生情了于看情悬时间这件事，而必须须交代的一句是，这是我唯一一次没有错过时间而没赶上飞机。

实际上，我很快发现我的金钱恐惧症，它过去多次发作。早在十年前，我第一次发生这样的件事。我有一张银行行卡，办理事情的是我曾经通过书、讲座和办公室课程辅导的约，可是写作的，所以有一次我需要通过ATM机操作往转帐到另一张银行卡上，操作结束后，我竟然忘了取走这张卡，而是把它落在了广州日报社内的ATM机上，没有造成损失。

我把几次“意外”做了一下总结，回忆了一下每次忘记这张卡的时点结果发现每次发生这样的事都是收入上有了意外惊喜的时候，比如说奖金的支出超预期，或者收到几本书的版税时。

再仔细体会每次有“意外惊喜”时的感受，都有些紧张和不适，越“意外惊喜”越大，这种惊讶和不适应就越明显，严重时甚至有发呆的感觉。

如果不是学了心理学，我会认为这是因为“意外惊喜”让我忘了自己的手，所以才会出现这些错误的记忆。但在我知道这是，是我内心深处不想要这些钱，所以想将它们最终丢掉，但幸好我种心境还在，所以最终没有造成损失。

这种心理其实不只是我一个人，例如我父亲。我父亲的运气非常好，他从小字就看着能各种小生意，例如果水果、大米、生料、烟草等，在我们村里，他的经商意识几乎是最强的，他最早一批卖水果的，是最早一批卖大米的，还车包过的里卖钢材的。他曾经用一辆自行车装了三四百斤的荞麦，从两百里的地方拉到这儿村来卖，今年春节听他细说些经历，我觉得太不可思议，第一次觉得我父亲是英雄。

可是，我父亲一直很穷，从来没有因为父亲的势利人和变富裕起来，我们家的人，有些人突然富了起来，我们家却一直是日子过得平平，甚至可能还不如买一辆车的钱都没有。为什么这样的情况？我能看到的原因：父亲总喜欢帮人。钱到得越多，他就遇见一些人坏的，一他不被偷就是被骗。
