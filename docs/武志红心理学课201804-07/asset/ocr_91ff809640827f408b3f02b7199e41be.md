# 问答：胃部的隐喻

这一节我要回答一个比较麻烦的问题。

我想说，关于这个问题，有很多复杂的、微妙的面向。

首先，我希望大家能够记住：我们身体的任何一个部位，都不只是一个物理意义上的“器官”或“组织”。

它们同时是我们情感的“容器”和“表达者”。

比如，我们经常说“我胃不好”，这句话背后的潜台词往往是“我承受不住了”或者“我很焦虑”。

胃部位于我们身体的“中心”，是消化食物的地方，在心理层面上，它对应着我们的“接纳”与“消化”能力。

我们每天都在“消化”各种信息、情绪、人际关系、工作压力……

当我们摄入的信息太多、太复杂，或者是我们内心对某些事情感到“无法消化”时，胃部就会发出信号，比如胃痛、消化不良、胃胀等。

举个例子：如果你在工作中总是被迫接受自己并不认同的观点，或者在人际关系中一直在“吞咽”委屈，你的胃就可能“抗议”。

所以，下次当你感到胃部不适时，除了去看医生，也请试着问问自己：

> “最近有什么是我‘吃不下去’或者‘无法消化’的吗？”

可能是某段让你痛苦的关系，可能是某个你不想面对的任务，也可能是某种你压抑的情绪。

胃部的隐喻提醒我们：真正的健康，不仅是生理的通畅，更是心理的“畅通”。

只有当我们学会选择性地“摄入”、勇敢地“拒绝”、有耐心地“消化”时，我们的身心才能真正地和谐共生。
