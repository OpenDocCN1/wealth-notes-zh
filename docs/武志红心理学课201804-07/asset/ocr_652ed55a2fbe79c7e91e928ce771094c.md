否尊重现实，而不是执着于你的想象。

现实检验能力是区分正常人和最严重的精神疾病患者的重要标准。

如果你有现实检验能力，就意味着你能接收外界信息，承认外界信息的真实性，而放下你的想象，这就意味着你能吸收外界的信息，于是你就不再只是活在一个人的世界中，可以与世界交换信息。

参考课程：《现实05｜两条道路》

# 延迟满足

心理学重要名词

延迟满足 (Delayed Gratification)，即“迟迟的满足感”，是指一种为了更有价值的长远结果而主动放弃即时满足的抉择倾向，以及在等待期中展现的自我控制能力，是心理成熟的表现。

延迟满足是培养孩子在合适的时间和地点做想做的事，是自控力的一部分。反面概念是即刻满足 (Instant Gratification)，就是要立即体验快感、满足感，一刻也不能延迟，简单说，就是“想要的东西，现在就要”。

参考课程：《动力11｜时空感》

# 微笑抑郁

心理学重要名词

“微笑抑郁”（smiling depression）并不是一种精神疾病的诊断类别，它是一类抑郁患者对自己病情的反应模式。

这是一种非典型的抑郁表现形式，他们在别人面前表现的很开心、有幽默感、外向积极，能力人际关系也挺好。

但在微笑和乐观的面具背后，却充满了无价值、残缺和绝望感。虽然他们看起来在笑，但实际上每天都在低落的情绪中挣扎。

参考课程：《关系13｜你可以A，也可以一A》

# 选择性注意

心理学重要名词

视觉系统每时每刻都会收到大量信息，注意过程需要选择重要的信息来进行优化加工，注意其中某个信息，抑制其他信息。

通俗来说，就是在外界很多刺激中，只是注意到某些刺激，或者刺激的某些方面，而忽略了其他刺激。

参考课程：《命运03｜改变，从体验开始》

# 自我成就感

心理学重要名词

我们常常追求的不是单纯的胜利结果，而是在追求“我”自己的成就，个人的“胜利”就是自我成就感。

自我成就感的对面是，是自我挫败感。遇到挫折的时候觉得“这是’我’的失败”。自我挫败感，会影响自我发掘潜能。

要想发挥自己的全部潜能，就要放下头脑的评判，让注意力高度集中在事情上，并信任身体的自然反应。

参考课程：《命运02｜警惕你的自我成就感》

# 心理舒适区

心理学重要名词

心理舒适区（Comfort zone）是一个你人为构想出来的一个让你保持安全感和免受不舒服的感觉的边界，就是让你觉得放松，没有压力，并且不会引起你的焦虑的心理边界。

最简单的舒适区的例子就是我们的习惯。你习惯待着的位置、习惯扮演的角色、习惯相处的的人、习惯表现的态度……总之包含了你所习惯了一切事物。

参考课程：《动力13｜挑战舒适区》
