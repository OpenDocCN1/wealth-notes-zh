
# 强弱与善恶

中爱多，还是很多。当你既是强大的，又是基本善意的，我们最容易展开自己，由此拥有一种完整的复杂人性。

- 每个人都想带着主体感展开自己的生命，因此会生出强烈的竞争欲，想用各种方式增强自己，并想在各种各样的关系中一较高下。
- 在展开生命的这条路上，一个人很容易被这两种感觉所折磨：当自体虚弱时，容易感觉到羞耻；当自强大后，又容易感觉到罪疚。解决这个冲突的是情感，也就是善恶。当你能充分活在爱与连接中时，羞耻感和罪疚感都会得到化解。
- 强弱和善恶是紧密联系在一起的，这两个维度和自我与关系等因素糅合在一起，会生出复杂的人性，这也是现实世界复杂无比的根本所在。关于这两个维度可以概括为鼓励自体的增强，同时别忘了拉回到关系中来。

### ■ 划重点

自我和关系都有强弱和善恶两个维度，当你既是强大的又是基本善意的时候最容易展开自己，由此拥有一种完整又复杂的人性。每个人都想带着主体感展开自己的生命，因此会生出强烈的竞争欲，想用各种方式增强自己，并想在各种各样的关系中一较高下。强弱和善恶是紧密联系在一起的，这两个维度和自我与关系等因素糅合在一起，会生出复杂的人性，这也是现实世界复杂无比的根本。

# 问答：从现实世界再到想象世界

### 问答：从想象世界回到现实

武志红

这里是我专栏的问答时间，我先选一个观点，再回答一些用户的问题。

本单元的四个课程，基本上都是在讲“从想象世界到现实世界”，可能会给你这样一个印象：孤独的想象世界是幼稚低级的，而真实、复杂的现实世界才是成熟高级的。

所以我特别想强调的是，当我们不断谈现实世界的重要性时，千万别忘了《人类简史》中的一个说法：智人，也就是我们智人这一类，一个重要特点就是可以构建想象共同体，然后集聚力量，在竞争中占据优势。

由此，我们可以有一个基本假设：也许很多团体以绝对的正确性，其本质也是想象共同体集体自恋的结果，它们本来也只是想象而已。当有了这个假设，我们就可以给全人类的想象留出一个巨大空间，也许我们放弃大家共同拥有的想象，去想象一些不可能之事，这把被想象共同体视为不可能东西，本来就是不可行。

英国陆军军长阿方斯·劳伦斯于一战期间以不可思议的方式率领处于部落状态的阿拉伯人，击溃了奥斯曼帝国，创造了一系列不可思议的奇迹。他作为一名牛津大学的毕业生，在著作《智慧的七柱》中，写下了一段很有感染力的话：

人都有梦，但多数不留。夜间做梦的人，白天醒来，当心血做梦的人，不过是一场幻觉。那些白日做梦的人，是危险的，因为他们会在睁着眼睛做梦的时候，把梦变成现实。

他的真实故事拍摄的电影《阿拉伯的劳伦斯》，我看两遍，觉得他其实是一个活在全能自恋中的人，近乎“疯子”，可这个“疯子”，创造了奇迹。

多接触那些先天性之人，你会发现，他们之所以成为今天的这个样子，并创造一些非凡成就，那是因为这是他们的根本想象。

# 预告：金钱的隐喻

### 预告：金钱的隐喻

武志红

这是“现实”主题下的第三单元，本单元的主题是“金钱的隐喻”。

钱、权、名、色这些俗物中，金钱是最俗的一个，同时也是人们普遍最渴望的一个，同时还是遭遇了各种诋毁的一个。

金钱，是最现实之物，同时，它也是让现实世界变得特别复杂的关键。

在上一个单元的文章《强与弱、善与恶》中，我讲了理解人性的两个基本维度：力量上的强与弱，和道德上的善与恶。金钱这个最现实之物，太多人性之恶围绕着它展开，所以金钱也容易被视为坏东西。

这是在善恶维度上看金钱，而从强弱维度上看的话，金钱有一个非常简单直接的功能，那就是增强一个人的力量。因此也可以说，当你排斥金钱时，你也可能会陷入虚弱。

然而，如果你能在强弱和善恶这两个维度上都处理好金钱这件事，那么就可以说，你拥有了最成熟的人性。

同时也可以说，如果你还没有遭遇金钱这个最现实俗物的考验时，你认为的道德与纯净未必是真实的，当真正的考验降临时，你可能会发现抗拒不了金钱的诱惑。

本单元的调查是当提到“钱”这个词时，你第一时间想到了什么，又想到了什么，又想到了什么？试试做三次自由联想就好。

好，我们来分享一段鲁米的诗：

> 你不知道给你选一份礼物会那么艰难。
> 似乎什么都不合适。
> 为什么要送黄金给金矿，或水给海洋。
> 我想到的一切，都是像带着香料去东方。
> 给你我的心脏，我的灵魂，无济于事，
> 因为你已拥有这些。
> 所以，我给你带来了一面镜子。
> 看看你自己，记住我。

# 现实08 | 金钱恐惧症

我这一讲单元的主题就是“金钱的陷阱”，这是我的一讲PPT，这是“恐惧症”。

首先我得澄清一下，专业诊断中没有“金钱恐惧症”这种心理疾病，这也是我很喜欢说的一个说法，所以用这个词来描述我自己先觉得这是一个很有说服力的说法。

于是，我早上8点左右就离港地到了广州白云机场后，为办理登机手续，立即登机，然后赶赴北京没有其它航班，可以当天晚上就到北京。一直到只有一个航班，而且只余一个商务舱位了，其实很久以前我就已经乘坐过商务舱位了，和得到签约的事也越来越重要，但我竟然犹豫了一会儿，然后要决定时这个商务舱位已经没有了。

最后结局就是我第二天一早的飞机，在中午前赶到了得到公司，签了签约。你可以从这件事情中看出很多小事，作为一个很研究心理的心理咨询师，我真的绝还有一点点心理问题，而且花钱上，绝对是“久病成医”了。

虽然我是一名“病人”，但我也养成了心理咨询师的职业习惯：每当发生类似的事情时，我都要问问自己这是怎么回事。关于上面所说的签约迟到之事，以及一些相似的事，通读分析，通过自我分析，以及找我的精神科医师分析，都得出了同样的结论：我害怕省钱。

上面讲到的案例，分析得出的可能结论是，我有时已经想到和得到签约会有可观的收入，可是竟然会因入已经付不起，但每年入于下边还不少，得到专门帮你将我的收入抵过我的心悬悬然于看，我最意识中应该让事情，然生情了于看情悬时间这件事，而必须须交代的一句是，这是我唯一一次没有错过时间而没赶上飞机。

实际上，我很快发现我的金钱恐惧症，它过去多次发作。早在十年前，我第一次发生这样的件事。我有一张银行卡，办理事情的是我曾经通过书、讲座和办公室课程辅导的约，可是写作的，所以有一次我需要通过ATM机操作往转帐到另一张银行卡上，操作结束后，我竟然忘了取走这张卡，而是把它落在了广州日报社内的ATM机上，没有造成损失。

我把几次“意外”做了一下总结，回忆了一下每次忘记这张卡的时点结果发现每次发生这样的事都是收入上有了意外惊喜的时候，比如说奖金的支出超预期，或者收到几本书的版税时。

再仔细体会每次有“意外惊喜”时的感受，都有些紧张和不适，越“意外惊喜”越大，这种惊讶和不适应就越明显，严重时甚至有发呆的感觉。

如果不是学了心理学，我会认为这是因为“意外惊喜”让我忘了自己的手，所以才会出现这些错误的记忆。但在我知道这是，是我内心深处不想要这些钱，所以想将它们最终丢掉，但幸好我种心境还在，所以最终没有造成损失。

这种心理其实不只是我一个人，例如我父亲。我父亲的运气非常好，他从小字就看着能各种小生意，例如果水果、大米、生料、烟草等，在我们村里，他的经商意识几乎是最强的，他最早一批卖水果的，是最早一批卖大米的，还车包过的里卖钢材的。他曾经用一辆自行车装了三四百斤的荞麦，从两百里的地方拉到这儿村来卖，今年春节听他细说些经历，我觉得太不可思议，第一次觉得我父亲是英雄。

可是，我父亲一直很穷，从来没有因为父亲的势利人和变富裕起来，我们家的人，有些人突然富了起来，我们家却一直是日子过得平平，甚至可能还不如买一辆车的钱都没有。为什么这样的情况？我能看到的原因：父亲总喜欢帮人。钱到得越多，他就遇见一些人坏的，一他不被偷就是被骗。

人的收入就不能由他本人来分配，而会由共生关系的掌权者分配。干活好，收入多，那意味着要承担太多责任，并且被剥削，挣钱动力就会受到巨大影响。

- 共生关系中常会看到“鞭打快牛”的现象，能干的人不断被加上各种责任，同时又被剥削被驱使，而拿到的好处又有限。谁挣的钱主要归谁支配，这是非常简单而根本的规则。

### ■ 划重点

社会中的各种关系停留在共生中时，一个人的收入就不能由本人来分配，而会由共生关系的掌权者分配，也常会看到“鞭打快牛”的现象，能干的人不断被加上各种责任，同时又被剥削被驱使，而拿到的好处又有限。谁挣的钱主要归谁支配，这是非常简单而根本的规则。

这26种观念，是美国著名心理治疗师露易丝·海在她的著作《生命的重建》中写出的“与钱过不去”的观念。如果说她的这26种观念做一个心理测试，那么可以说是关于金钱恐惧症的一个测试。你的“金钱恐惧指数”有多高呢？也可以由此对照一下，你的收入是怎样的呢？

十多年前，我具备了这些观念中的大多数，而且有些程度非常严重。从我自己的经历来看，我觉得当时持有这样的金钱观时，一个人很有福气。

我2001年开始工作的，很早就年收入就有了15万以上，在那个年代这个收入还算不错。2005年，我买了第一套房子，价格才4400一平米。如果把不能用这笔钱好好想挣钱的事，也是我不敢用钱的开始，但现实是我本就是一个“月光族”。到了年底一看，钱包里还剩不下多少钱，可我像也没什么，同时我既不是一个奢侈浪费的人，像这些我都很困惑地说我消失了。现在我收入上些，我觉得在相当程度上得益于我2008年后逐渐开始的观念转变。

我特别把这个指数称为“金钱恐惧指数”，是因为对于有可能导致金钱恐惧的观念，而言，金钱的观念会导致一些令人恐惧的事发生。露易丝·海在《生命的重建》这本书中，写了一个故事：

> 一个学生家素工非常努力，希望能增加自己的利润，一天晚上在特别小心，因为他刚刚赢了500美元。他一边儿地说：“我无法相信！我还没有从来赢过！”大家知道在相信转变的外在在反映，但他却感觉到另一个，第二个愿意他晚上上课，因为他摔断了腿，医疗费刚好花掉了500美元。

对此，露易丝·海的解释是这个学生害怕走向真的富裕，他其实并不期望变富，所以用这种方法惩罚了自己。

十多年前曾经写过一个新的剧本，但列文安全部她妈妈买了张新床垫，她把妈妈用了很久的旧床垫从垃圾扔掉了。她对妈妈表达爱的学生，就连这张旧床垫都，露易丝·海的半生积一千旧床垫。后来安娜一家人去赶去老找这张床垫，可怎么都找不到了。

这样事发生后，老太太很看开，她安慰女儿说，虽然很伤心，但总比被车撞了或得了不治之症要好。老太太的这句话很有意思，它包含这样的逻辑：如果享受善意，就会被撕掉，或得个不治之症，而女儿弄丢了她地钱，反而让她免除了这样的危险。

然而，金钱真的会带来灾祸吗？美国针对那些彩票大奖得主的研宪显示，事实似乎的确如此。美国的一项调查显示，欧美大多数彩票大奖得者，在中奖后五年内，因挥霍无度等原因而变得负债累累，其中75%的破产。

对于以上这样的故事，露易丝·海的解释是自己人不想富有，所以用这种方式惩罚了自己。这种解释很不够，说服力不够强，但信你访中是否发现有更深层的原因。我讲来讲来访者的故事与领悟，然后再谈谈我的理解。

我的一位来访者，她每个月收入少的时候有一千多元，多的时候也有五六千元，她说，每次挣到一笔钱，她都会感恩，然后她会捐出去一小笔钱，例如50元或5元。

听上去，这是很棒的公益行为，但她每次深入访问发现，她是出于恐惧。每当她挣到一笔钱，她都会有惊恐，然后捐一小笔钱，好像是在请求某种力量不要惩罚她。

另一个故事是我的又一位来访者，每次和别人一起吃吃喝喝之类的时候，她都会抢着买单，但随后会感到严重不安，然后就不愿意和别人一起吃饭喝酒了。同时她还有一一个特点，她既不能接受别人比自己高，也不想要被接受，自己比人高。前者会引起的嫉妒，而后者，她担心自己会引起别人的嫉妒。所以，她总是隐藏自己真实收入情况，而当必须讲自己收入时，她会根据自己的收入，虚构自己的收入，目的是和对方的人收入基本持平。

第二件是去讲中的嫉妒，我总觉得是很根本的原因。之前《嫉妒① 动力与弱点》这门课程中我讲到，强烈的力量维度和善意的道德维度，来的人的个心理维度。如果说金钱是什么隐喻的话，那么最重要的隐喻就是力量。的力量，人可以支配的越多，这就意味着她的力量越强，在能量力量时，第一重要的因素是权力，可权力比很多东西都，也也不能很好地量化，特别是当家的权力处于相对水平时。但金钱不同，是一个很容易量化的指标，谁多谁少，一目了然。因此，金钱很容易引起人嫉妒恨的嫉妒。

力量的强弱，也可以延伸出一个很好诉的维度，就是谁高谁低，或是活在全能自恋中的人，更容易在乎关系中谁高谁低。基本落在一些关系的人，会希望永远都是高他人，可他们也会知道，在另个时候别人会高过他。同样，在一关系中，人会想自己而那样显得更有力、地位更高的人，会是的很不得对方去死。

这样一来，就引出了一个很深的矛盾：我不能接受别人比我高，又不敢比对方高，那最好就是我们彻底平等。

我们再回头来看安娜妈妈的，故事，她说，一万或千了是很好，但总比被车撞了或得了不治之症要好。这意思显然是如果她真赢了一百万，就可能会像某种力量惩罚，而撞车或病治之症。我认为这种意思，可能是他想念中的别人的嫉妒。

露易丝·海讲的赢了500美元然后摔断腿的学生，他的隐喻也更明显，你赢的500美元，这可以用以隐藏更清楚完整的表达是，作为学生我就是一个客体500美元，然后他摔断腿，他认为可以传递在这个集体传递这信息：别嫉妒你，别伤害我，我根本没有那么多力量。这样我第一句听到，这一点令我的来访者，每次挣到一笔钱都会捐出去一些，我也认为是在向某种力量传递同样的含义。

力量强调这个维度来看，金钱恐惧的强弱，可以从自己，有所处的情家庭或家族许奖励竞争吗？虽然我们现在特别强调成功，家长为了培养强者的竞争能力，让他们去争第一。
