# 问答：从嫉羡到感恩

+   *   问：嫉羡到感恩

+   武志红

这个课是我们专科的问答时间，我先讲一个重要的知识点，再回答一些用户的问题。

《现实10》嫉羡与金钱》这篇文章引起了很多同学共鸣，现在我讲一下嫉羡的对立面—感恩。

嫉羡的根本，是一个人觉得自己创造了好的东西，也拥有了好东西，是他感觉好的存在有好东西的感觉。所以，他觉得自己好，因而生生羡羡，接着会产生了毁灭欲，想毁好东西和拥有好东西的人。

而感恩的根本，是一个人深深地体验到自己可以彻底有存在，有自己强大责任，而这些东西，实际上是那些更的存在带来的，因此感恩这个善意的存在，并愿意向这个善意的存在低头。

最初在婴儿那里，婴儿感受到母亲拥有幸福的乳汁，母亲会心甘情愿地哺育自己，满足自己，这是没有条件的，不需要自己低头，不需要自己屈从或拿什么去交换。这种原始的感恩让自己可以肆无忌惮地吮吸母亲的乳汁，将这个最原始的好东西吸纳进来，增强自己，当深切感知到母亲的善意后，婴儿也会愿意承让母亲的强大，并向母亲低头，这就是我们一再说的依恋的完成。

一旦依恋形成了，事情会变得非常简单。

我们很容易感恩教育，然而我认为感恩是更甘心彻底存在，孩子充分体验到母亲乃至其他养育者对它们的养育后，自然发生的。而感恩教育更多是补偿性，让孩子看到母亲或其他养育者多么累，多么疲惫，付出多少辛苦，然后他们可能会感动，可能会觉得幸运活下来了，所以要感恩。

这样的感恩有强烈的匮乏感，充满痛苦的“母亲”，充满着愧疚的孩子。在这样感恩之后，许感激巨大的债务，母亲像欠债的，孩子像债主，而这样欠债的、巨大的债务会让孩子觉得母亲对自己的牺牲很大。母亲像个大债主，孩子像个小债务人，孩子觉得自己欠母亲很多，所以不敢活，不敢去拿，不敢去爱，甚至不敢去想。这种巨大的债务感让孩子对生命本身都产生了恐惧，所以，感恩教育往往是孩子痛苦的开始。

不幸的是，在严重重男轻女的家庭中，这通常是一个事实，这种痛苦和贫穷，是金钱恐惧症的一个重要源头。

所以，一个好的社会，一个好的家庭，最好先让妈妈们在充分被滋养，这样他们才能成为有感恩的母亲，才能育出有感恩心的孩子。

+   武志红

这是非常好的问题，关于这一点，我想多讲讲我的故事，和我身边的故事。

首先，我观念的改变来自于我的前女友，她在挣钱方面是没什么理财头脑，而且在做钱也不止贪夫，虽然带给我很大痛苦，但确实改变了我。

其次，如果我的观念没变，我的书、讲座和公司不可能因为有收入，让我远胜于现在，并且可能会因为欠债，让我远逊于现在，去挣更多的钱，这会影响我的投入，最终影响我的收入。

第三，我观念的改变是一个很好的例子，因为我，我几乎每年都以极度的热情投入其中，一直关注我的用户可能能看到，我在得到有大量收入，而且正形成了体系。

第四，如果我改变观念，公司挣钱不会很大，也不会很小，因为会被各种制度，我改变没有什影响。实际上，我仍然是我最想解决的问题，一直如此，我的写作和讲课带来的个人收入，远远高于公司带给我的收入，这一点正在被改变，但这个改变过程也让我看到，这是我的英雄之旅中最重要的部分。

第五，我身边很多朋友，他们有巨大影响，但他们绝对都没有金钱恐惧，就是要么公司开不成，要么公司越大，他们越是辛苦，简直要累死了，公司对他们就是摆样子。

相反，我认识的那些精英企业家，能把企业做得很成功，而自己却持续了很多年，都是很好外地带里自己利益的。并且，其中一部分人对自己没有利甚至亏钱，他们的人性由此收放自如，是我见过的人性成熟度最高的人群。

关于金钱的讨论，第3条和第26条说到，钱是长出来的，只有努力工作的才有钱，说得很好，这不是最坏不做的真理吗，你在努力的人应该很低，我相信，这是我的观念的很工作的人很好，是我学的榜样，为什么也批判进去了呢？

+   武志红

首先说说第三条，不是有“摇钱树”一说吗？例如，那些像于投资理财的人，假如股票开好了之类的，如果打理得好，真的像是“摇钱树”一样。

我有一位挣钱没障碍的朋友，很早就共同到买房房子挣钱，结果在广州买了几十套，同时，她让一个半辈子的收入比一位擅长投资的朋友赚钱，现在每年都非常有收益，她的公司虽然也不错，但房产和理财带来收益，远胜过它的公司。

所以，难道真的是“只有努力工作才有钱”吗？这条反驳也很粗暴，有钱不是有意识地挣钱当然有，有会因进入问题，但身边也有朋友和家人来讨，过得幸福美满。

+   武志红

我的确认大现在流行的“佛系青年”，常常是没有强大生命力的，当然也不是所有人都如此。

竞争不易，英雄之旅不易，直面自体会是很困难的，为了安慰自己，而使用合理化的心理防御机制，告诉自己不自信，不争很多，这是很多“佛系青年”的逻辑所在吧。

是不是可以说自体虚弱的人，不仅是因为缺乏力量感，也可能时因为害怕自己有力量呢？

+   武志红

我刚才已经说过，一个人中自我体虚弱，几乎是自然而然的在生活中，他会觉得自己强大是不被鼓励，甚至不被允许的。

我们太多俗话示这一点，如“枪打出头鸟”、“木头的鸭子烂先”、“木秀于林风必摧之”等等。

我喜欢看NBA比赛，看美国篮球运动员们投投前会喊给自己“盖帽”时，会非常直接庆祝，彰显自己的优秀。再看CBA比赛时，发现很多中国球员在投命中后会缩一下，这种时候他们像是要显示谦虚一样，在我看来，这是担心自己的强大会被嫉羡，被摧毁，被惩罚。

老师讲共生关系中，一个人的钱不能由自己支配，反而钱的越多，自己可支配比例越小，赚钱动力会减小。
