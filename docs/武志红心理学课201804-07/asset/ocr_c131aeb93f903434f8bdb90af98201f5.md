# 复盘：关于“空间”主题的回顾

复盘：关于“空间”主题的回顾

武志红

我们专门讲述了“命运”、“自我”、“关系”、“动力”、“思考”、“身体”、“情感”、“感知”和“空间”八个主题，今天我来对“空间”这个主题进行一次复盘。

容器和被容之物，是一对根本的命题。上一章讲的“觉知”，可以理解为是一种容器，而这一章讲的“空间”，则是是非常直接、非常实在的容器。如果你没有自己的空间，那么你作为容器就没有意义，也就意味着没有安身立命之处。

我在得到的第一场直播，讲的是“界限意识与其关系”，春节前在凤凰卫视的“世纪大讲堂”讲过类似的主题“模糊逻辑与界限意识”，接下来我还会就此系统做课程，写一本专著，这些内容都可以视为空间主题范畴内的内容，都是我们这一章内容的延伸。

为什么对这个话题如此感兴趣？一是因为我觉得这是中国社会人际关系的大多数问题的源头，二是因为我只能在头脑和想象层面捍卫自己的边界，而在情绪感和利益这些层面，我的边界意识一团糟，作为“病人”，我这也算是众病悉成，当然本来也算是心理医生。

你可以点击链接回顾关于“界限意识”的视频文字整理，这样“空间”这一章的内容就更圆满了。

点击复：重温直播之界——界限意识与其关系

当时的直播中，我讲到界限有三种，地理界限、心理界限和身体界限。这也可以说，空间有三种，地理空间、心理空间和身体空间。

界限意识，或边界意识，其实就是地盘意识，这是我的地盘，在这个地盘里我是主人，那是你的地盘，你是主人。在共同的地理里，我们要去确认秩序与规则。

如果守不住自己的界限，那就意味着，你其实是心理上的殖民地，有人在你的世界里是宗主国。

不管建立个宗主国，你都会想并且也需要它迁走。常常见一种情况是即便成年了，父母还可能是宗主国，这时就需要把父母请出他的地盘。

学习尊重彼此的底线，学习尊重共同体空间的规则和秩序，在任何一个社会都同等重要。至于你自己，必须意识到你需要一个属于你的空间。

# —— 创造你的生活空间 ——

这一周我们讲的是如何创造并维护你的生活空间。

我先讲了《房子的隐喻》，因为作为自己和家人居住的房子的，就是生活中最私密的领地。文章中讲了一个类似唐娜的接纳故事，一位女士不断买房子，而且买的都是转角角房或大平层，都奇形怪状，房子的共同点是狭窄的卧室，要有一个长长的通道，为的是当妈妈要进入她卧室时，她能提前知道。

为什么要有这么大开销？给卧室加一把锁不就可以了吗？问题是，她妈妈不允许她这么做，而她已经40多岁了，她妈妈就是她世界的宗主国，而她是自己世界里的殖民地。

父母最重要的价值，是给孩子提供安全感。第二篇文章《我们都需要一个安全空间》，讲的是当父母能稳定地给孩子提供安全的空间，这个人把内在化后内在，就形成了所谓安全感，即使独立后依然会自信但漫灌，一任遭遇严重关系的折磨。

如何能给孩子提供一个安全空间呢？《让家成为真正的港湾》中说道，有时候，这需要抗令，而战争的对象就是自己生活空间里的入侵者，最简单的例如是自己的父母。

当父母能给孩子提供安全空间时，孩子就会在这个空间里，好好去《修炼掌控力》。这篇文章中，我们给读者提供过概念，例如孩子中会内化过渡客体过渡客体，孩子们通过掌控这个过渡客体，学习和现实世界打交道。

过渡客体，也给孩子提供了过渡空间。实际上，原生家庭就是这个过渡空间，孩子从原生家庭的想象世界，通过进入现实世界的想象世界，最终进入到现实世界的真实空间。

# —— 创造你的工作空间 ——

要想拥有属于你的工作空间，就必须懂得维护空间这个概念，我本上《维护你的权力空间》，这是我在广州日报工作时得出的一个概念，我认为一个人的权力要放到赋予每个点上而不是好的权力空间，在这个空间里，他说了算，这样员工才能在激情和创造力。就算是领导说员工的能量，最终让企业失去活力。

《做一棵永远成长的苹果树》一文中，讲了一种成长，苹果树分两种果树，一种是永远成长的苹果树，一种是自断的苹果树。多年前我写这篇文章时，以为苹果树所以自断经脉，是老板机制的原因，现在才明白这是权力空间的问题。当一个人在工作当中没有自己的权力空间，只能服从，那么他放弃的主动性就转向自身，从而构成自断经脉。

成长过程，是从孤立的想象空间，到家庭的过渡空间，再到社会化的现实空间的过程，而这过程中就有个性、社会化与社会化的矛盾。这个过程正常的发展，是一个人的社会化过程，但社会化太多，而失去个性，就会构成体系化。以往的社会是中心化的，打造一个平台不易，而体系拥有平台容易，而往往在个人的力量时代，体系化就容易发生，在现在的事物互联时代，互联网形成了人类共享的一个平台，这些联系形成了一个共享体，也可以帮助这个平台，轻松获得生存空间。所以可以说，这个时代是越来越鼓励个性化的时代。

在《加餐：工作空间中的“无情”》这篇文章中，我写了一个非常个性化的感悟：想在无心中保持开心，也许你要为它付出代价来消除无情，比如弗朗斯与马克，在我看来就是无情的典范。

这篇文章收到了一些用户的反对。其实和这篇文章相匹配的，还有我另外一句话——成长是根绝是一场绝望，意思是那些成长后的黑色金力一旦开始展现，就会显得些可怕，但不管多需要展开生命，而生命力会在真实世界的熔炉中得以淬炼，如果活得好世界。

人类的另一热情，无论是好还是坏的，都是他根绝使生命有意义。必须找到一条新的道路，让孤独活跃死记硬背的热情，让他感觉到生命力及生命完整，这是唯一的路，否则，你固然可以把他驯服，却永远不能他治愈。
