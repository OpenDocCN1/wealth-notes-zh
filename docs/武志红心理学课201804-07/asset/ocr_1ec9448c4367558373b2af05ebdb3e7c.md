# 问答：幼稚、单纯、世故和成熟

问答：幼稚、单纯、世故和成熟… 2

武志红

这一讲是我们专栏的问答时间，我先分享一下我的感悟，再回答一些用户的问题。

我的这个感悟来源于我仅有的一次相亲经历。说实话，我有点点头约，我感觉自己条件说得还过去，但是不知道为啥，没有人给我介绍相亲，这是我仅有的一次。

在这次相亲中，我讲了一句很有感受的话：成熟有两种，一种是掌握了现实规则的成熟，一种是人生性的成熟。

我就不给大家讲有秘密的相亲故事了，我要说明，毕竟没有秘密的人是长不大的孩子。

我想继续给你谈简单和复杂。很多用户在留言中提到，如何定义单纯、简单、幼稚和复杂这些词。

这是一个好问题，就用我刚才这句话感悟，和管理学院中向向东老师不断使用的‘四象限坐标图’来区分下简单与复杂。

点击试听：宁波大学·海洋学院管理理学·《学术领导的极简指南》

制作一个四象限坐标图，需要有两个维度，结合本单元的‘复杂与单纯’这个主题，以及我刚才说到的感悟，我认为可以有两个维度：一个是内在人性 的幼稚与成熟，另一个是外在规则的无知与掌握。

这样一来，就可以区分出四种模式和我的定义：

+   1. 内在人性幼稚，同时对外在规则无知，这是幼稚；
2. 内在人性成熟，同时对外在规则无知，这是单纯；
3. 内在人性幼稚，同时掌握了外在规则，这是世故；
4. 内在人性成熟，同时掌握了外在规则，这是成熟。

![](bbox=[0.2, 0.63, 0.8, 0.78])

世故和成熟的人，都是复杂的，而幼稚和单纯的人，都是简单的。

四象限坐标图是很有用的工具，我觉得可以在这个坐标图上继续发挥一点创造性，我们可以在坐标图上坐标的原点，也就是在内在人性和外在规则都为零的这个位置上，这是一种原始的合一，而在内在人性和外在规则得分都很高的位置上，也会存在合一的可能。

这样 的人，就可以达到王阳明的境界，不仅证悟到天道即理心“致心”之外，则无它了。而且悟得‘此心无’，随缘而应。到了这种境界，就是最简单，也是最复杂，简单和复杂由此统一了起来。

# — 单元问答 —

复杂的人会被简单的人吸引吗？如果每个人都是复杂的，就像世界里面只有男人，也是不符合 A 与 A 吗？

武志红

复杂的人，当然会被简单的人吸引。特别是有些地方，会被幼稚的人吸引。我认为在这有两个原因，一是幼稚的人容易被掌控；二是幼稚的人有一种简单的美好，这给了世故的人一种对美好的想象。

电影《阿甘正传》里的阿甘，就是一个智商不高极其简单的人，阿甘的简单和单纯却带给了他巨大的幸运。无论独舞，电影多数场景或艺术作品中，都会有类似的形象，甚至是中国古语里都有‘傻人有傻福’。这样的作品常让人觉得单纯是人生至高的精神财富，武老师是怎么看待这种简单的呢？

武志红

我也非常喜欢《阿甘正传》这部电影，我觉得在一个规则基本公平合理的社会，这是一种真实的可能性。

然而 我很好奇的是，如果我们观察自己的周围，会有这样一个阿甘吗？阿甘实际上没有世俗的成功，而郭靖不同，他最后成了武林至尊。

如果用这节课所讲提到的四象限图，可以那种‘生辰成而对外规则无知’的人，他们的单纯性是容易被赞许的，同时也可能会获得成功，如幼稚的人难以做到。

此外，当所有人都是世故时，看似单纯的人也容易出，因为他们代表了大家都不敢做的事。例如埃及前总统穆萨德，他是埃及传奇总统赛菲的副手，在纳赛尔去世后，各方派系斗非常厉害，可他一直很老实，被称为‘土推上校’，大家觉得他好控制，于是为一致推他继任总统。谁想到，他的老实装傻为厉害，一上台总选党之后，他立即变成了杀死法哈斯非常厉害的角色，而且表现得非常正确。

简单的人会因为对简单的人提防他，而获得生存空间，但也只是仅此而已。

武老师，你之前专栏中说的孙博不就是一个纯粹又活得简单的人吗？那样的人不是那么人好向往的生活状态吗，他命运又怎么就那么凶？他不就是那种一直活非常的高尚且从来不去复杂，却一直走来都很幸福的人吗？

武志红

我认为只有一种简单是可以的，就是你一直在做自己，这个点你本来通过，这时你有 一个强大的内在，同时也可以适应外在。也就是说外在不是偶合适，而是你常常会让外在为你改变。

孙博是一个真正纯粹的人。同时，他也是一个非常复杂的人，他对复杂世界的真实世界的规则简直看得真真切切。因此他可以保持简单且活得幸福。

简单的人选择复杂的人生，是强化自体之道，那么复杂的人，最简单地 人 生是如何？个体经常追求关系中的简单，比如我想见到我对象就是对她亲热也少要玩手段，就会担心孩子将门铃按到母亲 人未来婚姻关系中，这样我对亲密关系中自体虚弱导致的吗？

武志红

世故的人，在最亲密关系中都较比对待别人，去控制，去控制，这也是一种自虐的表现，觉得为了增强自己，而必须去剥削别人，就像婴儿觉得必须吸吮妈妈的乳汁一样。

简单且自体虚弱的人会通过接触复杂的人和世故且自体虚弱的人，又被对方报复。那么今我理解了这份自体虚弱，又该如何主动改变，从而不 报也能增强自体呢？

武志红

通过你的内心，按照你的感觉去活，去这个世 界 里。在这些感受中，至少有两个东西是增强自体的关键。

+   1. 反脆弱：你的身体和心灵都是一个反脆弱系统，可以在打击中不断强大起来，而不是从承受打击，但是强大。用我的一再强调的话来讲，就是你要不断去尝试死，能量死不死不死，而且你常常能到死就能强化生命本能。
2. 关系的深度：自体强大的人，是你在唤醒自己，发掘被激活了，你的生命力没有带来灾难性后果，相反还加深了你们的关系，这是根本 的自体强化之路。
