# 复盘：关于“创造”主题的回顾

复盘：关于“创造”主题的回顾

+   *   武志红

我们专门讲述了“命运”、“自我”、“关系”、“动力”、“思维”、“身体”、“情感”、“感知”、“空间”和“创造”这十个大主题，这节课我们再来对“创造”这个主题进行一次回顾。

首先说明一下，在这一章的课里我也有了创新。原本这一章是在讲创造，但我想着去讲一下最大的创造是按照你的意图去活。这里大一点，我们又紧扣了大主题——“拥有一个你说了算的人生。”

我甚至想说得更绝对一点：只有一种生活值得过，那就是过你想过的生活。

说话的时候，以及写这本单元内容的时候，我一直想写一个守车事，但最终还是没把这个故事写到文章中，现在补充一下。

这个故事的主人公是一位女企业家，她多年的就有几百万家产，算是成功人士，她的人生总有一种很深的空虚感和遗憾感，她回顾自己一生，发现自己什么时候做选择，她要么是大地的选择，有一个是大众认为对的，那必然是选择后者，而从来没有选择过前者。

例如读书时，她很想考艺术类院校，她在这方面有天赋，但她最终选择了普通院校。例如恋爱时，她爱人爱得如痴如狂，但她放弃这个人，选择了另一个她觉得好的对象。

通过她的努力，她构建了一个在别人看来堪称完美的生活，她也认为这是一个完美的世界，可空虚感和遗憾感总在撕咬她，并且，最终让她认了婚姻中的丈夫提出了离婚，让她完美世界崩塌。

通过各种努力，她终于逐渐地能去选择那些她由衷热爱的事物和人，这时她才开始感受到另外的充实感。

我还想到另一个故事，一位超级富豪，同样也是拥有数百万家身，但他在中年时的时候，他疯狂地爱上了一个人，然后才发现，他平生第一次体会到了什么是活着。

这两人，我们虽然都选择了财富这种价值，但却没有创造力意义感这种价值。

不过我想，听到这里你可能可能会想：如果拥有巨额财富，需要付出的代价是牺牲个人感，那我愿意。但我想说的是，我也见过那些适应自己心意，但一开始充满热情和创造力的富豪，他们的满足感和意义感，是我们故事中的那两位富豪远远不能比的。

罗素说，假如多多多，乃是幸福根源。愿我们每个人都能随自己的心，过自己个性化的生活，这样世界会显得既多变，也更立体、更美、更有创造力。

# ——创造，来自臣服——

这个单元一开始，我介绍了我的写作方法，要点是写时必须先给两种感觉：一是我能做到了这个人；二是对这个人要有一种完整了解感。

因此，在写作者的准备阶段，我不会先列提纲，而是先去了解这个人，搜集所有和他有关的资料，其实也就是对这个人做调查研究，直到我心中感觉对这个人形成了一种完整认识感之后才开写。

这样的做法，不是用脑袋去套事实，而是先放下脑袋的成见，沉到事实之中，然后从中升起一些感觉和判断。

这种做法的关键，是所有容忍模糊的能力。容忍模糊，是所有有创造力的在他们擅长的领域内的共同特点。容忍模糊，不是急着看头脑下判断，太早追求确定性。

创造力的敌人，是头脑层面的自恋，太把自己的想法当真。拥有第一流才能的人，如伯尔列、迈克尔·杰克斯和泰尼斯，他们都深切知道不是“我在创造，”“我只是一个管道，好东西是经由“我”而来，不是由“我”而来。”

有着伟大头脑的尼采说，他的创造力秘诀是他非常善于地吸收思考。对此，我使用弗洛伊德的初级思维和次级思维概念做了理解。

本单元的前三节课程，有些用户觉得有点难懂，因为自己可能从来没有以这种方式做事情，而在第四节课程《最朴素的创新方法》中，我都深入调查。不过，我和几个见多识广的朋友沟通这件事，大家一致说那是平时难以看着各种内容在头脑里交错在一起，一样地可以看到真相，容易流于表层的认识。所以创造力真不是一件简单的事。
