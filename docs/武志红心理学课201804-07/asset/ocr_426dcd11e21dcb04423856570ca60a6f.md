# 问答：罪疚感，是完整人性的一部分

问答：罪疚感，是完整人性的一部分

武志红

这节课是专门的问答时间，我先集中解答一下本来单元用户问得最多的问题，再来讲别回答一些用户的提问。

这个问得最多的问题是：是否存在着这样一群人，他们并不认为“需要有罪”？

人为什么会觉得需要有罪？如何才能让自己内心更自在，更自足的享受或满足自己的需要？激发对方的需要，并将罪感转移到对方是否是一种心理防御机制？

在我的理解中，只要我们活是活在“我与它”的关系中，因为需要而产生的一种罪疚感，是无法避免的。所以，存在一“不认为需要有罪的人”。当然，有些人可能会看不到自己的罪疚感，我觉得这可能要带着严重的心理问题，所以，不太希望去把罪疚感消灭掉。

罪疚感，是完整人性的一部分，我们需要体验它，让它流动，而不是将它视为是负面体验去屏蔽它、消灭它，实际上它也不能简单地被消灭掉，最多是压抑到潜意识中，或转嫁给别人而已。

按照阿··布伯的理论，关系有神性的“我与”的，这个时刻我放下了我的所有期待，也就不用“需要”了，而一旦有需要，关系就会降格为利用与被利用的“我与它”，这时罪疚感就会产生。一有需要，就有罪疚感，这里面有着极为深刻的逻辑，我会在下来两个单元课程中去探讨它。

通俗意义上，当关系双方都体验到巨大的愉悦，并享受其中的时，罪疚感会明显下降，而当关系是一方从另一方身上索取需要，而另一方有损失时，罪疚感就会更重。

所以，父母带孩子时，满足孩子的需要很重要，而在满足孩子需要时，能否让关系变成彼此都享受其中的关系，也同样很重要。当父母带着满足的需要，去满足孩子时，孩子的罪疚感会变得更低。

不过，我个人认为，我们没法在普通关系中去排除罪疚感，而只能是带着它去生活，去构建需要与被需要了的关系，它只能是“我与”的层面上才能真正被消除。

总之，不要试图想把人性中一些不舒服的基本负面体验给消灭掉，而是要让它流动，同时知觉它。

# 单元问答

需要和欲望有没有区别？

武志红

这是非常好的问题，这个问题让我感受到得到用户与众不同之处。

实际上，我自己并没有仔细地区分需要和欲望，所以我常常没有随意地使用“需要”、“欲望”和“欲望”这些词汇，但法国精神分析家雅克·拉康对这些词汇做了非常细致地划分。

拉康的欲望理论，将需求分为三层：需要need、要求demand 和欲望desire，需要就是实际诉求，例如婴儿要吃奶，不吃会饿。要求落实到，不高兴，要求吃奶时，不仅仅是要求吃奶，还要疼爱。欲望则是在需要和要求的缝隙之间。

拉康的理论复杂而深邃，他自己也喜欢做晦涩的理论阐述，对他，我的精神分析课程，我了解的还不够，所以很少提及。

不过我可以举个例子。婴儿吃奶时，被喂到了，这是实际需要被满足了，但是，如果是妈妈在喂奶时，不高兴，不愿意，甚至有逼婴儿吃奶的情况，那么，这时婴儿会感觉到，妈妈对你有，进食会让婴儿感到妈妈的奶水有毒，进而导致进食如问题，这是生理需要被满足了，但情感要求却没有被满足。

这时也存在着权力欲望，妈妈是按照婴儿的意志来喂，还是按照自己的意志来喂，这会令着婴儿不高兴，前者会让婴儿感觉到被爱，后者则让婴儿感觉到被忽视，而这种差别背后，是婴儿期待权力被满足。

需要是可以被满足的，而欲望是很难被满足的。性欲如此，生理意义上的需要容易被满足，可如果一个人心总幻想占有最有魅力的异性，这个欲望就很难被满足了。

在“怕表达需求”下，“怕被拒绝”和“怕欠下人情”有什么关系吗？不想欠下人情，也是怕被拒绝吗？

武志红

我认为这是为了避免自己的罪疚感。通常，这是源自一个孩子和匮乏的母亲所构建的关系。当母亲处于匮乏之下，她就算满足了孩子的需要，孩子仍然会觉得愧疚，他们会觉得像是自己吃了母亲的一块肉，自己的需要被满足后，而妈妈的资源就少了。特别是如果妈妈还有意识地给孩子制造内疚时，它会更强烈。

怕被拒绝的人，当被拒绝时，产生的是羞耻感，怕欠下人情的人，当他会体验到别人时，产生的是罪疚感，它们会有很大不同。羞耻感是觉得“我真蠢，我怎么傻到向他求助”，而罪疚感是觉得“对不起，我伤害了你”。

学习了这两个单元的课程，我觉得非常震撼，因为我本身就是种不“喜欢”愤怒、喜欢照顾别人，也不喜欢别人麻烦的人，甚至不喜欢跟一个也难以做别人外，找一个不非常吵闹的邻居，请问我老师这两者没有什么样的关系呢？

另外我内心也非常不喜欢这样，一直在尝试改变，包括有时行为先为我找好的“容器”，但有时就是无法拒绝别人，把关系弄得很难堪，请问武老师这种情况有什么技巧吗？

武志红

首先，既然一直不擅长表达愤怒，那么当你最想拒绝对方时把握不好，会尴尬，那么你最重要的是改变自己的尝试和练习，要有不怕麻烦的精神。

其次，我写过一篇文章，题目是《内耗是对内向者的保护，外向是对内向者的嘉奖》，大概意思是说，如果一个人关系内耗多，不太懂得拒绝别人，那他最好是内向的，因为他不可能一个人，他不擅长跟人，能用人，还能使用成功，那他自然想外向一些，因为每多构建一个关系，他整体上获益的。

我以前有个上司，是武老师说的非常喜欢麻烦别人人，也受不得别人麻烦的人，他本人是极度边没有用动性，第一眼，很难让人信赖人，边看，动性第二，看出他其实看不起任何人，但对京和一，些小事情会很出心，并且受到：第三，他的一切细节你能看到的举动，都是受人就是。同样也是“爱惜麻烦人”，为什么这种同样有多讨厌，人道“爱麻烦别人”也分境界？

武志红

没有麻烦，就没有感情，也并不是说去谁无端地爱去麻烦别人，入侵侵犯人，如果是后者，后者会容易引起别人的反感。

在关系中麻烦别人，就是“我”将动力传递到了“你”身上，这种至少是关系开始建立了。这只是上，而不是结束。如果像改性一样，如果一个人不去攻击性，那就什么都不用，但表达攻击性，并不意着直接去伤害别人。

我们在生活中每天会遇到无数的人，那我们是应该以“我与”的状态去面对每一个吗？还是说我们只对此种态面对一些人？如果是，我们只区分人，那么哪些人呢？是我们的重要他人吗？
