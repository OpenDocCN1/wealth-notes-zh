# 自由 07 | 让一切情绪流动

武志红

我这一节课的主题是“让情绪流动”，这是我们第四十一节“让一切情绪流动”。

在之前的三节课中，我讲了悲伤与愤怒这两种情绪的流动，这一节课来给我讲讲其他情绪的流动。

# 让恐惧流动

恐惧，是极为根本的负面情绪，可以说，恐惧决定着我们的盲区。边界。我的世界要突破自己的舒适区，进入更大的世界或舒适区的边界，总是由恐惧所形成。

不过这里你需要认识到一个很重要的东西，那就是我们在恐惧的所形成的多半是在童年，甚至是在童年早期的形成的。那个时候，我们的外在资源和内在力量都比较匮乏，随着逐渐长大，内在资源充足了，一个人随着的外在和内在力量都多了很多，这时候常常就可以去面对生命早期所恐惧的东西了。

来，举个例子。有一位女士，每当夜幕降临的时候，她总想把自己关在房间里，把所有门窗锁上，并一遍遍地检查，生怕没有锁好。

即便如此，她也不能安心，她还会把家里所有的灯都打开，然后自己坐在电视机前看电视。当什么节目不看后，也会把声音调到很大。她经常就这样一直看电视到大亮，第二天一看，恐惧也随之消失，而后才在疲惫中睡去。

她有一个5岁多的儿子，但儿子一点都不能给她带来安全感。有时，为了在晚上睡一觉，她会求朋友来陪伴，朋友不一定得是成年人，那样她才能睡着，不然不管得做什么，只要在她的任何一个地方待着，她就能在朋友安慰入睡，不管她睡得多好，只要朋友一离开她的家，她一定会在短时间内醒来。

我们在咨询中探讨，发现她对黑夜的恐惧达到了这种地步，是因他曾遭受过严重创伤。

她在4岁时，一个漆黑的夜里，亲生父母把她送人。那一天，她傍晚时睡着了，等一觉醒来，发现自己不在家里，而是在一条船上，身边是一对陌生的妈妈和叔叔。她说，他们现在真的是爸爸和妈妈了，她亲生父母不要她了。

这是非常惨痛的创伤，给她幼小的心灵留下了无法抹去的伤痕。现在，这位女士之所以再一次如此焦虑，是因为她第二次被最重要的亲人“抛弃”，她的丈夫和她离婚。

第二次，当她在黑夜中被放弃时，容易重新激活了她的幻想：如果我当时没有睡着，或许我就不会被爸爸妈妈抛弃了，这样，带不带？现在，就好像她是说：我不能在晚上睡觉，如果她不睡觉，她就可以避免第二次被重要的亲人抛弃了。这是心理上常见的“刻舟求剑”的游戏。

面临极端的防御我们最常用到的是防御恐惧。这位女士正是如此，她一遍遍地检查门窗有没有锁紧，打开所有的灯，把电视调到很响，找成年人陪，都是为了不想体验到恐惧。

但我认为在这个时候，最好的办法是要她去聆听恐惧，发现恐惧所传递的信息。假如她挖掘了，自己的恐惧来自4岁时被父母抛弃的经历，那么这种恐惧也许就可以逐渐地化解了。

不过，这么惨痛的创伤是独自一人不能承受与化解的，她需要寻求专业人士的帮助。这是她成年后所需要的专业之助，你有了金钱，你有了人脉，你有了生命的自主权，然后可以去寻找各种能帮助到你的资源。

恐惧，常常是在揭示生命的真相。你越是恐惧的地方，可能是藏着极为重要的生命真相。

# 让内疚流动

比起悲伤、愤怒和恐惧来，还有一种情绪是人类更不愿意接受的，那就是内疚。因为当处于内疚，愤怒和恐惧中，人常常会体验到自己的弱小，而处于内疚之中，你会产生“我不好”这种感觉。

为了避免“我不好”这种感觉，很多人宁愿选择不接受关系的真相，我时常会听到人们说这样的话：“我已经仁至义尽”，“我问心无愧”，“我心里上没有一点点不安”等等。

但是，一份和谐的关系，必然有丰言的付出与接受，你给予了物质和精神的爱，我接受，你给予你质和精神的爱，我接受，然后回到更多。如果这个付出和接受的循环被破坏，关系也会随即向坏的方向发展。

并且，与想象不同，付出和接受的循环被破坏，很多时候并不是因为不愿意给予，而是因为不愿意接受。这是冯培生会来得内疚。“我们，的国象治疗，和西方有权利说，我们得去的时候，就会感觉到义务”。

如果只付出而不接受，一个人就会有一种清心无愧，会觉得自己在这个关系中绝对清白无悔。这是一种很舒服的感觉，有这种感觉，会觉得自己在关系中永远站得住。那么，相应的，他的另一方也会觉得不舒服，会频频感到内疚，即使用明自己付出什么，那么难为情付出，也会经常觉得问心有愧，最终一定会产生逃离的冲动。

一旦对方彻底选择了逃离，那个一直认为自己清白无辜的付出者就会觉得受到了莫大伤害，并甚至会激烈地指责逃离者的背弃，但实际上，付出者是破坏关系的始作俑者。

我在做心理咨询和日常生活中，见过很多这样的故事：夫妻两口中，一个人很好，另一个人会所谓环的人，可那个被大家视为坏的人，却坚定地提出了离婚，而那个很好的人拒绝离婚，各种闹，各种不舍。

这是因为在这样，关系中，那个人“好”是迫于求清白，而那个“坏人”则越来越不喜欢种感觉，但他们常常难以说清，这到底是因为什么。

我的咨询师朋友于东辉就讲过这样一个案例。“坏人”丈夫说，对不起，我很难原谅他，可能你太太好了，太好对我，我家的人也太好，什么都好……我说不，但就是对这这一点不舒服”。

“好人”妻子听了更加委屈，激励地说：“我太好了，难道我是一个加害吗？”

接着，“好人”妻子对咨询师于东辉说：“对这个人，我尽全了力，要，是真正做到离婚这一步，我也问心无愧。

咨询师立即问她：“在和其他人的重要关系中，你也问心无愧？”

她说：“是的，我对所有人都尽力做到最好。”

咨询师再次问她：“你对人很好，他对人好，那么是你的朋友多，还是他的朋友多？”

这个问题问到了关键，的确的确，这位“好人”妻子的朋友远多于“坏人”丈夫。

一个人不够多么付出，仍会不可避免的会伤害另一方，总会产生或轻或重的内疚。所谓“好人”常常拒绝这个伤流动，正是非常不常力去做一个完美的付出者，那样就可以问心无愧了。只不过，这份问心没有消失，它其实是被“付出者”有意无意地转换到“接受者”身上了。

简而言之，“付出者”其实是在享受这样一种逻辑：既然我是付出的一方，那么我们关系中无论出现什么问题，都是你的错了。

最根本的人性是自恋，所以人最容易逃避的东西，就是“我错了”，明白了一点，就不难理解，所谓的“好人”为什么常常不被待见了。

# 让一切情绪流动

人性复杂，我们也极为复杂，在复杂的关系系统中，我们会产生各种各样的情绪，每一种情绪都深具信息，越是能够尊重这些情绪，并让它们在情感关系中充分流动，越会对自己和我和关系有尊重中。

如果我们把一些情绪视为好的而去表达，而把另一些情绪视为坏的而去压抑，那么关系就会各种不真实的信号，于是关系，和我，都变得更加真实。
