# 表 40.6 等腰三角形底部排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 計算排列最高點與最低點之間的高度，由最高點向上衡量或由最低點向下衡量排列高度，結果就是向上突破或向下跌破的最低目標價位。另外，等腰三角形也可能發生在一段走勢的中點，依此衡量目標價位。 |
| 順勢交易 | 等腰三角形屬於連續排列的可能性稍高，所以價格可能朝排列發生之前的趨勢方向進行突破。 |
| 等待突破 | 為了防範等腰三角形反轉型態，務必等待實際的突破。 |
| 排列內交易 | 如果三角形的排列規模很大，可以考慮在排列下限買進或回補，在排列上限賣出或放空。可是，當排列發展而逐漸接近三角形頂點，就停止排列內的交易。 |

點是進入排列之前價格趨勢的起點，此處採用的衡量法則與三波段衡量漲勢或跌勢完全相同（請參考第 26 與 27 章）。

按照個別情況，採用一種或兩種衡量法則。第一種方法（採用排列高度）比較保守，達成目標價位的可能性較高。

實際發生突破之前，無法預先判斷等腰三角形的突破方向。原則上，等腰三角形扮演連續排列的可能性較高。換言之，三角形將朝排列發生之前的中期趨勢方向進行突破。即使是圖 40.8，這個三角形排列雖然是短期下降趨勢的反轉型態，但屬於較長期上升趨勢（圖形沒有顯示）的連續型態。此處討論的較長期趨勢起始於 2 月初的$6 附近，9 月初曾經創$11^{7/8} 的高價，漲幅將近一倍。
