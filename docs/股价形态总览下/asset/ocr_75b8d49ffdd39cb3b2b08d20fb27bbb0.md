# Zurn Industries（建材，NYSE，代碼 ZRN）

三重頂

![](bbox=[0.18, 0.21, 0.89, 0.51])

圖 40.4 兩個等腰三角形排列。左側的案例向上突破，但沒有出現 5% 或以上的跟進漲勢（所謂的 5% 失敗）。這個三角形是三重頂排列的一部分。

果是雙重頂排列；如果把三角形排列向上突破的峰位考慮在內，整個結構是三重頂排列。請注意，在三角形排列之內，價格回檔並沒有跌破前述雙重頂所夾谷底的低點，所以前述雙重頂並沒有被確認或完成。

當價格向上突破第一個三角形而出現 5% 失敗之後，回檔走勢跌破三重頂排列最低谷底，三重頂排列於是完成。整個價格走勢雖然兩度回升到三重頂低點附近，但最後還是繼續下跌。前述的回升走勢構成圖 40.4 的第二個等腰三角形排列。

由整體結構觀察，就夠能夠解釋第一個三角形何以失敗。
