# 表 33.4 矩形頭部排列的突破統計數據

| 說明 | 向上突破 | 向下突破 |
| :--- | :--- | :--- |
| 發生回挫/回升走勢的排列 | 74/140 或 53% | 34/62 或 55% |
| 完成回挫/回升走勢的平均時間 | 11 天 | 11 天 |
| 到達最終高點/低點的天數 | 8 個月（244 天） | 3 月（82 天） |
| 突破位置在最近 12 個月 價格區間的下緣、中央或上緣 | 下緣 3%，<br>中央 21%，<br>上緣 76% | 下緣 18%，<br>中央 36%，<br>上緣 46% |
| 前述突破位置的 平均漲幅/跌幅 | 下緣 22%，<br>中央 51%，<br>上緣 56% | 下緣 20%，<br>中央 21%，<br>上緣 19% |

大部分的矩形頭部排列發生在年度價格區間的哪個位置呢？把突破發生當時的最近 12 個月價格區間劃分爲三等份（上緣、中央與下緣），不論向上或向下突破，排列大多發生在年度價格區間上緣。如果考慮年度區間三個位置的排列績效，向上突破落在上緣位置的平均漲幅最大（56%）；發生在三個位置的向下突破績效都差不多。
