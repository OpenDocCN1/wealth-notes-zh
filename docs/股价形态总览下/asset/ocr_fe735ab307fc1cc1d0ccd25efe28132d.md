# American Home Products（藥品，NYSE，代碼 AHP）

![](bbox=[0.07, 0.18, 0.86, 0.48])

圖 34.3 反轉型態的圓形底部排列。

這是一個圓形底排列，但沒有扮演連續型態的角色。如果你預期價格在排列完成之後將繼續下跌，最後可能認賠收場。所以，我把這個排列或其他類似案例視爲失敗。

另一種失敗類型稱爲「5%失敗」，價格朝預期方向突破，但沒有發生5%或以上的跟進走勢，結果又朝相反方向出現重大走勢*。在我所考慮的全部243個案例當中，只有11個排列發生5%失敗的情況。這意味著，一旦型態向上突破之後，價格通常都會繼續上漲。

*譯按：必須跌破圓形底的最低價，型態才算失敗。
