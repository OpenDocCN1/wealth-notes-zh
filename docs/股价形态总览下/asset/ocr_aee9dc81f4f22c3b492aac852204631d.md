# Thomas Industries Inc. (建材，NYSE，代碼 TII)

![](bbox=[0.15, 0.2, 0.95, 0.51])

圖 28.2 發生在下降趨勢末端的底部單日反轉。請注意，當天是一支向下突兀的長線形，收盤價位在盤中高薪附近。

成交量相當大，線形向下突兀的程度遠超過最近一年內的其他突兀線形。

為什麼會發生單日反轉排列呢？每當我看到一支突兀長線形，就想到一種情況：引發停損。在目前的價位下，設定著一系列的停損單，只要出現相當程度的跌勢，就會引發第一個停損。如果賣出的數量夠多，再配合造市者、帽客與短線玩家的放空行爲，價格很容易進一步下跌。在這種情況下，透過惡性循環的效應，下檔的停損單將陸續被引發。所以，股價將一路暴跌，直到足以吸引大量買單進場為止。這種盤勢經常是由股票做手故意引發，頗有洗盤的味道。
