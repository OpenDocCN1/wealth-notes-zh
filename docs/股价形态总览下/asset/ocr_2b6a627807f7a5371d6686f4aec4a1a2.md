類似如先前價格峰位提供的下檔支撐，往往也會影響修正階段的價格回檔程度。當價格下跌到支撐區，通常會稍作停頓或橫向整理，然後才繼續下跌或向上反彈。支撐區過去發生的成交量大小，經常可以反映支撐力道的強勁程度。如果先前的價格峰位曾經爆出大量，目前所提供的支撐力道就應該相對強勁；當然，強勁的支撐還是可能被貫穿，但至少比較困難一些。

# # 統計數據

表 27.2 列示三波段衡量漲勢的統計數據。我總共找到 501 個案例，其中 69%屬於下降趨勢的底部反轉型態（換言之，第一隻腳發生在價格下降趨勢的末端），剩下的 156 個案例則屬於上升趨勢的連續型態。

排列的失敗率為 23%，稍高於我願意接受的最高門檻 20%。這意味著每四個案例當中，平均就有一個排列的第二隻腳不能向上穿越第一隻腳的高點。本章「失敗案例」一節中曾經提到，很多失敗情況都是因為第二隻腳的漲勢停頓於第一隻腳的高點附近，構成雙重頂的頭部排列。

對於成功的排列來說，平均漲幅為 68%。前文已經提到，如此偏高的漲幅似乎另有玄機，確實如此。由於進場點通常不會發生在修正階段結束之前，所以第二隻腳的平均漲幅（37%）或許更能反映這個排列的實際操作績效。
