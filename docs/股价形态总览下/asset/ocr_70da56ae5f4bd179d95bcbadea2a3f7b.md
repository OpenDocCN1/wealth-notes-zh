# 表 26.3 三波段衡量跌勢的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 第二隻腳的長度較第一隻腳短 10% 左右。第一隻腳的長度是由最高價衡量到最低價（修正階段的起點），由修正階段的最高價向下衡量第一隻腳的長度，結果就是第二隻腳的目標價位（達成率爲 43%）。另外也可以利用第一隻腳的三分之二長度來衡量目標價位，達成率提高爲 80%。 |
| 第二隻腳的放空與停損 | 一旦確定三波段衡量跌勢正在進行中，儘快進場放空。萬一價格反彈穿越修正走勢的高點，立即認賠出場。價格偶爾會第二次向上測試修正高點，然後才正式展開跌勢，所以停損設在修正高點的稍上方。 |
| 結束部位 | 價格下跌到重要支撐區或目標價位附近，回補空頭部位。 |
| 支撐/壓力 | 修正階段經常提供後續走勢的重要支撐與壓力。 |

中利用 A、B、C 與 D 標示三波段衡量跌勢的重要轉折點。首先計算第一隻腳的高度，利用波段最高價 $52 \frac{7}{8}$ （A 點）減去波段最低價 $42$ （B 點），結果是 $10 \frac{7}{8}$ 。由修正階段最高價 $47 \frac{3}{4}$ （C 點），向下衡量第一隻腳的高度 $10 \frac{7}{8}$，即是目標價位 $36 \frac{7}{8}$ 。這個目標價位完成於 12 月 7 日。

一旦判斷三波段衡量跌勢正在形成當中——通常是在修正走勢結束而價格開始下跌的時候——進場建立空頭部位。利用衡量法則估計下檔目標價位，但必須瞭解目標價位經常不能完成。建立空頭部位之後，把停損設在修正階段高點的上方 1/8
