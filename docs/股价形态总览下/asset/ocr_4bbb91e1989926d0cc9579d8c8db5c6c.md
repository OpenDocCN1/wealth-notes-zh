# 週線上關鍵反轉

![](bbox=[0.32, 0.3, 0.52, 0.41])

# 摘要資料

**外觀**
在週線圈上，線形高價高於前一週高價，低價也低於前一週低價。收盤價高於前一週的高價。

**反轉或整理**
短期（3 個月以內）的多頭反轉走勢。

**失敗率**
23%。

**平均漲幅**
44%，最經常發生漲幅為 20%。

**目標價位 達成率**
84%。

**意外發現**
配合中等程度的大量（移動平均量的 150%），關鍵反轉的績效最理想，但隨著成交量繼續擴大，績效就會下降。關鍵反轉本身的線形愈長，績效表現通常愈理想。

**参照排列**
（46）週線向下關鍵反轉。
