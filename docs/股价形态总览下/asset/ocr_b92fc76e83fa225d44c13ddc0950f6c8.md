# 表 32.2 矩形底部排列的一般統計數據

| 說明 | 向上突破 | 向下突破 |
| :--- | :--- | :--- |
| 排列數量：1991 年~1996 年的 500 支股票 | 41 個 | 54 個 |
| 反轉或整理排列 | 41 個反轉 | 54 個整理 |
| 失敗率 | 0 | 2/54 或 4% |
| 成功排列的平均漲幅 / 跌幅 | 46% | 19% |
| 最經常發生漲幅 / 跌幅 | 20% | 10%~15% |
| 達成目標價位的成功排列 | 38/41 或 93% | 34/52 或 65% |
| 完成排列的平均期間 (由起始到突破) | 3 個月 (84 天) | 3 個月 (87 天) |
| 成交量呈現下降趨勢的排列數量 | 19/41 或 46% | 29/54 或 54% |
| 成交量呈現下降與上升趨勢的績效 | 下降 43%，上升 49% | 下降 17%，上升 22% |
| 相對於突破前一天成交量，突破當天與隨後 5 天的成交量 | 163%，167%，106%，91%，91%，133% | 171%，201%，141%，124%，121%，133% |

如同「摘要資料」所強調的，在矩形底部向下突破的所有案例當中，只有 2 個失敗情況，失敗率為 4%，相當於整體矩形底部排列的失敗率為 2%。請注意，只因爲我沒有發現矩形底部向上突破的任何失敗案例，並不表示該排列不會失敗。這只意味著我所觀察的股票在某特定期間內沒有發生這類的事敗。可是，雖然矩形底部排列的失敗率很小，但確實存在提前突破的情況，仍然需要小心。
