# 辨識準則

等腰三角形屬於辨識上比較困難的一種股價型態，讀者對於這一點或許覺得有些意外，但實際上就是如此。表 40.1 列示排列辨識準則。等腰三角形底部排列發生之前，價格呈現下降趨勢，頭部排列則發生在上升趨勢之後。雖然底部排列也可能發生在年度高價附近，但只要排列發生之前的價格處於下降趨勢，我就把型態歸類爲底部排列。圖 40.2 提供另一個等腰三角形底部排列的例子。
