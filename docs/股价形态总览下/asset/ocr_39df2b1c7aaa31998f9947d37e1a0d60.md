# 表 39.6  下降三角形排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 在三角形排列的起點，計算型態的高度。由水平下限向下衡量型態高度，結果就是最低目標價位。另一種衡量方法，在排列下限的起點位置，向右下方繪裂一條直線與排列上限平行，當價格向下突破，取當時對應的平行線價位為下檔目標價位。 |
| 務必  等待確認 | 由於排列向上與向下突破的可能性幾乎相同，所以最好等待實際突破。向下突破之後，可以考慮立即放空，或等待回升走勢結束而價格又開始下跌，才進場放空。另一種方法，是等待排列向上突破，然後買進股票。向上突破的經驗常發生漲幅為 25%，平均漲幅為 42%，這種績效似乎值得等待與下注。 |
| 向下突破  的賣出訊號 | 如果你是一位短線交易者，只要下降三角形向下突破，立即放空股票，股價繼續下跌的可能性頗大。對於中、長期投資人，如果不希望賣出持股，可以考慮在下檔目標價位附近加碼買進，或利用下檔支撐協助預測最終低點。 |
| 按照衡量法則  回補空頭部位 | 對於短線交易者，一旦價格接近目標價位（利用衡量法則），回補空頭部位。 |

附註：排列向下突破而股價回升到排列下限附近，進場放空股票，然後在目標價位附近回補空頭部位。或者，考慮排列向上突破之後買進。

向下突破的時候，該平行線的對應價格就是目標價位。
