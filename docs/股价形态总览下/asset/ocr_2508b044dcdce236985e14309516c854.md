# 表 36.1 上升與下降扇貝形排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 價格趨勢 | 不論上升或下降扇貝形排列，型態發生之前的價格趨勢應該朝上。 |
| 勾狀走勢 | 對於兩個扇貝形構成的排列，不論上升或下降型態，都有兩個價格峰值，中間夾著開口向上的圓弧狀走勢。上升排列的右側峰值較高，下降排列的左側峰值較高，前者的每個扇貝形都呈現勾狀，後者則呈現左右顛倒的勾狀。 |
| 成交量 | 上升排列的成交量呈現 U 型，排列兩端的成交量大於中間部分。下降排列沒有明顯的成交量型態。 |
