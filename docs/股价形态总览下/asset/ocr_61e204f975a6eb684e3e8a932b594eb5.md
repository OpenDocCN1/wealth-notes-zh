# 表 33.1   矩形頭部排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 價格上升趨勢 | 排列發生之前的短期或長期價格趨勢必須朝上。 |
| 水平趨勢線 | 沿著價格走勢轉折高點與轉折低點繪製的趨勢線，應該呈現水平狀或近似水平狀。 |
| 觸及點 | 每條趨勢線都至少有 2 個觸及點，總共至少有 4 個觸及點。 |
| 成交量 | 突破之前，成交量通常趨於下降。 |

確。舉例來說，銜接排列上限的兩個轉折高點，不應該發生在同一段橫向走勢內；換言之，前述兩個轉折高點之間，價格走勢應該顯著回檔，使得兩個轉折高點成爲顯著的峰位。
