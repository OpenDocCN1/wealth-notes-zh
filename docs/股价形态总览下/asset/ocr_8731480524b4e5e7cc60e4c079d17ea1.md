大量突破是否有助於排列續效？關於大量突破與小量突破，此處繼續引用前一段的定義。不論向上或向下突破，大量突破的續效都優於小量突破，但兩者之間的差異缺乏統計上的顯著意義；換言之，前述結論可能純屬巧合，但也可能確實如此。同樣地，樣本很小。

# 交易戰術

表 40.6 列示等腰三角形底部排列交易戰術的摘要內容。我們可以透過兩種方法衡量排列的目標價位。圖 40.8 顯示第一種方法。計算型態內最高價（B 點$9^{3} / 4$）與最低價（A 點$8^{3} / 8$）之間的排列高度（$1^{3} / 8$）。把排列高度加上 B 點，或由 A 點扣減，即代表向上或向下突破之後的最低目標價位。就目前這個例子來說，由於向上突破，所以目標價位爲$11^{1} / 8$（=9^{3} / 4+1^{3} / 8$）。在不到 1 個月的期間內，價格就完成目標價位。

某些等腰三角形的行爲類似大型的三角旗形（pennants）。它們經常出現在一段快速走勢的中點位置（就像三波段衡量漲勢或跌勢一樣）。如果三角形向下突破，價格很可能繼續下跌而完成目標價位。在這種情況下，衡量 C 點（$11^{7} / 8$）到 A 點的距離，然後由 B 點扣減。結果，下檔的目標價位爲$6^{1} / 4$。C
