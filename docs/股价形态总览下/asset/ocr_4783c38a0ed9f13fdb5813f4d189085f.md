# 表 43.1  三重頂排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 三個顯著而<br>大規模的頭部 | 尋找三個轉折高點，彼此間隔一段距離，形狀非常明顯。頭部經常呈現Λ形的尖銳峰位，三個峰位所夾的兩個谷底，形狀則相對圓滑。 |
| 相同價位 | 三個峰位的價位差異應該很小。中間峰位不得顯著較高，否則就是頭肩頂排列。小型的三重頂排列經常呈現擴張型態，尤其是直角三角形的擴張頂，所以也應該留意谷底的價位水準。 |
| 成交量<br>下降趨勢 | 排列內的整體成交量應該呈現下降趨勢，但肉眼恐怕很難察覺。表面上看起來，成交量呈現水準狀，只有三個峰位附近的水準特別高。第一個峰位的成交量通常特別大。 |
| 確認點 | 當價格由第三個峰位下跌，只代表潛在的三重頂排列。唯有當價格下跌而穿越排列的最低價（確認點），三重頂才算完成。 |
| 迴線圖 | 由於三重頂通常屬於大規模的排列，不妨參考迴線圖，或許有助於辨識較長期的型態。 |

排列內的成交量大體呈現下降趨勢，交投相對冷清；當然，每個案例的情況都各自不同。三個峰位的成交量較大，尤其是第一個峰位。
