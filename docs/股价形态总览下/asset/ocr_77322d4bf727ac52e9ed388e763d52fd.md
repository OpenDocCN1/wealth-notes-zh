# 摘要統計數據

# 定義與說明

在這份摘要總結內，首先就本書討論的股價型態，按照英文名稱的字母順序排列整理一份績效統計數據。其次依據各種衡量基準，提供績效最佳的前 10 種股價型態。

表格內某些簡寫或符號的意義：

+   不重要 = 太少而可以忽略
不適用 = 未經考慮或不適用於本排列
( ) = 括弧內的數據代表下跌
* = 因為樣本太小而出現的不尋常讀數

欄位標題解釋：

| | |
|---|---|
|失敗率|沒有出現預期行為的排列百分率，包括 5%失敗情況在內。這些數據適用於排列完成突破（經過確認）之後。|
|反轉或整理|標示爲「反轉」，代表該排列大部分都扮演既有趨勢的反轉型態；標示爲「整理」，代表該排列大部分都扮演既有趨勢的整理或連續型態。如果同時標示「反轉」與「整理」，意味著該股價型態沒有明顯的反轉或整理傾向。|
