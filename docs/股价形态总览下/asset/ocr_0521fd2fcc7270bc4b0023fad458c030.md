# 向上突破

外觀 排列之前的價格趨勢朝上，排列內轉折高點不斷下滑，轉折低點不斷墊高；排列上限向下傾斜，排列下限向上傾斜，兩條趨勢線向右收斂。向上突破。

反轉或整理 短期（3個月以內）的多頭整理走勢。

失敗率 5%。

平均漲幅 37%，最經常發生漲幅為 20%。

成交量趨勢 下降。

提前突破 14%。

回升 58%。

目標價位達成率 81%。

其他名稱 螺旋。

參照排列 （20）頭肩頂排列，（37）鰭鱸排列，（38）上升三角形排列，（39）下降三角形排列，（40）等腰三角形底部排列。

如果讀者熟悉等腰三角形排列的話，可能想知道我如何劃分頭部與底部排列。我以排列發生之前的價格趨勢做為基準，如果排列發生之前的價格處於上升趨勢，等腰三角形屬於頭部排列；如果排列發生之前的價格處於下降趨勢，等腰三角形屬於底部排列。我按照價格趨勢劃分排列，原本希望藉此判斷突破方向，結果顯然沒有幫助。本章準備討論等腰三角形頭部排列。

等腰三角形頭部排列的失敗率偏低，向下突破為 6%，向上突破為 5%。我認為失敗率不超過 20%，就屬於可靠的排列。

向下突破的平均跌幅為 20%，大約對等於一般的空頭排列。向上突破的平均漲幅為 37%，稍差於一般多頭排列的續
