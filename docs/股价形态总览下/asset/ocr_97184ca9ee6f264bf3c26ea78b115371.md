# 表 35.1 圓形頂排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 日線圖或週線圖 | 排列的期間很長，所以週線圖上也會呈現。 |
| 圓頂狀半月形結構 | 價格呈現開口朝下的圓頂狀走勢，最初呈現漲勢，到達峰位之後，反轉為跌勢。排列末端的底部位置，可能高於型態起點的價位。 |
| 成交量呈現圓弧狀趨勢 | 成交量型態大体上也呈現對應的圓弧狀，但開口朝上。 |

價格排列都呈現圓頂狀，最初的漲勢較快，然後速度轉緩，最後由漲轉跌，甚至下跌速度加快，畫出開口朝下的圓弧狀軌跡。

如同圓形底一樣，圓形頂的成交量型態也呈現圓弧狀，但圓弧的開口朝上，不同於價格的圓頂狀開口朝下。換言之，在圓形頂排列的最初與末端，成交量相對較大，排列中央部分的成交量最小。請注意，這只是一個參考準則，不是價格型態成立的必要條件。許多情況下，我們發現圓形頂排列的成交量呈現不規則型態，這並不妨礙價格排列的有效性。重要的是價格本身具備圓頂狀的走勢，成交量只是補充證據而已。

圖 35.2 提供兩個週線圖上的圓形頂例子。第一個排列起始於 1991 年 12 月底的低價$12$1/16。價格由此緩慢上升，越過峰位之後，又緩慢下跌，最後在$14 附近回升，並且展開一段長期的漲勢，然後演變為第二個圓形頂排列。
