# 底部排列

**外觀** 價格向下跌空，經過幾天盤整，又在類似價位向上跳空，留下孤島狀的底部。

**反轉或整理** 短期（少於 3 個月）的多頭反轉排列。

**失敗率** 17%。

**平均跌幅** 34%，最經常發生跌幅低於 20%。

**成交量趨勢** 向下。

**回挫** 70%。

**價格目標達成率** 85%。

島狀反轉排列（island reversals）的績效沒有預期理想，這點讓我覺得相當訝異。頭部與底部排列的失敗率都還算不錯，分別為 13% 與 17%，低於我認爲可靠排列所允許發生的最高門檻 20%。

頭部排列的平均跌幅爲 21%，稍優於一般空頭排列的平均水準（20%），但最經常發生跌幅不足 10%。這或許意味著你不應該經常操作這個排列。底部排列的平均漲幅爲 34%，稍低於一般多頭排列的平均漲幅（40%）；最經常發生漲幅爲 20%，大約類似於一般多頭排列的水準。
