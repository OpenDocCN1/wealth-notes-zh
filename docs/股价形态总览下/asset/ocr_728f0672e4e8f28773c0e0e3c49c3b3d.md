# 辨識準則

上升與下降楔形屬於最難辨識的股價型態。可是，此處還是可以提供一些辨識準則，請參考表 45.1。

相關說明請參考圖 45.2。首先，我們發現排列是由兩條向上傾斜的趨勢線所界定。銜接排列轉折高點與轉折低點的兩條趨勢線都必須向上傾斜，不允許存在水平狀的趨勢線（否則就是上升三角形排列或上升直角三角形擴張排列）。

表 45.1 上升楔形排列的辨識特質

| 特質 | 討論 |
| --- | --- |
| 兩條向上傾斜的趨勢線 | 分別沿著價格走勢的轉折高點與轉折低點繪製趨勢線，兩條趨勢線都向上傾斜，而且向右收斂。 |
| 多個觸及點 | 上升楔形排列的兩條趨勢線需要多個觸及點。如果觸及點不足 5 個，排列可能有問題（某條趨勢線有 3 個觸及點，另一條趨勢線有 2 個觸及點）。 |
| 至少 3 星期 | 下降楔形排列的涵蓋期間至少 20 個交易日（3 星期）；如果期間少於 20 個交易日，應該屬於三角形排列。排列期間也很少超過 90 到 120 個交易日（3、4 個月）。 |
| 成交量趨勢 | 排列內的成交量通常呈現下降趨勢。 |
| 突破量 | 可能大量突破或少量突破，但突破量通常低於平均水準。 |
