# 下降排列

+   外觀
價格下跌,創谷底之後,稍微回升整理,然後又繼續下跌,形成一系列顛倒勺狀或扇貝狀的走勢。

+   反轉或整理
短期(3個月以內)的空頭整理走勢。

+   失敗率
3%。

+   平均跌幅
24%,最經常發生跌幅大約是20%。

+   成交量趨勢
沒有明顯的趨勢。

+   目標價格達成率
52%。

+   參照排列
(19)複雜頭肩底排列,(34)圓形底排列。

傳統技術分析只提到上升扇貝形排列(ascending scallops),這是由一系列(至少兩個)勺狀價格排列構成的上升走勢。根據我的推想,既然有上升排列,就應該有對應的下降格式。可是,詳細討論這兩種排列之前,或許應該先簡略說明重要的發現。

上升扇貝形排列的失敗率為25%,超過可靠排列的最高門檻 20%。下降扇貝形排列(descending scallops)的失敗率只有 3%。兩者的失敗率為何有如此大的差異呢?我運用排列右端高價做爲基準,藉以計算最終高價或最終低價的變動百分率。對於上升扇貝形排列,右端最高價的水準遠高於排列左端高價,造成基準過高的不利狀況。反之,由於下降扇貝形排列的右端高價比較接近——相對於左端高價而言——排列低點與最終低點,以此做為衡量基準,自然有利於續效。

譯按:這可以解釋上升排列平均漲幅何以低於一般多頭排列,或下降排列平均跌幅何以超過一般空頭排列,但這些解釋與失敗率之間有什麼關聯呢?
