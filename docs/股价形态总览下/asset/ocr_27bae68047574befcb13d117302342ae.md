表 24.3 內側日排列的意外發現

| 說明 | 結果 |
| :--- | :--- |
| 內側日是否預示隔天將發生重大價格走勢？ | 否 |
| 內側日前一天收盤價，是否預示排列突破方向？ | 否 |
| 內側日當天收盤價，是否預示排列突破方向？ | 是 |
| 內側日收盤價落在前一天價格區間的位置，是否預示排列突破方向？ | 是 |
| 內側日是否導致隔天的價格區間擴大？ | 是（56%） |
| 內側日前一天與當天之間的價格區間比率愈小，排列的漲幅或跌幅是否愈大？ | 沒有明確結果 |

前一天的收盤價位置，對於排列隨後的突破方向，是否可以提供預測上的線索？不行。我把內側日前一天的價格區間劃分為三份：上端 25%、中間 50%與下端 25%。然後，我考慮該天收盤價落在上端 25%與排列隨後向上突破，這兩個事件是否存在關聯？同樣地，我也考慮收盤價落在下端 25%與排列向下突破，兩者之間是否存在統計上的相關性？結果，沒有證據顯示內側日前一天收盤價位置與排列突破方向之間存在關聯。

其次，我考慮一個類似的問題：內側日收盤價落在當天價格區間上端的 25%之內，這個事件與排列隨後向上突破之間是否存在關聯？結果，在所有收盤價落在上端 25%的案例中，有 61%發生向上突破。同樣地，我也考慮向下突破的情況，結果也很類似。在所有內側日收盤價落在當天價格區間下端 25%以內的案例，有 60%發生向下突破。
