# 失敗案例

一旦價格向上穿越確認水準，由第三個谷底起算的漲勢期間平均應該超過 1 個月。價格穿越壓力線之後，通常會拉回測試支撐，然後——大部分情況下——繼續上漲。某些情況下，價格向上穿越確認水準的幅度不足 5%，回檔測試支撐失敗，價格繼續下跌，這稱爲 5%失敗。我們知道，潛在三重底出現之後，唯有當價格向上穿越確認水準（向上穿越三個谷底所夾兩個峰位的最高價），三重底才正式完成。所以，對於已經完成的三重底排列，只可能發生 5%失敗的情況。非常幸運地，5%失敗的情況很罕見；在全部 122 個案例中，只有 5 個 5%失敗的案例，發生頻率大約是 4%，圖 42.4 就是一個例子。
