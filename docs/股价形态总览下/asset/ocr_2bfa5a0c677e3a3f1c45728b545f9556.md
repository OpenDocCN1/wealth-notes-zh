表 34.4 圓形底排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 杯口右緣價位減去排列最低價，此為排列高度。由杯口右緣向上衡量排列高度，結果是向上突破之後的最低目標價位。這個衡量法則大約只適用於三分之一的案例，所以運用上必須謹慎。 |
| 等待價格上漲 | 等待收盤價向上穿越杯口左緣價位，然後才進場買進。 |
| 留意柄部 | 圓形底排列的上漲過程中，價格一旦到達杯口左緣先前高點附近，可能回檔形成柄部。在柄部發展過程，當價格向上穿越杯口右緣或柄部的下降趨勢線，代表進場買進的訊號。 |

杯口右緣，然後進場買進。進一步討論相關的 transaction 戰術之前，請注意表 34.4 列示的衡量法則。目標價位可以用來估計排列的獲利潛能。讓我們利用圖 34.5 做爲例子，說明衡量法則的運用。首先計算排列高度，把杯口右緣價位減去排列最低價。對於圖 34.5 的例子，杯口右緣為$31^{7/16}（這個價位頗有爭議），排列最低價為$25，排列高度爲 6^{7/16} 點。由杯口右緣向上衡量排列高度，目標價位爲$37^{1/8}$，於 11 月底達成。

關於衡量法則，我希望提出一項警告：這個方法基本上不適用，因爲只有三分之一的圓形底排列能夠達成目標價位。所以，如果你希望評估某個圓形底交易對象的風險／報酬關係，或許應該藉由支撐與壓力來界定報酬潛能。
