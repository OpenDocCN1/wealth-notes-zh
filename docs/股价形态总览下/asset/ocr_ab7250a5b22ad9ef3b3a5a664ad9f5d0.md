# 交易範例

戴夫是一位藝術家。由於傳統藝術的出路不太理想，戴夫準備進入電腦領域，讓自己成爲一位圖形設計師。他嘗試各種硬體與軟體設備，希望透過最新科技來模擬創作的感覺。

關於如何辨識股價型態，這點對於戴夫來說一點也不困難，因爲他的眼力非常敏銳。事實上，這也是戴夫介入圖 33.6的理由；可是，他沒有及早察覺這個排列，一直等到向上突破之後的回挫過程中，他才發現這個交易機會。

戴夫計算矩形排列的高度，由排列上限衡量矩形高度，估計上檔的最低目標價位。他決定買進這支股票，但並沒有在回挫走勢中買進。一直等到價格向上跳空 (突破缺口)，他才實際進場，買進成本爲 $40。價格連續上漲三天之後，走勢完成目標價位 $43 \frac{1}{2}。隔天，價格再度向上跳空 (竭盡缺口)，意味著漲勢即將結束 *。隔天，收盤價稍微下跌，戴夫也在這一天結束部位，賣出價格爲 $47 \frac{1}{2}。不到一個星期之內，戴夫賺取每股 7 點的獲利，相當於 18% 的報酬率。

他提領半數的獲利，利用這筆資金更新電腦設備。其餘的獲利仍然留在市場，準備尋找其他的交易機會。

> *譯按：唯有從事後的角度才能判斷這個缺口是「竭盡缺口」而不是「逃逸缺口」。換言之，譯者認爲，絕對不應只因爲價格向上跳空而結束部位。
