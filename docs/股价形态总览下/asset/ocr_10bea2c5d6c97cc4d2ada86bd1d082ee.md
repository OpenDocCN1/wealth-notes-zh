# 底部排列

外觀 單日的向下突兀長線形，在盤中高價附近收盤。

反轉或整理 短期（少於 3 個月）的多頭反轉排列。

失敗率 17%。

平均漲幅 26%，最經常發生報酬率 10%~15%。

成交量趨勢 當天成交量很大，但迅速萎縮。

回挫 61%。

其他名稱 高潮日，賣壓高潮。

「摘要資料」給我們的唯一大驚奇是：單日反轉排列（one-day reversals）的績效理想程度遠超過預期。沒錯，頭部排列失敗率 24% 高於我認為可靠排列所允許發生的最高失敗率 20%，但已經較預期情況好多了。頭部排列的平均跌幅為 19%，非常接近整體空頭排列的平均水準 20%。可是，底部反轉排列的平均漲幅只有 26%，遠低於整體多頭排列的平均水準 40%。不論頭部或底部排列，最經常發生漲幅或跌幅都在 10% 到 15% 之間，大體上符合預期。可是，請注意，單日反轉——顧名思義——的關鍵走勢發生在一天之內，等到你察覺盤勢的變化，恐怕已經太遲了；換言之，你通常不可能實際掌握統計數據所顯示的績效。

頭部排列經常發生回升走勢（發生頻率大約有 71%），這意味著賣出持股或放空股票的動作可以稍微延遲。底部排列發生回挫走勢的頻率稍低，這方面的操作不可期待過高。
