
## 表 41.1 等腰三角形頭部排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 形狀 | 價格沿著兩條趨勢線發展，排列上限向下傾斜，排列下限向上傾斜，兩者朝向未來（右方）收斂。排列雖然稱為等腰三角形，但兩腰（上限與下限）不必具有相同長度。 |
| 觸及點 | 銜接排列上限與下限的轉折高點與低點，至少需要各有兩點（換言之，總共至少需要四個轉折點）。 |
| 成交量 | 排列內的成交量呈現下降趨勢，但允許偶爾出現大量，瀕臨突破之前的成交量通常很小。 |
| 提前突破 | 這是指收盤價穿越到排列之外，但在通過三角形頂點之前，很快又回到排列之內。相對於真正突破，提前突破的發生時間稍早，突破成交量也較小。 |
| 突破方向 | 事前不知道突破方向。採取行動之前，應該等待實際的突破。所謂突破，是指收盤價穿越到排列之外，但這與提前突破不一樣，不會很快又折返排列之內。如果突破之後發生折返走勢（回挫或回升），通常會在排列邊緣或三角形頂點獲得支撐或遭遇壓力。 |
| 排列期間 | 至少應該是 3 個星期以上。期間少於 3 個星期，最好歸納為三角形旗形。 |

接近或觸及排列上限或下限的轉折高點或低點，標示為阿拉伯數字，每條趨勢線都至少有两个觸及點。請注意，這些觸及點必須是非常明確的峰值（轉折高點）或谷底（轉折低點）。

成交量型態的趨勢朝下。排列發展過程中，成交量當然可能呈現「價漲量增／價跌量縮」的現象，但整體趨勢應該趨於下降。我們或許可以說，如果等腰三角形的成交量沒有呈現下降趨勢，應該屬於不尋常現象，但還是可能發生。可是，話說回來，即使成交量呈現下降趨勢，肉眼也未必能夠察覺，除非你計算迴歸直線的斜率。大約有 80% 的三角形排列，成交量呈現下降趨勢，這個百分率已經高到足以讓你謹慎思考任何的例外情況。

### Minnesota Mining and Manufacturing（化工，NYSE，代碼 MMM）

![](img/157738047fa61d5e4bdbaf89f0241a36_354_0.png)

圖 41.2 發生提前突破的等腰三角形頭部排列。價格向上突破，但在通過三角形頂點之前，又折返排列之內。在目前這個例子中，價格不但重返排列之內，而且朝另一邊突破。阿拉伯數字標示趨勢線觸及點。向下突破屬於迴光返照走勢，價格在單日之內下跌$5，然後向上反彈，但最後還是下跌。

所謂「提前突破」，是指收盤價穿越到排列上限或下限之外，但很快——幾天之內——又折返到排列之內。請注意，價格必須在還沒有通過三角形頂點之前折返。相對於真正突破，提前突破發生的時間較早，成交量也較小（細節內容請參考「統計數據」）。

對於圖 41.2 的三角形排列，價格向下突破，代表既有的上升趨勢向下反轉。由事後的角度觀察，最初的向上突破顯然是提前突破。價格穿越排列上限之後，很快又折返到排列之內，甚至朝另一側發展。提前突破的向上動能無法持續，單日之內出現$5 的跌勢，呈現迴光返照的走勢。價格繼續下滑，最後創$46^{3/8}的低點，跌幅為 20%。

圖 41.3 顯示兩個三角形排列。左側排列並不是有效的等腰三角形。左側三角形是由轉折低點（A 點）開始，然後價格上漲到轉折高點（B 點）。接著，價格沿著排列上限下跌，到達轉折低點（C 點）。請注意，此處只有一個轉折高點（B 點）與兩個轉折低點（A 點與 C 點），但第二個轉折低點（C 點）沒有落在三角形之內。這個排列不只欠缺一個轉折高點與一個轉折低點，而且排列下限的繪製方法也不正確。三角形中央的留白太多，這經常是排列辨識不當的微兆。價格應該來回穿梭排列，不應該留下太多空白。

第二個三角形排列發生在 10 月中旬，排列上限與下限的轉折點數量都不只兩個。這是一個有效的等腰三角形，但發展有些不尋常。就在即將通過三角形頂點之前，價格向下假突破，然後立即回升，幾乎剛好穿越三角形頂點而向上發展。

我不認為最初的向下突破屬於真正突破，因為價格最後顯然是向上發展（換言之，這是價格出現最大走勢幅度的方向）。價格穿越到排列下限的 3 天走勢，我認為這屬於提前突破。不論向上或向下的提前突破，收盤價必須穿越排列上限或下限，而且最後必須又折返回排列之內。

### Gleason Corp.（機械，NYSE，代碼 GLE）

![](img/157738047fa61d5e4bdbaf89f0241a36_356_0.png)

圖 41.3 兩個等腰三角形頭部排列，一個有效，另一個無效。右側三角形出現提前向下突破，真正突破的方向朝上。左側排列不屬於有效的三角形。

對於圖 41.3 的兩個排列，成交量基本上都呈現下降趨勢。以 10 月中旬開始的排列來說，最初的每天成交量為 60,100 股，突破前一天的成交量為 4,600 股，成交量顯著縮小。

讓我們回頭觀察左側的排列。請注意，A 點左側與 C 點右側各有一個峰位，配合 B 點的峰位，整個排列實際上是頭肩頂型態。

在擴張排列之後，如果緊接著發生等腰三角形排列，整個結構將是菱形頂或菱形底排列。如果三角形上限或下限呈現水平狀，結果將是上升三角形或下降三角形排列。這些都是你需要特別注意的價格型態。許多排列的發展勁道超過等腰三角形，不論在操作上或目標價格的衡量上都需要留意。

### 失敗案例

即使你確定某個排列是等腰三角形，但又如何判斷它是否會發生預期中的行為呢？完全無法判斷。請觀察圖 41.4，這是一個向下突破的等腰三角形，價格隨後回升到排列下限附近，接著又緩步下滑，然後突然折向三角形的頂點。在三角形頂點附近，價格經過一個月的橫向盤整，最後又恢復中期上升趨勢。

圖 41.4 即是我所謂的 5% 失敗情況。換言之，價格朝某個方向突破，但還沒有出現 5% 或以上的跟進走勢之前，價格又朝相反方向發展。非常幸運地，等腰三角形排列很少發生 5% 失敗的情況。可是，如同圖 41.4 顯示的，偶爾還是可能发生，所以你必須防範。

### Office Depot（辦公設備與供給，NYSE，代碼 ODP）

![](img/157738047fa61d5e4bdbaf89f0241a36_358_0.png)

圖 41.4 5%失敗的等腰三角形頭部排列。價格向下突破，然後拉回到排列下限，接著朝三角形頂點發展，最後走高。這屬於 5%失敗案例，因為價格向下突破之後，在發生 5%或以上的跟進跌勢之前，又朝上發展。

觀察圖 41.4，我們發現等腰三角形排列發生之前的價格趨勢朝上，但三角形最初向下突破。由於半數以上的等腰三角形都屬於連續型態，這個例子的突破方向應該朝上，但實際不然。碰到這種情況的時候，應該考慮這是否是合理的發展。是否有任何經濟基本面的理由導致價格下跌？如果你不知道答案，就不要進行交易。反之，如果你決定順著向下突破走勢放空股票，務必設定停損。一旦價格順利朝下發展，儘快把停止價位調降到損益兩平點。

就等腰三角形頭部排列來說，向上突破的案例數量幾乎是向下突破的兩倍。由於頭部排列發生之前的價格趨勢朝上，所以向上突破的排列屬於連續型態。

兩個突破方向的排列失敗率分別爲 5%與 6%，都低於可靠排列所允許發生的最高失敗率 20%。在全部 255 個案例當中，失敗的排列只有 14 個，非常不錯的績效。

向上突破的平均漲幅爲 37%，稍低於一般多頭排列的平均水準 40%。向下突破的平均跌幅爲 20%，類似一般空頭排列的績效。向上與向下突破的最經常發生跌幅分別為 20%與 15%。

![](img/157738047fa61d5e4bdbaf89f0241a36_360_0.png)

圖 41.5 等腰三角形頭部排列向下突破的跌幅次數分配 最經常發生跌幅為 15%。

圖 41.5 是等腰三角形頭部排列向下突破的跌幅次數分配，顯示這種排列最可能發生的跌幅。我們發現，跌幅介於 10% 到 15%之間的案例最多，佔 25%；所以最經常發生跌幅為 15%。另外，大約有半數案例（46%）的跌幅小於 15%，77%的案例跌幅小於 25%。如果你打算針對等腰三角形頭部排列向下突破進行放空，績效恐怕沒有預期的高。

圖 41.6 顯示排列向上突破的漲幅分配情況，20%的欄位最高，最經常發生漲幅爲 20%。請注意，大約只有三分之一排列的漲幅低於 20%。所以，由比較樂觀的角度說，漲幅超過 20%的案例佔 65%。既然漲幅如此偏高，衡量法則的運作續效應該很不錯。確實如此，大約有 81%的排列完成目標價位。我認爲，這個比率只要超過 80%，就屬於可靠排列。向下突破的情況較差，目標價位達成率只有 62%。關於衡量法則的計算細節，請參考「交易戰術」一節。

![](img/157738047fa61d5e4bdbaf89f0241a36_362_0.png)

大部分突破點發生在排列時間寬度的 80%到 85%位置。

所謂排列時間寬度是指排列起點到三角形頂點的距離，我計算排列起點到突破點的距離，然後把後者表示為前者的百分率。關於所有案例的突破位置分配狀況，請參考圖 41.7。我們發現，許多排列的突破位置都落在排列時間寬度的 80%到 85%之間。最初，我認爲等腰三角形應該與上升或下降三角形一樣，突破發生在排列時間寬度的三分之二位置。可是，實際的資料顯示，等腰三角形的突破時間較遲。這讓態度積極的交易者，更有機會運用排列內的上下擺動來回操作：在排列下限買進或回補，在排列上限賣出或放空。

表 41.3 列示提前突破的相關統計數據。所謂「提前突破」，是指收盤價穿越到排列之外，但很快——通常是一天之內——又折返到排列之內。提前突破的情況不經常發生，不論向上或向下突破，發生的頻率都不超過 20%。

提前向上突破比較經常發生在真正的向下突破排列內。向下突破排列發生提前向上突破的頻率為 16%，向上突破排列發生提前向上突破的頻率只有 3%。提前向上突破發生在真正向上突破排列中，成交量低於平均水準；提前向上突破發生在真正向下突破排列中，成交量高於平均水準。對於向上突破排列，提前向上突破的成交量是 25 天移動平均量的 88%；對於向下突破排列，提前向上突破的成交量是 25 天移動平均量的 116%。向下突破排列發生提前向下突破的頻率只有 10%，向上突破排列發生提前向下突破的頻率則有 12%。關於提前向下突破成交量，情況與提前向上突破剛好相反，發生在真正向上突破的排列內，成交量大於平均水準（25 天移動平均量的 229%），發生在真正向下突破的排列內，成交量小於平均水準（25 天移動平均量的 66%）。如果真正突破方向朝下，大約有三分之一的案例同時發生向上與向下的提前突破。

相對於真正突破來說，提前突破發生的時間較早（提前突破位在排列時間寬度的 71%到 76%之間，向上與向下真正突破則分別位在 78%與 79%）。如果你發現某個突破的發生時間較正常狀況提早，而且成交量又偏低，最好放棄這個機會。

表 41.4 列示等腰三角形頭部排列的突破統計數據。排列突破之後，發生回挫與回升走勢的可能性大約為 58%與 59%。這方面的數據還沒有高到足以把回挫與回升走勢納入交易計畫中，但它們確實代表加碼的機會。回挫與回升走勢平均需要 13 天與 10 天才能回到排列邊緣或三角形頂點。

*> 譯按：不論真正突破方向如何，發生反向提前突破的可能性較高（這類的突破通常稱為「假突破」），發生相同方向提前突破的可能性較低；另外，反向提前突破的成交量較大，相同方向提前突破的成交量較小。事實上，前述現象似乎普遍存在於所有的排列內，不僅侷限於等腰三角形頭部排列。*

突破位置通常落在年度價格區間的哪裡呢？不論向上或向下突破，半數以上的排列突破點發生在年度價格區間三等份的上緣。這個結果或許不令人覺得意外，因為—根據定義—頭部排列是發生在一段價格漲勢之後，所以排列的發生位置偏高。突破點發生在年度價格區間三等份上緣、中央與下緣的排列，它們的績效各自如何呢？對於向上突破，突破點發生在上緣的排列績效最理想（平均漲幅為 40%），突破點發生在下緣的排列績效最差（平均漲幅 29%）。至於向下突破，三個區間的平均跌幅都在 20%左右，其中以突破點發生在下緣的排列績效最理想（平均跌幅為 23%）。這些統計數據顯示一個現象：強者恆強，弱者恆弱。如果你打算放空，最好挑選那些股價創新低者。如果股價創新高，走勢可能繼續上揚。

表 41.5 列示等腰三角形頭部排列的成交量相關統計數據。如果衡量排列內成交量時間序列的迴歸直線斜率，絕大部分排列（80%以上）的成交量都呈現下降趨勢。我們發現，排列發生突破之後的隨後一個星期內，成交量通常都高於正常水準。這意味著交易者在晚上得知排列發生突破，隨後幾天陸續進場操作。

小量突破是否比較容易發生回挫或回升走勢？這個問題需要分兩部分回答。首先，讓我界定小量與大量的意義：小量突破是指突破當天的成交量為 25 天移動平均量的 50%或以下，大量突破是指突破當天的成交量為 25 天移動平均量的 150%或以上。小量向上突破發生回挫走勢的比率只有 6%，大量向上突破發生回挫走勢的比率為 56%。另一方面，小量向下突破發生回升走勢的比率有 24%，大量向下突破發生回升走勢的比率為 20%。請注意，兩種情況的樣本都很小，這或許可以解釋它們的結論何以相互衝突。

大量突破是否能夠驅動較大的價格走勢？對於向上突破，大量突破的平均漲幅為 38%，小量突破為 35%。至於向下突破，大量與小量突破的績效很接近，平均跌幅分別為 21% 與 20%。唯有小量突破的結論具有統計上的顯著意義，大量突破的結論可能純屬巧合。

### 交易戰術

表 41.6 列示等腰三角形頭部排列的交易戰術。第一個戰術是估計價格走勢的程度。圖 41.8 說明如何運用衡量法則來估計等腰三角形頭部排列的目標價位。

整個三角形的最低價，是排列起點的 $18^{7}/8$（B 點），最高價是 $23^{1}/2$（A 點），所以三角形高度是 $4^{5}/8$ （$=23^{1}/2-18^{7}/8$）。對於向上突破，由最高價向上衡量排列高度，結果是 $28^{1}/2$ （$=23^{1}/2+4^{5}/8$）。對於向下突破，由最低價向下衡量排列高度，結果是 $14^{1}/4$ （$=18^{7}/8-4^{5}/8$）。這些價位屬於最低目標價位，通常都能夠完成，尤其是向上突破。

我們知道，等腰三角形通常都扮演既有中期趨勢的連續型態，反轉型態的發生頻率較低。所以，在操作上，通常應該預期排列將朝既有的中期趨勢方向突破。如果排列發生之前的中期價格趨勢朝上，通常都會向上突破，而且繼續上漲。

### 表 41.6 等腰三角形頭部排列的交易策略

| 交易策略 | 解釋 |
| :--- | :--- |
| 衡量法則 | 計算排列最高點與最低點之間的高度，由最高點向上衡量或由最低點向下衡量排列高度，結果就是向上突破或向下突破的最低目標價位。另外，等腰三角形也可能發生在一段走勢的中點，依此衡量目標價位。 |
| 順勢交易 | 等腰三角形屬於連續排列的可能性稍高，所以價格可能朝排列發生之前的中期趨勢方向進行突破。 |
| 等待突破 | 爲了防範等腰三角形反轉型態，務必等待實際的突破。 |
| 停損 | 向下突破的空頭部位，可以把停損設定在最高價上方 1/8 點處；向上突破的多頭部位，可以把停損設定在排列最低價下方 1/8 點處*。如此設定的停損如果太寬，可以考慮其他的支撐或壓力水準；一旦價格朝有利方向發展，應該調整停損點。 |
| 排列內交易 | 如果三角形的排列規模很大，可以考慮在排列下限買進或回補，在排列上限賣出或放空。可是，當排列發展而逐漸接近三角形頂點，就停止排列內的交易。 |

可是，等腰三角形頭部排列大約有三分之一的機會出現反轉型態，操作上或許還是應該等待實際突破。一旦收盤價突破到排列之外，順著突破方向建立部位（換言之，向上突破則買進，向下突破則放空）。

*> 譯按：如何設定停損，當然是見仁見智的問題。但是，對於等腰三角形，停損位置通常是以遠逃的趨勢線爲基準（換言之，向上突破的停損設定在排列下限的下方，向下突破的停損設定在排列上限的上方）。這通常已經是最寬鬆的停損（除非突破位置太接近三角形頂點，或三角形的高度太小）。*
