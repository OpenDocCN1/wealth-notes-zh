# 表 46.2 連續向下關鍵反轉的一般統計數據

| 說明 | 統計數據 |
| :--- | :--- |
| 排列數量：1991 年~1996 年的 200 支股票 | 412 個 |
| 反轉或整理排列 | 151 個整理，261 個反轉 |
| 失敗率 | 153/412 或 37% |
| 成功排列的平均跌幅 | 18% |
| 最經常發生跌幅 | 10% |
| 成功排列的目標價位達成率 | 189/259 或 73% |
| 成功排列到達最終低點的天數 | 3 個月（80 天） |
| 突破位置在最近 12 個月價格區間的下緣、中央或上緣 | 下緣 15%，中央 18%，上緣 67% |
| 前述突破位置的Average 跌幅 | 下緣 21%，中央 16%，上緣 17% |
| 相對於關鍵反轉當週，前一週與後一週的平均成交量 | 51%，80% |

列的數量很多，我只由 500 支股票內挑選 200 支股票，做爲尋找樣本的對象。大部分案例都扮演短期趨勢的反轉型態，很多連續型態屬於 5% 失敗案例。在我們觀察的案例當中，5% 失敗的情況大約佔 37%；換言之，向下關鍵反轉出現之後，價格沒有發生 5% 或以上的跟進跌勢，然後又顯著上漲。
