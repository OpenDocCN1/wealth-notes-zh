# 表 27.1 三波段衡量漲勢的辨識特質


| 特質 | 討論 |
| :----- | :----- |
| 下降趨勢 | 排列發生之前，經常出現幾個星期或長達一年以上的價格下降趨勢。在這種情況下，三波段衡量漲勢代表趨勢開始向上反轉的排列，通常發生在年度低價附近。 |
| 第一隻腳 | 進入修正階段之前，價格通常沿著上升趨勢通道發展。 |
| 修正階段 | 價格下跌，幅度通常是第一隻腳長度的 35%到 65%之間。修正階段的價格折返程度，通常與第一隻腳長度之間保持正向比例關係：第一隻腳的漲幅愈大，向下修正的幅度也愈大。某些情況下，修正階段可能出現鋸齒狀的排列（換言之，一系列的急漲急跌走勢），持續一段期間才向上突破。如果排列發生之前曾經出現延伸性的漲勢，修正階段比較可能發生鋸齒狀型態。 |
| 第二隻腳 | 第二隻腳的傾斜角度通常類似第一隻腳（換言之，兩隻腳的趨勢線斜率大約相同）。兩隻腳走勢通常都落在明確的趨勢通道內，但這並不是必要條件。 |
| 避免情況 | 如果價格在修正階段向下折返太深，超過第一隻腳長度的 80%，最好避免介入。 |


降趨勢包括任何規模的跌勢而言。以稍早的圖 27.1 為例，先前的多頭走勢起源於 1991 年 12 月，但只持續 2 個月，隨後幾個月的期間內，基本上維持橫向而稍微下滑的走勢，價格由$18¼的高價逐漸下跌到 1992 年 11 月份的低價$14¾。
