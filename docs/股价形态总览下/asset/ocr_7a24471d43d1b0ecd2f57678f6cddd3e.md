# **Whirlpool Corp.（家庭電器，NYSE，代碼 WHR）**

![](bbox=[0.07, 0.18, 0.81, 0.49])

象意味著排列績效通常較佳。這個三重底排列是一波重大漲勢的起點，起漲價位在$34½，16 個月之後的高價為$73½。

在三重底排列之內，成交量通常呈現下降趨勢，最大成交量經常發現在第一個谷底位置。第二個谷底的成交量趨於下降，第三個谷底更明顯萎縮（請參考圖 42.2）。11 月中旬，盤中價格一度向上突破確認水準，當天的成交量顯著放大。隨後幾天之內，價格盤旋在確認水準下緣，最後才夾著大量跳空穿越$40%的壓力。經過兩天的急漲之後，價格出現擴張頂排列。
