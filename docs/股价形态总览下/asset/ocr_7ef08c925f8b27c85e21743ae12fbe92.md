表 28.1 單日反轉排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 價格趨勢 | 頭部排列通常發生在幾個星期或幾個月的價格上升趨勢末端；底部排列通常發生在幾個星期或幾個月的價格下降趨勢末端。 |
| 突兀長線形 | 不論頭部或底部排列，當天應該出現突兀長線形。單日反轉突兀線形的長度至少應該是最近一年內突兀線形平均長度兩倍。 |
| 極端價位收盤 | 頭部排列在盤中低價附近收盤，底部排列在盤中高價附近收盤。所謂「附近」是指當天價格區間三等份的上線或下線。 |
| 成交量 | 單日反轉當天通常會爆出大量。 |

果回顧稍早的走勢，可以發現 1992 年 11 月起源的上升趨勢在 1993 年 8 月份做頭。經過一段橫向整理之後，出現為期兩週的跌勢，然後發生單日反轉。

前述兩個例子中，單日反轉都呈現非常突兀的線形。當天的線形長度遠超過稍早的線形。如果由左往右觀察股價的發展，單日反轉線形似乎突然由走勢中躍出，顯得非常突兀。

另一個型態辨識重點，是當天的收盤價位置。對於頭部排列，當天收盤價應該落在盤中低價附近。底部排列的情況剛好相反，當天收盤價應該落在盤中高價附近。收盤方向已經顯示稍後的股價發展方向：頭部排列之後，股價將向下發展；底部排列之後，股價將向上發展。隔天的線形雖然可能與單日反轉
