# 表 31.1 長管頂排列的辨識特質

| 特質 | 討論 |
| --- | --- |
| 週線圖的向上突兀長線形 | 在週線圖上，尋找兩支連續的向上突兀長線形。兩支向上突兀線形的長度，必須顯著超過最近一年內的其他向上突兀線形，而且整個排列明顯向上凸出。 |
| 價格重疊部分很多 | 長管狀排列的兩支線形必須大部分重疊。兩支線形的長度必須大致相同。 |
| 兩支線形的高價相差不大 | 兩支線形的高價相差不大，通常在 3/8 點之內，但高價股可能出現$1 的價差。 |
| 下降趨勢的向上折返 | 績效表現最佳的排列，經常發生在延伸性下降趨勢的向上折返末端。 |

深入觀察之後，你將發現大部分的長管頂排列都發生在下降趨勢的向上折返走勢末端，類似圖 31.2 的情況。股價走勢在 3 月中旬創$39^7/8 的峰位，經過大約 1 個月的回檔，價格又開始回升，但沒有多久就在 6 月份出現第二個峰位。股價在一天之內由$35^1/2 下跌到$29，然後又繼續下跌 4 天才反彈。這波向上折返走勢由低點$26^1/4 反彈到高點$30^7/8，也是長管頂排列發生的位置。

排列兩支線形的高點只有 .1/8 點的差異，較週遭其他線形顯著凸出。相對於最近.1 年內的其他向上突兀線形，這兩支線形的長度非常凸顯（除了 3 月中旬的峰位為例外）。由於兩支線形的低價相同，所以價格區間幾乎完全重疊。
