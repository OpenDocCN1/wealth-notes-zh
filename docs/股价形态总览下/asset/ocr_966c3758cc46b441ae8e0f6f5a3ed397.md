向上突破之後，價格到達最終高點的平均期間爲 192 天。反之，向下突破之後，價格到達最終低點的平均期間爲 66 天。請注意，兩者都是由突破當天起算。

如果把年度價格區間劃分爲三等份（上緣、中央與下緣），排列突破點通常都落在哪個位置？大多數向上突破都落在年度高價附近（64%）。向下突破在這三個位置的分配比較平均，上緣與中央各有 35%。至於這些突破位置的排列績效又各自如何呢？落在年度價格區間中央的向上突破，績效最理想，平均漲幅爲 41%。至於向下突破，績效最理想的排列落在年度高價附近，平均跌幅爲 23%。

最後一項統計數據是關於對稱性的問題。沿著水平軸而上下對稱的鰱鱸排列，它們的績效比較理想。我們藉由下列公式衡量對稱性：

+   對稱參數=0.10~0.50 這是決定排列所需要對稱程度的變數。

頂點價位=(H₃+L₃)/2 H₃與 L₃是分別代表排列第 3 天的高價與低價。

底部高度=H₁-L₁ H₁與 L₁是分別代表排列第 1 天的高價與低價。

對於指定對稱程度的鰱鱸排列，必須滿足下列方程式：

```
頂點價位≤H₁-(底部高度×對稱參數)
頂點價位≥L₁+(底部高度×對稱參數)
```
