# # 交易戰術

表 32.5 列示矩形底部排列的相關交易戰術。首先運用衡量法則預測排列突破之後的目標價位。這是計算矩形排列內最高價與最低價之間的差值，以此代表矩形高度，然後由突破點向上或向下衡量矩形高度，結果就是向上突破或向下突破之後的最低目標價位。讓我們利用圖 32.6 做為說明範例。矩形排列的上限為$12^{7/16}$，下限為$11，矩形高度為 $17/16$ 點（= $12^{7/16} - 11$），

| 表 32.5 | 矩形底部排列的交易戰術 |
| --- | --- |
| 交易戰術 | 解釋 |
| 衡量法則 | 計算矩形排列上限與下限之間的高度，由突破點向上或向下衡量矩形高度，結果就是向上突破或向下突破的最低目標價位。 |
| 等待突破 | 由於矩形底部排列沒有預期突破方向，所以應該等待收盤價實際突破矩形排列的上限或下限，然後才按照突破方向順勢操作。 |
| 來回操作 | 如果矩形的高度夠高，可以考慮在排列下限買進或回補，在排列上限賣出或放空，如此來回操作。 |
| 回挫與回升走勢 | 對於向下突破，等待回升走勢結束而價格重新下跌，放空股票或加碼空頭部位。同理，對於向上突破，等待回挫走勢結束而價格重新上漲，買進股票或加碼多頭部位。 |
| 其他 | 留意矩形排列發生在三階段衡量走勢的修正階段，若是如此，按照情況調整目標價位。橫向打底過程中，經常發生矩形反轉排列。 |
