# Modine Manufacturing（汽車零件，NASDAQ，代碼 MODI）

![](bbox=[0.08, 0.18, 0.81, 0.49])

圖 41.8 等腰三角形頭部排列。緊跟著發生上升扇貝形排列，最後又出現頭肩頂排列。首先計算排列高點（A 點）與低點（B 點）之間的高度。對於向上突破，由排列高點（A 點）向上衡量排列高度；對於向下突破，由排列低點（B 點）向下衡量排列高度。結果就是突破之後的最低目標價位。

多頭部位的停損設定在排列最低價下方 1/8 點處，空頭部位的停損設定在排列最高價上方 1/8 點處。對於圖 41.8 來說，進場買進之後，停損設定在$18^{3/4}$（換言之，B 點的下方 1/8 點處）。價格突破之後，回挫或回升走勢通常會停頓在排列近邊的趋势線或三角形頂點的水平位置。換言之，如果走勢足夠強勁，價格通常不會重新折返進入排列之內。萬一價格穿越遠邊的趋势線，甚至穿越排列最高價或最低價，就應該停損出場。
