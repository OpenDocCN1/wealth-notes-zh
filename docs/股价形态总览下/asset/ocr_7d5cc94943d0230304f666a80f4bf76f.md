# 表 45.4 上升楔形排列的突破統計數據

| 說明 | 統計數據 |
| :--- | :--- |
| 向下突破落在排列寬度的位置 | 61% |
| 向上突破排列數量 | 32/179 或 18% |
| 向下突破排列數量 | 147/179 或 82% |
| 向下突破而失敗的排列數量 | 11/179 或 6% |
| 發生回升走勢的排列數量 | 78/147 或 53% |
| 完成回升走勢的平均期間 | 10 天 |
| 成功排列由突破到達<br>最終低點的期間 | 2.5 個月（78 天） |
| 突破位置在最近 12 個月<br>價格區間的下緣、中央或上緣 | 下緣 15%<br>中央 18%<br>上緣 68% |
| 前進突破位置的平均跌幅 | 下緣 21%<br>中央 17%<br>上緣 19% |

表 45.4 顯示突破的統計數據。上升楔形排列的向下突破點平均落在排列寬度的 61% 位置。所謂「排列寬度」是由排列起點到楔形頂點之間的距離，楔形頂點是排列上限與下限向右收斂的交會點。如果我們繪製前述排列突破位置與排列跌幅之間的相關散佈圖，結果找不到明確的結論。雖然下降楔形排列最強勁的突破點落在排列寬度的 50% 到 80% 之間（這個區間的中心點為 65%，請參考第 920 頁），但上升楔形排列的突破點位置與排列績效之間似乎只存在隨機關係。
