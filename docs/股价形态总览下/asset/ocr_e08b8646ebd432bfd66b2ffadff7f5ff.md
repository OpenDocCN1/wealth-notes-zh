# Magne Tek, Inc.(墊子設備，NYSE，代碼 MAG)

![](bbox=[0.21, 0.195, 0.92, 0.5])

圖 39.7 下降三角形排列，緊跟著出現三波段衡量漲勢。小陳沒有針對這個排列放空股票，反而利用衡量法則在下檔目標價位附近買進。隨著股價上漲，他持續向上調整停止賣單的價位。結果，他在$23被停止出場，獲利為$2,000。三波段衡量漲勢使得小陳很容易估計上檔目標價位。

形上限的外緣，如此就能夠偃限損失，防範價格向上發展。可是，他還是不願意，反而希望在低價買進股票，所以我建議他依據衡量法則的估計，嘗試在下檔目標價位附近買進。

計算三角形的高度，然後由排列下限向下衡量最低目標價位，結果大約在$12½附近。不久，排列向下突破，而且繼續朝下發展。當價格觸及目標價位，而且隨後稍微反彈，他猜想這已經是低價了——至少他認爲如此。
