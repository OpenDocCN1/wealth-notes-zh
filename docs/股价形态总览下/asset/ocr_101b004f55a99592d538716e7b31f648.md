# # 交易戰術

表 45.5 列示上升楔形排列的交易戰術。上升楔形排列的衡量法則剛好與下降楔形相反。一旦排列向下突破之後，價格至少應該下跌到排列最低價。雖然下檔目標價位代表的跌幅很有限，但目標價位達成率仍然只有 63%。我認爲可靠排列的目標價位達成率至少應該超過 80%，所以上升楔形排列的這方面績效很差。

圖 45.6 說明衡量法則的計算方法。目前這個上升楔形排列非常標準，符合表 45.1 的所有辨識準則。如果投資人針對排列向下突破建立空頭部位，可以透過衡量法則估計下檔目標價位。就目前的例子來說，目標價位是排列的最低價$29\%$。排列向下突破之後，一個星期內就完成目標價位。

表 45.5 上升楔形排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 價格向下突破之後，至少應該到達排列最低點。 |
| 突破之後賣出 | 爲了提升獲利機會，最好等待價格實際向下突破（收盤價穿越到排列下限之外）。 |
| 回升之後賣出 | 如果你錯失突破當時的賣出訊號，可以考慮在回升走勢完成而價格又開始下跌的時候放空。 |
| 迅速獲利了結 | 由於跌幅有限，隨時準備獲利了結。 |
