超過 20%）。所以，你真的想要操作這種排列嗎？

如果答案是肯定的，最好只挑選向上突破的排列。請記住，如果外側日當天收盤價落在最高價的 25%以內，隨後大約有三分之二的機會向上突破（此處沒有顯示失敗率的資料，所以務必謹慎）。如果外側日本身的線形長度很短（例如：小於 0.5 點），向上突破的漲幅也比較理想。除此之外，請參考「交易範例」。

# ## 交易範例

許博士是一位成功的醫生。當他沒有看診的時候，很喜歡嘗試一些投資技巧。關於外側日排列，他設定五項必要條件，唯有股價型態完全滿足這五個條件，許博士才會進場操作。

+   1.  排列必須向上突破。主要是因爲向上突破的平均績效優於向下突破（分別為 32%與 17%）。

+   2.  排列必須發生在年度低價附近。如果把最近 12 個月的價格區間劃分為上緣、中央與下緣三等份，突破點發生在下緣的排列平均績效優於其他兩個等份（下緣為 49%，上緣與中央分別為 32%）。

+   3.  外側日當天的成交量必須是平均量的 150%。外側日出現大量的平均漲幅為 37%，小量外側日的平均漲幅為 29%。
