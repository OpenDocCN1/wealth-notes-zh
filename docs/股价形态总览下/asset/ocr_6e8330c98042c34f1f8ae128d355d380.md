後 5 天的成交量仍然偏高，但有逐漸縮小的趨勢。按照這些數據推論，價格一旦向下突破，買壓轉強，造成價格進一步下跌。

# 交易戰術

表 43.4 列示三重頂排列的交易戰術，首先討論衡量法則。我們可以運用衡量法則，協助估計價格向下突破之後的目標價位。排列高度是以排列最高價減去最低價，然後由突破點（確認點）向下衡量排列高度，結果就是最低目標價位。不幸地，在三重頂排列的全部案例當中，達成都市目標價位的比率只有 47%；換言之，大部分排列向下突破之後，價格都不能到達目標價位。

表 43.4 三重頂排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 計算排列最高點與最低點之間的高度，由最低點向下衡量排列高度，結果就是向下突破的最低目標價位。 |
| 等待確認 | 大多數潛在三重頂排列都不能演變爲有效的三重頂，所以必須等待價格向下穿越三個峰位所夾兩個谷底的最低價（確認水準）。一旦向下突破之後，價格通常會繼續下跌。 |
| 等待回升 | 大多數三重頂排列會發生回升走勢，可以考慮在回升走勢完成之後才進場投資或加碼。 |
| 停損 | 空頭部位的停損可以設定在排列最高點上方 1/8 點處。 |
