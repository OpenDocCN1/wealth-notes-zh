# 向下突破

外觀 價格趨勢朝下發展，進入排列之後，價格波動於兩條水平趨勢線之間，最後向下突破。

反轉或整理 短期（3 個月以內）的空頭連續型態。

失敗率 4%。

平均跌幅 19%，最經常發生跌幅大約是 10%~15%。

成交量趨勢 下降。

提前突破 17%。

回升 70%。

目標價格 達成率 65%。

意外發現 提前突破與實際突破之間方向相反的案例佔 75%。

參照排列 （33）矩形頂部排列。

如同其他缺乏頭部或底部傳統定義的排列一樣，我按照價格型態發生之前的趨勢方向，界定矩形排列（rectangles）屬於頭部或底部型態。如果先前的價格趨勢朝下，矩形排列定義為底部；先前的價格趨勢朝上，矩形排列定義為頭部。這種劃分方法雖然涉及主觀認定的問題，但有助於決定或判斷隨後突破方向。
