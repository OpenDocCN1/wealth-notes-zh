表 24.1 內側日排列的辨識特質
| 特質 | 討論 |
| :--- | :--- |
| 較高的盤中高價 | 外側日當天的盤中高價高於前一天高價。不允許兩者相等的情況。 |
| 較低的盤中低價 | 外側日當天的盤中低價低於前一天低價。不允許兩者相等的情況。 |
| 價格區間 | 外側日前一天的線形必須存在價格區間。換言之，外側日前一天的盤中高價與盤中低價不得相等。（譯按：外側日前一天的線形不得為「十字線」。） |
