# 交易範例

老周的脾氣非常暴躁。任何人只要招惹他，就沒有好日子過，
甚至會牽連週遭的人。辦公室裡的同事都不願與他打交道，但
管理階層對他頗有好感，因爲他擁有工程碩士學位，在專業領
域內似乎頗有見地。

非常不幸地，我所設計的一套印刷指令軟體發生問題，
必須與老周協調。稍微觀察一下資料，進行幾項測試之後，發
現問題不是出在我的軟體之上。於是，那一年的國慶日提早放
煙火。我真的被老周整慘了，只有默默走開。

三十年風水輪流轉，當老周需要我幫忙的時候，態度顯得
非常謙虛。他剛開始從事交易，對於週線向上關鍵反轉似乎頗
有興趣。他投資圖 47.5 的股票。這個關鍵反轉完全符合他對於
該型態設定的條件，於是進場買進股票，成交價格爲$20\frac{1}{2}$。進
場之後，股價立即上漲，一切看起來都很順利。隨著時間經過，
股價呈現階梯狀的走勢，上漲兩週，然後下跌一週。

沿著成交量柱狀圖上緣繪製一條直線，結果顯示上升趨
勢。成交量呈現「價漲量增，價跌量縮」的現象，老周不知道
這種型態是否具有重要意義。對於他來說，這似乎意味著動能
增加，協助推升股價走高。
