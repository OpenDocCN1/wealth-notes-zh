表 24.1 內側日排列的辨識特質  
| 特質 | 討論 |
| --- | --- |
| 較低的盤中高價 | 內側日當天的盤中高價低於前一天高價，不允許兩者相等的情況。 |
| 較高的盤中低價 | 內側日當天的盤中低價高於前一天低價，不允許兩者相等的情況。 |
| 價格區間 | 內側日當天不能只有單一價位；換言之，內側日當天的價格區間不能是一點。 |
