表 44.2 下降楔形排列的一般統計數據
| 說明 | 統計數據 |
| :--- | :--- |
| 排列數量： 1991 年~1996 年的 500 支股票 | 92 個 |
| 排列數量： 1996 年~1998 年的 297 支股票 | 33 個 |
| 反轉或整理排列 | 77 個整理，48 個反轉 |
| 失敗率 | 12/125 或 10% |
| 等待向上突破之後的失敗率 | 2/115 或 2% |
| 成功排列的平均漲幅 | 43% |
| 最經常發生漲幅 | 20%~30% |
| 成功排列的目標價位達成率 | 101/115 或 88% |
| 排列平均長度 | 1.5 個月（44 天） |

我把 20% 與 30% 視爲最可能發生的漲幅。另外，透過這份圖形，我們發現 90% 以上的離群漲幅發生頻率頗高，使得平均漲幅向上推升爲 43%。

關於目標價位的衡量法則，細節內容請參考稍後的「交易戰術」一節。可是，此處準備討論目標價位的達成率。由於衡量法則估計的目標價位距離排列突破點並不遠，所以很容易達成。只要成功向上突破，大部分排列（88%）都能夠完成目標價位（換言之，向上觸及或穿越排列的最高價）。

完成下降楔形排列的平均期間爲 44 天；實際天數介於 20 天到 125 天之間（3 星期到 4 個月之間）。
