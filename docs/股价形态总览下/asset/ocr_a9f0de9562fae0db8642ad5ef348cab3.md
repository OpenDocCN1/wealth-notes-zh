波段挺進到$13 與$16，然後才回檔到$11 附近，重新測試圓形底杯口的支撐。

圓形底排列通常附帶「柄部」（柄部是直接銜接杯口右緣的價格整理走勢），但不屬於型態的必要條件。當價格沿著圓形底部發展，逐漸上漲到杯口左緣的先前高點附近，在此遭受壓力之後，通常會回檔整理，然後再嘗試向上突破。這類回檔整理的走勢，就是所謂的「柄部」。在柄部走勢中，價格可能必須經過數度嘗試，才能克服上檔杯口左緣與右線的壓力，甚至因為不能消化賣壓而跌破先前的圓形底。

排列內的成交量型態通常對應價格型態，也是呈現開口向上的圓弧狀結構。請參考圖 34.2，雖然這個例子並不特別明顯。

# 失敗案例

老實說，圓形底排列之所以失敗，大部分都是因爲定義的問題。實務研究上，我發現大多數圓形底都屬於既有價格趨勢的連續排列。換言之，價格經過一段漲勢之後，出現開口向上的圓弧狀回檔走勢，然後又恢復先前的上升趨勢。凡是不符合前述格式的圓形底排列，一律歸納爲失敗案例。圖 34.3 提供一個這類的失敗案例；此處的圓形底排列屬於既有價格趨勢的反轉型態。圓形底發生在價格下降趨勢的末端，排列完成之後，價格向上反轉而展開新的上升趨勢。
