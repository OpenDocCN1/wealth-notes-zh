# 向上突破

外觀 排列之前的價格趨勢朝下，排列內轉折高點不斷下滑，轉折低點不斷墊高；排列上限向下傾斜，排列下限向上傾斜，兩條趨勢線向右收斂。向上突破。

反轉或整理 短期（3 個月以內）的多頭反轉走勢。

失敗率 3%。

平均漲幅 41%，最經常發生漲幅為 20%。

成交量趨勢 下降。

提前突破 16%。

回升 43%。

目標價位達成率 79%。

意外發現 大量突破的漲幅較大。大量突破比較可能出現回挫走勢。

其他名稱 螺旋。

+   參照排列
* （11）菱形排列，（18）頭肩底排列，
* （37）鰭背排列，（38）上升三角形排列，
* （39）下降三角形排列，（41）等腰三角形頭部排列。

我把等腰三角形（symmetrical triangles）劃分為兩大類：排列發生之前，價格呈現下降或上升趨勢。兩種類別的操作方式不盡相同，所以我分別整理最有用的統計數據供讀者參考。本章準備處理等腰三角形底部排列，它們發生在價格下降趨勢之後。

向下與向上突破的失敗率分別為 2% 與 3%。一旦突破發生之後，價格通常都繼續朝突破方向發展，很少發生 5% 失敗的情況（換言之，突破之後的跟進走勢不足），突破之後的平均績效大約類似於一般空頭與多頭排列。向下突破的平均跌幅為 19%，向上突破的平均漲幅為 41%。
