# 表 44.4 下降楔形排列的突破統計數據

| 說明 | 統計數據 |
| --- | --- |
| 向上突破落在排列寬度的位置 | 65% |
| 向上突破排列數量 | 115/125 或 92% |
| 向下突破排列數量 | 10/125 或 8% |
| 向上突破而失敗的排列數量 | 2/125 或 2% |
| 發生回挫走勢的排列數量 | 54/115 或 47% |
| 完成回挫走勢的平均期間 | 12 天 |
| 成功排列由突破到達最終高點的時間 | 7 個月（206 天） |
| 突破位置在最近 12 個月價格區間的下緣、中央或上緣 | 下緣 44%，中央 32%，上緣 23% |
| 前述突破位置的平均漲幅 | 下緣 47%，中央 42%，上緣 36% |

位置的相關散佈圖（correlation scatter chart），我們發現最強勁的突破點落在排列寬度的 50% 到 80% 之間。這個區間的中心點 65% 剛好是突破點落在排列寬度的平均位置。

在全部 125 個案例當中，向上突破的排列有 115 個（佔 92%），其他爲向下突破（佔 8%）。5% 失敗的案例只有 2 個；換言之，價格向上突破之後，沒有出現 5% 或以上的跟進漲勢。

向上突破之後，只有 47% 的排列發生回挫走勢。發生頻
