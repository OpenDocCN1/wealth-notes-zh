關鍵反轉當週的線形完全吞噬前一週線形，而且收盤價位在最高價附近，這意味著價格將走高。一般來說，情況確實如此，而且價格上漲的程度往往很可觀。

圖 47.1 的兩個關鍵反轉都沒有出現顯著的大量或小量；成交股數大約是中等水準。這不屬於異常現象，因爲大多數績效理想的向上關鍵反轉，成交量都保持平均或偏低的水準。

# 辨識準則

表 47.1 列示週線向上關鍵反轉的辨識準則。首先，在週線圖的價格下降趨勢內尋找向上關鍵反轉。關鍵反轉當週的高價必須高於前一週高價，低價必須低於前一週低價，收盤價必須高

表 47.1 週線向上關鍵反轉的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 週線圖 | 採用週線圖觀察單週的關鍵反轉。 |
| 價格下降趨勢 | 價格必須處在下降趨勢過程或末端。如果當時的價格趨勢明顯向上，不必考慮向上的關鍵反轉，除非是發生在上升趨勢的向下修正過程。 |
| 較高的高價與較低的低價 | 相對於前一支線形，高價必須較高，低價也必須較低。不允許兩支線形具有相同的高價或低價。 |
| 較高的收盤價 | 關鍵反轉的收盤價必須高於前一支線形高價。 |
