# 表 38.6 上升三角形排列的交易戰術

| 交易戰術 | 解釋 |
|---|---|
| 衡量法則 | 在三角形排列的起點，計算型態的高度。由水平上限向上衡量型態高度，結果就是最低目標價位。 |
| 等待確認 | 向上突破之後（收盤價超越排列上限至少 1/8 點），隔天買進股票。如果錯失突破買進訊號，等待價格回挫到排列上限附近，一旦價格重新朝上發展，立即進場買進。 |
| 按照目標價位賣出 | 對於短線交易者，當價格接近上檔目標價位（參閱衡量準則）或向下貫穿支撐，賣出股票。對於中、長期的投資人，繼續持有股票，直到基本面或市況發生變化為止。 |
| 向下突破的賣出訊號 | 如果你持有股票，一旦價格超越排列下限，立即賣出。對於空手者，可以把向下突破視為放空訊號。回升走勢代表加碼或進場放空的第二次機會。 |
| 放空 | 如果你所放空的股票出現上升三角形排列，價格向下突破的機會大約只有三分之一。如果價格向上突破，立即回補空頭部位。 |

附註：收盤價實際超越排列上限，代表買進訊號。價格到達目標區域，考慮賣出。

稱爲衡量法則。
