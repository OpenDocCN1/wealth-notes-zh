# ## 交易戰術

表 31.4 列舉長管頂排列的交易戰術。排列的續效取決於既有的趨勢。如果你希望尋找跌幅較大的長管頂排列，就應該鎖定下降趨勢。在長期下降趨勢中，長管頂排列經常顯現為向上折返的整理走勢（換言之，這類長管頂排列是長期下降趨勢的連續型態）。對於這類操作對象，你應該尋找剛開始的下降趨勢。由另一個角度說，你應該避開下降趨勢末端的長管頂排列。至於如何判斷某個趨勢是否即將結束，其中的藝術成份當然很大。可是，如果股價跌勢已經延續幾個月或一年以上，或許就不應該接受長管頂的放空機會。

表 31.4  長管頂排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 下降趨勢 | 續效表現最佳的長管頂排列，大多發生在價格下降趨勢末端；價格向上反彈，形成長管頂排列，然後繼續下跌。 |
| 小心趨勢結束 | 如果長管頂排列發生在長期下降趨勢中，不宜視為空頭訊號，該排列可能預示下降趨勢的結束。 |
| 長期上升趨勢 | 留意長期上升趨勢的狀況。如果長管頂排列發生在長達 1 年或以上的上升趨勢中，可能代表趨勢向下反轉的訊號。然而，這可能是領先訊號，領先期間可能長達 2~5 個月。 |
| 上升趨勢的折返走勢 | 長管頂排列發生在上升趨勢中，可能代表短期回檔整理的訊號。這類空頭訊號只適合短期操作。 |
