# 表 26.1 三波段衡重跌勢的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 第一隻腳 | 通常起始於價格新高點。價格趨勢由此向下反轉，經常呈現快速而筆直的跌勢。如果這波段跌勢呈現由線狀（圓形、弧狀或碟形），儘量避免介入。 |
| 修正階段 | 價格可能進行橫向盤整，但通常會向上折返，折返的幅度可能是第一隻腳長度的 40%到 60%之間。修正結束後，將恢復下降趨勢。如果向上修正走勢攀升到第一隻腳的高點附近，儘量避免介入。 |
| 第二隻腳 | 第二隻腳的傾斜角度通常類似第一隻腳（換言之，兩隻腳的趨勢線斜率大約相同）。兩隻腳走勢通常都落在明確的趨勢通道內。 |
| 避免情況 | 對於一系列三波段跌勢構成的下降趨勢，設法操作第一段走勢，避免介入隨後發生的三波段跌勢，因為下降趨勢終有結束的一天。如果三波段走勢發生在橫向盤整行情中，呈現水平的鋸齒狀排列，避免介入這類的案例。如果衡量法則預測的目標價格為零或負數，應該另外尋找操作對象。 |
