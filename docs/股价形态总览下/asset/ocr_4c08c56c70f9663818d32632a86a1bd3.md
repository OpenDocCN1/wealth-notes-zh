# ### 緣起與辨識準則

表 24.1 列出內側日的辨識準則，圖 24.1 提供很多內側日的範例。顯而易見，所謂「內側日」是指當天線形完全處在前一天線形的內側（當天線形完全被前一天線形吞噬）。某些分析師允許內側日的盤中高價等於前一天的高價，或盤中低價等於前一天的低價；我個人不允許這些情況發生。除此之外，我還規定內側日當天不允許只發生單一價位；換言之，盤中高價與盤中低價不得相等。除非是交投非常冷清的股票，否則這個條件不會構成真正的影響。可是，即使採用表 24.1 的相對嚴格定義，資料庫內的許多個股还是有 100 個以上的案例。所以，在「統計數據」一節中，我說明如何把樣本數量減少到方便處理的程度。
