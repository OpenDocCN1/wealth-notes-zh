# 表33.5 矩形頭部排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 計算矩形排列上限與下限之間的高度，由突破點向上或向下衡量矩形高度，結果就是向上突破或向下突破的最低目標價位。 |
| 連續型態 | 超過三分之二的矩形頭部排列屬於連續型態。排列很可能朝既有趨勢方向突破。 |
| 等待突破 | 由於矩形頭部排列沒有預期突破方向，所以應該等待收盤價實際突破矩形排列的上限或下限，然後才按照突破方向順勢操作。 |
| 來回操作 | 如果矩形的高度夠高，可以考慮在排列下限買進或回補，在排列上限賣出或放空，如此來回操作。 |
| 其他 | 留意矩形排列發生在三階段衡量漲勢的修正階段，若是如此，按照情況調整目標價位。盤頭過程中，經常發生矩形反轉排列。 |

下衡量矩形高度，結果就是向上突破或向下突破之後的最低目標價位。

讓我們利用圖33.6做為說明範例。矩形排列的上限為$38%，下限為$33%，所以排列高度為5點。如果這個排列向下突破，下檔目標價位為$28%，相當於排列下限$33%減去$5。可是，實際的突破方向朝上，所以把排列上限$38%加上排列高度$5，上檔目標價位為$43%。向上突破之後，走勢大約在1個月之後完成目標價位。
