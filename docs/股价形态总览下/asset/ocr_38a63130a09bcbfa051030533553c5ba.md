# 統計數據

表 32.2 列示矩形底部排列的一般統計數據。進入矩形底部排列之前的價格趨勢必須朝下，唯有突破方向不確定。我按照兩種突破方向把統計數據劃分為兩類：向上突破與向下突破。

在全部 95 個案例中，連續型態的數量稍多於反轉型態，分別為 54 個與 41 個。所以，對於任意的矩形底部排列，按照排列發生之前的下降趨勢，推估矩形隨後將向下突破，勝算雖然稍微大些，但結果與純粹的猜測沒有多大的差別。
