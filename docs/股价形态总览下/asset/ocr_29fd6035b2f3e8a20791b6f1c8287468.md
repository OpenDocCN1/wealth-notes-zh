# Circus Circus Enterprises, Inc. (飯店／賭博，NYSE，代碼 CIR)

![](bbox=[0.19, 0.21, 0.91, 0.51])

圖 28.3 頭部單日反轉的 5% 失敗案例。價格跌到下檔支撐之後才反彈。

在價格下降趨勢中，出現一支向下的突兀長線形。當天的成交量很大，價格收在盤中高價附近。這個單日反轉排列預示價格將走高；事實上，隨後兩個月的趨勢也確實向上發展。由單日反轉當天高價，衡量到波段漲勢最高點（A 點），漲幅不足 4%，所以也屬於 5% 失敗的案例。

這兩個案例為什麼會失敗？因爲隨後的走勢都遇到難以克服的支撐或壓力。請回頭參考圖 28.3，$35½存在顯著的支撐；圖 28.4 的壓力則在 $43~$44 之間。這兩個排列完成之後的走勢，都因爲遭逢阻力而失敗。教訓？對於任何股價型態，都應該評估排列完成之後的可能目標價位，以及上檔壓力或下檔支撐。
