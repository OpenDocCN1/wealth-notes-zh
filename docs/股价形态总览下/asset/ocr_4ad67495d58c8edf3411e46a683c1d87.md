表 39.1 下降三角形排列的辨識特質

| 特質 | 討論 |
|---|---|
| 三角形結構 | 價格在排列內來回穿梭，轉折高點銜接成爲向下傾斜的排列上限，轉折低點銜接成爲水平狀的排列下限；排列上限與下限向右收斂，呈現爲三角形。 |
| 水平狀底部支撐 | 下檔價格支撐爲水平狀或接近水平狀。回撤走勢至少必須兩度觸及這條水平下限（換言之，至少需要兩個轉折低點觸及或接近水平下限）。 |
| 向下傾斜的上限 | 排列內價格走勢的轉折高點持續下滑，使得排列上限朝右下方傾斜，與排列下限交錯爲三角形頂點。價格漲勢至少必須兩度觸及或接近排列上限（換言之，至少需要兩個顯著的轉折高點）。 |
| 成交量 | 排列內的成交量型態應該處於下降。突破前的成交量通常很小。 |
| 提前突破 | 不經常出現，但總是夾著大量，所以不容易區分假突破與真突破。 |
| 向下突破 | 通常會夾著大量突破，然後成交量逐漸縮小。請注意，小量突破的情況也經常發生。 |
| 突破後的價格行爲 | 價格通常會快速下跌，直接到達最終低點。大約有三分之二的案例發生回升走勢。 |

都呈現成交量萎縮的趨勢。雖然排列末端的成交量小於初期，但趨勢不是持續減少，反而像是開口向上的弧形狀。
