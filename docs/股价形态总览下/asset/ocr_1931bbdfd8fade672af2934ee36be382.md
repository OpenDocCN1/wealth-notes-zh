# 表 38.4 上升三角形排列的突破統計數據

| 說明 | 統計數據 |
| :--- | :--- |
| 向上突破發生在排列寬度的位置 | 63% |
| 向下突破發生在排列寬度的位置 | 68% |
| 向下突破而成功的案例 | 33/725 或 5% |
| 向上突破案例 | 450/725 或 62% |
| 向下突破案例 | 238/725 或 33% |
| 水平突破案例 | 37/725 或 5% |
| 發生回挫走勢案例 | 262/450 或 58% |
| 發生回升走勢案例 | 117/238 或 49% |
| 完成回挫走勢的平均期間 | 15 天 |
| 完成回升走勢的平均期間 | 13 天 |
| 成功排列到達最終高點的天數 | 6 個月（186 天） |

附註：如果排列向上突破，通常都會繼續上漲。

所謂「回挫走勢」（throwback），是指價格向上突破之後，不久就折返到排列上限或三角形頂點附近重新測試支撐。同理，回升走勢（pullback）是指價格向下突破之後，不久就折返到排列下限或三角形頂點附近重新測試壓力。向上突破案例發生回挫走勢的比率為 58%，向下突破案例發生回升走勢的比率為 49%；所以，向上突破發生折返走勢的頻率較高。
