# 第 46 章 週線向下關鍵反轉 / 955

表 46.1 週線向下關鍵反轉的辨識特質

| 特徵 | 討論 |
| :--- | :--- |
| 週線圖 | 採用週線圖觀察單週的關鍵反轉。 |
| 價格上升趨勢 | 價格必須處在上升趨勢中。如果當時的價格趨勢明顯向下，不必考慮向下的關鍵反轉。在上升趨勢之後的向下或橫向修正走勢中，只要關鍵反轉發生的位置接近峰位（距離 5 週之內，而且價格差異不大），就視為有效的關鍵反轉。 |
| 較高的高價與較低的低價 | 相對於前一支線形，高價必須較高，低價也必須較低。不允許兩支線形具有相同的高價或低價。 |
| 較低的收盤價 | 關鍵反轉的收盤價必須低於前一支線形低價。 |

週稍早的價格繼續創新高，當週隨後出現急跌的走勢※。在這種情況下，排列很容易辨識，也具有說服力。可是，關鍵反轉另外還有一半的機會落在峰位之後。
