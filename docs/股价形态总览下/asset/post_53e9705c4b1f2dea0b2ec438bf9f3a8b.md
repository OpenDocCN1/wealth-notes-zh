
## 交易範例

如何利用前述的交易戰術來提昇操作績效呢？讓我們觀察葛先生如何處理圖 34.6 的情況。葛先生希望成為一位專業的當日沖銷者，但他目前還沒有足夠的交易資本，也不具備專業的操作技巧。所以，他打算慢慢來。

1992 年 12 月份，隨意翻閱股價走勢圖的時候，葛先生看見圖 34.6 的雙重底排列。在日線圖上，發生在 8 月份與 11 月份的兩個底部很難察覺。這是否是一個有效的雙重底排列？是否代表適當的買進機會？葛先生認為兩個谷底所夾的向上折返走勢不夠高，而且兩個谷底的形狀也不夠顯著。他認為，既然他不能清楚判斷這個排列，那麼其他人也會有類似的困擾。若是如此，進場買進的人就不多，所以股價也不會上漲。

當他翻開週線圖，卻發現截然不同的結果。他清楚看見圓形底排列，甚至連成交量也呈現對應的圓弧狀。所以，他決定等待價格上漲到先前的杯口左緣價位 $21\frac{3}{8}$。1993 年 2 月份，當價格連續 2 週盤旋在杯口左緣價位附近，他知道這已經逼近關鍵時刻。問題是：盤勢接下來將如何發展？

隔週，價格下跌，形成杯口右緣。葛先生決定繼續等待，他必須等到收盤價向上穿越杯口右緣。他知道過早進場的風險，股價可能一路走低；如果股價真的能夠向上穿越杯口右緣，那麼繼續走高的成分就很大。

當價格觸及 $22$，葛先生進場買進。他回顧整個股價走勢，決定把停損點設定在杯口右緣支撐的下側 1/8 點處。他相信，如果走勢引發他所設定的停損，就代表價格將進一步走低。他自認為整個交易計畫相當完善，考慮非常周詳，距離專業當日沖銷只有一步之遙。隨著股價逐步走高，他更加信心滿滿，甚至開始索取一些當日沖銷課程的簡介。可是，6 月底的時候，走勢跌破上升趨勢線，這是任何人都不會忽略的警訊。當然，葛先生也瞭解情況已經發生根本變化。

Alco Standard Corp.（辦公設備與用品，NYSE，代碼 ASN）

![](img/157738047fa61d5e4bdbaf89f0241a36_223_0.png)

圖 34.6 在這份週線圖中，圓形底排列隱約可以見到雙重底型態。

隔週，他接到經紀人的電話，得知停損單已經成交。雖然他早有心理準備，但還是很難接受每股大約 $1$ 的損失。當他實際查閱報價，更覺得懊惱，因為他的賣單幾乎成交在當週的最低價。

三年之後，葛先生已經不再嘗試成爲專業的當日沖銷者。可是，他還是決定叫出這支股票的走勢圖看看。結果，交易價位爲 $66$，剛好是他當初買價的三倍。

### 摘要資料

| 項目 | 內容 |
| :--- | :--- |
| 外觀 | 大規模的圓弧狀價格走勢，圓弧缺口（杯口）朝下。 |
| 反轉或整理 | 長期（6 個月以上）的多頭整理型態。 |
| 失敗率 | 19%。 |
| 向上突破之後的失敗率 | 6%。 |
| 平均漲幅 | 41%，最經常發生漲幅為 20%~40%。 |
| 目標價格達成率 | 69%。 |
| 意外發現 | 圓形頂完成之後，價格大多上漲。 |
| 其他名稱 | 圓蓋頂，圓形反轉。 |
| 參照排列 | （8）蹦跳-奔馳頭部反轉排列，（19）複雜頭肩頂排列。 |

什麼情況下，頭部不代表頭部？當圓形頂（rounding top）或圓蓋頂（dome）排列完成而價格向上突破的時候。這實在是一個非常意外的發現，因為大部分的圓形頂排列都向上突破。失敗率為 19%，稍低於我認爲可靠排列所允許發生的最高失敗率 20%。如果等待向上突破之後，排列的失敗率下降爲 6%。最初，我把突破點設定爲排列高度的三分之一；換言之，一旦圓形頂排列向上折返的幅度超過排列高度的三分之一，就視爲向上突破。前述上漲走勢經常穿越下降趨勢線，讓其他投資人得以察覺趨勢變化（協助推高股價）。可是，結果實在不太實際（失敗率爲 0%，平均漲幅爲 58%）。前述考量忽略其他先漲後跌的走勢。所以，我重新把突破點設定爲圓形頂的峰位。結果比較合理：平均漲幅爲 41%，最經常發生漲幅介於 20%~40%。

### 緣起

圖 35.1 顯示日線圖上的圓形頂排列，一些突兀狀線形使得圓弧狀軌跡顯得不太平滑。1995 年 2 月份開始一波漲勢，5 月中旬創峰位，漲幅大約是 22%。隨後，股價分成幾個階段下降，9 月份創最低價位，然後開始回升，並且迅速穿越原來的高點，目前的價位大約在 $71$ 附近。

我們不難解釋圓形頂的發生原因。最初，在多頭氣氛下，股價夾著成交量上揚。由於股價漲勢穩定，賣方沒有出脫持股的急迫性，使得需求沒有受到供給的壓抑。可是，隨著股價走高，需求逐漸減少，最後終於與供給達成平衡狀態。價格由漲轉跌，畫出圓頂狀的軌跡。由於股價已經超過股票的內含價值，賣方的態度轉爲積極。精明資金也開始抽離市場，股價下跌。

一旦投資人察覺價格向上動能已經反轉，賣壓轉強，迫使價格下滑。成交量可能放大，因爲更多的交易者受到股價下跌刺激而希望拋售持股。最後，當沒有經驗的投資人覺得恐慌而離場，股價跌勢就告一段落了。只要所有希望賣出股票的人都賣出之後，精明資金就進場撿便宜貨。

### 失敗案例

當我在股價走勢圖中尋找圓形頂案例的過程中，很快就發現它們大多扮演既有趨勢的連續排列。相關的統計數據也支持我的感覺。所以，我認為任何圓形頂排列只要不是既有趨勢的連續排列，就歸類爲失敗案例。我之所以如此處理，原因與圓形底相同。假定你認爲圓形頂排列完成之後，價格將朝排列發生之前的趨勢方向繼續發展，並且建立對應的部位。在這種情況下，如果價格趨勢發生反轉，部位通常都會陷入虧損。圓形頂反轉型態非常罕見；在我的資料庫內，這類案例不超過 20%，但畢竟還是會發生。

圖 35.3 提供一個圓形頂失敗案例。排列發生之前，價格曾經出現 5 個月的上升趨勢。可是，就在圓形頂排列開始的前幾個星期，價格跌破上升趨勢線。針對這個圓形頂排列，投資人可能預期排列完成之後，價格將繼續先前的上漲走勢，但實際的發展顯然不是如此。由圓形頂的高點往下衡量和 3 個月之後的低點，跌幅爲 60%。

我可以找到一些技術上的理由，解釋這個排列爲何沒有發生預期中的行爲。圓形頂開始的前兩個星期，價格走勢跌破重要的中期上升趨勢線（圖形只顯示一部分）。10 月中旬到 11 月初之間，價格回升，重新站上中期趨勢線，然後展開一段相當凌厲的漲勢，一直到隔年 1 月中旬才明顯下跌。價格在 1992 年 9 月份第一次跌破上升趨勢線，這代表一項警訊，意味著上漲趨勢即將告一段落。持有股票的投資人開始覺得緊張。最後，這些緊張的壓力終於轉化為龐大的成交量，驅動股價崩跌。

Amgen Inc.（藥品, NASDAQ, 代碼 AMGN）

![](img/157738047fa61d5e4bdbaf89f0241a36_231_0.png)

圖 35.3 圓形頂排列失敗案例。圓形頂排列發生之前，價格跌破上升趨勢線（圓形只顯示一部分），這是排列失敗的徵兆之一。

所謂「向上突破」，是指價格向上穿越圓形頂的峰位。一旦向上突破之後，價格通常會出現 5% 以上的跟進漲勢。若非如此，則屬於 5% 失敗情況。在全部 165 個案例中，總共只有 6 個排列在向上突破之後沒有發生 5% 以上的跟進漲勢。所以，對於大部分圓形頂排列，只要型態向上突破，價格通常都會繼續上漲。

### 交易戰術

表 35.4 列示圓形頂排列的交易戰術。衡量法則所預估的是最低目標價位。在傳統技術分析的領域內，圓形頂排列根本沒有所謂的衡量法則，但勉強套用的結果還有 69% 的排列達成目標價位。我認爲可靠排列的目標價位達成率至少應該是 80%；因此，就這方面而言，圓形頂不屬於可靠排列。如果打算運用衡量法則，另外還必須考慮上檔壓力。關於衡量法則的計算，我把型態峰位（最高價）減去排列右側最低價，以此代表排列高度，然後由型態峰位向上衡量排列高度，結果就是目標價位。

**表 35.4 圓形頂排列的交易戰術**

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 計算排列峰位到右側低點之間的距離，由排列峰位向上衡量前述距離，結果就是目標價位。 |
| 突破之後買進 | 收盤價向上穿越排列峰位，進場買進。 |
| 向上折返 30% 之後買進 | 另一個風險較高而獲利潛能較大的買點是：價格由右側低點向上反彈的幅度超過排列高度 30%。 |
| 右側低點的支撐 | 右側低點屬於重要支撐。一旦價格跌破這個價位，相當於突破重要支撐，考慮賣出持股。 |

讓我們運用圖 35.5 來說明，B 點代表型態峰位 $49\frac{7}{8}$，A 點代表排列右側最低價 $45\frac{5}{8}$，兩者的差值即是排列高度 $4\frac{1}{4}$ 點，由 B 點向上衡量排列高度，目標價位為 $54\frac{1}{8}$ （=$49\frac{7}{8}+4\frac{1}{4}$），完成於 7 月中旬。

![](img/157738047fa61d5e4bdbaf89f0241a36_236_0.png)

圖 35.5 圓形頂與上升楔形排列。夏小姐掌握這個交易機會。在圓形頂排列發展過程，當價格向上穿越下降趨勢線，夏小姐進場買進，隨後在上升楔形向下突破的時候賣出。

面對圓形頂排列，可供考慮的操作方法很多。最保守的做法，是等待收盤價向上突破排列峰位。一旦向上突破之後，我們的案例顯示價格繼續上漲的機率高達 94%。所以，這種操作方法相當穩當，雖然還是不能保證成功。如果你願意接受更大的風險，可以在更低的價位進場（由排列右側低點起算，當價格回升超過排列高度的三分之一）。當價格由低點回升三分之一，通常都已經向上穿越下降趨勢線。價格回升三分之一，或向上突破下降趨勢線，這些徵兆通常已經足以讓投資人進場，下檔的風險相當有限。

在圓形底排列發展過程中，如果發現價格向上回升，而且漲勢持續 1 個月左右，結果又下跌穿越原來的排列右側低點，最好賣出股票（如果你已經提早進場買進）。價格跌勢很可能在排列右側低點向上反彈，因爲該處代表支撐。另外，隨時都應該留意下檔支撐，評估多頭部位的潛在風險。

### 交易範例

夏小姐的精力非常旺盛。她是那種下班之後經常泡在酒吧，受到男人包圍的人。總之，她是一種很容易相處的人，經常成爲聚會的核心人物。

她的投資風格完全反映日常生活方式。當她看見圖 35.5 的圓形頂排列，就決定在適當的買點進場。最初，她誤以爲是頭肩頂排列，但頭與兩肩的價位太接近，成交量型態也不對。

6 月中旬，當價格開始上漲，並且穿越下降趨勢線，夏小姐進場買進，成交價格為 $47$。然後，她嚴密觀察每天的走勢發展。8 月份之後，她發現價格漲跌之間的波動幅度愈來愈小，似乎逐漸構成上升楔形排列，但成交量不太對勁。正常情況下，上升楔形排列的成交量應該趨於萎縮。

9 月初，成交量突然顯著下降，夏小姐覺得這是即將變盤的徵兆。根據過去的經驗顯示，上升楔形即將突破之前，成交量經常巨幅萎縮；所以，當價格跌破楔形排列下側趨勢線，她立即賣出持股，成交價格為 $62$。

整個操作過程非常完美。賣出股票之後，股價一度拉回到楔形排列的下限附近，盤整兩天重新測試該處的壓力，然後才展開正式的暴跌走勢。隔年 1 月份，股價下跌到 $34\frac{1}{8}$。

### 摘要資料

#### 上升排列
- **外觀**
價格上漲，創峰位之後，稍微拉回整理，然後又繼續上漲，形成一系列勾狀或扇貝狀的走勢。
- **反轉或整理**
長期（6 個月以上）的多頭整理走勢。
- **失敗率**
25%。
- **平均漲幅**
33%，最經常發生漲幅爲 20%~30%。
- **成交量趨勢**
排列兩端最大，中間較小，形狀如同英文字母 U。
- **目標價格達成率**
71%。
- **意外發現**
一系列的扇貝狀走勢，但走勢的價格高度與時間寬度都愈來愈小。
- **參照排列**
（9）帶柄杯狀排列，（19）複雜頭肩底排列，（34）圓形底排列。

#### 下降排列
- **外觀**
價格下跌,創谷底之後,稍微回升整理,然後又繼續下跌,形成一系列顛倒勺狀或扇貝狀的走勢。
- **反轉或整理**
短期(3個月以內)的空頭整理走勢。
- **失敗率**
3%。
- **平均跌幅**
24%,最經常發生跌幅大約是20%。
- **成交量趨勢**
沒有明顯的趨勢。
- **目標價格達成率**
52%。
- **參照排列**
(19)複雜頭肩底排列,(34)圓形底排列。

傳統技術分析只提到上升扇貝形排列(ascending scallops),這是由一系列(至少兩個)勺狀價格排列構成的上升走勢。根據我的推想,既然有上升排列,就應該有對應的下降格式。可是,詳細討論這兩種排列之前,或許應該先簡略說明重要的發現。

上升扇貝形排列的失敗率為25%,超過可靠排列的最高門檻 20%。下降扇貝形排列(descending scallops)的失敗率只有 3%。兩者的失敗率為何有如此大的差異呢?我運用排列右端高價做爲基準,藉以計算最終高價或最終低價的變動百分率。對於上升扇貝形排列,右端最高價的水準遠高於排列左端高價,造成基準過高的不利狀況。反之,由於下降扇貝形排列的右端高價比較接近——相對於左端高價而言——排列低點與最終低點,以此做為衡量基準,自然有利於續效。

譯按:這可以解釋上升排列平均漲幅何以低於一般多頭排列,或下降排列平均跌幅何以超過一般空頭排列,但這些解釋與失敗率之間有什麼關聯呢?
