# 三波段衡量跌勢

![](bbox=[0.3, 0.32, 0.53, 0.43])

# 摘要資料

外觀 價格下跌，然後向上修正，接著又繼續下跌。向下的兩隻腳，價格距離與涵蓋時間都大約相同。

反轉或整理 中期（6個月以內）的空頭反轉型態。

失敗率 22%。

平均跌幅 36%，最經常發生跌幅介於 25%與 40%之間。

第一隻腳跌幅 25%，54 天。

修正階段漲幅 16%，39 天（向上修正幅度是前一波跌幅的 40%到 60%）。

第二隻腳跌幅 27%，60 天。

衡量法則 第二隻腳長度超過第隻一腳長度的案例佔 43%。

意外發現 修正階段漲幅與第一隻腳跌幅之間維持比例關係。

其他名稱 擺動衡量走勢。
