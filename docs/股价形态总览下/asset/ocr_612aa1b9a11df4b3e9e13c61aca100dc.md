# 向下突破

**外觀**

連續三支線形構成的等腰三角形排列，盤中高價持續下滑，盤中低價持續墊高。向下突破。

**反轉或整理**

短期（3 個月以內）的空頭反轉或整理走勢，反轉型態的發生頻率為 55%。

**失敗率**

44%。

**平均跌幅**

21%，最經常發生跌幅為 10%或以下。

**成交量趨勢**

下降。

**回升**

58%。

**意外發現**

排列結構上下對稱，績效比較理想。

**参照排列**

（40）等腰三角形底部排列，
（41）等腰三角形頭部排列。

鱗鱸排列（shark-32）雖然只由三支線形構成，但我還是決定採用 5%失敗的定義。排列突破之後，價格沒有出現 5%或以上的跟進漲勢，結果又朝相反方向發生重大走勢，這稱為「5% 失敗」。對於向上突破的案例，失敗率偏高為 41%；向下突破的情況更糟，失敗率高達 44%。我認為可靠排列的失敗率不應該超過 20%。排列失敗率之所以偏高，一方面是因為型態的涵蓋期間太短（只由 3 支線形構成），規模太小。價格朝某個方向突破，又反轉回到排列之內，很容易再朝另一個方向突破，於是造成排列失敗。對於較大规模的排列，價格一旦跌回排列之內，迴旋的空間比較大，朝原先方向再突破的可能性較高（換言之，比較不容易朝相反方向突破）。
