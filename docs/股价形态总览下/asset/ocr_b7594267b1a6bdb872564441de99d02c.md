# 緣起

圖 28.1 顯示一個不太對稱的頭肩頂排列，「頭」部本身是單日反轉排列。整個頭肩頂型態發生在一段延伸性漲勢末端，整段走勢起漲於 1995 年 1 月份。單日反轉排列的收盤價幾乎就是盤中最低價，線形向上突兀的程度遠超過最近一年內的大多數突兀線形。

圖 28.2 提供一個單日反轉底部排列的例子。這個底部型態發生在短期下降趨勢末端。單日反轉發生之前，股票大約維持兩個月的跌勢。單日反轉線形的收盤價位在盤中高價附近，
