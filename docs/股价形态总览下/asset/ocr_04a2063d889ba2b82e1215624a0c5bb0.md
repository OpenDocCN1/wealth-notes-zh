# 表 32.1 矩形底部排列的辨識特質

| 特質 | 討論 |
|---|---|
| 價格下降趨勢 | 排列發生之前，短期或中期價格趨勢朝下。 |
| 水平狀趨勢線 | 排列本身由兩條相互平行的水平狀趨勢線界定，分別代表排列的上限與下限。 |
| 觸及點 | 排列的上限與下限都至少各有 2 個觸及點（總共至少有 4 個觸及點）。 |
| 成交量 | 成交量型態視突破方向而定：向上突破，成交量趨於放大；向下突破，成交量趨於縮小。 |
