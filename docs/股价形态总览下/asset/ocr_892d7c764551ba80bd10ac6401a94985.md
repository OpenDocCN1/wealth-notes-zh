# **BankAmerica Corp.（銀行，NYSE，代碼 BAC）**

![](bbox=[0.2, 0.2, 0.9, 0.48])

圖 31.5 在上升-回檔的模式中，這個長管頂排列發生上升階段與回檔階段的銜接點。先前上升階段的漲幅為 35%，回檔階段的跌幅為 15%。

1993 年 6 月份，約翰看見圖 31.5 的長管頂排列，於是擬定一份特別的操作計畫。首先，他衡量去年 11 月（A 點）到今年 1 月（B 點）之間的第一隻腳漲幅為 34%（=[19¼ - 14¾]÷14¾）。其次，計算 B 點到 C 點之間的回檔幅度為 15%。

由 C 點到長管頂排列之間的第二隻腳漲幅為 36%，非常接近第一隻腳的漲幅 34%。他判斷（或希望）長管頂完成之後，價格的回檔程度會接近 B 點到 C 點之間的回檔程度 15%。所以，他進場放空股票，成交價格為 $22½，並且按照前述預估的回檔水準把回補買單設定在 $19。另一方面，心理停損設定在 $23¾，稍高於長管頂右側線形的高點 $23 3/16。
