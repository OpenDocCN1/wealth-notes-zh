表 40.1 等腰三角形底部排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 下降趨勢 | 底部排列發生之前的價格趨勢朝下發展，但排列本身可以向上或向下突破。 |
| 形狀 | 價格沿著兩條趨勢線發展，排列上限向下傾斜，排列下限向上傾斜，兩者朝向未來（右方）收斂。排列雖然稱為等腰三角形，但兩腰（上限與下限）不必具有相同長度。 |
| 觸及點 | 銜接排列上限與下限的轉折高點與低點，至少需要各有兩點（換言之，總共至少需要四個轉折點）。 |
| 成交量 | 排列內的成交量呈現下降趨勢，但允許偶爾出現大量，瀕臨突破之前的成交量通常很小。 |
| 提前突破 | 這是收盤價穿越到排列之外，但很快又回到排列之內。 |
| 突破方向 | 事前不知道突破方向。採取行動之前，應該等待實際的突破。所謂突破，是指收盤價穿越到排列之外，但這與提前突破不一樣，不會很快又折返排列之內。 |
| 排列期間 | 至少應該是 3 個星期（21 個交易日）以上。期間少於 3 個星期，最好歸納為三角旗形。 |

後的回升走勢折返到排列下限，接著展開正式的跌勢。價格走勢受到兩條趨勢線的界定；排列上限向下傾斜，排列下限向上傾斜。沒有任何一條趨勢線呈現或接近水平狀，兩者都具有某種程度的斜率。這是很重要的特質，因爲排列上限或下限如果呈現水平狀，就屬於上升或下降三角形。另外，排列上限與下限朝向右側收斂，不同於各種擴張排列（broadening formations）。
