# 表 26.2 三波段衡量跌勢的一般統計數據

| 說明 | 統計數據 |
| :--- | :--- |
| 排列數量：<br>1991 年~1996 年的 500 支股票 | 622 個 |
| 反轉或整理排列 | 77 個整理，545 個反轉 |
| 失敗率 | 134/622 相當於 22% |
| 成功排列的平均跌幅 | 36% |
| 最經常發生跌幅 | 25%~40% |
| 排列平均長度 | 5 個月（153 天） |
| 第一隻腳價格跌幅 | 25%，54 天 |
| 修正階段價格漲幅 | 16%，39 天 |
| 第二隻腳價格跌幅 | 27%，60 天 |
| 修正階段價格折返幅度 | 40%~60% |
| 排列起始於最近 12 個月價格區間的下緣、中央或上緣 | 下緣 0%<br>中央 6%<br>上緣 93% |
| 衡量法則 | 第二隻腳長度超過第一隻腳的案例佔 43% |

在我發現的案例中，絕大部分（88%）屬於上升趨勢末端的頭部反轉排列，其餘案例則屬於下降趨勢的整理排列。三波段衡量跌勢的整理排列，通常是延伸性跌勢的構成部分。某些情況下，相對於整個下降走勢，三波段衡量跌勢本身的規模很小；另一些情況下，整個下降趨勢是由一系列的三波段衡量跌勢構成。
