# Fruit of the Loom (成衣，NYSE，代碼 FTL)

![](bbox=[0.05, 0.19, 0.85, 0.49])

圖 45.6 等腰三角形排列跟著發生上升楔形排列。等腰三角形向下突破，顯示價格將繼續下跌。上升楔形的下檔目標價位就是排列最低價$29%。

爲了提升操作的成功機會，最好等待向下突破之後才進場放空。建立空頭部位之前，收盤價應該穿越到排列下限之外。按照這個準則操作，失敗率可以由 24%降低爲 6%。可是，降低失敗率也需要付出對應的代價，你必須放棄向下突破之前價格下跌的獲利機會。雖說如此，穩當的獲利還是比較重要。

萬一錯失突破過程的進場機會，或許可以在回升走勢進場。排列向下突破之後，大約有半數的案例（53%）會發生回升走勢，價格拉回到排列下限附近，讓你有第二次進場機會。如果你打算運用這個機會，應該等待回升走勢完成而價格又開始下跌才進場，如此可以避免回升走勢繼續上揚。
