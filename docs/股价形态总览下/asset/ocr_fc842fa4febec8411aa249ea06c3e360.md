# 表 30.1 長管底排列的辨識特質

| 特質 | 討論 |
| --- | --- |
| 週線圖 | 長管底排列雖然也出現在日線圖上，但週線圖上的排列績效較理想。儘可能完全採用週線圖。 |
| 連續兩支向下突兀長線形 | 尋找連續兩支向下的突兀長線形。 |
| 兩支線形的低價相差不大 | 兩支線形的低價相差不大，大約是$0.25或以内，但高價股的差異可能會稍微大些。 |
| 向下突兀長線形 | 這兩支線形必須是向下的突兀長線形，長度應該超過最近一年內的大多數突兀長線形。兩支長管狀線形在週線圖上看起來就非常突兀，隔週的低價應該落在長管底排列的高價附近。 |
| 價格重疊部分很多 | 長管狀排列的兩支線形必須大部分重疊。 |
| 大成交量 | 雖然不是必要條件，但長管狀排列兩支線形或至少一支線形的成交量必須放大。 |
| 明顯的長管狀 | 在週線圖上，排列明顯向下凸出，否則另外尋找操作對象。績效最理想的長管底排列，往往發生在下降趨勢末端。 |

然這些辨識準則的數量似乎不少，但內容非常明顯。請參考圖 30.2 的例子。第一個準則建議你採用週線圖。雖然長管底排列也可以運用於日線圖，但週線圖的排列績效普遍較理想。長管底排列是由連續兩支向下的突兀長線形構成，看起來像是兩條相互平行的垂直線段。排列左側線形低點與右側線形低點之
