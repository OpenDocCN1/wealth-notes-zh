表 44.6 下降楔形排列的交易戰術

| 交易戰術 | 解釋 |
| :--- | :--- |
| 衡量法則 | 價格向上突破之後，至少應該到達排列最高點。 |
| 突破之後買進 | 由於排列內的價格趨勢朝下發展，最好等待向上突破之後才買進。 |
| 回挫之後買進 | 如果你錯失突破當時的買進機會，可以考慮在回挫走勢完成而價格又開始上漲的時候買進或加碼。 |
| 留意頓挫 | 價格即將向上突破之前，有 27%的排列會發生頓挫走勢。這是等待實際突破才買進的另一個理由。 |

排列最高價發生在 6 月初的排列起點 $48^{5}_{8}$，這也是最低目標價位。價格向上突破之後，頗有拉回測試排列頂點的意圖，但回檔的程度非常有限。然後，價格一路走高，8 月中旬完成目標價位。楔形排列的高點成為後續漲勢的壓力，所以走勢在此盤旋 2 週左右，才真正突破這道阻力。最後，價格上漲到 $51$，這個高點也即是排列的最終高點。

由於 90%左右的下降楔形排列都向上突破，似乎沒有等待實際突破的絕對必要性。可是，排列內的價格趨勢朝下發展，如果等待實際突破，或許可以在更低的價格買進。向上突破之後，至少能夠繼續上漲；5%的下降楔形排列佔 98%。另外，下降楔形排列並不是一種很容易辨識的股價型態，等待價格實際突破，比較不容易辨識錯誤。
