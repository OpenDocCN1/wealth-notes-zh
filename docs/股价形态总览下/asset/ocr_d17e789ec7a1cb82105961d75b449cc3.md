# 交易戰術

表 42.4 摘要列示三重底排列的相關交易戰術，首先討論衡量法則。衡量法則預測排列完成之後的上檔最低目標價位，計算排列最高價與最低價之間的排列高度，三重底向上突破之後，至少應該會出現相當於排列高度的漲勢。讓我們利用圖 42.6 來說明計算程序。排列最低價發生在第一谷底的$21¼，排列最高價為第一谷底與第二谷底所夾峰位的$25¼，排列高度為$4½。請注意，這個排列的確認水準也是$25¼；換言之，確認水準也就是排列最高價。由排列最高價向上衡量排列高度，目標價位為$30¼（=25¼+4½）。這個目標價位完成於 7 月初。
