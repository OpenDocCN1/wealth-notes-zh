# 表 27.3 三波段衡量漲勢的交易戰術

| 交易戰術 | 解釋 | |---|---| | 衡量法則 | 第一隻腳的长度是由最高價衡量到最低價，由修正階段的最低價向上衡量第一隻腳的长度，結果就是第二隻腳的目標價位。藉由目標價位計算交易的潛在報酬，比較報酬與風險之間的關係，評估交易的可行性。 | | 年度低價 | 挑選排列起點（第一隻腳的最低價）位在年度價格區間三等份下線的交易對象。避免介入年度高價附近的排列。 | | 買進 | 修正階段結束之後，在第二隻腳漲勢初期，進場買進。 | | 支撐／壓力 | 修正階段經常提供後續走勢的重要支撐與壓力。 |
