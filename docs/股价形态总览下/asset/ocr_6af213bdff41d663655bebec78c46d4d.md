# 表 32.4 短形底部排列的突破統計數據

| 說明 | 向上突破 | 向下突破 |
|---|---|---|
| 發生回挫／回升走勢的排列 | 25/41 或 61% | 38/54 或 71% |
| 完成回挫／回升走勢的平均時間 | 11 天 | 9 天 |
| 到達最高點／低點的天數 | 9 個月（275 天） | 2.5 月（78 天） |
| 突破位置在最近 12 個月價格區間的下緣、中央或上緣 | 下緣 19%，<br>中央 50%，<br>上緣 31% | 下緣 56%，<br>中央 32%，<br>上緣 12% |
| 前述突破位置的<br>平均漲幅／跌幅 | 下緣 45%，<br>中央 49%，<br>上緣 36% | 下緣 21%，<br>中央 16%，<br>上緣 16% |

把突破之前的年度價格區間劃分為三等份（上緣、中央與下緣），向上突破大多發生在中央位置。我原本預期大多數的向上突破發生在上緣位置，因爲頭部排列原本應該發生在價格區間的上端，而向上突破又應該發生在頭部排列的上端。如果考慮年度區間三個位置的排列績效，向上突破落在中央位置的平均漲幅最大（49%）。非常奇怪地，向上突破落在上緣位置的績效竟然相對最差，只有 36%。一般來說，在年度高價附近，動能玩家應該會繼續推動股價走高。

向下突破落在年度價格區間下緣位置的績效最佳，平均跌幅爲 21%。這意味著「弱者恆弱」；換言之，如果你打算放空股票，應該挑選那些創新低價的對象，不是創新高 的股票。
