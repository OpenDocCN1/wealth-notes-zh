# 表 39.2 下降三角形排列的一般統計數據

| 說明 | 統計數據 |
| :--- | :--- |
| 排列數量： | 689 個 |
| 1991 年~1996 年的 500 支股票 | |
| 反轉或整理排列 | 267 個反轉，422 個整理 |
| 失敗率 | 309/689 或 45% |
| 向下突破之後的失敗率 | 27 個或 4% |
| 成功排列的平均跌幅 | 19% |
| 失敗排列的平均漲幅 | 42% |
| 最經常發生跌幅 | 10%~20% |
| 成功排列的目標價位達成率 | 256 個或 67% |

| 起點至三角形頂點 | 3 個月（87 天） |

附註：大約只有半數的下降三角形發生預期價格行爲，其中的三分之二完成目標價位。

地，成功排列的平均跌幅只有 19%，大約反映一般空頭排列的平均績效（20%）。關於排列的最經常發生跌幅，我採用次數分配圖，把排列跌幅劃分爲 10 個區間，每單位刻度爲 5%，請參考圖 39.5。我們發現最高欄位分別落在 10%、15%與 20%的位置，所以我把最經常跌幅設定爲 10%~20%。

下降三角形向上突破之後的表現很不錯，平均漲幅爲 42%。這個數據顯示你應該順著突破方向進行交易——排列向上突破則做多，向下突破則做空。
