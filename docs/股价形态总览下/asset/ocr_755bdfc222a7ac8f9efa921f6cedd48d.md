# 表 44.1 下降楔形排列的辨識特質

| 特質 | 討論 |
| :--- | :--- |
| 兩條向下傾斜的趨勢線 | 分別沿著價格走勢的轉折高點與轉折低點繪製趨勢線，兩條趨勢線都向下傾斜，而且向右收斂。 |
| 多個觸及點 | 大多數排列都至少有 5 個觸及點，某條趨勢線有 3 個觸及點，另一條趨勢線有 2 個觸及點。如果觸及點不足 5 個，排列可能有問題。 |
| 至少 3 星期 | 下降楔形排列的涵蓋期間至少 3 個星期；如果期間少於 3 個星期，應該屬於三角旗形排列。排列期間也很少超過 4 個月*。 |
| 成交量趨勢 | 突破之前的成交量通常呈現下降趨勢。 |

我認爲，可靠的下降楔形排列，趨勢線至少需要 5 個觸及點。爲什麼？下降楔形排列的價格型態是由數個轉折高點與轉折低點構成，轉折高點與轉折低點都持續下滑，而且轉折高點的下降速度快於轉折低點。至少 5 個觸及點，可以避免把某些來回擺動的價格走勢歸納爲下降楔形排列。型態的發展過程中，需要數個交替觸及點。舉例來說，圖 44.2 的趨勢線有 6 個觸及點，但只有 5 個交替觸及點（第 3 個觸及點不屬於交替觸及點，因爲它與第 2 點一樣觸及下側趨勢線）。

分別銜接轉折高點與轉折低點的趨勢線，是辨識下降楔形排列的另一個關鍵。兩條趨勢線都必須向下傾斜，而且向右

\* 譯按：3 星期應該是 21 個交易日，4 個月應該是 120 個交易日。按照第 916 頁的說明，涵蓋期間應該介於 20 天到 125 天之間。
