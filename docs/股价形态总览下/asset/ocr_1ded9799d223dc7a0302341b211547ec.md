# 辨識準則

表 42.1 列示三重底排列的辨識準則。我想，大多數技術分析師都會告訴你，任何三個底部不一定就構成三重底排列。三個底部的規模通常很大，彼此相隔一段距離，兩個底部之間夾著圓弧狀拱出的價格走勢。三個底部的最低價應該大約落在相

表 42.1 三重底排列的辨識特質
| 特質 | 討論 |
| :--- | :--- |
| 三個顯著而<br>大規模的底部 | 尋找三個轉折低點，彼此間隔一段距離，形狀非常明顯。底部規模通常很大，呈現尖銳的 V 形，兩個谷底所夾的價格峰位通常相當圓滑，但這不屬於必要條件。 |
| 相同價位 | 三個谷底的價位差異應該很小。中間谷底不得顯著較低，否則就是頭肩底排列。 |
| 成交量<br>下降趨勢 | 排列內的整體成交量應該呈現下降趨勢，但三個谷底本身的成交量可能很大。就三個谷底而言，第一個谷底的成交量通常最大，第三個谷底最小。 |
| 確認點 | 當價格由第三個谷底回升，只代表潛在的三重底排列。唯有當價格上漲而超過排列的最高價（確認點），三重底才算完成。 |
| 過線圖 | 由於三重底通常屬於大規模的排列，不妨參考過線圖，或許有助於辨識較長期的型態。 |
