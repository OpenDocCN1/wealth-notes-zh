# Airgas, Inc. (特殊化工，NYSE，代碼 ARG)

![](bbox=[0.22, 0.2, 0.97, 0.5])

圖 24.5 內側日與吊人線。針對這個內側日排列，老郭由紙上模擬交易獲利 $2,000。12月中旬，價格走勢出現吊人線形。

之後，他才曉得當天的盤勢。老郭沿著近來的下跌走勢上線，繪製一條下降趨勢線，發現 A 點的單日反彈只不過稍微穿越趨勢線，未必構成有效的突破，但還是可能意味著趨勢即將向上反轉。隔天，當老郭還在三心兩意不知道是否應該回補股票的時候，價格又開始下跌。

由於實在難以決定，老郭決定投擲銅板，結果他繼續持有空頭部位。當天交易結束的時候，股價確實收低，重新跌破下降趨勢線。可是，老郭認為當天的發展純屬運氣，決定股票收盤價如果再度向上穿越下降趨勢線，就回補空頭部位。
