# 表 40.3 等腰三角形底部排列的提前突破統計數據

| 說明 | 向上突破 | 向下突破 |
| --- | --- | --- |
| 發生提前突破的排列數量 | 10/63 或 16% | 13/83 或 16% |
| 向上提前突破的排列數量 | 0 | 8/83 或 10% |
| 向上提前突破的成交量 | 0 | 25 天移動平均的 79% |
| 向下提前突破的排列數量 | 10/63 或 16% | 7/83 或 8% |
| 向下提前突破的成交量 | 25 天移動平均的 123% | 25 天移動平均的 161% |
| 同時發生向上與向下提前突破的排列數量 | 0 | 2/13 或 15% |
| 向上提前突破發生在排列時間寬度上的位置 | 0 | 72% |
| 向下提前突破發生在排列時間寬度上的位置 | 71% | 72% |

或向下突破，等腰三角形發生提前突破的情況比較少見（佔所有案例的 16%）。所謂「提前突破」，是指收盤價穿越到排列上限或下限之外，但很快又折返到排列之內。表 40.3 顯示兩種方向的提前突破與成交量數據。提前突破的成交量大於平均水準，所以無法藉由成交量判斷提前突破或真正突破。可是，就突破發生在排列時間寬度上的位置來說，提前突破稍微提早發生（向上突破為 71%與 79%，向下突破為 72%與 74%）。
