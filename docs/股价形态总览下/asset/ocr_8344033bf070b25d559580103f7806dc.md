| 表 45.3 上升楔形排列提前突破的統計數據 |
| :--- |
| 說明 | 統計數據 |
| 發生提前向上或向下突破的排列數量 | 40/179 或 22% |
| 向下提前突破的排列數量 | 16/179 或 9% |
| 向上提前突破的排列數量 | 29/179 或 16% |
| 提前突破向下／真正突破向上的排列數量 | 6/179 或 3% |
| 向下提前突破發生在排列時間寬度上的位置 | 60% |
| 提前向下突破成交量大於平均水準的案例數量 | 56% |


排列曾經發生提前向下突破而真正突破方向朝上的案例，總共只佔 3%。換言之，即使你針對提前向下突破而放空股票，空頭部位最後仍然得以賺錢的機會很高。這一點顯然很重要，因為我們很難判別提前突破與真正突破。

把排列寬度定義為排列起點到楔形頂點之間的距離，我們希望知道提前突破落在排列寬度的哪個位置？平均而言，提前突破點落在排列寬度的 60%位置，真正突破則落在 61%的位置。所以，我們不能就突破位置判別提前突破與真正突破。

提前向下突破的成交量較平均量大的案例佔 56%。這個數據看起來雖然偏低，但實際突破成交量較平均量大的案例只佔 38%而已。平均而言，提前向下突破量是當時 25 天移動平均量的 113%。
