# 統計數據

表 31.2 列示長管頂排列的一般統計數據。雖然資料庫涵蓋 500 支股票，但 150 支股票已經提供 443 個案例，我認為這已經達到試算表處理能力的極限。在這些案例中，54%為連續型態，46%為反轉型態。失敗率為 18%，剛好低於我認為可靠排列所允許發生的最高失敗率 20%。大部分失敗案例都屬於 5%失敗的情況；換言之，長管頂排列出現之後，價格朝下發展（跌幅不足 5%），但很快又大幅向上翻升。排列平均跌幅為 21%，大約是一般空頭排列的正常水準。
