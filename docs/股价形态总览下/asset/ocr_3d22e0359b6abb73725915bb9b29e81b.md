# 緣起

圖 26.1 提供三波段衡量跌勢的範例。由 3 月中旬的峰位（A 點）到向上折返走勢的起點（C 點），這段走勢稱爲第一隻腳（first leg）。向上折返走勢又稱爲修正階段（corrective phase）。修正走勢完成之後，隨後發生的跌勢稱爲第二隻腳（second leg）。第一隻腳與第二隻腳的價格長度與時間寬度大約相同，但行爲還是存在差異，細節請參考「統計數據」一節。

在下降趨勢的修正階段中，價格向上折返，代表股價走勢進行整理或喘息的階段，沒有經驗的投資人經常把修正走勢誤
