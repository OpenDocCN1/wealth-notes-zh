# **Fleet Financial Group Inc.**（銀行，NYSE，代碼 FLT）

圖 27.3 演變為雙重頂排列的三波段衡量漲勢失敗案例。

請參考圖 27.3，其中顯示三波段衡量漲勢最典型的失敗案例。第二隻腳形成雙重頂，使得整個排列提早壽終正寀。失敗的情況非常明顯，因爲第二隻腳上漲到$37\frac{3}{8}$，距離第一隻腳高點還有 1/8 點。如同大多數標準的三波段衡量漲勢一樣，第二隻腳的長度不如第一隻腳。可是，目前這個排列究竟爲什麼失敗呢？請注意，第一隻腳發生之前，股價呈現起伏洶湧的橫向鋸齒狀走勢。第一隻腳非常明確的向上穿越鋸齒狀走勢高點，然後向下翻轉，開始回檔整理。當時的情況讓我想起小型的蹦跳-奔馳反轉排列（bump-and-run reversal）。可是，蹦跳階段的高度不足前奏階段的兩倍（譯按：第一隻腳的長度不超過鋸齒狀走勢高度的兩倍）。所以，這多少會影響進場投資意願。
