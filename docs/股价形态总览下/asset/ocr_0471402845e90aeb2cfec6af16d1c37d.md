# 表 36.3 上升與下降扇貝形排列的交易戰術

| 交易戰術 | 解釋 |
| --- | --- |
| 衡量法則 | 計算扇貝形右端高點到最低點之間的距離，此為排列高度。對於上升扇貝形，由右端高點向上衡量排列高度；對於下降扇貝形，由排列最低點向下衡量排列高度。結果就是最低目標價位。 |
| 折返扇貝形右端高點 | 對於上升扇貝形排列，一旦扇貝形的右端高點出現之後，如果價格回檔過程中跌破扇貝形底部，趨勢已經向下跌轉，排列宣告失敗，你應該避免買進或結東多頭部位。同理，對於下降扇貝形排列，一旦扇貝形的右端高點出現之後，當價格回檔結束而重新向上穿越扇貝形右端高點，則趨勢已經向下跌轉（如果前述價格回檔幅度不足 5%，視為 5%失敗）。 |
| 買點 | 扇貝形右端高點一旦出現，進場建立部位。對於上升扇貝形排列，等待回檔走勢結束而價格重新向上發展。對於下降扇貝形排列，只要價格開始下跌，就進場放空。 |
| 停損 | 上升扇貝形：最低價下方 1/8 點處。下降扇貝形：右端高點上方 1/8 點處。 |
| 避開 | 如果價格下降趨勢已經存在幾個月，針對下降扇貝形排列放空，務必謹慎，因爲跌勢可能即將結束。 |

結束於 10 月下旬的向上扇貝形，A 點代表右端高價$16，B 點代表該扇貝形最低點$12½，所以排列高度為 3½點。上檔目標價位是由右端高點向上衡量排列高度，結果是$19½（=16+3½）。這個目標價位完成於隔年 4 月底（圖形沒有顯示）。如果前述扇貝形發生在下降趨勢中，下檔目標價位是由該扇貝形最低點向下衡量排列高度，結果是$9（=12½-3½）。
