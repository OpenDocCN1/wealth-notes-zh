# 3
盡職調查

我的工作還沒結束。我非常認識我的潛在夥伴，也了解這一行，但我不會只根據情緒或相
我的膽識，就下決定。
一個投資機會通過篩選程序後，接下來就是重頭戲了。你要開始做盡職調查。盡職調查就是你做功課的程序，你要搬開所有的石頭，確定一切不會有意外。這就是調查工作的部分，你要像創投家一樣思考，但不是像牛羚的創投家，你要去分析這個機會的經營面。
對案子充滿熱情很好，而且你也不應該沒有熱情，但熱情雖然是必要條件，卻不是充分條件。
不管是兼職創業家，或雙重投入的創業家，任何創業家做過最糟糕的事就是愛上一個點子。
一旦愛上，你就可能不會問艱難的問題、冷靜思考，或是在不相信這個公司或這個團隊時，你不會說不。你當兼職創業家的目標，就是做出聰明的決定。好消息是，大部分的盡職調查工作，都是結合基本常識與注意細節。你必須評估公司、團隊、以及整個投資機會各個環節的特質。你要確認一切是否合乎情理、團隊不會迴避艱難的問題，並且能用事實與數據支撐這家公司。
