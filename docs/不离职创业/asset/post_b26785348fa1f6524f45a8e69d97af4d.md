
# 讓名字成為名片中最重要的品牌

在召集團隊、打造機制之前，你自己要很清楚。你即將要和很多人談話，所以為了讓每一個人的時間都用得很有效率，你必須要能清楚說明你是誰，你的目標是什麼。回想一下第六章，你寫了一份專業自傳。你當時可能不了解，其實你是在對自己做盡職調查。你是在用一種一致而可以理解的方式，把你職業生涯的一切寫出來。現在這個練習可以進入下一個階段，請思考一下，這對你的品牌與你對別人的建議，有什麼意義。

你應該還記得，我提到我一開始在做兼差事業時，我的自我介紹做得很差勁。在我把我的故事搞清楚之前，我傾向仰賴隨機的活動與靈感當話題，結果所有人都感到困惑，包括我自己。我從經驗中學到，你投射到世界的形式，就大致上是別人看你的方式。因此你需要一個強有力的行銷說詞。如果你在幾個句子內，就清楚說明你的專長以及你想做的事情，你就能掃除大家的困惑，並投射出自信、有信用與使命感給你周圍的人。再回頭看看在中國創業的美國年輕人蓋文，很顯然他的自我行銷說詞很成功。他為每一位潛在的投資人裁切客製化的訊息，這一個行動突顯了，他已經知道某個人將會如何影響他的公司。這是一連串研究、反省與很多練習的結果。

準備自己行銷說詞，需要很多事前的工作。想像一下，你在某個社交場合，有人問你你的工作是什麼。這就是你告訴他們你是兼職創業家的機會，所以千萬不要錯過這個機會。好消息是；由於你在第六章做的練習，你已經有了所有需要的基本元素。重點是要讓人有可以記住的東西，也許是你的日常工作，或你的公司，然後把這個記憶點和你未來想達到的目標連結起來。只要做點準備，這可以很簡單。例如：派翠克的自我行銷說詞，就可以用濃縮在幾個句子：我派翠克。我一開始是醫生，但很快就決定想進入商業界。在從事企業顧問期間，我運用我的醫療經驗在法醫訓練，尤其是在戰爭衝突地區。之後，我開始對衝突地區的安全感興趣，於是我決定把一切整合成在一起，成立了一家安全與法醫公司。我現在想到新的地區發展，歡迎介紹任何在這領域有專精的人。當然他也可以只是說：「我的名字是龐德，詹姆士·龐德。」但你就永遠不會知道，他曾經是企業顧問。

## 擬訂自我行銷說詞

回到你在第六章擬好的較短版本的自傳。把這個版本的自傳當基礎，做成一份自我行銷說詞。注意，只需要幾句話，但這些句子中要包含以下的信息：

- 你的姓名
- 你在「做」什麼
- 為什麼你在這領域很有信用（例如：現在或過去的經驗）
- 你想達到的目標

重點是說明你白天的工作、讓你的兼差計畫看起來有些可行性，然後提到幾個你需要幫助的領域。記住，你是在給一個概述，以引出未來的對話。

在研擬自我行銷的說詞時，你可以實驗一下，如何把履歷表上的所有品牌整合起來。這可能包括你的大學、過去與現在的雇主，以及你兼差事業的公司名稱。對於 Wrist Tunes 的希利爾．詹寧斯來說，他的兼差事業與母校，是他行銷說詞中的關鍵，但對其他人來說，可能就會沒有那麼重要。你可以根據對象、情況，以及有用的資訊，調整說詞中的內容。這樣做的時候，你會發現，用一個強有力的說詞介紹自己的好處，是大家通常會想知道更多。當你

一旦有了自我行銷的說詞，再思考一下，如何針對不同觀眾量身修訂，例如：潛在的事業界夥伴、朋友、某個可能會介紹你投資機會的人，或是一家你想參與成為顧問的公司。針對性說詞的訣竅在於為每個聽眾想出有關的「請求」，例如：如果你是天使投資人，你要說：「我正在尋找機會，想以天使投資人的身分投資有潛力的公司。」如果你想成為顧問，你就要說：「我想當顧問，以運用我的知識與人際關係。」如果你在找事業夥伴，你也可以修改你的「需求」。放手去做，盡量直接。只要有個好的自我行銷說詞，就有足夠的動能讓你採取直接的表達方式。

## 為你的團隊招兵買馬

很多人都認為，人脈是事業成功的第一個驅動力，但經營人脈要花的时间，也會讓人震驚。從連結人脈成癮症中復原的我，很辛苦地學到這一課。我花了數不清的時間在喝咖啡、喝酒、用餐，全都是為了建立關係。這也是我自己的錯，因為我真的喜歡認識新朋友，而且我認為每次的互動都能學到東西。但是在我的職業生涯中，雖然我有很驚人的連絡人數量，但我在這過程中，浪費了很多時間與精神。沒有人教我們如何建立人脈。我們也隨著時間過去而慢慢學習，一開始是在遊樂場，接

對「你在做什麼？」的答案超過一、兩個字時，人們通常會開始感到好奇。只要你說得清楚而自信，你會發現，你很快就會被問到更多細節了。這就是在你開始要連結人、要找志同道合的人時，要做的第一個步驟。一旦你擬妥了自我行銷說詞，請不斷練習，直到你能表現得非常自信與明確的時候。另外，也可以在朋友或老師面前練習，他們都可以給你建議。

著就到了工作上的社交場合。我們很少停下來思考，所有的這一切，包括喝咖啡聊聊天、很快碰個面認識一下，以及各行各業的研討會，到底有什麼價值。一般來說，我們已經建立關係的人數太多了，但根本沒有時間好好運用。當你還是社會新鮮人或想換工作時，盡量見越多人，似乎很合理。但如果 你同時肩負很多互相矛盾 的職責，這樣做完全無法持續下去。如果後來什麼事都沒有發生，為什麼還要蒐集成堆成塔的名片？不管你是在建立蒐集案源的管道、為一個案子找投資人，或是尋找指標性租戶，建立一個能幫你完成一切的團隊，找人是很重要的環節。雖然在尋求交易時，很容易讓你有目的地建立人脈，並同時投入多個方向，但如果能更有系統地思考這件事，獲益會更大。如果能嚴謹地做這件事，你將會發現你投入的時間與精神，所得到的報酬會增加。所謂的有系統，就是從你現有的人脈開始。你的第一站就是家人與朋友。他們是最關心你的人，也隨時願意提供協助，而且你也信任他們。接下來，搜尋一下你的通訊錄，花點時間在領英或其他社交媒體平臺。然後再回到你之前已經寫好的專業自傳，再好好讀一遍，並思考一下目前或之前同事、工作上的連絡人或同學，有哪些人能幫助你。你所注意的，在目前的人脈圈中，哪一個人現在正在做的事情是讓你覺得興奮或有趣的事。如果 你可以在已經認識的人裡面找到想找的人，何必再大費周章見一大堆不認識的人？畢竟這些人也是最可能回應你的人。透過當面的會談、電話，甚至在生日聚會或烤肉聚會上的互動，就能活化你的人脈圈並創造機會。越能把這些和事業有關的討論，整合到你的其他生活層面中，產生的衝突也會越少。在每一次這樣的對談中，你可以請教別人的意見，或請求別人的引見。如此一來，你新增的連絡人也會與你認識和信任的人有關。你可以對這些對話，做些記錄或筆記重點，你就會知道這些點子與建議從何而來，之後也有可以繼續的話題。另外別忘記，這件事不能做得太自私。問一下你可為對方做什麼以做為回報，然後就可以開始建立你的人脈機制。如果透過你已經認識的人，無法找到對的人，必須和在你人脈圈以外的溝通，那麼你就是要開始進行陌生推銷了。這類行為包括：在研討會中接觸主講人、接觸一個天使得投資團體、連絡當地大學的公司加速器，或是打電話給一個你在報紙上讀到的人。根據行業或情況而定，陌生推銷也許會產生令人驚喜的結果。企業家是一群心胸特別開放的人，因為大部分的人都知道，請求別人的協助是什麼感受。這樣的同理心表示，他們也傾向會回應你。如果 你要接觸的某一個人，和你有相同的政經地位、畢業自同一所學校或專業領域，你得到對方回覆的機會也會更大。即使你與對方沒有什麼共同點，一則表達良好的訊息，以及之後的後續追蹤，也會成為對方是否回覆的關鍵。如果某個人寄給我某些吸引人的訊息，並且緊追不

捨，我通常會撥出時間見見他們。不管你是採取陌生推銷方式，或重新連絡上老朋友或同事，有幾個基本的禮節與常識要注意。很多人一天會收到數十封或上百封電子郵件，他們絕對不會想讀一封沒有重點、沒有價值的信，我喜歡把這些郵件稱為「沒營養」的郵件。當你準備要寫任何電子郵件、陌生推銷，或其他接觸對方的方法時，請遵守以下的要求點：

- 用自己的個人郵件信箱
- 熱情，但要簡潔
- 把文字寫得個人化一點
- 絕對不要寄制式信函
- 強調共同的利益或認識的人
- 提出明確的請求｜沒有人想要寫一大堆來回回的郵件，才能得知你的「請求」
- 提供任何對方許需要的協助做為回報。
- 永久要說：「請」和「謝謝」
- 後續追蹤尚未解決的事項

只要你主動連繫對方，如果一個星期都沒有得到回覆，再試一次，或是打個電話給對方。
很多忙碌的人不會在第一封請求協助的郵件就回覆對方。他們對鍥而不捨的人會回覆，但對禮貌的人則未必。當然尋求協助與惹人厭煩之間界線，在你處於非經常緊急的情況之下，可能會有点模糊。如果 你試了幾次，對方還是沒有回覆，那就試試下一個人選吧。他們不是太忙，就是對你不感興趣。不管是哪一種原因，他們並不想成為你的團隊。另外，未來有一天，如果你考慮用一樣的方式打發某個人，不妨回頭想想自己被這樣對待的那一刻。
這類嘗試會成功的原 因，通常是你 在請求協助時，對方願意對你表示善意。如果 你需要對方的幫忙，盡量把你的請求說得讓對方覺得自己有點責任。你讓對方越容易幫助你，對方就越可能即使提供協助。例如：你希望對方幫你介紹給某個他認識的人，你的郵件要寫得很簡潔，但要說明這個請求的來龍去脈，還要包含相關的資料。要運用你的自我行銷說詞，讓對方很清楚，你的態度是很認真的。一旦對方願意協助，針對每一個你想見的人，都要寄一封獨立、明確的訊息給對方。盡量讓別人要轉寄你的信，並附上自己的評語時，做起來非常

容易。另外，如果你想介紹兩個可能有共同利益的人認識，一定要先做之前，詢問對方的意願。介紹兩個陌生人認識，可能會很快把好意糟蹋掉，造成傷害可能比疲勞轟炸的沒營養郵件更大。
這些努力要花點時間才會開花結果。因為你正在建立一個機制，你為了讓它發揮效果而投入的能量越多，它就會越活躍。這包括要花這些時間讓一切有條理。例如：你可以整理出一個資料庫，讓你可以記錄在兼差事業中連繫互動的人。這需要前期時間投資，但會成為一個很有用的工具，未來想做什麼事，都會用到。採取有系統的方式做這件事，會讓你更有效率，也會讓你的機制啟動。Silvercar的彼得．巴洛經常會發很短的郵件，給他人脈圈中的五個人，就是為了保持連繫。他以非常嚴謹的態度來經營人脈，這樣做也讓他的人際關係永保如新。
要和人建立關係，訣竅就是要親臨現場。如果你不知道要從何開始，不妨去參加各種擴展人脈的場合，就可以很短的時間內見到很多人。如果你已經準備好你的自我行銷說詞，這種場合就值得你花點時間，因為這些場合通常會聚焦在明確的專業利益。全世界一百八十個國家中，有超過二十萬種讓人認識的聚會，參與其中的人超過二千二百萬人，聚會的主題各式各樣，也超出你的想像。這些也只是你在你的社群中，可以找到的正式與非正式聚會

## 針對明確的問題，找到明確的答案

人脈的力量，不會在招募一群團隊成員之後就停止發揮作用。人脈的力量還會延伸到盡職調查，也會讓你的事業更成功。對於你已經知道的事，你要有信心；對於不知道的事，則要謹慎。不要害怕問題，因為沒問出口的問題，通常就是造成良好決策與錯誤決策的關鍵。所有的事實都是好的，數據也會勝過自我，所以你要找的不是別人的肯定，你的目標是評估值得你投入時間與資源的各種機會，然後你要決定如何把這些機會整合成到你的生活與職業生涯中。遇到還沒有解答的問題時，你就要運用和找專業人士建立團隊一樣的策略。在這個階段，你要為明確的問題找到明確的答案。你必須找到在某個領域比你有更多專

業知識的人，並要能夠用到他們的智慧資本。你要運用自己的商業判斷來蒐集資訊，並評估你的研究發現，但你還需要比你有更好立場做決定的人的意見。例如：如果你想了解曼哈頓的海鮮市場，就應該去找路克·霍爾談談；如果你想知道投資客怎麼看房地產業，那就應該找像法拉·罕這樣背景的人。這些主題都是無法得知的資訊，但在你進行盡職調查時，你需要找到能提供你資訊、建議與觀點的人。
在盡職調查時，你可以運用人脈圈中所有人 的智慧資本與知識。現在你已經組建了自己的團隊，你就要運用所 有專家的集體智慧，因為他們擁有你所沒有的洞見與技能。和專家進行一次良好的電話或咖啡會談，就能幫你省下時間、指引正確的方向，或讓你遠掉麻煩。你學到的每一件事，都能幫助你問正確的問題，徹底思考某個機會的商業原理，在這個過程中，也能讓你擁有需要的工具，對市場、產品與成功的前景，有更好的理解。當然你是要謹慎發展出自己的意見，維持健康的懷疑態度，避免成為盲從的羊羔。總之，在這些對談下來，你一定會變得更聰明。
既然你已經正式參與一家公司，不管是當顧問、天使投資人或創辦人，你都需要找到未來可以幫助你、擁有特殊才能的人。現在你已經成為一家新公司的夥伴，真正的 工作才正要開始，當你在找某些特定的知識或技能時，知道要打電話給誰，真的非常重要。甚至你在建立一個蒐集案例源和盡職調查的團隊時，也可以從相同的團隊中找到有相關才能的人，他也許可以以全職、兼差或彈性的參與方式，加入你的事業團隊。經營事業需要各式各樣的協助，在特定時間內，知道要去哪裡找對的人，就是一項很Invaluable的資源。這可能包括知道特約工作者、退休或半退休人士、在家的爸爸或媽媽、學生，或正在換工作或找工作的人。這些人 可能就是實際捲起袖子做事、讓你的投資更成功的人。對於想要控制成本的新公司，這些人 也是非常有價值的人力資源。如果 你手上有一群身懷特殊技術的特種部隊，你一定會成為各界爭取的熱門對象。幾年前，我在一個社交場合認識湯瑪斯·卡雷（Thomas Quarre），他是手機介面與產業品 程師。他在自 我介紹時我才發現，我以前從來沒有認識過任何設計手機關用程式的人，我們當天的對話也一直留在我的腦海中。他後來和我持續保持連繫，每幾個 月就會連絡一下，而 且 總是會問我是 否有他可以協助的地方。後來有個朋友問我，是否認識專精於介面設計的人，我就知道要打電話給誰了。當時我甚至無法評論湯瑪斯的工作，所以我建議他們兩人直接碰面，以評估他的工作履歷，並看 看 雙方是否投緣。雙方談得很愉快，於是就合作了。幾個月後，又有人問我類似的問題，我又推薦了湯瑪斯一次，但這一次是基於他對我朋友公司的貢獻。從那之後，湯瑪斯已經和我人脈圈中的幾個朋友合作。我很感謝他從沒忘記

## 利用網路建立信用

問我，他能為我做什麼以做為回報。他似乎很自然就理解到，和我或和我人脈圈中的人合作，是是一種互利互惠關係，不管是天使投資人、顧問或只是志同道合的團體中的某個人，所以以我很快就會推薦他。我在這樣做的時候，不只是幫助了一個有才能的工程師，也是為我投資組合中的公司增加價值，並強化了我與夥伴和公司團隊的關係。

你不會只穿著內衣就跑去參加社交活動，所以你也必須確認關於線上的社交活動，也要有適當的裝備。藉由加強你的線上信用，更可能提升有意義的連結。至少至少，這表示你在領英的個人檔案要包含所所有的證照。你的領英檔案要以你過去完成的工作做為基礎，以形成你自傳，內容要協調一致，並提供個人經驗與志向的脈絡說明。讓過去的成就就說明一切，是非常明智的事。基於某些理由，人們似乎樂於沉浸在網路上大量的誇張資訊中。但如果你是比爾．蓋茲（Bill Gates）或歐普拉（Oprah），說自己是「有遠見的企業家」（這是大 家最喜歡的說法）並無不妥，但對其他九九．九九％的人來說，這種說法就太誇張了。因此最好

讓你的經驗與自傳說明事實就好。如果寫得正確，別人會更認真地對待你，而你想傳遞的訊息也會順利送出去。
如果計畫推出一個強勢品牌，做為你的兼差事業，就可以更進一步，在網路中切出一個屬於你的角落。一般人通常會對網路上看到的訊息信以為真，所以如果你在某個特定領域能加強信用，會更有效果。目標很簡單：任何人只要Google一下你的名字，你就會出現，並且是在某個領域的權威。這就是所謂的谷歌檢驗。不管你是從部落格開始、為專業刊物寫文章、發特短信、在研討會上演講，甚至在電視上出現，所有的活動都會建立信用，強化你的個人品牌，也能說服其他人，和你見面是值得花時間。
我在實際嘗試之前，一直很懷疑這個做法。我以前三不五時Google自己的名字時（承認吧，你也會這樣做），我會找到有關雀巢普瑞納（Nestlé Purina）前執行長派翠克·麥金尼斯（Patrick McGinnis）各式各樣的資料，卻很少有我個人的資料。我決定讓自己的名字成為名片中最重要的品牌之後，我也決定要更新我在網路上出現的形象。我的第一步就是寫個人部落格。我開始寫我有強項的主題，然後寄出幾篇文章給赫芬頓郵報（Huffington Post）。這算是第一次陌生活銷的行為了，對方後來也邀我為他們寫稿。我也用免費的線上工具，用自傳設立了一個網站，並開始為其他線上刊物寫和我興趣相關的文章。從那之後，只要我

用陌生成銷售的方式接觸到某個人，我就可以選擇附上一篇相關部落格貼文的網址，或是我的自傳網址。我也發現，回應我的郵件請求的比率也因此大幅提高。如果你現在 Google 我，你會找到各式各樣來源的連結，這些資料全部加起來，就 يمكنك知道我很多事。來自普瑞納的派翠克·麥金尼斯，似乎不再是鎮上唯一的派翠克·麥金尼斯了。你有很多想在某個特定領域公開宣稱你的興趣，要看你對宣傳兼差事業的自在度而定。你可能 會選擇把線上形象和兼差事業獨立開來，也可能基本上想維持線上的低知名度。無論如何，當你在對別人介紹自己時，還是有幾個基本步驟可以加強你的信用。只要在時間與金錢上小小的投資，就可以買到網域名稱、設定「公司」郵件、訂購名片，甚至把商標設計交給群眾外包。這些資源大部分都免費或很便宜，但會讓一切看起來有如天壤之別。由於這些做法都非常容易，所以我每次收到的名片上印的電子郵件是 hotmail 信箱、看起來也没什麼價値時，我都會有點意外。當改善這一切是這麼便宜而且容易時，為什麼要讓自己看起來像個業餘的角色？
