# 堅持本業

你可能會發現，公司願意讓你用比較彈性的工時工作，讓你可以在新事業上投入更多精神。

藉著發揮強項，你要專注在你了解與喜愛的領域，以及能與你的其他生活結合在一起的領域。這個策略的一個明顯好處是你會比較有信心，因為你不是從脫離專業領域太遙遠的地方開始著手。你就可以集中注意力，並避免錯誤的恐懼以及最佳選擇的恐懼所帶來的危害。
當然要做一件完全和核心能力無關的計畫，並沒有什麼錯。你可能想出一個很棒的點子，而旦和你目前的人生沒有任何關係，然後勇往直前，並大獲成功，這並不是完全不可思議的。
