+   - 用自己的個人郵件信箱
- 熱情，但要簡潔
- 把文字寫得個人化一點
- 絕對不要寄制式信函
- 強調共同的利益或認識的人
- 提出明確的請求｜沒有人想要寫一大堆來回回的郵件，才能得知你的「請求」
- 提供任何對方許需要的協助做為回報。
- 永久要說：「請」和「謝謝」
- 後續追蹤尚未解決的事項
