# 針對明確的問題，找到明確的答案

人脈的力量，不會在招募一群團隊成員之後就停止發揮作用。人脈的力量還會延伸到盡...職調查，也會讓你的事業更成功。對於你已經知道的事，你要有信心；對於不知道的事，則要謹慎。不要害怕問題，因為沒問出口的問題，通常就是造成良好決策與錯誤決策的關鍵。所有的事實都是好的，數據也會勝過自我，所以你要找的不是別人的肯定，你的目標是評估值得你投入時間與資源的各種機會，然後你要決定如何把這些機會整合成到你的生活與職業生涯中。遇到還沒有解答的問題時，你就要運用和找專業人士建立團隊一樣的策略。在這個階段，你要為明確的問題找到明確的答案。你必須找到在某個領域比你有更多專

的活動更了解之後，也可以增加明確的細節。這些資訊可以包括專業領域、活動地點或產業重點。如果你在生活中的其他場合遇到新的人，或是為了兼差事業透過陌生接觸連絡到某個人，也把他們加進你的資料庫，並寫一下你可能會有合作的方式，並標記任何要後續追蹤的事項。
