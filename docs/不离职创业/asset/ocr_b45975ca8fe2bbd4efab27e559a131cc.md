# 讓名字成為名片中最重要的品牌

在召集團隊、打造機制之前，你自己要很係理。你即將要和很多 人談話，所以為了讓每一個人的時間都用得很有效率，你必須要能清楚說明你是誰，你的目標是什麼。回想一下第六章，你寫了一份專業自傳。你當時可能不了解，其實你是在對自己做盡職調查。你是在用一種一致而可以理解的方式，把你職業生涯的一切寫出來。現在這個練習可以進入下一個階段，請思考一下，這對你的品牌與你對別人的建議，有什麼意義。

你應該還記得，我提到我一開始在做兼差事業時，我的自我介紹做得很差勁。在我把我的故事搞清楚之前，我傾向仰賴隨機的活動與靈感當話題，結果所有人都感到困惑，包括我自己。我從經驗中學到，你投射到世界的形式，就大致上是別人看你的方式。因此你需要一個強有力的行銷說詞。如果你在幾個句子內，就清楚說明你的專長以及你想做的事情，你就能掃除大家的困惑，並投射出自信、有信 用與使命感給你周圍的人。再回頭看看在中國創業的美國年輕人蓋文，很顯然他的自我行銷說詞很成功。他為每一位潛在的投資人裁切客製化的訊息，這一個行動突顯了，他已經知道某個人將會如何影響他的公司。這是一連串研究、反省與很多練習的結果。
