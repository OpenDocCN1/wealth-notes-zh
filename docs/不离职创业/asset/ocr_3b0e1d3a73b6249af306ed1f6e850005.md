# 不同類型的兼職創業，有不同的資源組合

顧問而不是天使投資人，可以讓你不必掏錢出來承擔風險，也能參與公司的決策。即使你在某個階段決定要成為天使投資人，還是可以考慮擔任顧問，以增加你在這項投資的利益。這樣做，會讓你的錢更有價值。

讀到這裡，你可能會以為自己沒有什麼資源，或覺得自己太忙，根本分身乏術，或者沒有可以投資的財務資本。但別因此而氣餒。你可以在接下來的幾章，好好想想你的資源，並讓你的每一項資產發揮出最大的效果。你可以針對自己的特殊條件，為自己量身打造並研擬實務的策略。不過在埋頭研究細節時，也值得用較寬廣的角度好好思考一下，你所擁有的資源會如何影響你的選擇。接下來，你將看到每一種不同型態的兼職創業家，就代表不同的時間、財務與智慧資本的組合。
