# 你的資源：時間、金錢、智慧

資訊，也無法預測未來，你現在就可以採取步驟，做些準備。評估一下你可以發揮的資源，
然後做出一個行動計畫，你就能面對未來的每次交叉路口了。

就像任何創業家一樣，要根據你的條件，決定有關的兼差資源。你要把稀缺的資源延伸利用、平衡取捨，然後隨時因應調整。

第一，你要考慮，對於你的營試，你能投入多少時間。

這些地方。另外，你也知道，投資幅度會隨著時間自然演變。
