# 如果你想成為天使投資人……

如果你擔心的是時間問題，因為你平常就很忙，或沒有固定的工作作息，那麼成為天使投資人是一種非常高度彈性的參與形式，也能發揮很大的功效。創業家在理想上會找「聰明的錢」，也就是不只投入現金的投資人，但你實際上的投入程度完全由自己決定。根據你對這個案子的興趣，你可以培養自己和這家公司、這家公司的經營團隊，以及其他投資人的關係。這樣一來，你會有更深入的了解，也會建立更深的人脈關係，這對你的未來很有好處。你也可以藉此創造機會，承擔較正式的角色，或成為顧問，以增加你的有利情勢。不過你寄出支票後所做的每一件事，都是可以選擇的，如果你沒有很多時間可以投入，就不需要這麼做。
