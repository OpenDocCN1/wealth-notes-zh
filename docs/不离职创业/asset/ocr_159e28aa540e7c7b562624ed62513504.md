# 最後決定清單

如果你正在做最後決定，你可以再看一下整個盡職調查程序的問題：

+   - 公司的定位是否成功？
- 你的投資是否可以得到豐厚的報酬？
- 合夥人是否具備應有的能力與操守？
- 各方的誘因是否一致？
- 你是否能對公司產生有意義的貢獻？
- 你是否能為未來的機會建立人脈、培養智慧資本？

永遠要謹記在心，這是一個過程，你會從中學習與改善，甚至也會犯一點錯。只要你有經驗，就會看到更多的機會，見到更多的人。即使你決定跳過，你也永遠不會知道未來會發生什麼事。創業家也會有所學習，某個人的點子現在也許不太對，但下一回也許就是熱門的生意。所以如果你決定跳過某個案子，你還是可以把這次互動，看成一個跟上未來的機會。
