# 想知道未來的目標，先回顧過去

當你一直在相同的行業或角色工作一段時間之後，你會忘記你每天都在做很多事其實是非常特別的事。如果你和一千個很會用試算表的人，坐在同一棟辦公大樓裡，你可能會忘記，在這棟大樓以外，有很多人覺得試算表很難。某些你曾經很努力才學會的技能，有一天卻覺得很稀鬆平常，是很有的事。如果有一天，你脫離自己的社群，離開自己的日常界線，你就會發現，別人不會把你會的技能視為理所當然。律師對會計師能憑空做出一張試算表，覺得很了不起。會計師卻對設計師能憑空想出可以結合機能的點子，也驚嘆不已。同樣表現可以延伸到很多行業，例如：資訊科技、行銷、藝術、木工，以及任何需要專門技能的領域。在零機會成本練習中，你花點時間擺脫日常生活框架，盡量探索「想做什麼？」的問題。現在你要把這一長串清單縮小，聚焦在能發揮強項的領域。因此你要再回答另一個問題：「你擅長什麼？」這就是你的智慧資本所在。雖然大部分的人在寫履歷表時，會把所有的工作經驗都寫出來，但精確找到並整合計你的專長，特別是你的智慧資本所在，可能比想像中困難。我開始成為兼職創業家時，就覺得很
