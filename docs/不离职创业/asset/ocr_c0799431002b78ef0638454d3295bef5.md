# 你的角色

這個事業是否符合你自己設定的兼差計畫條件，因此你能(1)對公司產生有意義的貢獻；(2)為未來的機會建立人脈、學到經驗與智慧資本？

在你的兼差計畫中，你會非常興奮、非常投入，而無法任由它自動運作。你會做這件事是因為你想學習、建立新的人脈，為自己打造一點什麼東西。你在場邊觀看的時間已經夠久了，這是你著裝上場比賽的機會。 不管我在一個新事業中承擔什麼角色，我通常無法滿足於只是一個開支票的人。只要在我能直接增加價值的地方，我才會覺得血脈賁張。當你是兼職創業家時，你可以提供建言、建立人脈，或幫忙解決公司每天都要應付的各種問題，因此你的參與才會讓公司更有價值。這樣做的理由有三點，每一點都和你的自身利益有關。第一，如果你無法做出顯著的影響， 提升公司成功的機會，就該合理懷疑你是 否夠了解這家公司的業務。第二，如果你無法協助這個團隊，你要如何建立有意義的人際關係，讓他們以後還能提供你更多的機會？你又如何種下未來的種子？第三，採取積極主動的角色，讓你可以建立行動的記錄與風評。如果
