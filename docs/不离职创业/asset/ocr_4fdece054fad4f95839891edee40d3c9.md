# 3
找出專長與智慧資本的領域

真對待，也希望盡可能有效率地運用每一個人的時間。因此除非你正在找工作，否則不要把履歷表寄給每一個人。所以你需要別的方法清楚表明，你有貨真價值的東西可以貢獻，因此才能脫穎而出，並省下詳說明技能與經驗的寶貴時間。準備一份自傳，你可以從電子郵件寄出去，或到網站貼出來，例如：貼在領英。在自傳中，你可以說明你的過去，並強調你的成就不必覺得不在或尷尬。自傳會為你說明一切。

最重要的是，準備自傳對你大有好處。雖然告訴其他人你的強項在哪裡很重要，但你也特別需要為了自己，把自己的故事情楚。藉由後退一步看，你可以評估一下你的過去，然後想想看，那對你的未來有什麼意義。當你回溯這個思路、這個主題，以及你擁有智慧資本的領域，當你要利用你的智慧資本，並應用在你的兼差計畫上時，就知道該怎麼思考。為了你所成就的事感到自豪，並不為過。偶爾停下腳步，記得自己一直做某一件可以反映出自己努力與才華的事，是一件很好的事。因此不妨定一下，你認真努力過的一切。第一次坐下來寫自傳時，你可能會發現，已經忘記很多以前做過的事了。
