# 1 天使投資人 — 需要一定財力

人。業餘創業家是以創業做為工具，以探索自己熱衷的事物；雙重創業家本身已經是全職創業者，成為雙重創業家的主要目的，是要讓自己的投資更加多元化。

創投公司或許仍然是矽谷的老大，但不是只有他們才有資格玩創投的遊戲。現在這個時代，成立一家公司所需要的資金越來越少，多數的創投資本家都沒興趣為了一張小額支票而起床，這時候，我們的機會就來了，像你我這樣的獨立投資人，就成了這些新事業的重要資金來源。這樣的投資者就稱為天使投資人，知名企業包括：谷歌、支付寶（PayPal）、星巴克（Starbucks）和家得寶（Home Depot）的第一批支持者，都是這樣的投資人。光是在二〇一三年，超過三十萬名的天使投資人挹注了大約二百四十一億美元的資金，幫助了七萬三千四百家公司，比起前十年，成長了大約六〇%。對許多人來說，成為天使投資人理所當然是成為兼職創業家的第一步。我就是這樣。剛開始的時候，我其實不是很確定該怎麼發展副業，但我很確定一件事：我想開始。我把心中渴望告訴朋友和業務上接觸到的人，於是他們開始和我分享各種投資的機會。有資金需求
