# 2
杜絕噪音，要專注

們是神聖不可侵犯的公司財物，所以要克制想挪為己用的誘惑。另外，不要做任何觸犯公司原則的行為，也不要違反公司合約的工作條件。

如果可以的話，不妨想想臉書、推特、Youtube、網飛（Netflix）、部落格、電子商務網站、線上報紙、簡訊，甚至電子郵件出現之前的日子。現已已經很難記得，我們在那麼多的空間時間裡，都在做什麼事。美國人每星期平均大約花二十三個小時在電子郵件、簡訊、社群媒體、以及其他線上通訊的工具上。1 英國、印尼、菲律賓、中國、巴西、美國、奈及利亞、哥倫比亞、泰國、沙烏地阿拉伯、南非、捷克與俄羅斯的民眾，不管是電視、電腦、手機或平板，一天至少花六個小時盯著螢幕看！2
