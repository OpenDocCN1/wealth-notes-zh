# 2
篩選

一日手上有了一個或多個投資機會時，下一個步驟就是找出有沒有任何符合你的目標與資源的案子。根據你在這本書前面做的功課，你就能判斷它們是否符合你為兼差事業設定的條件。這個階段就叫篩選，這是縮小範圍的第一步。你要思考的是某個機會和你的資源，也就是你的時間、金錢與智慧資本，如何搭配一致。基本上，你要問自己兩個問題：

找到最初的案子後，你就停不下來了。在下一章你會看到，蒐集案源是一種連結人的活動。只要建立蒐集案源的管道，你就會一直注意新動向，繼續和很多人談事情，同時產生出一堆潛在案源庫，接著就會進入投資程序，在每一個階段縮小聚焦範圍，直到留下最好的案子。目標是盡可能聰明地投資你的時間，所以要在接下來的投資程序中縮小範圍。在蒐集案源時，案源庫越大越好，找到真正絕佳案子的機會也會越大。如果你發現，自己忙得焦頭爛額，而無法及時評估或回覆潛在的機會，就該放慢腳步一段時間的時候了。不要因為沒有回覆或不可靠，而讓帶給你案子的人離你遠去。
