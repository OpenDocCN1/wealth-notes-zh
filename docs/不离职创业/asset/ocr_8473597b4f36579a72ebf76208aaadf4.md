# 你的夥伴

從投資人到經理人，你的夥伴是否具備應有的能力與操守？各方的誘因是否一致？

的喜悅。一旦完成這些功課，你就可以評估，和風險相對起來，這個機會是否還有吸引力。如果 你支持的是一家創業初期的事業，執行的風險比較高，你就必須確定，如果公司成功，你可 以得到非常大的報酬，例如：是投資金額的五倍或十倍，或甚至更多。不妨想一想，如果你 投資一個高風險的事業，你得到的報酬只比本錢多一點點，而創辦人則拿著好幾百萬元，拍 屁股走人，你會做何感受。你承擔了很大的風險，而創辦人卻得到所有的好處。從另一個 角度看，如果你投資的是一家已經很穩定且低風險的公司，也不要期待你的投資會賺到十倍 的報酬。在盡職調查期間，你要和公司創辦人坐下來，了解他們為你預期的報酬，以及他們 對自己的報酬的期待。如果你是創辦人，你就要確認，潛在的有利情勢是否符合你投入的資 源。然後再判斷，未來的報酬是否能彌補公司的風險。如果可以，你就可以進行下一步，評 估你的夥伴。
