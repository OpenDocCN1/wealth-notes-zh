# 如果你想成為創辦人：...

如果你想當一家公司的創辦人，你就要有心理準備，你必須投入自己全部的資源。當你成立一家公司，你必須撥出時間研究市場、培養關鍵的人際關係、開發產品，然後推展公司的業務。所有的這一，將會運用到你的人生經驗中得到的所有智慧資本。雖然很多現代公司的基本營運工具並不昂貴，但還會有一些持續的成本，特別是你持續在運作的時候，所以你最後可能還是要投 資一些財務資本，以支付基本的開銷。

也因此她可以在這段期間內同時得到很多公司的股權。很多顧問是在公司還在點子的發展階段就投入了。他們在公司的創立初期就投入，是為了提供信用與支持，讓公司在外面籌措資金時，讓別人知道公司內部有很多重量級的專業人士。在這種情況下，當公司募到資金時，你可以考慮要求投資的權利。如此一來，顧問這個身分，也就自然而然成為天使投資人的跳板了。另外，由於你自己已經參與其中，你有得知該公司是否做得成功的有利位置，因此根據你所掌握的內部消息，就可為自己創造更多的報酬。
