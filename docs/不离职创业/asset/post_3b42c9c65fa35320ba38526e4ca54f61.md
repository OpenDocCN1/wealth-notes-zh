
# 每天撥出10%的時間

## 1 讓時間更有價值

我認識的每一個兼職創業家都會提到時間，也有運用時間的策略，也希望能有更多的時間。

不管已婚、未婚，在家照顧小孩或一邊工作的家長，都會找出個人與工作職責的平衡。

無論如何，一天二十四小時是全球標準，一點也無法改變。所以不管你是史蒂夫．賈伯斯，還是懶鬼史蒂夫，都只有一樣的時間分配給所有想做的事情。

要謹記在心的，10%是一個目標，但它更像是一種心態。所以當我在建議你，應該為你的副業每天撥出10%的時間，為了撥出這些時間，你就必須做判斷。有幾個撥出時間的方法：第一，在一段固定時間內達成多重目標；第二，排除和優先事項不一致的事；第三，大致就像派翠克做的事，先以現有技能為基礎，找出相關的活動，接著做出整體目標。

越聰明運用時間越好，所以思考如何找出更多時間，是兼職創業家最重要之事。你可能很習慣一次做很多件事，把每天塞進更多活動，或為了某一件事而縮短另一件事的時間。但

注意，開車時不要傳簡訊！我並不支持多工哲學，我必須專心把事做對，並喜歡這種做事的方式。但我也認為同一段時間可以達成多重的目標。其中的訣竅就在於把需要深度思考的活動，結合被動性質的活動，例如：摺衣服或在健身器材上運動。如果你有工作要專心處理，打電話連繫的事就可以在通勤或午餐，或下午喝咖啡時再做。在你可以為自己做點什麼事的時候，為什麼要把寶貴的時間浪費在聽廣播、玩手機遊戲，或聊辦公室政治等老話題？你也可以在晨跑或淋浴時，好好組織你的想法，或是在孩子的學校遊樂場中，為了新的機會，和其他家長連絡感情。這一切的活動都對你的兼差計畫有幫助，還能無縫接軌到你的生活中心。我認識一個傢伙，會一邊遛狗一邊聽有關石油與天然氣的播客。當他帶著狗在街上到處晃的時候，還很努力跟上能源產業的趨勢。值得提醒的，很多人在每天在辦公室中，其實都花很多時間等待，或是待在沒完沒了的會議中。雖然過去二十年來，職場效率有很大的進步，但大部分的人每週至少還是花了四十個小時在工作上。這表示在辦公時間內，應該可以完成更多工作。我在華爾街工作的前幾年，變得非常熟悉「露臉時間」（face time）的概念。露臉時間是老闆在離開辦公室前，不管員工實際上沒有事要做，都應該坐在位子上的 一種沒說出口的普遍預期。遺憾地，在大部分的公司裡，這已經提升到一種藝術形式。我曾經有一個總是工作到很晚的同事，他經常在半夜十二點之後發郵件。在我們其他懶蟲都呼呼大睡時，他竟然願意工作到那麼晚，讓我們一票老闆們印象深刻。我對他驚人的工作態度深感敬畏，直到多年後的一天，我才知道，原來他是有預設電子郵件在晚上隨機發送的習慣。我這才了解，原來他是個「虛擬」露臉的高手。你可能會猜，派翠克一定不常露臉。其實他在從事顧問工作時，會提供更有價值的服務，因此他的同事沒有人會質疑他投入的時間；但因為實在有很多人事要做，他還是要浪費很多時間出現在辦公室。根據工作屬性，企業也許會非常願意根據工作成果，而不是工作時間付員工報酬。既然在深夜或週末回電子郵件時，也不會有加班費，所以為什麼不在每天的工作時間中，為兼差計畫找出更多時間？這就是本書提到的很非常忙碌的人，即使已經有非常高度投入的工作，仍然能經營兼差事業的原因。智慧型手機就是一個可以隨身帶著走的辦公室，你可以找出幾分鐘寫幾封郵件、打幾通電話，並在上班時間搞定日常的工作。很重要的一點，也值得特別強調的，當你花時間在處理兼差事業時，絕對不能跨過一條紅線—必須永遠把白天的工作放在優先位置，尤其是在上班時間時。畢竟這是一開始讓你可以從事個人事業的基礎。這份工作讓你的生活穩定，也讓你有投資自己的現金流量。如果你在班表現不佳，你的兼差計畫與其他的90%，全部都有風險。不值得冒這個險，這也不會是你想要的運作方式。要尊重你的公司，以及公司提供的工具，包括公司的電子郵件。它們是神聖不可侵犯的公司財物，所以要克制想挪為己用的誘惑。另外，不要做任何觸犯公司原則的行為，也不要違反公司合約的工作條件。

如果可以的話，不妨想想臉書、推特、Youtube、網飛（Netflix）、部落格、電子商務網站、線上報紙、簡訊，甚至電子郵件出現之前的日子。現已已經很難記得，我們在那麼多的空間時間裡，都在做什麼事。美國人每星期平均大約花二十三個小時在電子郵件、簡訊、社群媒體、以及其他線上通訊的工具上。1 英國、印尼、菲律賓、中國、巴西、美國、奈及利亞、哥倫比亞、泰國、沙烏地阿拉伯、南非、捷克與俄羅斯的民眾，不管是電視、電腦、手機或平板，一天至少花六個小時盯著螢幕看！2

減少分心的時間，並把這些時間配置在兼差計畫上，就會有很大的進展。如果像我一樣，浪費寶貴的時間查看郵件、瀏覽網頁、收發簡訊，這一切都會犧牲你的生產力。排除這些噪音，可以幫助你專注，變得有條理，也能找到做事的時間。你不必把自己關在隔離的房間才能專心，但必須好好花時間在你的事業上。這表示你要減少看電視的時間、關掉手機、電腦不要顯示通知，如果可能的 話，午餐時間還可以離開辦公室，找個安靜的角落做自己的事。要優先處理的事還包括健康。大家會一直提醒你，別把健康視為理所當然，但如果 你頂多只是得過嚴重的流感，你可能無法想像，當身體不聽使喚的時候是怎麼回事。如果 你生病了，而且是很嚴重的病，那你就是生病了，除非恢復健康，否則你很難專注在其他的事情上，更別提你的事業了。屆時你才會理解，如果你想要有足夠的身體與心理強度，以克服挑戰、追求新事業、擁抱改變，你就必須有強壯的身心。把自己的健康照顧好，會更有生產力，所以要吃得好、在正常的時間睡覺，也要找時間運動，這會讓你覺得精神很好，也能思考得更清楚。如果 你想要更專注，可以考慮練習靜心。只要達到精神敏銳度，一天只要安靜凝神幾分鐘，也有很大的幫助。

## 投入10%的財務資本

們很想結束計畫、糟糕透頂的狀況。他們活在一天二十四小時、一週七天，全年無休的生活，生活中塞滿了家人、旅行、寵物、嗜好，以及其他讓人生忙碌又有趣的事。但他們也只是凡夫俗子，也必須在一天二十四小時內搞定一切。所以如果你覺得生活已經失控，千萬別絕望，你絕對有改變情況的力量。

時間有時候很難估算，但金錢則很直截了當。我第一次決定要投入一項兼差事業時，是因為這樣的投入程度，讓我感到非常自在。因為我投入的是時間，我覺得十分之一也代表著一種有意識但謹慎的資金投入。直到一段時間之後我才了解，我的「膽量」配置也剛好符合市場。根據考夫曼基金會⑦，一般的天使投資人會配置10%的財富在新創事業上。³即使你的錢很少，或根本沒有錢可以再撥出來，投進你的兼差計畫，在本書中，你還是可以看到相關的案例研究與策略。只如果你有錢，一定會有更多機會。因此終極目標是投

入你的部分財務資源到兼差事業上，理想上最少要有10%。你可以把這件事情想成是什麼稅。但⑧但是有了這筆錢，受益的將是你整體的財務多元化與未來。記住，你現要做的是長

投資除了能產生財務回報，也可以讓自己多元化，不只是工作多元化，也和你的其他技巧能組合有關。對很多人來說，人生最重要的投資就是房子。紐約大學最近一個研究顯示，美

所以要撥出部分財務資本，在實際上要怎麼做？在日常生活中，管理金錢大致上就像管
理時間，都是在做選擇。檢視一下你平常怎麼花錢，並把儲蓄拿出來投資，就就可以擬定財務資本的計畫，如此一來，也許是今天，或是有朝一日，你也可以開始投資自己的副業。
即使是小錢，各種開銷加起來的速度是很驚人的。美國人一年平均花在咖啡的錢超過一千美元，花在酒精類飲料的錢大約占收入的1%⁵、到餐廳用餐的費用也超過收入的5%⁶另外，有線電視的成本，一年也超過一千二百美元。當我收到有線電視一個月二百美元的帳單時，因為我很少在看這些頻道，就決定不再續約。我把這筆錢存到我的兼差計畫資金。比起在數十個頻道中尋找值得看的節目，對我來說，打造兼差計畫更有樂趣。
存錢並不是要你大幅改變日 常的生活，並排除所有的生活樂趣，但你的確必須撥出某些現金，也許是從現有的存款與投資中撥出來，或者減少開銷，以存到更多錢。⁷假以時日，你的財務資本就能形成一種離散投資（discrete investment）的組合，任何產生的獲利，也能經常再做投資。為了啟動儲蓄與投資的程序，你必須了解自己目前的財務狀況，以及存錢的能力。

兼差計畫的主要目標是創造有利情勢。如果以天使投資人的身分投資，就是用現金投資在有前途的公司上，這些公司的未來預期會有利。那麽在投資報酬率上，可以期待什麽？考夫曼基金會根據一項長達十五年、大約一千二百件投資項目的天使投資人報酬率研究中發現，以投資組合來看，在三年半的時間內，投資人可以賺到投資金額二．五倍的報酬。這表示每一年的報酬率約30%。另外，創投資本家大衛·泰登（David Teten）彙整了十二個研究則顯示，天使投資人可以預期每年有8%到54%的投資報酬率。8 如果你考慮到股票的長期報酬率一年大約10%，或者抱著現金一年的報酬率大約3·5%，這様的投資報酬率已經非常吸引人。9 即使對這些研究結果再打個折扣，報酬率也依 然很高。另外，經過十年之後，報酬率的差距還會繼續拉大，天使投資人多元化投資組合的投資報酬率，會比持有現金超過十倍；比持有股票超過五倍。當然這些研究紀錄的報酬率都是投資組合的報酬率，也就是說，投資組合中的某些投資案，會比平均表現更佳，或者也可 能有完全血本無歸的投資。因此謹慎的投資人在整個職業生涯上，應該要找機會做出投資組合，而不只是投資一、兩家企業。

不管你一年有五千美元或十萬元可以投資，心裡都要堅守幾個指導原則，以架構出你的投資組合。第一，雖然10%的資金就可以為你創造有利情勢，但如果會犧牲你的整體財務健康，你也不能做。永遠不要把錢投進你承擔不起的長期事業，這會有風險。這也是堅持10%原則的妙之處，不要把所有雞蛋放在同一個籃子裡。第二，長期一定要尋求多元化。為了形成你的投資組合，要在兼差計畫中努力增加不同的資產與投資案。舉例來說，如果你是天使投資人，你可以根據產業或公司的成熟度，來做不同的投資。另外，隨著時間過去，在投資組合中增加投資項目，將能促進多元化，降低風險，並提升挑到贏家的機會。投入資金之外，你也可以用顧問的角色參與。 不管是投資財務資本，還是智慧資本，都是在做投資。當然其中的不同之處，在於如果投資的是智慧資本，風險只是你的時間，而不 是你的荷包；如果你除了投資時間，也投資現金，就會發現，在同一家公司擔任天使投資人和顧問，會有非 常顯而易見的好處。身為顧問，你會和公司的經營團隊一起工作，也會讓公司更成功。不管你是以顧問或天使投資人的身分，得到公司的股票，這樣做對你的股票很有利，你也會得到最大的綜合報酬率。你的10%策略是一個多元化的工具，也是 一個和你人生中的股東討論風險的機會。每個人都想要有自主性，但不能犧牲你的人際關係。因此和其他人徹底討論你的投資策略，是
