# 4 最後決定

完成盡職調查之後，你就能決定是否進一步投入，這就是做出最後決定的階段。創投公司在做投資決策時，投資委員會會一起具體討論這筆交易的優點與風險，之後再根據討論進行投票。所以如果你不是非常肯定，或你想聽聽別人的意見，找朋友或家人談一下你揮之不去的疑慮，也很幫助。這就像你專門擁有的投資委員會。如果已經做了決定，就可以繼續進行下一步。如果對盡職調查的結果很滿意，也認為這個機會符合你的策略，就可以答應。如果這個案子並不符合你的期待，你就可以禮貌地跳過。有時候，你做的最好投資是決策，就算是你沒投資的案子。執行最後決定，並進一步投入，總是讓人有點心驚膽顫。如果你是天使投資人，更是如此，因為你投進去的是你辛苦賺來的錢。我在投資 risky 的時候，我做了盡職調查，也小心思考了公司的團隊，以及我投入的程度。一步一步跟著投資程序做，我就有充分的資訊做出最後的決定。當然我還是很緊張。最後我了解到了，我既然沒有水晶球，就必須信任自己做出的盡職調查。如果我不能投資這麽有吸引力的公司，和我已經非常熟悉的人合夥，那我可能永遠無法投資新事業。
