# 選擇對的機會：兼差事業的投資程序

現在你知道如何運用智慧資本，來判斷哪些類型orer案子能讓你發揮強項，就可開始尋找投資機會了。這時候，你可以問一下自己：我要如何找到與我相關的案子？你甚至可能有幾個想法，但懷疑自己要如何知道，這些想法是否都是好點子？這就是投資程序能派上場的地方了。這個程序會幫你思考清楚，避免一窩蜂的誘惑，或做出不符合最佳利益的決定。
