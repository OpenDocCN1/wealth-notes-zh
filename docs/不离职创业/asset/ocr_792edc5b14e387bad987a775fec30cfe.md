# 讓兼差事業成為身分的一部分

說到兼職創業家，史蒂芬·席格（Stephen Siegel）簡直就是一個傳奇人物。他是個白手起家的不動産大亨，他是全世界最大的商業不動産經紀公司世邦魏理仕（CBRE）董事長。他自稱自己是個「交易迷」，在我還在包尿布之前，他就一直做兼差事業。史蒂芬在二十幾歲的時候，就做了第一筆投資。他和兩個包袋較深的合夥人聯手，買了一家位在曼哈頓中城的飯店。現在已經過了四十年，他目前投資超過一百個案子，從不動産到餐廳，還有其他更多案子。

如果你在規劃兼差事業時，想的是數十年，而不是幾個月或幾年，兼差事業就會成為你的職業生涯與生活中，很有意義的一部份。認識史蒂芬之前，我就聽過他的故事了，因為他的兼差事業就是他個人形象的一部份。他是紐約 P. J. Clarke’s 餐廳復活的幕後合夥人之一，其他合夥人包括演員提莫西·哈頓（Timothy Hutton）與已故的紐約洋基隊老闆喬治·史坦布瑞納（George Steinbrenner）。他甚至擁有一支小聯盟棒球隊的一部份。他之前的一個客人戶決定要買這支球隊時，史蒂芬加入了這個投資團隊。長期以來，他一直十分熱愛棒球，他知道他可能永遠沒有機會擁有大聯盟球隊。擁有小聯盟球隊，雖然不是最好，也算是次好的
