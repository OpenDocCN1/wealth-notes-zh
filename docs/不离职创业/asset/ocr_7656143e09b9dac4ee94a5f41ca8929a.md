# 失敗了怎麼辦？

身為兼職創業家，你就要接受失敗只是成立公司過程的一部分。即使你最後事業非常成功，一定也經歷過很多次，覺得自己快要失敗了。創業就是實驗，因此找出什麼事行不通，通 常是判斷什麼事行得通的唯一方法。但有時候，無論做了多少實驗、努力工作與規劃，也

根據計畫建立團隊，讓你的投資程序發揮作用。只要你做到這一切，你的研究功課以及你的判斷，將會促使你思考，而你最後也會根據一個條件做決定——這個公司有沒有通過檢驗？參考一下彼得。巴洛的故事，彼得在飛機上和 Silvercar 的創辦人開始談話之前，已經失敗過兩次。他不是因為風險太大而回絕這的點子，也不是在沒做任何研究之下就愛上這個點子，而是嚴格遵守計畫。他查核了潛在合夥人的背景、花很多時間做盡職調查，並從旅行業聘了一個有經驗的創業家到董事會。 因此雖然從他一看 到這個商業計畫那一刻開始，他就很興奮，也準備好捲起袖子開始工作，但他從評估自己的資源，到啟用投資程序與團隊，還 是按部就班地遵循他擬訂的兼差計畫。
