# 如果你想當業餘創業家或雙重創業家……

做為公司的創辦人，在公司成立初期，你可能會決定自己負責營運。這種做法也可以做得很好，尤其 Experiment 投入時間應付得來、資金需求也很小的時候。不過到了某個時間點之後，需 要投入的時間與金錢都會增加。根據你的業務形態，可能需要做出產品原型、準備庫存、簽訂租約，還要僱用員工。你可以決定，如何以最有效的方法配置未來需要的更多資源，以繼續執行你的商業計畫。

遇到資源有限時，踏克．霍爾登的方法是找一位有智慧資本，也有時間投入公司日常營運的合夥人。他也找到了自己的父親，一起投資了踏克龍蝦快餐連鎖店的初期成本。另外，希利爾．詹寧斯從投資人募集到一筆資金後，仍然繼續在兄弟的協助下，自己經營 Wrist Tunes。他自己投入了智慧資本，並把設計與製造外包給在中國的夥伴公司。

做為業餘創業家或雙重創業家，你可以依適 合程度決定自己投入的架構，然後再選擇天使投資人、顧問或創業家的角色。你也可以根據自己投入的資源，結合多重的角色。舉例來說，迪亞哥．塞斯—吉爾（Diego Saez-Gil）在 Bluesmart 的角色，就同時是顧問與創辦人；使投資人、顧問或創業家的角色。
