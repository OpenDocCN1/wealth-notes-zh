# 為你的團隊招兵買馬

很多 人都認為，人脈是事業成功的第一個驅動力，但經營人脈要花的时间，也會讓人震驚。從連結人脈成癮症中復原的我，很辛苦地學到這一課。我花了數不清的時間在喝咖啡、喝酒、用餐，全都是為了建立關係。這也是我自己的錯，因為我真的喜歡認識新朋友，而且我認為每次的互動都能學到東西。但是在我的職業生涯中，雖然我有很驚人的連絡人數量，但我在這過程中，浪費了很多時間與精神。沒有人教我們如何建立人脈。我們也隨著時間過去而慢慢學習，一開始是在遊樂場，接

對「你 在做什麼？」的答案超過一、兩個字時，人們通常會開始感到好奇。只要你說得清楚 而自信，你會發現，你很快就會被問到更多細節了。這就是在你開始要連結人、要找志同 道的 人時，要做的第一個步驟。 一旦你擬妥了自我行銷說詞，請不斷練習，直到你能表現得非常自信與明確的時候。另 外，也可以在朋友或老師面前練習，他們都可以給你建議。
