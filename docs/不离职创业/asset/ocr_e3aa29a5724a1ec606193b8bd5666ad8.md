# 5
沒有失敗的本錢

貫注，將所有的時間和精力花在測試、驗證、修正、改善你的構想。在達到目標之前，唯一的選擇就是耐心等待時機。這樣的決定太重要了，所以不要把它浪費在平庸的事情上。

每隔一段時間，我就會聽到一些具有警示意味的事情。這些故事，足以讓曾經有過創業念頭的人，聽得脊背發冷。其中讓人比較印象深刻的一個故事，是關於一個男人，先姑且稱他為「霹運男」吧。他曾是一所頂尖企管學校裡的明星學生。畢業後，其它同儕紛紛投入了華爾街金融業、諮詢顧問業，或者擔任企業的重要職位，他則選擇創業之路，從此經歷一連串失敗的經歷。
