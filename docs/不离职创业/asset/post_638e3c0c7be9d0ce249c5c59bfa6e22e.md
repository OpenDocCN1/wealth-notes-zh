# 擁有自己的事業，創造有利益的機會

創業的核心價值就是擁有屬於自己的事業。你可以幫別人打工，一年又一年領了一筆又一筆的薪水，但是如果你手上沒有公司的股份，光靠薪水累積的財富是很有限的。我剛進投資公司的时候，一個同事要我坐下來，他向我解釋，身為公司的職員，公司的每一筆投資，我都能分到一小杯羹。他很認真地對我說：「派翠克，這就是所謂的」一給再給的禮物」。
我當時不太能理解他的意思。除了堆衣物和一些小玩意之外，我似乎不曾真正擁有過什麼，更別說擁有一家公司的一部分了。這樣到底有什麼好處呢？「這麼說吧！」我的同事繼續說：「即使將來你離職了，五年或甚至十年之內，還是可以收到公司寄給你的紅利支票。」這就是擁有一家公司股權的價值。只要你擁有它，它就永遠都是你的，說不定什麼時候，就會帶給你意外的好處。

當一個兼職創業家，你可以規劃出一個包含各種經濟活動的投資組合，這就是所謂的「二給再給的禮物」。如此一來，你就可以藉由其中有潛力的事業或計畫，累積經濟利益，經過一段時日之後，你的投資就能產生可觀的回報。但切記，這是一個長期性策略，不要期望能因此在短期內暴發致富。雖然有時候的確會有二、一、二筆投資項目，在短期內就產生了可觀的利潤，但那並非常態。你的目標是一邊做你喜歡的事，並在長時間後能產生真正的價值。不管是投入時間或精力以創造有利益的機會，這些都能讓你得到真正的財務回報。再拿 Bunny 的例子來看。幾年前，我遇見亞歷山大的時候，他邀我加入他的公司擔任顧問。在下一章你會讀到，顧問的工作是以投入的時間或勞力，換取公司的股權做為酬勞。交易的內容很簡單，在二年內，我每個月份花一個小時和該公司的高層主管共事，公司就給我 ○·五％的股權。我和 Bunny 的關係，建立在公司的執行長對我的信任，他們相信我能夠持續對公司提供經營策略、管理建議和人脈方面的協助。根據協議，我需要投入的時間，符合我設定的一○％的範圍內；對該公司來說，他們可以從我在其他九○％的專業生涯裡所累積到的知識、人脈與獨特觀點中獲益。這樣的共生關係，不管是對我的個人成長或財務上，都很有大的收穫。不論你投資的是時間還是金錢，持有某家公司的股權，就是讓你取得創造有利益機會的門票。如果你不曾採取任何行動，就永遠不可能有這樣的機會。以金錢來衡量，會是個怎麼樣的概念？如果你相信《經濟學人》（Economist）的估值，那麼我所擁有的公司股份，今時今日已經有將近二十五萬元美市值，而且還有很大的增值空間。以我所投入的時間和精力神來說，這樣的回報實在是相當美好，特別是以每小時為單位來計算時，更是如此。

# 讓人脈、專業知識和生活更豐富、更有趣

如果你正打算成為兼職創業家，下列這些話，你可能曾經對自己說過其中幾句：

「我喜歡我的工作，但不知道為什麼，我總覺得好像缺少了什麼。我的意思是說，我已經經達到了一直以來追求的目標，但忍不住要問自己：就是這樣了嗎？」

「一直以來，我都希望能擁有屬於自己的公司，但是在現階段，我根本不可能辭掉目前的工作，捨棄現有的一切就離開，因為那實在是太瘋狂了。但是我又不想完全放棄自己的夢想。我需要找到一個方法，能夠同時享有這兩件事的最大利益。」

「我懷念和一群創業家一起努力，一起推出新東西的感覺。我覺得只有當我跳出舒適圈時，才能表現出最好的自己，但是現在的我並不想完全離開舒適圈，在外冒險。」

「我的交遊廣闊，認識各行各業的人，我也經常協助朋友處理各種事務，但都是義務幫忙，沒有收費。一定有什麼方法，可以把我擁有的人脈轉化成錢脈吧。

「我對現在的工作已經沒有熱情，但又需要這份薪水，不能離開。我實在不想在日後心生後悔，但也不知道有什麼方法，可以擺脫現在這種一成不變的困境？」

以上的訊息，都有一個共同的主題：我們想要的更多。我們想要結交新朋友、嘗試新點子、把我們的人際關係和專業知識轉化成金錢、和別人一起協力解決問題、成為某個事業或計畫的一分子。最重要 的，不論是在專業上，還是在個人成長上，我們都希望能持續學習與成長。我的副業中的每一筆投資，帶給我的回報，早已超過金錢本身的價值。因為在這過程中，我遇到了一些很棒的人、學到了一 些很有用的技能，並且盡我所能地做出貢獻，幫助那些勇敢實現夢想的創業家，將事業做得比我還沒有參與時更成功。財務規劃公司喜歡在廣告時，一再宣揚事先做好完善退休計畫的諸多好處。如果仔細看就不難發現，在這一類的廣告裡，總是會出現一些面帶微笑的退休人士，他們一輩子汲汲營營，至此總算功成名就，也累積了豐富的人生經驗和智慧，終於可以開始真正享受生活，做自己想做的事。但每次我看到這樣的廣告，總是很不以為然，因為這樣的觀念早就已經過…

時了。如今這個時代，有誰會想等到退休之後，才去追尋自己的夢想？誰說實現自己的想法，非得要排在工作之後？為什麼不能同時並行，並且在退休後持續享有自己的興趣？

丹·戈特薩科夫（Dan Gertsacov）才不想等到退休之後，才去做他想做的事。他出生於美國羅德島州，目前定居在哥倫比亞的波哥大，在阿克多納多斯公司（Arcos Dorados，麥當勞在拉丁美洲的特許營運商），擔任數位長一職。丹熱愛生活，並且有為谷歌（Google）在哥倫比亞設立分公司的經驗，所以如果我告訴你，他也是個兼職創業家，你應該不會感到意外。他在拉丁美洲投資了數家科技、出版以及電子商務領域的公司，或是擔任這些企業的顧問。因為我們兩個都是Bummy的顧問，所以我有幸親眼看到他運籌帷幄時的英姿。

雖然丹在麥當勞的工作量已經滿載了（這不是雙關語喔），再加上副業與家庭生活，他仍然有辦法抽出時間，學習廚師的烹飪手藝，度假時也經常在行程中規劃數日參加烹飪學校的課程。在不同的烹飪學校上過不同的烹飪課程之後，丹很確定自己並不想以廚師為業。在空閒或旅行時上課、煮煮東西，是很棒的消遣，但他可不想把每天的時間都花在這件事上。面。因此他找出另一個將興趣與生活結合起來的方法，他決定投資一家叫La Xarcuteria的餐廳，這家餐廳是由一位很被看好的主廚所經營。結果這筆投資不但為他帶來額外的財務利益，也讓他的生活更多采多姿。

# 打造更穩固、更有創業精神的職業生涯

表面上，投入現職以外的事業，是以自身利益為依據。你是在運用自己的技能、人脈和知識，其中有 一部分還是來自你的全職工作，目的是為自己創造更多的機會。同時藉由接受

隨便問任何一個家長，他們都會告訴你，他們希望自己的小孩多才多藝，具備多方面的才能。但為何自身作為成人的我們，為何卻自己放棄了這個原則？你很喜歡自己動手做家具嗎？或者你總是利日週末到處攝影拍照？還是你很熱衷於室內設計？如果不必考慮金錢，你可能會以興趣做為工作的原則，但你一定也意識到了，如果在財務上無法獨立，就必須面對沉重的取捨問題。兩相權衡之下，通常安全感會戰勝熱情，這是人類的天性使然，因為很少人會願意犧牲財務和個人生活品質，只為了追求自己熱愛的興趣。但這並不代表你得完全放棄。與其蜻蜓點水式地東做一點，西學一下，或是把興趣完全擱置一邊，直到退休，你還有另一個選擇，那就是走兼職創業這條路，既可以結合個人興趣，還可以讓你以有意義、專業、能賺到錢的方式完成這件事。
