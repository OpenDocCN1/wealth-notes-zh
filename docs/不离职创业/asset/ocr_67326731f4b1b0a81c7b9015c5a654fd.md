# 1
蒐集案源

要，也不能假手他人。第一個步驟是蒐集案源，你可以建立一個得到案源的管道，這些都是你兼職事業的候選名單。接著你用篩選程序，去除不符合你的兼職計畫參數的事業。接下來，你要執行盡職調查，以評估每個機會的整體吸引力。根據你的發現，你可以做出最後決定，決定要進一步投入，還<|message|> 跳過這個機會。最後，你要藉由適當的法律文件，讓一切成為正式的投資案。

根據你到目前為止的工作經驗，當你成為兼職創業家的第一天，你就很知道自己有什麼資源可以拿來發揮。至少在開始，你也會感覺到，自己要爭取哪些類型的兼差事業。接下來你會怎麼做？一開始手忙腳亂的階段已經過去了，現<|message|> 你必須思考實際上要如何開始。你會想做第一筆投資案，見見你的第一位合夥人，或想出一個絕妙的點子，讓你很確定，它是你投入時間最好的案子。這此都是很好的衝動。你必須同時很忙碌，但也很專注，所以一點急迫感對你有好處。另外，也必須在熱情中帶點耐心來平衡一下。你並不是要盡快種下一顆種子，然後就希望長出什麼東西。你是要打造一座花園，讓你一年到頭都有花可賞。
