# 覺得卡關時，相信你的計畫

二〇一四年六月，一則訊息忽然出現在我的收件匣，發信人的名字我並不認識。這是新聞記者班·崇津格（Ben Schreckinger）寫來的電子郵件，他正在為《波士頓》（Boston）雜誌，

研究 FOMO 術語的由來，這個字也寫成「錯過的恐懼」（Fear of Missing Out）。他追

蹤到這個字的起源是我在二〇〇年還在當學生時寫的一篇文章。這是臉書把 FOMO 當成

記得兼差事業是一項持續進行中的事，也會減少一點壓力。你將不斷嘗試新的點子，檢驗你的想法，行得通的就繼續做，行不通的點子就放棄。當我接受我的兼差事業基本上是公司成立初期的那一刻，而且我是公司的創辦人時，不知為什麼，我當場覺得較自由了一點。

我有一份兼差計畫，但我不需要隨時知道所有的答案。我可以承擔風險，跳脫框架思考，尋求別人的協助，因為這就是在成立新創公司時應該做的事。當我學到更多，提升了自己的能力，我也可以回到畫板上，做些計畫的調整。帶著這份理解，當我遇到阻礙，我覺得可以更安心，也更有心裡準備堅持下去。
