# 1 用自己的話說自己的故事

如果你完全依賴履歷表找機會，就會失去自己說故事的機會。一張履歷表不過就是一籮筐的工作、技能與教育成果。但履歷表沒有來龍去脈、沒有觀點，也沒有連結這些經驗的故事，事，好讓讀者了解為什麼你會有這些經驗。如果你的變動很大、丟了一份工作，或轉到新的行業，履歷表沒有辦法告訴別人，你這些行動的理由與好處。更精確地說，你留給讀者自己去判斷。但另一方面，自傳就是你的人生故事，由你來說，也由你來架構。你可以控制訊息，所以你可以強調你認為最重要的一部分。

最後，他列出自己的強項以及明確的專精領域，因此任何在相關領域工作的人，都能想出幾個可以一起合作的方式。
