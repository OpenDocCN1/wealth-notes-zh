# 4 業餘創業家 — 讓自己的技藝充份發揮

身為業餘創業家，你會分配相當比例的時間和精力，以天使投資人或顧問的身分，甚至以創辦人的身分，投注在你熱愛的事物上。即使你只是以兼職的方式參與，你對這件事的熱愛，實際上已經遠遠超過業餘興趣，你已經不甘心只是當個業餘愛好者。舉例來說，你不想只是獨自一人在自己的車庫中吹喇叭；不滿足你用心烹調的精緻晚餐，只能讓親朋友享用。雖然你不打算把打發時間的嗜好當作工作，卻還是熱切希望能有機會，讓自己的技藝得到充分的發揮，同時還能照常工作。雖然只是一份副業，但你所需具備的專業程度已經相當於任何一位天使投資人、顧問或創辦人。不同的<|message|>是驅使你的動機是熱情，而不是單純的利益。你仍然必須具備創業家的心態，辛勞付出，才能成為一個可以自給自足的事業機會。我的文學經紀人蜜爾卓瑞德·袁（Mildred Yuan）第一次讀到我這本書的提案時，很快就抓住了這個概念，讓我非常驚訝。她告訴我，她在成為經紀人之前，是個職業舞者。她從小就開始跳舞，甚至曾經想以舞踏做為事業。根據她的說法，她是個「傳統亞洲家庭的小孩」，父母並不鼓勵她選擇以藝術維生，於是她選擇攻讀財務學。既然當職業芭蕾舞者已經變成遙不可及的夢想，她便把注意力轉移到國標舞上，這樣舞蹈壽命也會比留在芭蕾舞界長
