# 誠信至上，
尤其是面對雇主時

兼差計畫為你提供無數的好處，但不會付你薪水，所以你不能犧牲全職工作來打造兼差事業。萬一發生衝突時，毫無疑問，必須優先考慮白天的工作。因為白天的工作中繼續做得好，是你有能力從事兼差事業的主因，因為你有承擔風險的財務資本與穩定性。在工作上表

做事，讓一切成真。我希望你已經相信，現在就是著手的最 好時機。看看周遭，從別人身上學習，加入他們的團隊，然後打造自己的兼差事業。在本書中，你也許已經看見，兼職創業家並不是只有一種類型。他們遍布全世界，來自各行各業，而且每個人的背景也非常多元。其中有一個共同點，那就是這些人會尋找機會，並讓事情發生。從這一點開始，他們會承擔計算過的風險，從錯誤中學習，然後繼續改善。記住，這一章將提供你一套指導原則，其中顯示的是第一線兼職創業家的男男女女的集體智慧。這些指導原則就是你的羅盤與地圖，你可以隨時回到這一章，確定自己是否還待在正確的軌道上。
