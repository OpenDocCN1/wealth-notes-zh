# 知道看哪裡，才能找到正確答案

小時候我是個埋頭苦幹型的人，關於課業上的好成績，我的祕方只有一個：投入時間就對了。我堅定地認為只要我比別人更用功，比別人花更多時間準備，我就會表現得很好。這一個成功方式有一段時間都很有致，但到上大學之後，一切就不是我能掌控的了。我來自綿因州的一所公立高中，我真的很怕課業成績不好，白白浪費父母辛苦賺來的錢。本能告訴我，一定要過度準備。 大一新生那一年的前幾個月，我不知哪根筋決定，預讀還沒指定要讀的教科書章節，是很聰明的做法。結果這一學期的成績，是我有史以來最差勁的一學期，因為我浪費很多時間，把還沒在教學大綱中的內容，硬塞進我的腦袋裡。直到大三那一年，我到阿根廷當交換學生，我才終於學會放鬆。阿根廷人準備考試的方式法完全不一樣，我覺得有點社會主義者的調調。對我來說，去阿根廷就像去了另一個星球，而不是另一個大陸。在學期末時，班上成績最好的學生，會為每一個人 「影印一份筆記。雖然每個人的最後成績會受到個人準備程度、智力，以及考試當天的表現影響，但所有需要複習的素材，都已經由大家平均分擔了。如果有任何需要，只要知道找誰拿就好了。事業中的很多部分，其實就是找到最好的人問問題，以蒐集能讓你做出周延決定的資
