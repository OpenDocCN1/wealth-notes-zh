# 如果你想成為顧問......

過三百個這樣的團體。歐洲、亞洲與拉丁美洲各地，也有類似的團體。可以找到創業家的地 Wal , 就能找到天使投資人。事實上，距離一般創投公司營運的地方越遠，你的資金與專業就會顯得越重要。

如果你沒有那麼多資金，但有更多的智慧資本與時間，則可以考慮成為顧問。你投資的是智慧資本，而不是財務資本，你貢獻的是雙方都同意的一定時間，然後這家公司則以股權的方式付給你報酬。在實務上，預期顧問投入的時間，不同公司的差異非常大。有些公司希望顧問能穩定提供建議，一個月出席一個小時或兩個小時。他們會打電話給你，請教你策 略 略 意見或提 供 人脈，或只是單純的腦力激盪。這就是我和 Bunny 公司的合作方式，我每個 月會花兩個小時和公司的執行長與財務副董見面，並一起決定這個月剩下來的時間，我可以 用什麼方式協助公司的成長。我花的時間就差不多這樣，但每一次談話結束後，我都會留下 一份應辦事項清單，在下一次見面前，就用電子郵件保持連繫。在這樣的時間投資下，像貝絲·費雷拉這樣經驗豐富的顧問，在同一時間擔任很多家公司的顧問，也是很鬆平常的事，
