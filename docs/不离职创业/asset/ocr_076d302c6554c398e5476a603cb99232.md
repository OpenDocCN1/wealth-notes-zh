# 當鐵飯碗不再是鐵飯碗

原來，有這麼人在他的職業生涯裡，一直處於夢遊狀態。其實這也不令人意外。曾經

事實上，當今這個時代，得過且過、安於現狀的心態，在美國職場裡簡直無所不在。或許你並沒有在桌子下打呼睡覺，也不像我，選擇了一條「消極攻擊」①的路線，但你大概也沒把多少心思放在工作上吧！二〇一五年，民調公司蓋洛普（Gallup）發表一份針對美國職場的研究報告，將近七成的民眾對自己的工作，不是「沒有投入」，就是「積極地不投入」。根據我的計算，這表示全美有數以千萬計的員工，可能正處於「放空」狀態，因為他們根本就是人在心不在。

① Passive-aggressive，消極性的攻擊行為，也就是透過一些小手段，例如：說一些帶有反諷意味的話，或是以不配合的態度，來達到攻擊別人的目的。舉例來說，二人吵架，一人在被指責之後，說：「好吧，一切都是我的錯，你永遠都是對的，你滿意了吧！」
