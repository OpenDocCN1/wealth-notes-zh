
# 你的資源：時間、金錢、智慧

資訊，也無法預測未來，你現在就可以採取步驟，做些準備。評估一下你可以發揮的資源，然後做出一個行動計畫，你就能面對未來的每次交叉路口了。

就像任何創業家一樣，要根據你的條件，決定有關的兼差資源。你要把稀缺的資源延伸利用、平衡取捨，然後隨時因應調整。

第一，你要考慮，對於你的事業，你能投入多少時間。

第二，你要決定，你可以投資多少財務資本或金錢。你的目標是拿出一○％的資源放在這些地方。另外，你也知道，投資幅度會隨著時間自然演變。

第三，考慮你的智慧資本，也就是你的知識與技能符合的程度。說到智慧資本，目標是結合你做得很好與很享受的事。智慧資本是讓你能把時間與金錢投資，經營得更有生產力的要素。運用知識與判斷，你將會做出明智的決定，也將會提升成功的機會。

雖然手上的資源可能彼此沒有關連，但把這些資源放在一起，就可以把它們想像成一種投資組合。每一個成分都是動態的，所以你的投資組合也會隨著你的生活階段、財務資源、經驗水平而改變。就像所有的投資組合一樣，為了增加每一個資產的價值，同時把組合起來的價值極大化，你也需要計算賭注。隨著投資組合變大，你的選擇會變多；根據資源配置的方式，不管是各自開或整體應用，你也會有更大的彈性。如果你的投資夠明智，投資報酬率就會呈現複合式的成長，產生比各自加總起來更大的報酬。沒有人有用的不完的時間、燒不完的資金，或深不見底的專業知識，但只要有所欠缺，你隨時可以另一種資源來彌補。把資源想像成投資組合時，你可以把有所欠缺的地方（也許是資金），和你有強項或非常充分的地方（例如：時間與知識）加以調和。牡蠣灣釀酒公司的創辦人決定要維持白天的工作，並投入資金，以促使公司成長時，這些決定的意義非常清楚，他們必須以最

## 如果你想成為創辦人：...

如果你想當一家公司的創辦人，你就要有心理準備，你必須投入自己全部的資源。當你成立一家公司，你必須撥出時間研究市場、培養關鍵的人際關係、開發產品，然後推展公司的業務。所有的這一切，將會運用到你的人生經驗中得到的所有智慧資本。雖然很多現代公司的基本營運工具並不昂貴，但還會有一些持續的成本，特別是你持續在運作的時候，所以你最後可能還是要投資一些財務資本，以支付基本的開銷。

也因此她可以在這段期間內同時得到很多公司的股權。很多顧問是在公司還在點子的發展階段就投入了。他們在公司的創立初期就投入，是為了提供信用與支持，讓公司在外面籌措資金時，讓別人知道公司內部有很多重量級的專業人士。在這種情況下，當公司募到資金時，你可以考慮要求投資的權利。如此一來，顧問這個身分，也就自然而然成為天使投資人的跳板了。另外，由於你自己已經參與其中，你有得知該公司是否做得成功的有利位置，因此根據你所掌握的內部消息，就可為自己創造更多的報酬。

## 如果你想當業餘創業家或雙重創業家……

做為公司的創辦人，在公司成立初期，你可能會決定自己負責營運。這種做法也可以做得很好，尤其時間投入應付得來、資金需求也很小的時候。不過到了某個時間點之後，需要投入的時間與金錢都會增加。根據你的業務形態，可能需要做出產品原型、準備庫存、簽訂租約，還要僱用員工。你可以決定，如何以最有效的方法配置未來需要的更多資源，以繼續執行你的商業計畫。

遇到資源有限時，踏克．霍爾登的方法是找一位有智慧資本，也有時間投入公司日常營運的合夥人。他也找到了自己的父親，一起投資了踏克龍蝦快餐連鎖店的初期成本。另外，希利爾．詹寧斯從投資人募集到一筆資金後，仍然繼續在兄弟的協助下，自己經營Wrist Tunes。他自己投入了智慧資本，並把設計與製造外包給在中國的夥伴公司。

做為業餘創業家或雙重創業家，你可以依適合程度決定自己投入的架構，然後再選擇天使投資人、顧問或創業家的角色。你也可以根據自己投入的資源，結合多重的角色。舉例來說，迪亞哥．塞斯—吉爾（Diego Saez-Gil）在Bluesmart的角色，就同時是顧問與創辦人；使投資人、顧問或創業家的角色。

兼職創業家永遠不會非常確定，要在每一個機會投入多少。我喜歡把每個投資案想成是一顆種子。有些種子不會發芽，有些種子會活下來，並且長得很旺盛，有些種子還會產生新的種子，並隨風吹散，落到你沒有預期的地方，然後生根。一段時間之後，你就可以跟著這些種子，和一群從先前的嘗試中認識與信任的夥伴，參與一個又一個新事業。你也可能會發現新的自己，並在這一路上建立財務與專業的自主性。有一天早上醒來，你可能會發現，歷經這些新事業的歷練之後，你已經完全脫胎換骨，變成不一樣的人了。

由於兼差的事業，派翠克·利能班克（Patrick Linnenbank）博士現在的角色有點像電影○○七的主角詹姆斯·龐德（James Bond）一樣，只是他的工作更有意思。

派翠克是荷蘭人，他經營一家反恐與調查公司，也是幾家人權組織的董事會成員。他也在很多深奧的領域擁有證照，包括文明黑客（ethical hacking）①、Krav-Haganah防身格鬥術②、駕駛逃脫術（evasive driving）③與犯罪剖繪（criminal profiling）④。他的履歷表讓他看起來像是一個祕密情報員，但除非你是壞人才能擔心他，因為平時的他，是個腳踏實地、風度翩翩的人，他的兩個孩子都能證明。

派翠克為什麼會踏上這樣的職業生涯？因為他在讀完醫學院之後了解到了，外科醫生的職業生涯中有一個重要缺點，即必須固定待在某一個地方。於是他打包行囊，飛到法國，取得

一個商學碩士學位。之後他在貝恩管理顧問公司擔任企業顧問，除了必須埋頭在一堆簡報工作之外，還接了在急診室二十四小時值班的醫生工作。因為對他來說，只有「完全瘋掉」，才會只做一份工作。之後的二十年，派翠克一邊繼續在顧問公司工作，而且一路做到合夥人，但同時還一邊以救人性命當作副業。對大部分的人來說，這樣的人生已經夠刺激了，但他還另外培養出法醫的興趣。這件事讓他可以運用他的醫學訓練，同時也可以在人權領域做出自己能力及的貢獻，這是他的另一個熱情。在非洲從事亂葬崗調查時，他的人身安全受到好幾次威脅，所以他接下來取得的專長，就是與安全有關的議題，他因此成為熟練的神槍手，也能從囚禁中逃脫，還有待在地球最危險的角落上，要保命必須知道的所有一切知識與技能。

根據他在白天工作與副業中培養出來的技能，他創辦了天使保安集團（Seraph Protection）

Group）

這家公司專精於高危險的安全工作、反恐顧問工作，以及法醫調查工作。它的辦公室涵及歐洲、亞洲、拉丁美洲與中國，提供服務的對象包括：船運公司、非政府組織，以及高淨值人士（high-net-worth individuals）⑤。但他還是不足於只有一份工作，因此還同時為客戶提供顧問服務。

派翠克的故事讓我印象深刻，他不只是詹姆斯·龐德，也是傑克·鮑爾（Jack Bauer）⑥，還帶有一點《急診室的春天》（ER）與《CSI：犯罪現場》（CSI）的醫生與探員的角色。

如果 你看到他在領英（LinkedIn）上的個人檔案，很自然會感到震驚。他的資歷幾乎會讓每一個人（包括我自己）看起來都像是個懶骨頭。他顯然是一個聰明又有行動力的人，但他的成功歸因於一個簡單的事實——他是善用時間與金錢的專家，而且他很努力地聰明投資自己的資源。

派翠克把三個似乎不同的專業領域：醫療、法醫與安全，整合成一份工作。如果我和你一樣，想知道他是怎麼辦到的，答案很簡單，就像你將在本書中會看到的人一樣，他會認真坐下來，拿出紙和筆，然後想出他可以撥出多少時間與財務資本，投資在創業活動上。一旦他思考清楚想做的事，他有兩大策略。第一，他會直接專注在已經取得智慧資本的領域。從醫療跳到法醫是很自然的轉換，也會比他變成跳水運動員或演奏會上的鋼琴家，會有更高的生產力。第二，對於他還沒有專業技能的領域，他會很有方法地取得那些特殊技能，以便讓他達成整體的目標。派翠克知道，如果他想在亂葬崗法醫鑑定領域中領先別人，他就需要充足的訓練，於是他很有計畫地把時間與金錢投資在他負擔得起的最好的訓練課程；也就是說，他曾到美國、以色列與非洲，和反恐專家一起學習。

在這一章，你要仔細盤點你是如何利用你的時間與金錢。並且要為了白天工作之外的事，至少撥出你一〇％的時間與財務資本。如果你從頭開始做，看起來好像是一個很大的承諾，但你會很驚訝，有了計畫與優先事項的安排之後，你的每一個資源都能發揮更大的功效。

記住，你就要開始從事你喜歡的案子了，這將會為你的事業與人生帶來實質的利益。雖然難免要做些犧牲，但最後的收穫一定會比付出更多。
