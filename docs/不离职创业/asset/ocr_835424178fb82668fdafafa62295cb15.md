# 分配財富

當你擁有創業心態時，你會在以前沒看到的地方看到機會。你也會很快知道，這並不是一個零和遊戲。你的能力來自你的專業，也來自你的人脈。你會自己做研究，信任自己直覺，但為了讓事情啟動，你也會積極利用別人的才能、想法、人脈與善意。這就是讓兼差事業擴大規模的方法。你不可能隨時都待在每個地方，也不可能知道一切。這就是你需要團隊的理由。你要打造的是 一部能自給自足的機器，靠著你找來的團隊成員的精力與腦力，就能順暢運作。這些人會在你的兼差事業中扮演各種角色，包括和你一起投資，給你建言，為你兜集案源，甚至會為你做事，或在你的投資組合中的公司做事。在中國發展補習教育的蓋文·紐頓，坦塞很早就體認到，如果他的周圍有對的人，公司成長潛力將會無可限量。他也馬不停蹄地把自己的想法告訴那些資深的專業人士，並把他們一一引進董事會。

Bluesmart 工作，一邊攻讀學位，並為了公司的利益大幅運用 MIT 社群的資源。之後，當 Bluesmart 的業務起飛，他就先暫停課業，全職投入工作。
