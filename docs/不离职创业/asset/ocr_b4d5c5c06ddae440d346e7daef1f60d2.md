# 謝誌

如果你想培養一種更深的感恩心，那就去寫一本書吧。寫書應該是一件最孤獨的事，而且有時候真的是這樣，但大地上，你會接受到很多人的人的善意與鼓勵。本書是多年討論與實驗的結果。首先也是最重要的，是我必須感謝我的兼差事業中的每一人、本書提到的所有創業者，以及很多提供背景說明的人。你們所有的貢獻與想法，讓我受益良多。

Jason Haim，我的朋友中沒有人比他更有智慧、更好的羅盤。 Geoff Gougion，把數位版的唐·德雷伯（Don Draper）①放在我的旁落，實在讓我深感

① 電影影集《廣告狂人》（Mad Men）劇中的男主角，角色塑造成功，有「女人都想要他，男人都想成為他」的說法。
