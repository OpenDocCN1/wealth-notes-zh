# 把新的機會融入忙碌的生活中

我在商學院念書的第二年，修了一堂進階的競爭策略課程。這堂課的副題有點神秘：「企業整合」。過了一個學期之後，我發現「企業整合」這四個字，隱含著一個非 compres 力的獨特觀點，即企業的所有活動，必須以一致的風格整合在一起，企業才會成功。透過精心規劃的策略，聰明的企業都會根據一個能自我強化的良性循環機制，來架構公司的組織與業務。公司ame 每一個部門也會因為這個整體計畫而變得更好。這聽起來像是 一個很簡單的概念，但我以前從來沒有把企業想成是一部整合的機器。擁有嚴密整合策略的公司，就像明星運動員。當你觀察世界級馬拉松選手時就可以發現，他們的跑步看起來就像是機械性的動作。每一個動作都把跑者向終點線更推進一步。如 果跑者的小區域動作，例如：足部的著地、手臂的擺動，都互相搭配，那麽飛奔向前所需要用到 的力氣就會減少。有效率就會帶來速度，而且因為每個細部動作都協調一致，受傷的風險也會降低。這就是所謂的良性循環機制。由於動作較不費力，而且目標一致，跑步的人整合了整個跑步的動作。思考一下世界級菁英跑步者如何移動身體，或一部機器的各種部件如何整合在一起完成
