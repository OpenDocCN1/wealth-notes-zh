# 5
雙重創業家 —
同時擁有其他事業

家之外，她目前還代表一 些世界冠軍舞者以及頂尖的編舞家，其中有 些人從她參加舞蹈比賽時就認識她了。雖然不見得每個人都曾經和她一起跳過舞，但這些客戶都很高興她，知道她是打從心裡了解他們是如何看待自己的作品。這樣的特質讓蜜爾卓瑞德在業界獨具一格，別具競爭力。

一旦你打開了創業閘門，就很難再把門關上。如果 你曾經成功地創辦或經營過一家公司，你就已經晉級到另一個階段，再要你創這些什麼事業，不但不會膽怯退縮，相反地，在你眼中，到處都是機會。同時你也能認識事實，成功的機率並不高，失敗的機率往往比成功來得更高。因此你必須讓自己多樣化，畢竟當你投注全部的時間與精力，在一個新創公司時，就把所有的雞蛋都放在同一個籃子裡，這份賭注很可能會決定你未來能否擁有多少財富。你在自己創立的事業之外，藉著當天使投資人或顧問，還可以同時擁有其他公司的股權，讓你的投資更加樣化，這樣做，也是讓你在嘗試新事業的同時，提供了下跌保護。如此一來，等於在你百分之百投入創業的同時，再加上一個％的投資，於是你就成了雙重創業家。
