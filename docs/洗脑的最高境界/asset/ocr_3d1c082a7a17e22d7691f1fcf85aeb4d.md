# 第十七套：好处引导术

原理：

把你的产品或者服务列出 3 大好处后，导入你的目的。

公式：

好处+好处+好处+目的

实例：

+   1、当你掌握了攻心语言模式后，你将有超强的说服力、拥有超强的能量、拥有把话说出去把钱收回来的技能，这时你就会认为我的这本书，是这个世界上最厉害的语言武器。
