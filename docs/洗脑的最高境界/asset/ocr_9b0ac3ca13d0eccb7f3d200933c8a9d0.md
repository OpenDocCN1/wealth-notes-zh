# 第一百零六套：意外惊喜术

原理：

当你在迷茫、抱怨时突然给你一个大大惊喜，你会为这个惊喜而流泪，从而在内心建立忠诚！ 公式：

持续的痛苦，给予对方意想不到的惊喜。

实例：
