# 第二十六套： 条件前置术

原理：

人们永远关心自己的事情，站在对方角度说话，然后导入你的目的。

公式：

+   当你、一旦你、如果你

实例：

+   1、当你每天还在为订单发愁的时候，你是否有种孤独 和无助的感觉，我的很多客户在没有购买我的产品之前，都 是你这样的感觉！

+   2、一旦你想快速提高自己的说服力，想快速获得成功， 而没有一个好的方法时，请你给肖鸿志老师打个电话吧！

+   3、如果你想学会一对多的批发式销售！

如果你想让你的员工自动自发的工作！ 如果你想彻底改变企业和整个家族的命运！ 你只有学习肖鸿志老师的《洗脑的最高境界》。

练习：写出你的目的，利用这个魔法句型练习吧！
