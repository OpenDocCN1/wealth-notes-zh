# 第一百零八套：消除自我术

原理：

人们只对自己的事感兴趣，别拿自己当回事好吗?不要跟猪谈梦想，要跟猪谈饲料！

公式：

听（对方说），二说（说对方感兴趣的，而不是你感兴趣的）。

实例：

通过 2 个实例对比

例子 1：
