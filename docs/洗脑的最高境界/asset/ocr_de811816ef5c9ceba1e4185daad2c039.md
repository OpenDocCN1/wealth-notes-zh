# 第三十八套：强制因果术

原理：

万事万物皆因果

公式： 因为

实例：

+   1、我着急上班，我要插队！ 对比

因为我着急上班，所以我要插队！ 大家可以对比一下，加上一个 “因为” 语言的威力 马上就发生了变化。

+   2、我饿了，我要吃火锅。 对比

因为我饿了， 所以我要吃。
