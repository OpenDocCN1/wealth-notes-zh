第三十六套：佛教四谛（苦、集、灭、道）

原理：

佛教四谛：

+   1、苦：指人生很苦，主要有生老病死苦、爱别离苦、 怨憎苦、求不得苦、五阴炽盛苦（即身心之苦）。

+   2、集：苦的原因是因为人有烦恼、有对情欲的执著， 所以能导致人的生死，不出三界。

三界：欲界、色界、无色界。欲界众生执著于欲， 色 界众生执著于色（事物的形象），无色界众生执著于无色（没有形象的事物），均为执著，所以不能了生死。

+   3、灭：要灭掉苦，应该走向寂灭（指修行圆满）。

+   4、道：要圆满，就要修道，通过修道去掉对情欲的执著和种种烦恼。

佛学博大精深，通四谛就可看透人生！
