# 第十四套：预设框架控制术

原理：

对你的目的进行假设，框住对方。

公式：

是…还是

实例：

+   2、你是在我公司还是去贵公司，签合同。目的要签合同

+   3、我猜你是先抬左脚还是先抬右脚。目的是让对方抬脚

+   4、我猜你是给我生男孩还是女孩
