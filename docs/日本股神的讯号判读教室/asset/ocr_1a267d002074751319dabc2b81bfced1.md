# ◎ 首先一定要注意「3 個月」「6 個月」

透過日本 Pan Rolling 研發的「線圖集錦」顯示日線圖後，由於圖中會以直線區隔每個月分，因此很自然地就能意識到 1 個月當中發生過什麼樣的價格變動，也能馬上看出「股價碰到低點並開始上漲後過了幾個月」或「碰到高點並開始下跌後過了幾個月」（編按：此為日本線圖服務，台股的歷史走勢線圖可參見台灣證券交易所或各大券商網站服務）。

下頁圖 20 是 SUMCO 的日線圖，以紅色箭頭表示上漲期間，藍色箭頭表示下跌期間，並以綠色線頭與盤整時的上限／下限來表示股價盤整推移的期間。對於漲跌期間，我們把起漲點（也就是低點）與起跌點（高點）所在的月份當成「第一個月」來計算。如圖所示，圖左的盤整走勢持續了 2 個月，同時在起漲點（低點）①所在的月份開始算起，總共持續上漲了 3 個月。之後從高點②所在的月份開始算起，直到抵達低點③的月份為止，共持續下跌了 4 個月，中途持續有 3 個月的盤整走勢。沒有永遠上漲的股票，也沒有永遠下跌的股票。以長遠的觀點綜覽股價的話，就能明白價格波動會呈現「下跌、盤整、上漲」，反之則是「上漲、盤整、下跌」，就像「µ」「n」字形一樣。這一點從圖 20 即可清楚看出。
