# ⊙ 用鳥嘴察覺趨勢轉換與加速

股價會反覆地上下變動，但是當你綜觀整體股市時，就會發現偶爾有持續上漲或持續下跌的情況。觀察整體價格變動時的股價方向性，就稱為「趨勢」。股票投資的重要關鍵就在於跟隨趨勢交易，也就是上漲趨勢時以做多為主，下跌趨勢時以做空為主。

那麼，趨勢改變的話該怎麼辦呢？這時候，我希望大家將相場式獨創訊號「鳥嘴」謹記在心。

說到顯示趨勢轉換的均線訊號，最有名的即為黃金交叉和死亡交叉。持續下跌的股價轉為上漲，而至今位於長期線下方的短期線被股價帶動，轉為向上後由下往上突破長期線——此現象就稱為黃金交叉。反之，短期線由上往下穿破長期線，則稱為死亡交叉。

然而，如果遵照「在黃金交叉時買進」原則的話，會出現很多案例是以為趨勢轉換而買下，但股價其實已經開始下跌，導致交易失敗。即使成功，股價在黃金交叉發生的時間點上多半已經漲了很多，能賺取的價差有限，非常可惜。這一點在「死亡交叉時賣出」情形中也一樣。
