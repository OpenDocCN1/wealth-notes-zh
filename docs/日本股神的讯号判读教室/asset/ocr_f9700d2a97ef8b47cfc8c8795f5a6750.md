# ◎ 股票投資的考古題就是「線圖」

股票的原則就是「每天都必須有很多人進行大量買賣，才會產生清晰易讀的價格變動」。股票的買賣量稱為「成交值」或「成交量」。此外，公司發行的股票數量乘以股價，就稱為「市值」，理論上即為買下整家公司所需要的金額。對於市值小且成交值也少的小型股或新興股票，若大戶投資人投入可觀的資金進行買賣，就能輕易使其暴起暴落。像這種價格變動無規則可循的股票通常很難預料，最好少碰為妙。

在相場式投資中，運用融資融券交易的放空手法，就可以在股價下跌的走勢中把跌幅變獲利。上漲也好，下跌也好，從所有的股價變動當中賺取獲利，才是相場式交易的精髓。

因此，相場師朗和門下弟子只會鎖定**市值在數千億日圓以上，每天最少有 50 萬股以上交易量，並且可以操作融資融券交易的「大型股」**。

網羅了眾多這種個股的市場，即為日本股市的代表性指數「日經平均股價指數」（日經 225），以及特別重視企業業績與獲利能力，因而篩選出的企業股價指數「JPX 日經 400」。

除此之外，像「日經 225 迷你期貨」這種可以買賣股價指數本身
