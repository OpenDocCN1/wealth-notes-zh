**表③** 當本益成長比低於 0.75 倍是布局好時機

本益成長比的判斷標準

| 本益成長比 | 股價合理程度 | 採取動作 |
| :--- | :--- | :--- |
| 低於 0.75 倍<br>(低於 0.66 倍更好) | 股價被低估 | 買進 |
| 等於 1 倍 | 股價合理 | 空手者不買，持有者不賣 |
| 高於 1.2 倍 | 股價被高估 | 賣出 |

資料來源：《散戶兵法祖魯法則》

外資準備出貨的拉抬手法？

本益成長比可以說是完全以成長性為首要考量的投資策略，當標的出現低於 0.75 倍的買進訊號時，往往代表該檔股票具備成長潛力，而且目前價值被市場所忽略或低估。因此，當未來市場發現或認同此檔股票的獲利爆發力時，股價往往會一飛沖天，而持股的投資人就能享受到盈餘的成長，加上本益比調升所帶來的雙重威力，這樣的結果，通常都是倍數以上的上漲空間。
