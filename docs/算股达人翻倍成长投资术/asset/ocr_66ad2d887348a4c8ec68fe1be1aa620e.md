# 1-4 選股法則 4
股東權益報酬率 15% 以上

一家企業最重要的是獲利能力，而獲利能力不能只單看賺進多少的淨利，還要看投入多少的資金。在財務比率分析當中，最常使用的兩項觀察指標就是「資產報酬率」（Return On Assets，簡稱 ROA）與「股東權益報酬率」（Return On Equity，簡稱 ROE）。

ROE 愈高，代表愈能有效運用股東資金賺利潤

其中，股東權益報酬率是股神巴菲特（Warren Buffett）很重視的一項指標，重要程度幾乎與每股盈餘不相上下，它能看到一家企業運用股東資金創造獲利的效率，股東權益報酬率愈高，代表企業為股東賺取利潤的能力愈強。
