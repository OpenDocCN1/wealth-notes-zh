# 善用 8 大法則 篩出潛力標的

營收成長與淨利成長呈現正相關，而淨利成長與股價上漲也是正相關。過去 5 年營業收入正成長主要是看出向上升的趨勢，確定你買進的公司，正處於營運上升的階段，而未來營收是否能夠持續增長才是關鍵。

# 優選未來 3～5 年每年營收成長至少 10% 標的

如果投資人買進的個股，未來的 3 年至 5 年以上的成長幅度，能夠維持在每年 10%～15% 以上的成長幅度，就是我們首選的標的，因為從歷史的經驗來看，營收成長幅度愈高，股價漲幅愈驚人。但是，如果現階段找不到符合條件的標的，退而求其次，在本益比夠低，而且殖利率高於平均值的前提下，找出營收年複合成長率約 5%～10% 的股票。
