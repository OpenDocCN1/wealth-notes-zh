# Chapter 3
檢視公司體質  增加持股信心

運上無可避免的負債。非流動負債則是指到期時間在 1 年以上的債務，包括向銀行的長期借款，以及發行公司債等。

比較值得投資人注意的是，非流動負債裡的「長期借款」與「應付公司債」，因為它們是需要支付利息的債務，我們通常希望兩者的占比不要過高。一般而言，我們會希望有息的長期負債占總資產的比重，至少維持在 20% 以下，一旦占比太高，所需支付的利息就會大增。這個部分我們可以從利息保障倍數進一步觀察。

利息保障倍數 = EBIT（稅前息前淨利）÷ 利息費用

利息保障倍數就是用來評估，公司賺來的盈餘是否能償還負債的利息，是用來衡量企業支付利息費用的能力。倍數愈高，表示債權人受保障的程度愈高，也代表債務人支付利息的能力愈高。
