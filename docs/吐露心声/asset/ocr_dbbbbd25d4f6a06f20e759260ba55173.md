# 24、全力以赴，走出去

劳拉·萨默斯（Laura Sommers）

以前我只知道读书。后来，我试着去见当地机构的一位创意总监。我给他带了一袋白色内衣，给他留在了前台桌子上，他当时正在工作，不能接见我。

十年后，我碰到他，他依然记得那件事。

现在，我访问人们时，我会立即提到塔吉特，添柏岚，以及威格。不要太过谦虚。大牌通常能让你占据上风。

你最有效的营销就是你有什么样的客户。找理由和他们见面。亲自和客户面对面提出提议。放下手头工作。去邻里间走走。带一些小糕点或咖啡。
