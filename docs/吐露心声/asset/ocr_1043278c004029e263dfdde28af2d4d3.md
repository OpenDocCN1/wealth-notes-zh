# 13、撰稿者的思维障碍——如何打破思维障碍，让你泉思如涌

奥钠·格雷（Aurel Gergey）

打破撰稿者思维障碍的 7 个简单方法：

+   1. 瞒骗你自己：任务分解法
2. 全身心投入其中
3. 通常只有安静下来，才能投入工作
4. 音乐，所有工作最好的助力剂
5. 积极地利用醉酒
6. 外部活动能带动大脑活动
7. 做有益于自己的事，然后写下来

让我们来简单地看看每个方法：

# 1. 瞒骗你自己：任务分解法

写作者的局限（更确切地说是文案撰稿者的局限）通常是因为有太多工作要做，一时无从下手。那么，你可以和我一样：我要做各种各样的事情，而不仅仅是我应该做的——完成本职工作。
