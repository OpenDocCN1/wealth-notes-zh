# 距離越遠，感情只會越淡

美國心理學家康恩 (Timothy J. Kahn) 曾做過一個說距離和好感度關係的實驗。實驗設定一名男性同時和坐在距離五十公分處，以及二四公尺處的女性說話，結果發現男性對比較近的女性會有好感，反過來說女性也是。

此外，情侶的住處距離相隔越遠，兩個人結婚的機率就越小──這就是「包薩德法則」。

美國心理學家包薩德 (H. S. Bosann) 以已婚夫婦為對象，調查兩人婚前的住家距離。當訂婚時彼此的距離越遠，結婚率就越低。看來，比起遠方的人，人們的確有喜歡上附近的人的傾向──「遠距離戀愛」果然很困難。
