# 騙子不會多找藉口

「一次就行，就當作被我騙，試用看看吧。」

當登門拜訪的推銷人員這麼一說，許多人就不由自主地買下了。即使知道有很多惡質推銷，這類詐欺案還是層出不窮。

這些詐騙分子很清楚自己推銷的是次級品，因此絕不會宣傳商品有多優質——這樣不僅會讓對方警戒，萬一被反駁時自己也無從答起，多加解釋只會令對方更懷疑。

人們很容易因為推銷員一句「您會懷疑也是理所當然」而上當。

當對方承認後，我們會感到放心。承認有可疑之處，與懷疑消失完全是兩碼事，可是中間的心理漏洞就會使騙子有機可趁。
