# 改變「說話順序」，結局大不同

越晚取得，越容易記得

針對記憶機制，還有「越後面取得的資訊，人們越容易相信」這種「新近效應」。聽起來好像跟上一節的「初始效應」有點矛盾？

「新近效應」容易發生在從一群人取得情報的場合，「初始效應」則發生在從同一個人取得情報。

美國的心理學家諾曼·安德森 (Norman H. Anderson) 曾經以實際發生的案子為例進行模擬法庭的實驗，驗證提供證言的方式會如何改變陪審團的判斷。

辯護方與檢察官同樣提供六筆證言，文書長度也做了統一，沒有哪段證言特別突出。

提出證言時，由其中一方先提兩筆證言，接著另一方也提出兩筆。最終當陪審團下結論時，結果有利於最後提出證言的一方。接下來改由其中一方連續提六筆證言，再由另一方提出六筆。這一次結果也一樣，陪審團下的結論還是對最後提出證言的一方有利。

# 最後一句話最要緊

從上述實驗可以知道，從不同來源取得各種訊息時，人們最容易受到最後資訊的影響。

即使同樣受到稱讚，先稍微批評後再讚美時，人們通常會比較高興。就算說的內容都一樣，最後的一句話也能打消之前的壞印象。
