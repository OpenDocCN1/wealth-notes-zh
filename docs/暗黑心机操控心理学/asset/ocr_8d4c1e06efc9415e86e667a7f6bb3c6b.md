# 萬全的舞台準備

——長年為公司效力，努力奮鬥了這麼多年，也差不多看到職業生涯的盡頭了……，而且每天下班後，自己總是忍不住懷疑，公司是不是並沒有特別看重我，我也沒辦法盡情發揮自己的能力呢？—而如今證據就是——M 公司相中了我的能力吧？

當 T 先生開始起了想轉職的念頭時，這時候獵人頭顧問又特別「提醒」說：「因為我們公司必須遵守保密條款，今天我和你說的話、提到的任何資訊，都要嚴格保密，並且會和你簽定合約來要求遵守。—這個你保密約非常要緊，要是這件事情傳出去了，你被公司慰留，或是公司不讓你離職的任何事情都發生了。」

# 小知識

# 獵人頭（Headhunter）

正式名稱為「高階人才顧問」。企業寻觅高階主管時，為避免同業競爭對手察覺洩漏商業機密，以及因故而不方便挖角，因此便會委託獵人頭公司搜尋。
