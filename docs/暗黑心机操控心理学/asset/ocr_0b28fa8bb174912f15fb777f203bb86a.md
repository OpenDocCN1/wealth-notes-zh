# 睡眠者效應，欺騙大腦直覺的說服術

美國的社會心理學家卡爾・霍夫蘭德（Carl Hovland）和華特・維斯（Walter Weiss）做了一個實驗，證明即使是內容完全相同的訊息，由可信度較高的人傳達，說服效果也比較好。他們由此得到結論：情報源頭的可信度高，說服力更大。

不過，經過四個星期後，他們再次調查所有受試者，卻發現這次的意見和當初實驗時相反。也就是說，被可信度低的情報影響的人變多了。

上述這個現象，稱做說服的「睡眠者效應」（Sleeper Effect）。不管原本發送情報的人可信度高或低，隨著時間經過，人們都會接受情報的內容。換句話說，即使記得情報內容，記憶中的情報源頭也容易變得模糊不清。

# 失誤的直覺

走在街頭，看見某個招牌的時候，我們會心想：「對了，我好像在哪裡聽過這家店的名字。」雖然記不清楚，但是曾在雜誌或電視上看到；既然會出現在媒體上，那一定有是有名的店了——我們會這麼直覺判斷。

就算不記得是報紙的置入性行銷，或美食節目，甚至是從食物中毒的新聞畫面中看到，最後通常只會留下「好像是有名的店」這個印象。
