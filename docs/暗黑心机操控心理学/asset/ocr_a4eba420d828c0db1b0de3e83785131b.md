# 體驗「靈魂出竅」，人工製造的幻覺

# 阻斷感覺能產生幻覺

部分新興宗教會強調神祕體驗、超常體驗，並視之為教祖創造的奇蹟，藉此向普羅大眾宣揚教義的正當性。

奧姆真理教的信奉之中，也有人否定教團的行為，但卻完全不肯認「看見未來」、「知道前世」、「在光的包圍下接受了祝福」、「感覺不到肉體，靈魂能夠出竅」等奇蹟。也有很多人相信，這是修行所觸發的「真實」體驗。

不過，心理學有個「阻斷感覺」的實驗。實驗受試者進入隔音的小房間內，戴上半透明的護目鏡，用海綿塞住耳朵，手也繃了起來。在感覺器官接收不到刺激之下，人會無法冷靜下來，也

不能整理思緒，不安感增強，不到一天——比較快的人甚至在二十分鐘後——就出現了幻覺。

# 大腦的誤導

雖然這個實驗是心理學基礎中的基礎，但也有人把這些「靈魂出竅」、「看著躺病床上的另一個自己」的幻覺當真。

的確，「體驗」是真的。但這並不是教祖的力量造成，也不是信奉者身上發生了什麼特別變化，不過是單純的大腦作用罷了。

根據大腦生理學，阻斷感覺將很可能会促進大腦物質「腦內啡」分泌，其作用就是會讓人看見幻覺。
