# 14
擔訽巧妙心機，把妹輕鬆到手

「我看你是個男子漢，就拜託你了。」有人低頭拜託你，而你的女朋友就在身邊時，要怎麼做才好呢？一個大男人流淚請求，你多少會有所猶豫，無法冷淡對待；況且身為男人，你也會希望女友能看見自己可靠的一面。

和親密的對象在一起時，我們的心理作用會避免任何讓評價下跌的行動。

男性把妹時有一種搭訕技巧，便是「專挑女性二人組」。這是因為結伴女性碰上男性搭訕時，會為了展現自己比另一位「更成熟」、「懂得多」而虛張聲勢，不加思索地衝動行事。男性就會利用這一點，輕鬆搭訕成功。
