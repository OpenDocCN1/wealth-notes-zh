# 以退為進，「示弱」能騙得人心

利用自己的失誤操縱對方

「唉！我昨天不小心喝太多了，就把重要的文件忘在計程車裡。」看起來很認真的主管，竟然說出這樣的話，下屬們應該會覺得這樣的主管很有親切感吧。

平常，人們的心理機制會為了捍衛自己的威嚴，努力不洩漏對自己不利的情訊。

然而，坦然說出「弱點」和「不小心……」的這種「失誤」，反而會帶給人「很有人性」的印象，而且，在心理層面上，也確實比較願意接納這樣的人。

因此反過來利用這一點，故意露出自己柔弱的一方面，就能夠讓對方放下戒心，接納自己。不

過，能夠徹底把示弱效果發揮出來的人，只有那些已經具備一定權威，有弱點反而讓人感到「意外」的人。

示弱能展現「人性」魅力

外號威武的大政治家，竟然怕老婆——這樣的八卦最能夠引起一般民眾的興趣，甚至會覺得這名政治家不為人知的一面頗有魅力。只不過，這或許是政治人物故意營造的形象。

政客或宗教領袖，即使有些缺點，選民和信眾仍然覺得沒什麼大不了。所以會有這個不可思議的現象，正是因為支持群眾覺得比起完美的聖人，偶爾有些弱點的人還比較有魅力。
