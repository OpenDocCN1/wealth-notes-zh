# 14
最強請求術，無論誰都買帳

「其他人都已拒絕了，你是我最後的救
星！」當有人淚流滿面地請求，你應該會忍不住
地動搖吧。

有人拜託麻煩事時，我們通常會說：「你問
別人看看。」就算不好意思直接推拒，也會用「我
沒辦法傷害啦！」的說法委婉拒絕掉。

當周遭有很多人時，人們會產生「就算自己
不做，別人也會做」的心態，這就是心理學上的
「責任分散」概念。

只不過「你是我最後的救星」這句話，打從
一開始就封死「別人也能做」這條逃生路，而且
少有人在聽到別人說「我需要你」時無動於衷，
也就不由自主地答應無理的請求。
