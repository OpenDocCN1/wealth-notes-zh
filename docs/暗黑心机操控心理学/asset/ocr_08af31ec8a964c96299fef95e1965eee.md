# 10  越美越孤單，最易趁虛而入

感情騙子都說：「美女比較容易騙。」的確，美女常讓人覺得「高攀不起」，很少男性勇於追求。一直單身的美女，不是因為選擇太多，大多是因為沒人敢靠近她們。此外，工作能力優秀、自尊心很高的女強人，也普遍使男性敬而遠之。

只要是人，都會覺得孤獨難過，希望有人陪在自己身邊，結婚也是這種孤獨感的延伸。感情騙子就是利用這份孤獨，趁虛而入，偽裝成高收入、容貌英俊的菁英，滿足女性的「三高」擇偶標準。當女性的自尊心因此得到滿足，覺得「這個人才配得上我」時，轉眼之間就上當了。
