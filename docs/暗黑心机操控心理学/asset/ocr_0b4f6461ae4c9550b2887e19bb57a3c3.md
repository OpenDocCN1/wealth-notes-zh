# 「好人」面具下的真相

# 感覺孤獨，最容 易下手

到目前為止，我想你應該不再輕易認定「我 不會被騙」吧，但糟糕的是，我們生活在容易受 騙的時代，自己處處洩漏破綻。

其中，現代人的孤獨感正是重要因素之一。 即使生活在通訊高度發達的時代，可透過手機或 社群網站二十四小時一連在一起」，但人們還是 高喊「無緣社會」、「孤獨死」的標語，時時刻 刻感受到強烈的「孤獨感」。

人類會本能地因孤獨而感到不安。許多人熱 衷占卜、新興宗教，就是為了填補內心的孤獨 感，而詐騙分子正是利用人們心靈交戰之際，假 裝親切地接近目標對象。

不只年輕人，高齡長輩、家庭主婦或單身貴 族，只要深刻體會現代社會孤獨氛圍的人們，都 會成為「溫柔騙子」的目標。

# 需要被認同的不 安感

現代的人們有著難以找到自己定位的現象， 這同樣也與孤獨有關。過去明確的親子關係、師 生關係以及國家與國民關係，到了如今都已經變 得很模糊。自己究竟是什麼樣的人？很多人沒有 答案。

在這樣迷惘的狀態之下，人心很容易感到不 安。無法融入社群又满怀疑慮，就會輕易相信詐 騙人士的甜言蜜語了。
