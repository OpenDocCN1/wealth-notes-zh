## 前言

### 毒草或良藥，在於你怎麼用

![](img/2018e93cfe67e2b8480702f5a6ffc9fe_3_0.png)

毒草或良藥，在於你怎麼用

有一種人，他們生來就是人生勝利組，無論求學或求職都一路順遂；找到所愛的人一同組成幸福美满的家庭，過著人人稱羨的生活。然而，這樣的人卻也容易街頭推銷員、新興宗教、通靈騙子等詐欺犯給騙上鉤。另外還有一種人，他們在一家公司上班，主管信誓旦旦地保證：『絕對不會安排調職！』他們也信以為真。沒想到某一天突然接到命令，立刻被調往偏遠的鄉下地方而求助無門，最後只能悲嘆：『被公司騙慘了！』上述這些例子，都不能單從表面來評斷：『誰叫他們人有機可趁，這都是自作自受啊！』我們應該如何客觀地分析外界的資訊，培養出無論遇到什麼情況，都能夠保持疑慮、不輕易被欺騙的思考方式呢？

透過本書，我想從心理學的觀點，一一列舉那些自認立場堅定、不隨風起舞以及擇善固執的人，卻仍受騙的各種案例；同時，我也會介紹詐騙惡徒、商業話術如何利用人類心理，設下陷阱請君入甕的例子。

我把這樣的心理學觀點稱之為「暗黑心機操控心理學」，這個詞或許讓有些讀者覺得是教人為惡，多少讓人心生抵觸。不過，本書介紹這些說謊、欺騙的手法，是為了不讓你陷入「心靈陷阱」，而不是教導讀者懷著惡意來欺騙別人。

現代社會充斥著詐騙陷阱，往往能巧妙攫住人性弱點，本書的目的就是希望各位讀者能看破這些技巧，保護自己，不受欺騙。另一方面，若能聰明運用人類心理來操縱他人內心的手法，只要用在正確的地方，也能有效改善溝通，使人際關係更加順遂。除此之外，磨練說客套話、表面話、小謊話，也可以幫助我們減輕日常壓力，讓生活過得更順利。

無論是什麼樣的知識，都有可能因為「使用方法」的差異，從劇毒轉身一變為良藥。我誠摯希望各位將本書當作詐欺術解套範本，甚至能成為人際關係的潤滑油。

樺 旦純

### 01 渴望越強，越難逃出騙術圈套

歡迎……，這樣的欲望越強，就越容易受騙。

所有「欲望」，皆源自需求

人會受騙，最根本原因就在於「欲望」。每個人都有想滿足欲望的需求，美國心理學家亞伯拉罕．馬斯洛（Abraham Maslow），便將人類的欲望分為五個層次：

- 第一層次：食色睡眠等的「生理需求」
- 第二層次：不受天災傷害的「安全需求」
- 第三層次：歸屬於團體、追求愛情或友情的「愛與歸屬需求」
- 第四層次：想得到認同、滿足自尊心的「受尊重需求」
- 第五層次：想實現抱負的「自我實現需求」

想變得更有意，想變得更美、想要更受女性青睞。

潛藏內心的需求，騙子最懂

說起這些需求並不特別，每個人多少都有一些。另外還有一些需求是潛藏在自己內心深處，平常不會輕易發覺，而職業詐騙人士正是專挑這種需求下手。受騙的原因除了需求，還有知識不足、同情心、深信絕沒問題等因素。

這麼一想，我想大家應該能重新發現：不管什麼年齡、性別、社會地位、個性，任何人均有可能受騙，覺得「詐騙跟我無關，我絕對不會被騙」的人，才更有受騙的危險。

### 02 騙子眼中的肥羊，是哪些人？

聰明人也難逃受騙

雖說任何人都可能被騙上當，但其中還是有特別容易受騙的類型，我就在這裡舉幾例子吧。

首先，「好人」很容易受騙。他們不懂懷疑別人，看到別人有困難，就肯犧牲自己，也無法狠下心不出手協助，因此最容易打著「悲情牌」的小額詐欺、假借愛心名義的詐欺募款等給騙上鉤。

再來，聰明的人也很容易受騙，更精準地說是「覺得自己聰明」的人。他們沒有想過自己也會被騙，當騙子針對過度自信的弱點出招時，他們就會徹底上當了。

絕不放過的肥羊

小氣鬼也是容易受騙的類型，像是幾十年積蓄一夕騙光的新聞屢見不鮮。大家可能覺得匪夷所思，不過這類人本來就亟需存錢，才會對好康的投資法感興趣，打著「錢滾錢」如意盤算，自然容易上鉤。不如此，騙子好像天生就能嗅出這種小財主，受騙機率自然就高。

另外，虛榮心強的人也容易受騙。這類人非常需要他人讚美自己，好彰顯出優越感。還有，異常害怕孤獨，總是希望有人能接納自己——也就是缺乏自我、容易受人影響的人，往往深信詐騙分子充滿善意，進而上當。

### 03 「好人」面具下的真相

#### 感覺孤獨，最容易下手

到目前為止，我想你應該不再輕易認定「我不會被騙」吧，但糟糕的是，我們生活在容易受騙的時代，自己處處洩漏破綻。

其中，現代人的孤獨感正是重要因素之一。即使生活在通訊高度發達的時代，可透過手機或社群網站二十四小時「一連在一起」，但人們還是高喊「無緣社會」、「孤獨死」的標語，時時刻刻感受到強烈的「孤獨感」。

人類會本能地因孤獨而感到不安。許多人熱衷占卜、新興宗教，就是為了填補內心的孤獨感，而詐騙分子正是利用人們心靈交戰之際，假裝親切地接近目標對象。

不只年輕人，高齡長輩、家庭主婦或單身貴族，只要深刻體會現代社會孤獨氛圍的人們，都會成為「溫柔騙子」的目標。

#### 需要被認同的不安全感

現代的人們有著難以找到自己定位的現象，這同樣也與孤獨有關。過去明確的親子關係、師生關係以及國家與國民關係，到了如今都已經變得很模糊。自己究竟是什麼樣的人？很多人沒有答案。

在這樣迷惘的狀態之下，人心很容易感到不安。無法融入社群又满怀疑慮，就會輕易相信詐騙人士的甜言蜜語了。

### 04 操控人心的騙術，也可以很善良

我們確實活在一個不能大意、不敢鬆懈的社會，但只要學習本書的心理法則，便能有效迴避詐騙分子，避免上當。

利用人類心理作用的詐騙手法，從另一個角度來看，其實也是能解讀人心，促進人際關係順利的潤滑油。

在我們的生活當中都充斥著謊言，例如：「嗨！最近還好嗎？」「託你的福，我過得很好。」類似對話每天都在上演。「託你的福」到底託了什麼福？但也正是這樣曖昧不明的說話技巧，人際往來才能順利進展。

只要善用於騙分子的技巧，在一瞬間拉攏，隨心所欲操縱對方，人際相處會變得更和諧！

#### 01 先佯裝讓步，後面更佔便宜

「愧疚感」使人卸下心防

冒然邀請不熟的女性：「下次一起去旅遊，好嗎？」對方應該不會答應。可是，在對方婉拒之後，過一陣子再試著約她：「今晚要不要一起吃個飯？」一般女性心中普遍會因上次的拒絕而有所愧疚，自然而然就會心軟，覺得「吃個飯也還好」，答應你的邀約。

美國的心理學家羅伯特·席爾迪尼（Robert Cialdini），曾做過一個心理實驗。當研究人員詢問路人：「您明天方便來捐血嗎？」結果只有三十一．七％的人答應；六八．三％的人則當場拒絕了。接著，他們又試著拜託這些人：「您可以跟我們簽個約，預定今後幾年期間，每兩個月捐血一次嗎？」

當然幾乎所有人都拒絕這個請求，於是他們又接著問：「那只捐這次也沒關係，請您明天來捐血。」竟然就有四九．二％的人答應。

說服老手都這麼用

故意提出會被拒絕的要求，先讓對方婉拒，然後再說出原本真正的要求，這麼一來，對方會在心中比較兩個要求，反而覺得後來提的條件較簡單，就會忍不住答應。

這樣的技巧就稱為「以退為進法」（Door in the face），說服老手都是這麼達成目的。

#### 02 讓你「先說滿再打壓」的暗黑管理學

讓下屬積極提出反對意見

真正有能力的公司經營者，絕對不會明目張膽地打壓員工的反對意見。

讓員工以為自己成功說服老闆，但最終卻是被老闆帶向自己想走的方向，這就是經營者的策略。

舉例來說，老闆會頻繁召開會議，並且在會議上刻意安排站在反對意見的員工擁有充分的發言機會。

理所當然地，因為這時候老闆都已經事先安排好人馬，營造出自己方為多數派的局面。

最後的結果會是，即使討論再多，也不可能會推翻最初的決議，如此表述結果仍舊反映出老闆的期望。

不過，反對派的一方因為在會議上能夠充分發言，因此容易誤以為表決結果也考量了自己的意見，欣然接受定案。

不僅如此，這時連最初一直表態反對的員工還會在不知不覺之間，自發性地願意遵從會議的決定。

#### 面帶和善聽取意見，更要小心

#### 03 眼睛是「靈魂之窗」，直通內心秘密

##### 眼睛比嘴巴更能探知「真相」

一般來說，當人們被問到喜歡戀人的哪一點時，許多人通常會回答：「我喜歡他的眼睛」。

雖然說「眼睛為心靈之窗」，不過從這點也可以知道，人們彼此之間互相對話、溝通時，「視線」扮演著極為重要的角色。只要觀察視線，就能讀懂對方的心；而當我們精準掌握自己的目光落點時，也能使對方的心情隨之起伏。

有一個可以解釋上述情形的理論，即「溝通分析」（Transactional Analysis，簡稱TA），正是探究視線方向和心理狀態兩者之間的關係。這個理論將人類在溝通時的自我狀態，歸類為下列三個要素——

- P（Parent）：對待孩子的父母心理狀態
- A（Adult）：冷靜沉著、能做知性判斷的心理狀態
- C（Child）：自我中心、天真無邪的孩童心理狀態

在不同的心理狀態之下，人們的視線很常表現出下面的應對現象——

- P狀態強烈：向下俯視的視線
- A狀態強烈：水平視線
- C狀態強烈：仰視的視線（向上看）

舉例來說，當主管和下屬處在同一個空間，前者的視線會自然俯視後者，這是因為主管在下屬面前時，為了維持自己身為上司的威嚴，「P」心理狀態變得很強烈的緣故。

##### 溝通分析理論

###### 三種自我狀態

| 狀 態 | 說 明 |
| :--- | :--- |
| P (Parent) | 家長的心理狀態<br>就像父母對孩子說話 |
| A (Adult) | 成人的心理狀態<br>能夠冷靜做出理性的判斷 |
| C (Child) | 孩童的心理狀態<br>會衝動、自然地表達自己的想法 |

###### 不同狀態下的視線

| 狀 態 | 視線方向 |
| :--- | :--- |
| P強烈 | 目光向下俯視 |
| A強烈 | 視線保持水平 |
| C強烈 | 目光向上仰視 |
