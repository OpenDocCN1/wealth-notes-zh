# # 11 最易受人擺佈的五種個性特徵

對自己沒自信的人，也很容易被別人所騙。

當自己的能力獲得他人的稱讚與認同後，就會產
生自尊心。

+   *   自尊心低落的人，會有以下特徵——
    *   對他人的評價沒自信，謹言慎行
    *   對人際關係不安，討厭受矚目
    *   對他人抱著強烈的不信任或反感，卻不表現
    *   自己的想法
    *   失敗時，產生很強烈的懊悔感
    *   責任感很強，會熱衷於一件事，但很悲觀
    *   自尊心低的人，很懷疑自己下判斷、做決定
    *   的能力，一旦碰上自信滿滿的時，便很容易任由
    *   對方擺佈。
