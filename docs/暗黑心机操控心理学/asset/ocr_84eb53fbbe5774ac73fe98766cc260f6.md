# 09
認同的渴望，最容昜引狼入室
獵人頭詐欺

雖然「挖角」在日本並不常見，不過我們把目光轉移到在歐美國家的商業界，則非常流行從其他企業挖角優秀人才。

而與這股挖角風氣相對應的，便是催生了專門接受企業委託、促成人才媒介的組織，一般通稱為「獵人頭」，這種職業的人會從各地尋找人才。

巧合的是，日本企業傳統的終身僱用制、年功序列制，也在全球化與金融危機的衝擊之下，逐漸面臨崩解。

這同時也意味著，一名職員一輩子效忠一家公司的風氣變得越來越薄弱，當轉職、跳槽逐漸成為職業規劃的考量時，人們也開始熟悉起獵人頭公司或顧問，希望能夠透過他們的介紹，快速轉到更好的企業，拿到更高的待遇。

T 先生原先在中型規模的公司擔任部長，便曾經碰到一名自稱來自獵人頭公司的顧問。當雙方寒暄幾句、交換名片之後，T 先生發現對方名片上的公司名稱標示了英文，看起來似乎是外商公司。

這時候，對方也開始說明來意：「我手邊正好有 M 公司的委託，他們正在尋找優秀人才，不知道您有沒有興趣，讓我花一點時間，稍微介紹一下呢？」
