# 15
電腦只能選花生，擇偶靠不住

怎麼追，才會成功？
「科學方法，由電腦為你選出絕配伴侶！」
這句台詞，經常可以在婚友社、相親銀行的各種廣告宣傳中看到。

人際交友的考量點很多也很複雜，與人實際相處時，彼此個性是否投合、平時習慣或愛好、飲食口味等等能否互補，這些人際關係都需要一段觀察時間。
總之，現在先讓我們把焦點放在「電腦相親」，所謂的「科學方法」會造成什麼樣的心理作用吧。

在婚姻市場上，大家普遍會達成一個共識，認為男女之間能不能成爲情侶、進而組成家庭

的種種條件當中，有一條非常重要的法則，那就是——男女雙方的外在條件與魅力，要不相上下，才比較容易長久經營關係。這項法則就稱為「配對假說」。

心儀的對象如果在外表、身分地位或經濟能力等外在條件上，遠比自己更具魅力、條件更優越，即使鼓起勇氣向對方告白，勇敢展開追求，恐怕最終也只會淪於被拒絕的下場。

所以，這也是為何一般人自覺在兩人關係中若處於弱勢時，便不會選擇主動出擊，因他們自覺成功機會並不大。

不僅如此，在自尊心的作崇之下，對方也不會覺得條件比自己差的人有什麼魅力可言，自然也不會刻意搭訕。
