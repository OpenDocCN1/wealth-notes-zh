# 04  男女約會怎麼坐，有學問

# 坐哪裡，「有關係」

開會或吃飯的時候，從坐的位置，就能夠一窺人與人之間的關係。

當其中一方坐在另一方的正對面，兩人中間隔著桌子，代表彼此問心理的距離很遠。不僅如此，由於雙方的視線會正面交鋒，很容易會產生對立的關係。

因此搭乘電車或火車，或是在候車室坐著等待時，這些場合都很容易讓不認識的人們無可避免地侵犯彼此的身體領域，這時候最好儘量選擇不正對某個人的座位。

相對地，並排而坐則幾乎緊貼著旁邊的人，心理上不會產生對立感。兩個人面對相同方向、

# 利用座位營造氣氛

看著相同對象時，潛意識中會產生連帶感。

由此可知，會坐在一個人的旁邊，要不是對這個人有非常強烈的親近感，就是希望這個 人對自己產生親密感。

無論是男性還是女性，當兩個人隔著桌子說話，應該代表彼此關係還沒有很密切吧。不過若換成並排座位時，即使沒有刻意交談什麼，仍然會產生兩人化為一體的感覺。
