# # 16 喜歡或不要？眼睛瞳孔說真話

# ## 瞳孔光丟的真心話

女性凝視情人時的水汪汪雙眼、母親哄著嬰兒時，眼睛散發著光輝。這不是氣氛營造出的效果，而是在物理上，瞳孔確實放大了。

美國一位研究瞳孔變化的心理學家何斯（Richard H. Hesse），曾在微暗的房間裡專心看著動物寫真集，這時妻子對他說：「你的瞳孔變大了。」何斯推測瞳孔大小可能會因為心理活動而改變，並立即做了實驗。

何斯的實驗結果顯示，試著讓女性觀看嬰兒或猛男的照片時，她們的瞳孔普遍會放大约二十％左右。

若實驗對象換作是男性，他們觀看同樣的照片

片時，瞳孔則幾乎沒有變化；不過，當男性看到美女的照片時，瞳孔也會放大约二十％。

# ## 瞳孔映照你的心

看見自己感興趣、關心的對象時，瞳孔會放大，看起來眼睛像是「發光」似地。

即使對方嘴上說著「好棒」，但瞳孔卻變小，我們就無法確定對方是不是真心這麼覺得。相反地，即使嘴上掛著「我不要」，只要瞳孔發出光輝，就是對方口是心非的證據。

經驗老道的推銷人員，絕對不會錯過瞳孔的大小變化。就算我們嘴巴推拒，但只要瞳孔放大，他們就會視為機會來臨，再加把勁推銷。
