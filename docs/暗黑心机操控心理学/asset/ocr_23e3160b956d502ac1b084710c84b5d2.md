# 體面穿著的威力

詐騙分子被捕的時候，往往會發現他們的穿著多半很整潔，簡直就像菁英上班族。這些犯罪分子就是利用人們的一廂情願——服裝體面更值得信賴。

有個心理實驗中，設定某十字路口的交通號誌顯示紅燈，但是並沒有車輛行經，這時若有個穿著西裝、打著領帶的男性直接越過馬路，周圍的行人多半也會跟著他闖紅燈；假如換成一個工人打扮的人闖紅燈，周圍行人便不會跟著過馬路了。

人們會對服裝抱持先入為主的印象，因此外表的影響力超乎想像得大。

# 外表暗示會騙人

美國的心理學家倫納德・比克曼（Leonard Berkman）曾做過一個有趣實驗。他將一枚十分錢硬幣放在電話亭內的顯眼位置，當有人進入電話亭時，研究人員會等上兩分鐘按著敲門詢問：「我把一枚十分錢硬幣忘在裡面了，你有看到嗎？」

這個時候，當研究人員穿著得体時，拿回硬幣的機率是七七%；當研究人員穿著寒酸時，歸還機率則是三八%。

即使我們都知道「內在比外表重要」，卻還是無法忽略第一印象，而試圖詐騙的人，給人的第一印象多半都非常好，各位要特別注意。
