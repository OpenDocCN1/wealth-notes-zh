# 05
感情出軌的欺瞞話術

被老婆聽到交情要好的女性朋友打電話來，
即使自己明明沒有出軌，兩個人之間還是會疑
心生暗鬼。
當老婆裝作一副若無其事的樣子問：「剛才
的電話是誰打來的？」這其實就是她非常在意
的證據了。

這個時候，男性最常犯的錯誤，就是不想多
解釋什麼，敷衍地回答：「喔，不是什麼重要的
人。」來含糊其詞。但這種語帶保留的回應方式，
只會加深她的懷疑，今後保證也會對你所有的行
動都往出軌的方向揣測。

不管是該隱瞞的祕密，還是沒什麼好隱瞞的

事，一旦為了掩蓋什麼而說謊時，人們必定會為
了補全這個謊言，不得不說更多的藉口來圓謊。

# 反向坦誠更有用

是公司以前應酬常去的夜店的女生。最近
比較不景氣，都沒再去了，所以對方打電話來拉
客人。」像這種被老婆知道也沒什麼大不了的事
實，還是清楚說出來為妙。

一般來說，大多數人確信另一半如果出軌，
通常都會極盡所能試圖隱瞞。主動坦承，就是反
過來利用「沒有人會把對自己不利的事說出來」
的認知，巧妙地引導對方的心理。
