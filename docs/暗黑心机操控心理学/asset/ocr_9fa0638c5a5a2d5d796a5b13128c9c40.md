# 盲目助人的愛心，引來騙子的壞心

# 好心不一定有好報

「能不能請您幫個忙？我需要把這筆錢送到那家店去，但是突然碰到一些狀況，沒辦法自己去……」走在街頭時，迎面忽然來了一個人，向你提出這樣的請求，同時拿出（看起來好像）裝滿鈔票的袋子。

只要你一點頭答應，對方就會接著說：「我不是要懷疑您，只是這筆錢對我來說很重要，您能不能提供一樣東西，暫時寄放在我這兒呢？」這時，受託的人也會因為拿著對方的鉅款，覺得自己也應該給對方一件較值錢的東西當作信物，然而詐騙人士就會拿著你給的信物逃之夭夭了。

# 樂於助人也不可盲目

一九八四年，一位男性正是用這個手法，成功騙了五十人，最後被逮捕了。他在被捕時說，只要鎖定看起來很認真的年輕人，成功率是百分之百。可見世界上還是有很多好人，會無條件地相信素昧平生的陌生人。

每個人都認為想幫助人、想做好事，是身為人的基本——平常沒機會助人的 人，大概更會這麼覺得吧！為了減少無法幫助別人的罪惡感，他們會在機會來臨時，積極向他人展現自己的助人熱忱，然後被騙得團團轉。
