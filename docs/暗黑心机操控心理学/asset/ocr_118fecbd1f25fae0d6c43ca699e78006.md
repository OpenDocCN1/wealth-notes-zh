# 雲霄飛車的「性興奮」

遊樂園經常被票選為情侶約會的聖地。特別是一起坐雲霄飛車或引人尖叫的遊樂設施、鬼屋探險，更能为兩個人的感情加溫。

並不只是因為男性能期待女孩子在驚聲尖叫後，緊緊貼著自己不放鬆，這個約會準則也經得起心理學驗證。

有一個心理學實驗如下：在一座七十公尺高的吊橋上，請一名男性走過吊橋後，在橋的另一端安排他和某位女性會面。接著詢問該男性對這名女性的印象時，得知他深受對方所吸引。這是因為「經過吊橋時，恐懼讓心跳加快」，而這樣單純的生理變化，可轉變成性興奮。

# 生理變化的錯覺

除此之外，還有一個實驗是請受試者先踩室內飛輪，在劇烈運動之後觀看色情片，調查受試者性興奮的程度。

實驗結果顯示：男性踩完全室內飛輪，再看五分鐘色情片，的確感覺格外興奮。運動本來就會讓心跳加速，卻造成了「性興奮」的錯覺。明明是運動或恐懼的關係，男性卻以為是因女性魅力而興奮的現象實際發生了。

因此，和異性一起坐雲霄飛車，或是結伴運動過後，兩個人會比較容易發生關係，就成了不争的事實了。
