# 01 先佯裝讓步，後面更佔便宜

「愧疚感」使人卸下心防

冒然邀請不熟的女性：「下次一起去旅遊，好嗎？」對方應該不會答應。可是，在對方婉拒之後，過一陣子再試著約她：「今晚要不要一起吃個飯？」一般女性心中普遍會因上次的拒絕而有所愧疚，自然而然就會心軟，覺得「吃個飯也還好」，答應你的邀約。

美國的心理學家羅伯特·席爾迪尼（Robert Cialdini），曾做過一個心理實驗。當研究人員詢問路人：「您明天方便來捐血嗎？」結果只有三十一．七％的人答應；六八．三％的人則當場拒絕了。接著，他們又試著拜託這些人：「您可以跟我們簽個約，預定今後幾年期間，每兩個月捐血一次嗎？」

當然幾乎所有人都拒絕這個請求，於是他們又接著問：「那只捐這次也沒關係，請您明天來捐血。」竟然就有四九．二％的人答應。

說服老手都這麼用

故意提出會被拒絕的要求，先讓對方婉拒，然後再說出原本真正的要求，這麼一來，對方會在心中比較兩個要求，反而覺得後來提的條件較簡單，就會忍不住答應。

這樣的技巧就稱為「以退為進法」（Door in the face），說服老手都是這麼達成目的。
