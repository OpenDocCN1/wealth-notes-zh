# 總是買太多

# 讓顧客「抓狂跟風」的從眾效應

從報章媒體看到特賣會資訊，人們總是興高采烈地到了現場，仔仔細細地逛了一圈、四處比價之後，最後覺得自己買到的都是超划算的東西。

可是等你回到家之後，當把商品從一包又一包的購物袋中拿出來檢視之時，這時在你理智較為冷靜之後，才會赫然發現買了這麼多東西自己卻根本沒賺到。

相信有很多人都有過這樣的衝動購物經驗吧？特賣會場的氣氛，似乎特別容易煽動購物慾和競爭心理。

這股「大家都這麼做，自己當然也就非做不可」的衝動行為，正是「從衆效應」的心理表現。

看到身邊大多數人都這麼做，受到這些人的影響後，就覺得好像應該放棄自己一廂情願的想法，跟著大家一起行動。

若是沒有遵從多數人的行為，會顯得自己不合群，心生不安。

# 煽動你的購物慾

在日本，有一個登門拜訪推銷的代表性手法，就是業務員會到國宅社區找一戶住戶，並且說服對方：「四樓的××也買了，七樓的△△也是：……」用這種暗示性的話語，強迫對方購買。

這個手法也同樣也是利用「無法不跟其他人買」。
