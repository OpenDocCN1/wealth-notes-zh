# 19
「YES」問話術，讓人難拒絕的詭計

為什麼A會被老闆說服呢？
上述舉例是蘇格拉底擅長的「反詰法」，他會不斷回答「是」、「對」；於是，原本會否定的事項，也在不知不覺中答「YES」了。

A先生在東京的總公司工作，最近他接獲調職指令，要被調到外縣市的分公司去。A自然不願意，最後終於被老闆叫去談話了。

+   老闆：「嗨，A，最近好嗎？」
A：「是，托您的福，我最近很好。」
老闆：「A，你也滿四十歲了呢。」
A：「對，前幾天終於過了四十歲了。」
老闆：「對了，老家的爸媽都還健康嗎？」
A：「是，托您的福。」

+   （對話持續……）
老闆：「那你願意調去那家營業所吧？」
A：「是，請讓我過去為您效力。」

# 如何自保

心理學有個「自我概念」的理論。當人在某個情境下做了一個決斷，馬上又置身同樣的情境時，會傾向重複上次的行為。因為人有一維持自我概念的求，因而產生了心理作用。

當陷入只能重複回答「是」的過程，拒絕的意志會越來越薄弱，即使是切身相關的問題，也會不由自主回答「好」。當被詢問只能回答「是」時，你得轉移話題，準備好說「NO」。
