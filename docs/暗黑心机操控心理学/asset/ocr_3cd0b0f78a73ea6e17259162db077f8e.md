# 「只有您」的話術

電視購物頻道以前常使用「只提供給現在正在看節目的您！」這句台詞。不過，在幾百萬名觀衆前說的話，怎麼可能只服務你一個人呢？可是這招話術還是相當有效。

人都會對任何一種形式的「實力不被認可」而感到不平、不滿，而「只有您」這句話，就能觸動這樣的自尊心，讓人毫無防備。

「您從一萬人中獲選了！」「只提供年薪六百萬以上的菁英。」諸如此類的電話，即使當事人明明知道事有蹊蹺，卻還是忍不住聽下去，就是因為自尊心被撥動，以為「實力被認同」的時刻終於來臨，因而展現的弔詭心理。

# 證照強迫推銷

其中最典型的詐騙手法，就是「證照強迫推銷」，也就是隨便編出「××師」、「△△鑑定師」、「○○教練」等看似有模有樣的資格，然後對參加證照講習會的其中一人說：「只有您獲選了。」

他們會用「近期會變成國家證照」的說法來引誘對方，騙取這個不存在的資格證照的講習參加費、教材費、註冊費。
