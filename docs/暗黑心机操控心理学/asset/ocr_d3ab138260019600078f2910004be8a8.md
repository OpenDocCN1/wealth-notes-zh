# 「盡量試用」背後隱藏的掙錢心機

化粧品專櫃的試用品堆積如山，很多食品賣場也有試吃，服飾店的店員則會在您找衣服時湊過來建議：「您可以試穿看看喔。」總而言之，就是要你試試看──這種銷售方法之所以常見，就是因為「模擬體驗」確實見效。

美國曾進行過相關的實驗，讓抽菸的學生扮演肺癌患者，並且宣告：「你得了肺癌，必須開刀。」接著和醫生詳談手術及後續處理。在扮演遊戲結束後，抽菸的學生要不是戒掉菸癮，就是減少了抽菸的量。

口頭說明白難以令人信服的事，只要實際體驗過，就會變得容易接受了。
