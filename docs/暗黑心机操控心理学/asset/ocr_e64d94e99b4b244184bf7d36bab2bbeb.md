# 說服力最強的肢體語言

習慣動作會透露本意

人的表面舉止，永遠與內心想法存在差距。從頭到尾面帶微笑，好像很體貼的人，一到結論卻執意不退讓。

不管臉上的笑容有多燦爛，當做出以下動作，就是「拒絕」的微兆

+   ▪ 雙手抱胸：基本上代表拒絕。這是不讓對方踏入自己領域的姿態，但如果伴隨著點頭、微笑，則有可能表示接納、感興趣。

▪ 手指摸鼻子：手指摸著鼻翼，代表「懷疑」；頻繁搓鼻子，則代表「拒絕」。手指放在鼻子下方，大多意味著「不愉快」。

▪ 食指摸鼻子：表示感到煩惱、需要解說。

+   ▪ 小指挑起耳朵邊頭髮：表示覺得懷疑。

▪ 抿嘴微笑：即使臉上帶著笑容，多半代表拒絕。

# 開放與封閉姿態

心理學家麥金萊曾針對說服的姿勢加以研究，他將說話姿態概分為「開放姿態」和「封閉姿態」，並認為前者比較能說服他人。

開放姿態是指臉朝正面，雙腳稍微打開，讓對方看見手掌的姿態；封閉姿態則是雙手抱胸、翹腳的姿態。

要是擺出封閉姿態說服人，不管你給對方的好感有多強，他都很難答應！
