# ## 眼神閃爍？騙子眼晴難有破綻

![](bbox=[0.73, 0.02, 0.85, 0.18])

一般常說「別開視線就是說謊的證據」。實際上，專業騙子才不會因為這樣被識破。要是心想：「擁有這麼乾淨的眼神，才不會騙人。」而輕信對方的話，就會發現他才是高明的騙子。

臉上會表現出說謊徵兆的人，代表他們對說謊有罪惡感、感到不安。然而在詐騙分子之中，有很多人數於騙人是完全不會感到罪惡的。

想欺騙敵人，就要先騙得過自己人；想欺騙對方，就要先讓自己認同。因此專業的詐騙分子反而會筆直地看著對方的眼睛，用沉穩、帶著權威的口氣說服人。
