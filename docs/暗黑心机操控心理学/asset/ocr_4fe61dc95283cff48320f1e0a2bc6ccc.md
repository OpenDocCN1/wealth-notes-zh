# 易對同鄉抱有親切感

# 找關係，拉關係，怎麼做都沒關係

「什麼？你也是××人啊？原來我們是同鄉喔！」即使是偶然遇見的人，也會因此而產生親切感。來自同一個家鄉、同一所學校畢業、興趣相同……只要有了共通點，再小的事都足以拉近彼此距離。這就是心理學的「相似效應」。

人們甚至會因為「名字縮寫一樣」這樣的理由而心生親近，這是因為人心潛藏著「我討厭孤獨」、「我想和別人融洽相處」的陰影。

# 共通點能為「好人」形象加分

要是所有的人都是好人也就罷了，可是偏偏就有人會趁虛而入。

當我們接到「我是××高中△△年畢業的學弟……」的電話時，就願意聽對方說下去，但學弟的真面目卻可能是拿著畢業紀念冊，從頭打電話到尾的期貨推銷員。

當女性來電說：「要不要碰個面？以前都沒什麼機會跟你聊天。「你應該也會開開心心、毫無警戒地約了幾次，結果某天她突然帶你去直銷會場，強迫你入會，這就是典型的「約會強迫推銷」。

同鄉，也不過是跟自己有一點像，但我們卻會陷入「認定對方是好人」的心理陷阱。這就像是挖洞給自己跳，主動上當了。
