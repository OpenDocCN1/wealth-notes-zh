# 「好感度」等於「好商品」的廣告洗腦術

# 業務勤跑，不會做白工

想要推銷商品時，如果對方不曉得有這個產品的存在，我們也無從談起。為了增加新客戶，不盡一切努力接觸越多人，機會也不會來臨。之所以會有「業務人員」這個職業存在，就是為了要從早到晚走進人群，到處「打招呼」、「打好關係」，建立人脈。

上述的作用機制，在心理學中被稱為「單純曝光效應」，美國的心理學家札恩茲（Robert Polesav Zajonc）便曾經做過相關實驗，加以證實。

這個實驗是先從畢業紀念冊中隨機抽出當中的學生照片，並且以兩張照片為一組，分成A

到F共六組，並給學生看A組照片一次、B組照片兩次、C組照片五次、D組照片十次、E組照片二十五次，F組照片則一次都沒給學生看。

當學生看完照片之後，札恩茲詢問他們對照片中的人物印象，結果發現看過的次數越多，對照片人物抱持好印象的傾向也越強。

將照片換掉，改成與實際的人物見面，最後得到的結果也是一樣。
