# 恐懼會伴隨敵意

美國心理學家詹尼斯（Irving L. Janis）和費許巴克（Seymour Fisher）曾做過一個實驗。他們將參加預防蛀牙講習會的人分為 A、B、C 三組，分別宣導刷牙的重要性。講習途中，安排 A 組看蛀牙末期症狀的投影片，B 組看初期症狀，C 組只看與牙齒成長及功能有關的投影片。接著再對三組成員同樣做了「一定要愛惜牙齒」的結論，最後調查參與者的心得。

強烈的恐懼過後，會產生很強的否定情緒，促使記憶試圖忘掉該情報，而且還會忍不住對帶來該情報的對象抱持敵意。

用威脅手段說服似乎很有效，但會帶來反效果。威脅時不能過度刺激對方，只要足以產生緊張情緒即可，因此委婉的威脅是很重要的。
