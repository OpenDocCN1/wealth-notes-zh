# 06 人類大腦有弱點，容易被騙的要害

# 大腦記憶的特性

當我們回想起某個人時，印象最深刻的應該還是初次見面時的印象吧？這是因為人類的記憶結構具有「序列位置效應」（serial position effect）的特性，當事情一連串發生時，只有最初和最後的印象，會強烈停留在人的大腦中。

美國心理學家喬治·米勒（George Armitage Miller）曾進行過一個實驗，他請學生們閱讀一篇關於吉姆的文章，然後詢問學生的意見，評論主角吉姆是有社交性或不具社交性的人。

這篇文章的前半段大幅描述著吉姆很外向，後半段則是側重內向的一面。結果所有的學生都回答吉姆具有社交性，為人和善又積極，毫無例

外。

米勒接著又請其他學生閱讀「前後半段對調」的文章，然而這一為的學生全都回答吉姆不具社交性，而且個性消極。

# 第一印象很關鍵

上述這個現象，就稱為「初始效應」，說明人們很容易相信一開始得到的資訊。

最初見面時，假如對方的穿著整潔得體，人們就會輕易地相信對方——很多詐騙事件都能看到這樣的例子。

人們即使之後發現對方有些可疑，也會自我說服而刻意忽視掉，最後便受騙上當了。
