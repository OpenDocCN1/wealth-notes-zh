# ## 反覆灌輸暗示，控制思想的洗腦

像這類邪教或組織的思想控制，有以下幾種方法。接下來讓我一一說明。

+   - 阻斷感覺：阻斷任何的感覺資訊，也就是所謂的「洗腦」。

邪教團體會以「研修」、「靈修」為名，首先會把信眾帶到隔絕外界、無法接觸人們的封閉場所，例如深山之中。接著把信徒關進狹窄的房間內，斷絕所有的通訊設備，長時間封鎖來自外界的資訊。

當人們長久處於完全無法接收外界資訊的環境之中，內心不僅會感到強烈的不安，渴求刺激的欲望也會一波波襲來，逐漸侵蝕敏感的心靈。在這個狀態之下吸收的資訊，便会深深滲入內心深處。

+   - 阻斷感覺，清空大腦

藉由控制外部環境條件，深入心靈、操控人心的手法，就叫做「思想控制」。

在過去，曾犯下殺人重罪的奧姆真理教正是以運用各種手段、全面控制思想的駭人行徑而聞名。

即使奧姆真理教的信徒一度脫離組織，但清醒一段時間後又馬上後悔、轉身重回教團懷抱的人，其實為數不少。

這個現象也間接證明，人們要脫離思想控制非常困難。實際上，只要一天深陷其中，無論你再怎麼努力、掙扎、用盡一切辦法，這輩子就永遠難以脫身了。
