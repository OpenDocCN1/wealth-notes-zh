# 用反問回答問題，洩漏心虛

交往對象最近感覺有點冷淡，因此你千方百計要找出真相。

可是，要是單刀直入：「妳是不是有別的男 人了？」兩個人的關係可能也就到此結束了。這時 候不如問：「妳是不是有什麼事瞞著我？」來 觀察對方的反應。

萬一女友回答：「沒有啊。你才有什麼事瞞 著我吧！」那就非常可疑了。即使你回答沒有， 也會被「那你幹嘛騙問我？是你心虛才會這麼問 吧？」岔開話題。

用反問回答，就是試圖含糊帶過不想回答、 不想被人知道的事情時，心理所產生的反應。若 說話的速度變快，那就更可疑了。
