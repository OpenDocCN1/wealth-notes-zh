# 花言巧語如蜜糖，最黏女人心

偶像劇成真

感情騙子不只善於包裝自己，給人充滿魅力的印象，他們也能精準拿捏女人心，女性想聽任何甜言蜜語，他們都能能毫不害臊地說出來。感情騙子的目的就是騙取金錢，所以絕對不會讓對方不開心。一般情侶絕對說不出口、只會在偶像劇裡出現的台詞，他們也能發揮自如，而且很擅長撥動女性的心思。

感情騙子都會很勤勉地陪伴女性，毫無例外。他們會頻繁地打電話、送禮物，或是邀請對方約會。女性遇到這類攻勢，難免覺得：“以前都沒人費這麼多心思追我，這個人真特別。”不過，詐騙分子的工作內容本來就跟一般人上班族不一樣，時間當然多得不得了。

如果是—般正常情境下的男女關係，交往到一定程度後，通常就不會像剛認識的時候，天天在耳邊呢喃甜蜜蜜語。可是，感情騙子就不同了，他們的嘴巴上會一直掛著花言巧語，讓女性芳心朵朵開。

利用溫柔獲取女性的心，讓對方無法輕易離開自己，這個時候再進一步提出：“我想跟你結婚，可是……”最後將話題帶到自己因為某些原因急需用錢，終於從女性身上騙得鉅款。
