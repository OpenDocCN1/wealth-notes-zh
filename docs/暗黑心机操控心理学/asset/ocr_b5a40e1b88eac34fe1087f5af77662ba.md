# 誰都言聽計從的寂寞心靈

房屋改裝詐騙的受害者大多都是獨居老人，手法便是突然登門拜訪，熱情地說：「免費診斷您住的房子喔。」接著鑽進天花板、地板夾層，謊稱「嚴重舊化」、「地板下有白蟻」等等，要求老人支付高額的施工費用。

基本上，獨居老人都很寂寞，就連子女都很少來探望。但是推銷人員卻會頻繁來訪，溫柔地陪他們說說話，嘘寒問暖，讓老人家忍不住相信並依賴對方，進而受騙。

很多獨居老人會購著家人支付高額費用，若是被發現了，還會站在推銷人員那一邊，完全不認為自己上當了。
