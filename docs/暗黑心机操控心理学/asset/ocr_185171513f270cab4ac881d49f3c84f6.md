# 「感心廣告」會催眠，買到手軟都安心

動機名正言順，顧客更買單

掃地機器人、洗碗機、快速料理包……讓家庭主婦更有效率處理家務的發明漸漸普及，現在可以說沒有家電，就沒辦法完成主婦的工作。然而在前一陣子，主婦利用「微波爐」烹飪，內心多少會有一「不用心照顧家人」的罪惡感。

即溶咖啡在美國剛上市的時候，廠商以「簡單」、「方便」的標語來宣傳，可是「咖啡一定要從磨豆開始」是許多人根深蒂固的常識，一時間很難接受即溶咖啡。

於是廠商轉換策略，以「即溶咖啡，讓你多出時間留給家人」來宣傳，這樣促使主婦轉變心態——我用即溶咖啡不是因為輕鬆，而是為了丈夫和孩子！

# 普世價值的理想難抗拒

即使做的事實質上就是「偷懶」，但只要說成「節省時間」、「為了家人」，給予對方合理的動機，就算事情的本質不變，對方也能毫不抗拒地接受。

就像許多直銷商會主張「改變因循守舊的制 度」、「只要努力，每個人都能獲得幸福」；宗教的大義名分也一定是「世界和平」或「救贖」。

發動沙林毒氣事件的奧姆真理教也一樣，信奉深信可以透過殺人來救贖對方，很多人確實受到這種洗腦與誤導而犯罪。
