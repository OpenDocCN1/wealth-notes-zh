# 『眼睛』會洩漏情報

街頭強迫推銷的老手，只要看著對方的眼睛，就能立刻確定眼前的人有沒有機會說服成功。他們正是透過眼睛的視線，進一步解讀人們的心理狀態。

當對方說話時，眼睛毫不閃躲地看著你，呈現的就是一種說話」的心理狀態；相反地，當對方避開你的目光，就表示他此刻並不想跟你說話；原本眼睛筆直注視著你，但在中途卻忽然開始避開你的視線，就表示對方對你說話的內容已經不感興趣了。

另外，人們面對討厭的對象時，會刻意降低回話次數、不經意從應話內容透露霹等等，除了這些輕而易舉就能從言談間察覺的徵兆之外，也往往會出現目光閃躲的傾向。

除此之外，也有些人會在你說話的途中眼神飄移，這種狀態多半是因為精神緊繃、不安，或是抱有戒心而造成的。他們會不停移動眼睛，看東看西，試圖擴大自己所能看見的範圍，儘可能收集視覺資訊，藉此判讀周遭環境與對話氣氛，好讓自己安心下來。
