# # 12 話要說得動人，「表情」很關鍵

# ## 怎麼說話才動聽

一說到推銷人員，大家肯定覺得他們「很會說話」，但實際上並非如此。

美國肢體語言研究權威心理學家麥拉寶（Albert M. Mehrabian），設計了一種公式，用以判斷人在說話時，表情、聲音與字句的影響比重。

結果是表情占了五五%，對聽眾的影響力最大；其次是聲音占三八%；而字句僅僅只占七%。

聲音特質的相關研究也證實，一個人的音量大、低沉、有節奏感且充滿活力，就代表這個人的外向、具有領導力和說服力。的確，經驗老道的推銷員會用錄音機把自己的聲音錄下來，訓練如何把話說得更多魅力。

# ### 聽見自己真正的聲音

演講者、電台DJ、宗教界頂尖人物等，大多擁有獨特的嗓音，能夠讓聽眾陶醉其中。

一般來說，若要吸引對方的心，重點就是用低音、音量大、有節奏的方式說話。不過，你知道自己的聲音實際聽起來如何嗎？

我們平常聽到自己發出的聲音，是通過頭蓋骨直接震動鼓膜，所以跟別人實際上聽到的聲音差距相當大。若試著錄下自己的聲音，應該有不少人覺得根本像是另一個人。
