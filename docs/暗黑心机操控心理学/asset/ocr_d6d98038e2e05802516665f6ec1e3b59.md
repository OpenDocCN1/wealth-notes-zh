# 暗藏玄機、勾引人心的「交易陷阱佈局」

形象儘量曝光。讓更多的人們看到，才是行銷最重要的目的。

此外，政治領域的新聞記者也常用「一夜訪朝探」的方法。他們會在大清早或下班回家的深夜，突襲捲入案件的政治人物家中。這是利用其他多數人（包含政治家在內）休息的時段，凸顯記者仍熱心工作的勤奮形象，引起對方注意，進而產生過意不去的想法。

# 多露臉，就有機會

不管是推銷還是其他人際關係的經營，只要不斷露臉，被拜訪的一方就很難忽視，甚至會逐漸產生親切感。成功創造出突破口後，接下來的發展也就水到渠成了。
