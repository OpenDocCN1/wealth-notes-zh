# 第三章 敲開心防，詐騙邪教的洗腦布局

# 16 博取同情的「小額詐騙」致富術

「希望妳借一點錢給我，我馬上就會還。」
像這樣用各種理由，每次只騙走幾百元的手法，就稱作「小額借款詐欺」。

因為金額少、轉眼之間發生，因此受害人不太難抓到這些騙子。即使一次只騙幾百元，積沙也會成塔，有的騙子重復行騙，最後騙取數百萬元。

他們的藉口五花八門，大多是「我的錢包丟了，能不能借我錢搭車」。得手率會這麼高，當然是因為金額少，而且巧妙地利用受害人的同情心。人們一廂情願認為不出手幫助的話，他们就太可憐了。假若沒發現自己被骗，倒也能維持快樂的心情。
