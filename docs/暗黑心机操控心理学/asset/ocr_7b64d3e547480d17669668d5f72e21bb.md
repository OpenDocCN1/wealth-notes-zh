# ### 約會燈光暗一點，貼心話容易說

黑暗使男女親近

美國心理學家格根（Keme 1 Gorgen），曾經做了一個實驗，他安排六、八名男女分別待在約一坪大的小房間內，為時一小時，並調查每個人的行動。

進入明亮房間的男女，都會彼此保持一段距離，聊著不痛不癢的話題，幾乎沒人更換位置。反觀進入黑暗房間的男女，隨著時間經過，他們交談越來越少，許多人換位置，不久後便開始擁抱、觸碰身體，男女關係變得更親密。

這是因為黑暗中人們看不清彼此，反而能夠放開顧慮，大膽行動。

# 魅惑的舞臺

搭乘電車時，與隔壁的人聊天，竟然不經意地袒露非常親密的私事，自己都嚇了一跳——大家是不是常碰到這樣的情況呢？

面對親近的人，我們必須維持形象，展現好的一面，無法展露真正的自己。若是碰巧同行的陌生人，即使是私事也能放心說出來。

在黑暗中，男女都會放下戒心，打開心房說出具心話，容易營造出氣氛。酒吧或夜店的燈光昏暗、一起加班的男女同事容易感情變好，也都是出自這個道理。以往總是一個人度過的夜晚，卻可以和另一個人共享，便會學得出親近感。
