# 顏色包裝，誘拐人心的欺騙手法

家路易·關斯金 (Louis Cuseck) 所進行。值得一提的是，關斯金本人覺得C的彩色組合相當理想，也是他親自設計的。

# 包裝效果不容小覷

有三種不同的中性清潔劑，分別編號為A、B、C，其中A裝在黃色的容器內，B裝在藍色的容器內，C裝在藍色中點綴著黃色的容器內。

接著，請主婦們分別使用這三種清潔劑，連續一段時間，測試清潔劑的去污效果。主婦們得出的結論分別如下——

+   • 清潔劑A：去污力強但很傷手，令人困擾。
• 清潔劑B：洗後很清爽，卻很難去除污垢。
• 清潔劑C：洗得乾淨也不傷手，最要好好評。

但其實這三款清潔劑都是一樣的！

上述這個有趣的實驗，是由美國色彩心理學

# 顏色的超級力量

商品的顏色，不只會影響消費者購物時的心理，甚至還會左右使用時的感受。

根據關斯金的研究指出，某家公司用黑色的容器搬運商品，一到下午，負責運貨的員工們全都開始抱怨身體不舒服，覺得很疲憊。不過，在將所有的容器重新塗成淡綠色後，員工的怨言就消失了，工作效率也猛然倍增。
