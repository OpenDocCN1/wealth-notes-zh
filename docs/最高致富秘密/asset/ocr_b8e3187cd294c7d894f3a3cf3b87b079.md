她優雅但堅定地說：「不用擔心，妳土星回歸的課題到 現在仍然有效。要是妳能領悟它帶來的課題，妳還是能突破蛋 殼。」

知道自已還有機會後鬆了口氣，雖然晚了十年，但我還 是想要像小雞破卵一樣進入新世界，叙玹也同時在外面幫我打 破蛋殼，我現在沒太多時間能浪費。

# 導師語錄

+   「土星回歸通常是在二十八到三十歲， 還有五十八到六十歲之間， 這個時期幻想和自以為的聰明會被滅。要是能好好利用， 妳會產生質變。這時候更需要專注自己內在聲音和實踐 『當下擁有』，而且效果會十分顯著。 」

+   「佛家語有句話叫『啐啄同時』， 它的意思是，小雞要從蛋裡孵出來， 得靠自己跟母雞同時從內和外打破蛋殼才行。 這和土星回歸的概念是一樣的。 妳想要突破外殼的欲望，和宇宙要打破它的能量同時相遇。 在這期間裡，所有的痛苦都是幫助妳昇華的能量。 當妳衝破外殼後就會進入真正的世界中， 妳有很大的能力可以掌握妳的生活。」
