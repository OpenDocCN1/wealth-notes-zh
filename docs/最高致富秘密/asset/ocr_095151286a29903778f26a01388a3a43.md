告別後，我走出屋子，感覺和我剛進來時完全不同，像是進入另一個時空。全身心都知道我已經離開母體，我精力充沛地往前邁進。

# 導師語錄

+   〇「多數人都沒意識到自己有這樣機械論的觀點。他們視這世界為一座巨大的工廠，而自己只是裡面的一個小齒輪。枷鎖很早被套在身上，這一輩子能賺多少錢也底定好了。他們會覺得不能貪心，而且得做出犧牲，這樣才能擺脫貧窮。」

+   〇「妳目前所感知到的，不是母體外面的真實世界。在真實世界裡，妳能聽到真正的聲音，釋放妳的潛能，隨心所欲改變世界，這就是真實人在做的事。對他們來說每一天都是真實生活，為之歡慶。」

+   〇「信不信由妳，妳已經在打破監獄的圍牆了，把汲取妳能量的軟管拔除。」

+   〇「『當下擁有』就像耶穌誕生時，天上出現指引人們的伯利恆之星。它能減少妳的恐懼和焦慮。」

+   〇「妳才是突破母體的人，沒有人能代替妳做這件事。妳已經快到了，洪女士，只要再往前踏一步，事情會比妳想像的來得快又容易。」
