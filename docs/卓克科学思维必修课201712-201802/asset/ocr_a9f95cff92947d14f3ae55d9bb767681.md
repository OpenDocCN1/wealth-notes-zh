D。

这段时间，智人的文明程度应该是发展了很多，C 在东南亚应该是落后了，结果是在距今3万年的时候，C 的数量大幅下降。ON 组合看起来是一个强有力的入侵型，这个过程可能类似于16世纪欧洲人灭掉了南美土著那样。而就是这批入侵者，奠定了如今东亚黄种人的主要血统，包括我们中国人。

但 D 的系列并没有灭种，他们的生活空间不断地往东压缩，最后都被挤到现在的台湾岛上，又从台湾岛往东北方向走到了琉球群岛。当然那个时候，琉球是陆地。然后又从琉球继续往北，走到了现在日本的九州岛，这群身材矮小、皮肤黝黑的 D 分支就是在我们之前课里说到的日本最早的祖先，绳文人。

ON 组合别看驱除了 C 跟 D，他们互相也在激烈地竞争。O 分成了 O1、O2、O3，这 3 支是中国人最主要的祖先。

O1 主要生活在中国南方，长江中下游就是他们长期盘踞的位置，而在之前我们讲五谷杂粮中水稻的来源的时候，最后我提了一个问题，都说华夏民族起源自黄河，那为什么后来在考古的证据中发现，距今 9500年前到7000年前，有大量的碳化的水稻颗粒在长江流域被发现了？因为有这些颗粒保存就说明那个时候已经出现农业了，其实答案就落在今天这里。

那是 O1 这批人祖祖辈辈在这里生活留下来的，这批人后来被叫做百越人。

而 O2 那一批生活在内陆的人规模比 O1 还要大，他们叫做百濮人，一直生活在中原地区的百越跟百濮后代形成了华夏民族的主体，没有融入到这边的百越跟百濮人，在周朝时代主要偏居在云贵地区跟越南喃甸。等文字出现了之后，百越跟百濮这两个词反而是专指西南地区的少数民族了，其实他们在3万年前跟我们是一家。

# ——◆ 今日内容小结 ◆——

这节课的年代跨度很大，我们能从中得到什么规律呢？

你发现没有，不论是我们走出非洲沿着哪条路，还是使用哪种语言，这些最终的选择都谈不上是谁规划的，或者是某位领袖、某位祖先的创举，都谈不上。

我们更应该转变思维，从另一个角度想，几万年前一定也有很多人试图走出非洲，没有从东非沿着海岸线走，也没有到达过巴勒斯坦这个位置再分流，但他们会在半路遇到更大的困难而团灭。也一样出现过没有“踢踢踏踏”发音的语言，但那种交流方式会把动物们都吓走，自己没有了食物，也更容易团灭。

所以一种民族的出现，一种语言的出现，都是在各种限制的夹逼下，自然而然展现出来的那些可能性，这些可能性几乎无法提前预知，它在大跨度的历史时间中基本就是由大的背景参数筛选得到的。比如季风常年怎么刮，哪里的地势低容易存水，哪儿是盆地，哪儿更容易干旱，它们塑造着地球的生物，也塑造着人类历史跟语言。

# ——◆ 今日思考题 ◆——

在19世纪末，当时为了沟通更顺畅，矛盾更少，世界语被发明出来了。它的发音简单清晰，语法明了，和世界上的其他语言都不一样，比如像拉丁语系的语言有一个特点，就是发音上是没有特例的，只要你会说，一定就会写，不会像咱们中文会说跟会写中间还差着一大截呢？但是拉丁语系的语法是很复杂的，也会有很多特例。相比来说，英语就是在发音跟语法上都有大量的特例，从学习难度和掌握的速度上看，世界语确实是容易多了。

那么如果你参考我们这节课说的规律，你是如何看待世界语的呢？
