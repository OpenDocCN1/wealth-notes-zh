# ——概念15：泡沫——

一项新的科研成果出现，总会引发很多人的热情，有些人是为科学欢呼，有些人则希望从中渔利，于是泡沫从中诞生。识别出泡沫，不但有利于保护我们自己，也能在识别的过程中进一步理解科学的本质。

小时候最吸引我的几个科学问题是：

+   外星人是不是被美国国防部给藏起来了？
百慕大三角的海底有没有魔鬼？
尼斯湖的水怪到底是哪种恐龙？

那时候还专门有一本介绍外星人的杂志叫《飞碟探索》，我经常看完了，夜里不敢去上厕所。

# ——尼斯湖水怪传说——

这些讨论我们先放一放，我们先来聚焦在尼斯湖水怪上，挖一挖这个文明世界的传说是怎么出现的。

苏格兰北部的尼斯，从一九二几年就开始有人陆续地说，在尼斯湖里看到了奇怪的东西，当地的报纸就会刊登这些奇闻怪事。

# ——恶作剧——

第二年，有一个外科医生叫罗伯特·威尔逊，他拍摄到了水怪的照片，而这张照片后来也成为尼斯湖水怪最出名的证据，那就是在一个昏暗的水面，有一个动物耸着长长的脖子，样子说起来它的上半身有点像条龙，当时《每日邮报》都从伦敦派来了记者去采访，之后这个消息就快速散播到了全世界。

# ——谣言粉碎——

虽然这是一个恶作剧，但围绕尼斯湖水怪的调查可真没少做。

1962年，英国成立了尼斯湖现象调查局，他们找了6年都没有结果。
