# ——◆骨头汤无法补钙◆——

最没用的就是喝骨头汤。
直觉上，钙是骨头很重要的成分，那么嚼不动那些骨头，用骨头熬汤总能补钙了吧？

# ——◆虾皮无法补钙◆——

下面一个经常听说的方法，就是吃虾皮。
