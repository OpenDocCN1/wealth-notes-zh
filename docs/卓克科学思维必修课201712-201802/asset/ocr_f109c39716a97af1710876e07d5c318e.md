# 概念12：旁证

对历史事件的研究很难有直接证据，所以旁证和考据就是重要依据。基因技术的出现，让历史研究中的旁证更加坚实，很多从前打嘴仗的内容，现在变得无可争议。这一系列我们介绍衣服、猫、狗、人的起源，就是利用了旁证。

# 139 | 旁证：最早的语言听上去什么样？

+   1. 人类祖先的迁徙，不是那种日夜奔袭，前往一个目的地的搬家，而是在几千、上万年的时间里，随着觅食范围的变化而自然发生的居住地变迁。\n2. 一种民族的出现，一种语言的出现，都是在各种自然条件限制的夹逼下，自然而然展现出来的那些可能性，这些可能性几乎无法提前预知，它在大跨度的历史时间中，基本就是由大的背景参数筛选得到的。

# 140 | 旁证：人类祖先是怎么逃过大灾难的？

+   1. 触及文化和心理元素的复杂系统，没有清晰的边界、确定的过程和稳定解，人为地设计与限制，需会付出极高的成本，因为始终都要跟新的趋势抗衡。\n2. 人类祖先面临极为严苛的生存条件，除了我们都灭绝了。通过发掘古人的语言和艺术品，是大规模协同让人类存续至今。\n3. 苏美尔、古巴比伦、古埃及、古希腊、古印度、古中国都有大洪水的记载或神话，这源自地球在比较暖和时期的冰雪消融，由此推断，人类在5万年前就有了语言。

# 141 | 旁证：文字诞生前的人类文明

+   1. 一个自然演化的体系，在有约束条件存在的情况下，自然会往约束少的地方流动演化。\n2. 资源丰富也不一定全都是好事，一个困境，只要保证了最低的生活条件，就能产生各种可能性。\n3. 科学是一个客观理性的工具，它可以纠正历史记录中的偏差，客观上拉近了世界民族之间的距离，降低了民族主义中无来由的优越感。

# 142 | 旁证：酵母菌也能致命吗？

+   1. 酵母菌是适应性超强的真菌，可以在无氧环境下生存，在有氧状态下快速繁殖，60摄氏度以上才会死亡，零下20摄氏度冻上几天，死亡也不多。\n2. 人体内的肠道菌群处于精准的动态平衡状态，但人体变弱、微生物变强都可能打破这种平衡。\n3. 格特隐球酵母菌是一种高危真菌，随着全球变暖，它的繁衍开始扩散，与人类的生存空间产生了更多重叠，在形成新的平衡前免不了带来疾病与死亡。

# 答疑时间

# 143 | 问答：猪肉打激素了吗？

+   1. 猪和鸡的快熟猛长，是靠一代一代育种筛选出来的品种。正规渠道买到的肉类制品应该都是安全的，大人孩子都可以放心吃。\n2. 养殖业不太可能使用“激素”对牲畜进行催熟，因为它不仅贵，而且会抑制生长。\n3. 美国、东南亚的很多国家都在使用合法的瘦肉精“莱克多巴胺”，但中国是禁止的。另外，它在猪肉中的含量几乎不可能对人产生危害。\n4. 瘦肉精在中国也禁止生产，因此不容易买到，价格也贵，偷加的养殖户很少。

# 144 | 问答：养殖场滥用抗生素，肉还能不能吃？

+   1. 不用担心吃到猪肉里的抗生素，因为在屠宰前，会有几天停药期，药物会在猪的肝脏、肾脏里代谢完。\n2. 抗生素禁用后，就是大面积的猪瘟，到时只能吃到病猪和死猪，危害更大，所以在养殖环节，抗生素是不能禁止的。\n3. 滥用抗生素真正的危害，是把养殖场变成了耐药菌工厂，细菌的耐药性还会通过基因平移转给其它菌种，虽然人体的免疫系统能够抵御，但是一旦免疫系统出现问题，再被耐药菌感染时，可能就找不到有效的抗生素了。
