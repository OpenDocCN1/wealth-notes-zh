# 128 | 旁证：黑猩猩还有机会变成人吗？

# —— 概念12：旁证 ——

对历史事件的研究很难有直接证据，所以旁证和考据就是重要依据。基因技术的出现，让历史研究中的旁证更加坚实，很多从前打嘴仗的内容，现在变得无可争议。这一系列我们介绍衣服、猫、狗、人的起源，就是利用了旁证。

黑猩猩还有机会变成人吗？

这个问题几乎就是一个十万个为什么级别的问题，相信听了这么多节课，各位都可以顺利地答对，没有机会了。

原因是，我们跟现存的任何一种猩猩都是早在几百万年前就分道扬镳了，然后各自在不同的道路上越走越远。

可以用一个形象的比喻：

假设演化的路径就像铁路，每个城市就相当于演化过程中出现的物种，北京人假如是人类跟各种猩猩的共同祖先，上海代表着现代人类，那么我们这一支是从600万年前沿着京沪线走了过来，而其他的猩猩有的走的是京哈线，有的是京九线，有的是京包线，它们也走了600万年。当我们到达上海的时候，它们分别到达了天津、霸州、保定、张家口。它们明显进展慢一些，我们都已经到了上海了，它们才走了100多公里，但我们走的依然是完全不同的道路。

![](bbox=[0.12, 0.00155, 0.9, 0.00235])

也就是说，现在的黑猩猩、红毛猩猩、大猩猩和几百万年前它们的祖先也 Athletics 不太一样了，只不过差异的幅度没有我们人类跟祖先的差异那么大。我们这一支跟几百万年前的差异之所以这么大，是因为我们的生活环境变化太大了，其他猩猩也沒有可能退回到北京重新走京沪线，所以这就注定了它们没法演化成人。

最终演化成智人的这一支，经历了很多次形态上的变化，比如说著名的露西，在归类上属于南方古猿阿尔法种，而南方古猿还有其他很多种，比如像埃塞俄比亚种、鲍氏种、祖祖种、非洲种，但它们都在半途绝灭了。

![](bbox=[0.08, 0.00335, 0.88, 0.00425])

而且现在看来，有一点不可思议的是，灭绝掉的这几个种，都属于是南方古猿中体型粗壮、肌肉发达的，活下来的反而是那些瘦长型的古猿，后来它们发展成了能人、直立人、海德堡人、尼安德特人、弗洛勒斯人、丹尼索瓦人，当然还有我们人类。

# —— 是人还是猿？ ——

那我们现在是怎么确认那些几百万年前的灵长类不属于人类呢？毕竟不能亲眼所见。

所以我们只能靠间接证据。

最简单的几个例子，我们可以举一些：
一个是对比如脚的样子，看看大拇趾跟脚上其它四个脚趾是不是朝一个方向，是不是都向前。

![](bbox=[0.12, 0.0060999999999999995, 0.88, 0.00715])

只要我们看到这一个差异，就应该意识到哪边的物种离人更近。如果是左边那种，一定不可能人类，那种脚还是—种适合抓握的形状，也就是说它还生活在树上，面临的生存压力跟环境选择跟其他的猴子没什么区别。

但是如果是右边这种，起码可以说明它是以直立行为为主的，因为只有五个脚趾头全朝前，才有可能统一地高效率地向后蹬地，才有可能快速直立奔跑。

而且也因为这样的模式，粗壮的拇指开始承担全身40%的体重了。那你现在可以不脱鞋，想象一下，如果你现在光着脚，双脚大拇指同时受了伤，不能着地，你走路受到的影响会不会非常大呢？但是现在你再想，如果你双脚受伤只是小拇指的话，你走路受到的影响是不是小很多呢？这个就是大拇指结构上的变化对直立行走的影响。

有的时候脚掌的化石证据更加间接，比如说通过脚印来判断。

1976年，在坦桑尼亚莱托里发现了一串脚印，这里从前是活火山，火山灰落下来，人一走就会形成一串脚印，考古学家最初以为那些脚印是几千年前的 人类踩出来的，但通过精确的测量发现，这是350万年前的。

![](bbox=[0.12, 0.01, 0.88, 0.01105])

看了上图，结合我刚才说的知识分析一 下，这串脚印能说明什么？

从图中可以看到这串脚印，五个脚趾头都是朝一个方向的，就说明它是直立行走的，而且大脚印旁边还有一串平行的 小脚印，说明当时很可能是一位母亲牵着自己的孩子，孩子紧紧贴着母亲，走在当时还是泥潭一样的火山灰里，也许它们是在找吃 的，也许是在回家的必经之路上。

所有这些结论，都是我们通过间接证据推导出来的，谁也没见过这对母子牵手直立行走的样子。

还有一个可以辨别是人还是猿的证据，就是对比手上的拇指。我们的拇指跟其他四个手指头距离比较近，可以做拇指一算的动作，你可以试试，拇指跟小指、拇指跟无名指是可以轻松地掐在一起的，但是这个动作对黑猩猩来说是完全不能做到的。

![](bbox=[0.15, 0.0136, 0.85, 0.01465])

看了上面这张图，你就知道黑猩猩为什么做不到 了。

![](bbox=[0.18, 0.01515, 0.82, 0.0161])

另外你还可以试试平伸手掌之后，大拇指水平地画圈，这个动作也是只有人类才能做出来的。

我们的手指能完成更精细的操作，比如说从地上捡起一根针，我们是可以攥用食指+拇指的指尖把它从地上提起来的，但是黑猩猩做不到这一点，它们虽然也可以用手指在地上捡东西，但是必须用两根手指的指肚捏起来，这个动作有点像我们平时捏一张银行卡那样，必须用指肚才可以。

我们可以做到这一点，就是因为手指上每平方厘米有1400多个触觉小体，它们都紧贴在皮肤下面，每一个里面都有许多神经。哪怕是在指尖密度也很高，就是这些变化，才让我们能使用骨针缝衣服，使用画笔画出蒙娜丽莎。
