# —— ◆ 谎言粉碎 ◆ ——

其实，尼斯湖到底有没有水怪，从科学原理上也可以解释清楚。

尼斯湖在苏格兰的北部，它是不列颠群岛的最北边。说是湖，其实更像是条大河，平均宽度1.6公里，然后它分出的一些支流流入到北大西洋。下面的地图中，标红的地方就是尼斯湖，你也可以把它理解成尼斯河。所以，尼斯湖不但小，而且非常冷。

![](bbox=[0.28, 0.52, 0.85, 0.71])

这个地方的水温，水下5米的时候就只有5摄氏度了，几乎所有的鱼都生活在5米以上的�层里，而且即使这样，也因为温度太低，鱼都很少。

假如真的有蛇颈龙一样的水怪，这里的食物总量顶多只能满足几只水怪的食物需求。但是，一个物种要延续，物种的数量是有硬性指标的。

比如，大型的动物至少需要几百只的规模才不会因为近亲结婚，最终导致了基因恶化，种族灭绝。

尼斯湖里，如果80多年来一直有水怪存在，那就能说明它的种族还在延续，所以这个湖里应该至少有几百只水怪。可是几十年来，翻天覆地地找也没有发现哪怕是一只存在的证据，所以从理论上说，这里头不可能有大型的食肉动物。

到此为止，尼斯湖水怪的谎言就算被系统地粉碎了。

# —— 今日内容小结 ——

这节课我们能得到什么科学思考习惯呢？

就是对什么东西好奇，这个事有点像口味，比如一个穷苦的朝鲜人，30岁之前都没有吃过饱饭，那当他来到中国，就算是给他最廉价的散装方便面，他不用就水，直接干嚼，吃完了还会感觉是终身难忘的味道。

但是，他在中国生活的时间久了，像兰州拉面、武汉的热干面、北京的炸酱面等等，已经吃遍了中国各地的小吃之后，再让他吃散装方便面的话，他起码是不会对这种油炸食品评价非常非常高了，因为他知道好味道是什么样的，健康食品都是什么样的。

那这个道理，一样可以用在判断一个人的科学素养上。

像那些《世界未解之谜》的书里，都夹杂着半真半假的科学术语，确实常常被不明白真相的图书商人当作科普类的图书归类。但如果一个人认真读过《十万个为什么》，一个人习惯看《环球科学》杂志的话，这些内容质量极差的书是没法满足他们对信息量跟信息刺激强度的心理需求的，他们的大脑已经习惯于分析更有逻辑性，更有思维深度的内容了。

比如像咱們《科学思维课》专栏的订阅用户，很多 人都是有这样的特质的。在你们眼中，那些一聊起 UFO 就兴致大增，把《法老的诅咒》当作科普书看的人，那些本该在小学高年级就因为知识水平进展，就应该渐渐失去兴趣的内容，竟然对一些人依然能产生较强的刺激，依然能够愉悦他们的大脑，那 就只剩一种可能了，就是这些人还没有迈过阅读的最低门槛。

中国近20年，随着科技跟教育的提升，这类内容虽然已经不是科普书的主流了，但还没有完全退出科普的领域。
