# 138 | 问答：献血对身体有害处吗？

138 | 问答：献血对身体有...

有同学问献血方面的知识，他自己在网上查了很久，有说好的，也有说坏的，但他觉得说的都太片面了。这次答疑，我就来仔细说说。

我先给出答案：

献血对个人的身体健康来说，按照规范，健康成年人士一次献200毫升到400毫升的量，两次献血的间隔在6个月以上，只要满足这些条件，既没有找到对身体有害的足够的证据，也没有找到对身体有益的足够的证据。
