# —— ◄概念12：旁证► ——

对历史事件的研究很难有直接证据，所以旁证和考据就是重要依据。基因技术的出现，让历史研究中的旁证更加坚实，很多从前打嘴仗的内容，现在变得无可争议。这一系列我们介绍衣服、猫、狗、人的起源，就是利用了旁证。

日本人是中国人的后代吗？

这个问题想要回答正确，可不是简单的一句是或者不是，因为什么算中国人，什么又算日本人，这就已经很难清楚了，这两个问题没有标准答案。

比如说，人类祖先6万年前走出非洲，那次算是真走遍了世界，其中走向亚洲的一支是从南亚进入到了中国大陆的，但是他们并不是像现在一样，80%的人口分布在中国东部，而是往东北方向走到了蒙古、俄罗斯，甚至更北。

这些经过了东亚大陆的人算中国人吗？

历史上我们曾经只管在中原腹地居住的人才叫中国人，这批祖先后来又南下再进入了中原腹地，但他们后来又南下到很南方的地区，可中国有了文字之后，管这些地方叫做蛮夷，那么他们算中国人吗？

每个历史变点上都存在这样的疑问，所以什么人属于中国人，这要说起来估计能写一本书了。同样，什么算是日本人，也存在这样难以一句话说清的问题。

所以今天这一节课，我们借这样一个标题来提醒大家：

要回答一个问题之前，想清楚问题里每一个元素都是什么意思，然后再考虑要不要回答。看急回答是或不是，那都是 一种不健康的思考习惯。

# —— ◄日本人的祖先构成► ——

实际上是这样的呢？

实际上第一批进入日本的人类大约是在35000年前，这批人在之前几万年里一直生活在东南亚大陆上，当时没有海水，但海平面开始上升之后，这批皮肤棕黑色的东南亚人开始北上，有的就定居在中国大陆南方了，有的直接走到了琉球，他们于是成为了第一批日本人。

![](bbox=[0.12, 0.005900000000000001, 0.88, 0.0067])

现在日本把那一股祖先叫做绳文人，他们世世代代生活在日本的南方，创造了绳文文化。这里出现了日本最早的居民很好理解，因为至少这块还是温暧潮湿，气候还不错，大陆也还连着。现在你也可以看到日本人里确实有一些皮肤颜色非常深的人，他们就是绳文人的后代，以这些人的来源看，日本人、菲律宾人、马来西亚人他们拥有共同的祖先。

但是日本人不止这一个来源，因为在这期间，从日本北方也不断地进人，他们是从西伯利亚南下的，叫做阿伊努人，他们到了日本定居在北海道跟本州岛的北部，从北方进入的阿伊努人在1.5万年前就终止了，因为在那之后大陆桥消失了，中间就是一片海洋。

![](bbox=[0.12, 0.0077800000000000005, 0.88, 0.0085])

阿伊努人长的跟亚洲人差异非常大，他们眼窝深、鼻腔宽大，毛发非常浓密，皮肤非常白，跟欧洲人的特征有点像。

![](bbox=[0.22, 0.00884, 0.78, 0.00958])

上面这张是阿伊努人皮肤的样子，这体毛浓密到有一点像猿人了。以这些人的来源来看，日本人、东西伯利亚人拥有共同的祖先。

可是日本人还不止这两个来源。

因为九州岛跟朝鲜半岛中间虽然有海，但是很长一段 时间里它只有几十公里宽。如果 你还记得复活节岛的故事，你就能理解，这个距离对于生活在海边的人来说，跨越它的宽度简直易如反掌。

所以日本人还有一个来源，就是从朝鲜半岛迁徙过来的 人，这些朝鲜人从前也都是从中国来的，可以算是中朝人。但中朝人来得比较晚，大约是从15000年前到2500年前陆续到达的日本。他们形成了后来大和民族的主力。以他们的来源来看，日本人、朝鲜人、中国北方人拥有共同的祖先，他们的样子跟中国人差不多。

所以到了这里，日本人的三大来源就清楚了，他们的差异比较大。所有这些清晰的差异都是通过分析父系遗传的 Y 染色体 DNA 跟母系遗传的线粒体 DNA 分析出来的。
