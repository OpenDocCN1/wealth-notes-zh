只发生了两代的变化。就这么一套语言分析下来就发现，还说得通。所以当时的研究结果，就是水稻是4000年前从古印度起源的。

这个观点其实到了1950年还是国际的主流观点，哪怕是你现在在百度上搜，还有大量的文章说水稻是起源于古印度的，其实这种观点已经过时了。

这个就是第一个版本研究水稻起源的方式，你看这种方式为什么值得介绍呢？因为它已经用了它所处的那个时代所能用到的最好的工具了。

# ——◆ 水稻起源于长江流域 ◆——

第二个版本就是咱俩国家自己做的，大约是1915年开始，咱俩中国科学家就发现，我们中国的野生水稻的种类一点儿都不比印度的少，从界、门、纲、目、科、属、种上看，咱俩22个，印度24个，它本身没什么明显的差距，你再仔细一找，说准能找出26个来呢。

而当初说起源于印度，很大的一个理由就是说印度的野生种的数量多，现在一样多的情况下，你这个结论的可靠就 Nike不那么强了。而且，凭借野生种的数量多就说这是发源地，这个逻辑也是有漏洞的。
