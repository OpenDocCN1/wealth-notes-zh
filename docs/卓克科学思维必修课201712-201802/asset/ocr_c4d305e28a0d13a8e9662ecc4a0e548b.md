# 115 | 发展：已经灭绝的天花，卷土重来

# ——概念11：发展——

科学是从古代哲学、宗教和艺术中发展出来的，了解科学演化的历程，才更能体会科学的本質。用发展的眼光观察曾经困扰人类的那些疾病，你会发现，现代医学的出现，实际上拓展了生命的范畴，缩小了死亡的边界。

# ——上节思考题解答——

上节课最后的问题，天花为什么不分高低贵贱，不分时间跟空间，分布得比其他传染病更平均呢？

我看到很多人都答对了：

因为它是凭借空气传播的，所以流动性比通过接触、水源这些介质更加宽泛。

这个判断依据也能用在其他的传染病上，比如说每次 H1N1 的流感病毒一流传，各国的疾控中心就开始严密监控，就是看这个病毒会不会变异出空气传播的特性来。

# ——接种人痘——

今天我们从医学史中挖出天花是怎么被消灭的，和之后是怎么卷土重来的。

人们一直想方设法治疗天花，其中的一个谬误就是基于我们讲过的，天花是一种太广泛的疾病了，所以16世纪以后的欧洲人，把它当作人生必须迈过的一道坎儿。既然早晚都躲不过去，那如果我先浅尝辄止地让自己的身体跟天花来一次小接触，那命中注定一定会染一次的天花的劫数是不是就算修满了呢？

所以那个时候真有人开始从病人身上提取脓疱里的液体，然后把一团棉线泡在挤出的脓液里，之后再割开手臂上的皮肤，把这棉线塞进去，然后再绑紧伤口，过24小时之后再取出这团棉线，这次密切接触就算完成了。

当然，他们那会儿肯定找的是患病程度最轻的那些病人，但是这样做完之后，这些人等上12天，自己仍会发起天花来，虽然他们大都是很轻微的，但病程是一点没有缩减，仍然是要聚上1个月左右，只不过起的疹子没有那么猛，死掉的概率也没有那么高。后来的统计是，通过这种方式感染的死亡率大约是2%，这比普通的天花35%要低太多了。

那你说，大家都这么搞，不就可以了吗？为什么几百年来天花仍然肆虐呢？

这就说到医疗手段跟公共预防政策了，只有国家背书，安排相关的部门执行、宣传、接种，甚至给补贴才有可能成为一种全民的行为，否则就算是有效的疗法出现了，也依然是个人的行为。

# ——牛痘实验——

但是这么做还是有问题，因为被种痘的人从潜伏期到痊愈这1个月的时间里，他仍然是有传染性的，他自己染病是通过皮肤上的伤口，可是他传染别人还是通过传统的空气传播，所以会导致更广泛的病毒传播。为此，英国还专门设立了一个天花专用的接种医院，带隔离措施，防止那些接种的人传染其他健康人。

# ——消灭天花——

现在的解释是，天花病毒属于正痘病毒，牛痘病毒也同属于这个科，所以它们表面带的蛋白质特征非常像，牛痘病毒感染人之后的症状很轻微，只是局部的红肿，但只需要一次的感染，就能让免疫系统记住这些蛋白质外壳的形状了，于是下次即使遇到天花病毒也会在短时间制造出足够多的抗体消灭病毒，于是就保护住了身体。

而用牛痘去感染人，两个大问题都解决了：

+   首先，牛痘不会造成2%的死亡率；
另外，牛痘在接种期没有空气传染的问题。
