# 147 | 边界：恐怖记忆也能遗传吗？

# ——►概念13：边界◄——

人类观察世界的边界，是由所能使用到的最好的工具决定的，面对任何问题，只有尽可能多找一些可验征的细节，不过度地理解，不过度地解读，才可能了解真相。

2013年，《自然·神经科学》上登了一篇文章，题目还挺有文采，叫：来自父亲的原罪。

这篇文章一登出，马上就被各大媒体给转载了。其实文章里说的是小老鼠父亲的原罪，这个原罪指的就是对苯乙酮的恐惧，这种恐惧居然还传给了自己的儿子、孙子们。

# ——►基因序列异常◄——

事情是这样的，科学家们想弄清楚到底哪些东西能遗传，像我们听说过的遗传病就可以遗传，地中海贫血、色盲等等，那就是上一代的 DNA 上某个基因序列异常导致 的。

具体什么意思呢？

就拿地中海贫血来举例：

指导如何生产血红蛋白的这个基因，它就有一个氨基酸，按3个碱基排1个氨基酸这个规律来说，这里本该是CTT，对应的是缬（xié）氨基酸。但是不幸，这些地中海贫血的患者在这个位置上，这3个碱基从CTT 变成了CAT，于是最后表达的就不是缬氨基酸，而是谷氨酸，这就是序列不同。

# ——►表现遗传◄——

但是在上世纪90年代之后发现了越来越多的反例，就是像 ATCG 这些序列没有变，但是表现出来的特征截然不同，而且这种特征还能够遗传给下一代，所以这一下就让科学家们意识到，基因并不是把上一代的特征传递给下一代的唯一途径，还有其他的途径。

于是，专门研究这些途径的学科就诞生了，这个现在叫做表现遗传。

我们回到《自然》上那篇<|start|>文章“父亲的原罪”。

具体电击是这样的：

+   就是3天的时间里，每天电5次，先释放香味儿，然后就电击小老鼠的脚丫，电击比较轻微，就是会疼一下。3天过后，这批小老鼠只要再闻到苯乙酮，那就是一副担心受怕的样子。看来这种恐惧已经烙印在它的脑子里面。

结果等第二代小老鼠长大了之后，各方面都发育完全之后，第一次实验让它们闻了一下苯乙酮，这个味道刚一出现，它们就高度紧张。如果在释放香味的同时，周围还很嘈杂的话，那它们就已经叫得不行了。
