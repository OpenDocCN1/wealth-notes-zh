# —— 概念13：边界 ——

人类观察世界的边界，是由所能使用到的最好的工具决定的，面对任何问题，只有尽可能多找一些可验证的细节，不过地理解，不过度地解读，才可能了解真相。

为什么镜子里的东西都是左右颠倒的？

这个问题可能很小的时候大家都遇到过，你举起右手，镜子里的人举起的是左手，你衣服胸前如果印着一段字，那从镜子里看每个字都是反着的，都很难认出来。

但是你想过这个问题没有？为什么镜子没把我们上下颠倒一下呢？
