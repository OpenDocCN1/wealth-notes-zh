# **應收帳款收現天數：跟前面相同，這也是需要檢驗的數據。萬一哪天債權人不願意借錢給公司，突然要求公司速速償還之前的短期債務，此時公司如果屬於「天天收現金」的生意模式，比較有能力馬上變成現金，償還給該債權人。即使速動比率＜150%，如果應收帳款收現天數能夠小於15天，筆者會認定該公司仍具有速速還款的能力。

# **總資產週轉率：還記得「覆巢率」，越高越好！這句話嗎？假設這家公司前面幾個指標全部不符合，那它的總資產週轉率絕對不能小於1。因為小於1，代表這家公司是資產密集（很燒錢）的行業，結果它手上的現金低於10%，又不是收現金的行業，此時速速還債能力「速動比率」又偏低，一旦市場有風吹草動或突然出現非預期的黑天鵝事件，該公司可能會立刻陷入危機。台股上市櫃公司約有2000家，投資理財千萬不要將自己的資金，放在遇上景氣波動就會陷入危機的公司，大家別與自己存的辛苦錢過不去！
