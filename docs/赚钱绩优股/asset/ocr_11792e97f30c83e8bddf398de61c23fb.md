# 4. 投資的錢絕對不能與生活所需的基本開銷混在一起。

全世界最聰明的人之一，前美國聯準會主席格林斯柏非常清楚這一點。他曾說過：「最好是您未來三到五年不會用到的錢，才投資到股市。」

因為景氣有波動，股價有高估，如果您將生活費也投入股市，一旦面臨股價波動，常常會陷入追高殺低的失誤循環。

# 5. 配合您的人生階段，隨著年紀增長，您所能承受的风险應該越來越低。

换句话说，年纪越大，您應該減少賭博性質高的理財產品，例如原物料、外匯、黃金、白銀、期貨、選擇權……。
