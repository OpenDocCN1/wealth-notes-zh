# 4. 從獲利能力破解
這是不是一門好生意？越好越好。
獲利能力＝這是不是一門好生意？越好越好。

投資不只是看毛利率，更是瞭解行業經營的態度、公司是否節省精神。獲利能力最重要的概念，就是如何找到一個兼顧效率與穩定的生意。

# 5. 從財務結構破解
公司的破產危機
財務結構＝那根棒子，位置越高越好。

公司的財務槓桿好不好？對外的負債會不會太多？有沒有殺死生命的「以短支長」情事？如何提前買出公司的破產危機，趨吉避凶。

# 6. 從債務能力破解
公司的還錢本事
債務能力＝你欠我的，能還嗎？還越多越好。

風險當多，債務能力欠佳容易引發債權人到該公司的信任損失，同樣會死公司。為了避免公司破產危機，必須瞭解公司是否具有償還能力的邏輯能力。

公司。找出關鍵股，將你的投資組合升級成：「買企業，而不是買股票」。

股神巴菲特所提過的技術，正是融合五大數字：找出能夠持續安定獲利的優質公司。
