# #### 大立光時存貨管理優異

由圖表3-10看出，大立光的存貨週轉率，在2013年只有5.46趟／年，逐步提升至2015年全年存貨做了6.55趟，三年之間存貨的經營能力提升了18%。這個優異的表現，也可以從大立光的平均銷貨日數（在庫天數）由2013年的65.88天，縮短到2015年的55.72天，此數據表現也與報章雜誌刊载的新聞相符：大立光的光學鏡頭更热销，營收逐步攀新高。
