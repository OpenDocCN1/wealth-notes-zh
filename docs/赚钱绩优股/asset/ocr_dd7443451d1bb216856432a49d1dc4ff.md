債款能力在五大財務比率分析的位置

+   1. 資產負債比 = 總負債 / 總資產
2. 速動比率 = (總資產 - 存貨) / 總負債
3. 現金流量比率 = 現金流量 / 總負債
4. 應收帳款回轉率 = 純銷貨額 / 應收帳款淨額
5. 存貨回轉率 = 銷貨成本 / 存貨淨額
6. 股本回轉率 = 純銷貨額 / 股本
7. 固定資產回轉率 = 純銷貨額 / 固定資產淨額
8. 所有資產回轉率 = 純銷貨額 / 總資產
9. 純利率 = 淨利 / 純銷貨額
10. 淨資產報酬率 = 淨利 / 平均所有權益
11. 總資產報酬率 = 淨利 + 利息費用 / 平均總資產
