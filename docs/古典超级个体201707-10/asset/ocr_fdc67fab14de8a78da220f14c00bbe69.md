# 快问14

long：想做的、需要做的事情很多，但时间、精力有限，我该如何权衡取舍？

古典

先做好需要做的一一然后做最想做的，不做会后悔的一一最后做那些投入产比高的。
其实你坚持这样做一两年后，就会发现，三种事情逐渐聚合成为一种事情。
如果在单项里依然冲突，那就按照重要性排序。
如果排不出来，证明其实差别不大，抛个硬币吧。
