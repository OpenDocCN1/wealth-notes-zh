# 如何选择生还是不生

|  | 生 | 不生 |
|---|---|---|
| 消费品 or 生产品 |  |  |
| 益 | • 亲子共同成长的快乐
• 中国传统价值观的贯彻 尊重与传承
• 年老后的依靠（情感 精神 抚外） | • 经济压力小
• 花更多时间投入自我实现
• 保持二人世界和谐稳定 |
| 弊 | • 巨大的时间 经济与精力投入
• 必须得牺牲的稻荷 | • 家庭和谐压力
• 年迈后孤独 情感缺失伴随 |

生不生娃不是一道辩论题，也不是一道是非题，而是一道选择题。生娃有优势也有风险，每个人都应该有自己喜欢的选择，这是一个自由人很重要的权利。
