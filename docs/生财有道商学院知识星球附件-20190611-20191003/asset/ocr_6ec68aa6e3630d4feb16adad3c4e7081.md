所发布的视频必须要求是原创的，做自媒体最看重的就是原创，而且各大自媒体平台也更青睐原创，原创作品被推荐、推广的几率更大。

若是做搬运，不仅不会增加你的权重，还会影响账号的整体情况，得不偿失。

# **2、垂直度**

垂直度相信关注天朝学子博客的朋友也比较熟悉了，是指一直专注于某个领域。就像天朝学子博客每天更新的文章都是关于互联网行业如何赚钱。

大家也正是因为这样的话题才来关注我们的，如果我明天开始写育儿经验，相信大家也接受不了，这是同样的道理。

所以不管是运营哪个自媒体平台的账号之前，都要想清楚你要专注的领域，这样账号才能有权重。

# **3、健康度**

大家或许并不知道健康度是什么意思，其实这里的健康度并不是我们平时理解的那种意思。

这里的健康度是指文章的排版，比如小标题加粗，是否缩进，是否有分割线之类的，只要合理进行排版，都可以快速提高健康度。

# **4、活跃度、互动度**

我这里把活跃度和互动度放在一起，活跃度跟互动度其实是可以互通的，也很好理解，就是看你在平台的活跃程度以及跟粉丝之间的互动程度。

这方面是比较好把握的，所以此处就不作过多的阐述。当做好以上几点，头条号指数 600，还是非常容易达到的。
