# 1、新手如何操作？

网赚新手对互联网的熟练度也能够碾压很多普通人，玩起来并不难。只不过是塑造形象而已，多做分享视频，适当交流群就行。

不过千万不要去各种论坛，这群人是没有什么价值的，老油条居多。想要做这一行还是从其他平台上考虑吸引新客户，这类客户的申卡率比较高。
