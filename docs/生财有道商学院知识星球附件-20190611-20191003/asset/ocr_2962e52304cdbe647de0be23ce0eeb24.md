# 4、发文频率要适度

每天 4-6 条为宜，包括广告、个人生活、资讯干货等，根据时间段，每次 1-2 条最好；太少容易被人忽略；太多容易刷屏，被人厌恶；精选、错开时间段，会让人觉得很有内容、很自强上进，通过你的微信能够吸收很多东西。
