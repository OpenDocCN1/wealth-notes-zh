# 城通网盘赚钱的模式是怎么样的？

下面为你讲解一下：

如下图这个通过点击新浪博客下载链接之后然后跳转到的一个城通网站下载链接的页面，通过页面我们发现这里有一个大的横幅广告，这一个广告都是广告商花钱来投放的，广告花费低至 6 元起/千次弹出 不弹出不计费，除了这一个广告位置之外。

还有一个文字广告位，在下载说明的右边有一个精彩推荐，在下载有一个广告位，这一个广告位置是按包月来收费的，一个月收费 150 元，可以投放一个月，这个价格相对来说还是比较的便宜的。

![](bbox=[0.15, 0.41, 0.85, 0.68])

城通网盘就是依靠这一种接广告主的广告，然后收广告来赚取收入，我们用户也可以通过上传一些电子书、教程、资料等这一些数字资源进行变现，只要别人点击你的下载链接，那么你就有 95%广告分成。

不管别人有没有下载成功它都是有广告分成的，这一点也是吸引无数站长去做这一个城通网盘的原因。
