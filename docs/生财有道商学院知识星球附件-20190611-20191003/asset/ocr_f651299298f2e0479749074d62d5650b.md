# 一、知乎的规则

知乎=头条+公众号

1、说知乎像头条是说知乎的问答像头条，头条是怎么样的？机器推荐算法，根据赞，收藏评论等推荐。

知乎的问答就是这样，你写一个回答之后，知乎会把这个回答先给一部分人看，如果反馈好（赞、评论、感谢多），那就会推荐给更多的人。

主要是通过，通知中心和首页给推荐的。

通过通知中心，是说你只要回答了这个问题，那么知乎会把你的答案推荐给关注了这个问题的一部分人，并不是全部。
