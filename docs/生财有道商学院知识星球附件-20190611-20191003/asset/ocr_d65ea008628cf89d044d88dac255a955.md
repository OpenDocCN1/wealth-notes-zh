# **一、什么是小说分销**

简单来说，就是小说的作者，为了把小说推广出去，产生效益，给予我们小说推广的推广权，由我们把小说推广出去给消费者，消费者在看小说过程中产生的消费由我们和作者分成。（分成比例高达百分之 90）消费者充值 100，我们得 90。

第二种需要注册认证的服务号，直接和小说平台做对接。这适合团队作业。
