# **信用卡填表技巧**

10大注意事项，一张图告诉你

+   1. 年收入

在诚实的基础上当然越多越好，
所以记住一定要填写税前收入。

+   2. 婚姻状态

已婚已育 > 已婚未育 > 未婚

+   3. 学历

学历高是个加分项，一般本科及以上对
下卡有很大帮助

+   4. 住宅状况

有房无贷款 > 有房有贷款 > 租房

+   5. 联系方式

填写常用手机号，确保银行能联系到你

+   6. 工作状况

根据单位性质：一般公务员、事业单位、
国企、世界500强等知名企业申请额度较高

+   7. 邮寄地址

建议选择单位地址侧面说明你在这上班

+   8. 身份证有效期

如果身份证有效期快到了， 核减过
率不大，建议换好身份证再申请

+   9. 银行开立账户

可以在申卡前，在该银行存一笔定期，
一般1~3万存3个月

+   10. 如实填写

银行有很强大的背景调查体系。虚假
填写，不仅申卡被拒，还可能被银行
列入黑名单

现在整个信用卡体系构建也非常复杂，这里不细说了，单纯想要赚点开卡佣金，
用这个办法最合适。像这样专业细节化的知识，通俗易懂，能让更多人理解，所
以更容易产生信赖。

# 新手可以从哪些渠道找到这些信用卡开卡渠道呢？

有的公司，能够把大部分银行的渠道都搜集到，想要拿高佣金，必须开卡量上去。
所以找到这些公司才是最重要的。很多银行的开卡渠道，都是外包的，并不是直
接找银行，而是找到这些外包公司，就能够获得这个资格。而这些公司经常活跃
的地方无非是各大 CPA 推广平台。
