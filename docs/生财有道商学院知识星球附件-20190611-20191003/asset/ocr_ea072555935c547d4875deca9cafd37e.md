电商变现这块我将它分为淘宝电商和直播电商两块，下面分开描述：

# （1）淘宝电商

在抖音的电商变现方式尚未明确之前，很多创作者的第一动作是把购物车里的商品直接链接到淘宝，创作者在发布视频时添加商品直接引导用户到淘宝购买。

用户在抖音平台触达商品，最终在淘宝完成购买行为。对于有自己的淘宝店的创作者而言，把抖音当作渠道的变现方式简直 so easy！
