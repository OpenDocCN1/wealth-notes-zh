# 10、社交立减金推广，实现快速转化(免费)

用户在小程序内购物后，会获得“微信立减金”，用户将“立减金”分享给好友/微信群的同时，自己也完成了领取。好友在领取“立减金”后，也可通过快速入口完成新的交易。通过社交裂变，带来新的流量。
