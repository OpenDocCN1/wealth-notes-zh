# 3、如何提高直播间的人气？

直播间的人气与直播点赞是有关系的，也与你的电视剧或者电影的选材有关，如果选的好，顿时会涌入一大堆人观看。慢慢的直播间的权重就会上去。

当然，你也可以通过给自己细分定位来提高人气，比如电影可以分为恐怖电影、搞笑电影、功夫电影、等等，都可以。目前来看，恐怖电影里面，以林正英的电影人气最高。
