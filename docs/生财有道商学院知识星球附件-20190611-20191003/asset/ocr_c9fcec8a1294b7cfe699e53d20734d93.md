# 3、 账号资料

# （1）头像设置

头像是你像陌生人展示的主图，别人会不会主动和你打招呼，会不会主动搭讪你，90%以上都是看你的头像。

我相信大多数人在刚开始的时候和陌生人勾搭，都是去看一个人的外在，在网上也是一样，别人在刚认识的时候，都回去通过你的资料和照片去了解。

首先看的就是这个人的头像。如果这个人的头像看起来既漂亮又真实，那么几个本就有了很强的加为好友的冲动。

背景墙可以放一些自拍照，或者风景照，千万别放广告，头像也是，真实化的生活照。

# （2）资料设置

资料尽量设置完整一些，性别一般设置为女性，情感状态设置为单身，完善度不低于 80%，增强真实性。

个人资料最好与你的头像类型相匹配，会让人觉得你是一个真实存在的人，这样会让那些勾搭你的人增加信任感。
