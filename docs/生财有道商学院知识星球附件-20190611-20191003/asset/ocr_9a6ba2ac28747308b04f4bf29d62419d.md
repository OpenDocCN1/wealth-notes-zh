# ### 四、如何规避风险

+   1、不要发电影、电视剧题材的。现在版权管理严格，国内的影视剧现在都是独播后再卖版权，一旦产生纠纷，封号是必须的。

所以推荐国外的素材，能够很好的降低风险。
