# ## 四、收购小组。

豆瓣有很多有价值的小组，但组长变现能力却很垃圾，运营也不怎么样，大家 都是随意注册，因为标题带有关键词，莫名其妙就火了。

所以可以投资收购，这样是最快的。

这个和收购域名、网站、公众号一样，是一种投资，既然是投资就有赔的风险。
