# 闲鱼快速出单小技巧

账号：

支付宝账号芝麻分越高越好，账号的权重就会越高。

产品：

选品是很重要的，选择爆款，蓝海产品，确定好自己店铺的类目，就不要再更更
改了。

多花费时间去选品。可以卖闲鱼首页的那几个类目的爆款产品。

货源：

上面也说到我自己的货源，如果自己有货源就更好了，没有货源就是自己制造货
源，我做的也是无货源。

定价：

闲鱼上的用户本来就是看着商品的价格便宜来的 ，所以很多的商家就是把商品
的几个定的很低，一位这样就能很快的出单，但是这样做是很危险的，不要认为
自己很聪明，这样做平台是不允许的，你有可能会受到惩罚的。参考同行，可以
稍微不同行的便宜点，只要不是太过分就可以。
