每个人都或多或少地接触过直播。

太多的女主播通过直播实现了人生逆转，这些主播主要分 3 种。

1.个人播着玩；

2.公会签约主播（就是传媒公司通过各种渠道招来的主播）；

3.官方签约主播（个人播的好的官方会找你签约）。

公会主播和官方签约的主播会有更多的平台资源，像各个推荐位，活动奖励等，大家要知道，做直播也是要天时地利人和的，并不一定是长大好看，才艺好就能火的起来。

一个新主播能火起来差不多就以下这些方式：

1.公会提供推荐位强推，就是将你的直播间再某一时间推广到平台的主页，每个公会都是几千上万的线上主播，全靠经纪人再其中协调。

2.主播之间相互连麦。

3.经纪人帮你刷礼物吸引人气，一般公会都有专用的账号，以超低的价格从平台充值然后刷给自己公会的主播，当然这部分礼物肯定是无法提现的。

4.自身自带粉丝或者是网红。
