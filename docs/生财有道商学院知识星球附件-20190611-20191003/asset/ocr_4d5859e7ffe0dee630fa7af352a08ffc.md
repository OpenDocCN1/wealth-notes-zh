# 倒卖二手车差价赚钱，一年轻松赚 10 万

今天我给大家分享一个赚快钱的方法，方法是我花四千请人吃饭偷师来的。但是 这是要投资的，也有门槛，本金十万赚十万的。

二手车非传统卖法。人生钱很难，钱生钱也就是眨眼间。

其实很简单卖二手车，但是是卖二手小货车，注意是小型拉货车。买主买来都是 做生意用的，十万本金是用来收车的。但不一定要一次给。

# 1
找车源

首先你要找车源，网络上，别人的车源，同行朋友圈里的消息，法院拍卖的，典 当的。都要有消息网，不是一蹴而就的生意。

我就讲其中一条网上收车。到各个软件，网站去找，最好找个人车主。

你看准了哪个车看的人最多，要买的人最多。约好看货车，第一次你别去，叫朋 友去，去是砍价揽合的，能砍多少砍多少。你再去加一点，价格合适就买下。

还是吃不准，就交一个定金，告诉车老板车我要了，两天内带朋友来成交，不来 定金不要了。这就等于你用很少的钱定了这台车两天。

# 2
找买家

在买车之前你换个网站发相同的贴，车资料是别人的。电话换成是你。

别人发很多人看，你发也会有人要。
