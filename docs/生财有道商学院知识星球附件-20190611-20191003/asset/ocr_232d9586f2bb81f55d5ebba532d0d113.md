# 第五、职业免费送玩家。

对的，就是免费送，包邮赚邮费，不包邮赚商家推广费。

比如同城送水果体验装，邮费就赚 3 元左右，然后引导拉群，首次买一件送一件，拉的朋友享受同样福利。

但其实闲鱼店主并不是卖水果的，实际是做成城社群拼团的，导入这样一个精准客户入群并购买提成 10-50 元。

优化好免费送的宝贝，自己的号吸粉的同时，可以无限为各种商家拉精准小群。

每个客户拉 5 个不同的群，就是净利润 50-250 元。
