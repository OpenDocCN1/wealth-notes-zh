# 地图标注有哪些好处？

地图标注是将企业和商户标注在地图上，通常标注的信息包含商户名称、商户地址、商户相册、有时也能展示商户电话。

标注之后，在手机端和电脑端都能搜索到，当用户搜索时地图上就会凸显出一个标注红点，为商户引流、做品牌。

目前能进行地图标注的平台，几乎涵盖了国内全部的地图系统。
