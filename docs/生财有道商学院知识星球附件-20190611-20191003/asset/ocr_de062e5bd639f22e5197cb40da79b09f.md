# 源码是啥？

源码是指编写的原始程序代码。我们平时使用的各种软件或登录的网站，都是需要经过程序员最初的源码编写，使用软件时，程序就会把源码翻译成我们能看得懂的形式。

也就是说，开发一款软件或网页时，必须要有源码的支持。

但是开发一套源码可不是谁都能做的，还是需要比较专业的人士。既然知道了源码是啥，我们就来说说如何利用源码进行赚钱。
