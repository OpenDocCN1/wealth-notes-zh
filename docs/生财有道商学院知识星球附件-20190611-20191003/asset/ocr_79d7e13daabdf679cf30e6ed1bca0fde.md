# 美图秀秀社群精准引流

一

众所周知，美图秀秀是靠拍照美颜和图片处理起价的，在这一方面也是佼佼者，知名度很高。

但是，随着市场的需求量不断扩大，这两年越来越多的美颜拍照软件和图片处理软件上线，导致行业竞争越来越激烈，对美图秀秀冲击很大，所以美图秀秀另辟捷径，推出了美图秀秀社区。

应该说瘦死的骆驼比马大，虽然美图秀秀现在的同行很多，但是作为开山鼻祖，用户量依然数以亿计，对于我们来讲可说是个超级大的流量池。
