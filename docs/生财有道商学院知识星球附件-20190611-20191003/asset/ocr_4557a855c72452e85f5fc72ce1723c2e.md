# 四、天猫供销货源

天猫的货源比较真实可靠，但相对的价格可能会笔者其他的平台稍高些。

该平台货源的质量售后都特别过硬，关键是你代销的商家可以有很大几率允许你代销分账，这样的话就不用去垫付资金，直接买家确认收货后你与上家各得各的钱。

而且，你看好了他的供销要求，那他们开车用的主图，你也是可以直接用的。关键是这个上家链接就算是链接到你家，一不会影响你家权重，二则你照样可以报很多的促销活动。
