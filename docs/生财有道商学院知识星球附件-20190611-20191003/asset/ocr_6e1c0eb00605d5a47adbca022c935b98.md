# 7.小红书引流方法：

其实关于小红书引流方法我之前分享过很多了，今天再分享一下，无非就是两个渠道，第一个是坚持写笔记，有能力就原创，没能力就搬运。用心做好内容，坚持 0 广告纯分享，当你坚持操作一段时间，你会发现你的播放量慢慢上去了，然后点赞+收藏+评论也会越来越多。

当你分享的笔记有人在下面评论的时候，比如问你怎么买，什么产品之类的，你就可以通过发私信的方式回复她。

这里要注意：

（1）微信这两个字绝对不能出现，否则你发出去的内容别人是收不到的。

（2）不要一直发同一句话，即使内容无推广信息，系统也会默认你在发垃圾广告。

（3）微信号提前做好模板，如果有人私信，直接复制粘贴，用几种话术交替去发，避免被系统检测到。
