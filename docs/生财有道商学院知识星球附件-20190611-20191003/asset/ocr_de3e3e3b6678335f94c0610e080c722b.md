# ## 3、新手可以通过哪些渠道找到这些信用卡开卡渠道？

其实，很多银行的开卡渠道，都是外包的，并不是直接找银行，而是找到这些外包公司，就能够获得这个资格。

而有的公司，能够把大部分银行的渠道都搜集到，想要拿高佣金，必须开卡量上去。所以找到这些公司才是最重要的。

而这些公司经常活跃的地方无非是各大 CPA 推广平台。
