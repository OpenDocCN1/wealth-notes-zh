# 2.电视红包

电视台现在为了收视率，都会发小红包，如果你看到了电视右下角红包图标，这时候你只要：掏出手机-支付宝-搜索电视红包-打开，通过声音鉴别电视台，然后红包就跳出来了。这一招，在元旦、春节、各晚会时候特别好使。

# 3.推荐有赏金

邀请朋友开通支付宝，可以获10元佣金；

邀请没有线下支付过的朋友，可获得5元佣金；

邀请已经用过的朋友，可以获得0.1元的佣金；

被邀请的人，也会获得红包，最高99元。身处农村、四线乡镇，或者自己有店面的朋友，可以操作起来了。
