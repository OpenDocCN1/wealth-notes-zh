# 谈谈项目

所谓“月饼项目”各个韭菜机构的大致玩法都是。

第一，上 X 宝上搜索今年最新的爆款月饼，然后下载图片素材和文字描述等信息，然后上 1688 找到此款的月饼货源，然后经过精准的计算得出一次买多少价格会低于 X 宝的价格。

然后再给你一个非常老套的营销策略，教你把这些月饼卖出去。
