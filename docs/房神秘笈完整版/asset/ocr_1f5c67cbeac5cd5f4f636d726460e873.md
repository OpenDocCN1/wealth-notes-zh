# 第十一课 以租代收——百万富翁的印钞机

以本课前面的案例来看，首付款为5%，即11,500元。每月租金为1500元，一般租金开支不能超过正常收入的30%，才能保证收支平衡。即该买家月收入应该至少5000元。即首款应该为月收入的2倍左右。

如果买家掏不出11,500元，说明他很可能没有5000元的稳定月收入，或者说其收支失衡。那也就意味着他很可能无法保证未来每个月1,500元的租金支付。

你愿意把房产租给一个租金很可能超越其收入水平的买家吗？明知他可能会“断租”，你还会坚持跟他签“以租代收”协议吗？

所以，5%的首付可以有效地过滤一些不合格的买家，可以阻止投资者犯可能的错误。

5%的首付不是绝对的数额，你也可以选择3%，一般不会高过10%，否则会极大影响买家的接受程度。比如，房价为40万，你就可以只收3%的首付，计1.2万。房价为20万，可以收5%的首付，计1万元。

其额须应“让买家掏得容易，却又费思量”——这是一个很考究细节功夫的经验数值。

当然，5%的首付款也是投资者向买家融资的一种渠道。可以免费占用3~5年，何乐而不为呢？
