# 融资策略

结合这类“信用贷款”特点，我们可以制定如下融资策略：

+   由于无需房产抵押，所以可以在办理银行房贷之后快速申请信用贷款。

+   由于数额偏小，所以只能作为银行房贷的补充，主要用于把买房的首付款再融通出来。

+   由于还款期短、月还款额高，应尽量通过“以租代售”的模式由买家承担还款压力。
