# 第十二课 “归隐术”——反璞归真的投资境界

同时，你拥有的房产越多，你的管理麻烦就会越多；即使“以租代售”也是如此。只要这些房产在你名下，你就不可避免地要“消受”这些麻烦。

更重要的是，这些房产虽然净值较高，但都是“不动产”——流动变现能力很差。无法让你真正尝到“经济自由”的生活享受。

这类投资“招术”有如逆水行舟，不进则退；内外交煎，难以“停车止步”。不提升投资模式，就无法真正的“功成身退”。

那该如何突破“招术”的瓶颈呢？

解决之道，就在于“忘却招术”，把投资之道回归本源——“有房”的本源就是“无房”；即通过各种方式，把房产转让出去，使自己“无房一身轻”、归隐幕后。

无为而治的投资方法，方是大成化境。
