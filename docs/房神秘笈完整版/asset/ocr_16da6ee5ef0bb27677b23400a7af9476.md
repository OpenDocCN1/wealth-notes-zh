# 转租权利

第**条 转租权利
乙方在占有使用权期间有权对房屋出租。对乙方经营房屋利益甲方无权主张。

此外，“转租权利”是一定要求取到的，这一点不容争议。如果房东要求必须经过他同意才能转租，那你就需要使用其他“更好的建议”来解除房东的疑虑。
