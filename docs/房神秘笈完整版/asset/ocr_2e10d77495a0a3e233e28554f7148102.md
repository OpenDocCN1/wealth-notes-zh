# 第四课 以租代买——“借房赚钱”绝技

融合了“出租”与“购买”的特点，成功地将“资本围墙”拆除，使“卖房的人”与“买房的人”都保障了自己的利益——其本质就是一种“资本运作”模式。

我们的口号就是：“向房东借房，向租客借钱”——“以租代买”是“零首付”的经典模式，一个“借”字说要玩得神入化。
