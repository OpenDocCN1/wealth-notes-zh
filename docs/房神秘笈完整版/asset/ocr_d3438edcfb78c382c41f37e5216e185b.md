# 第十三课 大道至简：房地产投资的普遍规律

我们以普通的房产交易为例来理解一下这条定律。买房人 A 首先通过“中介 B”了解到了一处房产（房东为 C）的信息，A 看中了该房产，于是 A 与 C 签订了购房合同；A 没有足够现金，由是向银行 D 申请二手房按揭贷款，D 审批通过。A 于是向 C 支付首期款，银行向 C 支付按揭贷款，B 帮助买卖双方完成过户。过户给 A 后，A 定期向 D 还款。

这三种流程贯穿始终，我们可以简单划分如下：

表 13-1 三种流程示例说明

| 流程分类 | 流向 | 内容 |
| :--- | :--- | :--- |
| 信息流 | ① C→B | 房东 C 向中介 B 发布卖房信息 |
|  | ② B→A | 中介 B 将信息传递给买家 A |
| 产权流 | ③ C→A | 房东 C 将房屋过户给 A |
| 资金流 | ④ A→C | 买家 A 付首期给房东 C |
|  | ⑤ D→C | 银行 D 付按揭贷款给房东 C |
|  | ⑥ A→D | 买家 A 定期付贷款给银行 D |

如果 A 与 C 直接洽购房产交易，那么就可以省略中介 B 的角色，即“信息流”是由买卖双方直接接触完成——

> 为隐藏图形的不规则形。C→A 直接洽购时省略掉 C 或 A 为中间媒介，直接完成房产交易；B→A 省略，该交易由 C 自己完成。只有 A→C 直接洽谈成交。
