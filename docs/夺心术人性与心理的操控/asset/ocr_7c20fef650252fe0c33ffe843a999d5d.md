# 第一印象，第一句話

無論你是老闆或是銷售員，在你們要開發新客戶的時候，第一次會面，第一句話，是不是告訴他：「某某先生你好，我是 ABC 公司的代表，我的姓名是 DEF，我們的產品可以幫助你節省金錢，還可以讓你賺錢……。」接下來，馬上堆砌親切的笑容， $${}$${}$$ 卓躬屈膝，彎腰駝背伸出雙手緊緊握住對方 的手，盡量表現出艷陽般的熱情，博取對方的好感？

這樣做，無非是讓人覺得你是一位好好先生，是一位有禮貌，又熱情豪邁的商人。
