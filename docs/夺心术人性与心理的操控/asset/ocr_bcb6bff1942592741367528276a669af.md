# 瞳孔和赚钱的关系

在古中的中国和印度的珠寶商人是有受過觀察客人瞳孔敢大的訓練。舉例：假如我是一個珠寶商人，你來到我的店鋪時，我先拿出藍寶石介紹給你。介紹過程中我注意你的瞳孔有沒有變化，如果沒有的話，我就拿出鑽石再觀察你的瞳孔。如果還是沒變化，我就拿出紅寶石，假設這次我看到你的瞳孔膨大了，你的身體就已經告訴我你最想要的就是紅寶石了。

你的客戶的權利就是可以騙你，因為我們想減價，就算你是客戶時你也會做同樣的動作，因為你希望這樣說能夠讓對方心虛覺得需要減價給你。你的客戶可能會跟你說：「你這店這麽差，開了多少年？」「你這藍寶石這麽爛，要多少錢？」「嘩！這麽爛還這麽貴。」「那麽這紅寶石呢？品質這麽差，設計得好像鬼一樣，要多少錢？」
