# 不可思議的祖師

NLP 影響學就是運用下意識的溝通技巧，超越對方的理性而直接影響潛意識。NLP 兩位創辦人在七十年代的時候，跟二十世紀最偉大的催眠師 Dr. Milton Erickson 學習催眠技巧。

Dr. Milton Erickson 是一個很傳奇的人物，他是一個心理醫生。在世時曾接下三萬個心理治療和轉導個案，全美國最難治的病人，通常都會被他們的心理醫生轉介紹給 Milton。他的治療成功率高達百分之九十五。這是一個非常驚人的數口。

# 超級催眠之「神」
