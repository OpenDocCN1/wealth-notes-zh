# 權謀法則

不管你的客戶說：是、不是、可能、我不知道或沉默，你都一定要有準備好的答案。

其實不管對方怎樣答，我們都可以賣弄權威。千隆問屈術裡最重要的是時機，你可以透過經驗的累積，領悟什麼時候作千，什麼時候隆，什麼時候問，什麼時候屈。
