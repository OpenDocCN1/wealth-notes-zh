# 老千如何尋找獵物？

老千尋找獵物之時，開口的第一句話，一定先引起對方的情緒反應，接下來，把對方的情緒推上天堂，拉下地獄，讓對方感受到既痛苦又快樂，先是希望，然後就失望，在對方的心情上上下起伏的過程中，對方已經完全受制於老千的魔掌之上。第三步，他們會製造緊急狀況，容不得對方思考，在沒有充足的時間，倉促作出決定。
