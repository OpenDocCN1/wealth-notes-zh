# 来自日课: 武器级的说服力

万老师，这里提到“同步”和沟通中经常说的“共情”是一个意思吗？

# 万维钢

“同步”与“共情”很有关系。 “共情（empathy）”，是说对他人的感受感同身受。比如我们看一个电影，当剧中人悲伤、疼痛或者高兴的时候，我们会自动带入，就好像自己悲伤、疼痛或者高兴一样。共情是人脑中镜像神经元起的作用，把发生在别人身上的事情当做发生在自己身上。共情作用是自发的，是人的本能。
