# ## 五、 生造的idea

这不是一个好的方法论，通过生造idea获得成功的公司，屈指可数。

把它列到这里，是希望跟大家提个醒。

下次，当你脑海里冒出一个天外飞仙的想法"我想到一个绝妙的点子"的时候，多问问自己，用户在哪里？谁愿意付费？

最易骗的人，是你自己。我们很容易被自己的生造idea搞得很嗨。千万别轻易爱上自己的想法。
