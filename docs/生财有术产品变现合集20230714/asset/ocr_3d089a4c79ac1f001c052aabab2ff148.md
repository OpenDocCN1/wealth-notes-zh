# 应对措施

+   1. 多注册几个开发者账号，同一套内容微调后打包成不同的APP，自己和自己竞争。既覆盖了更多的关键词，也营造出竞争已经饱和的氛围。

+   2. 使用calibre工具，对上千个epub文件进行批量二次编辑，一方面打上水印减少被搬运风险，另外也是重新规范epub文件格式，提高用户体验降低崩溃频率（电脑：活久见啊...跑calibre也能连续跑十几个小时）。

+   3. 对恶意抄袭太过分的竞对进行投诉反击，有一些效果但不明显，但埋下了巨大的隐患。
