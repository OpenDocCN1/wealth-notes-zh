# 4.是非之辩

你可以用一个有“是非之辩”的问题，然后提供一些支持以及反对标题中说法证明。比如，“在亚马逊河旅游，你应该携带价格不菲的单反相机吗？”支持者认为，你可以拍摄到最美的照片。反对者认为，小一点，便宜一点的相机也可以拍出不错的照片，而且拍摄起来速度也快，因为体积小的相机更容易携带。
