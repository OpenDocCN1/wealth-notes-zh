# 6、10 个魔法标题公式

你的文案中最重要的部分就是标题。花点时间，把标题写好，接下来就顺理成章了。文案的前几行决定着整个文案的生死。因此，写好这部分非常关键，在这部分打动读者，吸引他们继续阅读下面的内容。

米格尔·阿尔瓦雷斯创作了一套自己的标题撰写公式系统。这些公式可以带你随心所欲撰写出自己想要的标题。他的建议是，下面列举的每种标题，你要至少写5出个。这样，可以激发你的创造力，引导你思考如何用不同的方式展现你的产品或服务。

# 1.直接陈述式标题

a）世界上最奢华的酒店！

b）加入家庭计划，永久免费打电话！

# 2.问题式标题

a）你是不是厌倦了朝九晚五的工作方式？

b）你是不是经常在找钥匙上浪费时间？

# 3.“如何”标题

a）如何以其人之道还治其人之身，对付美国国税局？
