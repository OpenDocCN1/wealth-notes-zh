# ——思考题——

这一讲的思考题是：

我们做决定往往有三种框架，一种是基于自我定位的，就是我是什么人就做什么决定；一种是基于规则的，就是规则怎么定我就怎么做决定，不管决定是什么；一种是基于理性的，就是做预期收益最大的决定。你做决定是基于自我定位呢，基于规则呢，还是基于理性？

欢迎你在留言区写下你的选择。

# 划重点

我们如何做人生选择？ 1.人生选择实际上很多时候就是做概率题，懂概率能帮你作出正确决定； 2.一生一次的选择，对你没有概率可言。你只能做自己，你可以选择忠实于自己。 3.个人一生一次的选择，对于整个社会才有概率可言，作对社会有利的选择，是慈悲的。
