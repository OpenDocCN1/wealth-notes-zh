# 政治无处不在

政治是什么，政治学家有他们的解释，我给一个广义解释：

政治是与法治相对而言的。所谓法治，就是追求一切由规则决定；所谓政治，就是追求一切由力量对比决定。

没有纯粹的政治，因为自从智人从森林里走出来以后，打架就得在自己发明的各种规则之中打；当然也没有纯粹的法治，因为你我都知道，规则之所以存在，就是用来打破的。

在法治的理想里，政治不该有一席之地；政治的世界却是可以部分兼容法治，法治是政治的工具，合适就拿过来用，不合适就放在一边，变成阻碍就打破它。规则只能约束实力，实力却能制造规则。世界就这么现实。
