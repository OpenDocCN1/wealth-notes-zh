# 国家大战略

大战略这个词来源于国际政治学术语，指最高层次的战略。《牛津字典》上说，它是最高层次的治国术，领袖应该如何运用军事、外交、政治、经济和其他力量来确保他所认为的国家利益。

我两年前参加耶鲁“世界学人”项目时，上了教授级学者加迪斯（John Lewis Gaddis）的《大战略》课。加迪斯专治冷战研究，这门课开有几十年，已成为耶鲁名课。

加迪斯领衔，一群顶尖学者和自尼克松、基辛格时代就参与美国对外政策制定的老家伙伙同，面对耶鲁学生，用老家伙点经验年轻人讨论的形式，传授美国过去的大战略，理解现在的大战略，想象未来大战略。

# 人生大战略的九点提示

借用加迪斯的智慧，给你的人生大战略九点提示。

第一，要敢为天下先。

第二，瞒着你自己位置越升越高，掌控越来越大的格局，你越要泰然从事。

第三，在一切必然超出掌握的现实里摸索，你得有个方向，但不要过度准备。

第四，在路上你要带上清单，而不是地图。

第五，同样的道理：理论很有用，但你得知道怎么用好它。

第六，你为未知意外所能做的最好准备，是拥抱自己的前后不一和自相矛盾，把它们变成你的战略优势。

第七，自相矛盾也可以叫权变，时左时右，时进时退，把这事跟随即乱来分开来的是原则。既要有原则就要通权变，这话说来容易做来难。

第八，对我们来说，正是因为每天都要在坚持原则与权变之间做取舍，所以分寸感极为重要。
