# 关键词一【社群】

人是一种社群动物，这一点被许多人所忽视，因为人过于注重自我；思维沉浸在自我里，视野自然短视，要提升认知，首先是跳出自我，在社群中俯瞰自身，鸡国每天出生约5万多人，每年出生约1990万人，你只是其中一个小元素。
