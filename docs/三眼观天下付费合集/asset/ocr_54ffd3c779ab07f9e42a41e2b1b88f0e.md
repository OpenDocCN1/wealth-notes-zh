# 存量与增量

分配是做大蛋糕（增量）然后大家分、分配的结果就是存量，给中产分配到的纸面财富只是顺带的，小便宜而已，小便宜背后有无数大便宜。

分配游戏一旦开始，参与的对没参与的是个猪杀，但是分配里面参与的也会有猪杀。

联系开篇那几个框架，我们都活在分配里，充满世界的东东西有俩：假象与猪杀。一个词概括就是：抢劫。任何社会交互活动，都是抢劫活动。任何没有崩塌的秩序，都有一套分配结构在支撑。你按照我的规则玩，那我就对你好点…
