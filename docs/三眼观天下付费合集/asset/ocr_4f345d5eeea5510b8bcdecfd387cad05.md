# 一、“大神”的产生

比如当股市是大牛市，跳出的“股神”就会多起来，小学没毕业黑西服白衬衫发蜡擦亮脑袋，掏出一套忽悠逻辑，天天亮嗓门，就可以当股神。因为一个交易市场接近 100% 多军形态的时候，瞎买也涨，“股神”就能站稳脚跟。
