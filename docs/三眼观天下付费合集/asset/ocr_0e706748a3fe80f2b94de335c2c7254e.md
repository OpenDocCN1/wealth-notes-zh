# 睜折騰的科學

这是为什么？是这样的：

一群低维生命形态，在一个高维空间里，雕造出一个低维世界，这个世界叫人类社会。

这个低维世界存在的方式，就是通过人的思维定义出来的！

比如在抽象的情感上，定义出是非、好坏、善恶等；

在物质世界里，定义出各种“科学定义”的东西，比如水、火、土、木。

人类特别爱折腾，不断的将定义精密化！

在情感上越来越细化搞出精神分析、心理分析等；在物质上从直观层进入微观层，拆分成越来越多的元素。

当完成一个很复杂的定义之后，就开始装逼：

> “你看，我多牛逼，我对这个世界进一步了解了！比你们都了解的要深哦！”
