# 讲在前面的“二元”思维

问题一：

为什么会有社会？社会为何是在发展的？我们为什么会思考？思想与社会发展有何联系？

三眼答：

在这个层面的所有问题都可以归结到“动与静”的问题上。

为何事物在发展变化，为何人的思想在不停运转，这是因为它们在“运动”；

原本万事万物都是静止状态，直到有一个东西打破了静止；

这个东西在道家看来就是“道”；

在佛家看来源自“起心动念”；

在西方哲学里源自辩证法、矛盾对立与统一。
