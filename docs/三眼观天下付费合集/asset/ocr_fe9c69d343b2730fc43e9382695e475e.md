# 2、政治（宗教）的结构——魂

“细胞”是不 能独活的，必须要依附于一个“活体”而存活，就如生命必存于生态之中！

所以人一定要集合起来，形成一个“活体”，这个活体有魂（政治宗教），有骨（依附于自然土地的空间结构），有肉（生产和能量交换），有血（能量的输送）。

作为活体，首先要有“魂”，不然就是“植物人”。

魂是什么？

关系，那就一定是抽象的！

由“细胞”到“魂魄”，这是一个从具象的个体到抽象的集体之过程。
