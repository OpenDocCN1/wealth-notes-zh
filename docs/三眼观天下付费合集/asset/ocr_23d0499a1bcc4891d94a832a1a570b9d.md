# 【歪理邪说的多空市场】

为什么这么多歪理邪说？

因为市场本质上是多空交战，无论多还是空，收的都是心智的钱。

市场上几乎是没有实话的，只有故意而为之的话术，而这些话术分为多空两派。

唱多的赚得多，因为赚“想赚钱的”人的钱，是最容易的。

比如概念洗脑，搞出各种炒房客，牵头的赚后跟进者的钱，不亦乐乎，这就跟股市大牛市来的时候一样，随便个铜锣扔下去都能听见个声响，小散们赚了，那拜师费自然乐意交，“股票大师”自然赚得多。等熊市股市疲软了，大师们不是转行就是不见踪影了。
