# 为什么不是钱？

钱是什么？只是一个交换承载物，在过去我们经过金银本位、粮本位和与美元挂钩本位，那时候市面上钱有多少不是哪个个人或者机构发行的，那时候的钱很实在，充分扮演的趋于公平交换的价值。而今，与发达帝国一样，钱是信用本位，何为信用？就是只要有信用即可一直增发钱，永不完结。信用靠的是一个国家领域的水平，以武力护航。武力+某领域的水平=其货币信用。比如美帝工业科技水平+武力，体现在股票市场上。而我们是土地+武力，体现在土地市场上（地产二级市场本源自土地一级市场），也就是说我们发多少钱ㅁ头说的算，国土资源部才说的算，批多少资源，释放多少土地（地产与农耕土地），就能发多少钱。在这一点上来说了，我坚信 RMB 是比美元要坚挺多的将来，因为科技是有上限的，武力是受到制约的，但我们农村是庞大的！

所以钱一定是越来YW贬值的，因为土地信用是没有预期完结的，起码我们这代人到死也不会见其完结。

那么一个人想积累久的财富，攒钱肯定是不对的，比如养老靠攒钱，想必到老会很凄凉。不用看未来，看过去30年内的变化即可。
