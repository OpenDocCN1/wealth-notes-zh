# 包装与共鸣。

明的知识，因为要让大多数人都接受它，所以要“包装”。

我们每个人从小穿拖鞋子，都是经过“包装”的知识，时间久了就习惯成了“包装模式”，也就是认知形成惯性了。

习惯是个可怕的东西，一旦形成很难改变，能改变的人少之又少，需要颠覆根本观念从内心上会很痛苦的！

包装的东西都带有主观的、人性化色彩的，用三眼的话讲就是逻辑夹带情绪。

只有绝大多数人都可以接受的东西，才能“明”者讲。
