# 内卷化趋势会以往赚钱快的人嗡声最大！

那这时候就要想了，人都是养着钱奔着机去会的，有钱的聚集才有黄金大道，所以你最后那个问题是不对的。

这里讲个逻辑，黄金大道就三点：

+   1、钱多；
2、人多；
3、环节多。

什么内不内卷化的，什么竞争饱和的，都不是主要因素，无论何种情况，倒食就看上面这三点。一个钱多、人多、环节多（分配链条复杂且长）的地方，才是机会会好的地方，是“确定性”的地方。
