# 阴毒与阳善

知识如刀，
放在阴毒者手里，是行凶利器；
放在阳善者手里，是切割工具。
知识就如这把刀，而力量源自持刀者的心性。

天性阴毒者入魔，因其心性中充满贪婪、狡诈、愤怒，而只知道攻击，知识在其手里必为击杀的利器；

# 猎捕与反捕

世界就是个捕猎场，捕食与反捕是社会存在的基本逻辑。
人人与人之间的交互必在攻与守；矛与盾；暗与明；
皆为阴阳。

捕食者必作茧自缚，自损而损；
反捕者必困兽犹斗，无退而亡。
