# 长短反正

利器有长短，事物有反正。

+   长短相互克制；
正反相互转化；
生出形、势、情。

+   得与失即为形；
进与退即为势；
攻守即为观形度势。

形势之较量关键在于心性，在于心志，更在于心力。

# 心志攻守在虚实

+   背离之人，言语懈怠；
疑惑不定，言语散乱；
贤德语少，浮躁语多；
谄媚排挤，虚浮不实；
失去操守，不会气壮。

阴毒者打击阳善者，须以阳善的假象迷惑；
阳善者打击阴毒者，须比阴毒者更加阴毒。
阴毒与阳善只存乎心性，而不在表象。
