# 后记：

何谓思想？何谓谋略？

思想，就是一把把刀；谋略，就是怎么用刀。

或者说，

思想，就是“观牛”；谋略，就是“解牛”。也可以叫“解构”和“重构”。

怎么讲都 dilaksanakan，咱仿庄子，用“牛”来比喻思想或许更便于理解一些。

观牛，是如何把牛看透，看出新高度；

人与人的差别首先是思想的差别，差别在于对事物存在来形状认知不一样；

观牛水平决定了解牛水平。

解牛，是如何顺应或者操控事物的形态。
