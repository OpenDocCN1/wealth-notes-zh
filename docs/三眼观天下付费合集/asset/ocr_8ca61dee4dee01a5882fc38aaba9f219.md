# 简化与复杂

如果把人的思想结构用实际图形表述，姑且可以面为立体三角形，这是在空间上的姑且描述；

思想的原本状态，或者说叫不动状态是 0。也就是没有思想，当加入了时间因素当思想动起来，就会产生从 0-1，而随着思想动作越发复杂，在 1 的后面理论上可以添加无限数字，也就是 ∞。
