# 大树底下不长草！

“草根”这个词发明的很好，虽然不知发明者是否有此意，三眼阁释一下：

![](bbox=[0.22, 0.68, 0.88, 0.78])

大树下面是没有草的，为什么？因为周围土壤的养料被吸收，草无法生长。

这个逻辑套用在社会生产生活上就是：强者把资源都占了，弱者只能在边角。

套用在一个组织体系内就是：领导太“强”，以至于小弟无法施展，变成角落的草。
