# 蛤蟆与宇宙

这世界最逗的事情，莫过于“蛤蟆在井里研究宇宙”！

我们都是蛤蟆，蛤蟆有两种：

+   一种是知道自己是傻逼，去感悟宇宙；

+   另一种是觉得自己牛逼，用“井视”去判定宇宙。

比如现代人用“现代词汇”去研究佛道之法，而这些现代词汇都是由佛道之法衍生出来的，比如用“价值观”去套佛教的逻辑。

如果说我们活在一种“规则定义”里，那么佛道之法就是“定义规则的规则”，用前者去判定后者，就如同井里蛤蟆判定宇宙。
