# 2、贴脸

如果你是村长，你每次在村里搞事，你会先扶慰谁？肯定先是自己人，然后是裙带大户，最后才是吃瓜群众啊。同理，条例落地前，有个风吹草动的，哪里最容易被“送温暖”，或者反向看哪里最安全？

从空间上说肯定是大城市啊。占分配链就是这个意思，同学们要会找“温暖避风港”，有温暖了第一波送到，有麻烦了最避风头。

这些东西从经济数据上你是看不出来的，这属于务虚的“性格层面”的东西。
