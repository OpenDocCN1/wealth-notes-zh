# 【意识形态】

“备周则意怠，常见则不疑”——三十六计之瞒天过海！
我们都对平常皆可见到的事物产生思想的惰怠，因为准备太周详了，不会发出疑问，更不会深入思考，而真正有用的“几点”，也就是关键道理，都是在这些最普通不过的东西上。

诸位有心人打开手机看一看，整个社会的信息流，除了非常专业的应用程序知识外，剩下几乎都是围绕“获得个啥”。
