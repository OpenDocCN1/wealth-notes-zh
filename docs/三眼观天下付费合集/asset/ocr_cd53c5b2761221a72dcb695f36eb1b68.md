# 2、被灌水的混乱的信息流动

首先要感谢互联网，这是人类发展几百万年，能开启民智的最大工具。
但真的能开启吗？
可以，但没有想象当中的强度那么大！
为何？
因为你所能见到的信息，几乎都是被“灌水”后故意扔出来的，随便看。
而且越看越糊涂，越看人的认知越往下走。

首先是因为现在的信息流被割掉！
比如三眼看10篇至少三四篇发不出去，对于三眼来说，写文字的难点不在于思考和表达，而在于怎么表达才能发出来又能讲明白一些东西，这就很难了！
一些词汇要用拼音代替，因为人的思想构成是一个动态体，而动态的关键点就是一个个关键词，只要把关键词控制住了，动态体基本就很难起来。

再次是多数的文章都是没有系统的！
