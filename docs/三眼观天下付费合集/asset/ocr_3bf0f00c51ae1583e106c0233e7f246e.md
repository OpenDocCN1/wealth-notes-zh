# 权、术、势

权势于何时？秦！

人活着就是要“谋”，谋有谋略和权谋之分。

在秦统以前，玩的是谋略，在秦之后玩的是权谋。

谋略之谋在于“略”字，略是棋盘格局，讲的是博弈；

而权谋之谋在于“权”字，没有权力谈不上谋划，这是一种围绕权力、依附权力且以权力强弱为范围边界的“有限博弈”。

乱世靠谋略，治世靠权谋！

秦统一，法家归结八字就是权术势；

权代表着地球上玩等级制最至极、最森严，权位决定一切；
