# 3、股市

放水一定要放的，钱进不去楼市多少，进不了企业，去哪？去股市，股市会波动显现机会。

# 4、举债到蓄养

消费需求会疲软，因为人们，不光普通人，中小企业也一样，对现金的重要性的意识会提升到前所未有的高度，疫情过后，会有一波企业同行抢现金，倒食小民变按门爱攒钱。居民储蓄率应该能回升，正好“养一养”。

# 5、金融资产利好

储蓄意味着百姓从实体资产向虚拟资产转移，也就是对金融资产有利，居民稳定收益的投资需求会提升，例如货币（黄金）、理财、基金、债券。
