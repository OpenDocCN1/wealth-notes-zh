# #货币的信用

好了，那么假设你是一国钱庄的老大，造多少货币都归你管，你会怎么造？

首先你要保证全社会分工交换所需要的货币要够用，而且要多造点；
当社会分工进一步细化，生产的东西更多了，钱也要跟着多造一点。

当然你也不能乱造，比如鸦鹊心泛滥，想多造出好几倍的钱，然后给自己钱庄翻修一下搞奢华，小兄弟们都发点，大家不用劳动就来了钱了，但钱总会流入到社会各个角落，全社会生产的事物数量如果跟不上你造钱的速度，什么结果？

物资增长很少，钱多造了好几倍，物资价格必然翻翻，市场上商品价格一时间就会高涨，混乱不堪，你这样玩老百姓还敢信你吗？

参照前面第二点：
2、这种计算方式大家都要信服才行。

所以乱造也不行，自掘坟墓，比如秦宸长当时玩崩盘了就是这个原因，很多历史朝代崩盘了都是因为这个。

老百姓信你才让你管货币，你乱玩失去民心，基本上就要被革掉了。
也就是“灌水多导致淹死了”。

那么怎么灌水才合适呢？这个度怎么把握呢？这个就涉及到货币的信用。

所有的管理者，都在互相掰“养植物”竞争，也就是看谁拖给经济增长厉害。
