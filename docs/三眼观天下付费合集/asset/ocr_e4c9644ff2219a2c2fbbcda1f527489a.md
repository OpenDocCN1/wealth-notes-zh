# 危就是机！

危机危机，危与机是共生在一起的！

危就是“转不动”的时候，自然产生负增长危险，就要“倒通”分配，就要倒通政策，就要倒通开启法门！

机就是“再分配”的契机，所以我们看到金融开放，土地改革，股市改革。

每一次机会，都在危机后的重新分配之中！
