# 假象是生活的刚需

事实上多数人的 人生，只是 个八卦，而 不是求真务实。

求真这个过程古人有 个词：去伪存真！

人心一动，就要“八卦”，怎么去伪呢？

这是人的巨大漏洞，也就是三眼一直讲的“心性不对”！

这时候小伙 伟就说了：三眼你说的这个我知道，那我就不八卦，我也要求真务实，不就 可以 了吗？

三眼答：很难！

因为假象对于人们来说就像是空气和水，每天都离不开，人们不活在假象里就浑身难受…

不要以为想离开它就能离开了，人们会不由自主的就进入假象之中，这是人心 的巨大漏洞。

假象是这个世界最大的“市场需求”！
道被打破了，也是人们的“市场需求”！

人们只要起心动念，皆造假象。
