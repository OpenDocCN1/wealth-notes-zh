# 从表象到具象再到抽象

那什么是“形态”呢？“童子功”是个啥？

看古代经典思想，思想家们一张嘴先聊的就是极度抽象的东西，这不是故弄玄虚，而是因为：

思想力就是从表象到具象再到抽象的能力。观察事物，就是穿越层层表象，洞察其最内层、最本真的形态，这个形态一定是抽象的！

俺字：扛根！

为啥要扛根？为啥要把事物搞抽象？

事物的表象都是纷纷复杂，欲想掌控事物就要化繁为简，找到那个“最简单的形态”，以便于操控它！

研究的越透，扛根越深，思想力越强，事物所呈现的形态就越简单，操控性就越方便，竞争 Walker
