# 柔弱与刚强

猎捕场欲想胜出，必运用两把利器：
柔弱与刚强。

短兵相见，刚胜柔；
持久之战，柔胜刚。

为人妙处在于变易，
时而柔弱时而刚强。

# 简化与复杂

开悟需要简化；
迷惑即为复杂。

简化属守，属明，属康；
复杂属攻，属暗，属矛盾。

知识的妙处在于变化，
即可简化，亦可复杂。

简化，使人得到真相；
复杂，使人得到幻象。

助人，须教人简化之道，简化使人开悟；
捕食须给人平添复杂，复杂使人迷惑。

世间幻象奇多，真相稀少。

众人多皆沉迷于幻象不能自拔，被捕食却快乐非常。
