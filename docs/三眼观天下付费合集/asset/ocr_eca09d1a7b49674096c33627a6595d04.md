# 闲聊百年变局（一）我们都活在分配里

![](bbox=[0.175, 0.195, 0.885, 0.435])

熟悉三星眼的小伙伴都知道“分配”这个词，很重要的一个词，这不仅是一个现实逻辑，更是一个有效思维，它不局限于经济领域，所有涉及到生活领域都要用分配去看，才能有完整的格局。

比如现在最火的、最神秘的、对于大家伙未来发展创食物生活最重要的四个字：百年变局，就是一场地球各帮派之间分配的变化，也就是最大的天要变了…会响未来 20 年都不为过！

分配有大有小，有粗有细，无处不在；静态的叫利益，动态的叫分配。有人的地方就有江湖，就有分配。为啥叫分配呢？

充满世界的东张西例：假设与猪亲。一个词概括就是：抢劫。任何社会交互活动，都是抢劫活动。

信不信由你，这是阶级小白和智者的心法观念。

分配这个词不要觉得很高端，其实是一个很土的词，源于土匪出去抢东西，抢完了就要分东西，或者说抢东西就是为了分东西，这就是分配。只不过现如今地球各个帮派很大，分配形式就很复杂。

但不要把抢说成是后面想发的高端，其实很土的。轻量级撕破脸就是对着骂街；重量大就是互相搭帮，再大点就是帮结伙帮手，弄出各种咋害<|start|>；量级再大点就是互相扔飞弹，那就彻底撕破脸破了。

所以，坏学生都喜欢看古惑仔，到了社会就容易创食；好学生喜欢看我为祖国献石头，这种号放现在 20 年前就很容易创食，但现在走市场经济路线了，就不太容易创食。

虽然是玩笑归玩笑，但背后的逻辑还是分配，因为以前玩分配没啥抓手，那只能用道德去搞分配，现在呢因为几十年参与地球帮派分配，发展有了钱就是用利益分配，玩法变了。

本来我们认为的来叫本源上都是 T 组织嘛…唯一区别就是组织干的大，在地球都排上号，所以叫“大组织”。而因为太大了，一举一动都影响了势力范围里小动物们的创食生活，所以研究大组织就显得很重要了。
