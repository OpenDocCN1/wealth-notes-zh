# 离产业核心要赛越近，分配的财富肯定越多。

从国有到市场，从地产到衣食行用到互联网，哪里“无形的手”多？ 怎么掌握的？都直接决定财富分配路线，直接选行业选项目找位置。

# 资产。

比如股市与楼市的局。股市在创立之初就是为国企融资寻找接盘侠的，再过去 20 年里，随着经济发展货币增发，股市最大的功能就是消灭过剩的流动性，大白话就是把散户的钱蒸发掉，不然这些钱到了市场，那大米不得翻几倍价格啊？过去它一直扮演“蒸锅”的角色，散户的钱就是水，目的就是把水蒸发掉，所以在高度通过膨胀时期，股市大概率会来一波快牛加大鹏来蒸发“水分”。而楼市是土地信用载体的延伸，作为信用载体的一部分，资产价格走高是必然，往往资产价格走高之后，或者之前，股市都会刹一轮韭菜，蒸发一遍水，每次先后顺序不一样。大的规律是不变的，只是在每次的手法上有个花样而已。

# 消费升级与产业升级。

此局的意义更在于普通的生意上，产业升级的根本是消费升级，想必没人会这样说。大白话说就是：人都有钱了，爱花钱，企业才能制造出更高端的商品来满足消费，都穷可不得拼多多嘛，不要怨企业家无能，百富榜都是什么地产、零售这些玩财富转移的，核心在于居民可支配财富。
