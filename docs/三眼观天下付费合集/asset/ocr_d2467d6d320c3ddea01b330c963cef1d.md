# 1、辩证

辩证思维是人看待万事万物的基本思维，这么质朴简单又实用的思维，缺很少有人拥有！

**什么是辩证思维？**
就是双向思维！所有的具体“结构”都是由此演化而来！这是“结构”本源！

哲学是人思考的起点，人们对哲学敬畏和不解，是因为大多数搞哲学
的把哲学给搞复杂了，哲学“以为为本”，只要你想用它，它就会很简单！
