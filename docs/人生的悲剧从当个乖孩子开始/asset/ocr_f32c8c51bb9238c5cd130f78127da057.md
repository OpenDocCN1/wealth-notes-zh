# 不安的三種基本性格

關於人被遺棄時，內心所感受到的不安是什麼呢？我們來想想看。羅洛·梅針對不安這種情緒的說明如下：請想像一群在戰場上浴血奮戰的士兵，假如敵人炸掉了我方的通訊中心，結果會如何？恐怕我方軍隊會失去方向，不僅慌張失措，甚至會潰不成軍吧。這時，士兵們就會陷入不安之中。羅洛·梅說，不安會使人類失去生存方向，不知所措。
人們只要感到不安就無法放心，最後被滿身的焦悖驅動、懷著神經質的競爭意識，或者想造成他人不幸，或者食欲不振、失眠纏身、極端地迎合他人。
引發不安情緒的，就是內心的糾結。卡倫·霍妮表示，要解決這些糾結的方法，首先得區分當事人屬於三種基本性格中的哪一種。其中一種性格屬於 работникам? Actually: 屬於勉強自己裝乖，也就是所謂「乖孩子」這類的性格。他
