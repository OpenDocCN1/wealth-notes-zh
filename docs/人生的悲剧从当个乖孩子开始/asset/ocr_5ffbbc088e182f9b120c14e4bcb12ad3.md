# 夫妻失和導致孩子精神扭曲

人不會壓抑恨意，也會壓抑愛意。讓我們思考看看以下這個案例。父母感情失和，但父親與女兒的感情卻很好。女兒為了維持與父親的關係，選擇跟父親站在同一陣線，而壓抑自己對母親的情感。當雙親感情不睦時，家庭成員中就會產生某些壓抑。如果是父子結盟，那麽兒子就會壓抑對母親的愛；而若是母女聯盟，女兒就會壓抑對父親的愛。為了跟父母的一方維持關係，於是禁止自己擁有某些感情。但逼迫自己拋棄這些情感，並不表示情感就不存在，只是從意識層面放逐到潛意識。親子關係因此變得更加複雜，難以釐清。如同前述，壓抑愛意是為了跟父親母其中一方維持關係。要跟母親維持關係，就得壓抑對父親的愛。母親的存在等於是妨礙自己去愛父親。結果，孩子對母親產生了敵意與憎恨。
