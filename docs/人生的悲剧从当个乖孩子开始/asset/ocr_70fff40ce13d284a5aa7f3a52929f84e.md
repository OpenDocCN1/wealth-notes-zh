# 遷怒到孩子身上

問題父母的類型可說是五花八門，其中一類父母光有身本事，卻不能力用在自我成長，而把精力耗費在強迫孩子接受自己的價值觀。這種父母會因為孩子隨意的話語、無心的動作而遍體鱗傷，勃然大怒。佛洛伊德說過：「所謂人類的成長就是自我滿足，就是面對他人對待自己
的態度時，是能否心平氣和。」「這不僅是人類的成長，還可說是自我的確立。
當自我完整了，就不會因為他人的舉動，動搖不安。
關於這點，馬斯洛也有過類似看法：當安全、歸屬、愛情、尊敬等渴求，
只能從當事者以外的人身上獲得，那麼這個人就只能依賴旁人。例如，向人撒
嬌的渴望就能歸於這部分吧。
