# 孩子淪為父母精神糾葛的犧牲品

人心中一旦有煩惱，就沒有餘力去管其他事，糾結的情緒已經占據了整個心靈。為人父母者若被自己內心的糾葛而分散了注意力，就無法顧及孩子的心緒，這種狀況可說是屢見不鮮。

陷入憂煩的人沒閒工夫聽別人說話，或許耳朵有在聽，但注意力卻沒在那上頭。煩心的人經常陷入自己世界，縱使眼前有絕妙美景也視而不見；即使吃著山珍海味卻如同嚼蠟，老是掛意著別的事情。

換句話說，煩惱的人無法關心外在世界，情緒總是高漲且緊繃，也無法與他人接觸交流，畢竟光是消化處理自己的事，就足以令他筋疲力竭了。

跟這種滿是憂懼的人來往，即使是成人也會覺得相當費力。這樣想來，若孩子在苦於內心糾結的父母膝下長大，他們會有多麼為難，就不想像了吧？
