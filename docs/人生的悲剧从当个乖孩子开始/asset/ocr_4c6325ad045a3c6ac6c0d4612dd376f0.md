# 也可說是一種安撫。

母親聆聽孩子說話，就是他給予年幼孩子的安撫行為。但當母親屬於「必須得到他人的需要的人」，就無法給予孩子充分的安撫。這名母親只會把自己認定「自我中心式的愛情」施加在孩子身上。她滿腦子急於把自認的愛情形式施加在孩子身上，根本沒有多餘的心思去傾聽孩子的語言。想從孩子身上索求安撫的母親並不少，結果孩子被改造成了「安撫母親的小孩」。「乖孩子」可說正是「安撫父母的小孩」。套用《強者的誕生》的內容來說，乖孩子們都罹患了「母愛缺乏症」，用身體來比喻則是營養失調。

這類罹患「母愛缺乏症」的孩子日後將成為心靈容易受創、難纏又聒叨的大人。由於他們將自己與對方連結在一起，隨著對方的態度改變，就會致使他們頓時失去依靠。

為了逃避這些不安感，乖孩子們究竟扛下了多少的重擔？他們永無止盡地拚命逃避，直到整個NIEnv消耗殆盡。
