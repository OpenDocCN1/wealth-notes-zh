# 表面上的「適應」

神官能症的人大多會說著冠冕堂皇的話，心底想的卻是相反的事。
比方說，一名精神官能症患者，表面上擺出作風民主、對權力毫無欲望，
彷佛聖人般，但內心深處卻期望如同專制君主一樣獨斷，且眾人都對自己臣服
得五體投地。他們忽略自己在情緒方面並不成熟，卻試圖展現手腕，作出一番大事；所遵循的規則與本性之間經常彼此矛盾，無法意識到自己內心的真實。
精神官能症患者最後遭到他人厭惡，就因為內心擺明有強烈的支配欲，但用看似光明正大的理由將之合理化，自己則渾然不覺。
明明感到憂懼不安，還硬裝出一副自信滿滿的樣子，這種偽裝的自信使人厭煩。

讓我們重新思考一下幼童與母親之間的關係。
