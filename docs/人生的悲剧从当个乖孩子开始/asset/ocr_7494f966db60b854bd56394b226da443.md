# 升遷憂鬱症、搬家憂鬱症的機制

人類必須把自己當作依歸，才能夠真正相信自己，湧出活下去的自信。為
了獲得活下去的自信，首先必須學會從心理上依靠自己。只要能夠相信自己，
其他人也才能相信你。

若能擁有自己的人生定位，心理上就能安定。這樣就能讓自己從延期償付
（moratorium）²畢業吧！心境上也能量區分自己是自己、他人是他人。在
心理學上，稱作「形塑自我境界」。

舉例來說，搬家或升遷常是引發憂鬱症的契機，因此發病的就被稱為「升
遷憂鬱」或「搬遷憂鬱」。那麼為什麼這些事情會導致發病呢？

搬離長年住慣了的地方，或者離開已經駕輕就熟的工作型態，的確會喚起
人們內心的不安，但光是這樣並不足以說明為何引發憂鬱症。
