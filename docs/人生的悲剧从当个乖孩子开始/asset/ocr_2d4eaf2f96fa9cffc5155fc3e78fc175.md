# 「無私父母」的利己主義

我們經常在電視上看到非洲野生動物的生態，當獅子追逐小鹿時，在後頭緊追不捨，直到小鹿筋疲力竭、雙腿發軟，最後慘遭捕獲，落入獅口。
看到這樣的畫面，我經常會聯想到「乖孩子」與「不安感」的關係。乖孩子
子努力想要逃離不安感的掌控，使盡全身的氣力逃跑，在倒下前都一直 在逃 。
但不管他如何逃竄，也無法逃離不安感的手掌心。結果還是被抓到，且被吞食
入肚。憂鬱症就是這麼來的，也可說是「燃燒殆盡症候群」吧。

我父親就像前述的人們一樣，無法光明磊落 地將自己的想望說出口。無論
大 小事，他固定會採取的模式是：「一切都是受到對方請託，所以我來幫他
做」。父親總是把自己的願望粉飾成別人的願望，轉一個大彎來實現。
