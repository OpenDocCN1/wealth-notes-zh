# 第十二话 因远故近，因假显真的网络情欲

# 网络情缘的本末倒置法则

# 网络世界是内心的投射

网络改变了世界，也包括改变了世界上人与人之间的相处模式。网络的投射，就是人性的投射，那些心理普疾，原来都差不多：寂寞、渴爱、希望被关注……

而这一切，统统可以透过网络这个平台填补。只因为，它存在于虚与实之间，想象空间可以无限被放大，平衡真实所不能发生的困顿和乏味。

网络里的交往，都是本末倒置的。真实生渍，见面寒暄，客套，七分距离，风一般来去，没痕迹地逗留过。网络上容易无所防备，打开心房，更容易找个对象来对号入座，让自己幻想、希冀、渴望、失落于现实的一切发生。

# 幻想空间越大，爱得就越伟大

有时候，网络情骗案中，所扯出的心理黑洞，令人咂舌，更令人难以置信。

我的一个姐妹是个见多识广，思维也走得比起普罗大众更具前瞻性的媒体人，没想到在寂寞投射前，还是差点栽了跟斗。误堕情网骗局，在网上你侬我侬，后来是老掉牙的情节：对方寄来礼物，后来说被扣押，要女友交税款云云……

女友竟然对对方还抱有信任，觉得：「如果他是真的，我怀疑了他，我岂不是辜负了他？J

要不是对方催钱催急了，让女友生疑吞吞吐吐地拿出来讨论，被几位姐妹淘反设计令对方露出真面目，女友将是赔上感情和金钱，又被人骂笨蛋的受害者。

唉，足见在现实生活，我们抑压了多少情感，不敢承认自己的需要，才在网络上被人有有机可趁！
