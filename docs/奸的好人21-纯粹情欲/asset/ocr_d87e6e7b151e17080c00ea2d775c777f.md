# 明明白白女人心

女人心，海底针？好难明白女人到底要什么？

事实上，女人好容易明白，甚至掌握。那就是，在她在乎的人面前，她是一个情绪化的小女人，她是一个爱哭鬼，她是一个爱撒娇的小朋友，有时候又是一个软弱无力的笨蛋。换句话说，女人千变万化，但万变不离其宗的就是要你注意，要你疼惜，要你呵护。千穿万穿，马屁不穿，这句话用在女人身上尤其合适。

当然，如果你懂得修饰和包装，就是秒杀的甜言蜜语了。

跟女人互动看似地雷处，事实上，女人最难明白的地方是：有时候就连自己都不知自己想怎样，反而要你告诉她，她想怎样。

男女相处时，最常见的女性内心对话有四个：

# (一) 要我讲出口你才做就没有意思！

女人时常提供矛盾的信息：「我想要在你身上得到这样那样，可是又不喜欢自己讲出口了你才来做。因为若要我讲了了你才做，我根本不知道你是真心要做还是被我逼到你做，而且我最讨厌咕咕逼人，但我更讨厌你没做……我究他妈的竟想怎样啊？」

到最后，你会发现你的女人言行不一，你所提供的，她都否定，同时又脸臭臭的告诉你「没事，没关系」，她的脸已经臭到连盲人也看得出她是有诉求的，但她偏偏的就是不想讲出来。

你可能会想「那很简单啊，就拿一系列的东西来试问她，直到我讲中或猜中的话，不就行了吗？」

不行。我假设你讲出的其中一样东西是她要的话，就因为被你讲了出来、问了出口，她还是会给你不置可否的答案。

这，就是女人！
