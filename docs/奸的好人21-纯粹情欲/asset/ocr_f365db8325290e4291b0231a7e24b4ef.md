# 男女间等价交换的危机

女人虽口头上说希望她的男人不断给她钱花，但正常的人就会有「情感亏欠」，所以才会衍生出等价交换的概念。

但，在男女关系上，因为加上了「感情」的因素，这个等价交换的兑换率就会因此而改变了。

我的付出让你觉得不错，你的亏欠感告诉你以后要回馈「不错」。我的付出让你觉得很好，你的亏欠感告诉你以后要回馈「很好」。我的付出让你觉得感动，你的亏欠感告诉你以后要回馈「感动」。

需知道，上面我所讲的三个付出，在物质上可能是一样的，但我呈现给你的方式若不同的话，你的感觉就会不同。

男女感情里面绝对不是无条件付出，也绝对不是等价交换。无条件付出的，最后自己作贱。很有意识的计算和衡量等价交换的话，那根本不是爱情，只是交易。

# 情欲解码:

爱情就是有时候无条件、有时候等价交换、有时候不等价交换，而且还要大部分的时候在下意识中进行，少部分清醒。

男人在付出的过程中，总以为「物质」的付出比「感情」的付出更重要。而女人就算本来已经爱上了一个男人，但，当这个男人开始对女方做出很多物质上的付出，他会有一个危机：女方觉得他「感情」上的付出比起「物质」
