# 男女对安全感的不同诠释

就算不在婚姻，普通的爱情也会受物质的影响。在一段感情里面，大部分的时候男人是供给者，女人也希望被呵护照顾。一个愿给，一个愿受，有什么问题呢？

到底是「给」和「受」什么呢？

安全感。

不过，很多人认为男女的安全感大有不同，男人对安全感的思考方向是「物质」，而女人对安全感的定义往往最「情感」。

所以，有些男人在物质上奉献了很多给他的女人，女人会说：「我不需要你常带我去什么高级消费的地方，不需要吃什么龙虾餐或喝什么 Chateau Mouton 名酒，我只是要人对我好，珍惜我。」

男人会很纳闷的想「我不是已经对你很好了吗？」，于是就有人谷女人要寻找的安全感是属情绪上的。但，这不是全貌。我可以担保如果一个男人能提供给女人情绪上的安全感，却没办法提供物质上的享受，她照样会拿「物质问题」来和男人吵。
