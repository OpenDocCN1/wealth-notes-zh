# 情欲解码：

一个能够给自己很多理由不出轨的男人，未必是件好事。将来出轨的话，是因为他找到了更好或更足够的理由。

理由其实就是借口。

他不是不想出轨，而只是有很多借口不出轨。

真正发不出轨，不是因为道德、责任、感情或孩子，而是纯粹简单的一很恋她。（只是爱她是不够的）

凡是跟你讲「我不能乱来，因为 XYZ」的，一就是曾经乱来，或二，多次想过要乱来了。所以我从来不相信讲这些话的男女。

# 男人喜新厌旧的秘密

在我的追女班里面我常用一个「扬州炒饭理论」来诠释为什么男人会喜新厌旧。

一般的男人都会说再好吃的东西，如果每天吃，最后也一定会闷。闷了就想吃些新东西。跟一个女人在一起久了，不管她多漂亮，床技多厉害，久了就会闷，会开始想试试新的女人。

所以这时候男人一就是偷吃劈腿，再不然就是开始物色新猎物，然后分手。然后他发现跟新的女人在一起的时候，啊！那么违的感觉回来了，爽啊……

但，热恋期一过，你会发现又不知怎的又闷了。如是者，男人会说就算你喜欢吃扬州炒饭，你不能每天吃。过了一段时间，你要吃福建炒面；再过一段日子，你要吃小笼包。

但，我要提醒男人们所犯的一个很关键错误：

你觉得天天吃扬州炒饭很闷，你飞到巴黎的高级法式餐厅，坐下后你跟侍应说：excusez-moi，扬州炒饭 s'ilvous plait。

你只是在不同的地点、人物、文化、气氛之下，重新再吃扬州炒饭。头两三次在欧洲最浪漫的美食之都吃扬州炒饭，确实会有另有一番风味，但接下来就未必了。
