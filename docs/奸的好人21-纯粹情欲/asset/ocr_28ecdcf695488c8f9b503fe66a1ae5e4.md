# 男人的口品

不过，我男性朋友中最经典的 Turn off 故事，是一个自行中断的一夜情。他某次在夜店中喝了一些酒，跟一名火辣的他族女性擦出火花，酒精和热舞之后，顺理成章的到了时钟旅馆。女方很熟练的解开他的裤头，开始为他口交，功夫很好，但总觉得有一点点说不出的怪怪感觉。
