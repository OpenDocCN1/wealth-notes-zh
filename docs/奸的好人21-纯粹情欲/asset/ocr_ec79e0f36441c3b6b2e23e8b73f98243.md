# 男女有别的性感

女人的性感睡衣、内衣裤，姐妹淘之间称之为「战衣」，一言以蔽之，是用色诱男人穿的。女友跟男朋友分手，心痛的是：「刚刚买了一批很贵的内衣裤！难道要穿来给自己看？」女人穿得性感，从来都需要观众。女人：以挑起男人的欲望得到满足感，当然，同时也是满足自己的虚荣心。

可是，似乎很少有人会去研究，女人喜欢看男人怎样穿、穿什么，来达到视觉刺激的效果。

这一点，恐怕跟男人看女友有所不同。问男人，十个有十个，都会说要令男人春心荡漾、心痒难搔、蠢蠢欲动又不敢动的，是四大真字：若隐若现，得要靠造想象空间，而不是纤毫毕露，老土一句，就是「性感不等于暴露」。

想象力才是杀人的武器，这种激发想象力的穿著，会在下一篇透露。

# 自制吹气公仔

十年前在读大学时，我和两位女同学是「姐妹三人组」，我们都非常喜欢学校的篮球队队长，高大俊朗的外型，洋溢着阳光气息，最重要的是，他的胸肌发达坚挺，又喜欢穿紧身衣示人，下半身经常是白色长裤，迷死校园一众情窦初开，荷尔蒙沸腾的少女。

那时候我们三人自创了袭胸十式，只要在口沫横飞间「偷袭」了他的巨胸，就足以令我们兴奋半天。

有一天在宿舍无聊，我们又想起了队长那四十二寸胸肌，一时间「兽性大发」，便找来一件蓝色紧身衣，一条白裤子摊在地上，然后在上半身塞进一个枕头，营造了队长平日胸肌逼爆的效果。尽管如此，还是觉得有点不对劲，才想起是胯下之拉链部位太扁塌不够真实，就找来了一条香蕉，令两腿中间隆起，造型成功！我们为着这次的意淫，笑了三天！
