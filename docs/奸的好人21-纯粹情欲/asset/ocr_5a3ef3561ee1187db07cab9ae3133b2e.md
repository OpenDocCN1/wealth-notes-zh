# 第二十一话 出轨是出了什么轨？

# 精神出轨是种高级玩意

# 文明人的出轨

出轨就是出轨，为何把出轨画出一条楚河汉界，区分为精神和肉体？

有了文明以后，这个世界忽然多了很多似是而非的道理和解释，一旦我们发现自己某些行为是违逆了这个主流价值，自然而然便要言之凿凿地搬出大条道理，以表示自己并无违反社会规则，好让自己堂而皇之地生存下去。

于是，出轨的人分为两组：精神和肉体，当然后者当中有很多又是灵肉皆出的个案。尽管精神肉体出轨这般分类的起源不明，但显然是「精纽」那班人搞鬼，把难以拿捏标准和罪证的「自己」和「人」的身份抬高一点，好让另一组人可以贬入十八层地狱为自己垫尸。

当然，「肉纽」人亦不笨，他们懂得借尸还魂：「我跟她只有性，没有爱，我还是爱你的」……因此获得开恩成功返回阳间的，还大有人在！因为，一讲到爱，爱是无色无嗅无形无态，换句话说，是任你讲的，怎么讲，都是对的！

自古正派的爱情观都认为邪派的该死，而邪派的都认为自己爱情观被误解。
