# 男女互不敢先开价的游戏

两性关系中男人的主动出击已经是天公地道到近乎宇宙定律了。男人的精虫每天可以生产上亿，女人的卵却每个月只有一粒，一生之中不会生产多过四百多粒。基于物以稀为贵的道理，所以在两性关系里面，通常是男人采取主动去争取洛阳纸贵的卵。但，不要被这个表面上的形式所骗了。

大部分男女的初阶约会形式，都会玩着一种类似商场上的「开价」谈判游戏，两方都不想成为第一个先开价的人。在商业谈判进行当中，买方不想先透露自己的预算，卖方也不想先报上自己的价钱，生怕先开价就会失去了主导权。

约会初期，如果双方势均力敌，即你有我要的美色，我又有你垂涎的才智，同时大家又隐隐约约的知道对方好像又有兴趣，两个「聪明人」就会开始玩这种「你先开价」的谈判游戏。开始时我可能还会承认对你有好感，但我的计划是打死也不先说我爱上你。

目的就是不想失去主控权，我若告诉了你我爱你，我会不会把你给吓走？你拒绝我的话，我岂非很没面子？

# 情欲解码：

情场高手有两种，一种是单向，另一种是双向。

如果你是单向高手，你能够让对方觉得她爱你多过你爱她，进而使她情不禁的被你拉了过来。

如果你是双向高手，你能够让对方觉得你们俩互相喜欢对方的程度是不断增加，进而双双被对方拉得越来越近。
