# 一个最难的选择题

想象一下你现在要面对一个可能是你人生中最大的选择：放弃性快感但保留味觉，或者，失去味觉但保留性的享受，你会选哪一个？

好好的思考这个问题，若你不觉得难以下定决心，那你可能还没有真正地生活过。

我们的一位朋友（辩论大师）曾经因为鼻腔发炎，而导致他的味觉神经受损。他曾经好几个月吃什么东西都没有味道，就算他放再多的酱油、辣椒、姜戎，他什么味道都尝不到。

最要命的是，他极嗜美食，所以他非常的恐慌。最后，每逢他与朋友一起到餐厅用餐时，他会夹着食物来嗅一次，尝试想象食物香味吃下去的感觉，然后不断地叫朋友描述菜肴的味道。

你能想象自己接下来的人生在吃饭时候，只能靠朋友的描述来激发起自己记忆中的味觉享受吗？

# 太监心理变态的真相

辩论大师是因为生病而忽然失去了味觉，所以这个丧失是忽然式的，而不是渐进式的。如果一个人突然间失去性能力，那其实跟太监没什么分别。

性能力不等于性欲，太监切除了身体上的性器官，不代表他们没有了性的欲望。这种欲望不是身体上的欲望，而是心理上的。

相对于生理欲望，心理上的欲望才是最难控制的。
