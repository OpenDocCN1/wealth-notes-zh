# 网络见真心

人与人之间都渴望得到一种可以把心中的话说出来的联系感，但社会的礼教却规范我们不要太热情。网络恰恰变成一个可以满足这个需求的替代品。

在面子书上，你可以单单写出感性的金句，而得到人家认可。但，在现实的环境，你不能马上就讲出一金句，你需要有句前铺排和句后跟进。现实生活中，你不可能跟朋友聊著菲律宾和台湾的政治紧张当儿，忽然间爆出一句：「当火花、激情和感觉都完全没有后，你们还选择在一起的话，就是爱。」

但，在面子书上，抛出这一类的金句，不少人就会来回应你，特别是女人。因为这一类「长情」金句，女人是最容易做出情绪上的对号入座。追求异性的过程中，通常是到了熟悉后，大家才开始聊这类话题，但面子书上大家都可以违例超车，越过前面的培养感情，直接走到分享内心价值观的阶段。

所以我不赞同社会上的一些评论家说网络使人与人之间变得更冷漠的言论。可是，为什么网络的距离反而让人更容易分享内心话？

# 因为假，所以能显真

网络上的交流，就因为有假面具的保护之下，所以用户才敢把自己的本来面目显现出来。因为对方看不翻也听不到自这，你就如同电影ĀVĀTAR般，进入了一个虚拟替身来跟另一个人的虚拟替身交流。

大家戴著面具时，交谈时的顾虑和修饰都会大大降低，心里的话就容易溜出来。

但，你可能会问：「我们在网上会把自己的样子，甚至是职业、年龄、一些背景也上传，每个人都会看到的，怎么会说是戴上了面具呢？」
