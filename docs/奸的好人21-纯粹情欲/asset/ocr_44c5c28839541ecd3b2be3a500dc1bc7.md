# 没有生命力和有生命力的型

常年累月对「型」的机械化认知底下，就是完全对「型」堕入单一标准陷阱的机械化反应：只要你这样的外型条件，就是型！

只要你说或做了这样的事，就是型（反之则「火罗、出糗」！只要你戴了这个手表涂了这个香水穿了这条内裤喝这个品牌的啤酒（矿泉水也行！）用这个发蜡洗发水……就是型！

所以，你可以想象，大部分男人在生活上是多么不型，自我价值感早已淹没在一堆工厂倒模的准则当中。

事实上，敢于活出自我风格，有自己味道的男人，才是最型。

时装大师 Coco Chanel 讲过这样一句话，被女士奉为金科玉律，男士现在学也不算太迟：潮流瞬息万变，只有风格永存。
