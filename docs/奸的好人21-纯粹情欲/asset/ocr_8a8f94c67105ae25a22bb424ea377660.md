# 做个多类高潮的男人

我会告诉你这种无射精高潮的深度是会更全身式的，射精高潮有爆发性，但却是局部性的。

所以，如果有人告诉你全身式的高潮才是值得追求，又或者有人说有爆发性射精的高潮才会得到真正的满足，这两种男人都是没有实践过这两种高潮。

人类，是贪心的。试过了这两种高潮后，你就不会认为这两种高潮是位于一直线式的层次，所以根本不能说谁比较高。你将知道这两种高潮是不同性质的高潮，要比较的话，就好像拿橙和苹果来比较哪个好吃。

真正的答案是：你喜欢吃橙还是苹果？或许有些时候你喜欢吃橙，另一些时候你喜欢吃苹果？而且，如果除了橙和苹果，还能给我多一个选择——蜜桃，我会更开心。因为我以后的高潮就开始多姿多彩了。

所以，当我看到一些作家或专家说不射精的高潮才是高层次的，我就只能猜测可能只是一位抄写者，不是实践家。实践过的话，你根本不会把不同高潮放在高低位。

甚至有些作家还说不射精的高潮，阴茎还能维持坚挺时，我也知道他们肯定也是没有实践过这些方法。

现实的情况是：没有射精的高潮，只要有海绵体的重复收缩和放松，之后还是一定会软下来。

这种无射精的高潮，也仅一次。不能做到所谓的多重高潮。
