# 为什么不要搞办公室恋情？

职场中的恋情，往往没有一般恋情的直截了当。同事与同事之间还好，一旦涉及上司与下属的，就有很多事情要关注了。

首先，先查查自己公司对性骚扰的政策是什么。在外国企业，公司里面的性骚扰法律和政策是很清晰的。一些是指明上司和下属不能有任何情侣关系，因为这可以避免偏爱行为（Favoritism）。

在一些外国公司，就算是同事的关系，也不鼓励发展成为情侣。所以老外们有一句话：Don’t shit where you eat，意思是不要在自己的饭桌上大便。跟同事发生了恋情，未必会对效率有太大的影响，但如果之后在恶劣的情况下分手，就会有很多很麻烦的骨牌效应。

若你们是恋人，开会时如果你不认同情人的建议，你会坦白在会上说出来吗？她犯错，你会如卖大公无私的举报出来吗？你提出公司走大胆路线，她是会计部的，她发表了她的保守建议，你们俩都对自己的工作非常认真，你认为这个意见上的不协调不会影响到你们的私人感情吗？
