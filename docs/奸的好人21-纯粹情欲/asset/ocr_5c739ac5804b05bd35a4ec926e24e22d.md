# 客户讲出假要求，厂商提供虚货品

然而，对于自尊心强的男人来说，真是成也自尊，败也自尊。他们怎敢承认自己在暗中模仿哪个明星？跟随银幕上哪些举动来自我塑造形象？

我见过一些男人活在刘德华青涩演技时代，一进会议室或咖啡厅的门口，就会鼻孔微露、印章微皱般的刻意造作烂有型。（更过瘾的问题是：刘德华当年又是模仿哪个明星？）

如何建立起自我风格？难道要去问人吗？

要记得，男人是走错路也不肯问路的动物啊！结果还要承受画虎不成反类犬的挫折和压抑……做男人，真辛苦！

其实，女人都是表里不一的，表面上说喜欢这个男明星那个男歌手，因为够型、够养眼。对于浪漫男女关系做有遐想式的自我投射，当然是这套标准。

而电影和电视的主要客户群还是女人，所以市场上就生产了一系列放大女人内心幻想的角色，诸如星星或暮光之城是女观众最爱。而当男人模仿这些媒体炒出来的型，就是缘木求鱼了。

女人自己芳心被拨动的时候，往往不是表面希冀的这套。她爱上的那个男人可以丑、肥、没钱、没事业、没名牌或以上皆有……但他有自己的风格，就够了。

所以，当男女间对「型」的认知有如此大的鸿沟时，男的就提供了一个没有人要的货，女人就乱讲自己要什么货。

好了，那么撇开了「型」的迷思，什么才叫自我风格？

# 脱离型的思想

那得要先有勇气打破机械式的思维和观念，譬如，觉得自己样丑身肥就没有吸引力、追不到女生……先扭转自己对型的认知，打破这个思想闷局，就开始活出了自我风格。
