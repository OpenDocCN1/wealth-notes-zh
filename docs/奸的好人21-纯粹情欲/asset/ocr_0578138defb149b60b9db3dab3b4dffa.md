# 打了一场惊心动魄的手枪

中学时因为常看一本很多性知识的女性杂志，里面也讲了不少男女自慰的方法，看得自己更加的心神荡漾。因为杂志中讲到龟头很多快感的神经末端，所以有一次洗澡的时候就躺在浴室地上，用了一点点肥皂泡沫涂在指掌充当润滑，然后就搓弄自己的龟头，果然很刺激。

越搓越爽，就闭上眼睛的享受。搓到下体也流出了些润滑液，心里面也兴奋起来，继续再搓的时候，润滑液越来越多。睁开眼睛看看，我被吓傻掉了。

原来我不是搓出了润滑液，而是搓出了血。

心想不是吧，从射精演变到射血？

在看清楚点，发现应该是指甲刮伤了包皮和龟头底下连接处的结构。不过，这还是蛮吓人的，那一次之后，我的飞机作业就停止了约半年。

重新再打开自己的飞机场，再度投入快感探索后. 又「掌握」揉搓龟头的自慰法。

# 各种自乐法的不同体验

总结而说，我的自慰腿法，所得到的高潮比较全身式，能够体验到又深又细致又长的高潮，全身都会投入的快感操作。正常男人的高潮约莫是两三秒，不过我却试过高潮的时间长达半分钟以上。

活塞式的自慰手法的高潮通常没有全身式，因为全身只有手和下体投入快感操作，如果没有想象力的话，就加多一双眼睛看计算机，所以它的高潮就没有腿法般深、长、细。

搓弄龟头的自慰法属于比较刺激，不常做，就好像笨猪跳是很刺激，但久久做一次就可以了。可是千万记得打飞机别打到出血。
