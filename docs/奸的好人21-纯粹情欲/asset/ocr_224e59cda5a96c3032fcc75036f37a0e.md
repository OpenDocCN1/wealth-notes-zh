# 第二十话 爱情与物质的冲突

爱与物：本是同根生，相煎何太急？

# 爱情中的有形无形论

如果你们双双不是大有钱人，爱到有鱼水之欢后，你们之间的爱情和物质就会开始有微妙的变化。

爱情需求和物质需求，是一还是二？

爱与物可以是同一脉络，只不过在普遍的教育思想层次当中，人们只能把两者分化处理，简化价值观的灌输。

只因两者形体不一：前者无形，后者有形，以有形象度无形，就好像用有限来理解无限。以有涯随无涯，殆矣！

爱是无形，所以爱需要有形的语言、物质来承载。物质就好像一个容器，能烘托出爱的形态，让我们看得到、摸得到、听得到、感受得到。

# 情欲解码：

如果一个人常说他的爱是无声胜有声的话，他一就是自闭症，再不然就是骗人。

比方说，我很重视你的生日，为了给你个惊喜，我特地做了一个「色香味」俱全的蛋糕给你，你从那个蛋糕的外观、香气和口感，领略到那份付出的心思，进而接收了爱的讯息。试想想，若没有了蛋糕（物体）把感情具体话，爱又该如何表达？

世上所有的表达方法，都离不开形式和物体。女人要求男人情人节送花、纪念日送个戒指、生日有惊喜……其实，是想要花、戒指和惊喜背后所带来的被爱的感觉。
