# 做爱的召妓真实面

不止一个朋友曾经说过，真实的性爱，绝对没有电影、小说中精心铺排的那么旖旎浪漫，的确如此。现实中，床第之欢比较贴近那些「一楼一凤」的接客现场：卫生纸、避孕套、开套套时翻错了方向、皱巴巴的床单、毛发、液体……

缠绵到全身香汗淋漓的美态，就只能在电影中看到。现实中做爱做到全身汗如雨的时候，还需要边摘边抹汗。

而更真实一点的是，生活中的性爱，往往没有故事情节中那么缠绵悱恻、高潮叠起，反而「过门不入」、「临门失脚」、「半途而废」的案例比比皆是。谁没试过在床上败兴？

# 江魔性糗事

我曾经试过戴了套子后，搞到一半时，忽然觉得怎么这套子的质感会如此不同。然后低头看着自己的下体抽出时，才惊觉原来套子已经不知何时如火箭升空般脱了节。

当时吓得我们一大跳，因为男人的爱液里面也会含有为数不少的精虫。因为都在抽插着，套子不可能离茎叛道的飞走了，只有可能是被阴道蠕动时节节退下。最后我又得用手指尝试把褶在阴道里面的套子勾出，前女友又得用自己的手指，折腾了几分钟后才弄了出来。

后又得再拿新的套子，重新再来一次前戏，(真的有做戏 NG 的感觉) 互相弄硬逗湿后，快快的套上再来。
