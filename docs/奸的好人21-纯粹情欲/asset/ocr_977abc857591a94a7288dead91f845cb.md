# 男人性欲的悲歌

男人的性，非常的千篇一律，而且是极度空虚的，不管男人学过多少种性交的体位，不管时间可以拉得多长，千辛万苦最后的高潮就是那区区的三秒，不空虚吗？

难怪男人会常常需要性，因为所谓的满足根本不是满足，只是达成高潮目标后的空虚。

你跟你老婆在一起没有了性趣上的新鲜感，不是因为爱情的新鲜感本来就有期限，而是你这个「人」没有新鲜。

如果你的「人」不是「新鲜」的话，你会觉得每一次的高潮都一样。和一个新的女人做爱，那新鲜感是假象，因为最终你还是会觉得千篇一律。但，如果你的「人」是「新鲜」的话，你反而会觉得每一次的高潮都不同。

如果你的做爱就只是为了做爱，你的性体验还没有热忱（Passion）。热忱必须附带着情绪，而且不是你想象中的爱或关怀等所谓正面的情绪。

要怎样才能明白做爱会做到好像有艺术家般的热忱呢？

在艺术界里面，所谓的热忱情绪，近乎都是负面的：愤怒、恐惧、痛苦。

不少的艺术家有抑郁症，Robbin Williams 这个超级演员和台上笑匠，是有抑郁症的。周星驰这厉害的喜剧演员也听说是 有抑郁症。我的编剧老师也提出了喜剧的另一角度，他说喜剧是一种愤怒的艺术。

这也很容易明白，只要你稍微的看看一些出名的台上笑匠，他们都是在取笑和揶揄着一些现象。看起来是弄人笑，只要你想深一层，就知道这些笑匠都是有愤怒的。香港的黄子华的栋笃笑里面，轻易的看出他所揶揄的，都话中有骨头、有刺。

那么难道我们要变成愤世嫉俗同时又患上抑郁症，我们的情欲生活才会提升吗？
