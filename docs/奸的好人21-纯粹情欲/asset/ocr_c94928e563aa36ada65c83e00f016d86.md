# 唯一真爱病的真相

为什么好男人在追求女生时，会若生若死，而被追求的女方却可以视你为可有可无？

因为大部分的好男人都超认真地窄化自己的视线和选择，还未追到手就已经把对方封神，而且还是「唯一真神」。

反之，一般女生不会有这个问题，因为在任何一个时候，她都知道有过多过一个男人喜欢她，甚至一些还同时被几个男士积极的追求着。在明白了自己有很多选择时，她视野的宽度，就决定了她不惑的稳度。

要知道，人是很贱的，当你知道你的伴侣没有其他人在对他有性趣时，你对他的性趣同样地也会降低。但，一旦你察觉瘦田耕了之后有人争，你的瘦田会变成秀田。

难道我们要变成花心萝卜，我们才能在一段感情中有主导权吗？

# 坏男人吸引力背后的真相又是什么？

非也，爱情中多选择只是其中一个方法。但只要你不要把感情或爱人的位置摆在你人生的第一位就可以了。

问问自己，你生命中的热忱是什么？What are you passionate about in life?

其实是什么都不要紧，可以是政治、宗教、武术、爬山、收藏等等，总之是你喜欢的、有兴趣的、甚至是沉迷的，它就可以成为你生命中的重心。若你的生命没有重心，你在感情生活中就会很容易失衡。
