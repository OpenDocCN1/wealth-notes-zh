# 第八话 女神

# 女神其实不是神

# 女神的内心世界

因为工作关系，我访问过许多香港女艺人，当中不乏被公众投射为「女神」形象的大美人。这些美女风姿不一、个性不一、思想层次不一，可是不约而同说过一句话：「外人都以为我很多人追，事实并不然！」

同样的道理可以套在非娱乐圈中的女生，大美人级数的女生，不一定最多男人追，她们确实是很多男人敢远观而不敢近品，只敢遥拜，不敢狎玩，怕会亵渎了神明而遭到报应。

情欲解码：

最漂亮的反而不是最多人搭讪的，但却是每个人都会留意的。所以，男人怕搭讪全场最漂亮的原因是怕被拒绝后的羞耻，会被全世界女生看到。

事实上大部分男人以为大美人很多人追而不敢越级挑战，美人长期芳心寂寞，结果往往「委身」于大家眼中看起来不怎么样的男人，然后归咎为「还不是因为那男人有钱！」

# 女神择偶的局限

事实上，女明星的生活和社交圈子，八九不离十都是有钱有势的人，这不是她的问题，只是工作背景属性使然。她必定长久跟有关人士接触，所以，择偶对象就只分为不好看或者好看的有钱人。

只是呢，男人也许是自尊心或自卑感作崇，思想脉络仅仅是「有钱能使鬼推磨」一条，从来不曾逆向思考，妄论越级挑战了！试想想，貌丑又年纪大的有钱男人，若是有心理障碍，自觉配不起貌美如花的女星的话，也无法抱得美人归。
