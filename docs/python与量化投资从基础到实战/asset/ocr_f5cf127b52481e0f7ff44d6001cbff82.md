分别对源数据进行线性及三次样条插值，使用｀splrep｀和｀splev｀，在表 3-3 中列出了 splrep 函数的主要参数及其描述，在表 3-4 中列出了 splev 函数的主要参数及其描述。

# 表 3-3

| 参数 | 描述 |
| --- | --- |
| x, y | Y=f(x) 上的数据点 |
| w | 应用到 y 坐标上的权重 |
| xb, xe | 拟合区间 |
| s | 平滑因子，权衡相似度与平滑度之间的关系 |
| k | 样条拟合阶数 |

# 表 3-4

| 参数 | 描述 |
| --- | --- |
| x | 一组插值点的 x 坐标 |
| tck | Splrep 返回的长度为 3 的 tuple（节点，系数，阶数） |
| der | 导数的阶 |
| ext | 如果 x 不在节点序列中，则 0 外推，1 返回 0，2 返回异常，3 返回边界值 |

代码如下：

```
In [123]:ipo1 = spi.splrep(X,Y,k=1) #k 样条拟合顺序（1<=k<=5）
    ipo3 = spi.splrep(X,Y,k=3)
In [124]:iy1 = spi.splev(x,ipo1)
    iy3 = spi.splev(x,ipo3)
```
