如下代码展示了部分调仓时间，在每个交易日每隔两分钟进行调仓：

```
2017-01-04 09:30:00
2017-01-04 09:32:00
2017-01-04 09:34:00
...
2017-01-04 14:56:00
2017-01-04 14:58:00
```
