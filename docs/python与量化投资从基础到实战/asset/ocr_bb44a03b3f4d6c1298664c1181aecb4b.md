+   ○ 价差形成了长期趋势。虽然这时价差恢复到了 $N$ 日平均线，但是与开仓点相比，其偏离程度很大。

○ 价差偏差程度较小，这时均值回复的收益不足以弥补手续费和冲击成本造成的损失。
