r_t 与它的过去值 r_{t-1} 的线性相关性，这时我们把相关系数的概念推广到自相关系数。

r_t 与 r_{t-1} 的相关系数被称为 r_t 的间隔为 1 的自相关系数，通常记为 ρ_l。
具体计算公式为
ρ_l = Cov(r_t, r_{t-l}) / sqrt(Var(r_t)Var(r_{t-l})) = Cov(r_t, r_{t-l}) / Var(r_t)

这里用到了弱平稳序列的性质：
Var(r_t) = Var(r_{t-l})

可以看到，由于对投资组合添加了一定的噪声，所以导致计算出的因子权重与原先设置的有一些偏差。

对一个平稳时间序列的样本 {r_t}，1 ≤ t ≤ T，则对间隔为 1 的样本自相关系数的估计为
\hat{ρ}_l = [ Σ_{t=l+1}^{T} (r_t - ar{r})(r_{t-l} - ar{r}) ] / [ Σ_{t=1}^{T} (r_t - ar{r})^2 ] , 0 ≤ l ≤ T-1

则函数 \hat{ρ}_1、\hat{ρ}_2、\hat{ρ}_3 等被称为 r_t 的样本自相关函数（ACF）。

当在自相关函数中所有的值都为 0 时，我们就认为该序列是完全不相关的，因此，我们经常需要检验多个自相关系数是否为 0。

# 5. 混成检验

原假设为 H0: ρ_1 = ... = ρ_m = 0，备择假设为 H1: ∃i ∈ {1,...,m}, ρ_i ≠ 0，混成检验统计量的计算公式为
Q(m) = T(T+2) Σ_{l=1}^{m} \hat{ρ}_l^2 / (T - l)

Q(m) 渐进服从自由度为 m 的 χ² 分布。

决策规则为 “Q(m) > χ²_α, 拒绝 H0”，即在 Q(m) 的值大于自由度为 m 的卡方分布 100(1-α) 分位点时，我们拒绝 H0。

大部分软件会给出 Q(m) 的 p-value，则当 p-value 小于等于显著性水平 α 时拒绝 H0。
