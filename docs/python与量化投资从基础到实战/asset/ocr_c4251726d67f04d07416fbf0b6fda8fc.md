z-score 标准化的计算公式为：

$z' = \frac{v - u}{\sigma}$

Min-max 标准化可以将标准化后的值统一到 0～1；z-score 标准化可以使标准化后的数据分布均值为 0，方差为 1。我们将去极化后的数据再进行一次标准化，如图 4-16 及图 4-17 所示。

```
((df_[‘ROE’] - df_[‘ROE’].min()) / (df_[‘ROE’].max() - df_[‘ROE’].min())).plot.hist(bins=100)
```
