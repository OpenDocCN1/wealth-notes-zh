# 3.5.2 调色板

Seaborn 拥有极其丰富的调色板库，大致可分为循环、渐变、混合三类，利用 set_palette() 函数进行设置：

```
In [154]:plt.figure(figsize=(12, 8))
    sns.set_palette("muted")
    plt.subplot(221)
    sinplot()
    plt.title('循环')
    sns.set_palette("Blues_d")
    plt.subplot(222)
    sinplot()
    plt.title('渐变（深-浅）')
    sns.set_palette("Blues")
    plt.subplot(223)
    sinplot()
    plt.title('渐变（浅-深）')
    sns.set_palette("RdBu")
    plt.subplot(224)
    sinplot()
    plt.title('混合（红-蓝）')
```
