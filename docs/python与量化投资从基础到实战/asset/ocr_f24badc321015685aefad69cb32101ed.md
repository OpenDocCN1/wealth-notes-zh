我们根据真实类别和测试集预测类别的组合划分出真正例、假正例、真反例、假反例这四种情形，分别用 TP、FP、TN、FN 来表示。若已知 TP+FP+TN+FN=样例总数，则可画出学习结果的混淆矩阵，如表 3-7 所示。

我们关心的两个指标为查全率与查准率，其中，查准率的计算方式如下：

P=TP/(TP+FP)

查全率的计算公式如下：

R=TP/(TP+FN)

在本例中，查准率为 100%，查全率为 40%。
