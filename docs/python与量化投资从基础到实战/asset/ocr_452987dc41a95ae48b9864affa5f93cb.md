# 6.8.3 风险平价模型

假设有两种资产 E₁ 和 E₂ 可供选择，如果同时投资于这两种资产，权重分别为 w₁、w₂，则组合风险可表示为

σₚ = √{w₁²σ₁² + w₂²σ₂² + 2w₁w₂Cov(R₁,R₂)}

用资产 E₁ 的权重 w₁ 增长带来的组合风险边际增长定义资产 E₁ 的边际风险贡献，可表示为

MRC₁ = ∂σₚ/∂w₁ = [w₁σ₁² + w₂Cov(R₁,R₂)]/σₚ = Cov(R₁,R₂)/σₚ

则资产 E₁ 对组合的总风险贡献为

TRC₁ = w₁MRC₁ = w₁ Cov(R₁,R₂)/σₚ

组合 P 总风险可表示为各项资产总风险贡献之和：

σₚ = TRC₁ + TRC₂
