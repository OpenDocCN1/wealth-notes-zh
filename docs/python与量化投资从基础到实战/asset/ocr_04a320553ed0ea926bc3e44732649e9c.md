# 3. continue 语句与 break 语句的区别

continue 语句指的是结束执行本次循环中剩余的语句，然后继续下一轮的循环；而 break 语句指的是直接结束这个循环，包括结束执行该循环的剩余的所有次循环。

请区分以下两个程序。

程序 1 如下：

```
In [63]: for i in range(10,19):
    if i==15:
        continue
    print i

Out[63]:
10
11
12
13
14
16
17
18
```

程序 2 如下：

```
In [64]: for i in range(10,19):
    if i==15:
        break
    print i

Out[64]:
10
11
12
13
14
```

在程序 2 中，i=15 及之后均没有输出，因为执行遇到 break，直接跳过了剩余的所有循环，而程序 1 仅跳过了 i=15 这一此循环。
