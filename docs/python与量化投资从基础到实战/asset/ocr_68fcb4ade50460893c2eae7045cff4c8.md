+   ○ 情绪类：指基于量价关系来衡量市场参与者的情绪。
○ 收益与风险类因子：指与收益风险相关的因子，例如股票的 60 日 alpha 和 beta。
○ 基础科目与衍生科目：是财报数据的衍生，例如净利润的 TTM 数值、息税前净利润（EBIT）等。
○ 分析师预期：根据分析师的一致预期数据计算，体现了分析师对个股趋势的预测。
