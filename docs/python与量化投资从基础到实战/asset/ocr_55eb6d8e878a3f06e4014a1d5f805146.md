# 4.3.4 数据转化

除了数据清洗，为了建立模型，我们有时还需要进行数据转化。这里介绍两个常用的数据转化方法：数据标准化及设置哑变量。

+   1. 数据标准化

数据标准化可以消除量纲及变量自身变异程度的影响，对很多模型来说都是十分重要的。常用的数据标准化有 Min-max 标准化和 z-score 标准化。

Min-max 标准的计算公式为：

v' = (v - Min) / (Max - Min)
