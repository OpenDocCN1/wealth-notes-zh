```
In [27]:arr5 ** 0.5
Out[27]:array([[ 1.          ,  1.41421356,  1.73205081],
               [ 2.          ,  2.23606798,  2.44948974],
               [ 2.64575131,  2.82842712,  3.         ]])
```

在 NumPy 中还有一些内置的数学函数，可以帮助我们快速地对数据进行统计计算，比如 sum、max、mean、std 等。

```
In [28]:arr5.sum()
Out[28]:45
In [29]:arr5.std()
Out[29]:2.5819888974716112
In [30]:arr5.mean()
Out[30]:5.0
In [31]:arr5.max()
Out[31]:9
```

表 3-1 列出了基本的数组统计方法。

# 表 3-1  基本的数组统计方法

| 方法 | 说明 |
|---|---|
| sum | 对数组中的全部或某个轴向元素进行求和 |
| mean | 算术平均数 |
| std、var | 标准差、方差 |
| min、max | 最大值、最小值 |
| argmin、argmax | 最大值索引、最小值索引 |
| cumsum、cumprod | 所有元素的累计和、累计积 |

我们也可以自定义函数，再将其传入 ndarray 中：

```
In [32]:def f(x):
    return x ** 2
In [33]:f(arr5)
Out[33]:array([[ 1,  4,  9],
               [16, 25, 36],
               [49, 64, 81]])
```
