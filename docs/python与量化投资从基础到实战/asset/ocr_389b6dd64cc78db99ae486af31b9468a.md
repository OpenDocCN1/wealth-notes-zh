# 2.4.3 认识分支结构 if

if 语句在 Python 中表示选择性地执行，虽然形式简单，但功能相当强大。选择性执行是常规程序设计中的主要控制机制之一，是计算机能够执行复杂任务的关键组成部分。

if 语句的格式用法如下：

```
if (是这样的):
    执行该部分的语句
elif (或者是这样):
    执行 elif 部分的语句
else (或者以上情况都不是):
```
