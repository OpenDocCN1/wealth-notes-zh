# Python量化投资
从基础到实战

# 关于本书

本 RELEASE 主要讲解如何利用Python进行量化投资，包括对数据的获取、整理、分析挖掘、信号构建、策略构建、回测、策略分析等。本书也是利用Python进行数据分析的指南，有大量的关于数据处理分析的应用，并将重点介绍如何高效地利用Python解决投资策略问题。本书分为Python基础和量化投资两大部分：Python基础部分主要讲解Python软件的基础、各个重要模块及如何解决常见的数据分析问题；量化投资部分在Python基础部分的基础上，讲解如何使用优矿（uqer.io）回测平台实现主流策略及高级定制策略等。

如果您从未接触过Python或者任何其他编程语言，则建议您从第1章开始看起，对Python基础编程稍做了解；如果您已经是Python的忠实用户，则可以从第4章开始看起，直接使用优矿平台完成对策略的编写。关于Python基础部分的内容，您可自行安装、运行Python进行学习；关于量化投资部分的内容，您需要用到优矿在线量化平台，不安装Python也可运行。

本书的配套代码可以在http://books.hcquant.com下载。其中，Python基础部分的示例代码的后缀名为.ipynb，是Jupyter Notebook文件，可以直接用Python打开运行；量化投资部分的示例代码的后缀名为.nb，需要上传到优矿的Notebook运行。
