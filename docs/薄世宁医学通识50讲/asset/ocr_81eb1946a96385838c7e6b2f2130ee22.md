# **20~39岁**

不推荐对该年龄段人群进行乳腺筛查。

# **40~45岁**

+   1. 适合机会性筛查。
2. 每年 1 次乳腺 X 线检查。
3. 对致密型乳腺(腺体为 c 型或 d 型)推荐与 B 超检查联合。

# **45~69岁**

+   1. 适合机会性筛查和人群普查。
2. 每 1~2 年 1 次乳腺 X 线检查。
3. 对致密型乳腺推荐与 B 超检查联合。

# **70岁或以上**

+   1. 适合机会性筛查。
2. 每 2 年 1 次乳腺 X 线检查。

# 乳腺癌高危人群筛查意见

建议对乳腺癌高危人群提前进行筛查[小于 40 岁]，筛查同期推荐每年 1 次，筛查手段除了应用一般人群乳腺 X 线检查之外，还可以应用 MRI 等新的影像学手段。

# 乳腺癌高危人群的定义

+   1. 有明显的乳腺癌遗传倾向者。
