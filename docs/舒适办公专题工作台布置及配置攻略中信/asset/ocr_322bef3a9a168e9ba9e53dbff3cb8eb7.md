# 2.1 键盘——介绍

我们推荐机械键盘，机械键盘键程较长，能有效延缓长久打字下的手指疲劳问题

| 轴体类型 | 特点 | 优点 | 缺点 | 是否适合投行人员 | |  |  |  |  | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | 青轴 | 段落感明显，敲击声大 | 段落感、机械感较强，适合打字 | 噪音略大 | 推荐居家使用 |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | 红轴 | 直上直下，没有明显的段落感（黑轴轻量化手感） | 手感轻盈 | 按底噪音略大（可选静音红轴） | 推荐 |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | 茶轴 | 段落结构轴体，但较青轴段落感较为轻微 | 段落感较弱、压力克数适中 | 手感一般 | 适合机械键盘入门 |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | 黑轴 | 直上直下，没有明显的段落感 | 噪音较小 | 按压较为费劲 | 不适合 |  |  |  |  |  |
