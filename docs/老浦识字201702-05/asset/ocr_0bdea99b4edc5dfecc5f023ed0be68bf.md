# ## 恶毒的比用两个桃子就够了

据《晏子春秋》记载，晏子在齐国为相，齐国当时有三个勇士，公孙接、田开疆、古冶子，为人相当傲慢。

有一次，“晏子过而趋，三子者不起。”

“趋”是一种小步快走的姿态，说身为宰相的晏子遇见三位勇士，很礼貌地低头弯腰而行，而这三家伙居然都无动于衷。

这种无礼的举动让晏子感到了危机。

于是晏子就去跟景公说，三个人能力功劳太大，恐怕管束不住，不如除掉他们。

怕管不住就杀掉，这理由也是够奇葩的，而齐景公居然同意了。

晏子让人捧来两个大桃子，让三人自己叙述功劳，谁的功劳大，谁就可以吃桃。

这就是比啊。

三个有勇无谋的家伙立刻上套了。

公孙接说，我上山可以打猛虎，入林可以擒野猪，我当然可以吃桃。二话不说拿了一个桃。

田开疆说，我是三军统帅，打败了那么多敌军，谁的功劳可以和我相提并论？也拿了一个桃。

古冶子急了：“俺当年下乡杀了袭击国王的大鳖，救了国王一命，岸上的老百姓看着俺顶着巨鳖的出头来的时候，都以为是河神现身。这样的功劳不能吃俩吗？”说着拔出宝剑：“你们是不是该把桃子退出来？”

退什么退，都吃进肚子里了。

两人听了很惭愧，竟然拔剑自杀了。

古冶子没想到会是这样的结果，也拔剑自刎（ wèn）了。

这就是历史上著名的二桃杀三士的故事。

对这个历史故事古代文人有多种解读：

+   - 有称赞晏子智慧的；

+   - 有感叹三勇士知耻的；

+   - 有论诛杀功臣的。

在老潘看来，三勇士是掉进比较的陷阱，被人玩了。

以能力论，三人各有优势，并没有高下之分；以功劳论，杀猛虎和杀巨鳖其实没什么区别，开疆拓土更是不逊于救国王一命，也没什么高低之分，

关键是阴险的晏子就拿了两个桃，于是三个平时很仗义的哥们就此分裂，而知耻的优秀品质被利用，三个人就此丢了性命。

可见这比字真真正正是两把匕首，能要人命。
