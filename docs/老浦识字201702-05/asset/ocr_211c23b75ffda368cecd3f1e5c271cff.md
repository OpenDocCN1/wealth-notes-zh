# 望山川风物

望乡，望月，在望向远方时，还有怎样的情怀？

我们还是来欣赏一下草书的望字：

![](bbox=[0.32, 0.523, 0.63, 0.594])

草书的灵动之美让希望的望充满美感。

王国维在《人间词话》中，提出了人生的三个境界。

第一个境界他引用了晏殊的词：昨夜西风雕碧树。独上高楼，望尽天涯路。

说的是一个人在秋天万事萧疏，西风把树叶从树枝上横扫下来，在这种人生不如意的情沉下，独上高楼，望向天涯，也许茫然，也许伤怀，但仍然登高望远，对未来充满希望。

如果你连梦的敢做，怎会有希望呢？

而杜甫，在15岁登上泰山之巅的时候，就写下“会当凌绝顶，一览众山小”的语句。

你认真回忆一下，上一次用到“望”这个动作是什么时候？

想不起来吧，因为我们绝大多数时间沉浸在自己的世界里，我们平常用眼一般都是看手机，看电脑，看电视，看路，看衣服，看人，你看，很少很少用到望。

因为望一定是站到高处，暂时放眼下，舒展眼光望向远方。你这么登高一望，五百里满流奔来眼底，数千年往事注到心头。

我们通过汉字“望”，欣赏了超越文字的图画之美，幻想了古人望乡、望月和登高抒怀的激情，激励我们要勇于突破山寨对我们身心的限制，望向更远的未来。
