# 素帛很高贵

素的本意是生绸，准确地说是还没有染色的生丝。

中国是世界上最早应用桑蚕丝织丝绸的国家，男耕女织是中国农村的常态，所以关于纺织、丝绸的汉字就特别多。我们现在看到所有绞丝旁的汉字基本上都与纺织有关。素字下面的“糸”也是绞丝变形过来的。

《说文解字》：素，白织缯也。从糸，取于溻也。意思是说素是没有染色的本色丝绸。字形表示润泽下垂。

没有经过染色的素帛曾经是最昂贵的书写材料。

纸是东汉蔡伦时期发明的，在此之前，汉字刻在甲骨上，铸造在青铜上，书写在竹简上，也书写在蚕丝织就的素帛上。

“欲寄彩笺兼尺素，山长水阔知何处。”彩笺是信笺，古人把花的汁液融进信纸做成彩色信笺，叫彩笺。历史上最有名的是薛涛笺，成都的朋友应该熟悉。唐宋有用彩笺的，也有用素色的信笺和素色的丝帛写成长信，但是山高水远，你在哪里？这是北宋张珠的记，人生第一重境界引用的是出自同一首《蝶恋花》。我把这首词抄录在后面，感兴趣的朋友可以欣赏。在没有造纸术以前，信件只能用丝帛，非常贵重。

素帛传书，曾经有许多浪漫的故事。“客从远方来，遗我双鲤鱼。呼儿烹鲤鱼，中有尺素书。长跪读素书，书中竟何如？上言长相思，下言加餐饭。”这是汉朝的乐府诗，说渔子发现了丝帛写成的书信，竟然是亲人寄来，表达自己的相思。

最神的是苏武牧羊，鸿雁传书。据《汉书·苏武传》记载：说汉朝又派使节到匈奴，要求放苏武回去但单于仍不愿意放人，谎称苏武已死。汉朝使者一早和苏武联系上了，说汉朝皇帝打猎时，曾射到一只北方飞来的大雁，雁足上系着一封信，说苏武没病死，仍在北海牧羊。

单于只好放人。后来，人们便把传递信息的使者称为“鸿雁”，“鸿雁传书”一词也由此而来。

# 素成为中国文化审美的最高境界

这是篆文

![](bbox=[0.4, 0.00136, 0.65, 0.0014299999999999998])

，是秦代李斯规范的汉字，这个素取消了系绳旁边的双手，字形上下大小，有韵律感的曲线和椭圆形的“素”字构成了汉字特殊的美感。

素是未经染色的本色，而色彩曾经是绘画的生命。人类最早的岩画就是矿石上涂上去的红色，西方绘画对颜色的登峰造极是19世纪的印象派，他们把光影造成颜色瞬间的变化捕捉下来，成为视觉的盛宴。

中国颜色的顶峰是唐代，走进敦煌石窟就走进了颜色谱写的音乐，流动的音乐奏响大唐的盛世之音。唐三彩，那就是颜色的狂欢了。

当年老普到布达拉宫参观，对墙上的壁画色彩赞叹不已，人介绍说，这些颜料都是天然宝石研磨而成，蓝色是蓝宝石，红色是红宝石，黄色当然是黄金了。

但是素以山水，色彩便逐渐从中国绘画中消逝了，先是水墨山水，进而人物画也直黑变成白描。较之世界其他各民族的绘画，这大概是绝无仅有的现象，中国人放弃了色彩，选择了素。

他们说：墨分五色。

为什么中国美术选择了素色？

这大概是三方面的原因促成的：

+   1. 文人画的兴起，有惯了笔墨的文人兴之所至，用书法的笔法信手涂抹两下，烟云缥缈的山峦就呈现出来。

+   2. 北宋灭亡，南宋退居江南。江南的烟水迷离，给画家创造了天然的意境。

+   3. 最重要的，《老子》说：“五色令人目盲。”主张“致虚极，守静笃。”追求清静无为的境界，空灵的素色正是中国文人淡薄名利心境的体现，“，曲终人不见，江上数峰青。”
