# 一万小时成就一门技艺

在网上看到一个说法，说是外国人研究的，一个人只要孜孜不倦连续学习一万小时，就能成为任何一个领域的专家。有人算了一下，按每天学习3小时，一年300天计算，要苦读7年。每天2小时，就是10年。

十年寒窗，磨出一门手艺。

在古代市场，经常能够在古玩店的角落里发现堆着一些用过的老砚台，都是古玩商收藏的民间日用的普通砚台，石质一般，不大值钱。特点是个个砚台都磨出了深深的小坑。

那是多少个寒窗，磨掉了多少墨块，写亮了多少只毛笔，才能磨出这样的小坑。

手艺是磨出来的。

但是下苦工耕时间就能成大师吗？显然不行。那成就一个大师的关键在哪里呢？

还是从我们古老的汉字中寻找答案。

# 甲骨文的“艺”是一幅图画

艺，本义就是园艺、农艺。表示种植物、培土除草。

![](bbox=[0.25, 0.87, 0.75, 0.98])
