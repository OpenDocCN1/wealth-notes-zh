# 【安】关于房子的梦想

【安】关于房子的梦想

老禛提示：订阅专栏后，文稿中的象形文字可截图点，放大来看，细细品读。

有个段子：想搞工作的十几年，谁都没骗过我，就房产中介没骗过我，他们十九年来一直苦口婆心地骚扰我让我买房，说房价一定会涨，我没听。

如果上天给我一次机会重来，我一定不会挂你电话！

这个段子说出很多人都感受：房价2千的时候嫌贵没买，现在都2万了，还是二环以外的。

房子，是多少人可望不可即的梦想，正像另一个段子说的：如果你一个月挣1万，想在深圳买一套100平的房子，那么没关系，可以先定个能实现的小目标。

——比方说先买个500年。

真是安居才能乐业啊。

在甲骨文那个年代，安居同样是美好的梦想。安居的安，就是这样造的字。

# 安居是美好的梦想

安在甲骨文是一个房子里加一个安坐的女人。

![](bbox=[0.18, 0.58, 0.4, 0.62])

坐就是安呢？

在商代，部族之间的战争非常频繁，在殷的周边，有狄（dí）、羌（qiāng）、荆楚等部族，打仗是家常便饭，而在战争中如果被俘虏，就会沦为奴隶。

我们以前讲过的“怒”中就涉及到奴隶的奴，

![](bbox=[0.2, 0.73, 0.45, 0.77])

就是只手抓住一个女人，这人才沦为奴隶了。

这是妾，女人头顶上有一把刑刀，这是女奴。

![](bbox=[0.25, 0.83, 0.45, 0.87])

这是奚，是只抓手指的奴隶，有个被绑缚的人，这就是战俘了。

![](bbox=[0.2, 0.91, 0.4, 0.95])

这是及，一只从后面抓一个人，这是追捕逃跑的奴隶。

![](bbox=[0.2, 0.99, 0.45, 0.00103])

这是因，被抓住以后就是这悲惨的下场。

![](bbox=[0.25, 0.00107, 0.5, 0.00111])

所以，女人能在屋里坐着，是多么安宁的场面。这样的安居实在是太来之不易。

![](bbox=[0.05, 0.001155, 0.85, 0.00123])

那时候北方的民居是半地穴式的，要先在地上挖个坑，然后在上面搭个房子，中间用一根柱子顶上。汉字“宋”就是表现这种房屋的。

# 安居不易，安稳为先

![](bbox=[0.1, 0.001395, 0.45, 0.00145])

这是秦代李斯的字体

来自《诅（jǔ）石颂》，原石已经毁了，这是后人仿写的。李斯的字，笔画粗细均匀，结构四平八稳，显示着秦代在严刑峻法之下规整森严的社会特征。

李斯、商鞅是将秦国由一个边塞野蛮的二流国家变为一个强大的虎狼之国的关键人物。

商鞅变法，把整个秦国变成一个大军营，他首先推行户籍管理，实行什伍连坐，五家为伍，十家为什，要他们相互监视，纠举“奸人”，隐瞒不报者连坐。

告奸者与斩敌者同赏，匿奸者与降敌者同罚，不告奸者腰斩。

这样的居住制度，不仅谈不上安居，还让人自危，开启了民间告密制度的恶劣先例，这样的保甲制度我们在电影《抓壮丁》里还可以看到。

![](bbox=[0.15, 0.00173, 0.8, 0.00185])

商鞅变法和李斯主张焚书坑儒，作为法家人物一度受到推崇，认为他们的铁腕帮助秦国完成了统一大业，在这样的历史大潮之下，个人的福祉（zhǐ）不值一谈。

老嘴认为好的制度首先应该是让老百姓安居乐业的，什伍连坐这样反人性的制度，焚书坑儒这样反文明的逆行，注定会反噬制度制定者本身。

商鞅发现新王要收拾自己，赶紧逃命，但他自己制定的什伍连坐制度让他根本找不到敢收留他的民家或旅店，最终被逮住，惨遭车裂。

李斯则遭到赵高诬陷谋反，惨遭腰斩，成为专制制度的殉葬者。
