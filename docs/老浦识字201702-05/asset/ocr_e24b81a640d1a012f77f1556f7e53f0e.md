# ## 义字里面有一个大大的我字

在简化字之前，义字下面都有一个大大的我字。

《说文解字》说：

> 义，己之威仪也。从我羊。

说：

义字是自己的威仪。

就是我的威仪。

说明义字是自我的，即使是奉献，也是完成自我。

所有讲义气的人都是超级自恋的人。

关公放曹操就是因为自恋，自恋到不愿顾大局，甚至不顾性命。

义士楚飞也是珍珠羽白不愿乘人之危，本质也是自恋。

例子还有很多。听说马超骁勇，要回蜀地去比武。看不起黄忠拒绝接受五虎上将军衔。更要命的是，一句“虎女怎配犬子”侮辱孙权，破坏了联吴抗曹的大政方针，导致叛变被袭，最终败走麦城。

毛泽东说：关云长大体上是不懂统一战线，这个人并不高明，对待同盟军搞关门主义，不讲政策。

《三国志》的作者陈寿说：

> 羽刚而自矜。

说：

关羽刚直而自傲。

这是他失败的根本原因。

义固然令人敬佩，但核心还是自我之境。
