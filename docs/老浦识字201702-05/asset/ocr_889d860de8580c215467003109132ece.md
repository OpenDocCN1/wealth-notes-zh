为什么长头发代表老人呢？因为古代成年的男人是束发的，而到了老年，头发稀疏，就被散开来，意味着老人已经不必束缚自己了。

《说文解字》说：考，老也。考就是老，两个字通，都是指老年人的意思。

考和老后来发展出不同的含义。老表示老年，考表示去世的死。《礼记·曲礼》说：生曰父、死曰考。那么古时的母亲呢？叫妣。有些墓碑上会刻 '先考 '、'先妣 '，就是用的这个含义。

有学者认为，考字下面的木棍也许有更深含义，那就是远古时期的风俗——棒杀老人。

广西桂林一处7000年前的古人类遗址，发现了14具头骨，其中4具头骨发现有明显的钝器打击伤痕，表明是被人打死的。经鉴定，年龄都在50岁以上，而其他年轻人的头骨则没有这种现象。

在石器时代，大多数人都死于二十多岁，50绝对是长寿者。他们为什么会被打死呢？

学者研究这与远古的生死观念有关。在远古看来，死是重生的机会，灵魂会转世回来新生。所以当老人疾病缠扰的时候，老人乐于赴死，只是担心死的方法不对。

那什么样的死亡是对的？要流血。也许是古人看到流人血后会晕厥，认为血液是灵魂寄存的所在，所以死的时候要没有流血，灵魂就难以成，不吉。

这也许是棒杀老人的原因吧。

这种对血的崇拜一直影响到后世的丧葬制度，人们在死者身上撒上面砂，棺椁内壁涂成红色代表血。

这表现了对待老人另一个可怕的习俗——抛弃于荒野。

同样出于灵魂再生的理念，古人认为人的身体被野兽啃食吃掉会转世再生，同时大概出于生产力低下，老人成为儿孙的陷阱，所以自愿让儿子将自己抛弃到荒野岭，生自弃。而被野兽吃剩了的骨头，家属再收回来埋葬。

战国初期的《墨子·节葬》说：

> 楚之南有炎人国者，其亲戚死，斩其头而弃之，然后埋其骨，乃成为孝子。

说：

> 楚国南部的炎人将死者抛弃，任其腐朽，然后把骨头埋回来，这是孝子的行为。

但是汉代的一个故事表明人们观念的变化。一个叫原谷的人相帮父亲，把祖父抬回弃于荒野。原谷去干嘛？他回答说：以父母把他带回来是。他父亲在醒悟原谷，然后自己把父亲去掉了，于是回去老态龙飞回来养谷，原谷因此获得孝孙的好名声。这个故事一方面说明抛弃老人习俗的存在，另一方面也反应了人们思想观念的改变。

其实西藏的天葬，也是这种观念的延续。天葬师会仔细地将骨头敲碎，拌上糌(zān ) 耙喂给老虎秃鹰。我们认为自己的观念觉得难以接受，但他们认为，尸体被禽鸟吃得越干净，亲人转世就越吉利。
