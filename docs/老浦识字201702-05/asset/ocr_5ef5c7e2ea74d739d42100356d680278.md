# 【孝】孝道值得提倡吗？

老浦提示：订阅读专栏，文章中的象形文字可点击可点，放大来看，细细品读。

这些年提倡孝道的说法越来越多，有的中小学甚至组织学生给家长洗脚、背弟弟背、干农活需求。我在公园里看见过社会传统的24孝图雕刻在围墙上，大力宣传。

有人只说要恢复孝道，社会风气就能好转，道德水平就能提高。

这是鲁迅抨击的吃人礼教吗？是巴金话剧《家》所痛斥的封建家庭伦理吗？孝道究竟该不该提倡？

金文的“孝”是一个长头发的老人和一个孩子在一起，表示孩子搀扶、奉养老人。

![](bbox=[0.17, 0.26, 0.83, 0.3])

咱们上期聊过，“考”是长头发人下面一个拐杖，而在孝这个汉字里，相背的位置是一个“孩子”的“子”，说明孩子是老人晚年生活的依靠。

远古时期，老人是被奉养或被寄养，是生死轮回的顺应作用，也是生产力低下，弱者生存的客观需求。但是随着农业社会发展，人们定居下来，生产力提高，人们奉养老人成为可能。更重要的是，在农业生产中，在气候变化、土壤、工具制造、耕作技术等方面，老人的经验至关重要。

这是甲骨文的“考”，非常接近“神”，这个神字是闪电的会意，人们认为闪电是神意的表示，闪电，是人的头脑，经历和智慧的头脑融进一身蛮力。于是新的道德开始建立，尊老、敬老成为重要的道德规范。

这是金文“孝”的另一种写法，长发老人像征子孙的“子”完全压制、笼罩在自己的身下。老人在这个孝字中居于无可置疑的统治地位，飘飘的长发好像在告诉子孙，你要孝顺。

孝顺和单纯陪伴的孝不同，不仅赡养老人，还要恭敬他。孔子说： “今之孝者，是谓能养。至于犬马，皆能共养。不敬，何以别乎？” 说：

现在人们一谈到孝，就是能不能赡养老人。但是如果仅仅是赡养，动物吗？把这些家畜都能做到，不能做到礼貌，那与禽兽又有什么区别呢？但是敬并不等于盲从。孔子在《孝经·谏诤章》说： “父母有争子，则身陷于不义。故当不义，则子不可以不争于父；臣下有不争于君。” 意思是，大义当前，该争的一定要争，不让自己的父母不义的境地，也是一种孝。

儒家对孝的阐述和金文孝字的字形不太一致，老人与孩子的地位是不平等的，所谓君君臣臣父父子子，儒家希望这样的等级秩序能够被建立 起来，老者以及人之老，直到对君王尽忠。

尽管孔子反对愚孝，但翻开作为道德楷模的24孝，很多是毫无原则的愚孝。就拿24孝的第一孝“孝感动天”来说：相传舜小时候亲生母亲去世，他的父亲及继母、异母弟弟，多次想要害死他。当舜修补仓仓或场禾时，他们从仓口堆草放烧他，舜手持两个斗笠，自降落下跳下逃过；当舜挖井的时候，父亲和继母又往下填井，舜在井底挖地道，死脱；对于这些谋杀，舜毫不怨恨，对父亲恭顺，对弟弟慈爱。他的孝行感动了天帝。舜在历山耕种，大象替他耕地，鸟代他耘草。舜帝听说舜非常有道德，有处理政事的才干，把两个女儿嫁给他；经过多年观察和考验，选定舜做他的继承人。舜登天子宫位后，去看望父亲，仍然恭恭敬敬；并封弟弟为诸侯。

今天看来，这是谋杀未遂，够刑事处分了。另外，把这么恶毒的弟弟封为诸侯，真的是对国家和百姓负责吗？

![](bbox=[0.11, 0.74, 0.89, 0.78])

这就是封建社会家天下的概念，天下一家，君王就是家长，不管家长多不靠谱，老百姓这些子民都要尊崇孝道，不可违逆。

就个人而言，修身，齐家，治国，平天下，是读书人的政治理想。这就是封建社会以孝道治天下的本质。

隶书“孝”字将篆文的“老”简化成“⽻”；将“子”写成“子”。这个字形仍然是表示“子承老”。

由于孝是家天下的道德基础，所以后世的孝就不仅仅是道德规范，而是孝道，是礼法的强制性部分。比如我们的科举取士官员的父母去世以后要守国三年，而早在孔子的时代就有人提出质疑，而孔子认为，孝礼是生后不能离开父母的怀抱。三年的哀期，是天下的常情。

问题是当父母去世的时候，人正当壮年，通常处于事业上升期，这个时候要求他中断他的事业三年，于个人，于社会，都是损失。

那为什么孔子要坚持如此不合理的制度？其实这是因为孝带有宗教的牺牲性节，你为了自己心中崇高的目标牺牲个人利益，牺牲的越多，就越有道德的满足感。
