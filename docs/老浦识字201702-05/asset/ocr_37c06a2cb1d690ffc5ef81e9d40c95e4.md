# 设想不可设想的事

《对华之战》（War with China)出自兰德公司之手。

兰德是家了不起的智库，在中国人心中更有神话流传。比如朝鲜战争爆发后，美国参战前，据说兰德公司出了份只有一行字的报告：中国必应出兵。

这个故事当然是假的。因为兰德公司不是算命先生，不会给你一个结论，出个“为什么”，说什么不可深潜。兰德报告啊，得有调查分析对策，就以这篇《对华之战》为例，前后一百多页，光资料目录就几十页。

类似的兰德神话诸多，但兰德不需要这些，因为真实故事更神奇。

兰德的英文名称是RAND，缩写展开是Research And Development，即研究和发展。作为现代智库之母，兰德这个名字塑造了当今全世界各类研究机构的国家级甚至影响到中国政府下属的国务院发展研究中心，发展研究所，development & research，其实就是德兰呐。

兰德几十年来名声显赫，在美国军事、外交决策中享有独特地位。比如，是个研究机构有专门页出具成果获得的学术荣誉，但兰德这一页面令人震惊，光诺奖得主就有3个，横跨经济学奖、物理学奖、化学奖还有和平奖。而且，与许多机构的诺奖得主是功臣在此获奖是若干年后的成果。诺贝尔经济学奖得主威廉·夏普（William Sharpe）说：“想像既有美感又有用处的研究，兰德是一个好地方。”

比如刚刚去世的托马斯·谢林，在这里作博弈论研究，直接服务于美国冷战策略：怎样威慑才可信？充分沟通能不能使美苏两大阵营至少保持相互谅解？怎样才能有效地劝告敌国，但为了信号？结果不但拿到了诺贝尔经济学奖。我在本专栏文章《新年许愿的正确姿势》里说到，许愿之我与执行必许愿望，直接出自我的文章。

兰德原属美国空军和一些大防务公司创的智库，发端于研究核战争的可能及策略，使命即是 think about the unthinkable，设想不可设想。当然，兰德是博弈论研究使用的重镇。谢除外，博弈论的创始人冯·诺伊曼在这里做过研究，听说法纳的创始人也来都听说过纳什均衡，纳什在这里呆了4年。除这几位外，拿过诺奖的博弈论大家还有曼恩、夏普利、维克里斯、威廉姆森。

可想而知，博弈论思维贯穿了《对华之战》报告。第一作者查尔·康伯特（David Compt）曾任美国国家安全事务副总监，曾打理过总监一职，绝对的内部人。《对华之战》标题抓人，但并非主对对华为战。中美关系复杂，除非真是一份报告能说得清？所以它只取一瓢饮：如果中美开战，故事可能会怎样展开？怎样避免开战？

比如，没去估计开战的概率有多大，这种预测难分开好的。别预测，做准备。它并不认为中美开战不可预测，也不认为可能性很高，但认为哪有可能性极低也须直面，因为后果太不可估量。报告副题为 Think Through the Unthinkable，与兰德的使命陈述仅一字之差，显示了作者上承兰德研究传统的自我期许。设想不可设想的事，这是分析师的使命。

报告基于一个假设，如果中美开战，战事主要在东亚地区，包括海上、海底、空中、太空；除网络战以外，总体是地区性和常规性战争，中国不会攻击美国本土。

这些假设是否成立其实很难讲，但分析总要从什么地方去开，这组假设就是报告的起点。如果把假设改成全面战争和核战争，那是真正不可想象之事，让我们还是先不想它吧。

基于以上假设，如果战事于近期爆发，又是什么结果？如果战事远期爆发，又是什么结果？这是时间维度；另一个维度是激烈程度和战事长度。三维度组合出八种可能情形：

+   - 近期，激烈，短促
- 近期，激烈，漫长
- 近期，温和，短促
- 近期，温和，漫长
- 远期，激烈，短促
- 远期，激烈，漫长
- 远期，温和，短促
- 远期，温和，漫长

不一一细讲了，基本判断如下：

+   - 第一，中美战事不会有决定性后果，没有清楚的胜者，不会有哪方获得绝对胜利而另一方遭遇完败。
- 第二，如果战事于近期爆发，美国军力会实质性受损，少于远期爆发，损失更大上很多，因为中国军力在迅速成长；但无论近期远期，中国军力损失更大。
- 第三，战争激烈与否取决于领导人战争开始时所决心，战事长度取决于双方何时丧失继续作战的意志。
- 第四，东亚海空成为战区，不论在哪种情形中，中国经济都将遭受重创，战事变得漫长更有实质性后果；美国经济损失也会冲击，但相对小，主要因双边贸易损失；此外，如果战事变得漫长，国际形势对中国会进一步恶化。
- 第五，战事爆发最可能的原因是一方误判，为可以通过一场短促战争达到目的，以前冷战换境策略就出现这种误判，以战备态势决持续几个星期，结果是持续4年，一代精英丧生，当时的世界中心地都焦土化。为防止这种误判，报告认为必须向对方清楚地表明自己已做好长期激烈战备。
- 以激烈的长期战争的后果作威慑，杜绝另一方通过短促胜负获取的幻想，使战争爆发时可能性最小化，要打长期打到，所以最好的不可设想的是兰德报告的逻辑内核。如何使长期激战的威慑变得可信？政策建议由此而来，兰德建议美国应适度整军，加强其盟友的军事能力和准备程度，在经济层面对好产业链被战争扰乱的后果等等。
- 不过，如果这些动作来临，必然会计传出另一种信号：美国封锁中国。而它会会增加还是降低冲突的可能？兰德报告对此没有多讲。已知她都能减少到零，但然而何其难！这世界上没有完全透明的信号、单一后果的行动，是意外之轮转动的，往往是意外（ unintended consequences）。
