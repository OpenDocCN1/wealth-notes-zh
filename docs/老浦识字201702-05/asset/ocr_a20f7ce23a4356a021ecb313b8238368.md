# 望要登到高处

在上一期《老编识字》中，我们探讨了限制的“限”，感语词只有走出囚禁你身心的山崖，才能欣赏山峰顶上的风光。登上山顶，我们会用到哪一个汉字呢？没错，是“望”。

看看看甲骨文的“望”，居然就是一个古人站到了山崖上。

![](bbox=[0.2, 0.33, 0.4, 0.38])

甲骨文的“望”是一个直立的人形，站在一个圆圈上方，那是甲骨文的“土”字，在这里表示站在高处。身体的头部简化成了一个大大的“臣”字，这个字的原意是竖起来的眼睛。在这里表示登高，是为了用眼睛看，看哪里？当然是远方。远方是什么？是诗。

> 《说文解字》说：“望，出亡在外，望其也也。”

说“望”是亲人远行在外，盼望回家。

# 望乡

三千年前，每个月年轻的人被征发往边塞或远离本乡的边疆。超负荷的劳动让他身心俱疲，已经有不少伙伴被累死了，此刻这个年轻人更加思念家乡。夜已经很深了，他悄悄爬上附近的小山，向家乡遥望。

> 陟(zhì) (彼 bǐ) 彼，瞻望夫。妇：难！男子行役，夙夜无已。上惧伤(zhí nǐ) 我！犹来无已。(《登高思夫山》阿，远远的我多要遥望。耳边回想起老爹的诩语：唉，我的儿啊，你每天从早到晚地劳作。可爱当自身休啊，千万不要把自己留在远方。)

后面相同的句式，还有思念母亲、兄弟的语句。

这是《诗经》中征人遥望故乡，思念亲人的诗句。

![](bbox=[0.2, 0.75, 0.8, 0.82])

从明代就有民谣，孟姜女哭倒长城。她老公服的兵役伐。花木莲替父从军，她代父亲服的兵役。

> “昨夜见军帖，可汗大点兵。军书十二卷，卷卷有爷名。阿爷无大儿，木兰无长兄。愿为市鞍马，从此替爷征。”

不光出力，盔甲鞍马都是自己出。

沉重的征伐，沉重的词语。有多少离散的亲人在登高远望。

在全国各地，有不少景点叫“望夫石”，这些民间传说大同小异，都是说留守的妇人登高远望，伫立望夫，天长日久化而为石。

> 据古书说：“武昌北山有妻夫石，状若人立。古注云：昔有贞妇，其夫从役，远赴国难，携弱子独赴北山，立望夫而化为立石。”

辽宁省兴城市西南望夫山的望夫石，传为孟姜女望夫之所。

宁夏回族自治区隆德县西南、江西省分宜县尖山峡水口、贵州省贵阳市北谷顶关（ju）、广东省清远市，这些地方都有望夫石。

你的家乡也有望夫石吗？

# 望月

古人登高远望，除了望远，还望什么呢？当然是望月。大家可以到文本里去查看。

![](bbox=[0.3, 0.00113, 0.7, 0.0011799999999999998])

“文”“望”字的写法，已超越纯文字，完全是一幅画面。几乎每古人都问：“汉字真的有这么写的？”

![](bbox=[0.2, 0.00123, 0.8, 0.00135])

真的加上了这样一笔弯月。现在还有谁会怀疑，汉字就是一幅意境深远的画面，就是一首诗啊。

> 床前看月光，疑是地上霜。举头望明月，低头思故乡。

李白这首诗，简直就是金玉“望”字的诗歌诠释版。

说到这首诗，自然想到马未都老师提到的“床，乃胡床之床的公案。马未都指出，李白《静夜思》之床不应该是我们现在的床，是胡床。也是我们今天的马扎子，人自然是在室外，举头望月，而华亭不夜，自然月光能照徘徊。其实在马未都之前，学界对这个床的就有不同的解释，除了摇床、马扎以外，还有一种井床说。井床就是水井周围置栏杆并台。“井”在人们当时的生活中占有非常重要的位置。人们围绕着井相聚，逐渐形成市场，这就是市井。离家乡游称“背井离乡”，而在“井床”前思念故乡，不是很自然的吗？

从汉字角度考察，老端是赞同马未都老师的。望是登到高处，在屋里自然没法望，井床也不是高处。

别刚，读诗的时候你是不是有一点别扭？说明这里引用的不是日本版的《静夜思》，而不是这是第一句留作“看”月亮，也不是“明”月，第三句举头望山月，而不是“明”月光。

难道说千里之外的日本保存的版本反而比我们本土的版本还要准确吗？

翻翻古书，其实这个版本可不仅仅在日本才有。宋代的《李白文集》、《乐府诗集》，明代初年的《唐诗品汇》，以及清康熙皇帝钦定的权威本《全唐诗》中，《静夜思》的原文都同日本版的一样。
