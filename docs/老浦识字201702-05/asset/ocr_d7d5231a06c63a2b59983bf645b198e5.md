# 【善】怎样辨别伪善

老编提示：订阅读专栏后，文稿中的象形文字可能有点小，放大来看，细细品读。

在我们这个时代，善⒈既稀缺又泛滥。

说稀缺，老人跌倒没人扶，小孩被车碾轧没人管。

说泛滥，王宝强一篇微博离婚就引发千万人同时讨论，一篇感人的网络文章就能吸引百万捐款。

陈光标高调慈善，宣传无所不用其极。清华大学获赠资助穷人1500万，去世四年才为众人所知。

到底是什么才是真的善？

# 善是无条件的牺牲

我们来看甲骨文。

甲骨文的善字有⒈种写法

![](bbox=[0.05, 0.62, 0.95, 0.7])

弯弓的羊角，大大的眼睛，其实就是一个羊头的造形。以上表示作为祭品。羊代表善道。之所以突出表示眼睛，大概是因为羊眼睛透露出的纯净、安详，让人感到善良地。

在汉字中，和羊有关的字通常与祭祀、和平，吉祥有关，如吉祥的祥，美好的羔，羞涩的羣等等。

圣经《旧约》有一个故事：有个叫亚伯拉罕的闪族人，他99岁得了个儿子。一天，耶和华突然降临，要他杀掉自己的儿子以撒献祭上帝。亚伯拉罕忍住悲痛，将儿子放在祭坛欲动刀时，天使飞来拦住了他的手，告诉他这只是耶和华的考验，他可以改用山羊作为祭品。

![](bbox=[0.05, 0.96, 0.6, 0.00108])

羊是古代祭祀中必不可少的主要的祭品。羊除了用作献祭上帝的牺牲，还承担了一项任务，那就是给人类“替罪”。这就是替罪羊的来历。

所以迭字首的寓意就是无条件的牺牲。无奈到了洋子们都跟着干。

清华大学教授赵家和一生清贫，把一生所有积蓄1500万全部捐出来资助贫困学生，最后还捐赠了自己的遗体。并且隐藏了自己的姓名，去世四年后，他的事迹才被披露。

对比一下，陈光标的高调宣传就有些让人不舒服。

他在演讲中回应，自己希望通过宣传，影响更多人做好事，做好事应该不说。一次宣传、一次传播会影响更多人，相当于做更多好事和善事。

其实这件事的是非，看看陈光标的名片就一目了然了。

“中国慈善十、元、玉奖全国抗洪救灾英雄模范”等笔11个荣誉头衔。

不敢说他的慈善有什么功利目的，利用慈善名誉确实很爱出风头。

利用慈善达到个人⒈目的伪善。

# 善是平等的交流

我们再来看看金文善字的写法

![](bbox=[0.2, 0.0018700000000000001, 0.8, 0.0019399999999999999])

上面是一个羊

![](bbox=[0.2, 0.00199, 0.8, 0.0020499999999999997])

代表吉祥，下面两个

![](bbox=[0.2, 0.0021000000000000003, 0.8, 0.00215])

言语的言 并行排列，这两个“言”，表示言语祥和亲切，平等交流。

平等，而不是居高临下的施舍，是善重要的组成。

生活中我们经常帮助志愿者，你献诚恳地去帮助别人，但受到帮助的人似乎并不领这份情。

比如资助贫困地区的学牲，你若物资去，他们就嫌弃你，说我不要救，有人会说你恨不得东⒈西⒈来打打，千人就买贵，木村买贵。

还有的人定资向贫困学生，受助者毕业以后再也不想和捐款人往来，并且刻意隐瞒自己受助过的经历。

为什么这样？

有一个现实版本的故事，说是日本一个寿司店的老版发现，自己销售的最贵的金枪鱼，大部分来自海商缴打的索马里。

2012年，木村向索马里政府提交了渔业援助⒈问支援申请，向索马里民众传授捕鱼技术，冷冻仓使用技术，建立起“当地捕鱼，本村买贵”的模式。

有人说这是寿司店老板打散了他索马里海盗。

![](bbox=[0.05, 0.00277, 0.6, 0.0028799999999999997])

尽管这样的说法并不夸张，索马里海盗的消失主要得益于国际联合打击的结果，但正如中国的古语，授人以鱼不如授人以渔。民众的生计有了保障，海盗问题就不会死灰复燃。

而那些受到恩惠却不懂得感恩的人，是因为没有建立起自己健康的人格，心理上总显得自卑。

所以真正的善是祥和的羊，是两个“言”字并排的平等交流。

居高临下是伪善。

# 善是完善自我

我们现在来看篆字的善

![](bbox=[0.4, 0.00327, 0.6, 0.0034])

仍是一个羊字，两个言语的言字，延续了金文字形。《说文解字》对这个字形是这样解释的：

善，吉也。此与义美同意。

意思是：善 = 吉义
