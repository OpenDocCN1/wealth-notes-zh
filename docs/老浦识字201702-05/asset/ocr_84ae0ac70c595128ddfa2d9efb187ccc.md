有人说是祭祀。日本汉学家白川静认为这些动物不是养在屋下，而是埋在地下。但是猪

不是猪，而是狗

“家乃祭祀先祖的神圣建筑物，即祖庙。此类建筑物开工之前，要先埋入牺牲，以免土地神发怒，此谓‘镇地祭’。古人的住房围绕祖庙搭建，家逐渐演变为住宅、家园之意。”

白川静之所以认为家这个字形伞盖下面是狗而不是猪，是因为根据考古发现，大型宗庙建筑的确要用犬祭祀，不仅犬，殷墟遗址发现，还有牛羊，更有人，但还真没有猪。

可这个字形明明是猪的象形，不是犬啊。

而且，怎么解释这是一头公猪呢？

有人这样解释，说周系氏族社会实行族外婚，外族来的男子只在女家过一宿就离开，生下来的孩子由母亲和舅舅抚养，云南纳西族的走婚还保留着这样的风俗。

原始部落家养的母猪常常遇到外面野猪的性使，外族一头猪，于是先民把这种现象与走婚联系起来，创造了房子下面一头公猪的“家”字。

学者们研究最大的问题是脱离实际。野猪光顾人猪圈里，属于偶发事件，不可能成为一种常态，否则留着被拱坏的缺口，家里的猪还不都跑光了。

究竟这个“家”字是怎么造出来的？

# ### 家是定居的象征

猪和狗是人类最早驯养的动物。石器时代，采集和游猎居无定所，农业使人有可能定居下来。定居，是人类伟大的进化，也是当时人们优越感的源头。定居代表进步，文明。

猪是杂食动物，什么都能吃，也不需要专门放牧，猪圈都挨着人的住宅，所以养猪意味着定居。

想象一下，当疲惫的男人狩猎、农耕回来，远远望见猪槽旁的自家房屋，家，这个温暖的汉字就诞生了。
