# # 【牛】为什么这么牛？

【牛】为什么这么牛？

老编辑说：文章专栏内，文章中关于文字的字形字义，可以放大来着，细细品读。

十二生肖之二是丑牛，不是说牛很丑，是说古24小时分为12个时辰，其中牛时是第1个时辰是子时，晚上11点到凌晨1点，丑时是第二个时辰，凌晨1点到3点。

牛有4个胃室，牛是吃草的，休息的时候就会休息两个小时，可以反刍在胃里的食物反刍到嘴里再嚼一遍，这种情况就被称为反刍现象。牛是休息的时间，也是牛反刍的时间。这大概是在十二生肖中牛排第二的原因吧。

牛体型庞大，力大无比，但性情温顺，任劳任怨，吃得是草，奉献的是奶，历来受到人们的喜爱。但问题是，这样温顺的动物，我们在日常口语中，常说某人很“牛”，“牛”是什么意思？

我们通过解析字形，看能不能解答这个问题。

# ## 牛是神宝之物

金文，承续甲骨文的字形，规整圆润，像摆在祭坛上的牺牲。

牺牲这个词，我们今天通顺做动词，“某某为国牺牲”，指的是为了信仰舍弃生命。但在古代，牺牲是名词，指祭祀用的贡品。

牛在古代中国人的心目中是具有灵性的动物，可以崇拜，所以，在重大的祭祀仪式上一般都选用牛。

所以“牺牲”都是牛字旁。具体来说，杀牛为“牺”，牛头为“胙”，牛色纯白的牛，是只有天子才能使用的最高等级的祭品。

> > 《礼记·曲礼下》记载：
> “凡祭……天子以牺牛，诸侯以肥牛，大夫以索牛，士以羊、豕。”

“牺牲”是指整只的牛，“肥牛”即宰长肥壮的牛，“索牛”意思是经过筛选挑选出来的牛。

被选定为祭品的牛要受到特别的待遇。《史记·老庄申韩列传》云：“祭祀之用养牛之道养，衣以文绣。”

选用祭祀的牛还要受到人们的尊重，就连国君见到牲牛也要表示敬意。

牛在农村社会至为重要。为了保护耕牛：
西周就有“诸毋无故不杀牛”的规定；
在汉朝，杀牛要连性命；
在唐朝，牛主人自愿杀牛，判徒刑一年；
在元朝则杖责一百；

在宋和明时期，不管这头牛老得老得老得不能动了，还是意外倒地了，都是不能杀的，除非牛自然死亡。

《水浒传》里描写好汉动不动就二斤牛肉下酒的描写，实际是不存在的。那时候谁能吃得起牛肉啊。

今天印度神牛的待遇大概和中国古代有过之无不及。印度神牛不仅可以在大街上随便散步，还是受保护对象，到人家客厅溜达。这是宗教信仰使然，同时也反映社会对牛的尊重的反映。

牛吧。

# ## 牛是宙斯撩妹的神器

隶书“牛”将篆文的一对尖角写成，使得字形完全失去动物形象。在中国古代传说中，地上的一物都是神牛下凡做成的，所以“物”是牛字旁。

![](bbox=[0.08, 0.0012549999999999998, 0.92, 0.00127])

在希腊罗马神话里，宙斯就特别喜欢把自己变成一只外表俊美、性格温顺的大公牛，到世界各地找人类，和美人儿交配。

传说有一次宙斯看中了某一个美女，就变作一头公牛引来她。美女们喜欢这只美丽的公牛，她们纷纷抚摸它，毫无防备地给公牛戴上花环，抚摸着牛背。
