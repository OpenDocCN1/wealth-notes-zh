# 【慈行】慈母的心灵感应

老编提示：订阅本栏后，文稿中的象形文字可能显示不全，放大来看，细细品读。

这间周日是母亲节，今天的「慈」字，就送给自己每一位母亲，节日：快乐！

> 慈母手中线，游子身上衣。
临行密密缝，意恐迟迟归。
谁言寸草心，报得三春晖。

这是唐朝诗人孟郊的《游子吟》，我们小时候都背过。每当读起这首诗，老妈妈在灯下一针针一线线缝补寒衣的温暖情景就会浮现在眼前。

说到母爱，这大概是最经典的场景了吧。

今天我们学习汉字，惊奇地发现，原来慈母的爱真的是这缕缕线，联系着母亲和子女的牵挂。

「慈母金文的上部是两个并排的幺，幺是表示桑蚕丝线的象形。幺丝很细，但韧性很强。两个幺表示缠绕在一起，是表示织成丝成缆。这一丝缠绕的丝就表示织成，加上心合在一起，表示母亲牵挂儿女的慈爱。

《说文解字》说：慈，爱也。爱就是爱。

24孝里的故事不多长，但有两个关于母亲的故事却相当合理。

![](bbox=[0.15, 0.65, 0.85, 0.72])

这是24孝中的一个故事《董永卖身葬父》，说的是一个叫董永的农民，由于没钱埋葬父亲，就把自己的女儿给买了，当工还清，有一天，董永在大树下遇见一个美女，美女说自己丈夫死了，现在无家可归，愿意嫁给他相依为命。董永去请问财主，财主答应了，并说如果要100天内能够织出100匹细绵，就可以为自己赎身。美女日夜不停地织布，终于在100天内织出了100匹细绵，成功为董永赎身。

下面就是「夫妻双双把家还」的场景了，没错，这《天仙配》就是根据这个故事改编的，原故事的结果令人追爱，董永承认真了七仙女，下界帮助董永说的是孝行感动了上天，派他帮助董永的，说完自己上天了。所以故事发生的地方才改名作孝感。你跟我来我家呀，我挑水你浇园的日子幸福并没有实现。

这个故事的孝道我们先不谈，单仙女织布，其实反映了农业社会妇女劳动的辛苦。

这样的劳动，像丝线般的蚕丝，平凡得几乎令人看不见，但却绵延不绝没有尽头。

20年前我曾经到陕西农村拍摄农家生活，我们的摄影机4点多起来就上路在院子里等了许多人，最后起来的是媳妇儿，开始起火做饭。第一个起床的是老头太，老头太先去给家里喂的鸡、猪、牛等喂食，拿到门口的地上去。敬奉完，拿起扫把扫房，从上扫到下。然后打扫完房间。这就时，一家人就陆陆续来，劳动的一天空了。

在农村，几乎所有的日用品都是自己解决的，线自己纺，布自己织，农衣自己缝，花自己做一件洗洗洗，洗衣、喂猪喂羊喂驴，农忙的时候和男人一样下田、打场，当然，还有更重要的活儿，带孩子。

我生活中，年代，但几个孙子孙辈，衣服线织补是补不了的了。而家里每个人身上厚实的毛衣，都是母亲一针一线织出来的。

慈爱，就在这一针一线的辛劳当中。

「慈篆文的字上部积丝成缕的「益」，更加清晰规整，而兹由丝线渐渐聚集成缕，引申出草木生生渐多的意思。可真真是「谁言寸草心，报得三春晖」。

24孝里另一个和母亲有关的故事是「恝痛」和「尝药」的故事，讲的是儿子给母亲看病的。

![](bbox=[0.15, 0.00138, 0.85, 0.00145])

孔子的学生曾参侍奉母亲极其孝顺。曾参入山打柴，家里来了客人，母亲不知所措，曾参砍柴送回家中，牵着曾参说：「有客忽然到来，我脱手挡我知道。

这就是我们常说的心灵感应吧。六行千里还相依，儿行千里，那一根长长的丝线是不剪不断的。

最近在朋友圈里看到了一个新知：「量子纠缠」，说两个或者多个粒子在同一个状态纠缠，相互纠缠，相互影响，在空间上可能分割很远。当其中一粒被探测发生变化，另一粒也会即刻发生8倍。爱因斯坦称量子纠缠为「鬼魅般的远距离作用」。

这个实验为母子心灵感应找到了科学依据。

我想，慈这个汉字中的丝线，就是量子纠缠中那一粒粒的爱心能量吧。母亲的关爱，就这样纠缠着你，无论走多远，无论如何回到故乡多，甚至阳隔两隅，都让这慈爱继续缠绕着你。

这是人间最美好的纠缠，最长不断的线。
