# 【礼】礼尚往来

老浦提示：订阅专栏后，文稿中的象形文字可戳可点，放大来看，细细品读。

“滚滚长江东逝水，浪花淘尽英雄，是非成败转头空。青山依旧在，几度夕阳红。”

这首《临江仙》是《三国演义》的开头曲，作者是明朝的状元，大才子杨慎。许多人不不知道的是，杨慎这首词填写于流放云南途中。他当时受到两次廷杖，几乎被打死。披枷带锁还能够写出“一壶浊酒喜相逢，古今多少事，都付笑谈中”的旷达，也是令人敬佩。

以后三十多年，杨慎一直没有得到赦免，终老在戍（xù）所。

他落到如此境遇的原因，是因为他领头参与了明朝当时惊天动地的“大礼议事件”。

大礼议事件是围绕“礼”这一封建社会的核心价值展开的，老浦想通过讲述这件事的来龙去脉，解读汉字“礼”字。

甲骨文 *礼* 是一个祭祀的器皿

皿里盛着 *羊* ，是成串的

玉石 *玉* ，下面一个有脚架的大鼓 *鼓* ，在这里表示击鼓献玉，敬奉神灵。

> > 《说文解字》：
>
> 礼，履也。所以事神致福也。

说白了：

礼，是用来敬神致福的仪式。

打鼓代表仪式，玉是敬献的贡品。

在上古，只有酋长才有祭祀上帝的权利，所以礼就是特权，是建立在敬奉祖先基础上的秩序。

![](bbox=[0.25, 0.65, 0.85, 0.72])

大礼议就是争议宗族、祖先的位次问题。不过因为涉及皇位，问题就格外严重。

封建皇权的继承是按照父死子继；父亲死了儿子继承；没儿子，兄终弟及，就是哥哥死了弟弟继承。

明武宗死了，没有儿子，也没有亲兄弟。

那怎么办？

就找了他最年长的叔叔兴献王的儿子，也就是明武宗的堂兄朱厚熜（cōng）来继承这个皇位。这就是后来的嘉靖皇帝。

但朱厚熜不是皇帝的亲兄弟，按照礼法，就得把他变成亲兄弟。怎么变，好办，让朱厚熜认皇帝爹，也就是明孝宗为亲爹，换句话说，就是把他叔叔的儿子过继给父亲，这不就成亲兄弟了吗。

说干嘛那么麻烦，堂兄弟不也是一家人吗，谁让你没有亲兄弟的。干嘛搞这套虚的。
