的女孩子，其中有人在被囚禁期间因为争抢吃醋，竟然杀害了自己的难友，被警察出来以后同样受到法律的惩处。还有人在侦讯期间百般为绑架虐待自己的罪犯遮掩。同是被囚禁，而难友之间却还在互相伤害。

# **这是典型的斯德哥尔摩综合症。**

这种心理疾病的发现同样缘于一个刑事奇案。

1973年8月23日，两名有前科的罪犯在意图抢劫瑞典首都斯德哥尔摩市内最大的一家银行失败后，挟持了四位银行职员，把他们扔在黑暗的地下室。

在警方与歹徒僵持了6天之后，歹徒被放弃而结束。

然而这起奇案发后几个月，这四名遭受挟持的银行职员，仍然对绑架他们的人显露出怜悯的情感，他们拒绝在法院指控这些绑匪，甚至还为绑匪出钱请律师辩护。

他们都表明并不痛恨歹徒，并表达他们对歹徒非但没有伤害他们却对他们照顾的感激，并对警察采取敌对态度。

更有甚者，人质中一名女职员竟然还爱上劫匪，并与他在服刑期间订婚。

这是怎么回事？

这件事激发了社会科学家和心理学家，研究者发现到这种典型症候的例子见于各种不同类型的经验中，从集中营的囚犯、战俘、受虐妇女与乱伦的受害者，都可能发生斯德哥尔摩综合症体症候。

专家深入研究：人性能承受的恐惧有一条脆弱的底线。

当人遇上了一个凶猛的杀手，杀手不讲理，随时要取他的命，人质就会把生命权渐渐付托给这个凶手。

时间太久了，人质吃一口饭、喝一口水，每一呼吸，他自己都自觉是恐怖分子付出的宽忍和慈悲。

对于绑架自己的恶徒，他的恐惧，会先转化为对他的感激，然后变为一种崇拜，最后人质也下意识地为凶徒的安全，就是自己的安全。在心理上成为危害自己的人的私党。

这种屈服于最暴的弱点，就叫“斯德哥尔摩精神症候群”。

东汉许慎对篆字“限”的解读，山崖受到暴力的限制怒目而视，互相伤害，能够让正常的人性扭曲变态，与现代心理学研究的结论是不谋而合。

# **因为限制，所以麻木**

隶书的“限”山崖变成耳刀旁，右边为“良gèn”。

《周易》艮（gèn）卦，是山，在人体是腰，眼光限制在人的腰部，和我们说的小孩依赖妈妈逛街的感受一样。

艮（gèn）卦的卦象是遇到障碍不宜前行。艮（gèn）卦和耳刀组成的“限”字当然不宜冒头老实得事。

有意思的是当“艮”读（gěn）的时候，指食物不易松动或嚼烂，也形象为人处事不干脆、不利索、过于认真、没有弹性。和耳刀合起来的“限”，显出一种长期压抑之下的麻木。

![](bbox=[0.05, 0.0010400000000000001, 0.95, 0.00115])

九十年代初，我曾经陪同客户到美国考察，那时候出国还是非常难走的经历，等于睁着眼睛看世界。我自己是第一次出国，对现代化的美国充满好奇。

但我的这些客户在美国处处表现出“不过如此”的情绪：在华盛顿尖塔前，他们说还不如他们那儿音乐喷泉。在夏威夷的巨浪前，他们说我们那儿刮台风的时候浪也很大。总之美国基本上处处不如自己的城市。

这种由于封闭而产生的盲目自大情绪在出国的人中很普遍，还曾经有人在希腊迈台神庙前抗议，说我们千里迢迢来，你就让我们看几个破柱子？

如果自己是封闭的，你就是把门打开，也拒绝走出心理的山崖。

限制固然来自外界，更多的时间来自自己的内心。

我们认识了限制的“限”的三种字体，认识到限的本意是被压在在石崖下，眼光、心理都受到局限。最可怕的是，自己对自己的局限性没有感觉，甚至长期压抑之，心理产生扭曲、变态。要有所成就，就要登上山崖，突破局限，才有可能欣赏山顶的风景。
