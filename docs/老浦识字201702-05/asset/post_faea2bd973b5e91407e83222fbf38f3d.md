# 天，老子就是不怕你，你能把我咋地

祭祀实际是一种权力，代表天意发布施令。当商王和巫师在权力上产生矛盾，斗争就开始了。

有一个商王叫武乙，决心破除对天的崇拜。据说他让人制作了一个革人，称之为“天神”，然后和革人下棋，命人替天神出子。结果“天神不胜”，武乙便将革人斩首，用刑戮对“天神”加以侮辱，谓之射天。

不服？寡人让你看看天怎么流血！武乙命左右用皮革制作了一个囊袋，里面盛满血，悬吊于空中，他拉满弓，仰天射穿囊血，鲜血迸出，这就是“武乙射天”。

结果，传说一天，武乙游猎，晌晴白日突然电闪雷鸣，武乙遭暴雷震击而死。估计这个结果的传说是巫师说出来的，用以吓唬后人，意思是即便你是商王，也不能和天作对。

# 啥叫天心地利人和

这是金文“天”的写法，甲骨文头顶上那一片虚空间在变成了一个实心的黑疙瘩。在甲骨文诞生的同时，一种比甲骨文还要正規的文字也诞生了，它们被铸造在青铜器里，用以记述彝（yi二声）器主人的功德，由于古代把青铜称之为金，所以我们今天把这种文字称之为金文。

有意思的是，金文在青铜器中的位置不是不容易阅读的边缘上，而是在器皿的里面，中间，冲上。很显然，这些文字不是方便人阅读的，而是写给天看的。

# 素帛很高贵

素的本意是生绸，准确地说是还没有染色的生丝。

中国是世界上最早应用桑蚕丝织丝绸的国家，男耕女织是中国农村的常态，所以关于纺织、丝绸的汉字就特别多。我们现在看到所有绞丝旁的汉字基本上都与纺织有关。素字下面的“糸”也是绞丝变形过来的。

大家从本文里可以看到，素的金文字形是

![](img/792d2d18bbe99e723a0a2f17774d50d0_75_4.png)

是植物下垂的象形。

《说文解字》：素，白织缯也。从糸，取于溻也。意思是说素是没有染色的本色丝绸。字形表示润泽下垂。

没有经过染色的素帛曾经是最昂贵的书写材料。

纸是东汉蔡伦时期发明的，在此之前，汉字刻在甲骨上，铸造在青铜上，书写在竹简上，也书写在蚕丝织就的素帛上。

“欲寄彩笺兼尺素，山长水阔知何处。”彩笺是信笺，古人把花的汁液融进信纸做成彩色信笺，叫彩笺。历史上最有名的是薛涛笺，成都的朋友应该熟悉。唐宋有用彩笺的，也有用素色的信笺和素色的丝帛写成长信，但是山高水远，你在哪里？这是北宋张珠的记，人生第一重境界引用的是出自同一首《蝶恋花》。我把这首词抄录在后面，感兴趣的朋友可以欣赏。在没有造纸术以前，信件只能用丝帛，非常贵重。

素帛传书，曾经有许多浪漫的故事。“客从远方来，遗我双鲤鱼。呼儿烹鲤鱼，中有尺素书。长跪读素书，书中竟何如？上言长相思，下言加餐饭。”这是汉朝的乐府诗，说渔子发现了丝帛写成的书信，竟然是亲人寄来，表达自己的相思。

最神的是苏武牧羊，鸿雁传书。据《汉书·苏武传》记载：说汉朝又派使节到匈奴，要求放苏武回去但单于仍不愿意放人，谎称苏武已死。汉朝使者一早和苏武联系上了，说汉朝皇帝打猎时，曾射到一只北方飞来的大雁，雁足上系着一封信，说苏武没病死，仍在北海牧羊。

单于只好放人。后来，人们便把传递信息的使者称为“鸿雁”，“鸿雁传书”一词也由此而来。

# 素成为中国文化审美的最高境界

这是篆文

![](img/792d2d18bbe99e723a0a2f17774d50d0_75_6.png)

，是秦代李斯规范的汉字，这个素取消了系绳旁边的双手，字形上下大小，有韵律感的曲线和椭圆形的“素”字构成了汉字特殊的美感。

素是未经染色的本色，而色彩曾经是绘画的生命。人类最早的岩画就是矿石上涂上去的红色，西方绘画对颜色的登峰造极是19世纪的印象派，他们把光影造成颜色瞬间的变化捕捉下来，成为视觉的盛宴。

中国颜色的顶峰是唐代，走进敦煌石窟就走进了颜色谱写的音乐，流动的音乐奏响大唐的盛世之音。唐三彩，那就是颜色的狂欢了。

当年老普到布达拉宫参观，对墙上的壁画色彩赞叹不已，人介绍说，这些颜料都是天然宝石研磨而成，蓝色是蓝宝石，红色是红宝石，黄色当然是黄金了。

但是素以山水，色彩便逐渐从中国绘画中消逝了，先是水墨山水，进而人物画也直黑变成白描。较之世界其他各民族的绘画，这大概是绝无仅有的现象，中国人放弃了色彩，选择了素。

他们说：墨分五色。

为什么中国美术选择了素色？

这大概是三方面的原因促成的：

- 文人画的兴起，有惯了笔墨的文人兴之所至，用书法的笔法信手涂抹两下，烟云缥缈的山峦就呈现出来。
- 北宋灭亡，南宋退居江南。江南的烟雨迷离，给画家创造了天然的意境。
- 最重要的，《老子》说：“五色令人目盲。”主张“致虚极，守静笃。”追求清静无为的境界，空灵的素白色是中国文人淡名利心的体现，“曲终人不见，江上数峰青。”

这种淡雅素净的风格不仅体现在绘画上，南宋汝窑的雨过天晴，已经把实用的器物升华为高雅的精神境界。这是中国文化审美的最高境界。

# 【仁】虚伪吗？

老铺提示：订阅专栏后，文稿中的象形文字可截图片，放大来看，细细品读。

# 仁是爱人

读《水浒》，很多人都迷惑不解，宋江，一个县衙司法局的公务员，貌不惊人，武艺平庸，也就是平常人缘比较好，怎么能统领一百多江湖好汉，啸聚水泊梁山，干出惊天动地的造反勾当呢？

仔细研究，你会发现，宋江为人就一个字，仁。

仁，甲骨文“图片”和我们熟知的简“图片”化字差不多，人字旁，两横。只不过甲骨文的人字旁“图片”是象形的，像一个侧面站立的人形。

甲骨文人字旁含义很清楚，就是和人有关，那两横“图片”是什么意思呢？为什么人字加两横，就成为中国传统文化最高的道德标准呢？

这两横表示等同，比如整齐的“齐”“图片”，就是三个小禾苗“图片”，下面两横“图片”，表示大量种子同时发芽。

人字旁两横，是说人与人平等的关系。

中国文化尤其是儒家文化，大量的思考都是关于人与人的关系。

在汉字中，表示人与人之间关系的字有很多，

- 比“图片”是两个人并肩站立；
- 从“图片”是一个人跟着另一个人；
- 斗“图片”是两个人打架。

大家可以看看字源版这几个字甲骨文的形式，特别好玩儿。

# 仁是儒家文化的核心，按照孔子对仁的定义：

> “夫仁者，己欲立而达人，己欲达而达人”。

意思是说：

仁，就是自己想要有所建树，先要帮助别人建树；自己想要发达，先要帮助别人发达。

用这个标准看宋江还真对的上。

宋江不算是有钱人，他父亲就是乡下一个地主，还不是大的，而当他公务员的收入也很有限。

有人分析他灰色收入很多，大概也不尽然。你看晁盖让刘唐给他送100金，他只留下一块金条，余下的都让刘唐带回去，可见此人不太贪。

真正有钱的一个是柴进，贵族。还有就是河北玉麒麟卢俊义，那是大地主。

但要说江湖影响力，首推及世而宋江。

为什么？大概和他己欲立而达人的平常心有关，无论是武松、李逵这样的哥们，还是邻居老人家，他都帮。碰上晃盖犯事，他可以冒着去饭碗的风险去报信，确实称得上及时雨。

这样的平常心我们在《三国演义》的刘备身上也能看出来，他和关羽张飞出身不同，却能结为生死兄弟。对诸葛亮这个年轻人可以三顾茅庐。

想自己成事，先帮别人成事。
