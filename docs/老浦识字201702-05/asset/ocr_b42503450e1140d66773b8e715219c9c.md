# 仁是爱人

读《水浒》，很多人都迷惑不解，宋江，一个县衙司法局的公务员，貌不惊人，武艺平庸，也就是平常人缘比较好，怎么能统领一百多江湖好汉，啸聚水泊梁山，干出惊天动地的造反勾当呢？

仔细研究，你会发现，宋江为人就一个字，仁。

仁，甲骨文“图片”和我们熟知的简“图片”化字差不多，人字旁，两横。只不过甲骨文的人字旁“图片”是象形的，像一个侧面站立的人形。

甲骨文人字旁含义很清楚，就是和人有关，那两横“图片”是什么意思呢？为什么人字加两横，就成为中国传统文化最高的道德标准呢？

这两横表示等同，比如整齐的“齐”“图片”，就是三个小禾苗“图片”，下面两横“图片”，表示大量种子同时发芽。

人字旁两横，是说人与人平等的关系。

中国文化尤其是儒家文化，大量的思考都是关于人与人的关系。

在汉字中，表示人与人之间关系的字有很多，

比“图片”是两个人并肩站立；

从“图片”是一个人跟着另一个人；

斗“图片”是两个人打架。

大家可以看看字源版这几个字甲骨文的形式，特别好玩儿。

# 仁是儒家文化的核心，按照孔子对仁的定义：

> “夫仁者，己欲立而达人，己欲达而达人”。

意思是说：

仁，就是自己想要有所建树，先要帮助别人建树；自己想要发达，先要帮助别人发达。

用这个标准看宋江还真对的上。

宋江不算是有钱人，他父亲就是乡下一个地主，还不是大的，而当他公务员的收入也很有限。

有人分析他灰色收入很多，大概也不尽然。你看晁盖让刘唐给他送100金，他只留下一块金条，余下的都让刘唐带回去，可见此人不太贪。

真正有钱的一个是柴进，贵族。还有就是河北玉麒麟卢俊义，那是大地主。

但要说江湖影响力，首推及世而宋江。

为什么？大概和他己欲立而达人的平常心有关，无论是武松、李逵这样的哥们，还是邻居老人家，他都帮。碰上晃盖犯事，他可以冒着去饭碗的风险去报信，确实称得上及时雨。

这样的平常心我们在《三国演义》的刘备身上也能看出来，他和关羽张飞出身不同，却能结为生死兄弟。对诸葛亮这个年轻人可以三顾茅庐。

想自己成事，先帮别人成事。
