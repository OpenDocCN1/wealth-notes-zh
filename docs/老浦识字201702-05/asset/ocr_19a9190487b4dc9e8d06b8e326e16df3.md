# 糖尿病跟“灾”字有关

你知道糖尿病和灾难有关吗？

中国是糖尿病第一大国，据卫生部门的数据，2014年我国糖尿病患者1.14亿，也就是说，不到10个成年人中，就有一个糖尿病患者。

我父亲安徽人，有一句口头禅，“宁可撑死个人，不能占个益”，决不允许剩饭，拜我父亲教育所赐，我是饭桌上著名的垃圾槽，结果吃出了糖尿病。

吃到饭能 eat 出糖尿病？没错。

美国遗传学家尼尔教授在20世纪60年代首次提出“节俭基因”学说。他认为，饥饿让那些吃了上顿没下顿，在营养很差的情况下仍然能够生存的人，进化出“节俭基因”。

中国是世界上灾祸饥荒最多的国家之一，饿了多少年多少代，却在我们这一代突然进入稳定富足的现代社会，滴灌改漫灌了，那还不水漫金山。这回真“撑死个人了”。

“灾”这个汉字，居然已经刻进了中华民族的基因里了。

灾难世界各国都有，为什么中国人的基因会刻下节俭基因呢？

中华维族的发祥地在黄河流域，而历史上黄河是一条最捉摸不定的河流，经常泛滥改道。“十年河东十年河西”说的就是黄河泛滥改道。

甲骨文距今3500年前，是商代晚期的文字，商朝500多年历史，前二百多年曾迁移过13次，到殷，也就是今天的安阳，由于地势较高才稳定下来。这样的迁徙多出于躲避洪灾。
