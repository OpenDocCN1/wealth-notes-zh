就呈现出来。

+   2. 北宋灭亡，南宋退居江南。江南的烟雨迷离，给画家创造了天然的意境。

+   3. 最重要的，《老子》说：“五色令人目盲。”主张“致虚极，守静笃。”追求清静无为的境界，空灵的素白色是中国文人淡名利心的体现，“曲终人不见，江上数峰青。”

这种淡雅素净的风格不仅体现在绘画上，南宋汝窑的雨过天晴，已经把实用的器物升华为高雅的精神境界。这是中国文化审美的最高境界。

# 吃素为什么可以成为时尚

![](bbox=[0.35, 0.28, 0.6, 0.34])

把笔匾画直，再也看不出和丝绸有什么葛焉了。现实的情况也是如此，由于原的原意是本，白，就引申为与荤相对的纯素食饮食，即素食。

其实佛教西来，忌荤是不吃葱姜蒜这些气味刺激的蔬菜，并不禁止吃肉。真正主张吃素是从南北朝时期梁朝的梁武帝萧衍开始的。他见佛经戒律不杀生，就索性硬性规定出家人不得吃肉。

素色的丝帛，寄来的是最深的情谊。

素雅的山水画，挥洒的是参透人生的淡泊。

素食，自律的是众生平等的慈悲。

素，构成独特的东方审美和生活态度。

落花散尽，风轻云淡，人淡如心，素心如简。
