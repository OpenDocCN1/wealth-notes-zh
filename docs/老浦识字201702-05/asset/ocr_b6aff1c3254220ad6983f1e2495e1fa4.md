十二生肖全是动物，为什么冒出一个在现实世界中并不存在的龙呢？

我们还是来看看汉字。

龙的甲骨文 [图片：甲骨文“龙”] 是一

只弯曲着身体、张着大口的动物 [图片：甲骨文“龙”]，在这只身形刚劲的动物头上有一个“辛”字。

有人说是爬行巨兽头螨，

[图片：甲骨文“辛”] 表示“龙”头上长着锋利的角；

有人说是鸮子鸟，因为“龙所居，常在水泽之中”；

有人认为这是一条大蟒蛇，头上的 [图片：甲骨文“辛”] 是一个倒过来的“壬”字；

有人甚至认为是蛇信，蛇信就是蛇的舌头；

还有人认为是云、闪电。

闻一多先生认为：

> “龙的形状是在蛇的基础上，接受了兽类的四脚、马的鬃毛、蜃的尾、鹿的角、狗的爪、鱼的鳞和须”。并说龙“不是一种图腾，而且是只存在于图腾而不存在于生物界中的一种虚拟的生物，因为它是由许多不同的图腾拼合而成的一种综合体”。

![](bbox=[0.15, 0.7, 0.85, 0.78])

说了这么多，究竟哪一种说法靠谱呢？

都有道理，但老潘个人认为，这是一个大蟒蛇，头上的 [图片：甲骨文“辛”] 是巫师的帽子。

我们再看“凤” [图片：金文“凤”]，同样也是一只大鸟头上顶着这样一个帽子，象征不是现实中的动物，而是神。

《说文解字》说：

> 龙，鳞虫之长。能幽，能明，能细，能巨，能短，能长。春分而登天，秋分而潜渊。

一句话，它就是个神。

# 成为神是因为能行云布雨

龙这个神之所以能够混进十二生肖，是因为它能行云布雨。

在农业社会，大自然中的水对人们的生活影响最大——不下雨，土地干旱，颗粒无收；一下大雨造成洪水，同样也是颗粒无收。所以人们盼望有一个神把下雨这件事管理起来。

龙就这样混进了十二生肖。

# 贴门神的由来

再来看看金文的龙 [图片：金文“龙”]，还是那个大蟒张牙，张开的巨口不见了，头上的王冠却更明显夸张了。

早期的龙是诸多神鬼中的一种，是管下雨的。《西游记》中断龙王的故事故事最有代表性。

唐太宗时，掌管雨水的龙王，因为暴改玉帝下凡大圣回，触犯天条，玉帝派遣太上老君边边的大圣回处死龙王。

情急之下，龙王托梦唐宗太宗，请他想办法救自己，结果唐太宗营救计划失败，龙王，还是被斩了。

龙王的魂魄心怀委屈，夜夜骚扰唐太宗，让他不得安宁。

于是，秦叔宝、尉迟敬德两位大将奉命为唐太宗守夜驱鬼，时间住了，唐太宗见二位将军劳累，派人作为两位将军画了画像，贴在门上。

龙王的魂魄就再也不敢来了。

这就是民间贴门神的由来。

这个故事反映了人们盼望龙王尽忠职守的愿望，放能了，人间的忠臣也要能龙能，挂皇帝带帮都受用。

# 为什么我们是龙的传人

下雨这事太重要了，各地都有大大小小的龙王庙，祈求风调雨顺。

那从什么时候起，龙成为皇家的专属，而我们中国人又被称作为龙的传人呢？

龙不仅是行云布雨的神兽，还是华夏原始部落的图腾。

图腾是原始部落选定一种动物作为自己部落的象征和保护神。有专家说，龙之所以集合了很多动物的特征，是因为以大蛇为图腾的部族融合了许多用马、鹿、鱼等动物为图腾的部族，最后形成了龙。相传中国人祖先伏蚩氏和女妇就是人面蛇身，其实就是龙的图腾崇拜。

所以我们都是龙的传人。
