# 发射的發

简体字把头发的“髮”和發展的“發”合并成一个发字，其实这两个字除了发音相同，没什么共同之处，我认为这两个字都是人类发展史上非常重要的字。

头发的髮我们谈过了，在古人心目中是近乎神圣意义的。

而發展的發則是改变人类命运的动作描述。

在石器时代，人类在自然界并不强大，事实上他们经常成为体型比他们大、速度比他们快，牙齿比他们锋利的动物的食物。

早期人类的胜出靠两绝活：语言和工具。语言能够让他们组织起来，设置陷阱、围追堵截，都需要语言沟通交流。

而工具的使用，让他们变得强大起来。

汉字發展的發就是原始狩猎使用工具的形象描述。

我在网上看到过现代非洲土著，用标枪这种原始工具狩猎的画面，那威力真是超乎想象。在几十米甚至上百标枪真的猛射下，无论是敏捷高速的鹿、豹子，还是庞大的野牛、河马、大象，都毫无还手之力，轰然倒地。

形，表示使用弓箭狩猎。

弓箭不同于用石头槽做成的标枪，弓箭制造更复杂，射程更远，杀伤力更强。

对人类历史发展来说，这是一次巨大的飞跃。

对原始人类来说，采集狩猎是生存的主要方式，弓箭的出现，使人类能够获得更多的肉食，促进了人类发展。

新石器遗址动物骨骸有猪、猴、牛、羊、鹿、狼、狗、虎、熊、鱼等等，表明在工具的帮助下，人类已经可以狩猎几乎所有的动物。

> 恩格斯说：“弓箭对于蒙昧时代，正如铁剑对于野蛮时代和火器对于文明时代一样，乃是决定性武器。”

# 发兵的發

![](bbox=[0.15, 1.0, 0.5, 0.0010500000000000002])

有双脚，有弓箭，还有手持的棍棒。

《说文解字》说：發，射戟也。从弓，登（bā）声。由于發射弓箭一往无前的特性引申为出發、發兵。

汉代名将李广是有名的射箭高手，他祖上就是秦军名将，曾击败燕国的太子——丹。

李广曾夜追老虎，一箭射去，才发现是块石头，而箭已经射进石头里。再射，箭怎么也射不进去了。

李广戍守北疆，与匈奴打了一辈子，匈奴人很怕他，但阴差阳错，李广一直没有能立下显赫的军功。

公元前119年，汉武帝发兵5万发动漠北战役，任命李广为他将军。

这也许是李广伐伐的最后机会，但大将军卫青却让他分走东路。

东路不仅路途遥远，还是绕远道。

结果李广迷途，无功而返。

战后卫青追究责任，李广不愿受羞辱而自杀。

一代名将，委屈而亡。

發兵如果失去方向，再精妙的箭术也是枉然。

唐代李渊和李世民也是射箭高手，追李广为自己的先祖。其实血液上一点关系都没有。

# 发财的發

![](bbox=[0.15, 0.00135, 0.6, 0.0014])

变形为“登高”的“登”的上部，“弓”还在，手持棍棒变成反文，發字由于“前往”的特性，引申为发达、发财。

战国时期最能发财的大概就是赵国的范雎（jū）了，他在帮助魏王政攻灭以后，功成名就。

传说携西施泛舟五湖，经商三次成为首富，又三次把财散发尽，隐居身退。

由于最后定居在定陶（今山东菏泽市定陶区），自号陶朱公，此后世为财神。

可是这个财神偏偏是不爱财的。

有发财的欲望，也有发财的手段，但是对待财富的态度却很洒脱，认为财富过多是不祥之事，主运动散财。

这想对发财的人是不是有点启发？

# 发展的發

简 体 字 的 “ 发 ” 是 从 草 书

![](bbox=[0.15, 0.00165, 0.5, 0.0017])

一直是两个系统，一个是印刷体的正体字，由于还准确缜密分写，笔画比较多。另一个系统就是手写体，为了书写方便，有行书和草书，笔画就比较简单。

这个“发”字就是一样，印刷体比较繁杂，草书很简单，但这种草书是绝对不会写错的。
