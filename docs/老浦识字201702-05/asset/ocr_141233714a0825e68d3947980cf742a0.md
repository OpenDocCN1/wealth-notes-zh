# 【虎】怎么变成弱势群体了？

老虎提示：订阅专栏后，文稿中的篆形文字可放大看，放大来看，细细品读。

老虎在十二生肖中排名第三，对应的寅（yín）时，是凌晨3点到5点，正是老虎夜间觅食的时间。

据说唐寅是寅年寅月寅日寅时出生的，所以叫唐寅，字伯虎。

甲骨文的老虎是相当威风的

![](bbox=[0.18, 0.32, 0.82, 0.4])

，血盆大嘴像一个夸张的A字，一身美丽的斑纹，弯曲有力的尾巴，活生生像一个吃人的猛兽。

八达岭和宁波的老虎咬死人，人们普遍同情老虎，而怪人。究其原因，是因为老虎被关在动物园里，人与老虎的关系，不是强势，老虎是弱势。

人嘛，总是同情弱者。

但是老虎历来是战神啊。汉字里凡是虎字头的字，都是威风彪炳的。云从龙，风从虎，这只吊睛白额大虫什么时候变成让人同情的弱势群体了？

我们尝试用几个虎字头的汉字来梳理这个过程。

甲骨文的虒

这也是一个虎字头的汉字，空虚的虎

![](bbox=[0.35, 0.00157, 0.65, 0.00165])

，一个虎头

![](bbox=[0.2, 0.0017, 0.8, 0.0017800000000000001])

这反应了当时人和猛虎的关系，人在虎的面前毫无还手之力，要么倒霉被老虎抓住，猛虎。要么远离他乡，能躲多远躲多远。

要躲多远呢？

100公里以外。

老虎居于食物链的顶端，需要的食物很多，所以需要养活它的领地就很大。老虎的领地范围一般是100 - 400平方公里。

虎是很孤独的，只有在繁殖季节雌雄才在一起生活。

当老虎巡视领地时，会往到有强烈气味的尿液喷在树上，界定自己的势力范围。

《说文解字》说：虎，虏也。山兽之君。

那时候真是王者风范。

# 虎是神

这是篆文的虎

![](bbox=[0.18, 0.0027, 0.82, 0.00278])

，巨大的虎头下面，一个“人”

![](bbox=[0.4, 0.0028599999999999997, 0.6, 0.00292])

，字笼罩在虎威之中，表示人臣服于虎。

这时候人类由于敬畏老虎，已经把老虎奉为神明。

这是另一个虎字头的汉字彪形中的“彪”的

金文

![](bbox=[0.18, 0.00314, 0.82, 0.00322])

，是一个老虎的虎

![](bbox=[0.18, 0.00327, 0.82, 0.00335])

形，加上三撇

![](bbox=[0.35, 0.0034, 0.65, 0.00348])

，三撇的本意是长发，在这里表示老虎身上条形的花纹。合起来表示老虎威风彪炳的形态，这是虎神的形象。

中国传统文化中有四个神兽，分别是青龙、白虎、朱雀、玄武，老虎是唯一真实存在的动物，其他三种都是想象中的神兽。

虎，为百兽之长。它的威猛和传说中降伏鬼物的能力，使得它变成了阴阳的神兽。

作为神的白虎具有避邪、横（rǎng）灾、折夭及恶毒猛兽、发财致富、喜结良缘等多种神力。

白虎代表的方位是西方，左青龙、右白虎，在五行中属金，色白，在四季里代表秋天。

秋天在古人看来主肃杀，是兵象。

白虎是战神、杀伐之神。所以古代兵用的符命会做成老虎的形状，称为虎符。

![](bbox=[0.1, 0.00413, 0.9, 0.00445])

对白虎的崇拜源自文化中对虎的图腾崇拜，虎一直受到多个民族的崇拜，是正义、勇猛、成功的象征。

直到今天我国的彝族、白族、布依族、土家族等民族仍号称白虎是他们的祖先。
