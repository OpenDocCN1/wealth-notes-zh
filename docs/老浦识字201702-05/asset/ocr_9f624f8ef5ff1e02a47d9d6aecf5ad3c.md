# 【善】怎样辨别伪善

老师提示：订阅专栏后，文章中的象形文字可截屏点赞，放大来看，细细品读。

在我们这个时代，善良既稀缺又泛滥。

说稀缺，老人跌倒没人扶，小孩被车碾轧没人管。

说泛滥，王宝强一篇微博离婚就引发千万人同时发声，一篇感人的网络文章就能吸引百万捐款。

陈光标高调慈善，宣传无所不用其极。清华教授捐赠资助学生1500万，去世四年后才为人所知。

到底什么是真正的善？

# 善是无条件的牺牲

我们来看甲骨文。

甲骨文的善字有几种写法

![](bbox=[0.2, 0.5, 0.8, 0.6])

都是羊和眼睛的组合，

弯曲的羊角，大大的眼睛，其实就是一个羊头的造形。这是表声作为祭品。羊代表善，吉祥有关，如意吉祥、美好的含义，甚至包含善等等。

圣经《旧约》有一个故事：有个叫亚伯拉罕的闪族人，他99岁有了一个儿子，天父来向他降临。他就舍弃了自己的儿子，以撒作为献祭。亚伯拉罕忍住悲痛，将儿子放上祭坛欲动刀时，天使飞来救住了他的命。上帝告诉他只是耶和华的考验，他可以改用羊来作为祭品。

![](bbox=[0.2, 0.81, 0.8, 0.9])

羊是古代祭祀中必不可少的主要贡品。羊除了用作献给上帝的牺牲，还承担了一项任务，就是给人类“替罪”。这就是替罪羊的来历。

所以造字善的原意就是无条件的牺牲。无条件为了儿子都能舍弃的地步。
