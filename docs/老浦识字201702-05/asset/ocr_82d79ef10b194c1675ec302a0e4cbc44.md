# 别人的女人不能抢，会出大事

汉字金文“怒”：

![](bbox=[0.4, 0.33, 0.7, 0.4])

上边是一个“女”，表示女人；一个“又”，表示手，这是一个“奴”字

![](bbox=[0.3, 0.48, 0.6, 0.55])

。在古代，女人经常被抢，沦为奴隶。

下边一个“心”，表示一种心理状态。手抓住了女人，就怒了。古人是什么意思呢？

有人解释说因为成为奴隶，内心愤怒；还有人解释这是一只成猪手，骚扰了女人，女人怒了。

要搞清楚这个问题，还要看另外一个汉字——妻子的“妻”。

![](bbox=[0.3, 0.81, 0.6, 0.88])

。在这里又看到了“女”，也看到了“又”——那只野蛮的手。

不过区别是这只手扯掉了女人的头发，表示对这个女人的控制。女人跨坐的姿势表示征服，而头发上的三个短横，表示荆钗（chai，荆枝做的簪钗），是为人妻的标志。
