# 妖言惑众

甲骨文的众

![](bbox=[0.3, 0.26, 0.5, 0.34])

是一个日，

也就是太阳，下面三个人形。

在古代，三就表示多。

廉颇为表示自己还未老，在赵国使臣面前吃一斗米饭，十斤肉。赵国使臣回去报告上司。一句话就把廉颇毁了：廉颇还挺能吃，但吃饭的时候，三进三出。

不是说吃一顿饭上了三次厕所，而是多次上厕所。可能阑尾炎，但干部考核没通过，失去了上阵打仗的机会。

太阳下很多人就是群众的众。

三个人表示多，写三个人不就完了吗，为什么还要在上面加个太阳？

事实上，最早的甲骨文还真的就是三个形，没有日。为什么要加上日？

![](bbox=[0.25, 0.52, 0.45, 0.58])

先讲个故事。公元前209年，秦二世元年，大雨滂沱，一群900人的新兵正在赶赴今天的北京地区，当时这里是边疆，北方的匈奴经常骑骆驼劫掠。由于大雨耽误了日期，队伍中都传说，按照秦朝法律，迟到者赶到以后全体都会被处死，所以队伍中弥漫着绝望的情绪。

终于可以扎营做饭了，厨子在收拾刚刚从市集买回来的鱼，突然发现鱼肚子里居然有一块丝帛，上书三个大字：“陈胜王”。

而在宿营地附近的狐狸，隐隐约约传来狐狸的叫声，好像在叫“大楚兴，陈胜王”。对，我讲的就是陈胜吴广大泽乡起义。

这则来自《史记》的记载从来没被人怀疑过，秦朝的法律竟然如此严苛，3个逃犯就要统统杀人，造反是必须的啊。

直到1975年11月，在湖北省孝感地区云梦县出土了大量秦简竹，其中很多是法律条文。其中有用朝廷规定征发徭役的详细规定：

迟到三天到五天，批评；

六天到十天，罚一块盾牌；

超过十天，罚一副盔甲；

因大雨或洪水导致的耽误，可免除此次征发。

那么陈胜吴广起义时声称“因大雨耽误日期，肯定会被处死”的说法是哪来的呢？

很明显，和鱼肚子里的丝帛，夜里狐狸的叫声一样，都是陈陈胜吴广搞的鬼。

![](bbox=[0.25, 0.85, 0.65, 0.93])

这就颠覆了咱们以往的认知。我们一直以为陈胜吴广起义是因为迟到要被处头，反正早晚是死，被迫造反，所谓官逼民反。现在看来不是这么回事。

这是一场精心策划的阴谋：先造谣说大伙都要被处头，然后装神弄鬼推出假陈胜王，最后制造一个事件爆发造反。

为什么要这样装神弄鬼啊？

来看看甲骨文的众，可以解释为太阳下人们集体劳动，也可以理解为人们头顶共同的神。

太阳就是神，没有神，众人就是一盘散沙。

在远古要把人群聚集起来，要有个身份，要么是王，要么是巫师，你普通人人我认识你是谁啊。他要么让自己超神，要么让天派来的，跟着他，就不用担心成不了事，老天自有安排。

出身佣工的陈胜和农民出身的吴广没有背景，要造反没人听怎么办法？那就要自己制造——天意。他要么让自己超神，要么让天派来的，跟着他，就不用担心成不了事，老天自有安排。

世袭的君王会表明自己是“君权神授”，那些依靠鬼神来制造聚众造反，就一定要拖无鬼神来制造自己起事的合法性。

黄帝起义的口号是“苍天已死，黄天当立，岁在甲子，天下大吉”。

元末红巾军韩山童的口号是“天下大乱，弥勒佛下生，明王出世”。信奉的是白莲教。

太平天国搞的是拜上帝教，天王父天父兄一大堆。

在我们当代，一句蛊惑人心的口号就能聚集大量信徒的事情层出不穷，最新的是，连通宇宙能量的心灵培训机构，会员上万人，敛财800多万。这种妖言惑众的戏码在中国这片土地上常玩长新鲜。

这种戏码中的核心就是“众”字上面的“日”。

# 众人一且等于盲目

金文群众的“众”把甲骨文上面的日，演化成成一个横着的“目”。

这可能是在古代书写过程中写错了，但我觉得这里冥冥之中反映了乌合之众的另一个特征，就是集体的目标。

乌合之众都有一个蛊惑人心的目标。

陈胜吴广说“王侯将相宁有种乎！”

小成自说“吃他娘，喝他娘，闯王来了不纳粮”。

水泊梁山杏黄旗下不也是大书“替天行道”吗？
