# 5.外邦人也怕蛇

不仅中国人怕蛇，全世界的人都怕蛇。在古老的文明中，绝大多数有蛇神崇拜，比如印度文明、埃及文明、玛雅文明等。

![](bbox=[0.08, 0.09, 0.92, 0.15])

最恐怖的是希腊神话中的美杜莎，她的头发是无数条小蛇，腿部是蛇尾，身体能发出蛇叫的声音。最恐怖的是她的眼睛，只要你一眼，立刻把你变成一具石像。

后来希腊英雄帕尔修斯杀死了美杜莎，把她长满小蛇的头献给了雅典娜。雅典娜把她佩戴到自己的盾牌上，于是这面盾牌也具备了石化敌人的功能。

可见在希腊人心目中，蛇是多么恐怖。

最有意思的是澳大利亚卡卡杜国家公园有一幅石画，画了一条大蛇，澳大利亚土著称之为彩虹蛇。传说大蛇，彩虹蛇是从水洞六冒出来的，孕育生命和水，使大地繁荣旺盛。据说天空出现彩虹时，彩虹蛇会从一个水坑到另一个水坑，确保各水源充足。

人们相信，这条蛇是大地之母，它划出了澳大利亚的地形。直到今天，澳大利亚每年都举办彩虹音乐节。

![](bbox=[0.1, 0.41, 0.9, 0.54])

彩虹蛇的传说在非洲也有，贝宁、尼日利亚、刚果都有这样的神话传说，均与生命创造密不可分。

![](bbox=[0.1, 0.59, 0.9, 0.64])

# 6.吓人的蛇是治病救人的标志

这是隶书的“它”，还能看出蛇的形状。楷书的“它”，将隶书的独体结构分解成“宝盖头”和“匕”，那个恐怖的蛇头终于不见了。

别急，还有更让你惊奇的事情。

![](bbox=[0.25, 0.75, 0.75, 0.82])

这是世界卫生组织的会徽，看到中间那条蛇了吗？一条吐着蛇信的蛇盘在一根针上。世界卫生组织的会徽上为什么会有一条蛇呢？

这源于希腊神话，医神阿斯克勒披斯，手持一根盘绕着一条灵蛇的神杖，巡游四方，治病救人。于是神杖和蛇就成为西方医务工作者的标记了。

再看看这张图：

![](bbox=[0.3, 0.95, 0.7, 0.00101])

这是中华人民共和国卫生部的部徽。同样有一条灵蛇，代表西方医学。不过这根针不是医神阿斯克勒披斯的神杖，而是中医针灸的银针，体现了我国“中西医并重”的卫生工作方针政策。

人人恐惧的蛇竟然是治病救人的标志。恐惧可以把人打垮，也可以给人力量。

我原来怕读慢，还一点轻微的口吃。有一次接受央视一位朋友出镜录了一段话，朋友直摇头，说你吃了不开口饭。第一次在北京上自己策划的节目《五星夜话》做嘉宾，也被编导批评说话慢，说话犹豫。原因很简单，从小就害怕当众讲话。迎上去，练哦。这么多传媒大学出身的老师，向人家请教呗。

然后珍惜每一次出镜的机会，把每一次出镜当做最后一次来认真准备，让所有环节心中有数。

后来就在越来越多的电视、广播节目中进行刻意练，后来接触自媒体，对录屏像机得红也能滔滔不绝。

害怕很自然，但不能给自己贴上“我就是不能”的标签。
