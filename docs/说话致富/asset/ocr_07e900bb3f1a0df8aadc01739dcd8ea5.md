# 想成為億萬富翁，你得先學會掌握機會！

我也是一樣，雖然當時充滿了幹勁想創業成功，但那時的我，並沒有年收一億元的野心。

要達到年收一億元的目標，我們需要的是機會。

所以本書想傳達的重點，不是已經達到年收一億元的人重視什麼，而是那些人在達成年收一億元之前，所重視的事物。

如果你真的想要年收一億元，那麼必須做的第一件事就是──「改變努力的方式」。俗話說「職業不分貴賤」，但很遺憾的，賺錢的速度會依職業而有所不同。

舉例來說，便利商店的工讀生，不管再怎麼努力，時薪頂多一千五百元（台幣約四百零五元），以月薪來看，了不起三十萬到四十萬元。這雖然不是什麼壞事，但如果你真的想賺到年收一億元的話，就會有如徒手摘星般困難了。
