樣，如果一直大聲說話，聽的人會覺得很疲憊，但如果是刻意壓低說話音量，就能吸引聽眾注意。

其他還有先用較高的音調說話，在重要的部分刻意壓低音量的。像這樣讓聲音有強弱和高低之分，可藉此吸引對方的關心和興趣。

# 最後是「視覺訊息」。

視覺訊息（外表與氣氛）占了五五%，所以也可以適時的「比手劃腳」。

# 「比手劃腳」也就是肢體語言的意思，可設法配合說話內容運用手勢。

童話故事「桃太郎」，會成為一個很好的練習。

說到「一顆很大的桃子」時，可手比一顆大桃子；講到「劈桃子」的部分，就用手當柴刀往下劈。

另外，也能參考一些海外人士演講時，所運用的手勢技巧。當然也要考慮到時間、地點和場合，請不要濫用手勢。不過你可以找一些值得學習的對象，學習他們的說話方式和動作。
