# （結論）

「不管什麼事情都一樣，先決定目標，然後再選擇方法很重要。」「舉例來說，你想去大阪的話，應該會坐新幹線；如果是去東京車站可能會搭山手線；去附近的超市大概就是要腳踏車吧。每次都是先決定目的地，然後才選擇手段或交通工具不是嗎？」（比喻 1）

「你會做料理嗎？假如今天想做漢堡肉，就會先從準備絞肉開始吧。可能還會需要洋蔥。材料準備好後，就會依照「做漢堡肉」這個目標進行處理，不會先切好食材，才開始想要做什麼料理。」（比喻 2）

「棒球也是一樣吧？漫無目的的打棒球，跟以甲子園（編按：日本著名的全國高中棒球聯賽）為目標的棒球，兩者的打法應該不同。如果目標是甲子園，那也會有相當程度的練習吧？如果漫無目的的打球，沒有立下甲子園這個目標，這樣打球會很快樂，可是技巧不會變好吧。」（比喻 3）

「如果你想得到某種顯著的結果，或是特別的結果，那就應該先從決定目標開始吧？」（提案）
