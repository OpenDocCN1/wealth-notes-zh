# 溝通能力在信用經濟時代會成為更重要的武器。

對他人造成更大的影響。因為即使技巧再不純熟，也不會被扣分，但有些不佳的態度，則會讓人留下負面印象。

換句話說，就算你技巧再精湛，惡劣的態度還是會讓你被大大扣分。學生時期，應該幾乎沒有人上過溝通課程吧。因為在日本，根本沒有人意識到溝通是需要學習的。

從現在起，從頭開始學習溝通技巧，一定可以創造出非常大的價值。因為你的競爭對手幾乎未曾學習過，因此在校方面，當然會顯得沒有自信。

所以提升溝通能力，會讓你明顯不同於周圍的人。要知道，沒有任何的事物比認真學習溝通技巧的CP值還要更高了。
