# 你我都有可能！

### 注意！想賺錢，請避開三種類型的麻煩人物

事業有成的人遇到問題時，往往會先將矛頭指向自己。他們會思考自己有哪些不好並努力改善。但其實，問題可能是出在他們的往來對象。請記住：千萬別跟容易惹麻煩的人來往，因為不是和每個人都打好關係，就能賺到年收一億元。

你身邊有這種朋友嗎？請和他們「保持距離」！

- **1 一開口就講錢的人**

這類型的人如果找到條件更好、能賺更多錢的交易對象，馬上就會頭也不回的棄你而去。人生不是只有好事，所以跟沒有金錢關係也能來往的人，比較能建立長久的人際關係。

- **2 情緒或情感起伏劇烈的人**

靠衝動選擇事情的人，會因為情緒起伏而輕易違反約定。不過這類型的人大多充滿了幹勁。如果你能冷靜幫忙踩煞車控制住他們，就能巧妙的與他們來往。

- **3 自我正義感較強的人**

人和人相處，本來就會遇到意見分歧之時，但如果和只會單方面將自身想法強加在他人身上的人往來，就會吃盡苦頭為自己帶來麻煩。

# 靠說話創造財富

### 提升溝通能力，是實現目標的第一步

為什麼作者能在 26 歲創業，40 歲前達到年收一億元呢？因為他知道要成為一個能夠賺大錢的人，就必須磨練「說話術」。只要懂得說話技巧，贏得人心，錢脈自然無可限量。

該怎麼說話才能打造好人緣，吸引財神找到你？

- **1 提升他人的自尊**

聆聽、稱讚與傳遞感謝，都是可以提升對方自尊心的好方法。如果能做到這三點，對方就會覺得你是一個珍貴且值得尊敬的人。

善於溝通的人有個共同點就是——擁有幽默感。有幽默感的人比較容易受人歡迎。因此想贏得好人緣，幽默感是不可或缺的要素。

其實，不管你想或不想都不是最主要的問題。因為工作關係，我常會遇見許多有錢人，「很少有人是因為想賺到一億元而賺到的」。這是我看過許多有錢人之後的真心話。

請試著想一下，如果你看到一個人到處說：「給我一億元！」你會覺得他很厲害嗎？反而會退避三舍吧。

要成為一個能夠賺錢的人，關鍵在於「讓人聚集在自己身邊」。這是許多成功者的共通點。機會總是由人介紹的，眾人聚集在自己身邊才會迎來機會。換句話說，「年收一億元者」的說話術，就是讓眾人聚集在自己身邊的溝通術。

過去的我，不擅長與人来往，朋友也很少。溝通和對話我更是個長，是一個我不想觸及的領域。最糟糕的時期是在學生時代。我重考過一次，所以出社會時已是二十三歲。很遺憾的，我的求職過程一點也不順利。那時的我的大，大三升大四都有問題了，因此完全沒去找工作（編按：日本的學生通常在大三時開始找工作，畢業後就會直接就業）。面試我也很不擅長，想要盡可能避免掉。

好不容易升上大四大後，我發現到一件悲慘的事情，那就是同屆之中，就只剩下我還沒找到工作，焦慮感油然而生，心想：「總之不管做什麼都好，要快點找到工作才行……」於是我從員工人數較多的公司開始徵，最後去了一間大型通訊公司工作。

現在回想起來，沒有比這更值得感謝的事情。我書讀得不好，也不想參與面試，個性又是個「慢郎中」，但對方還是錄用了像我這樣的學生，而且我很任性，找工作時有一個條件絕對不會退讓，那就是「要做不會與人接觸的工作」。

畢竟我對溝通沒自信，個性又很害羞，我一直覺得像業務那種要面對人的工作，絕對不適合我。最後好不容易有間大型通訊公司錄取我，職缺剛好又不用面對人群，這完全符合我的需求。換句話說，我對溝通很沒自信又一直逃避。我可以斷言，絕對沒有人能夠超越我。正因如此，我才更能明白的告訴你：

# 你真的想成為億萬富翁嗎？

在學習「一億元說話術」的具體技巧之前，先透過本章節來改變你的金錢觀念。

這裡想詢問大家：

- 「你是『認真』想成為年收一億的人嗎？」

許多人聽到「想不想年收一億？」這個問題，大概會回答：「想」吧。因為大家會覺得有錢不會傷腦筋，而且有錢就能做自己想做的事情。但如果加了「認真」兩字，大家就會猶豫了。

我在二十六歲還是上班族的時候，去聽了出版《成功的 9 個步驟》（台灣未出版）一書的知名成功人士——詹姆斯·斯金納的演講。他在演講中問了一個問題。

「你希望年收多少？」

當時我在紙上寫「我想要一千萬元」。結果他說：

「如果你現在寫一千萬或兩千萬，那你就是一個自私的人」。

當時我心想：「咦？現在確實不太景氣，想要年收一千萬真的很自私呢，稍微降低一點吧。」

結果斯金納又說：「如果你現在想降低自己的期望年收，那你真的非常自私，因為年收一兩千萬就能滿足的人，內心只想到自己，認為自己幸福就夠了。但，如果你想幫助周圍的人，想要對社會帶來貢獻的話，這樣的收入真的足夠嗎？」

這件事情大幅改變了我對收入的觀念。他又接著說：

「請在你的期望年收後面多加一個零。你期望的是自由，目標是否貼近現實並不重要。就算目標不切實際，只要讓計畫貼近現實就好。人生只能得到自己期望的東西。先試著從放大期望開始吧。」

如果不是因為這場演講改變了我對金錢的觀念，恐怕我也不會真心想賺到年收一億元吧。當然我不會說以一億元為目標就是正確答案。再重新問你一次。

你是「認真」想年賺一億元嗎？

多數人可能會說：「應該也做不到認真的地步啦……」。說明白點，就算有一億元，你可能也不知道該怎麼花。

本書開頭也說過，年收一億元的人，不是一開始就以此為目標。大多數的人都是認真做好眼前的工作，不知不覺就成了年收一億元的人。

有了這個前提之後，可以看見左邊和右邊的象限在概念上就有非常大的差異。

左邊象限的工作方式是將時間變成金錢；右邊象限則是將時間變成方法。變成方法是指擁有不動產、自己的事業、長期投資股票，或招募同伴創業等。

細節先不談，四大象限如果想賺到年收入一億元，必須靠下列方法：

# 你想用時間換取金錢，還是用時間換取賺錢的方法？

- **E象限（雇員）**：

以成為受聘總經理一職為目標，或到外商等可期待有高額年薪的地方工作。

- **S象限（自營業）**：

高單價的工作，具體如法律或稅務等。重點是從事專業性強，無法輕易被取代的工作。

- **B 象限（大企業老闆）**：

    1. 擁有自動化的系統：如網拍事業或Youtube等。只要建立起一套固定的工作流程後，接下來在方法上努力即可。
    2. 擁有事業團隊：招募相信且支持自己的夥伴。關鍵在於要有人望，讓比自己優秀的人能夠信任你。

- **C 象限（投資者）**：

尋找優秀的投資夥伴，持續投資優良標的。大多數情況下，很難一次拿出一大筆錢來投資，所以可以小筆累積投資金額，或從事某方面的事業賺錢後，再拿賺到的錢繼續投資，投資的收益可和其他象限相乘。

這四大象限之中，最需要溝通能力的就是——大企業老闆的②「擁有事業團隊」

最知名的則是人稱「鋼鐵大王」的安德魯·卡內基 (Andrew Carnegie)的事蹟。他的墓誌銘上寫著：「長眠於此的人，善於讓比他優秀的人為他工作。」從這裡可以看出，他是如何藉助眾人的力量獲得成功。

另外，福特汽車的創始人亨利·福特 (Henry Ford) 也有一段有名的趣聞。某次，有一群優秀的金融人士刻意問福特一些困難的問題。對只有高中畢業的福特來說，這些問題很難回答。金融人士得意洋洋的想看他出糗，但福特卻如此回答：「雖然我無法回答你的問題，但我可以在五分鐘之內，找到能解答的人。」

由此可知，不只是福特和卡內基，大部分的偉大企業經營者，幾乎都是善於交際的天才。

有許多人即便沒有名氣，但依舊能造救出巨大的成果，這樣的人大部分都善於交際。跟他們講話會感到非常有趣，也會想與他們相處。這是因為他們都有過人的溝通能力。

# 溝通能力是CP值最高的軟實力

你知道「評價（信用／經濟社會）」這個詞嗎？

至今的主流是「資本主義經濟」，說的就是擁有「資本＝金錢」的人最偉大、企業家或資本家最偉大的思考方式。

然而，這種資本主義經濟的思維在現代社會會有很大的變化。換句話說，社會的觀念開始改變，認為有些事物比金錢更有價值，那就是「社會評價」與「知名度」。就算身無分文，只要具備這兩個條件，就能不停挑戰新事物，過著十分豐足的生活。

舉例來說，如果在社群網站上有一百萬人追蹤，那要賺到一億元就不是一件難事。但即使你花費一億元，也很難讓一百萬人願意追蹤你。

更進一步來說，即便是眾所皆知的人物，大家願意追隨，通常會和該人物的「信用度」成正比，而不是單靠「知名度」。這是因為大家並不會為了知名度而買單。

經常會看見許多名人嘗試建立付費社群，但結果落入根本沒人願意加入的窘境。很遺憾的，現在光靠高知名度已經賺不到錢了。換句話說，現今社會最重視的就是：

# 「知名度×信用度」

知名度就是「範圍」，信用度則是「深度」，兩者相乘決定你的收入，這也稱為「信用經濟」。

聽起來有些矛盾，但如果你想賺大錢，最重要的就是要有信用，而不是埋頭苦幹的拚命賺錢。只要贏得足夠的信用，要增加收入就不是太困難的事情。

如果你已經有一定程度的資產或金錢，或許就不需要在評價（信用）經濟社會中奮鬥了。

但如果你是白手起家，那麼獲取信用成為眾人支持的存在，會是成為年收一億元的最快捷徑。
