# 學會這四招，就能輕鬆吸引初次見面的人

與人邂逅當然很重要，但在那之前必須思考一件事。那就是「從對方的角度來看，你會是他想認識的人嗎？」

相信許多人在校園這種封閉環境中，都曾聽過「大家好相處」這句話。但就連在封閉環境內，都很難和所有人保持良好的關係吧。出了社會後，會遇到形形色色的人，使得人際關係變得更加複雜，因此很難只藉著相遇，就讓感情立刻變好。

這是因為大家都不是學生的身分，對方並不會積極的想和你好好相處。這時，你必須做的第一件事就是——讓對方覺得「遇見你真好」。

拓展人脈特別重視「第一印象」。

甚至有心理學家表示，除非雙方有進一步接觸，否則第一印象會維持三年的時間。由此可見，第一印象有多麼重要，所以想拓展人脈，就必須提升自己的第一印象。

針對以下四點，請試著思考如何提升第一印象。

- ① 儀容
- ② 笑容
- ③ 反應
- ④ 感謝（寒暄）

# 如何提升第一印象？

### ①儀容

舉例來說，你會想買沒貼任何標籤的瓶裝水來喝嗎？一般來說，你應該會很害怕，不敢購買也不敢飲用才對。一瓶水的瓶身如果有貼標籤寫「好喝的水」或「○○天然水」，相信你就會安心購買。

由此可知，外表的影響力就是如此巨大。所以你的儀容當然也會造成很大的影響。儀容不佳的人，在交談前會先被貼標籤，對方就連想和你深交的念頭都不會有。你的打扮或許有自己的風格，但在對方眼中，那可能不是打扮，而是一種單純的「自我感覺良好」。

儀容最重要的標準就是「對方的感受」。

### ②笑容

假設你在便利商店，店員有以下兩種反應，你會有什麼感受呢？

(1)只說：「歡迎光臨」
(2)露出笑容說：「歡迎光臨」
肯定是(2)會讓你有好印象，而且還會想要再度光顧。就連便利商店的待客之道都展現出：一個小小的笑容絕對會改變印象。
所以才會說，笑容是上天賦予人類最強的武器。你知道為什麼嬰兒和父母對上眼就會露出笑容嗎？這就是人類與生俱來的「社會性微笑」。換句話說，人類天生就具備了微笑的能力。
這邊要詢問一個問題：「你曾經練習過笑容嗎？」每個人都知道笑容很重要，可是卻很少人練習如何展現笑容。其實若能展現甜美笑容，就會比周圍的人更有機會。我從事講師工作時，常有機會看到後台的真實模樣。有不少講師在上台演講之前，都會先舒展臉部肌肉。因為臉部的肌肉跟身體一樣，不動就會變得僵硬。
甜美笑容的訣竅就在於：眼角下垂和嘴角上揚，如此而已。請務必在鏡子前進行練習。

### ③反應

我在自己的講座課程中，經常告訴大家「反應是一種愛的表現」。試著想像一下，假設你和最愛的人約會，你拚命找話題聊天，但很遺憾的是，對方看起來毫無反應，不知道有沒有在聽你說話。

你覺得對方愛你嗎？想必你應該感受不到自己被愛、被重視吧。反應是關心和用愛接觸對方的證明。

日本人尤其不擅長做反應。剛開始做反應時，你可以比平常誇張兩倍，等習慣之後，再增加其他類型的反應吧。一直用相同的反應，對方不會覺得你在聽他說話。不要只說「對」，也可以用「原來如此」或「好厲害」之類的話語來附和對方。

重複對方的話也非常有效。舉例來說，上司指示你做某件事時，可以複誦一遍：「○○嗎？我知道了！」光是這樣的反應，對方的印象就會大幅改變。

請記住：「反應是一種愛的表現」。

### ④ 感謝 （寒暄）

早上進公司，遇到有人用陰沉的聲音和你說早安，你的感受如何呢？再進一步來說，如果對方連招呼都不打呢？

寒暄是人際關係的基本，也是決定第一印象的要因。沒有比用開朗的聲容和笑容寒暄，更能快速提升第一印象的方法了。

順帶一提，一般認為會讓人留下好印象的音域是「Fa」和「Sol」。不用太精準，請試著發出「Do、Re、Mi、Fa、Sol」後，再用「Fa」和「Sol」範圍的音域發聲即可。換句話說，音調可以「稍微」高一點。

要提升第一印象，寒暄確實非常重要，但我還想再附加一點，那就是「感謝」。

感謝的話語有如魔法般，能使人打開心房。因此，與對方見面打招呼時，希望大家可以嘗試著傳達感謝的心情，如「今天很高興能見到你，謝謝你」。

題外話，我一個在當老闆的朋友，他接電話的第一句不是「喂」，而是「感謝來電」。我模仿他的方法後，感覺人際關係變好了。

與人碰面時，傳達感謝是很正常的，感謝對方願意花時間與精力和自已碰面，試著從「謝謝」開始建立人際關係如何呢？

仔細觀察上述四點，會發現都是表面工夫。正如前述，人類在看內在前，會先從肉眼看得見的地方來判斷第一印象。外表不全然代表一個人，這句話百分之百正確。但請意識到，對方會先用外觀審視，之後才會看見內在。

不過當你在觀察一個人的時候，有一點希望你能注意。雖然聽起來很矛盾，但請你別用外表去判斷對方。

請退一步想想，一個人很難永遠將開朗快樂的一面展現給別人看。只要是人，難免會有心情不好、態度不佳的時候。你對某人的第一印象，有可能是那天他剛好身體狀況不佳。

所以，我希望你努力提升自己的第一印象，但不要用第一印象去決定一個人。因為一定會有第一印象不太好，卻能和你往來一輩子的人。

為了拓展人脈，重點在於努力提升自己的第一印象，然後不要用第一印象去判斷他人。

# 億萬富翁都懂得「體貼」和「貼心」

人脈廣的人大多都懂得「體貼」和「貼心」。眼懂得體貼和貼心的人在一起會很舒服，所以眾人會聚集在他們身旁，這點無庸置疑。但意外的是，在這個時代有許多人做不到。

你有想過體貼和貼心有多麼重要嗎？我和一位我尊敬的企业經營者一起吃飯時，第一個注意到杯子空了，並幫大家倒水的人，是我的直屬導師。他比店員和其他人早一步注意到這件事。

能觀察四周環境並注意到身旁的人是否感到困擾，且適時的提供協助，這就是一種體貼的表現。

體貼的程度會決定一個人是否成功。因為一帆風順的人也很擅長體貼別人。由此可見，「覺察力」會成為工作或人際關係的必備能力。

作家兼研究人員的山口周老師，在《成為新人類》這本書中提到，在現今社會，相較於「解決問題的能力」，會更需要「發現問題的能力」。他所謂的「發現問題的能力」，指的就是「覺察力」。

那什麼是貼心呢？以刪才的飯局為例，假設大家聊得非常開心。在這種情況下，不去打斷談話，並且為了能讓對方暢所欲言，於是刻意集中精神聆聽對方說話，即使想去倒水也先忍住，這就是一種貼心。

換句話說，貼心就是「替對方著想」的能力。推測對方的想法和感受，並做會使他開心的事情。懂得貼心的人，能得到所有人的尊敬。

有一次，我的朋友舉辦出版紀念演講，他和牙科醫師兼作家的井上裕之醫師只見過一次面，但井上醫師卻專程送了大花圈來祝賀。這正是一種貼心的舉動。就算人不在現場，一樣會去思考怎麼做才會讓對方開心。所以井上醫師受到許多人的信任和支持。簡單來說：

「體貼」：考量現場狀況，減少困擾的事情。
「貼心」：重視對方的行為。

能一起做到體貼和貼心當然最好，不行的話，可以先從體貼開始學習。因為體貼是「去意識現場發生的事情」，所以任何人都做得到。為此，你需要具備「三種眼」。

# 為什麼億萬富翁不會說「下次再約」？

「謝謝你。我們下次再約時間見面。」看著某位男性精神抖擻的離開後，我的導師對我說：

「他還需要再磨練一段時間。」

剛才我們明明聊得很開心，對方也沒留下半點不好的印象，所以聽到這句話，我感到很意外。

「為什麼？」

他離開前說：「我們下次再約時間見面」，對吧？沒有一種機會叫「下次」。有句話說：「明確就是力量」，用詞模糊可只會招來模糊的結果；反過來說，說話明確就會得到明確的結果。如果你真的想和對方再次碰面，應該要說：『我希望還能與您見面，我可以調整一下行程後，晚點與您聯絡嗎？』或是問：『下個月有空嗎？』『諸如此類。如果想要藉助我的力量，那至少要當場約下次見面的時間，或是跟對方說好會另外約時間，讓雙方有下次見面的機會再離開才對。」

你或許會覺得對方這麼忙，一直跟對方聯絡不太好意思。但成功者其實意外的有時間。甚至有時候你開口麻煩他們，他們還會爽快答應。

會受人喜愛的人都有一些特質，那就是「開朗」、「坦率」、「有朝氣」和「厚臉皮」。

總是很客氣的話，是不會受人喜愛的。因為成功者不會因為你在旁邊等待，就主動出手協助。你必須主動才能抓住機會。

順帶一提，後來我聽說那位男性事後連一封感謝信都沒有寄。這樣的話，如此難得的緣分就會很難延續下去。
