# ③反應

我在自己的講座課程中，經常告訴大家「反應是一種愛的表現」。試著想像一下，假設你和最愛的人約會，你拚命找話題聊天，但很遺憾的是，對方看起來毫無反應，不知道有沒有在聽你說話。

你覺得對方愛你嗎？想必你應該感受不到自己被愛、被重視吧。反應是關心和用愛接觸對方的證明。

日本人尤其不擅長做反應。剛開始做反應時，你可以比平常誇張兩倍，等習慣之後，再增加其他類型的反應吧。一直用相同的反應，對方不會覺得你在聽他說話。不要只說「對」，也可以用「原來如此」或「好厲害」之類的話語來附和對方。

重複對方的話也非常有效。舉例來說，上司指示你做某件事時，可以複誦一遍：「○○嗎？我知道了！」光是這樣的反應，對方的印象就會大
