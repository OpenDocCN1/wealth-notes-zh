知音体就是，恶搞《知音》杂志的标题风格给一些经典故事改题目。

《嫦娥奔月》——《铸成大错的逃亡爱妻啊，射击冠军的丈夫等你悔悟归来》

《牛郎织女》——《苦命村娃离千女——一段被狠心岳母拆散的惊世恋情》

《唐伯虎点秋香》——《我那爱人打工妹哟，博士后为你隐姓埋名化身农民工》

《杨玉环》——《公爹变丈夫，一缕香魂散——妖媚贵妇命断鸳鸯绊》

《花木兰》——《震撼天地——孝顺女为父从军甘当魔鬼女大兵》

《白雪公主》——《苦命的妹子啊，七个义薄云天的哥哥为你撑起小小的一片天》
