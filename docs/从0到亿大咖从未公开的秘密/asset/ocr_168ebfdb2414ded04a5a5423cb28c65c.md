# 微信三级分销是一套怎样的体系？

分三级分销员，自己往下可以发展一级分销员、二级分销员和三级分销员，每一级都有相应的佣金比例。一级分销员、二级分销员和三级分销员在商品交易成功后所产生的佣金利润也会按佣金比例进行分润。
