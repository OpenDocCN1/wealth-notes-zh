# 洛克菲勒的第一份工作

洛克菲勒踏入社會後的第一份工作，就是在一家名叫「休威．泰德」的公司當書記員。這也是他精於計算的良好的開始。

在「休威．泰德」的第三年，<u>洛克菲勒</u>已經對於經營貿易的要訣，掌握得十之八九了，並且對於這一個行業是躍躍欲試。在這一年之中，<u>洛克菲勒</u>未經老闆的同意，就自作主張的做起了小麥粉與火腿的生意。不久之後，新聞報導饑荒在英國發生了，這使他的計劃得到了實現的契機。
