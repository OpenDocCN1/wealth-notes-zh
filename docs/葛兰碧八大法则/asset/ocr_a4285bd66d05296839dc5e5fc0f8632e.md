# ☆、信奉魚頭理論

一對資產逾億的夫妻檔，化名「堅夫贏富」，在分析他們的 致富術時說：「我向來是信奉魚頭理論；一條魚不要想從魚頭吃 到魚尾；我吃中間的魚肉就夠了！」這對夫妻在證券市場上是極 爲冷靜，不貪多，也沒有受過重傷，長期下來是持盈保泰。

如果是沃爾瑪的股票，長期持有會比較賺的；其次的選擇才 是波段操作 (swing trading)，再其次是當日沖銷交易 (day trading)。

過多資訊導致執行上的優柔寡斷 (analysis Paralysls)

這是說，投資人對於支微末節的事情，過於熱衷，常常弄得 自己困惑不已，而使自己無法在第一時間採取行動；或者是操盤 手的過於專注於——要抓到市場的轉折點，弄得猶豫不決，錯過 了時機而無法及時的採取有利行動來。
