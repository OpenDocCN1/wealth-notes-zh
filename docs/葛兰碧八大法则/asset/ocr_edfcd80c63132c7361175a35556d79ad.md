# ☆。巴菲特熱愛工作的過程

熱愛工作的人，多能在自己所屬的領域中出人头地；這是因為他們熱愛工作的過程，遠多於後來的金錢報酬。

不過，有趣的是，財富往往是隨著工作的熱忱而來。如果一個人愛錢超過他的工作，他們通常是會工作得很不愉快——後來，他們所賺到的錢，也會比那些熱愛自己工作的人賺的少很多。

巴菲特就經常指出：他熱愛自己的工作，甚至願意付錢來從事這一份事業。不過，他倒是沒這個必要——理由是 his 的工作已經爲他帶來可觀的財富了！
