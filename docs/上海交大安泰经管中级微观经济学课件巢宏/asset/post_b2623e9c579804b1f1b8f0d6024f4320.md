
## Examples of Returns-to-Scale

The perfect-substitutes production function is

y = a₁x₁ + a₂x₂ + ... + aₙxₙ.

Expand all input levels proportionately by k. The output level becomes

a₁(kx₁) + a₂(kx₂) + ... + aₙ(kxₙ).

![](img/e3f3f402f74cf453caf4596d2d7d7398_931_0.png)

The perfect-substitutes production function is

```
y = a₁x₁ + a₂x₂ + ... + aₙxₙ.
```

Expand all input levels proportionately by k. The output level becomes

```
a₁(kx₁) + a₂(kx₂) + ... + aₙ(kxₙ).
= k(a₁x₁ + a₂x₂ + ... + aₙxₙ)
= ky
```

The perfect-substitutes production function exhibits constant returns-to-scale.

![](img/e3f3f402f74cf453caf4596d2d7d7398_932_0.png)

The perfect-complements production function is

y = min{a₁x₁, a₂x₂, …, aₙxₙ}.

Expand all input levels proportionately by k. The output level becomes

min{a₁(kx₁), a₂(kx₂), …, aₙ(kxₙ)}.

![](img/e3f3f402f74cf453caf4596d2d7d7398_933_0.png)

The perfect-complements production function is

$$y=\min\{a_1x_1,a_2x_2,\cdots,a_nx_n\}.$$

Expand all input levels proportionately by k. The output level becomes

$$\min\{a_1(kx_1),a_2(kx_2),\cdots,a_n(kx_n)\}.$$ 
$$=ky$$

The perfect-complements production function exhibits constant returns-to-scale.

![](img/e3f3f402f74cf453caf4596d2d7d7398_934_0.png)

The Cobb-Douglas production function is

$$y=x_1^{a_1}x_2^{a_2}\cdots x_n^{a_n}.$$

Expand all input levels proportionately by k. The output level becomes

$$(kx_1)^{a_1}(kx_2)^{a_2}\cdots(kx_n)^{a_n}$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_935_0.png)

**The Cobb-Douglas production function is**

$$y=x_1^{a_1}x_2^{a_2}\cdots x_n^{a_n}.$$

**Expand all input levels proportionately by k. The output level becomes**

$$(kx_1)^{a_1}(kx_2)^{a_2}\cdots(kx_n)^{a_n}$$

$$=k^{a_1}k^{a_2}\cdots k^{a_n}x_1^{a_1}x_2^{a_2}\cdots x_n^{a_n}$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_936_0.png)

The Cobb-Douglas production function is

```
y = x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}.
```

Expand all input levels proportionately by k. The output level becomes

```
(k x₁)^{a₁} (k x₂)^{a₂} ⋯ (k xₙ)^{aₙ}
```

```
= k^{a₁} k^{a₂} ⋯ k^{aₙ} x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}
```

```
= k^{a₁+a₂+⋯+aₙ} x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}
```

![](img/e3f3f402f74cf453caf4596d2d7d7398_937_0.png)

The Cobb-Douglas production function is

```
y = x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}.
```

Expand all input levels proportionally by k. The output level becomes

```
(k x₁)^{a₁} (k x₂)^{a₂} ⋯ (k xₙ)^{aₙ}
= k^{a₁} k^{a₂} ⋯ k^{aₙ} x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}
= k^{a₁ + a₂ + ⋯ + aₙ} x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}
= k^{a₁ + ⋯ + aₙ} y.
```

![](img/e3f3f402f74cf453caf4596d2d7d7398_938_0.png)

The Cobb-Douglas production function is

```
y = x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}.
```

```
(k x₁)^{a₁} (k x₂)^{a₂} ⋯ (k xₙ)^{aₙ} = k^{a₁+⋯+aₙ} y.
```

The Cobb-Douglas technology’s returns-to-scale is

constant if a₁ + ... + aₙ = 1

![](img/e3f3f402f74cf453caf4596d2d7d7398_939_0.png)

# The Cobb-Douglas production function is

$$y=x_1^{a_1}x_2^{a_2}\cdots x_n^{a_n}.$$

$$(kx_1)^{a_1}(kx_2)^{a_2}\cdots(kx_n)^{a_n}=k^{a_1+\cdots+a_n}y.$$

# The Cobb-Douglas technology’s returns-to-scale is

- **constant** if $a_1+\cdots+a_n=1$
- **increasing** if $a_1+\cdots+a_n>1$

![](img/e3f3f402f74cf453caf4596d2d7d7398_940_0.png)

# The Cobb-Douglas production function is

y = x₁^{a₁} x₂^{a₂} ⋯ xₙ^{aₙ}.

(k x₁)^{a₁} (k x₂)^{a₂} ⋯ (k xₙ)^{aₙ} = k^{a₁+⋯+aₙ} y.

# The Cobb-Douglas technology’s returns-to-scale is

- constant if a₁ + ... + aₙ = 1
- increasing if a₁ + ... + aₙ > 1
- decreasing if a₁ + ... + aₙ < 1.
