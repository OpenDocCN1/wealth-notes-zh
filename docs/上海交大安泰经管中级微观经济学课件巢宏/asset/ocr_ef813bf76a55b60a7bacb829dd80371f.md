# Markup Pricing

$$p(y^*)\left[1+\frac{1}{\varepsilon}\right]=k \quad\Rightarrow\quad p(y^*)=\frac{k}{1+\frac{1}{\varepsilon}}=\frac{k\varepsilon}{1+\varepsilon}$$

is the monopolist’s price. The markup is

$$\frac{1}{1+\frac{1}{\varepsilon}}=\frac{\varepsilon}{1+\varepsilon}.$$
