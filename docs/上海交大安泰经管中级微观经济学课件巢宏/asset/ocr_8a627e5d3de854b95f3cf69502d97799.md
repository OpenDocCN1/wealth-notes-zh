# Short-Run Profit-Maximization;  
A Cobb-Douglas Example

**Solving** \(\frac{p}{3}(x_1^*)^{-2/3}\tilde{x}_2^{1/3}=w_1\) **for** \(x_1\) **gives**

\[(x_1^*)^{-2/3}=\frac{3w_1}{p\tilde{x}_2^{1/3}}.\]

**That is,**

\[(x_1^*)^{2/3}=\frac{p\tilde{x}_2^{1/3}}{3w_1}\]

**so**

\[x_1^*=\left(\frac{p\tilde{x}_2^{1/3}}{3w_1}\right)^{3/2}=\left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}.\]
