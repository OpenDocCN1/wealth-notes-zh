# Mixed Strategies

Player B

|  | L, π<sub>L</sub> | R, 1−π<sub>L</sub> |
|---|---|---|
| U, π<sub>U</sub> | (1,2) | (0,4) |
| D, 1−π<sub>U</sub> | (0,5) | (3,2) |

A’s expected value of choosing Up is π<sub>L</sub>.

A’s expected value of choosing Down is 3(1 − π<sub>L</sub>).

If π<sub>L</sub> < 3(1 − π<sub>L</sub>) then A will choose only Down, but there is no NE in which A plays only Down.
