# Mixed Strategies

Player B

L, 3/4    R, 1/4

Player A

U, 3/5

D, 2/5

|  | L, 3/4 | R, 1/4 |
|---|---|---|
| U, 3/5 | (1,2) | (0,4) |
| D, 2/5 | (0,5) | (3,2) |

If there is a NE then necessarily 2π_U + 5(1 - π_U) = 4π_U + 2(1 - π_U) ⇒ π_U = 3/5; i.e. the way A mixes over Up and Down must make B indifferent between choosing Left or Right.
