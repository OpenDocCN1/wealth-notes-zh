# Long-Run Profit-Maximization

So given the prices \(p\), \(w_1\) and \(w_2\), and the production function
\[
y=x_1^{1/3}x_2^{1/3}
\]

the long-run profit-maximizing production plan is

\[
(x_1^*,x_2^*,y^*)=\left(\frac{p^3}{27w_1^2w_2},\frac{p^3}{27w_1w_2^2},\frac{p^2}{9w_1w_2}\right).
\]
