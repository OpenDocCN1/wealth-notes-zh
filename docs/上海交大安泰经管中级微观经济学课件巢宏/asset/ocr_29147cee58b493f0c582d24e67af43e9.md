# Application — rebating a tax

+   ◆ 1. put a tax on gasoline and return the revenues
+   ◆ 2. original budget constraint: $px^* + y^* = m$
+   ◆ 3. after tax budget constraint: $(p + t)x' + y' = m + tx'$
+   ◆ 4. so consumption after tax satisfies $px' + y' = m$
+   ◆ 5. so (x, y) was affordable originally and rejected in favor of $(x^*, y^*)$
+   ◆ 6. consumer must be worse off
