# The Long-Run and the Short-\nRuns

$y = x_1^{1/3}x_2^{1/3}$ is the long-run production function (both $x_1$ and $x_2$ are variable).

The short-run production function when $x_2 = 1$ is

$y = x_1^{1/3}1^{1/3} = x_1^{1/3}$.

The short-run production function when $x_2 = 10$ is

$y = x_1^{1/3}10^{1/3} = 2.15x_1^{1/3}$.
