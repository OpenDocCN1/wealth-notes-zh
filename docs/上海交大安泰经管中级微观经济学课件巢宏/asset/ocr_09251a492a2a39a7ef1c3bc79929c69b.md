= p ( p / 3 w₁ )^{1/2} x̃₂^{1/2} − w₁ ( p / 3 w₁ )^{3/2} x̃₂^{1/2} − w₂ x̃₂

= p ( p / 3 w₁ )^{1/2} x̃₂^{1/2} − w₁ p / 3 w₁ ( p / 3 w₁ )^{1/2} − w₂ x̃₂

= 2p / 3 ( p / 3 w₁ )^{1/2} x̃₂^{1/2} − w₂ x̃₂
