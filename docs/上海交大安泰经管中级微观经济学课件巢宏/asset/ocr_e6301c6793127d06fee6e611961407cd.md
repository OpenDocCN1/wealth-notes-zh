# Returns-to-Scale

If, for any input bundle $(x_1,\ldots,x_n)$,

$$f(kx_1,kx_2,\cdots,kx_n)>kf(x_1,x_2,\cdots,x_n)$$

then the technology exhibits **increasing returns-to-scale.**

***E.g.*** (k = 2) doubling all input levels more than doubles the output level.
