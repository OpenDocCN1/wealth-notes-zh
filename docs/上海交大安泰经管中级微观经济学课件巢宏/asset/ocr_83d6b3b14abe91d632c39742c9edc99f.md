# Monopolistic Pricing & Own-Price Elasticity of Demand

Notice that, since $MR(y^*) = p(y^*)\left[1 + \frac{1}{\varepsilon}\right] = k,$

$p(y^*)\left[1 + \frac{1}{\varepsilon}\right] > 0 \ \Rightarrow\ \ 1 + \frac{1}{\varepsilon} > 0$

That is, $\frac{1}{\varepsilon} > -1 \ \Rightarrow\ \ \varepsilon < -1.$
