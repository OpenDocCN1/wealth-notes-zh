## 理性受限选择

- $(x_1^*, x_2^*)$ 满足两个条件：
- (a) 预算被耗尽；
  $$p_1x_1^* + p_2x_2^* = m$$
- (b) 预算约束的斜率 $-p_1/p_2$，以及包含 $(x_1^*, x_2^*)$ 的无差异曲线的斜率在 $(x_1^*, x_2^*)$ 处相等。

## 计算普通需求 - 一个柯布-道格拉斯示例。

- ◆ 假设消费者具有柯布-道格拉斯偏好。

U(x₁, x₂) = x₁ᵃ x₂ᵇ

![](img/e3f3f402f74cf453caf4596d2d7d7398_178_0.png)

- ◆ 假设消费者具有柯布-道格拉斯偏好。

U(x₁, x₂) = x₁ᵃ x₂ᵇ

- ◆ 那么    MU₁ = ∂U/∂x₁ = a x₁ᵃ⁻¹ x₂ᵇ

MU₂ = ∂U/∂x₂ = b x₁ᵃ x₂ᵇ⁻¹

![](img/e3f3f402f74cf453caf4596d2d7d7398_179_0.png)

◆ 所以边际替代率是

MRS = dx₂/dx₁ = − (∂U/∂x₁)/(∂U/∂x₂) = − (a x₁^{a−1} x₂^{b})/(b x₁^{a} x₂^{b−1}) = − (a x₂)/(b x₁).

![](img/e3f3f402f74cf453caf4596d2d7d7398_180_0.png)

◆ 所以边际替代率是

MRS = dx₂/dx₁ = - (∂U/∂x₁)/(∂U/∂x₂) = - (a x₁^{a-1} x₂^{b})/(b x₁^{a} x₂^{b-1}) = - (a x₂)/(b x₁).

◆ 在 (x₁*,x₂*) 处，MRS = -p₁/p₂ 所以

- (a x₂*)/(b x₁*) = - p₁/p₂ ⇒ x₂* = (b p₁)/(a p₂) x₁*.

(A)

![](img/e3f3f402f74cf453caf4596d2d7d7398_181_0.png)

♦ (x₁*,x₂*) 也耗尽了预算所以

p₁x₁* + p₂x₂* = m.    (B)

◆ 所以现在我们知道

x₂* = (b p₁)/(a p₂) x₁*   (A)

p₁ x₁* + p₂ x₂* = m.   (B)

![](img/e3f3f402f74cf453caf4596d2d7d7398_183_0.png)

◆ 所以现在我们知道

$$x_2^* = \frac{b p_1}{a p_2}x_1^*$$  (A)

代入

$$p_1x_1^* + p_2x_2^* = m.$$  (B)

得到

$$p_1x_1^* + p_2\frac{b p_1}{a p_2}x_1^* = m.$$

这简化为 ...

x₁* = (a m) / ((a + b) p₁).

# 将 x₁* 代入

p₁ x₁* + p₂ x₂* = m

# 然后得到

x₂* = (b m) / ((a + b) p₂).

![](img/e3f3f402f74cf453caf4596d2d7d7398_185_0.png)

所以我们发现了，对于具有柯布-道格拉斯偏好的消费者

U(x₁, x₂) = x₁ᵃ x₂ᵇ

最优可负担组合为

(x₁*, x₂*) = ( am / (a + b)p₁ , bm / (a + b)p₂ ).

![](img/e3f3f402f74cf453caf4596d2d7d7398_186_0.png)

## 理性受限选择

- ◆ 当 $x_1^* > 0$ 且 $x_2^* > 0$
- 且 $(x_1^*,x_2^*)$ 耗尽了预算，
- 且偏好是凸的，
- 且无差异曲线没有“拐点”，普通需求可通过求解以下问题得到：

- ◆ (a) $p_1x_1^* + p_2x_2^* = y$

- ◆ (b) 预算约束的斜率 $-p_1/p_2$，以及包含 $(x_1^*,x_2^*)$ 的无差异曲线的斜率在 $(x_1^*,x_2^*)$ 处相等。

## 理性受限选择

- 但如果 $x_1^* = 0$ 呢？
- 或如果 $x_2^* = 0$ 呢？
- 如果 $x_1^* = 0$ 或 $x_2^* = 0$，则普通需求 $(x_1^*, x_2^*)$ 是在预算约束下最大化效用问题的角点解。
