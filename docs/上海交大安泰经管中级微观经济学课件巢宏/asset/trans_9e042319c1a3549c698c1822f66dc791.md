

## 价格通胀

- 我们令 p₁=1，从而 p₂ = 1+ π，这并不失一般性。
- 于是我们可以将预算约束
  p₁c₁ + (p₂ / 1+r) c₂ = m₁ + (m₂ / 1+r)
  改写为
  c₁ + ((1+π) / 1+r) c₂ = m₁ + (m₂ / 1+r)

c₁ + (1 + π)/(1 + r) c₂ = m₁ + m₂/(1 + r)

可整理为

c₂ = - (1 + r)/(1 + π) c₁ + [(1 + r)m₁ + m₂]/(1 + π)

因此跨期预算约束的斜率为

- (1 + r)/(1 + π)

- 在没有价格通胀（p₁=p₂=1）时，预算约束的斜率为 -(1+r)。
- 现在，存在价格通胀时，预算约束的斜率为 -(1+r)/(1+ π)。这可写为

−(1 + ρ) = − (1 + r) / (1 + π)

ρ 被称为实际利率。

## 实际利率

```
-(1 + ρ) = - (1 + r)/(1 + π)
```

可得

```
ρ = (r - π)/(1 + π).
```

对于低通胀率（π ≈ 0），ρ ≈ r - π。对于较高的通胀率，这一近似会变得不准确。

## 证券估值

- 该证券等价于以下三种证券之和：
  - 第一种只在第1年末支付$m₁，
  - 第二种只在第2年末支付$m₂，以及
  - 第三种只在第3年末支付$m₃。

- 一年后支付的$m₁的现值为 m₁ / (1+r)
- 两年后支付的$m₂的现值为 m₂ / (1+r)²
- 三年后支付的$m₃的现值为 m₃ / (1+r)³
- 因此，该证券的现值为 m₁ / (1+r) + m₂ / (1+r)² + m₃ / (1+r)³。

## 债券估值

- 债券是一种特殊类型的证券，它在 T 年内（其到期日）支付固定金额 $x，然后支付其面值 $F。
- 现在最多应该为这种债券支付多少钱？

![](img/e3f3f402f74cf453caf4596d2d7d7398_589_0.png)

| 年末 | 1 | 2 | 3 | … | T-1 | T |
|---|---:|---:|---:|---:|---:|---:|
| 支付金额 | $x | $x | $x | $x | $x | $F |
| 现值 | $\frac{x}{1+r}$ | $\frac{x}{(1+r)^2}$ | $\frac{x}{(1+r)^3}$ | … | $\frac{x}{(1+r)^{T-1}}$ | $\frac{F}{(1+r)^T}$ |

$$PV = \frac{x}{1+r} + \frac{x}{(1+r)^2} + \frac{x}{(1+r)^3} + \cdots + \frac{x}{(1+r)^{T-1}} + \frac{F}{(1+r)^T}.$$
