# Long-Run Profit-Maximization

What is the long-run profit-maximizing input 1 level? Substitute

$$x_2^* = \frac{p^3}{27w_1w_2^2}$$ into $$x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}$$

to get

$$x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\left(\frac{p^3}{27w_1w_2^2}\right)^{1/2} = \frac{p^3}{27w_1^2w_2}.$$
