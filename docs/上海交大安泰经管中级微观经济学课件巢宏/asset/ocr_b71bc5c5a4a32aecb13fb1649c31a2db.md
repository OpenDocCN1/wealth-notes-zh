# Marginal (Physical) Products

E.g. if

$y = f(x_1, x_2) = x_1^{1/3} x_2^{2/3}$

then the marginal product of input 1 is

$MP_1 = \frac{\partial y}{\partial x_1} = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$

and the marginal product of input 2 is

$MP_2 = \frac{\partial y}{\partial x_2} = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$.
