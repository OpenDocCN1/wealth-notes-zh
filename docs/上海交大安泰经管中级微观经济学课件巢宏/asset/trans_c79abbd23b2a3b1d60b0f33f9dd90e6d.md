

## 囚徒困境

| 邦妮 / 克莱德 | S | C |
|---|---|---|
| S | (-5,-5) | (-30,-1) |
| C | (-1,-30) | (-10,-10) |

这个游戏唯一可信的纳什均衡是克莱德和邦妮在每个时期都选择招供。即使游戏重复进行大量但有限的时期，这也是成立的。

|          | 克莱德 S | 克莱德 C |
|----------|---------|---------|
| 邦妮 S | (-5,-5) | (-30,-1) |
| 邦妮 C | (-1,-30) | (-10,-10) |

然而，如果游戏无限期地重复进行，那么该游戏就有大量可信的纳什均衡。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1784_0.png)

| 邦妮 \ 克莱德 | S | C |
|---|---|---|
| S | (-5,-5) | (-30,-1) |
| C | (-1,-30) | (-10,-10) |

永远选择(C,C)就是这样一个纳什均衡。但(S,S)也可以是一个纳什均衡，因为参与者可以惩罚另一方不合作（即选择招供）的行为。

## 交换

- 两个消费者，A 和 B。
- 他们对商品 1 和 2 的初始禀赋分别是 ω^A = (ω₁^A, ω₂^A) 和 ω^B = (ω₁^B, ω₂^B)。
- 例如，ω^A = (6,4) 且 ω^B = (2,2)。
- 可用总量为：商品 1 有 ω₁^A + ω₁^B = 6 + 2 = 8 单位，商品 2 有 ω₂^A + ω₂^B = 4 + 2 = 6 单位。

埃奇沃思和鲍利设计了一种称为埃奇沃思盒的图形，用以展示两种商品的可利用数量在两个消费者之间的所有可能配置。

## 其他可行配置

- \((x_1^A, x_2^A)\) 表示给消费者 A 的配置。
- \((x_1^B, x_2^B)\) 表示给消费者 B 的配置。
- 一个配置是可行的，当且仅当
  \[
  x_1^A + x_1^B \leq \omega_1^A + \omega_1^B
  \]
  且
  \[
  x_2^A + x_2^B \leq \omega_2^A + \omega_2^B.
  \]
