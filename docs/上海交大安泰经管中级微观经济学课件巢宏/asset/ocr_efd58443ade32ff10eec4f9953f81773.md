# Mixed Strategies

|  | Player B |  |
|---|---|---|
|  | L, 3/4 | R, 1/4 |
| Player A |  |  |
| U, π_U | (1,2) | (0,4) |
| D, 1-π_U | (0,5) | (3,2) |

B’s expected value of choosing Left is 2π_U + 5(1 - π_U).

B’s expected value of choosing Right is 4π_U + 2(1 - π_U).

If 2π_U + 5(1 - π_U) < 4π_U + 2(1 - π_U) then B plays only Right, but there is no NE where B plays only Right.
