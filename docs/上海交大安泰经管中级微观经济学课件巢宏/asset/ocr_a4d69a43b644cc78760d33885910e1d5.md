# A Perfect Complements Example of Cost Minimization

The firm’s production function is y = min{4x₁, x₂}

and the conditional input demands are x₁*(w₁, w₂, y) = y/4 and x₂*(w₁, w₂, y) = y.

So the firm’s total cost function is c(w₁, w₂, y) = w₁ x₁*(w₁, w₂, y) + w₂ x₂*(w₁, w₂, y) = w₁ y/4 + w₂ y = (w₁/4 + w₂) y.
