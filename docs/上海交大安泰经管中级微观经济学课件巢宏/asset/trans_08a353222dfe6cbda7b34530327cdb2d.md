## 两部分关税

◆ **垄断者在采用两部分关税时，通过将单位价格 p₂ 设为边际成本，并将一次性费用 p₁ 设为消费者剩余来最大化其利润。**

![](img/e3f3f402f74cf453caf4596d2d7d7398_1532_0.png)

## 两部分关税

+   ♦ 利润最大化的两部分关税产生一种有效市场结果，其中垄断者获得的利润为所有交易收益之和。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1533_0.png)

## 垄断竞争

+   - 罕见见到纯粹垄断，其他企业可能通过生产类似产品进行竞争。
+   - 含义：
+     - 垄断者仍具有市场力量 – 需求向下倾斜
+     - 来自类似产品的竞争使利润降为零。
+     - 为最小化竞争，企业会努力差异化产品。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1535_0.png)

## 差异化产品

+   - 在许多市场中，交易的商品非常接近，但不是完全的替代品。
+   - *例如，* T 恤、手表、汽车和饼干的市场。
+   - 因此每个单独的供应商都具有一定的“垄断力量”。
+   - 这种市场的均衡看起来如何？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1536_0.png)

## 差异化产品

+   - 自由进入 ⇒ 每个卖家的利润为零。
+   - 利润最大化 ⇒ 每个卖家的 MR = MC。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1538_0.png)
