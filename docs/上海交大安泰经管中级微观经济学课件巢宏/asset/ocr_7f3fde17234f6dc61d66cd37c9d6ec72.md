# An Example of a Two-Player Game

Player B
L R

Is (U,R) a likely play?

Player A
U
D

|  | L | R |
|---|---|---|
| U | (3,9) | (1,8) |
| D | (0,0) | (2,1) |

If B plays Right then A’s best reply is Down since this improves A’s payoff from 1 to 2. So (U,R) is not a likely play.
