# Profit-Maximization; An Example

At the profit-maximizing output level y*, MR(y*) = MC(y*). So if p(y) = a - by and if c(y) = F + αy + βy² then

MR(y*) = a − 2by* = α + 2βy* = MC(y*)

and the profit-maximizing output level is

$$y^* = \frac{a - \alpha}{2(b + \beta)}$$
