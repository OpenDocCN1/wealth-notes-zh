

## 边际（物理）产品

例如，如果

$y = f(x_1, x_2) = x_1^{1/3} x_2^{2/3}$

则投入 1 的边际产品为

$MP_1 = \frac{\partial y}{\partial x_1} = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$

投入 2 的边际产品为

$MP_2 = \frac{\partial y}{\partial x_2} = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$。

通常一种投入的边际产品取决于其他投入的使用量。例如，如果

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ 则，

如果 $x_2 = 8$，$MP_1 = \frac{1}{3} x_1^{-2/3} 8^{2/3} = \frac{4}{3} x_1^{-2/3}$

如果 $x_2 = 27$ 则

$MP_1 = \frac{1}{3} x_1^{-2/3} 27^{2/3} = 3 x_1^{-2/3}$。

◆ 投入 i 的边际产品是递减的，如果随着投入 i 的水平增加而变小。即，如果

∂MPᵢ/∂xᵢ = ∂/∂xᵢ (∂y/∂xᵢ) = ∂²y/∂xᵢ² < 0。

![](img/e3f3f402f74cf453caf4596d2d7d7398_918_0.png)

例如，如果 $y = x_1^{1/3} x_2^{2/3}$ 则

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ 且 $MP_2 = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$

![](img/e3f3f402f74cf453caf4596d2d7d7398_919_0.png)

例如，如果 $y = x_1^{1/3} x_2^{2/3}$ 则

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ 且 $MP_2 = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$

因此 $\frac{\partial MP_1}{\partial x_1} = -\frac{2}{9} x_1^{-5/3} x_2^{2/3} < 0$

![](img/e3f3f402f74cf453caf4596d2d7d7398_920_0.png)

例如，如果 $y = x_1^{1/3}x_2^{2/3}$ 则

$MP_1 = \frac{1}{3}x_1^{-2/3}x_2^{2/3}$ 且 $MP_2 = \frac{2}{3}x_1^{1/3}x_2^{-1/3}$

因此 $\frac{\partial MP_1}{\partial x_1} = -\frac{2}{9}x_1^{-5/3}x_2^{2/3} < 0$

且 $\frac{\partial MP_2}{\partial x_2} = -\frac{2}{9}x_1^{1/3}x_2^{-4/3} < 0.$

两个边际产品都是递减的。

![](img/e3f3f402f74cf453caf4596d2d7d7398_921_0.png)

## 规模报酬

- 边际产品描述了单一投入水平变化时产出水平的变化。
- 规模报酬描述了所有投入水平按相同比例变化时产出水平如何变化（例如所有投入水平加倍，或减半）。

![](img/e3f3f402f74cf453caf4596d2d7d7398_922_0.png)

如果，对任意投入组合 (x₁,...,xₙ)，

f(kx₁, kx₂, ⋯, kxₙ) = k f(x₁, x₂, ⋯, xₙ)

则由生产函数 f 描述的技术表现出规模报酬不变。

例如，(k = 2) 所有投入水平加倍则产出水平加倍。

![](img/e3f3f402f74cf453caf4596d2d7d7398_923_0.png)

$$f(kx_1,kx_2,\cdots,kx_n)>kf(x_1,x_2,\cdots,x_n)$$
