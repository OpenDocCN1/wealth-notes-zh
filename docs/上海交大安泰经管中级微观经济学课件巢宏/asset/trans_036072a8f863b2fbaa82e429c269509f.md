## 数量税与市场均衡

pₛ = (a − c − b t) / (b + d)

p_b = (a − c + d t) / (b + d)

qᵗ = (a d + b c − b d t) / (b + d)

The tax paid per unit by the buyer is
p_b − p* = (a − c + d t)/(b + d) − (a − c)/(b + d) = (d t)/(b + d).

The tax paid per unit by the seller is
p* − p_s = (a − c)/(b + d) − (a − c − b t)/(b + d) = (b t)/(b + d).

## 数量税与市场均衡

$p_s = \frac{a-c-bt}{b+d}$

$p_b = \frac{a-c+dt}{b+d}$

$q^t = \frac{ad+bc-bdt}{b+d}$

The total tax paid (by buyers and sellers combined) is

$T = tq^t = t\frac{ad+bc-bdt}{b+d}$.

## 税负归宿与自价格弹性

Around p = p* the own-price elasticity of demand is approximately

```
ε_D ≈ (Δq / q*) / ((p_b - p*) / p*) ⇒ p_b - p* ≈ (Δq × p*) / (ε_D × q*)
```

## 税负归宿与自价格弹性

Tax incidence = (p_b − p*) / (p* − p_s)

p_b − p* ≈ (Δq × p*) / (ε_D × q*)
