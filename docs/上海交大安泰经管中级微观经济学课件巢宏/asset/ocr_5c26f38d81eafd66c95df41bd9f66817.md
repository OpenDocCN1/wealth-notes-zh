# Common-Value Auctions

+   - Bidder i’s estimate is \(V_i = V + \varepsilon_i\), where \(V\) is the common value and \(\varepsilon_i\) is bidder i’s estimation error.
+   - If every bid is truthful, the winner is the bidder with the largest estimation error \(\varepsilon_i\).
+   - So a truthful winner on average pays more than the true value \(V\)—the winner’s curse.
