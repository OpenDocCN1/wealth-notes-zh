# Quantity Competition

Similarly, given firm 1’s chosen output level y₁, firm 2’s profit function is

Π₂(y₂; y₁) = p(y₁ + y₂) y₂ − c₂(y₂)

and the profit-maximizing value of y₂ solves

∂Π₂/∂y₂ = p(y₁ + y₂) + y₂ ∂p(y₁ + y₂)/∂y₂ − c₂′(y₂) = 0.

The solution, y₂ = R₂(y₁), is firm 2’s Cournot-Nash reaction to y₁.
