# Marginal & Average Cost Functions

$$\frac{\partial AVC(y)}{\partial y}=0 \quad \text{as} \quad MC(y)=AVC(y).$$

$$\begin{cases}
\frac{\partial AVC(y)}{\partial y}>0 & \text{as } MC(y)>AVC(y)\\
\frac{\partial AVC(y)}{\partial y}<0 & \text{as } MC(y)<AVC(y)
\end{cases}$$
