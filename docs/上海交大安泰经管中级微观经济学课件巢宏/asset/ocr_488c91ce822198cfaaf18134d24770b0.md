# Comparative Statics of Short-Run Profit-Maximization

The Cobb-Douglas example: When y = x₁^(1/3) \tilde{x}₂^(1/3) then the firm’s short-run demand for its variable input 1 is

x₁* = (p / 3w₁)^(3/2) \tilde{x}₂^(1/2) and its short-run supply is

y* = (p / 3w₁)^(1/2) \tilde{x}₂^(1/2).
