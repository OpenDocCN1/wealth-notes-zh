- ◆ In which market will the monopolist cause the higher price?

- ◆ Recall that
- MR₁(y₁) = p₁(y₁) [1 + 1/ε₁]
- and
- MR₂(y₂) = p₂(y₂) [1 + 1/ε₂].

- ◆ But, MR₁(y₁*) = MR₂(y₂*) = MC(y₁* + y₂*)

## Third-degree Price Discrimination

So

$$p_1(y_1^*)\left[1+\frac{1}{\varepsilon_1}\right]=p_2(y_2^*)\left[1+\frac{1}{\varepsilon_2}\right].$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_1511_0.png)

## Third-degree Price Discrimination

So p₁(y₁*)[1 + 1/ε₁] = p₂(y₂*)[1 + 1/ε₂].

Therefore, p₁(y₁*) > p₂(y₂*) if and only if 1 + 1/ε₁ < 1 + 1/ε₂

![](img/e3f3f402f74cf453caf4596d2d7d7398_1512_0.png)

## Third-degree Price Discrimination

So

Therefore, p₁(y₁*) > p₂(y₂*) if and only if
1 + 1/ε₁ < 1 + 1/ε₂  ⇒  ε₁ > ε₂.

## Third-degree Price Discrimination

So p₁(y₁*)[1 + 1/ε₁] = p₂(y₂*)[1 + 1/ε₂].

Therefore, p₁(y₁*) > p₂(y₂*) if and only if

1 + 1/ε₁ < 1 + 1/ε₂ ⇒ ε₁ > ε₂.

The monopolist sets the higher price in the market where demand is least own-price elastic.

## Two-Part Tariffs

- ◆ A two-part tariff is a lump-sum fee, \(p_1\), plus a price \(p_2\) for each unit of product purchased.

- ◆ Thus the cost of buying \(x\) units of product is

\(p_1 + p_2x\)
