
## 斯塔克尔伯格博弈；一个例子

问：对于领导者的选择 y₁^S = 13·9，企业2的回应是什么？

答：y₂^S = R₂(y₁^S) = (45 − 13·9)/4 = 7·8.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1672_0.png)

**问：** 对于领导者的选择 \(y_1^S = 13\cdot 9\)，企业2的回应是什么？

**答：** \(y_2^S = R_2(y_1^S) = \frac{45 - 13\cdot 9}{4} = 7.8.\)

古诺-纳什产出水平为 \((y_1^*, y_2^*) = (13,8)\)，因此领导者产量高于其古诺-纳什产出，跟随者产量低于其古诺-纳什产出。这一点通常是成立的。

## 价格竞争

- 如果企业仅使用定价策略而非仅使用产量策略进行竞争，会怎样？
- 企业只使用价格策略并同时行动的博弈是伯特兰博弈。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1678_0.png)

## 伯特兰博弈

- 每个企业的边际生产成本恒定为c。
- 所有企业同时设定价格。
- 问：是否存在纳什均衡？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1679_0.png)

- 问：是否存在纳什均衡？
- 答：是的。只有一个。

## 序贯价格博弈

- 如果企业不是同时进行定价策略博弈，而是一家企业先于其他企业决定价格，会怎样？
- 这是一个序贯的定价策略博弈，称为价格领导博弈。
- 先于其他企业设定价格的企业是价格领导者。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1688_0.png)

- 设想一家大型企业（领导者）和许多竞争性的小企业（跟随者）。
- 小企业是价格接受者，因此它们对市场价格p的集体供给反应就是其总供给函数Y_f(p)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1689_0.png)
