# Trade in Competitive Markets

+   - Since there is an excess demand for commodity 2, $p_2$ will rise.
+   - Since there is an excess supply of commodity 1, $p_1$ will fall.
+   - The slope of the budget constraints is $-p_1/p_2$ so the budget constraints will pivot about the endowment point and become less steep.
