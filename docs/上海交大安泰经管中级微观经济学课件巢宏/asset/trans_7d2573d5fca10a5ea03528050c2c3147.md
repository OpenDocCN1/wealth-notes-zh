# Cobb-Douglas 技术

◆ Cobb-Douglas 生产函数的形式为

```
$$y = A x_1^{a_1} x_2^{a_2} \times \cdots \times x_n^{a_n}.$$
```

◆ 例如

```
$$y = x_1^{1/3} x_2^{1/3}$$
```

其中

```
$$n = 2, A = 1, a_1 = \frac{1}{3} \text{ and } a_2 = \frac{1}{3}.$$
```

# 固定比例技术

- ◆ 固定比例生产函数的形式为
- $y = \min\{a_1 x_1, a_2 x_2, \cdots, a_n x_n\}.$
- ◆ 例如
- $y = \min\{x_1, 2 x_2\}$
- 其中
- $n = 2, a_1 = 1 \text{ and } a_2 = 2.$

# 完全替代技术

- ◆ 完全替代生产函数的形式为
- $y = a_1x_1 + a_2x_2 + ... + a_nx_n.$
- ◆ 例如
- $y = x_1 + 3x_2$
- 其中
- $n = 2, a_1 = 1 \text{and} a_2 = 3.$

# 边际 实际 产品

例如如果

y = f(x₁, x₂) = x₁^{1/3} x₂^{2/3}

则投入 1 的边际产品为

MP₁ = ∂y/∂x₁ = 1/3 x₁^{-2/3} x₂^{2/3}
