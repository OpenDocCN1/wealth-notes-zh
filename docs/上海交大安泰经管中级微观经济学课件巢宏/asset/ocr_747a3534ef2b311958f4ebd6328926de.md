# The Intertemporal Choice Problem

+   - The intertemporal choice problem: Given incomes m₁ and m₂, and given consumption prices p₁ and p₂, what is the most preferred intertemporal consumption bundle (c₁, c₂)?
+   - For an answer we need to know:
+     - the intertemporal budget constraint
+     - intertemporal consumption preferences.
