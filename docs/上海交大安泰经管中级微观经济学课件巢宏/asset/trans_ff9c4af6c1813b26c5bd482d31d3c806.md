## 消费者剩余、补偿变差和等价变差

- ◆ 首先考虑当 p₁ 从 p₁’ 上升到 p₁” 时消费者剩余的变化。

![](img/e3f3f402f74cf453caf4596d2d7d7398_644_0.png)

## 消费者剩余、补偿变差和等价变差

If

$U(x_1, m) = v(x_1) + m$

then

$CS(p_1') = v(x_1') - v(0) - p_1' x_1'$

## 消费者剩余、补偿变差和等价变差

**If**  
\(U(x_1,m)=v(x_1)+m\)  
**then**

\[CS(p_1)=v(x_1)-v(0)-p_1x_1\]

and so the change in **CS** when \(p_1\) rises  
from \(p_1'\) to \(p_1''\) is

\[\Delta CS=CS(p_1')-CS(p_1'')\]

![](img/e3f3f402f74cf453caf4596d2d7d7398_646_0.png)

## 消费者剩余、补偿变差和等价变差

If          U(x₁, m) = v(x₁) + m          then

CS(p₁′) = v(x₁′) − v(0) − p₁′x₁′

and so the change in CS when p₁ rises from p₁′ to p₁″ is

ΔCS = CS(p₁′) − CS(p₁″)

= v(x₁′) − v(0) − p₁′x₁′ − [v(x₁″) − v(0) − p₁″x₁″]

![](img/e3f3f402f74cf453caf4596d2d7d7398_647_0.png)

## 消费者剩余、补偿变差和等价变差

**If**  
\(U(x_1,m)=v(x_1)+m\)  
**then**

\[CS(p_1)=v(x_1)-v(0)-p_1x_1\]

and so the change in CS when \(p_1\) rises  
from \(p_1'\) to \(p_1''\) is

\[\Delta CS=CS(p_1')-CS(p_1'')\]

\[=v(x_1')-v(0)-p_1'x_1'-\left[v(x_1'')-v(0)-p_1''x_1''\right]\]

\[=v(x_1')-v(x_1'')-(p_1'x_1'-p_1''x_1'')\]

![](img/e3f3f402f74cf453caf4596d2d7d7398_648_0.png)

## 消费者剩余、补偿变差和等价变差

- 现在考虑当 p₁ 从 p₁’ 上升到 p₁” 时 CV 的变化。
- 给定 p₁ 时消费者的效用为 v(x₁*(p₁)) + m − p₁x₁*(p₁)，而 CV 是在新价格下使消费者的效用与旧价格下相同的额外收入。也就是说，...

## 消费者剩余、补偿变差和等价变差

$$v(x'_1)+m-p'_1x'_1$$
$$=v(x''_1)+m+CV-p'_1x'_1.$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_650_0.png)

## 消费者剩余、补偿变差和等价变差

$$v(x_1') + m - p_1'x_1'$$
$$= v(x_1') + m + \mathrm{CV} - p_1'x_1'.$$

So

$$\mathrm{CV} = v(x_1') - v(x_1'') - (p_1'x_1' - p_1''x_1'')$$
$$= \Delta\mathrm{CS}.$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_651_0.png)

## 消费者剩余、补偿变差和等价变差

- ◆ 现在考虑当 p₁ 从 p₁’ 上升到 p₁” 时 EV 的变化。

- ◆ 给定 p₁ 时消费者的效用为 v(x₁*(p₁)) + m − p₁x₁*(p₁)

而 EV 是在旧价格下使消费者的效用与新价格下相同的额外收入。也就是说，...

## 消费者剩余、补偿变差和等价变差

u(x₁') + m − p₁' x₁' − EV
= u(x₁'') + m − p₁'' x₁''.

![](img/e3f3f402f74cf453caf4596d2d7d7398_653_0.png)

## 消费者剩余、补偿变差和等价变差

v(x₁') + m − p₁' x₁' − EV
= v(x₁'') + m − p₁'' x₁''.

**That is,**
**EV = v(x₁') − v(x₁'') − (p₁' x₁' − p₁'' x₁'')**
**= ΔCS.**

![](img/e3f3f402f74cf453caf4596d2d7d7398_654_0.png)
