∂U/∂x₁ dx₁ + ∂U/∂x₂ dx₂ = 0

移项得

∂U/∂x₂ dx₂ = − ∂U/∂x₁ dx₁

# 边际效用与边际替代率

即

$$\frac{\partial U}{\partial x_2}dx_2=-\frac{\partial U}{\partial x_1}dx_1$$

移项得

$$\frac{dx_2}{dx_1}=-\frac{\partial U/\partial x_1}{\partial U/\partial x_2}.$$

这就是边际替代率（MRS）。

![](img/e3f3f402f74cf453caf4596d2d7d7398_151_0.png)

# 边际效用与边际替代率：一个例子

◆ 假设 U(x₁,x₂) = x₁x₂。则
∂U/∂x₁ = (1)(x₂) = x₂
∂U/∂x₂ = (x₁)(1) = x₁

所以 MRS = dx₂/dx₁ = − (∂U/∂x₁)/(∂U/∂x₂) = − x₂/x₁。

# 拟线性效用函数的边际替代率

- 拟线性效用函数的形式为 U(x₁,x₂) = f(x₁) + x₂。
- ∂U/∂x₁ = f′(x₁) ∂U/∂x₂ = 1
- 所以 MRS = dx₂/dx₁ = − (∂U/∂x₁)/(∂U/∂x₂) = −f′(x₁)。

# 单调变换与边际替代率

- ◆ 对于 U(x₁,x₂) = x₁x₂，MRS = - x₂/x₁。
- ◆ 构造 V = U²；即 V(x₁,x₂) = x₁²x₂²。V 的 MRS 是多少？

MRS = - ∂V / ∂x₁ / ∂V / ∂x₂ = - 2x₁x₂² / 2x₁²x₂ = - x₂ / x₁

这与 U 的 MRS 相同。

# 单调变换与边际替代率

◆ 更一般地，如果 V = f(U)，其中 f 是严格递增函数，则

*MRS* = − ∂V / ∂x₁ / ∂V / ∂x₂ = − [f′(U) × ∂U / ∂x₁] / [f′(U) × ∂U / ∂x₂]

= − ∂U / ∂x₁ / ∂U / ∂x₂。

因此，正的单调变换不会改变 MRS。
