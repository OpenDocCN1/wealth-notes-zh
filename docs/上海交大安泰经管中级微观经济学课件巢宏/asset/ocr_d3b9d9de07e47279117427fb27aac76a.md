# Technologies with Multiple Inputs

+   E.g. the maximal output level possible from the input bundle (x₁, x₂) = (1, 8) is
+   
+   y = 2 x₁^(1/3) x₂^(1/3) = 2 × 1^(1/3) × 8^(1/3) = 2 × 1 × 2 = 4.

+   And the maximal output level possible from (x₁,x₂) = (8,8) is
+   
+   y = 2 x₁^(1/3) x₂^(1/3) = 2 × 8^(1/3) × 8^(1/3) = 2 × 2 × 2 = 8.
