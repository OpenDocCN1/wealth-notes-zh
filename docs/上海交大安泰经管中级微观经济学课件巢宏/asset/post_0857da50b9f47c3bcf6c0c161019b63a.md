
## Sequential Price Games

- The market demand function is D(p).
- So the leader knows that if it sets a price p the quantity demanded from it will be the residual demand
  L(p) = D(p) − Y_f(p).
- Hence the leader’s profit function is
  Π_L(p) = p(D(p) − Y_f(p)) − c_L(D(p) − Y_f(p)).

## Sequential Price Games

- The leader’s profit function is
  Π_L(p) = p(D(p) − Y_f(p)) − c_L(D(p) − Y_f(p))
  so the leader chooses the price level p* for which profit is maximized.
- The followers collectively supply Y_f(p*) units and the leader supplies the residual quantity D(p*) - Y_f(p*).

## What is a Game?

- A **game** consists of
  - a set of **players**
  - a set of **strategies** for each player
  - the **payoffs** to each player for every possible choice of strategies by the players.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1696_0.png)
