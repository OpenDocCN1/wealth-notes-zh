
# Short-Run Profit-Maximization; A Cobb-Douglas Example

Suppose the short-run production function is y = x₁^(1/3) x̃₂^(1/3).

The marginal product of the variable input 1 is MP₁ = ∂y/∂x₁ = (1/3) x₁^(-2/3) x̃₂^(1/3).

The profit-maximizing condition is MRP₁ = p × MP₁ = (p/3) (x₁*)^(-2/3) x̃₂^(1/3) = w₁.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1005_0.png)

**Solving** $\frac{p}{3}(x_1^*)^{-2/3}\tilde{x}_2^{1/3}=w_1$ **for** $x_1$ **gives**

$(x_1^*)^{-2/3}=\frac{3w_1}{p\tilde{x}_2^{1/3}}.$

**That is,**

$(x_1^*)^{2/3}=\frac{p\tilde{x}_2^{1/3}}{3w_1}$

![](img/e3f3f402f74cf453caf4596d2d7d7398_1006_0.png)

**Solving** $\frac{p}{3}(x_1^*)^{-2/3}\tilde{x}_2^{1/3}=w_1$ **for** $x_1$ **gives**

$(x_1^*)^{-2/3}=\frac{3w_1}{p\tilde{x}_2^{1/3}}.$

**That is,**

$(x_1^*)^{2/3}=\frac{p\tilde{x}_2^{1/3}}{3w_1}$

**so**

$x_1^*=\left(\frac{p\tilde{x}_2^{1/3}}{3w_1}\right)^{3/2}=\left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}.$

x₁* = ( p / 3w₁ )^(3/2)  x̃₂^(1/2)   is the firm’s short-run demand for input 1 when the level of input 2 is fixed at x̃₂ units.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1008_0.png)

$x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}$ is the firm's short-run demand for input 1 when the level of input 2 is fixed at $\tilde{x}_2$ units.

The firm's short-run output level is thus

$y^* = (x_1^*)^{1/3}\tilde{x}_2^{1/3} = \left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2}$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1009_0.png)

# Comparative Statics of Short-Run Profit-Maximization

+   ◆ What happens to the short-run profit-maximizing production plan as the output price p changes?

![](img/e3f3f402f74cf453caf4596d2d7d7398_1010_0.png)

The equation of a short-run iso-profit line is

$$y = \frac{w_1}{p}x_1 + \frac{\Pi + w_2\tilde{x}_2}{p}$$

so an increase in p causes

+   - a reduction in the slope, and
+   - a reduction in the vertical intercept.

+   ◆ **An increase in p, the price of the firm’s output, causes**
+   
+   – an increase in the firm’s output level (the firm’s supply curve slopes upward), and
+   
+   – an increase in the level of the firm’s variable input (the firm’s demand curve for its variable input shifts outward).

![](img/e3f3f402f74cf453caf4596d2d7d7398_1015_0.png)

The Cobb-Douglas example: When y = x₁^(1/3) \tilde{x}₂^(1/3) then the firm’s short-run demand for its variable input 1 is

x₁* = (p / 3w₁)^(3/2) \tilde{x}₂^(1/2) and its short-run supply is

y* = (p / 3w₁)^(1/2) \tilde{x}₂^(1/2).
