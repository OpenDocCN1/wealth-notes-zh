# Long-Run Profit-Maximization

$\Pi = py^* - w_1x_1^* - w_2\tilde{x}_2$

$= p\left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2} - w_1\left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2} - w_2\tilde{x}_2$

$= p\left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2} - w_1\frac{p}{3w_1}\left(\frac{p}{3w_1}\right)^{1/2} - w_2\tilde{x}_2$

$= \frac{2p}{3}\left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2} - w_2\tilde{x}_2$
