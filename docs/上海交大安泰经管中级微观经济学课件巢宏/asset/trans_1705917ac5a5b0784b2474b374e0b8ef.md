- ♦ 我们能否使用逆向市场需求和供给曲线来计算市场均衡？
- ♦ 可以，计算是相同的。

![](img/e3f3f402f74cf453caf4596d2d7d7398_746_0.png)

q = S(p) = c + d p ⇔ p = (−c + q)/d = S⁻¹(q)，
