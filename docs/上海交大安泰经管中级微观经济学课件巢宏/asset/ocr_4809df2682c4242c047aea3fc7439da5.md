# Recovering Indifference Curves

+   ◆ Suppose we observe:
+   A: (p₁,p₂) = ($1,$1) & (x₁,x₂) = (15,15)
+   B: (p₁,p₂) = ($2,$1) & (x₁,x₂) = (10,20)
+   C: (p₁,p₂) = ($1,$2) & (x₁,x₂) = (20,10)
+   D: (p₁,p₂) = ($2,$5) & (x₁,x₂) = (30,12)
+   E: (p₁,p₂) = ($5,$2) & (x₁,x₂) = (12,30).

+   ◆ Where lies the indifference curve containing the bundle A = (15,15)?
