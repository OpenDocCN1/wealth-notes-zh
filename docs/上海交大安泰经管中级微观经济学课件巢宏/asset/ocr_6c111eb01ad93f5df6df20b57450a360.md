# Revealed Profitability

**ΔpΔy ≥ ΔwΔx**

**is a necessary implication of profit-maximization.**

Suppose the output price does not change. Then Δp = 0 and profit-maximization implies **0 ≥ ΔwΔx**; *i.e.*, a competitive firm’s input demand curve cannot slope upward.
