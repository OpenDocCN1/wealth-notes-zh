

## 数量税

- ◆ 即使征税，市场也必须出清。
- ◆ 即。买方在价格 p_b 下的需求量必须等于卖方在价格 p_s 下的供给量。

D(p_b) = S(p_s)

p_b − p_s = t    and    D(p_b) = S(p_s)
描述市场的均衡。
请注意，这两个条件无论税是对卖方征收还是对买方征收都适用。

![](img/e3f3f402f74cf453caf4596d2d7d7398_773_0.png)

$p_b - p_s = t$ and $D(p_b) = S(p_s)$ describe the market’s equilibrium.

Notice that these two conditions apply no matter if the tax is levied on sellers or on buyers.

因此，销售税率 $t$ 的效果与从量税率 $t$ 相同。

![](img/e3f3f402f74cf453caf4596d2d7d7398_774_0.png)

- 例如，假设市场需求和供给曲线是线性的。

D(p_b) = a − b p_b

![](img/e3f3f402f74cf453caf4596d2d7d7398_789_0.png)

D(p_b) = a − b p_b and S(p_s) = c + d p_s.

![](img/e3f3f402f74cf453caf4596d2d7d7398_790_0.png)

D(p_b) = a − b p_b and S(p_s) = c + d p_s.

在征税的情况下，市场均衡满足

p_b = p_s + t  and  D(p_b) = S(p_s)  so
p_b = p_s + t  and  a − b p_b = c + d p_s.

![](img/e3f3f402f74cf453caf4596d2d7d7398_791_0.png)

D(p_b) = a − b p_b and S(p_s) = c + d p_s.

在征税的情况下，市场均衡满足

p_b = p_s + t and D(p_b) = S(p_s) so

p_b = p_s + t and a − b p_b = c + d p_s.

将 p_b 代入得

a − b(p_s + t) = c + d p_s ⇒ p_s = (a − c − b t)/(b + d).
