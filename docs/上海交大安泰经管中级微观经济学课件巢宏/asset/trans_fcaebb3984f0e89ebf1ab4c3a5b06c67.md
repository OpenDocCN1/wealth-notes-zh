

## 预算约束

+   ♦ 消费者的预算集合是所有可负担的组合的集合；
+   B(p₁, ..., pₙ, m) =
+   { (x₁, ..., xₙ) | x₁ ≥ 0, ..., xₙ ≥ 0 and
+   p₁x₁ + ... + pₙxₙ ≤ m }

+   ♦ 预算约束是预算集合的上边界。

## 两种商品的预算集合与约束

预算约束为
p₁x₁ + p₂x₂ = m.
如果 x₂ 是复合商品，
p₂ 标准化为 1。

## 预算约束 - 收入变化

+   - 收入增加时不会失去原有选择且会增加新选择，因此更高的收入不会使消费者变差。
+   - 收入减少可能会（通常会）使消费者变差。

![](img/e3f3f402f74cf453caf4596d2d7d7398_54_0.png)

## 预算约束 - 价格变化

+   降低一种商品的价格会使约束向外枢轴转动。 不会失去旧选择且会增加新选择，因此降低一种价格不会使消费者变差。

![](img/e3f3f402f74cf453caf4596d2d7d7398_58_0.png)

## 预算约束 - 价格变化

+   ◆ 同样，提高一种价格会使约束向内枢轴转动，减少选择并可能（通常会）使消费者变差。

![](img/e3f3f402f74cf453caf4596d2d7d7398_59_0.png)
