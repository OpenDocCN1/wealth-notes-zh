# # Economic Profit

+   - A firm uses inputs \(j = 1,\ldots,m\) to make products \(i = 1,\ldots,n\).
+   - Output levels are \(y_1,\ldots,y_n\).
+   - Input levels are \(x_1,\ldots,x_m\).
+   - Product prices are \(p_1,\ldots,p_n\).
+   - Input prices are \(w_1,\ldots,w_m\).
