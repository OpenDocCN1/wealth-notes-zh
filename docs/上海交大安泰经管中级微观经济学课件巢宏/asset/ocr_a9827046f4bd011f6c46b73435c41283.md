# Quantity Taxes & Market Equilibrium

D(p_b) = a − b p_b and S(p_s) = c + d p_s.

With the tax, the market equilibrium satisfies

p_b = p_s + t and D(p_b) = S(p_s) so

p_b = p_s + t and a − b p_b = c + d p_s.

Substituting for p_b gives

a − b(p_s + t) = c + d p_s ⇒ p_s = (a − c − b t)/(b + d).
