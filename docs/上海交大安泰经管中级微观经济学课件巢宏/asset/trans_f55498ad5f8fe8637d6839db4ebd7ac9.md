## 固定投入与经济租金

+ Q：当存在进入壁垒时，已在行业中的厂商难道不会获得正的经济利润吗？

+ A：不会。行业中每个厂商的经济利润为零。为什么？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1388_0.png)

## 固定投入与经济租金

+ ♦ 一种在长期固定的投入（例如经营许可证）会造成长期固定成本，F。
+ ♦ 长期总成本，c(y) = F + c_v(y)。
+ ♦ 而长期平均总成本，AC(y) = AFC(y) + AVC(y)。
+ ♦ 在长期均衡中，F 的值会是多少？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1389_0.png)

## 固定投入与经济租金

+ - 设想一家需要经营许可证的厂商——许可证是一种被租赁但不被厂商拥有的固定投入。
+ - 如果厂商获得正的经济利润，那么另一家厂商可以向许可证所有者提供更高的价格。在这种方式下，所有厂商的经济利润都会被竞争掉，降为零。

## 固定投入与经济租金

因此在长期均衡中，每个厂商的经济利润为零，每个厂商的固定成本就是其为经营许可证支付的费用。
