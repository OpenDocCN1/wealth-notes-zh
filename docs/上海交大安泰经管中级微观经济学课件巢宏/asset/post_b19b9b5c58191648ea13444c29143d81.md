- An increase in w₁, the price of the firm’s variable input, causes
  - a decrease in the firm’s output level (the firm’s supply curve shifts inward), and
  - a decrease in the level of the firm’s variable input (the firm’s demand curve for its variable input slopes downward).

The Cobb-Douglas example: When
\[
y=x_1^{1/3}x_2^{1/3}
\]
then the firm’s short-run demand for its variable input 1 is

\[
x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}
\]

and its short-run supply is

\[
y^* = \left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2}.
\]

![](img/e3f3f402f74cf453caf4596d2d7d7398_1025_0.png)

The Cobb-Douglas example: When y = x₁^(1/3) \tilde{x}₂^(1/3) then the firm’s short-run demand for its variable input 1 is

x₁* = (p / 3w₁)^(3/2) \tilde{x}₂^(1/2) and its short-run supply is

y* = (p / 3w₁)^(1/2) \tilde{x}₂^(1/2).

x₁* decreases as w₁ increases.

The Cobb-Douglas example: When y = x₁^(1/3) \tilde{x}₂^(1/3) then the firm’s short-run demand for its variable input 1 is

x₁* = (p / 3w₁)^(3/2) \tilde{x}₂^(1/2) and its short-run supply is

y* = (p / 3w₁)^(1/2) \tilde{x}₂^(1/2).

x₁* decreases as w₁ increases.

## Long-Run Profit-Maximization

- Now allow the firm to vary both input levels.
- Since no input level is fixed, there are no fixed costs.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1028_0.png)

- Both x₁ and x₂ are variable.
- Think of the firm as choosing the production plan that maximizes profits for a given value of x₂, and then varying x₂ to find the largest possible profit level.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1029_0.png)

**The equation of a long-run iso-profit line is**

$$y = \frac{w_1}{p}x_1 + \frac{\Pi + w_2x_2}{p}$$

**so an increase in $x_2$ causes**

- no change to the slope, and
- an increase in the vertical intercept.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1032_0.png)

Larger levels of input 2 increase the productivity of input 1.
