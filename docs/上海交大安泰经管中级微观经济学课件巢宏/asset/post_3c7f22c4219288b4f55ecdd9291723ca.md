
## Index Numbers

+   ◆ Over time, many prices change. Are consumers better or worse off “overall” as a consequence?
+   ◆ Index numbers give approximate answers to such questions.

![](img/e3f3f402f74cf453caf4596d2d7d7398_422_0.png)

## Index Numbers

- **Two basic types of indices**
  - price indices, and
  - quantity indices
- **Each index compares expenditures in a base period and in a current period by taking the ratio of expenditures.**

![](img/e3f3f402f74cf453caf4596d2d7d7398_423_0.png)

## Quantity Index Numbers

◆ A quantity index is a price-weighted average of quantities demanded; i.e.

I_q = (p₁x₁ᵗ + p₂x₂ᵗ) / (p₁x₁ᵇ + p₂x₂ᵇ)

◆ (p₁,p₂) can be base period prices (p₁ᵇ,p₂ᵇ) or current period prices (p₁ᵗ,p₂ᵗ).

## Quantity Index Numbers

◆ If (p₁,p₂) = (p₁ᵇ,p₂ᵇ) then we have the Laspeyres quantity index;

L_q = (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_425_0.png)

## Quantity Index Numbers

◆ If \((p_1,p_2)=(p_1^t,p_2^t)\) then we have the Paasche quantity index;

$$P_q=\frac{p_1^t x_1^t+p_2^t x_2^t}{p_1^t x_1^b+p_2^t x_2^b}$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_426_0.png)

## Quantity Index Numbers

◆ How can quantity indices be used to make statements about changes in welfare?

![](img/e3f3f402f74cf453caf4596d2d7d7398_427_0.png)

## Quantity Index Numbers

◆ If L_q = (p₁ᵇ x₁ᵗ + p₂ᵇ x₂ᵗ) / (p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ) < 1 then

p₁ᵇ x₁ᵗ + p₂ᵇ x₂ᵗ < p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ

so consumers overall were better off in the base period than they are now in the current period.

## Quantity Index Numbers

♦ If P_q = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) > 1 then

p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ > p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ

so consumers overall are better off in the current period than in the base period.

![](img/e3f3f402f74cf453caf4596d2d7d7398_429_0.png)

## Price Index Numbers

◆ A price index is a quantity-weighted average of prices; *i.e.*

$$I_p = \frac{p_1^t x_1 + p_2^t x_2}{p_1^b x_1 + p_2^b x_2}$$

◆ $(x_1,x_2)$ can be the base period bundle $(x_1^b,x_2^b)$ or else the current period bundle $(x_1^t,x_2^t)$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_430_0.png)

## Price Index Numbers

◆ If (x₁,x₂) = (x₁ᵇ,x₂ᵇ) then we have the Laspeyres price index;

Lₚ = (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_431_0.png)

## Price Index Numbers

◆ If (x₁,x₂) = (x₁ᵗ,x₂ᵗ) then we have the Paasche price index;

Pₚ = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_432_0.png)

## Price Index Numbers

- How can price indices be used to make statements about changes in welfare?
- Define the expenditure ratio
  - M = (p₁ᵗ x₁ᵗ + p₂ᵗ x₂ᵗ) / (p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ)

## Price Index Numbers

◆ If
Lₚ = (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) < (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) = M

then
p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ < p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ

so consumers overall are better off in the current period.

## Price Index Numbers

◆ But, if

P_p = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ) > (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) = M

then

p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ < p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ

so consumers overall were better off in the base period.

## Full Indexation?

$P_q = \frac{p_1^t x_1^t + p_2^t x_2^t}{p_1^t x_1^b + p_2^t x_2^b}$

Notice that this index uses current period prices to weight both base and current period consumptions.
