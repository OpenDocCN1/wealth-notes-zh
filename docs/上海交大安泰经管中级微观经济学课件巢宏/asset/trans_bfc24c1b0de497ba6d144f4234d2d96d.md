- ◆ 每个卖方的供给量都低于其产品的有效数量。
- ◆ 此外，每个卖方的供给量都低于使其平均成本最小的数量，因此在这个意义上，每个供应商都存在“过剩产能”。

-   - (i) 所有 3 个卖方都位于同一点。

-   - (iii) 每个卖方位于不同的点。
