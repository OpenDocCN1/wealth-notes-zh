# 拍卖

## 谁使用拍卖？

- ◆ 艺术品、汽车、邮票、机器、矿产权等的拥有者
- ◆ 问：为什么要拍卖？

![](img/e3f3f402f74cf453caf4596d2d7d7398_836_0.png)

- ◆ 答：因为许多市场是不完善的，很难发现潜在买家对你的资产的真实估值。拍卖有助于发现这些信息。

![](img/e3f3f402f74cf453caf4596d2d7d7398_837_0.png)

## 拍卖类型

- **英式拍卖：**
  - 出价是公开宣布的
  - 出价不断上涨，直到没有进一步出价为止
  - 出价最高者获胜
  - 获胜者支付其出价。

- ◆ **密封投标一价拍卖：**
  - 出价是私人信息
  - 出价同时进行
  - 出价最高者获胜
  - 获胜者支付其出价。

![](img/e3f3f402f74cf453caf4596d2d7d7398_839_0.png)

- ◆ **密封投标二价拍卖：**
  - 出价是私人信息
  - 出价同时进行
  - 出价最高者获胜
  - 获胜者支付第二高出价
  - 也称为维克里拍卖。

![](img/e3f3f402f74cf453caf4596d2d7d7398_840_0.png)

- **荷兰式拍卖：**
  - 拍卖师宣布一个高价然后逐渐降低出价
  - 第一个接受出价的买家获胜并支付该价格。

## 保留价

- ♦ 卖方指定的出价水平，低于该水平不进行销售。

## 经济学家对拍卖的分类

- **私值拍卖：**
  - 每个潜在买家都确切知道自己对待售物品的估值
  - 这些个人估值彼此独立。

![](img/e3f3f402f74cf453caf4596d2d7d7398_843_0.png)

- ◆ 公共价值拍卖：
  - 待售物品对每个潜在买家具有相同价值
  - 潜在买家对其共同价值的估计各不相同。

![](img/e3f3f402f74cf453caf4596d2d7d7398_844_0.png)

## 拍卖设计

- ◆ **目标：**
  - 帕累托效率
  - 最大化卖方的利润。

![](img/e3f3f402f74cf453caf4596d2d7d7398_845_0.png)

## 拍卖与效率

- ◆ 没有保留价的英式拍卖必须是有效率的，因为如果估值低的买家即将购买，估值最高的买家会出更高价。

![](img/e3f3f402f74cf453caf4596d2d7d7398_847_0.png)

- ◆ 有保留价的英式拍卖不一定有效率，因为如果保留价设定在卖方不知道的最高买家估值之上，则不会有销售，因而没有交易收益。

## 为什么使用保留价？

- 假设有 2 个买家。
- 卖方认为每个买家的估值以 1/2 的概率为 $20，以 1/2 的概率为 $50。
- 即以 1/4 的概率，卖方认为她面临的买家估值为 ($20,$20)、($20,$50)、($50,$20) 和 ($50,$50)

- 即以 1/4 的概率，卖方认为她面临的买家估值为 ($20,$20)、($20,$50)、($50,$20) 和 ($50,$50)。
- 使用英式拍卖。
- 出价必须至少提高 $1。
- 以 1/4 的概率，获胜出价将为 $20、$21、$21 和 $50，如果没有保留价。

- 以 1/4 的概率，获胜出价将为 $20、$21、$21 和 $50，如果没有保留价。

- 卖方的预期收入为 ($20 + $21 + $21 + $50)/4 = $28，没有保留价。

![](img/e3f3f402f74cf453caf4596d2d7d7398_851_0.png)

- 以 1/4 的概率，卖方认为她面临的买家估值为 ($20,$20)、($20,$50)、($50,$20) 和 ($50,$50)。
- 设定保留价为 $50。
- 以 1/4 的概率将不会有销售。
- 以 3/4 的概率获胜出价将为 $50。

![](img/e3f3f402f74cf453caf4596d2d7d7398_852_0.png)
