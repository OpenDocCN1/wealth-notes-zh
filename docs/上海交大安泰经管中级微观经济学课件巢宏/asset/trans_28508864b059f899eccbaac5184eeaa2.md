## 效用函数

- 并不存在偏好关系的唯一效用函数表示。
- 假设 U(x₁,x₂) = x₁x₂ 表示一个偏好关系。
- 再次考虑束 (4,1)、(2,3) 和 (2,2)。

## 物品、劣品和中性品

- 物品是指增加效用（带来更受偏好的束）的商品单位。
- 劣品是指减少效用（带来更不受偏好的束）的商品单位。
- 中性品是指不改变效用（带来同样受偏好的束）的商品单位。

## 其他效用函数及其无差异曲线

◆ 形式为

$$U(x_1,x_2)=f(x_1)+x_2$$

的效用函数仅在 $x_2$ 上是线性的，称为 **拟线性**。

◆ *例如*  $U(x_1,x_2)=2x_1^{1/2}+x_2$。

![](img/e3f3f402f74cf453caf4596d2d7d7398_144_0.png)

## 拟线性无差异曲线

每条曲线都是其他曲线的垂直平移副本。

![](img/e3f3f402f74cf453caf4596d2d7d7398_145_0.png)

## 其他效用函数及其无差异曲线

◆ **任何形式为**

$$U(x_1,x_2)=x_1^a x_2^b$$

且 a > 0 且 b > 0 的效用函数称为 **柯布-道格拉斯** 效用函数。

◆ *例如*  $U(x_1,x_2)=x_1^{1/2}x_2^{1/2}$  （a = b = 1/2）

$V(x_1,x_2)=x_1x_2^3$  （a = 1, b = 3）

![](img/e3f3f402f74cf453caf4596d2d7d7398_146_0.png)

## 柯布-道格拉斯无差异曲线

所有曲线都是双曲线的，渐近于但永远不会触及任何轴。

## 边际效用

- ♦ 边际意为“增量的”。
- ♦ 商品 i 的边际效用是随着商品 i 消费数量变化时总效用的变化率；即

$MU_i = \frac{\partial U}{\partial x_i}$

## 边际效用与边际替代率

无差异曲线的一般方程为
U(x₁,x₂) ≡ k，一个常数。
对该恒等式全微分得到
∂U/∂x₁ dx₁ + ∂U/∂x₂ dx₂ = 0
