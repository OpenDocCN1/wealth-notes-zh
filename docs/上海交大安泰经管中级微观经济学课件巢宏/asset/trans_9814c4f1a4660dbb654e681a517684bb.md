

## 偏好关系

- **比较两个不同的消费束 x 和 y：**
  - **严格偏好：** x 比 y 更受偏好；x ≻ y。
  - **无差异：** x 与 y 的偏好程度完全相同；x ∼ y。
  - **弱偏好：** x 至少与 y 一样受偏好；x ≽ y。

- x ≽ y 且 y ≽ x 蕴含 x ∼ y。
- x ≽ y 且（并非 y ≽ x）蕴含 x ≻ y。

![](img/e3f3f402f74cf453caf4596d2d7d7398_84_0.png)

## 关于偏好关系的假设

- **完备性：** 对于任意两个消费束 x 和 y，总能做出这样的陈述：要么 x ≽ y，要么 y ≽ x。

![](img/e3f3f402f74cf453caf4596d2d7d7398_85_0.png)

- **自反性：** 任何消费束 x 总是至少与自身一样受偏好；*即* x ≽ x。

![](img/e3f3f402f74cf453caf4596d2d7d7398_86_0.png)

- **传递性：** 如果 x 至少与 y 一样受偏好，且 y 至少与 z 一样受偏好，那么 x 至少与 z 一样受偏好；*即* x ≽ y 且 y ≽ z → x ≽ z。

![](img/e3f3f402f74cf453caf4596d2d7d7398_87_0.png)

## 无差异曲线

- 取一个参考消费束 x。所有与 x 偏好程度相同的消费束的集合就是包含 x 的无差异曲线。

![](img/e3f3f402f74cf453caf4596d2d7d7398_88_0.png)

## 无差异曲线的极端情形；完全替代品

- 如果消费者愿意以固定比率用一商品替代另一商品，那么这些商品就是完全替代品，并且消费束中两种商品的总量唯一决定其偏好排序。

![](img/e3f3f402f74cf453caf4596d2d7d7398_94_0.png)

## 无差异曲线的极端情形；完全互补品

- 如果消费者总是按固定比例（例如一对一）消费商品 1 和商品 2，那么这些商品就是**完全互补品**，只有两种商品的配对数决定消费束的偏好排序。

![](img/e3f3f402f74cf453caf4596d2d7d7398_97_0.png)

消费束 **(5,5)**、**(5,9)** 和 **(9,5)** 各包含 5 对，因此每个都同样受偏好。

## 离散商品的无差异曲线

- 如果一种商品可以以任何数量获得，那么它是无限可分的（或连续的）；例如水或奶酪。
- 如果一种商品以 1、2、3 等整数单位出现，那么它是离散的；例如飞机、船舶和冰箱。

![](img/e3f3f402f74cf453caf4596d2d7d7398_100_0.png)
