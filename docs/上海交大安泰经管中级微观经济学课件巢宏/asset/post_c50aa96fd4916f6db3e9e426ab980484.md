## Input Bundles

- **xᵢ denotes the amount used of input i;** *i.e. the level of input i.*
- **An input bundle is a vector of the input levels; (x₁, x₂, ..., xₙ).**
- ***E.g. (x₁, x₂, x₃) = (6, 0, 9).***

![](img/e3f3f402f74cf453caf4596d2d7d7398_869_0.png)

## Production Functions

- y denotes the output level.
- The technology’s production function states the maximum amount of output possible from an input bundle.

y = f(x₁, ..., xₙ)

## Technology Sets

The technology set is

T = { (x₁, ⋯, xₙ, y) | y ≤ f(x₁, ⋯, xₙ) and x₁ ≥ 0, ..., xₙ ≥ 0 }.

## Technologies with Multiple Inputs

- What does a technology look like when there is more than one input?
- The two input case: Input levels are x₁ and x₂. Output level is y.
- Suppose the production function is

  y = f(x₁, x₂) = 2 x₁^(1/3) x₂^(1/3).

![](img/e3f3f402f74cf453caf4596d2d7d7398_877_0.png)

E.g. the maximal output level possible from the input bundle (x₁, x₂) = (1, 8) is

y = 2 x₁^(1/3) x₂^(1/3) = 2 × 1^(1/3) × 8^(1/3) = 2 × 1 × 2 = 4.

And the maximal output level possible from (x₁, x₂) = (8, 8) is

y = 2 x₁^(1/3) x₂^(1/3) = 2 × 8^(1/3) × 8^(1/3) = 2 × 2 × 2 = 8.
