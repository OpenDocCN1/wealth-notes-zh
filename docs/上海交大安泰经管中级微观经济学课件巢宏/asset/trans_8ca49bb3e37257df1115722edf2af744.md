## 帕累托效率

- Vilfredo Pareto；1848–1923。
- 帕累托结果不允许“浪费福利”；
- 即，一个人的福利只能通过降低另一个人的福利来改善。

![Pareto efficiency diagram 1](img/e3f3f402f74cf453caf4596d2d7d7398_28_0.png)
![Pareto efficiency diagram 2](img/e3f3f402f74cf453caf4596d2d7d7398_28_1.png)

- 帕累托无效率的结果意味着仍存在未实现的互利交易收益。
- 任何实现所有可能交易收益的市场结果必须是帕累托有效的。

![Pareto efficiency diagram 3](img/e3f3f402f74cf453caf4596d2d7d7398_29_0.png)

- **竞争均衡：**
  - 所有公寓租户都认为其价值为市场价格 pᵉ 或更高
  - 所有其他人认为公寓的价值低于 pᵉ
  - 因此不再存在互利交易
  - 因此结果是帕累托有效的。

- **歧视性垄断：**
  - 公寓的分配与完全竞争市场相同
  - 因此歧视性垄断结果也是帕累托有效的。

![Discriminatory monopoly Pareto efficiency diagram](img/e3f3f402f74cf453caf4596d2d7d7398_31_0.png)

- **垄断：**
  - 并非所有公寓都被出租
  - 垄断者可以通过将空置公寓租给没有公寓的人来增加利润，只要他向此人收取的价格不高于此人的保留价格。
  - 因此垄断结果是帕累托无效率的。

### 预算约束

- 包含 x₁ 单位商品 1、x₂ 单位商品 2 等直到 xₙ 单位商品 n 的消费组合记为向量 (x₁, x₂, ..., xₙ)。
- 商品价格为 p₁, p₂, ..., pₙ。

![Budget constraint diagram](img/e3f3f402f74cf453caf4596d2d7d7398_37_0.png)

- Q：何时消费组合 (x₁, ..., xₙ) 在给定价格 p₁, ..., pₙ 下可负担？
- A：当 p₁x₁ + ... + pₙxₙ ≤ m 时可负担，其中 m 为消费者（可支配）收入。
- 所有仅刚好可负担的组合构成消费者的预算约束。这是集合

{ (x₁,...,xₙ) | x₁ ≥ 0, ..., xₙ ≥ 0 and p₁x₁ + ... + pₙxₙ = m }.
