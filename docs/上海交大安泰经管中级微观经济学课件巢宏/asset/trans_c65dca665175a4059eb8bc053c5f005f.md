## 柯布-道格拉斯成本最小化示例

So the firm’s total cost function is

c(w₁, w₂, y) = w₁ x₁*(w₁, w₂, y) + w₂ x₂*(w₁, w₂, y)

![](img/e3f3f402f74cf453caf4596d2d7d7398_1110_0.png)

So the firm’s total cost function is

```
c(w₁, w₂, y) = w₁ x₁*(w₁, w₂, y) + w₂ x₂*(w₁, w₂, y)
```

```
= w₁ (w₂ / 2w₁)^(2/3) y + w₂ (2w₁ / w₂)^(1/3) y
```

![](img/e3f3f402f74cf453caf4596d2d7d7398_1111_0.png)

**So the firm’s total cost function is**

$$c(w_1,w_2,y)=w_1x_1^*(w_1,w_2,y)+w_2x_2^*(w_1,w_2,y)$$

$$=w_1\left(\frac{w_2}{2w_1}\right)^{2/3}y+w_2\left(\frac{2w_1}{w_2}\right)^{1/3}y$$

$$=\left(\frac{1}{2}\right)^{2/3}w_1^{1/3}w_2^{2/3}y+2^{1/3}w_1^{1/3}w_2^{2/3}y$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_1112_0.png)

So the firm’s total cost function is

$$c(w_1,w_2,y)=w_1x_1^*(w_1,w_2,y)+w_2x_2^*(w_1,w_2,y)$$

$$=w_1\left(\frac{w_2}{2w_1}\right)^{2/3}y+w_2\left(\frac{2w_1}{w_2}\right)^{1/3}y$$

$$=\left(\frac{1}{2}\right)^{2/3}w_1^{1/3}w_2^{2/3}y+2^{1/3}w_1^{1/3}w_2^{2/3}y$$
