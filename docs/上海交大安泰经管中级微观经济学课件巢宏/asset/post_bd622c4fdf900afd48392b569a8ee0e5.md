
## Returns-to-Scale

- Q: Can a technology exhibit increasing returns-to-scale even if all of its marginal products are diminishing?
- A: Yes.
- E.g. $y = x_1^{2/3} x_2^{2/3}$

Let $y = x_1^{2/3} x_2^{2/3} = x_1^{a_1} x_2^{a_2}$. Since $a_1 + a_2 = 4/3 > 1$, this technology exhibits increasing returns-to-scale.

![](img/e3f3f402f74cf453caf4596d2d7d7398_944_0.png)

But $MP_1 = \frac{2}{3} x_1^{-1/3} x_2^{2/3}$ diminishes as $x_1$ increases,

![](img/e3f3f402f74cf453caf4596d2d7d7398_945_0.png)

and $MP_2 = \frac{2}{3} x_1^{2/3} x_2^{-1/3}$ diminishes as $x_2$ increases.

![](img/e3f3f402f74cf453caf4596d2d7d7398_946_0.png)

- So a technology can exhibit increasing returns-to-scale even if all of its marginal products are diminishing. Why?

![](img/e3f3f402f74cf453caf4596d2d7d7398_947_0.png)

- A marginal product is the rate-of-change of output as one input level increases, holding all other input levels fixed.
- Marginal product diminishes because the other input levels are fixed, so the increasing input’s units have each less and less of other inputs with which to work.
- When all input levels are increased proportionately, there need be no diminution of marginal products since each input will always have the same amount of other inputs with which to work. Input productivities need not fall and so returns-to-scale can be constant or increasing.

## Technical Rate-of-Substitution

- At what rate can a firm substitute one input for another without changing its output level?

![](img/e3f3f402f74cf453caf4596d2d7d7398_950_0.png)

![](img/e3f3f402f74cf453caf4596d2d7d7398_951_0.png)

The slope is the rate at which input 2 must be given up as input 1’s level is increased so as not to change the output level. The slope of an isoquant is its **technical rate-of-substitution**.

![](img/e3f3f402f74cf453caf4596d2d7d7398_952_0.png)

- How is a technical rate-of-substitution computed?

![](img/e3f3f402f74cf453caf4596d2d7d7398_953_0.png)

- The production function is $y = f(x_1, x_2)$.
- A small change $(dx_1, dx_2)$ in the input bundle causes a change to the output level of $dy = \frac{\partial y}{\partial x_1}dx_1 + \frac{\partial y}{\partial x_2}dx_2$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_954_0.png)

Since $dy = 0$ (there is to be no change to the output level), the changes $dx_1$ and $dx_2$ to the input levels must satisfy

$0 = \frac{\partial y}{\partial x_1}dx_1 + \frac{\partial y}{\partial x_2}dx_2$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_955_0.png)

Rearranging:

$\frac{\partial y}{\partial x_2}dx_2 = - \frac{\partial y}{\partial x_1}dx_1$

so

$\frac{dx_2}{dx_1} = - \frac{\partial y/\partial x_1}{\partial y/\partial x_2}$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_956_0.png)

### Technical Rate-of-Substitution; A Cobb-Douglas Example

Let $y = f(x_1, x_2) = x_1^a x_2^b$.

Then $\partial y/\partial x_1 = a x_1^{a-1} x_2^b$ and $\partial y/\partial x_2 = b x_1^a x_2^{b-1}$.

The technical rate-of-substitution is

$\frac{dx_2}{dx_1} = - \frac{\partial y/\partial x_1}{\partial y/\partial x_2} = - \frac{a x_1^{a-1} x_2^b}{b x_1^a x_2^{b-1}} = - \frac{a x_2}{b x_1}$.

For $y = x_1^{1/3} x_2^{2/3}$, $a = 1/3$ and $b = 2/3$, so

$TRS = - \frac{a x_2}{b x_1} = - \frac{(1/3)x_2}{(2/3)x_1} = - \frac{x_2}{2x_1}$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_959_0.png)

When $x_2 = 8$ and $x_1 = 4$,

$TRS = - \frac{x_2}{2x_1} = - \frac{8}{2 \times 4} = -1$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_960_0.png)
