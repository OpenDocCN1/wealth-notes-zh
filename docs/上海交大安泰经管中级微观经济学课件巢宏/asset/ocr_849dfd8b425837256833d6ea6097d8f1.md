# Short-Run & Long-Run Total Cost Curves

**MP₁** is the marginal physical productivity of the variable input 1, so one extra unit of input 1 gives **MP₁** extra output units.
Therefore, the extra amount of input 1 needed for 1 extra output unit is **1/MP₁** units of input 1.
Each unit of input 1 costs **w₁**, so the firm’s extra cost from producing one extra unit of output is

$$MC = \frac{w_1}{MP_1}$$
