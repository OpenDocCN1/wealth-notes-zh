dR/dp = X*(p)[1 + ε]

![](img/e3f3f402f74cf453caf4596d2d7d7398_712_0.png)

## 收入与需求自价格弹性

dR/dp = X*(p)[1 + ε]

但如果 −1 < ε ≤ 0 则 dR/dp > 0

并且价格上涨会提高卖方的收入。

![](img/e3f3f402f74cf453caf4596d2d7d7398_714_0.png)

## 收入与需求自价格弹性

$$\frac{dR}{dp}=X^*(p)[1+\varepsilon]$$

并且如果 $\varepsilon<-1$ 则 $\frac{dR}{dp}<0$

并且价格上涨会降低卖方的收入。

![](img/e3f3f402f74cf453caf4596d2d7d7398_715_0.png)

## 边际收入与需求自价格弹性

卖方的边际收入是卖方销售单位数量变化时收入变化的速率。

```
MR(q) = dR(q)/dq
```

![](img/e3f3f402f74cf453caf4596d2d7d7398_717_0.png)

## 边际收入与需求自价格弹性

p(q) 表示卖方的逆需求函数；即卖方可以以该价格售出 q 单位。然后

R(q) = p(q) × q

因此
MR(q) = dR(q)/dq = [dp(q)/dq] q + p(q)

= p(q) [ 1 + (q / p(q)) dp(q)/dq ] .

## 边际收入与需求自价格弹性

$$MR(q)=p(q)\left[1+\frac{q}{p(q)}\frac{dp(q)}{dq}\right].$$

并且  $$\varepsilon=\frac{dq}{dp}\times\frac{p}{q}$$

因此  $$MR(q)=p(q)\left[1+\frac{1}{\varepsilon}\right].$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_719_0.png)

## 边际收入与需求自价格弹性

MR(q) = p(q)\left[1 + \frac{1}{\varepsilon}\right] 表示卖方收入随其销售单位数量变化的速率取决于需求数量对价格的敏感性；即取决于需求的自价格弹性。

![](img/e3f3f402f74cf453caf4596d2d7d7398_720_0.png)

## 边际收入与需求自价格弹性

MR(q) = p(q)[1 + 1/ε]

如果 ε = -1    则  MR(q) = 0.

如果 -1 < ε ≤ 0 则  MR(q) < 0.

如果 ε < -1    则  MR(q) > 0.

![](img/e3f3f402f74cf453caf4596d2d7d7398_721_0.png)

## 边际收入与需求自价格弹性

如果 ε = −1 则 MR(q) = 0。销售一个额外单位不会改变卖方的收入。

如果 −1 < ε ≤ 0 则 MR(q) < 0。销售一个额外单位会降低卖方的收入。

如果 ε < −1 则 MR(q) > 0。销售一个额外单位会提高卖方的收入。

\[p(q) = a - bq.\]

则 \[R(q) = p(q)q = (a - bq)q\]

并且 \[MR(q) = a - 2bq.\]
