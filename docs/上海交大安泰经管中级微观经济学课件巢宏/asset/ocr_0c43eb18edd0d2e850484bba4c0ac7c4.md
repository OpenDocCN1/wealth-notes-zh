# The Prisoner’s Dilemma

|       | Clyde S | Clyde C |
|-------|---------|---------|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

Now suppose the start of period t = 2 has been reached. Clyde and Bonnie expect each will choose Confess next period. What should Clyde do? What should Bonnie do? Both should choose Confess.
