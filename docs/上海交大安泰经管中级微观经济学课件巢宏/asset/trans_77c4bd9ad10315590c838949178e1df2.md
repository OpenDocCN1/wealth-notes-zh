## 企业的短期供给决策

对于 y_s* > 0 的内部情形，一阶最大利润条件为

dΠ_s(y)/dy = p − MC_s(y) = 0

即，p = MC_s(y_s*)。

因此在 y_s* > 0 的利润最大化时，市场价格 p 等于产量 y = y_s* 时的生产边际成本。

## 企业的短期供给决策

- ◆ 但企业 MC 曲线向上倾斜部分上的并非每个点都代表利润最大化。

- ◆ 企业的利润函数为

\[\Pi_S(y)=py-c_S(y)=py-F-c_V(y).\]

- ◆ 如果企业选择 \(y=0\) 则其利润为

\[\Pi_S(y)=0-F-c_V(0)=-F.\]

## 企业的短期供给决策

◆ 因此企业只会在
Πₛ(y) = py − F − cᵥ(y) ≥ −F 时选择产量 y > 0。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1277_0.png)

## 企业的短期供给决策

- 因此企业只会在产量 y > 0 时
Πₛ(y) = py − F − cᵥ(y) ≥ −F。

- 即，仅当
py − cᵥ(y) ≥ 0

等价地，仅当
p ≥ cᵥ(y)/y = AVCₛ(y)。
