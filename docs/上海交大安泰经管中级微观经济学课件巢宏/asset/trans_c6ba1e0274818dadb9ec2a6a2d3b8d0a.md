## 跨期预算约束

(1 + r)c₁ + c₂ = (1 + r)m₁ + m₂

是预算约束的“未来价值”形式，因为所有项都以第二期价值表示。这等价于

c₁ + c₂/(1 + r) = m₁ + m₂/(1 + r)

这是约束的“现值”形式，因为所有项都以第一期价值表示。

## 跨期选择

- ◆ 同样，第一期最大可能的支出是
- 
- $$m_1 + \frac{m_2}{1+r}$$
- 
- 因此第一期最大可能的消费是
- 
- $$c_1 = \frac{m_1 + m_2/(1+r)}{p_1}.$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_561_0.png)

## 跨期选择

- 最后，如果第一期消费 c₁ 单位，则消费者在第一期花费 p₁c₁，留下 m₁ - p₁c₁ 用于第一期储蓄。第二期的可支配收入将是
- 
- m₂ + (1 + r)(m₁ - p₁c₁)
- 
- 因此
- 
- p₂c₂ = m₂ + (1 + r)(m₁ - p₁c₁).

## 跨期选择

**p₂c₂ = m₂ + (1 + r)(m₁ − p₁c₁)**

**整理后为**

**(1 + r)p₁c₁ + p₂c₂ = (1 + r)m₁ + m₂.**

这是预算约束的“未来价值”形式，因为所有项都以第二期价值表示。与其等价的是“现值”形式

$p_1c_1 + \frac{p_2}{1+r}c_2 = m_1 + \frac{m_2}{1+r}$

其中所有项都以第一期价值表示。
