

## 标记定价

+   ◆ 标记定价：售价是生产边际成本乘以“加成”。
+   ◆ 垄断者的加成有多大，以及它如何随着需求的自价格弹性而变化？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1432_0.png)

## 标记定价

$$p(y^*)\left[1+\frac{1}{\varepsilon}\right]=k \quad\Rightarrow\quad p(y^*)=\frac{k}{1+\frac{1}{\varepsilon}}=\frac{k\varepsilon}{1+\varepsilon}$$

是垄断者的价格。加成是

$$\frac{1}{1+\frac{1}{\varepsilon}}=\frac{\varepsilon}{1+\varepsilon}.$$

+   ◆ Q：税后利润 (1-t)Π(y*) 如何最大化？

## 对垄断征收利润税

+   - 按税率 t 征收的利润税将利润从 Π(y*) 降至 (1-t)Π(y*)。
+   - Q：税后利润 (1-t)Π(y*) 如何最大化？
+   - A：通过最大化税前利润 Π(y*)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1437_0.png)

## 对垄断征收利润税

+   - 按税率 t 征收的利润税将利润从 Π(y*) 降至 (1-t)Π(y*)。
+   - Q：税后利润 (1-t)Π(y*) 如何最大化？
+   - A：通过最大化税前利润 Π(y*)。
+   - 因此利润税对垄断者的产量水平、产出价格或投入需求的选择没有影响。
+   - 即利润税是一种中性税。

## 对垄断者征收数量税

+   - 每单位产出的数量税 $t 将生产边际成本提高 $t。
+   - 因此该税降低了利润最大化的产量水平，导致市场价格上涨，投入需求下降。
+   - 数量税具有扭曲性。

## 对垄断者征收数量税

+   - 垄断者能否将 $t 数量税全部“转嫁”给消费者？
+   - 假设生产边际成本恒定为 $k/单位产出，且垄断者面临恒定弹性需求曲线。
+   - 无税时，垄断者的价格为 $p(y^*) = \frac{k\varepsilon}{1+\varepsilon}$。

## 对垄断者征收数量税

+   - 该税使边际成本增加至 $(k+t)$/单位产出，从而使利润最大化价格变为
+     $$p(y^t)=\frac{(k+t)\varepsilon}{1+\varepsilon}.$$

+   - 买方支付的税额为
+     $$p(y^t)-p(y^*).$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_1445_0.png)

## 对垄断者征收数量税

p(yᵗ) − p(y*) = (k + t)ε / (1 + ε) − kε / (1 + ε) = tε / (1 + ε)

是转嫁给买方的税额。例如，如果 ε = -2，则转嫁的税额为 2t。

因为 ε < -1，ε / (1 + ε) > 1，因此垄断者转嫁给消费者的税额超过了税本身！

## 垄断的低效率

+   - 如果市场实现了最大可能的总交易收益，则市场是帕累托有效。
+   - 否则市场是帕累托无效。
