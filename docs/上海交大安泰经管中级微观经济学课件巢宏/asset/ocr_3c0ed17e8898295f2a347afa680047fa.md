# Profit-Maximization; An Example

At the profit-maximizing output level y*, MR(y*) = MC(y*). So if p(y) = a - b y and if c(y) = F + α y + β y² then
MR(y*) = a − 2 b y* = α + 2 β y* = MC(y*)

and the profit-maximizing output level is
$y^* = \frac{a - \alpha}{2(b + \beta)}$

causing the market price to be
$p(y^*) = a - b y^* = a - b \frac{a - \alpha}{2(b + \beta)}$
