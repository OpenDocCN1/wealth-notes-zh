# Stackelberg Games; An Example

**The leader’s profit function is therefore**

$$\Pi_1^S(y_1)=(60-y_1-R_2(y_1))y_1-y_1^2$$
$$=(60-y_1-\frac{45-y_1}{4})y_1-y_1^2$$
$$=\frac{195}{4}y_1-\frac{7}{4}y_1^2.$$

**For a profit-maximum for firm 1,**

$$\frac{195}{4}-\frac{7}{2}y_1\Rightarrow y_1^S=13.9.$$
