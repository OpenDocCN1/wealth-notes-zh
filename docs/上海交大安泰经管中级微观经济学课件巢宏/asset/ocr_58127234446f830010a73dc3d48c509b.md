# Economic Profit

+   - Suppose the firm is in a short-run circumstance in which $x_2 \equiv \tilde{x}_2$.
+   - Its short-run production function is
+     $$y = f(x_1, \tilde{x}_2).$$
+   - The firm’s fixed cost is $FC = w_2\tilde{x}_2$ and its profit function is
+     $$\Pi = py - w_1x_1 - w_2\tilde{x}_2.$$
