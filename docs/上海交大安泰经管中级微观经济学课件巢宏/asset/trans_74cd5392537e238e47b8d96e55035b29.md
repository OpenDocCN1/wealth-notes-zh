

## 预算约束再探
因此，给定 p₁ 和 p₂，拥有禀赋 (ω₁, ω₂) 的消费者的预算约束为

p₁x₁ + p₂x₂ = p₁ω₁ + p₂ω₂.

预算集合为
{(x₁, x₂) | p₁x₁ + p₂x₂ ≤ p₁ω₁ + p₂ω₂,
 x₁ ≥ 0, x₂ ≥ 0}.

## 净需求
假设 (ω₁, ω₂) = (10, 2) 且 p₁=2, p₂=3。则约束为 p₁x₁ + p₂x₂ = p₁ω₁ + p₂ω₂ = 26。

如果消费者需求 (x₁*, x₂*) = (7, 4)，则用 3 单位商品 1 交换 2 单位商品 2。净需求为 x₁* - ω₁ = 7 - 10 = -3 且 x₂* - ω₂ = 4 - 2 = +2。

![](img/e3f3f402f74cf453caf4596d2d7d7398_498_0.png)

p₁(x₁ − ω₁) + p₂(x₂ − ω₂) = 0

在价格 (p₁,p₂) 下，消费者出售商品 1 的单位以获取更多商品 2 的单位。

在价格 (p₁′,p₂′) 下，消费者出售商品 2 的单位以获取更多商品 1。

p₁′x₁ + p₂′x₂ = p₁′ω₁ + p₂′ω₂

## 劳动供给

- w 为工资率。

$p_c C = w(\bar{R} - R) + M$

整理为

$C = -\frac{w}{p_c} R + \frac{M + w\bar{R}}{p_c}$
