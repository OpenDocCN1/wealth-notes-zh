## 良态偏好

- ◆ 偏好关系是“良态”的，如果它是
  – 单调且凸的。

- ◆ 单调性：任何商品的更多数量总是更受偏好（即不存在餍足，且每种商品都是好商品）。

## 良态偏好

- - **凸性：** 商品束的混合（至少弱）偏好于商品束本身。例如，商品束 x 和 y 的 50-50 混合为
  \[
  z = (0.5)x + (0.5)y.
  \]
  z 至少与 x 或 y 一样受偏好。

![](img/e3f3f402f74cf453caf4596d2d7d7398_104_0.png)

z = (t x₁ + (1-t) y₁, t x₂ + (1-t) y₂) 对于所有 0 < t < 1 都优于 x 和 y。

## 效用函数

◆ 效用函数 U(x) 表示偏好关系 ≽，当且仅当：

- 1. x ≻ y ⇔ U(x) > U(y)
- 2. x ≺ y ⇔ U(x) < U(y)
- 3. x ~ y ⇔ U(x) = U(y)

![](img/e3f3f402f74cf453caf4596d2d7d7398_115_0.png)

## 效用函数与无差异曲线

- ◆ 考虑商品束 (4,1)、(2,3) 和 (2,2)。

- ◆ 假设 (2,3) ≻ (4,1) ~ (2,2)。

- ◆ 为这些商品束赋予任意保持偏好排序的数字；例如 U(2,3) = 6 > U(4,1) = U(2,2) = 4。

- ◆ 将这些数字称为效用水平。

## 效用函数与无差异曲线

- 无差异曲线包含同样受偏好的商品束。

- 同等偏好 ⇒ 相同的效用水平。

- 因此，无差异曲线上的所有商品束具有相同的效用水平。
