## 企业的长期供给决策

- 长期是指企业可以在其所有短期情形中进行选择的情形。
- 企业的长期供给决策与短期供给决策相比如何？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1287_0.png)

- 竞争性企业的长期利润函数为

  \(\Pi(y) = py - c(y).\)

- 生产 \(y\) 单位产出的长期成本 \(c(y)\) 仅由可变成本构成，因为在长期内所有投入都是可变的。

- 企业的长期供给水平决策为

  \(\max_{y \ge 0} \Pi(y) = py - c(y).\)

- 一阶和二阶最大化条件为，\(y^* > 0\) 时，

  \(p = MC(y)\) 且

  \(\frac{dMC(y)}{dy} > 0.\)

此外，企业的经济利润水平必须不为负，否则企业将退出行业。因此，

\(\Pi(y) = py - c(y) \ge 0 \Rightarrow p \ge c(y)/y = AC(y).\)
