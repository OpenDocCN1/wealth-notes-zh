# Application: Choosing a Tax

+   - For a given consumer, income tax is better than quantity tax.
+   - Limitations:
+     - A uniform income tax for all consumers is not necessarily better than a uniform quantity tax.
+     - Taxing income will discourage earning income.
+     - No supply response — only looked at demand side
