# Short-Run & Long-Run Total Costs

+   ◆ The long-run cost-minimization problem is $\min_{x_1,x_2 \ge 0} w_1 x_1 + w_2 x_2$ subject to $f(x_1,x_2)=y$.

+   ◆ The short-run cost-minimization problem is $\min_{x_2 \ge 0} w_1 x_1'' + w_2 x_2$ subject to $f(x_1'',x_2)=y$.
