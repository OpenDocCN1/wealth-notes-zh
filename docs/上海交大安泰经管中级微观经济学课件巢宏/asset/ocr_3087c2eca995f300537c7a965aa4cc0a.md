# Collusion & Punishment Strategies

+   - What are the firms’ profits in the noncooperative C-N equilibrium?
+   - π₁(y₁; y₂) = (24 − y₁ − y₂)y₁ − y₁².
+   - y₁* = y₂* = 4.8.
+   - So each firm’s profit in the C-N equilibrium is π₁* = π₂* = (14.4)(4.8) − 4.8² ≈ $46 each period.
