

## 技术替代率；柯布-道格拉斯示例

$y=x_1^{1/3}x_2^{2/3};\ a=\frac{1}{3}\ \text{and}\ b=\frac{2}{3}$

$TRS=-\frac{ax_2}{bx_1}=-\frac{(1/3)x_2}{(2/3)x_1}=-\frac{x_2}{2x_1}$

$TRS=-\frac{x_2}{2x_1}=-\frac{6}{2\times12}=-\frac{1}{4}$

## 良好的技术 - 凸性

凸性：如果输入束 x’ 和 x’’ 都提供 y 单位的产出，那么混合 tx’ + (1-t)x’’ 至少提供 y 单位的产出，对于任意 0 < t < 1。

## 长期与短期

+   - 长期是指企业在所有投入水平的选择上不受限制的情况。
+   - 存在许多可能的短期。
+   - 短期是指企业在至少一种投入水平的选择上受到某种限制的情况。

## 长期与短期

+   ◆ 使企业处于短期的限制示例：
+   - 暂时无法安装或移除机器
+   - 法律要求满足积极行动配额

![](img/e3f3f402f74cf453caf4596d2d7d7398_971_0.png)

## 长期与短期

+   ◆ 一个有用的思考长期的方法是，企业可以选择处于哪种短期情况。
