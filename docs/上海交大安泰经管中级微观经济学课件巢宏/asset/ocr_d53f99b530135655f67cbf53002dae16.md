# An Example of a Two-Player Game

Player B

L R

Is (U,L) a likely play?

Player A

U

D

|   | L | R |
|---|---|---|
| U | (3,9) | (1,8) |
| D | (0,0) | (2,1) |

If A plays Up then B’s best reply is Left.
If B plays Left then A’s best reply is Up.
So (U,L) is a likely play.
