

## 统一从价销售税

- ♦ 按 5% 的税率征收的从价销售税会使所有价格上涨 5%，从 p 上涨到 (1+0.05)p = 1.05p。
- ♦ 按 t 税率征收的从价销售税会使所有价格上涨 tp，从 p 上涨到 (1+t)p。
- ♦ 统一销售税适用于所有商品。

## 统一 *从价* 销售税

- ◆ 按 *t* 税率征收的统一销售税会将约束条件从

p₁x₁ + p₂x₂ = *m*

改为

(1+*t*)p₁x₁ + (1+*t*)p₂x₂ = *m*

即

p₁x₁ + p₂x₂ = *m*/(1+*t*)。
