## 短期与长期总成本

![img](img/e3f3f402f74cf453caf4596d2d7d7398_1157_0.png)

短期产量扩张路径

$x_2$; $y'''$ 短期产量扩张路径; $y''$; $y'$; $x_2'''$; $x_2''$; $x_2'$; $x_1'$; $x_1''$; $x_1'''$; $x_1$.

**长期成本为：**

$$c(y') = w_1 x_1' + w_2 x_2'$$
$$c(y'') = w_1 x_1'' + w_2 x_2''$$
$$c(y''') = w_1 x_1''' + w_2 x_2'''$$

**短期成本为：**

$$c_s(y') > c(y')$$
$$c_s(y'') = c(y'')$$
$$c_s(y''') > c(y''')$$

## 固定、可变与总成本函数

- $F$ 是厂商短期固定投入的总成本。$F$，即厂商的固定成本，不随厂商的产量水平而变化。
- $c_v(y)$ 是厂商在生产 $y$ 单位产量时其可变投入的总成本。$c_v(y)$ 是厂商的可变成本函数。
- $c_v(y)$ 取决于固定投入的水平。
- $c(y)$ 是在生产 $y$ 单位产量时固定和可变所有投入的总成本。$c(y)$ 是厂商的总成本函数：

$$c(y) = F + c_v(y).$$

## 平均固定、平均可变与平均总成本曲线

厂商的总成本函数为 $c(y) = F + c_v(y)$。对于 $y > 0$，厂商的平均总成本函数为

$$AC(y) = \frac{F}{y} + \frac{c_v(y)}{y} = AFC(y) + AVC(y).$$
