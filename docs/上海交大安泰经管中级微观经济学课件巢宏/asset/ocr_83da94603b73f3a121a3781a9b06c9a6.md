# Mixed Strategies

Player B

L, 3/4  R, 1/4

U, πᵤ

Player A

D, 1−πᵤ

|  | L, 3/4 | R, 1/4 |
|---|---|---|
| U, πᵤ | (1,2) | (0,4) |
| D, 1−πᵤ | (0,5) | (3,2) |

B’s expected value of choosing Left is 2πᵤ + 5(1 − πᵤ).

B’s expected value of choosing Right is 4πᵤ + 2(1 − πᵤ).

If 2πᵤ + 5(1 − πᵤ) > 4πᵤ + 2(1 − πᵤ), then B will choose only Left, but there is no NE in which B plays only Left.
