

## 现值

+   ◆ Q: 现在，在当前时期需要存多少钱，才能在下一期的开始获得 1 美元？
+   ◆ A: 现在存的 $m 在下一期开始时变为 $m(1+r)，所以我们想要 m 的值使得 m(1+r) = 1
+   也就是说，m = 1/(1+r)，
+   在下一期开始获得的 1 美元的现值。

## 现值

+   ◆ 在下一期开始可用的 1 美元的现值是

$$PV = \frac{1}{1+r}.$$

+   ◆ 而在下一期开始可用的 $m 的现值是

$$PV = \frac{m}{1+r}.$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_535_0.png)

## 现值

+   E.g., 如果 r = 0.1 那么你现在为下一期可用的 1 美元最多应支付

PV = 1 / (1 + 0.1) = $0.91.

+   而如果 r = 0.2 那么你现在为下一期可用的 1 美元最多应支付

PV = 1 / (1 + 0.2) = $0.83.

+   - 设 p₁ 和 p₂ 为第 1 期和第 2 期消费的价格。

+   - 跨期选择问题：给定收入 m₁ 和 m₂，以及消费价格 p₁ 和 p₂，最优选的跨期消费组合 (c₁, c₂) 是什么？
