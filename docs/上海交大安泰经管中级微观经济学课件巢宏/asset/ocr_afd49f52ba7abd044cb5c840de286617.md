# Short-Run Iso-Profit Lines

+   - A $\Pi$ iso-profit line contains all the production plans that yield a profit level of $\Pi$.
+   - The equation of a $\Pi$ iso-profit line is
+     $$\Pi \equiv py-w_1x_1-w_2\tilde{x}_2.$$ 
+   - I.e.
+     $$y=\frac{w_1}{p}x_1+\frac{\Pi+w_2\tilde{x}_2}{p}.$$
