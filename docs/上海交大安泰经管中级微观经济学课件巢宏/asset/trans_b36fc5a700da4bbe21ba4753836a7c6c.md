
## 一个例子

- 两个消费者
  - 消费者1的支付意愿较低
  - 消费者2的支付意愿较高
- 假设 MC = 0

## 二级价格歧视

- 对 x₁⁰ 收取 A，希望获得消费者1。
- 对 x₂⁰ 收取 A + B + C，希望获得消费者2。
- 但消费者2购买 x₁⁰ 会更好，并得到消费者剩余 CS = B。
- 无法让消费者自我选择。
- 也可以对 x₂⁰ 收取 A + C 来识别消费者2。
- 利润 = 2A
- 利润 = 2A + C

![](img/e3f3f402f74cf453caf4596d2d7d7398_1492_0.png)

- 减小 x₁⁰，使 A 略微减少，但 C 可以大幅增加。消费者1和2仍能被识别。
- 利润更高。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1493_0.png)

- 利润在 x₁ᵐ 处达到最大化。
- $/单位产出, MC(y), 数量, A, B, C, x₁ᵐ, x₂⁰

![](img/e3f3f402f74cf453caf4596d2d7d7398_1494_0.png)

- 二级价格歧视也可以发生在质量维度上。
- 剧院中不同座位价格不同。
- 飞机上经济舱和商务舱座位价格不同。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1495_0.png)

## 三级价格歧视

- 给定群体中的购买者对所有购买单位支付相同的价格。但价格在不同购买者群体之间可能不同。
- 商品质量在各群体之间相同。
- 可以识别群体，但无法在该群体内进一步识别。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1496_0.png)

- 垄断者通过改变供应给该市场的产品数量来操纵市场价格。
- 因此，“垄断者将对每个群体分别设定何种歧视性价格？”这一问题实际上就是“垄断者将向每个群体供应多少单位产品？”。

- 两个市场，1 和 2。
- y₁ 是供应给市场1的数量。市场1的反需求函数是 p₁(y₁)。
- y₂ 是供应给市场2的数量。市场2的反需求函数是 p₂(y₂)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1498_0.png)

- 对于给定的供应水平 y₁ 和 y₂，企业的利润为：

  Π(y₁, y₂) = p₁(y₁)y₁ + p₂(y₂)y₂ − c(y₁ + y₂)。

- 什么值的 y₁ 和 y₂ 能使利润最大化？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1499_0.png)

### 利润最大化的条件是

Π(y₁, y₂) = p₁(y₁)y₁ + p₂(y₂)y₂ − c(y₁ + y₂)。

∂Π/∂y₁ = ∂/∂y₁ (p₁(y₁)y₁) − [∂c(y₁ + y₂)/∂(y₁ + y₂)] × [∂(y₁ + y₂)/∂y₁] = 0

∂Π/∂y₂ = ∂/∂y₂ (p₂(y₂)y₂) − [∂c(y₁ + y₂)/∂(y₁ + y₂)] × [∂(y₁ + y₂)/∂y₂] = 0

![](img/e3f3f402f74cf453caf4596d2d7d7398_1500_0.png)

![](img/e3f3f402f74cf453caf4596d2d7d7398_1501_0.png)

由于 ∂(y₁ + y₂)/∂y₁ = 1 且 ∂(y₁ + y₂)/∂y₂ = 1，利润最大化的条件变为：

∂/∂y₁ (p₁(y₁)y₁) = ∂c(y₁ + y₂)/∂(y₁ + y₂)

和 ∂/∂y₂ (p₂(y₂)y₂) = ∂c(y₁ + y₂)/∂(y₁ + y₂)。

∂/∂y₁ (p₁(y₁)y₁) = ∂/∂y₂ (p₂(y₂)y₂) = ∂c(y₁ + y₂)/∂(y₁ + y₂)

![](img/e3f3f402f74cf453caf4596d2d7d7398_1503_0.png)

MR₁(y₁) = MR₂(y₂) 说明，分配 y₁、y₂ 使得销售 y₁ + y₂ 单位产出的收益最大化。

例如，如果 MR₁(y₁) > MR₂(y₂)，则应将一个单位产出从市场2转移到市场1，以增加总收益。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1504_0.png)
