
## Marginal (Physical) Products

E.g. if

$y = f(x_1, x_2) = x_1^{1/3} x_2^{2/3}$

then the marginal product of input 1 is

$MP_1 = \frac{\partial y}{\partial x_1} = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$

and the marginal product of input 2 is

$MP_2 = \frac{\partial y}{\partial x_2} = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$.

Typically the marginal product of one input depends upon the amount used of other inputs. E.g. if

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ then,

if $x_2 = 8$, $MP_1 = \frac{1}{3} x_1^{-2/3} 8^{2/3} = \frac{4}{3} x_1^{-2/3}$

and if $x_2 = 27$ then

$MP_1 = \frac{1}{3} x_1^{-2/3} 27^{2/3} = 3 x_1^{-2/3}$.

![](img/e3f3f402f74cf453caf4596d2d7d7398_917_0.png)

◆ The marginal product of input i is diminishing if it becomes smaller as the level of input i increases. That is, if

∂MPᵢ/∂xᵢ = ∂/∂xᵢ (∂y/∂xᵢ) = ∂²y/∂xᵢ² < 0.

![](img/e3f3f402f74cf453caf4596d2d7d7398_918_0.png)

E.g. if $y = x_1^{1/3} x_2^{2/3}$ then

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ and $MP_2 = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$

![](img/e3f3f402f74cf453caf4596d2d7d7398_919_0.png)

E.g. if $y = x_1^{1/3} x_2^{2/3}$ then

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ and $MP_2 = \frac{2}{3} x_1^{1/3} x_2^{-1/3}$

so $\frac{\partial MP_1}{\partial x_1} = -\frac{2}{9} x_1^{-5/3} x_2^{2/3} < 0$

![](img/e3f3f402f74cf453caf4596d2d7d7398_920_0.png)

E.g. if $y = x_1^{1/3}x_2^{2/3}$ then

$MP_1 = \frac{1}{3}x_1^{-2/3}x_2^{2/3}$ and $MP_2 = \frac{2}{3}x_1^{1/3}x_2^{-1/3}$

so $\frac{\partial MP_1}{\partial x_1} = -\frac{2}{9}x_1^{-5/3}x_2^{2/3} < 0$

and $\frac{\partial MP_2}{\partial x_2} = -\frac{2}{9}x_1^{1/3}x_2^{-4/3} < 0.$

Both marginal products are diminishing.

![](img/e3f3f402f74cf453caf4596d2d7d7398_921_0.png)

## Returns-to-Scale

- Marginal products describe the change in output level as a single input level changes.
- Returns-to-scale describes how the output level changes as all input levels change in direct proportion (e.g. all input levels doubled, or halved).

![](img/e3f3f402f74cf453caf4596d2d7d7398_922_0.png)

If, for any input bundle (x₁,...,xₙ),

f(kx₁, kx₂, ⋯, kxₙ) = k f(x₁, x₂, ⋯, xₙ)

then the technology described by the production function f exhibits constant returns-to-scale.

E.g. (k = 2) doubling all input levels doubles the output level.
