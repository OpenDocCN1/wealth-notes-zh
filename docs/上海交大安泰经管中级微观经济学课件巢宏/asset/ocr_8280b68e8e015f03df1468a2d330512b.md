# Mixed Strategies

Player B

L, 3/4    R, 1/4

Player A

U, π_U

D, 1-π_U

|  | L, 3/4 | R, 1/4 |
|---|---|---|
| U, π_U | (1,2) | (0,4) |
| D, 1-π_U | (0,5) | (3,2) |

If there is a NE necessarily π_L = 3(1 - π_L) ⇒ π_L = 3/4; i.e. the way B mixes over Left and Right must make A indifferent between choosing Up or Down.
