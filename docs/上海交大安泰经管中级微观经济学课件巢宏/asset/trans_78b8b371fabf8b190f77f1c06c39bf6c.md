

## 从个体到市场
需求函数

+   ◆ **当所有消费者都是价格接受者时，商品 j 的市场需求函数为**

$$X_j(p_1,p_2,m^1,\ldots,m^n)=\sum_{i=1}^{n}x_j^{*}(p_1,p_2,m^i).$$

+   ◆ **如果所有消费者都相同则**

$$X_j(p_1,p_2,M)=n\times x_j^{*}(p_1,p_2,m)$$

**其中** $M=nm$.

## 弹性

+   - 弹性衡量一个变量相对于另一个变量的“敏感性”。
+   - 变量 X 相对于变量 Y 的弹性为
+     εₓ,ᵧ = %Δx / %Δy。

![](img/e3f3f402f74cf453caf4596d2d7d7398_682_0.png)

## 弹性的经济应用

+   - 经济学家使用弹性来衡量敏感性
+     - 商品 i 的需求量相对于商品 i 价格的敏感性（需求的自价格弹性）
+     - 商品 i 的需求相对于商品 j 价格的敏感性（需求的交叉价格弹性）。

## 弹性的经济应用

+   - 商品 i 的需求相对于收入的敏感性（收入弹性需求）
+   - 商品 i 的供给量相对于商品 i 价格的敏感性（供给的自价格弹性）

![](img/e3f3f402f74cf453caf4596d2d7d7398_684_0.png)

## 弹性的经济应用

+   - 商品 i 的供给量相对于工资率的敏感性（供给相对于劳动价格的弹性）
+   - 以及许多、许多其他情况。
