# Collusion & Punishment Strategies

+   ◆ What are the firms’ profits in the noncooperative C-N equilibrium?

+   ◆ π₁(y₁;y₂) = (24 − y₁ − y₂)y₁ − y²₁.

+   ◆ y₁ = R₁(y₂) = (24 − y₂)/4.

+   ◆ Similarly, y₂ = R₂(y₁) = (24 − y₁)/4.

+   ◆ The C-N equilibrium (y*₁,y*₂) solves y₁ = R₁(y₂) and y₂ = R₂(y₁) ⇒ y*₁ = y*₂ = 4.8.
