# Collusion & Punishment Strategies

+   πᴹ(y₁,y₂) = (24 − y₁ − y₂)(y₁ + y₂) − y²₁ − y²₂.

+   What values of y₁ and y₂ maximize the cartel’s profit? Solve
+   
+   ∂πᴹ/∂y₁ = 24 − 4y₁ − 2y₂ = 0
+   
+   ∂πᴹ/∂y₂ = 24 − 2y₁ − 4y₂ = 0.

+   Solution is yᴹ₁ = yᴹ₂ = 4.
