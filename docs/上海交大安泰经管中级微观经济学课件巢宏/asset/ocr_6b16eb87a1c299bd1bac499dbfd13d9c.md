# The Prisoner’s Dilemma

|          | Clyde S | Clyde C |
|----------|---------|---------|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

Suppose the start of period t = 3 has been reached (i.e. the game has already been played twice). What should Clyde do? What should Bonnie do? Both should choose Confess.
