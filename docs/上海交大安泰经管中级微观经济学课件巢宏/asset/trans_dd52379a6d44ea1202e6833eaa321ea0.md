

# 短期利润最大化；柯布-道格拉斯示例

假设短期生产函数为 y = x₁^(1/3) x̃₂^(1/3)。

可变投入 1 的边际产量为 MP₁ = ∂y/∂x₁ = (1/3) x₁^(-2/3) x̃₂^(1/3)。

利润最大化条件为 MRP₁ = p × MP₁ = (p/3) (x₁*)^(-2/3) x̃₂^(1/3) = w₁。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1005_0.png)

**求解** $\frac{p}{3}(x_1^*)^{-2/3}\tilde{x}_2^{1/3}=w_1$ **对** $x_1$ **得**

$(x_1^*)^{-2/3}=\frac{3w_1}{p\tilde{x}_2^{1/3}}.$

**即，**

$(x_1^*)^{2/3}=\frac{p\tilde{x}_2^{1/3}}{3w_1}$

![](img/e3f3f402f74cf453caf4596d2d7d7398_1006_0.png)

**求解** $\frac{p}{3}(x_1^*)^{-2/3}\tilde{x}_2^{1/3}=w_1$ **对** $x_1$ **得**

$(x_1^*)^{-2/3}=\frac{3w_1}{p\tilde{x}_2^{1/3}}.$

**即，**

$(x_1^*)^{2/3}=\frac{p\tilde{x}_2^{1/3}}{3w_1}$

**所以**

$x_1^*=\left(\frac{p\tilde{x}_2^{1/3}}{3w_1}\right)^{3/2}=\left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}.$

x₁* = ( p / 3w₁ )^(3/2)  x̃₂^(1/2)   是在投入 2 的水平固定在 x̃₂ 单位时，企业对投入 1 的短期需求。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1008_0.png)

$x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}$ 是在投入 2 的水平固定在 $\tilde{x}_2$ 单位时，企业对投入 1 的短期需求。

企业的短期产出水平因此为

$y^* = (x_1^*)^{1/3}\tilde{x}_2^{1/3} = \left(\frac{p}{3w_1}\right)^{1/2}\tilde{x}_2^{1/2}$。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1009_0.png)

# 短期利润最大化的比较静态分析

+   ◆ 当产出价格 p 变化时，短期利润最大化生产计划会发生什么变化？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1010_0.png)

$$y = \frac{w_1}{p}x_1 + \frac{\Pi + w_2\tilde{x}_2}{p}$$
