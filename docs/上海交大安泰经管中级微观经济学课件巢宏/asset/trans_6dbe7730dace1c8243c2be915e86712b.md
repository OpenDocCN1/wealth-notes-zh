

## 合谋

在保证另一家企业至少获得其C-N（古诺-纳什）均衡利润的前提下，使一家企业利润最大化的产出组合路径。其中必有一种产出组合能使卡特尔的总利润最大化。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1627_0.png)

![](img/e3f3f402f74cf453caf4596d2d7d7398_1628_0.png)

\((y_1^m, y_2^m)\) 表示使卡特尔总利润最大化的产出水平。

- 这样的卡特尔稳定吗？
- 一家企业是否有动机欺骗另一家企业？
- *即*，如果企业 1 继续生产 \(y_1^m\) 单位，企业 2 继续生产 \(y_2^m\) 单位是否是其利润最大化选择？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1629_0.png)

- 企业 2 对 \(y_1 = y_1^m\) 的利润最大化反应是 \(y_2 = R_2(y_1^m)\)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1630_0.png)

```
y₂

y₁ = R₁(y₂), firm 1’s reaction curve

y₂ = R₂(y₁ᵐ) is firm 2’s best response to firm 1 choosing y₁ = y₁ᵐ.

R₂(y₁ᵐ)

y₂ᵐ

y₁ᵐ

y₂ = R₂(y₁), firm 2’s reaction curve
```

- 企业 2 对 \(y_1 = y_1^m\) 的利润最大化反应是 \(y_2 = R_2(y_1^m) > y_2^m\)。
- 如果企业 2 通过将产量从 \(y_2^m\) 提高到 \(R_2(y_1^m)\) 来欺骗企业 1，其利润会增加。
- 类似地，如果企业 1 通过将产量从 \(y_1^m\) 提高到 \(R_1(y_2^m)\) 来欺骗企业 2，其利润也会增加。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1633_0.png)

```
y₁ = R₁(y₂), firm 1’s reaction curve

y₂ = R₂(y₁ᵐ) is firm 2’s best response to firm 1 choosing y₁ = y₁ᵐ.

y₂ = R₂(y₁), firm 2’s reaction curve
```

![](img/e3f3f402f74cf453caf4596d2d7d7398_1634_0.png)

- 因此，一个以利润为导向、由企业合作设定产出水平的卡特尔从根本上是不稳定的。
- *例如，* 欧佩克（OPEC）破裂的协议。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1635_0.png)

## 合谋与惩罚策略

- 要判断这样的卡特尔能否保持稳定，我们需要知道 3 件事：
  - (i) 每家企业在卡特尔中的每期利润是多少？
  - (ii) 欺骗企业在实施欺骗的第一期所获得的利润是多少？
  - (iii) 欺骗企业在首次欺骗之后的每一期所获得的利润是多少？

- 假设两家企业面对的市场反需求为 \(p(y_T) = 24 - y_T\)，总成本分别为 \(c_1(y_1) = y_1^2\) 和 \(c_2(y_2) = y_2^2\)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1638_0.png)

- (i) 每家企业在卡特尔中的每期利润是多少？
- \(p(y_T) = 24 - y_T\)，\(c_1(y_1) = y_1^2\)，\(c_2(y_2) = y_2^2\)。
- 如果企业合谋，它们的联合利润函数为 \(\pi^M(y_1,y_2) = (24 - y_1 - y_2)(y_1 + y_2) - y_1^2 - y_2^2\)。
- 什么样的 \(y_1\) 和 \(y_2\) 取值能使卡特尔利润最大化？求解

\[
\frac{\partial \pi^M}{\partial y_1} = 24 - 4y_1 - 2y_2 = 0
\]

\[
\frac{\partial \pi^M}{\partial y_2} = 24 - 2y_1 - 4y_2 = 0
\]

![](img/e3f3f402f74cf453caf4596d2d7d7398_1640_0.png)

解为 \(y_1^m = y_2^m = 4\)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1641_0.png)

- \(\pi^M(y_1,y_2) = (24 - y_1 - y_2)(y_1 + y_2) - y_1^2 - y_2^2\)。
- \(y_1^m = y_2^m = 4\) 使卡特尔利润最大化。
- 因此最大利润为 \(\pi^M = (24 - 8)(8) - \$16 - \$16 = \$112\)。
- 假设两家企业平均分配利润，每期各获得 \$112/2 = \$56。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1642_0.png)
