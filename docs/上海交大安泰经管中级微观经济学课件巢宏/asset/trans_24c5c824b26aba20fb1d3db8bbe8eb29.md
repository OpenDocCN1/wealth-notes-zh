

## 成本最小化问题

- 考虑一家使用两种投入生产一种产出的企业。
- 生产函数为
  y = f(x₁,x₂)。
- 将产出水平 y ≥ 0 视为给定。
- 给定投入价格 w₁ 和 w₂，投入组合 (x₁,x₂) 的成本为
  w₁x₁ + w₂x₂。

## 成本最小化问题

- 对于给定的 w₁、w₂ 和 y，企业成本最小化问题为求解 min w₁x₁ + w₂x₂
  x₁,x₂≥0
  在约束条件 f(x₁,x₂) = y 下。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1090_0.png)

## 成本最小化问题

- 最低成本投入组合中的投入水平 x₁*(w₁,w₂,y) 和 x₂*(w₁,w₂,y) 是企业对投入 1 和 2 的条件需求。

- 生产 y 单位产出的（最小可能）总成本因此为 c(w₁,w₂,y) = w₁x₁*(w₁,w₂,y) + w₂x₂*(w₁,w₂,y)。

## 条件投入需求

- 给定 w₁、w₂ 和 y，最低成本投入组合位于何处？
- 总成本函数如何计算？

## 等成本线

- 包含所有成本相同的投入组合的曲线是等成本曲线。

- 例如，给定 w₁ 和 w₂，$100 等成本线方程为 w₁x₁ + w₂x₂ = 100。

## 等成本线

一般而言，给定 w₁ 和 w₂，$c 等成本线的方程为
w₁x₁ + w₂x₂ = c
即
x₂ = - w₁/w₂ x₁ + c/w₂。

斜率为 - w₁/w₂。

**在内部成本最小投入组合处：**

**(a)** \(f(x_1^*,x_2^*) = y'\) **且**

**(b)** 等成本线斜率 = 等产量线斜率；即

\[ -\frac{w_1}{w_2} = \mathrm{TRS} = -\frac{MP_1}{MP_2}\quad\text{at }(x_1^*,x_2^*). \]

- 企业柯布-道格拉斯生产函数为
  y = f(x₁, x₂) = x₁^(1/3) x₂^(2/3)。

- 投入价格为 w₁ 和 w₂。

- 企业的条件投入需求函数是什么？

## 成本最小化的柯布-道格拉斯示例

在使生产 y 单位产出成本最小化的投入组合 (x₁*,x₂*) 处：

(a) y = (x₁*)¹/³ (x₂*)²/³ 且

(b) − w₁/w₂ = − (∂ y / ∂ x₁)/(∂ y / ∂ x₂) = − [(1/3)(x₁*)⁻²/³ (x₂*)²/³] / [(2/3)(x₁*)¹/³ (x₂*)⁻¹/³] = − x₂* / (2 x₁*)

## 成本最小化的柯布-道格拉斯示例

**(a)** \(y=(x_1^*)^{1/3}(x_2^*)^{2/3}\)

**(b)** \(\frac{w_1}{w_2}=\frac{x_2^*}{2x_1^*}\).

由 (b) 得，\(x_2^*=\frac{2w_1}{w_2}x_1^*\)。

现在将其代入 (a) 得

\[y=(x_1^*)^{1/3}\left(\frac{2w_1}{w_2}x_1^*\right)^{2/3}=\left(\frac{2w_1}{w_2}\right)^{2/3}x_1^*.\]

## 成本最小化的柯布-道格拉斯示例

**(a)** \(y=(x_1^*)^{1/3}(x_2^*)^{2/3}\)

**(b)** \(\frac{w_1}{w_2}=\frac{x_2^*}{2x_1^*}\).

**由 (b) 得，** \(x_2^*=\frac{2w_1}{w_2}x_1^*\)。

**现在将其代入 (a) 得**

\[y=(x_1^*)^{1/3}\left(\frac{2w_1}{w_2}x_1^*\right)^{2/3}=\left(\frac{2w_1}{w_2}\right)^{2/3}x_1^*.\]

**因此** \(x_1^*=\left(\frac{w_2}{2w_1}\right)^{2/3}y\) **是企业对投入 1 的条件需求。**
