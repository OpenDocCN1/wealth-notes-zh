

## 自价格弹性

ε_{X_i^*, p_i} = p_i / X_i^* × dX_i^* / dp_i

例如 假设 p_i = a - bX_i。

则 X_i = (a - p_i)/b 且

dX_i^* / dp_i = -1 / b。因此，

ε_{X_i^*, p_i} = p_i / ((a - p_i)/b) × (-1 / b) = - p_i / (a - p_i).

## 自价格弹性

ε_{X_i^*, p_i} = (p_i / X_i^*) × (dX_i^* / dp_i)

例如 X_i^* = k p_i^a。则 (d X_i^* / d p_i) = k a p_i^{a-1}

因此
ε_{X_i^*, p_i} = (p_i / k p_i^a) × k a p_i^{a-1} = a (p_i^a / p_i^a) = a.

![](img/e3f3f402f74cf453caf4596d2d7d7398_704_0.png)

## 收入与需求自价格弹性

- 如果提高某种商品的价格导致需求量下降幅度很小，则卖方的收入会上升。
- 因此，自价格缺乏弹性需求会导致价格上涨时卖方收入上升。

![](img/e3f3f402f74cf453caf4596d2d7d7398_706_0.png)

## 收入与需求自价格弹性

- 如果提高某种商品的价格导致需求量大幅下降，则卖方的收入会下降。
- 因此，自价格富有弹性需求会导致价格上涨时卖方收入下降。

## 收入与需求自价格弹性

卖方的收入为 R(p) = p × X* (p)。

## 收入与需求自价格弹性

卖方的收入为 R(p) = p × X* (p)。

因此 dR/dp = X* (p) + p dX*/dp

![](img/e3f3f402f74cf453caf4596d2d7d7398_709_0.png)

## 收入与需求自价格弹性

卖方的收入为 R(p) = p × X* (p)。

因此 dR/dp = X* (p) + p dX*/dp

= X* (p) [ 1 + (p / X* (p)) (dX*/dp) ]
