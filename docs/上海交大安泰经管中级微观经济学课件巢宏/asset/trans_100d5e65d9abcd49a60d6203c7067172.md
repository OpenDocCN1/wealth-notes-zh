## 数据

+   - 轮盘上的158种独特投注
+     单个号码、两个号码、三个号码、六个号码、列（未使用）、等额投注（未使用）
+   - 什么算“近似”？
+     在赌桌上相隔一格
+     在轮盘上相隔一个槽位
+   - 因变量：在第t轮中，赌徒是否对第t-1轮中的近似命中号码下了注
+   - 控制变量：之前的投注（偏好号码）、已有的近似命中投注数量（机械性）

## 情境

+   - 急速轮盘：个人触摸屏
+     真实轮盘，庄家在中央
+     30秒下注时间，30秒转轮时间
+     位于里诺/太浩湖的大型赌场，周六晚9点至凌晨1点
+     401次不同的旋转，36位不同的玩家*，共下注6390笔

*现金余额归零后，5分钟内有新的买入视为同一玩家，超过5分钟视为新玩家
