## The Firm’s Short-Run Supply Decision

For the interior case of y_s* > 0, the first-order maximum profit condition is

dΠ_s(y)/dy = p − MC_s(y) = 0

That is, p = MC_s(y_s*).

So at a profit maximum with y_s* > 0, the market price p equals the marginal cost of production at y = y_s*.

## The Firm’s Short-Run Supply Decision

- ◆ But not every point on the upward-sloping part of the firm’s MC curve represents a profit-maximum.

- ◆ The firm’s profit function is

\[\Pi_S(y)=py-c_S(y)=py-F-c_V(y).\]

- ◆ If the firm chooses \(y=0\) then its profit is

\[\Pi_S(y)=0-F-c_V(0)=-F.\]

## The Firm’s Short-Run Supply Decision

◆ So the firm will choose an output level y > 0 only if
Πₛ(y) = py − F − cᵥ(y) ≥ −F.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1277_0.png)

## The Firm’s Short-Run Supply Decision

- So the firm will choose an output level y > 0 only if
Πₛ(y) = py − F − cᵥ(y) ≥ −F.

- i.e., only if
py − cᵥ(y) ≥ 0

Equivalently, only if
p ≥ cᵥ(y)/y = AVCₛ(y).
