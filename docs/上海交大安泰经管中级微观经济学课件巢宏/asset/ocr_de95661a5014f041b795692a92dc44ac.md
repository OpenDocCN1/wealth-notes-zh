# Third-degree Price Discrimination

$\Pi(y_1,y_2)=p_1(y_1)y_1+p_2(y_2)y_2-c(y_1+y_2).$

# The profit-maximization conditions are

$$\frac{\partial \Pi}{\partial y_1}=\frac{\partial}{\partial y_1}\bigl(p_1(y_1)y_1\bigr)-\frac{\partial c(y_1+y_2)}{\partial (y_1+y_2)}\times\frac{\partial (y_1+y_2)}{\partial y_1}$$
$$=0$$
