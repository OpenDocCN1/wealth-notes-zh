# Cobb-Douglas Technologies

◆ A Cobb-Douglas production function is of the form

```
$$y = A x_1^{a_1} x_2^{a_2} \times \cdots \times x_n^{a_n}.$$
```

◆ E.g.

```
$$y = x_1^{1/3} x_2^{1/3}$$
```

with

```
$$n = 2, A = 1, a_1 = \frac{1}{3} \text{ and } a_2 = \frac{1}{3}.$$
```
