

## 指数数

+   ◆ 随着时间的推移，许多价格都在变化。消费者“总体上”因此变得更好还是更差？
+   ◆ 指数数对这类问题给出近似答案。

![](img/e3f3f402f74cf453caf4596d2d7d7398_422_0.png)

## 指数数

- **两种基本类型的指数**
  - 价格指数，以及
  - 数量指数
- **每个指数通过取支出比率来比较基期和当期的支出。**

![](img/e3f3f402f74cf453caf4596d2d7d7398_423_0.png)

## 数量指数数

◆ 数量指数是需求数量的价格加权平均值；即

I_q = (p₁x₁ᵗ + p₂x₂ᵗ) / (p₁x₁ᵇ + p₂x₂ᵇ)

◆ (p₁,p₂) 可以是基期价格 (p₁ᵇ,p₂ᵇ) 或当期价格 (p₁ᵗ,p₂ᵗ)。

## 数量指数数

◆ 如果 (p₁,p₂) = (p₁ᵇ,p₂ᵇ) 则我们得到拉氏数量指数；

L_q = (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_425_0.png)

## 数量指数数

◆ 如果 \((p_1,p_2)=(p_1^t,p_2^t)\) 则我们得到帕氏数量指数；

$$P_q=\frac{p_1^t x_1^t+p_2^t x_2^t}{p_1^t x_1^b+p_2^t x_2^b}$$

![](img/e3f3f402f74cf453caf4596d2d7d7398_426_0.png)

## 数量指数数

◆ 数量指数如何用于对福利变化做出陈述？

![](img/e3f3f402f74cf453caf4596d2d7d7398_427_0.png)

## 数量指数数

◆ 如果 L_q = (p₁ᵇ x₁ᵗ + p₂ᵇ x₂ᵗ) / (p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ) < 1 则

p₁ᵇ x₁ᵗ + p₂ᵇ x₂ᵗ < p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ

因此消费者总体上在基期的状况比现在在当期的更好。

## 数量指数数

♦ 如果 P_q = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) > 1 则

p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ > p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ

因此消费者总体上在当期的状况比基期更好。

![](img/e3f3f402f74cf453caf4596d2d7d7398_429_0.png)

## 价格指数数

◆ 价格指数是价格的数量加权平均值；*即*

$$I_p = \frac{p_1^t x_1 + p_2^t x_2}{p_1^b x_1 + p_2^b x_2}$$

◆ $(x_1,x_2)$ 可以是基期组合 $(x_1^b,x_2^b)$ 或当期组合 $(x_1^t,x_2^t)$。

![](img/e3f3f402f74cf453caf4596d2d7d7398_430_0.png)

## 价格指数数

◆ 如果 (x₁,x₂) = (x₁ᵇ,x₂ᵇ) 则我们得到拉氏价格指数；

Lₚ = (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_431_0.png)

## 价格指数数

◆ 如果 (x₁,x₂) = (x₁ᵗ,x₂ᵗ) 则我们得到帕氏价格指数；

Pₚ = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ)

![](img/e3f3f402f74cf453caf4596d2d7d7398_432_0.png)

## 价格指数数

- 价格指数如何用于对福利变化做出陈述？
- 定义支出比率
  - M = (p₁ᵗ x₁ᵗ + p₂ᵗ x₂ᵗ) / (p₁ᵇ x₁ᵇ + p₂ᵇ x₂ᵇ)

## 价格指数数

◆ 如果
Lₚ = (p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) < (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) = M

则
p₁ᵗx₁ᵇ + p₂ᵗx₂ᵇ < p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ

因此消费者总体上在当期更好。

## 价格指数数

◆ 但，如果

P_p = (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ) > (p₁ᵗx₁ᵗ + p₂ᵗx₂ᵗ) / (p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ) = M

则

p₁ᵇx₁ᵗ + p₂ᵇx₂ᵗ < p₁ᵇx₁ᵇ + p₂ᵇx₂ᵇ

因此消费者总体上在基期更好。
