# Marginal Revenue and Own-Price Elasticity of Demand

If ε = −1 then MR(q) = 0. Selling one more unit does not change the seller’s revenue.

If −1 < ε ≤ 0 then MR(q) < 0. Selling one more unit reduces the seller’s revenue.

If ε < −1 then MR(q) > 0. Selling one more unit raises the seller’s revenue.
