## 永久债券估值

- ♦ 永久债券是一种永不终止的债券，每期支付 $x 永久。
- ♦ 永久债券的现值是多少？

![](img/e3f3f402f74cf453caf4596d2d7d7398_593_0.png)

## 永久债券估值

PV = x/(1+r) + x/(1+r)^2 + x/(1+r)^3 + ...

= 1/(1+r) [ x + x/(1+r) + x/(1+r)^2 + ... ]

= 1/(1+r) [ x + PV ]。解出 PV 得

PV = x/r.

![](img/e3f3f402f74cf453caf4596d2d7d7398_595_0.png)

## 永久债券估值

例如，如果 r = 0.1 现在及以后，那么为获得每年提供 $1000 的永久债券现在最多应支付

PV = x / r = $1000 / 0.1 = $10,000.

- ♦ r₁ + ... + rₙ 因此将是获取 n 加仑汽油在价格为 $0 时效用总变化的美元等价物。

## $ 等价效用增益

- 第一加仑的美元等价净效用增益为 $(r₁ - p_G)
- 第二加仑为 $(r₂ - p_G)，
- 以此类推，因此交易收益的美元价值为 $(r₁ - p_G) + $(r₂ - p_G) + ... 只要 rₙ - p_G > 0。
