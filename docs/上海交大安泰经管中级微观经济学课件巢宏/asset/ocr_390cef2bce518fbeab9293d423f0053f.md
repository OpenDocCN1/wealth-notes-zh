# Short-Run Profit-Maximization

$$MP_1 = \frac{w_1}{p} \quad \Leftrightarrow \quad p \times MP_1 = w_1$$

$p \times MP_1$ is the marginal revenue product of input 1, the rate at which revenue increases with the amount used of input 1.

If $p \times MP_1 > w_1$ then profit increases with $x_1$.

If $p \times MP_1 < w_1$ then profit decreases with $x_1$.
