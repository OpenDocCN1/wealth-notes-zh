$(y_1', y_2')$ 比 $(y_1^*, y_2^*)$ 能为两家企业带来更高的利润。

+ ◆ 因此两家企业都有利润激励去通过降低产量水平“合作”。
+ ◆ 这就是共谋。
+ ◆ 被称为形成卡特尔的企业正在共谋。
+ ◆ 如果企业形成卡特尔，它们应该如何做？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1619_0.png)

+ 假设两家企业希望最大化其总利润并在它们之间分配。它们的目标是合作选择产量水平 y₁ 和 y₂ 以最大化 Πᵐ(y₁,y₂) = p(y₁ + y₂)(y₁ + y₂) − c₁(y₁) − c₂(y₂)。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1620_0.png)

+ ♦ 由于企业可以合作选择其古诺-纳什均衡产量水平，从而获得其古诺-纳什均衡利润，因此企业不可能因共谋而变得更差。所以共谋必须提供至少与其古诺-纳什均衡利润一样大的利润。
