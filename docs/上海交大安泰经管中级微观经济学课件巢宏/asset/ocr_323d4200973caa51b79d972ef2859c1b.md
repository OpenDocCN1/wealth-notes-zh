# An Example of a Two-Player Game

**Player B**

|  | L | R |
|---|---|---|
| **Player A: U** | (3,9) | (1,8) |
| **Player A: D** | (0,0) | (2,1) |

(U,L) and (D,R) are both Nash equilibria for the game. But which will we see? Notice that (U,L) is preferred to (D,R) by both players. Must we then see (U,L) only?
