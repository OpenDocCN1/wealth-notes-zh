# The Prisoner’s Dilemma

|          | Clyde S | Clyde C |
|----------|---------|---------|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

So the only Nash equilibrium for this game is (C,C), even though (S,S) gives both Bonnie and Clyde better payoffs. The only Nash equilibrium is inefficient.
