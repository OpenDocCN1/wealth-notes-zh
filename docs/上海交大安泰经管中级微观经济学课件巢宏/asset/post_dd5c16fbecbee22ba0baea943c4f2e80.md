
## The Prisoner’s Dilemma

| Bonnie / Clyde | S | C |
|---|---|---|
| S | (-5,-5) | (-30,-1) |
| C | (-1,-30) | (-10,-10) |

The only credible NE for this game is where both Clyde and Bonnie choose Confess in every period. This is true even if the game is repeated for a large, but finite, number of periods.

|          | Clyde S | Clyde C |
|----------|---------|---------|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

However, if the game is repeated for an infinite number of periods then the game has a huge number of credible NE.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1784_0.png)

| Bonnie \ Clyde | S | C |
|---|---|---|
| S | (-5,-5) | (-30,-1) |
| C | (-1,-30) | (-10,-10) |

(C,C) forever is one such NE. But (S,S) can also be a NE because a player can punish the other for not cooperating (i.e. for choosing Confess).

## Exchange

- Two consumers, A and B.
- Their endowments of goods 1 and 2 are ω^A = (ω₁^A, ω₂^A) and ω^B = (ω₁^B, ω₂^B).
- E.g. ω^A = (6,4) and ω^B = (2,2).
- The total quantities available are ω₁^A + ω₁^B = 6 + 2 = 8 units of good 1 and ω₂^A + ω₂^B = 4 + 2 = 6 units of good 2.

Edgeworth and Bowley devised a diagram, called an Edgeworth box, to show all possible allocations of the available quantities of goods 1 and 2 between the two consumers.

## Other Feasible Allocations

- \((x_1^A, x_2^A)\) denotes an allocation to consumer A.
- \((x_1^B, x_2^B)\) denotes an allocation to consumer B.
- An allocation is feasible if and only if
  \[
  x_1^A + x_1^B \leq \omega_1^A + \omega_1^B
  \]
  and
  \[
  x_2^A + x_2^B \leq \omega_2^A + \omega_2^B.
