

## 一个双人博弈的例子

| Player A \ Player B | L | R |
|---|---|---|
| U | (3,9) | (1,8) |
| D | (0,0) | (2,1) |

![](img/e3f3f402f74cf453caf4596d2d7d7398_1707_0.png)

**Is (D,R) a likely play?**

If B plays Right then A’s best reply is Down.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1708_0.png)

If A plays Down then B’s best reply is Right.
So (D,R) is a likely play.

**Is (D,L) a likely play?**

![](img/e3f3f402f74cf453caf4596d2d7d7398_1710_0.png)

If A plays Down then B’s best reply is Right, so (D,L) is not a likely play.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1711_0.png)

**Is (U,L) a likely play?**

![](img/e3f3f402f74cf453caf4596d2d7d7398_1712_0.png)

If A plays Up then B’s best reply is Left.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1713_0.png)

If B plays Left then A’s best reply is Up.
So (U,L) is a likely play.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1714_0.png)

## 纳什均衡

- A play of the game where each strategy is a best reply to the other is a Nash equilibrium.
- Our example has two Nash equilibria; (U,L) and (D,R).

![](img/e3f3f402f74cf453caf4596d2d7d7398_1715_0.png)

## 囚徒困境

- To see if Pareto-preferred outcomes must be what we see in the play of a game, consider the famous example called the Prisoner’s Dilemma game.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1718_0.png)

| Bonnie \ Clyde | Clyde S | Clyde C |
|---|---|---|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

What plays are we likely to see for this game?

![](img/e3f3f402f74cf453caf4596d2d7d7398_1719_0.png)

If Bonnie plays Silence then Clyde’s best reply is Confess.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1720_0.png)

If Bonnie plays Confess then Clyde’s best reply is Confess.

![](img/e3f3f402f74cf453caf4596d2d7d7398_1721_0.png)
