

## 囚徒困境

|          | Clyde S | Clyde C |
|----------|---------|---------|
| Bonnie S | (-5,-5) | (-30,-1) |
| Bonnie C | (-1,-30) | (-10,-10) |

无论 Bonnie 选择什么，Clyde 的最佳回应始终是坦白。坦白是 Clyde 的占优策略。

同样，无论 Clyde 选择什么，Bonnie 的最佳回应始终是坦白。坦白也是 Bonnie 的占优策略。

因此该博弈唯一的纳什均衡是 (C,C)，尽管 (S,S) 能让 Bonnie 和 Clyde 都获得更好的收益。唯一的纳什均衡是无效的。

## 谁先行动？

- 在两个例子中，玩家同时选择策略。
- 这类博弈是同时行动博弈。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1725_0.png)

- 但也有其他博弈，其中一名玩家在另一名玩家之前行动。
- 这类博弈是序贯行动博弈。
- 先行动的玩家是领导者。后行动的玩家是追随者。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1726_0.png)

## 一个序贯博弈示例

- 有时一个博弈有多于一个纳什均衡，很难说哪个更可能发生。
- 当博弈是序贯的时，有时可以论证其中一个纳什均衡比另一个更可能发生。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1727_0.png)

|   | L | R |
|---|---|---|
| U | (3,9) | (1,8) |
| D | (0,0) | (2,1) |

当该博弈同时进行时，(U,L) 和 (D,R) 都是纳什均衡，我们无法判断哪个均衡更可能发生。

假设该博弈改为序贯进行，A 领先，B 跟随。我们可以用其扩展式重写该博弈。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1729_0.png)

A 先行动。B 后行动。

(U,L) 是一个纳什均衡。(D,R) 也是。哪个均衡更可能发生？

![](img/e3f3f402f74cf453caf4596d2d7d7398_1732_0.png)

如果 A 选择 U，则 B 会跟随选择 L；A 得到 3。

如果 A 选择 D，则 B 会跟随选择 R；A 得到 2。

因此 (U,L) 是更可能的纳什均衡。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1735_0.png)

这是我们之前的例子再次出现。假设再次行动是同时的。我们发现该博弈有两个纳什均衡 (U,L) 和 (D,R)。

玩家 A 被认为选择 U 或 D 进行行动，但不能同时组合；即纯粹选择 U 或 D。U 和 D 是玩家 A 的纯策略。

同样，L 和 R 是玩家 B 的纯策略。

![](img/e3f3f402f74cf453caf4596d2d7d7398_1738_0.png)
