# Marginal (Physical) Products

Typically the marginal product of one input depends upon the amount used of other inputs. E.g. if

$MP_1 = \frac{1}{3} x_1^{-2/3} x_2^{2/3}$ then,

if $x_2 = 8$, $MP_1 = \frac{1}{3} x_1^{-2/3} 8^{2/3} = \frac{4}{3} x_1^{-2/3}$

and if $x_2 = 27$ then

$MP_1 = \frac{1}{3} x_1^{-2/3} 27^{2/3} = 3 x_1^{-2/3}$.
