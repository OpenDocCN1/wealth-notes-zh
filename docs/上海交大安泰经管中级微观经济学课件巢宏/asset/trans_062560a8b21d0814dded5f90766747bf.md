## 长期利润最大化

长期利润最大化的投入1水平是多少？将

$$x_2^* = \frac{p^3}{27w_1w_2^2}$$ 代入 $$x_1^* = \left(\frac{p}{3w_1}\right)^{3/2}\tilde{x}_2^{1/2}$$

## 长期利润最大化

长期利润最大化的产出水平是多少？将

x₂* = p³ / (27 w₁ w₂²) 代入 y* = (p / 3 w₁)^{1/2} \tilde{x}₂^{1/2}

得到

y* = (p / 3 w₁)^{1/2} (p³ / 27 w₁ w₂²)^{1/2} = p² / (9 w₁ w₂)。

## 长期利润最大化

因此，给定价格 \(p\)、\(w_1\) 和 \(w_2\)，以及生产函数
\[
y=x_1^{1/3}x_2^{1/3}

\[
(x_1^*,x_2^*,y^*)=\left(\frac{p^3}{27w_1^2w_2},\frac{p^3}{27w_1w_2^2},\frac{p^2}{9w_1w_2}\right).
\]
