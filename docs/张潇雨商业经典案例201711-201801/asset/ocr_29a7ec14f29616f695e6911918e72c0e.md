# 小败局 | 盛大游戏的“传奇”崛起

从陈天桥的故事中，我们看 出他是一个 公知和沟通能力非常强的人，用手头仅有的资金和其他资源最终开启了盛大的辉煌；更重要的是陈天桥活出了自己，他知道自己想要什么，想做什么：当别人觉得“学霸”要走仕途的时候，他走向了商界；当大家觉得他功成名就赚了大钱的时候，他心中却有了淡淡的隐忧！

[1] 知道自己想要什么，或者去探索自己想要什么永远是最重要的。无论拒绝继续当秘书，还是与中华网出手，陈天桥都 很清楚自己的想法，也愿意去做出尝试。在日常生活中，听过太多故事，有着太多诱惑，很多时候我们以为自己知道了想要什么，实际上只是随意选择了他人的选择中看起来不错的那个，而并不是真正心里想要追 求的那个。
[2] 办法总还是有的，关键是积累。很多时候，克服眼前困 难的关键不是灵机一动，或者猛然发力，大多都是长期积累的结果。表面上看，浪潮、戴尔以及中国电信的同意思是幸运的，但实质上是盛大公司以前的信誉积累，以及陈天桥能够准确把握求助的重点和方向。

听过很多因为游戏而改变一个人，成就一个人的例子，今天这个，大概是最值得说出去给那些“为了你好”的家长了吧。短短的几个字，一句话，很难表达一个人所有的内心感受，正如陈天桥那句：“谢谢您，但那不是我想要的”。我很想告诉我的一些亲戚，“其实让孩子们玩游戏没那么槽”，但是这其中包含了太多需要解释的前提了。这大概也是为什么老师会在专栏里鼓励，即使人家玩《王者荣耀》，你也不应该瞧不起他。

今日商业心法分享：1.可怕的自制力。一个在网络游戏世界里呼风唤雨的人，在投身网络游戏行业之后，反而戒掉了游戏。我想陈天桥可怕的自制力背后是“目标感”，网络世界里那种“睥睨天下”的君王之感和现实生活中小渴望证明自己价值，背后都是目标感、对生命的掌控感，难是难在切换得过于脆弱。2.每个成功男人背后都有一个伟大的女人。找到一个智慧的好女人，不仅不会因为各样日常琐事损耗精力，反而会以一种非常正向的姿态激发男人。真是羡慕陈天桥和维芊芊！3.惊人的胆识。无论是“一鱼四吃”的商业模式，还是迅速找到客户在哪里，迅速组建“万人扫把”、铺设线上销售系统，都可以看出陈天桥惊人的胆识。4.执念或者说信念。陈天桥执念与中华网的分手，可以看出：一个根深蒂固的信念，对成 事有多重要。5.只为证明自己的价值，挣钱只是副产品。陈天桥创业成功之后那种并不快乐的状态，恰恰就像是周航30岁“荣老”时无所事事的状态。这足以说明：人活着并不像是当下很多年轻人追逐的那样为了挣钱，当钱多到失去意义，其他意义就会出来。

# 小败局 | “盛大盒子”为什么会失败

成功的转型，是企业发展的里程碑；失败的转型，是企业遭遇的“滑铁卢”。成败的分水岭，在于是 否选对了转型方向。简而言之，陈天桥的失误，可归结为两点：不知己、不知彼。“不知己”方面，盛大缺少做好盛大盒子的软硬件技术能力，缺少开发和整合内容的实力。最根本的，是做网络游戏起家的盛大，没有做全平台娱乐产业的“基因”。“不知彼”方面（“彼”指的是市场和对手）。当时，以家庭为载体的虚拟娱乐市场，面临有需求但不够现实、有技术但不够成熟的局面；而家庭客厅，又是传统电视台杀得你死我活的必争之地，作为民企的盛大的介入，既是市场搅局者，也是政策“添乱者”。综合来看，其结果也可想而知了。

个人认为盛大在盒子上的失败是与生俱来的，盛大之前的成功倚重因素占比太大，缺乏一个足够的积淀过程，就如同苹果的iPad，iPhone之前有iPod虽然是不 同产品，不过都能看见脉络，英特转换做处理器也不是凭空而来，这是第一点。其次大环境不成熟，并不能提供配套的技术支持，让雷军提早几年，一样做不出小米。

今天的专栏，让我想到了吴军老师讲过的“极限思维”。也更让我知道，研究能力的重要性。如果当年陈天桥把力气更多地用在自己研究产品上，明白硬件和软件的局限，也许就不会那么“固执”地要做盒子或者再等几年。当然，我们今天看，很容易“马后炮”。但是我们每个人都有 些我们“拟念”的东西，更难的也许不是坚持，而是能从旁观者的视角观察自己吧。

陈天桥当年肯定是不懂皮克斯的战略，不知道把鸡蛋放在一个篮子里，依托于盛大本身在游戏领域的多 年耕耘，陈天桥完全可以把公司转变为游戏的生产商、发行商。当时的中国网吧，出了传奇，还有CS、魔兽争霸这样的打击游戏大作，而且虽然没有正式在国内引进，日本索尼的PS游戏主机、psp掌机，任天堂的GB、GBA、NDS掌机，后来的wii主机，微软的xbox主机在中国都有非常不错的销量。盛大如果很时为这些游戏设备开发游戏提供内容，打造盛大旗下的IP，以当时他们的财力完全可以成为日本Konami、光荣、capcom、史克威尔，美国的动视暴雪、EA、Vavle这样的游戏发行商。虽然会面对盗版问题，但是依托这些平台，把中国类似轩辕剑、剑侠情缘这样的内容输出到欧美也是完全可能的。等有了自己的内容，返回头来做“盒子”也好，围绕自己IP拍电影，做动漫也好，都是顺理成章的事了。

# 小败局 | 陈天桥：人的意义在大脑

关于陈天桥对游戏白光的体验我也有过同样的感悟。大学之前痴迷于玩儿游戏，从小学到高中，这么多年换了很多款，不仅玩儿，还研究，看攻略，研究各种技术招数队 员构成杀戮更高效......大学学习游戏设计。当时，有参观一些游戏公司，自己也参与设计角色、装备、战斗特效等。我发现自己仅仅需要给角色设计一件不一样的装备，就 可以让玩家花钱花时间去追逐够买；甚至为原有的装备换一个不一样的颜色，所謂的“高级版”限量版就可以价值更高。等级、经验值、技能、装备......都仅仅是别人电脑里的一堆数据和代码，随便改一个数字，在1后添加两个0，就可以让一个人投入好几年在你制定的规则下打怪升级，吸引成千上万的人去追逐......这真的很神奇。玩家们这是在过着被 人设计好的生活.....当时我无比恐惧、一身冷汗，从此再也没有痴迷什么游戏。偶尔玩儿，仅仅是放松，能更好地控制自己。希望每个人都能做自己的主人，当你真正了解当前事物的本质，也就是要去追逐更高更远目标的时候。
