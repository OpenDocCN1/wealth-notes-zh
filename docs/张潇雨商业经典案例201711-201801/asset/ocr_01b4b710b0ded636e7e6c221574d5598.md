# 阿里 | 欺诈事件与卫哲的离开

1.卫哲。能在被市场认可的头部企业会提供不一样的视野和气质，卫哲的主观能动性非常强，他知道想要的，自身是否缺少，然后会选一条能补缺或实现的最大性价比路径。但不得不说只有在某个领域做到一定高度后再想向跨界，才会协助你宏观地把握另外一个领域的全局，所以卫哲给了我三点择业成长启示：一是做自己能垂直上升的事；二是选能让自己一直倍增价值、弥补短板的事；三是注意会成为未来趋势的行业。2.马云。这个诚信事件一定会辞退参与其中的员工，不然他们通过这种方式获得非系统利益却没有受到惩罚，那等于给别的同事提供效仿的榜样，也无缘给上万名没涉及问题的员工最大的不公，会破坏阿里整个内部系统。这样的代价太大了，阿里想的路太长（102年），马云也肯定很难。对待这个大面积爆发的問題，必然会涉及到管理层，其中或许还有很多原因同时博弈的决定。3.分享《管子·君臣》的一句话：“君道不明，则受令者疑；权度不一，则修义者惑。民有疑惑贰豫之心而上不能居，则百姓之与间，犹揭表而令之止也。”领导没有明确的边界，下面的会没有尺度来衡量攻守，反向导致员工有了问题领导也不能匡正。这就等于是让员工停止进攻的目标和守卫的底线，一旦高压线和边界确定，不会因有能力的人而有所宽容。

阿里这个公司太有中国特色了，我学到了三点：1）要有格局，有做大事的想法。2）要有激情和诚信，有能力和品质，能迎来生命中的贵人，能有真正影响力来召回险人共同为梦想奋斗！3）面对挫折要百折不挠，面对诚信要坚决守护，面对纷争要依据大道，面对批评要专注目标。最后的感觉其实很多中国人也许都应该感谢儒文化的影響，侠之大也，为国为民，知其不可为而为之，相信很多人的心底对于郭靖或杨过的侠情怀都难以忘怀。马云以风清扬自居，开发这厢院，他的心底也许永远还有一个热情万丈、无限柔情的年轻大侠，希望让这个江湖或世界更美好！希望自己也多一些侠气，在江湖里不忘初心，让心里永远装着一个更大一些的梦想，侠意江湖！

看了这几期关于阿里巴巴的专栏，让我对马云改变了一些看法。马云做事的格局的确是很大的，对战略的把握也很精准，的确是整个公司的灵魂。没有他，阿里巴巴很难有今天。做正确的事情比把事情做正确重要，堅持原則和底线是非常重要的，这里的原则和底线指的是价值观和使命。只要这样，方能修成正果。但同时，我也想指出，阿里在我眼里并不是一个伟大的公司。虽然马云目前极力在全世界销售自己的理念，想在全世界布局。在抢占国内市场时，遇到的对手虽然也十分强大，但更多的还是国外对手水土不服的问题。赚国人的钱不等于国外的钱你也能赚到，大多数国人去淘宝购物的时候是因为为什么？想一想就清楚了。等阿里在全球遍地开花的时候，阿里才能算是一家伟大的公司。

读今天的专栏，想得最多的就是与运气的关系。以前万老师讲过，成功的很大一部分就是运气，即使是让某些成功的人再来一次，都不一定能成功。但是今天的这篇专栏，我们可以看到，也许他们的成功，跟运气有关系，但是也跟他们自身脱不开了关系。如果你相信运气，那么今天这篇专栏无疑给你一个最好的解答，关于运气和成功，你应该做些什么。

# 阿里 | 蚂蚁金服和支付宝、阿里集团的关系

由于太多的信息不对称，很多在我们没有足够证据和信息的时候，就会从众评论热点事件，或是出言不逊地伤害他人，非常不理智。这样做从心理学的角度看，其实就象满足一种“我比你强，我一定对”的全能自恋。还记得前年在在大本钟前看跨年烟火时，一个爱尔兰的父亲给我和他的孩子们讲，每个都有自己的难处，永远不要轻易地评价任何一个人，即使是那个路上要钱的乞丐。从那之后在不了解更多的信息的时候，我不会对任何一个人有道德上的评判，也不会对任何一个人有失去理性的崇拜！这也是张老师这周专栏要传递的一个思想吧！

对于不确定的问题，首先是学习而不随意下判断。学习可以借鉴别人研究的结果节省时间，得到上每个专栏的讲解都是加工过的知识和信息，可以学习。分析，对于同一个问题点，即使在得到上，每个老师的着眼点和分析角度都不同。这是每个人的知识背景决定的，但最终的结论是一致的。对于不确定的问题自己也会尝试分析，无关对错，重在锻炼思维。最后做结论，综合学习的内容，他人 and 自己分析的过程。举例，投资，对于自己不确定的领域，在得到一年的时间，很多老师讲投资，李笑来老师讲投资BAT、Amazon、Google……王煜全老师讲投资，说比特币和英伟达；王炎老师指数组基金；吴军老师讲巴菲特的投资之道和指数基金。听过这些大家说投资，结合自己的实际状况分析，指数基金是可以长期投资的。当然国内缴税费用比美国要高，保证本金的相对安全是首要的，这是自己的投资理念，所以指数基金适合。 每个人学习同样的知识都会有不同的分析和结论，适合自己的才是最重要的。

曾有过武断的判断，为了避免误解和伤害，现在基本上是任何时候都不肯做轻易的判断了。要做判断的时候会：1）尽可能地去了解事实的“全貌”以及各个相关和关联方，而不会只听“一面之词”。2）考查数据的真实性，考量各方的利益点。3）设身处地地去理解当时的状况和处境，当事人的心态和局势等。

在自己拿不准或不确定的情况下，最谨慎的态度是“允许讨论、不做定性、挖掘真相、力求公正”。商业世界里有各种信息不对称，各个国家有不同的法律和政策条件，要委在一线能听到炮火的将士快速做决定的权力，只要这个将军不是贪生怕死或者为了己私利，就算是做的决定不完美也是可以原谅的。孙正义和杨致远那麽聪明的人也会在信息不对称的条件下出现这种误判和恶意的猜测，也足以窥见人性的深刻与不理性。当然阴谋论者也许可以继续腹诽马云：正是因e为孙正义和杨致远提出了强烈质疑和反对，才让马云做出让步和补偿，要不然他还不道歉违法外？所以真的应了那句話：创业者的胸怀是被委屈放大的。

想起隔壁专栏薛老师的话，对自己看不懂的事，先让它飞一会儿再说。
