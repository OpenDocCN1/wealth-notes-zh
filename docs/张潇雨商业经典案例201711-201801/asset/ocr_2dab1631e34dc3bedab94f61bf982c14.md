# 小敗局 | 雷士照明的巔峰與分家大戰

“能夠共患難，但無法同安樂”，今天討論的話題讓我想起了另一個話題“掙多少錢才能財務自由？”舉例來說，一個人每月生活費2500元，他出租房子的收益是2500元，那就算是財務自由了。只是這樣的財務自由是有條件的。宅在家裡，沒有女友及家庭負擔的財務自由。每個人的目標是不相同的，每個人的欲望是不相同的，每個人的需求是不相同的。有些人還在途中，有的人已達目的地。吳长江的目的地還在遠方，胡永玄與杜剛可能需要暫時休息一下，他們的差別只是在此而已。

[1] 要理解和接納人性，而不是與人性對抗。面對利益和權力的誘惑，其實很多人都會把持不住，就像一些人在平時工作時，都喜歡高叫一級，或者都喜歡叫這個“總”那個“總”的，多少還是滿足了人心中底的一種欲望。所以在這種情況下，只有理解和接納人的這種不足，通過利用戶權制約等形式，來規範自己的行為，特別是規範在優勢狀態下的行為。

[2] 經常反思自己的缺陷和不足。記得從小就聽大老師教導要自省，在電視劇中還可以看到提醒晉王“謙受益，滿招損”的情節。這些自省就是要讓自己在意識到自己成功的同時，仍然要找到自己的不足。現在的技術水平，容易讓人只接受自己喜歡的信息，進而窄化自己的視野，從而不知道自己的邊界究竟在哪裡。因此在經歷一段順風順水的生活後，不少人都迷失了方向，丧失了斗志，或者是試圖揪走身邊人，稱王稱霸。

在網上看了一些信息，讓人惊讶，比如說從新東方三大佬，到萬通六兄弟，到聯想柳傳志與倪光南，真功夫內斗、國美之爭等，有挺多這樣的案例的。在我看來根本問題之一還是在核心領導人身 上，為什麼阿里和騰訊的合伙人制度就成了呢？第二就是當事人缺乏成本意識，沒有看到目前的爭議給未來可能企業發展規模帶來的風險以及給自己的損失。得道多助，失道寡助，吳长江用這樣的極端方式拋去合伙人，傷害了企業的現金流，也失去了兩個有力的左膀右臂，是非常短視的。西方普遍的合伙人制度還行得挺好，也許是因為法律意識和機制更強吧。

我覺得有以下幾點原因：1.沒有現代公司治理意識，雖然公司發展得不錯，但創始人思維還停留在以前，認為我們是同學，是朋友，應該平起平坐，看不得作為公司代表的人出去拋頭露面，享受鮮花和掌聲。有現代公司治理意識的人，會明確各自的分工，有各自的分寸感。2.創業前沒有將怎麼分錢、怎麼發展談清楚，并寫在公司章程里面嚴格執行。以至於公司發展后，每個人的意見不一致，導致公司內耗。總認為同學之間一起做事，該該會伤感情，殊不知后邊這麼混亂更伤感情。3.彼此之間交流、沟通不够，再加上作為公司領導者的驕恣妄為，如隨意在公司賬上支錢，大肆揮霍，導致合作伙伴之間裂痕加大。那麼我能想到的避免此类情況的做法是，在創業前就明確好各自的股權比例，商量好公司后續的發展战略，以及什麼時候持續投入發展，什麼時候分红等等，然後明確各自在公司的職務和分工，運用現代公司治理模式來治理公司，并严格按照規章制度來办事，在生活中可以是同學、朋友，在公司工作時就在各自職責範圍內履行自己的义务。最后是嚴格要求自己，要有職業操守，管好自己，同時和合作伙伴经常交流、沟通，尊重股东的意见。

# 小敗局 | 雷士照明的資本“局中局”

[1] 為何沒有去學習資本運作的基本知識？通過文章的描述，感受到似乎在面對如此複雜的資本問題時，吳长江并沒有去深入研究資本運作的模式，以及用資本周邊的各類制度來武裝自己，從而達到目的。似乎他使用的斗争方式与其 他几个股东存在着代差，从而导致自己无法有效控制战场上的主动权。[2] 从以 往的课程介绍创业时签订的风险投资协 议，到各大公司的兴衰，可以清楚地发 现：资本的使用应该是除了技术之外， 影响公司发展最为重要的因素，也是最 致命的因素。在借助外部资金来发展自 己的时候，需要专业的知识打底，才能 进一步发挥个性，否则陷入各种种中 局，就会变得非常被动，不仅仅是友 谊丢失，甚至还会有牢狱之灾。

今日商业心法分享：1.看完今天的文章，脑海中一直浮现一个词：见识。一开始是缺乏与资本市场打交道的经验使得公司股份被贱卖，毛区健领后来获得20倍回报；抱着制衡软银富豪的初心，结果反而稀释条款的存在反而使得自己的股权被稀释；原以为施德电机可以和雷士照明形成协同效应，这是投资机构的增值服务，没想到这是资本的局中局。心里为吴长江打抱不平的同时，也在感慨资本的铁蹄和见识的重要性。2. 吳长江在公司缺钱时到处找钱，天天做噩梦，让我一下渴望自己能够设身处地进入他当时那个情景：如果当时是我，我有这样的毅力和勇气挺过来吗？看过了这么多商业经典案例，真是越来越理解中学教科书上的“天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身”之类的名言，只有真正经历过无比黑暗的人，心智才会成长起来，展翅高飞的羽翼才会有力量。

雷士照明的案例和真功夫的案例，曾经是当年创始人纠纷引发混乱的经典案例。与其说是资本介入，引发了后面的事故，不如说创始人团队未能处理好自己内部的关系，才导致恶果。同时，在别有心计的资本方看来，企业出现危机，是介入的好机会，颇有些趁人之危的意思。但这种情況，并不能塑造出一家优秀的公司来，只是出现了一个风险很大的投机机会。即低价买入股份，赶走创始人，用自己的管理团队来试图重振旗鼓，以侯后来获利。雷士的案例与其他相似的案例中有一个很大的不同点，即创始人不是心甘情愿地放弃企业。饶恩资本、3G资本，包括早期的花旗银行和标准石油公司，都曾运用过资本的力量来整合企业，但一般用的是“阳谋”。雷士案例中，仿佛看到的是“阴谋”，一家以阴谋取的公司，业绩难以达到资本的预期。一家企业，特别是中国企业，创始人的DNA很强，不是随意换一个人就能带领企业的。这往往需要创始人愿意的基础上，积极配合资本方和新进入的管理方，才能取得好的效果。显然，靠阴谋是没法达到这个目的的。资本虽然很重要，但一家企业的核心价值还是在市场与客户上面体现，这就需要好的管理和优秀的团队。否则，再多的资本也无法挽回企业的颓势。因此，优秀的资本即使发现收购的机会，最好用阳谋而不是阴谋。失去优秀创始人的公司，是没几个成功的。

老師好！隔壁的王錫全老師提到一支成功创业团队时，总会強調，“创意+技术+融资”三驾马车并驾齐驱，这也将会是创业公司的标配。回瞰前几周的课程，马云身边有蔡崇信、刘强东有徐新和张磊，如果没有这些资本运作高手，或许就不会有今天的阿里巴巴和京东。资本成就了今天中国互联网商业的繁荣，但是资本是逐利的，有时甚至是贪婪的，吴长江身边如果有一个资本高手帮他保护利益、把控风险，或许他不会落得现在的境地。善用资本，建立健全的防控机制，才能真正实现自己的规划。

# 小敗局 | 第三次出局，雷士告别“吴长江时代”

我感觉吴长江的故事表明中国的企业家应该从“江湖心态”进行升级，转变为更加成熟的“公司心态”。我所说的“江湖心态”是以感情为做事情的基础，利益为辅助。这种情况下，人心难测，可能会将小矛盾演化出大分裂。“公司心态”是有照公司治理架构，股东各自利益为公司目标，股东利益所向决定企业的發展方向，这与创业者的初心有可能会相违背。这时，如果没有足够的股份做话语权的支持，那么被请出门是符合残酷的经济视规律的。也看出，不论是同学还是好朋友合作做事情，大家感情好是一方面，另外要约定清晰各自的责、权、利，保持充分沟通的基础上，冷静决策。其次，借助资本的力量扩张时，要考慮清楚自己的能力与胃口是否匹配，单方面利好因素往往会掩盖很多风险，甚至还有合作者的资本野心。
