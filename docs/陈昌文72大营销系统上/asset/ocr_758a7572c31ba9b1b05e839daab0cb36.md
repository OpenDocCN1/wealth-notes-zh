# 德行是财富的主人

赚钱与其说是能力问题，不如说是人品问题，道德问题。一个人首先要纠正自己的人品、道德、发心、位置、定位，如果这个都搞不清楚，这个人就算讲话很厉害，也有才能，这一辈子也难。一个人要是搞清楚自己的发心、位置、定位、德行问题，这个人就算没什么能力，也能借到大力，成就一番事业。

**德行是财富的主人，也是才干的主人。财富、才干，不过是有德之人的奴隶。君子坦荡荡，小人长戚戚。**一个君子，是什么就说什么，不会藏着掖着。比如，您的儒家思想、陈昌文方法，是从陈昌文老板社群这里学来的，您就要讲明白出处，不要据为已有。据为己有，这是人品问题，这是道德素质问题，当然，也就是您的前途问题了。您以为您很聪明，实在在人品不过关。而人之视己如见肺肝然，这个社会上的任何人，都想骗别人，为什么？因为别人看您啊，就如同看到肺肝一样，您是什么人，别人心里一清二楚。所以，您讲陈昌文方法，不说陈昌文这个人，不说陈昌文老板社群，您自然是心怀鬼胎，难。您吸收到粉丝，也会觉得您这个人有问题，只是看您的直播、视频，觉得有道理而已，但很难给您付费。

**人是靠感觉活着的，第六感非常厉害，它能区别这个社会上一切。**比如，您追求一个女人，您的心里不舒服，即便是这个女人漂亮，您砸钱吸引到了，也跟他有鱼水之欢，但是您最终会痛苦，分开是大概率事件，这就是提前的感觉预告了结局，只是您没有注意。

而真正的坦荡之人，他从一开始就知道我对这个女人不爽，我不喜欢这个女人，我心里没有鬼胎，这种坦荡之人，会把一切讲明白。如果这个女人继续让这个坦荡之人不舒服，那么就早早的分开了，而不会陷入严重
