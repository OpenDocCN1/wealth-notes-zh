# 儒者， 从日常行用做起

儒家思想到底是什么？圣人为什 么厉害？不过是日常行用的小事做到极致了。做人的道理，做到极致了。

比如，早睡早起，做到了，您就比普通人时间多。

比如，锻炼身体做到了，您就比普通人身体好。

比如， 长久的做好一份工作，您就获得复利效应，成功只是时间的问题。

《论语》的伟大，在于不谈玄之又玄的东西，而只谈日常行用，普通人努力点，严格要求自己，都能触摸，都能做到的事情。大家严格按照《论语》当中的精神去做，必然能让自己的家庭幸福，社会关系和谐，阶层提升，事业、财富双丰收。
