# 天下武功，唯真不破

这世界，最可怕的就是虚假。

虚假粉丝，毫无意义，带不来欢乐，互动。

虚假的服务，欺骗顾客财富，顾客知道过后，以后就不跟您玩了。您的收入提升不起来。

虚情假意，注定不长久。天下武功，唯真不破。

只有真实才能长远。

现在是互联网时代，在网络上，不要搞欺骗，不要吹牛，老老实实做人。每句话都是真的。否则，当别人扒您皮的时候，您会死的非常难堪。那个高铁霸座的男子，就被人扒皮了，这会儿亏大了吧？做人，必须老实。不是一报，时候未到。

不要想着糊弄别人，您糊弄不了谁的，您糊弄的，只是相信您的人。大家心里跟明镜似的，一个人，必须靠实在，必须靠真真实实的功夫来生存。

网络上有许多虚假，我痛恨虚假，我不喜欢虚假。虚假不能带来金钱。我们每一刻，都必须完全真实。我知道，虚假是一种工具，是虚假的东西，都会被揭露的。我们要做的，就是实事求是，天下武功，唯真不破。
