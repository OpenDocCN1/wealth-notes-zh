# 乱讲话，是要倒霉的

不要在背后说人坏话，这个坏话一定会传到那人的耳朵里，背后要多说人好话，好话也一定会传到那人的耳朵里。我们在网络上讲课，一定要多讲人好话，一般情况下，我们就踏踏实实赚钱，踏踏实实做自己的业务，当然，我们要明白，我们一定要做正规项目，一定不要欺骗任何人，否则，就会倒霉。

您善于说好听的话，领导喜欢，就提拔您；朋友喜欢，就推荐给您好工作，您就有更好地机会；女孩喜欢您，您就有更大概率找到老婆。所以，懂得说好话，这就是资源，可以换取您想要的一切。

把自己培养成一个品好的人，然后把别人培养成人品好的人，只跟人品好的人交往，就是功德无量。讲话，只讲正面的话，帮助人的话，对人有益处的话，顺手，帮人赚钱。

乱讲话，是要倒霉的。乱讲话，有人会找您麻烦，言语最容易伤人。所以，大家一定要习惯性好讲话，讲正能量的话，对任何人都尊重，谦虚，谨慎。不给人把柄，不给人伤害我们的机会，做好免责声明。

我在网络做生意，不想得罪任何人，就算这个人很愚蠢，没事找事，我们也尽量好话讲给他听。不然我们有什么办法呢？人见多了，总是有人不上道。不上道的人，您如果跟他吵架，就是浪费时间，然后他就骂您，跟这样的人没什么好说的。没必要招惹他。

要理解，人上一百，形形色色。忍一时风平浪静，退一步海阔天空。看开点，看淡点。
