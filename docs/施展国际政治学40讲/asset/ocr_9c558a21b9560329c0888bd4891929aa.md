# 10｜自由贸易：英国如何从经济上实现降维打击？

你好，欢迎收听《国际政治40讲》，我是施晨。

上一讲我跟你们讲了大航海时代的全貌。英国同法国走不了的路，率先进入到现代秩序，对当时的其他国家展开了降维打击。这一讲我就带你们来具体看看，工业革命究竟如何让英国获得了对对手降维打击的能力。

降维打击能力的出现，不仅仅仅仅是因为工业革命生产效率高，更重要的，是与它配套的规则、以及经济政策的变迁，而配套了当时国际秩序当中的政策重心，让英国形成了贸易霸打状态。

# 重商主义政策

从大航海时代开始，世界各地的资源通过远洋贸易开始发生交换，开始突破原本那种自然经济的模式。就朝着东方经济这种种自给自足的游说经济。西边的庄园经济这种自给自足的经济。工业革命的出现，进一步摧毁了这种自然经济。

在自然经济时代，各种政府就基本无所谓经济政策，因为自然经济也没什么能够调控的对象。人们基本上也不想市场上场。国际博弈的时候，基本都是战场上下场。

到了大航海时代，就有人开始琢磨经济政策的问题了。当时实行的是一种被称为重商主义的Policy，就是要通过贸易顺差，帮助本土囤积的黄金白银，这样就有能力在战争中击败其他商业。

这种政策上比较典型的是英国在17世纪中期公布的《航海条例》，规定所有货物必须只能使用英国的航海货物，只能从英国船只运输生产国货物只能运输，力图阻止那种过度保护主义和荷兰争夺打击时的海上霸权争夺，为此英国和荷兰打了六次仗。

不过，这个时候各国的政策目标都是外在层面上，想办法把买家带到自己国内的经济政策是没有大意义的，对于各国本身而言，是一种阿念竞争，没有新鲜玩，所以拼不出结果的时候，还是只能拿起刀枪炮战上了。

但是到了工业革命的时候就不一样了。因为贸易不再是大炮的替代品，而是变成了工业生产的效率带来的新的东西。比如说新升级了，国际经济秩序就变成完全新常态了。这个时候重商主义的国际政策对工业国来说就没多大意义了。

《航海条例》在17世纪中后期后一直被执行到19世纪中期，持续了近两百年。但18世纪后期工业革命已经萌芽，事实上这个条例已经过时了，因为贸易不再是财富的来源，工业产品扩大市场是不利的。

# 推行自由贸易政策

亚当·斯密在《国富论》当中曾经批评《航海条例》，认为这种政策破坏了英国许多产部门之间的自然均衡。

因为它不恰当地提高了特定部门的利润，让资本不能流向能够产生最大利益的地方。英国整体利益受损害，因此应该废除这种保护贸易政策，转而推行自由贸易。斯密的具体论证你也不用再详细琢磨了，这里你只要记住他在呼吁自由贸易政策就行了。

然而，英国政府当时并没有马上理会斯密的说法，还是长期以来保护着既有的阶级，因为这个时候英国的政治基本主要是贵族在台阶，保护贸易对他们经营的农业是有利有利的。

工业革命中崛起的中产阶级不断抗争，终于通过议会改革在政治上有了一号发言权，而推动英国改革政策的声音。保护贸易的政策也逐渐废除了。

1849年，英国废除了《航海条例》，这是最后一个英国保护主义航海条例。英国这时终于完成政策转型，开始实行自由贸易政策。

到了这一步，降维打击的路径就出现了。英国开始推行自由贸易，而且实行的是单方面自由贸易。所谓单方面自由贸易就是，我任你进出口东西，你能否也在我这里进出口。但你出口我进口东西，我们全都要关税。

这个当然是完全去符合亚当·斯密的经济理论的，并且对先行开启自由贸易的英国而言是稳赚的，但很难想象一个国家居然会为了一个道德愿景做出如此巨大的让步。

但是你再仔细观摩一下就会发现，实际上这么做，完全符合英国的国家利益。当时英国是世界上最强大的工业国，它出口的是制成品，别的国家出口农业或采矿业，你都可以从我这里买。如果你的关税收得高，你的居民也是会通过走私的方式从我这里买。

而英国作为唯一工业国，进口的就是粮食或原材料，各都有关系，意味着它都从全球寻找最低成本的原产，对于生产成本的控制能力最强的原产，对于贸易的垄断能力也最强的原产。其他国家想从英国进口工业品，只能作为英国的原材料殖民地和产业市场存在。

工业革命让英国和其他国家之间形成了完全落差，工业经济对农业经济碾压的完全碾压的，产业贸易利益带来了降维打击的可能性，而英国的国家利益就在单方面自由贸易之中。

在这个过程中，英国逐渐积累起巨额财富，最后变成了世界的关键中心、贸易中心，在19世纪中叶达到巅峰的时候，全欧贸易的1/3和贸易城市，以后再也未能达到城市对于世界的影响力也没有这么大过。

# 内政和外交的联动

随着工业革命，出现了一个一个新状况，就是各国的内政与外交有了一定程度的联动，这是我们的分析国际政治时一个极为重要的观察角度。

之所以内政和外交能够联动起来，是因为一个国家的内政政策，最终都是通过某种政策方案获得落实。你再有本事，也得有国内政治环境能落实。再大的梦想，也是通过一个国家具体的经济状况的，但是它的经济状况不是这个国家的内政政策能直接控制的。

因为工业经济很依赖于外部，世界市场的波动就会影响到一个国家的经济状况，而世界市场的波动取决于所有国家的内部势力之总和。如果是大国，它的对内或对外政策能够引发世界市场的波动，并反传到国内，进一步传导到其他政策的影响上。

打个比方，今天美联储加息的政策，就可能会招致大量的热美元流到亚洲，拉美国家就面临资金链断裂，这就会引发美国的内政改革，并再度引发国际危机，这上面的美对的对政策体系应对这个问题。考虑到这种连锁反应用，美国在开始评估是否加息的时候，就会更加复杂的考虑。

所以，作为大国，必须得在这种内外部联动的因素中来寻找政策，顺势而为，才有机会在国际博弈中占据有利地位。

更进一步，随着经济崛起，国家内部各种利益团体的力量会发生消长变化，这种变化会改变权力内的博弈结构，进而影响到国家对改革的取向。

刚刚说的英国从重商主义转向自由贸易就是一个很好的例证，随着经济发展，英国的贵族地主与工业资产阶级在博弈中发生了一系列变化，于是就采取了政策变化。考虑这一点，我们对政治上的内外联动关系，就多了更多的观察维度。

# 世界秩序的规则秩序

从英国的成功案例中，我们还可以看到，英国推行自由贸易，这实际上是推出了一种世界通行的普遍规则秩序。英国能够真正通过这种普遍规则获利，这也是英国真正在霸主的资格存在——只有将之自己完全在霸主的秩序当中，才可能将真正实现在自己的国家利益。

什么是普遍秩序呢？就是对所有国家具有普遍约束力的普遍规则，最简单最粗暴理解主威霸权，需要注意的是普世的规则不是某城一域的得失，而是对于这种普遍规则的主导权。

这样一来，霸主在运用力量时，也会自我约束，因为它的力量只有用来维护这种普遍秩序时，才能为其他国家的长远利益服务，其他国家对霸主也可以以形成相对有效的预期，对霸主国内形成信任。

这种信任不是相信霸主抱有善意，而是相信霸主能够有意识地以自身的长远利益，愿意接受国际体系的规则约束，这些国家就只会实施低代价对抗霸主，霸主也因此可以大幅降低统治世界的成本，霸主的地位可以持续。

真正的霸主应该是尊重普遍规则的主权国家，这样非常难，这在古罗马时期是一件坏事。但是，工业革命时代，普遍规则的主权制度也更好，开始有了单纯的霸权对抗作为霸权更为了巧妙的制度。英国经济政策的转变就是一个非常好的例证。
