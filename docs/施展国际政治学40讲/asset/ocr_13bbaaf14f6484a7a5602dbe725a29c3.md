# 到底是什么国际秩序

好，说到这里，我可以总结一下前面所说的国际秩序是什么。

**国际秩序就是以全球为单位，以国家为主体方式，以贸易和战争为基本的互动方式，以国际法和国际条约为基础的**行为**规范，从而形成的一种秩序**。它在大航海时代出现欧洲而形成，深深塑造了整个现代世界，成为一个国家都要面对的外部约束条件。

所有的这些要素，从大航海时代一直到今天的这四百多年，一直在不断地演化，但是其中的起始要素就是出现在大航海时代。

比如，法国在反抗哈布斯堡帝国过程中，发展出了国家观念；英国在与西班牙对抗的过程中，发展出区别于大陆视角的海洋视角；这个过程中又巨大刺激来自国际秩序的一条辅助主线，也就是海权与陆权之间的对抗逻辑。

此外，前面提到了，这个时代还有国际法的出现。在国际法的基础上，各国家对战争和和平的规则有了基础共识，从而出现了人类历史上第一个国际体系——威斯特伐利亚体系。

所有这些，都为此后国际秩序的进一步演化奠定了基础，也形成了后续演化必须面对的一些基础框架，成为我们理解今天国际秩序演变的起点。

在大航海时代这个板块里，我会把这些国际秩序的要素是如何形成的，又是如何演化的，一一给你展示，让你了解进入1.0阶段的国际秩序如何一步步生成的。

下一讲，我们就会来说，国际秩序中的基本行为体——国家，这一观念是怎么发展出来的。

国家之间一律平等，这种理解方式也就是三四百年前才出现的。

当时的欧洲有帝国，有很多王国。帝国首先文而的概念，皇帝是谁不重要，重要的是它代表的宗教文明不能消失，也是的帝国，会消亡。帝王国首先就是他的概念，如果这片土地上的行政规则完了，王国也没了。

所以帝国理所当然地认为自己高于王国，并认为自己理应统一统治欧洲。在这种格局下，帝国和王国，都不会按照“国家之间一律平等”的方式来理解彼此的关系。

随着历史的演进，新的国家秩序逐步确立，国家之间的平等观念逐渐深入人心，成为国际秩序的重要基石。
