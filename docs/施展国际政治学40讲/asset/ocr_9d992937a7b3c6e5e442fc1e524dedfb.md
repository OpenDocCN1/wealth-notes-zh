# 04 | 海洋视角的浮现：英国是如何打败海洋霸主西班牙的？

你好，欢迎收听《国际政治学40讲》，我是陈斌。

上一讲我通过法国击败普鲁斯巴德维的故事，跟你讲述了“国海论”和战争如何改变了人的“大陆帝国时代”。除去争霸战，欧洲出现了多少次海争战争。这个海洋争霸的过程，其实就是英国对於海洋霸主西班牙的故事，故事的结果却难以想象，就是英国击败了西班牙，取代而代之，成为了新的海洋霸主。

在英国和西班牙海洋争霸的过程中，出现了一个很重要的观念转型，就是从传统的陆地视角向全新的海洋视角观念转型，这是现代国际政治中的一个很重大的变化，也是我们观察国际政治时最重要的一个视角。

你要知道，任何转型都不是容易的，因为转型意味着你要放弃自己的舒适区，进入到一种完全陌生的有过子的方式来。比如，谁会想到过去的政府以方式有着路径依赖，不会轻易偏离舒适区主动性，而欧洲确实需要对付大的变化而不稳定性。通常是意味着失败。失败者，它们无能为力之下，被迫做出观念转型，反倒有机会逆袭。

而这一讲的主角英国，也正是因为，在大航海时代的时候被落后了，才被逼迫到了观念转型。

# 陆地视角下的争霸

在这个时代，西班牙率先开拓了新大陆，在海外发现了大量殖民地，成为海洋霸主。但是，西班牙虽然最早开拓新大陆，却仍是站在陆地视角下看这个问题的。

什么叫陆地视角思考问题呢？我们可以看一下西班牙人在海外所做的尝试，明朝下。西班牙通过大航海，首先做的是发现大量贵金属矿藏。这意味西班牙人认为，财富和力量最重要的基础来源于土地。

西班牙的这种思维在当时也很容易理解，因为土地的自然供给量在定性且安全感多，海洋则充满了不确定性，所以在殖民欧洲大西洋上，占有土地一定能获取更多的机会。而对西班牙来说，除战争之外用非采取军事大航海和占领的手段，风险也比较高，它的意义也不是特别多。

不仅西班牙人是这种思维，那时候整个欧洲都是这种陆地视角，甚至加勒比海外的岛国---英国也不例外。

在陆地视角下，岛国就是一个非常不利的处境，所以英国岛国就从中国历史以来的战略目标就是如何在欧洲大陆站稳脚跟。法、西之间著名的百年战争就是为岛国占领了西方的战略目标。但在1453年，发生了两种历史意义的大事，一个是斯多曼主义者火攻君士坦丁堡，另一个是百年战争的结束。

百年战争的结果是，英国在欧洲大陆占领的领土几乎全部丢掉，再度回归脆弱的岛国地位，看上去就去做海为一个无足轻重的二流国家。之后英国又开始了持续30年的政敌战争，国内的王权争夺多位王位继承，彼此厮杀，热门国就《权力的游戏》，它的历史原型基本不就是政敌战争。

等到英国的王位争夺终于告一段落，英国发生了很长时英国历史，新教徒起之际，才发现自己在大航海上已经远远落后了。美洲气候最好最富有的土地都被西班牙、葡萄牙人占领了，留给英国的全是一些无人居住的荒芜之地。

西班牙依靠在美洲找到的殖民地，装备起规模庞大的舰队，横行四洋，更在海上建立殖民点，不如说，1493年西班牙进入北美洲，西班牙与葡萄牙还瓜分了统治全球世界的权力，其他国家的人如果未经两国的许可便想在海上航行，就是海盗行为。可以官方攻击。英国在海洋外的各种活动因缺乏就缺乏法律正当性。

你看，英国在这个时候是满院烂牌，看上去似乎没有翻盘的机会了。

就像我们前面说的，只有失败者才有动力做出转型。处在这种进退不得的状态中，英国被迫采用了种新的战略。

# 英国的观念转型

因为这个时候，英国已经没有办法再去海外占领土地了。因为英国无法再谋求占领多领地，他也开始意识到不能只控制上航道，因为只贸易到，只能够控制海上航道，就能制到洋贸易。

那怎样才能控制住海上航道呢？说起来也较简单，英国开始把重点精力放在一系列特定的港口，比如直布罗陀、好望角、马六甲、新加坡等等。这些地点都是海上航线的咽喉要道，比如直布罗陀是控制从地中海到海洋的大西洋的咽喉，好望角则是从大西洋到印度洋的咽喉，新加坡则是从印度洋到太平洋的咽喉。

控制住这些港口，海洋贸易就属于英国的财富，都可以放在他手上海军。海军就是英国的财富，它们可以放在他手上海军，而且，英国完全不用负担占领、管理和统治这些土地的成本。

进一步说，一旦英国控制了这些要点，那么即便西班牙人占领多多的领土，意义也不大了，因为西班牙那些领土上的财富，如果不想运到本土，也得从海上来，而海上的航道是控制在英国人手里，西班牙的财富，相当于要命上自己就没了。

你可能会好奇，既然控制海上据点有这么多好处，为什么西班牙人想不到呢？就像我们前面说的，领先者没动力去主动改变。而变动的西班牙作为大航海时代的先行者，他们所关注的财富首先来源于土地，从美洲的土地上已经可以获得源源不断的财富了，而那些据点并不能直接产生效益，所以西班牙人就不会有多大兴趣去占这些点。

海上据点与财富之间的关系，是需要一种根本的观念转型才能够被发现出来的。可以想到，西班牙人虽然拥有了强大的军事和航海，加于没有造到太多困扰，他们也不会改造观念。要知道，改变观念，实际上比改变世界更加困难得多，经观念是无论如何无法和旧观念调和，刚刚让你看到了，英国的观念转型也是这样。

当然，英国人占领这些海上据点也并不是一下就能完成的。也是他在漫长的历史中逐渐占领的。但是重要的是，英国通过这一时期战略的转型，开始比较关注海上战略优势，而是以控制海上航线据点为主。

理解了英国的观念转型，你就能够理解来英国的一系列行为逻辑。直到16世纪末，英国则开始允许与外殖民地，除了印度这个大例外之外，英国殖民者行为了，北美殖民地，在海上还占有太多土地，基本上殖民地，那些多半属于民间行为商业行为。

而观念转型后，英国的岛国身份也从最初的不利处境中转化为最大的便利。因为岛国可以面对任何来自陆地上的威胁，而所有的资源可以投向海洋，不用分大部分资源去照顾陆地安全这方面。

# 英国成为新一代海洋霸主

正由于这个观念转型，才让英国轻松上，最近我们两个故事。结果，也能念到，载运过海的西班牙，标志性的事件是1588年英国击败西班牙的无敌舰队，这场战斗本并极其象征意义。

无敌舰队是当时世界上最大的一个舰队，拥有100多艘战舰，3000多士兵，数万的士兵。这只只是西班牙远远穷于英国的舰队，西班牙海军战舰在西班牙却有100多艘战舰，总排水量超过了二战时期英美两国的舰队。可以想象当时西班牙海军规模达到什么程度。

此外，西班牙为了能够远洋航行，还开始了造船方面的“一体化”，更多的海，于是人们用的船只只要能够导航。船舶能海上商，同时也随着移动，没风的时候就需要依靠人力来移动。但要想进行远洋航行，桅杆需要定得长且不定的，人们开始研究改进帆的技术，形成了纯粹的帆船。

这样一来，1571年的普里特海峡大战，地中海上不可一世的土耳其舰队，土耳其就失去了主力，就失去了海洋，只集中精力在陆地上发展。

那为什么短短十几年内，西班牙开始会输船队规模小于土耳其的英国人呢？

重要原因之一，就是西班牙开始了造船术的变迁，但在航海技术上没有发生重要变化。

即使是海战，它仍然依赖于近身搏斗，就是我，我的船开到你的船上，再上你的船，然后用长枪或者刀砍。这一点，无论西班牙人还是英格兰人都熟悉，战争皆熟悉。西班牙当时的海军仍然延续，火绳枪，但无法解开英国最有利的办法还是近身搏斗，这就意味着西班牙在相当程度上，仍然是以战船的胜来打海战。

对比下英国就明显了。英国放弃了近身搏斗这种打法，专门用火炮。英国船上的炮位小于西班牙的炮位，但是火炮的炮数远远大于西班牙的火炮数量。对于西班牙来说，虽然依然近身博斗，火炮也同样不很大的射程。

所以英国人能依靠自己小船，机动灵活地摆脱西班牙战船，免得拼入内战，动不动火绳枪远距离攻击。西班牙人就很被动得很难用，不久又赶上了一场风，于是整个无敌舰队就失败了。
