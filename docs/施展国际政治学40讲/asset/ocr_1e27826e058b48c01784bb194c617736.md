# 留言精选

王晓彤
凯恩斯的看法的确有广阔而宏大的视野，而他的观点和当时欧洲政治的力量与人心并不符合，所以没有被重视。这让我想到凯恩斯从事投资的小故事：

作为世界顶尖的宏观经济学家，凯恩斯凭自己优秀的宏观经济专业、利用经济形势和行业优势进行股票投资，结果亏亏，大幅度跑输指数。

凯恩斯很不服气，继续研究，他发现投资市场既不需要远见，也不存在理性，驱动金融价格变化的是人心，于是他开始研究交易心理。

经过反复研究和实验，凯恩斯发觉交易其实类似于选美竞赛，每位评判不是选择自己认为最优秀的那位，而是选择大家都认为最优秀的那位。于是得出结论：投机是仅仅预测几个月以后因规模所决定的市场估价的基础的变化，而不是预测一项投资在以后几年的收益。

最后，凯恩斯管理了剑桥大学的一支基金，获得了极高的回报。

佛祖门徒
了解一战后世界历史发展的人或许都会由衷感叹凯恩斯的“上帝视角”，仿佛开了“天眼”一般，做出了无比准确的预言。凯恩斯在《和平的经济后果》中说，《凡尔赛和约》是“迦太基式的和平”，“它是一个残忍的胜利者在文明史上所干出最凶暴的行为之一”，凯恩斯将打败德国的法国比作是布匿战争中战胜了迦太基并将其彻底摧毁的罗马帝国。

从经济后来看，《凡尔赛和约》一味强调压榨德国，加重了德国的经济负担，同时欧洲经济也复苏乏力。同时，《凡尔赛和约》深深地刺痛了德国人民的民族情感，魏玛共和国总统里宾特洛普曾说：“作为一个军人，我绝不能感到，与接受耻辱的和平，不如光荣地战死在沙场。”和约不仅把发动战争的全部责任完全推到德国身上，而且在领土划分时拒绝考虑德国人的意愿就把众多的德意志人分割出去。《凡尔赛和约》不仅没有解决欧洲大陆的主要矛盾，也没有解决战胜国之间的矛盾，没有使其任何一方的野心得到满足。

戚志光
技术越发达，同一个产品能够影响的人的数量就越多。看看当下的互联网产品，动辄就可以影响数亿人的生活。这样的产品规模，远不是一两个国家能够容纳的。
全球化的重要作用，就是把全世界统一成一个市场，从而使得超级产品在全球范围内能够没有障碍的流通，创造出巨大的价值。
从这个角度讲，谁的产品用户越多，谁就都离不开全球化。

金戈铁马
今天课程中提到的凯恩斯，并不是一般意义上的经济学家；他的特殊之处，是对现实政治有深刻而敏锐的洞察。同时，基于这种洞察，进行了经济学理论上的创新。一战的时候，凯恩斯参与了巴黎和会，为了战争赔款政策的合理化而呼吁；经济危机和大萧条时代，他呼吁用政策拯救失业；二战结束了，他又积极参与、谋划欧洲的重建。可以看出，凯恩斯的大半生，都是伴随着战争与危机，他这一辈子，像一个天才的救火队员，总是出现在重大的危机现场，发挥重要的作用。
凯恩斯一生中最大的贡献，就在于与罗斯福合作，催生了罗斯福新政，帮助美国撑过了大萧条不仅仅，而是这些经济政策的制定和出台，并不仅仅是帮助美国，也帮助了世界上其他国家。在此前的巴黎和会上，各国的方案都是出于自身利益，基本上都是自扫门前雪，甚至把糟糕到自己国家，可以说是在实现自身政治目标的必要途径。换句话说，各国之间根本没有通过合作实现共同繁荣的意愿。而正是在罗斯福与凯恩斯合作之后，这种想法逐渐形成了；随后，国际间经济合作模式，开始成为各国的共识。二战之后的许多国际组织，包括世界银行、国际货币基金组织、关税总协定，可以说都包含着凯恩斯的思想。从中，我们不难看出，国际政治秩序，并不是一个孤立的存在，其中必然包含了重要的经济因素；把握了国际经济合作的趋势和规律，也就能够更好的理解国际政治秩序形成和演变的历程。
