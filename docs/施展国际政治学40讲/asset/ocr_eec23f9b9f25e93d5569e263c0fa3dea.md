# 中国革命的双重属性

实际上，中国影响力的展开过程跟中国的革命有着直接关联。我在《中国历史》那门课程中讲过，唐文一系列史中漫的史学家可以进入20世纪之后，“革命”便一直是中国历史的关键词，最后走上了中国共产党领导的社会主义革命道路。

对于中国在冷战时期的历史，你应该也不陌生，对于中国来说，那也是一段极为艰难岁月，尤其是20世纪60年代，中国和苏联关系破裂后，中国两大阵营的代表，也就是美国和苏联，都在处**在对立的状态**，等于被敌人全方位包围了。

然而，正是在这种局面下，**中国反而打开了一种强大的世界观**，逐步获得了在国际秩序中的影响力。这一切是怎么发生的呢？

为了搞清楚这个问题，我们得先来说**中国革命的本质**。中国革命的社会主义革命，在世界秩序的理解上，有着双重属性。

一种是普遍主义的取向，因为它主张的理想**是以全人类的解放为目的。另一种是民族主义的取向**，因为中国共产党在进行革命的时候，**大张旗鼓地实现民族独立**，改造主义与民族主义双重主张，使得大阵营时代的中国在占有一系列独特地位。

# 中国革命的普世性

先说普世性这一面，它直接地改变二战之后的国际地缘体系。

雅尔塔体系的初衷是美、英、苏、中四大国家携手**维护战后世界和平**。简单来说，就是每个国家都管理世界当中的某一部分区域，世界秩序的规定能够**确保**美国管理美洲洲，苏联管理欧洲和东欧，英国管理欧洲南部，这和当二战前的瓜分独立主义状态。

在上一讲，我讲过苏联共产主义原想激活了美国的首义主义，但**这个激活就反应在具体的改造**中，相当程度上是通过中国的共产主义革命而实现的。
