# 20 | 凯恩斯的方案：用全球经济组织来超越民族主义

你好，欢迎收听《国际政治学40讲》，我是施展。

前面两讲我们聊了一战之后彼此竞争的两种资本主义意识形态，分别是威权主义和列宁主义。在这两种政治之外，当时还出现了一种超越民族主义的经济方案，而且这个经济方案在整个二十世纪，就已经留到用到了今天的全球经济治理框架。这个就是凯恩斯的方案。

凯恩斯是我们今天非常熟悉的一位经济学家，但是1919年商事二战前反法西斯的巴黎和会，凯恩斯是代表美国政府的经济咨议会，他会和上个工作了几个月之后，就在6月底也生过上了会，当时一个比较糟糕的不满的情绪，和这一几个强国的巨头们决定，德国必须承担巨战战负赘款。

听到这个消息，凯恩斯清晰地看到，这在欧洲带来灾难，可怕的前景，决定“逃离这场噩梦”。两年后，凯恩斯回到了英国。不久之后，战胜国和败战国签订了凡尔赛的和约。而凯恩斯在三个月后，完成了一本重要的小册子，这就是《大国的经济后果》。

在这本书中，凯恩斯预言凡尔赛和约很可能会导致又一次世界大战，这个预言不幸言中。为了避免这个可怕的结果，凯恩斯在书里又提出了一套完整的方案，可惜，这些方案在当时并没有人听，直到第二次世界大战的进行结束之后，到了1944年20多年前出现的这套方案，才最重被人们讨论并付诸实践，并构成了二战后世界经济的组织机制。

听到这里你可能会先有一个问题，为什么二战后，德国还能巨献赔款，就带来什么可能的呢？

# 一战后的赔款支付

凡尔赛和约中对于德国的苛刻条件，满足战国的民众复仇主义情绪，尤其是法国人，他们在1870年的普法战争失败之后，一直对于德国人有强烈的复仇情绪，一想到这里就要对于死地而后快。

凯恩斯在会议上述战舰的领导人，战后赔款不必偿还，也是他在经济领域的主要主张，而他与绍德默斯特，一个神学大师和政治领袖，选举民来解释，他们从不接受要求这样一项议案，但是给他播来了他所掌握的英国经济主义这一角度。

听起来为一个神学问题，意思就是说德国认定本国对民族利益至高无上，神圣不可侵犯，一切战争的本都都为此让步。很明显，战胜国民族主义情绪的延续。

问题是，凯恩斯提醒人们，各国的经济并不是这样以国家为单位割裂来运行的，相反，在19世纪中期到20世纪初，英国主导的世界秩序逐渐进入了深化的全球化，到一战后，整个欧洲乃至美利坚，已经形构成了极为共同的经区，包含在经济圈上极大依赖彼此间分工，整个欧洲经济德国之中形成了复杂的分工体系，一荣俱荣，一损俱损。

如果你是巨献赔款，彻底弄垮德国经济，那么欧洲乃至西方世界的经济体都跟着遭灾重创，由战争导致的损失将远远超过所有的支付。如果说一切损失来自于战胜国所有的民族利益让步，各国经济体都会掉入可怕的深渊。

更可怕的是，即使德国有钱支付赔款，也是它赔款的危险性，就意味着战胜国对的市场会受到冲击。为什么这么说呢？

你想，德国支付赔款的能力从哪里来？它对外支付力它的货币没有设定，要为德国自身提供稳定的，它只能为外国货币，要么贬值，要么发行大量债券，从通过大规模进口来购买，要么获取巨额的外债，它只通过大规模进口来获取稳定。

问题是，大规模出口挤占的是谁的市场？恰好就是战胜国的市场。这意味着德国被迫有经济恢复能力，战胜国国内的市场冲击也越猛烈。假以时日，当德国赔款支付完毕之后，就是战胜国的灭亡之时。

面对这样的可能，凯恩斯就只得希望于德国没有这样的能力，而这样的谈话德国不可能获得赔款，于是，对与德国赔款的要求，便只剩下了一种毫无意义的羞辱，在国际政治上是极为危险的。

事实上战胜国还有一个选择，就是把德国彻底奴役，让它的本不再成为一个国家。法国确实也是这么想的，但是英国美国又不会同意。

对英国来说，不能让欧洲大陆出现一个压倒性的英国，无论怎样，所必须保留德国制（以限制法国），对英国来说，威权主义只会让民族主义，得到压迫，所以凯恩斯主张它们独立并去德国，但是德国民族制的地区如果被肢解，同样将变得民族主义原欲。所以英美不会同意肢解德国，法国自然怎么想复仇也是做不到的。

德国既不能被奴役，丹索雷巨献赔款又对德会更有利的是，那么凯尔森要巨献赔款对本国的种种条款，最终只能是战胜国搬起石头砸自己的脚，让自身的尊严国更可怕的战争，这就是凯恩斯方案的最初可怕的背景，短暂二十年之后，他的预言全部验证了。

# 凯恩斯的方案

如果凯恩斯仅仅只是在书中所指出和中所包含的巨大危险，那也只能说他是个于于口，还算伟大的思想家。凯恩斯伟大的地方就在于，他进一步提出了一整套的解决方案，这套方案直接构成了二战中期中一重要到现在的全球治理体制的底层方案。

现在来看者看凯恩斯的这套方案。

凯恩斯首先解释了为什么法国、意大利等国一定要对德国报复，民族复仇。除了为这些国家本国的民族主义歇斯底里之外，还有一个更重要的原因，即这些国家为了在战争中当得下，也借了大额的公债，战争打响这些国家的经济也被极大冲击，所以就只好拼命压榨德国，从这些钱才能还债。

而战偿是欠谁的债？主要是英国和美国，所以，既然让法国意大利报复美国对德国巨额的战款，那么美国也必须允许法国意大利偿还给他们的债务，否则这个事情在经济上就是无解的。

按说欠债还钱天经地义，但问题是，对商业贷款来是确定如此，可战争贷款是一种政治贷款，两贷款的目的是不同的，政治贷款的目的是为了在本土的价值，政治贷款的实现就是实现你的政治目标。如果一定要偿还它，会导致最重要的目标政治目标会求落空甚至走向反目的，那么此时可能需求还债，这才是更加公正的。

这还仅仅是第一步，凯恩斯接着就提出一系列的措施，要在国际组织的框架下成立一系列国际机构。

首先，要成立一个自由贸易联盟，联盟内的国家不能对其他联盟成员设设的设限设限有关税，联盟下面应当成立一个协调联盟内部煤炭和钢铁生产的委员会。此外，还应成立一个提供国际贷款的机构，所有的国有法团，无论是官僚政府，都应当向所有的法团机构获得贷款，以期帮助衰退的各国重建经济。

与这个国际机构机构相配套的，还有一个自由保证基金，以此机制帮助各国偿还贷，进而稳定汇率，避免经济危机。凯恩斯建议美法英军国各给两分，他希望由此能够确保美国在这些国际组织中的主导地位，从而确保英国对于国际规则的主动权。

说到这儿，你可能已经能够很多的东西往下很相似了。

凯恩斯建议英美两国放还战争贷款，这不是二战后欧洲复兴的贷款计划非常相似吗？协调欧洲内部煤炭和钢铁生产的委员会，这不就是二战后的欧洲煤钢联共的第一步步，欧洲共同市场的早期吗？成立有自由国际，提供国际贷款的机制以及设定自由国际保证基金，这不就是二战后的关贸总协定、世界银行和国际货币基金组织三大国际经济组织的原因吗？

凯恩斯所提出的这套方案，都是要用于一种普世主义的经济方案，来克服民族主义灾难的深灾难。

# 技术演化和经济单位规模的关系

说到这里，你可能已经会到一个问题，在上个时代，大家到时代，我们讨论过边际经济学家怀特的理论。他认为的国际政治理论确实是一套民族主义理论，而且德国和奥地利的民族主义都是李嘉图式的理论有关。

那么，为何在大革命时代，民族主义的经济理论不会带来严重的问题，但是到了一战之后就不大行得通了？

这其实和技术的演化有关。人类的技术在历史上一直在持续演化，但最近二三十年以后，技术演化的速度大大加快。不同的是，技术越来越远的过程对技术的规模有不同的要求。越是最近出现的技术，所需要的经济规模的规模就越大。

比如，水力磨坊和手工劳动这种技术，最基本的经济单位就是中世纪的庄园或者贸易城邦；第一次工业革命以蒸汽机为代表这种技术，最基本的经济单位是以近代民族国家，或者像英国这样的无规模的国家；而第二次工业革命以互联网和量化工程国家，最适中的国家。
