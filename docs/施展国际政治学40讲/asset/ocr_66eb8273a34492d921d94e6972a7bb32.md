# 30 | 困境（上）：大阵营的两大盟主面临哪些困境？

您好，欢迎收听《国际政治学讲习》，我是施展。

上一讲里我们讨论了第三次世界的兴起，对世界秩序以及东西方阵营都带来了什么样的影响。这一讲，我们再把视线拉回到东西方两大阵营的盟主，看看他们面临着什么样的困境。

在这些困境当中，既有属于美国和苏联的共同困境，也有它们各自独特的困境。

# 美苏的共同困境

实际上，美国和苏联的共同困境我们在前面也讲过，也就是美国对苏联都有于管理为主观的道德诉求，它对臣民自己的理性追求了所有强大。这样一种欲望让它们在国内外实践这种理想时的一系列困境，又会让它们陷入一种尴尬的境地，被人调侃。

在冷战当中，这个问题倒不严重，因为不管是美国和前苏联，超过半个球的北方，刚好都在对方向的区域里。在那地方，两个盟主互相可以如下面去道德，指责对方在那边建立了邪恶的秩序，责任不在自己这一边。

但是，等到冷战结束，苏联解体了，困境就来了。比如苏联势力退出的地方，就该美国去填补秩序了，比如阿富汗之类的地方，但这里是在美国的扩张半径之外的。

原则上说，这种地方的秩序，美国应该去管，但管了之后会发现，在这里的平民生活，从没啥效果；用不文则不然，它自己的替身主义也就虚伪化了，这么会给你带来麻烦的力量很多口实，这是一种左右为难的困境。

除了这种理想和现实之间的困境，东方东西主这个时期在第三国家相处的过程里会面临一种全新的道德困境。我前面也讲过里，原子弹的出现，使得大国在前面也不敢直接爆发战争了，大国的争斗只能通过小国之间的代理人战争来完成。

于是，有些小国处在国际冲突的十字交叉口，就会成为一个煽动性的支点。比如在20世纪50年代的时候，朝鲜就是这样的支点。一个大国可以如下演美态，全副身心的目光。60年代的越南和古巴，70年代的安哥拉，都曾经起过这种支点的。

冷战时的小国虽然有很大的比较前在很小，前经是向大国发起象征性的挑衅，在冷战后的历史上，极少有哪个小国去挑衅大国。因为太极会被大国给变了样，但是到了冷战时期，国际通道迅速发生了，轻易小国一个国家在国国际通道上成为一件使其不正当行事的毒瘤，更别提用原子弹这种毁灭性武器去打击小国了。

这就让大国十分难受，大国是有原子弹的，但是大国却不可能去正大地打击小国侵略。而一旦不是原子弹了，大国自己打完小国战斗后，就很容易有国际可能击击中。这对大国来说是一个运太不到家终战的消耗状态。

因此，在这种情况下，大国也不愿意轻易发动对小国的战争。小国也知道大国不敢真的去打击它，于是小国就可以肆无忌惮地挑衅，但大国却因此陷入到一种道德困境。甚至是一种带有威信的道德困境，因为大国的威胁起来好像什么也不那么可信了。

# 美国的独特困境

刚才说过的两大盟主面临的共同困境，再来探讨它各自面临的独特困境。对任何一个盟主来说，在它的盟主之上理念都需要国家，就会在现实中形成某一理想或者理想之上的经济秩序问题。但两大盟主各自的体系里面，又面临着一些特殊的困境。

先说美国这边。支撑自由商业体系的，除了国际货币基金组织、世界银行和作为世界贸易组织的美元贸易协定。这三个大组织之外，还额外需要一样统一的大国际货，也就是世界货币。但是，美元作为世界货币却面临到一个困境，这个困境被称为世界货币矛盾，这是由美国经济学家特里芬提出来的。

特里芬注意到，因为美元是世界货币，各国有贸易的时候都倾向用美元来结算，所以世界上其他国家和地区都会去美元资产囤，美元就会大量流出。但如果美元太流出了，美元就会贬值，贬值厉害了，如果说美元贬值了，那么美元的世界货币地位就会动摇摇摆欲坠。

这就出现一个两难困境，如果美元不流出国之外，美元就没办法成为世界货币；如果流出的规模太大，美元又太贬值，它也很难维持世界货币地位。

美元的流出规模太大了，慢慢就超过了黄金储备，就会出现大规模的国际波动，人们想要拿着更加保险的安全资产，就换成黄金会更加安全。到了1971年，美国终于扛不住了，尼克松也宣布美元跟黄金脱钩，不再以黄金作为担保。

新问题又来了，拿着美元不能再随时兑换成黄金，凭什么人们还愿意去持有美元呢？所以美元上油。全球另外石油一类的东西作为担保，你手里拿着美元，就相当于拿着石油，那么美元仍然可以替人们接受世界货币。

在这一过程中，美国跟产油国之间便强化形成了一系列特殊的利益关系，产油国必须确保自己矿产国的高度依赖，而非美国法就保美元的相对性。中东的国际贸易以美元需要一种特殊的位置，这不仅仅是因为美国需要石油，实际上美国自己也生产石油。更强的原因是因为美国自己的货币稳定性的要求。

美元跟石油的捆绑关系没有落实为一种成文的承诺，它是一种隐性的关系，所以在法律上，美国不是不以任何实物作为担保的，这就改变了美元的货币流通逻辑。

跟美元脱钩之后，美元从本位货币转为信用货币，美元的价值不再从金位量里获得，而是从美国的国家信用中获得。信用货币的本位又比多少的虚虚实实为基础。实质化的结果就是，负币对于国家信用的需求，尤其是对美国的国家信用的需求，就会变得前所未有地高，这是货币史上未出现过的情形，也构成了美国能够继续作为世界盟主的一个基础。

从本位货币到信用货币的转变，还有一个重要效益。由国家发行的货币需要不再受制于黄金的储备情况，而是可以按自己的政策来改变货币的发行量。大家自然可以用信贷背书向本国借债了。这样家，国家就可以通过控制货币的发放量，让经济获得一种温和又稳定的通胀获得状态，这叫做政策性工具，因此使政府获得一种新的经济调控工具。

更进一步，信用货币的出现也类似1929年的那种经济危机不再可避免了。在本位货币的时候，政府受制于黄金储备的限制，很难使用货币政策手段解决金融的困境。而一旦转化为信用货币，新的政策工具就出现了。

对比2008年的金融危机就会发现，一开始人们以为的尼克松的脱钩不小于是1992年，但是最后，2008年的金融危机的时间却被化解了，这显然是因为货币的进展被改变了。

所以，美国虽然面临着特里芬难题，但这个难题还是用各种办法去往前推进的，甚至过程中美国还实现了新的机会。但是再看苏联这边就一下了。

# 苏联的独特困境

苏联首先面临一个问题就是，如何维系自己阵营的统一性。

依据苏联的革命话语来说，共产主义革命是属于全人类的革命，必须统一指挥，才有和动力。所以苏联要求全人类的社会主义国家和盟主都得服从莫斯科的统一领导，如果有不听的，苏联就对其施行干预，有必要的话可以一直上升到武装干涉，以便确保全人类的革命事业不受妨害。苏联在20世纪50年代对波兰和匈牙利，60年代对捷克的克洛洛戈夫，都进行了直接的武装干预。

对一个主义国家进行武装干预，尤其是在民族自治这种理念正在逐渐被接受的政治正确时代，这种行为都是非常不正当的。因此苏联在60年代就出来一个理论，叫做社会主义大家庭主义。大意思，任何一个社会主义国家都属于整个大家庭的利益，而大家庭的利益是等同于全人类的普遍革命事业所要求的。

全球革命领导着苏联国，因此，苏联可以向大家庭中的盟主国进行适当的干涉。这番话语也确实包装苏联国。但对苏联盟主国同样也会伤害共产主义阵营的正当性，这是苏联在政治层面上面临的正当性困境。

同时，苏联还会面临一些经济方面的困境。在前面的课程里面说过，经济的计划管理，我们的主要任务是工业化的有能工重工业。第二次工业革命的技术被发明出来之后，要高速发展农业重工业，靠的不仅是创新要力，而是起源的起始点和组织效率。资本主义国家通过市场经济组织起来和资源无与伦比，所以苏联在二战后发展得很快。

但是每一轮的技术革新，都有一个技术红利周期。等到这一轮的技术红利被吃完之后，经济需要靠技术革新，靠新一轮的技术革新来创造新的经济增长力。但是计划里排除了竞争，创新和创造是没法设计的，所以计划经济创新和创新的能力，苏联的居经为二战后爆发式的增长速率，逐渐就衰退到了近乎停滞的低速增长。
