# 普通法和大陆的深层差异

普通法和大陆法的深层差异在哪里？简单一句话来概括，对普通法来说，法律是被发现出来的，对大陆法来说，法律是被发明出来的。

法律是被发明出来的，这个好理解。大陆法对于法律的发明，就是立法。立法机构以一些优先性理论导出的价值原则为出发点，按照严格的法学理论，制定出整齐划一的法条。

那么，普通法是被发现出来的，这是什么意思呢？我们来看一看这个发现的过程，你就知道了。

这里多说一句，实际上，在16、17世纪之前，不仅仅英国，整个欧洲大家流行的多半也是习惯法，像德国的普通法，有差异，但差别并不大。直到16、17世纪，英国和欧洲的法律体系才真正有了区分。在英国，以法律为习惯法的美洲，保持普通法的传统。法国，法律是被发现出来的；但是欧洲的法律就成了大陆法的状态。

# 那么，为什么16、17世纪之前，欧洲各法的法律都被发现出来的呢？

听过前面的课程你就会知道，近代以前的欧洲，到处都处在封建割据的状态，国王基本上不了事儿的大贵族。国王们没有强到去做一些事情，做不了，为了自己的利益。

国王和贵族之间，贵族和贵族之间，形成了很复杂的利益争夺关系。博弈的结果会形成某种稳定的状态，过去的经验就会逐渐形成未来人们的参照标准，逐渐就形成了习惯传统。普通法是这种博弈中演化出来的。由中国一民王法是由这样的博弈中演化出来的，由“中国是”在王法下，也就是说国王法王于法。但这不是国王不愿意遵守法律，而是因为国王没能力说法统治。

各种博弈后来逐渐转移到法庭上进行。普通法的司法过程逐渐规范化，初审、上诉等审理层级划分也越来越清晰。法律就在司法过程中逐渐发展出来的。

依靠原先英国的普通法，在初审的法院里，诉讼双方的原告和被告由陪审团来决定，只允许由法官判决定罪。定罪之后，陪审团就确定一个有罪之后，再具体地适用法则，法官在初审裁决过程中会引用哪些先例，陪审团判决的适用法则则往往是由法官决定的。对于英国人来说则是由法官决定的。

我们来看一个例子。A、B、C三个地方出现了类似诉讼。但是在这几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到，所以在几个地方都得到过判决，风也没到。

到了上诉法院这一步，会综合考虑初审法院的事实判断是没有问题的，它就不再做事实判断，只做法律判断。看看到哪个在先案例适用这个上诉的判决的判决。上诉法院完全可能推翻这些诉讼的初审被驳回的判决。可是这些不一样的裁决怎么办都都没有问题的呢？

上诉法院就必须从几个诉讼中抽象出一些共同的原则，以此来解决，这样看上去不一样的裁决实际上是一样的。不断上诉的案例越来越多，被提炼出的共同原则就会变得越来越清晰抽象。

# 普通法经过这样不断抽象的过程，逐渐只剩下程序正义了，就成为只做程序正义，不再实体，不再讲究实质正义，也就是不承诺结果有善恶有问题。

那为什么在普通法，它逐渐成为一个“程序正义”的标准呢？

准确来说，英国没有把实质正义放在司法院这个层面上，基于地方性的公共风俗来实现。越进到高级的司法的机构，就越依赖程序正义，比如高等法院、司法审判时，只剩下了正当程序的承诺了，才能将各种不同风俗的地方整合为统一规则体系之下。

而这恰恰是实质正义，这也蕴含在立法时所优先体现的实质正义，不管这一实质正义就会强制他服，用强制来保障。

大陆法在被发明出来的那一刻就定型了，但普通法没有定型的时刻。社会要它不断产生新的案例，普通的法官通过要把它不断的裁决来都能整合在统一的规则下，法律就不断在演化。

刚才说了，在传统早期英国和欧陆走上分岔口，英国仍然保持着普通法的传统，欧陆走上了大陆法的状态，这是为什么呢？这就跟英国和欧陆的地缘因素有关了。

英国是岛国，不包括任何陆地上的威胁，不需要强大的陆军，国土上没必要存在法军政府和各种民用体同时利益集团博弈，英国在大陆，就相对弱。

利益起陆国家必须要面对陆地上的威胁，就必须要一支强大的陆军。而在战前的英国里发生过，大航海和海洋贸易为国王赚取了巨额的财货。这样一来，国王就不太需要国王了，而“国王会按照自己的，开始去制定自己的法，形成了主权至上上的新画面，法律变成由立法者发明出来的大陆法。

由这些区别又可以看出，普通法是大社会小型的结构，大社会国相比，多数是大陆法社会的结构。并且，只有海洋国家能把普通法的秩序维护下来，大陆国家做不到。

# 普通法国家为何成为全球霸主

说了这么多，普通法和英美法看全球霸主身份又有什么关系呢？我们要看英国的扩张过程就明白了。

英国是土会政治政府，社会非常有活力。所有英国的对外扩张首先民行为，而不是国家行为。

英国商人在海外贸易的时候，得适应当地的法律和习惯，这些法律习惯和英国法律可能很不一样。但普通法要求，它能被在不可忽略的习惯之下寻找共通则了。结果是，英国商人对不同国别对，对贸易权益会被带到哪了哪。但他们不是要求对方接受英国法律，而是说，咱们保留各自的，他也得到规则

在这个过程中，普通法就开始展现出两个层次，一个层次是英国人自己的法律，另一个层次则适用于各个之间的更有普世性，英国法，这个更高的规律在不断被揭开开发，英国法律秩序就不断扩展为世界性秩序。

即使到了今天，不同国家的商人之间进行国际贸易的时候，如果各自的法律规定有冲突，双方也会经常的达成普通法，来规定共同的执行。几乎可以说，普通法其实就是规范整个海洋秩序和国际经济秩序的基本游戏规则。
