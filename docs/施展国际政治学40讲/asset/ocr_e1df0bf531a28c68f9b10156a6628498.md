# 晚清 国际政治40讲

1720年，这是起起落落的一年，也是让牛特柳被砍成1/4的一年。

1月，南海公司打探英格兰银行，并购了一国股份，用英国机开方拉抬南海公司的股票，公司的人们看到在此有每股要赚到1倍的进账，就出高价买入。1月份，每股的价格超过了128英镑，到了6月份，每股的价格超过了315英镑。

与此同时，市面上涌现了一大波股份公司，专门赚钱的家伙，把公司的钱投在其他这些小专业计什么的，只要公司就能赚钱，大家就都热衷。

6月份，英国国会通过了《泡沫法法案》。六大核心交易价格，在泡沫公司签约的1个月，民众逐渐清场。

7月份，民众开始抛售抛售股票。股票暴跌，到了8月份，政府与南海公司破产清算，公司董事离开英国，南海泡沫崩塌。

而牛特柳的货币发行限制也不是非人性，当时牛特柳4个月就限，股票也有限制。

1741年，南海泡沫事件爆发，英国经济遭遇重创。
