# 为什么西班牙人率先构建国际法

学过法律的人都公认，公认的国际法之父是17世纪早期的荷兰人格老秀斯，不过国际法学界还有个说法认为，格老秀斯的理论并没有更新，而是基于16世纪西班牙的萨拉曼卡学派、伊莎卡卡布劳的重要论文、人物维多利亚提出的一个基本国际法原则，而被格老秀斯继承下来的。

你很容易就能想得明白，为什么是西班牙的学者成为国际法莫里斯，因为西班牙是领先开始海外冒险的，也是最早与海西时代完全不同，它所能遭遇的问题一定是最多的，也就会最先开始遇到。国际法其实发生的，没有什么是应对问题、解决问题的过程中发展起来的。

萨拉曼卡学派形成是因为20世纪60年代的伊萨即阿们而形成的学派，不过其最远的时候是发大关系的问题，也就是西班牙人和印第安人关系的问题，也是西班牙人和印第安人的关系。

这里多说一句，那个伊拉萨卡学派是在伊拉萨卡大学的宗教学院发展起来的。这跟有关，罗马法在中世纪是宗教法会法获得各种传承的，罗马法在天主教圣言里会发展的很成功，其中形成的大量法律概念、法律原则和法学方法，都构成了国际法的基座。

而中世纪的天主教也会逐渐发展起一种判法，用现代观念会自身以各种宗教事务，这就是神会法。教神会法的核心、基本法律概念和法学的法方法，都来源于罗马法，但又进入了很多基督神学的要素，所以神会法一直是最有宗教的替代性学科。一门神学理论也积累了很多法律法学家。所以国际法最初的源来自神会法就不奇怪了。

伊萨卡卡学派的代表人物维多利亚，他认为整个一本关于讨论到正义问题的。他讨论的问题核心就是，西班牙人对印第安人的侵略有没有正当性。

维多利亚认为，上帝创世让人分布在此相关遥远的世界各地，是个伟大的智慧。因为只有这样，人类才可能会长出相关联系而相互依赖于一类，各种可能性都能相互支撑，如果人类聚居于同一块大陆，反而显得力所出些问题。现在各个地方人，都是自己所创造的这片土地上的合作区，这是是上帝所赐予的，而每个地方的人并不信仰上帝，他们也同样拥有这种权利。

相应地，为了能够实践上帝对人类发展的意图，人们也能够有机会权利去对世界各处自由航行，自由贸易、自地交往，并对当地主人有义务负责自己的权益，他会平等地去做这一切。如果有谁拒绝了他们的权利，甚至伤害到对方伤害亲人，那就是在违背上帝德意志，从这种伤害到正义，就是正义的战争。

而依据罗马法，敌人的财产可以被视为为无主物，一旦被占领放弃，就成了战胜方的财产。因此，西班牙人是通过“正义战争”获得了对于印第安人及其土地的统治权。

维多利亚这么改文西班牙的正当性，为西班牙人对印第安人的侵略提供了一当性解释，但所起来认为觉得过于虚伪的，把人打光了，还要强调自己是有正义的。
