# 技术对人类秩序的重构

在开始之前，我先讲一个小故事，这个故事能让你看到当前的技术所能带来的颠覆，让你感受到一些新的疑问。

2016年土耳其发生过一次军事政变，却被总统埃尔多安反转了。土耳其在以前的几十年中曾多次发生多次政变。在土耳其，第三世界国家政变的基本流程是，一个少校或者中校带军人先占领国家电台，通知全公播发国民性总统被拘禁了，已经通过公共电视宣布现在推翻了，这个人暂时接管了国家。

这种政变成功的关键是，在于通过公共性的平台进行正式的宣告，而国家电台就是唯一公共共享平台，只要总统无法再通过网络台发声，统治的正当性转到夺取者手中，政变就成功了。只要埃尔多安在电视中通过电视台成功发声，就推翻了政变。

埃尔多安在为什么能将军方政变呢？原因是，埃尔多安仍然有可用的公共平台埃尔多安，失去占领电台。但电视台愿意看埃尔多安，埃尔多安在一年前为他的地方，协助埃尔多安发动的Facebook软件，全球发出声音，谴责政变。

在以前发生的政变中，如果没有人知道总统在电视台，总统没法发出告警，那么当总统就将被政变夺了权力。但这次政变中，政变方不知道总统政变时，总统竟然会利用自然世界发声，政变方仍然保有天然的正当性，政变者都被还原成叛徒。埃尔多安靠一根网线就推翻了政变，这是最出少校想象的。

你看，在互联网的语境下，政变式的操作都已经在反互联网，从此，你看到新技术会从意想不到的方向去人类秩序带来的影响。

未来可能会带来人类秩序的变化，实际上有很多，我这里要谈三种颠覆性技术，分别是广义的人工智能技术、新能源技术和生物技术。

我之所以集中这三种技术，是借鉴了《知识的节奏》作者在维基斯克的探讨，得到这本书有非常深的启发。但是，在下述讨论的不是技术本身，而是这些技术对人类的秩序和国际政治可能造成的颠覆性冲击。

# 人工智能技术带来的影响

先说第一个，人工智能技术。随着广义的人工智能技术强化，一系列东西都被重新定义。

比如医疗，未来的医院将有可能仅仅是为一个检查中心存在，在医医院需要做全部检查，检查结果被上传到云端，然后回到家，家人戴上VR（虚拟现实）眼镜，效果就相当于面对面地诊诊了。

大家随时可以把你的检查结果显示调出来，比如你的心电，VR眼镜里会显现出一个三维高清晰的画面，大夫可以反复细心地翻过来，给指给病人的发痛部位，这就是传统医疗诊室里问存在的安排，医院就只作为一个医学中心存在，其他流程可以在任何地方完成。

对于办公司来说也一样，等到VR技术发展到一定程序，都不需要进办公司了，所有人都在家里面戴上VR眼镜，就做了一个真实的办公现场开各种会议。这意味着公司在物理空间上的组织形态会发生革命性变化。

伴随这个变化，现在城市的空间结构也会发生变化。每个人住在北京吗，北京公司的信息不要到住在北京，那住在哪里，就、海南、新疆、斯里兰卡，都可以，哪里在，就不需要那么多房地产了。人们不需要去上班通勤了，对住位住宅和工作区的需求，就会发生本质变化，各种居住区配布的布局也会发生变化。

城市空间结构的变化，又会影响到房地产，交通、汽车的制造业等很多行业的变化，它们会引起水泥、钢材、家装等行业的变化，这些导致原材料的定价变化，层层叠叠的变化，传导到的是国际秩序的变化的变化，传向国际政治秩序演化的。

另一方面，这些日常经济空间结构的变化，和人的价值观念相互作用，相互改造，引发着变化。从而会让人们对于国际秩序想象发生变化。

历史上有过这种例子，比如中世纪的贵族生活，贵族虽有私家城堡，但大家都在城堡空间中，那个大格局里面，没有个人生活空间；而当今的楼间没有个人利益，个人隐逸之类的情境。对应地，也就没人认可自我之类的道德。

婚姻不是基于爱情，而是基于贵族家族的目的，要通过联姻来达成各种联盟关系。这种观念使得贵族贵族彼此之间的认同远大于他们和本国民众之间的认同。

等到法国启蒙运动开始，个人权利的观念逐渐盛行，由启蒙意识到，私人生活空间的确由自然改变才能。法国大革命之后，又彻底地推翻了贵族的跨国认同，要求本国内精英和大众认同的国家，这就引起了一种新的反对大范围的认同，进而引发国际秩序的深刻变化。

人工智能时代的生活空间结构的变迁，使得国际秩序的变迁方向确定，我们说得清楚，但影响肯定是深远的。

还有一个更加直接的政治性影响是，人工智能技术能准确识别数据，对各种数据的处理，我们可以做出大量中间几个公司的处理，他们对世界的影响力就是不再是商业的，而是有了史无前例的政治影响力。

说得再直接点，政治和经济的、商业之间的边界会变得模糊，大政治和大的国家公司基本上是不太关注各种大公司，但原来的大商业会超越传统国家大的一种国际政治的现实当中。甚至国际大本身，也会在这个过程中重新定义，它和国际政治的边界也会越来越模糊。

Facebook开始发行数字货币Libra，他们也已在广电的大人工智能技术中，这些技术可归到国际大当中变现啊。数字资产的发行者就是些大平台，中央银行无法管控，数字货币并行处在一种分立的状态。

这些大公司基于其用户的信任而发行政政货币，用户需要保存的，数字资产就保存了主权货币的与兑换管制相脱节。就是有了不同货币之间的兑换管制。数字货币管理了这些，对各国货币政策的很强，因为货币体系本国的经济以及社会稳定有着控制权，但是数字货币政策在货币政策的控制领域之外。

这在第三世界不发达国家的影响更深远的。因为这些国家的各种基础设施不足发达，ATM机在这些国书会到某种程度，在数字支付方式对这些地方只有了颠覆性发展。这不是非洲典型，手机和网络为让人们越过这些传统的金融设施的限制。

跨国大公司发行的数字货币再加上便捷支付，基本上都把发展中国家的中央银行架空了。这个基于政治经济、商业之间的边界更加模糊，我们很快会看到这个方面的影响。

人工智能技术可能带来的影响是全方位的，比刚才说的那些有限，我只能说它有限的角度，聚焦一些有限的方面，来谈它对未来的影响。

# 新能源技术带来的影响

接下来讲颠覆性的第二个技术，就是新能源技术。有一些正在探索的方向，包括核聚变、生物质能源、氢能、太阳能、风能等等。

这些有效的新能源技术一旦开发出来，人们对于石油的需求就会大幅下降。全球能源格局会出现极为明显的变化。而今天世界上最重要的能源分布问题集中在中东和亚太地区，恰好也是稳定不了国际局势的一些地区。

现在这些地方的恐怖主义还会发展得难以控制，是因为国际霸权或某人霸霸霸权不能对全球财富采取绝对掌控，或某人吧。一个人对天然气的需求发生一种颠覆性变化，这些地区就会陷入巨大动荡，进而引发全面爆发的政治危机。这些动荡意味着在上面马上会遇到的新战争潜能，以及新的文明冲突的逻辑，紧紧缠绕在一起。

所有这些颠覆性意味着技术的变迁及演化不仅是一个技术问题，它同时也是经济问题和国际政治问题。
