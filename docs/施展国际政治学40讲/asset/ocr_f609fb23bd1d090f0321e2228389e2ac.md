# 25 | 大阵营时代：原子弹为何会终结大国间战争？

你好，欢迎收听《国际政治学40讲》，我是施展。

这一讲开始，我们就进入国际政治4.0版本，大阵营时代。所谓的大阵营时代，就是指二战之后，世界进入到以美国为代表的西阵营和以苏联为代表的东方阵营互相对抗的时代。

我们在前面几章看到，从大航海时代到大革命时代，再到大战争时代，每个时代变迁，内在的动力机制都是重大的技术进和观念变迁。

技术进带来的新的资源，但是新资源从来不会平均分配，于是就会引起社会中的不均衡现象；而观念变化会使人们对未来的对待自己的期许，期望值和现实之间的差距同样会渐扩大而不均等，一旦不均衡的程度超过了某个限度，秩序就会出现颠覆的变化。

从大战争时代到大阵营时代的变迁，同样也是重要的技术进和直接观念。其最重要的技术进，是原子弹的问世，尤其是第二次世界大战，还是由意识形态所驱动的无限战争，双方拼死拼活的那种打法。

这种打法也是战争技术迅速强化，到战争后期出现了终极武器，原子弹。

# 原子弹带来的变化

原子弹是一种特殊的武器。特殊性就在于，它是一种国家级才能共同参与的战争。拥有原子弹的国家之间，不会再有战争了。为什么会有这样呢？

你可能听过一个说法叫“战争是政治的延续”，也就是说战争是一种手段，它发目标是让政治目的达成，但要么政治目的达成，需要一步得就一步。战争的参与双方必须控制它的力量，就意味着，除非你想把对方彻底可以或消灭，否则就刻意希望原子弹达成任何可逆的局势目的。

这就会在大国之间造成一种特殊局面，两个大国如果打起来，谁也决断不能在战争中占亏的一方不得用原子弹，原子弹一旦使用，当方战争所要达战争目的就作死，这就导致，终极大国战争也变成了无意义了。所以说，原子弹出现之后战争，基本上都是没有原子弹的小国之间发生的常规战争。

那大国民在干什么呢？很简单，操纵小国作为代理人，替自己在一些热战中打仗。大国不能进行核战了，为了能够控制热中局自己一边，使它在战地间维持在，争夺的核心命题是，人类的前进命运到往何往何方。它们通过小帮战争去打造各自的阵营，就更多的防止它们在竞争中打，所以国际秩序就进入了冷战的大阵营时代。

除了对战争形式的影响，原子弹的出现还引起了国际秩序另一更重要的变化，那就是常见的欧洲国家那种规模的民族国家，不再是一个有能力的政治单位了。因为，你原来原子弹不可能被安装在这样的单位里，它不大，没有的来保证人们不要用这个。民族国家没有足够的资源，一颗原子弹下来，本果就差不多被抹消，所以在原子弹时代，有能力的政治单位必须是跨国规模的政共同体。

你注意到了就会发现，战争技术的发展和最适合生存的政治规模之间，是有着一定的比例关系的。比如冷兵器时代的大刀长矛，最大将兵系为优势，但战争对应的政治规模大致就是古代封建领主或村落的规模。到了后来的热核时代，包括坦克所带来的政治规模大致就是民族国家的规模。

而一旦发展出原子弹技术，民族国家的规模就不能了，需要的是国家，一方面，原子的破坏力超出了大国的极限，这种规模的破坏力必须让有足够规模的承担，另一方面，战争的技术力的要求，意味着这是一种有挑战的系统工程，而且需要越多的社会分工合作，才能支撑起来。如果没有一个大规模的政治体出现，如此复杂系统性的现代工业分工是难以出现的，这些就意味着帝国的。

# 二战后的现代帝国

这里所说的帝国，就是远远大于民族国家的政治联盟。

今天你听到帝国这个词，可能会联想到一系殖民色彩的，比帝国主义对人的压迫，殖民者的野蛮。但实际上一古典意义上的帝国，是一个与文明相关的非常正统的概念。

人类诞生了若干种大文明，每一种文明都会想在世界中实现自己的道德理想，帝国就自认为这个文明的道德理想或的载体。也就是说，帝国不以特定的人或被统治为自己的识别标志，而是以文明作为自己的识别标志。

这就和民族国家大不一样，民族国家以特定的人群和领土作为自己的识别标志。理想状态下，民族国家的使命就是服务人民利益，不涉及到，帝国的使命则是把自己所服务的超越任何具体人群个人的理念，以管理家做出什么来体现它，覆盖到远超过民族国家的疆域，甚至全人类。

搞明白了古典帝国的基因，我们大致可以提出二战后的现代帝国的三个特征。

第一，帝国是一个超越单个国家的国家联盟，它在物理很大，有足够大的战略纵深，所以它可以克服单个上存在能力比较浅。

第二，这个联盟必须有核心主导国家，才能把其他国家拢住，就是这个主导国家就有两种利益，一种是这个国家，追求国家间的利益，一种是它的帝国主义，追求的是整个联盟的利益。

第三，这个国家联盟，要靠超越特定民族文化的善主义的理念去选择，才能形成精神凝聚力。只要联盟中的国家，尤其是其中的主导国家，一直在强调本民族的至圣至上，那么整个联盟还是脆弱的。

冷战阵营当中的双方就是满足主了两个帝国。自19世纪上半叶以来，英法美为核心，共产主义的世界秩序以苏联为核心，它们二战后联立国，日本，西方所谓的民族主义理念，之后又分别主导了两大阵营。

美苏两都把帝国作为各自都的念去覆盖整个星球，都尽量把热战都到第三地区，进行冷对抗，比拼帝国主义和霸权，做一个更大的局，以便承担更多的责任来维持自己的阵营面，形成一个反帝霸外交，进而也带来了第三世界的很多代理人战争。

# 中国崛起和第三世界国家的独立

除了两大阵营的对抗，这一时期，国际政治出现了一个非常重要的变量，就是中国的崛起。

大阵营时代以前的中国，长期是国际政治当中一个无足轻的角色，但是进入二十世纪中叶以后，中国就从变成了一个国到全世界一个不容忽视的大国，并且从共产营的一个把手，逐渐演化为第三世界头角，进而推动了全地球秩序转变，从美苏三角格局转化为一个更有整和型中美苏三角格局这样一种三博弈的格局。

美苏冷战结构，以及从中分叉出的中美苏三角结构，也就是我们理解这个大阵营时代的核心线索，这也是人们理解二十世纪中后期国际秩序的层面上的关键线索的一个核心线索。世界在今天面临的一些问题，其背后的历史根源就在大阵营时代。

美苏两大阵营的对抗，也给第三世界带来了机会，美国和苏联在大国之间的对抗中都可以牺牲自己的利益，它们在广大非第三世界都有很强大的存在感，所以它们就从大力推非殖民化的过程。大量前殖民地区都起来了，第三世界开始在国际上发出自己的声音。这其中，给提供了一个重要的外交基本盘，中美苏三方博弈的可能性也是在这个过程中慢慢浮现出来。

另一方面，新殖民地区的大规模独立，让世界上的国家数量急剧膨胀。此世界大国有97个百国家，但是大量第三世界国家的独立，使世界目的国家数近两百个，联合国会员数目大国数倍。

在此过程中，联合国一方作为国给了重要的发声空间，作为各行为体正当性的来源，另一方联合国也被更加深刻地参与到多边政治的过程中。这些因素的出现，也是我们今天能看到的一系列国际秩序演变有。

# 计划经济和市场经竞争的

刚才大阵营的时代有两种观念体系在竞争，我们这见的大竞争同时被也表现为制度，就是既经济模式，就是以苏联为代表的计划经济和以美国为代表的市场经济。

二战刚结束时，苏联的发展可见，当时世界有得大相信，计划经是方未来模式的基础竞争，中当苏联的经发展得如此高期望，为什么其后开始的第二工业革命的个特性有关。

第二次工业革命是以重工业、钢铁、重型起为主的革命。对于这些东西而言，到个过程是靠技术上的新，但是一旦有人能到从人，他可能只是让造这些东西，要下来一，需要的就是创新。但是与大规模的现代化生产、工业组织相比，一种经的竞争就是。
