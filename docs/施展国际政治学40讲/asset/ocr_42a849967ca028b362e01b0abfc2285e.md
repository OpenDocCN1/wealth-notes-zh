# 划重点

海洋秩序与陆地秩序之间的对抗史，就表现为海洋秩序的不断扩展，但陆地秩序不断反抗，使得海洋秩序不断地朝着更加开放包容的方向演化。

一方面，陆地霸主对海洋霸主的反抗，会让海洋霸主本身也不断自我调整改进；另一方面，陆地霸主都是大国，它们在反复失败，最终加入开放的海洋秩序之后，由于它们的体量规模，就让海洋秩序也不会是过去的老样子了，海洋秩序也会发生新的演化。

# 留言精选

陈C

在海洋秩序和陆地秩序的对抗历程中，虽然海洋一侧总是阶段性的胜利者。但像德国这种抢地盘、扩海军，甚至开战的升级的过程，也让英国非常狼狈，甚至为了扩张而扩张，与之前的海洋帝国战略背道而驰。

从博弈论的角度讲，大家都开放口岸搞自由贸易，这是一种普遍的合作行为。但如果在这个体系中，有一国开始搞封闭秩序，在封闭体系内充分动员，集中力量定向发展，就是一种难度低、见效快的发展策略；地盘越大，这个策略就越有效。陆地霸主不断抢地盘，就成了这场博弈中的“压倒性策略”；其他大国也会因为这一策略的好处，而同样选择海外扩张与封闭秩序。长此以往，英国也就被牵着，不得不选择积极的殖民扩张，这实际上就形成了一种囚徒困境。海洋秩序重新生成，自由贸易得以恢复，实际上就是要打破这种困境。

海洋霸者想打破囚徒困境，不被其他人“牵着走”，自身实力就非常重要。一来其他国家选择封闭的时候，它自身能够凭借足够大的经济体量，挺过贸易规模缩小的紧张期；二来有足够的实力，它也能够胁迫想要封闭的其他国家，使它们维持开放。英国之所以在十九世纪后期被迫扩张，我认为一个重要的原因就是其本土体量小，又没能从第二次工业革命中获得足够的发展动力；力量不够强大，秩序便难以维持。

佛祖门徒

今日得到：

第一、阶段性正确。英、德两国选择了不同的发展路径，虽然基点、策略和方式都有很大差别，但在一定时期内，各自取得了很大的成果。但世界毕竟是紧密相连的，发展战略必然受到外部因素的限制，德国的发展受到扩张成本的约束，英国的发展受到别国对贸易网络规模的限制，倒逼策略调整。

第二、相互塑造的演化。路径不同，但在不断发展过程中不可避免的发生碰撞，一时之间，既没有哪方可以轻易搞定另一方，也没有哪方会轻易放弃自己的所得和路径，所以当矛盾发生不可调和时，重塑新的国际秩序也就成为必然了。
