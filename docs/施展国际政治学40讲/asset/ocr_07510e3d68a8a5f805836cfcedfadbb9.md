# 5.0版本：大颠覆时代

推动大颠覆时代的重要技术力量就是互联网，它使用人类突破主要框架上的时间和空间的约束。一下子被截断了，这就彻底突破了传统社交秩序，以及传统的道德观念。人类秩序进入了一种前所未有的状态。

5.0版本才刚刚开刷，我们还看不清它未来的走向，但是我们可以，在这个版本当中，文明之间的对抗，和新技术的更迭中，有各种各样的秩序演演为舞台。而中国在这个过程里，会扮演决着重要的角色，这个角色究竟会是什么样子，相当程度上取决于我们在今对于未来的想象。

通过我们所看过的这封信可以看出来，在5.0版本的大范围的世界，核心资源是对于未来的想象，谁谁掌握想象力，谁就有很大的机会主导未来。谁掌握了对于历史的理解力，谁就会拥有更大的想象力。

好，通过这一讲，你应该对于国际秩序的演变史有了大概的了解。对于下一讲开始，我们进入国际秩序演变的具體进程中，让你看看在历史的现场，新的观念、新的体系都是如何产生的。

# 划重点

这门课国际体系系列分为不断演化的五个版本，分别是大航海时代、大革命时代、大战争时代、大阵营时代以及我们今天所处的大颠覆时代。背后的依据，就是不同时代技术和观念的变迁。

每一个时代，都有自己的核心命题。我们今天处在第五个版本，也就是大颠覆时代。要理解未来会往什么方向发展，就要先理解前面四个版本是怎么发展过来的。

# 留言精选

无名的沉默

1.0 大航海时代的主命题是“探索”，面对广阔无边的世界，谁能够更灵活、更开放，探索出更好的路径，谁就是胜利者。2.0大革命时代的主命题是“再分配”。上一个时代积累下来的超额财富和积累的技术如何被重构“再分配”，因利益分配不合理引发的冲突爆发，需要通过“再分配”整合到更多的资源和更广的力量，谁能做到谁就是赢家。

3.0 大战争时代的主命题是“反思”，虽然你已经完成了再分配，但你仍然很难留在上个时代，两场世界大战无可避免地让人们开始思考一种适应当下技术环境的国际政治格局。谁能适应上这种新的规则、标准，谁就是时代赢家。4.0 大阵营时代的主命题是“试验”。因为各阵营所不知道的未来社会体系进行了一次规模空前的政治试验。结果是美国赢了。5.0 大颠覆时代的主命题是“想象”，再一次的技术革命会让旧的格局有可能的强势改变，创新的空间有无限，谁能想象出丰富的未来，提出的观念和适应的结果会发展，谁就是未来时代的赢家。
