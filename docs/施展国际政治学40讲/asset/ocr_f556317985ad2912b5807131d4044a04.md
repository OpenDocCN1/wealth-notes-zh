# 07 | 体系的成型：主权平等原则是如何出现的？

梅毅《国际政治大讲学》

你好，欢迎收听《国际政治大讲学》，我是梅毅。

前面几讲，我分别给你讲了法国、英国，还多西班牙，在大航海时代各自遇到了什么难题，他们为解决这种问题的过程中，带来了怎样的结果。比如国家观念的形成，是法国的理论创新，还有海洋视角，这是英国的观念转型，比如国家法的雏形，最先在西班牙奠定。

在大航海的前期，各国各自已经碰到了很多新情况，并且为解决问题的过程里产生了这些国际秩序的基本框架。

# 三十年战争

但是，到了大航海时代的后期，欧洲秩序越发混乱，各种战争不断。为什么有这么多战争，是因为大家都从海外带回来更多的财富，但欧洲内部又不可能分成这么多份，所以各种不均衡，从而带来动荡。

再来是，发现新大陆之后仅仅才六十多年的1517年，欧洲又开始了另一个惊天动地的大事，宗教改革。你可以知道，信仰问题的冲突很顽固和深，尤其是旧政体的政治所说还有世俗化，信仰就是无法真正被的根本冲突。所以，他们的冲突会导致极大极大的冲突。天主教国家与新教国家之间因此发生了大量宗教战争。

大航海神是为主旨都是西部，而宗教改革发生在神圣罗马帝国内部，我们在那面说过，1516年之后西地中海和圣罗马帝国的最高势力，都集中在反方向期望国家头上。于是，大航海和宗教改革两股力量的合流，与哈布斯堡王朝侵略欧洲的势力又合在一处，战争就卷入了更多的区域。

海外财富激起的是各国及其内部群体在世俗利益上的争夺，宗教改革激起的是人们在信仰层面的博弈，信仰兴趣激起的则是征兵一切的权力。不同群体的诉求彼此之间难以沟通，同一个群体也可能会有若干种诉求，各种信仰又无法不可能完全协商解决，各种矛盾就此相互叠加强化，战争越发难于平息。

积累多种斗争，恨到1618年，终于爆发了一场规模巨大的战争，把大部分国际关系国家都卷入进来。战争一直打到1648年，共持续了30年，所以历史上称之为“三十年战争”。

三十年战争是当之无愧欧洲的战争不断频繁的结果，惨烈到什么程度？在持续不断的冲突和战争中，这场战争给参与国带来了至少百分之十的人口。这不仅上人口损失，甚至远超过了第二次世界大战中损失最为惨重的一方。德国曾是神圣罗马帝国的一部分，1619年~17民国家是欧洲最大最富裕的德意志人，为三十年战争所吞食过的巨大历史灾难，甚至超过纳粹政权。

战争打到这种程度，哪个国家都承受不了，而三十年战争开始前后，原有的盟约体系都失效了。各个国家基本就是混战和相互干杀。

这样一种混乱无序的环境中，人们有共识才可能开始重建，是无法回答各种诉求，以满足诉求的方式，结果会越积越多。问题是有领导有秩序，只有大家都能认可的规则，战争才能导致向某种秩序的建立，而不是单纯的相互杀戮。

关于秩序的建立，很多人都做出了重要的理论贡献，比如我们前面提到的西班牙最早学法学派的德亚理亚，这方面大德索雷斯是莫拉基亚。但格拉西内是西班牙的。也有格老修斯，他是公认的公法学家。他尤其把包括很多利比亚和巨人提出的国际法原则，发展成一套庞大又成熟的法律体系。

三十年战争的结局看，参各方在神圣罗马帝国的和威斯特法尼亚协议下各方相互妥协，终结了战争。条约所体现的法律原则则来源于格老修斯在1625年所写的《战争与和平法》。由此形成的威斯特伐利亚体系，也被认为是人类历史上第一个国际体系。

# 格老修斯的国际法学说

格老修斯的学说到底是怎样重建秩序的基础原则，最终促成了威斯特伐利亚体系的？

问题的关键在当年的战争。格老修斯在这一大动中的一生，始终在思考如何才能给战争的目标和手段，从而向前进推和结构的目的，这是重建秩序的前提。战争必须有正义的。那就得先定义，正义战争的标准是什么？

先来看看前人。标准中世纪的基督教神学家奥古斯丁、阿奎那都提出过正义战争的三个原则：一、战争组织的权威。二、战争正义的理由。三，战争目的当。关于这两个大神学家的重要性，你可以在我老博的《西方大约50讲》课程当中听一下。

格老修斯在前人基础的研究上进一步了，但他同时发现，正义是战争最重要的决定条件就是要有正义的理由。正义理由就是，为了维护或者实现所确定的权利和自由形成，所以的战争都不是正义的。

自然法是从哪里的呢？格老修斯认为它来源于“自然”和“人的”理性，是，一种法律的基础和标准。自然的权利并不是开于了格老修斯时候才提出来的，古希腊、古罗马的学者，人们就讨论起古代自然法。但科学革命让当时的人对于人类的理性获得了巨大信心，格老修斯是生存在这样一个时代，他认为自然法正在出人类，那么，基于这一种自然法的正义战争，那么，就把基于宗教的战争理由给排除在外了。

再往前一步，就是战争。自然法所规定的权利和自由是什么？格老修斯看来，只能是主权国家。除主权国家之外的贵族、医生、地方官员、宗教领袖等等都不能发起战争，或者说都不能不负责任等。国家主权的特性，对内的最高权力，对外独立的、不受任何其他权力的制约。这就把我们已经提到的法国所发展起来的“国家”观念，在国际法层面又进一步落实了。

这样一来，战争组织的权威、战争的正义理由，在格老修斯的理论当中就确定了。接下来就是到底用原则进行什么操作能够符合正义标准。什么样的行为是正义的，参战者可以因此而为但不损害自己合法权利，什么样的行为是不正义的，参战者对交战不能拥有交战权利，等等。

这里面有一系列的法律技术性的展开，我在这里就不一一说了。一句话，格老修斯在这里就产生公法理论，达成三十年战争当中的各方对于规则的共识，并成为威斯特法利亚条约的法理基础。

格老修斯对20世界的影响颇为深远，以至于差不百余五十年来，成书为在传播格老修斯的影响。格老修斯亦被为父亲，而圣父，不过有学者也以此自证，认为自己的变法活动，就是如布衣平民的自组织，而为天下立法。

# 威斯特伐利亚体系的原则

说完了格老修斯的国际法学说，就能明白威斯特伐利亚条约当中一些法则原则的来源。战争名仁以及规则的一个核心规则，即维持体系内的主权各方，都承认对方主权，在此之前他们可不是这个理由相互关系的。

比如条约中规定，各国主权一律平等，海管你这个国家的统治君主头衔，是皇帝、国王，还是大公，在对外关系上都是平等的。这样一来，就不会再现当初神圣罗马国对抗神圣罗马帝国所面临的主权困境。

再比如条约中规定，数信固定。也就是说，一个国家内究竟提倡信什么宗教，由该国的统治者说了算，别的国家不许干涉。这就止息了宗教战争直接端掉掉掉了。

还记得，条约规定，要用国际会议的方式和平解决国际争端，条约必须被遵守，违约方可能会被制裁，这样一来就告诉国际社会不是丛林社会，而是有一些基本规则的。

所以，三十年战争称做最后一场宗教战争，也被称为第一场国际战。因为它在这之后，至少在欧洲范围内再也没有人为重要战争，是以宗教的名义发动的了，而都是与国家的名义发动的。

所有这些，都意味着我们今天所熟悉的一些国际秩序的基本准则开始成熟了，比如最基础的就是国家主权平等，再如，国家开始实现世俗化，还比如一些基本国际规则原则，等等。正因为确立了这些基本原则，就在欧洲秩序所笼罩的哪种国家体系，也都在这个时期成为历史了。

说到这里，关于近代国际秩序发生，就基本讲完了。通过个阶段，你也发现，国际秩序就是一个对特提出的新变量，不断寻找解决方法和规则，并且是不断的演变秩序体系。

威斯特伐利亚体系稳定之后，欧洲的竞争过程也依旧持续，新的参与者为了新的国家也英国，以及原有的法国和德国。两项争主又给这个时期的国际秩序带来了一些新的变化。
