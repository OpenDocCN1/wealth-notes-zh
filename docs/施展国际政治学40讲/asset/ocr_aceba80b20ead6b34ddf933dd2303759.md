# 划重点

海洋是自由的，陆地是封闭的；但是，海洋虽然是自由的，海权却又一定是独霸的；陆地可能是封闭的，但陆地上的格局却总是多雄并立的。

因此，陆地霸主只能形成一个区域性的霸权秩序；而海洋联通全球，海洋霸主也天然地是全球霸主。
