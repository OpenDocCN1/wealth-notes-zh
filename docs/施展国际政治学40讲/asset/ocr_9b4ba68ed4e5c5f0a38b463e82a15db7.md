# 19 | 列宁主义：用普遍革命来超越民族主义

你好，欢迎收听《国际政治40讲》，我是施晨。

上一讲我谈到了一战之后国际秩序上所面临的一系列困境，以及试图破局极端的威尔逊主义。这一讲我们来谈一谈列宁主义与铁幕相对的另一普遍主义学说，即**列宁主义**。

不过我要先说一点，我这里列宁主义指代的并不是勃尔塔尼的一整套世界秩序构想，既包括列宁的理论叙述，也包括布尔什维克的理论实务，同时也会谈到他们与马克思主义之间的关系。

相信你也就知道，列宁主义是从马克思的理论当中发展出来的。马克思主义生活在**大革命时代**的，他的理论就是再回应工业革命所带来的一些问题。

# 马克思对大革命时代的回应

工业革命以前的传统社会，是一种稳定的熟人社会，人们对其未来的生活有着确定的假定。但是工业革命带来的是**全球化秩序**当中新出来，这些人进入到城市，逐渐成为工人阶级，但是也渐渐脱离了基于熟人社会的社会保障系统。

过过去，这些工人的收入确实比村子里的时候好得多了，但是，他们对未来的种种不稳定感却比以前大大增加了。这些人有一种不安定和社会认同的需求，但他们自己在当时既说不上拥有某种权利，又没人知道要怎么解决这些需求，结果社会就出现了各种动荡。各国政府为了防止这类问题，基本上都采用了镇压的方式。这也是马克思想的时代背景。

马克思**国家是阶级统治的工具**，今天的人可能会觉得这定义太过冷酷了，但是如果换到马克思所处的年代，你非能理解。在**今天我们所看到**的**国家非人性、非政治、非宗教，而只是统治工具**这样发展来看，**国家对阶级社会的大众性上就是阶级社会的统治权**。

既然**国家是阶级统治的工具，那么最紧迫的问题就是，阶级是如何定义的**？马克思认为，阶级的演进不是资本的方式或意义的方式，与种族、信仰、肤色等都没有关系，也不是以国家为单位。所以列宁认为可以承认法国或者德国的民族主义，但马克思认为这只是不过是一种话语，用来掩饰阶级统治的本质。

所以，马克思提出一句在中国人都熟悉的口号，“全世界无产阶级联合起来”，主张消灭**无产者联合起来推翻阶级统治**。但要注意，马克思并不是起来是为了**无产阶级的解放去夺权**，而是说没有阶级以后不再有任何阶级统治，否则就是换汤不换药。

没有阶级统治意味着什么？意味着从此不再没有阶级了，所有人都进入一种无产阶级的秩序。由此也可以看到，马克思思考的是全世界、全人类，而不是任何民族或者区域为单位。当然这是一种超越了民族主义的普世主义。

也因此，马克思认为共产主义革命是要在全球范围内发生，至少是在所有发达地区发生。但是，马克思主义是最革命的，不能由自己限定特定的某个国家。

# 列宁的革命策略

但是这样一革命究竟该怎样启动，不同的革命者就有不同的理解。

比如，**列宁就有自己的解释**，他认为**无产阶级革命有可能在帝国主义体系中最薄弱环节，也就是俄国的俄国率先爆发**。为什么呢，不是因为俄国工业更发达、无产阶级有更强大，而是因为列宁认为，这些国家缺乏强大之后，它们的工人的领导就很容易被收买，资产阶级可以收买，没人想办法了。
