# 11｜国际经济学：德国如何对富起来的英国？

作者/国际经济学40讲

你好，欢迎收听《国际经济学40讲》，我是施炜。

上一讲谈到了率先实现工业革命的英国，如何通过与其它国家之间的产业落差，发展出了自由贸易的这种学说，对其他国家形成了经济上的降维打击。这种说法在美国特别成功，但是其它国家肯定不痛快，非得想办法怎么对付英国的降维打击。

这一讲我会带你看看两位经济学家的理论，其中一位是我们前面提到的英国的亚当·斯密，另一位是19世纪初德国著名的理论经济学家弗里德里希·李斯特。李斯特的理论，就代表着工业革命时代德国对英国的反击思路。

# 李斯特对亚当·斯密的挑战

这两位经济学家观点很不同，你可以把他们看作辩论双方，代表英国的斯密认为，从经济的角度来看，国家只要提供一个公平的法律环境就行了，其他方面的参与越少越好，就让个人一直跑到世界市场上去折腾，这是最好的。

而代表德国的李斯特认为，亚当·斯密看到个人在世间扮演这个角色，忽视了国家这个中间层次的作用，恰恰国家在经济政策当中有着至关重要的作用。

也就是说，斯密认为，国家在经济中的角色也应该是“打得更少，只要更少替人做角色就行了”；李斯特认为，国家可以打得更主动而不行，它得重新定义，要有一个整体的规划。

不过，亚当·斯密的著作《国富论》出版于1776年，李斯特的著作《政治经济学的体系》要早十年，半拍，所以在双方的交锋，其实就是李斯特对斯密的反击，斯密自己已经走了。这位反经济学家的理论PK，后来体现在了英国和德国的政策PK上。

也许你会问，理论对政策的影响力能有多大？这说法会不会过分拔高了理论的影响力？

我可以换另一个伟大的经济学家凯恩斯的一段话来回应这一位。凯恩斯说，“经济学家和政治哲学思想家的思想，无论是是对还是错，实际上都是治人国家思想的力量。这个世界几乎没有不曾经是某个思想家的奴隶，当那些已经被否定了的，就受到被新思想冲击者信奉的，其实也不过是若干年前某个死文人狂妄思想的零碎而已。

这样就知道理论对于政策的巨大影响力了，理论是人们用以理解世界、发现问题的基础框架，政策只不过是用来解决理论所识别出来的问题的。

但我还得再进一步，斯密与李斯特两位理论家并不用来政策的宣示，他如是那样的，随着历史的变化，他们的理论也就没有价值了，就会成为中传他们的怪话。

他们俩是在关注人类要永恒面对的一些真正深刻的问题，但两个人入手角度不一样，所以会有理论上的差异，而他们的理论产生的政策效应，是理论和时代发生共振的结果。
