# 留言精选

![](bbox=[0.06, 0.168, 0.14, 0.198])

王黎璐

国家力量与个人力量之间存在着交互作用。我们本不该求全斯密，他或许有感于封建制度的束缚；也不应该责备李斯特，他或许背负着民族富强的责任。与其说自然秩序传统反对理性和制度设计本身，不如说反对忽视人类知识局限性的理性建构传统。而李斯特便是后一传统的代表，认为政府有意识地控制和指导是个人经济自由的保证，因而主张加强政府对经济生活的干预。在对理性作用的认识问题上它的基础显然与前一传统不同：政府官员足以知道并能根据社会成员的偏好，考虑到社会需要的所有细节并据此构建社会经济制度。然而，社会的制度既不可能是单靠个人（或其集合）社会经济活动自然演进的结果（即不单纯是不同行为主体在追求各自目标时不经意间的结果）；又不可能是人类可以设计的结果（即不可能是由于包括国家在内的任何经济主体理性地预见到其利益而谨慎设计的）。

刘渊澜

斯密和李斯特的经济观点是“看不见的手”对“看得见的手”两种貌似对立的观点之争，不过结合二人所处的国家还有时代环境，也不难解释两人观点上的差异。

斯密所处的时代正好是英国实现降维打击的时代，一路做群雄，在这样的时代，加上斯密个人的道德观，就提出了政府应该起到守夜人作用，不必做出太多干预。而李斯特所处的德国，当时可以说还处于四分五裂的状态，想要实现志态，就一定要经历前所未有的阵痛，政府也就要起到关键作用。

其实李斯特的理论可以被视为斯密理论的“世俗化”，毕竟现实情况无法完全像斯密的理论一样，大家都着有一定的道德标准。相比之下，李斯特的理论更接地气，也更符合当时德国的国家发展需求。

Exodus白

这是很深刻的一课。

对任何理论的解读和运用，都应该考虑当时所处的环境。新理论的提出，处于什么样的时代背景和立场，这话说是说给谁听的，又想到什么样的目的。也就是说应该从知人论事的角度来评价，而非仅仅套用自已的文学审美和价值取向。

亚当斯密处于工业革命和全球化的风口期，在此之前缺少相关经验，但作为一个经济学家，希望大英帝国能够尽可能多而持久地吃到这一波技术革命带来的红利，也希望自由贸易能够在道德价值层面辐射全球。

而李斯特的理论，代表德国作为一个有文化抱负的追赶者，需要跳出亚当斯密构建的理论框架，用新的打法来跻身第一梯队，甚至实现反超。

亚当斯密的理论是在向全世界喊话，李斯特看到的世界已经不再是亚当斯密眼的世界，他必须做出理论创新，向亚当斯密隔时空喊话。
