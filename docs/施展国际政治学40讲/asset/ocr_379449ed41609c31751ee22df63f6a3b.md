# ## 法国大革命之前的战争模式

要解释战争模式的全民战争，就得先说说此欧洲战争模式是什么样子的。

简单的说，**法国大革命之前的欧洲战争，基本上可以解释为贵族战争，而贵族战争无论从战争的目标设定上，还是从战争的发动能力上，都是比较有限的。**

先说贵族战争的**目标设定，无非中外，贵族们都有特别强烈的等级、秩序意识，**要把自己的地位从别人那里拿出来，**以等级秩序维持，贵族对于平民的态度。**这种贵族在秩序上对普通贵族对于特权的态度，法国的贵族自然也是对其他贵族的，平民就是被动的。

战争的**目标，基本上也就是贵族之间的利益平衡，所以会发生比较激烈的战争。因为贵族们对于彼此的血统正当性都看得很重，但是无法通过战争来达成目的，那贵族们就干脆不打了。所以战争的发动权是很少，也是贵族们发动的。

再说贵族战争的**资源动员能力。贵族**的战争主要靠贵族自己的土地和收入，再加上国王对贵族的税收。这种税收有限，所以战争的规模和持续时间，也相对有限。
