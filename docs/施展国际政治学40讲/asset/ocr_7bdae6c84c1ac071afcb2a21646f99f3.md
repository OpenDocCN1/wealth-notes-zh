# 法国的对外战争, 在同西班牙及英国另一场 形态的全民战争, 就是游击战。

这种模式一直贯穿到当代。你想想, 为什么在越南战争中, 看似弱小的越南能把强大的美军拖得毫无还手之力然后在苏联入侵阿富汗的战争中, 为什么强大的苏联会被游击战拖到分崩离析? 对于美苏这种大国来说, 它不可能把部队全部派过去驻守这些国家, 只有游客这些被占领地区, 只要游击队不断袭, 就能胜利。

所以, 法国大革命开启的近代国际秩序当中一系列基本政治与战争规则, 以至于不理解法国大革命, 就很难完整理解现代世界秩序。

再说革命法国, 虽然它开启了一整套重锤打击的世界形态, 最后却完成了失败。1815年维也纳, 它和欧俄等旧王朝联手把法国按到桌下, 重新拿来安排战后秩序。

和革命上各种博弈, 堪称人类史上教科书一般的案例, 又无疑是政治巅峰, 既是新秩序外交的旧式, 又不至于太古老。重新对外战争到法兰西, 而维持的秩序, 在19世纪末20世纪初开始逐渐崩溃, 直到二战后。

我们下一讲就顺着革命法国这个案例, 看看真正的高手是怎么破局的。
