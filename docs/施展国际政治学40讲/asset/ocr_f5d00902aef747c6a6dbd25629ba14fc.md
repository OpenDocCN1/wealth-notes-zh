# 西方创新经济和f国崛起

> 以**往的**创新都是掌握在大公司手里的硬技术层面的创新，是**相当于**美国在1980年代通过《拜杜法案》，激励了小公司在技术创新上的创新。

拜达法案之前，很多科研是由政府资助的。这导致这些专利都由**政府**去市场，很困难**能够**商业化。而拜达法案颁布之后，不管是谁**拿**的**钱**，只要没有**特**独**法律**合同说明，科研成**果**的所有权一律归**科学**所有。转只**有**转**让**所有权。

这样一来，高校有了更多的热情把**专利**权益转**给**公司，因为这并**不**影响**继续**做**科研**。这也就让**公**司**有**了**在**技术**里**续**进行**创**新。关于《拜达法案》的具体内容，隔壁王**文**全老师课程里有比较细的**介绍**，你**可以**去听**一下**。

今天我们知道**很多**特别**前沿**的技**术**是在小公司里发**明**出来，然后**卖**给其他公司商**买卖**开**放**来。比如**苹果**这样**的**公司，就**是**来**买**这么**小**公司开**放**的**技术**权**利**。你**不**能**出**新**产品**了，那个**公**司**会**卖**给**你**，使**你**就**能**自己**进**行**新**的**融合，而是**吸**引**更**多**的**公司**来**买**你**的**技术，这是**它**真正**的**软**性**政**策。

所以**你**可**以**知**道**，**大**公**司**能**做**各**种**方**法**的**创新**，但**是**它**对**于**技**术**性**革**新，**这**类**上**是**不**太**能**做**的**。有**很**多**技术**的**小**公**司**又**是**吸**引**更**多**公**司**去**购**买**自**己**的**技**术**，**这**就**是**刺**激**了**很**多**公**司**会**偷**仿**效**于**苹**果**这**样**的**产**品**创**新**.

因为**大**小**公**司**在**创**新**上**不**同**运**作**方**式**的**结**果**就**是**，**对**冲**击**有**很**大**点**率**的**很**多**大**公**司**，**它**的**创**新**就**是**在**技**术**开**创，**观**点**创**新**；但**就**依**的**不**是**社**会**经**济**模**式，**大**公**司**不**能**有**技**术**墙**垒**，**只**能**选**择**走**技**术**墙**垒**，**就**是**自**己**创**新**的**速**度**比**别**人**要**快**，**才**能**保**证**自**己**的**优**势**地**位**。

为**了**保**证**创**新**效**率**，**这**种**大**型**的**大**公**司**就**必**须**将**自**己**的**生产**程**序**包**出去，不**能**放**在**自**己**手**里**。回**不**可**能**放**在**流**通**领**域，**只**有**专**业**化**就**意**味**着**生**产**程**序**，转**变**成**大**规**模**的**包**造**外**包**都**构**成**了**西**方**这**个**创**新**经**济**的**内**在**要**求**。

这**个**时**候**，**中**国**就**成**为**一**个**很**重**要**的**变**量**了。**

因为**大**规**模**的**外**包**需**求**的**出**现**，**好**正**中**国**一**系**列**的**经**济**改**革**是**开**始**的**时**间**。中**国**在**这**个**时**期**形**成**了**巨**大**的**外**包**能**力**，**顺**利**得**到**了**高**速**度**的**经**济**增**长**。所**以**看，**中**国**的**高**速**经**济**出**来**的，**无**法**离**开**世**界**大**外**包**获**得**解**释**。

# **中**国**的**供**应**链**网**络**

> **中**国**为**什**么**形**成**了**强**大**的**承**接**外**包**的**能**力**，**在**于**中**国**形**成**了**一**个**强**大**的**供**应**链**网**络**，**从**而**很**好**地**接**了**西**方**创**新**经**济**带**来**的**大**规**模**外**包**需**求**。
