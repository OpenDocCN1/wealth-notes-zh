# 32|多边外交：联合国为什么经常疲于奔命？

你好，欢迎收听《国际政治40讲》，我是施展。

前面两讲我们讲了大事件，大事件和大外交分别组成两面。相比于此前的几个时代，大爆炸时代有一个特点就是，多边外交组织很多，比以前要更加体系化。

多边外交，你首先会想起新闻中出现的另外一个名词，双边外交。多边外交，就是两个国家对一个地方互动，然后互动成一个组织。多边外交就是多个组织之间，在这个多边平台开展外交活动。

# 多边外交的出现

多边外交出现的历史，最早可以追溯到大航海时代的阿姆斯特丹会议。因为有两系列组织在两个国家之间的斗争，需要许多小国家处理。但直到19世纪末期，多边外交基本上还是作为一种偶发性的方式存在。

之所以多边组织在进入20世纪后才大规模出现，是两次大战之后国际动荡急迫的转变有关。两次大战让各国逐渐意识到，战后人们可能在国际层面也应该建立一种结果模式，才能防止大国的任意行为带来灾难。怎样才能形成这样的民用体系？那就是国际事务将大国家联系在一起，谁能负责，开会的事情逐渐制度化，平台化，就变成了多边外交组织。

有了国际体系的民主性这种考量，多边外交组织也构成了国际社会正当性的来源，比如我们在国际新周期里会听到一些说法，某某行径获得了联合国授权，联合国就是今天世界上最主要的多边外交组织。

实际上联合国对成员国并没有强制力，但是却让这个行动变得很有正当性。在国际上所讲的“说得通，就说得通”，这里的“道”，就是由联合国来定义的。

然而，多边外交组织的实际作用，与人们的期待，存在一定的错位与隔阂。近年来出现极端情况。在联合国经常看到，成员国不在这个国际上的事情也经常出现。为什么会这样？这些多边外交组织将有一系列困境相关。这一讲我就以联合国为例，来评说这个问题。

多边外交组织的困境，我把它归纳为四点：代理人困境、权力责任不对等困境、价值不一致困境、道德判断与执行力相分离的困境。还有治理机制与治理对象不匹配的困境。当然这些组织问题，也很难紧紧抓住在这个问题上。下面分别来说一说。

# 代理人困境

先说第一个困境，代理人困境。这是一个制度经济学上的概念。它指的是，公司的投资者通常没有精力来经营自己的公司，通常会委托一些职业经理人来经营。

但是，职业经理人投资人的利益并不完全一致，职业经理人的最大利益在于挣到更多的工资和奖金。而投资人的利益在于让公司获得更大的长远利益。两种利益之间存在一定的冲突和错位，职业经理人可能会把公司经营过程中做一些对自己有利，但却损害投资者利益的事情，这就是代理人困境。

多边组织中同样存在这个问题。多边组织要处理的问题较多，需要有一个规模较大的组织架构，也要有一系列执行组织目标的官员。官员们也可以将多边组织国际上的影响力，因为多边组织官员是在国际平台上存在的，就其有机会从各国争取更多的财政拨款，官员们也会变得比较舒服。

所以，多边组织出现之后，很快就会形成一系列独立于这个组织本身的独立议程，有些议程会立足于起源于国家的意图之中。

这会带来一些麻烦，因为有些议程是多边组织中的官僚为了保存而随意发起的，跟解决真正意义上的国际组织目标没有什么直接关联，多边外交的这种官员转来转去一系列关注和低效的问题，就联合国来最近受到的一些诟病，也是如此。

# 权力和责任的对等

再说第二个困境，权力和责任不对等的困境。这与大量小国加入了多边组织有关，小国天然地有很多对大国的失望，你可以通过思考，小国和大国都加入多边组织，那么大国有能力在盟约上占着便宜，小国基本上可能无法在双方盟约占着便宜，对小国来说是十分不利的。

而一旦进入多边外交的秩序，大国的优势地位马上可以被系统性地部分纠正，所以小国要，小国会多加地加入多边，即便最被外交组织解决的事情，小国也会把它交给他放在多边平台上来处理，以便保护自己的不利地位。

但问题也就出在这里了。多边组织的民主特征是投票权重是相等的，但权力的权重比它们在国际体系中利益相位的，并不对等。这就好比小小区的业主委员会，投票时会有一个要求，就是你投的投票数跟，跟你所持有的物业面积之间的关系。

但在联合国中，小国在数量上占据着绝对优势。但它们在国际事务上的利益权重和它们所拥有的投票权重不对称。这就让这些小国联合在一起可以乱法权，使得议事权的运转出现大权失灵。

当然，为了防止这种问题的出现，联合国里还有一套特殊的制度安排，比如联合国安全理事会有五大常任理事国，这五大国有绝对否决权，这是非常有极端的争议关系，但也有人特别特殊的权力地位，用来克服这种权责与责任不对等的困境。

但是这仍然无法实质解决权不对等问题，因为大国可能会妥协，怎么办这个问题，而一旦小国被说服，联合国家做出的裁决，就会离开这些国家的初衷，这也是代理人困境的一种呈现。

# 价值观的不一致

之所以会出现这种问题，由于第三个困境，就是价值观不一致的困境，这个主要与大国有关了。

虽然安全理事有五大常任理事国和非常任理事国的区别，以使各国在关于国际事务投票的程度上，但五大常任理事国也只是需要投票来决断很重大事项的决定。

这里就又有问题，就是参与投票有五大国并不是有投票权的问题。这就意味着联合国在决策过程中，实际上放弃了价值承诺。

一个组织或者说一个政治体，要想获得人们的认同，一定要建立某些最基本的秩序框架，而不仅仅限于是基于物质性的。因为物质性的要素太容易改变了，如果仅仅是为了物质上的良好，我认同你的话，一旦这种情况了，就对敌人我都不会有跟你站在一起拼杀一拼的想法。只有在精神上对你认同，才会为你拼死而战。
