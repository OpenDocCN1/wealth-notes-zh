# 第三世界国家如何走向独立

要说起这些国家。我们先看看第三世界国家是如何走上国际政治舞台的，这里有三个转折性的事件，就是1956年的苏伊士战争。

战争的起因是，当时埃及的领导人纳赛尔，决定要把苏伊士运河国，将纳赛尔苏伊士运河局所有资产和股权转给埃及。建，建苏伊士运河局。苏伊士运河在1869年是由苏伊士运河公司修造并营运的，这个公司是由国人士创办的，长期掌管着运河的营权，后来英国人成为公司大股东。

运河公司每年能收到巨额的运河通行费，埃及和政府对收益都非常满意。纳赛尔努力要让埃及和独立自主，他就说运河公司势力，但是没谈成结果，于是他在1956年强行将运河公司收归国有。

这个结果英美法国肯定也无法接受，便联合以色列共同行动，要夺回对公司从而对运河的控制权。战争过程中，出现了三个有趣的印象，从军事上讲来，英法和以色列取得了胜利，但从国际道义上来说，英法却处于下位。

之所以下了通义，是因为二战之后的国际道义观念了。强国是欺负人、弱小的国际道义，现在，强国被反打不是大们。在冷战中，强占平民有任何正当性。

苏联一直以西的守护者看看，看到埃及的状，马上又各种大支持纳赛尔。而美国如果看纳赛尔就在苏联手里越过，美国在做什么，以及能不能在大阵局，失去，要问问美国在西方阵营中喜欢纳赛尔国手这样的方式。所以美国开始反对英法压，要求它们做出退让，否则就会失去美国的支持。

这下英美两国就太了，它们在国际上节度，又面对了两大阵营的主同时施压，迫于无奈，英法军吃出吃到里的种和好处，灰溜溜地撤了。

苏伊士战争可以被做做一个转折点，此再也没有任何强国敢于以殖民者的方式来面对第三世界国家了。

这对所有的第三的殖民地区来说，都发非常重大的事件，它们从中看到了某种新的希望。因此，世界的各种反殖民运动便风起云涌地展开了。

与此同时，英法也开始考虑放弃对殖民地的统治，因为它们要承担的统治成本越来越高。而获得的收益越来越少，甚至是负数，强夺殖民地已经对英国来说，不计了。因此，非殖民运动在20世纪50年代末开，到了60年代，亚洲各方的大量殖民地区开始陆续成为独立国家。

# 共产主义在第三世界的影响

这些国家的独立进程通常有两种式。一种是英法主动退出地区的殖民，允许其独立，另一种是一种殖民地区的民族解放战争，这通常都会以游击战的方式进行。

第三世界国家要想有效地开展民族解放运动，对殖民统治的构成重大大，就必须对群众形成大规模的动总发。最为庞大的群众对象一定是针对底层的，因为底层人数规模最大。而共产主义恰恰是以它为它的动员对象的。

因此，共产主义在第三世界的民族解放运动中，就成了一种组织和反击，共产主义阵营的势力。使民族解放运动获得了更大的力量，而民族解放运动的成力，又可以不断地壮大共产主义阵营的势力，它们形成了一种相互成大的关系。

所以，共产主义在第三世界地区的影响力不断扩大，这种英美自由主义阵营构成一个巨大的压力。尤是对于一些关键的节点地区，比如印控，两个重要的争夺不仅仅是道义层面的争夺，更是直接进入印度的争夺。

美国在冷战时期提出了过多米诺骨牌理论，这个理论认为，东南亚地区就像一多米诺骨，越南是其中的第一块，一旦越南被张牌带下，被共产主义阵营征服，那么印度就会有一来国家像骨牌一样就前倒去。因此，为了一道多米诺效应，美国就必须站住越南这张牌。
