# 斯大林的构想

说完了丘吉尔和罗斯福，再来看看斯大林。

就理念层面来说，苏联想有些类似于美国，有着一种深刻的理想主义。共产主义同样拒绝老欧洲追求势力均衡的秩序观，但它拒绝这些的深层原因，在于它对“国家”这个概念的拒斥。

依照列宁主义，一旦世界实现普遍革命，国家就消亡了，人类就建立了大同世界。但是此时才所期待的西方国家连锁革命并未出现，苏联也就不得不与西方国家共存；而要共存的话，苏联必须考虑自己的战略安全问题，所以迅速地落入到一种势力均衡的逻辑。

但是这和丘吉尔的追求大不一样，因为对斯大林来说，势力均衡不是追求的目标本身，而只是面对现实的一种暂时妥协，理论上来讲，这种秩序终将被普遍革命所推翻。

所以，斯大林在雅尔塔会议上极力要把苏联的势力范围推进到中欧地界，但这并不是像丘吉尔一样为了消除战争隐患，划清双方边界；而是一方面要让苏联获得战略安全缓冲，一方面构成革命对外推进的准备。从这里可以看到，斯大林的主张中，革命的一面是高度理想主义的，而划势力范围的一面又是高度现实主义的。

这样三种不同的秩序观的多重复杂博弈关系，相互支撑又相互制衡，最终在雅尔塔会议上找到了一些交叠共识，就是我们所熟知的二战后建立起来的三大国际经济组织、联合国、五大常任理事国等等安排。

这些安排终结了大战时年代，但是其中蕴含着一系列内在的张力，终于引发了持续半个世纪的冷战，国际秩序进入到阵营割据时代。

从下一讲开始，我们就来进入这个新的板块。

下一讲再见。

划重点

为了安排战后秩序，必要考虑这么几个问题：

+   - 第一，要尽可能地避免再次爆发大战，那么就得尽可能形成国际道德观的均衡，同时还能匹配各国力量对比的结构性关系；

+   - 第二，要让本国利益尽可能最大化，既包括物质层面的利益，也包括本国价值观念的更广传播；

+   - 第三，基于前两种考虑所形成的战后国际秩序方案，要能够获本国支持，需要和国民的精神气质以及本国的内政机制有着某种共振性。

# 留言
听了这一讲之后我认为总的来说到列宁和斯大林威胁的共产主义可以以在某种程度上回忆成为形式。因为共产主义在本质上不是以国家为基础而是以阶级为基础，只要是统一的政党也可以以不同的国家，这也是苏联的形态。所以共产主义的意志在英美为主的国家中能否有土壤就不再是法律问题，而是现实问题。所谓现实问题就是老百姓是否能过上好日子，如果西方的制度不行，共产党人打游击就会敌苏联威胁。但是反观资本主义，国民党主义的思想并不能动摇共产党执政的基础，因为他们所依靠的民族的民族角度在苏联也存在。所以从我意识形态角度出发，我判断西方社会的精英在当时应该是对着威胁的，共产主义确确实实是。真正让苏联输掉冷战的不是意识形态，而是共产主义意识形态最终既没有带来繁荣，也没有带来公平，经济发展始终不如西方社会。没有带来最大的就是低层的民众，所以失去了民意基础。列宁和斯大林在共产主义思想并没有很好地解决经济问题。
