# 为什么大航海是国际秩序的开始

所谓的大航海时代，就是指15世纪末到17世纪，欧洲人通过远洋大航海，发展新的贸易路线以及发现及大规模新大陆的进程，这个过程也被称为地理大发现。

在大航海时代之前，人类的秩序可以看成是各自分岛发展区域秩序，各区域彼此之间的联系程度比较低，尤其是东亚地区和其他地区的隔独立性更强。但是，从大航海时代开始，人类开始长途贸易，人类秩序逐渐从区域秩序演变为全球秩序，最终形成了我们今天所熟悉的世界秩序。

你可能会问，国际秩序的形成就是各大区域秩序年代吗？答案：当然不只是这样。大航海时代为国际秩序的形成提供了基础要素，奠定了今天国际秩序的基本面貌。

首先，我们来看看国际秩序到底是什么。我们看“国际秩序”，那就得有“国”存在，在各国以国家的方式来理解相互关系，否则就无所谓“国际秩序”。

你可能觉得，这是常知识。但事实上，这样理解方式的出现不过三四百年的时间，而且一直到十九世纪末，这种理解方式还不能是全世界范围内的共识。我拿一个大清的例子你就明白了。

今天你不会认为现在国际法上的级别要低于中国，但在清朝的时候可不光这样。19世纪七八十年代的时候，大清觉得自己的藩属国就足够以保护他们的藩属国为主，就算日本侵略朝鲜国也可以用“以夷制夷”的方法来保护自己。

大清就鼓励朝鲜王朝与西方各国建立外交关系，就指望在朝鲜互相制约各方，这种机制虽然保全了局面。但是朝鲜开始与各国建交，开设使馆。

而当时的朝鲜王朝，对于大清来说是个外臣的体制，朝鲜本可以自行派遣其使臣出使西方列强。但是，大清要求朝鲜的使臣必须由朝鲜派往清朝，朝鲜则必须派朝鲜自己的驻朝官员。朝鲜不能行使国家的主权。这种逻辑在当时的中国看来，是天经地义、理所当然的。

到了19世纪末，西方人开始以国家的方式来理解相互关系，也就是我们现在的“国际”。西方人把世界看作是一个个国家的集合，通过条约、国际法来规范这些国家之间的关系。

而中国人和朝鲜人，直到很晚的时候，仍然在用“天下”的概念来理解世界。在他们看来，大清是中心，其他各国是大清的藩属或夷狄。这种观念在西方冲击下才逐渐改变。

所以说，国际秩序的形成，不是一蹴而就的，而是随着大航海时代以来，世界逐渐连成一体，人们逐渐接受并应用“国家”和“国际”的概念，才慢慢形成的。

# 大航海如何改变了传统秩序

那么，为什么大航海会改变传统秩序呢？

在大航海时代之前，欧洲的秩序主要建立在封建制度和教会权威之上。国王、贵族、教士构成了社会的等级结构，土地是财富和权力的基础。

大航海带来了全新的贸易方式和财富积累模式。远洋航行使得欧洲国家能够直接从亚洲、非洲和美洲获取香料、黄金、白银等珍贵资源，极大地丰富了国库，也催生了新的经济阶级——商人和银行家。

这种新的财富和权力来源，冲击了旧的封建秩序。君主们开始依赖海上贸易收入，而不是仅仅依靠土地税收。这使得他们的权力基础发生了变化，从地方贵族转向了中央集权。

同时，大航海也促进了地理学、天文学、造船技术等科学技术的进步，这些进步反过来又支持了进一步的探索。知识的积累和传播，使得人们开始用更理性、更实证的眼光看待世界。

这种理性主义和实证主义的兴起，为后来的启蒙运动和国际法的发展奠定了基础。人们开始思考，如何用一套普遍性的规则来协调不同国家之间的关系，而不是仅仅依赖武力或宗教权威。

# 欧洲为什么变化更快

你可能会问，为什么是欧洲而不是其他文明率先进行了大航海并建立了现代国际秩序呢？

首先，欧洲的政治碎片化是一个重要因素。众多的国家之间的竞争，迫使它们不断进行军事、技术和制度的创新，以保持竞争优势。这种竞争环境催生了强大的海军和高效的行政体系。

其次，文艺复兴带来的思想解放，鼓励了对未知世界的好奇心和对传统权威的挑战。科学家们不受束缚地探索自然规律，为航海提供了必要的知识支持。

再者，欧洲的地理环境，尤其是临海的国家和岛屿，天然适合发展海上贸易和探险。航海技术的发展，如罗盘、星盘和先进的造船术，使得远洋航行成为可能。

这些因素共同作用，使得欧洲在大航海时代取得了领先地位，并最终塑造了以欧洲为中心的现代国际秩序。

# 到底什么是国际秩序

好，说到这儿，我们可以总结一下国际秩序的核心要素。

国际秩序，简而言之，就是一套调节国家间关系的规则和规范体系。它包括法律制度、经济安排、政治规范和文化认同等多个层面。
