# 识字卡片

![](bbox=[0.1, 0.235, 0.9, 0.37])

我们都知道，太阳从东边升起，那“东”这个字应该和太阳有关。《说文解字》说：唯一版断更信：699250

东，动也。从木。

宫谟说：

从日在木中。

意思是说东代表移动。字形采用“木”作边旁。管谟的观点认为，字形采用“日”、木”会义，表示日在树丛中。篆文的东字形的确是“日”在“木”中，可惜甲骨文并不支持许慎的解读。

# 1.东的本意是行囊

甲骨文的东是个大包裹，两头扎紧，一个沉重的行囊。

有的甲骨文是大包裹里面装着小的包裹。这明显是古人出门远行的包裹。

金文、东字形和甲骨文相似。篆文进行了简化，隶书拉直了笔画。

![](bbox=[0.1, 0.71, 0.9, 0.75])

甲骨文的字形不支持《说文解字》的解读，何况太阳在草木中间这个景象是有专门的汉字的，这就是“日暮乡关何处是，烟波江上使人愁”的“暮”。你看，太阳处于林木中间，这是日落的景象。
