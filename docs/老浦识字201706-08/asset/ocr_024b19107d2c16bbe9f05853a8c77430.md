# 1.闪电既可怕，又是福音

甲骨文的神  就是一道闪电。

在古代，有许多事情古人无法解释，于是都仰望苍天，觉得世上万物都是上天决定的。

但上天的旨意体现在哪里呢？那就该是闪电吧。

闪电可不仅看起来很可怕，一个霹雳下来，可以打死人，还会引发森林大火，非常恐怖。

然而，闪电带来的火也是人类的福音。火烧死了很多野兽，被火烧过的兽肉格外香，很好消化。而且，被火焚烧的林地长出的庄稼也格外茁壮。

闪电既恐怖，又有益，真是上天的意志，神了。

《说文解字》：

> 神，天也。引以万物者也。

所以，闪电的形状就是神的样子。

# 2.手雷掌电的宙斯

希腊神话中，最高级别的神——宙斯，就是掌管雷电的。

普罗米修斯为人类盗火，让人成为万物之灵，却遭到宙斯严厉的惩罚：宙斯令其他的山神把普罗米修斯用铁链缚在高加索山的一块岩石上，让恶鹰天天来啄食他的肝脏，而他的肝脏又总是重新长出来，这样的痛苦将持续三万年。

# 3.“神”从什么时候变成了“示”字旁？

佛道儒三教当然后果对人类当要对“示”进行祭祀，这就是金文的“神”  。

和世界很多古老文化一样，中国人也相信万物有灵，世界上所有的事物都有神灵负管肇。后世，人们把无所不包、无所不在的大神称为帝，而具体的办事处则由神灵来掌管：河神、山神、土地神、财神、送子娘娘等等。

![](bbox=[0.25, 0.88, 0.75, 0.98])

篆文的“神”   将金文的  写成   ，已经不像闪电了。

隶书 神  隶书    楷书 神

这就是我们今天使用的神字了。

# 4.人体内也有“神”

中国文化中，不仅大自然是由神管理的，人体内也有神，这就是我们平常说的精气神。

这个神，指的是人的意识和灵魂。道家养生，说炼精化气，练气化神，就是指通过对身体进行物质性的修炼，涵养你的意识。也就是神，神养好了，就能够强健身体。我们平时说的“闭目养神”就是这个意思。

宋代的丞相范仲淹在《岳阳楼记》中说：

> 登斯楼也，则有心旷神怡，宠辱皆忘。

这个神，指的是人的意识。

# 5.和闪电有关的字

闪电   加上  ，是神仙的神。

加上雨头   ，就是雷电的“电”  。

由于闪电很长，由上往下延展，加上单人立人  ，就是伸展的伸。

而由于闪电的神性，本字申  就引申为自下而上的请求和表达，比如申请、申诉。申，还被借用为地支第九位，辰酉。

# 总结一下

+   1.神的原意是一道闪电，闪电带来神祗莫测的文场，也带来火，使人成为万物之灵。

+   2.汉字细分后，给闪电加上不同的偏旁，组成不同的字。加“示”成为“神”，加“雨”成为“电”，加“人”成为“伸”。原字“申” 由闪电演化为自下而上的请求和表达，比如申请、申诉。
