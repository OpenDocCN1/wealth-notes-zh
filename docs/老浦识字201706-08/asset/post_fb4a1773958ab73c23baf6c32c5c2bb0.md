
# 【羊】吉祥和公正的代表

老浦提示：订阅老栏后，文章中的象形文字可藏可点，放大来看，细细品读。

我们先来看看甲骨文中的“羊”，就是一个羊头，和牛头的字形原是一样的，只不过牛角是上翘的，而羊角是向下弯曲的。

![](img/6b2d826949bfddce96931988065f7fef_0_1.png)

- **羊是祭品，代表吉祥**

在中国，羊是祭品。牛祭被称为太牢，羊祭是少牢。《说文解字》解释：“羊，祥也。”我们知道“示”的原意是祭台，所有示字旁的字都与祭祀有关。用羊祭祀，祈求吉祥。

这是金文中的“羊”，更加突出了弯曲的羊角，更加具有装饰性。让人看起来一派祥和。

![](img/6b2d826949bfddce96931988065f7fef_0_2.png)

加水是“洋”，是烟花、太平的大海。加火是“烊”，是熄灭为安。打烊，指关门熄灯。加气是“氧”，是空气中令人呼吸顺畅安宁的气体。加言是“详”，是在祭祀时赞美神迹。加行是“徉”，是步态安详。徜徉（cháng yáng），就是神游从容自在，步态高逸安详。加飞是“翔”，是展翅长空，顺风顺水。加鱼是“鲜”，是人间美味。

- **国宝四羊方尊的身世**

![](img/6b2d826949bfddce96931988065f7fef_0_3.png)

1938年4月的一个上午，湖南省宁乡县黄材镇转耳仑山上，姜家兄弟三人挖到了一件宝贝。这就是国宝四羊方尊，是商代用于祭祀的青铜重器。古董商计划20万大洋倒卖出去。当时的长沙县政府为了防止国宝流失，收缴了这件文物。

## 【鸡】

- **古人认为鸡可以带来光明、驱逐妖魔**

甲骨文的“鸡”字，是一只昂首挺胸、引吭高歌的大鸟，象形字突出了它高耸的鸡冠、美丽的羽毛，尤其突出了张开的喙，表现公鸡最大的特征。鸡打鸣本来就是一种生物现象，光线刺激了鸡的眼睛，它就不由自主地打鸣，宣告主权，提醒家庭成员它至高无上的地位，也警告邻近的公鸡不要打它家财产的主意。古人不懂这个，他们以为太阳是鸡叫出来的，所以认为鸡能带来光明、驱逐妖魔。正月初一“鸡主镇宅”年画的风俗，就是这么来的。

- **“呆若木鸡”到底是不是傻？**

这是甲骨文“鸡”的另外一种写法：

![](img/6b2d826949bfddce96931988065f7fef_1_9.png)

在“鸟”字旁边，增加了一个“奚”字。

![](img/6b2d826949bfddce96931988065f7fef_1_10.png)

“奚”是一只手抓住一个被捆绑起来的人，也有奴役并戏弄的意思。这反映了公鸡的一个特性，就是被人利用，比如斗鸡。

![](img/6b2d826949bfddce96931988065f7fef_1_11.png)

这是“金文鸡”的一种写法，因为是铸造在青铜器上的，造型比较写实。这个鸡像，让我想起一个成语：呆若木鸡。庄子讲过一个故事，说一个训练斗鸡的高手为齐王养斗鸡，过了十天，齐王问：“鸡训练好了吗？”高手答：“还没有，这鸡虚浮骄傲，自恃意气。”又过了十天，齐王问。

又过了十天，齐王问。高手答：“还没有，它听到动静马上有所反应，不稳重。”再过十天，齐王又问。高手答：“还行，它眼光敏锐迅猛，傲气十足。”又过了十天，齐王最后一次问。高手终于回答：“这回可以了，别的鸡打鸣，这只鸡不为所动，看着就跟一只木鸡似得，别的鸡看见它精气内敛，渊渟岳峙的姿态，根本不敢跟它打，转身就跑。”其实，呆若木鸡这个成语，是形容一种不为外所动的极高的人生境界。

![](img/6b2d826949bfddce96931988065f7fef_2_0.png)

## 【狗】

狗是人类最早驯化的动物，在狩猎采集为主要生产方式阶段，狗是不可或缺的得力助手。甲骨文的狗是一个象形字：犬，细长的身体，长长的尾巴，一看就是一只善于奔跑、身形健美的好狗。

![](img/6b2d826949bfddce96931988065f7fef_2_1.png)

和犬相关的字，反映了古人心中的狗的形象。臭（xiù），上面一个表示鼻子的“自”，下面一个“犬”，表示狗嗅觉的灵敏。狩猎的狩，一个“持”加上一个“犬”，表示手持木棍，带上狗去打猎。埋伏的伏，一个人带着犬趴在隐蔽的地方。篆文的猝，一个犬，加上一个表示声旁的卒，表示犬从草丛中猛地窜出来追逐猎物。这些犬字旁的汉字，是古代狩猎活动生动的写照。从这些字上，我们分明能够感觉到猎人和自己心爱的猎犬亲密无间的关系。

再来看一个很有意思的字—戾。戾气的戾，上面的户代表房屋，旁边有个犬，表示狗在看门的时候极其凶恶。

# 【柴】本来是用来敬神的

老浦提示：订做专栏后，文稿中的象形文字可载可点，放大来看，细细品读。

![](img/6b2d826949bfddce96931988065f7fef_4_0.png)

柴是家庭最低值的易耗品，缺不了，也不值钱。但是在古代，柴可不简单，那曾经是很神圣的物品。

## 1.柴字的含义

篆文柴，上面一个此，下面一个木。“此”的甲骨文，旁边一个字，合起来表示人站立的地方。有的甲骨文的“此”，把人字放在脚趾上面，站立地点的意思更加明确。柴还有一个异体字，“此”字下面一个“示”，示的原意是供奉，凡示字旁都与祭祀有关，可见柴的原意是用于祭祀的木头。《说文解字》中说：“柴，烧柴燎祭天也。”

## 2.惨烈的柴燎

古代柴燎祭天叫柴祭，《后汉书·丁鸿传》：“瞻灵山，嘉祥降割：柴祭之日，白气上升，与柴烟合，氛祲辈举。”这是说皇帝到柴祭天，柴祭上升的白烟与柴熏一起缭绕，预示着吉祥如德。这是帝祭的祭天，宣示皇帝的君权神授。但在更加远古的商代，这是祭天祈雨的惨烈之举。之所以说惨烈，是因为这种柴燎仪式是要用活人祭祀，活人的级别越高，表示祭祀之心越虔诚。

夏朝末年，天上大旱，商代的开国君王汤，发动的汤武革命，推翻了夏朝的残暴统治，但是引发夏朝危机的天下大旱已经持续了七年，仍然没有下雨的迹象。巫师说，要用活人来祭才能感动上帝。商汤决定以自己能出这样的牺牲。请允许我用一段潘先生先生在《青铜时代》中对这一场景的描述：“于是商汤把自己泡在水里，散发，断甲。商汤素车、白马、身披白茅，彤光外发，站在台子上，和其他牛羊杂品祭成一排，伴着牛羊的叫声，被一齐抬到了宗庙的祭坛上，周围架起了柴束，为了方便上帝品尝，人们给商汤肚子上放了一盘肝片。”这当然是潘水先生根据史料的想象，但是当时用柴燎祈雨确实是历史真实发生过的。据说商汤的做法感动了上帝，天降大雨，商汤也没被烧死，但是后患，随着王权的强大，被烧死的就是王或者俘虏，而不是巫师本人了。

## 3.跟柴有关的汉字

这是甲骨文，一个人交叉着双腿，在火上被活活烧死，这就是柴燎祈雨的写照。到春秋战国时期，汉字进一步细分，从山上采集、作为居家燃料的干柴叫“橚”；从山上采伐、未锯断、劈细的原木叫“薪”；由原木劈成细块，作为居家燃料的木料叫“柴”。薪的本意就是柴火，在庭院中点火照明，一个将终，马上点燃另一个，叫薪火相传。后世用这个成语形容事业代代相传。

# 总结一下

- 柴最早是用于祭祀的柴火；
- 隆重的祭祀仪式是要用活人作牺牲的；
- “薪”的本意是柴火，由于砍柴汲水是日常用度，后来就把工资称为薪水。

文字原意：古文的盐上面是卤水的卤，下面是一个卤水过滤的容器，右部是古人手工提炼的食盐。

![](img/6b2d826949bfddce96931988065f7fef_5_2.png)

《舌尖上的中国》有一句话，我印象很深：一个美食家说，世界上最难吃的食物，是没放盐的食物。汉代王莽曾在诏书中说道：“夫盐，食肴之将。”意思是：盐是食物中的将军。

- 金文的盐，下面一个器皿皿的皿，上面一个卤水的卤，卤的原意是未加工过的含盐的卤水，而加上器皿皿，表示人工提炼过的食盐。
- 有的金文，加上了表示查看的监，监的原意是用水盆照镜子，在这里表示监视卤水转化为晶体的情况。

《说文解字》：盐，咸味。从卤，监声。古者，宿沙初作煮盐。意思是说是咸味的。字形采用“卤”作边旁，采用“监”作声旁。一个名叫“宿沙”的人最早开始通过煮熬海水制盐。用海水煮盐，肯定要用心监察。甲骨文没有盐字，只有卤，表示用卤水浸泡食物，以防防腐，长期保存。《尚书·禹贡》记载，说在夏代，这种叫做调味品盐极为珍贵，要作为贡物上交。到了周代，人们已经把咸味作为“五味”，即酸、苦、辛、咸、甘之一。

![](img/6b2d826949bfddce96931988065f7fef_6_1.png)

![](img/6b2d826949bfddce96931988065f7fef_6_2.png)

“**米**”，是一个象形字。甲骨文的字形像是围绕着穗梗挂满了米粒，但是这可不是我们日常吃的大米，而是粟（sù）和黍（shǔ），粟是小米，黍是有粘性的黄米，这两种米是古时候北方的主食。

![](img/6b2d826949bfddce96931988065f7fef_6_3.png)

![](img/6b2d826949bfddce96931988065f7fef_6_4.png)

金文的米和甲骨文区别不大。而篆文米把上下两点贯通。隶书米则写成“木”加“两点”，成了我们今天写的米字。为什么这个米指的是小米而不是大米？因为甲骨文产生于北方，当时北方只能种植粟和黍，南方的大米叫“稻”。《说文解字》：“米，粟实也。象粟实之形。”意思是，米是粟的籽实，是象形字，字形就是粟的籽实的形状。

农业起源对古代文明具有决定性作用。全世界有三个主要的农业起源地，一个在西亚，就是现在的伊拉克及其周围地区，是小麦与大麦的起源。第二个就是中国，中国是小米和大米的起源国。小米是指粟、黍，主要在黄河流域起源和发展。北方现在主要的谷物是小麦，而小麦又是从西亚那边传过来的，不是中国原生的。第三个是在美洲，美洲是玉米和红薯的起源地。玉米和红薯在明代传入中国。这是甲骨文里来的黍。

# 【酱】化腐朽为神奇的食物

# 识字卡片

![](img/6b2d826949bfddce96931988065f7fef_7_1.png)

字源演变：jiàng

文字原意：“肉”的下面是一个“酉”，上面是两只手，两只手捧着一个大的食物。这个食物是肉和酒混合，发酵的产物。发酵是跟酒有关的，古时候的“酉”代表酒，所以“酱”是酒里煮肉。

## 1.发酱都是因为了舍不得浪费食物

在中国古代发明里，酱的发明是最没有争议的，韩国都没学。我是安徽人，爱吃臭鳜鱼，闻着臭，吃起来确实鲜美无比。传说是一百多年前前金老爷爱吃鲜鳜鱼，路上鱼死臭了，渔家舍不得扔，就清洗干净用盐腌了起来，不料到地方把臭鱼试着烹调，鲜美无比。我们以前在讲汉字的时候说过，中国自古多灾多难，常年闹饥荒，所以中国人对食品从来都很珍惜，不仅动物，野菜甚至树叶、树皮、观音土都吃，而且动物身上任何部位都不会浪费，鸡头、鸡爪子、鸡肠子都有不同吃法。那么变质的东西自然是舍不得，我猜，酱的发明权只能归于中国人，没有哪个民族这样珍惜食物。酱的发明也是出于舍不得的心理。

## 2.“酱”字的含义

## 3.酱的种类自古就很多

最早的内酱也叫醢(hǎi)，是由肉做成的，其加工方法，是将新鲜的好肉研碎，用酿酒用的曲和盐拌匀，再倒进酒里去，装进容器，容器用泥封口，放在太阳下晒，百日以后才可以食用。作为王公贵族专享的奢侈品，《周礼》中记载了不同的肉酱：鹿肉酱、獾肉酱、田螺肉酱、蛤蜊肉酱、唇蛤肉酱、兔肉酱、鹿肉酱等等，不同的酱搭配不同的主食；雕胡米饭和野菜羹配螺肉酱，干肉粥配兔肉酱，熟糜肉片配鱼肉酱，吃鱼片配河豚。这么讲究，难怪孔子“割不正不食，不得其酱不食。”宫廷中甚至有专门管酱醋的人，叫“酱人”，和“酒人”、“浆人”一样，都是后勤部门的重要官员。

进入西汉以后，出现了豆酱。马王堆一号墓就发现了豆酱。有了豆酱，有蚁就也有了酱油。东汉时称为清酱，是酱油上面澄清的一层液体，到宋代，才叫酱油。酯(yǐ)，这是一种加上糯米稀饭的略带酸咸味的食品，是古代长江流域的美食，传入日本，成为今天的寿司。

# 总结如下

酱的“酉”字表明最早的酱是酒酿的碎肉，盛放在三大鼎里，是贵族专享的奢侈品；后来有了带“卤”的字样，表明用盐腌制作肉酱；肉酱有很多种，不同的食品配不同的肉酱，孔子对酱很讲究，酱搭配不对就不吃；进入西汉以后有了豆酱，酱和酱油从此进入寻常百姓的厨房，并传播到朝鲜、日本、东南亚，成为亚洲共同的美食传统。
