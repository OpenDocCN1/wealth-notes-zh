# 1、篆文及以前并没有“茶”

甲骨文、金文甚至篆文里都没有“茶”，说明茶是比较晚才出现的事物。

不对啊，喜欢喝茶的人都知道，茶是神农发明的。说神农尝百草，日遇七十二毒，得荼而解之。没错，这个“荼（tú）”，小篆有

![](bbox=[0.4, 0.56, 0.6, 0.6])

这是茶最早的传说。

最新的考古发现，河南濮文化村遗址出土了距今6000年左右的山茶树根，经专业机构检测认定，左侧属于茶树植物遗存，是目前已知我国境内考古发现的最早的人工种植茶树的遗存。这样的考古发现，连同云南的千年古茶树，证明饮茶就是中国人的发明，而不是西方人相信的印度或斯里兰卡。

但是甲骨文里就是没有茶，金文甚至晚至秦汉的篆文里都没有茶字，这让喜爱茶文化的人十分郁闷。

# 2、那“荼”是不是茶呢？
