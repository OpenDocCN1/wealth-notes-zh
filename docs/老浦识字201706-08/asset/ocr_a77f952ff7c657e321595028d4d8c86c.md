# 1.德，本意是为正直

生活中，有些日常用语我们都会用，但是并不知道原意。比如骂人话“王八蛋”，原意是“忘八端”。什么是八端？按照儒家的解释：孝、悌、忠、信、礼、义、廉、耻，这是八端。

忘八端，说白了就是缺德。

甲骨文的“德”，是一个十字路口，中间有一个眼睛，眼睛上面有一条直线，这是曲直的直。合起来表示在大道上行走，目标坚定，绝不曲折犹豫。

有的甲骨文将十字路口“行”简化为双立人“彳”，意思不安。德的本意是行为正直，不偏歪门邪道。

# 2.因为强调了心灵，德的分量越来越重

金文的字义发生了变化。金文的德在甲骨文眼睛上的一条直线加上了一点，写成，强调这条直线是重点。有的金文加上了“心”，表明这不仅为心灵，更是心灵的修养。

因为强调了心灵，德的分量越来越重，德高望重、感恩戴德、功德圆满，甚至以德报怨。

# 3. “唾面自干”的典故和对“以德报怨”的误解

娄师德是武则天时期的宰相。他弟弟被任命为代州刺史，来向他辞行。娄师德嘱咐弟弟一定要低调。

他弟弟说：“放心，就算有人往俺脸上吐口水，俺擦了就算了。”

娄师德说：“那不行，你擦了，人家觉得你不厉害。让他吐你还是应该让那口吐沫自己干。”

这就是唾面自干的典故。这种以德报怨的态度，孔子其实是认同的。《论语宪问》里说：

> > 或曰：以德报怨，何如？
> 子曰：何以报德？以直报怨，以德报德。

学生问孔子：人家欺负我，我用道德感化他，如何？

孔子说：你用德来回报怨恨，那你可以用什么来回报有道德的人呢？正确的做法是，用正直来回报怨恨，用道德回报道德。正直行世，是甲骨文本色。

关于“以直报怨”的解读有不同版本，另有一说，说“直”是“等价”的意思，这一点在陈慧《断魂书院》中，《9.11：论语如何用到9.5》做梦梦到重大，能选花了几周时间非常详细地聊了孔子，推荐大家看看。

# 4.东京审判与以德报怨

二战结束以后，由美、中、英、法、苏等11国指派的11名法官组成远东国际军事法庭，在日本东京，对第二次世界大战中日本主要甲级战犯进行了国际大审判，史称东京审判。

东条英机、广田弘毅、土肥原贤二、板垣征四郎、松井石根、武藤章、木村兵太郎等16人被判处无期徒刑，永户军判处20年徒刑，重光葵被判处7年徒刑。

7人于1948年12月23日在东京巢鸭监狱被执行死刑。东京审判从1946年5月3日开始，到1948年11月12日结束，前后持续两年多，共开庭818次，有419名证人出庭作证，受理证物4336件，英文判词录共48412页。整个判词判750万单词。从1948年11月4日起宣读长达1231页的判决书，到12日才读完。

这不是简单的复仇和传统意义上的要报恩，而是严格和国际法进行这些报复，对战争中犯罪进行公正、公开、严谨的审判，对恶人不姑息，也绝不意气用事。这就是我理解的以德报怨。

# 总结一下

+   1. 德的甲骨文原意是在大道上行走，目标坚定，绝不曲折犹豫，表示行为正直，不走歪门邪道；
2. 金文增加了心，表示这是心灵的修养；
3. 儒家总结了八德：孝、悌、忠、信、礼、义、廉、耻；
4. “唾面自干”来自于一个典故：娄师德嘱咐即将外地的弟弟不能擦唾，让别人往自己脸上吐口水，不能擦掉，让人自己干；
5. 今天“以德报怨”的用法是后人的断章取义，孔子的原意是以直报怨，二战的纽伦堡审判、东京审判都是这一原则的体现。
