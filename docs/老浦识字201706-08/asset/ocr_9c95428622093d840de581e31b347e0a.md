# ### 1.公的原意是公平分配食品

甲骨文的‘公’，上面是一个‘八’，原是‘分开’；下面是，口形有好几种解释，人体器官之口、吃的进食之口、祭器之口，也可能表示口形的器皿。在这里，就是表示口形器皿的大盘。合起来，表示平均分配食物，这就是公平。

金文的‘公’，承袭甲骨文的字形：

篆文，稍有变形，在岔上增加了一竖作为指示符号，表示公平分配的不仅限于食物：

而隶书，将篆文的‘口’明确写成‘△’。

> 《说文解字》：

> 公，平也。从八，从厶。八犹背也。韩非曰：背厶为公。

意思是，公，平均分配。字形采用‘八’、‘厶(si)’会义。八，犹如相背。韩非子说，与私相背，就是公。

虽然形骸有差异，但意思是不会改变的，S是形而核是公，S是私，与私相反，就是公。字形用的不对，原意却也没错。

司马迁在《史记 · 屈原贾生列传》中说：

> > 屈平疾王听之不聪也，谗谄之蔽明也，邪曲之害公也，方正之不容也。

这里的公，就是公正、公义的意思。

# ### 2.公字的引申

公字由公平，引申出大家的，共同的。《礼运》：

> > 大道之行也，天下为公。

由共同的，进而引申出开放、不隐瞒、公开。杜甫诗句：

> > 公然抱茅入竹去，唇焦口燥呼不得。

公然，本是偷偷摸摸的事却不遮掩，大白天把屋顶的茅草卷走，把公字用活了。

进入氏族社会以后，父亲越来越重要，父亲成为氏族的家主，也就成了掌管分配权的人民和利益班的代表。我们在‘缝’这个字里学过‘父’字，是手持猎具的父的会意，代表生殖权力。郭沫若解读为手持杀羊从事劳作，许慎在《说文解字》的解释是手持木棍，代表家长的权力。
