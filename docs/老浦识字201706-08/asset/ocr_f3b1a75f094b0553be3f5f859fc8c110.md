# 1. “绝”的象形字

绝，是个极端的字，断子绝孙，这是多毒的诅咒。有种解读是：贪官一沾上色，就绝了。那用铁笼旁的绳子把色捆起来，就可以绝了错误吗？

甲骨文的 '絶' 是两缕丝线中间各加一条短横，表示将丝线割成两段。
金文 '絶' 则在两缕丝线之间加一把刀，明确表示用刀割断丝线。

# 2. 和“兹”有关的字

我们在谈母亲的「慈」时，曾经见过这两缕丝线，是“兹”，表示草木繁盛生长，引申出生殖繁衍，生生不息的意思。

由“兹”组成的字，很多都与生殖有关：
慈，是母亲的亲。
擎，是擎生、繁殖生长的意思。
滋，是滋生、滋养的意思，又引申出味道、滋味的意思。
缕，是连接、继承。你可以点击蓝色的句子去看「缕」的解读。

这些字都与繁衍有关，断斩丝线已经令人痛惜，而切断了繁衍和继承，就是断子绝孙了。

所以我覺得“絕”這個漢字是帶有強烈感情色彩的。

# 3.以“色”为例，说汉字体分现象

你可能会说，这不对呀，这个“绝”更像是断绝的“斷”，怎么成了篆文绝？
这就是汉字体分的现象了。这两个字都来自金文 '斷'，是在金文基础上加上了一个表示斧头的斤，表示用斧头砍断物品。

而“绝”，是将两缕丝线规范成丝绞旁，加上刀，保留了“用刀割断”的原意，又加上一个形旁，扩大了义域，表示这样的割断是与人的遭遇有关。
需要注意的是，虽然“绝”的“色”的字形与颜色的“色”很接近，但它们是不一样的，“颜色”的“色”的上部是人形，而“绝”的右边的“色”是刀。

为什么不一样？这是因为，隶书的 '絶' 把篆文字形误写了。
所以，“绝”不是用丝线把色捆起来，而是用刀斩断丝线，引申为割断血缘继承。

# 4.子不学，断机杼

《三字经》里有句话，你肯定听过：
昔孟母，择邻处。子不学，断机杼。
说的是孟母为了给孟子一个好的学习环境，多次搬家。

有一天，孟子逃学回家，孟母正在织布，她看见孟子就非常生气，拿起一把剪刀，把织布机上的布匹割断了。

孟子看得很困惑，问原因，孟母说：“你读书就像我织布一样，织布要一线一线地连成一寸，再连成一尺，再连成一丈，最后成一匹，织完后才是有用的东西。学问也必须累积历久，是十分辛苦劳动才得来的。你如果偷懒，不好好读书，半途而废，就像这被裁断的布匹一样变成了没有用的东西。”
孟母由此决绝的行为，告诉孟子一个道理：中途浪费这业，那以前的所有努力也就废了，绝了。

# — 总结一下 —

+   1. 绝的甲骨文 '絶' 原意是用刀割断丝线，表示事物彻底中断；
2. 篆文的“色”细分为两个类型，一个是上面是表示斧头的“斤”，另一个是上面是“人”。到隶书，演化为今天的模样“绝”；
3. “兹”，意思是 由丝线缕、草木茂盛生长，而引申为繁衍。
