# 【幹】幹部和乾燥，都不是武器

> 【幹】幹部和乾燥，都不是...

老铺提示：订阅专栏后，文章中的象形文字可戳大点，放大来看，细细品读。

# —— 识字卡片 ——

![](bbox=[0.05, 0.33, 0.95, 0.5])

简化字用原意为武器的干 (gān)，合并了幹部（gān）和乾燥的乾 (gān)，这三个字原来的用法有很大不同，我们今天就在这三个字仔细一捋。

# 1. 先说 “幹 (gān)”

先看 幹 部 的 幹 (gān)，“幹”是 “幹” 的俗写体。篆文的幹，左边一个 柺 形，表示日出，下面一个木 木，合起来表示树幹。

幹的原意是树木最主要的枝幹，《淮南子·主训》：

故枝不得大如幹，末不得强于本。

意思是说树技不会强于树幹，树梢不会强于树根。

《徐霞客游记》中说：

柏虽大皆如臂，无不平贴石上，如苔薛然。

说柏树的树幹虽然像胳膊一样粗，却都像苔薛一样贴在石壁上。

《说文解字》:

幹，筑墙版 (duǎn) 木也。

意思是说幹这个字是筑墙夹板支撑的大木头。古代筑墙，是先立夹板，用粗木支撑，然后在夹板里填土，夯实，干燥以后拆除夹板，就是土墙了。

![](bbox=[0.1, 0.0010500000000000002, 0.9, 0.00115])

这是上世纪七十年代的 “干打垒”，是北方传统的筑墙方法。注意那些立着放的粗木就是许慎说的筑墙版 (duǎn) 木，也就是幹。许慎的这个解读，应该是幹的引申义，原意是树幹。

由于树幹的主力作用，所以就衍生出作为力含义的词汇，就社会组织而言，起主要作用的就叫幹部。就人体而言，主要受力的是躯幹。就人的能力来说，叫才幹。主要的道路，叫幹道。主要的河流，叫幹流。业务能力 强，堪当大任的，是骨幹。

由能幹，进一步引申出幹活以及口语中从事的工作，如我是幹编辑的，幹革命等等。

# 2. 再说 “乾 (gān)”

下面再说说乾燥的乾 (gān)，金文的乾，中间是一个表示朝阳、日出的符号 ☀，下面是火 火，两边是升腾而上的蒸汽 ∥，合起来表示水汽蒸发，空气乾燥。篆文 幹 将蒸汽改斋成 “乞” ⌒，仍然表示日照蒸发水分。

杜甫《茅屋为秋风所破歌》:

床头屋漏无乾处，雨脚如麻未断绝。

意思是，屋里到处都漏雨，没有一口乾燥的地方。

由乾燥，引申出缺乏水分的物品: 乾肉、乾货、豆腐乾、乾草、乾乾淨淨。

由缺乏水分，引申出副词空洞、徒劳的意思，如乾脆、乾笑。而没有来由的人际关系也可以用这个乾: 乾爹、乾儿子。

# —— 总结一下 ——

+   1. 幹 (gān) 的原意是树幹，正规的写法是幹，幹是幹的俗写体，许慎解读是筑墙的支柱;

2. 由于树幹对树木起到主要作用，所以引申出一系列起主要作用的词汇: 幹部、幹流、幹道、才幹、骨幹等等;

3. 乾 (gān) 的原意是太阳初升，日照强烈，水汽蒸腾形成的乾燥;

4. 引申出缺乏水分的物品和事物: 乾货、葡萄乾、乾笑、乾爹等等;

5. 这两个字，和作为武器的 “干” 没有关系，简化字把他们合并成为一个字，我们了解了它们的区别，使用汉字的时候就能够更准确了。
