# 【问答】为什么羊和手在一起会害羞

汉字重的甲骨文非常传神，一个背着包袱被压弯了腰的人物跃然纸上 ☎。让我们对沉重的概念感同身受。这样活泼的甲骨文还有一些，比如这个字 ⑄，金文是这样的 ⑋，你能猜猜这是个月么字，反映了怎样的情景？

**老浦**
这是保护的保，一个人手臂后延 ⑈，反抱着一个孩子 ⑉，就是孩子。古时候人们很辛苦，无时无刻都要参加劳动，孩子丢在屋里，很容易受到野兽侵袭，所以人们把孩子背在背上进行保护。现在在—些贫困地区还可以看到这样的情景，母亲用一个布兜背着孩子，有些甚至是大一点的孩子这样背着小一点的孩子上学或劳动。

了解了汉字“尸”和“屝”，你判断一下，尸体素餐和行尸走肉，分别应该用哪一个“尸”、“屝”？

**老浦**
尸体素餐，行尸走肉。尸体素餐出自《汉书·朱云传》：“今朝廷大臣，上不能匡主，下位以益民，皆尸位素餐。”比喻空占着职位而什么都不做事，白吃饭。用的是尸的原意。行尸走肉出自晋·王嘉《拾遗记·后汉》卷六：“夫人好寿，虽死犹存；不学者，虽存，谁之行走属肉矣。”这里前面说了好学的人虽死犹存，对应不学习的人活着也恨死人一样，所以这里的屣是尸体的屝。

羊作为字符，可以组成不同的字，这是一个有“羊”作为字符的甲骨文 ⑀，由羊 ♀ 和手 ㄅ 组成，你能猜猜这是什么学吗？利用了羊怎样的特征？

**老浦**
这是害羞的“羞”，原意是手捧羊肉进献，用于祭祀或款待宾客，引申为高级精美的食品，李白有诗“玉盘珍羞直万钱”。进而引申出惭愧、耻辱之心。汉·李陵《答苏武书》：杀身无益，足是增羞。

公是口形大瓮上面一个八 (u)，八 (1) 是分开的意识，甲骨文分开的分㏒就是八字下面一个刀，表示用刀分开。这个金文字形里也有八这个字符 亅，上面一个八，下面一个牛。你能猜猜这是什么学吗？

**老浦**
这是半字，表示把杀死的牛分成两半。

字义的变化很神奇，我们以前聊过，物是杂色牛，而驳 ⚓ 是杂色马，你能不能分析一下，这个杂色马是怎样演变出“驳斥”的意思吗？

**老浦**
由于驳是杂色马，所以七嘴八舌就被称为杂讧，驳议。由于人多嘴杂，自然就有不同意见，于是就有辩驳、批驳、反驳的引申了。《晏子春秋》就有“不以己是驳人之非。”的说法。意思是君子不依仗自己的正确去驳斥别人的过失。
