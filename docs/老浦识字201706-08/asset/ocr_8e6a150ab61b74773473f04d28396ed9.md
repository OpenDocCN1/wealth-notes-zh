今天，我想从“膏”字入手，为你介绍三个字：膏、脂和油。

# 1、膏和脂的区别

在甲骨文里，“膏”是代表油脂的字，还有一个“脂”字，也是代表油脂的字，而且都是动物脂肪提炼出来的。

这两个字分别是什么意思呢？

膏，甲骨文 ![甲骨文1](icon1)，上面是代表庙堂之高 ![甲骨文2](icon2)，下面一个表示肉的肉（实际上是月的简写） ![甲骨文3](icon3)，合起来表示敬献给庙堂的动物油脂。油脂是动物的精华，最好的东西当然只能敬神。

那“脂”又怎么解释？金文脂 ![金文脂](icon4)，上面是勺字下面加一个器皿，表示美味的“旨” ![甲骨文旨](icon5)，下面一个表示肉的月 ![甲骨文月](icon6)，合起来表示美味的动物油脂。篆文 ![篆文脂](icon7) 调整成左右结构。

那“膏”和“脂”到底有什么区别？

> 《说文解字》说：

脂，戴角者脂。无角者膏。从肉，旨声。

什么意思？牛羊头上有角，牛羊油是脂，猪头上没有角，猪油叫膏。现在我们说民脂民膏，就是人民身上的血肉。

《说文解字》的这个解读是字源的发展。你有没有注意到，脂和膏这两个字都有“月”字旁。

汉字月字旁的字和月亮无关，它是由“肉” ![肉字旁](icon8) 字演化过来的，实际上是肉字旁，凡月字旁的字都和肉有关。

![](bbox=[0.1, 0.83, 0.9, 0.9])

这是立在河南开封府的宋太祖赵匡胤的《成石铭》，黄庭坚书写。是专门告诫官员的，你们的工资收入，都是老百姓的血汗，欺负老百姓容易，上天却能把你看清楚。

脂、膏这些提炼出来的动物油，除了敬神，当然人也能够吃。

能点灯用吗？最早的灯具出现于战国时期。著名的长信宫灯是西汉汉时期的，使用提炼技术也是从西域传入的，中国才有植物油。当然这些器都是只有贵族才能使用的奢侈品。

# 2.油是“水”，不是油脂

有人说，“膏”和“油”是同一个意思，其实是一种误解。

> 《说文解字》说：

油，水。出武陵旆（chán）施，东南入江。从水由声。

意思是，油，是河川的名称。这条河流从武陵旆施西，于东南汇入长江。字形采用“水”作形旁，“由”是声旁。

![](bbox=[0.35, 0.00122, 0.65, 0.00132])

# 3.从河川名到食用油脂的演变

我们今天食用的植物油，也就是菜油，是张骞出使西域带回来的芝麻粉的油，提炼技术也是从西域传入的。从此以后，油才大规模进入寻常百姓的厨房。

由于有了这种液体的植物油，古人就借用了河流的“油”字来称呼这种物质。

现在，油不仅指可食用的油脂，还泛指从矿物中提炼的油脂，比如石油。

# 总结一下

+   1. 古代的油脂都是动物脂肪提炼的，有角动物的油叫脂，无角动物的油叫膏；
2. “油”这个字最早是一条河流的名字；
3. 汉代张骞出使西域带回了芝麻和植物油压榨技术，中国才有植物油，人们借用一个河流的名字“油”称呼植物油；
4. 现在的油泛指石油、植物和矿物油。
