有用户要求讲“正”字到，这个字看起来很简单，基本均为布局的笔画，方方正正，连我们计票唱票的时候都会写“正”字，但这个字，其实并不简单。

甲骨文的“正” [图标]，是一个方框形 [图标]，下面有个代表行进的止 [图标]，对于这个字形，文字学家有不同的解释。

# 1.对甲骨文的不同解读

一种说法是，这是射候的靶子。咱们以前在读“察”的时候接触过这个词，周天子会组织贵族青年射候，成绩好的可以封侯，这叫射候。有学者认为“正”是射候的靶子。

《诗·齐风·猗嗟》：
终日常候，不出正兮。
意思是（这个英俊的男人）射候一整天，次是命中靶心。

也有人认为是“征”，行进的意，但也可以不限于战争。在古代晚期，每年的第一个月要举行巡狩之礼，正zhēng，正一年中盛大的节日，所以这个月就称为正zhēng月。

最后一种解读是，这个方框 [图标] 是城邑，止 [图标] 是前往，如果说卫 [图标] 是城邑周围都是止（脚），意为保卫，那么城邑下面一个止 [图标]，那就是攻伐了。正的本意就是出征攻打城邑。

总结一下的解读，除了射候这一点，其他解读大致是一样的，那就是出发前往某地，而活动的主体是天子或王，是有君临身份感的人。读音为正zhēng。

《书·汤誓》：
予畏上帝不敢不正。

# 2.“正”的字形演变

金文 [图标] 承接了甲骨文字形。
篆文 [图标] 表示成城邑的一点变成一横。
楷书 [图标] 把这个字变得四平八稳。

# 3.zhēng怎样变成了zhèng

由于是居高临下的正，于是引申出中间、正确的含义，这时候读音为正zhèng。
比如孔子说：“席不正不坐，割不正不食。”
正，也成为道德标准，正人君子、平心持正。没毛病的事，我们会说：正常。
