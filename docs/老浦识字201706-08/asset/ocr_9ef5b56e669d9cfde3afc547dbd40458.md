文字原意：
重，是一个人站在东方腰带左右腰侧的口袋，在古代是皮制的。甲骨文用这个字的形象表示很沉重。

# 1. “重zhòng”和“出”造反了吗？

我们在【出】这一期的思考题里，请你思考过汉字“出”，有人认为出是造反了的，不合造字“出”和“重”是不是造反了？两个山相叠，应该很沉重；而“重”上下拆开是“千”和“里”，千里之行始于足下，这才应该是出门的。

我们已经了解了“出”的甲骨文的原意，是迈步走出地穴式茅屋，字型演变为两个山重叠。

这次我们来详细谈谈“重”：

重（zhòng）的甲骨文是一个人形，背上有一个大口袋，这个口袋就是“东”字的原型，原意是两头捆扎的皮质口袋，用来装东西。这种口袋很重，长途跋涉更是辛苦，所以用这个情景表示沉重。

# 2. 为什么人们会误以为“重”是“千里”？

金文把甲骨文的左右结构改变为上下结构，把人形放到了上面，表示行囊的“东”放到了人形的下面，意思改变。

有的金文在下面加上“土”，表示站在土地上。

篆书基本承续金文字形。

隶书“重”变形比较大，“人”形、“东”形消失。
