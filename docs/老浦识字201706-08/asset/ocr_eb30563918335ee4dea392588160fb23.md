# 【问答】为什么房子下面有土堆就是官

现在有一个甲骨文 [图]，是戈矛 [图] 加上双手 [图]，金文是这样的 [图]，同样是双手与戈矛的组合。请你猜猜看，这是个什么字？

这是戒备的戒 [图]，双手紧握武器，随时警惕敌人的进攻。戒烟、戒酒乃至修行持戒，没有与恶习拼死战斗的决心是“戒”不掉的。

在古汉字中，双手捧着器物表示恭敬，双手捧酒是尊敬的“尊” [图]，双手捧竹简是典籍的“典” [图]。现在这儿还有一个甲骨文 [图]，是双手 [图] 捧着“鼎” [图]，你来猜猜看，这是个什么字？

这是具备的具 [图]，双手捧着大鼎，表示准备祭祀用品，最重要的鼎已经摆好了，原意是供置、陈设。

我们在谈十二生肖的时候说过，马是改变人类历史的动物，由马组成的汉字很多，这个甲骨文字形 [图] 也有马，是不是让你想起2008奥运会的运动图标 [图] 了？请你猜猜看，这是一个什么字？

这是骑马的“骑”，一个手握缰绳的人形骑乘在马背上的象形。金文字形变化为“奇” [图]，篆文 [图] 加上了“马” [图]，再次明确了骑马的含义。2008奥运会运动图标的设计灵感正是来自甲骨文字形。

比是两人并肩而立，并肩而立的两个人 [图] 下面有一个“曰” [图]，这个字形 [图] 会是什么呢？

这是皆大喜的“皆” [图]，“比”是并肩而立，一起、共同。“曰”是说话，合起来表示异口同声，是谐的原字。引申为都、全。

[图] 的原意是土堆，也是“师”的甲骨文简写。现在有一个甲骨文，把这个“垓”放进了房子 [图] 里， [图]，你来猜猜看，这是一个什么字？

这是官员的“官” [图]，由房子 [图] 和师的简写 [图] 组成。师既可以是一师之众，也可以是一师之长，是领导。领导在屋子里办公，就是官员。
