# 2.大鼓为什么代表南方

南的本意是一种鼓形乐器，由于来自长江地区的南方，所以“南”字就借为方位的字。

关于鼓为什么能够代表南方，上有一种说法，古代朝堂坐北朝南，举行仪式的时候，乐队在天子的对面，而乐队最主要的乐器是鼓。天子坐北，鼓代表的乐队就是南了。

金文 <img alt='金文南' src=''/> 在甲骨文字形 <img alt='甲骨文南' src=''/> 的中间加上了一个棍棒 <img alt='棍棒' src=''/> ，表示敲击鼓形乐器。

有的金文 <img alt='金文南2' src=''/> 有所变形。篆文 <img alt='篆文南' src=''/> 继承了金文字形，成为我们今天熟悉的南。

> 《说文解字》：
草木至南方，有枝任也。

意思是草木到了南方生长的格外茂盛。

> 《徐日》注释：
南方主化育，故曰主枝任也。

> 《前汉·律历志》：
太阳者，南方。南，任也。阳气任养万物，故时为夏。

这些都是根据篆文字型，用阴阳五行学说来解说的，不是甲骨原意。

中国文化南北差异很大，以楚文化为代表的南方文化鄙视代表崇尚、崇火拜日、喜巫近鬼。以屈原为代表的楚辞浪漫华丽，想象力丰富，是中国浪漫主义文学的鼻祖。就文字而言，近年大量出土的楚简、帛书以及战国后期满出土的青铜器上的鸟篆文字，与我们常见的金文、秦简差异很大，字型非常有特点。
