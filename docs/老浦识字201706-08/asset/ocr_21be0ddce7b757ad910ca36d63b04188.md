# 1.道的主要是祈求神灵引领知道

道的甲骨文“ ”，外围是一个表十卡路口的“行”“ ”，在道路中间有一个小折“ ”。这个词与祭祀有关，是祈求神灵指示王应该走哪条路，以求打猎有更多收获，是“导”（導）的本字。

金文的道“ ”，仍然有完整的表示十卡路口的“行”“ ”，但是把甲骨文的人换成了代表头部的“首”“ ”，这样不仅仅代表人，更暗含了“能观察、思考、选择”的含义。在“首”的下面，还有表示行走的“止”“ ”。

有的金文“ ”的“首”下面不是“止”，而是表示手的“又”“ ”，都是表示伸手指点道路。

日本学者白川静有一种氏解读：说“上古时代，人们相信旧的氏族居住的地域中存在旧氏族之灵或鬼类。贸然进入的话会招致灾祸，因此进入其领域时，须手提高级者的首领进行，借助首领的祝咒之力辟邪疫（fú）灾。”

# 2.道的第一种引申义：道路

道的意思是引导，《史记·留侯世家》记载：

> 留侯性多病，即道引不食谷，杜门不出岁余。

意思是张良在辅助刘邦打天下以后，声称自己身体不好，在家闭门不出，不吃饭，练习引导养生术。这里的“道”，就是用引导的意思。

《说文解字》：

> 道，所行道也。从是（chuò），从首。一达谓之道。

意思是说：道，指人们所走的路。字形采用是（走）和首（头）为首（走、首）会意。直达的大路叫作“道”。

李白有诗：

> 大道如青天，我独不得出。

这个大 道，就是道路。

# 3.道的第二个引申义：途径、方法

由于大道是达到旅途终点的必然途径，所以引申为途径、方法。《荀子》中说：

> 好荣恶辱，好利恶害，是君子、小人之所同也，若其所求之道则异矣。

意思是说君子和小人都喜欢荣誉、利益，不喜欢被侮辱，被伤害，这些是相同的，不同的是实现这些目标的途径。君子选择正道，小人选择邪道。

# 4.道的引申义步步高

由于“道”具有神往指点迷津的基因，又于大道 的正确性 和 唯一性 ，所以“道”就引申为规律、道理，又引申为学说、主张。

《论语》说：

> 虽小道，必有可观者焉。

这里的道，就是道理的道。

由道理，进一步引申为道义、正道理。

圣人者，道之极也。

说圣人就是正义到了极点。

这还不算，“道”字到了老子的口中，终于升级为宇宙真理，万物之源：

> 道生一，一生二，二生三，三生万物。

# 5.真理需要阐述

道既然已经升级为真理，如此重，得道多助失道寡助，那自然需要阐述，讲解，表述，于是引申出说话、表达的含义。

司马迁在《报任安书》中说：

> 然此可为智者道，难为俗人言也。

说这个苦衷跟智者说可以理解，俗人就没法跟他说了。

# 6.道还是行政单位

由于大道辐射四方，所以“道”也借用于地方行政区划分名。汉代设下说道，唐代分全国为十五道。清代在州和府之间设道，相当于现在的地区市。

# 7.道的登峰造极：宗教

老子把道尊为真理，但并不绝对，因为任何真理都是可以讨论的，真理越辩越清晰。世界上真正绝对的道，不可讨论的是宗教，道教并不是老子创造的，它是尊奉老子为教主，太上老君，奉《道德经》为理论基础，有组织的道教，是汉代才有的。有了道教，道最终成为宗教了。

# —— 总结一下 —

+   1.道的原意是祈求神灵引导，引申为道路——途径、方法——规律、道理——学说、主张——道义、正道——宇宙本源——道教；

+   2.由于真理需要阐述，道引申为说话、表述；

+   3.由于道辐射四方，“道”借用为地方行政区名，大致相当于现在的地区市。
