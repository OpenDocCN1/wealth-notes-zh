# 1、热食物放进容器里是文明的表现

今天我们来认识一下食物的食，简单领略一下古人怎么吃饭。

甲骨文的食，是一个有脚的容器，表示装满食物，上面一个盖子，两个点，表示热气。吃起来表示热气腾腾的食物准备就绪，可以吃饭了。

![](bbox=[0.05, 0.41, 0.95, 0.5])

把热的食物盛放在容器里进餐，本身就是文明的表现。为什么呢？

你知道中国古称华夏，华是华丽，夏是大人，穿着衣服的人就叫华夏文明人，因为四夷未开化的人散发文身、不穿衣服。同理，钟鸣食就是食物吃食，食这样的容器里，鸣钟奏乐，当然是文明的表现，因为四夷未开化的茹毛饮血，生吃的肉。

# 2、文明的容器用来装什么样的食物？

这文明的容器里盛放什么样的食物呢？是混合着小米、蔬菜和牛肉的粥或米饭。

中国历史上有一个出名的白痴皇帝，晋武帝司马衷。这是一个锦衣玉食，从未到民间同百姓吃饭的公子哥。一次，全国闹饥荒，老百姓没饭吃，饿死无数，这个皇帝听了几大臣汇报后，感到很奇怪，便问侍臣说：“老百姓既无饭吃，为何，不食肉呢？”这话听起来就如同个千古笑话。

肉糜就是碎肉混合粮食熬成的粥，类似皮蛋瘦肉粥。当然那时候没有皮蛋，在皇帝那儿，肉糜是最平常的食物。而普通百姓，能有粥就不错了，肉是奢侈品，所以他们称贵族为肉食者，意思是吃肉的人。

# 3、匜（yí）是专门用于餐前洗手的青铜器

金文的食，将表示容器的“豆”写成。篆文的食，将金文字形中豆器的脚部写成“匕”，也就是匙子，像拿着匙子进食。

筷子是汉代才普及的，在此之前，人们用手吃饭。所以在出土的青铜器里，专门有餐前洗手用的匜（yí）。

![](bbox=[0.05, 0.87, 0.95, 0.93])

从这精美的器物，就可以想象出古人用餐的讲究。

# 4、其他表现古人用餐讲究的汉字

这里有三个汉字，形象地描述了古人用餐的过程。

即，一个人来到豆前，谨慎地跪坐，准备就餐。

卿，主宾双方恭敬地跪坐，准备用餐，

这三个金文都是卿的变体，表现用餐时彬彬有礼的情形。

![](bbox=[0.05, 0.00106, 0.95, 0.00109])

这是既，表示吃完告退。

这些字，都是食的细节。

![](bbox=[0.05, 0.0011149999999999999, 0.95, 0.00115])

普通的工作餐称为“饭”，正餐称为“食”，宴会称为“餐”。从商代到汉代，一天吃两顿饭。7-9点是“大食”，是这天最主要的一顿饭，一天的体力就靠这一顿了。下午3-5点是“小食”，量少而简单。

晚上不吃饭吗？晚上连灯都没有，最早的灯具是战国时代的，大多数人晚上早早地洗洗睡了。

# 总结一下

+   1. 食的甲骨文是一个冒着热气的盛饭器皿，表示吃饭；

+   2. 古人吃饭比我们今天品种要少很多，主要是小米、蔬菜和牛肉，一起煮着吃，辅料有酱、腌菜和酒。

+   3. 即、卿和既都体现了吃饭的礼仪；

+   4. 在汉代以前，一天吃两顿；

+   5. 在古代，普通的工作餐称为“饭”，正餐称为“食”，宴会称为“餐”。
