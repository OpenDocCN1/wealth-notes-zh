# 1. "地"的写法有很多

大地，是古人所有食品和生活用品的来源，怎样表现这广袤深厚的土地呢？

大地 的 字 形 有 好 几 种 ， 比 如 金 文 𡇷 、 𡇸 、 𡇹 （坠） ， 阜（fu） 𡆉 是山崖，下面有土 𡆉 ，合起来表示把动物扔下山崖，抛下的动物可能是犬 𡴤 ，也可能是豕（猪） 豕 ，这是古人祭祀土地仪式的写照。

还有一种写实的思路，䧏（zhou）文 𡈼 是山 𡈺 加水 𡈸 再加土 𡈷 ，形象地表示出大地是由山、水和土地构成的。

还有一种简单一点的写法 土𡆉 ，由水和土构成。

# 2. 地里育蛇

还有一种需要会意的写法， 𡆉 由土 𡆉 加上 也 构成， 也 是 示 "土地"，也（蛇）也是象征的。

《说文解字》：金文里， 和 𡆉 是 同一个字源，原意是指 ，引申为女性生殖的象征。

"土"加上"也"，组成 𡆉 ，引申出大地孕育万物，无私滋养的特性。

# 3. "土也"地的定形

篆文 𡆉 采用了 土 𡆉 加 也 𡆉 的字形，地这个字从此定型。

> 《说文解字》：

> 地，元气初分，轻清阳为天，重浊阴为地。万物所以陈列。从土，也声。

意思是说，地，宇宙间浑沌的元气初分之时，轻清的阳气上升为天，重浊的阴气下沉为地。地是万物陈列的所在。字形采用"土"作意旁，"也"是声符。

许慎的解读体现了中国古代的宇宙观，把世界分为阴阳，天为阳，地为阴，大地母亲滋养万物。

大地最终定型为"土也"，是和中国自古以来的生殖崇拜和农业社会安土重迁的特点分不开的。

有意思的是，武则天认为地这个字造的不妥，自己另造了一个 𡆉 ，思路其实和铭文 𡆉 一样，不知是受到古铭文的启发，还是精巧想到一块去了，无论这种哪种武则天思想，随着武则天退位，新字就自然废止了。

# 古代重祖重地 社：祖宗和土地

如果你到北京旅游，你可能会去天安门广场参观。过了金水桥，天安门门两侧有两个公园，左边是劳动人民文化宫，这是明清时期的太庙，大殿里原来供奉着皇家的祖宗牌位和画像。右边是中山公园，这是明清时期的社稷坛，俗称五色土，是明清时期祭祀土地的地方。这种格局，叫做左宗右社，自西周以来，任何朝代的皇城或者村社，都是这种格局，村子左边是祭祖的祠堂，右边是土地庙。

由此可见中国古代最重视的两件事：祖宗和土地。

![](bbox=[0.08, 0.0010500000000000002, 0.6, 0.0011])

祖与社都是封建政权的象征。社稷是"太社"和"太稷"的合称，社是土地神，稷是五谷神，两者是农业社会最重要的根基。

你来看汉字的 社 𡆉 ，是示字旁一个土字，示字旁祭台，敬奉土地，这是中国人对生养自己的大地母亲的敬畏和回报。
