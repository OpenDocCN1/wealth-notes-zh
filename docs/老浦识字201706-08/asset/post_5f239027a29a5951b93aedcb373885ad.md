
## 本周问答：“走”是走路还是跑步？

有一门不同于唱歌的声乐艺术，魏晋时期的阮籍、陶渊明都喜欢，你知道是哪个汉字吗？反映了主人公什么特点？

**老浦**：

这个字是“啸”，啸是一种发声方法，有人说是口啸，有人说是类似美声的气息控制发声，胸腔、颅腔甚至腹腔共鸣都用上了。

啸的发声虽然没有词，但也有丰富的内容。传说阮籍到山中访问一位隐居高人孙登，话不投机，阮籍长啸一声，起身就走。走到半山腰，传来了隐士孙登的一声长啸，犹如龙吟凤鸣，让阮籍叹服。可惜这样的声音，我们今天是听不到了。

我们今天听的音乐，绝大部分都是娱乐性的，无论是流行音乐还是古典音乐，那么今天还有用到礼仪性音乐的场合吗？如果有，可以举两个例子吗？

**老浦**：

和古代庙堂音乐近似的是国事活动中的礼仪音乐，如国歌、进行曲等。

哀乐和婚礼进行曲也是礼仪性的音乐，只在特定场合使用。

简化字的“声”取消了“聲”字的“耳”字旁，你还能找到同样被取消“耳”字旁，的另一个简化字吗？

**老浦**：

简化字的“听”同样取消了耳字旁，繁体字的“聽”不仅有耳字旁，其它的字符含义也很丰富；

德字符表示认真审视，用心体会，是听的正确姿势。

简化字的听是口字旁，变成“说”了，而且还有一个表示大斧子的“斤”，这是说你听的时候心里有把大斧子，随时准备批判反驳吗？

繁体字的“顯”由表示太阳的“日”、“丝线”以及表示人脸的“页”组成。

## 【听】不是简化字

1. “听”本是开口大笑的意思

听的繁体字——聽，笔画很多，在汉字简化的时候变成“听”，但是个听并不是完全造出来的，而是和丑（醜）一样，是借用了一个笔画较少的古体字。

但这个听在最早的时候，并不表示听觉。

听，篆文 [图片：听的古体写法] 是一个表示张嘴的口语 [图片：古体部件]，加上一个斤 [图片：古体部件]，斤的原意是斧头 [图片：古体部件]，在这里是欢快的“欣”的省略，合起来表示张大嘴巴开心地笑。读听（yǐn）。

《说文解字》说：

> 听，笑貌。

意思是：听（yǐn），是张口大笑的样子。

2. 开口大笑怎么变成听觉了

明朝的时候就有“听”的俗体字了。成书于明朝崇祯年间的《正字通》首次录入：“听，俗借为聽字省文。”

意思是，听是俗体字借用为“聽”的简体，这是最早的以“听”假“聽”的记载。

我们以前介绍过俗体字，是民间为了简省笔画而写的，比如“展院”的“展”写成尸字下面加一横，“树莫”的“葉”写成“叶”，都是这种情况。

这种俗体字通常是文化比较低的人手写的，所以也没有什么道理可讲。

## 【绝】是用绳子把色捆起来吗？

老编提示：订阅读主档后，文稿中的象形文字可戳可点，放大来看，细细品读。

### 识字卡片

![](img/6b2d826949bfddce96931988065f7fef_25_1.png)

甲骨文 → 金文 → 小篆 → 隶书 → 楷书

文字原意：...（图中有二维码和'老派说字' App 二维码）

### 1. “绝”的象形字

绝，是个极端的字，断子绝孙，这是多毒的诅咒。有种解读是：贪官一沾上色，就绝了。那用铁笼旁的绳子把色捆起来，就可以绝了错误吗？

甲骨文的 '絶' 是两缕丝线中间各加一条短横，表示将丝线割成两段。
金文 '絶' 则在两缕丝线之间加一把刀，明确表示用刀割断丝线。

### 2. 和“兹”有关的字

我们在谈母亲的「慈」时，曾经见过这两缕丝线，是“兹”，表示草木繁盛生长，引申出生殖繁衍，生生不息的意思。

由“兹”组成的字，很多都与生殖有关：
- 慈，是母亲的亲。
- 擎，是擎生、繁殖生长的意思。
- 滋，是滋生、滋养的意思，又引申出味道、滋味的意思。
- 缕，是连接、继承。你可以点击蓝色的句子去看「缕」的解读。

这些字都与繁衍有关，断斩丝线已经令人痛惜，而切断了繁衍和继承，就是断子绝孙了。

所以我覺得“絕”這個漢字是帶有強烈感情色彩的。

### 3. 以“色”为例，说汉字体分现象

你可能会说，这不对呀，这个“绝”更像是断绝的“斷”，怎么成了篆文绝？
这就是汉字体分的现象了。这两个字都来自金文 '斷'，是在金文基础上加上了一个表示斧头的斤，表示用斧头砍断物品。

而“绝”，是将两缕丝线规范成丝绞旁，加上刀，保留了“用刀割断”的原意，又加上一个形旁，扩大了义域，表示这样的割断是与人的遭遇有关。
需要注意的是，虽然“绝”的“色”的字形与颜色的“色”很接近，但它们是不一样的，“颜色”的“色”的上部是人形，而“绝”的右边的“色”是刀。

为什么不一样？这是因为，隶书的 '絶' 把篆文字形误写了。
所以，“绝”不是用丝线把色捆起来，而是用刀斩断丝线，引申为割断血缘继承。

### 4. 子不学，断机杼

《三字经》里有句话，你肯定听过：
> 昔孟母，择邻处。子不学，断机杼。

说的是孟母为了给孟子一个好的学习环境，多次搬家。

有一天，孟子逃学回家，孟母正在织布，她看见孟子就非常生气，拿起一把剪刀，把织布机上的布匹割断了。

孟子看得很困惑，问原因，孟母说：“你读书就像我织布一样，织布要一线一线地连成一寸，再连成一尺，再连成一丈，最后成一匹，织完后才是有用的东西。学问也必须累积历久，是十分辛苦劳动才得来的。你如果偷懒，不好好读书，半途而废，就像这被裁断的布匹一样变成了没有用的东西。”
孟母由此决绝的行为，告诉孟子一个道理：中途浪费这业，那以前的所有努力也就废了，绝了。

### 总结一下

- 1. 绝的甲骨文 '絶' 原意是用刀割断丝线，表示事物彻底中断；
- 2. 篆文的“色”细分为两个类型，一个是上面是表示斧头的“斤”，另一个是上面是“人”。到隶书，演化为今天的模样“绝”；
- 3. “兹”，意思是 [图片] 由丝线缕、草木茂盛生长，而引申为繁衍。

## 【德】应该以德报怨吗？

老潘提示：订阅读专栏，文稿中的象形文字可截图点开放大看，细细品读。

### 识字卡片

![](img/6b2d826949bfddce96931988065f7fef_26_1.png)

### 1. 德，本意是为正直

生活中，有些日常用语我们都会用，但是并不知道原意。比如骂人话“王八蛋”，原意是“忘八端”。什么是八端？按照儒家的解释：孝、悌、忠、信、礼、义、廉、耻，这是八端。

忘八端，说白了就是缺德。

甲骨文的“德”，是一个十字路口，中间有一个眼睛，眼睛上面有一条直线，这是曲直的直。合起来表示在大道上行走，目标坚定，绝不曲折犹豫。

有的甲骨文将十字路口“行”简化为双立人“彳”，意思不安。德的本意是行为正直，不偏歪门邪道。

### 2. 因为强调了心灵，德的分量越来越重

金文的字义发生了变化。金文的德在甲骨文眼睛上的一条直线加上了一点，写成 [图片]，强调这条直线是重点。有的金文加上了“心”，表明这不仅为心灵，更是心灵的修养。

因为强调了心灵，德的分量越来越重，德高望重、感恩戴德、功德圆满，甚至以德报怨。

### 3. “唾面自干”的典故和对“以德报怨”的误解

娄师德是武则天时期的宰相。他弟弟被任命为代州刺史，来向他辞行。娄师德嘱咐弟弟一定要低调。

他弟弟说：“放心，就算有人往俺脸上吐口水，俺擦了就算了。”

娄师德说：“那不行，你擦了，人家觉得你不厉害。让他吐你还是应该让那口吐沫自己干。”

这就是唾面自干的典故。这种以德报怨的态度，孔子其实是认同的。《论语宪问》里说：

> > 或曰：以德报怨，何如？
> 子曰：何以报德？以直报怨，以德报德。

学生问孔子：人家欺负我，我用道德感化他，如何？

孔子说：你用德来回报怨恨，那你可以用什么来回报有道德的人呢？正确的做法是，用正直来回报怨恨，用道德回报道德。正直行世，是甲骨文本色。

关于“以直报怨”的解读有不同版本，另有一说，说“直”是“等价”的意思，这一点在陈慧《断魂书院》中，《9.11：论语如何用到9.5》做梦梦到重大，能选花了几周时间非常详细地聊了孔子，推荐大家看看。

### 4. 东京审判与以德报怨

二战结束以后，由美、中、英、法、苏等11国指派的11名法官组成远东国际军事法庭，在日本东京，对第二次世界大战中日本主要甲级战犯进行了国际大审判，史称东京审判。

东条英机、广田弘毅、土肥原贤二、板垣征四郎、松井石根、武藤章、木村兵太郎等16人被判处无期徒刑，永户军判处20年徒刑，重光葵被判处7年徒刑。

7人于1948年12月23日在东京巢鸭监狱被执行死刑。东京审判从1946年5月3日开始，到1948年11月12日结束，前后持续两年多，共开庭818次，有419名证人出庭作证，受理证物4336件，英文判词录共48412页。整个判词判750万单词。从1948年11月4日起宣读长达1231页的判决书，到12日才读完。

![](img/6b2d826949bfddce96931988065f7fef_26_2.png)

这不是简单的复仇和传统意义上的要报恩，而是严格和国际法进行这些报复，对战争中犯罪进行公正、公开、严谨的审判，对恶人不姑息，也绝不意气用事。这就是我理解的以德报怨。

### 总结一下

- 1. 德的甲骨文原意是在大道上行走，目标坚定，绝不曲折犹豫，表示行为正直，不走歪门邪道；
- 2. 金文增加了心，表示这是心灵的修养；
- 3. 儒家总结了八德：孝、悌、忠、信、礼、义、廉、耻；
- 4. “唾面自干”来自于一个典故：娄师德嘱咐即将外地的弟弟不能擦唾，让别人往自己脸上吐口水，不能擦掉，让人自己干；
- 5. 今天“以德报怨”的用法是后人的断章取义，孔子的原意是以直报怨，二战的纽伦堡审判、东京审判都是这一原则的体现。

繁体字“聽”的含义非常丰富，让我仔细给你们说说。

![](img/6b2d826949bfddce96931988065f7fef_27_2.png)

甲骨文里的“听”，是一个“耳朵”“旁边有‘两个口’，表示用耳朵倾听不同的言论。有的甲骨简化为‘耳朵’边上加一个‘口’，表示倾听。

人类表达的欲望远高于倾听的欲望，我们在日常生活中经常会碰到各说各话、鸡同鸭讲的情况。

我做过凤凰卫视《一虎一死谈》的制片，这是一个辩论节目。这么多来，很少见到哪个真人认真对待对方的观点，更见不到被对方说服。

### 2. 学会倾听需要深厚的修养

![](img/6b2d826949bfddce96931988065f7fef_27_3.png)

这是汉字哑器的“聒”，一个表示‘人臉’的‘頁’，周围都是‘口’。满脸是口，哪里顾得上听。

金文的“聽”承继甲骨文字形。

![](img/6b2d826949bfddce96931988065f7fef_27_4.png)

有的金文在一口一耳下加了一个‘省’，这是‘省’的简写，省的意思是认真观察；又加册上一个‘王’，是‘玉’的简写，玉表示一个人站在高处。

所以，合起来都表示：听，要像站在土坡高处一样，保持客观心态，审视细微事物。

这时的古人已经意识到，听，不容易，要有深厚的修养。

### 3. 唐太宗之‘德’，体现在倾‘聽’上

李世民杀了太子以后，召见魏征质问道：‘你为什么要离间我们兄弟？’魏征说：‘皇太子如果听从我的话，必定没有现在的灾祸。’意思是：能不能听从善言，关系到政权的存亡。

太宗听得很震动，对他厚加礼遇，擢升他为谏议大夫，多次让他进宫请为政之道。

贞观六年，唐太宗在九成宫，宴请近臣。长孙无忌说：‘王珪（gui）和魏微从前侍奉太子，我见了他们好像见了仇人，没想到现在在宴会上。’太宗说：‘魏微从前确实是我的仇人，但我尽为他心，应当宽恕。魏微常常犯颜直谏，不容许我做错事，这就是我敬他的原因。’

魏微拜了两拜说：‘陛下引导我让我说话，我才敢直谏。如果陛下不采纳我的直言，我又怎么敢冒犯龙颜、触怒圣听呢？’

贞观七年，魏微生病，请求辞职，太宗说：‘你见我的过错，有不说的时候吗？金经过匠人的反复锤炼才成宝器，被人珍视。我自已比金，把你当做良臣。你虽然有病，还不衰老，怎能让你就这样辞职呢？’魏微是不辞职。

唐太宗的伟大就在于他会听，他能够超越原来的仇恨任人唯贤，这是听字中‘玉’，象征站的高处；自比金子，把大臣的建议比作是锤炼金子的铁锤，这是听字中‘省’，用于深刻反省。

篆文‘聽’省略了‘口’，加上‘德’，更加明确了倾听是重要的品德。唐太宗之德，正是体现在他的‘聽’上。

### 总结一下

- 1. 听的原音是用耳朵听不同的言论；
- 2. 人们越来越多意识到能够认真倾听不容易，就在金文中加了表示认真省察的‘省’和表示站在高处的‘王’，引申为倾听要有客观的高度和认真的态度；
- 3. 篆文‘聽’换成‘耳子旁’加一个‘德’，强调倾听是一个人的重要品德；
- 4. 唐太宗与魏征君臣的古美谈，正是他依赖唐太宗的德。
