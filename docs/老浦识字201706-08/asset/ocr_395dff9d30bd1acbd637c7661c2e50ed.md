# 129 【西】为什么物品叫东西不叫南北

“我去买点东西”，这是日常生活常用的词语，但为什么叫“东西”不叫“南北”呢？

之前我们已经讲过北、南、东这些方向字的来历了，今天先来看一下“西”，再来研究“东西”。

# 1. 西的原意是鸟巢

西的甲骨文是鸟巢的形状，你可以从上图中看到这个字形的演变。

> 《说文解字》：
西，鸟在巢上。象形。日在西方而鸟栖，故因以为东西之西。

《说文解字》说西是鸟在巢上，这是根据文字字形 来说的。许慎把 形认作是鸟，这显然和甲骨文原意不符。但他的解释很准确，说日在西方的时候，飞鸟归巢而栖。

“或许明日太阳西下倦鸟已归时，你将已经踏上明日的旅途。”罗大佑的歌词很好地解释了“西”的来历，太阳落山，正是飞鸟归巢之时。所以鸟巢就被借用做太阳落山的方向：西。

陶渊明著名的诗句：
采菊东篱下，悠然见南山。
山气日夕佳，飞鸟相与还。
此中有真意，欲辨已忘言。

说我东边的篱笆下采菊，抬头悠然眺望南山。山间因霞气缭绕，暮鸦都结伴归巢。此刻，鸟儿从山西飞来，鸣叫着相伴归来。这样的情景是有着人生真谛的，只是我已经忘记怎样向你解说说明了。

西的原意是鸟巢，被借用为表示方位的字。原意另造“棲”代替。

# 2. 为什么是“东西”

为什么表示物品叫东西呢？
有人说你产于四方，故称东西。这不通，既然是产于四方，为什么不说“南北”呢。

还有人说，东汉时，商人大都集中在东京洛阳和西安长安，俗话说“买东”或“西”，即“东西”指代“东和西安”的产物。还有，唐时，长安有严格的区分，只有东市和西市可以购物，所以“东西”成为货物的代称。

这些说法都没有说服北宋大学者朱熹。朱老先生有一天在路上碰见他的朋友盛温如提着篮子上街。
朱熹问：你上哪儿？
盛温如回答：上街买东西。
朱熹又问：难道不能买南北？

“盛温如回答：当然不能。东方属木，西方属金，凡属金木类，篮子装得了；南方属火，北方属水，水火灾之类篮子是装不得的，所以只能‘买东西’，不能买‘南北’。”

意思是按照阴阳五行，金木水火土，金代表金属矿广和树木类。木代表一切植物，方位在东。金类和木头都是物质，当然可以购买。而方位在北的水类和南方火类，不是具体的物体，自然没法购买了。

这事放在今天当然解释不通了，水要交水费，火要交煤气费，都得购买。

# — 总结 —

+   1. 西的原意是鸟巢 ，由于鸟儿归巢正是太阳西下之时，所以古人将鸟巢借用做方位字：西。
2. 原意另造“棲”代替。
3. 我们称物品为东西而不叫南北，是古人按照阴阳五行总结出来的，东方属木，西方属金，金木类都是可以购买的物质，故称东西。而方位在北的水类和南方火类，不是具体的物体，自然没法购买了。
