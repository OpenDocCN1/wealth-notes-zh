# 3.酱的种类自古就很多

最早的内酱也叫醢(hǎi)，是由肉做成的，其加工方法，是将新鲜的好肉研碎，用酿酒用的曲和盐拌匀，再倒进酒里去，装进容器，容器用泥封口，放在太阳下晒，百日以后才可以食用。

作为王公贵族专享的奢侈品，《周礼》中记载了不同的肉酱：鹿肉酱、鹿肉酱、獾肉酱、田螺肉酱、蛤蜊肉酱、唇蛤肉酱、兔肉酱、鹿肉酱等等，不同的酱搭配不同的主食；雕胡米饭和野菜羹配螺肉酱，干肉粥配兔肉酱，熟糜肉片配鱼肉酱，吃鱼片配河豚。

这么讲究，难怪孔子“割不正不食，不得其酱不食。”

宫廷中甚至有专门管酱醋的人，叫“酱人”，和“酒人”、“浆人”一样，都是后勤部门的重要官员。

进入西汉以后，出现了豆酱。马王堆一号墓就发现了豆酱。

有了豆酱，有蚁就也有了酱油。东汉时称为清酱，是酱油上面澄清的一层液体，到宋代，才叫酱油。

酯(yǐ)，这是一种加上糯米稀饭的略带酸咸味的食品，是古代长江流域的美食，传入日本，成为今天的寿司。

# 总结如下

酱的“酉”字表明最早的酱是酒酿的碎肉，盛放在三大鼎里，是贵族专享的奢侈品；

后来有了带“卤”的字样，表明用盐腌制作肉酱；

肉酱有很多种，不同的食品配不同的肉酱，孔子对酱很讲究，酱搭配不对就不吃；

进入西汉以后有了豆酱，酱和酱油从此进入寻常百姓的厨房，并传播到朝鲜、日本、东南亚，成为亚洲共同的美食传统。
