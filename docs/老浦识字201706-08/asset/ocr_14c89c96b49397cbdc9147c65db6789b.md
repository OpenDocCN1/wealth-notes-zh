# 1. 为什么“逋”不能写成“遥”

大多数人会把胡逋，写作胡遥，因为“遥”是“逋”的简体字嘛。至于胡逋本人签名的写法或许是有些人随意写胡逋的字，大概以写送仅仅是繁体字和简体字的区别。其实，把胡逋写成胡遥是错的。

先说胡逋的逋，全文是“逋”，上面一个“帝”下面加一个“口”。

帝是捆扎整齐的柴束，以前我们的“柴”在讨论“柴”的时候了解到柴，柴的原意就是用木柴条把天上，而“帝”就是柴天上的具体样式，由此引申为天神。由于把柴束又捆紧，就有了编织、扎束的含义。

帝加上口为音（chi），口是祭祀祀鬼之，合起来表示有资格读祭口、祭祀上天的人，作为帝的子孙，有资格祭祀帝，就是适合，进而引申出前往的意思。

有的金文加上表示前行的走之“辶”，前往的意思更加明确。

文言版《说文解字》：

> 逋，之也。

“之”是前往的意思。

> 《诗 · 魏风 · 硕鼠》：

> 逝将去女，适彼乐国。

意思是：我发誓离开你，前往安乐的地方。就用走的这个意思。

篆文沿袭了金文的写法。隶书将篆文的“走”写成走之，逋的原意是来源于帝，所以这个字形构成的汉字，都有帝的影子。

嫡（dí），嫡系，是“帝”的血系。正妻也叫嫡，正妻生的儿子就叫嫡子。

镝（dí），锋镝，是“帝”的弓矢。

谏（zhè），坟谯，是“帝”的责罚。
