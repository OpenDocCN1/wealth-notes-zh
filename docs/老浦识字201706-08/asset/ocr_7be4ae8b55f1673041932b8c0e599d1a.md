# 【柴】本来是用来敬神的

柴是家庭最低值的易耗品，缺不了，也不值钱。但是在古代，柴可不简单，那曾经是很神圣的物品。

# 1.柴字的含义

篆文柴，上面一个此，下面一个木。“此”的甲骨文，旁边一个字，合起来表示人站立的地方。有的甲骨文的“此”，把人字 放在脚趾，上面，站立地点的意思更加明确。

柴还有一个异体字，柴，“此”字下面一个“示”，示的原意是供奉，凡示字旁都与祭祀有关，可见柴的原意是用于祭祀的木头。

> 《说文解字》中说：“柴，烧柴燎祭天也。”

# 2.惨烈的柴燎

古代柴燎祭天叫柴祭，《东汉笺记·丁鸿传》：

> “瞻灵山，嘉祥降割：柴祭之日，白气上升，与柴烟合，氛箭辈举。”

这是说皇帝到柴祭天，柴祭上升的白烟与柴熏一起缭绕，预示着吉祥如德。

这是帝祭的祭天，宣示皇帝的君权神授。但在更加远古的商代，这是祭天祈雨的惨烈之举。之所以说惨烈，是因为这种柴燎仪式是要用活人祭祀，活人的级别越高，表示祭祀之心越虔诚。

夏朝末年，天上大旱，商代的开国君王汤，发动的汤武革命，推翻了夏朝的残暴统治，但是引发夏朝危机的天下大旱已经持续了七年，仍然没有下雨的迹象。巫师说，要用活人来祭才能感动上帝。

商汤决定以自己能出这样的牺牲。请允许我用一段潘先生先生在《青铜时代》中对这一场景的描述：“于是商汤把自己泡在水里，散发，断甲。商汤素车、白马、身披白茅，彤光外发，站在台子上，和其他牛羊杂品祭成一排，伴着牛羊的叫声，被一齐抬到了宗庙的祭坛上，周围架起了柴束，为了方便上帝品尝，人们给商汤肚子上放了一盘肝片。”

这当然是潘水先生根据史料的想象，但是当时用柴燎祈雨确实是历史真实发生过的。据说商汤的做法感动了上帝，天降大雨，商汤也没被烧死，但是后患，随着王权的强大，被烧死的就是王或者俘虏，而不是巫师本人了。

# 3.跟柴有关的汉字

这是甲骨文，一个人交叉着双腿，在火上被活活烧死，这就是柴燎祈雨的写照。

到春秋战国时期，汉字进一步细分，从山上采集、作为居家燃料的干柴叫“橚”；

从山上采伐、未锯断、劈细的原木叫“薪”；

由原木劈成细块，作为居家燃料的木料叫“柴”。

薪的本意就是柴火，在庭院中点火照明，一个将终，马上点燃另一个，叫薪火相传。后世用这个成语形容事业代代相传。

# 总结一下

+   柴最早是用于祭祀的柴火；

+   隆重的祭祀仪式是要用活人作牺牲的；

+   “薪”的本意是柴火，由于砍柴汲水是日常用度，后来就把工资称为薪水。
