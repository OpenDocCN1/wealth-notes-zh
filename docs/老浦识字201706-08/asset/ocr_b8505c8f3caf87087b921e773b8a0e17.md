# 【户】不是死人

> 【户】不是死人

# 1. 户的原意是活人坐着接受祭祀

尸体怎么会不是死人呢？

甲骨文的户 像一个坐着的人。其角色是角色扮演，在祭坛上装着死去的亲人，接受祭祀。

夏商周三代的祭祀，要用活人扮演逝去的亡灵，此人双手抚膝，正襟危坐，一动不动。而祭祀的食品，他也象征性地吃一点，这样的角色就叫“户”。

那谁来扮演死去的人呢？一般是死者的下属和晚辈。

《仪礼·士虞礼》注：

> 户，主也。孝子之祭不见亲之形，哀心无所系，立户而主意焉。

说户是被祭祀的主人，孝子祭祀的时候要看不见亲来人的形象，哀心无所系，所以设立一个户来代为代表。

这段话说明了古人为何要弄一个活人坐在那儿坐着接受祭祀的原因。

# 2. 户的演变

+   - 金文的户 承继了甲骨文字形；
- 篆文 户 手写变化，下部消尖；
- 楷书 户 写成“封口”字，下部完全消失。

由于户舒舒服服坐在那儿接受祭拜并且吃吃喝喝，人们就把那个位置叫什么也吃不消的称为“户位”；不干事的官员叫“户官”。

汉人王充在《论衡·量知》中痛斥一些人：

> 无道德之学，不晓政治。默坐朝廷，不能言事，与户无异。

# 3. 户字延伸出来的字

了解了“户”的原意，就不难理解由“户”延伸出来的字的含义了，这些字都与“户”这种坐姿的形态有关：

+   - 尻 kāo ：九为多、为大，所以这个手指屁股；
- 尾 ，祭祀舞蹈的人装饰着尾巴；
- 屎 ，人屈身排泄；
- 尿 ，同样是屈身排泄。

# 4. 怎样变成了死人

汉字表现死人的字是“屍 shì”。终，也。从尸，从死。

这原本是两个字，简化汉字因为省笔，把“户”和“屍”合并成为“尸”。活人被打死了。

# 5. 越短代庖的含义

有意思的是，如果你不了解“尸”的原意，对于成语“越短代庖”就不可能理解。我们都知道了，越短代庖意思是超出自己业务范围去管不属于自己事。

越，走远跳越；短 zǔ，是祭祀的礼器；庖，是厨师。

这个典故出自《庄子·逍遥游》：

> “短虽不冶庖，尸祝不越祝短而代。”

+   - 户：装扮祖先的人；
- 祝：主持祭拜仪式的人；
- 短：厨师；
- 祝：放在祭台前的祭祀礼器。

这是说，在祭祀的时候，户坐在那里装扮祖先不动，拜完了大家去吃饭，但是厨师忙不过来，这时候户和祝反正没事，就跳起短代的礼器来帮忙，做厨子该做的事，叫做“越短代庖”。

庄子的意思是，就算户待在那里没事做，也不能越短代庖，不然仪式的神圣感就荡然无存了。

# — 总结一下 —

+   1. 户的原意是活人扮演逝去的祖先接受祭祀 ；
2. 因为这种工作占着位置什么也不干，就有“户位”、“户官”这些贬义词；
3. 户特殊的姿势，延伸出一些屈身姿势的汉字，如尻、尾、屎、尿；
4. 死去的人是另一个字：屍。简化字合成了笔画简单的“户”；
5. 成语“越短代庖”就来自活人扮演死者的祭祀仪式，扮演逝者的人看厨师忙不过来，跨过祭祀的礼器下来帮忙，做不该自己做的事，这叫越短代庖。
