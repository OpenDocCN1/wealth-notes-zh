我们先来看看甲骨文的

![](bbox=[0.68, 0.225, 0.82, 0.285])

，就是一个羊头，和牛头的字形原是一样的，只不过牛角是上翘的，而羊角是向下弯曲的。

+   1.羊是祭品，代表吉祥

在中国，羊是祭品。

牛祭被称为太牢，羊祭是少牢。

《说文解字》解释：

> “羊，祥也”

我们知道“示”的原意是祭台，所有示字旁的字都与祭祀有关。用羊祭祀，祈求吉祥。

这是金文

![](bbox=[0.36, 0.495, 0.55, 0.54])

的羊，更加突出了弯曲的羊角，更加具有装饰性。让人看起来一派祥和。

加水是“洋”，是烟花、太平的大海。

加火是“烊”，是熄灭为安。打烊，指关门熄灯。

加气是“氧”，是空气中令人呼吸顺畅安宁的气体。

加言是“详”，是在祭祀时赞美神迹。

加行是“徉”，是步态安详。徜徉（cháng yáng），就是神游从容自在，步态高逸安详。

加飞是“翔”，是展翅长空，顺风顺水。

加鱼是“鲜”，是人间美味。

+   2.国宝四羊方尊的身世

![](bbox=[0.18, 0.815, 0.82, 0.9])

1938年4月的一个上午，湖南省宁乡县黄材镇转耳仑山上，姜家兄弟三人挖到了一件宝贝。

这就是国宝四羊方尊，是商代用于祭祀的青铜重器。

古董商计划20万大洋倒卖出去。

当时的长沙县政府为了防止国宝流失，收缴了这件文物。
