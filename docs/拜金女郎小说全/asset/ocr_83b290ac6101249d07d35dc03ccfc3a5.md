# 第四卷 刘逸文

（十一）机场

冷夜辉觉得今天所有的一切，都不在预定的轨道上。

她刚到机场，下了汽车，就有一个穿着恭僮土著服装的少女迎了上来。“刷我地卡，姑娘你福象饱满，面泛桃花，今天一定有人用 9999 朵玫瑰向你求婚哦”。

冷夜辉楞了一下，然后就被一堆人拥簇着进了航空公司。

在贵宾厅里，一个皮肤黝黑的胖子，据说是他们的营运总监。非得一口咬定，冷夜辉有 5000000 航空里程没有补登。哭死哭活一定要帮她补登记上去。

冷夜辉觉得又好气又好笑，费尽了口舌解释。可对方双手比划，用尽蹩脚的英文，将耶稣佛陀圣母玛丽亚都举出来了，就说她是他们的 VVVVIP 客户。

机场外面的大厅传来一阵喧嚣。“轰然”她一下，似乎整个大厅都爆炸开来了。冷夜辉侧耳听去，隐隐约约听见机场广播：“尊敬的寰宇一家会员，您乘坐的……航班，由于 Overbooking，现征求自愿退票者。如果 2 小时的下一班，经济舱补贴退票费 2 万元，头等舱补贴退票费 20 万元……”

然后她就听见外面哗啦啦地传来排山倒海般的脚步声。一群花子蜂拥地跑了过去，海啸般的人群几乎把整到的办票窗口都压塌掉。花子们尖叫着“我要，我要，赚翻了”。比整个旅行团的团费还要多。

冷夜辉摇了摇头，觉得今天的一切都凝聚得不真实。

眼看起飞时间临近，冷夜辉实在拗不过这个胖子。只得让他办了一张贵宾卡。一群人恭恭敬敬地送到了门口。胖子和小妹们排成一列，低眉含什礼仪说：“姑娘你福象饱满，面泛桃花，今天一定有人用 9999 朵玫瑰向你求婚哦”。

冷夜辉到达机场的时间很早，可是现在却几乎最后一位登机。胖子让专车送她直接影响到跑道上，冷夜辉登上机舱，飞机过一会就匆忙忙飞翘了。
