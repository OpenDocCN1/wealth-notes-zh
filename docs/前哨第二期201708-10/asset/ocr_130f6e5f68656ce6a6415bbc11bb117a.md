在周一的节目里我们说过，Editas Therapeutic 是由 CRISPR-Cas9 的主要发明之一的张峰参与创办的。张峰是一位非常了不起的80后华人科学家，他在发明改造 CRISPR-Cas9 技术之前，就已经做了很有影响力的工作，主要体现在科研和产业两个方面。

# 一、张峰的科研成就

在他还是 一年级博士生的时候，他就跟从导师 Karl Deisseroth，提高了一种感光蛋白在细胞里的表达，改善了光遗传的神经刺激技术，之后还成功应用在神经可塑性等的研究中。2010年光遗传技术被《自然》杂志评为年度新技术，目前它是神经科学研究中的一把利器。

之后张峰一直致力于新的基因编辑技术的发展，包括 TALEN、CRISPR-Cas9。

CRISPR-Cas9 之后，他依旧马不停蹄，2015年他又发掘出了比 CRISPR-Cas9 更小更精准的 CRISPR-Cpf1 系统，并且成功地把 CRISPR 应用在多种致病基因筛查和药物靶点筛查当中。

# 二、张峰创立Editas公司

延续了他科研上一贯的敏锐和高效，2013年张峰在技术发表之后，很快就成立了专注基因治疗的 Editas Therapeutic 公司。公司成立之初就获得了4300万美元的融资，2016年公司又成功上市。

与此同时，张峰加急申请了专利，他所在的 Broad 研究所拿到美国专利权后，也将专利的商业应用优先授权给了 Edit as 公司，Edit as 公司在其业务范围内具有专利的独家授权，其他公司的申请得先经过 Edit as 审批，只有 Edit as 不感兴趣的领域才有可能获得授权。

2015年张峰发掘了 CRISPR-Cpf1 系统之后，Broad 也获得了相关的美国专利权，而且不出意外，应该也会优先授权给 Edit as。

当然除了张峰，Edit as 的另外几位创始科学家 George Church、Jennifer Doudna、Keith Joung 以及 David Liu 也都是牛人。在明星创始人团队和众多专利技术的加持之下，Edit as 可以说是基因治疗领域的领跑者，也是了解行业的代表案例。

周一我们说过，针对人体的基因治疗领域与非基因治疗领域的产业特点大不相同。今天我们就通过 Edit as 看看基因治疗领域面临的挑战，以及生物医药行业的一些产业特点。

# 三、Editas的主要业务情况

Edit as 目前主要的研究方向有7个，每个方向针对一种疾病，涉及到眼、肺、肝、血液、肌肉等器官，具体包括了癌症、囊肿性纤维化、莱伯先天性黑内障等疾病。

除癌症以外的其他疾病都是基因突变比较明确、突变的位置较少的遗传病。它们严重影响患者的生活质量和存活寿命。而且其中一些疾病还是常见的遗传病，但目前却没有有效的治疗手段。

在这些研发项目中，针对癌症的治疗研究中，大名鼎鼎的 CAR-T疗法是 Edit as 与诺华合作进行的，我们将在后面的癌症免疫治疗中给大 家作详细介绍。

不过，诺华也不是仅仅和 Edit as 一家合作，今年8月30日有一个重大喜讯，FDA 专 家以10：0的投票，通过了诺华公司的 CAR-T 治疗，Kymriah 上市，用于难治性或复发至少两次的 B 细胞前体急性淋巴细胞白血病的儿童和年轻成人患者。

这一产品是诺华和宾州大学合作的结果，不是和 Edit as，因为合作从2012年就开始了，那时候 Edit as 还没成立。

目前 Edit as 所有的项目都还在研发阶段，不过他们最早开始研发的莱伯先天性黑内障，有望在今年进入临床试验期。如果能按计划实现，这将会是运用 CRISPR 编辑技术的首个临床试验。

不难看出，这些针对发病率高、危害严重又没有有效治疗手段的疾病所提出的新疗法将给患者带来福音，同时其中还隐藏着巨大的商业价值。A轮融资之后，Edit as 又获得了包括比尔·盖茨、Google 等在内的上亿美金的投资。

# 四、生物医药创业领域的行业特点

今天一开始我们就说到，Edit as 公司2013年成立，2016年就上市了。

既然这家公司技术前景大好，又得到了广泛的认可和投资，为什么它要急早早上市呢？

其实，早上市是生物医药创业领域的一个特点。

这点和 IT 创业领域大不相同。在 IT 创业领域，一些被看好的有潜力的公司往往会推迟上市，尽可能地把价值上涨的红利包含在 IPO 之前的阶段，这样就能让早期进入的风险投资者获得最大化的利益。相对的，IPO 之后普通投资者能够分享到的上涨空间就小得多了。

但是生物医药公司恰恰相反，它们总是在公司成立早期，还没有任何产品，甚至没有进入临床试验的时候，就已经上市了。这是因为生物医药研发往往非常昂贵，耗时很久的临床实验更是会轻易烧掉5到10亿美金，所以生物医药初创企业总是选择早早上市融资。

这恰好给我们普通投资者提供了一个可以早期进入，分享红利的机会。一旦公司获得专利，或者研发和临床试验获得阶段性成功，股价就会有一个陡峭的上升曲线。

当然高收益常常伴随着高风险：

+   首先，生物医药公司的研发周期可能很长；
其次，取 得了阶段性成果之后仍然有可能会在最后一步试验失败，或者被 FDA 的审批拒绝。

后面我们要讲的癌症免疫治疗领域的 Provenge 公司就是一个活生生的例子。因此就算早期进入，你的投资还是有可能长期得不到回报，甚至遭受损失。这也是我们接下来要谈的话题。
