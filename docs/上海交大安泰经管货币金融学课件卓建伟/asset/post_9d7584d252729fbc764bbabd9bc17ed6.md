## 均衡变动：总供给（通货膨胀）冲击

- 总供给曲线的移动可能是由暂时性的供给（通货膨胀）冲击造成的，这种情况下长期总供给曲线不移动，也可能是由持久性的供给冲击造成的，这种情况下长期总供给曲线会发生移动。

## Changes in Equilibrium: Aggregate Supply (Price) Shocks

- 暂时性的供给冲击：
  - 当暂时性的冲击涉及供应的限制时，我们将这种类型的供应冲击称为负面（或不利）供应冲击，导致商品价格上涨。
  - 暂时的正面供给冲击将短期总供给曲线向下和向右转移，导致最初的通货膨胀率下降，产出增加。然而，从长远来看，产出和通货膨胀将保持不变（持有总需求曲线常数）。

## 永久性供应冲击与真实经济周期理论

- 永久性的负面供应冲击--例如增加不明智的监管，使经济效率降低，从而减少供应--将减少潜在产出，并将长期的总供给曲线左移。
- 由于永久性供应冲击将导致更高的价格，将有短期上升的通货膨胀，因此短期的总供给曲线将会转移到左边。

## 永久性供应冲击与真实经济周期理论

- 以爱德华. 普雷斯科特为代表的一批经济学家认为，经济周期的波动是由长期供应冲击造成的，他们的总体经济波动理论被称为真实经济周期理论。

## 总结

- 总需求和供应分析可以得出如下结论：
  1. 总需求曲线的变化只在短期内影响产出，并且在长期内不会对总产出产生任何影响。
  2. 暂时性的供应冲击只在短期内影响产出和通货膨胀，从长远来看没有影响（总需求曲线保持不变）。
  3. 长期供应冲击会影响短期和长期的产出和通货膨胀。
  4. 经济有一个自我修正的机制，可以将其恢复到潜在产出和随时间推移的自然失业率。
