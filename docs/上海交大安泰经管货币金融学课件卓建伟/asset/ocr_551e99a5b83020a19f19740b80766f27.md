|   | 资产 | 负债 |
|---|---|---|
| 准备金 | 2000万 | 存款 | 1亿 |
| 贷款 | 8000万 | 银行资本 | 1000万 |
| 证券 | 1000万 |  |  |

|   | 资产 | 负债 |
|---|---|---|
| 准备金 | 1000万 | 存款 | 9000万 |
| 贷款 | 8000万 | 银行资本 | 1000万 |
| 证券 | 1000万 |  |  |

+   - 假设银行的法定准备金率为10%
+   - 只要银行拥有足够的超额准备金，存款外流就不会迫使银行调整其资产负债表的其他部分
