# 群策群力

我每天的工作，從早上6時5分開始。友人摩爾（Jeff Moore）開紳寶汽車從麻博罕過來，順道送我進城。他老婆芭比（Bobbie）在前座，我在後座，夫婦倆都是放射線科醫師。

因為天色還不亮，芭比在前座點著小燈看X光片，我在後座也有一盞小燈來看年報及圖表，還好我這些資料從不曾和芭比的病歷資料搞混。在車上我們不常說話，大夥各忙各的。
