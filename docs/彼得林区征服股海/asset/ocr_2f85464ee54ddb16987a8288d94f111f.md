# 冰河銀行公司

我是在聖誕節隔天打電話給冰河銀行公司，那天我穿著休閒的花格子長褲及運動衫到波士頓的辦公室。整個大樓似乎除了我和安全人員外，別無他人。

假日最適合加這種班。如果發現上市公司主管連12月26日也來上班，能不感動嗎？

在堆積如山的辦公桌翻尋一陣後，我找出冰河銀行的檔案。當時冰河銀行股價12美元，比一年前上漲60%。盈餘每年成長12%到15%，股價本益比十倍，不特別吸引人，但風險也不大。
