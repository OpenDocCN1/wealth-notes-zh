比通常人们习惯的浸泡洗好，实验证明时间浸泡会降低洗净度，浸泡时间越长，污垢越难疏掉。原因是长时间浸泡后，污垢带进一少座入纤维中而难以洗净。

7. 集中预洗、洗净、清除。一时间洗涤量超过2公斤干衣，用集中洗涤法可达到省水、省电、省时间、省洗涤剂的效果。即用一桶清水可预洗多批衣物，把受难衣物预洗干净，再同样以一桶洗衣粉水溶液连续洗那几批衣物，发现洗涤液浓度下降（泡沫太少时），适当添加一些洗衣粉，直至全部洗净，再拧上清水，延一分钟消毒。

8. 特别脏处用手工预洗；对衣物上局部极脏的部位，如，衣领、袖口、膝盖、被头等处， prior用肥皂进行手工搓洗后，再放入洗衣机里洗涤，以免除不必要的延长洗涤时间，并确保衣物洗净度的均匀性。

# 使用洗衣机时应注意的几个问题

+   1. 温度。洗衣时一般用水自来水、井水、河水，也可用温水。严禁用于高于60℃的热水，以免塑料件过热变形、损坏。

+   2. 洗衣物直接加入清水中，将洗衣物放在溶解的水中均匀散开时，再逐渐投入洗衣粉。注意在衣物桶内没有足够浓的情况下，不能用热水直接在桶中溶解衣物粉。

+   3. 洗衣前，应把衣物口袋的钥匙、小刀、硬币及铁等杂物清理干净。

+   4. 洗带有细长布带、缎绳物时，如：带绕线的围巾、口袋、口罩、坐垫、背带裤等，最好能把绕线两端互相扣上。洗毛绒时，要装在纱布袋内进行洗涤，以免绕线、毛绒缠绕在波轮轴上，影响洗涤的正常运行。

+   5. 在寒冷冬季，不宜在零度以下的环境中使用，更不能把水存贮在洗衣桶内，以免冻坏损伤部件。

+   6. 洗衣机的滚动轴承用润滑轴承结构时，应在半年至一年内按说明书要求，在滚动轴承处加注润滑油（20号机油或缝纫机油），可减少噪音，延长使用寿命。
