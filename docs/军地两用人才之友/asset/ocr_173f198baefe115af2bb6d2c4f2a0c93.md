# 合理施肥

合理施肥，充分发挥肥料的增产作用，是实现高产、稳产、低成本的一个重要措施。
一、合理配施、互补促进 有机肥料和化肥配合，氮、磷配合，是合理施肥的重要原则。有机肥料营养齐全，肥效慢；化肥肥力见效快，特别是化学肥料中含有大量的有机质，微量生物作用，形成腐殖酸，能改变土壤结构，使其疏松绵软、透气良好，这不仅有利于作物根系生长发育，而且有助于提高土壤保水、保肥能力。化肥可以供给微生物活动最需要的速效养分，加速微生物繁殖和活动，促进有机肥料分解，释放出大量的二氧化碳和其他养分，这就利于土壤中难溶性养分的分解。因此有机肥料和化肥配合使用，能取长补短，互相调剂，充分发挥这两种肥料的作用。
