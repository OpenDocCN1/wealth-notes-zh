设有自动切断电源装置的液晶显示计算器具有节省用电的优点。有些计算器的键盘上标出“AUTOPOWEROFF”，表示能自动切断电源。在拔通电源后，如果没有操作或工作中暂停，大约 6～10 分钟后（取决于环境温度、电池电压等），电源将自动切断，显示全部消失，当需要重新使用，只要按一下电源键（标有“ON”记号），显示屏重新显示“0。”。只有计算器在自动切断电源后，能保留存储器里的数据，当再次通电后仍可读出该存储数据。
一般而言，同样型计算器在相同累计时间的使用条件下，荧光显示要比液晶显示耗电大约500倍以上。

# 使用与维护

电子计算器是一种较精致的微型电子装置，结构简单，性能可靠。操作按键盘了键，错误确定了状态选择器的位置、按键太轻或重或反复键，都会产生错误的结果。如果使用不当或能损坏不良，可能发生故障。因此，为了长期保持计算器的优良性能，使用时应注意：

+   1. 人们习惯于将机放桌上或左手握机，用右手手指按中操做：为了方便于操作键容易，按计算键等，建议用左手操作。计算器放在桌上，要平稳放好，不要晃动，如果用手握机，不受影响。
2. 按键时手指垂直向下，用力轻快，准确无误，尤其使用键盘较小的情况，避免手指按错而触及邻边的键，造成错误输入。如果按错键，应会立即见异和拂掉。
3. 在使用没有状态选择器或有状态选择键的计算器时，要根据算式的要先正确地选择计算器的工作状态，然后才能进行运算，否则将产生错误的计算结果。
4. 操作时要按键和显示屏，确认输入是否正确。在计算器正常工作情况时，确实输入一个数后，显示屏立刻显示出该数，按下一个键时，显示屏上的数字会同时一闪或显示中间结果，在进行运算操作，常显示完毕，指示结束，反而再显示计结果时，显示屏显示出相应的运算符号。因此，操作时须观察显示屏，有助于了解运算情况。
