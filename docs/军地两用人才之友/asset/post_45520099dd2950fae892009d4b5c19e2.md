
# 保证当年产的培植

- （一）坚持保留表土。这是保证当年能高增产的关键。
- （二）早夏墒播水，保留墒情，为适时播种，达到苗全、苗壮创造条件。
- （三）深耕细作，打碎土块。
- （四）重施有机肥，巧施速效肥。应重施有机肥（人粪尿最好）和露肥，挖坑部位的施肥量应为垄方部位的 2 倍。改良通施肥为集中施配，氮、磷配作复合肥。追肥应轻方多施，填方少施。
- （五）选种耐寒性，加强田间管理。

# 土壤的培植

高产土壤的特点：（一）因地制宜，农田基本建设好，土地平整，适宜机械化作业；灌溉设施完备，早修除收。（二）疏松耕层，土壤渗性好，黏性适宜，结构良好，颗粒细实，易耕易种，宜耕期较长，整地效果高，苗好壮。（三）养分充足，作物吸收能力强；土壤有机质含量丰富，代养肥量、速效养分多。在作物生长过程中，不脱肥，不早衰。（四）通水层厚，水平条件好；养分层厚肥满，通气透水性能好，土比较紧实，抗旱防涝能力高。

高产土壤的培备条件：依据农田基本建设，改善农业生产条件，这是培育高产土壤的基础。应根据本地地区具体特点，做到以改土、治水为中心，山水田林路综合治理。山地、丘陵区农田基本建设重点应以水土保持为中心。改变地形地势，改建农田水利，山地水肥利和绿化。平川地区主要是整土地和深翻，改良土壤、合理灌溉，实现园田化。

土壤培肥措施：1.轮作茬作，用养结合，“互口倒顺，好比上美”。实践证明轮作倒茬，是用养结合，培养土壤的最有效途径。因为不同作物需肥的差异，根据以根系分泌物，对土壤中微生物的供给和分解的影响不同，不同样根系的根系微生物，对象养分、水分的需要不同，其根系深度、利用养分、水分的层次也各差异。实行轮作，能起到相辅相成，协调土壤养分的效果。特别是粮肥、棉花配作、间套，在用地同时又养地利，对土壤肥力培育有重要的作用。

2. 深翻改土，创造深厚疏松的活土层；深耕可以改善土壤孔隙状况，加深活土层，提高保墒能力，增强通气性，促进微生物活动，提高土壤有效养分的供应，促进作物根系伸展，减少病虫害。深耕一般可增产10～15%，有的达到三倍以上。
3. 增加有机肥料，提高土壤肥力；以有机肥料为主，有机肥料和无机肥料配合施用，可以增加土壤有机质和养分，改良土壤紧密质，提高土壤肥力。
4. 客土改良，调剂土壤；粘重土壤土质硬，保水保墒好，但土性凉，通气差，耕作不便，砂质土，土质疏松，耕性好，通气性强，但保水、保墒性差。针对这些特点，采取客土方法，粘质砂壤地长补短，把肥料送过耕层混合到犁底层，砂质土里加进一些粘土可以增加耕层土壤的水、肥、气、热状况。
5. 因土施肥，提高养分利用率。砂质土壤有机质少、保肥力差、养分缺乏，造成生物生长发育易衰。应增施有机肥料，追肥宜少量多次。粘质土壤保肥力强，养分转化慢，宜用发酵的有机肥料作基肥，注意施用应随作，随施肥。阳地应用速效肥，牛粪等速效肥料；阴地，下地应宜施腐熟鸡粪等热性肥料。生土地上最好施有机肥料，配合施用速效性氮肥和磷肥。

# 制定育种目标

进行育种工作时须首先调查了解当地地土墒系条件、栽培水平、主要病虫害以及当前品种存在的问题，并应预见今后一个时期生产发展、耕作制度、农业机械化、水肥条件的改善对品种提出的新要求，抗住主要矛盾，制定育种目标。一般地说，制定育种目标时，应考虑以下几点：

高产 要有良好的丰产性状和增产潜力，如小麦要求戴穗率高、穗粒数多、千粒重大、籽粒饱满等。

稳产 有较强的抗逆性，对当地经常出现的自然灾害如病、虫、旱、涝等抵抗力强。适应性广，在不同年份能稳产。

品质好 酿酒等要求出粉率高，蛋白质多多，油料作物要求含油率较高；

生长期适宜 要根据品种与当地气候条件，新作制度相适应。

# 主要育种途径

引种 就是从外地引进优良品种，经试验鉴定，从中评选出好的品种繁育推广。引种时应注意以下几点：

- 1. 每个良种都有一定的适应范围，引种时，要对原产地经纬、海拔、日照、雨量、气候和栽培条件等进行了解，凡是这些条件与本地大体相近的，引种较易成功。
- 2. 引进的品种一定要经过多次观察、品种比较和生产示范等试验。确有突出优点，经鉴定后繁殖推广，必须时也要从原产地调运种子。对表现较好，但生长不一致的品种，在试验过程中要去杂去劣，提纯复壮，或用系统选育提高。
- 3. 引种时，要严格执行检验制度，以免病菌传染。

# 系统选种

1. 单株选avg：利用现有作物种类的自然变异，选择优良的单株或单穗，对其后代作选择性培育，选出新品种，这种方法叫做单株选择，也叫系统选种，通常称为一条传—霏选。其具体做法是：作物品种，对选择良变单株或单穗，分期分别收、分离处理、与原品种及对照种植进行比较，或选择优良株，如有分蘖，表现不整齐，可进行多次单株选择，直至性状一致时，再进行品种比较试验。

2. 混合选种：对单株选植，已形成若干类型品种，可从中选择性状相同的优良单株（单株、混合收获，混合种植，与原品种进行比较，从中选出新品种。如果一次混合选择没有杂交，也可用多次混合选择。此外，还可先进行混合选种，当植株性状趋于一致时，再进行一次单株选择，然后通过鉴定比较，选出新品种，这一种单株与混合结合的选择方法。

| 棉花 | 选中晴凉晾开花第1~2节的花各生植, 下午4时以后, 选取2天将发育的花, 即田花期以各白花以后任咋各对外形的花蕾, 剪子将花蕾轻轻在花台外的做法, 摊落花, 剥开花瓣, 选出花蒂, 用长约3厘米的发夹将丝状针连进行隔。 | 开花前1天, 备父本花冠用细铁丝从卵孔扎下, 防止虫传粉等。第2天上午9~10取采父本花粉, 用纸袋或直授用父本花粉袋, 授粉后将亲上表签并挂钩。 |

（2）杂种二代：将杂种一代中选的组合分解点播，一般1个组合点播1,000株左右。每个组合开头种父、母本各1行，每隔9行或19行种1对照行，以便比较。杂种从第二代开始分离，应根据育种目标、先进性状组成配合，再从中选育优良单株，对表现差的组合，如两个剑叶等单株也选留。

（3）杂种三代：将杂种二代入选的单株旋组合分株点播。每株1个区叫做株系，每系株100株左右。隔9或19系设1对照，杂种三代仍在分离，着重从优良组合中挑选优良的株系，再从中选杂系中选优良单株。

（4）杂种四代：将杂种三代选出的单株旋组合成株系。每隔9或19系设1对照。一般种植到第4代以后基本稳定，可按株系选择。中选的株系作为新品系，混成品种，下年可开整定面积和品系比较试种。确有无推广价值。对仍分离的优良品系，继续单株选育，待性状稳定后再试种。

杂种优势的规律 两个遗传性不同的品种或类型进行杂交所产生的第一代杂种（F₁），往往比亲本具有较强的生长力、适应性、抗逆性和生产力。这种植间杂种优势的表现是多方面的，产量而有，优良组合达到双亲总和最大，而比当地普通优良品种，一般增产2～3成，有的甚至更高。

杂种一代为什么会有这样的高产特性呢？这是因为杂种是由两个具有一定遗传差异的品种杂交而产生的，这就形成了杂种内的遗传生物学矛盾，从而表现出较强的活力，在一定范围内，这种遗传性矛盾越激烈，生长力就越强。

杂种优势现象，只是杂种一代表现较为突出，杂种第二代（F₂）及以后几代，一方面由于亲本性严复分离，植株中的高、有矮的、有旱等的，有返祖的，特别是通过“三系”制配的杂种第二代，还有出现一部分不育株，故产量明显下降。所以在生产上只利用杂种第一代。

选择，可得到性状稳定，生长整齐一致的自交系；优良的自交系之间或品种和自交系之间杂交，或叫配置出适性性强，增产潜力大的杂交种。

- (1) 单交种：由两个优良的自交系杂交而成，如单981一号，其组合为（武105×武102）。单交种增产潜力大，制种简便，因此在生产上主要繁育单交种。
- (2) 双交种：由两个单交种再进行杂交配制成双交种，如陕玉661，其组合为（武105×武102）×（盛24×盛-11）。
- (3) 三交种：一个单交种和一个自交系或普通品种杂交而成，如陕玉883，其组合为（武105×武102）×野糯红。
- (4) 顶交种：一个自交系和一个普通品种杂交而成。如旗顶一号，组合为武105×野糯红。

2. 利用“三分”配制杂交种。有些作物如水稻、高粱等由于人工去雄等技术困难，不易大规模配制杂交种，因而影响杂种优势的利用。为实现和创造这种不育系，并找到维持性和不育保持系和雄性不育恢复系，作为利用杂种优势的创造者有下列条件。

- (1) 雄性不育系，雌蕊正常，具有受精能力，但雄性发育不正常，自交不育或结实率低。优良的雄性不育系应具有不育性稳定，可恢复性好，便于制种等繁殖特点。
- (2) 雄性不育保持系（商品保持系）：将其花粉授给雄性不育系，使其不育性保持传递，并能保持雄性不育种的性状，这样它的基因就是这个被保持系的保持系，通常雄性不育系用“A”表示，雄性不育保持体系用“B”表示，如水稻二九南1号雄性不育系可做成二九南1号A，二九南1号雄性不育保持系可配成二九南1号B。雄性不育保持系繁殖变addon，花粉量多，以利于高产生产。雄性不育系和雄性不育保持体系外观大体相似，但有些性状差异明显。
(3) 雄性不育恢复系（简写恢复系）：它和不育系杂交后能使杂种一代恢复正常的生育和自交繁种的能力，如国家1号高粱恢复系是用8137A和平罗矮绿头杂交而成的，平罗矮绿头就是3197A的一个恢复系。生产上利用价值的恢复系要求具备：恢复能力强，杂种制种繁率高，优良性状多，配合力强，优势明显，植株比不育系高大；花粉发育
