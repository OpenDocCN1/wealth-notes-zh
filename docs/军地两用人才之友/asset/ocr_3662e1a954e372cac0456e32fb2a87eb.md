执行决策，作出决策而不执行，等于于一句话空话。方案选定后，就要制订具体的实施措施和政策，要使决策广大执行者充分接受和透彻了解，要制订相应的各项具体政策，保证决策的正确执行；要把决策目标落实到一个执行单位，明确具体责任；要通过控制系统的报告制度，及时地掌握决策实施过程中的具体情况。在执行决策中，人的因素是重要的。

决策系统。在决策已经付诸实施后，管理人员还不能确定结果一定符合预定的目标，必须要有—套跟踪和检验的方措施，以保证所得到的结果与决策的期望值一致。这套办法包括三个步骤：（1）规定标准；（2）用标准衡量执行情况；（3）纠正偏差。所定标准要用可计算的数值来表示，但并非必须如此。标准应有灵活性，不要显得太死；纠正办法包括：重新做工作，重新对执行人员发出指示，重新制定目标等。

# 企业计划的种类

企业计划按时间分，可分为：长远（期）计划、年度计划和作业计划三类。

# 长远计划

它是指一年以上的较长时间的计划。它所包括的内容，都是有关企业在较长时间内的生产、技术、经济发展的一些重大问题。它一般包括下列项目：

+   （1）企业的产品发展方向。包括主要产品品种和新产品的 ADEVELOPMENT：科研实验项目的提出；产品质量的提高；标准化、系列化等的推 行；以及企业专业化、协作化程度的提高等。

+   （2）企业生产体系的任务。如企业生产能力的扩大变动，机器设备的更新和厂房的建设新建任务；职工人数和企业机构的调整变化 等。
