# （7）其它刀法

+   1. 剞刀法（又称花刀），是适用直刀法和斜刀法将原料切上相成深度的（一一般为原料的三分之二或五分之四）各种刀纹的阵法。用剞刀法在原料表面划上各种花刀纹，不仅使原料易于渗透调味，受热均匀，形成熟透，保持其原地脆嫩，而且使原料受热后弯曲成各种美观的形状，起到美化菜肴的作用。剞刀法主要用于卸带中间或整条鱼等原料。如猪肉、瘦、肚、鹿等（见图12）。
