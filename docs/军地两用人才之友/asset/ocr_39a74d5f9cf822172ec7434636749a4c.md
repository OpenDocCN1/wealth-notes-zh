# 图 喷枪形式

喷漆时将手把压住，压缩空气就从出气嘴喷出，使漆液从出漆嘴中均匀地喷在物面上。

喷涂一般要经过以下几道工序：

底底处理 可按各种物件底部处理项目选用。

除漆处理 处理后的物面干燥后即可进行。
按，表皮二道腻子 批腻子要把物面有大洞和深凹处补平，第一道腻子用先用铲刀刮去表面不平处和腻子残留，再用砂纸打磨平整并拭扫干净，按接批第二道腻子，于后用砂纸打磨平整并拭扫干净。

第一道底漆 这道底漆要稀，以增加后道腻子的结合能力。
就后正底纸 二道底漆打好如果发现有细小漏洞可用腻子补修。腻子干后用砂纸打磨平整，清洁干净。

第二道底漆 干后用砂纸打磨。再用湿布将物面擦净拭干。

 Fuller 二三道底漆 干一或喷涂包透明漆、直涂各一遍。待道漆面都用砂纸打磨后并清扫干净。选用水砂纸要先粗后细。喷漆由嘴距约喷嘴，但不宜过薄或过厚。

擦砂光、上光蜡 砂纸要多磨，直到表面十分平整为止。光蜡擦到出现闪光为止。
