# 绿素

| 名称 | 含硼量(%) | 性质 | 施用方法 |
|---|---|---|---|
| 硼砂 | 30~36 含硼量(%) | 灰白色粉末，不溶于水，迟效 | 与有机肥料堆肥作底肥配施。如能移到施硼无机能力强的腐殖质料，效果更好 |
| 硼酸钾 | 含硼量(%) 48~50 | 白色结晶，生物活性，速效 | 作肥料追肥。每亩用15~30斤 |
| 氧化硼 | 50~60 含硼量(%) | 同上 | 作肥料追肥。对土豆、箱等作物在播种时早撒施撒施 |
| 草木灰 | 6~10 含硼量(%) | 黑灰色，碱性，含有磷、钙、镁、铁和多种微量元素 | 作肥料和追肥。适于种豆种块 |
| 硼酸 | 养分含量 含硼17.5 | 白色结晶粉末，易溶于水 | 与有机肥料合作配成追肥。亩用盐0.2~0.5斤，叶面喷施浓度为0.1~0.2% |
| 硼砂 | 含硼11.3 | 同上 | 用量比硼酸增加一倍，其余同上 |
| 硼酸锰 | 含硼50 | 白色结晶，溶于水 | 与过磷酸钙混合作底肥，亩用量20克，喷施浓度为0.03~0.05%，浸种液浓度为0.05% |
| 碳酸锶 | 含硼40 | 白色结晶，溶于水 | 与农肥作底肥，喷施浓度为0.015~0.15% |
| 硫酸锶 | 含硼24~28 | 粉红色结晶，溶于水 | 作底肥，亩撒2.5~5.0斤，喷施浓度为0.1%左右 |
