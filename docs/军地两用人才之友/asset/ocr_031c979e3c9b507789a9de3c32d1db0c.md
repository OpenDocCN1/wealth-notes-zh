# 收音机的正确使用和维护

# 使用注意事项

+   （1）晶体管收音机通常使用磁性天线。收听时注意调整收音机的方向，使接收的广播信号最强、最清晰。

+   （2）附近电机的、高频电热装置、电磁炉等会影响收听，要通过调整收音机的方向加以避免。

+   （3）无线电波的传播一种是沿地面传播，它比较稳定，不受天气条件影响。但容易被地面所吸收，传播距离近。中波广播主要靠地表面。另一种无线电波由地面向空中发射，经电离层高层反射再向地面复。这种波称天空波，它的传播距离很远，因为电离层的密度、厚度受昼夜日气和季节变化，所以，天空波的频率要很高，短波传播主要靠天空波，所以短波收音机可以接收到的电台。白天电离层变化大，晚上收到的电台数目比白天多，而且声音也更响亮。这种现象不是收音机的故障，而是电波传播方式引起的。

+   （4）半导体收音机以干电池作为电源。干电池有正负极性，在更换电池时不可搞反极性，以免烧坏元件。注意不要将旧和新电池混用，因旧时电能难以留住，大，新旧电池混用也不能发挥新的电池作用。收音机长时间不用时应取出电池，以防止电池渗漏，腐蚀机件。

+   （2）半导体收音机使用时应避免高温高湿的地方。平时应注意防尘，最好用干净细布擦拭。

+   （3）注意防尘防湿的摆弄和来自外来的冲击，以免损坏机壳和机内元件。

（4）最好每天都开一段间，尤其在潮湿的天气里，开关可以驱除潮气，另外，长时间不通电使用，机内的电解电容容易老化失效。

# 收音机的常见故障及排除

# 完全无声 突然完全无声的收音机，可以从以下方面检查排除。

+   1. 电源。

+   （1）可因电池使用日久，电压低落，应更换新电池。

+   （2）可因电池夹引线脱落或端钮严重，接触不良，应予修复。
