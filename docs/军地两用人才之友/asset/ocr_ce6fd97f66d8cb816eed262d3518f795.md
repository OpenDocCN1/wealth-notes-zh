# 续表

| 元素名称 | 主要生理作用 | 作用吸收形态 |
|---|---|---|
| 靶 | 靶对根、茎的生长，核酸分解组织及生殖器官的发育都有一项的作用，能促进蛋白质和氨基酸代谢，增加光合作用，改善有机物供应分配，增强作物抗病能力，能增强豆科植物根瘤固氮能力 | 靶离子 |
| 硅 | 硅是一些氧化还原酶的成分，也是形成细胞壁的成分，它可促进种子发育和幼苗生长，以及花粉发育和花粉管生长 | 二价离子态硅 |
| 锌 | 锌能参与叶绿素的形成，细胞呼吸和氧化还原过程。增加和促进和叶片产生氧素及色素含量，对蜡类代谢起到一定作用 | 阳离子态锌 |
| 钼 | 钼是硝酸还原酶的成分，能促进作物对氮的吸收利用，能提高根瘤菌和固氮菌的固氮能力 | 钼酸离子 |
| 铜 | 铜是各种氧化还原活化的核心元素，能催化酶氧气还原反应，促进叶绿素的形成和加强呼吸作用，并可增强作物的抗逆性 | 铜离子态铜 |
| 锰 | 锰在叶绿体内合成反应中起不可缺少的辅助作用，在叶绿体合成受影响时，它能使叶绿体的光合反应活化 | 氯离子 |
