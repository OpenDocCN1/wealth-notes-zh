各级调度值班人员一定要做好调度值班记录，填好调度日志，包括生产状况情况、生产中发生的问题及产生的原因，当天已处理和遗留的问题等等，都要作出详细记录，并要严格执行交接班制度。

# 2. 调度会议制度

调度会议是调度工作的重要方法。通过调度会议，可以广泛听取各方面意见，集中了解各方面的情况，并在集思广益的基础上作出调度决定，即交与有关单位严格执行。调度会议一般可分为定期调度会，现场调度会，工段（小组）班前班后会。

# (1) 定期调度会，一般由厂部与车间分别召开。厂部调度会由生产厂长主持，生产调度部门负责人参加、各有关科室和车间负责参与。车间调度会由车间主任主持，车间调度组长兼系，车间有关人员及厂部调度委员会参加。

# (2) 现场调度会，是领导会员同有关人员直接到现场讨论和解决问题的活动。

# (3) 工段（小组）班前班后会，是基层单位进行生产调度工作的重要方法。一般由工段长（小组长）主持，如有重要问题，主要调度负责人参加。班前会，主要是布置生产任务及本班应注意的问题和注意事项。班后会，主要总结生产任务的完成情况，总结本班工作经验和教训。

# 3. 各级生产信息反馈制度。为了使各级生产领导及时掌握生产情况，企业的基础调度机构都要建立一套调度信息制度。

从基层单位，都要将本班的计划执行情况迅速地向上级报告。厂级生产调度部门，应将各车间调度报告的当天中午的收获日报等资料，有重点地将各车间的情况，产品质量情况，商品产量情况，以及其它的重要情况，编写生产日报，向有关领导进行汇报反映。
除定期报告外，各级调度人员还应随时地把生产中出现的重要问题，及时向有关领导汇报，以使问题迅速地得到处理解决。
