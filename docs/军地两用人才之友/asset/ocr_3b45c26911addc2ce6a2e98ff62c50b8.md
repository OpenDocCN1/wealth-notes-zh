# 大衣拖拽法：

把大衣两条袖子往里翻，并套在一起。绳带从里面向穿过，一边留环，中间打结，使伤员仰卧在大衣里，头枕在衣袖上，扣上衣纽。腰部用一绳子连同大衣捆在一处。救护者俯卧在地上，将从衣袖中穿出的绳带分别绕在两肩上，拖拉伤员前进。

膝举拖运法：在不需爱护藏的情况于，可以采用膝举拖运运送损伤员。方法是将带于打一环，大小以使用合适为宜。将环的一端套在伤员的两条大腿上，另一端绕在救护者的肩上，救护者一手扶住伤员腰部，收紧在自己怀里，或可以站起身前进（图五十）。
