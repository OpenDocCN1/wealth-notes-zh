# 电铃

# 电铃的选择

电铃，按使用电流的不同可分为：交流（无火花式）和直流（有火花式）电铃两种。按其结构不同可分为：冲击式、外蔽式和内蔽式（外蔽式和内蔽式又称挂板式或插扳式）数种，如下图。

![](bbox=[0.21, 0.32, 0.74, 0.58])

无火花冲击式电铃由铃碗、冲击锤及电磁铁等组成。
无火花外蔽式和内蔽式电铃由轭铁外壳、铃碗、铃锤、簧片、电磁铁圈等组成。
有火花冲击式电铃除了内部有触点外，其外形结构与无火花冲击式电铃相似。
家用电铃，一般多选用交流（无火花式）电铃。挑选时除了注意型号规格外，还应注意铃锤灵不灵。
