# 防空悬浮弹

随着雷达和防空导弹技术的发展，现代作战飞机已由原来高空、高速的发展方向，改变为低空出击、低空突防、低空返回的"三低"战术。现在，许多各放都非常重视能有效地击落低空出击作战的飞机，新技术。在现有的一些战术武器能够有效攻击低空飞行的飞机时，一种新型防超低空武器应运而生，这就是美军近年来所研制成功的“防空悬浮弹”。

防空悬浮弹，也叫做防空悬浮弹。它是一种发射出能悬浮在空中的炮弹，实际上也是一种特殊的火箭炮火。这类炮弹目前主要有两种，一种是完全用金属质成的薄片，另一种是带中心杆干炸药，在金属片中夹有炸药，它们的体积都很小，一般只有几十厘米。具有良好的气动特性，发射后，一般都能在空中悬浮十多秒钟。不管哪种类型的飞机，如果在飞行中吸入或撞摄上这类家伙，就有丧生或严重受伤的危险。

超低空悬浮弹可用火箭、迫击炮、高射炮发射，也可由射器、飞机等发射。发射时，首先把悬浮弹装到一个容器里，发射时，发射装置将装有悬浮弹的容器射到空中，当容器落地后，悬浮弹便四下飞散，像散落在地里的礼花一样，景象十分动人。所以有人称它是能打飞机“的“礼花”。

使用超低空悬浮弹做致射是最优越的战术：在发现敌机后，不需要对敌机进行跟踪，只要飞机能够飞越防空区域就可对目标实施攻击，就可建立起一个攻击的火坝。这种新式武器的诞生，为对付低空袭击的敌机，开辟了一条简单而有效的防空新途径。
