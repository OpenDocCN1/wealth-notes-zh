# 带盒的质量检验

+   (1) 带盒的外形尺寸及各通作孔的孔位、孔径必须符合盒式磁带国际标准的 规定。

+   (2) 带盒表面及内零件必须精密、平整、无掉坑和毛刺，在 0～40℃环境温度下不应有几何变形。高质量的带盒其连接韧摩擦配合严 密，用手操不易感觉出有缝隙存在。

+   (3) 磁带的磁芯与带盒配合良好。手持盒式磁带轻轻旋转时，能明显感觉带芯密闭方向是垂直的。将磁带带入录音机，按下播放键，磁带在盘芯上应该得到缓慢匀。倒带过程不应有大的振荡动作。在按下降键时，音量类极小，对磁带在运行中不应有明显的机械噪音。

+   (4) 带盒两者对叶片有对盒式磁带的质量影响很大。高质量的盒式磁带往往将衬垫及设计成具有各种波浪或瓦形状（如图8），其目的是为了减少磁带盘和衬垫的摩擦力。同时，因其衬垫本身具有弹性，可使磁带盘得到平整。
