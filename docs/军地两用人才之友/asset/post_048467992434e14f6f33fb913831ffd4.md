开始砌第一皮毛石时，要选用比较方正的石块砌在大角处（称角石），角石要选三面方正的毛石，砌好后，把水平线挂到角石上，再砌外皮石（面石）后砌中间石块（腹石）。

砌第二层毛石时，先要试放，并与下层石块错缝，砂浆厚度以40～50毫米，外墙边缝宽30～40毫米的缝口，以便在砌第二个毛石时，挤压成20～30毫米的灰缝，石块应立紧用在侧面打锤头夹，以手锤敲实，如石块不稳可在外侧用小石片垫稳，不能在里面垫石片，以防止砌时歪斜，外侧、外体、影响砌体的质量。

毛石墙方法，基本上与钢筋混凝土相同。为保证毛石墙体的整体性，必须在每一层毛石墙1米左右处，砌一根横向的拉结石（俗称通石或清石），上下层的拉结石要立相错开，在立面上成梅花形。拉结石要选表面比较平整的石块，其长度应不小于墙厚的2/3。砌时要先砌里、外皮石，后砌中间石块，不允许砌成夹心墙，见图12。

# 砌毛石墙应注意几点：

- （1）砌好的石块不要震动。
- （2）如有洞口、沟道，应作预留，不得后凿。有沉降缝处应分两段砌筑，不要搭接。
- （3）基础砌完后要随作回填子，基础面要抹找平层，弹好墙身线砌毛石墙基础。
- （4）毛石砌筑完要用水草等或麻袋盖严养护。
- （5）毛石墙的砌筑高度不得超过1.2米。
- （6）接茬时要有茬高的石块，要清除砂浆，用清水冲刷后再砌。
- （7）每砌一步架要找平一次，封顶时要用1:3水泥砂浆抹平。
- （8）砌完皮数墙，墙面要基本平整，均匀缝的缝子要高出毛石墙面5毫米左右。

# 小型构件的安砌方法

目前常用的通用住宅设计图集，采用的木门窗，洞口都是用标准混凝土预制过梁，代替了砖砌过梁，节约了木材，方便施工，也利于施工进展。

使用门窗、洞口的混凝土小型构件过梁，是由施工方法来决定的：后塞口的门窗是先放混凝土过梁，先立门窗则要后放置混凝土过梁。如采用钢筋一般都是预留窗口，后安窗扇，故也须预先安放混凝土过梁。

相同。构件进入现场应交认真检查，按规格、型编码堆放，便于号码入库。安装时要平稳、牢固，并注意堆放时的安全。如发现构件有局部缺陷，应事先修补好，再行安装；有断裂影响工程质量的，不得使用。

# 下水道闭水试验的方法

室内现有的用水排水管道一般用水泥管或红瓦管，其管端口连接须用水泥砂浆接口并做灌水。管壁上不准开三通眼，如室内外管道管径较大必须用三通眼时，要用水泥加麻刀的砂浆堵塞，最好用防水砂浆（即掺水泥用量3%的防水粉），按设计要求做好防水。在管口连接完毕接头处后，用塑料膜或草帘覆盖养护。经常浇水、湿润，到一定的强度（一般在正常温度下28天左右），全部或局部带

完后，方可做闭水试验。

做闭水试验时，要一端封堵密实，从另一端灌水加压，着管件本身和接口处，有无渗漏现象。常用的方法，是在下水道一端用橡胶皮堵封闭，另一端用堵封闷水，从另一端灌水，加至5~6公斤压力，仔细检查管道的各不带，有无渗漏之处，若属管件本体有裂缝、裂纹渗水，就须另换管件，如是在接口处漏水，就说明接口不牢固，要拧去灰口，重做管口灰口，修复完毕再做闭水试验，合格后回填土。埋好下水管道。在冬季施工不宜用石灰块封堵时，防止冻坏接口处，损坏下水道。不论是在寒温或冬季都不能确定下水道，就立即做回填土，然后再做闭水试验，因不好检验也无从检验修。

# 涂料的组成

涂料品种包括各种油脂漆、天然树脂漆、合成树脂漆以及辅助材料等。涂料既能保护物件免受外界来源各种侵蚀,又能起到装饰的作用。

涂料是一种混合剂,基本上是由粘结剂、颜料、稀释剂和辅助材料（如催干剂、增塑剂、固化剂）等组成。

粘结剂是涂膜于被涂物面，形成坚韧涂膜的主要成分，是主要成膜物质。粘结剂有油料和树脂两类。油料一般多用于干性油，如桐油、亚麻油、崂油等。树脂有松香、虫胶、醇酸树脂、酚醛树脂。硝基纤维素等。在水性涂料中则有各种天然和合成树脂作为粘结材料。

颜料是涂料中的固体部分，也是形成涂膜的组成部分，但不能离开主要成膜物质单独成膜，胶状颜料为次要成膜物质。涂料中所用的颜料基本上分成三类，即着色颜料、防锈颜料和体质颜料。着色颜料主要是使涂料具有色彩,一般常用的品种有：锌红、锌黄、氧化铁红、铅白、铅黄、炭黑、绿青、群青等。防锈颜料主要是使涂料具有防锈功能，常用的一种颜料有：红丹、铬黄、氧化铁等。体质颜料又称填无料，用以增加涂膜的厚度和加强涂膜的体积等，提高涂膜的耐磨和抗久性能。常用的品种有：重晶石粉（硫酸钡）、大白粉（碳酸钙）、滑石粉（硅酸盐）、云母等。

稀释剂由溶剂、助剂稀释剂和稀释剂三部分组成，用以溶解或稀释涂料，改变涂料的稠度，使之便于施工。稀释剂是一些能挥发的液体，并且具有溶解或软化成膜物质的能力，常用的稀释剂有：松香水（200号溶剂汽油）、松节油、汽油、香蕉水、苯、稀释水、乙酸戊酯的俗称、以及各种混合溶剂。

催干剂又各涂料、燥煤、煤头水、它们的作用是加剧涂料的干燥，有和催油反应类。固体的有铅、钴、锰等金属氧化物和金属盐类，目前多使用“铅、锰、钴催干剂”和“液体钴干剂”等液体催干剂。增塑剂用以增加涂膜的柔韧性，克服涂膜硬的缺点，常用的有增塑脂肪酸。

涂料的组成中不加颜料的透明体称为清漆，加有颜料的不透明体称为色漆，在干性油内加大量着色、体质颜料制成的厚膜状物体称为厚漆。

# 油漆材料

漆油 可作为厚漆和防锈漆调配时的油料用，也可单独使用，但油膜柔软，易发粘。

自取漆油 在建筑工地上用的最广，不论木材面、抹灰面和一般物件等刷油前都先用它打底。

厚漆 又名钝油，需要加油，溶剂等稀释后才能使用。可作建筑面漆的涂漆配，也可单独表面涂刷，但光亮度、坚硬性较差。厚漆也可用来调配油色和腻子等。

调合漆 分为油性和酸性两类。油性调合漆适用于室外表面涂刷。磁漆等适用于室内较适宜。

清漆 是一种不含颜料的，以树脂作为主要或唯一的物质的透明油漆，分油漆清漆和树脂清漆两类。油漆清漆俗称凡立水，如酚醛清漆、醋胶清漆、酯酸清漆、醇酸清漆等。树脂清漆不含干性油，如虫胶清漆等。

- 1. 酚醛清漆 适用于木器家具、门窗、板壁等的涂刷及金属表面上光。
- 2. 醇酸清漆 适用于室内外木器和金属面装饰。
- 3. 醋酸清漆 俗称三宝清漆。适用于喷、刷室内外金属、木材表面。
- 4. 虫胶清漆 俗称稀立水。适用于木材面的底漆和高级家具的出光。一般用于木器家具装饰。
- 5. 酚醛清漆，又名喷涂漆，俗称腊光。适用于高级建筑的门窗、板壁、扶手等装饰上。
- 6. 氨基清漆 适用于仪表木壳、收音机、缝纫机台板、家具等涂饰，是一种较理想的涂料。但干燥方法受一定条件的限制，操作比较麻烦。
- 7. 丙烯酸木器清漆 适合喷高级木制品及家具等。

磁漆 是漆添加颜料制成的，干后呈透明色彩。常用的漆漆有：
1. 醇酸磁漆 在耐光、耐霉、坚韧性等方面比酚醛磁漆好，适用于高级建筑的金属、木装饰和家具等表面涂饰。

# 2. 酚醛磁漆 适用于高级建筑中饰室内外一切木材、金属表面。

乙苯乙烯漆 它是用酚醛、脂肪酸做的专用配套品种，有底漆、磁漆、清漆等三种，适用于防腐、耐酸、耐碱、耐盐类的各种物面的喷涂该涂料。还具备不能和其他涂料混合使用。

这种化学漆柔软、不怕震荡，在建筑工程中可作为夹夹着油漆中有漆膜部分的部分涂料层料（即在未施工先将被该涂漆于潮湿的地方，再在该漆面上作油漆施工）。

该类磁漆 适用于装饰运动场木板箱和缝纫机台板等高级清水木制品，以及耐酸碱的木制品。

防锈漆 有油性防锈漆和树脂防锈漆两类。一般的防锈漆对轻金属（如铜）是不适宜的，轻金属表面打底防锈最好使用锌黄醇酸防锈漆。

天然漆 天然漆是用漆液的液汁加工而成。它的优点是漆膜坚固耐用，长期耐水如碱，不裂不粘，耐酸、耐腐蚀。天然漆也有生漆、广漆等品种，生产漆制后成为紫色的漆膜，光亮比漆好，适用于涂刷木门、地面、家具等。生漆可用作胶补料，也可用作底漆。推光漆作用表面 现在油漆厂已研制成各种性能的天然漆。较为适用的有漆膜清漆、醇酸乙烯醋清漆、油焦大漆等。

漆酚清漆 适用于化肥、化工厂设备、机械、农业设备，有油性树、盐水浸泡以及要求耐水、耐酸等工业用木材或木制品。

漆酚环氧树脂 适用于漆等涂饰。深色、罩光，可加颜料染配成色漆，用木器家具、锅具、漆器以及各种车辆内外涂饰。

焕美大漆 适用于木器家具、门窗、室内陈设物的贴金、罩光等，也可根据需要调入颜料制成色漆。

聚醋酸乙烯乳胶漆 是一种优良的墙漆。

# 刷涂材料和调配材料

在刷涂施工中除了用工厂产品和自配油漆外，在刷涂及调配涂料中还需用以下一些材料

石灰 一种是熟制的石灰灰，只需加水调制到适当浓度即可使用，并可加些食盐来增加其附着力；另一种是生石灰块，加水沸制成石灰浆使用。必要时，在石灰水沸腾时加入少量熟桐油，以增加其粘结和防水性能。石灰主要用于内外墙灰面刷浆和在较潮湿的抹面上打底。

大白粉 是一种研磨的白塑土碳酸钙，又名老粉，也叫土粉。它和石灰混合成为大白浆，主要用于墙面、平顶刷白，使用时要在加入浆液、胶皮，以增加附着力。大白一般用于房屋内部，但不能在潮湿的抹灰面上涂刷。大白粉还作调粉油粉、润水粉、调配乳胶漆子的原料。

可柔粉剂 是由细大白粉与颜料研磨再加入干胶（酸酪酸）而制成。使用时要用水浸泡。漆膜的附着力、耐磨性都比大白粉好，适用于室内墙面刷面，使用时需加入少量熟鸡油或酸增加润滑，防止沉淀。

石灰膏 主要用于调配腻子。

鸡黍糜 又名龟角粉（北方地区采用龙须菜），是一种海生植物，它是白胶的主要原料。有时也用龙须菜代替。

皮胶 是一种动物性胶，常用于牛皮胶。加入粉浆中起粘结作用。

血料 一般用作香料，有生血、熟血两种。生血用于打底，熟血用于调配腻子或打底。

色颜料 是一种特殊的颜料，有黄粉粉、黑粉粉、品红、品绿、洋红木（金黄粉）、块状金粉、块状金红、哈巴粉（紫色粉）、黑蓝粉等多种。品色颜料要用酒精（乙醇）和开水来溶解，一般用于室内家具涂装中。

石性颜料 是一种不透明的颜料，有很好的遮盖力。常有的有氧化铁黄、氧化铁红、群青、铅白、炭黑、谐黄、谐绿、朱砂粉。用于室内外涂料为宜。

地蜡 有砂蜡、光蜡、硬蜡（石蜡）等。光蜡比砂蜡更光亮滑，常用于最后面层上光。硬蜡主要用于水泥石面层上光，也可作地漆面上光用。

净石粉 用于虫胶漆施工时撒涂木材棕眼。

# 油漆与染料的调配

油漆品种很多，但不仅需要满足种种工程及设备的要求，还要自己进行调配。各种涂料材料也要需要时进行调配。油漆与染料调配得正确与否，对质量、经久耐用程度及装饰节约等都有直接影响。在调配前要详细查阅产品的出厂说明，充分了解其性能及用途。

# 颜色的调配

各类颜色都可由红、黄、蓝三种最基本的颜色拼成，所以称这三种颜色为原色。图1各原色间构成三角形所指为三种原色，虚线三角形所指为相应的两种原色相加而配成的颜色。其中黄色是最亮的，蓝色是最暗的。与某色对应的另一个色为其补色，补色加入复色中会使颜色变暗淡。从三种原色的互相混合来调，若改变它们相互间的用量，配出的颜色的变化要比两个原色相加还要多。原色或复色用白色冲淡，可得出深浅不同的颜色。

# 涂料的调配方法

配清油 自配清油以熟桐油为主，经稀释〈冬季还需加焦干油〉而成，其主要为木器材料打底用。调配时根据清油所稀释程度和颜料，将一定数量的颜料、熟桐油、松香水〈或汽油〉拌和在起，过80目锦纶纱过滤后即可使用。一般的配合比为1：2.5〈稀释油：松香水〉。

黏稠油 根据配合比例《表2及表3》将全部用量的鱼油加2/3用量的松香水调成混合。把铅油由罐桶内挤出放在干净的铁桶内，倒入少量混合油充分搅拌，直至铅油没有完全都分散开就不能开始就把铅油加得很多稀，待了分钟直至没有出现气泡，然后全部混合油逐渐加入并搅拌均匀。这时可加入熟桐油〈冬季用油也可加入焦干油〉并用100目锦纶纱过滤，再将剩下1/3用量的松香水涂工具铁桶后掺入铅油内即可。如铅油是几种色调配成的，更先把几种铅油稍加混合，配成需要颜色后才再加混合油搅拌。
