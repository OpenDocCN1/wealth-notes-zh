3. 子实体形成和分化 蕈丝培养基这一段时间后，在培养料的上部可见子实体原基出现，它是褐头大的白色朵盛或类梨物。当它们长抵露出孔口，可去掉掉盖让它们继续向外界生长，其后如鸡爪伸出般口。逐渐由白色变黄，顶部伸长并开。在此个时期，温度应控制在25℃左右，相对湿度在75—95%。先继以散射光为宜，温度应光直接照射。其荚子二氧化碳比较敏感，赏盖形成时需每天定时开窗换气。此阶段共需两、三个月的时间。

当子实体长到一定程度，有包被散出，赏盖边缘呈红色时，即可采收。正常京兰盖较大，发有随机时子实体呈条状或魔角状，甚至为群状、球状和不结盖。采下的灵芝可阴干，或放在40—50℃下干燥烘存。

# 虫药饲养及养蜂

# 蝎子

饲养蝎子，要根据其生活习性，尽可能创造适宜的饲养条件。现介绍室内饲养蝎类的简易方法。

+   1. 金丝、绿丝、家庭的盆、缸和罐，洗净后里面放置些土块、瓦片，使蝎子可以躲藏，再投放蛆等，定时给予饵料，也可在人家玻璃内饲养，最好少见光观。
2. 地盆 要选地势平坦，修建蝎池。地基用砖（上口用砖以面砌成）砌高80—100厘米的池子，其内壁的上口用20厘米的薄砖或板一周，以防蝎子爬出。池底布后，里面垫一层砖，上而堆放些砖、瓦片，让蝎子在底下栖息。

3. 养床 蝎房高一般不超过2米（太高不易管理），长宽各2米，用土砖砌成。两块土砖之间，放小瓦片，以少量泥浆粘结为好。门窗可留小孔，以免晚上放灯引诱昆虫。又可通地空气，周圈挖沟，用水混合黄泥一层，不涂防虫为宜。既养床可藏蝎子外透，又可供蝎子饮水。蝎房应保持一定温度，但又要阴凉。入冬后，可停止投食，并饮水。
