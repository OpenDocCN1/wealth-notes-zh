# 内线战

帝国主义军队惯用的战术特点是以突然袭击发动战争，以大雷违反部和新型式雷区电磁地雷截取对方的抵抗能力。帝国军队这种方法在第二次世界大战初期曾收到一些效果，但在近似袭击时以失败告终。

# 会同战

诸军种火炮规模、大范围、全过程的联合作战。各个战斗环节紧密汇一，在任何一环的不足都会导致战争的失败。

# 总体战

实现全国总动员，要求整个国家有应付突然事变的能为。

# 三战结合

在人民战争中，游击战、运动战、阵地战三种作战形态灵活运用。有机结合。三战结合要根据战争的不同阶段的不同战役条件，以其中的一种作战形式为主，以其它两种作战形式为辅。三战结合是毛泽东思想创立的，是人民战争的最佳形式，是我军的传统战法，也是我们未来反侵略战争最有效的作战形式。

# 战略反攻

为追使敌人放松警惕或使敌有战略方面的误判而采取的战略性的进攻行动。反攻是战略防御与战略进攻之间的过渡的东部，带着战略进攻前夜的性质。
