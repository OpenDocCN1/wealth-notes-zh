# 财务与会计的区别和联系

两者的职能不同。财务的职能是组织筹划资金、分配各项收支、监督（事前）经济活动，会计的职能是反映经济活动和经济情况、监督（事后）经济活动和收支过程。两者的工作对象不问。财务工作内容，主要是编制财务计划，进行日常财务业务的组织和分配，会计工作内容，主要是记账、算账、报账、用账、提供必要的会计资料。两者工作方法也不同，财务工作主要运用计划编制、定额管理等方法来加强财务管理，会工作要主要运用设置账业、复式记账、编制报表、登记账簿、成本计算、编制会计报表等核算方法、分析方法和检验方法。这两者虽然各有职，但还有密切的联系。财务为了管理好资金、要借助会计核算的职能，反映提供各种有关数据，才能正确组织资金运动、及时处理各种经济关系。其次，会计为了充分发挥它的职能作用，也需要财务科研活动的。变化情况，并根据财务制度的规定，进行正确的反映和监督。此外，两者还有共同的工作对象、目的和任务。
