# 其它类型水泵

深井泵：
这里一种立式，多级的高压泵，其工作原理与离心泵相同。深井泵在东北地区应用较多。

深井泵由泵体部分、抽水管部分和传动部分组成。图2为外形图，图3为泵体部分结构。
当工作时，水泵部分装入井内，叶轮浸入水下，动力部分装在井上，中间用泵轴相连。由于叶轮在动水面以下，吸水高度不受允许吸上真空高度的限制。启动前不必灌水，运行操作方便，但缺点是效率消耗大，轴长、消耗耐材料，出故障时拆装不方便。深井泵工作见图4。
