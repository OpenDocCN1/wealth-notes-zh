# 止血带的应用

止血带，是一种制止肢体出血的急救用品。常用的止血带是一条三尺长的粗橡皮管，另有绷带皮带、布带、一般在四肢大动脉出血用其它方法止血无效时，才采用这种方法（图十二）。

# 上止血带应注意事项

上止血带应该注意击点。这条的实践经验已经证明，如果四肢大出血加压包扎不能止住血，就在伤口上端动脉止血时，即可止住出血。上止血带的位置距离伤口只要在动脉的远端。这时的好处是，万一肢体发生缺血性坏死时，也不必高位截肢。但是不能把止血带扎在上臂的中间1/3处，因为在这一段肌肉的筋膜体的前后侧有一个动脉斜行于枠体中，管路上肢大部分肌肉在筋膜的钳夹经过这一动脉是通不过，这个沟又很狭窄，如果在这一段扎止血带，就很容易把动脉掩经坏，造成手脚下垂炎症，肢体坏死。上止血带条要，这止血带不能直接扎在皮肤上，应先用三角巾、毛巾或者软平整地垫好在皮肤上，这样才能避免止血带损伤皮肤。止血带应该松紧适度，以止住出血，摸不到动脉脉动为合适。上止血带不能松，松了压力不足，只要止回流的肢脉，血液回流受阻，没有压动脉脉动，血流来源不断，结果是一方面造成血流而无
