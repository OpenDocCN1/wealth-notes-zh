正常：目标逆风运动，则加上风的修正量。

# 提前量应从目标中央算起。

射击方法是：在目标转动的方面，选好待机点，并预瞄随靶，当目标接近时，迅速修正高度，并逐渐增加对机器的压力，待目标进到所需要的射击距离时，不失时机果断击发，切忌犹豫或抢拍机器。如果失去了时机或未命中目标，应迅速转向下下一个待机点，按上述方法继续射击。

这种射击，将瞄准线指向目标运动的前方，取出提前量，平稳地移动身体，并保持瞄准线和谐与瞄口的正确关系，均勻地扣扳机。在追踪中完成射击。追踪距离不宜过长。
对纵向运动目标射击时，应装定距离表尺分划，对向我前进的目标瞄准下半部，对背我逃跑的目标瞄上半部。

# 山地射击

山地地形起伏，气象变化较大，目标与射击位置通常不在一个水平面上，因此，射击姿势不易稳固，观察、测距较困难，向上市或下射击时，射弹 مُ比地射击容易打高，打远。只要根据特点，结合实地进行训练，就能掌握山地射击的技术。

山地射击时，应注意选择隐蔽，射弹干燥和有利于射击姿势稳固的射击位置，并训地观测目标和准确地测童距离。
向上市射击，射击距离尽量提高高（机器瞄准线尽量是水平）。
卧射时，两脚分开与肩并平，身体稍向前倾，两腿伸直或倚倚物体，必须时右腿屈回，使身体紧贴地面。握枪时，左肩稍向里合，右前稍向外张。瞄射和立刻时，身体辐紧，意心掌握左右。
向下射击时，如果地不平适宜（机器枪瞄准线应置适当降低）。
卧射时，肢体要自然地，两脚分开比平地射击稍宽，左手托枪位置稍前，右肘尽量合会转换为抬高。瞄射和立刻时，以姿势稳固为宜。
