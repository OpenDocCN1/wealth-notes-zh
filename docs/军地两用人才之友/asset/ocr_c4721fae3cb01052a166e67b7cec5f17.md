# 生物 战

所谓生物战，就是用某些能引起疾病以至死亡的生物制剂作为武
器，用来杀伤敌人、牲畜和农作物。现在，军事生物学家们已能够培育
传染致病菌，使人类致命的瘟病，如炭疽病和鼠疫等。但是，他
们还没有找到一种行之有效的方法，能够保证这些致病种只害
敌人而不伤害自己。

目前军备竞赛中，超级大国主要是以核武器战争相互威胁。未来
战争的舞台上最可能进行核部队战争。未来的战争，在武器的使用
