+   ①音响效果的关键影响因素是录放磁头的质量优劣。可以打开盖门，并拆下套纸盘，使磁头伸出，仔细观察磁头包角是否圆滑。若有凹陷或不平整现象，部也许造成效果。

+   ②用试听带进行放音，试听喇叭的质量如何，并调节音量，音调旋钮，看其是否控制灵敏，若有失控、间断或跳变现象，说明质量不好。

+   ③进行试录。若选择收录两用机，可以先利用收音机录一段音乐节目，然后放音比较。应当与收音效果接近而不应出现明显失真。再利用机内语聊在距话筒较近一处或靠近一只收音机，然后重放比较。应适当有真实感，而且声音宏大，若录音已载回放的磁带重放一收录一放一记录，再放音，仔细听声音是否干净，有否其他杂音。如果原来记录完全清晰，也无“咔哒”的噪声，说明拾音也是很好的。

# （3）外观要求

主要标准是造型美观，款式新颖，结构紧凑，比例均匀，能给人以美感。
