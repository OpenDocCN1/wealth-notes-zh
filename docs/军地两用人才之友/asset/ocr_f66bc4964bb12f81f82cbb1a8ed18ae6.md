# 室外人像摄影采光

室外拍摄人像最好的时机是假阴天，或晴天薄雾。光线较为柔和，投下的影子不强烈，明亮反差较较正常。四十五度（或侧光三角度）光线是在很情形下常用的光线角度，即太阳高度角照射的方向均匀成45°角。被摄者面向太阳，降为做左或做右，倘被摄子于的影子斜至鼻角处，并在影子上面的顿部形成一三角形的白光照明，这时的光线朝向45°左右，照人脸上会因脸的离垂直光（即顶光），人的眼睛被前额下阴影落没，眼窝、额下额背线重叠，必须用反光板或其他光源消除，反光板可用白板、白布或特制的棚等被操，约四五尺大小最好，它最能折起来以便携带，在太阳时到斜的情形下，只有帽子能透光能造成阴影。背光，即被摄者背向太阳，如光线很柔和，无须使用外补光，当阳光强烈，反差很大的时候，可用闪光灯做补助光（但不宜强，光线一强就失真了）或用反光板把暗部反光。
