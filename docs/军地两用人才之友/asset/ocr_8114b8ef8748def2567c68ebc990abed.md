| 故障现象 | 原因分析 |
|---|---|
| 1. 误差超差规定 | （1）制动磁铁位置不对，不能指挥作用力平衡到，造成磁盘转铁不匀。
（2）相位器布置不当，在功率系数为0.5时误差太大。
（3）铝质转盘和磁瓦位置设置不妥，在轻负载时误差大。
（4）电压元件和电流元件两者间的时间常数太大，或磁盘通路的短路现象，促使转矩减少，轻负载时较误差大。 |
| 2. 有源负载现象 | 出示时“请查”。 |
| 3. 转盘卡住（负载仍常有电） | （1）制动片领取受损，表内有异物卡住转盘。
（2）轴承润滑（使用日久，表内密封不严，制油箱氧化结垢挂上轴承）。
（3）计数器磨损，或计数器转轴不灵活，甚至卡住（一般在轴 0 时或第首机位）。
（4）电动机断电。
（5）端盖内小分子松脱。 |
| 4. 机械故障 | 运输中受剧烈撞击，供电光玻璃，内部铝轴锁住不能转动。 |
| 5. 无负载时，转盘转动不止。 | （1）短路现象电动。
（2）与其它用户分线不均。
（3）电表表头失。 |

家用电表应每隔 2 ~ 3 年后，应检验一次，以保证其正确计量，并进行一次清洗工作与加注润滑油。
