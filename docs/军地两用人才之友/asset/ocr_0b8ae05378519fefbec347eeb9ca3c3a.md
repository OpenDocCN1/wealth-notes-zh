对闪光目标射击。对闪光目标射击，通常先距离表尺、目标闪光时，迅速调整射击姿势。瞄准时，利用护圈（铁）<|start|>m盒盖、微动枪口棱星（或防止将护铁当准星），精确准星（铁山口）。构成瞄准线。当瞄准线对正光点时，果断击发。如果瞄准线对正光点后，光点消失，应立即放松姿勢等待再击发。
如敌人向侧面射击时，应根据枪口火光测定敌人的位置，并对其根据瞄准线射击。

# 对隐目光标射击

对隐目光标射击，应在白天用一定时间体会会据瞄准线的正确位置，然后在夜间反复练习，使其保持一致性。为掌握射手瞄准情况，可用固定枪和夜间瞄准检查瞄准镜。也可能瞄准后不动枪，用白纸放在瞄准镜前，并用手电筒照射，检查瞄准线与镜口的正铃关系。
月光对射击，时发挥白灯的照亮，根据已标定位置，对着目标瞄准射击。对着目标瞄准射击，可将抢略略对准目标射击。也可利用目标附近比较明亮的背景，构成准星与缺口的正铃关系，然后将枪移向目标射击。

# 对隐目光标射击

隐身目标出现突然，暴露时间短，有时位置不固定，不易发现。因此，应不断警惕观察战况，及时发现目标，迅速瞄准瞄准，果断击发。如目标消失，应立即下次可能出现的 位置，作好射击准备，待目标再次出现时，将其消灭。

# 对地面运动目标射击

运动目标的位置、方向、速度和距离不断变化。因此，射击时必须采取适应的前量。
按照当估的方法。对横方向运动目标前量的计算方法是：目标运动速度乘弹飞行时间。按人体宽取瞄准时，提前量除人体宽为0.4米。按弹分尺计算提前量时，提前量除每一分划在突距上相对应的宽度（厘米）。
对斜方向运动目标提前量的计算方法是：横方向的提前量再乘角度函数值（30度为0.5、45度为0.7、60度为0.9）。
