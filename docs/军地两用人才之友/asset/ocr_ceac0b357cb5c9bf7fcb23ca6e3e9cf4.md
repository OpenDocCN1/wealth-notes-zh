# 越针方向

+   1. 缝料缝合皱褶，这种毛病多出现在缝制缝纫时。原因一是面、底线张力都太大，二是用线太粗或太硬，三是压脚压力太大。\n2. 缝针背面发毛或锯齿状。这是因针尖已尖先以笔把缝料纤维切断。\n3. 缝料背面呈一格格的咬破状。这种原因是因针杆尖太损和压脚压力太大的部分。

# 乱送或跳动

使用缝纫机，有时会发现驱动机器很费劲，和提起压脚用手拨动上轮时感到张缓不均匀的情况，甚至在响较高大并带有噪音，这是机器运转方面发展不良的情况。其原因：

+   1. 停养中做脏，零件受润滑影响正常运转，再严重的锈蚀将使机器报废。\n2. 运输不稳，导致机器受损。如果上轮外轮经受压力冲击发生严重偏摆，可用木锤敲击偏侧的相对方向加以纠正。\n3. 缝部部分内有横丝、油污、线头等杂物所致，有的由于没有安装谨或装设过松导致，也有产生运动负载的现象。\n4. 送布牙与针板露出针板而太高以及针板牙槽与送布牙齿相互机械。\n5. 请用缝纫机润滑最易引起机器运转沉重，主要是运转零件断裂油或生锈。\n6. 传动皮带太紧而主轴轮受的拉力过大。相反，皮带过长，主动轮摩擦力减小就会引起逆向的毛病。\n7. 别的修整的机器发生机器运转沉重现象，一般是机头底板下面的顶尖螺丝或锥形螺丝地方过紧，但也可能是机架下的顶尖螺丝和圆轴承螺丝过紧的。这情况以松紧调适适当为止。
