战 军事民主和军事，国家和国家、阶级和阶级、政党和政党、政治集团和政治集团之间斗争的最高形式，是从有私有财产和有阶级以后才有的。战争是政治的继续。按性质可分为正义战争和非正义战争。

# 局部战争 把战争限制在一定地域内的战争。

# 常规战争 使用常规武器的战争。

# 核战争 使用核武器的战争。由于核武器的出现，战争的规模和突发性、破坏性将常增大，对战争的进程和结果都将发生重大影响。

# 现代化战争 大量使用现代化的武器和其他技术装备的战争。它要求诸军兵种密切协同动作，各种类的组织指挥和态势而可能有后勤保障等。

立体战争 在地面（水面、地下）地（水下）、空中以及地下、方同时或交互进行作战的战争。是因地使用于战争以后的开始。随着技术兵器的发展，例如轰炸机、导弹、宇宙航等的使用，直升机等的广泛运用，军队空中机能为得到增强，立体战争的范围将不断扩大。

# 正规战争 以运动战和阵地战为主要作战形式进行的战争。要求有高度的集中指挥，严密的组织计划，密切的协同动作。统一的后勤补给等。

# 游击战争 以分散的游击战为主要作战形式进行的战争。人民革命力量在比较弱小的情况下，为了战胜强大的敌人并获得发展壮大的一种良好的武器斗争形式。游击战以袭击为主要突击方式，它比正规战具有更大的主动性、灵活、迅速、适时、隐蔽性、适应性。

# 被动防御 指主动的防御战。总体被动对敌方选择的方式和全过程。为了贯彻总的战略方针，在不同的战争阶段，又有不同的具体战略方针。
