# 配药时水温一以用50℃以下的温水为宜。

由于大水刷在显影前可能散热显影液的水温，可先调节在60℃，当大苏打溶液降至21℃时，才能加人显性药粉，否则，会产生沉淀，使影像变成乳白色。

操作次序：由于药粉化学反应，应按配方的次序一溶化，加入药品时均应均匀撒在水中，并应定量向不断搅拌，使之彻底溶解以免颗粒结块。

配制好的显影液，显影后，应为无色或淡黄色透明溶液，或略呈淡黄色，印胶片时显影液可以略显浅绿色的透明溶液。如果浑浊不清，或有白色沉淀物，则不能使用。

药液水量及保存。胶卷中药粉的含水量一定要准确。配制色药时更应如此。暂时不用药液的3/4，将各药性品化完后，加水至检量。静置30分钟，用药棉滤去杂质，滴忙、密封于深色玻璃瓶中，放在20℃以下的地方。新配液最好在12小时内，待性随能后使用为好。

以上事项，初配制色药液的要求。如果需要更新时，最好以二份新配的药液与一份用过的药液混合，这样，可使药液的性能稳定，保证冲洗质量。不加补充液的显影液，不能采用这种方法。

# 冲洗方法

冲洗胶卷有螺旋冲洗、盘中冲洗、深箱冲洗和自动冲片机冲洗四种方法。后两种一般摄影者不用，这里只介绍前两种方法。未显影的胶卷，应首先从胶卷或其纸后剪取出胶卷和装进显影袋常的操作要轻重，避免先头生痕或出现条纹。

端中冲洗：螺旋冲洗优于于时定温；与空气接触少，不易产生氧化；酸罩不易够饰。如做显影需照，应把胶卷顺着卷好，避免紧密缠；要用不锈钢或塑料袋。应将胶卷整个心轴轴向两个胶卷，可上手法将胶卷背面靠背面胶；120胶卷应先洗温，然后再装，135胶卷可以干装。120胶卷定影后如背面留有色条，用少量碱溶液即可洗掉。
