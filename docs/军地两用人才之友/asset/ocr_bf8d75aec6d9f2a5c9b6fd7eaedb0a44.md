# 核武器之杀伤破坏作用

原子弹、氢弹爆炸后，产生四种杀伤破坏因素：冲击波、光辐射、贯穿辐射，放射性沾染。

冲击波、光辐射和放射性沾染的作用时间有几秒钟到十几秒钟，放射性沾染的作用时间较长，有时能持续几天到十几天。

+   1. 冲击波；冲击波是核爆炸最主要的杀伤破坏因素。其性质同台风相似，不传速漏速是复合风，压力也比台风大得多。
一颗中型原子弹空爆时，能使距爆心两三至四公里的暴露人员受到中等程度的伤害，对地面上暴露的轻型坦克和各种火焰的破坏半径约为七百到一千米。

+   2. 光辐射；光辐射是核爆炸后火球发出的强光，能烧伤人员皮肤和引起一类物质燃烧。一颗中型原子弹空爆时，距爆心距离点三到四公里内的暴露人员，可可能受到不同程度的烧伤，能使二到三公里内的武器、装备器材的燃烧部分起火燃烧。
由突然出现的闪光时，能使距爆心几十公里内暴露人员的眼睛暂时花。

+   3. 贯穿辐射：贯穿辐射是原子弹爆炸时放出的大量射线。它和爱克斯光相似，但作用要强得多。射线是看不见摸不着的，但它具有很强的贯穿能力，能够穿透各种物体。
贯穿辐射对人体器官没有什么时候破坏作用，但破坏人体细胞组织的正常功能，人类受到一定剂量的照射（100伦以上）后就会引起放射病，出现身体虚弱、头痛、恶心、呕吐、白血球减少等症状。
中型原子弹空爆时，能使距爆心一到两公里以内暴露人员患中等放射病。
