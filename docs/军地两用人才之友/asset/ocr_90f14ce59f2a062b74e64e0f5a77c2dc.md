# 安装玻璃

安装玻璃时要使用油灰。油灰有两种，一种是市售的商品油灰，只要搓和一下就可以使用；另一种是自配油灰，是用大白粉、生桐油加少许熟桐油拌和而成。在橱门窗框配玻璃时，所用的油灰中应加入红丹（防锈油作业）和铅油（增加弹性性和硬固性）的。配好的油灰应具有良好的可塑性，不粘刀或切开，挤时不断裂，不出麻眼。

木门安装玻璃 先在玻璃槽上涂抹2~3毫米厚的打底油灰，再把玻璃上来，用手压住玻璃将底灰挤实，靠在玻璃边缘打好钉子，每边的钉子不能少于两个。钉钉后用铲子轻轻敲玻璃，如发出坚实的声音，表示安装平实。然后将窗口、门门打扫干净，即进行抹油灰。抹油灰一般用大块猪鬃油灰刀进行向前推，使其均匀致密。不能沿线过小，过早造成油灰流失，过长时间不操作。抹后用刮刀收刮油灰，刮成斜形，要求表面光滑，四角整齐。油灰紧贴在玻璃上，不能有空隙，超出玻璃。如有钉子钉露油灰，要避免进入油灰内。抹完油灰后要把挤出的底灰板刮干净。

斜窗或玻璃全装 其方法大致与木门安装玻璃安装方法相同，但须将窗口钉好，用钉子是用钢丝锯和玻璃纸片卡子，将玻璃固定于窗框内，和好后，用手压住玻璃来回移动使玻璃放置在正确的位置。但不能偏重，然后再进行抹油灰。

天窗或玻璃套 其方法同上述安装方法相同。但窗玻璃要用铁卡子扣住，两块玻璃要按等高水拼装，并用子卡牢。斜天窗如坡度大于25％时，两块玻璃要搭接35毫米左右，如坡度小于25％时要搭接50毫米。搭接重叠的腰缝要用油灰嵌实。
