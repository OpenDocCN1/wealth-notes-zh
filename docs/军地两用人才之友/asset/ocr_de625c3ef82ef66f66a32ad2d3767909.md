# “潘兴Ⅱ”导弹

“潘兴Ⅱ”导弹是美国在欧洲部署的机动导弹“潘兴ⅠA”导弹的改型。它弹长十米，重约七吨，射程可在七百四十里到二千四百公里之间任意选择。与“潘兴ⅠA”相比，它不但具有更远的射程和更高的精度，而且还备有多种类型弹头，并具有快速更换目标的能力。 “潘兴Ⅱ”导弹代表美国八十年代初期导弹的水准。

“潘兴Ⅱ”导弹有精确的制导系统，即雷达区域相关控制导装置。雷达对抗装置在导弹的飞行末段开始工作，它能依次完成地面返回与预先存储的目标区地形图像进行比较，确定位置误差，送入弹载计算机，形成控制指令，把弹头导向目标。

“潘兴Ⅱ”导弹装有核弹头，常规定弹和穿地弹头，可以用来打击不同类型的目标。其它中型弹头以600米/秒左右的速度着地。按弹头在穿地爆炸时，对地下设施的破坏作用，要比地爆或空爆的作用大得多。

“潘兴Ⅱ”导弹体积宽巧，发射装置轻便，可以每小时六十公里的速度，在三百公里范围内，沿公路进行“导弹游击战”。由司机转为发射，仅需两分钟，并可实现远程发射。

“潘兴Ⅱ”导弹部部署在欧洲各处，能对整个欧洲的重要军事指挥中心、军队集结地域、与加强、未加固的导弹发射场、以及海、空军基地、后勤补给基地、铁路枢纽和其他军事设施构成威胁。
