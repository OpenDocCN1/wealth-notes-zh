进入钉子轮的缺口，同时在拨动齿轮，凭借轮上的钢针禁止梢杆止著，查出错位处，用工揿要点钢丝，使其距离适当，在调整中测试边试声音，使报时点点一致即可。

+   4. 钟不响、声音，或声音微弱。
    处理由不同，调节震幅和敲的距离适当。震动声音增加。

+   5. 到时不响或响不止。
    出现这种<|start|>故障原因很多，如御针不正，可取下调梁。要用锤时，必须先将字盘（钟）取下，使拨轮转到与时间与钟上定位块夹角（宝盒）对准，然后才发条上。以处理时如无声，要将弹簧片向上弯动，使弹簧片增加张力，使禁止杆的高低适当。

# 电钟的维护和故障处理

普通电钟多是用交流电源的，电压分110V、220V两种。安装时首先了解当地电源电压，否则会烧坏电机的线圈。一般电钟的电压不是固定的，线圈上若有三色线头或装有变压器头，只要变换线头或插头，即可改变电压。电钟侧原都可拆卸，如损坏或机件发生故障时，应将被头拆下，防守时要清洁润滑，不要放在潮湿或灰尘多的地方，以防机器锈蚀和损坏。当发现电钟走动发生“沙沙”声音或敲击微弱，说明机器有润滑油或尘土过多，需要擦拭加油。使用中每隔两年左右，即应擦拭加油一次。

有的电钟接通电源后不走，或开时走动，用了一段时间就不走动。产生此毛病的原因为，一是线圈可能被烧坏，二是某机器间能发生故障。确定方法，一是从外面看著。如钟面玻璃上出现一层烟雾，可肯定是线圈烧坏；二是卸开钟壳的背盖，将钟电钟插进电源，让电流通过线圈，然后用一只细绷的鳄鱼刀，手将电钟两端轻轻敲击电钟里的磁铁，如感到磁铁圈有磁性，即说明线圈上有电流通过，由磁铁圈产生磁性，证明线圈没有损坏。反之，则说明线圈已经损坏。经过检查证明线圈没有损坏，不走的原因肯定是由于机件发生故障造成。
