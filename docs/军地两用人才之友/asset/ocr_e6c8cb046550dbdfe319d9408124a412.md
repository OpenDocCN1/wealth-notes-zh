# （5）靠刀

+   1. 推片刀与拉片刀 推片刀是将刀身放平，与砧（或原料）平行，刀进原料后，由里向外推移的片法。拉片刀是將刀身放平，与砧（或原料）平行，刀进原料后，由外向里移动的片法。这两种刀法适合于煮熟回软的脆性与韧性的原料，如熟笋、玉兰片、肉等（见6～7图）。

+   2. 滚料片 滚料片是左手扶稳原料，右手持刀，先将刀平切进原料，并随着左手的原料向后滚动，刀刃紧紧靠向前面进的一种刀法。
