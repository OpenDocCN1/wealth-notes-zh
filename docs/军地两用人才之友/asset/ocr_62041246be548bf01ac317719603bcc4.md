萌拉手抽屉也叫无拉手抽屉。在大多数情况下这种抽屉在关闭后都露在柜架外，图31（3）就是其中一种。比较好的做法是侧板端部做成燕尾槽，在抽屉面相对位置打一燕尾槽，将侧板从底部嵌入抽屉槽中【参看图31（3）的剖面】。抽面取打板时不需要道。大约为抽屉高度的3/4即可。从上面看是否不出装饰。

抽面在装饰上还有一定的作用，因此抽屉面要尽可能选用质地坚韧、花纹美丽的木材。图31（4）的形式做做，其整体是用窄小的木料纹；外面覆盖一层人造板，四周缝条或不缝条皆可。这样能使的优惠数物。

# 拉手

拉手是做为一种装饰在抽屉和框门上，以材料与有木粒手、金刚手、有机玻璃拉手等。以外形状基本上为长形、圆形、楔形。 一般拉手就装在抽屉面侧板上，并与本来长方形图案。图... 手要在木材表面上凿一孔将其放入。暗拉手即在抽屉面底部做一槽以扣开。

# 斧

一般的桶腿是直接钉到下部的，无须处理。对套配式桶腿，为了稳固还可在后面板上木螺丝。

在小、中槽的结构中为顶负底部狭缝的下垂，可在两面中间内侧打槽，装入一木板，也起较好的加固作用。

# 子

普通的椅子见图32，是由框架和椅面组成。因为椅子前面略高后面略小，所以其榫接和一般家具不同，如果两副榫板的两端做成呈斜形（榫面和榫头不相直）。两榫接板的榫头有两种做法，一种是直槽，一种是斜槽。若为直角时螺钉要做斜，从理论上说直榫是好的，但缺点是斜腿不好看，如果本身不过硬则反之则反之。斜榫直观优、缺点和前者相反。榫头偏斜因斜缝方向的改变质量不好，但垂直时却较方便，因此一般都使用斜榫眼。这两种做法都可，在若本身过硬做的情况下是以直槽眼为好。

为了考虑坐的舒服，后腿上部要有一定斜后倾，一般和椅面成100°的夹角。前腿最好将处理的上大下小并将角倒圆，这样从造型上看起来很稳。前面的椅腿距离榫板两边的尺寸为80～100毫米。
