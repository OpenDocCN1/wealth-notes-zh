# 吸音材料的选取；

为了减小或消除声波的反射，避免产生线体的空鸣声，箱体内的各反射面上铺一层吸音材料，如玻璃、棉絮、泡沫丝、旧毛毯、多孔泡沫塑料等，其厚度一般为15～20毫米，并将钉钉牢在箱体内。判别箱内吸音材料的数量是否合适，可用一只1.5V电池弛断地触音箱引出栓，在电路断开的瞬间仔细听听音箱发出的声音。如果声音短促而微弱，信号没有拖尾现象，就表明吸音材料的阻尼合适，即厚度适宜。
